# 讲透图：图宇宙全景（五部）

> **图是万物的骨架**：社交网络、分子、程序、注意力、马尔可夫链、宇宙纤维——把实体当点、关系当边，图是**关系结构**的通用语言。本系列五部全景：**数学之图**（图论/谱/组合极值/拓扑/子式）→ **网络科学**（复杂网络/社群/中心性/动力学）→ **学习之图**（表示/GNN/表达力/生成/大图系统）→ **状态之图**（自动机/马尔可夫/Petri/模型检测/数据流图）→ **应用之图**（知识图谱/分子/芯片/推荐）。
