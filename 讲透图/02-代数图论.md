# 02 · 代数图论：谱的心脏

> **一句话**：把图写成矩阵，矩阵的特征值（谱）就是图的"心电图"——连通性、社群结构、随机游走速度、GNN 的表达能力，全部写在谱里。
>
> 实验配套：[`experiments/karate_spectral.py`](./experiments/karate_spectral.py)（Laplacian 谱 + 谱聚类 Karate Club，出图 `spectral.png`）

---

**1973 年，Fiedler 发现了一个特征值。** 捷克数学家 Miroslav Fiedler 研究拉普拉斯矩阵的第二个最小特征值时，意识到它度量图的"连通强度"——后人把它叫作**代数连通度**（algebraic connectivity，记 λ₂ 或 a(G)）。一个纯矩阵的特征值，居然精确刻画"这个图有多难被切成两半"。这一发现打开了**图 ↔ 谱**的双向之门：图的问题用矩阵解，矩阵的性质用图理解。今天：谱聚类（数据科学标配）、Cheeger 不等式（几何分析）、GNN 的谱根（深度学习）、混合时间（马尔可夫链）——全是 Fiedler 那扇门里的风景。

---

## 一、直觉层：图的心电图

把图 G=(V,E) 写成矩阵有两种基本姿势：

- **邻接矩阵 A**：A_ij=1 若有边。特征值管"走多少步能回到自己"（闭合游走计数）
- **拉普拉斯矩阵 L = D − A**（D=度对角阵）：**L = 每条边的 (e_i−e_j)(e_i−e_j)ᵀ 之和**——它是"图的能量算子"

**心电图读法**（无向图 L 的谱 0=λ₁≤λ₂≤…≤λ_n）：
- **λ₁=0 恒成立**（常数向量是特征向量）——"什么都不做"的零能量态
- **λ₂>0 ⟺ 图连通**——第二低频振动出现，图是一整块
- **零特征值个数 = 连通分量数**——图断成几块，心电图就有几条零线
- **λ₂ 大** = 连通得紧（难切断）；**λ₂ 小** = 有细脖子（一掐就断）
- **λ_n 大** = 图里有"高对比"结构（比如完全二部图的大明星边）

→ **谱 = 图的频率分解**：低频=全局结构（分量/瓶颈），高频=局部对比（边的不均匀）。这正是傅里叶分析在图上的推广——**图信号处理**（GSP）的全部出发点。

## 二、数学层

### 2.1 二次型：L 的能量本义

对任意向量 x ∈ ℝⁿ：

$$x^\top L x = \sum_{(i,j)\in E} (x_i - x_j)^2$$

**证明一行**：按边展开即得。这句话值得盯十秒——**L 度量"x 在边上有多不光滑"**。x=常数 → 能量 0（λ₁ 的本质）；x 想要低能量 → 必须在每条边上变化小 → 低频特征向量沿图缓慢变化 → **Fiedler 向量（λ₂ 的特征向量）的符号自然把图切成两半**——谱聚类的全部原理。

### 2.2 谱聚类（Ratio Cut / Normalized Cut）

最小割问题 min |∂S|（切断最少的边）是 NP 难，但**松弛**成连续问题后正是 Rayleigh 商：

$$\lambda_2 = \min_{x \perp \mathbf{1}} \frac{x^\top L x}{x^\top x}$$

离散的切图指示向量松弛成连续 x，解出 Fiedler 向量后按符号切回离散——**NP 难 → 特征值问题**的经典松弛（与 SDP 松弛 Max-Cut 同族）。归一化版本用 L_sym = D^(−1/2) L D^(−1/2)（防止高度数点主导）。

### 2.3 Cheeger 不等式：谱隙与瓶颈的定量婚姻

对 d-正则图，**Cheeger 常数** h(G)=min over S (|∂S|/|S|)（最细脖子的相对粗细）：

$$\frac{\lambda_2}{2} \;\le\; h(G) \;\le\; \sqrt{2 d \lambda_2}$$

→ λ₂ 与最小割**互相锁定**（差最多平方级）：谱隙大 ⟺ 图是 expander（无瓶颈的"理想连通体"）。**Expander 是图世界的均质刚体**：随机图大概率是 expander——这是 04 章随机图理论的基石，也是"为什么随机化能造出鲁棒结构"的数学答案。

### 2.4 谱与游走：L 与 A 的分工

| | 邻接谱 A | 拉普拉斯谱 L |
|---|---|---|
| 直觉 | 走 n 步回原地的路数（(Aⁿ)_ii） | 振动/扩散的能量 |
| 主特征值 | λ_max(A) 管增长速度（PageRank 用 A/D 的幂迭代） | λ₂ 管连通/聚类 |
| 与 GNN | 谱滤波器的"频域"（22 章 GCN 的谱根） | 谱聚类的引擎 |

### 2.5 谱的全系列伏笔

- → **12 章**：Laplacian 的热方程 ∂u/∂t=−Lu——图上扩散=低通滤波（高频先衰减）
- → **22 章**：GCN = 谱域低通滤波的一阶近似（每层=一次邻域平均=一次热扩散步）
- → **23 章**：**WL 分离谱间隙**（实测 Petersen λ₂(L)=2.000 vs PentagonalPrism λ₂(L)=1.382——标准谱可区分两 WL 不可分图）——谱不只是结构描述子，还是 GNN 可分性的指纹（math-agent C1 方向（注：math-agent loops/ 原报 7.000/5.472 为其项目内部 gap 量纲，非标准 λmax(L)；标准拉普拉斯谱实测 Petersen λ₂=2.000/λmax=5.000，Prism λ₂=1.382/λmax=5.618——两图谱可分结论不变，量纲以 loops/ 原定义为准））
- → **32 章**：随机游走的混合时间 ≤ O(log n/λ₂')（谱隙=收敛速度的定量控制）

## 三、代码层（bash 实跑验证）

```python
# experiments/karate_spectral.py 节选
import numpy as np, networkx as nx
G = nx.karate_club_graph()                       # 34 节点，2 个真实社群
A = nx.to_numpy_array(G); D = np.diag(A.sum(1))
L = D - A
eigvals = np.linalg.eigvalsh(L)                  # 对称矩阵特征值（升序）
assert eigvals[0] < 1e-9                         # λ₁=0（常数向量零能量）
assert eigvals[1] > 0.4                          # λ₂>0：连通且无致命瓶颈
# Fiedler 向量符号 = 谱聚类二分
_, vecs = np.linalg.eigh(L)
fiedler = vecs[:, 1]
labels = (fiedler > 0).astype(int)
acc = max(=(labels == true_labels).mean(), (1-labels == true_labels).mean())
# Karate Club 上谱聚类准确率 ≈ 0.97+（一个特征向量打赢一个模型）
```

## 四、不足与边界（批判）

1. **谱松弛有界但不紧**：Cheeger 只保证 λ₂ 与 h(G) 差平方级——Fiedler 切分可能远差于最优割（细腰多重嵌套时最惨）
2. **谱不唯一确定图**：**同谱不同图**（cospectral graphs）存在——心电图相同的不同病人；谱是图的不变量，但不是完全不变量（这也是 23 章"谱特征做 GNN 判别会漏图"的根源）
3. **特征值计算 O(n³)**：全谱对大图不可行——Lanczos 等迭代法只求前 k 个（数值线代的活，挂讲透数值线代）
4. **静态谱 vs 动态图**：谱刻画快照，流式图的谱漂移理论远未成熟
