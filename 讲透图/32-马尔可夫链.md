# 32 · 马尔可夫链：图上的随机游走

> **一句话**：马尔可夫链 = 带权有向图上的随机游走——转移矩阵就是（归一化的）邻接矩阵。平稳分布是"游走的归宿"，谱隙是"多快到归宿"，PageRank 是"归宿的排序"。
>
> 实验配套：[`experiments/pagerank.py`](./experiments/pagerank.py)（幂迭代 PageRank + 收敛验证，出图 `pagerank.png`）

---

**1998 年，两个博士生给网页排序。** Larry Page 和 Sergey Brin 面对"如何度量网页重要性"——不是数入链（可被刷）、不是人工编辑（扩展不了）——他们让一个随机冲浪者在 30 亿网页构成的图上永无止境地随机跳转：**他在极限状态下停留在各页的时间比例，就是这页的重要性**。PageRank = 马尔可夫链的平稳分布 + 一个 damping 修正。这个三百行的数学（1906 年马尔可夫的链条 + Perron-Frobenius 定理）长成了 Google。本章讲清楚这条从图到"重要性/分布/时间"的完整管线——它同时是物理（扩散）、算法（随机游走）与机器学习（对比学习的负采样器）的公共地基。

---

## 一、直觉层：醉汉、染料与网页

三种形象同一条数学：

- **醉汉游走**（离散）：每分钟沿一条随机出边挪一步——他在哪、将去哪，只依赖当前位置（**马尔可夫性**=无记忆）
- **染料扩散**（连续）：一滴染料在管道网络里随水流散开——浓度分布的演化就是转移矩阵的幂
- **冲浪者**（极限）：随机点链接的网民——长期来看他泡在"结构中心"页面的时间最长

**关键对应**：状态=节点，转移=P（行随机矩阵，即出边归一化的邻接），图连通性 ⟺ 链的不可约性，自环 ⟺ 非周期性。**马尔可夫链不过是把 01 章的图按边权概率化了**——图的每个经典概念在链上都有动力学的化身。

## 二、数学层

### 2.1 转移矩阵与 Chapman-Kolmogorov

P_ij = Pr(X_{t+1}=j | X_t=i)。t 步分布：μ_t = μ_0 P^t——**矩阵幂=分布演化**（与 22 章 S^t 的扩散幂完全同构：GCN 的层间传播=概率传播的骨架）。

### 2.2 平稳分布：归宿的存在与唯一

πP = π。**核心定理（Perron-Frobenius）**：有限、不可约（强连通）、非周期的链存在唯一平稳分布，且任意初始分布收敛于它：

$$\mu_0 P^t \to \pi \quad (t\to\infty)$$

- **细致平衡**（可逆链）：π_i P_ij = π_j P_ji ∀i,j ⟹ 平稳（每个"边界"双向流量相等——统计力学的平衡条件，MCMC 的合法性来源 → 挂讲透概率图模型 05-MCMC）
- 无向图上的简单随机游走：平稳分布 **π_v ∝ deg(v)**——度即热度（直观：度大的房间门多，被路过的次数多）

### 2.3 谱隙与混合时间：多快到归宿

转移矩阵特征值 |λ₁|=1 ≥ |λ₂| ≥ …，**谱隙 γ = 1 − |λ₂|**：

$$t_{\text{mix}}(\varepsilon) \;\le\; O\!\left(\frac{\log(n/\varepsilon)}{\gamma}\right)$$

——**02 章的 λ₂ 在此转世**：谱隙大=快速混合（几步就忘掉初始状态）；谱隙小=链上有瓶颈（Cheeger：瓶颈 ⟺ 小谱隙，双向锁死）。这条不等式是 **MCMC 实用性的命门**（混合慢的采样器=错误的采样器）与**扩展图算法**（随机游走快速覆盖）的理论根基。

### 2.4 PageRank：带传送门的平稳分布

真实网络不总是强连通/非周期，Brin-Page 的修正——**damping**：每步以 α≈0.85 走链接、以 0.15 传送到随机页：

$$\pi = \alpha \pi P + (1-\alpha)\,\mathbf{u} \;\;\Longrightarrow\;\; \pi = (1-\alpha)\,\mathbf{u}\,(I - \alpha P)^{-1}$$

三重威力：①保证唯一平稳（传送打破不连通）②α 控制局部/全局平衡（0.85=经验甜点）③解是良态线性系统——幂迭代 O(迭代×边数) 稀疏可算（30 亿页也扛得住的原因）。

### 2.5 图扩散方程：L 与 P 的血缘

P = D^(−1)A（行随机）。无向图上 P 与 D^(1/2)(I−L_norm)D^(−1/2) 互为换装——**随机游走 ⟷ 热扩散是同一动力学的两种单位制**（概率 vs 温度）。因此：GCN（22 章的扩散步）＝游走的算子 ＝ 低通滤波（02 章）——三章在此闭环。

## 三、代码层（bash 实跑验证）

```python
# experiments/pagerank.py 节选
P = A / A.sum(1, keepdims=True)                  # 行随机化
alpha = 0.85
pi = np.ones(n) / n
for it in range(100):
    pi_new = alpha * pi @ P + (1 - alpha) / n    # 幂迭代
    if np.abs(pi_new - pi).sum() < 1e-12: break  # L1 收敛
    pi = pi_new
assert np.abs(pi @ P - pi).sum() < 1e-9          # 平稳方程验证
# 在 Karate 图上：度最大的节点（1 号教练）PageRank 最高 ✓
# 混合时间实测：谱隙 1-|λ2| 与收敛步数的关系图 → pagerank.png
```

## 四、不足与边界（批判）

1. **无记忆是假设不是真理**：真实用户有会话惯性/回退行为——高阶马尔可夫/强化游走（node2vec 的 p,q 参数正是补丁）付出状态爆炸代价
2. **平稳 ≠ 有趣**：收敛后的分布忘掉了起点——如果你关心"从哪来"（如推荐场景），平稳定理反而碍事（个性化 PageRank=按起点加权的修补）
3. **混合时间常被乐观估计**：谱隙界是上界，实际瓶颈链混合可指数慢（MCMC 的实践陷阱：跑完了还没混合，样本看似随机实则带偏）
4. **静态图假设**：动态网络的时变谱理论（谱隙随时间抖动）尚无正典——流式图上的"在线平稳"是开放方向
