# 🚀 第 5 幕 · 应用：记忆架构选型决策树

## 决策树（核心交付）

```
你的 Agent 需要记忆吗?
│
├─ 否(单次任务) → 不用记忆层, 优化 context 即可
│
└─ 是(跨会话)
   │
   ├─ 任务是「记住用户偏好」?
   │  → OpenAI Memory 风格: LLM 静默抽事实, 用户可编辑
   │
   ├─ 任务是「跨会话知识累积」?
   │  → mem0 风格: 向量+图谱双存储, RRF 融合
   │
   ├─ 任务是「长期自传/时间演化」?
   │  → Zep/Graphiti: 时序知识图谱
   │
   ├─ 任务是「大规模代码库」?
   │  → Augment 风格: 实时语义索引(本质是 RAG+缓存)
   │
   └─ 任务是「OS 式分级内存」?
      → Letta/MemGPT: LLM 自主管理 page in/out
```

## 场景选型表

| 场景 | 推荐方案 | 关键考量 |
|---|---|---|
| **客服 bot** | prompt caching + 短期会话记忆 | 高频重复 prefix → 缓存; 会话内记忆即可 |
| **coding agent** | Augment 式大规模索引 + 缓存 | 整个代码库当 context |
| **陪伴/个性化助手** | mem0 双存储 + 用户可编辑 | 长期偏好, 隐私隔离 |
| **研究助手** | Zep 时序图谱 | 知识演化, 时序查询 |
| **游戏 NPC** | Letta 分级内存 | 类 OS 内存管理, 沉浸感 |

## 五条生产铁律

1. **先优化 context, 再加记忆**（Anthropic 主张）。很多时候「需要记忆」是 context 没管好的症状。
2. **写入要保守**——错误事实一旦写入，污染所有后续。多次确认 + 用户可编辑。
3. **遗忘是 feature 不是 bug**——Ebbinghaus 衰减 + 容量上限 + 主动过期。
4. **多租户严格隔离**——隐私泄漏是生产事故级。
5. **可观测**——记忆命中/未命中/过期都要有日志，否则无法调试。

## 🎬 五幕收束

> 记忆工程 = 把「瞬时高熵经验」固化成「可检索低熵结构」，并精准遗忘噪声。**最危险的不是「记不住」，是「记错且固化」**。生产化核心：写入保守、遗忘积极、隔离严格、可观测。
>
> 用 `故事原语/02-熵论辩证` 收尾：**记忆是认知层的负熵注入，但必须开放——封闭的记忆会变成幻觉的回音室**。
