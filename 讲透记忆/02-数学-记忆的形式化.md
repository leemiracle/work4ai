# 📐 第 2 幕 · 数学：记忆的形式化

第 1 幕留下三问：**写入什么 / 怎么检索 / 何时遗忘**。本幕把它们变成数学。

## 1. 向量检索：cosine 相似度

把每条记忆 $m_i$ 编码成向量 $\mathbf{v}_i \in \mathbb{R}^d$。查询 $q$ 编码成 $\mathbf{q}$。相似度：

$$\text{sim}(\mathbf{q}, \mathbf{v}_i) = \cos\theta = \frac{\mathbf{q} \cdot \mathbf{v}_i}{\|\mathbf{q}\|\,\|\mathbf{v}_i\|}$$

**检索** = 取 top-k：$\text{retrieve}(q) = \arg\max_{i}^k \text{sim}(\mathbf{q}, \mathbf{v}_i)$

**为什么用 cosine 不用欧氏距离？** cosine 只看方向不看幅度，对 embedding 的「绝对长度」无关——而长度常被训练噪声污染。L2 归一化后 $\|\mathbf{v}\|=1$，cosine 等价于点积。

**问题**：单一向量检索只抓「语义相关」，抓不到「关系」（A 是 B 的父亲）。这就是图谱登场的理由。

## 2. 知识图谱：三元组

结构化记忆用三元组 $(h, r, t)$：头实体-关系-尾实体。如 `(用户, prefers, 暗色模式)`。

检索 = 图遍历：从 $h$ 出发沿关系 $r$ 找 $t$。

**向量 vs 图谱的互补**：
- 向量：模糊语义匹配，低精度高召回
- 图谱：精确关系查询，高精度低覆盖

**mem0 的做法**：两者都存，检索时**融合**。这就是 RRF。

## 3. Reciprocal Rank Fusion (RRF)

当多个检索器（向量、图谱、BM25）各返回一个 ranking，怎么合并？Cormack 2009 的 RRF：

$$\text{RRF}(d) = \sum_{r \in R} \frac{1}{k + \text{rank}_r(d)}$$

其中 $R$ 是检索器集合，$\text{rank}_r(d)$ 是文档 $d$ 在检索器 $r$ 里的排名，$k \approx 60$ 是平滑常数。

**直觉**：不看绝对分数（不同检索器分数不可比），只看排名。排名越靠前贡献越大，但用 $1/(k+\text{rank})$ 衰减避免冠军垄断。**这是最稳健的「多检索器融合」公式**。

## 4. Ebbinghaus 遗忘曲线：何时该忘

Ebbinghaus 1885 用自己背无意义音节，测出遗忘规律：

$$R(t) = e^{-t/S}$$

$R(t)$ 是时间 $t$ 后的保留率，$S$ 是记忆强度（与重复次数正相关）。

**Agent 记忆的启发**：每条记忆应有一个「强度」$S_i$，随访问递增（强化），随时间衰减。检索时不仅看语义相似，还看强度：

$$\text{score}(q, m_i) = \text{sim}(q, m_i) \cdot R_i(t)$$

这是 **recency × relevance** 的雏形。完整版加 frequency，成 **recency + frequency + relevance（RFR）**——Letta/mem0 都用某种变体。

## 5. 记忆层的形式化总定义

把以上拼起来，一个 Memory 系统的数学骨架：

$$\text{Memory} = (\mathcal{M}, \text{write}, \text{retrieve}, \text{forget})$$

- $\mathcal{M}$：记忆库（向量 + 图谱 + 元数据）
- $\text{write}(m)$：抽取 $m$ 的事实，去重合并，更新强度
- $\text{retrieve}(q, k)$：多路检索 + RRF 融合，返回 top-k
- $\text{forget}()$：按 $R_i(t)$ 和容量上限淘汰

第 3 幕会用 numpy 实现这个抽象。

## 6. 一个反直觉：检索的不确定性下界

假设记忆库有 $N$ 条，查询相关记忆的真正相似度为 $\mu^*$，噪声 std 为 $\sigma$。top-1 命中的概率随 $N$ 上升而下降（更易被噪声干扰）：

$$P(\text{hit}) \approx \Phi\left(\frac{\mu^*}{\sigma / \sqrt{\log N}}\right)$$

**推论**：记忆库越大，单一向量检索越易失手——必须靠 rerank（粗检索→精排）或图谱精确查。这就是为什么生产系统都是「两阶段检索」。
