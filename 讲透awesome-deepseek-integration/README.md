# 讲透 Awesome DeepSeek Integration

> DeepSeek 集成生态清单仓的中文知识库：按应用场景分类收录接入了 DeepSeek 的聊天应用、生产力工具、IDE 插件、浏览器扩展与 AI 框架，是把 DeepSeek 嵌入日常工具链的选型目录。

## 内容（deepwiki/ 30 页）

- **聊天应用**：EEChat、SwiftChat、4EverChat
- **生产力工具**：ToMemo、钉钉、AingDesk
- **文档工具**：ChatDoc、Refine Reader
- **IDE 集成**：Continue、Neovim 插件、Cline
- **浏览器扩展与 AI 框架**：翻译/助手扩展、Xhay 浏览器、Agent 与数据 AI 框架
- **创意与知识管理**：16x-Prompt、思源笔记

## 用法

先读 `deepwiki/1.2` 集成方法与 `1.3` API 配置页打通密钥/端点，再按场景跳对应章节选工具；写代码场景优先 IDE 章（Continue/Cline），配合《讲透awesome-deepseek-agent》看 CLI 侧，API 细节配《讲透DeepSeek-V3.2-Exp》。
