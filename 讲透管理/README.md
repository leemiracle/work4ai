## 一句话总纲

**管理 = 激励（机制设计）+ 协调（组织结构）+ 控制（度量反馈）+ 演化（学习探索）的四维工程**——每一维都有可计算的算法与可验证的实证；这套武器库既管人类组织，也管 AI Agent 集群，因为底层数学是同一个。

```bash
cd experiments
python3 beer_game.py            # 牛鞭效应 7177× 放大
python3 auction_mechanism.py    # DSIC + 收益等价定理验证

# 浏览器打开 dashboard.html -> 交互计算器 + 全部图
```
