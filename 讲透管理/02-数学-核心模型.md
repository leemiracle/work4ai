# 02 - 数学：核心模型内核

> 管理学六大理论支柱的数学骨架。全部数值实测于 experiments/。

## 1. 交易成本（Coase 1937 / Williamson 1985, Nobel 2009）
**企业边界条件**：扩张直到 边际内部治理成本 = 边际市场交易成本。
关键变量：资产专用性 k、不确定性 u、频率 f。k 高 → 敲竹杠风险 → 纵向一体。
敲竹杠模型：事后纳什讨价各得 1/2 → 专用投资方只回收一半 → 投资不足 → 内化消除。
数字时代回响：平台用"算法+声誉+合约"重新外部化（Uber 不雇司机）。

## 2. 委托代理（Jensen & Meckling 1976）
max E[π−w(π)] s.t. **IC**: e* = argmax U(w(π(e)),e)；**IR**: E[U] ≥ 保留效用。
信息不对称 → 代理成本（偷懒/在职消费/过度投资）→ 解法：激励契约、监督、声誉。

## 3. 机制设计 / 拍卖（Myerson 1981, Nobel 2020）
**显示原理**：任何机制都可被"说真话"的直接机制复现。
**虚拟估值** ψ(v) = v − (1−F(v))/f(v)；最优拍卖 = 给虚拟估值最高且 ≥ 保留价者；U[0,1] 时 r*=1/2。
**收益等价**（实测 N=5：一价 0.6664 ≈ 二价 0.6664 ≈ 理论 0.6667）。
**DSIC**（实测）：二价拍卖真实报价效用 +0.0336 > 抬价/压价一切偏离。
**VCG**：付"你对他人造成的社会损失"，社会福利最大 + 说真话。

## 4. 系统动力学（Forrester / Sterman 1989）
库存调整：dI/dt = max((T−I)/τ,0) − sales，稳态 I* = T − sales·τ（实测 50 = 100−10×5）。
加延迟 L → 二阶系统 → 过冲振荡（实测轨迹 40→72→55→62→60）。
**牛鞭 = 方差放大**（实测 7177×）。控制论稳定性：增益 α↑ × 延迟 L↑ → 极点出单位圆 → 失稳（实测相图见 experiments/deep_bullwhip_control.py：α≥1.5 全线失稳）。

## 5. 前景理论（Kahneman & Tversky, Nobel 2002）
v(x) = x^0.88 (x≥0)；−2.25·(−x)^0.88 (x<0)。实测 v(100)=57.5, v(−100)=−129.5，不对称比 2.25。
解释：沉没成本谬误、确定效应、框架效应——管理决策的系统性偏差。

## 6. 报童与多期库存
单期：Q* = F⁻¹(cu/(cu+co))。实测 CR=0.625 → 订 62.5 分位。
多期：base-stock 策略 + 预测方差膨胀（σ²+τ²）+ 贝叶斯学习。
**实测**：贝叶斯学习 100 期累计利润 **+16.9%**（91,668 → 107,142）——数据驱动库存管理（DDDL）的雏形。

## 附：RCPSP（资源受限调度，NP-hard）
实测：CPM=14（资源无限）→ **RCPSP 精确最优 19**（ILP，容量 2 人）→ 启发式 22。
管理含义：**关键路径未必是瓶颈，关键资源才是**（TOC 约束理论核心）。
