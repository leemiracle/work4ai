## §1 反向传播（Backpropagation）

### 数学 → ML 精确对应

| 数学概念 | 公式 | ML 算法 |
|---------|------|---------|
| **链式法则** | `dz/dx = dz/dy · dy/dx` | 反向传播的每一层梯度传递 |
| **Jacobian 矩阵** | `J_ij = ∂f_i/∂x_j` | 反向传播 = Jacobian-向量积（JVP）|
| **计算图 + 反向模式 AD** | `∂L/∂x = Σ ∂L/∂y_k · ∂y_k/∂x` | PyTorch `loss.backward()` |

### 费曼式讲解
- **直觉**：损失 L 是山顶，参数是要调整的位置。梯度 ∇L 是"最陡下坡方向"。
- **数学**：Jacobian 是多变量链式法则的矩阵形式。反向传播 = 先算输出对损失的梯度，再**反向**乘回每一层的 Jacobian。
- **代码验证**（见下方）：
```python
import torch
x = torch.tensor(2.0, requires_grad=True)
y = x ** 2          # y = x²
y.backward()        # 反向传播
print(x.grad)       # dy/dx = 2x = 4.0  ✓
```

- #3 MIT 18.06 线代（矩阵乘法 / Jacobian）
- #2 多变量微积分（偏导 / 链式法则）
- #5 Berkeley Math 110（线性映射 = 矩阵）

## §2 Transformer / 注意力机制

### 数学 → ML 精确对应

| 数学概念 | 公式 | ML 算法 |
|---------|------|---------|
| **矩阵乘法** | `QK^T` | 注意力分数（query 与 key 的相似度）|
| **softmax** | `softmax(z)_i = e^{z_i}/Σe^{z_j}` | 归一化为概率分布 |
| **缩放点积** | `softmax(QK^T/√d_k)V` | 自注意力（除 √d_k 防饱和）|
| **凸组合** | `Σ α_i v_i, Σα=1` | attention 输出是 value 向量的加权平均 |
| **低秩近似** | `W ≈ UΣV^T`（截断 SVD）| 多头注意力 = 并行子空间 |

### 为什么除 √d_k？（关键反直觉点）
- 当 d_k 大时，`QK^T` 的元素方差 ~ d_k。若不缩放，`QK^T` 值很大 → softmax 进入**饱和区**（梯度≈0）→ 学不动。
- 除 √d_k 使方差回到 1，softmax 在线性区。
- **数学**：这是**高维向量内积的集中现象**（主题 3 高维概率）。

### 需要的数学课
- #3 MIT 18.06（矩阵乘法 / 谱）
- #2 多变量微积分（softmax 的导数）
- #7 概率（softmax = Boltzmann 分布）

## §3 优化器（SGD / Adam / Lion）

### 数学 → ML 精确对应

| 数学概念 | 公式 | 优化器 |
|---------|------|--------|
| **梯度下降** | `w ← w - η∇L` | SGD |
| **动量** | `v ← βv + ∇L; w ← w - ηv` | Momentum SGD |
| **自适应学习率** | `m,v` 一阶/二阶矩估计 | **Adam**（✅ `1412.6980`）|
| **符号函数** | `w ← w - η·sign(αm+(1-α)g)` | **Lion**（✅ `2302.06675`）|
| **凸优化的 KKT** | ∇L = Σλ∇g | 约束优化的最优性条件 |

### 费曼式讲解
- **SGD**：下山，每步沿最陡方向走。
- **Momentum**：像重球滚下山，有惯性，能冲过小坑。
- **Adam**：每个参数有自己的学习率（按历史梯度方差自适应）。平坦方向走大步，陡峭方向走小步。
- **Lion**：只看梯度方向（sign），不看大小——更省内存，大 batch 下更好。

- #20 Stanford CME 364A 凸优化（梯度法/对偶/KKT）
- #18 UT Austin M 383E 数值（迭代法/收敛速率）

## §4 泛化（Generalization）

### 数学 → ML 精确对应

| 数学概念 | 公式 | ML 意义 |
|---------|------|---------|
| **大数定律 (LLN)** | `x̄_n → μ` | 训练 loss 估计真实 loss |
| **集中不等式** | `P(|x̄-μ|>t) ≤ 2e^{-cnt²}` | 泛化界（Hoeffding）|
| **PAC 学习** | `P(err ≤ ε) ≥ 1-δ` | 可能近似正确框架 |
| **VC 维 / Rademacher 复杂度** | 经验过程理论 | 模型容量度量 |
| **Double descent** | 过参数化后 test error 再降 | ✅ `1812.11118` |

### 费曼式讲解
- 经典观点：模型太复杂→过拟合（U 形曲线）。
- 现代发现（double descent）：**继续增加参数越过插值点后，test error 反而下降**！
- **数学直觉**：高维空间里，"插值"的解有无穷多个，SGD/正则倾向选"最简单"的那个（implicit bias）。

### 需要的数学课
- #17 MIT 18.175 概率（LLN/CLT/集中不等式）
- #16 MIT 18.125 测度（经验过程）
- 前沿：见 [`LATEST_RESEARCH.md`](LATEST_RESEARCH.md) 主题 1

## §5 扩散模型（Diffusion）

### 数学 → ML 精确对应（最美的一段数学）

| 数学概念 | 公式 | ML 算法 |
|---------|------|---------|
| **正向 SDE（加噪）** | `dx = f(x,t)dt + g(t)dW` | 数据 → 高斯噪声 |
| **反向 SDE（去噪）** | `dx = [f - g²∇log p]dt + g dW̄` | 噪声 → 数据（✅ `2011.13456`）|
| **score function** | `∇_x log p(x,t)` | 网络要学的对象 |
| **score matching** | `min E‖s_θ(x,t) - ∇log p‖²` | 训练目标 |
| **变分下界 (ELBO)** | `log p(x) ≥ E[...] - KL` | DDPM/VDM 的 loss（✅ `2107.00630`）|
| **Itô 积分** | `∫f dW` | 随机积分（非标准微积分）|

### 费曼式讲解
- **直觉**：把一滴墨水滴进水里（正向扩散=加噪），墨水慢慢扩散到均匀（高斯）。反向扩散 = **倒放这个过程**，从均匀墨水还原一滴墨水。
- **数学**：反向过程由 **score** `∇log p` 完全决定。所以只需要学一个网络 `s_θ` 逼近 score。
- **关键**：为什么能用网络学 score？因为 **score matching** 不需要知道 p 本身，只需要 p 的梯度（可从样本估计）。

### 需要的数学课
- #25 Berkeley Math 218 随机过程（马尔可夫/SDE）
- #26 UT Austin M 387D 随机微积分（Itô 积分）
- #16 测度论（概率测度的严格定义）
- #20 凸优化（变分下界 = 凸共轭）

## §6 RAG / 检索增强（向量检索）

### 数学 → ML 精确对应

| 数学概念 | 公式 | ML 算法 |
|---------|------|---------|
| **内积 / 余弦相似度** | `cos(a,b) = a·b/(‖a‖‖b‖)` | 向量检索（找最相关文档）|
| **embedding** | `φ(text) ∈ ℝ^d` | 文本→向量 |
| **近似最近邻 (ANN)** | HNSW / IVF 索引 | 大规模检索（避免 O(n) 全扫）|
| **KL 散度** | `KL(p‖q) = Σp log(p/q)` | rerank / 分布距离 |

### 费曼式讲解
- RAG = "开卷考试"。先把知识库编码成向量存好，提问时把问题也编码成向量，找最像的几段（内积最大）塞进 prompt。
- **数学**：内积度量相似度，高维下内积 = 余弦（归一化后）。

### 需要的数学课
- #3 MIT 18.06（内积/投影）
- #22 信息论（KL = 信息距离）

## §7 RLHF / 对齐训练

### 数学 → ML 精确对应

| 数学概念 | 公式 | ML 算法 |
|---------|------|---------|
| **KL 散度** | `KL(π‖π_ref)` | RLHF 防止策略偏离太远 |
| **奖励模型** | `r_φ(x,y)` | 学人类偏好 |
| **策略梯度** | `∇J = E[∇log π · A]` | PPO（强化学习优化）|
| **DPO（直接偏好优化）** | 把 RLHF 变成分类 loss | 用 Bradley-Terry 模型 |
| **Bradley-Terry 模型** | `P(y_w ≻ y_l) = σ(r(y_w)-r(y_l))` | 偏好建模的数学基础 |

### 费曼式讲解
- RLHF = "用人类反馈训练奖励函数，再用 RL 优化策略"。但 RL 不稳定。
- DPO = "数学上证明：可以绕过奖励模型和 RL，直接用偏好数据训练"——把 RLHF 变成简单的二分类 loss。
- **数学关键**：最优策略 π* 和奖励 r 的关系是 `π*(y|x) ∝ π_ref(y|x)·exp(r/β)`，代入 Bradley-Terry 后 r 被消掉，直接得到 DPO loss。

### 需要的数学课
- #22 信息论（KL）
- #20 凸优化（对偶变换）
- #7 概率（指数族分布）

## §8 用数学诊断 ML bug（10 个真实案例）

这是本文档最实用的部分——**用数学知识精确定位 bug 根因**：

### Bug 1：梯度爆炸（gradient explosion）
- **症状**：训练 loss 突然变 NaN。
- **数学根因**：**Hessian 矩阵的最大特征值 λ_max 过大**。梯度 ∇L 的范数与 λ 相关，深层网络梯度 = 多个 Jacobian 连乘，若每层 ‖J‖>1，梯度指数增长。
- **数学课**：#5 线代（特征值/谱半径）、#18 数值（条件数）。
- **修复**：梯度裁剪（clip ‖∇‖）、残差连接（让 ‖J‖≈1）、层归一化。

### Bug 2：梯度消失（gradient vanishing）
- **症状**：深层网络浅层学不动。
- **数学根因**：每层 Jacobian 的范数 ‖J‖<1，连乘后梯度 →0。sigmoid 的导数最大 0.25，所以深层必消失。
- **修复**：ReLU（导数 = 0 或 1）、残差连接（`h_{l+1}=h_l+f(h_l)`，梯度有直通路径）。

### Bug 3：模式崩溃（mode collapse，GAN）
- **症状**：GAN 生成器只产出几种样本。
- **数学根因**：GAN 训练是**博弈（纳什均衡）**，但 SGD 在非凸博弈中不保证收敛到均衡。判别器太强时，生成器塌缩到能骗过的少数模式。
- **数学课**：#20 凸优化（博弈论/纳什均衡）、#7 概率（KL/JS 散度）。
- **修复**：WGAN（用 Wasserstein 距离代替 JS 散度，梯度更平滑）。

### Bug 4：softmax 数值溢出
- **症状**：`softmax([1000, 1001, 1002])` 溢出。
- **数学根因**：`e^1000` 超过浮点上限。
- **修复**：减去最大值 `softmax(z) = softmax(z - max(z))`（数学上等价，数值上稳定）。
- **数学课**：#18 数值（数值稳定性 / log-sum-exp trick）。

### Bug 5：交叉熵 loss = NaN（log(0)）
- **症状**：模型输出概率为 0 时 `log(0) = -∞`。
- **数学根因**：`log` 在 0 处发散。
- **修复**：加 ε `log(p+ε)` 或用 `logsumexp`。
- **数学课**：#1 微积分（函数定义域/发散）。

### Bug 6：矩阵不可逆（线性回归正规方程）
- **症状**：`w = (X^TX)^{-1}X^Ty` 报错 singular matrix。
- **数学根因**：X^TX 奇异（特征共线 / 样本 < 特征数），行列式 = 0。
- **修复**：岭回归 `w = (X^TX+λI)^{-1}...`（加正则使矩阵正定）。
- **数学课**：#3 线代（正定矩阵/行列式）、#20 凸优化（L2 = Tikhonov 正则）。

### Bug 7：协方差矩阵不正定（高斯过程 / 多元高斯）
- **症状**：采样多元高斯报错。
- **数学根因**：数值误差使协方差矩阵有极小负特征值。
- **修复**：加 jitter `Σ + εI`。
- **数学课**：#3 线代（正定性/特征值）、#7 概率（协方差）。

### Bug 8：KL 散度 = inf（VAE）
- **症状**：VAE 训练早期 KL 项爆炸。
- **数学根因**：后验与先验支撑集不重合时 `KL = ∞`（p>0 而 q=0 的地方）。
- **修复**：用更平滑的先验、warmup KL 项。
- **数学课**：#22 信息论（KL 的定义域/绝对连续）。

### Bug 9：学习率太大导致发散
- **症状**：loss 震荡或上升。
- **数学根因**：学习率 η > 2/L（L 是 loss 的 Lipschitz 常数 / Hessian 最大特征值的倒数），梯度下降发散。
- **数学课**：#20 凸优化（Lipschitz 连续/收敛条件）、#18 数值（迭代法稳定性）。
- **修复**：减小 η、用 Adam（自适应）。

### Bug 10：float16 训练精度损失
- **症状**：fp16 下小梯度被截断为 0。
- **数学根因**：fp16 的最小正数约 6e-8，小于此的数 flush to zero（denormal loss）。
- **修复**：混合精度（fp16 主算 + fp32 主权重）、loss scaling。
- **数学课**：#18 数值（浮点表示/下溢）。
