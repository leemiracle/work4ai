## 一、知识森林，不是知识树（结构决策）

**结论：森林（多父 DAG + 深挖树 + 循环地被），不是单根树。**

证据（Mathlib 2026-02 实测，arXiv:2604.24797）：真实数学的依赖图 **DAG 深度只有 84 层**，跨命名空间边占 **50.9%**——数学是**扁而宽的网**，不是深而窄的树。R2（结构叠加）生成的节点天然多父：Lie 群 = 群 × 拓扑 × 几何，任何单亲树放置都会丢失 2/3 的到达路径。

```
知识森林 = 三层结构
─────────────────────────────────────────────
深挖层（乔木）: 讲透X 单元——在高流量节点上长出的深树（DFS）
节点层（树冠）: 63 个 MSC 类锚点卡 + R1-R5 生成边（多父 DAG）
地被层（菌丝）: LOOP-* 循环卡片——引擎每次点火的痕迹记录
─────────────────────────────────────────────
引擎（天气系统）: 七阶段循环在森林上调度：BFS 点亮节点 / DFS 深挖乔木
```

**森林对循环引擎的四个最大化**：
1. **多路到达**：P 计划阶段从任一父节点都能找到目标节点 → 工具选择更多（测度论 → 概率/遍历/统计三条路都能进）。
2. **复用最大化**：一个 verified 循环的产物（代码/证明/直觉卡）自动被所有下游节点继承（Cantor 集测度代码 → 测度论 → 概率 → 遍历理论）。
3. **增量挂网**：新节点 = 新锚点卡 + 指向已有节点的生成边，永不"重排树"（符合孤儿率 <10% 宪法）。
4. **深挖自由**：DFS（讲透系列）可以在任何节点生根，不阻塞 BFS 主推进——减法优先时砍树冠枝条，不砍根。

> 单棵树唯一胜出的场景：教材写作（线性阅读路径）。那是讲透单元内部的事，不是森林层的事。

## 二、五条生成规则（森林的边语法）

每条边回答："这个分支是怎么从父节点**生成**出来的？"

| 规则 | 操作 | 历史实例（生成的分支） |
|------|------|----------------------|
| **R1 公理反问** | 删掉/取反/局部化某条公理 | 欧氏第五公设→双曲几何；去交换律→非结合代数；整数局部化→p 进数 |
| **R2 结构叠加** | 两个结构压在一起 | 拓扑×群=Lie 群；测度×群=调和分析；代数×几何=代数几何 |
| **R3 对象提升** | 升维/换载体/无穷维化 | 单复变→多复变；矩阵→算子理论；连续→离散化（数值分析） |
| **R4 逆问题** | 把"求"反过来"给" | ODE 的逆=积分方程；正交变换的对偶=抽象调和分析；求根→Galois 理论 |
| **R5 不变量迁移** | 把一个领域的度量工具搬到另一领域 | 同调：拓扑→代数→几何→QFT；谱：图→流形→随机矩阵 |

**内化测试**：拿到任何新分支，能说出"父节点 + 规则"（如 遍历理论 = 拓扑×测度×动力，R2）= BFS 直觉建立。

## 四、七阶段循环协议（引擎）

| # | 阶段 | 你做什么 | 绑定工具 | 硬性产物 |
|---|------|---------|---------|---------|
| 1 | **T 理论** | 三层讲透：直觉→数学→代码 | opencode 读讲透单元；@librarian 查文献 | 知识卡雏形 |
| 2 | **P 计划** | 分解 ≤1h 机器可验证小任务，每条声明验证信号 | @oracle review（YAGNI）；todowrite | 任务清单+验收标准 |

**RL 形式化**：
- `state` = 知识状态（锚点卡库 + 仪表盘）；`action` = P 阶段任务；`policy` = 你的计划器
- `reward` ∈ 五类验证信号：① Lean `0 sorry 0 axioms` ② 符号恒等（SymPy） ③ 数值误差<阈值（mpmath/区间算术） ④ OEIS/LMFDB 命中 ⑤ 显著超 dummy 基线（p<0.05）
- **expert iteration**：每轮把 verified 产物沉淀为下轮 few-shot 示例（= AlphaProof 专家迭代 = 实战案例-Prover数学Agent 的蒸馏三件套）

## 五、Wave 计划表（BFS 调度）

```
Wave 0  (2周)  L0 四锚点：逻辑/集合/归纳/计数      每锚点 1 迷你循环(≤2h)
Wave 1  (4周)  母结构六锚点                        每锚点 1 符号验证 + 1 数值验证
Wave 2  (6周)  主干六锚点：ODE/PDE/复变/泛函/微分几何/变分
Wave 3  (4周)  抽象统一五锚点：范畴/同调/代数几何/Lie/遍历（概念循环=构造型，可 Lean/Sage）
Wave 4  (6周)  交叉应用九锚点：按 E>R>P>M 加权（概率/统计/数值/信息论优先）
Wave 5+ (持续) 前沿汇聚层：仅选 interp / AI-for-Math 相关 3-5 节点 DFS
```

**每节点固定成本（迷你循环三件套，≤2h）**：读（定义+名定理各一，20min）→ 跑（种子实验，60min）→ 挂（锚点卡+生成边，30min）。
**纪律**：同层全部点亮才进下一层；深挖（升级为讲透单元）只发生在高流量节点；BFS 期间 D 阶段 ε-greedy 的 ε 只在同层内随机。
