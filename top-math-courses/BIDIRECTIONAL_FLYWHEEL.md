# BIDIRECTIONAL_FLYWHEEL：双向飞轮操作系统

> **本文档是什么**：把"AI 赋能数学"与"数学赋能 AI"从两条平行TODO合并成**一台机器**。此前的问题：发现引擎（AI→Math）和知识森林（Math→AI 的原料库）各自迭代，但**没有显式的回流管道**——发现不自动变成 AI 改进，AI 改进不自动记录数学来源。本纲定义两环、四类管道、耦合点与度量。

## 〇、核心论题：这不是两个方向，是一个环

$$\text{飞轮扭矩} = \underbrace{D}_{\text{AI→Math 发现率}} \times \underbrace{M}_{\text{Math→AI 变现率}} \times \underbrace{C}{\text{耦合增益}}$$

单环快不等于飞轮快——**断环就是两条平行线**（现状诊断：C≈0.3，大部分发现和知识点还没有回流管道）。三条公理：

1. **每个发现必须带变现路径**（AI→Math 的产物不能停在"候选清单"）；
2. **每个知识点必须带赋能管道**（森林条目的"AI 锚点"升级为"怎么让 AI 变强"，不是"用在哪儿"）；
3. **每个引擎改进必须记录数学来源**（让耦合可审计——C 值是设计出来的，不是许愿出来的）。

## 一、AI→Math 环（发现引擎，已运转）

```
森林供给知识件（不变量/域/模板）
   → 生成（算子+组合枚举+LLM提议）
   → 级联验证（n5→n7→随机→Lean）
   → 幸存者分流：
       ├─ rediscover（校准，量化引擎可信度）
       ├─ 已知加强（如 C1：E≥n+λ1−α vs 2026 新定理）
       └─ 新候选 → 文献查证 → Lean 形式化 → （投稿级）
   → 固化：锚点卡 / 讲透X / mathlib PR
```

**已产出**：T1（NG 三度 rediscover）→ T2（**C1 S 级**，19% 图上强于 2026 新定理）→ T2+（跨分支，埋雷者定理被引擎纠错）→ T3（RL 化，双空间对照）→ T4（AI 数学域开辟中）。

**本环短板**：变现断链——C1 若证明成功，除了"投稿"没有第二条出口。修法见 §二管道 P2。

## 三、耦合点：引擎自举（飞轮最值钱的部分）

发现引擎是 AI 系统 → 森林里的数学可以改进它 → 它产出更好的数学。这是讲透Loop Ch08 IMPROVE 算子 $\mathcal{A}_{t+1}=\mathrm{IMPROVE}(\mathcal{A}_t;\mathcal{S}_t)$ 的**双域版**：改进信号 $\mathcal{S}_t$ 可以来自任务（数学），也可以来自森林（元知识）。

**自举台账**（从今天起强制记账，C 值由此可审计）：

| 日期 | 数学来源 | 引擎改进 | 效果 |
|------|---------|---------|------|

| 08-26 | Loop: 验证阶梯 | T4 级联课程 | ✅ 埋雷 8/8+4/4 |

**③裁决（2026-08-26，基于 ①⑤②④ 结果）**：**3 号任务（攻坚）锁定 C1（E ≥ n+λ1−α）**。
依据：①T4 熵锥线性扫描已证明挖不到 non-Shannon 金子（60 条 LP 不可行全是采样盲区假阳性，全灭）——原候选之一降级；②④μP 线方向对但属学习线非攻坚线；**C1 是唯一具投稿级出口的候选**——且 T4b 教训反向加持（图域随机采样覆盖远好于熵域 Dirichlet，10k 零违反的假阳性风险低）。攻坚三步：(a) 全文献深查 E±λ1±α 族是否已知（1-2 天）；(b) n=8..12 大样本加固；(c) Lean 形式化+证明搜索（接 Prover 十条规律）。若 (a) 命中已知→立即降级为学习材料止损。

## 四、飞轮度量（转速表）

| 指标 | 定义 | 当前 | 目标（3 月） |
|------|------|------|-------------|
| D 发现率 | 机器验证幸存→文献确认为"值得攻"的候选数/周 | ~2/天（T 系列冲刺态） | 稳态 3-5/周 |
| M 变现率 | 森林知识点带已执行赋能动作的比例 | 3/155 ≈ 2% | 15% |
| C 自举率 | 引擎改进中来自数学知识（非工程直觉）的比例 | ~0.4（2/5 次改进） | >0.6 |
| 环延迟 | 发现→变现的平均天数 | ∞（断链） | <30 天 |

M 和 C 是新指标——**它们把"学了 155 个知识点"从囤积变成负债表**（每个未变现知识点都是挂在账上的库存）。

## 五、诚实边界（RSI 悬崖的双环投影）

1. **方向归人不变**：飞轮的转速再高，"攻哪个域、哪条管线值得变现"仍在验证层级顶端之上（2607.07663）——本纲的 §二管道表就是人定的方向，机器只执行；
2. **自举≠无限**：引擎用数学改进自己属于 bounded self-refinement（收敛、可评估、可回滚——每个自举步骤留 git 快照），不是 open-ended RSI。判据：改进的是 $\Sigma$（配置），不碰 $\theta$（不训练模型）；
3. **变现可能失败**：数学好≠工程有用（大量理论界的"赋能"停留在论文比喻）。每条 P1/P2 管道启动前写一行预期效果+验证方式，失败就回滚记账——**飞轮的摩擦力也要测量**。

## 六、执行优先级（两环统一排序，替代各系统各自的TODO）

1. **T4 跑通**（AI 数学域：矩阵不等式+熵锥）——同时喂两环：发现（AI→Math）+ 森林 L3 素材（Math→AI）；
