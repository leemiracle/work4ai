# Princeton Mathematics — 完整课程清单

> **学校**：Princeton University
> **学院**：Department of Mathematics
> **一手来源**：[math.princeton.edu/undergraduate](https://www.math.princeton.edu/undergraduate) + [ua.princeton.edu/fields-study/departmental-majors-degree-bachelor-arts/mathematics](https://ua.princeton.edu/fields-study/departmental-majors-degree-bachelor-arts/mathematics)（2026-08 一手核实）
> **强项**：纯数学（全美第一）、解析数论、几何与拓扑、表示论

---

## 一、为什么 Princeton 数学是首选（纯数学方向）

**与你的方向（ML 理论/概率/数值/优化/信息论）匹配度：★★★**

1. **纯数学全美第一**（US News #1, Shanghai #1）
2. **MAT215/217 是本科分析的标杆**——证明严格、定义精准
3. **FIELDS Medal 制造机**（Wiles, Taylor 等）
4. **小班教学**——本科就能接触到顶级教授
5. **本科研究方向**（junior paper, senior thesis 是毕业要求）

> **不选 Princeton 的理由**：纯数学偏重，与你 ML 工程师方向的应用数学训练**不完全匹配**。建议**主要看 MAT215/217 作为分析/线代的对照参考**，其他课按需选修。

## 二、本科核心序列（**重点**：4 个起点序列）

Princeton 数学最独特的是**大一可选 4 个不同强度的序列**：

### 2.1 标准数学专业序列（推荐）

```
大一秋: MAT 215 Single Variable Analysis
大一春: MAT 217 Honors Linear Algebra
大二秋: MAT 300 Multivariable Analysis I
大二春: MAT 322 Introduction to Partial Differential Equations
```

### 2.2 加速序列（**已经熟悉 proof 的学生**）

```
大一秋: MAT 216 Accelerated Honors Analysis I
大一春: MAT 218 Multivariable Analysis and Linear Algebra II
```

### 2.3 入门 proof 序列（其他专业想接触数学）

```
大一秋: MAT 210 One-Variable Calculus with Proofs
       或 MAT 214 Numbers, Equations, and Proofs
大一春: MAT 215 Single Variable Analysis
```

## 四、与 ML 理论的关联（建议路径）

### 必修 4 课（按顺序）

1. **MAT 215 Single Variable Analysis**——证明训练 + 单变量实分析
2. **MAT 217 Honors Linear Algebra**——本科线代最严格版本
3. **MAT 300 Multivariable Analysis I**——多变量分析
4. **MAT 330 Complex Analysis**（Stein & Shakarchi 教材）

### 选修方向

| 方向 | 推荐课程 |
|---|---|
| 概率 | MAT 514 Theory of Probability |
| 信息论 | MAT 575 Information Theory |
| 代数 | MAT 345/346 Algebra I/II |
| 几何 | MAT 385 Differential Geometry |
| 拓扑 | MAT 429 Topology |
