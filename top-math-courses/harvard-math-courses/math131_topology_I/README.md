# Harvard Math 131 — Topology I: Topological Spaces and the Fundamental Group

> **学校**：Harvard
> **一手来源**：Harvard Undergraduate Brochure 2025-2026

## 课程信息
- **编号**：Math 131
- **先修**：Math 25b 或 Math 55a 或 Math 122
- **教材**：Munkres, *Topology*
- **特色**：点集拓扑 + 基本群

## 教学大纲
1. **Topological spaces**
2. **Connectedness, compactness**
3. **Countability & separation axioms**
4. **Fundamental group $\pi_1$** ★
5. **Seifert-van Kampen 定理**
6. **Covering spaces**

## 与 ML 的关联
- 拓扑数据分析（TDA）
- 流形学习

## 🔬 理论联系实际
1. **紧致性 → 极值定理**: 参数空间正则化 → loss 最小值存在
2. **连续映射 → NN**: 神经网络是拓扑空间的连续映射
3. **商拓扑 → 等变网络**: 集合/图上的网络使用商结构
4. **同伦 → 持续同调 (TDA)**: 数据形状分析 / loss landscape
5. **分离公理 → 度量化定理**: Urysohn 度量化定理 → 可嵌入欧氏空间

## 🆕 2024-2026 最新研究
- **Topological Data Analysis (TDA)**: 持续同调分析 loss landscape ⚠️
- **等变神经网络**: 商拓扑 $X/G$ 上的网络设计 ⚠️
- **Persistent Homology + LLMs**: 表示空间的拓扑分析 ⚠️
