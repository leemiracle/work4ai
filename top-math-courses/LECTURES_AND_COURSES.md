## 四、✨ 核心推荐

### 🥇 第一推荐：Terence Tao Lecture Notes + Blog（数学领域的"David Tong"）

**我必须单独强调**——Tao 的讲义和博客是当代数学自学者最该用的资源：

- **免费**（https://terrytao.wordpress.com + UCLA 页面）
- **覆盖全面**：分析（实分析 / 测度 / 调和分析）/ 概率（高维 / 随机矩阵）/ 数论（解析 / 加性组合）/ 几何 / 数学物理 / ML 理论 / 形式化
- **写得极清晰**——被全球数学学生公认为"当代最好的数学讲义"
- **每篇都配 intuition + 严格 + 历史 + 应用**（和费曼、Tong 一样的风格）
- **现代 + 持续更新**（2007 至今，每周更新）
- **配 MathOverflow / arXiv 互链**

**关键作品**（全部免费）：
- **Tao《Analysis I》+ Lean companion**——你的实分析主战场
- **Tao《An Introduction to Measure Theory》**——测度论最优讲义
- **Tao《Topics in Random Matrix Theory》**——随机矩阵
- **Tao《Higher Order Fourier Analysis》**——加性组合前沿
- **Tao《Additive Combinatorics》**（与 Vu 合著）——该方向圣经
- **Tao blog "Career advice" 系列**——研究者心智
- **Tao blog "What's new"**——每周前沿

**建议**：用 Tao 替代/补充你 30 课路径里**所有分析 / 概率 / 数论**方向的教材。免费、现代、比大多数教材好。

### 🥈 第二推荐：J.S. Milne Lecture Notes（纯代数方向的"Tong"）

- **免费**（https://www.jmilne.org/math/）
- **覆盖**：群论 / 环论 / Galois 理论 / 代数数论 / 类域论 / 代数几何 / étale 上同调 / 模形式 / 群概形 / Abel 概形
- **权威**：每个方向都是全球标准（被多所大学采用）
- **精炼**：每本 100-300 页，无废话
- **持续更新**（Milne 退休后仍在改）

**建议**：用 Milne 替代/补充**所有纯代数方向**（#12 Artin / #13 Artin II / #16 测度外的代数 / 抽代 / 数论）。

### 🥉 第三推荐：Allen Hatcher Algebraic Topology（代数拓扑的全球标准）

- **免费**（https://pi.math.cornell.edu/~hatcher/AT/AT.pdf）
- **覆盖**：代数拓扑全书（基本群 / 同调 / 上同调 / 同伦群）
- **全球标准**：Hatcher 之后，几乎所有代数拓扑课都用它
- **配图丰富**（不像 Bourbaki 那样 dry）

**建议**：学 #14 MIT 18.901 拓扑和后续代数拓扑时的必读。

### 🏅 第四推荐：3Blue1Brown（数学的"Mechanical Universe"）

- **免费 YouTube**
- **覆盖**：微积分 / 线代 / 神经网络 / 微分方程 / 概率 / 几何
- **直觉之王**——让抽象数学变可视
- **对应**：物理的 Mechanical Universe（52 集科普）

**建议**：每开始一个新数学主题，先看 3B1B 该主题系列 1-2 集，建立直觉。

## 六、给你的"免费完整数学教育"路径

如果你想**纯免费**学完 30 课：

```
阶段 0（基础，免费）：
  MIT 18.01 (OCW) + 3Blue1Brown Calculus
  MIT 18.06 (OCW Strang) + 3Blue1Brown Linear Algebra
  MIT 18.02 (OCW Auroux)
  MIT 18.03 (OCW Mattuck)

阶段 1（本科基础，免费）：
  Axler《LADR》+ Axler YouTube（线代严格版）
  Harvard STAT 110 Blitzstein（概率，YouTube + 免费书）
  Tao《Analysis I》+ Lean companion（实分析）⭐

阶段 2（本科核心，免费）：
  Tao《Measure Theory》notes（测度）
  Milne Group Theory + Galois Theory notes（抽代）
  Hatcher Algebraic Topology（拓扑）

阶段 3（本科应用，免费）：
  Tao Probability notes / Williams（概率）
  Trefethen & Bau（数值线代）
  Boyd Convex Optimization + Stanford 视频（凸优化）⭐
  MacKay Information Theory（信息论，免费）

阶段 4（研究生，免费）：
  Tao《Topics in Random Matrix Theory》
  Stein-Shakarchi 4 卷（部分免费）
  Milne 高级 notes（类域论 / étale 上同调）

阶段 5（前沿，免费）：
  Tao blog（持续跟）
  Scholze Bonn lectures（YouTube）
  Buzzard Lean lectures（YouTube）
```

**结论**：纯用免费资源，你能完成 UNIFIED_ROADMAP 30 课的 80%。剩下的 20%（如 Rudin / Hartshorne / Lax）是付费教材，但可借 / 二手。
