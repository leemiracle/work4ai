## 基础题

### Q1（极限）
求 $\lim_{x\to 0}\frac{\sin 3x}{x}$。

> **答案**：$3$（利用 $\lim_{u\to 0}\frac{\sin u}{u} = 1$，令 $u = 3x$）。

### Q2（导数 + 链式法则）
$y = \ln(\cos(x^2))$，求 $\frac{dy}{dx}$。

> **提示**：三层复合。
>
> **答案**：$\frac{dy}{dx} = \frac{1}{\cos(x^2)}\cdot(-\sin(x^2))\cdot 2x = -2x\tan(x^2)$。

## 中等题

### Q3（极值与梯度下降）
$f(x) = x^3 - 3x^2 + 2$：
(a) 求所有临界点并分类
(b) 从 $x_0 = 0$ 出发，$\eta = 0.1$，梯度下降第 1 步到哪里？

> **答案**：(a) $f'(x) = 3x^2 - 6x = 3x(x-2)$，临界点 $x = 0$（$f''(0) = -6 < 0$，局部最大），$x = 2$（$f''(2) = 6 > 0$，局部最小）。 (b) $f'(0) = 0$，梯度为零，不动！（临界点起始的陷阱——实际需要加噪声或从非临界点出发）。

### Q4（积分）
计算 $\int_0^1 x e^{-x}\,dx$。

> **提示**：分部积分。
>
> **答案**：$= [-xe^{-x}]_0^1 + \int_0^1 e^{-x}\,dx = -e^{-1} + (1 - e^{-1}) = 1 - 2/e$。

## 开放题（连接 ML）

### Q5（链式法则 → 反向传播推导）
对 $L = (\sigma(wx + b) - y)^2$，推导 $\frac{dL}{dw}$，并解释为什么这叫"反向"传播。

> **答案要点**：$\frac{dL}{dw} = 2(\sigma(z)-y)\cdot\sigma'(z)\cdot x$，$z = wx+b$。"反向"指从损失 $L$（输出端）逐层向 $w$（输入端）回溯局部导数。详见 [MIT 18.01 exercises Q6](../../mit-math-courses/18_01_calculus/exercises.md)。

### Q6（Newton 法 vs 梯度下降）
对 $f(x) = \frac{1}{2}x^2$，从 $x_0 = 5$ 出发：
(a) 梯度下降（$\eta = 0.1$）多少步使 $|x| < 0.01$？
(b) Newton 法呢？
(c) 为什么深度学习不用 Newton 法？

> **答案要点**：详见 [MIT 18.01 exercises Q7](../../mit-math-courses/18_01_calculus/exercises.md)。(a) ~36 步（几何衰减）。 (b) 1 步（$f'' = 1$，$x_1 = 5 - 5/1 = 0$）。 (c) 大模型 Hessian $f''$ 是 $n\times n$ 矩阵（$n \sim 10^9$），存储/求逆不可行。
