## 教学大纲
1. **Linear programming 建模**
2. **Simplex method** ★
3. **Duality**（LP 强对偶定理）
4. **Integer LP**（ILP）
5. **Branch & bound**
6. **Cutting planes**（Gomory）
7. **Network flows**（max flow, min cut, Ford-Fulkerson）
8. **Matching**
9. **Submodular optimization 入门**

## 与 ML 的关联
- 整数规划用于结构化决策
- 网络流用于图算法
- 学完后：能读组合优化 ML 论文
