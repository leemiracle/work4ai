# 数理逻辑 / 可计算性 / 复杂性（模型蒸馏版）
> 一句话本质：数学把"推理本身"变成了数学对象——逻辑学研究推理的语法与语义如何互锁，可计算性理论划出"机器能做什么"的绝对边界，复杂性理论在边界内按资源价格分层；三者共享同一台发动机：**对角论证**。

- teacher：GLM-5.3（逻辑与计算理论域）
- 验证状态：L1 全过——`experiments/dm_logic_check.py` 14/14 断言 PASS（2026-08-27，python3+numpy+sympy）
- 置信统计：条目级标记 机器验证 14 条 / 教师高置信未核 10 条 / 争议或简化 3 条（§2+§3 逐条前缀；§4 断言清单整体为机器验证级）
- 诚实边界：不可判定性定理无法被有限脚本"证明"；L1 验证的是**证明的构造骨架**（对角模板、编码往返、归约保持）在有限实例上的正确性——星标的含义是"机器抽查通过"，定理级确证归 L3（Lean/Prover，挂账）。

## 1. 直觉链（这个域为什么存在）
1. **为什么形式化**：自然语言论证会自我打架（"这句话是假的"）。
   形式化把"陈述"与"谈论陈述的陈述"分层——推理的**语法**（符号操作）与**语义**（真假指派）剥离后，
   才能问"语法能追上语义多远"。
   → 落点：B2（X↔¬X 恒假：语法层面的自我打架被精确捕捉）。
2. **为什么对角论证是模板而不是技巧**：任何声称"完整枚举了 X"的列表，都能被"第 i 项反对第 i 个"的新对象逃逸。
   康托尔（实数不可数）、罗素（集合悖论）、Gödel（不可证句）、图灵（停机）是**同一骨架的四次部署**。
   前提只有两个：列表可枚举 + 新对象可构造。→ 落点：B1（有限对角逃逸）、B4（quine）。
3. **Gödel 编码一句话讲透**：给每个符号一个号码，整条公式编成一个整数（素数幂积，B5）——
   从此"关于公式的陈述"被翻译成"关于整数的算术陈述"，**算术获得了一面照见自己的镜子**，自指从悖论变成工具。
   → 落点：B5/B6（编码往返 + 唯一性）。
4. **为什么完备性和不完全性不打架**：两个"完备"打不同的靶。
   完备性：一阶逻辑的证明能力**刚好**覆盖逻辑有效性（语法=语义，1929，好结局）。
   不完全性：任何一致、递归可枚举、含算术的公理系统，证明能力**追不上算术真**（真>可证，1931，天花板）。
   → 落点：B3/B3b（G 真而不可证的命题骨架可满足性对照）。
5. **为什么复杂性理论是"价格理论"**：可计算只回答"能不能"，但 n² 与 2ⁿ 是天壤之别。
   P vs NP 问的是核心经济不对称：**验证便宜是否蕴含发现便宜**。
   → 落点：B10（玩具单向函数：求根枚举 38 步 vs 验证 1 步）、B7（NP 证书验证）。
6. **为什么 CoT 能"升维"**：固定深度 Transformer 一次前向 ≈ 常数深度电路（TC0 型上界）；
   CoT 把串行步数变成可变资源——**用时间买深度**，t 步 CoT ≈ 深度 t 的电路。
   表达力阶梯（正则<CFL<P<…）因此与 CoT 长度挂钩（FOREST 域十九·B 的 L3 入口主题）。
   → 落点：B12（a⁴b⁴ 超出 3 状态 DFA——"层级>正则"的最小物证）。

## 2. 定理网络
1. ★ **可靠性定理**：可证 ⇒ 逻辑有效。
   - 为什么：推理规则保真（在一切模型下保持真值）。出处：Enderton。
   - → 关联：语法的"不越界"半边；与完备性合成"刚好"。
2. ★ **Gödel 完备性定理（1929）**：逻辑有效 ⇒ 可证（一阶逻辑）。
   - 为什么：把"非可证"翻译为有限可满足性构造（Henkin 常量法）。
   - → 关联：紧致性的来源；B11 的有限检查器是其工程倒影。
3. ☆ **紧致性定理**：句子集的每个有限子集可满足 ⇒ 整集可满足。
   - 为什么：证明是有穷对象，矛盾必在有限步内现身。
   - → 关联：非标准模型的来源（§3.7）；B11（奇环/偶环 2-着色的有限影子）。
4. ★ **Gödel 第一不完全性定理**：一致、递归可枚举、含算术的 T 存在不可判定句 G。
   - 为什么：对角引理造 G ↔ ¬Prov(⌜G⌝)；T 证 G 则 T 不一致，T 证 ¬G 则 T 不一致（B3 是此推理的命题骨架）。
   - 出处：Gödel 1931（原始文献未核；转述见 Enderton）。
   - → 关联：B3b（G 真而不可证的模型侧写）。
5. ☆ **Gödel 第二不完全性定理**：T 不能证明自身的一致性 Con(T)。
   - 为什么：第一定理的证明可在 T 内部复述；T 证 Con(T) 即证 G，自毁。
   - ⚠（条目内警示：此定理最常被泛化误用，见 §3.1。）
6. ★ **对角线引理**：对任意公式 φ(x) 存在 G 使 G ↔ φ(⌜G⌝)。
   - 为什么：完全构造性——B4 的 quine 是其代码版（"程序打印自身"="公式谈论自身"）。
   - → 关联：一切自指论证的工厂；DM-META 策略 12 的母模板。
7. ★ **停机问题不可判定（Turing 1936）**：无算法对任意 (M,x) 判定 M(x) 是否停机。
   - 为什么：假设判定器 H 存在，构造 D：若 H 说 M(M) 停则死循环，否则停；问 D(D)——H 的任何回答都自相矛盾。
   - → 关联：B1/B2（对角骨架的有限实例）；从"某问题不可判"到"某类不可判"用归约（条目 11）。
8. ★ **Church-Turing 论题**：直观可计算 = 图灵可计算。
   - ⚠（条目内警示：这是**论题**不是定理——"直观可计算"无形式定义；但至今零反例，是数学史上最坚固的工作假设之一。）
9. ★ **时间层次定理**：DTIME(f) ⊊ DTIME(f log f)。
   - 为什么：对角——枚举所有 f 时间的机器，造一个与每台机器恰在一处不同的语言。
   - → 关联：B1 的时间版；"更多时间真的算得更多"。
10. ★ **Cook-Levin 定理**：SAT 是 NP-完全的。
    - 为什么：多项式时间计算过程可编码为多项式大的布尔电路可满足性。出处：Arora & Barak。
    - → 关联：B7（证书验证）+ B8（归约保持）；一切 NP-完全性的根。
11. ★ **多项式归约保持真假**：A ≤p B 且 B∈P ⇒ A∈P。
    - 为什么：归约是多项式可计算的翻译，P 对多项式合成封闭。
    - → 关联：B8（3-Clique→SAT 保真假实例）；B9（2-SAT∈P vs 3-SAT NP-完全——子句长度差 1，世界差一个 P）。
12. ☆ **Ladner 定理**：P≠NP ⇒ 存在既非 P 也非 NP-完全的中间问题。
    - 为什么：延迟对角 + 填充构造（技术上精妙，陈述层面记住"世界不会二分"即可）。
13. ☆ **Baker-Gill-Solovay 相对化障碍**：存在 oracle A 使 P^A=NP^A，也存在 B 使 P^B≠NP^B。
    - ⚠（条目内警示：朴素对角论证相对化，而 P vs NP 需要非相对化技术——"为什么 50 年没证出来"的第一课，见 §3.6/§3.9。）
14. ☆ **Transformer 表达力线（Merrill-Sabharwal）**：对数精度 soft-attention 固定深度 Transformer ⊆ TC0 族；
    t 步 CoT 对应深度 ~t 电路，可逐级越过严格层级。
    - 出处：Merrill & Sabharwal（作者与结论链可靠；具体 arXiv ID 待核——按项目铁律不凭记忆写，FOREST 域十九·B 有导航条目）。
    - → 关联：§5 与 AI 的关联核心；B12。

## 3. 反例与陷阱（模型见过最多人栽的坑）
1. ☆ **"不完全性定理说数学不可靠"**
   - 澄清：它只说**特定形式系统**存在其内部不可判定的句子；ZFC 至今零已知实质矛盾，数学实践照常运转。
   - 修正：不完全性是"公理化能力"的天花板声明，不是"真理崩溃"声明。
2. ★ **"Gödel 句子神秘莫测"**
   - 反例：G 就是对角引理产出的普通算术句子（"我这个号码的公式不可证"）；B4 的 quine 是玩具版——自指可以完全机械地构造。
   - 修正：把"自指"从哲学词汇还原为构造技术。
3. ★ **"完备性与不完全性矛盾"**
   - 区分：完备性作用于**逻辑有效性**（一切模型皆真），不完全性作用于**算术真**（标准模型为真）。
   - 关键事实：逻辑有效句集合 ⊊ 算术真句集合——前者语法可完全追上，后者追不上，毫无冲突。
4. ★ **"停机证明是图灵的灵感魔法"**
   - 谱系反例：康托尔 1891（对角）→ 罗素 1901（理发师版）→ Gödel 1931（可证性版）→ 图灵 1936（机器版）——同一骨架四件套（B1/B2 有限版可亲手跑）。
   - 修正：识别模板比记住定理重要——见 [./DM-META-01-学习元知识.md](./DM-META-01-学习元知识.md) 策略 12。
5. ★ **"NP = '非多项式'"**
   - 反例：NP = nondeterministic polynomial = **证书可多项式验证**的问题类；P ⊆ NP（B7：验证比求解便宜是定义的一半）。
   - 分界实例：2-SAT∈P 而与其只差一个字面量的 3-SAT 是 NP-完全（B9：两种算法 40 个随机实例一致）。
6. ☆ **"P≠NP 已被证明"**
   - 澄清：未解决（Clay 千禧问题）；相对化障碍（§2.13）说明朴素对角技术**原则上不够**。
   - 修正：见到"P≠NP 已证"的标题先查可信来源。
7. ☆ **"一阶逻辑能唯一刻画自然数"**
   - 反例：紧致性 ⇒ 任何一阶算术公理化都有非标准模型（含"无穷大"元素）；一阶归纳公理是公理**模式**而非单一公理，永远追不上"标准 N"。
   - 修正：二阶归纳可范畴刻画 N，但二阶逻辑没有完备证明系统——表达力与可判定性不可兼得。
8. ☆ **"CoT 让 Transformer 理论上万能"**
   - 反例：t 步 CoT 的表达力仍受 t 的多项式时间约束（不是"什么都能算"）；且表达力 ≠ 实际学得会（expressivity 是上界语言，不是可学习性语言）。
   - 修正：正确读法是"CoT 长度买电路深度"的**阶梯结构**（§2.14）。
9. ☆ **"对角论证到处能用"**
   - 反例：BGS 相对化障碍——存在 oracle 世界里 P=NP，也有 P≠NP；朴素对角在 oracle 面前"失明"。
   - 修正：对角需要"可枚举+可反转"两条件，且被相对化；前沿需要穿越 oracle 的技术（arithmeticization → algebrization 层级）。
10. ★ **"quine/自指只是玩具"**
    - 反例：对角引理的全部构造性就藏在 quine 技术（B4）里——"程序输出=自身源码"与"公式断言自身可证性"是同一枚硬币；
      Kolmogorov 复杂性的不可计算性（Berry 悖论版）复用同一构造。
    - 修正：玩具即定理的种子。
