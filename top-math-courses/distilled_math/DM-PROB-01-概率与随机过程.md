# 概率论与随机过程（模型蒸馏版）
> 一句话本质：概率是"把不确定性变成可以加减乘除的测度"，随机过程是"让测度随时间流动"，而鞅是流动中不漂移的那根基准线——一切公平性/无套利/收敛论证都挂在这根线上。

## 1. 直觉链（这个域为什么存在）
1. **为什么需要测度论**：样本空间一不可数，"每个单点的概率"就全是 0，朴素加法失效。Kolmogorov 的解法：只在 σ-代数上规定可数可加测度，单点概率让位于事件概率——概率论从此是分析学的分支，"频率收敛"（大数定律）变成可陈述的定理而非定义。
2. **为什么条件期望是投影**：E[X|G] 是 X 在"G-可测函数空间"上的 L² 正交投影——离答案最近且只准用 G 里的信息。tower property（E[E[X|G]|H]=E[X|H]，H⊂G）就是"先投影到大空间再投影到小空间 = 直接投影到小空间"，纯几何。
3. **为什么鞅是基准线**：鞅 = "过去不给你关于未来期望的任何优势"。整个随机过程论的动作是：找到过程里的鞅（做零漂移校正），然后套 Doob 收敛机器。SGD 的 supermartingale 收敛证明就是这招的工程版（FOREST 域二明确标注的缺口——本卡补桥）。
4. **为什么马尔可夫性是信息压缩**：给定现在，过去与未来条件独立 = "状态"这个词在数学上的合法性证明。记忆压缩成一个点，才有 MCMC/强化学习 state/混合时间分析的整套算法学。
5. **为什么布朗运动是万能极限**：Donsker 不变原理说，任何"方差有限的微粒步"在 √n 重标度下都流形同一个极限——布朗运动是随机游走的"吸引子"。这就是扩散模型、金融定价、统计物理共享同一套数学的原因。
6. **为什么高维概率是反直觉重灾区**：高维高斯"几乎全部质量在厚度 O(1) 的球壳上"（半径相对波动 O(1/√n)）——集中不是发生在均值点附近，而是发生在薄壳/带子上。高维统计的一切惊奇（维度灾难与它背面的"免费午餐"）都源于"测度集中 ≠ 几何集中"。

## 2. 定理网络（骨架 14 条）
1. ☆ **Kolmogorov 扩张定理**：相容的有限维分布族 ⟹ 存在唯一概率测度。
   - 为什么真：半环上的测度可唯一延拓（Carathéodory）。出处：Durrett。
   - → 关联：[DM-REAL-01](DM-REAL-01-实分析与测度.md) 测度论。
2. ★ **强大数定律（精确边界）**：E|X|<∞ ⟺ (X₁+…+Xₙ)/n → EX a.s.
   - 为什么真：可截断 + Borel–Cantelli + 四级数论证；反方向说明这不是技术假设（Cauchy 反例见 P6）。出处：Durrett。
3. ★ **中心极限定理（Lindeberg 形式）**：标准化和 → N(0,1)。
   - 为什么真：小增量在特征函数域是乘性扰动，取 log 后可加，泰勒展开只剩前两阶。→ P4。
4. ☆ **重对数律**：limsup Sₙ/√(2n log log n) = σ。
   - 为什么真：CLT 给一次的尺度，LIL 给所有时间的包络——Borel–Cantelli 在对数尺度精调的产物。
5. ★ **条件期望 = L² 投影 + tower**：E[E[X|Y]] = E[X]。
   - 为什么真：投影幂等（P11 数值）。
6. ★ **Doob 鞅收敛定理**：非负上鞅 a.s. 收敛；L¹ 收敛 ⟺ 一致可积。
   - 为什么真：上鞅的上穿不等式把振荡次数按预算封顶。→ 关联：反例 E5（Galton–Watson，UI 失败活例 P10）。
7. ★ **Optional stopping 三充分条件**：E[M_T]=E[M₀] 成立，若 (a) T 有界；或 (b) 停住的鞅一致可积；或 (c) E[T]<∞ 且增量有界。
   - 为什么真：(a) 逐项取期望 + 控制收敛；(b)(c) 是让"有限截断→取极限"不漏质量的屏障。→ 反例 R3 是本卡最值钱的一条（P9 活演示）。
8. ★ **Gambler's ruin 具体解**（[0,N] 吸收壁，起点 i）：
   - 对称 p=1/2：P(先到 N) = i/N；E[T] = i(N−i)。
   - 非对称：P(先到 N) = (1−r^i)/(1−r^N)，r=q/p（i/N 与线性时长是差分方程 h_i = p·h_{i+1}+q·h_{i−1} 在重根情形的线性解；一般情形特征根 1 与 r）。→ P1-P3。
9. ★ **马尔可夫链收敛定理**：不可约 + 非周期 + 正常返 ⟹ 唯一平稳分布且任意起点收敛。
   - 为什么真：耦合论证——两条链在随机化时刻有正概率相遇。出处：Levin-Peres-Wilmer。→ 反例 R6（P12）。
10. ★ **反射原理与布朗标度**：P(sup_{t≤1} B_t ≥ a) = 2P(B₁ ≥ a)，故 E[sup_{t≤1} B_t]=√(2/π)。
    - 为什么真：路径首中 a 后镜像反射成二对一映射。→ 随机游走版 P8。
11. ☆ **Donsker 不变原理**：一切方差有限步长的游走 → 同一布朗极限。
    - 为什么真：tightness + 有限维分布收敛（CLT）双管齐下；P8 只验证一个矩，定理本体不冒领 ★。
12. ★ **高斯集中 / 球壳现象**：g~N(0,Iₙ) 则 ‖g‖/√n → 1，波动 SD≈1/√(2n)。
    - 为什么真：‖g‖² 是 χ²_n = n 个独立平方和，大数定律的几何化。出处：Vershynin。→ P7。
13. ☆ **Borel–Cantelli I**：ΣP(Aₙ)<∞ ⟹ 只有有限个发生（不需任何独立性）。
14. ☆ **Azuma–Hoeffding**：有界增量鞅 P(|Mₙ−M₀|≥t) ≤ 2exp(−t²/(2Σcᵢ²))。
    - 为什么真：mgf 放缩逐项相乘。→ 关联：FOREST 域二"集中不等式=泛化界原材料"。

## 3. 反例与陷阱（R7 富矿：模型见过最多人栽的坑）
1. **"两两独立 ⟹ 相互独立"**
   - 反例：X,Y iid Bernoulli(1/2)，Z=X⊕Y。三对全部独立（如 P(X=1,Z=1)=1/4=P(X=1)P(Z=1)），但 P(X=1,Y=1,Z=1)=0 ≠ 1/8。
   - 修正：独立性要所有子族同时成立。XOR 分布同时是信息论第一反例（条件互信息爆炸，见 [DM-INFO-01](DM-INFO-01-信息论与编码.md) R3-3）。
2. **"零相关 ⟹ 独立"**
   - 反例：X 取 {−1,0,1} 等概率，Y=X²。E[XY]=E[X³]=0=EX·EY，但 Y 被 X 完全决定。
   - 修正：相关系数只看见线性关系。
3. **Optional stopping 滥用（赌博系统谬误）**
   - 错误直觉："鞅停在任何停时，期望不变"。
   - 反例：对称随机游走从 0 出发，T=首次到达 +1 的时刻：P(T<∞)=1 但 E[M_T]=1 ≠ 0=E[M₀]；根因 E[T]=∞（三充分条件全不满足）。doubling strategy（输就加倍）"稳赢"论证死在这。
   - 修正：先验 T 有界，或证 UI，或证 E[T]<∞+增量有界。P9 用 E[M_{T∧n}]≈0 vs M_T≡1 活演示。
4. **"E[X|Y=y] 逐点不增（条件化必逐点降不确定性）"**
   - 反例（具体 4 格表）：P(X=0,Y=0)=P(X=1,Y=0)=0.01，P(X=0,Y=1)=0.98，P(X=1,Y=1)=0。则 H(X)≈0.114 bit，但 H(X|Y=0)=1 bit > H(X)。
   - 修正：降的是平均 E[H(X|Y·)]；点态可以升——"证据可能局部增加不确定性"的数学形态（信息论卡 R3-2 同款，P11/I9 数值）。
5. **"a.s. 收敛 ⟹ 期望收敛"**
   - 反例：临界 Galton–Watson（后代数 P(0)=P(2)=1/2），Zₙ 是鞅，Zₙ→0 a.s.（灭绝概率 1）但 E[Zₙ]≡1 永不降落。
   - 修正：需要一致可积；"非负鞅 a.s. 收敛"和"它收敛到你期望的地方"是两件事。P10。
6. **"马尔可夫链只要平稳分布存在就收敛"**
   - 反例 1（周期）：{0,1} 上确定性翻转链，分布永远振荡。
   - 反例 2（零常返）：Z 上简单随机游走无平稳分布。
   - 修正：不可约+非周期+正常返三件套缺一不可（P12 双反例+懒惰版修复）。
7. **"高维高斯质量集中在均值附近"**
   - 反例：n=10000 维标准高斯，P(‖g‖ ≤ 0.1√n) ≈ e^{−O(n)} ≈ 0——均值点的任何固定比例小球质量趋零！质量全在半径 √n、厚度 O(1) 的壳上。
   - 修正：集中的是 Lipschitz 泛函（如 ‖g‖ 本身），不是几何位置；"高维球体积几乎全在赤道带"是同一现象的另一面（P7）。
8. **"CLT 对重尾也成立"**
   - 反例：Cauchy 样本均值与单个样本同分布（stable 律，α=1），永不集中。
   - 修正：有限方差（Lindeberg 条件）是硬门槛；重尾世界的极限是 stable 律（P6 演示 Cauchy 5-均值 KS 拟合）。
9. **"Borel–Cantelli II 不需要独立性"**
   - 反例：Aₙ ≡ A，P(A)=0.3，ΣP(Aₙ)=∞ 但 A 只发生一次。
   - 修正：第二引理需（两两）独立或精细相关结构。
