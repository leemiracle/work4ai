# 范畴论（模型蒸馏版）
> 一句话本质：数学的**关系语法**——不问对象"是什么"，只问箭头如何复合；把"结构"本身变成可计算的对象。

## 1. 直觉链（这个域为什么存在）

1. **为什么"忘掉元素"反而是进步？** 同构不变的性质才算数学性质。范畴论强制你只用箭头语言说话，正确性自动获得同构不变性。工程类比：对象是模块、箭头是 API，范畴论是"只看接口合同"的极端面向对象——而且这台编译器从不对实现撒谎。
2. **为什么 Yoneda 引理是"最重要的抽象废话"？** 一句话：**你是什么 = 你与所有他人的关系总和**。对象 A 被它的关系档案 Hom(A,−) 完全决定——两个对象不可区分 ⟺ 档案不可区分。GNN 的"节点=其邻域"哲学是 Yoneda 的工程倒影（FOREST 域十六原话：嵌入=关系保持）。为什么它"废话"却强大：一根钉子挂一幅画——自然性把整个自然变换钉死在 α_A(id_A) 上，其余分量全部被逼出。
3. **为什么泛性质比构造好？** "乘积是什么"不如"乘积做什么"：满足同一泛性质的对象**唯一同构**——构造是实现细节，泛性质是规格说明书。这是数学的"接口与实现分离"，也是 Lean/Haskell 里类型类（typeclass）设计的哲学来源。
4. **为什么伴随处处都是（MacLane：Adjoint functors arise everywhere）？** 自由/遗忘伴随是"最小生成"与"最大遗忘"这对张力的数学化：free 函子最经济地造结构，forgetful 函子最彻底地扔结构，伴随性说这对"造/扔"达到完美平衡（unit/counit 是平衡证书）。几乎所有"最优/最省/对偶"结构——极限、Kan 扩张、张量积——背后都是伴随。
5. **为什么 Lens 进入了 AI？** Lens = 可组合的"读-写"对，恰是可微计算的形状：反向传播一个节点输出 (值, 梯度回传洞)，正是 put/get 对。组合 Lens = 组合反向传播链——FOREST 域十六写的就是这句：**反向传播 = Lens 的组合代数**。数据库视图更新、编辑器状态管理、光学器件是同一骨架。
6. **为什么类型论×范畴论是程序语义的 Rosetta 石？** Curry–Howard–Lambek 三位一体（对照表见 §5）：命题=类型=对象，证明=程序=箭头。Lean 的类型系统直接生活在笛卡尔闭范畴里——写 Lean 证明就是在范畴里砌箭头（→ [../../讲透Lean4数学/README.md](../../讲透Lean4数学/README.md)）。

## 2. 定理网络（骨架）

- ★ **范畴公理**：对象 + 箭头 + 复合 + 单位，满足结合律与单位律。
  为什么这样设计：把"结构 = 可复合的箭头"公理化，元素被彻底驱逐。
  → 实算 CAT-01（预序范畴）/ CAT-02（幺半群 = 单对象范畴——"范畴论包含所有代数"的第一证据）。
- ★ **函子**：保复合与单位的映射——"结构保持"的精确定义。
  为什么真：两条函子律就是"穿过映射后图表仍交换"。
  → 实算 CAT-03（幂集函子保单位/保复合）。
- ★ **自然变换**：函子间的一族映射，使每个自然方交换。
  为什么重要：它捕捉"一族映射的**一致性**"——比单射满射更高阶的对称。
  ☆ 史实：范畴论 1945 年诞生（Eilenberg & MacLane）的原始动机就是给"自然同构"下精确定义。
  → 实算 CAT-04（幂集单子单位 η: Id ⇒ P 的自然性）。
- ★ **Yoneda 引理**：Nat(Hom(A,−), F) ≅ F(A)。
  为什么真：自然性把整个变换钉死在恒等箭头上——α 的每个分量都被 α_A(id_A) 唯一决定。
  → 实算 CAT-05：3 对象预序范畴 9 对 (A,B) 穷举验证；CAT-12：Yoneda 嵌入忠实。
- ★ **泛性质 / 极限**：终对象、乘积、等化子、拉回——用"进入它的映射唯一存在"定义对象。
  为什么真（Set 中）：逐点检查泛性质方程即可。
  → 实算 CAT-06（乘积：穷举 64 映射证唯一性）/ CAT-07（拉回 = 匹配对集合）。
- ☆ **伴随**：F ⊣ U ⟺ Hom(FX,Y) ≅ Hom(X,UY)（自然）；等价于单位/余单位满足三角恒等式。
  为什么真：双射的自然性沿 Hom 骨架传播，三角恒等式是"造/扔一来一回"的守恒律。
  → 实算 CAT-08/09（List ⊣ U_Mon 的实例侧）。
- ★ **自由幺半群 = List(A)**：任意 f: A→U(M) 唯一扩张为幺半群同态 List(A)→M。
  为什么真：扩张=逐元素求积，唯一性由"单字生成"逼出。
  → 实算 CAT-09（ext 保单位与乘法）。
- ☆ **极限 = 右伴随**：lim 是对角函子 Δ 的右伴随——"右伴随保极限"由此免费获得。一大类守恒律（保积、保拉回）都是伴随性的 corollary。
- ☆ **可表示函子**：F ≅ Hom(A,−) 型的函子；"泛元素"= 可表性。Yoneda 的直接推论——泛性质 ⟺ 可表示。
- ★ **Lens 三定律**：PutGet / GetPut / PutPut——可组合双向变换的合同条款。
  → 实算 CAT-10（fst-lens 全过）/ CAT-11（broken put 违反 PutGet）。
  ⚠ 数据库 view-update 语义的原始文献出处待核（不凭记忆写）。
- ☆ **monoidal 范畴 / string diagram**：张量积上的图形演算——架构图、量子线路的形式语义（FOREST 域十六 L3 条目）。
- ☆ **笛卡尔微分范畴**：微分的公理化；反向传播的范畴语义（FOREST 域十六 L3：2023-2026 活跃方向）。

## 3. 反例与陷阱（最值钱部分）

1. **错误直觉："任意两对象间总有箭头。"** 反例：预序范畴 0≤1 中 Hom(1,0) = ∅——这正是 Yoneda 穷举里 Nat 计数 = 0 的来源（★实算 CAT-05 中 A=0,B=1 档）。修正："有箭头"是结构，不是背景；无箭头携带信息（不可比）。
2. **错误直觉："泛性质确定的对象是唯一的。"** 反例：Set 的笛卡尔积 A×B 与"交换分量的积" B×A 都满足乘积泛性质，同构但**不相等**（☆）。修正：唯一性 = 唯一同构，从来不是字面相等——"数学中的同一性"第一课。
3. **错误直觉："函子只要给对象指定对象就行。"** 反例：把幂集函子的箭头部分胡乱指定（如恒取空映射），F(g∘f) ≠ F(g)∘F(f) 立刻爆雷（☆；CAT-03 的两条检查就是防它）。修正：函子 = 对象部分 + 箭头部分 + 两条定律，三位一体缺一不可。
4. **错误直觉："任何结构都能随便当'自由对象'。"** 反例：拿"A 上所有二元树"当自由幺半群——多余的（不同树可代表同一乘积字），违反泛性质的唯一性（☆）。修正：自由对象 = 满足泛性质的**最经济**版本；List 没有一个多余元素（CAT-09 验证的唯一扩张正是"无冗余"的证书）。
5. **错误直觉："Lens 只是 get/put 二元组，随便实现都行。"** 反例：broken put 忽略新值 put(s,a')=s，PutGet 立刻违反（★实算 CAT-11）。修正：三定律是把"可更新视图"做对的合同；违反即出现"写不进/读不出"的一致性 bug。
6. **错误直觉："自然变换就是逐对象各给一个映射。"** 反例：η: Id ⇒ P 若在某个非空对象上把 x ↦ ∅，自然方立刻不交换——P(f) 把空集映到空集，而 η_B(f(x)) = {f(x)} 非空（☆）。修正：分量必须随**每个** f 一致流动——"自然"是强约束，这正是 Eilenberg–MacLane 要发明这个词的原因。
7. **错误直觉："范畴论是纯抽象，没有计算内容。"** 反例：本卡的 Yoneda 验证就是一段可运行程序——3 对象范畴的 Nat 个数被穷举出来且与公式吻合（★CAT-05）；Haskell 的 lens 库、Lean 的 Mathlib 是工业级范畴代码（★）。修正：范畴论 = **可执行的规格语言**，泛性质直接翻译成测试用例。
8. **错误直觉："伴随 = 逆函子。"** 反例：List ⊣ U，但 List∘U ≠ Id——把幺半群忘成集合再造自由幺半群，整体"胖了一圈"（☆：unit 是"单字列表"嵌入而非恒等）。修正：伴随是最优近似而非可逆操作；unit/counit 是近似程度的证书。

## 4. 计算验证（experiments/dm_cat_check.py，12 条断言全过）

| A | B | 穷举得 Nat 数 | \|Hom(B,A)\| | 吻合 |
|---|---|---|---|---|
| 0 | 0 | 1 | 1 | ✓ |
| 0 | 1 | **0** | 0（Hom(1,0)=∅） | ✓ |
| 0 | 2 | **0** | 0 | ✓ |
| 1 | 0 | 1 | 1 | ✓ |
| 1 | 1 | 1 | 1 | ✓ |
| 1 | 2 | **0** | 0 | ✓ |
| 2 | 0 | 1 | 1 | ✓ |
| 2 | 1 | 1 | 1 | ✓ |
| 2 | 2 | 1 | 1 | ✓ |

| 范畴论 | 类型论/编程 | 逻辑 |
