## 1. 直觉链（这个域为什么存在）
1. **为什么"计数=测度"**：组合证明的黄金标准是双射——两个集合等势因为存在保持结构的映射。母函数把计数变成代数（序列↔解析函数），卷积=独立选择的组合。这是"有限测度论"的自觉：所有概率工具（期望、方差、集中）都能借来用，只需把"均匀随机"当作计数装置。
2. **为什么 Ramsey 理论存在**："完全无序是不可能的"——足够大的系统必然包含规则子结构。R(3,3)=6 说 6 人中必有 3 人互识或互不识；鸽笼原理的无限迭代给出 R(k,l) 有限。它是"无序的不可能性"的第一定理。
3. **为什么 Erdős 概率方法是范式革命**：要证明"存在图既无大团也无大独立集"，不构造——**随机取图，算出它同时避开两个坏事件的概率 >0**。妙处：期望视角下坏事件罕见，不需要知道好图长什么样。这是存在性证明从"构造"到"概率"的哥白尼转折，也是随机算法与 [DM-PROB-01](DM-PROB-01-概率与随机过程.md) §5 所说"采样找见证"的共同祖先。
4. **为什么谱图论存在**：邻接矩阵 A 把图变成算子，组合性质立刻获得谱翻译：连通性 ↔ λ₁(Perron) 单重；二部性 ↔ 谱对称于 0；"处处均匀连接"（expander）↔ 第二特征值小。矩阵分析的全部机器（Rayleigh 商、变分、摄动）瞬间可用于图——**图论问题=算子问题**。
5. **为什么 Cheeger 不等式是"三位一体汇率"**：λ₁（谱隙：随机游走收敛速度）/ h（边扩张：割断图的难度）/ 混合时间，三个看似无关的量被夹在同一个不等式里：λ₁/2 ≤ h ≤ √(2λ₁)。哪一侧紧取决于图的病灶是"长径弥散"还是"单一瓶颈"（C10 实测还纠正了本教师初稿的直觉，见 §3-7）——MCMC 混合时间分析（FOREST 域十五）全靠它定价。
6. **为什么随机图有相变**：G(n,p) 在 p=1/n 处，乘性常数决定全局结构（亚临界=森林碎片，超临界=巨分量涌现）——这是统计物理相变的纯组合切片，也是"局部规则 → 全局相"的最简实验室（GNN 数据异质性建模的天然语言，FOREST 域十四）。

## 2. 定理网络（骨架 14 条）
1. ★ **Ramsey R(3,3)=6**：K₆ 任意红蓝染色含单色三角形；K₅ 存在无单色三角形的染色。
   - 为什么真（≤ 方向手推）：取一点 v，其 5 条边至少 3 条同色（鸽笼），设为红边 va,vb,vc；若 ab/bc/ca 有红边则红三角，否则 abc 为蓝三角。K₅ 反例=红 C₅+蓝补 C₅（C1a 穷举 + C1b 构造）。
2. ☆ **Erdős–Szekeres 递推**：R(k,l) ≤ R(k−1,l)+R(k,l−1)（鸽笼二分），给出 R(k,k) ≤ C(2k−2,k−1)。
3. ★ **Erdős 概率方法下界**：C(n,k)·2^{1−C(k,2)} < 1 ⟹ R(k,k) > n。
   - 为什么真：G(n,1/2) 中含单色 K_k 的期望 <2，故存在两者皆无的图（C3 公式验证 + C4 构造性见证）。给出 R(k,k) ≳ k·2^{k/2} 量级——与上界的 4^k 之间至今隔着指数鸿沟（§3-6）。
   - → 关联：概率侧地基见 [DM-PROB-01](DM-PROB-01-概率与随机过程.md) §1-1（"有限测度论"自觉）；信息论的同构胜利见 [DM-INFO-01](DM-INFO-01-信息论与编码.md) §1-3（Shannon 随机编码）。
4. ★ **Handshake / 双计数**：Σdeg = 2|E|（每条边被两端各数一次）。
   - 双计数=组合的 Fubini：两种方式数同一堆东西。一切"平均 argument"的地基。
5. ★ **Turán 定理**（Mantel 是 r=2 特例）：K_{r+1}-free 图至多 (1−1/r)n²/2 条边，Turán 图 T(n,r) 取等。
   - 为什么真：完全 r 部平衡图让每条边"跨部"最有效；归纳+度压缩（C5 验证 Mantel n=5：7 边必有三角形，6 边 K_{2,3} 无）。
6. ☆ **Erdős–Ko–Rado**：n≥2k 时相交 k-子集族 ≤ C(n−1,k−1)（星族取等）——"大族必有公共点"的局部性原理典范。
7. ★ **谱-结构对应三条**：A 实对称 ⟹ 谱实；G 二部 ⟺ 谱关于 0 对称；G 连通 ⟹ λ₁ 单重、特征向量全正（Perron–Frobenius）（C7/C8 数值）。
   - → 关联：Perron–Frobenius 的算子谱理论面见 [DM-FUNC-01](DM-FUNC-01-泛函分析.md)。
8. ★ **谱半径界**：λ₁ ≤ Δ，取等 iff 存在 Δ-正则连通分量。
   - 为什么真：λ₁x = Ax 取最大分量做放缩。星 Sₙ：λ₁=√(n−1) ≪ Δ=n−1（C9：星图精确值 + 三角形 |λ_min|≠λ₁ 反例）。
9. ★ **Cheeger（离散版）**：归一化 Laplacian 满足 λ₁/2 ≤ h_G ≤ √(2λ₁)。
   - 为什么真：Rayleigh 商的变分定义给出 λ₁ ≤ 2h 方向；h ≤ √(2λ₁) 方向用"水平集切割"把谱隙翻成割（C10 数值实测：环=下侧紧（λ₁≈4.93h²，只差常数 π²/2）、哑铃=上侧紧（λ₁≈1.86h，差 8%）——两极端各占一侧，且实测纠正了教师初稿"哑铃下侧紧"的直觉错误）。
10. ☆ **Expander mixing lemma**：|e(S,T) − dn·|S||T|/n| ≤ λ√(|S||T|)——第二特征值直接控制"类随机性"（稀疏图当随机图用）。
11. ☆ **ER 相变**：p=1/n 临界；p=(log n)/n 连通阈值；p=c log n/n 时孤立点消失。出处：Bollobás《Random Graphs》/ Alon-Spencer。
12. ★ **Matrix–Tree（Cayley）**：τ(G)=Laplacian 任一余子式；Kₙ 生成树 n^{n−2}。
    - 为什么真：Laplacian 与生成树计数的矩阵恒等式（Kirchhoff）；C11 整数行列式精确验证 K₅=125。
13. ☆ **Szemerédi 正则性引理**：任意图可 ε-正则分解为 O(1/ε⁴) 块——"大图=有限结构噪声"（graphon 图极限与 GNN 极限理论的共同地基，FOREST 域十四）。
14. ⚠ **C1 猜想（项目资产，open）**：邻接谱能量 E(G)=Σ|λᵢ| ≥ n+λ₁−α(G)（α=独立数）。
    - 证据：本地 121,196 图（n≤14 精确）+GPU 292,864 图（n≤18）=414,060 零违反，Kₙ 取等；19% 随机图与全部星族上严格强于 Graffiti 线新定理 E≥2(n−α)（项目已核 2607.19817）；Lean 陈述已在 Mathlib v4.14 编译通过。**未证明，实验强支持**（本卡 C12 独立复验小规模）。

## 3. 反例与陷阱（R7 富矿）
1. **"R(3,3)=6 所以小图安全"**
   - K₅ 的显式逃生染色：红=C₅（五条弦全蓝）。验证：任何三角形要么用两条红边（但红边构成奇圈无三角）要么全在蓝弦里（补 C₅ 也无三角）（C1b 构造级验证）。
   - 坑在于"对称性幻觉"：人们常以为逃生染色必须是"不均匀的拼凑"，而它其实是高度对称的奇圈结构。
2. **"度序列决定图"**
   - 反例：度序列 (2,2,2,2,2,2) 同时由 C₆ 和两个不交 C₃ 实现（C6 构造验证）。
   - 修正：Erdős–Gallai 只判可实现性；计数=交换图（switching）轨道大小问题。
3. **"邻接矩阵的 0 特征值数=连通分量数"**
   - 反例：P₂ 的 A=[[0,1],[1,0]] 谱 {1,−1} 无 0。0 的重数属于 **Laplacian**（重数=分量数）；A 的 λ₁ 由 Perron–Frobenius 恒正。
   - 修正：混 A 与 L 是谱图论第一坑（C7/C8 用同一对图分别验证）。
4. **"谱决定图"**
   - 经典共谱对：K_{1,4}（星）与 C₄∪K₁ 的 A 特征值同为 {±2,0,0,0}，但一个连通一个不连通。
   - 修正：邻接谱丢失部分结构（C8：A 谱相同，L 谱的 0 重数 1 vs 2）；谱方法的有效性建立在"幸存的谱信息够用"上。
5. **"|λ_min|=λ₁ 总成立"**
   - 反例：三角形谱 {2,−1,−1}：|λ_min|=1≠2。
   - 修正：|λ_min|=λ₁ ⟺ 存在 Δ-正则二部连通分量。谱对称 ⟺ 二部是真的，但"对称的强度"容易被高估。
6. **"存在性证明≈构造"（概率方法弱下界）**
   - 数值见证：第一矩公式对 k=5 只证 R(5,5)>11（n=12 时 C(12,5)·2^{−9}≈1.55>1 失效），而真值已知远大于此（具体已知界待核）——概率下界与真值差指数级，显式构造 60 年无大进展。
   - 修正：正概率可以小到宇宙尺度；去随机化/显式构造是独立的手艺（expander 的 LPS/Ramanujan 线、zig-zag 提升线）。
7. **"Cheeger 两侧同时紧 / 病灶判断靠感觉"**
   - 数值见证（C10，实测还纠正了本教师初稿的直觉错误）：环 C₅₀：h=2/n，λ₁=2sin²(π/n)≈4.93h²——下侧 λ₁≥h²/2 只差常数（π²/2），上侧 λ₁≤2h 松一个 n 量级；哑铃（两个 K₂₅ 一条桥边）：h=1/601，λ₁≈1.86h——**上侧** λ₁≤2h 紧（差 8%），下侧松三个数量级。
   - 修正：病灶是"均匀弥散/长径"（环、路径）时 λ~h²（下侧有效），病灶是"单一瓶颈"（哑铃）时 λ~2h（上侧有效）——用错侧=混合时间估计差多项式级。
8. **"随机图参数应随 n 收敛到单点"**
   - ⚠ 教师级知识：G(n,1/2) 的团数只在相邻两个整数间震荡（two-point concentration），不收敛单点。
   - 修正：一阶矩/二阶矩相接的位置留有 O(1) 震荡带——"看似该收敛的量未必收敛"是随机图论的常态而非例外（Bollobás《Random Graphs》，具体定理出处待核）。
9. **"λ₁=Δ 当图很稠密"**
   - 反例：星 Sₙ（n 大时观感"几乎完全图"）λ₁=√(n−1) 而非 Δ=n−1。取等需要正则性而非密度。
   - 顺带：星族恰是 C1 猜想严格强于 2026 新定理的见证族（§5）——同一个反例家族在两个定理里扮演相反角色，这类"反例矿脉复用"是谱图论选图的手感。
