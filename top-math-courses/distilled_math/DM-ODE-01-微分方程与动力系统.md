## 1. 直觉链（这个域为什么存在）
1. **为什么解公式不是主角**
   自然法则给的多是"当前状态 → 变化率"的关系（Newton 定律、化学反应率、梯度流），显式解只对线性/可分离等少数结构存在。存在唯一性定理保证"虽然写不出解，但解在谈它之前就存在且只有一个"——这是整个定性理论的合法性来源。
2. **为什么要 Lipschitz**
   速率场若在某点"无限撕扯"（√x 在 0 处斜率无穷），同一点出发可以合法地"现在就走"或"先歇一会儿再走"（非唯一）。Lipschitz 把撕扯速度限制住，轨迹才被初始条件唯一钉死。
3. **为什么稳定性比解更重要**
   既然解写不出来，就问更粗但更有用的问题——扰动会衰减吗？Lyapunov 的天才是把"轨道会不会乱跑"换成"找一个沿轨道单调下降的量"（能量直觉）：V 正定 + V̇≤0 ⇒ 稳定。这是数学版的"找 Lyapunov 函数 = 找广义能量"。
4. **为什么会有分岔**
   参数 μ 缓慢变化时，平衡点的数量与稳定性可以瞬间改组（saddle-node：一对平衡点湮灭；pitchfork：对称破缺）。分岔是非线性系统的"相变"，控制论/神经动力学/RL 训练中的突变都能在这里找到范式。
5. **为什么混沌不是随机**
   确定性方程 + 轨道指数分离（正 Lyapunov 指数）+ 有界吸引子 = 有限精度下长期不可预测。可预测性不要求随机性失效，只要求初始误差指数放大。
6. **为什么 PDE 是无穷维 ODE**
   空间离散化后热方程就是几万个耦合 ODE；PDE 新出的困难是无穷维（紧性替代有限维定理）与多尺度（边界层）。数值上 PDE=大 ODE，分析上完全是另一个世界。

## 2. 定理网络（骨架）
- ☆ **Picard–Lindelöf 存在唯一性**
  右端连续+局部 Lipschitz ⇒ 局部唯一解。为什么真：迭代算子是压缩的。出处：Coddington & Levinson《Theory of Ordinary Differential Equations》。→ 关联：失效模式见 §3-1/§3-2；一切数值积分的前提。
- ★ **线性系统稳定性判据**
  ẋ=Ax 渐近稳定 ⇔ A 特征值实部全负。为什么真：e^{At} 被谱指数控制。Strogatz。→ 关联：O3；非线性问题的第一近似（Hartman–Grobman）。
- ★ **Lyapunov 直接法**
  V 正定、V̇≤0 ⇒ 稳定；V̇<0 ⇒ 渐近稳定。为什么真：V 沿轨道单调有下界，只能收敛。Strogatz。→ 关联：O4；RL 的 value function=Lyapunov 候选（域十三）。
- ☆ **LaSalle 不变原理**
  V̇≤0 时轨道趋于 {V̇=0} 中的最大不变集。为什么真：极限集必含于 V̇ 消失处。→ 关联：阻尼单摆 V̇=−cẋ²，不变集里 ẋ=0。
- ☆ **Hartman–Grobman 定理**
  双曲平衡点邻域共轭于其线性化。为什么真：双曲性给指数压缩/扩张积木。→ 关联：非双曲陷阱 §3-6；零实部方向交给中心流形。
- ★ **2D 平衡点分类**
  Jacobian 的 trace/det 决定节点/鞍点/螺线。为什么真：二次特征方程的两根符号。Strogatz。→ 关联：O3 的谱证据。
- ★ **saddle-node 分岔范式**
  ẋ=μ−x²，μ 过 0 时一对平衡点湮灭。为什么真：抛物线与横轴相切。Strogatz。→ 关联：O5；湮灭点附近的慢通过现象。
- ★ **超临界 pitchfork**
  ẋ=μx−x³，μ>0 对称破缺出一对稳定平衡点。为什么真：三次项把增长饱和。Strogatz。→ 关联：O6；对称系统的普适范式。
- ★ **Hopf 分岔范式**
  r'=r(μ−r²)（笛卡尔形式见 O9），平衡点失稳冒出极限环。为什么真：径向三次饱和。Strogatz。→ 关联：O9；振荡神经网络/电机工程。
- ★ **Lorenz 系统混沌**
  σ=10, ρ=28, β=8/3 时存在奇怪吸引子：轨道有界且初值敏感。为什么真：拉伸+折叠的马蹄机制。Strogatz（原经典文献 Lorenz 1963，卷期待核）。→ 关联：O7。
- ★ **Lyapunov 指数**
  δx(t)≈e^{λt}δx(0)，λ>0 ⇒ 混沌；Benettin 重正化数值法。为什么真：切向量的指数增长率。→ 关联：O8。
- ☆ **Poincaré–Bendixson 定理**
  平面紧极限集只能是平衡点/极限环——平面无混沌。为什么真：Jordan 曲线把平面分成内外，轨道不能自交。Strogatz。→ 关联：混沌至少要 3 维（§3-4 由 Lorenz 见证）。
- ☆ **中心流形定理**
  非双曲方向上存在低维不变流形承载长期动力学。为什么真：谱分裂+不变图。→ 关联：分岔范式推导的机器。
- ★ **热方程极值原理**
  u_t=Δu 的最大值在抛物边界达到。为什么真：内部极大值处 Δu≤0 与增长矛盾。Evans。→ 关联：O11；最大值原理→Harnack/正则性链条。
- ⚠ **能量法与辛格式（简化陈述）**
  波方程能量守恒（连续陈述，教师级）；leapfrog/辛 Euler 在 CFL≤1 保持离散能量有界不漂移。为什么真（简化版）：格式是辛映射，反误差分析给出"修正能量"守恒——不等于能量精确守恒，O10 的 2.6%/8% 偏差正来自修正能量与真能量之差。LeVeque。→ 关联：O10/O12。

## 3. 反例与陷阱（模型见过最多人栽的坑）
1. ★ **错误直觉：右端连续就有唯一解**
   反例 ẋ=√|x|, x(0)=0：x(t)≡0 与 x(t)=t²/4（还有"歇 t₀ 再走"的整族）都是解（O1 机器验证 t²/4 残差 <1e-12）。修正：唯一性要 Lipschitz；√|x| 恰在 x=0 处斜率爆炸。
2. ★ **错误直觉：解至少局部存在就能一直积分下去**
   反例 ẋ=x², x(0)=1：x=1/(1−t) 在 t=1 处爆破（O2 验证 x(0.999)=1000）。修正：最大存在区间是定理的一部分；数值积分器在有限时间 overflow 不是 bug。
3. ☆ **错误直觉：线性化稳定 ⇒ 大范围稳定**
   反例 ẋ=−x+x³：x=0 处 f'(0)=−1<0 局部指数稳定，但 x₀>1 的解有限时间逃逸。修正：Lyapunov 稳定性天然是局部概念；全局性要另找整体 Lyapunov 函数或排除逃逸。
4. ★ **错误直觉：低维也能混沌**
   反例：平面自治系统被 Poincaré–Bendixson 锁死（只有平衡点/极限环）；Lorenz 恰好 3 维就出现奇怪吸引子（O7）。修正：连续自治混沌的最小维度是 3；离散映射（Logistic）1 维就够。
5. ★ **错误直觉：V̇≤0 就收敛**
   反例：无阻尼单摆 V=½ẋ²+1−cos x 有 V̇≡0，轨道永远环绕（O4 的对照面）；加阻尼 0.2ẋ 后 V̇=−0.2ẋ²<0 才渐近稳定。修正：V̇≤0 给稳定，收敛要 V̇<0 或 LaSalle；"找能量"是起点不是终点。
6. ☆ **错误直觉：平衡点性质=线性化性质**
   反例 ẋ=−x³：f'(0)=0（线性化全零），但 0 渐近稳定（次指数收敛）；反过来 ẋ=x³ 线性化也为 0 却不稳定。修正：非双曲点的命运由高阶项决定，中心流形/正规形是正确工具。
7. ★ **错误直觉：数值积分器只关心精度阶数**
   反例：谐波振子 ẍ=−x 用显式 Euler，能量以 (1+h²)^n 指数漂移（O10 实测 E/E₀=147）；辛 Euler 能量有界振荡（偏差 2.6%）。修正：长期模拟要保结构（辛/守恒），不是把阶数堆高；这是几何数值积分存在的原因。
8. ★ **错误直觉：CFL 条件是建议**
   反例：波方程 leapfrog CFL=1.06，π 模能量 300 步放大 4.7 万倍（O12）；CFL=0.95 时能量带稳定在 9% 内无漂移。修正：显式格式的稳定性条件是硬边界；结构保持（上一条）不豁免稳定性。
9. ★ **错误直觉：热方程倒着放就是把 t 换成 −t**
   反例：单模式 sin(kx) 正向衰减 e^{−k²t}，倒向放大 e^{+k²t}（k=10, t=0.1 时 2.2 万倍，O13）。修正：倒向热方程不适定——这就是"去模糊/图像修复需要正则化"的数学根源（也连扩散模型 score 估计的病态性）。

## 5. 与 AI 的关联（FOREST 域十三逐行对齐）
- **SSM/HiPPO 矩阵 = S4/Mamba 的数学根基**
  状态空间模型 ẋ=Ax+Bu, y=Cx 就是线性 ODE；HiPPO 矩阵是"把历史投影到多项式基"产生的特定 A；本卡 O3 的谱判据直接决定 SSM 的记忆衰减模式；FOREST 标注"Mamba 一家没盖是硬伤"——本卡是补桥起点。
- **可控性/可观性 → SSM 表达力**
  线性系统理论（Kalman 秩条件）给出"状态能不能被输入塑造/被输出分辨"的精确答案，是 SSM 长程记忆分析的现成语言。
- **Lyapunov 稳定性 × RL**
  value function 就是 Lyapunov 候选函数（安全 RL 证书）；FOREST 的 L3 入口"学习到的 Lyapunov 证书验证"接 Lean 形式化——与本库 L3 管线天然对接。
- **随机侧：OU 过程 / mixing time / 遍历定理**
  OU=score 模型原型（讲透扩散模型部分覆盖）；mixing time 连 MCMC/扩散采样；遍历定理是 RL 平均奖励与时间序列建模的地基；MPC 滚动时域=model-based RL。
- **训练即动力系统**
  梯度流视角（loss 场上的 ODE）、momentum=阻尼振子（O3/O10 正是它的两个数值面孔）、分岔=训练中的相变——互链 [DM-OPT-01](DM-OPT-01-优化与变分.md)（Euler–Lagrange/adjoint）与讲透优化器。
- **Neural ODE**
  resnet=ODE 前向，反传用 adjoint 法（=变分法/最优控制的必要条件，见 OPT 卡 §2）。
- **讲透Loop 的外环**
  E4 双相跃迁本质是离散动力系统的分岔图读取——同一套范式语言。
