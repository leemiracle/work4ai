## 1. 直觉链（这个域为什么存在）

1. **为什么 Riemann 不够**：Riemann 按"定义域竖切"求和，对逐点极限极其脆弱（§3 反例 1：逐点收敛到 0 的函数列积分恒为 1）。Lebesgue 改"按值域横切"（simple function 逼近），用 σ-代数先给"长度"一个可数可加的推广——极限运算从此可以穿过积分号（三大收敛定理）。**测度论是"为极限交换而生的积分论"**。
2. **为什么收敛模式这么多**：无限维/测度空间上"收敛"分裂成 a.e. / 依测度 / Lᵖ / 弱收敛，因为没有任何一种能统治其他——每种收敛对应一族可与积分/取 sup 交换的极限操作，分裂是结构性代价。Egorov（§2.6）说明有限测度下 a.e. 收敛"几乎"一致，是缝合两种世界的针脚。
3. **为什么必须 σ-代数而不是全部子集**：Vitali 不可测集证明：幂集上不存在可数可加+平移不变+归一化的测度。σ-代数是"承认放弃一部分集合"的妥协设计——数学里最常见的设计模式：缩小论域换取结构。
4. **为什么 a.e. 处处是语法糖**：可测函数类对 a.e. 极限封闭，于是把"除零测集外成立"当作新的等号——Lᵖ 空间的元素严格说是**等价类**而非函数（§3 反例 6 的坑正来源于此）。
5. **为什么 Lᵖ 按 |f|ᵖ 积分来定范数**：这是把函数空间"线性化+拓扑化"的最低成本方案；p=2 是唯一能配出内积的（平行四边形恒等式刻划，见姊妹卡 DM-FUNC-01），p→∞ 退化为本质有界。Hölder/Young 是"指数凑对"的配平机器（§2.7）。
6. **微积分基本定理的测度论真相**：Lebesgue 微分定理说"局部平均→函数值"是密度现象；牛顿-莱布尼茨公式只对**绝对连续**函数恢复——Cantor 函数（§3 反例 4）是钉死这扇门的反例主角。

## 2. 定理网络（骨架）

依赖图（从构造到收敛机器）：

```
Cantor/外测度 ─→ Carathéodory 扩张 ─→ Lebesgue 测度 ─→ 可测函数(simple 逼近)
        └──────────────┬────────────────────────────────────┘
                 单调收敛 MCT ─→ Fatou ─→ 控制收敛 DCT ─→ Riesz-Fischer(Lᵖ 完备)
                        └───────→ Fubini-Tonelli ─→ Radon-Nikodym（密度=score 的身份）
Lebesgue 微分定理 ← 极大函数方法；绝对连续 ⟺ NL ← Cantor 函数（反侧）
```

1. ★ **Cantor 集测度计算**：三等分构造下第 n 步剩 2ⁿ 段、各长 3⁻ⁿ，总测度 (2/3)ⁿ→0。为什么真：每步保留 2/3，几何递减。出处：Rudin, PMA（讲透实分析 01 章同款构造）。→ 关联：§3 反例 3"测度小≠元素少"；胖 Cantor（§2.16）反面。
2. ☆ **Carathéodory 扩张定理**：外测度限制在可测集族上是可数可加的。为什么真：Carathéodory 判据恰好把"可加性障碍"挡在门外。出处：Folland, Real Analysis。→ 关联：一切具体测度（Lebesgue/Hausdorff/概率）的安装台。
3. ★ **Fatou 引理（非负）**：∫liminf fₙ ≤ liminf ∫fₙ。为什么真：liminf fₙ = supₙ inf_{k≥n} fₖ 是单调极限，套单调收敛。出处：上述任一教材。→ 关联：不等号可紧（R2/R3 数值演示）；DCT 证明的原材料。
4. ★ **单调收敛定理（MCT）**：0≤fₙ↑f ⇒ ∫fₙ↑∫f。为什么真：非负简单函数阶梯逐层交换极限。→ 关联：与 Fatou 在非负世界等价（互相推出）；计数测度版=非负级数逐项求和（R13）。
5. ★ **控制收敛定理（DCT）**：fₙ→f a.e. 且 |fₙ|≤g∈L¹ ⇒ ∫fₙ→∫f。为什么真：对 g+fₙ 与 g−fₙ 各用一次 Fatou。使用条件（三件套缺一不可）：逐点收敛 + 可积控制 + **控制函数必须在积分前给出（先验性）**。→ 关联：§3 反例 1/5；概率论依分布收敛 + 矩收敛的标准工具。
6. ☆ **Egorov 定理**：有限测度域上 a.e. 收敛 ⇒ 剔除任意小测度集后一致收敛。为什么真：坏点集是可数个"余零测"集合的交，按 ε 分层截断。→ 关联：Lusin 的姊妹；说明 a.e. 与一致只差一个"小坏集"。
7. ★ **Hölder/Minkowski/Young 机器**：1/p+1/q=1 ⇒ ‖fg‖₁≤‖f‖_p‖g‖_q；三角不等式；ab≤aᵖ/p+b^q/q。为什么真：Young 是凸函数切线不等式（p=q=2 时就是 (a−b)²≥0，R6 符号验证）。→ 关联：Lᵖ 是范数空间的入场券；R8-R10。
8. ☆ **Riesz-Fischer 定理**：Lᵖ 完备（1≤p≤∞）。为什么真：Cauchy 列抽快速收敛子列 → a.e. 极限存在 → DCT 回填范数收敛。→ 关联：Lᵖ 成为 Banach 空间的根源（DM-FUNC-01 的地基）。
9. ☆ **Riemann 可积判据**：有界函数 Riemann 可积 ⟺ 不连续点集零测。为什么真：上下 Darboux 和之差=振幅×覆盖长度的下确界。→ 关联：新旧积分的精确接缝——1_ℚ 不可积（处处不连续）但 Lebesgue 可积=0；反向缝见 §3.8（sin x/x）。
10. ☆ **绝对连续 ⟺ 牛顿-莱布尼茨恢复**：F(x)=F(0)+∫F′ 成立的充要条件是 F 绝对连续（严格强于连续+逐点可导）。→ 关联：Cantor 函数（§3 反例 4）。
11. ★ **Lebesgue 微分定理**：f∈L¹_loc 时 shrinking ball 平均→f(x) 在 a.e. x（Lebesgue 点）成立。为什么真：Hardy-Littlewood 极大函数弱 (1,1) 型 + 加权覆盖引理。→ 关联：R11 数值（光滑点速率 h²/3 严格吻合）；概率密度=测度的 RN 导数视角。
12. ☆ **Lusin 定理**：可测函数删去任意小测度集后连续——测度世界与拓扑世界的翻译官。→ 关联：神经网络逼近可测函数（universal approximation 的测度论前提）。
13. ☆ **Vitali 不可测集**：[0,1] 按 ℚ 等价类取代表，平移可数个不相交并盖住 [0,1]——测度可数可加+平移不变+归一化三者不相容。→ 关联：σ-代数必要性的存在性证明。
14. ☆ **Fubini-Tonelli**：非负（Tonelli，**先交换后验可积**）或可积（Fubini，先验 |f|∈L¹）时累次积分可交换；两版都要求 σ-有限。为什么真：σ-有限测度的单调类论证。→ 关联：ML 中"期望=对分布积分"的合法性来源；σ-有限不满足的爆炸见 §3.10。
15. ☆ **Radon-Nikodym 定理**：σ-有限 + ν≪μ ⇒ 存在密度 dν/dμ。为什么真：Fatou 型格论证（上鞅式构造）。→ 关联：概率密度、score function（log dν/dμ 的梯度）、变分推断的 dQ/dP 全在此定理上；坑见 §3.10。
16. ★ **胖 Cantor 集（Smith-Volterra）**：挖中段长 4⁻ᵏ，剩余测度恰 1/2 且无处稠密。为什么真：挖除总量 Σ2⁻ᵏ⁻¹=1/2。→ 关联：R12 数值；证明"正测度集可以没有内点"——拓扑与测度是两个独立刻度。

## 3. 反例与陷阱（模型见过最多人栽的坑）

1. ★ **错误直觉："逐点收敛可以直接穿过积分号"** → 反例：fₙ=n·1_{(0,1/n)} 于 [0,1]，fₙ→0 处处（每点 x>0 最终为 0）但 ∫fₙ=1 恒定。→ 修正：必须先验控制函数；本例最小控制包络 g(x)=⌈1/x⌉ 的积分发散（R5 数值见证对数增长）——**DCT 的"控制"条件是不可绕过的付费墙**。
2. ★ **错误直觉："Fatou 不等号一般取等"** → 反例（两型）：逃逸质量 fₙ=1_{[n,n+1]} 于 ℝ（liminf 积分 0 < 1）；有限域尖峰即反例 1。→ 修正：质量逃逸或增高都会造成 strict；一致可积 + 紧支撑（Vitali 定理）才保证取等。
3. ★ **错误直觉："测度 0 就是元素少/可数"** → 反例：Cantor 集测度 0（R1 数值 (2/3)ⁿ→0）但基数 2^ℵ₀ 与 ℝ 等势（此半句 ☆ 未机器验证）；胖 Cantor 反向：无处稠密却测度 1/2（R12）。→ 修正：测度、基数、拓扑（稠密性）是三个正交的"大小"刻度。
4. ☆ **错误直觉："连续+导数 a.e. 为 0 ⇒ 常数"** → 反例：Cantor 函数 C(x) 连续、递增、C′=0 a.e.，但 C(1)−C(0)=1≠∫₀¹C′=0。→ 修正：牛顿-莱布尼茨的成立类=绝对连续函数；C(x) 还把零测 Cantor 集映满 [0,1]（可测映射不保零测集，Luzin N 性质是额外条件）。
5. ☆ **错误直觉："L¹ 收敛 ⇒ a.e. 收敛（或直接反向）"** → 反例：打字机序列（dyadic 区间轮流扫描 [0,1]）L¹→0 但每点 a.e. 不收敛（值在 0/1 间无穷振动）☆；反向即反例 1（a.e.→0 但 L¹ 不收敛）★。→ 修正：L¹ ⇒ 依测度 ⇒ **子列** a.e.；全列 a.e. 无保证。
6. ☆ **错误直觉："Lᵖ 中的函数可以谈某点的函数值"** → 反例：1_ℚ 与 0 是 L¹ 同一等价类但逐点处处不同。→ 修正：Lᵖ 元素是 a.e. 等价类；逐点赋值不是合法操作——**RKHS（DM-FUNC-01 §5）之所以特殊，正是因为它恢复了"逐点赋值合法性"**。
7. ★ **错误直觉："a.e. 收敛 ⇒ 依测度收敛处处成立"** → 反例：fₙ=1_{[n,n+1]} 于 ℝ（无限测度）：a.e.→0 但 m{|fₙ|>½}=1 不减（R2 数据）。→ 修正：有限测度域才成立；无限域上两大模式彻底脱钩。
8. ☆ **错误直觉："收敛了积分极限存在 ⇒ 可积"** → 反例：sin x/x 于 [0,∞)：反常积分条件收敛（Dirichlet），但 ∫|sin x/x|=∞，不属 L¹。→ 修正：Lebesgue 理论=绝对收敛的理论；反常积分（条件收敛）是另一套极限，ML 里重尾分布的"期望存在但绝对矩不存在"同构此坑。
9. ☆ **错误直觉："Tonelli/Fubini/Radon-Nikodym 的前提只是可积性/绝对连续"** → 反例：μ=Lebesgue 于 [0,1]，ν=counting 测度：ν(A)=0 ⟺ A=∅，故 μ≪ν 成立，但不存在 f 使 μ(A)=∫_A f dν（若有则 f(x)=μ({x})=0 处处 ⇒ μ=∅，矛盾）——失败原因正是 ν **不 σ-有限**。→ 修正：σ-有限性不是技术装饰，是这三条大定理的承重墙；使用前逐条核对（模型见过大量"直接换积分号"的失效案例都栽在这里）。
10. ⚠ **简化声明**：本卡"可测"默认 Lebesgue 可测（Borel 的完备化）。Borel σ-代数与 Lebesgue σ-代数的差异（完备化）在概率论的 rigorous 处理（如随机过程轨道可测性）里是真实的技术分叉，此处统一淡化——细读 Folland。

## 5. 与 AI 的关联

- **FOREST 映射**：[../AI_MATH_FOREST.md](../AI_MATH_FOREST.md) **域六（微积分/分析）**——"测度论语言：读懂任何理论论文的前提"（该行现挂于域二表格，同一事实）；域六的逼近论/变分条目全部以本卡语言书写。
- **扩散模型**：score matching、Wasserstein 梯度流=概率测度空间上的测度论结构；Radon-Nikodym 导数（§2.15）是 score 的数学身份（模型=绝对连续分布的密度）。Dirac δ"函数"严格说是测度/分布——扩散模型从 δ 出发用热核平滑的技术叙事全靠测度语言。
- **泛化界与渐近统计**：liminf 型论证（Fatou）是 generalization bound 与一致性证明的标准动作；一致收敛控制（DCT 的 g）对应"一致可积/一致界"的付费墙。
- **特征归一化/嵌入空间**：L² 等价类（§3.6）说明"函数=类"——embedding 的范数归一化本质是在选等价类的代表元；逐点评估的合法性在 RKHS（DM-FUNC-01 §5）才恢复。
- **EM/MCMC 收敛分析**：迭代算法的收敛证明在函数空间上做——DCT/MCT 是把"逐点更新"升级为"泛函收敛"的标准桥。
- **重尾与损失景观**：L¹ vs 条件收敛（§3.8）对应"期望存在但方差不存在"的分布族——损失裁剪（gradient clipping）的理论动机之一。
- **姊妹卡**：DM-CPLX-01（一阶延伸）、DM-FUNC-01（Lᵖ 完备性→Banach）；讲透实分析 0.1 节的知识树即本三卡的谱系图。
