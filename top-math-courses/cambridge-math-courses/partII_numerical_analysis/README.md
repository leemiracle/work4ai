# Cambridge Part II — Numerical Analysis

> **学校**：Cambridge | **学期**：Lent (大三春)
> **一手来源**：[maths.cam.ac.uk/undergrad/files/coursesII.pdf](https://www.maths.cam.ac.uk/undergrad/files/coursesII.pdf)

## 课程信息
- **学期**：Lent (24 lectures, D-course)
- **教材**：Iserles *A First Course in NDE*；Süli & Mayers *An Introduction to Numerical Analysis*
- **特色**：本科高阶数值分析

## 教学大纲
1. **Approximation theory**（多项式 / 样条 / Chebyshev）
2. **Quadrature** (Gaussian, Clenshaw-Curtis)
3. **ODE** (multistep, Runge-Kutta, stability)
4. **PDE** (finite difference, finite element 入门)
5. **Eigenvalue computation** (QR algorithm)
6. **Iterative methods for linear systems** (Krylov, GMRES, CG)
7. **FFT** & 应用

## 与 ML 的关联
- Transformer 加速（Krylov）
- 谱方法 → 神经网络核方法
