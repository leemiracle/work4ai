# Cambridge Part IB — Markov Chains

> **学校**：Cambridge | **学期**：Lent (大二春)
> **一手来源**：[maths.cam.ac.uk/undergrad/files/coursesIB.pdf](https://www.maths.cam.ac.uk/undergrad/files/coursesIB.pdf)

## 课程信息
- **学期**：Lent (12 or 16 lectures)
- **教材**：**Norris, *Markov Chains*** (Cambridge Series in Statistical and Probabilistic Mathematics) ★
- **特色**：本科马尔可夫链金课

## 教学大纲
1. Markov property
2. Transition probabilities
3. Class structure, irreducibility
4. Recurrence / transience
5. Stationary distributions ★
6. **Ergodic theorem**
7. **Reversibility**
8. Random walks
9. Applications (queueing, PageRank)

## 与 ML 的关联（**强化学习核心**）
- MDP = Markov chain + reward
- MCMC 采样的基础
- 学完后：理解 RL 的 Bellman 方程
