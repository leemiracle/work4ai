## Overview of Caching Layers

| Cache Layer | Cached Entity | Purpose | Key File & Implementation |
|---|---|---|---|
| Graph Level Cache | CompiledFxGraph | Caches entire compiled FX graphs + wrappers keyed on FX graph & metadata | torch/_inductor.codecache.FxGraphCache torch/_inductor/codecache.py 39-45 |
| AOT Autograd Cache | Forward/backward joint graphs | Caches result of AOTAutograd joint tracing and compilation | torch._functorch._aot_autograd.autograd_cache.AOTAutogradCache torch/_functorch/_aot_autograd/autograd_cache.py 30-31 |
| Python Wrapper Cache | Python/Triton kernel wrapper code | Stores generated Python wrappers and Triton kernel source text | torch/_inductor.codecache.PyCodeCache torch/_inductor/codecache.py 48 |
| GPU Binary Cache | Compiled CUDA/ROCm binary libraries | Stores compiled binary objects ( .so / .dll / .dylib & GPU cubin/hsaco) | torch/_inductor.codecache.CUDACodeCache torch/_inductor/codecache.py 44 |
| Autotuning Cache | Kernel runtime configurations | Stores optimal kernel launch parameters (block sizes, tiling, etc.) | torch._inductor.runtime.autotune_cache torch/_inductor/codecache.py 143-144 |

- Performs strict cacheability checks via check_node_safe torch/_functorch/_aot_autograd/autograd_cache.py 36 to ensure the FX graph nodes contain only safe, cacheable operators.

## Asynchronous Compilation and Worker Interaction

### Key Components

- AsyncCompile: The main interface managing compilation workers torch/_inductor/async_compile.py 27
- SubprocPool: A process pool that handles task submission via submit() torch/_inductor/compile_worker/subproc_pool.py 50 and manages worker liveness through a _health_monitor torch/_inductor/compile_worker/subproc_pool.py 116
- CodeCacheFuture: Represents the result of an async compile task; calling result() blocks until the worker completes torch/_inductor/async_compile.py 25-45
- Worker Isolation: Workers run in a separate SubprocMain torch/_inductor/compile_worker/subproc_pool.py 26 and communicate via a result pipe. The system includes a watchdog to detect sidecar death and fail pending futures torch/_inductor/compile_worker/subproc_pool.py 87-91

# Summary

- Graph-level caches for compiled FX graphs ( FxGraphCache ) and AOT Autograd compound graphs ( AOTAutogradCache ).
- Code caches for Python and Triton kernel wrappers ( PyCodeCache ) and compiled GPU binaries via CUDACodeCache .
- Asynchronous compilation handled by worker pools ( AsyncCompile and SubprocPool ) for non-blocking kernel builds.
- Persistent autotune caches storing kernel tuning results for reuse and sharing.
