## Overview

`ComputedBuffer`

Key Responsibilities:

- Dependency Analysis: Utilizing precise memory read-write dependencies to verify safe execution order.
- Fusion Grouping: Identifying operations that can be merged to improve data locality.
- Memory Planning: Allocating and reusing buffer storage to minimize memory footprint.
- Loop Ordering: Deciding iteration order for kernel loops to improve cache locality and tiling.
- Emission: Producing a scheduled sequence of fused nodes ready for backends like TritonScheduling or SIMDScheduling .

### Specialized Fusion Types

- Pointwise Fusion: Merges operations with identical iteration domains ( numel ).
- Reduction Fusion: Fuses reductions that share the same input and reduction dimensions.
- Mix Order Reduction: Fuses reductions reducing across different dimensions of the same input tensor. This is primarily supported for Triton backends torch/_inductor/scheduler.py 196-202
- Combo Kernels: Horizontal fusion of independent kernels to reduce launch overhead, enabled by config.combo_kernels torch/_inductor/scheduler.py 162-168
