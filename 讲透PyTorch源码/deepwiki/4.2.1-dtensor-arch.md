## DTensor Object Structure

`DTensor`
`torch.Tensor`
`DTensorSpec`

- _local_tensor : The actual torch.Tensor stored on the current rank, representing a piece of the global data. torch/distributed/tensor/_api.py 112-118

- DeviceMesh : Represents the topology of devices (e.g., a 2D grid for TP and DP). torch/distributed/tensor/_dtensor_spec.py 68
- Placement : A tuple of placement types, one for each dimension of the DeviceMesh . torch/distributed/tensor/_dtensor_spec.py 69

## Core DTensor APIs

### from_local and to_local

`torch.autograd.Function`

- from_local : Wraps a local tensor into a DTensor . It uses _FromTorchTensor to handle the transition. torch/distributed/tensor/_api.py 164-246
- to_local : Unwraps a DTensor to return its local shard. It uses _ToTorchTensor . torch/distributed/tensor/_api.py 102-159

### redistribute

`redistribute(device_mesh, placements)`
`DTensor`

- Planning : It determines the sequence of collectives (e.g., all_gather , reduce_scatter ) needed. torch/distributed/tensor/_redistribute.py 83-95
- Cost-Awareness : Supports a graph-based algorithm using Dijkstra to find the minimum-cost communication path. torch/distributed/tensor/_redistribute.py 44-48

### Strategy Registration

`register_op_strategy`
`register_single_dim_strategy`

- Pointwise Ops : (e.g., add ) follow the input sharding. torch/distributed/tensor/_ops/_pointwise_ops.py 100-144
- Reduction Ops : (e.g., sum ) may convert a Shard placement into a Partial placement. torch/distributed/tensor/_ops/_math_ops.py 203-209
