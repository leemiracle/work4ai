## Architecture Overview

`DevicePool`

- Device Management: Uses a thread-local current device index curDeviceIndex c10/xpu/XPUFunctions.cpp 36 and a global DevicePool that is initialized once via initDevicePoolCallOnce c10/xpu/XPUFunctions.cpp 145-150
- Memory Management: Employs an XPUCachingAllocator for device memory allocation, which is optimized to reduce fragmentation and allocation overhead c10/xpu/XPUCachingAllocator.cpp 10-161
- Stream and Event Abstractions: Wrap SYCL queues and events to implement PyTorch streams and events torch/xpu/streams.py 39
- Native Kernels: Implements optimized operations, often leveraging oneDNN for primitives like Convolutions and GEMMs cmake/Modules/FindMKLDNN.cmake 80-86
- Compilation Integration: Supports FX graph lowering through Inductor targeting SYCL or Triton-XPU backends.
