### Configuration Flags

`torch/_functorch/config.py`

- functionalize_rng_ops - converts RNG ops to functional form.
- debug_assert - enable extra assertions for correctness.
- cse - apply common subexpression elimination.
- view_replay_for_aliased_outputs - use view-replay instead of as_strided for output aliasing.
- treat_parameters_as_free_to_save - treat parameters as zero save cost during partitioning.

## Stage 1: Functionalization and Metadata Collection

`AOTState`

- The function inputs are converted into fake tensors by FakeTensorMode for tracing compatibility torch/_subclasses/fake_tensor.py 76-77
- If randomness functionalization is enabled, RNG is tracked via CUDARngStateHelper torch/_functorch/_aot_autograd/runtime_wrappers.py 49
- The forward function is wrapped to functionalize in-place mutations, converting them to pure out-of-place operations with updated outputs.
- After a functionalized forward run, alias and mutation metadata are collected to produce a ViewAndMutationMeta object describing: Which inputs are mutated (data and metadata). How outputs relate to inputs or intermediate tensors (aliasing info). Which outputs require gradients.

## Stage 2: Pre-Compile Wrappers

`_create_wrappers_for_dispatch`

- AOTDedupeWrapper : Deduplicates repeated input tensors to reduce graph input size. This deduplication is undone in runtime wrappers.
- AOTSyntheticBaseWrapper : Collapses aliased inputs into synthetic base tensors to enable functionalization. The original aliased inputs are reconstructed after execution via runtime epilogue.

## Stage 3: Joint Graph Tracing

`graph_capture_wrappers.py`

### Inference Path (No Autograd Needed)

- The function is functionalized.
- Input mutations are converted to extra outputs.
- The forward function is traced using make_fx to produce a pure forward FX graph.

### Training Path (Autograd Required)

- The function is functionalized and prepared for autograd by detaching inputs and setting up tangent inputs.
- A joint forward-backward function is constructed that runs the forward pass followed by a backward pass through torch.autograd.grad .
- The joint function is traced with make_fx producing a single FX graph that contains both forward and backward computations, enabling joint optimizations.

### Recomputation Heuristics

`MinCutOptions`

| Flag | Description |
|---|---|
| ban_if_used_far_apart | Avoid recomputation if result used far downstream. |
| ban_if_long_fusible_chains | Disallow recomputation on long fusible operator chains. |
| ban_if_materialized_backward | Avoid recomputation for nodes consumed by backward ops. |
| ban_if_reduction | Do not recompute reductions (expensive operations). |
