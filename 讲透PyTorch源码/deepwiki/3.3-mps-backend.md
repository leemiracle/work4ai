## Purpose and Scope

- Support for Apple GPUs using the Metal framework via Metal Shading Language (MSL) kernels.
- Operations implemented as Objective-C++ source translation units ( .mm ) dispatching to compiled Metal shader functions.
- Coverage of approximately 800+ operations: linear algebra, indexing, distributions, attention modules, and more.
- Integration with PyTorch’s dispatch system under the mps device key.

## Metal Shader Compilation and Caching

### Compilation Modes

- Bundled Mode (Default): Metal kernels are compiled offline during the PyTorch build using xcrun metal and packaged as .metallib binaries. MetalShaderLibrary::getBundledLibrary() provides access to these.
- JIT Mode: When PYTORCH_JIT_COMPILE_SHADERS is defined, Metal source is embedded as base64 strings in headers (e.g., LinearAlgebra_metallib.h ) and compiled at runtime.

## Key Operation Implementations

MPS Operations and Metal Kernels

### Linear Algebra

- Implementation in LinearAlgebra.mm handles matrix multiplication ( mm ), batched multiplication ( bmm ), and addmm .
- Matrix multiplication kernels in LinearAlgebra.metal use tiled shared memory ( A_tile , B_tile ) and threadgroup_barrier for synchronization.
- Sources: aten/src/ATen/native/mps/operations/LinearAlgebra.mm 70-120 aten/src/ATen/native/mps/kernels/LinearAlgebra.metal 12-54

### Indexing and Slicing

- Indexing.mm implements advanced indexing and masked_select .
- Uses validateInputData to enforce limits (e.g., maximum 16 indices).
- Kernels in Indexing.metal handle coordinate translation for multi-dimensional indexing.
- Sources: aten/src/ATen/native/mps/operations/Indexing.mm 66-143

### Reductions

- ReduceOps.mm manages operations like sum , mean , max , and min .
- Includes logic for set_apparent_shapes and set_axes to handle keepdim and specific reduction dimensions.
- Sources: aten/src/ATen/native/mps/operations/ReduceOps.mm 63-146

## Memory Management and Leak Detection

### Memory Query and Control APIs

- torch.mps.current_allocated_memory() : Bytes currently allocated by caching allocator.
- torch.mps.driver_allocated_memory() : Bytes allocated by Metal GPU driver.
- torch.mps.empty_cache() : Explicitly releases cached memory to the system.
