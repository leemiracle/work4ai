## Variable-Length Attention (varlen)

torch/nn/attention/varlen.py 2-6

### Implementation Details

- Input Format : Variable length sequences packed into a tensor shaped (total_tokens, num_heads, head_dim) . The boundaries of sequences are indicated by cumulative sequence tensors cu_seq_q and cu_seq_k torch/nn/attention/varlen.py 96-98
- Runtime Dispatch : The _select_backend logic inspects device and hardware support, routing to cuDNN or Flash Attention backends torch/nn/attention/varlen.py 144-182
- Supported Backends : Flash Attention : Preferred backend on CUDA devices, supporting windowed attention torch/nn/attention/varlen.py 181-182 cuDNN : Used for sequences where max_q > 128 and supported devices (SM90/SM100) torch/nn/attention/varlen.py 109-112
- Auxiliary Outputs : Users can request auxiliary outputs like log-sum-exp (LSE) for numerical stability using AuxRequest torch/nn/attention/varlen.py 18-21

## Compilation and Export Integration

- AOTInductor C Shim : Fused attention ops like aten._flash_attention_forward and aten._scaled_dot_product_flash_attention are registered as fallback ops to ensure ABI compatibility during AOT compilation torchgen/aoti/fallback_ops.py 49-82
- Autograd Support : Derivatives for attention ops are defined in derivatives.yaml , allowing AOT Autograd to trace through the joint forward-backward graph tools/autograd/derivatives.yaml 1-25
- Deterministic Algorithms : The backends respect torch.use_deterministic_algorithms . For example, Flash Attention will check the global context before selecting a non-deterministic path in backward passes aten/src/ATen/native/transformers/cuda/attention_backward.cu 152-162
