### Workflow Logic

- Matrix Generation : vllm-benchmark.yml runs generate_vllm_benchmark_matrix.py to create a dynamic matrix of models and runners (e.g., h100, b200) .github/workflows/vllm-benchmark.yml 85-89
- Source Build : _vllm-build.yml builds PyTorch and vLLM wheels. It also builds DeepGEMM using tools/install_deepgemm.sh .github/workflows/_vllm-build.yml 110-138
- Execution : _vllm-benchmark.yml installs the artifacts using uv pip install .github/workflows/_vllm-benchmark.yml 126-134
- Device Detection : The workflow detects hardware (CUDA, ROCm, HPU) to set the DEVICE_NAME . For ROCm, it utilizes amd-smi .github/workflows/_vllm-benchmark.yml 163-186
- Setup & Run : It uses setup_vllm_benchmark.py to configure the benchmarks in the vLLM repository before execution .github/workflows/_vllm-benchmark.yml 202-205
