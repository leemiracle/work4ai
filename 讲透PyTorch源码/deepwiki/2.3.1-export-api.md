## ExportedProgram Structure

`ExportedProgram`

### Core Components in ExportedProgram

| Attribute | Type | Description |
|---|---|---|
| graph_module | torch.fx.GraphModule | FX graph representing the traced model's computation with pure ATen operators. |
| graph_signature | ExportGraphSignature | Describes semantic kinds of inputs and outputs (parameters, buffers, user inputs). |
| state_dict | Dict[str, Any] | Model parameters and buffers captured at export time. |
| range_constraints | Dict[sympy.Symbol, ValueRanges] | Constraints describing symbolic tensor dimension bounds. |
| constants | Dict[str, Any] | Constant tensors lifted outside of the graph via _materialize_and_lift_constants . |

### Input and Output Kinds

`graph_signature`

- InputKind : USER_INPUT : Inputs supplied by the user at runtime. PARAMETER : Module parameters (weights). BUFFER : Persistent state like running means. CONSTANT_TENSOR : Constant tensors embedded as graph constants. CUSTOM_OBJ : Non-tensor objects like torch.ScriptObject or FakeScriptObject .
- OutputKind : USER_OUTPUT : The actual returned tensors from the forward method. BUFFER_MUTATION : Buffers mutated in-place reported as outputs. LOSS_OUTPUT : Special output for training loss.

### Tracing Modes: Strict vs Non-Strict

- Strict Mode ( strict=True ) : Uses TorchDynamo to produce a single undivided FX graph. Captures full symbolic shape guards and range constraints. Produces functional graphs composed of ATen operators.
- Non-Strict Mode ( strict=False ) : Permits graph breaks; the model may be handled with _NonStrictTorchFunctionHandler . Works via simplified tracing and input fakification using make_fake_inputs torch/export/_trace.py 39 Allows some dynamic behaviors and Python runtime by not requiring full bytecode analysis.
