## Core Components

| Component | Description | Key Files / Locations |
|---|---|---|
| native_functions.yaml | YAML registry defining operator signatures, schema, dispatch mappings, and variants. | aten/src/ATen/native/native_functions.yaml |
| Dispatcher (c10) | High-performance C++ router matching operator calls to implementations. | aten/src/ATen/core/dispatch/Dispatcher.h 1-100 |
| Backend Kernels | Device-specific kernels in C++, CUDA, or other languages providing actual computation. | aten/src/ATen/native/ |
| Meta Kernels | Kernels implementing shape/dtype inference without allocating storage. | torch/_meta_registrations.py 1-77 |
| Decomposition Table | Defines how complex ops decompose into simpler primitives. | torch/_decomp/decompositions.py 1-40 |
| torchgen | The code generator that produces dispatch and registration boilerplate. | torchgen/model.py 1-100 |

### Meta Kernels and Decompositions

- Meta Kernels : Registered via register_meta torch/_meta_registrations.py 66-76 these allow the system to perform shape inference without memory allocation.
- Decompositions : Complex operators can be broken down into simpler ones using register_decomposition torch/_decomp/decompositions.py 125-140 This is critical for backends that only implement a subset of the ATen IR.
