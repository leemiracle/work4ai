## Inductor Intermediate Representation (IR)

torch/_inductor/ir.py 189-220

- TensorBox : The top-level IR node representing a tensor output. It may own storage or represent a view.
- View : Metadata node modeling tensor views (e.g., transpose, slice) without copying data.
- StorageBox : Abstraction for storage ownership with layout information.
- Buffer : Represents a physical 1D memory allocation holding tensor data.
- Pointwise, Reduction : Operation nodes representing element-wise and reduction computations.

| IR Node Type | Role | Source Location |
|---|---|---|
| TensorBox | Top-level tensor node | torch/_inductor/ir.py:84 |
| StorageBox | Tensor with owned storage | torch/_inductor/ir.py:89 |
| Buffer | 1D allocated tensor data buffer | torch/_inductor/ir.py:211 |
| Pointwise | Element-wise computation node | torch/_inductor/ir.py:81 |
| Reduction | Aggregation computation node | torch/_inductor/ir.py:82 |
