## Gradient Synchronization Data Flow

```

```

- The Reducer installs autograd hooks during prepare_for_forward() before the forward pass starts torch/_C/_distributed_c10d.pyi 60
- When gradients for a parameter become ready during backward, autograd hooks notify the Reducer.
- The Reducer flags the parameter as ready; when all parameters in the bucket are ready, it initiates asynchronous all-reduce via the ProcessGroup torch/distributed/distributed_c10d.py 111-112
- If a communication hook is registered, the Reducer runs it before triggering the collective, enabling gradient compression or custom reductions torch/_C/_distributed_c10d.pyi 75
- The returned Work object allows asynchronous waiting or overlapping of communication and computation torch/distributed/distributed_c10d.py 65-66
- Once all buckets complete, backward finishes and DDP can proceed with the optimizer step.
