## Guard Checking and Recompilation

### Runtime Guard Validation Flow

- Locals and Globals Captured: The RootGuardManager receives the current frame's locals and globals.
- Traversing Guard Tree: The RootGuardManager recursively traverses GuardManager nodes and invokes LeafGuard checks. Accessors extract child objects during traversal.
- Tensor Metadata Checks: Specialized TensorCheck objects validate tensor dispatch keys, dtype, device index, requires_grad, and optionally symbolic dynamic dim information torch/csrc/dynamo/guards.cpp 177-194
- Symbolic Shape Guards: Complex symbolic shape constraints are validated using ShapeEnv to ensure dynamic shapes conform to expected symbolic constraints torch/fx/experimental/symbolic_shapes.py 200 torch/_dynamo/guards.py 106-112
- Global State Guards: Checks on global PyTorch state variables such as grad enabled and default dtype torch/_dynamo/convert_frame.py 60
- Guard Failures: If any guard fails, the entire guard validation returns false, causing Dynamo to trigger recompilation torch/_dynamo/guards.py 175-178

### Guard Failure Reporting and Recompilation Trigger

- On guard failure, a GuardFail object tracks the failure reason torch/_dynamo/guards.py 175
- Detailed debug info including the failed guard condition are collected for diagnostics torch/_dynamo/guards.py 63
- The current cache entry is invalidated, and Dynamo searches the list of compiled cache entries for another that matches.
- If no valid cache exists, recompilation occurs to produce a new specialized graph torch/_dynamo/convert_frame.py 98-103
- Recompilation limits are enforced via recompile_limit to prevent excessive compilation torch/_dynamo/config.py 121

### Compilation Cache and Cache Misses

`CacheEntry`
torch/_dynamo/convert_frame.py 199

- At runtime, Dynamo tests each cache entry's guard set using RootGuardManager .
- On the first cache entry whose guards all pass, the cached compiled code is executed.
- If no entry matches, a cache miss occurs, prompting compilation via ConvertFrame torch/_dynamo/convert_frame.py 11-12
- The number of recompilations is tracked; exceeding recompile_limit (default 8) triggers a fallback to eager execution or a warning torch/_dynamo/config.py 121

## Optimization: Version-Based and Tag-Safe Guards

- dict_version : Uses CPython dictionary internal version numbers to quickly detect dictionary mutations, allowing skipping deep rechecks if versions remain unchanged torch/_dynamo/guards.py 55
- Type MRO Guards: Instead of checking every base class, TypeMROGuardAccessor ensures the method resolution order (MRO) is unchanged torch/_dynamo/guards.py 76
- Leaf Guard Deduplication: When adding guards, the system skips adding duplicates to the manager torch/csrc/dynamo/guards.cpp 141-145
- Symbolic Shape Hints: guarding_hint_or_throw provides concrete hints for symbolic values to avoid unnecessary symbolic reasoning when possible torch/fx/experimental/symbolic_shapes.py 131-154
