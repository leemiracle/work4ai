- GraphLowering is the main driver that takes an FX node and produces one or more IR nodes. torch/_inductor/graph.py 93-107

### Lowering Registration System

- lowerings dictionary : Keys are ATen operator overloads or strings representing symbols; values are lowering functions. torch/_inductor/lowering.py 127
- user_lowerings : User-registered lowerings that take priority over built-in ones. torch/_inductor/lowering.py 129

### Layout Constraints

- needs_exact_strides : Requires strides to match eager-mode tensor exactly. torch/_inductor/lowering.py 205-206
- needs_contiguous_strides : Requires standard contiguous memory layout. torch/_inductor/lowering.py 207-208
- needs_fixed_stride_order : Requires fixed relative stride ordering (e.g., channels last). torch/_inductor/lowering.py 209-210

## Decompositions

- The decompositions registry maps ops to decomposition functions generating simpler building blocks. torch/_inductor/lowering.py 69
- Inductor heavily relies on common decompositions to expand unsupported or compound ATen ops. torch/_inductor/lowering.py 69-70
- During lowering, decompositions are checked and applied before invoking registered lowering logic. torch/_inductor/graph.py 25
