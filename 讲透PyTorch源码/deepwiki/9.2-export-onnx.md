### Core Pipeline Flow

`torch.onnx.export(..., dynamo=True)`

- Graph Capture : Captures the model into an ExportedProgram . This is achieved via torch.export.export() which uses TorchDynamo to produce a graph with functionalized ATen operators torch/export/_trace.py 114-125
- Decomposition : Transforms high-level ATen operators into ONNX-compatible decompositions. The system uses the torch.export.default_decompositions to resolve complex operators into primitives torch/export/test_export.py 57-58
- Translation : Converts the functionalized FX graph into ONNX IR nodes. This stage utilizes FakeTensor metadata for shape and dtype propagation torch/_subclasses/fake_tensor.py 20-21 torch/_export/non_strict_utils.py 200-215
- Post-processing : Applies IR passes such as axis renaming and opset import collection.
