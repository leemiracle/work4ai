## Position in the Compilation Stack

`torch.compile`

- TorchDynamo : Captures Python bytecode and performs symbolic tracing to produce a forward FX graph. torch/_functorch/_aot_autograd/graph_compile.py 193-196
- TorchInductor (or other backend compilers): Compiles optimized kernels from partitioned forward and backward FX graphs. torch/_inductor/compile_fx.py 55-64

- TorchDynamo produces an FX graph module.
- AOT Autograd takes this forward graph, traces joint forward-backward FX graphs after functionalizing mutations. torch/_functorch/_aot_autograd/graph_compile.py 61-63
- It partitions the joint graph into forward and backward subgraphs. torch/_functorch/partitioners.py 67-71
- Each subgraph is compiled independently by the backend compiler. torch/_inductor/compile_fx.py 146-155

### Stage 1: Graph Capture ( aot_stage1_graph_capture )

- Handles input deduplication ( AOTDedupeWrapper ) and creation of synthetic bases to unify aliasing ( AOTSyntheticBaseWrapper ). torch/_functorch/_aot_autograd/graph_compile.py 186-191
- Traces a joint forward-backward autograd graph if needs_autograd is True , or a forward graph for inference via aot_dispatch_base_graph . torch/_functorch/_aot_autograd/graph_compile.py 61-63
- Collects aliasing and mutation metadata ( ViewAndMutationMeta ). torch/_functorch/_aot_autograd/runtime_wrappers.py 93-94

### Stage 2: Compilation ( aot_stage2_compile )

- Applies graph partitioning using min_cut_rematerialization_partition . torch/_functorch/partitioners.py 52-55
- Runs configured forward and backward compilers independently.
- Wraps the result in a RuntimeWrapper that manages mutation side effects after execution. torch/_functorch/_aot_autograd/runtime_wrappers.py 193-209
