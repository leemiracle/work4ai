- Location: torch/distributed/device_mesh.py 152-168

### _MeshLayout

- Location: torch/distributed/_mesh_layout.py 28-130
- _MeshLayout is a frozen dataclass encoding (shape, stride) layout metadata to represent multidimensional mesh coordinates.
- Implements "layout algebra" inspired by NVIDIA CuTe but adapted for PyTorch’s lexicographic storage order.
- Used to translate between multi-index mesh coordinates and flat rank indices.
- Key methods: numel() — product of all dimension sizes, total ranks in this layout torch/distributed/_mesh_layout.py 99-100 complement(world_size) — computes a complementary layout to fill all ranks in the world torch/distributed/_mesh_layout.py 132-155 composition(other_layout) — applies one layout as a selector on another torch/distributed/_mesh_layout.py 102-130

### Implementation Details

- Storage: A LocalTensor holds a dictionary of local shards indexed by rank torch/distributed/_local_tensor/__init__.py 7-8
- Dispatch: It uses __torch_dispatch__ to apply operations to each local shard. For collectives, it performs mathematically equivalent operations on the local shards torch/distributed/_local_tensor/__init__.py 23-26
- Mesh Requirement: Issued collectives must respect a DeviceMesh abstraction to reverse engineer collectives for ranks not participating in the current local PG torch/distributed/_local_tensor/__init__.py 27-39
