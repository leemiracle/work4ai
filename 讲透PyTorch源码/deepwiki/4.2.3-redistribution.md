## Purpose and Scope

redistribution system
Sharding Propagation and OpStrategy

- Planning optimal collective communication sequences for multi-dimensional mesh layouts.
- Executing collectives such as all-gather, all-reduce, reduce-scatter, and all-to-all on local shards.
- Optimizing communication sequences to minimize overhead and memory traffic via flattening.
- Supporting cost-aware, graph-based planning (Dijkstra) and a faster heuristic greedy approach.

- torch/distributed/tensor/_redistribute.py 1-54
- torch/distributed/tensor/_api.py 26-29

## Redistribution Planning Strategies

### Greedy Algorithm (Default)

Key points:

- Iterates over each mesh dimension to detect differences between source and target placements.
- Generates a _TransformInfo per mesh dimension needing transformation.
- Faster but may miss global communication cost optimizations in complex meshes.

- torch/distributed/tensor/_redistribute.py 472-568
