## Overview of the Eager Mode Workflow

- Model Preparation : Modules are manually instrumented with QuantStub and DeQuantStub .
- Fusion : Adjacent operations (e.g., Conv + ReLU) are fused using fuse_modules to improve performance and numerical stability.
- QConfig Assignment : A QConfig (Quantization Configuration) is assigned to the model or specific sub-modules, defining which Observer or FakeQuantize modules to use.
- Preparation : The prepare function (for static) or prepare_qat (for QAT) is called to insert observers or fake-quantization modules.
- Calibration/Training : The model is run with representative data to collect statistics.
- Conversion : The convert function transforms the observed FP32 model into a quantized integer model.

## Migration toward PT2E

- Graph Capture : PT2E uses torch.export.export() instead of manual QuantStub placement.
- Lowering : Quantized graphs in PT2E are lowered to Inductor, which can autotune kernels.
- Static Runtime : For mobile/edge deployment, static runtime passes like ReplaceWithCopy optimize memory management for quantized tensors benchmarks/static_runtime/test_static_runtime.cc 43-48
