## Pattern Matcher Infrastructure

Pattern Matcher
`torch._inductor.pattern_matcher`

### Overview

- Patterns are defined as pairs of search and replacement functions.
- Registration is done via register_replacement or register_graph_pattern , which convert search functions into internal graph patterns for matching torch/_inductor/pattern_matcher.py 6-28
- The match DAG is represented by a graph of PatternExpr nodes torch/_inductor/pattern_matcher.py 31-34
- PatternMatcherPass is parameterized by a subsystem name, enabling independent pattern sets (e.g., joint graph, post-grad) torch/_inductor/fx_passes/post_grad.py 77-79

### Key Classes and Concepts

| Symbol / Class | Description |
|---|---|
| PatternMatcherPass | Container for a group of patterns applied sequentially; constructed with a subsystem name. torch/_inductor/pattern_matcher.py 29 |
| register_replacement | Decorates search/replace functions to trace them into a graph transformation. torch/_inductor/pattern_matcher.py 51 |
| Match | Holds successful match results, including nodes and matched arguments. torch/_inductor/pattern_matcher.py 32-33 |
| Arg , KeywordArg | Placeholders within pattern definitions to match nodes or keyword-arguments. torch/_inductor/pattern_matcher.py 20-27 |
| MULTIPLE | Sentinel symbol indicating multiple quantities can be matched. torch/_inductor/pattern_matcher.py 150-158 |

## Important Optimization Passes

### Joint Graph Passes

- No-op Removal : Eliminates trivial arithmetic like x + 0 , x * 1 , or x / 1 . It uses fake_tensors_eq to ensure the replacement is safe, checking shape, device, and dtype torch/_inductor/fx_passes/joint_graph.py 95-172
- Lossless Cast Widening : Identifies floating-point casts that do not discard precision or range (e.g., float16 to float32 ) and simplifies them if redundant torch/_inductor/fx_passes/joint_graph.py 63-81
- Initialization : lazy_init sets up patterns for specialized kernels like pad_mm (matrix multiplication padding) and sfdp (scaled dot product attention) torch/_inductor/fx_passes/joint_graph.py 84-93

### Post-Grad Passes

- Profiler Ops Removal : Erases record_function enter/exit nodes from the graph to prevent them from blocking fusion torch/_inductor/fx_passes/post_grad.py 93-114
- Random Ops Ordering : If config.fallback_random is set, this pass chains nondeterministic seeded nodes (e.g., random generators) using control_deps to preserve their original program order torch/_inductor/fx_passes/post_grad.py 125-143
- Reinplace Transformation : The reinplace_inplaceable_ops pass converts functional ATen ops back to their in-place versions (e.g., aten.add to aten.add_ ) when it is safe to mutate the input buffer torch/_inductor/fx_passes/reinplace.py 43-55
