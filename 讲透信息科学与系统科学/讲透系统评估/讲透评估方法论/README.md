# 讲透评估方法论 · 测量与聚合的宪章

> **定位**:这支负责评估的**中下两层**——怎么把价值变成数(测量),怎么把数变成排序(聚合)。AHP/TOPSIS/DEA/outranking 都住在这里。
> 自定主干支(GB/T 12040 未列三级;2026-09-07 立宪)。

## 诞生

测量论(20 世纪初心理物理学的量表之争)→ von Neumann–Morgenstern 效用公理(1944)→ Saaty AHP(1977/1980)→ outranking 学派(ELECTRE, Roy 1968 法国学派)。

## 核心问题(3-5 条)

| 问题 | 状态 |
|------|------|
| 偏好能否公理化测量 | ✅ vNM 效用定理(期望效用下基数可测) |
| 两两比较→权重的算法 | ✅ AHP 特征向量法(Perron–Frobenius) |
| 免权重评估 | ✅ DEA 线性规划包络(1978) |
| 聚合的公理边界 | ✅ Arrow 不可能定理(否定式) |
| 排序稳定性 | ✅ 否定式:rank reversal(1983) |

**这支最美的一个事实**:你永远说不出 A 的绝对重要性,却总能说出 A 对 B 的相对重要性——而 n(n−1)/2 个相对判断能精确还原 n 个绝对权重(信息不损失,这正是特征向量机的工作原理)。
