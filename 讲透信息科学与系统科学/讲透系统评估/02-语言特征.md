# 02 · 语言特征:偏好表、权重与 Arrow 之墙

> **本章回答五问之三(家族层):表达?逻辑?规范化?**
> 评估的母语三件:**偏好表**(两两比较矩阵)、**权重**(归一化正向量)、**聚合算子**(表+权重→排序)。三件之上横着一堵墙——Arrow 不可能定理,规定了这门语言**永远说不出**的话。

---

## 一、表达:这门语言能说什么

三步法:直觉——评估语言的基本句型是"A 比 B 好多少";严格——偏好关系 ⪰ 定义在方案集 X 上,配效用函数 u:X→ℝ;最小例子——两两比较矩阵 A=(a_ij),a_ij=3 读作"i 比 j 略重要"。

| 说得出 | 说不出 |
|-------|-------|
| 方案间偏好强度(AHP 1-9 标度) | 不可通约的价值(尊严 vs 效率) |
| 准则权重与分层结构 | 权重的"真值"——权重是构造不是测量 |
| 群体聚合的程序与结果 | 满足全部无害公理的"完美聚合"(Arrow) |
| 不确定性下的期望效用 | 模糊偏好的一票否决表达(outranding 部分弥补) |

为什么是这样:评估对象是**价值**,而价值不像长度有外部基准——语言的一切扭曲(基数化、可分解、聚合)都是"没有基准还要算数"的代价。

## 二、逻辑:Arrow 之墙与三条定理

评估的逻辑性质由三条定理钉死:

1. **Arrow 不可能定理**(1951):≥3 方案、≥2 人(或准则),同时满足无限制域/帕累托/无关方案独立性/非独裁的聚合**不存在**。三步法:直觉——没有完美的投票;严格——四公理两两不相容;最小例子——孔多塞循环:3 人 3 方案,A>B>C、B>C>A、C>A>B,群体偏好成环,任何"群体排序"都违反某条公理。
2. **rank reversal**(Belton–Gear 1983):AHP 分布模式下加新方案可翻转旧排序——**为什么**:归一化让每个准则的"蛋糕"恒为 1,新方案进场必然重新切分(实验数值显形)。
3. **Goodhart 定律**(定性):指标成为目标即失效——逻辑根源:代理与目标的相关性在博弈压力下断裂。

✨ 美之时刻(⑧要件):Arrow 定理的证明只用了三个方案两个偏好的**最小反例**构造——整个社会选择理论的不可能性,被一个 3×3 的循环钉死。为什么美:极简;怎么亲历:手推孔多塞循环,看每条公理死在哪一步。

## 三、规范化:从手艺到制度

| 层级 | 状态 |
|------|------|
| AHP/TOPSIS/DEA 有完整公理化(算子定义在偏好结构上) | 高 |
| 两两比较 1-9 标度是 Saaty 学派的**约定**,非测量标准 | 中 |
| 环评/可行性研究的**程序**规范(法规级) | 高(法律规范化) |
| 指标体系设计 | 低(手艺,病理学见支) |

为什么是这样:数学侧规范化高(算子可公理化),价值侧只能程序化(法规管程序不管数值)——**数学规范化到哪,恰恰标出价值问题在哪止步**。
