# 讲透可行性分析 · 工程的 go/no-go 宪法

> **定位**:这支负责评估的**事前时态**——大额投入前的系统化审查:技术上可行吗?经济上划算吗?社会与环境可接受吗?"先评估后上马"的制度载体。
> 自定主干支(GB/T 12040 未列三级;2026-09-07 立宪)。

## 诞生

美国 1936 年《洪水控制法》(收益必须超过成本)→ RAND 成本效益分析(1950s)→ 联合国工发组织《工业可行性研究手册》(1978,全球扩散)→ 中国 1980s 将可行性研究写入基本建设程序。

## 核心问题(3-5 条)

| 问题 | 状态 |
|------|------|
| 未来的收益流如何与当下成本比较 | ✅ 折现现金流 NPV/IRR(资本预算成熟工具) |
| 不确定性下的 go/no-go | 🔄 实物期权(Black–Scholes 思想的工程化)仍在推广 |
| 非市场价值如何入账 | 🔄 环境估值(条件价值法等)争议持续 |
| 沉没成本如何被排除 | ✅ 决策论定论:只有边际成本相关(实践常违反——沉没成本谬误) |

**这支最美的一个事实**:可行性分析的最难处不是算 NPV,而是**证明"不做"也是一个方案**——机会成本概念把"行动的世界"变成"方案对方案的世界",不行动从此有了价格标签。

## 假设与依赖

未来可折现(折现率的选择=代际伦理,争议焦点);风险可概率化(深度不确定性下失效);预测可信(Goodhart 风险)。前置:家族层 00 章。
