# 讲透指标体系 · KPI 的病理学

> **定位**:这支负责评估的**测量材料学**——指标怎么设计、怎么分层、怎么异化。一切"综合得分"的地基,也是 Goodhart 反噬的案发现场。
> 自定主干支(GB/T 12040 未列三级;2026-09-07 立宪)。

## 诞生

泰勒科学管理(1911,测量劳动)→ 平衡计分卡 Kaplan & Norton(1992,财务+客户+流程+学习四维)→ 中国目标责任制与考核指标体系(1980s-); Goodhart 定律(1975 提出)在量化管理普及后成为显学。

## 核心问题(3-5 条)

| 问题 | 状态 |
|------|------|
| 指标能否忠实代理目标 | ✅ 否定式:Goodhart 定律(成为目标即失效) |
| 多维指标如何平衡 | ✅ 平衡计分卡(实务方案,非定理) |
| 指标可否自我检验 | 🔄 坎贝尔定律的社会测量学仍在前线 |
| 指标博弈如何监测 | 🔄 代理-目标相关性衰减监测(工程实践) |

**这支最美的一个事实**:"凡测量即扭曲"有精确的戏剧版——苏联用钉子重量考核工厂,得到少而重的巨型钉子;改考核数量,得到多而轻的针钉。**指标定义了被优化函数,被考核者是最强的优化器**——测量工具与被测系统构成闭环,测量从此不再是旁观。

## 假设与依赖

指标与目标正交相关(一被使用即衰减);指标可分层分解(SMART 原则);可考核=可管理(德鲁克信条,Goodhart 之下需加"会反噬"脚注)。前置:家族层 [`../02-语言特征.md`](../02-语言特征.md)。
