# 讲透系统评估 · 把价值判断变成可辩护的程序

> **本质一句话**：系统评估=在"什么都想要、什么都量化不了"的困境里，把多目标、多主体、不确定的价值判断变成**可辩护的程序**——评估不是测量，是测量+聚合+程序正义。
>
> GB/T 13745-2009：120 **系统评估与可行性分析**(GB/T 未列三级→本家族自定主干支，各支标注「自定主干支」)。
> 家族：[讲透信息科学与系统科学](../README.md)·12040。五章为家族总纲，三支子系列各自由宪法 README 起步。
