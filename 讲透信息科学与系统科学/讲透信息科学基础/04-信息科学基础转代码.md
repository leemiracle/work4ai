# 04 · 信息科学基础转代码：三论的代码化身

> **本章回答五问之五（家族层）。** 三论恰好对应软件世界的三种"化身"：
> 信息论化身在**编解码器**（压缩/纠错/学习度量），控制论化身在**反馈循环**
> （从恒温器到 RLHF 训练环），系统论化身在**仿真引擎**（系统动力学到 agent 社会）。
> 最后给三论的代码边界（不可机械化处）。

---

## 一、三走廊总表（可机械化边界 / 代码走廊 / 工程师落点）

| 论 | 可机械化边界 | 代码走廊（问题类→算法→库/形态） | 工程师落点 |
|---|---|---|---|
| 信息论 | 熵/互信息可算；一般信道容量不可判定 | 文本熵统计→字频+log₂→纯 python；数据压缩→Huffman/arithmetic→zlib；信息度量→sklearn `mutual_info_score` | 压缩即学习的代理指标（更短描述=更好模型） |
| 控制论 | 线性系统综合全可机械；非线性 Lyapunov 无通用算法；RL 控制器无稳定性证明 | PID→`simple_pid`；状态空间→python-control；仿真→`scipy.integrate.solve_ivp` | 训练环/服务自动扩缩容/数据库反馈调节都是 PID 的变体 |
| 系统论 | 可仿真；涌现不可预测；同构性不可判定 | 系统动力学→差分方程循环；元胞自动机→numpy 卷积；agent 社会→循环调度 | 仿真=最廉价的实验；但输出是假设生成器，不是证据 |

## 二、逐条速写

### 走廊一：熵的十行实现（信息论）

```python
from collections import Counter; from math import log2
def entropy(s): p=[c/len(s) for c in Counter(s).values()]; return -sum(x*log2(x) for x in p)
```
香农 1948 的整个度量论，python 十行。**为什么能这么短**：因为熵被定义成
纯统计泛函（02 章）——无语义拖累，才能无工程拖累。

### 走廊二：反馈环的一百行实现（控制论）

实验脚本第二段是最小可跑版：一阶惯性对象（房间）+ P/PI 控制器 + 扰动阶跃。
真实现场：温控、电机、云服务 HPA（Kubernetes 的水平扩容=带设定点的反馈）。
**关键洞见**：训练神经网络本身就是反馈环（loss=误差信号，优化器=控制器）——
这就是 [01 章](01-近五年创新.md) "对齐=控制"的技术底座。

### 走廊三：仿真循环的一百行实现（系统论）

系统动力学的骨架=状态向量 + `x[t+1] = f(x[t])` 循环；agent 社会=给每个 agent
加感知-决策-行动三步。**关键边界**：仿真能跑≠结论可信——World3 模型（1972
《增长的极限》）当年跑出的预测成为半个世纪的争论，正因"可仿真、难证明"
（03 章）。仿真输出应作为**假设生成器**交给数据检验。

## 三、三论合体的当代样本：一个大模型训练现场

| 训练组件 | 三论化身 | 具体对应 |
|---|---|---|
| 数据管道/分词/压缩 | 信息论 | token 化=字典编码；数据选择=互信息筛选 |
| loss-梯度-更新循环 | 控制论 | 误差信号→参数修正（控制器=优化器） |
| RLHF/评估回路 | 控制论 | 人类偏好=设定点，策略=被控对象 |
| Scaling laws/涌现观察 | 系统论 | 规模作为结构变量；涌现=整体行为 |

一个训练现场同时跑着三论的代码化身——这就是本家族"三论公理层"的工程证明。

## 四、裂缝清单（不可机械化处，原则上/工程上）

| 裂缝 | 性质 | 后果 |
|---|---|---|
| 柯氏复杂度不可计算 | 原则上 | "最优压缩/最短描述"永远只能逼近（MDL 用作代理） |
| 一般非线性控制综合无算法 | 原则上 | 安全关键系统退回验证式设计（domain-specific 手艺） |
| 涌现不可预测、同构不可判定 | 原则上 | 复杂系统的"预言"只能事后归纳——买保险，别买预言 |
| 语义不可度量 | 原则上（香农主动排除） | "信息含量"的日常语义 ≠ 熵——引用熵时永远先问是哪一种 |
