## 〇、为什么三论是一个家族

1948 年是信息科学的"奇点年"：香农《通信的数学理论》与维纳《控制论》同年出版，
贝塔朗菲的系统思想同期成型。三论共享一个反直觉直觉——
**不看实体看组织**：信息不是纸上的字，是不确定性的消减；控制不是用力，是反馈；
系统不是零件堆，是关系网。三论是"组织化的科学"的三种方言。
