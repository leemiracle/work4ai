## 诞生

Bertalanffy 1937-1968：生物学家受不了"还原论把生命拆成分子就宣布解释了生命"，
提出一般系统论——**系统是关系的组织，同构性让生物学、社会学、工程学共享规律**。
1968《General System Theory》集大成；圣塔菲研究所（1984）把"复杂性"立为新旗。

## ✨ 这支最美的一个事实

**同构性**：心跳振荡器、萤火虫同步闪、伦敦千禧桥晃动——三个领域的同一道数学
（耦合振子）。系统论的"万物一篇结构"不是诗，是 Kuramoto 方程的三次出场。
