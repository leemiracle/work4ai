# 讲透信息论（GB/T 12010 三级 · 承接型支占位）

> **这支负责什么**：信息的度量、压缩与传输的极限——"信息"从日常词变成
> 可计算量的那门科学。本支为**承接型占位**：正主内容在
> [讲透数学/讲透信息论](../../../讲透数学/讲透信息论/)（✅ 8 章），本支管学科定位与入口。

## 诞生

Shannon 1948《通信的数学理论》：把"信息"定义为**不确定性的消减**（熵），
一次性给出压缩下界（信源编码）、传输极限（信道容量）与可靠传输的构造（编码）。
一门学科从一篇文章开始——科学史上罕见的零到一。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 无损压缩的下界 | ✅ 已解：熵即下界（Huffman/算术编码可达） |
| 含噪信道可靠传输 | ✅ 已解：信道容量定理（随机编码证明） |
| 速率失真理论（有损压缩） | ✅ 已解（框架） |
| 率失真码的显式构造与最优码 | 🔄 前线（极化码是最近一次大胜：2009 Arikan，达容量） |
| 语义信息度量 | ❌ 开放（香农主动排除语义；语义熵尚无公认理论） |

## ✨ 这支最美的一个事实

**熵的三条公理（连续/单调/可加）唯一确定 -Σp log p 这个形式**——
不是香农选了这个公式，是数学只承认这一个候选。
