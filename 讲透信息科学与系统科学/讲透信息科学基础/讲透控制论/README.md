> 本支为**承接型占位**：工程与理论正主在仓库根
> [讲透控制论](../../../讲透控制论/)；数学面由 [12030 讲透控制理论](../../讲透控制理论/)
> 家族承担（双挂）。

## 诞生

Wiener 1948《控制论》（Cybernetics，希腊语"舵手"）：防空火控的战时研究凝结成
"反馈=目的的机械论"——恒温器追温度、猎豹追羚羊、追炮弹追飞机，是同一个环。
书名取自安培 1834 年对"治理术"的借词——控制的词根就是掌舵。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 反馈何时镇定系统 | ✅ 已解（奈奎斯特/Lyapunov 判据） |
| 最优控制 | ✅ 已解（Pontryagin 极大值原理/Bellman 动态规划，冷战双生） |
| 非线性自适应系统的通用综合 | 🔄 前线（Lyapunov 设计=手艺） |
| 学习型控制器（RL）的稳定性保证 | ❌ 开放——AI 对齐问题的技术面 |
| 目标本身从何而来（目的的起源） | ❌ 哲学级开放（控制论自认排除） |

## ✨ 这支最美的一个事实

Black 1927 的负反馈：**用放大误差来消灭误差**——给失真的高增益放大器包一层环，
失真按增益比压缩。一个看似悖论的动作成为一切自动控制的母结构。
