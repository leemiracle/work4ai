# 讲透突变论 · 渐变如何突变为质变（GB/T 12020 三级：突变论）

> **这支负责的问题**：参数的连续变化为何引发行为的不连续跳变？
> 一句钉住：**突变论把"量变引起质变"做成分类学——
> 势函数的奇点只有七种基本突变（余维数 ≤4）。**
>
> 分工声明：突变论的数学正主是**奇点理论**，住在数学宇宙
> [讲透数学/讲透拓扑学/讲透奇点理论](../../../讲透数学/讲透拓扑学/讲透奇点理论/)；
> 本支取系统学侧——突变分类作为系统行为质变的语言。

## 诞生

Thom《Structural Stability and Morphogenesis》（1972，法语 1972/英译 1975）。
拓扑学家托姆用 Whitney 奇点理论回答生物学家的胚胎形态问题：
发育的连续过程为何产生离散的器官形态。1970s 被媒体捧为"万有理论"
（Zeeman 过度应用于监狱暴动/狗咬人），随后被学界反噬——
**过度承诺-反噬循环**是方法论史的经典教案。

## 核心问题

| 问题 | 状态 |
|------|------|
| 七种基本突变的分类定理 | ✅ 已解（Thom 分类，余维 ≤4 的普适展开） |
| 尖点突变的经验验证 | ✅ 部分（滞回/双峰态/发散性三标志在工程/心理数据中反复出现） |
| 高余维突变的分类 | ✅ 已解（但无穷序列，实用性递减） |
| 突变论作为"万有方法论" | ❌ 被证伪（1970s 教训：分类≠预测机制） |

## 这支最美的一个事实

**尖点突变的双重人格**：同一个系统，从"行为轴"一侧慢慢加压——
在某点突然跳变（狗从温顺直接翻到攻击，没有中间态）；但若绕道
"滞后轴"背后，却能连续地穿过——**跳不跳变取决于你走哪条路**，
这就是 hysteresis（滞回）：生态系统崩溃后加回原条件也不复原的
数学根源。

## 假设与依赖

系统由势函数（梯度系统）支配——这是突变论最强假设：
非梯度系统（如多数混沌系统）只有分岔分类，没有势。
