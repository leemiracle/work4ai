# 系统学思维技能（GB/T 12020 · 讲透系统学家族的抽象层）

## ① 何时用此分支（问题特征触发词）

1. "整体大于/不等于部分之和"——想解释或预测集体层的新性质
2. 现象跨领域重复出现（生物/社会/技术系统同款行为模式）→ 问同构性
3. 多主体、局部规则、全局模式（鸟群/市场/舆论/城市）
4. "临界点/相变/tipping point"——小扰动引发系统质变
5. 幂律、无标度、长尾——没有特征尺度的统计
6. 秩序从无序中自发出现（自组织），且系统开放、有能量/物质流过
7. 参数渐变导致行为突跳（量变→质变）
8. 需要判断"这个模拟结果可信吗"（涌现 vs artifact）

## ② 核心思维模式

- **系统眼**：先问"谁和谁在交互、交互拓扑是什么"，再问个体是什么
- **快慢分离**：找时间尺度最慢的变量（序参量）——它役使其余变量，
  是系统当前的主叙事
- **涨落眼**：临界点附近噪声=新秩序的种子；平衡态的直觉在此失效
- **系综替代**：混沌/复杂系统单轨不可预测，永远改问统计性质
- **承诺分层**：任何结论先标档——定理级/统计物理级/模拟级，证据折扣不同

## ③ 工具箱（何时用什么）

| 工具 | 何时用 |
|------|--------|
| 分岔图扫描 | 参数如何改变系统行为质（家族实验） |
| 李雅普诺夫指数（Benettin/1D ln\|f'\|） | 判定混沌与可预测时窗 |
| ABM（Mesa/自写） | 异质主体+局部规则→看全局模式 |
| 网络度量（NetworkX） | 交互结构：度分布/聚类/中心性/社团 |
| 盒计数维数 | 分形/奇异吸引子的维数 |
| 序参量方程（绝热消去） | 时间尺度悬殊时降维到慢变量 |
| 尖点突变三标志 | 滞回+双峰+发散性=尖点候选 |
| 有效信息 EI/PID | 粗粒化因果测量（涌现定量化，定义仍在竞争） |
| 临界慢化指标（方差/自相关升高） | 系统逼近 tipping point 的早期预警 |

## ④ 常见误区与禁忌

- **把"复杂/涌现"当修辞用**：说了等于没说——必须落到可测量
  （哪个指标？哪条走廊的承诺强度？）
- **涌现≠神秘主义**：能局部解释的别用整体搪塞；真不可还原的
  （如普适常数）恰恰是最可测量的
- **机制欠定遗忘症**：同一幂律至少四种机制生成——拟合曲线≠证明机制
- **ABM 单跑定论**：模拟=一次实验不是证明；不做敏感性分析就下结论是禁忌
- **系统论≠万物理论**：它给通约层语法，具体定律住在各学科里——
  越界解释（如"突变论解释社会革命"）是 1970s 已付学费的错误
- **给混沌系统上单轨精度**：指数敏感下堆算力无效，改堆样本

## ⑤ 与相邻分支的判别表 + 组合接口

| 症状像… | 但去 | 判别 |
|---------|------|------|
| 轨道长时间行为、吸引子 | 讲透数学/讲透分析/讲透动力系统 | 要严格定理→数学侧；要系统语境（边缘/控制/涌现）→本家族 |
| 有目标的反馈（机器人/恒温器） | 讲透控制理论家族（12030） | 控制论=有目标干预；系统学=无目标自组织 |
| 信息度量/编码 | 讲透数学/讲透信息论 | 熵的同源不同职：通信 vs 系统结构 |
| 个体策略互动 | 讲透数学/讲透博弈论 | 博弈=策略主体；ABM=规则主体 |

组合接口：系统学×博弈论→演化博弈/网络博弈；系统学×信息论→因果涌现 EI；
系统学×性能工程→大规模 ABM 的 GPU 化与系综并行；
系统学×深度学习→涌现能力/机制可解释性的复杂系统读法。
