# 讲透复杂系统 · 网络与涌现的科学（GB/T 12020 三级：复杂系统与复杂性科学）

> **这支负责的问题**：大量异质主体交互为何产生新的集体层次——
> 而这个新层次如何被观察、度量、甚至被定义？
> 一句钉住：**复杂系统=网络（结构）+多主体（异质）+涌现（新层次）
> +临界（敏感区间）——圣塔菲纲领的四根柱子。**
>
> 挂靠：计算/实战线在仓库根 [讲透复杂系统](../../../讲透复杂系统/)、
> 多智能体侧 [讲透群体智能](../../../讲透群体智能/)（就地成员，零迁移）——
> 本支是它们的 GB/T 学科户口卡。

## 诞生

1984 圣塔菲研究所（SFI）成立——物理学家 Cowan 与 Anderson 拉的局：
"复杂适应系统"（CAS，Holland 1992 命名）为纲领。三大早期支柱：
复杂网络（Watts-Strogatz 1998 小世界、Barabási-Albert 1999 无标度）、
幂律与标度（West/Brown/Enquist 1997 生物标度律）、
自组织临界性（Bak-Tang-Wiesenfeld 1987 沙堆模型）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 小世界/无标度的生成机制 | ✅ 已解（WS/BA 模型——但"生成机制"欠定：多机制同现象） |
| 幂律的普遍性与机制 | 🔄 部分（多种机制竞争：优先连接/SOC/相变/乘性过程） |
| 涌现的形式定义 | 🔄 前线（因果涌现 EI/PID 竞争中——家族 01 章方向二） |
| 网络可控性（哪些节点驱动全局） | 🔄 部分（结构可控性 2011 后大量展开） |
| 复杂系统的一般理论 | ❌ 未解（"复杂系统学没有自己的 F=ma"） |

## 这支最美的一个事实

**沙堆的 1/f 歌**：缓慢加沙的沙堆，坍塌规模服从幂律——没有特征尺度，
大小坍塌同源（1/f 噪声）。**系统自组织到临界点**（SOC）：
不靠外部调参，动力学自己把系统推到最敏感的边缘——
这是"复杂性免费出现在边缘"的最小示例。

## 假设与依赖

异质主体+交互网络+非线性（缺一退化为统计物理常规问题）；
"涌现层自主性"假设（下向因果 downward causation 仍争议）。
