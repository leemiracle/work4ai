# 讲透超循环论 · 分子的自组织（GB/T 12020 三级：超循环论）

> **这支负责的问题**：生命如何从无生命的化学中自组织出来？
> 一句钉住：**超循环=互为催化剂的循环的循环——信息与功能
> 在化学反应网络中联姻的最小结构。**

## 诞生

艾根（Manfred Eigen，1967 诺贝尔化学奖，快速化学反应动力学）1971 年
在 Naturwissenschaften 发表超循环理论，1979 与 Schuster 合著
《The Hypercycle》。动机：达尔文选择需要自我复制，但自我复制
（信息）需要酶（功能），酶又需要基因（信息）——先有鸡先有蛋的
化学版。超循环是打破死锁的中间结构。

## 核心问题

| 问题 | 状态 |
|------|------|
| 超循环的选择稳定性 | ✅ 已解（准种 quasi-species 模型，艾根 1971） |
| 准种理论→病毒进化的预测 | ✅ 已解并临床化（HIV/新冠病毒的准种动力学） |
| 超循环的自私寄生者问题 | ✅ 部分已解（空间结构/ compartmentalization 抑制寄生） |
| 从超循环到最小活细胞的实验重建 | 🔄 前线（合成生物学 ongoing） |

## 这支最美的一个事实

**准种云**：病毒不是"一个基因组"而是突变体的统计云——自然选择
作用在**云的形心**（平均序列）上，而不是单个序列。
药物打击"最适序列"，云却通过突变空间"绕行"——
准种理论直接解释了抗药性的产生速度。

## 假设与依赖

开放的非平衡化学系统+催化剂网络；准种模型假设高频突变+大群体
（误差阈值：突变率超过每基因组 1/信息量，选择崩溃——
RNA 病毒基因组长度受此约束）。
