# 讲透协同学 · 序参量的役使原理（GB/T 12020 三级：协同学）

> **这支负责的问题**：为什么亿万自由度的系统相变时只剩少数变量说了算？
> 一句钉住：**协同学=相变语言的系统学推广——快变量被慢变量"役使"，
  序参量是系统相变后的"新主人"。**

## 诞生

哈肯（Hermann Haken）研究激光（1960s）：无序光→相干光的跃迁与超导、
铁磁相变用同一套数学（Ginzburg-Landau 型序参量方程）。
1973 造词 Synergetics（"协同的工作"），1977《Synergetics: An Introduction》成书。

## 核心问题

| 问题 | 状态 |
|------|------|
| 役使原理（slaving principle） | ✅ 已解（中心流形/慢流形的物理版表述） |
| 序参量方程的普适分类 | ✅ 部分已解（与突变分类对接） |
| 从数据中识别序参量 | 🔄 前线（与 SINDy/降维交叉） |
| 认知/社会系统的协同学 | 🔄 概念迁移多、严格验证少 |

## 这支最美的一个事实

**激光的民主选举**：受激辐射概率与已存在光子数成正比——大量模式
"竞选"，最先随机冒头的模式把全部能量吸走、役使所有原子与之同相。
**序参量的诞生像相变中的对称破缺：谁赢是偶然的，有人赢是必然的。**

## 假设与依赖

时间尺度分离（快慢变量）；相变类比的合法性（系统不在物理相变点时，
协同学是建模选择不是推导结果——这是它与物理的严格性差距）。
