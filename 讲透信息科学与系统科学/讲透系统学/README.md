# 讲透系统学 · 一般系统规律的科学（GB/T 12020）

> **系统学研究"多体系统的一般规律"：整体行为如何从部分交互中涌现，
> 又如何反过来支配部分。**它诞生于对还原论的抗议（贝塔朗菲），
> 在远离平衡的热力学中找到物理地基（普利高津），在相变类比中获得数学骨架（哈肯），
> 在圣塔菲学派手里变成复杂性科学。一句钉住：**整体≠部分之和——多出来的那部分，
> 就是系统学的全部研究对象。**
>
> GB/T 13745：12020（二级学科，信息科学与系统科学 120 之下）。
> 宇宙：[讲透信息科学与系统科学](../README.md)。
