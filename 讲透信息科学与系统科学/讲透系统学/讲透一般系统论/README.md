# 讲透一般系统论 · 反还原论的宣言书（GB/T 12020 三级：一般系统论）

> **这支负责的问题**：是否存在适用于一切系统的普遍规律？
> 一句钉住：**一般系统论是系统学的"宪法层"——它立法（整体有自主性质），
> 但不执法（定律的具体形式住在各支里）。**
>
> 挂靠：哲学/方法论线在仓库根 [讲透系统论](../../../讲透系统论/)（就地成员，零迁移）。

## 诞生

贝塔朗菲（von Bertalanffy）1937 年提出、1968 年《General System Theory》定本。
动机：生物学中"有机体"装不进还原论的机械框架——开放系统、动态平衡、
等级组织需要一套新语言。同代同道：维纳的控制论、香农的信息论
（"三论"并立——见 [讲透信息科学基础家族](../../讲透信息科学基础/)，待产）。

## 核心问题

| 问题 | 状态 |

## 这支最美的一个事实

**Simon 的钟表匠寓言**：两个钟表匠修同样的表，Hora 把表分成子模块组装、
Tempora 整体组装——被打断的概率指数不同，Tempora 永远修不完。
结论：**稳定性可行的复杂系统几乎必然是层级结构**——为什么细胞→器官→
生物、士兵→班→军？因为只有层级能边出错边进化。

## 假设与依赖

同构性假设（跨领域通约）；近可分解性假设（层级可分）。代价见家族 00 章 §四。
