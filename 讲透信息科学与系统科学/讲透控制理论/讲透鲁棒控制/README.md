# 讲透鲁棒控制 · 模型必然有错，设计照样要稳

> 这支负责：**不确定性的数学**——辨识给出的模型永远有误差；鲁棒控制
> 不问"平均误差"（那是随机控制的问法），问"**最坏情况下还能稳吗**"。
> GB/T 13745：12030 三级。家族：[讲透控制理论](../README.md)。

## 诞生

Zames 1981（H∞ 指标：把"灵敏度峰值的上确界"当设计目标——对最坏频段负责）；
Doyle 的 μ 综合（1982-85）处理结构化不确定性；1990s LMI 方法（Boyd 等）
把整个领域折成凸规划。

## 核心问题（已解决/未解决）

| 问题 | 状态 |
|---|---|
| 小增益定理：‖L‖<1 ⟹ 闭环稳（任意不确定性） | ✅ 已解——一个不等式吃掉所有摄动 |
| H∞ 综合=解 Riccati/LMIs（凸，可算） | ✅ 已解 |
| μ 综合（结构化不确定性的充要条件） | 🔄 上界可算，精确 μ 为 NP-hard |
| 非线性鲁棒（增益调度/LPV） | 🔄 工程成熟，理论局部 |
| 学习模型的鲁棒证书 | ❌ 前线（与神经证书合流，家族 01 章） |

**这支最美的一个事实**：小增益定理——只要回路总增益 <1，**无论不确定性
藏在哪、是什么形状**，闭环必稳。一个不等式兑换无限种未知，这是"最坏情况
思维"能买到的东西的上限样本。

## 假设与依赖

不确定性有界且增益可包络；性能用最坏指标度量（付出：保守——为没发生的
坏情况花设计预算，"鲁棒-性能"权衡是本支的永久税）。
