# 讲透大系统理论 · 当系统大到没人看得见全局

> 这支负责：**大规模互联系统**（电网、交通网、供应链、多机器人）的控制——
> 当"集中式控制器"在信息与计算上不可行时，控制理论怎么办。
> GB/T 13745：12030 三级。家族：[讲透控制理论](../README.md)。

## 诞生

1960s-70s：递阶控制（Mesarovic）与分解-协调（Dantzig-Wolfe 分解的思想移植）
应电网经济调度而生；Wang & Davison 1973 的分散固定模态定理给出这门学科
最深的负面结果。80s 后与[系统学](../../讲透系统学/)的复杂系统线合流。

## 核心问题（已解决/未解决）

| 问题 | 状态 |
|---|---|
| 分解-协调：子问题迭代收敛到全局解 | ✅ 已解（凸/可分情形） |
| 分散固定模态定理：何时分散控制原理上不可稳 | ✅ 已解（判定算法存在） |
| 信息结构理论（谁看见什么信号决定能控什么） | 🔄 部分（Witsenhausen 反例等遗留） |
| 大规模网络化控制系统（NCS）的时延/丢包综合 | ❌ 前线 |

**这支最美的一个事实**：存在能控的系统，把信息拆给两个分散控制器后**原理上
不可稳**——能控性在信息受限时蒸发；动态不是全部，**信息结构也是物理**。

## 假设与依赖

子系统能分解+耦合弱（稀疏互联）；通信拓扑已知。上游：状态空间理论（家族 00 章）、
图论（[讲透数学/讲透图](../../../讲透数学/讲透图/)）。
