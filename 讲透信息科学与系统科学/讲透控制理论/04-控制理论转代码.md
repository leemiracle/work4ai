# 04 · 控制理论转代码：从 Riccati 到毫秒级闭环

> **本章回答五问之五（本支：讲透控制理论）。** 控制理论是**可机械化程度
> 极高**的数学学科（工厂侧全是算法）；它的转代码问题独特在**实时性**——
> 控制律必须在物理节拍内算完，否则数学再美也是事故。
> 三件套：可机械化边界 / 代码走廊 / 工程师落点。

---

## 一、可机械化边界

| 任务 | 可机械化程度 | 为什么 |
|---|---|---|
| LTI 稳定性/裕度分析 | ✅ 全自动 | Routh/极点/LMI 全是多项式算法 |
| LQR/Kalman/H∞ 设计 | ✅ 全自动 | Riccati/LMIs=凸，数值软件成熟 |
| MPC 在线求解 | ✅ 但有实时预算 | 每步一个 QP——毫秒级代码生成技术为此而生 |
| PID 整定 | ◐ 半自动 | 规则给初值，现场闭环整定靠人（内模原理只给结构） |
| Lyapunov 构造（非线性） | ❌→◐ | 画室（03 章）；SOS/神经证书正在半自动化 |
| 大系统分散结构设计 | ❌ | 信息结构组合爆炸，无通用算法 |
| 学习策略的安全证书 | ◐ 前线 | 证书可验（验证器），但策略本身黑箱 |

**边界判据一句话**：**凸则可机械化，非凸则找证书，无证书则靠试错**——
这是本学科转代码的第一宪法。

## 二、代码走廊（问题→算法→库）

| 问题类 | 算法 | Python/工程栈 |
|---|---|---|
| 系统建模/频域分析 | 状态空间/传递函数 | `python-control`（MATLAB control 的开源对位） |
| LQR/LQG/极点配置 | Riccati/Ackermann | `scipy.linalg.solve_continuous_are`；本家族实验即最小样例 |
| Kalman 滤波/状态估计 | 递推贝叶斯 | filterpy；SLAM 栈（机器人宇宙） |
| MPC | QP/SQP 逐时步 | CasADi（建模）、ACADOS/do-mpc（代码生成+实时） |
| 鲁棒/LPV 综合 | LMIs | Julia Jump/Mosek、PyLMI |
| 神经证书 | 学习+验证 |jax/casadi+验证器（2021-2026 前线，无标准栈） |
| 离散事件/逻辑控制 | 监督控制理论 | TCT 类工具（小众） |
| 机器人全身控制 | QP 任务优先级 | OSC/WBC 栈、[讲透机器人](../../讲透机器人/) |

> **✨ 美之时刻（极简）**：PID 的三行实现（P、I、D 各一项）统治了世界工厂的
> 九成回路——**史上部署最广的数学代码**可能就是这三行。
> **亲历**：对单变量回路（温度/流量）它足够；对倒立摆（本家族实验第 4 段）
> 它**原理上**稳不住——单环的结构极限给了"多变量革命"一个数值现场。

## 三、工程师落点（性能工程视角）

1. **实时即正确性**：控制律晚 10ms 算完 = 数学上的另一个系统。MPC 的
   代码生成器（ACADOS）把 QP 求解编译成无堆分配的定点 C——**编译期优化
   换物理世界稳定性**，这是性能工程最硬核的场景之一
2. **数值即裕度**：Riccati 病态问题（A 强不稳定）下双精度误差能吃掉你的
   相位裕度；嵌入式定点 PID 的量化效应会激发极限环——**有限字长是控制
   工程的一部分**（呼应[讲透数值线代](../../讲透数学/讲透数值线代/) 的浮点宪法）
3. **大系统的分布式账本**：电网/交通的分散控制把"通信延迟"写进控制律——
   控制器与网络协议共同设计（cyber-physical 的本义）
4. **学习控制的部署形态**：策略推理（ms 级神经网络前向）+ 证书检查器
   （区间算术/验证器）双进程——**学习的部分要快，验证的部分要绝对可信**，
   两种性能要求并存是新的工程形态

## 四、最小走通：本家族实验怎么用

[experiments/cart_pole_lqr_pid.py](experiments/cart_pole_lqr_pid.py) 是走廊的
微缩：`numpy` 造动力学 → `solve_continuous_are` 造控制律 → 自写 RK4 仿真 →
断言当测试（含单环结构极限与分离原理两课）。把它换成 CasADi + 约束，就迈进
MPC 走廊——**200 行之内，四条走廊的入口全路过**。

## ✍️ 练习

1. 把实验的 LQR 仿真步长放大 10 倍直到发散——你亲测了"离散化背刺连续设计"
   （采样控制的第一课）。
2. 实验第 4 段只扫了四组增益。问：θ 单环不可稳的根因是通道零点还是状态耦合？
   （提示：算 θ 通道的不变零点，看有没有右半平面的。）
3. 思考：为什么 MPC 的在线 QP 要代码生成，而 LQR 不用？（提示：LQR 的解在
   离线就解完了——增益是常数。）
