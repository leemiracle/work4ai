# 讲透状态估计 · 从半个状态重建全部现实

> 这支负责：**看不见的状态怎么办**——传感器只给噪声污染的部分观测
> （甚至只有位置没有速度），估计器要从"半个状态"重建全部。
> GB/T 13745：12030 三级。家族：[讲透控制理论](../README.md)。

## 诞生

Kalman 1960（《A New Approach to Linear Filtering and Prediction Problems》，
NASA 阿波罗导航计算机的第一生产现场）；Luenberger 1964 观测器给确定性对偶。
五十年来导航/SLAM/量化金融全在它的延长线上。

## 核心问题（已解决/未解决）

| 问题 | 状态 |
|---|---|
| Kalman 滤波=线性高斯下的贝叶斯最优递推估计 | ✅ 已解 |
| 能观性 ⟺ 估计误差动力学可稳（对偶于控制） | ✅ 已解 |
| 扩展 KF（EKF）/无迹 KF（UKF）用于非线性 | 🔄 工程成熟，理论保证局部 |
| 非线性全局最优滤波（维度诅咒） | ❌ 未解——粒子滤波只是采样近似 |
| 多传感器融合与数据关联（SLAM 核心） | 🔄 前线 |

**这支最美的一个事实**：Kalman 滤波把贝叶斯推断做成**递推**——不需要存储
任何历史数据，只维护"当前信念"（均值+方差）即可最优更新。整部历史压缩成
两个矩阵，这是状态空间结构送给概率论的礼物。

## 假设与依赖

(C,A) 可检测（能观性是估计的前提——本家族实验第 5 段的"只测 θ 不可观"
就是活教具）；噪声近似高斯白。上游：概率论、Riccati 对偶（家族 03 章）。
