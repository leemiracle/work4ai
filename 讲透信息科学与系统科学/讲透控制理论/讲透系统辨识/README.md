# 讲透系统辨识 · 从数据反推模型

> 这支负责：**模型的来路**——控制理论假设 $\dot x=Ax+Bu$，但 A、B 从哪来？
> 辨识回答：从输入输出数据里把它们"反解"出来。GB/T 13745：12030 三级。
> 家族：[讲透控制理论](../README.md)。

## 诞生

Åström 1965（最小二乘进动力学）；Ljung《System Identification: Theory for
the User》(1987) 立下统计视角的完整体系——辨识从此是"带结构的统计学习"
（比机器学习叫"学习"早了二十年）。

## 核心问题（已解决/未解决）

| 问题 | 状态 |
|---|---|
| 最小二乘/预测误差法的一致性与渐近理论 | ✅ 已解（Ljung 体系） |
| 持续激励（PE）条件：数据何时"够用" | ✅ 已解——单频正弦测不出系统全貌 |
| 模型阶数选择（AIC/BIC/交叉验证） | ✅ 已解（偏差-方差权衡） |
| 闭环辨识（反馈下的数据不能直接用） | 🔄 部分 |
| 非线性/黑箱结构的可辨识性 | ❌ 前线（与深度学习可辨识性交叉） |

**这支最美的一个事实**：持续激励条件说"输入必须充分多样化"——**单频正弦
无论多久都测不出系统全貌**（一个频率只照亮传递函数曲线上一个点）。
数据量替代不了数据多样性。

## 假设与依赖

模型结构类先定（线性/Box-Jenkins/状态空间）；数据来自充分激励的实验。
上游：概率统计（[讲透数学/讲透统计学习理论](../../../讲透数学/讲透统计学习理论/)）、
最小二乘（数值线代）。
