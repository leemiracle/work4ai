# 讲透控制理论 · 反馈的科学

> 控制理论：**让动力系统自己稳定到目标**的科学——测量误差、计算动作、修正行为，
> 循环往复。它的全部戏剧在于：**开环不稳定的系统，加上反馈就稳了**
> （倒立摆是它的图腾）。GB/T 13745：12030（二级学科）。
>
> 家族：[讲透信息科学与系统科学](../README.md) · 四支：[大系统理论](讲透大系统理论/)·
> [系统辨识](讲透系统辨识/)·[状态估计](讲透状态估计/)·[鲁棒控制](讲透鲁棒控制/)

## 本质一句话

用**反馈**对抗不确定性：你不需要知道系统的全部，只需要持续看到误差并持续纠正。

## 怎么产生的

1. **瓦特离心调速器（1788）**：蒸汽机转速的机械反馈——工业革命的自驾系统，
   但没人知道它何时会振荡失稳
2. **Maxwell《论调速器》（1868）**：线性化 + 特征根判稳——第一篇控制理论论文，
   把"机器发脾气"变成"方程的根在左半平面"
3. **Kalman 1960**：状态空间 + 能控性/能观性 + Kalman 滤波 + LQR——一年之内
   重写了整个学科的控制权（时域语言取代频域），史称"Kalman 革命"

## 核心问题清单（详见 00 章）

| 里程碑 | 年代 | 一句意义 |
|---|---|---|
| Routh–Hurwitz 判据 | 1877/1895 | 不解特征方程就能判稳——代数判据 |
| Nyquist 判据 | 1932 | 从**开环**响应读**闭环**稳定性——负反馈设计的第一宪法 |
| Kalman 滤波与对偶性 | 1960 | 估计与控制是一枚硬币（LQR 与 KF 解同一个 Riccati 方程） |
| 分离原理 | 1960s | 状态不可测？先估计再控制，两步设计=一步最优（线性情形居然成立） |
| H∞ 理论（Zames） | 1981 | 模型**必然**有错——为"最坏误差"设计，而非"平均误差" |
| MPC 工业（1978→） | — | 把控制变成每步解优化——约束进去，最优出来 |

悬而未决：非线性 Lyapunov 函数的系统构造法；学习控制的安全证书（正是 2021-2026 前线）。
