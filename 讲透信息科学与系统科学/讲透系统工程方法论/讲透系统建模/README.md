# 讲透系统建模 · 抽象的纪律

> **定位**:这支负责方法论的第一动作——**把世界变成模型**:保留什么、扔掉什么、怎么知道模型没骗你。GB/T 12050 三级"系统建模"的正主。
> GB/T 13745:12050 三级·系统建模(2026-09-07 立宪)。

## 诞生

控制论的状态方程(1950s)→ Forrester 系统动力学(1961,《工业动力学》,库存-流图)→ Zeigler 建模与仿真形式理论(1976)→ MBSE/SysML(2007-)。

## 核心问题(3-5 条)

| 问题 | 状态 |
|------|------|
| 模型与系统的关系能否形式化 | ✅ Zeigler:模型=系统的同态像(形式化定义) |
| 多分辨率模型如何共存 | 🔄 前线(作战仿真/数字孪生的核心难题) |
| 模型有效性如何验证 | 🔄 VV&A(校核/验证/确认)体制,无定理级判据 |
| 简单模型为何常胜复杂模型 | ✅ 定性:-box《系统之美》原理;奥卡姆式偏好 |

**这支最美的一个事实**:Forrester 的世界模型(1972《增长的极限》)用五个变量(人口/资源/污染/资本/粮食)推演全球百年——**激进的简化不是模型的弱点,是模型的表达力**:能算的粗模型永远胜过不能算的精细模型。

## 假设与依赖

模型目的先于模型形式(同一系统为不同目的建不同模型——"所有模型都是错的,但有些是有用的"Box);状态可选定(可观测性);参数可辨识。前置:家族层 [`../00-体系结构.md`](../00-体系结构.md)。
