# 🚀 第 5 幕 · 应用：学习型系统的实践

## 四层学习的工业实践

### L1 · ICL（上下文学习）
- **代表**：所有 LLM 的默认（GPT-4 few-shot）
- **用在哪**：即时任务、零成本适应
- **局限**：关掉就忘

### L2 · 经验回写（Reflexion / Memory）
- **代表**：Reflexion（Shinn 2023）、mem0、Voyager（Minecraft 自写技能库）
- **用在哪**：跨会话积累、不改权重的「学习」
- **局限**：受检索精度限制；反思可能错

### L3 · 从反馈学（RLHF / RLAIF / Constitutional AI）
- **代表**：ChatGPT 的 RLHF、Anthropic Constitutional AI
- **用在哪**：对齐、能力内化进权重
- **局限**：贵、慢、reward hacking

### L4 · 持续微调 / Self-play
- **代表**：AlphaGo（自我对弈极致）、STaR、Self-Rewarding LM、AlphaProof、Sakana AI evolutionary
- **用在哪**：理论无限自我提升
- **局限**：**Model Collapse（核心威胁）**

## AlphaProof 的范式（最值得学）

DeepMind 2024，用 Lean 形式化证明器 + self-play，达到奥数银牌。

**为什么没 collapse**：Lean 证明器是**永不疲倦的外部真相裁判**。模型可以放心自我博弈——每次都被真实数学验证。

**启示**：**安全的 L4 = self-play + 形式化外部信号**。这是通往可持续自我进化的范式。

## 选型决策树

```
你的 Agent 需要学习吗?
│
├─ 单次任务 → L1 ICL (塞 prompt)
│
├─ 跨会话积累, 不改模型 → L2 经验回写 (Reflexion + 记忆)
│
├─ 能力要内化, 有反馈数据 → L3 RLHF/RLAIF
│
└─ 要自我进化 → L4 self-play
   │
   ├─ 有形式化领域(数学/代码/游戏) → AlphaProof 式 (安全)
   └─ 无形式化领域(开放文本) → 危险! Model Collapse 风险
```

## 五条生产铁律

1. **可持续进化必须开放**——封闭 self-play 必然 Model Collapse。
2. **外部信号是天花板**——没有外部真相，self-improve 有硬上限。
3. **L4 + 形式化 verifier = 安全**（AlphaProof 范式）。
4. **L4 + 开放文本 = 危险**——必须混真实人类数据。
5. **看到「无限自我提升」宣传，问「外部信号在哪」**。
