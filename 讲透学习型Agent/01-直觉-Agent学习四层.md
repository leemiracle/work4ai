# 📈 第 1 幕 · 直觉：Agent 学习的四层

## ⚠️ 先澄清：这是「Agent 怎么学」，不是「人怎么学」

work4ai 已有 `费曼学习法/` `故事化学习法/` `cs61a-learning/`——讲**人**怎么学。本宇宙讲 **Agent** 怎么自己学。同一个词「学习」，主体完全不同，别混淆。

---

## 从一个让你困惑的事实开始

你用 GPT-4 帮你写了 100 次代码。第 101 次时，它**比第 1 次更聪明了吗**？

直觉答案：应该更聪明——它见过了你 100 次的代码风格、bug 模式、偏好。

现实答案：**完全没有**。它的权重是冻结的。每一次对话，它都从同一个起点开始。你用的 100 次，对它来说是 100 个独立宇宙。

这就是当前 LLM 的尴尬：**它有世界级的「先天能力」（预训练），但零「后天经验」（不随使用进化）**。

**学习型 Agent 工程，就是给 LLM 装上「后天学习」能力**。

---

## 学习的四层（本宇宙的核心分类）

学习不是一件事，是**四个层级**，时间尺度和机制完全不同：

```
L1 · 上下文学习 ICL       (秒级, 不改权重)
   ↓
L2 · 经验回写             (跨会话, 不改权重)
   ↓
L3 · 从反馈学             (训练, 改权重, 有外部反馈)
   ↓
L4 · 持续微调 / self-play (多代, 改权重, 自我生成数据)
```

每一层更强，但也更危险。最后一层（L4）是 AlphaGo 的圣杯，也是 Model Collapse 的悬崖。

### L1 · 上下文学习 ICL（In-Context Learning）

**机制**：把例子塞进 prompt，模型「现场」学会这个模式。

```python
# prompt 里:
"翻译: cat → 猫
 翻译: dog → 狗
 翻译: bird → ?"
# 模型输出: 鸟
```

**特点**：
- 时间尺度：单次推理内
- 改权重：**否**（权重冻结）
- 优点：零成本、即时、无训练
- 缺点：**关掉就忘**；例子多了 prompt 爆

**代表**：GPT-3 的 few-shot（Brown 2020）。这是当前所有 LLM 的默认学习方式。

### L2 · 经验回写（Memory / Reflexion）

**机制**：把上一次的经验（成功/失败/反思）**写进外部记忆**，下次检索出来用。

```
任务 1：写代码 → 失败 → 反思「忘了处理 None」→ 存入记忆
任务 2：写类似代码 → 检索到「处理 None」 → 这次写对
```

**特点**：
- 时间尺度：跨会话
- 改权重：**否**（仍是 ICL，但 context 来自记忆库）
- 优点：渐进积累，不需训练
- 缺点：受限于检索精度；记忆会污染（见 `讲透记忆/04`）

**代表**：Reflexion（Shinn 2023）、mem0、Voyager（Minecraft agent 自己写技能库）。**这是「不改权重的学习」的天花板**。

### L3 · 从反馈学（RLHF / RLAIF / Constitutional AI）

**机制**：用人类或 AI 的反馈训练一个奖励模型，再用 RL 优化 LLM 的策略。

```
LLM 生成多个回答
   ↓
人类（或 AI）排序哪个好
   ↓
训练 reward model
   ↓
用 PPO/GRPO 优化 LLM 跟着 reward 走
```

**特点**：
- 时间尺度：一次训练（数天-数周）
- 改权重：**是**
- 反馈来源：**外部**（人类或独立 AI）
- 优点：能力真正内化进权重
- 缺点：贵、慢、奖励黑客风险

**代表**：ChatGPT 的 RLHF、Constitutional AI（Anthropic）、RLAIF。这是当前主流对齐方法。

### L4 · 持续微调 / Self-play（自我生成数据训练自己）

**机制**：模型**自己生成训练数据，自己训自己**。

几种变体：
- **STaR**（Zelikman 2022）：模型生成 reasoning，用对的当训练数据，迭代
- **Self-Rewarding LM**（Yuan 2024）：模型当自己的 reward model
- **AlphaGo self-play**：模型自己和自己下棋，赢的强化
- **V-STaR / RFT**：生成多个候选，用 verifier 筛好的训练

**特点**：
- 时间尺度：多代演化
- 改权重：**是**
- 反馈来源：**自我**（或环境，如围棋规则）
- 优点：**理论上无限自我提升**
- 缺点：**Model Collapse 风险**（见下节）

**代表**：AlphaGo（自我对弈的极致）、AlphaProof（Lean 形式化防止 collapse）、STaR。

---

## Model Collapse：自我改进的悬崖

2024 年，Shumailov 等人在 *Nature* 上钉死了一个让所有 L4 方案头疼的事实：

> **当一个模型持续在自己（或同类）的输出上训练，几代之后会不可逆退化。** 尾部分布消失，输出越来越平庸，最终坍缩到少数模式。

直觉解释：
- 真实数据有**长尾**（罕见但重要的样本）
- 模型生成时倾向高频模式，**丢掉长尾**
- 下一代在「丢掉长尾的数据」上训练，丢得更多
- 几代后，长尾彻底消失，模型只会输出最平庸的东西

**这是「AI 吃自己尾巴会中毒」的数学证明**。

为什么 AlphaGo 没 collapse？因为围棋有**真实世界的信号**（胜负规则）不断注入负熵。纯 LLM 的 self-play 如果没有外部真相锚定，必然退化。

**关键洞察**：L4 的天花板 = **缺乏外部负熵**。Schrödinger 说生命以负熵为食，Agent 也一样。

---

## 四层的「外部信号」轴

把四层沿「**依赖外部信号的程度**」排开，会看到一条清晰的安全阶梯：

| 层 | 外部信号 | Model Collapse 风险 |
|---|---|---|
| L1 ICL | 用户每次输入 | 无（不改权重）|
| L2 经验回写 | 用户反馈 + 真实任务 | 无（不改权重）|
| L3 RLHF | 人类/AI 反馈 | 低（有独立 reward 来源）|
| L4 self-play | **无（纯自我）** | **高（这是 collapse 的温床）** |

**结论**：**可持续进化的 Agent，必须始终保留与真实世界的信号通道**。完全封闭的 self-improve 违背耗散结构原理，必然退化。这是 `故事原语/02-熵论辩证` 的直接推论——**开放系统才能维持有序**。

## Reflexion：L2 的典范（剧透第 3 幕）

L2 里最优雅的设计是 Reflexion（Shinn 2023）：

```
while not solved:
    1. Agent 尝试任务
    2. 失败 → 用 LLM 自我反思「为什么失败」
    3. 把反思存入记忆（自然语言形式）
    4. 下次尝试前，检索相关反思塞进 prompt
```

它的魔力：**用自然语言当「梯度」**。传统 RL 用数值 reward 更新权重；Reflexion 用语言反思更新 context。后者便宜得多，且可解释。

**结果**：在编程/推理任务上，Reflexion 让 GPT-4 多次尝试后成功率显著上升——**不改权重，却「越用越聪明」**。

第 3 幕我们会用 numpy 实现一个简化 Reflexion agent，跑出成功率曲线。

## 2024-2026 学习型 Agent 的前沿

| 工作 | 层级 | 突破 |
|---|---|---|
| **STaR / V-STaR** (2022-2024) | L4 | 自我生成 reasoning 数据，迭代提升 |
| **Self-Rewarding LM** (Yuan 2024) | L4 | 模型当自己的 reward model |
| **AlphaProof** (DeepMind 2024) | L4 | Lean 形式化信号防止 collapse，达奥数银牌 |
| **Sakana AI evolutionary merging** (2024) | L4 | 模型「交配变异」演化 |
| **Constitutional AI** (Anthropic) | L3 | AI 自己当反馈者（RLAIF）|
| **OpenAI o1 / o3** (2024-2025) | L4-ish | test-time 推理自我改进（争议归属）|

**AlphaProof 最值得学**：它证明了「**L4 + 形式化外部信号 = 既能自我进化又不 collapse**」。Lean 证明器充当永不疲倦的「真相裁判」，让模型可以放心自我博弈。这可能是通往安全 L4 的范式。

## 一个判据：你的 Agent 在哪一层？

给你手上的 Agent 系统，判断它在哪层：

- **关掉记忆/数据库后，它退化回基线吗？** 是→L1，否→至少 L2
- **它的策略会随训练数据更新吗？** 否→L1/L2，是→L3/L4
- **训练数据里有它自己生成的内容吗？** 否→L3，是→L4
- **有外部真相锚定吗？** 有→安全的 L4，无→危险的 L4

这个判据帮你快速定位一个系统的「学习深度」和「collapse 风险」。
