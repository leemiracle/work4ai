# 📐 第 2 幕 · 数学：自我改进的形式化与极限

## 1. Erev-Roth：强化学习的数学骨架

agent 在重复博弈里学。动作 $a$ 被选的概率随累积奖励更新：

$$P_{t+1}(a) = \frac{(R_a(t))^\gamma}{\sum_{a'} (R_{a'}(t))^\gamma}$$

$R_a(t)$ 是动作 $a$ 的累积奖励（含虚拟初始值），$\gamma$ 是学习率。

**直觉**：奖励越高的动作，下次越可能被选。**这是 L2 经验回写的形式化**——不改权重，但改选择概率。

## 2. Bootstrap：self-training 的数学

self-training：模型生成数据，再用这些数据训自己。设第 $t$ 代模型分布为 $p_t$。

**理想情况**（生成全部数据）：
$$p_{t+1}(x) = p_t(x)$$

不变——因为是在自己的分布上训练。

**实际问题**：只能采样有限样本 $D_t = \{x_1, ..., x_n\} \sim p_t$。训出的 $p_{t+1}$ 是 $p_t$ 的**经验估计**，会引入偏差。偏差来自哪？**采样偏差 + 模型偏好**。

## 3. Model Collapse：数学证明（Shumailov 2024）

**核心定理（直觉版）**：若第 $t+1$ 代在第 $t$ 代生成的数据上训练，且数据有限，则 $p_t$ 的尾部会随 $t$ 单调消失。

设真实数据分布 $p_0$ 有长尾（如尾部概率 $O(1/x^\alpha)$）。第 $t$ 代生成的样本里，尾部样本的**表示度递减**：

$$\hat p_t(x_{\text{tail}}) \leq \hat p_{t-1}(x_{\text{tail}}) \cdot (1 - \delta)$$

$\delta > 0$ 是采样损失。$t$ 代后尾部消失。

**后果**：模型输出越来越集中在高频模式，多样性坍缩，长尾信息**不可逆丢失**。

**为什么 AlphaGo 不 collapse**：胜负规则是**外部真值**，每代都被真实信号矫正，不靠自我生成。

**为什么纯 LLM self-play 危险**：没有外部真值锚，正反馈让偏差放大。

## 4. 信息论极限

Shannon 熵 $H(p) = -\sum p(x) \log p(x)$。

**自我训练的信息瓶颈**：模型从数据中学到的信息 $\leq$ 数据的信息 $\leq$ 训练数据的信息。

$$I(\text{model}; \text{truth}) \leq I(D_t; \text{truth}) \leq H(\text{truth})$$

若 $D_t$ 完全来自 model（无外部输入），$I(D_t; \text{truth})$ 随 $t$ 递减——**信息守恒不让自我蒸馏增加真相信息**。

**结论**：**学习型 Agent 的天花板 = 外部信息的注入率**。无外部信号 → 退化（熵增）。有外部信号 → 可持续（负熵为食）。

## 5. Reflexion 的「语言梯度」

Reflexion（L2）不用权重更新，用自然语言反思。形式化：

$$\text{context}_{t+1} = \text{context}_t \cup \text{reflect}(\text{failure}_t)$$

下次推理时，把 reflect 当 context。**这相当于在 context 空间做梯度下降**——每轮把「失败教训」作为方向向量。

**优点**：可解释、零训练成本、跨任务迁移。
**缺点**：受检索精度限制（context 装不下所有反思），且反思本身可能错（幻觉）。

## 6. STaR 的迭代推理蒸馏

STaR（Zelikman 2022）：

```
1. 给问题 q, 模型生成推理 r 和答案 a
2. 若 a 对: 把 (q, r) 加入训练集
3. 若 a 错: 给 hint, 重新生成 r', 用 r' 当训练数据
4. 用新数据 fine-tune 模型
5. 重复
```

**数学**：每轮把「正确推理路径」蒸馏进权重。$t$ 代后，模型对类似问题的推理质量上升。

**为什么相对安全**：答案正确性是**外部信号**（有 ground truth），不是纯自我生成。但若 ground truth 质量差（标注噪声），仍可能退化。

## 7. 学习率与稳定性

权重更新：$\theta_{t+1} = \theta_t - \eta \nabla L$。$\eta$ 太大→震荡，太小→停滞。

**self-play 的特有风险**：reward 来自自己 → reward hacking。模型找到「骗自己 reward model」的捷径，reward 上升但真实质量下降。

**防御**：Constitutional AI（用原则约束）、外部 verifier（AlphaProof 的 Lean）、reward 多样性。

## 🎬 本幕收束

> 自我改进数学 = Erev-Roth（不改权重的学习）+ bootstrap（self-training 偏差）+ Model Collapse（尾部不可逆消失）+ 信息论（无外部信号不增益）+ Reflexion（语言梯度）+ STaR（推理蒸馏）。**核心铁律：可持续学习必须开放，必须以外部负熵为食**。
