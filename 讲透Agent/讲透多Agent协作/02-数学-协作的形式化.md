# 📐 第 2 幕 · 数学：协作的形式化

## 1. 多智能体 MDP（马尔可夫博弈）

单 agent MDP 是 $(S, A, P, R, \gamma)$。$N$ 个 agent 推广为**马尔可夫博弈**：

$$(S, A_1, ..., A_N, P, R_1, ..., R_N, \gamma)$$

转移函数依赖**所有 agent 的联合动作**：

$$P(s' \mid s, a_1, ..., a_N)$$

每个 agent 有自己的奖励 $R_i$。这就是**耦合**的来源——我的最优策略取决于你的动作。

**协作 vs 对抗**：
- 协作：所有 $R_i$ 相同（共同目标）
- 对抗：$\sum R_i = 0$（零和）
- 混合：一般和（贸易、博弈）

## 2. 通信的信息论代价

agent $i$ 给 $j$ 发消息 $m$。消息的信息量 = 互信息：

$$I(X_i; M) = H(X_i) - H(X_i \mid M)$$

**协调收益** vs **通信成本**的权衡：

$$\text{Net Gain} = \underbrace{\Delta V_{\text{协调}}}_{\text{价值提升}} - \underbrace{C \cdot I}_{\text{通信代价}}$$

当 agent 数 $N$ 增大，理论上可传消息量 $O(N^2)$，但带宽有限——**必须选择性通信**。这就是为什么真正大规模的系统都用**分层/聚合**而非全连接。

## 3. Contract Net Protocol（合同网）

经典的多 agent 任务分配协议（Smith 1980）：

1. **manager** 广播任务
2. 多个 **contractor** 报价（能力 + 成本）
3. manager 选最优 contractor，签合同
4. contractor 执行，回报结果

数学上是个**拍卖**。每个 contractor 用 Luce 选择规则报价：

$$P(\text{bid } b_i) = \frac{\exp(U_i(b_i)/\tau)}{\sum_b \exp(U_i(b)/\tau)}$$

$U_i$ 是 agent $i$ 的效用，$\tau$ 是探索温度。

## 4. 共识算法：Raft/Paxos 的多 agent 版

当多个 agent 需要对**同一状态**达成一致（如共享世界状态），用共识算法。

Raft 的核心：leader 选举 + log 复制 + 多数派确认。数学保证：

> **只要多数派（$> N/2$）可用，系统就一致。** 容忍 $< N/2$ 的故障。

多 agent 系统的「共享黑板」本质是个** replicated state machine**——所有 agent 对同一 log 达成共识。

## 5. 通信开销的下界

Brooks 定律 AI 版的数学化：$N$ 个 agent 的协调成本 $\propto N^2$。但**有解**：

- **分层**：把 $N$ 个 agent 组成 $\sqrt{N}$ 个小组，每组 $\sqrt{N}$ 个，协调成本降到 $O(N)$
- **市场**：agent 只和「价格」交互，无需两两通信（Hayek 的信息效率）
- **stigmergy**：通过环境间接协调（见 `讲透群体智能/`），零直接通信

**这解释了为什么大规模系统必然分层或市场化**——全连接撑不住。

## 6. Debate 的可靠性增益

两个 agent 辩论，judge 裁决。设单 agent 答对率 $p$。辩论后：

$$P(\text{correct}) = p^2 + 2p(1-p) \cdot q$$

$q$ 是「一个对一个错时 judge 选对」的概率。当 $q > 0.5$，debate 严格优于单 agent。

**但**：当两 agent **相关**（同一基模型，同幻觉），$q$ 接近 0.5，增益消失。**debate 要用多样化的 agent 才有效**——这是工程上的关键。

## 🎬 本幕收束

> 协作数学 = 马尔可夫博弈（耦合）+ 信息论（通信代价）+ 共识（一致性）+ 拍卖（分配）。核心权衡永远是：**协调收益 vs 通信开销**。
