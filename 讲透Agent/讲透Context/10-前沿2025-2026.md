# 10 · 前沿 2025-2026：从技巧到理论——六线综述

> 讲透Context 第 10 章 ★用户重点 | 素材全部一手核实（`papers.md` §一§二§五）

2025 下半年到 2026，context engineering 完成了从"博客技巧集"到"有定理的学科"的惊险一跃。六条线按"离生产近→离理论近"排：

## 线 1：官方方法论定型（Anthropic，2025-11）

《Effective Context Engineering for AI Agents》把领域定义收窄成一句可操作的话：
> "find the **smallest set of high-signal tokens** that maximizes the likelihood of your desired outcome"——最小高信号 token 集。

配套长时程三技术：**compaction / structured note-taking / sub-agent**（本单元 Ch05/07/08 逐个实证过）。同期的 harness 文章补了两个概念：**compaction 提示词两步调法**（先最大化 recall 再修 precision）；**context anxiety**（模型接近窗口上限会提前草草收工——心理学的窗口压力）。

## 线 2：系统化综述（2507.13334，1400+ 篇）

Mei et al. 的 survey 给出领域三组件：**R&G（检索与生成）/ Processing（压缩、分层）/ Management（记忆、遗忘）**；四实现：RAG / Memory / Tool-Integrated / Multi-Agent。核心 gap 一句话：**"理解长输入强 vs 生成长输出弱"的不对称**——模型读得懂 200K，写不满 8K（本单元 E5 的细节丢失、E8 的 brevity bias 都是这条不对称的行为学证据）。

## 线 3：Agentic 化——上下文自己进化（ACE / ACON）

- **ACE**（2510.04618，Stanford/SambaNova/UCB）：Generator/Reflector/Curator 三分工，把"不断改进的上下文"本身当训练对象——**delta 更新**防"context collapse"（反复摘要导致的语义漂移），+10.6% agent 基准，开源版追平生产级 agent；
- **ACON**（2510.00615）：同时压**环境观察**与**交互历史**两类输入（此前 compaction 只管历史，工具返回值的膨胀没人管）；
- **ContextCurator**（2604.11462）/**AdaCoM**（2605.30785）：RL 学"选什么进窗口"——上下文策展从规则走向学习。

读法：这条线是"上下文的 fine-tuning"——改窗口不改权重，成本比训练低一个量级，效果介于 prompt 与微调之间。

## 线 4：会话即环境（Scroll，2608.21690）

把会话重构成**可执行环境**：append-only Event Log + 持久 Python kernel，eviction ≠ 删除（被挤出窗口的内容仍可寻址回溯）。LOCA 基准上超最佳系统 **37.4pp**。这是"窗口是唯一状态载体"这一前提的正面爆破——与讲透Graph 的图记忆（窗口外持久层）殊途同归：**状态要么进环境，要么进图，总之别全塞窗口**。

## 线 5：理论化——通信复杂度下场（2608.01326）

Context Compaction Theory 把 compaction 形式化为**单向通信问题**：

- **Thm 1**：Generation（任意摘要）等价于单向通信复杂度——随机化摘要的期望误差有信息论下界；
- **Thm 3**：Selection（选子集）比 Generation 多花 $\Theta(\log n)$ 预算——**压缩税是定理不是经验**；
- 实测打脸环节：Anthropic compaction endpoint 在 set membership 上接近随机猜，**输给同尺寸 Bloom filter**（本单元 E6 本地复现：Bloom 97.9% vs glm 摘要超预算仍输）。

读法：这是本单元 Ch06 的骨架。它宣告 compaction 从手艺变成编码论问题——1970 年的随机化数据结构（Bloom filter）在 2026 年的 agent 窗口里复活。

## 线 6：记忆与上下文合流（2512.13564 / 2602.06052）

45 位作者的记忆综述给出分工名言："**context engineering 把窗口当资源优化，agent memory 管窗口之外的知识演化**"。Forms（token/parametric/latent）× Functions（factual/experiential/working）× Dynamics 的三维分类；TMLR 后续把 memory 定位成"自进化的基座"（RL-learned curation；skills = 可移植的外显记忆）。这条线通往讲透Graph——**记忆图是窗口外的 context engineering**。

## 六线合一张图

```
生产技巧(线1) ──→ 系统化(线2) ──→ 自动化/进化(线3 ACE/ACON/RL)
                                    │
                        状态外移(线4 Scroll) ──→ 图记忆(讲透Graph)
                                    │
理论化(线5 通信复杂度) ──→ 记忆理论(线6 Forms×Functions)
```

**趋势判断**：2025 年的关键词是"压缩"（怎么把多的塞进去），2026 年的关键词是"**外移**"（状态搬到窗口外：环境、图、记忆层）+ "**理论**"（下界与税）。窗口正在从"唯一的家"缩编为"CPU 寄存器"——贵、小、只放当下要用的。

## 与本单元实验的对账

| 前沿主张 | 本单元证据 | 判决 |
|---------|-----------|------|
| 最小高信号集 | E1 渐进披露省 78% | ✅ |
| 理解强/生成弱不对称 | E5 细节 62.5%、E8 brevity bias | ✅ 行为学证实 |
| Selection vs Generation 的 log n 税 | E6 Bloom 97.9% 完胜 | ✅ 本地复现 |
