# 讲透 ibelick/ui-skills —— 设计工程师的 Skills 目录站与"品味层"

> ibelick/ui-skills（npm `ui-skills`@0.1.6，MIT，站点 ui-skills.com）｜46 文件｜图谱 82 节点/113 边

## 一、定位：不是 shadcn 生态，是技能分发层

**这不是 shadcn 生态合集**。shadcn 只出现一次——注册表收录 shadcn-ui 官方 `ui` 仓的 `shadcn` 技能一条（src/data/registry.ts:1046-1057），仅为 30 个上游源之一。

真实形态是**三层合一的分发设施**：①技能内容层——`skills/` 下 4 个第一方 SKILL.md；②注册表聚合层——registry.ts 硬编码 105 条社区技能元数据（src/data/registry.ts:49 起），来源含 anthropics、antfu(17)、pbakaus(18)、vuejs-ai 等 30 个上游仓；③分发层——Astro 5 目录站 + 443 行 sh 安装器 + npm bin CLI（package.json:6-8）。总量 109 技能挂 25 主题（src/data/topics.ts:10-170），八大设计主轴由 primaryDesignTopicSlugs 圈定（src/data/topics.ts:174-183），每主题配 4 个关联主题成推荐图（:185-210）。

安装器 ASCII 横幅自我定位："The open taste layer for agent-generated UI"（install.sh:41）；baseline-ui 开篇即 "prevent AI-generated interface slop"（skills/baseline-ui/SKILL.md:8）。

## 二、第一方技能清单：4 个"约束文件"，不是教程

| 技能 | 行数 | 一句话 |
|---|---|---|
| baseline-ui | 85 | UI 基线铁律八节：Tailwind 默认值、Base UI 基元、只动 transform/opacity、反馈 ≤200ms、禁渐变禁紫 |
| fixing-accessibility | 135 | 可访问性审计修复 9 级优先级 + before/after 对照 |
| fixing-metadata | 112 | SEO 元数据审计 8 级，title/canonical/og:url 须一致 |
| fixing-motion-performance | 151 | 动画性能 9 级：渲染术语表（skills/fixing-motion-performance/SKILL.md:32-36）、FLIP |

成对方法论：baseline-ui 是"生成时防错"，三个 fixing-* 是"存量审计修复"。

## 三、references 组织：单文件极简主义

与 Anthropic skills 规范（SKILL.md + 可选 `references/`）相比，这里全部内容收进单个 SKILL.md，**零 references 目录、零脚本**；注册表每条也只登记一个 rawUrl（src/data/registry.ts:8）。单文件内以三装置替代分层：①RFC 2119 情态词 MUST/SHOULD/NEVER，baseline-ui 85 行约 45 条规则（skills/baseline-ui/SKILL.md:46-57）；②`priority|category|impact` 优先级表（skills/fixing-accessibility/SKILL.md:35-45）；③common fixes 代码对照给可复制修法。

技能间引用不靠文件互链，靠**站点主题推荐图**：详情页 "Explore topics" 由技能 topics 并集关联表生成（src/pages/skills/[...slug].astro:257-270）。本地 4 技能的主题标注硬编码在 src/data/skills.ts:23-28 而非 SKILL.md，是两条数据路径的不对称点。

## 四、数据管线与站点：一份注册表驱动一切

数据流：registry.ts → skills.ts 合并——`import.meta.glob` 收本地 frontmatter（src/data/skills.ts:30-33），按 pathSlug 去重、本地优先（:65-77），baseline-ui 置顶（:79-89）。pathSlug=user/slug 统一小写（src/data/registry.ts:1411），4 组跨源重名 slug 冲突回退三段式（:1425-1428）。

**注册表同时是站点数据源与安装器机器契约**：`/skills/registry.txt` 输出 `pathSlug\trawUrl\tdescription` TSV（src/pages/skills/registry.txt.ts:7-12），install.sh 用 awk 解析定位 rawUrl（install.sh:129-147）；技能页对注册表技能在**构建期 fetch rawUrl**、剥 frontmatter、marked 渲染并重写相对链接（src/pages/skills/[...slug].astro:407-412、:28-45）——无重试无兜底，上游失效会把错误信息渲染进静态页（:418-422）。catch-all 路由一鱼四吃：技能页/主题分组/作者分组/遗留 slug 301 重定向（:145-147）。agent 面：站点级+技能级 llms.txt（src/pages/skills/[...slug]/llms.txt.ts:53-58）。⌘K 面板为自实现七信号评分搜索（src/ui/command-dialog.tsx:184-190），语料构建期生成（src/layouts/Layout.astro:76-87）。

## 五、与 Claude Code skills 生态的关系

install.sh 是 **16+ 工具安装矩阵**：项目级探测安装（目录已存在才装，install.sh:226-241）覆盖 .claude/skills、.opencode、.codex、.cursor、.kilocode、.roo、.goose、.gemini、.github(Copilot)、.factory、.windsurf 等并追加 .claude/commands、.cursor/commands；用户级全套见 :263-340；Windsurf 幂等追加 global_rules.md（:384-405）、Gemini CLI 生成 TOML（:412-417）。下载三级回退：本地 → registry rawUrl → llms.txt（install.sh:149-181）。另有 `npx skills add` 独立通道（src/ui/install-tabs.tsx:15），注册表技能按上游 repo+skill 名拼装命令（src/pages/skills/[...slug].astro:435-470）。页脚永久挂 Claude Skills 官方文档链接（src/layouts/Layout.astro:222）。

## 六、使用建议

1. `npx skills add ibelick/ui-skills` 或 `curl -fsSL https://ui-skills.com/install | bash`（默认仅 baseline-ui）；
2. 指定技能：`... | bash -s -- fixing-accessibility`（可串多个）；CLI `ui-skills add "baseline-ui fixing-metadata"`（bin/ui-skills:25-33）；
3. 拿任意注册表技能：`/skills/registry.txt` TSV 是稳定机器接口，按 rawUrl 直连上游更可靠；技能级 llms.txt 纯文本适合 agent 注入；
4. baseline-ui 配一个 fixing-* 成对使用。

## 七、甄别与勘误（源码实证）

1. **"46 文件"仓只自持 4 技能**——105/109 是转引，内容主体构建期从上游拉取（src/pages/skills/[...slug].astro:401）；
2. **`--all` 语义分裂**：仓内 ALL_SKILLS 硬编码 5 技能（install.sh:63），线上 /install 回传前正则替换为全量 109（src/pages/install.ts:8-10）；
3. **print_dim 引用未定义变量**：install.sh:53 用 `${DIM}`，颜色块只定义 DARK（:9-23）；
4. **双份 Wrangler 配置同义并存**（wrangler.jsonc/wrangler.toml）；rawUrl 失效错误直接进正式页，无 link-check CI；
5. **两处遥测**：安装发 onedollarstats 事件（install.sh:67-68）；页面注入 stonks.js（src/layouts/Layout.astro:144）；
6. **首页精选 owner 小写是隐性契约**（src/pages/index.astro:9-28 与 registry.ts:1411 联动）；
7. **CI 申请 id-token:write 却走 NPM_TOKEN 发布**（.github/workflows/release.yml:31-34）。

**一句话总结**：ui-skills 是 Agent Skills 时代的"目录站+安装器"样本——内容层极简（4 个单文件约束技能），工程重心在分发层最大化兼容（16+ 工具矩阵、registry.txt 机器契约、llms.txt agent 面）与站点质量；做技能分发生态时可直接借鉴。
