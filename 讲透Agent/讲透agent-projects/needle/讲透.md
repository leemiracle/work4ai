# 讲透 cactus-compute/needle（Needle 2）

> 45M 参数端侧工具调用模型的全链 Python 包：推理、LoRA 微调、导出。38 文件读完的源码级解读，行号锚均已核实。

## 一、定位

**Needle 2 是 Cactus Compute 的开源端侧 function-calling 基础模型**（`README.md` L5）：45M 参数、单一 14MB 二进制、整会话约 28MB RAM、CQ 2-bit 量化、自带推理引擎，对标 FunctionGemma 270M / LFM2.5 230M / Apple FM（体积差 5-70 倍互有胜负）。本仓是 **Python 包 `cactus-needle`**——不是引擎源码（C++ 引擎以预编译库从 HuggingFace 分发），而是三层胶水：工具 schema 编译器、LoRA 微调管线、`.cact` 导出器。架构论文 arXiv:2607.18363。心智模型：**类型注解描述工具 → 引擎在字节级语法约束下输出永远合法的 JSON 调用 → `Needle.run()` 驱动执行-回填循环**。

## 二、总体架构：三平面 + 一个枢纽

- **契约平面（零 JAX）**：`needle/__init__.py`（Needle 类 + ctypes）、`agent/tools.py`（类型→Schema）、`agent/fetch.py`。
- **训练平面（JAX 惰性导入）**：`model/architecture.py`（SAN 定义）、`model/quantize.py`（CQ）、`model/decode.py`（参考解码）、`model/finetune.py`（合成+LoRA+build）、`model/run.py`。
- **部署枢纽**：`model/export.py` 产出自包含 `.cact`（权重+码本+tokenizer 内嵌），引擎 mmap 直读零解析（docstring L1-76 就是规范书）。

`pyproject.toml` L5-12 列 jax/flax 为硬依赖但 `import needle` 不触发——JAX 导入全压在函数体内。版本事实：包 2.0.8（`__init__.py` L11），引擎独立 **2.0.3**（`fetch.py` L8）——`.cact` 与引擎绑定，跨版本不载入（L84-89）。

## 三、核心模块深读

### 3.1 Simple Attention Network（architecture.py，630 行）

1. **Hadamard MLP 替代 FFN**（L287-302）：`(d1*x)@H → SiLU(d2*z)@H → d3*z`，H 为固定 Walsh-Hadamard 正交阵（L280-284）。只有三条对角向量可学，**零矩阵权重、n log n 计算**——45M 压进 14MB 的结构原因。
2. **Engram 哈希 n-gram KV 记忆**（L181-206）：token 经 FNV 哈希（L116-117）查 8192 slot 表取 (k,v)，value 过 4-tap 因果卷积（L202-205）。在预设第 2/15 层注入（`PRESETS` L38-43）。
3. **多 lane 超连接 MHC**（L340-426）：四条残差流并行，层间路由经 **Sinkhorn 双随机化**（L169-174）。27 层由 `nn.scan+nn.remat` 压成参数堆叠，解码按 `[i]` 取层（`decode.py` L46-60）。
4. **双 probe 头**：ContrastiveHead 4 probe（L443-460）做工具检索（"每轮只渲染 top-5"的来源），ConfidenceHead 8 probe（L463-475）出校准置信分，共享 `probe_pool`（L429-440）。

**KV 内存是设计出来的**：`KV_BUDGET_BYTES=11.5MB`（L598），`kv_budget_window`（L603-611）按每位置字节数反推滑窗、向 32 对齐——README 的"256-token 滑窗"即此输出。

### 3.2 CQ 量化（quantize.py，366 行）

**"方向×范数"分离的矢量量化**（`cq_quantize` L134-147）：分组 Hadamard 旋转后拆成单位方向+fp16 范数，方向在 Lloyd-Max 码本（L94-106）上最近邻——2bit 可用因范数单独存。三值 1.58bit 用解析质心 ±1.2240064（L108-109）。配套混合位宽（L301-318）、字节统计（L175-189）、QAT 噪声与 STE（L231-239）。量化叶子只认 kernel/embedding/mhc_phi ≥2 维（L150-153），沿倒数第二维规约的先转置再量化——保证量化组沿 GEMV 规约轴排布。

### 3.3 .cact 格式（export.py，566 行）

120 字节头携全部几何+共享码本，无名张量目录（位置即语义，canon 顺序 L38-49），64 字节对齐、权重预转置按层摆放，`TAG=0x05E12A83`（L88）。三值索引用 3/0/1 的 2-bit crumb（L174-181）。`kv_window/kv_bits` 烧进 blob（L27-31）——"量化后必须同制式跑"。tokenizer 内嵌（L317-337），`RefTokenizer`（L460-533）立编码规范。`_geometry`（L103-124）对不支持配置显式拒导。

### 3.4 推理与 Agent 循环（__init__.py + decode.py）

ctypes 四符号 `needle_init/complete/reset/load`（L42-51）。`Needle.run`（L127-147）最多 `max_steps` 轮"点名→执行→JSON 回填"，未知工具与异常转 `{"error":...}` 回填。**权重安全显式设计**：引擎单例不可卸载，tuned 权重载入后再建 base agent 直接拒绝（L74-79），`test_weights.py` 钉死该语义。`decode.py` 是纯 JAX float32 参考解码（绕开 Flax），jit 静态锁 cfg/flash（L247）。**源码甄别**：README 说 "tools pinned as KV sinks"，但 Python 端 `_doc_prefix_len` 恒返回 0（`decode.py` L12-13）——真 sink 在 C++ 引擎内，本仓只见钩子。

### 3.5 工具 schema 编译器（tools.py，170 行）

零依赖（pydantic 可选，MRO 探测 L149-152）。`build_schema`（L115-146）吃签名+docstring（Args 解析 L99-112）+`Field` 约束（L18-49），支持 Literal→enum、PEP 604（3.9 兜底 L13）、嵌套 Pydantic。约束编译进**字节级解码语法**，保证调用合法。

### 3.6 微调管线（finetune.py，444 行）

四步：①`generate-data` 经 OpenRouter 合成（默认 `deepseek/deepseek-v4-flash` L29；1.3 倍超额、3 倍提交上限、按 (query,answers) 去重 L99-144）；②渲染 `<tools>+<think>+<tool_call>` 模板（L194-206，标记 id 见 `tokenizer.py` L22-29）；③LoRA 只挂五个注意力投影（L23），B 零初始化，loss 只掩码 target 段（L354-358）；④`build` 合并出 `.cact`。playground `_finetune_worker`（`server.py` L66-96）浏览器一键跑通，工具不变只 `needle_reset` 续聊（L33-37）。CLI 另有 fd 级 XLA 日志过滤器（L36-106）。

### 3.7 质量基建

测试双轨：纯逻辑单测随时跑；引擎/JAX 端到端靠 `conftest.py` `requires_engine`（L20-22）与迷你 SAN fixture（L26-45）。CI 每日发布火车：双 cron 防 DST、`pytest -m "not slow"`、自动 bump 版本（`release.yaml` L74-76）、发 PyPI。

## 四、使用建议

- **直接用**：装饰器描述工具 + `agent.run()`；tuned 模型同一 API。工具描述质量是全部，`llms.txt` 是最精确契约。
- **读架构**：`architecture.py` 四件套 → `decode.py` → `quantize.py`+`export.py` 压缩链。
- **微调**：一条 JSONL 几百条起步；**confidence 头不在微调范围**，tuned 权重下恒 None（`__init__.py` L60-62、L123-124）——别做置信门控。
- **坑位**：跨版本 `.cact` 要重 build；tuned 权重不可卸载，多模型分进程；16 平台含 android/ios/wasm（`fetch.py` L10-13），气隙走 `NEEDLE_LIB_PATH`。

## 五、结语

Needle 2 的启示是**把约束推到极端后的全链一致性**：无矩阵 FFN 与 2bit 矢量量化互相成全（Hadamard 既是模型结构又是量化旋转）；KV 预算是先验常量；语法约束在解码字节层；连"不可卸载权重"都编码成防错行为与专项测试。38 文件小仓每个决策都有源码锚点，是端侧 LLM 工程的高密度精读样本。
