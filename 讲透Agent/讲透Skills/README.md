## ⚠️ 三个最重要反直觉（开站先读）

1. **Skills 不是 prompt 的打包，是 prompt 的"分层延迟加载"**。杀手锏不是"写得好"而是 progressive disclosure：常驻上下文的只有 ~100 token 的 name+description，5000 token 的正文只在触发时装载，scripts/ 可以根本不进上下文直接执行。**装 100 个 skill 的固定代价 ≈ 装一个长 system prompt**。
2. **description 是唯一的检索键，且模型天然"欠触发"**。官方 skill-creator 的解法反直觉：描述要写得"pushy"（主动列举应该触发的场合）；优化它的 eval 里最有价值的是 near-miss 负例（看着像但不该触发的 query）。
3. **学术界已经把 skills 当研究对象**：北大 MCE（arXiv:2601.21557）让 meta-agent 用"agentic crossover"自动进化 skills，5 域实测相对 SOTA +5.6~53.8%；Agent Harness Engineering Survey（CMU 等 8 校，2026）把 static skills 列为 harness 工程的正式分支。**"写 skill"正在从手艺变成一门有论文、有基准的学科**。
