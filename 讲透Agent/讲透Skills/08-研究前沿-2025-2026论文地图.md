## 2. 六条线逐条讲透

### ① 综述与定位：Agent Skills for LLMs（arXiv:2602.12430, Xu & Yan）

四轴组织：**(i) 架构**（SKILL.md 规范/渐进披露/skills-MCP 互补：skills 供"what to do"，MCP 供"how to connect"）；**(ii) 技能获取**（人工撰写/RL 习得 SAGE/自主发现 SEAgent/组合合成）；**(iii) 大规模部署**（computer-use agents 为主战场）；**(iv) 安全**——最狠的数据：**26.1% 的社区贡献 skills 含漏洞**，由此提出 Skill Trust and Lifecycle Governance 四级门控权限模型（按 provenance 映射到渐进部署能力）。七个开放挑战从跨平台可移植到能力型权限模型。

三范式定位（原文）：prompt engineering (2022-23) → tool use (2023-24) → **skill engineering (2025-)**——skill 是"教 agent 怎么做事的高阶抽象"，工具执行即返回，技能重塑 agent 对任务的理解。前史谱系：Voyager（Minecraft 技能库）→ CREATOR/LLM-as-Tool-Maker → Toolformer，但那些是"模型生成、环境受限"；Agent Skills 强调"人写、可移植、可治理"。

### ② 实证 SE 研究：From Anatomy to Smells（arXiv:2607.01456, Hong/Imani/Ahmed, UC Irvine 系）

第一个把 SKILL.md 当**软件制品**做系统实证的研究：

- **解剖**：238 个真实 skills → 13 高层 + 44 低层语义组件分类法
- **最佳实践**：multivocal literature review 29 个来源 → 26 条 authoring 最佳实践
- **skill smells**：违反实践 = smell（借代码坏味道概念），自动检测器 SSD
- **两个发人深省的发现**：
  1. **99%+ 的 SKILL.md 至少含一个 skill smell**
  2. **skill smells 几乎不会随进化消失**（1295 个 commit 的纵向挖掘：引入后长期持续，无自然修复）

> 与本站呼应：E3 在本机 117 个目录抓出 3 违规 + 77 警告——同方向的小样本验证。这篇论文的结论"社区需要自动化 smell 重构工具"正是 skills-ref validate 的学术加强版需求。

### ③ 自动进化：MCE（arXiv:2601.21557，已在 [07](07-自动优化-从skill-creator到MCE.md) §3 详解）+ CoEvoSkills + SkillClaw

MCE 是系统化代表（双层框架、agentic crossover、+5.6~53.8%）；同行工作（从 2607.01456 引文）：**CoEvoSkills** 让 agent 自主创建/精化多文件技能包；**SkillClaw** 持续挖掘 agent 轨迹，把重复行为转成技能修订。共同主张：**skill 库是动态资产，不是静态文档**。

### ④ RL 技能获取：SkillRL（arXiv:2602.08234）+ SAGE + SEAgent

**SkillRL** 三件套：经验蒸馏（成功轨迹→演示，失败轨迹→简明教训，压噪声）；分层技能库 **SkillBank**（通用技能 vs 任务专用技能）；**递归技能进化**（RL 每个 validation epoch 后分析失败模式→新增/精化技能，技能库与策略共进化）。ALFWorld/WebShop/7 个搜索增强任务 SOTA，超基线 15.3%，且 60 步内成功率破 80%（无进化版需 90 步到更低峰值）——**进化机制同时加速收敛和抬高上限**。

**SAGE**（Skill Augmented GRPO）：Sequential Rollout（技能在任务链中前生后用）+ Skill-integrated Reward（奖励高质量可复用技能的生成）。AppWorld 上 +8.9pp，交互步数 -26%、生成 token -59%。

**SEAgent**（自主技能发现）：对新软件自主学技能，OSWorld 五个新环境成功率 11.3%→34.5%。

### ⑤ 技能即记忆：MemSkill（arXiv:2602.02474）+ Memento-Skills（arXiv:2603.18743）

**MemSkill**：把 agent 记忆操作（INSERT/UPDATE/DELETE/SKIP 四原语起步）重构为**可进化的记忆技能库**——controller（RL 训练的技能选择器）+ executor（按技能生成记忆）+ designer（从 hard case 挖掘→精化/新增技能），闭环交替"学用技能"与"进化技能库"。LoCoMo/LongMemEval/HotpotQA/ALFWorld 全面超基线。

**Memento-Skills**：agent-designing-agent——**SKILL.md 文件本身就是持久记忆单元**（"skills as memory"）。Read-Write Reflective Learning：read=行为对齐路由器检索技能（对比学习训练，优化"执行成功"而非语义相似——这直接攻击了 [03 章](03-路由与触发-description即检索键.md) 的 keyword-vs-intent 问题！）；write=失败后重写技能制品本身。GAIA +13.7pp、HLE +20.8pp；技能库从 5 个原子技能长到 41（GAIA）/235（HLE），t-SNE 显示技能按领域聚簇。**最深刻的定位**（原文）："continual learning need not reside in model weights: an ever-growing, self-improving skill library can serve as a persistent, non-parametric intelligence layer"——持续学习不必住在权重里，技能库就是冻结 LLM 的非参数智能层。

### ⑥ 基础设施：SkillNet（arXiv:2603.04448）

20 万+ 技能的开放基础设施：统一本体（异构来源创建技能）、丰富关系连接、**五维评估**（Safety/Completeness/Executability/Maintainability/Cost-awareness——与本仓 E3 的 C1-C7 及 skills 工程手册 6 维评价可对照）。ALFWorld/WebShop/ScienceWorld：平均 reward +40%、执行步数 -30%。定位：解决 agent"每次重新发明轮子"问题的公共地基。

## 3. 横向综合：这批论文共同回答的四个大问题

| 大问题 | 答案正在收敛为 | 关键证据 |
|---|---|---|
| **skill 为什么有效？** | 程序性知识的外置+按需注入，成本近零、无需重训 | 2602.12430 综述；渐进披露是"defining architectural innovation" |
| **skill 从哪来？** | 三源汇流：人写（当下主流）→ 轨迹蒸馏（SkillRL/SkillClaw）→ RL 习得（SAGE） | SAGE -59% token；SkillRL +15.3% |
| **skill 会自己变好吗？** | 会，但要闭环：失败信号→归因→重写技能（MCE/MemSkill/Memento-Skills 三家同构） | MCE +5.6~53.8%；Memento GAIA +13.7pp |
| **skill 可信吗？** | 当下不可信：26.1% 含漏洞 + 99% 有 smell 且不自愈——治理是下一战场 | 2602.12430 安全轴；2607.01456 |

## 4. 对本仓与个人的意义

1. **学术合法性确认**：skills 不再是"工程圈的文件格式小技巧"——SE 实证（smells）、RL 理论（技能-策略共进化）、记忆理论（skills as memory）三个学界都已入场。本仓的 skills工程手册/生态全景/本站构成完整的实践侧对照。
2. **研究空白清单**（论文自己承认的）：smells 对 agent 性能的因果影响未量化；学习到的技能如何**外化为可审计的 SKILL.md**（SAGE 技能是模型内部的，不可检查/共享/治理）——"learn ↔ externalize"的桥是最大空白。
3. **MATS/interp 方向启示**：技能-策略共进化（SkillRL）与 RLHF/内部化的关系、行为对齐路由器的可解释性，都是 interp × agent 的交叉富矿。
