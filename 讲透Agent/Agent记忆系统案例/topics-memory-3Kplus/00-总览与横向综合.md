## 四、发现③：正在收敛的设计共识（de facto standards）

1. **检索 = RRF 混合 + 重排**。BM25+向量（+图）RRF 融合已成事实标准：agentmemory 0.4/0.6/0.3 三路（`A04`）、ReMe K=60 向量权重 0.7（`A26`）、memvid RRF_K=60（`A07:77`）、MemOS 图/向量/BM25 三路并发（`A11`）；重排用 cross-encoder 60/40 混合+高分地板（`A20`）。纯向量检索已无拥趸。
2. **写入 = 结构化 patch，不是改写**。upsert/merge/skip 三选一（opensquilla dream `prompts.py:31-45`、腾讯四动作判重、hindsight delta_ops）+ 内容哈希乐观锁 + 软删除双写（EverOS md 与索引双侧 `deprecated` 打标可回滚，`A10:56`）。
3. **防污染 = 写入端纪律**。ReMe 保存前剔除 tool_result 防"检索结果伪装用户事实"的自污染回环（`A26`，auto_memory.py:24-31）；hindsight retain 先防御筛查；ms-agent 内容哈希台账仅成功后推进（`A22`，orchestrator.py:213-243）。**写入保守主义被反复独立发明**。
4. **注入 = KV-cache 友好**。持久召回块写进 SessionLog 保 prefix-cache（`A22`，llm_agent.py:1420-1466）；注入"位置+摘要"而非全文（memU）；检索每轮限 3 次防搜索成瘾（`A05`）；system/user 双路注入保护缓存。**记忆设计已与推理成本耦合**。
5. **遗忘 = 三因子或 FSRS 数学**。MineContext 年龄×重要性×访问频率概率删除（`A18`）；agentmemory 艾宾浩斯 retention+读取即强化（`A04`）；B 层 fsrs4anki 给出 375 行的 D/S/R 三变量现成实现（幂律遗忘+检索即再巩固+均值回归防漂移，`B03`）——**AI 记忆 decay 至今没人认真用这套数学，是明牌机会**。
6. **多租户 = 三态 scope 契约**。undefined 绕过/[] 拒绝/白名单 + 隐式私有 scope + 空写拒绝（`A20`，scopes.ts:203-230）；路径白名单+穿越双重校验（holaOS `A14`）；honcho session allowlist fail-closed（`A15`）。

## 五、发现④：基准乱象（全领域审计结论）

- **口径互不可比**：LongMemEval 上各家自报数字混合了 recall_any@5（检索召回）与 QA 准确率，agentmemory 自家对比表里 MemPalace 96.6% 反而高于其"95.2% #1"（`A04`）。
- **自封为主**：29 仓中可复现 harness 全开源的仅 mempalace（逐题结果+切分入库）、ReMe（自清洗子集+harness 开源）、SimpleMem（带 runner）、hindsight（harness 在库但对照数字只在 PNG 里）。
- **诚实度光谱**：mempalace（拒绝发布 100%、held-out 自称 honest）> EverOS/MineContext（README 零基准数字=反虚荣加分）> MemOS（token 节省数字出自论文不在仓库）> supermemory/memvid（引用已失效口径）。
- **一个反直觉的实证**：Agent-S 四代演进中删记忆+加推理反而涨分（`A29:125`）——记忆系统的增量必须超过检索噪声代价，否则是负资产。

## 六、发现⑤：B 层（系统内存）→ Agent 记忆的五条跨域迁移

（详证 `B00-B层合观.md`）

1. **分配溯源 ≈ 写入溯源**：memray 的高水位贡献度账本（snapshot.h:289-359）是"谁写入了这条记忆、贡献多少"的完整工程范本。
2. **FSRS = decay 的现成数学**：幂律遗忘曲线+可提取性预算旋钮+检索即再巩固，可直接移植为 Agent 记忆调度器。
3. **三点 diff = 变化检测协议**：memlab 的 `(target−baseline)∩final` 泄漏定义，可平移为"记忆状态漂移检测"。
4. **OS 内存列表 = 记忆分层语义**：memreduct 九类内存区（standby 逐出≠删除）是 working/long-term 分层的原生教科书。
5. **事件溯源 = 最小长期记忆**：12-factor-agents F5"thread 事件序列即单一事实源，Agent=foldl(events)"（`C02`），49 行 state.ts 即可起步。
