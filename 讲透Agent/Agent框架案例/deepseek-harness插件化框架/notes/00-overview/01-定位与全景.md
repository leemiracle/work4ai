# 01 · 定位与全景

> 对应仓库根 `README.md` / `AGENTS.md` / `docs/architecture.md` / `packages/README.md`
> 上游 HEAD `47f943859b`（2026-08-13）

## 1. 它是什么

DeepSeek Harness（`dsh`）是 DeepSeek AI 开源的 agent harness：给 LLM 装上工具、会话、沙箱、审批的**运行框架**。三条硬信息：

- **一切皆插件**：模型适配器、工具注册表、会话日志、agent loop 本身全是 Cordis 插件——没有可 patch 的特权核心（`docs/architecture.md:11-13`）。
- **Cordis 驱动**：插件向共享 context 贡献服务、类型化事件、可逆 effect；注册即 effect，卸载即回滚（`AGENTS.md:102`）。
- **developer preview**：README 明示"将出现破坏兼容性的变更"；发布前哲学是"正确的地基优先于爆炸半径"，可自由重命名（`AGENTS.md:5-7`）。

## 3. 五分钟跑通

```sh
# 从 npm（需 Node.js）
npx @deepseek-ai/dsh web            # Web UI, http://127.0.0.1:3080

# 从源码
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness && pnpm install && pnpm run build
pnpm dsh web
pnpm dsh --profile headless "task"  # 一次性任务（需 DEEPSEEK_API_KEY）
dsh --profile web --dump-config     # 打印实际启动的插件树，任意行可被 patch 替换
```

## 4. 核心包速查（架构文档 OWN 的表）

| 包 | 职责 | `ctx` key |
|---|---|---|
| `core/session` | append-only `SessionEvent` 日志 + 内存 store | `ctx.sessions` |
| `core/system-prompt` | prompt 段落 + 工具 schema 组装 | `ctx.systemPrompt` |
| `core/tools` | 作用域工具注册表 + 受卫执行管线 | `ctx.tools` |
| `core/agent` | `Agent` 接口、live 注册表、`agent/*` 事件 | `ctx.agents` |
| `core/agent-loop` | 默认驱动（turn/step 状态机） | `ctx.agentLoop` |
| `core/scope` | per-agent 作用域注册原语 | 库，无 key |
| `llm/llm` | 消息/流词表 + 适配器接缝 | `ctx.llm` |

## 5. 三类事件域（改代码前先选域）

`docs/architecture.md:55-61`：

- **会话事件**：durable 事实，进日志、可重放（`turn/*`、`step/*`、`user/message`、`assistant/*`、`tool/*`）。
- **Agent 事件**（`agent/*`）：携带 live Agent——inbox、step、request、校验、continuation。
- **能力事件**：在接缝上挂策略/适配器（`fs/*`、`tools/*`、`telemetry/*`），不 import loop。

瀑布（waterfall）监听器必须调 `next()` 委托，否则短路整链（`AGENTS.md:106`）；`agent/turn-stopping` 是串行的、没有 `next()`。
