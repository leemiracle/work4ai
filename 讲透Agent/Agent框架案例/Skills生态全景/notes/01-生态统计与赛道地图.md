# 01 · 生态统计与赛道地图：github.com/topics/skills 全景

> **快照口径**：GitHub Search API `topic:skills`，2026-08-19 实测。总量 **11,492 仓**；统计样本取 star 排序 top 500（star 区间 164 ~ 273,749）。所有 star 数均为 API 当日返回值，标注一次、全文通用。姊妹篇：[`02-规范演进与SKILL.md解剖.md`](02-规范演进与SKILL.md解剖.md)（规范怎么来的）、[`03-重点仓库深读.md`](03-重点仓库深读.md)（单仓卡片）。

---

## 1. 核心结论速览

1. **topic:skills 正在经历"语义迁移"**：这个词从"人类技能学习资源"（面试题库、编程练习）迁移为"**Agent Skills**（AI 技能包，SKILL.md 格式）"。top500 样本中 **79%（396/500）创建于 2025-10 之后**——语义迁移几乎整体重写了这个 topic 的高星层。
2. **官方源仓不在榜单上**：生态真正的 star 之王 anthropics/skills（170,317★，2026-08-19 API 实测）和 openai/skills（25,028★）都**没挂 `skills` topic**（前者只挂 `agent-skills`）——topic 检索必有盲区，须与 awesome 清单对账（见 §4.B 与 [`02`](02-规范演进与SKILL.md解剖.md) §6）。
3. **七条赛道**已经分化清晰：方法论框架 / 官方厂牌 / 合集与商店 / 注册中心与分发 / 垂直领域技能 / 平台产品 skills 化 / 存量旧语义仓。
4. **"skill" 正在变成营销关键词**：老平台（nacos 2018 年建仓）重新挂 topic、改描述蹭 AI 叙事；国内低代码平台（JeecgBoot、gin-vue-admin）把"内置 skills 管理"写进简介第一行。
5. **star 通胀与噪声并存**：榜首 obra/superpowers 273,749★（2025-10 建仓，10 个月）已是 2026 年 GitHub 现象级；但榜内也有 star 极高而与 skills 弱相关的仓（如 WiFi 感知 RuView 90,818★）——高星 ≠ 相关。

### 2.2 两代"skills"的对照

| | 旧语义（2011–2024 存量） | 新语义（2025-10 后） |
|---|---|---|
| 含义 | 人类学技能：面试题、编程练习、sysadmin 测验 | AI Agent 技能包：SKILL.md + scripts/references/assets |
| 代表仓 | JavaGuide(157,874★)、linkedin-skill-assessments-quizzes(28,811★)、test-your-sysadmin-skills(11,834★)、warriorjs(9,534★) | superpowers、awesome-agent-skills、google/skills、taste-skill |

| 活跃度 | 多数 2024–2025 后停更 | push 普遍在 2026-08 当周 |

**None 语言 60/500** 是新语义的指纹：技能包本质是"内容仓"（Markdown + 少量脚本），不是软件项目。
