## 1. 管线全景

两层：纯函数规则求值 `permissions.ts` + 带 UI 副作用的分流 `useCanUseTool.tsx`。三值输出：**allow / deny / ask**。

模式六种（PERMISSION_MODE_CONFIG）：对外四种 `default`/`acceptEdits`(⏵⏵)/`plan`(PAUSE)/`bypassPermissions`(⏵⏵ 红色)；隐藏 `dontAsk`（ask 全改 deny）与 ant-only `auto`。**plan 模式下若用户带 `--dangerously-skip-permissions` 启动，bypass 语义保留——模式只放宽不收紧**（permissions.ts:1268-1281）。

## 2. 规则语法与解析

格式 `Tool` 或 `Tool(content)`：`Bash(npm install)` 精确、`Bash(git:*)` legacy 前缀、含未转义 `*` 为通配符。解析器难点是**括号转义**：首尾括号用"前面反斜杠个数为偶数"判定；`Bash()`/`Bash(*)` 归一化为整工具规则；旧工具名别名兜底（Task→Agent、KillShell→TaskStop）——老配置继续生效。

通配符匹配先把 `\*`/`\\` 换 null 哨兵、其余元字符转义、`*`→`.*`、**带 s(dotAll) 标志**（heredoc 内嵌换行）；`git *` 尾部改写为 `( .*)?` 使裸 `git` 也匹配（与 `git:*` 对齐），多通配符 `* run *` 明确排除此优待（否则错配 `npm run`）。

**影子规则检测**：deny 先于 ask 先于 allow，故 `Bash` deny 后 `Bash(ls:*)` allow 永不可达——detectUnreachableRules 扫描并给 fix 文案；ask 遮蔽有沙箱豁免但**仅限个人配置**（共享配置一律告警，队友不一定开沙箱）。

## 3. 编号求值步骤（permissions.ts:1158-1319，每个编号=提前返回点）

| 步 | 条件 | 结果 |
|---|---|---|
| 1a | 整工具 deny 命中 | deny |
| 1b | 整工具 ask 命中（沙箱自动放行除外） | ask |
| 1c | 工具自己的 checkPermissions（Bash 子命令级规则） | 透传 |
| 1d | 工具返回 deny | deny |
| 1e | requiresUserInteraction 且 ask | **强制询问，bypass 不可跳** |
| 1f | 内容级 ask 规则 | **优先于 bypassPermissions** |
| 1g | safetyCheck（.git/.claude/.vscode/shell 配置路径） | **bypass 免疫，必须弹窗** |
| 2a | 模式层 bypass | allow |
| 2b | 整工具 allow | allow |
| 3 | 工具 passthrough | 兜底改写为 ask |

**步骤顺序即安全策略**：deny 永远最先；safetyCheck 与用户交互类不可被模式跳过；allow 排在模式之后。2a 前重新 getAppState()——工具 checkPermissions 是异步的，期间用户可能已切模式。

## 4. 分类器层

- **bashClassifier**（BASH_CLASSIFIER）：`Bash(prompt: ...)` 自然语言规则，Haiku 分类；**推测性检查在弹窗准备阶段提前发起，2 秒宽限期内高置信且用户未交互则自动批准**（useCanUseTool.tsx:126-158）
- **yoloClassifier/transcriptClassifier**（TRANSCRIPT_CLASSIFIER，auto mode）：整段会话 transcript + 当前动作发分类模型；**两阶段**——stage1 快判、存疑升级带思维链的 stage2 降误报；共享前缀放 cache_control 断点保 stage2 命中缓存。两条省钱快路径：acceptEdits 试算 checkPermissions 能放就不调 API（**Agent/REPL 显式排除——REPL 胶水 JS 里可能藏着 inner tool call 之间的 VM 逃逸，分类器必须看完整代码**）；安全白名单 SAFE_YOLO_ALLOWLISTED_TOOLS（Read/Grep/Glob/TodoWrite/Task 系/Sleep）直接放行
- **危险前缀静态过滤** DANGEROUS_BASH_PATTERNS：`Bash(python:*)` 这类 allow 等于任意代码执行会绕过分类器——解释器/包运行器/shell/eval/exec/sudo/xargs 进 auto mode 时剥离；ant 还有基于内部沙箱数据的经验清单（curl/wget/gh/git/kubectl/aws），注释坦承"empirical-risk call"
- **失败语义可配置**：分类器 API 不可用时查 `tengu_iron_gate_closed`——true 则 fail-closed 拒绝附重试指引、false 则 fail-open 回弹窗。**同一系统按业务语义分出三种读取策略**（宁可旧 true 的门禁/宁可旧 false 的安全限制/必须等新值的）
- **拒绝熔断** denialTracking：连续 3 次/累计 20 次触限降级 ask 让用户复核；`recordSuccess` 无变化返回原引用 + Object.is 短路避免无变化 store 通知

## 5. 三 handler 分流（ask 的去向）

1. **coordinatorHandler**：后台 worker——先 await 权限 hooks（快）再 await 分类器（慢），都未决落回对话框；检查失败只记日志不卡死 worker
2. **swarmWorkerHandler**：先试分类器自动批准，失败把权限请求**经 mailbox 转发给 leader**；回调先注册再发请求（防响应早于注册的竞态）
3. **interactiveHandler**：`createResolveOnce().claim()` **原子占位——用户点击/hooks/分类器/bridge/channel 远程响应多条路径只有一条能 resolve**；对话框弹出头 200ms 忽略按键（防误触取消正在进行的分类器批准）；bridge（手机审批）/channel（KAIROS）远程回调，本地胜出后注销远程监听

headless 不走三 handler：hook 返回 allow 落盘 updatedPermissions、deny+interrupt 直接 abort 整个 agent、hook 抛错落到**自动 deny 而非 crash**。

## 6. 两套隔离（12 篇要点）

- **本地沙箱**：Bash 命令包进 OS 级沙箱（macOS seatbelt / Linux bubblewrap），`@anthropic-ai/sandbox-runtime` 桥接——防"模型命令伤害宿主机"
- **CCR 出口代理**（upstreamproxy/）：容器出站被网关封死，所有 HTTPS 走本地 **CONNECT→WebSocket 中继**，服务端 MITM 注入组织凭据——防"容器命令绕过组织审计与凭据管控"。两套独立、目标不同，勿混为一谈
