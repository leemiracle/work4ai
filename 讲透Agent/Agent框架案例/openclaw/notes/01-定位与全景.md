# 01 · 定位与全景

> HEAD f612675284（2026-08-20）。README.md 自述："personal AI assistant that runs on your devices and meets you in the channels you already use"——单操作者、自有设备、已有频道。

## 一、它是什么

| 维度 | 事实 |
|---|---|
| 产品形态 | 常驻 Gateway daemon + 全平台客户端（apps/: android/ios/linux/macos + swabble）+ 聊天频道接入（Telegram/WhatsApp/Discord…） |
| 核心承诺 | **own your data**（官方 topics 之一）：跑在自己设备上，不经第三方云 |
| 安装 | `curl -fsSL https://openclaw.ai/install.sh \| bash`（自动配 Node 22.22.3+/24.15+/25.9+）；npm 直装/Docker/Nix 多路径 |
| 版本 | 2026.8.1（日历版本制——每月迭代） |
| 协议 | MIT |

增长解读（三个杠杆）：
1. **"own your data" 踩中隐私焦虑**——个人助手跑本地是 LLM 时代的刚需叙事。
2. **频道即入口**：不造新 app，钻进你已有的聊天软件（channel-docking 概念，docs/concepts/ 58 篇里占独立一篇）。
3. **社区病毒式**：crustacean/lobster 梗文化（README "EXFOLIATE!"、topics: crustacean/molty）+ Discord 活跃。

## 四、与同类的坐标

| | OpenClaw | dsh（DeepSeek 官方） | Claude Code |
|---|---|---|---|
| 定位 | 个人助手（全场景） | 编码 agent | 编码 agent |
| 插件化 | 42 挂点 + 包契约 | 219 插件包（Cordis） | skills/hooks |
| 部署 | 自有设备常驻 daemon | 开发工具 | 云+本地 |
| 多模型 | catalog 数据化（10 API） | 引擎方言层 | Anthropic 系 |

三者互证一个判断：**harness 挂点密度是 2026 年 agent 竞争的核心战场**（dsh 219 包 / OpenClaw 42 挂点 / Claude Code skills 开放标准）。
