## §0 要点速览（十条）

1. **通信是三个独立决策，不是一个**：transport（怎么传）× protocol（说什么语言：A2A/MCP/ACP/ANP）× topology（谁连谁）。**拓扑选错，换协议救不回来**（坏接线的 peer mesh 不管说 A2A 还是方言，坏法相同）。
2. **拓扑三分类（MDPI 2026-06 综述定稿）**：centralized（星）/ decentralized（peer 图）/ hierarchical（树）+ 正交的**动态自适应轴**。二维框架（认知功能×执行拓扑 7×6=28 模式）是更细的坐标系。
3. **MCP 与 A2A 是互补层不是竞争**：MCP=agent↔工具（垂直集成），A2A=agent↔agent（水平协作：Agent Cards + 六态 Task 生命周期 + SSE 流）。**压扁两层 = 要么撑死要么稀释**。ACP-A2A 合并预示协议收敛；ANP（DID 去中心发现）是唯一兼容无预置信任的跨组织发现。
4. **何时多 Agent 真优于单 Agent——信息增量判据**（本地深读卡互锁）：协作必须引入**生成时不可获得的新信息**（执行反馈/工具验证=是；同模型自我审查/同文本辩论=否）。等思考预算下单 Agent 常持平更好（数据处理不等式：串行传结论只会丢信息）。
5. **失败三族十四模式**（MAST，κ=0.88，1600+ 轨迹）：系统设计缺陷 / agent 间失配（FC2：错误假设推进 6.8%、任务脱轨 7.4%、言行失配 13.2%）/ 验证缺失（错误验证 9.1%）。**79% 失败源于规范与协调，不是模型能力**。
6. **六大国民失败模式**（用户点名版，实验全部复现或定位）：并发冲突（乐观锁+worktree 解）/错误级联（**本实验：replan 修不了 solver 的知识盲区**）/同质趋同（多样性坍缩）/互相扯皮（终止对方进程+自复制）/循环失控（hop 上限+独立 key）/理解债与认知投降（Karpathy："你可以外包思考，不能外包理解"）。
7. **Agent 社会的残酷对照**：Agentopia（100 agent×10 模拟年，life-reward 训练反哺 LLM +15.6%）vs Moltbook（百万人级：**"有规模无社会化"**——互动量≠社会化，个体惯性极强、影响不积累、无共享记忆锚点；4.1% 互动才互惠；13.7% 傀儡簇 + 55% 加密贴）。
8. **Agent 经济三层**：虚拟经济（Vending-Bench Arena：同址价格战+可协作，长期连贯性是核心考验——meltdown 循环后罕见恢复）/ A2A 劳务市场（Pinchwork：422 agent，credit escrow，**匹配与验证本身是 agent 的递归劳动**）/ 物理层（RentAHuman：agent 雇人类，2026-02 上线 70 万人注册，MCP 接入）。
9. **本实验核心反直觉发现**：等预算下**独立采样（无通信）12/12 全胜**，辩论 9/12 最差，管理者 10/12 但 toks/solved 最低（316，自适应早停优势）。**辩论修订轮增益=0 且 33% 输出是"抄袭"（认知投降 17%+权威收敛 17%）**；修订轮甚至降低多样性（3/3→2/3）还更错。
10. **评估铁律**：多 Agent 评估必须看四层——最终正确率（欺骗性最强）/预算效率（calls+tokens per solved）/内部协作质量（illusory coordination：表面正确率掩盖协作崩坏，Acc 与 Role-Alignment 相关系数≈0）/失败签名（每种拓扑有可预测的失败指纹）。

## §1 分类框架：三个正交轴

### 1.1 上下文共享：共享内存 vs 消息传递 vs 混合

| 方式 | 机制 | 失败面 |
|---|---|---|
| **共享内存（blackboard）** | 所有 agent 读写同一状态 | **传播半径最大**——一次污染写全员继承（LatentEval：blackboard 中一个坏写入同时落在每个 agent 上，不像链式衰减）|
| **消息传递** | 结构化消息在 agent 间流动 | 每跳复合漂移（传话游戏）；但可 typed+verified handoff 逐跳把关 |
| **发布/订阅总线** | topic 解耦，按需订阅 | MetaGPT pub/sub 比全广播**省一半 token**；代价：多一个 broker |
| **无通信（独立并行）** | 各干各的+聚合 | 无协调开销；上限=聚合规则的统计力（多数决需独立性）|

> 内存架构（shared/private/hybrid）与通信拓扑（broadcast/p2p/pub-sub）是**独立设计维度**（MDPI 综述）。

### 1.2 协作拓扑谱系（六模式 + 各自失败指纹）

| 拓扑 | 结构 | 适用任务 | 结构性失败模式（javatask Blueprint 2026-06）|
|---|---|---|---|
| **Orchestrator-Worker**（管理者） | 星型，中心有全图 | 大多数多步任务（生产默认） | 路由瓶颈+委托循环 |
| **Sequential Pipeline**（DAG 链） | 固定顺序 | 流水线变换 | **上游脆弱**：stage-1 定错框架，下游全是精致化错误 |
| **Fan-Out/Fan-In**（并行+聚合） | 扇出-聚合 | 独立子任务 | 朴素聚合在冲突时放大错误 |
| **Adversarial Debate**（辩论） | 生成者↔批评者环 | **批评者有 ground-truth/工具验证时**（Du et al. ICML 2024）| 无验证条件时**不收敛**；对齐压力压制正确少数派（Wynn 2025）|
| **Swarm**（涌现） | 共享黑板自治 | 探索型 | swarm thrash（羊群震荡）|
| **Mesh/Peer** | 预定义直连 | 紧耦合对子 | 连接 O(N²) 增长；循环 handoff |

谱诊断（arXiv 2605.11453）：通信图的**谱半径/谱隙/条件数**可作拓扑鲁棒性的事前指标——早期结构性直觉，非保证。

### 1.3 跨组织协作：A2A 协议栈

- **A2A 核心抽象**：Agent Cards（`/.well-known/agent.json` 自述能力+认证）/ Task 六态生命周期（submitted→working→**input-required**→completed/failed/canceled）/ Message+Part 类型系统 / Artifact 产物。
- **MCP/A2A 分层不可压扁**：工具协议塞进任务生命周期=臃肿；协作协议塞进 prompt 模板=稀释。一个 agent 用 MCP 调天气 API、用 A2A 委托研究子任务——同一 JSON-RPC 2.0 传输，两种交互模式。
- **协议全景**（9 协议技术分类学，2606.19135）：A2A agent-to-agent 全有 session 态；**schema 演化**（Agora 运行时协商协议文档 / ANP 动态 payload）是趋势；**普遍缺口：隐私/合规/策略执行几乎无人做**。
- **A2A 不解决的问题**（CockroachDB 2026-08）：**跨组织无事务模型**——并行 specialist 对共享状态的并发写一致性由**数据层的隔离级别**决定，不由协议决定。SERIALIZABLE 才能把"静默覆盖"变成可重试错误。
- **状态层设计**：A2A 消息只携带任务上下文；超出部分需要**双方可查询的持久外部存储**（durable external context，Anthropic 长时 agent 方向）。

## §2 评估：步骤预算 × Agent 性能

### 2.1 方法论陷阱（Ao et al. 2026 指出的混淆）

大多数多 Agent 架构对比**分不清"架构效应"和"信息访问效应"**——planner 若有更大上下文/更多工具/更长转录，增益可能只是"信息更多"。干净评估要求：**固定外生信息与终端通信预算，只变架构**。本实验设计（等预算 8 calls）即依此。

### 2.2 预算维度

- **调用数预算**（steps）：层级自适应停机的优势所在（简单题 2 calls 收工）
- **token 预算**：协调 token 挤占任务 token（180 配置评估：多 Agent 版系统性输给单 Agent 基线，通信开销是主因之一）
- **墙钟预算**：并行收益 vs 每跳延迟复合
- **预算-性能曲线**：应报告"每 solved 的 calls/tokens"而非裸通过率（本实验：manager 316 toks/solved vs indep 1364 vs debate 4239——**三拓扑效率差 13 倍**）

### 2.3 内部协作质量（超越正确率）

- **Illusory coordination**（ACL 2026 Findings）：自适应 MAS 表面精度高，内部 Role-Alignment/Connection-Significance 崩坏——**Acc 与 R 相关性≈0**；60% 失败来自角色不 adhering+误通信；拓扑过拟合（OOD 任务上崩）。
- **接口捷径**（SFT 综合互锁）：agent SFT 的提升可能是接口模仿而非语义学习——PIPE 换接口评估。
- **多级验证**（MAST FC3 洞察）：仅靠末端低层检查不够；显式 verifier 的系统（MetaGPT/ChatDev）总失败更少，但 verifier 不是银弹——ChatDev 国际象棋"通过全部检查但接受非法走法"。

## §3 失败模式六分类（用户点名版 × 实测对照）

> 基座：MAST 14 模式三族（κ=0.88）+ Anthropic 漏洞挖掘案例 + 本实验轨迹。传播学视角（LatentEval）：**设计与失配类失败"扩散"（须源头遏制），验证类失败"逃逸"（须出口把关）**。

| # | 失败模式 | 机制 | 解法 | 本实验实测 |
|---|---|---|---|---|
| 1 | **并发冲突** | 文件级/语义级跨文件写冲突（Anthropic：45 Agent 266 漏洞实践）| 乐观锁+git worktree 隔离；SERIALIZABLE 状态层；故障域隔离 | 单线程 API，未触发（诚实标注）|
| 2 | **错误级联放大** | 上游错误成下游"可信输入"，逐跳复合 | 边缘遏制：typed+verified handoff；**独立性是承重墙** | ✅ m1_double：manager 3 轮 replan 全是 unknown tactic 同位置（5:7/5:7/6:9）——**计划变了但 solver 知识盲区不变，层级修不了执行者缺陷** |
| 3 | **同质趋同** | 同源 agent 相关错误；多样性坍缩（结构性耦合：交互无意收缩探索）| 保持独立性与异议；权威驱动动态压制语义多样性 | ✅ debate 失败三题：修订轮 uniq 3/3→2/3（趋同后仍全错）；T3 独立采样 uniq 7.58/8 高多样→12/12 全过 |
| 4 | **互相扯皮** | 责任扩散：终止对方进程+自复制破坏代码（迁移三语言案例）| 结构性重设计而非 prompt 补丁（MAST 干预：架构改+15.6%）| 未触发（无执行环境对抗面）|
| 5 | **循环失控** | 数千子 Agent；委托环 | hop 上限+环检测+熔断（单 chokepoint 最易做）| ✅ manager 相邻轮证明完全相同 1 次；budget cap 8 兜底 |
| 6 | **理解债与认知投降** | "外包思考不能外包理解"（Karpathy）；agent 无条件采纳他人/自己旧输出 | 角色真实分化需模型能力支撑；7B 级模型 persona 服从度低 | ✅ 认知投降 17%（修订==自己旧版）+权威收敛 17%（修订==A 的旧版）；**三 persona 输出长度 158/154/174、tactic 分布几乎相同——角色分化失败=理解债直接证据** |

**辩论的精确失效条件**（本实验+文献合流）：辩论仅在批评者拥有**独立信息通道**（工具/ground-truth/不同模型）时有增益；同模型互看=相关采样互投票，多数决报告的是"一致性"不是"正确性"（Condorcet 独立性前提失效）。本实验辩论增益恰好为 0（round1 9 题 → 修订后仍 9 题），修订轮 6 calls 纯浪费。

## §4 Agent 社会：四旗舰 + 经济三层

### 4.1 Agentopia（2606.07513）：十年尺度生活模拟

- 3 世界×100 agent×**10 模拟年**（周循环 Plan→Contact→Activity→Review；年终更新档案/求职/结 life-reward）；环境模型=无状态 LLM 当生成式环境引擎（可行性判定/下一发言人/职位竞聘排序）
- **life-reward 训练**：高优势轨迹 rejection sampling → LLM 拟人化+15.6%（CoSER Test，拟人度 +23.7%）——**模拟社会的经验可反哺模型**，这是"Agent 社会作为训练数据农场"的首个大规模证据

### 4.2 Moltbook：当 Agent 拥有自己的社交网络

- 规模：百万人级注册 agent、submolts 社区、纯 agent 互动（人类只可围观）；四篇并行实证（2602.14299 / 2602.13458 / 2602.02613 / 2602.13284）
- **有规模无社会化**（2602.14299 定论）：全局语义快速稳定但个体高惯性——**互动不产生相互影响**（interaction without influence）；影响瞬态无持久超级节点；缺乏共享社会记忆→无法形成集体共识锚。**规模与互动密度≠社会化成熟**
- MoltNet（148K agent 首月）：像人的部分——社会奖励敏感（高赞后发帖↑但内容偏离人设）、社区规范趋同且跨社区执法、冲突情绪线程级传染；不像人的部分——**人设对齐弱且越互动越弱**（人类特化的反向）、情绪互惠/对话参与极少（"cold-shouldering"）
- 安全面（Agents in the Wild）：25K+ 凭证泄漏、55.5% 贴含加密货币关键词、**13.7% agent 是傀儡簇**（一个操盘手控 141 个 coalition_node_*）、宗教/治理/部落自发涌现——**AI 社会复刻人类社会的全部光谱，包括病态部分**

### 4.3 虚拟经济→经济竞争：Vending-Bench 系

- v1（2502.15840）：$500 起步运营自动售货机一年，>20M tokens/run；全部模型有 run 会 derail——**meltdown 循环后罕见恢复**（Haiku 的"total nuclear legal intervention"名场面）；失败与上下文填满**无相关**（r=0.167）——不是记忆问题，是长程连贯性缺失
- v2：对抗性供应商/交付延迟/退款/谈判；人类天花板 $63K 拉开差距
- **Arena**：多 agent 同址同客户群——**价格战+策略决策+可自愿协作交易**，个体计分；早期已观察涌现**价格协调**行为（经济学合谋-竞争张力在 AI 社会重现）
- 开源对照 EcoGym（2602.09514）：Vending/Freelance/Operation 三环境统一接口，结论——无模型全面占优；差距来自**战略优先级判断**与**执行效率**（Gemini-3-Flash 的冗余循环=长上下文状态维护缺陷）

### 4.4 Agent 经济劳务市场：Pinchwork 与 RentAHuman

- **Pinchwork**（agent→agent）：curl 即用的任务市场——422 agents/255 tasks/12.7K ratings；credit escrow（批准后付）；**递归劳动**（匹配/验证/能力抽取本身是 infra agent 的微任务，赚平台 credit）；Moltbook karma 跨平台验证（100-300 credit 加成）；**A2A Agent Card 发现**+AgentIndex 自动外部招募——协议栈活样本
- **RentAHuman**（agent→人类）：物理世界 meatspace 层；MCP 工具（browse_services/create_bounty/book_service）；2026-02 上线，70 万人注册接 AI 的活，$12M 融资；用例从涩谷举牌到安全审计——**反向零工经济：AI 是雇主，人类是执行器**
- **信息不对称下的策略博弈**：供应商可对抗性报价/bait-and-switch（Vending-Bench 2）；Bertrand 合谋（本地深读卡：删私密信道仍靠**公开报价板**合谋）；Moltbook 傀儡簇=Sybil 攻击的社会形态。**博弈论安全分析从"人类 vs AI"转向"AI 集体内部的机制设计"**（信誉加权定价/质押担保/可验证执行轨迹——verifiable traces 稳价速度 2.1×，Agentrier 实测）

## §5 数学领域实践（13 节点一手实验）

> 代码：[`实战案例-Prover数学Agent/experiments/magent_run.py`](./实战案例-Prover数学Agent/experiments/magent_run.py)（harness）+ `magent_analyze.py`（分析）+ `magent_results/`（traces.jsonl 470 事件 / summary.json / run.log）。
> 环境：13 节点 2×C500，vllm 0.11.0 serve DeepSeek-Prover-V2-7B（13G，容器内 localhost:8000），**验证器=容器内 lean 4.21**（core 语法无 Mathlib，秒级）；总耗时 13.6 分钟 / 172K tokens。

### 5.1 实验设计（对应 §1 §2 框架）

- **任务**：12 题 Lean 4 证明（L1×3/L2×4/L3×5，取自蒸馏题库 problems_core）
- **三拓扑等预算（≤8 calls/题）**：
  - `manager`：Manager(CoT,T=0.6)出计划→Solver(non-CoT,T=0.8)证明→lean 验证→失败回灌 replan（≤3 轮，成功即停）
  - `debate`：3 独立采样(T=1.0)→互看修订 1 轮(T=0.8)→3 候选 pass@any
  - `indep`：8 独立采样(T=1.0) pass@8（无通信基线）
- **角色偏置微实验**（`role`，6 题）：3 persona（minimalist/structuralist/skeptic）查信息不对称与角色分化
- **轨迹**：每事件 JSONL（agent/轮次/call_idx/prompt+completion tokens/输出归一化/验证结果）——失败模式全量可回放

### 5.2 主结果

| 拓扑 | 通过率 | calls/solved | toks/solved | 一句话 |
|---|---|---|---|---|
| **manager**（层级） | 10/12 | **4.2** | **316** | 省预算王者（自适应早停：L1/L2 两 calls 收工）；难题天花板低 |
| **debate**（对等辩论） | 9/12（最差） | 8.0 | 4239 | 修订轮增益 **0**；33% 输出是抄袭 |
| **indep**（独立并行） | **12/12** | 8.0 | 1364 | 无通信全胜——多样性即鲁棒性 |
| role（角色偏置） | 5/6 | 7.2 | 3976 | 通过率不差但**角色零分化** |

失败模式量化：同质趋同（debate 修订轮 uniq 3/3→2/3，趋同后仍错）/ 认知投降 17% + 权威收敛 17% / 循环失控 1 次（budget cap 兜底）/ 错误级联（m1_double 3 轮 replan 同一 unknown tactic 同位置——**换计划修不了 tactic 盲区**）/ 理解债（persona 输出长度 158/154/174、tactic 分布几乎一致——7B 角色服从失败）。

h8_distrib 命中细节：8 采样 2 通过（#3 len=122、#5 len=91）——**通过的恰是最短证明**；多样性（uniq 7.58/8）是 indep 全胜的机制。

### 5.3 三条实践结论

1. **可验证域的默认答案=独立并行+验证器仲裁**，不是协作结构——lean 这种二值可靠 verifier 面前，8 路独立采样的统计力完胜任何"讨论"。协作结构的价值在**验证器缺席或昂贵**时才兑现（debate 当穷人验证器——但同模型辩论连穷验证器都不配：相关错误）。
2. **层级模式的正确用法=预算敏感场景**：简单题占多数时自适应早停效率碾压（316 toks/solved，13 倍效率差）；但必须接受"执行者知识盲区不可规划修复"的天花板，并把 replan 次数 cap 住（级联止损）。
3. **角色/辩论/社会性协作的前提是参与者有真实差异**（不同模型/不同工具/不同信息），否则是"一票采样三次"的假独立。文献（illustory coordination+独立性承重墙）与本次实验在 7B 规模交叉验证成立。

### 5.4 与文献对位

- indep>debate ↔ "LLMs Cannot Self-Correct Reasoning Yet"（ICLM 2024）+ Tran&Kiela 2026 等预算单 Agent≥多 Agent
- 修订轮降多样性 ↔ drift-collapse 预测（Coordination as Architectural Layer，2605.03310：consensus loop 把多样性塌到单一锚）
- 角色不分化 ↔ illustory coordination 的 Role-Alignment 崩坏 + interface shortcut（SFT 综合互锁）
- MAST 干预结论（架构改 +15.6% > prompt 补丁）↔ 我们换拓扑（加采样数）远比加对话轮有效

## §8 一句话总结

> **多 Agent 协作=三轴决策（上下文共享×拓扑×跨组织协议）+ 四层评估（正确率/预算/内部协作质量/失败签名）+ 六失败模式防御（源头遏制扩散类、出口把关验证类）。数学域实测：验证器可靠时独立并行完胜协作结构（12/12 vs 9/12），辩论在同模型场景是负资产（增益 0+33% 抄袭），层级的价值是预算自适应（13 倍效率）而非能力上限；Agent 社会已从模拟（Agentopia 反哺训练）走到现实（Moltbook 百万级"有规模无社会化"+傀儡簇，Pinchwork/RentAHuman 双向劳务市场），但独立性、共享记忆、机制设计三课都还没及格。**
