## 要点速览（TL;DR）

1. **一句话总纲**：RL 在 2024-2026 完成了三级跳——从"对齐工具"（RLHF）到"推理引擎"（RLVR）到**"Agent 的学习机制"**（Agentic RL + TTRL）；每一跳都是 $J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}[R(\tau)]$ 这个目标的**轨迹侧或奖励侧**的一次扩容。
2. **2026-08 的三个新共识**：①credit assignment 是两波 RL 共同的心脏瓶颈（47 法综述）；②**TTRL 家族三个月进化三代**（majority vote → CoRE 均衡图 → Hi-TTRL 采样调控 + SCRL 负标签）——无标签自进化成为独立赛道；③**世界模型从"表示学习对象"变成"RL 的提速器"**（WMRL 3-4×，带收敛证明）。
3. **我们自己的两条硬教训**（别处看不到的）：窄动作空间 bandit 无优势（T3：UCB 8 vs 11）/ reward 不编码价值就精确地优化到错的方向（Goodhart 现场演示）——这两条与文献结论互证。
4. **统一收口**：全部 RL 现象（从 DQN 到 TTRL 到我们的发现引擎）都是 $\mathcal{A}_{t+1}=\mathrm{IMPROVE}(\mathcal{A}_t;\mathcal{S}_t)$ 的实例——差别只在 $\mathcal{S}$ 的验证层级与 $\theta/\Sigma$ 的改动深度。

## 二、四波浪潮：一个统一叙事（轨迹侧 × 奖励侧）

2606.16733（GRPO 第一性推导综述）给了最好的坐标系：一切策略梯度方法都改 $J(\theta)=\mathbb{E}[\sum R]$ 的**两个因子之一**。用这个坐标重述四波：

```
浪潮                    轨迹侧 τ                奖励侧 R                标志算法
─────────────────────────────────────────────────────────────────────────────────
W1 经典 RL              MDP 全交互              手工设计               Q-learning/PPO/SAC
（1998-2020）           （真环境）              （稠密可塑）
W2 RLHF 对齐            退化为单步 MDP          学习的奖励模型         PPO-RLHF/DPO
（2020-2023）           （prompt→response）     （人类偏好蒸馏）
W3 Reasoning RL         单步但超长 CoT          可验证奖励 RLVR        GRPO/DAPO/DeepSeek-R1
（2024-2025）           （500-30K token）       （测试/编译器判分）
W4 Agentic RL           POMDP 多轮交互          环境反馈+工具结果       ArCHer/Turn-PPO/AgentPRM
（2025-2026）           （10-100+ turn，        （延迟/稀疏/含噪）      /HiPER/RL-PLUS
                        100K-1M token）
W5 TTRL 自进化（进行中） 任意——用测试流本身     自生成伪奖励           TTRL/CoRE/Hi-TTRL/SCRL
（2026）                （无训练/测试之分）     （多数投票/均衡/熵门控）
```

**读法**：每波都是被上一波的失败逼出来的——W2 的奖励模型被 hack→W3 换可验证奖励；W3 的单步假设撑不住长轨迹→W4 上多轮；W4 的环境太贵太稀→W5 用自己的 rollout 当环境兼奖励。**每一次"失败→扩容"都发生在单一侧，而 2606.16733 的核心警告是：复合失败（两侧耦合）没有单侧解**。

W4 的正式定义已定版（TMLR 2026 综述，500+ 文献）：LLM RL 是退化单步 MDP，Agentic RL 是时间扩展的 POMDP，六大能力轴 = 规划/工具/记忆/推理/自我改进/感知——**RL 是把这些静态模块变成自适应行为的关键机制**。

## 三、2026-08 下旬增量（07 章截止后的新东西）

### 3.1 Credit Assignment：两波 RL 的共同心脏（47 法综述，2604.09459）

- **推理 CA 在收敛**：过程奖励模型（PRM）+ 免 critic 的组比较（GRPO 系）成为主流——但 episode 级优势摊到每个 token 是粗糙近似；
- **Agentic CA 在开新枝**（无先例可循）：①**Turn-PPO**（EACL 2026）：turn=宏动作的 MDP 重构，token 级重要性采样→turn 级，方差爆炸消失；②**AgentPRM**：MC 步标注（要重跑环境，太贵）→ TD+GAE 训步级 critic，**样本效率 8×**；③**hindsight 反事实**/特权不对称 critic/HiPER 分层优势估计（HAE）；
- 判据清晰：**轨迹 100K-1M token 时 episode 级信用完全失真**——第 3 turn 的一个错误工具调用和后面几十个正确动作拿同样的惩罚。

### 3.2 TTRL 家族：三个月三代（无标签自进化赛道成型）

| 代 | 方法 | 核心创新 | 数字 |
|----|------|---------|------|
| 1 | **TTRL**（NeurIPS 2025） | 多数投票当奖励：N 个 rollout 投票→伪标签→GRPO 更新 | Qwen-2.5-Math-7B AIME **+211%**；**超越自身 maj@n 上限**，逼近"直接在测试集上训练"的泄漏上界 |
| 2 | **CoRE**（2608.09324） | 投票→**均衡**：rollout 建图（答案一致×推理相似×置信度），复制子动力学提主导集→分级奖励+内聚门控；多数投票是特例 | 42 格实验 +21.7 vs +20.4；**少 54-70% 步数到同平台**；正确少数派可翻盘错误多数（有阈值定理） |
| 2' | **SCRL**（ACL 2026） | **负伪标签**（TTRL 首个负监督）：熵门控识别"低频+高不确定"的确定错误轨迹→剪枝而不冒充正例 | 弱共识/低预算下显著稳于 TTRL |
| 3 | **Hi-TTRL**（2608.03545） | 不改奖励改**采样**：半批估共识强度→出界则 MCMC 提示采样器（幂变换目标：α>1 锐化收敛/α<1 扁平化探索）调控共识入区间 | 三 backbone 平均 +9.87/+7.40 点（Qwen-2.5-Math-1.5B） |

**评注**：这条线的哲学突破在于"**标签可以自己长出来**"——共识不是真理，但在线 RL 让伪标签质量与模型能力共同上升（正反馈）。风险同样清晰：confidently wrong 的多数派会自我强化（SCRL 要解决的就是这个）——**又是验证层级问题**（讲透Loop Ch03）：L2 级自生成信号的可靠性天花板。AlphaProof 的 TTRL（Nature 2025-11）是形式域版本：变体课程+Lean 判分=L5 级伪奖励，天花板完全不同——**验证层级决定 TTRL 的上限**，这条我们体系的定律在文献里全面应验。

### 3.3 世界模型换岗：从表示对象到 RL 提速器（WMRL，2608.12564）

- **张力**：AutoResearch 轨迹=生成（可 batch 共享算力）+执行（每条独占沙盒真机时间）——轨迹变长时**执行成为 RL 的 scaling 瓶颈**；
- **解法**：世界模型（同 backbone 的 LM 预测执行结果）替换真执行，奖励带偏置 B+噪声 σ；**Online Debiasing**（收缩偏置项 $O(B^2)/(1+T/T_0)$）+ **Inverse-Variance Denoising**（方差压到两流都低）——两个定理保证收敛严格优于真执行流；
- **数字**：训练加速 3-4×，4B/9B 后训练 agent 超 48B/120B 开源对照；迁移到 VLA 后训练成功。
- **体系连接**：这正是"模拟器层级"问题——世界模型=L3 级验证器（讲透Loop 阶梯），WMRL 的两个修正项就是"对不完美验证器的统计学补偿"。我们的 Prover harness 若上 RL（蒸馏规律→训练），Lean=L5 真执行贵→可加"编译结果预测器"做同款提速。

### 3.4 其他值得记的（一笔带过）

- **GRPO 第一性推导综述**（2606.16733）：统一 REINFORCE→PPO→GRPO→后继的全景由 $J(\theta)$ 两因子定位；识别"复合失败需两侧联合设计"——下一代算法的设计起点；
- **RL-PLUS**：混合策略（内部利用+外部数据+多重重要性采样修分布失配+探索优势函数）破 on-policy 能力边界；
- **Agentic RL 应用面**（2604.27859）：SWE 全仓管理/科研自动化/网页操作/GUI/具身——与 AgentRL 生态深读的六大框架对表吻合。

## 五、统一收口：一切 RL 是 IMPROVE 算子的实例

讲透Loop Ch08 的算子 $\mathcal{A}_{t+1}=\mathrm{IMPROVE}(\mathcal{A}_t;\mathcal{S}_t)$ 给出最终坐标系——**全部浪潮按（信号层级 × 改动深度）定位**：

| 系统 | $\mathcal{S}_t$ 信号 | 验证层级 | 改 $\theta$ 还是 $\Sigma$ |
|------|---------------------|----------|--------------------------|
| 经典 RL | 环境奖励 | L4（真环境） | $\theta$ |
| RLHF | 偏好模型 | L2-L3（学习的判官） | $\theta$ |
| RLVR/GRPO | 测试/编译器 | **L4-L5** | $\theta$ |
| Agentic RL | 环境反馈+工具结果 | L3-L4 混杂 | $\theta$ |
| TTRL-投票 | 自共识 | **L1-L2（自生成）** | $\theta$ |
| TTRL-形式（AlphaProof） | Lean 判分 | **L5** | $\theta$ |
| rl_agent v5 三进化环 | 检索质量/任务成败 | L3-L4 | **$\Sigma$**（零训练） |
| 发现引擎 T1-T4 | 五类机器 reward | L4-L5 交叉 | **$\Sigma$** |
| TTRL 的上限差异 | —— | **信号层级=自进化天花板** | —— |

三条体系定律（文献+自家实验互证）：
1. **信号层级决定自进化上限**（2607.07663 实证规律在 TTRL 家族完全应验：投票型天花板=共识可靠性，Lean 型=形式真理）；
2. **reward 必须编码真实价值**（T3 Goodhart：+193% 假产出/真成功 53→8.6；文献对应：reward hacking 全家）；
3. **探索的价值随动作空间贫瘠度上升**（T3 双空间对照；文献对应：Clip-Higher/熵维持成为标配的深层原因）。

## 六、批判与开放问题（2026-08 时点）

1. **TTRL 的自我确认风险**没有被理论化——CoRE 有阈值定理但没有"何时正反馈变死亡螺旋"的刻画；SCRL 的负标签是工程缓解非解。**开放问题：自生成信号的收敛/崩塌分界**（连接 2607.07663 验证层级，可形式化）。
2. **Agentic RL 的评估仍是无重之地**：AgentBench/WebArena 测能力不测"学习效率"（多少 episode 学会）；循环级评估（收敛/成本/漂移/升级质量）无人做——与我们 2608.21884 的判词同源，**是双方向的机会**。
3. **世界模型的误差传播**：WMRL 证明了带修正的收敛，但多轮复合误差（模型幻觉执行结果的累积）在长 horizon 上的界仍开放。
4. **$\theta$ 与 $\Sigma$ 的混合**：工业界全在 $\theta$ 侧（训练框架），我们全在 $\Sigma$ 侧（harness 进化）——**两侧混合的系统性研究不存在**（何时该训练、何时该改配置，成本-效果边界无人刻画）。rl_agent 的生态位判定"互补不竞争"其实是这个大空白的两半。
