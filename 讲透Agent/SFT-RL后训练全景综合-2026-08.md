## 要点速览（TL;DR）

1. **一句话总纲**：后训练的三种方法（SFT/RL/蒸馏）**不是三个菜单项，是同一个状态分布问题的三种解**——监督信号从哪来（数据/奖励/教师）× 施加在哪些状态上（数据分布/自身 rollout/学生 rollout）的两个自由度，2026 年的全部创新都在这两个轴上重新组合。
2. **2026 最大的单一事件：On-Policy Distillation（OPD）成为第三范式**——五家旗舰（Qwen3/DeepSeek-V4/Kimi K3/MiMo-V2/GLM-5）独立把它放上关键路径：学生采自己的轨迹，教师逐 token 打分。一句话定位：**能力创造靠 RL，能力迁移靠 OPD，冷启动靠 SFT**。
3. **反直觉发现（PEAR）**：更强的 SFT checkpoint 在同配方 RL 后可能**更差**——SFT 阶段单独优化是代理指标，离线-在线分布失配是根因；"好的 SFT 为 RL 做准备，不是为 SFT 评分做准备"。
4. **我们体系的接线**：状态分布观=讲透Context/KV Cache 谱系的训练版；"SFT=Extend/RL=Recall"与 T3 的空间贫瘠度定律互证；Prover 蒸馏十条规律是我们自己的 OPD 前置经验。

## 二、统一框架：状态分布观（2605.22731，本年度最优雅的后训练理论）

一切后训练方法 = 在**哪个状态分布上施加什么监督**：

$$\mathcal{L} = \mathbb{E}_{s \sim q}\ \mathbb{E}_{z \sim \text{信号}(s)}\ [\ell_\theta(z \mid s)]$$

| 方法 | 状态分布 $q$ | 监督信号 $z$ | 一句话 |
|------|-------------|-------------|--------|
| **SFT** | 固定数据分布 $d_{\text{data}}$（离线） | ground-truth token（稠密） | 在别人的状态上模仿 |
| **RL** | 自身 rollout $d_{\pi_\theta}$（在线演化） | 标量奖励（稀疏） | 在自己的状态上试错 |
| **离线蒸馏** | 教师轨迹分布 | 教师 token/logits | 在教师的状态上模仿 |
| **OPD** | **学生自身** $d_{\pi_S}$ | **教师逐 token 分布**（稠密） | 在自己的状态上听课 |
| 拒绝采样 SFT | 数据 prompt + 自身采样过滤 | 幸存 token | RL 的信号+SFT 的损失（桥） |

三个实验现象钉死这个框架（Qwen3-0.6B 受控）：
- **温和 SFT 不遗忘，压力 SFT 大遗忘**——off-policy 压力把模型推离自身分布是破坏源（不是梯度本身）；
- **OPD 能超越退化的教师**——学生只在自己到达的状态上问教师，自动绕开教师的"坏街区"（全局差但局部好的教师仍有可教的）；
- **RL 天然保泛化**——on-policy 局部改进，漂移发生在自己会到达的地方。

**与我们体系的对接**：状态分布=讲透Context 的"上下文"在训练侧的镜像；OPD"学生自己的状态+教师的监督"正是讲透Loop maker-checker 分离在训练目标上的形态。

## 三、管线编年史：从两阶段到五阶段

```
2020  InstructGPT：SFT → RLHF(PPO)              两阶段定型
2023  Llama2：拒绝采样+SFT 迭代；DPO 去 RM       数据侧发力
2024  蒸馏冷启动（R1-Distill：教师轨迹 SFT）      三阶段：SFT→RL→SFT
2025  R1 证明纯 RL 可行；SFT-then-RL 成默认      阶段分工明确化
2026  五阶段旗舰标配：                            Qwen3 四阶段/GLM-5 四段
      长CoT冷启动SFT → 推理RL → 模式融合SFT → 通用RL
      + OPD 插位分化（见 §四）
```

**阶段分工的机理定版**（2606.04466 阶段专用数据）：
- **SFT = Extend（扩界）**：教还没掌握的推理模式（教师 CoT 引入新模式）；
- **RL = Recall（收拢）**：放大已部分可达的能力（非零奖励样本才有用）；
- 数据按难度分流：SFT 用 medium→hard 课程（hard 经 Bridge 机制改造——按重要性/跳跃度/难度做 keep/expand/compress/drop）；RL 用非全零样本；**全零失败样本回炉** Critique Fine-Tuning（诊断+修复+新轨迹进下轮 SFT）——SFT 与 RL 之间形成数据循环。

## 四、2026-08 核心增量

### 4.1 OPD 第三范式：五旗舰的自然实验

| 模型 | OPD 用法 | 关键细节 |
|-------|---------|---------|
| **Qwen3** | 轻量线（0.6B-14B）整管线替换为 strong-to-weak 蒸馏 | **1/10 GPU 时数**超四阶段成绩；先离线冷启动对齐思考模式 |
| **DeepSeek-V4** | **关键路径替换**：混合 RL 阶段整体换成多教师 OPD | 10+ 域专家（各自 SFT+GRPO 训出）合并回单模型 |
| **Kimi K3** | 9 专家（3 域×3 推理力度）→MOPD 合并 | 力度=RL 时 token 预算控制（超 τ×预算记 -1，退火 τ 出低中高档） |
| **MiMo-V2-Flash** | 命名 MOPD 并定位为范式 | 三段：通用 SFT→域教师 RL→MOPD 合并 |
| **GLM-5** | **链末修复段**：三段 RL 后累积退化→用各段末 checkpoint 当教师做跨阶段 OPD | 修复序列 RL 的能力侵蚀 |

**判词**（原文最清醒的一句）：**没有一个旗舰用 OPD 替代 RL——能力创造仍靠 RL，OPD 做能力迁移与合并**。Tsinghua 反思给了失败条件：①师生思考模式需兼容（同族 1.5B↔7B 在 token-KL 尺度上几乎不可分——基准分高≠分布上有新东西可教）；②教师须有学生未见过的真能力。修法：模式不兼容先离线冷启动；教师没新货就只选"教师会对学生错"的 prompt。

### 4.2 PEAR：SFT 优化的目标错了（2602.01058）

- **发现**：同配方 RL 后，更强 SFT 初始化可能输给更弱的（秩反转）——SFT 精度是 RL 后表现的**不可靠代理**；
- **根因**：行为策略（数据分布）≠ 目标策略（自身 rollout）的占用度失配——offline-to-online RL 的老问题在 LLM 复活；
- **修法**：OPE 启发的重要性重加权（token/block/sequence 三档）——把当前策略下不可能的延续降权、可能的升权，SFT 目标对齐 RL 将实际访问的前缀；**AIME-2025 pass@8 +14.6%**；
- **原则**：离线阶段应优先固化"目标策略可复现的成功"，不是最大化离线精度。

### 4.3 其他值得记的

- **BRIDGE**（双层优化 SFT+RL）：SFT 当 leader 预测 RL 的最优响应，LoRA 参数走上层/基模走下层——交替训练已胜两阶段，双层再胜交替；
- **推理数据 primer**（2606.02113，150 篇）：数据>算法的定版论证；**归因框架**（正确性=验证器相对/难度=基模相对/轨迹质量=轨迹相对/覆盖=血统相对——四个"好数据"都是条件化的）；天花板 vs 路径的分野（数据底座/验证器质量/支撑覆盖移天花板；损失设计/采样/课程改路径效率）——与预训练综合的 InfoLaw 呼应；
- **实践共识**（O'Reilly/Baseten 两篇工程文）：SFT 教分布/RL 教策略；**90% 团队的最短路径是"高质量 in-distribution 数据+真验证器+SFT/蒸馏迭代"，RL 是天花板突破器不是默认件**；混合配比实证（Qwen2.5-Coder 70:20:10 正迁移；绝对量>比例；先专后混优于平混）；
- **合成数据疆域**（RLHF book ch12）：指令 SFT 已被蒸馏全面攻陷（模型超人类写作可靠度）；偏好数据人类仍是护城河；**Cursor Composer 的特权信息自蒸馏**（判官在 RL 轨迹插 hint token 再上 KD 损失）是 OPD×RL 混合的工程标本。

## 五、方法选择决策树（综合五源的一页答案）

```
你能收集到高质量 in-distribution 演示吗？
├─ 能 ──→ SFT（+拒绝采样迭代）──→ 达标就停
│         └─ 需要更强 ──→ 有白盒教师？──→ OPD（学生 rollout+教师逐 token）
│                                    └─ 黑盒 ──→ 蒸馏变体（偏好信号/GAN 式）
└─ 不能，但能廉价可靠地验证 ──→ 先用验证器筛数据做 SFT（iterative SFT/RGT）
                              └─ 收益递减后 ──→ RL（RLVR/GRPO）
                                               └─ 需合并多个专家/修复链式退化 ──→ MOPD
小模型注意：教师 CoT 太长太难会 Long CoT Degradation
            ──→ Bridge 改造（按跳跃度压缩/展开）再进 SFT
```

## 六、统一收口：后训练是 IMPROVE 算子的训练侧实例

接 RL 综合的算子表，后训练三方法同表入座：

| 方法 | $\mathcal{S}_t$ | 改动对象 | 验证层级 |
|------|----------------|---------|---------|
| SFT | 数据 token | $\theta$ | L4（数据=人类/教师验证过的事实） |
| RL | 环境奖励 | $\theta$ | L4-L5（RLVR）/ L2-L3（RM） |
| OPD | 教师逐 token 分布 | $\theta$ | **L3（教师=判官）但作用在学生状态上** |
| **Prover 蒸馏十条** | 24 题轨迹+Lean 验证 | **$\Sigma$（规律/prompt）** | **L5（轨迹经 Lean 锚定）** |
| rl_agent 三进化环 | 检索质量/任务成败 | $\Sigma$ | L3-L4 |

**三条本仓库定律在后训练域的再次应验**：
1. 信号层级定律：OPD 教师质量=迁移上限（Tsinghua 同族不可分现象）；R1 蒸馏>小模型自 RL（DeepSeek 自报）在"教师够强"前提下的另一面；
2. 代理指标定律：PEAR 的秩反转=SFT 精度这个代理背叛了 RL 后真值——**与 T3 Goodhart（+193% 假产出）同构**：优化局部指标必然在全局指标上翻车，除非两者分布对齐；
3. 状态分布定律（新增，本篇提炼）：**监督的施加分布比监督的形式更根本**（2605.22731）——同损失不同 $q_k$ 天差地别；这正是讲透Context"放进去≠用得上"的训练版：**"在哪个状态上学"≠"学到什么"，但决定"学完在哪能用"**。

## 七、批判与开放问题

1. **OPD 的理论空白**：五旗舰都在用，但"何时教师有真新货"只有 Tsinghua 的必要条件（无充分条件）——**能力可迁移性的形式化刻画不存在**（连接 2607.07663 验证层级：教师判分是 L3，其可靠性天花板未定）；
2. **SFT-RL 管线的联合最优没人做**：PEAR/BRIDGE 都是单点修复；**阶段间的数据-目标-超参联合优化**（预训练综合的"三层双层优化"姐妹问题）是空白；
3. **阶段数膨胀 vs 理论空转**：旗舰管线已到 4-5 阶段，每段的存在理由多为工程叙事（GLM-5 的修复段=承认序列 RL 有累积退化，但退化本身的机理无理论）；
4. **评测与数据的循环依赖**：primer 指出"好数据"全部条件化于（基模,验证器,预算）——但换基模结论翻转的转移性研究刚起步（与预训练综合 D1 痛点同源）。
