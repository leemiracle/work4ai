# 01 — Few-shot 与 In-Context Learning

> 00 篇说 prompt 是控制信号。这一篇讲 prompt 工程最反直觉的能力：**只在 prompt 里放几个例子，模型就能学新任务——而且不更新任何权重**。这叫 In-Context Learning（ICL），是 GPT-3 之后大模型最神奇的能力之一。
>
> 配套实验：`experiments/01_few_shot.py`。

---

## 1. Zero-shot vs Few-shot

| | 不放例子 | 放几个例子 |
|---|---|---|
| 名称 | **Zero-shot** | **Few-shot** |
| prompt | 只有指令："判断情感" | 指令 + 例子里："好看→正面，难看→负面" |
| 依赖 | 模型预训练时见过类似任务 | 模型从例子当场学 |

Few-shot 的"例子"就是 00 篇说的 prompt 三要素之一。

---

## 2. ICL 的奇迹：不更新权重学新任务

这是 ICL 最反直觉的点。对比两种"学新任务"的方式：

| | 微调 | ICL |
|---|---|---|
| 怎么学 | 用数据更新权重 | 把例子塞进 prompt |
| 改了什么 | 模型参数 | **什么都没改** |
| 速度 | 几千~几万步训练 | 一次前向 |
| 持久性 | 永久写入权重 | 临时，推理完就忘 |
| 多任务 | 每个任务存一份权重 | 每个任务换一组例子 |

**ICL 是"用上下文代替梯度"**：同一个模型，塞不同例子就能做不同任务，权重始终不变。

### 实验（`01_few_shot.py` Part 1，最近邻类比模拟）

```
Few-shot 例子: 好看→正面, 难看→负面, 精彩→正面, 无聊→负面...
新输入判断(从相似例子推断):
  '精美' → 正面 (从'精彩/漂亮'推断)
  '难听' → 负面 (从'难看/难吃'推断)
```

> ⚠️ 诚实说明：本实验用"最近邻"类比模拟 ICL（找最相似的例子）。真实 LLM 的 ICL 不是简单最近邻，而是内部多层注意力的复杂计算。且最近邻粗糙——"乏味"被判正面（应负面）就是局限。但"从上下文例子学"的核心机制一致。

---

## 3. ICL 是涌现能力（小模型不会）

GPT-3 论文（2020）的关键发现：

- 小模型（<6B）的 Few-shot 效果**接近随机**——学不会从例子学。
- 模型到 ~13B 后，Few-shot 准确率**突然飙升**。

**ICL 是涌现能力**（呼应《讲透基础模型》03）。不是"模型越大 Few-shot 越好"的平滑提升，而是过了阈值才有。

### 机制：Induction Head（Olsson et al. 2022）

Anthropic 的机制可解释性研究发现：大模型训练中会**突然形成一个叫"归纳头"的电路**，它做的事是**前缀匹配**——

> 看到 prompt 里 `[A]→[B]`，后续遇到 `[A]` 就倾向输出 `[B]`。

这个电路一旦形成，ICL 就出现。这是少有的"涌现能力有明确机制解释"的案例。

---

## 4. Few-shot 设计要点

1. **例子要代表性**：覆盖任务的主要模式（正负例都要）。
2. **例子顺序影响输出**（recency bias）：放后面的例子影响更大。
3. **例子格式要统一**：模型会模仿格式，格式混乱则输出混乱。
4. **例子数量**：3–5 个常够；太多占上下文且边际收益递减。
5. **负例很重要**：只给正例模型不知道"不该做什么"。

---

## 5. ICL 的局限

1. **上下文长度限制**：例子占 token，长任务放不下太多。
2. **推理时才学**：每次推理都要重放例子（比微调慢、贵）。
3. **不如微调精准**：复杂/高频任务，微调固化能力更稳。
4. **依赖模型规模**：小模型不会 ICL。

**何时用 ICL**：快速原型、低频任务、多任务切换、不想训练。**何时改微调**：高频生产任务、要极致精度、任务固定。

---

## 6. 一句话总结

> **Few-shot 在 prompt 放几个例子，模型通过 In-Context Learning 当场学新任务——且不更新任何权重（用上下文代替梯度，区别于微调的永久写入）。ICL 是大模型的涌现能力（小模型不会，~13B 后突现），机制是内部形成的'归纳头'做前缀匹配。Few-shot 适合快速原型/多任务切换，高频精准任务仍该微调。**

---

## ✍️ 练习（`01_few_shot.py`）

1. **例子数量**：把例子从 7 个减到 2 个，看准确率如何变化——感受"例子代表性 > 数量"。
2. **负例作用**：只留正面例子，看模型能否判断负面——理解负例的必要性。
3. **真实 ICL**：在豆包/DeepSeek 上试 Few-shot（放3个情感例子），看大模型的真实 ICL 比本实验的最近邻准多少。
