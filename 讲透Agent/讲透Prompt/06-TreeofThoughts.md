# 06 — Tree of Thoughts：搜索式推理

> 「讲透 Prompt」第七篇。05 讲 Self-Consistency（并行采样）。本篇讲 **Tree of Thoughts（ToT）**——把推理变成**树搜索**：每步分支、评估、剪枝、回溯。这是把"下棋的搜索"搬到语言推理上。

---

## 1. 灵魂：推理 = 搜索

$$
\boxed{\text{ToT} = \underbrace{\text{思维节点}}_{\text{每个是一个推理状态}} + \underbrace{\text{分支}}_{\text{多个可能下一步}} + \underbrace{\text{评估}}_{\text{LLM 当裁判}} + \underbrace{\text{搜索}}_{\text{BFS/DFS}}}
$$

---

## 2. CoT → SC → ToT 的演化

| 方法 | 结构 | 搜索 | 成本 |
|---|---|---|---|
| CoT | 一条链 | 无（贪心）| 1× |
| Self-Consistency | $K$ 条独立链 | 无（投票）| $K$× |
| **ToT** | **一棵树** | **BFS/DFS + 剪枝** | $\sim K^d$× |

ToT 的关键：**每步评估**哪些分支有前途，剪掉差的，深挖好的。

---

## 3. ToT 的四步循环

```
1. 分解（Decompose）：把问题拆成思维步骤
2. 生成（Generate）：每个状态生成 B 个候选下一步
3. 评估（Evaluate）：LLM 给每个候选打分（"有前途/不确定/没前途"）
4. 搜索（Search）：BFS（广度优先，留 top-B）或 DFS（深度优先，可回溯）
```

### 实例：24 点游戏

用 3, 7, 8, 8 凑出 24：

```
状态: [3,7,8,8]
  ├─ 8-3=5 → [5,7,8]        评估: 有前途（接近）
  │    ├─ 8-5=3 → [3,7]     评估: 不确定
  │    └─ 7+5=12 → [8,12]   评估: 有前途
  │         └─ 12×8=96 ✗    回溯
  │         └─ 12/8=1.5 ✗   回溯
  ├─ 8/8=1 → [1,3,7]        评估: 没前途（剪枝）
  └─ 7-3=4 → [4,8,8]        评估: 有前途
       └─ 8×(8-4)... 最终找到 8/(8-7/3)=24? 验证...
```

**关键**：CoT 一条路走到黑，ToT 能**回溯**换路。

---

## 4. 什么时候 ToT 值得

| 场景 | ToT 值得吗 | 理由 |
|---|---|---|
| 数学题（有验证）| ✅ | 能判断对错，搜索有效 |
| 创意写作 | △ | "好坏"主观，评估难 |
| 代码生成 | ✅ | 能跑测试验证 |
| 闲聊 | ❌ | 杀鸡用牛刀 |

**经验**：ToT 在**有明确成功标准 + 搜索空间大**的任务上最强（24 点、填字、规划）。

---

## 5. 局限

- **成本爆炸**：$K^d$ 的分支因子，深度 $d$ 一大就爆炸
- **LLM 评估不准**：剪枝依赖 LLM 自己判断"哪条路好"——它可能误判
- **不如 RL**：ToT 是"用 prompt 模拟搜索"，但真正的搜索（AlphaGo 式 MCTS）需要价值函数，LLM 当裁判只是近似
