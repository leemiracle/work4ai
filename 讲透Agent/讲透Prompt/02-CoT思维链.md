# 02 — CoT 思维链：分步推理为何更准

> "让我们一步步思考"这几个字，能让模型数学准确率翻倍。这一篇讲透 CoT（Chain-of-Thought）为什么有效、何时有效、何时无效。
>
> 配套实验：`experiments/02_cot.py`。

---

## 1. CoT 的本质：分治

CoT 不是玄学，它的本质是**分治**——把一次复杂推理，拆成多次简单推理。

### 数学类比（实验 Part 1）

算 $17 \times 24$：
- **直接算**：一步得出 408（要同时处理多位，认知负荷大，易错）。
- **分步算**：$17\times24 = 17\times20 + 17\times4 = 340 + 68 = 408$。每步都是简单运算。

CoT 就是让 LLM 走"分步"路线。

---

## 2. 从 token 预测看 CoT 为何有效

LLM 是 token-by-token 预测。看应用题"5个苹果吃了2个又给3个，现在几个？"：

- **直接答**：输入[问题] → 预测 "6"。这一步要把 5/−2/+3 全部综合，单次预测信息密度高，$P(\text{6}|\text{问题})$ 可能不高。
- **CoT 答**：输入[问题] → 预测 "5−2=3" → 预测 "3+3=6"。每步只做简单运算，$P(\text{3+3=6}|\text{前文})$ 高。

**CoT 把"一次难预测"拆成"多次易预测"**，每步条件更充分。额外好处：中间步骤写进上下文，后续步骤能"看到"（等于扩展了有效计算）。

---

## 3. CoT 是涌现能力（小模型无效）

Wei et al. 2022（Chain-of-Thought Prompting）发现：

- **小模型（<10B）**：CoT 几乎无效，甚至比直接答更差（分步引入错误）。
- **大模型（~60B+）**：CoT 在数学/逻辑/多步推理上大幅提升。

```
GSM8K 数学题准确率:
  PaLM-540B 直接答 18%  →  CoT 56%   (提升 3 倍)
```

为什么是涌现？推理需要模型"维持中间状态 + 按规则推演"，这需要足够容量。呼应《讲透基础模型》03——CoT 推理是**真实的相变**（非度量幻觉）。

---

## 4. Zero-shot CoT：一句咒语

Kojima et al. 2022：不放示范，只在问题后加一句 **"Let's think step by step"**：

```
GSM8K 准确率 (GPT-3.5): 直接 17% → 加这句 60%+
```

仅仅触发"分步模式"，模型就自发展开推理。**这是最便宜的性能提升之一**。

---

## 5. 局限：CoT 不是万能

1. **消耗更多 token**：分步输出长，推理更贵更慢。
2. **不适合简单/事实任务**：事实检索、简单分类，CoT 无益甚至干扰。
3. **可能编造推理链**：模型有时先有答案再补"看似合理"的步骤（rationalization），推理链不可信。
4. **小模型无效**：必须大模型。

**适用**：多步推理（数学/逻辑/规划/代码调试）。**不适用**：事实问答、简单分类、单步任务。

---

## 6. 一句话总结

> **CoT 的本质是分治——把一次复杂推理拆成多次简单推理，每步 token 预测条件更充分，所以更准。它是大模型的涌现能力（小模型反而变差，GSM8K 上 PaLM 18%→56%）。Zero-shot CoT 仅靠"一步步思考"一句就能大幅提升。CoT 适合多步推理，不适合事实检索/简单任务，且推理链可能被编造（不能盲信）。**
