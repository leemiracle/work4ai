## §0 全局视角：Prompt = "不动权重的编程"

```
传统编程: 改代码
微调:     改权重
Prompt:   改输入 ← 不动模型本身
```

> 🔑 **核心 DNA**：**Prompt engineering 是"用自然语言编程 LLM"**——这是 LLM 时代最反直觉的能力：**改输入比改模型更高效**。

## §1 十条算法经验

### 算法经验 P1：In-Context Learning = 不更新参数的学习

> Few-shot examples 让模型在**推理时**学会任务，参数不变。
>
> 算法本质：**ICL 是隐式的梯度下降**（Akyürek et al. 2022 证明）——attention 在前向里"学"。
>
> 可迁移：**这是 ML 的反直觉——通常学习要反向传播，ICL 却纯前向**（应用 A2 attention=核回归、TR1 三视角）。

### 算法经验 P2：CoT = 显式展开中间状态（强化 Ch9 §4.2）

> Chain-of-Thought 让模型显式输出推理步骤：
> ```
> Q: ...
> A: Let's think step by step.
>    第一步: ...
>    第二步: ...
>    所以答案: X
> ```
>
> 算法本质：**CoT 把"隐式多步推理"展开成"显式单步序列"**——更多 token = 更多计算 = 更准（应用 Ch9 test-time compute）。

### 算法经验 P3：Few-shot 的"模板"决定能力

> 同样数据，不同模板，效果差几倍：
> ```
> 差: Input: X Output: Y
> 好: ### 任务: 翻译\n原文: X\n译文: Y
> ```
>
> 算法本质：**模板定义了"任务函数"——LLM 在执行模板，不是理解任务**（应用 A4 mask 定义任务、FT8 SFT 格式）。

### 算法经验 P4：Self-Consistency = 采样多样性投票（强化 R7 排名融合）

> 生成 N 条不同推理链，多数投票：
> $$\hat{a} = \text{majority\_vote}(a_1, a_2, \ldots, a_N)$$
>
> 算法本质：**用多样性换鲁棒性**——同款思想出现在 RAG 的 RRF（Ch11）、RL 的 ensemble、推荐的多路召回。

### 算法经验 P5：Tree of Thoughts = 显式搜索（强化 AG4 规划）

> ToT 把推理建模为树搜索：
> - 每步生成多个候选
> - 评估每个候选的"价值"
> - BFS/DFS 搜索最优路径
>
> 算法本质：**CoT 是贪心，ToT 是搜索**——这是把符号 AI 的搜索算法移植到 LLM（应用 C1 CKY 区间 DP、AG4 规划树）。

### 算法经验 P6：ReAct = 推理 + 行动（强化 AG1）

> ReAct 交替 Reasoning（思考）和 Acting（调工具）：
> ```
> Thought: 我需要查 X
> Action: search("X")
> Observation: ...
> Thought: 现在...
> ```
>
> 算法本质：**ReAct 是 Plan-Execute 范式的 LLM 实现**——把"决策"显式化（应用 AG1 三范式、D1 transition=MDP）。

### 算法经验 P7：结构化输出 = 用 schema 约束生成

> 用 JSON schema / function calling 约束 LLM 输出：
> ```python
> response = llm(prompt, response_format=ResponseModel)
> ```
>
> 算法本质：**用语法约束生成，类似编译器的 parser**——避免自由生成的随机性（应用 C2 符号 vs 子符号、E4 SRL 谓词中心）。

### 算法经验 P8：Prompt 安全 = 输入侧防御

> 攻击：prompt injection、jailbreak、prompt leak
> 防御：
> - **输入过滤**（敏感词、模式匹配）
> - **指令层级**（system > user）
> - **输出审查**（再过一次 LLM）
>
> 算法本质：**Prompt 是"代码"，所以会有代码注入**——同款思想在 SQL 注入、XSS（应用 G6 评估-纠错）。

### 算法经验 P9：Prompt 的"测试时计算"维度（强化 Ch9 test-time）

> Prompt 工程本质是**调整 test-time compute**：
> - **更多 token**（CoT）= 更多计算
> - **多次采样**（Self-Consistency）= 更多计算
> - **搜索**（ToT）= 更多计算
>
> 这与 Ch9 §4 test-time compute 完全一致。

### 算法经验 P10：Prompt 范式演化 = 从手工到自动

> 1. **手工 prompt**（2020）：人工写模板
> 2. **AutoPrompt**（2021）：梯度搜索 prompt
> 3. **Soft Prompt**（2022）：可学习 embedding
> 4. **DSPy**（2023）：自动优化整条 pipeline
>
> 趋势：**从"手工调"到"自动优化"**（应用 OP3 SGD、AG5 反思）。
