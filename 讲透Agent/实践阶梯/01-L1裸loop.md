# 01 · L1 裸 Loop：三版对照实验

> L1 的目标：**100 行级最小 agent**，用对照实验验证 00 章的矫正分层是否成立。
> 核心发现两条：few-shot 的适用边界；金标准粒度歧义毁掉精确匹配指标。

## 一、最小 agent 闭环是什么

单次 LLM 调用不是 agent。加上**工具（校验器）+ 反馈（问题清单拼回 prompt）+ 重试**，就构成了最小闭环：

```
用户句子 → [生成] → JSON → [校验工具：枚举/塌缩/接地三查]
                                    │ 通过 → 事实入库
                                    ↓ 不通过
                          [问题清单拼回 prompt] → [再生成 ×1] → 再校验
```

这就是 L1 的 C 版。代码：[experiments/01_l1_bare_loop.py](./experiments/01_l1_bare_loop.py)（约 150 行，纯 transformers，无任何 agent 框架——**证明 agent 不需要框架，需要的是循环+工具+校验**）。

## 二、三版设计

| 版 | 矫正手段 | 修的层 |
|---|---|---|
| A | 裸指令（复现基线） | — |
| B | +3 个 few-shot 示例（锚定"fact=具体内容"、演示无事实句输出空数组） | 语义层 |
| C | B + 校验器（枚举查/塌缩查/证据接地查）+ 反馈修复重试×1 | 语义+行为层 |

校验器三查（后续所有实验复用，定义已抽到 [fact_agent.py](./experiments/fact_agent.py)）：
1. **枚举查**：category ∈ {日程,账单,人际,档案,健康}
2. **塌缩查**：fact 不是标签词黑名单（"日期/事件/金额"…）且长度>2
3. **证据接地**：fact 必须是原句子的子串——**这是反幻觉的硬闸门**：任何编造的事实（不在原句里）直接丢弃

## 三、实测结果（2026-08-24，容器 96核CPU，贪心解码，n=10）

| 版 | json_rate | cat_ok | collapse(处) | grounded | ★pass | retry |
|---|---|---|---|---|---|---|
| A 裸指令 | 9/10 | **1/10** | **9** | 8/10 | 0/10 | 0 |
| B +few-shot | 10/10 | 6/10 | **0** | 5/10 | 0/10 | 0 |
| C +校验+重试 | 10/10 | 7/10 | 0 | 6/10 | 0/10 | 8 |

（原始日志 [experiments/l1.log](./experiments/l1.log)，261s 总耗时）

## 四、三个发现

### 4.1 few-shot 是特效药，但有边界

**塌缩 9→0**：三个示例就把"输出标签词"的病根治了（示例展示了"fact 长什么样"，模型模仿的是格式深层结构而不只是 JSON 语法）。**cat_ok 1→6**：示例顺带锚定了合法类别词。这与 00 章预测一致：语义层的病优先用语义层的药（示例），而不是语法层的药（约束解码）。

但 **grounded 5/10 < A 版 8/10**：few-shot 后模型开始输出更长的 fact（更具体），长 fact 更容易不是原子生子串（如模型写"周四上午体检"而原句是"体检预约在周四上午"）。**矫正一层可能损伤另一层**——多层指标必须同时看，单一指标优化会被 Goodhart。

### 4.2 修复重试收益有限（6→7），但 retry=8 说明校验器抓到了真问题

重试后 8 次里只有 ~1 次救回。0.5B 面对"你上次输出的问题是X"这种 meta 反馈，修正能力弱（它经常原样重写或换个方式错）。**教训：小模型上，防（few-shot/校验丢弃）优于治（反馈修复）**。重试保留但期望值要压低——这一条直接写入 00 章速度预算（重试≤1）。

### 4.3 pass 全线 0/10：金标准粒度歧义（L1 最大教训）

例："这个月电费已经交过了，一共137块"——抽 1 条（"这个月电费已交137块"）还是 2 条（"电费已交"+"金额137块"）**都对**。我标 gold_n=2，模型抽 1 条合并事实 → 判死。pass=0 不是模型烂，是**裁判的尺子有刻度歧义**。

> agent 评估的第一课：金标准的粒度必须有唯一解，否则精确匹配指标测的是标注者的口径而不是系统的能力。
> 修订（已落 [fact_agent.py](./experiments/fact_agent.py) 的 judge）：pass=类别多重集匹配+全接地+无事实句不编造；数量偏差降级为过程指标。

## 六、不足与批判

- n=10 太小，结论方向性可信、数值不可信 → L3 扩到 30
- 贪心解码掩盖了采样方差，但也意味着结论只对贪心成立
- few-shot 示例是手挑的 3 条，未做示例敏感性消融（换示例会怎样？→ L3 可扩展）
- 塌缩黑名单 GENERIC 是手写清单，覆盖有限
