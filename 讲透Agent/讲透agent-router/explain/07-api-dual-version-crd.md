# 07 · api/ 双版本 CRD 与生成客户端：整个系统的语言层

## 一、角色定位

`api/` 是 Agent Router 的语言：AIGatewayRoute/AIServiceBackend/BackendSecurityPolicy/GatewayConfig/MCPRoute 五种 CRD 声明"路由到哪、说哪种方言、用哪套凭证"。API group 固定 `aigateway.envoyproxy.io`（api/v1beta1/doc.go:10 的 `+groupName`）。双版本并非超集关系：v1alpha1 已整体打弃用警告（api/v1alpha1/ai_gateway_route.go:36）但 QuotaPolicy 只注册在 v1alpha1（api/v1alpha1/registry.go:21），v1beta1 则独有 MCPRoutePrefixMode。这一层几乎全是类型+CEL 标记，但"声明即约束"——大量非法配置在进 controller 之前就被 apiserver 拦下。

## 二、内部结构

**AIGatewayRoute（ai_gateway_route.go:37）**：ParentRefs CEL 只许 Gateway（ai_gateway_route.go:62）；Rules 上限 15 条（ai_gateway_route.go:96），注释说预留一格给 controller 注入的 catch-all；规则级 CEL 三连（ai_gateway_route.go:213）：保留名 `route-not-found`、InferencePool 与 AIServiceBackend 不可混用、每规则至多一个 pool；BackendRef 指定 group 只认 `inference.networking.k8s.io/InferencePool`（ai_gateway_route.go:325）；ModelNameOverride（ai_gateway_route.go:368）是模型改写钩子。路由级 LLMRequestCosts（ai_gateway_route.go:208）的大段注释演示了与 Envoy Gateway BackendTrafficPolicy 的 cost.Metadata 配合做按 token 限流。

**AIServiceBackend（ai_service_backend.go:28）**：APISchema 必填（ai_service_backend.go:59）；CEL 强制 BackendRef 是 Envoy Gateway 的 Backend 资源（ai_service_backend.go:68，注释指向 issue #902——k8s Service 尚未支持）；HeaderValueFilters 只对 GCPAnthropic/AWSAnthropic 生效（ai_service_backend.go:49）。

**VersionedAPISchema（shared_types.go:19）**：Name 十枚举（shared_types.go:22），Prefix 注释举例 Gemini `/v1beta/openai`、Cohere `/compatibility/v1`；模型头 `x-ai-eg-model`（shared_types.go:108）与元数据命名空间 `io.envoy.ai_gateway`（shared_types.go:172）也在此；LLMRequestCost 七类型+CEL（shared_types.go:121，06 篇已拆）。

**BackendSecurityPolicy（backendsecurity_policy.go:37）**：六种 Type（backendsecurity_policy.go:19）；六条互斥 CEL 保证"一种 policy 一种凭证"（backendsecurity_policy.go:50）；Azure 二选一（backendsecurity_policy.go:237）；AWS 侧 file/OIDC 都可缺省，注释（backendsecurity_policy.go:274）写明走 SDK 默认链（env→Pod Identity→IRSA→EC2 metadata）；OIDC 换临时凭证需 AwsRoleArn（backendsecurity_policy.go:331）；CredentialOverride 恰好一个源（backendsecurity_policy.go:356），默认头名 `x-aigw-*` 按类型逐个列出（backendsecurity_policy.go:374）。

**GatewayConfig（gateway_config.go:40）**：经 Gateway 注解引用；GlobalLLMRequestCosts 按 metadataKey 去重（gateway_config.go:82）；MetadataForwardingNamespaces（gateway_config.go:111）决定 Envoy 转发哪些动态元数据给 extproc（credentialOverride.fromDynamicMetadata 的前提）；ForwardProxy 劫持全部出网（gateway_config.go:115）。

**beta 增量**：MCPRoutePrefixMode 枚举 Always/Never（mcp_route.go:25），`<backendName>__` 前缀防工具名冲突，按后端覆盖是逃生舱（mcp_route.go:29）。**手写 helper**：默认请求超时 60s 覆盖 EG 的 15s（ai_gateway_route_helper.go:17）；IsCrossNamespace（ai_gateway_route_helper.go:111）供 controller 复用。

**生成物**：`make apigen` 先 controller-gen object 生成 deepcopy、再产 CRD 清单落进 crds-helm（Makefile:105）；`make codegen` 用 client-gen 三件套（Makefile:130），plural-exceptions 把 BackendSecurityPolicy 特判复数（Makefile:137）。clientset 入口 `AigatewayV1beta1()`（clientset.go:22），首行 `Code generated by client-gen. DO NOT EDIT.`（clientset.go:6）。

## 三、外部连接

- **internal/controller**：全部 reconciler 直接 import 两版本类型，gateway.go 翻译吃 CRD 吐 filterapi（08 篇）。
- **tests/crdcel**：84 文件逐一验证上述 XValidation 行为。
- **生成客户端真实消费面（勘误）**：grep 全仓实证 `api/*/client` 的 clientset/informers/listers 在 cmd/internal/tests **零引用**——controller 走 controller-runtime `mgr.GetClient()`（controller.go:121），e2e 走 kubectl apply（e2elib.go:194），aigw run 用 `k8s.io/client-go/kubernetes/fake`（run.go:33）。ONBOARDING ②节 L04"controller、e2e 与 aigw CLI 都经它读写"与代码不符，78 个生成文件目前是可用未用资产。
- **extensionserver**：直接 Get AIGatewayRoute 打 xDS 补丁（post_translate_modify.go:340）。

## 四、数据流

apply 一份 v1beta1 AIGatewayRoute：apiserver 按 CRD 清单做 structural schema+CEL 校验（pool 混用直接 422，无需 webhook）→ controller watch 进 08 篇总装线。改类型标准流：改 api/*.go → `make apigen`（deepcopy+CRD 进 chart）→ `make codegen`（客户端）→ `make apidoc`（site 文档）；三者在 CI precommit 全挂（Makefile:46），缺一步生成物即漂移。

## 五、设计决策

1. **约束前移 CEL**：互斥、pool 排他、Backend 强类型写在 CRD 里一行拦下，省 webhook 运维；复杂校验（多 BSP 挂一后端）仍留 controller（gateway.go:1200）。
2. **双版本不对称是过渡态**：方向是"类型收敛到 beta、alpha 只剩未稳定特性"（QuotaPolicy），与 ONBOARDING ⑦-3 一致——别假设 beta⊇alpha。
3. **默认值按 AI 负载调校**：60s 超时（ai_gateway_route_helper.go:16）、ModelsOwnedBy 默认 "Envoy AI Gateway"（ai_gateway_route.go:293），开箱即用优先。
4. **15 上限换一格 catch-all**：未命中兜底路由由 controller 注入，用户让出一格，沟通成本低于放开。

## 六、新人提示

改字段三跑 apigen/codegen/apidoc；CEL 用例去 tests/crdcel 抄同构示例。三坑：生成客户端零消费者，别往 clientset 加业务逻辑；v1alpha1 的 QuotaPolicy 别顺手搬 beta（05 篇按 alpha 假设）；HeaderValueFilters 配在非 Anthropic 后端被 CEL 拒（ai_service_backend.go:49），报错即规则原文。
