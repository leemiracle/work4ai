# 第二幕 · 数学：五条线，一组语言

## 1. MLA：解耦位置编码让低秩压缩成立

KV cache 的低秩压缩核心障碍是 RoPE（位置相关，不能与无关投影合并）。V2 的解法：**把每头的 KV 分解为无位置部分（压进 512 维潜在向量 c）+ RoPE 部分（64 维独立保留 pe_cache）**——每 token 只存 576 维潜在量（对比 MHA 128 头×(d_k+d_v)）。

- 压缩率：KV cache **−93.3%**（V2 论文口径，2.4B→~0.57B 级/千 token）
- 解码加速 = **吸收技巧**（`attn_impl="absorb"`）：把 wkv_b 吸收进 query 投影，直接对潜在 cache 打分（einsum bshc,btc），避免"先解压再算"
- FP8 KV 的 **656 B/token** 分解：512B fp8 NoPE + 16B 4×fp32 SF + 128B bf16 RoPE（**RoPE 不量化**——位置信息对量化误差最敏感）

## 2. MoE：受控稀疏路由的三重设计

$$y = \sum_{i \in \text{top-8}} \underbrace{\sigma_i(s)}_{\text{sigmoid 权重（bias 前）}} \cdot e_i(x), \quad \text{选择} = \text{top-8}(s + b_i)$$

- **选择与加权解耦**（aux-loss-free，V3 `model.py` Gate L564-594）：bias $b_i$ 只进 top-k 选择、路由权重取原始分（`original_scores.gather`）——负载均衡退出损失函数，改由逐步 bias 调整（步长 γ）承担
- **组限制路由**：256 专家分 8 组、每组选 ≤3，让 EP 的跨节点流量可预测（同组专家可同节点放置——EPLB 装箱的前提）
- V3 具体数字：256 路由专家 + 1 共享专家、top-8、route_scale 2.5、61 层中 3 层 dense

## 3. DSA：注意力本身的 top-k 硬稀疏

- 打分：$\text{score}(q,k) = \sum_{h=1}^{64} w_h \cdot \text{ReLU}(q_h \cdot k)$（每头 128 维，weights_proj 聚合；复用 MLA 的潜在 query 1536 维——**indexer 不新增 query 投影**）
- 硬选择：每 query 只保留 **top-2048** token，`dist.broadcast + assert` 强制 TP 各 rank 一致，mask 用 scatter(-inf) 注入 softmax
- 复杂度：O(L×2048)；FP8 GEMM 打分 + Hadamard 变换防 outlier
- 陷阱（官方公告）：indexer RoPE 需**非交错**布局而 MLA 是交错——写错静默掉点（低秩与位置编码的相互作用再次出现）

## 4. GRPO：组内归一化的策略梯度

$$\hat{A}_i = \frac{r_i - \text{mean}(r_{1..G})}{\text{std}(r_{1..G})}, \quad \mathcal{L} = -\hat{A}_i \log p(\tau) + \beta \cdot D_{KL}^{k3}$$

- 无 critic：用同 prompt 的 G=64 个样本的组内统计替代价值基线（Math 原始超参：lr 1e-6、KL 0.04、组 64、batch 1024）
- KL 用 k3 无偏估计直接进 loss（非奖励惩罚）
- 超参链演化：64/0.04（Math）→ 32/0.02（Prover-V1.5 RLPAF）→ 32+一致性奖励（Prover-V2）→ Math-V2 显式自评进奖励 $R = R_{format}(0.76R_{proof}+0.24R_{self})$
- RMaxTS 的好奇心奖励：$r(n) = \mathbb{1}[n \text{ 是树新增节点}]$ + DUCB $\gamma=0.99$——把"探索"形式化成树覆盖增量

## 5. 分块量化：per-128 标度的数学角色

FP8 e4m3 动态范围 ~448，per-128 标度 $s = \text{amax}/448$ 让：①128×128 tile 内 SF 规则布局（SM100 可 4-in-1 UE8M0 打包）；②tensor core 裸累加 FP8、CUDA core 每 128-K 块做 $acc \mathrel{+}= s_a s_b \cdot acc_{tc}$——**细粒度量化、粗粒度累加**误差界可控；③同一约定被 DeepEP（通信 cast）/FlashMLA（KV）/TileKernels（量化族）复用——量化噪声在四层间不放大。

## 6. 跨线恒等式（本幕的"统一语言"）

1. **一切 top-k 都是"选择与加权解耦"**：MoE bias 只影响选择、DSA 的 indexer 分只决定 mask、DeepSpec 置信头只决定截断点（不改变分布）——控制流与数值流分离。
2. **一切压缩都保留"敏感残差"原精度**：MLA 的 RoPE 64 维、FP8 KV 的 RoPE 段 bf16、DeepGEMM 的累加在 FP32——低秩/量化只吃掉可预测部分。
3. **稀疏度存在 U 型最优**：Engram 的配比律（固定总参，纯 MoE 次优，记忆占比 ρ≈75-80% 最优，val loss −0.0139）与 DSA 的 top-2048 饱和点都是同一现象——**稀疏不是越多越好，是与任务有效维度匹配**。

## 7. 三组硬数字（背下来够用）

| 数字 | 含义 |
|---|---|
| 576 / 656B | MLA 每 token 潜在维数 / FP8 KV 字节数 |
| −93.3% / 2.788M | V2 KV cache 压缩率 / V3 全训 H800 GPU 时（无 spike） |
| 2048 / 128 | DSA 每 query 保留 token 数 / 全栈量化标度粒度 |
