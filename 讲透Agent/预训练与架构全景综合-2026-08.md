## 要点速览（TL;DR）

1. **一句话总纲**：预训练已经从"炼丹"变成**"在约束下做装配"**——每个组件（数据配方/注意力/FFN/优化器/精度/并行）都是一道独立的选择题，前沿模型=一组**成本-能力解耦决策**的复合（DeepSeek-V3 哲学：5.5% 参数激活=671B 容量按 37B 成本跑）。
2. **2026 的两个结构性转向**：①**混合架构成为主流确认**（Olmo Hybrid 2× 训练效率 + 表达力定理——GDN+attention 能解两者单独都不解的问题；Qwen3.5/Kimi Linear/Granite 4/Nemotron 3 全线跟进）；②**数据配方科学化**（双层优化形式化 + InfoLaw 到 0.15% 损失预测精度 + ADO 课程式在线调混）。
3. **与推理时代的三向耦合**（本仓库视角）：架构选择现在被**推理/RL/Agent 负载**倒推（KV cache 大小=agent 经济学；Mamba-3 的 MIMO=decode 算术强度）；μP 让超参跨尺度迁移成为架构级标配候选。
4. **我们体系的独特贡献点**：谱系统一（讲透KV Cache 09）给混合架构一个统一数学叙事；遗忘地板 e\*=f/(r+f) 给 SSM/TTT 的状态设计一条可计算的设计律。

## 二、造模型的七维决策空间（统一框架）

一个 2026 年的预训练决策不再是"用什么架构"，而是七道选择题的联合求解：

```
D1 数据配方    （混什么/多少/什么顺序——双层优化）
D2 序列混合    （attention 家族 / SSM / 线性注意力 / 混合比例与排布）
D3 通道扩展    （dense FFN / MoE 路由 / 共享专家）
D4 上下文机制  （位置编码/长上下文训练/检索-压缩权衡）
D5 优化与稳定  （优化器/超参缩放律/数值精度）
D6 系统协同    （并行策略/算子/kernel 与架构共设计）
D7 目标函数    （下一词/多token MTP/多模态/课程）
```

**核心论题**：前沿能力=七维各自"成本-能力解耦"选择的复合，不是单一突破（DeepSeek-V3 教科书：MoE 解耦容量与计算 / MLA 解耦上下文与缓存 / MTP 解耦吞吐与单步 / FP8+DualPipe 压成本）。

## 三、2026-08 各维最新状态（网络增量）

### D1 数据配方：从炼丹到双层优化

- **形式化定版**（2604.16380 综述）：数据混合=概率单纯形上的**双层优化**（外层调配方/内层训练），四族方法：静态（规则/学习）vs 动态（自适应/外引导）；
- **预测精度竞赛**：Data Mixing Laws→**InfoLaw**（信息积累建模：质量=信息密度、重复=尺度依赖的收益递减；7B/425B token 上 **0.15% 平均损失预测误差**，跨过训练外推可靠）→MergeMix（可学习模型合并做中训配方）；
- **在线化**：ADO 把 scaling law 斜率当"领域学习潜力"做课程式预算分配——数据配方开始像 RL 的 explore-exploit；
- **课程学习真相**（2601.21698，14M-1B/300B token 受控实验）：课程**不改变**潜在学习阶段的顺序（共享相结构），只改变各相驻留时长；价值在小模型+长训练（降梯度噪声尺度/防输出头谱饱和=softmax 瓶颈的稳定器），**410M 以上差异消失**——"课程是正则化，不是新学习路径"。

### D2 序列混合：混合架构的主流确认年

- **Olmo Hybrid**（2026-03，AI2）：7B 开放基准+**表达力定理**（存在代码求值类问题：纯 Transformer 解不了∧纯 GDN 解不了∧**混合可解且经验上真能学到**）；受控 scaling 排序：**混合 GDN(3:1) > 纯 GDN > 纯 Transformer > 混合 Mamba2 > 纯 Mamba2**，且差距随规模保持；预训练效率 ~2×；
- **生态爆发**：Qwen3.5（GDN 混合，75% 线性层）/Kimi Linear/Nemotron 3 Nano/Granite 4.0 全线转混合——"一次研究趋势被同时采纳"；
- **Mamba-3**（2603.15569，CMU/NVIDIA）：SSM 视角三升级（指数-梯形离散化/复值状态=状态跟踪能力/MIMO=decode 算术强度 4×）——1.5B 平均精度 +1.8pp 超 GDN，**同状态规模一半达到 Mamba-2 困惑度**；
- **诚实的痛点**（Olmo 实录）：开源工具链地狱（vLLM kernel 慢/数值问题要 --enforce-eager --disable-cascade-attn 救）；**7B 混合的 RL 训练成本当前反而高于 7B dense**（GQA 都没用上）——3-6 个月修复期；TransMamba（序列级混合+共享参数 QKV↔CBx）给出训练-推理同构的激进选项。

### D3 通道扩展：MoE 的两个成熟标志

- aux-loss-free 负载均衡成为标配（DeepSeek 线：用可学习偏置替代辅助损失，免质量税）；
- **MoE 与混合架构完全兼容**（2510.04800 系统评估：所有架构形态加 MoE 都 NLL -0.08/few-shot +4pt）——D2/D3 正交复合。

### D4 上下文：从"更长"到"更准的长"

- 数据侧：Beyond length（ICLR 2026——量化长程信息含量而非只看长度）/"How to train long-context (effectively)"（ACL 2025 最佳实践）；
- 结构侧：MoBA 块注意力/NSA 稀疏注意力族；**推理侧倒推**（本仓库 KV Cache 系列主场）：MLA 57× 压缩后 agent 场景仍有 CacheScout/KVFlow 的调度红利。

### D5 优化与稳定：两条新腿

- **Muon 可扩展**（2502.16982："Muon is scalable"）+ **超参缩放律**（Predictable Scale 2503.04715：最优超参随规模可预测）——**μP 是其理论族**，我们 P1 demo 已验证方向（稳定区间宽一个量级）；
- 稳定三件套持续进化：Spike-no-more/WSM 无衰减学习率（checkpoint 合并替代 decay）。

### D6 系统协同：FP8 之后的下一站

- DualPipe/通信计算重叠成为默认；**架构-算子共设计**（Mamba-3 MIMO 的动机就是"让 RNN 的算术强度吃满 tensor core"）——**D2 的选择现在直接由 D6 倒推**；
- 效率统一观（2606.10706）：数据/显存/算力三约束耦合决策——不同 regime"好数据"定义不同（选择方法必须条件化于预算）。

### D7 目标函数：MTP 与 mid-training 常规化

- MTP（多 token 预测）= 训练信号加密 + 推理自投机解码的草稿头，一石二鸟；
- **mid-training 定型**（FCS 2026 综述收录为正式阶段）：领域强化/长上下文扩展/能力定向三合一，介于预训练与后训练之间的"第三阶段"成为标配。

## 四、横向统一：三条只有本仓库能给的线

### 4.1 谱系统一（KV Cache 09）解释了混合架构为什么赢

讲透KV Cache 09 的结论（KV cache↔SSM↔TTT 是同一序列混合算子在"精确外存↔压缩状态"谱系上的两端）**预言了 Olmo 的实验排序**：混合（谱系内点）> 任一纯端点——因为两种物化各有不可替代的检索/效率特性，混合=按层分配谱系位置。Olmo 的表达力定理（混合可解双不可解问题）给了这个叙事形式化版本。

### 4.2 遗忘地板给状态设计一条设计律

e\*=f/(r+f)（E5 推导+E4 架构实验确认）在预训练语境=**状态容量与遗忘率的联合设计**：Mamba-3 的复值状态/B/C 偏置=降 f（更可分的状态写入）；weight decay=调 γ（我们已实验验证稳态标度 η²σ²/2γ）。**SSM 的"选择性"本质是数据依赖的遗忘调度**——这给 D2 的消融一个理论坐标。

### 4.3 μP 是七维空间的"耦合器"

Predictable Scale/μP 线把 D5（超参）与 D2/D3（架构规模）耦合起来：换宽度/换层型后超参怎么迁移不再是经验活——我们 P1 管道首跑（μP 稳定区宽一个量级）是这条线在本地的一次落地。

## 五、批判与开放问题（2026-08 时点）

1. **混合架构的"为什么"仍弱于"是不是"**：Olmo 给了表达力定理（存在性），但**最优混合比例 3:1 的第一性推导不存在**（为什么不是 5:1？谱系叙事是定性的）；TTT-非线性末层的可约性（2602.21204 自认 open）卡着统一理论的最后一格；
2. **数据配方的跨域迁移性差**是综述公认痛点（换验证集/换模型结论翻转）——比超参缩放律落后一个身位；
3. **开源工具链是混合架构的隐形税**：Olmo 实录 RL 成本反超 dense——**架构先进性≠工程可用性**，这个 gap（3-6 个月）本身就是研究对象；
4. **scaling 理论与多 token 目标/课程的交互**没被刻画（InfoLaw 假设单目标下一词）；
5. **闭合问题**：预训练→mid→post 的配方全链联合优化（D1 的双层变成三层）无人做——**这是"预训练的 Loop Engineering"**，我们三部曲视角的自然延伸。
