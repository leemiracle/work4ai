  The Manifold HyperConnection (mHC) module provides a set of high-performance TileLang kernels designed to implement multi-head residual connections and iterative doubly-stochastic normalization. These kernels handle the transformation, normalization, and mixing of residual streams across multiple layers.

 
## Kernel Pipeline Overview

 The mHC system operates through a pipeline of kernels that manage the expansion of embeddings, the computation of mixing coefficients (including Sinkhorn normalization), and the final application of these mixes to the residual stream.

## 1. Normalization and Mixing Kernels

 
### sinkhorn_kernel

 Implements iterative doubly-stochastic normalization. The forward kernel `_mhc_sinkhorn_fwd` takes a residual mix tensor and iteratively normalizes rows and columns to ensure the matrix sum constraints are met [tile_kernels/mhc/sinkhorn_kernel.py11-16](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/sinkhorn_kernel.py#L11-L16)

 
 - **Forward**: Uses `T.reduce_max` for numerical stability during softmax, followed by `T.serial` loops for the requested number of Sinkhorn iterations [tile_kernels/mhc/sinkhorn_kernel.py32-55](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/sinkhorn_kernel.py#L32-L55)
 - **Backward**: `_mhc_sinkhorn_bwd` performs a complex reverse-mode pass, recomputing or loading intermediate normalization sums from shared memory to calculate gradients [tile_kernels/mhc/sinkhorn_kernel.py62-145](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/sinkhorn_kernel.py#L62-L145)
 
 
### norm_fn_kernel

 A collection of kernels for RMSNorm fused with GEMM operations.

 
 - **_mhc_pre_norm_fn_fwd_mul**: Fuses a GEMM (using `T.gemm`) with the initial square-sum accumulation for RMSNorm [tile_kernels/mhc/norm_fn_kernel.py65-114](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/norm_fn_kernel.py#L65-L114)
 - **_mhc_pre_norm_fn_fwd_norm**: Finalizes the RMS calculation using `T.rsqrt` and applies the normalization to the GEMM outputs [tile_kernels/mhc/norm_fn_kernel.py127-163](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/norm_fn_kernel.py#L127-L163)
 
 
### pre_split_mixes_kernel

 Splits a combined mix tensor into three components: `pre_layer_mix`, `post_layer_mix`, and `comb_res_mix` [tile_kernels/mhc/pre_split_mixes_kernel.py24-33](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/pre_split_mixes_kernel.py#L24-L33) It applies `T.sigmoid` and scaling factors during the split [tile_kernels/mhc/pre_split_mixes_kernel.py51-61](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/pre_split_mixes_kernel.py#L51-L61)

## 2. Structural Transformation Kernels

 
### expand_kernel

 Handles the dimension expansion between the hidden embedding and the multi-head residual stream.

 
 - **Forward**: Expands `(n, h)` to `(n, mhc, h)` by broadcasting the hidden dimension across multiple heads [tile_kernels/mhc/expand_kernel.py16-29](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/expand_kernel.py#L16-L29)
 - **Backward**: Reduces `(n, mhc, h)` back to `(n, h)` by summing across the `mhc` dimension into a `float32` accumulator to maintain precision [tile_kernels/mhc/expand_kernel.py44-58](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/expand_kernel.py#L44-L58)
 
 
### pre_apply_mix_kernel

 Applies the `pre_layer_mix` coefficients to the expanded residual stream. It uses a pipelined approach (`T.Pipelined`) to load residual fragments and multiply them by the mixing weights [tile_kernels/mhc/pre_apply_mix_kernel.py37-52](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/pre_apply_mix_kernel.py#L37-L52)

 
### post_kernel

 The final mixing stage where the layer output is combined with the residual stream using `comb_res_mix` and `post_layer_mix` [tile_kernels/mhc/post_kernel.py22-28](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/post_kernel.py#L22-L28)

 
 - **Forward**: Implements the linear combination $x = c \cdot d + A \cdot b$, where $A$ is the combination matrix and $c$ is the post-mix vector [tile_kernels/mhc/post_kernel.py50-53](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/post_kernel.py#L50-L53)
 - **Backward**: Computes gradients for all four input tensors ($da, db, dc, dd$) using specialized reducers [tile_kernels/mhc/post_kernel.py106-144](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/post_kernel.py#L106-L144)

## 3. Advanced Fusion and Recomputation

 
### pre_big_fuse_kernel

 An inference-optimized kernel that fuses the entire "Pre" mHC path into a single TileLang `T.prim_func`. It combines:

 
 - RMSNorm finalization (`_mhc_pre_norm_fn_fwd_norm`) [tile_kernels/mhc/pre_big_fuse_kernel.py43-58](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/pre_big_fuse_kernel.py#L43-L58)
 - Mix splitting and sigmoid activation [tile_kernels/mhc/pre_big_fuse_kernel.py62-68](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/pre_big_fuse_kernel.py#L62-L68)
 - Sinkhorn iterative normalization [tile_kernels/mhc/pre_big_fuse_kernel.py70-101](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/pre_big_fuse_kernel.py#L70-L101)
 - Application of the mix to the residual stream [tile_kernels/mhc/pre_big_fuse_kernel.py114-129](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/pre_big_fuse_kernel.py#L114-L129)
 
 
### multilayer_recompute_kernel

 Designed for training memory efficiency, this kernel recomputes intermediate residual states across multiple layers in a single pass [tile_kernels/mhc/multilayer_recompute_kernel.py42-59](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/multilayer_recompute_kernel.py#L42-L59) It uses a pointer table approach (`pre_mix_ptrs`, `layer_output_ptrs`, etc.) to access tensors across different layers without launching separate kernels [tile_kernels/mhc/multilayer_recompute_kernel.py60-67](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/mhc/multilayer_recompute_kernel.py#L60-L67)
