  The **MoE Routing Kernels** provide the computational foundation for token-to-expert assignment in Mixture-of-Experts (MoE) models. This module handles the selection of experts (Top-K), group-based scoring, load-balancing auxiliary loss computation, and the construction of indexing mappings required for efficient expert dispatch.

 
## Routing Pipeline Overview

 The routing pipeline typically proceeds through score calculation, Top-K selection, and mapping construction. The kernels are designed to handle both standard MoE routing and grouped MoE routing (where experts are partitioned into groups).

## Core Routing Kernels

 
### Top-K Selection (Standard and Grouped)

 
#### topk_gate_kernel

 This kernel performs a standard Top-K selection across a flat expert dimension. It uses an iterative maximum-finding approach with an `idx_reducer` to ensure stable sorting (returning the smaller index in case of ties) [tile_kernels/moe/topk_gate_kernel.py41-52](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/topk_gate_kernel.py#L41-L52)

 
#### topk_sum_and_topk_group_idx_kernel

 Used in grouped MoE architectures, this kernel selects groups based on the sum of their top-1 or top-2 expert scores [tile_kernels/moe/topk_sum_and_topk_group_idx_kernel.py71-88](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/topk_sum_and_topk_group_idx_kernel.py#L71-L88) It utilizes the `get_topk_group_idx` macro to perform intra-group scoring and inter-group ranking within a single warp [tile_kernels/moe/topk_sum_and_topk_group_idx_kernel.py55-63](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/topk_sum_and_topk_group_idx_kernel.py#L55-L63)

 
#### top2_sum_gate_kernel

 A highly specialized kernel that combines scoring (Sigmoid, Softmax, or Softplus), Top-K selection, and Tensor Parallelism (TP) rank masking [tile_kernels/moe/top2_sum_gate_kernel.py26-33](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/top2_sum_gate_kernel.py#L26-L33) It supports complex logic including:

 
 - **Scoring Functions**: Supports `SIGMOID`, `SQRTSOFTPLUS`, `SOFTMAX`, and `IDENTITY` [tile_kernels/moe/scoring.py5-9](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/scoring.py#L5-L9)
 - **Group Ranking**: Ranks groups by the sum of their top-2 experts [tile_kernels/moe/top2_sum_gate_kernel.py45](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/top2_sum_gate_kernel.py#L45-L45)
 - **Logical-to-Physical Mapping**: Handles mapping logical expert indices to physical indices for shared or duplicated experts [tile_kernels/moe/top2_sum_gate_kernel.py86-90](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/top2_sum_gate_kernel.py#L86-L90)
 
 
### Mapping and Indexing Kernels

 
#### get_fused_mapping_kernel

 This is a critical infrastructure kernel that transforms the `topk_idx` (which expert each token goes to) into a set of pointers for the dispatch/scatter phase. It produces:

 
 - `pos_to_expert`: Mapping from the expanded token buffer position to the expert index [tile_kernels/moe/get_fused_mapping_kernel.py46](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/get_fused_mapping_kernel.py#L46-L46)
 - `pos_to_token`: Mapping from the expanded buffer back to the original token index [tile_kernels/moe/get_fused_mapping_kernel.py47](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/get_fused_mapping_kernel.py#L47-L47)
 - `expert_start`/`expert_end`: The range in the expanded buffer belonging to each expert [tile_kernels/moe/get_fused_mapping_kernel.py50-51](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/get_fused_mapping_kernel.py#L50-L51)
 
 The implementation uses a two-pass approach with `T.sync_grid()` and `T.cumsum()` to calculate global offsets across SMs [tile_kernels/moe/get_fused_mapping_kernel.py104-124](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/get_fused_mapping_kernel.py#L104-L124)

 
#### inplace_unique_group_indices_kernel

 Deduplicates group indices for a single token in-place. It uses a bitmask (`T.uint64`) to track seen groups and marks duplicates as `-1` [tile_kernels/moe/inplace_unique_group_indices_kernel.py30-46](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/inplace_unique_group_indices_kernel.py#L30-L46) This is limited to 128 groups [tile_kernels/moe/inplace_unique_group_indices_kernel.py59](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/inplace_unique_group_indices_kernel.py#L59-L59)

 
### Load Balancing and TP Support

 
#### aux_fi_kernel

 Calculates the frequency indicator ($f_i$) used in auxiliary load-balancing losses. It counts how many tokens are assigned to each expert using `T.atomic_add` in shared memory before reducing to global memory [tile_kernels/moe/aux_fi_kernel.py30-45](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/aux_fi_kernel.py#L30-L45)

 
#### mask_indices_by_tp_kernel

 Filters expert indices based on the current device's Tensor Parallel (TP) rank. Experts not belonging to the rank are set to `-1`, and local experts are remapped to a local index range [tile_kernels/moe/mask_indices_by_tp_kernel.py34-42](https://github.com/deepseek-ai/TileKernels/blob/36d9e45d/tile_kernels/moe/mask_indices_by_tp_kernel.py#L34-L42)

## Kernel Details Table

 
| Kernel Name | Purpose | Key Complexity |
|---|---|---|
| topk_gate_kernel | Basic Top-K selection. | Iterative reduce_max with idx_reducer for stability. |
| get_fused_mapping_kernel | Builds dispatch indices. | Cross-SM synchronization (sync_grid) and global prefix sums. |
| top2_sum_gate_kernel | Fused scoring + selection. | Warp-level group ranking and TP rank masking logic. |
| aux_fi_kernel | Load-balancing metrics. | Atomic operations in shared memory for per-expert counts. |
| group_count_kernel | Expert load counting. | Similar to aux_fi, but returns raw counts. |
