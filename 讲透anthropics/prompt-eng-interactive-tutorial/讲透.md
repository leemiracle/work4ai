Anthropic 官方出品、业界引用最多的 Claude 教学资产之一：README 承诺学完可"掌握 prompt 基本结构、识别失败模式、从零构建强 prompt"（`README.md:15`），默认模型是最便宜的 Claude 3 Haiku（`README.md:19`）；markdown 与 code cell 交错，"每课底部有 Example Playground 实验区，改 prompt 看 Claude 反应变化"（`README.md:17`），并配答案键（`README.md:21` 另荐更友好的 Google Sheets 版）。

## 三、教学设计：交互组件如何承载概念

精髓不在 prompt 知识，而在五个组件把"做中学"工程化：

**1. `%store` 跨 notebook 环境传递**。00 章存 `MODEL_NAME`/`AWS_REGION`（`AmazonBedrock/anthropic/00_Tutorial_How-To.ipynb:100`；1P 线存 API key 占位符与无 Bedrock 前缀模型名，`1P/00_Tutorial_How-To.ipynb:46`），后续各章 `%store -r` 取回——实测每线 11 个 notebook 依赖此机制。

**2. `get_completion` 逐章演进式封装**。每章重定义这个十行 helper，签名随课程悄悄长参：00 章基础版（`:121`）→ 第 5 章长出 `prefill` 教"替 Claude 开口"（`05_*.ipynb:42`）→ 10.2 长出 `stop_sequences` 让 Claude 停在工具调用 JSON（`10_2_Appendix_Tool_Use.ipynb:44`）。参数演进史即概念演进史。三线形态不同：boto3 线手工 `json.dumps` body 且 `anthropic_version` 为空串（`AmazonBedrock/boto3/00_Tutorial_How-To.ipynb:127`，Converse API 前的化石写法）；1P 线最简（`1P/00_Tutorial_How-To.ipynb:91`）。

**3. `grade_exercise` 正则评分器**。每道练习后跟评分 cell，正则检查输出是否命中预期（"包含 hola""恰好 Michael Jordan"），改 prompt→重跑→立刻 PASS/FAIL——把单元测试反馈环搬进教材。

**4. `hints.py` 反 spoiler 答案库（最值得抄的设计）**。16 个 `exercise_X_Y_hint` + 5 个 solution 全是模块级字符串（`utils/hints.py:1` 起），练习 cell 只写一行 `from hints import exercise_1_1_hint`（`1P/01_Basic_Prompt_Structure.ipynb:282`），不主动跑就看不到提示——剧透权交给学员。9.2 Codebot 解法（`hints.py:142`）要求 Claude "Act as a Socratic tutor"、"只给引导不给答案"（`hints.py:170`）——用 prompt 工程教 prompt 工程。

**5. Example Playground**。每课尾部开放沙盒，无评分无目标；10.2 的 playground 甚至完整复制一整套工具函数供拆解。

## 四、核心 prompt 技巧传递脉络

九正章是一条递进叙事：**表达层→工程层→可靠性层→系统层**。第 1-3 章表达层：结构化 prompt、模糊请求改直接指令、角色抬高领域能力；800 词练习暗藏时代知识点——hint 明说 LLM 数不好词须超额要求。第 4-7 章工程层：XML 把数据与指令隔离（顺带演示注入为何要防）、prefill 用 assistant 开头强制格式、分步思考、few-shot 的 token 取舍。第 8 章可靠性层：幻觉治理三板斧——允许说"我不知道"、要求可验证引用、明确拒答边界。

第 9 章与附录是系统层：四个行业 chatbot 从零搭骨架；10.1 链式拆解大任务；**10.2 是全书技术含金量之最**——手写完整工具调用环：定义工具（`10_2_*.ipynb:242`）、解析调用载荷（`:268`）、结果回注对话（`:315`）、假数据库 CRUD（`:453-471`）。这是 function calling 原生化之前的 agent 工程第一课。10.3 补评测维度：代码正则/人工 rubric/模型当裁判三法（`10_3_*.ipynb:193` 的 `build_grader_prompt` 是 LLM-as-judge 最小实现）。

## 五、使用建议

**学习路径**：零基础走 1P 线（填 API key 即跑）；AWS 用户走 Bedrock 线并用 CloudFormation 一键起 SageMaker（`workshop-v1-final-cfn.yml:52`）。先跑 00 章，按章序推进。**课程设计参考**：直接抄三件套——`%store` 环境传递、`grade_exercise` 反馈环、`hints.py` 反 spoiler 答案库。**时效提醒**：内容定格 Claude 3 时代（无原生 tool use），当 prompt 工程思想史与教学设计范本读，勿当 API 手册用。

**勘误与陷阱**（源码实证）：① 附录编号三处不一致——anthropic 线 `10_4` 文件内标题写 "Appendix 10.3"、boto3 线写 "10.4"、根 README 目录漏列评测章；② 两份 hints.py（`AmazonBedrock/utils/hints.py` 与 `Anthropic 1P/hints.py`）diff 零差异，同源双拷贝维护债；③ `utils/hints.py:152` 的 `def calculate_circle_area` 是 solution 字符串内嵌示例而非模块函数，结构提取器会误报；④ 第 7 章文件名 "Examples" 后有空格、1P 线 Search & Retrieval 文件名含 `&`，脚本须原样保留路径。
