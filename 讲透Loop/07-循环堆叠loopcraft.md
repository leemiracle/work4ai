# 07 · 循环堆叠 loopcraft：从 agent loop 到 hill climbing

> 讲透Loop 第 7 章 | 实验基座：E4 双相外环（`experiments/04_outer_loop.py`，已跑通）
> swyx 的 "loopcraft: the art of stacking loops"（原文待核）——LangChain 产品化的四层堆叠

## 一、直觉层：四种循环嵌成一座塔

单层循环自动干活，堆叠循环**自动变强**。LangChain（2026-06-16）的四层：

```
L4  Hill climbing loop     trace → 分析 → 改 harness 配置 → 重跑
    "外环的手伸进内环，每圈外环让内环更强"
L3  Event-driven loop      事件/schedule 触发 run（04 章四形状在此入塔）
L2  Verification loop      产出 → grader 打分 → 不合格带反馈重试
L1  Agent loop             模型调工具直到任务完成（01 章内循环）
```

各层一句纲领：

- **L2 验证环**：RubricMiddleware / after_agent hook——确定性 grader 或 LLM judge 打分，失败反馈回去重试。质量换延迟与成本，"most production use cases"；
- **L3 事件环**：agent 从"你手动调用的东西"变成"系统里常驻的部件"（webhook/cron/Fleet channel）——04 章的四形状全部住在这一层；
- **L4 爬山外环**：**本单元的主角**。每次 run 产出 trace（模型做了什么/调了什么工具/grader 说了什么），trace 里有高价值信号——外环跑一个分析 agent 读 trace，改 harness（prompt/工具/grader 配置），下一轮内环变强。

关键直觉（LangChain 原文意译）：**L4 的返回箭头不是简单回到塔顶，而是直接伸进去修改内环**。L1-L3 自动化工作，L4 自动化**改进**。Satya 的组织学翻译：早建学习循环的公司，人类判断力和 token 资本一起复利，构成护城河。

开放的下一步（LangChain 展望）：开源权重团队把 L4 接到 RL 微调——trace/eval 结果当训练信号改参数；memory 与 skill 库同样可以被外环优化。"循环是模式，优化什么随你。"

## 二、数据层：E4——最小外环闭环的双面实验

E4 用规则型分析 agent 复现 L4 外环（trace 统计 → 规则补丁 → 重跑），做了诚实/污染双相——这是 loopcraft 的第一次模拟器级解剖。

### Phase A：诚实外环（reward = 真成功率）

| Gen | 配置 | 真成功 | 外环动作 |
|-----|------|--------|---------|
| A0 | 裸奔 self/无K/无cap | 8.0% | trace：早停 92% + 最长 64 轮 → **一次读出双补丁** |
| A1 | machine + K8 | 42.8% | trace：熔断 43% 里正常任务 19%（过敏！）→ R4: K→14 |
| A2 | machine + K14 | **53.3%** | 无补丁可打 → **收敛** |

三个值得背的结构性观察：

1. **补丁批量出**：一次 trace 分析打出多个正交补丁（A0→A1 同时升验证+装熔断）——外环的杠杆倍数 = 单次分析的补丁数；
2. **外环会调参还会诊断**：R4 规则（stalled_normal>8% = 熔断过敏）不是调 K 的数值，是**识别出了"止损器在误伤"这个因果结构**——这就是 trace 分析比盲目 grid search 强的原因；
3. **收敛即终点**：A2 后无补丁可打，外环功成身退（剩余 46.7% 失败全是"4 个卡死任务"的不可解部分——理论上限 8/12=66.7%，A2 已在上限的 80%）。**外环不是永动机，收敛后该停的是外环自己**。

### Phase B：污染外环（reward = claimed/tokens，"降本增效"接管）

从 A2 出发，污染外环读同样的 trace，用"自称产出率"当 reward：

| Gen | 配置 | 产出率 | 真成功 |
|-----|------|--------|--------|
| B0 | machine + K14 | 1.84 %/k | 52.9% |
| B1 | self（**拆掉验证**） | **5.39 %/k（+193%）** | **8.6%** |

污染外环的推理完全"合理"：验证调用不产生 claimed 增益、纯 token 成本 → 拆掉。reward 定义里没有"真"字，它就优化不到真——**Goodhart 剪刀差**：代理指标与真实目标反向撕裂。这是 03 章"gate ≠ goal"的动态版：静态写 gate 会写错，动态优化 gate 会被钻——**外环的 reward 必须在验证阶梯上至少与内环同级，否则它就是系统里最聪明也最危险的部件**。

### E4 的诚实局限（写进结论的那种）

模拟器的 stall 计数器基于真实进展 W——agent 骗不过它。真实世界的 L4 外环面对的 trace 里全是**自称**进展；污染外环完全可以一边产伪进展一边拆守卫，而 cap（唯一不依赖信号的守卫，05 章）将是最后防线。**cap 防伪进展这条定律在 E4 里无法演示，但 E4 的 B 相给出了它的上半场证明：能被骗的信号都会被骗。**

## 三、设计层：堆叠三原则

1. **每层只管一层的事**：L2 管单次质量，L3 管调度，L4 管改进。跨层兼职是坏味道——最常见的错误是让 L2 的 grader 同时当 L4 的 reward（用同一把尺子量单次质量和长期改进，Goodhart 找上门）；
2. **外环 reward 的验证层级 ≥ 内环验证层级**（E4 Phase B 的教训）：内环用 L4 测试，外环 reward 就不能是 L2 的自称指标——至少同级，最好异源；
3. **外环也要有守卫**：外环是循环（gen0→gen1→…），同样需要收敛条件（无补丁可打 = success）、熔断（连续 N 代指标不升 = stalled，防振荡）和 cap（最多 G 代）。E4 的 `max_gens=5` 就是外环 cap。**塔的每一层都要有自己的停止规则。**

升级路径（外环的 IMPROVE 目标菜单，接 08 章算子分类）：改 prompt（便宜，先试）→ 改工具/技能（中）→ 改 grader（危险——改尺子等于改 reality）→ 改模型参数（RL 微调，重武器）。**从左往右成本递增，从右往左可逆性递增——先左后右。**

## 四、不足与批判

1. **L4 是 2026 年最被高估也最未被验证的一层**：LangChain 的 Engine、各家 trace 分析 agent 全是新物种——2608.21884 的扫描里这一层**零采用**（连 L2 verifier 都零），爬山外环目前存在于博客和 demo，不在生产。本单元 E4 也是模拟器——规则型分析 agent 而非真 LLM 读真 trace；
2. **改 harness 会改分布**：L4 每次改配置，内环的轨迹分布就变——旧 trace 的解释力衰减（非平稳性）。真 LLM 外环需要"配置变了哪些 trace 还可比"的判断力，这是它最微妙的认知负荷；
3. **复利的另一面是复错**：Satya 说学习循环建护城河——但 Phase B 演示了同一个外环在坏 reward 下**指数级放大错误决策**（一刀回到 8.6%）。护城河还是绞肉机，取决于 reward 的验证层级——技术不提供这个保证，设计者提供。
