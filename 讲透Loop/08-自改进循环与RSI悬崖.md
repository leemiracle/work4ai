# 08 · 自改进循环与 RSI 悬崖：A_{t+1} = IMPROVE(A_{1:t}; S_t)

> 讲透Loop 第 8 章 | 文献基座：2607.13104（自改进综述）+ 2607.07663（RSI 综述，1,250 篇）
> 实例：AlphaProof / Prover harness / MATH_LOOP_ENGINE / E4 外环

## 一、直觉层：把 07 章的外环写成公式

07 章的 hill climbing 用自然语言说："外环读 trace 改配置"。2607.13104 把它形式化——现代 agent 是**配置**（configuration）：

$$\mathcal{A} = \underbrace{\theta}_{\text{基础模型}} \times \underbrace{\Sigma}_{\text{支架：prompt/memory/tools/控制逻辑}}$$

自改进就是**自诱导的更新算子**：

$$\mathcal{A}_{t+1} = \mathrm{IMPROVE}(\mathcal{A}_{1:t};\ \mathcal{S}_t)$$

$\mathcal{S}_t$ 是驱动信号。这个公式统一了你会遇到的一切"XX-loop"：

| 系统 | $\mathcal{S}_t$ | IMPROVE 改什么 | 改 $\theta$ 还是 $\Sigma$ |
|------|----------------|---------------|--------------------------|
| Ralph Loop | 测试输出 | 改代码直到绿 | 都不改（任务级） |
| E4 Phase A | trace 统计 | 守卫配置 | $\Sigma$ |
| OPRO / prompt 自优化 | 评分 | prompt | $\Sigma$ |
| MATH_LOOP_ENGINE | 五类机器 reward | 锚点卡/技能 | $\Sigma$（+人脑 $\theta$） |
| AlphaProof | Lean 验证 | 策略（RL） | $\theta$ |
| 开源权重 + RL（SkillRL/TT-SI） | 环境回报/不确定性 | 模型参数 | $\theta$ |

**表格的读法**：越往右，改进越持久（参数改动不随 context 消失）、越贵、越难回滚。改 $\Sigma$ 是租能力，改 $\theta$ 是买能力。

## 二、三类信号（2607.13104 的分类学）

按学习信号 $\mathcal{S}_t$ 的来源三分：

1. **内生示范** $\mathcal{S}_t \approx \mathcal{D}_t$：agent 自己生成任务-解答对再训练自己（Self-Instruct/Evol-Instruct/STaR 谱系）。风险：**自一致性塌缩**——confidently wrong 时，重复推理反复收敛到同一个错误结论，然后把它训进参数；
2. **内生评价** $\mathcal{S}_t \approx e_t$：agent 或内部 evaluator 给自己打分（Self-Refine/Reflexion/自奖励）。风险：**盲区放大**——错误类型超出模型感知范围时，"改进"会强化盲区而不是消除它；
3. **外生探索** $\mathcal{S}_t \approx \tau_t$：真实环境交互（工具执行/测试/证明器）。最稳，但受环境质量限制。

三类不是互斥的——生产系统混用（DeepSeek-R1 式管线里三类都有）。**选型原则一句话：信号的可信度决定它配驱动多深的改动**——L1 信号（自评）只配改任务级产物，L4-L5 信号（测试/证明器）才配改参数。这是 03 章验证阶梯在"改进深度"轴上的投影。

防塌缩护栏（2607.13104 综述的五件，值得抄）：保留种子基准数据防漂移（Gerstgrasier 2024：在生成数据上累加训练会塌缩，在种子数据上累加不会）/ 外部验证器过滤（单元测试、Lean）/ 多样性池扩充防模式坍缩 / 不确定性驱动的定向生成（TT-SI：只对薄弱点生成训练数据）/ 人在环审计评估器本身。

## 三、RSI 悬崖：bounded self-refinement vs open-ended RSI（2607.07663）

1,250 篇文献（2024-2026）的两轴分类：**改进对象**（部署行为/策略/评测器/研究过程本身）× **循环闭合度**（人在环→全闭环）。核心判词：

> **有界自精炼（bounded self-refinement）**：收敛、可评估、已是工业实践——E4 Phase A 三代收敛就是标准标本；
> **开放式递归自改进（open-ended RSI））**：受 grounding 要求、塌缩动力学、算力约束三重限制，**在每一个可测轴上都有界**。

而全书最重要的一张表是**验证层级**（03 章 L1-L5 阶梯的出处），加上它的实证规律：

- 已证实的自改进强度沿层级排列（L5 驱动的改进 > L4 > … > L1）；
- 失败模式（self-confirming loops / model collapse / diversity collapse）恰好是层级违反的后果——**用比被改进对象更弱的信号去驱动改进**；
- **"研究方向的设定"这个瓶颈卡在层级顶端之上**——形式验证器验证不了一个研究方向值不值得做，所以人类留在那个位置不是工程惯性，是层级的结构性结果。

RSI 理论还补了一个哲学注脚：全闭环 RSI 的三个上限里最硬的是 **grounding**——自改进系统最终需要接触它无法重写的现实（物理实验/人类偏好/形式真理）。Lean 之所以在数学域一枝独秀，因为形式真理是唯一可以完全装进机器的"现实"。

## 五、设计层：自改进循环的安全清单

让你的 IMPROVE 算子不坠崖的六条（综合 2607.13104 护栏 + 2607.07663 层级 + E4 教训）：

1. **信号层级 ≥ 改动深度的层级**：改 $\theta$（参数）必须 L4+ 信号；L1-L2 信号最多改任务级产物；
2. **改进要可回滚**：$\Sigma$ 改动全部进版本控制（一个 commit 一个补丁），$\theta$ 改动留 checkpoint——E4 每代存配置快照的最小版；
3. **保留种子集**：任何数据自生成管线必须锚定不可变基准，防漂移塌缩；
4. **方向归人，执行归机器**：研究/产品方向的决定权在验证层级顶端之上——机器可以提方向建议（L3 判官），人来批；
5. **外环戴守卫**：收敛条件 + 熔断（连续 N 代不升）+ 代数 cap——07 章原则 3；
6. **警惕"评估器改进"这一格**：2607.07663 把 self-evaluation 单列一类——每个改进循环都是一次"某信号可替代人类判断"的赌注。评估器自身的改动要走比普通改动更严的流程（改尺子=改 reality）。

## 六、不足与批判

1. **两篇综述的边界**：2607.13104/2607.07663 都是 arXiv 综述（后者含未评审预印），其"层级规律"是对文献的定性综合，不是元分析——把它当强先验而非定理；
2. **"RSI 有界"的结论可能过时得很快**：综述截止 2026 年中，前沿实验室的闭环 AI 研究员（AI participating in AI research）进展迅猛——2607.07663 自己也说 governance-grade measurement 是最空的生态位。本单元的立场：**数学边界（塌缩/grounding）是硬的，工程边界（算力/评估）是软的，两者别混**；
3. **本仓库实例的规模谦虚义务**：Prover harness 蒸馏 24 题、MATH_LOOP_ENGINE 30 卡——它们是结构标本（验证层级的正确配置），不是效果证据（没有对照组证明"这样更快"）。诚实的说法是：我们实践了学科的形状，没有测量学科的收益。
