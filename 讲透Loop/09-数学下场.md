> 讲透Loop 第 9 章 | 实验基座：E5（`experiments/05_convergence.py`，已跑通）

## 一、直觉层：循环的三个数学老三样

任何循环（改进循环/工作循环/学习循环）作为迭代过程，只有三个问题值得问：

1. **有不动点吗**——$\exists x^*: g(x^*)=x^*$，转着转着能停在一个"再改也不变"的状态吗？
2. **迭代收敛到它吗**——从你的起点出发，会不会真走到 $x^*$？
3. **$x^*$ 是你想要的那个吗**——收敛到的东西和你的目标是一个吗？（Goodhart 的全部故事：Phase B 收敛得又快又稳，收敛到 8.6%。）

前两个有定理（Banach 不动点），第三个数学不管——那是验证层级的管辖（03 章）。**数学保证你到达某处，层级保证某处是对的。**

## 二、定理层：Banach 收缩映射

**定理（Banach）**：若 $g$ 是完备度量空间上的收缩映射——存在 $q<1$ 使 $\|g(x)-g(y)\| \le q\|x-y\|$——则不动点存在唯一，且迭代收敛，误差几何衰减：

$$\|x_t - x^*\| \le q^t \|x_0 - x^*\|$$

$q$ 就是**收缩因子**——循环数学里最重要的一个数：$q=0.5$ 十轮收敛 99.9%；$q=0.95$ 十轮才收 40%。**$q$ 接近 1 的循环"理论上收敛、预算上发散"。**

工程翻译：

| 数学对象 | 循环对象 |
|---------|---------|
| $g$ | IMPROVE 算子（改代码/改 prompt/改配置的规则） |
| $x^*$ | 稳态：测试全绿的提交 / 稳定的 harness 配置 |
| $q$ | 每代改进的"有效步长"（进步幅度 - 回归幅度） |
| $q^t$ | 误差衰减 = 距离收敛的预算倒计时 |
| 初值敏感 | Gen0 配置差太远 → 需要的代数爆炸 |

## 三、代码层：E5 三个演示（全跑通）

### D1——改进步长的分界（$\|g'\|$ 定生死）

IMPROVE 玩具模型 $g(x) = x + r\,x(1-x)$（质量 $x$，改进强度 $r$），最优不动点 $x^*=1$ 处 $|g'(1)|=|1-r|$：

| r | $\|g'(1)\|$ | 40 代后 | 判 |
|---|------------|---------|-----|
| 0.5 | 0.5 | 1.0000 收敛 | 收缩 |
| 1.2 | 0.2 | 1.0000 收敛 | 收缩快 |
| 1.8 | 0.8 | 1.0000（但 40 代才到 ~1e-4 精度）| **慢收敛** |
| 2.0 | 1.0 | 1.0490 振荡 | 临界 |
| 2.4 | 1.4 | 1.1931 | 发散 |
| 3.0 | 2.0 | 1.1550（有界振荡+过冲）| 发散 |

三条工程读法：

1. **改过头 = 振荡**：$r>2$ 对应每代改动比剩余差距还大——下一代会冲过头再被拉回，永远在最优两侧摆动。E4 Phase A 的补丁"批量但克制"（一次 trace 改 1-2 个参数）是收缩设计；"一次大重构改十个子系统"是 $r>2$ 设计；
2. **慢收敛是隐性失败**：r=1.8 在数学上收敛（$q=0.8<1$），但 40 代才到 1e-4——如果你的预算是 20 代，它"实际上"没收敛。**判断标准从 $q<1$ 变成 $q^{\text{budget}} < \text{tolerance}$**：工程循环要在预算内收敛，不是在无穷处收敛；
3. **临界态最危险**：$q=1$（r=2）的振荡幅度小（1.049），看起来"差不多稳了"——这是最容易被误判为收敛的发散。

### D2——遗忘地板：$e^* = f/(r+f)$

学习循环的稳态错误不完全由学习率决定。每轮以 $r$ 比例掌握剩余错误、以 $f$ 比例把已会的混回错误：

$$e_{t+1} = e_t(1-r) + (1-e_t)f \ \Longrightarrow\ e^* = \frac{f}{r+f}$$

E5 实测：无遗忘 30 轮 $e\to 10^{-5}$；有遗忘（$r=0.35, f=0.10$）30 轮卡在 **0.2222 = 理论地板 $0.1/0.45$**，严丝合缝。

这是 MATH_LOOP_ENGINE 学习律 $(m+1)/2 = m - m/2$ 的连续版亲戚，也是 06 章 state file 的数学辩护词：**state file 是降 $f$ 的工具**——跨 run 记忆把遗忘率压向零，收敛地板才压向零。不写状态的循环 = 高 $f$ 循环 = 在 22% 错误率的地板上永远打转，无论学习率多高。**降地板优先于提学习率**（分母里 $f\to 0$ 时 $e^*\to 0$，与 $r$ 无关）。

### D3——闭式 vs 蒙特卡洛（E2 理论终验）

- $E[T] = W/p$：闭式 22.9 vs 20,000 次模拟 22.8，**偏差 0.1%**；
- 累积早停率 $1-(1-p_{\text{leak}})^{W/p}$：闭式 20.5% vs E2 实测 19.4%（差 1.1pp 来自 cap 截断和熔断的轻微干预）。

至此本单元的三条闭式律全部通过数值验证：**累积漏检律（03）、几何等待律（05）、成本期望律（本节）**——循环动力学从模拟上升到公式。

## 五、不足与批判

1. **玩具模型的谦虚义务**：$g(x)=x+rx(1-x)$ 是一维光滑映射——真实 IMPROVE 是离散组合空间上的非平稳算子（prompt 空间没有度量，更没有 $q$）。定理的价值是**给直觉装护栏**（步长/收缩/地板的思维方式），不是给工程提供计算公式；
2. **非平稳性被假设掉了**：Banach 要求 $g$ 不变——但 LLM 的 policy 会随版本/温度/上下文漂移，$g$ 每个 gen 都在变。非平稳下的收敛没有这么干净的理论，工程对策只有笨办法：每代留快照，指标回退就回滚；
3. **第三个问题数学不管**：再收敛的循环也可能收敛到错误的 $x^*$（Phase B 教训）。数学处理"到达"，层级处理"值得到达"——本单元把验证放在中心而把数学放在第 9 章（倒数第四），就是这个优先级的排版表达。
