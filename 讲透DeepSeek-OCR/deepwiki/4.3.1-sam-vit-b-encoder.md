## Purpose

 This document provides a technical deep-dive into the SAM (Segment Anything Model) ViT-B encoder used in DeepSeek-OCR's vision encoding system. The SAM encoder is one of two parallel vision encoders (the other being CLIP-L, see [4.3.2](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/4.3.2)) that process image inputs. The SAM encoder specializes in extracting spatially-aware, high-resolution features using window attention and relative positional embeddings, making it particularly effective for document understanding tasks that require precise spatial layout comprehension.

 For information about how SAM and CLIP features are combined, see [4.3.3](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/4.3.3) For the overall vision encoding pipeline, see [4.3](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/4.3)
