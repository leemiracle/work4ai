  This page documents the single image processing workflow using vLLM for real-time streaming OCR. The script `run_dpsk_ocr_image.py` provides an interactive way to process individual images with live output streaming, bounding box visualization, and support for geometric plot rendering.

 For batch processing of multiple images, see [3.2.3](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/3.2.3) For PDF document processing, see [3.2.2](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/3.2.2) For the Transformers-based interface, see [3.1](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/3.1)

## Processing Workflow Overview

 The single image processing pipeline consists of five main stages: image loading with EXIF correction, preprocessing with dynamic cropping, vLLM engine initialization, async streaming generation, and post-processing with visualization.

## Image Loading and Preprocessing

 
### Image Loading with EXIF Correction

 The `load_image()` function handles image loading with automatic EXIF orientation correction using `ImageOps.exif_transpose()` [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py33](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L33-L33) This ensures images are displayed in the correct orientation regardless of camera metadata. If the correction fails, the function falls back to a standard `Image.open()` [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py40](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L40-L40)

 **Sources:** [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py28-42](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L28-L42)

 Images are preprocessed using `DeepseekOCRProcessor` if the prompt contains the `<image>` token [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py212-214](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L212-L214)

## vLLM Engine Configuration

 The script uses `AsyncLLMEngine` to enable streaming output. The model must be registered with the vLLM `ModelRegistry` before initialization [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py26](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L26-L26)

### Bounding Box Visualization

 The `draw_bounding_boxes()` function renders annotations. It denormalizes coordinates from the 0-999 range used by the model back to the original image dimensions [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py99-103](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L99-L103)

 **Visual Style Rules:**

 
 - **Titles**: Outline width 4 [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py116](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L116-L116)
 - **Other Elements**: Outline width 2 [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py119](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_image.py#L119-L119)
