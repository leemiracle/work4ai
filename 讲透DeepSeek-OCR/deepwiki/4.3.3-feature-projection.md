## Purpose and Scope

 This document describes the feature projection layer in DeepSeek-OCR, which bridges the vision encoders to the language model. The `MlpProjector` class [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py7-174](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L7-L174) transforms concatenated vision features from the dual-encoder system (SAM + CLIP) into the language model's input dimension space. This page covers the various projection strategies, dimensionality reduction techniques (typically 2048 to 1280), and configuration options.

 For information about the vision encoders that produce the input features, see **4.3.1 SAM ViT-B Encoder** and **4.3.2 CLIP-L Encoder**. For details on how projected features integrate with the language model, see **4.5 Multimodal Integration**.

 The projection layer performs three key functions:

 
 - **Dimensionality Reduction**: Reduces concatenated 2048-dimensional features (1024 from SAM + 1024 from CLIP) to 1280 dimensions (the LLM embedding size).
 - **Feature Transformation**: Applies non-linear transformations using `GELU` activations [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py25](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L25-L25) for expressive feature mapping.
 - **Spatial Downsampling**: Optionally reduces the number of tokens by spatial pooling or unfolding for computational efficiency [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py153-154](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L153-L154)

## Projection Strategies

 
### 1. Identity and Linear

 
 - **identity**: Passes features through without modification [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py15-16](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L15-L16)
 - **linear**: A single `nn.Linear(cfg.input_dim, cfg.n_embed)` layer [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py18-19](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L18-L19)
 
 
### 2. Standard MLP (`mlp_gelu`)

 A multi-layer perceptron with `GELU` activations. The first layer maps from `input_dim` to `n_embed`, and subsequent layers maintain the `n_embed` width [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py21-27](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L21-L27)

 
### 3. Downsampling Projections

 These strategies reduce the sequence length (number of tokens) while increasing the channel dimension before the final projection.

 
 - **downsample_mlp_gelu**: Uses `F.unfold` to group spatial patches (e.g., 2x2) into the channel dimension [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py152-154](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L152-L154) 
 - Input shape: `(B, HW, C)`
 - Unfold shape: `(B, C * r^2, HW / r^2)` where `r` is `downsample_ratio`.
 - **normlayer_downsample_mlp_gelu**: Prepends an `nn.LayerNorm` before the downsampling and MLP stack [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py29-41](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L29-L41)

### 4. Split-Path Hybrid Projections

 These handle SAM (high-res) and CLIP (low-res) features with specialized sub-networks.

 
 - **low_high_hybrid_split_mlp_gelu**: Projects SAM and CLIP features separately using `high_up_proj` and `low_up_proj` (each to `n_embed // 2`) before concatenating them for a shared MLP [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py54-63](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L54-L63)
 - **hybrid_split_feature_mlp_gelu**: Similar to above, but splits a single concatenated input tensor based on a `channel_div` ratio [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py65-75](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L65-L75)
 - **low_high_split_mlp_gelu**: Maintains two completely independent MLP pipelines (`high_layers` and `low_layers`) that are only concatenated at the very end of the forward pass [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py77-86](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L77-L86)

## Optional Feature Modules

 
### Token Pooling

 When `token_pooling` is enabled, the model performs a 2x2 patch merge. It reshapes the sequence into a 2D grid, extracts patches using `unfold`, and projects the resulting `channels * 4` dimension back to the original `channels` using `self.token_pooling_layer` [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py98-113](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L98-L113)

 
### Convolutional Fusion

 If `conv_fusion_high_low_features` is active, the projector fuses dual features using a learnable linear layer: `self.fusion_layer(x[:, 0]) + x[:, 1]` [DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py115-116](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/deepencoder/build_linear.py#L115-L116)
