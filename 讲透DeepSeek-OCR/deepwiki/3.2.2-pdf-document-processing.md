# PDF Document Processing

  Relevant source files 
 - [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py)
 
  This page describes how to process multi-page PDF documents using the vLLM inference path. The `run_dpsk_ocr_pdf.py` script provides a production-ready pipeline for converting PDF documents to structured markdown with layout information, bounding box annotations, and visual overlays.

 For single image processing, see [Single Image Processing](https://deepwiki.com/deepseek-ai/DeepSeek-OCR/3.2.1-single-image-processing). For batch evaluation on datasets, see [Batch Evaluation](https://deepwiki.com/deepseek-ai/DeepSeek-OCR/3.2.3-batch-evaluation). For general vLLM inference concepts, see [vLLM Inference](https://deepwiki.com/deepseek-ai/DeepSeek-OCR/3.2-vllm-inference).

 
## Purpose and Scope

 The PDF processing pipeline is designed for:

 
 - **Multi-page document processing**: Academic papers, reports, books, forms.
 - **Concurrent page processing**: Parallel preprocessing with `ThreadPoolExecutor` [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py248-251](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py#L248-L251)
 - **Batch GPU inference**: Process all pages in a single vLLM batch [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py268-271](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py#L268-L271)
 - **Layout visualization**: Generate annotated PDFs with bounding boxes [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py218-220](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py#L218-L220)
 - **Image extraction**: Automatically extract and save figures/charts from documents [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py183-190](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py#L183-L190)
 
 The script produces three synchronized outputs: raw detection markup, cleaned markdown, and a visual layout PDF.

### Process Single Image Function

## Batch Inference with vLLM

 Once all pages are preprocessed, they are passed to vLLM for batch inference.

 
### vLLM Engine Configuration

 The LLM engine is initialized with production-optimized settings [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py32-44](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py#L32-L44):

 
| Parameter | Value | Purpose |
|---|---|---|
| model | MODEL_PATH | Model identifier |
| hf_overrides | {"architectures": ["DeepseekOCRForCausalLM"]} | Custom model registration |
| block_size | 256 | KV cache block size |
| enforce_eager | False | Use CUDA graphs |
| max_model_len | 8192 | Maximum sequence length |
| max_num_seqs | MAX_CONCURRENCY (100) | Batch size limit |
| gpu_memory_utilization | 0.9 | GPU memory allocation |

 
### Sampling Parameters

 The sampling configuration [DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py48-54](https://github.com/deepseek-ai/DeepSeek-OCR/blob/09eaf526/DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py#L48-L54) controls output generation:
