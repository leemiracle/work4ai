# 讲透区域政治 · 12 分区画像（GB/T 81040 区域政治细目）

> 支：[讲透国际政治学](../README.md)（GB/T 81040 三级：区域政治，
> 标准细目含美英法德日俄欧亚太拉美非洲中亚西亚 12 分区）。
> 一句话：**世界政治的地毯层**——理论在天上飞，分区研究在地上走。

## 定位句

本支负责**主要国家与区域的政情画像**：以"政治制度+政治文化+
对外姿态"三件套为每个分区建立基线档案，服务外交决策、
区域研究与跨国比较的落地层。

## 诞生与关键事件

- 1950s-60s 区域研究（area studies）冷战建制化
- 1990s 苏东研究=区域研究范式转换的活样本
- 2010s- 区域研究 vs 大样本方法的"深度-广度"之争持续
- 2020s 中国区域国别学一级学科化（2022 区域国别学入交叉
  学科门类）：分区画像的制度性需求放大

## 这支最美的一个事实

德国"建设性不信任投票"（1949）被比较政治学证明显著稳定了
联合政府——一个分区制度设计的专利，成为全球宪政设计的
标准零件（制度理论"设计可输出"的最好广告）。

## 假设与依赖

"区域"可界定（边界本身是政治的）、画像可时效维护（政情数据
衰减快）、跨分区比较需制度编码支撑（V-Dem 等数据库接口）。

## 教材锚

- 各分区权威通史/政情年鉴（如 Japan Almanac 式年度工具书谱系）
- The Economist / regional surveys 类持续情报流
- 制度编码：V-Dem country reports
