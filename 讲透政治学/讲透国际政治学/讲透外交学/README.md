# 讲透外交学 · 以言代战的技艺

> 支：[讲透国际政治学](../README.md)（GB/T 81040 三级：外交学）。
> 一句话：**战争是失败的沟通，外交是不流血的较量**——
> 谈判、信号、威慑的言语手艺及其制度包装。

## 定位句

本支负责**外交的理论与技艺**：谈判理论（利益区/ZOPA/ BATNA）、
信号与沟通（成本信号/羞耻成本）、威慑与保证（deterrence vs
reassurance）、外交官职业制度（使团/豁免/照会体系）、公共外交
与数字外交。

## 诞生与关键事件

- 1455 米兰公国首派常驻使节：现代外交制度起点
- 1648 威斯特伐利亚会议：多边外交之父（全体大会谈判范式）
- 1815 维也纳会议外交等级规则（大使/公使/代办）定型
- 1960 谢林《冲突的战略》：外交的博弈论语法
- 1972 尼克松访华式的"秘密渠道外交"研究兴起
- 2010s 数字外交（Twiplomacy）；2020s 演算法信号（制裁清单/
  出口管制的"文书威慑"）

## 这支最美的一个事实

谢林发现：**自缚双手可以增强谈判力**（破釜沉舟的可信性）、
"留退路"反而使威慑可信——外交的悖论手册全部来自博弈论
的反直觉定理（不可逆性=承诺装置，见挂靠引擎
[../../../讲透数学/讲透博弈论/07-子博弈完美与承诺.md](../../../讲透数学/讲透博弈论/07-子博弈完美与承诺.md)）。

## 假设与依赖

言语行为有可观测成本（信号可分真假）、谈判偏好可模型化、
外交制度（豁免/对等）是稳定均衡；批判：外交=强者的语法
（后殖民外交研究）。
