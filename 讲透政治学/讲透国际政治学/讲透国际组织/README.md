# 讲透国际组织 · 没有立法者的制度

> 支：[讲透国际政治学](../README.md)（GB/T 81040 三级：国际组织）。
> 一句话：**无政府世界里长出的制度珊瑚礁**——联合国、IMF、WTO、
> 欧盟：没有警察护航的规则如何存活。

## 定位句

本支负责**国际组织的理论、设计与运行**：组织类型学（政府间/
超国家；一般性/专门性）、国际制度理论（为何被遵守）、主要组织
解剖（联合国系统/布雷顿森林机构/区域组织）、组织改革政治
（安理会扩员、WTO 争端危机）与欧盟这个"超出理论"的特例。

## 诞生与关键事件

- 1865 国际电报联盟/1874 万国邮政联盟：技术性国际组织的先声
- 1919 国际联盟：第一个普遍性安全组织（失败样本）
- 1944 布雷顿森林+1945 联合国：当代体系地基
- 1957 罗马条约→1993 马斯特里赫特：欧盟的超国家实验
- 1984 基欧汉《霸权之后》：国际制度理论确立
- 1995 WTO 成立；2010s- 多边主义危机与"小多边"兴起

## 这支最美的一个事实

WTO 争端解决机制曾让小国告赢大国并使大国实际执行——
**在没有警察的世界上，裁决的执行靠"贴脸"**：违约会被公开
点名、授权报复，损失的是未来无穷次博弈的入场券（重复博弈
定理的制度肉身，家族 04 章走廊 2 的制度版）。

## 假设与依赖

国家是主要委托人（委托-代理框架）、组织有可识别的授权边界、
"遵约"可观测（shadow rating 争议）；欧盟研究需放松国家中心。
