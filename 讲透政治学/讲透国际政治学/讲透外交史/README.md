# 讲透外交史 · 使节制度的两千年

> 支：[讲透国际政治学](../README.md)（GB/T 81040 三级：外交史）。
> 一句话：**从战车上的求和使节到视频里的峰会**——外交形态的
> 演化史就是国际社会的文明史。

## 定位句

本支负责**外交形态与实践的演化**：古代使节（中国纵横家/希腊
heralds 的神圣不可侵犯）、常驻使节制度的形成（15 世纪意大利）、
会议外交（威斯特伐利亚-维也纳）、首脑外交（20 世纪）、
多边与峰会外交（20-21 世纪）、数字外交的当下。

## 诞生与关键事件

- 前 6 世纪起 希腊 heralds（传令官）不可杀的惯例：
  外交豁免的古代源头
- 战国合纵连横：职业外交家（纵横家）的第一个黄金时代
- 1455 米兰常驻使节→1648《威斯特伐利亚和约》多边大会
- 1815 维也纳会议规制：外交等级与礼宾的国际标准化
- 1919 巴黎和会：首脑亲自下场（"峰会"时代开端）
- 1972 尼克松访华：秘密渠道+电视直播的新混合形态
- 2020s Zoom 外交与"元首短视频"信号

## 这支最美的一个事实

战国纵横家（苏秦佩六国相印）与欧洲 1815 礼宾等级，相隔两千年
解决同一个问题：**让职业说客的信用可验证**——相印=授权文书、
国书=信用背书，形态不同，功能同构（外交信用装置的比较史）。

## 假设与依赖

外交档案连续可得（礼宾记录/使节名册结构化程度高）、外交形态
可分期、跨文明可比（"外交"概念的比较研究须自觉）。
