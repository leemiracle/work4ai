# 讲透国际政治学 · 无政府状态下的秩序

> 国际政治学：**在没有世界政府的世界上，秩序如何可能**——
> 战争与和平、合作与背叛、权力与制度，全部在"无政府"
> （anarchy，无最高强制者）约束下重演。

## 〇、家族定位（本质一句话）

国内政治的终极后盾是法院与警察；国际政治的终极后盾是**自助**
（self-help）——沃尔兹 1979 的这个公理重置了一切推理。本家族研究
无政府约束下的行为与秩序：大国博弈（国际关系理论）、秩序的演化
（国际关系史）、没有立法者的制度（国际组织）、以言代战的技艺
（外交学）及其历史（外交史）、跨国比较（国际比较政治）与分区
画像（区域政治：美英法德日俄欧亚太拉美非洲中亚西亚）。

**反直觉发现（家族级）**：无政府≠混乱。在没有警察的世界上，
贸易在增长、条约被遵守、航线在运行——**秩序不必来自最高权力，
可以来自恐惧、利益与惯例的平衡**（这正是IR 理论 300 年的核心
发现，也是博弈论重复博弈定理的政治版）。

## 二、诞生

- **1648 威斯特伐利亚和约**：主权原则奠基（学科的原点叙事）
- **1919 威尔士大学首创国际政治教席（Woodrow Wilson 主席）**：
  一战惨剧直接催生学科——"如何避免战争"是出生证上的第一行
- **1948 摩根索《国家间政治》**：古典现实主义立典
- **1979 沃尔兹《国际政治理论》**：结构现实主义——理论
  "科学化"的分水岭
- **1984 基欧汉《霸权之后》**：新自由制度主义应战
- **1992/1999 温特**："无政府是国家造出来的"——建构主义革命
- **1950s- 一至四次大辩论**：理想主义 vs 现实主义→传统主义 vs
  行为主义→范式间辩论→第四次（理性主义 vs 反思主义）；
  2020s "第五次大辩论"（非霸权秩序）正在被命名（家族 [01 章](01-近五年创新.md)）
