# 讲透国际关系史 · 秩序的演化

> 支：[讲透国际政治学](../README.md)（GB/T 81040 三级：国际关系史）。
> 一句话：**秩序换了好几茬，每次都以为自己是永恒**——
> 威斯特伐利亚到后冷战，一部"权力排列组合"的长卷。

## 定位句

本支负责**国际体系的秩序史**：威斯特伐利亚体系（1648）→
维也纳体系（1815）→ 凡尔赛-华盛顿体系（1919）→ 雅尔塔体系
（1945）→ 后冷战秩序（1991-）及当下的秩序过渡；每次秩序的
成因、运行、崩解是永恒的叙事骨架。

## 诞生与关键事件

- 1648 威斯特伐利亚和约：主权原则（学科原点叙事——
  "威斯特伐利亚神话"本身也被史家解构中）
- 1815 维也纳会议：欧洲协调（Concert）——第一个大国管理机制
- 1919 凡尔赛：理想主义的巅峰与失败（国联）
- 1945 雅尔塔+联合国：两极秩序 44 年
- 1989-1991 冷战终结：单极时刻与"历史终结"论
- 2008- 多极化/秩序过渡的命名与争论（家族 [01 章](../01-近五年创新.md)）

## 这支最美的一个事实

维也纳会议（1814-15）用"欧洲协调"把战乱 20 年的欧洲带进
近百年无全面战争——靠的不是惩罚法国，而是**把它请回大国
俱乐部**（均势的精髓是给对手留体面）——与凡尔赛的严惩
形成对照，后者 20 年后引爆二战。同一道题的两个答案，
相隔一百年。

## 假设与依赖

外交档案可得且可信（解密规则塑造史料分布）、"体系"可分期
（分期=理论选择）、长时段因果只能解释不能实验。
