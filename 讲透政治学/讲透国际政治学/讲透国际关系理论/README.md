# 讲透国际关系理论 · 无政府公理下的范式车间

> 支：[讲透国际政治学](../README.md)（GB/T 81040 三级：国际关系理论）。
> 一句话：**三家范式（现实/自由/建构）+一排中层理论（威慑/同盟/
> IPE），全部在"没有世界政府"这条公理上开工**。

## 定位句

本支负责**IR 的理论生产**：三大范式及其内部流派（进攻/防御
现实主义、制度/共和自由主义、常规/批判建构主义）、中层理论
（威慑、联盟、民主和平、国际政治经济学）与四次大辩论的学科史。

## 诞生与关键事件

- 1919 威尔士大学首设国际政治教席：学科诞生（避免战争之问）
- 1948 摩根索《国家间政治》：古典现实主义六原则
- 1979 沃尔兹《国际政治理论》：结构现实主义——理论科学化
- 1984 基欧汉《霸权之后》：新自由制度主义
- 1992 温特"无政府是国家造出来的"：建构主义宣言
- 2025 前后"第五次大辩论"（非霸权秩序）命名中
  （家族 [01 章](../01-近五年创新.md)）

| 问题 | 状态 |

## 这支最美的一个事实

温特的一句话改写整个学科的地基："无政府是国家造出来的"——
霍布斯式、洛克式、康德式三种无政府文化由互动建构：**敌人、
对手、朋友不是给定的，是实践出来的**（家族 [00 章](../00-体系结构.md)
三种文化的完整展开）。

## 假设与依赖

无政府公理、国家中心+理性（最低纲领三家共享；批判学派连
最低纲领也拆）；中层理论各自的形式内核在博弈论
（挂靠：[../../../讲透数学/讲透博弈论/](../../../讲透数学/讲透博弈论/)）。
