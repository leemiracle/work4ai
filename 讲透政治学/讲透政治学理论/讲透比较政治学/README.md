# 讲透比较政治学 · 没有实验室，就拿国家互相当对照组

> 支：[讲透政治学理论](../README.md)（GB/T 81010 三级：比较政治学）。
> 一句话：**为什么国家长得不一样**——民主、专制与之间的一切，靠系统
> 对比找规律。

## 定位句

本支负责**政体的比较科学**：把各国政治（政权类型、民主化、政党体系、
国家能力、政治暴力）放进同一张变量表，回答"什么条件下产生什么政体、
政体又造成什么后果"。它是政治学最大的实证车间。

## 诞生与关键事件

- 前 335 亚里士多德遍访 158 城邦写《政治学》——第一个比较政体研究
- 1950s-60s 行为主义+现代化理论（李普塞特《政治人》1959：
  "越富越民主"）确立现代范式
- 1968 亨廷顿《变化社会中的政治秩序》：现代化≠稳定，开创政治衰败研究
- 1991 亨廷顿《第三波》：20 世纪三次民主化浪潮的命名与解释
- 2010s-20s 民主衰退研究（列维茨基-威《民主如何死亡》2018）：显学化

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 经济发展是否导致民主化（现代化理论） | 🔄 前线（GDP 相关稳定，因果方向争） |

| 政党体系如何塑造政策与稳定 | ✅ 中层成熟（两党/多党效应已有复制） |
| 国家能力从何而来（战争→税收→官僚？） | 🔄 蒂利命题持续检验 |
| 比较的单位是"国家"还是"政权"？ | 🔄 单位虚构争论（方法论支接口） |

## 这支最美的一个事实

李普塞特 1959 年一张散点图（人均收入×民主）奠定了此后六十年议程——
**比较政治学最大的产业，始于一个可以画在明信片上的经验规律**。

## 假设与依赖

国家可比、政体可分级（Polity/V-Dem 可测）、样本国家独立性
（SUTVA 传染问题，见家族 [03 章](../03-可构造与结构.md)）。
