# 讲透政治学理论 · 权力如何被思考

> 政治学理论：**给"谁得到什么、何时得到、如何得到"（拉斯韦尔）提供概念、
> 解释与批判的底层学科**——比较的眼睛、社会的解剖、心理的显微镜、
> 地理的秤、学说史的长镜头、方法论的宪兵队。

## 〇、家族定位（本质一句话）

政治学理论是政治学的"底盘车间"：它不研究某一国某一年，而是生产
**看一切政治现象的通用镜片**——为什么有的国家民主稳固、有的反复崩溃
（比较政治学）；权力如何嵌入阶级、族群与市民社会（政治社会学）；
人为什么投票、为什么仇恨、为什么服从（政治心理学）；地理如何称量国运
（地缘政治学）；两千五百年智者如何接力定义"好政治"（中外政治学说史）；
以及——凭什么说你的解释是好的（政治学方法论）。

**反直觉发现（家族级）**：政治学理论的六大支不是"理论+五个应用"，
而是**三对互补的眼睛**——宏观（比较/地缘）配微观（心理学）、
实证（方法论）配规范（学说史）、结构（社会学）横切全部五支。

## 二、诞生

- **1880**：伯吉斯在哥伦比亚大学建政治学院，政治学从"历史与国家学"分家
- **1903**：美国政治学会（APSA）成立；1906《美国政治科学评论》创刊
- **1950s-60s 行为主义革命**：达尔、拉斯韦尔把"应然"逐出正门，只留"实然"
- **1969**：沃尔多等发动"后行为主义革命"——价值问题杀回（新制度主义萌芽）
- **1990s-2000s**：因果推断革命（KKV 1994）+ 形式模型（理性选择）双引擎定型
