# 讲透中外政治学说史 · 2500 年"好政治"定义权之争

> 支：[讲透政治学理论](../README.md)（GB/T 81010 三级：中外政治学说史）。
> 一句话：**从孔子到罗尔斯，每代智者都在回答同一组问题——
> 谁应当统治、服从为什么正当、好生活需要什么制度**。

## 定位句

本支负责**政治观念的谱系学**：中西两大传统（先秦诸子—宋明—近世西学
东渐；希腊—中世纪—现代性）如何各自提出并重答"权力正当性"问题，
以及两大传统在近代的相遇与互译。它是家族中唯一的规范话种正主场
（见家族 [02 章](../02-语言特征.md)双语种分析）。

## 诞生与关键事件

- 前 5 世纪双峰并峙：孔子（德治/正名）与柏拉图（哲学王/正义城邦）
  几乎同时开题
- 前 4 世纪 亚里士多德《政治学》与商鞅/孟子的政体与仁政之争
- 1513 马基雅维利《君主论》：政治与道德分家——现代性的起点之一
- 1651 霍布斯《利维坦》：从自然状态推出主权——契约论开山
- 1762 卢梭《社会契约论》：公意；1789 法国大革命=学说的大实验
- 1867 马克思《资本论》：政治的根基在生产关系——意识形态批判
- 1971 罗尔斯《正义论》：契约论复活，规范政治哲学 20 世纪下半叶
  重新合法化；1974 诺齐克《无政府、国家与乌托邦》右翼应战

## 这支最美的一个事实

罗尔斯"无知之幕"：让立法者在不知道自己将是富人穷人、多数少数的
情况下选规则——**用一个思想实验，把两千年的"公正旁观者"直觉
锻造成可论证的原理**，规范政治哲学由此从死地复活。

## 假设与依赖

文本可诠释（诠释学循环承认）、观念史有连续性（洛夫乔伊单元观念
假说）、中西可比（可比性本身是争论点）；依赖家族 02 章的"话种纪律"：
学说史研究"论证质量"而非"真伪预测"。
