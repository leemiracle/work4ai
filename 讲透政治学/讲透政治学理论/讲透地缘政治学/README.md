# 讲透地缘政治学 · 地理如何称量权力

> 支：[讲透政治学理论](../README.md)（GB/T 81010 三级：地缘政治学）。
> 一句话：**山川、海岸与距离是政治的慢变量**——国家战略被地理
> 悄悄打上刻度。

## 定位句

本支负责**权力的空间分析**：地理位置（临海/内陆/心脏地带）、
资源分布（石油/粮食/航道）、距离与投射成本如何约束国家行为——
以及"地缘"如何作为一种战略话语被使用与滥用。

## 诞生与关键事件

- 1890 马汉《海权对历史的影响》：制海权决定强国命运
- 1904 麦金德"心脏地带"演讲：欧亚内陆枢轴论——"谁统治心脏地带，
  谁就统治世界岛"
- 1942 斯皮克曼"边缘地带"：修正麦金德——沿海边缘带才是枢纽
- 1940s 德国地缘政治学（Haushofer）被纳粹挪用→战后学科污名化
- 1990s 埃斯（Ó Tuathail）批判地缘政治学：不问地理是否决定，
  问**谁在用地理讲故事**；2022 后经典词汇随大国竞争回归

## 这支最美的一个事实

麦金德 1904 年一篇 30 分钟演讲支配了此后 120 年的战略语言——
"心脏地带"被苏联、美国、俄罗斯战略家轮番引用：**一个学术隐喻的
生命周期比帝国还长**（这正是批判地缘政治学的研究对象）。

## 假设与依赖

地理是慢变量（技术会改写距离成本——航母/导弹/互联网）、空间分析
单位（国家为点）合法、战略行为体理性；批判派则连"地理实在性"
本身也问题化。
