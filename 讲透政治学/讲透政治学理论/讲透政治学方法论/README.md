# 讲透政治学方法论 · 政治学的宪兵队与军械库

> 支：[讲透政治学理论](../README.md)（GB/T 81010 三级：政治学方法论）。
> 一句话：**当别人说"研究表明"，本支负责问——凭什么信？**

## 定位句

本支负责**研究的质量科学**：因果识别（实验/自然实验/观测设计的
假设账本）、测量（概念→指标的信度效度）、定性-定量-形式模型三大
传统的语法统一、以及复制危机后的学术规范（预注册/透明度）。

## 诞生与关键事件

- 1920s 芝加哥学派入户调查：数据进政治学
- 1950s 行为主义：统计与调查法立宪（达尔、伊斯顿）
- 1969 后行为主义反扑：价值问题不许被方法驱逐（沃尔多）
- 1994 KKV《社会科学中的研究设计》：定性研究=隐式统计推断，
  两传统统一纲领（争议至今）
- 2000s 因果推断革命：Green-Gerber 田野实验、Imai 等
  《Quantitative Social Science》教科书化；2020s 预注册成顶刊常态

## 这支最美的一个事实

选举"断点设计"：得票率 50% 附近的险胜/险败近似随机分配——
**学者把"险胜"当成了大自然的掷硬币**，由此识别连任、席位与政策
的因果效应（Lee 2008；无实验世界的准实验典范）。

## 假设与依赖

潜在结果框架（Neyman-Rubin）、无混淆/外生冲击等识别假设"凭结构
信念收下"、测量论（信度/效度可分离）；对"科学统一性"的元假设
（后现代阵营否认）。
