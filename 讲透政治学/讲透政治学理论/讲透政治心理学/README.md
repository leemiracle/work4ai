# 讲透政治心理学 · 政治行为的个体发生学

> 支：[讲透政治学理论](../README.md)（GB/T 81010 三级：政治心理学）。
> 一句话：**把镜头从国家推近到选民的眼睛——人为什么投票、仇恨、
> 服从与觉醒**。

## 定位句

本支负责**政治的微观机制**：态度从哪来（家庭/媒体/人格）、信息如何
被加工（动机性推理/确认偏误）、身份如何驱动行为（党派性/情感极化）——
用心理学的实验与测量解释政治行为的个体差异。

## 诞生与关键事件

- 1930 拉斯韦尔《精神病理学与政治》：精神分析进政治学
- 1950 阿多诺《权威人格》：反犹与法西斯倾向的人格结构
- 1960 坎贝尔《美国选民》：政党认同=政治态度的"分子键"
- 1972 Converse 信念系统研究：大众意识形态的"天真与无结构"
- 2000s-20s 情感极化（Iyengar 等）：党派身份→道德部落；
  复制危机（2010s）后大样本预注册成新常态

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 政治态度来自信息还是身份（先有立场还是先有理由） | 🔄 动机性推理前线 |
| 权威人格是否稳定构念 | 🔄 复制危机后复活（2010s 跨国测量） |
| 媒体/社交媒体是否极化 electorate | 🔄 因果证据混合（选材效应 vs 内容效应） |
| 为什么投票（理性选民悖论：一票决定率≈0） | ✅ 有解：D+选票（Riker-Ordeshook 1968）+表达性投票 |
| 政治人格学（Openness/Conscientiousness 大五预测倾向） | 🔄 稳定小效应积累中 |

## 这支最美的一个事实

投票的期望收益≈0（你的票改变结果的概率约百万分之一），但人们照样
排队投票——**"为什么投票"这个最日常的行为，是理性选择理论最大的
钉子户，也是表达性/义务性动机的最好证词**。

## 假设与依赖

个体层面可测（调查/实验）、心理构念跨政治文化可比、实验刺激的
外部效度（一节实验课的诱导≠十年党争）。
