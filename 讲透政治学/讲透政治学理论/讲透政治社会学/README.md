# 讲透政治社会学 · 权力的土壤学

> 支：[讲透政治学理论](../README.md)（GB/T 81010 三级：政治社会学）。
> 一句话：**政治不是悬浮的——它长在阶级、族群、结社与信仰的土壤里**。

## 定位句

本支负责**政治的社会基础**：谁参与、谁动员、谁被排除——社会结构
（阶级/族群/宗教）如何变成政治力量（政党/运动/投票 bloc），
政治又如何反过来重塑社会。

## 诞生与关键事件

- 1835 托克维尔《论美国的民主》：结社密度=民主的活力计
- 1897 韦伯《新教伦理》：文化如何供养政治经济秩序
- 1950s 李普塞特、阿尔蒙德：政治文化学派（《公民文化》1963）
- 1970s 资源动员理论（Tilly、McCarthy & Zald）：社会运动从"集体
  非理性"变成"有组织的理性事业"
- 1993 普特南《使民主运转起来》：意大利南北市民社会实验对比——
  制度相同、绩效迥异，"社会资本"成为世纪关键词

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 社会资本是否因果地滋养民主 | 🔄 普特南命题三十年检验（因果方向未决） |
| 为什么有人投票有人不投 | ✅ 中层成熟（教育/年龄/动员效应可复制） |
| 新社会运动（环境/身份/性别）取代阶级斗争了吗 | 🔄 后物质主义争论 |
| 族群政治何时暴力化 | 🔄 前线（恐惧与制度设计之争） |
| 政治信任为何长期下滑 | 🔄 跨国趋势待解释 |

## 这支最美的一个事实

普特南发现：意大利南北 20 个大区 1970 年同时拿到一模一样的制度，
二十年后治理绩效天差地别——**制度移植会排异，土壤决定收成**
（一次"天然对照实验"，虽识别仍被质疑）。

## 假设与依赖

社会结构可测量（阶层/结社指数）、"社会"与"政治"可分析性分离
（批判理论反对）、调查数据跨文化可比（等值测量假设）。
