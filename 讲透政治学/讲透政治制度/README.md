# 讲透政治制度 · 规则如何塑造权力

> 政治制度：**权力的成文轨道**——议会、行政、司法、政党、选举五套
> 机器加上它们的古今中外演化史。制度是政治学中刚性最高的对象：
> 规则写在国际法与宪法文本上，可以被逐条构造、比较与设计。
>

> 模式母版：[讲透数学/GB-T13745全景.md](../../讲透数学/GB-T13745全景.md)。

## 〇、家族定位（本质一句话）

政治学理论回答"权力如何被思考"，本家族回答"**权力如何在轨道上运行**"。
制度=持久、成文、可执行的规则集合（谁投票、怎么算票、谁执行、
任期多久、争议谁裁决）。本家族的五套机器（议会/行政/司法/政党/选举）
+ 两个历史纵轴（中国/外国制度史）构成全部 8 支。

**反直觉发现（家族级）**：制度是"冻结的Politics"——每条看似中性的
规则（选区怎么画、任期几年、简单多数还是三分之二）都是**某次政治
斗争的胜者写下的、约束后来所有人的解**。研究制度=读取历史斗争的
化石层。

## 二、诞生

- **1787 费城制宪**：第一次工程化的制度设计——分权制衡从学说
  （孟德斯鸠 1748）变成成文操作系统，并带出"联邦党人文集"这份
  制度设计说明书
- **1867-1918**：内阁制、比例代表制（比利时 1899 首创 PR）、
  政党法在欧洲成型
- **1950s-60s**：制度研究被行为主义边缘化（"制度只是舞台"）
- **1984+ 新制度主义回归**：马奇-奥尔森"重新发现制度"；
  诺思（经济史侧）与温加斯特（政治侧）把制度变成自变量
- **1990s**：转型国家立宪潮=制度设计的世纪大实验（结果参差，
  喂养了整个比较制度文献）
