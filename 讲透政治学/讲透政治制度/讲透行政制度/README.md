# 讲透行政制度 · 执行机器的构造

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：行政制度）。
> 一句话：**法律不会自己走路**——谁执行、怎么组织、对谁负责，
> 这就是行政制度。

## 定位句

本支负责**政府首脑与执行机关的比较构造**：总统制/议会制/半总统制/
委员会制的分野、行政权与立法权的关系（分立或融合）、行政机构设置
（部委/独立机构/国有企业）。本支是制度视角的"外壳"，
官僚机器内部详读转 [../../讲透行政学/](../../讲透行政学/)。

## 诞生与关键事件

- 1887 威尔逊《行政学之研究》："行政应当走在政治之外"——
  政治/行政二分法开山
- 1900 古德诺《政治与行政》：二分法教科书化
- 1787 vs 1867：美国总统制与英国内阁制分道（同一问题的两种解）
- 1958 法国第五共和国：半总统制发明（双首长杂交种）
- 1990 Linz"总统制的危害"：固定任期+赢家通吃→民主崩溃风险论战

| 行政权扩张是否全球趋势（行政国家） | 🔄 前线 |

## 这支最美的一个事实

央行独立性：把货币政策交给不用面对选举的技术官僚，通胀反而更低——
**主动放弃一部分民主控制，换来了更好的经济结果**（ Rogoff 保守
中央银行家定理：承诺装置的政治学）。

## 假设与依赖

行政权可从政治环境中界定（二分法理想化，被西蒙以来的研究软化）、
宪法文本反映实际权力运行（纸面/运行之别）、政体类型可互斥编码。
