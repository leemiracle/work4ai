# 讲透政党制度 · 组织化竞争的机器

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：政党制度）。
> 一句话：**政党是民意的分包商**——把散装的偏好打包成可交易的
> bloc，政党制度就是这个市场的结构。

## 定位句

本支负责**政党与政党体制的比较研究**：政党从哪来（体制内外/
宗族/阶级/教派）、政党体制类型学（两党/温和多党/极化多党/一党
主导）、政党组织形态（干部党→群众党→卡特尔党→数字党）、
政党法与政党管制。

## 诞生与关键事件

- 18 世纪末英国辉格/托利：议会内派系→现代政党胚胎
- 19 世纪末欧洲群众党（社民党）：政党第一次成为会员制机器
- 1942 Duverger《政党》：机械效应+心理效应——选举制度造政党
- 1967 萨托利《政党与政党体制》：竞争-霸权谱系总图
- 1995 Katz-Mair 卡特尔党：政党变成国家供养的准公共机构
- 2010s-20s 数字政党/个人化政党（ Macron 的 En Marche、
  社媒党）：组织形态新突变

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 政党数量由什么决定（Duverger 定律的社会+制度双因） | ✅ 半解决（机械效应确立，心理效应因果仍争） |
| 政党在衰亡吗（党员流失/政党政府弱化） | 🔄 前线（Mair"空洞的政党民主"） |
| 极化多党制为何难以治理（萨托利极化多党陷阱） | ✅ 类型学成熟 |
| 新党为何有的存活有的闪灭 | 🔄 生存分析活跃 |
| 政党个人化（领袖品牌替代党品牌） | 🔄 2020s 核心新题 |

## 这支最美的一个事实

Duverger 的"心理效应"：选民明明最爱第三党，却因"它赢不了"
而含泪投给两大党之一——**选民用预期投票喂养了两党制，两党制
又反过来证实他们的预期**（自证预言的政治制度版）。

## 假设与依赖

政党=追求选票/office 的组织（Downs 供给面假设）、政党体制可
类型化（连续谱切割的边界争议）、组织形态演化有方向（后被数字
政党证伪一部分）。
