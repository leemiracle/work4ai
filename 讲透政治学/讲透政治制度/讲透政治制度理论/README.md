# 讲透政治制度理论 · 制度为什么有效、如何设计、如何变迁

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：政治制度理论）。
> 一句话：**其余七支研究"什么制度"，本支研究"制度"本身**——
> 规则凭什么被遵守、何时被设计、怎样演化。

## 定位句

本支负责**制度的元理论**：制度的有效性来源（强制/合法性/自我实施）、
制度变迁的动力（路径依赖/关键节点/渐进演化）、制度设计的方法论
（机制设计向政治的移植）——为七支具体制度研究供给分析框架。

## 诞生与关键事件

- 1748 孟德斯鸠分权学说→1787 费城制宪：制度设计第一工程
- 1962 布坎南-塔洛克《同意的计算》：宪政经济学——最优多数的
  成本曲线
- 1984 马奇-奥尔森《重新发现制度》：新制度主义宣言
- 1990 诺思《制度、制度变迁与经济绩效》：路径依赖与报酬递增
- 2002 Tsebelis《否决者》：制度比较的统一几何

## 这支最美的一个事实

诺思的"QWERTY 键盘政治学"：制度一旦上路，转换成本随使用者增多
而上升——**劣质制度可以靠先发优势永久锁死优质替代品**
（路径依赖=报酬递增的政治版）。

## 假设与依赖

制度可从环境中分析性剥离（批判：制度=文化整体）、行为者响应激励、
"有效性"可操作化；机制设计依赖共同知识与可承诺假设。
