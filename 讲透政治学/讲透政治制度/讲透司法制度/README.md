# 讲透司法制度 · 争议的最终裁决者

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：司法制度）。
> 一句话：**国家的质检科与安全阀**——当政治吵到无解，谁有权说
> "这一条不算数"。

## 定位句

本支负责**法院系统的比较构造**：司法审查（法院推翻立法的权力）的
强弱与模式（分散式美国 vs 集中式欧洲宪法法院）、法官选任与任期、
司法独立与问责的平衡、最高法院的政治角色。

## 诞生与关键事件

- 1803 马伯里诉麦迪逊：马歇尔大法官"顺手"夺走司法审查权——
  美国宪法没写这一条
- 1920 奥地利宪法法院（凯尔森设计）：集中审查的欧洲模式
- 1953-69 沃伦法院：司法主动主义的世纪样本（布朗案推翻种族隔离）
- 1958 德国联邦宪法法院：宪法诉愿——公民可直接告法律
- 1990s 全球司法扩权（the judicialization of politics，
  Tate-Vallinder 命名）

## 这支最美的一个事实

马伯里案：马歇尔既拒绝发令状（避免与总统硬撞），又宣布国会授权
违宪（夺取审查权）——**用一次战术撤退完成一次战略夺权**，
两百年的宪政基石出自一桩没打赢的官司。

## 假设与依赖

"司法独立"可测量（de jure 条文 vs de facto 行为两套指标）、
法官行为可用策略/态度模型化、跨法系可比（普通法 vs 大陆法的
审查模式差异须显式建模）。
