# 讲透议会制度 · 代议制引擎

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：议会制度）。
> 一句话：**把千万人的偏好熬成法案的锅炉**——一院还是两院、
> 委员会如何分权、议程由谁设置。

## 定位句

本支负责**立法机关的比较研究**：议会制与总统制下的立法过程、
一院制 vs 两院制（缓冲 vs 拖延）、委员会制度（专业化的车间）、
议程设置权（谁排菜单谁掌勺）。

## 诞生与关键事件

- 1265 孟福尔议会（英国）：平民首次入院
- 1689 权利法案：议会主权原则确立
- 1787 美国制宪：两院制+分权设计（参院代表州、众院代表人口）
- 1970s-80s Shepsle-Weingast：结构诱导均衡——议程规则造就立法
  稳定（家族 [04 章](../04-政治制度转代码.md)实验现场）
- 1990s 议会研究数据化（Parlgov/DBP 数据库）

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 两院制是否显著改变政策产出 | ✅ 中层成熟（否决点多→更保守/更多现状偏置） |

| 议会问政质量如何测量（发言/质询数据） | 🔄 文本大数据新前线 |
| 议会衰落（行政扩张）是否全球趋势 | 🔄 争论中 |
| 比例代表制议会是否更碎片低效 | 🔄 效率-代表性权衡持续检验 |

## 这支最美的一个事实

Shepsle 的发现：即使全体议员偏好成环（孔多塞循环），委员会管辖权+
修正规则的铁笼也能产出稳定法案——**混乱的多数被冰冷的议程驯服**，
这就是"结构诱导均衡"（本家族 04 章实验 [4] 可亲手复现）。

## 假设与依赖

立法行为可模型化（投票=空间偏好）、议程规则可编码（Krehbiel 的
规则测量之争）、跨体制可比（总统制立法与议会制立法的"同构"假设）。
