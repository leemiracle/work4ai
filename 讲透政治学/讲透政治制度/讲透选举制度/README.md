# 讲透选举制度 · 民意的翻译器

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：选举制度）。
> 一句话：**同一张民意输入，换一种翻译器就输出不同的政府**——
> 选举制度是政治学中最"工程"的部件。

## 定位句

本支负责**选票→席位规则的设计与效应**：公式家族（多数制/比例制/
混合制/排序制）、参数（选区规模、门槛、修正席）、效应（代表性/
政党数/治理效率/少数保护）、以及选举制度的选择政治学。

## 诞生与关键事件

- 1850s 英美多数制成型；单选区简单多数=FPTP
- 1899 比利时首创比例代表制（D'Hondt 公式工业化）
- 1942 Duverger《政党》发表；1945 后 PR 全球扩散
- 1949 德国发明混合成员制（MMP）：直选+政党名单双轨
- 1990s-2010s 排序复选（IRV）/两轮制/批准投票的地方实验
- 2010s-20s 选举公投时代：规则变更本身成为政治议题
  （家族 [01 章](../01-近五年创新.md)）

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 选举制度→政党体制（Duverger） | ✅ 半解决（最强经验定律之一） |
| PR 是否提高投票率/满意度 | 🔄 2024-25 重审（适应效应研究） |
| 门槛与代表性的最优权衡 | 🔄 设计问题（无最优解，价值权衡） |
| 选区重划（gerrymandering）如何检测 | 🔄 数学法庭科学前线 |
| 改革何时发生（谁推动规则变更） | 🔄 内生改革研究 |

## 这支最美的一个事实

D'Hondt 与 Sainte-Laguë 只差一个除数序列（1,2,3… vs 1,3,5…），
却系统性地分别优待大党与中立对待小党——**一条整除规则里藏着
半部政党体系的命运**（家族 [04 章](../04-政治制度转代码.md)
走廊 1 可亲手验算）。

## 假设与依赖

席位换算可精确复算（确定性最强）、选民与政党对规则响应（心理
效应假设）、跨国制度参数可比（数据库编码成熟）。
