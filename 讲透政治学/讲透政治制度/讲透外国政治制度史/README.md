# 讲透外国政治制度史 · 从抽签到代议制

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：外国政治制度史）。
> 一句话：**一部"谁有资格统治"的资格名单扩编史**——从雅典公民到
> 普选权，两千年五次大扩容。

## 定位句

本支负责**中国以外政治制度的演化史**：雅典民主（抽签+轮流执政）、
罗马混合政体（执政官-元老院-保民官）、中世纪等级会议与城市自治、
英国议会主权之路（1215-1689-1832）、美国成文宪法（1787）、
欧洲大陆立宪与比例代表（19 世纪末）、20 世纪三波民主化及其
制度选择。

## 诞生与关键事件

- 前 508 克利斯提尼改革：雅典民主制奠基（部落重划+陶片放逐）
- 前 27-公元 14 奥古斯都：共和国包装下的帝制（principate）
- 1215 大宪章：国王也要守约——契约原则首胜
- 1689 英国权利法案/1787 美国宪法：现代代议制双原件
- 1899 比利时 PR：选举制度设计时代的开启
- 1974- 葡萄牙政变开启第三波民主化（亨廷顿命名）

## 这支最美的一个事实

雅典民主的默认选官方式不是投票而是**抽签**（kleroterion 抽签机
至今存于博物馆）：雅典人认为投票天然偏向有钱有名的，抽签才是
真平等——**两千年后"随机公民大会"（citizens' assembly，
爱尔兰修宪用）重新发明了同一台机器**。

## 假设与依赖

制度演化叙事有连续性（"西方传统"整体化有建构性）、史料跨语言
可比、殖民地制度传播可追踪（"移植"隐喻的限度须警惕）。
