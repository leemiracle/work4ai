# 讲透中国政治制度史 · 三千年制度连续体

> 支：[讲透政治制度](../README.md)（GB/T 81020 三级：中国政治制度史）。
> 一句话：**世界史上最长命的官僚制样本**——从封建到郡县、从察举到
> 科举、从宰相到军机，一部"如何治理超大规模国家"的完整实验记录。

## 定位句

本支负责**中国历代政治制度的源流与结构**：政体框架（封建/郡县/
行省）、中央官制（三公九卿→三省六部→内阁军机）、选官制度
（世袭→察举→九品中正→科举）、监察制度（御史台/都察院）、
基层制度（乡里/保甲/编户齐民），及近代立宪尝试与当代制度的历史
资源。

## 诞生与关键事件

- 前 221 秦并天下：废封建立郡县——官僚制取代封建制的总开关
- 前 134 汉武帝察举：儒家士人进入选官管道
- 587 隋开科举（至 1905 废）：一千三百年的人才发动机
- 1380 明废丞相：皇权直接领六部——宰相制度终结
- 1729 雍正设军机处：奏折-军机系统=信息集权顶点
- 1906-11 清末新政与《钦定宪法大纲》：传统制度体系最后的
  自我改造尝试
- 1930s-40s 钱穆《中国历代政治得失》等：本支现代叙事奠基

## 这支最美的一个事实

科举不仅选官，还是**自愿参与的忠诚制造机**：落第者一生备考的
行为本身就是对体制的持续投资（"科举让你忙到没有时间造反"，
亦称"安全阀效应"）——一次制度设计同时解决人才与忠诚两个问题。
