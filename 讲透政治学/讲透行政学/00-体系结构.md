# 00 · 体系结构：一条主轴与四个部件

> **本章回答五问之一（本家族：讲透行政学）。**
> 行政学的大厦=**一条主轴**（政治-行政二分及其百年松动）×
> **四个部件**（组织/人事/财务/决策）——主轴是学科的自我怀疑，
> 部件是机器的解剖图。

---

## 一、直觉图像：先看画面

想象一所政务大厅：取号机（**决策**：谁先被服务——队列规则）、
窗口（**组织**：按部门切分的柜台）、柜员（**人事**：考进来的、
有编制的、看绩效的）、后面的预算科（**财务**：每个窗口每小时
成本几何）。窗口里坐着的"街头官僚"（Lipsky 1980）手握裁量权，
把政策翻译成你听到的那句"材料不全，回去补"——**国家与公民的
第一次见面，发生在行政的显微镜下**。

**严格陈述**：行政学=研究公共政策执行的组织科学，对象为官僚体系
（bureaucracy）的组织结构、人事制度、财务流程与决策机制；
与政治学的分界线（如果存在）在"决策的政治形成 vs 决策的组织执行"。

**最小例子**：同一个"扶贫"政策，五个县的执行可以天差地别——
行政学解释这 80% 的"执行方差"；政治学通常只解释那 20% 的
"决策方差"（Pressman-Wildavsky《执行》1973 的著名教训）。

## 二、一条主轴：政治-行政二分及其百年松动

| 阶段 | 信条 | 松动方式 |
|------|------|---------|
| 1887-1946 古典时期 | 政治/行政可分（威尔逊-古德诺）；行政=效率技术（泰勒同源） | —— |
| 1947-1970s 行为革命 | 西蒙："行政=决策"；事实/价值二分替换政治/行政二分 | 决策有政治 |
| 1970s-80s 批判转向 | 公共选择（Niskanen：官僚=预算最大化者）；街头官僚（裁量无处不在） | 执行有政治 |
| 1990s- NPM 与回摆 | 企业化政府（顾客隐喻）；新公共服务（公民不是顾客） | 价值回归 |
| 2020s 数字国家 | 平台政府/算法行政：裁量被代码接管的争论 | 技术重塑主轴 |

**主轴的今日状态**：二分作为描述已死，作为规范（专业中立公务员）
仍活在各国文官制度里——**学科以否定自己出生证的方式成长**。

## 四、怎么产生的（②：三个原生问题）

1. **"分赃制之痛"**（效率之问）：19 世纪美国"政党分赃"（spoils
   system）使政府随选举大换血、腐败横行——1883 彭德尔顿法确立
   考试文官制，威尔逊 1887 写学科出生证：要一个不随政治颠簸的
   执行机器。
2. **"组织为何僵化"**（官僚制之问）：韦伯 1922 给出理想型
   （层级/规则/档案/专业/非人格化）同时预言"铁笼"；米歇尔斯
   "寡头铁律"（1911）与默顿"官僚人格"（1940）接棒——行政学
   从第一天起就在研究自己的病。
3. **"决策为何荒腔走板"**（决策之问）：西蒙 1947 推翻"完全理性"
   （满意化取代最优化）；林德布洛姆 1959"渐进主义"（muddling
   through）；Cohen-March-Olsen 1972 垃圾桶模型（本家族实验）——
   组织决策的三连击全部来自对"理性计划"的失望。

📖 故事框：**《执行》的奥克兰教训**。1970 年 Pressman 与
  Wildavsky 受命研究联邦项目在奥克兰的落地：明明人人同意、钱也
  到位，项目还是死了。答案：**执行链条上 70 个决策点，每点
  90% 同意率，联合通过率 0.9^70 ≈ 0.06%**——"协议的复杂性"
  这个概念由此诞生，执行研究成为独立领域。

## 五、核心问题清单（③）

| 问题 | 状态 | 地位 |
|------|------|------|
| 官僚是否预算最大化（Niskanen 1971） | 🔄 半解决 | 理论被广泛引用，直接检验困难（目标不可观测） |
| 街头官僚裁量如何治理 | 🔄 前线 | Lipsky 框架持续产出（AI 裁量=新战场） |
| 代表制官僚（官僚人口构成→政策偏向） | 🔄 证据积累中 | 2020s 人口结构变化使其更热 |
| 绩效预算为何常失败 | 🔄 | 半世纪改革史，形式化-退潮循环 |
| 公务员考试能否筛选能力 | ✅ 中层 | 信度研究成熟，效度外部检验持续 |
| 组织决策能否被"设计"改进 | 🔄 | 西蒙纲领部分兑现（AI 决策支持） |

## 六、假设与代价（④总纲）

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 政治/行政可分 | 专业中立的技术自主性 | 决策政治性的盲区（已被修正） |
| 效率=可测量 | 绩效管理、问责工具 | 目标置换（完成指标≠完成使命） |
| 官僚=理性响应激励 | Niskanen 类可计算模型 | 公共动机（public service motivation）被外生化 |
| 组织=机器 | 结构-流程可设计 | 混沌性（垃圾桶）被低估 |

✨ **美之时刻 1**：垃圾桶模型——组织决策被重画为四股独立的流
  （选择机会、问题、方案、参与者）在"垃圾桶"里随机相遇：决策不是
  "解决问题"，常常是**"问题搭上了恰好路过的方案"**。它把组织从
  理性机器变成混沌花园，却能精确预言"决策风格随负载变化"的规律
  （本家族实验可亲手复现）。美在"意外"：最反理性的模型反而给出
  可检验的组织规律。
