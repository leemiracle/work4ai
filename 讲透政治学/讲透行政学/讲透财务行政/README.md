# 讲透财务行政 · 谁给国家记账

> 支：[讲透行政学](../README.md)（GB/T 81030 三级：财务行政）。
> 一句话：**预算是国家的骨架透视片**——看钱的流向，比听所有的
> 演讲都诚实。

## 定位句

本支负责**公共预算与财政管理**：预算编制（基数 vs 零基 vs 绩效）、
预算过程政治（渐进主义/预算最大化）、绩效与审计（合规审计到
绩效审计）、政府采购与债务管理。

## 诞生与关键事件

- 1215 大宪章：征税须同意——预算问责的基因
- 1921 美国预算与会计法：行政预算体系确立（ progressives 的
  标志性胜利）
- 1961 PPBS（规划-计划-预算体系）：兰德进国防部——"理性预算"
  的世纪尝试
- 1964 Wildavsky《预算过程中的政治》：渐进主义实证——
  预算=去年的预算+微调
- 1971 Niskanen 官僚预算最大化模型；1990s 绩效预算全球回潮

## 这支最美的一个事实

Wildavsky 数美国预算数字发现：各机构每年预算变动大多在 ±5%
内——**表面吵翻天的预算听证会，实际只是"去年 X 光片"的
复读**。渐进预算=把冲突最小化的政治技术（后来 Niskanen/
绩效改革都是对这台复读机的革命，各有成败）。

## 假设与依赖

预算数据可比（科目体系的政治性须处理）、财政年度可比、
"绩效"可编码（绩效定义=价值判断，家族 [02 章](../02-语言特征.md)
三账之汇率题）。
