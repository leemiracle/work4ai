# 讲透行政组织 · 机器的构造

> 支：[讲透行政学](../README.md)（GB/T 81030 三级：行政组织）。
> 一句话：**层级、幅度、部门化——国家执行机器的结构力学**，
> 以及结构尽头那个有血有肉的柜员。

## 定位句

本支负责**行政组织的结构与行为**：组织设计参数（层级/幅度/
部门化/标准化）、组织间网络（府际关系/协作治理）、街头官僚
（一线裁量），以及组织变革的动力学。

## 诞生与关键事件

- 1922 韦伯官僚制理想型：现代组织学的公理集
- 1938 巴纳德《经理人员的职能》：组织=协作系统（目的+意愿+沟通）
- 1961/1979 明茨伯格《组织的结构》：五配器（战略顶层/中间层/
  操作核心/技术结构/支持人员）——组织设计总图
- 1980 Lipsky《街头官僚》：一线裁量=影子政策制定
- 1990s- 网络治理（Agranoff-McGuire）：层级之外的市场与网络

## 这支最美的一个事实

明茨伯格"五配器"：任何组织图都只有五个器官——战略顶层的脚
踩操作核心的手，中间被技术结构与支持人员夹着；**教会、游击队、
政府部委与硅谷公司共用同一副骨架**，差别只在哪个器官肥大。

## 假设与依赖

组织可从环境中界定、结构可编码（幅度/层数可数）、权变假设
（环境-结构匹配）；批判：组织=权力装置，效率语言掩盖支配
（02 章公义语）。
