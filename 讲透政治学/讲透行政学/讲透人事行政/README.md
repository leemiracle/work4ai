# 讲透人事行政 · 选人、用人与代表性

> 支：[讲透行政学](../README.md)（GB/T 81030 三级：人事行政）。
> 一句话：**国家用谁的手干活**——考录、晋升、激励与一个深层
> 问题：官僚队伍应该长成社会的样子吗。

## 定位句

本支负责**公务员制度的设计与效应**：考录体系（考试信度效度）、
职位分类与职级晋升、薪酬与激励（绩效工资之争）、政治任命与
职业文官的边界、代表制官僚（官僚人口构成的政策后果）。

## 诞生与关键事件

- 前 111 中国汉代太学取士→587 科举：世界最早考试文官制
- 1855/1870 英国诺斯科特-屈维廉改革：现代文官考试制开端
- 1883 美国彭德尔顿法：分赃制终结
- 1974 Kingsley/Krislov 代表制官僚概念：官僚构成=政策偏向
- 1990s 绩效工资改革全球扩散与反复；2020s 韧性/数字化技能重塑

## 这支最美的一个事实

代表制官僚的"积极代表"研究：当官僚队伍里有一线教师、警察、
审批员"长得像"服务对象时，政策执行真的会变软或变硬——
**一张花名册就是一套政策参数**（人员构成=政策变量）。

## 假设与依赖

能力可测（考试假设）、激励可设计（代理理论）、官僚构成可统计
（人口分类的政治性须自觉）；PSM 的跨文化测量等值假设。
