# 讲透行政决策 · 从理性计划到垃圾桶

> 支：[讲透行政学](../README.md)（GB/T 81030 三级：行政决策）。
> 一句话：**组织怎么拿主意**——三连击推翻"理性人"之后，
> 决策成了社会科学最反直觉的展区。

## 定位句

本支负责**决策理论与决策支持**：完全理性 vs 有限理性、渐进
主义（muddling through）、垃圾桶模型（组织无政府状态）、
群体思维（groupthink）与危机决策、循证决策与决策支持系统
（DSS→AI 决策）。

## 诞生与关键事件

- 1947 西蒙《行政行为》：满意化替代最优化
- 1959 林德布洛姆《渐进调适的科学》：" Branch 方法"对
  "Root 方法"
- 1972 Cohen-March-Olsen 垃圾桶模型：组织无政府状态的数学像
- 1972 Janis《群体思维》：猪湾决策解剖（凝聚团体=劣质决策？）
- 1973 Pressman-Wildavsky《执行》：协议复杂性 0.9^70
- 2010s- 循证决策运动（nudge 单位扩散）+算法决策进入政府

## 这支最美的一个事实

垃圾桶模型的名言：**决策的产出常常不是"问题的答案"，而是
"方案找到了它的问题"**——组织里游荡的现成方案（一个待岗的
信息系统、一笔待花的预算）会主动认领新出现的问题
（"手里拿锤子，看什么都是钉子"的组织版定理）。

## 假设与依赖

决策过程可观察复原（访谈/档案偏差）、有限理性为公理、
垃圾桶的"模糊偏好"假设（组织无政府状态三特征：问题偏好
模糊/手段目的不清/参与者流动性）。
