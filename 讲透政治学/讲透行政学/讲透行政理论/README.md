# 讲透行政理论 · 政治与行政之间的百年争论

> 支：[讲透行政学](../README.md)（GB/T 81030 三级：行政理论）。
> 一句话：**学科的出生证与它的百年自我怀疑**——行政能否独立于
> 政治、官僚制是铁笼还是骨架、公共性到底是什么。

## 定位句

本支负责**行政学的元理论**：政治-行政二分法的历史与修正、
韦伯官僚制理想型及其批判、公共行政的范式之争（古典/NPM/新公共
服务/数字治理）、行政伦理与公共价值。

## 诞生与关键事件

- 1887 威尔逊《行政学之研究》：出生证
- 1922 韦伯《以政治为业》：官僚制+两种伦理（责任 vs 信念）
- 1947 西蒙《行政行为》：事实/价值二分替换政治/行政二分
  （"proverbs of administration"扫荡原则行政学）
- 1968 Minnowbrook 会议：新公共行政（公平上场）
- 1988 Minnowbrook II→1990s 新公共服务回摆；2020s 数字治理范式

| 问题 | 状态 |

## 这支最美的一个事实

西蒙用"满意化"（satisficing）一词拆掉了整个"最优决策"大厦——
承认人类算力有限之后，**组织反而变得可解释了**：组织存在的理由
就是替有限理性者搭"注意力的脚手架"（有限理性→组织必要性的
论证，横跨经济学AI 政治学三个宇宙）。

## 假设与依赖

"行政"可分析性独立于政治（规范保留）、理性模型/行为模型的
选择决定解释力分布、公共性可论述（批判理论否认单数 public）。
