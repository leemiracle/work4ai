## 〇、家族定位（本质一句话）

一条街上同时有市政府、外卖平台和 NGO：政治学理论管"谁有权修这条路"，
政治制度管"修路的决议怎么通过"，**行政学管"决议怎么变成工人手里的
铁锹"**——官僚组织的目标设定、人员激励、预算配置与决策流程。
它是政治学中最"管理学"的家族，也因此与
[../../讲透管理/](../../讲透管理/) 共享全部底盘。

**反直觉发现（家族级）**：官僚制不是低效的代名词，而是**人类发明的
第一个不依赖血缘与恩宠的平等机器**（韦伯：对事不对人、按规则升迁）——
它的病（文牍、僵化）恰是它的美德（可预期、不徇私）的影子。

## 二、诞生

- **1887** 威尔逊《行政学之研究》：学科的出生证——"行政是一门外于
  政治的技术"（二分法纲领）
- **1900** 古德诺《政治与行政》二分教科书化；**1926** 怀特《行政学
  导论》第一本教科书
- **1922** 韦伯《以政治为业》+官僚制理想型：本学科的理论基石
  （德语世界的平行奠基）
- **1947** 西蒙《行政行为》：有限理性革命——"行政就是决策"，
  二分法被打通
- **1972** Cohen-March-Olsen 垃圾桶模型：组织决策的混沌数学化
  （本家族实验的母题）
- **1980s-90s** 新公共管理运动（NPM）：企业化政府改革全球扩散；
  1990s 新公共服务（Denhardt）回摆：公民不是顾客
