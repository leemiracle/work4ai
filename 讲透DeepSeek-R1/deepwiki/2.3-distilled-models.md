## Purpose and Scope

 This page documents the distilled model variants in the DeepSeek-R1 family. These models are smaller, more efficient versions that preserve the reasoning capabilities of the full-sized DeepSeek-R1 model. This document covers the distillation process, available model variants, performance benchmarks, and deployment options. For information on the parent models, see [DeepSeek-R1-Zero](https://deepwiki.com/deepseek-ai/DeepSeek-R1/2.1-deepseek-r1-zero) and [DeepSeek-R1](https://deepwiki.com/deepseek-ai/DeepSeek-R1/2.2-deepseek-r1).

 
## Distillation Process Overview

 DeepSeek-R1-Distill models represent an effort to transfer the advanced reasoning capabilities of the large 671B (37B activated) parameter DeepSeek-R1 model to more accessible dense models. The distillation process enables smaller models to gain reasoning capabilities that would be difficult to achieve through direct reinforcement learning on these smaller architectures.

 The distillation process involves:

 
 - Generating a high-quality dataset of reasoning examples using DeepSeek-R1
 - Fine-tuning smaller open-source foundation models on this dataset
 - Preserving the specialized reasoning patterns while maintaining a more efficient model size

## Performance Benchmarks

 The distilled models demonstrate strong performance across various benchmarks, particularly in reasoning-intensive tasks such as mathematics, problem-solving, and code generation. The DeepSeek-R1-Distill-Qwen-32B model notably outperforms OpenAI-o1-mini across several benchmarks, establishing a new state-of-the-art for dense models of comparable size.

### Usage Recommendations

 For optimal performance with the distilled models, the following recommendations apply:

 
 - Set temperature within range 0.5-0.7 (0.6 recommended) to prevent repetitions or incoherent outputs
 - Avoid system prompts; include all instructions in user prompts
 - For math problems, include a directive like: "Please reason step by step, and put your final answer within \boxed{}"
 - Consider enforcing the thinking pattern by having the model begin responses with "<think>\n"
 - For benchmark evaluation, conduct multiple tests and average the results
