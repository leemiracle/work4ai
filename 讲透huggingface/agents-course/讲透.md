# 讲透 agents-course：HF 官方 Agents 课程与七语言翻译考古

> 仓库：huggingface/agents-course（645 文件，units/ 422）。行号锚均经源码逐条核实（2026-11-02）。

## 一、仓定位：不是代码库，是"课程源码"

Hugging Face 官方 AI Agents 课程的内容源仓库（根 README.md 链接课程站）。全仓无 Python 包——units/ 的 .mdx 文档就是"源码"，配 CI、quiz 管线与翻译脚本构成内容生产系统：

- **units/（422 文件，7 语言）**：课程正文，语言目录 en/es/fr/ko/ru-RU/vi/zh-CN，各带 `_toctree.yml` 导航树。
- **CI（3 条 workflow）**：build_documentation.yml 委托 doc-builder 并 pin 具体 commit；upload_pr_documentation.yml 用 `workflow_run` 触发。
- **quiz/**：quiz/push_questions.py:7 定义 `ORG_NAME = "agents-course"`，把 quiz JSON 推到 HF Hub 数据集供课程站渲染。
- **scripts/**：scripts/translation.py 机翻管线——scripts/translation.py:22 起三个 lambda（路径映射、`<think>` 标签转义 scripts/translation.py:23）+ write_out_file（scripts/translation.py:36），各语言 toctree 亦由它生成。

## 二、课程知识地图

**unit0（3 文件）迎新**：onboarding.mdx:5 自述"做四件事"实际有 5 个 Step——Step 5（Ollama）后期追加未同步计数，是全仓文档滞后演进的第一个标本。

**unit1（16 文件）Agent 基础**：LLM 底座 → 工具与推理（@tool 装饰器、ReAct vs CoT、dummy-agent-library 手写 Thought/Action/Observation 循环）→ tutorial 完整 app.py。quiz1/quiz2（`<Question>` 内联）与 final-quiz（iframe 外部 Space）构成两种 quiz 形态。

**unit2（30 文件）框架三平行——主菜**：smolagents（12 mdx）/llama-index（9）/langgraph（7）互为镜像。langgraph 线从 TypedDict State 到邮件分拣图再到 ToolNode 预构件；first_graph 明说"本例无 tool call 不算真 Agent"，重心在编排。smolagents 线讲 CodeAgent 与多 agent 编排。

**unit3（7 文件）agentic-RAG**：工程浓度最高。invitees/tools/agent 三页用 `<hfoptions>` 三框架切换块呈现同一任务的 smolagents/llama-index/langgraph 三实现（agent.mdx 一页 6 组）。

**unit4（6 文件）GAIA 实测+证书**：what-is-gaia.mdx:7 论文全集 466 题、:55 公开测试集 300 题，课程实做验证集 level 1 子集 20 题，得分 ≥30% 领证。称号矛盾：en/unit4/introduction.mdx:15 实际授予 **Certificate of Completion**，en/_toctree.yml:134 却写 "Get Your Certificate Of Excellence"。

**bonus 三单元**：bonus-unit1 函数调用微调（LoRA）；bonus-unit2 评测可观测（langfuse）；bonus-unit3 AI×游戏——LLM 函数调用打 Pokemon，可运行源码在外部 HF Space。

## 四、翻译质量与代际学：本仓最大独家发现

### 4.1 断代链一：认证截止日期三代

同一句话五个译本呈三个代际：**第一代 2025-05-01**（ko/unit0/introduction.mdx:100、vi:98）、**第二代 2025-07-01**（ru-RU:100、zh-CN:107）、**第三代无截止**（en/unit0/introduction.mdx:104）。上游至少改过两次并最终取消，各译本冻结在被翻译那天的 en 快照——截止日期成了天然的"放射性碳标记"。

### 4.2 断代链二：quiz1 答案排列

按 `<Question>` 块内 correct: true 前的 text: 项数提取：**en/es = BCEBCD，fr/ko/ru-RU/vi/zh-CN = CCCBCC**——五语言冻结在早期代。quiz2 则七语言全 CDCCC 一致。背译本答案去英文站作答会翻车。

### 4.3 断代链三：API 代际滞后

ko 的 Langfuse 段仍是 base64 手拼 Auth 旧代，en 已改 `get_client()+auth_check()`；ko 的 llama-index 章仍用 JSX `<Tip>`，en 已迁 `> [!TIP]`；es/unit1/dummy-agent-library.mdx 仍 provider="hf-inference"+Llama-3.3-70B，en 已切 InferenceClient+Kimi-K2.5。

### 4.4 es 事故全谱（本地化最深的代价）

es 改写最激进（连 print 都西语化），事故密度最高，多处**复制即崩**：

- **AI 文本污染（事故级）**：es/unit2/langgraph/building_blocks.mdx:74 代码行 `return "node_3"RetryClaude can make mistakes...`——AI 界面"重试提示语"被拼进代码，复制即 SyntaxError；全 units 唯一命中，翻译工具事故实锤。
- 双等号：es/bonus-unit2/monitoring-and-evaluating-agents-notebook.mdx:51。
- 方法名被误译：es/unit2/llama-index/llama-hub.mdx:40 `llm.completar(...)`（四语对照均 llm.complete），照抄即 AttributeError。
- 缺逗号+未定义变量：es/unit2/llama-index/workflows.mdx:265 root_agent 后缺逗号、:165 引用未定义变量 result。
- 缺引号：es/unit2/langgraph/first_graph.mdx:258（en:267 引号齐全）。
- 整段重复：es/unit3/agentic-rag/agent.mdx 的 Ejemplo 3 完整出现两次（:271 与 :420）。
- 独立引入 bug：es/unit3/agentic-rag/invitees.mdx:408 `print(messages['messages']...)`（en 为 response）；tools.mdx:84 链接少一级 ../。
- 教学隐患：es/unit2/langgraph/document_analysis_agent.mdx:26 pip install 多出 `base64`（标准库，会装到 PyPI 抢注包）；es/unit2/llama-index/tools.mdx 代码 fence 9 个 vs en 14 个，后续正文被吞进代码块。
- 关键指令丢失：es/unit4/hands-on.mdx 丢了 en 版"提交勿含 FINAL ANSWER 文本"括注。

### 4.5 zh-CN / ru / en 自身的问题

- **zh-CN 代码损坏 2 处**：zh-CN/unit1/dummy-agent-library.mdx:338 JSON 缺右花括号（en:309 齐全）；zh-CN/unit2/llama-index/workflows.mdx:264 缺逗号。另有 zh-CN/unit0/discord101.mdx:18 全角【注册】致链接失效、zh-CN/unit2/llama-index/agents.mdx:83 断链（es 同病）。
- **ru**：ru-RU/unit1/messages-and-special-tokens.mdx:183 一行 24 个连续 `<` 垃圾行（七语言唯一）；ru-RU/unit0/introduction.mdx:136 维护者段整段英文未译。
- **en 也不是真理**：en/unit2/langgraph/introduction.mdx:17 导航 `./quizz1` 双 z 死链；multi_agent_systems.mdx:238 `max_tokens=8096` 疑 8192 手滑；vision_agents.mdx:199 拼接未定义变量，代码本就跑不起来。

### 4.6 本地化深度梯度

en > fr > es 三档：fr 译注释与系统提示词但保留代码关键字串；es 深改连 print 字面量；zh-CN 译行内注释但保留解析键。**好的翻译与代码语义解耦**——fr 版连示例邮件都法语化，但 is_spam 依赖的英文关键字串保留，是最规范的处理。

## 五、使用建议

1. **主线学 en**：唯一"活"的版本（无过期截止日、quiz 新代、API 现行）；fr 是质量最好的完整译本。
2. **zh-CN 可读但避开两页代码**：zh-CN/unit1/dummy-agent-library.mdx 与 zh-CN/unit2/llama-index/workflows.mdx 直接抄会 SyntaxError。
3. **es 必崩页清单**（复制代码前必查）：es/unit2/langgraph/building_blocks.mdx:74、es/unit2/llama-index/llama-hub.mdx:40、es/unit2/llama-index/workflows.mdx:165、es/bonus-unit2/monitoring-and-evaluating-agents-notebook.mdx:51、es/unit2/langgraph/first_graph.mdx:258、es/unit3/agentic-rag/agent.mdx:271（重复段）、es/unit3/agentic-rag/invitees.mdx:408、es/unit2/langgraph/document_analysis_agent.mdx:26。
4. **ko/ru/vi 缺的单元只能回 en**；三语的截止日与 quiz 答案均过期，以 en/unit0/introduction.mdx:104 为准。
5. **贡献者**：.github/ISSUE_TEMPLATE/ 三模板分流；翻译改动经 scripts/translation.py 管线，勿手工绕过转义。
