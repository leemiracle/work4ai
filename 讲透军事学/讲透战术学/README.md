# 讲透战术学 · 交战的语法(GB/T 83035)

> **战术学=交战的语法**:战略决定为何而战,战役学把序列排上时间表,
> 本家族回答最后一公里——**分队与敌接触之后怎么打**:火力、机动、
> 防护三要素在地形与时间上的排列组合。战役给序列,战术管交战;
> 两层之间是一道翻译题:战役意图译成战术行动,战术结果回写成
> 战役态势。一句钉住:**一切战争计划最终都要通过一次一次交战兑现
> ——战术学就是研究"兑现"这个动词的学科。**
>
> GB/T 13745:83035(二级学科,军事学 830 之下,三级五条全建;
> 8303599 兜底不设系列)。宇宙:[讲透军事学](../README.md)。

## 〇、家族定位与成员

- 学科身份:830 宇宙的**交战层**——[军事理论](../讲透军事理论/README.md)
  供概念,[军事史](../讲透军事史/README.md)供经验表,战略学
  ([已建](../讲透战略学/README.md))与战役学(83030,波 3 待建)供意图
  与序列,本家族供接触之后的打法
- 与战役学的翻译关系:上层输出"在何时何地以何建制投入",下层回送
  "交战结果与可达性";**翻译损耗**(战役想定≠战术可行)是两学科
  的共同研究对象
- 与数学宇宙的分工:交战的形式本体(兰彻斯特方程/排队论火力通道/
  搜索论)在[讲透数学/讲透运筹学](../../讲透数学/讲透运筹学/README.md);
  本家族站在战术学视角取用,实验只消费不重复生产
- 敏感纪律:俄乌战场现象按公开研究文献通说陈述为**战术现象**
  (注明来源),不进入政治评价与立场;导弹部队战术学支按兵种
  战术通论写,不涉任何国家现实作战计划

- 「海上/空中/导弹的交战几何」→ 对应军种支
- 「蜂群/分布式杀伤怎么改写战术」→ 家族 01 章+实验

## 四、教材锚

- 孙子《孙子兵法》(约前 512——分数·奇正:战术组织的最古抽象)
- 若米尼《战争艺术概论》(1838——战术几何学派的系统化)
- 隆美尔《步兵攻击》(1937——下级军官视角的战术经验实录)
- Gudmundsson《Stormtroop Tactics》(1989——1914-18 德军战术创新
  的组织研究,"堑壕里长出机动战术"的正典)
- House《Toward Combined Arms Warfare》(1984——20 世纪合同战术通史)
- Hughes《Fleet Tactics: Theory and Practice》(1986——海军战术正典)
- Shaw《Fighter Combat: Tactics and Maneuvering》(1985——空战战术正典)
- 军事科学院《战术学》(学科正典教材,体系表述以学界通说为准)
- Cebrowski & Garstka《Network-Centric Warfare》(1998——分布式
  杀伤概念源头之一);澳陆军研究中心《Drone Warfare in Ukraine》
  (2025——无人机战术现象公开研究综述)
