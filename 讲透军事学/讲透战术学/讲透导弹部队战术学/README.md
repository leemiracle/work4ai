> **定位句**:这支负责讲清火力投送兵种的一般战术原理——平台
> 不夺取位置、不占领地域,**直接投送效果**:战术的核心变量从
> "机动"换成"**生存**"(打击之前不被毁)与"**突防**"(火力
> 到达之前不被截)。GB/T 13745:8303550 导弹部队战术学。
> 家族:[讲透战术学](../README.md)。

> 示例;**不涉任何国家现实作战计划、部署与能力推断**。

## 诞生

弹道火力投送首见于二战末的 V-2 运用(1944,火箭武器实战
开端);战后核弹头与运载工具结合,使这一兵种的战术天然横跨
战术与战略两层(生存性同时是战术问题与威慑问题——战略层
见[核战略学](../../讲透战略学/讲透核战略学/README.md)的
正主);精确制导时代(1991 海湾为公开通说锚)火力投送从
面毁伤转为点摧毁,侦察-打击闭环成型;无人机与巡飞弹把
"投送即平台"的逻辑推到低成本端(与本家族 01 章蜂群话语
在成本交换上同构)。

## 核心问题(带年代锚)

- **生存性三选一**:机动(跑)/加固(抗)/隐蔽(藏)——无免费解,
  每个选择重写整个兵种的编制与战术(1950s 起通论)——悬而未决的
  是三者的最优混合
- **C2 的暴露悖论**:通信以便协同 vs 静默以免被定位——打击前
  的"静默窗口"与联动的矛盾(通论)——进行中
- **齐射与通道**:饱和既是己方的武器也是己方受的威胁——攻防
  同构,家族实验(突防≈max(0, n−k·C))即其抽象——进行中
- **侦察-打击节奏**:对方的发现-决策-打击循环时长决定己方
  转移周期下限(换阵地比对方瞄准快)——1990s 起定量研究,进行中
- 诱饵与识别:突防辅助手段与对方识别率的军备竞赛(通论层面)——
  进行中

## ✨ 这支最美的一个事实

生存性三选一没有免费解:机动付出戒备水平(行进间难以准备
发射),加固付出地理固定(坐标可瞄准),隐蔽付出协同(藏起来
的部队难以联动)——**兵种战术的"打"的学问,一半是"不被打"
的学问**。这个结构与家族实验的成本交换律互为镜像:火力投送
兵种的存在理由是"效果直达",它的全部战术智慧是让"直达"
在对方的通道与循环里活得下来。

## 假设与依赖

通论层抽象假设(不针对任何具体系统参数);生存性度量的
对抗性(己方生存概率取决于对方侦察能力,而那是保密变量——
公开研究只能做区间与结构比较);威慑与战术的耦合(本支
只接战术层,战略层归[核战略学](../../讲透战略学/讲透核战略学/README.md))。
数据依赖:一切示例参数为教科书级虚构,引用须声明。
