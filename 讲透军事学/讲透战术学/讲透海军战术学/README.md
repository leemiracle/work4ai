# 讲透海军战术学 · 兵力与火力的海上几何(8303530)

> **定位句**:这支负责讲清海上交战的几何与力学——舰队是**移动的
> 火力平台群**,海战战术=平台群的相对运动+火力线管理:谁能把
> 更多火力投到对方、更久保持投送位置,谁赢。陆上战术争地形,
> 海上没有地形可争(除海峡与港口),**争的是几何关系**(T 字横头、
> 内线、射界)。GB/T 13745:8303530 海军战术学。家族:
> [讲透战术学](../README.md)。

## 诞生

帆船时代战列线条令化(17 世纪中叶起,舰队作战条令成文);
纳尔逊特拉法尔加(1805)以两列纵队垂直切线突破线列教条;
铁甲与无畏时代(1906)重写火力几何(全重炮射程);潜艇战与
护航体系给出第二种几何(点-面搜索:狼群 vs 船队);1942 珊瑚海
首次视距外航母交战(通说)——兵力几何换成舰载机半径几何;
导弹时代把火力线推到视距与地平线外,分布式杀伤(2015 概念
源头)使疏散成为火力生存形态。

## 核心问题(带年代锚)

- **集中火力 vs 集中兵力的张力**:T 字横头=集中火力不集中暴露,
  几何最优为何难求(1805-)——经典几何问题,悬而未决之解在传感器
- 航母改写什么:兵力几何→半径几何,发现即被打击(1942-)——进行中
- 反潜的搜索问题:搜索率与发现率的最优配置(1917-45 奠基,
  搜索论正主在运筹学)——进行中
- 单舰高价体系的疏散-集中两难(分布式杀伤,2015-)——01 章热线三
  的海军源头,悬而未决
- 蜂群/无人艇对近海几何的改写(2020s 公开研究)——进行中

## ✨ 这支最美的一个事实

特拉法尔加(1805):纳尔逊以两列纵队垂直切入法西舰队战列线
——违反战列线条令本身。切线瞬间,局部形成以多打少,但纵队
头部承受纵射代价,纳尔逊本人阵亡于旗舰甲板。**条令的"违背即
创新"**:几何上可算的方案(平行线对轰)条令早已规定,赢的
却常常是敢在正确时刻打破条令、自己承担代价窗口的一方
([军事史家族](../../讲透军事史/00-体系结构.md)美之时刻②的
战术几何正主)。

## 假设与依赖

水文与通视假设(海况/夜战改变几何结算);平台可数假设
(海军战术以"艘"为原子单位,损耗不可累积修复——单舰损失
即节点消失,损失厌恶是结构性的);军港与补给地理约束
(一切几何的起点在基地坐标)。数据依赖:舰队作战条令、
航海日志、射程表(02 章 T1 级材料的海军版)。
