# 讲透陆军战术学 · 兵种战术群:分队的能力边界与配系(8303520)

> **定位句**:这支负责讲清陆军各兵种分队的"能与不能"及配系
> ——步兵为基准兵种,装甲、炮兵、工程、通信、防化按"效果供给"
> 进入合同(GB/T 注:包括炮兵战术学、装甲兵战术学、工程兵战术学、
> 通信兵战术学、防化兵战术学等,三级名照录)。核心视角:
> **每个兵种是一段战术语法**——步兵是句子的主语(占领与控制
> 只能由它完成),其余兵种是改写句子速度、力度与可行性的成分。
> 家族:[讲透战术学](../README.md)。

## 诞生

线列与散兵之争(18-19 世纪)确立"火力密度决定队形疏散度";
1877 普列夫纳让纵队冲锋破产;1916-18 索姆河的消耗改造产出
渗透战术与步兵小组化(战术单元缩到班);二战装甲兵战术条令化
(隆美尔《步兵攻击》与古德里安装甲条令为两极文献);战后
步兵乘车机动使"下车线"(乘车间距×下车时机的几何)成为新经典
问题;无人机时代步兵重新成为杀伤链的锚(01 章热线四)。

## 核心问题(带年代锚)

- **下车线的几何**:乘车快而暴露、下车慢而稳固,换乘时机的
  最优点——1970s 起定量研究,进行中
- **炮兵集中指挥 vs 分散配属**:火力集中权放在哪一级——
  二战以来反复摇摆(分布式时代再摆一次),悬而未决
- 工程兵是"时间兵种":开路与设障买卖的是时间差,其节奏价值
  怎么入账——进行中
- 装甲与步兵的速度差缝合(伴随、搭载、混合编组)——进行中
- 无人机对步兵分队的火力/视野配比改写(2022-,公开研究)——
  进行中,澳陆军研究中心"不替代士兵"的通说修正为锚

## ✨ 这支最美的一个事实

1918 年春季的德军渗透战术:榴弹兵小组沿战壠交界渗入,绕过
支撑点留给后续梯队,炮兵以徐进弹幕按步速滚动——**最僵化的
堑壕战场产出了最流动的战术**:把"突破正面"改成"穿过间隙"。
它同时给出下半课:1918 年攻势战术成功而战役目标落空——
兵种战术的天花板在上一层(家族 00 章反直觉之一的正主)。

## 假设与依赖

步兵基准假设(一切兵种围绕步兵闭环——无人机时代在松动但
未推翻);地形尺度假设(陆军战术的结论对地形类型高度敏感,
平原答案不可移植到城市);训练水平假设(条令的"标准分队"
是均值虚构,实战输出随训练陡变)。数据依赖:兵种操典、
射击诸元表、工事作业定额(02/03 章操典语言与 schema 的正主)。

## 教材锚

- 隆美尔《步兵攻击》(1937——下级军官视角战术实录)
- Gudmundsson《Stormtroop Tactics》(1989——渗透战术的组织研究)
- 军事科学院《战术学》教材与各兵种条令文献(学科正典,通说)
