# 讲透合同战术学 · 协同的本体:诸兵种效果的时间窗叠加(8303510)

> **定位句**:这支负责讲清合同战术的通论——**合同≠并列**:把几个
> 兵种放在一张地图上不叫合同,让他们的效果在**同一时间窗内叠加**
> (坦克开路的那一刻,弹幕正滚过、步兵正贴上、工兵正架桥)才叫
> 合同。协同是本支的唯一主角:它本质是**时钟**——预定协同靠时间表,
> 临时协同靠传感器共享。GB/T 13745:8303510 合同战术学
> (三级,战术学理论主干)。家族:[讲透战术学](../README.md)。

## 诞生

车步骑协同古已有之(坎尼前 216 骑兵合围即协同母题);现代建制自
康布雷(1917-11-20):不预炮保奇袭+坦克轰开铁丝网+步兵随进+炮兵
声测反炮——步坦炮工第一次在同一张时间表上对表,首日推进超过
索姆河数月总和(通说)。两次大战之间各国条令化(合成战斗理论);
1982 空地一体战把协同时钟扩展到空地;1998 网络中心战把协同从
"计划对表"改为"传感器共享对表"(协同的两次语法升级)。

## 核心问题(带年代锚)

- **协同是时钟还是意图**:预定协同(时间表)与临时协同(临机
  调整)的最优配比——1917 时间表起,悬而未决
- **最小充分集**:哪些兵种是合同的下限(无坦克的合同?无炮的
  合同?)——1918 渗透战术给出过低配答案,悬而未决
- 合同的度量:效果叠加怎么核算(单项满分之和≠合同效果)——
  进行中
- 预定计划与任务式指挥的边界(计划管动作、意图管时机)——进行中
- 分布式时代的合同:疏散部署下协同时钟还能对多细(2020-)——进行中

## ✨ 这支最美的一个事实

康布雷的对表:四个兵种各自放弃了最习惯的东西——炮兵放弃火力
准备(换奇袭)、步兵放弃疏开跟进(换贴弹幕)、坦克放弃独立突击
(换载步速度)、工兵放弃预开路(换随排障)——**各自让步后的同时
到达**。首日的推进量级证明:合同的力量不在任何单一兵种的加强,
而在让步构成的叠加(家族 00 章美之时刻②的本支正主)。

## 假设与依赖

条令时效:合同战术文本是上一场战争的滞后吸收(军事史滞后列);
演习验证≠实战(演习无摩擦,协同在实战里的衰减未建模);兵种
编制比例即战术假设(编制定了,协同时钟的上限就定了)。数据
依赖:时间表/信号规定/空域协调计划是本支的一手材料(03 章
协同矩阵的字段源)。
