# 02 · 语言特征——操典·想定·军语:交战的三层语法

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)**。
> **本质一句话**:战术学说三种语言——**操典语言**(口令与动作:
  面向肌肉的零歧义规范)、**想定语言**(态势/任务/决心/协同/
  保障五段式:面向指挥员的决策文书)、**军语概念语言**(火力/
  机动/防护/协同:面向分析与传承);这门学科的手艺,是让
  "三〇三高地,占领"的口令、"本部决心于 X 日拂晓发起攻击"的
  决心句、与"此役火力密度对机动速度之比过高"的分析句,
  在同一份文书里各司其职、互不越权。

---

## 0. 开篇:一页操典的呼吸

📖 **故事框:线列时代的操典(18 世纪)**。普鲁士步兵操典把
燧发枪的装填-发射分解成若干个口令动作,每个动作一次呼吸,
练到肌肉记忆,全队列射速从每分钟约一发提到三到四发
(军事史通说)。这页纸有个惊人的性质:**它不解释任何东西**
——为什么先咬开弹壳、为什么枪管抬这个角度,一概不说;
它只规定做什么、什么顺序、什么节奏。战术的第一语言不是
论述,是操典:一种**面向执行而非面向理解**的语言——
今天读它,读到的正是"把人类动作编译成可执行规范"的最早
工程。操典之后的一切战术文书,都在"给肌肉的"与"给头脑的"
两种语言之间分工。

## 1. 表达力:三种语言各能说什么(三栏之一)

**操典语言能说的**:

| 能力 | 例 |
|------|-----|
| 动作分解 | "装填-瞄准-击发"逐口令化,零歧义 |
| 节奏规定 | 徐进弹幕"每分钟 X 米"——协同写成步速(00 章康布雷的对表) |
| 射表/诸元 | 装药号×表尺×气温修正——参数化语言 |
| 反应规则 | 接敌运动的条件动作("遇敌侧射即……") |

**想定语言(五段式)能说的**:

| 能力 | 例 |
|------|-----|
| 态势句 | 敌我兵力、地形、时间——事实链 |
| 决心句 | "本部决心……"——意图链(见 §2:承诺而非预言) |
| 协同句 | 信号规定、时间表、空域协调——多兵种对表 |
| 保障句 | 弹药基数、救护后送、维修——交战的资产负债表 |

**军语概念语言能说的**:

| 能力 | 例 |
|------|-----|
| 三要素归位 | "此段冲击押机动、弃火力掩护"——动作的要素审计 |
| 类型学定位 | "属包围,非突破"——交战几何分类 |
| 交换比断言 | "消耗比 1:5,不可持续"——量化判断 |
| 战术原则引用 | 集中、突然、节约兵力——原则层的对账 |

**三种语言都不能说的**:

- **不能进士兵的身体**:压制的恐惧、连续作战的耗竭,在操典
  与想定里都近乎不可传递(与军事史"不能进士兵的皮肤"同构,
  战术层的版本更尖锐——它直接影响三要素的实际输出)
- **不能表达"时机感"**:老连长"再等两分钟"的判断无法写成
  条件规则——操典管得住动作,管不住时机(00 章问题表)
- **不能给自己的前提定价**:想定默认敌情"如所判断"——
  判断错了,语法完美的文书照样全军覆没

## 2. 逻辑性质:三种句子的真假结构(三栏之二)

| 性质 | 操典句 | 想定句(决心) | 军语分析句 |
|------|--------|--------------|-----------|
| "真值" | 无真假,只有合规与否(规范句) | **承诺而非预言**——真值属于未来 | 分级(参数=兵棋观) |
| 一致性 | 口令序列不得冲突(装填中不得击发) | 上下级决心不得矛盾(战役⇄战术翻译的语法面) | 断言须与战果核算对得上 |
| 完备性 | **不追求完备**——战场情况超出操典即靠临机 | 五段式留白(首长临机处置) | 永不完备(交战不可穷举) |
| 可检验 | 演习可验,实战难复核 | 战后检讨可对账(决心 vs 结果) | 兵棋可算,冒充实测不可(04 章边界) |
| 反事实 | 无 | "倘若……则"是检讨文体的一半 | 显式标记后可用 |

**决心句的逻辑地位**(本学科最独特的一类句子):"本部决心
于拂晓发起攻击"既不是描述(尚未发生)也不是愿望(可被否决),
而是**以言行事**——说出的那一刻,下级的整个文书体系随之
改写。战术文书的真正枢纽是决心句,而**决心段永远是想定里
证据最薄、权力最重的一段**——这与军事史 02 章"决心段最薄"
的观察同源,战术层的版本是:读想定先读决心段挂的敌情判断
是几级(实察/推断/假设),三秒定这份文书的成色。

**分析句的参数纪律**:交换比/火力密度/突防概率都是模型输出
——引用必附参数来源与生成机制(承[军事史家族](../讲透军事史/02-语言特征.md)
数字三栏纪律的战术版:构造数字不注参数即按反事实处理)。

## 3. 规范化程度:军语、坐标与时间(三栏之三)

- **军语标准化**:战术军语有专门规范辞书(中文军语/北约
  AAP 系列术语表);跨阵营写作必须声明所用军语体系
- **坐标系**:军事网格参照(MGRS)是战术文书的空间语法
  ——"那座山"不是坐标,"网格 XYZ"才是
- **时间**:统一计时基准(Z 时/作战时间),协同时间表精确到
  分;**时间表是合同战术的第一公民**(00 章康布雷)
- **度量**:弹药用基数、距离用公制、舰艇用节/链——
  军种差异在计量上显形,跨军种文书须换算声明

**军语对译表(中文优先,中英对照,战术层高频)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 战术/战术学 | tactics | 兼指"战术"与"谋略",语境敏感 |
| 合同战术 | combined-arms tactics | 合同≠联合(joint):军种内兵种协同 vs 跨军种;汉译常混 |
| 队形/战斗队形 | (battle) formation | ≠编队仅指海军;陆空各有几何 |
| 疏散/疏开 | dispersal / dispersion | 两词英文常混用;疏散指部署状态,疏开指动作 |
| 火力通道 | fire (engagement) channel | 防空特有:同时接战目标数上限——排队论"服务台"的军语名 |
| 蜂群 | swarm | ≠集群使用(massed employment,预定计划/人工集中指挥)——01 章热线一辨析 |
| 分布式杀伤 | distributed lethality | 海军概念源头(2015),勿译"分散杀伤"丢掉"效果集中"义 |
| 杀伤链 | kill chain | 发现-决策-打击-评估循环;时长是设计变量(01 章热线四) |
| 交战规则 | rules of engagement (ROE) | 是许可/禁止规范集,不是"规则"泛称 |
| 徐进弹幕 | creeping barrage | 常误译"移动弹幕",丢掉"步兵贴着走"的协同义 |
| 渗透 | infiltration | 战术层=绕过支撑点;社会学 infiltration 语义场不同 |
| 突破 | breach / breakthrough | breach 是工程性开口,breakthrough 是战役性达成——两层常被一个词压扁 |
| 压制 | suppression | 暂时失能,≠歼灭(destruction)——火力效果分级的第一刀 |
| 同时弹着 | time-on-target (TOT) | 多炮不同位置同时落弹——"时间窗集中"的标准件 |
| 预备队 | reserve | ≠后备(后备=建制概念);战术层的"自由度" |
| 奇袭/突然性 | surprise | 战果审计里最难过秤的变量(00 章悬而未决) |
| 饱和攻击 | saturation attack | 攻方压通道;对防御方称通道饱和(saturation of channels) |

**对译纪律**:军语翻译的最大坑是**层次压扁**——中文四层
(战斗/战役/战争/战略)与英文三层(battle/operation/war)
不一一对应,加之合同/联合、突破/突破口、压制/歼灭这些
"一词两界"的词,引外军材料回译时必须先判层再落笔
(承[军事史 02 章对译表](../讲透军事史/02-语言特征.md)同款纪律,
战术层新增通道/蜂群/分布式三组近五年新词)。

## 📌 收束

战术学的语言=**操典管肌肉(规范句)、想定管头脑(五段式+
决心句)、军语管传承(类型学与原则)**;决心句以言行事,
分析句自带参数,对译先判层。下一章把这套语言压成数据:
队形、交战规则、协同矩阵怎么变成可构造对象:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **三层眼**:读任何战术文书先分层——这句是给肌肉的、
  给头脑的还是给档案的?层内越权(操典解释理论、决心
  兼职分析)就是文体病
- **决心句眼**:决心是承诺不是预言——看承诺先看它押的
  敌情判断挂几级证据
- **参数眼**:一切交换比/突防概率先问参数谁定的、模型
  边界画在哪(概念辨析即边界声明,01 章热线一)
