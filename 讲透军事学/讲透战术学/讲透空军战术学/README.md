# 讲透空军战术学 · 空中的交换几何:能量·编队·信息(8303540)

> **定位句**:这支负责讲清空中交战的几何——三维机动+能量管理:
> 空战是**用能量买角度、用角度换射击窗口**的连续交易;编队从
> 自卫几何(交叉火力)演化到信息几何(传感与数据链),无人机
> 时代再变无人几何。陆上战术的"位置"在空中变成"位置+能量状态"
> 四元组。GB/T 13745:8303540 空军战术学。家族:
> [讲透战术学](../README.md)。

## 诞生

一战缠斗期,波尔克空战格言(Boelcke's Dicta,1916)为首部
战斗机战术条令(先占高度、太阳背后来袭、打了就走);二战轰炸
箱型编队(combat box)以交叉自卫火力对抗拦截;1944 远程护航
改写攻防平衡;喷气时代,博伊德能量机动理论(1960s)用单位
剩余功率+转弯速率两参数把缠斗变成可计算曲面(F-16 的出生
证明之一,通说);超视距+电子战时代,"先敌发现先敌射击"把
战术重心从几何移到信息。

## 核心问题(带年代锚)

- **格斗死了吗**:视距内格斗与超视距的配比——每次宣布"格斗
  已死"(导弹时代/超视距时代)都被局部战争修正,悬而未决
- 编队自卫 vs 分散突防:集中自卫火力与疏散降低可探测性的
  权衡(1943 箱型编队起,隐形时代再摆)——进行中
- 能量-角度交易的统一结算:能量机动理论的边界(角度优势的
  战术价值依赖武器包线)——进行中
- 无人平台的空战几何(2020s 概念研究)——01 章热线四的空中版
- 电子战与传感器博弈:发现概率成为一等战术变量(1982 贝卡
  谷地公开战例为电子-火力协同经典锚)——进行中

## ✨ 这支最美的一个事实

能量机动理论:博伊德把"谁占战术优势"压缩成两个参数——单位
剩余功率 Ps(还能买多少机动)与瞬时/持续转弯速率(能换多少
角度)——一切缠斗动作变成这两参数张成的曲面上的攀爬。
**一个两参数曲面硬编码了此后五十年的战斗机设计**(轻型高推
比路线对重型高速路线的胜利,通说)。战术直觉被公式化的
最干净案例:先有几何语言,再有飞机。

## 假设与依赖

平台中心假设(战术围绕有人高性能平台组织——无人机时代在
松动);空域可分假设(制空权的任务分类可分性);损耗厌恶
结构(飞行员与平台的高价值使空军战术天然偏重风险管理);
气象与昼夜假设。数据依赖:飞行条令、空战演习数据(红旗
演习体系)、能量机动图表(03 章"能力卡"的空军版)。
