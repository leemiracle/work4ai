# 战术学思维技能卡(GB/T 83035 · 讲透战术学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「步坦炮怎么协同」「为什么是这几种队形」——合同战术问题
- 「集中兵力过时了吗」「透明战场怎么活」——集中的悖论
- 「蜂群能不能突防点防御」「加通道还是加拦截概率」——
  通道容量与饱和问题
- 「这个打法划算吗」——交换比/成本不对称问题
- 「队形/交战规则/协同计划怎么变数据」——schema 级需求
- 「无人机改写了什么」——先过概念辨析(蜂群 vs 集群使用),
  再谈革命
- 学战役/战略时缺"最后一公里"——计划怎么经交战兑现

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **三角眼** | 一切战术动作归位三要素:火力/机动/防护——都不沾的多半是仪式 |
| **翻译眼** | 战役⇄战术是一道翻译题:上层意图下层打得动吗,下层代价上层算过吗 |
| **时钟眼** | 多兵种协同的本质是对表(康布雷);看"合成/联合/分布式"先找协同时钟 |
| **通道眼** | 防御体系先问火力通道容量 k×拦截轮次——过拐点后数量线性买突防 |
| **速率眼** | 饱和的第一变量是到达速率 n/T,不是数量 n(时间压缩律) |
| **单价眼** | 攻防对策合法性由单价不对称决定:先算拦截弹/平台量级比 |
| **拓扑眼** | 多平台协同先画拓扑(星/链/网/树)——拓扑决定反制,数量只决定账单 |
| **逆境眼** | 战术创新集中在己方最不利的环境;顺境新战术多半是改名 |

## 3. 工具箱(何时用什么)

- **三要素三角**:火力-机动-防护+压制/遮蔽/诱骗三条边——
  任何战例的要素审计框架(00 章)
- **攻防六式**:突破/迂回/包围/追击+阵地防御/机动防御
  ——动作层的查重器(分解不掉的残余才是真新东西)
- **四跳编年**:阵法→散兵线(1916)→合同(1917)→分布式(2020)
  ——战术单元、核心问题、指挥介质四列对照
- **饱和模型**:突防≈max(0, n−p·k·C),拐点 n*=k·C
  (家族实验 `experiments/swarm_vs_defense.py` 为最小实现:
  饱和律/时间压缩律/成本交换律三组断言)
- **概念辨析框架**:蜂群(自治交互涌现)vs 集群使用
  (massed employment,预定计划/人工集中指挥)——
  反制面完全不同(MR 2025,检索校准 2026-09-07)
- **三值规则表**:目标×武器×条件→允许/禁止/需批准——
  ROE 的合规机器判定(03 章)
- **冲突扫描**:同 zone 同 window 交叠即红旗——
  协同计划的第一道机器检查
- **杀伤链计时**:发现-识别-决策-打击-评估分段计时,
  瓶颈段定位(01 章热线四)

## 4. 常见误区与禁忌

- ❌ **数量崇拜**:「多就是饱和」——到达速率才是第一变量;
  拉长窗口放进来,数量再多也排队等打
- ❌ **概念混用**:把一切多机协同叫"蜂群"——对策开错药方
  (反集群靠通道,反蜂群还要破坏交互)
- ❌ **分散误读**:把"分布式杀伤"读成"集中的否定"——
  死的是集中位置,活的是效果集中(空间疏散+时间密集)
- ❌ **参数裸奔**:交换比/突防概率不注参数来源——
  兵棋输出冒充实测是数字时代新病(承军事史 T6 纪律)
- ❌ **不注摩擦**:无延迟/误判/故障的推演输出的是操典
  不是战斗
- ❌ **自动化越界**:杀伤链自动化先过 ROE 空格检查——
  时机与决心永远是人脑保留地
- ❌ **敏感红线**:现役战例按公开研究文献通说陈述为战术现象
  (注明来源),不评价任何国家军队政策与人物;
  导弹部队话题只谈兵种通论,不涉任何现实作战计划
