# 讲透军事地学 · 战场的底图与图纸(GB/T 83060)

> **军事地学=战争与地表的接口科学**:战略在图上画底图,战术在
> 地上看图纸——本家族回答"战争发生在地表"这一平凡事实的全部
> 学科后果:地形(通视/坡度/通行性)、地理(要地/格局/纵深)、
> 水文(江河/潮汐/涉渡)如何进入决策。一句钉住:**地理没有敌我,
> 只有参数——谁先把参数译成行动,地形就为谁服务。**
>

> 8306040 军事测绘学→420 测绘科学技术、8306050 军事气象学→170

## 〇、家族定位与成员

- 学科身份:830 宇宙的**战场层**——[战略学](../讲透战略学/README.md)
  拿它当底图(格局与纵深),[战役学](../讲透战役学/README.md)
  拿它当选轴线(走廊与时节),[战术学](../讲透战术学/README.md)
  拿它当图纸(射界/掩体/走廊);本家族不研究"怎么打",研究
  **"在哪打、能不能去、看得见谁、何时能过"**
- 参数化接口:地形是战术三要素的参数供给方——通视给火力画
  射界,坡度给机动定走廊,遮蔽给防护供掩体
- 与挂靠学科的边界:军事测绘学(DEM/影像的**生产**)本体在
  420 测绘科学技术(待建宇宙),军事气象学(大气)本体在
  170 地球科学(待建宇宙)——本家族**消费其产品做分析**,
  不重复生产
- 敏感纪律:一切地理内容按学科通说与历史战例写作,不涉任何
  国家现实作战方向、阵地与边海防部署细节;现役话题只引公开文献
