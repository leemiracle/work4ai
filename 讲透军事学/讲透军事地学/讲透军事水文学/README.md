# 讲透军事水文学 · 江河·潮汐·涉渡窗口:水体的军事参数化(8306060)

> **定位句**:这支负责讲清水体的军事参数化——江河(水位/
> 流速/岸坡/底质)、湖泊与地下水、潮汐与海况的行动含义;
> **"何时能渡"是全支的第一问题**:水体把地学的空间问题
> (能不能去)叠加成时空问题(什么时候能去)。GB/T 13745:
> 8306060 军事水文学。家族:[讲透军事地学](../README.md)。

## 诞生

古代涉渡与水战的实践智慧积累千年(赤壁之战 208,风向与水文
条件的合流,通说叙述);近代工兵渡河作业条令化(徒涉场/
桥渡/舟桥规程);二战推上会战日程:敦刻尔克的潮汐与滩坡成全
撤退(家族 00 章美之时刻②)、第聂伯河强渡(1943,通说)示范
江河攻坚、诺曼底联立潮汐窗+滩坡+水下障碍(登陆日历的水文项);
当代数值水文模型与卫星测高使窗口计算常态化(家族 04 章 C4)。

## 核心问题(带年代锚)

- **徒涉场判定三要素**:水深×流速×底质(缺一即误判)
  ——条令化通说,进行中:三要素的现场量测方法
- **桥渡与舟桥的时窗**:架设时间×敌方火力的赛跑——1943 起
  定量研究,进行中
- **潮汐窗计算**:天文谐波可算到分钟级——1944 起建制化,
  成熟;与气象窗的联立(登陆日历)进行中
- **径流预报的边界**:降雨-径流耦合误差以天计——悬而未决:
  战时数据稀缺下的区间预报
- **水网地带的机动地理**:河湖密布区把走廊切碎成桥的网络
  ——咽喉密度问题,进行中

## ✨ 这支最美的一个事实

敦刻尔克:同一片沙滩——岸坡缓到驱逐舰无法近岸(对撤离是
陷阱),又缓到小艇能往返摆渡(对撤离是救援);叠上春季大潮,
九天撤离 33.8 万人(通说)。**水文参数没有"好坏",只有
"配谁用"**:敌我拿着同一张潮汐表,用法不同,参数的敌我
就换了边——家族定位句"地理没有敌我,只有参数"的历史出处。

## 假设与依赖

预报误差分级(潮汐分钟级/径流天级——精度与水体类型绑定);
战时数据稀缺(敌方水域的水文资料是情报缺口);季节律动与
战争日历的错位(错过窗口=等一个月,时窗代价以季节计);数据
依赖:水位站网/卫星测高/气象耦合(上游挂靠 170 地球科学之
气象面,待建宇宙)。
