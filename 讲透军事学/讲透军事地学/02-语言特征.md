# 02 · 语言特征——读图·分析·决策:地形的三层语法

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)**。
> **本质一句话**:军事地学说三种语言——**读图语言**(等高线/
> 高程/坡度:面向判读的图形语法)、**分析语言**(OCOKA 判断句/
> 走廊命名/要地编号:面向参谋的评估语法)、**决策语言**
> (AOI/时窗/推荐走廊+备选:面向指挥员的产品语法);这门
> 学科的手艺,是让"等高线在此变密"的读图句、"该高地通视
> 全纵深"的分析句、与"建议走二号走廊,备选涉渡"的决策句,
> 在同一份地文里各司其职、互不越权——**图上的每一句话,
> 都要知道自己说给了谁**。

---

## 0. 开篇:一页等高线图的呼吸

📖 **故事框:等高线的胜利(18-19 世纪)**。18 世纪末,等高线
的构想问世;19 世纪,各国军用测绘制图陆续用它取代晕滃法
(通说)——用短线的疏密晕染出山的明暗,好看,但读不出数。
等高线难看,却有三个革命性质:**可量测**(相邻两线的高差
是契约)、**可重建**(两线之间可以插值)、**可复制**(印刷
不失真)。这是地表的第一次"数据格式标准化"——比计算机
早一个世纪,地形就已经是数组了。今天 DEM 的一切语法,都是
等高线语法的数字化身:读图语言从诞生起就是**面向机器可判读**
的,只是那台"机器"最初是参谋的眼睛。

## 1. 表达力:三种语言各能说什么(三栏之一)

**读图语言能说的**:

| 能力 | 例 |
|------|-----|
| 形态量测 | 等高线疏密→坡度陡缓;闭合线圈→山头/洼地;两组鞍部→隘口 |
| 相对量 | 比高(相对高差)、分水岭与汇水界、谷底与棱线 |
| 微地形 | 鞍部/反斜面/切沟/断崖符号——机动与观察的开关件 |
| 状态标注 | 沼泽/沙滩/植被符号——通行性的静态近似 |

**分析语言能说的**:

| 能力 | 例 |
|------|-----|
| OCOKA 判断 | "该段通视受 120 高地遮蔽,射界断于谷线" |
| 走廊命名 | "一号走廊:沿 XX 谷地,装甲限 15°,暴露段 2 km" |
| 要地编号 | "K-3:该鞍部为唯一机动车渡口,失守则退至 40 km 外" |
| 窗口断言 | "涉渡窗口:水位降至 0.7 m 以下,约 72 小时后,持续 3 日" |

**决策语言(地学产品)能说的**:

| 能力 | 例 |
|------|-----|
| 推荐句 | "推荐走廊 B(暴露 1.6 km/距离 6.8 km),备选走廊 C" |
| 时窗句 | "潮汐窗 D-1 日 06:10-08:40,下一窗 D+14 日" |
| 触发句 | "AOI-7 出现车辙活动,置信度中,建议复核" |
| 边界句 | "本产品图龄 96 小时,通行性未现场核实" |

**三种语言都不能说的**:

- **不能说"今天能不能走"**:图与产品的通行性是静态近似——
  一场雨、一次翻浆,读图语法里没有变量(00 章反直觉之一)
- **不能自动说"哪里关键"**:关键地形依赖任务语境——图上有
  隘口,图上没有"这次任务的非它不可"
- **不能替你选**:决策语言只能说"推荐+备选+代价",选择本身
  是指挥员的(02 章 04 章一以贯之的"参数给齐,决心是人"纪律)

## 2. 逻辑性质:三类句子的真假结构(三栏之二)

| 性质 | 读图句 | 分析句 | 决策句(产品) |
|------|--------|--------|--------------|
| "真值" | 相对于图(在图上可核) | **条件句**:真值=平台参数×地表状态的函数 | 推荐而非承诺;成败事后对账 |
| 一致性 | 同图不得自相矛盾(等高线不相交) | 多源判断需注版本(1:5 万 vs 影像,谁覆盖谁) | 推荐必须附代价与备选,缺备选=越权 |
| 完备性 | 永不完备(两线之间是插值) | OCOKA 五问覆盖判断,不覆盖任务权衡 | 永不完备(图龄字段就是自认) |
| 可检验 | 量测可复核 | 实测可验(坡度仪/现场) | 事后复盘可对账(走了推荐路,代价兑现否) |
| 反事实 | 无 | 显式标记后可用("若水位再降 0.3 m 则…") | 备选项即制度化的反事实 |

**分析句的参数纪律**:"该坡装甲可通行"不是关于坡的陈述,
是关于(坡,土壤,车重,时刻)四元组的陈述——引用分析结论
必附平台参数与状态时点(承
[军事史 02 章数字三栏纪律](../讲透军事史/02-语言特征.md)
的地学版:构造判断不注参数即按反事实处理)。

**比例尺的认知陷阱**:1:5 万图上的一条"路"可能是 3 m 宽的
乡道;分辨率≠语义——精度幻觉(00 章反直觉一)在语言层的
形态:**图上的符号会撒谎,如果忘了它是比例尺压扁过的**。

## 3. 规范化程度:基准、坐标与军语(三栏之三)

- **坐标基准**:军事网格参照(MGRS)是地学文书的空间语法
  ——"那座山"不是坐标,"网格 XYZ"才是(与
  [战术学 02 章](../讲透战术学/02-语言特征.md)共用此纪律)
- **高程基准**:海拔从哪个面起算(平均海面/似大地水准面)
  ——跨源数据不声明基准,叠加即错位,这是 DEM 时代的第一坑
- **时间基准**:窗口句的时间基准(当地时/统一时)与图龄
  (as_of)必注——时效是地学数据的第一毒性指标(00 章)
- **度量**:陆用米、海用链与节、坡度用度或百分比——跨军种
  文书须换算声明(00 章问题清单末行)

**军语对译表(中文优先,中英对照,地学层高频)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 军事地学 | military geosciences | 泛称;含地形/地理/水文诸支(GB/T 83060 的整体) |
| 军事地形学 | military topography | ≠military geography:战术图纸 vs 战略底图,尺度两级 |
| 地形分析 | terrain analysis | 美军 OCOKA 框架的正式名;≠地形学(学科 vs 作业) |
| 通视/互通视 | line of sight / intervisibility | LOS 兼"视线/瞄准线",语境定义;互通视指两点互见 |
| 掩蔽 | cover | 防火力(弹片/炮弹)——**与隐蔽成对死分**,汉译常混 |
| 隐蔽 | concealment | 防观察(眼睛/传感器);不防弹——cover 不防侦察 |
| 关键地形 | key terrain | "关键"系于任务,非地形固有属性(图上无名) |
| 进接近路 | avenue of approach | ≠行军路线(march route,后方/输送概念) |
| 机动走廊 | (mobility) corridor | 走廊=经过代价分析的可通行带;家族实验的正主 |
| 障碍 | obstacle | 天然/人工;设障作业=obstacle emplacement |
| 反斜面 | reverse slope | 防炮兵的阵地构型;军事棱线=military crest≠topographic crest(山顶) |
| 通行性 | trafficability / going | going 是英军正字口语;≠mobility(机动性=平台属性) |
| 数字高程模型 | DEM (digital elevation model) | 高程≠地形:DEM/DTM(裸地)/DSM(含植被建筑)三分 |
| 地理空间情报 | GEOINT | 影像情报(IMINT)是其子集;与测绘学科名分立(01 章热线一) |
| 感兴趣区 | AOI (area of interest) | 监测概念≠控制概念(AO 战斗地域);触发句的宾语 |
| 徒涉场 | ford (site) | 水文支正主;桥渡/门桥/舟桥各有专词 |
| 潮汐窗 | tidal window | 时段概念≠"满潮时刻"单点;登陆日历的基本件 |
| 兵要地志 | (无标准对译) | 汉字文化圈军语;近译 military topographic report,对译需注 |

**对译纪律**:地学翻译的两大坑——**尺度压扁**(topography/
geography/corridor/route 四级尺度在中文里常被"地形/地理/路线"
三个词压扁)与**掩蔽-隐蔽混用**(cover/concealment 这一对,
英文死分而中文活混,译错直接开错药方:一个要工事,一个要
遮蔽幕)。引外军地学材料回译,先判尺度、再分成对词
(承[军事史 02 章对译表](../讲透军事史/02-语言特征.md)同款
纪律,地学层新增 DEM/GEOINT/AOI 三组近五年高频词)。

## 📌 收束

军事地学的语言=**读图管判读(图形语法)、分析管评估
(OCOKA 条件句)、决策管行动(推荐+备选+图龄)**;分析句
自带参数与状态时点,决策句必须自认不完备,对译先判尺度、
死分成对词。下一章把这套语言压成数据:DEM、暴露场、
走廊图、AOI 怎么变成可构造对象:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **三层眼**:读任何地学文书先分层——这句是给判读的、
  给参谋的还是给指挥员的?层内越权(图例兼职推荐、推荐
  兼职担保)就是文体病
- **条件眼**:一切"可通行/可通视"先问四元组(坡,土壤,
  平台,时刻)——缺哪元,哪元就是你日后埋雷的地方
- **图龄眼**:一切地理数据先看 as_of——决策语言里最诚实
  的字段,常常也是被读得最草率的字段
