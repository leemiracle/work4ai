## 诞生

马汉《海权对历史的影响》(1890)把海峡/基地/航线变成海军战略
的参数集;麦金德《历史的地理枢纽》(1904)用一张地图把两千年
帝国史重写成枢纽的争夺(大陆史观对海洋史观的翻转);斯皮克曼
(1942/1944,边缘地带论)修正枢纽;二战全球作战的地理参谋
作业建制化;冷战基地体系与"岛链"等格局概念成形(时代概念,
通说);当代全球补给与投送地理延续此脉(家族 00 章 1.2 节)。

## 核心问题(带年代锚)

- **咽喉经济学**:海峡/运河的通行权为何反复成为热点
  (霍尔木兹/直布罗陀/马六甲/苏伊士/巴拿马——通说列举,只谈
  地理不谈现状政治)——进行中:咽喉价值随航线与能源结构漂移
- **心脏地带 vs 边缘地带之辩**:1904-1944 两论对峙,悬而未决
  ——技术(铁路/航空/航天)每代重写一次答案(家族 00 章决定论
  之辩的正面战场)
- **基地-补给的全球地理**:前沿存在与补给线的距离账——进行中
- **格局概念的时代性**:岛链等冷战概念的解释力边界——进行中
  (概念史方法)
- **尺度耦合**:全球格局与战区走廊怎么接(翻译链的两端)
  ——悬而未决

## ✨ 这支最美的一个事实

麦金德 1904 年的皇家地理学会演讲:用一张地图把两千年帝国史
重写成"枢纽的争夺"——被后世批评了一百年的决定论,但**所有
批评者都得先站到他那张地图上开口**。一个地理框架的最高成就
不是被证明正确,而是成为此后一切辩论的坐标系——理论史上
罕见的"错了仍居中"。

## 假设与依赖

决定论之辩未决(地理约束 vs 技术与组织的自由度);格局概念的
时代性(为某代技术与对抗定制,换代即需重估);尺度断裂(全球
格局不能线性下推到战区走廊);数据依赖:公开地理数据与航运/
贸易统计(咽喉经济学的方法基础)。
