# 04 · 军事地学转代码——通视·走廊·坡度·窗口的四条最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:军事地学的问题一旦变成"关于高程数组/代价
> 层/暴露矩阵/水位序列的计算",就能进代码——通视变视线采样、
> 机动走廊变 Dijkstra、坡度变差分、涉渡窗口变阈值判定;
> **唯一不可外包给代码的,是"哪条路值得走"与"哪块地非争

> 搜索论)的正主在兄弟宇宙
> [讲透运筹学](../../讲透数学/讲透运筹学/README.md),本章
> 走廊只做一件事:**把地形长出来的代价层,喂给那些正主**。

## 0. 开篇:三个教科书问题的一次跑通

「这条路通吗」「哪条路最隐蔽」「坡度限值收紧会发生什么」
——三个参谋作业的标准问题,
`experiments/terrain_mobility_corridor.py` 三分钟给出结构化
答案(虚构地形,不对应任何现实地区):

- **绕行律**:最短路径 5818 m/暴露 3228 m;综合路径(距离×
  暴露折中,λ=12)6770 m/暴露 1624 m——**多走 951 m,
  换少暴露 1604 m**:暴露代价使路径绕开通视区
- **排序律**:暴露惩罚 0→12→3000 单调加码,暴露长 3228→
  1624→1607 m 单调降、距离 5818→6770→6994 m 单调升
  ——**λ 是指挥员价值偏好的旋钮**,曲线的弯曲处就是
  "距离与暴露的市场价"
- **坡度截断律**:限值 30°→22°→15°,走廊两条(北鞍部+
  南垭口)→一条(仅垭口)→零条(不可达,Dijkstra 返回
  None)——**坡度限值是走廊存在性的硬开关,不是效率旋钮**:
  差半度就是"有路"与"没路"之别

而脚本同时打印纪律:高程/植被/限值/λ 全是教科书级示例参数,
结论只做结构比较——**代码替你算走廊,替不了你定参数**。

## 1. 可机械化边界(三件套之一)

**能进代码的**(地表参数化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 通视/暴露 | 视线采样+高程冠层遮挡(布尔矩阵) |
| 坡度/通行 | 中心差分→阈值→可行格(截断律) |
| 机动走廊 | 代价层上的 Dijkstra(三算:最短/最小暴露/综合) |
| 咽喉识别 | 图的割点/割边(桥与隘口的机器定义) |
| 涉渡/潮汐窗口 | 水位序列+阈值→时窗枚举(C4) |
| 变化检测 | 前后时相差分+阈值→AOI 触发(01 章热线四) |
| 图幅/坐标换算 | 基准/网格变换(MGRS/UTM→局部) |
| 毁伤评估的地学面 | 战后影像差分:回写"地表→复测"环 |

**不能进代码的**(军事地学的"不可判定域"):

1. **关键地形的"关键"**——任务语境不在图上;代码能算
   "稀有性"(同类地物计数),算不出"这次非它不可"
2. **通行性的现场状态**——土壤含水量/翻浆/雪深是状态,
   遥感给的是概率面;代码只能给"图上可通行(图龄 X 小时)"
3. **参数的定价**——λ 与坡度限值是兵棋观;扫参可以,
   宣称"最优"越权(02 章决策语言的边界)
4. **地学与决心的接口**——推荐走廊+备选+代价,选择永远
   是指挥员的(00/02 章一以贯之)

> 边界的一句话:**代码是地表的会计师,不是地理的指挥员**。
> 格网上算十遍,不如现地看一眼(状态!)。

## 2. C1 通视走廊

暴露场(03 章 §1.3)的最小计算:视线采样。

```python
def los(elev, surf, a, b, h_a, h_b):
    """a→b 通视:沿线采样,高程或冠层抬过视线即遮蔽。"""
    z0, z1 = elev[a[1]][a[0]] + h_a, elev[b[1]][b[0]] + h_b
    for i in range(1, n := max(2, int(dist(a, b) * 2))):
        t = i / n
        xi, yi = cell_at(a, b, t)              # 沿线插值落格
        sight = z0 + t * (z1 - z0)
        if elev[yi][xi] + canopy(surf[yi][xi]) > sight:
            return False
    return True
```

军事用途:观察哨定位(反向问:哪个位置看得见目标区)、
射界核对、遮蔽路线筛查。**对偶纪律照抄 03 章**:算完
"哨看谁",回头算"谁看哨"。中途岛(00 章美之时刻①)
的侦察几何,在这条走廊里就是一个二维版本。

## 3. C2 机动走廊(✅ 家族实验已实现)

代价层(03 章 §1.2)+Dijkstra:节点=可行格,边=8 邻接,
代价=`step×mult + λ×exposed_step`。三算对比的结构(实验
断言①②):λ=0 得最短路径,λ 巨大得最小暴露路径,中间
λ 得综合路径——**"距离-暴露"权衡曲线的整条前沿,都可以
用 λ 扫出来**。扩展方向:多起点多终点(走廊清单一次成表)、
时限约束(时间窗内的 λ 重扫)、对偶走廊(守方视角:在哪里
设哨使对方任何路径的暴露下界最大化——暴露场的攻防博弈,
与[战术学实验](../讲透战术学/experiments/swarm_vs_defense.py)
的饱和逻辑在同一层接口)。

## 4. C3 坡度层与截断律

```python
def slope(elev, x, y, cell):
    """中心差分坡度(度):s = atan(|∇z|/格距)。"""
    dzx = (elev[y][x+1] - elev[y][x-1]) / (2 * cell)
    dzy = (elev[y+1][x] - elev[y-1][x]) / (2 * cell)
    return math.degrees(math.atan(math.hypot(dzx, dzy)))
```

坡度层+平台限值→可行格集合;实验断言③(截断律)的教学
价值:可达性对限值**不连续**——30° 两条走廊、22° 一条、
15° 零条。采购一台爬坡能力多 5° 的平台,在地图上可能就是
"多一个战略方向";反过来,工兵破坏一条垭口,就是把对方
的走廊表砍掉一行——**地形工事的算法本质:修改割点**
(C2 咽喉识别的对抗面)。

## 5. C4 水文窗口走廊(水文支的算法化身)

"何时能渡"=水位序列+阈值判定:

```python
def ford_windows(stage_series, threshold_m, min_hours):
    """涉渡窗口:水位降到阈值下的连续时段(≥min_hours 才算窗)。"""
    windows, start = [], None
    for t, h in stage_series:            # (时刻, 水位 m)
        if h <= threshold_m and start is None:
            start = t
        elif h > threshold_m and start is not None:
            if hours(start, t) >= min_hours:
                windows.append((start, t))
            start = None
    return windows                       # [(起, 止), …]
```

潮汐用天文谐波(可算,误差分钟级),江河用降雨-径流模型
(耦合,误差天级)——**预报边界随水体类型分级**(00 章
问题清单)。敦刻尔克与诺曼底的故事(00 章)在这里变成
时窗枚举:登陆日历=潮汐窗×曙光窗×气象窗的交集,
水文支的正主(见[该支宪法](讲透军事水文学/README.md))。

**裂缝清单**(sim-to-real 的四道缝):

1. **参数=兵棋观**:通行系数/λ/限值/阈值,引用必附来源;
   无来源只能敏感性扫描(03 章三问的运行时版)
2. **分辨率≠语义**:格网再细,分类是概率的、状态是缺位的

3. **图龄时效**:as_of 过期的走廊计算,输出的是历史地形;
   算法战场的"流式"愿景,受制于传感器的重访周期
4. **虚构纪律**:本家族一切分析示例用虚构地形,不对应任何
   现实地区,不做任何现实地区的指向性演算——地学工具的
   双重用途性(救灾与作战同构)使这条纪律成为工程红线

## 📌 收束

四条主走廊:通视(C1)管"看得见谁",走廊(C2)管"怎么
权衡着走",坡度(C3)管"有没有路",窗口(C4)管"何时能过",
外加变化检测(C5)一根哨;共用一条边界——**关键、状态、
参数定价、选择,永远留在人脑**。跑到这里回看 00 章那句
钉住本质的话:地理没有敌我,只有参数——代码能替你把参数
算尽,**但"为哪个参数付多少代价",永远是决策者的事**。

**🧠 认知升维**:

- **λ 眼**:看到任何推荐路线,先找它隐含的 λ(暴露/时间/
  距离的内部汇率)——没写 λ 的推荐,是没报价的单子
- **截断眼**:评估通过性先问阈值在哪一侧——可达性是阶跃
  函数, averages(平均值)在这里会说谎
- **窗口眼**:水边的行动先问窗口枚举——错过一个窗,
  往往就是错过一个月(时窗的代价以季节计)
