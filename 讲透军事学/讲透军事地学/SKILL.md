# 军事地学思维技能卡(GB/T 83060 · 讲透军事地学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「这座高地值不值得抢」「反斜面是哪个坡」——OCOKA 与
  关键地形问题
- 「这条路装甲能不能走」「为什么绕这么远」——走廊与
  通行性问题
- 「这条河何时能渡」「登陆为什么挑那天」——水文窗口问题
- 「看得见吗」「哨摆哪」——通视与暴露问题
- 「GEOINT 到底是什么」「算法战场是什么」——01 章四热线
- 「DEM/暴露场/走廊图/AOI 怎么变数据」——schema 级需求
- 学战术/战役/战略时缺"底图层"——计划默认了哪个地表

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **底图眼** | 任何军事叙事先找地理底图——没有底图的计划是悬浮的 |
| **走廊眼** | 谈机动先数走廊几条、各自代价(距离/暴露/时限)——走廊数=选择权 |
| **咽喉眼** | 看走廊先找割点(桥/隘口/渡口)——走廊的价值集中在最窄处 |
| **快照眼** | 一切地理数据先问 as_of 与图龄——时点错了,精度是毒药 |
| **对偶眼** | 每个观察位先问"它被谁看见"——通视双向,暴露与侦察同源 |
| **参数眼** | 地理没有敌我只有参数——找到参数就找到翻盘杠杆(敦刻尔克换边) |
| **尺度眼** | 同一张图,参谋/坦克/小型平台读到三种地形——数据必附"给谁用" |
| **状态眼** | 通行性是状态不是属性(坡没变,一夜雨变了答案)——问图必问天 |

## 3. 工具箱(何时用什么)

- **OCOKA 五问**:观察射界/掩蔽隐蔽/障碍/关键地形/进接近路
  ——任何地形判断的审计框架;注意它是环不是清单(00 章)
- **翻译链**:高程/位置/时间→坡度/通视/水位→射界/走廊/窗口
  ——给"新地学产品"定位它在链上加工哪一段(03 章)
- **三算走廊模型**:最短(λ=0)/最小暴露(λ→∞)/综合(λ 中间)
  ——"距离-暴露"权衡的最小实现(家族实验
  `experiments/terrain_mobility_corridor.py`:绕行律/
  排序律/坡度截断律三组断言)
- **截断律**:坡度限值是走廊存在性的硬开关(30°→22°→15°:
  两条→一条→零条)——评估通过性先问阈值在哪一侧
- **水文窗口**:水位/潮汐序列+阈值→时窗枚举——"何时能渡"
  的标准算法(04 章 C4)
- **构造三问**:时点对齐/基准与分辨率声明/参数谁定——
  地理数据进代码前的类型检查(03 章)
- **对译表**:cover≠concealment(掩蔽防弹/隐蔽防看)、
  topography≠geography(图纸/底图)、DEM/DTM/DSM 三分
  ——地学翻译的三大坑(02 章)

## 4. 常见误区与禁忌

- ❌ **精度幻觉**:把测量精度当判断精度——高程准到米,
  不知道今天泥不泥;分辨率每升一级都要问图龄与状态
- ❌ **掩蔽隐蔽混用**:一个要工事一个要遮蔽——开错药方
  的经典入口(02 章成对词死分)
- ❌ **把关键当图属性**:图上有隘口≠此役非它不可——
  "关键"系于任务语境,不在等高线上
- ❌ **静态图当现势**:旧 DEM 上跑新走廊,输出历史地形
  ——as_of 是地学数据的第一毒性指标
- ❌ **平均值过阈值**:可达性是阶跃函数——"平均坡度可通行"
  在截断律面前是谎言
- ❌ **参数裸奔**:λ/通行系数/限值不注来源——兵棋观参数
  只能做序数比较,不能做基数宣称
- ❌ **敏感红线**:一切地学分析用虚构或通说案例,不对应
  任何现实地区、不做任何现实作战方向与阵地的指向性演算;
  现役话题(GEOINT/算法战场)只引公开文献(01 章)
