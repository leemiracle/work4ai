# 讲透军事地形学 · OCOKA 五问:战术地形的操作系统(8306030)

> **定位句**:这支负责讲清战术地形分析的通论——地形不是交战的
> 背景板,而是**三张表**:火力的射界表(谁看得见谁、打得着谁)、
> 机动的走廊表(从哪能来、代价几许)、防护的掩体表(哪里躲得开
> 火与眼);OCOKA 五问(观察与射界/掩蔽与隐蔽/障碍/关键地形/
> 进接近路)是全支的操作系统。GB/T 13745:8306030 军事地形学
> (三级,军事地学理论主干)。家族:[讲透军事地学](../README.md)。

## 诞生

《孙子·地形》六形(通挂支隘险远——分类+每形行动规则,最早的
决策表)与《行军》六害之地(障碍清单)开篇;若米尼(1838)把
地形抽象进战术几何;一二战使判读成为参谋标准件(斯大林格勒让
城市地形独立成类);20 世纪中 OCOKA 条令化(美军通说),DEM
时代判读对象从纸图变格网;2020s 微地形把尺度压到平台厘米级
(家族 01 章热线三)。

## 核心问题(带年代锚)

- **OCOKA 五问能否穷尽地形判断**:完备性之辩——条令化 20 世纪
  中起,悬而未决(五问覆盖判断,不覆盖任务权衡)
- **通视-暴露对偶**:哨位优化的双向约束(看人者必被看)
  ——传感器时代加剧,进行中
- **通行性的度量**:静态属性 vs 时变状态(滑铁卢的雨到无人机
  时代的土壤承载力)——悬而未决
- **关键地形判定的形式化**:稀有性可数、必要性系于任务——
  进行中,无闭式解
- **微地形尺度下移**:平台参数重定义"障碍"(30 cm 的沟对机器
  人是墙)——2020-,进行中

## ✨ 这支最美的一个事实

同一座山有两个"山顶":测绘上的最高点(topographic crest)与
战术上的军事棱线(military crest)——**后者不在最高处,在
"能发挥火力又不全吃对方炮兵"的棱线上**;反斜面阵地更把力量
藏在山的背面,只把眼睛留在通视线上。最高点是几何概念,军事
棱线是任务概念:地形的价值从来不由等高线单独定义,由"配谁
用、干什么"定义——全家族"参数眼"的第一课。
