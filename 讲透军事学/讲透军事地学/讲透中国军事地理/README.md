> **定位句**:这支负责讲清中国域内的军事地理通说——以历史
> 地理格局为经(三级阶梯/江河轴线/边海防形态),以要地兴废
> 为纬(关隘/渡口/枢纽的千年账本)。GB/T 13745:8306010
> 中国军事地理。家族:[讲透军事地学](../README.md)。

## 诞生

《禹贡》以山川导天下(地理纲领的古典源头);历代正史兵志与
方志沉淀要地知识;明清之际顾祖禹《读史方舆纪要》集其大成
——山川险易为经、历代用兵攻取为纬,历史军事地理正典(家族
00 章 1.2 节);近代随军校教材建制化;当代以遥感/GIS 复原
古战场与格局演变(数字转身)。

## 核心问题(带年代锚)

- **阶梯格局的战略含义**:三级阶梯与"守在四境/守在腹心"的
  历史命题(通说)——悬而未决:约束力随技术换代重估
- **江河轴线**:淮河-长江-黄河与南北对峙的地理骨架(历史
  通说)——进行中:河道变迁使古今参数不可直接比
- **关隘体系**:函谷/潼关/剑门等"走廊咽喉"的历史案例集
  ——咽喉=走廊图上的割点(家族 03 章的史学版)
- **边海防形态的历史演变**:从长城体系到海防(学科通说)
  ——进行中
- **方法问题**:文献+田野+GIS 三角互证——进行中

## ✨ 这支最美的一个事实

顾祖禹以一人之力、数十年,把"天下"写成一部**可检索的军事
地理数据库**:山川为字段、历代战例为记录、州郡为索引——
后人论某地险要,至今仍在他的索引里翻页。**"史"与"地"在
军事需求的压力下合体**,比 GIS 早三百年给出"图层叠加"的
思想形态:一层地理、一层战史,叠出要地。

## 假设与依赖

历史战例的幸存者偏差(打过的仗才被记录,没打的关隘沉默);
古今地理参数不可直接比(植被/河道/城市形态剧变,通行性复原
只能区间估计);格局命题的时代性(技术每代重写约束力,家族
00 章假设四)。数据依赖:历史文献、古地图、今 DEM(上游挂靠
420 测绘科学技术,待建宇宙)。
