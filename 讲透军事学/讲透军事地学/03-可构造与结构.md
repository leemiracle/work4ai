# 03 · 可构造与结构——DEM·暴露场·走廊·AOI:地表作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:军事地学里"可构造"的不是大地,而是大地的
> **参数化身**——DEM 是高程的数组、暴露场是通视的布尔矩阵、
> 机动走廊图是可行邻接的图、AOI 是带触发器的监测区;而
> "结构"是这门学科自己的骨架:三个原始量→派生量→战术要素
> 的翻译链(00 章)与 OCOKA 的环形耦合。**把地表参数化,
> 正是"方志→地图→DEM→算法"四代介质在数据层的重演**。

---

## 0. 开篇:一个 DEM 能回答的五个问题

拿到一个高程格网,参谋会问五个问题:这两点看得见吗(通视)?
这条路通吗(走廊)?雨后还通吗(通行性状态)?哪片区域
变了(变化检测)?哪里非经不可(关键地形/咽喉)?前四问
都是**格网上的计算**——差分、采样、搜索、比较;第五问是
前四问的乘积再乘一个图外变量(任务)。本章的全部内容,
就是这五问的数据结构化:前四问各有 schema,第五问只有
半张结构——那一半的缺口,正是本学科的尊严所在
(§2 不可构造清单)。

## 1. 什么是"可构造"的:五类地学对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **DEM 高程格网** | z 数组+格距+基准(§1.1) | ✅ 高度可构造 | 高程≠地形:DEM/DTM/DSM 三分,混用即错位 |
| **地表/代价层** | 属性格网(类别×通行系数×遮蔽高)(§1.2) | ✅ 可构造 | 系数=兵棋观:谁定的参数,结论归谁 |
| **暴露场** | 观察哨集合×通视布尔矩阵(§1.3) | ✅ 可构造(家族实验已实现) | 通视双向:哨自己也在别人的暴露场里 |
| **机动走廊图** | 格网上的可行邻接图(§1.4) | ✅ 可构造(Dijkstra 正主在运筹学) | 走廊是图不是线:割点(桥/隘口)才是它的灵魂 |
| **AOI 监测区** | 多边形+触发器+时窗(§1.5) | ✅ schema 成熟 | 触发阈值定太高漏情、太低耗竭注意力(01 章热线四) |

**不可构造的**:关键地形的"关键"(任务语境不在图上)、
通行性的现场状态(雨后翻浆只有脚知道)、地形对士气的
作用(进[军事心理学](../讲透军事心理学/README.md)的辖区)、
以及"这片地值不值得为它打"(价值判断永远是指挥员的)。

### 1.1 DEM 高程格网 schema(动手者的第一格)

```yaml
# DEM:地表高程的数组化身(等高线的数字化身,02 章)
dem: {z: [[float]],            # 高程矩阵[z][x],米
      shape: [ny, nx], cell_size_m: 100.0,
      crs: str,                # 平面基准(MGRS/UTM…)
      vdatum: str,             # 高程基准——跨源不声明即错位
      as_of: str,              # 成图时点(图龄=第一毒性指标)
      source: 影像立体测绘|雷达|等高线矢量化|激光,
      kind: DEM|DTM|DSM}       # 裸地还是含植被建筑,必声明
```

### 1.2 地表/代价层:类别的参数化

```yaml
# 代价层:地表类型×通行系数×遮蔽高(系数=兵棋观,02 章)
cost_layer: {classes: [
    {name: 开阔, mult: 1.0, canopy_m: 0.0, passable: true},
    {name: 草甸, mult: 1.05, canopy_m: 0.0, passable: true},
    {name: 森林, mult: 2.6, canopy_m: 10.0, passable: true},
    {name: 水域, mult: null, canopy_m: 0.0, passable: false}],
  platform: {vehicle_height_m: 2.0,   # 平台参数化(01 章热线三:
   slope_limit_deg: 22.0, soil_note: 承载力未现场核实},
  as_of: str}                          # 植被/水位随时节——状态字段
```

森林的双重身份全在这两行:mult(慢)与 canopy_m(挡视线)
——**遮蔽与迟滞是同一片植被的两面**(00 章 OCOKA 的 C 与
O 在数据层的合流)。

### 1.3 暴露场:通视的布尔矩阵

```yaml
# 暴露场:谁被谁看见(家族实验的核心结构)
exposure: {observers: [{pos: [x, y], mast_m: 15.0, as_of: str}],
           target_height_m: 2.0,
           los: {(x,y): [obs_id, …]},   # 被哪些哨通视(布尔矩阵)
           rule: 森林格自带隐蔽(冠层>车高)}
```

对偶纪律:构造暴露场的同时,把每个观察哨自己也放进候选
暴露集算一遍——**哨看得越远,越早进别人的矩阵**(00 章
反直觉之三)。

### 1.4 机动走廊图:从格网到图

```yaml
# 走廊图:可行邻接(代价=距离×mult+λ×暴露)
corridor: {nodes: 可行格(坡度≤限值∧非水,桥除外),
           edges: 8 邻接, cost: step*mult + λ*exposed_step,
           chokepoints: [桥(18,20), 隘口],   # 割点/割边:走廊的灵魂
           reports: [{name: 一号走廊, via: [..],
                      length_m: 5818, exposed_m: 3228}]}
```

走廊的真身是**图**,不是图上画的那条线:决策要的输出是
{走廊名,经由,距离,暴露,时限}的清单+咽喉清单——家族
实验打印的三行对比表,就是 reports 字段的最小实例。

### 1.5 AOI 监测区:带触发器的面

```yaml
# AOI:算法战场的基本订阅单元(01 章热线一/四)
aoi: {polygon: [[x, y], …], theme: 车辙|施工|集结痕迹,
      trigger: {metric: 变化像素率, threshold: 0.08,
                window_h: 24, revisit_h: 6},
      confidence: 中,      # 触发句的宾语(02 章决策语言)
      as_of: str}
```

AOI 把"守着看"变成"订阅着等"——地学与指挥链的管道从
产品交付改为流式推送(01 章热线四的 schema 落点)。

## 2. 骨架一:翻译链的刚性(结构的承重墙)

00 章的翻译链(原始量→派生量→战术要素)是本学科的**刚性
结构**:任何地学新产品,都是这条链上的一段加工——GEOINT
影像产品在"位置→活动"段(01 章热线一),微地形分析在
"派生量→平台要素"段(热线三),算法战场想把全链流式化
(热线四)。**结构派的读法**:判断一个"新地学产品"的寿命,
先定位它在链上加工哪一段、参数谁定的;只换介质的,是改名
不是创新(承[战术学 00 章](../讲透战术学/00-体系结构.md)
逆境眼的同款逻辑)。

## 3. 骨架二:OCOKA 的环形耦合

OCOKA 不是五条并列的清单,是一个**环**:K(关键)依赖 A
(是不是必经),A 依赖 O/C(过得去还要活得下),O 与 C 共享
同一批地物(通视的坡就是射界的坡,遮蔽的林就是迟滞的林)。
**环的含义**:任何一问的答案都是其余四问的函数——所以
"逐问打分求和"的自动化评估(01 章热线三的诱惑)天然失真:
环上的耦合不是加法,是乘法甚至反馈。这也是 02 章说
"OCOKA 覆盖判断、不覆盖权衡"的结构原因。

## 4. 构造合法性清单(动手前三问)

把任何地理材料变成数据结构之前,先过三问——本家族的
"类型检查":

1. **时点对齐了吗**:DEM 的 as_of、代价层的植被状态、
   敌情的时点,三者一致吗?——图是三年的,植被是一季的,
   敌情是今晨的,拼起来就是自欺(00 章滑铁卢的数据版)
2. **基准与分辨率声明了吗**:crs/vdatum/DEM-DTM-DSM、
   格距或比例尺——不声明的叠加,是"看起来在同一张图上"
   的两套坐标(02 章比例尺陷阱的工程版)
3. **代价参数谁定的**:通行系数、暴露惩罚 λ、坡度限值、
   触发阈值——每个数都是兵棋观,引用必附来源;无来源的
   只能做敏感性扫描,不能做结论(承运筹学同款纪律)

三问全过,数据才获得进入 [04 章走廊](04-军事地学转代码.md)
的资格。**军事地学计算的第一特征不是算法,是把 02 章的
语言纪律(图龄/条件句/参数自带)写进数据结构。**

## 📌 收束

可构造的是**参数化身**(格网/矩阵/图/订阅),不可构造的是
**状态与语境**(泥泞的现场、"关键"的任务依赖);翻译链给
刚性,OCOKA 环给耦合,三问给入场券。下一章把这些 schema
接上代码:通视、最短路机动、坡度层、水文窗口四条走廊:
[04-军事地学转代码](04-军事地学转代码.md)。

**🧠 认知升维**:

- **化身眼**:拿到任何地学数据先问"它是什么的化身"——
  数组化丢失了什么(状态、语境、关系),比它保留了什么更重要
- **咽喉眼**:看走廊先找割点(桥/隘口/渡口)——走廊的价值
  集中在它最窄处,不在它最长处
- **三问眼**:拼数据先问时点、基准、参数——三个"没问题"
  里面至少藏着一个还没问过的问题
