# 讲透军事情报学 · 输入侧:把观察变成判断(GB/T 8304040)

> **定位句**:C2 的输入侧——情报周期(计划与指向→搜集→处理→
> 分析→分发)与研究方法:如何把观察喂给决策者、如何不把假设
> 喂成事实。一句钉住:**情报不是图片,是置信度**——它给指挥官
> 的不是"敌情",是"我们对敌情的相信程度及其理由"。
> GB/T 13745:8304040 军事情报学(三级学科,83040 之下)。
> 家族:[讲透军队指挥学](../README.md)。

## 诞生

近代情报建制化始于 19 世纪总参谋部情报处(与毛奇的参谋作业
同源,家族 00 章§1.2)。二战是本支的成人礼:太平洋战场密码
情报战(中途岛 1942"AF 缺淡水",通说叙事)与欧洲战场密码破译
(Ultra,通说)确立"情报是一阶战斗力"的通说。冷战时期情报分析
成为独立专业(Kent 1949、Heuer 1999,均公开文献),分析心理学
进入学科;当代 OSINT(公开来源情报)把"搜集"门槛踩平,
分析的质量问题反而更突出(方向锚)。

## 核心问题(带年代锚)

- 情报-决策接口:好情报为何不被采纳(进行中——02 章"通报伪装
  成命令"是它的语法面)
- **分析陷阱**:镜像思维/锚定/群体思维(Heuer 1999,公开文献)
- 秘密与公开:OSINT 时代秘密情报的边际价值(进行中,方向锚)
- 情报周期模型的失真:线性流程 vs 实际迭代(进行中)
- 情报的政治化与客观性(通说;敏感性按家族治理红线处理:
  只述学理,不评现行)

## ✨ 这支最美的一个事实

"AF 缺淡水"(1942.5):破译方让中途岛基地用明语发出"淡水设备
故障"的假报文,再从截获的日军通信中确认"AF 目标缺水"——
用一次受控的假信息把对手的"观察"变成自己设计的实验,目标之谜
在开战前揭晓,会战几何随之改写(通说叙事,证据级 T3;史学侧详
[讲透军事史](../../讲透军事史/README.md))。**情报战的极致
不是听见对手,是让对手说你安排的话**——OODA 的观察环
可以被"代填"(家族 00 章美之时刻③/假设三的敌对耦合实例)。
