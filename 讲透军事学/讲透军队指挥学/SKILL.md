# 军队指挥学思维技能卡(GB/T 83040 · 讲透军队指挥学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「指挥体系/参谋部/指挥链怎么设计」——组织设计需求
- 「任务式指挥 vs 详细式指挥怎么选」——语法层级与授权问题
- 「OODA 快是不是就赢」「信息优势为什么没转化成胜势」——节奏论
- 「AI 会让指挥更集中还是更分散」「决策优势怎么度量」——01 章热线
- 「通信一断指挥就瘫怎么办」——抗毁与预先授权
- 「意图怎么写才不会过期」——意图三元组(目的/终态/约束)
- 多智能体编排、控制平面、声明式系统的组织学对照——工程师反查
- 指挥关系/OODA 时延/COP 航迹/五段式命令的数据化——schema 级需求

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **节奏眼** | 看组织先看决策周期:OODA 四段各多长、最长的一段是谁(串行系统优化瓶颈) |
| **带宽眼** | 指挥=带宽受限的分布式系统:"管到一线"的冲动先算信道容量与排队队列 |
| **意图眼** | 管复杂系统靠"约束+意图"而非步骤清单;命令可改三遍,意图不改一遍 |
| **拓扑眼** | 指挥方式上限由网络拓扑决定:星型跑不了任务式,网状想集中也难 |
| **耦合眼** | OODA 是博弈不是田径——你的环会被对手攻击,观察可以被"代填"(中途岛) |
| **置信度眼** | 情报给的是置信度不是图片;每条航迹/断言自带"我们多相信它"的标签 |
| **担责眼** | 选项生成可机械化,裁定与担责不可——批准按钮的位置就是责任的位置 |

## 3. 工具箱(何时用什么)

- **五次信道革命编年**:将旗→电报总参谋部→无线电→数据链→
  网络中心/AI(每次革命先集中后分散的钟摆)——判断任何
  "新技术改写指挥"宣称的历史坐标
- **OODA 竞赛零模型**(家族实验 `experiments/ooda_race.py`):
  四阶段时延参数化+断链罚时;核心断言「单优信息+集中式
  <信息略差+去中心化」——节奏论的机器化
- **意图三元组**:purpose(目的)+end_state(终态)+
  constraints(不可越界清单)——共同理解的机器可读最小集
- **语法三级**:命令(无裁量)/指示(给边界)/通报(只给事实)
  ——一句指令先分层,再判断它的"变化保质期"
- **指挥关系六类**:隶属/配属/作战控制/战术控制/支援/协调,
  一律带 as_of 快照——权责的显式标注
- **决策优势三段**:快(时延)/好(方案质量)/分发(到达)——
  只报一段的度量必有隐瞒
- **五段式命令 schema**:态势/任务/执行/保障/指挥控制+
  意图完备性检查(04 章 C2 十行实现)

## 4. 常见误区与禁忌

- ❌ **带宽幻觉**:「看见一切就能裁决一切」——观察收益会被
  分发排队吃掉;信息优势的正确投资方向是边缘,不是中枢
- ❌ **把任务式当放任**:授权=意图+边界+能力+互信四件套,
  只给"你自己定"不是任务式,是甩锅
- ❌ **把 OODA 当田径**:独立时钟只是近似——对手在攻击你的环;
  引用"快者胜"必须补上"快而错"的反论
- ❌ **命令越写越细**:写多细=过期多快;变化环境下重心
  应压在意图段而不是执行段
- ❌ 仿真当检验:OODA 胜率是零模型输出(机器化反事实),
  冒充实兵检验是数字时代新病
- ❌ 裸值航迹:不带来源/时戳/置信度的态势数据,按流言处理
- ❌ **敏感红线**:各国现行指挥体制与条令按公开文献通说、
  只述学理;不评价任何国家军队政策与人物,不涉现行部署
