# 讲透军事通信学 · 信道层:命令跨地平线,也跨进对手的接收机(GB/T 8304030)

> **定位句**:C2 的信道层——军事信息的传输、交换与组网:命令如何
> 跨地平线(带宽)、如何在对抗下活着(抗毁)、如何不被对手听见
> (隐蔽)。一句钉住:**通信即能力,通信即暴露**——每一次发射
> 都在同时服务己方指挥链与敌方测向仪。
> GB/T 13745:8304030 军事通信学(三级学科,83040 之下)。
> 家族:[讲透军队指挥学](../README.md)。

## 诞生

电报军用化(19 世纪中叶)让命令第一次跑赢骑兵(毛奇的总参谋部
以电报+军列时刻表实现分进合击,家族 00 章§1.2);无线电(1900s)
让机动中的舰队、飞机、装甲兵第一次拥有实时信道,也让"发射即
暴露"成为公理。日德兰(1916)信号旗的语义歧义、二战无线电测向
与静默管理、冷战数据链与卫星通信、当代抗干扰组网与低截获概率
通信(LPI,通说),构成本支的四级台阶——每一级都在"带宽-抗毁-
隐蔽"三角里挪动位置。

## 核心问题(带年代锚)

- **带宽-抗毁-隐蔽三角**:三者互相牵制(方向锚:扩频/跳频以
  带宽换隐蔽;定向通信以机动换暴露)
- 协议语义的歧义成本——日德兰母题(1916,通说;家族 00 章§1.3):
  信道无恙、密码无恙,败在语义层
- 通信网拓扑与指挥方式耦合:网状网支持去中心化,星型网强迫集中
  ——**星型网上跑不了任务式指挥**(家族 03 章§3)
- 电磁频谱管理:军民共用频段的冲突(进行中,通说)
- 量子通信的军事前景(方向锚:物理本体在物理学宇宙,待建)

## ✨ 这支最美的一个事实

日德兰海战(1916.5.31):英大舰队旗舰在机动转换时出现两旗同挂、
含义相反的时刻,僚舰无从判读,舰队转向迟疑,追击窗口关闭
(通说叙事)——**史上最贵的协议语法歧义**。它把一件事钉进学科:
通信不只是物理层,协议的语义设计是战斗力;冲突消解规则
(上级>下级、最新>最早、明示>默示)是信道的一部分,不是事后
补丁(家族 00 章美之时刻的通信学注脚)。
