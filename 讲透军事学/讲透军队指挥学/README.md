# 讲透军队指挥学 · C2:军队的神经系统(GB/T 83040)

> **军队指挥学=把决心变成指令、把指令变成协同的组织科学——
> Command and Control(C2)是军队的神经系统**。战略学定"为何而战",
> 战役战术学定"怎么打",本家族管**决心如何变成千军万马的行动**:
> 观察-判断-决策-行动(OODA)的闭环在组织里怎么跑起来、跑多快、
> 断了怎么活。一句钉住:**"统帅的才能,一半在下决心,
> 一半在让决心跑赢对手的决心。"**(节奏论)
>
> GB/T 13745:83040(二级学科,军事学 830 之下)。宇宙:[讲透军事学](../README.md)。

  [讲透信息与系统工程技术/讲透信息安全技术](../../讲透信息与系统工程技术/讲透信息安全技术/)
