## 0. 开篇:一个 150 年的直觉,三分钟跑出数

「看得最清的手不该攥着所有裁决权」——这个 01 章热线三的反论
(空军大学:AI 决策支持增强去中心化执行)能不能用数据说话?

`experiments/ooda_race.py` 把双方各建成一台四阶段计时器
(观察/判断/决策分发/行动,指数时延),信息优势缩观察时延、
任务式指挥缩决策分发时延、链路中断给集中式重罚;40000 轮
蒙特卡洛跑出四个断言:

- **对称性**:同构双方胜率≈0.5(模型无偏)
- **双优胜出**:信息优+去中心化 显著胜 信息劣+集中式
- **反论检验(核心)**:「单优信息+集中式」胜率**低于**
  「信息略差+去中心化」——观察收益被分发排队吃掉的机器化证明
- **脆弱性梯度**:断链率上升,集中式胜率单调劣化快于去中心化

但脚本同时打印建模边界:独立时钟假设(敌对耦合未建模)、
时延参数=指挥文化假设(04 章§1)。**代码替你算节奏,
替不了你算文化**——军队指挥学数字化的第一课。

## 1. 可机械化边界(三件套之一):决心生成之辩

**能进代码的**(指挥数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 节奏比较 | OODA 时延参数 → 竞赛模拟/胜率(家族实验) |
| 方案(COA)生成 | 任务分析输出 → 候选方案枚举与排序(搜索问题) |
| 方案推演 | 兵棋引擎 → 各方案结局分布(承[军事史](../讲透军事史/04-军事史转代码.md)C3 兰彻斯特走廊) |
| 命令格式校验 | 五段式文书 → schema 检查+意图三元组完备性(C2) |
| 航迹融合 | 多源 COP → 置信度合成(C3) |
| 关系一致性 | 指挥关系图 → 双重隶属/环路检测 |
| 网络抗毁 | 拓扑图 → 节点删除模拟(集中度-韧性权衡) |

**不能进代码的**(指挥学的"不可判定域"):

1. **决心生成之辩**:算法可以生成方案、排序方案、推演方案——
   但"值不值得打、为什么打"的目的生成是价值判断;
   **选项生成可机械化,选项裁定不可**。更深一层:批准即担责,
   责任主体必须是人——不是认识论限制,是**责任结构的限制**
   (01 章 MDMP 讨论收敛于"意图与批准步留人"的同因)
2. **共同理解的生成**:可以校验命令里有没有意图段,不能校验
   下级有没有内化它——演习是唯一检验场,模拟只能测一致度
   不能测理解度(03 章§4)
3. **敌对耦合**:OODA 竞赛模型是零模型;真实对手会攻击你的环
   (中途岛式"代填观察")——对抗性推演可以逼近,不能穷尽
   (信息不完全下的博弈没有"算尽")

> 边界的一句话:**代码是指挥所的沙盘,不是指挥官**。
> 沙盘上推十遍,不如演习场上对一次。

## 2. C1 OODA 竞赛走廊(✅ 已实现)

成品=`experiments/ooda_race.py`(数据+断言一体):

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| obs/ori/dec/act | float(时延均值) | 参数=指挥文化假设,引用须附来源 |
| fail_p/fail_pen | float | 断链率/罚时:集中式重罚(总部中转)、去中心化轻罚(本地裁决) |
| rounds/seed | int | 固定种子=可复现;换种子看方差是正确姿势 |
| 输出 | 胜率 | 序数结论(谁更快),不是基数预言(伤亡几何) |

胜负从"先手"变"交换";把断链从罚时改成图删除(03 章§3 拓扑)。

## 3. C2 命令校验走廊(最小示例)

五段式命令的 schema 检查+意图三元组完备性(02 章§2.6/03 章§1.5):

```python
# 意图三元组完备性检查(03 章 intent schema 的最小落地)
def intent_complete(oporder):
    """指挥官意图=目的+终态+约束,缺一即"宪法段"不完备。"""
    it = oporder.get("s3_execution", {}).get("intent", {})
    missing = [k for k in ("purpose", "end_state", "constraints") if not it.get(k)]
    return not missing, missing

ORDER = {"s3_execution": {"intent": {"purpose": "夺占渡口",
                                     "end_state": "我岸至对岸走廊畅通",
                                     "constraints": []}}}   # 空约束清单
ok, missing = intent_complete(ORDER)
assert ok and missing == [], "三元组齐备才过检"
print("意图三元组齐备——格式可校验,'被理解'仍须演习检验(C2 边界)")
```

十行代码完成的事:一份命令 → 合法性标记 + 缺项清单。
校验器管"有没有",不管"懂不懂"——后者是 02 章"不能传递
理解本身"的代码回声。

## 4. C3 航迹融合走廊(最小示例)

COP 的置信度合成:独立源假设下 odds 相乘(朴素贝叶斯):

```python
def fuse_conf(p_a, p_b):
    """双源身份置信度融合(独立假设):odds 相乘再归一。"""
    o = (p_a / (1 - p_a)) * (p_b / (1 - p_b))
    return o / (1 + o)

assert abs(fuse_conf(0.6, 0.6) - 0.6923) < 5e-4   # 两个"略过半"≈0.69
assert abs(fuse_conf(0.9, 0.4) - 0.8571) < 5e-4   # 强源抬升弱源仍显著
print("融合律:弱源也在抬升置信度——但独立性假设是前提不是默认")
```

**走廊警告**:两源抄同一份通报时相乘=虚假自信(03 章§4
两条纪律的代码面);融合前必须核源间独立性,核不了就按
单源保守处理。

## 6. C5 意图约束的分布式 agent 走廊(描述级)

任务式指挥的仿真化:给每个 agent 只发意图三元组+约束

→ 04 章工程师落点的桥)。

## 7. 工程师落点(军队指挥学给你的工程赠礼)

- **声明式系统=任务式指挥的系统形态**:Kubernetes 式"期望状态
  +控制器自主收敛"就是意图三元组(end_state)的技术实现——
  运维界用十年重新发明了 Auftragstaktik,双向奔赴
- **控制平面设计=指挥链设计**:一致性 vs 可用性的权衡
  (CAP)即集中裁决 vs 断链可用的权衡;脑裂(split-brain)处理
  =多点指挥冲突消解(02 章消解规则的分布式版本)
- **降级预案=预先授权**:超时熔断、失败兜底、本地自治模式
  (断链语言:"若通信中断,按预定方案独立行动"的工程同构)
- **多智能体编排**:orchestration(中心编排)vs choreography
  (编舞式去中心)——集中-分散钟摆在软件架构里的又一轮摆动
- **事故指挥系统(ICS)**:准军事指挥语言的民用版
  (消防/应急的标准指挥语法)——五段式与意图三元组在事故现场的
  直接对应物

**走廊三警告**(承军事史家族 04 章警告同源):

1. **参数=指挥文化**:时延均值谁定的,结论就归谁——
   引用推演结果必附参数来源
2. **仿真输出=机器化的反事实**:OODA 竞赛的胜率是节奏论
   零模型的输出,冒充实兵检验是数字时代新病
3. **独立假设必注**:独立时钟/独立源,两条独立性假设不注明的
   模型,默认按教科书处理,不按指挥学处理
