## 三、特征速查(问题→家族)

- 战争的本质/军事思想流变 → 军事理论(含军事思想史)
- 战史/某场战争怎么打怎么败 → 军事史
- 士气/战场压力/军人选拔 → 军事心理学
- 国家层级战争筹划/核威慑 → 战略学;战区军团层级 → 战役学;分队交战 → 战术学
- 指挥控制/情报(密码学去 413)/军事通信 → 军队指挥学
- 体制/装备管理/军队管理 → 军制学;保障链/物资油料 → 军事后勤学
- 地形/军事地理/气象水文 → 军事地学;武器技术革命 → 军事技术
