> **定位句**:后方专业勤务=**各类保障物资与勤务的专业学**——
> 油料、弹药、军需(给养被装)、卫生、维修五大勤务各自的库存律、
> 时效律与安全律。一句钉住:**它们共用一张补给网,却各有一套
> 物理脾气**——油料是大流量流体,弹药是爆发性消耗+安全库存,
> 军需是连续小流量,卫生是易腐+时效,维修是逆向物流。GB/T

> [讲透军事后勤学](../README.md)。

## 诞生

古代只有"粮草"一门勤务(给养独大);火药时代加了弹药,蒸汽-
内燃机时代加了油料,工业化军队再加卫生与维修的专业建制(通说)。
一战催熟卫生勤务(大规模伤员后送体系),二战催熟维修勤务
(机械化装备的战场抢修);现代联勤体制把五大勤务从"各军种自办"
推向"统一核算、专业直供"(通说)——每一步都是**新的物理脾气
逼出新的专业**。

## 核心问题(带年代锚)

- **油料勤务**:大流量流体的管道化储存/前送;战略油料储备
  (二战石油命脉的延续题,通说)
- **弹药勤务**:爆发性消耗与基数语言(02 章);储备的防爆安全律
  与周转律的冲突(通说)
- **军需勤务**:连续小流量+季节性(被装)+文化性(给养)——
  最古老的勤务,最不可预测的偏好
- **卫生勤务**:伤员流的阶梯后送与"黄金一小时"时效律(一战-,
  通说);血液与药材的易腐库存
- **维修勤务**:三级维修(基层/中继/基地,通说)与战场抢修;
  逆向物流(损装后送)的优先级冲突

## ✨ 这支最美的一个事实

五大勤务的库存律像五行各异,却在"作战量纲"语言里汇成一套语法:
弹药按"基数"(能打几次)、油料按"日份"(能跑几天)、给养按
"日份"(能吃几天)、血液按"天数"(能存几天)、备件按"满足率"
(修得上吗)——**每种物资都用"能维持多久"自报库存**,五种
物理脾气被一个量纲收编(家族 02 章翻译眼的原始现场)。
