# 军事后勤学思维技能卡(GB/T 83055 · 讲透军事后勤学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「作战半径/战略投送/给养函数」——半径=流量的输出,不是愿望
- 「库存该囤多少」「安全库存怎么定」——报童/代价不对称问题
- 「大批次还是小批次」「配送频率怎么选」——批次-缓冲判据
- 「预置还是投送」「前置部署的储备放哪」——库存金字塔第二层
- 「对抗性后勤是什么」「补给线被打了怎么办」——环境假设换底
- 「预测性后勤/智慧保障靠谱吗」——信息替代库存及其软肋
- 「供应链为什么越囤越乱」——铁山律与牛鞭效应
- 供应链设计、多级缓存、容灾混沌、RTS 游戏经济——工程师反查
- 补给网络/储量参数/配送周期/伤员流的数据化——schema 级需求

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **流量眼** | 看部队/组织先看日消耗向量:烧什么、烧多少、从哪来——燃烧率决定一切半径 |
| **缓冲眼** | 库存=对无知的保险费;问一笔库存先问它保哪种无知(需求/时延/敌情) |
| **分篮眼** | 对抗环境下期望不值钱,分布才值钱——鲁棒性设计改方差,不改均值 |
| **环境眼** | 评估保障体系先问默认环境假设:安全还是对抗?假设一换,全部最优解作废 |
| **金字塔眼** | 库存不是数是结构:携行-预置-储备三层,数量×距离×响应三轴 |
| **三重真值眼** | 问"有没有库存"先问三件事:账实一致吗?在哪?还能用吗? |
| **循环眼** | 后勤不是链是环——消耗数据回流是感觉神经,回流一断就长铁山 |

## 3. 工具箱(何时用什么)

- **七次变轨编年**:辎重畜群→仓库围城→铁路动员→机械化岛跳→
  柏林空运学科自觉→集装箱化铁山→对抗性后勤——判断任何
  "后勤革命"宣称的历史坐标
- **批次-缓冲判据**(家族实验 `experiments/contested_resupply.py`):
  大批次劣于小批次的条件=对抗强度 p 高**且**缓冲 S 盖不住
  连续遭袭窗口(k≈⌈S/Q⌉+1 个满损批次);缓冲够深则集约经济
  恢复——策略优劣是 (p,S,Q) 的函数,不是属性
- **库存金字塔三层**:携行(基数×消耗率)/预置(位置变量)/
  战略储备——预置 vs 投送=第二层厚度问题
- **三重属性弧**:补给线每条弧带容量(吞吐上限)/时延(响应)/
  风险(概率×损失)——只有前两栏的图是和平地图
- **代价不对称公式**:断供:过储代价比→临界分位数→安全库存
  (04 章 C2 十行实现)——铁山的解析起源
- **牛鞭三问**:波动沿链放大了吗?批量订货锐化了吗?信息
  走样了吗?——预测性后勤的对症清单
- **给养函数作业**:建制实力快照×消耗标准(分强度)=日需求
  向量;除以运输日吞吐=所需线数——把"半径"变成除法

## 4. 常见误区与禁忌

- ❌ **把库存当美德**:库存是资产也是噪声——富裕的瘫痪
  (铁山律):越多越慢越看不清
- ❌ **用和平数据外推战斗日**:战斗日/平时消耗差一个量级,
  演习外推是系统性低估
- ❌ **裸值库存**:不带 as_of 快照、不挂强度假设、不对账的
  储量数字,按流言处理
- ❌ **单位四把尺**:吨/件/基数/日份混用不显式换算——加总即事故
- ❌ **把分篮当万能**:独立遭袭假设失守(对手学节奏打咽喉)
  时分篮逻辑部分失效——随机干扰≠对抗优化
- ❌ **仿真当检验**:蒙特卡洛的断供天数是模型世界的数,
  参数=消耗标准,引用必附来源
- ❌ **敏感红线**:各国现行后勤体制与条令按公开文献通说、
  只述学理;不评价任何国家军队政策与人物,不涉现行储量、
  运力与部署数据
