# 讲透军事后勤学 · 保障层:军队的循环系统(GB/T 83055)

> **军事后勤学=研究武装力量保障的科学——油弹食件怎么流、伤员与
> 损装怎么回、保障体系怎么在对抗下活着**。战略学定"为何而战",
> 战役战术学定"怎么打",本家族管**部队凭什么持续打下去**:
> 军事学通语"外行谈战术,内行谈后勤"的本体——后勤是军队的
> 循环系统,断了它,神经系统(指挥)再快也是瘫痪的快。
> 一句钉住:**任何作战半径都是给养函数的输出**(节奏论在这里
> 让位于流量论)。
>
> GB/T 13745:83055(二级学科,军事学 830 之下)。宇宙:[讲透军事学](../README.md)。

## 〇、家族定位与成员

- 学科身份:军事学宇宙的**保障层**——一切打法(战略/战役/战术)
  的物质前提:油料/弹药/给养/备件(油弹食件)四类流量 + 医疗
  (伤员后送)/维修(损装再生)两大逆向流 + 运输(把一切送达的
  动脉)——三件套在此合流
- 分层法:[战略学](../讲透战略学/README.md)定打多久打多远,
  [战役学](../讲透战役学/README.md)定打到哪,[军队指挥学](../讲透军队指挥学/README.md)
  定命令怎么跑,军制学(83045)定编制——**本家族定"部队凭什么
  还在打"**
- 跨宇宙挂靠:供应链/库存/网络的通论本体在
  [讲透管理学](../../讲透管理学/README.md)(宇宙级互链:军品
  保障与民口供应链是同一门流量科学的两套语汇);库存论/网络流/
  排队论的数学本体在[讲透数学/讲透运筹学](../../讲透数学/讲透运筹学/);
  经济动员与军费在[讲透经济学/讲透国防经济学](../../讲透经济学/讲透国防经济学/)
- 承接声明:[军事史家族 03 章"骨架三:后勤约束"](../讲透军事史/03-可构造与结构.md)
  提出"作战半径=给养函数"的史学骨架——**本家族是它的正主展开**
  (那边的四参数化在此升级为可构造模型),互指不重复
- 敏感纪律:涉各国现行后勤体制与条令(FM 4-0 等)一律按公开文献
  通说、只述学理;教科书式中性语体,不评价任何国家军队政策与人物;
  不涉现行部署、储量与运输数据
