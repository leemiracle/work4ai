## 诞生

辎重营是它的古代形态(押运即指挥);铁路动员时刻表(1860s-)
让它第一次需要参谋作业;红球快运(1944)证明**制度即运力**;
海湾"铁山"暴露计划-调度-可视三位一体的短板;2024"对抗性后勤"
入条令后,路线选择、批次节奏、节点抗毁成为设计变量——本支从
"运输管理"升格为**流量指挥学**(家族 00 章七次变轨的指挥侧)。

## 核心问题(带年代锚)

- **优先级裁定**:有限运力下"舍谁保谁"——作战急需>常规>储备
  的裁决序及其例外(通说;价值判断的组织化)
- 前送(push)还是后送(pull):计划配给 vs 需求牵引(二战-
  "基于配送"之争,家族 00 章问题清单)
- 配送网络的抗毁重构:多路径冗余/小枢纽分散/动态改线
  (对抗性后勤的核心动作,2024-;家族实验的批次与缓冲参数)
- 后勤指挥关系:建制保障/区域保障/相互支援的权责拓扑
  (承[军队指挥学](../../讲透军队指挥学/README.md)指挥关系六类)
- 需求汇总与预测:消耗数据回流怎么变成计划输入(预测性后勤,
  2020s-,家族 01 章热线二)

## ✨ 这支最美的一个事实

红球快运(1944.8-11):数千辆卡车、没有一件新装备,靠**单向
循环专线**的组织规则(去程专用、空车返程另线、民车禁入、司机
轮班)把运力近似翻倍,撑住整个战线的油弹血脉(通说叙事,T3)。
本支第一定律:**运力的上限常常不在车辆数,在调度协议**——
制度设计是隐形运力(家族 00 章美之时刻②)。
