# 03 · 可构造与结构——曲线、里程碑与网络:技术作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:军事技术里"可构造"的不是武器,而是**技术的
> 四套模型**:成熟度曲线(一项技术离战斗力多远)、采办阶段
> 状态机(一个项目走到哪步)、扩散网络(一项技术流向了哪里)、
> 反制响应对(一件武器被什么抵消、多久抵消)。而"结构"是链条
> 自身的骨架:发明-采办-扩散-反制的四环闭合、S 曲线的组织
> 吸收参数、行动-反行动的螺旋。

---

## 0. 开篇:四张图撑起一门学科

任何一个技术评估部门都在同时维护四张图:一张**成熟度曲线**
(这项技术现在什么水平、天花板在哪),一张**采办里程碑表**
(哪个项目卡在哪一步),一张**扩散网络图**(这项技术还漏给了
谁),一张**反制对照表**(我们依赖的每件武器,对手的对策是
什么、成熟到几成)。00 章说战斗力是链条的产物——本章把链条
四环全部数据化:**曲线是纵轴,状态机是进度,网络是地理,
响应对是对手**。四张叠起来,就是"军事技术"作为数据对象的
完整形态。

## 1. 什么是"可构造"的:六类技术对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **技术成熟度曲线** | S 曲线(Logistic)×TRL 阶梯 | ✅ 高度可构造 | 斜率=组织吸收率(建制变量,非技术变量);天花板 K 的声明是立场 |
| **采办阶段模型** | 状态机(里程碑节点+转移条件) | ✅ 高度可构造(法规文档) | 里程碑延误口径;并行路线(曼哈顿式押注)使状态非唯一 |
| **扩散网络** | 有向图(节点=国家/厂商,边=转移渠道) | ✅ 可构造(转让记录+扩散观察) | 货架件时代"边"不可数——部件级扩散无台账 |
| **反制响应对** | (措施, 反制, 成熟延迟) 三元组集 | ⚠ 半可构造:框架可写,延迟估值难 | 响应延迟是情报评估不是数学(02 章时效眼) |
| **效能折旧曲线** | 效能(t)=性能×(1−反制成熟度(t)) | ⚠ 半可构造:形式可写,参数保密 | 95%→6% 类数字口径与争议强制标注(01 章热线三) |
| **"最优技术路线"** | 优化目标函数 | ❌ 不可构造 | 目标函数(威慑值/费效/产业政策)不可公度——只有组合前沿,没有最优解 |

**不可构造的**:技术路线的最终裁定(政治过程)、突袭时机的
判断(战略决策)、"革命还是演化"的定性(范式之争,革命论支的
辩论场而非计算题)。

### 1.5 四套模型的最小数据模式(动手者的 schema)

```yaml
# 技术成熟度曲线(一项军事技术的生命线)
tech_curve: {tech: str,                # 技术名(声明谱系!02 章代际歧义)
             trl_current: int,         # 当前就绪度 1-9
             ceiling_k: float,         # 潜力上限(声明值,是立场)
             absorption_r: float,      # 组织吸收率(训练/条令/编制改造速度)
             noise_band: [lo, hi],     # 年度预算/训练波动
             as_of: str, source_tier: T1..T6}

# 采办项目(状态机的一实例)
acq_program: {name: str,
              node: 立项|研制|试验|小批量|列装|退役,  # 里程碑状态
              parallel_routes: [str],  # 并行技术路线(曼哈顿押注的数据面)
              mandate_refs: [str],     # 授权条款(与军制学 schema 对齐)
              entered_node: {node: str, year: int}}   # 里程碑时刻

# 扩散网络(一项技术的流向)
diffusion_net: {nodes: [国家|厂商|非国家行为体],
                edges: [{from: str, to: str,
                         channel: 军贸|仿制|两用件|人才|公开文献,
                         year: int}]}   # 货架件时代 channel 退化,须声明

# 反制响应对(行动-反行动螺旋的一节)
counter_pair: {measure: str,            # 我方措施(武器/战法)
               counter: str,            # 对手反制(干扰/诱饵/分散…)
               response_delay: float,   # 对手响应延迟(年,情报评估值)
               maturity_rate: float,    # 反制成熟速度
               evidence: str}           # 来源(争议标注强制)}
```

注意三个设计决定:①`absorption_r` 把"组织吸收率"写进曲线的
**斜率参数**——技术潜力(ceiling_k)与吸收率分离,正是 00 章
"技术必要而不充分"的 schema 化;②`counter_pair.response_delay`
显式携带延迟估计与证据标签——反制窗口可量化,但延迟估值是
情报评估不是数学(04 章边界);③扩散网络的 `channel` 在两用件
时代退化为不可数——**这不是数据的缺陷,是时代的结构性质**
(00 章反直觉三)。

## 2. 骨架一:S 曲线的组织参数(00 章红线的定量形式)

- 采办扩散的标准形状是 Logistic 曲线:**y(t)=K/(1+A·e^(−rt))**,
  其中 K=技术潜力,r=组织吸收率——**决定曲线形状的不是技术
  (它只定 K),是组织(它定 r)**:训练体系、条令修订周期、
  编制改造速度
- 历史标定:七纪元滞后列(1-107 年,[军事史家族](../讲透军事史/00-体系结构.md)
  实测)等价于 r 的历史变化范围——战时危机压缩吸收期
  (装甲纪元 1 年),和平惯性拉长(火药纪元 107 年)
- 战斗力形成时刻 T*(部署量达 K 的九成)对 r 一阶敏感、对 K
  不敏感:**同样的潜力,吸收率差数倍,形成时间差数十年**
  ——家族实验的全部断言都长在这条敏感性上(04 章走廊一)

## 3. 骨架二:采办状态机与并行押注

- 阶段转移(立项→研制→试验→列装)不是自动流:每个转移条件
  是**评审决策**——状态机的合法性条件(02 章底线一致性) +
  决策的不可计算性(03 章不可构造清单)并存
- **并行路线**是曼哈顿范式的数据面:状态机的"一个项目多路线
  同时在研"结构(1940 年代的冗余押注,今天的中标组合评审)——
  用工程冗余买科学确定性(00 章美之时刻②)
- 里程碑表与[军制学采办组合 schema](../讲透军制学/03-可构造与结构.md)
  对齐:军制学管预算流(钱怎么走),本家族管技术状态(技术
  走到哪)——同一状态机的两个投影

## 4. 骨架三:扩散网络与反制响应对

- 扩散的边类型学:军贸(可控)/仿制(半可控)/两用件(不可控)/
  人才流动/公开文献——**管控难度沿此序递增**,而两用件恰是
  当代主流(01 章热线一),这解释了反扩散研究为何转向部件与
  知识层
- 反制响应对的螺旋结构:每对 (措施, 反制) 成熟后自动生成
  "反-反制"需求(下一代措施)——技术史由此呈**螺旋**而非
  单线;冷战核军备竞赛是其制度化的极端形态(00 章节点四)
- **"使用即正常化"的窗口代数**:窗口 W ≈ 响应延迟 D + 反制
  成熟期——使用事件同时启动对手的(侦察→仿制→反制)三条钟,
  三钟皆窗口的减函数(01 章热线二;家族实验把 W 做成 D 的
  可测函数)

## 5. 从结构到评估:这套骨架买到了什么

- S 曲线 → "还差几年形成战斗力"的换算器(吸收率敏感性)
- 状态机 → 采办进度的合法性与并行押注的可审计性
- 扩散网络 → 反扩散的边类型分诊(可控性分级)
- 响应对 → 红利窗口的倒计时表(效能折旧的日历)

## 6. 构造合法性清单(动手前三问)

把任何军事技术材料变成数据之前,先过三问——本家族的
"类型检查":

1. **口径分层了吗**:性能数字声明了宣称/实测/兑现哪一层?
   效能断言携带对抗条件与日期了吗?(02 章三层眼+时效眼)
2. **组织参数标了吗**:曲线的斜率参数(吸收率)从哪来——
   建制评估还是拍脑袋?潜力上限 K 声明为立场了吗?
3. **争议标了吗**:反制延迟、效能折旧这类保密且带宣传偏差的
   量,带来源与争议标注了吗?(01 章热线三的纪律)

三问全过,数据才获得进入 [04 章走廊](04-军事技术转代码.md)的
资格。**军事技术计算的第一特征不是算法,是口径、组织参数与
争议标注的入库纪律**——这与[军事史家族](../讲透军事史/03-可构造与结构.md)
的"证据等级入库"同宗:史家入库证据级,本家族入库口径与
吸收参数。

## 📌 收束

可构造的是**四套模型**(曲线/状态机/网络/响应对),不可构造
的是**路线裁定与革命定性**;结构不是装饰——S 曲线的组织参数
是滞后列的定量化身,响应对是军备竞赛的最小单元。下一章把
四套模型接上代码:[04-军事技术转代码](04-军事技术转代码.md)。

**🧠 认知升维**:

- **斜率眼**:看扩散曲线先看斜率从哪来——潜力是技术的,
  斜率是组织的,混淆两者就混淆了这门学科
- **边型眼**:扩散问题先分边(军贸/仿制/两用件/人才/文献)
  ——管控政策只有对上边型才有效
- **螺旋眼**:任何"一劳永逸"的技术优势断言都漏了反制项
  ——措施-反制-反反制,没有终点站
- **入库眼**:口径>算法——军事技术数据的合法性先于一切
  计算
