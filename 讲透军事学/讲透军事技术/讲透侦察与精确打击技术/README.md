# 讲透侦察与精确打击技术 · 杀伤链的技术簇(自定主干支)

> **这支负责的问题**:侦察-决策-打击如何被技术焊成闭环——ISR
> (情报/监视/侦察)、远程精确打击、无人系统不是三件武器,
> 是**同一条杀伤链的三个工位**。一句钉住:**道丁系统以来的
> 全部秘密只有一条——器件对等时,整合决定胜负;而当代的新变量
> 是:对手的反制也在打击同一条链的每一节。**
> 支宪法(**自定支,GB/T 83065 无三级明细**,据宇宙 README 惯例
> 设自定主干支)。家族:[讲透军事技术](../README.md)。

## 诞生(谁/何时)

- 1940:道丁系统——雷达哨+观测员+过滤室+扇区站,第一条
  机器辅助杀伤链(器件对等,系统制胜的原型)
- 1944-1945:V-1 制导武器与无线电近炸引信——精确与自动化的
  早期两支
- 1970s-1991:制导弹药+卫星导航+数据链成熟;海湾战争(1991)
  精确弹药大规模登台(占投弹量约一成,通说)——侦察-打击
  复合体从苏联设想变为现实
- 2001-2020:武装无人机首用(2001)到纳卡战争(2020)——
  "集中即暴露"的透明战场成立([军事史七纪元](../../讲透军事史/00-体系结构.md)
  无人纪元锚,互指不复制)
- 2022-:[Military Review]《Unmanned Aircraft and the Revolution
  in Operational Warfare》(2025-07/08):近持续侦察/打击环境
  成为战役级命题;电子战反制使精确效能重估(natstrat 争议数据,
  来源与争议标注)【检索校准 2026-09-07】

## ✨ 这支最美的一个事实

**道丁系统的胜利**:1940 年英德都有雷达,英国赢在把器件织进
"探测-过滤-指挥-拦截"的信息流水线——战斗力长在系统里。
八十年后的一切 ISR 体系、侦察-打击闭环、数据链工程,都在解
这道题的变奏;而当代加的下半句同样漂亮:**对手的反制不再瞄准
器件,瞄准链条本身**(干扰链节、欺骗链路)——系统化既是战力
的来源,也是脆弱性的来源。

## 假设与依赖

闭环可分解假设(杀伤链可分节度量与优化——节间接口损耗常被
低估);透明度单调假设(侦察越透明战场越"单向"——欺骗与电磁
管控持续反证);依赖[军队指挥学](../../讲透军队指挥学/README.md)
(C2 处置端)、[战役学](../../讲透战役学/README.md)(环境约束的
用法侧)、家族 03 章 counter_pair(反制数据面)。
