## 诞生(谁/何时)

- 史学侧前史:Roberts 军事革命命题(1955/56,1560-1660 火器-
  战术-规模连锁)→ Parker 棱堡修正(1988:规模膨胀的真正推手
  是攻城成本)——"革命"史学的第一轮
- 苏联侧源流:奥加尔科夫等 1980 年代"军事技术革命"/侦察-打击
  复合体设想——技术侧命名者
- 美国侧大成:1991 海湾战争展示精确战后,RMA 话语机构化
  (Krepinevich 1994 报告、网络中心战论说 1998、转型纲领 2000s)
- 清算与重开:Biddle《军事力量》(2004)现代体系论——决定结局
  的是兵力运用体系不是技术代差;2020 年代"小型智能廉价"与
  无人系统再启新轮([Marine Corps Gazette]《What Military
  Revolution?》为代表的技术中心观批判,方向锚)

## ✨ 这支最美的一个事实

**革命判据的三曲线同跳**:一条曲线跳(技术出现)叫发明,两条跳
(技术+战术)叫扩散,**三条同跳(技术+战术+组织规模/结构)才配
叫革命**——Parker 用棱堡证明连"火药革命"都主要不是火药的功劳。
这个判据把一切"新技术将改变战争"的新闻稿挡在门外:先问
另外两条曲线在哪。

## 假设与依赖

可分离假设(技术效应与组织效应可分——滞后列持续拆台);革命
作为离散事件假设(间断平衡 vs 连续演化的范式之争);依赖军事史
七纪元滞后列(实证地基)、家族 03 章 S 曲线模型(吸收率的参数化)、
[军事理论](../../讲透军事理论/README.md)(战争形态概念)。
