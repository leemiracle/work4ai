> **这支负责的问题**:技术怎么从实验室走到部队、再走到别人的
> 部队——需求生成、研制试验、采办管理、扩散与转移的管道全程。
> 一句钉住:**管道的每一节阀门都不是技术阀门而是组织阀门
> ——曼哈顿工程证明管道可以三年跑通,军工复合体证明管道可以
> 膨胀成制度,货架件时代证明管道的入口已搬进市场。**
> 支宪法(**自定支,GB/T 83065 无三级明细**,据宇宙 README 惯例
> 设自定主干支)。家族:[讲透军事技术](../README.md)。

## 诞生(谁/何时)

- 前近代:军器监-武库体系(中国唐代起建制,学科史实),
  欧洲王室军械局——采购是宫廷行政
- 1790s-1914:国家兵工厂与互换性零件("美国制造体系")——
  军事需求孵化现代大规模生产
- 1942-1945:曼哈顿工程——并行押注+系统整合的大科学管理
  范式(现代研发工程管理的出生证)
- 冷战:PPBS 接入预算(1960s)、系统分析与里程碑评审学科化;
  艾森豪威尔 1961"军工复合体"命名(政治经济结构自觉)
- 当代:两用技术/货架件改写管道入口(发明侧市场化),
  [IDA/DMI]采办系统评估以冲突性法定授权框架重评绩效
  【检索校准 2026-09-07】

## ✨ 这支最美的一个事实

**曼哈顿的并行押注**:物理确定性不足时,格罗夫斯同时开工三条
铀浓缩路线、两种起爆方案——**用工程冗余买科学确定性**。它
反直觉地证明:最快的技术管道不是最聪明的单选,而是敢于并行的
组合;此后的中标组合评审、多路线研制,全是这次押注的制度后代。
