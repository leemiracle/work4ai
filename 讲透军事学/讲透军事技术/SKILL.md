# 军事技术思维技能卡(GB/T 83065 · 讲透军事技术家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「新技术会不会**革命战争**/RMA 争论什么」——革命论之辩
- 「一款武器**从发明到战斗力**要几步、卡在哪」——四环链条分诊
- 「为什么**效能数字互相打架**(95% vs 6%)」——口径与反制依赖
- 「新武器**用了一次之后**会发生什么」——使用即正常化
- 「**TRL 几级/第几代/货架件**这些词什么意思」——成熟度语言
- 「技术**扩散**为什么防不住」——两用件时代的网络结构
- 「无人机/精确弹药/ISR **体系**怎么回事」——技术簇视角
- 「扩散曲线/里程碑/反制窗口**怎么变成数据**」——schema 级需求

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **链条眼** | 任何武器问题先定位四环:发明≠采办≠列装≠战斗力——四环的新闻价值完全不同 |
| **吸收眼** | 看到"技术改变战争",先问组织吸收年(训练/条令/编制改了没)——滞后列是解毒剂 |
| **反制眼** | 一切效能数字先问对手反制成熟度——靶场指标是期初值,战场是折旧后的净值 |
| **窗口眼** | 武器列装之日起红利窗口开始倒数——效能报告第一栏是窗口余量,不是峰值 |
| **系统眼** | 器件对等时看整合(道丁系统标尺)——战斗力长在系统里,不长在名片参数里 |
| **三层眼** | 性能数字分三层:宣称值(厂商)/实测值(靶场)/兑现值(对抗环境)——三层混说是宣传 |
| **事件眼** | 扩散的单位是使用事件不是转让合同——用了才算广告 |
| **斜率眼** | 扩散曲线的潜力 K 是技术的,斜率 r 是组织的——混淆两者就混淆了整门学科 |

## 3. 工具箱(何时用什么)

- **四环链条**:发明-采办-扩散-反制——一切军事技术问题先在此
  坐标上分诊(00 章)
- **学科史五节点**:工匠手艺→工业标准化→大科学(曼哈顿并行
  押注)→军工复合体→两用市场——"技术生产的组织化"坐标
- **三堂课案例**:坦克十六年漂流(组织吸收差)/雷达链(发明-
  反隐蔽竞赛)/曼哈顿(工程管理作为武器)
- **四套 schema**(03 章):tech_curve(带 absorption_r)/
  acq_program(状态机+并行路线)/diffusion_net(边类型学)/
  counter_pair(带 response_delay 与争议标注)
- **扩散-反制窗口模型**(家族实验
  [experiments/adoption_scurve.py](experiments/adoption_scurve.py)):
  同潜力下吸收率决定形成时间差;窗口 W≈响应延迟 D+反制成熟期
- **效能三层口径**:宣称/实测/兑现——引用任何性能数字先声明口径
- **术语对译表**(02 章):RMA≠军事革命;ISR 是体系不是三件事;
  高超音速须 Ma5+且机动弹道;忠诚僚机≠CCA 正名

## 4. 常见误区与禁忌

- ❌ **效能直读**:拿靶场命中概率当战场效能——先乘反制折旧,
  再带口径与日期(95%→6% 类数字必须带来源与争议标注)
- ❌ **技术决定论复发**:看到新武器就预言战争改写——七纪元
  滞后列(1-107 年)是历史清算;Biddle 现代体系论是通说制衡
- ❌ **代际拜物**:跨体系比"第 N 代"——代际是各家谱系自述,
  比较先问"按谁的谱系、量什么口径"
- ❌ **把窗口当永恒**:任何"领先一代"断言都漏了反制项——
  措施-反制-反反制,没有终点站
- ❌ **廉价幻觉**:商用件只让发明便宜,体系与吸收的账单一件
  不少——吸收侧是老账单
- ❌ **敏感红线**:涉现实武器系统只述公开文献的技术原理与
  学理争论,不做效能断言、不涉任何国家军备决策;在研项目
  (高超音速/忠诚僚机/定向能)按方向锚处理,待核实
