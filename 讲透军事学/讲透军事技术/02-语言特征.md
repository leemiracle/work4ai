# 02 · 语言特征——技术军语:成熟度、代际与效能的语法

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)**。
> **本质一句话**:军事技术说的是一种**成熟度语言**——它的一切
> 词汇都在回答同一个问题:"这件事离战斗力还有多远"。TRL 说
> 研发离列装多远,代际说它比对手旧几轮,货架产品说它离市场
> 多近,效能说它在对手反制前值多少。听懂这门语言的手艺,就是
> 分清每个数字的**口径与时刻**——靶场的 95% 与战场的 6%,
> 说的不是同一门语言。

---

## 0. 开篇:同一枚弹的三个数字

📖 **故事框:三个场合的三个"命中率"(教学场景,通说化)**。
同一型精确弹药,航展展板写着"命中概率 0.95"(试验室与靶场
条件下,无对抗);试验通报写着"十发九中"(指定靶标,指定
射程,气象合格);战报写着"多枚被干扰偏离"(电磁对抗环境,
对手电子战成熟)。**三个数字都诚实,但它们说的是三件事**:
属性(设计性能)、表现(受控条件实测)、效果(对抗环境兑现)。
军事技术学的一切语言纠纷,都源于把这三层压成一个词"效能"
(场景为通说化教学情境,非任何具体武器的事实陈述)。

## 1. 表达力:技术军语能说什么(三栏之一)

**成熟度语言能说的**:

| 能力 | 例 |
|------|-----|
| 技术就绪度 | "TRL 6"(relevant environment 下的系统演示)——从原理(1)到实战验证(9)的九级阶梯 |
| 代际 | "第三代坦克""六代机"——与对手/前代的相对刻度(见 2.5 歧义一) |
| 货架产品 | "COTS 部件"——商用现成件:说明技术来源在民用市场,采办逻辑从研制变集成 |
| 原型/列装 | "技术验证机→工程样机→小批量→列装"——离部队的台阶数 |
| 研制状态 | "在试/在研/立项"——与 00 章四环链条的采办环对齐(03 章状态机) |

**能力语言能说的**(与[军制学 02 章](../讲透军制学/02-语言特征.md)
的采办语言互链):

| 能力 | 例 |
|------|-----|
| 能力需求 | "能在 X 条件下完成 Y 任务"——买能力不买器物(两家族共享的需求语法) |
| 体系贡献 | "杀伤链闭环时间"——单件性能升格为体系指标(道丁系统的语言化) |
| 反制鲁棒性 | "抗干扰条件下的命中概率"——把对手反制写进效能口径(热线三的词汇层) |

**技术军语不能说的**:

- **不能说"值不值"**:射程精度说得清,费效比说不清——那是
  03/04 章(账本+模型)的工作
- **不能说"组织跟没跟上"**:TRL 9 是器物的终点,不是战斗力的
  终点——条令/训练/编制的吸收进度不在技术词汇表里(00 章红线)
- **不能说"将来反制后"**:一切效能断言自带"截至对手反制成熟
  前"的隐藏时效(窗口眼,01 章)

## 2. 逻辑性质:技术断言的约束(三栏之二)

| 性质 | 军事技术断言 | 备注 |
|------|-------------|------|
| "真值" | 三层:宣称值(厂商)/实测值(靶场)/兑现值(对抗环境) | 引用任何性能数字必须声明哪层——三层混用是本学科最大伪证源 |
| 底线一致性 | 技术状态断言不能同时"在研"又"列装";TRL 单调(不回退,除非降级评审) | 03 章采办状态机的合法性条件 |
| 完备性 | 永不完备——反制环境的不可穷举使"最终效能"原则上不可定 | 效能=对手反制成熟度的函数(00 章假设三) |
| 时效性 | 一切效能断言携带"对手反制状态"与日期 | "95%→6%"争议案例的语法教训(01 章热线三) |
| 可比性 | 跨体系比较只比功能口径,不比代际标签 | "三代半"对"四代"是营销语言不是测量语言(2.5 歧义一) |
| 反事实 | "若无电子战则……"可用但须显式标记 | 反制折旧推演=机器化反事实(04 章边界,承[军事史家族](../讲透军事史/02-语言特征.md)T6 纪律) |

### 2.5 技术语言的三个系统性歧义(读新闻者必检)

1. **代际歧义**:"第 N 代"没有国际标准计量——代际划分是各家
   自述谱系(战斗机的"代"与坦克的"代"不同源),跨军种/跨国
   比较时"代差"是约数;凡代际断言先问"按谁的谱系"
2. **效能口径歧义**:"命中概率"的分母(发射数?进入末段数?)
   与条件(无对抗?光电/电磁对抗?)不声明,数字之间禁止直接
   比较——95% 与 6% 的落差一半在口径,一半在环境(00 章开篇
   故事框的正规化)
3. **成熟度歧义**:TRL 9(实战验证)≠规模化列装≠形成战斗力
   ——三级跳跃各有组织门槛;"技术成熟"到"战斗力"之间的距离
   就是本家族的全部主题(滞后列的语言面)

## 3. 规范化程度:军语、标准与对译(三栏之三)

- **技术就绪度标准**:TRL 九级量表源自 NASA/DoD 评估惯例,
  各国采办体系多有等效采用(建制史实,中性引证);使用时
  注明所依体系
- **试验与鉴定规范**:靶场口径(标准靶/标准气象/无对抗)与
  作战试验口径(代表性部队/对抗环境)分离立规——"两口径"
  是效能语言的法定语法
- **军语标准化**:中文军语有专门规范辞书;多国体系有
  NATO 标准化术语对照(与[军事史家族 02 章](../讲透军事史/02-语言特征.md)
  同款纪律:跨体系写作声明所用军语体系)
- **数字规范**:性能数字一律带(口径,条件,日期)三元组;
  涉外军在研项目按公开文献通说,不做效能断言(敏感纪律的
  语法化)

**术语规范与对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 军事事务革命 | Revolution in Military Affairs (RMA) | 勿译"军事革命"了事——RMA 特指 1990s 信息中心话语;"军事革命"(military revolution)是史学界 1560-1660 命题,两个词两族文献 |
| 情报、监视与侦察 | Intelligence, Surveillance & Reconnaissance (ISR) | 是一个体系概念不是三件事并列;单译"侦察"丢掉持续性与情报闭环 |
| 侦察-打击复合体 | reconnaissance-strike complex | 苏联军事理论源词(奥加尔科夫线);与西方 RMA 话语同源异流,译名保留复合体 |
| 协同作战飞机 | Collaborative Combat Aircraft (CCA) | "忠诚僚机"(loyal wingman)是概念化俗称,CCA 是项目类别词——两者不可互相当正式术语 |
| 定向能 | directed energy (DE) | 上位概念(激光/微波/粒子束);与"激光武器"不能互换——微波定向能的机理与激光完全不同 |
| 高超音速 | hypersonic | 严格指 Ma5+ **且**具备机动/滑翔弹道;仅速度达标的不算(弹道导弹再入速度早就超 Ma5)——媒体误用重灾区 |
| 助推-滑翔 | boost-glide | "匕首"(Kinzhal)类系统的弹道类型;与吸气式高超音速巡航弹(HCM)是两条技术路线,勿混 |
| 技术就绪度 | Technology Readiness Level (TRL) | readiness 译"就绪"不译"准备度";TRL 是量表不是状态 |
| 商用现货(部件) | commercial off-the-shelf (COTS) | "货架产品"是意译;军事语境强调采购逻辑改变(研制→集成) |
| 技术突袭 | technological surprise | 与战略突袭(strategic surprise)分层;技术突袭的窗口由双方吸收率之差决定(00 章) |
| 使用即正常化 | normalization through use | 军控研究术语:使用行为本身降低禁忌成本、加速扩散——勿望文生义为"习惯就好" |
| 成本强加 | cost imposition | 采办战略术语:让对手防御成本高于己方进攻成本;不是"涨价" |
| 电子战 | electronic warfare (EW) | 含干扰/欺骗/防护三面;中文口语常窄化为"干扰" |
| 杀伤链 | kill chain (F2T2EA 等变体) | 从发现到评估的闭环流程;译"猎杀链"带情感色彩,学科内用"杀伤链" |
| 军工复合体 | military-industrial complex | 艾森豪威尔 1961 告别演说出处词;是分析概念不是贬义标签(中性使用) |
| 反制 | countermeasure | 动词名词两用;与"对抗措施"同义,学科内统一用"反制" |

## 📌 收束

军事技术的语言=**成熟度语法+三层效能口径+时效标签**:每个词
都在回答"离战斗力多远",每个数字都必须携带口径(宣称/实测/
兑现)、条件(有无对抗)与日期。下一章把这套语言压成数据——
成熟度曲线、采办里程碑、扩散网络怎么变成可构造对象:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **三层眼**:性能数字先分层——宣称值/实测值/兑现值,三层
  混说的报道直接降级为宣传材料
- **代际眼**:代际是谱系自述不是国际单位——比较之前先问
  "按谁的谱系、量什么口径"
- **时效眼**:效能断言自带保质期(对手反制状态+日期)——
  过期指标按折旧处理
- **距离眼**:TRL 9 到战斗力之间的距离就是这门学科本身
  ——看到"技术成熟"先问组织跟没跟上
