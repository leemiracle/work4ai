# 讲透战场应激与士气 · 人在战斗压力下的崩溃与养护(自定主干支)

> **这支负责的问题**:战斗压力如何累积成崩溃,士气如何被测量与维持。
> 一句钉住:**崩溃不是意外,是剂量——每个人都有崩溃点;
> 这门分支就是战争里的剂量管理学。**
> 支宪法(GB/T 83020 无三级明细,本支为**自定主干支**,声明见
> [家族 README](../README.md)〇)。

## 诞生(谁/何时)

- 1915,迈尔斯《柳叶刀》命名**弹震症(shell shock)**——命名即
  病因之争(器质 vs 心理);里弗斯(Rivers)的克雷格洛哈特医院
  开创谈话治疗;军方"装病"处罚逼出"想病还是病了"之问
- 1917,萨蒙(Salmon)考察协约国,归纳 **PIE 三原则**(就近/
  即时/期望恢复)——1946 年阿佩尔与毕比(Appel & Beebe)以
  "每个人都有崩溃点"(聚合战斗日 200-240 天,通说)重述,
  确立**前线处置**建制
- 越战老兵运动(沙坦/利夫顿/哈利)推动 **PTSD 于 1980 年入 DSM-III**——病因第一次写进事件而非体质
- 2001 后,COSC(战斗与行动应激控制)条令化,分层预防成为默认建制

## 核心问题

| 问题 | 状态 |
|------|------|
| 崩溃的剂量-反应曲线(战斗日→减员) | ✅ 大体成立(队列级) |
| PIE/前线处置优于后送 | ✅ 历史与准实验反复支持 |
| 心理弹性能否训练(效应量) | ⚔️ 悬而未决(01 章证据门) |
| 道德损伤是否独立诊断 | ⚔️ 悬而未决(DSM 未单列) |
| 个体崩溃点的可预测性 | ❌ 只有分布,没有个体(04 章裂缝③) |

## 这支最美的一个事实

**1917 年的 PIE 三原则,今天仍是全球心理急救(PFA)的默认
设置——武器换了四代,人的崩溃与养护没换。**

## 假设与依赖

剂量学假设(压力可累积、可计量)+阈值假设(崩溃点是分布);
依赖量表与流行病学方法;主结局指标是**归队率**而非症状分
——它把临床结局翻译成建制语言。
