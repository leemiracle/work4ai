# 讲透军事人员选拔与评估 · 千万人次的选拔流水线(自定主干支)

> **这支负责的问题**:把合适的人放进生死的岗位——测什么、怎么算分、
> 切点画在哪。一句钉住:**效度每提高一点,省下的是训练成本与生命;
> 切点每移动一格,改写的是两拨人的人生。**
> 支宪法(GB/T 83020 无三级明细,本支为**自定主干支**,声明见
> [家族 README](../README.md)〇)。

## 诞生(谁/何时)

- 1917,耶基斯(Yerkes)主持**陆军甲乙种测验**(Army Alpha/Beta,
  约 175 万人次)——心理测量第一次服务大规模选拔;同一位耶基斯
  1908 年与多德森给出倒U定律:本家族两条主线出自一人
- 1940-1945,**陆军普通分类测验(AGCT)**施测约 1200 万人次(通说):
  一小时作答→百分位→岗位;**战略情报局 OSS 评估**(1943-45)另辟
  情境测验(压力面谈/无领导小组),是现代评价中心的前身
- 战后谱系延续为 ASVAB 至今;学界由施密特与亨特
  (Schmidt & Hunter 1998)元分析确立**一般心理能力(GMA)**
  对训练与绩效的预测地位

## 核心问题

| 问题 | 状态 |
|------|------|
| GMA 预测训练/岗位绩效 | ✅ 元分析稳固 |
| 情境测验对领导潜能的增量效度 | 🟡 有证据,成本高 |
| 人格/诚信等软变量的增量 | 🟡 部分成立 |
| 切点设置的政策学(误判两向不对称) | ⚔️ 价值问题,非技术问题 |
| 算法选拔的公平性与可解释性 | ⚔️ 前沿(04 章走廊③) |

## 这支最美的一个事实

**一张纸笔测验在五年里给约一千二百万人定了岗位——社会科学史上
最大规模的一次"分数改变命运"。**

## 假设与依赖

特质稳定性假设(今天测的与明天要用的同构)+岗位分析可靠+
效标可测;心理测量学为工具底座;明码标价的代价:全距限制、
切点二分、一次测验定终身的简化(家族 03 章✨③的还债工程)。
