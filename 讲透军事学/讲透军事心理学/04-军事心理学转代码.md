# 04 · 军事心理学转代码:可计算的走廊与不可编译的人

> **本章回答五问之五(家族层):这个家族的问题怎么变成 code 问题?**
> **本质一句话**:军事心理学的可计算核心是三种结构——**曲线
> (倒U)、队列(崩溃点)、阈值(切点)全部可算且算得准**;
> 但射击率的测量、道德叙事的语义、韧性的训练效应、个体的
> 崩溃预测住在代码外面。三件套:可机械化边界/六条代码走廊/
> 工程师落点,外加裂缝清单。

📖 **开篇故事:靶纸换人形**。1947 年马歇尔的"15-25% 射击率"
命题(02 章)被美军当作训练诊断接收:靶纸从圆环换成人形剪影、
增加条件反射式快速射击、伴随冲击训练——据后续战争的报告,
射击率大幅上升(传播中最常被引用的是朝鲜与越南的递增序列,
经格罗斯曼《On Killing》普及)。**但故事的骨架是个认识论奇案**:
基线数字(15-25%)的原始笔记下落不明(Spiller 1988),档案
复核给出高得多的估计(Engen 2011)——也就是说,**一项可能
有效的干预,恰好建立在有争议的数据上;而你再也无法用同一份
数据去证明或证伪它**。这是"军事心理学转代码"的第一课:
模型输出永远是**命题的化身**——代码会忠实复现文献命题的
逻辑,但对命题本身的真伪保持沉默,并且诚实地把它写在注释里。

## 一、可机械化边界(三件套之一)

| 任务 | 可机械化? | 说明 |
|------|-----------|------|
| 倒U曲线数值化(峰值/难度交互) | ✅ 全自动 | 解析+网格互验——走廊① |
| 崩溃队列模拟(剂量→减员→政策) | ✅ 全自动 | 蒙特卡洛+参数扫描——走廊② |
| 选拔切点/基础率/效度三元组 | ✅ 全自动 | 四格表代数——走廊③ |
| 量表计分与信度(条目→分→α→切点) | ✅ 全自动 | 纯算术——走廊④ |
| 分层预防配置(三层人群流转) | ✅ 全自动 | 马尔可夫链——走廊⑤ |
| 照护者损耗(同情疲劳续航) | ✅ 全自动 | 马尔可夫链——走廊⑥ |
| 量表构造(因子分析/效度验证) | 🟡 半自动 | numpy/scipy 可算,但**解释与条目取舍必须人来** |
| 射击率类行为测量 | ❌ 为主不可 | 观察/访谈方法学,数据本身有争议(02 章⑥) |
| 道德损伤的叙事语义 | ❌ | 条目可计分,叙事不可编译(裂缝②) |
| 韧性训练效应推断 | ❌ | 因果在 RCT,不在模型;模型只能做功效预设演算 |
| 个体何时崩溃预测 | ❌ | 只有分布,没有个体(裂缝③) |

## 二、代码走廊总表(三件套之二)

| 走廊 | 问题类型→形态→栈 | 承诺强度 |
|------|-----------------|---------|
| ① 倒U走廊 | "多少压力出最佳绩效" → P(A;τ)=A·e^(−β(τ)A) → 纯 python(实验一) | 算得准(函数已知) |
| ② 队列走廊 | "心理减员有多少、政策怎么选" → 蒙特卡洛队列+政策参数 → 纯 python(实验二) | 命题化身(参数=文献通说) |
| ③ 选拔走廊 | "切点放哪" → 效度×基础率×切点四格表 → 纯 python | 算得准(给定效度) |
| ④ 量表走廊 | "叙事→分数" → 条目计分+α+切点 → 纯 python | 算得准(给定条目) |
| ⑤ 分层走廊 | "三层预防怎么配资源" → 马尔可夫转移+成本 → 纯 python | 情景级 |
| ⑥ 照护走廊 | "照护者多久烧干" → 损耗/恢复双态链 → 纯 python | 情景级 |

### 走廊①:倒U的数值化(实验一)

```python
# P(A; tau) = A * exp(-beta(tau) * A);峰值在 A* = 1/beta(tau)
# 规律一(倒U):先升后降;规律二(难度交互):任务越复杂,最优唤醒越低
def performance(A, tau):
    b = 0.4 + 1.2 * tau          # 复杂度→衰减率
    return A * math.exp(-b * A)
# 亲测:过度唤醒(高A)对复杂任务的"相对损失"远大于简单任务
# ——1908 年小鼠电击实验的参数化转世
```

工程要点:数值峰值与解析峰值互验(网格分辨率容差);
"最优唤醒随复杂度左移"写成断言,不是画图题。

### 走廊②:崩溃点队列(实验二,本章主样本)

```python
# 每个士兵:崩溃点 ~ N(220, 40) 战斗日(Appel-Beebe 1946 通说)
# 日剂量 = 1.30 - 0.60*cohesion - 0.30*leadership(凝聚力/领导信任=保护因子)
# 政策:forward(PIE 前线处置,归队率0.70) vs evac(后送,0.20)
# 输出:减员结构(episodes/evac/wounded)、首次崩溃日、归队-慢性分岔
```

**三个学科现场**(实验专门演示):

1. **前送把慢性损失换成可重复的急性发作**:PIE 政策下后送
   (慢性)人数大减,但归队者会再次接近崩溃——总发作次数
   反而可能上升;账要分开记
2. **保护因子改变的是剂量,不是命运**:凝聚力从 0.2 到 0.8,
   首次崩溃日均显著后移——但分布的尾巴仍然存在,"没人崩溃"
   不是一个可达到的政策目标
3. **心理减员与战斗减员同场记账**:两条减员流共享同一个"在队"
   状态——这是 COSC 条令把心理减员纳入卫勤统计的代码倒影

### 走廊④⑤⑥:三条工程化走廊

- **量表走廊**:条目分→加权→总分→α 信度→切点;EMIS 式骨架
  二十行。要点:α 只管内部一致,**不担保效度**——代码注释
  必须写明(03 章刚性一)
- **分层走廊**:三人群(普遍/选择/指向)马尔可夫流转,
  每层挂成本与转化率;Cooper 2024 的"证据账本"在代码里就是
  每条转移边的证据档位标注(有 RCT 的边才能上生产)
- **照护走廊**:照护者两态链(功能态/损耗态)+恢复事件
  (督导/轮换);"照护者的照护"(01 章方向五)的续航演算

## 三、工程师落点(三件套之三;性能工程视角)

1. **蒙特卡洛的规模与敏感性**:万级 agent×数百天是毫秒-秒级,
   算力从不是瓶颈——**敏感性分析才是义务**:每个参数
   (崩溃点均值/剂量系数/归队率)单独 ±20% 扫一遍,
   结论随参数翻转的模型没有资格进决策会
2. **参数的来源档位必须显式**:本家族实验每个参数注明出处与
   档位(通说/命题/有争议)——军事心理数据的两难:真实数据
   稀缺且涉密,公开文献的数字常带方法论争议(马歇尔课);
   **参数表就是模型的质量声明**,不标注的参数等于伪造精度
3. **心理数据是高敏数据**:量表分、崩溃史、道德损伤自陈一旦
   入库即人事数据——做二次分析先过伦理与最小化两关;
   选拔类模型从 CI 到部署之间隔着法务与伦理审查,不是
   MLOps 的一环
4. **与 LLM 的接口**:叙事筛查辅助(转录→条目预判→人审)
   可用且必须人审;自陈量表的核心地位不可替代——LLM 无法
   替士兵回答"过去一个月你多久被噩梦惊醒",只能替文员
   整理他已经说出的部分

## 四、裂缝清单(原则上/工程上的不可转)

1. **自陈不可绕过**:被试知道自己在被打分——测量即干预
   (装好/装坏的动机随利害变化);任何"客观化"算法
   (语音/文本情感)都要回答:它测的是状态还是表演
2. **道德叙事不可编译**:EMIS-17 量出 17 个刻度,量不出
   "那天夜里他对我说的那句话";条目采样必有剩余(02 章)——
   分数用于分流,叙事用于理解,系统设计必须给两者各留接口
3. **个体预测的极限**:崩溃点、患病率都是人群命题(Rose
   预防悖论):预防政策在人群层有效,在个体层常常"多数人
   白付费、少数人被误标"——把人群模型翻成个体判决,
   是类别错误,不是工程优化问题
4. **干预效应的因果机器**:训练有没有效,因果证据只在 RCT
   及其元分析里(01 章证据门);模拟可以做事前功效演算,
   不能做事后效果宣布——**模型不产生证据,只组织证据**
5. **目标函数的伦理预设**:模型优化"战斗力"还是"人的
   福祉"?两者平时同向、战时可能分岔(00 章双重忠诚)——
   这个选择写在需求文档里,不写在代码里,**这是最后的诚实**

## ✍️ 练习

1. **政策分岔复现**:在实验二把 forward 归队率从 0.70 改成
   0.55/0.85,观察 evac 与 episodes 的双指标变化——找出
   "慢性损失"与"发作次数"出现反向移动的参数区间,
   写一段给卫勤参谋的说明
2. **切点沙盘**:按走廊③自建四格表(r=0.4,基础率 40%,
   切点 30%→15%),算两个"录对率"与"漏才率"——给兵役
   局长写一句话备忘录:你要哪个数,理由是什么
3. **参数档案练习**:给实验二的五个参数各写一行"来源与
   档位"注释(通说/命题/有争议/自设)——数一数有几个
   "自设",这就是这个模型的可信度边界

## 📌 收束

军事心理学转代码的图景:**走廊①③④算得准(曲线/切点/量表
的代数),走廊②⑤⑥是命题化身的情景演算(队列/分层/照护);
裂缝在自陈、叙事、个体预测、因果证据、目标函数五处**。
选走廊先看承诺强度,过裂缝靠显式预设不靠信念。读完五章,
这支家族的地图已完整——回[家族 README](README.md)的
三支家族树挑下一站。

**🧠 认知升维**:
- **化身眼**:任何心理模拟的输出先问"它是哪条命题的化身"
  ——命题错,模型精确地错
- **双账眼**:干预评估永远分两本账(慢性损失/急性发作;
  人群收益/个体误标)——只报一本账的结论都在挑选读者
- **预设眼**:每个分流算法背后都站着一个没写进代码的目标
  函数——找出它,是审查任何"人的系统"的第一动作
