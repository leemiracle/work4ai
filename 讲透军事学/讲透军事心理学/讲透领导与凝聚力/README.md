# 讲透领导与凝聚力 · 小群体为何而战,领导为何是道德的守门人(自定主干支)

> **这支负责的问题**:士兵为何而战(初级群体),领导如何守护
> 或击穿他们的底线(**道德损伤 moral injury**)。
> 一句钉住:**士兵为战友而战;当被信任的领导背叛"什么是对的",
> 受伤的就是道德本身——领导既是士气的放大器,也是道德损伤的
> 疫苗或病原。**

## 诞生(谁/何时)

- 1947,马歇尔(S.L.A. Marshall)《Men Against Fire》:射击率命题
  (仅 15-25% 实际开火)与**初级群体**命题——数字后被质疑,引用
  须连同争议(Spiller 1988/Engen 2011;家族 02 章⑥)
- 1948,希尔斯与雅诺维茨(Shils & Janowitz)分析被俘德军:
  **战斗力残存于初级群体而非意识形态**
- 越战后,谢伊(Shay)《阿喀琉斯在越南》(1994)提出**背叛式
  道德损伤**:"被握有正当权威的人在高压情境中背叛了'什么是对的'"
- 2009,利茨(Litz)等给出操作化定义与修复路径;2010s-20s 量表化
  (EMIS-17/MISS-M)与非临床转向(家族 01 章方向四)

## 这支最美的一个事实

**士气最可靠的预测因子不是信念,而是"你的班长会不会背着你的
尸体回家"——初级群体先于主义。**
