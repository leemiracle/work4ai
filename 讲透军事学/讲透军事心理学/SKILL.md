# 军事心理学思维技能(GB/T 83020 · 讲透军事心理学家族的抽象层)

## ① 何时用此分支(问题特征触发词)

1. "压力大到什么程度会垮/最佳表现需要多少压力"——倒U、崩溃点
2. "士气/凝聚力怎么测、怎么带"——初级群体、凝聚力四格
3. "怎么选人/分数切点放哪"——效度、基础率、切点代数
4. "创伤/PTSD/道德损伤"——诊断判据、量表、PMIE
5. "韧性/抗压能不能练"——训练效应与证据分级
6. "心理减员有多少、政策怎么选"——队列模型、PIE 前送/后送
7. "照顾别人的人先垮了"——照护者损耗、同情疲劳
8. 需要判断"这个心理数字可信吗"(量表/抽样/幸存者偏差)

## ② 核心思维模式

- **剂量眼**:压力不是事件是累积量——先问"余额还有多少",
  再问"他行不行";崩溃是剂量学的,不是意志论的
- **阈值眼**:连续分布上找切点(崩溃点/选拔线/量表分界),
  并始终记住线是画的、人有分布——切点是价值选择
- **分层眼**:干预按人群分层投放(普遍/选择/指向),
  资源跟着风险走,而不是跟着嗓门走
- **纽带眼**:战斗力的最小单位不是个人是初级群体——
  士气问题先查纽带(横向任务信任/纵向领导信任),再查个人
- **承诺分层**:任何结论先标档——代数级(算得准)/
  命题化身级(参数=文献通说)/叙事级(不可比)——
  证据折扣各不相同
- **双账眼**:干预评估分两本账——慢性损失 vs 急性发作、
  人群收益 vs 个体误标;只报一本账的结论在挑读者

## ③ 工具箱(何时用什么)

| 工具 | 何时用 |
|------|--------|
| 倒U曲线 P(A;τ)=A·e^(−βτA) | 唤醒-绩效问题;峰值随任务复杂度左移(实验一) |
| 崩溃点队列(蒙特卡洛) | 减员测算/政策分岔(PIE 前送 vs 后送;实验二) |
| 四格表(效度×基础率×切点) | 选拔/筛检切点沙盘;录对率-漏才率交换 |
| 量表引擎(条目→α→切点) | 自陈数据计分;α 只担保一致性不担保效度 |
| 马尔可夫分层链 | 预防资源配置/照护者续航演算 |
| 凝聚力四格(Carron) | 士气诊断;道德损伤的入口定位(纵向信任格) |
| 效度证据分级(RCT 优先) | 判断"训练有没有效"类主张的可信度 |
| Thorndike 全距校正 | "测验不管用"的量程假象排查 |

## ④ 常见误区与禁忌

- **把倒U当万能曲线**:它只管唤醒-绩效的粗粒度关系;
  原始证据(1908)支持的是"难度×强度交互",不是一条
  普适最优弧线——引用时带上这个限定
- **把量表分数当人**:分数是采了样的叙事;用它分流可以,
  用它定论一个人的全部是类别错误(02 章表达力边界)
- **把马歇尔数字当定论**:15-25% 射击率必须连同方法论争议
  一起引用(Spiller 1988/Engen 2011)——著名数据被质疑
  反而教会领域核对数据
- **把人群命题当个体预言**:崩溃点/患病率是分布性质;
  Rose 预防悖论下,人群有效的政策常对多数个体"白付费"
- **把韧性训练当万灵药**:效应量之争未决(01 章证据门);
  没有对照组的训练报告一律降档
- **忽视自陈偏差**:测量即干预——被试知道被打分,
  动机随利害改变;"客观"算法测到的可能是表演
- **忘掉双重忠诚**:服务于人 vs 服务于建制的张力不可清零,
  只可明示(保密边界/目标函数写进需求文档)
