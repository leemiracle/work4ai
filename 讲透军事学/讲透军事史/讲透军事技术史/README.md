> **定位句**:这支负责讲清武器技术与战术组织如何**共同演化**(不是单向
> 决定)——每一次"新技术改写战争"的预言如何落空,落空的方式又如何反复
> 重演。器物长在时间里,断代长在组织里。

> 家族:[讲透军事史](../README.md);技术史横断正主在科技史宇宙(互链见下)。

## 诞生

伴随两次世界大战的作战分析建制化;学科正典于 20 世纪下半叶成型:
Parker《军事革命》(1988)确立"军事革命"命题与修正,van Creveld
《技术与战争》(1989)确立"技术与组织共同演化"框架;富勒《装甲战》
(1932)是技术预言书的经典样本(预言对了方向、错了时间表——滞后列的
活教材)。

## 核心问题(带年代锚)

- 军事革命论:Roberts(1955)命题→Parker 修正(棱堡才是规模膨胀主因)→
  RMA(1990s)话语及其史学清算——"革命"还是"间断平衡",悬而未决
- 滞后列之谜:技术首现到纪元成立隔 1-107 年,组织吸收的快慢由什么决定
  (危机压缩/制度惯性/军官教育)——进行中
- 攻防平衡的技术经济学:棱堡/铁路/侦察透明化——进行中
- 军用-民用扩散方向:火药/核/互联网/GPS 的军转民清单史——进行中
- 无人纪元的组织题:传感器透明化下"集中即暴露"——进行中(2020 纳卡为
  成立锚,样本仅一,谨慎外推)

## ✨ 这支最美的一个事实

军变革命题——**火药没淘汰城墙:1453 君士坦丁堡陷落后,城墙进化为棱堡
(trace italienne),反而在火药时代登顶;淘汰城墙垄断的不是火药,而是
野战炮兵战术与攻防组织的再平衡**——武器改变战争的方式,从来不取决于
武器本身。

## 假设与依赖

警惕技术决定论的反复破产(00 章⑥反直觉之一):RMA 式预言("零伤亡"
"传感器必胜")在堑壕面前的再次失败是活的教案;器物存世偏置:博物馆里
剩的是武器,战场组织无实物——编制表/操典/训练记录是组织层的代理变量,
必须与器物对读。
