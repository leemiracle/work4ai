# 03 · 可构造与结构——战例、序列与编年:战争作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:军事史里"可构造"的不是战争本身,而是**战争的
> 组织方式**——战斗序列是树、会战是时空事件、后勤是网络流、
> 编年是点列、技术谱系是演化图;而"结构"是两千四百年战争史
> 自身的骨架:七纪元钟摆、攻防平衡交替、后勤约束函数。

---

## 0. 开篇:一场会战=两棵树+一张图+一条时间轴

打开任何一部严肃战史的附录,你都会找到同一件东西:**战斗序列表**。
一方一棵树(集团军→军→师→团),节点带四元组属性(单位-隶属-
指挥-实力);把两棵树放在同一张地形图上,再加一条时间轴切片
(D日 05:30/08:00/10:20……)——**这就是会战的可构造形态**。
军队是人类历史上记录最密的科层组织(点名册/番号/日报表),
所以战争虽是最混乱的人类活动,其史料却出奇地结构化
——这是 01 章档案海啸有浪可乘的根本原因。

## 1. 什么是"可构造"的:六类战争对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **编年**(纪元/战例年表) | 点列 {(年, 纪元, 锚战例)} | ✅ 完全可构造(本家族 `experiments/00_tech_tactics_eras.py`) | 断代=离散化:锚选样即史观,须声明 |
| **战斗序列(OB)** | 树+隶属图 | ✅ 高度可构造(02 章四元组) | 纸面序列≠战时实态:加强/配属/残部重组天天在变 |
| **战例记录** | 结构化事件 (时间, 地点, 双方, 兵力, 战损, 指挥, 地形) | ✅ schema 成熟(§1.5) | 战损数字自带生成机制,须三栏并存(§4) |
| **后勤网络** | 节点-流量图(仓-路-港-部队) | ✅ 可构造(铁路时刻表/船运舱单) | 民夫/驮兽等"软后勤"几乎不入档 |
| **技术谱系** | 演化图(父型→改型, 配装单位) | ✅ 器物史强项 | 器物存世≠战场主流:博物馆偏置 |
| **攻防平衡指数** | 构造性概念(代词) | ⚠ 半可构造:可排序、难定量 | 排序即判断;只能做序数比较,不做基数宣称 |

**不可构造的**:指挥决心(动机)、战场心理崩溃点(溃散的临界)，
"决定性"的度量(00 章悬而未决)、以及"如果"的一切
(反事实只能在兵棋里机器化,见 04 章边界)。

### 1.5 六类对象的最小数据模式(动手者的 schema)

```yaml
# 纪元记录(对应实验脚本的 ERAS)
era: {name: 冷兵器|火药|线列|堑壕|装甲|核|无人,
      tech: str, tactic_form: str,
      anchor_year: int, anchor_battle: str,      # 纪元成立锚(转型战例)
      tech_first_year: int, tech_first_note: str, # 技术首现(滞后列起点)
      balance: 攻|防|威慑, source_tier: T1..T6}

# 战例记录(C2 战例库的字段源)
battle: {name: str, year: int, tz: str,           # 时区基准必填(02 章)
         belligerents: [side],                     # side={power, strength,
                                                   #   commander, ob_tree}
         casualties: {claimed_by_each, independent, revised},  # 三栏(§4)
         terrain: str, coordinates: [lat, lon],    # GIS 字段(01 章热线三)
         source_tier: T1..T6}

# 战斗序列节点(OB 四元组)
ob_unit: {unit: str, parent: str, commander: str,
          strength_est: int, as_of_date: str,      # 实力必须带日期快照
          source_tier: T1..T6}

# 后勤边(补给网的一条流)
logistics_edge: {from: 节点, to: 节点, mode: 铁路|公路|水运|驮运,
                 capacity_per_day: str, source_tier: T1..T6}
```

注意 `source_tier` 与 `casualties` 的三栏结构:把 02 章的语言纪律
写进数据结构——**数据层自带证据等级与数字生成机制,是军事史计算
区别于普通数据分析的第一特征**(承法律史学 03 章同款纪律)。

## 2. 骨架一:七纪元结构(编年的组织)

七纪元不是七个抽屉,而是有三个内部规律的结构(实验断言):

1. **加速律**:纪元成立锚间隔 251→173→40→28 严格递减
   ——转型时钟从百年级拧到十年级(组织吸收在加速:操典、
   军校、参谋制度让吸收期系统性缩短)
2. **核反例**:1945→2020 间隔 75 年,反弹超过前两跳
   ——威慑冻结大国直接战争;**核纪元不是"更强的战",
   而是"战的结构性缺席"**(1991 海湾战争是核阴影下的纪元内变奏)
3. **技术先行律**:每个纪元的技术首现都早于纪元成立 1-107 年
   (火药最久、装甲最急)——**滞后=组织吸收期**,是"技术与战术
   谁驱动转型"之争的数据面:技术必要而不充分,组织是充分性的
   承运人

纪元边界的构造性声明:断代是研究者强加的离散化;04 章 §5 的
敏感性分析(换锚重跑)是使用这套结构的正确姿势。

## 3. 骨架二:攻防平衡钟摆

| 纪元 | 平衡态 | 机制 |
|------|--------|------|
| 火药(1453-) | 攻(攻城成本重置) | 攻城炮重置城墙成本,城墙以棱堡回应——攻防螺旋 |
| 线列(1704-) | 攻(野战机动) | 燧发枪+刺刀淘汰长矛,常备军操典化 |
| 堑壕(1877-) | **防(火力对机动优势)** | 后装线膛武器:正面冲锋边际成本>工事边际成本 |
| 装甲(1917-) | **攻(机动恢复)** | 内燃机+履带+无线电:防护与机动重新打包 |
| 核(1945-) | 威慑(第三态) | 攻防之外的均衡:大国直接战争退出可行集 |
| 无人(2020-) | 攻防再失衡 | 传感器透明化:集中即暴露,分散即指挥难 |

钟摆的史学用法:**"僵局"常是当时的理性均衡**(一战堑壕是
攻防失衡下双方的均衡解,不是技术停滞——00 章⑥反直觉之二);
判断任何时代的军事体系,先问摆锤在哪边、下一摆的技术-组织
条件是否已在路上(滞后列思维)。

## 4. 骨架三:后勤约束(作战半径=给养函数)

- 军事学通语:外行谈战术,内行谈后勤——它的史学形式是:
  **任何作战半径都是给养函数的输出**。罗马军团的日行程定额、
  漠北之战的出征马数、蒙古西征的驱赶畜群、铁路时代的动员时刻表,
  是同一个函数的四个参数化(技术史支/古代战争史支各自的案例场)
- 后勤史的构造形态:仓-路-港-前线四级网络的**日流量表**
  (铁路舱单与船运清单是 T1 级金矿)
- **战损三栏纪律**(骨架三的伴生纪律):claimed_by_each
  (双方各自宣称)/independent(第三方或战后修订)/revised
  (数额批判修正)——三栏并存是构造合法性的前提;
  只载一栏的战例库,数字必然在替某方的战报说话

## 5. 从结构到比较:这套骨架买到了什么

- 七纪元钟摆 → 跨文明比较的坐标(中国为何无线列纪元:
  火药早用而组织环境不同——李约瑟题军事版,00 章问题表)
- 攻防钟摆 → "革命话语"的解毒剂(RMA 批判的结构基础)
- 滞后列 → 一切"新技术将改写战争"预言的先验折扣因子
- 后勤函数 → 一切兵力数字与战略计划的可行性检验器
  (德尔布吕克数额批判的现代版)

## 6. 构造合法性清单(动手前三问)

把任何战争材料变成数据结构之前,先过三问——本家族的"类型检查":

1. **快照日期**:实力数字带 as_of 了吗?——不带日期的 OB 是
   "还活着的树"(隶属天天在改),带日期才是快照
2. **三栏齐了吗**:战损的宣称/独立/修订三栏,缺栏先补栏再入库;
   只有一栏的记录默认打 T5 档(02 章 §2.7)
3. **选样声明写了吗**:编年与战例库的入选规则(西欧锚/正史锚/
   建制档案锚)必须写在数据集头部——不同选样的数据集
   不可直接拼接比较

三问全过,数据才获得进入 [04 章走廊](04-军事史转代码.md)的资格。
**军事史计算的第一特征不是算法,是入库纪律**——这一条把它与
普通数据分析划开界河(承法律史学"数据层自带证据等级"同款精神,
军事版多了战损三栏与时区)。

## 📌 收束

可构造的是**组织方式**(序列/事件/网络/编年),不可构造的是
**决心与崩溃**;结构不是装饰,是比较研究的坐标系。

**🧠 认知升维**:

- **快照眼**:一切实力数字必须带 as_of 日期——纸面序列是某日
  快照,不是状态函数
- **三栏眼**:战损数字永远问三栏——谁宣称的、谁核的、
  数额批判修到多少
- **钟摆+滞后联动眼**:看到新武器,先问摆锤方向,再问组织
  吸收年——两者合起来才是"改变了什么"的完整答案
