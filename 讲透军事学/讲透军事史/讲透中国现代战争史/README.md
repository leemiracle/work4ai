# 讲透中国现代战争史 · 运动战·持久战·大兵团(1919-1949 及续编)

> **定位句**:这支负责讲清 1919 年以降(以 1919-1949 为主体)中国战争
> 形态的定型——运动战的机动与根据地后勤、持久战的阶段检验、大兵团决战
> 的运输与火力组织——一律军事学视角:兵力动员/后勤保障/指挥体系/武器
> 来源,按军事史学科通说呈现,不作政治评价、不引申。
> GB/T 13745:83015 军事史 · 三级「中国现代战争史」。家族:[讲透军事史](../README.md)。

## 诞生

随 1950 年代军事科学院建院建制化,《中国人民解放军战史》等正典陆续
成书;《论持久战》(1938)作为军事思想文本与战争实践的交叉一手文献,
是本支与思想史支的共用锚。当代续编(1949 后)按学科通说并入本支
叙述框架。

## 核心问题(带年代锚)

- 运动战的作战半径:诱敌深入的成本函数——根据地纵深、后勤容量与机动
  能力的三角约束——通说骨架已立
- 持久战的阶段检验:1938 年《论持久战》三阶段预测与实际战局对照
  (军事学视角:动员/消耗/空间换时间)——进行中
- 敌后战场的交通线破袭:百团大战(1940)——打击铁路网=打击后勤动脉的
  战役类型学——进行中
- 大兵团决战的组织:三大战役(1948-49)的铁路输送、民工支前、炮兵火力
  转型——进行中
- 火力-机动对比的时代变化:从"小米加步枪"到东北炮兵纵队的装备来源与
  编制演化——进行中

## ✨ 这支最美的一个事实

淮海战役(1948.11-1949.1):66 天,野战兵力约 60 万对 80 万,而支前
民工 543 万、担架与小车构成"第二后勤网"——战役史通说把胜负的重要解释
归于后勤动员体系:**大兵团战争是两个动员体系的对账,前线每一次冲击
背后都是数百万人的运输组织**。
