# 04 · 军事史转代码——编年·战例·兵棋的三条最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:军事史的问题一旦变成"关于编年/战例/推演数据的
> 计算",就能进代码——纪元编年变间隔序列、战例变结构化记录、
> 兵棋变兰彻斯特方程;**唯一不可外包给代码的,是史学判断本身
> (选样、断代、归因、决定性裁定)**。

## 0. 开篇:七条锚战例检验三个教科书直觉

「战争形态转型的间隔在缩短」「核武器冻结了大国直接战争」
「新技术从不立刻改变战争」——三个教科书级论断,能不能用数据说话?

`experiments/00_tech_tactics_eras.py` 内置七纪元年表(冷兵器→火药→
线列→堑壕→装甲→核→无人,每纪元六字段:主导技术/战术形态/
成立年/成立战例锚/技术首现年/攻防平衡态),结构化后跑出三个断言:

- **加速律**:成立锚间隔 251(1453→1704)→173(→1877)→40(→1917)
  →28(→1945)严格递减——转型时钟确实在拧快
- **核反例**:1945→2020 间隔 75 年>28 年——威慑把转型钟拨慢,
  核纪元的特殊性在编年数据上肉眼可见
- **技术先行律**:七个滞后值 984/107/17/36/1/7/19——
  技术首现永远早于纪元成立,**滞后列=组织吸收期**;
  火药吸收最久(107 年),装甲最急(1 年,战时危机压缩)

但脚本同时打印选样声明:锚战例选样=西欧-大西洋战场通说,
换选样(以中国战史锚重排)会改变曲线。**代码替你算数,
替不了你选样**——军事史数字化的第一课。

## 1. 可机械化边界(三件套之一)

**能进代码的**(战争数据化后的一切统计与推演):

| 任务 | 机械化形式 |
|------|-----------|
| 编年间隔/纪元断代 | 锚点列 → 间隔序列、断言加速律/反例(家族实验) |
| 战例聚合 | 战例库 → 兵力比分布、交换比分布、会战频率时代曲线 |
| 战斗序列解析 | OB 文本/表格 → 隶属树、实力快照 diff |
| 战损核验的**冲突标记** | 三栏数字 → 冲突表(宣称和>对方总兵力即红旗) |
| 兰彻斯特推演 | 兵力参数 → 平方律/线性律下的交战结局与残余 |
| 时区/纪年换算 | 会战时刻 → 声明基准的统一时间轴 |
| GIS 对勘 | 航拍/序列坐标 → 机动轨迹层(01 章热线三) |

**不能进代码的**(军事史的"不可判定域"):

1. **选样正当性**——哪些战例算"转型锚"是史学判断;代码只能做
   敏感性分析(§5)
2. **决定性裁定**——坎尼是否"决定性"没有客观函数;
   代码只能给"战后 N 年内战争结束"的相关表
3. **归因与动机**——"南云败于换弹"的因果强度,代码给不出;
   相关(时间相邻)永远推不出因果
4. **兵棋冒充档案**——推演输出是机器化的 T6 反事实;
   把兰彻斯特结果当史实引用,是数字时代的新型硬错误(02 章 §2.5)

> 边界的一句话:**代码是战史的沙盘,不是参谋部**。
> 沙盘上推十遍,不如档案里对一次。

## 3. C2 战例数据库走廊(最小示例)

战例库的核心纪律是**战损三栏**(03 章 §4)。最小可运行示例——
把一条会战记录压成结构化数据,并做"通胀红旗"检验:

```python
# 战例三栏记录(03 章 battle schema 的最小落地;数字为示例值)
JUTLAND = dict(name="日德兰海战", year=1916,
               claimed={"德": 1.1, "英": 6.1},      # 双方宣称击沉(万吨)
               independent=5.3, revised=5.0)         # 第三方/修订(万吨)

def inflation_flag(b):
    """通胀红旗:双方宣称之和显著超过修订值即标记(02 章生成机制)。"""
    total = sum(b["claimed"].values())
    return total / b["revised"]

ratio = inflation_flag(JUTLAND)
assert ratio > 1.1, "宣称和应显著高于修订值(战报通胀结构)"
print(f"{JUTLAND['name']} 宣称/修订比 = {ratio:.2f} —— 战报数字自带立场,三栏缺一不可")
```

十行代码完成的事:一条会战 → 结构化记录 + 通胀度量。
扩展方向:01 章 NARA 日报表(连级日粒度)接入后,unit 字段
自动聚合为任意分辨率战损曲线——**unit 级档案与战例库的接榫**。
史学红线:红旗只标记"数字冲突",裁定哪栏可信是史学判断。

## 4. C3 兵棋推演走廊(兰彻斯特最小实现)

兵棋走廊的史学用途不是预测,是**零模型**——检验"如果双方按
教科书原则行动,结局应该是什么形状",再与史实对勘。
最小实现用兰彻斯特(Lanchester,1916)两律:

```python
def lanchester_square(x, y):
    """平方律(瞄准火力):集中兵力的收益。
    同兵种对射,弱势方被歼时强势方残余 = sqrt(x**2 - y**2)。"""
    return round((x**2 - y**2) ** 0.5)

# 集中兵力母题:1000 对 500,胜方残余 ≈ 866——不是 500
assert lanchester_square(1000, 500) == 866
# 分兵母题:两倍兵力分两半逐次作战,每场 500 对 250 各剩 433——
# 平方律下"各个击破"是弱势方的死刑判决书(坎尼包围的数学幽灵)
assert lanchester_square(500, 250) == 433
print("平方律:集中即杠杆——歼灭战教条的数学_origin")
```

**走廊三警告**(与 01 章 ABM 警告同源):

1. 参数=史观:伤亡率系数谁定,结论就归谁——推演结果引用时
   必须附参数来源
2. 兰彻斯特律本身是**理想化假设**(火力全向有效、单位同质),
   03 章"构造性概念"的待遇:可用作序数比较,不可当基数预言
3. 摩擦不可外购(军事思想史支):克劳塞维茨的 Friktion 在任何
   推演里都必须人为注入噪声——**不注噪声的兵棋,
   输出的是教科书而不是历史**

## 5. §4.5 断代敏感性:换锚重跑(使用本家族实验的正确姿势)

断代是离散化,锚是史观。两个合法的"换锚"实验:

- **信息纪元假说**:若以 1991 海湾战争为"精确战纪元"成立锚,
  则核纪元统治期缩至 46 年,加速律在战后重新成立
  (75 年反例部分消解)——结论随选样变,这本身就是史学发现
- **中国锚假说**:若七纪元锚改用中国战史锚(如 1161 采石之战
  的火药水战、1592-98 壬辰的火器攻城),"纪元成立年"整体移动,
  滞后列改写——**七纪元的西欧坐标是选样产物,不是普适规律**

家族实验脚本把选样声明打印在结果之后——先看数字,再看声明,
这个顺序不许反。

## 📌 收束

三条走廊:编年(C1,已成)管"何时",战例库(C2)管"何地何损",
兵棋(C3)管"如果";三条共用一条边界——**选样、断代、归因、
裁定永远留在人脑**。跑到这里,回头再看 00 章那句钉住本质的话:
军事史用过去的战争给未来的战争买保险;代码能帮你算保费,
保险单还得史学来签。

**🧠 认知升维**:

- **零模型眼**:模拟的正确用法是"与史实对勘的对照物",
  不是"结论发生器"
- **参数即史观眼**:读任何推演结论,第一件事找参数来源,
  第二件事才是看输出
- **噪声必注眼**:任何不含摩擦/不确定性的军事模型,
  默认按教科书处理,不按历史处理
