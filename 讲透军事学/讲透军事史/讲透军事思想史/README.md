# 讲透军事思想史 · 将军们怎么想战争:孙子到核时代战略的观念谱系

> **定位句**:这支负责讲清"人们认为战争是什么、该怎么打"的观念史——
> 《孙子》的不战而胜与克劳塞维茨的绝对战争各抓住战争的哪一端、歼灭战与
> 消耗战的思想谱系、核时代威慑理论是思想革命还是旧思想的极限情形。
> 观念长在文本里,文本要过史学考据。
> GB/T 13745:83015 军事史 · 三级「军事思想史」。家族:[讲透军事史](../README.md)。

## 诞生

经典序列即学科前史:孙武约前 512 年著《孙子兵法》(1972 银雀山汉简出土
为最早文本实证);修昔底德的权力-恐惧解释是观念史第一页;克劳塞维茨
1812-1830 年撰《战争论》(1832 遗著出版),"战争是政治以其他手段的继续"
与"摩擦"成为现代军事思想轴心;若米尼《战争艺术概论》给出几何学派对照。
学科化于 20 世纪:战争哲学与战略研究建制(含钮先钟《西方战略思想史》)。

## 核心问题(带年代锚)

- "不战而屈人之兵"与"绝对战争":东西方经典各抓住战争哪一端(政治目标
  vs 暴力本质)——骨架已立,谱系化进行中
- "摩擦"(Friktion)的可操作性:从哲学词到仿真噪声项——概念史与建模史
  双线追踪——进行中
- 歼灭战/消耗战的思想谱系:德尔布吕克两战略→闪击战→持久战——进行中
- 技术与思想谁改写条令:滞后列的思想层(新技术先被旧条令吸收还是先造
  新思想)——悬而未决
- 核时代:威慑理论是思想革命还是旧思想的极限情形——悬而未决

## ✨ 这支最美的一个事实

克劳塞维茨的"摩擦":"战争中的一切都很简单,但最简单的事情也困难"——
计划在执行中必然衰减;这个 1830 年的哲学词至今无法被任何军事模型外购,
是一切兵棋必须**人为注入**的噪声项:**一个概念硬编码了后世所有军事仿真**。

## 假设与依赖

兵书≠军事实态:纸面条令与战场行为之间有缝(与家族"纸面序列≠战时实态"
同构);思想文本的编纂史(汉简本/宋本/译本)是考据地基;翻译链的概念
漂移(《战争论》汉译/《孙子》英译的术语回译)是显性风险,引观念必带版本。

## 教材锚

- 若米尼《战争艺术概论》;钮先钟《西方战略思想史》
