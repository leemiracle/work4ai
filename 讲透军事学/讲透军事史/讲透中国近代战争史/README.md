# 讲透中国近代战争史 · 代差实验场:冷热交替与旧军队近代化(1840-1919)

> **定位句**:这支负责讲清 1840-1919 年间中国经历的战争——两次鸦片战争、
> 太平天国战争、中法战争、甲午战争、清末军事改革——的核心军事学题:
> 兵器代差、编制训练、指挥通信、后勤体系的系统性落差如何决定战局。
> GB/T 13745:83015 军事史 · 三级「中国近代战争史」。家族:[讲透军事史](../README.md)。

## 诞生

即时反思自魏源《圣武记》(1842)始——鸦片战争战败当年即催生史学追问
("师夷长技"的出处语境);系统战史编纂随清末民初军制改革与参谋制度
起步。**现代学科**正典:军事科学院《中国近代战争史》(多卷)为代表的
建制化成果;档案丛刊(如中国史学会《中日战争》)提供一手文献底座。

## 核心问题(带年代锚)

- 代差题:1840 年英军滑膛枪炮对清军冷热混编的优势能否定量刻画
  (射速/精度/队列机动三指标)——进行中
- 湘淮军的兵制创新:勇营制度、粮台后勤自筹如何支撑长期内线作战——进行中
- 甲午体系差:大东沟(1894)单舰火力不弱而舰队战败,弹药供给/射速/
  队形指挥差在哪——通说骨架已立,细节随档案深化
- 海岸要塞的攻防经济学:虎门/旅顺/威海卫为何没能抵消海上机动优势——进行中
- 清末新军(1895 起)与军事教育:转型幅度与距近代参谋指挥体系的差距——进行中

## ✨ 这支最美的一个事实

甲午黄海大东沟海战(1894.9.17):定远、镇远的 305mm 克虏伯主炮口径为
全场之最,而日舰无一沉没、北洋舰队失舰五舰——**装备单件不落后而体系
(弹药供给/射速训练/队形指挥/通信)决定战果**:"体系对单品"的教科书
案例,此后百年反复重演。

## 假设与依赖

战报与战后总结由各方利益生成(战败追责文书/胜方宣传),证据分级使用是
地基;海军技术档案多存欧洲厂方,跨档案对勘是基本功;战损一律三栏
(宣称/独立/修订),回忆录降档使用(02 章军版阶梯)。
