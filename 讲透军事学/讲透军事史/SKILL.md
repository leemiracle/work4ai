# 军事史思维技能卡(GB/T 83015 · 讲透军事史家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「某场战争/会战**怎么打、为什么败**」——战例解剖需求
- 「这款新武器/无人机/AI 会改写战争吗」——先上滞后列,再谈革命
- 「决定性会战存在吗」「一战为什么挖堑壕」——攻防钟摆与均衡问题
- 战史数字可疑(古代兵力"号称八十万"/双方战报歼敌数)——数额批判
- 后勤与动员规模(淮海支前/漠北马政/铁路时刻表)——给养函数
- 兵棋推演/兰彻斯特/交换比——军事史的机器化走廊
- 编年/战斗序列/战例库的数据化——schema 级需求
- 学战略/战役/战术时缺经验表——史例是理论的原材料

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **实验眼** | 战史=人类自当实验品的实验:不可重跑但可对勘——先问对照材料在哪 |
| **四视角解剖** | 兵力/后勤/指挥/技术四把刀依次过一遍,不缺位 |
| **数额批判** | 一切兵力/战损数字先过行军宽度×道路容量×人畜耗水的可行性检验 |
| **滞后眼** | 技术首现≠纪元成立:看到新武器先问组织与条令的吸收年(1-107 年) |
| **钟摆眼** | 攻防平衡是钟摆:判断体系先问摆锤在哪边、下一摆条件是否已在路上 |
| **生成机制眼** | 每个数字先问谁写的、给谁看、写时在担什么责(战报通胀是制度行为) |
| **双层眼** | 叙事层(发生了什么)与分析层(意味着什么)分开读,中介词挂证据级 |

## 3. 工具箱(何时用什么)

- **七纪元年表**:冷兵器→火药→线列→堑壕→装甲→核→无人
  (家族实验 `experiments/00_tech_tactics_eras.py` 为最小实现:
  加速律/核反例/滞后列三组断言)
- **断言阶梯 T1-T6 军事版**:T1 作战日志→T2 官方战史→T3 回忆录
  (军事史特有降档:须与档案对勘)→T4 通说→T5 战时宣传→T6 反事实;
  动词即类型签名
- **战损三栏**:claimed_by_each / independent / revised 并存;
  只有一栏的数字必然在替某方战报说话
- **OB 四元组**:单位-隶属-指挥-实力(实力必须带 as_of 日期快照)
- **兰彻斯特律**:平方律(集中兵力杠杆)做序数比较;
  参数=史观,引用必附来源;不注摩擦的兵棋输出的是教科书
- **德尔布吕克数额批判操作化**:给养/道路/水源三函数反推兵力上限
- **时区纪律**:跨洋战役必须声明时区基准(中途岛美日记录差一天)
- **编年密度/间隔断言**:转型锚点列→间隔序列(04 章 C1)

## 4. 常见误区与禁忌

- ❌ **技术决定论**:「武器一响世界改变」——RMA 话语的反复破产史
  就是军事史的一条研究线;滞后列是先验折扣因子
- ❌ **战损数字直读**:把战时公报(T5)当战报(T1-T2)——
  军事史读物的头号病
- ❌ **将军史观**:只写指挥所看得见的东西;士兵体验/溃散/疫病减员
  系统性缺席(Keegan 批判)
- ❌ **把"僵局"当愚蠢**:一战堑壕是攻防失衡下的理性均衡,
  不是技术停滞——时代错置的反问
- ❌ 反事实当结论:兵棋输出=机器化 T6,冒充档案是数字时代新病
- ❌ 编造对话/战场细节;传说与孤证显式标注
- ❌ **敏感红线**:中国近现代战争史按军事史学科通说呈现,
  军事学视角(兵力/后勤/指挥/技术),**中性学术语体,不评价不引申**
