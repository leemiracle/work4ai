## 四、教材锚

- 修昔底德《伯罗奔尼撒战争史》(前 5 世纪——双柱奠基原典)
- 《孙子兵法》(约前 512;银雀山汉简本为最早文本实证——思想史支正主)
- 克劳塞维茨《战争论》(1812-1830 撰,1832 遗著出版——史例方法论的哲学层)
- 德尔布吕克《战争艺术史》(1900-1920——数额批判与军事学视角进史学)
- 富勒《西洋世界军事史》(1954-56——世界战争史通史范本)
- 军事科学院《中国军事通史》(十卷,1998——中国战史通史正典)
- Keegan《战斗的面目》(1976——从将军史观到士兵视角的方法转折)
- van Creveld《补给战》(Supplying War,1977——后勤史开山)
