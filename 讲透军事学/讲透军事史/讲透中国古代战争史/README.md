# 讲透中国古代战争史 · 车战·步骑·筑城·马政:城濮到雅克萨(前 632-1689)

> **定位句**:这支负责讲清先秦至 1840 前中国战争的组织与战例——车战如何
> 让位步骑、长城是一道什么样的成本函数、农耕帝国与草原的后勤对账怎么打
> ——一律从兵力/后勤/指挥/技术四视角进入。
> GB/T 13745:83015 军事史 · 三级「中国古代战争史」。家族:[讲透军事史](../README.md)。

## 诞生

传统战史书写自《左传》详记战例(城濮之战前 632:谋议-接战-检讨完整链条)、
《史记》卫霍列传近乎档案式记事,但传统文献**重庙算轻战场**(兵书极发达、
战记极简略)。作为**现代学科**建制于 20 世纪,以军事科学院《中国军事通史》
(十卷,1998)为正典标志;银雀山汉简《孙子兵法》(1972)与居延汉简
(戍役与军功文书)为出土校准器。

## 核心问题(带年代锚)

- 车战→步骑兵的转型机制(春秋→战国;前 541 晋"毁车以为行"著名个案)——大体已明
- 北疆防御的攻防经济学:长城=固定防御的成本函数,与机动野战军的换防——进行中
- 农耕-草原战争的后勤上限:漠北之战(前 119)的马政基础——进行中
- 长平(前 260)/赤壁(208)/淝水(383)的"号称"兵力数字须过数额批判
  ——方法论已立,逐案未完
- 火药 10 世纪已用于中国战场,为何未触发欧洲式军事革命(李约瑟题军事版)
  ——悬而未决

## ✨ 这支最美的一个事实

漠北决战(前 119):卫青、霍去病各率五万骑出塞,汉廷为这一战积累出征马
十四万匹、私负从马与步骑转辐数十万——**胜负在开战前已由马政写好一半**:
草原战争的胜负表,是两个后勤体系的对账单。

## 假设与依赖

依赖传世文献的结构性偏置(重谋议轻战场);出土简牍(军功爵/戍役/武库簿)
是校准器而非全貌,孤立引孤证即断案是硬错误。
