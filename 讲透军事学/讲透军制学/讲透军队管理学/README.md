# 讲透军队管理学 · 新陈代谢:千万人级组织的日常运转(GB/T 8304530)

> **这支负责的问题**:军队这台机器在不开火的日子里怎么运转——
> 人怎么进怎么出(兵役/军衔/人事)、事怎么按章办(条令/行政)、
> 物怎么维护(装备日常管理/营区)。一句钉住:**编制决定军队长得
> 像什么,管理决定它明天还能不能动——千万人级组织的战斗力,
> 大半藏在出操、点名与请领单据里。**
> 支宪法(GB/T 13745:8304530)。家族:[讲透军制学](../README.md)。

## 诞生(谁/何时)

- 古典:操典与军法的建制传统(中国先秦军法、罗马军纪——十一抽杀
  律等为纪律管理的古典形态;学科史实);《周礼》以降"兵制即
  行政"的传统使军政管理一体演化
- 近代:全民征兵(1793)与大规模常备军催生近代军政体系——
  军衔-薪饷-抚恤-档案的制度群在 19 世纪欧洲定型;
  普鲁士-法国的军官职业化(军校+晋升规测)是管理专业化的节点
- 20 世纪:两次大战的千万人动员把人事管理推到极限(美国选征兵
  役制 1940-1973 的档案与分类系统);战后管理科学(运筹/人力资源
  管理)进入军政领域
- 当代:合同化服役、岗位轮换制度、军人职业发展路径的制度化;
  组织变革理论进入军队(01 章热线二:转型学习)

## ✨ 这支最美的一个事实

**轮换制度的两难是管理学的教科书标本**:定期轮岗强制组织记忆
更新、防止山头与腐败(买到),同时冲掉专业积累与单位凝聚力
(付出)——同一制度同时是防腐剂和溶剂。军队管理学的大量制度
都是这种"一体两面的合同":读懂它们要同时读管理账与士气账
(与[讲透军事心理学](../../讲透军事心理学/README.md)的接口)。

## 假设与依赖

科层可管理假设(千万人组织可按规章运转——摩擦与例外是结构性的,
条令永远落后于现实半步);服役行为的可激励假设(军衔/薪饷/荣誉
的激励相容设计);依赖组织体制支给的编制与岗位坐标系、
[讲透管理学](../../../讲透管理学/README.md)的组织与人力资源
一般理论(上游宇宙,波4在建链宇宙级)。
