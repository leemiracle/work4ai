# 讲透军制学 · 军队这台机器的宪制(GB/T 83045)

> **军制学=军队这台机器的"宪制":编制怎么定、装备怎么来、队伍怎么管。**
> 战略学(83025)管"为何而战、怎么打赢",军制学管**"拿一支什么样的军队
> 去打"**——它是把战争需求翻译成组织、装备与管理制度的那道工序。
> 与军队指挥学一体两面:**指挥是神经,军制是骨架**——神经传递命令,
> 骨架决定形态;没有骨架的神经只是一束电信号,没有神经的骨架只是标本。
> 一句钉住:**"打什么仗造什么军队"还是"有什么军队打什么仗"——
> 这门学科两千年的全部工作,就是这两句话之间的拉锯与换轴。**
>
> GB/T 13745:83045(二级学科,军事学 830 之下;三级:军事组织体制/
> 军事装备学/军队管理学,支名=GB/T 三级名)。
> 宇宙:[讲透军事学](../README.md)。

## 〇、家族定位与成员(含纪律框,必读)

- 学科身份:830 宇宙的**组织制度层**——军事史供"过去怎么打",
  战略/战役/战术供"分层怎么打",[讲透军事理论](../讲透军事理论/README.md)
  供概念车间;本家族供这一切的**物质载体**:军队按什么结构编成、
  按什么流程获得装备、按什么制度日常运转
- 与军队指挥学(83040,波3待建)的分工:指挥学研究命令如何形成与
  传递(神经);军制学研究神经所依附的组织形态(骨架)——指挥体制
  本身(哪一级设哪一指挥部)是本家族的编制对象,指挥活动才是指挥学
- 与[讲透战略学](../讲透战略学/README.md)的分工:战略提出能力需求
  ("需要能在两地同时作战的部队"),军制把需求变成编制表与采办单
  ——**需求侧与供给侧的接口学科**
- 跨宇宙挂靠:[讲透经济学/讲透国防经济学](../../讲透经济学/讲透国防经济学/)
  (军费与动员的资源账本,互链:同一本预算账的两个视角)、
  [讲透管理学](../../讲透管理学/README.md)(科层组织与采办管理的
  一般理论上游;该宇宙波4在建,链宇宙级)
- 纪律框:本家族研究对象是**制度**不是政策——编制史、采办建制史、
  管理学史按学科通说中性呈现;不评价任何国家现行政治制度、军队政策
  与人物;涉外军力量设计与采办改革只述公开文献的学理与建制史实

**问题分流速查**(拿到一个军制问题,先分诊):

- 「这个军/师/旅怎么编的、为什么这么编」→ 组织体制支
- 「一款武器怎么从立项走到列装、为什么这么慢这么贵」→ 装备学支
- 「兵役/军衔/日常管理/人事制度怎么运转」→ 军队管理学支
- 「编制表/力量结构/采办组合怎么变成数据」→ 家族 03/04 章
- 「军队转型为什么这么难」→ 家族 00 章+01 章(力量设计热线)
