# 讲透军事装备学 · 全寿命:钱怎么变成战斗力(GB/T 8304520)

> **这支负责的问题**:装备从哪来、怎么养、何时退——需求生成、
> 采办管理、列装保障、退役处置的全寿命流水线。一句钉住:
> **军队买的从来不是武器,是"能力"在二十年时间轴上的交付流;
> 采办的慢与贵,常常不是管理失败,而是多重法定目标互斥下的
> 制度均衡。**
> 支宪法(GB/T 13745:8304520)。家族:[讲透军制学](../README.md)。

## 诞生(谁/何时)

- 前现代:军械管理是宫廷与将帅的行政事务(武库/军器监一类的
  建制,中国自唐代有军器监,学科史实);工业革命后军械工业-
  战争部采购体系成型(19 世纪)
- 两次世界大战:批量采购与标准化生产(自由轮/轰炸机产能),
  采办首次成为国家工业组织的核心业务
- 冷战:1960s 起美国 PPBS(规划-计划-预算系统)把装备需求接入
  预算流程(麦克纳马拉改革,建制史实);采办管理学科化
  (生命周期成本/里程碑评审方法定型)
- 当代:[IDA/DMI]《The State of the Defense Acquisition System
  2024》以**冲突性法定授权**框架重评绩效【检索校准 2026-09-07】;
  工业基础(产能本身)成为采办对象(01 章热线四)

## ✨ 这支最美的一个事实

**"买能力"三个字改写了整门学科**:需求文档写"能在 X 条件下
完成 Y 任务",而不是"买一种射程 Z 的导弹"——前者允许创新方案
竞争(也许无人平台更便宜地完成 Y),后者锁死技术路线。
需求生成语言的这一处措辞差异,是采办改革最便宜也最难学的
一课(02 章:军制学里语言即制度)。
