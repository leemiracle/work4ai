# 讲透军事理论 · 战争的自我意识(GB/T 83010)

> **军事理论=战争的自我意识**:从孙子的"兵者,国之大事也"到克劳塞维茨的
> "战争是政治的继续",人类在两千五百年里反复追问同一组问题——
> **战争是什么、为何而战、怎样才算赢**。战略学(83025)管"这一仗怎么筹划",
> 本家族管筹划背后的概念车间:重心、摩擦、奇正、持久、威慑、间接路线,
> 全是在这里铸造的词。一句钉住:**每一代军人都用上一代战争的经验
> 准备下一代战争——军事理论就是这场错位中永不完工的校正工程。**
>
> GB/T 13745:83010(二级学科,军事学 830 之下;三级名照录"马恩列斯军事理论"
> "毛泽东军事思想",按军事思想史学科史实中性呈现)。
