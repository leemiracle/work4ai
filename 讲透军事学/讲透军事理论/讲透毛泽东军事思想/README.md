# 讲透毛泽东军事思想 · 持久战与人民战争的概念体系(GB/T 83010 三级)

> **这支负责的问题**:1930-1940 年代中国战争实践中形成的
> 军事著作群提出了持久战、人民战争、积极防御、集中优势兵力等
> 概念。本 README 按**军事思想史的学科史实**中性呈现:
> 谁、何时、提出什么概念、在战争理论谱系中的位置;
> 不评价、不引申。

## 诞生(学科史实)

毛泽东 1936 年 12 月在中国陕北红军大学作《中国革命战争的战略问题》
讲演,总结土地革命战争经验,提出积极防御及"围剿"与反"围剿"
长期反复的战争形式分析;1938 年 5-6 月在延安作《论持久战》讲演、
写《抗日游击战争的战略问题》,提出持久战三阶段论并将游击战争
置于战略地位;1946-1947 年有一系列作战原则论述(集中优势兵力、
各个歼灭敌人,不计一城一地之得失等)。著作群构成 GB/T 83010
三级学科的核心文献。

## 核心概念(谱系定位)

| 概念 | 出处(年份) | 在战争理论谱系中的位置 |
|------|-----------|----------------------|
| 持久战三阶段论(防御/相持/反攻) | 《论持久战》1938 | 战争分期理论的形式贡献:把"谁赢"转为"经由什么阶段"的可检验命题 |
| 人民战争(战争伟力之根源存在于民众之中) | 《论持久战》1938 | 与总体战/全民动员谱系可对读的组织概念 |
| 游击战争的战略地位 | 《抗日游击战争的战略问题》1938 | 把游击战从战术层次提升到战略层次——战争层级论的重新划格 |
| 积极防御(攻势防御) | 《中国革命战争的战略问题》1936 | 克劳塞维茨"防御是更强的作战形式+防御须转入进攻"谱系中的相邻论点 |
| 集中优势兵力各个歼灭敌人 | 1946-1947 作战原则论述 | 消耗-机动战争谱系的数量优势论:整体劣势下逐次制造局部优势 |

## 这支最美的一个事实

"集中优势兵力、各个歼灭敌人"与兰彻斯特平方律(家族层
[03-可构造](../03-可构造与结构.md)✨④)可作纯形式对读:平方律下
整体劣势的军队若能分割对手、在每个局部集中,等于**在局部人为
制造平方律优势**——家族实验 [lanchester_laws.py](../experiments/lanchester_laws.py)
场景 3 的分兵账单正是其算学反演。概念(1946)与方程(1916)
互不相识,却在同一守恒量里会师。
