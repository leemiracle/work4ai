# 04 · 军事理论转代码:假设宇宙的可计算走廊与不可编译的战争

> **本章回答五问之五(家族层):这个分支的问题怎么变成 code 问题?**
> **本质一句话**:军事理论的可计算核心是**假设宇宙内的推演**——
> 兰彻斯特两律、小规模威慑博弈、OODA 玩具环、蒙特卡洛推演,
> 每一条走廊都算得动,但每一条都只在自己的假设宇宙里有效;
> 摩擦、政治目的、对手适应、史例归纳、威慑检验五处裂缝
> 是原则上不可编译的。三件套:可机械化边界/六条代码走廊/
> 工程师落点,外加裂缝清单。

📖 **开篇故事**:1916 年,英国汽车工程师兰彻斯特
(Frederick W. Lanchester,兰彻斯特汽车公司创始人)出版小册子
《Aircraft in Warfare: The Dawn of the Fourth Arm》,讨论飞机
作为"第四军种"的前景。第五章的标题是"集中原则"——他没有
引孙子,也没有引若米尼,而是写下了两行微分方程,证明集中兵力
的古老格言在数学上等价于一个守恒量。**一个造汽车的人顺手把
两千年的军事格言变成了可以算的东西**——本家族的全部"转代码"
事业,都活在这第五章划定的领地里:能写成方程的,进代码;
写不成方程的(摩擦/目的/对手的适应),留在门外,但要显性记账。

## 一、可机械化边界(三件套之一)

| 任务 | 可机械化? | 说明 |
|------|-----------|------|
| 兰彻斯特两律数值积分 | ✅ 全自动 | 常微分方程+数值积分——家族实验即样本(走廊①) |
| 集中-分兵推演(平方律宇宙) | ✅ 全自动 | 各个击破的分批计算,结论可 assert |
| 小规模威慑博弈求解 | ✅ 全自动 | 博弈树+逆向归纳——谢林工具箱的机器版(走廊②) |
| OODA 玩具仿真 | ✅ 全自动 | 离散时间步+延迟参数;但"判断"环节是占位黑箱(走廊③) |
| 蒙特卡洛推演统计 | ✅ 全自动 | 损耗随机化/置信区间(走廊④) |
| 推演裁决规则一致性检查 | 🟡 半自动 | 规则先人工命题化,再机检(走廊⑤) |
| 概念文件/条令的语言处理 | 🟡 半自动 | LLM 起草+人审(01 章方向三) |
| 摩擦建模 | ❌ 原则上不可完全 | 环节耦合不可枚举(02 章:摩擦长在环节数目里) |
| 政治目的量化 | ❌ | 胜负判据=价值不可通约;只能当外生参数供人设定 |
| 战争预测 | ❌ | 对抗性公理:对手会读你的模型并因此改变(裂缝③) |
| 威慑有效性验证 | ❌ | 成功时无事件可观察(00 章悬而未决②) |

## 二、代码走廊总表(三件套之二)

| 走廊 | 问题类型→形态→栈 | 承诺强度 |
|------|-----------------|---------|
| ① 兰彻斯特走廊 | "两军对耗谁剩" → ODE+数值积分 → 纯 python(家族实验) | 算得准(假设宇宙内可验证) |
| ② 威慑博弈走廊 | "威胁可信吗" → 博弈树+逆向归纳 → 纯 python | 算得对(给定偏好序) |
| ③ OODA 走廊 | "节奏差如何累积" → 离散仿真+延迟参数 → 纯 python | 玩具级(判断环节是占位) |
| ④ 蒙特卡洛走廊 | "胜负分布如何" → 随机损耗+大样本统计 → 纯 python/并行 | 统计可信(非演绎保证) |
| ⑤ 条令一致性走廊 | "裁决规则矛盾吗" → 规则命题化+可满足性 → 纯 python | 算得准(命题级) |
| ⑥ LLM 推演走廊 | "红队/控制员/裁决" → LLM+想定模板 → python+LLM API | 统计可信,偏置须显性测量(01 章方向四) |

### 走廊①:兰彻斯特两律(本章主样本)

**建模三步**:选律(平方律=直接瞄准火力/线性律=一对一或面杀伤)
→ 写方程(平方律 dx/dt=-βy, dy/dt=-αx;线性律 dx/dt=-kxy)
→ 数值积分(Euler/RK4,战斗至劣势方兵力下限截断)。

家族实验 [experiments/lanchester_laws.py](experiments/lanchester_laws.py)
的三组对照,每组都是一条军事理论的机器版:

1. **平方律 vs 线性律**:同为 1000 对 800(等效能),平方律下
   劣势方全灭时优势方剩约 600,线性律下剩约 200——
   **劣势方在线性律下生存状况更好**(固定作战时限内存量更高,
   交换比从 0.5 升到 1.0):交战律决定劣势方的生死算法
2. **分兵惩罚**:劣势方 800 合兵投入 vs 分两个 400 批次投入,
   优势方终局幸存约 600 vs 约 824——**分兵在平方律宇宙里
   等于给对手送汇率**(03 章✨④的机器版)
3. **分兵免疫**:同样的分兵在线性律下无惩罚(守恒量是 x-y,
   分批不改变总差)——**"集中兵力"不是公理,是平方律宇宙的
   地方性定律**;知道律的边界与知道律本身同等重要

### 走廊②:威慑博弈(谢林工具箱的机器版)

```python
# 极简威慑树:守方先布置威慑,攻方决定进攻与否,守方决定是否报复
# 逆向归纳:从叶到根,每一节点取该方偏好最大分支
# 实验问题:什么偏好序下"威胁可信"成立?——枚举全部偏好序,
# 数出威慑成功的比例(谢林:可信威胁是稀缺品)
```

偏好序的枚举(几个严格序的排列)+ 逆向归纳,三十行内完成;
结论依赖外生的偏好设定——**价值不可通约不是代码能替你选的**
(裂缝②)。

### 走廊③④⑤⑥:四条辅助走廊

- **OODA 玩具环**:双方各带决策延迟与执行延迟参数,时间步循环
  累积"行动滞后差";代码里"判断"=随机延迟占位——
  **黑箱的诚实表示法是把它显式标注为黑箱**
- **蒙特卡洛**:把损耗系数设为随机变量,跑万次得胜负分布——
  从"谁赢"升级到"多大把握赢";推演结论的正确形态永远
  是分布不是点
- **条令一致性**:推演裁决规则先人工命题化(每条规则=蕴含式),
  再做可满足性检查——方法论与理论法学家族的法条一致性
  检查器同构(条令文本治理是两个宇宙的共同问题)
- **LLM 推演**:大语言模型充当红队/控制员的原型已在多国防务
  院校试验(01 章方向四);工程纪律:裁决一致性回归测试+
  偏置显性测量(模型对"理性对手"的内置假设会把所有对手
  演成同一个模型——02 章对抗性语义的机器版)

## 三、工程师落点(三件套之三;性能工程视角)

1. **积分步长与截断**:平方律在劣势方趋零时 dy/dt 仍有限,
   Euler 的误差主要在战役中段;dt=1e-3 对千级兵力已给
   <1% 终局误差,RK4 再降两个量级——**先量误差再选方法**,
   玩具问题不要上重炮;战斗终局用兵力下限截断
   (理论全灭时间趋于无穷,工程上 x<ε 即停)
2. **蒙特卡洛的方差**:胜负分布的尾部(小概率大损失)才是
   推演要看的部位——朴素采样的尾部样本稀疏,重点采样/
   公共随机数(对比两律时共享随机流)是标准工具;
   **对比实验用配对样本,方差立减**(实验里两律对比
   用同参数标定,正是此法)
3. **大规模推演并行化**:兵棋蒙特卡洛天然 embarrassingly
   parallel(每局独立);瓶颈在想定装载与结果聚合;
   决策延迟参数扫描(走廊③)按参数分片并行
4. **LLM 裁决的回归测试**:温度=0 仍非严格确定;
   裁决一致性的黄金集(同想定 N 次裁决,分歧率报告)+
   对手角色漂移监测(红队出招分布随对话长度漂移吗)
   ——推演工程化的真正新工艺

## 四、裂缝清单(原则上/工程上的不可转)

1. **摩擦不可编译**:微小障碍的耦合不可枚举(02 章);
   模拟里加随机折扣系数是**拟合摩擦的统计影子**,
   不是摩擦本身——影子可用于训练,不可用于断言
2. **政治目的不可量化**:胜负判据是价值问题(胜利/成本/时间
   无公共刻度);代码只能执行外生给定的效用函数——
   **效用表是谁填的,比代码是谁写的重要**(最后的诚实:
   预设写在需求文档里)
3. **对手适应(单方模型悖论)**:克劳塞维茨——战争不是孤立
   意志的行为;你算出的最优恰好因为被对手预 read 而失效。
   博弈论处理形式化的互动,但对手建模对手的无限递归
   在计算上无底(共同知识的坍缩)——推演的对手永远
   是我们对中国历史的想象(02 章对抗性语义)
4. **史例归纳的统计陷阱**:军事机器学习的数据地基是战例——
   样本小/选择偏/幸存者叙事;从战例学的"规律"常常是
   **档案保管率的规律**——与史学界的方法论互助是唯一解药
   ([讲透历史学](../../讲透历史学/))
5. **威慑不可检验**:威慑成功时什么都不发生——无事件无数据;
   "三十年的和平证明威慑有效"与"三十年的和平证明对手
   本来就不想打"在观察上不可区分(00 章悬而未决②)

## ✍️ 练习

1. **参数翻转**:在家族实验里给防御方加"等效战斗力放大系数"
   (待之利的最简数量化,03 章✨①),从 1.0 扫到 1.5,
   找出交换比翻转的临界值——亲手摸到"防御是更强的作战形式"
   的一个数字化版本
2. **增援流**:把"分兵两批"改成"第二批延迟 T 时间到达"
   (方程加一项分段),数值实验:什么 T 以下分批不再吃亏?
   ——你会重新发现"各个击破"的时间条件
3. **威慑偏好序枚举**:走廊②的博弈树,枚举攻守双方的
   全部严格偏好序组合,统计威慑成功的比例——
   体会谢林"可信威胁需要精心设计"的稀缺性含义

## 📌 收束

军事理论转代码的图景:**走廊①-④算得动(假设宇宙内推演)、
走廊⑤管条令治理、走廊⑥在门槛上(统计可信,偏置须测量);
裂缝在摩擦/政治目的/对手适应/史例归纳/威慑检验五处**。
选走廊看承诺强度,过裂缝靠显性预设不靠信念——军事模型的
输出是"假设宇宙内的必然",把它当"现实的预测"是这门学科
两百年来反复犯的同一个错。读完五章,这支家族的地图已完整
——回[家族 README](README.md) 的家族树挑下一站。

**🧠 认知升维**:
- **假设宇宙眼**:任何军事模型的输出先问"在谁的假设宇宙里"
  ——平方律的结论对炮兵对射是洞见,对散兵坑里的步兵是幻觉
- **分布眼**:推演的正确输出是分布不是点——报"我们赢了"
  的推演没做完,报"70% 情形下惨胜,30% 情形下失败"才是
- **预设眼**:任何军事仿真都内嵌一张效用表——找到填表的人,
  是审查任何"科学推演"的第一动作(与理论法学家族的
  "解释者预设"是同一个动作)
