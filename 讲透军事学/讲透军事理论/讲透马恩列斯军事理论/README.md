# 讲透马恩列斯军事理论 · 战争-政治关系的唯物史观重述(GB/T 83010 三级)

> **这支负责的问题**:在军事思想谱系中,克劳塞维茨把战争系于政治
> ("战争是政治的继续");本支的谱系位置是把这条命题**再延长一环**
> ——政治及其暴力工具植根于生产方式。本 README 按**军事思想史的
> 学科史实**中性呈现:谁、何时、提出什么概念、在谱系中的位置;
> 不评价、不引申。

## 诞生(学科史实)

恩格斯 1850 年代移居曼彻斯特期间自学军事,为《纽约每日论坛报》
《普特南月刊》等撰写克里米亚战争等军事评论,时人有"曼彻斯特的
将军"之称;1857 年为《新美国百科全书》撰《军队》词条,论军队
组织随生产与交往手段而变;1878 年《反杜林论》"暴力论"三章
讨论暴力工具与经济基础的关系。列宁 1915 年《社会主义与战争》
等文引用并引申克劳塞维茨"战争是政治的继续"命题,以其作为
区分战争政治性质的判断根据;斯大林 1941-1945 年卫国战争时期
有战争问题论述(战时文告文献)。汇编见《马克思恩格斯军事文集》。

## 核心概念(谱系定位)

| 概念 | 出处 | 在军事思想谱系中的位置 |
|------|------|----------------------|
| 暴力论(暴力工具系于经济基础) | 《反杜林论》1878 | 对"政治决定战争"命题的再追问:政治又由什么决定——谱系的延长线 |
| 军队组织随生产方式而变 | 恩格斯《军队》词条 1857 | 军事社会学/军事制度史的早期命题 |
| 战争二分(依政治内容判别战争性质) | 列宁《社会主义与战争》1915 | 克劳塞维茨命题的应用论:由"政治内容"读战争性质 |
| 群众性武装/人民武装 | 马恩论 1848 年前后革命与恩格斯论民兵制 | 与职业常备军传统并立的武装组织概念 |

## 这支最美的一个事实

恩格斯《军队》(1857)把军事组织形态本身当作可解释对象:
装备、编制、战术不是自足演化,而是**生产与交往方式的函数**——
军事思想史上第一次把"军队"从给定前提变成理论变项
(军事社会学谱系的起点之一,与本宇宙军制学家族的
制度研究问题域隔代相望——该家族待建,建后互链)。
