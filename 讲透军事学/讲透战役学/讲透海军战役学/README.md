# 讲透海军战役学 · 海上战役:制海权与交通线(GB/T 8303020)

> **支定位**:海上重兵(舰队/编队群)战役的通论——制海权的夺取
> 与保持、海上交通线的破与保、登陆战役的海上阶段、海区兵力
> 协同。海是最大的地幅,也是最快的衰减介质:看不见对手,
> 是海上战役的第一物理事实。
> GB/T 13745:83030 战役学 · 三级「海军战役学」。家族:
> [讲透战役学](../README.md)。

## 支定位与地盘

- 地盘:海上战役的目标体系(制海/交通线/兵力投送)、舰队决战与
  分散袭扰两种形态、破交保交(攻击与护航交通线)、登陆战役的
  输送与上陆保障、潜艇战与反潜战役、海区侦察与观察体系
- 与家族主干的关系:合同战役学支供通用语法,本支供海洋域的
  物理约束——能见度衰减、续航力半径、基地体系、水文气象
  (承军事地学之海洋侧,波 3 待建)
- 域内特殊性:海上没有"占领"——控制是过程性的(航线通断的
  时间积分),不是地块的占有;这使得海上战役的"阶段"更接近
  连续控制问题

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 制海权 | 在需要的时间海区使航运通、敌不通——控制是时窗不是地块 |
| 存在舰队 | 不决战而牵制:兵力存在本身改变对方航运决策 |
| 交通线(破与保) | 海上战役的主要账本——吨位与船期的攻防 |
| 输送与上陆 | 登陆战役的海上阶段:船期表锁定 H 时 |
| 观察体系 | 海上战役的感知地基:没有侦察就没有舰队决战 |

## ✨ 这支最美的一个事实

莱特湾海战(1944.10):史上规模最大的海战(通说)。数日之内,
锡布延海、苏里高海峡、萨马岛近海与恩加尼奥角四个方向的交战
构成同一战役窗口——诱饵与主力的分合、夜战水道的堵截、
护航航空母舰群与中心编队的遭遇,把海上战役的要素(侦察迷雾、
兵力分合、时间咬合)一次推到极限;苏里高海峡夜战并成为
战列线对轰的绝唱(通说)。**多方向交战共享一个战役目的
——"同一张协同表装下四个海区"**,是家族协同表结构的
海洋域极限测试。
