# 战役学思维技能卡(GB/T 83030 · 讲透战役学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「方面军群/战区军团**怎么协同**」「几个集团军的行动怎么咬合」
  ——翻译层作业需求
- 「战役**阶段怎么划分**」「阶段转换条件是什么」——阶段结构问题
- 「**兵力序列**怎么从战略目的推导出来」——翻译的输出端
- 「为什么**战术赢而战略输**」——层间界面病理
- 「**杀伤链/杀伤网/JADC2** 是什么、改变了什么」——网络介质
  时代的战役法(先问概念史层位)
- 「战役计划/协同表/任务编组怎么**结构化与校验**」——schema 级需求
- 「集中还是分散」「预备队留多少」——冗余的两种通货(兵力/路径)
- 学战略觉得太虚、学战术觉得太碎时——中间层的文法在此

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **翻译眼** | 看到"目的"先问:序列谁排的?阶段谁定的?协同表谁维护?没有这三个回答的目的只是愿望 |
| **界面眼** | 灾难住在层间界面——"战术赢战略输"的裂缝先于战场存在于参谋部 |
| **阶段眼** | 大行动=阶段×转换门(条件+判断者);没有门的阶段表是愿望清单 |
| **拓扑眼** | 看到任何"链"先问:有备份路径吗?断一环会怎样? |
| **瓶颈迁移眼** | 压缩一段流程,瓶颈必迁到下一段;优化前先问迁去哪(打击快了,发现就是新瓶颈) |
| **概念史眼** | 军事新词先问层位:"多域""杀伤网"装的常是 1920s 旧酒(跨域协同+同时性) |
| **参数即史观眼** | 推演结论先找参数来源,再看输出;节点时延谁定,结论归谁 |
| **冗余眼** | 兵力冗余(预备队)与路径冗余(网)是同一件事的两种通货;单链效率在第一次打击后归零 |

## 3. 工具箱(何时用什么)

- **阶段-决心-协同三件套**(03 章 schema):战役计划的语法树;
  计划合法性三问——门齐吗/快照带了吗/是 DAG 吗
- **F2T2EA 六环**(发现-定位-跟踪-瞄准-打击-评估):杀伤链
  的环节分解;美系军语,引用须声明体系
- **D1-D5 断言阶梯**:D1 建制文书→D2 条令→D3 通说战史→D4 演习
  →D5 推演;条令是"应该"不是"能够",推演输出不可当文书引用
- **杀伤网闭合模拟**(家族实验 `experiments/kill_web_closure.py`):
  单链 vs 网状的平均闭合/抗单点/抗三点/降级仍快五断言;
  min-of-k 指数解析锚内置
- **概念史节点表**(00 章 1.1):命名 1922-26/条令化 1933/西方入典
  1982-86——给任何"军事革命"话语定层的年表
- **执行态规则**:愿望态动词只准出现在"目的"栏;
  时段必须可对表(H±min,不写"拂晓")
- **军语对译表**(02 章):合同≠联合;operation≠campaign;
  deep battle≠deep operation——跨体系引用第一防坑

## 4. 常见误区与禁忌

- ❌ **把条令当实证**:「某条令写了所以能打」——规范性≠证据性
  (D2 冒充 D3/D4)
- ❌ **推演冒充文书**:兵棋/仿真输出是机器化反事实(D5),
  当建制文书引用是数字时代新病
- ❌ **无门阶段表**:只画阶段不写转换条件(条件+判断者)——
  那是幻灯片不是计划
- ❌ **越层书写**:战役文书里写营连战术动作——层间语法不容混用
- ❌ **崇拜新词**:不加概念史检查就接受"颠覆性"军事概念——
  先问它在 1920s 原始问题(同时性/纵深/协同时间)上的层位
- ❌ **单链最优**:只算无对抗下的效率,不算断一环的后果——
  关键路径必须有备份路径
- ❌ **敏感红线**:涉各国现行条令/装备只述公开学理与建制史实,
  中性学术语体,不断优劣、不引申时事;故事框只用历史典故
  与公开战史(二战及以前优先);导弹部队题材只写兵种战役学通论
