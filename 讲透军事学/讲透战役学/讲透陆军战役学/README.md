# 讲透陆军战役学 · 地面战役:门与纵深(GB/T 8303050)

> **支定位**:地面重兵集团(集团军/方面军级)战役的通论——
> 突破地带的选择、炮兵火力毁伤的战役运用、装甲兵团的纵深
> 发展。GB/T 注:本支**包括炮兵战役学、装甲兵战役学**
> (两个兵种战役学按 GB/T 原注并入,不分家)。
> GB/T 13745:83030 战役学 · 三级「陆军战役学」。家族:
> [讲透战役学](../README.md)。

## 支定位与地盘

- 地盘:地面战役的方向选择与布势、进攻(突破-发展-合围-追击)
  与防御(坚守与反突击)、炮兵火力毁伤体系、装甲兵团与快速集群
  的使用、方面军/集团军两级协同
- 与家族主干的关系:合同战役学支供通用语法,本支供地面域的
  物理约束——地形容量、道路与渡口、兵力密度上限、补给纵深
- 两个并入的兵种战役学(GB/T 原注):
  **炮兵战役学**=火力毁伤的系统运用(火力计划/弹药基数/时节
  咬合);**装甲兵战役学**=装甲兵团的战役使用(突击方向/速度/
  技术保障)——两者是地面战役的"火力拳"与"机动腿"

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 突破地带 | 门开在哪:窄正面高密度的力量投掷点 |
| 炮兵火力毁伤 | 用火力给门"预热"——火力与机动的时窗咬合 |
| 装甲突击方向 | 开门后往哪冲——指向敌体系要害而非正面 |
| 追击 | 合围后的第三段——不给敌重建平衡的时间 |
| 技术保障 | 装甲战役的隐形地基:坦克跑多远取决于抢修与油料 |

## ✨ 这支最美的一个事实

色当突破与海峡冲刺(1940.5):装甲集群穿过"不可通行"的阿登,
在色当地段强渡马斯河,随后不做停留地向西直插海峡沿岸——
**突破(渡河)与发展(冲刺)两段之间几乎无缝**,十日左右
割裂盟军南北联系(通说叙事)。这一役把"突破地带选择+装甲
突击方向+速度即安全"三件套一次演示完毕;同时它也是
**条令与直觉的错位标本**:联军的战役预案败于对地幅通行性的
误判——地面战役的第一变量从来是地形容量(承军事地学,
波 3 待建)。
