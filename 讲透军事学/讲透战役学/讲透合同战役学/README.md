## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 战役布势 | 梯队+快速集群+预备队的静态构型——力量在纵深里的排法 |
| 突破 | 打开门:在选定地段压倒防御,为纵深发展开口 |
| 快速集群 | 突破后进入交战、向战役纵深机动的骨干兵力 |
| 合围 | 关上门:多路向心会合形成对敌集团的封闭 |
| 战役协同 | 诸军兵种的时间契约——家族 03 章协同表的实践源 |
| 阶段转换门 | "什么时候算完"的条件+判断者——计划的控制论化 |

## ✨ 这支最美的一个事实

巴格拉季昂行动(1944.6):四个方面军梯次展开于白俄罗斯,1944 年
6 月 22 日发起(通说,恰在三周年纪念日),数日内维捷布斯克、
博布鲁伊斯克多处合围,7 月 3 日明斯克收复——第二梯队进入第一
梯队打开的缺口,形成"口袋里的口袋";德军中央集团军群受重创
(损失通说约 25-35 个师)。**大纵深理论 1933 年条令化、十一年后
的大体兑现:快速集群+梯次投入+多路合围的语法一次用全**——
理论与建制的时间差本身(家族 00 章反直觉之二)是比战果更深的
教材。
