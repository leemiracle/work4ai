# 讲透导弹部队战役学 · 火力毁伤与侦察-打击配套(GB/T 8303040)

> **支定位**:导弹部队战役运用的**兵种战役学通论**——火力毁伤
> 体系、侦察-打击配套、突击时节与弹药管理、生存性与持久性。
> 本支只写学理与建制史实,不涉任何国家现实作战计划
> (家族治理红线,置顶声明)。
> GB/T 13745:83030 战役学 · 三级「导弹部队战役学」。家族:
> [讲透战役学](../README.md)。

## 支定位与地盘

- 地盘(学理层):导弹火力对战役纵深目标体系的毁伤组织——
  目标选择与火力计划、侦察-打击-评估的时窗咬合、弹药基数与
  再打击决策、发射单元的生存性(机动/隐蔽/分散)与战役持久性
- 与家族主干的关系:合同战役学支供通用语法,本支供"火力拳"
  的专门文法——当火力可以越过接触线直达全纵深,"阶段"的
  时间结构从顺序变为并行
- 域内特殊性:导弹战役的瓶颈常在**侦察与评估**环(打出去快,
  看清楚慢)——家族 01 章瓶颈迁移律在本支最典型

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 火力毁伤体系 | 目标清单×弹药×时节的总账——"拳"的账本 |
| 侦察-打击配套 | 传感器与射手的数据链闭环(俄系公开文献称侦察-打击综合体,通说) |
| 突击时节 | 火力与机动/与其他军种行动的时间咬合点 |
| 再打击决策 | 评估环的输出:补打还是转目标——闭合循环的尾环 |
| 生存性编组 | 机动-隐蔽-分散的编组学:火力单元活得久,火力才持续 |

## ✨ 这支最美的一个事实

两枚历史锚(公开战史,通说):其一,1944-45 年弹道导弹对英
突击——人类首次导弹战役运用,无有效拦截手段,但精度与
侦察配套不足,军事效果与投入之比有限:**火力的射程先于
火力的眼睛到达**——侦察-打击配套问题的史前标本。其二,
1991 年海湾战争首夜,巡航导弹与隐身飞机的大规模精确突击
(公开战史通说):火力打在侦察画出的体系节点上——
**四十七年后,眼睛与拳头终于同速**。两枚锚之间的四十七年,
就是本支的全部学科史压缩包。
