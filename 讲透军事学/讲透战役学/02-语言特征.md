# 02 · 语言特征——战役文书的语法

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:战役学说的是一种**文书语言**——它的母语不是
> 论文,而是命令、计划与协同表;判断一门战役学写作的优劣,不看
> 文采,看**阶段是否可转换、序列是否可执行、协同是否可对表**。
> 三栏分别回答:这门语言能说什么(表达力)、它的断言受什么约束
> (逻辑性质)、它如何被标准化(规范化)。

---

## 0. 开篇:同一次决心 的两种文本

📖 **故事框:决心怎么落纸**。统帅层的表达是愿望态:"在冬季到来前
粉碎敌翼侧集团"。参谋部的表达是执行态:"西南方面军 11 月 19 日
转入进攻,当日突破;快速集群次日进入交战,向卡拉奇方向发展;
顿河方面军 11 月 20 日转入进攻……"(示意文风,天王星框架)。
两段话之间隔着的,就是本家族的全部语言工作——**愿望态到执行态
的改写**,靠四个语法装置完成:阶段划分、兵力序列、协同表、
时间表(D 日/H 时)。战役文书的语言,就是这四个装置的组装规则。

## 1. 表达力:战役语言能说什么(三栏之一)

**能说的**:

| 能力 | 例 |
|------|-----|
| 阶段划分 | "战役分准备/突破/发展/结束四阶段"——把连续的时间切成可管理的段 |
| 转换条件 | "快速集群在突破口打开(正面 x 公里)后进入交战"——阶段之间的门 |
| 兵力序列 | "A 集团军辖三个军,加强坦克军一"——单位-任务编组-加强 |
| 协同表 | "炮火准备 05:30-06:15,航空兵压制时段表"——跨兵种的时间咬合 |
| 时间语言 | D 日/H 时/战役第 N 昼夜——相对时间轴,命令可预写 |
| 空间语言 | 战役方向/作战地境线/当前经线——把战场切成责任分区 |
| 分支与后续 | "若敌主力东调,则……"——计划树的枝 |

**不能说的**(表达力边界,与生俱来):

- **不能进战术细节**:营连怎么冲击是战术层语法;战役文书里写
  战术细节叫越权(层间语法不容混用——00 章分层假设的语言面)
- **不能写士兵体验**:文书语言里没有疲惫与恐惧的格(军事心理学的
  领地,[../讲透军事心理学/README.md](../讲透军事心理学/README.md))
- **不能裁定"决定性"**:战役文书只能说"达成/未达成阶段目的",
  不能说"这一役决定了战争"——那是史家的事(军事史家族悬而未决)
- **不能说目的的正当性**:为什么而战是战略层与政治层的话;
  战役语言只有"目的"没有"正当"

## 2. 逻辑性质:断言的证据约束(三栏之二)

战役学断言的证据来源有四,各带结构性偏置:

| 来源 | 偏置 |
|------|------|
| 条令/纲要文本 | 规范性不是证据性——写的是"应该",不是"能够" |
| 战史(回溯) | 决心段证据最薄(承[军事史 02 章](../讲透军事史/02-语言特征.md)五段式) |
| 演习数据 | 可控但脚本化——"对手"是自己人扮演的 |
| 推演/仿真 | 机器化反事实,参数即史观 |

### 2.5 断言强度阶梯(战役学版 D1-D5)

| 阶梯 | 措辞 | 证据状态 | 战役学特有注意 |
|------|------|---------|---------------|
| D1 建制文书 | "作战命令/训令载" | 战时命令与总结档案 | 命令是"生成"的:写下的协同表常是事后修订版 |
| D2 条令级 | "某条令规定/某纲要载" | 规范文本在场 | **引用即立场**:各军语体系不可直接对译(§3 对译表) |
| D3 通说战史 | "战史通说认为" | 多源二手趋同 | 回溯解释;决心段按军事史纪律降档 |
| D4 演习级 | "演习数据表明" | 可控实验 | 对手扮演+脚本两重折扣 |
| D5 推演级 | "仿真/兵棋输出" | 机器化反事实 | **不可当 D1-D2 引用**;输出必附参数来源(04 章同款纪律) |

**误用告示**:把条令(D2)当实证(D3/D4)——"条令这么写所以
这么能打"——是战役学读物的头号病;把推演输出(D5)当建制文书
(D1)是数字时代的新病(与军事史家族"兵棋冒充档案"同源)。

### 2.6 三个内部语法规则

- **执行态规则**:战役文书只写执行态动词(转入/突破/合围/巩固),
  愿望态表达(争取/希望)出现在"目的"栏且仅此一栏——
  愿望态泄漏进任务栏,即计划不合规
- **可核对规则**:任何时段表述必须可对表——写"拂晓"不合规,
  写"H+360 分"合规;协同表的存在就是把整场战役钉死在
  可核对的坐标系上
- **转换条件规则**:阶段之间必须有显式的门(条件+判断者);
  没有门的阶段表是愿望清单(00 章阶段眼的语法面)

## 3. 规范化:军语与对译(三栏之三)

- 中文军语有成文规范辞书;跨体系写作(尤其苏/俄系与美系对读)
  必须声明所用军语体系——两系的"战役"不重合(见下表第一行)
- 度量:兵力(员额/建制数)、地幅(正面×纵深,公里)、
  时间(D 日/H 时)、火力(弹药基数)——四类单位不得混写

**军语对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 战役 | operation(苏/俄系);campaign(美系战局层) | 中文一词横跨两系两层;俄系 operation=一次方面军级行动,美系 campaign 由多个 operation 组成 |
| 战役学/战役法 | operational art | 不是"操作的艺术";苏俄术语直译,1920s 命名 |
| 战争层级 | levels of war | 1986 美条令入典;学界批判其为启发式(00 章问题 1) |
| 合同战役 | combined(-arms) operation | "合同"(兵种间)≠joint"联合"(军种间)——中文教材第一坑 |
| 大纵深战役 | deep operation | 与纵深作战 deep battle 分层:前者战役法,后者战斗法(01 章方向五) |
| 突击集团军 | shock army | 苏军编制术语,非"敢死军"义 |
| 战役布势 | operational formation | 布势≠部署 deployment:布势是静态构型 |
| 兵力序列/战斗编成 | order of battle / task organization | OB 是建制隶属,task org 是任务编组;快照必带 as_of |
| 决心 | (commander's) decision | 苏军传统里"决心"是文书类型,不只是心理状态 |
| 战役协同 | (operational) coordination | 协同=时间的咬合,不是隶属关系 |
| 阶段 | phase | 与"时节"(stage)常混用;阶段有转换条件,时节是描述段 |
| 突破/合围 | breakthrough / encirclement | 几何动作词;突破是打开门,合围是关门 |
| 战役重心 | operational center of gravity | 承克劳塞维茨 Schwerpunkt,非物理重心 |
| 攻势顶点 | culminating point | 后勤与损耗共同决定的"跳不动那一刻" |
| 空地一体战 | AirLand Battle | 1982 FM 100-5 术语;非"空陆战争"字面 |
| 多域作战 | multi-domain operations (MDO) | 域=陆海空天网电,概念谱系通说 |
| 杀伤链 | kill chain (F2T2EA) | 六环缩写属美系;引用须声明军语体系 |
| 杀伤网 | kill web | 2010s 末智库用词(01 章方向一) |
| 联合全域指挥控制 | JADC2 / CJADC2 | 组合式前缀 C 为 2020s 更名(检索校准 2026-09-07) |
| 战役欺骗 | operational deception(苏军 maskirovka) | 音译词含伪装+欺骗+保密三义 |

## 📌 收束

战役学的语言=**执行态文书语法(阶段/序列/协同/时间四装置)+
四源证据约束(D1-D5 阶梯)+跨体系对译纪律**。它写下的每个
动词都在等一次核对。下一章把这四个装置压成数据结构:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **执行态眼**:读任何计划,愿望态动词出现在哪一栏,哪一栏
  就是没想清楚的地方
- **对表眼**:时段表述必须可核对——不可对表的时间承诺
  都是修辞
- **军语体系眼**:引用外军概念先问体系(苏系还是美系),
  直接对译是事故之源
