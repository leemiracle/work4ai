# 讲透空军战役学 · 空中战役:制空权与体系对抗(GB/T 8303030)

> **支定位**:空中重兵(航空兵战役集团)战役的通论——夺取制空权
> 的空中战役、对纵深体系的独立空中突击、防空战役、航空兵对
> 地面/海上战役的支援。天空没有地形可守:空中战役的攻防平衡
> 由体系(机场-预警-指挥-掩护)而非阵地决定。
> GB/T 13745:83030 战役学 · 三级「空军战役学」。家族:
> [讲透战役学](../README.md)。

## 支定位与地盘

- 地盘:空中战役的目标体系(对方航空兵/机场/防空网/指挥预警
  节点)、夺取与保持制空权的行动、独立空中突击战役、国土与
  战区防空战役、支援陆海战役的航空兵使用(纵深遮断与近距支援)
- 与家族主干的关系:合同战役学支供通用语法,本支供空域的
  物理约束——出动强度(波次/架次率)、基地体系、气象窗口、
  空域避碰(deconflict 的原生域)
- 域内特殊性:空中战役以**出动波次**而非兵力占领计量——
  战役节奏的单位是"架次/日",消耗与再生产(机务/弹药/飞行员)
  并列为一等变量

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 制空权 | 某时段某空域的行动自由度——不是财产,是租约 |
| 出动强度 | 架次率:空中战役的第一产能变量(机务是隐形前线) |
| 防空体系压制 | 对对方防空网的体系性压制行动(SEAD,公开军语) |
| 纵深遮断 | 打对方战役纵深的后勤与二梯队——空域对翻译层的贡献 |
| 波次计划 | 空中协同表的形态:按波次钉死时窗与空域 |

## ✨ 这支最美的一个事实

不列颠空战(1940.7-10,通说窗口):一次以航空兵战役独立决定
战局的早期样本——德国航空兵先压海峡航运与雷达站-机场体系,
9 月初转向城市突击,战斗机防御体系的再生能力(飞机生产与
飞行员补充)因此获得喘息,进攻方最终未能夺取制空权,
登陆输送的前提消失(通说叙事)。**体系目标的取舍改变了
战役结局:打体系(机场/雷达)还是打意志(城市),是空中战役
目标清单学的第一课**;防空一方把"阶段转换门"设在体系再生
能力上——家族阶段眼的空中版。
