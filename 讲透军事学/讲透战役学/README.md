# 讲透战役学 · 战略与战术之间的翻译层(GB/T 83030)

> **战役学=战争层级的翻译层:把战略目的翻译成兵力序列、阶段行动
> 与协同表**。战略说"要什么",战术说"这一步怎么打";两句话之间
> 隔着一次真实的翻译——翻译得好,方面军群的每一次突击都踩在战略
> 的节拍上;翻译得坏,战术的每一次胜利都在替战略挖坑。这一层有
> 自己的名字很晚:1920 年代苏军命名"战役法"(operational art),
> 二战用大合围与跨海峡登陆把它写成实践,1980 年代才进入西方条令。
>
> GB/T 13745:83030(二级学科,军事学 830 之下;三级五条全建)。
> 宇宙:[讲透军事学](../README.md)。

## 〇、家族定位与成员

- 学科身份:军事学宇宙的**中间层**——战争层级(战略-战役-战术)
  的承重梁;上邻[讲透战略学](../讲透战略学/README.md)(翻译的输入:
  目的从哪来),下接战术学(波 3 待建;台阶怎么砌);军队指挥学与
  军事后勤学(波 3 待建)是协同与可持续性的承运人
- 与[讲透军事史](../讲透军事史/README.md)的分工:战役是战史的天然
  颗粒度——史家拆战例"发生了什么",本家族问"这颗粒是怎么被
  设计出来的";与[讲透军事理论](../讲透军事理论/README.md)的分工:
  理论供概念(战争观→打法),本家族供文法(打法→文书与计划)
- 横断工具:[讲透数学/讲透运筹学](../../讲透数学/讲透运筹学/)
  (指派/网络流/排队/可靠性——战役筹划形式化的正主)
- 敏感纪律:涉各国军队现行条令与装备按公开学科文献通说陈述,
  只述学理与建制史实,不断优劣、不引申时事;故事框只用历史典故
  与公开战史(二战及以前优先)

## 四、教材锚

- 斯韦钦《战略学》(1923——三层定义与"台阶-跳跃-路径"之喻的出生证明)
- 特里安达菲洛夫《现代集团军战役的特性》(1929——大纵深理论奠基)
- 苏军 1933 年暂行野战条令(PU-33——大纵深战役的条令化,通说)
- 美军 FM 100-5《作战纲要》(1982/1986——空地一体战与战役层入西方条令)
- 艾森豪威尔《欧洲十字军》(1948——战役筹划一手叙述,回忆录级使用)
- Biddle《Military Power》(2001——"现代军事体系",01 章重估对象)
- 军事科学院《战役学》教材体系(通说教科书,中文正典)
