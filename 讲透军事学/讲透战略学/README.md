# 讲透战略学 · 在战争之上研究战争（GB/T 83025）

> **战略学=在战争之上研究战争：如何在战争爆发前就赢——威慑、联盟、
> 地理与资源的总体筹划。**一句钉住：**"战术赢战斗，战略赢战争，
> 大战略赢和平。"**孙子在公元前五世纪写下第一命题（不战而屈人之兵），
> 克劳塞维茨与若米尼在十九世纪把它劈成两条路线，冷战把它从统帅的
> 艺术变成"可能终结文明的科学"——谢林《冲突的战略》（1960）把
> 威慑变成可分析的博弈。
>
> GB/T 13745：83025（二级学科，军事学 830 之下；三级：战略学理论/核战略学，
> 支名=GB/T 三级名）。宇宙：[讲透军事学](../README.md)。

## 〇、家族定位与成员

- 学科身份：军事学宇宙的**国家层级筹划层**——战争与和平之间的整个
  博弈带归本家族；战役军团/分队交战归兄弟家族
  [讲透战役学](../README.md)（波3）/讲透战术学（波3）
- 分层法（本家族的经线）：战术赢战斗 → 战略赢战争 → **大战略赢和平**——
  层级越高，暴力的比重越低、讨价还价的比重越高
- 与国际政治学的分工（一体两面，互链）：
  [讲透国际政治学](../../讲透国际政治学/)看**权力秩序**（均势如何形成），
  本家族看**暴力运用与遏制的筹划**（威胁如何设计、承诺如何可信）
- 跨宇宙工具链：[讲透数学/讲透运筹学](../../讲透数学/讲透运筹学/)
  （博弈论本体，宇宙层已声明弱链）；[讲透经济学/讲透国防经济学](../../讲透经济学/讲透国防经济学/)
  （战略资源与动员的经济侧）；[讲透军事理论](../讲透军事理论/README.md)
  （军事思想史——本家族的"经学史"）

## 四、教材锚

- 孙子《孙子兵法》（公元前 5 世纪，"上兵伐谋"原典）
- 克劳塞维茨《战争论》（1832，政治-道德路线）；若米尼《战争艺术概论》（1838，几何-计算路线）
- 利德尔·哈特《战略论：间接路线》（1954，大战略概念定型）
- 布罗迪《Strategy in the Missile Age》（1959，核战略学开山）
- 谢林《冲突的战略》（1960）/《军备与影响》（1966，威慑博弈化原典）
- 卡恩《论升级》（1965，升级阶梯）；沃尔斯泰特"恐怖平衡的脆弱性"（1959）
- 弗里德曼《Strategy: A History》（2013，通史）；军事科学院《战略学》（中文通论）
