## 诞生

原典即全家族的两条古根:孙子《孙子兵法》(前 5 世纪,"不战而屈人之兵"
第一命题)与克劳塞维茨《战争论》(1832,政治路线)/若米尼(1838,
几何路线)的分岔;利德尔·哈特《战略论:间接路线》(1954)把边界
扩到大战略("赢和平");谢林《冲突的战略》(1960)把威慑变成可分析
的博弈——本支的理论内核由此定型。

## 核心问题(带年代锚)

- **可信度悖论**:理性的威胁为何可信?"非理性才可信"?——谢林
  1950s-60s 提,承诺装置可缓解,无终解([家族 00 章](../00-体系结构.md)问题表)
- 威慑成功**不可观察**(1960 提,证据学至今未解——[家族 02 章](../02-语言特征.md)沉默证据)
- 间接路线 vs 决战:历史决定性胜利的来源统计之争——进行中
- 大战略的资源配置:联盟/经济/地缘的全工具筹划——与
  [../../../讲透经济学/讲透国防经济学/](../../../讲透经济学/讲透国防经济学/)共管
- 多对手威慑的均衡分析:三人以上无公认可解模型(悬而未决,
  [家族 01 章](../01-近五年创新.md)方向二)

## ✨ 这支最美的一个事实

谢林焦点(1960):两个陌生人在陌生城市失散,事先没约,却各自走向
中央车站——无沟通的协调博弈里,文化与环境自动"凸现"出一个解。
这一发现同时照亮军控(为什么有些数字成为谈判焦点)、危机(为什么
某些线是红线)与日常生活(默认选项统治一切):博弈论在谢林手里
从"解的存在性"变成"**解的选择**"——战略学给整个社会科学的礼物。

## 假设与依赖

理性行为体假设(组织政治与认知偏差是明码代价——Sagan/Jervis 批评
构成本支的反思层);国家中心假设(非国家行为体装不下,冷战后最大
功课);可沟通假设(信号失真与红线的边缘侵蚀)。三条假设的完整
"买到/付出"账目见[家族 00 章](../00-体系结构.md)第四节。
