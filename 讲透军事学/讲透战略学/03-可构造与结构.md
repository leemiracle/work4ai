# 03 · 可构造与结构——态势、条约与阶梯：威慑作为数据对象

> **本章回答五问之 Q4（可构造性与结构）**。
> **本质一句话**：战略学里"可构造"的不是威慑本身，而是
> **威慑的载体**——态势是成本矩阵+决策树，条约是条款-核查-
> 退出的法条结构，阶梯是离散化的冲突谱；"结构"是冷战七十年
> 沉淀下来的稳定性骨架：两支柱模型、MAD 均衡条件、军控的
> 条约语法。把威胁的语法（[02 章](02-语言特征.md)）变成
> 可以入库、可以对账、可以重跑的对象，是本章的全部内容。

---

## 0. 开篇：一个威慑态势=一张矩阵+一棵树+一本账

把"核威慑态势"翻译成可构造对象，需要三件套：**成本矩阵**
（双方在"克制/升级"组合下的支付，含贴现——[04 章](04-战略学转代码.md)
走廊二的直接输入）、**决策树**（危机各分支上双方的行动序列
与主观概率）、**核查账本**（条约义务 vs 观测记录的对账表）。
[00 章](00-体系结构.md)的威慑三要素（能力/可信度/沟通）
分别住进三件套：能力→矩阵的支付值，可信度→树上的主观概率，
沟通→账本的共享字段。**要素不可直接测量，载体可以**——
这是战略学构造学的第一原理（02 章 §2.6 结构性论证的落地）。

## 1. 什么是"可构造"的：六类战略对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **威慑态势** | 成本矩阵+贴现因子+决策树 | ✅ 高度可构造（04 章走廊一/二） | 支付值是**己方估计的对方估价**——双重主观性必须标注 |
| **升级阶梯** | 有向层级图（44 级是经典参数化） | ✅ 完全可构造（状态机的骨架） | 离散化是研究工具——级数与级距都是构造选择，不是自然类别 |
| **军控条约** | 条款结构（上限/核查/退出/退化条款） | ✅ 法条可完整结构化 | 条约文本≠遵守行为：履约记录是独立数据层 |
| **力量结构账本** | 分类账（发射器/弹头/载具，按部署状态） | ✅ 数据成熟（公开来源三栏） | 计数规则（什么算"部署"）本身是谈判产物——规则变更=断代 |
| **危机事件库** | 事件记录（时间/双方/信号/结果/档位） | ⚠ 半可构造：样本偏差结构性存在 | 02 章 §2.6：被威慑住的危机不进库——库头必须声明反面案例法口径 |
| **稳定度指标** | 构造性合成指标 | ⚠ 半可构造：可排序、难定标 | 01 章方向一悬题：多维稳定无公认温标——只做序数比较 |

**不可构造的**：意图（真值不存在于任何数据库）、可信度
（对方的主观概率）、威慑的"历史功效"（S5 反事实，
02 章 §2.5）、以及"升级会不会失控"的一般性答案
（[00 章](00-体系结构.md)问题表悬题——只能按态势逐一分析）。

### 1.5 六类对象的最小数据模式（动手者的 schema）

```yaml
# 威慑态势（走廊一/二的输入）
posture: {actor_a: str, actor_b: str,
          payoff_matrix: [[a_xy, b_xy]],        # x,y ∈ {克制, 越线}
                                                  # 值=己方对对方估价的估计
          delta_a: float, delta_b: float,        # 贴现因子（耐心）
          credibility_est: {source: 推断, tier: S4},   # 主观概率必须标档
          domain: 常规|核|网络|太空}

# 升级阶梯节点
ladder_node: {level: int, name: str,             # 卡恩 44 级或自定参数化
              vertical: 烈度, horizontal: 地理|域,   # 02 章 escalation 词典
              reversible: bool,                   # 可否降级——阶梯的关键属性
              evidence_tier: S1..S5}

# 军控条约条款
treaty_clause: {article: str, type: 上限|禁止|核查|退出|透明,
                number_cap: int|null, verification: 国家技术手段|现场|开源,
                withdrawal_notice: str,           # 退出条款（退约通知期）
                compliance_record: [{year, finding, tier: S1|S2}]}

# 力量结构账本行（公开来源三栏）
ledger_row: {category: 发射器|弹头|载具, count_claimed: int,
             est_institute: int, est_osint: int,  # 研究机构估计/开源推算
             counting_rule_version: str, as_of: str}   # 计数规则版本必填

# 危机事件
crisis_event: {year, parties, signals: [{action, read_threat, read_stability}],
               outcome: 威慑成立|威慑失败|未构成检验,
               method_note: 反面案例法口径, tier: S2..S5}
```

注意 `tier` 字段与"己方估计的对方估价"标注：把 [02 章](02-语言特征.md)
的 S 阶梯写进数据结构——**战略学数据的每一格都自带证据档与
主观性来源声明**，这是它与普通博弈论数据集的界河
（承 [../讲透军事史/](../讲透军事史/) 03 章"数据层自带证据等级"
同款纪律，战略学版把 T 档换成 S 档、把战损三栏换成能力三栏）。

## 2. 骨架一：稳定性的两支柱及其扩展（学科的概念主梁）

经典定义把战略稳定拆成两根支柱，01 章方向一记录了它的扩展争议：

| 支柱 | 定义 | 可构造形态 |
|------|------|-----------|
| 危机稳定 | 危机中**无先发诱惑**的态势性质 | 成本矩阵判据：先发支付−后发支付 ≤ 0（走廊二的 δ* 阈值就是它） |
| 军备竞赛稳定 | 无军备冲刺激励 | 行动-反应模型：一方增量引发对方反应的弹性系数（度量至今未解决——01 章方向四悬题） |
| （新）多边稳定 | 多对手下无"跳船/转嫁"激励 | 三人以上博弈——数学上仍是大坑（01 章方向二悬题） |
| （新）技术稳定 | 部署速度不快于对方认知更新 | 时间常数耦合模型——概念已有、度量未立 |
| （新）退化稳定 | 条约真空下自我约束替代核查 | 惯例稳定性条件（软法接口，[../../讲透法学/讲透国际法学/](../../讲透法学/讲透国际法学/)） |

两支柱是**冷战的参数化解**（两极+条约环境）；新支柱全部
是"多极+无条约"环境的提案——尚未获得经典那样的共识。
构造学姿态：支柱清单是**开放的 schema**，不是封闭的教条。

## 3. 骨架二：MAD 均衡条件（态势构造的范例）

把 [00 章](00-体系结构.md)反直觉②（"MAD 比单方优势更稳定"）
写成构造性命题，全家族最漂亮的一次"语言→结构"转换：

1. **态势参数**：双方存力量 S_A、S_B；先发打击可摧毁对方
   比例 α（依赖突袭性与防御能力）；后发报复可造成的损失 D
2. **均衡条件**：后发能力存在 ⇔ (1−α)·S ≥ 二次打击门槛
   ——此时先发支付 = 遭报复的损失 D，后发支付 = 克制，
   **先发无收益，威慑成立**
3. **防御的翻转**：一方部署防御（拦截率 d）使对方
   (1−α)·S·(1−d) 降到门槛下——**防御侵蚀对方的 Mutual**，
   破坏均衡——ABM 限条（1972）限防御不限进攻的条约逻辑
   即此（军控=把均衡条件写成法条）
4. **贴现的角色**： impatient 的行为体（贴现因子 δ 低）
   更看重"现在解决"，先发诱惑上升——δ* 阈值由此进入
   均衡条件（[04 章](04-战略学转代码.md)走廊二把整条
   命题跑成代码，实验 Part B）

**构造学教益**：一个战略命题只有写到这一步（参数化到可代入
数字），才从 S4 模型级陈述升格为**可检验的态势工具**——
数字代入仍然充满主观性（α/D/δ 全是估计），但**主观性的
位置显式了**（在参数里，不在逻辑里）。

## 4. 骨架三：军控的条约语法（把稳定性写成法条）

军控条约的构造解剖——为什么军控是"稳定性的工程设计"
（[00 章](00-体系结构.md)1.4）：

- **上限条款**：数量帽——焦点（Schelling point）的条约化：
  把谈判收敛的显著数字写进法条（焦点的制度固化）
- **核查条款**：国家技术手段（NTM）+现场核查+（新增）开源
  核查——把"可观察"从假设变成工程（02 章沟通要素的硬件层；
  01 章方向四"技术核查的崛起"是其当前前沿）
- **退出条款**：退约通知期——把承诺改造成**可退出但可观察**
  的结构（退出有声音，对方来得及反应——条约的稳定性不在
  永久，在退出的可预警性）
- **退化条款**：透明度措施/数据通报/热线——条约失效后的
  惯例残留层（01 章方向四"无条约军控"的法社会学）
- **对账机制**：条约数据的申报 vs 核查发现的差异处理
  ——军控版的"审计恒等式"（[04 章](04-战略学转代码.md)
  走廊四把它写成数据对账逻辑）

## 5. 从结构到比较：这套骨架买到了什么

- 两支柱 → 一切"X 是否破坏稳定"争论的**分诊台**（先问：
  破坏的是哪根支柱？危机还是竞赛？）
- MAD 均衡条件 → 态势评估的可算框架（参数化把辩论从
  修辞移到参数表）
- 条约语法 → 军控史的比较工具（每一条条约都能按
  上限/核查/退出/退化四件解剖，比较其稳定性设计）
- 阶梯结构 → 危机沟通的共同坐标系（"第几级"是有噪声的，
  但比"很紧张"可操作）

## 6. 构造合法性清单（动手前三问）

把任何战略材料变成数据结构之前，先过三问——本家族的
"类型检查"：

1. **主观性定位了吗**：支付值/概率是**谁估计的谁的估价**？
   未标注来源与 S 档的矩阵是沙上建筑
2. **计数规则版本写了吗**：力量账本的数字不注明计数规则
   与 as_of 日期，跨年比较必然出假断代（军事史"快照眼"
   的战略学版）
3. **样本口径声明了吗**：危机库必须注明"未包含被威慑住的
   案例"（02 章 §2.6 沉默证据）与反面案例法的使用方式

三问全过，数据才获得进入 [04 章走廊](04-战略学转代码.md)
的资格。**战略学计算的第一特征不是算法，是把主观性显式化
的入库纪律**。

## 📌 收束

可构造的是**载体**（矩阵/法条/阶梯/账本），不可构造的是
**意图与功效**；结构不是装饰，是稳定性从修辞变成工程的
脚手架。下一章把 schema 接上代码：讨价还价、阈值、阶梯、
对账、核查、信号六条走廊：[04-战略学转代码](04-战略学转代码.md)。

**🧠 认知升维（这章给了你什么新眼睛）**：

- **载体眼**：测不了威慑，测得了态势——把不可测的大词
  翻译成可入库的载体，是这门学科的方法论核心动作
- **参数眼**：争论发生时先找参数表——主观性藏在哪个参数里、
  谁填的值，比争论结论更值得看
- **支柱分诊眼**：听到"破坏稳定"，先问哪根支柱——
  危机/竞赛/多边/技术/退化，五根支柱的病不一样
