# 军队政治工作学思维技能卡(GB/T 83050 · 讲透军队政治工作学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「士气怎么量化」「士气调查怎么做才可信」——测量问题
- 「为什么越补人战斗力越弱」「个体替换 vs 单位轮换怎么选」
  ——替换制度悖论(00 章反直觉①)
- 「凝聚力到底指什么」——任务/社会/组织/精神四分量
- 「道德损伤 PMIE 是什么」「人员制度跟心理健康什么关系」
  ——剂量侧接口(01 章热线四)
- 「动员/教育/奖惩为什么失效」——语法层级错配(02 章)
- 「荣誉奖励发多了会怎样」——承认通货的通胀
- 团队 churn/onboarding/激励设计、无应答数据治理——工程师反查
- 凝聚力量表/士气调查/轮换参数的数据化——schema 级需求

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **存量眼** | 战力=人数×人的系数,而人的系数是存量:补人补不了存量,先看纽带账本 |
| **分量眼** | 凝聚力不是一个数:横向/纵向/组织/精神分头测量、分头干预 |
| **比较眼** | 士气是比较量(相对剥夺律):无参照系的士气断言没有真值 |
| **谱眼** | 个体替换↔单位轮换是参数谱不是站队题:粒度×同步性×重训期 |
| **层级眼** | 教育(长时效)/组织(即时)/动员(分钟级)三层语法,错配即失效 |
| **账本眼** | 不听组织说什么,看它奖励什么:人事文书是价值观的实缴资本 |
| **无应答眼** | 缺的每份问卷都有偏向:无应答率是第一指标,不是数据噪声 |

## 3. 工具箱(何时用什么)

- **士气学五幕编年**:演说→荣誉建制→凡尔登轮换与二战社会
  测量→个体替换教训→标准模型与纵向证据——判断任何"人心
  工程"宣称的历史坐标(00 章)
- **纽带存量-流量图**(03 章§3):入流(共同经历)/出流
  (减员·调动·服役期满)→ 稳态存量 → 战力系数;恶性循环
  的回路图
- **替换队列零模型**(家族实验 `experiments/cohesion_replacement.py`):
  A 整建轮换 vs B 个体补员,断言稀释律/稳态差/战损比/
  扩大律——越战人员管理教训的机器化
- **凝聚力四分量**:横向战友/纵向领导/组织承诺/精神士气
  (标准模型,01 章热线一 2025 修订)——体检单不是总分
- **语法三级**:教育(内化)/组织(执行)/动员(情绪)
  + 不变式:人事文书不得推翻价值观表述(02 章)
- **承认通货律**:荣誉的价值=稀缺性×可信度;滥发通胀、
  错发破产(02 章§2.6)
- **无应答三问**:口径版本?应测分母?谁没填?——问卷数据
  的合法性检查(03 章构造清单)

## 4. 常见误区与禁忌

- ❌ **补员幻觉**:「缺人就补人,战力恢复」——战力是老战友
  比例的函数;个体替换的稳态是永久半新兵(实验断言①)
- ❌ **把士气当情绪**:士气是意志与耐受的比较量——改善绝对
  条件可能完全不动士气(参照组同步动)
- ❌ **总分崇拜**:用单一凝聚力分数考核单位——平均数吞掉
  分量病(抱团排外也能得高分)
- ❌ **信念可指令**:把"为何而战"写成命令口吻/积分任务——
  内化通道关闭,挤出效应启动
- ❌ 插补无应答:把不填问卷的人当平均值处理——等于把病修掉;
  无应答必须作为第一指标报告
- ❌ 仿真当检验:队列模拟是命题的化身(序数结论),不是
  任何真实组织的战损预言
- ❌ **敏感红线**:按军事组织行为学通说写作;不评价任何国家
  现行政治制度、军队政策与人物;不展开各国军队政治教育
  的意识形态内容与比较优劣;不涉任何现实军队实务
