## 0. 开篇:一个百年制度之争,三分钟跑出数

「个体替换侵蚀凝聚力」——这条越战人员管理教训的通说命题
(00 章§1.4)能不能用数据说话?

`experiments/cohesion_replacement.py` 把两个营位建成两条
减员-补员流水线:A 营位整建制作战+整建制轮换(满 D 轮部署
换一个共同训成的新营);B 营位同一个营常驻,减员即时回填
个体新兵+个人服役期满即单独离队。凝聚力=老战友比例的函数
(共处≥T 轮的两人比例),战斗力=凝聚力×训练水平,新兵
超额战损(任职初期风险最高)。48 轮蒙特卡洛跑出四个断言:

- **稀释律**:B 营凝聚力从满值下滑到远低于 A 的稳态
- **稳态差**:A 营位平均部署凝聚力显著高于 B 营稳态
- **战损比**:B 营位人均战损率显著高于 A(凝聚力折成战损)
- **扩大律**:双方累计战损差随轮次单调扩大(恶性循环)

但脚本同时打印建模边界:纽带仅以共处时长代理(领导力/
信念/选拔未建模)、参数=人员政策假设。**代码替你算制度,
替不了你算人心**——本家族数字化的第一课。

## 1. 可机械化边界(三件套之一):信念生成之辩

**能进代码的**(人心数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 制度比较 | 替换参数组 → 队列模拟/稳态凝聚与战损差(家族实验) |
| 量表计分 | 条目应答 → 分量得分+分量剖面图(C2) |
| 调查质量监控 | 记录流 → 无应答率预警+口径漂移检测(C3) |
| 参数扫描 | 替换谱 × 战损率网格 → 权衡前沿(C4) |
| 承认经济学 | 奖惩流水 → 稀缺度通胀指标(C5,描述级) |
| 暴露剂量 | 部署节奏/轮换方式 → PMIE 暴露面估计(01 章热线四接口) |

**不能进代码的**(本家族的"不可判定域"):

1. **信念生成之辩**:算法可以排序教育方案、模拟制度、预测
   疲劳——但"为何而战"的目的生成是价值判断;**剂量可算,
   意义不可算**。更深一层:价值观表述是组织的宪法层,
   它的裁定与担责必须是人——不是认识论限制,是**责任结构
   的限制**(与[军队指挥学 04 章](../讲透军队指挥学/04-军队指挥学转代码.md)
   "选项生成可机械化、选项裁定不可"同构)
2. **内化的检验**:可以统计课时与考核通过率,不能测出
   "信没信进去"——行为指标(留队率/申诉/战时表现)是滞后
   且噪声大的替代指标(02 章"不能传递信念本身"的代码回声)
3. **纽带的完整生产函数**:共处时长是纽带的最强代理,
   不是纽带本身——领导质量、任务意义、选拔相容性全部
   未建模;模拟输出是制度侧的序数结论,不是组织命运
   的基数预言

> 边界的一句话:**代码是人事部门的沙盘,不是信念的工厂**。
> 队列推十遍,不如共同任务干一次。

## 3. C2 凝聚力量表计分走廊(最小示例)

分量计分+剖面图(03 章 cohesion_scale schema 的最小落地):

```python
# 四分量计分(03 章标准模型;reverse 条目反向计分)
COMPONENTS = ("横向", "纵向", "组织", "精神")

def score(items):
    """items=[(component, ans_1to5, reverse)] -> 分量得分+剖面。"""
    prof = {c: [] for c in COMPONENTS}
    for comp, ans, rev in items:
        prof[comp].append((6 - ans) if rev else ans)
    return {c: sum(v) / len(v) for c, v in prof.items() if v}

raw = [("横向", 5, False), ("横向", 4, False), ("纵向", 2, False),
       ("组织", 4, True), ("精神", 5, False)]   # "组织"条目反向陈述
p = score(raw)
assert abs(p["组织"] - 2.0) < 1e-9 and p["横向"] == 4.5, "反向计分+分量均值"
print("分量剖面:", p, "——总分时代会把它平均成 4.0,病症全被吞掉")
```

十行完成的事:一份问卷 → 四分量剖面。计分器管"分量分开"，
管不了"测得准不准"——效度是量表版本的事(03 章三问之一)。

## 4. C3 无应答预警走廊(最小示例)

士气越低的单位越不填问卷——无应答是数据,不是噪声:

```python
def survey_health(eligible, respondents, unit):
    """无应答率>20% 即红旗:幸存者偏差结构性存在(03 章三问之二)。"""
    nr = 1 - respondents / eligible
    flag = "红旗:得分按幸存者处理" if nr > 0.20 else "可用:仍须报告无应答率"
    print(f"{unit}: 应测 {eligible}, 实测 {respondents}, "
          f"无应答率 {nr:.0%} —— {flag}")
    return nr

assert survey_health(300, 282, "1营") <= 0.20      # 6%:可用
assert survey_health(300, 180, "2营") > 0.20       # 40%:红旗
print("结论:2营的『士气高分』首先是『填问卷的人』的士气")
```

**走廊警告**:无应答与士气负相关——把它当缺数据补齐
(插补均值)等于把病修掉;唯一诚实做法是把它作为第一指标
  报告(02 章参照系眼的代码面)。

## 6. C5 承认经济学走廊(描述级)

奖惩流水的稀缺度分析:某类奖励的期间发行密度(发行数/
同规模人数)时间序列——密度上升=通胀预警,荣誉的
符号价值按 02 章§2.6 的通货逻辑贬值;定性结论可期,
量化验证需行为指标(申报率/展示率)反推,按描述级处理。

## 7. 工程师落点(本家族给你的工程赠礼)

- **团队粘性管理**:软件团队的"老兵比例"就是纽带存量——
  逐人替换的维护团队 vs 整组轮换(平台组全组交接),
  与 A/B 营位同构;把 T_BOND(成钮时长)读作新人上手期
- **新人风险期**:新人事故/缺陷率显著高于均值期
  (ramp-up 风险窗口=NEWBIE_RISK 的工程对应物)——排班
  与发布窗口的人事侧约束
- **无应答即信号**:系统可观测性的组织版——监控覆盖率
  下降本身就是事故前兆,不是"少几个指标";survey fatigue
  的治理与士气调查同题
- **徽章经济学**:开源贡献徽章/游戏成就=承认通货的数字版
  ——稀缺性与可信度决定它是激励还是通胀(拿破仑勋位的
  产品化转世)
- **轮换与值守**:on-call 轮值整组交接 vs 逐人穿插——
  疲劳与默契的权衡,替换谱的直接应用

**走廊三警告**(承[军队指挥学 04 章](../讲透军队指挥学/04-军队指挥学转代码.md)警告同源):

1. **参数=人员政策假设**:服役期/成钮时长谁定的,结论就
   归谁——引用模拟结果必附参数来源
2. **仿真输出=机器化的反事实**:队列模拟的稳态是命题的
   化身,冒充实兵检验是数字时代新病
3. **量表≠构念**:计分再准也只是代理——测量效度未验证的
   得分,按自评文学处理,不按组织行为学处理
