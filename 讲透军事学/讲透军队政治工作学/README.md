# 讲透军队政治工作学 · 人心:军队的士气-凝聚力系统(GB/T 83050)

> **军队政治工作学=研究战斗集体"人的系数"的组织科学——士气、凝聚力、
> 组织承诺与人事制度,如何把千万个体粘成一个能承受损耗的集体**。
> 按学科通说,本家族以军事组织行为学框架展开:军队指挥学是神经
> (决心变行动),军制学是骨架(编制与体制),**本家族是血与心
> (信念-士气-凝聚力的生成与养护)**。一句钉住:
> **"防线在地图上被突破之前,先在纽带上被突破。"**(纽带论)
>
> GB/T 13745:83050(二级学科,军事学 830 之下)。宇宙:[讲透军事学](../README.md)。

## 〇、家族定位与成员

- 学科身份:830 宇宙的**人的组织层**——战略/战役/战术(83025-83035)问
  怎么打,指挥(83040)问决心怎么执行,军制/后勤(83045/83055)问
  怎么编怎么供,本家族问:**"编进去、供上去的那群人,凭什么还愿意
  并能够继续战斗"**——士气(燃料)、凝聚力(结构)、人事制度(循环)
- 消歧三邻(与兄弟家族分工):

| 家 | 关系 | 领地 |
|---|---|---|
| [军事心理学](../讲透军事心理学/README.md) | 互链(士气侧分工) | 士气的**心理测量与机制线**(量表/应激/道德损伤的心理学)归那边;士气的**建制动员线**(教育/组织/人事制度设计)归本家族 |
| [军队指挥学](../讲透军队指挥学/README.md) | 神经↔人心 | 指挥学管决心变指令(组织认知);本家族管组织里的人变集体(组织粘性)——任务式指挥的地基"互信"两家里应各写一半 |
| 军制学(83045,波3待建) | 骨架↔士气 | 编制体制是骨架(静态结构);本家族管骨架里的血液循环(人事政策运行) |

- 跨宇宙挂靠:初级群体/群体动力学的**社会学本体**在
  [讲透社会学](../../讲透社会学/);量表与测量理论的**心理学本体**在
  ../讲透心理学/(待建 190,归入声明)——本家族只承接军事场景侧
- 敏感纪律:本家族按**军事组织行为学通说**写作(士气/凝聚力/组织
  承诺/人员制度四件套);学科史实中性呈现,不评价任何国家现行
  政治制度、军队政策与人物,不展开各国军队政治教育的意识形态
  内容与比较优劣,不涉任何国家现实军队的实务细节
