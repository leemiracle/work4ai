# 讲透军队组织工作学 · 战斗集体的人事引擎(GB/T 8305020)

> **定位句**:这支是 83050 的制度主干——把个体粘成集体的组织
> 装置:人事管理、奖励与纪律制度、组织建设、轮换与替换政策
> (按军事组织行为学与人事制度研究的学科通说展开)。一切
> "纽带存量怎么攒、怎么漏、怎么管"的问题在此立法。
> GB/T 13745:8305020 军队组织工作学(三级学科,83050 之下)。
> 家族:[讲透军队政治工作学](../README.md)。

## 诞生

建制源点是凡尔登轮换制(1916,noria:师定期轮换+休假权+后方
保障,家族 00 章美之时刻②)。二战把它变成社会科学:Stouffer 等
(1949)的士气测量给出制度变量。战后个体替换制的实践与反思
(个人服役期到点即走+减员即时回填,以越战人员管理为代表案例,
通说)是本支核心教案;Henderson《Cohesion: The Human Element
in Combat》(1985)把教训理论化;1980 年代 COHORT 类单位人事
实验是制度修正的建制尝试。当代形态:Siebold 标准模型(2007/
2025 修订)下的凝聚力量表+替换制度参数化(家族实验)。

## 核心问题(带年代锚)

- **个体替换还是单位轮换**——权衡未决:凝聚力存量 vs 在役率/
  换防运力(家族 00 章反直觉①;实验的机器化)
- 奖惩制度的设计边界——通说:承认通货律(稀缺性×可信度,
  滥发通胀,02 章§2.6)
- 组织承诺的双层结构——进行中:对班组的承诺≠对建制的承诺
  (标准模型分量,01 章热线一)
- 骨干保留与梯队建设——进行中:纽带存量的"关键节点"问题
- PERSTEMPO(部署节奏)的可持续线——进行中:节奏过密,
  单位轮换也会磨损(03 章§4 替换谱第三参数)

## ✨ 这支最美的一个事实

凡尔登(1916):流传百年的是"他们不得通过"的口号,真正守住
防线的是那套不起眼的制度——师定期轮换进出、休假权、后方热食、
"神圣之路"补给公路(通说叙事,证据级 T3)。**口号给了历史
一个记号,制度给了口号一个兑现机制**:鼓舞决定峰值,制度决定
耐力,而耐力才是消耗战的胜负手。本支的全部内容是这个时刻的
参数化延长线。

## 假设与依赖

标准士兵假设(人员可替换的"标准件"——本支的制度前提,
也是它的头号批判对象,家族 00 章假设二);凝聚力可加假设
(标量考核的代价:分量混同);测量依赖:凝聚力量表版本口径
漂移(03 章构造清单三问);文化偏置:替换制度文献以美军案例
叙事为主(通说引用须注明,不延伸评价)。
