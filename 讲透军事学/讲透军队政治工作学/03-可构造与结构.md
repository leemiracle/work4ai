# 03 · 可构造与结构——量表、调查、制度参数:人心作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:本家族里"可构造"的不是信念与荣誉感本身,
> 而是**它们的容器与回路**——凝聚力量表是分量结构、士气调查
> 是带无应答率的记录流、轮换与替换制度是参数组;而"结构"是
> 这门学科自己的骨架:三层凝聚(初级群体/组织/精神)、纽带
> 的存量-流量、个体↔单位的替换谱。

---

## 0. 开篇:一支军队的人心系统=一张量表+一条调查流+一组制度参数

打开任何一个建制的"人的系统",你都会看到同样的三件套:
定期滚动的**士气/凝聚力调查**(记录流:条目-应答-无应答);
一套**量表计分规则**(把应答折成分量得分);一组**人事制度
参数**(部署长度、个人服役期、补员方式)。军队是人事记录
最密的组织之一(名册/奖惩/轮换令),所以人心虽是最软的对象,
其制度容器却出奇地结构化——这是 04 章有走廊可走的前提。

## 1. 什么是"可构造"的:四类人心对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **凝聚力量表** | 分量结构(条目→子量表→分量得分) | ✅ 高度可构造(§1.5 schema) | 总分混同分量(01 章热线一);分量口径随版本漂移 |
| **士气调查** | 记录流(单位×时点×条目×分布) | ✅ 可构造 | **无应答率本身是士气指标**——漏掉它等于丢一半数据 |
| **轮换/替换制度** | 参数组(D/T/R/补员规则) | ✅ 高度可构造(家族实验) | 参数=人员政策假设,引用须附来源 |
| **奖惩制度** | 承认通货的发行规则(稀缺度×可信度) | ✅ 半构造(规则可写,估值难) | 通胀不可直接观测,须以行为指标反推 |

**半可构造的**:组织承诺(量表近似,自评偏差);道德损伤的
暴露面(PMIE 事件清单可数,主观权重不可数);参照系(相对
剥夺的比较组可问出来,但随时漂移)。

**不可构造的**:信念生成本身(价值判断的内化)、荣誉感的
意义内容、"为何而战"的那个"为何"——可构造的是容器、流程
与剂量,**不是内容**(04 章可机械化边界的正主)。

### 1.5 四类对象的最小数据模式(动手者的 schema)

```yaml
# 凝聚力量表(标准模型的分量结构,01 章热线一)
cohesion_scale: {scale_id: str, version: str,   # 版本必填:改量表=翻案
                 items: [{text: str, component: 横向|纵向|组织|精神,
                          reverse: bool}], scoring: 均值|加总,
                 norm: {sample: str, year: int}}

# 士气调查(一次单位级施测的记录)
morale_survey: {unit: str, as_of: date,
                respondents: int, eligible: int,     # 分母必填
                no_response_rate: float,             # 无应答率=第一指标
                scores: {morale: float, cohesion_*: float},
                instrument: scale_id@version}        # 口径声明

# 轮换/替换制度(家族实验的全部参数面)
rotation_policy: {mode: 单位轮换|个体替换,
                  deploy_len: int,        # D:单次部署轮数
                  tour_len: int,          # T:个人服役期轮数
                  replenish: 整建制|即时回填,
                  reconstitute: int,      # R:换防后重训期
                  perstempo: float}       # 部署节奏(在役率侧的代价)

# 奖惩事件(承认通货的流水)
award_event: {unit: str, person: str, type: str, as_of: date,
              scarcity: float}    # 该类奖在同期同规模的发行密度
```

注意 `version` 挂在量表上、`no_response_rate` 是必填字段、
`eligible`(应测分母)与 `respondents` 分列——把 02 章的语言纪律
写进数据结构:**数据层自带口径声明与无应答标注,是本家族计算
区别于普通"问卷平台"的第一特征**。

## 2. 骨架一:三层凝聚结构(构念的拓扑)

- 标准模型(Siebold 2007;2025 修订,01 章热线一):
  **横向纽带**(战友间)、**纵向纽带**(与直接领导)、**组织
  承诺**(对建制)、**精神士气**(对更大单位的自豪)——
  四个分量不是一个大小的四种说法,是可以分头测量、分头
  干预的四样东西
- 分层的政策含义:同一支军队可以纵向强横向弱(惧官不爱兵友)、
  组织承诺高精神士气低(认编制不认荣誉)——**干预点完全不同**;
  总分时代这些病全被平均数吞掉
- 与[军事心理学](../讲透军事心理学/README.md)的接口:分量的
  测量理论(信度/效度/因子分析)在那边,分量的制度干预面
  (怎么设计经历让分量生长)在本家族

## 3. 骨架二:纽带的存量-流量图(组织的心循环)

```
        ┌────────── 纽带存量(老战友比例)──────────┐
        │                                          │
   入流:+共同经历时长          出流:-减员/调动/服役期满
        │                                          │
        └──→ 凝聚力=存量/N²的函数 → 战斗力系数 ──→ 战损率
                        ▲                          │
                        └─── 战损又改进入流(新兵)───┘
```

- 凝聚力的生产函数:共处时长×共同任务强度(成钮时长 T 是
  阈值参数)——**存量思维**:补人补不了存量,只有时间+任务
  能补
- 个体替换制把出流开到最大(服役期满即走+减员即时回填),
  稳态存量由入流出流比决定——**恶性循环**:存量低→战损高→
  回填多→存量更低(家族实验断言④的机制)
- 单位轮换制把出流集中到换防瞬间,部署期内存量近似守恒——
  代价记在别处:在役率与换防运力(制度权衡的另一半,
  00 章反直觉①)

## 4. 骨架三:替换谱(个体↔单位的连续统)

- 个体替换 ↔ 单位轮换不是二值选项,是参数谱:补员粒度
  (一次换多少人)、同步性(同时进出还是滚动)、重训期 R
  (换防后给多久再粘合)——COHORT 类单位人事实验可视为
  谱上的一个点
- 谱上的位置决定纽带的稳态水位(03 章生产函数)与组织的
  灵活性(跨单位调配/紧急扩编的难度)——**位置=凝聚力×
  灵活性权衡点**,没有占优解,只有情境解
- PERSTEMPO(部署节奏)是谱外的第三参数:节奏过密,
  单位轮换也会磨损(重训期被压扁)——三参数联合决定
  系统的可持续性

## 5. 从结构到比较:这套骨架买到了什么

- 量表分量结构 → 凝聚力的"体检单"从总分变四项,暗面可测
  (01 章热线一的制度落点)
- 存量-流量图 → "补员速度≠恢复速度"从直觉变公式
  (家族实验的机器化)
- 替换谱 → 制度争论从站队变参数扫描:给定情境
  (战损率/扩编需求),最优位置可算——**权衡显式化**

## 6. 构造合法性清单(动手前三问)

把任何人心材料变成数据结构之前,先过三问——本家族的
"类型检查":

1. **口径声明了吗**:量表版本/条目集注了吗?——不注版本的
   凝聚力得分,跨研究比较是数字游戏
2. **无应答入账了吗**:应答率/应测分母带了吗?——士气越低
   的单位越不填问卷,幸存者偏差是结构性的
3. **参数来源呢**:制度参数(部署长度/服役期/成钮时长)
   谁定的?——参数=人员政策假设,不注明来源的模拟按
   教科书处理,不按组织行为学处理

三问全过,数据才获得进入 [04 章走廊](04-军队政治工作学转代码.md)
的资格。**本家族计算的第一特征不是算法,是口径与无应答的
入库纪律**——这一条把它与普通调查平台划开界河。

## 📌 收束

可构造的是**容器与回路**(量表/调查流/制度参数),
不可构造的是**信念与意义**;结构不是装饰,是分量干预与
制度权衡的检验坐标系。下一章把这些 schema 接上代码:
减员-补员队列、量表计分、无应答预警四条走廊:
[04-军队政治工作学转代码](04-军队政治工作学转代码.md)。

**🧠 认知升维**:

- **存量眼**:人心指标先分存量与流量——补得进流量,
  补不进存量;只看流量的报表都在骗人
- **分量眼**:凝聚力不是一个数——四分量分头测量、分头
  干预,平均数是暗面的遮羞布
- **谱眼**:制度选项先摆上参数谱——个体↔单位是一条轴,
  站队式辩论是懒惰的参数扫描
