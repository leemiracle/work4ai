# 💻 第 3 幕 · 代码：最小 Agentic 生成回路

第 1 幕说「Agentic = 生成→执行→看反馈→再改」。这里实现这个闭环（用模拟的 LLM，不依赖真 API）。

```python
import subprocess
import tempfile
import os

class FakeLLM:
    """模拟 LLM: 根据反馈迭代修复代码(demo 用)."""
    def __init__(self):
        self.attempt = 0
        # 模拟: 第 0 次 bug (用了不存在的 printn), 第 1 次修复
        self.buggy = "def add(a, b):\n    return printn(a + b)"
        self.fixed = "def add(a, b):\n    return a + b"

    def generate(self, task, feedback=None):
        self.attempt += 1
        if feedback and "printn" in feedback:
            return self.fixed, f"# attempt {self.attempt}: 修复 printn -> 直接 return"
        return self.buggy, f"# attempt {self.attempt}: 初版"

def execute_code(code):
    """执行生成的代码, 返回 (ok, output/error)."""
    with tempfile.NamedTemporaryFile(mode="w", suffix=".py", delete=False) as f:
        f.write(code + "\n\nprint(add(2,3))")
        path = f.name
    try:
        r = subprocess.run(["python3", path], capture_output=True, text=True, timeout=5)
        os.unlink(path)
        if r.returncode == 0:
            return True, r.stdout.strip()
        return False, r.stderr.strip().splitlines()[-1]  # 最后一行错误
    except Exception as e:
        return False, str(e)

def agentic_loop(task, max_iters=5):
    """生成-执行-反馈闭环."""
    llm = FakeLLM()
    history = []
    for i in range(max_iters):
        # 1. 生成
        feedback = history[-1][1] if history else None
        code, note = llm.generate(task, feedback)
        print(f"\n--- iter {i} ---\n{note}\n代码:\n{code}")
        # 2. 执行
        ok, out = execute_code(code)
        history.append((code, out))
        print(f"执行结果: {'✓' if ok else '✗'} {out}")
        if ok:
            print(f"\n🎉 {i+1} 次迭代后成功! 输出: {out}")
            return True, i+1
    return False, max_iters

if __name__ == "__main__":
    print("=== 最小 Agentic 代码生成回路 ===")
    ok, iters = agentic_loop("写一个 add 函数")
    print(f"\n总结: {'成功' if ok else '失败'}, 用了 {iters} 次迭代")
    print("\n洞察: 这个闭环就是费曼 F1-F4 (做→卡壳→修正→回炉).")
    print("真实系统里 LLM 换成 GPT/Claude, execute 换成跑测试套件.")
    print("SWE-bench 从 13%→50%+ 靠的不是模型变强, 是引入了这个执行反馈闭环(=耗散结构).")
```

## 这段代码教什么

1. **闭环结构**：generate → execute → feedback → regenerate
2. **反馈驱动修复**：LLM 根据 stderr 定位 bug（这里模拟「看到 printn 错误就修」）
3. **耗散结构**：每次执行是负熵注入，把统计噪声泵出系统
4. **可扩展**：FakeLLM 换真 API、execute 换测试套件、加 file ownership 支持多 agent
