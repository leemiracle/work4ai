# 讲透非洲史 · 人类摇篮的自我书写

> 非洲史：**人类 30 万年故事里最长的章节、却最晚被书写的一卷**——
> 它研究人类的起源大陆如何长出文明、经受奴隶贸易与殖民、并以 54 个现代国家
> 回到历史主语的位置。核心难题只有一句话：**没有文字的社会如何写史？**
>

## 诞生（作为学科的非洲史）

非洲的过去不缺史，缺的是**被承认的史学**。殖民时代的主流论调是"非洲无史"
（黑格尔《历史哲学》公然把撒哈拉以南划出世界史）。转折三步：
①1897 年英军焚掠贝宁城，青铜器流入欧洲，无声反证了非洲文明的高度；
②1948 年达喀尔-伊巴丹的大学建制起步，**尼日利亚的 K. O. Dike 1956 年
《尼日尔三角洲的贸易与政治》用口述+欧档双源写非洲人自己的史**——学科开山；
③1964 年 UNESCO 启动八卷本《非洲通史》（General History of Africa，
1980-1999 出齐），以"非洲中心视角"集体正名。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 班图人三千年扩张的路线与动力 | ✅ 大体落定 | 语言树+考古+基因三源互证，非洲史的"示范案件" |
| 大津巴布韦是谁建的 | ✅ 考古落定 | 殖民者坚称腓尼基人所建；碳十四证明是绍纳人（c.1100-1450）——政治压不过年代学 |
| 奴隶贸易的规模与后果 | 🔄 量化持续 | 跨大西洋上船约 1250 万人已成共识；对非洲社会的长期影响仍在争论 |
| 非洲为何被殖民（又为何这么快） | 🔄 持续争论 | 技术/奎宁/机枪论 vs 非洲内部分裂论；1880-1914 瓜分只用了一代人 |
| 独立后发展悖论（资源诅咒） | 🔄 前线 | 资源最富的国家最穷？"新非洲经济史"正用数据重审 |
| 口述传统能否当史料 | ✅ 方法落定 | 口述史有自己的考据学（语体/叠句/独立版本比对） |

## 假设与依赖

①口传可考（依赖口述史方法，而非默认口传=神话）；②长时段优先（殖民 80 年
不应遮蔽此前 30 万年——Iliffe《非洲史》主命题"非洲人是边疆拓荒者"）；
③非洲能动性立场（非洲人是行动者不是背景板——对"殖民一切论"的反题）。
