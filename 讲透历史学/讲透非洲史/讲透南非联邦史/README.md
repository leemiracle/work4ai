# 讲透南非联邦史 · 殖民、种族隔离与转型正义的标本

> 这支负责：**非洲最南端 1652-1994 的 settler（移民殖民）社会史**——
> 从荷兰东印度公司补给站到英帝国矿业帝国，从 1910 年"南非联邦"
> 到 1948-1994 种族隔离，再到真相与和解。GB/T 用"南非联邦史"名之，
> 本支按学界惯例覆盖联邦前史与后续，重心在 20 世纪。
>
> GB/T 77050·三级"南非联邦史"。家族：[讲透非洲史](../README.md)。

## 诞生

1652 年范里贝克在好望角设补给站（公司菜园即开普敦之始）；
科伊科伊人失去牧地的"边疆战争"是南非史的第一章。1806 年英国接管，
1830s 布尔人大迁徙（Great Trek）内迁建立共和国；1867 年金伯利钻石与
**1886 年威特沃特斯兰德金矿**把南非推入矿业资本主义，
1899-1902 英布战争后 1910 年四邦合并为南非联邦——**一个以种族为
宪法原则建国的自治领**。1948 国民党上台立法化种族隔离（apartheid），
1912 年成立的非国大（ANC）经 90 年斗争，1994 年曼德拉就任——
本支以"转型正义"收尾，学科上也以转型正义研究反哺世界。

## 核心问题

- ✅ 已解：种族隔离的劳动制度史（矿产革命→通行证制度→班图教育法的因果链）
- ✅ 已解：沙佩维尔 1960-索韦托 1976 的运动史档案齐备
- 🔄 前线：TRC（真相与和解委员会 1995-2002）档案的第二轮学术开采
  （赦免换真相的长期效果评估）
- 🔄 前线：边界战争（1966-89 安哥拉-纳米比亚）的冷战史重写
- ❌ 未解：不平等的历史再生产——为什么政治转型（1994）没能撼动经济结构

## ✨ 这支最美的一个事实

**真相与和解委员会**：以"说出全部真相换赦免"替代胜利者审判——
图图大主教的"没有宽恕就没有未来"。人类第一次把国家规模的
加害史交给听证而非绞刑架处理，成为三十国转型正义的模板
（利马、摩洛哥、加拿大寄宿学校 TRC 皆其后学）。

## 假设与依赖

①settler 殖民≠经典殖民（移民要地不要宗主国，土著被制度性地
"圈进保留地"——Mamdani《公民与主体》的分析框架）；
②矿业资本主义是解释 20 世纪南非的第一变量；
③1994 是政治断裂不是社会断裂（"自由的悖论"立场）。
