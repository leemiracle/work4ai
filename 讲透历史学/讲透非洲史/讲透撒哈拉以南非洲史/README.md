# 讲透撒哈拉以南非洲史 · 主体大陆的三千年

> 这支负责：**撒哈拉以南非洲**——非洲史的"主体大陆"：班图三千年、
> 西非帝国群、斯瓦希里海岸、刚果与津巴布韦、殖民地与独立。
> 它要证明的命题只有一句：**无文字 ≠ 无文明无国家无历史**。
>
> GB/T 77050·三级"撒哈拉以南非洲史"。家族：[讲透非洲史](../README.md)。

## 诞生

作为学科的诞生即"为承认而斗争"：1911 年大津巴布韦考古报告公布后，
罗得西亚政府施压官方结论回避"非洲人建造"；1960s 独立浪潮中
非洲大学（达喀尔、伊巴丹、达累斯萨拉姆）建立本土学派——
Ibadan 学派（Dike）主张用口述+贸易档案写非洲人视角，
Dar es Salaam 学派（Rodney《欧洲如何使非洲欠发达》1972）开创
依附论史学。本支是"非洲史=诉讼"这一学科性格的最大战场。

## 核心问题

- ✅ 已解：班图扩张（语言学+考古+基因三源同向，路线大体落定）
- ✅ 已解：西非帝国序列（加纳 c.700-1240 → 马里 1235- → 桑海 1464-1591）；
  曼萨·穆萨 1324 麦加朝圣撒金量在欧洲档案留痕——外档定年样板
- 🔄 前线：大西洋-撒哈拉-印度洋三条奴隶贸易的相对权重与相互作用
- 🔄 前线：前殖民国家能力（集权度）与今日发展（新非洲经济史，见家族 01 章）
- ❌ 未解：廷巴克图手稿库（数十万页）的整理与史学开采才刚开头

## ✨ 这支最美的一个事实

**大津巴布韦的石头墙替非洲打赢了一场史学官司**：殖民当局坚称
"非洲人造不出"，把考古学家逼到法庭；碳十四把建造者锁定为绍纳人
（c.1100-1450）。一座废墟成为"非洲中心论"从口号变证据的转折点。

## 假设与依赖

①口传可考据（版本比对规程）；②长时段优先（殖民 80 年不遮蔽三千年）；
