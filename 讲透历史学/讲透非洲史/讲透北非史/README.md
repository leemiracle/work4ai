# 讲透北非史 · 地中海与撒哈拉的双重前沿

> 这支负责：**埃及以外的北非**（马格里布+利比亚+苏丹一线）——
> 一个两千五百年里始终"面向两个海"的文明带：北望地中海，南通撒哈拉。
> 埃及单列一支（GB/T 另设埃及史三级）。
>
> GB/T 77050·三级"北非史"。家族：[讲透非洲史](../README.md)。

## 诞生

迦太基（前 814 建城）把北非第一次写进地中海强权史；汪达尔王国与拜占庭
收复（533）之后，643-709 年阿拉伯征服完成伊斯兰化-阿拉伯化双转型，
柏柏尔人从"被征服者"变成帝国兵源（909 年柏柏尔军士撑起法蒂玛王朝；
1060s 柏柏尔穆拉比特王朝反哺安达卢斯）。奥斯曼 16 世纪收马格里布为摄政国，
1830 年法国陷阿尔及尔开启殖民世纪，至 1951-1962 年利比亚、摩洛哥、
突尼斯、阿尔及利亚相继独立——**本支的"诞生"是一场超长拉锯的收口**。

## 核心问题

- ✅ 已解：阿拉伯化的深度图——城市阿拉伯语化、山区柏柏尔语存续的分布及其成因
- ✅ 已解：阿尔及利亚战争（1954-62）档案开放后的战争史重建（含 FLN 内部史）
- 🔄 前线：撒哈拉贸易带（黄金/盐/奴隶）与马格里布国家的关系重估
- 🔄 前线：柏柏尔之春（1980 起）与当代阿马齐格（Amazigh）身份政治的历史根源
- ❌ 未解：殖民"定居殖民主义"（阿尔及利亚百万欧洲移民）的长期社会遗产

## ✨ 这支最美的一个事实

**阿尔及利亚危机直接催生了法兰西第五共和国**：1958 年阿尔及尔政变
逼戴高乐复出重立宪法——一个殖民地的独立战争，改写了宗主国的宪法结构。
殖民史从来不是"边缘地区史"。

## 假设与依赖

①北非按"地中海-撒哈拉双重前沿"而非"阿拉伯世界东部"定位；
②奥斯曼时期（1517-1830）视为参与而非停滞（反驳"三百年衰落论"）；
③依赖阿拉伯语与法语双档（缺一即半盲）。
