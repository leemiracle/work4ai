> 这支负责：**尼罗河谷从法老时代到现代埃及的连续通史**——注意体例：

## 诞生

埃及是"历史"概念本身的第一现场：约前 3000 年上下埃及统一，
曼涅托（前 3 世纪）已按王朝编出 30 王朝史框架——**人类第一部
"通史"就在尼罗河边写就**。1798 年罗塞塔石碑出土、1822 年商博良
破译圣书体，法老埃及重新接入世界知识；1952 年纳赛尔革命后
埃及史写作回归埃及人自己（"法老民族主义"与阿拉伯认同的张力贯穿至今）。

## 核心问题

- ✅ 已解：王朝年表框架（都灵王表+天文对年+碳十四校准，绝对年代误差收窄到数十年）
- 🔄 前线：古王国崩溃（前 2181"第一中间期"）与气候干旱的关系（尼罗河流量重建）
- 🔄 前线：希腊化-罗马-科普特-阿拉伯的四层叠压：埃及人如何一次次改换语言与信仰
- ❌ 未解：金字塔劳动力的社会组织（"奴隶建塔"已被否定，"国家动员的轮换工匠"细节仍争）

## ✨ 这支最美的一个事实

**罗塞塔石碑=同一段话的三种文字并行**（圣书体/世俗体/希腊文）——
一个天然的"密文-明文对"，商博良用王名圈对照法攻破它，
让沉默三千年的档案一次性开口。破译方法论（已知语对照未知符）
后来在楔形文字、线性文字 B、玛雅文字上一再重演。

## 假设与依赖

①尼罗河是本支唯一的"结构变量"（洪水周期决定税基与王权——
"埃及是尼罗河的赠礼"即希罗多德命题）；②王朝框架是编年工具
不是社会史实（"中间期"标签含史家贬值偏见）；③科普特语基督教埃及
与阿拉伯埃及是连续体不是断代（反驳"征服=断裂"论）。
