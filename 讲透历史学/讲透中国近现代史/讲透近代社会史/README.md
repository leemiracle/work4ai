# 讲透近代社会史 · 市镇、移民与日常：大变局的社会层

> 这支负责：**1840-1949 中国社会的重组**——口岸城市与市民社会、
> 移民与海外华人、会党与民间结社、家庭与妇女、灾荒与救济：
> 在政治史的地基之下，普通人生活的秩序如何被替换。
>
> GB/T 13745：77035 三级"近代社会史"。家族：
> [讲透中国近现代史](../README.md)。

## 定位句

社会史把近代史的镜头从条约与政党摇向日常：施坚雅的市场体系
在口岸时代被穿孔重组（家族 [03 章](../03-可构造与结构.md)
结构二）；千万华工下南洋闯关东，形成跨国社会；会党从秘密
结社变成革命与秩序的双面力量；妇女放足、进学堂、进工厂——
**"大变局"最终必须落到生活世界的改造才算完成**。方法论特色：
把人口、家庭、组织的数据与微观叙事结合。

## 诞生

1930s 社会史论战（中国社会性质大讨论）是社会史的第一个高潮；
1950s-70s 被革命史框架吸收；1980s "复兴社会史"（冯尔康、
乔志强倡议）；1990s 区域社会史（华南学派：科大卫、刘志伟的
宗族与礼仪研究）与国际社会史（罗威廉《汉口》、曼素恩《缀珍录》）
双线繁荣；21 世纪城市史、医疗史、环境史、华侨史把本支扩为
近代史最大的板块之一。

## ✨ 最美的一个事实

**六边形遇上轮船**：施坚雅的宏观区域模型（古代史的均衡市场
层级——见[讲透中国古代史 03 章](../../讲透中国古代史/03-可构造与结构.md)）
在 1843 开埠后被口岸"穿孔"：区域重心从运河城市迁往条约港——
**一个几何模型预测的重组，被海关贸易数据逐年证实**。结构分析
与历史叙事在此严密咬合：社会史最接近"硬科学"的时刻。
