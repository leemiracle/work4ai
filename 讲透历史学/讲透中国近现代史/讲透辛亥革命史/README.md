# 讲透辛亥革命史 · 低烈度革命，大转型结局

> 这支负责：**1911-1912 的辛亥革命**——武昌首义、各省独立、
> 南北议和、清帝退位：一场准备了几十年、爆发在意外中、完成在
> 妥协里的革命，如何终结了两千年帝制。
>
> GB/T 13745：77035 三级"辛亥革命史"。家族：[讲透中国近现代史](../README.md)。

## 定位句

辛亥革命史研究的重心已从"谁领导"转向"如何接盘"：武昌城内的
意外（汉口租界炸弹事故+名单泄露）点燃火种，真正的转变在各省
咨议局-新军-会党的三方接力，以及袁世凯-革命党的南北交易。
**低烈度（全国战斗死亡远小于太平天国）与大转型（帝制终结）的
反差，是本支的中心事实**——它说明旧制度的合法性先于军事而崩溃。

## 诞生

革命党当时即自我修史（邹容、孙中山的叙述与《革命逸史》）；
1920s-40s 罗家伦等开端"辛亥革命史"书写；1961 辛亥 50 周年
（武汉）确立建制化研究；1981 80 周年国际研讨会开启两岸与海外
对话；1990s 后"各省独立过程"的档案细描（各省光复丛刊）使
革命史从领袖史变成结构史——2011 百年纪念产出总结性多卷本。

## ✨ 最美的一个事实

**旧绅士造出新共和**：各省咨议局（1909 设立的本是皇权咨询机构）
在革命中几乎全部转身成为独立后的权力机关——**清廷为延续统治
设计的"安全阀"，成为埋葬它的交接办公室**。制度的反噬结构，
没有比这更干净的案例。

## 假设与依赖

不彻底"论与"低烈度转型是成就"论各戴范式眼镜（家族 [00 章](../00-体系结构.md)）；
