# 讲透中国民主党派史 · 第三条道路的档案学

> 这支负责：**中国民主党派的历史**（1941 民盟成立起，含民革、
> 民建、民进、农工党、致公党、九三学社、台盟）——抗战末期到
> 1948-49 间"中间路线"的形成、高潮与终结，及其后参政党体制
> 的定型。
>
> GB/T 13745：77035 三级"中国民主党派史"——宇宙 README 初记
> 漏列此支，经官方简表复核补齐（见家族 README 计数勘误）。
> 家族：[讲透中国近现代史](../README.md)。

## 定位句

民主党派史研究的核心是**"第三条道路"为何可能、为何终结**：
1940s 后期一批自由主义知识分子与工商界人士（张澜、黄炎培、
罗隆基、梁漱溟等）试图在国共之间走议会中间路线；1946 政协
决议是其巅峰，1947 民盟被取缔标志终结，1948"五一口号"后
转为接受共产党领导的参政结构。这段历史是理解 20 世纪中国
自由主义命运的关键切片。

## 诞生

民盟等组织战时即自我记载（《民主周刊》《再生》等刊物群）；
1950s 各党派自修简史（纪念性叙述）；1980s 起作为党史-民国史
交叉领域学术化（闻黎明、袁小伦等个案研究）；1990s 后政协
档案与地方史料开放使中间路线研究细化；近二十年"自由主义
知识分子研究"（储安平《观察》群体）扩展了本支的知识社会学
维度。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 中间路线的社会基础 | ✅ 研究成熟 | 知识界+工商界+地方实力派的松散联盟 |
| 1946 政协的成败机制 | ✅ 档案充分 | 东北问题与整军方案的双重失速 |
| 民盟被取缔的转折 | ✅ 已解 | 1947：暴力环境下中立空间的物理消失 |
| "五一口号"的响应过程 | ✅ 文献清楚 | 1948 各党派通电：中间路线的制度性终结 |
| 参政党体制的形成 | 🔄 进行时 | 1949 后民主党派角色与组织延续 |

## ✨ 最美的一个事实

**一封电报定格一条道路的终点**：1948 年中共中央"五一口号"
发布后，各民主党派领导人（已在香港的流亡状态）联电响应
"参加新政治协商会议"——**中间路线不是被论战击败的，是被
内战大势与安全处境一次性清盘的**。史学的冷酷在此：观念的
胜负常常在战场之外先已决定。

## 假设与依赖

史料以党派自身刊物与回忆录为主（幸存者叙事偏样——1957 后
右派遭遇使部分叙述延迟多年才出现）；"第三条道路"的评价在
两岸叙事中截然相反（家族 [00 章](../00-体系结构.md)范式
自觉的现场）；依赖[讲透中国国民党史](../讲透中国国民党史/)
与[讲透中国共产党史](../讲透中国共产党史/)提供双边背景。
