# 讲透五四运动史 · 三个运动压缩成的名字

> 这支负责：**1915-1920s 的新文化与五四运动**——从《青年》杂志
> 到巴黎和会外交流产引发的学生运动，再到"主义时代"的开端：
> 中国思想界的一次总换血。
>
> GB/T 13745：77035 三级"五四运动史"。家族：[讲透中国近现代史](../README.md)。

## 定位句

"五四"是一个名字装着三个运动：**新文化运动**（1915 起，伦理与
文学革命）、**五四事件**（1919 年 5-6 月，学生-工商界的政治
动员）、**主义时代**（1920s，社团-政党-意识形态的重组）。
本支研究三者的接续与张力——文化启蒙如何被外交危机政治化，
政治动员又如何沉淀为组织化的意识形态竞争。

## 诞生

运动当年即被自我书写（《新青年》文本群、学生通电、上海罢市
记载）；1939 延安定名"五四青年节"完成纪念政治的第一步；
1950s 后五四阐释成为思想史正统议题（革命史范式：新民主主义
革命开端）；1979 五四 60 周年开启思想解放期的再阐释（启蒙
叙事回归）；1989 前后纪念热度与学术化同步冲高；近三十年
《新青年》全文数据库与报刊计量使话语研究可量化。

## ✨ 最美的一个事实

**一份杂志的重排版记录了思想革命**：《新青年》编辑方针的每次
变动（1918 议政、1919 轮值编辑、1920 走向组织化）与同人分裂，
精确对应思想界的重新组队——**把刊期目录连起来读，就是一代
知识分子的心电图**。数字人文在此有现成的用武之地（词频+
作者网络，家族 [04 章](../04-中国近现代史转代码.md)）。
