> 结构、派系斗争与信息错配中百日崩盘。

## 定位句

戊戌研究的一百年是从"道德剧"到"决策史"的一百年：旧叙事是
"帝党-后党、维新-守旧"的忠奸对立；新研究（茅海建《戊戌变法
史事考》系列）用军机处档案逐日重建 103 天的奏折流转与人事变动
——**变法不是被"顽固派"扑灭的抽象力量，而是在具体的票拟、
召见、罢免流程中逐日失血而死**。

## 诞生

变法失败当月即开始生产叙事（康梁流亡宣传是第一史料工厂，
《戊戌政变记》的夸张与剪裁本身成为研究对象）；民国时期档案
整理（中国史学会《戊戌变法》资料丛刊）奠定史料基础；1970s
黄彰健《戊戌变法史研究》以文献考订重勘政变时间线；2005 起
茅海建利用军机处《早事档》《现月档》完成逐日重建，改写多处
成说（如袁世凯告密与政变的时序关系）。

## ✨ 最美的一个事实

**档案把"告密"从原因改判为回声**：传统叙事"袁世凯告密引发
政变"，茅海建用档案时间线证明政变（1898-09-21 慈禧训政）发生
在袁氏告密消息到达之前——**一个流行百年的因果链，被一叠档册
的日期戳轻轻剪断**。史学最性感的时刻，莫过于时间轴的重新对齐。

## 假设与依赖
