## 定位句

近代经济史的争论轴心：彭慕兰《大分流》把 1750 前的江南与
英格兰拉回同一量级，于是"近代的落后"从"古已有之的停滞"变成
"分流之后的拉开"——**问题从"中国为何停滞"改写为"分流后差距
如何产生"**。本支用海关册、农商务统计、企业与银行账册逐项
对勘（口径审计是生命线——家族 [02 章](../02-语言特征.md)）。

## 诞生

1930s 中国经济史研究建制化（陶孟和的社会调查所；《中国近代
经济史研究集刊》）；1950s 后大陆以"资本主义萌芽"框架为主导
（许涤新、吴承明《中国资本主义发展史》集大成）；1970s-80s
国际计量经济史入场（Perkins 农业估计、Rawski 工业增长重估）；
2000 彭慕兰《大分流》与加州学派引发全球论战；近二十年
企业史（银行档案、账房簿记）与量化数据库建设并行。

## ✨ 最美的一个事实

**一个银本位国家的萧条路径**：1934 美国购银法案抬升银价，
中国白银外流、通货紧缩——**大萧条绕过贸易通道、通过货币金属
价格击中了中国**（美国中西部的银矿政治，决定上海的房贷利率）。
全球化的传导机制从无如此清晰的反直觉案例：金本位世界的危机，
经由银本位的汇率通道放大进入中国。
