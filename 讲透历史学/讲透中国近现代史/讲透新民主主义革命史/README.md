# 讲透新民主主义革命史 · 三十年长革命：从五四到建国

> 这支负责：**1919-1949 的中国革命长时段**——建党、大革命、
> 土地革命、长征、抗战中的根据地、解放战争：把"革命"当作一个
> 连续的历史过程而不是事件序列来研究。
>
> GB/T 13745：77035 三级"新民主主义革命史"。家族：
> [讲透中国近现代史](../README.md)。

## 定位句

本支的独有视角是**革命的机制学**：为什么城市罢工路线失败而
"农村包围城市"成功？土地革命如何同时完成动员、财政与政权
建设？解放军的组织形态为何强于人数相当的对手？——把三十年的
成败翻译为"动员结构、财政结构、军事组织"三个变量的耦合演化
（家族 [03 章](../03-可构造与结构.md) 结构三的可构造化）。

## 诞生

1949 后革命史是近代史学科的"第一显学"（胡绳《从鸦片战争到
五四运动》确立叙述框架，"三次高潮"论）；1980s 起实证化
（档案出版+地方革命史）；1991 苏东剧变后革命史研究面临
"革命是否必要"的再追问；1990s 俄档开放（共产国际档案）使
1920s-40s 中共建党与党内斗争研究获得外部证据链；近三十年
根据地财政经济档案（陕甘宁、晋冀鲁豫）的微观研究成为显学。

## ✨ 最美的一个事实

**空间转译：马克思主义的中国化首先是地理学**。欧洲革命理论
预设城市无产阶级中心；1927 后革命重心移向农村，阶级分析被
翻译为村庄里的成分划分，党组织的"支部建在连上"是组织学的
再发明——**理论旅行到中国，先换的是地图**。这一转译的成败，
比任何论战都更彻底地改写了 20 世纪。

组织与路线，本支管革命过程的社会力学。
