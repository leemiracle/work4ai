# 讲透中国共产党史 · 一个政党的组织演化史与自我修史

> 这支负责：**1921 年至今的中国共产党历史**——建党、路线斗争、
> 执政、改革：既是组织史（一个百年政党的制度演化），也是
> "自我修史"的独特样本（三个《历史决议》）。
>
> GB/T 13745：77035 三级"中国共产党史"。家族：
> [讲透中国近现代史](../README.md)。

## 定位句

党史的特殊性在于**它是当代执政党的历史**：史料开放分层
（1949 前依托俄档与地方档案，1949 后受档案制度约束）、
叙述规范（决议框架）与学术研究（档案实证）长期并行。
学术党史研究（杨奎松、高华一脉）的核心工作是：在开放
档案与回忆录的互证中，把路线、组织、人事的演化过程
做实证重建。

## 诞生

延安整风时期党的历史自我编纂启动（《六大以来》《两条路线》
文献集）；1945 第一个《历史决议》确立"路线斗争"叙事范式；
1981 第二个决议处理"文革"评价并重启实事求是研究传统；
俄档 1990s 开放带来建党与共产国际关系的证据革命；
2021 第三个决议（百年总结）——**三次决议本身就是党史学
的对象：一个政党如何为自己写终审判决书**。

## ✨ 最美的一个事实

**三个《历史决议》= 一部"自我修史"的连续剧**（1945/1981/2021）：
每次决议都在处理"如何评价此前路线"——通过否定或重新肯定
某个过去，为当下路线提供合法性。**把三份文件连读，你看到的
不是三次定论，而是一套"历史书写权与路线合法性"联动的
操作系统**——史学史（谁在写史、为谁写）最锋利的当代样本。

## 假设与依赖

档案开放分层是本支的第一约束（结论强度≤史料强度）；回忆录
需严格时序审计（家族 [02 章](../02-语言特征.md)）；与
[讲透新民主主义革命史](../讲透新民主主义革命史/)分工——
本支管党的组织与路线演化，彼管革命过程的社会力学；
1949 后段与[讲透中华人民共和国史](../讲透中华人民共和国史/)
共担（彼管国家，此管政党）。
