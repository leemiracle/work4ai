# 讲透中国国民党史 · 一个革命党的兴衰全周期

> 这支负责：**1894-1949（及迁台后）的中国国民党历史**——从
> 兴中会、同盟会到 1924 列宁式改组，从执政党到在野党的完整
> 周期：党史研究中唯一可观察"革命党→执政党→失败党"全样本。
>
> GB/T 13745：77035 三级"中国国民党史"。家族：
> [讲透中国近现代史](../README.md)。

## 定位句

国民党史是一部**组织演化实验室记录**：为什么 1924 苏俄式改组后
迅速崛起（组织+意识形态+军权合一），为什么 1928 建政后组织能力
反而退化（派系化、重回精英联盟、基层悬浮）？把共产党的组织史
作为对照组（[讲透中国共产党史](../讲透中国共产党史/)），
国民党的兴衰成为比较政治学的经典案例。

## 诞生

国民党自身文献整理起步早（党史会 1930 建立，罗家伦主持）；
台湾党史会与近史所保存核心档案（会议记录、组织卷宗）；
大陆研究 1980s 后解禁（第二历史档案馆民国档案为主体）；
1990s 后蒋中正日记（胡佛馆藏，2006 开放）成为研究引擎，
派系研究与组织研究（王奇生《党员、党权与党争》）完成
"革命党退化"的机制刻画。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 1924 改组为何有效 | ✅ 研究成熟 | 列宁式组织+意识形态动员的移植成功 |
| 建政后为何派系化 | ✅ 王奇生立论 | 清党后组织空心化：党员质量换数量失败 |
| 抗战中的党国体制 | ✅ 档案充分 | 战时动员与合法性的双线 |
| 大陆失败的组织根源 | 🔄 多线争论 | 财政崩溃+基层悬浮+派系互耗的合成 |
| 迁台后的再造 | 🔄 进行时 | 改造运动：革命党的第二次列宁化 |

## ✨ 最美的一个事实

**"弱者党组织"的量化剖面**：王奇生用党员统计与基层党部档案
证明：1929 后国民党党员大量是地主商人等旧精英"入党保位"，
党组织在乡村悬浮——**一个革命党的退化，可以在党员成分表上
逐年读出**。组织史用数据说话的最佳示范（家族
[03 章](../03-可构造与结构.md)耦合眼的现场应用）。

## 假设与依赖

核心档案分藏两岸（大陆二档/台北党史会+国史馆），任何单边
阅读都偏样；蒋中正日记需注意其"写给别人看"的层面；与
[讲透中华民国史](../讲透中华民国史/)分工——彼管国家断代，
此管政党组织。
