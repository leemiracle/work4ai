# 讲透中华人民共和国史 · 当代人所修的当代史

> 这支负责：**1949 年以来的中华人民共和国史**——从建国、
> 社会主义改造、改革开放到当下：一门"档案未全开、记忆正发酵"
> 的断代史，也是与现实政治贴得最近的史学分支。
>

> 本二级学科，本家族按 GB/T 收录）。家族：
> [讲透中国近现代史](../README.md)。

## 定位句

国史的方法论处境=**史学纪律与当代关怀的持续谈判**：档案定期
解密（25-30 年惯例）使每个十年都有新证据层；亲历者口述与
私人文献（日记、信件、单位档案）大量涌现；同时，路线评价与
决议框架（2021 第三个历史决议）规定了公共叙述的边界。
学术研究的策略：以地方档案与微观史（一个县、一个厂、一个
村庄）绕开宏观叙述的约束，做"自下而上"的国史。

## 诞生

1950s 国史随政权稳固开始自我记述（《人民日报》史、各行业史）；
1981 第二个历史决议为"文革"研究设置基准框架；1980s 当代中国
研究所体系建立（国史研究建制化）；1990s 地方档案陆续开放，
催生微观史路径；2000s 口述史工程（知青、三线、返城）抢救
亲历记忆；2009 至今各省级档案数字化逐步推进——01 章"档案-
记忆双轨"的前线。

## ✨ 最美的一个事实

**史学与记忆赛跑**：国史是唯一"研究对象仍在产生新史料"的
断代史——每过十年，一批档案解密、一代亲历者接受口述、一批
私人日记面世。**历史学第一次可以实时观察"记忆如何沉淀为
历史"**：这让国史成为史学方法论的天然实验室（01 章方向三）。

## 假设与依赖

档案开放分层与决议框架是第一约束——结论强度≤证据强度，
时点敏感话题以已刊档案与地方文献为限；口述史需时序审计
（家族 [02 章](../02-语言特征.md)）；与
[讲透中国共产党史](../讲透中国共产党史/)分工：彼管执政党
组织与路线，此管国家与社会；1949 前背景由
[讲透新民主主义革命史](../讲透新民主主义革命史/)供给。
