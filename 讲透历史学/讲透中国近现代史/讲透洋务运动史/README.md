# 讲透洋务运动史 · 自强三十五年：器物现代化的极限实验

> 这支负责：**清帝国第一次现代化尝试**（1861-1895）——江南制造局、
> 福州船政、留美幼童、北洋海军：一个只买机器不改制度的现代化方案，
> 及其在甲午海战中的总清算。
>
> GB/T 13745：77035 三级"洋务运动史"。家族：[讲透中国近现代史](../README.md)。

## 定位句

洋务运动研究一个现代性问题：**"技术移植能否与制度移植分离？"**
（"中体西用"的学术表述）。三十五年的军工业、学堂、航运电报确实
造出了亚洲第一的舰队，也确实在 1894-95 一年清零——本支的任务是
把"败因"从道德批判（李鸿章卖国）细化为结构分析（财政、人事、
军制、海军学问的每一条短板）。

## 诞生

洋务时期已自我总结（《校邠庐抗议》式的变法议论）；民国学界以
"洋务运动"命名并争论其性质（1930s 起）；1949 后经历"崇洋卖国"
评价期；1961 年史学界"洋务运动讨论"开启再评价，1980s 确立
"近代化的第一步"定位；近四十年企业史（汉阳铁厂、轮船招商局）
与人物个案（李鸿章、盛宣怀档案）研究使本支实证化。

## ✨ 最美的一个事实

**一个刻意的含糊撑起三十年改革**："中学为体，西学为用"在逻辑上
漏洞百出（体用不可分），在政治上却是唯一可行的联盟纲领——它让
顽固派与实务派都能留在同一条船上。**公式越含糊，联盟越稳固；
而联盟的崩溃（甲午）恰好在公式被现实逼问之处**——思想史与
政治史互为因果的完美标本。

## 假设与依赖

洋务档案（李鸿章朋僚函稿、企业账册）体量巨大但分散多馆；"失败"
判词以甲午为终审，需警惕后见之明（洋务遗产——工程师、学堂、
工业基础——实际延续到民国）；依赖[讲透晚清政治史](../讲透晚清政治史/)
（权力结构约束）与[讲透近代经济史](../讲透近代经济史/)（企业
账册的量化现场）。
