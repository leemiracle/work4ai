# 讲透鸦片战争史 · 开局之战：为什么战败没有惊醒帝国

> 这支负责：**近代的第一场对外战争**（1840-1842）及其历史记忆——
> 军事过程、条约后果，以及更大的问题：一个被打败的帝国为什么
> 用了二十年才开始"自救"。
>
> GB/T 13745：77035 三级"鸦片战争史"。家族：[讲透中国近现代史](../README.md)。

## 定位句

鸦片战争史不是"一场战争史"，而是**"败而不觉"的病理学**：军费与
赔款相对帝国财政并非致命，真正的冲击在认知层——天朝体系无法把
"平等对手"放进自己的世界图式。本支同时研究这场战争如何被后世
反复改写（从"通商战争"论到教科书叙事），即它的记忆史。

## 诞生

战时已有即时记载（《夷氛闻记》《中西纪事》）；民国时期蒋廷黻以
外交档案重开研究（《近代中国外交史资料辑要》）；1995 茅海建
《天朝的崩溃》以清方档案逐项复盘（军备、后勤、决策），完成从
"忠奸叙事"到"制度分析"的范式落地——"琦善卖国"案的档案复审是
全书最有名的手术。

## ✨ 最美的一个事实

**茅海建的"反叙事"手术**：用琦善、奕山等"卖国贼"的奏折与廷寄
逐日对勘，证明所谓卖国罪状多属构陷或误传——**把一个道德故事
还原为决策流程**。史学的"证伪"功能在此展示出最锋利的一面：
它连自己民族的创伤叙事也照删不误。
