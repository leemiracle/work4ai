# 讲透太平天国史 · 旧瓶装新酒的内战革命

> 这支负责：**近代第一次大规模内战与"旧式革命"**（1851-1864）——
> 拜上帝教意识形态、天朝田亩制度、《资政新篇》，以及它如何重塑
> 晚清权力格局（湘淮军崛起、督抚坐大）。
>
> GB/T 13745：77035 三级"太平天国史"。家族：[讲透中国近现代史](../README.md)。

## 定位句

太平天国是**一场用外来宗教语法发动的农民战争**：意识形态是新的
（基督教千年主义），社会纲领是旧的（均田免粮），政治结局是意外
的（汉人军功集团接管地方实权）。它同时是"革命史范式"的起点
（三次革命高潮第一次）与"现代化范式"的转折点（督抚主导的洋务
由此发端）——两副眼镜在此打成平手。

## 诞生

清方与同时人记载即巨量（剿平粤匪方略）；民国后简又文、罗尔纲
建立现代太平天国史学（罗尔纲《太平天国史》四卷为集大成）；
1950s 金田起义百年纪念使本支成为"显学中的显学"；1990s 后随着
范式多元化，研究重心从起义正当性转向治理实态（圣库制度、乡官、
妇女政策的地域实践）与战争暴力统计（人口损失估计区间 2000 万-
7000 万——计量史学的难题现场）。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 拜上帝教的来源与改造 | ✅ 已解 | 洪秀全对基督教的选择性再发明 |
| 天京事变的权力结构成因 | ✅ 研究成熟 | 首义诸王合伙制的崩解 |
| 《天朝田亩制度》是否实行 | ✅ 已解 | 基本未行——纲领与社会实践脱节 |
| 战争人口损失有多大 | 🔄 计量难题 | 估计区间宽（2000 万-7000 万），口径之争 |
| 湘淮军与晚清权力下移 | ✅ 主线清楚 | 内战造就督抚专政，直至清亡 |

## ✨ 最美的一个事实

**一份从未实施的土地纲领统治了百年记忆**：《天朝田亩制度》
（1853）"有田同耕，有饭同食"的方案在实际控制区几乎未推行，
但它作为文本成了 20 世纪革命史叙事的"先声"与合法性资源——
**文本的生命力与制度的执行力完全脱钩**，是"历史记忆学"最干净
的案例之一。

## 假设与依赖

太平天国自身文献毁于战火，清方记载带敌对滤镜；人口损失估计依赖

一节）；依赖[讲透近代社会史](../讲透近代社会史/)（会党与流民
的社会土壤）。
