# 讲透中华民国史 · 断代史与记忆史的双重身份

> 这支负责：**1912-1949 的中华民国断代史**——北京政府、
> 南京国民政府两个时期的国家建设、社会变迁与文化转型，
> 以及"民国史"作为记忆对象的当代命运。
>
> GB/T 13745：77035 三级"中华民国史"。家族：
> [讲透中国近现代史](../README.md)。

## 定位句

民国史的独特方法论处境：它是在大陆书写的"前朝断代史"，同时
是台湾保持记忆的"共和国史"——**同一对象，两侧档案、两套分期、
两种评价体系**。学术研究的任务是双档并用（大陆二档+台北国史馆/
党史会），把"国家建设的成败账"（法权收回、工业增长、教育扩张
vs 财政割据、战争创伤）与"民国记忆的政治学"（民国范儿的
当代消费）分开处理。

## 诞生

1956 年大陆将民国史列为重点项目（"隔代修史"传统）；1970s-80s
中华书局《中华民国史》启动（李新主持）；1980s 民国档案大规模
开放（第二历史档案馆）；台湾近史所同步研究（口述史工程）；
1990s-2000s 国际学界（剑桥中华民国史）完成多边综合；
21 世纪"民国热"（大众记忆）与学术民国史并行——01 章记忆研究
的现场（Rehabilitating Republican China, 2024）。

## ✨ 最美的一个事实

**一个断代，两套档案，互为镜像**：大陆第二历史档案馆存北京
政府与国民政府中央档案，台北存国民党党务与"行宪"政府档案——
研究 1945-49 几乎任何大事件都需要两侧档案对勘（家族
[02 章](../02-语言特征.md)对勘眼的制度化应用）。**档案的分治
是政治史分治的延续，而学术工作是把它重新拼合。**

## 假设与依赖

"废清末年的民国史"与"民国史的当代消费"需严格分层；民国统计
（海关册除外）口径审计是量化前提；依赖家族全部政党支
（国共两党+民主党派）与结构层三支供给解释框架。
