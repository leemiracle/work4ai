# 讲透抗日战争史 · 十四年：战争、社会与革命的叠加态

> 这支负责：**1931-1945 的抗日战争**——从九一八到东京湾受降：
> 一场民族总战争，同时是国共竞争、社会重组与东亚秩序重画的
> 十四年。2017 年起教材统一采用"十四年抗战"口径（1931 起算）。
>
> GB/T 13745：77035 三级"抗日战争史"。家族：
> [讲透中国近现代史](../README.md)。

## 定位句

抗战史的三条腿：**军事**（十四年的战场史：从局部抗战到全面
抗战、正面与敌后两个战场）、**社会**（难民迁徙、大后方经济、
沦陷区治理、细菌战与暴行的实证）、**政治**（战时国共关系与
战后格局的因果）。它的方法论特征是**多边史料交叉**：中日美苏
档案互证，任何单边叙述都站不住。

## 诞生

战时即产生海量记载（《大公报》流亡版、日军战报、史迪威文件）；
战后东京审判与国民政府调查留下第一批系统档案；1949 后大陆
研究以"人民抗战"为主轴，台湾以"正面战场"为主轴——两岸叙事
长期分工又对峙；1980s 起两岸学术互访与档案开放（第二历史
档案馆抗战卷宗）；1990s 后日方档案（防研所战史、联队史）与
民间史料（老兵日记）系统引入；2015 后国家社科抗战专项使
史料整理规模空前。

## ✨ 最美的一个事实

**《论持久战》（1938）把战争胜负写成可计算的时间结构**：
毛泽东用"敌强我弱、敌小我大、敌退步我进步"三组变量推出
防御-相持-反攻三阶段——五年后的战争进程与其预测大体吻合。
**一份战略文本获得了接近科学预测的验证度**，这在中外军事
思想史上都属罕见：持久战论=国防经济学+社会动员理论的合流。

的革命机制）与[讲透中华民国史](../讲透中华民国史/)（战时
国家）。
