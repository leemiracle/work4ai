# 讲透晚清政治史 · 新政十年：帝国的最后改革与崩盘

> 这支负责：**1901-1912 的晚清政治**——清末新政、废科举、预备
> 立宪、皇族内阁、铁路国有化：一场比戊戌激进得多的官方改革，
> 以及改革中的王朝为何反而加速死亡。
>
> GB/T 13745：77035 三级"晚清政治史"。家族：[讲透中国近现代史](../README.md)。

## 定位句

晚清政治史的核心悖论：**新政改革的广度超过此前一切自强努力
（官制、军制、学制、法律、宪政齐头并进），王朝却在改革第十一年
死亡**。解释这个悖论需要把政治结构（满汉、央地、新旧）、财政
枯竭（赔款+新政经费）与社会动员（报刊、商会、学生）三线合账
——改革不是稳压器，是加速器。

## 诞生

清亡前已有立宪派报刊的自我记载（《东方杂志》等）；民国时期
宪政史研究起步；1949 后"辛亥革命史"框架覆盖晚清十年（作为
革命背景板）；1980s 起晚清政治史独立成域（侯宜杰《二十世纪初
中国政治改革风潮》）；近三十年史料大涨：清末报刊数据库、地方
咨议局档案、端方/张之洞朋僚函电——决策史与社会史在此汇流。

## ✨ 最美的一个事实

**1905 年废科举：一条行政命令重置整个社会**。科举不仅是考试，
是教育投资方向、精英地理分布、乡村士绅地位与王朝合法性的四合一
接口。废除后新学堂-留学-都市的新阶梯立起，而乡村精英的旧回报
通道关闭——**改革最彻底的一项，也是离心力最大的一项**：
结构社会学的天然实验。

## 假设与依赖

清末报刊与档案体量剧增但立场分化严重（官报/商报/革命报对同一
事件三种叙事）；"改革失败"判词需与"帝制在任何方案下都难存活"
的反事实讨论并置；依赖[讲透辛亥革命史](../讲透辛亥革命史/)
（改革的对偶面）与[讲透近代思想文化史](../讲透近代思想文化史/)
（新知识群体的形成）。
