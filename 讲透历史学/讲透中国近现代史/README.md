## 〇、家族定位（本质一句话）

李鸿章 1872 年说"三千年未有之大变局"——本家族就是给这句诊断做
病历的学科：**外部**（鸦片战争起的条约体系）、**内部**（从洋务到
共产革命的六波应对）、**底层**（经济、思想、社会的重组）三层线索
互相咬合，1840-1949 共 110 年。鸦片战争的炮声是起点而非原因：
真正的研究从"为什么应对如此艰难"开始。

## 一、诞生

近代史是"伤病史学"：它本身就是大变局的产物。梁启超 1902 年首倡
"新史学"要"叙述人群进化之现象"；民国时期蒋廷黻、郭廷以用外交档案
建立近代史研究（清华大学历史系 1920s-30s）；1949 后"中国近代史"
学科建制化，范文澜、胡绳确立革命史范式（三大高潮、八大事件）；
1980s 起现代化范式与"在中国发现历史"（柯文 1984）加入竞争；
21 世纪档案开放（俄档、民国报刊数据库）与计量方法把领域推向
实证化。**范式更替本身就是这门学科的历史。**

## 四、假设与代价

本家族站在三条假设上：①**起点=1840 是叙述约定**——内部变迁论者
把近代性推至 16-18 世纪（白银、人口、市镇），起点选择即范式选择；
②**革命史/现代化双范式各有透镜代价**——前者看见解放、后者看见
建设，同一事件（如义和团）在两副眼镜下道德色彩相反；③**档案开放
不均匀**——俄档与民国报刊数字化改写了博弈格局，1949 后时段的
档案约束使当代史研究密度不均。
