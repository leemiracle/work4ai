## 定位句

近代思想史的经典叙述是**三层递进**：洋务（器物）→戊戌辛亥
（制度）→新文化（文化）——梁启超的反思框架至今仍是最强透镜，
但每一层都在被重估：器物改造自带制度前提、制度改革自带观念
前提，三层其实是同一过程的三个面。本支的工具是**概念史**
（关键词的户口普查——家族 [02 章](../02-语言特征.md)第五节）
与**知识社会学**（报刊、学堂、社团如何生产新知识人）。

## 诞生

梁启超《清代学术概论》（1920）是本支的自我奠基之作（"以复古
求解放"的三百年学术叙事）；1949 后思想史在革命框架内展开
（近代思想史三条线：改良/革命/保守）；1950s-70s 台湾新儒家
（牟宗三等）与海外中国学（列文森《儒教中国及其现代命运》的
"历史与价值"撕裂论）并行；1980s 大陆文化热重启；1990s 后
概念史方法（方维规等）与王汎森式的思想-生活史研究成为主流。

## ✨ 最美的一个事实

**"救亡与启蒙"的双重变奏**（李泽厚命题）：近代思想史的两大
议程——民族救亡与个体启蒙——本应合流，却在危机压力下反复
换位：救亡的紧迫屡屡压倒启蒙的耐心，而启蒙的欠账又回头加深
救亡的难度。**一个音乐隐喻写尽百年思想史的动力结构**——
它同时解释了激情与局限，这是框架之美的极致形态。
