# 讲透义和团运动史 · 底层排外的社会解剖

> 这支负责：**1899-1901 年的义和团运动与八国联军**——旱灾、
> 民教冲突、降神仪式、东南互保与《辛丑条约》：一场被中外双方
> 同时误用的农民运动，及"瓜分危机"的总爆发。
>
> GB/T 13745：77035 三级"义和团运动史"。家族：[讲透中国近现代史](../README.md)。

## 定位句

义和团是三副范式眼镜（家族 [00 章](../00-体系结构.md)）冲突最
尖锐的现场：革命史眼镜看"反帝爱国"，现代化眼镜看"排外蒙昧"，
社会史眼镜看"鲁西北生态危机中的民间宗教动员"。周锡瑞的起源
研究证明第三副最有产出：**"降神附体"不是笑话，是社会动员的
可用技术**——它的传播有清晰的地理与社会结构。

## 诞生

1900 当年即有中外多视角记载（日记、教会报告、联军史料）；1920s
起中国学界整理资料；1960s 义和团研究因"反帝"框架成为显学
（戚本禹"爱国主义"论述与后来的反驳）；1970s-80s 路遥等做鲁西北
田野调查（口述史采集）；1987 周锡瑞《义和团运动的起源》
（The Origins of the Boxer Uprising）以区域社会结构+仪式传播
分析立起新范式；近四十年教会档案（梵蒂冈、各国差会）持续开放。

## ✨ 最美的一个事实

**"迷信的地理学"**：周锡瑞把义和拳的传播画在地图上——它沿
运河区贫困带扩散，跳过士绅强大的核心区；降神仪式采用当地
民间神谱（孙悟空、关公）。**一个看似非理性的运动，分布理性得
像市场扩散曲线**——社会史方法给"理性"概念本身扩了容。

## 假设与依赖

教会档案视角偏（受害者叙事），清方档案偏（官府叙事），口述史
晚采（1980s 亲历者已 80+ 岁）；"排外/反帝"定性涉及当代政治
叙事，论证须格外分层；依赖[讲透近代社会史](../讲透近代社会史/)
（民间结社与教门的长期脉络）。
