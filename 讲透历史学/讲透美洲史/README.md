# 讲透美洲史 · 两个旧世界撞出的新世界

> 美洲史：**一部"碰撞史"**——1492 年两个互不知晓万年的世界相撞，
> 此后美洲的一切（人口、作物、帝国、音乐、菜系）都是这场碰撞的函数。
> 它的独门难题：**大部分主角没有留下文字**，而留下的文字大多是征服者写的。
>
> GB/T 13745：77055（四级三级支：美洲古代文明史/美国史/加拿大史/拉丁美洲史）。
> 宇宙：[讲透历史学](../README.md) · 薄家族（区域史纪律：章精简不注水）。

## 诞生（作为学科的美洲史）

美洲史天生是复数的：西班牙殖民编年史（16 世纪 Sahagún《新西班牙事物通史》
用纳瓦特尔语 informant 访谈——**人类学方法早于人类学三百年**）；
19 世纪各国民族史学（班克罗夫特 US、普雷斯科特《墨西哥征服史》1843）；
20 世纪三线合流——美国专业史学（1884 AHA 成立）、拉美殖民地史研究
（1940s 档案大开发）、美洲原住民史的"第四次发现"（1960s 起口述+考古
重写 1491 前美洲）。1992 哥伦布五百年的全球论战（"发现"还是"入侵"）
把本学科推向公共舞台。

## 假设与依赖

①"美洲"作为单元成立（GB/T 与学界"Western Hemisphere"口径：
共享碰撞起点，但内部差异巨大——本家族用"碰撞的函数"统摄）；
②1492 是分界但有前后连续性（原住民史学界推动"1491 前史"）；
③多语史料宪章（西/葡/英/法+纳瓦特尔/克丘亚/玛雅诸语）。

## 教材锚

- 美国史：Eric Foner《Give Me Liberty!》（教科书标杆）；
  Daniel Boorstin《The Americans》三卷（文明史笔法）
- 拉美史：《剑桥拉丁美洲史》（Bethell 主编，多卷权威）；
  John Chasteen《生于血与火》
- 全景：Charles Mann《1491》《1493》；Alfred Crosby《哥伦比亚交换》
  （术语出处）；Jared Diamond《枪炮、病菌与钢铁》（必读并必批）
