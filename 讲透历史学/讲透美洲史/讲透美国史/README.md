# 讲透美国史 · 成文宪法的实验室

> 这支负责：**1776 以降的美国**——一个"先写宪法再造国家"的实验场：
> 联邦制、成文权利法案、司法审查、政党轮替都从这里首发。
> 但它的另一半故事同样核心：奴隶制、原住民驱逐与移民浪潮
> ——**建国理想与其代价的双面账本**。
>
> GB/T 77055·三级"美国史"。家族：[讲透美洲史](../README.md)。

## 诞生

殖民地层面：1607 弗吉尼亚/1620 普利茅斯的双重起点（种植园与契约
社会）；1760s-70s 帝国危机（印花税→波士顿倾茶）引爆独立；
1787 费城制宪创设**世界上第一部成文国家宪法**与联邦制；1803
马伯里诉麦迪逊确立司法审查——"宪法实验室"三件套成型。
19 世纪西进+内战（1861-65，废奴第十三修正案）；20 世纪两次
大战登顶；1960s 民权运动完成"第二次建国"（Foner 语）。
1884 AHA 成立，1893 特纳"边疆学说"奠基专业史学。

## 核心问题

- ✅ 已解：建国一代与奴隶制的共生关系（Annette Gordon-Reed 杰斐逊研究、
  Hemings 案史实落定）
- ✅ 已解：内战起因论战尘埃落定于"奴隶制是必要条件"
  （学界共识，公共叙事仍争）
- 🔄 前线：1619 项目 vs 1776 叙事——开国叙事的政治与史学双线战争（家族 01 章）
- 🔄 前线：例外论 vs 大西洋史（把美国革命放回大西洋革命年代 1776-1825 比较）
- 🔄 前线：1970s 后社会史爆发的余波——劳工/性别/移民史的教科书份额重排

## ✨ 这支最美的一个事实

费城制宪 1787：55 人闭门一个夏天，把"邦联的失败"改写成
**可修正的宪法**（第五条修正程序）——文件自带更新接口，
此后 235 年只打了 27 个补丁。政治系统把"版本管理"写进
第一行代码。

## 假设与依赖

①"美国"作为单一叙事单元（内部分裂史要求多声部写法）；
②成文宪法是本支的结构变量（法学与史学交界）；
③依赖全球最低门槛的史料环境（人口普查 1790 起、报纸、法院档案
——美国史是全球量化条件最好的国别史之一）。
