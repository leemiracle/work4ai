# 讲透美洲古代文明史 · 无文字文明的历史学

> 这支负责：**1492 前的美洲文明**——奥尔梅克、玛雅、特奥蒂瓦坎、
> 阿兹特克、印加等。它的学科难题：书写系统未覆盖全部用途时，
> 历史学如何工作？答案是三源合流：**图像文字+考古+殖民转写**，
> 近五年再加第四源：遥感（家族 01 章）。
>
> GB/T 77055·三级"美洲古代文明史"。家族：[讲透美洲史](../README.md)。

## 诞生

奥尔梅克（c.1500-400 BC，巨石头盔）是"文化母板"；古典期（约 250-900）
玛雅城邦与特奥蒂瓦坎并立；后古典期阿兹特克（1428 三方同盟）与
印加（1438 起四域制）在 1492 前夕各自达到帝国峰值——
**两个帝国都只有不到百年"帝国史"，就撞上了天花与骑兵**。
学科诞生：普雷斯科特《墨西哥征服史》（1843）开创浪漫主义叙事；
20 世纪碑铭学破读玛雅文字（1960s Knorozov-Proskouriakoff 革命：
纪念碑不是天文呓语而是国王传记）；21 世纪 LiDAR 把人口估计翻了倍。

## 核心问题

- ✅ 已解：玛雅文字性质（语标+音节混合文字，1960s-70s 破读）；
  长历法换算（家族 04 章实验）
- 🔄 前线：LiDAR 改写人口与聚落密度（2018 PACUNAM 起，700-1100 万新估）
- 🔄 前线：古典期"崩溃"（750-950 南部低地）=干旱/战争/生态过载的权重分配
- 🔄 前线：印加结绳 quipu 的语义解码（哈佛 Khipu 数据库，~1000 条编目）
- ❌ 未解：特奥蒂瓦坎（约 1-550）突然衰落的原因——没有文字自述的大城

## ✨ 这支最美的一个事实

玛雅金星表：德累斯顿刻本里的金星会合周期记录精度达
**584 天对真值 583.92 天**——肉眼观测、树皮纸、桌球大小的历法机器，
误差每 500 年才差一天。天文学不是文字文明的专利。

## 假设与依赖

①殖民转写文献可用但须双读（纳瓦特尔层/西班牙层，家族 02 章）；
②"崩溃"概念本身是考古学修辞（人口重组≠文明消失）；
③文明序列不是单线进化（奥尔梅克"母板说"已被修正为多中心互动）。
