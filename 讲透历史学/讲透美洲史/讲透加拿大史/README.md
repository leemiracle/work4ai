# 讲透加拿大史 · 和平联邦的神话与重写

> 这支负责：**1867 联邦至今的加拿大**（含法属/英属前史与原住民一万年）——
> 一个靠谈判而非革命建国的国家，正被自己的真相委员会重写国史：
> **"和平、秩序与良治"的背面是寄宿学校与被偷走的儿童**。
>
> GB/T 77055·三级"加拿大史"。家族：[讲透美洲史](../README.md)。

## 诞生

原住民层（万年级）：因纽特、第一民族、梅蒂人三大支。
殖民层：新法兰西 1608（尚普兰建魁北克）——毛皮贸易的法国模式
（结盟而非定居）；1763 英国接管，1774 魁北克法案保法语天主教；
1812 年战争锻造认同。国家层：1867 英属北美法案——**安大略、魁北克、
新斯科舍、新不伦瑞克四省"协商建国"**，此后渐进独立（1931 威斯敏斯特法、
1982 宪法回归）。2021 年坎卢普斯雷达探测（家族 01 章）后，
加拿大史进入"TRC 重写期"：2008-15 真相与和解委员会已定调
寄宿学校系统（1870s-1997，15 万儿童）为"文化种族灭绝"。

## 核心问题

- ✅ 已解：加拿大为何没有走革命路（效忠派北迁+法英双社妥协结构）
- ✅ 已解：寄宿学校系统的规模与死亡率（TRC 报告 2015，档案齐备）
- 🔄 前线：无标记墓穴的考古-口述联合调查（2021 起，方法论正在生成）
- 🔄 前线：魁北克两次公投（1980/1995）与联邦制的张力史
- 🔄 前线：多元文化主义政策（1971，全球首创）的实效史

## ✨ 这支最美的一个事实

哈德逊湾公司 1670 年成立，靠一张皇家特许状垄断一块
**比今天加拿大还大**的流域的毛皮贸易，至今仍在营业——
**世界上最古老的股份制商业公司之一**。一家公司的账本
就是半部加拿大史（毛皮账簿是量化史学富矿）。

## 假设与依赖

①"协商建国"与"和平"是国史叙事也是国史立场（比较论：美国革命
的溢出效应成全了加拿大的保守建国）；
②双语双文化（英/法）+原住民三元结构是宪制常量；
③北方维度（气候、地缘）是常被南方叙事遮蔽的结构变量。
