# 讲透拉丁美洲史 · 混血大陆与不平等之谜

> 这支负责：**墨西哥以南的美洲**（含加勒比西语区）——
> 伊比利亚殖民遗产、混血社会（mestizaje）、海地开始的独立世纪、
> 以及贯穿一切的核心问题：**为什么资源最丰的大洲，
> 长出了世界最深的不平等？**
>
> GB/T 77055·三级"拉丁美洲史"。家族：[讲透美洲史](../README.md)。

## 诞生

1494 托尔德西里亚斯条约（教皇子午线）把美洲西部划给葡萄牙、
其余给西班牙——"拉丁美洲"的地质断层线在此划下。三个世纪殖民：
casta 血统等级制（家族 03 章）、白银经济（波托西）、天主教会。
独立世纪：海地 1804（奴隶革命孤例）→西属美洲 1810-1825（玻利瓦尔）
→巴西 1822（王室分家，和平）。19 世纪考迪罗；20 世纪墨西哥革命
（1910-20）、古巴革命（1959）、"依附与发展"论战；21 世纪粉红潮
与退潮。1940s 墨西哥学院与 1970s CEPAL 依附论先后让拉美成为
"自己解释自己"的大洲。

## 核心问题

- ✅ 已解：独立战争的社会史（原住民与混血下层打仗、土生白人精英接班）
- ✅ 已解：海地革命史（杜桑 1802 被俘→1804 独立→1825 法国 1.5 亿
  法郎"独立赎金"还到 1947——殖民债务议题源头）
- 🔄 前线：不平等的历史根源计量检验（encomienda 土地制度遗产 vs
  矿产分布，两派拉锯）
- 🔄 前线：非洲裔拉美史（被 mestizaje 叙事遮蔽的第三元）
- ❌ 未解：民主与发展的"拉美钟摆"能否被制度史解释

## ✨ 这支最美的一个事实

海地 1804：四十万奴隶击败拿破仑远征军——**大西洋世界唯一
成功的奴隶革命建国**。它迫使拿破仑贱卖路易斯安那（1803），
改写美国史；而"独立赎金"债务海地还到 1947 年。一个小岛牵动三大洲。

## 假设与依赖

①"拉丁美洲"是 19 世纪帝对阵营命名（法属美洲话语战遗产），
单元成立但内部多元（安第斯/加勒比/南锥差异巨大）；
②殖民强制劳役制（encomienda）是不平等的第一因（可检验命题）；
③依赖西语/葡语一手档案（英文二手会漏掉一半）。
