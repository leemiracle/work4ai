# 讲透史学史 · 历史学如何成为历史学

> 史学史：**研究"历史写作自身的历史"**——谁在写史、用什么体例、为谁而写、
> 史学如何从"资治的镜子"变成"职业的科学"。它把史家与史书当作史料：
> 一部《史记》既是史料，更是"司马迁为何这样写"这道题的答案。
>
> GB/T 13745：77010（二级学科，无三级明细——自定主干二支）。
> 宇宙：[讲透历史学](../README.md)。

## 诞生

中西双起源。中国线：孔子笔削《春秋》（一字寓褒贬的"书法"传统）→
司马迁《史记》（前 91 年，纪传体立范，"究天人之际，通古今之变"）→
刘知几《史通》（709 年，**世界第一部系统的史学方法论专书**）→
章学诚《文史通义》（"六经皆史"）。西方线：希罗多德"保存人类功业" →
修昔底德抛弃神意、确立因果"垂训"史学 → 兰克 1824 年《拉丁与日耳曼民族史》
提出"如实直书"（wie es eigentlich gewesen），在柏林大学用 seminar 制度
把史学**职业化**——历史学作为一门"科学"的诞生不过两百年。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 史学能否成为科学 | ✅ 阶段性落定 | 兰克学派以史料批判+专题研讨班完成职业化——但"科学"的含义此后一直在松动 |
| 中国官修与私修的双轨张力 | 🔄 贯穿全程 | 二十四史是官修正史，而《史记》《文史通义》式的私家史学不断越轨——制度与个人的两千年拉锯 |
| "一切历史都是当代史"（克罗齐 1917） | ✅ 诠释学落定 | 历史理解依赖当代问题——为后来的一切"转向"（社会史/语言学/数字）开了门 |
| 史学史自身的方法论 | 🔄 前线 | 从书录解题式的"史部目录学"走向知识社会学的史学场研究 |

## 假设与依赖

①史料可传可考（依赖[历史文献学](../讲透历史文献学/)）；②史家有法可循
（方法论可传承——刘知几到兰克共享"考据"内核）；③"过去"可知
（认识论乐观——被后现代持续挑战，见[史学理论](../讲透史学理论/)）。
