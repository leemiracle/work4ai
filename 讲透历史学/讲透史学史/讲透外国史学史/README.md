# 讲透外国史学史 · 从希罗多德到全球史

> 这支负责：**西方及全球史学传统演变**——从希腊叙事史到兰克职业化、
> 年鉴学派、后现代转向与全球史。
>
> 家族：[讲透史学史](../README.md)（自定主干支）。

## 诞生

希罗多德《历史》（前 5C）"保存人类功业"；修昔底德弃神意立因果；
奥古斯丁《上帝之城》立普遍史框架；兰克 1824 转向"如实直书"并建
seminar 制度；1929 年鉴学派以问题史取代事件史；1973 White 叙事转向；
1990s 全球史兴起。

| 问题 | 状态 |

## 这支最美的一个事实

兰克史学档案里保存着威尼斯外交报告——他教学生用的"实验室材料"
是四百年前的间谍信：**职业史学诞生于把外交情报变成教学标本的
那一刻**，史料批判与情报分析在方法上同源。
