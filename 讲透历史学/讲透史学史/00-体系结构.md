# 00 · 体系结构：中西史学的双螺旋

> **本章回答五问之一（家族：讲透史学史）。** 史学史的大厦不是一座塔，
> 是**两条独立生长又近代缠绕的螺旋**：中国的"史官-史馆-正史"制度线与
> 西方的"修辞-考证-职业科学"线——19 世纪末相撞，合流出近代史学。

---

## 一、先看一座楼：史学的三层地基

任何史学传统都要回答三个问题，答案的形状决定了这门史学的模样：

| 问题 | 中国传统答案 | 西方传统答案 |
|------|-------------|-------------|
| 为什么写史？ | **资治**（鉴往知来）+ **经世** | **保存功业**（希罗多德）→**垂训**（修昔底德）→**求真**（兰克） |
| 用什么写？ | 纪传/编年/纪事本末三体 | 叙事史→编年考据→专题论文（seminar 产物） |
| 谁来写？ | 史官（世袭→馆阁制度，国家工程） | 行吟者→修士→教授（个人→大学） |

📖 **故事框**：公元前 548 年，齐国崔杼弑君，太史书"崔杼弒其君"被杀；
其弟接续再书，又被杀；三弟仍书，崔杼放弃了。南史氏听说太史尽死，
执简以往——半路听说"已经写成"才返回。**中国史学的"书法"传统
以三条人命为开业成本**：史实的记录权高于强者的改写意志。

## 二、中国线：从"六家二体"到官修机器

```
春秋笔削(前5C)──▶《史记》纪传体立范(前91)──▶《汉书》断代为史(82)
      │                                        │
      └── 编年线《左传》《资治通鉴》(1084) ◀────┘
                     │
刘知几《史通》(709)：史学方法自觉──▶"六家二体"分类、直笔论
                     │
章学诚《文史通义》(1789)："六经皆史"、方志即史
                     │
1902 梁启超《新史学》："二十四史非史也，二十四姓之家谱也"——旧史学的自我爆破
```

三个结构性特征：
1. **官修机器**：二十四史由史馆（国家机构）编纂，宰相监修——史料征集能力强，
   但"为前朝修史"的结构保证它总在合法性地书写（易代修史=政权更替的认证仪式）
2. **私家越轨**：《史记》《史通》《文史通义》都是体制外的爆发——中国史学
   最有生命力的批判来自私修传统
3. **体例即理论**：本纪（帝王时间轴）+列传（人物）+书/志（制度）+世家+表——
   纪传体是一部"多维数据库"的设计（见本章实验：《史记》五体结构）

## 三、西方线：从修辞术到"科学"

```
希罗多德(前5C 希腊好奇)──▶修昔底德(因果+垂训,弃神意)──▶基督教史学(奥古斯丁:普遍史框架)
        │
文艺复兴:博学(antiquarian)传统───┐
        │                        │
兰克(1824《拉丁与日耳曼民族史》;1825柏林 seminar)──▶兰克学派:职业化=大学教席+史料批判+专题论文
        │
布克哈特(文化史)──▶年鉴学派(1929,《经济与社会史年鉴》):问题史取代事件史
        │
1968 社会史转向──▶1970s 计量史(Fogel)──▶1973 White 叙事转向──▶1990s 全球史──▶2010s 数字史
```

✨ **美之时刻 ①：seminar——一台"史料磨坊"**
兰克在柏林大学创办历史研讨班：学生围坐原始史料，逐条考辨。
**为什么美**：它把"如何做研究"本身变成可复制的教学装置——
此后全世界的理工科实验室制度、医学住院医制度，原型都近于此：
知识生产从师徒秘传变成标准化流程。
**怎么亲历**：本家族实验脚本里"史料交叉验证"的最小复现——
三条独立史料对同一事件的一致性计算，就是 seminar 桌上的日常动作。

## 四、双螺旋的近代缠绕

1840 后西学东渐，两条线开始缠绕：梁启超"新史学"直接借径日本译介的
兰克式史学；傅斯年 1928 创史语所（"史料学派"），口号"上穷碧落下黄泉，
动手动脚找东西"是兰克考据的中国化；同时马克思主义史学（郭沫若 1930
《中国古代社会研究》）开出第三条线——1949 后成为大陆主范式，
"古史分期问题"论战是它的巅峰现场。

**反直觉发现**：兰克"如实直书"常被当作史学"科学化"的完成，
但兰克本人相信历史显示"神意"——**客观主义方法与宗教目的论
在同一个头脑里毫无矛盾**。方法论革命与形而上信念的分离，
是史学史给科学史上的最重要一课。

## 这章给了你什么新眼睛

**史学史眼=看史书先看"谁写的、给谁看、用什么体例"**：
同一事件在编年体里是一条时间戳，在纪传体里是某人的动机链，
在纪事本末体里是一个因果叙事——体例选择已经是一次理论选择。
从此读任何史书，你会先翻它的目录结构再看正文。
