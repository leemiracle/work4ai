# 讲透中国史学史 · 从笔削到史语所

> 这支负责：**中国史学自身两千年演变**——史官制度、体例兴替、
> 史学思想的本土脉络。
>
> 家族：[讲透史学史](../README.md)（自定主干支）。

## 诞生

孔子笔削《春秋》立"书法"传统；司马迁《史记》（前 91）创纪传体；
刘知几《史通》（709）开方法自觉；章学诚"六经皆史"；1902 梁启超
《新史学》引爆传统史学；1928 傅斯年史语所引入兰克式考据。

## 核心问题

| 问题 | 状态 |
|------|------|
| 官修机器为何稳定两千年（易代修史的制度逻辑） | ✅ 制度史成熟 |
| 六家二体的分类学效力 | ✅ 刘知几框架沿用 |
| "新史学"断裂还是延续（传统史学近代化的路径） | 🔄 持续争论 |
| 唯物史观与中国史料学的会通（古史分期论战遗产） | 🔄 当代史学理论前沿 |

## 这支最美的一个事实

齐太史三兄弟为"崔杼弑其君"五字连死两人、第三弟仍书——
**中国史学的"事实记录权"以生命为保证金开局**，此后"书法不隐"
从职业风险变成职业尊严。
