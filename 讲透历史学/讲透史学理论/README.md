# 讲透史学理论 · 历史知识如何可能

> 史学理论：**历史学的哲学层**——历史有没有规律、历史解释算什么解释、
> 历史叙事与文学的分界在哪。若[史学史](../讲透史学史/)问"史家写了什么"，
> 本家族问"他们凭什么说写的是真的"。
>
> GB/T 13745：77015（二级学科；三级 3 支：马克思主义史学理论·中国传统史学理论·外国史学理论）。
> 宇宙：[讲透历史学](../README.md)。

## 诞生

三个原生问题逼出三层理论。**思辨层**：汤因比《历史研究》（1934-61）
问"文明为何兴衰"，试图给历史找规律——黑格尔"世界精神"、斯宾格勒"文明生命周期"
同属此层。**分析层**：Hempel 1942 年《历史中一般定律的功能》主张历史解释也是
覆盖律演绎——引爆八十年争论（历史学与物理学用不用同一种"因为"）。
**叙事层**：Hayden White《元史学》（1973）主张历史书写本质是文学编排
（情节化：浪漫剧/悲剧/喜剧/讽刺剧）——语言学转向的引爆点。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 历史有无普遍规律 | ❌ 思辨哲学基本退场 | 汤因比"挑战-应战"不可检验；唯物史观的"规律"地位在马克思主义史学理论内持续讨论 |
| 历史解释的形态 | 🔄 八十年长跑 | Hempel 覆盖律 vs 叙事解释（Danto/Dray）——叙事解释的自主性已获承认，覆盖律未死 |
| 历史客观性可能吗 | 🔄 持续 | "谁的客观性？"——White 之后的立场史学（postcolonial/feminist）要求把立场写进方法 |
| 叙事句的时间结构 | ✅ Danto 1965 落定 | "1989 年冷战结束"在 1989 年**不可能被说出**——叙事句内在地连接过去与叙述现在（见本家族实验） |

## 假设与依赖

①历史叙述有真假可言（语义假设——White 曾把它推到极限）；
②解释的"因为"可以分层（因果/理由/意义）；③理论必须能回史学实践
（马克思主义史学理论支的全部实践检验正在于此）。

## 教材锚

- E. H. Carr《历史是什么》（1961，分析层入门经典之冠）
- Collingwood《历史的观念》（1946，"一切历史都是思想史"）
- Hayden White《元史学》（1973，叙事层原典）
