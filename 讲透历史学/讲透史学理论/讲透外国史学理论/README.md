# 讲透外国史学理论 · 思辨/分析/叙事三段论

> 这支负责：**西方史学理论的三层塔展开**——思辨的历史哲学退场史、
> 分析的历史哲学八十年争论、叙事转向与其实践修正。
>
> GB/T 13745：77015·三级。家族：[讲透史学理论](../README.md)。

## 诞生

维柯《新科学》（1725）"人类创造历史故能认识历史"（verum-factum
原则——历史学与自然科学的分界原点）；黑格尔历史哲学讲演；
Hempel 1942 覆盖律论文；White《元史学》1973 叙事转向。

## 这支最美的一个事实

Hempel——覆盖律论文的作者——后来成了科学哲学中说明模型
（DN/IS 模型）的奠基人：**同一个"解释"形式化纲领同时射向
物理学与历史学**。射向物理学的那支命中了（科学说明论成科），
射向历史学的那支八十年未中——但正是这个未中，逼出了
"理由解释""叙事解释"的自主地位。一次失败的形式化，
买下两门学科的自觉。
