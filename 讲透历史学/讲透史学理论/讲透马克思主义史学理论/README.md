# 讲透马克思主义史学理论 · 唯物史观的原理与检验

> 这支负责：**唯物史观作为史学理论**——生产力/生产关系/社会形态的
> 原理体系、它对中国史学范式的塑造、及其持续的理论检验。
>
> GB/T 13745：77015·三级。家族：[讲透史学理论](../README.md)。

## 诞生

马克思《政治经济学批判》序言（1859）经典表述："物质生活的生产方式
制约着整个社会生活、政治生活和精神生活的过程"。
恩格斯晚年书信（1890s）补注经济决定论的正确读法（交互作用中的
最终决定）。中国现场：郭沫若《中国古代社会研究》（1930）首次
用唯物史观系统解释中国古史——社会史论战引爆，1949 后成为
组织性范式，"古史分期"大论战是其巅峰现场。

## 这支最美的一个事实

唯物史观是**第一个可部分证伪的历史哲学**：它给出具体机制
（生产力-生产关系矛盾运动）并接受史料检验（奴隶制→封建制
的分段在具体社会里成立不成立可以争）——与汤因比式思辨的
不可检验形成方法论对照。中国的"古史分期论战"五十年，
本质是一场超大规模的证伪实验。
