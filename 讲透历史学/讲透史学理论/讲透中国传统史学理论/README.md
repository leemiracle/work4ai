# 讲透中国传统史学理论 · 书法、通变与经世

> 这支负责：**中国本土的史学理论遗产**——不经西方哲学中介的
> 史学思考：书法、体例论、通变观、经世致用。
>
> GB/T 13745：77015·三级。家族：[讲透史学理论](../README.md)。

## 诞生

孔子"其义则丘窃取之"（《春秋》笔削之义）开理论自觉；
《左传》君子曰发论；刘知几《史通》立"六家二体/直笔/史才三长"；
章学诚《文史通义》提出"六经皆史""史德"——中国古代史学理论的
双峰（刘-章并称）。

## 核心问题

| 问题 | 状态 |
|------|------|
| "书法"的伦理判断如何与事实记录共存 | ✅ 理论史上成熟（一字褒贬的编码学） |
| 通变观（通史家风）与断代为史的张力 | 🔄 贯穿至今 |
| "六经皆史"的知识论含义（经典即史料） | 🔄 现代诠释活跃 |
| 传统理论范畴的现代转译（书法≠客观性，差在哪） | 🔄 当代史学理论热区 |

## 这支最美的一个事实

章学诚 1789 年提出"六经皆史"——**经典降格为史料**：不是经书
记载了历史，而是经书本身就是历史（先王政典）。比兰克"让史料
说话"早三十五年，且更激进：他把整个经典体系变成了档案。
中国史学理论最接近现代史学革命的一步，走在欧洲之前。

## 假设与依赖

汉字书写的连续性；史官制度的存续；经学框架的解释权威。
