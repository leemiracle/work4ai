# 讲透大洋洲史 · 人类最后一次远航与最长的连续文化

> 大洋洲史：**人类扩张史诗的终章**——从 6.5 万年前第一次跨越视野所及
> 的海峡，到公元 1250-1300 年定居新西兰（**人类最后定居的主要陆块**），
> 再到殖民、核试与去殖民。它的独门难题：把"航海史前史"与
> "口传家系"变成可考的证据。
>
> GB/T 13745：77065（二级学科，无三级明细——自定主干二支）。
> 宇宙：[讲透历史学](../README.md) · 薄家族（区域史纪律：章精简不注水）。

## 诞生（作为学科的大洋洲史）

欧人迟到：1606 荷人扬松首见澳大利亚，1769-70 库克测绘，
1788 悉尼罪犯殖民地。学科两支：**太平洋考古学**从 1950s 起靠陶器
分布画出拉皮塔扩张线；**新西兰"怀唐伊史学"**从 1970s《怀唐伊条约》
（1840）司法化起，把毛利语文本与英文文本的**翻译歧义**
（"主权" vs "治理"）变成国史核心问题。1990s 后，
"新太平洋史"（Hauʻofa"我们就是海洋"）把殖民地图的"零星小岛"
翻转为"航海者的巨大公路网"。

## 假设与依赖

①大洋洲作为单元（Hauʻofa 论：是"海中之岛"不是"岛之海"——
海洋是公路不是屏障）；②澳新（settler 社会）与太平洋岛屿
（原住民多数社会）双世界并置；③口传家系可用（与碳十四交叉校准
过的独立证据源）。
