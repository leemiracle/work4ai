# 讲透太平洋岛屿史 · 航海文明与殖民，再到气候时代

> 这支负责：**太平洋岛屿世界**（美拉尼西亚/波利尼西亚/密克罗尼西亚）
> ——从拉皮塔航海者到椰干与传教，从核试灰烬到 13 国独立，
> 再到今天为生存而写史的环礁国家。自定主干支（GB/T 77065 无三级明细）。
>
> 家族：[讲透大洋洲史](../README.md) · 自定主干支。

## 诞生

三千年前拉皮塔陶器人群从俾斯麦群岛出发，五百年铺到萨摩亚，
"长停顿"约 1800 年后爆发东进，AD 1250-1300 定居新西兰收官——
**人类扩张史的终章**（家族 00 章四层时间）。欧洲接触层：
麦哲伦 1521 横渡、传教浪潮 1797 起、黑鸟ing 劳工贸易 1863-1904
（62,000 岛民被运往昆士兰甘蔗园）；殖民层：德英法美日逐岛瓜分，
南太平洋委任统治转托管。核试验层：1946-58 比基尼（含 1954
城堡 Bravo 氢堡辐射惨案）、法属穆鲁罗瓦至 1996——
**冷战在天堂做的实验**。去殖民层：萨摩亚 1962 起 13 个政体
独立或自由联合，帕劳 1994 收官（家族实验面板 B）。

## ✨ 这支最美的一个事实

拉帕努伊（复活节岛）"生态自杀论"的经典叙事（岛民砍光树导致崩溃）
在 2010s-2020s 被推翻：老鼠随船入侵毁掉棕榈再生+欧洲接触
（奴隶掠夺与天花）才是人口崩塌主因——**用考古+古 DNA+地层花粉
三个独立证据源，替一个被冤枉的民族翻了案**。史学的再审法庭。
