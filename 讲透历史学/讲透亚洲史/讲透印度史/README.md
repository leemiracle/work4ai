# 讲透印度史 · 靠世界史料重建的文明核心

> 支：[讲透亚洲史](../README.md) GB/T 三级支。摩亨佐-达罗到印巴分治——
> 一个几乎没有官修史传统的文明，却拥有最长的连续生活史。

## 定位句（①本质）

本支负责**印度文明核心区的纵贯史**：哈拉帕城市文明、吠陀-婆罗门秩序、
孔雀-笈多-莫卧儿诸帝国、殖民统治与独立——以宗教、社会结构（种姓）与
物质文化为主轴，以碑铭与外来记载为骨架。

## 诞生（②怎么产生）

- 1786 琼斯论证梵语与希腊拉丁同源（印欧语系发现）——印度学的科学
  起点；19 世纪穆勒《英属印度史》三分期（印度教/穆斯林/英属）成为
  殖民史学框架，被批评为"两个民族论"的史学前置
- 1920s 哈拉帕/摩亨佐-达罗发掘：把印度文明起点前推两千余年
- 1982 庶民研究（Subaltern Studies，古哈主编）——把农民、贱民、妇女
  从精英史学里解放，影响整个后殖民史学

## ✨ 最美的一个事实（⑧美之时刻）

戒日朝印度（7 世纪）没有自己的官修史，它的骨架靠**外国人的笔记**撑起：
玄奘《大唐西域记》是那个时代印度最重要的世俗史料——"印度史的世界
史料网"（波斯、希腊、汉文、阿拉伯史料互证）是这个文明给史学的独特
馈赠。

## 反直觉（⑥）

黑格尔说印度"没有历史"——**错**：它缺的不是历史，而是纪年型官修史；
碑铭、铜板赐地文书、宗教编年与外来记载的总量足以重建复杂政治史，
只是方法不同（家族 02 章"多源三角测量"的教科书案例）。

## 假设与依赖（④假设与代价）

假设"文明连续性"优先于"政权断代"（买到：五千年叙事；付出：政权史
稀疏导致与中欧史对表困难）；假设宗教文献可作社会史料（需剥离仪轨
理想化的滤镜）。

## 教材锚

Wolpert《印度新史》；塔帕尔《早期印度》；库尔克与罗特蒙德《印度史》；
与区域侧 [讲透南亚史](../讲透南亚史/) 的分野见两支 README 互认。
