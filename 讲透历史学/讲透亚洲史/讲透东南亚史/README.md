# 讲透东南亚史 · 海上亚洲的曼荼罗

> 支：[讲透亚洲史](../README.md) GB/T 三级支。从"远印度"到东盟——
> 季风海域的政治是一种没有边界的几何。

## 定位句（①本质）

本支负责**中南半岛与群岛的通史**：印度化王国、贸易时代（1400-1650）、
殖民重组、冷战热战地与东盟时代——区域概念本身 1943 年才由军事地理
（蒙巴顿司令部）命名。

## 诞生（②怎么产生）

- 1948 科代斯（G. Coedès）《印度化的国家》：从碑铭重建被遗忘的王国
  序列——东南亚史作为学科的奠基
- 1968 沃尔特斯（O. Wolters）提出"曼荼罗（mandala）"模型：东南亚
  政体是没有固定边界的同心圆权力场，"国家"一词在这里失效
- 1988/93 里德（A. Reid）《贸易时代的东南亚》：以城市、商品、气候
  重写 1400-1650 的"亚洲地中海"

## 核心问题（③问题清单）

| 问题 | 状态 |

## ✨ 最美的一个事实（⑧美之时刻）

室利佛逝——统治马六甲海峡数百年的海上帝国，几乎没有留下本土文字
记载；1918 年科代斯从碑铭"破案"确认其存在，其历史靠义净的记述与
宋代市舶档案重建——**一部靠外部史料写成的海上帝国史**。

## 反直觉（⑥）

"没有边界的国家"比有边界的更稳定：曼荼罗政体里，王权随人与仪式
流动，两三个"首都"可以并存不悖——用威斯特伐利亚眼镜看东南亚，
看到的全是"混乱"，摘下来才看到另一种秩序。

## 假设与依赖（④假设与代价）

假设"区域"成立（买到：与东亚/南亚对表；付出：群岛与半岛差异极大，
马尼拉与万象的共性只剩季风）；假设碑铭+外部记载足以重建（热带气候
毁灭文献，考古是最长的那条腿）。

## 教材锚

科代斯《印度化的国家》；里德《贸易时代的东南亚》；安德森《想象的
共同体》（以东南亚为主场的民族主义理论）。
