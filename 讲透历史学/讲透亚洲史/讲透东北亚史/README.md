# 讲透东北亚史 · 朝贡体系的实态与冷战的凝固

> 支：[讲透亚洲史](../README.md) GB/T 三级支。中日韩俄四大力量交界带：
> 历史上最有序的国际体系，当代最凝固的分断线。

## 定位句（①本质）

本支负责**东北亚区域整体史**（朝鲜半岛、日本海圈、中国东北、蒙古）：
前近代朝贡体系的运行与实态、近代的帝国竞逐、冷战分断格局的形成与
延续——区域单位本身是冷战学术地理的产物。

## 诞生（②怎么产生）

- 1941 费正清与邓嗣禹提出"朝贡体系"解释清代外交——区域史框架的起点
- 1950-53 朝鲜战争把"东北亚"变成冷战学术单位；1981-90 卡明斯《朝鲜
  战争的起源》引发修正派论战
- 2010 年代康灿雄（David Kang）《西方之前的东亚》以实证重估朝贡体系：
  名义等级、实际互利的贸易稳定器

## ✨ 最美的一个事实（⑧美之时刻）

19 世纪之前的东亚国际体系（朝贡网）比同期威斯特伐利亚体系**更少战争**
（康灿雄统计：1590s 东亚大战之后近三百年区域无大国战争）——"中华
世界秩序"不是帝国主义的别名，更接近一个贸易稳定器；它的崩溃
（1894-95 甲午）反而开启了区域最血腥的半世纪。

## 反直觉（⑥）

最"等级"的体系实际最"平等"：朝鲜国王在国内是至尊，对清称臣纳贡、
对内却行皇帝礼（"大报坛"祀明皇帝）——**礼仪的双重账本**是朝贡体系
运行的秘诀，也是"名分"与"实利"分离的制度设计。

## 假设与依赖（④假设与代价）

假设冷战地理=历史区域（买到：研究单位清晰；付出：蒙古、中国东北与
朝鲜半岛的内在联系被国界切割）；假设汉文史料覆盖面=体系实态（满文、
蒙文、朝鲜史料的持续刊布不断修正"中华中心"视角）。
