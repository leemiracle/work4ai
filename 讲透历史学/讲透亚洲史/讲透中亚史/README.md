# 讲透中亚史 · 草原、丝路与内亚的翻案

> 支：[讲透亚洲史](../README.md) GB/T 三级支。被"心脏地带"理论误解
> 最深的地区——游牧不是历史的边料，是欧亚网络的原动力之一。

## 定位句（①本质）

本支负责**欧亚内陆（草原+绿洲）的通史**：斯基泰-匈奴-突厥-蒙古的游牧
帝国序列、丝绸之路的绿洲节点、伊斯兰化与突厥化、苏联民族划界与当代
五国——"内亚视角"是本支的方法论旗帜。

## 诞生（②怎么产生）

- 1940 拉铁摩尔《中国的亚洲内陆边疆》：游牧-定居是共生系统而非对立
  双方——内亚研究的奠基
- 20 世纪苏联/西方双轨（俄国中亚学积淀深厚但受意识形态约束；1980s
  后西方"内亚研究"复兴）
- 2000s "新丝路"研究热与成吉思汗全球史重估（Weatherford 通俗化+
  学界修正）

| 问题 | 状态 |

## ✨ 最美的一个事实（⑧美之时刻）

蒙古驿站系统（站赤/yam）让使者横贯六千公里帝国——人类第一个洲级
"信息带宽"；1346 年黑死病恰好沿这张网抵达克里米亚再入欧洲——
**全球化第一次亮相，就同时运输了丝绸、技术与瘟疫**。

## 反直觉（⑥）

"丝绸之路"上的主力货种从来不是丝绸而是……一切（马、玻璃、宗教、
奴隶、技术、疾病）；而且它大部分时间"不通"——绿洲链条随政治涨落，
稳定的从来不是路，是**节点的复利**（敦煌、撒马尔罕的千年枢纽地位）。

## 假设与依赖（④假设与代价）

假设"内亚"是与定居文明对等的单位（买到：游牧者从"入侵者"变成
"系统组件"；付出：绿洲城市社会的定居逻辑需要独立叙事补回）；史料
依赖多语（突厥鲁尼文、回鹘文、波斯文、汉文——零语源断点即断档）。

亚洲内陆边疆》；《剑桥蒙古帝国史》。
