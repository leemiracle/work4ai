# 讲透亚洲史 · 人类多数的历史

> 亚洲史：**把"亚洲"当作问题而不是舞台的史学**——这个洲名是希腊人
> 给的，疆界是欧洲人画的，而历史是三十多亿人自己过的。
>
> GB/T 13745：77045（二级学科）。三级 7 支：日本史·印度史·东北亚史·
> 东南亚史·南亚史·中亚史·西亚史（中国史归 77025-77035，本家族不含）。
> 宇宙：[讲透历史学](../README.md) · 区域史家族（章精简不注水）。

## 诞生

三个原生问题：①"亚洲"作为整体单位从何而来？——词源是亚述语 aṣû
（日出之地），经希腊人 Asia 到近代欧洲的"东方学"建制；②被殖民的亚洲
如何夺回自己的历史书写权？③亚洲内部的联系（朝贡、印度洋、丝绸之路、
佛教圈）如何构成历史主体？关键节点：1784-86 琼斯创亚洲学会并破译梵语
亲缘（东方学科学化）；二战后美国 Area Studies（区域研究）建制化；
1978 萨义德《东方学》引爆学科自省；1990s 亚际研究（Inter-Asia，沟口
雄三"作为方法的亚洲"谱系）推动亚洲人写亚洲的联合；冈仓天心"亚洲一体"
（1903）与福泽谕吉"脱亚论"（1885）是这对张力的最早表达。

## 假设与依赖

三条假设：①存在可叙述的"亚洲"整体（买到：与世界通史对表的单位；付出：
内部差异被压缩——日本与也门共属一名）；②多语文史料可通约（买到：跨
文明比较；付出：每个翻译都是一次解释权的转移）；③殖民时期档案可用而
须批判（买到：海量近代记录；付出：它们由统治者视角生成——反读档案是
必修课）。
