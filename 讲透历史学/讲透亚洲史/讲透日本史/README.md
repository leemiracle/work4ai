# 讲透日本史 · 非西方现代化的第一例

> 支：[讲透亚洲史](../README.md) GB/T 三级支。绳文孤岛到平成令和——
> 一个借入一切又改写一切的文明。

## 定位句（①本质）

本支负责**日本列岛的通史**：从绳文-弥生的原初社会、律令国家、武家
政治、锁国与开国，到明治维新"非西方现代化的第一例"与近现代的战争、
占领、经济奇迹。

## 诞生（②怎么产生）

- 712/720《古事记》《日本书纪》：日本史学起点（神话-史实混合体，需
  实证批判）
- 19 世纪末利斯（Ludwig Riess）把兰克式实证史学带进东京帝大——日本
  近代史学的直接源头是德国
- 20 世纪内藤湖南"唐宋变革论"与京都学派、战后津田左右吉的记纪批判，
  构成日本史学的自反传统

## 核心问题（③问题清单）

| 问题 | 状态 |
|------|------|
| 大化改新（《书纪》所载诏书）的可靠性 | 🔄 战后实证史学长期论争（史料层累说） |
| 明治维新的性质（革命/复辟/改革） | 🔄 多派并立（带有"从下往上"社会史重估） |
| 为什么是日本第一个非西方工业化国 | ✅ 解释框架多线并陈（藩政改革/教育/地税-金融重组） |
| 江户锁国的实际开放度 | ✅ "四个口子"研究成熟（荷兰、朝鲜、琉球、虾夷） |

## ✨ 最美的一个事实（⑧美之时刻）

126 代天皇未改一朝——世界现存最长君主制；但天皇实际亲政的时段不足
全部历史的三分之一（摄关、院政、武家、幕府轮流掌权）——**权威与权力
的分离**是日本政治千年不变的设计图。

## 反直觉（⑥）

"万世一系"不是古老事实而是近代发明：天皇符号的国家化（明治）先于
其"连续性"的史学论证——连续性叙事本身是维新政权的产品（家族实验
断言 5 给出跨度量化）。

## 假设与依赖（④假设与代价）

假设"列岛"是有效单位（买到：与大陆史对照的清晰边界；付出：弥生
移民、佛教、儒学、兰学——日本史的动力一半来自"海的那边"，孤立叙事
自带偏差）。

## 教材锚

"列岛外史"视角系列。
