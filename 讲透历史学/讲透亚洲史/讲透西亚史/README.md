# 讲透西亚史 · 文明摇篮与"中东"的发明

> 支：[讲透亚洲史](../README.md) GB/T 三级支。两河到今天的"中东"——
> 人类最早的城市在这里，最新的史学论战也在这里。

## 定位句（①本质）

本支负责**西亚整体史**（两河、伊朗、安纳托利亚、阿拉伯半岛、黎凡特）：
从城市与文字的发明，经伊斯兰文明的成型与奥斯曼帝国五百年，到殖民
重组与当代国家体系——包括"中东"这个概念本身的历史。

## 诞生（②怎么产生）

- 19 世纪楔形文字与圣书字破译（1822 商博良/1857 四学者对照实验）
  ——亚述学、埃及学创立，西亚史第一次拥有原文
- 1902 马汉海权论文发明"中东"（以欧洲为原点的方位词）——1916-22
  赛克斯-皮克特体系把它变成政治地理
- 1978 萨义德《东方学》：本支成为学科自省的风暴眼；2010s"新奥斯曼
  史学"终结"衰落范式"

## ✨ 最美的一个事实（⑧美之时刻）

1857 年皇家亚洲学会做了一次"对照实验"：把同一未刊铭文寄给罗林森、
欣克斯、塔尔博特、奥珀特四位学者独立翻译，**四份译文基本一致**——
史学史上罕见的可重复实验，亚述学由此被承认为科学。

## 反直觉（⑥）

"中东"是个 20 世纪的发明，而且是个**移动的**发明（最初指波斯湾，
一战后才覆盖阿拉伯半岛）；用它叙述五千年前两河的历史，等于用冷战
地图讲新石器——西亚史的第一课是先拆掉自己单位的脚手架。

## 假设与依赖（④假设与代价）

假设"伊斯兰世界"与"西亚"可互译（买到：文明框架便利；付出：伊朗的
波斯认同、土耳其的突厥认同、以色列/亚述基督徒的处境都在抗议这个
等号）；泥板档案在本地语境（两河）极厚、在游牧区极薄——档案密度
差即文明层级差，读图须知。

## 教材锚

胡拉尼《阿拉伯人民史》；罗根《阿拉伯人》（The Arabs: A History，
覆盖 1516 至今）；刘易斯《中东》（批判读，与萨义德对勘）。
