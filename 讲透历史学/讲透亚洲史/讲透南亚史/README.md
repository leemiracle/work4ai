# 讲透南亚史 · 分治划出的区域

> 支：[讲透亚洲史](../README.md) GB/T 三级支。印巴孟斯尼泊尔——
> 一条五周画出的边界线，把一个文明切成七个国家的现代史。

## 定位句（①本质）

本支负责**南亚区域整体史**（印度、巴基斯坦、孟加拉、斯里兰卡、尼泊尔
等）：以 1947 年分治为枢纽——殖民帝国的解体、分治的暴力与迁徙、
区域国家群的构建——与 [讲透印度史](../讲透印度史/) 的文明纵贯史互为
纵横坐标（GB/T 双支并立，非重复）。

## 诞生（②怎么产生）

- 1947 分治：一夜之间制造了人类史上最大规模的被迫迁徙，也制造了
  一门新区域史——"南亚研究"（SAS）在美国高校建制化
- 1960s-80s 剑桥学派与民族主义史学论战（殖民经济史的账怎么算）
- 1982 庶民研究运动从印度史扩展为南亚整体的"自下而上"范式

## ✨ 最美的一个事实（⑧美之时刻）

拉德克利夫——一位从未到过印度的英国律师，用约五周在地图上画出印巴
边界，而且**边界线的公布日在独立日之后**（1947-08-17）：先有国家，
后有国界——地图不仅描述现实，这一次它制造了现实：约 1400-1800 万人
背井离乡。

## 反直觉（⑥）

分治的暴力不是"古代仇恨的爆发"：1946 年以前大规模教派屠杀在印度
西北部并无长期先例——族群边界本身是选举政治（1919/1935 改革）动员
的产物；"两个民族论"是因果倒置的叙事。

## 假设与依赖（④假设与代价）

假设"分治"是有效枢纽（买到：区域单位的诞生时刻；付出：1947 前的
区域史被迫借印度史支的框架）；假设民族国家是终点形态（南亚的帝国、
土邦、部落遗产不断提出异议——尼泊尔 2008 年才终结君主制，见家族
实验断言 4）。
