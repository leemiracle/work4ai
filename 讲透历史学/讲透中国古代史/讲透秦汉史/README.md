# 讲透秦汉史 · 第一个大一统官僚帝国

> 这支负责：**帝制中国的操作系统安装期**（前 221—220）——郡县、编户、
> 律令、独尊儒术，四百年把"如何统治一个大陆级农业帝国"的方案写完，
> 此后两千年只是打补丁。
>
> GB/T 13745：77030 三级"秦汉史"。家族：[讲透中国古代史](../README.md)。

## 定位句

秦汉史研究"一统"如何可能：秦给出制度蓝图（郡县-文书-律令），
汉完成社会整合（编户齐民-乡里-察举），并用《史记》《汉书》把帝国
经验写成可复制的自我叙述。核心张力始终是**皇权与官僚、国家与豪族**
的拉锯——王莽改制的失败与豪族庄园的兴起，预告了中古贵族时代。

## 诞生

汉初已开始总结"秦何以亡"（贾谊《过秦论》）——这是中国最早的
"兴亡案例研究"；近代学术化标志：1900s 玉简金石之学转向简牍
（斯坦因获敦煌汉简 1907、居延汉简 1930），行政文书第一次让
"帝国如何运转"可考；1975 睡虎地秦简、2002 里耶秦简把秦代县级
行政从推断变成实证。

## ✨ 最美的一个事实

**里耶秦简的"洞庭郡"**：一枚洞庭郡迁陵县的行政木方，记载了史书
失载的秦郡设置——帝国行政的最小颗粒（一枚木方、一次邮行、一个
县廷的日常）修正了传世文献的顶层地图。秦政不再是"暴政"形容词，
而是可数的公文流。

## 假设与依赖

传世文献（正史+政论）幸存于官方筛选；简牍证据在时空上高度偏样
（边塞与特定遗址）；"汉承秦制"的连续性叙事可能低估了断裂。
前置阅读需要秦汉官制与地理基本功；依赖家族 [02 章](../02-语言特征.md)
的文书语言功底。
