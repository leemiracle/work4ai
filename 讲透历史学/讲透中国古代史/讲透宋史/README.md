# 讲透宋史 · 近世的门槛：唐宋变革的主战场

> 这支负责：**中国社会的"近代化预演"**（960—1279）——科举平民化、
> 货币经济、城市革命、理学兴起、与辽金的长期共处：一个不靠军事霸权
> 而靠制度与经济运转的王朝样本。
>
> GB/T 13745：77030 三级"宋史"。家族：[讲透中国古代史](../README.md)。

## 定位句

宋史的一切大问题都围绕**唐宋变革论**展开：唐宋之间是否发生了贵族→
平民、实物→货币、坊市→街市、门第→科举的整体转型？宋朝为此提供了
全部证据现场——它是中国史上"最像近代"的朝代，也是"为什么没有走到
近代"（内藤假说的另一半）这个大问题的时间起点。

## 诞生

宋代自己已感到剧变（沈括、郑樵的当代观察）；内藤湖南 1910s 提出
"唐宋变革论"把宋定位为"近世开端"，开创日本宋史学（宫崎市定等）；
20 世纪邓广铭、陈乐素建立中国宋史学统；1970s 后经济史（斯波义信、
Hartwell）与制度史（邓小南"祖宗之法"）双线推进，走马楼吴简之前的
宋代文书（徽州文书时间下探）与《宋会要》数据库让量化研究成为可能。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 唐宋变革的幅度 | 🔄 百年争论 | 质变派 vs 连续派：内藤假说至今未终审 |
| 科举社会如何成形 | ✅ 框架成熟 | "朝为田舍郎"的制度化：士大夫与皇帝共治 |
| 宋代经济革命的限度 | 🔄 量化前线 | 铁产量/城市化率/商税的估计区间仍宽 |
| "祖宗之法"的真实运作 | ✅ 邓小南立论 | 叙事性纲领如何实际约束君主 |
| 宋为什么军事不振 | 🔄 持续争论 | 强干弱枝的代价 vs 地缘格局的结构困局 |

## ✨ 最美的一个事实

**《清明上河图》是可核实的经济计量图**：画中店铺、招牌、船只、
税关可以逐一分类统计——一幅画=一份汴京商业活动的横截面普查。
艺术史与经济史在同一画面上共享数据源，这在世界史上几乎没有同类。

## 假设与依赖

宋代史料体量为古代史之最（正史+会要+文集+方志+文书），"材料多"
反而制造抽样难题；宋人自己强烈的道德叙事（如对新法的褒贬）渗透
一切文本；与[讲透辽金史](../讲透辽金史/)必须对读——宋的"中国"
是在与北朝共处中被定义的。

## 教材锚

- 邓小南《祖宗之法——北宋前期政治述略》（"叙事约束制度"的示范）
- 刘子健《中国转向内在》（两宋之际文化转向的经典判断）
- 斯波义信《宋代江南经济史研究》（量化经济史样板）
