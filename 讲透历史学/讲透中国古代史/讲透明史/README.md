# 讲透明史 · 白银帝国与内向转向

> 这支负责：**全球化的第一个中国回合**（1368—1644）——废丞相的
> 皇权重置、一条鞭法的白银税制、晚明的全球贸易与思想活力，
> 以及一个"看似一切都在变、却未走向近代"的巨大案例。
>
> GB/T 13745：77030 三级"明史"。家族：[讲透中国古代史](../README.md)。

## 定位句

明史的谜题是"活力的悖论"：白银流入、出版爆发、市镇繁荣、思想
多元（阳明学），但同时皇权制度内卷（废丞相后皇帝-宦官-内阁的
畸形制衡）、财政脆弱、军事收缩。**明代同时是"最开放的经济体"
和"最内向的政体"**——这对矛盾是本支的发动机。

## 诞生

清代官修《明史》（1739，修正代史中考据最精）叠加大量野史笔记；
孟森《明史讲义》立现代学统；20 世纪后期明清史合并研究兴起
（白银、市镇、人口长时段）；1990s 后"晚明全球化"框架（Flynn 与
Giráldez 的白银流动研究）与徽州文书、地方档案的大量利用，
让明代成为经济史实证最厚的断代之一。

## ✨ 最美的一个事实

**一条鞭法：中国税收用世界的钱计价**。美洲与日本白银经马尼拉
大帆船与月港贸易流入，张居正（1581）把繁杂的实物与力役折银
征收——中国农户的税单从此与全球银价挂钩。**一个江南县衙的
会计改革，背后是波托西银矿与长崎商船**：全球史最直观的
"蝴蝶效应"实证链。

## 假设与依赖

明代档案大损（明末战乱+清代政治过滤），文集与方志补位；"晚明
资本主义萌芽"框架已弃用，但替代框架（早期全球化参与者）仍在
打磨；依赖[讲透中国古代契约文书](../讲透中国古代契约文书/)支
（徽州文书的主场）与近现代史家族的白银续章。
