> 简帛，四类"商周秦汉人亲手写的字"，是重建上古与中古的第一证据链。
>

> 目录名轻规范化为"讲透中国古文字"。家族：[讲透中国古代史](../README.md)。

## 定位句

古文字学是一门**破译学科**：材料是挖出来的（或少不了科学发掘的），
对象是死语言+构形演变的文字系统，目标是把"字"变成"史料"。
它的独特地位在于**自证性**：甲骨金文是当时人写给当时人（或神）的
文本，不经后世转手——是上古史里唯一"零手抄损耗"的证据层。

## 诞生

1899 王懿荣鉴藏"龙骨"，甲骨文进入学术视野；罗振玉、王国维的
"罗王之学"完成甲骨学与二重证据法奠基（1910s-20s）；郭沫若以甲骨
治社会史；1949 后殷墟科学发掘持续，1970s 起简帛大发现（马王堆、
银雀山、睡虎地）把学科扩为"古文字学"；1998-2020s 战国竹书
（郭店、上博、清华、安大）让"重写先秦思想史"成为现实议程。

## ✨ 最美的一个事实

**王国维 1917《殷卜辞中所见先公先王考》**：商王世系表逐一对勘——
司马迁写于两千年前、无一手材料可据的王表，与出土甲骨几乎完全
吻合（仅个别错序）。**历史学最动人的一刻：一个诚实的人认真
整理过的二手信息，隔三千年被当事者亲笔签名确认。**

## 假设与依赖

假设字形演变有规律可循（构形学的公理）；假设出土文本与传世文本
可互证（简帛学发现"文本流动性"后已加修正）；材料受考古供给支配
——**本支的年产量由发掘报告决定**。依赖考古学（GB/T 780）与
[讲透先秦史](../讲透先秦史/)、[讲透秦汉史](../讲透秦汉史/)的史学问题牵引。
