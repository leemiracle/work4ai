# 讲透元史 · 世界帝国的汉地治理

> 这支负责：**蒙古时代的中国**（1206/1271—1368）——史上首个统治
> 全中国的草原政权：它用行省划省界、用运河连海运、把中国嵌进横跨
> 欧亚的贸易与知识网络；"中国的元朝"与"世界史的蒙古帝国"是同一
> 对象的两面。
>
> GB/T 13745：77030 三级"元史"。家族：[讲透中国古代史](../README.md)。

## 定位句

元史研究双重身份的张力：作为断代史，它问行省制、户籍分类、
科举停复如何治理汉地；作为世界史节点，它问"蒙古和平"
（Pax Mongolica）如何重塑欧亚的技术、贸易与知识流动（马可·波罗、
回回天文、纸币西传）。**行省制是本支的头号遗产——今天的中国省界
仍是元代的军事-财政地理。**

## 诞生

明初修《元史》（1370，速度仓促为正史之最），清代钱大昕等以西北
舆地之学补证；20 世纪元史学双源：洪业/陈垣的文献考订与伯希和
（Pelliot）的多语阿尔泰学传统；1949 后翁独健、韩儒林建立中国
元史学统；近三十年杉山正明等推动"蒙古时代史"升级为欧亚整体史。

## ✨ 最美的一个事实

**行省=军区变成省界**：元廷为军事控制设"行中书省"，其划界原则
是"山川形便"让位于"犬牙交错"（故意割裂自然经济区以防割据）——
一次出于统治安全的行政设计，被明清沿用并活到今天：
**你在地图上看到的省界，是一份 700 年前的安全审计报告。**
