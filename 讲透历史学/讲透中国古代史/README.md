## 〇、家族定位（本质一句话）

秦亡了，汉承秦制；清亡了，省界还是元划的。中国古代史研究的就是这种
**"王朝会死、结构长存"** 的现象：每个断代支管一段王朝兴亡，家族层管
那些跨朝代的制度结构——郡县、科举、小农经济、华夷秩序——如何在一次次
崩溃中被再生产出来。

## 一、诞生

中国古代史有两次"创世"。第一次是**内部的**：司马迁《史记》（前 91 年）
以纪传体立"通古今之变"之范，此后两千年正史连绵不断——中国是世界上唯一
保有连续官修史书传统的文明。第二次是**现代学术的**：19 世纪末甲骨文发现
（1899）与 20 世纪初罗振玉、王国维开创的"二重证据法"（地下之材料与
纸上之材料互证），加上疑古运动（顾颉刚）与马克思主义分期论（郭沫若
《中国古代社会研究》1930），把"旧史学"改造成现代断代研究。今天的
古代史=传世文献+出土文字+考古发掘三源合流。

## 三、核心问题（已解决里程碑 + 未解）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 商代信史地位 | ✅ 已解（王国维 1917） | 甲骨文证实《史记·殷本纪》世系——中国信史推到前 14 世纪 |
| 中国文明起源是单中心还是多中心 | ✅ 主流落定 | 苏秉琦"满天星斗"：区系类型并行，中原是熔炉不是唯一光源 |
| 唐宋之间是不是质变 | 🔄 百年争论 | 内藤湖南"唐宋变革论"（1910s）：中古→近世的转折，中日学界百年拉锯 |
| 大一统为何崩溃后总能重建 | 🔄 结构之谜 | 郡县-文官-科举的"结构再生产"，尚无公认定量模型 |
| 清代为何由盛转衰（内卷 vs 停滞） | 🔄 前线 | 大分流之争的另一半：1750 前江南曾是世界最富地区之一 |
| 出土文献的井喷还能改写多少历史 | 🔄 进行时 | 清华简、里耶秦简、走马楼吴简——每批新材料都可能推翻成说 |

## 四、假设与代价

本家族站在三条假设上：①**传世文献有代表性**——但二十四史是胜利者与
官方筛选后的幸存样本（幸存偏差是它的第一原罪）；②**断代是有效容器**——
但"唐宋变革"恰恰跨容器，分期切在问题转换处，不切在日历上；③**出土与
传世可互证**——二重证据法假设两类材料指向同一历史实在，简帛学对此已有
方法论修正。
