# 讲透先秦史 · 从满天星斗到天下一统

> 这支负责：**中国文明的形成期**——从邦国林立到三代王朝再到秦统一
> （约前 2070—前 221）。今日"中国"的全部底层协议（文字、王权、
> 天命、礼制）都在这段写好。
>
> GB/T 13745：77030 三级"先秦史"。家族：[讲透中国古代史](../README.md)。

## 定位句

先秦史回答三个起源问题：国家从哪来（二里头与邦国时代）、王权如何
合法（天命与礼制）、华夏如何成形（三代互动与"满天星斗"的区域并立）。
它的特殊性在于**无当时传世文献可全信**——考古与古文字（甲骨金文）
是第一证据，文献（《尚书》《史记》三代本纪）是需要审计的二手信息。

## 诞生

1920s 疑古运动（顾颉刚"层累地造成的中国古史"）把三代打成传说；
1928 安阳殷墟发掘启动，甲骨与宫殿基址把商代拉回信史；1980s 起
苏秉琦提出区系类型理论——中国文明起源从"中原一支独大"改写为
"满天星斗"；夏商周断代工程（1996-2000）给出三代年代框架（争议仍在）。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 商代是否信史 | ✅ 已解（王国维 1917/殷墟 1928） | 甲骨证世系+考古证都城，中国信史上推至前 14 世纪 |
| 二里头是不是夏都 | 🔄 持续争论 | 无自证文字，"对号入座"难题是考古学认识论的活标本 |
| 文明起源单中心还是多中心 | ✅ 主流落定 | 满天星斗→中原核心化，而非一线单传 |
| 封建制如何运作 | 🔄 进行时 | 西周分封=武装殖民+礼制网络，出土青铜器铭文持续补证 |
| 从封建到郡县的关键一环 | 🔄 战国转型 | 战国变法（郡县/编户/官僚）是秦统一的真实准备 |

## ✨ 最美的一个事实

**王国维 1917《殷卜辞中所见先公先王考》**：用甲骨文世系与《史记·
殷本纪》逐一对勘，商王世系几乎全部吻合——三千年前司马迁仅凭残存
文献排出的王表，被地下出土的"商朝人自己刻的字"证实。地下之材料与
纸上之材料互证（二重证据法）由此立范。

## 假设与依赖

考古类型学与碳十四测年是时间骨架；依赖[讲透中国古文字](../讲透中国古文字/)
（甲骨金文释读）与考古学（GB/T 780）的外部供给；"夏"作为朝代的
叙述暂系于文献与考古的间接对勘——本支对"对号入座"保持方法论克制。
