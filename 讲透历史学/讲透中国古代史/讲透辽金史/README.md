# 讲透辽金史 · 从边疆看中国：内亚王朝的双轨制

> 这支负责：**征服王朝的中国化实验**（辽 916-1125，金 1115-1234）——
> 契丹与女真如何同时统治草原与农耕，把"农牧二元"写成国家制度；
> 以及这段历史如何改写"何谓中国"的边界。
>
> GB/T 13745：77030 三级"辽金史"。家族：[讲透中国古代史](../README.md)。

## 定位句

辽金史把中国史从"中原向外辐射"的单向叙事倒转过来：辽的南北面官、
金的猛安谋克迁入中原、两个王朝的"中国"自称（辽自称"北朝"）——
**"多元一体"不是现代发明，辽金是第一个制度化的双轨实验场**。
这支的工具是汉文文献+契丹文/女真文出土文字+考古三源合流。

## 诞生

金代已修《辽史》，元修《金史》（1344）——但正史把辽金压成"旁支"；
19 世纪以降契丹文碑刻出土，20 世纪辽陵与城址考古展开；中国学统由
陈述、傅乐焕奠基，刘浦江《松漠之间》完成范式收束（族群互动+政治
制度并重）；"征服王朝论"（魏特夫 1950s）与"新清史"问题意识在此
汇流——辽金是清代的预演。

## ✨ 最美的一个事实

**辽的"南北面官"**：北面官治契丹诸游牧部落、南面官治汉地州县，
两套官制、两种法律、两个文化空间共用一个皇权——**把生态边界的
二元性写成宪法**。此后金、元、清的双轨治理全部由此发牌，
这是中国给大型多民族帝国治理史的第一份原创方案。

## 假设与依赖

辽金传世文献极薄（《辽史》成书仓促为正史之最），严重依赖考古与
民族文字释读；"汉化-蕃化"二分法本身需要被超越（互动模型替代
单向同化）；依赖[讲透中国古文字](../讲透中国古文字/)支的少数民族
古文字方向与考古学（780）外部供给。
