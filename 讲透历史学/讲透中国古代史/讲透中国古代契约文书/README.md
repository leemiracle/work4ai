> 这支负责：**民间社会的自我管理档案**——敦煌契约、明清徽州文书、
> 鱼鳞册黄册：土地怎么买卖、纠纷怎么解决、赋役怎么登记，

## 定位句

正史写国家，契约写社会。这支研究中国普通人用纸管理生活的两千年
传统：从汉晋简牍契约到敦煌吐鲁番文书，再到徽州数十万件契约与
鱼鳞图册——**中国农民没有罗马法，但有一套高效的文书实践**：
立契、中人、画押、悔约罚则，程序完备且跨地域稳定，使大规模
计量研究成为可能。

## 诞生

1900 敦煌藏经洞打开，数万件 4-11 世纪写本流散全球，催生敦煌学
（"吾国学术之伤心史"——陈寅恪）；1950s 徽州文书被陆续发现，
数十年间累积数十万件，形成"徽学"；黄册、鱼鳞册研究（栾成显）
把明代赋役档案变成制度-社会双线证据；21 世纪清水江文书等新区域
文书群持续进入视野——本支的史料供给曲线至今仍在上升。

## ✨ 最美的一个事实

**徽州：一个盆地留下十万件契约**。从南宋到民国，买卖、典当、
分家、山场股份、庙产轮值……同一群山民的纸面生活连续八百年不断
档。**这是世界史上罕见的"民间社会自我记录"完整样本**——
social history 的天然实验室，也是计量史学（家族 [04 章](../04-中国古代史转代码.md)）
最厚的一口井。

## 假设与依赖

契约是"纠纷预备文件"——留存的契约过采样了冲突场景；徽州经验
不能外推为"中国传统社会"（区域偏样）；文书残缺与归户难题
（同一家的文书被拆散）需要档案学方法。依赖家族 [02 章](../02-语言特征.md)
（套语与俗字）、[讲透宋史](../讲透宋史/)与[讲透清史](../讲透清史/)
（文书的时间两翼）。
