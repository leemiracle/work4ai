# 讲透清史 · 多元一统的极盛与内卷

> 这支负责：**帝制中国的最后一章**（本支主 1644—1840，1840 后衔接
> [讲透中国近现代史](../../讲透中国近现代史/)）——疆域倍增的多元一体
> 帝国、人口从 1 亿冲到 4 亿的内卷增长、以及大分流争论的"前半场"。
>
> GB/T 13745：77030 三级"清史"。家族：[讲透中国古代史](../README.md)。

## 定位句

清史古代段回答两个问题：其一，一个渔猎-游牧出身的小族群如何
建造并维系 1300 万平方公里的多元帝国（汉地十八省+满蒙藏回五套
治理系统）；其二，这个史上最大人口经济体为何在 18 世纪与西欧
分道扬镳（大分流：江南 vs 英格兰）。**清是古代史的终点，
也是近代史全部问题的起点。**

## 诞生

民国清史馆《清史稿》（1928，仓促且有遗民立场）；20 世纪明清档案
（内阁大库 8000 袋劫余）归中研院史语所，启动清史实证研究；
1970s 起"清朝国家形成"研究兴起；1996 《剑桥中国清代前中期史》
与 2000s "新清史"论战（罗友枝 vs 何炳棣，1996）把"汉化 vs 内亚
性"推成国际显学；内卷化（involution，黄宗智）与"高水平均衡陷阱"
（Mark Elvin）给经济侧提供概念工具。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 清帝国的多元治理结构 | ✅ 框架成熟 | 理藩院+驻防+盟旗+伯克：多法域帝国 |
| "汉化 vs 内亚性"之争 | 🔄 论战持续 | 何炳棣-罗友枝之争 30 年未终审 |
| 人口为何冲到 4 亿 | ✅ 主线清楚 | 新大陆作物+赋役制度+和平红利 |
| 为何未发生工业革命 | 🔄 大分流前线 | 江南与英格兰的逐项对勘仍在细化 |
| 盛世背后的财政脆弱 | 🔄 进行时 | "不加赋"的刚性收入 vs 人口爆炸的支出 |

## ✨ 最美的一个事实

**何炳棣-罗友枝论战（1996）**：一场关于"清朝成功的钥匙是汉化还是
内亚技艺"的学术对峙，把一个断代史问题升级为"帝国是什么"的
一般理论问题——此后 20 年清史研究的问题表几乎全部由这场论战
重排。**一场没有终审判决的官司，恰恰是学科最健康的状态。**

## 假设与依赖

清档案存世量古代史之最（内廷/军机/宫中档数百万件）但开放与
整理进度不均；"盛清"叙事需与 18 世纪的生态压力并读；本支与
近现代史家族在 1840 处需要明确分工口径（本支止于鸦片战争前夜，
晚清政治史在[讲透中国近现代史](../../讲透中国近现代史/)）。
依赖[讲透辽金史](../讲透辽金史/)（内亚脉络）与[讲透明史](../讲透明史/)
（白银财政的续章）。
