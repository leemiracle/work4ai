# 讲透隋唐五代十国史 · 帝国巅峰与崩解的全周期

> 这支负责：**中华帝国的黄金周期**（581—960）——隋的制度奠基、唐的
> 极盛与安史之变、五代的碎片化：一个完整"起-盛-衰-解"周期，内部
> 装着中国史最著名的制度创新（科举）与最经典的崩解案例（藩镇）。
>
> GB/T 13745：77030 三级"隋唐五代十国史"。家族：[讲透中国古代史](../README.md)。

## 定位句

这支的两端各有一个大问题：起点问**隋唐从哪来**（关陇集团的胡汉
军功贵族如何熔铸新帝国），终点问**唐为何死而帝国模式不死**（藩镇
割据五十余年，但"中国必再统一"已是所有玩家的默认预期）。中段的
科举、两税法、律令格式，是此后一千年制度的母版。

## 诞生

唐代自我叙述（正史+杜佑《通典》制度百科）已具研究雏形；现代学术
两大奠基：陈寅恪"关陇集团"与"藩镇论"（1940s-50s）立下全部大命题；
20 世纪敦煌吐鲁番文书出土地命中唐代（户籍、契约、过所），使唐代
基层社会成为中古实证最厚的断代；近三十年长安城考古与墓志大爆
（新出墓志逾万方）持续改写政治网络。

## ✨ 最美的一个事实

**《通典》——中国第一部制度史专著（杜佑，801 年）**：当欧洲还在
中世纪早期，杜佑已把职官、选举、食货、边防写成有体系的"帝国运行
手册"。它证明唐人不仅建造制度，还发明了"制度史学"本身——研究
唐朝的最好工具之一，是唐朝人自己造的。

## 假设与依赖

长安中心叙事偏重（边镇与江南常被降为配角）；墓志是精英+付费样本；
"盛唐"审美可能干扰对中晚唐的评估（中晚唐的财政国家与文学革新
实际更强）。依赖家族 [02 章](../02-语言特征.md)（文书语言）与
敦煌契约的[讲透中国古代契约文书](../讲透中国古代契约文书/)支。
