# 讲透魏晋南北朝史 · 分裂四百年，族群大熔炉

> 这支负责：**帝国的崩溃与重组**（220—589）——门阀政治、五胡政权、
> 佛道兴起、北朝再造：分裂期不是空白期，而是隋唐盛世的锻造车间。
>
> GB/T 13745：77030 三级"魏晋南北朝史"。家族：[讲透中国古代史](../README.md)。

## 定位句

魏晋南北朝史研究两件事：其一，大一统解体后，哪些结构死了（皇权直控
编户）、哪些变了（皇权与门阀共治）；其二，内迁诸族如何在华北建立
政权、又如何在制度与血统上"华夏化"，反向给"中国"注入新的边界观
（北魏孝文帝改革是定音锤）。**"隋唐的强盛是北朝给的"是本支最核心
的再认识。**

## 诞生

唐代史官已把这段写成"乱世"（《晋书》的道德叙事）；现代学术化自
陈寅恪《隋唐制度渊源略论稿》（1940s）——从北朝胡汉杂糅里钩出隋唐
制度的谱系；田余庆《东晋门阀政治》（1989）用政治史细读确立
"门阀与皇权共天下"的分析范式；考古（墓志、壁画、平城与洛阳城址）
三十年来持续补写物质侧。

## ✨ 最美的一个事实

**田余庆从一句童谣重建权力结构**："王与马，共天下"本是对王导-司马睿
组合的民间讥语；田余庆以残缺史料层层钩沉，还原出皇权与琅琊王氏
"合伙创业"的契约结构——**一句童谣的史学含量超过一篇平庸长文**，
示范了政治史细读的极限精度。

## 假设与依赖

史料奇缺且幸存极偏（南方士族视角为主）；墓志材料大增但仍属"精英
抽样"；"华夏化"叙事需警惕以唐代结果倒放。依赖家族 [03 章](../03-可构造与结构.md)
的世系/职官构造法消化墓志数据。
