## 这支最美的一个事实

**任何切法都自圆其说一部分**——"唐宋变革"与"宋元明连续"都有
扎实的证据；断点的"事实性"远低于直觉：**你先选了刀，才看见了缝**。
分期方法论的核心教训：带着多把刀读史。
