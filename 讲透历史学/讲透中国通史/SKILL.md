# 通史眼：看节律不看事件

## ① 何时用此分支（触发特征）

- 要为一段长历史（组织史/技术史/学科史/文明史）选择讲法或分期
- 看到宏大周期论断（"分久必合""技术循环""组织兴衰律"），想评估其强度
- 需要跨历法/跨纪年体系整理时间线（年号/干支/财政年/版本号）
- 判断"某个断点是不是真的断裂"（变革 vs 噪音）

## ② 核心思维模式

1. **双层拆解**：先分"事实节律层"（数据可检验）与"机制解释层"（叙事可反驳）——
   规律断言只在第二层，强度天然降一级
2. **多套分期并置**：任何切法都是历史观；带两三把刀看同一长时段
3. **索引意识**：任何长时段叙述都是按某列建索引（时间/人物/事件/框架），
   索引必弃维度——"全面史"形式上不存在
4. **政权/制度分层**：换的是国号还是地质？制度连续性才是"通"的骨架

## ③ 工具箱

| 工具 | 一句话·何时用 |
|------|--------------|
| 干支引擎 | `(y-4)%10/%12` 两行模算术——任何循环纪年体系的换算原型 |
| 索引三分法 | 评一部史书/公司史：问它按时间、人物还是事件切片 |
| 变点检测做镜子 | 机器断点（无历史观）对照史家断点，分歧处即争点 |
| 反事实三板斧 | 反事实用于暴露假设，不用于裁决——说了不算数 |
| 断点强度分级 | 年表级>过程级>规律级——先问断言属于哪级再争论 |

## ④ 常见误区与禁忌

- ❌ 把叙事概括当规律（"分久必合"是节律描述，不是力学定律）
- ❌ 单一分期走天下——切法即立场，独尊一刀就是独尊一种史观
- ❌ 数据补历史——序列稀疏且偏（偏灾异/精英），量化是盘问不是替代
- ❌ 坐标与解释混写——纪年换算应剥离成可测组件，别让历法错误污染解释争论

## ⑤ 与相邻分支的判别表

| 问题长这样 | 去哪个分支 |
|-----------|-----------|
| 三千年怎么切/通史怎么写 | **本分支（中国通史）** |
| 某段史事的具体考订 | 断代家族（中国古代史/近现代史） |
| 文本哪个本子可靠 | 讲透历史文献学 |
| 长周期节律的形式化 | 讲透数学/讲透分析/讲透动力系统 |
| 经济分流的全球比较 | 讲透经济学（经济史侧） |
| 事件网络/人物关系 | 讲透数学/讲透图 |

组合接口：通史（分期框架）→ 断代史（合同执行）；通史 × 动力系统（周期语言）= 节律的形式化现场。
