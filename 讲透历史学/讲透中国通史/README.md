# 讲透中国通史 · 把三千年读成一部有结构的长时间

> 通史不是"断代史拼接"，是一门**分期之学**：在哪里切分三千年，
> 决定了你看到的结构是什么——统一与分裂的节律、王朝循环的机制、
> 长时段的变迁（经济重心南移/人口周期/制度累积）。**换一种切法，就是换一部中国史**。

## 一、诞生（三个原生问题）

1. **怎么写"古今"**：司马迁《史记》（约前 91 年）发明纪传体通史——
   从黄帝到汉武帝三千年一贯，"通"是发明出来的，不是天然的。
2. **怎么从历史里学治理**：司马光《资治通鉴》（1084）用编年体重写战国到五代
   1362 年——"鉴于往事，有资于治道"，通史的第二个动机：治国手册。
3. **三千年是停滞还是循环还是演化**：近代以来的大问题——古史分期论战
   （社会史论战，1930s）、"唐宋变革论"（内藤湖南）、"高水平均衡陷阱"
   （伊懋可）与加州学派的反驳（彭慕兰《大分流》）——每一次分期主张，
   背后都是一套"历史是什么"的哲学。

📖 **故事**：钱穆 1939 年在抗战流离中写《国史大纲》，开篇先立
"对其本国已往历史之温情与敬意"四条信念——通史写作从来不是中立的技术活：
**切分三千年的人，必须先声明自己站在哪里看**。

| 唐宋变革论（内藤假说） | 🔄 修正中（"宋代近世说"百年争鸣，中古/近世边界之争） | 一条分期线撬动整部社会史 |
| 大分流问题（为何是欧洲） | 🔄 前线（加州学派 vs 传统解释持续交锋） | 通史终点的全球比较——中国史与世界史的接口 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 三千年有连续性（"中国"可通贯叙述） | 通史可能 | 连续性预设会抹平断裂（改朝换代/族群迁移的质变） |
| 存在可辨识的分期断点 | 结构可讲 | 断点是建构——任何切法都能自圆其说一部分 |
| 王朝是有效的叙述单位 | 叙事抓手 | 王朝框架遮蔽长时段（经济/气候/人口不听皇帝的） |
