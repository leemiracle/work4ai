# 讲透历史学 · 问题转 code 路由表

> **本表定位**：把历史学的真实问题/任务**逐条翻译成 code 任务**。
> 家族 04 章（如 [专门史](讲透专门史/04-专门史转代码.md)、[历史文献学](讲透历史文献学/04-历史文献学转代码.md)）管**边界与走廊**——计量史学的五条走廊（名录/序列/词频/网络/GIS）、可机械化档位、"AI 可算密度不可替考据"的红线；
> 本表管**具体问题怎么接单**——一句话问题进来，形式化、code 任务、工具、坑、落点家族一行查清。
> 全表覆盖 13 家族；[C] 层条目与专门史 04 章"不可机械化"清单严格对齐。
> 姊妹表：[讲透物理学 · 问题转 code 路由表](../讲透物理学/问题转code路由.md)。

## 〇、使用方法（三步）

1. **查表**：找到最接近你问题的一行，先读"形式化后"列——
   这一步写不出来，说明问题还没到接代码的成熟度（回尾部工作流第 1 步回炉）。
2. **对读**：跳到"落点家族"的 04 章，在其可机械化边界确认档位；
   历史问题的第一坑几乎总是**口径**（数的是什么单位、谁被统计、谁被漏掉），
   接单前先在 04 章对齐该问题领域的口径判例。
3. **接单**：按"算法/库"列的最轻项起步——百行脚本跑通，再谈平台化。

**层标**（标于"领域问题"列首）：

- **[A] 可直接编码**：数据在手即可跑，算法与库现成，课内一天量级；
- **[B] 需先建模**：成败主体在建模选择（口径对齐/特征设计/记录链接规则），编码是后半程；
- **[C] 研究级开放**：考据责任制所在，AI 可做辅助与密度，**不可替定谳**。

**查不到怎么办**：先看能否拆成表内两行以上的组合（如"人口序列"+"政区叠加"=区域人口史闭环）；
拆不动的问题多半缺数据或缺口径判例——先补口径，再谈代码。

## 二、覆盖与走廊分布

**覆盖声明**：13 家族全落子（每家族至少 1 行）。按专门史五走廊归类——

- **名录**：#2、#3、#30；**序列**：#1、#21-#23、#27、#29；
  **词频**：#5、#6、#11、#18；**网络**：#3、#12、#26、#30；**GIS**：#13、#14、#26、#28；
- 五走廊之外，表内另有两条支线：**文本工程**（#4、#7、#8、#17、#25——
  检索/OCR/校勘/转写/对勘，全是数据基础设施，A/B 层）与
  **考据辅助**（#9、#10、#15、#31——谱系/考证/释读/反事实，全部 [C] 层）；
- 表的结构就是学科的结构：**地基可自动化，定谳不可**——
  五走廊与文本工程覆盖了本表全部 [A]/[B] 层，四条 [C] 全部压在
  "AI 可算密度，不可替考据"红线上（与专门史 04 章不可机械化清单一一对应）。

## 五、通用工作流（问题→形式化→选走廊→写断言）

1. **问题→形式化**：把一句话问题改写成"输入/输出/判据"三元组；
   历史问题的判据里必须含**口径声明**（统计单位/来源边界/谁被漏掉），
   写不出→ 回炉，不许带病接单。
2. **形式化→选走廊**：查本表定落点家族与 code 任务；进家族 04 章
   对齐该领域的口径判例；跨家族问题按"数据与口径正主在哪"归队
   （#1 口径正主在计量史学→归专门史，尽管数据出自断代史）。
3. **选走廊→写 code**：最轻工具起步（百行脚本），跑通后再平台化；
   [B] 层预算分配参考：口径与建模七成、编码三成。
4. **写断言**：每条序列配口径标注（同一条曲线不同区间含义不同，见 #1）；
   每个量化结果要能回答"数在说谎时谎在哪一层"——
   能对拍第二数据源的，必须对拍（#27 代用资料×文献即为此设）。

### 接单示范（#1 定量某朝人口，B 层走完全程）

1. **形式化**：输入=正史历代户口序列；输出=实际人口估计区间；
   判据=与人口学界共识区间交叉验证。
2. **口径声明**（B 层的核心动作）：宋"口"仅计男丁、清"丁"先是税额单位——
   同一列数在不同区间含义不同；先做口径分段，再谈曲线本身。
3. **写 code**：pandas 内嵌数据表+分段标注
   （[专门史实验脚本](讲透专门史/experiments/china_population_series.py)即现成标本）。
4. **写断言**：755→760 官方户口跌 ~68% 处必须触发口径断言——
   登记崩塌≠人口崩塌；输出的不是"人口曲线"，是"带口径注释的区间图"。
