# 讲透法国史 · 大革命与政体钟摆

> 支：[讲透欧洲史](../README.md) GB/T 三级支。1789 之后，法国把
> "什么是现代政治"的问题重复实验了两百多年。

## 定位句（①本质）

本支负责**法国通史**：卡佩王朝的国家建构→大革命及其出口（人权、
公民、民族、左右）→帝国-王朝-共和的反复摇摆→第五共和——政治
现代性的原型实验室。

## 诞生（②怎么产生）

- 19 世纪基佐（自由主义官学）与米什莱《法国史》（浪漫民族史学
  巅峰："我找回我的祖国"）
- 1856 托克维尔《旧制度与大革命》：革命连续性命题（旧制度死于
  自身的成功）——所有革命史研究的理论起点
- 1929 年鉴学派在斯特拉斯堡创刊——法国史学的方法革命；1978 福雷
  《思考法国大革命》终结社会解释一统："大革命结束了"

## 核心问题（③问题清单）

| 问题 | 状态 |
|------|------|
| 大革命起源：社会危机还是政治文化危机 | 🔄 索布尔（社会） vs 福雷（政治）——范式级对峙 |
| 革命与旧制度的连续性 | ✅ 托克维尔命题基本成立（行政集权被革命继承） |

## ✨ 最美的一个事实（⑧美之时刻）

1791-1958 法国产生十三部宪法文本，平均约 13.9 年一部（本家族实验
断言 5）——"政体钟摆"不是修辞，是频率：欧洲最激进的共和实验室，
也是政权形式最不稳定的西方大国。

## 反直觉（⑥）

大革命最重要的一夜不是攻占巴士底（1789-07-14，守军不足百人），
而是 8 月 4 日之夜——贵族一夜之间放弃封建特权：**革命的动力常常是
精英的自我解散，而不是群众的冲锋**。

## 假设与依赖（④假设与代价）

假设"革命"是理解法国近现代的总钥匙（买到：两百年的问题清单清晰；
付出：旧制度八百年被压缩成"序幕"——年鉴学派正是在给"序幕"翻案）。

## 教材锚

托克维尔《旧制度与大革命》；福雷《思考法国大革命》；古贝尔《路易
十四时代的法国》；朱特《战后欧洲史》（法国章节）。
