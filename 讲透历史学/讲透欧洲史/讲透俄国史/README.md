# 讲透俄国史 · 欧洲最东的扩张机器

> 支：[讲透欧洲史](../README.md) GB/T 三级支。基辅受洗到苏联解体——
> 一条持续四百年的大陆扩张线，与一个从未解决的出海口执念。

## 定位句（①本质）

本支负责**俄罗斯通史**：基辅罗斯（988 受洗）→蒙古时期的东北罗斯→
莫斯科公国→彼得帝国→1917 革命→苏联→1991 后转型——欧洲的东方
边界、亚洲的西方参与者、大陆帝国的极端案例。

## 诞生（②怎么产生）

- 1818-29 卡拉姆津《俄国国家史》：官方-感伤主义奠基作（献给亚历山大
  一世）；索洛维约夫、克柳切夫斯基接续建成学院谱系
- 苏联时期马克思主义史学（波克罗夫斯基）与西方"克里姆林学"对峙
- 冷战后档案开放（1991）重写革命史：派普斯（Pipes）与菲格斯（Figes）
  的"自上而下 vs 自下而上"论战

## ✨ 最美的一个事实（⑧美之时刻）

从莫斯科公国（约 200 万 km²）到苏联（2240 万 km²）：四百年平均每天
吞并约 130 平方公里——但四个世纪的扩张始终没有换来一个可靠的不冻
出海口：**大陆帝国的悖论——越大越渴**。

## 反直觉（⑥）

"极权主义"模型把俄国史读成连续的专制常量；但 1905-1917 的俄国曾是
欧洲最活跃的议会-出版-结社社会之一——**沙皇末期不是"停滞的前夜"，
而是被战争引爆的多元社会**（修正派的核心发现）。

## 假设与依赖（④假设与代价）

假设"欧亚"是分析单位（买到：扩张线与民族问题可整体处理；付出：
"西方派 vs 斯拉夫派"的百年争论被结构化为学科预设——俄国永远是
"属于哪里"的问题本身）。
