# 讲透西班牙史 · 第一个全球帝国的兴衰与转型

> 支：[讲透欧洲史](../README.md) GB/T 三级支。1492 年的三件大事
> 开启全球化，1898 年的一年清算结束帝国——西班牙是"帝国周期"的
> 完整标本。

## 定位句（①本质）

本支负责**西班牙通史**：收复失地运动→哈布斯堡全球帝国（第一个
"日不落"）→波旁改革与拿破仑危机→1898 灾难→内战与佛朗哥→
1975-78 协商民主转型——帝国兴衰与民主转型的双标本。

## 诞生（②怎么产生）

- 16-17 世纪官方编年史学（印第安编年史是世界史料的富矿）；18-19
  世纪自由派史学与"黑色传说"（Leyenda negra）之争成为主线
- 20 世纪卡斯楚-桑切斯-阿尔沃诺斯论战：西班牙身份是"三文化共存"
  还是"冲突排他"——本支的元问题
- 佛朗哥后流亡史学回归 + 普雷斯顿/托马斯的英语内战史——内战史学
  战至今未熄

## ✨ 最美的一个事实（⑧美之时刻）

1492 年的三连击：1 月格拉纳达陷落（收复失地完成）、3 月驱逐犹太人
法令、8 月哥伦布启航——**同一年的三个事件分别关闭了中世纪、撕裂了
社会、打开了全球化**；而 1898 年一年之内失去古巴、波多黎各、菲律宾、
关岛：三百年帝国一年清盘。西班牙史把"帝国的生老病死"压缩成两个
年份。

## 反直觉（⑥）

西班牙帝国的核心难题不是"获得"而是"治理"：白银流入的净效应是
帝国自身的去工业化（制造业被进口替代）与欧洲金融中心的转移——
**第一个吃到全球化的，也是第一个被全球化吃掉的**。

## 假设与依赖（④假设与代价）

假设"帝国"是西班牙史的主轴（买到：兴衰叙事完整；付出：半岛内部
的加泰罗尼亚、巴斯克问题需要独立线——1978 自治区体制是帝国遗产
与民族问题的当代和解方案，仍在承受压力测试）。
