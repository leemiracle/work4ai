# 讲透北欧国家史 · 从战争机器到福利国家

> 支：[讲透欧洲史](../README.md) GB/T 三级支。丹麦-瑞典-挪威-芬兰-
> 冰岛：维京的子孙如何把欧洲最凶的军事机器改写成最温和的社会。

## 定位句（①本质）

本支负责**北欧复合国家史**：维京世界→卡尔马联盟（1397）与瑞典
帝国时代→1814 后的小国化→社会民主与福利国家（20 世纪）→当代
北欧模式——"从输出暴力到输出规范"的四百年转身。

## 诞生（②怎么产生）

- 冰岛萨迦（13-14 世纪成文）：世俗叙事文学的早熟高峰，也是维京
  世界的一手史料
- 19 世纪民族浪漫主义史学为独立运动服务（挪威 1814/1905、芬兰
  1917 叙事）
- 1950s 后"北欧模式"研究兴起：社会民主史观与"小国和平主义"
  自我叙事成为学术对象——近年再被右翼民粹与新实证史学双重检验

## ✨ 最美的一个事实（⑧美之时刻）

冰岛阿尔庭（Althing）建于 930 年——**世界现存最古老的议会**；而
瑞典自 1814 年起 200 余年未参加战争——欧洲现存最长和平纪录。同
一片土地，16-17 世纪还是古斯塔夫·阿道夫的军事机器（三十年战争
的最强军团）：北欧史是"战争与和平可以互相转化"的完整实验记录。

## 反直觉（⑥）

福利国家不是富了以后才建的：北欧模式的地基（义务教育、互助金、
全民保险）多在还很穷的 19 世纪末-20 世纪初铺设——**共同体保险
先于共同财富**，方向与"先富后福利"的直觉相反。

## 假设与依赖（④假设与代价）

假设"北欧五国"可比（买到：小样本高相似度的比较实验；付出：冰岛
（殖民地身份）与芬兰（俄瑞之间）的历史线与斯堪的纳维亚三国差异
不小）；萨迦史料的"文学性折扣"是本支的常年作业。

## 教材锚

诺德斯特罗姆《1500 年以来的斯堪的纳维亚》；希尔森《北欧模式》；
萨迦选集（《尼亚尔萨迦》等，史源批判读）。
