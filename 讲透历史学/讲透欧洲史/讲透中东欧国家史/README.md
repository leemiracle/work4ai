# 讲透中东欧国家史 · 帝国之间的民族国家化

> 支：[讲透欧洲史](../README.md) GB/T 三级支。波兰-匈牙利-捷克-
> 巴尔干-波罗的海——"两强之间之地"（the lands between）的百年
> 挣扎：从多民族帝国到民族国家，再到欧盟成员。

## 定位句（①本质）

本支负责**中东欧复合国家史**（波兰、捷克、斯洛伐克、匈牙利、
罗马尼亚、巴尔干诸国、波罗的海三国）：四帝国（德俄奥匈奥斯曼）
之间的民族国家化进程、二战与苏联化、1989 转型——欧洲的"边境带"
如何变成"欧洲的腹地"。

## 诞生（②怎么产生）

- 一战结束四帝国解体（1917-1922，家族实验断言 1）——本支的国家
  体系由此诞生，"新国家的史学"与国家同龄
- 1984 昆德拉《中欧的悲剧》：被西欧误读的"绑架的西方"——"中欧"
  概念回归的思想宣言
- 1989 后转型比较史学（休克 vs 渐进）+ 戴维斯《上帝的游乐场》把
  波兰史写成英语世界的典范

## ✨ 最美的一个事实（⑧美之时刻）

波兰立陶宛联邦的"自由选王"与"自由否决权"（liberum veto）：议会
里**一名议员即可解散议会并否决全部已通过法案**——欧洲最大国家
之一以"极端分权"运转两百年，终被三家瓜分（1772/1793/1795），从
地图上消失 123 年。它是民主的祖先之一，也是"否决政治"的最早
警示标本。

## 反直觉（⑥）

"民族国家"在这个地带多是**进口品而非土产**：1918 年后的国界内
三分之一以上人口是"别的民族"——民族清洗与人口交换不是民族国家
的意外，而是它的**建成条件**（本支最沉重的反直觉）。

## 假设与依赖（④假设与代价）

假设"中东欧"是可比单位（买到：转型比较的平台；付出：北（波罗的海）
中南（哈布斯堡）东南（奥斯曼/拜占庭）三条历史线差异极大，比较须
带层标签）；多语史料（波兰/捷克/匈牙利/罗马尼亚语…）决定任何
综合都必然依赖转手文献——本支的诚实声明。
