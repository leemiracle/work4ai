# 讲透意大利史 · 从地理表达到国家工程

> 支：[讲透欧洲史](../README.md) GB/T 三级支。梅特涅说意大利只是
> "一个地理表达"——这个国家是用一百五十年的时间把自己造出来的。

## 定位句（①本质）

本支负责**意大利通史**：城市共和国与文艺复兴→外国统治下的分裂→
1861 统一（复兴运动）→法西斯主义的第一个成功→共和国与"经济奇迹"→
南北问题——"制造国家"与"制造民族"两个工程的竞赛史。

## 诞生（②怎么产生）

- 1520s 马基雅维利《佛罗伦萨史》：人文主义史学开山（政治智慧嵌进
  叙事）；圭恰迪尼接续实证化
- 19 世纪复兴运动史学（巴尔博《意大利的希望》）：史学直接服务统一
- 1945 后克罗齐《意大利史》与反法西斯史学重写近代；1976 金兹堡
  《奶酪与蛆虫》从意大利乡土长出微观史——世界史学方法的意大利贡献

## ✨ 最美的一个事实（⑧美之时刻）

1861 年统一时，日常说意大利语的人口仅约 2.5%（德莫罗 1963 年的
语言史统计）——**先有意大利，后有意大利人**："我们制造了意大利，
现在必须制造意大利人"（传为阿泽利奥语）。民族不是语言的产物，
是国家追认的工程。

## 反直觉（⑥）

文艺复兴不是"意大利的黄金时代"而是"城市精英的文化项目"：当时
九成以上人口是文盲农民，皮埃蒙特农民听说"意大利"这个国家时以为
是一位女王的名字（那不勒斯民歌《啊，我的太阳》时代的口述证词）——
文化史与大众史之间的落差本身就是史料。

## 假设与依赖（④假设与代价）

假设"统一"是意大利史的主轴（买到：1861 前后叙事清晰；付出：
威尼斯、那不勒斯、西西里各自的千年被折叠成"地方史"——城市史与
地方史（campanilismo）研究正在偿还这笔债）。

## 教材锚

金兹堡《奶酪与蛆虫》（微观史样本）；吉尔摩《追寻意大利》；金斯伯
格《意大利及其不满》。
