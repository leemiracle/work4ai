# 讲透欧洲史 · 最小的大陆，最大的世界影响

> 欧洲史：**多中心竞争的实验室**——罗马之后再无统一帝国，恰是这种
> 分裂让欧洲在近代跑赢；本学科的元问题："欧洲"是地理事实还是历史
> 工程（基督教世界→列强体系→欧盟）？
>
> GB/T 13745：77060（二级学科）。三级 8 支：俄国史·英国史·法国史·
> 德国史·意大利史·西班牙史·中东欧国家史·北欧国家史（欧洲共同体的
> 通史叙事归世界通史/世界中世纪史等断代支）。
> 宇宙：[讲透历史学](../README.md) · 区域史家族（章精简不注水）。

## 诞生

三个原生问题：①为什么分裂的欧洲在近代胜过统一的帝国？②民族国家
如何被发明又如何书写自己的历史？③欧洲作为整体的观念从何而来？
关键节点：文艺复兴人文主义者（布鲁尼、比昂多）发明"古代-中世纪-
近代"三分——**欧洲给自己发明了分期**；1756 伏尔泰《风俗论》首次写
"文明史"；1824 兰克《拉丁与日耳曼民族史》创立档案史学——欧洲史
长期充当全世界史学的"默认模板"；1929 年鉴学派（布洛赫、费弗尔）把
研究对象从事件转向结构；1949 布罗代尔《地中海》把结构史推到顶峰；
1990s 后"欧洲整合史"（欧盟作为史学对象）与"欧洲记忆研究"兴起。

## 假设与依赖

三条假设：①"欧洲"有可叙述的整体性（买到：断代对表便利；付出：俄国的
欧亚二重性、奥斯曼的边缘身份、拜占庭的独立线索长期被"西欧=欧洲"压缩）；
②民族国家是自然容器（买到：档案按国组织；付出：跨国进程——文艺复兴、
启蒙、工业革命——恰好不守国界）；③欧洲分期可外推（买到：全球通史骨架；
付出：这是本学科最大的历史负债——世界通史 00 章"分期自反"的源头）。

## 教材锚

- 蒂利《强制、资本与欧洲国家》——国家形成的社会学经典
- 布罗代尔《地中海与菲利普二世时代的地中海世界》——年鉴学派巅峰
