# 讲透英国史 · 宪政连续性的神话与真相

> 支：[讲透欧洲史](../README.md) GB/T 三级支。1066 到脱欧——第一个
> 工业国，与一部被后世追认出来的"古老宪政"。

## 定位句（①本质）

本支负责**英国（联合王国）通史**：诺曼征服→大宪章→内战与光荣革命→
第一帝国（大西洋）→工业革命→维多利亚帝国→20 世纪撤退与脱欧——
"连续渐进"的自我叙事与反复革命性并存。

## 诞生（②怎么产生）

- 1754-61 休谟《英国史》：第一部叙事成熟的多卷国史，作者靠它致富
- 1848-61 麦考莱《英国史》：辉格史学巅峰（"英国史=自由的成长史"）
- 1931 巴特菲尔德《辉格史解释》点名批评本支——"连续渐进"叙事本身
  成为史学史对象；1970s 革命修正派（拉塞尔等）再拆 1688

## ✨ 最美的一个事实（⑧美之时刻）

1215 大宪章颁布约十周即被教皇英诺森三世宣告无效，63 条中至今仍有
法律效力者仅 3 条——**它的宪法神圣地位是 17 世纪辉格法学家们的
发明**："传统"本身有生日，而且是个相当晚的生日。

## 反直觉（⑥）

"英国宪政连续渐进"是史学史上最成功的叙事工程之一：内战、弑君、
复辟、政变一样不少——连续的不是制度，是**叙事把断裂消化为演进**
的能力（本支给全家族的教训：先查连续性叙事的生产日期）。

## 假设与依赖（④假设与代价）

假设"联合王国"是单一单位（买到：议会-法律-财政记录全球最连续；
付出：苏格兰、爱尔兰被"英格兰史"吸收——四国史正是纠偏）。

## 教材锚

摩根主编《牛津英国史》；麦考莱（史源，批判读）；基思·托马斯《宗教
与巫术的衰落》；卡纳丁论帝国与阶级。
