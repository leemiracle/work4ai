# 讲透世界古代史 · 城市与文字的发明

> 支：[讲透世界通史](../README.md) GB/T 三级支。前 3000-476：从乌鲁克到
> 罗马陷落——原生文明各自生长，轴心时代同时开花。

## 定位句（①本质）

本支负责**文明的原生发生**：两河、埃及、印度河、黄河（及中美洲、安第斯
两个非旧大陆中心）如何各自从农业走向城市、文字与国家；古典地中海文明
（希腊、罗马）如何把这套遗产变成"传统"传给后世。

## 诞生（②怎么产生）

- 19 世纪埃及学（商博良破译圣书字 1822）与亚述学（楔形文字破译，1857
  四学者对照实验）创立：古代史第一次拥有原文
- 20 世纪考古学成熟（吴雷发掘乌尔、商代甲骨证史）把"传说时代"变成
  地层序列
- 1949 雅斯贝尔斯《历史的起源与目标》提出"轴心时代"，给本支以比较框架

## ✨ 最美的一个事实（⑧美之时刻）

轴心时代：前 800-200 年，黄河、恒河、爱琴海、黎凡特-伊朗一带**互不知晓**
的地区几乎同时产生批判性思想（诸子、佛陀、希腊哲学、先知）——人类史上
最壮观的平行对照实验，"同时性"至今没有公认解释。

## 反直觉（⑥）

四大文明"古国"里，延续性最好的不是埃及也不是中国，而是**美索不达米亚
的书写传统**——楔形文字作为行政语言被连续使用三千余年（至公元 1 世纪），
比任何帝国的寿命都长。

## 假设与依赖（④假设与代价）

假设"文明"是可比较的单位（买到：跨区域比较框架；付出：互相不可通约的
细节被剪掉）；假设晚期文献可回溯早期（汉距孔子五百年，司马迁的夏商
已是考古对象——文献与地层必须分账）。

## 教材锚

《剑桥古代史》；崔格尔《理解早期文明》（比较原生文明的标准著作）；
吴于廑、齐世荣《世界史》上古卷。
