# 讲透世界近代史 · 网络闭合与功率革命

> 支：[讲透世界通史](../README.md) GB/T 三级支。1500-1900：两个半球
> 接线，一台蒸汽机改写全球功率分配——"近代"是被制造出来的全球状态。

## 定位句（①本质）

本支负责**全球化的第一波**：哥伦布-达伽马的航海把两个生物圈、三个贸易
圈接成一张网；工业革命重分配了这张网上的功率；到 1900 年，"世界"第一次
有了单一的政治经济结构。

## 诞生（②怎么产生）

- 1756 伏尔泰《风俗论》：第一部把欧洲之外当作"历史"写的世界史尝试
- 19 世纪兰克学派建立档案史学，但把"世界史"写成欧洲外交史
- 1963 麦克尼尔《西方的兴起》与 1972 克罗斯比《哥伦布大交换》确立本支
  的全球-生态双框架；2000 彭慕兰《大分流》引爆核心争论

## ✨ 最美的一个事实（⑧美之时刻）

哥伦布交换的**生态单向性**：旧大陆带给美洲人口与牲畜（人、马、牛、
天花），美洲还给旧大陆卡路里（玉米、土豆、番薯）——美洲作物支撑了
明清中国人口从约 1.5 亿（1650）涨到约 4.3 亿（1850）：一场"植物学上的
再征服"（数据见家族实验断言 5 的窗口）。

## 反直觉（⑥）

1800 年以前的世界经济中心在亚洲而非欧洲——欧洲长期用美洲白银购买
"亚洲制造"；"西方领先"在历史时间里是一段很晚、很窄的事件，不是常态。

## 假设与依赖（④假设与代价）

假设"近代性"（modernization）是有内容的单数概念（买到：比较框架；付出：
多元近代性被压扁——日本明治、奥斯曼坦志麦特、清朝洋务各算什么？）；
假设 1500 是有效断点（美洲史对此表示同意，非洲史保留意见）。
