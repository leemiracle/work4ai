# 讲透原始社会史 · 人类史的 99%

> 支：[讲透世界通史](../README.md) GB/T 三级支。从猿人分家到农业起源——
> 没有文字的 700 万年，靠石头、骨头与基因写成。

## 定位句（①本质）

本支负责**文字之前的人类史**：人类起源、认知革命、狩猎采集社会、
农业起源与"原始社会"形态——一门证据全靠考古学、遗传学、语言学重建，
没有一手文字史料的史学。

## 诞生（②怎么产生）

- 1859《物种起源》→1871 达尔文《人类的由来》：把人纳入自然史
- 1877 摩尔根《古代社会》：亲属制度重建史前社会——恩格斯 1884《家庭、
  私有制和国家的起源》将其纳入马克思主义框架，深刻影响中苏学界
- 20 世纪碳十四测年（Libby 1949）+ 21 世纪古 DNA 革命（2010 尼安德特人
  基因组）两度重写本支

## ✨ 最美的一个事实（⑧美之时刻）

现存全人类的线粒体 DNA 溯至约 15-20 万年前非洲的一位女性（"线粒体夏娃"）
——她**不是当时唯一的女性**，而是唯一一条母系线延续至今的女性："夏娃"
之名是数学的，不是神话的。

## 反直觉（⑥）

"原始"不等于"简单"：狩猎采集者的食谱多样性、工时结构（"原始富裕社会"
假说）可能优于早期农民——农业不是进步的奖赏，更多是人口-生计的陷阱。

## 假设与依赖（④假设与代价）

假设"物质遗存能代表社会结构"（买到：无文字也有历史；付出：仪式、语言、
组织形态几乎全部丢失）；假设今人类比可用（民族志类比）——每个类比都是
一次赌博。

## 教材锚

达尔文《人类的由来》；摩尔根《古代社会》；恩格斯《家庭、私有制和国家的
起源》；当代综述见克里斯·斯特林格等古人类学通论。
