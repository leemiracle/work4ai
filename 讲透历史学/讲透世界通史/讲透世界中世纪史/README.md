# 讲透世界中世纪史 · 旧世界的三大网络

> 支：[讲透世界通史](../README.md) GB/T 三级支。476-1500：不是欧洲的
> 黑暗时代，而是伊斯兰黄金期、唐宋变革与蒙古治世——三大网络缝合旧世界。

## 定位句（①本质）

本支负责**全球网络成形期**：西欧重组、伊斯兰世界崛起、中华帝国的唐宋
高峰、游牧世界的蒙古整合——"中世纪"这个词只在欧洲是自指，在其他地方
都是他者的纪年。

## 诞生（②怎么产生）

- 15 世纪人文主义者发明"中世纪"（medium aevum）自饰"再生"——概念
  出生即带宣传目的
- 1937 皮朗遗著《穆罕默德与查理曼》：地中海的关闭而非日耳曼入侵决定
  中世纪欧洲——现代中世纪学的起点
- 20 世纪末"全球中世纪"（Global Middle Ages）运动把本支从欧洲史
  解放成世界史

## ✨ 最美的一个事实（⑧美之时刻）

皮朗命题倒过来看：决定欧洲命运的不是日耳曼人入主罗马，而是**地中海的
关闭**——"没有穆罕默德，查理曼就不可想象"。一位比利时史家在战俘营里
想出的命题，重塑了整个领域对"欧洲从哪里来"的回答。

## 反直觉（⑥）

"黑暗时代"的欧洲恰恰是技术进步期：重犁、马轭、水车、三分轮作在
6-10 世纪相继普及——罗马的奴隶制经济从不觉得值得省力，"落后的"中世纪
农民才需要机器。

## 假设与依赖（④假设与代价）

假设 476-1500 的欧洲纪年可作全球框架（买到：教学对齐；付出：美洲完全
缺席、非洲只剩斯瓦希里海岸的侧影）；假设宗教共同体（基督教世界/伊斯兰
世界/佛教世界）是有效分析单位。
