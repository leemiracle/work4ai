# 讲透世界现代史 · 总体战、冷战与全球化的反复

> 支：[讲透世界通史](../README.md) GB/T 三级支。1900-今：人类第一次拥有
> 摧毁自己的能力，也第一次把整个星球装进一个体系。

## 定位句（①本质）

本支负责**单一世界体系的运行与应激**：两次总体战、去殖民化、冷战两极、
全球化及其逆流——"现代史"是第一段有"全球同时性"的史学（每个事件都有
实时全球回声）。

## 诞生（②怎么产生）

- 1964 巴勒克拉夫《当代史导论》确立"当代史"作为独立史学对象（离身
  太近的历史如何写——方法论自觉的起点）
- 1961 菲舍尔《争雄世界》引爆德国史学大战：一战是"德意志的抓取"吗——
  当代史档案政治的标本
- 1970s 后冷战"新史"（加迪斯）依赖多国档案开放；1991 后档案再扩容

## 核心问题（③问题清单）

| 问题 | 状态 |
|------|------|
| 一战起源 | 🔄 菲舍尔论战未闭合（责任分配 vs 结构性故障，克拉克《梦游者》回到结构） |

## ✨ 最美的一个事实（⑧美之时刻）

"长和平"：1945 年以来大国之间没有直接战争——史上最长的此类纪录，
而它的抵押物是相互确保摧毁。**和平不是善意的产物，是成本曲线的产物**：
史学由此获得一个研究对象——"以末日为抵押的和平"如何自我维持又如何
耗损。

## 反直觉（⑥）

两次大战之间的 1919-1939 在全球化指标（贸易/资本流动占 GDP 比）上是
一段"倒退的黄金时代"被 1990 年代才重新超越——全球化不是单向门，
历史会掉头。

## 假设与依赖（④假设与代价）

假设"当代史"可以史地写（买到：档案充足；付出：离身太近，结论半衰期
短——01 章时效声明即本支纪律的家族化）；假设 1945 是全球断点（对多数
亚非国家，断点在 1947/1949/1960）。

## 教材锚

霍布斯鲍姆《极端的年代》；托尼·朱特《战后欧洲史》（欧洲侧典范）；
加迪斯《冷战》；巴勒克拉夫《当代史导论》（方法论）。
