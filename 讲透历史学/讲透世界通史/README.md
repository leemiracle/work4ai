# 讲透世界通史 · 把人类当作一个整体来叙述

> 世界通史：**在时间中追踪"联系"的学科**——不是各国历史的拼接，而是把
> 交流、传播与共生本身当作第一级研究对象的史学。
>
> GB/T 13745：77040（二级学科）。三级 5 支：原始社会史·世界古代史·世界中
> 世纪史·世界近代史·世界现代史（国际关系史归 81040，本家族不设）。
> 宇宙：[讲透历史学](../README.md) · 区域史家族（章精简不注水）。

## 诞生

世界通史的三个原生问题：①欧洲扩张把各大洲强制连成一体后，"世界"如何被
叙述？②"历史=欧洲史"的兰克式默认如何被打破？③人类有无统一的、可比较的
过去？关键节点：斯宾格勒《西方的没落》（1918-22）打破进步史观；汤因比
《历史研究》（1934-61）文明比较；**麦克尼尔《西方的兴起》（1963）以"接触
与传播网络"重写人类史，公认为全球史开山**；沃勒斯坦《现代世界体系》
（1974-）加上经济骨架；本特利《新全球史》（2000-）确立教学范式。中国侧：
周谷城《世界通史》（1949）为中国学者首部；吴于廑、齐世荣六卷本《世界史》
（1992-94）为标准教材。

## 假设与依赖

本家族站在三条假设上：①人类活动可以作为单一整体被叙述（买到：跨区域联系
可见；付出：地方与阶级的内部差异被抹平）；②"联系"是历史的主要驱动力
（买到：传播网络可分析；付出：内生发展逻辑被低估——"没有被联系到的历史
怎么讲"是全球史被批评最多处）；③分期可跨区域通用（买到：教学骨架；付出：
非洲与大洋洲在"古代/中世纪"分期里没有位置——这是欧洲纪年的殖民遗产）。

## 教材锚

- 威廉·麦克尼尔《西方的兴起：人类共同体史》（1963）——全球史奠基之作
- 本特利、齐格勒《新全球史：文明的传承与交流》——当代标准教科书
- 吴于廑、齐世荣主编《世界史》六卷本——中文标准教材
- 沃勒斯坦《现代世界体系》、彭慕兰《大分流》——解释框架两大支柱
- 塞巴斯蒂安·康拉德《全球史是什么》（2016）——方法论自觉的总结
