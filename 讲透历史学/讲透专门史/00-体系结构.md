# 00 · 体系结构：历史学的三维坐标系

> **本章回答五问之一（本家族：讲透专门史）。**
> 本质一句话：**专门史=按维度切历史**——断代史是时间的纵切、
> 区域史是空间的横切、专门史是问题的第三轴；每门专门支都是
> "一个维度 × 一组专门史料 × 一套专门方法"的三元组。

---

## 一、怎么产生的：从书志传统到年鉴革命

中国线早熟：杜佑《通典》（801）首开典章制度通史，
郑樵《通志》（1161）"会通"之学，马端临《文献通考》（1307）
——"三通"传统就是中国的专门史大学：食货（经济）、职官（政治）、
舆地（地理）各有专卷两千年不断。章学诚（1738-1801）进一步把
方志升格为专门之学（"志属信史"）。

西方线是革命叙事：19 世纪兰克式政治外交史一统天下；
1929 年布洛赫、费弗尔创办《经济与社会史年鉴》，宣布
"事件史不是历史"——历史学的对象应是**结构**（长时段）与
**集体心态**。此后半个世纪，社会史、经济史、心态史、
计量史学、微观史学逐门开张。**每门专门史都是一次越狱**：
从"帝王将相的一颦一笑"越狱到"普通人的结构处境"。

📖 **故事框**：布洛赫与费弗尔给期刊起名时坚持不用"历史"二字
——《年鉴》全名《经济与社会史年鉴》。两位主编一个研究中世纪
农村一个研究16 世纪心态，都不是传统"正史"题材。1944 年布洛赫
作为抵抗组织成员被盖世太保枪杀——**学科的边界的确是有人用命划的**。

## 二、三维坐标系（本家族的骨架图）

```
时间轴（断代史）：先秦 │ 秦汉 │ … │ 清 │ 近现代
空间轴（区域史）：中国 │ 亚洲 │ 非洲 │ 美洲 │ 欧洲大洋洲
维度轴（专门史）：政治 │ 思想 │ 文化 │ 科技 │ 社会 │ 城市 │ …
```

任何历史研究都是坐标系中的一点：如"宋代江南经济史"
= 时间（宋）×空间（江南）×维度（经济，GB/T 外归 79027）。
专门史的独立性来自**维度轴有自己的史料与方法**：
方志、家谱、舆图、名录、概念——它们不服务于任何单一断代或区域。

## 四、核心问题清单

- ✅ **专门史→整体史的脚手架论**（年鉴纲领）：布罗代尔《地中海》
  （1949）示范：地理结构（长时段）+经济社会（局势）+事件（政治）
  三层叠合=整体史——**专门史分工是手段，重装整体是目的**
- ✅ **概念史成立性**（Koselleck）：概念既是"时代的指标"
  （反映）也是"时代的因素"（塑造）——"革命""进步""人民"
  这些词的语义变迁本身就是历史动力
- ✅ **历史地理学双维性**：谭其骧主编《中国历史地图集》
  （八卷，1974-1988）把历代疆域政区装进统一坐标——
  时间×空间的乘积成为独立学科
- 🔄 **维度可分离的限度**：思想史离开经济史能走多远？
  每门专门支的论文综述第一段都要回答这个常驻质疑
- 🔄 **数字人文重构**：CBDB（65 万人物）与 CHGIS 把人物研究、
  历史地理推入计算范式（01 章）
- 🔄 **计量史学的边界**：Fogel 诺奖（1993）与《苦难的时代》
  争议（1974）同时到达——走廊与红线（04 章）

## 五、假设与代价

| 假设 | 买到什么 | 付出什么 |

| 维度可分离 | 深井式专业积累 | "纯经济/纯思想"的切片失真；须靠整体史回补 |
| 长时段优先 | 结构解释力（气候、人口、地理） | 事件与个人的能动性被降格 |

## ✨ 美之时刻

**布罗代尔的三种时间**（1949/1958）：地理的几乎不动的时间、
经济社会的慢节奏（la conjoncture，50 年周期）、政治事件的
浪花时间——三种时间在同一个"地中海"里同时流动。
一个框架把地理学、经济学、政治学焊进一部历史著作。
极简（三层）、意外（事件被降为浪花）、统一（从此一切
"长时段"讨论都回到它）。亲历：读《地中海》第一卷
"几乎不动的部分"，感受"时间变慢"的文风实验。

## ✍️ 练习

1. 把你最熟悉的一个历史事件（任选）放进三维坐标：
  断代×区域×维度各是什么？再问：换一个维度重述这件事，
  事件"主角"会换成谁？
2. 用"三通"传统对照"年鉴"传统：两场专门史运动相隔千年，
  动因有何同异？（提示：都是对"纪传/事件中心"的反动。）
