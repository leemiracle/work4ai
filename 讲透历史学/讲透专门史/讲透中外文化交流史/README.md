# 讲透中外文化交流史 · 文明互鉴的双向账本

> 这支负责：**中外交流的文化维度**——佛教东传、西学东渐、
> 中学西传、物质与技术的双向旅行。它铁律一条：
> **记双向账**（只记单向流入或流出，就不是交流史是神话史）。
>
> GB/T 77070·三级"中外文化交流史"。家族：[讲透专门史](../README.md)。

## 诞生

母题可以上溯《史记·大宛列传》，但作为学科由三个事件奠基：
①李希霍芬 1877 命名"丝绸之路"（Seidenstrasse），把欧亚通道
变成研究对象；②利玛窦-徐光启的交往成为范式案例
（1607 合译《几何原本》前六卷——科学与语言的双向改造）；
③20 世纪敦煌学兴起（1900 藏经洞）把"十字路口史料"变成
国际显学。1980s 后全球史兴起，交流史获得新框架：
**交流不是加法（谁传给谁）而是化学反应（混血新生）**。

## 核心问题

- ✅ 已解：佛教中国化两千年路径（格义→判教→禅宗本土化——
  宗教交流史的世界级样板）
- ✅ 已解：美洲作物入华的路线与时点（玉米/甘薯 16 世纪海路，
  与清代人口扩边的耦合——家族 04 章实验侧面）
- 🔄 前线：西学东渐的再平衡（中国如何反向塑造欧洲启蒙——
  伏尔泰读中国、莱布尼茨读《易》的再研究）
- 🔄 前线：白银全球链的量化闭环（波托西→马尼拉→月港，
  与 [../../讲透美洲史/](../../讲透美洲史/) 共题）
- ❌ 未解：翻译的极限——"格义"式误读何时是桥梁何时是墙

## ✨ 这支最美的一个事实

徐光启与利玛窦 1607 年合译《几何原本》：为译"点、线、面、
平行"诸词，中文被迫发明一套新术语——**四百年后中国学生
在数学课上每天使用的词汇，就是那场合作的原装遗产**。
（译文世界见 [../../../讲透数学/讲透数学史/](../../../讲透数学/讲透数学史/)。）
