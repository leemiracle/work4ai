# 讲透思想史 · 概念的传记

> 这支负责：**思想维度的历史**——学说、概念与心态如何产生、
> 旅行、变义、消亡。它给自己的根本任务起过一个漂亮的名字：
> **给概念写传记**（概念的生卒年、旅行路线与变形记）。
>
> GB/T 77070·三级"思想史"。家族：[讲透专门史](../README.md)。

## 诞生

三源合流。①中国注疏传统（经学两千年的注释链本身就是
思想史的原始档案）；②洛夫乔伊《存在巨链》（1936）创
"观念史"（history of ideas，unit-ideas 追踪）；③剑桥学派
（Skinner/Pocock，1969-）反叛"永恒观念"：**思想是言语行为，
必须放回论辩语境读**；科塞雷克《历史基本概念》（1972-97）
的德国概念史（Begriffsgeschichte）提供第三种语法——
概念既是时代的指标也是因素。中国现代范式：侯外庐
中国思想史体系 → 葛兆光《中国思想史》（1998-2001）
以"一般知识史"扩容精英思想史。

## 核心问题

- ✅ 已落定：语境主义方法论（剑桥学派胜利）——脱离论辩语境的
  "观念传承"叙述不可靠
- 🔄 前线：中国概念史成型（"封建""文明""科学"诸概念的语义考古）
- 🔄 前线：数字概念史（词频+语境向量追踪，家族 01 章方向三）
- ❌ 未解："缺席的概念"如何研究——证明古人"没想过 X"
  几乎只能靠沉默的厚描述（负证据问题，家族 02 章）

## ✨ 这支最美的一个事实

"封建"一词的三生三世：西周封邦建国实义 → 19 世纪末日本学者
借壳译 feudalism → 20 世纪社会形态五阶段论术语——
**一个词的三次变身，本身就是一部中国近代史学史**。

## 假设与依赖

①思想有历史（概念语义可变——反对"永恒哲学问题"预设）；
②文本与语境互锁（意图、文体、论敌缺一不可）；
③依赖原典精读+语言功力（翻译会抹平语义断层）。

## 教材锚

- 葛兆光《中国思想史》两卷；Skinner《自由主义之前的自由》
- 科塞雷克《概念史》中译本；《历史基本概念》（词条选读）
