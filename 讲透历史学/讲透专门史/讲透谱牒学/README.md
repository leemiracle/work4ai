# 讲透谱牒学 · 家谱的文献学与数学

> 这支负责：**谱牒（家谱、族谱、世系表）的整理、辨伪与利用**
> ——中国存世家谱 5 万种以上（上海图书馆近 3 万种为世界最大
> 单位藏）。这支有本家族最硬的数学骨架：**家谱=树结构**，
> 而且树的性质（谱系合流）直接指导辨伪。
>
> GB/T 77070·三级"谱牒学"。家族：[讲透专门史](../README.md)。

## 诞生

谱学两起两落：魏晋南北朝鼎盛（选官靠谱牒，"上品无寒门"的
制度基础），唐末五代战乱谱亡；宋代复兴且完成范式革命——
欧阳修、苏洵各创谱式（**欧式横行、苏式竖行，五世一表**），
私修取代官修、"敬宗收族"取代"选官凭据"。清代谱学大盛
（徽州谱牒），并出现辨伪自觉（梁启超论谱病）。
现代：上图整理编目；GEDCOM 国际标准与基因家谱把谱学推进到
"纸谱-口传-基因"三源互证时代。

## 核心问题

- ✅ 已解：欧苏谱法的体例学（五世一表=树宽爆炸的显示解法，家族 03 章）
- ✅ 已落定：谱牒的"愿望文档"性质——攀附名贤（托黄帝、冒望族）
  是系统现象，须整体校准而非逐谱求真
- 🔄 前线：pedigree collapse 的数学与谱系置信度建模
  （2^40 > 历史人口——合谱必然，线路存疑）
- 🔄 前线：基因家谱与纸谱互证（姓氏-Y 单倍群的统计对应）
- ❌ 未解：女性世系的系统性缺失（传统谱"女不载"）

## ✨ 这支最美的一个事实

算术题：你的第 40 代祖先理论上有 2^40 ≈ 1.1 万亿人——
超过任何历史时期的中国人口。所以家谱必然"收拢"
（不同分支汇向同一批远祖）：**明清两家"毫无关系"的族谱，
在唐代顶点几乎必然相交**。攀附未必是造假，可能只是
对数学必然的叙事化（家族 03 章美之时刻的可读版）。
