# 讲透科技史 · 知识如何成为"科学"

> 这支负责：**科学技术维度的历史**——知识生产、仪器与实验、
> 技术与社会。它是专门史家族里"内史/外史"之争最尖锐的一支，
> 也是本宇宙与仓库根两个科技史系列的对接口。
>
> GB/T 77070·三级"科技史"。家族：[讲透专门史](../README.md)。

## 诞生

三块奠基石：①萨顿 1912 年创 Isis（科学史第一刊），立实证-编年
内史传统；②1931 赫森论牛顿《原理》的社会经济根源，点燃外史火种；
③库恩《科学革命的结构》（1962）以"范式转移"重写进步叙事。
中国线：李约瑟《中国科学技术史》（1954- ）把中国技术传统接入
世界比较框架，留下**李约瑟问题**（为何近代科学不在中国发生）。
1970s-80s 科学知识社会学（SSK）把"科学如何被制造"推向极端，
内外史之争至今未熄。

## 核心问题

- ✅ 已解：17 世纪科学革命叙事重构（伟人链→仪器-制度-实践复合史）
- ✅ 已落定：中国四大发明的世界史地位（全球传播链已复原）
- 🔄 前线：李约瑟问题的现代重述（制度/文化/竞争格局多因素模型）
- 🔄 前线：AI 史建制化——AI 自身成为科技史新章节（挂靠系列主场）
- ❌ 未解：辉格史之戒如何执行——排列"正确"的职业病因何难戒

## ✨ 这支最美的一个事实

1962 年库恩用一个词（范式 paradigm）让"科学=累积进步"的
百年叙事崩塌：教科书里的"胜利者史"被改写成
**常规科学→反常→危机→革命**的循环——研究"科学"的学问
亲手示范了一次范式转移。

## 假设与依赖

①科学是历史现象（没有超历史的"科学方法"标准答案）；
②内史（知识内容）与外史（社会条件）互补——单腿走不远；
③依赖仪器史与实验重演（复原实验=科技史的"考古发掘"）。
