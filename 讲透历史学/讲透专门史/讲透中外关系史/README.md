# 讲透中外关系史 · 朝贡、条约与两个世界的相遇

> 这支负责：**中外关系的政治外交维度**——朝贡体系、条约体系、
> 使团、战争与交涉。与文化交流史的分野：**这支管国家间关系**
> （权力与制度），那支管文化旅行（意义与知识）。
>
> GB/T 77070·三级"中外关系史"。家族：[讲透专门史](../README.md)。

## 诞生

现代学科由费正清体系奠基：《中国沿海的贸易与外交》
（1953）提出朝贡体系框架，与 Teng 合著《东亚：传统的变革》
（1955）定型"冲击-回应"模式。1970s-80s 两次大修正：
柯文《在中国发现历史》（1984）批评冲击-回应的西方中心；
"新清史"（1990s 末起）把清朝重新定义为内亚帝国。
当代前线：朝贡 vs 条约双体系过渡（1793 马戛尔尼使团
到 1842《南京条约》的再解释）。

## 核心问题

- ✅ 已解：朝贡体系的制度细节（贡期、贡道、回赐的账面逻辑——
  它是礼仪秩序不是赔本买卖）
- ✅ 已落定：马戛尔尼"磕头之争"的事实层（礼仪分歧被
  双方各自叙事化——史学经典案例）
- 🔄 前线：鸦片战争起因的多因再平衡（贸易/白银流动/国内政治）
- 🔄 前线：朝贡体系论战（它是实存的东亚国际秩序，还是
  后设的史学建构？——费正清框架的总体检讨）
- ❌ 未解：不平等条约体系的长期遗产如何评价（法理 vs 情感的双轨）

## ✨ 这支最美的一个事实

1793 马戛尔尼使团：中英双方档案对同一事件的记载几乎是
两部作品——英方写"平等被辱"，清方写"远人向化"。
**两份档案都"真实"，合读才出史实**：双档互勘是本支的
看家本领，也是 02 章"愿望文档"命题的最佳教具。

## 假设与依赖

①关系可制度化为研究对象（朝贡/条约双体系框架）；
②双档互勘律（每场交涉至少两边档案）；③警惕目的论
（"朝贡必然让位于条约"是后见之明）。
