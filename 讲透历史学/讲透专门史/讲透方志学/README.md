# 讲透方志学 · 一县一册的通史工程

> 这支负责：**方志（地方志）的编纂、体例与利用**——
> 中国独创的"地方通史"文类：一县一册、百年一修、
> 分门别类（疆域/赋役/官师/人物/艺文），存世 8000 余种。
> 它既是专门史的一支，又是其他各支的**史料供给站**。
>
> GB/T 77070·三级"方志学"。家族：[讲透专门史](../README.md)。

## 诞生

文类演化链：图经（隋唐，地图+说明）→《元和郡县图志》（813，
现存最早全国总志）→宋《太平寰宇记》（增人物、艺文门——"史体化"
关键一步）→明清鼎盛（永乐颁修志凡例，官修制度化）。理论自觉
在清：章学诚提出**"志属信史"**（方志是史不是地理书）、立志科、
创"三书"体例——方志学成立。民国傅振伦《中国方志学通论》
（1935）为第一部教科书；1950s 起新方志编修接续至今。

## 核心问题

- ✅ 已解：方志体例的标准结构（分门-条目-按语——"字段化"的
  古代形态，家族 03 章账本）
- ✅ 已落定：章学诚"志属信史"的辨体论证（史体 vs 地理体千年之争收官）
- 🔄 前线：方志数字化的全文结构化（分门解析、赋役数字抽取）
- 🔄 前线：灾异志与历史气候重建（旱涝等级序列 500 年，气候史主源）
- ❌ 未解：官修美化的系统偏差如何校正（赋役、名宦两门是
  "重灾区"，家族 02 章"愿望文档"）

## ✨ 这支最美的一个事实

8000 余种方志的分门结构惊人一致：随便抽一册清代县志，
"疆域-建置-赋役-官师-选举-人物-艺文-祥异"的目录骨架
几乎相同——**一个持续千年的全国统一字段规范**，
前现代世界最大规模的结构化数据工程。

## 假设与依赖

①方志是史（章学诚命题：可考、可互校、有体例）；
②地方资料性优先（"地近则易核，时近则迹真"——章氏方法名句）；
③依赖版本考订（修志抄前志，讹误会层积——须代际校勘）。
