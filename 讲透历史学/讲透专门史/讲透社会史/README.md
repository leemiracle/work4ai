# 讲透社会史 · 自下而上的历史

> 这支负责：**社会维度的历史**——人口、家庭、宗族、阶层、
> 乡村与城市共同体；它把历史学的主语从帝王将相换成
> **"沉默的大多数"的出生、婚姻、纳税与死亡**。
>
> GB/T 77070·三级"社会史"。家族：[讲透专门史](../README.md)。

## 诞生

1929 年《年鉴》创刊即宣战：研究对象从事件转向结构——
社会史是年鉴革命的主力军。战后两波：英国马克思主义史学
（Thompson《英国工人阶级的形成》1963，"自下而上"口号）与
计量家庭史（剑桥小组的家族重构法）。中国线：傅衣凌学派 →
华南学派（宗族与市场的田野-文献互证）→ 何炳棣人口史
（家族 04 章实验的数据源头）。它既是 12 支之一，又为各支
提供"社会底盘"。

## 核心问题

- ✅ 已解：家族重构法（教会登记→前现代人口量化复原，剑桥范式）；
  中国宗族的组织逻辑（华南学派）
- ✅ 已解：施坚雅市场体系理论（1964-65）：乡镇市场六边形
  层级是中国社会的"隐结构"——人类学-地理学-史学三栖示范
- 🔄 前线：历史人口与气候-灾害的联合建模（数据叠层时代）
- 🔄 前线：社会流动的长期测量（科举与家族地位延续——
  与经济学"代际弹性"文献合流）
- ❌ 未解：结构 vs 能动性的世纪平衡（Thompson 遗产仍在花利息）

## ✨ 这支最美的一个事实

何炳棣 1959 年用一手档案证明：明清官方"人口"数字先是税额
单位（"丁"）后才是人——**六百年的"人口曲线"其实是
一部财政制度的自画像**。一个口径判断，改写了整部
中国人口史（家族 04 章实验即此判例的可跑版）。

## 假设与依赖

①结构优先（人口、家庭、市场是慢变量，比事件更能解释长期）；
②自下而上的视角（税收记录、教会登记、族谱是第一等史料）；
③量化与厚描述互补（剑桥计量派与汤普森文化派长期对峙后和解）。

## 教材锚

- Braudel《15-18 世纪的物质文明、经济和资本主义》；施坚雅《中国农村
  的市场和社会结构》
