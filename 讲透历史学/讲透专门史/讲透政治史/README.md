# 讲透政治史 · 制度、权力与国家形成

> 这支负责：**政治维度的历史**——制度沿革（官制、法制、财政）、
> 国家形成与崩溃、革命与政权合法性。它曾是历史学的"默认全史"
> （兰克式政治外交史），如今是专门史家族的"长子"：
> 资历最老、包袱也最重。
>
> GB/T 77070·三级"政治史"。家族：[讲透专门史](../README.md)。

## 诞生

中国线：书志传统即政治史母体——杜佑《通典》（801）以职官-礼-刑
分门，马端临《文献通考》扩至 24 门；钱穆《中国历代政治得失》
（1952）立"制度史学"现代范式。西方线：兰克 19 世纪确立
"档案+外交史"的职业标准；20 世纪被社会史夺位后转向
新政治史（投票行为量化）与新制度主义（North：制度是
长期经济绩效的根本变量——1990）。政治史的每一次自我更新
都是"从帝王到结构"的下沉。

## 核心问题

- ✅ 已解：中国官制的通代框架（三公九卿→三省六部→内阁军机）；
  科举制的制度史（1905 废除的长期后果仍在开采）
- 🔄 前线：国家能力的历史测量（财政汲取率、官僚密度——与
  "新非洲经济史"共用工具）
- 🔄 前线：革命比较研究（大西洋革命年代 1776-1848 的联动重估）
- ❌ 未解：政体韧性的因果——为何有些制度千年自修复、有些一击即溃

## ✨ 这支最美的一个事实

科举（隋 605 创至 1905 废）：用标准化考试把精英再生产
从血统手里接过——**世界历史上规模最大、运行最久的
人力选拔算法**。现代文官考试（英 1855 起）皆其后学。

## 假设与依赖

①制度文本≠制度运作（"纸面制度"须以奏议、档案校准——
家族 02 章"愿望文档"命题）；②政治可与其他维度分离研究；
③依赖官制术语的精确性（三把刀之一）。
