# 讲透专门史 · 用维度切时间的人

> 专门史：**不按时间也不按空间、而按"维度"切历史**——政治、思想、
> 文化、科技、社会、城市、交流、地理、方志、人物、谱牒。
> 断代史纵切时间，区域史横切空间，专门史按问题切——
> 三种切法构成历史学的三维坐标系。它的悖论式命题：
> **专门史的目的不是"专"，而是通往"整体史"的脚手架**
> （年鉴学派：先拆解长时段结构，再重装整体）。
>
> GB/T 13745：77070（GB/T 列 14 三级支：经济史归 79027、军事史归
> 83015 不设，本家族落 12 支）。宇宙：[讲透历史学](../README.md)。

## 诞生（作为学科）

中国传统里专门史早于断代史：书志（政书）传统——《通典》（801，
杜佑，典章制度通史）到"三通""九通"，就是政治-经济-制度专门史
两千年谱系。西方线：19 世纪兰克政治史一统 →1929 年布洛赫与费弗尔
创《年鉴》反叛"事件史"，开出社会-经济-心态专门史；
20 世纪思想史（Lovejoy 1936 观念史）、科学史（1931-60s 独立建制）、
计量史学（Fogel & Engerman 1974）依次分蘖——**每门专门史的诞生
都是对"帝王将相史"的一次越狱**。

## 假设与依赖

①维度可分离（可分别研究政治/经济/思想——代价见上表第二行）；
②长时段优先（结构>局势>事件，布罗代尔三种时间）；
③专门史料配专门方法（方志有方志学、谱牒有谱法、舆图有历史地理）。
