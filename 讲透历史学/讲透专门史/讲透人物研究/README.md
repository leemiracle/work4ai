# 讲透人物研究 · 传记、年谱与群体传记学

> 这支负责：**历史中的人**——个体传记、年谱、群体传记学
> （prosopography）三层递进：写一个人、排一个人的一生、
> 算一代人的共同背景。
>
> GB/T 77070·三级"人物研究"。家族：[讲透专门史](../README.md)。

## 诞生

传记是最古老的史体：《史记》七十列传即传记史学开山。
年谱始于宋、盛于清（考证学供给方法）。现代转折两次：
①梁启超《中国历史研究法补编》（1926-27）专论传记作法，
批评旧传"墓志化"；②西方群体传记学（prosopography）成熟
——Lawrence Stone 1971 年定义："对共同背景人群的集体传记
研究"。21 世纪第三转折：CBDB（65 万人物，家族 01 章）把
群体传记学推入计算范式——**从"为名人立传"到"为一个时代
建立人物全体数据"**。

## 核心问题

- ✅ 已解：传记方法的规范（传主与其时代的互文——
  "个人史即社会史的切片"）
- ✅ 已落定：年谱学的考证规范（系年、交游、著述三线并进）
- 🔄 前线：CBDB 驱动的社会流动计算（科举网络的代际传递）
- 🔄 前线：微观史与传记的合流（一个"小人物"的一生重建
  一个世界——《马丁·盖尔归来》《王氏之死》范式）
- ❌ 未解：同情偏置——研究者越靠近传主越难保持距离；
  传记伦理（家属、隐私、死后名誉）成新前沿

## ✨ 这支最美的一个事实

史景迁《王氏之死》（1978）：用刑案档案、县志与《聊斋》
三源重建清初郯城一个农妇的最后岁月——**无名者的生命
第一次成为历史学的主角**。传记学的边界被推到"沉默者"，
与 CBDB 的"全体数据"刚好构成这 50 年人物研究的两极。

## 假设与依赖

①个体与时代互文（没有无背景的传主）；②三层递进律
（个案→年谱→群体，每层互证）；③史料配额制
（正史+文集+方志+档案至少两源——单源不成传）。
