# 讲透历史地理学 · 时间 × 空间的乘积学科

> 这支负责：**历史地理维度**——历代疆域政区、地名沿革、
> 河道变迁、城市区位、人口分布的历史复原。它是本家族唯一
> **双维学科**：以时间为经、空间为纬，产品是"历史瞬间的地图"。
>
> GB/T 77070·三级"历史地理学"。家族：[讲透专门史](../README.md)。

## 诞生

中国自成一体：舆地学传统——《禹贡》（战国，地理志雏形）、
《汉书·地理志》、顾祖禹《读史方舆纪要》（1692，军事地理
巅峰）、杨守敬《历代舆地图》（清末先声）。现代定型：1930s
禹贡学会（顾颉刚、谭其骧）把"沿革地理"升级为"历史地理学"；
1950s-80s 谭其骧主编《中国历史地图集》八卷——**两千年政区
变迁装进统一坐标**；侯仁之开创城市历史地理。2001 年起
复旦-哈佛 CHGIS 把图层数字化——从舆图到 GIS 的跃迁。

## 核心问题

- ✅ 已解：历代疆域政区的层积复原（谭图八卷+CHGIS）
- ✅ 已解：黄河六次大改道的编年与人口后果（1855 铜瓦厢改道
  与近代黄泛区）
- 🔄 前线：历史气候-灾害-社会的联合建模（树轮/方志灾异/
  粮价三源叠层）
- 🔄 前线：地名消歧的机器学习（同名异地、异地同名、
  避讳改名——数据科学新题）
- ❌ 未解：历史疆域的表示学——地图集的每一次"定界"
  都是一次史学判断（谭图凡例本身就是方法论论文）

## ✨ 这支最美的一个事实

谭其骧八卷本《中国历史地图集》：学界用三十余年把原始社会到
清代的政区界线落到统一比例尺——**每个边界多边形背后都有
考据论文支撑**。"数据字典=史学论纲"的超级样板（01 章字段眼）。

## 假设与依赖

①历史地理格局影响历史进程（地理不是背景是变量）；
②地名是层积的化石（每一层改名都是一个事件）；
③投影与定界即立场（地图从来不是中立的）。

## 教材锚

- 谭其骧主编《中国历史地图集》+《长水集》；侯仁之《历史地理学的
  理论与实践》
- 顾祖禹《读史方舆纪要》（古舆地学巅峰，选读）
