# 讲透文化史 · 意义的日常考古

> 这支负责：**文化维度的历史**——仪式、习俗、阅读、饮食、死亡、
> 笑与怕：一个社会如何生产与分配意义。它的口号史：
> 从布克哈特的"高雅文化"到新文化史的"**普通人的一切都是文本**"。
>
> GB/T 77070·三级"文化史"。家族：[讲透专门史](../README.md)。

## 诞生

布克哈特《意大利文艺复兴时期的文化》（1860）开山：
把"时代精神"当研究对象。20 世纪两次转向：①1929 年年鉴学派
把心态（mentalités）纳入长时段——布洛赫《国王的神迹》（1924）
研究国王摸疹治病信仰，是心态史开山；②1970s-80s"新文化史"
（Lynn Hunt、Darnton《屠猫记》1984、Roger Chartier 阅读史）：
文化不是反映社会的镜子，而是**塑造社会的实践**。
中国线：民俗学运动（1920s 歌谣学）→ 社会文化史
（王笛《茶馆》成都日常史的范式作）。

## 核心问题

- ✅ 已解：印刷革命与阅读公众的成型（Chartier/爱森斯坦线）
- ✅ 已解：新文化史方法定型（微观史+厚描述+人类学互借）
- 🔄 前线：物质文化史（器物、服饰、城市声景——感官史兴起）
- 🔄 前线：文化史与数字人文的紧张关系（意义不可计数 vs
  语料库无处不在——家族 04 章边界案例）
- ❌ 未解：跨文化比较的尺度（"文艺复兴"式概念能否迁移）

## ✨ 这支最美的一个事实

《屠猫记》：18 世纪巴黎印刷工学徒集体屠杀猫并举行"审判"取乐——
达恩顿用这个"不可理解的笑话"层层解码学徒文化、劳资冲突与
民间象征——**当一个玩笑变得能理解时，一个陌生时代就打开了一扇门**。

## 假设与依赖

①文化是实践不是上层建筑（格拉克曼-格尔茨人类学底盘：
"深描"方法）；②日常生活是第一等史料（会账、戏票、
违禁记录）；③对量化天然警惕（但不拒绝——家族 02 章总表）。
