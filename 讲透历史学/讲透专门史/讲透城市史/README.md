# 讲透城市史 · 空间里的社会机器

> 这支负责：**城市维度的历史**——城址、形态、市政、城市社会
> 与城市性（urbanity）本身。城市是"社会的压缩文件"：
> 城墙内叠着政治、经济、文化与技术的全部维度。
>
> GB/T 77070·三级"城市史"。家族：[讲透专门史](../README.md)。

## 诞生

韦伯《城市》（1921，遗稿）奠基：用"市民共同体"概念
比较东西方城市（西方中世纪城市为何长出自治与公民权——
他的比较框架至今是绕不开的起点）。美国线：Schlesinger 1940s
"城市在美国历史中的作用"论纲 → 1960s 新城市史（人口迁徙
量化）；中国线：施坚雅主编《中华帝国晚期的城市》（1977）
用中心地理论重排中国城市层级（巨区 macroregion 框架），
罗威廉《汉口》（1984）以一座城市重估"中国市民社会"之争。
1990s 后空间转向（列斐伏尔"空间的生产"）把城市史
升级为"空间-社会"耦合研究。

## 核心问题

- ✅ 已解：中国城市体系的层级结构（施坚雅巨区-市场层级模型）
- ✅ 已落定：唐宋城市革命（坊市制崩解→街市制，宵禁瓦解）——
  中国内部城市现代性的中世纪起点
- 🔄 前线：HGIS 街坊层重建（家族 04 章走廊 5 的主战场）
- 🔄 前线：比较城市史的尺度统一（城墙内人口估算方法之争）
- ❌ 未解："韦伯问题"的当代重述——城市自治的条件组合

## ✨ 这支最美的一个事实

北宋汴京：《清明上河图》+《东京梦华录》双证据复原出
**11 世纪世界最大城市**的街市、外卖与夜生活——
坊墙倒塌（唐末宋初）之后，中国城市先于欧洲五百年
进入"开放式街市"形态。一幅画+一本书=一座城的
完整数字孪生（材料级）。

## 假设与依赖

①城市是分析单元（不是"背景"）；②空间形态与社会结构
互为因果（空间转向的核心假设）；③依赖地图、方志城池篇、
行会档案三件套（跨家族取材：[../讲透方志学/](../讲透方志学/)）。
