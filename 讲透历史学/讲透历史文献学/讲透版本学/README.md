# 讲透版本学 · 副本的族谱

> 这支负责一个问题：**同一本书的几十个本子，哪个最接近原貌**——
> 鉴别刻本/抄本/影抄/活字的身份与谱系。GB/T 原名即"版本学"（自定主干支）。
> 家族：[讲透历史文献学](../README.md)。

## 诞生

雕版印刷普及（宋）使"同书异本"爆发，版本鉴别成学；清代黄丕烈"佞宋"藏书
题跋开鉴赏派；近世以行款/版式/讳字/刀法/纸墨的"版本鉴定五要素"定型。

## 核心问题

| 问题 | 状态 |
|------|------|
| 版本源流考订（祖本—翻刻链） | 🔄 逐书作业，永续（每部要籍一部"版本史"） |
| 版本鉴定方法学（五要素） | ✅ 已成熟 |
| 真本/伪本鉴别（书贾作伪：抽序/改牌记/染纸） | 🔄 攻防持续 |
| 版本谱系的算法推断 | 🔄 前线（家族 01 章方向二） |

## 这支最美的一个事实

**讳字是免费的碳十四**：一部书"世"缺笔（避唐太宗）而"弘"不缺（不避乾隆），
年代下限立刻锁进唐代——政治禁令制造的"创伤标记"反而成了最可靠的断代锚
（禁令越严，时间戳越准）。

## 假设与依赖

- 假设：早本≈近真本 → 代价：孤证早本可能恰是劣本（唐人也会抄错）
- 依赖：[目录学](../讲透目录学/)（版本要挂在书目之下）、校勘学（异文暴露谱系）
