# 讲透历史文献学 · 让两千年前的文本可以被可靠地读到

> 文献学是文本的**传输纠错学**：一本书从汉代抄到清代、从清代排印到今天，
> 每一步都引入错误——文献学的全部手艺，就是**判断手上这个副本离作者的原意有多远**，
> 并尽可能把错误纠回来。
>
> GB/T 13745：77020 历史学·二级学科（无三级明细，自定主干支三支）。
> 家族：[讲透历史学](../README.md)·波3（2026-09-07 六学科 GB13745 扩展）。

## 一、诞生（三个原生问题）

1. **书会烂、会抄错**：先秦典籍经秦火、口传、汉初隶写（"隶古定"），到刘向奉诏校书
   （前 26 年），第一次系统面对"同一本书、多种抄本、彼此不同"——他发明了
   "一人读书、一人校雠"的结对流程与《别录》，目录学与校勘学同日出生。
2. **伪书混真**：《伪古文尚书》骗了学界一千余年，阎若璩《尚书古文疏证》（1700s 初）
   用一百二十八条证据将其证伪——"辨伪"成为文献学的常备武器。
3. **地下新材料**：20 世纪敦煌遗书、郭店楚简、清华简接连出土——文献学从
   "整理传世本"扩展到"释读两千年前的墨迹"，古文字学成为它的现役前线。

📖 **故事**：乾嘉学者顾广圻以"不校校之"闻名——明知有异文而不轻改，
只出校勘记留证。他说：**"书是以不校校之而误者少，以意改之而误者多。"**
这是数据完整性的直觉，比 CRC 校验早了一百五十年。

## 二、核心问题清单

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 《四库全书》式全量整理 | ✅ 已完成（1782，三千年存世典籍的首次编目总账） | 古典文献学的天花板工程 |
| 《伪古文尚书》证伪 | ✅ 已解（阎若璩） | 辨伪学的示范件：文本证据链可以推翻"千年经典" |
| 出土文献释读 | 🔄 进行中（郭店/上博/清华简/安大简，一代人的持续工程） | 每批新简都可能改写思想史叙事 |
| "作者定本"的恢复 | ⧜ 原则上不可达 | 原本可能从未唯一存在——见 03 章 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 文本有谱系（异文不是随机噪声，是复制树） | 谱系推断可能 | "横向污染"（引用、合抄）会打断树假设 |
| 越早的版本越好 | 大体成立 | 唐写本也会抄错，宋椠也有臆改——孤证早本危险 |
| 通行本可作底本 | 校勘可操作 | 底本选择本身是判断，不是事实 |
