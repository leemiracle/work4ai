# 00 · 体系结构：文献学的三支大厦

> **本章回答五问之一（本支：讲透历史文献学）。**
> 文献学的大厦只有三层——**找书（目录）、认本（版本）、正读（校勘）**——
> 但每层都是两千年工匠手艺的沉积。本章给三支地图、刘向流程的解剖、
> 和贯穿全家族的"谱系总图"。

---

## 一、三支地图：一个查书人的完整旅程

你要读《荀子》。旅程是：

1. **目录学**：查《汉书·艺文志》→"孙卿子三十三篇"——确认汉代存目；
   再查《四库总目》→ 子部儒家类——确认清代的分类与版本源流。
   （**目录学=书的地图**：著录书名/卷数/作者/存佚，让"有什么书"成为可查的公共知识。）
2. **版本学**：《荀子》今本出自唐杨倞注本系统，宋台州本为祖本之遗，
   王先谦《荀子集解》汇集诸本。（**版本学=副本的族谱**：同一本书的
   每个抄本/刻本/排印本都是族谱上的一个节点。）
3. **校勘学**：诸本异文如何取舍？王先谦集解的校语就是现场——
   "元刻作某，宋本作某，今从某"。（**校勘学=错误纠正**：用多本互证逼近原文。）

三支不是并列的"三个方向"，是**一个流程的三个环节**：目录定位对象，
版本确定材料，校勘产出成果。

## 二、刘向流程解剖：公元前 26 年的"数据管道"

刘向校书的流程（据《别录》佚文复原）：

```
中书（宫廷藏书，多副本、多异本）
  → 广搜异本（"臣向言：所校中《孙卿书》凡三百二十二篇，
     以相校，除复重二百九十篇，定著三十二篇"）
  → 一人读本、一人校雠（结对校对——人机对读的祖师）
  → 定著篇目、写定叙录（每书一份"校对报告"：篇目/异本情况/作者事迹/内容评价）
  → 汇总为《别录》，子歆缩编为《七略》——全国知识总目录
```

✨ **美之时刻①**：这条两千年前管道的每一步，都能与现代数据工程对上——
去重（除复重）、双通道校验（两人校雠）、元数据（叙录）、索引（七略）。
**美的理由：必然**——面对"多副本+有损复制"，流程必然收敛到这四步；
文明相遇同一问题，长出同一形状。**怎么亲历**：用 git 管理一批文本文件、
故意引入错改、再 `git diff` 找回——你已经在校雠。

## 三、谱系总图：全家族的结构主梁

```
              作者原稿（可能不存在唯一形态）
                 │  历代传抄/翻刻（每代引入异文）
        ┌────────┼────────┐
      甲本      乙本      丙本        ← 存世诸本（版本学的对象域）
        │        │        │
        └───异文矩阵───┘            ← 校勘学的对象域
                 │
           谱系树（stemma）推断       ← 谱系学：谁从谁抄来
                 │
           底本选择 + 校勘记          ← 产出：整理本
```

反直觉主梁：**存世诸本不是"作者的残影"，而是一棵复制树上的叶**——
树的形状（谱系）本身携带信息：两个本子共有同一个**独特错误**（衍文/倒文），
几乎必然共祖。**共同错误比共同正确更有信息量**——正确可以各自独立达到，
荒谬的错误几乎只能继承。这是 03 章"谱系可构造"的引擎。

## 四、假设与代价（家族级总账）

| 支 | 核心假设 | 买到 | 付出 |
|---|---|---|---|
| 目录学 | 分类可反映知识结构 | 全域检索 | 分类即预判——类名的时代性 |
| 版本学 | 早本≈近真本 | 族谱推断可行 | 孤证早本可能恰是劣本 |
| 校勘学 | 异文有谱系 | 系统纠错 | 横向污染（他校/引用）打断树 |

## 📌 收束：这章给了你什么新眼睛

**文献学眼：看谱系不看单本。** 你以后看到任何"古书引文"，第一反应不再是
"这是原文吗"，而是"这是复制树上的哪一层、离根多远、和谁共祖"——
读到的每一句话都自带版本坐标。这个眼睛同样适用于：新闻溯源、
代码分支管理、法律条文引用链。
