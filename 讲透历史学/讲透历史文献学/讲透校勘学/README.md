# 讲透校勘学 · 错误纠正码

> 这支负责一个问题：**用多个本子互证，把传抄翻刻中引入的错误纠回去**——
> 讹/脱/衍/倒四类错误的系统纠治。GB/T 原名即"校勘学"（自定主干支）。
> 家族：[讲透历史文献学](../README.md)。

## 诞生

刘向"一人读书、一人校雠"的结对校对（前 26 年）是工序起点；
清代达到巅峰——顾广圻"不校校之"（存真派）与段玉裁"定其是非"
（求是派）之争把方法论逼明；陈垣《校勘学释例》（1931）
以《元典章》校例定型"校法四例"，现代学科成立。

## 核心问题

| 问题 | 状态 |
|------|------|
| 校法四例（对校/本校/他校/理校） | ✅ 已定型（陈垣） |
| 二十四史点校（国家级校勘工程） | ✅ 一轮完成（1970s）；修订工程 🔄 持续 |
| 底本选择理论 | 🔄 逐书判断（无普适解） |
| 理校（无版本依据的推理改字）的边界 | ⧜ 永恒张力——"无证之证"是刀锋 |

## 这支最美的一个事实

**共同独特错误 > 共同正确**：两个本子在同一处都错得同样离谱，
几乎只能说明它们共祖——**荒谬比正确更有信息量**（正确可以各自独立达到，
荒谬几乎只能继承）。这是校勘学推断谱系的引擎，也与生物系统发生学
的"共同衍生性状"完全同构。

## 假设与依赖

- 假设：异文有谱系（树状传承）→ 代价：横向污染（他校混入/引用掺入）会打断树
- 依赖：[版本学](../讲透版本学/)（材料）、音韵/文字/训诂（小学，判断的弹药）
