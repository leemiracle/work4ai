# 讲透目录学 · 书的地图

> 这支负责一个问题：**都知道有些什么书**——书名/卷数/作者/存佚/归类，
> 让"天下藏书"成为可检索的公共知识。GB/T 原名即"目录学"（自定主干支）。
> 家族：[讲透历史文献学](../README.md)。

## 诞生

刘向《别录》→刘歆《七略》（前 26 年—前 6 年）：中国第一部系统目录，
六略三十八种的分类总图。西晋荀勖《中经新簿》改四部分类，魏征《隋书·经籍志》
定格"经史子集"——分类法两千年一脉。

## 核心问题

| 问题 | 状态 |
|------|------|
| 全国知识总目录（七略→四库总目） | ✅ 各时代已完成（1772-1782《四库》为古典顶点） |
| 存佚考（哪些书亡了、何时亡的） | 🔄 持续（马国翰/鲁迅《古小说钩沉》式的辑佚接力） |
| 分类体系的世界观变迁 | ✅ 已成学（从"辨章学术"到书架管理，见家族实验的熵判据） |
| 数字时代的"总目录" | 🔄 进行中（全国古籍普查登记基本数据库） |

## 这支最美的一个事实

《汉志》诸子略小说家著录 **1380 篇、十家第一**，班固按语却说
"诸子十家，其可观者九家而已"——**著录量第一的学派被逐出'可观'**：
目录学的收录（inclusion）与承认（recognition）是两回事，
一张目录里看得见一整套价值秩序。

## 假设与依赖

- 假设：分类可反映知识结构 → 代价：类名带时代预判（"小说"古今义大异）
- 依赖：版本学（定"一书"的边界——同书异本算几种？）
