# 讲透国际知识产权法学 · 创新的跨境产权（GB/T 82040 三级：国际知识产权法学）

> **这支负责的问题**：智力成果的产权如何跨国成立与执行——
> 一句钉住：**国际知产法的核心技术不是"保护什么"而是两个协调器：
> 国民待遇（不歧视外国人）+优先权（在 A 国申请日锚定 B 国的
> 新颖性）——一个"时间锚"条款支撑起整个全球专利体系。**

## 诞生

19 世纪的跨国展览逼出跨国保护：发明家把机器送去别国参展，
回来发现被当地"抢先"注册。1883《巴黎公约》（工业产权）与
1886《伯尔尼公约》（文学艺术作品）立起两大支柱（国民待遇+最低保护）；
1967 年《成立 WIPO 公约》设总管家；1994 年 TRIPS 协定把知产
绑上 WTO——**最低标准+强制争端解决，知识产权第一次有了"警察"**。

## 核心问题

| 问题 | 状态 |
|------|------|
| 国民待遇与优先权（两大协调器） | ✅ 已解（1883 年起运转百年） |
| 最低保护全球标准 | ✅ 已解（TRIPS 1994，绑入 WTO 单一承诺） |
| 公共健康与专利（强制许可） | ✅ 已解（多哈宣言 2001；TRIPS 疫苗豁免 2022 落地） |
| 遗传资源与传统知识保护 | 🔄 前线（WIPO 2024 年通过首份披露来源义务条约，批准尚在路上） |
| 生成式 AI 时代的作品与发明主体 | ❌ 未解（各国判例分叉，"AI 生成物可版权吗"无国际答案） |

## 这支最美的一个事实

优先权原则：在任一缔约国第一次申请专利后 12 个月内
（商标/外观 6 个月）到其他国家申请，新颖性仍按第一次的申请日算——
**一个多世纪的"时间锚"，让"全球专利布局"从不可能变成例行公事。**

## 假设与依赖

假设：统一最低标准利大于弊（南北方对此争论百年）；
创新激励与接入平衡可通过例外条款（合理使用/强制许可）动态调节。
依赖经济法支的贸易执行机制（TRIPS 依附 WTO）；各国知产局
（USPTO/EPO/JPO/CNIPA）的审查实务构成事实标准层。
