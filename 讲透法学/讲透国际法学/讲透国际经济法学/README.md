# 讲透国际经济法学 · 贸易投资金融的规则层（GB/T 82040 三级：国际经济法学）

> **这支负责的问题**：经济活动的跨国规则——贸易壁垒怎么拆、
> 投资者怎么起诉国家、金融监管怎么协调。一句钉住：
> **国际经济法是国际法体系里"执行得最好"的部分——因为守法本身赚钱：
> WTO 加入即同意强制管辖，是全世界自愿度最高的强制管辖。**

## 诞生

1944 布雷顿森林（IMF/世界银行）与 1947 关贸总协定（GATT——
哈瓦那宪章流产后的"临时协定"，一临时就是 47 年）搭起战后骨架；
乌拉圭回合（1986-1994）谈出一揽子"单一承诺"，1995 年 WTO 成立，
贸易争端从"打贸易战"变成"打官司"；双边投资条约（BIT）网络
+ICSID（1966）给私人投资者配上对国家的诉权（ISDS）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 非歧视双柱（最惠国+国民待遇） | ✅ 已解（GATT 1947 起成为整个体系的语法） |
| 强制性争端解决（加入即同意管辖） | ✅ 制度已立（WTO 1995）；上诉机构 2019 年起瘫痪，MPIA 临时代替 🔄 |
| 投资仲裁（ISDS）的正当性 | ❌ 未解（私诉国家的程序与实体改革拉锯中） |
| 安全例外边界 | 🔄 前线（例外被越用越宽，与"大国违约怎么办"同构） |
| 数字贸易统一规则 | ❌ 未解（方向锚：数字贸易碎片化——数据本地化遍地、诸边文本难产、电商关税暂停反复拉锯） |

## 这支最美的一个事实

GATT 以"临时适用议定书"的身份运行了 47 年，关税几轮回合谈下来，
成了史上最成功的"临时建筑"——**国际制度里，好用比名分重要。**

## 假设与依赖

假设：互惠让渡（市场换市场）能自我执行；经济相互依存是和平的压舱石
（ contested）；规则与例外共存（安全例外是体系的泄压阀，也是漏洞）。
依赖世界经济学做福利分析（对读），依赖私法支的仲裁走廊做执行。
