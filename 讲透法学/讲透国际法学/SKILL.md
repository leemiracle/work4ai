# 国际法学思维技能（GB/T 82040 · 家族抽象层）

> 家族本体：[讲透国际法学](README.md)；六章见章目表。
> 一句钉住：没有立法者，法从同意与习惯中长出；没有警察，法靠互惠与名誉存活。

## ① 何时用此分支（问题特征触发词）

1. "条约这条什么意思/能保留吗/怎么退出"——条约解释与生命周期
2. "哪国法院能管/适用哪国法/判决能执行吗"——国际私法三连问
3. "12 海里/毗连区/EEZ/公海/等距线"——海洋权益几何
4. "制裁名单/出口管制/两用物项/合规筛查"——国际经济法合规工程
5. "国际刑警红色通报=逮捕令吗/ICC 能抓谁/豁免挡不挡"——国际刑法
6. "习惯国际法怎么证明/opinio juris"——法源问题
7. "WTO 争端/ISDS 仲裁/BIT"——国家-投资者与贸易争端
8. "气候义务是硬是软/咨询意见有什么用"——环境法硬化线
9. "跨境数据/AI 条约/网络犯罪公约"——数字疆域立法
10. "谈判怎么设计/一揽子/建设性模糊"——条约工程

## ② 核心思维模式

- **同意眼**：任何国际规则先问"谁的同意、怎么给的"——
  管辖、义务、效力全从这问起
- **法源眼**：规则住在哪台机器里（条约/习惯/原则）——
  引用前先分清，习惯要两要素（实践+法律确信）
- **三连问眼**：跨国私案=管辖+选法+执行三问，只答一问等于没答
- **距离眼**：12/24/200 海里决定海上一切权力分配——
  位置先于实体
- **软硬眼**：义务的软硬是过程状态不是条款属性——
  问"什么机制在把它拧紧/软化"
- **无警察眼**：执行靠互惠、声誉、反措施——
  约束藏在明天里，不在罚则里
- **主体眼**：默认主体是国家；个人只在人权法（受益者）与
  刑法（被告）例外入场；公司无条约人格

## ③ 工具箱（何时用什么）

| 工具 | 何时用 |
|------|--------|
| VCLT 解释阶梯（31-32 条） | 条约条款有歧义——通常意义→上下文→目的宗旨→补充手段 |
| 保留三重门（19 条） | 判断保留可否：禁止？清单？目的与宗旨？ |
| 习惯两要素检验 | 无条约可引时：通例实践+法律确信，分开举证 |
| ARSIWA 责任框架 | 违约后怎么办：归因→违背→停止+保证+赔偿；反措施成比例 |
| 管辖依据清单 | 属地/属人/保护/普遍/被动人格——逐项过 |
| UNCLOS 分区表 | 海上权力分配的速查表（12/24/200+海峡+区域） |
| 冲突规则组 | 特别法/后法/强行法/对世义务——规则打架时排序 |
| 义务分级表 | shall/should/may——读条约先标硬度 |
| 重复博弈阈值 δ*=(T-R)/(T-P) | 解释"无警察为何守法"——互惠的数学条件 |

## ④ 常见误区与禁忌

- **"国际法是弱法所以不是法"**——错：执行软≠约束软，
  大多被遵守是经验事实（Henkin），机制是互惠与内嵌利益
- **"有世界警察/国际法院管一切"**——错：ICJ 管辖要同意；
  红色通报不是逮捕令；ICC 只管四类罪+补充性
- **"国际私法=选哪国法"**——错：三连问缺一不可，
  赢了管辖输了执行是常态
- **"软法没用"**——错：宣言与标准常经"硬化链"变成硬义务
  （气候咨询意见线），市场是比法庭更快的执法官
- **"条约自动约束非缔约国"**——错：pacta tertiis；
  除非它已结晶为习惯（两要素另证）
- **"把国内法直觉套国际法"**——错：横向体系无立法者/无强制执行/
  无先例拘束，法院是"同意的公证人"不是"权力的裁判官"
