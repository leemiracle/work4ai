# 讲透国际环境法学 · 从软法到硬化的气候生态规则（GB/T 82040 三级：国际环境法学）

> **这支负责的问题**：地球的公共坏处（污染/气候/灭绝）如何被
> "没有世界政府"的体系治理。一句钉住：**国际环境法是"软法先行"
> 的发明家——先用不具拘束力的宣言探路，再用议定书硬化，
> 如今更用咨询意见拧紧：方向锚——从软法走向咨询意见硬化。**

## 诞生

1972 斯德哥尔摩人类环境会议把"环境"从各国内政变成国际法对象；
1987《蒙特利尔议定书》证明条约能跑赢产业（受控物质清单年年被
缔约方决定增删）；1992 里约双公约（气候/生物多样性）+1997 京都
+2015 巴黎（自主贡献 NDC，刻意写软）；2024-2025 年咨询意见链
（ITLOS 2024-05-21"温室气体=海洋污染"→ICJ 首份气候咨询意见
2025-07-23）把软义务往硬处拧。更早的根：特雷尔冶炼厂仲裁
（1938/1941）立下"国家不得许可重大跨境损害"原则。

## 核心问题

| 问题 | 状态 |
|------|------|
| 不跨境重大损害原则 | ✅ 已解（1941 仲裁起成为习惯法基石） |
| 臭氧层治理 | ✅ 已解（《蒙特利尔议定书》1987——全员批准的唯一重大环境条约，臭氧层预计本世纪中叶愈合） |
| 气候义务硬度 | 🔄 前线（巴黎 NDC 是软的；咨询意见链正在把"应尽注意/不损害"拧到气候上） |
| 生物多样性遏制 | ❌ 未解（昆蒙框架 2022 定目标，执行机制悬空） |
| 气候损失与损害赔偿 | ❌ 未解（基金 2023 落地，规模与责任分配两悬） |

## 这支最美的一个事实

《蒙特利尔议定书》是第一份获得所有联合国会员国批准的
重大环境条约——**科学证据、条约机器、替代品工业三者闭环，
人类第一次在全球尺度上治好了一个自己造成的伤口。**

## 假设与依赖

假设：共同但有区别的责任（CBDR——历史责任不对称，义务也应对称）；
环境问题不可逆，故允许"软法先行、后硬化"的试错序（与常规条约的
"先谈硬再签"相反）；科学评估（IPCC 类机制）可接入规则修订回路。
依赖公法支的责任框架与公法支的划界技术（海洋）。
