# 讲透国际刑法学 · 个人的国际罪责（GB/T 82040 三级：国际刑法学）

> **这支负责的问题**：国际法如何直接追究**个人**的刑事责任——
> 一句钉住：**国际刑法是国际法体系里唯一"垂直"的分支：
> 它把被告席从国家换成个人，把"违反国际法的是人，不是抽象实体"
> （纽伦堡 1946）变成了可以开庭的规则。**

## 诞生

纽伦堡与东京审判（1945-46）首开个人国际刑事责任（并确立
"服从命令不免责"）；冷战冻结四十年后，前南斯拉夫问题国际法庭
（ICTY 1993）与卢旺达法庭（ICTR 1994）以特设法庭重启；
1998 年《国际刑事法院罗马规约》以 120 票通过、2002 年法院运作——
**从纽伦堡的临时法庭到常设法院，走了 57 年。**

## 核心问题

| 问题 | 状态 |
|------|------|
| 四类国际罪行（灭绝种族/危害人类/战争罪/侵略罪）成文化 | ✅ 已解（罗马规约 1998；侵略罪经坎帕拉 2010 修订、2018 激活） |
| 补充性原则（国家不愿或不能时 ICC 补位） | ✅ 已解（制度设计）；认定标准仍逐案争 |
| 国家元首豁免 vs 官方身份不免责（规约 27/98 条张力） | ❌ 未解（皮诺切特案 1998 起二十余年拉锯） |
| 逮捕执行（缔约国合作义务 vs 政治意愿） | 🔄 前线（2024 年多份逮捕令与 HRW《Justice at Risk》报告同框） |
| 非缔约国国民的管辖正当性 | ❌ 未解（安理会移交/属地触发之争） |

## 这支最美的一个事实

皮诺切特案（1998，伦敦）：一位退休国家元首因酷罪指控在伦敦被拘，
上议院为"元首豁免挡不挡得住酷刑普遍管辖"两次开庭、推翻自己一次裁决
——**"豁免属于职位，酷刑属于个人"自此进入全球司法对话。**

## 假设与依赖

假设：个人可为国际法主体（被告地位）；罪行"关涉全人类"支撑
普遍管辖；四道门槛（管辖/行为/心理/豁免例外）全过才有罪——
无罪推定在每个门槛上都设堡垒。依赖公法支的管辖理论与
国内刑法的教义工具；执行依赖缔约国政治意愿（无自有警力）。
