# 讲透国际公法学 · 国家间的宪法层（GB/T 82040 三级：国际公法学）

> **这支负责的问题**：主权国家彼此之间如何被规则治理——法源（法从哪来）、
> 主权与承认（谁是玩家）、管辖权（谁管什么事）、海洋与空间的权利分区、
> 武力使用的合法化门槛。一句钉住：**国际公法是国际体系的"宪法层"：
> 它不判个案，它规定"判个案的人凭什么判"。**

## 诞生

格劳秀斯 1625《战争与和平法》给出语法（理性之法），威斯特伐利亚和约
1648 给出舞台（主权国家体系），瓦泰尔 1758《万国法》给出根基
（国家只受自己同意的约束）；1920 常设国际法院开司法化先河，
1945《联合国宪章》+国际法院立起现行骨架——**三百年才写完一部
"没有立法者的宪法"。**

## 核心问题

| 问题 | 状态 |
|------|------|
| 法源体系（条约/习惯/一般原则） | ✅ 已解（规约 38 条框架+VCLT 1969 定型） |
| 海洋分区（12/24/200+公海+区域） | ✅ 已解（UNCLOS 1982，50 年炮程之争一锤定音） |
| 武力使用非法化（宪章 2(4)） | ✅ 规则已立（1945）；自卫边界与"间接武力"仍在解释中 |
| 习惯如何证明存在（opinio juris 认识论难题） | ❌ 未解（两要素检验定型，循环论证无终解） |
| 网络空间是不是"全球公域" | 🔄 前线（首份联合国网络条约 2024-25 只覆盖犯罪一角） |

## 这支最美的一个事实

荷花号案（PCIJ 1927）以 11:9 判下"国际法未禁止即自由"，
九位反对法官写下的"未允许即禁止"在日后的人道法与气候义务中步步还魂——
**同一个案件，产出两种国际观，百年张力皆源于此。**

## 假设与依赖

主权平等、同意约束、国家中心三条假设（家族 00 章 §四）在本支最纯；
依赖：国际政治学的权力分析做"暗面对照"，条约谈判记录与国家实践
语料做证据层。大国违约的执行缺口是本支永恒的背景噪声。
