# 讲透国际私法学 · 私人跨国的三连问（GB/T 82040 三级：国际私法学）

> **这支负责的问题**：私人（公司/个人）的跨国争议怎么办——
> 一句钉住：**国际私法的核心不是"适用哪国法"，而是三连问：
> 哪国法院管（jurisdiction）+哪国法管（choice of law）+
> 判决能否执行（recognition & enforcement）。只答一问，等于没答。**

## 诞生

17 世纪荷兰学者胡伯（Ulrik Huber）提出冲突法三原则——外国法之所以被适用，
出于"礼让"（comity）而非义务；美国斯托里（Joseph Story）1834 年
《冲突法评论》定名学科；20 世纪发生方法革命：僵化的硬性连结点
（合同订立法、侵权行为地法）让位于"最密切联系"
（Restatement (Second) 1971）。国际私法是从民法典的缝隙里长出来的学科
——商人先跨国，法学家后跟上。

## 核心问题

| 问题 | 状态 |
|------|------|
| 选法方法（硬性规则→最密切联系原则） | ✅ 已解（20 世纪革命，各国立法采纳） |
| 外国判决的承认与执行 | ✅ 部分解决（布鲁塞尔体系区域化；海牙判决公约 2019 起铺网） |
| 仲裁裁决全球执行 | ✅ 已解（纽约公约 1958，缔约方 170+——史上最成功的"执行条约"） |
| 互联网时代的管辖（数据跨境/平台全球可诉性） | 🔄 前线（效果原则/指向性活动标准竞合） |
| 跨国平行诉讼与挑选法院（forum shopping） | ❌ 未解（禁诉令各国各用，协调机制空缺） |

## 这支最美的一个事实

1958《承认及执行外国仲裁裁决公约》（纽约公约）让一纸仲裁裁决比
任何法院判决都更容易跨境执行——**为私人争议造出了全世界最强的
"执行联盟"，而国家间的判决执行至今没谈成同样的网。**

## 假设与依赖

假设：各国法律体系地位平等（没有"更高级的法"可供适用，只有选择问题）；
主权可以分解为"管辖/立法/执行"三束分别讨论。依赖各国民事诉讼法与
仲裁实务；国际经济法支提供商事合同的实体规则层。
