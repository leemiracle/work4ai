# 04 · 国际法学转代码：可编译的光谱与裂缝

> **本章回答五问之五（家族层）：这个分支的问题怎么变成 code 问题？**
> **本质一句话**：国际法的问题呈一条**可编译光谱**——
> 一端是纯几何（海洋分区 12/24/200 海里，一条 if-elif 链），
> 另一端是纯规范判断（"公平解决""目的与宗旨"，原则上不可自动化），
> 中间是状态机、规则引擎与博弈模拟的广阔地带。本章给三件套：
> **可机械化边界 / 六条代码走廊 / 工程师落点**，外加裂缝清单。

📖 **开篇故事**：一艘船在海上被拦截，律师问的第一句话不是"谁的船"，
而是"**在哪**"。位置决定法域：基线外 12 海里内是领海（船旗国法让位于
沿海国法，但有无害通过权），24 海里内是毗连区（沿海国只有海关/财政/
移民/卫生四类管制权），200 海里内是专属经济区（资源权归沿海国、
航行自由归大家），之外是公海（船旗国独占管辖）。
把这个判断写成代码就是一条 if-elif 链——国际法最"可编译"的部分。
而同一位律师转身面对"习惯法是否已经结晶"，任何代码都帮不了他。
**这两个场景的距离，就是本章的地图。**

---

## 一、可机械化边界（三件套之一）

| 任务 | 可机械化？ | 说明 |
|------|-----------|------|
| 海洋分区判定（12/24/200） | ✅ 全自动 | 基线+缓冲区几何（家族实验一）——注意真实划界须用大地测量学，实验是平面简化 |
| 等距线/中间线构造 | ✅ 自动（简化） | 逐点构造有标准算法；真实案件的基点取舍/海岸凹凸极复杂 |
| 条约生效/退出/继承状态机 | ✅ 全自动 | 批准数阈值/保留日/生效日/退出通知期，纯事件驱动 |
| 保留兼容性**程序性**筛 | ✅ 全自动 | 条约禁止保留？保留清单穷尽？——条文可查 |
| 保留兼容性**目的性**检验 | 🟡 半自动 | "与目的与宗旨相容"是规范性判断（VCLT 19(c)），只能给证据不能下结论 |
| 制裁/出口管制名单筛查 | 🟡 半自动 | 名单匹配全自动；因果认定与许可证判断在人（合规工程主战场） |
| 遵守的机制建模（互惠/声誉） | ✅ 可模拟 | 重复博弈（家族实验二）——**解释性**而非预测性 |
| 习惯法识别（实践→规则） | 🟡 半自动 | 联大投票/声明/立法语料的 NLP 归纳可列证据；opinio juris 判定在人 |
| 条约义务强度标注（shall/should/may） | 🟡 半自动 | 规则+LLM 草标，必须人审 |
| 判决预测/法益衡量 | ❌ 不可全自动 | 教义衡量+政治语境；AI 只能检索增强 |
| 划界方案的"公平解决"检验 | ❌ 原则上不可 | UNCLOS 83 条"公平解决（equitable solution）"是开放规范——几何给候选，公平衡量给裁决 |

**光谱总图**：几何（✅）→ 状态机（✅）→ 规则引擎（🟡 程序面 ✅）→
语料归纳（🟡 证据面）→ 规范衡量（❌）。**从左到右，规则退场，裁量进场**。

## 二、代码走廊总表（三件套之二）

| 走廊 | 问题→形态→栈 | 承诺强度 |
|------|--------------|---------|
| ① 海洋法几何 | "这点在哪个区/界在哪" → 基线+缓冲区+等距采样 → 纯 python（生产用 GIS+大地测量） | 平面模型算得准；真实世界须椭球修正 |
| ② 条约生命周期 | "保留有效吗/生效了吗" → 状态机+三重门规则 → 纯 python | 程序面确定；目的检验留人 |
| ③ 遵守博弈 | "没有警察为何守法" → 重复囚徒困境+触发策略 → 纯 python | 机制解释，非行为预测 |
| ④ 义务强度文本走廊 | "这条多硬" → shall/should/may 标注+条款比对 → nlp/LLM | 草稿级，必须人审 |
| ⑤ 案例与仲裁语料 | "先例地图" → 引用网络+检索增强问答 → python+图 | 检索准确≠推理正确 |
| ⑥ 合规工程 | "这门生意能做吗" → 制裁名单/两用物项筛查+审计留痕 → 企业级栈 | 工业界最成熟走廊 |

### 走廊①：海洋法几何（本章主样本）

```python
# 海洋分区的"直译"——国际法最可编译的一段（家族实验一为完整版）
def zone(distance_nm: float) -> str:
    if distance_nm <= 12:   # 领海：主权所及，但须容无害通过（UNCLOS 2/17）
        return "territorial_sea"
    if distance_nm <= 24:   # 毘连区：仅海关/财政/移民/卫生四类管制（33 条）
        return "contiguous_zone"
    if distance_nm <= 200:  # 专属经济区：资源性主权权利，非主权（56/57 条）
        return "eez"
    return "high_seas"      # 公海：六大自由（87 条）
```

三个工程细节是走廊的灵魂：
- **基线不是岸线**：正常基线=沿海低潮线；曲折海岸/群岛可划直线基线——
  基线怎么划本身是法律事实+测量事实的合成，几何引擎只能消费不能生产
- **平面 vs 椭球**：实验用平面欧氏距离教学；生产必须大地测量
  （WGS84 椭球测地线距离，Karney 算法），纬度越高平面误差越大
- **岩石条款是规范开关**：UNCLOS 121(3)——"不能维持人类居住或其本身
  经济生活的岩礁，不应有专属经济区"。"能不能维持人类居住"是
  法律-事实认定（有淡水算吗？季节性渔民算吗？）——
  实验一里它是一个布尔参数，现实里它是一场诉讼

### 走廊②：条约生命周期状态机（对应实验二上半）

```python
# VCLT 19 条"保留三重门"的直译
def reservation_admissible(treaty, reservation) -> tuple[bool, str]:
    if treaty.reservations_prohibited:                    # 门1:条约明文禁止
        return False, "prohibited"
    if treaty.permitted_list and reservation.item not in treaty.permitted_list:
        return False, "outside_permitted_list"            # 门2:只许清单内保留
    if not compatible_with_object_and_purpose(reservation):# 门3:目的与宗旨
        return False, "incompatible"                      # ← 规范判断,代码只能挂证据
    return True, "admissible"
```

门 1、门 2 是查表；门 3 是二百页法学论文的题目。**状态机负责"何时生效、
对谁生效"，规范引擎负责"能不能保留"——两台机器必须分开设**。
生效后还有 VCLT 20-21 条的效果矩阵（接受/反对/反对且阻止生效三态，
对每对国家关系分别成立），实验二把它跑通。

### 走廊③：遵守博弈——"Henkin 现象"的机制版

Henkin 说"几乎一切国家几乎在一切时候遵守"（[00 章](00-体系结构.md)
反直觉⑴）。为什么没有警察还守法？走廊③给出最小形式模型：

```python
# 无限重复博弈中,grim trigger 能支撑合作当且仅当贴现因子够大
# 囚徒困境支付: R=互相合作3  T=背叛诱惑5  P=互相背叛1  S=被背叛0
delta_star = (T - R) / (T - P)   # = 2/4 = 0.5
# delta >= 0.5 时,"你违约我永远报复"的威胁足以让守约成为最优——
# 没有警察,但有无穷个明天(民间定理的两人特例)
```

**读法纪律**：这是**机制解释**（互惠+长期性能替代警察），不是预测模型
（真实国家还受声誉、国内政治、议题联动影响）。它形式化了国际法
执行结构的核心直觉——**约束藏在明天里**。

### 走廊④⑤⑥：三句话导览

- **④文本走廊**：义务分级标注是法条工程的"语法高亮"——
  LLM 草标+人审是当前最优分工（幻觉红线见裂缝清单）
- **⑤语料走廊**：ICJ/PCA/ICSID/ICC 判决库的引用网络与检索增强，
  回答"谁引过谁"，不回答"谁会赢"
- **⑥合规走廊**：制裁名单筛查（OFAC/欧盟/联合国名单）、两用物项
  出口管制、审计留痕——**国际法最大的产业级代码面**，
  也是本章工程师落点的主场

## 三、工程师落点（三件套之三）

1. **合规工程**（走廊⑥）：跨国企业的制裁/出口管制/反洗钱筛查系统——
   名单每日更新、模糊匹配（同名/转写变体）、间接持股穿透、
   完整审计链。岗位密度最高的"国际法×代码"交叉点
2. **海事 GIS**：电子海图（ENC）上的船位监控与 EEZ 预警、
   渔业管控（VMS/AIS 数据×分区几何——走廊①的生产版）
3. **条约知识管理**：联合国条约库（UNTS）规模数万条约，
   检索/比对/保留状态追踪是天然的数据库工程
4. **法律科技**：仲裁文书起草、判例检索增强（RAG）、
   多语言条款对齐——法庭工程（03 章 L4）的软件面

## 四、裂缝清单（哪里会摔死）

- **平面几何的傲慢**：实验一的教学模型在真实纬度/长距离上误差惊人；
  生产必须换测地线距离与法定基点库
- **名单筛查的假阳性地狱**：同名、转写变体、间接持股——
  筛查系统漏报是违规、误报是商誉事故，两头都是官司
- **LLM 判案幻觉红线**：国际法没有官方判例汇编全库，
  模型会"编造"判词与条款号——AI 框架公约（[01 章](01-近五年创新.md)
  方向三）要求人类最终责任，正是这条红线的新条约化
- **规范性判断的伪自动化**：把"公平解决""目的与宗旨"硬塞进规则引擎，
  得到的是确定性外壳包裹的任意性——比没有代码更危险
- **数据真空**：国家实践证据（立法/声明/执法记录）本身不全——
  习惯法识别的上限不在算法在语料

## ✍️ 练习

1. **光谱自摆**：任取三个国际法任务（如"引渡请求是否符合双重犯罪"
   "某船位是否在 EEZ 内""侵略是否成立"），放在 §一光谱上，
   写明判断依据属于哪一档
2. **岩石开关实验**：跑实验一时把岛屿的 `rock=True/False` 各跑一遍，
   对比 (250,5) 点的法域变化——然后用一句话向非律师解释
   "为什么这个布尔值在现实里是十年诉讼"
3. **δ 阈值推异**：实验二把背叛诱惑 T 从 5 调到 7（δ*=0.667），
   观察合作更难维持——用它解释"高诱惑议题（安全类）比低诱惑议题
   （技术标准类）更难立约"

## 📌 收束

国际法学转代码=**一条从几何到公平衡量的可编译光谱**：海洋分区与
状态机全自动化，保留与习惯半自动（证据自动化、结论留人），
规范衡量原则不可自动。六条走廊里，合规工程已经是产业，
海洋几何是百年工艺，博弈模拟是解释引擎——而最前沿的战斗
（AI 条约要求的"人类最终责任"）恰好发生在光谱的最右端。
