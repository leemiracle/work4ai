# 讲透国际法学 · 无世界政府之下的秩序科学（GB/T 82040）

> **国际法学=无世界政府之下的秩序科学：主权国家们如何在没有立法者、
> 没有国际警察、没有强制执行法院的世界里，造出有约束力的规则——
> 而且这些规则大多被遵守。**一句钉住：**没有立法者，法从同意与习惯中长出；
> 没有警察，法靠互惠与名誉存活——国际法是一部水平方向运行的法。**
> 格劳秀斯 1625 给它语法，威斯特伐利亚 1648 给它舞台，联合国 1945 给它骨架。
>
> GB/T 13745：82040（二级学科，法学 820 之下，三级 6 条全部落子，支名=GB/T 三级名）。
> 宇宙：[讲透法学](../README.md)。

## 〇、家族定位与成员（含消歧框，必读）

- 学科身份：法学宇宙的**跨国切面**——国内法问"主权者如何治民"，
  本家族问"主权者彼此之间如何被规则治理"
- 与国际政治学的分工（一体两面，互链）：
  [讲透国际政治学](../../讲透政治学/讲透国际政治学/)看**权力秩序**（谁强谁弱、均势如何维持），
  本家族看**规范秩序**（规则如何成立、被解释、被遵守）——
  同一片国际无政府状态，两副透镜；读懂任何一边都要借另一边的光
- 跨宇宙弱链（只链已存在目标）：
  [讲透军事学](../../讲透军事学/README.md)（战争法/国际人道法本体在彼侧，就低弱链）、
  [讲透经济学/讲透世界经济学](../../讲透经济学/讲透世界经济学/)（国际经济法支的制度经济侧）、
  [讲透新闻传播学](../../讲透新闻传播学/)（信息主权与跨境数据弱链）

## 一、六支家族树

```
讲透国际法学/
├── 讲透国际公法学/        国家间的宪法层：主权·法源·管辖·海洋·武力
├── 讲透国际私法学/        私人跨国的三连问：哪国法院管+哪国法管+判决能否执行
├── 讲透国际刑法学/        个人如何为国际罪行担责：纽伦堡→罗马规约→ICC
├── 讲透国际经济法学/      贸易·投资·金融的跨国规则层：WTO/BIT/ICSID
├── 讲透国际环境法学/      气候与生态规则：从软法宣言到咨询意见硬化
└── 讲透国际知识产权法学/  创新的跨境产权：巴黎公约/伯尔尼/TRIPS/WIPO
```

> 归属注记：GB/T 82040 三级共 6 条全部落子（支名取 GB/T 三级名，不臆造支代码）；
> 国际人道法（战争法/jus in bello）本体在
> [讲透军事学](../../讲透军事学/README.md)，本家族公法支内按通说概述并互链；
> 国际人权法通说并入国际公法学支陈述，不另立支。

**特征速查（问题→支）**：

- 条约怎么读/海洋多远算谁的地盘/武力何时合法 → [国际公法支](讲透国际公法学/)
- 跨国合同去哪国法院吵/哪国法管/判决怎么执行 → [国际私法支](讲透国际私法学/)
- 战争罪/危害人类罪谁审谁抓 → [国际刑法支](讲透国际刑法学/)
- 贸易壁垒/投资仲裁/制裁合规 → [国际经济法支](讲透国际经济法学/)
- 气候义务/跨界污染/生物多样性 → [国际环境法支](讲透国际环境法学/)
- 专利商标著作权跨境保护 → [国际知产法支](讲透国际知识产权法学/)
