# 讲透安全法学 · 风险的可接受性如何写成条文（GB/T 8203080）

> **这支负责的问题**：安全领域的法律治理——职业安全、
> 公共安全、国家安全法治化的制度谱系与共同结构。一句
> 钉住：**安全法回答一个工程学不回答的问题——多安全
> 才算"足够安全"，这条线画在哪。**

## 诞生

**1833 英国工厂法**：职业安全立法起点（机器时代的肢体
保护）→ 19 世纪末-20 世纪公共安全立法扩展（矿山/建筑/
消防，事故推动型立法节奏）→ 1970 美国职业安全健康法
（风险标准体系化的样板）→ 20 世纪产品安全与系统安全
立法（从"事后追责"转向"事前标准"）→ 21 世纪各国网络、
数据等新领域的安全立法浪潮（制度谱系比较呈现）。因的
问题：安全是典型公共品（市场供给不足）+风险是概率
现象（零风险不存在）——法律必须回答"风险的可接受性"
这条线画在哪、由谁画、怎么检查。

## 这支最美的一个事实

安全法是"以事故为立法节奏"的领域——**每部重要立法的
背后，是一场灾难的制度学费；条文里每一个数字阈值，
背后都有一份事故清单**。别的法跟着观念走，安全法跟着
事故走：它是法律体系里最残酷也最诚实的学习算法。
