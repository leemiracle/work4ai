# 讲透司法鉴定学 · 从《洗冤集录》到 DNA：科学证据（GB/T 8203065）

> **这支负责的问题**：专门性事实问题如何经科学检验进入
> 法庭——鉴定意见怎么产出、怎么审查、怎么采信。一句钉住：
> **鉴定意见是"科学写给法庭的证词"——但科学也会错，
> 所以科学结论同样要接受质证。**

## 诞生

**1247 宋慈《洗冤集录》**：系统的验尸检验规程，法医学的
世界性先声 → 欧洲近代法医学（16 世纪帕雷的外科检验
著述，学科史通说引证）→ **1879 贝蒂隆人体测量法**：第一
个科学人身识别系统 → **1892 高尔顿《指纹》**：指纹个别性
论证，识别技术换代 → 20 世纪法庭科学实验室建制（毒理/
文检/血清各科分化）→ 1985 杰弗里斯 DNA 分型首案应用
（个体识别精度封顶）→ 各国鉴定人出庭与专家辅助人制度
成熟。因的问题：事实问题的专门性超出法官常识——法庭
需要一套把科学结论转译成证据、又防止科学权威压倒
质证程序的规则。

## 这支最美的一个事实

《洗冤集录》（1247）比欧洲法医学之父帕雷的著作早三个多
世纪——**七八百年前的验尸规程里已有"自缢与假自缢"的
甄别条目：科学证据的雏形，是一份给尸体提的问题清单**。
这门学科的方法论从未改变：把可疑的事实变成可检验的
问题。
