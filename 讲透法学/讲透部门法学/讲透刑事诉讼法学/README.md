# 讲透刑事诉讼法学 · 无罪推定：追诉权的程序缰绳（GB/T 8203050）

> **这支负责的问题**：国家追诉犯罪的权力按什么程序发动——
> 侦查/起诉/审判如何分权，被追诉人有哪些对抗权。一句钉住：
> **最强大的国家追诉权，被要求证明到"排除合理怀疑"才可
> 定罪——刑诉法是给追诉权套上缰绳的法。**

## 诞生

古典弹劾式（罗马与早期日耳曼：私人追诉，法院居中）→
中世纪纠问式（教会法 Inquisitio：官方主动查究，效率与
擅断一体两面）→ **1764 贝卡利亚《论犯罪与刑罚》**：无罪
推定的理论出生证 → 法国大革命后弹劾式改造（控审分离
重建）→ 19-20 世纪职权主义与当事人主义两大模式并立、
互相吸收（混合式改革）→ **1966《公民权利和政治权利国际
公约》第 14 条**：无罪推定成为国际标准。因的问题：纠问式
把追诉与审判合一，高效的代价是没有中立者——程序的第一
件事是把"控、辩、审"拆回三个座位。

## 核心问题

| 问题 | 状态 |
|------|------|
| 无罪推定与"排除合理怀疑"证明标准 | ✅ 1764 理论→19 世纪法典化→1966 国际公约，通说地基 |
| 控审分离/控辩平等/审判中立（三角形结构） | ✅ 通说成熟 |
| 非法证据排除规则 | ✅ 制度比较成熟（排除范围与例外各国宽窄不一） |
| 强制措施的比例原则 | ✅ 通说框架成熟（逮捕与羁押的必要性审查） |
| 认罪协商的制度定性 | ❌ 悬而未决（效率与对审制的张力，各国模式分岔） |

## 这支最美的一个事实

布莱克斯通 1765 年的比率（宁可放过十个有罪，不可冤罚
一个无辜，教科书常引）：**刑诉法给国家上的第一道缰绳是
一个数学式问题——"怀疑要排除到什么程度"**。证明标准
本质上是错误分配算法：它事先声明，哪一类错误是制度
更不能忍受的。
