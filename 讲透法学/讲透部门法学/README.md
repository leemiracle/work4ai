# 讲透部门法学 · 法的解剖学（GB/T 82030）

> **部门法学=法的解剖学**：理论法学（82010）问"法是什么"，
> 本家族把法这条大鱼**剖开分装**——公法屉（宪法/行政/刑法：国家权力
> 如何被法驯服）、私法屉（民法/婚姻/知产：平等主体如何自治）、
> 社会法屉（劳动/经济：结构性不平等的矫正）、程序法屉（三大诉讼
> +刑侦/司鉴两门证明科学：纠纷解决的轨道）、领域交叉带（军事/
> 卫生/环境/安全/宗教：按问题领域重切）。一句钉住：**每个部门都是
> 一把手术刀，切社会关系的一层——代价是掉进刀缝里的问题无人认领，
> 直到领域法把它们捞回来。**
>
> GB/T 13745：82030（二级学科，法学 820 之下；三级共 19 条：
> 18 支实建+1 条兜底声明）。
> 宇宙：[讲透法学](../README.md)。
