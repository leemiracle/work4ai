# 部门法学思维技能（GB/T 82030 · 讲透部门法学家族的抽象层）

## ① 何时用此分支（问题特征触发词）

1. 「这条规则适用于本案吗」——一切**要件匹配/涵摄**类问题
2. 某行为"违法"的强度判断——民事违约/行政违法/刑事犯罪三档怎么分
3. 数罪并罚/量刑区间/诉讼时效/期间届满日——**带数字与日期的规则计算**
4. 两条规则打架谁优先——上位法/特别法/新法（位阶冲突）
5. 权利主张的"依据是什么"——请求权基础检索
6. 合规即代码/法律科技/规则引擎/合同审查系统设计
7. 判例引用关系/引证网络/先例约束力结构
8. 跨领域问题归属——平台用工/数据/算法/AI 生成物掉哪个屉（领域交叉）

## ② 核心思维模式

- **屉眼**：先问"这掉哪个屉"（公法/私法/社会法/程序法/领域交叉），
  再问"是不是掉缝问题"——交叉问题天然多屉
- **要件眼**：把规则读成"要件→效果"的条件句；把案件读成
  要件三态（满足/不满足/待定）——**结论是步骤的输出，
  不是立场的输出**
- **楼层眼**：判断先画漏斗（该当→违法→有责；起诉要件→诉讼要件
  →本案）——分歧常因停在 Different 楼层
- **克制眼**：强制力越大的规范越看自我限制——刑法谦抑、
  罪刑法定、程序保障都是"刀鞘"
- **证明眼**：主张成立/不成立/真伪不明三态——真伪不明时
  谁举证谁输，证明责任分配=权利的成色
- **寿命眼**：规则要写得比政权长寿——把一时目标翻译成
  可反复适用的中性结构

## ③ 工具箱（何时用什么）

| 工具 | 何时用 |
|------|--------|
| 要件检查表（阶层漏斗） | 案件分析——逐层短路，防跳层 |
| 请求权基础定序检索（合同→…→不当得利） | 民事主张找依据，防遗漏防重复 |
| Hohfeld 八原子拆解 | "这条款到底给了什么"——权利/特权/权力/豁免 |
| 位阶冲突语法（superior→specialis→posterior） | 规范打架判优 |
| 数罪并罚三轨（吸收/限制加重/并科） | 多罪执行刑区间计算（家族实验①） |
| 期间计算（起算点+中断/中止+顺延） | 时效/期日问题 |
| 判例 DAG（拓扑排序+权威深度） | 引证网络与环检测（家族实验②） |
| 三档判档表（全自动/半自动/纯人工） | 任何"法律+代码"项目开工前 |

## ④ 常见误区与禁忌

- **"违法=犯罪"词汇病**：三档强度（民事/行政/刑事）不同，
  用词混档是最常见的业余信号
- **跳层判断**：不做要件分析直接给结论——鉴定式的价值在楼梯
  不在结论
- **把类型词当集合**："诚实信用/合理注意"没有封闭外延，
  枚举式实现必然漏边界案例——留给"待定"出口
- **给权衡上数字**：原则冲突的"重量"无刻度——任何权重表
  都是变相立法
- **规则库无版本**：法条有生效区间与修订史——没有版本化与
  生效日期的规则引擎是定时炸弹
- **全自动法律判断幻觉**：涵摄相似性与事实认定不可复核地
  自动化=输出不可说理的结论——半自动的显式人工出口是
  教义学要求，不是产品妥协
- **用外国概念硬套**：部门法高度本地化——比较法概念
  （如各类审查/责任模式）先做制度类型对照再迁移

## ⑤ 与相邻分支的判别表 + 组合接口

| 症状像… | 但去 | 判别 |
|---------|------|------|
| 法是什么/为何守法/解释方法论 | 讲透法学/讲透理论法学 | 元层问题在那边；本家族管具体部门规则的适用 |
| 法的历史沿革 | 讲透法学/讲透法律史学 | 纵向史料在那边；本家族只用其结论 |
| 跨国规则冲突 | 讲透法学/讲透国际法学 | 涉外/国际法源在那边 |
| 市场与竞争的经济机制 | 讲透经济学 | 经济本体在那边；经济法/劳动法支管规制切面（互链） |
| 司法/议会/选举制度本体 | 讲透政治学/讲透政治制度 | 制度本体在那边；宪法学/行政诉讼法学支互链 |
| 技术安全（攻防/测评） | 讲透信息安全技术 | 技术在那边；安全法学支管风险法律结构（互链） |
| 军事本体 | 讲透军事学 | 军事本体在那边；军事法学支就低互链 |

组合接口：部门法学×信息安全技术→合规即代码与数据规制；
部门法学×性能工程→法律规则引擎的延迟工程（检索与匹配的
热路径）；部门法学×统计学→司法鉴定/证据评价的错误率结构；
部门法学×LLM→法律科技（判档先行：结构可自动、涵摄留人）。
