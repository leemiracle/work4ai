# 讲透刑事侦查学 · 每一次接触都留下痕迹（GB/T 8203060）

> **这支负责的问题**：犯罪事实如何在审判之前被合法地发现
> 与固定——侦查措施怎么授权、物证怎么提取、现场怎么读。
> 一句钉住：**洛卡德物质交换原理——凡接触必留痕迹；
> 侦查学的全部技术，是让痕迹开口。**

## 诞生

前史：验尸与追缉的零散技艺（各文明古已有之）→ **1893
汉斯·格罗斯《司法检验官手册》**：把侦查技艺整理成学科，
并命名 Kriminalistik（刑事侦查学）→ 人身识别三级跳：
1879 贝蒂隆人体测量法（第一个科学识别系统）→ 1892
高尔顿《指纹》论证指纹个别性（测量法被淘汰）→ 20 世纪
法庭科学实验室分化（痕迹/文检/毒物）→ 侦查措施法制化
（强制侦查须法律授权，随各国刑诉法典化定型）→ 1980s
DNA 分型（识别精度再跃一级）。因的问题：犯罪发生在
过去、藏在暗处——侦查是"从结果回溯原因"的逆推工程；
而权力与技术握在同一只手里，必须同时给技术立方法、
给权力上缰绳。

| 问题 | 状态 |

## 这支最美的一个事实

洛卡德物质交换原理一句话把侦查学接到物理学上：**两个
物体接触，物质必然双向转移——没有完美犯罪，只有尚未
被提取的交换**。它不能被证明，只被百万次勘查默证；
侦查学的全部仪器，都是这条原理的读出装置。

  这门学科的生长带）
