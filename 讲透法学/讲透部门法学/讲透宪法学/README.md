# 讲透宪法学 · 根本法的规范结构（GB/T 8203010）

> **这支负责的问题**：一个国家全部规范的**位阶顶端**长什么样、
> 最高效力如何成为可操作的法律事实。一句钉住：**宪法学经历了
> 从"权力说明书"到"权利防线"的生长——组织法只是它的骨架，
> 基本权利才是它现代的心脏。** 本支只写规范结构与通说概念，
> 不作任何现行条文的政治解读。

## 诞生

亚里士多德《政治学》以"政体"（constitution）为政治组织的分析
单元（前 4 世纪）→ 1215《大宪章》：王权受规则约束的观念原型
事件 → **1787 费城制宪**：第一部现代成文宪法，成文宪政主义
开端 → 19-20 世纪成文宪法全球化 → 二战后基本权利复兴：
宪法从国家组织规范长成可裁判的最高规范。因的问题：
权力交接的规则化（谁来定规则、规则改不改得了自己）与
权力本身的驯化。

## 核心问题

| 问题 | 状态 |
|------|------|
| 成文/不成文、刚性/柔性的分类学 | ✅ 通说成熟（英国不成文宪法证明：宪法的本质是实效位阶秩序，不是一本装帧） |
| 违宪审查的制度类型比较 | ✅ 类型学成熟：集中式（凯尔森设计，1920 奥地利建制）vs 分散式（1803 马伯里案开创的附随审查）vs 混合式 |
| 权利义务的理论分类 | ✅ 通说框架：防御权/给付权（消极/积极），第一代-第二代-第三代权利 |
| 基本权利的第三人效力 | ❌ 理论争议中（直接效力说/间接效力说/国家行为说，各国实践分岔） |
| 数字时代基本权利的再参数化（信息自决等） | ❌ 进行中（家族 01 章方向四） |

## 这支最美的一个事实

没有一部叫"宪法"的文件的英国，保有最古老的宪制连续性——
**宪法的存在形式是实效的位阶秩序，不是文本的装帧**；
成文与不成文之争因此从来不是"有没有宪法"，
而是"最高法住在哪里"。

## 假设与依赖

- 规范主义假设：宪法作为最高法被实际遵循（位阶命题依赖
  违宪审查制度的实效运转——无审查则位阶退化为修辞）
- 通说概念依赖[理论法学](../../讲透理论法学/)的规范/效力概念
  （凯尔森规范等级是其理论源头之一）
