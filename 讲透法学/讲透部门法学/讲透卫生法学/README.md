# 讲透卫生法学 · 知情同意：身体自主的法律化（GB/T 8203072）

> **这支负责的问题**：健康领域的法律关系——公共卫生权力
> 的边界、医患关系的定性、药品与医疗技术的规制。一句
> 钉住：**卫生法的轴心是知情同意：把"我的身体归我做主"
> 从伦理命题翻译成法律程序。**

## 诞生

14 世纪威尼斯港口检疫（quaranta giorni，四十天隔离——
公共卫生立法的制度起点）→ 1848 英国公共卫生法（城市
卫生治理法治化）→ **1947 纽伦堡法典**（人体实验的知情
同意十原则——战后医学伦理法化的制度史原点）→ 1979
贝尔蒙特报告（知情同意/受益-风险评估/公正三原则，
研究伦理的制度定型）→ 20 世纪各国医事法与公共卫生法
体系化（医师执业/药品审评/传染病防治全链条）。因的
问题：医疗是双重不对称现场——医患之间信息不对称
（医生知道、患者承受），个体与社会之间健康外部性
不对称（个人身体、公共风险）——两重结构要求两套
规则。

## 这支最美的一个事实

"Quarantine"源自威尼斯方言 quaranta giorni——**一座
港口城市规定的四十天隔离期，成了全世界的制度名词**：
一种语言的行政词汇被所有语言借用。卫生法最古老的
工具（隔离）沿用至今，只是从天数的经验值长成了比例
原则的审查对象。

## 假设与依赖

- 双重不对称假设：医患信息不对称+健康外部性（卫生法
  的一切制度都从这两条不对称出发——失效处即新制度
  的生长点）

  风险规制工具与[讲透安全法学](../讲透安全法学/)同源
