# 讲透行政诉讼法学 · 民告官的轨道：合法性审查（GB/T 8203045）

> **这支负责的问题**：公民、组织不服行政行为时，法院能
> 审什么、按什么标准审、判到什么程度。一句钉住：**行政诉讼
> 的制度史，就是让行政机关坐上被告席的历史——进入法庭，
> 权力主体就只是一个当事人。**

## 诞生

法国大革命后参事院（1799）受理行政争议（行政审判在行政
系统内部建制的起点）→ 判例积累：1873 布朗戈判决确立
行政责任依行政法规则自主判断（制度史中性引证）→ 19-20
世纪各国行政审判专门化（德国行政法院体系等）→ **1989
中国行政诉讼法**（"民告官"制度的立法化，学科史实中性
记述）→ 比较法定型：双轨制（法德型）与单轨制（英美型）
两大模式。因的问题：行政行为错了谁来判——普通法院审怕
越权干预行政，行政机关自审又落入"自己当自己的法官"，
制度在这组两难里寻找可信任的第三方。

## 核心问题

| 问题 | 状态 |
|------|------|
| 合法性审查的结构（职权/程序/事实/法律适用） | ✅ 通说成熟 |

| 原告资格与诉的利益 | ✅ 通说框架（保护规范理论等工具各国取舍不同） |
| 诉讼类型（撤销/履行/给付/确认） | ✅ 制度类型成熟 |
| 规范性文件的附带审查 | ❌ 进行中（抽象行为如何进入司法轨道，各国模式分岔） |

## 这支最美的一个事实

参事院设立时的身份是行政的自我约束装置——**一个"让
行政自己审自己"的制度，长了两百年，长出了独立于行政
系统的审判功能**。名分的遗传不如功能的遗传顽固：制度
要解决的真实问题，最终会改写制度最初的名字。
