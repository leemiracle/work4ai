# 讲透劳动法学 · 从属性劳动的保护法（GB/T 8203030）

> **这支负责的问题**：形式平等的雇佣合同里实质从属的劳动者，
> 如何被法律倾斜保护。一句钉住：**劳动法是"私法公法化"的
> 第一现场——合同的外壳原样保留，内核换成了底线：
> 有的条款可以谈，有的底线不许碰。**

## 诞生

工业革命把"人"变成"劳动力商品" → **1802 英国《学徒健康与
道德法》**（通说认定的第一部工厂立法）→ 19 世纪各国工厂法
（工时/童工/安全）→ 1919 国际劳工组织（ILO）成立（《凡尔赛
条约》第十三编，国际劳动立法建制）→ 20 世纪劳动法体系化
（个别劳动法+集体劳动法双轨）。因的问题：古典民法雇佣契约
预设对等谈判，工厂的现实是"要么接受条款，要么挨饿"——
意思自治在自己的辖区里第一次被承认为幻觉。

## 这支最美的一个事实

1802 年第一部工厂立法管的事出人意料地具体：**童工的
工作时间与夜间劳动**——劳动法的第一条基因不是"多给钱"，
而是"人不是零件"。两百年来条款换了一茬又一茬，
这条基因没有变过。
