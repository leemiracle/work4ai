# 讲透环境法学 · 给未来人类的法律权利（GB/T 8203075）

> **这支负责的问题**：环境损害的法律治理——污染控制、
> 生态保护、代际公平如何写成可执行的规范。一句钉住：
> **环境法保护的权利主体，大部分还没出生——它是写给
> 未来人类的法律。**

## 诞生

前史：零散的邻妨规则（罗马法不可量物侵入之诉——传统
私法工具的天花板）→ **1969 美国国家环境政策法（NEPA）**：
环境影响评价制度首建 → **1972 斯德哥尔摩人类环境会议**：
环境议题国际建制起点，环境权第一次被写进国际文件 →
1987 布伦特兰报告（"可持续发展"定义原典）→ 1992 里约
宣言（预防原则/污染者付费定型）→ 21 世纪各国环境法
法典化浪潮。因的问题：环境损害三特性——不可逆性、
潜伏性、主体缺位（受损的是不特定公众与后代人）——
传统私法"个人损害-个人请求"的结构装不下，必须重建
请求权主体与预防结构。

## 核心问题

| 问题 | 状态 |
|------|------|
| 预防原则（科学不确定时的行动规则） | ✅ 1992 里约定型，适用强度各国分岔（通说作制度比较） |
| 污染者付费原则 | ✅ 1972 OECD 提出→各国制度化 |
| 环境影响评价（EIA） | ✅ 1969 NEPA 首建→全球扩散 |
| 环境权的可诉性 | ❌ 悬而未决（宣言性权利如何进入裁判，各国分岔） |
| 气候损害的归责结构 | ❌ 进行中（排放-损害因果链与既有归责框架的适配） |

## 这支最美的一个事实

环境权 1972 年才第一次被写进国际文件，是最年轻的
"世代权利"——**前三代权利都在保护已出生的人，这一代
第一次给还没出生的人留了座位**。法律体系花了几千年
学会保护在场者，又用一场会议开始学习保护缺席者。

## 假设与依赖

- 代际公平公设：未来世代的利益可被当代法律代表
  （代理结构如何搭建是学理常驻题——通说以信托理论
  等方案比较呈现）
- 经济本体互链[讲透经济学](../../../讲透经济学/)（外部性
  与环境经济学：规制工具的福利分析在那边）；私法工具
  依赖[讲透民法学](../讲透民法学/)（环境侵权的请求权面）
