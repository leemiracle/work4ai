# 讲透经济法学 · 国家干预市场的法（GB/T 8203025）

> **这支负责的问题**：当市场的自发秩序失灵（垄断/外部性/
> 信息不对称），法律如何介入而不杀死市场。一句钉住：
> **民法假设平等主体，经济法从"结构性不平等的现实市场"
> 起步——反垄断法是它的皇冠，也是唯一一部"专门限制
> 一种产权行使方式"的法。**

## 诞生

1890 美国《谢尔曼法》（第一部反垄断法；谢尔曼参议员名句：
"如果我们不忍受政治上的国王，我们也不该忍受生产、
交通与生活必需品销售上的国王"——教科书常引）→
1910s 德国战时经济立法使"经济法"（Wirtschaftsrecht）概念化
→ 1929 大萧条与新政（国家干预的全球实验）→ 战后竞争法
扩散（1957 德国《反限制竞争法》、1957 罗马条约竞争规则）→
20 世纪末至今市场规制体系化。因的问题：19 世纪末的
大企业与托拉斯让"契约自由"变成"支配自由"——私法的形式
平等管不住结构性的市场权力。

## 核心问题

| 问题 | 状态 |
|------|------|
| 竞争法三大支柱（垄断协议/滥用支配地位/经营者集中） | ✅ 通说结构成熟（各国文本高度趋同） |
| 相关市场界定（一切分析的前置） | ✅ 方法成熟（替代性分析；需求交叉弹性等工具） |
| 消费者保护与市场规制的工具箱 | ✅ 通说成熟（信息规制/标准/许可） |
| 产业政策与竞争政策的边界 | ❌ 常驻张力（各国配置不同，通说作制度比较） |
| 平台经济的反垄断分析（算法合谋/数据壁垒） | ❌ 悬而未决（家族 01 章方向一） |

## 这支最美的一个事实

经济法证明了法可以"反着写"：别的部门法都在保护产权与
意思自治，**反垄断法专门限制一种产权的行使方式**——
你拥有公司，但你不能借所有权把竞争者挡在门外。
保护竞争，而不是保护竞争者，是通说的第一课。
