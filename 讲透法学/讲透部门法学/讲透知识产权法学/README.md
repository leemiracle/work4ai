# 讲透知识产权法学 · 无体财产的临时垄断（GB/T 8203085）

> **这支负责的问题**：人类智力成果（发明/作品/标识）如何
> 成为财产。一句钉住：**知产=有期限的垄断换公开——法律
> 故意制造垄断，为了终结保密：你把发明讲清楚，社会给你
> 一段时间独占；期限一到，归还公众。**

## 诞生

1474《威尼斯专利法》（通说认定的第一部专利法）→
1624 英国《垄断法》（Statute of Monopolies，近代专利制度
起点）→ **1710《安娜法令》**：第一部版权法，作者取代
书商成为权利主体——**从"专印特权"（privilege）到"权利"
（right）的关键一跃** → 1883 巴黎公约/1886 伯尔尼公约
（国际体系建制）→ 1994 TRIPS（知产与贸易挂钩，全球化
定型）。因的问题：知识的公共品属性（一份拷贝人人可用）
与激励创造的市场机制之间的死结。

## 这支最美的一个事实

林肯 1859 年演讲的名句："**专利制度是给天才之火浇上
利益之油**"——这句话藏着知产的全部交易结构：天才之火
本来会烧尽（保密、失传、师徒封锁），利益之油让它烧得
更旺、也烧得更公开（说明书必须写到同业能复现）。
