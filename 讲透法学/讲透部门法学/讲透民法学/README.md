# 讲透民法学 · 市民社会的百科全书（GB/T 8203020）

> **这支负责的问题**：平等主体之间的人身与财产关系——
> 买卖、租赁、物权、合同、侵权、继承。一句钉住：
> **民法典是写给普通人的最长使用手册，它的语法是
> 请求权基础——每一个主张都要能指出一条
> "谁得请求谁为/不为什么"的规范。**

## 诞生

罗马市民法/万民法双轨 → 盖尤斯《法学阶梯》（161，
教科书体）→ **优士丁尼《法学阶梯》（533）：教科书变成法典** →
1804《法国民法典》（三编制，法典化运动的旗帜）→
1814 蒂堡-萨维尼法典化论战（急立法典 vs 先养学理）→
1900《德国民法典》（BGB，五编制潘德克顿体系，论战输了
90 年却赢了学理）→ 2020 中国民法典（七编制，学科史实中性
记述）。因的问题：市场经济需要一套人人可预期、可自学的
私法操作系统。

## 核心问题

| 问题 | 状态 |
|------|------|
| 物权/债权二分（支配权/请求权） | ✅ 潘德克顿通说的地基，两大法系与各国民法共同结构 |
| 意思表示理论（法律行为的原子） | ✅ 通说成熟（表示解释优先于意思探究的现代转向） |
| 物权行为无因性 | ✅ 德国特有构造；各国民法典取舍不同（通说作立法政策比较） |
| 违约/侵权的竞合结构 | ✅ 请求权基础检索的定序（家族 03 章 3.2） |
| 数据与数字资产的物法定位（数据产权） | ❌ 悬而未决（既非物、非智力成果、非单纯隐私——家族 01 章方向四） |

## 这支最美的一个事实

1814 年萨维尼在论战中反对立刻法典化，被蒂堡批评为误国——
**德国晚了 90 年，却因为先造学理再造法典，得到体系最精的
BGB**：论战的败者赢得了结果。民法典的历史反复证明：
**仓促的法典是给下一代出的题，从容的法典是给下一代的答案。**

## 假设与依赖

- 平等与理性假设：预设当事人地位对等、能为自己计算——
  该假设失效的地带正是社会法屉（劳动/经济法）的诞生地
- 概念地基（法律行为/权利能力）由
  [理论法学](../../讲透理论法学/)审计；历史纵深由
  [法律史学](../../讲透法律史学/)供给
