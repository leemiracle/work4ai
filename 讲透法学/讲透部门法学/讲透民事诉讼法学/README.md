# 讲透民事诉讼法学 · 处分原则与证明责任分配（GB/T 8203040）

> **这支负责的问题**：平等主体的纠纷进入国家法院后怎么走——
> 谁启动、谁举证、判决效力框到哪。一句钉住：**民事诉讼把
> "发现真实"从法官的任务改写成当事人的博弈规则——法院
> 居中不告不理，谁主张，谁举证。**

## 诞生

罗马法定诉讼→程式诉讼（大法官以"程式"划定可判事项，
当事人合意选择轨道）→ 中世纪教会法纠问程序（法院主动
查究的制度反例）→ **1806 法国民事诉讼法典**：大革命后
当事人主义法典化，"不告不理"成为体系原则 → 1877 德国
民事诉讼法典 + **1900 罗森贝克《证明责任论》规范说**
（证明责任分配的大陆法系通说地基）→ 20 世纪各国修法在
"当事人主义/职权主义"光谱上各自定位。因的问题：私权
纠纷里国家不能替当事人做主，但必须设计规则让当事人
自己把事实与请求摆上法庭。

## 核心问题

| 问题 | 状态 |
|------|------|
| 处分原则（起诉/撤诉/上诉范围由当事人划定） | ✅ 通说成熟：处分权框定了法院权力的外廓 |
| 辩论主义 vs 职权探知主义 | ✅ 类型学成熟（家事等身份诉讼引入职权探知为例外） |
| 证明责任分配 | ✅ 规范说通说：各方对自己有利的规范要件负证明责任（家族 02 章 2.4 的展开面） |
| 既判力（判决效力的客观与时间范围） | ✅ 通说框架成熟（争点效等扩张形态比较法呈现） |
| 大量小额损害的集体救济结构 | ❌ 悬而未决（代表人诉讼/公益诉讼的当事人构造各国分岔） |

## 这支最美的一个事实

"谁主张谁举证"只有六个字，却完成了一次制度转译：**把
真理发现变成博弈规则——法院不负责找真相，双方当事人
为了赢而竞相呈上真相，真相成了对抗的副产品**。罗马人
两千年前就懂：让利益驱动的人去挖事实，比让居中的官吏
去查事实，更接近真相。
