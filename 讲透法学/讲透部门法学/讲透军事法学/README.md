# 讲透军事法学 · 平时治军与战时护人的两副面孔（GB/T 8203070）

> **这支负责的问题**：武装力量如何按法律组织与行动——
> 军事司法、军事行政、战争法三大块的制度结构。一句钉住：
> **军事法有双重面孔：平时给军队上纪律的笼头，战时给
> 暴力上人道的笼头。**

## 诞生

古典时期战争受宗教与习惯约束（休战与使节不可侵犯的
观念）→ **1625 格劳秀斯《战争与和平法》**：jus in bello
（交战规则）系统化 → 1864→1949 日内瓦公约体系与
1899/1907 海牙公约（国际人道法两大支柱：受难者保护与
作战手段限制）→ **1945-46 纽伦堡与东京审判**（制度史
意义：个人战争刑事责任确立，"服从命令"被限定为不
免责原则）→ 1977 附加议定书（保护规则扩容）→ 各国
军事司法与军事行政体系比较定型。因的问题：军队的
效率逻辑（命令-服从）与法律的正当性逻辑（规则-审查）
天然紧张——军事法整门学科都施工在这条断层线上。

| 自主武器系统的作战规则定性 | ❌ 悬而未决（区分原则能否由算法执行——家族 01 章方向一的风险分级切面） |

## 这支最美的一个事实

纽伦堡审判把"我只是执行命令"从免责事由改写为定罪
考量——**纪律文明与法律文明的分界线，画在"明显违法
的命令"上**：服从不能赎买良知能识别的暴行。这条原则
此后进入各国军事刑法，成为军事法两副面孔的接缝。
