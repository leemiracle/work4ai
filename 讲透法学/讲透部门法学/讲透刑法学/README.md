# 讲透刑法学 · 犯罪与刑罚的科学（GB/T 8203055）

> **这支负责的问题**：国家最重的强制权（刑罚）何时可以发动。
> 一句钉住：**刑法学是刑罚权的"刀鞘之学"——罪刑法定是刀鞘
> 总纲：法无明文规定不为罪、不处罚（nullum crimen sine lege）；
> 最严厉的法因此最讲克制（谦抑性）。**
> 本支按通说写原理与制度结构，示例一律用抽象数字。

## 诞生

血亲复仇→赎罪金→同态复仇的成文化（《汉谟拉比法典》以眼还眼
的条款，把复仇限制在"等价"内）→ 中世纪刑罚擅断 →
**1764 贝卡里亚《论犯罪与刑罚》**：罪刑法定、罪刑均衡、
刑罚功利三命题，现代刑法学的出生证 → 费尔巴哈（1801）给出
罪刑法定拉丁公式与心理强制说 → 1810/1871 法德刑法典化 →
1880s 古典学派（行为）vs 近代学派（行为人：龙勃罗梭、
李斯特"目的刑罚"）大论战 → 三阶层体系（贝林-李斯特传统）
与四要件体系并立至今。因的问题：刑罚的正当性——
国家凭什么惩罚，惩罚到哪里为止。

## 核心问题

| 问题 | 状态 |
|------|------|
| 罪刑法定原则的确立 | ✅ 1764 理论 → 1810 法典化 → 各国宪法化 |
| 三阶层 vs 四要件 | ✅ 两大体系并立（家族 03 章 3.1 对读：差异浮现在边界案件） |
| 数罪并罚的三轨结构 | ✅ 通说成熟（吸收/限制加重/并科——家族实验①的可计算面） |
| 罪责与期待可能性 | ✅ 通说纳入有责性阶层（超法规阻却事由的边界仍有讨论） |
| 无罪责能力系统的归责（AI 时代） | ❌ 悬而未决（单位犯罪之外的新主体难题） |

## 这支最美的一个事实

通说把刑法定位为**最后手段（ultima ratio）**：凡民事的、
行政的手段足以保护的，就不得动用刑罚——**握有最重强制权的
部门法，给自己立的第一条规则是"能不出手就不出手"**。
刀越锋利，刀鞘越厚。

## 假设与依赖

- 罪责假设：只有能归责于自由意志的行为才可罚（决定论挑战
  是法哲学的常驻课题，通说以"可归责性"操作化处理）
- 结构依赖刑事诉讼法学（程序缰绳）与司法鉴定学（事实供给）；
  军事领域的特别刑法见[讲透军事法学](../讲透军事法学/)
