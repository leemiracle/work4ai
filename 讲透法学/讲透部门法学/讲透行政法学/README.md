# 讲透行政法学 · 行政权戴上笼头（GB/T 8203015）

> **这支负责的问题**：国家行政权与公民之间的隶属关系如何被
> 法律驯化——权力怎么来、怎么动、错了怎么救。一句钉住：
> **行政法是"戴着笼头的行政"之学——迈耶断语：宪法设定政治
> 框架，行政法才决定人民的日常生活，"宪法消逝，
> 行政法长存"。**

## 诞生

法国大革命后参事院（1799）开启行政审判传统（行政争议由行政
系统自审的双轨制起点）→ 德意志"警察国→法治国"转型 →
**奥托·迈耶《德国行政法》（1886-1895）**：提炼"行政行为"
（Verwaltungsakt）概念，行政法学脱离宪法学成为独立学科 →
20 世纪行政国家扩张，行政法从"秩序法"长成"给付与规制法"。
因的问题：工业化让行政权以前所未有的规模介入生活，
传统私法与组织法都管不住这支膨胀的权力。

## 核心问题

| 问题 | 状态 |
|------|------|
| 依法行政两原则的结构（法律优先/法律保留） | ✅ 通说成熟：不得抵触法律 + 干预基本权利须有法律授权 |
| 行政行为理论（行政法学教义的"原子"） | ✅ 迈耶奠基，效果存续/撤销/无效的类型学成熟 |
| 行政裁量及其控制 | ✅ 通说框架成熟（要件/效果裁量；不确定性法律概念） |
| 特别权力关系理论的兴衰 | ✅ 制度史完成：20 世纪中后期各国相继将其限缩，内部关系也须法律化 |
| 算法行政的法律定性（自动化决定=行政行为还是辅助？） | ❌ 悬而未决（家族 01 章方向一战场） |

## 这支最美的一个事实

迈耶那句常被误读为贬低宪法的名言，本意恰是敬意：**框架性的
宪法会随政治起落改写，而管着水电气、执照与罚款的行政法
才是法治的日常骨架**——宪法的承诺兑现多少，
要看行政法每天怎么做。

## 假设与依赖

- 可授权性假设：立法者能把目的翻译给行政（授权明确性），
  代价是"空白授权"的灰色地带
- 概念依赖民法学的法律行为理论（行政行为是其公法变体）；
  程序救济依赖
