# 讲透婚姻法学 · 身份关系的法（GB/T 8203035）

> **这支负责的问题**：婚姻、家庭、亲属、继承——法律如何
> 组织"最私密的关系"。一句钉住：**婚姻法学两百年的主线只有
> 一条：把身份的捆绑拆成合意的自由，再发现身份拆不掉——
> 结婚像合同，离婚像合同，唯独孩子不是。**

## 诞生

罗马法：家父权下的有夫权婚姻（cum manu）向后期的**无夫权
婚姻**（sine manu）演变——妻子保有人格与财产，两千年前的
"去身份捆绑" → 中世纪教会法将婚姻圣事化，同时贡献
**合意主义**（婚姻因双方同意而成立）→ 1804 法国民法典把
婚姻规定为民事制度（世俗化）→ 19-20 世纪婚姻自由与离婚
自由原则确立；中国 1950 年婚姻法（婚姻自由原则的立法化，
学科史实中性记述）。因的问题：家庭既是最古老的治理单元，
又是个人自由的最后边疆——法在"组织"与"自由"之间画线。

## 核心问题

| 问题 | 状态 |
|------|------|
| 婚姻成立要件（合意+形式） | ✅ 通说成熟（合意主义与形式主义的平衡） |
| 夫妻财产制类型学 | ✅ 共同制/分别制/混合制的比较框架成熟 |
| 离婚制度的演变 | ✅ 过错主义→破裂主义（通说叙事：从"找罪人"到"认现实"），救济与经济后果配置仍有比较差异 |
| 亲子关系（推定与否认） | ✅ 通说框架成熟；技术（DNA）对推定制度的冲击已制度化为否认之诉 |
| 新型家庭形态与既有范畴的适配 | ❌ 悬而未决（各国立法进程分岔，通说以比较法呈现） |

## 这支最美的一个事实

现代婚姻法是一件合金：**罗马的财产分离（无夫权婚姻）+
教会的合意主义（两愿成立）**——一边是两千年前的世俗装置，
一边是中世纪的教会遗产，世俗化时代把它们焊在了一起，
至今仍是各国婚姻法的共同底版。

## 假设与依赖

- 身份行为与财产行为二分假设：身份关系"不可任意"（不能
  预约、不能附条件），财产关系"全凭意思"——分界处的
  夫妻财产协议是二分压力的常驻测试点
- 依赖[讲透民法学](../讲透民法学/)的财产法工具；
  继承制度是其与财产法的合流处
