# 讲透外国法律思想史 · 从苏格拉底之死到哈特:自然法与实证主义(前 399-今)

> **定位句**:这支负责讲清域外法律观念的变迁——自然法的兴衰、历史法学派、
> 法律实证主义与它的批评者;核心战场只有一个:**法律与道德是什么关系。**
> GB/T 13745:82020 法律史学 · 三级「外国法律思想史」。家族:[讲透法律史学](../README.md)。

## 诞生

原生问题在雅典:**公民该服从不义的判决吗?**——前 399 年苏格拉底被判死刑,
拒越狱而死(柏拉图《克里同》)——"恶法亦法/恶法非法"两千年之争的原点。
作为学科谱系:格劳秀斯《战争与和平法》(1625)立近代自然法;萨维尼
(1814)以历史主义对抗抽象理性;奥斯丁(1832)立"法律即主权者命令"
的实证主义;哈特《法律的概念》(1961)以"承认规则"重建——链条成科。

## 核心问题

已解决:
- 自然法→实证主义的接力:阿奎那(13 世纪,永恒法-自然法-人法)→
  格劳秀斯(1625)→奥斯丁(1832)→凯尔森(1934,纯粹法学)→哈特(1961)
- 历史法学派的方法遗产:法是"民族精神"的产物(1814)——比较法史的直接祖先
- 战后回摆:拉德布鲁赫公式(1946,"极端不义即非法")回应实证主义在
  纳粹司法后的信誉危机;哈特-富勒论战(1958)把问题定形

未解决:
- **法律与道德是否必然关联**(哈特-富勒之争未了,派生至今)
- 全球化下自然法话语的复兴边界(人权话语是不是"新自然法")

## ✨ 这支最美的一个事实

苏格拉底拒绝越狱:他认为自己受到的是不义的判决,但城邦的"法律"
与他有约——**被不义判决,却守约而死,一个动作同时点燃了两个对立学派**。

## 假设与依赖

- 依赖译本与原文对读(概念跨语言漂移是常态:Recht/right/法 各有暗层);
  "学派接力即思想史"须打折——同代总有竞争学说,谱系是事后整理
- 警惕用中国范畴直译西学("礼"译自然法之类)——双向时代错置

## 教材锚

- 柏拉图《克里同》《法律篇》(一手);阿奎那《神学大全》论法律诸题
- 格劳秀斯《战争与和平法》;奥斯丁《法理学的范围》;哈特《法律的概念》
- 萨维尼《论立法与法学的当代使命》(1814);凯尔森《纯粹法学》
