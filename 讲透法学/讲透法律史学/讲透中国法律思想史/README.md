# 讲透中国法律思想史 · 人们认为法该是什么:礼法之争两千年(前 536-今)

> **定位句**:这支负责讲清中国两千五百年法律观念的论争史——法家儒家论争、
> 礼法合流、德刑之辨、以及近代法观念入关时与旧观念的碰撞。
> GB/T 13745:82020 法律史学 · 三级「中国法律思想史」。家族:[讲透法律史学](../README.md)。

## 诞生

原生问题:**法该不该公开?法与道德谁高?**——前 536 子产铸刑书引发
第一场论战(叔向反对、孔子评"民在鼎矣")。作为**现代学科**则诞生于
20 世纪:梁启超《中国法理学发达史论》(1906)首倡清理,
**杨鸿烈《中国法律思想史》(1936)**以"问题-流派-人物"体系奠基
——中国古代无此学科名(律学附于经学),它本身就是新学制与旧思想的合产物。

## 核心问题

已解决:
- 先秦论争骨架:公布成文法之争(前 536)/法家"缘法而治"与儒家"为国以礼"(战国)
- 合流路线:德主刑辅(汉,董仲舒约前 134)→"八议"入律(229)→
  "准五服以制罪"入律(268)→"一准乎礼"定型(653,《唐律疏议》)
- 清末礼法之争的议题清单:1910 前后礼教派与法理派就新刑律中
  "千名犯义""存留养亲"等条款存废的论争(学科史实,中性呈现)

未解决:
- **中华法系的思想资源可否再生?**(20 世纪初以来学界反复讨论——史学只供"是什么")
- 传统法律观念在现代法治话语中的连续性与断裂点在哪里(术语翻译史是切入口)

## ✨ 这支最美的一个事实

汉代董仲舒"春秋决狱"——法官以《春秋》经义断案、"原心定罪":
**在这个时代,儒家经典行使着最高判例法的功能,经典高于法条。**

## 假设与依赖

- 依赖文献目录学(论争文本大多经后世编次,辨伪是地基);传世文献以精英
  论说为主,民间法意识基本沉默(结构性缺席)
- 两个对称的坑:拔高("什么都早于西方")与贬低("礼法不分")——都是史学错误

## 教材锚

- 杨鸿烈《中国法律思想史》(1936,奠基);张国华《中国法律思想史》(通论正典)
- 《论语》《商君书》《韩非子》原典相关篇(一手);瞿同祖《中国法律与中国社会》
