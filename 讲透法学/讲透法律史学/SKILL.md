# 法律史学思维技能卡

## 1. 何时用此分支(触发词)

遇到以下特征的问题/困惑,切到法律史眼光:

- 「这条规则/这部法典**怎么来的**?为什么这么设计?」(每条"理所当然"都有生日)
- **礼法之争/德刑之辨**:儒家法家论争、引经决狱、德主刑辅——观念如何变成条文
- **法典化**:为什么拿破仑要自己法典、萨维尼为什么反对、清末为什么十年修律
- **移植与本土化**:同抄一部法典,为什么长出不同果实(日本继受/清末修律对照组)
- **法系比较**:中华法系/大陆法系/普通法系的骨架差异(律疏 vs 判例 vs 令状)
- **法律文本年代学**:条文存续(存/改/废/增)、术语首见年份、版本谱系
- 「学部门法卡在'为什么这么规定'」——历史语境是最好的直觉锚

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **双层眼** | 任何规则先分两层:宣告的规则(law in books)vs 运行的规则(law in action)——缝即研究对象 |
| **语境主义** | 回到当时的立法技术再评价——用现代法典标准判《唐律》是时代错置 |
| **路径依赖** | 五服调制量刑八百年、律例双层至清亡——"必然性"多为历史追认 |
| **证据分级** | T1 条文/档案 → T2 正史 → T3 通说 → T4 推断 → T5 传说 → T6 反事实;动词即类型签名 |
| **幸存者警觉** | 判例档案的幸存不代表判决的分布;纸面完整≠运行完整 |
| **对齐眼** | 移植=条文×机构×语言三条边对齐,缺一边都是半张照片 |

## 3. 工具箱

- **条文定位**:《唐律》卷-篇-条编号;罗马法 D.x.x.x(Mommsen 本)——先拿编号再下断言
- **编年对照**:世纪×法系切片(本家族 `experiments/00_dual_code_timeline.py` 为最小实现)
- **律疏对读**:律文(规定)×疏议(解释)×异代对应条文(沿革)三栏
- **量刑函数**:亲等×方向×行为→刑等的查表结构(五服制罪的结构化)
- **术语考古**:关键词何时被征用(权利 1864/主权)——观念入关的语言学证据
- **纪年换算**:年号-公元(光绪二十八年=1902)、颁行≠生效≠通行三分离

## 4. 常见误区与禁忌

- ❌ **时代错置**:把"民法""权利"直接回套古代实践——先查术语翻译史
- ❌ **纸面即运行**:法典条文当执行记录读——纸面≠行动(庞德之辨)
- ❌ **把后世评论当立法自述**:四库馆臣"一准乎礼"是 T3 证据,不是唐代立法文件
- ❌ 编造对话/判决细节——文学化≠虚构;传说显式标注(皋陶造律)
- ❌ **反事实当结论**:「若修律迟二十年」只能标记后使用
- ❌ 忽视选样:任何"大事记"密度度量的是正史关注度,不是法制产出
- ❌ 敏感红线:中国法制史(法家儒家论争/清末修律/近代法典化)按学科史实**中性呈现,不评价不引申**
