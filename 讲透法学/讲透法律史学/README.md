## 〇、家族定位与成员

- 学科身份:法学的时间维——理论法学问"法是什么",部门法学问"这条怎么判",
  本家族问"**法怎么变成这样的**":每条"理所当然"的法条都有生日与压力来源
- 与历史学宇宙的分工:史学方法(证据分级/叙事纪律/文献考据)上游在
  [讲透历史学/讲透史学理论](../../讲透历史学/讲透史学理论/);
  本家族拿法学材料用史学刀法——材料是法,方法是史
- 横断挂靠:[讲透科学技术史](../../讲透科学技术史/)——法律文献学与数字人文
  横断面互链(该宇宙聚合表已列本家族,双向对齐)
- 思想史侧:[讲透哲学](../../讲透哲学/)——自然法/正义论的观念谱系上游

## 一、三支家族树

```
讲透法律史学/
├── 讲透中国法律思想史/   人们认为法该是什么:礼法之争两千年(前536-今)
├── 讲透外国法律思想史/   自然法与实证主义:苏格拉底之死到哈特(前399-今)
└── 讲透法律制度史/       法实际怎么运转:法典·司法·诉讼的解剖(前451-今)
```

> 归属注记:GB/T 82020 三级三条全部落子。思想史两支按文明分家(观念长在语言里,
> 不可跨文明直译);制度史一支中西合璧(法典与司法组织可比性强,比较法史的
> 主战场)——这是学科建制的实际形状,也是本家族树的形状。

**问题分流速查**(拿到一个法律史问题,先分诊):

- 「某观念(礼治/自然法/罪刑法定)怎么来的」→ 思想史两支
- 「某制度(五刑/陪审/律例)怎么运转的」→ 制度史支
- 「法条/判决/学说文本本身怎么读」→ 家族 02 章(语言层)
- 「年表/条文/人物怎么变成数据」→ 家族 03/04 章(结构层)

## 三·五、双法系编年一览(实验数据的人类可读版)

| 断代 | 中华法系 | 罗马法系 |
|------|---------|---------|
| 起点 | 前 536 子产铸刑书 | 前 451 十二表法 |
| 定型 | 653《唐律疏议》律疏同文 | 533《国法大全》编成 |
| 危机/断层 | 1902-1911 清末修律解体 | 533-1070 休眠期(《学说汇纂》失传) |
| 复兴/扩散 | 701《大宝律令》东传日本 | 约 1070 重见→波伦亚复兴 |
| 近代法典化 | 1910《现行刑律》/1911《大清刑律》 | 1804 法国民法典/1900 德国民法典 |

## 四、教材锚

- 《唐律疏议》点校本(中华法系母法一手文献——本家族的"原本")
- 瞿同祖《中国法律与中国社会》——礼与法的运行实态(表达与实践的经典)
- 梅因《古代法》(1861)——"从身份到契约"原典,法律史学的独立宣言
- 萨维尼《论立法与法学的当代使命》(1814)——历史法学派宣言
- Pollock & Maitland《The History of English Law》(1895)——制度史写作范本
- 张晋藩主编《中国法制通史》(多卷本正典)
