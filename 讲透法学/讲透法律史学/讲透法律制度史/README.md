# 讲透法律制度史 · 法实际怎么运转:法典·司法·诉讼的解剖(前 451-今)

> **定位句**:这支负责讲清法**实际怎么运转**——法典怎么编、法院怎么设、
> 案件怎么办;中西合璧,比较法史的主战场。
> GB/T 13745:82020 法律史学 · 三级「法律制度史」。家族:[讲透法律史学](../README.md)。

## 诞生

原生问题:**为什么中华法系延续两千年,又在清末修律(1902-1911)间解体?**
中国一侧:沈家本《历代刑法考》(约 1912 成书)考订历代刑制;**瞿同祖
《中国法律与中国社会》(1947 初版)**立"纸面/运行"双层范式。
西方一侧:**Pollock & Maitland《英国法律史》(1895)**示范档案级写法;梅因《古代法》(1861)先给比较纲领。

## 核心问题

已解决:
- 中华法系制度骨架:律-令-格-式-例的形式谱系;《唐律疏议》(653)12 篇 502 条
- 量刑的社会结构:"准五服以制罪"(268 入律,唐律成熟)——刑罚随亲等调制
- 东亚扩散:《大宝律令》(701)继受唐律;普通法:1066 后巡回审判统一习惯,
  令状决定救济("救济先于权利")

未解决:
- **法律移植与本土化**:同抄一部法典,为何长出不同果实(条文×机构×语言三边对齐)
- **中华法系可再生吗**(史学只供"是什么");纸面与运行的缝如何量化

## ✨ 这支最美的一个事实

《唐律》的量刑是亲属关系的函数:同一殴打行为,对凡人与对兄姊刑差数等,
"准五服以制罪"把一张丧服图编译成刑罚的定义域。

## 假设与依赖

- 依赖法典文本(最规范)+司法档案(最稀缺)双轨;"法典代表制度"须打折
  (州县自理与民间调解大量不进文本,纸面≠行动);比较前提是功能对齐
