## 三、特征速查(问题→家族)

- 法是什么/为什么守法/法该怎样解释 → 理论法学(法理学·法哲学)
- 某法从哪来/中西法制如何演变 → 法律史学
- 宪法/行政/民法/刑法/诉讼/知产等具体争讼 → 部门法学(十八支)
- 跨国/跨境规则冲突 → 国际法学(公法·私法·经济法·环境法)

## 四、治理

- 波次:波2(4 家族)生产;支宪法随家族落盘(GB/T 三级 35 支逐条:理论法学 8+法律史学 3+部门法学 18+国际法学 6)
- 待办:法律心理学待心理学宇宙;兜底类 82099 不设系列,新兴方向按近亲归属
- 敏感纪律:中国法制史/法律思想史按学科史实中性学术呈现
