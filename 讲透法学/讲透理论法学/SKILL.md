# 理论法学思维技能(GB/T 82010 · 家族抽象层)

> 部门法学管"这条法怎么用";本技能管**元层**:法凭什么成立、
> 如何被制造、被推理、被传承。五章正文见
> [家族 README](README.md) 章目表。

## ① 何时用此分支(问题特征触发词)

1. "法是什么/法律的定义/法与道德什么关系"——概念与本质之争
2. "恶法是不是法/要不要遵守不义的法"——哈特-富勒轴
3. "为什么守法/守法的义务从哪来"——政治义务问题
4. "法条该怎么解释/文义-目的-体系-历史"——解释方法论
5. 大陆法系 vs 普通法系、法律移植为什么失败——比较法学
6. "书本上的法 vs 行动中的法"、守法行为的经验成因——法社会学
7. 立法技术:法条三要素、但书、法典结构、立法后评估——立法学
8. 三段论/道义逻辑/但书的例外结构/先例类比——法律逻辑学
9. 案例教学法/IRAC/法律思维可不可教——法律教育学
10. 法条一致性检查、规则即代码、法律本体、LLM 法律推理评测
    ——计算法学(AI 与法)

## ② 核心思维模式

- **元层眼**:用法的人看条款,审法的人看地基——
  听到任何规则先问效力来源与位阶,再问内容
- **道义分诊眼**:任何法律陈述先分"应当/是";义务/许可/禁止/
  授权四种规范力不同(02 章方言表)
- **原子眼**:"权利/义务"先拆 Hohfeld 八格——
  大半权利争论是词没拆开(03 章矩阵)
- **情形相对眼**:规则集"一致"只是"尚未在此情形下冲突"——
  冲突要连同事实一起判定(04 章实验)
- **工艺眼**:劣法(含糊/矛盾/不可执行)是工艺问题不是道德问题
  ——先查富勒八原则再谈价值(00 章✨②)
- **语境眼**:同一法条换个社会会怎样活?比较与经验是规范的双脚

## ③ 工具箱(何时用什么)

| 工具 | 何时用 |
|------|--------|
| 命令说/规范说/规则说/整全法 | 定位一场争论在"法是什么"编年史的哪一格 |
| 枪手情境 | 快速击破"法律=命令+制裁"类直觉 |
| 承认规则(效力链追溯) | 问"这条法凭什么有效"时 |
| 拉德布鲁赫公式/分离命题 | 处理恶法与非常态法秩序的边界案 |
| Hohfeld 矩阵 | 权利/义务话语的精确化与冲突排查 |
| 解释四要素(文义/体系/历史/目的) | 组织一场条文解释的论辩 |
| 规则 vs 原则(全有全无 vs 重量) | 判断冲突时"失效"还是"让位" |
| 但书结构(一般规则+例外+优先级) | 读任何带"除外"的条文;形式化第一步 |
| IRAC | 组织法律写作/审查 LLM 法律输出 |
| 命题化+可满足性检查 | 法条矛盾/漏洞的机检(家族实验) |
| 富勒八原则 | 审计任何规则文本(法典/校规/平台协议) |

## ④ 常见误区与禁忌

- **把"是法"与"好法"混为一谈**:实证主义分离命题是分析工具
  不是政治立场——先分开,再讨论该不该服从
- **把法学当纯文本学科**:经验侧(法社会学)与形式侧
  (法律逻辑/计算法学)都是正规军
- **把类比当演绎的劣化版**:Levi 的教训——规则本身从类比中
  产出;演绎负责正当化,类比负责发现,是流水线不是对手
- **道义算子照抄真值逻辑**:罗斯悖论在前(应当寄信≠应当寄信或烧信)
- **把"清晰"当修辞而非工艺**:含糊的法条是失败产品——
  可机读检查能抓住其中一部分(一致性/漏洞)
- **形式化时假装没有做解释**:每次命题化都埋了语义决策,
  必须显性记录(04 章裂缝①)
- **用代码预设回答正当性问题**:为何守法/恶法边界不可编译,
  预设只能写在需求文档里
