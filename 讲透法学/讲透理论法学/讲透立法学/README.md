# 讲透立法学 · 法的工艺学(GB/T 82010 三级:立法学)

> **这支负责的问题**:法不是被发现的,是**被制造的**——
> 怎么把社会目标铸成可执行、可遵守、不自相矛盾的规范文本。
> 一句钉住:**法哲学问"该不该",立法学问"造不造得好"——
> 一部法典是工程品,有公差,有废品率。**

## 诞生

工艺传统古老(查士丁尼国法大全、拿破仑法典的编纂技术),
学科化于二十世纪:富勒 1964《法律的道德性》以"雷克斯王"寓言
给出合法性八原则(一般性/颁布/不溯及/清晰/不矛盾/可遵循/稳定/
官方一致)——立法工艺的宪法。中国线:与改革开放以来的立法需求
同步成长(周旺生等推动学科化),2000 年《立法法》颁行为立法制度
提供基本框架(2015/2023 年修正)。

## 这支最美的一个事实

**雷克斯王的八次失败**:想立好法的国王败于八种工艺缺陷——
太详尽、公布不了、溯及既往、自相矛盾、要求不可能之事、朝令夕改、
执行与文本两样……富勒用寓言证明:**合法性不是价值装饰,
是可核对的工艺标准表**(00 章✨②)。

## 假设与依赖

规范可构造假设(社会目标能铸成规范文本);位阶与权限框架
(立法权从宪法取得)。依赖法理学支供概念,法律逻辑学支供一致性
检查(家族实验即"不矛盾"原则的机检),法社会学支供实施反馈。
