# 讲透法哲学 · 法的本质之争(GB/T 82010 三级:法哲学)

> **这支负责的问题**:法与道德、正义、权威的关系——**恶法是不是法、
> 为什么该服从法律、正义能不能被定义**。一句钉住:
> **法理学管"法如何可能",法哲学管"法凭什么值得"——
> 所有效力问题的终点,都是一个价值问题。**

## 诞生

雅典的"自然 vs 约定"之争(前 5 世纪,《安提戈涅》与《克里同》
两个原型);经院自然法(阿奎那,永恒法/自然法/人法等级);
近代自然权利与世俗化(格劳秀斯 1625);康德法权哲学;
战后大爆发——拉德布鲁赫公式(1946)、哈特-富勒论战(1958-69)、
德沃金整全法(1986)把这场两千年的争论推成二十世纪法学的中心戏。

## 核心问题

| 问题 | 状态 |
|------|------|
| 恶法是否法 | ❌ 未决(拉德布鲁赫公式 vs 分离命题;告密者案两边自洽) |
| 正义可定义否 | ❌ 未决(罗尔斯 1971《正义论》是最大输入,论战未息) |
| 法律权威与政治义务 | ❌ 未决(同意论/公平游戏/自然义务各有反例) |
| 分离命题(法与道德概念上可分否) | 🔄 前线(实证主义内部精细化为排他/包容两支) |
| 法的概念中的道德(整全法) | 🔄 前线(德沃金之后,规范性之谜接棒) |

## 这支最美的一个事实

**拉德布鲁赫公式**:一个战前实证主义者在纳粹废墟上写下
"不可容忍"条款——实在法与正义矛盾到不能容忍时,让位于正义;
一个学者用自己一生的立场换来一条边界的划定(00 章 1.3)。

## 假设与依赖

哲学方法(思想实验/体系建构/概念分析);价值判断可论辩
(理性非独断)。依赖哲学宇宙的伦理学与政治哲学
(弱链:[../../../讲透哲学/](../../../讲透哲学/))。

## 教材锚

- 拉德布鲁赫《法哲学》及其 1946 论文《法律的不法与超法律的法》
- 富勒《法律的道德性》(1964)/德沃金《法律帝国》(1986)
- 罗尔斯《正义论》(1971,政治哲学对法学的最大输入)
