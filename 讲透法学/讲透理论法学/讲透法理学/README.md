# 讲透法理学 · 法的一般理论(GB/T 82010 三级:法理学)

> **这支负责的问题**:不问"这条法怎么用",问"**法这种东西如何可能**"
> ——权利、义务、效力、规则、体系,这些所有部门法共享的概念,在哪个
> 车间里造出来、怎么质检。一句钉住:**部门法理各自案上的"法",
> 法理学管"法"这个词本身的户口。**

## 诞生

奥斯丁 1832《法理学的范围》为"一般法理学"定界(以命令说切割
法学与道德哲学);哈特 1961《法律的概念》以规则说重建(初级规则+
次级规则,承认规则);其间经凯尔森规范等级(1934)与美国现实主义
(1930s)的两侧夹击。中国线:1980 年代《法学基础理论》定名,
1990 年代改称"法理学",伴随"权利本位"等学术讨论,沈宗灵、
张文显主编教材为代表(学科史实中性引证)。

## 核心问题

| 问题 | 状态 |
|------|------|
| 法的定义(命令/规范/规则/整全法) | ❌ 未决——百年竞争本身是学科引擎 |
| 权利义务的概念构造 | ✅ 已解(Hohfeld 1913 八原子矩阵) |
| 法体系的结构与存在条件 | ✅ 已解(哈特 1961:初级+次级规则) |
| 法的要素:规则/原则/概念 | ✅ 已解(德沃金 1967 后的共识框架) |
| 为何守法(义务论/公平游戏/自然义务) | ❌ 未决,各有致命反例 |

## 这支最美的一个事实

**枪手情境**:抢匪的命令满足"命令+制裁"全部要件,却没人认为
你有交钱的义务——一个思想实验,终结了一个百年理论(00 章铁律一)。

## 假设与依赖

规范性假设(法与强盗命令不同);可分析假设(概念可靠语言分析澄清)。
依赖法哲学支供价值轴、法社会学支供经验轴、比较法学支供跨法系素材。
