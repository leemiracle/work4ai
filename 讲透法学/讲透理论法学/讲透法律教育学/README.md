# 讲透法律教育学 · 法的传承工艺(GB/T 82010 三级:法律教育学)

> **这支负责的问题**:法体系的自我复制——**一个法体系的质量上限,
> 由它如何训练法律人决定**。一句钉住:**法写在纸上会腐烂,
> 长在人身上才活着;法律职业的再生产,是法的免疫系统和升级机制。**

## 诞生

兰代尔(Christopher Columbus Langdell)1870 年任哈佛法学院院长,
1871 年刊行《契约法案例选》,把**案例教学法**(case method)制度化
——他的宣言:法律是科学,判例是它的实验材料,法学院应该是实验室。
此后一百年演化出 IRAC(争点-规则-适用-结论)的训练格式与
临床法学教育(legal clinic)。中国线:1970 年代末法学教育恢复重建,
1990 年代规模化,案例教学与诊所教育渐次引入(学科史实中性呈现)。

## 这支最美的一个事实

**Langdell 的图书馆宣言**:他说法律是科学,"一切可用材料"
都在判例报告里;被嘲弄了一百年的"书本至上",在 2025 年
计算法学需要百万判例数据集时得到迟到的正名——
**判例第一次真的成了数据**(01 章方向二)。

## 假设与依赖

教育可传递专业性假设(判断力能经训练习得);认知科学的
迁移研究支援(类比训练迁移到新案)。依赖法理学支定
"教什么"(理论共识),法律逻辑学支供"怎么推"(IRAC 骨架)。
