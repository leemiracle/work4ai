# 讲透比较法学 · 把法放进语境(GB/T 82010 三级:比较法学)

> **这支负责的问题**:同一问题,不同社会给出不同答案——**差异本身
> 就是数据**。一句钉住:**不比较,你以为本地的安排是自然的;
> 一比较,它只是可能的之一。**

## 诞生

1900 年巴黎第一届国际比较法大会,朗贝尔与萨莱伊提出比较法纲领
(甚至梦想建构"立法的共同法");此后重心从" dream of unity"转向
方法自觉:茨威格特与克茨《比较法总论》确立**功能主义**——
"功能是比较的第三项"(比较的不是条文,是各法如何解决同一社会问题);
勒内·达维德《当代主要法律体系》给出流传最广的法系地图。

## 核心问题

| 问题 | 状态 |
|------|------|
| 法系分类(大陆/普通法/宗教法/混合法系) | ✅ 已解的地图(细节边界仍有论战) |
| 功能主义方法(功能等价) | ✅ 已解的方法论共识 |
| 法律移植为什么成功/失败 | 🔄 前线("器官排异"机制,个案积攒中) |
| 共同法/私法国际统一可能否 | ❌ 未决(欧洲统一私法尝试数十年受挫) |
| 比较法与一般法理学的互喂 | 🔄 前线(一般理论必须经得起跨法系检验) |

## 这支最美的一个事实

**法律移植的"器官排异"**:条文抄得走,法官的思考方式抄不走——
近代若干法典继受的历史里,抄成文法用了十几年,
养出与条文配套的法学方法与职业惯性用了大半个世纪。

## 假设与依赖

可比性假设(各法系对同一功能问题有可比较的解);功能等价的
翻译可行。依赖法理学支供概念框架,法社会学支供"法如何活"
的测量(移植成败的经验判定)。

## 教材锚

- 茨威格特 & 克茨《比较法总论》(功能主义方法圣经)
- 勒内·达维德《当代主要法律体系》(法系地图经典)
