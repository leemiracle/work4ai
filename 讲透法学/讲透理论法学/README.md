# 讲透理论法学 · 问"法是什么"的法学自我意识(GB/T 82010)

> **理论法学=法学的自我意识**:部门法学(82030)问"这条规则怎么适用于本案",
> 本家族问"**规则凭什么算规则**"。三分工:**法理学/法哲学管本质**(法是什么/
> 为何守法/恶法是否法),**比较法学/法社会学管语境**(法在别的社会里、
> 在现实中如何活),**立法学/法律逻辑学/法律教育学管工艺**(法怎么造、
> 怎么推、怎么教)。一句钉住:**所有部门法都在用"法"这个字,
> 只有这里追问这个字凭什么——用法的人看条款,审法的人看地基。**
>
> GB/T 13745:82010(二级学科,法学 820 之下;三级共 8 条:7 支实建+1 条归入声明)。
