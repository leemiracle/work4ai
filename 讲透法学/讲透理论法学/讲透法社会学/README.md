# 讲透法社会学 · 法在社会里如何活(GB/T 82010 三级:法社会学,GB/T 注与社会学互见)

> **这支负责的问题**:不问"法条说什么",问"**法条如何活在社会里**"
> ——纸面上的法与行动中的法是两部法。一句钉住:
> **立法者写"应当",法社会学数"实际"——落差本身就是研究对象。**

## 诞生

埃利希 1913《法社会学基本原理》:"法发展的重心不在立法、法学
或司法,而在社会本身"——**活法**(lebendes Recht)命题;
庞德 1910"书本中的法 vs 行动中的法";1930s 美国法律现实主义
把问题推向司法行为("上诉法院做什么才是法");战后经验方法
成熟,Tyler 1990《人们为什么守法》给出里程碑实证。

## 核心问题

| 问题 | 状态 |
|------|------|
| 法效与法意识如何测量 | ✅ 方法论已解(调查/统计/民族志) |
| 人们为什么守法(经验版) | ✅ 重大发现(Tyler 1990:程序正义>威慑,见下) |
| 法与社会结构如何互构 | 🔄 前线(分层/组织/网络视角各有积累) |
| 司法行为的经验画像 | 🔄 前线(法官决策的统计模型,AI 时代再升温) |
| "书本法-行动法"落差的一般理论 | ❌ 未决(落差随时空变化,无普适公式) |

## 这支最美的一个事实

**Tyler 的发现**:预测守法行为的最强变量不是怕惩罚,
而是**觉得程序被公正对待**——合法性是一种态度,不是一笔算计;
刑罚威慑模型的心理学地基因此被重估。

## 假设与依赖

可经验研究假设(描述不评价,与"应当"层分开);测量误差与
价值中立的持续反省。依赖社会学理论与方法——宇宙互链:
[讲透社会学](../../../讲透社会学/)(GB/T 8201040 双向互见)。
