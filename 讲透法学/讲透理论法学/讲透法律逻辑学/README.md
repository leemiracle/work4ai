# 讲透法律逻辑学 · 法怎么推(GB/T 82010 三级:法律逻辑学)

> **这支负责的问题**:法律推理的形式研究——**三段论的骨架、
> 道义算子、但书的例外结构、先例类比的机制**。一句钉住:
> **法学的血肉是价值,骨骼是逻辑;这支管骨骼——并专门管骨骼
> 长不到的地方。**

## 诞生

亚里士多德的实践推理(修辞学/论辩)是远祖;近代学科化三步:
Klug 1951《法律逻辑》把命题逻辑用于刑法构成要件;von Wright 1951
创立道义逻辑(应当 O/可以 P/禁止 F 有了算子);Toulmin 1958
《论证的使用》给出非形式论证图式(主张-根据-正当理由-支援-反驳)。
1990s 起 Prakken/Sartor 谱系把法律论辩形式化为可废止逻辑。

## 这支最美的一个事实

**罗斯悖论**(1944):"你应当寄这封信"竟能逻辑推出
"你应当寄这封信**或者烧了它**"——道义算子照抄真值逻辑的必然恶果。
它宣判:**规范推理不能照抄事实推理**——这支学科独立存在权的出生证。
