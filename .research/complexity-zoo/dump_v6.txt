###R | title: Recursive Languages | id: r | url: https://complexityzoo.net/Complexity_Zoo:R#r
The class of decision problems solvable by a Turing machine. Often identified with the class of 'effectively computable' functions (the <i>Church-Turing thesis</i>). Defined in [[zooref#tur36|[Tur36]]], [[zooref#chu41|[Chu41]]], and other seminal early papers. Equals [[#re|RE]] &#8745; [[Complexity Zoo:C#core|coRE]]. Strictly contains [[Complexity Zoo:P#pr|PR]], the primitive recursive functions (see [[zooref#kle71|[Kle71]]]).

###RBQP | title: Strict Quantum RP | id: rbqp | url: https://complexityzoo.net/Complexity_Zoo:R#rbqp
The class of problems in [[Complexity Zoo:N#np|NP]] whose witnesses are in [[Complexity Zoo:F#fbqp|FBQP]]. For example, the set of square-free numbers is in coRBQP using only the fact that [[Complexity_Garden#integer_factorization|factoring]] is in [[Complexity Zoo:F#fbqp|FBQP]]. (Even without a proof that the factors are prime, the factorization proves that there is a square divisor.) Contains [[#rp|RP]] and [[Complexity Zoo:Z#zbqp|ZBQP]], and is contained in [[Complexity Zoo:B#bqp|BQP]] and [[#rqp|RQP]]. Defined here to clarify [[Complexity Zoo:E#eqp|EQP]]; see also [[Complexity Zoo:Z#zbqp|ZBQP]].

###RE | title: Recursively Enumerable Languages | id: re | url: https://complexityzoo.net/Complexity_Zoo:R#re
The class of decision problems for which a 'yes' answer can be verified by a Turing machine in a finite amount of time. (If the answer is 'no,' on the other hand, the machine might never halt.) Equivalently, the class of decision problems for which a Turing machine can list all the 'yes' instances, one by one (this is what 'enumerable' means). A problem C is complete for RE if (1) C is in RE and (2) any problem in RE can be reduced to C by a Turing machine. Actually there are two types of reduction: M-reductions (for <i>many-one</i>), in which a single instance of the original problem is mapped to an instance of C, and T-reductions (for <i>Turing</i>), in which an algorithm for the original  ……[中略]…… |[Muc56]]]. This is the resolution of <i>Post's problem</i> [[zooref#pos44|[Pos44]]]. Indeed, RE contains infinitely many nonequivalent 'T-degrees.' (A T-degree is a class of problems, all of which can be T-reduced to one another.) The structure of the T-degrees has been studied in more detail than you can possibly imagine [[zooref#sho99|[Sho99]]].

###REG | title: Regular Languages | id: reg | url: https://complexityzoo.net/Complexity_Zoo:R#reg
The class of decision problems solvable by deterministic finite automata (DFAs). Equals the class solvable by nondeterministic finite automata (NDFAs). Equals [[Complexity Zoo:D#dspace|DSPACE]](O(1)) [[zooref#she59|[She59]]], which equals [[Complexity Zoo:D#dspace|DSPACE]](o(log log n)) [[zooref#hls65|[HLS65]]]. Includes, i.e., "Is the parity of the input odd?," but not "Are the majority of bits in the input 1's?" This is sometimes expressed as "finite automata can't count." Contained in [[Complexity Zoo:N#nc1|NC<sup>1</sup>]]. See e.g. [[zooref#koz97|[Koz97]]], [[zooref#gur89|[Gur89]]] for basic results on regular languages.

###RevSPACE(f(n)) | title: Reversible f(n)-Space | id: revspace | url: https://complexityzoo.net/Complexity_Zoo:R#revspace
The class of decision problems solvable in space O(f(n)) by a reversible Turing machine (a deterministic Turing machine for which every configuration has at most one immediate predecessor). Was shown to equal [[Complexity Zoo:D#dspace|DSPACE]](f(n)) [[zooref#lmt97|[LMT97]]].

###RG | title: Refereed Games | id: rg | url: https://complexityzoo.net/Complexity_Zoo:R#rg
The class of problems solvable by a probabilistic polynomial-time verifier who can exchange a polynomial number of messages with two competing, computationally-unbounded provers -- one trying to convince the verifier that the answer is "yes," the other that the answer is "no." Note that the verifier can hide information from the provers. Public-coin RG amounts to {{zcls|s|saptime}}, which equals [[Complexity Zoo:P#pspace|PSPACE]] [[zooref#pap83|[Pap83]]]. RG is in [[Complexity Zoo:E#exp|EXP]] relative to any oracle [[zooref#km92|[KM92]]]; they are equal, unrelativized [[zooref#fk97b|[FK97b]]]. See also [[Complexity Zoo:P#pcd|PCD]], [[Complexity Zoo:G#gpcd|GPCD]].

###RG(1) | title: One-turn Refereed Games | id: rg1 | url: https://complexityzoo.net/Complexity_Zoo:R#rg1
The class of problems for which there exists a BPP machine M such that, on input x: <ol> <li>If the answer is 'yes,' then there exists a distribution Y such that for all distributions Z, M(x,Y,Z) accepts with probability at least 2/3.</li> <li>If the answer is 'no,' then there exists a distribution Z such that for all distributions Y, M(x,Y,Z) rejects with probability at least 2/3.</li> </ol> In other words, it's the same as [[Complexity Zoo:R#rgk|RG(<i>k</i>)]] for <math>k = 1</math>, the class of problems that admit interactive proofs with competing provers in which there's no communication from the verifier back to the provers. RG(1) trivially contains [[Complexity Zoo:S#s2p|S<sub>2</sub>P]]. Indeed, RG(1) can be viewed as a randomized version of [[Complexity Zoo:S#s2p|S<sub>2</sub>P]]. RG(1) is trivially contained in [[Complexity Zoo:R#rg2|RG(2)]] (and hence [[Complexity Zoo:P#pspace|PSPACE]]).

###RG(2) | title: Two-turn (one-round) Refereed Games | id: rg2 | url: https://complexityzoo.net/Complexity_Zoo:R#rg2
Same as [[#rg|RG]], except that now the verifier can exchange only two messages with each prover. Messages are exchanged in parallel, so the verifier cannot process the answer from one prover before preparing the question for the other. See also [[Complexity Zoo:R#rgk|RG(<i>k</i>)]]. RG(2) is contained in [[Complexity Zoo:P#pspace|PSPACE]], and they are equal, unrelativized [[zooref#fk97b|[FK97b]]].

###RG(k) | title: k-turn Refereed Games | id: rgk | url: https://complexityzoo.net/Complexity_Zoo:R#rgk
Same as [[#rg|RG]], except that now the verifier exchanges exactly <i>k</i> messages with each prover where <i>k</i> is a polynomial-bounded function of the input length. Messages are exchanged in parallel. By definition, RG(poly) = [[Complexity Zoo:R#rg|RG]]. See also [[Complexity Zoo:R#rg1|RG(1)]] and [[Complexity Zoo:R#rg2|RG(2)]]. Other than trivial bounds, very little is known of RG(k) for intermediate values of <i>k</i>. For example, does RG(<i>k</i>) = [[Complexity Zoo:P#pspace|PSPACE]] for each constant <math>k\geq 2</math>?

###R_HL | title: Randomized Halting Logarithmic-Space | id: rhl | url: https://complexityzoo.net/Complexity_Zoo:R#rhl
Has the same relation to [[Complexity Zoo:L#l|L]] as [[#rp|RP]] does to [[Complexity Zoo:P#p|P]]. The randomized machine must halt for every input <i>and</i> every setting of the random tape. Contains undirected reachability (is there a path from vertex u to vertex v in an undirected graph?) [[zooref#akl79|[AKL+79]]]. Contained in [[#rl|RL]].

###R_HSPACE(f(n)) | title: One-Sided Error Halting Probabilistic f(n)-Space | id: rhspace | url: https://complexityzoo.net/Complexity_Zoo:R#rhspace
Has the same relation to [[Complexity Zoo:B#bphspace|BP<sub>H</sub>SPACE(f(n))]] as [[#rp|RP]] does to [[Complexity Zoo:B#bpp|BPP]].

###RL | title: Randomized Logarithmic-Space | id: rl | url: https://complexityzoo.net/Complexity_Zoo:R#rl
Has the same relation to [[Complexity Zoo:L#l|L]] as [[#rp|RP]] does to [[Complexity Zoo:P#p|P]]. The randomized machine must halt with probability 1 on any input. It must also run in polynomial time (since otherwise we would just get [[Complexity Zoo:N#nl|NL]]). Contains [[#rhl|R<sub>H</sub>L]]. Contained in [[Complexity Zoo:S#sc|SC]] [[zooref#nis92|[Nis92]]]. [[zooref#rtv05|[RTV05]]] give strong evidence that RL = [[Complexity Zoo:L#l|L]].

###RNC | title: Randomized NC | id: rnc | url: https://complexityzoo.net/Complexity_Zoo:R#rnc
Has the same relation to [[Complexity Zoo:N#nc|NC]] as [[#rp|RP]] does to [[Complexity Zoo:P#p|P]]. Contains the maximum matching problem for bipartite graphs [[zooref#mvv87|[MVV87]]]. Contained in [[Complexity Zoo:Q#qnc|QNC]]. See also: [[Complexity Zoo:C#cornc|coRNC]].

###RNC^1 | title: Randomized NC1 | id: rnc1 | url: https://complexityzoo.net/Complexity_Zoo:R#rnc1
Has the same relation to [[#rnc|RNC]] as [[Complexity Zoo:N#nc1|NC<sup>1</sup>]] does to [[Complexity Zoo:N#nc|NC]]. And the same relation to [[Complexity Zoo:N#nc1|NC<sup>1</sup>]] as [[#rp|RP]] does to [[Complexity Zoo:P#p|P]]. Contained in [[Complexity Zoo:B#bpdotl|BP•L]].

###RP | title: Randomized Polynomial-Time | id: rp | url: https://complexityzoo.net/Complexity_Zoo:R#rp
The class of decision problems solvable by an [[Complexity Zoo:N#np|NP]] machine such that <ol> <li>If the answer is 'yes,' at least 1/2 of computation paths accept.</li> <li>If the answer is 'no,' all computation paths reject.</li> </ol> Defined in [[zooref#gil77|[Gil77]]] (implicitly: the class VPP that is defined is equivalent to RP by running the recognizer as many times as necessary to reach probability 1/2). Contains the problem of testing whether an integer is prime [[zooref#ah87|[AH87]]], although this problem was subsequently shown to be in P [[zooref#aks02|[AKS02]]]. For other problems in RP, see the standard text on randomized algorithms, [[zooref#mr95|[MR95]]]. Has the same [[Zoo Glossary#p-measure|p-measure]] as {{zcls|z|zpp}}. Moreover, this measure is either zero or one. If the measure is non-zero, then {{zcls|z|zpp}} = {{zcls|b|bpp}} = {{zcls|e|exp}} {{zcite|IM03}}. See also: [[Complexity Zoo:C#corp|coRP]], [[Complexity Zoo:Z#zpp|ZPP]], [[Complexity Zoo:B#bpp|BPP]].

###RP^cc | title: Communication Complexity RP | id: rpcc | url: https://complexityzoo.net/Complexity_Zoo:R#rpcc
The analogue of [[Complexity Zoo:P#pcc|P<sup>cc</sup>]] for bounded one-sided error probabilistic communication complexity. Contains the complement of the [[Complexity Garden#equality|EQUALITY]] problem.

###RP_^cc | title: Randomized {{zcls|p|pkcc|P_^cc}} | id: rpkcc | url: https://complexityzoo.net/Complexity_Zoo:R#rpkcc
The class of functions <math>F</math> which can be computed by <math>k</math> players with access to shared random bits in the number-on-forehead (defined as in {{zcls|p|pkcc|P<sub><math>k</math></sub><sup>cc</sup>}}) model, subject to two constraints: # The communication cost (the sum of the number of random bits used and bits written to the shared blackboard) is <math>O(\textrm{polylog}(n))</math>. # If <math>F(X_1, \dots, X_k) = 1</math>, then the players decide correctly with probably at least 2/3, whereas if <math>F(X_1, \dots, X_k) = 0</math>, the players always decide correctly. NP<sub><math>k</math></sub><sup>cc</sup> is not equal to {{zcls|r|rpkcc|RP<sub><math>k</math></sub><sup>cc</sup>}} for <math>k\le(1-\delta)\cdot\log n</math> players, for any constant <math>\delta>0</math> {{zcite|DP08}}.

###RPP | title: Restricted Pseudo Polynomial-Time | id: rpp | url: https://complexityzoo.net/Complexity_Zoo:R#rpp
The class of decision problems (x,m) (where x is an input of length |x|=n and m is an integer parameter), that are solvable by a nondeterministic (i.e. [[Complexity Zoo:N#np|NP]]) machine in poly(n+m) time and O(m+log n) space simultaneously. Defined in [[zooref#mon80|[Mon80]]]. See also [[Complexity Zoo:F#fpt|FPT]].

###RQP | title: One-sided Error Extension of EQP | id: rqp | url: https://complexityzoo.net/Complexity_Zoo:R#rqp
The class of questions that can be answered by a QTM that accepts with probability 0 when the true answer is no, and accepts with probability at least 1/2 when the true answer is yes. Since one of the probabilities has to vanish, RQP has the same technical caveats as [[Complexity Zoo:E#eqp|EQP]]. Contains [[Complexity Zoo:Z#zqp|ZQP]] and [[#rbqp|RBQP]], and is contained in [[Complexity Zoo:B#bqp|BQP]].

###RSPACE(f(n)) | title: Randomized f(n)-Space | id: rspace | url: https://complexityzoo.net/Complexity_Zoo:R#rspace
Same as [[#rl|RL]], but for O(f(n))-space instead of logarithmic-space. (Just as an RL machine must run in polynomial time, so an RSPACE(f(n)) machine must run in 2<sup>O(f(n))</sup> time.) Contained in [[Complexity Zoo:N#nspace|NSPACE(f(n))]] and [[Complexity Zoo:B#bpspace|BPSPACE(f(n))]].

###S_2P | title: Second Level of the Symmetric Hierarchy | id: s2p | url: https://complexityzoo.net/Complexity_Zoo:S#s2p
The class of decision problems for which there is a polynomial-time predicate P such that, on input x, <ol> <li>If the answer is 'yes,' then there exists a y such that for all z, P(x,y,z) is true.</li> <li>If the answer is 'no,' then there exists a z such that for all y, P(x,y,z) is false.</li> </ol> Note that this differs from [[#sigma2p|&#931;<sub>2</sub>P]] in that the quantifiers in the second condition are reversed. Less formally, S<sub>2</sub>P is the class of one-round games in which a prover and a disprover submit simultaneous moves to a deterministic, polynomial-time referee. In [[#sigma2p|&#931;<sub>2</sub>P]], the prover moves first. Defined in [[zooref#rs98|[RS98]]], where it was ……[中略]…… 1|[Cai01]]]. Contains (and contrast with) [[Complexity Zoo:O#o2p|O<sub>2</sub>P]]. If [[Complexity Zoo:N#np|NP]] is contained in [[Complexity Zoo:P#ppoly|P/poly]] then [[Complexity Zoo:P#ph|PH]] = S<sub>2</sub>P (attributed to Sengupta in [[zooref#cai01|[Cai01]]]), and even is equal to [[Complexity Zoo:O#o2p|O<sub>2</sub>P]] [[zooref#cr06|[CR06]]].

###SAC | title: Semi-Unbounded-Fanin AC | id: sac | url: https://complexityzoo.net/Complexity_Zoo:S#sac
SAC<sup>k</sup> is the class of decision problems solvable by a family of depth-O(log<sup>k</sup>n) circuits, with polynomial size, with unbounded-fanin OR & bounded-fanin AND gates. Negations are only allowed at the input level. A uniformity condition may also be imposed. Defined by [[zooref#bcd89|[BCD+89]]], who also showed that SAC<sub>k</sub> is closed under complement for every k&gt;0.

###SAC^0 | title: Semi-Unbounded-Fanin AC^0 | id: sac0 | url: https://complexityzoo.net/Complexity_Zoo:S#sac0
See [[#sac|SAC]] for definition. Not closed under complement [[zooref#bcd89|[BCD+89]]]. Not contained in ⊕SAC<sup>0</sup> [[zooref#k23|[K23]]].

###SAC^1 | title: Semi-Unbounded-Fanin AC^1 | id: sac1 | url: https://complexityzoo.net/Complexity_Zoo:S#sac1
See [[#sac|SAC]] for definition. Equals [[Complexity Zoo:L#logcfl|LOGCFL]]/poly [[zooref#ven91|[Ven91]]]. Contained in [[Complexity Zoo:Symbols#paritysac1|&#8853;SAC<sup>1</sup>]] [[zooref#gw96|[GW96]]].

###SAPTIME | title: Stochastic Alternating Polynomial-Time | id: saptime | url: https://complexityzoo.net/Complexity_Zoo:S#saptime
The class of problems solvable by a polynomial-time Turing machine with three kinds of quantifiers: existential, universal, and randomized. Defined in [[zooref#pap83|[Pap83]]], where it was also observed that SAPTIME = [[Complexity Zoo:P#pspace|PSPACE]].

###SBP | title: Small Bounded-Error Probability | id: sbp | url: https://complexityzoo.net/Complexity_Zoo:S#sbp
The class of decision problems for which the following holds. There exists a [[Complexity Zoo:Symbols#sharpp|#P]] function f and an [[Complexity Zoo:F#fp|FP]] function g such that, for all inputs x, <ol> <li>If the answer is "yes" then f(x) &gt; g(x).</li> <li>If the answer is "no" then f(x) &lt; g(x)/2.</li> </ol> Defined in [[zooref#bgm02|[BGM02]]], where the following was also shown: <ul> <li>SBP contains [[Complexity Zoo:M#ma|MA]], [[Complexity Zoo:W#wapp|WAPP]], and [[Complexity Zoo:E#existsbpp|&#8707;BPP]].</li> <li>SBP is contained in [[Complexity Zoo:A#am|AM]] and [[Complexity Zoo:B#bpppath|BPP<sub>path</sub>]].</li> <li>There exists an oracle relative to which SBP is not contained in [[#sigma2p|&#931;<sub>2</sub>P]].</li> <li>SBP is closed under union.</li> </ul> There exists an oracle relative to which SBP is not closed under intersection [[zooref#glm+15|[GLM+15]]]. If SAT can be solved by an NP-machine with sub-exponential number of accepting paths, then SBP = [[Complexity Zoo:A#am|AM]] {{zcite|Vol20}}.

###SBP^cc | title: Communication Complexity SBP | id: sbpcc | url: https://complexityzoo.net/Complexity_Zoo:S#sbpcc
The corresponding model consists of randomized protocols such that yes-inputs are accepted with probability at least &alpha; and no-inputs are accepted with probability at most &alpha;/2 where &alpha; is to be thought of as a function of n. The cost of a protocol is defined to be its communication cost plus log(1/&alpha;). Does not contain [[Complexity Zoo:C#conpcc|coNP<sup>cc</sup>]] [[zooref#raz92|[Raz92]]] [[zooref#gw14|[GW14]]]. Contains [[Complexity Zoo:M#macc|MA<sup>cc</sup>]] but does not equal it, since SBP<sup>cc</sup> is not closed under intersection [[zooref#glm+15|[GLM+15]]]. Contained in [[Complexity Zoo:A#amcc|AM<sup>cc</sup>]] and in [[Complexity Zoo:P#postbppcc|PostBPP<sup>cc</sup>]]. The complexity measure corresponding to SBP<sup>cc</sup> is equivalent to the "corruption bound" [[zooref#gw14|[GW14]]].

###SBQP | title: Small Bounded-Error Quantum Polynomial-Time | id: sbqp | url: https://complexityzoo.net/Complexity_Zoo:S#sbqp
The class of decision problems for which there exists a polynomial-time quantum algorithm that accepts with probability at least 2<sup>−p(n)</sup> if the answer is "yes", and with probability at most 2<sup>−p(n)−1</sup> if the answer is "no", for some polynomial p. Defined by Kuperberg in [[zooref#kup09|[Kup09]]], where he showed that SBQP = [[Complexity Zoo:A#a0pp|A<sub>0</sub>PP]].

###SC | title: Steve's Class | id: sc | url: https://complexityzoo.net/Complexity_Zoo:S#sc
(Named in honor of Stephen Cook.) The class of decision problems solvable by a Turing machine that simultaneously uses polynomial time and polylogarithmic space. Note that SC might be smaller than [[Complexity Zoo:P#p|P]] &#8745; [[Complexity Zoo:P#polyL|polyL]], since for the latter, it suffices to have two separate algorithms: one polynomial-time and the other polylogarithmic-space. Deterministic context-free languages ([[Complexity Zoo:D#dcfl|DCFL]]s) can be recognized in SC [[zooref#coo79|[Coo79]]]. SC contains [[Complexity Zoo:R#rl|RL]] and [[Complexity Zoo:B#bpl|BPL]] [[zooref#nis92|[Nis92]]]. SC equals [[Complexity Zoo:D#dtisp|DTISP]](poly,polylog) by definition.

###SE | title: Subexponentially-Solvable Search Problems | id: se | url: https://complexityzoo.net/Complexity_Zoo:S#se
The class of [[Complexity Zoo:F#fnp|FNP]] search problems solvable in O(2<sup>&epsilon;n</sup>) time for every &epsilon;&gt;0. Defined in [[zooref#ipz01|[IPZ01]]], who also gave reductions showing that if any of k-SAT, k-colorability, k-set cover, clique, or vertex cover is in SE, then all of them are.

###SEH | title: Strong Exponential Hierarchy | id: seh | url: https://complexityzoo.net/Complexity_Zoo:S#seh
The union of [[Complexity Zoo:N#ne|NE]], [[Complexity Zoo:N#np|NP]]<sup>[[Complexity Zoo:N#ne|NE]]</sup>, [[Complexity Zoo:N#np|NP]]<sup>[[Complexity Zoo:N#np|NP]]^[[Complexity Zoo:N#ne|NE]]</sup>, and so on. Is called "strong" to contrast it with the ordinary Exponential Hierarchy [[Complexity Zoo:E#eh|EH]]. Note that we would get the same class if we replaced [[Complexity Zoo:N#ne|NE]] by [[Complexity Zoo:N#nexp|NEXP]]. SEH collapses to [[Complexity Zoo:P#p|P]]<sup>[[Complexity Zoo:N#ne|NE]]</sup> [[zooref#hem89|[Hem89]]] There exists an oracle relative to which SEH is not contained in [[Complexity Zoo:E#eh|EH]] [[zooref#hem89|[Hem89]]]. [[Complexity Zoo:E#eh|EH]] and SEH are incomparable for all anyone knows.

###SelfNP | title: Self-Witnessing NP | id: selfnp | url: https://complexityzoo.net/Complexity_Zoo:S#selfnp
The class of languages L in [[Complexity Zoo:N#np|NP]] such that the union, over all x in L, of the set of valid witnesses for x equals L itself. Defined in [[zooref#ht03|[HT03]]], where it was shown that the closure of SelfNP under polynomial-time many-one reductions is [[Complexity Zoo:N#np|NP]]. They also show that if SelfNP = [[Complexity Zoo:N#np|NP]], then [[Complexity Zoo:E#e|E]] = [[Complexity Zoo:N#ne|NE]]; and that SAT is contained in SelfNP. See also: [[Complexity Zoo:P#permup|PermUP]].

###SF_k | title: Width-k Bottleneck Turing Machines | id: sfk | url: https://complexityzoo.net/Complexity_Zoo:S#sfk
The class of decision problems solvable by a k-bottleneck Turing machine. This is a machine that, after a polynomial amount of time, erases everything on the tape except for a single k-valued "safe-storage". There's also a counter recording the number of erasings, which is in effect a non-deterministic witness. For example, SF<sub>2</sub> contains both [[Complexity Zoo:Symbols#parityp|&#8853;P]] and [[Complexity Zoo:N#np|NP]] by using the counter as a witness. Defined in [[zooref#cf91|[CF91]]], where it was also shown that SF<sub>5</sub> = [[Complexity Zoo:P#pspace|PSPACE]]. The complexity of SF<sub>2</sub>, SF<sub>3</sub>, and SF<sub>4</sub> was studied in [[zooref#ogi94|[Ogi94]]] and [[zoo ……[中略]…… #modkp|Mod_3P]] ^ [[Complexity Zoo:Symbols#parityp|&#8853;P]]</sup> </td></tr> </table> (Here the [[Zoo Operators#bp|BP operator]] means that one makes the class into a bounded-error probabilistic class, the same way one makes [[Complexity Zoo:P#p|P]] into [[Complexity Zoo:B#bpp|BPP]] and [[Complexity Zoo:N#np|NP]] into [[Complexity Zoo:A#am|AM]].)

###SKC | title: Statistical Knowledge Complexity | id: skc | url: https://complexityzoo.net/Complexity_Zoo:S#skc
A hierarchy of generalizations of [[#szk|SZK]], in which Arthur is allowed to gain <i>some</i> information from his interaction with Merlin. Defined in [[zooref#gp91|[GP91]]]. There are several variants (which we only describe roughly), including: <ul> <li>'''SKC<sub>hint</sub>(k(n)): Hint sense.''' The simulator can reproduce Arthur's view of the protocol if given a hint string of size k(n).</li> <li>'''SKC<sub>hint</sub>(k(n)): Strict oracle sense.''' The simulator can reproduce Arthur's view if allowed k(n) queries to an oracle O.</li> <li>'''SKC<sub>avg</sub>(k(n)): Average oracle sense.''' For each input, the <i>expected</i> number of queries the simulator makes to oracle O is at most k(n).</li> <li>'''SKC<sub>ent</sub>(k(n)): Entropy sense.''' Defined in [[zooref#abv95|[ABV95]]]. For each input, the expectation (over Arthur's random coins) of -log(P) is at most k(n), where P is the probability that the view output by the simulator equals the view resulting from the actual protocol.</li> </ul> See also: [[Complexity Zoo:P#pkc|PKC]].

###SL | title: Symmetric Logarithmic-Space | id: sl | url: https://complexityzoo.net/Complexity_Zoo:S#sl
The class of problems solvable by a nondeterministic Turing machine in logarithmic space, such that <ol> <li>If the answer is 'yes,' one or more computation paths accept.</li> <li>If the answer is 'no,' all paths reject.</li> <li>If the machine can make a nondeterministic transition from configuration A to configuration B, then it can also transition from B to A. The undirected s-t connectivity problem (USTCON: is there a path from vertex s to vertex t in a given undirected graph?) is complete for SL, under [[Complexity Zoo:L#l|L]]-reductions. SL contains [[Complexity Zoo:L#l|L]], and is contained in [[Complexity ……[中略]…… atw00|[ATW+00]]]. [[zooref#nt95|[NT95]]] showed that SL equals [[Complexity Zoo:C#cosl|coSL]], and furthermore that SL<sup>SL</sup> = SL (that is, the symmetric logspace hierarchy collapses). Reingold ultimately showed that SL = [[Complexity Zoo:L#l|L]] [[zooref#rei04|[Rei04]]], even relative to an oracle. This subsumes many of the earlier results.

###SNP | title: Strict NP | id: snp | url: https://complexityzoo.net/Complexity_Zoo:S#snp
[[zooref#fag74|[Fag74]]] showed that [[Complexity Zoo:N#np|NP]] is precisely the class of decision problems reducible to a graph-theoretic property expressible in second-order existential logic. Then SNP is the class of decision problems reducible to a graph-theoretic predicate with <i>only</i> universal quantifiers over vertices, no existential quantifiers. As an example, k-SAT (CNF satisfiability with at most k literals per clause, for k a constant) is in SNP. But general SAT is not in SNP, basically because we're not allowed to say, "There exists a literal in this clause that satisfies the clause." Contains [[Complexity Zoo:M#mmsnp|MMSNP]]. See also: [[Complexity Zoo:M#maxsnp|MaxSNP]].

###SO | title: Second-Order logic | id: so | url: https://complexityzoo.net/Complexity_Zoo:S#so
We define second-order variable has got an arity <math>k</math> and represent any proposition of arity <math>k</math>. They are usually written in upper-case. Second order logic is the set of [[Complexity_Zoo:F#fo|FO]] formulae where we add quantification over second-order variables. Every formuale is equivalent to a formulae in prenex normal form, where we first write quantification on variable on second order and then a FO-formulae in prenex normal form. In [[zooref#imm98|Descriptive complexity]] we can see that SO is equal to [[Complexity_Zoo:P#PH|PH]], more precisely we have that formulae in prenex normal form where existential and universal of second order alternate <math>k</math> times are the <math>k</math>th level of the polynomial hierarchy. This means that SO with only existential second-order quantification is equal to <math>\Sigma^1</math> which is [[Complexity_Zoo:N#np|NP]], and with only universal quantification is equal to <math>\Pi^1</math> which is [[Complexity_Zoo:C#conp|Co-NP]].

###SO(Horn) | title: Second-order in Horn form | id: sohorn | url: https://complexityzoo.net/Complexity_Zoo:S#sohorn
SO(horn) is the set of boolean queries definable with [[Complexity_Zoo:S#so|second-order]] formulae in normal form such that the quantifier-free part of the formula is in conjunctive normal form with at most one positive instance of a quantified relation per clause. (Atomic queries to the database don't count.) It was shown in [[zooref#gra92|[Grä92]]] that this class is equal to [[Complexity_Zoo:P#p|P]]. Those formulae can be made in prenex form where the second order is existential and the first order universal without loss of generality.

###SO(Krom) | title: Second-order in Krom form | id: sokrom | url: https://complexityzoo.net/Complexity_Zoo:S#sokrom

It was shown in [[zooref#gra92|[Grä92]]] that this class is equal to [[Complexity_Zoo:N#nl|NL]]. Those formulaes can be made in prenex form where the second order is existential and the first order universal without loss of generalities.

###UP^cc | title: Communication Complexity UP | id: upcc | url: https://complexityzoo.net/Complexity_Zoo:U#upcc

Introduced in [[zooref#yan91|[Yan91]]], where it was shown that for total functions: <ul> <li> [[Complexity Zoo:P#pcc|P<sup>cc</sup>]]=UP<sup>cc</sup>. <li> The "Clique vs. Independent Set problem" CIS<sub>G</sub> on a graph G (Alice gets a clique, Bob gets an independent set: do they intersect?) is "complete" for UP<sup>cc</sup> in the sense that every f, say with UP<sup>cc</sup>(f)=c, reduces to CIS<sub>G</sub> for some G on 2<sup>c</sup> many nodes. </ul> The quadratic overhead in simulating UP<sup>cc</sup> with [[Complexity Zoo:P#pcc|P<sup>cc</sup>]], or equivalently the O(log<sup>2</sup>(n)) protocol for CIS<sub>G</sub>, is known to be essentially optimal [[zooref#gpw15|[GPW15]]].

###UPP^cc | title: Unrestricted Communication Analogue of PP | id: uppcc | url: https://complexityzoo.net/Complexity_Zoo:U#uppcc

###VC_k | title: Verification Class With A Circuit of Depth K | id: vck | url: https://complexityzoo.net/Complexity_Zoo:V#vck

###VP_k | title: Valiant P Over Field k | id: vp | url: https://complexityzoo.net/Complexity_Zoo:V#vp
The class of efficiently-solvable problems in Valiant's algebraic complexity theory. More formally, the input consists of constants c<sub>1</sub>,...,c<sub>m</sub> and indeterminates X<sub>1</sub>,...,X<sub>n</sub> over a base field k (for instance, the complex numbers or Z<sub>2</sub>). The desired output is a collection of polynomials over the X<sub>i</sub>'s. The complexity is the minimum number of pairwise additions, subtractions, and multiplications needed by a straight-line program to produce these polynomials. VP<sub>k</sub> is the class of problems whose complexity is polynomial in n. (Hence, VP<sub>k</sub> is a nonuniform class, in contrast to [[Complexity Zoo:P#pc|P<sub>C</sub>]] and [[Complexity Zoo:P#pr2|P<sub>R</sub>]].) Originated in [[zooref#val79b|[Val79b]]]; see [[zooref#bur00|[Bur00]]] for more information. Contained in [[#vnp|VNP<sub>k</sub>]] and [[#vqp|VQP<sub>k</sub>]], and contains [[#vnc|VNC<sub>k</sub>]].

###VPL | title: Visibly pushdown languages | id: vpl | url: https://complexityzoo.net/Complexity_Zoo:V#vpl
The class of problems that can be decided by a visibly pushdown automaton. In a visibly pushdown automaton, all push and pop transitions have to be triggered by special alphabet symbols, and thus are visible in the input word. Nondeterminism does not add to the expressive power of this automaton model, and the complexity class is closed under all Boolean operations. Originated in [[zooref#am04|[AM04]]]. See also [[zooref#am09|[AM09]]]. Properly contains [[#reg|REG]]. Properly contained in [[#dcfl|DCFL]].

###VQP_k | title: Valiant QP Over Field k | id: vqp | url: https://complexityzoo.net/Complexity_Zoo:V#vqp
Has the same relation to [[#vp|VP<sub>k</sub>]] as [[Complexity Zoo:Q#qp|QP]] does to [[Complexity Zoo:P#p|P]]. Originated in [[zooref#val79b|[Val79b]]]. The determinant of an n-by-n matrix of indeterminates is VQP<sub>k</sub>-complete under a type of reduction called qp-projections (see [[zooref#bur00|[Bur00]]] for example). It is an open problem whether the determinant is [[#vp|VP<sub>k</sub>]]-complete.

###WAPP^cc | title: Communication Complexity WAPP | id: wappcc | url: https://complexityzoo.net/Complexity_Zoo:W#wappcc
This class is parameterized by a constant &epsilon;>0. The corresponding model consists of randomized protocols such that yes-inputs are accepted with probability in [(1-&epsilon;)&alpha;,&alpha;] and no-inputs are accepted with probability in [0,&alpha;] where &alpha; is to be thought of as a function of n. The cost of a protocol is defined to be its communication cost plus log(1/&alpha;). Does not admit efficient amplification with respect to the &epsilon; parameter [[zooref#glm+15|[GLM+15]]]. ###XOR-MIP*[2,1] | title: {{zcls|m|mipstar|MIP*[2,1]}} With 1-Bit Proofs | id: xormipstar21 | url: https://complexityzoo.net/Complexity_Zoo:X#xormipstar21
Same as {{zcls|m|mipstar|MIP*[2,1]}}, but with the further restriction that both provers send only a single bit to the verifier, and the verifier's output is a function of the exclusive-OR of those bits. There should exist 0&lt;''a''&lt;''b''&lt;1 such that if the answer is "yes", then for some responses of the provers the verifier accepts with probability at least ''b'', while if the answer is "no", then for all responses of the provers the verifier accepts with probability at most ''a''. Defined by [[zooref#cht04|[CHT+04]]], whose motivation was a connection to the Bell and CHSH inequalities of quantum physics. XOR-MIP*[2,1] is contained in [[Complexity Zoo:N#nexp|NEXP]] [[zooref#cht04|[CHT+04]]]. XOR-MIP*[2,1] is contained in [[Complexity Zoo:Q#qip2|QIP[2]]] [[zooref#weh06|[Weh06]]]

###XP | title: Fixed-Parameter Tractable for Each Parameter | id: xp | url: https://complexityzoo.net/Complexity_Zoo:X#xp
The class of decision problems of the form (x,k) (k a parameter) that are solvable in time O(|x|<sup>f(k)</sup>) for some function f. The algorithm used may depend on k. Defined in [[zooref#df99|[DF99]]]. Contains [[#xpuniform|XP<sub>uniform</sub>]]. Strictly contains [[Complexity Zoo:F#fpt|FPT]] (by diagonalization).

###XP_uniform | title: Uniform XP | id: xpuniform | url: https://complexityzoo.net/Complexity_Zoo:X#xpuniform
Same as [[#xp|XP]] except that the algorithm used must be the same for each k (though it can take k as input). Defined in [[zooref#df99|[DF99]]].

###YP | title: Your Polynomial-Time or Yaroslav-Percival | id: yp | url: https://complexityzoo.net/Complexity_Zoo:Y#yp
The class of decision problems for which there exists a polynomial-time machine M such that: <ul> <li>For all input sizes n, there exists a polynomial-size advice string s<sub>n</sub> such that M(x,s<sub>n</sub>) outputs the correct answer for all inputs x of size n.</li> <li>For all inputs x and advice strings s, M(x,s) outputs either the correct answer or "I don't know."</li> </ul> Defined in a [http://www.scottaaronson.com/blog/?p=77 recent post] of the blog [http://www.scottaaronson.com/blog/ Shtetl-Optimized]. See there for an explanation of the class's name. Contains [[Complexity Zoo:Z#zpp|ZPP]] by the same argument that places [[Complexity Zoo:B#bpp|BPP]] in [[Complexity Zoo:P#ppoly|P/poly]]. Also contains [[Complexity Zoo:P#p|P]] with [[Complexity Zoo:T#tally|TALLY]] &#8745; [[Complexity Zoo:N#np|NP]] &#8745; [[Complexity Zoo:C#conp|coNP]] oracle. Is contained in [[Complexity Zoo:N#npiconp|NP &#8745; coNP]] and [[#ypp|YPP]]. Is equal to [[Complexity Zoo:O#onp|ONP]] &#8745; coONP.

###YP* | title: Yaroslav-Percival Star | id: yp* | url: https://complexityzoo.net/Complexity_Zoo:Y#yp*
[[Complexity Zoo:Y#yp|YP]] except the advice string s_n can be verified in polynomial time without needing the input x [[zooref#AD14|[AD14]]].

###YPP | title: Yaroslav BPP | id: ypp | url: https://complexityzoo.net/Complexity_Zoo:Y#ypp
The probabilistic analogue of [[#yp|YP]]; it is to YP what [[Complexity Zoo:M#ma|MA]] is to [[Complexity Zoo:N#np|NP]]. Formally, the class of decision problems for which there exists a syntactic [[Complexity Zoo:B#bpp|BPP]] machine M such that: <ul> <li>For all input sizes n, there exists a polynomial-size advice string a<sub>n</sub> such that for all inputs x of size n, M(x,a<sub>n</sub>) outputs the correct answer with probability at least 2/3.</li> <li>For all inputs x and advice strings a, the probability that M(x,a) outputs the incorrect answer is at most 1/3. In other words, the sum of the probabilities of the correct answer and "I don't know" is at least 2/3.</li> </ul> To amplify a YPP machine, one can run it multiple times, then accept if a majority of runs accept, reject if a majority reject, and otherwise output "I don't know." Contains [[Complexity Zoo:B#bpp|BPP]] and [[#yp|YP]], and is contained in [[Complexity Zoo:M#ma|MA]] and [[Complexity Zoo:P#ppoly|P/poly]].

###YQP | title: Yaroslav BQP | id: yqp | url: https://complexityzoo.net/Complexity_Zoo:Y#yqp
Is to [[#ypp|YPP]] as [[Complexity Zoo:B#bqp|BQP]] is to [[Complexity Zoo:B#bpp|BPP]], and [[Complexity Zoo:Q#qma|QMA]] is to [[Complexity Zoo:M#ma|MA]]. The machine is now a quantum computer and the advice is a quantum state |&psi;_n&gt;. Contains [[Complexity Zoo:B#bqp|BQP]] and [[#ypp|YPP]], and is contained in [[Complexity Zoo:Q#qma|QMA]] and [[Complexity Zoo:B#bqpqpoly|BQP/qpoly]].

###YQP* | title: Yaroslav BQP star | id: yqp* | url: https://complexityzoo.net/Complexity_Zoo:Y#yqp*
Is to [[#yqp|YQP]] as [[Complexity Zoo:Y#yp*|YP*]] is to [[Complexity Zoo:Y#yp|YP]] [[zooref#AD14|[AD14]]]. Is contained in [[Complexity Zoo:A#app|APP]], and so is low for [[Complexity Zoo:P#pp|PP]] [[zooref#yir24|[Yir24]]].

Equal to [[Complexity Zoo:B#bqpqpoly|BQP/qpoly]] [[zooref#AD14|[AD14]]].

###ZAM^cc | title: Zero-Information Arthur-Merlin Communication Complexity | id: zamcc | url: https://complexityzoo.net/Complexity_Zoo:Z#zamcc
Similar to [[Complexity Zoo:A#amcc|AM<sup>cc</sup>]] except that on each yes-input, the distribution of Merlin’s proof must leak no information about the input and moreover, this proof must be unique for each outcome of Arthur’s (i.e., Alice's and Bob's) randomness. Contained in [[Complexity Zoo:C#conpcc|coNP<sup>cc</sup>]] [[zooref#gpw16a|[GPW16a]]]. Unlike with other communication complexity classes, it is not known whether every function can be computed with O(n) communication in the ZAM<sup>cc</sup> model. In fact it is not even obvious that every function can be computed at all in this model, but this turns out to be the case; indeed, there is an O(2<sup>n</sup>) upper bound for every function [[zooref#gpw16a|[GPW16a]]]. Closely related to "private simultaneous messages" protocols in cryptography [[zooref#ar16|[AR16]]].

###ZBQP | title: Strict Quantum ZPP | id: zbqp | url: https://complexityzoo.net/Complexity_Zoo:Z#zbqp
Defined as [[Complexity Zoo:R#rbqp|RBQP &#8745; coRBQP]]. Equivalently, the class of problems in [[Complexity Zoo:N#npiconp|NP &#8745; coNP]] such that both positive and negative witnesses are in [[Complexity Zoo:F#fbqp|FBQP]]. For example, the language of square-free numbers is in ZBQP, because [[Complexity_Garden#integer_factorization|factoring]] is in [[Complexity Zoo:F#fbqp|FBQP]] and a factorization can be certified in [[#zpp|ZPP]] (indeed in [[Complexity Zoo:P#p|P]], by [[zooref#aks02|[AKS02]]]). Unlike [[Complexity Zoo:E#eqp|EQP]] or [[#zqp|ZQP]], ZBQP would generalize [[#zpp|ZPP]] in practice if quantum computers existed, in the sense that it provides proven answers. Contains [[#zpp|ZPP]] and is contained in [[Complexity Zoo:R#rbqp|RBQP]] and [[#zqp|ZQP]]. Also, ZBQP<sup>ZBQP</sup> = ZBQP. Defined here to clarify [[Complexity Zoo:E#eqp|EQP]] and [[#zqp|ZQP]].

###ZK | title: Zero-Knowledge (see CZK) | id: zk | url: https://complexityzoo.net/Complexity_Zoo:Z#zk
Often used as a shorthand for [[Complexity Zoo:C#czk|(computational zero-knowledge) CZK]], but may also be used as a general paradigm encomposing various classes ranging from perfect and statistical zero-knowledge ([[Complexity Zoo:S#szk|SZK]]) to computational ones ([[Complexity Zoo:C#czk|CZK]]), and also various forms of non-interactive zero-knowledge proof systems. Zero-knowledge proofs were introduced in [[zooref#gmr89|[GMR89]]], and further studied in [[zooref#gmw91|[GMW91]]], which demonstrated the wide applicability of the concept.

###ZP•L | title: Zero-Error Probabilistic L with Two Way Access to Randomness | id: zpdotl | url: https://complexityzoo.net/Complexity_Zoo:Z#zpdotl
Has the same relationship to [[Complexity Zoo:B#bpdotl|BP•L]] as [[#zpp|ZPP]] has to [[Complexity Zoo:B#bpp|BPP]]. More specifically, the set of languages with a log space, polynomial time Turing machine using a read only randomness tape such that on input x: 1. With high probability over the random bits used in the randomness tape will the machine correctly output whether x is in the language. 2. The machine will either wither correctly output whether x is in the language, or output 'unknown'. Contains [[Complexity Zoo:B#bpl|BPL]] [[zooref#nis93|[Nis93]]]. Contained in [[Complexity Zoo:R#rnc|RNC]] since [[Complexity Zoo:L#l|L]] is contained in [[Complexity Zoo:N#nc|NC]] and zero sided error is weaker than one sided error. Contained in [[Complexity Zoo:B#bpdotl|BP•L]].

###ZPE | title: Zero-Error Probabilistic E | id: zpe | url: https://complexityzoo.net/Complexity_Zoo:Z#zpe
Same as [[#zpp|ZPP]], but with 2<sup>O(n)</sup>-time instead of polynomial-time. ZPE = [[Complexity Zoo:E#ee|EE]] if and only if [[#zpp|ZPP]] = [[Complexity Zoo:E#exp|EXP]] [[zooref#ikw01|[IKW01]]].

###ZPP | title: Zero-Error Probabilistic Polynomial-Time | id: zpp | url: https://complexityzoo.net/Complexity_Zoo:Z#zpp
Defined as [[Complexity Zoo:R#rp|RP]] &#8745; [[Complexity Zoo:C#corp|coRP]]. Defined as the class of problems solvable by randomized algorithms that <i>always</i> return the correct answer, and whose <i>expected</i> running time (on any input) is polynomial, in [[zooref#gil77|[Gil77]]]. (Proposition 5.5(iii) in this paper shows that the two definitions above are equivalent.) Contains the problem of testing whether an integer is prime [[zooref#ss77|[SS77]]] [[zooref#ah87|[AH87]]]. In contrast to [[Complexity Zoo:B#bpp|BPP]] and [[Complexity Zoo:R#rp|RP]], it is not known whether showing ZPP = [[Complexity Zoo:P#p|P]] requires proving superpolynomial circuit lower bounds [[zooref#ki02|[KI02]]]. There exists an oracle relative to which ZPP = [[Complexity Zoo:E#exp|EXP]] [[zooref#hel84|[Hel84a]]], [[zooref#hel84b|[Hel84b]]], [[zooref#kur85|[Kur85]]], [[zooref#hel86|[Hel86]]]. Has the same [[Zoo Glossary#p-measure|p-measure]] as {{zcls|r|rp}}. Moreover, this measure is either zero or one. If the measure is non-zero, then ZPP = {{zcls|b|bpp}} = {{zcls|e|exp}} {{zcite|IM03}}.

###ZPP^cc | title: Communication Complexity ZPP | id: zppcc | url: https://complexityzoo.net/Complexity_Zoo:Z#zppcc
Equals [[Complexity Zoo:P#pcc|P<sup>cc</sup>]] if defined in terms of total functions; is not contained in [[Complexity Zoo:Symbols#paritypcc|&#8853;P<sup>cc</sup>]] if defined in terms of partial functions [[zooref#gpw16b|[GPW16b]]].

###ZPTIME(f(n)) | title: Zero-Error Probabilistic f(n)-Time | id: zptime | url: https://complexityzoo.net/Complexity_Zoo:Z#zptime
Same as [[#zpp|ZPP]], but with O(f(n))-time instead of polynomial-time. For any constructible superpolynomial f, ZPTIME(f(n)) with [[Complexity Zoo:N#np|NP]] oracle is not contained in [[Complexity Zoo:P#ppoly|P/poly]] [[zooref#kw98|[KW98]]].

###ZQP | title: Zero-Error Extension Of EQP | id: zqp | url: https://complexityzoo.net/Complexity_Zoo:Z#zqp
The class of questions that can be answered by a QTM that answers yes, no, or "maybe". If the correct answer is yes, then P[no] = 0, and vice-versa; and the probability of maybe is at most 1/2. Since some of the probabilities have to vanish, ZQP has the same technical caveats as [[Complexity Zoo:E#eqp|EQP]]. Defined independently in [[zooref#bw03|[BW03]]] and in [[zooref#nis02|[Nis02]]]. Contains [[Complexity Zoo:E#eqp|EQP]] and [[#zbqp|ZBQP]] and is contained in [[Complexity Zoo:B#bqp|BQP]]. Equals [[Complexity Zoo:R#rqp|RQP &#8745; coRQP]]. There is an oracle such that ZQP<sup>ZQP</sup> is larger than ZQP [[zooref#bw03|[BW03]]]; c.f. with [[#zbqp|ZBQP]].
