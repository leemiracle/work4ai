This page documents CleanRL's implementations of Deep Deterministic Policy Gradient (DDPG) and Twin Delayed Deep Deterministic Policy Gradient (TD3), both off-policy actor-critic algorithms designed for continuous action spaces. These algorithms learn deterministic policies through the use of replay buffers, target networks, and (for TD3) additional stabilization techniques.

For on-policy continuous control algorithms, see PPO (Proximal Policy Optimization). For stochastic actor-critic methods with entropy regularization, see SAC (Soft Actor-Critic). For discrete action spaces, see DQN (Deep Q-Network).

### Algorithm Overview

DDPG and TD3 are both deterministic policy gradient algorithms that directly output continuous actions without sampling from a distribution. Unlike DQN which operates on discrete action spaces, these algorithms extend the actor-critic framework to continuous control by concatenating observations and actions as input to critic networks.

Key Characteristics:

| Feature | DDPG | TD3 |
| Policy Type | Deterministic | Deterministic |
| Action Space | Continuous (Box) | Continuous (Box) |
| Sample Efficiency | Off-policy | Off-policy |
| Exploration | Gaussian noise | Gaussian noise |
| Q-Networks | Single | Twin (Clipped Double Q-Learning) |
| Policy Updates | Every step | Delayed (every N steps) |
| Target Policy | Direct copy | Smoothed with noise |

TD3 improves upon DDPG by addressing overestimation bias through three core techniques: clipped double Q-learning, delayed policy updates, and target policy smoothing regularization.

Sources: docs/rl-algorithms/ddpg.md4-17 docs/rl-algorithms/td3.md4-17

### Core Network Components

#### Actor Network Architecture

Both DDPG and TD3 use deterministic actors that map observations directly to continuous actions through a feedforward network with tanh output activation and action rescaling.

```

```

The `Actor` class handles asymmetric action spaces through `action_scale` and `action_bias` buffers:

  - action_scale = (action_high - action_low) / 2.0 cleanrl/ddpg_continuous_action.py 105

  - action_bias = (action_high + action_low) / 2.0 cleanrl/ddpg_continuous_action.py 108

  - Final action = tanh(fc_mu(x)) * action_scale + action_bias cleanrl/ddpg_continuous_action.py 115

Sources: cleanrl/ddpg_continuous_action.py97-116 cleanrl/td3_continuous_action.py106-133

#### Critic Network Architecture

The critic (Q-network) estimates state-action values by concatenating observations and actions as input.

```

```

DDPG: Uses a single Q-network (`qf1`) and its target counterpart (`qf1_target`). cleanrl/ddpg_continuous_action.py152-153

TD3: Uses two Q-networks (`qf1`, `qf2`) with corresponding targets (`qf1_target`, `qf2_target`) for clipped double Q-learning. cleanrl/td3_continuous_action.py172-175

Sources: cleanrl/ddpg_continuous_action.py82-95 cleanrl/td3_continuous_action.py88-103

#### DDPG Loss Functions

Critic Loss (Q-function):
The critic minimizes the mean squared temporal difference error cleanrl/ddpg_continuous_action.py214

Actor Loss (Policy):
The actor maximizes expected Q-values via policy gradient: `actor_loss = -qf1(data.observations, actor(data.observations)).mean()` cleanrl/ddpg_continuous_action.py223

Target Network Updates (Soft Updates):
CleanRL uses Polyak averaging (soft updates) with `tau` cleanrl/ddpg_continuous_action.py226-229

### TD3 Improvements Over DDPG

TD3 extends DDPG with three key techniques to reduce overestimation bias and improve stability:

#### 1. Clipped Double Q-Learning

```

```

TD3 maintains two Q-networks and uses the minimum Q-value for computing targets cleanrl/td3_continuous_action.py242-243

Sources: cleanrl/td3_continuous_action.py172-175 cleanrl/td3_continuous_action.py239-248

#### 2. Delayed Policy Updates

The actor network is updated less frequently than the critic networks (default: every 2 critic updates) cleanrl/td3_continuous_action.py255

Sources: cleanrl/td3_continuous_action.py255-267

#### 3. Target Policy Smoothing

TD3 adds clipped noise to the target policy actions to smooth out Q-values over similar actions cleanrl/td3_continuous_action.py231-238

Key Hyperparameters:

  - policy_noise = 0.2 (scale of smoothing noise) cleanrl/td3_continuous_action.py 61-62

  - noise_clip = 0.5 (maximum absolute value of noise) cleanrl/td3_continuous_action.py 69-70

Sources: cleanrl/td3_continuous_action.py61-70 cleanrl/td3_continuous_action.py231-238

### TD3 vs DDPG Implementation Comparison

| Feature | DDPG | TD3 |
| File | ddpg_continuous_action.py | td3_continuous_action.py |
| Q-Networks | 1 ( qf1 ) | 2 ( qf1 , qf2 ) |
| Actor Update Frequency | Every step | Every policy_frequency steps (default: 2) |
| Target Action Noise | None | Gaussian with clipping |
