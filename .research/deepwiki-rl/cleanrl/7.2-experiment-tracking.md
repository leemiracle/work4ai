### Purpose and Scope

This document describes CleanRL's experiment tracking infrastructure, which provides both local and cloud-based monitoring of training metrics, hyperparameters, and agent behavior. CleanRL supports two tracking backends: TensorBoard for local visualization and Weights & Biases (W&B) for cloud-based experiment management.

All CleanRL algorithms include built-in experiment tracking with a consistent interface. TensorBoard tracking is always active, while W&B tracking is optional and activated via command-line flags.

Sources: cleanrl/ppo.py27-34 docs/get-started/experiment-tracking.md1-9

### TensorBoard Integration

#### Initialization and File Organization

TensorBoard tracking is initialized immediately after argument parsing. The run name is generated using the environment ID, experiment name, seed, and a timestamp cleanrl/ppo.py134

Run Name Generation:
`run_name = f"{args.env_id}__{args.exp_name}__{args.seed}__{int(time.time())}"`

The `SummaryWriter` logs to `runs/{run_name}` cleanrl/ppo.py147

Sources: cleanrl/ppo.py134-147 cleanrl/ppo_continuous_action.py149-162

#### Hyperparameter Logging

Hyperparameters are logged as markdown tables to TensorBoard using `writer.add_text` cleanrl/ppo.py148-151 This ensures every run's configuration is stored alongside its results.

Sources: cleanrl/ppo.py148-151 cleanrl/ppo_continuous_action.py163-166

### Weights & Biases Integration

#### Conditional Initialization

W&B is initialized only when `args.track` is True. CleanRL uses `sync_tensorboard=True` to automatically bridge TensorBoard logs to the W&B cloud dashboard cleanrl/ppo.py141

W&B Initialization Parameters:

  - project : Taken from args.wandb_project_name cleanrl/ppo.py 139

  - config : Stores all hyperparameters from vars(args) cleanrl/ppo.py 142

  - monitor_gym : Automatically tracks environment stats cleanrl/ppo.py 144

  - save_code : Uploads the training script for exact reproduction cleanrl/ppo.py 145

Sources: cleanrl/ppo.py135-146 docs/get-started/experiment-tracking.md3-9

### Video Capture

Video capture is implemented using gymnasium's `RecordVideo` wrapper. To save compute and storage, it is typically applied only to the first environment (`idx == 0`) in a vectorized setup cleanrl/ppo.py83-85

Implementation:

  - env = gym.make(env_id, render_mode="rgb_array") cleanrl/ppo.py 84

  - env = gym.wrappers.RecordVideo(env, f"videos/{run_name}") cleanrl/ppo.py 85

When W&B is enabled, these videos are automatically detected and uploaded to the run dashboard docs/get-started/experiment-tracking.md3-4

Sources: cleanrl/ppo.py81-91 cleanrl/ppo_continuous_action.py87-103

### Post-Experiment Analysis

CleanRL provides utilities for aggregating and plotting data from W&B across multiple seeds and experiments.

  - cleanrl_utils/plot.py : A script to fetch data from W&B using the wandb.Api() cleanrl_utils/plot.py 44 and generate comparison plots using seaborn cleanrl_utils/plot.py 137

  - Smoothing : Both plot.py and paper_plot.py implement exponential moving average smoothing for clearer visualization of training trends cleanrl_utils/plot.py 119-127

  - Caching : The plotting scripts cache W&B data locally in cache.pkl to speed up repeated plot generation cleanrl_utils/plot.py 69-72

Sources: cleanrl_utils/plot.py17-44 cleanrl_utils/paper_plot.py17-68
