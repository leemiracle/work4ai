This document provides a detailed technical explanation of the Soft Actor-Critic (SAC) algorithm as implemented in CleanRL. SAC is an off-policy actor-critic reinforcement learning algorithm that incorporates entropy regularization for improved exploration and sample efficiency. CleanRL provides implementations for both continuous and discrete action spaces, allowing SAC to be applied to a wide range of environments from control tasks to Atari games.

For information about related algorithms like DDPG and TD3, see DDPG and TD3.

### Algorithm Overview

Soft Actor-Critic (SAC) extends the DDPG algorithm by using a stochastic policy and incorporating entropy regularization docs/rl-algorithms/sac.md5-7 This serves as a built-in, state-dependent exploration heuristic. Additionally, it uses two Soft Q-networks to reduce the overestimation bias issue common in Q-learning methods docs/rl-algorithms/sac.md7-8

### Implementation Variants

CleanRL provides two primary implementations of SAC:

  - Continuous Action SAC ( sac_continuous_action.py ): Designed for Box action spaces, commonly used in MuJoCo cleanrl/sac_continuous_action.py 188-190

  - Discrete Action SAC ( sac_atari.py ): Adapted for discrete action settings like Atari, using a categorical policy cleanrl/sac_atari.py 164-172

### Network Architecture

SAC utilizes an actor-critic architecture with twin Q-networks to address overestimation bias.

#### Continuous Action Space Architecture

In `sac_continuous_action.py`, the networks are defined as follows:

  - SoftQNetwork : A Multi-Layer Perceptron (MLP) that concatenates state and action inputs to predict a single Q-value cleanrl/sac_continuous_action.py 84-99

  - Actor : An MLP that outputs the mean and log_std of a Gaussian distribution cleanrl/sac_continuous_action.py 106-137 It uses a reparameterization trick (rsample) to allow gradients to flow through the stochastic sampling process cleanrl/sac_continuous_action.py 143

#### Discrete Action Space Architecture

In `sac_atari.py`, the architecture is adapted for image inputs:

  - SoftQNetwork : Uses a CNN encoder (Nature DQN style) followed by linear layers to output Q-values for all possible discrete actions cleanrl/sac_atari.py 112-135

  - Actor : A separate CNN encoder that outputs logits for a Categorical distribution cleanrl/sac_atari.py 138-162 Note: Sharing encoders between actor and critics is discouraged in SAC as actor gradients can degrade the representation cleanrl/sac_atari.py 109-111

### Key Implementation Specifics

#### Reparameterization and Tanh Squashing

For continuous actions, SAC samples from a Normal distribution and applies a `tanh` transformation to keep actions within bounds cleanrl/sac_continuous_action.py144-145 The log-probability is adjusted to account for this transformation cleanrl/sac_continuous_action.py148-149

#### Automatic Entropy Tuning (Autotune)

CleanRL implements automatic tuning of the entropy coefficient $\alpha$ by default cleanrl/sac_continuous_action.py65-66 The agent learns the optimal $\alpha$ by minimizing a dedicated alpha loss, ensuring the policy maintains a target entropy cleanrl/sac_continuous_action.py203-213 cleanrl/sac_continuous_action.py296-304

#### Optimization Details

  - Target Networks : Uses soft updates for target Q-networks via a smoothing coefficient tau (default 0.005) cleanrl/sac_continuous_action.py 49-50 cleanrl/sac_continuous_action.py 321-325

  - Learning Rates : Typically uses $3 \times 10^{-4}$ for the policy and $1 \times 10^{-3}$ for Q-networks cleanrl/sac_continuous_action.py 55-58

  - Delayed Policy Updates : The policy and entropy coefficient are updated less frequently than the Q-networks (controlled by policy_frequency ) cleanrl/sac_continuous_action.py 59-60 cleanrl/sac_continuous_action.py 282-284
