This page covers the implementation details of advanced reinforcement learning algorithms in the CleanRL repository. These algorithms extend beyond the core methods by introducing novel mechanisms such as auxiliary training phases, distributional value estimation, robust policy optimization, and imitation learning.

### Phasic Policy Gradient (PPG)

Phasic Policy Gradient (PPG) separates policy and value function training by introducing an auxiliary phase. It alternates between a Policy Phase (standard PPO) and an Auxiliary Phase that distill knowledge and optimize value functions using stored rollouts.

#### Algorithm Flow and Architecture

PPG uses a shared backbone with three heads: a policy head, a value head, and an auxiliary value head.

```

```

#### Implementation Details

  - Auxiliary Buffer : Unlike PPO, PPG stores experiences in aux_obs and aux_returns over multiple iterations to be used during the auxiliary phase cleanrl/ppg_procgen.py 255-275

  - Joint Loss : During the auxiliary phase, the agent minimizes a joint loss comprising the KL divergence between the current and old policy (behavior cloning) and the auxiliary value loss cleanrl/ppg_procgen.py 440-475

  - Normalized Initialization : PPG uses a specific initialization scheme where weights are divided by their L2 norm and scaled cleanrl/ppg_procgen.py 101-105

### Categorical DQN (C51)

C51 models the distribution of returns rather than just the expected value. It uses a set of `n_atoms` to represent the probability mass function (PMF) of the value distribution.

#### Distributional Update Logic

The core of C51 is the projection of the Bellman update onto the fixed support (atoms).

```

```

#### Key Implementation Features

  - Support (Atoms) : The support is defined as a linear space from v_min to v_max cleanrl/c51.py 99-100

  - Projection : In JAX, the projection is handled by calculating the indices l and u (lower and upper bounds) for the Bellman-updated atoms and distributing probability mass cleanrl/c51_jax.py 181-215

  - Network Output : The network outputs action_dim * n_atoms which is reshaped and softmaxed to produce valid probabilities cleanrl/c51_atari.py 128-134

Sources: cleanrl/c51.py94-116 cleanrl/c51_jax.py176-220 cleanrl/c51_atari_jax.py113-133

### Robust Policy Optimization (RPO)

RPO is a variant of PPO designed for continuous control. It introduces stochasticity into the policy during the optimization phase to improve robustness.

#### Stochastic Policy Update

In RPO, during the `get_action_and_value` call used for optimization, a random noise vector `z` (scaled by `rpo_alpha`) is added to the action mean.

```

```

  - Alpha Parameter : The rpo_alpha controls the range of the uniform noise added to the action mean cleanrl/rpo_continuous_action.py 109-111

  - Noise Injection : The noise is sampled using torch.uniform_(-self.rpo_alpha, self.rpo_alpha) cleanrl/rpo_continuous_action.py 140-141

### QDagger (Q-Distillation)

QDagger is a distillation algorithm where a "Student" DQN model learns from a "Teacher" model (often a pre-trained high-performance agent).

#### Distillation Process

  - Teacher Loading : The teacher model is downloaded from HuggingFace cleanrl/qdagger_dqn_atari_impalacnn.py 87-90

  - KL Divergence Loss : The student minimizes a distillation loss (KL Divergence) between the teacher's Q-logits and the student's Q-logits cleanrl/qdagger_dqn_atari_impalacnn.py 192-194

### Random Network Distillation (RND)

RND provides an exploration bonus by training a predictor network to mimic a fixed random target network. The prediction error serves as an intrinsic reward.

  - Curiosity Reward : The intrinsic reward is the MSE between the predictor and target networks cleanrl/ppo_rnd_envpool.py 70-72

  - Normalization : Observations are normalized using running statistics before being fed to the RND networks cleanrl/ppo_rnd_envpool.py 77-79

Sources: docs/rl-algorithms/ppo-rnd.md68-79

### Parallel Q-Network (PQN)

PQN is a simplified DQN variant that removes the target network and replay buffer, using parallel environments and Q(λ) returns for stability.

  - Architecture : Uses LayerNorm after layers to stabilize training without a target network cleanrl/pqn.py 88-104

  - Q(λ) : Combines n-step returns and current estimates cleanrl/pqn.py 198-215

Sources: cleanrl/pqn.py88-104 docs/rl-algorithms/pqn.md
