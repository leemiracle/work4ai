This page provides technical instructions for installing CleanRL and its dependencies. CleanRL utilizes `uv` for modern, high-performance dependency management while maintaining compatibility with `pip` via generated requirements files.

### System Requirements

CleanRL requires Python 3.8 to 3.10 pyproject.toml6 It is designed for high-quality single-file implementations that can scale from local machines to cloud clusters README.md15-21

#### Using uv (Recommended)

`uv` is the primary tool for managing CleanRL environments. It provides significantly faster installation and reliable dependency resolution docs/get-started/installation.md6
