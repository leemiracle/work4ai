This page documents CleanRL's integration with Procgen (Procedurally Generated) environments and the Phasic Policy Gradient (PPG) algorithm. Procgen is a benchmark suite designed to measure generalization in reinforcement learning by providing procedurally generated game levels with fixed mechanics but unlimited variations.

Key Characteristics:

  - 16 procedurally generated game environments cleanrl/ppo_procgen.py 39

  - Designed to test generalization, not memorization.

  - RGB observations (64×64×3) cleanrl/ppo_procgen.py 129-130

  - Discrete action spaces cleanrl/ppo_procgen.py 143

  - Configurable difficulty modes: easy , hard cleanrl/ppo_procgen.py 191

  - Native vectorization support cleanrl/ppo_procgen.py 191

### 5. Phasic Policy Gradient (PPG) Specifics

PPG separates the training into a Policy Phase and an Auxiliary Phase to mitigate the interference between policy and value function learning.

#### 5.1 Training Loop Logic

PPG iterates through `num_phases` cleanrl/ppg_procgen.py95 Each phase consists of:

  - Policy Phase : Runs for n_iteration cleanrl/ppg_procgen.py 73 It performs standard PPO-like updates and stores observations and returns in aux_obs and aux_returns cleanrl/ppg_procgen.py 274-277

  - Auxiliary Phase : Runs for e_auxiliary epochs cleanrl/ppg_procgen.py 79 It optimizes a joint loss to distill the policy and improve the value function.

#### 5.2 Auxiliary Phase Data Flow

During the auxiliary phase, CleanRL samples from the stored rollouts.

### 6. Generalization Testing

The primary goal of the Procgen integration is to evaluate generalization across procedurally generated levels.

#### 6.1 Configuration for Generalization

To test generalization, CleanRL scripts allow configuring the number of levels:

  - Training : Often done on a fixed set (e.g., num_levels=200 ) or unlimited ( num_levels=0 ) cleanrl/ppo_procgen.py 191

  - Evaluation : Performed on a separate set of levels (e.g., start_level=1000 ) to ensure the agent hasn't simply memorized the training seeds.

#### 6.2 Implementation Utilities

CleanRL includes helper functions to manage the high-dimensional data typical of Procgen:

  - flatten01(arr) : Flattens the environment and step dimensions for batch processing cleanrl/ppg_procgen.py 108-109

  - unflatten01(arr, targetshape) : Restores the original dimensions cleanrl/ppg_procgen.py 112-113
