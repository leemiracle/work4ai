This page documents CleanRL's implementation of reinforcement learning algorithms for continuous control, specifically focusing on MuJoCo physics environments. It covers core components, architectures, and implementation details common across different continuous control algorithms in the repository, including integration with `dm_control` via `Shimmy`.

### Introduction to MuJoCo and Continuous Control

MuJoCo (Multi-Joint dynamics with Contact) is a physics engine designed for robotics and biomechanics simulation. Continuous control involves producing real-valued action vectors, requiring algorithms to handle infinite action spaces. CleanRL implements several key algorithms for these tasks:

  - DDPG (Deep Deterministic Policy Gradient): cleanrl/ddpg_continuous_action.py

  - TD3 (Twin Delayed Deep Deterministic Policy Gradient): cleanrl/td3_continuous_action.py

  - SAC (Soft Actor-Critic): cleanrl/sac_continuous_action.py

  - PPO for continuous actions: cleanrl/ppo_continuous_action.py

Sources: cleanrl/ddpg_continuous_action.py1-46 cleanrl/td3_continuous_action.py1-46 cleanrl/sac_continuous_action.py1-40 cleanrl/ppo_continuous_action.py1-44

### Environment Setup and dm_control Integration

CleanRL uses `gymnasium` for environment management. For `dm_control` environments, it utilizes `Shimmy` to provide a Gymnasium-compatible interface. The `make_env` utility in continuous PPO demonstrates a robust pipeline for preparing these environments.

### Algorithm Comparison

| Feature | PPO (Continuous) | SAC | TD3 |
| Action Type | Stochastic (Gaussian) | Stochastic (Gaussian) | Deterministic + Noise |
| Exploration | Entropy + Gaussian Sampling | Entropy Maximization | Gaussian Action Noise |
| Architecture | 1 Actor, 1 Critic | 1 Actor, 2 Critics | 1 Actor, 2 Critics |
| Optimization | On-policy (GAE) | Off-policy (Maximum Entropy) | Off-policy (Target Smoothing) |
| Action Rescaling | Via Wrappers/Normal | Internal to Actor class | Internal to Actor class |
