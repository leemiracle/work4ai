This document covers TorchRL's integration with external reinforcement learning environment libraries. It explains how TorchRL provides unified interfaces to popular RL environment ecosystems including OpenAI Gym/Gymnasium, VMAS, Brax, Jumanji, and IsaacGym through wrapper classes and spec conversion systems.

For information about the base environment interface that all environments conform to, see Environment Base Classes. For details about environment transforms and data preprocessing, see Environment Transforms.

### Gym/Gymnasium Integration

The Gym integration is the most comprehensive, supporting both the legacy `gym` library and the modern `gymnasium` library through a backend management system.

#### Backend Management

TorchRL provides `set_gym_backend()` and `gym_backend()` functions to manage which Gym library is used:

| Function | Purpose |
| set_gym_backend(backend) | Sets the Gym backend ("gym" or "gymnasium") |
| gym_backend(submodule=None) | Returns the current backend or a submodule |
| implement_for decorators | Version-specific implementations |

#### Gym Wrapper Classes

| Class | Purpose | Base Class |
| GymWrapper | Wraps existing gym environments | GymLikeEnv |
| GymEnv | Creates gym environments by name | GymWrapper |
| MOGymWrapper | Multi-objective gym wrapper | GymWrapper |
| MOGymEnv | Multi-objective gym environment | MOGymWrapper |

### Spec Conversion Patterns

All environment library integrations follow common patterns for converting between library-specific specifications and TorchRL's `TensorSpec` system.

#### Common Conversion Patterns

| Library Space Type | TorchRL Spec | Conversion Logic |
| Discrete/Categorical | Categorical or OneHot | Based on categorical_action_encoding |
| Multi-discrete | MultiCategorical or MultiOneHot | Preserves discrete structure |
| Continuous/Box | Bounded or Unbounded | Based on bound values |
| Binary | Binary | Direct mapping |
| Dict/Composite | Composite | Recursive conversion |

### JAX Integration Utilities

For JAX-based libraries (Brax, Jumanji), TorchRL provides utilities for seamless data conversion between JAX and PyTorch.

#### JAX-PyTorch Conversion Functions

| Function | Purpose |
| _ndarray_to_tensor() | Converts JAX/NumPy arrays to PyTorch tensors |
| _tensor_to_ndarray() | Converts PyTorch tensors to JAX arrays |
| _object_to_tensordict() | Converts JAX objects to TensorDict |
| _tensordict_to_object() | Converts TensorDict to JAX objects |
| _tree_flatten() , _tree_reshape() | Handles batch dimension manipulation |
