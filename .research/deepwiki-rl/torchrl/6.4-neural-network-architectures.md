This page documents the neural network building blocks and architectures available in TorchRL for reinforcement learning applications. These components provide the foundation for policy networks, value functions, and other neural network components used in RL algorithms.

For information about higher-level policy and critic implementations that use these architectures, see Actors and Critics. For probability distributions used with these networks, see Probability Distributions.

### Core Network Building Blocks

TorchRL provides several fundamental neural network architectures that serve as building blocks for more complex RL networks.

#### Multi-Layer Perceptrons (MLPs)

The `MLP` class provides a flexible multi-layer perceptron implementation with extensive customization options. It supports lazy initialization, various activation functions, normalization layers, and dropout.
