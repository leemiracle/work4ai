Probability distributions are a cornerstone of reinforcement learning algorithms, particularly for representing stochastic policies, implementing exploration strategies, and enabling entropy regularization. This page documents the probability distribution implementations provided by TorchRL, which extend PyTorch's base distribution classes with features specifically designed for reinforcement learning applications.

These distributions integrate with TorchRL's TensorDict data structure and are primarily used with the `ProbabilisticTensorDictModule` class documented in TensorDict Modules.

TorchRL provides various types of probability distributions organized into three main categories:

#### Continuous Distributions

These distributions are designed for continuous action spaces:

| Distribution | Description | Key Properties |
| IndependentNormal | Normal distribution with location scaling | Prevents numerical instability with scaling |
| TanhNormal | Tanh-transformed normal distribution | Bounds outputs to a specified range |
| TruncatedNormal | Normal distribution truncated to specific bounds | Hard constraints on output range |

Sources: torchrl/modules/distributions/continuous.py46-104 torchrl/modules/distributions/continuous.py304-519 torchrl/modules/distributions/continuous.py138-286

#### Discrete Distributions

These distributions handle discrete action spaces:

| Distribution | Description | Key Properties |
| OneHotCategorical | One-hot encoded categorical distribution | Returns one-hot vectors instead of indices |
| MaskedCategorical | Categorical with masked invalid actions | Prevents sampling of invalid actions |
| MaskedOneHotCategorical | One-hot encoded masked categorical | Combines masking with one-hot encoding |
| Ordinal | Distribution for ordered finite sets | Preserves order information |
| OneHotOrdinal | One-hot encoded ordinal distribution | One-hot version of ordinal |
| LLMMaskedCategorical | LLM-optimized masked categorical | Optimized for language model applications |

#### Deterministic Distributions

These specialized distributions represent deterministic policies:

| Distribution | Description | Key Properties |
| Delta | Deterministic (Dirac delta) distribution | Always returns the same value |
| TanhDelta | Tanh-transformed deterministic distribution | Deterministic with bounded outputs |

#### Numerical Stability

RL algorithms often generate extreme values that can cause numerical instability. TorchRL implements several safeguards:

  - Location scaling in distributions like IndependentNormal prevents numerical issues:

  - Safe transformations like SafeTanhTransform ensure invertibility:

  - Numerical stability utilities in utils.py : safetanh_noeps and safeatanh_noeps functions prevent overflow/underflow _SafeTanhNoEps and _SafeaTanhNoEps autograd functions with proper gradients FasterTransformedDistribution optimized for compilation

  - Epsilon handling in distributions: TruncatedNormal uses eps = 1e-6 for numerical bounds Delta distribution uses atol and rtol for equality comparisons

### Summary

TorchRL's probability distributions extend PyTorch's distribution classes with features essential for reinforcement learning:

  - Bounded distributions for constraining actions to valid ranges

  - Numerically stable implementations to prevent training issues

  - Consistent interface for exploration/exploitation balance

  - Masking support for handling invalid actions

  - Reparameterization strategies for gradient computation with discrete actions

These distributions form a key component of the TorchRL ecosystem, enabling the implementation of various RL algorithms with a clean, consistent API.
