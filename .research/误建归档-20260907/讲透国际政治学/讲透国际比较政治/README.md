# 讲透国际比较政治 · 对外行为的国内根源

> 支：[讲透国际政治学](../README.md)（GB/T 81040 三级：国际比较政治）。
> 一句话：**外交是内政的延长线**——同一套国际压力，不同政体
> 接出不同的对外行为（国际比较=对外的比较政治学）。

## 定位句

本支负责**各国对外政策的比较研究**：second-image（国内政治→
对外行为）与 second-image reversed（体系→国内）的双向通道、
政体类型与对外行为（民主和平的机制层）、国内观众成本
（audience costs）、利益集团与对外经济政策。

## 诞生与关键事件

- 1976 Putnam"两层博弈"（Two-Level Game, 1988 正式）：
  谈判者同时面对国际桌与国内批准桌
- 1981 Fearon"民主和平的观众成本"（1994 论文化）：
  民主国家公开威胁的信号更可信
- 1990s 民主和平的机制之争（制度约束 vs 规范认同 vs 利益）
- 2000s IPE 的利益集团转向；2010s- 国内政治经济学的
  民粹化研究（贸易保护的政治回潮）

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 民主和平的因果机制（制度/规范/利益） | 🔄 现象锁定、机制三家竞答 |

| 民粹主义如何改写对外政策（贸易/联盟） | 🔄 2016 后显学 |
| 威权政体的对外承诺可信性 | 🔄 新兴比较威权-IR 交叉 |

## 这支最美的一个事实

Putnam 两层博弈的"温塞特集"（win-set）：国际协议能否批准，
取决于国内可接受方案集合的大小——**谈判力强的国家往往是
国内最难说话的国家**（"被国会绑架"反而是筹码）——国际谈判
教室里最反直觉的一课。

## 假设与依赖

国内政治可观测可编码（政体/选举/利益集团指标）、国际-国内
两层可联立建模、dyad 样本独立性假设（同盟传染= SUTVA 破坏，
家族 [03 章](../../03-可构造与结构.md)）。
