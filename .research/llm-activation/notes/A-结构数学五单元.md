## 1. 讲透激活函数（11 md）

**对「激活能力」主题的独特贡献**
1. 厘清了「激活」一词的两层含义：神经元层面的激活（activation = f(z) 的输出，0/1 掩码决定信息是否流过）vs 能力层面的激活（让已有权重表达能力）。前者是后者的微观机制基础——梯度门控决定哪些通路可被训练，进而决定哪些能力可被解锁。
2. 给出「能力表达的结构前提」的最小数学证明：没有非线性，任意深度坍缩为单层线性，深度红利为零——即 L0 规模堆叠若无非线性结构，能力根本不随规模涌现。
3. SwiGLU 证明「门控 = 按需激活」的结构版本：FFN 的每个 token 动态决定打开哪些特征通路（软路由），这是 L3 架构接入思想（MoE 硬路由的先声）在 LLM 内部的最早落点。
4. 激活函数四代演进 = 一部「表达能力 ↔ 梯度可传性 ↔ 部署成本」的三角妥协史，为能力激活提供了「结构选型影响能力上限」的实例。

**核心数学/结构事实**
- 线性坍缩：两层串联 $y = W_2(W_1x+b_1)+b_2 = (W_2W_1)x + (W_2b_1+b_2)$，合成后仍是单层仿射——纯线性网络 10 层等价 1 层。实测纯线性网络拟合 sin 的 MSE=0.1994，加一个 ReLU 后 MSE=0.000005（差 4 万倍）。锚点：`00-为什么需要激活函数.md:40-43`（代数推导）、`00-为什么需要激活函数.md:64-68`（实验数字）。
- ReLU 反向 = 掩码乘：$\partial L/\partial X = \partial L/\partial Y \odot M$，$M=(X>0)$ 为 0/1 布尔掩码；框架只缓存掩码（比 float32 输入省 4 倍），且可从输出 $Y>0$ 反推掩码、无需保留输入。锚点：`01-ReLU自动微分与反向传播.md:76`（"ReLU 的导数就是一个 0/1 掩码"）、`:113-115`（缓存优化）。
- 梯度消失的定量：Sigmoid 导数 $\sigma'(x) \le 0.25$，连乘 20 层 $0.25^{20} \approx 9\times10^{-13}$；ReLU 正轴导数恒 1，正轴完全无梯度衰减。锚点：`03-激活函数家族综述.md:34`、`02-为0与为1发生了什么.md:125-131`。
- Dead ReLU：神经元输入恒负 → 梯度恒 0 → 权重永不更新（神经元死亡）；但「权重绝对不变」仅在纯 SGD 无正则时成立，动量/权重衰减仍会推动权重（优化器惯性特例）。锚点：`02-为0与为1发生了什么.md:41-54`、`:73-99`。
- 四代家族：Sigmoid/Tanh（饱和，梯度消失）→ ReLU/Leaky/ReLU6（分段线性）→ GELU $x\cdot\Phi(x)$ / SiLU $x\cdot\sigma(x)$（平滑自门控）→ SwiGLU（GLU 变体，现代 LLM 事实标准）。锚点：`03-激活函数家族综述.md:11-16`（四代表）。
- SwiGLU 数学形式：$\text{SwiGLU}(X) = \text{Swish}(XW_{\text{gate}}) \odot (XW_{\text{up}})$——输入投影到两个空间，门决定放多少、值决定放什么，是「动态软路由」：每个样本每个位置网络自己决定哪些特征通路打开。Scaling Law 论文证明其参数利用效率显著高于 FFN+ReLU/GELU。锚点：`06-SwiGLU底层Kernel.md:26-35`。
- SwiGLU 工程事实：朴素实现 3 个中间张量 6 次穿越 HBM（~6.3MB），CUTLASS Epilogue 寄存器级融合后仅写回最终结果（~1.0MB，理论 ~6x）；硅片视角下 SwiGLU = 「带特殊收尾的单次 GEMM」。锚点：`06-SwiGLU底层Kernel.md:143-147`、`:115-120`。
- 选型实证：Sigmoid 收敛 57 步 vs Tanh/GELU 2 步（慢 10-28 倍）；输出层选错（回归用 Sigmoid）则模型物理性无法表达目标。锚点：`README.md:99-113`（实验 07）。

**一句话判断**：属 **L3 架构接入的微观基础 + 新增维度「能力可训练性」**——非线性结构是 L0 涌现的前提条件（无线性坍缩则无涌现），SwiGLU 门控是 L3 按需激活在 FFN 内的最早形态。

## 2. 讲透KV Cache（9 md）

**对「激活能力」主题的独特贡献**
1. 给出「注意力记忆的数学结构」：Q 用完即弃 / K-V 是历史档案的键值分离，这是长上下文能力的结构基础——没有 KV Cache，自回归推理每步重算，长上下文能力在算力上不可激活。
2. 精确的显存账公式揭示：L1 推理时激活（长 prompt、多轮对话）的成本结构由 KV Cache 主导，2024-2026 瓶颈从算力转为「KV Cache 装不下」。
3. MLA 展示了「表示效率决定能力可部署性」：DeepSeek-V3 若无 MLA（低秩 latent 压缩），65k 上下文 MoE 物理上不可部署——能力激活受架构表示效率硬约束。

**核心数学/结构事实**
- 键值分离的根据：$\text{out}_i = \text{softmax}(Q_iK_{1:i}/\sqrt{d})V_{1:i}$ 只需历史 K/V、不需历史 Q——Q 是即时查询，K/V 是历史档案。锚点：`00-为什么KV Cache是推理的生命线.md:38-54`。
- 复杂度账：无 cache 累计 $O(n^2d^2)$（投影），有 cache 降到 $O(nd^2)$——投影部分的数量级胜利；实测生成 200 token 累计 FLOPs 加速 39.3x。锚点：`00:66-76`（推导）、`:87-93`（实测）。
- 显存公式：$\text{KV Cache} = 2\cdot b\cdot s\cdot L\cdot H_{\text{kv}}\cdot d_h\cdot \text{bpp}$。Llama-3-8B 8k 上下文单请求 1.07GB；GQA→MHA 变大 4 倍（KV 头数 8→32）；FP16→INT4 降到 1/4。锚点：`01-KV Cache的数学与内存账.md:27`（公式）、`:37-47`（验证）、`:60-78`（思考题答案）。
- prefill/decode 二相性：prefill 是 (s,s) 方阵 compute-bound（算术强度 2048），decode 是 (1,s) 向量 memory-bound（算术强度 ≈ 1，差 2048x）——每个 KV 元素只被用 1 次却必须全部从 HBM 读出。由此推出 FlashAttention（减访存不减 FLOPs）、投机解码（用闲置算力）、PD 分离三大优化方向。锚点：`01:118-156`（表+推导+三推论）。
- 反直觉账：DeepSeek-V3 朴素 KV 单请求 393GB、batch=32 要 12.5TB——地球上没单机能装；MLA 压到 4.61GB。锚点：`00:130-147`、`01:85-95`。
- MLA 数学骨架：$c = W^{DKV}h$（latent 维 $d_c$=512），attention 时上采 $K=W^{UK}c,\ V=W^{UV}c$；每 token 每层只存 $d_c$ 维而非 $2n_{kv}d_h$ 维（24576 维），压缩 13-90x。关键：GQA 是「共享头」（聚类思路），MLA 是「投影到低秩空间」（表示学习思路），质变非量变。RoPE 与低秩冲突 → K 拆两段（压一部分 + 留一小撮 64 维位置部分）。锚点：`04-MLA深挖.md:27-47`、`:74`（GQA vs MLA 费曼回炉）。
- MLA 代价：存储成本换成计算成本（attention 多一次上采矩阵乘），短序列（<256 token）反而更慢。锚点：`04-MLA深挖.md:58-60`。

**一句话判断**：属 **L1 推理时激活的结构基础**——长上下文/多轮对话能力能否在推理时被激活，由 KV 分离结构 + 显存账 + 表示压缩（MLA）共同决定；MLA 部分属于 L3（架构接入决定能力可部署性）。

## 3. 讲透上下文缓存（7 md）

**对「激活能力」主题的独特贡献**
1. 前缀复用改变推理成本结构：system prompt / few-shot 等「能力激活载体」（L1 的 prompt 前缀）通过缓存从边际成本项变为固定成本项——prompt caching 是 L1 激活手段的经济学放大器。
2. 给出命中/未命中/过期的完整失败模式学：缓存只认字面前缀、不认语义（「无思考的负熵」），界定了推理时激活中「可缓存的确定性部分」与「必须重算的语义部分」。
3. RAG vs 长上下文 vs 缓存的三角权衡，是「用什么结构激活知识」的决策框架。

**核心数学/结构事实**
- 摊销的精确表述：无 cache 总复杂度 $O(n^2)+O(n^2)$，有 cache $O(n^2)+O(n)$——渐进相同，差别全在常数项（decode 每 token 从 O(n) 降到 O(1)），但 decode 是主要时间，实际延迟降一个量级。锚点：`02-数学-KV Cache与缓存命中.md:15-24`。
- 命中成本模型：$C_{\text{hit}} = p\cdot c_{\text{write}} + u\cdot c_{\text{input}} + o\cdot c_{\text{output}}$；Anthropic 定价 $c_{\text{write}}=1.25c_{\text{input}}$，$c_{\text{cache\_read}}=0.1c_{\text{input}}$。盈亏平衡：$1.25+0.1k < (k+1)$ → $k>0.28$ → **命中 1 次就划算**，cache read 比 input 便宜 90%。锚点：`02:45-55`、`05-应用-缓存经济学.md:27-29`。
- 语义缓存的数学：命中概率 $P(\text{hit}\mid\text{rel}) = \Phi((\tau-\mu_{\text{rel}})/\sigma)$，阈值 τ 高则精度高召回低、低则灾难性假命中；生产经验 τ≈0.95 起步且必须 A/B。锚点：`02:74-84`。
- PagedAttention 分页：KV 空间按 block（16 token/block）切分 + block table 映射，公共前缀物理共享（copy-on-write），吞吐 2-4x——OS 虚存思想在 LLM 推理的复活。锚点：`02:86-99`。
- 核心洞察：「缓存是无思考的负熵」——只认前缀相同不理解语义；**prompt caching 解决重复，语义缓存试图解决相似（危险），长期记忆才解决理解**，三者是认知复杂度递进。锚点：`README.md:59`、`05:77-79`。
- 失效条件硬约束：5 分钟 TTL；前缀改一字全失效（确定性前缀匹配的脆弱性）。锚点：`README.md:48-55`（厂商对比表）。
- Augment 60 万 token 启示：长 context 的竞争力不在窗口大小，在 context 管理（大规模语义索引 + 智能检索 + 缓存）。锚点：`05:69-71`。

**一句话判断**：属 **L1 推理时激活的成本经济学层**——不改变能力本身，改变激活能力的边际成本；与 KV Cache 单元构成「机制 ↔ 经济学」互补对。

## 4. 讲透MRL（10 md，Matryoshka Representation Learning）

**对「激活能力」主题的独特贡献**
1. 提供了「表示能力按需截取」的数学完整样本：一个编码器训练一次，部署时按需取前 m 维——这是「能力激活」在**表示层**的版本（激活多少表示精度由部署时决定，而非训练时固定）。
2. 训练时多目标嵌套损失（loss 改造）= L2 训练侧激活的一个具体机制：不改架构不改数据，只在损失函数上做文章就解锁了「多粒度部署能力」。
3. 界定了「激活」与「压缩」的边界：MRL 权重一个字节不变、推理不变慢——它激活的不是新能力而是**已有能力的可裁剪性**（截断悬崖：80% 内几乎无损，>80% 崩）。

**核心数学/结构事实**
- MRL 嵌套损失：$\mathcal{L}_{\text{MRL}}(\theta) = \frac{1}{|\mathcal{M}|}\sum_{m\in\mathcal{M}} c_m\cdot\mathcal{L}_{\text{base}}(\theta;m)$，在嵌套维度 $\mathcal{M}=\{8,...,768\}$ 上同时算 loss，强迫前 m 维也是好嵌入。锚点：`02-MRL数学.md:39-55`。
- 三角度解释：信息论（前 m 维须区分 $O(2^m)$ 个语义类别）、几何（超球面 $\mathbb{S}^{d-1}$ 上学嵌套子球面 $\mathbb{S}^{m-1}$）、梯度（低维 loss 反向影响前面维度权重）。锚点：`02:67-73`。
- 截断必须 renorm：单位向量截断后 $\|\mathbf{v}_{[:m]}\|<1$（768→128 维范数 0.627），不 renorm 时 L2 排序完全错乱（Recall@5 从 0.85 掉到 0.18，差 −67pp）。锚点：`01-直觉与几何.md:92-131`。
- 信息前置的物理证据：MRL 训练使前 1/8 维方差是后 1/8 维的 5 倍（0.0035 vs 0.0007）。锚点：`01:71-78`。
- 截断悬崖：50% 截断 Recall 0.998（几乎无损），95% 截断 0.62（悬崖）；<80% 无损、>80% 急剧下降是经验阈值。锚点：`01:189-201`。
- 2D-MRL（宽度+层数双嵌套）：$(m,\ell)$ 组合 (128,4) 只用 33% 层 + 17% 维 → 推理 FLOPs 6%——**MRL 唯一能真正缩小模型的变体**（标准 MRL 模型大小不变）。锚点：`02:91-123`。
- Matryoshka-Adaptor：冻结主干 + 小 MLP 残差 $\hat{\mathbf{z}} = \mathbf{z} + g_\phi(\mathbf{z})$，$W_2\leftarrow 0$ 初始化保证起点=原模型（<1% 参数）；因数据特异性甚至能在已 MRL 训练的模型上再涨 1-2pp。锚点：`02:132-152`、`:199-203`。
- 叠加性：MRL 截断与二进制量化正交可叠加（768d float32 → 128d binary 压缩 192×），但与 PQ 互相干扰。锚点：`01:227-233`、`README.md:107-116`（八条铁律）。

**一句话判断**：**新增维度「表示层按需激活」**——L2（训练时嵌套损失解锁）+ L3（部署时按需截取接入）的混合；与 L1/L2/L3 正交，是能力激活在嵌入空间的对偶版本。

## 5. 讲透复用权重（14 md）

**对「激活能力」主题的独特贡献**
1. 给出「能力可迁移的结构条件」：迁移的前提是源/目标共享通用特征（骨干 $\phi$ 通用、任务头 $g$ 特化）；什么阻断迁移——特征不兼容时负迁移，复用比从零更差。这直接界定了 L2 训练侧激活（SFT/LoRA）的可行域。
2. LoRA 证明「预训练模型内已存在的能力只需低秩补丁即可激活」：$\Delta W$ 本质低秩（内在维度低），微调是在低维子空间做任务特化——这是「激活已有能力」而非「注入新能力」的最强数学证据。
3. Scaling Laws 给 L0 规模涌现提供了幂律数学：loss 随 N、D 幂律下降 + Chinchilla 配比（D/N≈20），并诚实标注「loss ≠ 能力」——涌现争议的分析工具。
4. 成本摊销结构：预训练把「学通用特征」的昂贵成本摊到海量数据，下游只为「任务特化」付少量数据——这是 L2 激活比从零训练划算的经济学根源。

**核心数学/结构事实**
- 12 点实验（复用 vs 从零）：少样本下从零训练 0.850，复用源权重+微调 1.000——预训练范式的全部价值浓缩。锚点：`00-为什么复用权重.md:58-77`、`README.md:36-46`。
- 网络拆分与迁移三模式：$x \xrightarrow{\phi_\theta} \phi(x) \xrightarrow{g_w} y$；特征提取（冻骨干只训头，130 参数打赢从零 8642 参数）vs 微调（解冻）；经验法则数据 <1k 用特征提取、>1k 微调。锚点：`01-迁移学习全景.md:27-42`、`:50-72`。
- 负迁移（结构阻断条件）：领域差异大 / 任务冲突时复用反而差——真实案例：标准 make_moons 预训练骨干复用到旋转 60° 的 moons 比从零差。判断准则：「源任务学到的特征，对我的目标任务有道理吗？」锚点：`01:76-88`、`00:108-117`。
- LoRA 数学：$\Delta W = BA$，$B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times d}$、$r\ll d$，参数 $d^2 \to 2rd$（r=2,d=64 时 6%）；前向 $y=Wx+BAx$；$B$ 零初始化保证起点=原模型；训练完 $W+BA$ 可无损合并、推理零开销。实测 11.6% 参数达 100% 准确率（=全量微调）。锚点：`04-参数高效微调PEFT.md:29-52`、`:60-67`。
- 低秩假设的理论根据：微调的 $\Delta W$ 内在维度很低（Aghajanyan 2020 实证）——预训练已学好通用能力，微调只是低维子空间的任务特化调整。锚点：`04:92-96`。
- LoRA 边界：r 太小学不了大幅任务变化；某些任务（持续学习大跨度）全量微调明显更好。锚点：`04:98-103`。
- Scaling Laws 幂律：$L(N,D) \approx A/N^\alpha + B/D^\beta + L_\infty$，$\alpha,\beta\approx0.05\sim0.1$；Chinchilla：固定算力 $C\approx6ND$ 下 $N^*\propto C^{0.5}, D^*\propto C^{0.5}$，即每参数配约 20 token；GPT-3 D/N=1.7 属参数浪费，Chinchilla 70B/1.4T 用 40% 参数效果更好。锚点：`10-预训练ScalingLaws.md:18-48`。
- 批判锚点：幂律会饱和；数据墙（高质量文本有限）；**loss ≠ 能力**（推理、长程依赖不一定平滑缩放）；对齐阶段的缩放规律不如预训练干净。锚点：`10:93-98`。

**一句话判断**：横跨 **L0 + L2 + L3**——Scaling Laws 是 L0 的数学（+「loss≠能力」的警示）；迁移条件/LoRA 是 L2 训练侧激活的结构理论（激活已有能力 = 低秩调整）；LoRA/Adaptor 的「冻结主干+插小模块」形态与 L3 架构接入同构。

## 跨单元发现（3 条）

1. **「按需激活/按需截取」是贯穿五个单元的同一结构模式**：SwiGLU 门控（token 级软路由，`讲透激活函数/06:33`）、MLA latent 解压（用时再上采，`讲透KV Cache/04:33-37`）、MRL 按需截断（部署时取前 m 维，`讲透MRL/02:50`）、2D-MRL 按需减层（`讲透MRL/02:113-123`）、LoRA 冻结主干只训补丁（`讲透复用权重/04:29-33`）——全都是「大而全的结构 + 小而准的激活通道」。这与 L3 的 MoE 按需激活专家是同一家族：能力预先存在，激活是运行时的稀疏选择。
2. **低秩是三个单元独立收敛到的公共数学语言**：MLA 把 KV 联合压缩成低秩 latent（压缩 13-90x）、LoRA 假设 $\Delta W$ 低秩（参数 $d^2\to2rd$）、MRL 嵌套子球面本质是信息按维度低秩前置——「能力/记忆的可用自由度远小于其表观维度」是激活可能的数学根基。
3. **激活的经济学三角在单元间互补闭环**：上下文缓存给出命中成本模型（命中 1 次即划算，read 省 90%）、KV Cache 给出显存账（decode memory-bound，算术强度 ≈1）、复用权重给出成本摊销结构（预训练贵、下游激活廉）、Scaling Laws 给出源头配比（D/N≈20）——「激活 LLM 能力」不仅是算法问题，更是一条从预训练配比 → 训练侧低秩激活 → 推理时缓存摊销的完整成本链。
