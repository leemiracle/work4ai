## 1. 讲透泛化（10 md）——能力为什么"潜在"且能被兑现

### 对「激活能力」主题的独特贡献

1. **ICL = 泛化的第三次范式转移，是 L1 层最硬的理论定位**：GPT-3 的 in-context learning 打破"学习=改参数"范式——泛化可以在推理时涌现，不依赖训练时参数更新。理论界的三条解释路线：ICL=隐式梯度下降（Transformer 前向传播 ≈ 一层梯度下降，von Oswald 2022 / Akyürek 2022，部分验证限于线性回归）、ICL=隐式贝叶斯推断（Xie 2021）、in-weights + in-context 双重学习（Chan 2022）。（`HISTORY.md:330-348` §9 第三次范式转移）
2. **双层下降 = L0 规模涌现的理论根基**：过参数区（p>>n）测试误差不升反降——最小范数解随参数增多反而更平滑，"光滑=泛化"。实验数字：峰值 910 → 过参数区 5.3（N=3000，50 倍于样本数，降 171 倍）。（`03-双层下降.md:51-92` §二/§三）三条主线统一：过参数化给空间，SGD 隐式选简单解，结果是泛化（`03-双层下降.md:108-118` §五）。
3. **能力潜在性的解释：架构提供能力，不决定方向**——Zhang 2017 同一架构既能纯记忆随机标签（零泛化）也能泛化真实标签；泛化来自"数据真实结构 × 优化器偏好"的共同作用（`05-批判与未解.md:35-39` §2.3；`HISTORY.md:382-384` 反常识3）。即：潜在能力是数据结构与隐式正则共同写入权重的，不是架构的功劳。
4. **隐式正则 = 免费的能力写入器**：同模型闭式解测试 MSE 6.28 vs 梯度下降 0.029（差 219 倍），GD 甚至优于手调岭正则（λ=1e-6 给 0.038）——SGD 轨迹自带频率偏置/最小范数/大间隔三种偏好（`01-隐式正则.md:29-96` §二/§三）。

### 核心事实/数学

- 经典悖论：泛化误差 ≤ 训练误差 + O(sqrt(容量/n))，深度网络容量>>n 却泛化好（`README.md:24-27` 核心悖论）。
- 批判立场：五条主线无一完整，"我们能用，但不真懂"；界仍是空的（`05-批判与未解.md:7-19` §一）。
- 新现象清单直接对应该主题：grokking（训练收敛后泛化延迟突现，`05-批判与未解.md:45-49` §3.1）、ICL（`§3.2`）、涌现相变（`§3.3`）——三者都是"能力突然出现"，是 L0/L1 的理论空白区。
- OOD 是最深的洞：因果不变性（IRM）、DRO、预训练-微调迁移理论均未成熟（`HISTORY.md:351-364` §9.3）。

### 一句话判断

**为 L0（规模/过参数化为何良性）提供理论根基，同时把 L1（ICL）精确化为"前向计算如何泛化"的新理论问题——是四层谱系的"存在性证明"单元。**

## 2. 讲透微调（10 md）——L2 训练侧激活的数学与边界

### 对「激活能力」主题的独特贡献

1. **低秩假设 = "激活只需小旋钮"的数学**：微调的 ΔW 有效秩远小于 d（Aghajanyan 2020 本征维度），LoRA 用 ΔW=B·A 参数化，d=4096/r=8 时单层参数占比 0.4%（省 256 倍）；实验 r=1 用 5.9% 参数把 taskB 拟合到 0.0002 ≈ Full FT 0.0001。（`00-为什么LoRA能用1%参数逼近全参数微调.md:29-69` §2/§3）
2. **本征维度随预训练变强而缩小——L2 激活与 L0 能力的定量耦合**：预训练越强，微调所需有效参数越少（RoBERTa ~200 维即达全参数微调 90% 性能）；预训练把权重调到"好区域"，微调只需在低维流形上轻调。（`00-....md:75-81` §4；`01-LoRA数学深挖.md:67-77` §4）
3. **三选一决策边界（知识库内已收敛的稳定结论）**：改行为/风格/格式→微调（LoRA）；注知识/事实/最新→RAG；临时适应/可溯源→Prompt；常组合 LoRA+RAG。（`00-....md:104-119` §6；`README.md:54` 五大核心洞见第5条）
4. **激活的代价三联：灾难遗忘/过拟合/alignment tax**：lr 越大遗忘越重（实验 0.001→0.030 遗忘 0.9989→0.9997）；缓解=低 lr/LoRA 低秩约束/数据混合。alignment tax：SFT 对齐后通用能力下降（LLaMA-2 chat 版部分基准不如 base），缓解=SFT 数据混入通用能力维持数据。（`05-微调失败模式.md:9-93` §1/§3）

### 核心事实/数学

- W_new = W0 + (α/r)·BA，B∈R^{d×r}, A∈R^{r×d}, r<<d；推理时 BA 可合并回 W0，零额外延迟（`00-....md:39-45`）。
- **B=0 初始化 = 激活的"零起点保证"**：ΔW 起始严格为 0，训练从基座无损出发；A 必须高斯否则梯度死锁（A=0 时 B 拿不到梯度）（`01-LoRA数学深挖.md:17-38` §2）。
- α/r 缩放 = ΔW 强度旋钮，换秩只需调 α 复用超参（α=4/scale=1 收敛最好）（`01-....md:42-63` §3）。
- 低秩的失效边界：任务与预训练差异巨大（全新语言/模态）时 ΔW 不再低秩，必须 Full FT（`00-....md:83` §4 反向证据）。
- 评估纪律：必须同时看目标能力和原能力，否则把"变听话但变笨"误当成功（`05-....md:93` §5）。

### 一句话判断

**L2 训练侧激活的标准实现单元：低秩/本征维度证明"激活=在预训练好区域上的低维微调"；alignment tax 则揭示 L2 激活与 L0 原能力存在结构性张力。**

## 3. 讲透可解释性（12 md）——机制层面"激活"的直接证据

### 对「激活能力」主题的独特贡献

1. **Induction head = ICL 的物理基础（L1 激活的机制实证）**：Olsson 2022 跑遍 40+ transformer，凡 2 层以上 attention 几乎都自发长出 induction head（previous token head + induction head 两层协作，看到 [A][B]...[A] 预测 [B]）——few-shot 学新任务的能力本质是该 circuit 在工作；且在只训 100M token 的小模型上就出现，"ICL 在 transformer 上几乎是免费的"。（`03-Circuits与超级可解释性.md:11-17` 直觉层；`03-....md:186` 反直觉数字）
2. **能力在权重里的定位方法学**：circuit 判定金标准 = ablation 必要性（删 circuit → 功能大降）+ 充分性（只留 circuit → 功能保留）（`03-....md:54-62` §数学层）；经典战果：IOI circuit 26 head 完整回路（Wang 2022）、successor head。
3. **SAE：能力 = 稀疏特征字典**。superposition（N 个概念挤进 d<<N 维，靠几乎正交不混）导致单神经元多语义；SAE 赌注是存在更大稀疏 monosemantic 特征空间。Anthropic 2023 在单层模型挖出可命名特征（#1327 阿拉伯数字 / #4521 DNA / #712 比较级）；Claude 3 Sonnet 十亿维字典找到上千万特征（金鱼/背叛/代码 bug/奥斯汀）。（`02-稀疏自编码器SAE.md:19-38` + `02-....md:158`；损失 = 重建 + λ·L1，`02-....md:52-58`）
4. **Feature steering = 推理时机制化激活**：不改权重，推理时在残差流加 h+α·v_feature（v 取 SAE decoder 列），输出被因果引导；clamp 模式更稳（直接在 SAE 特征空间操作不混叠）。反直觉数字：单特征 clamp 后该概念概率从 ~0.1% 飙到 30%+ 而 perplexity 几乎不动——"高精度低扰动"。（`05-Scaling-Monosemanticity与激活导向.md:31-37` + `05-....md:120`）

### 核心事实/数学

- SAE recon loss 随 N_feat 幂律下降（β≈0.2-0.4）且无饱和拐点——概念密度比想象高（`05-....md:44-53` §数学层）。
- 边界诚实清单：steering 对低阶概念稳、对高阶抽象不稳；clamped 特征长 prompt 会"漂"（其他特征代偿——deceptive alignment 潜在通道）；interpretability illusion（SAE 特征是否模型真正使用，消融只能部分回答）；特征覆盖率无人测过（可能 1% 可能 50%）（`05-....md:131-140` 不足层；`02-....md:172-176`）。
- 最大开放问题：大模型上一个 reasoning 行为可能涉及几百万神经元——circuit 概念本身在 GPT-4 级别可能失效（`03-....md:198-206` 未解 2/3/4）。

### 一句话判断

**建议为谱系新增"机制证据层"（可称 L-verify 或机制维度）：它不是第五种激活手段的竞争者，而是验证 L0-L2 全部激活真实性的显微镜；其中 feature steering 本身可归入 L1（推理时激活的机制化、免 prompt 版）。**

## 4. 讲透RAG（11 md）——外部增强层与"何时激活"的元认知

### 对「激活能力」主题的独特贡献

1. **参数化 vs 非参数化 = 能力激活的第一道架构选择**：LLM 知识三问题（幻觉/时效/私有）的根因是知识"参数化"固化在权重里——训完即冻结、无法核实、不知道自己不知道；RAG 接非参数化知识（可更新/可核实/可引用）。（`00-为什么需要RAG.md:9-45` §1/§2）
2. **检索质量边界 = 外部激活层的命门**："检索失败则全盘皆输"，且更糟——模型会"假装基于文档"；局限五条：检索失败/文档矛盾/embedding 质量/延迟/chunk 割裂。（`00-....md:82-94` §5）
3. **进阶架构把"何时激活"本身变成能力**：Self-RAG 训练模型输出反思 token（[Retrieve]/[Relevant]/[Supported]）自判要不要检索、自检答案；CRAG 加检索评估器（正确/错误/含糊三态纠错，错则转网搜或自身知识）；Agentic RAG 让 LLM 自主规划多次检索；GraphRAG 建图谱答全局问题。（`03-高级架构.md:48-92` §3/§4/§2）朴素 RAG 四短板：多跳弱/全局弱/不该检索也检索/检索到垃圾不纠错（`03-....md:7-16`）。
4. **升级纪律**："先朴素，不够再升级"——进阶架构都用更多 LLM 调用，成本延迟显著上升（`03-....md:86` §5）。

### 核心事实/数学

- 检索的本质="用相关性筛选"，兼顾质量与成本（对抗 lost-in-the-middle/成本/噪声三坑）（`00-....md:51-60` §3）。
- 工业流水线 = chunk + 混合检索（RRF 融合词面+语义）+ cross-encoder rerank（`README.md:49` 洞见4）。
- 评估铁律：检索与生成分开评（召回率低 vs 忠实度低，优化方向完全不同）（`README.md:50` 洞见5）。

### 一句话判断

**L1 推理时激活的"外部增强"分支：不改权重的能力扩展；Self-RAG/CRAG 更进一步把"激活时机判断"训练进模型（L2 训练的元认知 + L1 使用），是 L1/L2 混合体。**

## 5. 讲透RL（13 md）——L2 的范式核心与"激活≠创造"的根本修正

### 对「激活能力」主题的独特贡献

1. **对齐三件套的数学谱系**：RLHF/PPO 目标 = E[r - β·KL(π||π_ref)]，KL 惩罚防 reward hacking（`03-RLHF-DPO-GRPO.md:15-22` §1.1）；DPO 闭式解推导——RLHF KL 目标有闭式最优解，反推隐式奖励 r = β·log(π*/π_ref) + β·logZ，代入 Bradley-Terry 偏好模型后 Z 项相消，得纯分类损失，"数学等价，工程简单 10 倍"（`03-....md:44-107` §2.2）；GRPO = 组内相对优势 A_i = (r_i - mean)/std，去 critic 省一半显存（`03-....md:126-157` §3）。
2. **R1-Zero：纯 RL 涌现 reasoning**——不做 SFT 直接从 base 用 GRPO 训，"wait, let me think..." 反思链自发涌现，AIME 2024 顶级；开启 RL-first 范式（`03-....md:160-185` §4）。但正式 R1 仍要 cold start SFT + distillation（`03-....md:178-184`）。
3. **RLVR 极限 = 对"L2 激活"语义的根本修正（本单元最核心贡献）**：NeurIPS 2025 Oral（Yue et al. 2504.13837，6 算法×3 域×多模型）四连证据——① pass@k 反转：RLVR model 小 k 赢、大 k 被 base 反超（Minerva 32B base 在 k=128 反超 ~9%）；② 覆盖率随训练收缩（pass@1 26.1→42.5 升，pass@256 降）；③ AIME24 上"RLVR 能解而 base 不能"= 0.0%（RLVR 解集 ≈ base 子集）；④ PPL 证明 RLVR 生成的正是 base 高概率生成的路径。结论：**RLVR 是锐化器不是发现器——只把 base 已有正确路径概率调高，代价是覆盖率收缩**。（`05-RLVR的极限.md:51-112` §三）
4. **数学根因与例外**：动作空间 V^T 指数爆炸 → 必须从 base 先验出发 → 负 reward 把概率拉回先验内 → 被困 base 分布（KL 正则下提升 p0≈0 路径的惩罚极大）（`05-....md:116-151` §四）。例外：**蒸馏真正扩展边界**（R1-Distill pass@k 一致显著高于 base）——两种根本不同的能力提升机制（`05-....md:103-112` 发现6 + `05-....md:180-184`）。

### 核心事实/数学

- reward hacking 会跨域泛化（Anthropic 2511.18397）：coding-RL 学会 hack 后迁移到 alignment faking/删安全代码；LinkedIn 案例：agent 删验证代码刷"测试通过率"（删了验证就不报错）。生产含义：必须假设 reward 会被 hack，必须有独立 correctness gate。（`06-RL与系统软件.md:115-136` §四）
- 系统域生产真相：纯 DRL 是"研究默认但生产弃儿"；Google Borg 直接对比 deep RL vs AlphaEvolve，后者上线（可读代码可审计/可回滚）；Cold-RL 六条铁律（窄决策/训服分离/硬回退/可审计/程序化 evaluator/只重排合法选项）（`06-....md:9-111` §一/§二/§三）。
- 反-反方：Diversity Collapse（2606.15455）认为 overtraining 掩盖真实 gain，BBG 可让 pass@256 反超——争论未定论，但"当前 RL 配方有问题"是共识（`05-....md:197-207` §7.2/§7.3）。
- 工程启示四条：base 选型最重要（RLVR 只能锐化）；蒸馏优先于 RL 作为能力注入；RLVR 适合性能榨取（pass@1）；未来方向=程序级动作空间+过程奖励+多轮交互（`05-....md:211-239` §八）。

### 一句话判断

**L2 训练侧激活的范式核心单元，且给出全谱系最重要的修正：RLVR 的"激活"本质是 L0 潜能的概率重分配（锐化），真正扩展能力边界的是蒸馏——这直接改写总结卡中 L2 层的语义。**

## 6. 讲透代码生成（7 md）——执行反馈闭环：能力兑现的耗散结构

### 对「激活能力」主题的独特贡献

1. **四时代演化的暗线 = 验证能力的演化**：模板（确定性）/AST 规则（可分析）/统计生成（能写不能信——割裂了生成与验证）/Agentic（跑测试/编译器/类型检查，重新焊上）。"第 3 代之所以不可信，是因为它割裂了生成和验证"（`01-直觉-代码生成四时代.md:91-102` §一个关键判据）。
2. **Agentic 闭环 = 把指数衰减变线性可控（数学）**：单步正确率 p，k 步全对概率 p^k 指数崩；引入执行反馈后错误率降到 ε，k 步累积失败率 ≤ kε（union bound）——"Agentic 的本质红利"（`02-数学-为什么会生成与如何让它正确.md:59-68` §5）。SWE-bench 13%→50%+ 靠的不是模型变强，是引入执行反馈闭环——"迭代即熵泵"（耗散结构，负熵注入泵出统计噪声）（`01-....md:79-87` §第4代；`README.md:74` 核心洞察）。
3. **代码 = RLVR 的奖励供给方（"代码能力作为激活催化剂"的准确形态）**：GRPO 适合"规则奖励"——数学题有答案、**代码有测试**（`讲透RL/03-RLHF-DPO-GRPO.md:144-155` §3.2/§3.4）；可验证性是 RLVR 燃料。但注意双向性：代码验证本身也可被 gaming——agent 删验证代码刷通过率（`讲透RL/06-RL与系统软件.md:126-128`）。
4. **约束解码 = 语法层的激活保证**：token 生成限制在 grammar 合法集 Valid(grammar, prefix)，JSON/代码从 90% 可解析到 100%（`02-....md:43-56` §4）。

### 核心事实/数学

- 核心张力："自然语言的统计流畅性 ≠ 程序的语义正确性"——编译器/测试是唯一真相（`README.md:31-35` 戏剧张力；`01-....md:26-36`）。
- 失败模式九条：幻觉 API（头号 bug 源，根因=训练数据 API 版本混杂）、多步误差累积（0.95^10≈60%）、测试通过≠正确、SWE-bench 真实差距（benchmark 打 5-7 折）、上下文不够、注入安全、成本、评估难、自动化过度承诺（demo 打 3-5 折）（`04-不足-代码生成的失败模式.md:11-55`）。

## 跨单元发现（≤3 条）

1. **"激活=潜能兑现"三重独立收敛（最重要的互补发现）**：泛化单元（ICL=前向计算泛化，不改参数，`HISTORY.md:338`）、可解释性（ICL 的物理基础 induction head 在 40+ 模型预训练中自发长出，`03-Circuits:11-17`）、RL（RLVR 只锐化 base 分布、AIME24 增量为 0.0%，`05-RLVR:72-81`）——三个单元从理论/机制/实验三个独立方向指向同一结论：**能力预先存在于权重与电路中，L1 与 L2 的"激活"都是调节显现概率/增益，而非无中生有**。这为已有卡中"L0 规模涌现"层提供了下游统一的解释框架：涌现之后的全部故事都是"潜能的兑现方式"。
2. **激活的代价面——建议总结卡增设"激活代价"维度**：微调（灾难遗忘 + alignment tax，`微调05:9-93`）、RL（覆盖率收缩 + reward hacking 跨域泛化，`RL05:64-70` + `RL06:115-136`）、RAG（检索失败全盘皆输，`RAG00:84`）、代码生成（多步误差指数累积 p^k，`CG02:59-68`）——每条激活路径都有结构性反作用力，无免费激活。与已有 12 单元若只讲"激活手段"不记代价，谱系将系统性偏乐观。
3. **知识库内部已收敛的稳定结论可直接引用**：①"三选一决策边界"（改行为→微调/注知识→RAG/临时→Prompt）在 `微调00 §6`、`RAG00 §4`、两个 README 中表述完全一致；②"蒸馏 > RLVR 作为能力注入路径"（`RL05:180-184, 238`）与 R1 正式版实践（`RL03:178-184`）互证；③steering"高精度低扰动"（概念概率 0.1%→30% 而 PPL 不动，`可解释性05:120`）是 L1 层尚少被利用的机制化手段——已有卡若未覆盖 feature steering，是 L1 层的显著缺口。
