# 讲透损失函数

> 配套实验: `experiments/loss_overview.py` (4 个子实验, 已实跑验证)

---

## 全景图: 损失函数是什么?

**损失函数 (loss function)** $\ell(\hat{y}, y)$ 是一个打分函数: 输入"模型预测 $\hat{y}$"和"真实标签 $y$", 输出一个标量, 衡量两者差距。

训练 = **经验风险最小化** (Empirical Risk Minimization):

$$\min_\theta \; \frac{1}{N}\sum_{i=1}^{N} \ell(f_\theta(x_i), y_i)$$

> **一句话**: 损失函数是优化的指南针。它定义了"什么是好预测", 梯度下降才知道往哪走。

---

## 灵魂洞察: 所有损失函数都是【统计假设的化身】(MLE 统一视角)

这是讲透的关键。表面上 MSE、MAE、CE 长得毫无关系, 但它们都来自同一个源头: **最大似然估计 (Maximum Likelihood Estimation, MLE)**。

### 推导骨架

假设数据 $y$ 围绕模型预测 $\hat{y}$, 服从某个噪声分布 $p(y \mid \hat{y})$。MLE 要求:

$$\max_\theta \prod_{i=1}^{N} p(y_i \mid \hat{y}_i) \quad \xrightarrow{\text{取负对数}} \quad \min_\theta \sum_{i=1}^{N} \underbrace{-\log p(y_i \mid \hat{y}_i)}_{\text{这就是损失函数!}}$$

**结论: 损失函数 = 负对数似然 (Negative Log-Likelihood, NLL)。你假设什么噪声分布, 就得到什么损失函数。**

| 你对噪声/标签的假设 | 噪声分布 | 推出的损失函数 | 用途 |
|---------------------|---------|---------------|------|
| 回归, 误差是高斯(钟形) | $\mathcal{N}(\hat{y}, \sigma^2)$ | **MSE** $\frac{1}{2}(y-\hat{y})^2$ | 回归 |
| 回归, 误差是拉普拉斯(重尾) | $\text{Lap}(\hat{y}, b)$ | **MAE** $\|y - \hat{y}\|$ | 鲁棒回归 |
| 二分类, 标签是伯努利 | $\text{Bern}(p)$ | **BCE** $-[y\log p + (1-y)\log(1-p)]$ | 二分类 |
| 多分类, 标签是多项式 | $\text{Cat}(\pi)$ | **CE** $-\sum_k y_k \log p_k$ | 多分类 |

> **所以选损失函数 = 对数据做统计假设。** 假设错了(比如数据有离群点却用 MSE), 模型就会学歪。

## 各损失函数三层拆解

### 1. MSE — 均方误差 (L2 Loss)

**直觉**: "误差越大, 罚得越狠, 而且是平方地狠"。像驾考: 压线扣 1 分, 开到对向车道扣 9 分。

**数学**:
$$\ell_{\text{MSE}} = \frac{1}{N}\sum_{i}(y_i - \hat{y}_i)^2, \quad \frac{\partial \ell}{\partial \hat{y}} = \frac{2}{N}(\hat{y} - y)$$

- 梯度 $\propto$ 误差大小: 错得越离谱, 梯度越大, 纠正越快。
- **假设噪声是高斯分布** (从 MLE 推出来)。

**代码验证** (`experiments/loss_overview.py` 实验1):
```
|e|=1: MSE=1,  |e|=3: MSE=9   (惩罚 ×3, 但平方增长)
```

**不足**:
- 对离群点极敏感 (1 个离群点能把整条拟合线拉飞 — 见实验2: MSE 最优 = 1.818, 真值 1.0)。
- 假设方差恒定, 若噪声方差变化则失准。

---

### 2. MAE — 平均绝对误差 (L1 Loss)

**直觉**: "无论错多少, 每单位误差罚 1 分"。一视同仁。

**数学**:
$$\ell_{\text{MAE}} = \frac{1}{N}\sum_{i}|y_i - \hat{y}_i|, \quad \frac{\partial \ell}{\partial \hat{y}} = \frac{1}{N}\text{sign}(\hat{y} - y)$$

- 梯度恒为 $\pm 1/N$: **即使误差很大, 梯度也不变大** → 收敛慢, 且在 $\hat{y}=y$ 处不可导。
- **假设噪声是拉普拉斯分布** (重尾, 离群点是常态)。

**代码验证** (实验2):
```
10 干净点 + 1 离群点(y=10):
  MSE 最优(均值)   = 1.818  (被拉飞)
  MAE 最优(中位数) = 1.111  (接近真值 1.0, 稳如老狗)
```

**优势**: 鲁棒。**不足**: 梯度恒定, 接近最优时仍是大步长, 来回震荡, 不易精细收敛。

---

### 3. Huber Loss — MSE 与 MAE 的混血

**直觉**: "小错用 MSE(精修), 大错用 MAE(不爆炸)"。取两者之长。

**数学** (以 $\delta$ 为分界):
$$\ell_{\text{Huber}} = \begin{cases} \frac{1}{2}(y-\hat{y})^2 & |y-\hat{y}| \le \delta \\ \delta(|y-\hat{y}| - \frac{1}{2}\delta) & |y-\hat{y}| > \delta \end{cases}$$

- 小误差区域: 凸且光滑(梯度趋零, 精细收敛)。
- 大误差区域: 线性(不被离群点拉飞)。
- 深度强化学习 (DQN) 几乎都用 Huber, 正是为此。

---

### 4. 交叉熵 (Cross-Entropy) — 分类的王者

**直觉**: "你越自信地错, 我罚得越重"。这是它和 MSE 哲学上最大的不同。

**二分类 BCE** (真实 $y \in \{0,1\}$, 预测概率 $p$):
$$\ell_{\text{BCE}} = -[y \log p + (1-y)\log(1-p)]$$

**多分类 CE** (真实 one-hot $y$, 预测概率 $p$):
$$\ell_{\text{CE}} = -\sum_{k} y_k \log p_k$$

**代码验证** (实验3): 真实 y=1 时
```
预测 p=0.99: BCE=0.010  (几乎对, 轻罚)
预测 p=0.01: BCE=4.61   (自信地错, 重罚!)
预测 p=1e-10: BCE=23.0  (爆炸)
```

**核心哲学**: MSE 罚的是"差多少", CE 罚的是"多自信地错"。分类问题里, 预测概率 0.49 和 0.51 在 MSE 下几乎没差, 但在 CE 下天差地别(因为涉及 log)。

**与 KL 散度的关系**:
$$H(y, p) = D_{KL}(y \| p) + H(y)$$
最小化 CE = 最小化"预测分布 $p$ 偏离真实分布 $y$"的 KL 散度 (因为 $H(y)$ 是常数)。

## 激活函数 × 损失函数: 必须配对的标准组合

这是初学者最常踩的坑。输出层激活和损失函数**必须配对**, 数学才漂亮、训练才稳定:

| 任务 | 输出层激活 | 损失函数 | PyTorch 写法 | 为什么配对 |
|------|-----------|---------|-------------|-----------|
| 回归 | 无 (线性) | MSE | `F.mse_loss` | 高斯噪声 MLE |
| 二分类 | sigmoid | BCE | `BCEWithLogitsLoss` | 伯努利 MLE, 内部防 log(0) |
| 多分类 | softmax | CE | `CrossEntropyLoss` | 多项式 MLE, 梯度 = p - y |

### softmax + CE 的【梯度魔法】

这是它们成为天作之合的原因。设 logits $z$, softmax 出 $p$, CE loss:

$$\frac{\partial \text{Loss}}{\partial z} = p - \text{onehot}(y)$$

仅仅 4 个字符! softmax 的分母雅可比很复杂, CE 的导数也很复杂, 但**组合在一起神奇地约简**成极简形式。

**代码验证** (实验3, 数值完全一致):
```
logits = [1.0, 2.0, 0.5],  真实类别 = 1
autograd dL/dz = [0.2312, -0.3715, 0.1402]
manual  (p-y)  = [0.2312, -0.3715, 0.1402]   ← 完全一致
```

> **铁律**: 在 PyTorch 里, 多分类**永远用 `CrossEntropyLoss` 而不是手动 softmax + NLL**。前者把 softmax 融合进损失, 数值稳定且梯度简洁。

---

## 数值稳定性: 永远不要裸写 log 和 softmax

### 坑 1: log(0) = -inf → NaN 污染整个训练

BCE 里 $-\log(p)$, 若 $p \to 0$, loss 爆炸成 inf; $p$ 恰好为 0 则 NaN。
- **解法**: 用 `BCEWithLogitsLoss` (输入是 logits 而非概率), 内部用 sigmoid + log 的合并公式, 自动避免 0。

### 坑 2: 裸 softmax 溢出

softmax = $\exp(z_i) / \sum \exp(z_j)$。若 $z = [1000, 1001, 1002]$, 则 $\exp(1000) = $ inf。

**代码验证** (实验4):
```
裸 exp([1000,1001,1002]) = [inf, inf, inf]
F.softmax (logsumexp)    = [0.09, 0.2447, 0.6652]   ← 正常
```

**解法 — logsumexp 技巧**:
$$\text{softmax}(z)_i = \exp(z_i - m) / \sum \exp(z_j - m), \quad m = \max(z)$$
减去最大值 $m$ 后, 所有 $\exp$ 参数 $\le 0$, 值域在 $[0,1]$, 永不溢出。结果数学上完全等价 (分子分母的 $e^m$ 约掉)。

## 速查表: 怎么选损失函数?

```
你的任务是什么?
│
├─ 回归 (y 连续)
│   ├─ 数据干净, 无离群点     → MSE  (F.mse_loss)
│   ├─ 有离群点/重尾噪声     → MAE  或 Huber (SmoothL1Loss)
│   └─ 量子化/概率输出        → 量化损失 (见激活函数 04 篇)
│
├─ 二分类 (y ∈ {0,1})
│   └─ 永远 → BCEWithLogitsLoss  (输入 logits, 别先 sigmoid!)
│
├─ 多分类 (y ∈ {0,1,...,K-1})
│   └─ 永远 → CrossEntropyLoss  (输入 logits, 别先 softmax!)
│
├─ 类别极不平衡
│   └─ Focal Loss  (降低易分样本权重, 关注难分样本)
│
└─ 度量两个分布差异 (VAE/蒸馏)
    └─ KL Divergence  (KL div 不是对称的, 注意方向)
```
