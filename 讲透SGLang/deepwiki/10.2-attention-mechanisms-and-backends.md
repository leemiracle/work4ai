## Purpose and Scope

 This document details the implementation of various attention mechanisms and their backends in SGLang. It covers Multi-Head Attention (MHA), Multi-Head Latent Attention (MLA), and DeepSeek Sparse Attention (DSA/NSA). It elaborates on specialized backends including FlashAttention, FlashInfer, TRTLLM MHA/MLA, AITER (AMD ROCm), Wave, and Triton, alongside backend selection logic, hybrid attention, and dual-chunk attention support.

 The goal is to provide a comprehensive technical overview of data flows, key classes, and runtime backend dispatch strategies.

 
---

 
## Attention Architecture Overview

 SGLang uses a modular attention layer design based on the `RadixAttention` abstraction [python/sglang/srt/layers/radix_attention.py110-111](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/radix_attention.py#L110-L111) which delegates computation to optimized backends. Each backend corresponds to a particular hardware platform or kernel library suited for specific model types and hardware capabilities.

## Attention Implementations

 
### Multi-Head Attention (MHA)

 MHA implements the classical attention mechanism with key-query-value matrices.

 
 - **FlashInfer Backend:** Highly optimized for NVIDIA GPUs. Uses `BatchDecodeWithPagedKVCacheWrapper` [python/sglang/srt/layers/attention/flashinfer_backend.py73-74](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/flashinfer_backend.py#L73-L74) and `BatchPrefillWithPagedKVCacheWrapper` [python/sglang/srt/layers/attention/flashinfer_backend.py74-75](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/flashinfer_backend.py#L74-L75)
 - **TRTLLM MHA Backend:** Specialized for NVIDIA SM90/SM100, supporting attention sinks and sliding windows [python/sglang/srt/layers/attention/trtllm_mha_backend.py3-13](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/trtllm_mha_backend.py#L3-L13) It supports `Q_PAGED_KV_NHD` and `HND` layouts [python/sglang/srt/layers/attention/trtllm_mha_backend.py7-8](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/trtllm_mha_backend.py#L7-L8)
 - **AITER Backend:** AMD ROCm-specific kernels supporting unified attention and sliding windows [python/sglang/srt/layers/attention/aiter_backend.py9-11](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/aiter_backend.py#L9-L11)
 
 
### Multi-Head Latent Attention (MLA)

 MLA reduces KV cache size by using latent vector compression.

 
 - **TRTLLM MLA Backend:** Optimized for Blackwell (SM100) and SM90, supporting FP8 QKV quantization and multi-CTA KV counters [python/sglang/srt/layers/attention/trtllm_mla_backend.py29-35](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/trtllm_mla_backend.py#L29-L35) It uses `trtllm-gen` for decoding [python/sglang/srt/layers/attention/trtllm_mla_backend.py188-192](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/trtllm_mla_backend.py#L188-L192)
 - **FlashInfer MLA Backend:** Provides `BatchMLAPagedAttentionWrapper` for MLA-specific paged attention [python/sglang/srt/layers/attention/flashinfer_mla_backend.py72-73](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/flashinfer_mla_backend.py#L72-L73)
 - **AITER MLA:** Uses persistent metadata (`SGLANG_AITER_MLA_PERSIST`) and persist designs for FP8-KV cache on AMD platforms [python/sglang/srt/layers/attention/aiter_backend.py92-93](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/aiter_backend.py#L92-L93)
 
 
### DeepSeek Sparse Attention (DSA/NSA)

 DeepSeek-V3/V4 models use sparse routing on blocks of KV tokens.

 
 - **DSA Backend:** Primary implementation using sparse KV token pools and indexers [python/sglang/srt/layers/attention/dsa_backend.py265-275](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/dsa_backend.py#L265-L275)
 - **Indexer:** The `Indexer` class [python/sglang/srt/layers/attention/dsa/dsa_indexer.py199-205](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/dsa/dsa_indexer.py#L199-L205) computes sparse top-k selections. It supports `deepgemm_paged_mqa_logits` and `aiter_paged_mqa_logits` backends [python/sglang/srt/layers/attention/dsa/dsa_indexer.py71-76](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/dsa/dsa_indexer.py#L71-L76)

## Backend Selection and Hybrid Attention

 
### Backend Selection Logic

 The backend is selected based on `AttentionArch` (MHA/MLA/DSA), hardware (CUDA/ROCm/NPU), and environment variables. For instance, `SGLANG_USE_AITER` forces the ROCm Aiter path [python/sglang/srt/layers/attention/dsa/dsa_indexer.py88](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/dsa/dsa_indexer.py#L88-L88)

 
### Hybrid Attention Backend

 The `HybridAttnBackend` aggregates separate backends for prefill and decode phases. This is common in models that mix attention types or where different kernels excel in different phases.
