  This page documents how SGLang processes multimodal inputs (images, videos, and audio) in the request pipeline. Multimodal inputs are transformed from raw data into embeddings that can be consumed by vision-language models (VLMs) and audio-language models.

 For information about vision-language model architecture themselves, see **Vision-Language Model Architecture (18.1)**. For the list of supported VLM models, see **Supported Vision-Language Models (18.3)**.

 
## Overview

 Multimodal input processing in SGLang transforms raw media into tensor features that are integrated with text tokens for model inference. The system supports:

 
 - **Image inputs**: Single images, batches, or multiple images per request.
 - **Video inputs**: Video files or URLs processed into frame sequences.
 - **Audio inputs**: Audio files for speech-to-text and audio-language models.
 - **Precomputed embeddings**: Direct tensor inputs bypassing preprocessing via `precomputed_embedding` format.
 - **Efficient Video Sampling (EVS)**: Optimized sampling strategies for long video processing.
 - **Encoder Disaggregation**: Offloading heavy multimodal encoding to specialized "encode servers" to decouple compute-heavy vision towers from the language model backbone.
 - **Rust-accelerated Preprocessing**: The `sglang-mm` pipeline (via `MmFamilyProcessor` and `sglang-server` components) provides high-performance media decoding, resizing, patchifying, and normalization.
 
 The pipeline handles feature extraction, caching, hashing, and integration with the text tokenization flow across distributed components.
