## Purpose and Scope

 This document provides a comprehensive explanation of the DeepSeek-V2, V3, and V4 architectures implemented within SGLang. It focuses on the **Multi-head Latent Attention (MLA)** mechanism, **DeepSeek Sparse Attention (DSA)** (formerly NSA), and the related memory management and quantization strategies.

 SGLang delivers optimized inference for DeepSeek models through hardware-specific kernels (Triton, DeepGEMM, FlashMLA), advanced quantization (FP8/FP4), and specialized memory pools for hierarchical sparse attention.

 
---

 
## DeepSeek Model Architecture

 The DeepSeek family (V2, V3, V4) utilizes Mixture-of-Experts (MoE) backbones combined with latent attention compression and sparse attention mechanisms:

 
 - **DeepSeek-V2**: Introduced MLA to compress KV cache memory footprint.
 - **DeepSeek-V3**: Added **DeepSeek Sparse Attention (DSA)** (previously called NSA), native FP8 support, and Multi-Token Prediction (MTP).
 - **DeepSeek-V4**: Integrates **HiSparse** (Hierarchical Sparse Attention), unified KV caching with ring buffers, and native FP4 expert support.

## DeepSeek-V4 Architecture and HiSparse

 DeepSeek-V4 introduces a hierarchical approach to sparse attention and unified memory management.

 
### Unified KV Cache and Ring Buffers

 DeepSeek-V4 uses a specialized memory pool, `DeepSeekV4TokenToKVPool`, which manages multiple types of storage:

 
 - **Standard KV Cache**: FP8 compressed storage for MLA.
 - **SWA (Sliding Window Attention)**: A ring buffer for the most recent tokens [python/sglang/srt/mem_cache/deepseek_v4_memory_pool.py91-112](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/mem_cache/deepseek_v4_memory_pool.py#L91-L112)
 - **Compressed States**: Hierarchical compression at ratios of 4x (C4) and 128x (C128) [python/sglang/srt/mem_cache/deepseek_v4_memory_pool.py34-48](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/mem_cache/deepseek_v4_memory_pool.py#L34-L48)

## Quantization and Optimization

 
### FP8 and FP4 Execution

 DeepSeek-V4 heavily utilizes FP8 for activations and FP4 for experts.

 
 - **Per-Token Quantization**: Kernels like `sglang_per_token_group_quant_fp8_dsv4_wo_a` handle the dynamic scaling required for DeepSeek-V4 [python/sglang/srt/models/deepseek_v4.py26-31](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/models/deepseek_v4.py#L26-L31)
