## Purpose and Scope

 This document details the implementation of FP4-based and MXFP4 quantization schemes in SGLang, adapted specifically for Blackwell-generation NVIDIA GPUs (SM100/SM107/SM120), Hopper GPUs (SM90), AMD ROCm platforms (e.g., MI35x/GFX950), and advanced architectures like DeepSeek-V3/V4 and Kimi-K3. The focus is on high-efficiency 4-bit floating-point compression formats used in both dense linear layers and Mixture-of-Experts (MoE) layers, with support for microscaling and various hardware backends.

 Key focus areas include:

 
 - NVIDIA's **NVFP4** format with ModelOpt and FlashInfer integration for Blackwell.
 - **MXFP4** (Microscaling FP4) quantization using `UE8M0` microscales.
 - **SM100-specific** optimizations including `cute-dsl` backends.
 - **Compressed Tensors** integration for W4A4 and WNA16 schemes.
 - Hardware-specific support for AMD ROCm via the `AITER` library.

## NVFP4 and MXFP4 Implementation

 NVIDIA's 4-bit FP4 quantization uses the E2M1 floating-point format. In the **MXFP4** variant, block-wise scaling is applied using `UE8M0` (unsigned 8-bit exponent-only) scales.

 
### Implementation Details

 
 - **Blackwell (SM100) Support**: SGLang detects SM100/SM107 capabilities to enable specialized FlashInfer backends. For SM100, the `cute-dsl` backend is preferred for FP4 quantization [python/sglang/srt/layers/quantization/fp4_utils.py24-25](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/fp4_utils.py#L24-L25)
 - **Microscaling (MXFP4)**: Weights are typically quantized in blocks of 32 elements. The neutral scale value for `UE8M0` is `127` (representing 1.0) [python/sglang/srt/layers/quantization/mxfp4.py74-76](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/mxfp4.py#L74-L76)
 - **Weight Reordering**: For TRT-LLM compatibility in MoE layers, weights and scales are reordered from `w1w3` to `w3w1` layout [python/sglang/srt/layers/quantization/mxfp4_flashinfer_trtllm_moe.py144-148](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/mxfp4_flashinfer_trtllm_moe.py#L144-L148)
 - **Activation Preparation**: Activations are quantized to FP8 (E4M3) or group-quantized with `UE8M0` scales before entering the fused MoE kernels [python/sglang/srt/layers/quantization/mxfp4.py84-118](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/mxfp4.py#L84-L118)

## MXInt4 and WNA16 Schemes

 SGLang extends 4-bit support to integer formats and mixed-precision MoE layers via the `CompressedTensors` framework.

 
 - **MXInt4 MoE**: Specifically targets SM100 using FlashInfer's `trtllm_mxint4_block_scale_moe`. It supports symmetric group quantization with a group size of 32 [python/sglang/srt/layers/quantization/compressed_tensors/schemes/compressed_tensors_w4a4_mxint4_moe.py63-71](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/compressed_tensors/schemes/compressed_tensors_w4a4_mxint4_moe.py#L63-L71)
 - **WNA16 MoE**: A flexible scheme supporting various bit-widths (e.g., 4-bit or 8-bit weights with 16-bit activations). It utilizes GPTQ-Marlin kernels for execution [python/sglang/srt/layers/quantization/compressed_tensors/schemes/compressed_tensors_wNa16_moe.py65-94](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/compressed_tensors/schemes/compressed_tensors_wNa16_moe.py#L65-L94)
 - **ROCm/AITER Support**: On AMD platforms, the system uses the `aiter` backend for specialized K3 MoE optimizations [python/sglang/srt/layers/quantization/mxfp4.py196-197](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/mxfp4.py#L196-L197)

## Summary of 4-bit Quantization Schemes

 
| Scheme | Format | Target Hardware | Key Components |
|---|---|---|---|
| NVFP4 | E2M1 | Blackwell (SM100) | flashinfer_cutedsl, trtllm_fp4 |
| MXFP4 | E2M1 + UE8M0 | Blackwell / ROCm | Mxfp4FlashinferTrtllmMoEMethod, aiter |
| MXInt4 | INT4 + Scales | Blackwell | trtllm_mxint4_block_scale_moe |
| WNA16 | 4-bit / 8-bit | Ampere+ (SM80+) | GPTQMarlinMoEMethod, WNA16MoE |
