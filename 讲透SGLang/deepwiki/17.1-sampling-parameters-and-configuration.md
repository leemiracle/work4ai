## Purpose and Scope

 This page documents the `SamplingParams` class and its role in controlling token generation behavior. `SamplingParams` encapsulates all sampling configuration including temperature, top-k/top-p/min-p filtering, repetition penalties, and stop conditions. These parameters flow from user requests through the scheduler to the sampler, where they control the token selection process during generation.

 Related pages:

 
 - **Logits processing**: See [Logits Processing Pipeline](https://github.com/sgl-project/sglang/blob/94183a8d/Logits Processing Pipeline) (17.2) for temperature and penalty application.
 - **Sampling algorithms**: See [Sampling Algorithms](https://github.com/sgl-project/sglang/blob/94183a8d/Sampling Algorithms) (17.3) for kernel implementations.
 - **Penalties and constraints**: See [Penalties and Constraints](https://github.com/sgl-project/sglang/blob/94183a8d/Penalties and Constraints) (17.4) for frequency/presence penalties.
 - **Constrained decoding**: See [Constrained and Structured Output](https://github.com/sgl-project/sglang/blob/94183a8d/Constrained and Structured Output) (19.2) for grammar-guided generation.

## Core Sampling Parameters

 
### Temperature and Greedy Conversion

 Temperature controls sampling randomness. SGLang handles low temperatures during initialization:

 
 - **Greedy Path**: If `0 <= temperature < 1e-6`, `temperature` is reset to `1.0` and `top_k` is set to `1` to force greedy decoding [python/sglang/srt/sampling/sampling_params.py147-150](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L147-L150)
 - **Default Top-K**: If `top_k` is `-1`, it is converted to `TOP_K_ALL` (entire vocabulary) [python/sglang/srt/sampling/sampling_params.py151-152](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L151-L152)
 
 
### Nucleus and Min-P Sampling

 
 - **Top-p**: Nucleus sampling keeps the smallest token set whose cumulative probability exceeds `top_p`. Validated to be in `(0, 1]` [python/sglang/srt/sampling/sampling_params.py161-162](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L161-L162)
 - **Min-p**: Filters tokens with probability less than `min_p * max_token_probability`. Validated to be in `[0, 1]` [python/sglang/srt/sampling/sampling_params.py163-164](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L163-L164)

## Structured Output and Grammar Configuration

 SGLang supports complex constrained decoding through the `GrammarManager` and various backends like `xgrammar`.

 
### Grammar Lifecycle

 
 - **Request Processing**: `GrammarManager` identifies if a request requires constrained decoding based on `json_schema`, `regex`, `ebnf`, or `structural_tag`.
 - **Backend Dispatch**: The manager instantiates a backend (e.g., `XGrammarBackend`) which compiles the constraint into a matcher.
 - **Reasoning Wrapper**: For reasoning models (e.g., DeepSeek-R1), a `ReasonerGrammarObject` may wrap the inner grammar to defer constraints until after the "thinking" block ends.
 - **Logits Masking**: During decoding, the `SamplingBatchInfo` carries a `GrammarMask` [python/sglang/srt/sampling/sampling_batch_info.py56](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L56-L56) The `Sampler` applies this to set forbidden token logits to `-inf`.

## Custom Logit Processors

 SGLang allows for extending the logits processing pipeline through `CustomLogitProcessor` subclasses. These are serialized using `dill` to be passed via IPC [python/sglang/srt/sampling/custom_logit_processor.py24-44](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L24-L44)

 
### Specialized Processors

 
 - **ThinkingBudgetLogitProcessor**: Controls the length of thinking for models like DeepSeek-R1 and Qwen3. It forces a newline followed by a thinking-end token once the `thinking_budget` (provided in `custom_params`) is exceeded [python/sglang/srt/sampling/custom_logit_processor.py71-120](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L71-L120)
 - **DeepseekOCRNoRepeatNGramLogitProcessor**: Prevents n-gram repetitions within a sliding window for OCR tasks [python/sglang/srt/sampling/custom_logit_processor.py156-203](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L156-L203)
 - **DisallowedTokensLogitsProcessor**: Sets logits for specific token IDs to `-inf` [python/sglang/srt/sampling/custom_logit_processor.py47-58](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L47-L58)

## Logit Processing and Penalties

 
### SamplingBatchInfo

 The `SamplingBatchInfo` class converts per-request `SamplingParams` into batched tensors for GPU execution.

 
 - **Logit Bias**: Converts the `logit_bias` dictionary into a dense tensor of shape `[batch_size, vocab_size]` [python/sglang/srt/sampling/sampling_batch_info.py135-141](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L135-L141)
 - **Custom Logit Processors**: Merges processors of the same type to optimize batch application by using a boolean mask for requests that share the same processor logic [python/sglang/srt/sampling/sampling_batch_info.py154-175](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L154-L175)
 
 
### Penalties

 Penalties are managed by the `BatchedPenalizerOrchestrator` [python/sglang/srt/sampling/sampling_batch_info.py59](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L59-L59)

 
 - **Min New Tokens**: `BatchedMinNewTokensPenalizer` prevents the model from generating stop tokens until the minimum length is reached by adding `-inf` to stop token logits [python/sglang/srt/sampling/penaltylib/min_new_tokens.py6-81](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/penaltylib/min_new_tokens.py#L6-L81)
 - **Verification**: `frequency_penalty` and `presence_penalty` are restricted to `[-2.0, 2.0]` [python/sglang/srt/sampling/sampling_params.py169-176](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L169-L176)
