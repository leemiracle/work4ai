## Overview

 SGLang supports a wide range of vision-language models through a unified multimodal architecture. The system handles:

 
 - **Vision-language understanding**: Image-to-text models (LLaVA, Qwen2.5-VL, InternVL, Kimi-VL, Step3-VL, etc.)
 - **Vision-language generation**: Text-to-image models (Janus, Janus-Pro)
 - **Video understanding**: Video-to-text models (LLaVA-NeXT-Video, Qwen2-VL, Qwen3-VL, InternVL2)
 - **Audio understanding**: Audio-to-text models (Qwen2-Audio, Qwen3-Omni, Phi-4-MM, Gemma 3/4, MiniCPM-V)
 - **OCR models**: Specialized document understanding models (DeepSeek-OCR, GLM-OCR, PaddleOCR)
 
 The framework provides automatic model detection, specialized configuration classes, and optimized multimodal processing pipelines. Models are identified by their HuggingFace architecture strings and automatically configured with appropriate vision towers, projectors, and chat templates.

### Model Type Classification

 The `ModelConfig` system determines model capabilities through architecture string matching. Multimodal models are identified to trigger specialized processing in the `TokenizerManager` and `ModelRunner`.

 
| Classification | Method | Example Architectures |
|---|---|---|
| Vision-Language | is_multimodal | LlavaForCausalLM, Qwen2_5_VLForConditionalGeneration, InternVLChatModel, Step3VLForConditionalGeneration |
| Multimodal Generation | is_multimodal_gen | MultiModalityCausalLM (Janus) |
| Image Generation | is_image_gen | JanusFlowForConditionalGeneration |
| Audio Understanding | is_audio_model | Qwen2AudioForConditionalGeneration, MiniCPMo, Phi4MMForCausalLM, Gemma3ForConditionalGeneration, Gemma4ForConditionalGeneration |
| OCR Specialized | N/A (detected via config) | DeepseekOCRForCausalLM, GLM_OCR, PaddleOCR |

### Vision Attention Mechanism

 The `VisionAttention` class in `python/sglang/srt/layers/attention/vision.py` is the core attention implementation for vision encoders.

 
 - **Backend Support**: Supports `flash_attn_varlen_func` for CUDA, ROCm, and XPU, and `torch_npu` for NPU backends [python/sglang/srt/layers/attention/vision.py48-72](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/vision.py#L48-L72)

### Quantization for VLMs

 Multimodal backbones (like Kimi-K3) often utilize advanced quantization schemes to manage the high parameter count of combined vision and text backbones.

 
 - **MXFP4 Support**: SGLang provides specialized `Mxfp4FlashinferTrtllmMoEMethod` for Mixtral/DeepSeek-style backbones in VLMs [python/sglang/srt/layers/quantization/mxfp4_flashinfer_trtllm_moe.py48-56](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/mxfp4_flashinfer_trtllm_moe.py#L48-L56)
 - **Block-wise Scaling**: Supports inter-process shuffling of FP4 expert weights for TRT-LLM kernels [python/sglang/srt/layers/quantization/mxfp4_flashinfer_trtllm_moe.py150-160](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/mxfp4_flashinfer_trtllm_moe.py#L150-L160)
