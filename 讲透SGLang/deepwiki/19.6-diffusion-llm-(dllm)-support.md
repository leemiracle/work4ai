  SGLang provides specialized support for discrete diffusion Large Language Models (DLLMs), such as **LLaDA2** (Large Language Diffusion with Autoregressive) and **SDAR**. Unlike standard autoregressive models that predict one token at a time, these models treat language generation as a denoising process, often involving masked language modeling (MLM) and iterative refinement over sequences.

 The DLLM implementation in SGLang leverages a specialized configuration system, scheduler mixins, and custom forward modes to handle the unique denoising loops and First-Done-First-Out (FDFO) scheduling required by these architectures.

 
## Architecture Overview

 The DLLM support is integrated into the SGLang Runtime (SRT) through a set of mixins and configuration classes that extend the standard request and scheduling logic.

 
### Key Components

 
 - **`DllmConfig`**: Encapsulates parameters for diffusion-based generation, including the specific `algorithm` (e.g., `LowConfidence`, `JointThreshold`), `block_size`, and `mask_id`. It maps model architectures to their required diffusion parameters. [python/sglang/srt/dllm/config.py7-78](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/config.py#L7-L78)
 - **`SchedulerDllmMixin`**: Injected into the `Scheduler` to handle the iterative denoising logic. It manages state transitions and specific scheduling requirements for diffusion requests. [python/sglang/srt/dllm/mixin/scheduler.py22-30](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L22-L30)
 - **`DllmReqPhase`**: An enumeration defining the lifecycle of a DLLM request: `INCOMING_PREFILL`, `STAGING_PREFILL`, `INCOMING_DECODE`, and `STAGING_DECODE`. [python/sglang/srt/dllm/mixin/req.py8-14](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/req.py#L8-L14)
 - **`DllmAlgorithm`**: A base class for denoising strategies. Implementations like `LowConfidence` and `JointThreshold` define how logits are transformed back into tokens and when a block is considered "done". [python/sglang/srt/dllm/algorithm/base.py7-24](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/algorithm/base.py#L7-L24)
 - **`ForwardMode.DLLM_EXTEND`**: A specialized execution mode for DLLM forward passes, allowing the engine to distinguish iterative refinement from standard autoregressive decoding. [python/sglang/srt/dllm/mixin/scheduler.py12](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L12-L12)

## Scheduling and Execution

 DLLM requests are treated uniquely by the `Scheduler`. While standard LLMs use a `DECODE` mode for single-token generation, DLLMs perform iterative refinements over blocks of tokens.

 
### First-Done-First-Out (FDFO) Scheduling

 SGLang implements FDFO scheduling for DLLMs. In this mode, each request can leave the batch as soon as its block is resolved by the denoising algorithm, preventing head-of-line blocking where fast-converging requests wait for slow ones.

 
 - **Resolved Blocks**: The scheduler commits the tokens to `output_ids` and advances the KV cache. [python/sglang/srt/dllm/mixin/scheduler.py130-148](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L130-L148)
 - **Unresolved Blocks**: If the algorithm determines a block is not yet confident (e.g., `accept_length == 0`), the scheduler stashes the partial state in `dllm_incomplete_ids` and carries the `dllm_algo_state` to the next round. [python/sglang/srt/dllm/mixin/scheduler.py113-119](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L113-L119)
 
 
### Iterative Denoising Loop

 The `SchedulerDllmMixin` manages the loop:

 
 - **Initialization**: `init_diffusion_llm` sets up the `DllmConfig` and `DllmManager`. [python/sglang/srt/dllm/mixin/scheduler.py23-29](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L23-L29)
 - **Request Fetching**: `_fetch_waiting_reqs` moves requests from the main `waiting_queue` to the `dllm_manager` based on `max_running_requests`. [python/sglang/srt/dllm/mixin/scheduler.py160-170](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L160-L170)
 - **Batch Creation**: `get_new_batch_dllm` forms a new batch using a specialized `PrefillAdder` that respects token budgets. [python/sglang/srt/dllm/mixin/scheduler.py31-67](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L31-L67)
 - **Result Processing**: `process_batch_result_dllm` handles the FDFO logic, updating `full_untruncated_fill_ids` and streaming outputs via `output_streamer`. [python/sglang/srt/dllm/mixin/scheduler.py69-158](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L69-L158)

## Configuration and Models

 
### Supported Models

 DLLM parameters are automatically mapped based on the model architecture in `DllmConfig.from_server_args`. [python/sglang/srt/dllm/config.py36-48](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/config.py#L36-L48)

 
 - **LLaDA2**: Supported via `LLaDA2ForCausalLM`. This model uses a `LlamaModel` backbone and implements a standard `forward` that can be utilized in diffusion mode. [python/sglang/srt/models/llada2.py27-113](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/models/llada2.py#L27-L113)
 - **SDAR**: Supported via `SDARForCausalLM` and `SDARMoeForCausalLM`. These models incorporate the diffusion denoising logic within their generation logic. [python/sglang/srt/models/sdar.py23-86](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/models/sdar.py#L23-L86) [python/sglang/srt/models/sdar_moe.py22-87](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/models/sdar_moe.py#L22-L87)
 
 
### Server Configuration

 Users enable DLLM support via CLI arguments:

 
 - `--dllm-algorithm`: Selects the denoising strategy (e.g., `low_confidence`, `joint_threshold`). [python/sglang/srt/dllm/config.py15-18](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/config.py#L15-L18)
 - `--dllm-fdfo`: Enables First-Done-First-Out scheduling. [python/sglang/srt/dllm/mixin/scheduler.py77](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/dllm/mixin/scheduler.py#L77-L77)
