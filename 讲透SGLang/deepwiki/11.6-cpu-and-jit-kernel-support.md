  This page documents the specialized kernel implementations for CPU execution (utilizing AMX and NUMA optimizations) and the Just-In-Time (JIT) kernel infrastructure used for dynamic kernel generation and platform-specific optimizations, including DeepGEMM, Intel XPU (Arc/Flex/Max GPUs), and custom CUDA kernels.

 
## 1. CPU Kernel Implementations

 SGLang provides specialized CPU-optimized kernels that leverage hardware features like Intel Advanced Matrix Extensions (AMX). These are integrated into the `sgl-kernel` library to enable efficient serving on x86 architectures.

 
### 1.1 Implementation Architecture

 The CPU kernels are dispatched via hardware-aware checks. For instance, `VocabParallelEmbedding` checks for AMX support to decide whether to use specialized weight packing methods [python/sglang/srt/layers/vocab_parallel_embedding.py40-45](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/vocab_parallel_embedding.py#L40-L45)

 
| Category | Key Functions | Implementation Details |
|---|---|---|
| Weight Packing | amx_process_weight_after_loading | Packs weights for better performance on CPU if AMX is available. Supports Linear and Conv layers python/sglang/srt/layers/amx_utils.py68-80 |
| Quantization | GPTQIntelAMXLinearScheme | Implements GPTQ quantization specifically for Intel AMX backends python/sglang/srt/layers/quantization/gptq/gptq.py25-26 |
| Vision Preprocessing | image_preprocess_cpu | Optimized image preprocessing (resize, rescale, normalize) using CPU kernels python/sglang/srt/layers/amx_utils.py44-61 |

 
### 1.2 AMX and Vectorized Operations

 
 - **AMX Detection**: SGLang checks for AMX support using `cpu_has_amx_support()` [python/sglang/srt/layers/amx_utils.py6](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/amx_utils.py#L6-L6)
 - **Alignment Requirements**: For AMX GEMM kernels, Output Channel (OC) must be a multiple of 16 and Input Channel (IC) a multiple of 32 [python/sglang/srt/layers/amx_utils.py83-93](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/amx_utils.py#L83-L93)
 - **Quantization Support**: CPU AMX backend currently supports 4-bit AWQ/GPTQ checkpoints via the `AutoRoundConfig` [python/sglang/srt/layers/quantization/auto_round.py23-27](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/auto_round.py#L23-L27)
 
 
### 1.3 NUMA Affinity and Binding

 For multi-socket CPU systems, SGLang implements NUMA (Non-Uniform Memory Access) binding to minimize cross-socket latency.

 
 - **Subprocess Configuration**: The `configure_subprocess` context manager handles `numactl` binding for worker processes [python/sglang/srt/utils/numa_utils.py27-69](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/utils/numa_utils.py#L27-L69)
 - **GPU-NUMA Mapping**: The system queries the closest NUMA node for a given GPU via `_query_numa_node_for_gpu` to ensure data locality [python/sglang/srt/utils/numa_utils.py118-143](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/utils/numa_utils.py#L118-L143)

## 2. JIT Kernel Infrastructure

 SGLang utilizes a JIT compilation system to generate optimized CUDA kernels at runtime. This infrastructure handles element-wise fusions and heavyweight GEMM kernels.

 The JIT system (located in `python/sglang/kernels/jit/`) provides C++ templates for common operations. For example, `per_token_group_quant.cuh` defines trait-driven quantization logic that is compiled at runtime.

### 2.2 DeepGEMM JIT Integration

 For Blackwell architectures, SGLang integrates **DeepGEMM**, a JIT-compiled GEMM library optimized for FP8 and MoE operations.

 
 - **Pre-compilation**: SGLang provides a `compile_deep_gemm` utility to avoid JIT overhead during serving. It generates kernels for a range of `M` (batch size) values [python/sglang/srt/layers/deep_gemm_wrapper/compile_utils.py115-156](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/deep_gemm_wrapper/compile_utils.py#L115-L156)
 - **Fast Warmup**: In fast warmup mode, the system compiles a small set of typical batch sizes (e.g., small BS for decode, powers of 2 for prefill) [python/sglang/srt/layers/deep_gemm_wrapper/compile_utils.py55-81](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/deep_gemm_wrapper/compile_utils.py#L55-L81)

## 3. Platform-Specific Optimizations

 
### 3.1 Intel XPU Support

 SGLang extends its kernel support to Intel XPU (Discrete GPUs like Arc B580/BMG and Data Center GPU Max).

 
 - **Kernel Implementation**: XPU uses AOT (Ahead-of-Time) symbols from `sgl_kernel` for operations like `topk_sigmoid` and `topk_softmax` [python/sglang/srt/layers/moe/topk.py185-189](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/moe/topk.py#L185-L189)
 - **XPU MoE**: Implements `HashTopK` for XPU, utilizing the `hash_topk` kernel from `sgl_kernel` which currently supports the `sqrtsoftplus` scoring function [python/sglang/srt/layers/moe/hash_topk.py181-189](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/moe/hash_topk.py#L181-L189)
 - **Persistent Cache**: CI environments use a persistent XPU kernel cache keyed by GPU mask and image ID to avoid re-compilation of Triton and Inductor kernels [scripts/ci/xpu/xpu_ci_start_container.sh112-140](https://github.com/sgl-project/sglang/blob/94183a8d/scripts/ci/xpu/xpu_ci_start_container.sh#L112-L140)

### 3.3 Advanced Quantization Kernels

 
 - **Per-Token Group Quantization**: Optimized JIT kernel for FP8/Int8 quantization. It supports different layouts including `row_major_fp32`, `col_major_fp32`, and `col_major_ue8m0` (DeepSeek-V3 style) [python/sglang/kernels/jit/csrc/gemm/per_token_group_quant.cuh106-137](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/kernels/jit/csrc/gemm/per_token_group_quant.cuh#L106-L137)
 - **UE8M0 Scale Path**: A bit-exact quantization path where the multiplier is an exact power of two, used in DeepGEMM dense and EP-MoE paths [python/sglang/kernels/jit/csrc/gemm/per_token_group_quant.cuh59-62](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/kernels/jit/csrc/gemm/per_token_group_quant.cuh#L59-L62)
 - **AutoRound**: Supports INT4 CPU inference specifically for Intel AMX backends, covering both `auto_gptq` and `auto_awq` packing formats [python/sglang/srt/layers/quantization/auto_round.py39-70](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/auto_round.py#L39-L70)
