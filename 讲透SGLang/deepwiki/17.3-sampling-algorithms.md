## Purpose and Scope

 This document describes the sampling implementations and backend selection in SGLang. It covers the `Sampler` class architecture, backend dispatch mechanisms (FlashInfer, PyTorch, Ascend), and the specific algorithms used for greedy, top-k, top-p, and min-p sampling. The sampling layer transforms model logits into token predictions as the final stage of generation.

 Related documentation:

 
 - For sampling parameter configuration (temperature, top_p, top_k, etc.), see page 17.1 [python/sglang/srt/sampling/sampling_params.py53-82](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L53-L82)
 - For logit processing and penalties applied before sampling, see page 17.2 [python/sglang/srt/layers/logits_processor.py14-106](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/logits_processor.py#L14-L106)
 
 
## Architecture Overview

 The sampling system in SGLang operates as the final stage of token generation, taking processed logits and producing token IDs. The system supports multiple backend implementations for performance optimization across different hardware platforms:

 
 - **FlashInfer**: Default for CUDA platforms, using optimized kernels from `sgl-kernel` [python/sglang/srt/layers/sampler.py30-38](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L30-L38)
 - **PyTorch**: Pure PyTorch fallback for platforms without specialized kernels [python/sglang/srt/layers/sampler.py310-342](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L310-L342)
 - **Ascend**: Specialized backend for Huawei Ascend NPU platforms [python/sglang/srt/layers/sampler.py345-391](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L345-L391)
 
 The sampler is instantiated per-worker and invoked during each forward pass in the model execution pipeline.

## Sampling Algorithms

 
### Greedy Decoding

 When all requests have `top_k <= 1`, the sampler uses `torch.argmax(logits, -1)` [python/sglang/srt/layers/sampler.py137](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L137-L137) This path avoids random sampling and multinomial computation. Support for optimized greedy sampling on ROCm platforms is provided via `aiter` [python/sglang/srt/layers/sampler.py49-58](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L49-L58)

 
### Top-K Sampling

 Restricts sampling to the K most probable tokens.

 
 - **Constant:** `TOP_K_ALL = 1 << 30` [python/sglang/srt/sampling/sampling_params.py40](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L40-L40)
 - **Default:** `top_k = -1` in `SamplingParams` maps to `TOP_K_ALL` [python/sglang/srt/sampling/sampling_params.py151-152](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L151-L152)
 - **Batched Logic:** The `SamplingBatchInfo` tracks if any request needs top-k sampling via `need_top_k_sampling` [python/sglang/srt/sampling/sampling_batch_info.py46](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L46-L46)
 
 
### Top-P (Nucleus) Sampling

 Samples from the smallest set of tokens whose cumulative probability exceeds threshold `p`. In the PyTorch backend, it masks tokens where `(probs_sum - probs_sort) > top_ps` [python/sglang/srt/layers/sampler.py330](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L330-L330)

 
### Min-P Sampling

 Filters out tokens whose probability is less than `min_p * max_probability`.

 
 - **Logic:** `min_p_thresholds = probs_sort[:, 0] * min_ps` [python/sglang/srt/layers/sampler.py332](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L332-L332)
 
 
### Temperature Sampling

 Logits are divided by temperature before softmax. If temperature is near zero ($< 10^{-6}$), it is treated as greedy ($top_k=1, temp=1.0$) [python/sglang/srt/sampling/sampling_params.py147-150](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L147-L150)

 **Sources:** [python/sglang/srt/layers/sampler.py130-175](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L130-L175) [python/sglang/srt/sampling/sampling_params.py40-153](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L40-L153)

 
## Deterministic Sampling

 When `enable_deterministic_inference` is enabled, SGLang uses a seed-based multinomial implementation [python/sglang/srt/layers/sampler.py394-426](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L394-L426)

 
### Seed-Based Multinomial Algorithm

 Instead of standard `torch.multinomial`, it uses the Gumbel-Max trick with a hash-based pseudo-random generator:

 
 - **Step Seed:** Combines base seed with token position using `murmur_hash32` [python/sglang/srt/layers/sampler.py408](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L408-L408)
 - **Uniform Sample:** Converts the hash to a float in `[0, 1]` [python/sglang/srt/layers/sampler.py414](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L414-L414)
 - **Gumbel Noise:** Computes `-log(-log(uniform))` [python/sglang/srt/layers/sampler.py417](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L417-L417)
 - **Selection:** Returns `argmax(log(probs) + gumbel)` [python/sglang/srt/layers/sampler.py420](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L420-L420)
 
 **Sources:** [python/sglang/srt/layers/sampler.py394-426](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L394-L426) [python/sglang/srt/layers/sampler.py9](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/sampler.py#L9-L9)
