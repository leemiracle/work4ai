SGLang is a high-performance serving framework for Large Language Models (LLMs) and Vision Language Models (VLMs), designed for scalability across diverse hardware platforms using a multi-process architecture [python/sglang/srt/entrypoints/engine.py207-268](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/entrypoints/engine.py#L207-L268)

## Monorepo Layout

 The SGLang repository consists of the following key directories, each with a distinct purpose in building, deploying, or running the framework:

 
| Directory | Description |
|---|---|
| python/ | Core Python package including SGLang Runtime (SRT), CLI, API entry points, diffusion framework, and various utilities. |
| sgl-kernel/ | High-performance kernel implementations for CUDA, ROCm, CPU, including attention, MoE, quantization kernels, and PyTorch bindings. |
| sgl-model-gateway/ | Enterprise-grade, high-performance model routing gateway, enabling multi-model orchestration and load balancing. |
| experimental/sgl-router/ | Experimental Rust-based slim router with KV-event-driven, cache-aware routing capabilities and Kubernetes EndpointSlice discovery. |
| rust/ | Rust extensions and crates such as sglang-grpc for gRPC server implementations and RPC bindings. |
| docs/ & docs_new/ | Documentation sources maintained in both legacy and updated formats. |
| examples/ | Example programs for DSL, API usage, and integration demonstrations. |
| scripts/ | Development, CI, benchmarking, and deployment helper scripts. |

## Major Packages

 
### 1. `sglang` (Python Runtime)

 The main Python package forms the core of SGLang and exposes runtime components, CLI interfaces, HTTP servers, and APIs.

 
 - **`sglang.srt`** implements the SGLang Runtime (SRT), comprising:

 
 - **TokenizerManager**: Tokenizes requests and manages pre-scheduling request lifecycle [python/sglang/srt/managers/tokenizer_manager.py210-225](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/managers/tokenizer_manager.py#L210-L225)
 - **Scheduler**: Runs as a subprocess to schedule, batch, and forward inference requests [python/sglang/srt/managers/scheduler.py1-95](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/managers/scheduler.py#L1-L95)
 - **DetokenizerManager**: Detokenizes model output tokens for final response [python/sglang/srt/entrypoints/engine.py61-91](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/entrypoints/engine.py#L61-L91)
 - **Engine** class: Central entrypoint that coordinates the TokenizerManager, Scheduler, and DetokenizerManager subprocesses, manages IPC, and exposes synchronous and asynchronous generation APIs [python/sglang/srt/entrypoints/engine.py208-590](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/entrypoints/engine.py#L208-L590)
 - **`sglang.cli`** exposes the CLI entry point `sglang` via `sglang.cli.main:main` [python/pyproject.toml202-203](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L202-L203)
 - **`sglang.multimodal_gen`** provides diffusion model support for image, video, and multimodal generation based on DiT model architecture, integrated into the runtime [python/pyproject.toml104-125](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L104-L125)
 
 
### 2. `sgl-kernel` (High-Performance Kernels)

 
 - Contains CUDA, ROCm, CPU implementations of critical kernels supporting attention mechanisms, expert parallelism (MoE), quantization, and other performance optimizations.
 - This package compiles into a Python wheel (`sglang-kernel`) exposing a unified kernel namespace integrated with the runtime [python/pyproject.toml73](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L73-L73)
 - Supports multiple hardware architectures with runtime detection and dispatch [python/sglang/srt/utils/common.py131-234](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/utils/common.py#L131-L234)
 
 
### 3. Rust Extensions (`rust/`)

 
 - The `sglang-grpc` crate implements a Rust-based, high-performance gRPC server, acting as a lightweight extension to the Python runtime for low-latency RPC serving [python/pyproject.toml210-217](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L210-L217)
 - Other Rust crates in this folder support various runtime extensions and tooling integrations.
 
 
### 4. Other Directories

 
 - **`sgl-model-gateway/`**: Provides an advanced model routing gateway and control plane for load balancing and multi-node orchestration.
 - **`experimental/sgl-router/`**: An experimental Rust-based router implementing KV-event-driven cache-aware routing and Kubernetes EndpointSlice discovery.
 - **`docs/`** and **`docs_new/`**: Distinct documentation sources in legacy and new formats respectively.
 - **`examples/`**: Contains example scripts demonstrating DSL usage, API interactions, and model loading.
 - **`scripts/`**: Includes development utilities, CI scripts, and benchmarking tools for environment setup and testing [python/pyproject.toml225](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L225-L225)

## Primary User Entry Points

 
### 1. Command Line Interface (CLI)

 
 - The primary CLI command `sglang` invokes `sglang.cli.main:main`, which parses command line arguments and initiates commands such as `serve` [python/pyproject.toml202-203](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L202-L203)
 - The `sglang serve` command launches the full SGLang inference engine with all subprocesses [python/sglang/cli/main.py40-46](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/cli/main.py#L40-L46)
 
 
### 2. HTTP Server (OpenAI-Compatible)

 
 - A FastAPI-based HTTP server implements OpenAI-compatible API endpoints, including Anthropic and Ollama extensions [python/sglang/srt/entrypoints/http_server.py86-111](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/entrypoints/http_server.py#L86-L111)
 - The server delegates request processing to background subprocesses via ZeroMQ IPC, mainly interfacing TokenizerManager, Scheduler, and DetokenizerManager components [python/sglang/srt/entrypoints/engine.py208-268](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/entrypoints/engine.py#L208-L268)
 
 
### 3. Python Engine API

 
 - The `Engine` class encapsulates the runtime as an embeddable Python API, exposing methods for synchronous and asynchronous generation [python/sglang/srt/entrypoints/engine.py208-590](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/entrypoints/engine.py#L208-L590)
 - It controls subprocess lifecycles, inter-process communication, and supports advanced features like multi-tokenizer support and LoRA adapter management.
 
 
### 4. gRPC Server

 
 - A Rust-backed gRPC server provides a high-throughput RPC interface leveraging the `sglang-grpc` crate [python/sglang/srt/entrypoints/grpc_server.py1-160](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/entrypoints/grpc_server.py#L1-L160)

## Tools and Expert Pack Utility

 
 - The monorepo includes a utility for building and validating expert pack files used for expert parallelism (MoE) models.
 - This utility is exposed under `tools/expert_pack` and supports the SGLANG-EXPERTPACK-v1 format.
 - Expert packs define the expert routing parameters and layout used by the DeepEP backend and related EP dispatch systems.
 
 
---

 
## Build and Dependency Management

 
 - Build and packaging rely on `pyproject.toml` and `setuptools` with Rust extensions built via `setuptools-rust` [python/pyproject.toml1-94](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L1-L94)
 - Key dependencies include `torch`, `transformers`, `pyzmq`, and optional extras for diffusion, tracing, and hardware-specific variants.
 - The `docker/Dockerfile` configures a multi-stage build environment targeting CUDA-enabled GPU systems with dependencies such as GDRCopy and RDMA libraries for high-performance networking support [docker/Dockerfile1-200](https://github.com/sgl-project/sglang/blob/94183a8d/docker/Dockerfile#L1-L200)
