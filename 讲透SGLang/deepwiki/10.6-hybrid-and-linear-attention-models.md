  SGLang provides comprehensive support for advanced attention architectures optimized for long context, including **hybrid attention** models that combine standard attention with linear or state-space mechanisms, and **linear attention** models featuring alternatives to quadratic complexity. This page documents the key implementations, data flows, kernel backends, and models such as Qwen3-Next, Falcon-H1, Kimi-Linear, and Bailing-MoE.

 
---

 
## Overview and Purpose

 The purpose of this section is to detail SGLang’s modular design around hybrid and linear attention backends, providing:

 
 - Hybrid backends that unify standard and linear state-space attention layers.
 - Linear attention backends such as GDN (Gated DeltaNet), KDA (Kernel Delta Attention), and Mamba2-style SSM attention.
 - Model implementations leveraging these backends (e.g., Nemotron-H, Kimi-Linear, Qwen3-Next).
 - Underlying kernel dispatchers, state management, and data flows.
 - Performance optimizations including FlashInfer integration and speculative decoding support.
 
 This enables efficient serving of models with long contexts via linear-time attention while supporting diverse hardware platforms including NVIDIA (Hopper/Blackwell), NPU, XPU, and CPU.

 
---

 
## Hybrid Attention Backend

 The `HybridLinearAttnBackend` and its base `MambaAttnBackendBase` serve as the central orchestrators for hybrid models. These backends manage the interaction and metadata synchronization across different attention modalities during a forward pass.

 Key features:

 
 - **Pooling Management**: Uses `HybridReqToTokenPool` and `MambaPool` to manage both standard KV tokens and SSM-specific state indices [python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py27-53](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py#L27-L53)
 - **State Tracking**: Invokes functions like `track_mamba_states_if_needed` to manage convolutional and SSM states within the global pools [python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py9-16](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py#L9-L16)
 - **Metadata Handling**: Generates `ForwardMetadata` and `Mamba2Metadata` to track query locations, cache indices, and ring buffer positions for GDN/KDA [python/sglang/srt/layers/attention/mamba/mamba2_metadata.py29-68](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/mamba/mamba2_metadata.py#L29-L68)
 - **Virtual-to-Physical Translation**: Handles physical slot mapping via `_translate_mamba_indices` to support unified memory and prefix caching [python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py95-99](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py#L95-L99)

## Linear Attention Backends

 SGLang's linear attention support centers on two major mechanisms: **Gated DeltaNet (GDN)** and **Kernel Delta Attention (KDA)**.

 
### Gated DeltaNet (GDN)

 GDN uses gated recurrent linear attention with specialized fused kernels.

 
 - **Dispatcher**: `GDNKernelDispatcher` routes calls to `TritonGDNKernel`, `CuteDSLGDNKernel`, or `FlashInferGDNKernel` based on hardware capability (SM90/SM100) [python/sglang/srt/layers/attention/linear/gdn_backend.py125-180](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/linear/gdn_backend.py#L125-L180)
 - **FlashInfer Support**: Optimized for SM90/SM100 (Hopper/Blackwell), providing high-performance prefill and decode paths. It supports specialized `gated_delta_rule_decode_pretranspose` and `gated_delta_rule_mtp` [python/sglang/srt/layers/attention/linear/kernels/gdn_flashinfer.py84-170](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/linear/kernels/gdn_flashinfer.py#L84-L170)
 - **Gating**: Uses `fused_gdn_gating` to combine gating signals with linear attention outputs [python/sglang/srt/layers/attention/linear/gdn_backend.py5-9](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/linear/gdn_backend.py#L5-L9)
 
 
### Kernel Delta Attention (KDA)

 KDA, prominently used in **Kimi-Linear**, implements a kernel delta rule with gated recurrent updates.

 
 - **Dispatcher**: `KDAKernelDispatcher` manages kernels for decode, prefill, and MTP (Multi-Token Prediction) verification [python/sglang/srt/layers/attention/linear/kda_backend.py40-127](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/linear/kda_backend.py#L40-L127)
 - **Backends**: Supports Triton, Helion, FlashInfer (`recurrent_kda`), and CuTe DSL [python/sglang/srt/layers/attention/linear/kda_backend.py50-88](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/linear/kda_backend.py#L50-L88)
 - **Verification**: Specialized verify kernels for speculative decoding scenarios, including `FlashInferKDAKernel` for SM100 chain-only verification [python/sglang/srt/layers/attention/linear/kda_backend.py102-122](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/linear/kda_backend.py#L102-L122)

## Model Implementations

 
### Hybrid Models

 
 - **Nemotron-H**: Combines Mamba2 SSM layers with standard attention. It utilizes `HybridLinearAttnBackend` and `MambaMixer2` [python/sglang/srt/models/nemotron_h.py34-38](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/models/nemotron_h.py#L34-L38)
 - **Qwen3-Next**: A hybrid model utilizing the Mamba2 architecture. It features a specialized `mamba_v2_sharded_weight_loader` to handle tensor parallel sharding of projections (x, B, C) [python/sglang/srt/layers/attention/mamba/mamba.py83-112](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/mamba/mamba.py#L83-L112)
 
 
### Linear Attention Models

 
 - **Kimi-Linear**: Leverages `RadixLinearAttention` and `KimiMoE`. It features gated linear attention with `KimiMLAAttention` and expert parallelism [python/sglang/srt/models/kimi_linear.py35-136](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/models/kimi_linear.py#L35-L136)
 - **Falcon-H1**: Supports hybrid linear attention configurations through the unified `HybridLinearAttnBackend` [python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py45-53](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py#L45-L53)

## Memory and State Management

 
 - **MambaPool**: Stores convolutional and SSM states. It supports `enable_linear_replayssm` for efficient state recovery during prefix-matching by managing per-slot decode counters [python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py147-152](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py#L147-L152)
 - **State Checkpoints**: `FlashInferGDNKernel` uses `state_checkpoint_every_n_tokens` to manage recurrent states during long-context prefill, populating packed FlashInfer checkpoint metadata [python/sglang/srt/layers/attention/linear/kernels/gdn_flashinfer.py43-82](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/linear/kernels/gdn_flashinfer.py#L43-L82)
 - **Virtual Slot ID Translation**: The `HybridReqToTokenPool` translates virtual mamba slot IDs to physical addresses, crucial for kernels feeding the SSM/conv operations [python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py95-99](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/attention/hybrid_linear_attn_backend.py#L95-L99)
