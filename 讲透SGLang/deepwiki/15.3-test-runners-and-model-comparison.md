  This document describes SGLang's test runners (`HFRunner` and `SRTRunner`), the model comparison utilities used for correctness validation, and the automated evaluation infrastructure. These tools enable bit-accurate or ROUGE-based comparison between the SGLang Runtime (SRT) and reference implementations like Hugging Face Transformers.

 
## Test Runner Architecture

 SGLang utilizes a dual-runner architecture to validate the runtime against a reference. The `HFRunner` executes models using the standard `transformers` library, while `SRTRunner` executes them using the SGLang engine.

 
### Runner Process Model

 To prevent CUDA context conflicts and memory fragmentation, runners often operate in separate processes. The `HFRunner` specifically launches a managed subprocess to isolate the Hugging Face model execution.

### HFRunner Implementation

 The `HFRunner` wraps Hugging Face models for various tasks including generation, embedding, and reward modeling. It uses `multiprocessing.Queue` to communicate with a worker process that holds the actual GPU weights.

 
 - **Initialization**: It sets up the model type (e.g., "generation", "embedding", "reward") and spawns the process using `mp.Process` [python/sglang/test/runners.py163-192](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/test/runners.py#L163-L192)
 - **Data Flow**: Inputs are sent via `in_queue`, processed by `AutoModelForCausalLM`, `AutoModelForImageTextToText`, or `SentenceTransformer`, and results are returned via `out_queue` as a `ModelOutput` dataclass [python/sglang/test/runners.py149-161](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/test/runners.py#L149-L161) [python/sglang/test/runners.py179-180](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/test/runners.py#L179-L180)

## CI Test Infrastructure

 SGLang uses a structured CI system to manage high-throughput testing across various hardware platforms.

 
### Test Registration and Suites

 Every CI test file must call a registration function (e.g., `register_cuda_ci`) to be discovered by the runner [test/README.md63-66](https://github.com/sgl-project/sglang/blob/94183a8d/test/README.md?plain=1#L63-L66)

 
 - **Metadata**: Registration includes `est_time` (seconds), `stage` (e.g., `base-b`), and `runner_config` (e.g., `1-gpu-small`) [test/README.md68-71](https://github.com/sgl-project/sglang/blob/94183a8d/test/README.md?plain=1#L68-L71)
 - **Runner**: `run_suite.py` is the main entry point for executing these suites, supporting hardware selection (`--hw`) and auto-partitioning for parallel CI jobs [test/README.md16-18](https://github.com/sgl-project/sglang/blob/94183a8d/test/README.md?plain=1#L16-L18) [test/README.md56-59](https://github.com/sgl-project/sglang/blob/94183a8d/test/README.md?plain=1#L56-L59)
 
 
### Failure Handling and Retries

 The CI system differentiates between code errors and transient infrastructure or accuracy flakes.

 
 - **Retriable Patterns**: Failures matching patterns like `AssertionError`, `accuracy`, `latency`, or `timeout` are eligible for retry [python/sglang/test/ci/ci_utils.py27-37](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/test/ci/ci_utils.py#L27-L37)
 - **Non-Retriable Patterns**: Hard errors like `SyntaxError`, `ImportError`, or `Segmentation fault` cause immediate failure [python/sglang/test/ci/ci_utils.py48-62](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/test/ci/ci_utils.py#L48-L62)
 - **Timeout Derivation**: Each test file is assigned a timeout based on its estimated time: `max(est * 1.5, est + 1800)` [python/sglang/test/ci/ci_utils.py145-151](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/test/ci/ci_utils.py#L145-L151)

## CI Weight Validation and Environment

 To ensure reliability in CI environments, SGLang uses specialized utilities to manage model weights and prevent corrupted downloads from failing tests.

 
 - **Weight Validation**: `ci_validate_and_clean_hf_cache` (imported in runners) checks for corrupted `safetensors` files and missing shards [python/sglang/test/runners.py35](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/test/runners.py#L35-L35)
