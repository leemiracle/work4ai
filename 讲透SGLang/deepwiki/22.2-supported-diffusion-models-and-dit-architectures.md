  SGLang provides a high-performance runtime for Diffusion Transformers (DiT), supporting a variety of state-of-the-art image and video generation models. This page documents the specific DiT implementations, their architectural components, and how they integrate with the SGLang diffusion pipeline.

 
## Architectural Overview

 SGLang's diffusion framework is designed around a stage-based pipeline where the DiT models serve as the core execution engine. Models are implemented as subclasses of `CachableDiT` [python/sglang/multimodal_gen/runtime/models/dits/base.py76](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/base.py#L76-L76) or `BaseDiT` [python/sglang/multimodal_gen/runtime/models/dits/base.py16](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/base.py#L16-L16) and utilize `LayerwiseOffloadableModuleMixin` [python/sglang/multimodal_gen/runtime/managers/memory_managers/layerwise_offload.py105-106](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/managers/memory_managers/layerwise_offload.py#L105-L106) to support layer-wise offloading for large models.

## Supported Models and Implementations

 
### 1. Flux (Flux.1 and Flux.2)

 Flux models utilize a dual-stream architecture. SGLang supports both the original Flux.1 and the updated Flux.2 which introduces SwiGLU-style activations.

 
 - **Key Components**: `FluxAdaLayerNormZero` [python/sglang/multimodal_gen/runtime/models/dits/flux.py186-192](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux.py#L186-L192) `_flux2_swiglu` [python/sglang/multimodal_gen/runtime/models/dits/flux_2.py146-188](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux_2.py#L146-L188) and `NDRotaryEmbedding` [python/sglang/multimodal_gen/runtime/models/dits/flux.py79-81](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux.py#L79-L81)
 - **Optimizations**: Supports Nunchaku W4A4 quantization via `NunchakuConfig` [python/sglang/multimodal_gen/runtime/models/dits/flux.py75-78](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux.py#L75-L78) It uses specialized fused kernels like `_flux_norm_modulate` [python/sglang/multimodal_gen/runtime/models/dits/flux.py162-183](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux.py#L162-L183)
 - **Parallelism**: Uses `USPAttention` for Unified Sequence Parallelism [python/sglang/multimodal_gen/runtime/models/dits/flux.py61](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux.py#L61-L61) Sources: [python/sglang/multimodal_gen/runtime/models/dits/flux.py162-192](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux.py#L162-L192) [python/sglang/multimodal_gen/runtime/models/dits/flux_2.py146-188](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/flux_2.py#L146-L188)
 
 
### 2. WanVideo

 WanVideo is a family of video generation models (T2V and I2V).

 
 - **Architecture**: Implements `WanSelfAttention` [python/sglang/multimodal_gen/runtime/models/dits/wanvideo.py137-207](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/wanvideo.py#L137-L207)

### 4. Z-Image

 A streamlined DiT architecture optimized for throughput, featuring a custom RMSNorm to preserve native BF16 behavior.

 
 - **Custom Norm**: Implements `ZImageRMSNorm` which avoids upcasting to FP32 [python/sglang/multimodal_gen/runtime/models/dits/zimage.py61-79](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/zimage.py#L61-L79)
 - **Fused Operations**: Supports `zimage_rmsnorm_tanh_mul_add` for fused residual connections via Triton kernels [python/sglang/multimodal_gen/runtime/models/dits/zimage.py82-101](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/zimage.py#L82-L101)
 - **QK Norm**: Provides `zimage_native_qk_rmsnorm` for per-head normalization [python/sglang/multimodal_gen/runtime/models/dits/zimage.py124-153](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/zimage.py#L124-L153) Sources: [python/sglang/multimodal_gen/runtime/models/dits/zimage.py61-153](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/runtime/models/dits/zimage.py#L61-L153) [python/sglang/multimodal_gen/configs/pipeline_configs/zimage.py124-199](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/multimodal_gen/configs/pipeline_configs/zimage.py#L124-L199)
