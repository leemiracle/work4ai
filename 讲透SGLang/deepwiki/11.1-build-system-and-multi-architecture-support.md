## Purpose and Scope

 This document describes the build system and multi-platform support for SGLang, focusing on the `sgl-kernel` library and the broader ecosystem's deployment strategies. It details:

 
 - **CMake Configuration**: Optimization for NVIDIA GPUs (SM90 Hopper, SM100 Blackwell).
 - **Multi-Architecture Packaging**: Support for NVIDIA CUDA, AMD ROCm (HIP), Intel XPU, Huawei NPU, Moore Threads MUSA, Apple Silicon Metal, and CPU (x86/ARM).
 - **Platform Detection**: Runtime hardware identification and capability checks.
 - **Docker & CI Integration**: Automated build pipelines for diverse hardware targets.

## Build System Architecture

 SGLang utilizes a hybrid build system. The core Python package is managed via `setuptools` and `uv`, while performance-critical kernels in `sgl-kernel` use `CMake` integrated with `scikit-build-core`. Rust extensions (e.g., for gRPC and multimodal processing) are managed via `setuptools-rust` [python/pyproject.toml1-3](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L1-L3)

## Multi-Architecture Compilation

 
### NVIDIA CUDA (SM90/SM100)

 SGLang provides deep optimization for NVIDIA architectures. The build system supports:

 
 - **SM90 (Hopper)**: Optimized for FP8 and Transformer Engine via `sgl-deep-gemm` [python/pyproject.toml72](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L72-L72)
 - **SM100 (Blackwell)**: Support for FP4/NVFP4 quantization and Blackwell-specific kernels [python/pyproject.toml66](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject.toml#L66-L66)
 - **CUDA Versions**: CI workflows specifically target CUDA 12.6, 12.9, and 13.0 variants [docker/Dockerfile187-205](https://github.com/sgl-project/sglang/blob/94183a8d/docker/Dockerfile#L187-L205)
 
 
### AMD ROCm (HIP)

 The ROCm build targets various versions including ROCm 7.0 and 7.2.

 
 - **Wheel Index**: ROCm wheels are published to a specialized index for `rocm700` and `rocm720` [3rdparty/amd/wheel/sglang/pyproject.toml73-89](https://github.com/sgl-project/sglang/blob/94183a8d/3rdparty/amd/wheel/sglang/pyproject.toml#L73-L89)
 - **Wave-Lang**: Uses `wave-lang` for optimized ROCm kernels [python/pyproject_other.toml122](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject_other.toml#L122-L122)
 - **Petit Kernel**: Integration of `petit_kernel` for AMD-specific performance [python/pyproject_other.toml119](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject_other.toml#L119-L119)
 
 
### Intel XPU and Huawei NPU

 
 - **XPU**: Built using specialized PyTorch versions (e.g., `2.13.0+xpu`) and git-based `sgl-kernel-xpu` [python/pyproject_xpu.toml57-62](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject_xpu.toml#L57-L62)
 - **NPU**: Utilizes specialized multimodal decoders like `decord2` for ARM64 Linux and `hf_transfer` for fast weight loading [python/pyproject_npu.toml26-31](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject_npu.toml#L26-L31)
 
 
### CPU Support (Xeon)

 For CPU-only environments, SGLang provides a specialized `sglang-cpu` package using `intel-openmp` and `triton` for CPU [python/pyproject_cpu.toml7-72](https://github.com/sgl-project/sglang/blob/94183a8d/python/pyproject_cpu.toml#L7-L72) The `xeon.Dockerfile` preloads `libtcmalloc` and `libtbbmalloc` for memory performance [docker/xeon.Dockerfile49-50](https://github.com/sgl-project/sglang/blob/94183a8d/docker/xeon.Dockerfile#L49-L50)
