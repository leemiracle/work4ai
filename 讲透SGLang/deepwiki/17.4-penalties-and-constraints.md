## Purpose and Scope

 This page documents the penalty and constraint mechanisms in SGLang's token generation system. Penalties modify token logits during generation to discourage or encourage specific patterns (e.g., reducing repetition), while constraints enforce hard limits on generation behavior (e.g., maximum output length, stop conditions, or structural grammar).

 For general sampling algorithms, see page 17.3. For the complete logits processing pipeline, see page 17.2. For sampling parameter configuration, see page 17.1.

 
---

 
## System Overview

 Penalties and constraints in SGLang are configured through the `SamplingParams` class [python/sglang/srt/sampling/sampling_params.py45-85](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L45-L85) and applied at distinct stages of the generation pipeline. The `SamplingBatchInfo` class serves as the central container for these configurations during the execution of a batch [python/sglang/srt/sampling/sampling_batch_info.py29-86](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L29-L86)

 
 - **Logits Modification Stage**: Penalties (frequency, presence, repetition, min new tokens) and logit biases are applied to adjust token scores before sampling. This is orchestrated by the `BatchedPenalizerOrchestrator` [python/sglang/srt/sampling/sampling_batch_info.py59](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L59-L59) which is initialized within `SamplingBatchInfo.from_schedule_batch` [python/sglang/srt/sampling/sampling_batch_info.py188-191](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L188-L191)
 - **Grammar Constraints**: For structured output (JSON, Regex, EBNF), bitmasks are applied to logits to zero out invalid tokens. This is integrated into the sampling batch via `GrammarMask` [python/sglang/srt/sampling/sampling_batch_info.py56](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L56-L56)
 - **Custom Logit Processing**: Advanced constraints like "Thinking Budgets" for reasoning models (DeepSeek-R1, Qwen3, GLM-4) are applied via `CustomLogitProcessor` subclasses [python/sglang/srt/sampling/custom_logit_processor.py24-154](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L24-L154)
 - **Post-Sampling Validation Stage**: Constraints check generation completion (max tokens, stop strings/tokens) within the request lifecycle.

## Penalty Types

 
### Frequency and Presence Penalties

 
 - **Frequency Penalty**: Reduces the logit score of tokens proportional to their appearance count in the current generation [python/sglang/srt/sampling/sampling_params.py66](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L66-L66) Valid values are in `[-2.0, 2.0]` [python/sglang/srt/sampling/sampling_params.py169-173](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L169-L173)
 - **Presence Penalty**: Applies a fixed penalty to any token that has appeared at least once [python/sglang/srt/sampling/sampling_params.py67](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L67-L67) Valid values are in `[-2.0, 2.0]` [python/sglang/srt/sampling/sampling_params.py174-178](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L174-L178)
 - **Implementation**: Handled by the `BatchedPenalizerOrchestrator`. Additive penalties are accumulated into `acc_additive_penalties` [python/sglang/srt/sampling/sampling_batch_info.py60](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L60-L60)
 
 
### Repetition Penalty

 Applies a multiplicative scaling penalty (typically > 1.0 to discourage repetition) to tokens that have already appeared [python/sglang/srt/sampling/sampling_params.py68](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L68-L68)

 
 - **Implementation**: Scaled penalties are accumulated in `acc_scaling_penalties` [python/sglang/srt/sampling/sampling_batch_info.py61-63](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L61-L63) and applied using the `apply_scaling_penalties` utility [python/sglang/srt/sampling/sampling_batch_info.py17](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L17-L17)
 
 
### Min New Tokens Penalty

 Ensures the model does not generate stop tokens or EOS tokens until a minimum length is reached [python/sglang/srt/sampling/sampling_params.py69](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L69-L69)

 
 - **Implementation**: The `BatchedMinNewTokensPenalizer` identifies all possible stop tokens (API stop tokens, EOS, and additional tokenizer stop tokens) [python/sglang/srt/sampling/penaltylib/min_new_tokens.py25-39](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/penaltylib/min_new_tokens.py#L25-L39) and applies a `-inf` penalty to them until the output length matches `min_new_tokens` [python/sglang/srt/sampling/penaltylib/min_new_tokens.py76-81](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/penaltylib/min_new_tokens.py#L76-L81)
 
 
### Logit Bias

 Allows manual adjustment of specific token scores by adding a fixed value to the logit [python/sglang/srt/sampling/sampling_params.py83](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L83-L83) `SamplingBatchInfo` converts the `logit_bias` dictionary from the request into a GPU tensor during batch initialization [python/sglang/srt/sampling/sampling_batch_info.py135-141](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_batch_info.py#L135-L141)

## Custom Logit Processors and Constraints

 SGLang provides a flexible `CustomLogitProcessor` interface for implementing complex generation constraints that require inspection of the full request history or specific metadata [python/sglang/srt/sampling/custom_logit_processor.py24-46](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L24-L46)

 
### Thinking Budgets for Reasoning Models

 Reasoning models (like DeepSeek-R1 or Qwen3) often use special tokens to wrap internal "thinking" blocks. SGLang uses `ThinkingBudgetLogitProcessor` to enforce limits on these blocks [python/sglang/srt/sampling/custom_logit_processor.py71-120](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L71-L120)

 
 - **Logic**: The processor tracks if the generation is currently inside a thinking block by searching for the `THINKING_START_TOKEN_ID` without a corresponding `THINKING_END_TOKEN_ID` [python/sglang/srt/sampling/custom_logit_processor.py61-68](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L61-L68)
 - **Enforcement**: Once the `thinking_budget` is exceeded, the processor forces the `NEW_LINE_TOKEN_ID` followed by the `THINKING_END_TOKEN_ID` to terminate the reasoning phase [python/sglang/srt/sampling/custom_logit_processor.py111-118](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L111-L118)
 - **Model Variants**: Specific implementations exist for `DeepSeekR1ThinkingBudgetLogitProcessor` (Start: 128798, End: 128799, NL: 201) [python/sglang/srt/sampling/custom_logit_processor.py139-145](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L139-L145) `Qwen3ThinkingBudgetLogitProcessor` (Start: 151667, End: 151668, NL: 198) [python/sglang/srt/sampling/custom_logit_processor.py131-137](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L131-L137) and `InklingThinkingBudgetLogitProcessor` [python/sglang/srt/sampling/custom_logit_processor.py147-152](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L147-L152)
 
 
### N-Gram Repetition Constraints

 The `DeepseekOCRNoRepeatNGramLogitProcessor` blocks the repetition of n-grams within a specific sliding window [python/sglang/srt/sampling/custom_logit_processor.py156-205](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L156-L205) This is particularly useful for OCR tasks where the model might get stuck in repetitive loops. It identifies banned tokens by looking at sequences within the `window_size` that match the current `ngram_size` prefix [python/sglang/srt/sampling/custom_logit_processor.py199-202](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/custom_logit_processor.py#L199-L202)

## Length and Stop Constraints

 
### Basic Constraints

 
 - **max_new_tokens**: Hard limit on generation length, defaults to 128 [python/sglang/srt/sampling/sampling_params.py54](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L54-L54)
 - **min_new_tokens**: Prevents early termination by ensuring a minimum number of tokens are generated [python/sglang/srt/sampling/sampling_params.py69](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L69-L69)
 - **Stop Conditions**: Generation terminates if the model produces a token in `stop_token_ids` [python/sglang/srt/sampling/sampling_params.py58](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L58-L58) or matches a string in `stop` [python/sglang/srt/sampling/sampling_params.py55](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L55-L55) SGLang also supports `stop_regex` for pattern-based termination [python/sglang/srt/sampling/sampling_params.py59](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/sampling/sampling_params.py#L59-L59)
