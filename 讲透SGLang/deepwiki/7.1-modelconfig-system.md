## Purpose and Scope

 The `ModelConfig` class ([python/sglang/srt/configs/model_config.py181](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/configs/model_config.py#L181-L181)) is the primary runtime configuration object representing a loaded model within the SGLang serving framework. It holds all essential parameters required for serving large language models (LLMs) and vision-language models (VLMs). Its core responsibilities include:

 
 - **Configuration Loading**: Fetches and parses HuggingFace model configurations from local or remote sources using `get_config` ([python/sglang/srt/utils/hf_transformers/config.py79](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/utils/hf_transformers/config.py#L79-L79)).
 - **Parameter Derivation**: Computes all necessary model shape parameters such as context length, attention head counts, hidden sizes, and vocabulary sizes via dedicated methods `_derive_model_shapes` ([python/sglang/srt/configs/model_config.py448-635](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/configs/model_config.py#L448-L635)) and `_derive_context_length` ([python/sglang/srt/configs/model_config.py409-441](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/configs/model_config.py#L409-L441)) in [python/sglang/srt/configs/model_config.py](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/configs/model_config.py)
 - **Architecture Detection and Validation**: Determines key architectural traits including the attention mechanism type (MLA vs MHA), quantization strategy, model capabilities (e.g. multimodal support, hybrid sliding-window attention (SWA), sparse attention layers like MiniMax), and specialized model formats.
 
 The `ModelConfig` is instantiated once per model at server startup, configured immutably, and then shared across components like `ModelRunner`, the memory management subsystem, and custom attention kernel dispatchers, making it the canonical source of truth for model-specific serving logic.

## Context Length Derivation

 The effective sequence length maximum is derived in `_derive_context_length()` ([python/sglang/srt/configs/model_config.py409-441](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/configs/model_config.py#L409-L441)) prioritizing user overrides while validating against the model's known maximum:

 
 - If `context_length` is passed explicitly and is less or equal to the model's max, use it.
 - If `context_length` is larger than the model's max and environment variable `SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN` ([python/sglang/srt/environ.py](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/environ.py)) is **not set**, raise an error.
 - Otherwise, fallback to the model's longest sequence length derived from `get_context_length(self.hf_text_config)` ([python/sglang/srt/utils/hf_transformers/common.py25](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/utils/hf_transformers/common.py#L25-L25)).

## Quantization Detection and Validation

 The method `_verify_quantization()` ([python/sglang/srt/configs/model_config.py897-1185](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/configs/model_config.py#L897-L1185)) performs comprehensive quantization configuration. It verifies that the quantization method is included in the global registry `QUANTIZATION_METHODS` ([python/sglang/srt/layers/quantization/__init__.py](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/layers/quantization/__init__.py)) and handles mapping of ModelOpt quantization schemes:

 
| ModelOpt quant_algo Value | Mapped SGLang Quant Method |
|---|---|
| MIXED_PRECISION | w4afp8 |
| FP4 or NVFP4 | modelopt_fp4 |
| FP8 | modelopt_fp8 |

## Relationship to Other Systems

 The `ModelConfig` acts as a central hub coordinating configuration information across multiple core subsystems:

 - **ServerArgs** ([python/sglang/srt/server_args.py188](https://github.com/sgl-project/sglang/blob/94183a8d/python/sglang/srt/server_args.py#L188-L188)) initializes and drives `ModelConfig` construction.
