## Purpose and Scope

 The `triton.language` module (abbreviated as `tl`) provides the Python API for writing GPU kernels in Triton. It defines the core data types, operations, and programming model primitives that kernel authors use to express parallel computations. This module serves as the user-facing interface for Triton's domain-specific language (DSL).

 This page documents the type system, tensor operations, and core language constructs. For information about:

 
 - JIT compilation and caching mechanisms, see [JIT Compilation and Caching](https://deepwiki.com/triton-lang/triton/2.2-jit-compilation-and-caching)
 - Semantic analysis and type checking implementation, see [Semantic Analysis and Type System](https://deepwiki.com/triton-lang/triton/2.3-semantic-analysis-and-type-system)
 - Code generation from Python AST to MLIR, see [Code Generator (AST to MLIR)](https://deepwiki.com/triton-lang/triton/2.4-code-generator-(ast-to-mlir))
 - The experimental Gluon frontend, see [Gluon Experimental Frontend](https://deepwiki.com/triton-lang/triton/2.6-gluon-experimental-frontend)

### Scalar Types (dtype)

 The `dtype` class represents scalar data types. Each dtype has properties including bit width, signedness (for integers), and mantissa/exponent width (for floating point) [python/triton/language/core.py383-450](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L383-L450)

 **Key dtype instances**:

 
 - **Integers**: `int1`, `int8`, `int16`, `int32`, `int64`, `uint8`, `uint16`, `uint32`, `uint64` [python/triton/language/core.py512-536](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L512-L536)

### Block Types (block_type)

 The `block_type` represents N-dimensional arrays (tensors) with a fixed element type and shape.

 **Key attributes**:

 
 - `element_ty`: Scalar type of each element.
 - `shape`: Tuple of integers defining dimensions.
 - `numel`: Total number of elements.
 
 Triton enforces a maximum tensor size via `TRITON_MAX_TENSOR_NUMEL` [python/triton/language/core.py17](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L17-L17)

## The tensor Class

 The `tensor` class [python/triton/language/core.py851-889](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L851-L889) is the primary runtime value in Triton kernels. It wraps an MLIR `ir.value` (the `handle`) and a `block_type` or `dtype`.

 
### Operator Overloading

 The `tensor` class defines magic methods for standard Python operators, which are routed to the semantic layer via the `@builtin` decorator [python/triton/language/core.py34-48](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L34-L48)

 
 - **Arithmetic**: `__add__`, `__sub__`, `__mul__`, `__truediv__`, `__floordiv__`, `__mod__` [python/triton/language/core.py892-930](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L892-L930)
 - **Bitwise**: `__and__`, `__or__`, `__xor__`, `__lshift__`, `__rshift__` [python/triton/language/core.py945-965](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L945-L965)
 - **Comparison**: `__lt__`, `__le__`, `__gt__`, `__ge__`, `__eq__`, `__ne__` [python/triton/language/core.py970-1000](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L970-L1000)

## Core Operations

 
### Memory Operations

 
#### load and store

 
 - `load(pointer, mask, other, ...)`: Loads a block of data. Supports cache modifiers (`"ca"`, `"cg"`) and eviction policies [python/triton/language/core.py1645-1714](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L1645-L1714)
 - `store(pointer, value, mask, ...)`: Stores a block of data to memory [python/triton/language/core.py1717-1753](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L1717-L1753)
 
 
#### Block Pointers

 Block pointers provide a structured way to access multi-dimensional arrays without manual offset arithmetic.

 
 - `make_block_ptr`: Constructs a descriptor for a block of memory [python/triton/language/core.py1802-1835](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L1802-L1835)
 - `advance`: Moves the block pointer by specified offsets [python/triton/language/core.py1838-1849](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/core.py#L1838-L1849)

## Programming Model

 
### Execution Model

 Triton uses a Single Program Multiple Data (SPMD) model where multiple instances of the same kernel run in parallel.

 
 - `program_id(axis)`: Returns the ID of the current program (CTA) in the grid [python/triton/language/semantic.py39-42](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/semantic.py#L39-L42)
 - `num_programs(axis)`: Returns the total grid size along an axis [python/triton/language/semantic.py44-47](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/semantic.py#L44-L47)
 
 
### Semantic Layer (TritonSemantic)

 The `TritonSemantic` class [python/triton/language/semantic.py26-34](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/semantic.py#L26-L34) bridges the Python DSL and the MLIR IR. It handles:

 
 - **Type Promotion**: Implemented in `computation_type_impl` [python/triton/language/semantic.py68-111](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/semantic.py#L68-L111) following PyTorch-like rules for scalars and C-style rules for integers.
 - **Implicit Casting**: Automatically converts Python scalars to Triton tensors via `to_tensor` [python/triton/language/semantic.py113-122](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/semantic.py#L113-L122)
 - **IR Construction**: Calls C++ IR builder methods (e.g., `builder.create_get_program_id`) [python/triton/language/semantic.py42](https://github.com/triton-lang/triton/blob/f893845b/python/triton/language/semantic.py#L42-L42)
