## Purpose and Scope

 Layout Encoding Attributes define how tensor data is distributed and organized across the GPU compute hierarchy (threads, warps, CTAs, and clusters) and memory spaces (registers, shared memory, global memory). These attributes are MLIR attributes attached to tensor types in the TritonGPU dialect to control data placement and enable hardware-specific optimizations.

 This page documents the encoding attribute hierarchy, their parameters, and their role in data distribution. For the mathematical framework that provides a canonical representation of layouts, see [3.4 LinearLayout System](https://github.com/triton-lang/triton/blob/f893845b/3.4 LinearLayout System) For operations on memory descriptors and how shared memory layouts are used, see [3.5 Memory Descriptors and Shared Memory Layouts](https://github.com/triton-lang/triton/blob/f893845b/3.5 Memory Descriptors and Shared Memory Layouts)

## Distributed Encoding Attributes

 Distributed encodings describe how tensor data is distributed across the 4-level GPU compute hierarchy: values per thread (registers) → threads per warp (lanes) → warps per CTA → CTAs per cluster (blocks).

 
### BlockedEncodingAttr

 The fundamental distributed layout that divides tensor dimensions into blocks distributed across the compute hierarchy.

 **Parameters:**

 
| Parameter | Type | Description |
|---|---|---|
| sizePerThread | ArrayRef<unsigned> | Elements per thread in each dimension |
| threadsPerWarp | ArrayRef<unsigned> | Threads per warp in each dimension |
| warpsPerCTA | ArrayRef<unsigned> | Warps per CTA in each dimension |
| order | ArrayRef<unsigned> | Dimension order (fastest-varying first) |
| CGALayout | CGAEncodingAttr | CTA cluster layout |

 Sources: [include/triton/Dialect/TritonGPU/IR/TritonGPUAttrDefs.td614-757](https://github.com/triton-lang/triton/blob/f893845b/include/triton/Dialect/TritonGPU/IR/TritonGPUAttrDefs.td#L614-L757) [lib/Dialect/TritonGPU/IR/Dialect.cpp190-210](https://github.com/triton-lang/triton/blob/f893845b/lib/Dialect/TritonGPU/IR/Dialect.cpp#L190-L210)

 
### LinearEncodingAttr

 The canonical encoding that represents any distributed layout using a `LinearLayout` object. This provides a unified mathematical representation where all layouts can be converted to/from this form.

 **Parameters:**

 
| Parameter | Type | Description |
|---|---|---|
| linearLayout | LinearLayout | The linear layout representation |

 **Input Dimensions:** `register`, `lane`, `warp`, `block`
 **Output Dimensions:** `dim0`, `dim1`, ..., `dimN-1`

 The `LinearLayout` maps from the 4-level hierarchy to tensor indices using linear algebra with basis vectors.

### AMDMfmaEncodingAttr

 Layout for AMD Matrix Fused Multiply-Add (MFMA) operations. Used in CDNA architectures (MI200, MI300).

 **Key Parameters:**

 
 - `version`: Architecture version (e.g., 0 for MI100, 1 for MI200, 2 for MI300).
 - `instrShape`: Shape of the MFMA instruction (e.g., [32, 32], [16, 16]).
 - `warpsPerCTA`: Distribution of warps across the M and N dimensions.
 - `isTransposed`: Whether the layout is transposed relative to the default instruction order.

 Shared memory encodings describe data layout in shared memory (CTA-local memory), often with swizzling patterns to avoid bank conflicts.

### SwizzledSharedEncodingAttr

 Applies XOR-based swizzling to avoid shared memory bank conflicts.

 **Swizzling Formula:**
 For element at row `r`, column `c`:

 
```
phase = (r / perPhase) % maxPhase
swizzled_column = c ^ (vec * phase)
```

 This is implemented in `swizzledSharedToLinearLayout` where bases are constructed by XORing the row-based phase into the column indices [lib/Dialect/TritonGPU/IR/LinearLayoutConversions.cpp49-95](https://github.com/triton-lang/triton/blob/f893845b/lib/Dialect/TritonGPU/IR/LinearLayoutConversions.cpp#L49-L95)

## Layout Propagation and Conversion

 The Triton compiler uses a data-flow analysis to propagate layouts through the IR and minimize `ttg.convert_layout` operations.

 - **Initialize Anchors:** Identify ops with fixed layouts (e.g., `tt.dot` result must be MMA) [lib/Dialect/TritonGPU/Transforms/RemoveLayoutConversions.cpp70-71](https://github.com/triton-lang/triton/blob/f893845b/lib/Dialect/TritonGPU/Transforms/RemoveLayoutConversions.cpp#L70-L71)
