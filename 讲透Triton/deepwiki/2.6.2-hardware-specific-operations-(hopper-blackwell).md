## Purpose and Scope

 This document describes Gluon's hardware-specific APIs for NVIDIA Hopper (SM90) and Blackwell (SM100) GPU architectures. These APIs provide direct access to advanced hardware features including TMA (Tensor Memory Accelerator), TMEM (Tensor Memory), TCGen5 (Tensor Core Generation 5), and enhanced synchronization primitives like mbarriers and Cluster Launch Control (CLC).

 For general Gluon type system and memory descriptors, see [Gluon Type System and Memory Descriptors](https://deepwiki.com/triton-lang/triton/2.6.1-gluon-type-system-and-memory-descriptors). For backend-specific compilation and code generation, see [NVIDIA CUDA Backend](https://deepwiki.com/triton-lang/triton/5.6-nvidia-cuda-backend).

## Hopper Architecture Support

 
### TMA (Tensor Memory Accelerator)

 TMA enables efficient bulk data transfers between global memory and shared memory using hardware-managed descriptors. The API is located in `triton.experimental.gluon.language.nvidia.hopper.tma`.

 
#### TMA Operations

 
| Operation | Description | Synchronization |
|---|---|---|
| tma.async_copy_global_to_shared | Copy from global to shared memory | MBarrier-driven |
| tma.async_copy_shared_to_global | Copy from shared to global memory | tma.store_wait() |
| tma.make_tensor_descriptor | Create device-side descriptor | Immediate |
| tma.store_wait | Wait for TMA stores to complete | Blocking |

### Warpgroup MMA Operations

 Hopper introduces `warpgroup_mma` which executes Tensor Core operations at the warpgroup level (128 threads) asynchronously.

 
| Function | Purpose | Returns |
|---|---|---|
| warpgroup_mma | Perform warpgroup MMA | tensor (sync) or warpgroup_mma_accumulator (async) |
| warpgroup_mma_wait | Wait for async MMA completion | Updated tensors |
| warpgroup_mma_init | Convert tensor to accumulator | warpgroup_mma_accumulator |

 Sources: [python/triton/experimental/gluon/language/nvidia/hopper/__init__.py98-149](https://github.com/triton-lang/triton/blob/f893845b/python/triton/experimental/gluon/language/nvidia/hopper/__init__.py#L98-L149) [python/triton/experimental/gluon/language/nvidia/hopper/__init__.py153-171](https://github.com/triton-lang/triton/blob/f893845b/python/triton/experimental/gluon/language/nvidia/hopper/__init__.py#L153-L171)

### TCGen5 MMA Operations

 TCGen5 is the Blackwell Tensor Core engine. It supports standard MMA and hardware-accelerated FP8 scaling.

 
| Operation | Description |
|---|---|
| tcgen05_mma | Standard MMA using TMEM accumulators. |
| tcgen05_mma_scaled | MMA with hardware-applied FP8 scales from TMEM. |
| tcgen05_commit | Synchronizes multicast descriptors across CTAs. |
| tcgen05_copy | Direct TMEM-to-TMEM copy. |
