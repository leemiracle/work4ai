# 讲透口头传统与早期非洲文学 · 深流怎么流——演述的大陆与早期的书写

> **定位句**:这支负责**深流侧**:非洲文学的地基——西非格里奥的世袭演述制度(《松迪亚塔史诗》在格里奥口中唱了七百年,1960 年经尼昂整理成书,通说),东非斯瓦希里语古典诗歌(utenzi,《坦布卡之战》1728 年抄本,通说)与夏班·罗伯特的现代转型,约鲁巴赞名诗(oriki)与奥贡德流动剧团的口头戏剧(通说);殖民接触期的早期书写(吉兹文/阿贾米/廷巴克图手稿的既有书面传统,通说),到 1930s 巴黎的黑人性运动(塞泽尔 1939 铸词,桑戈尔 1948 编选建制化,通说)与图图奥拉《棕榈酒鬼》(1952)的约鲁巴腔英语接缝收束。与现当代支分工:**这支保管大陆的记忆术,那边打赢写回的战争**。
> GB/T 13745 75084 非洲文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:曼德社会格里奥世代演述(松迪亚塔史诗的核心情节属 13 世纪马里开国,通说);1728 斯瓦希里抄本;奥贡德剧团 1940-50 年代巡演;塞泽尔《还乡笔记》1939/桑戈尔编《黑人与马达加斯加法语新诗选》1948(含萨特《黑俄耳甫斯》序,通说);图图奥拉《棕榈酒鬼》1952(通说)。
- **因什么问题**:①没有(或少有)大众书写时,文学住在哪里(答:演述制度——格里奥是口头公务员)②殖民接触后,骂名怎么变成旗帜(答:黑人性——用主人的语言拆主人的房子)③口头素材进书后剩下什么(答:程式磨损、情节核保真——家族幕一的转码链)。

## 核心问题

**已解决(通说)**:格里奥/utenzi/oriki 三大演述建制的制度结构可考;黑人性运动的铸造现场(巴黎,1930s)与文献序列清楚;《松迪亚塔史诗》的整理史可查。
**未解决/深水区**:演述的"功能等价替换"怎么测(程式探测器的盲区,家族 03 章);黑人性的再评价(泛非纲领 vs 本质主义批评,通说双录);格里奥制度在录音/流媒体时代的存续形态(家族 01 章主线 D)。

## ✨ 这支最美的一个事实

**连守门人的名字都是进口的**(家族 02 章美之时刻 5):曼德社会对自家吟游史官的自称是 **jeli**,而全世界叫了几十年的"griot(格里奥)"是法语殖民文献的转口词(词源或经葡语"仆役",通说有争议)——用殖民通道语称呼前殖民记忆制度的守护者。深流的第一课:**词的旅行史里住着权力的旧账**;每做一次"jeli(通称 griot)"的双名,通道就显形一次。

## 假设与依赖

- 买入"大众文学第一现场是演述"框架:代价是既有书面传统(吉兹文/阿贾米/廷巴克图)被压成支流(通说修正已写入);北非阿拉伯语区整体按语言归东方文学 75051(纯文字提及);涉殖民接触史按通说学术口径平实叙述,史学本体归历史学宇宙(文字提及)。
