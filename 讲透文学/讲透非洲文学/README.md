# 讲透非洲文学 · 口头的深流与写回的世界——三大洲之间的语言大陆

> **本质一句话**:非洲文学=**一条口头深流上面的多层写作大陆**——口头传统
> (西非格里奥吟游/东非斯瓦希里语诗歌/约鲁巴口头戏剧)是它的底层语法;
> 殖民接触带来欧洲语言与印刷,法语圈黑人性运动(Négritude,1930s,桑戈尔/
> 塞泽尔)先在巴黎举起旗帜;阿契贝《瓦解》(1958)用英语"写回帝国";恩古吉
> 1977 年后弃英语改用基库尤语,把语言之争推到极端;诺奖一批一批到(索因卡
> 1986→古尔纳 2021);阿达契警告"单一故事的危险"。一句话:**口头是深流,
> 语言是战场,承认是批量到的**。
>

| [`experiments/oral_language_market.py`](experiments/oral_language_market.py) | 口头转码-语言市场-承认结构三律模拟(纯标准库,固定种子 20260907):①**口头-书面连续统的转码链**——96 场格里奥演述(程式库三槽位组合)→转写(编辑保留程式 0.78)→翻译(赞名谚语类仅 0.52 保留/叙事连接类 0.86),重复 4-gram 覆盖率实测:演述 0.351→转写 0.263(75%)→翻译 0.168,纯书面对照 0.024(转写=其 11 倍);而 8 母题情节核转写段保留 0.945/翻译段累计 0.887——**程式层在磨损,情节层在保真:书面化不是搬运是转码,口头性是一条谱不是开关**;②**语言之争的双市场**(阿契贝-恩古吉对峙形式化,108 位作家三通道)——欧语通道十年译入 6.19 语种=本土通道 0.83 的 7.4 倍,但境内读者 6.8 万人=本土 22.9 万人的 30%;本土译入≥3 语种份额 17%=欧语 97% 的 17%;双语通道综合得分 1.11=最强单语 0.60 的 1.86 倍而单书成本 26.7 月=欧语 14.2 的 1.88 倍——**阿契贝-恩古吉之争的数学是市场结构,不是立场:双语是最优对冲,但成本最高**;③**诺奖序列的承认时滞与"迟到结构"**(70 位作家风险模型,五次门户 1986/1988/1991/2003/2021)——国际承认平均滞后区域声誉 9.2 年(≥5 年者 75%);门户窗口占在险时间 30% 却释放 50% 的首次承认(集中比 1.7),门户后 5 年同区域未获奖作家可见度=门户前的 2.7 倍——**外部承认跟随内部建制化,奖打开的是门,不是窗** | ✅ |
