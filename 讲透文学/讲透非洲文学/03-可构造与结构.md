# 03 · 可构造与结构:哪些非洲文学对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:非洲文学的对象沿一条**可构造谱系**排开——左端
> **严格可构造**(转码链的程式衰减、语言通道的市场行情、承认的时滞
> 与门户:写得下、算得动、能过 assert),右端**几乎不可构造**
> (语言选择的伦理重量、"单一故事"的矫正义务、作品的艺术等级:
> 只有思想操作化);全谱系共享三条**结构引擎**:**转码链引擎**
> (演述→文本→翻译的分层衰减)、**语言市场引擎**(双通道反比+双语
> 对冲)、**承认时滞引擎**(追认+门户效应);而一场演述、一次语言
> 选择、一部作品的世界之旅可以压进三张**结构卡**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
转码衰减 ── 双市场行情 ── 承认时滞 ── 口头演述卡 ── 语言选择卡 ── 市场通道卡 ── 语言伦理重量 ── 矫正义务
  │                                                                                │
严格可构造(可断言)                                                  几乎不可构造(只有思想操作化)
  └── 写得出、算得动、能过 assert                              └── 只能在阅读与论争里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:转码
衰减的语义是"重复 4-gram 覆盖率沿转码链的均值比"(输入输出明确);
而"恩古吉该不该弃英语"要求**通读并反刍的证据**——证据的给出无法
程序化。本章先盘家底,再看三条结构引擎,最后把非洲文学压成三张
结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **转码链衰减** | 演述生成器→转写/翻译算子→重复 n-gram 覆盖率 | 低(实验幕一全程可跑) | 程式的"功能等价替换"(同槽位换变体)测不到,衰减被低估 |
| **情节核保留** | 母题清单逐段点验 | 低 | 母题切分依赖研究者判断 |
| **双市场行情** | 三通道读者/译种/成本计数,反差比断言 | 低 | "读者深度"操作化为万人读者(简化) |
| **跨国壁垒** | 译入≥3 语种份额对比 | 低 | 十年窗口截断,长尾译本漏计 |
| **承认时滞** | 区域声誉年→国际承认年的风险模型 | 低 | "声誉确立年"三口径(代表作/区域奖/建制职位)须分记 |
| **门户效应** | 门户窗口的承认份额与可见度前后对比 | 低 | 门户叠加(诺奖之外的布克/凯恩)被折叠 |
| **口头演述卡** | 演述制度登记表 | 中(半构造:程式系统靠田野描述) | 采录者的剪裁权污染"原始演述" |
| **语言选择卡** | 通道/读者/译途登记 | 中 | 双语作家要靠"作品语种+写作现场"双判据 |
| **世界市场通道卡** | 出版/加冕/译入登记 | 中 | 销量与文学影响必须分账 |
| **语言选择的伦理重量** | 只有思想操作化(通读+论争) | **不可构造** | 恩古吉-阿契贝之争压成参数等于替作家发落 |
| **"单一故事"的矫正义务** | 只有思想操作化(批评写作) | **不可构造** | 谁该代表非洲写作是规范问题 |

**反直觉发现(本章铁律)**:**共名度与可构造性成反比是常态**。
这门学科最响的词(黑人性/写回/单一故事)全在谱系右端或正在往右漂;
最能跑的对象(转码比/通道比/集中比)几乎无名。**右端管洞察,左端
管校准**;拿右端对象硬造左端指标(给"非洲性"打分)是文学量化失真
的头号来源——两头都不是。

## 二、结构引擎 1:转码链引擎(口头性的算术骨架)

**直觉图像**:格里奥的嗓子里,一句赞歌有十个等价变体;进了书,
变体被编辑钉死成一个;译成英语,连这一个也可能被释义掉——但故事
的骨架一路都在。

- **数学化身**:演述=程式库(3 槽位×5 变体)按 0.72 概率组行;转写
  保留程式 0.78;翻译分型保留(赞名谚语 0.52/叙事连接 0.86);对照=
  无口头来源的纯书面创作(套语概率 0.10)。实测(实验幕一):程式
  密度 0.351→0.263(演述的 75%)→0.168(全程 48%),纯书面对照
  0.024(转写=其 11 倍);情节核 8 母题保留转写段 0.945/翻译段累计
  0.887。
- **理论地位**:这是 00 章争 2(连续统)的形式化——**中间态**与
  **分层保真**(程式层磨损,情节层保真)两个读数合起来,"口头性
  是一条谱"才有谱上的刻度。
- **刚性从哪来**:单调衰减与中间态是模型结构给的;软的地方在**
  保留概率**——按编辑方针/译者立场重估,锚形状不锚数值。
- **分工**:口传生成机制的汉语现场归中国民间文学家族(文字提及);
  本引擎只管**非洲口头资源进入出版链的衰减结构**。

## 三、结构引擎 2:语言市场引擎(语言之争的算术骨架)

**直觉图像**:同一个作家站在语言分岔口:左边是欧语通道(世界的
直航,境内的小众舱),右边是本土语通道(境内的大众舱,出海要转机),
中间是双语通道(两张票都买,钱包先瘦)。

- **数学化身**:108 位作家三通道,境内读者/万人与十年译入语种数:
  欧语 6.8 与 6.19;本土 22.9 与 0.83;双语 29.3 与 6.17。实测(实验
  幕二):欧语世界可见度=本土的 7.4 倍而境内读者=本土的 30%;本土
  译入≥3 语种份额 17%=欧语 97% 的 17%;双语综合得分 1.11=最强单语
  (0.60)的 1.86 倍,单书成本 26.7 月=欧语 14.2 的 1.88 倍。
- **理论地位**:这是 00 章争 1(阿契贝 vs 恩古吉)的形式化——**
  争论的数学是市场结构,不是立场**;双语对冲最优而成本最高,把
  "该用什么语言"翻译成"谁付对冲成本"。
- **刚性从哪来**:双向反差与对冲-成本差是模型结构给的;软的地方在
  **行情参数**(读者规模/译种期望按出版观察风格化)。

## 四、结构引擎 3:承认时滞引擎(加冕制度的算术骨架)

**直觉图像**:区域经典先在大陆内部长成,世界奖台隔着一片海;
每隔几年一艘"诺奖渡轮"靠岸,一次带走过一批人——门开的时候,
是成批放行。

- **数学化身**:70 位作家,承认风险随区域声誉积累上升(0.010+0.009×
  min(t,10)),五次门户(1986/1988/1991/2003/2021)窗口×3.0。实测
  (实验幕三):平均时滞 9.2 年,中位 8.0 年,≥5 年者 75%;门户窗口
  占在险时间 30% 却释放 50% 的首次承认(集中比 1.7);门户后 5 年
  同区域未获奖作家可见度=门户前的 2.7 倍。
- **理论地位**:这是"阿契贝之问"的模型版——**外部承认跟随内部
  建制化,且以门户批量到货**;锚例(通说):索因卡 1960《森林之舞》
  首演→1986 诺奖≈26 年;古尔纳 1994《天堂》布克短名单→2021 诺奖
  ≈27 年;阿契贝终身未获诺奖(2007 布克国际)——模型给的是结构,
  锚例给的是尺度。
- **刚性从哪来**:时滞为正与集中释放是模型结构给的;软的地方在**
  门户乘数与"承认"口径**(诺奖/布克/凯恩如何折算)。

## 五、结构卡 schema:把一场演述、一次选择、一部作品钉进三张卡

**先答为什么**:非洲文学评估的难点在"作品与通道互相成就"——
一部作品的意义一半在文本,一半在它走的语言通道与加冕时序。结构卡
是**有限字段的压缩格式**:字段固定、填空即可复用、可比可查可补;
每张卡带"证据分账"栏,强迫评估者区分**文本内证据**与**语境推断**。

### 卡 1:口头演述卡(把一场演述钉进制度)

```
【口头演述卡】
语种与文体(格里奥史诗/赞名诗/乌坦齐/口头戏剧):________
演述场合与听众(谁请、谁听、怎么付酬):________
程式系统(槽位/变体/可听出的重复):________
采录与转写史(谁采录、何时、经何种语言):________
转码链读数(转写保留/翻译保留,可估):________
情节核清单(母题序列):________
证据分账(演述实录/整理者剪裁/语境推断):________
```

样例(已填,《松迪亚塔史诗》,通说口径):语种文体=曼德语格里奥
史诗;场合听众=王室与社群仪式场合,格里奥世袭执业;程式系统=赞名
与叙事程式组合(通说概说);采录转写=格里奥 Mamadou Kouyaté 口述,
尼昂 1960 年以法文整理;转码链=口述→法文整理→英译→中译(幕一
衰减链的活例);证据分账=整理者的剪裁权必须单列——"整理本不是
演述的照片,是它的翻译"。**读卡法**:采录转写栏与证据分账栏同看
——**谁执笔,谁定形**。

### 卡 2:语言选择卡(把一次语言决定钉成市场对账单)

```
【语言选择卡】
写作语种(通道:欧语/本土/双语,哪年换的):________
境内读者层(该语种的文学读者规模):________
世界通道(直航出版/中介译本/自译):________
自译状态(是否自己译成通道语):________
成本结构(单书周期/谁补贴):________
身份声明(改造通道语/语言革命/双语对冲):________
证据分账(书目与语种/访谈自述):________
```

样例(已填,恩古吉,通说口径):通道=英语写作至 1970s 末,此后
基库尤语;境内读者层=基库尤语区(东非大语种之一);世界通道=自译
英语(《十字架上的魔鬼》1982 年英译通行世界);自译=是(作者本人
主持英译);身份声明=语言革命(《去殖民的心智》1986);证据分账=
基库尤语原作书目与英语译本书目分列。**读卡法**:通道栏与成本栏
同看——**语言革命的世界代价由自译劳动支付**(幕二双语通道成本
1.88 倍的活人版)。

### 卡 3:世界市场通道卡(把一部作品的世界之旅钉进账本)

```
【世界市场通道卡】
首版(语种/出版社/年份):________
加冕记录(奖项/短名单,作家与作品分记):________
译入语种数与首译年:________
旧作重译窗口(加冕后旧作再版时点):________
门户归属(哪次门户带它进门):________
市场读数(销量与文学影响分账):________
证据分账(出版书目/评论话语):________
```

样例(已填,《瓦解》,通说口径):首版=英语,Heinemann,1958;加冕=
作家获布克国际奖 2007,作品本身以选目与课程建制立典;译入=五十余
种语言(通说);旧作重译=历年常新版不断;门户归属=1986 索因卡门户
所开的英语经典序列的核心成员;市场读数=逾两千万册销量与"非洲现代
小说纪元"的文学影响分账;证据分账=出版书目为主,课程大纲佐证。
**读卡法**:加冕栏与译入栏分开看——**加冕晚于译入多年的作品
(《瓦解》),靠的是通道内经典化,不是奖台**。

**判定流程**(把一个非洲文学主张钉到谱系上):

```
该主张的核心对象能写成分布、比或链吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(填空带解释)─────▶ 中段:卡片化+论争双录,禁止硬算
  └─ 不能(伦理重量/矫正义务)─▶ 右端:思想操作化+批评写作,禁止压成参数
```

## 六、谱系×引擎×两支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| [口头传统与早期非洲文学](讲透口头传统与早期非洲文学/README.md) | 左端(转码衰减)经中段(口头演述卡)到右端(黑人性的规范内涵) | 转码链引擎全境+语言市场引擎前史侧 | 分裂:转码链可算,黑人性宣言不可 |
| [现当代非洲文学](讲透现当代非洲文学/README.md) | 左端(双市场行情、承认时滞)经中段(语言选择卡/市场通道卡)到右端(语言伦理重量) | 语言市场引擎+承认时滞引擎全境 | 分裂:行情与时滞可算,语言伦理不可 |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——转码链
与行情走计算,三张卡走填空加双录,伦理重量永远走批评写作。**没有
哪个支全家可构造,也没有哪个支全家不可构造**——这门学科的诚实,
就在把这条谱系画清楚。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

演述卡量"一场口传怎么变成书",语言卡量"一个作家怎么选战场",
