## ② 核心思维模式(这个分支怎么想问题)

1. **深流之眼**:非洲文学先看口头层——格里奥/赞名诗/utenzi 的
   程式住进了文本哪里;口头性是一条谱不是开关(转写文本程式密度
   0.263,卡在演述 0.351 与纯书面 0.024 之间)
2. **分层保真之眼**:转码链上程式层磨损(全程掉到 48%)而情节核
   保真(累计 0.887)——**格里奥进了小说,剩下的是骨头**:剩下的
   口头性主要住在情节核里
3. **通道之眼**:每个作家先问语言通道——欧语(世界可见度 7.4 倍/
   境内读者 30%)、本土语(境内深/出海难:≥3 语种份额 17% 对 97%)、
   双语(对冲得分 1.86 倍/成本 1.88 倍)——阿契贝与恩古吉吵的
   数学是市场结构,不是立场
4. **批量之眼**:世界承认是一批一批到的——平均滞后区域声誉 9.2 年,
   门户窗口以 30% 的时间释放 50% 的承认,门户后同区域可见度×2.7;
   奖打开的是门,不是窗
5. **范畴之眼**:"非洲文学"这个袋子本身是 1962 马凯雷雷会议+伦敦
   出版织的——用范畴时记得查编织记录;北非阿拉伯语写作本体按语言
   归东方文学(75051),马哈福兹是边界案
6. **证据分账伦理**:涉采录(格里奥整理本)与加冕(奖项行情),
   文本内证据与语境推断分开记;整理本不是演述的照片,是它的翻译

## ④ 常见误区与禁忌

- **把马哈福兹当非洲文学家族成员**:阿拉伯语写作本体按语言共同体
  归东方文学(75051);本家族只收"非洲诺奖序列"的现象侧(边界案)
- **把"非洲=无文字大陆"当前提**:埃塞俄比亚吉兹文书写、廷巴克图
  手稿、阿贾米书写都是前殖民书面传统——大众层面演述是第一现场,
  但书面支流从来存在
- **把黑人性当"黑人文化"标签**:它是具体的诗学纲领与政治纲领
  (1930s 巴黎铸造),有正题有反题(索因卡的讥评),通说+反方双录
- **把"写回"当姿态词**:写的技术是语言改造(阿契贝的谚语化英语),
  姿态好学,手艺难传——只谈"回"不谈"写"是用法走样
- **把诺奖当发现**:承认不是发现,是追认(平均滞后 9.2 年);把
  加冕与译入混作一团是行情报告的常见错——旧作先热,新作第二批
- **把语言之争当道德题裁断**:阿契贝 vs 恩古吉是市场结构的两极,
  双录不栽判;机器供通道行情,不供判决书
- **把"单一故事"当万能套语**:批评工具磨损成口号就失去工具性;
  每用十次,回炉一次原演讲
- **用"格里奥"时忘了它是转口词**:法语殖民文献的称呼盖过了本名
  jeli——论制度用 jeli 更准(02 章美之时刻 5)

| 要后殖民理论/翻译理论的一般机制(萨义德/旅行理论) | → [../讲透比较文学/README.md](../讲透比较文学/README.md)(方法论 vs 本家族现场个案) |
| 要世界文学编年全景(非洲在哪一段) | → [../讲透世界文学史/README.md](../讲透世界文学史/README.md)(编年并陈 vs 本家族纵深) |
| 要汉语民间口传的程式-类型-变异机制 | → 中国民间文学 75037(同波,文字提及;本家族管非洲现场的流通结构) |
| 要奴隶贸易/殖民史/去殖民运动的史学本体 | → 历史学/政治学宇宙(文字提及;本家族只做文学后果) |
