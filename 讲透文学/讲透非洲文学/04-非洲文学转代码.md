# 04 · 非洲文学转代码:把转码链、语言市场与承认结构搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:非洲文学的谱系左端(03 章)几乎可以无损转码,右端
> 几乎不可转码;三条代码走廊——**口头转码链**、**语言双市场**、
> **承认时滞与门户**——把"格里奥进小说剩的是骨头""阿契贝与恩古吉
> 吵的是市场""诺奖是一批一批到的"变成可跑、可断言、可做参数扫描
> 的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",非洲文学转代码要解决"**流通与演述
的代理化**":把一段学科语言("转写丢了一半程式""母语写作出不了海"
"获奖带动同乡")先翻成模型(衰减链算子/三通道计数/风险模型),再
翻成代码。损耗全部发生在第一步——所以本章先划清哪些对象第一步就
走得通(绿色区),哪些走不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 口头程式密度 | 重复 n-gram 覆盖率(盲探测器,不用程式库标签) | 实验幕一全程纯标准库 |
| 转码链衰减 | 演述→转写→翻译的逐段算子+覆盖率比 | 幕一;单调衰减断言 |
| 情节核保留 | 母题清单逐段点验 | 幕一;分层保真断言 |
| 语言通道行情 | 三通道读者/译种/成本计数 | 幕二;双向反差断言 |
| 跨国壁垒 | 译入≥k 语种份额对比 | 幕二 |
| 承认时滞 | 区域声誉年→国际承认年风险模型 | 幕三;时滞分布断言 |
| 门户效应 | 门户窗口承认份额+前后可见度对比 | 幕三;集中比断言 |
| 三张结构卡 | 定长字段记录+完整性断言(证据分账非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **语言选择的伦理重量**:代码能量通道行情,量不了"该不该弃英语"
   ——这是规范问题,写进评分函数等于让一种语言政治冒充自然法则
   (00 章争 1 永远双录)。
2. **"单一故事"的矫正义务**:批评工具可以流程化,批评的**责任**
   不可以——谁该代表谁写作,裁决权在论争,不在参数。
3. **殖民史与去殖民运动的史学判决**:史学本体归历史学与政治学宇宙
   (文字提及);机器只供转码与通道的形状,不供判决书。
4. **保留概率/行情/门户乘数等骨架假设**:三幕的全部关键参数都是
   通说观察的风格化——转码者必须把它们写在显式假设栏,重估会移动
   数值,锚形状不锚数值。

**边界的一句话**:绿色区=转码链+语言市场+承认结构三引擎,覆盖
"流通直觉的校准";红色区提醒:**转码是文学社会学的试算器,不是
非洲文学的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:口头转码链走廊(演述资源→出版链的损耗监测)

```
演述事件流 ──代理化──▶ {文本行, 阶段(演述/转写/翻译), 程式标记(仅生成用)} 
      │                          │
      └──统计──▶ 各阶段重复 4-gram 覆盖率 + 情节核点验 ──▶ 中间态/分层保真读数
```

- **理论→模型**:02 章"程式"条目与 03 章引擎 1 的参数化——程式库
  组行+分型保留算子;**度量器是盲的**(不使用生成时的程式标签),
  只看重复结构。
- **算法层**:n-gram 计数 O(N)(哈希表);全程毫秒级(实验幕一
  192 份文本)。
- **本家族实现**:[`experiments/oral_language_market.py`](experiments/oral_language_market.py)
  幕一——断言转写密度介于演述与纯书面之间(>纯书面 3 倍)、每步
  单调衰减≥10%/15%、情节核累计保留≥0.86。
- **真实系统**:口头传统的**数字化档案**(演述录音→转写→多语发布
  的损耗台账);濒危语言的**语料建档**(哪一层信息在哪一站蒸发);
  文体学的**口源性探测器**(判别文本的口头基因,用于整理本鉴定与
  数字人文教学)。
- **性能工程要点**:算力可忽略,**价值全在口径**——分词标准(词 vs
  音节)、窗宽(n-gram 的 n)、**功能等价替换的盲区**(同槽位换变体
  不改变语义但探测器看不见:衰减被系统性低估,断言只锚形状)。与
  模型家族同一条铁律:底表不标准,输出只是自洽的伪精确。

### 走廊 2:语言市场走廊(多语发布的通道组合对账)

```
作家/作品集 ──代理化──▶ {通道, 境内读者, 十年译入语种, 单书成本}
      │                              │
      └──计数──▶ 双向反差比 + 壁垒份额 + 对冲得分/成本比 ──▶ 通道结构读数
```

- **理论→模型**:03 章引擎 2 的参数化——欧语(直航出海/境内小众舱)、
  本土语(境内大众舱/出海转机)、双语(双票/双倍价)。
- **算法层**:计数与均值 O(N);实验幕二 108 位作家毫秒级。
- **本家族实现**:同实验幕二——断言欧语可见度>本土 4 倍、欧语境内
  读者<本土 45%、本土≥3 语种份额<欧语 30%、双语得分>最强单语 25%
  而成本>单语 1.5 倍。
- **真实系统**:多语言内容产品的**发布通道组合**(先全球语后本地/
  先本地后全球/双发——幕二矩阵的运营版);**本地化优先级**决策
  (哪个语种的市场深度值得先投);作者与出版社的**双语版税分账**
  (自译劳动的成本科目化)。
- **性能工程要点**:计算平凡,**口径在三处**:①"境内读者"以文学
  读者计,不以人口计;②"译入语种"以首译计,重译分列;③"成本"
  含制作+流通,自译按工时折算。口径三声明齐,对账才有意义。

### 走廊 3:承认时滞与门户走廊(加冕监测与冷启动预警)

```
作家声誉流 ──代理化──▶ {区域声誉年, 国际承认年(右删失), 门户事件表}
      │                              │
      └──仿真──▶ 时滞分布 + 门户窗口承认份额 + 前后可见度比 ──▶ 迟到结构读数
```

- **理论→模型**:03 章引擎 3 的参数化——风险随区域声誉积累上升,
  门户窗口×乘数;观测期末未承认者为**右删失样本**。
- **算法层**:逐年风险仿真 O(人数×年数);实验幕三 70 人毫秒级。
- **本家族实现**:同实验幕三——断言平均时滞≥9 年、≥5 年者≥75%、
  门户承认份额≥时间份额 1.6 倍、门户后可见度≥门户前 2 倍。
- **真实系统**:内容平台的**获奖流量运营**(award bump:获奖事件的
  峰值预案——幕三说旧作先热,先备好经典库存的再分发);**新市场
  进入的门户策略**(借大事件开门 vs 自建门户:评奖/榜单/节展);
  组织的**承认滞后审计**(内部公认的资深者多久获得外部称号——
  时滞结构不只在文学界)。
- **性能工程要点**:右删失是这条走廊的第一坑——未承认作家不能当
  "时滞无穷大"丢弃也不能当零剔除,**生产版换生存分析口径**
  (Kaplan-Meier 型估计),教学版以"承认率≥80%"的样本近似;这是
  文学实验反哺工程直觉的直接一例(用户留存/晋升/获奖数据全是删失
  数据)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:转码损耗仪表盘——给多语内容管道上"体检表"

- 任何"原始内容→中间格式→多语发布"的管道(文档/知识库/字幕)
  都可以像幕一那样**分段测量代理指标的留存**:术语一致性、套语
  保留率、结构标记存活率;每过一站记一次读数——**衰减不报错,
  只在仪表盘上显形**。别把三站平均成一个数:平均即失真(与东欧
  家族"分通道不合并"同一条纪律)。

### 落点 2:发布语言的通道组合——先本地还是先全球

- 多语言产品的语言策略就是幕二矩阵:全球语通道(可见度高/社区
  窄)、本地语通道(社区深/出圈难)、双语(最优对冲/成本最高)。
  幕二给的不是答案,是**对账框架**:先填三通道的读者/可见度/成本
  三行,再选组合——**语言决策是产品决策,不是立场决策**。

### 落点 3:加冕窗口的冷启动——旧库先热

- 任何"被大事件照亮"的内容(获奖/热搜/出圈)都要预案:幕三说
  承认的行情先热**旧作**——把经典库存的再分发排在新品前面;门户
  效应(可见度×2.7)是集体红利,备货要按"一批一批到"备,不是
  按单品备。

### 落点 4:骨架假设的显式化——参数即立场

- 三条走廊的全部关键参数(保留概率 0.78/0.52/0.86、通道行情、门户
  乘数 3.0)都写在代码头部常量区;**改参数=改文学史观**,重估参数
  的敏感性扫描(✍️练习 1)是这类人文实验的"性能压测"。
