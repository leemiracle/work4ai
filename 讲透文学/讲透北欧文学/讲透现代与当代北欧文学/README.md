## 诞生

- **谁/何时**:1835 安徒生第一册童话——小语种靠"最不依赖语境的文类"
  完成第一次世界出口;1864-91 易卜生旅居欧陆 27 年,问题剧立型;勃兰兑斯
  1871 年起讲稿点燃"现代突破";1909 拉格洛夫首位女性诺奖;1955 拉克斯内斯
  让冰岛进入世界正典;1965-75 马丁·贝克开 noir 先河;2023 福瑟获奖(均通说)。
- **因什么问题**:①小语种怎么被世界看见(文类选择+剧场外交+奖项杠杆)
  ②戏剧怎么处理社会(问题剧→斯特林堡的心理与梦→福瑟的沉默)③承认在
  峰值前还是峰值后(从盖棺定论转为生涯助推)。

## 核心问题

**已解决(通说)**:双出口线(童话/问题剧)与"现代突破"的建制事实;
诺奖北欧年表(16 位,1901-2026);noir 品类史(贝克开山/千禧品类化)。
**未解决/深水区**:北欧例外论(制度解释 vs 记账术,双录);noir 是社会批判的大众化还是自我东方主义(01 章主线 C);极简之后下一个出口。

## ✨ 这支最美的一个事实

**他们用两只手写字**(幕二实测):纯母语北欧作者 77.6% 在 45 年生涯内
未达全球可见(枢纽瓶颈),达可见者中位时滞 38 年=大语种基线(20 年)的
1.9 倍;而自英语写作或自译的双语作者未可见仅 0.1%,20 年可见度达基线
**95%**——自译通道几乎抹平语种差距;**一支笔写母语,另一只手递英语**。
