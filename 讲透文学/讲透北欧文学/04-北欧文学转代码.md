# 04 · 北欧文学转代码:把血仇网络、全球通道与承认时滞搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:北欧文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**萨迦网络**、**全球通道**、
> **承认时滞**——把"萨迦是网络叙事的中世纪范本""他们用两只手
> 写字""诺奖从盖棺定论到生涯助推"变成可跑、可断言、可做参数扫描
> 的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",北欧文学转代码要解决"**结构代理
化**":把一段学科语言("萨迦把恩怨写成网络")先翻成模型(图+义务
转移),再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清
哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条
走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 家族聚簇+仇杀桥 | 血亲边/血仇边二类图+密度/分量/桥占比读数 | 实验幕一全程纯标准库 |
| 血仇的义务转移 | 逐代状态机:复仇(翻转)或偿金(终止) | 幕一 [1b];终止率可参数扫描 |
| 通道瓶颈+时滞 | 双队列仿真(译出率/时滞/折扣三参数) | 幕二;可见度与未可见份额双输出 |
| 自译双语通道 | 直通队列对照(效率系数) | 幕二;与大语种基线配对比较 |
| 承认时滞 | 年表读数+声誉存量门槛选人模型 | 幕三;门槛分期可调 |
| 场域门槛标定 | 分期阈值+刚够格优先的打分函数 | 幕三;生涯助推选项开关 |
| 三张结构卡 | 定长字段记录+完整性断言(证据分账非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **萨迦的叙事之美**:代码能量"族间边占比",量不了叙述者退后
   三步的克制之美——那需要通读的见证(03 章右端)。
2. **极简剧场的静默**:福瑟的停顿在纸面上不存在,只在剧场的身体
   经验里发生;给"静默"打分是对观演的冒名顶替。
3. **诺奖的价值判断**:幕三给得出时滞与门槛,给不出"该不该发";
   把承认模型当价值裁判,等于让一个世纪的场域政治冒充美学法则。
4. **通道与门槛参数**:幕二的译出率/折扣、幕三的分期门槛是**骨架
   假设**——按出版统计与档案重估会移动数值(✍️练习 1);转码者
   必须把它们写在显式假设栏。

**边界的一句话**:绿色区=网络+通道+场域三引擎,覆盖"学科直觉的
校准";红色区提醒:**转码是叙事学与文学社会学的试算器,不是北欧
文学的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:萨迦网络走廊(手稿人物库的族间桥检测)

```
萨迦文本 ──代理化──▶ 血亲边/血仇边二类图(家族聚簇+仇杀桥)
      │                        │
      └──仿真──▶ 义务转移状态机 ──▶ 密度比/桥占比/终止率曲线 ──▶ 记账判定
```

- **理论→模型**:萨迦=谱系骨架(族内密网)+恩怨情节(族间仇杀
  桥)+偿金标点(03 章引擎 1);义务转移:每笔杀戮留应付,复仇翻转
  或偿金清账。
- **算法层**:建图 O(V²)(家族规模小);连通分量 O(V+E);链仿真
  O(N×代数),N=4000 秒级(实验幕一)。
- **本家族实现**:[`experiments/saga_nobel_channel.py`](experiments/saga_nobel_channel.py)
  幕一——断言族内密度>族间 5 倍、血仇占族间>55%、去族间边散成
  6 分量、终止率单调上升且第三代>第一代 1.6 倍、偿金份额逐代上升
  (机制检查:账本从血记到钱记)。
- **真实系统**:手稿数字库的**人物-关系标注层**(01 章主线 B 的
  数据侧:给数字化萨迦加可计算的关系边);叙事学的**聚簇-桥诊断
  器**(输入共现矩阵,输出社区结构与桥边清单);文类比较的**网络
  拓扑指纹**(家族萨迦 vs 国王萨迦 vs 现代小说的图统计对比)。
- **性能工程要点**:算力全在**边类标注的数据工程**(血亲/血仇/联姻
  的判定靠文本细读,是人力瓶颈不是算力瓶颈)——与模型家族同一条
  铁律:底表不标准,输出只是自洽的伪精确。

### 走廊 2:全球通道走廊(小语种作品的出海诊断)

```
小语种作品 ──代理化──▶ 双队列仿真: 枢纽(译出率/时滞/折扣) vs 自译直通
      │                              │
      └──对照──▶ 大语种基线 ──▶ 未可见份额/时滞倍数/20年可见度比 ──▶ 通道判定
```

- **理论→模型**:通道税=瓶颈+时滞+折扣(03 章引擎 2);自译通道
  免税;基线配对比较(同分布作者队列)。
- **算法层**:每作者 O(生涯年数×书数),N=2000×3 队列秒级(幕二)。
- **本家族实现**:同实验幕二——断言纯母语未可见>30%(实测 77.6%)、
  纯母语时滞>基线 1.5 倍(实测 1.9)、双语 20 年可见度>基线 85%
  (实测 95%)且未可见与基线同量级(实测 0.1% 对 0.0%)。
- **真实系统**:出版选题的**出海通道诊断**(一部小语种作品的译出
  概率/时滞/品类货架三读数);译者补贴政策的**参数化评估**(改
  TRANS_P 看未可见份额怎么塌——01 章主线 D 的政策接口);文学出口
  统计的**口径治理**(译入量与改编权两本账分列)。
- **性能工程要点**:队列间公平靠**同分布配对**(同一质量分布抽三
  队列);队列种子必须确定性偏移(勿用 hash()——跨进程盐化不稳定,
  本实验的实测教训),否则"可复现"三个字不成立。

### 走廊 3:承认时滞走廊(奖项的承认哲学监控)

```
奖项年表 ──代理化──▶ 时滞=授奖年−峰值年(峰值双认定);门槛分期选人模型
      │                              │
      └──标定──▶ 分期阈值 θ + 生涯助推开关 ──▶ 时滞曲线/年龄差/低时滞份额
```

- **理论→模型**:声誉存量饱和+分期资格门槛+刚够格优先(03 章引擎
  3);峰值认定双解(福瑟 2 年或 24 年)。
- **算法层**:每授奖年 O(候选数),候选数百级;全程毫秒级(幕三)。
- **本家族实现**:同实验幕三——断言早期平均时滞>当代 1.7 倍(实测
  2.6 倍)、四段单调下降、低时滞份额早期<25%→当代>45%(实测
  0%→83%)、年龄差>8 岁(实测 15 岁)。
- **真实系统**:奖项研究的**承认时滞监控**(逐年更新"授奖年−峰值
  年"分布,峰值双认定);文化政策的**杠杆效应评估**(授奖前后
  译介提速的差分读数——福瑟 2023 案例);图书采购的**获奖滞后
  补采**(哪些"高时滞正典"该趁助推期补齐)。
- **性能工程要点**:时滞读数对**峰值认定敏感**(一个作家的峰值
  换个认定法,时滞变 22 年)——先声明峰值的认定规则,再谈时滞
  长短;这与滞后搜索要先声明步长是同一条纪律。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:手稿库的关系边治理——边类分立不合并

- 数字化萨迦的人物-关系层一律**边类分立**:血亲/血仇/联姻三类边
  各一列,不合并成"相关"一列——幕一的全部读数(聚簇、桥、清偿)
  都挂在边类上;合并边类等于把恩怨账本记成流水账。

### 落点 2:小语种作品的出海诊断书

- 任何小语种作品立项(翻译/引进/改编)前出一份三读数诊断:译出
  概率(枢纽流量)、预计时滞(排队位置)、品类货架(市场命名);
  幕二说第三个读数(折扣)常被忽略——**通道税里最隐性的一项**。

### 落点 3:奖项承认的"缺行记录"

- 建奖项数据库时给"未获奖的大师"留缺行(易卜生/斯特林堡的诺奖
  空行,通说)——承认研究的数据完整性不在得主表,在**缺席表**;
  缺行与实行的比例,才是场域门槛的完整读数(03 章练习 3 的系统版)。

### 落点 4:仿真可复现的种子纪律

- 所有蒙特卡洛走确定性种子;队列/场景的派生种子用显式偏移表,
  **禁用 hash()**(字符串哈希跨进程盐化,同种子不同果——本实验
  开发期的实测教训,幕二曾因此两次跑数漂移);这条纪律写进任何
  文学仿真的 CI 门禁。

## ✍️ 练习

1. 🐍 给走廊 2 换补贴参数:把 TRANS_P 从 0.55 提到 0.85(强力译者
   补贴),重跑幕二,看纯母语未可见份额怎么塌、时滞怎么缩——
   "制度变量"的最小实验
2. 🐍 给走廊 3 换峰值认定:把福瑟的峰值年从 2021 改成 1999,重算
   锚读数,看年表结论怎么翻——"峰值认定敏感"的亲手版
3. ✋ 用落点 2 给一部未出海的北欧作品写三行诊断书(译出概率/时滞/
   货架),并给一行"自译改造建议"——通道卡的工程版
4. ✋ 把落点 3 写成一页数据备忘:奖项库的缺行字段怎么设计(缺席者/
   缺席年/公认峰值),为什么缺行必须显式而不能留空

缺行与实行之比。
