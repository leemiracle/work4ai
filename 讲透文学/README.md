## 三、特征速查(节选)

- 叙事学/文体学/文本细读工具 → 文学理论
- 作品之美/审美经验 → 文艺美学
- 批评方法/批评史 → 文学批评
- 影响研究/平行研究/跨文明对话 → 比较文学
- 先秦至清的文脉 → 中国古代文学
- 五四至 1949 → 中国现代文学(1840-1911 为近代文学)
- 诗词曲赋小说散文分体研究 → 中国各体文学
- 口头传统/神话/史诗 → 中国民间文学
- 蒙藏维哈朝等民族文学 → 中国少数民族文学(GB/T 11 三级逐条落子)
- 古典到当代的世界编年 → 世界文学史
- 印度/日本/波斯等 → 东方文学
- 黄金时代/白银时代/苏联解体后 → 俄国文学
- 莎士比亚到当代 → 英国文学;启蒙到新小说 → 法国文学;狂飙到战后 → 德国文学;
  但丁到现代 → 意大利文学;清教到后现代 → 美国文学;诺奖北欧五国 → 北欧文学;
  中东欧诸国 → 东欧文学;魔幻现实 → 拉美文学;口头与书写之争 → 非洲文学;南太平洋 → 大洋洲文学
