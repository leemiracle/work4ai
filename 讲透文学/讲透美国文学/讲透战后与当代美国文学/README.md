# 讲透战后与当代美国文学 · 正典的重写与扩盟——战后、后现代到莫里森的诺奖

> **定位句**:这支负责**战后与当代侧**:"不断扩盟的正典"怎么重写名单——战后一代把青春期与 suburbia 立成文体(《麦田里的守望者》1951/厄普代克"兔子"),垮掉的一代在门外敲门(《嚎叫》1956/《在路上》1957),后现代连"反正典"的写法也收编(《五号屠场》1969/《万有引力之虹》1973),族裔文学崛起从正典外走进名单核心(赖特-艾里森-鲍德温-莫里森/《女勇士》/《芒果街》),1993 年莫里森诺奖为正典化标志、多元正典成为默认设置(均通说)。与殖民至二战支分工:**那边打地基立国家文学,这支改名单扩盟**——棘轮的转动全在本支地界。
> GB/T 13745 75071 美国文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:塞林格《麦田》(1951)-厄普代克《兔子,跑吧》(1960)立战后文体;金斯堡《嚎叫》(1956)-凯鲁亚克《在路上》(1957)立垮掉的一代;冯内古特《五号屠场》(1969)-品钦《万有引力之虹》(1973)立后现代;赖特《土生子》(1940)-艾里森《看不见的人》(1952)-鲍德温论战-赫斯顿 1970s 复兴-莫里森《宠儿》(1987,1988 普利策)成非裔线;汤婷《女勇士》(1976)开亚裔建制化;西斯内罗斯《芒果街》(1984)开拉丁裔线;莫马迪《黎明之屋》(1968)开原住民线;正典战争(斯坦福 1988/布鲁姆 1994)与莫里森 1993 诺奖收口(均通说)。
- **因什么问题**:①战后繁荣写什么(青春期与中年的反叛)②"反正典"的写法算不算文学③正典名单为谁而开④族裔标签是债务还是资本。

## 核心问题

**已解决(通说)**:后现代与族裔文学崛起的坐标清晰;正典战争两端文本(斯坦福改革/《西方正典》)与诺顿扩容史可查;莫里森 1993 诺奖作为多元正典加冕标志成为通说。

**未解决/深水区**:扩盟到头了吗("扩张疲劳"论,通说综述;棘轮的增速问题,家族 01 章主线 A);标签政治与开放期的互相锁定(幕三的双面性无终局);例外论退场后"美国文学"容器还自洽吗(跨国转向)。

## ✨ 这支最美的一个事实

**诺奖作为扩盟的收据**:1993 年斯德哥尔摩把文学奖递给莫里森——首位非裔美国作家(通说);奖还是那个奖,受奖名单变了。为什么美:**席位扩张先在选本与课表里悄悄发生(棘轮),奖项只是最后开收据**——幕一模型里 1990s 正是运动峰值:加冕机器不动,被加冕者的名单在换;《詹姆斯》(2025 普利策,通说)证明扩盟的最高形态是派人进旧正典文本内部改写视角(00 美之时刻 4 的现场)。

## 假设与依赖

- 买入"建制行为可代理文学地位":奖项与选本份额被当作正典化的观测面;作家作品评述一律通说口径,争议双录
