# 04 · 美国文学转代码:把席位、双轨与生涯搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:美国文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**席位再分配仿真**、**双轨相关
> 分析**、**双市场生涯模拟**——把"正典扩张是棘轮不是钟摆""市场投
> 短期票,正典投长期票""标签是债务还是资本取决于开放期"变成可跑、
> 可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",美国文学转代码要解决"**代理化**":
把一段文坛语言("正典战争谁赢了")先翻成模型(席位份额+棘轮律),
再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清哪些对象
第一步就走得通(绿色区),哪些走不通(红色区),再给三条走通了的
走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 文学史概念 | 代码化身 | 备注 |
|-----------|---------|------|
| 正典席位再分配 | 份额序列递推+棘轮律+防线 | 实验幕一全程纯标准库 |
| 被置换不阵亡 | 防线约束(min 份额)的断言 | 幕一 1a |
| 制度化惯性 | 峰值后增量的时窗断言 | 幕一 1b |
| 棘轮 vs 钟摆判别 | 双泄漏系数(4%/40%)对照实验 | 幕一 1c |
| 当年销量/长期在版/入典 | 三元组生成+双相关系数 | 幕二 |
| 双轨预测力对比 | 分组入典率与加成比 | 幕二 2a/2b |
| 族裔作家生涯对冲 | 双渠道收入流+被弃风险仿真 | 幕三 |
| 标签双面性 | 开放度交互项的 logit | 幕三(封闭/开放两世代) |
| 三张结构卡 | 定长字段记录+完整性断言(证据栏非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **文学性**:代码能算入典概率,算不出《宠儿》好不好——风格判断
   只能由阅读见证(03 章右端)。
2. **"美国性"**:例外论叙事的文化气质不可枚举;把它压成打分,等于
   让一个批评立场冒充自然法则。
3. **标签的真诚度**:去标记是策略还是自然,动机不可观测;幕三的
   "策略"是研究者归类,不是传记事实。
4. **多元化好不好**:席位构成变化可算,"该不该变"是规范立场,
   不写进评分函数(01 章判读要点 2)。

**边界的一句话**:绿色区=席位+三元组+生涯三引擎,覆盖"建制行为的
校准";红色区提醒:**转码是出版与研究的试算器,不是文学价值的
替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:席位再分配走廊(正典重排拟合)

```
选本/课表席位史 ──代理化──▶ 份额递推: 放出=min(RELEASE·M·板块, 可让余量)
      │                            边缘竞争=推力×缺口; 回吐=LEAK·(1−M)
      └──递推+对照──▶ 棘轮读数/防线读数 ──▶ 峰值后增量与钟摆对照断言
```

- **理论→模型**:运动强度 M(t) 外生(批评运动史),席位转移内建
  (03 章引擎 1);防线=旧正典不可清零的建制约束。
- **算法层**:九个观察点×七组,一次递推 O(点数×组数),微秒级
  (幕一全程);对照实验=同随机流双泄漏系数各跑一遍。
- **本家族实现**:[`experiments/canon_expansion_two_track.py`](experiments/canon_expansion_two_track.py)
  幕一——断言旧正典 0.780→0.445 不清零、零席位群体占新增 81.1%、
  棘轮/钟摆=1.82×。
- **真实系统**:教研机构的**选本/课表审计**(历版选目对照自动化);
  出版研究的**正典监测仪表盘**(某群体席位份额逐年读数);数字人文
  的**大纲语料管线**(01 章主线 A 的工程侧)。
- **性能工程要点**:数据量级极小(几版选本),价值全在**口径纪律**
  ——分组口径(谁算"零席位群体")必须先冻结;口径一换,序列
  断裂,棘轮读数作废。

### 走廊 2:双轨筛选走廊(畅销-在版-入典分析)

```
书目史 ──代理化──▶ (spike, inprint, canon) 三元组生成器
      │                            │
      └──600 次生成──▶ 双相关+分组加成比 ──▶ 双轨假设检验/重估
```

- **理论→模型**:当年销量主要由市场契合驱动,在版主要由质量驱动,
  入典只看质量与存续(03 章引擎 2)——双轨分账写进方程结构。
- **算法层**:每书 O(十年)在版追踪;600 书毫秒级(幕二);相关
  系数与分组率全部线性扫描。
- **本家族实现**:同实验幕二——断言 corr 对比 +0.037 vs +0.548、
  四分位 32.5×、畅销前十加成仅 1.20×。
- **真实系统**:出版社的**长销预测**(在版史是最强的入典先导指标
  ——选题会看十年在版,不看当年榜单);媒体的**畅销榜祛魅**(榜单
  新闻自动配注"当年畅销≠入典"的结构读数);图书馆的**馆藏决策**
  (在版率权重高于短期流通)。
- **性能工程要点**:模型极轻,价值全在**代理纪律**——"当年销量"
  与"在版"的取数口径(首印/实销/长销/公版)必须显式;19 世纪
  书目的数据残缺要按缺失机制处理,不能当零。

### 走廊 3:双市场生涯走廊(族裔作家对冲模拟)

```
族裔作家生涯 ──代理化──▶ 双渠道收入流+被弃风险+存续阈值
      │                              │
      └──两世代×1200 生涯──▶ 存续率对比+标签双面性 ──▶ 开放期读数
```

- **理论→模型**:主流渠道高收入高淘汰、族裔社群渠道低收入低淘汰;
  标签的入典溢价=开放度的交互项(03 章引擎 3)。
- **算法层**:每生涯 O(期数);2400 生涯毫秒级(幕三);开放度
  与幕一 M(t) 共享,可做联动参数扫描。
- **本家族实现**:同实验幕三——断言对冲差≥0.22、封闭期标签债务
  (0.205<0.315)、开放期标签资本(0.556=2.71×0.205)。
- **真实系统**:编辑的**作家生涯体检**(双渠道作者的抗风险读数);
  族裔出版的**双渠道发行策略**(社群渠道不是低配,是保险);文学
  社会学的**开放期监测**(奖项与选本构成变化反演开放度,接幕一)。
- **性能工程要点**:生涯仿真天然可并行(作家分流 seed 可复现);
  真正贵的是**归类标注**——"拥抱/淡化标签"的判定依赖批评史共识,
  网络的边是数据工程,不是算法工程。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:长销预测——在版史优先于榜单

- 选题与再版决策的输入排序:十年在版史>课程采用>当年榜单——幕二
  断言的工程版(在版组入典率 4.08× 于畅销前十组);公版节点(如
  盖茨比 2021,通说)是"在版需求"的天然实验窗口,提前两年排期。

### 落点 2:正典监测仪表盘——席位与开放度双读数

- 给目标文类建两条曲线:席位份额(各群体在选本/课表的占比)与
  开放度代理(奖项构成变化);棘轮读数(份额回吐了吗)是唯一需要
  盯的警报——增速放缓是常态,回吐才是结构断裂(01 章主线 A)。

### 落点 3:双渠道发行的代价表——标签策略的预演

- 新作者的渠道组合按幕三模型预读:双市场存续差 +0.22 是对冲溢价,
  精力分流(0.8q×2)是代价;开放期读数决定标签是资本还是债务——
  同一策略在不同窗口的期望值要分开算,合并算会互相抵消。

### 落点 4:课程大纲与书单的审计

- 任何书单/课程上线前跑一次席位审计:分组份额的历史对照(与十年前
  的同类书单比);若无增长的分组占比过高且非有意选目,要么发现了
  被埋没者(价值),要么是选目口径漂移(风险)——审计结果写进
  编选说明。
