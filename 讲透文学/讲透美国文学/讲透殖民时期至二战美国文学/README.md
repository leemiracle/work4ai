# 讲透殖民时期至二战美国文学 · 正典的地基与建国——清教、超验、文艺复兴到迷惘一代

> **定位句**:这支负责**殖民时期至二战侧**:"不断扩盟的正典"怎么打下地基与建国——清教把文学当立国文书(布拉德斯特里特/爱德华兹),爱默生《美国学者》(1837)宣告文化独立,超验主义立"自助"精神(《瓦尔登湖》1854),美国文艺复兴五年爆出《红字》《白鲸》《草叶集》(1850-55),吐温把美国口语立为文学语言(《哈克》1884/85),德莱塞的自然主义与迷惘一代(《太阳照常升起》/《盖茨比》)、福克纳的约克纳帕塔法与南方文艺复兴合成现代主义建国。与战后支分工:**这支打地基立国家文学,那边改名单扩盟**——互为证词。
> GB/T 13745 75071 美国文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:布拉德斯特里特诗集(1650)与爱德华兹布道(1741)立宗教文书的地基;欧文(1819-20)-库珀-爱默生(1836/1837)立独立世代;1850-55 文艺复兴五年(霍桑/麦尔维尔/梭罗/惠特曼,狄金森身后入典,通说);豪威尔斯-詹姆斯-吐温立现实主义(《哈克》1884/85);德莱塞《嘉莉妹妹》(1900)开自然主义;斯泰因题词-海明威-菲茨杰拉德-福克纳立迷惘一代与现代主义(福克纳 1949 诺奖,通说);《我要表明立场》(1930)开南方文艺复兴(均通说)。
- **因什么问题**:①一门殖民地文学凭什么独立②美国英语算不算文学语言③没有国王与教会的国家写什么④"美国梦"许诺了什么、兑现了什么。

## 核心问题

**已解决(通说)**:文化独立的宣言时刻(《美国学者》)与建国一代的名单坐标清晰;文艺复兴五巨著的正典地位稳固;吐温的口语入文公认为美国文学的立户事件(海明威断语,通说)。

**未解决/深水区**:文艺复兴名单的排他性(马西森五人全是新英格兰白人男性,通说批评点);狄金森的"缺席正典"怎么入账(生前未出版);《哈克》结尾段"退场失败"争议长期双录(通说)。

## ✨ 这支最美的一个事实

**一场讲演替一个国家写文化户口**:1837 年爱默生对学会说,我们依赖欧洲的午后余晖太久了(《美国学者》,通说称"思想上的独立宣言")。为什么美:**一门文学的独立不需要军队,需要一个宣言的时刻**——此后吐温立语言、惠特曼立版图、德莱塞立社会面,都是这份讲演的执行条款。家族幕一的"旧正典"席位,起点正是这条文化独立线写下的名单(00 §一)。

## 假设与依赖

- 买入"文化独立叙事":独立宣言被当作第一推动;代价是把殖民地文学记成"前言"、与英国文学的连续面被切掉(00 轴线 2 双录)
- 买入"正典可数席位":建国一代的名单被当作份额序列的起点;作家作品评述一律通说口径,争议双录
