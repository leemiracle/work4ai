# 讲透美国文学 · 一部不断扩盟的正典——从山巅之城到莫里森的诺奖

> **本质一句话**:美国文学=**一部不断扩盟的正典**——清教徒把文学当
> 立国文书(爱德华兹),爱默生宣告文化独立(《美国学者》,通说"思想上
> 的独立宣言"),惠特曼要诗"容纳大陆",马克·吐温把美国口语立为文学
> 语言;二十世纪后半的"正典战争"把白人男性名单改写成多元名单,
> 1993 年莫里森诺贝尔文学奖为正典化标志(通说)。一句话:**先立国,
> 再建国,后扩盟——美国文学的一切机关,都在"谁算美国文学"的反复
> 议席里**。
>

## 一、家族定位

- **两支分工**:同一条"立国-建国-扩盟"主轴的上下游——**殖民时期至
  二战支**(正典的地基与建国:清教/超验主义/美国文艺复兴/现实主义/
  现代主义)与**战后与当代支**(正典的重写与扩盟:战后/后现代/族裔
  文学崛起/当代)。
- **一条主轴贯穿**:文化独立(爱默生)→国家文学(文艺复兴到现代主义
  的"建国一代")→正典扩盟(正典战争到多元正典)。前支守"地基怎么打",
  后支守"名单怎么改";家族实验把三段全部**算术化**(席位再分配/
  畅销-正典双轨/族裔双市场)。
- **零门槛**:读过一本《老人与海》或看过《了不起的盖茨比》电影就能进;
  术语随用随讲(三步法:直觉图像→严格陈述→最小例子)。不要求英语;
  要编年全景去[世界文学史](../讲透世界文学史/README.md),
  要跨语旅行去[比较文学](../讲透比较文学/README.md),
  要单一正典的马太动力学去[英国文学](../讲透英国文学/README.md)。
- 路线 A(问题派):美国文学为什么 19 世纪才"独立"?→00 §七发现 1
  的前史;正典战争谁赢了?→发现 1;《盖茨比》当年畅销吗?→发现 2;
  莫里森和汤婷谁的路对?→发现 3

  →[战后与当代支](讲透战后与当代美国文学/README.md)
- 路线 C(研究派):00→01(正典战争后续/奖项多元化/世界市场三前线)
