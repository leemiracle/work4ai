## 核心问题

**已解决(通说)**:物哀的形状——审美价值-预期寿命倒 U,樱花七日≈峰值
(家族实验律三:L*=6.5 日,昙花与松柏两极皆塌);极简诗形的形式制度——
季语(词典化季节制度)+切字(结构断点),可数可查(家族 02 第一栏)。

**未解决/深水区**:物哀是普遍审美还是江户国学的特定读法(家族 01
主线 A);《源氏物语》写本系统(青表纸/河内)的校勘之争(通说)。

## ✨ 这支最美的一个事实

**樱花为什么是七日**:物哀价值=形式(L)×哀感(L)——太短暂无形式
可凝视(昙花一现),太长久无哀感可触发(松柏千年),乘积峰值在中段
(家族实验律三:L*≈6.5 日,樱花七日 V=0.4207≈峰值);高敏感读者的
审美峰在终章之前(29.0→26.4 章前移)——**物哀不是越惨越美,是给
时间装上敏感器**。
