# 04 · 东方文学转代码:把断口、味感与易逝搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:东方文学谱系的左端(03 章)几乎可以无损转码,右端
> 几乎不可转码;三条代码走廊——**连环悬念走廊**(断口张力+嵌套再生
> +饶命反馈的夜夜动力学+中断位扫描)、**味感走廊**(八味坐标+混味
> 唤起+最优卷入寻优)、**易逝走廊**(形式×哀感乘积曲线+终章峰前移
> 检测)——把"山鲁佐德断在中段买命最多""甜-悲不相容""樱花七日
> 胜过昙花与松柏"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

意大利文学家族转代码要解决"记谱化"(韵式字母谱),东方文学家族要
解决"**机制化**":把一套学科语言("断在关键处""甜-悲不相容"
"对易逝之物的敏感")先翻成模型(断口递归/情感坐标/易逝曲线),再
翻成代码。翻译的损耗全部发生在第一步——所以本章先划清哪些对象第一
步就走得通(绿色区),哪些走不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 中断-续讲结构 | 断口张力+嵌套再生的夜夜递归 | 走廊 1(实验律一) |
| 断章的买命效率 | 中断位扫描→期望寿命曲线(倒 U) | 走廊 1 附带(参数扫描是灵魂) |
| 悬念的复利 | 夜末存量序列(冻结衰减+再生) | 走廊 1 附带 |
| 味的相容律 | 八味坐标+最近归类的混味唤起 | 走廊 2(实验律二) |
| 审美距离/卷入 | 逐味网格寻优+秩相关 | 走廊 2 附带 |
| 物哀的倒 U | 形式(L)×哀感(L)乘积曲线 | 走廊 3(实验律三) |
| 结束信号的前移 | 事件核+结束信号核的加权曲线 | 走廊 3 附带 |
| 三张结构卡 | 定长字段 schema+完整性校验 | 03 章卡 1/2/3 的直译 |

**转不动(红色区)**:

1. **"东方精神"的总体性**:他者化叙事生成的概念没有可测属性——
   统计再精也算不出"东方性浓度"(03 章右端;话语审计卡管其命名史,
   不测其"含量")。
2. **味的体验质感**:几何能算"哪些味相容、什么卷入最优",算不出
   "爱味尝起来如何"——体验的第一人称维度拒绝坐标。
3. **"紫式部/芭蕉为什么伟大"的评价**:伟大由千年阅读史生成;断口
   与曲线断言的是机制刚性,不是成就评分。
4. **成书层积的栽判**:《一千零一夜》波斯层-巴格达层-开罗层的史料
   归属是写本学问题;结构卡只登记层,不裁决层序(文献学论证)。

**边界的一句话**:绿色区=递归类+坐标类+曲线类,覆盖"叙事与诗学
机制直觉的校准";红色区提醒:**转码是东方文学的使用说明书,不是它
的替身**——算得出断口峰值 0.45,算不出山鲁佐德讲故事时的眼神。

## 二、代码走廊清单(三条主走廊,每条=史识→模型→算法→真实系统)

### 走廊 1:连环悬念走廊(断口-再生-换命的夜夜动力学)

```
断口张力 hang(p) + 嵌套再生 NEST_Q ──夜夜递归──▶ 夜末存量序列
    │                                            │
    ├─中断位扫描 p*∈[0.05,0.97] ──▶ 期望寿命倒U(峰值≈0.45)
    └─对照:无中断连环(每夜清零)──▶ 存量恒零,寿命≈2 夜
```

- **史识→模型**:《一千零一夜》山鲁佐德夜夜讲故事换命、断在关键处
  (通说);连环再生与断口中断是双机制(00 §一)。模型:两夜式故事
  +断口再生+饶命判定。
- **算法层**:夜夜递归 O(N×深度);中断位扫描 O(|网格|×R×N)
  (R=副本数,3000)——纯线性扫,无拟合;贵在**断口张力曲线的立法**
  (倒 U+泄漏,换曲线重标定)。
- **本家族实现**:[`experiments/frame_rasa_nights.py`](experiments/frame_rasa_nights.py)
  幕一——断言倒 U(峰值 p*=0.45 寿命 49.8 夜,早断 14.1/晚断 2.2,
  峰前严格爬坡/峰后严格回落)与复利(存量 2.20→3.83,1.74×;无中断
  对照寿命 2.0 夜,25×)。
- **真实系统**:连载/追更产品的断章设计(卡在哪一集末尾最留人);
  用户留存的"悬念存量"运营(多线剧情的悬置栈管理);播客/有声书的
  分集切点;课程设计的"且听下回"结构(每周断在展开处而非收束处)。
- **性能工程要点**:断言盯**对照差**(中断/无中断寿命比)与**形状**
  (倒 U/单调段),不盯绝对数;R 做收敛扫描(3000 副本下峰值判定
  稳定);参数敏感性先于结论(THETA/NEST_Q 扫描,03 章练习 2)。

### 走廊 2:味感走廊(八味坐标+混味唤起+卷入寻优)

```
八味(效价,唤起)坐标 ──混味场景──▶ 唤起点=主味+β(随味-主味)+噪声
    │                                        │
    ├─最近归类 ──▶ 主味唤起率/随味显影率 ──▶ 相邻>相对(甜-悲不相容)
    └─逐味网格寻优 e ──▶ ê*(味) 与唤起负相关 ──▶ 校准读者 1.20×
```

- **史识→模型**:婆罗多《舞论》八味与情由/情态生成论(通说);"主
  味-随味"的戏剧学组合论(通说)。模型:效价-唤起坐标(罗素模型
  借用,声明)+最近归类。
- **算法层**:每对 M=3000 观众采样 O(M);寻优 O(|味|×|网格|)——
  全线性;贵在**坐标立法**(八味落点是风格化,双人定)。
- **本家族实现**:同实验律二——断言相邻对主味唤起 0.411>相对 0.298、
  显影 0.208>0.000;甜-悲(最远对 d=1.657)唤起仅 0.237;ê* 与唤起
  ρ=-0.95,校准 1.20×。
- **真实系统**:内容推荐的情感标签体系(情感坐标而非离散标签的
  相容度);游戏/剧本的情绪曲线编排(相邻转场 vs 跳变转场);教育
  内容的卷入度适配(高危内容配距离感呈现,抒情内容配沉浸呈现);
  情感计算的混合情感判定(混合情感的"主导判定"算法)。
- **性能工程要点**:**对照组设计是灵魂**(相邻 vs 相对的差,不是
  绝对唤起率——坐标换了差仍在);ρ 断言前先做噪声敏感性(σ 扫描,
  04 章练习 2)。

### 走廊 3:易逝走廊(形式×哀感曲线+终章峰前移)

```
V(L)=L²/(L²+c²)×e^(-L/τ) ──网格──▶ 峰值寿命 L*(倒U断言)
    │
    └─读者敏感度 s ──▶ 事件核+结束信号核加权 ──▶ 高 s 组审美峰前移
```

- **史识→模型**:物哀=对易逝之物的审美敏感(本居宣长,通说);樱花
  七日的通说形象。模型:形式饱和×哀感衰减的乘积;结束信号核峰在
  0.8T(将尽未尽处)。
- **算法层**:曲线网格 O(点数);读者模拟 O(R×T)——线性;贵在
  **两函数的立法**(形式/哀感的参数化,参数变峰移形不变)。
- **本家族实现**:同实验律三——断言峰值 L*=6.5 日落在中段(七日
  V=0.4207≈峰值 0.4220)、昙花 0.0038/松柏≈10⁻¹³³ 两极塌;高敏感组
  审美峰 26.4<低敏感组 29.0(前移 2.7 章,总赋值 1.05×)。
- **真实系统**:限期内容的美学运营(倒计时/季终/告别展的"最优
  限期"设计);限量与稀缺的商品策略(太短无人成形,太长无人心
  动——倒 U 定价);系列作品的终章预告节奏(结束信号提前投放);
  订阅制的"毕业设计"(到期前的情感峰值编排)。
- **性能工程要点**:**倒 U 形状对参数稳健、峰值位置不稳健**——
  结论写形状,参数标定写区间;峰前移断言要分组中位数而非个体
  (噪声下单个体不稳)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:断点设计——你的连载断在哪里?

任何连载物(剧集分集/连载文章/课程周更/版本发布节奏)都有断口。
走廊 1 给三个动作:①给每个断口标"中断位"(本集内容在第几成处
断);②对照倒 U:断在 0.2-0.3(未入局)或 0.9+(近解决)的断口
在送命区;③多线叙事时数悬置栈深度(观众的"记挂"预算)——
**山鲁佐德的自由不是故事多,是断口准**。

### 落点 2:情感编排的卷入校准——距离是一种参数

内容系统对高危高唤起内容(灾难/暴力/惊悚)与低唤起抒情内容应有
**不同的卷入档**:前者给缓冲与距离(旁视角/间离呈现),后者给沉浸。
走廊 2 给三个动作:①给内容打(效价,唤起)坐标;②查混排转场的
相邻性(甜-悲直切=混味失败,要过渡);③按 ê* 配呈现档——**卷入度
不是越多越好,是与唤起相配才好**。

### 落点 3:稀缺的美学运营——给限期找峰值

一切有限期的事物(促销/展览/项目/实习)都有物哀曲线:太短无形式
(用户没形成习惯就结束),太长无哀感(结束时无人心动)。走廊 3 给
三个动作:①估目标行为的"形式养成期"(L²/(L²+c²) 的 c);②在
衰减侧设"结束信号"(倒计时的情感投放从 0.8T 开始,不是最后一刻);
③结束时回收情感峰值(终章美学)——**结束信号是产品的一部分,
不是产品的事后通知**。

### 落点 4:文化知识库——东方文学研究的数字基建

03 章三张结构卡就是数据库 schema:史诗-层-插话表(演述卡)/故事集-
断口-线头表(连环卡)/概念-命名-审计表(话语卡);双人校=标注信度;
写本影像=版本表。做人文知识库/阅读平台的工程师可直接借用——字段即
元数据标准,红区行(东方精神/质感/伟大)禁止入库为数值(01 章主线 B
的数字档案正是此基建的学术版)。
