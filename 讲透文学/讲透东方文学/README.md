## 一、家族定位

- **两支分工**:同一条文明圈纵深的两大件——**印度文学支**(7505110:
  情感的语法从哪来:吠陀与两大史诗的层积/迦梨陀娑与味论/泰戈尔与
  英语写作的现当代)、**日本文学支**(7505120:物哀与最短诗形:王朝
  物语/俳谐与切字/浮世草子/近代小说/战后双诺奖)。波斯/阿拉伯
  (《列王纪》/《玛斯纳维》/悬诗/《一千零一夜》)在 00 章与 02/03 章
  正文速写收编,不建目录。
- **三台引擎贯穿全家族**:演述(记忆怎么变成书)、诗学(情感如何被
  形式组织)、旅行(故事在文明间环流)——每个东方文学事实都能在
  坐标系里定位(00 章 §二、03 章结构卡)。
- **零门槛**:不要求梵语/日语(季羡林译《罗摩衍那》、丰子恺/林文月
  译《源氏物语》等通行中译即可入门);要跨文明影响考证去
  [比较文学](../讲透比较文学/README.md);要编年全景去
  [世界文学史](../讲透世界文学史/README.md);本家族管**文明圈内部
  的结构与诗学纵深**。
- 路线 A(问题派):山鲁佐德为什么断在中段?→00 §七发现 1;甜-悲
  为什么不相容?→发现 2;樱花为什么是七日?→发现 3。
- 路线 B(课程派):00→印度文学支(情感的语法)→日本文学支(物哀
  与最短诗形)。
- 路线 C(研究派):00→01(千年长尾与数字基建)→02(术语户口与
  "物哀""禅意""一千零一夜式"的中文迁移)。
- 工程师快轨:直接跑 [`experiments/frame_rasa_nights.py`](experiments/frame_rasa_nights.py),
  再回读 04 章。
