# 讲透印度文学 · 情感的语法从哪来——从吠陀吟诵到味论,从十万颂史诗到英语写作

> **定位句**:这支负责东方文学的**情感立法源头**:**吠陀**(《梨俱吠陀》约前 1500-1000 成集,口传千年,通说)与
> **两大史诗**(《摩诃婆罗多》约十万颂层积写定,内嵌《薄伽梵歌》;《罗摩衍那》约两万四千颂,传为蚁垤所作,通说)、
> **古典戏剧与诗论**(迦梨陀娑《沙恭达罗》;婆罗多《舞论》**味论**八味,通说;欢增《韵光》)、**泰戈尔与现当代**
> (《吉檀迦利》1913 诺奖,亚洲第一次,通说;英语与本土诸语双轨)——演述引擎(层积)与诗学引擎(味论)在此定型。
> GB/T 13745 75051 · **7505110 印度文学(GB/T 支)**。家族:[讲透东方文学](../README.md)

## 诞生

- **谁/何时**:约前 1500-1000 吠陀;约前 400-200 两大史诗层积写定;
  约 4-5 世纪迦梨陀娑与《舞论》;1913 泰戈尔;1947 后现当代双轨(通说)。
- **因什么问题**:①记忆如何千年保鲜②大文本怎么攒成(十万颂层积之问)
  ③感动能否立法(味论之问:家族实验律二的源头)。

## 核心问题

**已解决(通说)**:层积成书的方式——口传—写定—插话,大文本无单一
产权人(家族 00 §一);味的生成配方——情由+情态+不定情→八味,相邻
相容>相对(甜-悲不相容,家族实验律二:相邻唤起 0.411 vs 相对 0.298)。

**未解决/深水区**:味论是普遍情感理论还是梵语文化的地方知识(家族
00 §四);写本层序的校勘之争(文献学进行中,通说)。

## ✨ 这支最美的一个事实

**给"感动"写配方的人**:两千年前(通说断代),《舞论》把观众的眼泪
拆成零件——情由(对象在场)、情态(外显)、不定情(过路心绪),
组合唤起味。这是人类第一次给审美情感写生成论配方(通说地位);家族
实验律二是它的现代读法:八味落进效价-唤起空间,混味相容律可断言,
每味有最优卷入档(怒要距离、悲要怀抱,ρ=-0.95)——**能立法的情感
才进得了实验**。

## 假设与依赖

- 买入"味论是情感的形式理论";付出:效价-唤起是外来坐标系,结论只在
  "此坐标下"成立(家族 03 章软处)。买入"层积透镜";付出:迦梨陀娑、
  泰戈尔式的强作者维度被压低。依赖写本与译本选择(通说)。
