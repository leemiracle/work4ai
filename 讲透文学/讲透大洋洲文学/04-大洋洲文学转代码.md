# 04 · 大洋洲文学转代码:把歌线纠错码、口传保真与双家园市场搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:大洋洲文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码而且**不该**转码;三条代码走廊——**歌线走廊**、
> **口传保真走廊**、**散居市场走廊**——把"歌线是把大陆装进歌里的
> 纠错码""文字解除记忆的武装""散居文学是两种乡愁之间的套利"变成
> 可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",大洋洲文学转代码要解决"**结构代理化**":
把一段学科语言("歌与地景互为索引")先翻成模型(双线索提取+链式
导航),再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清哪些
对象第一步就走得通(绿色区),哪些走不通或不宜走(红色区),再给三条
走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 歌-地绑定检索 | 双线索提取概率+锚点序列 vs 串行清单对照 | 实验幕一 1a;参数可扫描 |
| 链式导航与断裂 | 逐链到达率×断链硬闯×再定向的乘积链 | 幕一 1b;割裂构型可随机采样 |
| 碎片化 vs 整块 | 同割裂数下断点分布对照 | 幕一 1b;构型级精确计算 |
| 韵律校验的口传保真 | 口误-检出-固化的逐代状态机 | 幕二 2a;卸载参数可调 |
| 编辑权结构 | 分布式否决(1-(1-p)^R) vs 单点静默编辑 | 幕二 2b;诵读者数可扫描 |
| 异域溢价与两种定价 | 题材权重×质量分布的双市场份额 | 幕三;主流/核心阈值可调 |
| 套利方向 | 期望收益+噪声的选题模拟 | 幕三 3b;市场规模系数可调 |
| 三张结构卡 | 定长字段记录+完整性断言(许可状态非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **歌的神圣效力**:代码能量"到达率",量不了歌对持歌者的效力——
   那要求在场与社群见证(03 章右端);**给它打分是对他人宗教的冒名
   顶替**。
2. **吟诵的现场**:韵律在纸面与波形里都不等于吟诵;转写保存信息,
   不保存事件(幕二的哲学浓缩在代码之外)。
3. **限制知识的伦理边界**:具体歌线内容、谱系的神圣段落按学术惯例
   不进语料、不进模型——这不是技术限制,是**许可结构**;任何"原住民
   知识大模型"先过许可再谈架构。
4. **模型参数的骨架性**:v/l 提取率、卸载系数、题材权重全部是**骨架
   假设**——按记忆实验、田野研究与市场数据重估会移动数值(✍️练习 1);
   转码者必须把它们写在显式假设栏。

**边界的一句话**:绿色区=记忆+传承+市场三引擎,覆盖"学科直觉的
校准";红色区提醒:**转码是口传研究与文学社会学的试算器,不是大洋洲
文学的替身,更不是原住民知识的仓库**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:歌线走廊(记忆结构与断裂检测)

```
歌线传诵 ──代理化──▶ 双线索检索模型 + 链式导航(逐链接力)
      │                        │
      └──对照──▶ 串行清单 / 割裂构型采样 ──▶ 检索率/到达率/放大倍数 ──▶ 纠错码判定
```

- **理论→模型**:绑定=位置记忆法的考古版(双线索+锚点固定);断裂=
  割链位后的航位推算与再定向(03 章引擎 1)。
- **算法层**:检索仿真 O(M×N),M=2400、N≤48 秒级;到达率对每个构型
  逐链 O(L) 精确计算,800 构型毫秒级——**不需要walker 级蒙特卡洛,
  构型级精确计算已够稳**(比幕二幕三更"解析")。
- **本家族实现**:[`experiments/songline_diaspora.py`](experiments/songline_diaspora.py)
  幕一——断言绑定逐项成功率高出对照 0.30 以上(实测 0.863 对 0.497)、
  绑定组加长不衰减(48 段合格率 90%)、割 5% 链位到达率<10%(实测
  0.066)、失败对割裂占比放大 15 倍以上(实测 19 倍)、碎片化比整块
  更伤(0.066 对 0.080)。
- **真实系统**:文化遗续评估的**连续性审计**(一条口传路径被道路/
  私有地/边界切成几段,到达率剩多少——地景变化的文学代价读数);
  教育侧的**绑定式记忆设计**(把长清单(法条/药品名/代码规范)绑上
  空间锚点,幕一 1a 的工程正用);口传研究的**断裂敏感性分析**
  (哪些路段是"咽喉链位",断了最伤)。
- **性能工程要点**:全部算力在**构型采样层**——到达率本身是解析乘积,
  采样只为了覆盖"断点分布"的不确定性;这与性能工程"先分析后仿真"
  的纪律同构:能解析的别蒙特卡洛。

### 走廊 2:口传保真走廊(传承机制的对照审计)

```
口传谱系 ──代理化──▶ 口误-检出-固化逐代状态机(韵律校验参数化)
      │                        │
      └──对照──▶ 转录线(誊抄误+认知卸载) ──▶ 保真曲线/不可检错率/编辑留存 ──▶ 卸载判定
```

- **理论→模型**:韵律=冗余校验码;转录=载体更换+校验退役;编辑权=
  分布式否决对单点编辑(03 章引擎 2)。
- **算法层**:每谱系 O(代数×名字数),600 谱系×10 代×30 名秒级
  (幕二);解析近似曲线与 MC 末代对读,双输出互校。
- **本家族实现**:同实验幕二——断言口传十代身份保真≥0.82(实测
  0.860)、顺序保真≥0.95(0.980)、转录线末代比口传低 0.20 以上
  (0.538)、末代不可检错率>口传 3 倍(实测 9.7 倍)、文本静默编辑
  留存>口传 4 倍(0.882 对 0.156)。
- **真实系统**:档案馆的**口传文献健康审计**(一份转写本离开校验
  传统多少年、社区复诵还剩多少——修复优先级读数);出版项目的
  **双语传承评估**(同文同源的双语出版是否缓解"卸载"——01 章主线 C
  的可测化);协作谱系库的**编辑权设计**(谱系数据由谁改、改动要不要
  过社区否决——幕二 2b 的数据库正用)。
- **性能工程要点**:状态机的**参数全在显式假设栏**——卸载系数(1.18/
  0.85)是风格化外生假设,不是实测;任何复用此走廊的项目先做参数
  敏感性扫描再下结论(✍️练习 1)。

### 走廊 3:散居市场走廊(双家园定价诊断)

```
散居作品 ──代理化──▶ 题材权重×质量分布的双市场对照(H/D/U 三题材)
      │                        │
      └──对照──▶ 两地本土书竞争盘 ──▶ 主流份额/核心读者率/溢价系数 ──▶ 套利判定
```

- **理论→模型**:题材权重=两个市场各认各的账;主流=前 10%、核心=
  前 40% 双阈值;套利=供给按期望收益选题(03 章引擎 3)。
- **算法层**:每书 O(1) 抽样,6000+2400 书毫秒级;份额计算 O(n log n)
  排序主导(幕三)。
- **本家族实现**:同实验幕三——断言 D 双市场核心读者率过线(实测 27%/
  51%)而主流份额均低(3.3%/8.8%)、H 侨居国榜>25%(39.8%)且母国榜
  <5%(0.0%)、两种定价 ×2.30、供给套利与母国接纳错位 10 倍以上
  (93.6% 对 0.0%)。
- **真实系统**:出版选题的**双市场诊断书**(一部散居作品在两个市场
  各落在哪个象限:核心/主流/边缘/缺席——营销与定价的输入);文化
  政策的**溢价结构监测**(异域包装的份额变化——收编风险的量化哨兵);
  文学节的**选目平衡审计**(散居作者总在"多元单元"而不在"主单元"
  么?双阈值读数照妖)。
- **性能工程要点**:双阈值(主流/核心)必须**同时输出**——只报主流
  份额会得出"散居作品没人读"的误判(核心读者率 27%/51% 才是真相);
  单指标叙事是这条走廊的头号事故源,与性能工程"先定指标再跑分"同律。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:知识库的"许可字段"治理——先许可后入库

- 任何涉原住民/少数社群内容的语料与知识库,默认带**许可状态字段**
  (公开学术文献/经社群许可/限制知识三档);限制档**不进训练集**,
  03 章三张卡的许可栏在数据层的投影——这是幕二"编辑权结构"的工程
  化:谁能入库、谁能改、谁能用,三问先于架构。

### 落点 2:长清单学习的绑定式设计

- 把歌线的"歌-地绑定"用作记忆工程的正模板:学一门长清单(法规条文/
  系统命令/接口清单)时给每项绑一个空间或情境锚点,并**按序走一遍**
  (链式)而非乱序刷卡片——幕一 1a 的读数(48 项合格率 90% 对清单式
  塌底)就是设计依据。

### 落点 3:口传/社区知识的版本控制——否决制提交

- 社区谱系与口传档案的版本控制不照搬"单人 merge"模型:敏感改动走
  **多签审核**(幕二 2b 的分布式否决),公开改动才走常规流——把
  "谁可改谱"从治理文档写进代码权限。

### 落点 4:双市场产品的定价与包装分账

- 任何跨市场内容产品(双语书/出海应用/跨区课程)建立**两本账读数**:
  两个市场各的核心用户率与主流份额分列;警惕"异域包装"的短期溢价
  长期收编(幕三 3b 的供给错位 93.6% 对 0.0% 是警号,不是机会)。

   散居写作卡的产品版

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:许可之眼**——看到任何原住民/社群知识的数据项目,
先问许可结构(谁能入库/谁能改/谁能用),架构问题是第二问;**绑定之眼**:
看到任何记忆与学习任务,先问有没有可绑的锚点序列(空间/情境),链式
顺序不是负担是纠错码;**双账之眼**:看到任何跨市场内容,先分两本账
(核心率与主流份额分列),异域溢价是账上的一个科目,不是产品的全部。
