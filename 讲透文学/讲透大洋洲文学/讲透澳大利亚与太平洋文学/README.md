# 讲透澳大利亚与太平洋文学 · 建制怎么建——殖民自立、国际承认与两个家

> **定位句**:这支负责**建制侧**:1788 年以来大洋洲的书面文学建制怎么长成——
> 劳森与《公报》(The Bulletin,1880 创刊)的丛林文学自立(1890s,通说)、曼斯菲尔德
> 的英语现代短篇(《园会》1922)、怀特的现代主义国际化(**1973 澳首位诺奖**,通说)、
> 怀蒂坦吉条约叙事(1840 条约/1975 法庭建制,通说)与和解文学、温特与豪欧法的
> 太平洋重绘(《我们的群岛之海》1993,通说)、当代萨摩亚-斐济散居写作与气候叙事。
> 与原住民与毛利支分工:**那边守深流(歌载大陆+韵律记账),这支建建制(双乡定价)**。
> GB/T 13745 75087 大洋洲文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:1890s 劳森与 Bulletin 派替殖民地造"丛林"身份(文学先于
  1901 联邦,通说);曼斯菲尔德把新西兰带进英语短篇第一线;1973 怀特
  诺奖;1975 怀蒂坦吉法庭建制后条约叙事进入小说;1973 温特《归乡之子》
  起太平洋现代小说成型,1993 豪欧法把大洋洲重读为"海连接的家"(均通说)。
- **因什么问题**:①没有母语建制传统的殖民地怎么自立(造身份范本)
  ②边缘文学怎么被世界承认(奖项与国际化)③散居与气候时代的太平洋
  写作写给谁(双家园市场的定价结构)。

## 核心问题

**已解决(通说)**:殖民文学与国际化的建制年表(Bulletin 派/1922/1973);
条约叙事与和解文学谱系;太平洋重绘的思想史地位。
**未解决/深水区**:散居写作会不会被两个市场同时边缘化(幕三的双核非主流结构);
"大洋洲文学"是区域实体还是外部分类器(家族 00 章争 2,双录);气候叙事的市场结构(异域溢价最新变体)。

## ✨ 这支最美的一个事实

**散居文学是两种乡愁之间的套利**(幕三实测):双家园作品(D)在侨居国
与母国市场核心读者率 **27%/51%** 各有读者,而主流榜份额仅 **3.3%/8.8%**
均非主流;"回望母国"(H)占侨居国主流榜 **39.8%**、在母国榜上是
**0.0%**,接受指数 **×2.30** 的两种定价;供给模拟 800 位新散居作者按
市场理性 **93.6%** 选 H,而母国并不买账——**他乡溢价,故乡折价,套利
在两种乡愁之间**(与东欧流亡双市场实验互为镜像:那边有回归,这边无回归)。
