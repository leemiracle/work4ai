> 观念场、传教士转录与 te reo 复兴(语言巢 1982,通说)、原住民书写

## 诞生

- **谁/何时**:口传深流年代以万年计(量级按考古通说);1788/1840 殖民
  接触后传教士转录把口传语言字母化(通说);1964/1965 原住民第一部
  诗集/长篇(通说),1970s 毛利文艺复兴与语言巢建制,1985《骨人》
  布克奖、1987《鲸骑士》(通说)。
- **因什么问题**:①没有纸的社会怎么保存大陆与谱系(歌-地绑定+韵律校验)
  ②转录之后传承机制怎么变(保存与卸载的两面账)③口传者的后代怎么以
  自己的署名进入印刷世界。

## 核心问题

**已解决(通说)**:歌线/谱系的形式描述(学术口径);原住民书写兴起的
定年;复兴建制年表(1970s/1982)。**未解决/深水区**:合作转写的署名
伦理(家族 00 章争 1,双录);转录对传承的长期净效应(幕二模型的重估
待办——01 章主线 C 双语出版是现场)。

## ✨ 这支最美的一个事实

**歌线是把大陆装进歌里的纠错码**(幕一实测):"歌-地"绑定(双线索提取)
24 段逐项检索 **0.863** 对无绑定清单 **0.497**,合格传诵率 **78% 对
0.0%**,清单加长到 48 段绑定组 **90%** 不降反稳;分割地景仅割 **2 链
(5% 地景)**,到达率即从 0.669 塌到 **0.066**(失败放大 19 倍),碎片化
比整块更伤——**冗余在链上,断链即弃权**(位置记忆法的考古版)。
