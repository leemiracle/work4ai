# 讲透大洋洲文学 · 最老的口传与最年轻的建制——歌线、谱系与两个家

> **本质一句话**:大洋洲文学=**世界上最古老的口传与最年轻的文学建制在同一片
> 片海相遇**——澳大利亚原住民以歌线(songline,通说学术口径:歌与地景绑定的
> 传诵路径)把大陆唱成地图,毛利人以 whakapapa(口传谱系)把祖先记进韵律;
> 殖民与移民用两百年造出书面建制:劳森与 Bulletin 派的殖民文学(1890s)、
> 曼斯菲尔德的短篇艺术、怀特 1973 的国际化诺奖;此后原住民书写兴起
> (努努卡尔 1964/穆杜鲁 1965/赫尔姆《骨人》1985 布克奖/伊希玛埃拉
> 《鲸骑士》1987)、怀蒂坦吉条约叙事与和解文学、当代太平洋散居写作;
> 一句话:**歌载大陆,韵律记账,双乡定价**。
>

## 一、家族定位

- **两支分工**:同一片海的两层——**原住民与毛利支**(深流怎么流:梦时与歌线/
  口传谱系/原住民书写的兴起与出版自主)与**澳大利亚与太平洋支**(建制怎么建:
  殖民文学与民族化/怀特的国际化/当代太平洋散居写作)。
- **一条主轴贯穿**:歌载大陆(歌线把地景写成可传诵的纠错码)──韵律记账
  (whakapapa 以冗余编码保谱系,转录后反见衰退)──双乡定价(散居作品在
  母国与侨居国两个市场各有一本账)。前段支守第一程,后段支守第二三程;
  家族实验把三段全部**算术化**(歌线纠错码/口传保真/双家园市场)。
- **零门槛**:读过一册曼斯菲尔德短篇或看过《鲸骑士》的电影就能进;术语随用
  随讲(三步法:直觉图像→严格陈述→最小例子);不要求毛利语或任何太平洋
  语言——全部用通行中译;要编年全景去[世界文学史](../讲透世界文学史/README.md),
  要后殖民一般理论去[比较文学](../讲透比较文学/README.md)。
- 路线 A(问题派):一首歌怎么装下一片大陆?→00 §争 1+发现 1;写下祖先的
  名字为什么反而让记忆变坏?→00 发现 2;散居作家写给谁?→00 发现 3
- 路线 B(课程派):00→[原住民与毛利支](讲透原住民与毛利文学/README.md)
  →[澳大利亚与太平洋支](讲透澳大利亚与太平洋文学/README.md)
- 路线 C(研究派):00→01(原住民出版自主/气候叙事/双语出版三前线)→02
  (关键词的铸造与转译损耗)
- 工程师快轨:直接跑 [`experiments/songline_diaspora.py`](experiments/songline_diaspora.py),
  再回读 04 章
