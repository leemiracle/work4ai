# 04 · 中国儿童文学转代码:把读龄、门房与市场搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:中国儿童文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**复杂度画像**、**门房扫描**、
> **替代拟合**——把"分级不是均匀刻度""好童书是门与房""原创从不
> 归零引进"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",儿童文学转代码要解决"**代理化**":
把一段行业语言("这书七岁看不懂")先翻成模型(指数+档位),再翻成
代码。翻译的损耗全部发生在第一步——所以本章先划清哪些对象第一步
就走得通(绿色区),哪些走不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 行业概念 | 代码化身 | 备注 |
|---------|---------|------|
| 语言复杂度/适龄 | 句长/稀有度/嵌套加权指数+发育投影档位 | 实验幕一全程纯标准库 |
| 双读者/大人也爱读 | 门 s×房 d 网格,两端概率模型 | 幕二的网格与蒙特卡洛 |
| 过密两头不讨好 | 网格分区计数(儿童端<阈 且 成人端<阈) | 幕二 2a,实测占 40.4% |
| 引进-原创消长 | 双产能曲线+份额+logistic 拟合 | 幕三;峰/拐点/滞后全自动检测 |
| 三张结构卡 | 定长字段记录+完整性断言(儿童端证据非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **童趣之质**:代码能估"门多宽",估不了"好不好笑"——游戏精神的
   在场只能由共读见证(03 章右端)。
2. **儿童观立场**:本位还是工具,是规范立场不是参数;把立场写进
   评分函数,等于让一个时代的儿童观冒充自然法则。
3. **发育的个体差**:指数量书不量人;读者能力的估计本体在教育
   测量(文字提及),模拟不能冒充测评。
4. **价值函数的权重**:40/35/25 的加权是**骨架假设**——换成别的
   权重,档位边界会移动(✍️练习 4);转码者必须把权重写在显式
   假设栏。

**边界的一句话**:绿色区=投影+门房+替代三引擎,覆盖"行业直觉的
校准";红色区提醒:**转码是选题与运营的试算器,不是孩子与童趣的
替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:复杂度画像走廊(适龄文本画像)

```
分级阅读 ──代理化──▶ 指数=0.40·句长+0.35·稀有度+0.25·嵌套(归一化)
      │                                │
      └──投影──▶ dev(a)=logistic(a;8,1.4) ──▶ 档位=反查指数带 ──▶ 带宽±1 岁
```

- **理论→模型**:阅读发育 logistic(拐点 8 岁);文本指标带噪采样
  (实验幕一);指数带=投影的逆运算。
- **算法层**:指标加权 O(L)(L=文本长度);档位反查 O(档数);
  幕一每档 240 文本×5 档全程序秒级。
- **本家族实现**:[`experiments/age_dualreader_market.py`](experiments/age_dualreader_market.py)
  幕一——断言五档单调、6→9 间距(42.0)压过其余、12→15(2.9)
  趋缓到 1/8。
- **真实系统**:选书助手的**适龄体检自动填充**(03 章卡 1);图书馆/
  电商的**非等距分级上架**(识字爆炸档加密);推荐系统的**年龄维
  校准**(按带不按点)。
- **性能工程要点**:单文本画像 O(L) 可流式;批量是天然可并行的
  map;真正贵的是**指标底表**(中文字频/词 rarity 底表是数据工程,
  不是算法工程)——底表不标准,指数只是自洽的伪精确。

### 走廊 2:门房扫描走廊(双读者结构检测与设计)

```
双重讲述 ──代理化──▶ 门 s(表层可达)×房 d(深层密度)
      │                                   │
      └──两端模型──▶ 儿童端=s·e^(-1.2d);成人端=(深度饱和)×(门反哺)
                     ──▶ (s,d) 网格扫描 ──▶ 价值=两端乘积 ──▶ 内点最优/过密区
```

- **理论→模型**:双层编码参数化(03 章引擎 2);驱逐速率与饱和
  常数显式声明为骨架假设。
- **算法层**:19×21 网格全扫 O(格数);蒙特卡洛 N=8000 读者秒级
  (幕二 2b)。
- **本家族实现**:同实验幕二——断言最优 s*≥0.90、d*∈[0.25,0.45];
  双层书成人重读 2.4 倍;过密书儿童端崩到 16%、两头不讨好区占四成。
- **真实系统**:亲子共读产品的**两层内容设计**(页面给孩子的门,
  导读/彩蛋给大人的房);选题会的**门房体检**(先估 (s,d) 再立项);
  绘本奖项评审的**双读者维度登记**(图文分工=门的材质)。
- **性能工程要点**:网格是二维扫描,天然可并行(格分流 seed 可复现);
  工程价值不在算力在**参数纪律**——驱逐速率按人群分层(低幼驱逐
  快、少年驱逐慢),全局单值会同时错杀两个市场。

### 走廊 3:替代拟合走廊(品类规划与引进/原创平衡)

```
译入-原创百年史 ──代理化──▶ 原创产能=logistic ramp;引进量=扩张-峰-长尾
      │                                        │
      └──份额──▶ S 形替代 ──▶ 峰/拐点检测 ──▶ 滞后≈产品周期;长尾守恒
```

- **理论→模型**:双产能曲线+份额(03 章引擎 3);±3% 市场噪声;
  峰值年=平滑量最大年,拐点=原创量过渐近半值年(滑动平均去噪)。
- **算法层**:逐年递推 O(年数);检测用滑动平均+阈值穿越,无拟合
  迭代(幕三全程毫秒级)。
- **本家族实现**:同实验幕三——断言 S 形单次跨越、先引进(≥0.83)、
  崛起期引进均值 0.44、末端长尾 0.23、滞后 9≈T_c=8 年。
- **真实系统**:出版社的**品类替代仪表盘**(原创/引进份额与品种量
  双轨监测——份额叙事与品种叙事分账,01 章判读要点 2);**引进长尾
  的存续管理**(经典引进版的常备书策略);**原创选题的起飞时点判断**
  (品类能力指标过半值=起飞信号)。
- **性能工程要点**:数据量级极小(年度几十行),价值全在**口径纪律**
  ——份额与存量分开记账、平滑窗口声明、政策事件外生标注(噪声项
  不是垃圾桶)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:选书助手的体检治理——带宽不刻线

- 输出永远是"指数带=9 岁带±1 岁",禁止"适读年龄=9 岁"的单值话术
  (幕一同档标准差≈4 点);体检卡自动填充+主题年龄线人工栏——
  语言线与主题线的落差(卡 1 读卡法)标成"两次消费空间",是产品
  的推荐理由,不是风险项。

### 落点 2:共读产品的门房结构化

- 内容生产按门/房双轨验收:正片(门)过儿童端测试,导读/家长页
  (房)过成人端测试;埋点看**两次消费信号**(童年标记-成年重读),
  它是 crossover 的直接观测(幕二蒙特卡洛的线上版);红线两条:
  过密区(儿童端崩)与无房区(成人端流失)。

### 落点 3:品类规划的替代仪表盘

- 双轨监测份额(叙事)/品种量(供给),标注政策事件;用"起飞滞后
  ≈一个产品周期"做规划:引进新品的本土仿创立项放在引进峰值后
  T_c 年窗口内(幕三断言 2 的工程版);经典引进长尾按常备书管理,
  不随份额下降清库(断言 1:长尾不消)。

### 落点 4:分级方案的刻度审计

- 任何分龄体系上线前跑一次幕一式审计:档距按发育投影还是等距?
  6-9 岁档密度是否≥其他档 2 倍?把审计结果(间距比 1:0.53:0.07
  一类的实测)写进产品文档——**等距分级是把尺子硬掰直**(02 章
  纪律 1)。

## ✍️ 练习

1. 🐍 给走廊 1 换权重:把 40/35/25 改成 25/35/40(嵌套主导),重跑
   幕一,看间距比怎么变、单调性是否稳——亲手体验"骨架假设决定
   档位边界"
2. 🐍 给走廊 2 加人群分层:驱逐速率 1.2 改成 {0.6,1.2,1.8}(低幼/
   中段/少年),各扫一次两头不讨好区面积——"读者耐性"外生参数的
   敏感性实验
3. ✋ 用落点 3 审计一个你熟悉的品类(不止童书):份额与存量分开了吗?
   政策事件标注了吗?起飞滞后估了吗?
4. ✋ 把落点 1 写成一页产品备忘:单值年龄话术为什么禁?带宽±怎么
   定?主题年龄线谁签字——"替孩子判断"的治理问题

原创崛起"叙事,先问三件事:刻度按发育投影了吗(间距比)?两层

这三问从行业修辞变成可跑的断言。
