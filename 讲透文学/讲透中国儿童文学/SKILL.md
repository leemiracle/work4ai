# 中国儿童文学思维技能卡(讲透中国儿童文学 · GB/T 75041)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **观念侧**:儿童的发现、儿童本位、教育工具论、童心论、缩小的成人、
  五四"人的文学"之儿童发现、童年消逝、普遍儿童概念的批评
- **历史线**:孙毓修《童话》丛书、"童话"译词、周作人《儿童的文学》、
  叶圣陶《稻草人》、张天翼、陈伯吹、十七年儿童文学、郑渊洁、《童话大王》、
  曹文轩国际安徒生奖、引进潮、《哈利·波特》中文版
- **创作产业侧**:图画书/绘本、桥梁书、幻想文学、成长小说、成长弧、
  畅销系列、原创图画书崛起、版权输出、书单与奖项
- **结构侧**:双读者、双重讲述、隐含的成人、crossover、门与房、
  过密两头不讨好、两次消费
- **分级侧**:适龄性、分级阅读、适读年龄、语言复杂度、蓝思、
  字频谱、识字爆炸期、主题年龄线、亲子阅读、对话式阅读

## ② 核心思维模式(这个分支怎么想问题)

1. **不等边三角之眼**:儿童文学的一切卡在"成人写、儿童读、成人评"
   的三角里;评任何童书先问三角怎么摆(作者立场/中介渠道/读者入口)
2. **读者发明之眼**:读者不是给定的,是被观念发明的——先有"儿童是
   另一种人"的观念,才有为儿童的文学;市场与平台仍在继续发明读者
3. **本位-工具分账**:教育工具论(教点什么)与儿童本位论(先给快乐)
   是百年张力不是待决问题;判断任何论争先找两端的账单(买了什么
   假设/付了什么代价)
4. **投影纪律**:分级=发育曲线的投影,不是均匀刻度——识字爆炸期
   (6→9 岁)档要密,青少年段档要疏;适龄结论报带宽不报刻线
5. **门房之眼**:童书双层编码——门(表层可达,孩子进得来)与房
   (深层意义,大人留得下);双层是资产(成人重读≈单层 2 倍),
   过密是负债(儿童端崩塌、两头不讨好)
6. **后发之眼**:先引进后原创是后发市场标准路径——S 形替代、起飞
   滞后约一个产品周期、引进长尾不消;"原创崛起/引进退场"的单一
   叙事把份额与品种量混作一团
7. **儿童端证据伦理**:替孩子判断的大人必须分账——自己的推断与
   孩子的反应(共读观察)分开记;三张结构卡各有此栏

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 三角审计(写/读/挑) | 拆任何童书现象:作者端立场/中介端渠道/读者端入口 |
| 论争双录卡 | 处理本位 vs 工具之争:两端各写一行,裁决栏可空 |
| 译入-原创年表 | 定位任何作品/事件在百年路径(1909 译入→1923 原创→2000 引进潮→2016 原创出海) |
| 适龄性体检卡 | 量门:句长/稀有度/嵌套→指数→档位带±;语言线与主题线的落差=两次消费空间 |
| 成长弧卡 | 量路:起点态/触发/试错/终点态;无代价的成长弧是说教 |
| 双读者结构卡 | 量房:门 s×房 d 与耦合方式;过密体检看深度是否堵门 |
| 发育投影模型 | 设计/审计分级方案:档距按 logistic 投影,不按年龄等距 |
| 门房网格扫描 | 双读者设计与检测:估 (s,d),离两头不讨好区多远即余量 |
| 替代动力学仪表盘 | 品类规划:份额/品种量双轨,峰值-拐点-滞后-长尾四读数 |

## ④ 常见误区与禁忌

- **把童话当浪漫滤镜**:学科义的童话是最讲规则的体裁(幻想自洽+
  游戏精神);"童话般的爱情"是被磨损的日常义(02 章对译表)
- **把绘本当带图的书**:图画书是图文合奏的独立体裁,图不是插图
  是叙事的一半;桥梁书有图文配比的结构含义,不是营销词
- **把双读者当书评套话**:"大人也爱读"要落到结构参数(门宽房中),
  不是气质描述
- **等距分级**:按年龄等距切档必错——发育是 S 形曲线,投影后
  一头密一头疏(幕一间距比 1:0.53:0.07)
- **单值适读年龄**:同档标准差≈4 点,同龄儿童差两三档;报"带宽±",
  禁报"适读年龄=N 岁"
- **替孩子下判断不留证**:评估卡必须分账"我的推断/孩子的反应"——
  儿童文学批评的第一伦理
- **份额叙事替代品种叙事**:"原创超越引进"要拆成份额(S 形可替代)
  与品种量(长尾不消)两个量,混说必错
- **给童趣打分**:门房量得出结构,量不出"好不好笑";把童趣压成
  参数是本品类量化失真的头号来源
