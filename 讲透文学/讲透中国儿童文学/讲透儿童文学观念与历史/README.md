## 诞生

- **谁/何时**:卢梭《爱弥儿》(1762)立"童年自有其位";阿利埃斯《儿童的世纪》
  (1960)回望"中世纪没有儿童"(争议双录,通说);1909 孙毓修《童话》丛书
  落地译词;1920 周作人《儿童的文学》立儿童本位纲领;1923 叶圣陶《稻草人》
  立原创第一碑——读者被发明→纲领被立→原创起飞(均通说)。
- **因什么问题**:①童年是不是成人的预备役②为儿童的文学该教还是该悦③后来者要不要先转述格林再写自己。

## 核心问题

**已解决(通说)**:建制起点有明确坐标(译词 1909→纲领 1920→原创
1923);论争谱系完整(周氏兄弟内部张力→十七年"童心论"批评→新时期
本位回归);译入-原创消长有史实骨架(十七年收敛→引进潮→原创崛起)。

**未解决/深水区**:"普遍儿童"的当代批评(本位论的读者是不是另一个成人投影);十七年儿童文学的评价重估;观念史与市场史的接缝。

## ✨ 这支最美的一个事实

**读者先于文学被发明**:中国早有儿童,1920 年才有"儿童的文学"的纲领
——直到观念相信童年自有其位,为儿童的文学才成为可想象的事业;一个门类
由**对读者的发明**启动,而不是由作品积累启动。朱自强《中国儿童文学与
现代化进程》把它写成总纲:儿童文学与现代中国**互相发明**;幕三替代
动力学是它的市场侧回声。

## 假设与依赖

- 买入"观念可以驱动建制":儿童观变迁能解释文学的建制节点;论争按通说口径双录,不栽判
- 代价:非观念变量(出版技术/战争/市场)被压成背景;阿利埃斯式命题的史料偏差同样威胁本支的回望叙事(通说双录)
