## 诞生

- **谁/何时**:品类谱系即诞生史——1922-1923《儿童世界》《小朋友》立专刊,
  冰心《寄小读者》立通信体;十七年立低幼与校园叙事(《神笔马良》1955/
  《没头脑和不高兴》1956/《小布头奇遇记》1961,通说);郑渊洁 1985 创
  《童话大王》;2000《哈利·波特》中文版引爆引进潮;2008《团圆》与 2009
  首届丰子恺奖开启原创图画书;2016 曹文轩国际安徒生奖后市场定型为"原创
  主力+引进长尾"(均通说)。
- **因什么问题**:①成人作者怎么给儿童写(双重声音的工艺化)②品类怎么按发育切分③后发市场怎么从引进走到原创。

## 核心问题

**已解决(通说)**:品类结构成形(图画书→桥梁书→章节书→YA 的发育阶梯即产品线);双读者结构是品类事实(图画书的图文分工是门房模型的材质实现);替代路径定型(引进潮 1990s-2000s→原创崛起 2005-2016→双市场)。

**未解决/深水区**:门与房的平衡无公式(过密两头不讨好,最优 (s,d) 按人群重估);中文分级标准化难题(无空格分词/字词脱节/主题适龄不可折算,通说);网络化重写渠道(网文低龄线/有声/短视频书单把"挑"的平台化)。

## ✨ 这支最美的一个事实

**好童书是给孩子的门和给大人的房子**(幕二网格的实测形状):门宽
(s*≥0.90)决定谁进得来,房深中等(d*∈[0.25,0.45])决定谁留得下——
双层书成人重读率 0.560,是单层书 0.230 的 2.4 倍,而儿童端不塌;深度
过密则儿童端崩到 16%,两头不讨好区占设计空间四成。**crossover 的经济
实质是童年读表层、成年读深层的两次消费**——"大人也爱读"从书评套话
变成一对可扫描的参数。

## 假设与依赖

- 买入"文本结构可参数化":门 s/房 d/指数可估(40/35/25 权重为骨架假设,显式声明);童趣之质与艺术等级不进门房与指数(家族 03 章右端)
