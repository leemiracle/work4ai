# 讲透中国儿童文学 · 被发明的读者——儿童本位百年论争、双读者文本与后发市场

> **本质一句话**:中国儿童文学=**先发明读者、再造文学**的领域——
> "儿童"作为特殊读者是被观念史发明的(卢梭→五四"儿童的发现"),为这个
> 读者写的文学因此带着三个结构性胎记:**为谁而写之争**(教育工具论 vs
> 儿童本位论,百年末决)、**写给谁看之谜**(成人作者写儿童的双重声音:
> 给孩子的门+给大人的房子)、**从哪里来之路**(从"童话"译入到本土原创
> 的后发替代);一句话:**儿童文学的一切机关,都在"成人写、儿童读、
> 成人评"这个三角里**。
>
> GB/T 13745-2009:750 文学 · 二级学科 **75041 中国儿童文学**(GB/T 无三级明细 → 自定 2 支;薄家族纪律:章 150-250 行)。

## 一、家族定位

- **两支分工**:同一条河的两岸——**观念与历史支**(读者是怎么被发明的:
  儿童的发现/儿童本位论争/从译入到原创的百年)与**创作与产业支**
  (文本是怎么被双写的:图画书/幻想文学/分级阅读/引进与原创市场)。
- **一条主轴贯穿**:儿童(被发明的读者)→文本(双层编码)→市场(后发
  替代)。观念支守第一程,创作产业支守后两程;家族实验把三段全部
  **算术化**(发育投影/门房模型/logistic 替代)。
- **零门槛**:读过一本童书、陪过一个孩子就能进;术语随用随讲(三步法:
  直觉图像→严格陈述→最小例子)。不要求文学史前置;要民间故事形态学去
  [民间文学](../讲透中国民间文学/README.md),要跨语旅行去
  [比较文学](../讲透比较文学/README.md)。
- 路线 A(问题派):童书凭什么大人也爱读?→00 §七发现 2;分级读物
  按年龄贴标签对吗?→发现 1;原创为什么崛起得这么晚?→发现 3
- 路线 B(课程派):00→[观念与历史支](讲透儿童文学观念与历史/README.md)
  →[创作与产业支](讲透儿童文学创作与产业/README.md)
- 路线 C(研究派):00→01(原创图画书/网络化/分级阅读三前线)→02(适龄量的话语)
- 工程师快轨:直接跑 [`experiments/age_dualreader_market.py`](experiments/age_dualreader_market.py),再回读 04 章
