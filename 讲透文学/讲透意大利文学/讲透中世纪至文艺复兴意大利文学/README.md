# 讲透中世纪至文艺复兴意大利文学 · 源代码编写期——温柔新体、三韵体与框架叙事的发明

> **定位句**:这支负责意大利文学的**标准件从哪来**:西西里宫廷诗(俗语立法之始,
> 通说)与**温柔新体**(圭尼泽利/卡瓦尔坎蒂;但丁《炼狱篇》自我命名,通说)、
> **但丁**(《神曲》1308-1320,三韵体=但丁发明;《俗语论》为俗语辩护)、
> **彼特拉克**(《歌集》:十四行诗的欧洲范本)与**薄伽丘**(《十日谈》1349-1353:
> 框架叙事范本)、阿里奥斯托《疯狂的罗兰》与塔索《被解放的耶路撒冷》——韵式引擎与框架引擎在此定型。
> GB/T 13745 75067(无三级明细 → **自定支**)。家族:[讲透意大利文学](../README.md)

## 诞生

- **谁/何时**:1230s 西西里宫廷诗;1270s-90s 温柔新体;1308-1320 但丁;
  1340s-50s 彼特拉克/薄伽丘;1516-1581 两座史诗(通说)。
- **因什么问题**:①俗语能否承载一切主题(《俗语论》)②爱情能否使人高贵
  (温柔新体之问)③讲故事要不要框(《十日谈》)。

## 核心问题

**已解决(通说)**:
- 三韵体的链式结构:单调推进、终点唯一(YZZ 自锁),断一节牵连剩余全部
  (家族实验律一:45/47,牵连比 45×)——形式即宇宙观
- 框架叙事的并列框语法:一层框+百故事,退出点少、单篇可拆卸(家族实验律二)

**未解决/深水区**:《十日谈》框的来源之争(东方假说 vs 自创,通说双录);
温柔新体的"爱情形而上学"不可操作化(家族 03 章红区)。

## ✨ 这支最美的一个事实

**诗人给自己的诗风命名**:《炼狱篇》第二十四歌,但丁当着对手的面自答
"我是温柔新体的诗人"——流派正名出自流派成员之口,写在万行史诗的中段
(家族 02 章美之时刻 5)。三韵体更狠:一条韵链滚动一万四千余行,断一节
后续全部重排——**《神曲》的宇宙结构学写进了韵脚的几何里**。

## 假设与依赖

- 买入"韵式是骨架";付出:思想史与散文传统被形式史压低。买入"框架可还原
  为框-深-广三数";付出:框内单篇质量差被抹平。依赖译本选择——中译的韵
  处理即学术立场(家族 02 章 §四)
