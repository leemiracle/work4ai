# 讲透意大利文学 · 欧洲文学的源代码库——从但丁的韵链到卡尔维诺的宇宙

> 意大利文学=**欧洲文学的源代码库**——当欧洲各国还在用拉丁文写"官文"时,
> 意大利人率先为"俗语"(volgare)立法(但丁《俗语论》),此后七百年,
> 这门文学反复输出"底层协议":三韵体(terza rima)给了欧洲诗歌一种
> 滚动的链式韵式、温柔新体(dolce stil novo)给了爱情诗一种天使化语法、
> 框架叙事(《十日谈》)给了欧洲小说一种讲故事的外壳、"文艺复兴"
> 这个词本身就是意大利的发明——**别的国别文学是欧洲文学的用户,
> 意大利文学长期是它的标准库**。三台引擎贯穿七百年:**韵式引擎**
> (形式的发明与输出:stilnovismo→terza rima→八行体→隐逸派)、**俗语
> 引擎**(标准语与方言的双层市场:但丁为俗语辩护,统一后标准语扩张、
> 方言写作退守认同腹地)、**框架引擎**(讲故事的结构:十日谈式并列框
> vs 东方嵌套框)。一句话:**意大利文学的伟大与它的"图书馆功能"同源:
> 它发明了太多欧洲文学后来运行的标准件**。
>

## 一、家族定位

- **两支分工**:同一条七百年大河的两段——**中世纪至文艺复兴支**(源代码
  的编写期:西西里宫廷诗→温柔新体→但丁→彼特拉克/薄伽丘→阿里奥斯托/
  塔索,韵式引擎与框架引擎在此定型)、**近现代支**(源代码的续写期:
  巴洛克与哥尔多尼→浪漫主义(曼佐尼)→真实主义(维尔加)→二十世纪
  三诺奖诗群(翁加雷蒂/蒙塔莱/夸西莫多)与皮兰德娄→战后卡尔维诺/
  艾柯/莫兰黛,俗语引擎在当代复活为方言与认同议题)。
- **三台引擎贯穿全家族**:韵式(形式发明)、俗语(双层语言市场)、框架
  (叙事结构)——每个意大利文学事实(一种韵式/一部框盒故事集/一位方言
  作家)都能在坐标系里定位(00 章 §二、03 章结构卡)。
- **零门槛**:不要求意大利语(田德望译《神曲》、肖天佑译《十日谈》等
  通行中译即可入门);要叙事学通则去文学理论,要跨国影响考证去
  [比较文学](../讲透比较文学/README.md);本家族管**意大利语的内部
  结构与它对欧洲的输出史**。
- 路线 A(问题派):为什么《神曲》的韵式像锁链,断一节全书重排?→00 §七
  发现 1;《十日谈》和《一千零一夜》差在哪一层?→发现 2;方言写作为什么
  死不了?→发现 3
- 路线 B(课程派):00→中世纪至文艺复兴支(源代码编写期)→近现代支
  (续写与复活期)
- 路线 C(研究派):00→01(文献地图与处境)→02(术语户口与"文艺复兴/
  卡尔维诺式"的中文话语迁移)
- 工程师快轨:直接跑 [`experiments/terza_rima_frames.py`](experiments/terza_rima_frames.py),
  再回读 04 章
