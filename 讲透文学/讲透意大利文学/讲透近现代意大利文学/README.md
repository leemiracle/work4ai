## 诞生

- **谁/何时**:1700s 中哥尔多尼改革;1825/1840 曼佐尼;1861 统一;1881 维尔加;1910s-30s 隐逸派与皮兰德娄;1945-1980 战后三峰(通说)。
- **因什么问题**:①统一后的"意大利人"怎么写(民族之问)②方言与标准语谁写文学(双层市场之问:家族实验律三)③学者能否写小说(理论-虚构之问:艾柯)。

## 核心问题

**已解决(通说)**:
- 民族文学的两条路:历史小说(曼佐尼)与底层实证(维尔加真实主义)先后回答"意大利人是谁"
- 双层市场的结构:方言份额单调降但渐近线>0、纪念年双向脉冲(家族实验律三:末期仍约 10%,外推 2200 年有保底 0.072 vs 无保底 0.002)
- 学者小说的范式:艾柯把符号学写进中世纪侦探小说,开创当代出口品牌

**未解决/深水区**:方言文学的正典地位(家族 00 §二地基之争);隐逸派"派"的谱系纯度(通说有辨);艾柯之后当代正典如何生成(家族 01 主线 C)。

## ✨ 这支最美的一个事实

**七百年的语言辩护状换防不退场**:1300s 但丁用拉丁文为俗语辩护;五百年后标准语一统,哥尔多尼用威尼斯方言写出正典喜剧、维尔加用西西里写"真实的意大利"、当代诗人继续以方言入诗——每一层"低"语言都靠杰作获得正当性,每一代都有人宣布它将死,每一代它都活过了讣告(家族实验律三:方言文学的死亡是指数的,永不到达)。
