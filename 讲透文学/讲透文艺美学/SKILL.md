# 文艺美学思维技能卡(讲透文艺美学 · GB/T 75014)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **作品侧**:文学作品的层次结构、语音层/意义单位层/再现客体层/图式化
  观相层、未定点、具体化、纯意向性对象、形式与意义、留白与召唤力
- **经验侧**:期待视野、审美距离(姚斯义/布洛义)、隐含读者、召唤结构、
  空白、卷入度、沉浸、叙事传输、审美经验、情感先验、视域融合
- **接受史**:经典化、正典、文学史重写、畅销与遗忘、《范妮》与
  《包法利夫人》型分岔、再发现、代际趣味变迁
- **实验侧**:倒 U 曲线、唤醒与偏好、新奇×复杂度、暴露效应、重复
  听读的厌倦、时尚引擎、幸存者偏差、贝叶斯先验、熟悉的陌生
- **当代线**:神经美学、计算美学、算法推荐与审美距离、短视频审美、
  互动叙事的隐含读者、数字阅读史

## ② 核心思维模式(这个分支怎么想问题)

1. **骨架-肉身分账**:作品=文本立法的骨架+读者填充的肉身;谈任何
   作品先分清哪部分是结构给的、哪部分是具体化的
2. **先验之眼**:谈任何审美反应先问期待视野——读者带什么类型先验来,
   作品满足它还是越出它?没有参照系的"新颖/无聊"是空话
3. **失配即审美**:审美事件在"期待被满足又被越出"的缝里——距离为
   零则无聊(复制品),距离过大则不可读(乱码),价值在中等偏离的
   内点(新奇×可读最大)
4. **倒 U 加暴露衰减**:偏好对唤醒取倒 U;重复暴露使感知新奇 ρ^t 衰减
   ——峰值品最脆弱,逐季最优新奇 A*/ρ^t 持续上涨直至烧穿尺度
5. **幸存者之眼**:经典=被世代过滤器选过的样本;用幸存集估计"当时
   平均水平"必然高估;接受史没有对照集就是幸存者自传
6. **量的纪律**:审美量(距离/新奇/卷入)必须带参照系、带函数关系、
   以分布不只以均值报告
7. **口音分账**:哲学口音(判断的规范性)与经验口音(参数的测量)
   各管一段;混用必须声明——测得出偏好,测不出"应当同意"的理由

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 英伽登四层分析 | 拆作品结构:语音/意义/客体/观相层层相依 |
| 未定点清单 | 定位留白:哪些是召唤(值得填)、哪些是含糊(没写清) |
| 期待视野重建 | 解释代际反应差:类型惯例+前作经验+媒介习惯 |
| 审美距离双尺 | 姚斯义(作品-视野落差)量创新度;布洛义(心理距离)量卷入-抽离 |
| 召唤结构分析 | 找文本的读者工位:空白/否定/视角切换怎么拽人入场 |
| 审美经验卡 | 把一次阅读钉进坐标:视野/距离/卷入/新奇/判断分栏记账 |
| 作品层次卡 | 把一部作品做成档案:四层+未定点+骨架-肉身分账 |
| 接受史卡 | 把一部作品的世代命运做成时间线:三波接受+对照集审计 |
| 贝叶斯视野模拟 | 新奇=先验-后验偏移;λ 扫描找"熟悉的陌生"最优点 |
| 倒 U 暴露曲线 | 解释流行为什么会过时;内容疲劳与排期决策 |
| 幸存者过滤器 | 审计经典榜单;再发现扫描(去淘汰堆里挖 τ 误杀之作) |

## ④ 常见误区与禁忌

- **把未定点当含糊**:未定点是作品的本体论构成(留白有召唤力),
  不是缺陷(没写清楚)
- **两个"审美距离"混用**:布洛=读者与对象的心理距离;姚斯=作品与
  视野的历史落差——同名异实,先问哪位
- **把隐含读者当目标受众**:它是文本结构里的位置,不是营销人群包
- **无参照系谈新奇**:"这作品很新颖"必须答"相对谁的视野"——
  先验在读者处,不在特征里
- **把倒 U 当死律**:峰值随暴露漂移(A*/ρ^t);且断言形状不断言数值
  (复现气候下锚序不锚数)
- **把经典当平均值**:经典是过滤后的样本;幸存集均值≈当时均值
  是幸存者偏差
- **仿真替代判断**:代码算得出"λ 取多少价值最大",算不出"这段诗
  更好,你应当同意"——规范性归哲学侧
- **价值函数当定律**:"新奇×可读"是骨架假设,换乘法为加法结论即变;
  转码时把骨架写在显式假设栏
