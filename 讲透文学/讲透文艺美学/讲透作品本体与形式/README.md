# 讲透作品本体与形式 · 作品是带空白的图式——英伽登的解剖学

> **定位句**:这支负责**作品侧**:文学作品以什么方式存在(纯意向性对象)、按什么
> 层次组织(四层相依)、把什么留给读者(未定点与具体化)、形式如何载义(骨架与肉身)。
> 与经验侧分工:**这支立法文本,那边立法阅读**——骨架能承受多少种具体化,是两支的接缝。
> GB/T 13745 75014 文艺美学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:英伽登《文学的艺术作品》(1931)立说,《对文学的艺术作品的认识》(1937,
  按通说)补认识论;源头是与胡塞尔的对话(意向性理论)与对新批评/心理主义的第三条路;
  韦勒克、沃伦《文学理论》(1949)的"存在方式"章是其美国回声(通说)。
- **因什么问题**:①作品到底是什么存在(不是印刷品/不是心理状态/不是理念)②"各人有
  各自的读法"何以不是任性(未定点)③形式与意义谁养活谁(层次相依)。

## 核心问题

**已解决(通说)**:
- 作品=纯意向性对象:以作者意向创造、以读者意向再创造的多层结构
- 四层相依:语音→意义单位→再现客体→图式化观相,层层以 lower 层为基
- 未定点与具体化:文本只给图式骨架,空缺由阅读填充——读法多样是结构使然

**未解决/深水区**:
- 层次切分的解释弹性(哪里算新层?形而上质是不是第五层?)
- 未定点与"写得含糊"的判据(召唤力如何不沦为趣味)
- 骨架的约束力:文本立法的边界在哪里(与经验侧的百年谈判)

## ✨ 这支最美的一个事实

**一万个哈姆雷特的本体论执照**:文本写"背影渐渐远去"——体貌、袍色、去向,一概不给;
这不是偷懒,是作品的**结构**。英伽登证明:再现客体天生带未定点,具体化是阅读的本分而非
失误。**多样性从缺陷变成机制**——此后"读不懂你"与"读懂了我"平权,但都跳不出文本画的圈。
