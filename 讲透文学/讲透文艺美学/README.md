# 讲透文艺美学 · 作品的机关与阅读的发生学——美如何住在作品里、发生在读者处

> **本质一句话**:文艺美学=把美学之问**聚焦到文学作品**——不问"美本身是什么"
> (那是[哲学宇宙美学家族](../../讲透哲学/讲透美学/README.md)的本体之问),
> 问三件可研究的事:**作品按什么结构存在**(英伽登的层次与未定点)、
> **审美经验如何发生**(期待视野被满足又被突破)、**经典如何被时间选出**
> (接受史的幸存者过滤器);一句话:**美的哲学本体在哲学宇宙,
> 本家族问作品与审美经验**。
>
> GB/T 13745-2009:750 文学 · 二级学科 **75014 文艺美学**(GB/T 无三级明细 → 自定 2 支;薄家族纪律:章 150-250 行)。

## 一、家族定位

- **两支分工**:同一条河的两岸——**作品侧**(作品本体与形式:作品按什么
  层次存在、未定点在哪、形式如何载义)与**经验侧**(接受与审美经验:
  期待视野如何被满足与打破、读者如何被卷入、审美距离如何调节)。
- **一条主轴贯穿**:作品 →(阅读)→ 经验 →(世代)→ 经典。作品侧守
  前半程,经验侧守后半程;家族实验把三段全部**算术化**(贝叶斯视野/
  倒 U 曲线/幸存者过滤器)。
- **零门槛**:审美经验人人都有;术语随用随讲(三步法:直觉图像→
  严格陈述→最小例子)。不预设哲学史;要哲学地基去
  [哲学宇宙美学家族](../../讲透哲学/讲透美学/README.md)。
- 路线 A(问题派):这书好在哪、我为什么被打动?→00 章→经验侧
- 路线 B(理论派):00→作品侧(英伽登)→经验侧(姚斯/伊瑟尔/杜夫海纳)
- 路线 C(研究派):00→01(实证转向的哲学检讨)→02(审美量的话语)
- 工程师快轨:直接跑 [`experiments/horizon_inverted_u.py`](experiments/horizon_inverted_u.py),再回读 04 章

## 二、家族树(GB/T 无三级明细 → 自定 2 支)

```
讲透文艺美学/                  GB/T 75014(无三级明细,自定 2 支;7501499 类兜底不适用)
├── 讲透作品本体与形式/        自定支——英伽登四层/未定点与具体化/形式与意义(作品怎么存在)
└── 讲透接受与审美经验/        自定支——姚斯期待视野/伊瑟尔隐含读者/审美距离(阅读怎么发生)
```

> 两支合抱成一条主轴:作品是**图式**(带空白的骨架),阅读是**具体化**
> (填空白的发生),经典是**过滤器**(世代选择后的幸存样本)——
> 哲学层(康德-黑格尔-现象学)的谱系归
> [哲学宇宙](../../讲透哲学/讲透美学/README.md),本家族只用不重讲。
