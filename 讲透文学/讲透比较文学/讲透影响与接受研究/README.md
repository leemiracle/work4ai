# 讲透影响与接受研究 · 跨国往来的证据学——文科的外交怎么做账

> **定位句**:这支负责**实证层**——法国学派的四道工序:**流传学**(声誉旅行)、**媒介学**
> (译者/期刊/游历/流亡:文学出国的通道)、**渊源学**(放送端取材)、**译介学**(翻译与
> 误读改写作为文学事实)。口号:没有证据链就没有影响研究。
> GB/T 13745 75021 比较文学 · **自定支(实证层)** · 家族:[讲透比较文学](../README.md)

## 诞生

- **谁/何时**:梵·第根《比较文学论》1937 三分工序定型;伽列序(基亚《比较文学》1951)
  称之"文科的外交";战后成国际主流;姚斯 1967 理论化"接受端";谢天振《译介学》1999 立中国学分主战场。
- **因什么问题**:①凭什么立"影响"(证据之问)②作品靠什么出国、经谁转手(通道之问)
  ③接受端拿到的是原作还是自己的镜像(再创造之问)。

## 核心问题

**已解决(通说)**:
- 证据分级纪律:文本实据/传播实据/旁证/风格相似,四级分明,D 级独撑不立案
- 媒介的类型学:个人媒介之外还有物质与制度媒介(期刊/出版/留学)
- 接受是再创造:"创造性叛逆"把"不忠实"从道德问题改成文学事实问题

**未解决/深水区**:
- 影响的"内在化"怎么证:读过的书如何变成写法的改变——证据链到此让位于阐释
- 口径与账本:零星接触与系统接受的界线(一个译本算影响吗?);数字时代数据库扩容,登记偏倚先除偏

## ✨ 这支最美的一个事实

**"文科的外交"真的有档案**:伽列的比喻不是修辞——影响研究的日常与外交史研究
共享同一套工序:找国书(阅读自述)、查出入境记录(译本/期刊年表)、核对使团
名单(译者行传)。**一个"影响"论断的可审计程度,不亚于一条外交事件的考证**
——人文学的硬,不是数硬,是账硬。
