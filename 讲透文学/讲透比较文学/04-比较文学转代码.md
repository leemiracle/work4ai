# 04 · 比较文学转代码:把跨语结构搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:比较文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**翻译流网络**、**观念漂移**、
> **母题变异**——把"世界文学空间有首都""理论搬家必改姓""创造性
> 叛逆是再生产"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",比较文学转代码要解决"**裁定与机械
的分离**":把一段学科语言("英语垄断了文学翻译的中介")先翻成
模型(语言为节点/译道为边/优先连接生成),再翻成代码。翻译的损耗
全部发生在第一步的**裁定**里(边怎么算、资本怎么赋值、成分怎么分
解)——所以本章先划清哪些对象的裁定已经结算清楚(绿色区),哪些
永远结算不清(红色区),再给三条结算清楚的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 翻译流网络 | 语言节点+直接译道边;生长模型(优先连接 ∝ 度+资本) | 家族实验幕一全程纯标准库 |
| 中介份额(枢纽地位) | 有序对最短路统计:经过枢纽的转译路径占比 | 卡萨诺瓦文学资本的可计算代理 |
| 去枢纽化压力测试 | 删枢纽节点重测连通率 | 目标攻击脆弱性的量版 |
| 观念漂移累积 | 概念向量逐站 v←normalize(v+δ·b+σ·ξ) | 旅行理论的最小几何 |
| 漂移方向性 | 位移对"语境问题域方向"的对齐度(配对噪声对照) | 幕二的判别性设计:对齐度是判决量 |
| 母题变异率 | 成分逐代存活的伯努利过程;1−(1−m)^k 解析式 | 幕三;MC 与解析互证是自检纪律 |
| 三张结构卡(03 章) | 定长字段记录(dict/dataclass)+完整性断言 | 走廊 3 的元数据工程 |

**转不动(红色区)**:

1. **文学性判断**:代码量得出声誉(译本数/评介量),量不出好
   ——02 章不可译残余;硬造"文学质量分"只会把自己的偏好训练
   回自己。工程对策:退到细读(03 章右端),不当目标函数。
2. **影响的经验认定**:模型可以演示优先连接,但"伏尔泰读过什么"
   是文献学考据(史料侧工艺归[历史学宇宙](../../讲透历史学/README.md)
   的方法,互链声明)——模拟不能冒充史料。
3. **语境引力场的真实赋值**:幕二的"问题域方向"是建模假设,
   不是测量结果;真实语境没有坐标纸,只有诠释学。模型给的是
   **测量方案**(距离/对齐度怎么算),不是历史结论。
4. **翻译质量与对话的价值判断**:归化好不好、对话诚不诚,是规范
   之问——留在批评与公共讨论(文学批评/文艺美学侧,同波兄弟,
   文字提及),不进实验台。

**边界的一句话**:绿色区=网络类+漂移类+计数类,覆盖"结构直觉的
校准与测量方案的原型";红色区提醒:**转码是理论的使用说明书,
不是理论的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:翻译流网络走廊(世界文学体系的全机械化)

```
卡萨诺瓦/莫莱蒂 ──参数化──▶ 语言节点+资本禀赋 ──生长──▶ 翻译网络
      │                                            │
      └──压力测试──▶ 中介份额 / 去枢纽连通率 ──▶ 断言
```

- **理论→模型**:诸语言带(人口,文学资本 s);种子双城译道,
  依次入网各开一条译道,通到谁 ∝(度数+资本);再加若干加密译道。
- **算法层**:加权抽样选端点;建成后全部有序对 BFS 最短路,
  统计中介份额;删枢纽重测连通率。
- **本家族实现**:[`experiments/worldlit_travel.py`](experiments/worldlit_travel.py)
  幕一——断言中介份额 ≥4 倍人口份额、去枢纽连通率中位降 ≥0.20。
- **真实系统**:国际出版与翻译资助政策的**枢纽依赖审计**(哪些
  语言对的文学交流完全经第三语言转手);文化多样性监测(去枢纽化
  情景=翻译基础设施的单点风险);世界文学选集的"转译暴露度"统计。
- **性能工程要点**:18 节点全对 BFS 是玩具规模;真实语言网
  (10²-10³ 节点)用预计算全源最短路(Floyd-Warshall O(n³) 或分批
  BFS);蒙特卡洛实现间彼此独立,按实现号分流
  seed=base+实现号,天然可并行;断言只锚中位数与量级,不锚尾数。

### 走廊 2:观念漂移走廊(旅行理论的几何化)

```
萨义德"旅行理论" ──参数化──▶ v←normalize(v+δ·b+σ·ξ) 逐站迭代
      │                                            │
      └──配对对照──▶ 同噪声 δ=0 臂 ──▶ 对齐度判决(有偏 vs 各向同性)
```

- **理论→模型**:概念=单位向量;每站语境引力 b(问题域方向)+
  各向同性噪声 ξ;**配对设计**是判别力的来源:同语境同噪声,只
  差引力——位移方向的差别全部归因于语境。
- **算法层**:逐站向量更新+归一化;统计距离(1−cos)与位移对
  合成引力方向的对齐度。
- **本家族实现**:同实验幕二——断言距离单调增、对齐度有偏臂
  ≥0.30 而噪声臂 ≈0、有偏臂距离 ≥1.25 倍噪声臂。
- **真实系统**:跨语言产品文档/标准/术语表的**语义漂移监控**
  (多语术语库的一致性退化检测:母语定义向量 vs 各语种历史版本的
  距离轨迹);学术概念的跨语引用追踪(同一术语在多语文献中的
  用法聚类漂移);翻译记忆库的版本管理。
- **性能工程要点**:向量运算是 O(k·d) 的小算术,k 站×T 旅程×d 维
  全是乘加——瓶颈在随机数生成,批量预生成噪声数组;距离用
  cos 就够,别上完整 SVD;配对对照臂共用噪声流,省一半随机数。

### 走廊 3:母题变异走廊(变异学的计数化)

```
埃斯卡皮"创造性叛逆"/曹顺庆变异学 ──参数化──▶ 核心成分 m_c/边缘成分 m_p
      │                                              │
      └──系统对照──▶ 强规范 vs 弱规范 × k 代 × T 世系 ──▶ 分层变异率断言
```

- **理论→模型**:母题=核心(仪式性格式)+边缘(装饰)成分;每代
  每成分以系统特异的概率变异(变异即换新,不漂回);分层统计存活。
- **算法层**:伯努利抽签逐代推进;解析期望 1−(1−m)^k 与 MC 均值
  互证(自检纪律:两者吻合说明实现无偏)。
- **本家族实现**:同实验幕三——断言弱系统总变异 ≥1.5 倍强系统、
  强系统核心 ≤边缘一半、MC 与解析差 <3 个百分点。
- **真实系统**:改编链的**保真度台账**(一部 IP 经小说→剧本→
  各语影视的成分存亡账);民间文学流变研究(母题版本树,对象侧
  与中国民间文学家族共享,文字提及);跨语重译的变异对照(同一
  原文的历代译本成分比对)。
- **性能工程要点**:T×k×成分数的抽签是最 embarrassingly parallel
  的负载;成分状态用位压缩(bool 列表→整数位标志)可把内存压
  64 倍;断言锚结构与量级(倍数关系),浮点尾数不进 assert。

### 元走廊:结构卡校验器(03 章三卡的机器执法)

三张卡各成一类记录;完整性断言(影响链卡的**反卡字段非空**——
证伪义务不得弃权;平行比较卡的**可比性论证栏非空**——填不出
即拉郎配;变异追踪卡的**成分分解双人校签名**非空)。这是元数据
工程:价值不在计算量,在纪律——把 02 章"影子语法"与 03 章
"判定流程"编译成校验器(留作 ✍️练习 1)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:多语言内容平台的枢纽依赖审计

给任何跨语言内容系统(翻译 pipeline/多语知识库/国际化文档)配一次
幕一式体检:内容从语种 A 到语种 B,多少比例经枢纽语种转手
(转译/转写/术语对齐借道英语)?枢纽依赖度=转手占比。**幕一的
教训是双向的**:枢纽带来效率(通道复用),也带来单点风险与系统性
失真(枢纽的语义先入为主——走廊 2 的引力场)。审计后你才知道
哪些语言对在"裸奔"。

### 落点 2:术语与文档的漂移监控

多语产品文档/标准/术语表随版本演化,各语种各自更新——漂移悄悄
累积(走廊 2 的工程版)。落点:以母语版本为锚,逐版本算各语种的
语义距离轨迹(嵌入向量或术语级比对),距离超阈值报警。**漂移
有方向**:先看它偏向哪一类词(功能词/文化词/数字词),再决定
要不要拉回——盲目回译同步可能把有意的本地化一并抹掉(归化不是
罪,见 02 章对偶)。

### 落点 3:改编与重译的变异台账

任何"一源多版"的资产(IP 改编链/多语重译/多平台改写)按变异
追踪卡建档:核心成分(必须保真的品牌/规范/法律要件)与边缘成分
(自由本地化区)分开登记,逐版本核算存活率。**幕三的分层是设计
原则**:核心区上变更控制(评审+回归),边缘区放权本地化——
强规范管骨架,弱规范管装饰,两不耽误。

### 落点 4:世界文学的数据纪律(选集与推荐)

内容平台做"世界文学"书单/课程/推荐时,先跑一遍 02 章的口径三问
(谁登记的/经谁转译/哪些语言没进账本),再决定推荐权重的去偏
方案——**别把登记偏倚当成读者偏好**;选集的"转译暴露度"
(多少作品经第三语言进入你的语种)是比国别配额更诚实的多样性
指标(走廊 1 的直接应用)。

## 📌 收束 + 🧭 认知升维

的内容流动,先问三件事:经没经枢纽(通道结构)、漂没漂移(方向
与距离)、核心成分还活着吗(分层存亡)。转码让这三问从修辞变成
可跑的断言;而红色区的边界同样有用:**结构算得出,意义读出来**——
两套设备各干各的活。
