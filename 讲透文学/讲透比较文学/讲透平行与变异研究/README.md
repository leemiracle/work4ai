# 讲透平行与变异研究 · 无往来的比较与必然的变形——可比性两问

> **定位句**:这支负责**类比层**——**平行研究**(无事实接触的对照,雷马克判据:服务于
> 文学性问题)、**跨文明对话**(中国学派主张:异质文明互为参照系)、**变异学**(曹顺庆:
> 流传中的过滤/误读/改写是研究对象本身,不只是噪音)。口号:没有往来也可比,可比必生变异。
> GB/T 13745 75021 比较文学 · **自定支(类比层)** · 家族:[讲透比较文学](../README.md)

## 诞生

- **谁/何时**:1958 韦勒克危机论开路;1961 雷马克定义合法化平行研究(影响/平行/跨学科
  三分);1970s 台湾学者提"中国学派",1980s 大陆学科重建;1979 钱锺书《管锥编》示范
  "打通";2000s 曹顺庆立变异学。
- **因什么问题**:①没有证据链的比较凭什么成立(可比性之问)②异质文明怎么比(跨文明之问)③比较只找"同"吗——变异才是常态吗(变异之问)。

## 核心问题

**已解决(通说)**:
- 三层次工序:类同(表面相似)→对比(同中之异的文化语法)→汇通(互相照亮不自知处);
  可比性判据从相似度改为**照明度**(并置产生的理解增量)
- 变异的三种基本形态:过滤(选择性接受)/误读(语境性重构)/再创造(文类性改写)

**未解决/深水区**:
- 可比性的最终判据:雷马克的"文学性"是判据不是程序,拉郎配之讥未绝
- 变异学的学科地位(独立方法还是交集,国际讨论中,家族 01 章主线 C);文明单位之争("跨文明"边界谁定)

## ✨ 这支最美的一个事实

**《管锥编》的"打通"是平行研究的中国解法**:钱锺书不考证影响,不建体系,只做一件事
——让中西文论在一个具体感受上互相照明(一句杜诗对一句荷马,一条刘勰对一条但丁)。
"东海西海,心理攸同"不是断言人类文化一样,而是**比较的作业方式**:同处在照明中
显形,异处也在照明中显形。**最好打的比较,"同""异"的账一起算**——这正是平行
研究(找同)与变异学(究异)住在同一支的理由。

## 假设与依赖

- 买入"无接触的对照可产出文学学知识",付可比性证明责任与拉郎配风险(对策:平行
  比较卡的可比性论证栏必填,家族 [03 章](../03-可构造与结构.md))
- 变异测量依赖母题成分分解(理论裁定+双人校);对象侧借民间文学类型学(同波,文字提及)
- 跨文明比较一律通说学术口径,不做文明优劣判断
