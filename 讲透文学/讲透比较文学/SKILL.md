# 比较文学思维技能卡(讲透比较文学 · GB/T 75021)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **体系类**:世界文学、Weltliteratur、文学世界共和国、文学资本、
  格林尼治子午线、中心-边缘、远读、椭圆形折射、世界文学体系
- **影响类**:影响研究、流传学、媒介学、渊源学、译介学、译本系谱、
  接受研究、期待视野、文科的外交
- **平行类**:平行研究、可比性、类同-对比-汇通、跨文明对话、
  中国学派、拉郎配
- **变异类**:创造性叛逆、变异学、误读、归化异化、过滤、改写、
  旅行理论、理论搬家、自译
- **方法之争类**:法国学派、美国学派、雷马克定义、韦勒克危机、
  艾田伯、欧洲中心主义批判、巴斯奈特倒转
- **量化类**:接受度、翻译密度、中介份额、变异率、母题存活率、
  翻译流网络、去枢纽化

## ② 核心思维模式(这个分支怎么想问题)

1. **国境线之眼**:看到文学现象先问——它跨语了吗?跨语的证据链
   在哪(译本/期刊/书信/藏书)?没跨语的对照,可比性论证过了吗?
2. **证据分级**:谈影响必先定级——A 文本实据/B 传播实据/C 旁证/
   D 风格相似;D 级独撑不得立"影响",那是平行研究的地盘
3. **可比性论证**:无接触的并置要答"理解增量是什么"——判据是
   照明度(照亮对方不自知处的程度),不是相似度;答不出即拉郎配
4. **变异分层**:跨语变形先问落在母题哪一层——核心(仪式性格式)
   还是边缘(装饰);强规范系统核心保守,弱规范系统全面高变异
5. **体系之眼**:单个跨语事件都在一张不平等的地图上——文学资本
   集中于枢纽语言,中介份额远超人口份额;连"被计数"都要经枢纽
6. **改姓预期**:理论/概念跨国旅行必被接受语境重铸——漂移有方向
   (每站往自己的问题域拉),不是各向同性的磨损
7. **先定量族再读数**:任何"很受欢迎/走向世界/被误读"先问用哪族
   量(接受度/翻译密度/变异率)、口径是什么、谁登记的账本

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 影响链卡(证据分级+反卡) | 审计任何"X 影响 Y"的主张;证伪义务(找过而未见)必填 |
| 平行比较卡(三层次+可比性栏) | 设计或检验无接触对照;类同→对比→汇通逐层填 |
| 变异追踪卡(成分分解+逐站登记) | 改编/重译/跨语改写的保真台账;核心-边缘分层 |
| 翻译流网络+中介份额 | 枢纽语言地位测量;多语系统的单点风险审计 |
| 去枢纽化压力测试 | 体系依赖度:拔掉枢纽,谁断路 |
| 语境引力/对齐度 | 概念跨语漂移的方向性诊断(有偏 vs 各向同性) |
| 母题存活率 1−(1−m)^k | 变异率的解析预期;强/弱规范系统对照 |
| 文学时差(卡萨诺瓦) | 边缘文学的"迟到"分析——位置描述,不是价值排序 |
| 四调定位(预言/诊断/定义/书架) | 快速诊断任何"世界文学"用语的站位 |

## ④ 常见误区与禁忌

- **把"影响"读成"模仿/抄袭"**:影响的内核是创造性转化,证据
  分级里 D 级(风格相似)单独不立案
- **把平行比较做成相似度陈列**:可比性判据是照明度,不是"X 和 Y
  都写了爱情"
- **把创造性叛逆当"乱译有理"的许可状**:它是描述性诊断(叛逆是
  到达的方式),不是翻译质量的赦免
- **把"时差"读成"落后"**:卡萨诺瓦的时差是文学空间的位置变量,
  转成价值排序恰是她反对的
- **把翻译流数字当无偏测量**:登记偏倚本身就是体系不平等的镜像
  (英语超额登记、小语种欠登记)
- **把"世界文学"当"外国文学合集"**:前者是关系概念(折射/获益/
  阅读三义),后者是库存概念
- **用模型冒充史料**:优先连接演示的是机制,伏尔泰读过什么是
  文献学的活
- **量得出声誉≠量得出好**:度量衡的尽头是细读的地界
