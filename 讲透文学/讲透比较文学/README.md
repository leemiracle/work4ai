# 讲透比较文学 · 文学的国境线——跨越语际的文学科学

> **本质一句话**:比较文学=文学的**跨语际科学**——它不研究某一国文学,
> 而研究文学**穿越语言国境线**时发生的一切:谁流向谁、经谁转手(影响与
> 接受研究),没有往来也可对照吗(平行与变异研究),穿越时必然变形的
> 那部分(翻译与世界文学);每收一对语言买入**跨语际的概括力**,付出
> **可比性的证明责任**;
> 一句话:**国界不是文学的墙,是这门学科的水文站——它量的是水流**。
>

## 一、家族定位(它在文学宇宙里的位置)

文学研究的一切方法都能在国境线内侧运行;比较文学的独特发问是:**把
国境线本身变成研究对象**——一部作品离开母语后经历了什么(译本/改写/
误读/经典化),两个互不来往的传统为何长出了相似的形态(平行研究),
一个观念跨语旅行后为何必然改姓(旅行理论/变异学)。它在 750 宇宙里是
**关系的科学**:国别家族管语言的内部纵深,文学理论管单语工具,本家族
管**文学的世界地理**——水流、水闸与水文站。五问(体系/前沿/语言/
构造/转码)的回答见家族层五章。

- **零门槛**:不要求多语能力(研究翻译史≠读原文,读对照译本即可入门);
  只想看"中外文学异同"趣谈的去各国别家族,本家族管**比较的纪律**
- 路线 A(问题派):一个理论出国后为何变了味?→00 章§七发现 2;
  小语种作家为何必须经英语出海?→00 章§七发现 1
- 路线 B(理论派):00→01(前沿地图)→02(比较的语言怎么造出来)
- 路线 C(研究派):00→03(三张结构卡)→04(转码走廊)
- 工程师快轨:直接跑 [`experiments/worldlit_travel.py`](experiments/worldlit_travel.py),再回读 04 章

## 二、家族树(GB/T 无三级明细 → 自定 3 支)

```
讲透比较文学/                GB/T 75021(无三级明细 → 自定 3 支)
├── 讲透影响与接受研究/       自定支(实证层)——流传学/媒介学/渊源学/译介学:
│                              影响关系的证据学(法国学派的工序,升级版)
├── 讲透平行与变异研究/       自定支(类比层)——平行研究/跨文明对话/变异学:
│                              无影响也可比,可比必生变异(美国学派+中国学派)
└── 讲透翻译与世界文学/       自定支(体系层)——翻译研究/世界文学体系/经典的
                               跨语旅行:文学的世界地图(歌德—卡萨诺瓦—莫莱蒂)
```

> 三支的共同血统:同一个发问「**跨越即方法**」的三层落地——实证层管
> **有过往来吗**(证据链),类比层管**没有往来怎么比**(可比性),体系层
> 管**所有往来加起来长成什么结构**(世界文学空间)。三层缺一即塌:
> 没有证据层是清谈,没有类比层是史料堆,没有体系层是无穷琐屑。
