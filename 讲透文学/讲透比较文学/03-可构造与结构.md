# 03 · 可构造与结构:哪些比较对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:比较文学的对象沿一条**可构造谱系**排开——翻译流
> 网络端**严格可构造**(边写得下、中介份额算得动、断言得了),变异
> 追踪端**半可构造**(成分分解是理论裁定,但分解定了就可计数),
> 文学性端**几乎不可构造**(细读的地界);全谱系共享两条结构引擎:
> **优先连接生成中心-边缘**(文学资本的马太效应)与**语境引力生成
> 定向漂移**(旅行理论的几何);而"比较的纪律"本身可以压进三张
> **结构卡**(影响链卡/平行比较卡/变异追踪卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
翻译流网络 ── 译本系谱 ── 变异追踪 ── 影响链卡 ── 平行比较卡 ── 跨文明对话 ── 文学性本身
  │                                                            │
严格可构造(可断言)                                        几乎不可构造(只有细读与论证)
  └── 边/中介份额/连通率全能过 assert                    └── 比较的结论在这里靠说服,不靠计算
        └── 变异追踪在中段:分解是裁定,计数是机械
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:翻译流
网络的语义是"语言对之间有无直接译道",输入输出明确;而"文学性"的
语义进入细读——**评价者本人就是测量仪器**,仪器无法装配仪器。本章
先盘家底,再看两条结构引擎,最后把比较的三台机器压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **翻译流网络→中介份额** | 语言为节点/直接译道为边;生长模型(优先连接 ∝ 度+文学资本);最短路统计转译路径 | 低(家族实验幕一全程可跑) | 边的判定口径("多少译本算一条译道")是理论裁定;登记偏倚(02 章) |
| **观念漂移累积** | 概念向量逐站 v←normalize(v+语境引力+噪声);距离与对齐度皆可断言 | 低(幕二全程可跑) | 语境"问题域方向"是建模假设——它量化的是萨义德的论点,不是证明它 |
| **母题变异率** | 母题分解为核心/边缘成分;逐代存活计数;1−(1−m)^k 有解析式 | 低-中(幕三) | 核心与边缘的**分解本身是文学裁定**(什么是十四行诗的"仪式性核心"?)——分解定了,计数是机械 |
| **译本系谱** | 同一作品诸译本的版本链:译者/底本/年代/出版 | 中(史料工程) | 底本考证是文献学工艺(史料侧方法归历史学宇宙,互链) |
| **影响链卡** | 放送者/媒介/接受者/证据类型/证据强度的固定字段表 | 中(§四 schema) | 证据强度的分级是判断,须双人独立定再对表 |
| **平行比较卡** | 比较项/比较点/类同-对比-汇通/可比性论证 | 中 | **可比性论证栏是本卡的灵魂**——填不出即拉郎配 |
| **跨文明对话** | 只有论证程序(双向照明/互为参照系) | 高 | "文明"单位本身的争议(00 章§四);对话质量无法程序化 |
| **文学性本身** | 细读与批评 | **不可构造** | 量得出声誉,量不出好(02 章不可译残余);度量衡的尽头是细读 |

**反直觉发现(本章铁律)**:**比较文学的名构念与可构造性成反比是
常态**。"世界文学"最有名,几乎不可构造;"翻译流网络"最少被文学
院提起,却能跑出过硬的断言。**左端管结构,右端管意义**;用右端对象
硬造左端指标(拿几个书目数字宣布某作品"属于世界文学")是本学科
量化研究的头号失真来源——两头都不是。

## 二、结构引擎 1:优先连接生成中心-边缘(文学资本的马太效应)

**直觉图像**:世界文学空间的不平等不是坏人做出来的,是**累积优势**
自我生成的——翻译伙伴越多的语言,越容易吸引新的翻译关系(译者供给
向大语种集中、出版社注意力跟市场走、学术体系用中心语言记账)。

- **数学化身**(家族实验幕一):语言 i 被新译道选中的概率 ∝
  (k_i + s_i),k=现有伙伴度,s=文学资本禀赋;种子从"伦敦-巴黎"
  双城开始,诸语言依次入网。三条刚性:
  1. **禀赋差复利放大**:英语的 s=10 对 s=1 的边缘语,初始吸引
     力差 10 倍;终局中介份额差近 6 倍(59.4% vs 人口份额 10.3%)。
     **小的历史差距×优先连接=终局的天壤之别**——卡萨诺瓦"文学
     资本靠积累增值"的形式化身。
  2. **枢纽稳定性**:200 个实现中 96.5% 枢纽=英语——结构的再生
     能力强(不是运气);换种子数字,结论不变。
  3. **目标攻击脆弱性**:移除枢纽,语言对连通率中位降 22.8%——
     无标度网络的经典性质(Albert-Jeong-Barabási 2000,通说)在
     文学空间的复刻:对随机故障鲁棒,对枢纽失效脆弱。
- **刚性从哪来**:概率规则与图论度量(最短路/连通率)是刚的;
  软的地方在**边的判定口径与 s 的赋值**——这正是 02 章的比较量
  口径问题。模型量化的是体系论的**机制直觉**,不是历史事实本身
  (它是一台思想实验机器,不是史料)。

## 三、结构引擎 2:语境引力生成定向漂移(旅行理论的几何)

**直觉图像**:观念跨语旅行不是各向同性的扩散(像墨滴入水),而是
**有引力的漂移**——每一站的接受语境用自己的问题域拉扯概念,轨迹
是被一路的引力场掰弯的。

- **数学化身**(家族实验幕二):每站 v←normalize(v+δ·b+σ·ξ),
  b=该站语境的问题域方向,ξ=噪声。三条刚性:
  1. **距离单调累积**:k=1→6 末端距离 0.033→0.344——部分保留+
     部分漂移,漂移只加不减(漂移过的成分不漂回)。
  2. **漂移有方向**:位移对"本旅程诸语境问题域"的对齐度 0.78,
     纯噪声对照 −0.02——**改姓不是随机的,是每站语境按自己的
     议程改写**。萨义德"接受环境重铸观念"的几何化。
  3. **引力胜扩散**:同站数下有偏臂距离 3.8 倍于噪声臂(0.344 vs
     0.090)——系统性引力走线性累积,随机噪声只走 √k 扩散;
     站数越多,语境的改写越是压倒性的。
- **对偶化身**:归化(韦努蒂)是语境引力在**翻译策略**上的名字;
  创造性叛逆(埃斯卡皮)是它在**价值判断**上的名字;变异学把它
  升格为**研究对象本身**——同一机制的三种口音(02 章§三)。
- **刚性从哪来**:随机游走与漂移的数学是刚的(大数定律);软的
  地方在"问题域方向 b"的设定——六个语境轴是建模假设,真实语境
  的引力场没有坐标纸。用法:模型给"旅行理论"提供**机制演示与
  测量方案**(距离/对齐度怎么算),不提供历史结论。

## 四、结构卡 schema:把比较的纪律压进三张卡

**先答为什么**:比较研究最难携带的是"纪律"——影响研究要证据分级,
平行研究要可比性论证,变异研究要成分分解,全靠自觉。结构卡是
**有限字段的压缩格式**:字段固定、填空即可复用、可比可查可补
(这是"可构造"在方法层的对应物:卡片本身严格可构造)。

### 卡 1:影响链卡(把一次跨国文学往来钉进证据分级)

```
【影响链卡】
放送者:________(谁影响谁:作品/作家/思潮,源语与年代)
接受者:________
媒介:________(译者/译本/期刊/游历/流亡/留学生——文学的出国通道)
证据类型与强度(逐条定级):
  A 级=文本实据(译本/藏书/书信中自述阅读)________
  B 级=传播实据(期刊译介/出版记录/流通痕迹)________
  C 级=旁证(同时代人记述/传记材料)________
  D 级=风格相似(仅此一条不得立"影响"——平行研究处理)________
接受端反应:________(评介/论战/再创作——接受是再创造)
可检验推论(一条):________(如"应存在 X 年前的译本/节译")
反卡(没有影响的检验):________(找过而未见的证据——证伪义务)
```

样例(已填,《赵氏孤儿》线):放送者=纪君祥(元);接受者=伏尔泰
(法);媒介=马若瑟译本入杜赫德《中华帝国全志》(1735,通说)+
18 世纪欧洲"中国热"期刊场;A 级=伏尔泰《中国孤儿》剧本与自称
取材之论;B 级=《中华帝国全志》出版与流通记录;接受端反应=启蒙
论战语境中的改写(改朝代/改主题);可检验推论=1755 前应有可供
伏尔泰读到的译本/转述(已证实);反卡=无证据表明伏尔泰读过更多
元杂剧(其中国知识来源可另行核查)。

### 卡 2:平行比较卡(把一次无接触对照钉进可比性论证)

```
【平行比较卡】
比较项 A / B:________(两个没有事实接触的文本/作家/文类)
接触检查(影响排除):________(检索过影响链卡吗?结果如何)
比较点(限三个以内):________(自然观/时间意识/抒情结构……)
三层次:
  类同(表面相似):________
  对比(同中之异——文化语法):________
  汇通(互释后各自的"不自知"):________
可比性论证(本卡灵魂):并置产生的理解增量是什么?________
  判据:照明度(照亮对方不自知处的程度),不是相似度
失效条件:________(什么新证据会让这次比较失去意义——如发现
  事实接触,则转入影响链卡)
```

样例(已填,IWL 教学案,01 章主线 D):A=杜甫/B=华兹华斯;接触
检查=无(时代与传播链均排除);比较点=自然观/抒情主体的位置/
个体与伦理秩序;类同=都以自然为抒情的触发器;对比=自然作为伦理
秩序的显影 vs 自然作为心灵的镜子;汇通=各自"自然"背后是两套
文明语法(入世的伦理宇宙/浪漫的主体性);可比性=照明度高——
并置后各自的传统边界显形;失效条件=若发现 18 世纪中国诗歌英译
曾实质影响华兹华斯(无此证据,通说)。

### 卡 3:变异追踪卡(把一次跨语变形钉进成分分解)

```
【变异追踪卡】
旅行线:源文本 → 第 1 站 → 第 2 站 → …(语言/年代/媒介)
母题成分分解(理论裁定,双人校):
  核心成分(仪式性格式:文类骨架/结构功能/禁忌)________
  边缘成分(情节装饰:人名/地名/插曲/结局细节)________
逐站登记:每站各成分 存留/替换/删除 + 变异类型(误读/过滤/
  归化/再创造)________
变异率核算:核心存活率 / 边缘存活率 / 总变异率(02 章量族 3)________
系统性判读:落在强规范还是弱规范系统(幕三实验的对照)________
创造性叛逆判据:变异是否换来新的文学效力(到达新读者/进入新
  文类)________
```

样例(已填,《赵氏孤儿》→《中国孤儿》):核心成分=孤儿蒙难/义士
代孤/牺牲与存续的仪式骨架(存留);边缘成分=朝代(宋→成吉思汗
时代)、复仇主线(改为文明教化)、人物谱系(大幅重设)——边缘
几乎全换;总变异率高,但**核心骨架存留**=典型的跨文明改写:
变异落在边缘层,母题核心靠"救孤"的仪式结构活了下来;创造性
叛逆判据=成立:不入启蒙论战,元杂剧进不了欧洲视野。

**判定流程**(把一个比较主张钉到谱系上):

```
该主张的核心对象能写成网络、清单或计数吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(清单/分解,填空带裁定)─▶ 中段:卡片化+双人校,禁止硬算
  └─ 不能(意义/文学性/对话质量)──▶ 右端:细读与论证,禁止压成参数
```

## 五、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 影响与接受研究 | 中段为主(影响链卡/译本系谱),右端是接受的理论 | 语境引力(接受端的再创造) | 中(卡片+系谱,填空带裁定) |
| 平行与变异研究 | 左-中横跨(变异追踪可计数,可比性论证在右端) | 双引擎并用(引力=变异的动力;连接=变异的通道) | 分裂:变异率可算,对话质量不可 |
| 翻译与世界文学 | 左端(翻译流网络/中介份额是最硬的一段) | 优先连接(中心-边缘的生成) | 高(网络与份额全机械化) |

**读表法**:一个支的"可构造纯度"决定它的转码方式(04 章)——
体系论走计算,证据学走卡片,对话走论证。**没有哪支全家可构造,
也没有哪支全家不可构造**;比较文学的独特处是它的**中段最宽**:
分解、分级、论证——裁定与机械各半,这正是三张卡存在的原因。

## ✨ 美之时刻(彩蛋第 6 枚:证据分级)

✨ **美之时刻 6:证据分级——"文科的外交"做成情报分析**(极简)
伽列说比较文学是文科的外交;影响链卡把外交做成情报分析:每条证据
带等级(A 文本实据/B 传播实据/C 旁证/D 风格相似),D 级单独不得
立案,"影响"与"模仿"从此有了分界线;还有一张反卡——**证伪
义务**(找过而未见的证据也要记录)。为什么美:**它把"我觉着他受
了影响"变成一张可审计的表**——人文学的论证第一次像海关报关单
一样可以逐项核验;而举证责任倒置的哲学(谁主张影响谁举证)就
藏在卡片的字段顺序里。亲历:给你信服的一个"影响论"填影响链卡
(✍️练习 1),D 级独撑的影响论会在表格里当场现形。

## 📌 收束 + 🧭 认知升维

交给细读。
