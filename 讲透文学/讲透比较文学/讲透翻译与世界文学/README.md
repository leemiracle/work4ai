# 讲透翻译与世界文学 · 文学的世界地图——水流加总成水系

> **定位句**:这支负责**体系层**——**翻译研究**(归化/异化/译者行为:翻译的内部之学)、
> **世界文学体系**(卡萨诺瓦文学资本与首都/莫莱蒂中心-边缘与远读/达姆罗什三义)、
> **文学经典的跨语旅行**(经典如何被翻译、重译与再经典化)。口号:所有跨语交往加起来,
> 长成一个有结构的世界。GB/T 13745 75021 比较文学 · **自定支(体系层)** · 家族:[讲透比较文学](../README.md)

## 诞生

- **谁/何时**:歌德 1827 谈 Weltliteratur;《共产党宣言》1848 以世界市场论断精神产品的
  全球流通(通说);韦努蒂《译者的隐身》1995 与巴斯奈特 1993 确立翻译研究独立地位;
  卡萨诺瓦 1999、莫莱蒂 2000、达姆罗什 2003 三峰并立。
- **因什么问题**:①"世界文学"从口号到概念:作品库、体系还是阅读方式(概念之问)
  ②文学世界空间有结构吗——平等交流还是中心-边缘(结构之问)③经典靠什么跨语存活(经典之问)。

## 核心问题

**已解决(通说)**:
- 达姆罗什三义:世界文学=民族文学的椭圆形折射/从翻译中获益的书写/一种阅读模式
- 体系论三模式:卡萨诺瓦(文学资本与首都)/莫莱蒂(不均的内部+远读)/达姆罗什(流通与阅读)——互竞但共享"结构化"纲领;归化/异化与译者行为成标准工具

**未解决/深水区**:
- 世界文学的单位:国家/语言/文明/资本,切法不同结论不同(家族 00 章§四)
- 体系论的多中心化(东亚、南亚翻译流是否另类水系,01 章主线 A);数据偏倚
  (数据库登记不全是体系不平等的镜像,除偏方法学在建)

## ✨ 这支最美的一个事实

**文学也有本初子午线**:卡萨诺瓦把"世界文学的不平等"从道德抱怨变成几何对象
——文学空间有自己的格林尼治:历史上在巴黎,现下在英语;各地文学有"时差",
边缘作家的"迟到"是位置不是缺陷,且可量化(写作年份与首译年份之差)。
**承认不平等才是分析的起点**——世界文学研究从互相祝酒的世界主义变成一门有地图的科学。
