# 讲透拉美文学 · 一台边缘接管的机器——从殖民编年史到 McOndo

> **本质一句话**:拉美文学=**一台边缘接管的机器**——殖民编年史从"被写"
> 起家(哥伦布航海日记/迪亚斯《新西班牙征服纪实》),索尔·胡安娜在巴洛克
> 里为殖民地夺回笔(1691《答菲洛特亚修女信》,通说"第十位缪斯"),高乔诗
> 把草原口语立成书面传统(《马丁·菲耶罗》1872),达里奥《蓝》(1888 前后)
> 让拉美第一次向欧洲输出风格,博尔赫斯《虚构集》(1944)造出观念小说的
> 出口,"文学爆炸"(1960s-70s:科塔萨尔/富恩特斯/略萨/马尔克斯 1967
> 《百年孤独》)十年内把大陆小说装进世界书市,独裁者小说与后爆炸、
> McOndo 一代再为标签赎身。一句话:**从被写到写,从译入到译出,从借标签
> 到拆标签——拉美文学的一切机关,都在"边缘怎么接管中心"的转译装置里**。
>

## 一、家族定位

- **两支分工**:同一条"边缘接管"主轴的上下游——**殖民至现代主义支**
  (笔怎么夺回来:编年史/巴洛克/高乔文学/现代主义诗歌/地区主义小说)与
  **文学爆炸与当代支**(世界书市怎么接管:博尔赫斯/Boom 四主将/
  独裁者小说/后爆炸与当代)。
- **一条主轴贯穿**:夺笔(索尔·胡安娜)→造出口(博尔赫斯的观念小说)→
  接管书市(Boom 十年)→赎回标签(后爆炸与 McOndo)。前支守"笔怎么
  到手",后支守"标签怎么拆";家族实验把四段全部**算术化**(时序结构/
  爆发窗口/标签市场)。
- **零门槛**:读过一本《百年孤独》或只知道"多年以后"开头句就能进;
  术语随用随讲(三步法:直觉图像→严格陈述→最小例子)。不要求西班牙语;
  要编年全景去[世界文学史](../讲透世界文学史/README.md),
  要跨语旅行去[比较文学](../讲透比较文学/README.md)。

| [`experiments/boom_time_labels.py`](experiments/boom_time_labels.py) | 魔幻时序-爆炸窗口-标签市场三律模拟(纯标准库,固定种子 20260909;叙事与市场参数为风格化构造,运动年代与出版机制按通说):①**魔幻现实的时序结构**——同一组 40 叙事单元,线性编年 vs 马孔多式(首句闪前+"多年以后"公式预告+羊皮卷弧线+尾声回环):张力重心 **0.680→0.512**(前移 0.167,张力从后段移到中段),前半程张力份额 **0.296→0.502**;重读伏笔密度 首读 0.125→二读 0.275(**×2.2 倍增**),二读密度为线性式的 **6.7 倍**——**马孔多的时序是设计出来的重读机器**;②**Boom 的世界市场爆发**——1963-1972 十年窗口吃掉全程世界可见度 **69.2%**(均匀基线 19.6% 的 **3.5 倍**),窗口释放量=1962 年全部存量的 **2.0 倍**;反事实去掉翻译接力:峰值降至 **32%**、峰值年推迟 **17 年**、中位年推迟 7 年——**条件链(1959 注意力事件+1962 巴塞罗那发行+1966-70 翻译接力)缺一环,爆发就不是爆发,是二十年的慢漏**;③**标签的市场动力学**——"魔幻现实主义"从批评概念到货架类别:corr(标签流行度, 贴标书中位正典分)=**−0.957**,概念期中位分 0.754 是营销期 0.227 的 **3.3 倍**;反标签(McOndo 式)部分成功:后爆炸读者群去标采用=贴标的 **2.0 倍**(胜出),旧市场仅 **0.36**(失联)而入典率只及贴标的 **21%**,末期两市场合计追平(1.18)——**标签是船票也是牢笼** | ✅ |
