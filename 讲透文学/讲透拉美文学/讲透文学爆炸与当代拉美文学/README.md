# 讲透文学爆炸与当代拉美文学 · 世界书市怎么接管——博尔赫斯、Boom 四主将到 McOndo

> **定位句**:这支负责**文学爆炸与当代侧**:"边缘接管的机器"怎么把世界书市接管——博尔赫斯《虚构集》(1944)造出观念小说的出口(1961 福门托奖先行出圈,通说),古巴革命(1959)的注意力事件、巴塞罗那全球西语发行线(1962 起)与法语英语翻译接力(1966-70)三环合流,Boom 四主将十年连环出牌:富恩特斯《阿尔特米奥·克罗斯之死》(1962)/略萨《城市与狗》(1962/63)/科塔萨尔《跳房子》(1963)/马尔克斯《百年孤独》(1967,1982 诺奖收据,通说);独裁者小说续写权力(《我,至高无上者》1974/《族长的秋天》1975);后爆炸转向小体量与媒介(普伊格《蜘蛛女之吻》1976/萨尔杜伊新巴洛克,通说综述);McOndo(1996)反标签、波拉尼奥重画版图、邦巴尔线与施维伯林一代的女性重估(均通说)。与殖民至现代主义支分工:**那边管笔怎么到手,这支管标签怎么借怎么拆**——幕二幕三的主场地界。
> GB/T 13745 75081 拉美文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:博尔赫斯线(《虚构集》1944/《阿莱夫》1949,与贝克特同获福门托奖 1961,通说);Boom 线(1959 注意力事件→1962 巴塞罗那发行线→四主将 1962-1967→1971 帕迪利亚事件降温,学术史平实叙述);独裁者小说线(阿斯图里亚斯《总统先生》1946 先声→罗亚·巴斯托斯 1974→马尔克斯 1975,通说);后爆炸线(萨尔杜伊《眼镜蛇》1972/普伊格 1976,通说综述);当代线(McOndo 文选与裂罅一代 1996/波拉尼奥《荒野侦探》1998/《2666》2004/邦巴尔线重估/施维伯林线,通说)。
- **因什么问题**:①边缘的小说怎么进世界书市②权力能否被小说解剖③总体小说之后写什么④标签是船票还是牢笼。

## 核心问题

**已解决(通说)**:Boom 的年代学与管道(巴塞罗那线/翻译接力)可考;四主将正典地位稳固;独裁者小说与后爆炸作为转向坐标清晰。

**未解决/深水区**:Boom 六十年后的名单重画(女性作家/小国作家,家族 01 章主线 C);标签第三期是什么(标签市场卡的开放格);McOndo 一代的自我命名已史化,之后的当代框架无共识(通说综述)。

## ✨ 这支最美的一个事实

**一句话装下一台时间机器**:《百年孤独》首句"多年以后,面对行刑队……"在三个时态里同时打开过去、未来与现在(通说常引)。为什么美:**幕一整台实验(闪前+预告+回环)在首句装配完毕——张力重心 0.68→0.51,重读密度×2.2;世界文学 1967 年学到的不是题材,是装置**。幕二幕三(窗口与标签)的全部机制都以这台机器的产品为货:手稿是真的,爆发是管道的,标签是后来贴上的。
