# 04 · 拉美文学转代码:把时序、窗口与标签搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:拉美文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**时序结构仿真**、**爆发窗口
> 递推**、**标签市场模拟**——把"马孔多的时序是设计出来的重读机器"
> "爆发不是匀速增长是集中释放""标签是船票也是牢笼"变成可跑、
> 可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",拉美文学转代码要解决"**代理化**":
把一段文坛语言("《百年孤独》为什么耐读")先翻成模型(悬念债+
时序装置),再翻成代码。翻译的损耗全部发生在第一步——所以本章先
划清哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给
三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 文学史概念 | 代码化身 | 备注 |
|-----------|---------|------|
| 悬念债与张力曲线 | 债务表(开位,还位,权重)×位置求和 | 实验幕一全程纯标准库 |
| 张力重心前移 | 位置加权均值的对照断言 | 幕一 1a |
| 重读收益 | 设计伏笔×两遍识别概率的密度 | 幕一 1b |
| 世界可见度爆发 | 存量池+条件链+释放的逐年递推 | 幕二 |
| 集中释放/窗口份额 | 窗口和/总和+均匀基线对照 | 幕二 2a |
| 缺环反事实 | 条件开关(接力 on/off)的同种子对照 | 幕二 2b |
| 标签流行度 | 逻辑斯蒂 L(t) | 幕三 |
| 标签稀释 | 流行度-中位正典分的相关+分期对比 | 幕三 3a |
| 反标签两市场 | 偏好矩阵×市场规模变迁的采用率 | 幕三 3b |
| 三张结构卡 | 定长字段记录+完整性断言(证据栏非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **文学性**:代码能算重读密度,算不出《百年孤独》好不好——风格
   判断只能由阅读见证(03 章右端)。
2. **"拉美性"/奇妙现实的真伪**:世界观与风格的"在场"不可枚举;
   把它压成打分,等于让一个批评立场冒充自然法则。
3. **伏笔的"设计意图"**:哪些预告是作者的装置、哪些是读者的倒溯,
   意图不可观测;幕一的"设计"是细读共识,不是作者自述。
4. **标签该不该贴**:流行度与纯度可算,"配不配"是规范立场,
   不写进评分函数(01 章判读要点 3)。

**边界的一句话**:绿色区=时序+窗口+标签三引擎,覆盖"转译装置的
校准";红色区提醒:**转码是出版与研究的试算器,不是文学价值的
替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:时序结构走廊(叙事张力与重读收益分析)

```
一部小说的时序 ──代理化──▶ 悬念债表: (预告位, 应验位, 权重, 是否设计)
      │                            张力(x)=Σ未偿债; 识别: p1(公式)/p2(全图)
      └──线性 vs 马孔多式对照──▶ 重心/前半程份额/重读密度 ──▶ 重读机器断言
```

- **理论→模型**:预告开债、应验还债;公式预告首读只被标出,全图
  在手才被认全(03 章引擎 1)。
- **算法层**:债务表 O(债数×格点);40 单元×100 格点毫秒级(幕一);
  对照实验=同权重两种排布各算一遍。
- **本家族实现**:[`experiments/boom_time_labels.py`](experiments/boom_time_labels.py)
  幕一——断言重心 0.680→0.512、前半程份额 0.296→0.502、重读密度
  ×2.2 且为线性式 6.7 倍。
- **真实系统**:出版社的**重读型作品识别**(长销书的后验特征之一
  是结构伏笔密度,选题会可验);阅读平台的**重读推荐**(重读收益
  高的书值得在读完页推"再读一遍");写作教学的**开头工作坊**
  ("多年以后"公式的装配图教学)。
- **性能工程要点**:数据量级极小,价值全在**标注纪律**——悬念债
  的开/还位置标注必须双人细读复核;标注口径漂移比算法误差致命。

### 走廊 2:爆发窗口走廊(存量-管道-窗口递推)

```
世界可见度史 ──代理化──▶ 存量池+流入; 释放=min(存量, 容量(t))
      │                        容量=基线×注意力×发行爬坡; 可见度=释放×接力×饱和
      └──条件开关对照──▶ 窗口份额/峰值年/中位年 ──▶ 反事实断言(缺一环则推迟)
```

- **理论→模型**:内因是存量,外因是窗口;三环条件链(注意力事件/
  全球发行/翻译接力)各自外生,可单环拆除做反事实(03 章引擎 2)。
- **算法层**:逐年递推 O(年数);51 年微秒级(幕二);反事实=同
  随机流换条件开关重跑,差分即机制贡献。
- **本家族实现**:同实验幕二——断言窗口份额 69.2%(3.5× 均匀基线)、
  窗口释放=存量 2.0 倍、去接力峰值降至 32% 且峰值年推迟 17 年。
- **真实系统**:国际书市的**窗口监测**(某语种/某地区文学的世界
  热度:译本量与书评量的窗口份额读数,预警"爆发前夜"或"管道缺环");
  版权贸易的**条件链尽调**(买下一部"即将爆发"的语种文学,先查
  三环:注意力事件有无?发行线在谁手里?翻译接力起跑了吗);
  文学社会学的**反事实复盘**(少一环会怎样,幕二方法)。
- **性能工程要点**:模型极轻,价值全在**代理纪律**——"世界可见度"
  的取数口径(译本数/书评量/馆藏量)必须显式并全程一致;小语种
  数据缺失要按缺失机制处理,不能当零。

### 走廊 3:标签市场走廊(流行度-纯度模拟)

```
流派标签史 ──代理化──▶ L(t) 逻辑斯蒂; 贴标量=base(0.3+L);
      │                     纯度 p(t)=0.92(1−L)^1.1; 正典分 Beta 混合
      └──两市场对照──▶ 相关/分期读数+反标签采用率 ──▶ 船票与牢笼断言
```

- **理论→模型**:标签两期(筛子/货架)与两市场(旧建制/新读者)
  的偏好矩阵;反标签=换市场不换质量(03 章引擎 3)。
- **算法层**:逐年混合抽样 O(年×书);两市场作者群模拟 O(作者×期);
  幕三全程毫秒级;Beta 抽样用标准库 gammavariate 合成,无第三方依赖。
- **本家族实现**:同实验幕三——断言 corr(L, 中位正典分)=−0.957、
  概念/营销 3.3×、反标签新市场 2.0× 胜出/旧市场 0.36 失联/入典 21%。
- **真实系统**:营销部门的**标签生命周期管理**(品类词从概念期到
  货架期的库存策略:概念期贵精,营销期防串味);编辑的**贴标决策
  预演**(给新书贴热词标签的短期/长期期望要分市场算,合并算会互相
  抵消);文学批评的**标签审计**(某热词当前的流行度位置与纯度
  读数,书评版可用)。
- **性能工程要点**:抽样天然可并行(seed 分流可复现);真正贵的是
  **"正典线成员"的标注**——判定依赖批评史共识(术语史三跳每跳
  都有论争),网络的建设是数据工程,不是算法工程。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:重读型作品识别——伏笔密度先于销量

- 长销预测的输入排序:结构伏笔密度(时序卡读数)>十年在版史>
  当年榜单——幕一断言的工程版;版权与再版决策把"重读收益"写进
  评分项:能被读两遍的书才付得起长销的复利。

### 落点 2:国际书市窗口监测——三环条件仪表盘

- 给目标语种文学建三条曲线:注意力事件密度(大奖/大新闻)、发行
  线集中度(谁握全球发行)、翻译接力起跑率(译本年增);三环齐亮
  才是窗口打开(幕二),只亮一环就抢跑,大概率买在渗漏期。

### 落点 3:标签货架管理——两期两账分开记

- 品类词的健康度按两期读:概念期看纯度(贴标即认证的含金量),
  营销期看周转(贴标即陈列的效率);同一标签的两本账分开记,
  用概念期的荣誉为营销期的库存背书,是标签市场最常见的坏账。

### 落点 4:反事实尽调——"缺一环会怎样"的例行公事

- 任何依赖多条件的计划(发布窗口=事件+渠道+接力)跑一遍拆环
  对照:峰值降多少、推迟多少年(幕二方法);条件链的脆弱性写进
  决策备忘,而不是等到错过窗口再复盘。
