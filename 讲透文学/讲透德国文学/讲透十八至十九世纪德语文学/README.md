# 讲透十八至十九世纪德语文学 · 高峰怎么来——狂飙突进、古典主义、浪漫派与现实主义

> **定位句**:这支负责**高峰侧**:1750-1900 年德语文学怎么从政治分裂的边地走到欧洲
> 文学的首都——狂飙突进(《少年维特》1774)、魏玛古典主义与 Weltliteratur 铸词
> (1827)、浪漫派的民族灵魂工程(格林童话 1812;诺瓦利斯/霍夫曼)、迟到的现实主义
> (冯塔纳 1895)。与二十世纪支分工:**这支铸造范型,那边扛住断层**。
> GB/T 13745 75064 德国文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:莱辛《拉奥孔》(1766)抬批评入欧陆一线;狂飙突进(1770s,通说)以
  《维特》风行欧洲;歌德转向古典,《威廉·迈斯特的学习时代》(1795-96)立成长小说
  范型、《浮士德》(1808/1832)立最高峰;耶拿浪漫派(《雅典娜神殿》1798,通说)立
  纲领,格林童话(1812 起)铸民间为民族;冯塔纳《艾菲·布里斯特》(1895)登顶(均通说)。
- **因什么问题**:①分裂的德意志凭什么有世界文学(答:语言共同体先于国家)
  ②个人怎么在市民社会里成形(Bildung 核心问)③民族的灵魂在哪里找(浪漫派答:民间)。

## 核心问题

**已解决(通说)**:高峰期坐标明确(狂飙 1770s→古典 1787-1832→浪漫 1798-1830s→
现实主义 1850-1890);Weltliteratur 与 Bildung 的铸造现场可考(艾克曼谈话录/
威廉·迈斯特);格林"民间铸成民族"路径定型。
**未解决/深水区**:"黄金时刻"叙事是不是民族主义建构(家族 00 章争 1,通说+
反方双录);德国现实主义为何迟到且"狭隘"(通说命题再评价);浪漫派的政治后果(双录)。

## ✨ 这支最美的一个事实

**政治分裂期的文学共和国**:数百个宫廷各自养剧院,书商在莱比锡,评论在耶拿,
作家在魏玛——没有国家的德意志用文学给自己造了一个精神祖国,1827 年歌德由此
宣布"世界文学的时代快要来了"(通说)。幕一出-回旅行模型从这一站发车:这个词
后来改铸两次,回到德语时已非出发时的词。

## 假设与依赖

- 买入"语言共同体可解释归属":按语言不按国界(瑞士的凯勒/奥地利的施蒂弗特入族);
  代价:黄金时刻叙事的反题常在(双录);诗哲联姻的"思想税"在本支最重;尼采的
  哲学底账归哲学宇宙(文字提及)。
