## ② 核心思维模式(这个分支怎么想问题)

1. **语言共同体之眼**:德语文学按语言不按国界——卡夫卡(布拉格)/
   里尔克(布拉格)/耶利内克(奥地利)/赫塔·米勒(罗马尼亚)都在
   族内;判断归属先问"用什么语言写",再问"在哪国写"
2. **出-回旅行之眼**:学术概念出国要拆包重铸,回国已改姓(Weltliteratur
   出-回漂移 0.40=单程 2.6 倍);回流版靠英美中转声望在母语学界胜出
   ——出口的词回不了家,回来的词自带签证
3. **代距之眼**:断层题材作品先算作者隔断层几代——亲历代高密度窄频
   (幸存者叙事),沉默代塌陷,孙代反弹至亲历代九成且频段放宽;
   记忆不是衰减曲线,是隔代回声
4. **规范反噬之眼**:范型与经典化耦合(标准弧正典率高),但反范型
   的兴起是范型最强时期的延迟回声(滞后约两代)——范型越强,反范型
   越迟到也越狠;没有比成长失败更德国的成长
5. **诗哲分账**:文学与哲学联姻是德语文学的资产也是"思想税";判断
   一个论题先分账——文学侧的联姻事实归本家族,哲学本体归哲学宇宙
6. **断层双录**:零点有没有/国内流亡怎么评价/记忆到哪代为止,一律
   "通说+反方"双录不栽判;幕二给代际形状,不判史学案
7. **证据分账伦理**:涉断层文学,文本内证据与语境推断必须分开记;
   三张结构卡各有此栏

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 语言共同体判据 | 定任何德语书写者的族籍:先语言后国界;卡夫卡问题一招解 |
| 概念出-回旅行图 | 追任何学术概念的多语境版本:铸造→回炉→回流,每站记语境引力 |
| 声望瓮对照 | 判断"回流版胜出"类现象:换公平声望重跑,看是不是声望在起作用 |
| 代距计算器 | 定位断层题材作品:作者出生年对断层年代换算代际位置,再看密度与频段 |
| 主题谱系卡 | 量"谁在什么代际写什么":母题行×代际列+档案层+回声判定 |
| 翻译接受卡 | 量"词与书怎么出去又回来":中转站/关键词改铸/回流事件 |
| 时代断层卡 | 量"一场灾难怎么被四代接力书写":首代叙事/沉默段/回声段/象征权之争 |
| 弧符合度三段表 | 量成长叙事:出走-迷误-和解逐段打分;无和解段即反弧候选 |
| 规范-反噬时间轴 | 把反范型作品的兴起对齐范型峰值做延迟分析(滞后≈两代) |
| 论争双录卡 | 处理零点/诗哲联姻/黄金时刻叙事之争:两端各一行,裁决栏可空 |

## ④ 常见误区与禁忌

- **把卡夫卡当"外国作家"**:按语言不按国界——布拉格德语在族内;
  同理里尔克、耶利内克、迪伦马特
- **把"世界文学"当歌德原义使用**:中文课程名≈建制回流版(总量义),
  歌德义是"互照的对话"——两版相差 0.40 个余弦距离,合账必错
- **把"教育小说"只当"写成长的书"**:Bildungsroman 是规范弧(出走-
  迷误-和解);"教育"译名丢"构形"义,"成长"译名丢规范义
- **把 Doppelgänger 当"长得像的路人"**:它是第二个自我的致命显形
  (让·保罗铸词/霍夫曼现场),不是外貌梗
- **记忆衰减直觉**:看到"断层越来越远所以越写越少"的论断,先看幕二
  ——废墟代塌陷后孙代反弹,记忆是隔代回声
- **反范型=时髦**:看到反成长小说成批出现,先问范型峰值在几十年前
  ——反噬是延迟回声;把正典耦合写成评分函数会系统惩罚下一个铁皮鼓
- **替断层判案**:零点之争/国内流亡评价/记忆终点是"通说+反方"双录
  题;机器供曲线,不供判决书
- **概念词条合并**:多语境词("世界文学""教化")分版本立词条,合并
  即平均,平均即失真
