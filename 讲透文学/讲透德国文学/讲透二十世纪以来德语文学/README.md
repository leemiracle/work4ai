## 诞生

- **谁/何时**:《变形记》(1915)《杜伊诺哀歌》(1923)《魔山》(1924)立现代
  主义(通说);1933 夺权后作家流亡欧美,西格斯《第七个十字架》(1942)为代表
  (通说);1945 零点之争与 1952 伯尔《废墟文学自白》立战后书写,四七社立批评
  共同体(通说);《铁皮鼓》(1959)立反成长,格拉斯 2006 自传引爆"迟到坦白"
  之争(通说双录);《分裂的天空》(1963)写墙;耶利内克 2004/赫塔·米勒 2009 诺奖(通说)。
- **因什么问题**:①崩解的经验怎么写(现代主义)②罪责与幸存怎么写(零点与废墟)
  ③分裂与统一怎么写(两德)④记忆到哪一代为止(家庭小说与 Ostalgie)。

## 核心问题

**已解决(通说)**:三断层的文学坐标清楚(流亡/零点/墙);废墟文学与四七社的
建制事实;反成长小说的经典地位(铁皮鼓入典)。
**未解决/深水区**:零点有没有(双录);国内流亡的评价;"柏林共和国"有无新范型;Ostalgie 是续命还是耗尽(01 章主线 B);殖民断层启用(主线 A)。

## ✨ 这支最美的一个事实

**记忆是隔代回声,不是衰减曲线**(幕二实测):亲历代书写密度最高(0.43)但频段
最窄(幸存者叙事 3.32 种有效母题);废墟一代塌到 0.13(沉默的五十年代);孙代反弹
到 0.38——达亲历代 89%,频段放宽到 4.81;纯衰减模型预测的沉默代是实测 2.7 倍。
**家族秘密要到孙代才解码**——档案开放、父辈离世、距离给足;家庭小说第四波
(01 章主线 C)是这条曲线的现场。
