# 讲透德国文学 · 先有文学后有国家——语言共同体、概念出口与断层记忆

> **本质一句话**:德国文学=**先有文学、后有国家**的文学——政治统一(1871)
> 之前三个半世纪,路德圣经德语(1534)就统一了书面语,歌德时期
> (1787-1832)的"文学共和国"就给了说德语的人一个精神祖国;它因此
> 带着三个结构性胎记:**语言共同体先于国家共同体**(按语言不按国界:
> 奥地利/瑞士/布拉格的德语作家都在族内——卡夫卡不是"外国作家")、
> **诗与哲学联姻**(它是概念出口国:Weltliteratur/Bildung/Doppelgänger/
> Unheimlich 全是这里铸造的词)、**断层记忆**(1933/1945/1989 三次断层,
> 文学是民族的记忆机器);一句话:**德语文学按语言不按国界,出口概念,
> 收藏断层**。
>
> GB/T 13745-2009:750 文学 · 二级学科 **75064 德国文学**(GB/T 无三级明细 → 自定 2 支;薄家族纪律:00-04 章 150-250 行)。

## 一、家族定位

- **两支分工**:同一条语言共同体的两段——**十八至十九世纪支**(它怎么
  达到高峰:狂飙突进/古典主义/浪漫派/现实主义,"文学共和国"与世界文学
  口号的铸造期)与**二十世纪以来支**(它怎么扛住断层:现代主义/流亡
  文学/战后/两德/当代,记忆机器的运转期)。
- **一条主轴贯穿**:语言先建国(路德→歌德)→概念出口(Weltliteratur/
  Bildung/Doppelgänger/Unheimlich)→断层记忆(1933/1945/1989)。前段
  支守第一二程,后段支守第三程;家族实验把三段全部**算术化**(出-回
  旅行/孙子效应/弧规范)。
- **零门槛**:读过一册《少年维特之烦恼》或一篇卡夫卡就能进;术语随用
  随讲(三步法:直觉图像→严格陈述→最小例子)。不要求德语——全部用
  通行中译;要编年全景去[世界文学史](../讲透世界文学史/README.md),
  要跨语机制去[比较文学](../讲透比较文学/README.md)。
- 路线 A(问题派):卡夫卡凭什么算"德国文学"?→00 §一定位句;"世界
  文学"这个词怎么出去又回来的?→00 §七发现 1;德国人为什么写了
  一百年"怎么面对过去"?→发现 2
- 路线 B(课程派):00→[十八至十九世纪支](讲透十八至十九世纪德语文学/README.md)
  →[二十世纪以来支](讲透二十世纪以来德语文学/README.md)
- 路线 C(研究派):00→01(后殖民转向/记忆文学/国际市场三前线)→02
  (概念出口的语法)
- 工程师快轨:直接跑 [`experiments/themes_collapse_memory.py`](experiments/themes_collapse_memory.py),
  再回读 04 章
