# 04 · 德国文学转代码:把概念旅行、代际记忆与成长弧搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:德国文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**概念出-回**、**代际记忆**、
> **弧符合度**——把"出口的词回不了家""记忆是隔代回声""没有比
> 成长失败更德国的成长"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",德国文学转代码要解决"**语义代理化**":
把一段学科语言("世界文学这个词早变了味")先翻成模型(语义向量+
语境引力),再翻成代码。翻译的损耗全部发生在第一步——所以本章先划
清哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条
走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 概念出国改义 | 语义向量+语境引力+归一,余弦距离 | 实验幕一全程纯标准库 |
| 出口转内销 | 声望加权波利亚瓮(回流版 vs 本土版) | 幕一的采纳竞争+公平对照 |
| 代际书写强度 | 直接经验衰减+延迟解码叠加,四代曲线 | 幕二;密度与频段双输出 |
| 记忆是衰减还是回声 | 纯衰减拟合对照(预测沉默代) | 幕二的机制检查 |
| 成长弧规范 | 三段弧符合度+正典概率耦合 | 幕三;正差可断言 |
| 规范反噬 | 规范强度曲线与反弧份额的互相关滞后搜索 | 幕三;滞后 L* 自动检测 |
| 三张结构卡 | 定长字段记录+完整性断言(证据分账非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **诗哲联姻之深**:代码能量"弧符合度",量不了《魔山》的思想
   密度——联姻的"哲学那一半"本体在哲学宇宙(文字提及),文学侧
   的深度只能由通读见证(03 章右端)。
2. **断层的伦理重量**:幕二给得出代际密度,密度不是价值;"记忆该
   到哪一代为止"是规范问题,写进评分函数等于让一个时代的记忆政治
   冒充自然法则。
3. **零点之争的史学判决**:断裂说 vs 延续说是史学本体(历史学宇宙,
   文字提及);机器只供两条曲线,不供判决书。
4. **语境引力与声望参数**:幕一的引力向量与声望权重是**骨架假设**
   ——按学科史重估会移动漂移数值(✍️练习 1);转码者必须把它们
   写在显式假设栏。

**边界的一句话**:绿色区=旅行+记忆+规范三引擎,覆盖"学科直觉的
校准";红色区提醒:**转码是概念史与记忆研究的试算器,不是德语文学
的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:概念出-回走廊(术语库的版本管理)

```
概念出国 ──代理化──▶ v←normalize(v+0.55·g_语境+0.10·noise),逐程迭代
      │                          │
      └──回流──▶ 声望瓮:回流版 vs 本土版采纳竞争 ──▶ 漂移/胜率双读数
```

- **理论→模型**:02 章"概念出口的语法"的三规律参数化(拆包=引力,
  回炉=向量改铸,不可译=引力近零的音译区);回流竞争=英美中转
  声望加权的波利亚瓮。
- **算法层**:每程 O(维度);蒙特卡洛 N=4000 学者采纳 O(N);全程
  秒级(实验幕一)。
- **本家族实现**:[`experiments/themes_collapse_memory.py`](experiments/themes_collapse_memory.py)
  幕一——断言累积漂移>2×单程、末程漂移>0.30、回流版胜率>0.55
  且公平对照≈对半(机制检查:是声望不是瓮)。
- **真实系统**:术语库/知识本体的**概念版本管理**(一个词条按语境
  分版本,不合并——"世界文学(歌德义)"与"世界文学(建制义)"
  分立词条);翻译记忆库的**改铸登记**(译名变更即新版本);数字
  人文的**概念旅行图谱**(概念-语境二部图)。
- **性能工程要点**:语义向量维度小(6-16),算力全在**语境引力的
  数据工程**(每个学科语境的引力向量要文献学论证)——与模型家族
  同一条铁律:底表不标准,输出只是自洽的伪精确。

### 走廊 2:代际记忆走廊(记忆书单的代际标注)

```
断层记忆 ──代理化──▶ 密度(g)=A·exp(-g/0.8)+B·f(g;τ)   [直接+传递]
      │                            │
      └──仿真──▶ 四代×N 部作品主题抽样 ──▶ 密度曲线+频段宽度 ──▶ 回声判定
```

- **理论→模型**:直接经验衰减+家族秘密延迟解码(03 章引擎 2);
  频段用主题分布的有效种数 exp(H) 度量;纯衰减拟合作机制对照。
- **算法层**:每代 O(N) 伯努利+类别抽样,N=260 秒级;对照拟合 O(1)。
- **本家族实现**:同实验幕二——断言亲历代密度最高且频段最窄、
  废墟代塌陷、孙代反弹(>父代,≥0.8×亲代)、纯衰减预测沉默代
  ≥1.8×实测。
- **真实系统**:书单与课程的**代际标注**(一部断层题材作品除年代
  外标注"作者隔断层几代"——幕二的读者版);出版选题的**回声窗口
  判断**(哪一代正在解码,哪类题材将起);记忆机构的**口述史采集
  时序规划(趁哪一代还在)**。
- **性能工程要点**:数据量级小,价值在**代际户口的口径纪律**——
  "隔断层几代"必须按作者出生年对断层年代算,不许按"写作时年龄"
  或"登场年代"混算;口径一混,回声峰是伪影。

### 走廊 3:弧符合度走廊(成长弧检测与规范诊断)

```
成长小说规范 ──代理化──▶ 正典概率=base+γ·c·norm(t);反弧份额=0.06+κ·norm(t-L)
      │                                │
      └──检测──▶ 作品层正差 + 时代层互相关滞后搜索 L* ──▶ 规范反噬读数
```

- **理论→模型**:三段弧(出走-迷误-和解)符合度 c 与经典化耦合
  (03 章引擎 3);norm(t) 按文学史通说校形(1810 年代峰值)。
- **算法层**:作品层 O(N) 伯努利;滞后搜索 O(候选滞后数×年数),
  全程毫秒级(实验幕三)。
- **本家族实现**:同实验幕三——断言标准弧正典率>1.6×残弧、
  L*∈[40,80] 且相关显著压过 L=0、反弧峰晚于规范峰 40 年以上、
  1945 后反弧均值>3×1850 前。
- **真实系统**:写作工具的**弧诊断器**(输入三段各一句话,输出
  弧符合度与"反弧倾向"提示——不当裁判,当镜子);经典化研究的
  **规范-反噬时间轴**(把反范型作品的兴起对齐范型峰值做延迟分析);
  数字人文的**体裁史量化**(弧型份额的年代扫描)。
- **性能工程要点**:滞后搜索对**时间步长敏感**(步长 5 年,断言带
  ±10 年容差);步长改 10 年时 L* 的分辨率同倍变粗——先声明步长,
  再谈滞后。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:术语库的出-回治理——分版本不合并

- 多语境词("世界文学""教化")一律**分版本立词条**:铸造义(歌德
  1827)、回炉义(1848 政治经济学)、回流义(学院建制)各一条,互
  链不互替;幕一的漂移读数(0.43)写在词条头作版本差警示——合并
  词条等于把三个语境引力平均掉,平均即失真。

### 落点 2:书单与课程的代际标注

- 断层题材书目除"出版年"外加一栏**"作者-断层代距"**(出生年与
  断层年代之差换算的代际位置);幕二说密度与频段都挂在这一栏上,
  缺栏的书单无法回答"谁在记"——而谁在记决定记什么(窄频或宽频)。

### 落点 3:弧诊断器当镜子不当裁判

- 写作辅助只输出**符合度与反弧倾向的描述**(三段完整性、和解缺失
  提示),不给"好/坏"分——幕三证明合弧者正典率高,但反弧是规范
  的延迟回声,不是失败;把正典耦合写成评分函数会系统惩罚下一个
  铁皮鼓。

### 落点 4:概念史图谱的工程口径

- 建概念-语境二部图时,边权=语境引力(文献学论证后填),节点=
  概念版本(落点 1);**禁止从共现统计直接推引力**——共现是相关,
  引力是因果代理,两个量在图谱里必须分列。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:版本之眼**——看到任何学科概念,先问它有几个
语境版本(铸造/回炉/回流),版本合并处就是失真处;**代距之眼**:
看到任何断层题材作品,先算作者隔断层几代——代距比年代更能预测
它写什么;**反噬之眼**:看到反范型作品成批出现,先问范型峰值在
几十年前——反噬是延迟回声,不是时髦。
