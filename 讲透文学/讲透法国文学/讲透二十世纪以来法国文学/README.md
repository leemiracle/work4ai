# 讲透二十世纪以来法国文学 · 立法机器怎么提速与失灵——追忆、介入、约束与去中心

> **定位句**:这支负责**二十世纪以来侧**:"自我立法"传统怎么提速与失灵——普鲁斯特让时间退出立法辖区(《追忆》)、存在主义立"介入"纲领(萨特/加缪,理论加冕的黄金时代)、新小说与乌力波把立法推到极端(怀疑的时代/约束生诗)、当代在三次诺奖与非洲法语写作中去中心(勒克莱齐奥/莫迪亚诺/埃诺/姆布加尔·萨尔)。与古典支分工:**那边立规矩,这支试极限**——立法极端化到变成数学,就到了这边。
> GB/T 13745 75061 法国文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:普鲁斯特《追忆似水年华》1913-1927(七卷,通说)把叙事从"讲故事"转向"追意识";萨特《恶心》1938 与《什么是文学?》1948 立介入纲领,加缪《局外人》《西西弗神话》1942 铸"荒诞"(通说);萨洛特《怀疑的时代》1950 与罗伯-格里耶 1956 檄文立新小说,1960 凯诺创乌力波,佩雷克《人生拼图版》1978(均通说);2008/2014/2022 三诺奖与 2021 龚古尔的去中心(通说)。
- **因什么问题**:①叙事的立法权还在不在②写作是不是行动③小说还能不能立规矩④当立法变成数学,文学剩什么⑤巴黎还发不发证书。

## 核心问题

**已解决(通说)**:介入纲领的文本与刊物建制(《现代》杂志,通说)坐标清晰;新小说与乌力波的檄文-作品对应可查;"荒诞"概念的铸造史(加缪-萨特之辩,通说)有标准叙述。

**未解决/深水区**:理论退潮后谁加冕(家族 01 章主线 C;幕二替代律是观测框架);差异化默契的时变性(媒体化与分榜是否侵蚀级联);"法语文学"的边界(francophone 命名之争,无判决)。

## ✨ 这支最美的一个事实

**当立法极端化,它变成了数学**:乌力波不立派规,立**生成约束**——佩雷克《人生拼图版》(1978,通说)表面是一栋公寓楼的横断面叙事,底层垫着以移动规则遍历楼层的写作约束(通说口径);约束越严,自由越显。为什么美:**四百年的"为文学立法"到此登峰造极——立法不再约束写作,而直接生成写作**;宣言脉冲(幕一)在这里的读数最短促也最纯粹:立法与创作合一,解散令无从谈起,因为约束不靠凝聚力,靠组合数学。亲历:任选一章数"房间-人物-物件"三元组,再想:这排列有几组自由?

## 假设与依赖

- 买入"建制行为可代理文学地位":加冕(理论/奖项)被当作正典化的观测面;作家作品评述一律通说口径,争议双录
- 代价:文本内部价值(文学性)不入账(家族 03 章右端);默契与共振参数为风格化构造,反演依赖标注工程(家族 04 章走廊 2/3)
