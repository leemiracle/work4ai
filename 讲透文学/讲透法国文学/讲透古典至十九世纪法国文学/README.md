# 讲透古典至十九世纪法国文学 · 立法机器怎么建成——七星诗社、古典主义、启蒙与小说黄金期

> **定位句**:这支负责**古典至十九世纪侧**:"自我立法"传统怎么从零建成——七星诗社为法语争文学权(1549)、古典主义把立法做成建制(学术院/三一律/《诗的艺术》)、启蒙让创作与批评同体(百科全书)、小说黄金期把宣言-作品-理论三件套定型(《人间喜剧》总纲-《实验小说论》-象征主义宣言)。与二十世纪支分工:**这支立规矩,那边试极限**——互为证词。
> GB/T 13745 75061 法国文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:1549 杜·贝莱《法语防御与阐明》立语言之法;1635 学术院-1636《熙德》三一律之争-1674《诗的艺术》立剧场之法;1721《波斯人信札》-1751-72《百科全书》立创作-批评同体;1842《人间喜剧》总纲-1880《实验小说论》-1886 象征主义宣言,三件套定型;前史《罗兰之歌》(约 11 世纪末)与克雷蒂安骑士故事立口传-书面接口(均通说)。
- **因什么问题**:①一门"庶出"的语言凭什么有文学②戏剧要不要服从规则③文学能不能当思想的武器④小说能不能立科学般的总纲。

## 核心问题

**已解决(通说)**:四代法典谱系完整(语言法-剧场法-思想法-小说法,各有原典);论争坐标清晰;《人间喜剧》人物再登场被公认为小说史的建制发明。

**未解决/深水区**:法典与杰作的落差怎么记(莫里哀式"违规杰作"的入账);浪漫主义与古典主义的断裂是否被夸大(通说有"延续论"一支);象征主义起点算 1857《恶之花》还是 1886 宣言(通说双录)。

## ✨ 这支最美的一个事实

**巴尔扎克用人物再登场把百部小说焊成一部"社会的自然史"**:《人间喜剧》1842 年总纲(通说)立起两千余人物、数百人物跨作品再登场的建制——同一个人物在别人故事的背景里走过,小说从"一部"变成"一个世界"。为什么美:**总集不是多写几本,是发明了文学宇宙的焊接术**——后来的系列叙事(从卢贡家族到当代类型宇宙)都在用这项专利。幕一宣言脉冲管它的开局(1842 总纲即宣言),这条美管它的建制原创。

## 假设与依赖

- 买入"立法文本能驱动文学建制":宣言与法典被视为第一推动;兑现对账(家族 03 章卡 1)用于检查过度承诺
- 代价:无总宣言的运动(启蒙)要找代理立法文本;法典的弹性(演出实践对三一律的变通)被压缩;作家作品评述一律通说口径
