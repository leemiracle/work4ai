# 03 · 可构造与结构:哪些法国文学对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:法国文学的对象沿一条**可构造谱系**排开——左端
> **严格可构造**(宣言脉冲序列、作家-理论家二部网络、奖项级联概率:
> 写得下、算得动、能过 assert),右端**几乎不可构造**(文学性判断、
> "法国性"、宣言的真诚度:只有思想操作化);全谱系共享三条**结构
> 引擎**:**宣言脉冲引擎**(运动的兴衰)、**加冕双通道引擎**(理论与
> 奖项的可替代性)、**级联场域引擎**(评审默契与脉冲折旧);而一个
> 流派、一对共生、一场评奖可以压进三张**结构卡**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
宣言脉冲 ── 二部网络 ── 级联概率 ── 宣言卡 ── 共生卡 ── 场域卡 ── 正典重估 ── 文学性
  │                                                                            │
严格可构造(可断言)                                              几乎不可构造(只有思想操作化)
  └── 写得出、采得出、算得动、能过 assert         └── 只能在阅读与批评里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义**:宣言
脉冲的语义是"振幅×时标×叠加律"(输入输出明确);而"这部作品有
法国性"的判断要求**给出立法传统与文本风格的联读证据**——证据的
给出无法程序化(02 章"操作化通道"的总纲)。本章先盘家底,再看
三条结构引擎,最后把流派、共生、评奖压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **宣言脉冲序列** | 宣言年表+脉冲核叠加(幕一) | 低 | 参数为风格化;宣言的"效力"只能用凝聚力代理 |
| **作家-理论家二部网络** | 共现关系+度分布+正典化回归(幕二) | 低 | 链接(谁分析过谁)要人工标注;共生≠因果 |
| **奖项级联概率** | 序列模型+默契参数+位次脉冲(幕三) | 低 | 默契强度 P_obey 不可直接观测,只能反演 |
| **流派宣言卡** | 六字段填空+兑现对账 | 中(半构造:兑现评估带解读) | 宣言与作品的对应依赖批评共识 |
| **作家-理论共生卡** | 双栏资本流向记账 | 中 | "概念资本"的计价是隐喻不是账目 |
| **奖项场域卡** | 位次×默契×脉冲三栏 | 中 | 销量数据的口径(首印/加印/长销)不统一 |
| **正典重估** | 选本史/教材史/译本史材料 | 高 | 与世界文学史家族的"经典层积"分工(那边管作品层积,本家族管作家加冕通道) |
| **文学性/"法国性"** | 只有思想操作化 | **不可构造** | 风格的"在场"无法枚举为特征 |

**反直觉发现(本章铁律)**:**宣言的声量与可构造性不成正比是常态**。
史上最响的宣言(超现实主义)其文本效力恰恰最不可算(靠凝聚力代理),
最能跑的对象(脉冲/网络/级联)全是**建制行为**而非文本内部对象。
**右端管洞察,左端管校准**;拿右端对象硬造左端指标(给"法国性"
打个分)是本学科量化失真的头号来源——两头都不是。

## 二、结构引擎 1:宣言脉冲引擎(运动兴衰的算术骨架)

**直觉图像**:宣言是运动的起跑枪;脉冲响应叠加出生-峰-衰退的曲线。

- **数学化身**:宣言 i 的凝聚力脉冲 I(s)=A_i·(s/τ)·exp(1−s/τ),
  s=距宣言年数,峰值在 s=τ;宣言越多,时标压缩 τ=τ0/(1+0.85(k−1)),
  后续振幅按 0.45^i 递减(再宣言=分裂信号)。
- **三个可断言形状**(实验幕一):每条凝聚力曲线 S+衰退(峰值年
  3-7,高原期 4-7 年,后 1/3 跌破峰值 35%);寿命分组均值
  20.0→14.5→12.0 随宣言数严格递减;r=−0.94——**宣言是运动的
  起跑枪也是解散令**。
- **理论地位**:这是"流派自觉立法"传统(00 §一)的算术版——立法
  文本的效力以运动凝聚力为代理;宣言史因此不是思想史,是**脉冲史**。
- **刚性从哪来**:形状五检查(升/峰位/高原/不可逆衰退/缓衰)是核
  函数给的;软的地方在**参数**——振幅与时标按流派重估,锚形状不锚
  数值。

## 三、结构引擎 2:加冕双通道引擎(正典化的可替代路径)

**直觉图像**:作家进正典有两条铁路——理论加冕(讲台/选本/概念化)
与奖项加冕(晚宴/书单/橱窗),可替代、可共振。

- **数学化身**:二部网络+优先连接(概念资本的马太集中);正典化
  P=σ(−2.8+2.0q+2.4C+1.6奖)——质量、理论资本 C、奖项三输入。
- **三个可断言形状**(实验幕二):同连顶级理论家的作家对共同正典率
  0.497 vs 0.203(**共振 2.45 倍**,经典簇);无理论正典作家获奖率
  0.613 vs 有理论 0.412(**补票上车**);纯理论无奖正典率 0.571 vs
  纯天赋 0.144(**4.0 倍**)。
- **理论地位**:这是"理论家的文学"(轴线 2)与场域论(轴线 3)的
  合成算术版——理论家不是文学的仆人,是**加冕通道的运营商**。
- **刚性从哪来**:可替代性(两通道系数可换)与共振(共连者共运)是
  网络结构给的;软的地方在**链接标注**——谁算"理论中介"依赖
  批评史共识。

## 四、结构引擎 3:级联场域引擎(评审默契与脉冲折旧)

**直觉图像**:十月-十一月的大奖像接力发令:首奖定风向,后奖做
差异化,书店橱窗按位次折旧。

- **数学化身**:五大奖位次 1-5;后续评审以 P_obey=0.97 只在未获奖
  书中选(差异化默契),3% 破例;销量脉冲 P0·ρ^(位次−1)。
- **三个可断言形状**(实验幕三):龚古尔得主同年再获后续大奖年份率
  0.03 vs 独立基线 0.88(**默契是准绳不是法律**);任一重复率 0.03
  vs 1.00;脉冲份额 0.593/0.242/0.103/0.044/0.018,头两位 83.4%、
  位次 1 为位次 3 的 5.8 倍(**几何折旧**)。
- **理论地位**:这是布尔迪厄场域论(轴线 3)的奖项截面——场域的
  立法不在法典里,在**评审团的相互位置**里。
- **刚性从哪来**:趋避与折旧是序列结构给的;软的地方在**默契的
  时变性**——媒体化与分榜可能改写 P_obey 与 ρ(01 章主线 A 的
  观察窗)。

## 五、结构卡 schema:把流派、共生、评奖钉进三张卡

**先答为什么**:文学史评估的难点在"评估者身处场内"——批评家自己
就是加冕机器的一部分。结构卡是**有限字段的压缩格式**:字段固定、
填空即可复用、可比可查可补;每张卡都带"兑现/证据"栏,强迫评估者
区分**纲领承诺**与**建制事实**。

### 卡 1:流派宣言卡(把一个流派钉进脉冲坐标系)

```
【流派宣言卡】
流派:________  宣言年:____  宣言人:________
立法对象(为语言/剧场/小说/无意识/……立法):________
纲领承诺(形式规范,可数者列条):________
兑现对账(代表作逐条对承诺:兑现/变形/落空):________
再宣言记录(次数+年份):________
解散信号(宣言者退出/另立/运动改名):________
凝聚力读数(建派→峰值→消散,约年数):________
```

样例(已填,象征主义,通说口径):宣言年 1886,宣言人莫雷亚斯;
立法对象=诗歌语言(以暗示代直陈);纲领承诺="给象征主义命名并立
三原则式诗法";兑现对账=马拉美一系的纯诗实践大体兑现,维尔哈伦
等外围变形;再宣言记录=1891(莫雷亚斯另立"罗马派"——**宣言者
亲手拆牌**);解散读数≈15 年(实验幕一的 k=2 组)。**读卡法**:
"再宣言+宣言者退出"两项同时亮红,即幕一断言的"解散令"现场。

### 卡 2:作家-理论共生卡(把一对共生钉进双通道)

```
【作家-理论共生卡】
作家:________  理论家:________  相遇文本(评论/选目):________
概念资本流向(理论家给了作家什么概念):________
分析对象回馈(作家给了理论家什么案例):________
加冕后果(作家正典化路径:理论线/奖项线/双线):________
共生强度(单次评论/长期选编/学派建制):________
拆伙风险(理论转向后作家是否被重估):________
```

样例(已填,巴特×巴尔扎克,通说口径):相遇文本=《S/Z》(1970,
把《萨拉辛》切为 561 个阅读单位);概念资本=可读/可写文本、读者
之诞;分析对象回馈=巴尔扎克在结构主义时代的高光案例;加冕后果=
理论线再正典化(现实主义总集被理论话语重新激活);共生强度=学派
建制级;拆伙风险=理论退潮后案例降温(01 章主线 C 的样本)。**读卡法**:
概念资本与回馈**双向非空**才是共生;单向的只是书评。

### 卡 3:奖项场域卡(把一场评奖钉进级联)

```
【奖项场域卡】
年份:____  奖项与位次:________  得主:________
位次语境(此前已颁出的奖与书):________
默契读数(得主是否已获同年前奖/落选热门):________
销量脉冲(获奖前后销量倍数,量级即可):________
出版社与场域位置(大社/独立社/外国社):________
正典化延迟(进教材/选本/译本用了几年):________
```

样例(已填,2021 龚古尔,通说口径):得主=姆布加尔·萨尔《最秘密
的记忆》(位次 1);位次语境=级联首棒,当年风标由它定;默契读数=
首奖无前奖冲突;销量脉冲=龚古尔量级效应(数十万册量级,通说);
场域位置=非洲法语背景作家经法国出版体系加冕(去中心样本);正典化
延迟=待观测(01 章主线 B 的跟踪对象)。**读卡法**:位次与场域
位置两栏联读——**首棒+边缘籍贯**就是"机器不动、领奖人在换"的
档案(00 章美之时刻 4 的卡片版)。

**判定流程**(把一个文学史主张钉到谱系上):

```
该主张的核心对象能写成脉冲、网络或级联吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(填空带解释)─────▶ 中段:卡片化+文献校,禁止硬算
  └─ 不能(文学性/法国性)────▶ 右端:思想操作化+批评写作,禁止压成参数
```

## 六、谱系×引擎×两支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| [古典至十九世纪](讲透古典至十九世纪法国文学/README.md) | 左端(宣言年表)经中段(宣言卡)到右端(法典美学) | 脉冲引擎的**史料侧**(宣言与法典文本)+共生引擎的**古典侧**(学院-选本传统) | 分裂:年表可算,法典弹性不可 |
| [二十世纪以来](讲透二十世纪以来法国文学/README.md) | 左端(网络/级联)到中段(共生卡/场域卡) | 双通道引擎全境+级联引擎的**当代侧** | 高(共生与级联是日常工具) |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——宣言
年表与级联走计算,三张卡走填空文献校,文学性与法国性永远走批评
写作。**没有哪个支全家可构造,也没有哪个支全家不可构造**——这门
学科的诚实,就在把这条谱系画清楚。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——身在加冕机器里的人,先给自己立规矩**(极简)
宣言卡量"开局"(立什么法,兑现几何),共生卡量"通道"(谁替谁
说话,资本怎么对流),场域卡量"收场"(哪一棒,什么位置)。为什么美:
**三张卡恰好把"立法-创作-加冕"回廊各钉一段**;每张卡强制一栏
"兑现/证据"——把纲领的许诺与建制的事实分账,是文学史批评的第一
伦理。亲历:给你最熟的流派/作家/评奖各填一张卡(✍️练习 1),最先
填不下去的格子,就是你的谱系位置。
