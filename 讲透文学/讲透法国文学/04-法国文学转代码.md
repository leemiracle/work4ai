# 04 · 法国文学转代码:把宣言、加冕与级联搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:法国文学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**宣言脉冲拟合**、**加冕网络
> 建模**、**级联默契仿真**——把"宣言是起跑枪也是解散令""理论加冕
> 与奖项加冕双通道""法国文学奖是十一月的天气预报"变成可跑、可
> 断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",法国文学转代码要解决"**代理化**":
把一段文坛语言("这个流派散了")先翻成模型(凝聚力脉冲+阈值),
再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清哪些对象
第一步就走得通(绿色区),哪些走不通(红色区),再给三条走通了的
走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 文学史概念 | 代码化身 | 备注 |
|-----------|---------|------|
| 流派兴衰/运动生命周期 | 宣言脉冲叠加+平滑+阈值检测 | 实验幕一全程纯标准库 |
| 多宣言=分裂信号 | 时标压缩系数 K_SPLIT 的敏感性扫描 | 幕一练习 4 的参数化 |
| 理论加冕/奖项加冕 | 二部网络+优先连接+logistic 正典化 | 幕二;共振/替代两断言 |
| 经典簇识别 | top-2 理论家邻域的共正典率 | 幕二 2a |
| 评审趋避/差异化默契 | 序列评奖模型+P_obey 反演 | 幕三 3a |
| 销量脉冲/位次折旧 | P0·ρ^(pos−1)+噪声;ρ 反演 | 幕三 3b |
| 三张结构卡 | 定长字段记录+完整性断言(兑现/证据栏非空) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **文学性**:代码能算凝聚力,算不出《包法利夫人》好不好——
   风格判断只能由阅读见证(03 章右端)。
2. **"法国性"**:立法传统的风格气质不可枚举;把它压成打分,等于
   让一个批评立场冒充自然法则。
3. **宣言的真诚度**:再宣言是分裂信号(幕一)是**统计断言**,不是
   对宣言人动机的判定——动机不可观测。
4. **默契的伦理读数**:差异化默契可反演其强度,但"默契好不好"
   (评审独立 vs 文学生态共谋)是规范立场,不写进评分函数。

**边界的一句话**:绿色区=脉冲+网络+级联三引擎,覆盖"建制行为的
校准";红色区提醒:**转码是出版与研究的试算器,不是文学价值的
替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:宣言脉冲走廊(流派生命周期拟合)

```
流派宣言史 ──代理化──▶ I(s)=A·(s/τ)·e^(1−s/τ), τ=τ0/(1+0.85(k−1))
      │                                │
      └──叠加+平滑──▶ 凝聚力曲线 ──▶ 峰位/高原/寿命检测 ──▶ S+衰退五检查
```

- **理论→模型**:宣言效力以运动凝聚力为代理(03 章引擎 1);再宣言
  =时标压缩+振幅衰减(分裂信号)。
- **算法层**:每运动 O(窗口×宣言数);五检查(升/峰位≤窗口 1/4/
  高原≤8 年/后 1/3<35% 峰值/半衰>半升)全是线性扫描,毫秒级
  (幕一全程)。
- **本家族实现**:[`experiments/manifesto_field_cascade.py`](experiments/manifesto_field_cascade.py)
  幕一——断言五运动形状全过、寿命分组均值 20.0→14.5→12.0、
  r=−0.94。
- **真实系统**:文化研究的**流派年表仪表盘**(宣言-建刊-解散事件
  的时间结构);出版选题会的**"宣言策略"代价表**(以 manifesto
  marketing 开局的新品牌/新丛书,按脉冲模型预读其凝聚曲线);
  数字人文的**宣言语料标注**(类型/立法对象/承诺条目)。
- **性能工程要点**:数据量级极小(百年几十条),价值全在**代理纪律**
  ——"凝聚力"的取数口径(成员发表同派作品的比例/刊物存续/再宣言
  次数)必须显式声明;代理换了,参数全换。

### 走廊 2:加冕双通道走廊(正典化网络建模)

```
作家-理论家共生 ──代理化──▶ 二部网络(优先连接)+正典化 logistic
      │                                    │
      └──蒙特卡洛(4000 场)──▶ 共振比/替代律读数 ──▶ 通道权重反演
```

- **理论→模型**:概念资本随理论家度数集中(马太);正典化三输入
  (质量/理论资本/奖项,系数显式为骨架假设)。
- **算法层**:每场 O(作家×理论家+邻域对);4000 场蒙特卡洛秒级
  (幕二);pairwise 共正典率 O(对数)。
- **本家族实现**:同实验幕二——断言共振 2.45×、奖项依赖差 0.20、
  纯理论/纯天赋 4.0×。
- **真实系统**:科研计量与出版研究的**选本/教材收录审计**(理论线
  与奖项线的权重随年代怎么变);文学史数据库的**共生边标注**;
  策划编辑的**通道体检**(这位作家走哪条线进正典,线通不通)。
- **性能工程要点**:蒙特卡洛天然可并行(场分流 seed 可复现);
  真正贵的是**标注工程**(谁在何时以何文本"中介"了谁)——网络
  的边是数据工程,不是算法工程;边不干净,度数只是自洽的伪精确。

### 走廊 3:级联场域走廊(评奖默契与脉冲仿真)

```
十月-十一月大奖季 ──代理化──▶ 五位次序列;后续评审 P_obey 只选未获奖书
      │                                        │
      └──32 个秋季仿真 ──▶ 趋避率 vs 独立基线 ──▶ ρ 反演 ──▶ 印量决策
```

- **理论→模型**:差异化默契为软排斥(03 章引擎 3);销量脉冲几何
  折旧(P0、ρ 为构造量级,按实际数据重估)。
- **算法层**:每年 O(奖数×候选);32 年仿真毫秒级(幕三);反演
  ρ=位次 k 与 k+1 脉冲比的对数均值。
- **本家族实现**:同实验幕三——断言顶级对撞车 0.03 vs 0.88、头两位
  份额 83.4%、位次 1/位次 3=5.8×。
- **真实系统**:出版社的**评奖季印量决策**(首奖出、二奖未出时的
  加印窗口——级联位次就是天气预报的等压线);媒体书评的**位次
  折旧意识**(后位奖的书评量与位次份额对齐,不追平首奖待遇);
  奖项研究的**默契监测**(P_obey 逐年反演,看差异化默契是否被
  媒体化侵蚀——01 章主线 A 的观察窗)。
- **性能工程要点**:模型极轻,价值全在**口径纪律**——销量数据
  (首印/实销/长销)与"重复获奖"的奖种范围(五大秋季奖?含学院
  奖?)必须先冻结再比较;口径漂移比模型误差更致命。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:评奖季的加印决策——位次即预报

- 首奖(位次 1)揭晓即触发最大脉冲窗口;二奖揭晓前是**次级脉冲的
  期权窗口**——按 ρ 折旧模型,位次 2 的预期脉冲≈位次 1 的四成
  (幕三 0.242/0.593);对"首奖落选热门"的书提前备货,是级联结构
  的标准操作(差异化默契保证它大概率拿后位奖)。

### 落点 2:正典化监测——双通道仪表盘

- 给目标作家群建"通道体检":理论线(被批评文献/选本/课程收编的
  时点)与奖项线(获奖-加印-长销曲线)分账;替代律读数(无理论组
  的获奖依赖差)逐年更新——理论退潮若真在发生,这一读数将系统性
  上移(幕二断言的工程版)。

### 落点 3:宣言策略的代价表——营销宣言的预读

- 新品牌/新丛书若以宣言式营销开局(联名檄文/流派标签),按幕一
  模型预读:再宣言次数越多,时标越短;**把"二次宣言"从荣誉改成
  风险项**——每发一次新宣言,先算一次凝聚力时标的压缩量
  (K_SPLIT 的敏感性扫描即此用途)。

### 落点 4:选本与教材的加冕审计

- 任何选本/课程大纲上线前跑一次通道审计:收录作家的理论线/奖项线
  两条通道占用率各多少?若无理论中介又无奖项的作家占比过高,
  要么是发现了被埋没者(价值),要么是选目口径漂移(风险)——
  审计结果写进编选说明。

## ✍️ 练习

   A(1−e^(−s/τ))·e^(−s/τ2),重跑幕一,看哪些形状检查失守——
   "核函数决定生命周期"的敏感性实验
2. 🐍 给走廊 2 改通道系数:把 BC=2.4 改成 1.2(理论资本减半),重跑
   幕二,看共振比与替代律读数怎么变——"理论退潮"的参数化预演
3. ✋ 用落点 1 写一页决策备忘:位次 1 揭晓后 24 小时内,加印、书评、
   橱窗三个动作各自的级联依据是什么
