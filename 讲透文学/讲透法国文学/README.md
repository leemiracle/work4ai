# 讲透法国文学 · 自我立法的文学——宣言开局、双通道加冕与奖项场域

> **本质一句话**:法国文学=**自我立法的文学**——从七星诗社为法语立
> 法、古典主义为戏剧立三一律,到超现实主义为无意识立法、新小说为
> 小说立法,流派习惯**以宣言开局**;而作家进入正典有**两条加冕通道**:
> 理论加冕(萨特/巴特一系的作家-理论家共生)与奖项加冕(龚古尔一系的
> 十月-十一月 cascade);一句话:**流派以宣言开局,正典以加冕收场——
> 法国文学的一切机关,都在"立法-创作-加冕"的回廊里**。
>

## 一、家族定位

- **两支分工**:同一条立法-创作-加冕回廊的上下游——**古典至十九世纪支**
  (立法传统的奠基:七星诗社/古典主义/启蒙/小说黄金期/象征主义)与
  **二十世纪以来支**(立法传统的极限与变奏:普鲁斯特/存在主义/新小说
  与乌力波/当代)。
- **一条主轴贯穿**:立法(宣言与规范)→创作(作品)→加冕(理论/奖项)。
  前支守"立法机器怎么建成",后支守"立法机器怎么提速与失灵";家族
  实验把三段全部**算术化**(宣言脉冲/加冕双通道/奖项级联)。
- **零门槛**:读过一本《局外人》或看过《悲惨世界》音乐剧就能进;
  术语随用随讲(三步法:直觉图像→严格陈述→最小例子)。不要求法语;
  要编年全景去[世界文学史](../讲透世界文学史/README.md),
  要跨语旅行去[比较文学](../讲透比较文学/README.md)。
- 路线 A(问题派):为什么法国流派都爱发宣言?→00 §七发现 1;
  萨特和龚古尔谁说了算?→发现 2;十一月的法国书店在等什么?→发现 3
- 路线 B(课程派):00→[古典至十九世纪支](讲透古典至十九世纪法国文学/README.md)
  →[二十世纪以来支](讲透二十世纪以来法国文学/README.md)
- 路线 C(研究派):00→01(龚古尔变革/去中心/理论退潮三前线)→02(加冕话语)
- 工程师快轨:直接跑 [`experiments/manifesto_field_cascade.py`](experiments/manifesto_field_cascade.py),
  再回读 04 章
