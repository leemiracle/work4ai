# 04 · 中国各体文学转代码:把体裁的坐标搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:各体文学的谱系左端(03 章)几乎可以无损转码,右端
> 几乎不可转码;三条代码走廊——**体裁距离矩阵**、**规范门演化**、
> **跨体棘轮**——把"体裁是坐标""门决定演化速度""破体单行道"三个
> 命题变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",各体文学转代码要解决"**风格化参数的
纪律**":把一段文体语言("词的门比诗宽")先翻成模型(坐标+门宽+迁移
算子),再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清哪些
对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条走通了的
走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 文体概念 | 代码化身 | 备注 |
|---------|---------|------|
| 体裁距离 | 八维风格化坐标+加权欧氏(约束维加倍) | 实验幕一;锚序不锚值 |
| 杂交定位 | 凸组合+噪声,残差与内分比可验 | 实验幕一 3 |
| 维度归因 | 消融某维(如舞台性)看距离坍缩 | 实验幕一 2;归因即删列 |
| 规范强度→演化变异率 | 门宽 gate(n)+继承+突变+淘汰迭代 | 实验幕二;r=−0.998 |
| 规范崩解 | 门参数的 regime 切换,崩解前后统计 | 实验幕二 3 |
| 跨体迁移 | 松紧不对称的迁移算子(约束维棘轮) | 实验幕三 |
| 三张结构卡 | 定长字段记录+完整性断言(空格=右端留白,须显式) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **体感与气象**:"盛唐气象""本色当行"是调动整个阅读史的趣味判断
   ——代码算得出平仄分布,算不出"这个字拗得好"(评点的地界)。
2. **规范强度的实证测度**:仿真可以指定 n,但从谱、评点、选本、科场
   程式**综合估出一个真实文体的门宽**是文献学问题,模拟不能冒充考据。
3. **正变褒贬**:正变是价值判断(变可胜正),只能双录立场,不能算出
   排名——"一代之所胜"的矩阵是描述,不是打分器。
4. **八维坐标与权重本身**:坐标取值与约束维加倍是**骨架假设**——换
   权重,距离的序可能变(✍️练习 4),转码者必须把骨架写在显式假设栏。

**边界的一句话**:绿色区=门引擎+迁移引擎+距离度量,覆盖"文体直觉的
校准";红色区提醒:**转码是文体学的试算器,不是品鉴的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:体裁距离矩阵走廊(体裁空间的全机械化)

```
四体特征向量 ──加权欧氏──▶ 6 对距离 ──消融某维──▶ 归因(舞台性独撑?)
      │                                          │
      └──杂交作品(凸组合+噪声)──▶ 残差/内分比 ──▶ 跨体定位
```

- **理论→模型**:四体各 8 维风格化坐标(02 章"形式量"的压缩);权重
  显式声明(约束维加倍——体裁距离首先是形式约束的距离)。
- **算法层**:O(K) 距离计算,K=8;杂交生成=凸组合+U(−0.04,0.04) 噪声;
  线段投影与内分比是闭式。
- **本家族实现**:[`experiments/genre_distance_drift.py`](experiments/genre_distance_drift.py)
  幕一——断言 d(诗,散)=1.860 最大对、戏剧无近邻(1.307)、消融舞台性
  d(小,戏) 1.307→0.596 跌破 d(散,小)、杂交残差中位≈0.065 贴线。
- **真实系统**:**文类标签系统**(把独热标签升级为坐标:任意作品可报
  "距诗歌 0.7、距散文 1.1");**跨体写作助手**(给作品的八维坐标与
  最近体邻域,提示"你正在从哪跨到哪")。
- **性能工程要点**:全部闭式,单次评估微秒级;工程价值不在算力在
  **坐标系纪律**——特征维与权重必须版本化(换权重的矩阵不可比);
  大规模书目定位时把坐标存成向量,距离用点积展开(平方距离=|a|²+|b|²−2a·b,
  与嵌入检索同构,现成的 ANN 索引直接可用)。

### 走廊 2:规范门演化走廊(松紧与变异率)

```
规范强度 n ──门宽 gate(n)──▶ 继承+突变+淘汰 ──▶ 变异率曲线
      │                                            │
      └──regime 切换(规范崩解)──▶ 崩解前后统计 ──▶ 新变体爆发
```

- **理论→模型**:亚文体带 n;每代 x←0.85x+N(0,0.30),|x|>gate 淘汰,
  幸存者复制回补;T=80 代取终代 std 为变异率。
- **算法层**:O(W·T) 一次扫描(W=240,T=80,毫秒级);3 次重复取均值压
  单run噪声。
- **本家族实现**:同实验幕二——断言 r=−0.998、近体 0.044 对现代散文
  0.253(5.8 倍)、崩解后 0.044→0.255 且出旧门限变体 0%→78%。
- **真实系统**:**平台类型管理**(把内容类型的"规范化程度"当参数:
  门太严→同质化(变异率 0.04),门崩→类型瓦解(78% 出门变体);排期
  创新=受控开门);**文类演进监控**(某类型标签的句式/程式指标逐期统计,
  变异率跳升=规范崩解信号=新流派窗口)。
- **性能工程要点**:注意**饱和陷阱**——若突变尺度远小于门宽,门失效,
  宽端变异率饱和、秩倒置(本实验第一版实测踩过:mutation 0.10 时 r 只有
  −0.90);建模任何"选择+变异"系统,先查门是否全程起作用。演化主体
  多时(网文类型×千部作品),按类型分流独立 Random(seed=base+类型号)
  保证可复现并行。

### 走廊 3:跨体棘轮走廊(破体的迁移算子)

```
作品坐标 w ──迁往目标体──▶ 约束维:松=一步到位/紧=恢复乏力(γ)
      │                     内容维:部分收敛(β)
      └──链式迁移 诗→词→曲→拟古回近体 ──▶ 单调性/不可逆断言
```

- **理论→模型**:约束维集 {韵律,整齐,程式};松紧不对称即棘轮;γ=0.15、
  β=0.65、噪声 ±0.02 全部显式(03 章"骨架假设"栏的范例)。
- **算法层**:纯状态转移,无迭代;每腿 O(K)。
- **本家族实现**:同实验幕三——断言去程残距 0.14/0.37、回程 0.78、
  离原体 0.667→1.001 单调增、回程后 0.785>0.667、整齐度 0.95→0.39。
- **真实系统**:**风格迁移与体裁约束**(文本生成中的"体裁控制":
  约束维应设硬闸、内容维设软导——把"松"当免费是错的,松开就锁死);
  **跨体写作助手的代价提示**(用户从散文跨向律诗,助手按棘轮模型提示
  "句式约束恢复乏力,建议保留草稿版本——解放容易,复原难")。
- **性能工程要点**:三条走廊中最便宜(无迭代),但**参数敏感度最高**:
  γ 从 0.15 调到 0.45,回程追回率巨变(00 章练习 4)——上线任何"棘轮"
  机制(权限放开/依赖引入/数据schema迁移同理)先做 γ 扫描,把单向门
  的不可逆性标进 API 文档。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:文类标签系统——从独热到坐标

内容平台的分类(玄幻/言情/悬疑…)是**独热标签**;按走廊 1 升级为
**坐标+邻域**:每部内容八维特征(可由计量文体学指纹+人工规范标注混合
估出),标签=最近的体邻域而非单点。收益:跨体内容不再"无处安放"
(散文诗不再在诗歌/散文二选一),推荐与检索都能用距离语义。

### 落点 2:类型演化监控——把"门"当运营参数

按走廊 2,给每个内容类型维护两个数:**门宽**(规范执行强度:标签准入
规则、审校清单)与**变异率**(新形式的实测占比)。门宽是可调参数:
同质化(变异率<某阈)→受控开门;类型瓦解(出门变体>60%)→收门或
裂变新类型。"规范崩解期=创新窗口"是这条曲线的运营版。

### 落点 3:跨体写作助手——报坐标,提示棘轮

按走廊 3,对生成/辅助写作系统显式分维控制:**约束维**(格式/格律/
结构模板)设硬约束闸并保留"松开确认",**内容维**(题材/语气)开放
自由——因为约束维松开不可逆(文档版本、格律恢复都是补丁),内容维
改主意成本近零。任何"放开限制"的按钮都应走棘轮模型定价。

### 落点 4:计量文体学的分账纪律

接 01 章主线 B:工程侧做文体计量(风格指纹:词频/句长分布)时,与
体裁规范系统(规则表)**分库分账**——指纹库答"像谁",规范库答
"合什么律";两库可以互相标注,禁止互相冒充(风格距离近≠同体)。
