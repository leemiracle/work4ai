# 讲透中国戏剧文学 · 杂剧-传奇-戏曲与话剧——独撑一维的文学

> **定位句**:这支负责**戏剧谱系**(GB/T 7503420:杂剧/传奇/戏曲与话剧):从优孟
> 衣冠到花部再到 1907 年话剧,唯一全程要求**当众扮演**的文学——代言体的语法、
> 场上与案头的张力。与小说支分工:**那边讲给人听,这支演给人看**。
> GB/T 13745 75034 中国各体文学 · **GB/T 支(7503420)**。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:优孟衣冠(《史记·滑稽列传》)→唐参军戏→宋杂剧/金院本→**元杂剧**
  (一本四折一楔子、一人主唱,按通说)→明清传奇(长篇铺展)→花雅之争(乾隆年间,
  按通说)→京剧成于北京→1907 春柳社起话剧→五四后话剧落定。
- **因什么问题**:①叙述与代言的语法分界(作者隐身,角色自道)②曲牌联套与脚色制
  怎样把文学装进演出③场上与案头,剧本为谁而写(李渔重"场上",按通说)。

## 核心问题

**已解决(通说)**:代言体(区别于小说叙述体的根本语法);脚色制与联套(生旦净丑
类型系统+宫调-曲牌组合序,文学与演出的接口);杂剧/传奇的体制差(四折短制对
数十出长编)。

**未解决/深水区**:场上案头之争的当代版(剧本文学与剧场文学的权重);戏曲与话剧同支的建制约定——曲律之有无(实验门宽:杂剧 0.80 对话剧 0.25),"中国戏剧文学"是一个家族还是两段谱系;音乐性不可恢复项(曲谱之外的唱法与排场)。

## ✨ 这支最美的一个事实

**舞台性一维独撑**:实验幕一消融实测——去掉"舞台性"这一个维度,戏剧到其余三体
的距离坍缩最狠(降 24-54%,而非戏剧对只降 0%),其中 **d(小说,戏剧) 从 1.307
跌到 0.596,竟跌破 d(散文,小说)=0.926**——在纸面上,剧本文学几乎混同于散文-
小说连续体。戏剧的独立坐标由一维撑起:**读剧本与看戏是两种经验,差的正是这个维度**。
GB/T 把杂剧传奇与话剧同置一支,因为它们共享这一维——曲律可以没有(话剧),
"当众扮演"不能没有。

## 假设与依赖

- 买入"剧本可离场上而研":文本侧研究合法,场上效果恒为右端留白(家族 03 章谱系)
- 坐标锚序不锚值;折出/联套结构卡可全写,音乐性不可写;话剧起点年代按通说双录

## 教材锚
