## 一、家族定位

- **四支纵切**:同一部中国文学史的四种"体"的读法——**诗歌支**(7503410:诗/词/曲
  的诗歌谱系,格律的定与破)、**戏剧支**(7503420:杂剧/传奇/戏曲与话剧,场上
  与案头)、**小说支**(7503430:笔记-传奇-话本-章回-现代小说,街谈巷语到
  殿堂)、**散文支**(7503440:古文-小品-现代散文,载道到性灵)。
- **一条主轴贯穿**:**形式规范的生命周期**——起源(破上一体而生)→定型
  (体制-格律-程式收紧)→守恒(严体千年不变)→松动(规范崩解)→被新体
  取代或互渗重生。家族实验把整条主轴**算术化**(距离矩阵/规范门/棘轮)。
- **零门槛**:会背一首唐诗、看过一场戏、读过一部章回就能进;术语随用随讲
  (三步法:直觉图像→严格陈述→最小例子)。
- 路线 A(问题派):词牌为什么管那么严?→直接进诗歌支;章回为什么有回目?→小说支
- 路线 B(谱系派):00→诗歌(最严的体)→戏剧(唯一活在台上的体)→小说(最会
  吸收的体)→散文(最少约束的体)
- 路线 C(研究派):00→01(跨文体写作/计量文体学/俗雅边界)→02(各体的形式量)
- 工程师快轨:直接跑 [`experiments/genre_distance_drift.py`](experiments/genre_distance_drift.py),再回读 04 章

> 四支不是并列的四个抽屉,是**一个形式空间**的四个区域:诗歌是约束极(齐言格律),
> 散文是自由极(形散),小说戏剧住在中带,戏剧再被"舞台性"一维单独抬起——
> 家族实验幕一就是这个空间的实测地图。
