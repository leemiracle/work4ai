# 讲透中国小说文学 · 笔记-传奇-话本-章回-现代小说——街谈巷语到殿堂

> **定位句**:这支负责**小说谱系**(GB/T 7503430):从稗官野史到"文学之最上乘",
> 地位最低而爬升最高的体;形式空间的**中带**,兼容并包最会吸收。与戏剧支分工:
> **这支讲给人听(叙述体),那边演给人看(代言体)**。
> GB/T 13745 75034 中国各体文学 · **GB/T 支(7503430)**。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:班固《汉书·艺文志》定调"小说家者流,盖出于稗官,街谈巷语"→
  魏晋志怪(《搜神记》)/志人(《世说新语》)笔记→**唐传奇**(鲁迅断为"始有意为小说",按通说)→
  宋元话本(说书场入市井)→明清章回(四大奇书到《红楼梦》)→1902 小说界革命
  ("小说为文学之最上乘",梁启超,按通说)→1918《狂人日记》开现代小说。
- **因什么问题**:①残丛小语怎么长成叙事巨制(体制增益史:入话-回目-章回)②地位
  怎么从稗史爬到最上乘(正典化三步机制)③章回体制与现代小说的衔接之辩。

## 核心问题

**已解决(通说)**:演进分期的通说框架(笔记-传奇-话本-章回-现代)及其体制标志;
章回体制(分回标目、说书程式"话说""看官听说""有诗为证");白话/文言两大系统
并流(话本一系与传奇一系)。

**未解决/深水区**:章回的现代转型(五四截断还是内在演化,通说双录);网络文学是否新一轮"街谈巷语到殿堂"(家族 01 章主线 C 的当代回合);演进单线叙述的风险——多源并流,谱系不是直线。

## ✨ 这支最美的一个事实

**小说的居中性**:实验幕一杂交定位实测——给散文诗、章回韵散间体这类跨体作品报
坐标时,**第二近邻常被小说抢走**(散文诗的双亲前二包揽率 0%,章回韵散间仅 10%,
而散文化小说、诗剧都是 100%):小说住在形式空间的**中带**,离诗、散、戏都不远。
"最会吸收"第一次有了几何表述——两千年地位史(街谈巷语→最上乘→殿堂)与空间
位置互为印证:**一个什么都吃得下的体,最终什么都吃到了**。

## 假设与依赖

- 买入演进分期的叙述框架(分期点即争议点,双录处理)
- "始有意为小说"是鲁迅断案(通说),用作唐传奇界标而非全称判断
- 程式计数(回目/套语)可算,叙事节奏的"疏密"不可算(家族 03 章账单)
