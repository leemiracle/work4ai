# 03 · 可构造与结构:哪些体裁对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:各体文学的对象沿一条**可构造谱系**排开——左端
> **严格可构造**(体裁距离矩阵、规范门演化、跨体迁移轨迹:写得下、算得动、
> 能过 assert),右端**几乎不可构造**(体感、本色、"一代之所胜"的价值
> 直觉:只有思想操作化);全谱系共享两条结构引擎:**规范门引擎**(体的
> 松紧决定演化速度)与**迁移棘轮引擎**(破体单行道);而每一体、每一制、
> 每一次跨体,可以压进三张**结构卡**(体裁身份证卡/形式规范卡/跨体实验卡)。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
距离矩阵 ── 规范门演化 ── 迁移轨迹 ── 词谱参数表 ── 回目程式清单 ── 谱系分期 ── 本色当行 ── 体感/正变褒贬
  │                                                                                │
严格可构造(可断言)                                                 几乎不可构造(只有思想操作化)
  └── 写得出、数得出、算得动、能过 assert                            └── 只能在批评与阅读里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:距离矩阵的
语义是"坐标+度量"(输入输出明确);而"这首诗有盛唐气象"要求调动整个
阅读史的趣味判断——判断的给出无法程序化。本章先盘家底,再看两条结构
引擎,最后把体/制/跨体压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **体裁距离矩阵** | 四体八维风格化坐标+加权欧氏 | 低(实验幕一全程可跑) | 坐标是风格化取值:**锚序不锚值**;权重带理论(约束维加倍) |
| **杂交定位** | 凸组合+噪声生成,残差/内分比可验 | 低(实验幕一 3) | α(双亲配比)靠解释设定,非测量所得 |
| **规范门演化** | 门宽 gate(n) +继承+突变+淘汰,迭代 T 代 | 低(实验幕二) | "门=规范强度"是化简;真实规范还有师承/科举/出版变量 |
| **迁移棘轮** | 约束维松紧不对称的迁移算子 | 低(实验幕三) | γ(恢复系数)是风格化参数;个案历史要单独考 |
| **词谱参数表** | 牌名→(字数/句式/韵位/可平可仄) | 低-中(半构造:谱有异体,须择本) | 音律感不可恢复(乐失传) |
| **回目/程式清单** | 逐回标目、程式语计数 | 中(半构造:标记依赖体例决定) | 程式的"功能重量"不可枚举 |
| **谱系分期** | 源流时间线(笔记→传奇→话本→章回) | 中 | 分期点即争议点(通说+反方双录) |
| **体感/正变褒贬** | 只有思想操作化(评点写作) | **不可构造** | 价值判断的给出是理性空间内的活动,不能外包给算法 |

**反直觉发现(本章铁律)**:**名气与可构造性成反比是常态**。最有名的
词("一代有一代之所胜""本色当行")全在谱系右端,最能跑的对象(矩阵/
门/棘轮)名气最小。**右端管洞察,左端管校准**;拿右端对象硬造左端指标
(给"盛唐气象"打个分)是本学科量化失真的头号来源——两头都不是。

## 二、结构引擎 1:规范门引擎(体裁身份证的松紧)

**直觉图像**:每张体裁身份证上都印着一道门——门里是合律,门外是出律。

- **数学化身**:亚文体带规范强度 n,门宽 gate(n)=a+b·(1−n);文群每代
  继承+突变,出门者淘汰。**变异率是门的函数**:实验幕二实测 Pearson
  r=−0.998,近体(n=0.95)0.044 对现代散文(n=0.15)0.253 差 5.8 倍;
  门开(规范崩解)后 15 代变异率跳至 0.255,出旧门限变体 0%→78%。
- **理论地位**:这是"严体保守、宽体多变"与"文体解放期爆发新形式"的
  最小机器——00 章"一代有一代之所胜"的动力学翻版:门与时代场合咬合,
  则该体盛;场合迁移,门成为枷锁,破体者开新门。
- **刚性从哪来**:序关系是刚的(门窄→变异低,单调);软的地方在**门的
  实证测度**——真实规范强度须从谱、评点、选本、科场程式中综合估定,
  实验取的是风格化值(02 章"应然实然分账"的落地)。

## 三、结构引擎 2:迁移棘轮引擎(破体单行道)

**直觉图像**:跨体旅行不是对称的往返,是带方向的棘轮。

- **数学化身**:作品特征向量 w 迁往目标体:约束维(韵律/整齐/程式)
  目标更自由则**一步到位**,目标更严格则**恢复乏力**(γ=0.15);内容维
  正常收敛。实测:去程残距 0.14/0.37,回程 0.78;离原体距离单调增,
  回程后仍大于第一站;句式整齐度 0.95→0.39。
- **理论地位**:这是钱锺书"破体"说的动力学化——"以诗为词"容易,
  "以词还诗"不可能:苏轼把词的门打开之后,再没有人能回到晚唐五代
  小令的世界(通说框架)。
- **刚性从哪来**:单调性与不对称是算子性质(刚);软的地方在**维度
  分类**——哪些维算"约束维"取决于该体的立法史(诗的整齐是约束,
  散文的"散"是身份),个案须单独核。

## 四、结构卡 schema:把一体、一制、一次跨体压进三张卡

**先答为什么**:各体文学对象的难点在"历史性"——谱系长、规范杂、
互渗多。结构卡是**有限字段的压缩格式**:字段固定、填空即可复用、
可比可查可补(卡片本身严格可构造,是"可构造"在理论层的对应物)。

### 卡 1:体裁身份证卡(把一个体裁钉进空间)

```
【体裁身份证卡】
体名:________(别称/雅号一行)
体制一句话:________(框架的最小描述:几段/几折/几句/有无定式)
格律与程式清单:各一行(声律要求/固化单元)
规范强度自评(0-1,注明依据:谱?评点?选本?):___
八维坐标(韵律/整齐/程式/抒情/叙事/篇幅/口语/舞台,各 0-1):________
谱系上下游:承________ / 启________(通说口径)
破体近邻(谁常跨进来/它常跨进谁):________
门的名言(该体自述规范的代表性话语一条,通说):________
```

样例(已填,词):体名=词(长短句/诗余);体制=依词牌而定,一牌一格;
格律与程式=逐字平仄对谱/过片定式;规范强度=0.80(词谱在,门存);
坐标=(0.85,0.45,0.80,0.90,0.35,0.08,0.40,0.20);承=唐五代曲子词、
启=散曲;破体近邻=诗(苏轼以诗为词跨进来)/曲(曲破其定字);门的名言=
"依声填词"。**读卡法**:坐标+规范强度合起来,就是这个体在空间里的
位置与门的宽度——身份证不只是名字。

### 卡 2:形式规范卡(把一个"制"钉成规则表)

```
【形式规范卡】
制名:________(体名+具体制式,如:七言律诗/念奴娇/杂剧一本四折)
单位与数量:________(句数/字数/折出数/回数)
位置规则:________(韵位/对仗位/联套序/回目位置)
自由度(哪里可通融/可平可仄/可增衬字):________
违例名称(出律/失粘/失对/失套):________
判例(通说公认的名家破例一条+批评反应):________
可构造代理:参数表可全写(左端)/部分写(中段):________
```

样例(已填,杂剧体制):制名=元杂剧一本四折一楔子;单位与数量=四折+
楔子(通常一本);位置规则=一人主唱(正末或正旦,按通说);自由度=
折数偶有破例(五折个案)、楔子可省;违例名称=失套(宫调联套错乱);
判例=明人改本多就范于传奇体制(通说);可构造代理=折出结构可全写,
联套音乐性不可写(乐失传)。**读卡法**:规范卡填得出,"辨体"就落到
了纸面;填不出的格子(音律感/场上效果)就是谱系右端的留白。

### 卡 3:跨体实验卡(把一次破体钉成迁移记录)

```
【跨体实验卡】
甲体→乙体:________(方向!棘轮是单向的)
迁移维度清单:________(约束维:韵律/整齐/程式?内容维:叙事/抒情?)
每维的迁移量(松/紧/无):________
通说先例(谁做过同向迁移):________
棘轮风险评估(约束维若被松开,回得去吗):________
批评语言反应(当时怎么说/后来怎么说):________
一句话(这次破体改写了什么边界):________
```

样例(已填,以诗为词):甲→乙=诗→词;迁移维度=句式整齐度(松:齐言
→长短句)、题材内容(松:艳科→无意不可入);先例=苏轼(通说"以诗
为词");棘轮风险=整齐度松开后不可逆(实验幕三:0.95→0.39),其后
"词"的边界永久改写;批评反应=当时讥"要非本色"(按通说,李清照
《词论》立场之代表),后世奉为豪放开山;一句话=它把词从歌筵搬到
了书案。**读卡法**:跨体实验卡的"方向+维度+先例"三栏,就是"破体"
的操作化全表——00 章"以 X 为 Y"句式的展开。

**判定流程**(把一个文体主张钉到谱系上):

```
该主张的核心对象能写成坐标、规则表或迁移算子吗?
  ├─ 能,且语义有限确定 ──────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(清单/谱系,填空带解释)─▶ 中段:卡片化+双人校,禁止硬算
  └─ 不能(体感/正变褒贬/气象)──▶ 右端:思想操作化+评点写作,禁止压成参数
```

## 五、谱系×引擎×四支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| [诗歌](讲透中国诗歌文学/README.md) | 左端(谱参数表/距离)到右端(气象/味) | 门引擎的**极点**:最严的门 | 分裂:谱与矩阵可算,体感不可 |
| [戏剧](讲透中国戏剧文学/README.md) | 中段(折出/脚色表)到右端(场上效果) | 迁移引擎的**大站**:戏与曲、戏与话剧的两度大迁移 | 中(结构卡+场上留白) |
| [小说](讲透中国小说文学/README.md) | 左端(程式计数/演进分期)到右端(叙事神品) | 门引擎的**宽门带**+迁移引擎的吸收站 | 中(程式可算,节奏不可) |
| [散文](讲透中国散文文学/README.md) | 右端为主(门最宽=规范最少,卡片天然稀薄) | 门引擎的**自由端**:无门之门 | 低(卡片两栏恒空,正是其身份) |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——谱与矩阵
走计算,结构卡走填空双人校,体感永远走评点。**散文支的卡片最空,
不是研究落后,是对象使然**:一个以"最少形式约束"为身份的体,结构卡
填不满正是它的身份证(02 章"形散神不散"的卡片版)。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——体、制、行**(极简)身份证卡记"体"(位置
与门宽),规范卡记"制"(规则表),跨体实验卡记"行"(迁移与棘轮)。
为什么美:**恰好在"是什么/守什么规则/做了什么"三层把一个体裁的
历史性装订成档**——填不出的格子就是谱系右端的留白,空格本身在报
信息。亲历:给你最熟的体裁填三张卡(✍️练习 1),看哪张最先填不下去
——那就是你自己的谱系位置。

4. ✋ 用 §三引擎 2 把"以文为词"(辛弃疾)与"以诗为词"(苏轼)各写

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:卡片之眼**——遇到任何体裁/体制/跨体事件,先问
三张卡填得出吗:身份证(位置与门宽)、规范卡(规则表)、跨体卡(方向
与棘轮)。以及一问硬指标:**它的核心对象在谱系哪一端**——左端去算,
中段填卡双人校,右端去写评点。
