# 讲透中国散文文学 · 古文-小品-现代散文——自由端的身份证

> **定位句**:这支负责**散文谱系**(GB/T 7503440):从唐宋古文到晚明小品到现代
> "美文",以**最少形式约束**为身份的体——形式空间的自由端,因为无体,才与诗
> 相距最远。与诗歌支分工:**那边是约束极,这支是自由极**。
> GB/T 13745 75034 中国各体文学 · **GB/T 支(7503440)**。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:先秦诸子史传之文(无体之体的源头)→唐宋古文运动(文以明道,八大家)→
  周敦颐"文以载道"、桐城"义法"(方苞)一脉守**载道**;晚明公安派"独抒性灵,不拘格套"
  (袁宏道)守**性灵**→现代:周作人倡"美文"(1921,按通说)、鲁迅杂感别开生面,两线并流至今。
- **因什么问题**:①文与道的关系(载道的规范力从何来)②"散"怎么成为文体身份
  (形散神不散的两账)③散文史的边界画到哪(杂文学问题)。

## 核心问题

**已解决(通说)**:载道/性灵两脉的张力叙述(中国散文史的价值坐标);义法=软规范
(桐城有约束之名而宽约束之实——实验门宽的注脚);"形散神不散"的形式账/功能账
分层(1961 前后大讨论,按通说)。

**未解决/深水区**:散文史的边界(奏议碑志应用之文算不算——纯文学 vs 杂文学,家族 00 章轴线 2);"神"的不可操作化(功能账只能评点,压成参数即失真);当代扩容(非虚构/学术随笔入散文,边界再谈判——家族 01 章主线 A)。

## ✨ 这支最美的一个事实

**最大对的另一端**:实验幕一实测——**d(诗,散)=1.860 为全矩阵最大**,散文是
约束极(诗)的正对面;幕二实测——散文门最宽(现代散文 n=0.15,变异率 0.253 全
家族最高)。一个以"最少形式约束"为身份的体,恰恰因此:与最强的门(诗)相距最远,
内部百态丛生(小品/杂感/美文/随笔各走各路)。"形散神不散"在这里获得算术注脚:
**散是坐标(自由端),不散是功能(右端的评点)**——形式账可算,神账只能读。
散文支的结构卡最空,不是研究落后,是身份使然。

## 假设与依赖

- 买入四分法下"散文"为建制事实(凡不归诗戏小者多入散——剩余类的宿命)
- 家族约定:赋/骈文入本支(《文选》"文"之传统),诗歌支互见;骈文是支内例外
  (四六对仗,门较严 n=0.90):"散文=自由"须留此脚注
