# 讲透中国诗歌文学 · 诗-词-曲的谱系——形式约束的极点

> **定位句**:这支负责**诗歌谱系**(GB/T 7503410:诗/词/曲):从齐言格律(近体)
> 到依谱长短句(词)到衬字自由(曲),一条"**约束逐级松绑**"的直线;家族实验
> 幕二(最严的门)与幕三(棘轮)的主现场。与散文支分工:**这支是约束极,那边是自由极**。
> GB/T 13745 75034 中国各体文学 · **GB/T 支(7503410)**。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:诗三百→楚辞→汉魏乐府→五七言古体→**近体**(齐梁萌芽、初唐定型,
  按通说)→**词**(依燕乐而填,敦煌曲子词-花间-两宋而盛)→**散曲**(元,衬字破
  词之定字)。通说一句"诗庄词媚曲俗",正是约束松绑的三级。
- **因什么问题**:①声音的规则怎么变成制度(平仄-对粘-韵位的立法史)②约束松一档,
  表达宽多少(词"无意不可入")③松开的约束为什么回不去(诗之余-词之余的谱系论)。

## 核心问题

**已解决(通说)**:近体格律体系(句式四型/对粘/中二联对仗)——格律成为可谱化的
规则系统;词牌=字数/句式/韵位/可平可仄的联合分布(一牌一格);衬字机制(曲的
口语性由此而来)。

**未解决/深水区**:音律的不可恢复项(燕乐失传,"依声"之声只剩谱);平仄的感知
基础(为什么这套约束能成美);"诗余/词余"地位史:谦辞还是排序(通说双录)。

## ✨ 这支最美的一个事实

**近体格律定型后千年守恒**:实验幕二实测——近体的规范强度 n=0.95,文群演化 80 代
变异率仅 0.044,全家族 16 个亚文体中最严。一首初唐律诗与一首清代试帖诗,遵守的是
**同一张平仄谱**:门立起来之后一千年没挪过位置。更妙的是隔壁:词的门 0.80(变异率
0.099),恰好宽出那一档,盛得下苏轼的"无意不可入,无事不可言"(刘熙载《艺概》
评东坡语,按通说)——**诗与词的全部距离,就写在两道门的宽度差里**。

## 假设与依赖

- 买入"格律可离乐而存":乐失传后谱仍在(音律感除外,家族 02 章账单)
- 实验的规范强度与坐标是风格化取值,**锚序不锚值**;词谱有异体,填卡须择本注明
