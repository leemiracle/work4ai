## 诞生

- **谁/何时**:先民歌诗成集(诗经;删诗说存疑,通说双录);战国屈原
  宋玉与诸子史官;汉初至司马相如扬雄(赋);汉武帝立乐府采诗(通说);东汉末无名氏(古诗十九首)。
- **因什么问题**:①第一批文体分类怎么来的 ②四言为何让位五言
  (格式过时之问——家族流变轴卡的标本案)③铺排的赋与叙事的乐府
  为何并存(宫廷与民间两条声部)。

## 核心问题

**已解决(通说)**:风雅颂=功能分类,赋比兴=手法分类(最早的分类学);
五言在东汉末证明自己("五言之冠冕");诸子寓言与《左传》叙事是后世叙事文的源头。

**未解决/深水区**:诗经编辑过程与年代学(删诗/采诗说并存);赋的
评价地位("劝百讽一"的批评汉代已起);乐府口头层与写定层难分离。

## ✨ 这支最美的一个事实

**无名氏的冠冕**:《古诗十九首》的作者全部不可考——一群不知姓名的
人写下"思君令人老,岁月忽已晚",被刘勰评为"实五言之冠冕"。中国
诗歌的第一声成年叹息,签不了名。**经典可以无作者**:文学史的地基
不是天才名录,是匿名的语感共同体。
