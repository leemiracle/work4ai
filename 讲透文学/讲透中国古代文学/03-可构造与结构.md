# 03 · 可构造与结构:哪些古典文学对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:中国古代文学的对象沿一条**可构造谱系**排开——
> 平仄谱端**严格可构造**(对+粘+韵句限定从首句推出四式,枚举可验,
> assert 可断),对仗端**半构造**(词性桶可写,小类相对与"合掌"
> 要靠眼力),文学史判断端**风格化可模拟**(生命周期曲线是标定参数
> 的示意,断言只锚结构性质);全谱系共享三条结构引擎:**骨架推导
> 引擎**(对粘规则)、**平行组合引擎**(桶乘积)、**生命周期引擎**
> (错峰更替);而古典文学的日常资产可以被压进三张**结构卡**
> (格律卡/文体谱系卡/流变轴卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
平仄四式谱 ── 对仗配对 ── 词牌谱 ── 章回体例 ── 接受史 ── "一代之文学" ── 意境/风骨
  │                                                                                │
严格可构造(可断言)                                                几乎不可构造(只有思想操作化)
  └── 推导得出、枚举得验、能过 assert                        └── 只能在例诗与论辩里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:平仄谱
的语义是"每字的二值标注",输入输出明确;而"这首诗有没有意境"的
判据要重建千年的例诗参悟传统——**法庭没有成文法**。本章先盘家底,
再看三条结构引擎,最后把古典文学的三种日常资产(格律/文体/流变)
压成三张结构卡。四段速写定位:严格端集中在唐宋(律诗/词牌),
中段贯穿全史(对仗/体例),右端也贯穿全史(意境/风骨从诗经到清)。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **平仄四式谱** | 对+粘+韵句限定,从首句起式确定性推导(实验律一) | 低(全程可跑) | 推导对;但"合律"评价不等于"好诗"(崔颢《黄鹤楼》违律成公案,通说) |
| **格律变体计数** | 锁定位+自由位的组合计数;逐句/联级双枚举验证 | 低 | 只在"一三不论"近似下成立;细律(孤平/三平调/拗救)层层削减 |
| **对仗配对** | 词性分桶+对位取词(实验律二) | 低 | 词性可自动标,**小类相对**(天文对天文)与**合掌**(两句同义)需人工;平仄与词性两约束正交 |
| **词牌谱** | 字数-句式-平仄-韵位四元组的查表 | 低-中 | 同牌异体并存;音乐本体已亡,谱只存文字侧 |
| **章回体例** | 回目对句+说书套语+悬念结尾的模式化 | 中 | 例不等于法;名作破例是常态(红楼回目工艺远超通例) |
| **接受史** | 历代选本/诗话评语的引用链数据化 | 中 | 选本覆盖偏差;评语的非抽样性(诗话点悟,不求全) |
| **"一代之文学"** | 体裁生命周期的风格化模拟(实验律三) | 中 | 标定参数非拟合数据;断言只锚错峰/重叠/序列对齐三条结构性质 |
| **意境/风骨** | 只有思想操作化(例诗参悟+共同体裁定) | 高 | **构造学缺席**——无显式判据;"交融+言外"的指认依赖训练 |
| **经典化事件** | "谁在何时把谁推上经典"的叙事还原 | 高 | 因果不可实验;苏轼之于陶渊明是孤例叙事,非可重复机制 |

**反直觉发现(本章铁律)**:**这门学科最硬的资产在左端,最贵的
判断在右端,而教学的中枢在中段**。右端管洞察(陶渊明的迟到三百
年是接受史叙事,不是算法),左端管检验(四式谱是否唯一、变体数
是否恰为 2^16、瓶颈位是否最窄桶),中段的结构卡管**传承**(古典
文学训练的本质就是教人填卡:蒙学的对课在填对仗卡,学诗先学拗救
在填格律卡)。用左端硬造右端指标("意境打分器")与用右端拒绝
左端证据("格律是死学问")是镜像对称的两类事故。

## 二、结构引擎 1:骨架推导引擎(对粘规则——格律即约束编程)

**直觉图像**:律诗的八句不是八次独立的平仄选择,是**一次起式+
七次强制传播**——首句定,全篇定。

- **数学化身**:四种句式(A 仄仄平平仄/B 平平仄仄平/C 平平平仄仄/
  D 仄仄仄平平)为状态;"对"是联内偶位的取反映射,"粘"是联间
  偶位的保持映射;四式谱=四种初值的轨道。
- **三条刚性**(实验律一的数值化身):
  1. **推导唯一**:对与粘各自给出的候选句式恰为一个(映射可逆且
     唯一)——四式谱不需要搜索,是三条规则的确定输出,与王力
     《诗词格律》通行谱逐一相符。
  2. **变体有精确额度**:锁定位(2/4 字+句脚)之外,每句恰 2 个
     自由位,每式 2^16=65536 个变体,枚举与计数一致;叠"避孤平/
     避三平调"细律后四式合计 262144→29952——**约束层叠,额度递减**。
  3. **拗救是补偿协议**:违律(拗)之后有法定的补偿(救),拗救
     系统本身可描述——破格不是无法,是**第二层协议**。
- **刚性从哪来**:规则显式且封闭(可用 assert 执法);软的地方在
  **古音依据**——平仄依中古音系(平水韵系),用今音判定会系统性
  出错(02 章第四节的门槛)。
- **批评史地位**:这条引擎把"格律"从死记的谱重述为**生成的语法**:
  永明体发现四声(南北朝支)→律诗完成系统(唐代支)→拗救成熟
  (杜甫"晚节渐于诗律细")——形式系统的一千年工程史,九支里
  南北朝与唐两支共讲。

## 三、结构引擎 2 与 3:平行组合引擎(对仗)/ 生命周期引擎(错峰)

**引擎 2 直觉图像**:对仗不是灵感对对碰,是**逐位取词的独立选择**——
每位从同词性桶取一个,合格对句数=∏桶宽。

- **数学化身**:词性桶宽 [10,12,12,8,14](数量/禽鸟/动词/颜色/景物
  模板)→161280 个合格对句(全枚举验证);对桶 i 加一词的增益=
  总数/桶宽 i,**窄桶增益大**——颜色桶(8 词)是瓶颈(实验律二)。
- **刚性从哪来**:乘法原理是刚的;软的地方在**桶的划分粒度**——
  宽对(名词对名词)与工对(小类对小类)的界限是共同体规约,且
  **合掌**(两句同义,如"蝉噪"对"鸟鸣"义近)这种"合格的坏对"
  桶乘积测不出。
- **批评史地位**:它把"工对难得"翻译成库存经济学——**语言的
  小类库存决定对仗的产能上限**;蒙学对课(天对地,雨对风)就是
  给儿童预装桶结构的千年训练法。

**引擎 3 直觉图像**:"一代有一代之文学"不是朝代开关,是**四条
错峰的生命周期**——峰值间隔 197-378 年,重叠期恒有人跨界。

- **数学化身**:体裁强度=上升 logistic×下降 logistic(双 logistic);
  峰值 761/1139/1336/1693;主导体裁=逐年 argmax;开关(982/1285/
  1455)均落相邻两峰之间;重叠期内跨界文人可定位(苏轼 1080/白朴
  1280)(实验律三)。
- **刚性从哪来**:错峰与重叠是结构性质,对参数扰动稳健(改参数,
  峰值移动,序列与包含关系不变);软的地方在**参数的实证性**——
  标定非拟合,真实份额曲线要用数字人文数据(01 章主线 B)来还债。
- **批评史地位**:它给"一代之文学"(王国维)与"文体并行"(复线
  论)之争(00 §二)各判一半:峰值对线性叙事为真,死亡对复线论
  为真——**错峰更替,不是同步开关**。

## 四、结构卡 schema:把古典文学资产压进三张卡

**先答为什么**:古典文学的难点在"体量"——一个格律、一种文体、
一段流变,读散落文献难以携带。结构卡是**有限字段的压缩格式**:
字段固定、填空即可复用、可比可查可补(这是"可构造"在教学层的
对应物:卡片本身严格可构造)。

### 卡 1:格律卡(把一种体式的规范钉进字段)

```
【格律卡】
体式名:________(如:五言律诗·仄起首句入韵)
句数×字数:________(8×5)
句式骨架:________(逐句平仄谱)
核心规则(≤3):________(对/粘/韵位)
自由位与变体额度:________(如:16 位→2^16;叠细律后收缩)
禁手清单:________(孤平/三平调/失对/失粘)
补救协议:________(拗救方式)
范文锚:________(通说范本 1-2 首)
```

样例(已填,五律·仄起首句不入韵):句式骨架=仄仄平平仄/平平仄仄平/
平平平仄仄/仄仄仄平平×2(由对+粘推导);核心规则=联内偶位相反(对)+
联间偶位相承(粘)+偶句平收押韵;自由位=每句第 1/3 字(变体
2^16,叠避孤平/避三平调后本式 65536→9216);禁手=孤平(仄平仄仄平)/
三平调(句脚三连平)/失对/失粘;补救=B 式句孤平可本句自救(三字
改平);范文锚=杜甫《春望》(通说)。

### 卡 2:文体谱系卡(把一种文体的"户口与语法"钉进字段)

```
【文体谱系卡】
文体名:________(如:词)
诞生现场:________(何时/何地/倚什么音乐/谁 first 定型)
形式语法:________(体制四元组:字数-句式-平仄-韵位;或体例要件)
题材默认域:________(该文体的看家题材)
边界之争:________(与相邻文体的分界论战及双方)
经典化节点:________(选本/评点/大家谁把它推上正典)
衰变与遗留:________(主导权何时让出;退到哪条车道)
```

样例(已填,词):诞生现场=晚唐五代倚燕乐而起,温庭筠/花间定貌,
柳永拓慢词;形式语法=词牌四元组(如《水调歌头》95 字,谱见词谱
工具书),音乐亡而文字谱存;题材默认域=艳科言情→苏轼扩至怀古
说理(边界之争:李清照"别是一家" vs 苏轼"以诗为词");经典化
节点=《花间集》→南宋选本→清代词派中兴;衰变与遗留=元以后让出
主导权(实验律三:词峰 1139,小说峰 1693 之间词退边缘车道),今
存于创作与吟诵圈。

### 卡 3:流变轴卡(把一段流变钉进坐标系)

```
【流变轴卡】
流变命题:________(如:四言→五言的格式换代)
驱动力(≤3):________(音乐/媒介/制度/表达压力)
关键节点:________(年代+事件+人物,≤5 个)
过渡形态:________(新旧混体的标本)
完成标志:________(新格式压倒性占比/典范出现)
反例与回流:________(旧格式的复兴尝试及结局)
可检验代理:________(存世文献的何种统计可验证)
```

样例(已填,四言→五言):流变命题=诗经四言格式在汉代过时,五言
由乐府民歌上溯文人化;驱动力=乐府采诗的音乐形态+情感密度需求
(通说概说);关键节点=汉乐府民歌(陌上桑)→古诗十九首(五言
成人礼,"五言之冠冕")→建安文人五言(三曹七衣)→齐梁声律化→
唐五律定型;过渡形态=汉初骚体残响与四言颂赞并存;完成标志=东汉
末五言文人诗典范出现;反例与回流=曹操仍写四言(《观沧海》/《龟虽
寿》,通说)而未能挽格式——四言此后仅存于颂铭体应用文;可检验
代理=存世诗歌的句式占比曲线(数字人文可算,存世偏差需附注)。

**判定流程**(把一个古典文学主张钉到谱系上):

```
该主张的核心对象能写成谱、桶或曲线吗?
  ├─ 能,且规则显式封闭 ──────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(卡片/查表,填空带判断)─▶ 中段:卡片化+例诗对照,禁止硬算
  └─ 不能(意境/风骨/经典化)──▶ 右端:例诗参悟+论辩,禁止压成参数
```

## 五、谱系×引擎×支总表(把九支钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 周秦汉 | 中段(文体谱系卡的源头站)+右端(比兴的例诗参悟) | 生命周期(格式过时的第一案) | 低-中 |
| 魏晋 | 右端为主(接受史/风骨),流变轴卡为中段 | 生命周期(经典滞后) | 低-中 |
| 南北朝 | 左端起步(声律:从发现到立法)+中段 | 骨架推导(前史) | 中 |
| 隋唐五代【主轴】 | 左端(四式谱/拗救全可跑)+中段(唐传奇叙事) | 骨架推导+平行组合 | 高 |
| 宋代【主轴】 | 左端(词牌谱查表)+中段(流派之争的论证链) | 平行组合+生命周期(接棒案) | 高 |
| 辽金 | 中段(过渡形态的标本库) | 生命周期(重叠期) | 中 |
| 元代 | 中段(宫调-曲牌半查表)+右端(场上艺术不可谱化) | 平行组合(衬字弹性) | 中 |
| 明代 | 中段(章回体例模式化)+右端(性灵/格调之争) | 平行组合(回目对句) | 中 |
| 清代 | 右端为主(红学/义法)+中段(桐城义法近乎卡) | 生命周期(收束期) | 低-中 |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——唐宋
两支走计算(谱推导/查表/计数),元明清走卡片与体例分析,先秦两汉
与魏晋走例诗参悟与流变叙事。**没有哪支全家可构造,也没有哪支全家
不可构造**;最深的误解是拿左端工具否定右端判断(或反之)。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——把三千年装进书包**(极简)
格律卡定骨架(什么规则、几格自由、哪些禁手),文体谱系卡查户口
(生于何乐、争过何界、让位何年),流变轴卡看大势(什么力推动、
何处过渡、何代完成)。为什么美:**它把"读懂文学史"变成"填得出
卡"**——可携带性从书斋移进任何场合;三卡互相引用(格律卡挂在
文体谱系卡的形式语法栏,流变轴卡引用文体谱系卡的让位节点),一个
传统的强度与磨损一目了然。亲历:给你最熟的文体(词?章回?)填
三张卡(✍️练习 1),填不出的格子就是你的(或该领域的)盲区地图。
