## 诞生

- **谁/何时**:北宋(960-1127):柳永/欧阳修/王安石/苏轼/周邦彦;两宋之交与
  南宋:李清照/杨万里/陆游/辛弃疾/姜夔。话本随城市娱乐业生长,存本多经
  元明定型(通说)。
- **因什么问题**:①词凭什么在宋接棒(倚声+城市娱乐+文体容量之问)②"以诗为词"与"别是一家"谁对(边界之问——本支招牌论战)③宋诗"以议论为诗"是退化还是转型(唐宋之争,800 年未决)。

## 核心问题

**已解决(通说)**:词体完成——词牌四元组(字数-句式-平仄-韵位)语法化,
  音乐亡而文字谱存;慢词扩容(柳永)与格律深加工(周邦彦);江西诗派
  互文的显式纲领("点铁成金"——与 AI 外挂知识库同构,01 章美之时刻 4);古文集大成(八大家宋居其六)。
**未解决/深水区**:唐诗宋诗之争(严羽已开战,通说立场"两条路,非高下");
苏轼"以诗为词"的张力(扩容功臣 vs 破体者,李清照派反诉,双录);话本
口头层与写定层(存本多经元明改写)。

## ✨ 这支最美的一个事实

**两个口号的对峙**:苏轼把诗的题材与语法搬进词牌,词从此怀古、说理、
悼亡无所不写("以诗为词",通说概括);李清照《词论》回击:词"别是
一家",必须守住自己的音乐语法,协律与本色不可让渡。**一场文体边界
之争被双方各用创作与立法完成**:苏轼用作品扩界,李清照用论文立规
——词史走向是两者的叠加(豪放婉约并行,词牌语法保留):文体边界的
最终裁决者是后世的写作实践,不是论战。
