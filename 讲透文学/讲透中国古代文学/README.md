# 讲透中国古代文学 · 三千年文体的连续实验场——一代有一代之文学,一代有一代之约束

> **本质一句话**:中国古代文学=从诗经楚辞到桐城派的一部**文体兴替连续实验
> 记录**——每个时代把创作能量集中押注在一种主导文体上(骚—赋—骈—诗—
> 词—曲—小说),而格律与对仗把汉语的**形式可能性**逼到极限:律诗的
> 平仄骨架是"对+粘"两条规则从首句确定性推出的形式系统,对仗是词性
> 桶的组合匹配,"一代之文学"是四条错峰的生命周期。一句话:**王朝会改,
> 文体会老,但语言的形式实验三千年没停过;文学史不是作品的堆栈,
> 是文体市场的能量再分配史**。

## 一、家族定位

- **九支分工**:GB/T 三级即**断代切分**——九支就是九个朝代段的文学现场;
  **主轴 2 支**(隋唐五代/宋代)加厚:唐诗与宋词是形式约束(格律/词牌)
  最成熟、文献与研究成果最厚的两段,家族的方法论主轴(实验三律)以
  唐诗格律与宋词体制为标本;其余七支精简为断代宪法。
- **一条主轴贯穿全家族**:**文体市场的能量再分配**——任何一段文学史
  都可以问三件事:这个时代的主导文体是什么?旧文体退到哪条边缘车道?
  新文体的形式约束(格律/对仗/宫调/章回)把语言逼出了什么?(家族实验
  律三:诗/词/曲/小说四条生命周期峰值错开 200-400 年,重叠期恒有人跨
  双体裁)
- **四段速写法**:九支在章层按"先秦两汉/魏晋南北朝/唐宋/元明清"四段
  组织叙事——断代落支(GB/T 纪律),四段成章(阅读纪律)。
- **零门槛**:不要求音韵学前置;平仄只当作二值约束使用(如"对/粘"),
  不问构拟。想看概念去[文学理论](../讲透文学理论/README.md),想看
  历史骨架去[历史学](../../讲透历史学/README.md)。
- 路线 A(问题派):为什么唐诗以后诗让位给词?→00 §二;一首五律的平仄
  是谁规定的?→00 §七+实验律一;曹雪芹为什么在 1790s 写小说?→清代支
- 路线 B(方法派):00→[隋唐五代支](讲透隋唐五代文学/README.md)→
  [宋代支](讲透宋代文学/README.md)(主轴两支顺读)→其余七支按朝代顺读
- 路线 C(研究派):00→01(文献地图:数字人文/AI 与古典文学)→02(古代
  文论术语怎么进入今天的批评话语)
- 工程师快轨:直接跑 [`experiments/meter_parallel_genres.py`](experiments/meter_parallel_genres.py),再回读 04 章
