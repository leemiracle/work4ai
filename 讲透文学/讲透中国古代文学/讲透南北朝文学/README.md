## 诞生

- **谁/何时**:刘宋谢灵运/鲍照;齐永明(483-493)沈约谢朓王融倡声律
  ("四声八病");梁代萧氏父子(《文选》/宫体);庾信由南入北;北朝乐府民歌入隋唐犹唱。
- **因什么问题**:①四声为什么恰在此刻被发现(佛经转读刺激说为一
  说,通说双录)②声律是成就还是"拘忌"(钟嵘已批"伤其真美")
  ③南北两条声部如何合流(庾信案)。

## 核心问题

**已解决(通说)**:永明体→近体诗的直系(声律说即律诗生成语法奠基,
  家族律一"对/韵"规则的雏形在此);《文心雕龙》《诗品》在本期成书(方法论归批评家族,文字提及);宫体的工艺积累为唐诗储存语言零件。

**未解决/深水区**:"八病"的具体指认(史料互异,不逐一坐实);宫体
  的再评价(淫靡论/工艺论,双录);北朝文学的独立价值评估。

## ✨ 这支最美的一个事实

**先发现物理,再造语法**:公元 5 世纪末,沈约们意识到汉语声调是
一个可分离的系统(平上去入),并在十几年内把它装进诗律。此后一千
年,中国诗歌运行在一条**被人工发现的语音轴**上——如同先发现电磁
波再发明无线电。律诗不是慢慢长成的,是一次语音学发现的技术转化。
