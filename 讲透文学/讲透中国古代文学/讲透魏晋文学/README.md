## 诞生

- **谁/何时**:建安(196-220,三曹七子,五言腾涌);正始(240-249,
  阮籍《咏怀》/嵇康);西晋太康(三张二陆两潘一左);东晋(兰亭/
  玄言诗/陶渊明 405 弃官归田)。
- **因什么问题**:①文人诗从乐府集体歌唱中独立意味着什么(自觉
  之问)②风骨为何成于丧乱(气候与骨力的耦合)③陶渊明为何当世
  只有中品(接受史之问——本支招牌问题)。

## 核心问题

**已解决(通说)**:建安风骨的定义链(情感力度+语言骨力+丧乱气候;唐
  人陈子昂以"汉魏风骨"复古);五言完成文人化;陶的接受史定位(钟嵘中品→萧统编集→苏轼推尊,迟到三百至九百年)。

**未解决/深水区**:"文学自觉"的起点(魏晋说/更早说,双录);陶的
"真"与自我塑造(《五柳先生传》的自传策略);玄言诗"淡乎寡味"
(钟嵘语)的评价是否公允。

## ✨ 这支最美的一个事实

**迟到三百年的经典**:陶渊明在钟嵘《诗品》里位列中品;三百年后
萧统为他编集作序,九百年后苏轼说"吾于诗人无所甚好,独好渊明之诗"
(通说引),陶这才登上极峰。**作品原地不动,裁判换了三拨**——
文学史的评分表不在当代,经典化是作品与后世读者的相遇史。
