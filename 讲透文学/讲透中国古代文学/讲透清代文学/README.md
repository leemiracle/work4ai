## 诞生

- **谁/何时**:清(1644-1911;本支止于清中叶,1840 后归近代,断限纪律)。
  清初遗民文学;康熙朝(《聊斋》/《长生殿》1688/《桃花扇》1699);乾嘉(袁枚性灵/姚鼐桐城定型/程高本 1791);嘉道间龚自珍(1839,跨限注明)。
- **因什么问题**:①顶点(红楼)为何出现在王朝盛极转衰处(错位之问——律三:小说峰 1693)②"义法"为何能统治两百年(最简立法之问)③版本为何自己长成学问(红学之问)。

## 核心问题

**已解决(通说)**:红楼的文本双层结构(脂抄八十回与程高后四十回并传,
  版本批评的教科书现场);桐城"义法"极简立法(义=言有物,法=言有序;姚
  鼐合义理考据辞章);清词中兴(边缘车道复兴——复线论强证据)。

**未解决/深水区**:后四十回的评价(红学永久战场,双录);曹雪芹家世与脂本关系(考证持续);桐城派评价(义法之严 vs 文章之美,双录)。

## ✨ 这支最美的一个事实

**未完成的顶点自成一门学问**:前八十回与后四十回拼成一部"完成的未
完成"——脂批提示的佚稿(狱神庙/悬崖撒手)永远悬置,而正是这个断口
生产了红学:版本学/曹学/探佚学围绕一条断口建成一座学科。**残缺成为
生产性结构**:每个世代都在断口处续写自己的结局想象。
