## 诞生

- **谁/何时**:明(1368-1644)。前中期四大奇书先后定型刊行(三国嘉靖
  本 1522 系通说节点);中后期:后七子复古→汤显祖高峰(《牡丹亭》
  1598)→公安三袁(性灵说)→竟陵派→拟话本工程(1620s 前后)。
- **因什么问题**:①章回小说为何在明代登顶(媒介之问:刊刻商业化)②复古与性灵之争在争什么(格套是资产还是债务)③"奇书"经典化怎么完成(选目/评点/刊本)。

## 核心问题

**已解决(通说)**:章回体体例要件(回目对句+说书人套语+悬念收尾);
  四大奇书的累积成书(史传-说话-平话-刊本的层累定型,通说显学);
  公安派对七子拟古的直接反叛(反复古阵营的通说定位)。

**未解决/深水区**:《金瓶梅》作者"兰陵笑笑生"之谜(诸说并存);各奇
书成书年代与祖本(版本学持续工程);复古运动的评价(两面,双录)。

## ✨ 这支最美的一个事实

**"情不知所起,一往而深"**:汤显祖《牡丹亭·题词》(1598)给"情"下了
不问来源、不设边界的定义,让杜丽娘为情而死、为情再生——在理学秩序的
世界里,剧场把"情"立为超越生死的本体。**复古派在梦里回到盛唐,汤显
祖在舞台上发明了未来**:两极都是对"当下不够好"的回答。
