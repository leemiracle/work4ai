## 诞生

- **谁/何时**:元(1271-1368;文学史通常自金亡 1234 起算前史)。元曲
  四大家说系周德清《中原音韵》提名、后人定型(通说);散曲由金诸宫调
  与民歌汇流;南戏元末《琵琶记》定型;诗文有元诗四大家。
- **因什么问题**:①剧场综合文体(曲白科)为何在元代成熟(制度之问)②衬字的弹性意味着什么(曲牌语法比词牌宽在哪)③《赵氏孤儿》18 世纪西译的最早出海案(归比较文学侧,文字提及)。

## 核心问题

**已解决(通说)**:杂剧体制(四折一楔子/一人主唱/宫调-曲牌联套)的完整
  规范;散曲与剧曲的分野(抒情与叙事共用曲牌而功能不同);书会才人的
  身份(文人下移与市井合流,关汉卿"驱梨园领袖"自述,《不伏老》,通说)。

**未解决/深水区**:关汉卿生平与剧作真伪(史料稀缺);杂剧衰落的解释
(明初生态变迁诸说并存);散曲"豪放/清丽"二分的有效性(与宋词二分同构)。

## ✨ 这支最美的一个事实

**制度把文人搬进剧场**:科举停废,仕进关闭,文人流向书会为勾栏写戏
——关汉卿自署"普天下郎君领袖,盖世界浪子班头"(《不伏老》,通说)。
**一代之文学有制度发动机**:谁给天才发薪水,天才就造哪种文体;曲的
市井声口,是被制度改道的天才的声口。
