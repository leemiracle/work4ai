- **谁/何时**:辽(907/916-1125)汉契丹双轨文献;金(1115-1234):借才

## 核心问题

**已解决(通说)**:诸宫调的枢纽地位——同一故事(西厢)从唐传奇→诸宫调
  (说唱)→杂剧(王实甫)的体裁接力,长篇音乐叙事逐级成型;元好问的
  三重身份(丧乱诗人+词人+批评家);《中州集》"以诗存史"的方法论。

**未解决/深水区**:辽文学的独立评估(史料过少的根本限制);董解元
生平几乎无考(存疑处不虚构);金源文化与汉文化的融合度测量。

## ✨ 这支最美的一个事实

**底本比成品早一百年**:王实甫《西厢记》的伟大常被当作天才的突降;
但底本——董解元《西厢记诸宫调》——早一百年就把同一故事的叙事、曲牌
联套与人物加工完成大半(通说:王实甫是董西厢基础上的创造性转化)。
**新文体不是发明,是装配**:零件在过渡带车间试装完毕,杂剧是总装下线。
