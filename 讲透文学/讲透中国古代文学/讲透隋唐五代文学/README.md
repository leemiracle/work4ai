## 诞生

- **谁/何时**:隋一统(581)至五代终(960)。初唐四杰/陈子昂;盛唐(713-766,
  李杜王孟高岑,通说断限);中唐韩孟/元白/柳刘;晚唐小李杜;唐传奇盛于中唐;词起于晚唐五代(温庭筠→《花间集》940→李煜)。
- **因什么问题**:①格律为何在此时定型且定型反而放大表达(律一:骨架确定,自由位集中)②盛唐气象是风格还是气候 ③诗的全盛期为何同时是词的起点期(律三:诗峰 761,词峰 1139,重叠期 942-1302 恒有跨界者)。

## 核心问题

**已解决(通说)**:律诗四式谱与拗救系统的完备(沈宋以来定型说;律一给出
  程序化推导:对+粘+韵句限定从首句推出四式,变体额度 2^16);古文运动纲领
  (文以明道+反骈俪);词的起源(倚燕乐而起,温庭筠为鼻祖,敦煌曲子词民间层并存)。
**未解决/深水区**:李杜之争(仙圣并尊,双录);盛唐气象成因诸说并存;新乐府的讽谕效力与艺术性张力;唐传奇与章回小说的关系强度(话本另有源头说为主,通说)。

## ✨ 这支最美的一个事实

**一次起式,全篇确定**:五律八句的平仄不需要逐句决定——首句句式
一起,对(联内偶位相反)与粘(联间偶位相承)两条规则就把其余七句
**唯一地**确定;四式标准谱是四种初值的轨道,与王力《诗词格律》通行
谱逐句相符(律一实测:推导无搜索,枚举可验证)。**唐诗的"自由"住
在一个封闭系统里**:一三五不论只买到 2^16 个变体,避孤平/避三平调再砍
一刀——巅峰的秘密是约束最紧而表达恰好挤得进去。
