## 开篇:为什么古文论读着像诗话,算起来像代码

新手有两个相反的困惑:一是"风骨/气韵/意境这些词好像都是感觉",
二是"平仄/对仗/词牌又精确得像法律条文"。两个困惑同源:这门学科的
语言在**评论侧**与**形式侧**按两套规格运行——评论词来自历朝诗话
的印象式传统(点悟式,不定义),形式词来自声律与体制的规则传统
(推导式,可检验)。本章三栏 X 光:先查文论术语户口(第一栏),
再看这门学科罕见的另一半——**它的量**(第二栏),最后追踪这批词
如何进入今天的日常批评并变形(第三栏)。四段速写贯穿:每个术语
与每种文体量都标注它的朝代段(先秦两汉/魏晋南北朝/唐宋/元明清)。

## 一、第一栏:文论术语——构念的户口本

**先答为什么**:古文论术语不是描述词,是**品第的快捷方式**——说
某诗"有风骨",等于同时执行了"情感力度+语言骨力+时代气候"三重
判断。术语的麻烦在于:多数诞生于诗话的印象传统,**定义从来不给全**,
靠例诗参悟。本家族十四个高频词:

| 构念 | 一句话定义 | 判断工序(思想操作化) | 血统 | 常见误用 |
|------|-----------|---------------------|------|---------|
| 风雅颂 | 诗按功能的三分(地方/朝堂/宗庙) | 按歌唱场合与功能归类,不按题材 | 先秦(诗经) | 当作"高雅"的同义词 |
| 赋比兴 | 直陈/比喻/起感的三种手法 | 先辨"直说还是托物还是触景" | 先秦(周礼/诗序,通说) | 把"兴"混同于"比喻" |
| 风骨 | 情感的力度与语言的骨力 | 查情感是否有力、语言是否遒劲 | 魏晋南北朝(建安→刘勰《风骨》) | 当作"文风泼辣" |
| 声律 | 平仄相对相承的音韵规则 | 按四声标注句内与联间关系 | 南北朝(沈约永明体) | 当作"押韵"的雅称 |
| 意境 | 情景交融而成的艺术世界 | 查景语与情语是否互化、有无言外层 | 唐宋定型(王昌龄/皎然→近代王国维) | 当作"意境很美"的空泛赞美 |
| 气象 | 作品整体的规模与气候 | 通篇读后的总体感受能否用"盛唐"级尺度命名 | 唐宋(严羽《沧浪诗话》"盛唐气象"系) | 与"风格"混同 |
| 拗救 | 出句违律后对句的补偿规则 | 指认拗处与救处的平仄对应 | 唐宋(律诗实践,清人总结) | 当作"可以乱写"的许可 |
| 点铁成金/夺胎换骨 | 化用前人语而另出新意 | 指认来处与转化的增量 | 宋代(黄庭坚江西诗派,通说) | 当作抄袭的遮羞布 |
| 别是一家 | 词须守住自身音乐语法的独立性 | 查协律/本色与否 | 宋代(李清照《词论》) | 当作"自成一派"的客套 |
| 以诗为词/以文为诗 | 跨文体语法的移植 | 指认被移植的语法特征 | 宋代(苏轼/黄庭坚) | 当作"创新"的泛称 |
| 当行本色 | 深谙本文体惯例的纯熟 | 查是否守住该文体的看家语法 | 宋元(评词评曲通用) | 与"内行"日常义混同 |
| 谱(词谱/曲谱) | 文体的字数-句式-平仄-韵位四元组 | 按谱填词,逐项核对 | 唐宋起,明清集大成(钦定词谱) | 当作"乐谱" |
| 义法 | 义=言有物,法=言有序 | 查内容有无、次序当否 | 清代(方苞桐城派) | 当作"意义与法则"泛解 |
| 独抒性灵 | 写真性情,反拟古 | 查是否有拟古套语遮蔽己意 | 明代(公安派三袁) | 当作"抒情"的同义词 |

**构念的生存法则**:一个古文论术语要活到今天,过三关——**有例可
指**(诗话给了对照例诗:说"风骨"必举建安)、**有对可反**(能说出
什么不算:绮靡不算风骨)、**有史可续**(后代有人接着用并扩充:
意境从王昌龄到王国维)。三关全过的(风骨/意境/比兴)成为批评硬
通货;"气象"类大词只过前两关,使用时必须附例诗,否则退化为气氛
形容词。

## 二、第二栏:文体量——这门学科用什么数,硬在哪

**先答为什么**:文学史家常说古代文论"只可意会";但形式侧恰恰
相反——**平仄、对仗、词牌、曲牌是显式量,可核对可判定**。这套
量化传统的完备度,直到 20 世纪形式语言与约束求解出现才有对等物。
七个常用"文体量":

| 文体量 | 定义 | 谁在用 | 压缩掉了什么(坑) |
|--------|------|--------|------------------|
| 平仄谱 | 每字平/仄的二值序列 | 律诗创作与校验(四式谱) | 中古音到今音的变迁(入派三声):用普通话读,判平仄会错;须依韵书(平水韵系) |
| 对/粘 | 联内偶位相反/联间偶位相承 | 律诗骨架推导 | 只管偶数位;奇数位的"一三不论"有例外(孤平) |
| 韵部 | 押韵字所属的声调类聚(平水韵 106 部,通说) | 用韵与今昔对照 | 韵部是宋末元初的归纳,与唐音、今音都不全等 |
| 对仗律 | 联内词性/小类相对+平仄相反 | 颔联颈联的工艺标准 | 词性相同不保证语义工整(宽对/工对之别);"合掌"(两句同义)是量不出的病 |
| 词牌语法 | 字数-句式-平仄-韵位的四元组 | 填词(龙榆生《唐宋词格律》式工具书) | 音乐已亡(唱法失传),谱只存文字侧;同牌异体并存 |
| 曲牌+宫调 | 曲牌联套+宫调统辖+可加衬字 | 元曲创作 | 衬字的弹性使"合律"判定比词更宽也更难自动化 |
| 章回体例 | 回目对句+说书人套语+悬尾 | 明清长篇叙事 | 例不等于法:名作常破例(红楼的回目工艺远超通例) |

**反直觉发现(本章铁律之一)**:**文体量是判定的下限,不是评价的
上限**。实验律一证明:四式谱+禁手检查可程序化判定("合律"是可判
定问题),但"合律"与"好诗"的相关性远非一一对应——打油诗可以
完全合律,千古名句可以带拗(崔颢《黄鹤楼》前四句违律而成唐人七律
第一的公案,通说)。**用文体量做评价,等于用语法检查器当主编**;
反过来,完全无视文体量谈"格律束缚天才",等于没读过程序就骂编译
器。两层分开,是本家族的基本功。

**附:三层"可判定"阶梯**(给工程师的定位)

```
合律(平仄/韵)   ── 完全可判定:规则显式,程序可验(实验律一)
对仗(词性/小类) ── 半可判定:词性可自动标,小类相对与合掌需人工
好诗(意境/风骨) ── 不可判定:构念无显式判据,例诗参悟+共同体裁定
```

## 三、第三栏:话语迁移——"风骨/意境/炼字"的日常变形记

**先答为什么**:文论词是压缩包,日常话语拆包时只拿走**词名**、丢掉
**工序与例诗**——于是同一个词在学术与日常两界执行完全不同的程序。
三个样本的全程追踪:

### 样本 1:"风骨"——从建安气象到夸人狠

- **学术原义**:情感力度与语言骨力的合体(刘勰《文心雕龙·风骨》:
  "结言端直,则文骨成焉;意气骏爽,则文风清焉",通说);对标的是
  建安"慷慨以任气"的整体气候。
- **日常变形**:"这记者的稿子有风骨""他打球很有风骨"——多数时候
  只是"有个性/敢说话"的雅化;与"骨力遒劲"的语言标准已无关。
- **变形丢失了什么**:**语言侧的判据**。日常"风骨"只剩人格投射,
  不再检验文字本身的骨力——丢掉这一条,"有风骨"与"有胆量"就
  没了区别。

### 样本 2:"意境"——批评的万能货币

- **学术原义**:情景交融、虚实相生、有言外之层的艺术世界;从王昌龄
  "三境"说、皎然,到王国维《人间词话》"境界"说的千年建构(通说)。
  使用它要能指认:哪句是景语,哪句情语化了景,言外层是什么。
- **日常变形**:"这家餐厅意境不错""这张照片很有意境"——退化为
  "氛围好"的高级替换词;连"交融"与"言外"两个必要工序都不再
  执行。
- **变形丢失了什么**:**层次结构**。意境的本义是多层的(景-情-
  外),日常用法是单层的(氛围);一词被压缩回一层,批评的分辨率
  随之清零。

### 样本 3:"炼字"——从工序示范到玄学话术

- **学术原义**:对单字选择的推敲工序,有标准案例链——"推敲"本身
  出自贾岛(《刘公嘉话》所记"僧敲月下门"事,通说);王安石"春风
  又绿江南岸"改稿数次(《容斋随笔》记,通说);杜甫"语不惊人死
  不休"。炼字=**可展示修改史的选词工艺**。
- **日常变形**:"这句写得真炼字"——常常只表示"用词讲究";更坏的
  用法是玄学化("这个字有禅意"),把可展示的修改工序变成不可复核
  的神秘直觉。
- **变形丢失了什么**:**可展示的修改史**。炼字的证据是"改"——
  能摆出备选字与优劣理由的才算炼字;摆不出的,只是把修辞效果倒推
  成作家苦功的事后追认。

**迁移的通则**:文论词日常化 = 词名存活 + 工序死亡 + 例诗失踪。
判断一个日常用法是"活用"还是"误用",看它是否还保留**原工序的
任一步**(能不能指出景与情的交融处?能不能摆出备选字?)——一步
不剩,就是冒名顶替。这个通则与文学批评家族的"话语迁移"分析同构
(那边样本是"细读/解构/政治正确",文字提及)。

## 四、规范化:术语对译与古今接轨

古文论词进英语学术界,对译是硬仗(读国际文献的最低装备):

| 原文 | 通行译法 | 易错点 |
|-----|---------|--------|
| fenggu | wind and bone(直译渐成惯例) | 不是"风格";力与骨的合成构念 |
| yijing / jingjie | artistic conception / poetry-world(王国维"境界"多译 jingjie) | yijing≠"意义";jingjie 不宜径译 realm 了事(译法之争见汉学界) |
| feng ya song | Airs, Court Hymns, Eulogies(雅各布译名系,通说) | "雅"≠elegant;是朝堂功能类 |
| fu bi xing | exposition, comparison, affective image | 兴不是比喻,是起感(译 evocation/stimulus 的争论仍在) |
| sao / Chuci | Sao style / Songs of Chu | "骚"带贬义的后起义(骚人墨客)勿混入 |
| gufeng / jinti | ancient style / recent style(古体/近体) | 近体≠新诗;是唐人视角的"近" |
| pingze | level and oblique tones | 二值是近似(上去入=仄;入声今已派散) |
| duilü | parallelism / antithesis | 对仗含平仄相反,单译 parallelism 丢一半 |
| cipai / qupai | tune patterns (to ci/qu) | 不是曲名,是格律模板;音乐已亡 |
| daiyou yidai zhi wenxue | each era has its own literature(王国维命题) | "一代"是文体生命周期,不是朝代(00 §七发现 3) |

另有**古今音接轨**的规范化:平仄依中古音系(平水韵系韵书),
今音(普通话)判定会系统性出错(入声字如"白/独/竹"今读平而实仄,
通说举例);这一条是"用文体量"的第一道门槛,也是 AI 格律校验器
最容易翻车的点(01 章主线 C)。

## 五、一门学科,五种口音并存(批评话语的社会学)

同一首作品——设一首唐人五律(格律精严、颔联写景、尾联言志)——
五种口音给出五张不同处方:

| 口音 | 诊断句 | 看的列 |
|------|--------|--------|
| 格律派 | 首句仄起入韵,颔联"XX"位犯孤平拗而未救——工艺有疵 | 形式判定列 |
| 气象派 | 中二联气象阔大,尾联收束稍弱——盛唐底色,中唐收笔 | 时代气候列 |
| 意境派 | 颔联景语中"孤"字情化,言外有迁谪之感——景情交融的枢纽在一个字 | 意境层次列 |
| 源流派 | 颔联句式出自谢朓某句,点化而未换骨——江西式的"来处"检查 | 互文谱系列 |
| 史料派 | 此诗系年牵动作者行迹考——系年错则"迁谪之感"全成悬想 | 文献考据列 |

**五种口音都对一部分**;但同一篇论文混用口音而不声明,等于批评的
列来回换——读者无法复核你的判据(与文学批评家族"框架声明"纪律
同构,文字提及)。先声明主导口音,再借别的列,是古典文学写作的
纪律。

## ✨ 美之时刻(彩蛋第 5 枚:双规格引擎之美)

✨ **美之时刻 5:一千年前的可判定文本**(极简)
"白日依山尽,黄河入海流"——十字之内,平仄相对、词性相对、句脚
平收,一首合律且对仗的五绝骨架在一个没有"算法"二字的时代被精确
执行。为什么美:**中国诗人先于计算机一千三百年,在写"可判定"的
文本**——格律是显式规范,对仗是组合约束,拗救是补偿协议;这门
学科的语言因此双规格:评论侧如诗话,形式侧如协议。亲历:任取一首
你熟的五律,用第二栏的阶梯给每一联分层(合律?对仗?意境?),体
会"判定"与"评价"在十三个字里如何分工(✍️练习 1)。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:双规格之眼**——听到任何古文论词,先问它住在
哪一侧:评论侧(压缩包,拆开看工序与例诗)还是形式侧(文体量,
按谱核对)?看到任何"格律/对仗"类断言,先问它用的是哪层判定
(合律可判定,好诗不可判定)。两问过后,术语的误用与日常变形
当场现形。

下一章 [`03-可构造与结构.md`](03-可构造与结构.md)——这门以
参悟自傲的学科,哪些对象居然可以严格构造(平仄谱可以,意境很难),
以及文体的日常资产怎么被压进三张结构卡。
