# 讲透近代世界文学史 · 小说的世纪——印刷资本主义与最长的一棒

> **定位句**:这支负责**近代段**(GB/T 7504730:文艺复兴-启蒙-19 世纪):约 15 世纪-19 世纪末(通说),印刷资本主义把方言升格为民族文学载体,长篇小说从"街谈巷语"登上主导体裁之位。家族实验幕一(最长的一棒:23.25)与幕二(思潮波的实证区)的主现场。与现代支分工:**这支是中心的形成与扩张,那边是中心的扩散与多极化**。
> GB/T 13745 75047 世界文学史 · **GB/T 支(7504730)**。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:文艺复兴(但丁-彼特拉克-薄伽丘开线,塞万提斯《堂吉诃德》1605/莎士比亚,通说)→启蒙(伏尔泰/卢梭/歌德《浮士德》与 1827 世界文学谈话,通说)→19 世纪浪漫主义-现实主义长河(巴尔扎克/狄更斯/福楼拜/托尔斯泰/陀思妥耶夫斯基/惠特曼/波德莱尔,通说)。
- **因什么问题**:①印刷市场如何把小说推上主导位(安德森"印刷资本主义",通说)②"文学的世纪"为什么落在 19 世纪(长篇小说的 logistic 大平台,幕一活跃窗 28.5-71.5)③歌德 1827 到《共产党宣言》1848 的观念史为什么恰好落在本段(世界文学观念与文学市场同步出生)。

## 核心问题

**已解决(通说)**:小说兴起的媒介-市场解释框架(印刷/识字/期刊连载/城市读者);现实主义小说的经典序列;浪漫主义-现实主义作为跨国思潮的传播史(幕二实证区)。

**未解决/深水区**:小说兴起的欧洲性与全球平行(同期东亚白话小说"平行兴起"怎么入账,通说比较文学老题);"文艺复兴属中世纪还是近代"的判据之争(02 章标签学样例);帝国与文学市场的关系怎么写(后殖民批判的回投,通说双录)。

## ✨ 这支最美的一个事实

**最长的一棒,且接棒早在鼎盛前**:幕一实测——长篇小说的主导块长 **23.25 刻度,六大体裁之最**("小说的世纪"第一次有了算术表述);更妙的是它的起步:小说萌芽于 t=24.75,**早于骑士传奇的峰值 26.8**——印刷机开动时,骑士传奇正当红,小说还是"街谈巷语"的边缘体裁;两百年后它在交点 t*=34.25 接过主导位。**媒体革命先在旧体裁鼎盛期埋下接棒者的种子**——也是"别把断代当墙"的最佳教例:近代开端线两侧各是传奇的黄昏与小说的黎明,断代线画在交点上才不亏待任何一侧。
