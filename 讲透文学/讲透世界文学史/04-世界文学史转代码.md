# 04 · 世界文学史转代码:把编年动力学搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:世界文学史的谱系左端(03 章)几乎可以无损转码,右端
> 几乎不可转码;三条代码走廊——**体裁接力**、**思潮传播**、**经典层积**
> ——把"每时代有主导体裁""思潮越远越迟越迟越变""经典是层积岩"三个
> 命题变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",世界文学史转代码要解决"**风格化参数的
纪律**":把一段史学语言("19 世纪是小说的世纪")先翻成模型(logistic
参数+交点),再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清
哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条走通了的
走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 史学概念 | 代码化身 | 备注 |
|---------|---------|------|
| 体裁生命周期 | 双 logistic 份额曲线 σ(ra(t−a))·σ(rb(b−t)) | 实验幕一;锚序不锚值 |
| 主导体裁与断代交点 | argmax 曲线族+相邻求交 | 断代从墙变交点(02 章) |
| "一代有一代之文学" | 主导块序列+交接数(对照齐头并进=0) | 通说的全局形式化 |
| 思潮到达时间 | 网络最短路+每跳时距 | 实验幕二;树网风格化 |
| 本土化偏离指数 | 每跳改造当量的平方和累积 | 只增不减:每次接收都在改写 |
| 经典层积剖面 | 禀赋×时代权重 top-K 迭代 | 实验幕三;权重含反转代 |
| 在典率/进出跳变/预测力 | 名单历时的集合统计 | 选集目录可直接实测 |
| 三张结构卡 | 定长字段记录+完整性断言(空格=右端留白,须显式) | 03 章 schema 的机器执法 |

**转不动(红色区)**:

1. **时代精神与断代的终极正当性**:"Zeitgeist""该不该以 1640 断"是
   调动整个解释传统的判断——代码算得出交点,算不出"这个交点配不配当
   断代线"(02 章标签学的地界)。
2. **"世界文学"的定义之争**:总和/流通/市场/选本四说是立场选择,
   模型必须先声明取哪一义(00 章轴线 1),代码不能替你选。
3. **文学性**:远读量的是形态与流量;份额曲线可以给《堂吉诃德》定位,
   不能给它判卷——右端永远是批评的地界。
4. **风格化参数本身**:体裁的 logistic 参数、网络时距、禀赋分布是**骨架
   假设**——换参数,棒长与交点都动(03 章练习 2),转码者必须把骨架写在
   显式假设栏。

**边界的一句话**:绿色区=接力+波浪+层积三引擎,覆盖"编年直觉的校准";
红色区提醒:**转码是文学史的试算器,不是书写的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:体裁接力走廊(生命周期的全机械化)

```
体裁参数表 (a,ra,b,rb) ──双 logistic──▶ 份额曲线族 ──argmax──▶ 主导块序列
        │                                                    │
        └──相邻求交──▶ 断代交点 ──对照模型──▶ 接力 vs 齐头并进
```

- **理论→模型**:体裁份额=双 logistic;主导=argmax;断代=交点(03 章引擎 1)。
- **算法层**:网格扫描 O(G·T)(G=体裁数,T=刻度数,均为百级,毫秒);
  交点用网格符号变化定位,步长即精度。
- **本家族实现**:[`experiments/genres_waves_center.py`](experiments/genres_waves_center.py)
  幕一——断言峰值错列(7.8→83.0)、相邻活跃期重叠段全非空(9.2-22.8)、
  新体萌芽早于旧体峰值(46.5<49.2)、五交点恒夹旧峰后新峰前、
  齐头并进对照交接数=0。
- **真实系统**:**类型生命周期管理**(内容平台的类型兴衰:把每个内容
  类型当一条 logistic 线,断代交点=排期换挡信号);"**一代有一代之主导**
  "的 A/B 检验(任何"某类型已死/将兴"的断言,先画出它的曲线与交点)。
- **性能工程要点**:全部闭式,微秒级;工程价值不在算力在**参数纪律**
  ——(a,ra,b,rb) 表必须版本化(换参数的棒长不可比);平台数据充足时,
  风格化参数可由实测份额(标签占比/产量)拟合替换,拟合用两点定参
  (峰值时刻+半衰带宽)即可起步。

### 走廊 2:思潮传播走廊(波动力学的全机械化)

```
文学圈网络(中心+路线×环) ──每跳时距 U(6,10)──▶ 各站到达时间
        │                                            │
        └──每跳改造当量 U(0.06,0.18) 平方和累积──▶ 偏离指数
                                                     ▼
                            单调性断言 + r(到达,距离)/ρ(偏离,距离)/r(到达,偏离)
```

- **理论→模型**:到达=路径时距和;偏离=路径改造当量平方和开方(只增不减
  ——每次接收都在改写,03 章引擎 2)。
- **算法层**:树网上就是前缀和,O(边数);一般网络用最短路(Dijkstra),
  逐跳 RNG 保证可复现并行(每波独立 Random(seed+wave_id))。
- **本家族实现**:同实验幕二——断言三波各环均值逐环严格增大(浪漫主义波
  7.92→16.74→24.84→32.46→40.39;偏离 0.116→0.284),汇总 r=0.986/
  ρ=0.903/0.869。
- **真实系统**:**发布波规划**(功能/风格/规范的分圈发布:内环灰度→逐圈
  放量,到达时间=各圈稳定时点,本土化=各圈配置差异——"越远越迟越迟越变"
  的工程版);**技术采用监控**(一项技术各团队的到达时间与改造度统计,
  偏离指数高的采用=本土 fork 信号)。
- **性能工程要点**:注意**偏离只增不减**的设计——它编码"每次接收都在
  改写";若业务里改写可逆(配置可回收),累积量会高估偏离,先声明语义。
  真实文学圈网络的边须由翻译史/引用数据重建(幕二的树网是风格化脚手架),
  除偏与口径声明见比较文学家族 01 章(登记不全是体系不平等的镜像)。

### 走廊 3:经典层积走廊(重估地质学的全机械化)

```
作品库(禀赋 s_i × 价值侧写 v_i) ──每代权重 w_t(含反转代)──▶ 打分
        │                                            │
        └──top-K 入典 ──▶ 12 代名单 ──▶ 层积剖面/跳变/预测力/冲击检验
```

- **理论→模型**:得分=BASE_W·s+ALIGN_W·⟨w_t,v_i⟩+噪声;经典集=每代
  top-K;禀赋是"基岩"的构造输入(03 章引擎 3)。
- **算法层**:每代排序 O(N log N),N=作品数(60 到百万级皆可);
  剖面统计 O(N·T)。
- **本家族实现**:同实验幕三——断言核心层进出跳变 0.00 对搅动层 3.38、
  单代预测末代平均 0.614(最大 0.80>随机 0.33 但远非全预测)、核心层
  生存率 1.00 对首代名单 0.80、反转代核心在典率 1.00 而外围重叠 0.40。
- **真实系统**:**热榜层积审计**(推荐热榜/歌单/书单的地质学:把榜单
  历史按层积剖面读——核心层大=榜单老化(需主动重估),搅动层大=榜单
  健康;反转代实验=运营改权重前的压力测试);**正典化监控**(获奖/入选
  名单的历时对比自动化,单次冲击翻不动核心层——组织变革同理:一次换血
  换不掉基岩,连续加压才会)。
- **性能工程要点**:top-K 用堆把每代降到 O(N log K);**结果对 ALIGN_W
  敏感**(alignment 项压过禀赋项时核心层消失——幕三调参实录:ALIGN_W
  1.15 时核心层与搅动层混层,0.9 才分层),上线前做 ALIGN_W 扫描,
  把"基岩/偏好"的权重比写进配置而非硬编码。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:类型生命周期管理——把"一代有一代之主导"当运营参数

给每个内容类型维护一条份额曲线与两个数:当前主导块还剩多长、下一个交点
在哪。收益:类型排期从经验直觉变成曲线外推;"某类型复兴"的提案先过
logistic 检验(新曲线萌芽于旧主导鼎盛期吗?——幕一的"新体萌芽早于旧峰"
是复兴的必要条件模型)。

### 落点 2:发布波规划——分圈放量,本土化计入偏离

灰度发布即思潮传播:内环(公司)→中环(种子用户)→外环(全量)。两个
可测数:各圈到达时间(稳定时点)与各圈改造度(配置偏离)。要点:偏离
只增不减是常态(各圈都会本地化),规划的不是"零偏离"而是"偏离可控"
——超过阈值的圈标为 fork 候选。

### 落点 3:热榜层积审计——榜单的地质学体检

对任何 Top-N 榜单(热榜/精选/里程碑)按幕三统计:核心层占比(长期在榜)、
搅动层占比(进出频繁)、单期名单对长期的预测力。诊断表:核心层过大=
老化(该主动重估了);无核心层=纯噪声(榜单没有权威性);反转压力测试
=把权重倒转一次,看哪些条目岿然——那就是榜单真正的"基岩"。

### 落点 4:编年数据的分账纪律

接 01 章主线 E:工程侧做量化文学史(词频/标签/产量曲线)时,与书写叙事
**分库分账**——计数库答"什么在涨落"(幕一幕二的实测侧),叙事库答
"这意味着什么时代"(右端);两库可以互相标注,禁止互相冒充(份额曲线
不判文学性,词频不判断代正当性)。
