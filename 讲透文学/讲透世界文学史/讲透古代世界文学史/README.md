# 讲透古代世界文学史 · 文明的第一棒——史诗时代与轴心并世

> **定位句**:这支负责**古代段**(GB/T 7504710:美索不达米亚/埃及/希腊罗马/古印度):从文字之初到罗马帝国倾覆(通说约 5 世纪),诸文明各自点燃文学、并世而几乎不相识的编年。家族实验幕一(接力的第一棒)与 00 章"轴心并世"的主现场。与中世纪支分工:**这支是起源与同构(各自点火),那边是并存与前夜(三大传统并立)**。
> GB/T 13745 75047 世界文学史 · **GB/T 支(7504710)**。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:《吉尔伽美什》(两河,通说标准版前 1 千年纪定本)与埃及文学(《亡灵书》等,通说)→希腊(荷马/萨福/雅典悲喜剧)→罗马(维吉尔《埃涅阿斯纪》/奥维德)→古印度(吠陀/《摩诃婆罗多》《罗摩衍那》/迦梨陀娑《沙恭达罗》,通说)。
- **因什么问题**:①文学为什么在几条大河文明各自独立开始(起源之多中心)②第一个大体裁为什么是史诗(口头程式与记忆技术,通说)③轴心时代诸文明"没有联系却有同构"怎么解释(雅斯贝尔斯命题,通说+反方双录)。

## 核心问题

**已解决(通说)**:史诗作为第一个主导体裁的编年地位(幕一第一棒,主导块 11.25);主要文明的经典序列与文本定型史;希腊罗马与印度文学对后世传统的"经典供给"地位。

**未解决/深水区**:并世同构的解释(传播论/独立发生论/人类条件论三派对峙,通说双录);埃及文学为何长期缺席通行叙事(轴线 2 的古代版);口头的史诗与书写的史诗如何在一个编年里记账。

## ✨ 这支最美的一个事实

**接力的第一棒在自己鼎盛期就孕育了接棒者**:幕一实测——史诗份额峰值在 t=7.75(编年轴第一个主导块),而下一棒**悲剧 t=4.5 就已萌芽**,早于史诗峰值三格还多:雅典的悲剧场在史诗吟诵传统仍是"文学本身"的年代就已开演(通说:悲喜剧以史诗为上游)。**接棒不是等前棒跑完才起跑,而是在旧体裁如日中天时从它怀里长出来**——第一棒如此,棒棒如此(六个新体裁的萌芽全部早于前一棒峰值)。
