> **定位句**:这支负责**现代段**(GB/T 7504740:20 世纪至今,含当代):现代主义从欧陆都会出发全球旅行,后殖民写作把帝国语言翻面,魔幻现实从拉美反向输出,诺奖与翻译流通织成**第一个真正的全球文学市场**。家族实验幕二(波与改写)与幕三(经典层积)的主现场。与近代支分工:**那边管中心的形成与扩张,这支管中心的扩散、改写与多极化**。

## 诞生

- **谁/何时**:现代主义(乔伊斯《尤利西斯》1922/卡夫卡/普鲁斯特/伍尔夫/艾略特《荒原》1922/福克纳,通说)→中期分流(拉美文学爆炸:博尔赫斯-马尔克斯《百年孤独》1967/略萨,通说)→后殖民与全球南方(萨义德《东方学》1978 开理论线;阿契贝《瓦解》1958/恩古吉/拉什迪/库切;诺奖序列如 2021 古尔纳,通说)→当代全球文学市场(翻译流通/多极入史,通说)。
- **因什么问题**:①现代主义为什么几乎同时点火于欧陆多城又全球扩散(波动力学的百年样本)②后殖民写作如何把帝国语言变成批判武器(改写的自觉化)③全球市场时代"经典"怎么形成(诺奖/选集/课程的正典化机器,幕三现实版)。

## 核心问题

**已解决(通说)**:现代主义经典序列与时间窗(约 1890-1945);后殖民理论的文学建制;拉美"文学爆炸"的传播个案(幕二魔幻现实主义波的原型参照);诺奖体系作为正典化机器的机制描述。

**未解决/深水区**:全球南方入史的重写方案(01 章主线 B 主战场);"当代"怎么断代(没有下一棒可参照:电影叙事交点 t*=76.75 之后谁接棒);世界文学市场的多中心化(英语枢纽地位的变迁,通说讨论中)。

## ✨ 这支最美的一个事实

**越是后来者,越是改写者**:幕二实测——魔幻现实主义波从拉美出发,第 1 环平均偏离指数 0.125,第 5 环(全球圈)0.303,到达越迟偏离越大(r=0.869)。文学史的对应:各地的"魔幻现实"接的是自己的传统——印度的接史诗,非洲的接口述,东欧的接政治寓言——**没有一个"魔幻现实主义"是拉美的复印件**(通说)。这句模型读数就是本支的世界观:现代文学史不是影响的单向输出,是**一圈圈本土化的改写接力**;研究传播与研究改写是同一件事的两面(与比较文学的变异学互证,通说)。
