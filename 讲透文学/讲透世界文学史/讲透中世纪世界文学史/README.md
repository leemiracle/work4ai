# 讲透中世纪世界文学史 · 多个世界文学——三大传统并世而不相识

> **定位句**:这支负责**中世纪段**(GB/T 7504720:欧洲/阿拉伯-波斯/东亚):约 5-15 世纪(通说),欧洲、阿拉伯-波斯、东亚三大文学传统各自登峰,却几乎没有相互认知——**中世纪不是"一个世界文学的停顿",是"多个世界文学的并存"**。家族实验幕二(传播波)的反读区:距离即隔绝。
> GB/T 13745 75047 世界文学史 · **GB/T 支(7504720)**。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:欧洲(但丁《神曲》/骑士传奇(亚瑟王圈/特里斯丹)/冰岛萨迦/谣曲,通说)∥阿拉伯-波斯(《一千零一夜》成书/菲尔多西《列王纪》/鲁米/哈菲兹,通说)∥东亚(白居易文集东传日本/平安物语(《源氏物语》)/和歌/唐宋诸体,通说)——三线并世。
- **因什么问题**:①为什么三大传统彼此几乎不相识(但丁不知《源氏物语》,通说举例)——网络未通时代"世界"的边界由什么画 ②宗教与抄本如何塑造各传统的体裁选择 ③"并存的多元"怎么写进一部编年(轴线 2 的中世纪版:欧洲标签最不适配的一段)。

## 核心问题

**已解决(通说)**:三大传统各自的经典序列与高峰期;东亚"汉字文化圈"的传播(白氏文集东传为标志个案);骑士传奇作为幕一第三棒(主导块 13.25)的编年地位。

**未解决/深水区**:并世的编年书写方案(并陈式/联通式/多轴式,各有代价);"中世纪"标签对东亚的适用性(唐宋被称"中世",通说争议);三大传统后来的相遇账怎么记(近代支与幕二的接力课题)。

## ✨ 这支最美的一个事实

**距离即隔绝——到达时间为∞的传播波**:幕二模型里,思潮第 5 环平均 t=39.4 才到达,已算"迟到";而中世纪的三大传统之间网络根本未连通——**到达时间不是迟,是∞**。正读这个∞:12 世纪的日本宫廷读白居易如读经典,却与同代的普罗旺斯谣曲互不知晓;全球航路一通,诸传统瞬间进入同一张网络,"世界文学"(歌德义)才成为可能——**"世界文学"不是文学的默认状态,是网络的成就**(波需要边,边是历史的造物;通说:全球化前史正在本支与近代支的交界)。
