## 一、家族定位

- **四支横切**:同一条世界文学时间轴的四段——**古代支**(7504710:美索不达米亚/
  埃及/希腊罗马/古印度,文字之初到罗马帝国倾覆)、**中世纪支**(7504720:欧洲/
  阿拉伯-波斯/东亚,三大传统并世)、**近代支**(7504730:文艺复兴-启蒙-19 世纪,
  印刷资本主义与小说的世纪)、**现代支**(7504740:20 世纪至今,现代主义与
  后殖民的全球文学市场)。
- **一条主轴贯穿**:**长时段编年动力学**——体裁接力(每时代有自己的主导体裁,
  交接有交点)、思潮波浪(越远越迟,越迟越变)、经典层积(重估翻动上层翻不动
  基岩)。家族实验把整条主轴**算术化**(三幕)。
- **零门槛**:读过一部《百年孤独》或一部《荷马史诗》就能进;术语随用随讲
  (三步法:直觉图像→严格陈述→最小例子)。
- 路线 A(问题派):为什么"小说的世纪"是 19 世纪?→直接进近代支;非洲文学
  怎么进的世界文学史?→现代支+00 章轴线 2
- 路线 B(编年派):00→古代(文字之初)→中世纪(多个世界文学)→近代(小说的
  世纪)→现代(全球市场)
- 路线 C(研究派):00→01(去西方中心书写/体系论数据化/量化文学史)→02(时代
  分期的标签学)
- 工程师快轨:直接跑 [`experiments/genres_waves_center.py`](experiments/genres_waves_center.py),
  再回读 04 章
