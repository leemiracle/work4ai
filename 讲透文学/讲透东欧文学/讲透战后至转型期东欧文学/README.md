# 讲透战后至转型期东欧文学 · 铁幕怎么扛——地下出版、流亡与回归

> **定位句**:这支负责**铁幕侧**:1945 年以来的东欧文学怎么在审查建制下续命与自救——社会主义现实主义与 1956/1968 两次松动-收紧循环(通说口径平实叙述),地下出版(samizdat:捷克挂锁丛书/波兰第二流通)与域外出版(tamizdat:巴黎文学研究所/多伦多六八出版社)双通道,流亡作家群(米沃什/什克沃雷茨基/昆德拉),中欧的自我命名(昆德拉《被绑架的西方》1983/1984),转型期的重译热潮、档案文学与世界市场重估(凯尔泰斯 2002/托卡尔丘克 2018 诺奖)。与十九至二十世纪支分工:**那边铸造语种共同体,这支扛住铁幕**。
> GB/T 13745 75077 东欧文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:米沃什《被禁锢的头脑》1953 年在巴黎文学研究所出版(通说);昆德拉《玩笑》1967 与作家代表大会演讲(小民族文学论,通说);1968 布拉格之春后"正常化",哈维尔《无权力者的权力》(1978,通说);赫拉巴尔《过于喧嚣的孤独》1976 年起以 samizdat 流传(通说);昆德拉 1975 流亡,《不能承受的生命之轻》1984(捷克语版由多伦多六八出版社出,通说);1989 剧变,哈维尔当选总统;凯尔泰斯 2002、托卡尔丘克 2018 诺奖;昆德拉 2019 重获捷克国籍(均通说)。
- **因什么问题**:①审查下文学怎么出版(答:双通道——地下传抄+域外印刷)②流亡作家的语种选择(答:换语买西方票、丢母国票)③铁幕倒后回归市场要什么(答:被禁的旧我先回家)。

## 核心问题

**已解决(通说)**:双通道建制事实(出版社/丛书/名单可考);流亡作家队列与语种路径可考;转型期重译潮的出版书目可查。
**未解决/深水区**:档案文学的解释权(秘密警察卷宗的伦理,家族 01 章主线 B);"东欧/中欧"命名之争的终局(00 章争 1);昆德拉的母国争议(00 章争 2 双录)。

## ✨ 这支最美的一个事实

**流亡作家回家时,家里等着的是他离开前的自己**(幕三实测):换语写作的西方接受指数 6.05=母语坚持 2.79 的 2.17 倍,但流亡新作回流母国率只有 18%(母语队列 56%);1989 后被禁旧作的重译热度 6.25=流亡新作回流 2.25 的 2.78 倍,且旧作平均在墙倒后 1.0 年到货,新作要再等 3.6 年——回归市场先要"被禁的旧我",流亡期的新我是第二批货。
