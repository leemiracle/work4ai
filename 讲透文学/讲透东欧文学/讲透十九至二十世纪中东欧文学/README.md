# 讲透十九至二十世纪中东欧文学 · 民族复兴怎么来——用语文学造民族的工程

> **定位句**:这支负责**奠基侧**:约 1790-1945 年中东欧诸民族怎么"用语文学造民族"——波兰浪漫主义在亡国期(1795-1918)把文学变成国土(密茨凯维奇《塔杜施先生》1834),捷克民族复兴从德语书面文化里夺回捷克语,匈牙利有裴多菲的革命诗与马达奇《人的悲剧》;现实主义与两次大战间现代主义全线爆发(显克微支 1905 诺奖/哈谢克《好兵帅克》/恰佩克 R.U.R. 铸 robot/舒尔茨/贡布罗维奇/马拉伊《烛烬》),安德里奇《德里纳河上的桥》(1945)作收束。与战后支分工:**这支铸造语种共同体,那边扛住铁幕**。
> GB/T 13745 75077 东欧文学 · **自定支**(GB/T 无三级明细)。家族:[../README.md](../README.md)

## 诞生

- **谁/何时**:1795 波兰三次瓜分亡国后,密茨凯维奇以《先人祭》(1823/1832)与《塔杜施先生》(1834)立"民族诗人"范型(通说);捷克民族复兴夺回书面语;裴多菲《自由与爱情》(1847)与 1848 革命(通说);显克微支 1905、莱蒙特 1924 诺奖(通说);恰佩克《R.U.R.》(1920)铸词 robot(通说:其兄约瑟夫建议);舒尔茨(1934)/贡布罗维奇(1937)/马拉伊《烛烬》(1942);安德里奇《德里纳河上的桥》战时写成、1945 出版,1961 诺奖(通说)。
- **因什么问题**:①没有国家时民族靠什么存活(答:语言与文学)②小语种怎么接入欧洲文学(答:中介语与翻译——小民族文学卡的中介语层)③小语种能不能长出前卫形式(答:能——形式实验不问语种大小)。

## 核心问题

**已解决(通说)**:各国民族复兴节点与代表作序列清楚;"文学为民族代言"传统(弥赛亚主义/民族诗人)的定型可考;robot 铸造现场可考。
**未解决/深水区**:代言传统的代价(艺术自主 vs 民族义务,家族 00 章争 2 双录);哈布斯堡遗产的怀旧批判(争 1 反题);卡夫卡边界的布拉格三语文化归属(按语言归德语文学,本支只收影响史,文字提及)。

## ✨ 这支最美的一个事实

**亡国民族的文学国土**:波兰在地图上消失 123 年(1795-1918,通说),波兰语文学就是它的政府与疆域——《塔杜施先生》在流亡中写成,写的是故乡立陶宛边地的一天;一个不存在的国家,靠一部长诗保持存在感。家族 00 章开篇从这一站发车:小民族文学的"代言"传统由此定型。

## 假设与依赖

- 买入"语种联盟可解释范畴":按民族语言不按国界(捷/波/匈各成共同体);代价:双语作家与布拉格德语(卡夫卡)要靠边界案处理;代言传统的评价争议一律通说+反方双录;涉瓜分史与两次大战按通说学术口径平实叙述,史学本体归历史学宇宙(文字提及)。

## 教材锚

- 蒋承俊主编《东欧文学简史》及国内通行教材诸本(通说);各国别文学史。现场文本:《塔杜施先生》《你往何处去》《好兵帅克》R.U.R.《鳄鱼街》《费尔迪杜尔克》《烛烬》《德里纳河上的桥》。
