# 讲透东欧文学 · 欧洲的另一个文学——小块语言的共生、铁幕与中欧的自觉

> **本质一句话**:东欧文学=**小块语言之间的共生体**——在俄语与德语两个
> 大语区的夹缝里,波兰语/捷克语/匈牙利语/南斯拉夫诸语每种只有几百万到
> 几千万人使用(小民族文学:市场太小,文学被迫替民族保管语言与记忆,
> "文学为民族代言");二十世纪被铁幕切成两半,地下出版(samizdat)与
> 流亡出版社(tamizdat)成了它的第二出版体系;1989 年后它以"中欧"
> 重新自我命名(昆德拉《被绑架的西方》,1983 法文初刊/1984 年英译
> 流传,通说)——一句话:**小块语言,大写文学;铁幕切得开市场,
> 切不开共同体**。
>

## 一、家族定位

- **两支分工**:同一条共生体的两段——**十九至二十世纪中东欧支**(民族
  复兴怎么"用语文学造民族":波兰浪漫主义/布拉格与布达佩斯的现代主义,
  到 1945 收束)与**战后至转型期支**(铁幕怎么切、地下出版与流亡怎么
  续、1989 后怎么回归)。
- **一条主轴贯穿**:小民族文学(民族复兴为文学立法,文学即民族的语言
  国土)→铁幕与地下(官方出版体系被切开,samizdat/tamizdat 两条民间
  通道)→转型与回归(1989 后重译热潮、档案开放、世界市场重估);家族
  实验把三段全部**算术化**(时滞不对称/网络韧性/双市场回归)。
- **零门槛**:读过一册《不能承受的生命之轻》或《好兵帅克》就能进;
  不要求任何东欧语言,全部用通行中译;要编年全景去
  [世界文学史](../讲透世界文学史/README.md),要苏联文学去
  [俄国文学](../讲透俄国文学/README.md),要跨语机制去
  [比较文学](../讲透比较文学/README.md)。
- 路线 A(问题派):一部小说怎么给全人类捐一个词(robot)?→00 §七
  发现 1 的姊妹题(02 章);地下出版社为什么打不死?→00 发现 2;
  流亡作家回家时家里等着谁?→00 发现 3
- 路线 B(课程派):00→[十九至二十世纪中东欧支](讲透十九至二十世纪中东欧文学/README.md)
  →[战后至转型期支](讲透战后至转型期东欧文学/README.md)
- 路线 C(研究派):00→01(后殖民批评/档案研究/世界市场三前线)→
  02(小民族文学的说话方式)
