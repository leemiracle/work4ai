# 讲透俄国文学 · 替民族保管灵魂的文学——从普希金的太阳到被 1917 切开的三条河床

> 俄国文学=**替民族保管灵魂的文学**——当西欧把终极问题分给哲学与教会,
> 俄国把它们全部交给了文学("文学中心主义":小说替民族做思想诊断,
> "谁之罪/怎么办/活着还是不活"全是文学命题)。三台引擎贯穿二百年:
> **典型引擎**解释它拿人物当病例卡(多余人/小人物/地下室人/奥勃洛摩夫
> 性格——谱系传递,骨架不变病情变)、**全景引擎**解释它拿长篇当社会
> (《战争与和平》式多枢纽共现网络:皮埃尔们是社会的关节)、**命运引擎**
> 解释它拿文学史当政治史(1917 一次性分岔:留下适应/流亡/内部流亡,
> 一条分岔线把一部文学史切成三部)——
> 一句话:**俄国文学的伟大与苦难同源:它太重要,所以它被争抢**。
>

## 一、家族定位

- **两支分工**:同一条大河的两段河床——**十九至二十世纪初支**(奠基与
  巅峰:普希金 1820s→黄金时代→白银时代→现实主义长篇传统的定型)、
  **苏联与当代支**(分岔与合流:苏联时期→流亡三波→解体后)。
- **三台引擎贯穿全家族**:典型(病例卡)、全景(共现网络)、命运
  (政治史切开文学史)——每个俄国文学事实(一个典型人物/一部长篇/
  一位作家的去向)都能在坐标系里定位(00 章 §二、03 章结构卡)。
- **零门槛**:不要求俄语、不要求先读原著(选可靠中译即可入门);要
  叙事学通则去文学理论,要跨国影响考证去
  [比较文学](../讲透比较文学/README.md);本家族管**俄国文学的内部
  结构与它的国家命运**。
- 路线 A(问题派):为什么俄国小说里全是"能看穿自己却救不了自己的
  人"?→00 §七发现 2;为什么一部小说要写五百多个人?→发现 1;
  1917 之后一部文学史怎么变成三部?→发现 3
- 路线 B(课程派):00→十九至二十世纪初支(奠基与巅峰)→苏联与
  当代支(分岔与合流)
- 路线 C(研究派):00→01(文献地图与处境)→02(术语户口与"多余人/
  白银时代"的中文话语迁移)
