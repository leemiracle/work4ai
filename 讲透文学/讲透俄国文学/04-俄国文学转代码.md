# 04 · 俄国文学转代码:把枢纽、谱系与分岔搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:俄国文学谱系的左端(03 章)几乎可以无损转码,右端
> 几乎不可转码;三条代码走廊——**共现网络**(枢纽检测+破碎度对照)、
> **典型谱系**(特征向量的继承-变异+保守率检验)、**路径分岔**
> (一次性窗口检测+轨迹分化+第二峰识别)——把"摘掉皮埃尔俄国就散了"
> "多余人的骨架四代不变""1917 一刀切成三部"变成可跑、可断言、可做
> 参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",民间文学家族要解决"户口化",俄国
文学家族要解决"**结构化**":把一套学科语言("这部长篇人物众多")
先翻成模型(共现-枢纽网络),再翻成代码。翻译的损耗全部发生在第一
步——所以本章先划清哪些对象第一步就走得通(绿色区),哪些走不通
(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 全景长篇的社会性 | 共现网络+度数/介数排序 | 走廊 1(实验律一) |
| 主人公=枢纽 | 定向移除 vs 随机移除的破碎度对照 | 走廊 1 附带(对照实验是灵魂) |
| 典型人物的型号 | 四维特征向量+相似度矩阵 | 走廊 2(实验律二) |
| 型号的遗传与变异 | 继承(不变带)+变异(随机游走)+保守率 | 走廊 2 附带 |
| 1917 分岔 | 分流窗口检测+跨路径流动率 | 走廊 3(实验律三) |
| 三线命运 | 逐年产量轨迹+峰谷结构+分化度 | 走廊 3 附带 |
| 三张结构卡 | 定长字段 schema+完整性校验 | 03 章卡 1/2/3 的直译 |

**转不动(红色区)**:

1. **"俄罗斯灵魂"的总体性**:宗教-思想叙事的总体概念,没有可测
   属性——统计再精也算不出"灵魂深度"(03 章右端)。
2. **复调的审美体验**:巴赫金明确反对把对话性还原为结构;网络算
   得出声部间的连接,算不出声部的"同时在场感"(02 章口音分界)。
3. **1917 分岔的应然评价**:谁该走谁该留是伦理问题;代码只能描述
   分岔结构,不能裁决路径价值(01 章 §七要点 1)。
4. **"伟大"的等级**:正典地位由百年阅读史生成,任何单期指标
   (销量/奖额/被引)都只是影子。

**边界的一句话**:绿色区=网络类+向量类+轨迹类,覆盖"结构直觉的
校准";红色区提醒:**转码是俄国文学的使用说明书,不是它的替身**——
算得出摘皮埃尔网络碎成五块,算不出娜塔莎为什么歌唱。

## 二、代码走廊清单(三条主走廊,每条=史识→模型→算法→真实系统)

### 走廊 1:共现网络走廊(枢纽检测+破碎度对照)

```
场景表 ──共现连边──▶ 邻接表 ──Brandes──▶ 介数排序 ──▶ 枢纽=接线员
    │
    └──对照实验──▶ 定向摘枢纽 vs 随机移除 ──▶ 破碎度差断言
```

- **史识→模型**:全景长篇=多圈子社会+跨圈枢纽(通说出场五百余人的
  《战争与和平》);枢纽的圈子资格即情节通道(婚姻/继承/被俘/从军)。
- **算法层**:连边 O(Σ|场景|²);Brandes 介数 O(V·E)——百人级网络
  毫无压力,万人级换稀疏矩阵与近似介数;破碎度=连通分量+跨组可达率
  (比"最大连通片"更敏感的破碎指标)。
- **本家族实现**:[`experiments/network_types_paths.py`](experiments/network_types_paths.py)
  幕一——断言枢纽度数 4.2× 于非枢纽、介数 top5 全为枢纽;定向摘 5
  枢纽跨圈可达率 100%→0%、碎 5 块,随机移除对照(200 次)仍 100%
  连成一片。
- **真实系统**:组织人脉图的关键连接人识别(谁离职网络就断);推荐
  系统的桥接用户;知识图谱的枢纽实体(百科跨领域节点);小说/剧本
  的改编裁剪决策(保枢纽、裁圈子——翻译删节史的形式化)。
- **性能工程要点**:断言盯**对照差**不盯绝对值(随机移除基线随网络
  密度浮动);场景切分(章/幕/场)是最大的自由度——报告里必须写明
  切分粒度。

### 走廊 2:典型谱系走廊(继承-变异+保守率)

```
型号定义 ──四维向量──▶ 世代传递 ──▶ 相似度按代距衰减断言
    │                        │
    │                        └──保守率(骨架维带内占比)vs 散开度(际遇维)断言
    └──系综:N 条谱系平均(单条家谱是噪声,规律在系综)
```

- **史识→模型**:典型=骨架(不变带,被拉回)×际遇(随机游走);
  命名是追认的,遗传是前瞻的(屠格涅夫 1849 定名→此后作家向型号
  对表)。
- **算法层**:相似度 O(d);系综蒙特卡洛 O(N·代数·d)——便宜;贵在
  **维度选取**(四维卡是约定,换维谱系会动)。
- **本家族实现**:同实验律二——断言相似度按代距 0.895>0.862>0.832
  单调衰减;骨架保守率 97.2%;际遇维散开 3.2×。文学史锚点(通说四
  典型)仅作单次噪声实现展示,断言一律打在系综上。
- **真实系统**:用户画像分层的"型库"(行为骨架稳定、偏好际遇随季
  漂移——两套更新频率);角色系统的成长曲线设计(核心特质锁、环境
  特质漂);品牌人格的代际传递;克隆代码/文档家族的特征继承分析。
- **性能工程要点**:**区分两种维度的更新频率**是本走廊的可迁移内核
  ——把"骨架维拉回带内,际遇维自由游走"写进任何画像/配置系统,
  就同时得到稳定性与适应性;单条谱系不做断言(噪声),断言打系综。

### 走廊 3:路径分岔走廊(一次性窗口+轨迹分化)

```
cohort ──分流年登记──▶ 窗口期/窗口后流动率之比 ──▶ 一次性断言
    │
    └──逐年产量──▶ 三线轨迹 ──▶ 分化度+峰谷结构 ──▶ 第二峰断言
```

- **史识→模型**:1917 分岔=一次性事件(窗口 1917-22,此后换边成本
  极高);流亡线"第二峰"=域外重建读者群(柏林→布拉格/巴黎出版链,
  通说流亡文学分期)。
- **算法层**:流动率 O(人数·年);轨迹平滑 O(年数);分化度=逐段
  极差+两两最大分道——全是线性扫描;苦工在**年表数据**(传记辞典
  与出版记录的结构化)。
- **本家族实现**:同实验律三——断言窗口分流率 285× 于窗口后(流动
  仅 2/90);分岔前三线同源(极差 0.10),分岔后每五年段极差≥0.15、
  两两最大分道≥0.6;流亡线 1922 谷 0.74→1930 第二峰 1.51(×2.0,
  峰年反超留下线)。
- **真实系统**:人才流失的窗口分析(一次裁员潮/收购后的离职是单峰
  还是长期流失);移民社群的文化再生产(域外"第二峰"=侨民市场的
  重建);平台改版后的创作者分流(留下/迁站/潜水);学术共同体的
  范式分岔史(一次争论把领域切成三支)。
- **性能工程要点**:"一次性"必须给**比率断言**(窗口/窗口后)而非
  绝对数——不同 cohort 规模不可比;轨迹比较先平滑再断言,窗口宽做
  敏感性扫描(00 章 §七练习 4 的反向操作)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:枢纽依赖审计——你的系统里有几个"皮埃尔"?

任何依赖关键连接人的系统(人脉/知识/服务链)都可以跑走廊 1 的移除
对照:定向摘掉你认定的关键节点,与随机移除对照比破碎度。若跨组可达
率崩塌,你有单点故障;若纹丝不动,你以为的关键人物其实可有可无。
注意红区:结构承担≠价值大小——皮埃尔不可替代,但卡拉塔耶夫(度数
极低的农民)才是皮埃尔的转折点。**低度数节点仍可以是高影响节点**。

### 落点 2:画像的"骨架/际遇"双速更新——型库工程

用户/角色/品牌画像分两类字段:**骨架字段**(身份核心,拉回带内,
慢更新)与**际遇字段**(环境响应,随机游走,快更新)。走廊 2 的
保守率/散开度断言直接搬用:骨架字段被短期数据带偏(保守率跌破阈)
时自动校正回带,际遇字段自由漂移。这就是"多余人骨架四代不变"的
配置系统版。

### 落点 3:人才/创作者分流的一次性窗口管理

组织剧变(裁员/收购/改版)是一次性分岔窗口:窗口期内的去留决定
此后数年的三线轨迹。走廊 3 给三个动作:①窗口内主动管理(窗口后
换边成本极高,挽留要趁窗口);②监测"第二峰"(离开者的域外再创
常在 2-5 年后——离队者社区是组织的一面镜子);③三线分开画健康度
(总量指标会把三条不同的轨迹平均成一条假线)。

### 落点 4:文化知识库——俄国文学研究的数字基建

03 章三张结构卡就是数据库 schema:作品-人物-场景表(网络卡)/型号-
世代表(谱系卡)/作家-路径-产量表(路径卡);双人校=标注信度;
删节本对照=版本表。做人文知识库/阅读平台的工程师可直接借用——
字段即元数据标准,红区行(价值判断)禁止入库为数值。

## ✍️ 练习

1. 🐍 在走廊 1 把枢纽的圈子资格从 3-4 个减为 1 个(如库图佐夫只在
   军界):先笔算介数排序会怎么变,再改 HUBS 字典验证——接线员的
   "接线"资格是圈子数买的
2. 🐍 在走廊 2 把不变带 σ(0.45)放宽到 1.5:先笔算保守率断言(≥96%)
   会在哪个量级失败,再改码验证——骨架是纪律买来的,不是天然的
3. ✋ 用落点 1 审计你所在团队/系统:列出"皮埃尔"候选三人,设计
   移除对照的思想实验(不用真跑),写出预期的破碎块数
4. ✋ 用落点 3 复盘一次你经历的组织变动:画出三线(留下/离开/消极
   在岗)的"产量轨迹",找你的"第二峰"在哪年
