## 诞生

- **谁/何时**:1917-1922 革命窗口期作家三分(留下适应/流亡/内部流亡);1922
  "哲学船"(通说);1934 章程化;1954《解冻》;1970s 第三波;1986-88"回归文学"
  (《日瓦戈医生》1988 苏联首发,通说);1991 后流亡史接回国内史。
- **因什么问题**:①一座文学能不能被切成三部(分岔之问)②域外能否长出读者群
  (第二峰之问)③合流之后正典怎么写(重写之问)。

## 核心问题

**已解决(通说)**:
- 分岔的一次性:分流集中革命窗口,此后换边成本极高(家族实验律三:窗口分流率
  为窗口后 285×,流动仅 2/90)
- 流亡线"第二峰":坠谷后域外重建读者群再冲高(1922 谷 0.74→1930 峰 1.51,峰年反超留下线);蒲宁 1933 首获俄语诺奖为标志

**未解决/深水区**:"俄语文学作为连续体"怎么写成正史(三案并立);内部流亡线最缺档案;解体后正典如何定型(家族 01 主线 D)。

## ✨ 这支最美的一个事实

**流亡者不是余波,是再创**:被船送走的人在柏林和巴黎重建出版社、期刊与读者群
——十年后流亡线产量冲出"第二峰",峰年甚至反超留下线(实验律三)。**边境线
切开的是文学的生产结构**:三条河床各自长出高峰,合流带回三部完整历史。
