> 屠格涅夫/陀思妥耶夫斯基/托尔斯泰/契诃夫)、**白银时代**(象征主义/阿克梅/

## 诞生

- **谁/何时**:1820s 普希金立起点;1842 果戈理开全景与小人物两向;1849 定名"多余人"
  /1859 追问"奥勃洛摩夫性格";1865-1880 托/陀双峰;1890s-1910s 白银时代(通说)。
- **因什么问题**:①俄语能否装下当代灵魂(语言之问)②小说能否替民族做思想
  诊断(功能之问:"文学中心主义")③五百人的社会怎么写进一本书(装置之问)。

## 核心问题

**已解决(通说)**:
- 典型谱系可遗传:多余人四代、小人物系列(家族实验律二:骨架保守 97.2%)
- 全景长篇的装置:多圈子+跨圈枢纽,摘枢纽即碎(家族实验律一)
- 复调说:陀思妥耶夫斯基长篇的多声部结构(巴赫金,通说)

**未解决/深水区**:复调的形式化极限(算得出连接,算不出同时在场感);"多余人"
是俄国病还是现代病(跨文明比较归比较文学);白银时代跨 1917 切口的书写权(家族
README §二双录)。

## ✨ 这支最美的一个事实

**一个词走过四代人**:1823 奥涅金打哈欠,1840 毕巧林制造不幸,1856 罗亭雄辩,
1859 奥勃洛摩夫不起床——同一个灵魂换了四种病情;1849 年屠格涅夫才定名,而
命名之后,每一代作家写人都先跟型号对表。**型号是追认的,但追认造出了引力**
——文学像物种一样演化:骨架遗传,病情变异。

## 假设与依赖

- 买入"人物浓缩国民精神";付出:活人被压成四维向量,非典型人物失焦
- 买入"长篇是社会结构的模型";付出:复调的"同时性"算不出;另依赖译本选择——中译丢姓名语法(家族 02 章 §四)
