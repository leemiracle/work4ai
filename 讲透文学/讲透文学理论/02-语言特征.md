> 程度——长什么样?**

## 开篇:为什么文学理论读起来像常识,用起来像外语

新手有两个相反的困惑:一是"'陌生化'不就是写得新奇吗",二是
"同一首诗,形式主义者、叙事学者、文化研究者给出三种毫不相干的
读法,而且互不引用"。两个困惑同源:这门学科的词汇一半来自日常
(故事/情节/隐喻),但它的**构念**是"为回答'文学性栖居何处'
而造的中间变量",且每台定义机器自带一套方言。本章三栏 X 光:先查
构念户口本(第一栏),再看这门学科独有的**量化语法**——文本量
(第二栏),最后跟踪术语的**越狱路线**(第三栏)。

## 一、第一栏:理论术语——构念的户口本

**先答为什么**:理论构念不是描述词,是**压缩包**——每个词背后压
着一台定义机器的一个零件。不懂机器,词就是空的。本家族十二个
高频词:

| 构念 | 一句话定义 | 思想操作化 | 血统 | 常见误用 |
|------|-----------|-----------|------|---------|
| 文学性 | 使文本成为文学的那个东西 | 对"改写试验"的敏感度:换掉什么文学就死了 | 什克洛夫斯基/雅各布森 | 当"文学味道"的日常语;与"文学价值"混同 |
| 陌生化 | 手法使事物陌生、使感知减速 | 同一对象的常规表述与文学表述的加工深度对比 | 什克洛夫斯基 1917 | 译成"新奇/猎奇";当作营销话术的"让人陌生" |
| 自动化 | 手法因习惯而失效 | 重读次数与感知加工量的衰减曲线 | 形式主义 | 当作"自动化技术"的同名异物 |
| 故事/情节 | 事件按发生序 vs 按讲述序 | 双时间线标注:故事时间 vs 讲述时间 | 形式主义 fabula/syuzhet | "情节"日常义(桥段)与术语义(安排)混同 |
| 意图谬误 | 以作者意图为解释依据的谬误 | 文本证据 vs 作者自述的冲突清单 | 维姆萨特-比尔兹利 1946 | 当作"作者不重要";当作不读传记的许可 |
| 张力/悖论/反讽 | 语义的对峙与并置 | 冲突义素的共存结构(外延+内涵的拉伸) | 退特/布鲁克斯 | 日常"有张力"=紧张感;悖论=矛盾 |
| 前景化 | 诗的语言对常规语的系统性突出 | 相对参照语料的频率/结构偏离度量 | 穆卡洛夫斯基 1932 | 当作"被强调了一下" |
| 诗性功能 | 等价原则从选择轴向组合轴的投影 | 韵/律/平行等邻接位置上的等价标记密度 | 雅各布森 1960 | 当作"诗意";与"抒情"混同 |
| 期待视野 | 读者带向文本的前理解框架 | 文类惯例的先验分布;作品对惯例的偏离度 | 尧斯 1967 | 当作"期待心情";丢掉"视野改变"的历史义 |
| 隐含读者 | 文本为阅读预置的位置 | 文本召唤结构(空白/未定点)的清单 | 伊瑟尔 | 当"理想读者/目标读者" |
| 可读/可写文本 | 消费性的 vs 生产性的文本 | 读者重写自由度的分级 | 巴特 1970 | 当"好读/难读"的评语 |
| 作者功能 | "作者"作为话语建构的分类原则 | 署名如何改变文本的流通与解释 | 福柯 1969 | 当作"笔名"研究 |

**构念的生存法则**(与姊妹学科的户口本法则同构——构念不是描述词,
是机器的零件):一个好构念要过三关——**区别效度**(前景化≠
强调,期待视野≠心情)、**解释位置**(挂在哪台机器的哪个零件上)、
**操作化通道**(哪怕暂时没有算法,也要说得出思想操作化)。
"文学性"过第一关就 famously 艰难(伊格尔顿 1983),这正是它至今
是学科第一词的原因:它标记的是**猎捕行动本身**,不是已捕到的猎物。

## 二、第二栏:文本量——把文学变成数的语法

**先答为什么**:文学理论在 20 世纪发生了**测量转向**:争论"什么是
文学"争不出结果,但"这篇文本的词分布长什么样"可以精确回答。
文体学与计算文体学的工作语言因此不是形容词,而是**一小组带名字
的统计量**——文学理论里离工程最近的一栏。

| 量 | 定义 | 测什么 | 暗礁 |
|----|------|--------|------|
| type-token 比(TTR) | 不同词种数/总词次 | 词汇丰富度:同一个词反复出现(词种少)还是常换新词 | **随文本长度衰减**(越写越低),必须标准化(MATTR 滑窗)才可比 |
| 词汇密度 | 实词(内容词)/总词数 | 信息密度:名词动词多=实,虚词多=松 | 依赖分词与词性标注;中文尤甚 |
| 可读性公式 | 词长+句长的加权(如 Flesch) | 阅读难度 | 为英语设计;直接套中文是常见事故 |
| 齐普夫定律 | 词频∝排名的幂律(f∝r^{-s}) | 词分布的整体形状 | 健康文本 s≈1;偏离提示异常(代笔/生成) |
| 高频词剖面 | 最常见 N 词的相对频率向量 | 作者/文体的分布签名 | Delta 的原料;参数(N 的取法)敏感 |
| 情感弧线 | 逐段情感值连成的序列 | 叙事的情绪轨迹 | 情感词典效度;分段的任意性(01 章主线 B 的暗礁) |

**三句行话的翻译**(新手最常撞的三块礁):

1. **"TTR 不可比"**:两篇文本比词汇丰富度,长度不同就没得比——
   长文必然摊薄 TTR。行话"标准化"=改用等长滑窗或曲线拟合法。
2. **"功能词/内容词"**:功能词=语法用的小词(的/了/也/在),
   内容词=指称世界的实词(剑/月/城)。这对区分是**整个计算文体学
   的地基**(实验幕二:指纹在前者)。
3. **"风格是分布性质"**:单句无风格可言,风格是**全文本词频分布**
   的性质——所以风格能算,而"这句写得好"不能算。

**为什么这一栏重要**:它划出了本家族的**可机械化边界**(03 章)
的左端——凡是能变成这些量的对象(作者归属/文类区分/弧线),都能
进实验室;凡是变不成的(这句是否动人),一个字也不要硬算。

## 三、第三栏:话语迁移——术语的越狱路线

**先答为什么**:文学理论是人文诸学科中**流行语产量最高**的一门
——它的词在 20 世纪末经历了一场"大逃亡":从学术期刊逃进报纸、
广告、政治评论与日常聊天。迁移三步:实验室术语→学科行话→公共
语汇;每过一步,词就钝一点。

| 术语 | 学术义 | 日常用法 | 迁移中的失真 |
|------|--------|---------|-------------|
| **叙事** | 叙事学对象:谁讲、怎么看、讲成什么次序(热奈特三层) | "移民的叙事""要讲好故事"——泛化为"说法/宣传" | 丢掉话语层:日常"叙事"只当内容讲,不问谁在讲 |
| **宏大叙事** | 利奥塔 1979:为知识合法性担保的元故事(进步/解放) | "别信那套宏大叙事"=大话/空话 | 从知识论诊断贬为修辞抱怨 |
| **隐喻** | 莱考夫-约翰逊 1980:概念系统的深层映射(时间是钱) | "这只是个比喻" | 从认知结构降为修辞装饰 |
| **陌生化** | 手法使感知减速、恢复事物的可感性 | 营销/设计圈:"打造陌生化体验" | 从感知论降为"新奇感"的同义词 |
| **解构** | 德里达:文本内部指意链的自我松动 | "让我解构一下这个问题"=拆解/吐槽 | 从严格读法降为"批评"的时髦变体 |
| **文本** | 一切可作符号分析的对象(文化文本) | "按文本发"——回到最原始的"文字稿"义 | 完成一次循环:扩张后又缩回原义 |
| **话语权** | 福柯:话语与权力的共生(谁在说、在哪说、算谁说) | "抢夺话语权"=发声机会 | 从分析框架降为阵地名词 |

**反直觉发现(本章铁律之一)**:**术语的流行度与它的可操作度成
反比,与失真度成正比**。"叙事"最流行,于是最失真(人人会用来
指"说法");"前景化"几乎没出圈,于是保住了完整的技术义。一个
词进入日常话语,是这门学科影响力的**证书**,也是这个词学术功能
的**讣告**——理论史因此需要不断造新词(旧词钝了就换:陌生化→
前景化→偏离统计,一茬接一茬)。

**用法**:写论文时,凡用入圈词("叙事""隐喻"),先声明学术义
还是日常义;公共写作反向操作——用日常义前先想一下它的学术户口,
很多"新概念"其实是半个世纪前的旧户口(01 章判读要点 3 的词法版)。

## 四、规范化:术语对译与国际接轨

理论词从希腊语(模仿/净化)、德语(效果史/视域)、法语(可写/延异)、
俄语(陌生化/故事-情节)来,对译表是读国际文献的最低装备:

| 原文 | 通行中译 | 易错点 |
|-----|---------|--------|
| mimesis | 摹仿(模仿) | 与"临摹"无关;指按可然律再造世界 |
| katharsis | 净化(陶冶) | 不是"发泄",是恐惧怜悯的疏泄与澄清 |
| literariness | 文学性 | 勿与"文学性(味道)"的日常义混 |
| ostranenie / defamiliarization | 陌生化 | **勿译"异化"**(alienation 是马克思/卢卡奇的另一个词) |
| fabula / syuzhet | 故事/情节 | 术语义"情节"=讲述的安排,非日常"桥段" |
| foregrounding | 前景化 | 布拉格学派 aktualisace 的英译;勿作"强调" |
| the intentional fallacy | 意图谬误 | fallacy 是"谬误推理",不是"错误观点" |
| horizon of expectations | 期待视野 | 勿作"心理期待";带历史先验义 |
| implied reader | 隐含读者 | 不是"理想读者"(ideal reader 是另一个构念) |
| writerly / readerly | 可写的/可读的 | 顺序勿颠倒(writerly=可写=生产性) |
| différance | 延异 | 德里达生造词(词根差异+延缓);勿译"差别" |
| distant reading | 远读 | 不是"略读";是"以距离换系统"的方法宣言 |
| transmedial narratology | 跨媒介叙事学 | 与产业词"跨媒体 IP 运营"严格分家 |

## 五、一门学科,四种口音并存(语言的社会学)

同一文本——**一首当代诗被教科书收录**——四种口音给出四张不同
诊断:

| 口音 | 诊断 | 处方倾向 |
|------|------|---------|
| 形式主义 | 全诗的动词系统在陌生化:常规搭配被逐处打碎 | 拆手法:哪几处加工最深,感知在哪里减速 |
| 叙事学 | 即便是抒情诗也有"谁在看":聚焦在抒情者还是场景 | 标注话语层:声音与视点的每一次切换 |
| 文体学 | 高频词剖面偏离当代诗参照语料三倍标准差 | 上测量:前景化指标列队,别先谈感受 |
| 文化研究 | "教科书收录"本身就是经典化的权力事件 | 查建制:谁选的、为谁选、挤掉了谁 |

**四种口音都对一部分**;但同一个论证里混用口音而不声明,等于把
诊断开给四台机器轮着付——先定主导话语,再开处方(§三的用法)。

## ✨ 美之时刻(彩蛋第 5 枚:流行词的考古层)

✨ **美之时刻 5:"叙事"的旅行——一个词的两百年往返**(意外)
"叙事"(narrative)从日常词起家,20 世纪 60 年代被叙事学捕获、
磨成技术词(谁讲/怎么看/什么次序),90 年代携带学位逃回公共话语,
如今成为政治评论的第一名词——而它磨掉的正是学术芯:**人人谈
"叙事",无人问"谁在讲、聚焦在哪"**。为什么美:**一个词的出圈
史就是这门学科的权力与代价的缩微胶片**——理论改变公共语言的
方式是贡献词汇,而词汇一旦流通就开始背叛理论。亲历:本周新闻里
找三处"叙事",逐个换回"说法",看句子损失了什么、又暴露了新闻
想借用什么(✍️练习 1)。

## ✍️ 练习

1. ✋ 做"叙事"考古:找本周三处"叙事"的公共用法,各写一句学术义
   的追问(谁在讲?聚焦在哪?次序如何安排?)——美之时刻 5 的亲历版
2. ✋ 取你两段各 300 字的文字(不同场合写的),手工数出 type 数与
   token 数,算 TTR 并比较;再回答:两段长度不等,这个比较合法吗?
   (第二栏暗礁 1 的亲历版)
3. ✋ 体检一段文学评论:数它用了几个入圈术语("张力/悖论/陌生化"),
   逐个查它是否给出思想操作化;全无操作化的,判为"户口本挂空"
4. ✋ 把"AI 生成文本"写成对偶:它同时是什么与不是什么(至少两对,
   参考:作者功能/意图谬误的当代变体),每对给出失效条件

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:三层之眼**——听到任何文学术语,先定位它在
三层装置的哪一层:户口本构念(哪个机器的零件)、测量量(能不能
变成数)、流行语(钝到什么程度);读任何评论,先问它的主导口音
是哪台机器。三问过后,深谈与蹭词当场分流。
