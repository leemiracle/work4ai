# 03 · 可构造与结构:哪些理论对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:文学理论的对象沿一条**可构造谱系**排开——功能
> 序列端**严格可构造**(转移矩阵写得下、合法故事数得清、语法检测
> assert 得了),词频向量与押韵系统同在左端;中间是**半构造**的
> 标注与卡片(时序标注、前景化指标、结构卡);细读判断与审美经验
> 端**几乎不可构造**(只有思想操作化,没有装配学)。全谱系共享
> 三条结构引擎:**语法引擎**(约束压缩)、**分布引擎**(高频词
> 签名)、**投影引擎**(等价类×组合轴);而"理论机器"本身可以
> 被压进三张**结构卡**(叙事语法卡/文体指纹卡/理论定位卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
功能序列 ── 词频向量 ── 押韵组合系统 ── 时序标注 ── 前景化指标 ── 结构卡 ── 细读判断 ── 审美经验 ── 文学性
  │                                                                        │
严格可构造(可断言)                                          几乎不可构造(只有思想操作化)
  └── 写得出、数得清、算得动、能过 assert                   └── 只能在阅读与争论里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:功能
序列的语义是"功能表+转移合法性",输入输出明确;而"这句是否动人"
的语义内嵌于读者的整个经验世界——**测量仪器无法装配测量仪器的
使用说明书**。本章先盘家底,再看三条结构引擎,最后把整台定义
机器压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **功能序列(叙事语法)** | 功能表+相邻转移矩阵+锚定约束;生成=走矩阵,检测=查矩阵 | 低(实验幕一全程可跑) | 语法只回答"可不可讲",不回答"讲得好不好";真实故事的语料标注是苦工 |
| **词频指纹(作者归属)** | 高频词相对频率向量+距离判别(Delta 系) | 低(实验幕二全程可跑) | 训练文本量、文类混杂、题材渗透;司法场景要求极高的错误率控制 |
| **押韵组合系统(诗性投影)** | 语义类×韵部的拉丁方;约束生成+偏差度量 | 低(实验幕三全程可跑) | 真实词库的语义坐标没有现成刻度(词向量是代理);韵的判定(平水韵/新韵)须先声明 |
| **叙事时间线标注** | 双时间线(故事序 vs 讲述序)的对照表 | 中(半构造) | 单元切分带判断;标注者间信度须双人对表 |
| **前景化指标** | 相对参照语料的偏离统计 | 中(半构造) | 参照语料的选择即立场;偏离大≠文学性高 |
| **结构卡(三张)** | 定长字段的记录+完整性校验 | 低 | 坐标定级带主观性;须双人独立定再对表 |
| **细读判断** | 逐句的张力/反讽/空白分析 | 高 | **构造学缺席**——可示范可训练,不可程序化(新批评的功夫正在此) |
| **审美经验/文学性本身** | 只有思想操作化(改写试验/视野改变) | **不可构造** | 定义问题不是测量问题(01 章主线 A 的地基) |

**反直觉发现(本章铁律)**:**学科的名气与可构造性成反比是常态**。
最有名的词(文学性/审美经验/细读)全在谱系右端,最能跑的对象
(功能表/词频向量)名气最小。**右端管洞察,左端管检验**;用右端
对象硬造左端指标(拿一个公式判"文学性指数")是本学科量化研究
的头号失真来源——两头都不是。

## 二、结构引擎 1:语法引擎(约束压缩)

**直觉图像**:故事不是事件的自由串,是**语法约束下的可讲序列**
——约束每加一条,可能的故事空间塌缩一个数量级。

- **数学化身**(实验幕一):8 功能、转移矩阵 T(相邻功能严格按
  固定次序)、锚定约束(加害与加冕必在场)。合法故事=可讲序列
  =64 个;自由排列 8!=40320;**压缩比 630×**(log₁₀=2.80)。
- **三条刚性**:
  1. **次序不自由**:哪怕全部功能在场,次序也只有一种(保序)——
     "战胜→禁令"一步即非法,检测率 100%(千个随机排列零漏检)。
  2. **锚定即半壁**:仅"加害必在场"一条就砍掉一半故事空间
     (2⁷=128→64)——普罗普"故事由加害或缺乏启动"的语法重量。
  3. **扩展有账**:真 31 功能下合法序列仍远小于排列数,但计量
     复杂度上升(2³¹ 量级的子列空间)——语法越富,枚举越贵,
     检测(查表 O(L))却几乎不涨。**生成难、检验易,是语法引擎
     的结构红利**(04 章性能侧再谈)。
- **理论地位**:这是叙事学"普遍语法"纲领在形式侧最干净的一段;
  软的地方在**功能从哪标**——真实文本的功能识别是解释工作,
  模拟里的转移矩阵是我们**指定**的(方法侧问题,文字提及)。

## 三、结构引擎 2:分布引擎(高频词签名)

**直觉图像**:风格不是单句的性质,是**全文本词频分布**的性质
——分布签名稳定到足以判"谁写的",又细微到作者自己都意识不到。

- **数学化身**(实验幕二):作者剖面 p(词)+生成(每篇 200 词
  的独立抽样);判别=余弦最近剖面。实测:全词表 **100%**,删功能
  词只留内容词 **64%**(降 36 个百分点)。
- **三条刚性**:
  1. **指纹在功能词**:内容词属于题材(两位作者同写一话题时分布
     近同),功能词是"不知不觉的签名"——Delta 系方法的全部
     根据这一条。
  2. **签名对噪声鲁棒**:每篇只需 200 词,152 个功能词元已够把
     剖面分到判别满分;信号浓度(高频)压倒抽样噪声。
  3. **签名≠人格**:分布判"谁写的"判不了"写得好不好"——
     引擎 2 的管辖权在归属,不在价值(可机械化边界的红区)。
- **理论地位**:文体学从形容词学科变成测量学科的分水岭;也是
  "意图谬误"的反讽式续篇——**作者死了,分布活着**。

## 四、结构引擎 3:投影引擎(等价类×组合轴)

**直觉图像**:诗性的机制=**约束下的等价选择**——韵律把每步的
可行选项砍窄,但选择若仍发生在语义等价类内,意义毫发无损。

- **数学化身**(实验幕三):64 词排成 8 语义类×8 韵部拉丁方
  (同类近义:类内偏移≤0.5;跨类远义:类中心间距 4)。三种生成器:
  自由诗(选项均值 8.0)/格律诗人(4.5,押韵行=1)/押韵机器
  (只认韵:偏差均值 10.4,≈36 倍诗人)。
- **三条刚性**:
  1. **约束收窄选择**:选项均值 8.0→4.5,熵 3.0→1.5 比特/步
     ——"戴着镣铐"的可计算版。
  2. **等价类保住意义**:诗人的语义偏差锁死在半径 0.5 内
     (max=0.50≤0.5)——镣铐收窄步幅,舞步仍在舞池。
  3. **约束单独不保意义**:押韵机器同样满足韵律约束,偏差却爆表
     ——**投影的双轴缺一不可**:只有组合轴的约束(韵)而没有
     选择轴的等价(义),是打油诗的数学定义。
- **理论地位**:雅各布森 1960 一行公式的可操作化;也是 AI 写诗
  评测的天然框架——生成的文本"押上韵"只是机器的一半,"仍在
  等价类内"才是诗的一半(04 章落点 2)。

## 五、结构卡 schema:把一台机器压进三张卡

**先答为什么**:定义机器的难点在"整体性"——读散落文献难以携带。
结构卡是**有限字段的压缩格式**:字段固定、填空即可复用、可比可查
可补(这是"可构造"在理论层的对应物:卡片本身严格可构造)。

### 卡 1:叙事语法卡(把一个文类的可讲性写成语法)

```
【叙事语法卡】
文类/语料:________(如魔法故事/侦探小说/游戏任务链)
功能表(≤10 条,固定次序):____ → ____ → ____ → ____
锚定约束(必在场/必缺席):________
转移矩阵特记(哪些相邻对被禁止/哪些功能成对出现):________
压缩比量级(合法序列数 vs 自由排列数):________
最短合法序列(两拍故事):________
可构造代理(谱系位置):________
已知争议(如结构 vs 形式之争):________
```

样例(已填,本家族简化普罗普):功能表=禁令→违禁→加害→出发→
交锋→战胜→归返→加冕;锚定=加害与加冕必在场;特记=成对功能
(禁令-违禁)与(交锋-战胜)倾向连袂;压缩比=630×;最短=
加害→加冕;代理=实验幕一;争议=列维-斯特劳斯 1960 批评(固定
次序是叙事者的线性假象,神话的全集才是结构)。

### 卡 2:文体指纹卡(把一个作者/文体的签名写成可检验剖面)

```
【文体指纹卡】
对象(作者/文类/时代):________
特征集(多少维?功能词/字符 n 元组/句长谱):________
参照语料(对照分布):________
距离/判别方法(Delta/余弦/支持向量机等):________
判别成绩与混淆对象:________
消融结果(删功能词后掉多少):________
失效条件(题材渗透/模仿/翻译):________
```

样例(已填,实验幕二):对象=模拟作者 A/B;特征=8 功能词+20 内容词
相对频率;参照=对方剖面;方法=余弦最近;成绩=80 篇 100%;消融=
删功能词跌至 64%;失效=两位作者同题材时内容词无信号、跨题材时
反而内容词先分(指纹与题材的边界要按语料声明)。

### 卡 3:理论定位卡(把一台定义机器钉进 00 章三战线)

```
【理论定位卡】
理论名:________
三战坐标:文本内-外(0-10):___ / 作者-读者(0-10):___ / 语法-阅读(0-10):___
买入假设(≤3 条):________
付出盲区(≤3 条):________
招牌机制(挂引擎 1/2/3 或思想操作化):________
可构造代理(谱系位置):________
盟友/对手(同战线相邻/对角机器):________
一句话鉴定(它救了哪个解释危机):________
```

样例(已填,新批评):文本内 2/作者-读者 0(两端同砍)/语法-阅读
8(读这一篇);买入:文本自足公共物、细读充分、意图与感受皆谬误;
盲区:历史建制、读者差异、经典选目偏见;机制=细读(右端,思想
操作化);代理=无(细读不构造);盟友=形式主义(同为文本内),
对手=接受理论(读者端)/文化研究(文本外);一句话鉴定:救"作者
崇拜与印象式批评"的危机。

**判定流程**(把一个理论主张钉到谱系上):

```
该主张的核心对象能写成功能表、分布或约束系统吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(标注/指标,填空带判断)─▶ 中段:卡片化+双人校,禁止硬算
  └─ 不能(判断/经验/定义)────▶ 右端:思想操作化+论证,禁止压成参数
```

## 六、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| [叙事学与文学性](讲透叙事学与文学性/README.md) | 左端(功能序列)横跨到右端(陌生化的感知侧) | 语法引擎+投影引擎 | 分裂:语法可算,感知不可 |
| [文体学与修辞](讲透文体学与修辞/README.md) | 左端(指纹)到中段(前景化指标);隐喻的认知建模在中段 | 分布引擎+投影引擎 | 高(测量学科化) |
| [数字时代的理论](讲透数字时代的理论/README.md) | 左端方法(远读/计算)回答右端问题(地位/价值) | 三引擎并用 | 中(方法可算,问题不可) |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——功能
表与剖面走计算,时序标注走双人校,细读与审美永远走阅读。
**没有哪支全家可构造,也没有哪支全家不可构造**;文学性本身住在
谱系最右端(定义问题),但这不妨碍左端的三台引擎步步进逼——
两千年猎捕史的当代段,正是左端向右端的持续试探(01 章)。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——把两千年猎捕史装进上衣口袋**(极简)
叙事语法卡验可讲性(哪些序列是故事),文体指纹卡验签名(谁写的),
理论定位卡验立场(哪台机器、什么账单)。为什么美:**它把"读懂
理论"变成"填得出卡"**——可检验性从细读天赋移进表格纪律;三张
卡互相引用(语法卡挂实验幕一,指纹卡挂幕二,定位卡挂引擎),一台
机器的强度与磨损一目了然。亲历:给你最信的一台机器填三张卡
(✍️练习 1),填不出的格子就是你的盲区地图。

## ✍️ 练习

1. ✋ 给接受理论(或任一台机器)填理论定位卡;再给侦探小说填叙事
   语法卡(功能表自拟,锚定约束提示:谜面必在真相之前)——标出你
   填不出的格子
2. 🐍 在实验幕一里把锚定约束改为"只需加害在场"(删加冕):先笔算
   合法故事数(2⁷=128),再改码验证;再用练习 1 的侦探功能表(9 条)
   笔算压缩比,体会"语法越富,压缩越狠"
3. ✋ 给"文体指纹"填消融行:如果把特征集从功能词换成句长谱,你
   预期判别率升还是降?写出理由与验证设计(可用实验幕二改码)
4. ✋ 用 §五判定流程给两个主张定位:"《红楼梦》前八十回与后四十
   回作者不同(可检验)"(左端)与"后四十回续得不如前八十回
   (价值判断)"(右端)——各自的证据该长什么样

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:卡片之眼**——看到任何文学主张,先问三张卡
填得出吗:语法(哪些序列合法)、指纹(什么签名可验)、定位(哪台
机器、什么账单)。以及一问硬指标:**它的核心对象在谱系哪一端**
——左端去算,右端去读,中段填卡双人校。
