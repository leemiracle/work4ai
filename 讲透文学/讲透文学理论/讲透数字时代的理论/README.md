# 讲透数字时代的理论 · 文学性的当代现场——跨媒介、计算与理论之后

> **定位句**:这支负责**文学性的当代现场**:老问题在新对象与新工具前怎么再审——**跨媒介叙事**(叙事范畴出境到游戏/图像小说/互动剧,出境成功则升格为普遍理论)、
> **计算文体学与远读**(文学变成可计算对象:模式换细节)、**理论之后**(伊格尔顿 2003:"大理论"退潮,被搁置的文学性/价值/判断重新开庭)。文学性在此=**媒介与计算中的开放案件**。
> GB/T 13745 75011 文学理论(无三级明细 → **自定支**)。家族:[讲透文学理论](../README.md)

## 诞生

- **谁/何时**:1983 赛义德《旅行中的理论》埋线;2000 莫莱蒂"远读"(NLR 宣言);2002 伯罗斯 Delta;2003 伊格尔顿《理论之后》;2006 詹金斯《融合文化》(产业侧跨媒介);
  2010s 瑞安一系跨媒介叙事学成线;2015 syuzhet 情感弧线之争;2020s 大语言模型把"机器文本的文学性"顶上议程。
- **因什么问题**:①经典只读几百部,结论只对经典有效(规模之问)②叙事范畴是印刷文学的方言还是普遍语法(媒介之问)③理论退潮后文学性、价值、判断怎么重审(后理论之问)。

## 核心问题

**已解决(通说)**:
- 远读作为方法可行:统计模式换单篇细节,文学史级问题(形式的兴衰)可检验
- 指纹方法出圈:作者归属从学术方法长成司法/平台应用(代笔鉴定、AI 检测)
- 情感弧线与经典情节论合流:计算侧供给规模,理论侧供给范畴(检索校准 2026-09-07)

**未解决/深水区**:
- 文学性可否计算判定:DH 说不可操作化即被架空,理论说是范畴错误(《Literariness》2024 之争)
- 后数字批评的范式:VR/AI 环境重画文本内外/作者读者/理论阅读三线(JELL 2024;均检索校准 2026-09-07)
- AI 生成文本的文学性:陌生化以感知习惯为参照,机器没有感知——从哪头成立

## ✨ 这支最美的一个事实

**"放弃阅读"作为阅读方法**:莫莱蒂的远读悖论——要理解文学史,就别细读那么多书;**距离是知识的条件**:不读单篇,才看得见几百部小说同时涨落的形式潮流。细读给你一棵树,
远读给你整片森林的地形图。**"读"与"知"被拆开**——两千年"解释单篇"的学科第一次有了望远镜;而它最猛的批评者也只能承认:不看森林,你连自己在哪棵树上都不知道。

## 假设与依赖

- 买入"文学=可计算对象":语料可代表文学场;付出:幸存者偏差(数字化偏样本)与"模式≠意义"的解释缺口
- 买入"范畴可出境":叙事学范畴可平移到新媒介;平移失败的案例恰好暴露印刷预设(范畴重建才是理论工作)
- 双向依赖:计算侧需要经典理论的范畴,理论侧需要计算侧的规模——单向依赖即退化成工具或玄谈
