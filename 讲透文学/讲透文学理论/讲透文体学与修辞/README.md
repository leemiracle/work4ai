# 讲透文体学与修辞 · 文学性的语言指纹——前景化、平行与隐喻

> **定位句**:这支负责**文学性的语言指纹**:文学凭什么被认出笔迹——穆卡洛夫斯基**前景化与偏离**(诗的语言对常规语的系统性突出)、**平行结构**(等价在邻接位置的叠加)、
> 雅各布森**诗性功能**(等价原则从选择轴向组合轴的投影)、莱考夫-约翰逊**概念隐喻与转喻**(修辞是认知的地基)。文学性在此=**可测量的分布性质**。
> GB/T 13745 75011 文学理论(无三级明细 → **自定支**)。家族:[讲透文学理论](../README.md)

## 诞生

- **谁/何时**:1932 穆卡洛夫斯基《标准语言与诗的语言》(前景化,布拉格学派);1960
  雅各布森《语言学与诗学》闭幕辞(诗性功能公式);1980 莱考夫-约翰逊《我们赖以生存的
  隐喻》(修辞的认知转向);2002 伯罗斯 Delta(指纹可计算)。
- **因什么问题**:①"诗的语言"与普通语言差在哪(偏离之问)②节奏对仗排比为什么有效
  (平行之问)③风格能不能不靠形容词而靠数来刻画(测量之问)。

## 核心问题

**已解决(通说)**:
- 前景化可操作化:相对参照语料的频率/结构偏离(偏离大≠文学性高,但可测)
- 诗性功能一行公式:押韵/格律/对仗/排比=等价投影到组合轴的各分项
- 作者归属看最高频功能词:指纹在分布,不在华彩(Delta;家族实验幕二 100% vs 64%)

**未解决/深水区**:
- 偏离的"好/坏"界线:同样偏离常规,杰作与胡言的判据(价值问题,拒绝测量化)
- 隐喻的计算建模与跨语言指纹的可比性(翻译保留多少签名)

## ✨ 这支最美的一个事实

**指纹在最不起眼的地方**:判"谁写的"最灵的证据不是意象、不是辞藻,而是"的/了/也/在"
这些**没人苦吟过的功能词**——没人会为选"的"还是"也"而失眠,但恰是这些小词的分布把
两位作者判到 100% 准确;删去它们只留内容词,判别力塌到 64%。**作者死了(意图无效),
作者的分布却活着**——代笔鉴定与 AI 检测的全部底气在此。

## 假设与依赖

- 买入"风格是分布性质":单句无风格,全文本词频分布才有;付出:抽样长度敏感(TTR 教训),须标准化
- 买入"参照语料"概念:偏离须有参照系,参照的选择即立场;测量管辖权声明:指纹判归属,不判价值
