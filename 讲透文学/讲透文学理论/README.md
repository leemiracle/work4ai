## 一、家族定位

- **三支分工**:同一门"文学性栖居何处"之问的三种组织法——**叙事学与
  文学性支**(文学性在文本的**机制**:功能序列/话语三层/陌生化)、
  **文体学与修辞支**(文学性在语言的**指纹**:前景化/平行/隐喻)、
  **数字时代的理论支**(文学性在**媒介与计算的新现场**:跨媒介叙事/
  计算文体学/理论之后)。
- **三条战线贯穿全家族**:文本内 vs 文本外(文学性住在哪里)、作者端 vs
  读者端(意义由谁完成)、理论 vs 阅读(普遍语法还是个别文本)——
  每台定义机器都能在坐标系里定位(00 章 §二、03 章理论定位卡)。
- **零门槛**:不要求文学史前置;想读作品去宇宙各家族,想问"美"去
  [美学](../../讲透哲学/讲透美学/README.md);本家族是它们共同的**理论底座**。
- 路线 A(问题派):文学性是什么?→00 章;一个文本凭什么算诗?→叙事学与文学性支
- 路线 B(理论派):00→叙事学与文学性支(机制)→文体学与修辞支(指纹)→数字时代支(现场)
- 路线 C(研究派):00→01(文献地图)→02(理论话语怎么互相翻译)
- 工程师快轨:直接跑 [`experiments/narrative_stylistics.py`](experiments/narrative_stylistics.py),再回读 04 章

## 二、家族树(GB/T 无三级明细 → 自定三支)

```
讲透文学理论/                GB/T 75011(无三级明细 → 自定三支;不设兜底支)
├── 讲透叙事学与文学性/      自定支——理论本体:普罗普功能序列/热奈特时序-语式-语调/
│                             陌生化机制(文学性=文本的机制)
├── 讲透文体学与修辞/        自定支——语言指纹:前景化与偏离/平行结构/隐喻与转喻
│                             (文学性=语言的指纹)
└── 讲透数字时代的理论/      自定支——当代现场:跨媒介叙事/计算文体学/理论之后
                              (文学性=媒介与计算中的新问题)
```

> 三支恰好铺满三条战线:机制支占**文本内**端,指纹支把文本内推到
> **可测量**,数字支迎向**文本外**的媒介与计算挑战——古典纲领
> (模仿/表现)与后现代纲领(解构/文化研究)作为 00 章的历史纵深,
> 不单设支。
