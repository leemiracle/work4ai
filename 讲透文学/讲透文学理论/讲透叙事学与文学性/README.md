# 讲透叙事学与文学性 · 文学性的机制本体——故事与感知的语法

> **定位句**:这支负责**文学性的机制本体**:文学凭什么"工作"——普罗普**功能序列**(故事的固定语法)、
> 热奈特**时序-语式-语调**(话语扭曲故事的三层旋钮)、什克洛夫斯基**陌生化机制**(感知的受阻与更新)。
> 文学性在此=文本的**机制**,不是作者的光环、不是读者的眼泪、也不是文化的回声。
> GB/T 13745 75011 文学理论(无三级明细 → **自定支**)。家族:[讲透文学理论](../README.md)

## 诞生

- **谁/何时**:1917 什克洛夫斯基《作为手法的艺术》(陌生化+文学性造词);1928 普罗普
  《故事形态学》(31 功能 7 角色圈,固定次序);1969 托多罗夫造词"叙事学";
  1972 热奈特《叙事话语》(话语三层登顶)。
- **因什么问题**:①传记批评解释不了"写得好"(机制之问)②故事千变万化,底下有没有
  恒定结构(语法之问)③同一事件不同的讲法差在哪(话语之问)。

## 核心问题

**已解决(通说)**:
- 功能序列的固定次序(可缺省,不重复)——可讲性=语法约束的产物
- 故事/情节(fabula/syuzhet)之分:讲述对故事时间的三重扭曲(顺序/时距/频率)
- 聚焦与声音分离:谁看≠谁说

**未解决/深水区**:
- 陌生化的感知论落点:认知科学测得到"感知减速"吗(实证化进行中)
- 普罗普语法是否欧洲民间故事的地方法(跨文化的功能表修订)
- 列维-斯特劳斯 1960 批评:线性次序是叙事者的假象还是结构本身

## ✨ 这支最美的一个事实

**普罗普压缩**:一百个俄国魔法故事,人物姓名、法宝、妖怪全部不同,抽出 **31 个功能**后
只剩**一条时间线**——功能的无限组合底下是次序的单一。家族实验幕一的最小版:8 功能语法下
合法故事恰 64 个,自由排列 40320 个,**约束压缩比 630 倍**。**多样性是词汇给的,可讲性
是语法给的**——文学理论第一次拿到"像句法一样硬"的结果。

## 假设与依赖

- 买入"故事有语法":功能次序约束先于内容;付出:讲得好不好不在语法管辖内
- 买入"文学性在文本内":陌生化是文本手法的效应;功能标注依赖解释判断(方法侧,文字提及)
