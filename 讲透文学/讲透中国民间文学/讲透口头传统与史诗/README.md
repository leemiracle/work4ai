# 讲透口头传统与史诗 · 怎么唱出来——零件库、现场与每一次表演

> **定位句**:这支负责民间文学的**生产机制**:**帕里-洛德口头程式理论**(程式=相同格律条件下表达给定基本观念的一组词;主题=可展开场景;歌手不背词句,备零件库)、
> **表演理论**(鲍曼《作为表演的口头艺术》:民间文学的本体是有听众的交流事件,文本只是残骸)、
> **三大史诗的方法论枢纽**(格萨尔/玛纳斯/江格尔——本体归 75044 少数民族文学,此处取其验证理论的枢纽地位)。
> 口传引擎在此=零件库的现场装配:即兴不是自由创作,是重组。
> GB/T 13745 75037 中国民间文学(无三级明细 → **自定支**)。家族:[讲透中国民间文学](../README.md)

## 诞生

- **谁/何时**:1930s 帕里为解"荷马问题"赴南斯拉夫录古斯勒歌手(档案今存哈佛,通说);1960 洛德《故事的歌手》立口头程式理论;
  阿夫多实验(听一遍新歌,次日唱出更长版本,通说);1977 鲍曼立表演理论;2000 朝戈金《口传史诗诗学》完成中国现场化;
  三大史诗随非遗时代进入保护语境(2006 首批国家级名录;格萨尔/玛纳斯 2009 入选人类非遗代表作名录,通说)。
- **因什么问题**:①文盲歌手怎么唱出数万行(记忆之问:答案是零件库不是背诵)②每次唱的都不一样,哪一版是"正文"(文本之问:答案是异文群)③离开场合与听众,录音还算不算那个文本(语境之问)。

## 核心问题

**已解决(通说)**:
- 程式-主题-故事模式的三层装配:口头创作的语法(洛德范式)
- 口头与书面的结构差异可计量;两场表演行集交并比仅 16% 而零件库相同——"每一次表演都是再创作"(实验律一)

**未解决/深水区**:
- 表演的"突生"(歌手-听众互动涌现之物)如何在档案里存证——录音是残骸还是遗骸
- 中国连续文献传统(国风/乐府/俗曲)与口传现场如何互证——"多元印证"的中线怎么走
- 遗产化(舞台/赛事/话筒)正在改写表演生态多少——话筒会改变唱法

## ✨ 这支最美的一个事实

**文盲歌手听一遍,唱得更长**:洛德记录,文盲裁缝歌手阿夫多听别人唱一首他不熟的歌,
次日回唱,篇幅从两千余行扩到六千余行,情节完整而更精彩(通说)。
**"创作"与"记忆"的边界在此溶解**——他不是背下再加工,是当场用零件库重新生产;
家族实验律一的读数:零件拼装空间 800 行,比自由取词小 24 个数量级,但口传行 100% 合法。
史诗的"文本"只存在于每一次表演里。
