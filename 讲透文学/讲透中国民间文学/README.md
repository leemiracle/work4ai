# 讲透中国民间文学 · 没有底本的文学——口头传统、异文群与它们的百年建制史

> 中国民间文学=**没有底本的文学**——作家文学研究固定文本,本家族
> 研究**异文群**:同一首歌谣村村不同,同一个故事年年不同。三台
> 引擎贯穿一百年:**口传**解释它怎么被现场造出来(歌手不背词句,
> 备零件库)、**流传**解释它怎么走千里而骨头不变(情节核保守,
> 装饰壳多变)、**建制**解释它怎么从村口走进国家名录(1918 歌谣
> 征集→《歌谣》周刊→三套集成→非遗时代)——
> 一句话:**民间文学是被现代学术发明出来、又不断改写自己方法的
> 对象;它的"没有底本"不是缺陷,是它的生产方式**。
>

## 一、家族定位

- **三支分工**:同一片汪洋的三种读法——**口头传统与史诗支**
  (怎么唱出来:帕里-洛德口头程式理论/表演理论/三大史诗方法论
  枢纽)、**故事类型学支**(怎么传出去:ATU 索引/中国故事类型/
  类型流传与变异)、**歌谣与民俗叙事支**(怎么被看见:歌谣运动
  史/民歌与谤谣/传说与地方叙事/非遗语境)。
- **三台引擎贯穿全家族**:口传(零件库)、流传(核/壳)、建制
  (征集→集成→名录)——每个民间文学事实(一首歌谣/一个类型/
  一次表演)都能在坐标系里定位(00 章 §二、03 章结构卡)。
- **零门槛**:不要求任何文学史前置;要田野与仪式理论去
  [社会人类学](../../讲透社会学/讲透社会人类学/README.md),
  要三大史诗本体去少数民族文学 75044;本家族管**异文群的文学
  形态学与建制史**。
- 路线 A(问题派):歌手不识字怎么唱几万行?→00 §七发现 1;故事
  为什么走到哪都认得出又认不出?→发现 2;"非遗"到底保护了
  什么?→歌谣支
- 路线 B(课程派):00→口头支(怎么唱)→类型学支(怎么传)→
  歌谣支(怎么被看见)
- 路线 C(研究派):00→01(文献地图与处境反思)→02(编号的语法
  与"非遗/原生态/采风"的话语磨损)
- 工程师快轨:直接跑 [`experiments/formula_type_variation.py`](experiments/formula_type_variation.py),再回读 04 章

## 二、家族树(GB/T 无三级明细 → 自定 3 支)

```
讲透中国民间文学/             GB/T 75037(无三级明细 → 自定 3 支;不设兜底支)
├── 讲透口头传统与史诗/       自定支——怎么唱出来:帕里-洛德口头程式理论/
│                              表演理论/三大史诗(方法论枢纽,本体归 75044)
├── 讲透故事类型学/           自定支——怎么传出去:ATU 索引/艾伯华-丁乃通-
│                              刘守华的中国类型/类型流传与变异
└── 讲透歌谣与民俗叙事/       自定支——怎么被看见:歌谣运动史/民歌与谤谣/
                               传说与地方叙事/非遗语境
```

> 三支恰好切开异文群的三面:没有零件库,故事现场造不出来(口传);
> 没有核壳结构,故事走不出乡(流传);没有建制史,这一切不会成为
> "学科"(建制)。神话与传说的谱系研究散入三支(形态入口在类型
> 学支,语境入口在歌谣支),谚语/歇后语归歌谣支的谣谚线。
