# 讲透故事类型学 · 怎么传出去——编号、异文群与核壳分离

> **定位句**:这支负责民间文学的**旅行机制**:**ATU 索引**(阿尔奈 1910→汤普森 AT→乌特 2004:给世界故事上编号的百年工程)、
> **中国故事类型三系**(艾伯华 1937 自建体系/丁乃通 1978 挂 AT 编号/刘守华《中国民间故事类型研究》——编号即理论立场的三代对表)、
> **类型流传与变异**(芬兰历史-地理学派的原型重构;核保守壳多变的旅行学)。
> 流传引擎在此=故事带着骨架旅行:情节核是识别码,装饰壳是本地化接口。
> GB/T 13745 75037 中国民间文学(无三级明细 → **自定支**)。家族:[讲透中国民间文学](../README.md)

## 诞生

- **谁/何时**:1910 阿尔奈建类型索引,汤普森 1928/1961 修订为 AT,2004 乌特修订为 ATU(通说);
  1937 艾伯华自建中国体系;1978 丁乃通把中国材料挂进 AT 编号(中译 1986,通说);刘守华一系续作;
  方法源头:芬兰历史-地理学派(克罗恩)以异文群倒推"原型"。
- **因什么问题**:①天下故事何其相似,怎么登记(编号之问)②一个故事怎么走出起源地(流传之问)③异文之间有没有亲缘(谱系之问)。

## 核心问题

**已解决(通说)**:
- 类型/母题双层编号:类型管情节核(可编号),母题管最小单元(可跨类型迁移)
- 中国材料的世界对表:叶限(《酉阳杂俎》,9 世纪,通说视为最早的灰姑娘型文字记录之一)、老虎外婆(AT 333C,通说)等经典对接
- 流传的双面律:密度随距离衰减,结构核不随距离散架(家族实验律二:核保留 86%-94% 而壳 58%→12%)

**未解决/深水区**:
- 原型重构的真值:历史-地理方法产出的是假设不是事实(实验律三的采录者效应随时伪造信号)
- 欧洲框架与中国材料的水土:挂 ATU 得可比性,自建体系得完整性(02 章"编号的语法")
- 地图空白=传统空白还是田野空白(数据库时代的采样偏差)

## ✨ 这支最美的一个事实

**一个传说替学科做了两千年实验**:孟姜女——春秋知礼的杞梁妻→汉代"哭之而城崩"→唐代哭崩长城→明清抗暴骂秦(顾颉刚 1924 年清理,通说)。
两千年里同一个女人换了四份工作;故事没有"原本",只有**层累的变体**。家族实验律二的两千年田野版:
骨头(亡夫之哭)未变,衣服(崩的城、骂的帝)随时代换装——研究故事史不是找原型,是画变异的地图。

## 假设与依赖

- 买入"异文可抽象为类型+母题":编号体系让汪洋可比;付出:欧洲框架先行,切分即立场
- 依赖异文登记的采录元数据(年/人/地):没有它,密度地图与谱系全都带着采录者偏差(家族 03 章红区行)
- 与比较文学母题实验的分工:那边管跨文明翻译变异,本支管境内地理流传变异(家族 README §〇)
