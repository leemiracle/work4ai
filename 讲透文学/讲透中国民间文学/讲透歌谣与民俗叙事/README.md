## 诞生

- **谁/何时**:1918.2 刘半农、沈尹默、周作人等在《北京大学日刊》发起歌谣征集(通说);1922.12《歌谣》周刊创刊;
  1924 顾颉刚孟姜女研究示范演变实证;1927-30 中山大学民俗学会与杭州中国民俗学会(钟敬文线);1950 中国民间文艺研究会;
  1980s 中期三套集成启动;2001 昆曲入选首批人类口头和非物质遗产代表作(通说)开启非遗时代;2006 首批国家级名录(民间文学类在列,通说)。
- **因什么问题**:①老百姓的口头创作算不算文学(命名之问)②怎么把它带出村口(采录之问)③认定之后,它还是它吗(遗产化之问)。

## 核心问题

**已解决(通说)**:
- 歌谣运动的"学术的/文艺的"双目的:既是民俗资料又是新诗营养(刘半农《瓦釜集》为反哺样本)
- 征集表制度:流传地/唱者/场合/方言四栏——百年采录的元数据起点(家族 01 章美之时刻 4)
- 传说的风物锚定:梁祝"读书处"多地并存,地方叙事把故事钉进山水(核壳分离的地理机制)

**未解决/深水区**:
- 非遗是保护还是改写:名录化、舞台化、"进校园"是否正在把生活语境改成展演语境(民间文学类的"冷板凳"处境)
- 谣谚的政治史:从"采诗观风"到当代段子,谤谣始终是舆论的影子语言——文学史怎么安放它
- 数字化能否替代田野:档案在暴增,语境在退场,"人走歌歇、歌入库活"的复合局面

## ✨ 这支最美的一个事实

**一首情歌走遍中国,村村唱自己的版本**:《看见她》——小伙子第一次去未婚妻家,一路的紧张与得意——
董作宾在《歌谣》周刊时期收集整理,异文四十余首遍布各省(通说):同一副骨架,各省的村名、物产、礼俗全套换装。
一首歌做完了实验律二的全流程(核不变,壳全换);一张异文地图,把"没有底本"从概念变成了实物档案。

## 假设与依赖

- 买入"认定即保护":名录与建档给民间文学以存续的政治保障;付出:遗产化改写对象(为评审而表演、为名录而"原生态")
- 依赖采录伦理与登记质量:征集表四栏不全的旧档,语境研究即告残废(家族 03 章卡 3 的缺项账单)
