# 讲透译介与文学转型 · 换轨的供给侧——谁进来、隔多久、经谁手

> **定位句**:这支负责近代文学的**供给线**:外来文学如何进入中国——**传教士译介**(《万国公报》系/傅兰雅征文:"小说有用"的观念预植)、
> **林纾现象**(口译笔述双轨制,不通外文而译书 180 余种)、**翻译文学的建制化**(译馆→书局→杂志三级通道)、
> **周氏兄弟《域外小说集》**(直译先行,1909 东京出版而市场冷遇)。
> 译介在此=改供给的发动机:书目即观念史档案。
> GB/T 13745 75027 中国近代文学(无三级明细 → **自定支**)。家族:[讲透中国近代文学](../README.md)

## 诞生

- **谁/何时**:1862/1868 同文馆与江南制造局翻译馆立译制;1873《昕夕闲谈》首部有影响汉译长篇(通说);1895 傅兰雅"时新小说"征文;
  1898 严复《天演论》刊行("信达雅");1899《巴黎茶花女遗事》(王寿昌口译/林纾笔述);1909 周氏兄弟《域外小说集》东京出版。
- **因什么问题**:①文学写什么(供给之问:世界文学经谁挑拣进入)②隔多久进来(时滞之问:通道决定速度)③翻译用什么语言(文体之问)。

## 核心问题

**已解决(通说)**:
- 时滞结构:早期专挑旧名著(茶花女 51 年/黑奴吁天录 49 年),后期转向时新(天演论 5 年/福尔摩斯 4 年)
- 林译机制:口译笔述双轨=语言能力与文章能力分包的工业化生产;其"讹"与魔力同源
- 《域外小说集》的历史意义:直译+弱小民族文学选目的先见(鲁迅自述东京两册共售出四十一册)

**未解决/深水区**:
- "翻译多于创作"的口径之争(阿英/樽本照雄一系数字不一,数据库时代重算中)
- 经日转译的底本问题:中国读者读到的托尔斯泰/雨果,是哪一层转手版本
- 严复译名为何全线败给日译词(通道论:发行网络胜过修辞质量——02 章 §二)

## ✨ 这支最美的一个事实

**1909 年的直译比时代早了十年**:同一个文坛,林译(归化文言)一年数种、洛阳纸贵;
周氏兄弟的《域外小说集》(直译/保留原著单位/选弱小民族文学)两册合计售出四十一册(鲁迅自述)。
市场判归化胜,历史判直译胜——十年后新文学一代按《域外小说集》的路子重起炉灶。
**翻译的到达不均匀,不止在书与书之间,还在方案与方案之间**:先到的(归化)搭好市场,后到的(直译)定义未来。

## 假设与依赖

- 买入"冲击-反应"框架:外来文学是近代转型的主动力;付出:内生演化(《海上花》一脉)被低估
- 依赖目录学与数据库:时滞三元组(源作年/中译年/文类)的录入边界即研究边界(家族 03 章红区)
