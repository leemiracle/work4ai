## ② 核心思维模式(这个分支怎么想问题)

1. **三台发动机之问**:任何近代文学事实先定位——译介改供给
   (它从哪条线进来/隔多久/经谁手)、报刊改载体(它挂在什么
   节拍上)、口号改等级(它在哪张等级表的哪一格)
2. **书目即档案**:看到译作清单先问选择偏食——先到的是被挑过
   的;翻译书目是观念史的实物档案(实验律一)
3. **节拍之眼**:看到连载文本先想发布周期——同期阅读共同体、
   回末钩子、"浮露"的传播策略都是节拍的产物(实验律二)
4. **棘轮之眼**:看到升格口号先查正反馈第一环——观念翻转
   不可逆,但地位不等于成就(实验律三的红区警告)
5. **出生证之眼**:近代术语先查铸造年——"新"的购买力随年代
   贬值;革命/经济/小说都有近代出生记录
6. **史实与评价分账**:时滞可算、"过渡带"不可算;数据库裁决
   不了史观之争——左端去算,右端亮明框架再论证

## ④ 常见误区与禁忌

- **把"三界革命"当三个事件**:它们是纲领不是事变;革命在此处
  多为"革新"义,与辛亥革命不是一个"革命"
- **把新文体当白话文**:新文体/新民体仍是文言(解放了的文言),
  白话文革命在 1917 之后;裘廷梁们的白话是"维新工具的白话"
- **把谴责小说泛化**:鲁迅专指四大名家一线的揭发小说,界说
  "辞气浮露,笔无藏锋",与《儒林外史》式讽刺小说分家
- **把林译当"林纾的翻译"**:林纾不通外文,是口译笔述双轨制的
  笔述端;评林译先建译介链,再谈讹与美
- **把"小说为最上乘"当小说成就证明**:那是等级表翻转(观念史),
  不是作品质量评分——谴责小说地位与争议同年并存
- **把"翻译多于创作"当定论**:通说估计而已,口径随目录学工程
  与数据库边界跳变,引用先声明边界
- **拿等级指数为美学背书**:softmax 份额是观念读数;算得出
  地位,算不出动人(03 章红区)

## ⑤ 与相邻分支的判别表 + 组合接口

| 症状像近代文学,其实是… | 判别 |
|------------------------|------|
| 1917-1949 的文学(鲁迅小说/新诗/曹禺) | → 中国现代文学 75031(待建,文字提及):本家族只管 1840-1911 与基础设施移交 |
| 先秦至清中叶的文体谱系(同光体/宋诗派源流) | → 中国古代文学 75024(待建,文字提及):文体源流归它,文学事实在本段 |
| 报馆制度/发行网络/新闻文体史 | → [../../讲透新闻传播学/README.md](../../讲透新闻传播学/README.md):媒介归它,文本归本家族 |
| 洋务/戊戌/辛亥的事件史 | → [../../讲透历史学/README.md](../../讲透历史学/README.md):本家族只取年代学骨架 |
| 翻译的跨语际方法论(影响/变异/世界文学体系) | → 比较文学 75021(待建,文字提及):本家族供译入端的史料现场 |
