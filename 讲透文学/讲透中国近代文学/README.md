# 讲透中国近代文学 · 1840-1911 文学的换轨七十年——译介、报刊与文类等级的翻转

> 中国近代文学=传统文学在新世界里的**换轨史**——三台发动机在
> 1840-1911 的七十年里把"文学是什么、写给谁、用什么写"换了一遍:
> **翻译**改供给(西书与东瀛新学涌入),**报刊**改载体(连载把读者
> 拉进公共节拍),**革命口号**改等级表(小说从"小道"翻上"最上乘");
> 到辛亥年轨道已换完,五四的火车驶入的是已铺好的轨道——
> 一句话:**近代文学是现代文学的排练场,而排练本身就是正戏**。
>

## 一、家族定位

- **两支分工**:同一场换轨的两种读法——**译介与文学转型支**(换轨的
  **供给侧**:翻译文学/传教士译介/林纾现象/周氏兄弟《域外小说集》:
  外来文学如何进入、隔多久、经谁手)、**报刊文学与文体变革支**(换轨的
  **载体与观念侧**:报章体/诗界文界小说界革命/谴责小说/白话先声:
  文学被搬进什么节拍、等级表被谁翻转)。
- **三台发动机贯穿全家族**:译介改供给、报刊改载体、口号改等级——
  每个文学事实(一部译作/一份杂志/一次论争)都能在坐标系里定位
  (00 章 §二、03 章结构卡)。
- **零门槛**:不要求古代文学前置;要事件史去[历史学](../../讲透历史学/README.md),
  要报馆制度去[新闻传播学](../../讲透新闻传播学/README.md);本家族管
  这七十年里**文学自身的换轨**。
- 路线 A(问题派):为什么"没有近代文学就没有现代文学"?→00 章;
  林纾不懂外文怎么成为翻译家?→译介支;一句话怎么把小说抬上"最上乘"?→报刊支
- 路线 B(课程派):00→译介支(供给侧)→报刊支(载体与观念侧)
- 路线 C(研究派):00→01(文献地图)→02(近代话语的户口本:日语借词/"新"字经济)
- 工程师快轨:直接跑 [`experiments/translation_press_genre.py`](experiments/translation_press_genre.py),再回读 04 章
