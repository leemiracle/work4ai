# 讲透蒙古族文学 · 史诗与史传双线——江格尔、秘史与双语写作

> **定位句**:GB/T 支 **7504410**——**活态史诗线**(《江格尔》与江格尔齐;
> 《格斯尔》与藏族《格萨尔》同源异流,非遗名"格萨(斯)尔"蒙藏共录,
> 通说)、**书面史传线**(《蒙古秘史》《黄金史》《源流》三大名著,
> 通说;尹湛纳希《一层楼》《青史演义》);**现当代线**(纳·赛音
> 朝克图、玛拉沁夫与蒙汉双语写作)。口号:**史诗与史传双线并行**。
> GB/T 13745 75044 · **GB/T 支 7504410** · 家族:[讲透中国少数民族文学](../README.md)

## 诞生

- 13 世纪中叶《蒙古秘史》成书(通说);卫拉特蒙古的《江格尔》口头
  世代流传,20 世纪被系统采录;尹湛纳希 1837-1892 在世;20 世纪中叶
  蒙文新文学与双语写作并起(通说)。
- 三问:①口头与书面怎么分工(史诗唱神话时间,史传记历史时间)
  ②跨境传统怎么归属(《江格尔》亦流传蒙古国与卡尔梅克,通说——
  本支管中国境内)③母语与汉语写作怎么并存(家族实验幕二的现场)。

## 核心问题

**已解决(通说)**:《江格尔》2006 年列首批国家级非遗(2021 年内蒙古
扩展列入,通说);格斯尔-格萨尔同源异流谱系;江格尔齐程式句法研究
成为口头诗学中土化标本(朝戈金 2000,通说)。
**未解决/深水区**:江格尔齐传承梯队的老龄化(家族 01 章主线 C);
《格斯尔》诸本谱系;蒙汉双语写作的代际语言分布。

## ✨ 这支最美的一个事实

**《蒙古秘史》——失去原本却以"注音"永生**:畏兀体蒙古文原本早已
佚失,明初用**汉字逐字记音**加旁译把它留存下来(通说)——一部书靠
给另一种文字"标拼音"活过七百年,成为蒙古语的中古"录音";《秘史》
的音写复原校勘学是本支独有工艺。
