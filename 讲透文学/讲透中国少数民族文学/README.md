## 一、家族定位(它在文学宇宙里的位置)

国别家族按语言与国境切;本家族的独特发问是:**把"多语"与"族别"本身
变成研究对象**——中国文学史为什么曾经默认是汉语的(单一汉族文学史)?
三大史诗的发现怎样改写了"中国无史诗"的旧论?一部史诗没有"定本"只有
"部"与"异文",文学研究怎么对待?双语作家选哪种语言写作,是趣味还是
结构(幕二:读者规模×表达保真的均衡)?5 个 GB/T 原生支蒙藏维哈朝,
速写层傣彝壮苗瑶柯尔克孜锡伯——**族别是入口不是牢笼**:每个文学事实
都要在"族别传统×中华文学总账本×跨境共享"三层里定位(00 章坐标系)。

- **零门槛**:听过《格萨尔》《玛纳斯》《江格尔》的名字、读过一两首
  仓央嘉措即可入门;本家族管的是**活态传统怎么被研究、被整理、被建制**
- 路线 A(问题派):史诗为什么没有定本?→00 §七发现 1+实验幕一;
  为什么多数民族作家用汉语写?→00 §七发现 2+实验幕二;整理本为什么
  谁都不满意?→00 §七发现 3+实验幕三
- 路线 B(理论派):00→01(前沿地图)→02(多语文学的量与话语陷阱)
