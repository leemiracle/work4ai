# 讲透维吾尔族文学 · 喀喇汗双璧——福乐智慧、纳瓦依与丝路书面高峰

> **定位句**:GB/T 支 **7504430**——**古典书面线**:《福乐智慧》
> (1069-1070,优素甫·哈斯·哈吉甫)与《突厥语大词典》(1072-1074,
> 麻赫穆德·喀什噶里)并称喀喇汗时期双璧(通说),《真理的入门》
> 续之;**察合台线**:纳瓦依(1441-1501)的高峰(《五卷记》);**现当代
> 线**:黎·穆特里夫、铁依甫江与双语格局。口号:**文学与语文学不分家**。
> GB/T 13745 75044 · **GB/T 支 7504430** · 家族:[讲透中国少数民族文学](../README.md)

## 诞生

- 11 世纪下半叶喀喇汗王朝的两位大家在喀什几乎同时完成双璧(通说);
  15 世纪纳瓦依把察合台文学推至顶点;20 世纪现代维吾尔文学奠基并
  延续双语格局(通说)。
- 三问:①书面古典如何证明"非汉语传统自成高峰"②抄本怎么变成文学史
  (《福乐智慧》三种主要抄本传世,通说)③古典与当代的连续性。

## 核心问题

**已解决(通说)**:喀喇汗双璧的文献整理与现代译介(《福乐智慧》
《突厥语大词典》均有现代汉译本);纳瓦依研究的世界学术地位。
**未解决/深水区**:抄本谱系的细化(年代与流传);古典—当代连续性
的叙述框架(族内断代之争);当代双语写作的面板数据。

## ✨ 这支最美的一个事实

**一部治国手册写成了长诗**:《福乐智慧》以对话体(国王/大臣/贤者)
讨论公正、幸运、智慧、知足四种品质的治国之学(通说),作者葬于
喀什的陵墓至今(通说)——**文学与经世之学不分家**:在喀喇汗王朝
的宫廷里,诗就是政治哲学的载体。"纯文学"是很晚的发明——古典的
高峰常常站在学科分界线还不存在的地方。

  本支不替语言学下结论)
