> 盘索里等说唱、《阿里郎》等民谣;**书面线**:延边朝鲜文期刊文学与
> 教育—出版体系(通说),金哲等朝鲜文写作的延续;**双语线**:金仁顺
> 等以汉语写作进入全国文坛(通说)。口号:**家族实验幕二的活现场**。

## 诞生

- 朝鲜族移民垦殖以来农谣传统延续;1950s 起延边朝鲜文文学建制(期刊/
  出版/教育体系)成型;改革开放后汉语写作作家进入全国视野(通说)。
- 三问:①劳动的歌怎么变成世界遗产 ②母语文学生产的建制怎么维持
  (期刊/出版/教育三件套)③双语写作的代际分布(幕二的面板现场)。

## 核心问题

**已解决(通说)**:农乐舞 2009 年入选联合国名录;延边朝鲜文文学建制史
(期刊与作家群);与朝鲜半岛文学共享经典谱系的跨境共录处理(家族 README §〇)。
**未解决/深水区**:双语写作的代际分布(母语写作的可持续性,家族 01
主线 B 最热的现场);农乐舞从劳动伴奏到展演的语境变迁;读者规模面板化。

## ✨ 这支最美的一个事实

**劳动的歌进了世界名录**:农乐舞从农事的伴奏与节令的欢庆(乐与舞
一体)到 2009 年联合国人类非遗代表作名录(通说)——**一个"伴生"的
艺术(给劳动打拍子的)被承认为人类遗产**:"日常的、活着的、还在用的"
才是名录时代最想保住的东西(演述不必悲壮,也可以是节令里的敲敲打打)。
