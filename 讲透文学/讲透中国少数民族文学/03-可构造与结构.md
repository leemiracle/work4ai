# 03 · 可构造与结构:哪些民族文学对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:少数民族文学的对象沿一条**可构造谱系**排开——
> 演述记录端**严格可构造**(场次×艺人×单元集×行数写得下、变异
> 分解算得动、断言得了),语言选择与版本合并端**半可构造**(模型
> 的裁定是学科判断,但定了就可计数),"民族性"与民族审美端
> **几乎不可构造**(细读与语境的地界);全谱系共享三条结构引擎:
> **演述逻辑**(骨架是传统的,血肉是当晚的)、**均衡逻辑**(读者
> 规模×表达保美两种力的中间态)、**分布逻辑**(异文是分布不是
> 变体)——而学科的田野纪律可以压进三张**结构卡**(史诗艺人卡/
> 多语作家卡/翻译链卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
演述记录 ── 双语份额面板 ── 版本合并度量 ── 艺人卡/作家卡/翻译链卡 ── 民族性/民族审美
  │                                                                │
严格可构造(可断言)                                             几乎不可构造(只有细读与语境)
  └── 场次×艺人×单元集全能过 assert(幕一)                    └── "《福乐智慧》好在哪"靠读,不靠算
        └── 幕二幕三在中段:裁定是学科的,计数是机械的
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:演述
记录的语义是"哪位艺人哪一晚唱了哪些单元多少行"(音像档案时代
可逐场登记,01 章主线 A),输入输出明确;而"民族性"的语义进入
阐释——**阐释者本人就是测量仪器,仪器无法装配仪器**。本章先盘
家底,再看三条结构引擎,最后把田野纪律压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **演述记录(场次档案)** | 场次×艺人×单元集×行数清单;组内/组间变异分解 | 低(音像档案时代可批量登记,01 章主线 A) | 单元切分是分析裁定(功能单元怎么划,学派有别);行数口径(韵行/散句)要统一 |
| **变异分解** | 同艺人内部 vs 艺人之间的长度差/序列 tau/集合 Jaccard | 低(幕一全程可跑) | 样本量:每位艺人的多次演述记录在传统采录里常不足——模型可跑,实证要等档案 |
| **双语份额面板** | 作家×年份×语言的作品清单;份额轨迹 | 中(代表作可数,全量作品志是大工程) | "代表作级"面板有幸存者偏差(未发表/母语期刊长尾缺登记) |
| **语言选择动力学** | 收益=读者规模×表达保真的选择模型;配对臂 | 中(幕二全程可跑) | 参数(读者比/保真度)是模型设定,不是实测——用于力学的演示,不用于预测 |
| **版本合并度量** | 异文集合的距离矩阵;四候选的长度/覆盖/距离 | 中(幕三全程可跑) | 单元切分与"同一单元"的对齐裁定;长度按行数忽略音乐维度 |
| **艺人卡/作家卡/翻译链卡** | 固定字段表(§五 schema) | 中 | 传记与曲目记载按通说口径,存疑处显式标注"缺证据" |
| **翻译链重构** | 原文→中介语→译本→选本下游的链登记 | 高(文献学硬活) | 中介语常不可考(转译未注明);版本链断档 |
| **"民族性"/民族审美** | 细读与语境阐释 | **不可构造** | 风格计量(词频/意象)量得出指纹,量不出"民族性"——用指标冒充审美是这个学科量化的头号失真 |

**反直觉发现(本章铁律)**:**越"民族"的词越不可构造,越"技术"
的对象越可构造**。"民族性"最有名,不可构造;"演述记录矩阵"最少
被课堂提起,却能跑出过硬的断言(同艺人 tau 1.00 vs 长度差 16.6%)。
**左端管结构,右端管意义**;拿右端对象硬造左端指标(用几个意象
词频宣布某作品"民族性 0.8")是双重失真——两头都不是。

## 二、结构引擎 1:演述逻辑——骨架与血肉的分层

**直觉图像**:活态史诗的每次演述像一场演出:剧本结构(情节功能
序列)是传统的公共财产,当晚的一切(扩容的疏密、可选段子的取舍、
状态的起伏)是艺人的即兴。**变异不是噪音,是活态的定义**。

- **数学化身**(家族实验幕一):一部之 14 核心+9 可选功能单元;
  艺人带个人扩容量/可选单元库/个人章节块顺序;每晚带状态因子。
  三条刚性:
  1. **骨架不动**:核心单元 100% 出场,同艺人序列 tau 中位 1.00
     ——"同一部"之所以可辨认,靠的是骨架的公共性。
  2. **长度是事件属性**:同艺人两晚长度差中位 16.6%(10-30% 量级,
     通说格萨尔艺人现象的量级)——把任何一次演述当"该艺人的
     定本"都是范畴错误。
  3. **艺人口音**:艺人之间长度差 28.8%(1.73 倍内部)、tau 0.829、
     Jaccard 0.789 三降——传统之内存在稳定的个人风格分布。
- **刚性从哪来**:组内/组间的分层统计是刚的;软的地方在**单元
  切分**的裁定(情节功能怎么划单元,分析者之间有出入)——正式
  研究要求切分方案随数据发布。模型量化的是"骨架-血肉"的机制
  直觉,不冒充实录(幕一是六位艺人的压力测试,不是某个传统的
  统计报告)。

## 三、结构引擎 2:均衡逻辑——两种力的中间态

**直觉图像**:双语作家的每一次语言选择,都在两个力之间称重:
读者规模(汉语的全国市场)把收益拉向汉语,母语不可译经验(只能
母语承载的题材)把份额锚在母语。**格局=均衡,不是同化的中转站**。

- **数学化身**(家族实验幕二):选择概率=σ(收益敏感×log(汉语
  收益/母语收益)+母语依恋);汉语侧收益=读者比(4→24)×保真度
  (0.60→0.82)。三条刚性:
  1. **漂移为真**:主臂汉语份额 42.5%→56.9%(个体为正 67%)
     ——市场扩张的传导是真的。
  2. **锚也为真**:全漂臂(题材全可迁移)92.3%、全留臂(全不可
     迁移)0%,真实臂 56.9% 停在中间且末期混写 98%——保留压
     不是修辞。
  3. **均衡是动态停点**:增长停表后份额 3 年变动 2.2%(趋平)
     ——均衡不是不动,是两种力对冲后的稳态。
- **刚性从哪来**:配对臂的因果分离是刚的(三臂共享作家池);软的
  地方在**参数的标定**(读者比与保真度是设定值)——模型的价值
  在力学(两个力怎么互动),不在点位(具体某年该是多少)。这是
  "半可构造"的教科书案例:**结构可断言,数值要打折**。

## 四、结构引擎 3:分布逻辑——异文是分布不是变体

**直觉图像**:同一个"部"的九次演述(九份异文)不是九个版本的
同一文本,是一个分布的九个样本——**没有藏在其后的"真本",只有
分布本身**。整理者的全部工作是在分布上做选择。

- **数学化身**(家族实验幕三):异文=对单元集的三档出现率采样
  (核心 0.96/中频 0.55/低频 0.16);四候选规范本(并集/交集/
  多数/最优异文)。三条刚性:
  1. **无真本**:两两距离中位 0.36;任何一份异文(含最优异文)
     都存在距离 ≥0.25 的同伴——"找回真本"是没有目标物的工作。
  2. **两难**:并集本 1.50 倍膨胀(没人这样唱过);交集本 0.44
     倍、覆盖仅 44.3%(过半内容丢失)——长度与完整性不可兼得,
     且四种候选无一同时达标(≤1.10 倍且 ≥98% 覆盖)。
  3. **选择必做**:多数本平均距离最小(0.259)但仍删削每份异文
     近两成(最少 12%)——最好走的路也有代价,代价要写进前言。
- **刚性从哪来**:距离与覆盖率计算是刚的;软的地方在"同一单元"
  的对齐裁定与**行数口径**(音乐维度被忽略)——所以幕三输出的是
  两难的结构,不是某次整理的具体账。

## 五、结构卡 schema:把田野纪律压进三张卡

**先答为什么**:民族文学研究最难携带的是**归属与语境的纪律**——
谈艺人要带演述证据,谈作家要带语言标注,谈翻译要带中介与方向,
全靠自觉。结构卡是**有限字段的压缩格式**:字段固定、填空即可
复用、可比可查可补(这是"可构造"在方法层的对应物;02 章§三的
尊重表述清单在此字段化)。

### 卡 1:史诗艺人卡(把一位艺人钉进传统与演述)

```
【史诗艺人卡】
族别与传统:________(藏族格萨尔/柯尔克孜族玛纳斯/蒙古族江格尔/
  哈萨克达斯坦/傣族章哈……——族别+传统双标注,称谓用本族专名)
称谓与身份:________(仲肯/玛纳斯奇/江格尔齐/达斯坦奇/阿肯/章哈;
  类型描述如"神授"等按通说登记为现象,不作事实断言)
师承与习艺脉络(带年份):________(无师承的自述按口述登记)
曲目清单:________(会唱之部及数量——按通说口径,不夸张转写)
演述记录:________(场次档案:年份/场合/时长/行数——幕一的输入;
  无多次记录时显式标注"单场采录",变异不可分解)
代表性唱本与整理关系:________(整理本据哪几场演述合成?整理立场
  是择优/并集/交集/多数?——幕三的字段化)
传承状态:________(传承人认定/授徒情况——非遗三栏之一)
存疑登记:________(行数记载的出处与口径;传记矛盾点)
```

样例(已填,居素普·玛玛依,通说口径):族别与传统=柯尔克孜族
《玛纳斯》;称谓=玛纳斯奇;曲目=演唱八部(二十余万行的记载,通说);
演述记录=20 世纪中后期多次采录(具体场次以采录档案为准,存疑处
标注);代表性唱本=玛玛依唱本柯尔克孜文版整理出版(通说);传承
状态=代表性传承人体系内的重点对象(通说);存疑登记="八部全本"
等表述的口径依整理文献,本卡不作超出通说的断言。**读卡法**:这张卡
最重的字段是**演述记录**——幕一的变异分解只有在多次采录处才能
做;单场采录的艺人卡是"定本风险"最高的档案(一次演述被当成
本人的"文本")。

### 卡 2:多语作家卡(把一位作家钉进双语格局)

```
【多语作家卡】
族别与语言系:________(族别+创作语言双标注:藏文写作/汉语写作/
  双语——02 章§三纪律 2)
代群:________(按创作活跃期划;代群是双语格局的结构变量)
语言份额轨迹:________(代表作级估计:母语/汉语作品比,按创作
  阶段分;证据=作品志/期刊出版记录——幕二的输入)
题材-语言匹配:________(哪些题材以哪种语言写——"母语不可译
  经验"的个案登记:某题材只以母语出现吗?)
发表阵地:________(民族文字期刊/全国期刊/出版社——阵地即读者)
翻译参与:________(自译/被译;译入哪个方向——翻译链卡的接口)
经典化状态:________(母语经典化/全国经典化/译介国际——三级
  漏斗的族际版)
```

样例(已填,阿来,通说口径):族别与语言=藏族作家,以汉语写作
(藏语能力自述见其访谈,不在此断言);代群=当代(1959 生,通说);
语言份额=汉语写作为主;题材-语言=藏文化题材以汉语承载(其写作
本身成为"母语经验-汉语表达"的标本研究);阵地=全国期刊与出版
(《尘埃落定》1998,2000 年获第五届茅盾文学奖,通说);经典化=
全国经典化(茅奖)+译介;翻译参与=作品多语种译介(通说)。
**读卡法**:阿来卡的关键在**题材-语言匹配**字段——它是幕二
"母语不可译经验"的反向样本(以汉语承载母语经验的成本与收益,
批评界长期讨论的"汉语写作的藏族文学"之问,通说口径)。

### 卡 3:翻译链卡(把一部作品的族际旅行钉进链条)

```
【翻译链卡】
作品与源语言:________(如:撒尼口传叙事/维吾尔语诗体/蒙古文史传)
起点形态:________(口传演述/书面抄本/整理本——起点不是"原著"
  而是某个形态)
环节链:________(源语言→[中介语]→汉语→[外语]→……每环:译者/
  年份/所据底本——中介语不可考时显式标注)
方向与功能:________(民译汉=入史通道/汉译民=资源输入/民译民=
  族际直译——02 章量 2 的字段化)
选本下游:________(译本进入哪些选本/教材/名录——漏斗第三级)
变形登记:________(韵散体式改变/章节重组/篇幅增删——幕三式
  选择在翻译环的体现)
```

样例(已填,《阿诗玛》,通说口径):作品与源语言=撒尼(彝族支系)
口传叙事长诗;起点形态=口传演述(异文群);环节链=1950s 搜集
整理为汉文本(云南省人民文工团圭山工作组,通说)→电影改编
(1960s,通说)→多语种译介;方向与功能=民译汉(整理即族际翻译
的第一环)→再经影视与译介进入公共符号;选本下游=2006 年首批
国家级非遗名录(通说);变形登记=口传异文群→单一整理汉文本
(典型幕三式选择:分布变定本);影视改编再叠加形象定型。
**读卡法**:《阿诗玛》链的每一环都在做幕三的选择——**"整理"
就是第一次翻译**(从分布到定本),后续每环的选择强度只增不减。

**判定流程**(把一个学科主张钉到谱系上):

```
该主张的核心对象能写成场次清单、份额面板或距离矩阵吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(模型/卡片,裁定带学科判断)─▶ 中段:卡片化+双人校,
  │                                     参数声明为设定值,禁止硬算
  └─ 不能(民族性/审美/传统价值)──▶ 右端:细读与语境,禁止压成参数
```

## 六、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 蒙古族文学 | 左-中横跨(江格尔演述记录最硬;《秘史》版本学在中段) | 演述+分布 | 分裂:演述可算,史传评价不可 |
| 藏族文学 | 左端重镇(艺人多次采录的档案密度最高,通说) | 演述+分布 | 高(分部本计量/艺人类型学) |
| 维吾尔族文学 | 中段为主(抄本谱系/译本链;古典审美在右端) | 分布(抄本=另一形态的异文分布) | 中 |
| 哈萨克族文学 | 左端(对唱的场次结构可数;即兴质量评价不可) | 演述 | 中高 |
| 朝鲜族文学 | 中段(双语面板最规整;文学价值判断右端) | 均衡 | 中高(期刊出版数据规整) |
| 速写层七族 | 中段(《玛纳斯》同藏族格萨尔;其余以登记为主) | 演述+分布 | 中 |

**读表法**:一个支的"可构造纯度"取决于**它留下的档案形态**——
多次采录的活态传统(格萨尔/玛纳斯)在左端,抄本传统在分布引擎的
书面上,双语格局最规整的出版记录(朝鲜文期刊)成了均衡引擎的天然
面板。没有哪支全家可构造;少数民族文学的独特处是**它的三条引擎
都长在"没有定本"这个前提上**。

## ✨ 美之时刻(彩蛋第 6 枚:同一批数据的两张成绩单)

✨ **美之时刻 6:tau=1.00 与 16.6%——同一批演述的两张成绩单(极简)**
幕一跑完,打印出看似矛盾的两行:同艺人功能序列 tau 中位 1.00
(完美一致),同艺人长度差中位 16.6%(差异可观)。为什么美:**
这两个数不是矛盾,是活态史诗的全部秘密**——骨架层(传统)严丝
合缝,血肉层(当晚)自由浮动;"同一部"的可辨认性与"每次都不
一样"的真实性同时成立。它给一切"忠实记录"的讨论划了界:记录
什么层,就是忠实什么层。亲历:跑幕一,把 MOOD_SD(当晚状态波动)
调到 0.02,再调到 0.30——看哪张成绩单动了、哪张纹丝不动
(✍️练习 2)。
