# 讲透藏族文学 · 活态史诗之巅——格萨尔、古典谱系与两种语言的当代

> **定位句**:GB/T 支 **7504420**——**活态史诗线**:《格萨尔王传》,
> 迄今篇幅最浩瀚的活态史诗传统(通说),开放式**分部本**结构——
> 没有"全本",只有"部"的集合与还在唱的艺人(仲肯;"神授"等类型
> 描述按通说登记);**古典书面线**:《萨迦格言》、仓央嘉措情歌、《勋努
> 达美》等(通说);**当代线**:藏文写作(端智嘉等)与汉语写作(扎西达娃、阿来等)。
> GB/T 13745 75044 · **GB/T 支 7504420** · 家族:[讲透中国少数民族文学](../README.md)

## 诞生

- 《格萨尔》在青藏高原口头世代演述,20 世纪被系统采录;13 世纪《萨迦
  格言》成书;仓央嘉措 1683-1706 在世;1980s 起扎西达娃、阿来等登场(通说)。
- 三问:①没有定本的文学怎么研究(分部本+异文群+艺人,家族实验
  幕一幕三的学科原型)②一个人怎么"记住"一部史诗 ③藏文写作与
  汉语写作怎么并存(幕二:两种力的均衡)。

## 核心问题

**已解决(通说)**:格萨(斯)尔 2006 年列首批国家级非遗、2009 年入选
联合国人类非遗代表作名录(通说);扎巴老人等代表性艺人的抢救记录;
艺人类型学的登记框架(通说)。
**未解决/深水区**:艺人记忆机制(现象清楚,机制存疑);分部本总量
普查;规范本整理的立场声明(幕三两难的最重现场);双语写作代际结构。

## ✨ 这支最美的一个事实

**一个人比一部《荷马史诗》更能装**:《格萨尔》以分部本开放式结构
流传,通说称其为迄今篇幅最长的活态史诗传统;代表性艺人一生的演唱
记录动辄数十部分部本(通说口径)——**"长度"不是文本属性,是"还能
再唱一部"这个结构属性的后果**:部是开放的,新的部可以继续被唱出来。

## 假设与依赖

- 买入"艺人类型描述按通说登记"的纪律("神授"等为现象分类,不作
