## 诞生

- **谁/何时**:1922《荒原》《尤利西斯》同年出版(通说;后者在巴黎,英语世界因猥亵指控长期禁售);
  1925/1929 伍尔夫立意识流诗学与女性写作政治经济学;1949/1954 奥威尔与戈尔丁;1953 贝克特《等待戈多》;
  1981 拉什迪《午夜之子》获布克(1993/2008 两度回访再夺魁,通说);2013 布克向全球英语开放(通说)。
- **因什么问题**:①打碎句子之后诗与小说还剩什么(形式之问:意识流与神话方法)②帝国退潮后
  "英国文学"装谁的写作(容器之问:移民作家入席)③奖项与课堂能否制造经典(正典之问:当期读数
  vs 沉淀读数)。

## 核心问题

**已解决(通说)**:
- 现代主义的审查-流亡生态:禁书、小杂志与自费出版构成经典生产线(《尤利西斯》线路,通说);
  移民转向的事实性:三代作家把混合英语写进中心(通说综述口径)
- 奖项的正典功能:布克从英国小说奖长成全球英语文学引擎(2013 规则,通说)

**未解决/深水区**:
- "英国性"的定义式与谱系式之争:后脱欧研究把老问题翻新(家族 01 章主线 B)
- 混合英语的测量单位:词级混合率不捕捉句法迁移与语域切换(家族 03 章引擎 3 软处)
- 当代作家的席位预测:当期热度与沉淀读数可以差多远(实验律二的未竟应用)

## ✨ 这支最美的一个事实

**一本小说赢了两次,隔了二十七年**:《午夜之子》1981 年获布克奖;1993"布克中的布克"、
2008"布克四十年最佳"两度回访再夺魁(通说)。首奖测当期热度,回访奖测席位沉淀——正典的
时间结构是"再次获奖"。家族实验律三给出它的语言面:混合英语的接受度存在最优区间
(模拟峰值 m\*≈0.34,峰顶高出全同化端 0.32 分)——拉什迪的"酸辣酱化"恰好站在峰值带上:
**当代英国文学的中心,已从伦敦标准英语移到语言接触带**。
