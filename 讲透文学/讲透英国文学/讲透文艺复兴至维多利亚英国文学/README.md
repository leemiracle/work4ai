> 琼森,剧场把戏剧抬成文学)、**小说兴起**(1719-1789:笛福/斯威夫特/理查逊/菲尔丁/斯特恩,

## 诞生

- **谁/何时**:c.1387 乔叟开笔《坎特伯雷故事》(通说);1476 卡克斯顿建印刷所;1590-1613 莎士比亚
  创作期,1616 琼森《文集》、1623 第一对开本把剧本升格为文学(通说);1719-1749 小说在书商市场
  成形;1798《抒情歌谣集》开浪漫主义;1837-1901 维多利亚连载小说高峰。
- **因什么问题**:①俗语英语凭什么当文学语言(语言之问)②娱乐产品怎么变成"文学"(升格之问)
  ③ novel 的合法性从哪来(体裁之问:菲尔丁的"散文体喜剧史诗"自我命名)。

## 核心问题

**已解决(通说)**:
- 剧本升格为文学作品的制度路径(琼森《文集》/第一对开本);小说起源的书商市场解释
  (Watt 1957:形式现实主义与中产读者)
- 浪漫主义的语言纲领("从人们真正使用的语言中选择",1800/1802 序,通说)

**未解决/深水区**:
- 莎士比亚合作写作的边界:计算文体归属给出概率,不给判决(家族 00 章)
- "伟大的传统"的名单权:Leavis 名单与制度链研究的拉锯(家族 01 章主线 D)
- 维多利亚连载的物质史:全量数字档案才刚就位(见家族 01 章)

## ✨ 这支最美的一个事实

**莎士比亚的两三万词表,是篇幅的段位**:现存文本常引 88 万词、3.15 万词形(口径略异,通说);
家族实验律一模拟"新词率递减+按频复用"的写作者,88 万词自动落出 31,149 词形(Heaps 拟合
R²=0.9997,β=0.527),且八个创作期的新词从 10,662 递减到 2,049——**天才的证据不在词表
大小,在用法**;两万词表不是记性好,是幂律增长的自然段位。
