## 一、家族定位

- **两支分工**:同一条正典河的上下游——**文艺复兴至维多利亚支**
  (正典的奠基段:莎翁世纪/小说兴起/浪漫主义/维多利亚,约 1500-1901,
  乔叟与中古英语作源头档案挂支内)、**现代与当代支**(正典的重写段:
  现代主义/战后/移民转向,1890 年代至今)。
- **三台引擎贯穿全家族**:正典(席位再生产)、语言(英语的开采史)、
  帝国(容器随殖民扩张与移民回流变形)——任何英国文学事实(一部戏/
  一部小说/一次获奖)都能在坐标系里定位(00 章 §二、03 章结构卡)。
- **零门槛**:不要求英语或任何文学史前置;要编年全景去
  [世界文学史](../讲透世界文学史/README.md),要跨国影响通道去
  [比较文学](../讲透比较文学/README.md);本家族管**这条正典本身
  的建造与改写**。
- 路线 A(问题派):莎士比亚三万词表是记忆奇迹吗?→00 §七发现 1;
  正典名单为何百年不倒又年年微调?→发现 2;移民作家为何改写了
  "英国文学"的定义?→发现 3
- 路线 B(课程派):00→文艺复兴至维多利亚支(正典怎么建)→
  现代与当代支(正典怎么被改写)
- 路线 C(研究派):00→01(文献地图与近五年现场)→02(正典话语
  与"X 式"词族的话语迁移)
