# 讲透五四至抗战文学 · 新文学的发明期——白话、社团与论战

> **定位句**:这支负责**奠基层(1917-1937)**——文学革命与白话文运动
> (1917 两文→1920 国语令)、三大流派论争(为人生的文学研究会/为艺术
> 的创造社/转向革命的后期创造社,及语丝vs现代评论、新月格律诗论)、
> 左翼十年(1928 革命文学论争→1930 左联→两个口号)、京海派与上海
> 现代派。口号:**新文学是发明出来的**——语言、社团、期刊、论战四件套。

## 诞生

- **谁/何时**:1917 两文发难,1918 鲁迅《狂人日记》示范;1921 两社
  同年成立+《小说月报》革新;1928-1936 左翼十年;1930s 京海并立(通说)。
- **因什么问题**:①用什么语言写(白话之问)②为什么写、为谁写
  (纲领之问)③怎样组织起来(建制之问:社团+期刊+论战)。

## 核心问题

**已解决(通说)**:白话的胜利=1917-1927 语言替换(家族
[实验](../experiments/journals_canon_narrative.py)幕三:相变,S 形+临界点);社团—期刊建制成型
(幕一:阵地即身份,论战即接触,阵地份额 83.5%=4.9 倍置换期望);
三大主张论战谱系与 1930s 双线(左翼/上海现代派+京派)的地图。

**未解决/深水区**:论战的净产出(组织文坛的效率 vs 窄化议题的代价);被漏斗筛掉的期刊大多数如何入史(01 章主线 A 条件刚具备);通俗文学并行线与纯文学线的关系(范伯群路线之争)。

## ✨ 这支最美的一个事实

**一份印钞机刊物的改宗**:《小说月报》1910 年创刊,原是礼拜六派趣味
的老牌畅销刊;1921 年起沈雁冰全面革新,一年之内变成新文学第一全国
阵地(通说)。**白话的相变不在宣言里,在一份刊物的改版里**(幕三
的 1921 权威冲击即指此)。
