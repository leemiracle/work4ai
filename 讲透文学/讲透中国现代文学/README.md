# 讲透中国现代文学 · 1917 以降的白话中国——新文学一百年的阵地、漏斗与形式

> **本质一句话**:中国现代文学=**用白话写现代中国、并被现代建制(社团/
> 期刊/选本/文学史)持续再生产**的文学——它不是古代文学的自然延伸,是
> 一次语言革命(1917)引爆、一份刊物(《新青年》)点火、一代代阵地
> (期刊)、漏斗(选本→文学史)与形式实验(小说/新诗/话剧)接力出来的
> **建制化文学**;每收一段断代买入**"现代"的概括力**,付出**起点与
> 边界的争议成本**(1917 还是晚清?1949 切在哪?网络文学算不算?);
> 一句话:**白话赢了,文学史才有了"现代"这一卷——而白话赢的不是辩论,
> 是网络效应**(家族实验幕三)。

## 一、家族定位(它在文学宇宙里的位置)

国别家族管语言的内部纵深;本家族的独特发问是:**把"现代"本身变成
研究对象**——一段文学凭什么自称"现代"(白话/新人观念/世界文学参照),
它靠什么建制存活(社团/期刊/选本/文学史的四重机器),它的经典怎样被
制造与重造(经典化漏斗),它的边界怎样一次次被重划(起点之争/重写文学
史/网络文学入史之争)。它是 750 宇宙里**唯一以语言革命为起点**的国别
卷:1917 以前的中国文学换朝代不换语言,1917 以后连语言都换了——这是
本家族三条实验线(阵地网络/经典化漏斗/语言替换)的共同源头。

- **零门槛**:读过中学语文课本里的鲁迅朱自清老舍即有全部感性储备;
  只想看作家作品趣谈的读 00 章故事框即可,本家族管的是**文学怎么被
  组织、被筛选、被写进史**的机制
- 路线 A(问题派):白话为何几年内取代文言?→00 §七发现 3+实验幕三;
  张爱玲为何 1980s 才"重新发现"?→00 §七发现 2+实验幕二;论战为何
  这么多?→00 §七发现 1+实验幕一
- 路线 B(理论派):00→01(前沿地图)→02(新文学的语言怎么造出来)

> 三支的共同血统:同一个发问「**现代文学的建制再生产**」的三段落地——
> 奠基层管**发明**(白话+社团+期刊怎么造出新文学),体制层管**组织化**
> (文艺怎样被纳入体制又被体制重塑),媒介层管**再发明**(互联网是否
> 重演了 1917:新的语言、新的阵地、新的漏斗正在形成)。三层缺一即塌:
> 没有奠基层不知其所来,没有体制层不知其所变,没有媒介层不知其所在。
