## ② 核心思维模式(这个分支怎么想问题)

1. **建制之眼**:看到文学现象先问——阵地在哪(期刊/平台)?
   漏斗走到哪一级(发表/选本/文学史/榜单)?没有建制的文学
   事件先怀疑其存续力
2. **阵地即身份**:作家与社团的绑定靠刊物——谈归属先问在哪儿
   发表;跨社流动大量以论战形式发生(论战是文坛的社交协议,
   不是故障)
3. **断代之眼**:"现代"断在哪里——1917(语言)/1942(体制)/
   1949(政体)/1998(媒介)?断点不同,史的面目不同;分期是
   工作假设不是本体承诺
4. **漏斗之眼**:读文学史先找它的选本上游;读榜单先问它将锁定
   谁;经典化滞后创作约一代人,早期选本的覆盖率是路径依赖的
   存证
5. **相变之眼**:新旧规范之争不看辩论看份额——临界点以下改革
   免疫,越点不可逆;权威节点(刊物改版/政令/平台规则)是引爆器
6. **任务书之眼**:关键词自带时代任务书(白话=语言合法性/大众化=
   受众/民族形式=形式);听词先问它铸造于哪场论争、漂移到哪档口音
7. **通说+反方双录**:文学史叙述有版本(左翼叙事/审美重写/海外
   汉学),读任何定论先问它的筛选标准属于哪一版

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 作家群像卡(流动轨迹带年份) | 审计任何作家的归属叙述——无年份的归属是标签不是轨迹 |
| 期刊阵地卡(编辑权+革新节点+终刊) | 分析任何刊物/平台频道的建制角色;编辑权变动常是文学史事件本身 |
| 经典化轨迹卡(漏斗逐级节点) | 追任何"经典/名作/上榜"的来历;区分"缺证据"与"没查过" |
| 阵地密度+置换检验 | 量化"以期刊为阵地"的主张;主场份额 vs 随机期望 |
| 论战集中度 | 检验社团间接触以论战形式发生的程度 |
| 漏斗模型(时滞+锚+覆盖率) | 经典化路径依赖的量化;榜单/书单固化审计 |
| 相变模型(三不动点+权威冲击) | 新规范采用预测与复盘;份额监测用流量口径不用存量口径 |
| 三代关键词谱系(白话→大众化→民族形式) | 给任何新文学关键词定位代际与债务 |
| 大词语义史(启蒙/为人生/人民性) | 听到纲领词先问主语、任务与漂移 |

## ④ 常见误区与禁忌

- **把白话文运动当"口语写作"**:白话是被发明的书面语,不是说话
  的记录;文言残存是新文学文本的可测地层
- **把"为人生/为艺术"读成绝对对立**:论争有表演成分,文研会
  同样重创作,后期创造社急转革命文学
- **把左翼十年读成铁板一块**:左联内部有论战(两个口号),
  外部有平行繁荣(京派/上海现代派)——文坛的多中心是常态
- **把文学史当作品的直通车**:文学史写的常常是选本选过的;
  谈"入史"必问选本上游与版本(以哪个版本入史?)
- **把"重写文学史"当拆漏斗**:重写换的是筛选标准,不是三级
  漏斗本身;边际新增从来是一小撮
- **把辩论胜负当采用原因**:规范竞争看份额与临界点;白话的
  胜利是相变,1930s 的文论文战是用白话打的
- **用模型冒充史料**:阵地网络模拟量化的是组织生态的机制,
  笔名归并与期刊考据是文献学的活(历史学宇宙方法,互链)
- **把网络文学当"不算文学"的修辞题**:建制化后的问题已从
  "算不算"变成"如何运转"(类型引擎/平台漏斗/IP 链)
