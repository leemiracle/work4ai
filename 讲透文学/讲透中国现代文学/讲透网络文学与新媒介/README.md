  标志);1997-98 榕树下;2003 起点 VIP 付费制(通说:产业化节点);

  经典化还成立吗(漏斗之问)。

## 核心问题

**已解决(通说)**:产业化机制(付费阅读—日更—催更的生产节律;
升级-期待-兑现的爽感结构被付费节奏锻造的通行描述);建制化事实
(研究建制三件套[教材/年鉴/学位点]与作协吸纳,家族 [01 章](../01-近五年创新.md)主线 B)。

**未解决/深水区**:网络文学能否入史(点击榜漏斗与选本漏斗是否同构;
百万字连载与文学史单位的换算——家族 00 §四最热未决题);平台规则即
编辑权,算法筛选无法像选本序言一样被批评;AI 辅助写作对"作者"建制的冲击。

## ✨ 这支最美的一个事实

**千字两分钱的相变**:2003 年起点 VIP 付费制——一个商业模式的发明
定义了一个文类:按章节结算逼出日更,日更逼出可无限延展的类型,实时
数据逼出爽感节奏工程。**1917 年白话的胜利靠权威刊物改版引爆(家族
[实验](../experiments/journals_canon_narrative.py)幕三),2003 年的生产革命靠一条定价规则引爆**——
引爆器从"政令与改版"变成了"结算方式"。
