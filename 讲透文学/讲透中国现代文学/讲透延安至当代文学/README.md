# 讲透延安至当代文学 · 建制的换轨期——从讲话到市场

> **定位句**:这支负责**体制层(1942-)**——延安文艺与 1942 讲话
> (工农兵方向/民族形式落地)、十七年文学(作协刊物体系/双百/反右/
> 三红一创)、文革与地下写作、新时期文学(伤痕→反思→改革→朦胧诗)、
> 寻根与先锋(1985 前后)、1990s 至当代(市场化/人文精神讨论)。
> 口号:**文学被组织起来之后**;涉及各时期文艺政策,一律按学术史平实叙述。
> GB/T 13745 75031 中国现代文学 · **自定支(体制层)** · 家族:[讲透中国现代文学](../README.md)

## 诞生

- **谁/何时**:1942 延安文艺座谈会讲话;1949 第一次文代会(通说:
  当代文学起点);1950s 作协-刊物体系建成;1976 后新时期;1992 后市场化。
- **因什么问题**:①文学能不能被组织(体制之问)②写什么、怎么写由谁
  定(标准之问)③体制松动后文学怎样再分化(市场与审美重新立约)。

## 核心问题

**已解决(通说)**:一体化体制的运行描述(社团期刊制→作协刊物制:
所有制换了,阵地逻辑不变——家族 [实验](../experiments/journals_canon_narrative.py)幕一的机制在新
建制下延续);新时期分层叙事成教材通说;经典化代际时滞与重估
(张爱玲/沈从文线=漏斗可改道,幕二:海外节点=漏斗外入口)。

**未解决/深水区**:当代文学能否写史(唐弢之问);十七年边缘写作(地下写作/旧体延续/通俗残脉)的史学位置;1990s 后文学场自主性与市场的关系。

## ✨ 这支最美的一个事实

**《白毛女》的三级跳**:民间传说("白毛仙姑")→1945 延安鲁艺集体
创作的歌剧→1950s 电影→1960s 芭蕾舞剧(通说谱系)。**民族形式不是
理论,是一条改编链**:民间资源每升一级媒介与体制就被重写一次,而
"旧社会把人变成鬼,新社会把鬼变成人"的骨架贯穿到底——02 章三代
关键词在链上全部到场。
