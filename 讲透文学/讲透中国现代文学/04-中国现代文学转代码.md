# 04 · 中国现代文学转代码:把文学史结构搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:现代文学史的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**期刊阵地网络**、**经典化
> 漏斗**、**语言替换相变**——把"阵地即身份""文学史写的常常是
> 选本选过的""白话赢的不是辩论是网络效应"变成可跑、可断言、
> 可做参数扫描的实验;而平台时代(第三支)让这三条走廊第一次
> 有了全量数据。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",现代文学转代码要解决"**裁定与机械
的分离**":把一段学科语言("社团以期刊为阵地")先翻成模型
(作家×期刊×社团矩阵+阵地惯性),再翻成代码。翻译的损耗全部发生在
第一步的**裁定**里(笔名怎么归并、归属怎么定时段、份额按什么口径)
——所以本章先划清哪些对象的裁定已经结算清楚(绿色区),哪些永远
结算不清(红色区),再给三条结算清楚的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科概念 | 代码化身 | 备注 |
|---------|---------|------|
| 发表网络(阵地矩阵) | 作家×期刊×社团三元组清单;密度/Jaccard/覆盖率 | 幕一全程纯标准库;数据库时代可实证取数(01 章主线 A) |
| 阵地惯性 | 本社团阵地发表份额 vs 标签置换检验 | 4.9 倍差距类断言 |
| 论战集中度 | 跨社流向对论战对家的份额 vs 同边际均匀期望 | 幕一的判别性设计 |
| 经典化漏斗 | 发表→选本→文学史的概率级联;时滞与覆盖率统计 | 幕二;对照臂做因果分离 |
| 路径依赖 | 有锚/无锚双臂的跨版存续率对比 | 76% vs 12% 类断言 |
| 语言份额动力学 | p=σ(K(f−0.5)+A+e) 的逐年模拟;不动点求解 | 幕三;S 形/临界点/不可逆全可断言 |
| 三张结构卡(03 章) | 定长字段记录(dict/dataclass)+完整性断言 | 元走廊的元数据工程 |

**转不动(红色区)**:

1. **审美价值判断**:风格计量(词频/句长/标点节奏)量得出指纹,
   量不出好坏——"量得出收录,量不出好"。工程对策:退到细读
   (03 章右端),不当目标函数。
2. **笔名归并的经验认定**:模型可以演示阵地逻辑,"沈雁冰=茅盾=
   玄珠=……"的归并是文献学考据(工艺归[历史学宇宙](../../讲透历史学/README.md)
   方法,互链声明)——模拟不能冒充考据。
3. **"入史"的判定**:以哪部教材为准是史学立场问题;本家族实验
   用代表性教材序列做代理(幕二的裁定),换序列结论量级变、
   结构不变——**转码是裁定的使用说明书,不是裁定的替身**。
4. **分期叙述的取舍**:1917/1942/1949/1998 的断代之争(00 章§二)
   是史学论证,不进实验台;实验只在给定分期下量机制。

**边界的一句话**:绿色区=矩阵类+漏斗类+份额类,覆盖"建制直觉的
校准与测量方案的原型";红色区提醒:**文学史的意义层靠读不靠算,
建制层靠算不靠猜**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:期刊阵地网络走廊(组织生态的全机械化)

```
"阵地即身份,论战即接触" ──参数化──▶ 作家×社团归属+阵地惯性+论战权重
      │                                        │
      └──检验──▶ 置换检验 / 论战集中度 / Jaccard ──▶ 断言
```

- **理论→模型**:作家带社团归属与固定跨社渠道;每篇发表按阵地
  惯性落本社团期刊,跨社渠道按论战权重抽取(论战对 5:其余 1)。
- **算法层**:加权抽样生成发表记录;密度=落点与归属的重合率,
  期望=社团标签随机置换的分布(400 次);集中度=跨社落点对论战
  对家的份额 vs 均匀期望;期刊对 Jaccard 同社/跨社分组统计。
- **本家族实现**:[`experiments/journals_canon_narrative.py`](experiments/journals_canon_narrative.py)
  幕一——断言阵地份额 ≥3 倍置换期望、论战集中度 ≥1.8 倍、
  两栖主第二阵地 ≥1.8 倍均匀、同社 Jaccard ≥3 倍跨社。
- **真实系统**:民国期刊数据库的**阵地研究流水线**(笔名归并+
  发表矩阵+社团归属表——数字人文的现成工程);更远的谱系:
  平台创作者生态的多平台分布分析(落点 1)。
- **性能工程要点**:置换检验 400 次彼此独立,按置换号分流
  seed=base+序号,天然可并行;矩阵在十万级发表记录下仍是稀疏
  dict 的天下,别上重框架;断言只锚比值与量级,不锚尾数。

### 走廊 2:经典化漏斗走廊(路径依赖的因果分离)

```
"文学史写的常常是选本选过的" ──参数化──▶ 发表→选本→文学史概率级联
      │                                          │
      └──对照臂──▶ 无锚世界(逐版独立重抽) ──▶ 存续率对比断言
```

- **理论→模型**:作家带创作峰值与天赋分位;锚(1935 大系)按
  天赋筛第一轮;后续选本与文学史接力(成员高概率存续,非成员
  小概率凭天赋与"重写开口"进入);对照臂删锚逐版重抽。
- **算法层**:概率级联逐步推进;统计时滞分布(首次文学史化−
  峰值)、锚成员/非成员的入史率、名单覆盖率、跨版存续率。
- **本家族实现**:同实验幕二——断言中位滞后 ≥25 年、锚成员入史
  率 ≥2 倍非成员、名单覆盖率 ≥0.60、有锚存续 ≥1.3 倍无锚
  (实测 6.3 倍)。
- **真实系统**:任何"**早期精选锁定后续序列**"的系统审计——
  推荐系统的冷启动榜单固化(第一年的歌单决定五年的曲库)、
  课程书单的代际传递、开源项目的早期 star 结构与后续贡献者
  构成(落点 2)。
- **性能工程要点**:级联是逐事件的独立抽签,embarrassingly
  parallel;名单覆盖率这类比率指标注意分母规模(同龄段 n<30
  时区间宽,断言降级为方向性);对照臂与主臂共用作家池(配对
  设计),变异减半。

### 走廊 3:语言替换相变走廊(规范竞争的动力学)

```
"白话赢的不是辩论,是网络效应" ──参数化──▶ p=σ(K(f−0.5)+A+e) 逐年演化
      │                                        │
      └──对照臂──▶ 无权威冲击世界 ──▶ S形/临界点/不可逆断言
```

- **理论→模型**:每年 M 条新出版物;单条选白话的概率随份额
  超线性上升(逻辑斯蒂响应);外生冲击=权威节点转向(期刊改版/
  政令/平台规则);对照臂无冲击。
- **算法层**:逐年二项抽样的份额更新;不动点数值求解(二分);
  临界穿越速度与回落率统计(蒙特卡洛)。
- **本家族实现**:同实验幕三——断言 S 形(最大增量年 1919-1921)、
  有冲击臂 ≥95% 实现终局 ≥0.9 而对照臂卡低均衡、穿越 ≤2 年、
  回落率 ≤2%。
- **真实系统**:**新规范/新格式/新工具的采用监测**(技术侧的
  日常决策:何时押注新栈?看份额离临界点还有多远,而不是看
  辩论谁赢);平台的内容形式变迁(短视频对图文、付费对免费)
  全是同构问题(落点 3)。
- **性能工程要点**:二项抽样用循环计数在 M=600 规模足够;百万级
  换 `random.binomialvariate`(3.12+)或正态近似;不动点求解的
  二分区间要先用符号检查括住根(本章实测:三个不动点,低均衡
  与临界点容易被混——先画 g(f)=σ(·)−f 的符号表再二分)。

### 元走廊:结构卡校验器(03 章三卡的机器执法)

三张卡各成一类记录;完整性断言(作家群像卡的**流动轨迹带年份**
——无年份的归属是标签不是轨迹;期刊阵地卡的**编辑权变动栏**
非空——挂名与实编必须分账;经典化轨迹卡的**漏斗每级节点或显式
留空注明**——缺证据与没查过是两个字段)。这是元数据工程:
价值不在计算量,在纪律——把 02 章"任务书三关"与 03 章"判定
流程"编译成校验器(留作 ✍️练习 1)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:创作者生态的阵地-身份审计

给任何多平台内容系统(视频/图文/播客)配一次幕一体检:创作者的
"主场份额"(核心平台发文占比)是多少?跨平台流动是随机的还是
向"对家平台"集中(论战的工程版:平台互怼越凶,双栖创作者越多)?
**幕一的教训是双向的**:主场黏性带来身份与流量复利,也带来
身份锁定(换个平台,读者不认)——签约与独家条款定价之前,
先量主场份额。

### 落点 2:推荐与选品的路径依赖审计

推荐系统的冷启动榜单、编辑精选的年度书单/歌单,都是幕二那只
"1935 大系":**早期精选决定后续序列的覆盖率**(实测类比:66%)。
审计动作:现任榜单/书单对首年版本的覆盖率逐年画曲线;覆盖率
不降说明漏斗已固化,此时"个性化"只在边际 9% 里做文章——要么
接受(经典化的稳定是产品特性),要么做"锚外入口"(幕二张爱玲
线:主动引入外部评价体系打破锁定)。

### 落点 3:新规范采用的相变监测

团队或行业引入新规范(新框架/新编码/新流程)时,别问"辩论谁赢",
问三个数:**当前份额**(新规范在新产出中的占比,不是存量占比)、
**临界点**(从众响应曲线的不动点)、**权威节点**(谁能引爆——
 flagship 项目的切换等价于《新青年》改版)。份额在临界点以下时
推不动是结构不是人心;推过临界点后连反对者也自动跟进(幕三:
回落率 0.0%)。KPI 设计:**监测"新产出份额"而不是"存量份额"**
——幕三的 f 是流量口径,存量口径会掩盖相变。

### 落点 4:多版本资产的漏斗台账

"一源多版"资产(多端文档/多语言站点/长线 IP)按经典化轨迹卡
建档:首发版本、现行流通版本、各入口(搜索/推荐/外链)对版本的
覆盖率——**流通版本≠最新版本≠你想要的版本**,这是漏斗逻辑在
工程里的日常显形;版本链断档(初版不可考)要显式标注,不与
"没查过"混填。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:台账之眼**——看到任何内容生态、任何序列
(榜单/书单/经典/规范),先问三件事:阵地份额多少(身份结构)、
早期锚锁了什么(漏斗结构)、份额离临界点多远(相变结构)。转码
让这三问从修辞变成可跑的断言;而红色区的边界同样有用:**建制
算得出,价值读出来**——两套设备各干各的活。
