# 讲透文学批评 · 裁判席的坐姿史——每换一个框架,同一批作品重新排名一次

> **本质一句话**:文学批评=给"这个文本**好在哪、坏在哪、是什么**"下可辩护判断的
> **可训练手艺**——理论(75011)造眼镜,批评戴眼镜看具体作品;一部批评史=
> 裁判席上换了一轮又一轮坐姿:从作家的生平(圣伯夫)坐到文本的肌肤(新批评),
> 再坐到语言的深层结构(结构主义)、身份与权力(女性主义/后殖民)、直到
> 整个书架(计算批评);一句话:**每个批评框架都是一张特征打分表——
> 框架换代,同一批作品就被重新排名一次**。
>
> GB/T 13745-2009:750 文学 · 二级学科 **75017 文学批评**(无三级明细→自定 3 支)。

## 一、家族定位

- **三支分工**:同一门"怎么对文本下判断"的三种组织法——
  **方法史支**(纵切编年:传记-历史式→形式主义→新批评→结构后结构→文化研究,
  裁判席坐姿的更换史)、**当代批评实践支**(横切装备:女性主义/后殖民/生态批评/
  酷儿理论,现役政治批评框架的对垒)、**计算批评支**(新尺度:cultural analytics/
  情感分析/主题建模,把证据单位从单篇扩到语料)。
- **一条主轴贯穿全家族**:**框架=特征打分表**——任何批评框架都可以问三件事:
  它给文本的哪些特征开权重?哪个维度的权重最高?两框架的权重差落在哪一列?
  (家族实验幕三:两框架排名 Spearman 可低至 0.16,反转系统性偏向权重差最大的列)
- **零门槛**:不要求文学史前置;想看文本与史料去国别/断代家族,想看概念去
  文学理论;本家族管的是**判断的生产线**。
- 路线 A(问题派):批评有没有客观性?→00 §二;一部小说为什么会越读越有味?→
  00 §七+方法史支新批评段
- 路线 B(方法派):00→方法史支(坐姿编年顺读)→当代实践支(现役装备)→计算批评支
- 路线 C(研究派):00→01(文献地图)→02(批评话语怎么互相翻译、怎么泄漏进公共语言)
- 工程师快轨:直接跑 [`experiments/arcs_paradigms.py`](experiments/arcs_paradigms.py),再回读 04 章

| [`experiments/arcs_paradigms.py`](experiments/arcs_paradigms.py) | 情感弧线与批评范式三幕模拟(纯标准库,固定种子,assert 自验证)。**三律**——①六型弧线(白手起家/悲剧/U 型/伊卡洛斯/俄狄浦斯/灰姑娘变体)由"初始值+分段漂移"参数化生成,z 标准化后 k-means(k=6,k-means++ 十次重启)收出六纯簇且与六型双射,留出集识别 24/24;打乱段落后识别率跌至 16.67%(恰=随机基线 1/6)——情感形状住在段落次序里,不在词频里 ②细读 vs 远读:弱信号主题检出率随样本量严格单调升(5→320 篇:0.158→0.952);同为 3 篇,细读(全读)完胜浅读(强信号 1.000 vs 0.728),但弱信号下细读系统性漏检(0.343),唯规模可救——莫莱蒂"远读"的统计学本体:尺度即方法 ③范式排名反转:60 部作品在两框架(审美自律 vs 政治批判)下 Spearman ρ=0.163,10 部系统性反转;反转作品在权重差最大维度(政治介入,|Δw|=0.90)上极端得多(偏置 0.842,其余维度 ≤0.228);抹平该维度后 ρ 升至 0.686——范式不是镜片度数差,是打分表的列不同 | ✅ |
