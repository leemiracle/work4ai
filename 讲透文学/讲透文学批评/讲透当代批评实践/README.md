# 讲透当代批评实践 · 现役政治批评装备——立场即方法的四支军团

> **定位句**:这支负责**现役框架装备**:女性主义批评(米利特《性政治》1970/肖瓦尔特/吉尔伯特-古芭《阁楼上的疯女人》1979)、
> 后殖民批评(赛义德《东方学》1978/斯皮瓦克"属下能说话吗?"1988/霍米·巴巴杂糅)、生态批评(格罗特费尔蒂《生态批评读本》1996)、
> 酷儿理论(塞奇威克《密柜认识论》1990/巴特勒《性别麻烦》1990 性别操演)——共同纲领:**阐释的每一步都有政治后果,文本里没有无辜的角落**。
> 近五年主战场:去殖民转向(从读出边缘到拆学科建制;家族 [01 章 §二](../01-近五年创新.md))。
> GB/T 13745 750 文学 · 二级学科 **75017 文学批评 · 自定主干支**。家族:[讲透文学批评](../README.md)

## 诞生

- **谁/何时**:前史伍尔夫《一间自己的房间》1929;1970 米利特把名作家送上性别法庭;1978 赛义德揭示"东方"的文本制造;
  1990 塞奇威克-巴特勒双年开酷儿理论;1996 生态批评成建制。
- **因什么问题**:①正典为什么几乎全是死去的白人男性(正典之问)②文本如何参与压迫的再生产(再现之问)
  ③被静音者如何被读出而不被再度代言(表述之问,斯皮瓦克的核心焦虑)。

## 核心问题

**已解决(通说)**:
- 正典可重写:沉默者被读出,边缘文本入典(1970s-90s 建制成果)
- 抵制性阅读/双重身分析/属下分析成为标准动作(细读的政治化)
- "立场即方法"的合法性:阐释位置必须声明(与科学端"价值中立"的对等谈判)

**未解决/深水区**:
- 政治记分与美学成就的换算率(对手批评:"主题先行"的边界在哪)
- 表述悖论:替属下说话是否又一次剥夺其声音(斯皮瓦克之问未解)
- 去殖民转向的操作化:拆建制(书目/流通等级)的可行方案(进行中)

## ✨ 这支最美的一个事实

**巴特勒的性别定义**:性别不是一个名词,而是一句被重复念的话——
没有先于表演的表演者,是重复本身把"女人"/"男人"念成了实体。一次术语转移(名词→动词),
把"天生如此"与"社会建构"的百年对峙改写成同一个机制的两半。

## 假设与依赖

- 买入"文本政治性优先":一切再现都在权力结构中;每个框架带账单(有把美学成就换算成政治记分的倾向,家族 [00 章 §五](../00-体系结构.md))
- 立场声明纪律:声明阐释位置(女性主义/后殖民/酷儿/生态),不混踩(批评写作的范式纪律)
- 装备依赖谱系:方法史支供框架出身(政治批评=结构后结构的批判续集);论证链卡(03 章)是本支论文的可检查格式
