# 03 · 可构造与结构:哪些批评对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:文学批评的对象沿一条**可构造谱系**排开——情感
> 弧线端**严格可构造**(序列写得下、聚类收得回、打乱后断言得了),
> 批评框架端**半构造**(权重表可写,但"看哪些特征"带判断),阐释
> 有效性端**几乎不可构造**(赫什的"含义"没有重建程序);全谱系共享
> 三条结构引擎:**次序决定形状**(弧线引擎)、**证据量决定可见性**
> (检出力引擎)、**权重决定排名**(打分表引擎);而批评的日常资产
> 可以被压进三张**结构卡**(框架卡/细读笔记卡/论证链卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
情感弧线 ── 主题信号 ── 框架权重表 ── 细读笔记 ── 排名反转 ── 阐释有效性 ── 审美价值判断
  │                                                                          │
严格可构造(可断言)                                          几乎不可构造(只有思想操作化)
  └── 写得出、算得动、能过 assert                          └── 只能在阅读与论辩里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:情感
弧线的语义是"每段的情绪分",输入输出明确;而"这个解读是否忠实于
含义"的语义要重建一个不在场的意图——**法庭缺被告**。本章先盘家底,
再看三条结构引擎,最后把批评的三种日常资产(框架/细读/论证)压成
三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **情感弧线** | 漂移模板(初始值+分段漂移)+噪声;或实测逐段打分 | 低(实验幕一全程可跑) | 情感测量的文化偏差;对次序不敏感的表示测不出形状(02 §二) |
| **主题信号检测** | 词袋+背景率+阈值检验(实验幕二) | 低 | 检出=统计可见,不是"重要";弱信号小样本必漏 |
| **框架权重表** | 特征×权重的定长表(实验幕三) | 低 | "看哪些特征"本身带判断;权重只能写不能证明 |
| **排名比较** | 两框架打分+Spearman+反转集合 | 低 | ρ 只测秩序一致,不测哪张表"对" |
| **细读笔记卡** | 选段/手法指认/张力链的固定字段(§四) | 中 | 半构造:指认靠训练出的眼力,双人校是纪律 |
| **论证链卡** | 前提→文本证据→推理→结论+反驳位(§四) | 中 | 反驳位留白=论证未完成;链条强度≠结论为真 |
| **正典清单** | 选集/书目/翻译计数的数据化 | 中 | 计数测流通权力不测价值;清单构造易,清单**辩护**难 |
| **阐释有效性** | 只有思想操作化(含义的重建程序缺被告) | 高 | **构造学缺席**——赫什判据(作者意图)不可全验,费什判据(共同体规约)只描述不裁决 |
| **审美价值判断** | "好在哪"的最终定夺 | **不可构造** | 可列出全部证据(半构造),权重合成与最终裁断永远回到判断者 |

**反直觉发现(本章铁律)**:**批评最著名的成就在右端,最能跑的对象
在左端,而学科的生产力在中间**。右端管洞察(阁楼上的疯女人是细读,
不是算法),左端管检验(六型是否稳定、弱主题是否可见、排名反转是否
真实),中间的结构卡管**传承**(批评训练的本质就是教人填卡)。
用左端硬造右端指标("审美价值打分器")与用右端拒绝左端证据
("数字不算文学研究")是镜像对称的两类事故。

## 二、结构引擎 1:次序决定形状(弧线引擎)

**直觉图像**:叙事的情感不是一堆情绪的集合,是一条**轨迹**——
同样的情绪值,排列次序不同,故事形状完全不同。

- **数学化身**:弧线 = 初始值 + 分段漂移(漂移方向与切换点定义"型")
  + 逐段噪声;六型=漂移组合的六个参数化(白手起家/悲剧/U 型/伊卡洛斯/
  俄狄浦斯/灰姑娘变体)。
- **三条刚性**(实验幕一的数值化身):
  1. **可聚类收回**:参数化生成的弧,z 标准化后 k-means 收出六个纯簇,
     簇-型双射,留出集识别 24/24——"型"不是聚类算法的礼物,是数据的
     真实结构。
  2. **打乱即随机**:段落次序随机重排(情绪多重集不变),识别率
     16.67%=随机基线——形状住在次序里。
  3. **表示依赖**:任何对次序不敏感的表示(词袋/主题模型)原则上测
     不了弧型——引擎给"该用什么量"立了表示层判据(02 §二)。
- **刚性从哪来**:聚类的数学是刚的(分离良好的簇);软的地方在
  **情感分从哪来**(词典/模型/人工打分,各有偏差)——实验里我们
  指定模板,现实里要靠测量,测量侧的账单要另付(计算批评支)。

## 三、结构引擎 2 与 3:证据量决定可见性(检出力)/ 权重决定排名(打分表)

**引擎 2 直觉图像**:"存在一个弱主题"是一个统计命题——它能否被
看见,不取决于目光的虔诚,取决于**读到的总词数**。

- **数学化身**:检出力随证据量 T 按 √T 爬坡(实验幕二:弱信号检出率
  5→320 篇从 0.158 单调升到 0.952);深度(单篇全读)与规模(多篇浅读)
  的分工由信号强度决定:强信号 3 篇细读完胜(1.000 vs 0.728),弱信号
  细读系统性漏检(0.343),唯规模可救。
- **刚性从哪来**:二项检验的功效曲线是刚的;软的地方在**背景率的
  假定**(实验假设已知 p0=0.02,现实要估计)与"主题=共现结构"的
  操作化(02 §二的坑)。
- **批评史地位**:这条引擎把莫莱蒂的"远读"口号翻译成了统计命题:
  **尺度不是态度,是功效**——它同时给细读划了领地(强信号/单篇深描)
  和远读划了领地(弱信号/语料普查),两派之争由此可判:争的其实是
  目标信号的强度。

**引擎 3 直觉图像**:批评框架=特征打分表;作品的名次=特征在权重上
的投影。框架分歧不在"看不看得见",在"给哪列开多少分"。

- **数学化身**:两框架排名的 Spearman ρ 可低至 0.163;反转集合系统
  偏向权重差最大的维度(偏置 0.842 vs 其余 ≤0.228);抹平争议维度,
  ρ 跳至 0.686(实验幕三)。
- **刚性从哪来**:线性加权+独立特征下,排名相关由权重内积决定——
  这是**可计算**的;软的地方在特征本身的选取(一张表纳入哪些列,
  是框架的政治,引擎 3 测不出)。
- **批评史地位**:它把"范式之争"从修辞变成算术——每次批评史
  "重新发现一位作家",可还原为打分表的改版;00 §七发现 3 的机制层。

## 四、结构卡 schema:把批评资产压进三张卡

**先答为什么**:批评的难点在"整体性"——一个框架、一次细读、一条
论证,读散落文献难以携带。结构卡是**有限字段的压缩格式**:字段固定、
填空即可复用、可比可查可补(这是"可构造"在批评层的对应物:卡片
本身严格可构造)。

### 卡 1:批评框架卡(把一个框架钉进坐标系)

```
【批评框架卡】
框架名:________
核心之问(它问文本什么):________
特征清单与权重(打分表的列×分):________
判断工序(三步以内):________
买入假设(≤3 条):________
付出盲区(≤3 条;它给什么记零分):________
前任框架与修复点(它救了谁的危机):________
可构造代理(谱系位置):________
对手框架(权重差最大的那张表):________
```

样例(已填,新批评):核心之问=文本如何组织成有机整体;特征与权重=
张力/悖论/复义/反讽(形式列 9 分),语境/作者/读者各 0-1 分;工序=
逐行指认→张力网→整体解释;买入:文本自足、意义全在手法、双谬误;
盲区:历史与读者被驱逐,形式精巧≠价值;前任=传记-历史式(修复点:
把目光从生平搬回页面);可构造代理=细读笔记卡(卡 2);对手=
马克思主义批评(00 §五互为账单)。

### 卡 2:细读笔记卡(把一次细读变成可复核的记录)

```
【细读笔记卡】
对象文本/选段:________(精确到行/段)
手法指认(每种手法→行号证据):________
张力链(哪两股力量如何互相牵制):________
复义清单(歧义的各支+共存证据):________
步骤性解读(局部→整体的收拢):________
备选读法(第二人可能怎么读+分歧点):________
一句话判断(这段好在哪/坏在哪):________
```

样例(已填,鲁迅《秋夜》开头):对象="在我的后园,可以看见墙外有
两株树,一株是枣树,还有一株也是枣树";手法指认=同义反复的延宕
(不是"两株枣树"而是分两次看见);张力链=观察的缓慢(时间被拉长)
vs 陈述的重复(语义为零);复义=单调烦闷的心境/刻意的凝视仪式/
对"写出"本身的拖延;备选读法=语法教学式(病句说)——分歧点在
语境权重;一句话判断=用语义的零度换取时间的厚度,心境先于景物
进入文本(通说细读口径)。

### 卡 3:论证链卡(把一篇批评论证写成可检查的链)

```
【论证链卡】
论题(一句话):________
前提(不可省的假设,≤3):________
文本证据(行号级,≥3 条):________
推理链(前提×证据→结论的每一步):____ → ____ → ____
反驳位(最强的反例与回应):________
结论的适用边界(它不证明什么):________
```

样例(已填,"阁楼上的疯女人"):论题=伯莎是简的被放逐的自我;前提=
维多利亚淑女规范压抑女性愤怒/小说需要为女主保持"可敬"/双重身是
时代常见装置;证据=伯莎每次出场恰在简愤怒压抑之后(婚礼前夜撕面纱)/
伯莎的行为与简的暗念呼应(纵火与简的灼热梦境)/镜像场景(简看镜中
"异样的脸");推理链=愤怒无处安放→文本需容器→伯莎承接全部→
双重身成立;反驳位=也可能是单纯的哥特惯例(回应:惯例为何恰在此处
启用);边界=不证明作者有意为之,只证明文本结构支持此读。

**判定流程**(把一个批评主张钉到谱系上):

```
该主张的核心对象能写成序列、表格或链吗?
  ├─ 能,且语义有限确定 ──────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(卡片/清单,填空带判断)─▶ 中段:卡片化+双人校,禁止硬算
  └─ 不能(含义/价值/最终裁断)──▶ 右端:思想操作化+论辩,禁止压成参数
```

## 五、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 批评方法史 | 中段为主(框架卡的历史串),两端各有标本 | 打分表(改版史=引擎 3 的编年) | 中(框架卡可数据化,论战还原靠阅读) |
| 当代批评实践 | 右端为主(立场与洞察),论证链卡为中段 | 打分表(新列的开立)+文本证据 | 低-中(论证链可检查,立场不可构造) |
| 计算批评 | 左端(弧线/信号/排名全可跑) | 弧线+检出力+打分表三引擎并用 | 高(全程 assert;测量偏差是软肋) |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——计算批评
走计算,方法史走卡片与编年,当代实践走论辩与细读。**没有哪支全家
可构造,也没有哪支全家不可构造**;最深的误解是拿左端工具否定右端
判断(或反之)。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——把一百七十年批评史装进上衣口袋**(极简)
框架卡定位(哪张打分表、什么账单),细读笔记卡验货(证据指到行号
了吗),论证链卡开审(前提是什么、反驳位在哪)。为什么美:**它把
"读懂批评"变成"填得出卡"**——可复核性从实验室移进阅读;三卡
互相引用(框架卡挂细读卡,细读卡喂论证链),一个批评传统的强度与
磨损一目了然。亲历:挑一篇你信服的批评文填三张卡(✍️练习 1),
填不出的格子就是它的(或你的)盲区地图。

## ✍️ 练习

2. 🐍 在家族实验幕一里把六型模板的漂移切换点各挪 5 段(如 U 型

4. ✋ 用 §四判定流程给两个主张定位:"该作者的环保主题词频五年翻倍"
   (左端)与"这部小说的结尾是对读者的宽恕"(右端)——各自的证据
   该长什么样

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:卡片之眼**——看到任何批评主张,先问三张卡填得
出吗:框架(哪张打分表、给哪列记零分)、细读(证据指到行号了吗)、
论证(前提与反驳位在哪)。以及一问硬指标:**它的核心对象在谱系
哪一端**——左端去算,右端去辩,中段填卡双人校。
