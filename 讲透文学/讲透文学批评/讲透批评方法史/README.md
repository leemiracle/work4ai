# 讲透批评方法史 · 裁判席的坐姿编年——从认识作者到拆解结构到阅读文化

> **定位句**:这支负责**方法谱系本体**:裁判席的坐姿如何一代代更换——传记-历史式(圣伯夫《月曜日漫谈》1849 起/丹纳种族-环境-时代 1863)→形式主义与
> 新批评(什克洛夫斯基陌生化 1917/瑞恰慈-布鲁克斯细读 1929-47/意图谬误 1946)→结构后结构(弗莱原型 1957/巴特《S/Z》1970/《作者之死》1967/德里达)→
> 文化研究(霍加特-威廉斯-霍尔,伯明翰 1964 建制)。每次换坐姿=对上一代盲区的修复+打分表改版。
> GB/T 13745 750 文学 · 二级学科 **75017 文学批评 · 自定主干支**。家族:[讲透文学批评](../README.md)

## 诞生

- **谁/何时**:1849 圣伯夫开专栏(传记式);1863 丹纳立三要素(历史式);1917-1947 形式主义-新批评把目光搬回文本;
  1957-1972 弗莱-结构主义画整体地图;1967-1970s 后结构拆椅;1957-1970s 文化研究拔界碑(通说编年见家族 [00 章 §一](../00-体系结构.md))。
- **因什么问题**:①判断的标准从哪来(标准之问:作者/文本/结构/文化)②每次换代修复了什么盲区(修复之问)
  ③"科学批评"梦为何屡败屡战(科学之问:从丹纳到计算批评的百年续集)。

## 核心问题

**已解决(通说)**:
- 生平≠作品(普鲁斯特《驳圣伯夫》);意图/感受不能当法庭(双谬误)——作者侧的两个里程碑
- 细读成为可教学、可复核的职业程序(瑞恰慈-布鲁克斯)
- 结构-后结构的连续性:《S/Z》是同一实验的两半(可分析与不可穷尽)

**未解决/深水区**:
- 换代是进步还是时尚?(打分表改版有无方向——家族实验幕三只证"可重排",不证"更对")
- 文化研究之后,批评对象还有边界吗(万物皆文本的代价)
- 科学端的百年执念:批评能否有累积的知识(计算批评是最新一次押注)

## ✨ 这支最美的一个事实

**普鲁斯特的反驳方式**:圣伯夫说"认识人才能读书",普鲁斯特没有写论战文章——
他写了《驳圣伯夫》与《追忆似水年华》:**用一部传记式批评读不懂的杰作,反驳一种读法**。
最好的方法论反驳不是论证,是作品——批评史的真理常常由创作来判。
