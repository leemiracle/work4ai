# 讲透计算批评 · 新尺度上的裁判席——cultural analytics/情感弧线/主题建模

> **定位句**:这支负责**证据与尺度**:文化分析(cultural analytics)工具线——莫莱蒂"远读"(2000)开山,Jockers《Macroanalysis》(2013)示范,
> Reagan et al.(2016)六型情感弧线成经典锚,《文化分析杂志》(JCA,2016 创刊)立规范;近五年进入工具化阶段(嵌入表示/大模型辅助测量,检索校准 2026-09-07)。
> 纲领:**有些批评问题只能在一千部作品的规模上回答**——尺度不是态度,是功效(家族 [实验幕二](../experiments/arcs_paradigms.py))。
> GB/T 13745 750 文学 · 二级学科 **75017 文学批评 · 自定主干支**。家族:[讲透文学批评](../README.md)

## 诞生

- **谁/何时**:2000 莫莱蒂《世界文学猜想》造"远读"(读个别文本之外的模式);2005《图表·地图·树》示范;2013 Jockers 宏观分析;
  2016 Reagan et al. 六型+JCA 创刊;2023-24 文化分析工具化(方向锚,家族 [01 章 §一](../01-近五年创新.md))。
- **因什么问题**:①正典太小,文学太大(尺度之问:只读几百部怎么谈"文学"的规律)②批评直觉能否检验(可验之问:
  "故事就那么几种"能不能算)③测量与判断的分工(边界之问:模型能给什么、不能给什么)。

## 核心问题

**已解决(方法共识扩展中)**:
- 远读可行:聚合模式(弧线/主题/网络)可计算、可复现
- 六型情感弧线在多语料上被反复引用与复制(经典锚)
- 细读/远读的分工可形式化:信号强度×样本量的功效裁决(实验幕二)

**未解决/深水区**:
- 模式≠意义:黑箱给出的形状是"发现"还是"投影"(可解释性是最硬的问题)
- 语料偏差:数字化书架的幸存者偏差被当"规律"
- 测量校准:情感模型的文化偏差/讽刺反分(测量侧账单,03 章右端警告)

## ✨ 这支最美的一个事实

**几千个故事,六种心跳**:Reagan et al. 把语料库数千个故事的情绪轨迹聚类,
人类的讲故事方式收束为六种基本形状(白手起家/悲剧/U 型/伊卡洛斯/俄狄浦斯/灰姑娘变体)——
且家族实验幕一证明这六型住在**段落次序**里:打乱章节,识别率恰落随机基线(16.67%)。多样性下面的不变量,次序里面的结构。

## 假设与依赖

- 买入"文本可数值化且数值保留批评相关信息";付出语义压缩损耗、语料偏差、模式≠意义(家族 [00 章 §五](../00-体系结构.md) 账单)
- 尺度纪律:任何"没发现"先查功效设计(样本量×信号强度);任何"发现"先查表示敏感性(对次序敏感吗?)
- 工具不中立:情感词典/嵌入模型自带文化先见——测量偏差是本支的第一市民
