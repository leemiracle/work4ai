# 文学批评思维技能卡(讲透文学批评 · GB/T 75017)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **方法史类**:传记式批评、种族-环境-时代、驳圣伯夫、陌生化、文学性、
  实用批评、新批评、细读(close reading)、复义、意图谬误、感受谬误、
  精致的瓮、原型批评、四种神话素
- **结构后结构类**:叙事学、功能(普罗普)、叙事话语、S/Z、五种代码、
  作者之死、互文性、解构、盲视与洞见、可读的文本/可写的文本
- **政治批评类**:政治无意识、永远历史化、性政治、阁楼上的疯女人、
  东方学、属下(subaltern)、杂糅、密柜认识论、性别操演、生态批评、
  编码/解码、文化研究、伯明翰学派
- **阐释理论类**:含义与意义(赫什)、接受美学、召唤结构、阐释共同体、
  反对阐释、影响的焦虑、怀疑阐释学
- **计算批评类**:远读(distant reading)、文化分析(cultural analytics)、
  情感弧线、六型形状、主题建模、正典量化、细读vs远读
- **判断类**:批评的客观性、正典之争、书评怎么写、这部作品好在哪

## ② 核心思维模式(这个分支怎么想问题)

1. **打分表先行**:听到任何批评判断,先问三件事——它给哪些特征开了
   权重?哪列权重最高?它给什么记零分?框架换代=打分表改版=作品重排
2. **工序检查**:批评术语是压缩包——"细读""反讽"各压着一套判断
   工序;说得出工序的词才是术语,说不出的是修辞
3. **证据可指认**:判断的权威来自行号级证据,不来自身份;细读的
   复核条件是第二人能重做
4. **次序敏感**:情感弧型住在段落次序里;对次序不敏感的表示(词袋/
   主题模型)原则上测不出形状——选量先问它对文本哪一层敏感
5. **功效思维**:"语料里有没有弱主题"是统计功效问题:弱信号需要
   N,不是注意力;没有功效设计的"没发现"只是没测到
6. **深度与规模的分工**:单篇深读(细读)与语料浅读(远读)之争
   由信号强度裁决——强信号深读完胜,弱信号唯规模可救;两派不是
   品味之争,是分工
7. **立场声明**:写批评先声明主导框架(哪张打分表),再声明借了
   别的列;通篇换列而不声明,读者无法复核你的权重

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 框架卡(核心之问/特征权重/账单/前任修复点) | 把一个批评框架压进可携带字段;比较框架;找自己的默认表 |
| 细读笔记卡(手法指认/张力链/复义/备选读法) | 把一次细读变成可复核记录;批评写作的前置工序 |
| 论证链卡(前提/证据/推理/反驳位/边界) | 检查一篇批评论证的强度;写书评的骨架 |
| 六型弧线模板(白手起家/悲剧/U/伊卡洛斯/俄狄浦斯/灰姑娘变体) | 叙事节奏分析;连载监控;次序敏感性的对照实验 |
| 检出力曲线(样本量扫描) | 语料主题普查前的样本量预计算;"没发现"的效力评估 |
| Spearman+反转集合+维度偏置 | 量化两个榜单/两个框架的分歧结构;榜单差异归因 |
| 抵制性阅读(读出被静音者) | 政治批评的标准动作:谁被写成功能性怪人/谁替谁承担不可言说 |
| 双重身/镜像分析 | 文本内部被放逐部分的定位(疯女人式读法) |
| 编码/解码三位置(主导/协商/对抗) | 受众与文本的意义争夺分析(媒介侧接传播学) |

## ④ 常见误区与禁忌

- **把意图谬误读成"作者无关论"**:谬误在"以意图为意义法庭",
  不在研究作者;赫什的边界案(含义/意义之分)是必备反例
- **把细读当态度词**:"我细读了"≠细读;没有行号证据与可复核工序
  的"细读"是印象式批评的制服
- **把解构当拆穿**:解构是严格阅读(找文本自我瓦解的等级),
  且解构者自己也被解构(自反性);单向的"解构"是冒名顶替
- **拿均值说形状**:情感均值相同的两条弧可以是六型之差;次序不敏感
  的指标测不出弧型(实验:打乱段落后识别率=随机)
- **拿功效问题当眼力问题**:"远读没发现细读的洞见"或"细读看不见
  语料的模式"多数是信号强度与样本量的错配,不是方法优劣
- **拿计数当价值**:正典指数(选集/翻译/被引)测量流通权力,
  不测量审美价值;两张表列不同,ρ 低不是谁错了
- **测量冒充判断**:模型能给弧线(测量),给不了"弧线用得好不好"
  (判断);把工具化读成替代论的第一步就是混淆这两层
- **政治帽子化**:"这就是政治正确"式终结对话——批评内部的问题是
  可辩论的个案(怎么指称才公正),帽子把问题杀死了
