  Cherry Studio is an open-source desktop AI client designed for Windows, macOS, and Linux that unifies access to multiple Large Language Model (LLM) providers [docs/cherry_studio.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L5-L5) It serves as a comprehensive orchestration platform, supporting over 300 pre-configured assistants, knowledge base RAG (Retrieval-Augmented Generation), Model Context Protocol (MCP) servers, and multi-channel messaging integration [docs/cherry_studio.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L5-L5)

 
## Platform Availability and Installation

 The client is distributed as a native application across all major desktop operating systems [docs/cherry_studio.md10-18](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L10-L18)

 
| Platform | Installer Formats |
|---|---|
| Windows | .exe |
| macOS | .dmg (Intel and Apple Silicon) |
| Linux | .AppImage, .deb, .rpm |

## DeepSeek Provider Configuration

 Integration with DeepSeek V4 requires configuring the built-in model provider within the application settings [docs/cherry_studio.md20-22](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L20-L22)

 
### Configuration Workflow

 
 - **Access Settings:** Navigate to the gear icon in the lower-left corner [docs/cherry_studio.md22](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L22-L22)
 - **Provider Selection:** Under **Model Provider**, select **DeepSeek** [docs/cherry_studio.md24](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L24-L24)
 - **Authentication:** Input the `API Key` obtained from the DeepSeek Platform. The default `API Host` is set to `https://api.deepseek.com` [docs/cherry_studio.md25](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L25-L25)
 - **Model Discovery:** Use the **Fetch model list** function to populate available models, specifically adding `deepseek-v4-pro` and `deepseek-v4-flash` [docs/cherry_studio.md26](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L26-L26)
 - **Activation:** Toggle the provider switch to the "enabled" state [docs/cherry_studio.md27](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L27-L27)
 
 
### Reasoning Effort and Context Window

 Cherry Studio natively supports the DeepSeek V4 **1 million token** context window without additional manual configuration [docs/cherry_studio.md41](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L41-L41) To optimize performance for complex logic or coding tasks, users can adjust the `reasoning_effort` [docs/cherry_studio.md43](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L43-L43)

 
| UI Setting | API Implementation | Use Case |
|---|---|---|
| Extra High (穷究) | reasoning_effort: "max" | Complex coding, mathematical proofs, deep logic. |

## Advanced Features

 
### Agent Creation

 Agents are created via the **Agents** tab [docs/cherry_studio.md35](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L35-L35) When adding a new agent, users must specify the `Model` (e.g., `deepseek-v4-pro`) and set the permission mode to define the agent's capabilities [docs/cherry_studio.md35](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L35-L35)

 
### Knowledge Base (RAG)

 Users can perform Retrieval-Augmented Generation by dropping local files (PDF, Markdown, Office) into the **Knowledge Base** tab [docs/cherry_studio.md53](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L53-L53) The DeepSeek V4 model then acts as the reasoning engine over this ingested data [docs/cherry_studio.zh-CN.md51](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.zh-CN.md?plain=1#L51-L51)

 
### MCP Server Integration

 Cherry Studio supports the **Model Context Protocol (MCP)** [docs/cherry_studio.md55](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L55-L55) Servers are configured under **Settings → MCP**, allowing DeepSeek-driven agents to execute external tools defined by those servers [docs/cherry_studio.zh-CN.md53](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.zh-CN.md?plain=1#L53-L53)

 
### OpenClaw Messaging Bridge

 Cherry Studio bundles **OpenClaw**, a messaging bridge that connects DeepSeek V4 to chat platforms like Feishu and WeChat [docs/cherry_studio.md56](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/cherry_studio.md?plain=1#L56-L56)
