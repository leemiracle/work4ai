# Guide Format and Bilingual Requirements

  Relevant source files 
 - [.github/PULL_REQUEST_TEMPLATE.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/.github/PULL_REQUEST_TEMPLATE.md?plain=1)
 - [CONTRIBUTING.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1)
 
  This section defines the mandatory structure, linguistic requirements, and repository conventions for contributing new integration guides to the `awesome-deepseek-agent` knowledge base. Adherence to these standards ensures consistency across the documentation and facilitates a streamlined review process.

 
## 1. Mandatory File Structure and Bilingualism

 Every contribution for a new tool must include two versions of the documentation within a single Pull Request (PR). Splitting these into multiple PRs is not permitted [CONTRIBUTING.md15-17](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L15-L17)

 
### File Naming Convention

 Guides are stored in the `docs/` directory using the following naming pattern:

 
 - **English Version**: `docs/tool_name.md` [CONTRIBUTING.md17](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L17-L17)
 - **Simplified Chinese Version**: `docs/tool_name.zh-CN.md` [CONTRIBUTING.md17](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L17-L17)
 
 
### Asset Management

 All visual aids, such as screenshots or diagrams, must be stored in a centralized asset directory:

 
 - **Path**: `docs/assets/` [CONTRIBUTING.md79-81](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L79-L81)
 - **Requirements**: Use descriptive filenames and ensure file sizes are optimized for web viewing [CONTRIBUTING.md81](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L81-L81)
 
 
### The Lifecycle Structure

 Each guide is required to follow a logical progression to assist users in the setup process [CONTRIBUTING.md11-13](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L11-L13):

 
 - **Installation**: Steps to acquire and install the tool.
 - **Configuration**: Detailed setup of API keys, endpoints, and model parameters.
 - **First Run**: The initial execution flow to verify the integration.
 
 **Sources:** [CONTRIBUTING.md11-17](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L11-L17) [CONTRIBUTING.md79-81](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L79-L81)

## 3. README Registration

 To ensure discoverability, every new guide must be registered in the master index tables located in the root directory.

 
 - **Files to Update**: Both `README.md` and `README.zh-CN.md` [CONTRIBUTING.md19-21](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L19-L21)
 - **Ordering**: Entries must be inserted in **alphabetical order** based on the tool name. This convention is strictly enforced to minimize merge conflicts during concurrent PR submissions [CONTRIBUTING.md21](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L21-L21)
 
 **Sources:** [CONTRIBUTING.md19-22](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L19-L22)

 
## 4. Technical Content Requirements

 The following technical specifications are mandatory for all guides. Failure to include these will result in the PR being flagged during the review process [CONTRIBUTING.md23-25](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L23-L25)

 
### Model and Context Configuration

 
| Requirement | Specification | Implementation Detail |
|---|---|---|
| Model Names | Must use V4 identifiers | deepseek-v4-pro or deepseek-v4-flash CONTRIBUTING.md27-32 |
| Context Window | 1M Token Support | Append [1m] for Anthropic-compat or set context_window: 1000000 CONTRIBUTING.md36-42 |
| Reasoning Effort | Maximize logic | Set reasoning_effort: max or CLAUDE_CODE_EFFORT_LEVEL=max CONTRIBUTING.md46-52 |

 
### Pricing Accuracy

 If pricing is mentioned, it must be verified against the official DeepSeek API documentation. The repository maintains a snapshot of current rates for reference:

 
 - **V4 Pro**: Input $0.435/M, Output $0.87/M [CONTRIBUTING.md60-63](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L60-L63)
 - **V4 Flash**: Input $0.14/M, Output $0.28/M [CONTRIBUTING.md60-63](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L60-L63)
