# Technical Checklist and Critical Checks

  Relevant source files

  This page defines the mandatory technical standards and verification steps required for all DeepSeek V4 agent integrations. These checks are strictly enforced during the Pull Request (PR) review process to ensure that the community knowledge base remains accurate, high-performance, and aligned with the latest DeepSeek API capabilities.

 The scope of these checks covers model naming conventions, context window optimization, reasoning engine configuration, and pricing accuracy.

 
## 1. Core Model Naming Conventions

 All integrations must use the current DeepSeek V4 model identifiers. Following the April 2026 model rebranding, legacy V3 names are deprecated and should not appear in configuration snippets or prose.

 
| Category | Deprecated Names (V3) | Current Names (V4) |
|---|---|---|
| Pro Tier | deepseek-chat, deepseek-reasoner | deepseek-v4-pro |
| Flash Tier | deepseek-coder | deepseek-v4-flash |

 Contributors must search their diffs for legacy strings like `deepseek-chat` and replace them with the appropriate V4 identifier [CONTRIBUTING.md27-35](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L27-L35)

## 2. 1M Context Window Configuration

 DeepSeek V4 models support a context window of up to **1,000,000 tokens**. Documentation must explicitly configure this window to prevent agents from prematurely truncating long codebases or conversation histories [CONTRIBUTING.md36-38](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L36-L38)

 
 - **Anthropic-compatible endpoints**: Use the `[1m]` suffix directly in the model name (e.g., `deepseek-v4-pro[1m]`) [CONTRIBUTING.md40](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L40-L40)
 - **OpenAI-compatible endpoints**: Set the `context_window` parameter to `1000000`. If the tool uses `max_tokens` to define the total window, use `384000` or the tool's maximum supported value [CONTRIBUTING.md41](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L41-L41)
 - **Prose Requirement**: If a tool does not expose context window settings, the guide must include a note stating that DeepSeek V4 supports 1M context [CONTRIBUTING.md42-44](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L42-L44)

## 3. Reasoning and Thinking Mode Setup

 DeepSeek V4 Pro introduces multiple reasoning effort levels. Integrations should default to or provide instructions for the `max` effort level to ensure the highest quality coding output [CONTRIBUTING.md46-49](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L46-L49)

 
### Configuration Parameters by Protocol

 
| Protocol | Configuration Key | Recommended Value |
|---|---|---|
| Claude Code | CLAUDE_CODE_EFFORT_LEVEL | max |
| Anthropic-compat | thinking: { type: "enabled" } | Include max budget |
| OpenAI-compat | reasoning_effort | max |

 
### Critical Restriction: No Performance Degradation

 Do not recommend disabling "thinking mode" or "reasoning" as a primary workaround for API errors or upstream bugs. If an agent has a bug handling reasoning content (e.g., failing to parse `<thought>` tags), the guide must point users to the upstream fix rather than advising them to degrade the model's performance [CONTRIBUTING.md54-55](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L54-L55) [CONTRIBUTING.md67-70](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L67-L70)

### Common Pitfalls to Avoid

 
 - **Unverified Config Fields**: Only document configuration options that have been tested and verified to work within the specific agent [CONTRIBUTING.md71-74](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L71-L74)
 - **Split PRs**: The English (`docs/tool.md`) and Simplified Chinese (`docs/tool.zh-CN.md`) versions must be submitted in the same PR [CONTRIBUTING.md15-18](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L15-L18)
 - **Non-Alphabetical Ordering**: Entries in the `README.md` and `README.zh-CN.md` tables must be inserted in alphabetical order to minimize merge conflicts [CONTRIBUTING.md19-22](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L19-L22)
