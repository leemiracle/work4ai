## Configuration Initialization

 The initialization process creates the necessary directory structure and a default configuration schema.

 
### The Onboard Command

 Executing `nanobot onboard` generates the `config.json` file in the user's home directory [docs/nanobot.md36-40](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/nanobot.md?plain=1#L36-L40)

 
 - **Windows Path**: `%USERPROFILE%\.nanobot\config.json` [docs/nanobot.md44](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/nanobot.md?plain=1#L44-L44)
 - **Linux/macOS Path**: `~/.nanobot/config.json` [docs/nanobot.md45](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/nanobot.md?plain=1#L45-L45)
 
 
### config.json Schema

 The configuration file is divided into `agents` (defining behavior and default models) and `providers` (defining API credentials and endpoints) [docs/nanobot.md50-64](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/nanobot.md?plain=1#L50-L64)

 
| Key | Description | Recommended Value |
|---|---|---|
| agents.defaults.model | The primary model identifier used by the agent | deepseek-v4-pro |
| agents.defaults.provider | References the key in the providers object | deepseek |
| providers.deepseek.apiKey | Authentication token for DeepSeek API | <your API Key> |
| providers.deepseek.apiBase | The base URL for the OpenAI-compatible endpoint | https://api.deepseek.com/v1 |

## Execution: The nanobot Agent

 Once configured, the agent is launched via the CLI.

 
### Launch Command

 The command `nanobot agent` starts the agentic loop, utilizing the settings defined in `config.json` to initialize the session [docs/nanobot.md68-72](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/nanobot.md?plain=1#L68-L72)

 
 - **Initialization**: The tool reads the `agents.defaults` to determine which provider to invoke.
 - **Authentication**: It retrieves the `apiKey` and `apiBase` from the corresponding provider block.
 - **Session Start**: The agent becomes active, ready to process tasks or integrate with external chat tools as specified in the broader environment [docs/nanobot.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/nanobot.md?plain=1#L5-L5)
