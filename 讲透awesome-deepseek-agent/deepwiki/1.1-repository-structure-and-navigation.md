## Directory Layout and File Conventions

 The repository utilizes a flat directory structure for documentation to minimize nesting and simplify path referencing. The core logic of the repository is contained within the `docs/` directory and the root `README` files.

 
### The `docs/` Directory

 All integration guides are stored in the `docs/` folder. The repository enforces a strict naming and pairing convention for these files to ensure accessibility for both English and Simplified Chinese speakers [CONTRIBUTING.md15-17](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L15-L17)

 
 - **Bilingual Pairing**: Every tool documented must have two corresponding files: 
 - `docs/<tool_name>.md`: The English version of the guide.
 - `docs/<tool_name>.zh-CN.md`: The Simplified Chinese version of the guide.
 - **Assets**: Visual aids, such as screenshots or diagrams, are stored in `docs/assets/` [CONTRIBUTING.md79-81](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L79-L81) Guides reference these assets using relative paths to ensure they render correctly on GitHub and other Markdown viewers.
 
 
### Root Index Files

 The repository's entry points are the two README files in the root directory:

 
 - `README.md`: The primary English landing page [README.md1-11](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/README.md?plain=1#L1-L11)
 - `README.zh-CN.md`: The primary Simplified Chinese landing page [README.zh-CN.md1-11](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/README.zh-CN.md?plain=1#L1-L11)

## The Master Index Mechanism

 The README files serve as more than just a welcome page; they act as a functional "Master Index" for the repository. This index is implemented as a Markdown table that categorizes tools and provides direct links to their respective guides.

 
### Table Structure

 The table contains three primary columns:

 
 - **Tool**: The name of the AI agent or coding assistant.
 - **Description**: A brief technical summary of the tool's capabilities.
 - **Guide**: A relative link to the specific `.md` or `.zh-CN.md` file in the `docs/` directory.
 
 
### Alphabetical Enforcement

 To maintain order and prevent merge conflicts during concurrent pull requests, all entries in the `Contents` table must be inserted in **alphabetical order** [CONTRIBUTING.md19-21](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L19-L21)

## Technical Standards for Guides

 Every file within the `docs/` directory must adhere to specific technical requirements defined in the contribution guidelines. These standards ensure that "Natural Language" instructions correctly map to "Code Entity" configurations required by the agents.

 
### Key Configuration Requirements

 
| Requirement | Implementation Detail | Source |
|---|---|---|
| Model Naming | Must use deepseek-v4-pro or deepseek-v4-flash. | CONTRIBUTING.md27-32 |
| Context Window | Configured for 1,000,000 tokens (e.g., [1m] suffix). | CONTRIBUTING.md36-44 |
| Reasoning Effort | Must target max effort levels in config files. | CONTRIBUTING.md46-54 |

## Navigation Summary

 To navigate the codebase effectively:

 
 - **Start at the Root**: Use `README.md` (EN) or `README.zh-CN.md` (ZH) to find the tool of interest.
 - **Locate the Guide**: Follow the link to the `docs/` folder.
 - **Verify Configuration**: Ensure the guide mentions the mandatory V4 model identifiers and 1M context settings as required by the `CONTRIBUTING.md` specification [CONTRIBUTING.md23-54](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L23-L54)
 - **Check Assets**: If images are broken, verify their existence in `docs/assets/` [CONTRIBUTING.md79-82](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/CONTRIBUTING.md?plain=1#L79-L82)
