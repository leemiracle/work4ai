# OpenClaw

  Relevant source files 
 - [docs/openclaw.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1)
 - [docs/openclaw.zh-CN.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.zh-CN.md?plain=1)
 
  OpenClaw is an open-source personal AI assistant designed to bridge high-performance language models with daily productivity tools. It supports multi-channel integration (such as Feishu and WeChat) and features an extensible "Skill" architecture to enhance its functional capabilities [docs/openclaw.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L5-L5)

 
### 1. Installation

 OpenClaw provides platform-specific installation scripts to streamline the setup of the assistant environment.

 
| Platform | Command |
|---|---|
| Linux / macOS | curl -fsSL https://openclaw.ai/install.sh \| bash |
| Windows | iwr -useb https://openclaw.ai/install.ps1 \| iex |

 Sources: [docs/openclaw.md9-19](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L9-L19)

 
### 2. Configuration and Onboarding

 After installation, OpenClaw initiates an onboard wizard to configure the core provider and model settings. This process can be manually triggered using the `openclaw onboard --install-daemon` command [docs/openclaw.md23](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L23-L23)

 
#### Configuration Workflow

 
 - **Safety Acknowledgment**: Confirm the personal-by-default nature of the tool by selecting **Yes** [docs/openclaw.md25](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L25-L25)
 - **Setup Mode**: Select **QuickStart** for an optimized configuration path [docs/openclaw.md26](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L26-L26)
 - **Provider Selection**: Choose **DeepSeek** as the `Model/auth provider` [docs/openclaw.md27](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L27-L27)
 - **Authentication**: Input the [DeepSeek API Key](https://platform.deepseek.com/api_keys) [docs/openclaw.md28](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L28-L28)
 - **Model Selection**: Navigate to **Enter model** and specify either `deepseek-v4-pro` or `deepseek-v4-flash` [docs/openclaw.md29](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L29-L29)
 
 
#### DeepSeek V4 Thinking Mode Support

 To ensure compatibility with DeepSeek V4's reasoning features, users must use **OpenClaw v2026.4.24** or higher. This version specifically addresses the handling of `reasoning_content` to prevent `400` errors during API calls [docs/openclaw.md32](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L32-L32)

### 4. Operational Modes

 OpenClaw can be launched in different modes depending on the user's workflow requirements:

 
 - **Web Dashboard**: Provides a graphical chat interface and management console. 
 - Command: `openclaw dashboard` [docs/openclaw.md39](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L39-L39)
 - **Terminal User Interface (TUI)**: An interactive, terminal-based dashboard. 
 - Command: `openclaw tui` [docs/openclaw.md45](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L45-L45)
 - **Terminal Chat**: A direct command-line interface for rapid AI interaction. 
 - Command: `openclaw terminal` [docs/openclaw.md51](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/openclaw.md?plain=1#L51-L51)
