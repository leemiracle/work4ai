### Configuration and Implementation

 
#### 1. Moon Bridge `config.yml`

 Moon Bridge uses a top-level configuration structure to define models, providers, and routing logic [docs/codex.md37-40](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L37-L40)

 
| Key | Description |
|---|---|
| mode | Set to "Transform" for proxy operations docs/codex.md40 |
| server.addr | The local address Moon Bridge listens on (default: 127.0.0.1:38440) docs/codex.md42-43 |
| models | Defines capabilities like context_window (1,000,000) and supported_reasoning_levels docs/codex.md45-74 |
| extensions.deepseek_v4 | Enables specific compatibility flags for DeepSeek V4 docs/codex.md57-59 |
| providers | Contains the DeepSeek api_key and base_url (https://api.deepseek.com/anthropic) docs/codex.md75-82 |

 
#### 2. Codex Sidecar Files

 Codex requires two specific files in its home directory (`$HOME/.codex`) to recognize the proxy [docs/codex.md109-112](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L109-L112)

 
 - **`config.toml`**: Configures the provider to use `wire_api = "responses"` and points to the Moon Bridge URL [docs/codex.md155](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L155-L155)
 - **`models_catalog.json`**: Contains model metadata including context windows and tool support [docs/codex.md156](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L156-L156)

### Deployment Scripts

 Moon Bridge provides automated scripts to handle the configuration and launch process in a single step [docs/codex.md178-180](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L178-L180)

 
 - **Bash (Linux/macOS)**: Uses `CODEX_HOME_DIR` and `go run` to pipe the generated config [docs/codex.md115-130](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L115-L130) 
 - Command: `./scripts/start_codex_with_moonbridge.sh --project-directory /path/to/project` [docs/codex.md182-183](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L182-L183)
 - **PowerShell (Windows)**: Uses `Set-Content` and `$env:CODEX_HOME` [docs/codex.md134-151](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L134-L151) 
 - Command: `.\scripts\start_codex_with_moonbridge.ps1 -ProjectDirectory C:\path\to\project` [docs/codex.md188-189](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/codex.md?plain=1#L188-L189)

### Troubleshooting

 
| Error | Root Cause | Resolution |
|---|---|---|
| connection refused | Proxy not running or port mismatch docs/codex.md229 | Ensure go run ./cmd/moonbridge is active and server.addr matches docs/codex.md98-229 |
| Model not visible | Missing metadata in Codex home docs/codex.md230 | Rerun the --print-codex-config command to regenerate models_catalog.json docs/codex.md124-230 |
| field provider not found | Deprecated YAML schema docs/codex.md231 | Update config.yml to use top-level providers and routes keys docs/codex.md231 |
| 401 / 402 | Auth or Billing issues docs/codex.md232-233 | Verify api_key in config.yml and check DeepSeek platform balance docs/codex.md232-233 |
