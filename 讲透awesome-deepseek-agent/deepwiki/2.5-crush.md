# Crush

  Relevant source files 
 - [docs/crush.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1)
 - [docs/crush.zh-CN.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.zh-CN.md?plain=1)
 
  Crush is a terminal-native, open-source AI coding agent developed by Charm. It provides a sophisticated TUI (Terminal User Interface) that integrates Language Server Protocol (LSP) support, Model Context Protocol (MCP) servers, and agentic workflows to automate coding tasks directly from the command line [docs/crush.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L5-L5)

 
### Installation

 Crush can be installed via Node Package Manager (npm) or Homebrew for macOS users.

 
| Method | Command |
|---|---|
| npm | npm install -g @charmland/crush docs/crush.md13 |
| Homebrew | brew install charmbracelet/tap/crush docs/crush.md22 |

 After installation, verify the setup by checking the version: `crush --version` [docs/crush.md19](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L19-L19)

### Configuration and Provider Setup

 Crush utilizes a JSON-based configuration file located in the user's home directory. To integrate DeepSeek, users must define a custom provider using the `openai-compat` type [docs/crush.md36](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L36-L36)

 
#### Configuration Path

 
 - **Linux / macOS**: `~/.config/crush/crush.json` [docs/crush.md28](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L28-L28)
 - **Windows**: `%USERPROFILE%\.config\crush\crush.json` [docs/crush.md29](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L29-L29)
 
 
#### Schema Implementation

 The `crush.json` file requires a specific schema to map the DeepSeek API endpoints and model capabilities. Key fields include:

 
 - `base_url`: Set to `https://api.deepseek.com` [docs/crush.md37](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L37-L37)
 - `api_key`: Reference an environment variable (e.g., `$DEEPSEEK_API_KEY`) for security [docs/crush.md38](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L38-L38)
 - `can_reason`: A boolean flag that must be set to `true` to enable reasoning capabilities for DeepSeek-V4 models [docs/crush.md45](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L45-L45)

### Model Management and Execution

 Once configured, Crush allows dynamic model switching during an active session.

 
 - **Launch**: Navigate to a project directory and execute `crush` [docs/crush.md78-83](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L78-L83)
 - **Model Switcher**: Use the `/model` command or the `Ctrl+L` shortcut to trigger the selection UI [docs/crush.md85](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L85-L85)
 - **Selection**: Select the `deepseek` provider and choose between `DeepSeek-V4-Pro` or `DeepSeek-V4-Flash` [docs/crush.md86](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/crush.md?plain=1#L86-L86)

### Technical Specifications

 The integration leverages the 1M context window and high token limits of the DeepSeek-V4 family.

 
| Parameter | Value | Source |
|---|---|---|
| Provider Type | openai-compat | docs/crush.md36 |
| Context Window | 1048576 | docs/crush.md43 |
| Max Tokens | 32768 | docs/crush.md44 |
| Reasoning Support | can_reason: true | docs/crush.md45 |
