# GitHub Copilot CLI

  This page provides a technical guide for integrating DeepSeek V4 models into the GitHub Copilot CLI using the Bring Your Own Key (BYOK) mechanism. It details the requirement for the Anthropic-compatible protocol to ensure stable reasoning-enabled chat sessions and provides configuration for token management and offline operations.

 
## Overview and Implementation

 The integration leverages the `@github/copilot` CLI's ability to interface with custom model providers via environment variables [docs/copilot_cli.md90-91](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/copilot_cli.md?plain=1#L90-L91) While DeepSeek provides an OpenAI-compatible endpoint, GitHub Copilot CLI must be configured to use the `anthropic` provider type when interacting with DeepSeek V4 models [docs/copilot_cli.md7-8](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/copilot_cli.md?plain=1#L7-L8)

 
### Protocol Compatibility: Why Anthropic?

 A critical implementation detail involves how reasoning content is handled. DeepSeek's reasoning models require that the `reasoning_content` generated by the model be echoed back to the API in subsequent turns of the conversation [docs/copilot_cli.md7-8](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/copilot_cli.md?plain=1#L7-L8)

 
| Provider Type | Behavior with DeepSeek | Result |
|---|---|---|
| openai | Does not echo reasoning_content in chat history. | 400 Bad Request |
| anthropic | Uses the Messages API structure which avoids this requirement. | Success |

## Advanced Configuration

 
### Token Limit Overrides

 Since DeepSeek V4 models are not natively defined in the Copilot CLI internal catalog, the CLI may default to conservative token limits. Users should manually override these to leverage the 1M context capabilities of DeepSeek V4.

 
 - **Prompt Tokens:** Set `COPILOT_PROVIDER_MAX_PROMPT_TOKENS` to `840000` [docs/copilot_cli.md59](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/copilot_cli.md?plain=1#L59-L59)
 - **Output Tokens:** Set `COPILOT_PROVIDER_MAX_OUTPUT_TOKENS` to `128000` [docs/copilot_cli.md60](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/copilot_cli.md?plain=1#L60-L60)
 
 
### Offline Mode

 Setting `COPILOT_OFFLINE=true` restricts the CLI from communicating with GitHub's backend servers for configuration or telemetry [docs/copilot_cli.md77-86](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/copilot_cli.md?plain=1#L77-L86)

 
> **Note:** This does not enable local LLM execution; prompts are still transmitted to `api.deepseek.com` [docs/copilot_cli.md86](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/copilot_cli.md?plain=1#L86-L86)
