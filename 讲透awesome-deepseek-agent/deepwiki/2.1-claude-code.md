  Claude Code is a high-performance AI coding assistant developed by Anthropic that operates directly within the terminal or as a VS Code extension. By leveraging the DeepSeek Anthropic-compatible endpoint, users can integrate DeepSeek V4's reasoning capabilities into the Claude Code workflow, benefiting from its 1M context window and advanced coding intelligence [docs/claude_code.md3-5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/claude_code.md?plain=1#L3-L5)

 
## Installation

 Claude Code can be deployed in two primary environments.

 
### 1. Claude Code CLI

 The CLI version provides a terminal-native experience for interactive coding and repository management.

## Configuration

 Configuration is managed either via a `settings.json` file (recommended for persistence across both CLI and Extension) or via environment variables [docs/claude_code.md34-36](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/claude_code.md?plain=1#L34-L36)

 
### Option 1: settings.json (Recommended)

 Create or edit the configuration file at the following location:

 
 - **Linux/Mac**: `~/.claude/settings.json` [docs/claude_code.md41](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/claude_code.md?plain=1#L41-L41)

## Technical Implementation and Data Flow

 The integration relies on the `ANTHROPIC_BASE_URL` override to redirect Claude Code's internal API client from Anthropic's servers to DeepSeek's compatible endpoint.

 
### Context Window and Reasoning

 
 - **[1m] Suffix**: DeepSeek V4 requires the `[1m]` suffix appended to the model name (e.g., `deepseek-v4-pro[1m]`) to activate the full 1-million-token context window [docs/claude_code.md52-55](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/claude_code.md?plain=1#L52-L55)
 - **Effort Level**: Setting `CLAUDE_CODE_EFFORT_LEVEL` to `max` ensures the model utilizes its maximum reasoning capacity for complex architectural and debugging tasks [docs/claude_code.md57](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/claude_code.md?plain=1#L57-L57)
