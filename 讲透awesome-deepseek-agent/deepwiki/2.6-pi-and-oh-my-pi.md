  Pi (pi-mono) and its fork, Oh My Pi (OMP), are minimal yet highly extensible terminal coding frameworks. They leverage a tree-structured session model and support a wide array of AI providers through TypeScript extensions, skills, and prompt templates [docs/pi_mono.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/pi_mono.md?plain=1#L5-L5) While both tools share a common lineage, Oh My Pi requires specific compatibility configurations to handle DeepSeek V4's reasoning content and tool-calling requirements without encountering 400 errors [docs/oh-my-pi.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L5-L5)

 Pi is installed via npm or a shell script and serves as a coding harness that adapts to developer workflows [docs/pi_mono.md5-14](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/pi_mono.md?plain=1#L5-L14)

### Configuration Schema

 Pi uses a JSON-based provider system located at `~/.pi/agent/models.json` (Linux/macOS) or `%USERPROFILE%\.pi\agent\models.json` (Windows) [docs/pi_mono.md31-32](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/pi_mono.md?plain=1#L31-L32) The configuration defines the `baseUrl`, `api` type, and specific model capabilities.

| reasoning | true | Enables thinking capabilities docs/pi_mono.md48 |

## Oh My Pi (OMP)

 Oh My Pi is a fork that provides enhanced terminal agent capabilities. Although it ships with built-in DeepSeek V4 entries as of v14.5, a custom `models.yml` is mandatory to avoid API errors during complex reasoning tasks [docs/oh-my-pi.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L5-L5)

 
### Critical Compatibility Fields

 DeepSeek V4 introduces specific requirements for its thinking mode that differ from standard OpenAI implementations. Failing to include these in `~/.omp/agent/models.yml` results in 400 Bad Request errors [docs/oh-my-pi.md98-100](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L98-L100)

 
 - **`supportsToolChoice: false`**: DeepSeek V4 reasoning mode does not support the `tool_choice` parameter [docs/oh-my-pi.md104](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L104-L104)
 - **`requiresReasoningContentForToolCalls: true`**: The model requires `reasoning_content` to be preserved in the conversation history across tool-call turns [docs/oh-my-pi.md105](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L105-L105)
 - **`requiresAssistantContentForToolCalls: true`**: Ensures tool-call messages contain non-null content fields [docs/oh-my-pi.md106](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L106-L106)
 - **`extraBody.thinking.type: enabled`**: Explicitly activates the V4 thinking mode [docs/oh-my-pi.md95](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L95-L95)
 
 
### Thinking Mode Mapping

 OMP uses an internal effort scale that must be mapped to DeepSeek's supported levels (`high` and `max`) via the `reasoningEffortMap` [docs/oh-my-pi.md94](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L94-L94)

## Model Selection and Usage

 Both Pi and Oh My Pi provide interactive commands to switch between the Pro and Flash models during a session.

 
| Feature | Pi Command | Oh My Pi Command |
|---|---|---|
| Model Switcher | /model docs/pi_mono.md123 | /model or Ctrl+L docs/oh-my-pi.md121 |
| Direct Launch | pi (then select) docs/pi_mono.md120 | omp --model deepseek/deepseek-v4-pro docs/oh-my-pi.md112 |

 
### Authentication

 Neither tool currently supports DeepSeek OAuth login. Authentication must be handled via the `DEEPSEEK_API_KEY` environment variable or the `apiKey` field in the configuration files [docs/pi_mono.md100-113](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/pi_mono.md?plain=1#L100-L113) [docs/oh-my-pi.md127](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/oh-my-pi.md?plain=1#L127-L127)
