  This page provides a technical guide for integrating DeepSeek V4 models into Factory AI Droid. It covers the configuration of the `customModels` array and the `missionModelSettings` within the application's settings schema, supporting both Anthropic-compatible and OpenAI-compatible API protocols.

 
## Configuration Overview

 Factory AI Droid utilizes a central configuration file located at `~/.factory/settings.json` [docs/deepseek-droid-guide.md18](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L18-L18) The application employs a file-watching mechanism to automatically detect and apply changes to this file [docs/deepseek-droid-guide.md115](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L115-L115)

 
### Custom Model Schema

 To integrate DeepSeek, models must be defined within the `customModels` array. Each entry requires specific metadata to ensure the Droid can route requests correctly.

 
| Field | Description |
|---|---|
| model | The upstream model identifier (e.g., deepseek-v4-pro). |
| id | A unique identifier, typically prefixed with custom:. |
| index | A unique integer used for ordering in the UI. |
| baseUrl | The API endpoint (provider-specific). |
| apiKey | The authentication token or environment variable reference ${DEEPSEEK_API_KEY}. |
| provider | The protocol driver: anthropic, openai, or generic-chat-completion-api. |
| maxOutputTokens | Set to 384000 for DeepSeek V4 models. |

## Troubleshooting

 
### Model Visibility

 If a model does not appear in the Droid selector:

 
 - **JSON Validation**: Ensure `~/.factory/settings.json` (or the legacy `config.json`) is syntactically valid [docs/deepseek-droid-guide.md114](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L114-L114)
 - **Field Completion**: Verify all mandatory fields (`id`, `model`, `provider`, `baseUrl`) are present [docs/deepseek-droid-guide.md116](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L116-L116)
 - **Index Uniqueness**: Ensure the `index` value does not conflict with other custom models [docs/deepseek-droid-guide.md107](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L107-L107)
 
 
### Authentication and Connectivity

 
 - **Invalid Provider**: The `provider` key is case-sensitive and must be one of the three supported strings: `anthropic`, `openai`, or `generic-chat-completion-api` [docs/deepseek-droid-guide.md120](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L120-L120)
 - **401 Unauthorized**: If using environment variables, ensure the variable is exported in the shell before launching the Droid: `export DEEPSEEK_API_KEY=your_key_here` [docs/deepseek-droid-guide.md108](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L108-L108)
 - **Endpoint Mismatch**: Ensure the `baseUrl` corresponds to the selected `provider`. Using the OpenAI base URL with the `anthropic` provider will result in 404 or 400 errors [docs/deepseek-droid-guide.md127](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-droid-guide.md?plain=1#L127-L127)
