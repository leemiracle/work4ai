# AstrBot

  Relevant source files 
 - [docs/astrbot.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1)
 - [docs/astrbot.zh-CN.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.zh-CN.md?plain=1)
 
  AstrBot is an open-source, all-in-one agent assistant designed to bridge Large Language Models (LLMs) with mainstream messaging platforms and extensible toolsets. It supports integration with QQ, WeChat, Feishu, and Telegram, and allows for functional expansion through a plugin system, custom skills, and the Model Context Protocol (MCP) [docs/astrbot.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L5-L5)

 
## Installation

 AstrBot can be deployed using the `uv` package manager for local environments or via `Docker` for containerized environments.

 
### Method 1: Installation via uv

 The `uv`-based installation provides a streamlined CLI experience for macOS, Linux, and Windows users.

 
 - **Download and Install**: 
 - **macOS/Linux**: `curl -LsSf https://docs.astrbot.app/install.sh | bash` [docs/astrbot.md14](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L14-L14)
 - **Windows**: `iwr -useb https://docs.astrbot.app/install.ps1 | iex` [docs/astrbot.md20](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L20-L20)
 - **Initialize Environment**: Run `astrbot init` in your desired directory to set up the local environment [docs/astrbot.md26](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L26-L26)
 - **Launch**: Run `astrbot run` to start the application [docs/astrbot.md27](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L27-L27)
 
 
### Method 2: Installation via Docker

 For users preferring containerization, AstrBot provides a `docker-compose` configuration.

 
 - **Clone Repository**: `git clone https://github.com/AstrBotDevs/AstrBot --depth 1` [docs/astrbot.md35](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L35-L35)
 - **Start Service**: `sudo docker compose up -d` [docs/astrbot.md42](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L42-L42)

## Configuration and Data Flow

 Once the service is running, configuration is managed through a Web UI accessible at `http://localhost:6185` [docs/astrbot.md50](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L50-L50) The configuration process involves registering a Model Provider and then assigning that provider as the system default.

 
### Provider and Model Setup

 
 - **DeepSeek Provider**: Navigate to the `Providers` page, add a new `DeepSeek` entry, and input the `API Key` [docs/astrbot.md53](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L53-L53)
 - **Global Defaults**: In the `Config(Normal Config)` page, the `Default Chat Model` must be mapped to the newly created DeepSeek provider [docs/astrbot.md55](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/astrbot.md?plain=1#L55-L55)
