# DeepSeek-TUI

  Relevant source files 
 - [docs/deepseek-tui.md](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1)

  DeepSeek-TUI is an open-source terminal AI coding assistant implemented in Rust using a Codex-style 13-crate workspace architecture [docs/deepseek-tui.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L5-L5) It provides a high-performance, sandboxed environment for AI-driven development, supporting both DeepSeek-V4-Pro and DeepSeek-V4-Flash models with a full 1 million token context window [docs/deepseek-tui.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L5-L5)

 
### Installation and Setup

 DeepSeek-TUI can be installed via multiple package managers or as a standalone binary.

 
| Method | Command | Requirements |
|---|---|---|
| npm | npm install -g deepseek-tui | Node.js environment docs/deepseek-tui.md15 |
| Cargo | cargo install deepseek-tui-cli | Rust 1.85+ docs/deepseek-tui.md18 |
| Binary | Download from GitHub Releases | None docs/deepseek-tui.md20-22 |

 
#### Authentication

 The tool requires a DeepSeek API Key, which can be configured in two ways:

 
 - **Interactive:** Run `deepseek auth` to save the key to `~/.deepseek/config.toml` [docs/deepseek-tui.md32](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L32-L32)
 - **Environment Variable:** Set `DEEPSEEK_API_KEY` in your shell [docs/deepseek-tui.md32](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L32-L32)
 
 
### TUI Modes and Reasoning

 The TUI features three distinct operational modes that control how the agent interacts with the local system, cycled via the `Tab` key [docs/deepseek-tui.md43](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L43-L43)

 
| Mode | Behavior | Security Level |
|---|---|---|
| Plan | Read-only investigation. Cannot write files or execute shell commands docs/deepseek-tui.md47 | High (Safe) |
| Agent | Multi-step tool use. Side-effectful tools (file writes, shell) require user approval docs/deepseek-tui.md48 | Medium (Restricted) |
| YOLO | Auto-approves all tool calls and lifts workspace boundary restrictions docs/deepseek-tui.md49 | Low (Unrestricted) |

 
#### Reasoning Effort

 Users can cycle through reasoning intensity levels (`off` → `high` → `max`) by pressing `Shift+Tab` [docs/deepseek-tui.md43](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L43-L43) This controls the `reasoning_effort` parameter sent to the DeepSeek API.

 DeepSeek-TUI operates as a multi-crate Rust workspace. ### Advanced Features

 
#### Model Orchestration

 
 - **Sub-agents:** The primary model can spawn child agents using the `agent_spawn` tool [docs/deepseek-tui.md81](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L81-L81) These sub-agents have their own lifecycle managed via `agent_wait`, `agent_result`, and `agent_cancel` [docs/deepseek-tui.md81](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L81-L81)
 - **RLM (Recursive LM):** A specialized tool for processing inputs that exceed typical context limits. It operates in a sandboxed Python REPL to summarize or extract data without polluting the main conversation context [docs/deepseek-tui.md82](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L82-L82)
 
 
#### Extensibility

 
 - **MCP (Model Context Protocol):** DeepSeek-TUI acts as both an MCP client (connecting to external tools) and an MCP server (exposing its own capabilities via `deepseek mcp serve`) [docs/deepseek-tui.md78](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L78-L78) Configuration is managed in `~/.deepseek/mcp.json` [docs/deepseek-tui.md78](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L78-L78)
 - **Skills:** Markdown-based tool definitions (`SKILL.md`) can be placed in `~/.deepseek/skills/` (global) or `./.deepseek/skills/` (project-specific) to extend agent capabilities [docs/deepseek-tui.md79](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L79-L79)
 - **Hooks:** Lifecycle hooks for `stdout`, `jsonl`, or `webhook` can be configured in the `[hooks]` section of `config.toml` [docs/deepseek-tui.md80](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L80-L80)
 
 
#### HTTP Runtime API

 By running `deepseek serve --http`, the application exposes a REST API at `/v1/*` [docs/deepseek-tui.md86](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L86-L86) This allows external IDEs or Web UIs to interface with the DeepSeek-TUI runtime, managing sessions, threads, and tasks programmatically [docs/deepseek-tui.md86](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L86-L86)

 
### Configuration Reference

 The primary configuration resides in `~/.deepseek/config.toml` [docs/deepseek-tui.md66](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/deepseek-tui.md?plain=1#L66-L66)

 
| Variable | Config Key | Description |
|---|---|---|
| DEEPSEEK_API_KEY | api_key | Authentication token docs/deepseek-tui.md70 |
| DEEPSEEK_BASE_URL | base_url | Defaults to https://api.deepseek.com docs/deepseek-tui.md71 |
| DEEPSEEK_MODEL | model | Default: deepseek-v4-pro docs/deepseek-tui.md72 |
| DEEPSEEK_PROVIDER | provider | Allows switching to nvidia-nim or others docs/deepseek-tui.md73 |
