  Reasonix is a terminal-native AI coding assistant built specifically for the DeepSeek ecosystem. Unlike generic agents that use protocol translation shims, Reasonix is DeepSeek-native, meaning it is designed to leverage specific features of the DeepSeek API such as Context Caching, the `deepseek-v4-flash` model for cost-efficient loops, and automatic tool-call repair [docs/reasonix.md3-5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/reasonix.md?plain=1#L3-L5)

 
## System Overview and Architecture

 Reasonix operates as a Node.js-based terminal application that manages a project-specific coding loop. It utilizes a "Flash-First" design philosophy, prioritizing `deepseek-v4-flash` for rapid, low-cost iterations while allowing on-demand escalation to `deepseek-v4-pro` for complex reasoning tasks [docs/reasonix.md23](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/reasonix.md?plain=1#L23-L23)

## Configuration and API Management

 Reasonix simplifies the onboarding process through a built-in API key wizard. ## Execution and Slash Commands

 The agent is launched within a project directory using the command `npx reasonix code` [docs/reasonix.md20-21](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/reasonix.md?plain=1#L20-L21) Once active, users interact with the agent via a Terminal User Interface (TUI) that supports slash commands for real-time model steering.

 
### Cost Control and Model Switching

 Reasonix implements a tiered model strategy to balance performance and cost:

 
| Command | Effect | Model Target |
|---|---|---|
| Default | Standard iteration and tool use | deepseek-v4-flash |
| /pro | Switches the next turn to the Pro model | deepseek-v4-pro |
| /preset max | Sets the entire session to use the Pro model | deepseek-v4-pro |
| /help | Displays the full reference of slash commands | N/A |

 
### Key Features

 
 - **Cache-First Loop**: Optimizes context window usage by prioritizing cached prefixes in the DeepSeek API, reducing latency and cost for long-running sessions [docs/reasonix.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/reasonix.md?plain=1#L5-L5)
 - **Automatic Tool-Call Repair**: If the model generates a malformed tool call, Reasonix attempts to fix the syntax before execution to prevent loop breakage [docs/reasonix.md5](https://github.com/deepseek-ai/awesome-deepseek-agent/blob/4481ad5b/docs/reasonix.md?plain=1#L5-L5)
