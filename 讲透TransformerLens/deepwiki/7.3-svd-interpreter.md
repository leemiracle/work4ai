  This document covers the SVD (Singular Value Decomposition) Interpreter system in TransformerLens, which enables mechanistic interpretability analysis by computing singular vectors of key weight matrices in transformer models. The SVD Interpreter helps researchers understand what different components of a transformer are doing by analyzing the principal directions of their weight matrices.

 For general activation patching techniques, see [7.1 Activation Patching](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/7.1 Activation Patching) For automated attention head detection, see [7.2 Head Detection](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/7.2 Head Detection) For model evaluation utilities, see [7.5 Evaluation Tools](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/7.5 Evaluation Tools)

 
## Purpose and Scope

 The SVD Interpreter provides a systematic way to analyze transformer weight matrices through singular value decomposition. It extracts the most significant directions in attention head output-value (OV) matrices and MLP input/output weight matrices, allowing researchers to understand what features these components are detecting or computing.

 The system is designed for:

 
 - Analyzing attention head behavior through OV matrix decomposition.
 - Understanding MLP layer computations via input/output weight analysis.
 - Generating interpretable vectors that can be visualized and analyzed.
 - Supporting mechanistic interpretability research workflows.

### Singular Vector Computation

 The core computation process involves projecting the right singular vectors ($V$) onto the unembedding matrix to see which tokens are most associated with those directions:

 
 - **Matrix Retrieval**: Extract the weight matrix (e.g., `W_in.T`).
 - **SVD Computation**: Perform `torch.linalg.svd(matrix)` to obtain $U, S, V$.
 - **Embedding Projection**: For each of the top $k$ vectors in $V$, compute `activations = V[i, :] @ W_U`.
 - **Formatting**: Stack the results into shape `(d_vocab, 1, num_vectors)`.

### Integration with FactoredMatrix

 For OV matrices, the system uses the `FactoredMatrix` class. This is particularly efficient because `FactoredMatrix` handles the composition of $W_V$ and $W_O$ and provides optimized access to the product's SVD components without full matrix materialization.

### Numerical Stability Warning

 As noted in the implementation, numerical instability in SVD can lead to inconsistencies across different hardware devices (CPU vs. GPU). It is recommended to perform these analyses on the same device where the model was originally loaded for reproducibility.
