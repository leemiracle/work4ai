  The `FactoredMatrix` class provides efficient operations for low-rank factored matrices, where a matrix $M$ is represented as the product of two matrices $A$ and $B$ ($M = A @ B$). This representation enables memory-efficient storage and computation for matrices that have low intrinsic dimensionality, which is common in transformer weight matrices used for mechanistic interpretability (e.g., QK and OV circuits).

 For general matrix operations in TransformerLens, see the utilities module. For activation caching and manipulation, see [Activation Cache (3.4)](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/Activation Cache (3.4))

 
## Core Architecture

 The `FactoredMatrix` class stores a matrix as two factor matrices rather than the full product matrix, enabling efficient computation when the middle dimension `mdim` is smaller than the outer dimensions. It supports both `torch.Tensor` and `TensorLike` duck-typed inputs for basic matrix operations.

## Efficient Algorithms

 
### SVD Decomposition

 The `svd()` method computes the Singular Value Decomposition without ever materializing the full `AB` product. It uses a "middle-out" approach by computing SVDs of the smaller factor matrices and then combining them.

 
 - Compute SVD of `A` and `B`.
 - Form a small "middle" matrix from the singular values and singular vectors.
 - Compute SVD of the middle matrix.
 - Rotate the original singular vectors by the middle SVD components.
 
 Sources: [transformer_lens/FactoredMatrix.py263-324](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/FactoredMatrix.py#L263-L324)

 
### Eigenvalue Computation

 The `eigenvalues` property computes eigenvalues of the product $AB$. It leverages the identity that non-zero eigenvalues of $AB$ are identical to those of $BA$. If $mdim < ldim$, it computes eigenvalues on the smaller $BA$ matrix.

 Sources: [transformer_lens/FactoredMatrix.py349-365](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/FactoredMatrix.py#L349-L365)

 
### Norm Calculation

 The Frobenius norm is computed efficiently using the singular values: $|M|_F = \sqrt{\sum \sigma_i^2}$.

## Usage Patterns

 
### Mechanistic Interpretability: QK Circuit Analysis

 In transformer analysis, the QK circuit is often represented as $W_{QK} = W_Q W_K^T$. Storing this as a `FactoredMatrix` allows for rapid SVD analysis of which "keys" a "query" attends to without materializing a $d_{model} \times d_{model}$ matrix.
