## Specialized Evaluations

 
### MMLU (Massive Multitask Language Understanding)

 The MMLU evaluation tests model performance on 57 subjects across STEM, humanities, and social sciences. Each question is multiple choice (A, B, C, D).

 The `mmlu_eval()` function returns:

 
 - `accuracy`: Overall accuracy across all selected subjects.
 - `num_correct` / `num_total`: Raw counts.
 - `subject_scores`: A dictionary mapping each subject to its specific accuracy.

### IOI (Indirect Object Identification) Evaluation

 The IOI evaluation tests a model's ability to identify indirect objects in sentences with specific templates (e.g., "When John and Mary went to the store, John gave a drink to Mary").

 
#### IOI Dataset Structure

 
```

```

 The `IOIDataset` class handles:

 
 - **Template Parsing**: Uses placeholders like `[A]`, `[B]`, `[OBJECT]`.
 - **Symmetric Sampling**: If `symmetric=True`, it generates pairs of prompts where names are swapped to reduce bias.
 - **Multi-token Names**: Correctly identifies the position of names even if they tokenize into multiple IDs.
 
 
#### IOI Evaluation Metrics

 The `ioi_eval()` function computes:

 
 - **Logit Difference**: The difference between the logit of the correct name (IO) and the incorrect name (S).
 - **Accuracy**: The percentage of samples where the IO logit is higher than the S logit.
