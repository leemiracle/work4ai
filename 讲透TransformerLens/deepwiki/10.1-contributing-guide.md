## Purpose and Scope

 This guide covers the development workflow, coding standards, and contribution process for TransformerLens. As of version 3.0, the codebase is transitioning from the legacy `HookedTransformer` to the new `TransformerBridge` architecture. This page provides technical details on setting up the development environment with `uv`, running tiered tests, and following the adapter-authoring workflow.

 
## Development Environment Setup

 
### DevContainer Setup

 For a one-click setup, this project includes a [DevContainer](https://containers.dev/) configuration [docs/source/content/contributing.md30-35](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L30-L35) It can be used locally with VS Code or with GitHub Codespaces.

## Code Quality Standards

 
### Formatting and Linting

 The project uses `pycln`, `isort`, and `black` for formatting. Note that the `black` line length is set to **100 characters** [docs/source/content/contributing.md105-112](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L105-L112)

 
 - **Format:** `make format` (runs `pycln`, `isort`, and `black`).
 - **Check:** `make check-format`.
 - **Type Check:** `uv run mypy .`.
 
 **Hard Rules:**

 
 - **No Pre-commit Hooks:** You must run formatting and type checking manually before pushing [docs/source/content/contributing.md114-115](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L114-L115)
 - **No Type Ignores:** Adding `# type: ignore` is generally prohibited [AGENTS.md16](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/AGENTS.md?plain=1#L16-L16)
 - **Base Branch:** All PRs (except bug fixes for the current release) must be based on the `dev` branch, not `main` [.github/PULL_REQUEST_TEMPLATE.md1-4](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/.github/PULL_REQUEST_TEMPLATE.md?plain=1#L1-L4)

## Testing Framework

 
### Test Tiers

 TransformerLens employs a tiered testing strategy to balance speed and coverage [docs/source/content/contributing.md85-92](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L85-L92)

 
| Tier | Path | Purpose | Loads Models? |
|---|---|---|---|
| unit | tests/unit/ | Fast feedback on single modules | No (or synthetic) |
| integration | tests/integration/ | Cross-component verification | 1-2 cached models |
| acceptance | tests/acceptance/ | End-to-end behavior | Full models |
| benchmarks | tests/benchmarks/ | Throughput and memory | Varies |
| mps | tests/mps/ | macOS-MPS smoke tests | TinyStories-1M |

 
### Running Tests

 
 - `make unit-test`: Runs fast unit tests [docs/source/content/contributing.md76](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L76-L76)
 - `make test-pr`: The standard surface for PR reviews (unit + docstring + acceptance + integration) [docs/source/content/contributing.md75](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L75-L75)
 - `make test`: Runs everything including benchmarks and notebooks [docs/source/content/contributing.md81](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L81-L81)
 
 
### Quarantined Tests

 The `HookedTransformer` acceptance suite is currently **quarantined** due to CI test-pollution [docs/source/content/contributing.md3-7](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L3-L7) Changes to `HookedTransformer` internals require extra manual care. See `tests/QUARANTINES.md` for details [docs/source/content/contributing.md97-102](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L97-L102)

## Contribution Workflow

 
### Pull Request Process

 
 - **Target Branch:** Target the `dev` branch [.github/PULL_REQUEST_TEMPLATE.md1-4](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/.github/PULL_REQUEST_TEMPLATE.md?plain=1#L1-L4)
 - **Naming:** Do not name your branch `main` or `dev` [.github/PULL_REQUEST_TEMPLATE.md4-5](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/.github/PULL_REQUEST_TEMPLATE.md?plain=1#L4-L5) If your PR affects docs, include "docs" in the branch name to trigger doc builds [.github/PULL_REQUEST_TEMPLATE.md6](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/.github/PULL_REQUEST_TEMPLATE.md?plain=1#L6-L6)
 - **Mirroring Rule:** If you modify `HookedTransformer` behavior that has a `TransformerBridge` counterpart, you **must** update both in the same PR [AGENTS.md38](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/AGENTS.md?plain=1#L38-L38)
 - **Model Verification:** New model support should be verified using `transformer_lens.tools.model_registry.verify_models` [docs/source/content/contributing.md24](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/contributing.md?plain=1#L24-L24)
 
 
### Issue Reporting

 
 - **Bugs:** Use the Bug Report template and include a minimal reproduction [.github/ISSUE_TEMPLATE/bug.md1-28](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/.github/ISSUE_TEMPLATE/bug.md?plain=1#L1-L28)
 - **Proposals:** Use the Proposal template to outline motivation and pitch [.github/ISSUE_TEMPLATE/proposal.md1-32](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/.github/ISSUE_TEMPLATE/proposal.md?plain=1#L1-L32)
