  This page covers TransformerLens support for BERT-style encoder models through the `HookedEncoder` class and the `BertArchitectureAdapter`. Encoder models are bidirectional transformers that can attend to both past and future tokens, making them suitable for tasks like masked language modeling (MLM) and next sentence prediction (NSP). For autoregressive decoder models like GPT, see the main `HookedTransformer` documentation.

 
## Architecture Overview

 The `HookedEncoder` class provides a BERT-style encoder implementation with the same hooking capabilities as `HookedTransformer`. The key architectural differences from decoder models include bidirectional attention, post-normalization, and support for multiple input sequences through token type embeddings.

## BERT Component Architecture

 
### BertBlock Forward Pass

 The `BertBlock` implements the post-normalization pattern. Unlike `TransformerBlock` which applies normalization *before* the sublayer (pre-norm), BERT applies it *after* adding the residual [transformer_lens/components/bert_block.py73-76](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/bert_block.py#L73-L76)

 
| Hook Point | Description | Shape |
|---|---|---|
| hook_resid_pre | Input to the block | [batch, pos, d_model] |
| hook_attn_out | Output of the attention layer | [batch, pos, d_model] |
| hook_resid_mid | resid_pre + attn_out | [batch, pos, d_model] |
| hook_mlp_out | Output of the MLP layer | [batch, pos, d_model] |
| hook_resid_post | ln1(resid_mid) + mlp_out | [batch, pos, d_model] |
| hook_normalized_resid_post | Final output after ln2 | [batch, pos, d_model] |

### Masked Language Modeling (MLM) Head

 The `BertMLMHead` is responsible for predicting masked tokens. It applies a linear transformation, a GELU activation, and a LayerNorm before the final unembedding [transformer_lens/components/bert_mlm_head.py24-35](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/bert_mlm_head.py#L24-L35)

 
### Next Sentence Prediction (NSP) Head

 The `BertNSPHead` performs binary classification on the pooled output of the [CLS] token to determine if two sentences are sequential [transformer_lens/components/bert_nsp_head.py14-29](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/bert_nsp_head.py#L14-L29)

## Key Differences from Decoder Models

 
| Feature | HookedTransformer (Decoder) | HookedEncoder (BERT) |
|---|---|---|
| Attention | Causal (Masked) | Bidirectional (Unmasked) |
| Normalization | Pre-LN (usually) | Post-LN transformer_lens/components/bert_block.py21 |
| Input | tokens | tokens, token_type_ids transformer_lens/HookedEncoder.py155 |
| Heads | Unembed only | MLM Head, NSP Head, Pooler transformer_lens/HookedEncoder.py90-93 |
| Generation | Supported | Not supported transformer_lens/model_bridge/supported_architectures/bert.py28 |
