  The **Generalized Component** system is the foundation of the `TransformerBridge` architecture. It provides a standardized interface for various transformer parts (Attention, MLP, Blocks, etc.) by wrapping original HuggingFace (HF) modules. This system decouples the specific implementation of a model's layer from the `TransformerLens` hook system, allowing consistent activation access across diverse architectures like GPT-2, Llama, Mamba, and BERT.

 
## Overview of the Component Hierarchy

 All bridge components inherit from `GeneralizedComponent`, which provides core functionality for hook registration, property aliasing, and weight mapping.

## Base Component Class: `GeneralizedComponent`

 - **Hook Registration**: Standardizes `hook_in` and `hook_out` for every component [transformer_lens/model_bridge/generalized_components/base.py61-62](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/base.py#L61-L62)

## Attention Components

 Attention bridging is split into several specialized classes to handle different weight layouts and position embedding schemes.

 
### `AttentionBridge`

 The standard bridge for attention layers. It provides standard hooks like `hook_q`, `hook_k`, `hook_v`, and `hook_z` (output) [transformer_lens/model_bridge/generalized_components/attention.py33-38](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/attention.py#L33-L38)

 
 - **Split QKV Fork**: Supports capturing residuals before LayerNorm to provide `hook_q_input`, etc. [transformer_lens/model_bridge/generalized_components/attention.py113-117](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/attention.py#L113-L117)
 - **Auto-Conversion**: Uses `AttentionAutoConversion` to ensure activations match `TransformerLens` shapes (e.g., `[batch, pos, head, d_head]`) [transformer_lens/model_bridge/generalized_components/attention.py94-95](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/attention.py#L94-L95)
 
 
### `JointQKVAttentionBridge`

 Used for models like GPT-2 or BERT where Q, K, and V weights are fused into a single linear layer (often called `c_attn` or `query_key_value`).

 
 - **Logic**: It wraps three internal `LinearBridge` instances (`q`, `k`, `v`) and uses a `split_qkv_matrix` function to distribute weights from the fused HF layer to these virtual sub-components [transformer_lens/model_bridge/generalized_components/joint_qkv_attention.py68-83](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/joint_qkv_attention.py#L68-L83)
 
 
### `PositionEmbeddingsAttentionBridge`

 Designed for RoPE-based models (Llama, Gemma). It reimplements the attention forward pass to ensure hooks like `hook_rot_q` (post-rotation) fire at the correct stage [transformer_lens/model_bridge/generalized_components/position_embeddings_attention.py104-138](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/position_embeddings_attention.py#L104-L138)

 **Sources:** [transformer_lens/model_bridge/generalized_components/attention.py26-140](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/attention.py#L26-L140), [transformer_lens/model_bridge/generalized_components/joint_qkv_attention.py23-95](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/joint_qkv_attention.py#L23-L95), [transformer_lens/model_bridge/generalized_components/position_embeddings_attention.py104-147](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/position_embeddings_attention.py#L104-L147).

## Block and Normalization Bridges

 
### `BlockBridge`

 The `BlockBridge` [transformer_lens/model_bridge/generalized_components/block.py32](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/block.py#L32-L32) acts as a container for all sub-components in a transformer layer.

 
 - **Hook Placement**: It defines standard residual stream hooks: `hook_resid_pre`, `hook_resid_mid`, and `hook_resid_post` [transformer_lens/model_bridge/generalized_components/block.py42-52](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/block.py#L42-L52)
 - **Pre-LN Capture**: It can install `forward_pre_hook` on normalization layers to capture the residual stream *before* normalization, allowing for hooks like `hook_mlp_in` to see the un-normalized data [transformer_lens/model_bridge/generalized_components/block.py113-161](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/block.py#L113-L161)
 
 
### `NormalizationBridge`

 Wraps `nn.LayerNorm` or `RMSNorm`.

 
 - **Implementation**: It can either use the native HF autograd or a custom implementation that exposes `hook_scale` and `hook_normalized` (the centered/scaled activations before weight/bias application) [transformer_lens/model_bridge/generalized_components/normalization.py41-111](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/normalization.py#L41-L111)
 
 **Sources:** [transformer_lens/model_bridge/generalized_components/block.py32-111](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/block.py#L32-L111), [transformer_lens/model_bridge/generalized_components/normalization.py12-111](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/normalization.py#L12-L111).

## Linear and MLP Bridges

 
### `LinearBridge`

 A simple wrapper for `nn.Linear` or `Conv1D`. It is primarily used as a leaf component within `MLPBridge` or `AttentionBridge`. It exposes `weight` and `bias` through standard aliases [transformer_lens/model_bridge/generalized_components/linear.py10-25](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/linear.py#L10-L25)

 
### `MLPBridge`

 Wraps the MLP/Feed-Forward block.

 
 - **Gated MLPs**: Handles models with gating (like Llama's SwiGLU) by wrapping `gate`, `in`, and `out` linear layers.
 - **Aliases**: Provides `hook_pre` (after first projection) and `hook_post` (after activation) [transformer_lens/model_bridge/generalized_components/mlp.py15-45](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/mlp.py#L15-L45)
