## Dependency Groups

 TransformerLens uses optional dependency groups to keep the core installation lightweight while supporting specialized features like multimodal models and quantization.

 
| Group | Description | Key Packages |
|---|---|---|
| multimodal | Support for vision/audio models (LLaVA, Gemma 3, etc.) | timm, torchvision |
| quantization | Loading models in 4-bit/8-bit precision | bitsandbytes, optimum-quanto |
| dev | Development tools, linting, and testing | pytest, black, isort, mypy, circuitsvis |
| jupyter | Interactive notebook support | ipython, jupyterlab, ipywidgets |
| docs | Building documentation | sphinx, furo, myst-parser |
| evals | Model evaluation metrics | lm-eval |

## Environment Variables

 TransformerLens behavior can be tuned via environment variables. These are typically checked during initialization or when specific utilities are called.

 
### Core Configuration

 
 - **`HF_TOKEN`**: Required for accessing gated models (Llama-3, Gemma, etc.). [docs/source/content/getting_started.md42-48](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/getting_started.md?plain=1#L42-L48)
 - **`TRANSFORMERLENS_HF_RETRY`**: Set to `"1"` to enable automatic retries (up to 3 times) with exponential backoff for HuggingFace Hub requests that return HTTP 429. [transformer_lens/__init__.py38-41](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/__init__.py#L38-L41) [docs/source/content/getting_started.md50-58](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/getting_started.md?plain=1#L50-L58)
 - **`TRANSFORMERLENS_ALLOW_MPS`**: Set to `"1"` to enable Apple Silicon (MPS) acceleration. This is opt-in due to potential instability in some PyTorch ops on MPS. [docs/source/content/getting_started.md60-66](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/docs/source/content/getting_started.md?plain=1#L60-L66)
 
 
### Testing & CI

 
 - **`TL_FORCE_EXIT_AFTER_TESTS`**: Used in CI to prevent lingering non-daemon threads from hanging the process. [.github/workflows/checks.yml54-57](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/.github/workflows/checks.yml#L54-L57)
