  This document covers the implementation of T5-style encoder-decoder models in TransformerLens. The `HookedEncoderDecoder` class provides interpretability tools for T5 models, enabling analysis of both encoder and decoder components as well as cross-attention mechanisms.

 For decoder-only models like GPT, see **3.2 HookedTransformer (Legacy)**. For encoder-only models like BERT, see **5.2 Encoder Models (BERT)**.

### T5Attention with Relative Positional Bias

 T5 uses relative positional embeddings instead of absolute ones. The `T5Attention` component computes a `relative_attention_bias` which is added to the attention scores.

 
| Feature | T5Attention | Standard Attention |
|---|---|---|
| Positional Encoding | Relative bias buckets | Absolute/RoPE/ALiBi |
| Bias Parameters | b_K, b_V | b_Q, b_K, b_V |
| Query Bias | None | b_Q |
| Cross-Attention | Supported | Not applicable |

## Limitations and Differences

 
### Current Limitations

 
| Limitation | Description |
|---|---|
| No LayerNorm Folding | Weight processing like folding is not yet supported for T5 transformer_lens/HookedEncoderDecoder.py54 |
| Single Device | HookedEncoderDecoder does not support multiple devices transformer_lens/HookedEncoderDecoder.py78-79 |
| Token Inputs | Core forward pass primarily expects tokens, though some string support exists transformer_lens/HookedEncoderDecoder.py55 |
| No Dropout | Model does not include dropouts, impacting training parity transformer_lens/HookedEncoderDecoder.py51 |

 Sources: [transformer_lens/HookedEncoderDecoder.py50-79](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/HookedEncoderDecoder.py#L50-L79)

 
### Architectural Differences from GPT

 Unlike `HookedTransformer`, `HookedEncoderDecoder` handles the bidirectional encoder and the causal decoder with cross-attention. It also defaults to `RMSNorm` and T5-specific attention biases.

 
| Aspect | T5 (HookedEncoderDecoder) | GPT (HookedTransformer) |
|---|---|---|
| Structure | Encoder-Decoder | Decoder-only |
| Attention | Self + Cross-attention | Self-attention only |
| Positional Encoding | Relative bias buckets | Absolute/RoPE |
| Normalization | RMSNorm | LayerNorm |
