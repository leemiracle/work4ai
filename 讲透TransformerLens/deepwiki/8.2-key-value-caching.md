## Purpose and Scope

 This document describes the Key-Value (KV) caching mechanism in TransformerLens, a performance optimization technique that significantly speeds up autoregressive text generation. KV caching stores previously computed attention keys and values to avoid redundant calculations when generating text token by token. This page covers the implementation details, data flow, and integration within both `HookedTransformer` and the `TransformerBridge` architecture.

## Overview

 Key-Value caching is a critical optimization for transformer models during text generation. In autoregressive generation, the model processes one token at a time. Without caching, it would recompute attention calculations for all previous tokens with each new token. By storing and reusing previously computed keys and values, KV caching reduces the computational complexity from $O(n^2)$ to $O(n)$ for generating $n$ tokens.

## Cache Data Structure

 Each cache entry stores keys and values as tensors with specific shapes. The system ensures the cache matches the model's `dtype` to prevent accidental type promotion (e.g., from `float16` to `float32`) which can break attention matmuls.

 
| Attribute | Tensor Shape | Description |
|---|---|---|
| past_keys | [batch, pos_so_far, n_heads, d_head] | Cached keys for all processed positions. |
| past_values | [batch, pos_so_far, n_heads, d_head] | Cached values for all processed positions. |

 The `n_heads` dimension is determined by `cfg.n_key_value_heads` if Grouped Query Attention (GQA) is used, otherwise it defaults to `cfg.n_heads`.

### Appending and Freezing

 During the forward pass, new keys and values are concatenated to the existing tensors. The cache supports a `frozen` state, which is useful for generating multiple continuations from a fixed prefix (e.g., prompt).

 
 - **Append**: `torch.cat([self.past_keys, new_keys], dim=1)` extends the sequence length.
 - **Freeze**: Sets `frozen=True` on the cache and all its entries. Subsequent `append` calls will return the updated tensors for the current forward pass but will **not** update the stored state in the cache.

## Advanced Usage: Left Padding

 TransformerLens supports KV caching even with padded batches. The `append_attention_mask` method in `TransformerLensKeyValueCache` manages the concatenation of attention masks across generation steps. This is critical for models using `padding_side="left"`, ensuring that position embeddings and attention calculations remain numerically stable.
