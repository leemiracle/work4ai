## Purpose and Scope

 The Head Detection system in TransformerLens provides utilities for identifying specialized attention heads in transformer models. This feature allows researchers to automatically detect common attention head patterns such as previous token heads, duplicate token heads, and induction heads, which are frequently studied in mechanistic interpretability research. The module is designed to replace manual visualization workflows with an automated scoring system based on attention pattern templates.

 
## Overview

 Head detection works by comparing attention patterns produced by a model to predefined pattern templates. It computes a similarity score for each attention head, which indicates how well its attention pattern matches the expected pattern for a specific type of head.

## Detection Patterns and Error Measures

 
### Detection Patterns

 TransformerLens supports several predefined attention patterns that represent common head types. These are defined in the `HeadName` literal [transformer_lens/head_detector.py18-19](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L18-L19)

 
 - **Previous Token Head**: Attends to the token immediately before the current token.
 - **Duplicate Token Head**: Attends to previous occurrences of the current token.
 - **Induction Head**: Attends to tokens that follow the same previous context.
 
 Custom patterns can be provided as `torch.Tensor` objects, but they must be lower triangular and match the sequence length [transformer_lens/head_detector.py131-133](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L131-L133)

### Error Measures

 The similarity between the `attention_pattern` and the `detection_pattern` is calculated using one of two measures [transformer_lens/head_detector.py20](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L20-L20):

 
 - **Multiplication (`"mul"`)**: 
 - Multiplies both tensors element-wise and divides the sum of the result by the sum of the actual attention pattern [transformer_lens/head_detector.py255-256](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L255-L256)
 - Interpretable as: "What fraction of this head's attention is allocated to these specific query-key pairs?"
 - **Absolute Difference (`"abs"`)**: 
 - Calculates the mean element-wise absolute difference [transformer_lens/head_detector.py266-267](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L266-L267)
 - The result is mapped to a `(-1, 1)` interval, where `1` is a perfect match and `-1` is a perfect mismatch [transformer_lens/head_detector.py65-67](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L65-L67)

## Implementation of Pre-defined Patterns

 
### Previous Token Head

 Defined in `get_previous_token_head_detection_pattern` [transformer_lens/head_detector.py166-177](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L166-L177) It creates a diagonal pattern where query `i` attends to key `i-1`.

 
### Duplicate Token Head

 Defined in `get_duplicate_token_head_detection_pattern` [transformer_lens/head_detector.py181-197](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L181-L197) It uses `np.equal` on the token IDs to find all previous positions with the same token value.

 
### Induction Head

 Defined in `get_induction_head_detection_pattern` [transformer_lens/head_detector.py201-219](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/head_detector.py#L201-L219) It takes the duplicate token pattern and shifts it forward by one position (`torch.roll`), identifying heads that attend to the token that *followed* the current token's previous occurrence.
