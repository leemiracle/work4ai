  This page covers the attention component system in TransformerLens, focusing on the `AbstractAttention` base class and its associated implementations. This includes standard attention, Grouped Query Attention (GQA), and specialized architectures like Multi-Head Latent Attention (MLA), along with utilities for RoPE, ALiBi, and QK normalization.

 
## Architecture Overview

 The attention system is designed for mechanistic interpretability, providing explicit access to every intermediate tensor. The `AbstractAttention` base class defines the shared logic for projections, masking, and hook points.

## AbstractAttention Class Structure

 `AbstractAttention` uses the `better_abc.abstract_attribute` pattern to force subclasses to implement Key and Value projections while providing shared logic for Query and Output projections.

 
### Parameters and Projections

 
 - **Query & Output**: Defined in the base class. If `load_in_4bit` is enabled, these use `bitsandbytes.nn.modules.Params4bit` [transformer_lens/components/abstract_attention.py60-84](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/abstract_attention.py#L60-L84)
 - **Key & Value**: Abstract attributes `W_K`, `W_V`, `b_K`, and `b_V` implemented by child classes to support varying head structures (e.g., GQA) [transformer_lens/components/abstract_attention.py85-92](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/abstract_attention.py#L85-L92)
 
 
### Hook Points for Interpretability

 The class registers several `HookPoint` instances to intercept the data flow [transformer_lens/components/abstract_attention.py143-157](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/abstract_attention.py#L143-L157):

 
| Hook Point | Shape | Description |
|---|---|---|
| hook_q | [batch, pos, head_index, d_head] | Queries after projection. |
| hook_k | [batch, pos, head_index, d_head] | Keys after projection. |
| hook_v | [batch, pos, head_index, d_head] | Values after projection. |
| hook_z | [batch, pos, head_index, d_head] | Values weighted by attention pattern. |
| hook_attn_scores | [batch, head_index, q_pos, k_pos] | Pre-softmax scores. |
| hook_pattern | [batch, head_index, q_pos, k_pos] | Post-softmax probabilities. |
| hook_result | [batch, pos, head_index, d_model] | Per-head contribution to residual stream. |

## Specialized Attention Implementations

 
### Grouped Query Attention (GQA)

 `GroupedQueryAttention` implements the GQA mechanism where multiple query heads share a single key/value head. Under the hood, weights are stored in their compressed form (`n_key_value_heads`) and expanded via `torch.repeat_interleave` during property access or forward passes to maintain compatibility with analysis tools [transformer_lens/components/grouped_query_attention.py20-88](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/grouped_query_attention.py#L20-L88)

 
### Multi-Head Latent Attention (MLA)

 MLA (used in DeepSeek models) compresses keys and values into a latent vector to reduce KV cache size. TransformerLens implements this while preserving hooks for the latent projections.

 
### T5 Attention

 `T5Attention` supports relative position biases. The first block in a T5 stack typically calculates the bias, which is then passed to subsequent blocks [transformer_lens/components/t5_block.py29-33](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/t5_block.py#L29-L33)

## Attention Utilities

 
### Rotary Positional Embeddings (RoPE)

 RoPE applies a rotation to the Query and Key vectors based on their position. `AbstractAttention` manages a cache for `rotary_sin` and `rotary_cos` to avoid redundant computation.

 
 - **Dynamic Extension**: The cache is extended on-demand if the sequence length exceeds the initial size [tests/unit/components/test_attention.py157-186](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/tests/unit/components/test_attention.py#L157-L186)
 - **Hooks**: Supports `hook_rot_q` and `hook_rot_k` for analyzing vectors after rotation [transformer_lens/model_bridge/generalized_components/position_embeddings_attention.py3-9](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/model_bridge/generalized_components/position_embeddings_attention.py#L3-L9)
 
 
### ALiBi (Attention with Linear Biases)

 ALiBi adds a constant bias to the attention scores that penalizes distance between tokens. TransformerLens pre-calculates the ALiBi slope and bias matrix during initialization [transformer_lens/components/abstract_attention.py624-756](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/abstract_attention.py#L624-L756)

 
### QK Norm

 Some models (e.g., OLMo, MoE architectures) apply `RMSNorm` to queries and keys before computing attention scores to improve training stability. This is toggled via `cfg.use_qk_norm` [transformer_lens/components/abstract_attention.py95-114](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/abstract_attention.py#L95-L114)

## Mathematical Analysis Tools

 The attention components expose the `QK` and `OV` circuits as `FactoredMatrix` objects, enabling efficient decomposition and eigenvalue analysis without materializing the full matrices.

 
 - **QK Circuit**: `W_Q @ W_K.T`. Determines "where" a head attends [transformer_lens/components/abstract_attention.py169-180](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/abstract_attention.py#L169-L180)
 - **OV Circuit**: `W_V @ W_O`. Determines "what" information is transferred [transformer_lens/components/abstract_attention.py158-167](https://github.com/TransformerLensOrg/TransformerLens/blob/4ba2187b/transformer_lens/components/abstract_attention.py#L158-L167)
