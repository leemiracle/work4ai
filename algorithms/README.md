## 🔴 四个必懂的"反直觉/不可能"定理

1. **比较排序有天花板** — Ω(n log n) 是信息论下界，再聪明也突破不了（除非跳出比较框架，如计数排序）。
2. **平摊 O(1) ≠ 单次 O(1)** — 动态数组扩容单次 O(n)，但 n 次均摊仍 O(1)，靠"势能法"证明。
3. **23 人就有 50% 同生日** — 哈希碰撞是 O(√m) 而非 O(m)，碰撞不可避免。
4. **停机问题不可判定** — Turing 用对角线证明：不存在程序能判断任意程序是否停机。这是计算的绝对边界。
