# 艺术 · 扩散模型的创造数学

> **博士级**：扩散模型在艺术中的数学 + 创造性争论。

## 一、扩散模型的数学（回顾）

详见 [`讲透生成模型`](../../../讲透生成模型/)。

核心：

```
forward: x_0 → x_1 → ... → x_T（加噪）
reverse: x_T → ... → x_0（去噪 = 生成）
```

**score function**：$\nabla_x \log p(x)$

**生成** = Langevin dynamics / probability flow ODE。

## 二、文本到图像

### 2.1 CLIP（Radford 2021）

- 图像 + 文本对训练
- 联合嵌入空间
- 提供文本"理解"

### 2.2 Stable Diffusion 架构

```
文本 → CLIP encoder → text embedding
                              ↓
噪声图像 → U-Net（cross-attention）→ 去噪图像
                              ↑
                         VAE（压缩）
```

### 2.3 关键组件

- **U-Net** + **cross-attention**
- **VAE**（latent space）
- **text encoder**（CLIP）
