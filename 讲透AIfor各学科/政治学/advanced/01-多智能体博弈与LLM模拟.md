## 二、LLM 多智能体模拟

### 2.1 SmallVille 架构（Park 2023）

```
每个 agent：
  - 身份（性别 / 年龄 / 职业 / 价值观）
  - 记忆（流式记录）
  - 反思（定期总结）
  - 规划（每日日程）
  - 行动（基于以上）

环境：
  - 地点（家 / 工作地点 / 公共空间）
  - 时间（每步 = 时间段）
  - 互动（agent 相遇 → 对话）
```

### 2.2 涌现现象

- **情人节派对**：一个 agent 提出，传播，其他人参加
- **选举**：候选 + 辩论 + 投票
- **没显式编程**——从规则涌现
