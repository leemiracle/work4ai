## 一、政治学为什么需要 AI

### 1.1 数据丰富

- **选举数据**：百年投票记录
- **社交媒体**：政治讨论 + 假新闻传播
- **议会记录**：Hansard / 国会辩论
- **政府文档**：政策文本

### 1.2 复杂系统

- 选举 = 多变量（经济 + 媒体 + 候选人 + 国际）
- **预测极难**（2016 美国大选几乎全错）

### 1.3 AI 双刃剑

- **正面**：模拟政策 / 自动立法 / 公民参与
- **负面**：假新闻 / 监控 / 操纵 / 选举干预

---

## 二、AI 在政治学的六大应用

### 2.1 选举预测

- **经典**：民调 + 经济指标
- **AI**：社交媒体情绪 + LLM 分析
- **代表**：**PredictWise / Metaculus**

**2016 教训**：传统民调错。AI 是否更准？2024 美国大选测试。

### 2.2 假新闻检测 / 制造

**检测**：
- AI 识别 LLM 生成内容
- 事实核查（FactCheck + LLM）
- **困难**：检测落后于生成

**制造**：
- LLM 大规模生成政治假新闻
- **Deepfake 视频**（2024 多国选举）
- 俄罗斯 / 中国 / 美国互相指控

### 2.3 政治文本分析

- **议会辩论**：LLM 摘要 + 立场分类
- **政策文件**：自动比较 / 影响
- **政客发言**：谎言检测（争议）

### 2.4 政策模拟

- **多智能体 LLM** 模拟政策效果
- "如果减税 5%，选民怎么反应？"
- 早期但前景

### 2.5 国际关系

- **事件预测**（中东冲突 / 中美贸易）
- **GDELT** 数据集：全球事件实时
- **LLM 分析外交文档**

### 2.6 公民参与

- **AI 辅助投票**：解释政策 / 候选人立场
- **Deliberative Democracy**（协商民主）+ LLM
- **风险**：算法偏见 / 操纵
