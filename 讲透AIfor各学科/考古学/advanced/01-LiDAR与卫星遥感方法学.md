# 考古学 · LiDAR + 卫星遥感方法学

> **博士级**：考古遥感的技术 + AI。

## 一、遥感技术

### 1.1 LiDAR（激光雷达）

- 飞机 / 无人机 / 卫星
- 激光脉冲穿透植被
- 地面微地貌
- 精度 cm 级

### 1.2 多光谱 / 高光谱卫星

- **Sentinel / Landsat**：免费
- **Planet / Maxar**：商业高分辨率
- NDVI / 微波

### 1.3 SAR（合成孔径雷达）

- 穿透云层 / 植被
- 城市遗址
- 埃及沙漠古河道

## 二、AI 找遗址

### 2.1 CNN 分类

- 卫星图像 → 是否有遗址
- **Parcak / GlobalXplorer** 公民科学

### 2.2 异常检测

- 找"不寻常"的地貌
- 早期城堡 / 墓葬

### 2.3 LiDAR 点云分析

- 地面模型 → 找人工结构
- CNN 处理 3D 点云

### 2.4 多源融合

- LiDAR + 多光谱 + SAR + 历史
- 多模态 AI

## 五、方法学挑战

### 5.1 验证

- 遥感发现 → 实地验证
- 成本 + 政治限制
- **不确定**

### 5.2 误报

- 自然地貌 vs 人工
- 需专家判断
- **AI + 人协作**

### 5.3 数据访问

- 高分辨率商业数据贵
- **开放数据**运动

### 5.4 政治限制

- 战乱区难进入
- 卫星是唯一方式
- **e.g., 叙利亚 / 也门**
