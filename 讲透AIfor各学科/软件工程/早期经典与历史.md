# 软件工程 · 早期经典（1960s-2010s）

## 一、Dijkstra 1968——Go To 有害
**Edsger Dijkstra**：
- *"Go To Statement Considered Harmful"*
- 结构化编程
- **软件工程方法论开端**

## 二、Royce 1970——瀑布模型
**Winston Royce**：
- 软件开发生命周期
- 瀑布 / 螺旋 / 敏捷
- **软件工程的方法论**

## 三、Brooks 1975——人月神话
**Fred Brooks**：
- *"Adding manpower to a late software project makes it later"*
- 软件不可压缩性
- **项目管理的经典**

## 四、C++ / Java（1980s-1990s）
- **Stroustrup**（C++，1979）
- **Gosling**（Java，1995）
- 面向对象编程
- **企业软件基础**

## 五、敏捷开发（2001）
**Agile Manifesto**：
- 迭代 + 用户反馈
- Scrum / Kanban
- **替代瀑布**

## 六、开源运动（1990s-）
- **Linux**（1991）
- **Git**（2005）
- **GitHub**（2008）
- **协作开发**

## 七、DevOps（2009-）
- CI/CD
- Docker / Kubernetes
- 基础设施即代码

## 八、GitHub Copilot（2021）
- AI 代码生成
- **50% 代码 AI 写**
- **软件工程的 AI 时代**
