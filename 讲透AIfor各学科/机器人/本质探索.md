# 机器人 · 本质探索——具身智能的本质

> 机器人与软件 AI 的本质区别是什么？具身智能意味着什么？

## 一、机器人学的第一性问题

### 1.1 研究/做什么

机器人 = **感知 + 决策 + 执行**的**物理实体**。

### 1.2 莫拉维克悖论

- **下棋 / 数学**（高级认知）→ AI 容易
- **抓杯子 / 走路**（感知运动）→ AI 极难

**为什么**？进化花了**数亿年**优化运动；数学只有几千年。

### 1.3 具身智能

- 智能**不只是大脑**——需要**身体**
- 感知 + 行动 + 环境
- **认知 = 具身**

> 🎯 **本质**：智能是**身体 + 环境 + 大脑**的耦合——不是纯计算。
