## §1 四大代表模型深度对比

### 1.1 总览表

| 维度 | RT-2 | π0 | OpenVLA | GR00T |
|------|------|-----|---------|------|
| **机构** | Google DeepMind | Physical Intelligence | Stanford/UC Berkeley | NVIDIA |
| **年份** | 2023 | 2024.10 | 2024.06 | 2024（待核）|
| **基础** | PaLI-X / PaLM-E（VLM）| PaliGemma + Flow Matching | Llama 2/3 + ViT | 多模态 LLM |
| **动作表示** | **离散 token**（256 bins × 7D）| **连续 Flow Matching** | 离散 token | 待核 |
| **训练数据** | 互联网图文 + 机器人数据 | 跨 embodiment 万亿 token | Open-X-Embodiment | Open-X + 自有 |
| **跨 embodiment** | 部分 | ✅ 强（多机器人）| ✅ 开源通用 | ✅ 人形专用 |
| **开源** | ❌ 闭源 | ❌ 闭源（论文开放）| ✅ **全开源**（权重+代码）| 🟡 部分开源 |
| **推理速度** | 慢（LLM 解码）| **快**（Flow 1-10 步）| 中 | 待核 |
| **定位** | 研究里程碑 | 商业通用模型 | 开源社区标准 | 人形基础模型 |

### 1.2 RT-2：VLA 的开山之作（Google 2023）

**核心创新**：把机器人动作当作"另一种语言"，让 VLM 直接输出动作 token。

```
输入：图像 + "把可乐拿起来"
        ↓ VLM (PaLI-X)
输出：<action_token_1> <action_token_2> ... <action_token_7>
        ↓ 反离散化
动作：[x, y, z, rx, ry, rz, gripper] 7 维
```

**动作 token 化**（呼应 [advanced/01 §2.2](./advanced/01-VLA数学.md)）：每维离散化为 256 bins → 7 维动作变 7 个 token → VLM 用标准 next-token prediction 训练。

**历史意义**：第一次证明"VLM 的语义理解能直接驱动机器人"，打通了 LLM → 机器人的桥梁。

**局限**：
- 离散化损失精度
- LLM 解码慢（不适合高频控制）
- 闭源，难复现

### 1.3 π0：通用机器人 Foundation Model（Physical Intelligence 2024）

**核心创新**：用 **Flow Matching** 替代 diffusion/离散化，实现**快速 + 连续 + 多机器人**通用 policy。

**架构**（呼应 [advanced/01 §3](./advanced/01-VLA数学.md)）：
```
图像 I → PaliGemma (VLM) → 语义表征
语言 l → PaliGemma → 指令表征
        ↓ Flow Matching 头
   噪声动作 x0 → 向量场 vθ → 真实动作 x1
        ↓ 1-10 步
   连续动作（7-20 维，适配不同机器人）
```

**为什么 Flow Matching 而不是 diffusion**：
| 维度 | Diffusion | Flow Matching |
|------|-----------|---------------|
| 推理步数 | 50+ | 1-10 |
| 训练稳定 | 好 | 好 |
| 数学 | SDE | ODE（更简洁）|
| 机器人适用 | 慢 | **快（高频控制可承受）** |

**跨 embodiment 的设计**：π0 用**动作头适配器**——同一个 VLM 主体，不同机器人换不同的动作头。这是"通用 model + embodiment 适配"的工程哲学。

**历史意义**：第一个**商业级通用机器人 Foundation Model**，覆盖机械臂/人形/双臂等多种形态。

### 1.4 OpenVLA：开源 VLA 标杆（Stanford/Berkeley 2024）

**核心创新**：在 Llama 2/3 上接 ViT，用 Open-X-Embodiment 训出**第一个全开源、可复现、效果接近闭源**的 VLA。

```
图像 → ViT (DINOv2/SigLIP) → 视觉 token
语言 → Llama tokenizer → 语言 token
        ↓ 联合 self-attention
      Llama 2/3 trunk
        ↓ 动作头
      离散 token（255 bins × 7D）
```

**为什么重要**：
- **全开源**：权重 + 数据 + 训练代码 + 评估 pipeline
- **可微调**：社区可以在自己的机器人上 LoRA 微调
- **标杆作用**：所有后续开源 VLA 都对标 OpenVLA

**局限**：离散动作 + Llama 解码 → 推理偏慢（~5Hz，不如 π0 的 Flow）。

### 1.5 GR00T：人形专用（NVIDIA 2024）

**核心创新**：NVIDIA 为**人形机器人**量身打造的基础模型，深度整合 Isaac Lab 仿真生态。

**定位差异**：
- RT-2/π0/OpenVLA 偏**机械臂操作**
- GR00T 偏**人形全身控制**（双足行走 + 灵巧手 + 操作）

**生态优势**：Isaac Lab 仿真 + Omniverse 渲染 + Jetson 部署 + GR00T 模型 = **NVIDIA 全家桶**。这是 NVIDIA 的平台战略。

## §2 训练数据：VLA 的"燃料"

### 2.1 三大数据集

| 数据集 | 规模 | 特色 |
|--------|------|------|
| **Open-X-Embodiment**（2023, 22 机构）| 100 万+ 轨迹 | **跨 embodiment 统一格式**，VLA 训练的事实标准 |
| **DROID**（2024）| 开放机器人操作数据 | 多场景多样 |
| **π0 自有**（Physical Intelligence）| 万亿 token 量级 | 闭源，最大规模 |

### 2.2 数据的三大挑战

1. **规模**：相比 LLM 的万亿 token，机器人数据量小 1000×
2. **异构**：不同机器人的动作空间/传感/embodiment 完全不同
3. **成本**：一条遥操作轨迹 ~$50，10 万条 = $500 万

### 2.3 解法：仿真数据 + 真实数据混合

呼应 [05 §2](./05-机器人RL工程实战.md)：仿真海量生成（便宜）+ 真实遥操作（精确）混合训练。这是 2024-2026 的主流数据策略。

## §3 能力评估：VLA 怎么比

### 3.1 评估的难题

LLM 有 MMLU/HumanEval，VLA 的评估**远未标准化**：
- 不同机器人任务无法直接比
- Sim2Real 表现 ≠ 真机表现
- 泛化能力难量化

### 3.2 2024-2026 主流 Benchmark

| Benchmark | 任务 | 指标 |
|-----------|------|------|
| **LIBERO**（Berkeley）| 操作任务套件 | 成功率 |
| **CALVIN** | 长程多步操作 | 任务完成数 |
| **Open-X-Embodiment** 评测 | 跨 embodiment 泛化 | 平均成功率 |
| **真机评测** | 各实验室自定 | 任务成功率 |

### 3.3 诚实现状（2026-08）

- **开源 VLA（OpenVLA）** 在 LIBERO 上 ~90% 成功率，但真机泛化仍有限
- **闭源 VLA（π0）** 真机表现更强，但无法复现验证
- **跨 embodiment** 仍是开放问题——一个模型通吃所有机器人？2026 还没答案

## §4 2026 前沿方向

### 4.1 VLA + RL 微调（最热）

**范式**（呼应 [05 §6.2](./05-机器人RL工程实战.md)）：
```
大规模示教预训练 VLA → RL 在仿真/真机微调 → 超越示教性能
```

这是 2026 最活跃的方向——把 LLM 的"预训练 + RLHF"完整搬到机器人。

### 4.2 World Model + VLA

**思路**：让 VLA 内置世界模型，能在"脑内"推演动作后果再执行。
- **Genie 2**（DeepMind 2024，待核）：可玩世界模型
- **Dreamer V3 + 视觉**：在 latent 空间规划
- 详见 [`讲透世界模型/`](../../讲透世界模型/)

### 4.3 长程任务规划

**挑战**：VLA 擅长短动作（抓/放），但"做一顿饭"需要**长程任务分解 + 多步执行**。
- **LLM 高层规划 + VLA 低层执行**的层次架构（SayCan/PaLM-E 路线）
- 详见 [`讲透Agent/03-规划与搜索`](../../讲透Agent/03-规划与搜索.md)

### 4.4 灵巧手（最难的硬件）

**现状**：平行夹爪任务 VLA 已较好，**多指灵巧手**仍极难（高维动作空间 + 接触丰富）。
- **DexCap**（Stanford 2024）：灵巧手示教
- **Any-point Manipulation**：通用操作

## §6 一句话总结

> 🎯 **5 句话**：
> 1. **VLA = LLM 推理能力 + 机器人动作**，2024-2026 是具身 RL 的"LLM 时刻"。
> 2. **四大代表**：RT-2（开山，离散 token）/ π0（通用商业，Flow Matching）/ OpenVLA（开源标杆）/ GR00T（人形专用）。
> 3. **动作表示两大流派**：离散 token（RT-2/OpenVLA，简单但慢）vs 连续 Flow Matching（π0，快且通用）。
> 4. **数据是瓶颈**：Open-X-Embodiment 是事实标准，但规模比 LLM 小 1000×，靠仿真数据补。
> 5. **2026 最热方向**：VLA + RL 微调（把 LLM 的预训练+RLHF 搬到机器人）+ World Model 集成。
