# 00 · AI for Aerospace 是什么

> **第一性问题**：航空航天是**最复杂工程**——气动 / 结构 / 推进 / 控制 / 任务，每秒百万级传感器数据。**SpaceX 火箭回收** + **波音 737 MAX 事故**——AI 在两端都有戏。

## 一、航空航天为什么需要 AI

### 1.1 系统复杂

- **气动**：Navier-Stokes 高维
- **结构**：疲劳 / 振动
- **推进**：燃烧 / 喷流
- **任务**：轨道 + 导航

### 1.2 数据爆炸

- 飞机传感器：**每秒 GB**
- 卫星数据：每天 TB
- 仿真数据：PB 级

### 1.3 自主需求

- SpaceX 自动对接
- 无人机 / eVTOL
- 深空探测（通讯延迟，必须自主）

## 二、AI 在航空航天的六大应用

### 2.1 气动设计

- **CFD 加速**：Neural Operators / PINN
- **形状优化**（翼型 / 机身）
- 代表：**AirShaper / NTopology**

详见 [`讲透AIfor各学科/物理`](../物理/) § 流体。

### 2.2 结构健康监测

- **传感器 + AI**：实时监测飞机 / 卫星健康
- 预测性维护
- **代表**：GE Aviation / Rolls-Royce

### 2.3 飞行控制

- **RL 自动驾驶**（部分）
- **波音 / 空客** 自动驾驶系统
- **SpaceX** 火箭回收 AI（部分）

### 2.4 任务规划

- **卫星轨道优化**
- **星际任务规划**
- **无人机路径规划**

### 2.5 太空探索

- **火星车自主导航**（Perseverance）
- **深空探测器**
- **James Webb / Hubble** 数据分析（[`讲透AIfor各学科/天文`](../天文/)）

### 2.6 制造

- **3D 打印 + AI**（GE LEAP 引擎喷嘴）
- **复合材料设计**
- **数字孪生**

## 三、航空航天专属的方法学

### 3.1 物理嵌入

- **PINN**（Physics-Informed NN）
- **守恒律**严格遵守
- 详见 [`讲透AIfor各学科/物理`](../物理/)。

### 3.2 数字孪生

- 飞机 / 发动机的实时仿真副本
- **NASA / GE** 大量使用
- 故障预测 + 优化

### 3.3 极端可靠性

- 失败成本：**人命 + $B**
- **AI 必须可验证**
- 形式化方法 + AI

### 3.4 实时约束

- 控制循环 ms 级
- **边缘 AI**（机载）
- 算力受限
