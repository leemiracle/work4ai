# 法学 · AI 法与全球监管

> **博士级**：AI 法本身——欧盟 AI Act / 美国 / 中国的分歧。

## 一、欧盟 AI Act（2024 生效）

### 1.1 分级监管

| 风险等级 | 例子 | 监管 |
|---|---|---|
| **不可接受**（禁止）| 社会评分 / 实时人脸识别（部分）| **禁止** |
| **高风险** | 招聘 / 教育 / 司法 / 医疗 | **严格审查** |
| **有限风险** | 聊天机器人 / 深度伪造 | **透明** |
| **最小风险** | 垃圾邮件过滤 | **无监管** |

### 1.2 关键要求

- **风险管理体系**
- **数据治理**
- **透明度**
- **人类监督**
- **准确性 + 鲁棒性**
- **注册**（高风险）

### 1.3 罚款

- 最高 **€35M 或全球收入 7%**
