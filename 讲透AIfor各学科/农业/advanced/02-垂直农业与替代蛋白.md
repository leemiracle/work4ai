# 农业 · 垂直农业 + 替代蛋白

> **博士级**：AI 驱动的食物生产革命。

## 一、垂直农业（Vertical Farming）

### 1.1 概念

- 室内多层种植
- LED + 水培 / 气培
- **完全可控环境**

### 1.2 优势

- **100× 单位面积产量**（vs 传统）
- 节水 95%
- 无农药
- 城市周边（减少运输）

### 1.3 AI 控制

```
传感器：光 / 温 / 湿 / CO2 / 养分
   ↓ AI
优化：生长速度 / 营养 / 风味
   ↓
自动调整
```

**代表公司**：
- **Plenty**（旧金山）：$540M 融资
- **Bowery Farming**（纽约）
- **AeroFarms**（新泽西）
- **Spread**（日本）
- **Infarm**（柏林，2023 困境）

## 二、AI 在垂直农业

### 2.1 生长优化

- 每个生长阶段的最佳条件
- **RL** 学习
- 光配方（光谱 + 强度 + 时间）

### 2.2 病虫害检测

- 计算机视觉
- 早期发现
- 自动隔离

### 2.3 产量预测

- 时序 + 多变量
- **供应链优化**

### 2.4 遗传育种

- 选最佳品种
- 基因组 + AI

## 三、挑战

### 3.1 能耗

- LED 耗电大
- **可再生能源**搭配
- 成本仍高

### 3.2 作物限制

- 叶菜适合（生菜 / 菠菜）
- **谷物 / 水果**难（高度 / 时间）

### 3.3 商业模式

- 高成本 → 高价格
- **大众化**挑战
