# 00 · AI for Agriculture 是什么

> **第一性问题**：**2050 年 100 亿人要吃饭**——粮食产量必须增 70%。土地 / 水 / 化肥都有极限。AI 是**精准农业的核心**——从卫星到拖拉机到无人机。
>

## 一、农业为什么需要 AI

### 1.1 粮食安全

- 2050 人口 100 亿
- 当前 8 亿人挨饿
- 必须**增产 70%**（FAO）

### 1.2 资源约束

- 可耕地有限
- 水资源紧张
- 化肥污染

### 1.3 气候影响

- 极端天气
- 病虫害扩散
- **AI 帮应对**

### 1.4 劳动力短缺

- 农业人口老化
- 年轻人进城
- **机器人替代**

---

## 二、AI 在农业的六大应用

### 2.1 精准农业

- **卫星 + 无人机**：作物健康监测
- **NDVI**（归一化植被指数）
- **变量施肥**：每平方米定制

**代表**：**Climate FieldView**（Bayer）/ **John Deere Operations Center**

### 2.2 病虫害检测

- **图像识别**（手机 / 无人机）
- 早期预警
- **代表**：Plantix / PlantSnap

### 2.3 自动驾驶农机

- **John Deere** 自动拖拉机
- **激光除草**（Carbon Robotics 2021）
- **采摘机器人**

详见 [`讲透AIfor各学科/机器人`](../机器人/)。

### 2.4 作物育种

- **基因组选择**（GS）+ ML
- 加速育种周期
- **CRISPR + AI**
- 详见 [`讲透AIfor各学科/生物`](../生物/)。

### 2.5 牲畜管理

- **牛脸识别**（Cainthus / Ever.Ag）
- 健康监测（智能耳标）
- 自动挤奶

### 2.6 供应链

- **冷库 + AI**（减少浪费）
- **价格预测**
- **溯源**（区块链 + AI）

## 三、农业专属的方法学

### 3.1 多光谱遥感

- 卫星 + 无人机
- **NDVI / NDWI / EVI**
- AI 处理海量图像

### 3.2 物联网 + AI

- 土壤湿度 / 温度 / 养分传感器
- 边缘 AI（离线）
- **小数据 + ML**

### 3.3 育种 + 基因组

- **GWAS + ML**
- 基因组选择
- 详见 [`讲透AIfor各学科/生物`](../生物/)。

### 3.4 边缘 + 离线

- 农村网络差
- 模型必须小 + 离线
- **TinyML**

## 四、当前前沿（2024-2026）

### 4.1 大型农业 AI 公司

- **John Deere**：自动拖拉机 + See & Spray（激光除草）
- **Climate FieldView**（Bayer）
- **Farmers Business Network**

### 4.2 垂直农业

- **Plenty / Bowery / AeroFarms**
- AI 控制光 / 水 / 温
- **10-100 倍单位面积产量**

### 4.3 无人机 + AI

- **大疆 / PrecisionHawk**
- 喷洒 + 监测
- 中国大规模应用

### 4.4 替代蛋白

- **Impossible / Beyond Meat**
- AI 设计植物肉口味
- **精密发酵**

### 4.5 气候智能农业

- 抗旱品种
- **碳汇农业**
- AI 监测 / 验证

---

## 五、AI 改变了农业的什么

### 5.1 效率提升

- 化肥减少 30-50%
- 水减少 20-30%
- 产量提升 10-20%

### 5.2 农民角色

- **从体力 → 数据**
- 新技能（AI 操作）
- 年轻人回流农村？

### 5.3 食品安全

- 溯源 + 早期预警
- 减少**食源性疾病**

### 5.4 环境影响

- 减少污染（化肥 / 农药）
- 保护生物多样性
- **可持续农业**

### 5.5 全球粮食安全

- 发展中国家受益最大
- 但**技术鸿沟**

## 七、一句话总结

> 🎯 **四句话**：
> 1. **AI 是 2050 粮食安全的核心**——精准农业 + 机器人 + 育种 + 供应链。
> 2. **六大应用**：精准 / 病虫害 / 自动农机 / 育种 / 牲畜 / 供应链。
> 3. **方法学**：多光谱遥感 + IoT + 边缘 AI + 育种 ML。
