# 芯片设计 · 早期经典（1940s-2010s）

> 从晶体管到 EDA——芯片设计的演进。

## 一、Shockley 1947——晶体管

**Bell Labs**（Bardeen/Brattain/Shockley）：
- 1947 发明**点接触晶体管**
- **1956 Nobel**
- 开启半导体时代

## 二、Kilby/Noyce 1958-1959——集成电路

- **Jack Kilby**（TI）：1958 混合 IC
- **Robert Noyce**（Fairchild）：1959 平面 IC
- **2000 Nobel**（Kilby）
- 芯片小型化的基础

## 三、Moore 1965——摩尔定律

**Gordon Moore**（Fairchild / Intel）：
- "晶体管密度每 18 个月翻倍"
- 持续 60 年
- **2020s 接近物理极限**

## 四、Mead-Conway 1980——VLSI 设计方法论

**Carver Mead & Lynn Conway**：
- *Introduction to VLSI Systems*
- **芯片设计民主化**
- 芯片设计 = 编程
- 1980 《Scientific American》

## 五、EDA 1980s-

### 5.1 商业 EDA

- **Mentor Graphics**（1981）
- **Cadence**（1988）
- **Synopsys**（1986）

### 5.2 关键算法

- **Placement**：模拟退火 / 力导向
- **Routing**：迷宫 / 拓扑
- **Synthesis**：RTL → 门

### 5.3 工艺节点

```
1980s:  3 μm
1990s:  350 nm
2000s:  90 nm
2010s:  14 nm
2020s:  3 nm
```

## 六、FPGA 1985-

- **Xilinx**（1985）
- 可编程芯片
- AI 加速器的基础

## 七、时间线

```
1947  Shockley 晶体管
1958  Kilby/Noyce IC
1965  Moore 摩尔定律
1980  Mead-Conway VLSI
1985  Xilinx FPGA
1988  Cadence / Synopsys
2010s EDA 成熟
2020s 后摩尔 + AI EDA
```

## 八、博士级练习

1. 读 Moore 1965 原文
2. 了解 Mead-Conway 方法论
3. 分析 EDA 工具演进
