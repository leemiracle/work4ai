# 天文 · 早期经典（1900s-2010s）

> 从 Hubble 到 SDSS——AI 之前的天文学。

## 一、Hubble 1929——宇宙在膨胀

**Edwin Hubble** 发现星系退行速度与距离成正比 → **宇宙膨胀**。

- 改变宇宙学——从静态到膨胀
- 催生**大爆炸模型**
- **暗能量**的伏笔（1998 加速膨胀）

## 二、Cannon 1901-1912——恒星分类

**Annie Jump Cannon**（哈佛天文台女性先驱）：
- OBAFGKM 光谱分类
- 分类 20 万+恒星
- **数据驱动天文学的开端**

## 三、Rubin 1970s——暗物质证据

**Vera Rubin**（女性天文学家）：
- 星系旋转曲线**异常**
- 星系外缘旋转太快——**看不见的物质**
- **暗物质的观测证据**

## 四、COBE 1992——宇宙微波背景

- **COBE 卫星**发现 CMB 各向异性
- 证实大爆炸 + 结构形成
- **2006 Nobel**（Mather/Smoot）

## 五、SDSS 2000+——数字巡天

- **Sloan Digital Sky Survey**
- 数百万星系 / 类星体光谱
- **数据驱动天文学的标准**
- 催生 **astroinformatics**

## 六、LIGO 2015——引力波

- **2015.9**：首次直接检测引力波
- **2017 Nobel**（Weiss/Barish/Thorne）
- 多信使天文学时代

## 七、时间线

```
1901  Cannon 恒星分类
1929  Hubble 宇宙膨胀
1960s Rubin 暗物质
1992  COBE CMB
2000  SDSS 数字巡天
2015  LIGO 引力波
```
