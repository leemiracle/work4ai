# 天文 · 多频段 + 异常检测方法学

> **博士级**：天文 AI 的方法学——为什么天文和一般 ML 不同。

## 一、天文数据的特殊性

### 1.1 数据特征

- **高维**：每像素多频段（光学 + 红外 + 射电）
- **不平衡**：罕见事件（双中子星合并）极稀疏
- **时空序列**：时序数据
- **噪声 + 缺失**：天气 / 仪器

### 1.2 物理先验

- **宇宙学原理**（大尺度均匀）
- **守恒律**（能量 / 角动量）
- **红移**（光谱偏移）

## 二、异常检测（核心方法）

### 2.1 为什么异常检测

天文常找**没见过的**——不能训练监督模型。

### 2.2 主要方法

| 方法 | 用途 |
|---|---|
| **Isolation Forest** | 找异常星系 |
| **Autoencoder** | 重构误差 |
| **Normalizing Flows** | 概率密度 |
| **VAE** | 潜空间 |

### 2.3 主动学习

- AI 给候选，人审核
- **ZTF / LSST** 用此流程

## 三、球面几何

### 3.1 挑战

- 标准 CNN 假设平面图像
- 球面有 **畸变**（极点放大）
- **23 LIGO 探测器网络**

### 3.2 球面 CNN

- **DeepSphere**（Perraudin 2019）
- 六边形网格（HEALPix）
- 等变（旋转）

## 四、模拟器 + 推断

### 4.1 天文模拟

- **Millennium** / **IllustrisTNG**：宇宙演化
- 计算成本：百万 CPU 小时

### 4.2 模拟器替代（Emulator）

**FlowPM**（2020）：用 normalizing flow 加速宇宙大尺度流模拟 1000×。

### 4.3 模拟推断（Simulation-Based Inference, SBI）

- 模型复杂 → 不能写显式似然
- 用模拟 + 神经网络做推断
- **sbi** Python 包
