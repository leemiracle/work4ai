# 00 · AI for Public Health 是什么

>
> **COVID-19** 是分水岭——AI 在疫情预测 / 疫苗开发 / 政策模拟中扮演关键角色。

## 一、公共卫生为什么需要 AI

### 1.1 全球健康挑战

- **疫情**：COVID / 禽流感 / Ebola
- **慢性病**：心血管 / 糖尿病 / 癌症
- **精神健康**：抑郁 / 焦虑（[`讲透AIfor各学科/心理学`](../心理学/)）
- **不平等**：发达国家 vs 发展中国家寿命差 30 年

### 1.2 数据丰富但碎片

- EHR（电子健康记录）
- 流行病学监测
- 基因组 / 蛋白组
- 社交媒体 / 移动数据

### 1.3 因果 + 预测

- 公共卫生**本质因果**：政策 X 降低死亡率吗？
- **观察数据 + 因果 ML**
- 详见 [`讲透因果推断`](../../讲透因果推断/)。

## 二、AI 在公共卫生的六大应用

### 2.1 疫情监测 + 预测

- **早期预警**：社交媒体 + 搜索 + 移动
- **传播模型**：SIR + AI
- **代表**：**HealthMap / BlueDot**（COVID 早期预警）

### 2.2 流行病学

- **病因学**：找疾病风险因素
- **GWAS + ML**（详见 [`讲透AIfor各学科/生物`](../生物/)）
- **队列研究**：AI 加速分析

### 2.3 疫苗开发

- **AlphaFold**（蛋白结构）
- **mRNA 设计**（BioNTech / Moderna 用 AI）
- **COVID 疫苗**：从基因到人体 11 个月（传统 5-10 年）

### 2.4 健康政策模拟

- **多智能体 LLM** 模拟政策效果
- **封锁 / 口罩 / 疫苗** 的优化
- **Imperial College**（COVID 模型影响英国政策）

### 2.5 公共健康干预

- **AI 个性化戒烟 / 减肥**
- **心理健康**（[`讲透AIfor各学科/心理学`](../心理学/)）
- **慢病管理**

### 2.6 全球健康公平

- **AI 远程诊断**（发展中国家）
- **手机健康**（mHealth）
- **资源优化**（疫苗分配）

## 三、公共卫生专属的方法学

### 3.1 流行病学方法

- **队列研究** + AI
- **病例对照** + ML
- **因果推断**（详见 [`讲透因果推断`](../../讲透因果推断/)）

### 3.2 时空分析

- **GIS + AI**：疾病地图
- **Hotspot 检测**
- **迁移 + 扩散模型**

### 3.3 多源数据融合

- EHR + 基因 + 社会 + 环境
- **多模态 AI**
- 隐私挑战（联邦学习）

### 3.4 伦理 + 隐私

- **HIPAA**（美国）/ **GDPR**（欧盟）
- 健康数据极敏感
- **差分隐私 + 联邦学习**

## 四、当前前沿（2024-2026）

### 4.1 COVID 后的反思

- AI 早期预警有效（部分）
- 但**政策响应失败**——技术 ≠ 决策
- **下次疫情准备**？

### 4.2 多模态健康 AI

- **Med-PaLM 2 / GPT-4 Medical**
- 文本 + 影像 + 基因
- 个体化 + 群体化

### 4.3 联邦学习

- **医院间协同训练**
- 数据不出院
- **NVIDIA Clara FL**

### 4.4 健康公平 AI

- 算法偏见检测（种族 / 性别）
- **公平 ML**（fairness ML）
- 政策影响

### 4.5 大流行准备

- **WHO** + AI 早期预警
- **mRNA 平台**：快速响应新病毒
- **AI 设计广谱疫苗**

### 4.6 老龄化 + AI

- **长期照护**：AI 监测
- **老年心理健康**
- **资源分配**

## 五、AI 改变了公共卫生的什么

### 5.1 早期预警能力

- 从"事后"到"事前"
- 全球监测网络

### 5.2 政策科学化

- AI 模拟政策效果
- 决策基于数据
- 但**政治仍主导**（COVID 教训）

### 5.3 个性化公共卫生

- 不是"一刀切"
- 个体风险分层
- **精准干预**

### 5.4 全球合作

- 数据共享 + AI
- 但**地缘政治阻碍**（中美数据壁垒）
