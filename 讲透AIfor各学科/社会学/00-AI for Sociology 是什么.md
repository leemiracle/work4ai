## 一、社会学为什么需要 AI

### 1.1 数据爆炸

- **社交媒体**：Twitter / 微博 / TikTok
- **移动数据**：位置 + 通讯
- **互联网档案**：行为痕迹

### 1.2 复杂系统

- **网络效应**：群体行为非线性
- **文化演化**：长时间尺度
- **社会运动**：突发涌现

### 1.3 LLM 作为"社会模拟器"

- LLM agent 模拟**社会行为**
- **Stanford SmallVille**（2023）：25 agent 小镇
- **新方法论**
