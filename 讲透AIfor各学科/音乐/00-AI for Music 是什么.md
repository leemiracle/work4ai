# 00 · AI for Music 是什么

> **第一性问题**：音乐是**通用的情感语言**。AI 能作曲 / 演奏 / 演唱吗？**Suno / Udio**（2024）让"全民作曲"成为可能——但**AI 音乐算艺术吗**？

## 一、AI 音乐的演进

### 1.1 早期（1950s-2010s）

- **Lejaren Hiller**（1957）：算法作曲
- **David Cope**（1980s）：EMI 模仿巴赫
- **DeepBach**（2017）：DL 巴赫风格

### 1.2 深度学习（2015-2020）

- **WaveNet**（DeepMind 2016）：原始音频生成
- **MuseNet**（OpenAI 2019）：多风格作曲
- **Jukebox**（OpenAI 2020）：歌词 + 旋律

### 1.3 2024 爆发

- **Suno v3**（2024）：完整歌曲生成
- **Udio**（2024）：高质量
- **Stable Audio**
- **ElevenLabs Music**

## 二、AI 音乐技术

### 2.1 符号音乐（MIDI）

- **Music Transformer**（2018）
- **Lakh MIDI Dataset**
- 旋律 + 和声 + 节奏

### 2.2 原始音频（WaveNet / 扩散）

- **WaveNet**：因果空洞卷积
- **EnCodec**（Meta）：音频压缩 + 生成
- **AudioLDM / Stable Audio**：扩散

### 2.3 多模态（歌词 + 音乐）

- **Suno / Udio**：歌词 → 完整歌曲
- **vocal synthesis**
- **stem separation**（分轨）

### 2.4 音乐信息检索（MIR）

- 节拍检测 / 和弦识别
- 流派分类
- **Spotify / Apple Music** 用

### 3.4 音乐治疗

- 个性化治疗音乐
- **心理健康**应用
