# 统计学 · 本质探索——不确定性的科学

> 统计学的本质是什么？AI 时代，统计学被 ML 取代了吗？

## 一、统计学研究什么

### 1.1 核心

统计学 = 研究**不确定性**的科学——从数据推断规律。

### 1.2 两大流派

- **频率派**（Fisher / Neyman）：概率 = 长期频率；p-value / 置信区间
- **贝叶斯派**（Bayes / Laplace）：概率 = 信念度；后验分布

### 1.3 与 ML 的关系

ML 是统计学的**超集**——加了计算 + 算力。但 ML 的核心（学习 = 推断）仍是统计。

> 🎯 **本质**：统计学是**理性的数学框架**——怎么从有限数据做可靠推断。

## 二、AI 改变了统计学吗

### 2.1 从 p-value 到 ML

经典统计：假设检验 / p-value。
ML：预测 / 准确率。

**冲突**：p-value 被滥用（可重复性危机）；ML 不管推断只管预测。

### 2.2 不确定性的处理

经典统计：CI / 后验。
ML：**经常忽略**——只给点估计。

**问题**：AI 不告诉"它不确定什么"。

### 2.3 Conformal Prediction 的回归

- 分布无关的不确定性量化
- 2024 爆发——每个 LLM 都该有
- **经典统计的复兴**

## 三、关键开放问题

### 3.1 深度学习为什么 work

- VC 维 / Rademacher 预言失败
- 双层下降打破 U 曲线
- **理论空白**

### 3.2 p-value 的终结

- 可重复性危机
- 替代方案（Bayes factor / effect size）
- **统计学教育改革**

### 3.3 因果 vs 预测

- 统计学偏因果
- ML 偏预测
- **两者必须统一**

### 3.4 人工智能的"统计"

- LLM 输出的不确定性
- **怎么量化？**
- AI 的"自信"可信吗？

## 四、一句话总结

> 🎯 **统计学的本质是从数据做可靠推断——处理不确定性。ML 让预测更强但忽略不确定性。Conformal Prediction + 因果 ML 是融合方向。博士级训练不只是调参，是反思"我们多不确定"。**
