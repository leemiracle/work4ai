# 00 · AI for Psychology 是什么

> **第一性问题**：心理学研究**人类心智和行为**——AI 是它的**实验对象 + 实验工具 + 理论镜像**。
>
> LLM 像"人类心智的镜子"——它训练于人类语言，**反映人类的偏见、情感、推理偏差**。这让 AI 成为心理学的新工具。
>
> 配套：[`讲透科学的现代性`](../../讲透科学的现代性/) + [`讲透AIfor各学科/哲学`](../哲学/)（心智哲学）

## 一、心理学为什么需要 AI

### 1.1 三重关系

```
心理学 ──研究对象──→ 人类心智
   ↑                  ↑
   │                  │
AI 作为镜像      AI 作为对象
（反映心智）    （AI 有心智吗）
   ↑
   │
AI 作为工具
（分析心理数据）
```

### 1.2 数据爆炸

- **fMRI**：每次扫描 GB 级
- **智能手机 + 可穿戴**：连续生理 / 行为数据
- **社交媒体**：海量行为文本

### 1.3 可重复性危机

- 心理学**最严重的可重复性危机**（详见 [`讲透科学的现代性/02`](../../讲透科学的现代性/02-可重复性危机.md)）
- 70% 经典实验无法重复
- AI 工具：自动化复现 + 检测 p-hacking

## 二、AI 在心理学的六大应用

### 2.1 LLM 作为"心智模型"

**核心思想**：LLM 训练于人类语言，可能反映人类认知。

- **心智理论测试**：LLM 在 ToM benchmark 接近人类（Strudel 2023）
- **认知偏差**：LLM 表现**确认偏差 / 锚定 / 损失厌恶**？
- **大五人格**：给 LLM 大五测试，有"人格"

**意义**：LLM 是**人类心智的退化镜像**——研究 LLM 间接研究人。

### 2.2 神经影像 + AI

- **fMRI 解码**：从脑活动重建图像 / 文字（2023 多篇 *Nature*）
- **脑机接口**：神经信号 → 文字 / 控制（详见 [`讲透AIfor各学科/生物`](../生物/)）
- **诊断**：抑郁 / 焦虑 / 精神分裂的 AI 标志

### 2.3 心理健康 AI

- **聊天机器人治疗师**（Woebot / Wysa / Replika）
- **抑郁 / 焦虑检测**：语音 + 文本 + 行为
- **自杀风险预警**（社交媒体分析）

**争议**：AI 能替代治疗师吗？伦理问题。

### 2.4 行为预测

- 社交媒体预测**情绪 / 行为**
- 推荐 → 成瘾（伦理）
- **选举预测**（详见 [`讲透AIfor各学科/政治学`](../政治学/)）

### 2.5 认知建模

- **ACT-R**（经典认知架构）+ AI
- **神经网络作为认知模型**（McClelland / Rumelhart 传统）
- **LLM 作为语言认知模型**——Fodor vs 连接主义大战的延续

### 2.6 心理学研究自动化

- LLM 自动**文献综述**
- AI 检测 p-hacking / 异常
- **复现研究**自动化

## 三、心理学专属的方法学

### 3.1 实验心理学

- **受试者招募**（Amazon MTurk / Prolific）
- **A/B 测试** + AI 分析
- **预注册**（registered reports）

### 3.2 心理测量学

- **量表设计** + AI 验证
- **项目反应理论**（IRT）+ ML
- **文化差异**：LLM 跨文化

### 3.3 因果推断

- 心理学**本质是因果**
- **AI + 因果 ML**（[`讲透因果推断`](../../讲透因果推断/)）
- 解决观察数据混杂

### 3.4 伦理敏感

- 受试者同意 / 隐私
- **AI 操纵行为**（推荐算法 / 假新闻）
- 严格的伦理审查

## 四、当前前沿（2024-2026）

### 4.1 LLM 心智理论

- **Strudel 2023**：LLM 在 ToM 接近人类
- **Ullman 2023**：LLM 失败于"简单"心理推理
- **争论**：LLM 真有 ToM 还是模式匹配？

### 4.2 fMRI 解码

- **Tang 2023 *Nature***：从 fMRI 重建图像
- **LLM + fMRI**：解码连续语言
- **BCI 突破**（详见 [`讲透AIfor各学科/生物`](../生物/)）

### 4.3 AI 治疗

- **Woebot**（CBT 聊天机器人）
- **Wysa**（心理健康）
- **FDA 批准**：第一个 AI 治疗工具（2024）
- **争议**：替代治疗师？伦理？

### 4.4 心理测量 + AI

- **动态心理评估**（自适应测试）
- LLM 个性化问卷
- **文化适应**（跨文化心理学）

### 4.5 AI 对心理学的影响

- **儿童发展与 AI**（屏幕时间）
- **青少年心理健康**（社交媒体 + AI 推荐）
- **AI 偏见**对心理学研究的影响

## 五、AI 改变了心理学的什么

### 5.1 实验对象扩展

- 不只是人类 → 也研究 LLM
- **比较心理学**：人 vs AI

### 5.2 数据规模

- 实验室 N=100 → 在线 N=10000
- AI 分析海量数据

### 5.3 应用扩展

- 治疗师短缺 → AI 补位
- 早期诊断（抑郁 / 自闭症）

### 5.4 心理学反思

- **AI 操纵行为**：算法责任
- **认知自由**：在 AI 推荐下还有吗？

## 七、一句话总结

> 🎯 **四句话**：
> 1. **AI 是心理学的三重角色**：实验对象 + 工具 + 理论镜像。
> 2. **六大应用**：LLM 心智模型 / 神经影像 / 心理健康 / 行为预测 / 认知建模 / 研究自动化。
> 3. **方法学**：实验 + 测量 + 因果 + 伦理。
> 4. **AI 让心理学可量化**——但伦理风险（操纵 / 读心 / 隐私）**核心**。
