# 哲学 · AI 伦理与治理

> **博士级**：AI 伦理的核心问题 + 治理框架。

## 一、AI 伦理的核心议题

### 1.1 算法公平（Fairness）

**冲突**：多个公平定义互斥
- **个体公平**：相似个体相似对待
- **群体公平**：不同群体相同指标
- **统计**： demographic parity / equal opportunity

**Chouldechova / Kleinberg 不可能性定理**：除非基础率相同，三个定义不可能同时满足。

### 1.2 偏见（Bias）

- **数据偏见**：训练数据反映社会偏见
- **算法偏见**：模型放大
- **部署偏见**：反馈循环

**例**：面部识别对黑人女性准确率低（Buolamwini 2018 *Gender Shades*）

### 1.3 透明度（Transparency）

- **可解释性**：详见 [`讲透可解释性`](../../../讲透可解释性/)
- **披露**：告知用户 AI 使用
- **审计**：算法审查

### 1.4 问责（Accountability）

- **责任归属**：AI 出错谁负责
- **追责机制**
- **法律 + 道德**

### 1.5 自主性（Autonomy）

- **人类决策权**（GDPR 22 条）
- **AI 操纵**（推荐算法）
- **认知自由**
