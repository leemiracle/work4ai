# 经济金融 · 本质探索——市场的本质

> 市场是什么？经济规律是"发现"还是"发明"？AI 能预测经济吗？

## 一、经济学的第一性问题

### 1.1 经济学研究什么

- **稀缺资源的分配**
- **人类行为的聚合**
- **价值的创造 + 交换**

### 1.2 与自然科学的区别

- 经济学**研究人**——人有**意志 + 反思**
- 物理定律不变；经济"定律"**随人的行为变**
- **反射性**（Soros）：人对市场的认识改变市场

### 1.3 经济学的"科学性"争议

- **能否实验**？（部分——RCT）
- **可重复**？（难——历史不重复）
- **可预测**？（极难）

> 🎯 **本质**：经济学是**社会科学**——研究有意志的系统的科学。

## 二、AI 改变了经济学吗

### 2.1 数据爆发

- 交易 / 社交 / 卫星 / 移动
- AI 处理
- **更准的短期预测**

### 2.2 LLM 模拟

- SmallVille 等让经济**可实验**
- 测试政策
- **方法论革命**

### 2.3 但预测极限

- 2008 金融危机没人预测到
- COVID 经济冲击
- **黑天鹅事件**不可预测

> 🎯 **本质问题**：经济是**复杂适应系统**——AI 能模拟但**不能完全预测**。

## 三、关键开放问题

### 3.1 市场有效吗

- **EMH**（有效市场假说）
- 行为金融反驳
- AI 加剧还是缓解？

### 3.2 价值是什么

- 劳动价值论 / 边际效用 / 主观
- AI 创造价值吗？
- **AGI 后的经济学**？

### 3.3 AI + 不平等

- 自动化替代谁？
- **全民基本收入**（UBI）
- 后稀缺经济？

### 3.4 经济学的未来

- AI 让经济学更"硬"？
- 还是更"软"（LLM 模拟）？
- **经济学方法论的革命**

## 四、一句话总结

> 🎯 **经济是复杂适应系统——AI 让数据 + 模拟更强但不可完全预测。AGI 后经济学可能被重写。博士级训练不只是建模，是反思 AI 时代"价值"和"市场"的本质。**
