# 地球气候 · 球面几何 + 多尺度 AI

> **博士级**：地球科学的几何 + 物理约束。

## 一、球面 AI 的数学

### 1.1 球面卷积

标准 CNN 假设平面——地球是球：
- **极点畸变**
- **不同纬度分辨率不同**

### 1.2 解决方案

| 方法 | 思路 |
|---|---|
| **icosahedral grid**（GraphCast）| 20 面体细分 |
| **球谐函数**（Spherical Harmonics）| 频域 |
| **Cube-Sphere** | 6 面展开 |
| **HEALPix** | 天文用 |

### 1.3 GraphCast 的网格

**20 面体**（icosahedron）→ 每面细分：
- 分辨率：~0.25°（25 km）
- 节点：~100 万
- 边：GNN 处理

## 二、物理约束

### 2.1 守恒律

- **质量** / **能量** / **动量**
- GraphCast **emergent** 学到（不显式）

### 2.2 热力学

- **熵增**
- **相变**（水蒸气 ↔ 液态）

### 2.3 边界条件

- 地形
- 海陆
- 植被

## 三、多尺度建模

### 3.1 尺度跨越

```
云（m, s）→ 锋面（km, h）→ 气旋（100km, d）→ 气候（global, yr）
```

经典方法：不同尺度用不同模型。

AI：**统一基础模型**（Aurora / Prithvi）

### 3.2 Scale-Aware 网络

- **Multi-scale GNN**
- **金字塔结构**
- **注意力跨尺度**

## 四、数据同化（Data Assimilation）

### 4.1 问题

将观测融入模型——**数值模型的核心环节**。

经典：**4D-Var / Ensemble Kalman Filter**

### 4.2 AI 数据同化

- **FourDimNet**
- **GraphCast-based DA**
- 加速 100-1000×

## 五、集合预报（Ensemble）

### 5.1 不确定性

- 初始条件不确定
- 模型不确定
- → 多个 forecast（ensemble）

### 5.2 GenCast（扩散集合）

- **扩散模型**生成 ensemble
- 比 ECMWF ENS 更准（97.2%）
- **概率预报**
