# 生物 · AlphaFold 应用生态

> **博士级**：AlphaFold 2/3 之后的应用生态——改变了什么？

## 一、生态全景

```
AlphaFold 2（2020）—— 蛋白质结构
   ↓
AlphaFold Database（2 亿+结构）
   ↓
AlphaFold 3（2024）—— 全生物分子
   ↓
应用生态：
   - 药物发现
   - 疾病机制
   - 合成生物学
   - 进化生物学
   - 教育
```

## 二、关键应用

### 2.1 药物发现

详见 [`化学/advanced/02`](../../化学/advanced/02-AI药物发现工程.md)。

- **靶点结构**：之前未知的蛋白
- **对接**：蛋白-配体
- **结合位点**：自动识别

### 2.2 疾病机制

- **错义突变效应**：AlphaMissense 预测
- **癌症突变**：影响蛋白结构？
- **罕见病**：基因变异

### 2.3 合成生物学

- **从头设计蛋白**：RFdiffusion / Chroma
- **新酶**：催化反应
- **生物材料**：丝蛋白 / 胶原

### 2.4 进化生物学

- **古蛋白重建**：从灭绝物种
- **祖先蛋白**：演化路径
- **进化约束**：保守结构

### 2.5 结构基因组学

- **全蛋白组覆盖**：人类 2 万+ 蛋白
- **复杂体**：蛋白-蛋白相互作用
- **膜蛋白**：以前难的

## 三、AlphaFold 3 的扩展

### 3.1 蛋白-蛋白

- 多聚体（multimer）
- 抗原-抗体

### 3.2 核酸

- DNA / RNA 相互作用
- 核糖体（巨大复合体）

### 3.3 小分子

- 药物结合
- 辅因子

### 3.4 局限

- 动态结构（蛋白质是动态的）
- 无序蛋白（intrinsically disordered）
- 翻译后修饰（糖基化等）

## 四、关键工具

### 4.1 数据库

- **AlphaFold DB**：2 亿+
- **ESM Metagenomic Atlas**：6 亿+ 元基因组
- **PDB**：实验结构

### 4.2 软件

- **ColabFold**：在线 AlphaFold
- **OpenFold**：开源复现
- **ESMFold**：单序列快速版

### 4.3 工具链

- **PyMOL / ChimeraX**：可视化
- **BioPython**：编程接口

## 五、改变的研究范式

### 5.1 结构生物学

- **X 射线晶体学**需求降低（部分）
- **冷冻电镜**与 AlphaFold 互补
- 实验确认 vs 预测

### 5.2 药物开发

- 缩短 5-10 年
- 降低 $1B+ 成本
- **新型药物**（以前无结构靶点）

### 5.3 生物学教育

- 教科书重写
- 学生用 AlphaFold
- **可视化革命**

## 六、限制与挑战

### 6.1 准确度不是 100%

- pLDDT < 70 的不可信
- 无序蛋白全错

### 6.2 动态 vs 静态

- AlphaFold 给一个结构——蛋白是动态的
- 构象系综（ensemble）

### 6.3 复合体挑战

- AlphaFold 2 单链强，多链弱
- AF3 改进，但仍有错

### 6.4 商业化争议

- DeepMind 数据库免费，但商业 API 收费
- 公共资源 vs 私有

## 七、博士级练习

1. 用 ColabFold 预测你感兴趣的蛋白
2. 对比 AF 预测 vs PDB 实验
3. 评估 AF3 在 RNA 上的精度
