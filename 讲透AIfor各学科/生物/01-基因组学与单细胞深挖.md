# 01 · 基因组学与单细胞深挖

> **博士级**：AI 在基因组学 + 单细胞生物学的应用——从 DNA 到 RNA 到蛋白的全链路。

## 一、基因组学的 AI 革命

### 1.1 测序技术

```
一代测序（Sanger, 1977）：~1 kb，$1000+
二代测序（NGS, 2008+）：~100 GB，$100
三代测序（PacBio / Oxford Nanopore, 2015+）：长读长，$500
```

**AI 在每步**：
- Base calling（信号 → 序列）
- 比对（序列 → 参考基因组）
- 变异检测
- 注释

### 1.2 DeepVariant（Google 2018）

- 变异检测的**CNN**
- 从 BAM 到 VCF
- **临床标准**之一

### 1.3 基因组组装

- 长读长 + AI 组装
- **T2T-CHM13**（2022）：第一个完整人类基因组

## 二、基因表达预测

### 2.1 从 DNA 序列预测 RNA

**核心问题**：DNA → 哪些区域被转录？

**Enformer**（DeepMind 2021）：
- Transformer 处理 200 kb 序列
- 预测 ~5000 个基因的表达
- 在多种细胞类型上

### 2.2 表观遗传

- **DeepSEA**（Zhou 2015）：从 DNA 预测染色质状态
- **BPNet**（Avsec 2021）：转录因子结合
- **Borzoi**（2024）：Enformer 改进

### 2.3 剪接预测

- **SpliceAI**（Jaganathan 2019）：CNN 预测剪接位点
- 临床诊断遗传病

## 三、单细胞生物学

### 3.1 单细胞 RNA 测序（scRNA-seq）

- 每个细胞单独测基因表达
- 揭示细胞异质性
- **2015+ 爆发**

### 3.2 关键工具

- **Scanpy**（Wolf 2018）：Python 工具
- **Seurat**（Satija）：R 工具
- **scVI**（Lopez 2018）：变分推断

### 3.3 单细胞基础模型

- **scGPT**（2024）：Transformer for scRNA
- **Geneformer**（Theodoris 2023 *Nature*）
- **CellPLM**（2024）
- **跨任务**：细胞类型 / 批次校正 / 推断

## 四、基因组编辑 + AI

### 4.1 CRISPR 设计

- **DeepCRISPR**（Chuai 2018）：预测效率
- **CRISPRoff**（2021）：可编程沉默
- AI 优化 guide RNA

### 4.2 碱基编辑

- **ABE / CBE**
- AI 预测脱靶
- **Prime Design**（2023）

### 4.3 未来

- **AI 设计基因治疗**
- **CAR-T** 优化
- 个体化医疗
