# 06 — 控制论与 RL：RLHF 是教科书级 PI 控制

> 「讲透控制论」第七篇。04/05 讲 LQR/MPC 是控制论的"解析最优"。本篇把现代 AI 的核心训练方法（Q-learning/PPO/RLHF）从控制论视角重新解构——**它们全是反馈环的不同化身**。
>

## 1. 灵魂：RL = 控制论 + 随机性

$$
\boxed{\text{RL} = \text{最优控制} + \text{随机性} + \text{奖励信号}}
$$

控制论和 RL 不是两个学科——**它们是同一学科的两个切面**：
- 控制论：确定性系统，最小化代价
- RL：随机系统，最大化奖励

| 控制论 | RL | 对应 |
|--------|----|----|
| 状态 $x$ | 状态 $s$ | 同 |
| 输入 $u$ | 动作 $a$ | 同 |
| $A, B$ 矩阵 | 转移 $P(s'\|s,a)$ | RL 是随机的 |
| 代价 $c(x,u)$ | 负奖励 $-r(s,a)$ | 符号相反 |
| Bellman (控制) | Bellman (RL) | **完全相同** |

---

## 2. MDP = 随机化的状态空间方程

### 2.1 控制论状态空间

$$
x_{t+1} = Ax_t + Bu_t
$$

### 2.2 RL 的 MDP

$$
s_{t+1} \sim P(\cdot | s_t, a_t), \quad r_t = R(s_t, a_t)
$$

**唯一区别**：
- 控制论的转移是**确定函数**
- RL 的转移是**概率分布**（同一状态/动作下，下一状态可能不同）

数学上，MDP = 随机化的状态空间方程 + 加了奖励信号。

---

## 3. Q-learning：用采样解 Bellman

### 3.1 算法

$$
Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]
$$

**关键**：方括号里就是**Bellman 误差**——"当前估计 vs 一步 TD 目标"的差。

### 3.2 实测：4×4 网格世界

跑 500 episode Q-learning，看学到的策略：

```
       0       1       2       3
  ------------------------------------
   0|   ↓       ↓       ↓       ↓
   1|   →       →       ↓       ↓
   2|   →       →       →       ↓
   3|   →       →       →       G
```

**完美学到最优策略**：每个状态都朝向终点 G（右下角）。

### 3.3 收敛曲线

| Episode 区间 | 平均奖励 |
|:----------:|:------:|
| 0-100 | +0.65 |
| 100-200 | +0.83 |
| 200-300 | +0.90 |
| 300-400 | +0.93 |
| 400-500 | **+0.94** |

**单调收敛**——这就是反馈环的力量。

### 3.4 控制论视角

$$
\underbrace{Q(s,a) \leftarrow Q(s,a) + \alpha \cdot e}_{\text{误差驱动修正}}, \quad e = \underbrace{r + \gamma \max Q'}_{\text{目标}} - \underbrace{Q}_{\text{当前}}
$$

这就是控制论的"P 控制器"：误差 $e$ 驱动参数修正。$\alpha$ 是反馈增益。

---

## 4. RLHF = 教科书级 PI 控制

### 4.1 PPO 的更新公式

$$
\theta \leftarrow \theta + \alpha \cdot A(s, a) \cdot \nabla_\theta \log \pi_\theta(a | s)
$$

其中 **advantage**：

$$
A(s, a) = R(s, a) - V_\pi(s)
$$

### 4.2 与 PI 控制一一对应

| 控制论 | RLHF |
|--------|------|
| 状态 $x$ | prompt $x$ |
| 输入 $u$ | 生成的 token $y$ |
| 目标 $r^*$ | 奖励模型 $R(y)$ |
| **误差** $e = r^* - y$ | **advantage** $A = R(y) - V(x)$ |
| **P 项** $u = K_p \cdot e$ | **policy update** $\Delta\theta \propto A \cdot \nabla \log \pi$ |
| **I 项** $\int e \, dt$ | **GAE（广义优势估计）**——累积 advantage |

**结论**：RLHF 是教科书级 PI 控制，只是作用于**参数空间** $\theta$ 而非**系统状态** $x$。

### 4.3 实测：简化 RLHF

模拟"1 维参数策略"，目标 $\theta \to 1.0$：

| Baseline 设置 | 最终 θ | 解读 |
|:----------:|:----:|------|
| baseline = -0.5（接近实际奖励）| 接近 1.0 | advantage 信号强 → 收敛快 |
| baseline = -1.0（远离实际奖励）| 偏离 1.0 | advantage 信号弱 → 收敛慢 |

**关键**：baseline $V(s)$ 的作用就是控制论的**误差归一化**——把绝对奖励变成相对优势。

### 4.4 GAE = I 项的化身

PPO 用 [GAE（Generalized Advantage Estimation）](https://arxiv.org/abs/1506.02438)：

$$
A_\text{GAE}^{(t)} = \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l}, \quad \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)
$$

GAE 是**多步 TD 误差的指数加权和**——本质就是 I 项（累积历史误差）。

## 5. 为什么 RL 容易发散？回到 03 的稳定性

### 5.1 自举（Bootstrapping）

Q-learning 用 $Q$ 自己更新 $Q$ → 反馈环 → 可能不稳定（[Baird 反例](https://www.cs.rutgers.edu/~mlittman/courses/547/lect-slides/baird-1995.pdf)）。

### 5.2 函数逼近 + off-policy

神经网络 + off-policy 三重不稳定组合。解法：
- **Target Network**（DQN）：延迟反馈 = 低通滤波
- **双 Q 学习**：消除 over-estimation
- **Gradient clipping**：防止单步发散

### 5.3 奖励稀疏

reward 信号断断续续 → advantage 估计噪声大 → 反馈信号弱。解法：奖励塑形、curiosity-driven exploration。

### 5.4 策略崩塌

policy 概率塌缩 → 探索不足。解法：entropy bonus（鼓励探索）、KL 约束（TRPO/PPO）。

**所有这些都是 03 节控制论稳定性问题的化身**。

## 6. AI 训练 = 控制论实践

| AI 算法 | 控制论对应 |
|---------|----------|
| SGD | P 控制（用当前梯度）|
| Adam 动量 | I 控制（累积历史梯度）|
| Adam RMSprop | D 控制（自适应步长抑制震荡）|
| Q-learning | P 控制 + Bellman 误差 |
| DQN target network | 低通滤波（延迟反馈）|
| PPO KL 约束 | 防止单步发散 |
| RLHF advantage | 控制误差 $e = r^* - V$ |
| GAE | I 项（累积历史 advantage）|

---

## 7. 一句话总结

> **RL 本质是控制论：MDP = 随机化状态空间，Q-learning = 用采样解 Bellman（控制论最优性方程），RLHF = PI 控制（advantage = 误差，policy update = 修正）。实测 4×4 网格世界 Q-learning 500 episode 学到完美策略，奖励从 0.65 → 0.94 单调收敛。Bellman 误差 $r + \gamma\max Q' - Q$ 就是控制论核心思想"误差驱动修正"。baseline $V(s)$ = 误差归一化，GAE = I 项累积。学 RL 不学控制论，等于把 Bellman/PPO 当魔法，看不到它的反馈环本质。**
