# 07 — Agent 的控制论视角：三种范式回到反馈环

> 「讲透控制论」最终篇。本系列前 6 篇讲了控制论的数学和工程。本篇把它**拉回到 Agent**——ReAct / Plan-Execute / Reflexion 这三种 Agent 范式，本质就是开环、MPC、闭环三种控制结构。控制论系列收尾，让 Agent 找到它的"控制论祖先"。
>
> 配套实验：`experiments/07_agent_cybernetics.py`。

---

## 1. 灵魂：三种 Agent 范式 = 三种控制结构

| Agent 范式 | 控制论对应 | 反馈类型 |
|-----------|---------|:------:|
| **ReAct** | **开环控制**（每步独立）| ❌ 无 |
| **Plan-Execute** | **MPC**（先规划后执行）| 弱 |
| **Reflexion** | **闭环 + 记忆**（失败反思）| ✅ 强 |

---

## 2. ReAct = 开环控制

### 2.1 ReAct 的循环

```
Thought → Action → Observation → Thought → Action → ...
```

每步独立决策（基于当前 obs），**没有"误差驱动修正"机制**——下一步不一定修正上一步的错误。

### 2.2 控制论视角

ReAct 等价于**开环控制**：每步根据"当前状态"选动作，但没有"目标 - 当前 = 误差"的反馈环。

**实测**：在累积误差任务上，ReAct 平均误差 10.0，**50% 任务失败**。

### 2.3 失败模式（与开环系统一致）

- 步数多了误差累积（无修正）
- 中间步错了无法回头
- 没有"偏离目标"的检测机制

---

## 3. Plan-Execute = MPC

### 3.1 Plan-Execute 的循环

```
Plan: 一次性生成 N 步计划
Execute: 执行第 1 步 → 观察
Re-plan: 根据 obs 调整后续计划
```

### 3.2 控制论视角

这就是 [05 篇](05-模型预测控制MPC.md) 讲的 **MPC**：
- 用"环境模型"（LLM 内部世界模型）预测未来 N 步
- 优化计划让总代价最低
- **只执行第 1 步，下步重规划**

**实测**：Plan-Execute 平均误差 8.0，1.7% 任务失败——比 ReAct 好，但仍非最优。

### 3.3 与 MPC 的对应

| MPC | Plan-Execute Agent |
|-----|-------------------|
| 环境模型 $f(x,u)$ | LLM 内部世界模型 |
| 预测未来 N 步 | Plan 阶段 |
| 只执行第 1 步 | Execute 第 1 步 |
| 滚动优化 | 失败时重规划 |

---

## 4. Reflexion = 闭环 + 记忆

### 4.1 Reflexion 的循环

```
Episode 1: 跑 ReAct → 失败
Reflector: 反思 → 写教训 → 加入 memory
Episode 2: 跑 ReAct (带 memory) → 改进
...
```

### 4.2 控制论视角

Reflexion 是**闭环 + 记忆**反馈：
- 失败 = 误差 $e$
- 反思 = 误差归因（为什么失败）
- 加入 memory = 累积历史（I 项）
- 下次避免 = 误差驱动修正

**完美对应 PI 控制**：
- P 项：当前 episode 的"实时反馈"（observation）
- I 项：累积的反思 memory（lesson 记忆）

### 4.3 实测：闭环反馈的累积效应

| 范式 | 平均误差 | 最大误差 | 失败率（>10）|
|------|:----:|:----:|:--------:|
| ReAct | 10.03 | 12.43 | **50.0%** |
| Plan-Execute | 8.04 | 10.99 | 1.7% |
| **Reflexion** | **4.16** | **10.35** | **0.3%** |

**Reflexion 学习曲线**：
- 前 50 任务平均误差：高（教训少）
- 后 50 任务平均误差：**改进 16.2%**（教训累积）

这就是 I 控制的**累积效应**——历史反思驱动系统逼近最优。

### 4.4 Reflexion 论文实证

[Shinn et al. 2023](https://arxiv.org/abs/2303.11366)：
- HotPotQA：比 ReAct 提升 22 个百分点
- AlfWorld：比 ReAct 提升 30 个百分点
- 编程任务：从 80% → 91% 通过率

## 5. 三种范式的控制论统一

```
                    ┌─────────────────┐
                    │   控制论视角     │
                    └────────┬────────┘
                             │
        ┌────────────────────┼────────────────────┐
        │                    │                    │
        ▼                    ▼                    ▼
   ┌─────────┐         ┌──────────┐         ┌──────────┐
   │  开环   │         │   MPC    │         │ 闭环+记忆│
   └────┬────┘         └────┬─────┘         └────┬─────┘
        │                   │                    │
        ▼                   ▼                    ▼
   ┌─────────┐         ┌──────────┐         ┌──────────┐
   │ ReAct   │         │Plan-Exec │         │Reflexion │
   └─────────┘         └──────────┘         └──────────┘
   每步独立            先想后做              失败反思
   无反馈              弱反馈                强反馈
   失败率 50%          失败率 1.7%           失败率 0.3%
```

**控制论视角让我们看清楚**：
- ReAct 不是"算法不行"，是"开环结构注定失败"
- Reflexion 不是"魔法反思"，是"I 控制的累积效应"
- 三种范式不是平级的"流派"，是**控制结构的三种升级**

## 6. 反过来：从 Agent 看控制论

控制论的核心洞见"**智能 = 负反馈**"，在 Agent 上的实证：
- ❌ 无反馈（ReAct）：失败率 50%
- ✅ 闭环反馈（Reflexion）：失败率 0.3%

**这就是 Wiener 1948 的 80 年实证**——任何能持续修正自己的系统看起来都"智能"。Agent 不是 AI 的新发明，是控制论的工程化。
