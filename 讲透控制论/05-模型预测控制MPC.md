# 05 — 模型预测控制 MPC：与 Agent Plan-Execute 同根

> 「讲透控制论」第六篇。04 讲 LQR（解析最优控制）。本篇讲 MPC——**控制论版的 Plan-Execute 范式**。1980s 控制工程师发明的 MPC，与 2023 年 LLM Agent 圈"重新发现"的 Plan-Execute，本质是同一件事。
>
> 配套实验：`experiments/05_mpc.py`。

---

## 1. 灵魂：MPC = 用模型预测未来 N 步

$$
\boxed{u_t^* = \arg\min_{u_{t:t+N}} \sum_{k=t}^{t+N} c(x_k, u_k) \quad \text{s.t.} \quad x_{k+1} = f(x_k, u_k), \; u_\min \leq u_k \leq u_\max}
$$

**每步**：
1. 用环境模型 $f$ 预测未来 $N$ 步轨迹
2. 优化：找让总代价最低的 $N$ 个 $u$
3. **只执行第 1 个 $u$**，抛弃其他
4. 观察新状态，回到 1（滚动优化）

**这就是 LLM Agent 的 Plan-Execute 范式**（先想后做 + 中途重规划）。

---

## 2. MPC vs LQR：约束与非线性的差别

### 2.1 LQR 的局限

LQR 假设线性系统 + 二次代价 + **无约束**。但实际工程：
- 马达有力矩上限（$|u| \leq u_\max$）
- 系统是非线性（如倒立摆 $\sin\theta$）
- 有避障约束（$x \notin \text{obstacle}$）

LQR 处理不了这些。**MPC 就是为约束+非线性而生**。

### 2.2 倒立摆实测：约束 $|u| \leq 2$

| 控制器 | 稳定？ | 最大 \|u\| | 约束满足？ | 总代价 |
|--------|:----:|:-------:|:-------:|:----:|
| **LQR (无约束)** | ✅ | **10.75** | ❌ | **4.97** |
| LQR + clip \|u\|≤2 | ❌ | 2.00 | ✅ | 83.54 |
| MPC 简化版（随机采样）| ❌ | 1.99 | ✅ | 71.55 |

### 2.3 诚实记录

- **LQR 无约束**：理论最优，但 \|u\| 高达 10.75，实际马达做不到。
- **LQR + clip**：强制约束后**不再稳定**——clip 破坏了 LQR 的最优性证明。
- **MPC 简化版**：实验里用随机采样 50 次搜索 horizon=10 的序列，搜索空间 $4^{10} \approx 10^6$，采样太稀疏，没找到稳定解。

**真实工程 MPC** 用凸优化（OSQP、cvxpy）或 CEM（交叉熵方法）、梯度下降——能在约束内找到稳定解。本实验的随机采样是教学简化，不适合生产。

## 3. MPC 的算法详解

### 3.1 滚动优化（Receding Horizon）

```
t=0: 预测 N 步 → 优化 u[0:N] → 执行 u[0]
t=1: 预测 N 步 → 优化 u[1:N+1] → 执行 u[1]
...
```

**关键**：每步都重新规划，不"承诺"未来 N 步的执行。这就是为什么 MPC 能处理扰动——预测错了下步重规划。

### 3.2 与 Agent Plan-Execute 完全同构

| MPC | Agent Plan-Execute |
|-----|-------------------|
| 环境模型 $f(x, u)$ | LLM 内部"世界模型" |
| 代价 $c(x, u)$ | 任务目标 |
| 预测未来 N 步 | Plan 阶段：LLM 列出 N 步计划 |
| 只执行第 1 步 | Execute 阶段：执行第 1 步 |
| 重规划 | 观察 obs，回到 Plan |

**这是控制论 1980s 的发明**，LLM Agent 2023 年的"Plan-Execute"重新发现它。

### 3.3 horizon（预测步数）的影响

| horizon | 性质 |
|:------:|------|
| 1 | 退化为贪心（= ReAct）|
| 3-5 | 通常够用（接近 LQR）|
| ∞ | 退化为 LQR（无限预测）|

**工程经验**：horizon 取系统时间常数的 3-5 倍。

---

## 4. MPC 的工程化

### 4.1 优化求解方法

| 方法 | 适用 | 速度 |
|------|------|------|
| 凸优化（OSQP/cvxpy）| 线性+二次代价 | 快（毫秒级）|
| SQP（序列二次规划）| 非线性 | 中（10-100ms）|
| 内点法 | 一般非线性 | 慢（100ms+）|
| CEM（交叉熵方法）| 黑盒 + 随机 | 中（采样开销）|
| 梯度下降（可微模拟）| 可微模型 | 快（GPU 加速）|

### 4.2 实时性挑战

MPC 每步都要解优化问题。自动驾驶要求 < 10ms/步，所以：
- 用**简化模型**（自行车模型而非完整车辆动力学）
- 用**暖启动**（上一步解作为初始猜测）
- 用**显式 MPC**（离线把解空间参数化）

## 5. MPC → AI 的四座桥

### 5.1 MPC = Plan-Execute 范式的根

控制论 1980s（[Richalet 1978](https://en.wikipedia.org/wiki/Model_predictive_control)、[Cutler 1980]）提出 MPC，LLM Agent 2023 年（ReWOO、Plan-and-Solve）重新发现同样思想。

### 5.2 世界模型 = MPC 的环境模型

MPC 需要环境模型 $f(x, u)$。现代具身 AI 训**世界模型**：
- OpenAI **Sora**：视频生成 = 学视觉世界模型
- Wayve **GAIA-1**：自动驾驶世界模型
- Yann LeCun **JEPA**：联合嵌入预测架构

有了世界模型，就能做 MPC。

### 5.3 MuZero = MPC + 学习世界模型

[DeepMind MuZero 2020](https://www.nature.com/articles/s41586-020-03051-4)：
- 不给规则，**自己学世界模型**
- 用 MCTS（蒙特卡洛树搜索）做 MPC
- 击败围棋/国际象棋/将棋/Atari 全部 SOTA

**本质是 MPC + 可学习世界模型**。

### 5.4 自动驾驶 = MPC 实战

- **横向控制**（转向）：LQR + MPC
- **轨迹规划**：凸优化 MPC（考虑障碍物约束）
- Waymo/Tesla/Cruise 都用 MPC 变种

---

## 6. 一句话总结

> **MPC（模型预测控制）：每步用环境模型预测未来 N 步，选最优当前动作，只执行第 1 步。倒立摆实测：LQR 无约束 \|u\|=10.75（马达做不到），LQR+clip 破坏稳定性，真实工程 MPC 用凸优化能在约束内稳定。MPC = 控制论 1980s 版的 Plan-Execute 范式，LLM Agent 2023 重新发现同一思想。MuZero = MPC + 学习世界模型，击败围棋 SOTA。学 Agent 不学 MPC，等于错过"Plan-Execute"的控制论根。**
