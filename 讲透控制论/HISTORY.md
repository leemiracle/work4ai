# 讲透控制论 · 思想史

> **一句话定位**：从瓦特蒸汽机调速器到 2026 年的机器人基础模型，控制系统走了 238 年——但贯穿全程的始终只有一句话：**用误差驱动修正（负反馈）**。这份思想史要回答的不是"谁在何时发明了什么"，而是"为什么某个思想在某个时代被需要、为什么被淘汰、又为什么在 AI 时代复活"。

> **方法论声明**：本文不是年代史（"1868 年 Maxwell 写了论文"），是**思想史**（"为什么 1868 年 Maxwell 要给调速器做数学分析——因为火车事故频发，经验调参不再够用"）。每一段都追问"为什么是此时"。方法论详见 [`../讲透AI历史/00-为什么学AI历史.md`](../讲透AI历史/00-为什么学AI历史.md)。

## 0. 方法论

### 0.1 思想史 > 年代史

控制论的历史比 AI 长得多——如果从 Ktesibios 的水钟浮阀（公元前 270 年）算起，有 2300 年。即便只从 Watt 调速器（1788）算起，也有 238 年。但绝大多数教科书把这段历史压缩成一张时间线：

```
1788  Watt 调速器
1868  Maxwell 分析
1922  Minorsky PID
1932  Nyquist 判据
1948  Wiener《Cybernetics》
1960  Kalman 状态空间 / Kalman 滤波
1956  Pontryagin 最大值原理
1957  Bellman 动态规划
1976  MPC（Richalet）
1981  H∞（Zames）
2020s 控制 + RL / 机器人基础模型
```

**问题**：这张表告诉你"发生了什么"，但不告诉你**为什么此时发生**。

思想史问的问题：

| 问题 | 例子 |
|------|------|
| **为什么此时此地？** | 为什么 Nyquist 1932 在 Bell 实验室做频域分析——而不是在大学？因为长途电话需要反馈放大器，Bell Labs 有最强的工程动机。|
| **为什么被淘汰？** | 为什么经典控制论（传递函数）没被状态空间"杀死"？因为单输入单输出（SISO）系统用频域更直观。|
| **为什么复兴？** | 为什么 2020 年代"控制 + 学习"重新爆发——因为 GPU 让神经网络可以做可微控制器了。|
| **偶然性：如果…？** | 如果 Wiener 1948 没有提出"Cybernetics"这个大词，控制论和 AI 可能不会分家 70 年。|

### 0.2 本文的五条方法论纪律

1. **问"为什么此时"**——每个突破都追问驱动力（工程需求 / 理论瓶颈 / 战争 / 算力）。
2. **路径依赖敏感**——当前的"标准方法"可能是历史偶然（PID 统治工业 95%，不是因为最优，是因为最简单）。
3. **失败与成功同等重要**——被淘汰的方向有教训（Wiener 的大控制论、模糊控制热潮）。
4. **控制论与 AI 的分合**——两者同源（Cybernetics 1948），分家 70 年，现在重新合流。这条线贯穿全文。
5. **警惕术语膨胀**——"MPC"和"Plan-Execute"是同一件事的两个名字；"RL"和"最优控制"共享 Bellman 方程。

### 0.3 与本系列其他章节的关系

```
HISTORY.md（本篇，思想史/时间维度）
    ×
00-07（本系列，原理/深度维度）
    ×

```

**本文提供"为什么是这样"的纵深；00-07 提供"怎么实现"的深度。**

## 1. 前夜：瓦特调速器与 Maxwell 分析（1788–1868）

### 1.1 瓦特调速器：世界上第一个自动控制装置

1788 年，James Watt 和 Matthew Boulton 为蒸汽机设计了一种**离心调速器**（centrifugal governor）：两个旋转的金属球，转速越快，离心力把球推得越开，通过连杆带动阀门关小蒸汽进汽量——转速降低。反之亦然。这是一个**纯机械的负反馈回路**，不需要电、不需要计算。

**思想史追问：为什么是 1788 年？**

不是 Watt 突然天才。离心调速器的原理在风车磨坊里已经用了上百年——磨坊主用它调节磨石间距。Watt 的贡献是把这个已有装置**移植到一个新场景**（蒸汽机）。驱动力是**工业革命的需求**：蒸汽机转速不稳会导致织布机断纱、矿井水泵效率波动——工程痛点催生解决方案。

更早的反馈装置：
- **Ktesibios 浮阀水钟**（~公元前 270 年）：水位恒定 → 流速恒定 → 计时准确。这是人类已知的**第一个反馈控制器**，比 Watt 早 2000 年。
- **古代酒器自动注水**：类似的浮阀原理。

**关键洞察**：反馈控制的思想**不是被发明的，是被反复发现的**。每个时代的人都独立地"发明"了负反馈——浮阀、调速器、恒温器、RLHF。这本身就是"智能 = 负反馈"的千年实证。

### 1.2 调速器的麻烦：hunting（猎行）现象

调速器装上蒸汽机后出现了一个诡异现象：转速**周期性振荡**——快了减速、减过头了又加速、又减过头……来回"猎行"（hunting）。有些火车因此出轨。

原因：纯比例反馈（P 控制）在有时滞的机械系统里天然容易振荡。但 19 世纪的工程师不知道这些——他们靠试错（加重/减轻飞球、调整连杆比），没有一个**预测性理论**来告诉你"什么样的调速器会振荡"。

### 1.3 Maxwell 1868：反馈控制的数学诞生

1868 年，James Clerk Maxwell（就是写 Maxwell 方程组的那个 Maxwell）发表了 *On Governors*——**第一篇用微分方程分析反馈稳定性的论文**。

Maxwell 的洞见：把调速器**线性化**（在小偏差附近近似为线性系统），写成微分方程，然后分析特征方程的根。如果根的实部全为负，系统稳定——不会 hunting。

这开创了一条路线：**稳定性 = 特征根的实部为负**。后续 Routh（1877）和 Hurwitz（1895）分别给出了不需要解出根就能判断的方法——Routh-Hurwitz 判据，至今是控制论教材第一章的内容。

**思想史追问：为什么是 Maxwell，而不是工程师？**

Maxwell 不是搞蒸汽机的——他是物理学家。他做这件事的动机是**数学好奇心**：他注意到"调速器 hunting"本质上是一个动力学问题，可以用他熟悉的微分方程工具来分析。这揭示了控制论史上的一个反复出现的模式：**重大的理论飞跃往往来自"局外人"用新工具看老问题**——Maxwell 用微分方程看调速器，Wiener 用统计信号看火炮，Kalman 用线性代数看控制系统。

### 1.4 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 反馈可以自动调节，但可能振荡 |
| **数学工具** | 微分方程、线性化、特征根 |
| **驱动力** | 工业革命（蒸汽机、火车、工厂） |
| **局限** | 只能分析，不能系统设计——"怎么调参数"仍靠试错 |

## 2. PID 与频域：Minorsky → Nyquist → Bode（1922–1945）

### 2.1 Minorsky 1922：PID 的诞生

1922 年，俄裔美国工程师 Nicolas Minorsky 在美国海军研究**自动操舵系统**。他观察有经验的舵手怎么操舵，总结出三条规则：

1. **当前偏差大 → 大幅打舵**（比例，P）
2. **偏差一直存在 → 越来越用力**（积分，I）
3. **偏差在快速变化 → 提前打舵**（微分，D）

这就是 PID 控制的三件套。Minorsky 在 USS New Mexico 号上做了实验，验证了自动操舵的可行性。

$$
u(t) = K_p e(t) + K_i \int_0^t e(\tau)\,d\tau + K_d \frac{de(t)}{dt}
$$

**思想史追问：为什么 PID 这么"朴素"的方案统治了工业 95%？**

不是因为 PID 最优。LQR、MPC、H∞ 都比 PID "更优"。PID 统治的原因是：

1. **模型无关**——PID 不需要知道被控对象的精确数学模型，靠整定（调 $K_p, K_i, K_d$）就能工作。这在 1922 年是革命性的，在 2026 年仍然是巨大优势（很多工业系统至今没有好模型）。
2. **可解释性**——三个参数各有清晰的物理意义（当前/历史/未来），工程师能凭直觉调。
3. **鲁棒性**——PID 对模型失配不敏感，这在不确定环境里至关重要。

**反常识**：控制论发展了 240 年，产生了状态空间、最优控制、MPC、鲁棒控制……但工业界 95% 的控制器仍然是 PID。**理论进步和工程采用之间存在巨大的滞后和鸿沟**——这不是理论界的失败，是 PID 恰好"够用"。

### 2.2 Black 1927：负反馈放大器

1927 年，Harold Black 在曼哈顿渡船上（据说写在《纽约时报》上）想出了**负反馈放大器**——用反馈降低放大器失真。这是 Bell 实验室为长途电话开发的核心技术。

Black 的洞见：开环放大器有非线性失真；但如果你**故意放大很多倍，再用反馈砍回来**，失真也被砍回来了。代价是降低了增益，但换来了线性度。

**这直接催生了 Nyquist 和 Bode 的理论**——因为现在需要回答："什么样的反馈会不稳定？"

### 2.3 Nyquist 1932：频域稳定性判据

Harry Nyquist（Bell Labs）1932 年发表 *Regeneration Theory*——**频域稳定性判据**。

核心思想：不需要解微分方程、不需要算特征根——只需要**开环频率响应**（给系统输入不同频率的正弦波，画出输出幅相曲线），就能判断闭环系统是否稳定。

Nyquist 判据：如果开环传递函数的 Nyquist 图（极坐标频率响应）逆时针包围 $(-1, j0)$ 点的圈数等于右半平面极点数，则闭环稳定。

**思想史追问：为什么是 Bell Labs？为什么 1932？**

因为长途电话。1930 年代 AT&T 要铺设横跨美洲的电话线，需要成百上千级放大器级联——每级放大器引入失真和噪声，级联后灾难性。Black 的负反馈放大器解决了失真，但反馈可能振荡——Nyquist 的判据告诉你"反馈多深才安全"。

**这是控制论史上最重要的路径依赖之一**：频域方法不是从蒸汽机或航空发展出来的——它从**电话工程**发展出来。如果没有 Bell Labs 的长途电话需求，Nyquist/Bode 的频域工具可能晚 20 年出现，状态空间方法可能更早成为主流。

### 2.4 Bode 1940：频域设计工具

Hendrik Bode（Bell Labs）进一步发展了频域方法：

- **Bode 图**：幅频和相频曲线，用对数坐标画，直观显示系统的增益裕度和相位裕度。
- **Bode 定理**：增益和相位之间的积分约束——你不可能同时获得高增益带宽和好的相位裕度（这对控制工程师是"物理定律"级的约束）。

Bode 1945 年的著作 *Network Analysis and Feedback Amplifier Design* 成为经典控制论（Classical Control）的圣经。

### 2.5 二战：伺服机构的爆发

二战是控制论的**第一次大规模爆发期**：

- **雷达跟踪**：雷达天线要持续追踪移动目标
- **火炮瞄准**：维纳和 Bigelow 研究的防空火炮预测
- **伺服机构**（servomechanism）：被控对象位置/速度的精确控制

MIT 的 Servomechanisms Laboratory、英国 TRE、德国 Askania 都在做相关研究。战争催生了：

1. **大量工程实践**——成千上万的伺服系统被设计、测试、部署
2. **统一术语**——"servo"、"feedback"、"transfer function" 成为标准词汇
3. **跨学科合作**——电机工程师、数学家、物理学家、生理学家开始对话

这种跨学科对话直接孕育了 1948 年的 Cybernetics。

### 2.6 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 用频域分析稳定性；PID 提供工程标准 |
| **数学工具** | Laplace 变换、传递函数、频率响应、Nyquist/Bode 图 |
| **驱动力** | 长途电话（Bell Labs）→ 二战伺服/雷达/火炮 |
| **局限** | 只适用于 SISO 线性时不变系统；MIMO 无能为力 |

## 3. 第一次范式转移：Wiener 控制论（1948）

### 3.1 Wiener 的雄心：统一科学

1948 年，Norbert Wiener 出版 *Cybernetics: Or Control and Communication in the Animal and the Machine*。书名来自希腊语 *κυβερνήτης*（舵手）——和"governor"（调速器）同源。

Wiener 的核心论点：

> **动物和机器中的控制和通信遵循相同的原理：负反馈。**

这不是一个技术细节——这是一个**世界观**。Wiener 想建立一门统一科学，涵盖：
- 工程控制（伺服机构、火炮瞄准）
- 神经科学（反射弧 = 反馈环）
- 社会学（组织 = 反馈网络）
- 计算机科学（计算 = 反馈修正）

他在书里大量讨论了 Wiener 滤波（从噪声中估计信号）、反馈的生理学基础（小脑损伤导致运动振荡 = 失去反馈）、以及"信息"的概念。

### 3.2 思想史追问：为什么是 1948？

1. **二战遗产**：战争迫使工程师和科学家跨学科合作——Wiener 本人就和生理学家 Arturo Rosenblueth 合作研究反馈的生理学基础。
2. **技术成熟**：反馈放大器（Black）、雷达跟踪、火炮预测都验证了反馈的威力。
3. **信息概念萌芽**：Wiener 和 Shannon 交流频繁，两人都在思考"信息"的本质。
4. **跨学科时代精神**：战后科学家希望打破学科壁垒（von Bertalanffy 的一般系统论、Wiener 的控制论、Shannon 的信息论都在 1948 前后）。

### 3.3 Cybernetics 的分崩离析

Wiener 的宏大愿景**部分成功、部分失败**：

**成功**：Cybernetics 成为一个全球性的学术运动。1949 年的 Macy Conference 汇聚了 Wiener、von Neumann、Shannon、Bateson、Mead、Bigelow——跨学科的阵容空前。

**失败**：Cybernetics 作为统一科学没有存活下来。它**分裂**成了若干独立学科：

| Cybernetics 子领域 | 独立后成为 |
|-------------------|-----------|
| 工程控制 | 控制理论（Control Theory） |
| 信号处理/通信 | 信息论（Shannon）、信号处理 |
| 计算/自动推理 | 计算机科学（CS）、AI |
| 生物反馈 | 系统生物学、神经科学 |
| 社会反馈 | 系统论、社会控制论 |

**每个学科都继承了 Cybernetics 的一块碎片，但没有一个学科继承了 Wiener 的统一愿景。** 今天，控制理论家不读 Wiener，AI 研究者不读控制论——但 Wiener 想说的是：**它们是同一件事**。

### 3.4 Shannon 1948：信息论的平行诞生

Claude Shannon 同年发表 *A Mathematical Theory of Communication*——信息论。Shannon 和 Wiener 有密切交流（Wiener 甚至声称 Shannon 的部分想法来自他），但两人走了不同的路：

- **Wiener**：关注**控制**（反馈、因果、时序）——"信号是有意义的时间序列"
- **Shannon**：关注**传输**（编码、压缩、容量）——"信息源是概率分布"

Shannon 的框架更"干净"（可以公理化），最终在通信领域胜出。Wiener 的框架更"丰富"（包含因果和反馈），但对纯数学家不够优雅。这个分裂深刻影响了后来的发展——**信息论有定理，控制论有工程**。

### 3.5 反常识：Wiener 被自己的领域遗忘了

> **控制论教科书不教 Wiener。** 本科控制理论课从 PID 讲到状态空间，几乎不提 *Cybernetics* 这本书。Wiener 被当成一个"历史注脚"——一个有远见但不够数学化的先驱。

这是胜利者叙事的典型案例。Wiener 的核心思想（反馈 = 智能）在 1948 年是革命性的，但后来被**拆解**进了各个学科，以至于每个学科都觉得这是"自己的"常识，忘了来源。

> **2022 年 RLHF 的成功，本质上是 Wiener 1948 年那句话（智能 = 负反馈）的回声。** 但今天做 RLHF 的研究者，有几个读过 *Cybernetics*？

### 3.6 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 负反馈 = 动物和机器的统一原理 |
| **数学工具** | Wiener 滤波、平稳过程、相关函数 |
| **驱动力** | 二战跨学科遗产 + 统一科学的雄心 |
| **遗产** | 分裂成控制论/信息论/CS/AI/生物控制论——统一愿景丧失 |

## 4. 第二次范式转移：状态空间 + Kalman（1957–1965）

### 4.1 经典控制的瓶颈

到 1950 年代，经典控制（传递函数 + Nyquist/Bode）非常成功，但遇到了瓶颈：

1. **只处理 SISO**（单输入单输出）。但航空航天系统是多输入多输出（MIMO）的——火箭有多个推力器，姿态有 6 个自由度。
2. **只处理线性时不变系统**。但导弹的飞行包线跨度极大，参数随高度/速度剧烈变化。
3. **时域行为不透明**。传递函数在频域好看，但"系统在第 3.7 秒的状态是什么"很难直接读出。

1957 年 Sputnik 升空——太空竞赛开始。NASA 需要控制火箭、卫星、登月舱，这些系统的复杂度远超经典控制的处理能力。**需求倒逼理论**。

### 4.2 Kalman 1960：状态空间革命

Rudolf E. Kálmán 在 1960 年前后发表了三篇划时代论文：

1. **"Contributions to the Theory of Optimal Control"**（1960）——状态空间描述 + LQR
2. **"A New Approach to Linear Filtering and Prediction Problems"**（1960）——**Kalman 滤波**
3. **与 Bucy 合作**——连续时间版（Kalman-Bucy 滤波）

Kalman 的贡献是**范式级的**：

- **状态空间描述**：用 $\dot{x} = Ax + Bu, \; y = Cx + Du$ 描述系统。状态 $x$ 是系统的完整内部描述，时域行为一目了然。
- **能控性/能观性**：Kalman 定义了"系统能不能被控制"（controllability）和"内部状态能不能从输出推断"（observability）——这是经典控制没有的概念。
- **LQR**（Linear Quadratic Regulator）：线性系统 + 二次代价 → 最优控制有**闭式解**（Riccati 方程）。详见 [`04-最优控制.md`](04-最优控制.md)。
- **Kalman 滤波**：线性系统 + 高斯噪声 → 状态估计有**最优解**。这是信号估计的黄金标准，从阿波罗登月到 GPS 到自动驾驶都在用。

### 4.3 分离原理（Separation Principle）

Kalman 学派最优雅的结果之一：**最优控制（LQR）和最优估计（Kalman 滤波）可以分开设计，组合后仍最优**。

```
传感器 → [Kalman 滤波] → 状态估计 x̂ → [LQR 反馈 u=-Kx̂] → 执行器
```

这就是 **LQG**（Linear Quadratic Gaussian）控制——"估计和控制分离"，使设计大大简化。

### 4.4 思想史追问：为什么状态空间是"范式转移"（库恩意义）？

用库恩的框架看经典控制 → 现代控制的转移：

| 库恩要素 | 经典控制（旧范式） | 现代控制（新范式） |
|---------|------------------|------------------|
| **世界观** | 系统是输入-输出映射（传递函数） | 系统是内部状态演化（状态空间） |
| **数学工具** | Laplace 变换、频域 | 线性代数、矩阵、微分方程 |
| **典型问题** | SISO 稳定性 | MIMO 能控性/能观性/最优性 |
| **不可通约性** | "增益裕度"在状态空间里没直接对应 | "能控性"在频域里没直接对应 |

**但关键**：经典控制**没有被杀死**。今天工业界仍然大量用 Bode 图、Nyquist 判据、PID。状态空间在航空航天/机器人/过程控制中占主流，但两者**共存**。

**反常识**：范式转移不是"新杀旧"，而是"新开辟新领地"。状态空间没有取代频域——它**开辟了频域到不了的地方**（MIMO、最优、时变）。旧范式在它擅长的领域仍然活着。这与 AI 史上的"符号主义没死"（Neurosymbolic 复活）是同一个模式。

### 4.5 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 系统有内部状态；控制和估计可分离；最优有闭式解 |
| **数学工具** | 线性代数、矩阵论、Riccati 方程 |
| **驱动力** | 太空竞赛（Sputnik → Apollo）+ 计算机使矩阵运算可行 |
| **局限** | 假设线性+高斯；实际系统多非线性非高斯 |

## 5. 最优控制：Pontryagin 与 Bellman（1956–1960）

### 5.1 两个独立发现

最优控制理论在冷战两端几乎同时、独立地诞生：

**苏联——Pontryagin 最大值原理（1956）**

Lev Pontryagin（苏联数学家，盲人）提出了**最大值原理**（Pontryagin's Maximum Principle）——连续时间最优控制的**必要条件**。它告诉你：最优控制轨迹必须满足一组伴随微分方程（Hamilton 正则方程的形式）。

最大值原理的美在于：它把"在无穷多控制序列中找最优"变成"解一组微分方程"——虽然方程可能很难解，但至少有解析结构。

**美国——Bellman 动态规划（1957）**

Richard Bellman 提出**动态规划**和**最优性原理**：

> 最优路径的任意子段都是最优的。

由此推出 **Hamilton-Jacobi-Bellman（HJB）方程**——连续时间最优控制的**充分必要条件**。Bellman 的框架是离散时间友好的（$\to$ 这直接催生了强化学习）。

### 5.2 两者的关系

| | Pontryagin 最大值原理 | Bellman 动态规划 |
|---|---|---|
| **时间** | 连续 | 离散（也可连续 → HJB） |
| **性质** | 必要条件 | 充分必要条件 |
| **求解方式** | 解伴随 ODE（打靶法） | 解 HJB PDE / 值迭代 |
| **后世影响** | 航空航天轨迹优化 | **强化学习**（$Q$-learning, Bellman 方程） |

**关键**：Bellman 方程 $V(s) = \max_a [r(s,a) + \gamma V(s')]$ 就是动态规划在随机环境下的推广。**强化学习的数学根在这里**——不是在心理学，不是在神经科学，是在 1957 年的最优控制。

### 5.3 思想史追问：为什么冷战两端同时发现？

1. **共同需求**：航空航天。卫星轨道、洲际导弹、登月都需要"省燃料的最优轨迹"。
2. **数学传统不同**：苏联数学偏分析（Pontryagin 的变分法传统）；美国偏计算（Bellman 的递归思维）。
3. **信息隔离**：冷战使两边不知道对方在做什么——独立发现是必然的。

### 5.4 LQR = 最优控制的闭式解

对于**线性系统 + 二次代价**（LQ），最优控制有**闭式解**——这就是 LQR（§4.2）。这是最优控制理论中最美、最实用的结果。详见 [`04-最优控制.md`](04-最优控制.md)。

**但 LQR 假设线性 + 二次 + 无约束**。现实中系统是非线性的、约束是硬的（马达力矩有上限）、代价不是二次的——LQR 够不着这些。这就是 MPC 的动机。

### 5.5 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 最优控制有数学结构（必要/充分条件） |
| **数学工具** | 变分法、Hamilton 系统、HJB 方程 |
| **驱动力** | 太空竞赛（省燃料 = 省重量 = 能上天） |
| **关键遗产** | Bellman 方程 → 30 年后变成强化学习的根 |

## 6. MPC：模型预测控制（1976–）

### 6.1 从石油化工厂出发

MPC（Model Predictive Control）的起源和太空竞赛无关——它来自**石油化工厂**。

1970 年代，Shell Oil 和其他石化企业面临一个难题：精馏塔、裂解炉等化工过程有**硬约束**（温度不能超限、压力有安全上限）且高度**耦合多变量**。PID 和 LQR 都处理不了约束。

1976 年，Jacques Richalet 等人提出 **IDCOM**（Identification and Command）——用过程模型预测未来行为，在约束下优化控制序列。1980 年，Cutler 和 Ramaker 在 Shell Oil 提出 **DMC**（Dynamic Matrix Control）——更实用的版本。

$$
u_t^* = \arg\min_{u_{t:t+N}} \sum_{k=t}^{t+N} c(x_k, u_k) \quad \text{s.t.} \quad x_{k+1} = f(x_k, u_k), \; u_{\min} \leq u_k \leq u_{\max}
$$

每步：预测 N 步 → 优化 N 步 → **只执行第 1 步** → 重新观测 → 滚动重复。详见 [`05-模型预测控制MPC.md`](05-模型预测控制MPC.md)。

### 6.2 思想史追问：为什么 MPC 诞生在工厂而不是大学？

1. **工业痛点**：石化行业每年因控制不好损失数百万美元——他们有**最强的经济动机**搞创新。
2. **大学不在意**：1970-80 年代，控制理论学术界的主流是"漂亮的数学"（H∞ 正在酝酿），"解约束优化"被认为不够优雅。
3. **计算限制**：MPC 每步要解一个优化问题——1970 年代算力勉强够化工厂用（采样间隔分钟级），但做不了快速系统（毫秒级）。

**反常识**：MPC 是控制论史上罕见的**"自下而上"发明**——从工厂实践中长出来，后来才被理论界接纳和严格化。大多数控制理论是自上而下的（理论先 → 应用后），MPC 反过来。

### 6.3 MPC 与 Agent Plan-Execute 的同构

2023 年，LLM Agent 圈"发明"了 Plan-Execute 范式：先让 LLM 列计划，执行第 1 步，观察结果，重新规划。

**这和 MPC 一模一样。**

| MPC（1980） | Agent Plan-Execute（2023） |
|-------------|--------------------------|
| 环境模型 $f(x,u)$ | LLM 内部"世界模型" |
| 代价函数 $c(x,u)$ | 任务目标 |
| 预测 N 步 | LLM 生成 N 步计划 |
| 只执行第 1 步 | 执行第 1 步 |
| 滚动重规划 | 观察后重新规划 |

控制工程师 1980 年就发明的东西，AI 圈 40 年后重新发现。**这不是"AI 的胜利"——这是控制论的回归。**

### 6.4 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 用模型滚动预测 + 约束优化 |
| **数学工具** | 凸优化（QP/NLP）、滚动时域 |
| **驱动力** | 石化工业（约束 + 多变量 + 经济代价） |
| **关键遗产** | 与 Agent Plan-Execute 同构——控制论的 AI 化 |

## 7. 鲁棒控制：H∞（1981–）

### 7.1 最优 ≠ 鲁棒：LQG 的翻车

1980 年代有个震惊控制论界的事件：**Doyle 证明 LQG 可以任意不鲁棒**。

LQG（§4.3）看起来很完美——最优控制 + 最优估计，分离原理优雅。但 John Doyle 1978 年证明：存在系统，LQG 设计的控制器使闭环**名义上最优**，但**对无穷小的模型误差都不稳定**。

换句话说：**你把模型精确到小数点后 100 位，LQG 还是可能因为第 101 位的误差而崩溃。**

这击碎了"最优 = 最好"的幻象。**最优是在你的模型上的最优——如果你的模型错了呢？**

### 7.2 Zames 1981：H∞ 控制

George Zames 1981 年提出 **H∞ 最优控制**——不是最小化代价的期望（像 LQG），而是**最小化最坏情况的增益**。

$$
\min_K \|F_l(P, K)\|_\infty
$$

其中 $\|\cdot\|_\infty$ 是系统的 H∞ 范数（传递函数奇异值的上确界）。直觉：**假设扰动是"最恶意的对手"**，设计控制器使其影响最小。

H∞ 把控制问题变成了**博弈问题**——控制器 vs 最坏扰动。这与 `欺骗动力学视角`（§后文）直接相关：**鲁棒控制 = 假设测量信道里有诈**。

### 7.3 后续：μ 综合、滑模、鲁棒 PID

- **Doyle 的 μ 综合**（1982）：处理结构不确定性（不只是最坏情况，而是特定结构的扰动）。
- **滑模控制**（Utkin 1977）：让系统沿设计面"滑动"，对匹配扰动完全免疫——最极端的鲁棒设计。
- **鲁棒 PID**：在 PID 基础上加鲁棒整定（保证增益/相位裕度）。

### 7.4 思想史追问：为什么鲁棒控制是"反最优"的？

这是一个深刻的思想转变：

- **LQR/LQG 范式**："我知道模型，找最优解。" → **乐观主义**
- **H∞ 范式**："我不知道模型有多错，假设最坏。" → **悲观主义/对抗主义**

这与 AI 安全的思路惊人一致：RLHF 的 reward hacking 就是"策略在欺骗奖励模型"——H∞ 的"假设信道有诈"是对此最早的形式化。详见 [`00-为什么需要控制论.md`](00-为什么需要控制论.md) §欺骗动力学视角。

### 7.5 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 最优不等于鲁棒；假设最坏扰动 |
| **数学工具** | H∞ 范数、博弈论、线性矩阵不等式（LMI） |
| **驱动力** | LQG 不鲁棒的发现 + 航空航天对安全性的需求 |
| **关键遗产** | 控制 = 博弈 vs 最坏扰动 → AI 安全的数学根 |

## 8. 第三次范式转移：自适应与学习（1970s–2010s）

### 8.1 自适应控制：控制器自己调自己

当被控对象**参数未知或随时间变化**时，固定参数的控制器（PID/LQR/H∞）都不够好。自适应控制的思路：**在线估计系统参数，自动调整控制器**。

- **MIT 规则**（Whitaker 1958）：最早的自适应方案——梯度下降调整控制器增益使误差最小。
- **模型参考自适应控制**（MRAC）：定义一个"理想模型"，调整控制器使实际系统行为趋近理想模型。
- **自校正调节器**（Åström & Wittenmark 1973）：在线辨识系统参数 → 用估计参数设计 LQR/min-variance 控制器 → 循环。

自适应控制在 1970-80 年代很热，但遇到了**稳定性难题**：自适应闭环是非线性的（参数在变 + 控制器在变），经典稳定性工具不直接适用。直到 1980 年代才有严格的稳定性证明（Narendra, Goodwin 等人）。

### 8.2 模糊控制：日本的狂热

1980-90 年代，日本掀起了一股**模糊控制**热潮。模糊逻辑用"如果温度有点高，就稍微减少加热"这样的语言规则替代精确数学——不需要模型，专家知识直接编码。

典型成功：Sendai 地铁（1987）用模糊控制实现极其平稳的自动驾驶——比人类司机还平稳。模糊洗衣机、模糊电饭煲成为日本家电卖点。

**但热潮退去**：模糊控制缺乏严格理论——什么时候稳定？什么时候最优？没有好的回答。随着严格的自适应控制和后来的人工智能方法成熟，模糊控制逐渐退回特定利基（消费电子、工业过程）。

**反常识**：模糊控制不是"失败"——它在不需要严格保证的场景里至今有用（洗衣机、空调）。但它在学术界的"革命"叙事**失败了**——人们发现模糊逻辑的数学结构可以用常规方法（增益调度、插值）完全解释，不需要"模糊"这个框架。

### 8.3 神经网络控制：早期尝试

1990 年代，随着神经网络（反向传播 1986 复活）的发展，研究者尝试用神经网络做控制器：

- **神经网络做系统辨识**：用 NN 拟合 $f(x,u)$
- **神经网络做控制器**：用 NN 拟合控制策略 $u = \pi(x)$
- **强化学习控制**：用 TD-learning（Sutton 1988）训练 NN 控制器

早期结果有限——NN 控制器没有稳定性保证，训练不稳定，泛化差。但**种子已经种下**：20 年后 GPU 让 NN 变大变强，这些早期框架变成了深度强化学习。

### 8.4 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 控制器应该适应/学习，而不是固定不变 |
| **数学工具** | 在线辨识、MRAC、模糊集、神经网络 |
| **驱动力** | 未知/时变系统 + 神经网络复兴 |
| **关键遗产** | "控制器 = 可学习策略"的种子 → 深度 RL |

## 9. 第四次范式转移：控制 + RL / 机器人基础模型（2013–2026）

### 9.1 深度强化学习：Bellman 的复活

2013 年，DeepMind 发表 DQN（Deep Q-Network）——用深度神经网络近似 $Q$ 函数，在 Atari 游戏上达到人类水平。2016 年 AlphaGo 击败李世石。

**关键**：DQN 的核心是 **Bellman 方程**——1957 年 Bellman 在最优控制里提出的。

$$
Q(s,a) = r(s,a) + \gamma \max_{a'} Q(s', a')
$$

**强化学习不是新东西**——它是 Bellman 1957 动态规划的随机推广。Sutton 1988 的 TD-learning、Watkins 1989 的 Q-learning 都是 Bellman 方程的近似求解。深度学习只是给了它一个**足够强的函数近似器**（神经网络）。

**思想史洞察**：RL 和控制论共享 Bellman 方程——它们是同源的两个分支。控制论假设模型已知（model-based），RL 假设模型未知（model-free，靠试错学）。**控制论 ⊂ RL**——控制论是 RL 去掉探索和延迟奖励的特例。详见 [`00-为什么需要控制论.md`](00-为什么需要控制论.md) §RL 视角 和 [`06-控制论与RL.md`](06-控制论与RL.md)。

### 9.2 RLHF：控制论回归台前

2022 年 ChatGPT 用 RLHF 让 LLM "听话"。RLHF 的核心循环：

```
LLM 输出 → 奖励模型评分 → advantage = 评分 - baseline → PPO 更新策略 → LLM 变好
```

这是教科书级**PI 控制**：误差 = advantage = $r - r_{\text{baseline}}$，参数更新正比于误差。

详见 [`06-控制论与RL.md`](06-控制论与RL.md) 和 [`00-为什么需要控制论.md`](00-为什么需要控制论.md) §6.1。

**Wiener 1948 那句话——智能 = 负反馈——在 2022 年回来了。** 做 RLHF 的人大多不知道自己在做 PID，但他们确实在做。

### 9.3 机器人基础模型：2022–2026 的新前沿

2022–2026 年，控制论正在经历**第四次范式转移**：从"为每个机器人单独设计控制器"到"训练一个通用基础模型控制所有机器人"。

**里程碑**：

| 年份 | 模型 | 团队 | 核心创新 |
|------|------|------|---------|
| 2022 | RT-1 | Google DeepMind | Transformer 做机器人控制，大规模真实数据训练 |
| 2023 | RT-2 | Google DeepMind | VLM（视觉-语言模型）→ VLA（视觉-语言-动作），语义理解 + 动作生成 |
| 2023 | Open-X-Embodiment | 21 个机构 | 跨机构/跨机器人形态的统一数据集 |
| 2024 | Octo | UC Berkeley | 开源通用机器人策略 |
| 2024 | π0 | Physical Intelligence | Flow matching 做动作生成；通用泛化 |
| 2024-25 | π0.5 | Physical Intelligence | 在线微调 + 推理时计算 |
| 2024 | Diffusion Policy | 多个团队 | 扩散模型生成动作序列 |

**核心思想转变**：

- **旧范式**（1948-2020）：为每个系统设计/学习一个专用控制器（PID for 温度、LQR for 倒立摆、MPC for 化工）。
- **新范式**（2022-）：用海量跨场景数据训练一个**通用策略网络** $\pi_\theta(\text{视觉}, \text{语言}) \to \text{动作}$，像 LLM 一样 zero-shot 泛化到新任务。

**这和 LLM 的发展路径一模一样**：从 task-specific 模型（BERT for 分类、GPT for 生成）到 foundation model（一个 GPT-4 做所有事）。机器人控制正在走同一条路。

### 9.4 但控制论的核心约束没变

机器人基础模型很酷，但控制论的**老问题**仍然在：

1. **稳定性**：神经网络策略没有李雅普诺夫稳定性保证——它可能在训练分布外发散（OOD）。
2. **安全性**：机器人不能像 LLM 那样"幻觉"——幻觉一个动作可能伤人。
3. **约束**：力矩上限、关节限位、避障——这些硬约束在端到端神经网络里很难显式处理。
4. **延迟**：真实机器人需要毫秒级控制，大模型推理太慢。

**2024-2026 年的前沿**正在尝试把控制论的"安全/约束/稳定"和学习方法的"泛化/灵活性"**融合**：

- **Differentiable MPC**：MPC 的结构 + 神经网络学模型和代价
- **Control Barrier Functions (CBF)** + 学习：用 CBF 保证安全，用学习做高性能
- **Diffusion + MPC**：扩散模型生成动作分布，MPC 约束剪裁
- **VLA + 经典控制**：大模型做高层规划，PID/MPC 做底层执行（分层架构）

**这是 Wiener 1948 梦想的回归**——控制和智能的重新统一。

### 9.5 这一阶段的思想底色

| 特征 | 内容 |
|------|------|
| **核心思想** | 通用策略网络 → zero-shot 泛化；控制 + 学习融合 |
| **数学工具** | 深度学习、Transformer、扩散模型、Flow matching |
| **驱动力** | GPU 算力 + 大规模机器人数据 + VLM 成功 |
| **关键张力** | 泛化性（学习）vs 安全性/稳定性（控制）——未解 |

## 10. 思想史反思：五个反常识

### 反常识 1：控制论和 AI 是同一个东西分家 70 年后的重逢

1948 年 Wiener 的 *Cybernetics* 是**控制论和 AI 的共同起源**。然后它们分家：

- **控制论 → 控制理论**：PID、状态空间、最优控制、MPC——严谨、确定性强、安全第一。
- **Cybernetics 的智能部分 → AI**：感知机、专家系统、深度学习、LLM——泛化性强、可解释弱、黑盒。

70 年后它们重新合流：RLHF = PI 控制，Reflexion = 负反馈，Agent Plan-Execute = MPC，机器人基础模型 = 学习的控制器。**分家是历史偶然（Wiener 的大控制论没撑住），合流是逻辑必然（它们本来就是一件事）。**

### 反常识 2：PID 统治工业不是因为"最优"

PID 是 1922 年的方案，100 年了。工业 95% 的控制器仍然是 PID。不是 PID 最优——LQR、MPC、H∞ 都比 PID "更优"。PID 统治的原因是**模型无关 + 可解释 + 够用**。

**教训**：理论进步和工程采用之间有巨大鸿沟。学术界的"更优"在工业界常常不如"够用 + 可靠 + 可维护"。做 AI 也是——最花哨的模型不一定上线，"够用 + 稳定 + 可运维"的才上线。

### 反常识 3：最优 ≠ 鲁棒（Doyle 的教训）

LQG 是"最优"的——但 Doyle 证明它可以对无穷小模型误差不稳定。**在错误的模型上追求最优，等于在最坏的情况下做最脆弱的事。**

这对 AI 的教训是直接的：在 benchmark 上刷 SOTA ≠ 在真实世界鲁棒。**reward hacking 就是 LQG 不鲁棒的 AI 版**——策略在 reward model 上"最优"，但在真实人类偏好的"模型"上崩溃。

### 反常识 4：大多数"AI 新发明"是控制论的旧酒

| "AI 新发明" | 控制论的旧名 | 时间差 |
|------------|-----------|:----:|
| RLHF | PI 控制 / 反馈对齐 | 100 年 |
| Reflexion Agent | 负反馈 / 积分控制 | 70 年 |
| Plan-Execute Agent | MPC（滚动优化） | 40 年 |
| Q-learning | Bellman 方程 | 30 年 |
| Reward shaping | 代价函数设计 | 50 年 |
| Sim-to-real | 系统辨识 + 鲁棒控制 | 40 年 |

这不是贬低 AI——而是说明**控制论是 AI 的隐形骨架**。学 AI 不学控制论，等于不知道自己的算法从哪来。

### 反常识 5：Wiener 被自己的领域遗忘了

控制理论教科书几乎不讲 *Cybernetics*。Wiener 被当成"有远见但不够数学化"的先驱。但 2022 年 RLHF 的成功本质上是 Wiener 1948 年那句话的回声。

**这和 AI 史上 McCulloch-Pitts 被遗忘、Minsky 被简化成"杀死神经网络的人"是同一类胜利者叙事**——历史被赢了的人改写，先驱的贡献被吸收进"常识"，然后被遗忘。

## 12. 失败方向

### 12.1 Wiener 的大控制论（Cybernetics as Universal Science）

Wiener 想建立涵盖工程、生物、社会的统一科学。但：
- **太宏大**——没有一个数学框架能统一这么多领域
- **被拆解**——每个子领域独立发展，没人维持统一
- **被遗忘**——今天"Cybernetics"更多是历史标签，不是活跃学科

**教训**：跨学科愿景有价值，但如果不能在每个领域产生**可操作的成果**，就会被各领域抛弃。AI 的"AGI"叙事可能重蹈覆辙——如果 AGI 不能分解为可操作的子问题。

### 12.2 模糊控制热潮（1980-90s）

如 §8.2 所述，模糊控制作为"革命"失败了——因为它可以用常规数学完全解释，不需要"模糊"框架。但在特定利基（消费电子）仍然有用。

**教训**：新框架要有**不可替代性**。如果旧框架能做同样的事，新框架只是换包装。

### 12.3 早期神经网络控制（1990s）

1990 年代用 NN 做控制器的研究很多，但：
- 没有稳定性保证
- 训练不稳定
- 泛化差

**教训**：学习方法**必须有经典控制的安全保证**作为底线——否则不能上真机器人。2020 年代的 Control Barrier Functions 正是在解决这个问题。

### 12.4 纯模型预测的迷信

MPC 很强大，但过度依赖模型会导致灾难——如果模型在某区域完全错误（如飞行器失速区），MPC 会自信地做出错误控制。**模型置信度**是被忽视的关键问题。

**教训**：任何 model-based 方法（MPC、model-based RL、世界模型）都必须回答"模型在哪里不可信"。

## 13. 路径依赖与偶然性

### 13.1 如果 Bell Labs 不存在……

频域方法（Nyquist/Bode）几乎完全诞生在 Bell Labs。如果长途电话的需求不存在，频域方法可能晚 20 年——状态空间方法可能更早成为主流，控制理论的发展路径会完全不同。

### 13.2 如果没有太空竞赛……

状态空间和最优控制的最大驱动力是太空竞赛（Sputnik → Apollo）。没有太空竞赛，Kalman 的理论可能仍然是纯数学，不会这么快工程化。**冷战的地缘政治深刻塑造了控制理论的面貌**——Pontryagin 和 Bellman 在铁幕两端独立发现最优控制，这本身是冷战的产物。

### 13.3 如果 Wiener 没写 *Cybernetics*……

Wiener 1948 年的大书让"控制论"成为一个时代热词。但讽刺的是，它的**成功导致了分裂**——太多人涌入，各取所需，统一愿景消散。如果 Wiener 写一本更聚焦的书（只讲工程控制），控制论和 AI 可能不会"分家"70 年——但也不会有 1940-50 年代那种激动人心的跨学科对话。

### 13.4 如果 Doyle 没有"翻车" LQG……

Doyle 1978 年证明 LQG 可以不鲁棒——这直接催生了整个鲁棒控制领域（H∞, μ 综合）。如果没人发现这个问题，控制理论可能在"最优"的幻觉里多待十年。**一个反例改变一个领域的方向**——这和 AI 史上 Minsky 1969 年一本书推迟神经网络 20 年是同一类"偶然性改变历史"的模式（虽然方向相反）。

### 13.5 如果 DeepMind 不存在……

DQN（2013）和 AlphaGo（2016）让 RL 从冷门学科变成 AI 核心。如果没有 DeepMind 的资源投入，RL 可能仍在学术冷宫——RLHF 可能不会出现，ChatGPT 的"对齐"方案可能完全不同。**一个公司的存在与否改变了 AI 的技术路线**——这是典型的路径依赖。

## 14. 开放问题

### 14.1 学习的控制能否有经典控制的安全保证？

机器人基础模型（RT-2、π0）很强大，但没有稳定性/安全性保证。如何把李雅普诺夫稳定性、Control Barrier Function、H∞ 鲁棒性嵌入大模型策略？**这是 2026 年控制论的核心开放问题。**

### 14.2 通用策略 vs 专用控制器——谁是终局？

LLM 的发展表明"通用模型 + 少量微调"可以胜过专用模型。机器人控制会走同一条路吗？还是说物理世界的安全约束注定了需要专用控制器？**如果把 PID 的可靠性和 π0 的泛化性融合——最优架构是什么？**

### 14.3 控制论的"GPT 时刻"何时到来？

LLM 的"GPT 时刻"是 GPT-3（2020）——规模到了，能力涌现。机器人控制的"GPT 时刻"需要什么？更多数据？更多算力？还是新的架构（diffusion policy / flow matching / world model）？

### 14.4 Wiener 的统一愿景会复活吗？

1948 年 Wiener 想统一控制、通信、智能。78 年后，这个愿景在"foundation model"（一个模型做感知、推理、控制）的名义下部分复活。**但统一的代价是失去了控制论的安全性和可解释性**——如何兼得？

### 14.5 RL 和控制论的数学统一何时完成？

Bellman 方程是两者的共同根。但 RL 的 sample complexity、exploration、credit assignment 和控制论的 stability、robustness、constraint handling 至今是**两套语言**。是否存在一个统一框架（如不同的可微规划）？**这可能是下一个博士论文金矿。**

### 14.6 控制论能否解释 LLM 的"幻觉"？

LLM 的幻觉 = 开环生成（无反馈）。如果给 LLM 加负反馈（自检/自纠/Reflexion），幻觉能否消除？**这是控制论对 LLM 的直接贡献**——但目前仍停留在经验层面，缺乏理论。

## 16. 费曼回炉

### F1：能不能用一句话讲清控制论 238 年？

> **"用误差驱动修正。"** 从 Watt 的金属球到 π0 的神经网络，从蒸汽机调速器到 RLHF 的策略更新——所有控制系统都在做同一件事：感知偏差，修正偏差，让系统趋向目标。工具在变（机械 → 电子 → 深度学习），原理从未改变。

### F2：卡壳点

我长期把"控制论"和"控制理论"当成同义词。重读 Wiener 1948 才意识到**它们不是一回事**：

- **Cybernetics（控制论/赛博）**：Wiener 的跨学科统一愿景——控制 + 通信 + 智能 + 生物 + 社会。
- **Control Theory（控制理论）**：Cybernetics 分裂后的工程分支——只管数学化的反馈控制。

**控制理论是控制论的一个碎片**。说"控制论 = 控制理论"就像说"进化论 = 遗传学"——前者是更宏大的框架，后者是其中一个形式化的分支。

还有一个误区：我以为 RL 和控制论是两个独立学科，后来发现它们共享 Bellman 方程——**RL 是控制论的直系后代**。Bellman 1957 的动态规划就是 Q-learning 的爷爷。这个认知让我重新理解了 RLHF：它不是"强化学习的胜利"，是"控制论的回声"。

### F3：术语翻译

- **负反馈** → 修正方向与偏差方向相反——偏左就向右纠。不是"偏差为负"，是"修正为负"（对抗偏差）。
- **传递函数** → 把系统当成"输入→输出的黑盒变换"，在频率域（不同频率的正弦波）里刻画它怎么放大/延迟信号——相当于给系统拍一张"频率 X 光片"。
- **状态空间** → 把系统从"黑盒输入输出"升级为"透明盒子"——你能看到内部状态 $x$ 怎么随时间演化，像看发动机内部齿轮一样。
- **Kalman 滤波** → "在噪声里找信号"的最优方法——假设你知道系统的物理模型 + 噪声是高斯的，它给你"最可能的真实状态"。GPS 定位、阿波罗登月都用它。
- **Bellman 方程** → "最优决策的递归结构"——今天的最优 = 今天的收益 + 明天的最优。把无穷长的决策序列拆成一步一步的递推。RL 的 $Q$ 函数就是 Bellman 方程的神经网络近似。
- **H∞ 控制** → "假设对手在最恶意的方向给你注入扰动"——不是平均最优，是最坏情况最优。控制论的"对抗训练"。
- **MPC** → "每一步都先想 N 步，但只走第一步"——像下棋先看 N 步，但每走一步都重新评估。Agent 的 Plan-Execute 就是它的翻版。

### F4：回炉——从"年代史"到"思想史"的迭代

v1（初稿心理模型）我把控制论史写成一张时间线："1788 Watt → 1868 Maxwell → 1922 PID → …… → 2024 π0"。重心在"谁在何时做了什么"。这是**年代史**。

v2 顿悟后，我把每一段都追问"为什么此时此地"：
- Watt 调速器不是因为 Watt 天才，而是工业革命需求 + 风车已有同类装置
- Nyquist/Bode 不是从蒸汽机发展出来的，而是 Bell Labs 长途电话催生的（**路径依赖**）
- Kalman 状态空间不是"更好的方法取代经典控制"，而是"开辟 MIMO 新领地"（**范式转移 ≠ 新杀旧**）
- PID 统治工业 95% 不是因为它最优，是因为它**模型无关 + 可解释 + 够用**（**工程采用 ≠ 理论最优**）

**diff**：从"年份 + 人物 + 事件"的维基百科，升级为"驱动力 + 路径依赖 + 范式转移 + 反常识"的判断力训练器。核心转变是**从"发生了什么"到"为什么此时发生、为什么存活、为什么可能被替代"**。

### F5：终极自测——如果有人问我"控制论和 AI 到底什么关系"

> 它们 1948 年是同一个东西（Cybernetics）。然后分家 70 年——控制论变成严谨的数学工程（PID/LQR/MPC/H∞），AI 变成数据驱动的学习（感知机/深度学习/LLM）。但它们的**数学根是同一个**：Bellman 方程。**2022 年 RLHF 让它们重逢**——RLHF 本质是 PI 控制，Reflexion 是负反馈，Plan-Execute 是 MPC。分家是历史偶然，合流是逻辑必然。学 AI 不学控制论，等于不知道自己的算法从哪来。
