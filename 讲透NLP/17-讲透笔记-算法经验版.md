## §0 全局视角：序列标注 = 结构化预测的最简形态

序列标注：给序列每个位置打一个标签。看似简单，但**标签之间有依赖**（如 NER 实体边界、POS 语法一致），所以不是独立分类问题。

> 🔑 **核心算法 DNA**：**如何建模标签间依赖**——这是所有结构化预测（POS、NER、句法、IE）的共同主题。

| 方法 | 标签依赖建模 | 算法本质 |
|------|------------|---------|
| HMM | 转移概率 $P(t_i\|t_{i-1})$ | 生成式概率图 |
| MEMM | 条件转移 $P(t_i\|t_{i-1}, x)$ | 判别式 + 局部归一化 |
| CRF | 全局序列得分 | 判别式 + **全局归一化** |
| BiLSTM-CRF | LSTM 算特征 + CRF 算依赖 | 神经 + 结构化 |
| BERT-tagging | 微调 + softmax/CRF | 端到端 |

## §1 六条算法经验

### 算法经验 Q1：label bias 问题与全局归一化

> MEMM（最大熵马尔可夫模型）的致命缺陷：**局部归一化**导致 label bias——某些标签的"出度"低，模型偏向它们。
>
> CRF 的解法：**全局归一化**——所有可能标签序列一起 softmax。
>
> $$P(y|x) = \frac{\exp(\text{score}(x, y))}{\sum_{y'} \exp(\text{score}(x, y'))}$$

**算法本质**：**局部 vs 全局归一化**是概率图模型的核心权衡。

可迁移：
- **RNN 的 teacher forcing vs free running**
- **attention 的 local vs global**
- **MoE 的 top-1 vs softmax routing**

### 算法经验 Q2：维特比 = 序列 DP

> HMM/CRF 解码用 Viterbi 算法：动态规划找最优标签序列。
>
> **算法本质**：**用 DP 高效搜索指数级序列空间**。

可迁移（对应 AS2 CTC forward 算法、Ch12 CKY）：
- **CKY 句法分析**
- **DTW（动态时间规整）**
- **强化学习的 trajectory optimization**
- **生物序列对齐（Needleman-Wunsch）**

### 算法经验 Q3：CRF 的配分函数 = 又一个 Z(x)（应用 #7）

> CRF 的配分函数 $Z(x) = \sum_{y'} \exp(\text{score}(x, y'))$ 不可解析，但前向算法可高效计算。
>
> 这与 DPO 的 $Z(x)$（Ch9 #7）、CTC 的 $Z$、玻尔兹曼机的 $Z$ **完全同构**——都是"配分函数用 DP 高效算"。

### 算法经验 Q4：神经 + 结构化的混合架构

> BiLSTM-CRF 是经典混合：**BiLSTM 学表示 + CRF 学依赖**。
>
> 算法本质：**神经网络负责特征学习，结构化模型负责依赖建模**。

可迁移（应用 M5、A5）：
- **BiLSTM-CRF**（NER）
- **Transformer-CRF**（现代 NER）
- **GNN + CRF**（图结构预测）
- **CNN + NMS**（检测后处理）

### 算法经验 Q5：OOV（未知词）的算法本质

> HMM/CRF 的发射概率对未知词（OOV）无能为力。解法：
> - **形态学特征**（词缀、大小写）
> - **字符级 CNN/RNN**
> - **上下文嵌入（BERT）**——彻底解决 OOV
>
> **算法本质**：**OOV 问题的根源是"离散词表"，子词/字符级建模解决它**。

可迁移：
- **BPE/WordPiece**（LLM 词表）
- **OOV 推荐物品**（用 item embedding）
- **罕见类别分类**（用层次化 softmax）

### 算法经验 Q6：BERT 收编了所有结构化预测方法

> BERT 微调 + softmax/CRF 在大多数序列标注任务上达到 SOTA，**收编了 HMM/CRF/BiLSTM-CRF**。
>
> 但 NER 的边界 cases（嵌套实体、长尾实体）仍需 CRF + 规则辅助。

可迁移（应用 T10 LLM 收编规律、Ch10 M4）：**LLM 收编结构化预测，但小数据/精确控制仍用专门模型**。
