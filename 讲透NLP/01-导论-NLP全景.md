# 01 — 导论：NLP 全景、三代方法与无处不在的歧义

## 0. 为什么需要一篇"导论"

NLP（自然语言处理，Natural Language Processing）——让机器理解、生成、翻译人类语言的学问。但"语言"是个无比庞大的对象，入门者面对的典型困惑是：

- NLP 到底包含哪些任务？拼写纠错、机器翻译、聊天机器人、搜索引擎…它们是同一个领域吗？
- 为什么这门课一会儿讲概率统计、一会儿讲神经网络、一会儿讲句法树——这些毫不相关的东西怎么串起来？
- BERT/GPT 出来后，老方法（HMM、CFG、CRF）还有用吗？

这一篇就是回答这些。**核心论断：NLP 不是一堆方法的拼盘，而是"同一个核心难题——歧义——在不同层面的反复出现"；三代方法（规则→统计→神经）都是在打这个难题**。本系列后面的每一章，本质上都在处理某一层的歧义。

---

## 1. NLP 解决什么问题：任务五层

人类语言可以从底到顶分五层，每层都有对应的 NLP 任务：

| 层 | 语言学概念 | NLP 任务 | 本书章节 |
|---|---|---|---|
| **语音层** | 音素 / 声学信号 | ASR（语音转文字）、TTS（文字转语音）| Ch14-16 |
| **形态层** | 词怎么构成（词根+词缀）| 分词、词形还原、形态分析 | Ch02 |
| **句法层** | 词怎么组合成句 | 词性标注 POS、成分/依存句法分析 | Ch17-19 |
| **语义层** | 句子是什么意思 | 词义消歧、语义角色标注、信息抽取 | Ch20, 附录I |
| **语用/篇章层** | 上下文与意图 | 指代消解、篇章连贯、对话系统 | Ch22, 24 |

五层之上还有**应用层**——直接面向用户的任务：机器翻译（Ch12）、问答/检索（Ch11）、情感分析（Ch22）、拼写纠错（附录D）、对话助手（Ch24）。

> 🎯 **关键观察**：每一层的核心难题都是**歧义**。语音层："recognize speech" 还是 "wreck a nice beach"？句法层："I saw the man with a telescope" 是谁有望远镜？语义层："bank" 是银行还是河岸？**整个 NLP 史，就是一部"如何用更聪明的模型消解歧义"的历史**。

## 2. NLP 的三代方法（也是三代失败与补救）

| 代 | 时期 | 代表方法 | 核心思路 | 为什么被取代 |
|---|---|---|---|---|
| **① 规则/符号派** | 1950s–1980s | 上下文无关文法 CFG、专家系统 | 把语言学知识**手写成规则** | 知识获取瓶颈（写规则太贵）+ 脆弱（覆盖不到就崩）|
| **② 统计派** | 1990s–2010s | N-gram LM、HMM、CRF、IBM Model | **数语料的频次**，用概率消歧 | 上下文太短（N-gram 只看几个词）+ 离散表示无法泛化（cat/cats 不互帮）|
| **③ 神经派** | 2014–至今 | RNN、Transformer、BERT、GPT、LLM | 学**连续向量表示** + 端到端梯度 | （目前主力，但：黑箱、数据饥渴、幻觉）|

**三代不是替代，是收编**。第三代（神经）并没有杀死前两代的知识，而是**把它们的输出当训练数据或结构先验**：
- 句法树（规则派的产物）→ 仍用来训 BERT 的结构感知
- 词性标注（统计派 HMM 的强项）→ 仍是大模型预训练的辅助任务
- 规则方法 → 至今活跃在"可解释、可审计"场景（法律/医疗 NLP、拼写纠错兜底）

> 📌 **本系列的主线叙事**：你会看到每一代方法**为什么出现**（解决上一代的什么痛点）、**为什么被超越**（自己又栽在什么上）、**今天还有没有用**。这是 SLP3 最有价值的部分，也是本系列区别于"只讲最新 LLM"的快餐教材的地方。

## 3. 核心难点：歧义无处不在

用一个经典例子展示歧义如何在**每一层**都出现：

> 原句：**"I saw her duck"**

这四个词，至少有四种合法解读：

| 解读 | 含义 | 歧义在哪层 |
|---|---|---|
| ① | 我看见了她（的）鸭子 | duck=名词"鸭子"；her=物主 |
| ② | 我看见她（弯腰）躲闪 | duck=动词"躲避"；her=宾格 |
| ③ | 我用锯子看了她的鸭子 | saw=名词"锯子"（不是 see 过去式）|
| ④ | 我用锯子看了她（在躲避）| 组合歧义 |

人类凭**上下文 + 常识**瞬间消歧，机器要解决它需要：
- **词法**：duck 是名词还是动词？（形态层）
- **句法**：her 是修饰 duck 还是 saw 的宾语？（句法层）
- **语义**：saw 是"看见"还是"锯"？（语义层）
- **语用**：农场语境 vs 木工坊语境，选哪个？（语用层）

**这就是 NLP 难的原因**：每一层都可能歧义，且层与层互相影响（句法结构反过来约束语义）。

## 4. SLP3 全书路线 + 与 work4ai 的对接

- **Volume I（Ch1-16）：大语言模型与语音**——从 N-gram 一路讲到 LLM 对齐，再到语音三件套。**这是当下 NLP 的主战场**。

## 5. 代码：歧义性 + 三代方法对比（bash 跑通）

```bash
cd 讲透NLP
python3 -u experiments/01_nlp_overview.py
```

实验对 "I saw her duck" 做两件事：① 枚举词法层所有歧义组合；② 用规则/统计/神经三代方法对 `duck` 词性消歧，对比各自思路。

**铁证 1 · 词法层歧义组合**：

```
歧义词的可能解读:
  saw   → 2 种: [(V_past, 看见), (N, 锯子)]
  her   → 2 种: [(PRP$, 她的/物主), (PRP, 她/宾格)]
  duck  → 2 种: [(N, 鸭子), (V, 躲避/低头)]

仅【词法层】的歧义组合总数: 8 种（尚未含句法/语义/语用层）
枚举（节选）:
  解读1: I(?) saw(V_past) her(PRP$) duck(N)  → 我 看见 她的 鸭子
  解读2: I(?) saw(V_past) her(PRP)  duck(V)  → 我 看见 她 躲避
  解读5: I(?) saw(N)     her(PRP$) duck(N)  → 我 锯子 她的 鸭子  ← saw 当锯子！
  ...
```

**4 个词、3 个歧义词、词法层就有 8 种组合**。加上句法（her 修饰谁）、语义（saw 看见/锯）、语用（场景），合法解读远不止 8 种。

**铁证 2 · 三代方法各有死角**：

```
① 规则派: IF her=PRP$ THEN duck=N; IF her=PRP THEN duck=V
   痛点: 必须先消 her 的歧义 → 规则依赖外部知识，覆盖不到就崩

② 统计派: 数语料 'her duck' 后接词频次 → 推词性
   投票: {'N': 2, 'V': 1}
   痛点: 只看局部 bigram，'watch her duck' 这种模糊上下文仍难；数据稀疏

③ 神经派: 整句编码成 768 维向量 → softmax 输出 duck 词性
   优势: 看全句上下文 + 连续表示可泛化（ducking/ducks 互帮）
   代价: 黑箱 / 需大数据 / 幻觉（新型歧义）
```

> 🎯 **实验结论**：一句 4 词英文，仅词法层就有 8 种歧义组合。三代方法各能部分消歧，但各有死角——**规则=可解释但脆、统计=数据驱动但短视、神经=强大但黑箱**。歧义是 NLP 核心难点，贯穿每一层；三代方法史 = 一部消歧方法进化史。

## 6. 局限与争议

- **三代划分是教学简化**：现实里规则和神经常混合（神经符号 Neuro-Symbolic），统计和神经也常插值（如 kNN-LM、infini-gram 与 LLM 插值降 73% PPL）。
- **"歧义是核心难点"——LLM 时代部分成立**：LLM 用海量数据"记住"了消歧模式，已不太显式处理歧义。但**幻觉本质上是新型歧义**（模型自己造了解读），所以难题没消失，只是变了形态。
- **本系列不教你调 LLM API**——那是 [`讲透Prompt`](../讲透Prompt/) 的事。本系列教你 NLP 的**地基与方法史**，让你理解 LLM 之前的世界，以及 LLM 把哪些问题解决了、哪些只是掩盖了。
