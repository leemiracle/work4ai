## 1. 直觉：语言能力的四层金字塔

Chomsky (1956) 把所有形式文法分成**嵌套的四层**——从弱到强：

```
Type 3（正则）  ⊂  Type 2（上下文无关）  ⊂  Type 1（上下文有关）  ⊂  Type 0（无限制）
   ↑                     ↑                        ↑                        ↑
  最低                    ↑                        ↑                     最高
 正则表达式            CFG                      CSG                   图灵机
 有限自动机         下推自动机              线性有界自动机
```

**核心洞察**：越往上走，文法能表达的语言越复杂，但**计算代价也越大**。

- **Type 3**（正则）：能表达 `a*`（任意多个 a），但不能表达 $a^n b^n$（n 个 a 后跟 n 个 b）。正则表达式和有限状态自动机在这个层级。
- **Type 2**（上下文无关 / CFG）：**能**表达 $a^n b^n$（括号匹配！），但不能表达 $a^n b^n c^n$。**自然语言和编程语言的基本句法在这里。**
- **Type 1**（上下文有关）：能表达 $a^n b^n c^n$，规则形如 $\alpha A \beta \to \alpha \gamma \beta$（在上下文 $\alpha \ldots \beta$ 中替换 $A$）。
- **Type 0**（无限制）：图灵机能识别的一切。任何可计算语言。

> 🎯 **为什么 NLP 关心这个？** 因为 CFG（Type 2）恰好覆盖了自然语言句法的**大部分**——嵌套结构（"the cat [that the dog [that the boy saw] chased] ran"）本质上是括号匹配，需要 CFG 的递归能力。但 CFG 不够强：跨序列依赖（如 $a^n b^n c^n$ 对应的"n 个主语 + n 个谓语 + n 个宾语"一致性约束）需要更强的文法。

### 经典语言与层级归属

| 语言 | 定义 | 层级 | 为什么 |
|------|------|------|--------|
| $L = a^*$ | 任意多个 a | Type 3 | 正则：循环即可 |
| $L = a^n b^n$ | n 个 a 后跟 n 个 b | Type 2 | 括号匹配：CFG 可表达 |
| $L = a^n b^n c^n$ | 三组等量 | Type 1 | 需要跨三组计数，CFG 做不到 |
| 任意可判定语言 | — | Type 0 | 图灵完备 |

## 2. 数学层

### 2.1 CFG 的形式定义

一个上下文无关文法是一个四元组：

$$G = (N, \Sigma, R, S)$$

| 符号 | 含义 | 例子 |
|------|------|------|
| $N$ | 非终结符（non-terminal）集合 | {S, NP, VP, Det, N, V, P} |
| $\Sigma$ | 终结符（terminal）集合 = 词表 | {the, cat, saw, dog, ...} |
| $R$ | 规则（production）集合 | {S→NP VP, NP→Det N, ...} |
| $S \in N$ | 起始符号（start symbol） | S |

每条规则形如 $A \to \beta$，其中 $A \in N$（**左边只能有单个非终结符**——这就是"上下文无关"的含义：替换 $A$ 不依赖 $A$ 周围的上下文），$\beta \in (N \cup \Sigma)^*$（右边是终结符和非终结符的任意串）。

**语言** $L(G)$ = 从 $S$ 出发能推导出的所有终结符串的集合。

### 2.2 Chomsky 层级的精确定义

| 层级 | 规约形式 | 自动机 | 生成语言 |
|------|---------|--------|---------|
| **Type 3**（正则 / regular） | $A \to a$ 或 $A \to aB$（右线性）/ $A \to Ba$（左线性） | 有限状态自动机（FSA） | 正则语言 |
| **Type 2**（上下文无关 / context-free） | $A \to \gamma$，$A \in N$，$\gamma \in (N\cup\Sigma)^*$ | 下推自动机（PDA） | 上下文无关语言 |
| **Type 1**（上下文有关 / context-sensitive） | $\alpha A \beta \to \alpha \gamma \beta$，$\gamma \neq \epsilon$ | 线性有界自动机（LBA） | 上下文有关语言 |
| **Type 0**（无限制 / unrestricted） | $\alpha \to \beta$，$\alpha \neq \epsilon$ | 图灵机 | 递归可枚举语言 |

每层是下层的**真子集**：存在 Type 2 语言不是 Type 3（如 $a^n b^n$），存在 Type 1 语言不是 Type 2（如 $a^n b^n c^n$）。

> **"上下文无关"的含义**：规则 $A \to \beta$ 可以在任何地方替换 $A$，不关心 $A$ 左右是什么。对比 Type 1 的 $\alpha A \beta \to \alpha \gamma \beta$：只有当 $A$ 处于上下文 $\alpha \ldots \beta$ 中时，才能替换为 $\gamma$——这就是"上下文有关"。

### 2.3 Chomsky 范式（CNF）

**定义**：一个 CFG 在 Chomsky 范式（CNF）中，当且仅当每条规则是以下两种形式之一：

$$A \to B\,C \quad (B, C \in N) \qquad \text{或} \qquad A \to a \quad (a \in \Sigma)$$

即：**右部要么是两个非终结符，要么是一个终结符**。没有混合终结符/非终结符的右部，没有超过两个符号的右部，没有 ε-产生式，没有单位产生式（$A \to B$）。

**为什么需要 CNF？** 因为 CKY 算法要求**二叉树**——它从底向上填充 $n \times n$ 矩阵，每次只合并两个子串。CNF 保证了每棵树都是二叉的，CKY 才能正确工作。

### 2.4 转换算法：任意 CFG → CNF

四步转换（假设文法已去 ε）：

**Step 1：混合终结符替换**（Terminal → dummy non-terminal）

规则 $A \to B\,a\,C$（右部混合终结符 $a$ 和非终结符）变成两条规则：
$$A \to B\,T_a\,C, \qquad T_a \to a$$
其中 $T_a$ 是为终结符 $a$ 新建的哑非终结符。

**Step 2：消除单位产生式**（Unit production elimination）

单位产生式 $A \to B$（右部是单个非终结符）需要展开。如果 $B \to \gamma$ 是非单位规则，则添加 $A \to \gamma$。递归处理传递闭包：若 $A \Rightarrow^* B$ 且 $B \to \gamma$，则添加 $A \to \gamma$。

**Step 3：长右部二叉化**（Binarization）

规则 $A \to B_1\,B_2\,B_3\,B_4$（右部超过 2 个非终结符）被递归拆分：
$$A \to B_1\,X_1, \qquad X_1 \to B_2\,X_2, \qquad X_2 \to B_3\,B_4$$
其中 $X_1, X_2$ 是新建的哑非终结符。从左到右（或任意固定方向）贪心合并。

**Step 4：复制已合规的规则**

形如 $A \to B\,C$ 和 $A \to a$ 的规则直接保留。

> 🧩 **反直觉发现**：CNF 转换后规则数通常**膨胀**（长规则被拆成多条短规则，单位产生式展开后产生大量新规则）。但 CKY 的时间复杂度 $O(|R| \cdot n^3)$ **本质上不变**——因为 $|R|$ 是常数（只取决于文法大小，不随句子长度 $n$ 变化），而 $n^3$ 才是随输入增长的项。膨胀的 $|R|$ 只是增大了常数因子。

### 2.5 文法等价性

| | 弱等价（weak equivalence） | 强等价（strong equivalence） |
|---|---|---|
| 定义 | 生成相同的**字符串集合** $L(G_1) = L(G_2)$ | 生成相同字符串集 **且** 每个字符串的**解析树结构相同** |
| CNF 转换的结果 | ✅ 弱等价（语言不变） | ❌ 不强等价（树结构变了：三叉变二叉） |

> CNF 转换是**弱等价**的——生成的语言不变，但树结构不同（长右部被拆成二叉了）。对于"判断一个句子是否合法"足够，但如果需要原树结构（如成分标注），需要从 CNF 树**还原**原始结构。

### 2.6 Pumping Lemma for CFLs

Pumping Lemma 是证明**某个语言不属于某层级**的工具。对于上下文无关语言：

**定理**（Bar-Hillel, Perles, Shamir 1961）：如果 $L$ 是上下文无关语言，则存在一个常数 $p$（pumping length），使得对于 $L$ 中任何长度 $\geq p$ 的字符串 $w$，可以将其分成五段 $w = uvxyz$，满足：

1. $|vy| > 0$（$v$ 和 $y$ 至少有一个非空）
2. $|vxy| \leq p$（中间三段合起来不太长）
3. **对所有** $i \geq 0$，$uv^ixy^iz \in L$（"泵入" $v$ 和 $y$ 任意次仍在语言中）

**直觉**：如果一棵推导树足够深（$|w| \geq p$），必然有一条从根到叶的路径上**同一个非终结符出现两次**（鸽巢原理）。把这对重复非终结符之间的部分"泵入"（重复），生成的串仍在语言中。

**用 Pumping Lemma 证明 $L = a^n b^n c^n$ 不是 CFL**：

反证法：假设 $L$ 是 CFL，取 $w = a^p b^p c^p$（$p$ 为 pumping length）。根据条件 2，$|vxy| \leq p$，所以 $vxy$ 无法同时覆盖 a、b、c 三段。那么 $v$ 和 $y$ 最多涉及两种字母。泵入 $i=2$ 后，被涉及的字母数量增加，没涉及的字母数量不变——三种字母的数量不再相等——$uv^2xy^2z \notin L$。矛盾！$\square$

> **为什么 NLP 要关心 Pumping Lemma？** 它告诉我们 CFG 的**能力边界**。$a^n b^n c^n$ 类的结构（如"三个序列的等长约束"）在自然语言中确实存在（一致关系、wh-移动的某些模式），这正是 CFG 不够用、需要更强大文法（如 mild context-sensitive grammar, TAG, CCG）的理论原因。

## 4. 批判性视角

- **CNF 不是唯一选择**：CNF 是 Chomsky (1963) 提出的原始范式，但实践中也用 **Binarization**（只做 Step 3，不强求 $A \to a$ 的形式）。纯二叉化的文法同样适用于 CKY，且规则膨胀更小。Stanford Parser 和 spaCy 实际上用的是比 CNF 更宽松的范式。

- **Pumping Lemma 是"否证"工具，不是"证明"工具**：Pumping Lemma 只能证明"某语言**不是** CFL"（通过反证法），**不能**证明"某语言**是** CFL"（存在满足 pumping 条件但非 CFL 的语言）。更强的工具（如 Ogden's Lemma）在理论上更完备，但实践中 Pumping Lemma 已经够用。

- **CFG 对自然语言够不够？** 这是一个**持续 60 年的争论**。Chomsky 自己从 1950s 起就主张自然语言需要超越 CFG 的文法（如 Transformational Grammar、Minimalist Program）。但统计 NLP 的实践表明，CFG（甚至 PCFG）对**绝大多数**英语句子够用——少数需要更复杂文法的结构，可以用**词法化**或**特征结构**（如 LFG、HPSG）来补充。

- **形式理论与工程实践的脱节**：Chomsky 层级和 Pumping Lemma 在理论上精妙，但 NLP 工程师几乎不会用到——现代 parser（神经的或统计的）不依赖文法层级判定，而是直接从数据学习。理论告诉我们"为什么 CFG 不够"（Pumping Lemma），实践告诉我们"但加足够多的特征后够用了"。这种张力是计算语言学最有趣的领域之一。

- **从 CFG 到 LLM 的范式断裂**：LLM 不使用显式文法规则——它通过注意力机制隐式建模结构依赖。这意味着 Chomsky 层级对 LLM 的分析力不从心：LLM 能处理的"语言"不对应于任何经典层级，它是一个**连续的、统计的**函数逼近器，不是离散文法生成器。
