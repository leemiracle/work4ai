# 职业全貌与面试指南：AI 时代的求职与工作

> 配套 [`00-AI for 所有职业`](00-AI%20for%20所有职业.md)。本篇回答两个实操问题：**"这个职业每天到底在做什么？"**（工作全貌）和 **"AI 时代面试考什么？"**（面试场景）。

---

## 一、AI 时代面试的三大变化

### 1.1 AI 工具使用能力成为必考项

| 变化 | 2023 前 | 2026 后 |
|---|---|---|
| 代码题 | 白板写算法 | **允许用 Copilot**，考"能不能写出好的 Prompt" |
| 案例题 | 口头分析 | **允许用 ChatGPT 辅助**，考"能不能批判性验证 AI 输出" |
| 系统设计 | 画架构图 | 考"**AI 怎么融入架构**"（RAG/Agent/LLM 服务）|

### 1.2 反 AI 作弊成为考察点

面试官会**故意看你怎么用 AI**：
- "这段 AI 生成的代码有什么 bug？"（考**代码审查能力**）
- "AI 说这个方案好，你怎么验证？"（考**批判性思维**）
- "不用 AI，手写这段"（考**基本功**）

### 1.3 行为面试更重

AI 替不了的部分（沟通/判断/价值观）在面试中权重**上升**。"你会用 AI"是基本要求，"你在 AI 给出错答案时怎么办"才是区分点。

## 二、各职业面试重点

### 2.1 程序员/ML 工程师

| 类型 | 考察 | AI 时代变化 |
|---|---|---|
| **算法题** | LeetCode Medium+ | 允许 AI，但考"**代码审查 + 边界 case**" |
| **系统设计** | 分布式/数据库 | 加考"LLM 服务架构"（KV Cache/批处理/降级）|
| **ML 基础**（ML 岗）| 训练/推理/评估 | 加考"实验设计 + 统计严谨性" |
| **行为** | 团队协作 | 加考"你怎么用 AI 提效 + 怎么处理 AI 幻觉" |

**典型新题**：
- "用 Copilot 写一个 RAG 系统，然后说出它可能有哪些问题"
- "这个 LLM Agent 在生产中延迟太高，怎么排查？"

### 2.2 数据分析师

| 类型 | 考察 |
|---|---|
| **SQL** | 写 JOIN/窗口函数（允许 AI 生成，但要审查）|
| **案例** | "销售额下降了 20%，怎么查？"（考因果推断，不只是描述统计）|
| **可视化** | "选什么图展示这个数据？为什么？"（考 Tufte 原则）|
| **业务** | "A/B 测试结果显著但业务说不对，可能什么原因？" |

### 2.3 产品经理

| 类型 | 考察 |
|---|---|
| **AI 产品设计** | "设计一个 AI 客服产品，怎么设定什么时候转人工？" |
| **Prompt 工程** | "给客服 LLM 写 system prompt，包含品牌语气+边界" |
| **数据决策** | "AI 推荐点击率涨了但用户投诉也涨了，怎么看？" |
| **伦理** | "你的 AI 产品有偏见，怎么发现和修复？" |

### 2.4 设计师

| 类型 | 考察 |
|---|---|
| **AI 辅助** | "用 Midjourney 生成一个 banner，然后修到可用" |
| **品味** | "AI 生成的 10 张图里选 3 张，为什么？" |
| **品牌** | "怎么让 AI 生成的图保持品牌一致性？"（LoRA/ControlNet）|

### 2.5 安全工程师

| 类型 | 考察 |
|---|---|
| **攻防** | "这段代码有什么漏洞？"（OWASP Top 10）|
| **AI 安全** | "LLM 的 Prompt 注入怎么防？"（讲透 Prompt 08）|
| **事件响应** | "凌晨 3 点收到告警'数据库被拖库'，你的前 30 分钟做什么？" |

## 三、各职业一天工作全貌

### 3.1 程序员（AI 辅助后）

```
09:00  站会（15min，AI 生成会议纪要）
09:15  用 Cursor 开发新功能（AI 补全 60% 代码）
11:00  Code Review（审查 AI+同事的代码）
12:00  午饭
13:00  修 Production Bug（AI 辅助定位，人判断根因）
15:00  设计讨论（架构/技术选型）
16:00  继续开发 + 写测试（AI 生成测试用例）
18:00  部署（CI/CD 自动化，AI 预测风险）
19:00  下班 / On-call（可能被叫起来）
```

**变化**：写代码时间从 60% → 30%（AI 补全），**审查/设计/决策**从 20% → 50%。

### 3.2 数据分析师

```
09:00  看仪表板（AI 异常检测已标注异常点）
09:30  业务方问"为什么转化率降了"→ 用 AI 生成 SQL 拆维度
10:30  发现原因 → 写报告（AI 起草，分析师审查+加洞察）
12:00  午饭
13:00  A/B 测试分析（AI 算 p-value，分析师检查实验设计）
15:00  和业务团队开会（解释数据 + 给建议）
16:30  建新仪表板（AI 自动选图表+配色）
18:00  下班
```

**变化**：写 SQL/做图时间从 50% → 20%，**商业洞察/因果推理**从 20% → 50%。

### 3.3 产品经理

```
09:00  看数据（AI 总结昨日关键指标变化）
09:30  和开发对齐（PRD 审查）
10:30  用户调研（AI 分析访谈记录，PM 提炼洞察）
12:00  午饭
13:00  写 PRD（AI 起草框架，PM 填业务逻辑）
14:30  和设计/开发评审
16:00  处理线上问题（用户反馈 → AI 分类 → PM 优先级排序）
17:30  写周报（AI 生成，PM 审查）
18:30  下班
```

**变化**：写文档时间从 40% → 15%，**沟通/决策/用户洞察**从 30% → 60%。

### 3.4 运维/SRE

```
09:00  查夜间告警（AIOps 已降噪+关联，只看 3 条关键）
09:30  处理告警（1 个是自动扩容解决，2 个需人判断）
10:30  部署（CI/CD + AI 风险评估，金丝雀发布）
12:00  午饭
13:00  写 Terraform（AI 生成 IaC，人审查 plan）
14:30  容量规划（AI 预测下月流量，人决策扩容策略）
16:00  Postmortem（AI 分析日志关联，人写根因 + Action Item）
18:00  下班 / On-call
```

**变化**：告警处理从 40% → 15%，**架构/SLO/容量规划**从 20% → 40%。

## 四、AI 时代的职业转型路径

```
初级程序员 ──AI平权──→ 必须升级到"会设计/会审查/会部署"
    │
数据分析师 ──SQL被替代──→ 必须升级到"会因果推断/会商业洞察"
    │
传统翻译 ──通用翻译被替代──→ 必须升级到"审校/本地化/创译"
    │
客服 ──常见问题被替代──→ 必须升级到"复杂问题处理/客户体验设计"
    │
初级测试 ──自动化──→ 必须升级到"测试策略/AI 测试 Bot 管理"
```

> 🎯 **共同规律**：AI 把"执行层"（写代码/写 SQL/翻译/答问题）自动化，人必须升到"**判断层**"（设计/审查/决策/沟通）。不会升级的人被 AI 平权，会升级的人被 AI 放大。

## 五、面试备考清单（通用）

| 维度 | 要准备 |
|---|---|
| **AI 工具使用** | "你怎么在日常工作中用 AI？"（要有具体案例）|
| **AI 局限认知** | "AI 在你的领域有什么做不好？"（要诚实）|
| **代码审查** | 能识别 AI 生成代码的典型问题（安全/性能/逻辑）|
| **系统设计 + AI** | 知道 RAG/Agent/LLM 服务怎么融入架构 |
| **伦理/安全** | 知道 AI 的偏见/幻觉/隐私风险 + 应对方法 |
| **行为** | 用 STAR 法则准备 3-5 个"用 AI 解决问题"的故事 |
