> **铁律**：顶级专家不是"读完最多书的人"，是"被引用最多的人"。每周必产出，每季度必有公开物。

## 🎯 产出金字塔

```
                  ┌─────────────────┐
                  │ Paper (cited)   │  ← 顶级专家
                  │ workshop/main   │
                  └────────┬────────┘
                           │
                  ┌────────▼────────┐
                  │ arXiv preprint  │  ← 1 年内目标
                  └────────┬────────┘
                           │
                  ┌────────▼────────┐
                  │ Technical Blog  │  ← 季度目标
                  │ (新发现 / 实验) │
                  └────────┬────────┘
                           │
                  ┌────────▼────────┐
                  │ Twitter Thread  │  ← 周目标
                  └────────┬────────┘
                           │
                  ┌────────▼────────┐
                  │ GitHub commit   │  ← 日目标
                  └─────────────────┘
```

**节奏**：
- 日：代码 commit（私有 OK）
- 周：Twitter 1 条带数据
- 月：blog 1 篇（轻量笔记）
- 季：blog 1 篇（深度技术文）
- 年：1 篇 arXiv preprint 或 workshop paper

## 📝 Blog 写作铁律

### 选题（什么算"输出"）

**算输出**：
- ✅ 复现一篇论文 + 加你的新发现
- ✅ 把两个领域概念联起来（"用 PGM 视角理解 RLHF"）
- ✅ 反驳流行观点（带数据 + 实验）
- ✅ 工具/库深度评测（不是 README 翻译）
- ✅ "我踩过的坑" 实战记录

**不算输出**：
- ❌ 读书笔记（重复别人的话）
- ❌ 教程翻译（重复别人的话）
- ❌ "今天学了 X"（无新信息）
- ❌ "10 大 LLM 框架"（listicle）

### 风格（参考顶级研究员）
- **Lilian Weng**: 长 + 全 + 配图（适合综述）
- **Neel Nanda**: 直接 + 实用 + 自嘲
- **Karpathy**: 直觉 + 代码 + 例子
- **Jay Alammar**: 配图丰富
- **Sebastian Raschka**: 实验 + 数据驱动

### 字数
- 1 篇季度深度文：3000-8000 字 + 配图 + 代码
- 1 篇月度笔记：500-1500 字
- 1 条 Twitter thread：5-15 个 tweet

### 工具
- **数学公式**: LaTeX 语法（Markdown 内嵌）
- **配图**: **Excalidraw**（手绘风）/ **Mermaid**（流程图）/ matplotlib
- **代码高亮**: Astro / Hugo 都自带

## 🐦 Twitter 学术圈（**每周必发**）

### [必] Twitter 高质量 post 模板

**模板 1：复现发现**
```
I reproduced [Author]'s [paper].

Main result: [confirms / contradicts] their claim.

But I noticed something they didn't report:
[Specific finding]

Thread 🧵 (1/N)
```

**模板 2：新观察**
```
Hot take after [N] weeks on [topic]:

[Counterintuitive observation]

Evidence: [link to blog/experiment]

Curious what @[AuthorHandle] thinks.
```

**模板 3：求 feedback**
```
I'm [N] weeks into [research direction].

Current question: [specific question]

My approach: [brief]

If you work on this, I'd love feedback:
[link to draft]

🧵
```

### 不要做
- ❌ "Great work!"（无内容评论）
- ❌ "Awesome!"（同上）
- ❌ Daily 报告学习进度（自言自语）

### 必做
- ✅ 回复 Tier 1/2 大牛，附**具体数据 / 实验结果**
- ✅ Thread 拆解复杂话题（Twitter 比单纯链接传播远 5 倍）
- ✅ 引用源论文 + @作者

## 📜 arXiv 投稿（**6-12 月目标**）

### [必] arXiv 入门
- **URL**: `arxiv.org`
- **提交**: `arxiv.org/user/submit`
- **要求**: LaTeX（推荐 `overleaf.com`）
- **endorsement**: 第 1 次提交需要领域内人 endorse（在 Discord 求）

### [必] 论文模板
- **NeurIPS / ICML 模板**: `github.com/NeurIPS2020/DeepLoft` 等
- **_latex_style** 文件从会议官网下
- **Overleaf 模板**: 直接用

### 论文必备工具
- **LaTeX**: Overleaf（在线协作）/ TeXLive（本地）
- **图表**: matplotlib / seaborn / plotly
- **引用**: Zotero + BibLaTeX
- **协作**: Overleaf / GitHub
- **AI 辅助**: Claude / GPT 帮润色（**必须在 ack 里声明**）

## 📖 OpenReview 当 Reviewer（**反哺社区**）

### [必] 注册 OpenReview
- **URL**: `openreview.net`
- **是什么**: NeurIPS / ICLR / COLM 等都用 OpenReview
- **公开 reviews**: 你能读所有历史 review——这是研究训练金矿

### [重] 申请当 reviewer
- COLM / NeurIPS workshop 通常接受新人 reviewer
- 邮件组委会说明：你的方向 + 已有 blog / preprint
- **价值**: 学习如何写 review = 学习如何写论文
