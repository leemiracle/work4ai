## 🔬 研究工具

### [必] Zotero（论文管理）
- **URL**: `zotero.org`
- **是什么**: 开源论文 / 书目管理。免费 300MB（够用），付费 $20/年 5GB
- **关键插件**:
  - **Zotero connector**（浏览器一键保存论文）
  - **Better BibTeX**（LaTeX 集成）
  - **Zotfile**（PDF 管理）
- **替代**: Mendeley（Elsevier，不推荐）/ EndNote（付费）

### [必] Obsidian（笔记）
- **URL**: `obsidian.md`
- **是什么**: Markdown 笔记，本地优先，双向链接。
- **关键插件**:
  - **Excalidraw**（手绘图）
  - **Dataview**（笔记查询）
  - **Templater**（模板）
  - **Anki Sync**（同步闪卡）
- **使用方法**:
  - 每篇论文 / 每个 concept 一个 note
  - 用 `[[]]` 双向链接
  - 用 `#tag` 标签分类

### [必] Anki（闪卡）
- **URL**: `apps.ankiweb.net`
- **是什么**: 间隔重复记忆系统。**学数学必备**。
- **核心**: 任何你忘记觉得"应该记住"的概念 → 立刻做闪卡
- **数学公式**: LaTeX 语法
- **同步**: 免费 AnkiWeb

### [重] Connected Papers（文献图）
- **URL**: `connectedpapers.com`
- **入门**: 输入 1 篇种子论文 → 生成相关论文图

### [选] 其他
- **Notion**: 项目管理 / 数据库
- **Logseq**: Obsidian 替代
- **Readwise Reader**: 稍后读 + 笔记整合

## 🐍 Python 环境（2026+ 标准）

### [必] uv（取代 pip + venv + pip-tools）
- **URL**: `github.com/astral-sh/uv`
- **是什么**: Astral（Ruff 作者）出品，**Rust 实现的极速 Python 包管理器**。比 pip 快 10-100 倍。
- **关键命令**:
  ```bash
  uv init my-project      # 创建项目
  uv venv                 # 创建虚拟环境
  uv add torch            # 添加依赖
  uv add --dev pytest     # 开发依赖
  uv sync                 # 同步环境
  uv run python train.py  # 在环境内运行
  uv lock                 # 锁定版本
  ```
- **为什么是 [必]**: 比 conda 快 100 倍，比 poetry 快 10 倍。**2025+ 业界标准**。

### [必] PyTorch
- **版本**: 2026-08 最新 PyTorch 2.13
- **安装**: `uv add torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121`

### [重] pixi（conda 替代）
- **URL**: `prefix.dev`
- **特点**: Rust 实现，跨语言（Python / R / C++）
- **何时用**: 需要非 Python 包（如 CUDA toolkit）

### [必] Notebook
- **Marimo**（`marimo.io`）: **2024+ 推荐**。reactive notebook（不像 Jupyter 顺序执行，改一个 cell 全部更新）
- **JupyterLab**: 经典，仍在用
- **Hex / Deepnote**: 团队协作 notebook

## 🤖 ML 工具栈

### [必] HuggingFace 生态
```bash
uv add transformers datasets accelerate peft trl
```
- **transformers**: 模型（v5.14+）
- **datasets**: 数据集
- **accelerate**: 分布式训练抽象
- **peft**: 高效微调（LoRA / QLoRA）
- **trl**: RLHF / DPO / PPO 训练

### [必] 实验跟踪
- **W&B**（`wandb.ai`）: 业界标准，免费个人账号
- **MLflow**: 开源替代，自托管
- **为什么 [必]**: 没有实验跟踪 = 没有可复现实验。你 work4ai「讲透泛化」已经讲过。

### [重] 数据版本控制
- **DVC**（`dvc.org`）: Git for data。把数据集版本化

### [重] HuggingFace Hub
- **必用**: 模型 / 数据集 / Space 全在 HF Hub
- **CLI**: `huggingface-cli` 上传下载
- **token**: `huggingface.co/settings/tokens`

### [重] 模型 quantization
- **bitsandbytes**: NF4 / INT8
- **AutoGPTQ**: GPTQ
- **compressed-tensors**: vLLM 标准
