## 🆓 级别 1：免费（**本周必用**）

### [必] 1. Hugging Face ZeroGPU ⭐⭐⭐⭐⭐
- **URL**: `huggingface.co/docs/hub/en/spaces-zerogpu`
- **是什么**: 共享 NVIDIA RTX Pro 6000 Blackwell（48GB / 96GB），按时段分配。
- **免费额度**:
  - Unauthenticated: 2 分钟/天
  - Free account: **5 分钟/天**（账号需 30 天 + 验证邮件）
  - PRO ($9/月): **40 分钟/天** + 8 倍优先级
  - Team / Enterprise: 40-60 分钟/天
- **如何启用**: Space → Settings → Hardware → ZeroGPU；代码中 `@spaces.GPU` 装饰函数
- **何时用**: interp 实验（7B 模型 inference + probing）/ 小模型 fine-tune
- **入门动作**: 注册 HF 账号 → 创建一个 ZeroGPU Space → 跑通 demo

### [必] 2. Google Colab ⭐⭐⭐⭐⭐
- **URL**: `colab.research.google.com`
- **免费**: T4 16GB（时段性可用，使用时长波动）
- **Colab Pro** ($10/月): 更长 session + 优先 T4 / L4 / A100
- **Colab Pro+** ($50/月): 几乎常驻 A100 40GB
- **何时用**: notebook 式学习，快速原型
- **关键技巧**: 把训练 checkpoint 同步到 HF Hub / Drive，避免 session 断丢

### [重] 3. Kaggle Notebooks ⭐⭐⭐⭐
- **URL**: `kaggle.com/code`
- **免费**: P100 16GB / T4 ×2，每周 30 小时
- **何时用**: 数据竞赛 / 长期训练（比 Colab 稳）

### [选] 4. Lightning AI Studio
- **URL**: `lightning.ai/studio`
- **免费**: 每月一定 GPU 时长，集成 PyTorch Lightning

### [选] 5. GitHub Codespaces
- **URL**: `github.com/codespaces`
- **免费**: 每月 120 core-hours（无 GPU），适合 CPU 实验

## 🎓 级别 3：学术申请（**月 12 后冲**）

### [必] 1. Hugging Face Community Grant ⭐⭐⭐⭐⭐
- **URL**: `huggingface.co/spaces` → 创建 Space → Community Tab 提交申请
- **是什么**: HF 免费给 ZeroGPU / dedicated GPU 额度给开源 / 教育 / 研究项目
- **如何申**:
  1. 建 Space（先跑通代码，即使 OOM）
  2. Community Tab 发帖标题：「Apply for a GPU community grant: Academic project」
  3. 正文：1 段项目说明 + 1 段为什么需要 GPU
- **批准率**: 公开 / 研究 / 教育项目通常几天内批准
- **何时申**: 当你有具体的 interp / 教学 demo 项目时

### [必] 2. Hugging Face Academia Hub
- **URL**: `huggingface.co/docs/hub/en/academia-hub`
- **是什么**: 学术机构订阅计划（**$10/seat/月**），含:
  - 1TB private + 1TB public storage
  - ZeroGPU 优先
  - Data Studio
  - SOC 2 / SSO / 2FA
- **何时用**: 通过你的学校 / 研究机构订阅（如果有的话）

### [重] 5. Google TPU Research Cloud (TRC)

## ⚠️ 算力使用陷阱

1. **不要在 GPU 上写代码**。开发用 CPU，确认无误再上 GPU。
2. **永远 checkpoint 到云**（HF Hub / S3 / Drive），不要只存本地。
3. **batch_size 不是越大越好**——读 Grad Accumulation 文档。
4. **学 mix-precision**（bf16 / fp8）——白送 2-4 倍速度。
5. **学 FlashAttention**——所有 SOTA 模型都用。
6. **Colab/ZeroGPU 不能长跑训练**（最长 12-24h）。训练大模型用 RunPod。
7. **学习成本控制**: 用 `nvidia-smi -l 1` 实时看显存，超 $50 主动停。
