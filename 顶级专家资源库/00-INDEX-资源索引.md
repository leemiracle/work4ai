## 🚨 红线警告

如果出现以下情况，**立即停下来反思**：
1. 连续 2 周没产出 → 时间管理有问题
2. 连续 1 月没参加社群 → 社群动力消失
3. 连续 2 月数学进度 < 50% → 数学路径需调整
4. 累计 3 月没 interp 实验 → 方向可能选错
5. 总时间 < 计划 60% → 目标需重定
6. 心理状态差 / 焦虑 / 失眠 → 必须休息
