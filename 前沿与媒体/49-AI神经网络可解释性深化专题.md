---

## 0. 可解释性的"两条路"

```
   ① Mechanistic Interpretability（机制可解释性）
      ↓ 拆网络为可理解电路 / 特征 / heads
      ← Anthropic / OpenAI Superalignment / Goodfire
   
   ② Post-hoc Explainability（事后解释）
      ↓ SHAP / LIME / Attention 可视化
      ← 学术界经典
```
