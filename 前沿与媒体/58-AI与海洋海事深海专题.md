> 海洋是地球最未探索区域（70% 表面，95% 深海未测绘）。AI + 海洋 = 自主潜水器 + 海洋观测 + 水产养殖 + 海事监控。

---

## 0. AI × 海洋的"四场景"

```
   ① 自主水下航行器（AUV）          ← Saildrone / Hugin / Bluefin
   ② 海洋观测（卫星 + 浮标）         ← NOAA / Copernicus / argo
   ③ 海事监控（船运 / 渔业 / 搜救）   ← Windward / Spire
   ④ 海洋生物学 + 水产               ← eDNA + AI / 三文鱼养殖
```
