## 三、开源治理模式

- **BDFL（仁慈独裁者）**：Linus Torvalds / Guido / Dries
- **Meritocracy（精英制）**：Apache
- **Foundation（基金会）**：Linux Foundation / Apache / Eclipse / CNCF / OSI
- **Benevolent Company（公司控制）**：MongoDB（SSPL）/ Elastic / HashiCorp（BSL）
- **Open Core**：GitLab / Grafana / Databricks
- **DAO / Token**：少数实验
