## 0. 行业 AI 共性

```
       通用 LLM（ChatGPT/Claude）
                ↓ 行业适配
       行业 Base 模型（Med-PaLM / BloombergGPT / Harvey）
                ↓ 数据/合规
       行业产品（Epic AI / Bloomberg / LexisNexis / Khanmigo）
                ↓
       最终用户（医生 / 交易员 / 律师 / 教师）
```

**共性痛点**：① 合规（医疗 HIPAA / 金融 SEC / 法律 attorney-client / 教育 FERPA）；② 数据私有；③ 错误成本高；④ 强监管。

## 一、AI + 医疗健康（Healthcare）

### 应用场景
- **诊断辅助**：影像（Paige / Aidoc / Zebra / 数坤科技）
- **药物发现**：见 [`15-AI for Science`](./15-AI%20for%20Science%20专题.md)
- **医患对话**：Hippocratic AI（"Polarily-Aligned Generative Healthcare Agents"）
- **循证医学问答**：OpenEvidence / Glass Health
- **EHR 电子病历**：Epic / Cerner / Athenahealth 内嵌 AI
- **心理 AI**：Woebot / Wysa / Replika（争议大）

### 关键产品
| 产品 | 公司 | 强项 |
|---|---|---|
| **Med-PaLM 2 / Med-Gemini** | Google | 医学多模态 |
| **Hippocratic AI** [hippocraticai.com](https://www.hippocraticai.com/) | Polly-aligned | ⚠️ Cloudflare，但行业明星 |
| **OpenEvidence** | OpenEvidence | 医学文献 LLM |
| **Glass Health** | Glass Health | 临床决策 |
| **Paige** | Paige.AI | 病理 AI（FDA 批准）|
| **Aidoc** | Aidoc | 急诊影像 |
| **Suki / Abridge / Nuance DAX** | 多家 | 医患对话转写 |

### 中文医疗 AI
- **腾讯觅影** / **百度灵医智惠** / **数坤科技** / **推想医疗** / **汇医慧影**
