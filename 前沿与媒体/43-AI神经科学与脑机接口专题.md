# 前沿与媒体 · 43 - AI 神经科学与脑机接口（BCI）专题

> 姊妹篇：[`21-哲学/意识`](./21-AI哲学、意识与认知科学专题.md)｜ [`15-Science`](./15-AI%20for%20Science%20专题.md)。
>
> AI + 神经科学双向：① 用 AI 解码大脑（BCI）；② 用大脑启发 AI（neuromorphic）。本篇给神经科学家 / BCI 创业者 / 跨学科研究者。

---

## 0. 三个方向

```
   ① BCI（脑机接口）         ← Neuralink / Synchron / Precision
   ② AI for Brain            ← 用 ML 解码 fMRI/EEG 信号
   ③ Brain-inspired AI       ← 神经形态计算（Intel Loihi / IBM TrueNorth）
```

---

## 一、BCI（脑机接口）公司

| 公司 | 路线 | 状态 |
|---|---|---|
| **Neuralink** [neuralink.com](https://neuralink.com/) | **侵入式**（柔性电极）| 🟢 2024 首例人体植入，2026 多人 |
| **Synchron** | 血管内（Stentrode）| 🟢 FDA 批准临床试验 |
| **Precision Neuroscience** | 微创（皮层表面）| 🟢 |
| **Blackrock Neurotech** | Utah Array（老牌）| 🟢 |
| **Paradromics** | 高带宽侵入式 | 🟢 |
| **BrainCo 强脑科技** | 非侵入（中国）| 🟢（哈佛背景）|
| **博睿康** | 中国 BCI |
| **NeuroPace** | 癫痫治疗 BCI（FDA 批准）|

## 二、AI for Brain（神经科学 AI）

| 项目 | 强项 |
|---|---|
| **BrainLEE / fMRI 解码** | LLM 解码大脑活动 |
| **Brain-to-Text** | 思考转文字 |
| **Mind-Video** | 视觉皮层活动→视频（2024 突破）|
| **Patch-seq + AI** | 单细胞神经分类 |
| **Connectomics + AI** | 脑连接组学（FlyWire/Janelia）|

## 三、神经形态计算（Brain-inspired AI）

| 项目 | 强项 |
