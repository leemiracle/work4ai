## 0. 消费服务的"AI 三层"

```
        供给端（选品/库存/定价）       ← 推荐系统 + LLM
                ↓
        匹配端（搜索/推荐/广告）        ← 嵌入 + LLM + 多模态
                ↓
        体验端（客服/内容/营销）        ← 生成式 AI + 客服 bot
```

---

## 一、AI + 零售 / 电商（Retail & E-commerce）

### 关键场景
- **推荐系统**：协同过滤 → 深度学习 → LLM 推理
- **搜索**：语义搜索 + 多模态（图搜图）
- **定价**：动态定价（亚马逊经典案例）
- **库存**：需求预测
- **客服**：聊天机器人
- **生成**：商品描述 / 营销文案

### 关键公司
| 公司 | 强项 |
|---|---|
| **Amazon** | **Alexa / Amazon Bedrock / Rufus 购物助手 / Just Walk Out**（无人店）|
| **Alibaba 阿里** | 淘宝推荐 / 通义千问电商 / 万相台 |
| **JD 京东** | 言犀大模型 + 智能客服 |
| **Pinduoduo 拼多多** | Temu 跨境 + 农业 AI |
| **Shopify Magic** | Shopify AI 工具（中小卖家）|
| **Stripe / Adyen** | 支付 AI 反欺诈 |
| **Instacart / Doordash / Uber Eats** | 即时配送 AI |
| **字节 Douyin 电商 / 抖音电商** | 短视频/直播 + AI 推荐 |

## 三、AI + 餐饮 / 食品（Food & Restaurant）

### 关键场景

- **配送**：路径 + 时效（与物流重叠）
- **快餐后厨**：麦当劳/星巴克 AI 自助点餐
