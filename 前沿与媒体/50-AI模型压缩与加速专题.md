## 0. 模型压缩的"四把刀"

```
   ① Quantization（量化）     ← INT8/INT4/FP8/MXFP4
   ② Pruning（剪枝）           ← 去掉冗余权重
   ③ Distillation（蒸馏）       ← 大模型教小模型
   ④ Sparse / MoE              ← 稀疏激活
```

---

## 一、Quantization（量化）

| 方法 | 强项 |
|---|---|
| **GPTQ** | 后训练量化（PTQ）经典 |
| **AWQ** | Activation-aware（MIT-Han Lab）|
| **SmoothQuant** | 平滑激活 |
| **GGUF / llama.cpp** | 本地推理量化（4-bit）|
| **EXL2 / ExLlamaV2** | 混合精度量化 |
| **BitsAndBytes** | HF 集成（NF4 / QLoRA）|
| **MXFP4 / Microscaling** | 微软 + AMD + Intel + NVIDIA 标准（Kimi K3 用）|
| **FP8（NVIDIA Hopper+）** | 硬件原生 |

### 关键人物
- **Tim Dettmers**（Washington，BitsAndBytes / QLoRA 作者）
- **Song Han**（MIT-Han Lab，Deep Compression）
- **Gordan Yuan / Wei Sun**（中文贡献者多）
