## 四、AI 估值关键指标

- **Revenue Multiple**：AI 公司估值倍数远高于传统 SaaS（30-100x ARR）
- **GPU Equity**：2023-2024 出现"用 GPU 算力换股权"模式（a16z / NVIDIA）
- **Talent Acquisition**：买人式收购（Acqui-hire）常见
- **API Revenue**：很多 AI 公司 ARR 中 50%+ 来自 OpenAI/Anthropic API 转售（争议）
