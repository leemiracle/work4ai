## 0. AI 网络安全的"双向战场"

```
        ┌─────────── AI 攻击（黑客）──────────┐
        │  Phishing 钓鱼（Deepfake 邮件/语音）  │
        │  漏洞挖掘（AI 自动找 CVE）            │
        │  自动化渗透（WormGPT/FraudGPT）        │
        │  对抗样本（ evasion / poisoning）     │
        │  AI 社工（情报聚合）                   │
        └─────────────────────────────────────┘
                            vs
        ┌─────────── AI 防御（白帽）──────────┐
        │  威胁检测（CrowdStrike Falcon）       │
        │  异常行为（用户/实体行为分析 UEBA）   │
        │  漏洞修复（AI 补丁生成）              │
        │  反钓鱼（邮件过滤）                   │
        │ 事件响应（自动化 IR）                 │
        └─────────────────────────────────────┘
```

## 四、AI Safety vs Cyber Security（容易混）

| 维度 | AI Safety（[`11`](./11-AI政策、伦理与Safety专题.md)）| Cyber Security（本篇）|
|---|---|---|
| 关注 | AI 系统的失效模式 | 网络/系统被攻击 |
| 例子 | Hallucination / Sleeper Agents / 对齐失败 | 钓鱼 / 漏洞 / DDoS |
| 主体 | AI Lab（Anthropic/OpenAI）| CSO / SOC |

**交叉点**：① LLM 越狱（jailbreak）= 两个领域都关心；② Prompt injection = 攻击 LLM 应用本身；③ AI 红队 = 两个领域都做。

## 五、AI 应用安全（Prompt Injection 等）

这是 2023–2026 的新分支（"AI 安全的 Web 2.0"）。

| 攻击 | 防御 |
|---|---|
| **Prompt Injection**（直接/间接）| LLM Guardrails（Llama Guard / Prompt Guard / NVIDIA NeMo Guardrails）|
| **Jailbreak**（越狱）| RLHF + Constitutional AI + 红队 |
| **Data Poisoning**（训练数据投毒）| 数据清洗 + 差分隐私 |
| **Model Stealing**（模型提取）| API 限速 + 水印 |
| **Adversarial Examples**（对抗样本）| 对抗训练 |
| **LLM Tool Abuse**（MCP/Function Calling 滥用）| 工具白名单 |

**关键框架**：
- **OWASP Top 10 for LLM**（开源）
- **NIST AI RMF + GenAI Profile**（见 [`11`](./11-AI政策、伦理与Safety专题.md)）
- **MITRE ATLAS**（Adversarial Threat Landscape for AI Systems）
