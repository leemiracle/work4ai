## 0. 金融 AI 的 5 大场景

```
   量化交易（高频/中频/低频）       ← 时序模型 + RL + LLM 情绪
        ↓
   反欺诈 / 反洗钱（AML）           ← 图神经网络 + 异常检测
        ↓
   信贷决策（消金/信用卡/小微信用）   ← 替代数据 + 信用评分
        ↓
   支付（路由/反欺诈/对账）          ← 实时推理
        ↓
   加密货币（DeFi/链上分析/做市）    ← 链上 AI
```

## 一、量化交易（Quantitative Trading）

### 关键玩家
| 类型 | 公司 |
|---|---|
| **顶级量化对冲** | Renaissance（Medallion）/ Citadel / Two Sigma / DE Shaw / Millennium / Balyasny |
| **量化主动** | WorldQuant / AQR / Man Group |
| **高频 HFT** | Jump Trading / Tower Research / Hudson River Trading |
| **中国量化** | 幻方（High-Flyer，DeepSeek 母公司！）/ 九坤 / 明汯 / 灵均 / 衍复 |
| **Crypto 量化** | Wintermute / Jump Crypto / Alameda（已倒闭）/ Amber Group |

### AI/ML 在量化的角色
- **时序预测**：Transformer / Mamba for 金融（FinGPT 类）
- **替代数据**：卫星图 / 消费日志 / 社交情绪 / 招聘数据
- **执行优化**：拆单 + RL 择时
- **LLM 情绪**：Fed 会议纪要解读 / 新闻瞬时反应
- **风险模型**：图神经网络做关联风险

### 关键人物
- **Jim Simons**（Renaissance，已逝 2024）— 量化先驱，《The Man Who Solved the Market》
- **David Siegel**（Two Sigma）
- **Ken Griffin**（Citadel）
- **梁文锋**（幻方/DeepSeek 创始人，2024-2025 因 DeepSeek 出圈）
