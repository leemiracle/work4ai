## 0. AI 研究的"全工作流"

```
       ① 找论文（发现）           ← Connected Papers / Elicit / Consensus / SciSpace
                    ↓
       ② 读论文（精读）           ← LLM (Claude/GPT) + ChatPDF / SciSpace Copilot
                    ↓
       ③ 管理论理（文献库）        ← Zotero / MendeleY / Notion
                    ↓
       ④ 写综述 / 写论文          ← Claude / GPT + Overleaf + Zotero 插件
                    ↓
       ⑤ 投稿 / 同行评议          ← OpenReview / arXiv / 顶会系统
```

**铁律**：**AI 不会替你做研究**——它只会让你"10× 快地发现 / 阅读 / 整理"。**核心判断力还在你脑子里**。把 AI 当"超级助理"，别当"代笔"。

## 二、读论文（Reading）—— AI 时代最大变化

### R3. AI 辅助精读工具

| # | 工具 | 模式 | 强项 |
|---|---|---|---|
| R3-1 | **Claude（Anthropic）** | 上传 PDF + 提问 | 长上下文（200K+），论文 PDF 直接吃，**目前最强** |
| R3-2 | **GPT-4 / GPT-5** | 上传 PDF + 提问 | OpenAI 旗舰 |
| R3-3 | **SciSpace Copilot** | 浏览器内嵌 | 跟随阅读，划词解释 |
| R3-4 | **ChatPDF** | 上传 PDF | 早期最简单入口 |
| R3-5 | **Humata / PDF.ai** | 上传 PDF | 商业版，企业用 |
| R3-6 | **Kimi / 通义千问 / 文心** | 中文论文 | **国内长上下文之王**，中文 PDF 解析强 |

> **诀窍**：上传 PDF 直接问 Claude"这篇的核心贡献是什么 / 公式 X 怎么推 / 实验里 ablation 缺什么"——比逐字读快 5 倍。**但 LLM 会编**，关键数据要回原文核对。

## 五、典型工作流（实战）

### 流程 A：快速跟前沿（每周 2 小时）

```
周一早 30 分钟：扫 AK + HF Daily Papers → 命中 3 篇
周三晚 60 分钟：上传到 Claude，逐篇问"核心贡献 + 局限 + 复现难度"
周五晚 30 分钟：命中的存 Zotero，用 Zotero AI 插件做摘要
每月一次：Connected Papers 看关系图，找"前驱/后继"
```

### 流程 B：写综述（2-3 周）

```
Day 1-3：Elicit + Consensus 找 50 篇候选
Day 4-7：用 Claude 逐篇过，筛出 20 篇必读
Day 8-14：精读 20 篇（每篇 1 小时）+ 用 SciSpace Copilot 划词
Day 15-21：Claude 起综述大纲 + Overleaf 写正文 + Zotero 插引用
```

### 流程 C：找研究方向（开题）

```
1. 用 Connected Papers 看目标方向的"关系图"——找被引最多的"中心论文"
2. 用 Elicit 问"What are the open problems in X?"
3. 用 Consensus 问 yes/no 问题测共识度
4. 在 OpenReview 看去年顶会的 reject 论文（找被忽视的方向）
```
