## 0. 翻译 AI 的"四代"

```
   1. 规则翻译（1960s-1980s）       ← SYSTRAN
   2. 统计机器翻译（SMT, 2000s）    ← IBM Model / Moses / Google SMT
   3. 神经机器翻译（NMT, 2014+）    ← Google NMT / DeepL / Transformer
   4. LLM 翻译（2023+）             ← GPT-4 / Claude / 上下文感知
```
