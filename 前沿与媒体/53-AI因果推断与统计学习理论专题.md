## 一、因果推断

### 关键人物
| 人物 | 贡献 |
|---|---|
| **Judea Pearl**（UCLA，图灵奖）| 因果革命 / Do-calculus / 《Causality》 |
| **Donald Rubin**（Harvard）| Potential Outcomes 框架 |
| **Susan Athey**（Stanford）| 经济学 + ML 因果 |
| **David Blei**（Columbia）| Topic modeling + Causal |
| **Bernhard Schölkopf**（MPI）| Causal Representation Learning |
| **Elias Bareinboim**（Columbia）| Pearl 学生 |
| **Yoshua Bengio**（Mila）| 因果表征 |

### 关键概念
- **Pearl's Ladder of Causation**：观察（Seeing）→ 干预（Doing）→ 反事实（Imagining）
- **Do-calculus**：从观察分布推干预分布
- **Counterfactuals**：what-if
- **Instrumental Variable（IV）/ Difference-in-Differences / Regression Discontinuity**：经典计量
- **Causal Forests / Double Machine Learning**：ML + 因果

### 应用
- **经济学**（诺贝尔奖常含）
- **医学**（A/B 测试 + 因果）
- **推荐系统**（不只要"喜欢"，要"推荐什么会改变行为"）
- **AI Fairness**（区分相关 vs 因果）

## 三、为什么 LLM 让理论失效？

- **过参数化 ≠ 过拟合**（Double Descent）
- **NTK 理论解释有限**（真实 LLM 不是无限宽）
- **Scaling Laws（Kaplan/Chinchilla）**：经验主导
- **Grokking**：训练曲线理论尚未统一
