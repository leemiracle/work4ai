## 0. AI 生物特征识别 vs 隐私

```
        ┌──────────────────────────────────┐
        │  ① 识别（监控侧）                  │  ← Clearview / SenseTime / Megvii
        │  人脸 / 声纹 / 步态 / 虹膜 / DNA   │
        └──────────────────────────────────┘
                         ↕（矛与盾）
        ┌──────────────────────────────────┐
        │  ② 保护（被监控侧）                │  ← Glaze / Nightshade / PhotoGuard
        │  对抗样本 / 数据投毒 / 脱敏        │
        └──────────────────────────────────┘
                         ↕
        ┌──────────────────────────────────┐
        │  ③ 法律（合规侧）                  │  ← GDPR / CCPA / PIPL / BIPA
        │  数据最小化 / 同意权 / 删除权       │
        └──────────────────────────────────┘
```

## 三、Deepfake（深度伪造）

| 类型 | 用途 |
|---|---|
| **政治 Deepfake** | Zelensky 投降伪造（2022）/ Biden 骗电话 / Trump 假视频 |
| **色情 Deepfake（非自愿）** | Taylor Swift 事件（2024）/ 普通女性受害（流量巨大）|
| **名人 Deepfake 广告** | Elon Musk / Trump 假加密货币广告 |
| **商业 Deepfake** | 香港 Arup 案（2024）|
| **个人复仇色情（NCII）** | 普通人 NCP / 止损平台（StopNCII）|

### Deepfake 检测 / 防御
- **Sensity / Reality Defender / Hive AI**（商业）
- **DeepMedia / Truepic**（认证水印）
- **C2PA**（Coalition for Content Provenance and Authenticity）— Adobe + Microsoft + BBC 等
- **SynthID**（Google DeepMind，AI 内容水印）
- **OpenAI C2PA 标记**
