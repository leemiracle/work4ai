## 0. 数据可视化 + AI 的"三层"

```
   ① 传统 BI（仪表盘 / 报表）         ← Tableau / Power BI / 帆软
        ↓
   ② NLBI（自然语言 BI）              ← Julius / ChatGPT Advanced Data Analysis
        ↓
   ③ AI 数据故事（自动洞察 + 叙事）    ← Hex Magic / ThoughtSpot Sage
```
