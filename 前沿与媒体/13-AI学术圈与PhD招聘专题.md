## 三、PhD 申请（北美 AI 方向）

### 申请通道与时间线
| 时段 | 事件 |
|---|---|
| 9-10 月 | 准备材料（SOP / CV / 推荐信 / 成绩单）|
| 11-12 月 | 截止申请（多数 12.1-12.15）|
| 1-2 月 | 面试 |
| 2-3 月 | 录取 offer |
| 4.15 | 决定日（北美统一）|
| 8-9 月 | 入学 |

### 选校建议（AI 方向）
| Tier | 学校 |
|---|---|
| **Tier 1** | MIT / Stanford / Berkeley / CMU（四大）|
| **Tier 1.5** | Princeton NLP / UW / Toronto / NYU / ETH |
| **Tier 2** | UIUC / Georgia Tech / UT Austin / Wisconsin / UMass / Michigan / Edinburgh / MILA |
| **Tier 3** | USC / UCSD / Columbia / Duke / Brown / Purdue |

### 推荐信 vs 文书
- **推荐信 > SOP**：找一位"会强推你"的教授（高引学者 / 知名 lab）> 找一位"你做得好"的导师
- **Top lab 远程 RA**：先去远程做 RA（1 年），让 PI 真正了解你
- **顶会一作**：NeurIPS / ICML / ICLR / ACL 一作 1 篇 = 强信号

### 奖学金 / 资金
- **几乎所有美国 PhD** = 全奖（tuition + stipend $30-50k/年 + 医疗）
- **NSF GRFP**（美国公民/绿卡）：3 年奖学金，含 $37k stipend
- **NDSEG / DOE / NIH Fellowships**：政府奖学金
- **CSC 国家留学基金**（中国学生）：公派
- **Anthropic / OpenAI Doctoral Fellowship**：2024 起，AI Safety 方向

## 五、Frontier Labs 实习 / 全职

### 实习通道（通常 5-9 月，10 周以上）
| Lab | 实习计划 |
|---|---|
| **OpenAI Residency**（6 个月）| 最抢手，转正率高 |
| **Anthropic Visiting Researcher / Scholar** | 多种 |
| **Google DeepMind Internship / Student Researcher** | 1 年多次 |
| **Meta FAIR PhD Internship** | 经典 |
| **Microsoft Research PhD Internship** | Redmond / 北京 / Cambridge |
| **NVIDIA Research** | 硬件 + 算法交叉 |

### 全职研究员路径
- **直接 PhD → Lab**：少见但有（如 Jason Wei Google Brain → OpenAI → Meta）
- **Postdoc → Lab**：标准路径
- **Top Lab Faculty**：Berkeley / Stanford / CMU 教授 → 顾问 + 学生送入

## 六、签证 / 移民

### 美国
- **F1 留学签**：PhD 入学
- **OPT 12 个月 / STEM OPT 24 个月**：PhD 毕业后实习
- **H-1B 工作签**：抽签（中国/印度中签率低）
- **O-1 杰出人才**：PhD 顶会论文多可申请
- **EB-1A / NIW 绿卡**：PhD 标配

### 英国
- **Tier 4 学生签** → **Tier 2 工作签** → **Global Talent Visa**（AI 路线）

### 加拿大
- **学签 → 毕业工签（PGWP）3 年** → **PR**（EE/CEC）

### 欧洲
- **欧盟蓝卡** + **各国博士合同**（含工资）

### 新加坡
- **Tech.Pass / ONE Pass**（高薪直通车）
