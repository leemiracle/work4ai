> **收录原则**（铁律）：
> 1. **一手 > 二手**：优先官方 blog / 论文 / 创始人访谈；二手新闻聚合（机器之心 / 量子位 / TLDR）只作"扫描雷达"，不作"理解源头"。

> 3. **覆盖谱系**：必须覆盖 论文 / 论文聚合 / 播客 / 个人博客 / 机构博客 / Newsletter / 社区 / 中文 / AI Safety / 评测 十类，缺一类就有盲区。

## 二、详解：论文与论文聚合（A 类）

> **为什么这层最重要**：AI 圈"二手震惊体"和"一手论文"的差距，比任何领域都大。一个研究者一年读 100 篇 arXiv，认知会甩开只看新闻的人几个数量级。本层 = 你的"信息源头"。

### P1. arXiv — 🟡 永恒基石

- **入口**：https://arxiv.org/list/cs.LG/recent | cs.CL | cs.CV | cs.AI | stat.ML
- **用法**：
  - **每日 RSS / 邮件订阅**：arxiv.org/help/subscribe
  - **按 category 列表浏览**：每周一晚（美东）批量上线
  - **抓 PDF 全文**：永远是 `arxiv.org/pdf/<id>` 这个稳定 URL
- **诀窍**：
  - 别试图读完，**先扫标题+摘要**，命中的再下 PDF
  - 用 Semantic Scholar / AK / HF Papers 做二次筛选，效率高 10 倍

## 十一、推荐「信息食谱」（与讲透系列 + 公开课串起来）

本仓库已有的体系：
- **「讲透 XXX」系列** = 钻深度（一次一个概念，往死里讲）
- **公开课清单** = 系统学（按课表走）
- **访谈及其他** = 中文深度（人物/历史脉络）
- **本篇（前沿与媒体）** = **保持手感**（每周/每日跟进）

四者关系：

```
零基础建立认知
  ├─ 公开课（系统学：Karpathy / CS224n / 李宏毅）
  └─ 「讲透」系列（深度：讲透激活函数 / 基础模型 / 微调 / RAG / Prompt）
        │
        ▼
保持每周手感（本篇清单）
  ├─ 每日 10 分钟：
  │     ├─ AK / HF Daily Papers（扫标题）   ← A 类
  │     └─ X "AI Core" List 列表（5 分钟）
  │
  ├─ 每周 1 小时：
  │     ├─ Import AI（Jack Clark）          ← E2
  │     ├─ Latent Space Newsletter          ← E5
  │     ├─ Last Week in AI / TLDR AI        ← E4 / E7
  │     └─ 机器之心 / 量子位（中文）          ← G1 / G2
  │
  ├─ 每月精读 2-3 篇：
  │     ├─ Lilian Weng / Sebastian Raschka 综述  ← C2 / C4
  │     └─ 旗舰机构 blog（OpenAI / Anthropic / DeepMind）← D1 / D2 / D3
  │
  └─ 通勤/健身时听播客：
        ├─ Lex Fridman / Dwarkesh（深度对谈）  ← C1 / C2
        ├─ Latent Space / Cognitive Revolution（论文解读）← C5 / C4
        └─ 张小珺（中文产业）                  ← G6
```

**一句话策略**：
- **70% 时间**：一手（论文 + 机构 blog + Karpathy/Raschka/Weng 综述）
- **20% 时间**：高质量二手（Import AI / Latent Space / Last Week in AI）
- **10% 时间**：扫描雷达（AK / X / 机器之心 / 量子位 / Hacker News）

**反模式警告**：
- ❌ **只看二手新闻**（机器之心/量子位/TLDR）→ 永远停留在"知道发生了什么"，不懂"为什么"
- ❌ **只听播客不看论文**（Lex/Dwarkesh 是入口，不是终点）→ 知识被动接收，无法形成判断力
- ❌ **只跟一手不跟二手**（只读 arXiv 不读 Import AI）→ 错过政策/产业视角
- ❌ **信噪比失控**（关注 100 个 X 账号 / 订阅 30 个 newsletter）→ 信息过载，反而什么都没吸收
