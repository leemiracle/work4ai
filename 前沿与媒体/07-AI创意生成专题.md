## 五、典型工作流（实战）

### 流程 A：设计师出图（Midjourney 风格）
```
Midjourney v6 / Flux → 命中后用 ControlNet 微调姿态 → Photoshop 后期
```

### 流程 B：短视频创作者
```
Runway Gen-3 / Wan 生成 5s 片段 → Suno 配乐 → 剪辑
```

### 流程 C：开源本地跑（无审查、隐私）
```
ComfyUI + Flux.dev + ControlNet 在本地 RTX 4090 上跑
```
