## 0. AI 编程语言矩阵

```
   Python — 绝对主导（PyTorch/Transformers/diffusers...）
        ↓
   C++/CUDA — 高性能内核（vLLM/FlashAttention/Triton）
        ↓
   Rust — 安全系统（HuggingFace tokenizers/Candle）
        ↓
   Julia — 科学计算（SciML/Flux.jl）
        ↓
   Mojo — Modular 新语言（Chris Lattner，Python + 性能）
        ↓
   JavaScript/TypeScript — Web AI（ML5.js/Transformers.js）
```

---

## 一、Python（绝对主导）

| 生态 | 强项 |
|---|---|
| **PyTorch** | 训练事实标准 |
| **Transformers**（HF）| 模型库 |
| **JAX**（Google）| 函数式 + TPU |
| **NumPy/Pandas/Polars** | 数据 |
| **uv / Poetry / Rye / Pixi** | 现代 Python 包管理（已在 [`讲透公开课 02`](../讲透公开课/02-数理计算机神课清单.md)）|

## 二、C++ / CUDA

| 项目 | 强项 |
|---|---|
| **PyTorch csrc**（C++ 后端）| 主流 |
| **CUDA / CUTLASS / cuDNN / TensorRT** | NVIDIA 栈 |

## 三、Rust for AI

## 五、Mojo（Modular）

- **Chris Lattner**（Swift / LLVM / MLIR 父亲）创办 Modular
- Mojo = Python 语法 + 性能（C++ 级）
- **MLIR** 后端
- 2023 发布，2024 火热但生态未稳
