## 0. AI 历史的"七幕"

```
幕 1（1943-1956）黎明
   McCulloch-Pitts / Turing / "图灵测试" / 达特茅斯会议（1956）
        ↓
幕 2（1956-1974）黄金年代
   LISP / 符号 AI / 早期 NN / 感知机 / Minsky 反对 NN
        ↓
幕 3（1974-1980）第一次寒冬
   Minsky & Papert《Perceptrons》/ DARPA 削减资助 / "AI 无用论"
        ↓
幕 4（1980-1987）专家系统热
   XCON / LISP 机 / 日本五代机 / Hopfield 网络 / 反向传播重发现
        ↓
幕 5（1987-1993）第二次寒冬
   LISP 机市场崩溃 / 第五代机失败 / PC 取代专用硬件
        ↓
幕 6（1993-2012）统计 / 贝叶斯 / SVM 时代
   IBM 深蓝 1997 击败 Kasparov / Web 2.0 数据 / Netflix Prize
        ↓
幕 7（2012-至今）深度学习 + LLM 时代
   AlexNet 2012 / AlphaGo 2016 / Transformer 2017 / GPT-3 2020 / ChatGPT 2022 / GPT-4 2023 / Claude 5 2026
```

## 一、关键事件年表

| 年份 | 事件 | 意义 |
|---|---|---|
| 1943 | McCulloch & Pitts 神经元数学模型 | 神经网络概念起源 |
| 1950 | **Turing《Computing Machinery and Intelligence》** | 图灵测试 |
| 1956 | **达特茅斯会议**（Dartmouth Workshop）| "Artificial Intelligence" 术语诞生（McCarthy 命名）|
| 1958 | Rosenblatt 感知机（Perceptron）| 第一台 NN 硬件 |
| 1969 | Minsky & Papert《Perceptrons》| 算 XOR 限制，**打击 NN** |
| 1986 | **Rumelhart, Hinton, Williams 反向传播** | 现代深度学习起点（Nature）|
| 1989 | LeCun CNN 用于手写数字（LeNet）| 早期 CNN 工业应用 |
| 1997 | **IBM 深蓝击败 Kasparov（国际象棋）**| AI 首次超人类棋类 |
| 1997 | **LSTM**（Hochreiter & Schmidhuber）| RNN 长序列突破 |
| 2006 | **Hinton "Deep Belief Networks"** | "Deep Learning" 术语流行 |
| 2011 | IBM Watson 赢 Jeopardy | 自然语言 TV 问答 |
| 2012 | **AlexNet**（Krizhevsky/Sutskever/Hinton）ImageNet | **深度学习革命** |
| 2014 | GAN（Goodfellow）| 生成模型突破 |
| 2016 | **DeepMind AlphaGo 击败李世石** | AI 突破"直觉"博弈 |
| 2017 | **Transformer《Attention is All You Need》** | 现代 LLM 架构诞生 |
| 2018 | **图灵奖颁给 Hinton/LeCun/Bengio** | 深度学习三巨头 |
| 2020 | **GPT-3**（175B 参数）| "Scale is all you need" |
| 2022-11 | **ChatGPT 发布** | AI 走向大众 |
| 2023-03 | **GPT-4** | 多模态 + 专业考试超人类 |
| 2024-10 | **2024 诺奖化学颁给 Hassabis/Jumper/Baker**（蛋白） | AI for Science 诺奖化 |
| 2024-10 | **2024 诺奖物理颁给 Hinton** | 深度学习物理意义 |
| 2025-01 | **DeepSeek-R1 开源** | 推理 RL 开源里程碑 |
| 2026-07 | **Claude Opus 5 / Sonnet 5 / Fable 5** | Anthropic 5 系列 |
| 2026-08 | **GPT-5.4 / DeepSeek-V4-Pro / 国产开源生态**（Kimi K3 等）| 当前 frontier |

## 三、经典书（按时代）

### 通史
- **《Artificial Intelligence: A Modern Approach》**（Russell & Norvig）— **AIMA 第 4 版**，全球 AI 教材 No.1
- **《Life 3.0》**（Max Tegmark）— 现代科普
- **《The Master Algorithm》**（Pedro Domingos）— 5 大流派

### 深度学习史
- **《Deep Learning》**（Goodfellow/Bengio/Courville）— 经典教材（2016，有些过时但仍是基础）
- **《Genius Makers》**（Cade Metz, 2021）— 记者写 Hinton 派故事
- **《Genius Factory》**类似

### LLM 时代
- **《The Alignment Problem》**（Brian Christian, 2020）
- **《Artificial Intelligence: A Guide for Thinking Humans》**（Melanie Mitchell, 2019）
- **《Deep Utopia》**（Bostrom 2025+）

## 七、关键争论节点（思辨史）

| 争论 | 时间 | 双方 |
|---|---|---|
| **符号 vs 联接** | 1960s-至今 | McCarthy/Minsky vs Hinton/LeCun |

| **Searle 中文房间** | 1980 | Searle vs Churchlands/Dennett |
