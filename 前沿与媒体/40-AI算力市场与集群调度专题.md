## 0. AI 算力的"四级市场"

```
   ① 一级市场（NVIDIA/AMD 直销）— Stargate / 微软 / Meta / OpenAI 巨头直接拿
        ↓
   ② 二级市场（公有云）— AWS / Azure / GCP / Oracle / 阿里云
        ↓
   ③ 三级市场（GPU 云）— CoreWeave / Lambda / Together / Nebius / RunPod / Vast.ai
        ↓
   ④ 四级市场（去中心化）— Render / Akash / io.net（与 31 重叠）
```
