## 0. 优化的层次

```
   ① 凸优化（经典）         ← 梯度下降收敛保证
   ② 非凸优化（深度学习）    ← 没保证但实践有效
   ③ 大规模分布式             ← 数据/张量/流水线并行
```

---

## 一、优化器谱系

| 优化器 | 强项 |
|---|---|
| **SGD / Mini-batch SGD** | 经典 |
| **Momentum / Nesterov** | 加速 |
| **AdaGrad / RMSProp** | 自适应 |
| **Adam / AdamW** | 主流（带 weight decay）|
| **LAMB / LARS** | 大 batch 训练 |
| **Lion**（Google Brain，2023）| 符号 + 动量 |
| **Shampoo / Muon**（最新）| 二阶近似 |
| **Sophia**（Stanford 2023）| 对角 Hessian |
| **SOAP / Muon 2024+** | 2024-2025 新一代 |

---

## 二、关键论文 / 理论

| 论文 | 意义 |
|---|---|
| **Robbins & Munro 1951 SGD** | 奠基 |
| **Kingma & Ba 2014 Adam** | 主流 |
| **Loshchilov & Hutter 2017 AdamW** | Decoupled weight decay |
| **You et al. LARS/LAMB** | 大 batch |
| **Reddi et al. 2018"On the Convergence of Adam"** | AMSGrad 修正 |
| **Chen et al. Lion 2023** | 自动搜索 |
| **Shampoo / Muon 2024** | 新一代 |

---

## 三、学习率调度

- **Step Decay**（经典）
- **Cosine Decay**（主流）
- **Warmup + Cosine**（Transformer 标准）
- **OneCycle**（Leslie Smith）
- **WSD（Warmup-Stable-Decay）**（DeepSeek）

---

## 四、分布式优化

| 并行 | 强项 |
|---|---|
| **Data Parallel（DP/DDP）** | 模型副本 |
| **ZeRO 1/2/3**（DeepSpeed）| 切分优化器/梯度/参数 |
| **FSDP**（PyTorch 原生）| 同 ZeRO-3 |
| **Tensor Parallel（TP）** | Megatron-LM |
| **Pipeline Parallel（PP）** | GPipe / PipeDream |
| **Sequence Parallel（SP）** | 长上下文 |
| **Expert Parallel（EP）** | MoE |
