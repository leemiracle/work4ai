# 00 - 群论是什么：对称性的代数

> 群论是**对称性的语言**。本章用 3 个例子让你"看见"群。

---

## 一、直觉：3 个对称的例子

### 1.1 等边三角形的对称 $D_3$

哪些操作让三角形"看起来一样"？6 个：恒等 / 旋转 120° / 旋转 240° / 3 条中线翻转。它们构成**群** $D_3$。

4 条性质：**封闭** + **单位** + **逆** + **结合** = 群的定义。

### 1.2 整数加法群 $\mathbb{Z}$

无限 Abel 群。

### 1.3 钟表群 $\mathbb{Z}/12\mathbb{Z}$

$7 + 8 = 3$（mod 12）。**有限**循环群。

**反直觉**：群可以有限。有限群是抽象代数的核心。

---

## 二、数学：群的定义 + Lagrange 定理

### 2.1 定义

群 $(G, \cdot)$：结合律 + 单位元 + 逆元。满足交换律则 Abel。

### 2.2 阶 / 子群

$|G|$ = 元素数。$H \leq G$ 是子群。

### 2.3 Lagrange 定理 ⭐

**定理**：有限群 $G$，子群 $H$，则 $|H|$ 整除 $|G|$。

**反直觉**：6 阶群没有 4 阶子群（4 不整除 6）。

## 五、为什么群论重要

| 应用 | 用什么群 |
|------|---------|
| Galois 理论（5 次方程无求根公式）| 有限群 |
| 粒子物理标准模型 | Lie 群（$SU(3) \times SU(2) \times U(1)$）|
| 密码学 | 椭圆曲线群 |
| ML 等变神经网络 | 群作用 |
| 晶体学 | 空间群 |
| 几何（Klein 爱尔兰根纲领）| 变换群 |
