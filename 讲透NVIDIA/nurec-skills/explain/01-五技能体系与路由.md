# 01 · 五技能体系与路由：nurec-index 如何把任务分发出去

## 角色定位

nurec-skills 是 NVIDIA NuRec 生态的 agent 技能包，本质是 **thin coordination layer**（README.md:31-34）：仓内没有引擎源码，只教 agent 驱动 NGC 容器、GitHub 仓与 HF 工件。六个技能各管一段：`nurec-index` 是路由器（README.md:43 "Read first"）、`ncore` 转传感器数据为 NCore V4、`nre` 做 3DGUT/3DGRT 重建渲染、`asset-harvester` 收割逐对象高斯资产、`nurec-fixer` 做 DiffusionHarmonizer 帧清理（nurec-fixer/SKILL.md:86 明言"老 Fixer 技能的公开继承者"）、`physical-ai-datasets` 做数据集目录。任务语境的"五技能体系"= 五个管线技能 + 一个目录技能。

## 内部结构

路由核心在 `skills/nurec-index/SKILL.md`（v0.2.4，skills/nurec-index/SKILL.md:9）：11 节 391 行。`## Pick a skill` 决策表（skills/nurec-index/SKILL.md:168 起）按目标匹配左列、右列给技能，箭头表示"按序执行"；`## Easy mix-ups`（skills/nurec-index/SKILL.md:216）处理易混淆对——最典型的是 "NuRec vs NRE"：前者产品名、后者引擎名，都路由到 `nre`。`## The skills in this folder`（skills/nurec-index/SKILL.md:202）给一行式摘要。index 自己 `tools:` 只声明读类工具，**不执行任何管线**。

## 外部连接

找不到兄弟技能时按 discovery 顺序解析（skills/nurec-index/SKILL.md:329-330）：`.agents/skills/nre/SKILL.md` → `.claude/skills/nre/` → `.cursor/skills/nre/` → `~/.cursor/skills/nre/` → 兜底 clone 本仓。`.agents/skills/` 本身只是 `skills/` 的 symlink（README.md:53），保证跨技能相对链接在任一前缀下成立。维护约定在 `## Keeping this index up to date`（skills/nurec-index/SKILL.md:373）。发布治理走 `request-nvskills-ci.yml`，issue 评论 `/nvskills-ci` 触发（.github/workflows/request-nvskills-ci.yml:16）。

## 数据流

一次典型请求的两跳：① 用户目标（"渲染这个 clip"/"把 ROS2 bag 转 NCore"）→ index 决策表 → 目标技能；② 目标技能按各自 SKILL.md 菜谱驱动上游——ncore 驱动 `pip install nvidia-ncore` 的上游包（ncore/SKILL.md 1058 行，Path A :245 用既有转换器、Path B :285 从 `ncore_template` 写新的），nre 驱动 `release_26.04` NGC 容器（nre/SKILL.md:44 pin），harvester/fixer 各驱动自己的镜像与权重。

## 设计决策

- **路由与执行分离**：index 不碰管线，避免路由知识与技术细节互相污染；决策表+易混淆表双机制覆盖正反两向。
- **负触发写进 frontmatter**：每个技能 description 自带 "Do NOT use..."（如 nre/SKILL.md:67 把逐对象收割推给 asset-harvester；physical-ai-datasets/SKILL.md:3-22 末尾 "Do NOT use as a runtime"），agent 侧双向防误触。
- **上游 pin 显式化**：版本不藏在文档里而在 metadata 块（asset-harvester/SKILL.md:27-40 pin GitHub+HF 四工件；README.md:41-48 表格第三列），上游发版只 bump frontmatter。

## 新人提示

先读 README.md:41-48 路由表再读 index 全文；注意 `physical-ai-datasets` 是唯一没有 BENCHMARK.md 的技能；nre 的 BENCHMARK 判 FAIL 是文档含 GPS 坐标的发布合规问题（skills/nre/BENCHMARK.md:12），不是功能不可用。
