# 06 · 平台层与硬件监控：三平台移植与遥测的物理源头

## 角色定位

同一套 NSM/SPDM/PLDM 协议栈跑在三种平台：MCXN556/MCXN236（NXP 双核 Cortex-M33，量产）与 x86（宿主机仿真，CI 用）。`src/sys/` 按平台分目录，`src/nv/` 的硬件监控族（194 文件）则是 NSM Type3 遥测数值的物理来源。这一层回答两个问题：固件怎么移植、遥测数据从哪来。

## 内部结构

**平台层**：`src/sys/mcxn556/`（135 文件）——`src/sys/mcxn556/sys/bootloader/bootloader.cpp:47`（Driver::run_on_index 镜像选择）、`:62`（use_boot_rom 常量）、`:110`（Driver::hw_init）、`:119`（`__attribute__((no_stack_protector))` 的 set_stack_cookie——启动早期栈保护特殊处理）；接口声明 `src/sys/mcxn556/sys/bootloader/bootloader.h:28`（class Driver）与跨平台门面 `src/nv/bootloader.h`（96 行：boot reason/镜像状态查询）。`src/sys/mcxn236/`（104 文件）量产主力，与 556 同构 HAL 族（ipc/flash/i2c/usb）。`src/sys/x86/`（95 文件）仿真平台：`src/sys/x86/sys/common/error-inject.cpp` 故障注入 + console 直写 stdout，配 `src/overrides/` 的 libc/thread 覆盖。`src/sys/mcu/` 公共抽象，`src/boards/` 板级时钟与引脚复配，`corepdk/platforms/mcxn236` 模块级平台公共层。

**硬件监控族**（src/nv，注意传感器与 powersensor 都在 `src/nv/i2c/` 之下）：温度传感器 `src/nv/i2c/emc1812.cpp:22`（Emc1812 构造：port+address+TelemId 三参即接入缓存体系；同层还有 nct75/tmp1075/tmp432/tmp461/tmp468 族）；热插拔功率传感器 `src/nv/i2c/powersensor/device_manager.cpp:91`（DeviceManager::identify_power_sensors 识别热插拔控制器）、`:210`（read_mfr_info 读厂商/型号）、`:302`（add_hsc_device 注册），具体驱动 hsc_lm5066i.cpp/hsc_mp5926.cpp/hscc_mp29540.cpp/hscc_raa22800X.cpp/hsc_xpd712021.cpp 一型号一文件；注错调试 `src/nv/i2c/error_injection.cpp`；电压/漏电 `src/nv/volt_mon/leak_detect.h` 与 `src/nv/volt_mon/leak_detect_pds_seed.h`（PDS seed）、`src/nv/volt_mon/pgood_volt.h`；热插拔状态机 `src/nv/ahs/ahs.cpp:47`-`:444`（nv::ahs 命名空间全跨度）；USB 侧 `src/nv/usb/mctp_router.cpp:98`（update_routing_table）。其余：vrot/vpp 风扇电源、i3c/ssif、vcom/vruart 虚拟串口、fancontrol、lstp/gpu_pwr_controller、perf_mon（`src/nv/mctp/nsm_type_4.cpp:45` 引其 CPU 利用率）。

**跨核服务**：`src/nv/ipc/`——`src/nv/ipc/event.h:35`（class Event，FreeRTOS 事件组封装）、`src/nv/ipc/queue.h:35`（class Queue）与 `src/nv/ipc/queue.h:124`（get_queue_max_items）、`src/nv/ipc/supervisor.h:37`（class Supervisor）、task.h（176 行任务基类：事件循环/队列/定时器骨架）；flash 门面 `src/nv/flash/flash.h`（130 行）与 `src/nv/flash/common.h:27` 起的跨核请求布局（`:28` SectorSize/`:29` PhraseSize 常量，RequestHeader/Request/Response 结构）；日志 `src/nv/logger/log.h:35`（class Logger，191 行）；工具 `src/nv/common/utils.h`（222 行字节序/位操作）。

## 外部连接

向上：硬件监控族写遥测缓存（`src/nv/telemetry/cache.cpp:46` set_cache）供 NSM Type3 读取（`src/nv/mctp/nsm_type_3.cpp:54`）；ipc/flash 服务被 NSM/SPDM/PLDM 三协议共享；bootloader 状态被 `src/nv/mctp/nsm.cpp:400` 起的固件管理（State::InProgress/Complete）与 `src/nv/spdm/spdm_cert_chain.cpp:121` 的证书槽位消费。向下：MCXN 平台 HAL 经 corepdk/platforms 接 UBS 构建；x86 平台接 `src/overrides/` 仿真桩。

## 数据流

遥测物理链：LM5066I/MP5926 经 I2C 总线（`src/nv/i2c/port.h` 端口抽象）→ `src/nv/i2c/powersensor/device_manager.cpp:91` 识别并轮询 → `:210` 读厂商信息确认型号 → helper 换算 → `src/nv/telemetry/cache.cpp:46` 入库 → NSM Type3 命中应答（见 01 篇）。跨核链：MCXN 双核（core0 协议栈/core1 实时控制典型分工）经核间邮箱 → `src/nv/ipc/queue.h:35` 的 Queue → 对核任务（flash 读写擦走 `src/nv/flash/common.h:27` 的请求布局）。热插拔链：`src/nv/ahs/ahs.cpp:47` 的状态机感知板卡在位事件 → nhp 引脚控制 → `src/nv/i2c/powersensor/device_manager.cpp:302` 重建设备表。

## 设计决策

①**x86 仿真平台是一等公民**——`src/sys/x86/sys/common/error-inject.cpp` 的故障注入让 CI 无硬件演练异常路径（配 `src/nv/i2c/error_injection.cpp` 的传感器注错），协议栈逻辑可 PR 级回归；②**HAL 同构双 MCU**——mcxn236/556 文件名对齐（ipc/flash/i2c/usb 各一套），移植=换实现不换接口；③**I2C 端口抽象极薄**（`src/nv/i2c/port.h` 39 行）——传感器族只依赖这一层，新传感器接入不动总线代码（`src/nv/i2c/emc1812.cpp:22` 三参构造即插即用是明证）；④**flash 走跨核服务而非直调**——读写擦统一经 `src/nv/flash/common.h:27` 的请求/响应布局，core1 实时控制不被 flash 长操作阻塞。
