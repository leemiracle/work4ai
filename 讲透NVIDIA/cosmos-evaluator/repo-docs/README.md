# Cosmos Evaluator

Cosmos Evaluator is an automated evaluation system for synthetic video output generated by [Cosmos](https://developer.nvidia.com/cosmos). It validates quality across multiple dimensions — object correspondence, environment conditions, and more — producing structured quality scores you can use to assess and improve your video generation pipeline.

This document will show you how to get started with running the different checker containers.

## What's Included

This release includes four evaluation checks and the service framework to run them:

| Check | What It Does |
|-------|-------------|
| [**Hallucination Check**](docs/checks/hallucination.md) | Looks for hallucinated or removed movement by comparing motion masks in original and augmented videos. |
| [**Objects Check**](docs/checks/objects.md) | Evaluates whether objects in a generated video correspond to their expected ground-truth positions. |
| [**Attribute Verification Check**](docs/checks/attribute_verification.md) | Uses language and vision-language models to verify requested scene attributes. |
| [**Physical Plausibility Check**](docs/checks/physical_plausibility.md) | Uses temporal video representations to score whether motion in a generated video is physically plausible. |

All checks are available as **REST API microservices** using the included service framework. They can also be used programmatically via their Python APIs. Advanced users can build custom checks on top of the framework.

Beyond running checkers individually, the release also includes an **orchestration layer**: an **Arbitrator** service that coordinates multiple checkers per request, a **Database REST API** for durable result recording, and a **PostgreSQL** container for storage. See the [Orchestration Layer guide](docs/services/orchestration.md) for details.
