# 05 · 导出基准与测试防线

## 一、角色定位

`code/export/` 把训练产物转成 SafeTensors 并生成独立评测数据包；`code/benchmarks/` 是 CPU 可跑的微基准；`code/scripts/` 承接本地/容器/集群三档运行入口；`code/tests/`（含 mid/ 子层）与 `.github/workflows/` 构成三层测试防线。全是训练下游：发布、复现、防回归。

## 二、内部结构

**导出**：`checkpoint_to_safetensors.py` 兼容三种 state dict 格式并剥 DDP `module.` 前缀（`code/export/checkpoint_to_safetensors.py:44`），`weights_only=True` 防 pickle 执行（`code/export/checkpoint_to_safetensors.py:52`）；`--model-id` 明示 color 卷积 checkpoint 不可转（`code/export/checkpoint_to_safetensors.py:83`）——color 加宽末层卷积，surface 架构装不下。`safetensors_utils.py` 走无 Hydra 路线：`_build_minimal_cfg` 手拼最小配置（`code/export/safetensors_utils.py:37`），model_id/感受野/filters 写入文件头（`code/export/safetensors_utils.py:80`），加载先 `safe_open` 只读 header（`code/export/safetensors_utils.py:112`）。

**数据生成**：435 行 `generate_test_data.py` 产端到端评测包：Stim 采样、beliefmatching 抽 H/O/priors、PyMatching baseline，落小端二进制。两技巧：path 自举（`code/export/generate_test_data.py:81`）+伪造 `qec.surface_code` 包对象绕过拖入 torch 的 `__init__.py`（`code/export/generate_test_data.py:92`）；默认 25p 噪声模型钉 p=0.003（`code/export/generate_test_data.py:107`）。H/O/priors 即 cudaq artifacts（`code/export/generate_test_data.py:193`），供 CUDA-Q 消费（`code/export/generate_test_data.py:240`）。

**基准**：`bench_color_memory_circuit_construction.py` 测 color MemoryCircuit 构造耗时，warmup 丢弃 + median（`code/benchmarks/bench_color_memory_circuit_construction.py:42`）；docstring 自认基线 TBD（`code/benchmarks/bench_color_memory_circuit_construction.py:26`）——诚实未完成标记。

**脚本线**：`local_run.sh` 万能入口（train/inference/decoder_ablation 等）；忽略环境 BASE_OUTPUT_DIR/LOG_BASE_DIR，只认 `PREDECODER_` 前缀（`code/scripts/local_run.sh:79`）——防集群全局变量写歪产物路径；generate_stim_data 强制单进程（`code/scripts/local_run.sh:93`），多机各起 writer 会死等 rendezvous；多卡多机才走 torchrun（`code/scripts/local_run.sh:274`）。`offline_smoketest.sh` 两段式（纯 Stim 链 + 带 checkpoint 推理链），推理设 `PREDECODER_EMIT_INFERENCE_SUMMARY=1`（`code/scripts/offline_smoketest.sh:55`），末尾内嵌 Python 抓最后一个 `[Inference Summary] ` 行（`code/scripts/offline_smoketest.sh:88`）；模型缺失 skip 不失败（`code/scripts/offline_smoketest.sh:72`）。集群线：`cluster_install_deps.sh` 以 TORCH_CUDA（默认 cu121）选轮子（`code/scripts/cluster_install_deps.sh:23`）；容器脚本见 `PREDECODER_PYTHON` 能 import torch 即跳装（`code/scripts/cluster_container_install_and_train.sh:47`），兼顾烧入镜像与裸镜像。

## 三、外部连接

导出线接 `model/registry.py` 与 config_validator；数据生成接 stim/pymatching/beliefmatching。smoketest 与 CI 都回到 local_run.sh；cookbook 两本 notebook（`cookbook/predecoder.ipynb`、`cookbook/color_code.ipynb`）前几 cell 自装依赖，是零安装前门。

## 四、数据流

发布流：.pt → registry 查 spec → 最小 cfg 重建 → strict 加载 → 可选 half() → 连元数据落 .safetensors → 推理时 `PREDECODER_SAFETENSORS_CHECKPOINT=... WORKFLOW=inference`。评测数据流：一次产出六类文件，下游无 stim 也能复现解码实验。CI：push 触发 cu128/cu130 矩阵（`.github/workflows/ci-gpu.yml:59`），REQ_FILE 映射 cu13/cu12（`.github/workflows/ci-gpu.yml:89`），短跑 16k 样本断言 LER<0.35；长线每日 cron（`.github/workflows/long-running-tests.yml:31`）跑四 job，24h 无提交自动跳过。

## 五、设计决策

①**命名空间收窄**：local_run.sh 只认 `PREDECODER_` 前缀，集群变量污染被硬隔离。②**分层测试即分层目录**：short 靠 `unittest discover` 发现，mid 无 `__init__.py` 天然不被发现（`code/tests/README_TEST_TIERS.md:23`）；对照表收口（`code/tests/README_TEST_TIERS.md:112`）。③**孤儿测试防御**：`test_training_progress.py` 的被测脚本已不在仓，`skipTest` 守卫（`code/tests/test_training_progress.py:23`）保 CI 绿。④**镜像导入语义**：`test_tensorrt_fallback.py` 不 import 生产代码，复刻两处 TRT 导入块的 try/except（`code/tests/test_tensorrt_fallback.py:74`），钉死"ImportError 必炸、引擎坏才降级"。⑤**诚实降级**：缺模型 skip、基线 TBD、TRT 缺失 RuntimeError——宁可降级不伪造通过。

## 六、新人提示

发布色码模型只有 "B" 可转，color 卷积转换必失败是设计如此。local_run.sh 两铁律：输出只认 PREDECODER_ 前缀；generate_stim_data 永远单进程。加测试放对层：分钟级 code/tests（pre-merge 必跑）、GPU 级 tests/mid/（merge 后）、小时级 long-running-tests.yml。test_training_progress 被 skip 是孤儿守卫非坏味道。notebook 首跑自装依赖，别在只读挂载跑。
