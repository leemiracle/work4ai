# 03 · 数据管线与生成器：Stim 采样、on-the-fly 生成与超批预取

## 一、角色定位

`code/data/`（11 文件 2550 行）是预解码器的弹药库，两条供弹线泾渭分明：**训练线**完全 on-the-fly——不建数据集，`create_datapipe` 在 memory 模式直接返回 (None, None)（factory.py:34 起），数据由 generator 在 GPU 即时生成；**推理线**用 Stim 采样器现场抽 shot。公共语言是四通道张量 trainX (4, T, D, D)。另有种子守卫、超批预取、噪声加载三个横向小件。

## 二、内部结构

**factory.py**（259 行）`DatapipeFactory`（factory.py:25）按 cfg.code×{train,inference} 四路分发。重活全在两个 inference 分支：`_create_surface_datapipe_inference`（factory.py:77）与 `_create_color_datapipe_inference`（factory.py:148）都在**方法体内**延迟 import 各自的 Stim 管线（factory.py:82-86、151-156）。surface 两数据源：`PREDECODER_STIM_SAMPLES_DIR`（factory.py:109）指到预生成目录时选 `..._from_stim_file`，否则现场采样；噪声指纹不匹配默认报错，`PREDECODER_STIM_STRICT_NOISE=0` 降级警告（factory.py:126）。both basis 下文件管道挑 X 探形状（factory.py:113）。

**datapipe 双子**：datapipe_stim.py（354 行）含 `QCDataPipePreDecoder_Memory_inference`（datapipe_stim.py:33）与 `_from_stim_file`（datapipe_stim.py:217）；采样核心一行 `circ_X.stim_circuit.compile_sampler().sample(shots=...)`（datapipe_stim.py:101，X/Z 双电路各一次）。datapipe_stim_color.py（279 行）的 `QCDataPipePreDecoder_ColorCode_inference`（datapipe_stim_color.py:32）同构，多 superdense/schedule 参数。

**生成器三兄弟**：`QCDataGeneratorTorch`（generator_torch.py:22，自述"Torch-only on-the-fly generator using precomputed H/p/A"）是 surface 主力；`MultiQCDataGeneratorTorch`（generator_torch_multi.py:31）多 patch 课程（公共面已禁）；`ColorQCDataGeneratorTorch`（generator_torch_color.py:55）是 color 版，contract（generator_torch_color.py:25）：`generate_batch(step, batch) -> (trainX, trainY)`，(B, 4, n_rounds, rows, cols) 落 CUDA；v1 限制"DEM 固定 p，扫 p 需多 bundle"。

**superbatch.py**（278 行）：`_BuiltSuperbatch`（superbatch.py:16）持 train_x/train_y/ready_event（CUDA event）；`SuperbatchBuffer`（superbatch.py:27）做一步-ahead 预取——`generate`（superbatch.py:188）有现成超批直接归还，同时 `_submit_locked`（superbatch.py:112）向另一 CUDA stream 提交下一批，`_wait_for_consumer`（superbatch.py:179）保证读完才覆盖。

**seed_layout.py**（70 行）：`check_seed_layout`（seed_layout.py:20）校验训验种子区间不重叠且不越 2^31 模。generator_torch_color.py:46-52 注释讲透防线：相邻 rank 种子流以 `RANK_STREAM_STRIDE=1_000_003`（generator_torch_color.py:52）隔开，三道闸各管一边。

## 三、外部连接

- 上游：qec/ 供电路与 DEM（generator_torch_color 直接 import `ColorMemoryCircuitTorch`）；precompute_dem 产出 H/p/A bundle。
- **勘误**：code/data/ 下并无 data_mapping.py；4 处函数体内延迟 import `SurfaceCode` 在 **qec/surface_code/data_mapping.py:197/316/441/532**，规避 data_mapping↔memory_circuit 环依赖。
- 下游：training/train.py 拿 generator 造批；run.py 的 data 任务打印 syndrome 形状冒烟。
- precompute_frames.py（60 行）是 legacy 遗迹：docstring（precompute_frames.py:18-21）自述 CLI 已被 augmented-DEM 管线取代；`_load_config_mapping`（L30，json→omegaconf→yaml 三级回退）与 `_load_noise_model`（L50，兼容三种嵌入位）两个 helper 被 precompute_dem 反向调用。

## 四、数据流

**训练线**：NoiseModel → qec 电路 → augmented-DEM bundle → generator 每 step `generate_batch` 在 GPU 出 (trainX, trainY) → SuperbatchBuffer 藏一步延迟 → 训练循环。p 在 bundle 固化、分布恒定。
**推理线**：MemoryCircuit → stim_circuit → `compile_sampler().sample(shots=N)`（datapipe_stim.py:101）→ detector 矩阵 → detector_input/data_mapping 折成 trainX → 前向 → 与 PyMatching/Chromobius 比 LER。color 线多一步 plaquette 映射（predecoder_transform.py，252 行）。
两线在 factory 汇合：train 返回 None、inference 返回 Dataset——同一接口两种供弹。

## 五、设计决策

1. **on-the-fly 优先**：错误样本采样廉价无重放价值，预生成数据集只占盘——训练线不建 Dataset。
2. **import 全在方法体内**（factory.py:82/151）：surface/color 管线互不连累，重依赖挡在 train 快路径外。
3. **双流预取**：CUDA event + 独立 stream 把"采样"与"消费"重叠，generate 的等待被摊平。
4. **种子三防**：步数预算防跨 rank 流、验证偏移防训验同源、2^31 模数防回卷——复现性按防线设计。
5. **legacy 壳保留**：precompute_frames 只删 CLI 留 loader，反向依赖不断链——渐进迁移的克制样本。

## 六、新人提示

- 看数据形状：`workflow.task=data` 打印每批 syndrome shape，不起训练。
- 排查复现问题先查 seed_layout 三道闸报错，再查 RANK_STREAM_STRIDE 是否被改。
- p 扫描实验记牢 color 生成器 v1 限制：一个 bundle 一个 p。
- 找 data_mapping 别在 code/data/ 翻——它在 qec/ 两码族子包下，4 处延迟 import 是环依赖活证据。
- from_stim_file 噪声指纹默认严格模式，换噪声重采样比关严格模式省事。
