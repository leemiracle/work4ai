# 10 · 用户入口三件套：cli.py mcp 子命令、mcp_server.py 与 .opencode 编辑器集成

## 一、角色定位

SkillSpector 对外三个人机入口：①`skillspector mcp`（cli.py:3114-3155 的 Typer 子命令）把扫描器变成 MCP server；②`src/skillspector/mcp_server.py`（285 行）是 server 本体——单个 `scan_skill` 工具，让任何 MCP-capable agent 或远端运行时**在装 skill 之前调用裁决**，从带外审计工具升级为运行时门禁；③`.opencode/` 编辑器集成（斜杠命令 + 两个 TS 文件共 590 行）把同一能力嵌进 OpenCode 会话，自带**与 Python 侧对等的权限边界**。三件套共享 graph 内核，差异全在传输层与信任边界。

## 二、内部结构

**cli.py 侧**：`TransportChoice` StrEnum（:140-144，stdio/http）；`mcp` 命令（:3114-3155）默认 stdio（:3124）、http 可配 host/port（默认 127.0.0.1:8000，:3125-3132）；函数体只是延迟 import + 转发（:3149-3152），`ModuleNotFoundError` 转 exit 2 并提示装 `skillspector[mcp]` extra（:3141-3155）。cli.py 全文 3245 行，mcp 与 scan/baseline 并列。

**mcp_server.py（核心）**：
- `run_scan`（:91-223）刻意与 mcp SDK 解耦（:22-25，无 mcp 依赖可单测）。五参：target/use_llm/output_format/allow_local_targets/yara_rules_dir。
- **本地目标闸**：`allow_local_targets=False` 时 `_is_local_target`（:70-88）判定 target 与 yara_rules_dir，file://、UNC、绝对路径、相对且存在 → 拒绝（:121-127）。判序：git@ 前缀明确远程（:75-76）、含 `://` 视为远程（:79-80）、其余走 Path 判定。
- **诚实 LLM 记账**：`is_llm_available` 预检（:129-130）；返回体带 `llm_requested/llm_available/llm_used/scan_mode`（:214-218，:117-119"绝不让调用方误以为跑了全扫"）。
- **safe_to_install 六条件门**（:193-200）：risk ≤ RISK_THRESHOLD、execution_successful、entirely_uninspected==0、partially_inspected==0、(is_complete 或 reference_caveat_only)、analysis_requirement_met。`reference_caveat_only`（:184-191）是精妙例外：账本异常全是 REFERENCE_MISSING（引用 bundle 外路径但**所有已发现文件都被检视过**，藏不了字节）时不挡安装；REFERENCE_UNRESOLVED（歧义引用）继续挡（注释 :176-183）。`analysis_requirement_met`（:192）：要 LLM 却没跑完就不许安装，recommendation 从 SAFE 降 CAUTION（:202-203）。
- `graph.ainvoke` 带遥测 metadata（:150-163）；finally 里 `cleanup_result`（:221-223）。
- `build_server`（:226-272）：FastMCP 构造，mcp 包缺失给精确重装指引（:232-243）；`@server.tool()` 注册 `scan_skill`（:247-270），docstring 即 agent 侧工具说明。
- `run`（:275-285）：**transport 决定信任边界**——stdio 给本地路径权限、http/streamable-http 拒绝（:277）。

**.opencode/ 集成**：
- `commands/skillspector.md`：斜杠命令，声明"static analysis by default"，`$ARGUMENTS` 传目标给 tools。
- `tools/skillspector_scan.ts`（24 行）：`tool()` 注册（:9），四参 schema——target 必填、format 默认 json、**noLlm 默认 true**（LLM 显式 opt-in，:14）、output 可选（:15）；execute 委托 executeScan 注入 fs 探针（:17-23）。
- `tools/skillspector_scan_lib.ts`（566 行，纯函数库，零 plugin 依赖可跑 `node --test`，:1-2）：
  - 常量：TIMEOUT_MS 120s / MAX_STDOUT 12000 / MAX_STDERR 6000（:6-8）；`CREDENTIAL_ENV_NAMES` 14 个凭据 env 白名单（:22-37，注释："读任意 *_KEY 会扩大宿主数据边界"）。
  - `redact`（:44-66）：已知凭据值正则替换 + 三类模式兜底（sk-ant-/sk- 前缀、KEY/TOKEN 赋值形）。
  - 目标分类：`isScpGitTarget`（:68-74，git@host:owner/repo.git 窄正则）、`isRemoteTarget`（:76-87，仅 https:// 与 scp 算远程——任意 scheme 当远程会误把本地文件名变成网络权限请求，:83-85）、`isFilesystemRoot`（:96-104）。
  - `resolveBinary`（:112-128）：SKILLSPECTOR_BIN > 仓内 .venv > PATH 三级回退。
  - `buildCliArgs`（:137-146）：宿主可能吞默认值，库内**重申 noLlm=true**。
  - `childProcessEnv`（:269-279）：剥全部 `LANGCHAIN_/LANGSMITH_` 变量——tracing 在 LLM 关闭时也会上传 graph 输入（:271-273）。
  - `llmPermissionMetadata`（:376-403）：按 provider 映射 egress 目的地（CLI 家标 local-*-cli），供权限展示。
  - `buildPermissionRequests`（:405-490）：远程目标→webfetch；本地目标→read（越 session 目录加 external_directory）；output→edit；LLM 开启→`skillspector-llm:{provider}:{destination}:{model}` 一次性 webfetch（always 空，:456-469）；绝对路径二进制→external_directory；最后 `bash: {bin} scan *`（:482-488）。
  - `executeScan`（:492-566）：解析绝对路径→逐个 ask（**拒绝异常故意不捕获**，:530-533）→ 三处 `assertNoSymlinkedPath`（:535-551，output/本地 target/二进制逐分量 lstat——InputHandler 也拒 symlink，这里在进程启动前执行同一边界，防权限授予被改道，:538-542）→ execFile（120s/32MB/剥 tracing env）→ `formatExecError`（:168-201，**exit 1 且有输出=风险报告而非崩溃**，:192-195）/`formatSuccess`（:203-218）。

## 三、外部连接

mcp_server 上游：graph.ainvoke、effective_findings（suppression）、ANALYZER_MODULES×semantic_runtime（:41-42, :53-67）、RISK_THRESHOLD、LedgerReason。下游：FastMCP（mcp extra）、cli.py mcp 子命令。.opencode 线与 Python 线经 **skillspector CLI 子进程**连接（非 import）——exit code 语义（1=超阈/2=用法错）被 formatExecError 消费；tests/opencode/*.test.ts 验纯函数层，tests/unit/test_mcp_server.py 验 server 层。

## 四、数据流

MCP 路径：agent 调 scan_skill → run_scan → 本地目标闸（http 下拒绝）→ LLM 预检 → graph.ainvoke → 结果装配（suppression/六条件门/诚实记账）→ verdict 回 agent。OpenCode 路径：`/skillspector ./x` → executeScan：权限 ask 序列 → symlink 三查 → 子进程 `skillspector scan ./x --format json --no-llm` → stdout 截断+脱敏 → 回会话；LLM opt-in 多一道 provider/destination/model 粒度的 egress 权限。

## 五、设计决策

1. **传输层定信任**：同一 run_scan，stdio 给本地路径、http 拒绝（mcp_server.py:277）——远程调用面永远更小。
2. **safe_to_install 是"完备性门"而非"分数门"**：五个附加条件全在防"没看到的部分藏恶意"（未检视文件、歧义引用、LLM 没跑完）；REFERENCE_MISSING 豁免给出"藏不了字节"的安全证明——例外也要论证。
3. **LLM 记账诚实**：静态低分不冒充全扫低分——四字段记账+降级双保险。
4. **TS 侧边界对等复刻**：窄正则远程分类、symlink 前置拒绝、凭据白名单、tracing env 剥离——Python 核心防什么编辑器壳就防什么，纵深而非替代。
5. **exit 1 = 报告不是错误**：非零退出码语义被 TS 侧正确翻译，不把"扫出风险"显示成"扫描失败"。

## 六、新人提示（坑与勘误）

- **mcp 子命令不带扫描参数**：只起 server（transport/host/port）；扫描参数在 agent 调 scan_skill 时给，shell 单发扫描用 `skillspector scan`。
- `build_server` 默认**拒绝本地路径**；只有 `run()` 的 stdio 分支翻 True。自建 FastMCP 嵌入时显式决策这一参。
- **`_is_local_target` 的存在性判定有细节**（:88 `candidate.exists()`）：不存在的相对路径会被当"非本地"放行——语义是"存在的相对路径才算本地"。
- .opencode/ 下只有两个 TS 文件（scan.ts 注册 + scan_lib.ts 纯函数）；知识图谱曾列 `skillspector.ts`，盘上不存在。
- TS 库 `redact` 只替换 ≥4 字符的凭据值（:47）——更短的会漏进输出，取舍而非 bug。
- `isProvenUsageError` 需 stderr 同时含 "Usage:" 与 Error/Try--help（:164-166）——只有 Usage 行不算用法错。
- 安装法是把 `.opencode/` 拷进目标项目或 `~/.config/opencode/`（OPENCODE_EXTENSION.md）；二进制找不到时给 uv tool install 提示（lib :9-10）或 SKILLSPECTOR_BIN 指路。
