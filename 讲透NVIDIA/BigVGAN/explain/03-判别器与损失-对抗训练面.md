# 03 · discriminators.py + loss.py——对抗训练面

## 角色定位

discriminators.py（651 行九类）给 GAN 训练供"真伪判别信号"，loss.py（254 行）供"重建+对抗"两类目标。组合决定世代差异：v1 = MPD+MRD+单尺度 mel L1；v2 = MPD+CQTD+多尺度 mel（配置键 `use_cqtd_instead_of_mrd`，train.py:85-89 分派）。两文件都是"上游引用集大成"：MPD 源自 HiFi-GAN（discriminators.py:4）、MRD 源自 UnivNet、MBD 源自 descript/vocos（discriminators.py:280-281）、CQT 源自 Amphion（discriminators.py:406）。

## 内部结构

**四族判别器**，全部输出 `(logits, fmap)` 二元组供特征匹配：
- `DiscriminatorP`（discriminators.py:21）：把波形按 period 重排成 2D（reflect 补齐，discriminators.py:93-97）过 5 层 Conv2d；`MultiPeriodDiscriminator` 并联周期 [2,3,5,7,11]（discriminators.py:110-120，周期表来自 config `mpd_reshapes`）。
- `DiscriminatorR`（discriminators.py:143）：先手工 STFT 取幅度谱（discriminators.py:225-244，`torch.norm(p=2)` 取模长），再 5 层 (3,9) 卷积；`MultiResolutionDiscriminator`（discriminators.py:247）锁三组分辨率 [[1024,120,600],[2048,240,1200],[512,50,240]]（config `resolutions`）。支持 `mrd_use_spectral_norm`/`mrd_channel_mult` 覆盖（discriminators.py:154-164）。
- `DiscriminatorB`/`MultiBandDiscriminator`（discriminators.py:283/367）：复数谱按频带切 5 段各自卷积再拼回（discriminators.py:307/341）；MBD 在**九配置中零启用**（`use_mbd_instead_of_mrd` 无人置真）。
- `DiscriminatorCQT`（discriminators.py:408）：外部 `nnAudio.CQT2010v2` 做 Constant-Q（discriminators.py:428-437），且**先 2x 上采样再 CQT**（Resample fs→2fs，discriminators.py:506/533），幅度+相位双通道（discriminators.py:537-541），逐八度 pre-conv 后拼接（discriminators.py:544-555）；`MultiScaleSubbandCQTDiscriminator`（discriminators.py:568）三尺度 hop [512,256,256]（discriminators.py:581）。

**损失**（loss.py）：`MultiScaleMelSpectrogramLoss`（loss.py:23）7 组 (n_mels 5→320, window 32→2048)（loss.py:55-56），namedtuple STFTParams 管参数（loss.py:71-84），lru_cache 缓存窗与 mel 基（loss.py:95-106），自实现 mel_spectrogram（loss.py:108-165，与 meldataset.py 独立）；`feature_loss` L1 均值×2（loss.py:223）；LSGAN 式 `discriminator_loss`（(1-dr)²+dg²，loss.py:233-236）与 `generator_loss`（loss.py:249-252）。

## 外部连接

train.py:27-38 导入两文件全部公共符号；mel 损失权重 `lambda_melloss` 默认 45（v1）、v2 配置 15（train.py:526-532）；auraloss 的 MR-STFT 只用于验证（train.py:292）。

## 数据流

每步先 D：真波形 y 与 detach 的假波形 y_g_hat（train.py:489/495）各过 MPD+MRD/CQTD → LSGAN 判别损失 → clip_grad_norm → step；再 G：同一前向不 detach，取 fmap 做特征匹配 + logits 做对抗项 + mel 项（train.py:535-547）。

## 设计决策

① 判别器吃**波形域**（P/CQT）与**谱域**（R/B）互补——谱域天然对相位不敏感；② CQT 的 2x 上采样把时频分辨率平移一个八度，等价于在更低频段获得更细 bin；③ v2 弃 MRD 用 CQT：常 Q 对数的频带对齐适配音乐/环境声（v2 目标数据更杂）；④ mag/log 双权重默认 (0,1)——只训 log 域更稳。

## 新人提示

`CombinedDiscriminator` 属性名拼写为 `self.discrimiantor`（discriminators.py:630），且该类与 MBD 在仓内无消费者——当"存在但未接线"读。loss.py:208 的 mag_weight 项误用了 log-mel（应为原始 mel，默认权重 0 不触发，详见勘误 #2）。调 CQT 超参只认 `cqtd_*` 前缀键（discriminators.py:574-585 全带默认值）。
