# 精讲三：数据管线与特征预计算——从目录约定到 TRT 推理轴

## 角色定位

本篇覆盖 data/ 包、两个特征脚本与推理出口：AlignedDataset 决定「模型看到什么」，encode_features.py 与 precompute_feature_maps.py 决定「实例特征从哪来」，test.py+run_engine.py 构成三条推理轴。四个部件合成 pix2pixHD 的数据面全图。

## 内部结构

AlignedDataset（data/aligned_dataset.py:6）按后缀目录约定组织输入：_label/_img/_inst/_feat 四路（feat 目录仅 --load_features 时挂载，data/aligned_dataset.py:28）。__getitem__（data/aligned_dataset.py:35）的双 transform 分支是全仓最重要的约定：label 走 NEAREST 插值、不归一化（data/aligned_dataset.py:44）再乘 255 保留类别索引（data/aligned_dataset.py:45）；真实图走默认 BICUBIC 加 [-1,1] 归一化（data/aligned_dataset.py:52）。instance 图复用 label 的 transform_A（data/aligned_dataset.py:59），预计算特征图再过 normalize（data/aligned_dataset.py:64）。crop/flip 参数由 get_params 一次抽取（data/aligned_dataset.py:39），保证三路空间对齐。

## 外部连接

加载链两层延迟 import 破循环依赖：CreateDataLoader 在函数体内引 CustomDatasetDataLoader（data/data_loader.py:3），CreateDataset 再引 AlignedDataset（data/custom_dataset_data_loader.py:7）——data 包因此得以自引用闭环。特征脚本消费模型侧实现：encode_features.py:31 调 model.module.encode_features（实现在 models/pix2pixHD_model.py:240，取实例中心像素特征 models/pix2pixHD_model.py:254，附面积占比 models/pix2pixHD_model.py:258）；precompute_feature_maps.py:29 直前向 netE。--load_features 打开后训练直接读 _feat 目录 png（data/aligned_dataset.py:28）。

## 数据流

特征两段管线：第一段 encode_features.py 强制单线程单批不翻转（encode_features.py:8）遍历全数据集聚成 per-label 特征表，KMeans 聚类时过滤面积占比大于 0.5 的实例（encode_features.py:47）、簇数取 min(样本数, n_clusters) 保护（encode_features.py:49），落盘 features_clustered_%03d.npy（encode_features.py:52）。第二段把特征图上采样 2 倍存成 png（precompute_feature_maps.py:30），保存路径把 train_label 替换为 train_feat（precompute_feature_maps.py:32）。推理轴三开关分流（test.py:26）：--engine/--onnx 走延迟导入的 run_engine（test.py:36）；--export_onnx 导出后立即 exit(0)（test.py:50）；默认走 model.inference（test.py:59）。

## 设计决策

NEAREST×255 约定与 one-hot scatter（models/pix2pixHD_model.py:119）配对——破坏它会让标签静默错位。特征图当图像存是有损取舍：feat_num 维 float 存 png 须经量化，换来 1024p 训练免在线编码。run_engine.py 是 TRT 3.x 时代化石：trt.infer.ConsoleLogger（run_engine.py:33）、onnxparser 的 create_onnxconfig（run_engine.py:140），且 range(iter)（run_engine.py:115）、max_batch_size/max_workspace_size（run_engine.py:157）、run_onnx 末行的 engine（run_engine.py:173，应为 trt_engine）三处未定义名在现代环境下必然 NameError。

## 新人提示

两个特征脚本都是顶层直跑、无 main 守卫（encode_features.py:7 起即解析参数并硬改 opt），改配置要么动命令行要么动文件头。复现顺序：先 encode_features 再 precompute_feature_maps，聚类文件名要与 --cluster_path 默认值 features_clustered_010.npy 对上。不要在现代 TensorRT（5+）上试 run_engine.py——旧 API 已全部移除；TRT 路线实为历史实验，主线推理以 test.py:59 为准。
