# Third-Party Software

The Game Agent SDK distribution includes the third-party components enumerated below, grouped into three categories:

- **Open-source components** vendored or linked under `external/` (items 1-12).
- **NVIDIA proprietary redistributables** under `external/cuda-runtime/` (item 13), distributed under the NVIDIA CUDA EULA. Not open source.
- **Bundled model artifacts** under `data/models/` (items M1-M4), each under its upstream model-card terms.

The Apache 2.0 license in the repository root (`LICENSE.txt`) covers only NVIDIA-authored SDK code. Each component listed below is redistributed under its own license; the Apache 2.0 license does not extend to bundled binaries, proprietary redistributables, or model artifacts.

## NVIDIA Proprietary Redistributables

#### 13. NVIDIA CUDA Runtime Redistributables (CUDA 12.8)

- **Files:** `external/cuda-runtime/bin/cudart64_12.dll`, `cublas64_12.dll`, `cublasLt64_12.dll`. These are copied into `_out/` by an `ACE.SDK` postbuild step so the sample executables can resolve them at runtime, and packaged into the release zip's `bin/`.
- **Component versions:** CUDA Runtime 12.8.57, cuBLAS 12.8.3, cuBLAS Light 12.8.3 (from each DLL's embedded FileDescription).
- **Why bundled:** The SDK's vendored llama.cpp build (`external/llamacpp/bin/release/ggml-cuda.dll`) is dynamically linked against `cudart64_12.dll`. Bundling the matching runtime alongside the executables means end users only need an NVIDIA display driver; they do not need to install a CUDA Toolkit themselves.
- **License:** NVIDIA Software License Agreement (the CUDA EULA). Section 1.6 / Attachment A of the CUDA EULA expressly permits redistribution of these specific runtime components. This is not an OSS license; it is a redistribution permission grant from NVIDIA. Full EULA text at https://docs.nvidia.com/cuda/eula/index.html .

## Bundled Models

The Game Agent SDK redistributes the following upstream open-source models under `data/models/`. Each model is distributed under the upstream license listed below; refer to the linked model card for the full license text, citation requirements, and intended-use notes.

Where the bundled file is a format-converted or quantized version of the upstream tensors, the conversion was performed mechanically using unmodified upstream tools. No weights were trained, added, removed, or manually edited, and no architecture, tokenizer, or chat-template changes were made.

#### M1. [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)

- **File:** `data/models/miniLM/all-MiniLM-L6-v2.F32.gguf`
- **Purpose:** English text embeddings for RAG semantic search
- **Source:** `sentence-transformers/all-MiniLM-L6-v2` on HuggingFace
- **Upstream attribution:** Built on the pretrained `nreimers/MiniLM-L6-H384-uncased` base model and fine-tuned by the sentence-transformers project on a corpus of ~1.17B training tuples (MS MARCO, S2ORC, Reddit, WikiAnswers, PAQ, and others). Developed during the Hugging Face / Google JAX/Flax community week.
- **Citation:** No canonical citation is provided in the upstream model card. See the linked model card for the latest recommended reference.
- **License:** Apache License 2.0 (full text under M4 below)
- **NVIDIA modification:** Upstream tensors mechanically converted to GGUF (F32 precision) using unmodified upstream `llama.cpp` tools

---

#### M2. [ms-marco-MiniLM-L6-v2 (cross-encoder)](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L-6-v2)

- **File:** `data/models/miniLM/cross_encoder_ms-marco-MiniLM-L6-v2.onnx`
- **Purpose:** Cross-encoder reranker for RAG retrieval results
- **Source:** `cross-encoder/ms-marco-MiniLM-L-6-v2` on HuggingFace
- **Upstream attribution:** Base model is `microsoft/MiniLM-L12-H384-uncased`; trained by the sentence-transformers project on the `sentence-transformers/msmarco` dataset (derived from Microsoft's MS MARCO Passage Ranking task).
- **Citation:** No canonical BibTeX citation is provided in the upstream model card. See the linked model card for the latest recommended reference.
- **License:** Apache License 2.0 (full text under M4 below)
- **NVIDIA modification:** Upstream tensors mechanically converted to ONNX using unmodified upstream tools
