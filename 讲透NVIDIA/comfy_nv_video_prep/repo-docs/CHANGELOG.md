All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-03-03

### Added

- **VideoPrep Interactive Crop** — Interactive image cropping with draggable rectangle, live preview, simultaneous image + mask cropping, grid snapping
- **VideoPrep Preview Bridge** — Robust image/mask pass-through with premultiplied alpha, multiple output and preview modes
- **VideoPrep Preview Bridge (Advanced)** — Built-in persistent mask editor with brush/erase, Cut/Keep/Extend modes, alpha channel import
- **VideoPrep TTM Interactive Editor** — Click-to-segment with SAM2, polygon editing, multi-layer keyframe animation, background animation
- **VideoPrep TTM Compose & Animate** — Multi-layer compositor with up to 4 subjects, per-layer keyframe transforms, background pan/zoom/rotate
- Apache 2.0 license
- NVIDIA standard repository structure (CODE_OF_CONDUCT, SECURITY, SUPPORT, GOVERNANCE)
- Example workflows
- THIRD_PARTY_NOTICES for runtime dependencies
