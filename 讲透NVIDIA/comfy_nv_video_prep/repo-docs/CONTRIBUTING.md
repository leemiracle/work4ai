# Contributing to ComfyUI_VideoPrep

**This project is currently not accepting any external contributions.**

ComfyUI_VideoPrep is developed and maintained internally by the NVIDIA AWD team.
All source code in this project is original NVIDIA-authored work. No third-party
code is included.

## Bug Reports and Feature Requests

While we do not accept code contributions, we welcome:

- **Bug reports** — File an issue using the bug report template
- **Feature requests** — File an issue using the feature request template

## Code of Conduct

All participants in this project are expected to follow our
[Code of Conduct](CODE_OF_CONDUCT.md).

## Security

If you discover a security vulnerability, please follow the process described
in [SECURITY.md](SECURITY.md). **Do not file public issues for security reports.**
