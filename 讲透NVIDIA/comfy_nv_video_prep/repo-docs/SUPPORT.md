# Support

## Support Level

**Experimental** — This project is provided as-is for research and prototyping purposes.

## How to Get Help

- **Bug Reports:** File an issue using the bug report template
- **Feature Requests:** File an issue using the feature request template
- **Questions:** File an issue using the general question template

## Response Expectations

This project is maintained by the NVIDIA AWD team on a best-effort basis.
There are no guaranteed response times or SLAs for issue resolution.

## Scope of Support

This project provides ComfyUI custom nodes for video preparation workflows.
Support is limited to:

- Node functionality and usage within ComfyUI
- Installation and setup issues
- Bug reports with reproducible steps

Out of scope:

- General ComfyUI support (see [ComfyUI documentation](https://github.com/comfyanonymous/ComfyUI))
- Third-party custom node compatibility
- Hardware-specific issues
- Training or fine-tuning models
