# 02 · 布局推断族（ir/layout 全族 67 文件）

## 1. 角色定位

布局（Layout）回答一个问题：**张量的每个元素放在哪、归哪个线程管**。tilus 把它做成三大 dataclass + 一套自动推断引擎，是全仓的"灵魂子系统"（图谱 L04 层，67 个文件）。设计动机直接来自 README 的卖点"显式控制 shared memory 与寄存器"——显式控制不等于让用户手写排布，而是**推断默认、允许覆盖**：用户可以用 `self.annotate_layout` 标注期望布局（前端落在 `AnnotateLayoutInst`，`python/tilus/ir/instructions/hints.py:26`），其余全部自动补全。思想承自 Hexcute（`python/tilus/ir/layout/__init__.py` 模块摘要明言）。

## 2. 内部结构

**三大布局中枢**：
- `RegisterLayout`（`python/tilus/ir/layout/register_layout.py:35`，491 行）＝ local × spatial × replicated 的代数结构：spatial 声明"哪些线程各持哪些元素"（构造器 `spatial()`，`python/tilus/ir/layout/ops/register_ops.py:29`）、local 是每线程的私有维（:65）、replicated 是跨线程复制（:101）；其上有完整代数闭包——compose（:231）、permute、reshape、divide、left_divide 等 19 个函数共 975 行（register_ops.py 是布局的"词汇表"，推断规则与发射器共用）；
- `SharedLayout`（`python/tilus/ir/layout/shared_layout.py:88`）+ Swizzle（:30）：共享内存 stride 代数，swizzle 模式计算在 `shared_row_major_swizzle`（`python/tilus/ir/layout/ops/shared_ops.py:283`）——bank conflict 消除的数学核心；
- `GlobalLayout`（`python/tilus/ir/layout/global_layout.py:25`）：纯 shape+strides。

**推断引擎三层**：协议层 `LayoutInferenceRule`（静态 `inference` 方法，`python/tilus/ir/layout/inference/rule.py:56`）与 `LayoutValidationRule`（静态 `validate`，:37）——注意**没有 forward/backward 双向协议**（图谱摘要此处失实，见勘误），一个指令类型可注册多条推断规则（`_inference_rules` 是 defaultdict(list)，python/tilus/ir/layout/inference/rule.py:92），`register_rule`（:100）注册、`get_inference_rules`（:115）/`get_validation_rule`（:134）查找。规则层 `inference_rules/` 27 文件 45 个 Rule 类，逐指令定制：MmaDotRule（`python/tilus/ir/layout/inference/inference_rules/mma_dot.py:24`）按 TensorCore 碎片约定推 A/B/C 三操作数布局——matmul 性能的命脉规则；LoadStoreGlobalRule 族（`python/tilus/ir/layout/inference/inference_rules/ldst_global.py:25,93,103`）推导寄存器布局与全局地址的对应并施加向量化宽度约束；BinaryRule（`python/tilus/ir/layout/inference/inference_rules/elementwise_binary.py:22-28`）令双操作数与输出共享同一布局；EmptyRule（`empty_rule.py`）给同步类无输出指令做占位，统一分发免特判。算法层 `infer_layout`（`python/tilus/ir/layout/inference/inference.py:160`，345 行）。

## 3. 外部连接

上游：tilus pass 管线里 `LayoutInferencePass`（`python/tilus/transforms/layout_inference.py:69`）先跑 `ApplyLayoutAnnotationRewriter`（:26）应用用户标注，再调主算法；默认 12 pass 序列里它出现两次（`python/tilus/transforms/__init__.py:31` 的 get_default_passes——lower_load_store 前后各一）。横向：CUTLASS 互操作层 `python/tilus/ir/layout/utils/cute.py` 做 CuteLayout/CuteSwizzle 双向翻译；tcgen05 硬件约定的对接层是 `CanonicalSharedLayout`（`python/tilus/ir/layout/cuda/tcgen05/smem.py:75`，CUTLASS 风格原子网格）+ `canonicalize_shared_layout`（:166）与 `generate_canonical_layout`（:307）双向转换；`ldst.py` 的 `get_ldst_layout` 按 tcgen05 访存参数推 TMEM↔SMEM 排布。下游：发射器直接消费布局——如 `DotInstEmitter.resolve_mma_config` 用布局除法 `p / q` 匹配 MMA 配置（`python/tilus/backends/emitters/cuda/mma_dot.py:41-47`），wgmma 发射器从 canonical 布局取 LBO/SBO（`python/tilus/backends/emitters/cuda/wgmma.py:169-177`）。

## 4. 数据流（推断主算法解剖）

`infer_layout`（python/tilus/ir/layout/inference/inference.py:160）的循环：**step 0** 预检——所有缺布局指令必须已有注册规则且规则必须出现在全局序表里，否则直接抛 `LayoutInferenceError`（:193-220 列出违规清单）；**step 1-2** 收集仍有缺布局张量的指令，为空即返回（不动点）；**step 3** 把 (指令, 规则) 对按三元组排序——已定布局的指令优先、规则全局序小者优先、程序中靠后的指令优先（`pair_sort_key`，python/tilus/ir/layout/inference/inference.py:246-253）；**step 4** 按序尝试，**每轮只应用第一条成功的规则**：拿 mapping → 校验形状一致 → `tensor.with_layout(layout)` 重写整个函数（:276-289）→ 回到 step 1。一轮下来无任何规则可用即失败（:303-322），报出全部卡死的张量与完整函数 IR——绝不静默给默认布局。规则全局序是手工调优的优先级表 `inference_order`（`python/tilus/ir/layout/inference/order.py:56`，编译进 `rule2order`:90）：TMEM/tcgen05 组最前 → SliceRegister/MmaDot/WgmmaMmaSS → 元素级 → 全局访存 → 变换类 → 共享内存组殿后——本质是"硬件约束最强的先落子，自由度大的后补"。

## 5. 设计决策

**约束传播而非求解**：布局推断是约束满足问题的贪心版本——MMA 碎片这类硬约束先固定，元素级指令的"跟随"约束后传播，避免通用求解器的复杂度。**规则可多条而非单条**：同一指令在不同上下文（如 load_shared 的 ldmatrix 路径 vs 普通路径，`inference_rules/load_shared.py` 拆成 4 条规则）给出不同推导，由优先级序裁决。**失败要响亮**：推断不动点卡死时抛出带全量 IR 的错误，定位体验优先。**canonicalize 收尾**：`canonicalize_layout`（python/tilus/ir/layout/register_layout.py:471）做 singleton/contiguous 规范化（:345,:373），保证语义相同的布局只有一种表示——这是布局可哈希、缓存可命中的前提。**布局代数做成函数库而非方法**：ops/ 下的 compose/permute 是自由函数，规则作者与发射器作者共用一套词汇，避免 OO 方法爆炸。

## 6. 新人提示

- 入门顺序：先读 `docs/source/programming-guides/layout-system/register-layout.rst`（370 行代数详解）→ `rule.py`（150 行，协议极简）→ `inference.py` 主算法 → 任一条具体规则（`assign.py` 22 行最小）。
- 新增指令必须同步三处：IR 指令类、`inference_rules/` 规则、`order.py` 全局序——漏登 order.py 会在 step 0 预检就报 "not specified in the rule order list"（python/tilus/ir/layout/inference/inference.py:203）。
- 调试布局：`visualize_layout`（`python/tilus/ir/layout/ops/utils.py` + python/tilus/ir/layout/register_layout.py:284）把布局渲染成表格；docs 自带 1934 行的交互式布局演示 `docs/source/_static/layout-demo/layout-demo.js`。
- 布局运算是代数不是数值：`p / q` 表示"p 可分解为 q×外层"（LayoutOperationError 表示不可整除），初见易误读为元素除。
- SharedLayout 的 swizzle 不是简单转置——`shared_row_major_swizzle`（python/tilus/ir/layout/ops/shared_ops.py:283）输出的是带模式的 stride 方案，对照 wgmma/tcgen05 的 swizzle 枚举（`python/tilus/hidet/ir/primitives/cuda/tcgen05.py:178` Tcgen05SwizzleMode）理解才完整。
