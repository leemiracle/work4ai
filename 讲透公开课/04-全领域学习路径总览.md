## 三、按时间预算的节奏校准

> 同一条路径，时间预算不同节奏差很大。下面是经验值。

| 时间预算 | 建议节奏 | 适合 |
|---------|---------|------|
| **30 小时**（一个月周末） | 一条路径的"入门段" | 试水、确认兴趣 |
| **100 小时**（三个月业余） | 一条路径的"入门 + 专精" | 转岗 / 副业项目 |
| **300 小时**（半年全职 / 一年业余） | 完整走完一条路径 | 转行 / 深度提升 |
| **1000 小时**（一年全职 / 两年深度业余） | 一条路径 + 跨第二条 | 成为领域专家 |
| **3000+ 小时**（多年） | 多路径 + 原创产出 | 研究者 / 创业者 |

**关键建议**：
- **不要囤课**：30 小时学一门 + 做完作业 > 100 小时刷 10 门课不做作业
- **作业 > 视频**：所有"有作业的课"（CS224n / CS285 / DLSys / 6.5840）必须做作业
- **输出倒逼输入**：每 100 小时产出一个东西（博客 / demo / PR / 复现）
