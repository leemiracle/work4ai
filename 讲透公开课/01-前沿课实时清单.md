## 二、核心「⚠️ 未抓 → 已核对」三门详解

### 1. DLSys (CMU 10-414/714) · Deep Learning Systems — 🟢 Fall 2025

> **核对要点**：确认最新一期是 **Fall 2025**（首课 2025-08-26）；讲师从纯陈天奇变为 **Tim Dettmers + 陈天奇（tqchen@cmu.edu）** 双 instructor。课程内核没变：5 个作业从零造一个叫 **Needle** 的深度学习库。

- **官网**：https://dlsyscourse.org/
- **最新版本**：Fall 2025（下一期预计 Fall 2026）
- **讲师**：Tim Dettmers（QLoRA/局部可用量化作者）、陈天奇（TVM/MXNet/XGBoost 作者）
- **讲什么**：自动微分 → NDArray（CPU/CUDA 后端）→ CNN/RNN/Transformer 实现，最后做 final project 给 Needle 加新特性
- **作业（HW0–HW4）**：
  - HW0 softmax 回归（前置自测）
  - HW1 自动微分框架
  - HW2 神经网络模块 + 优化器
  - HW3 NDArray 库（CPU + CUDA 后端）
  - HW4 卷积、RNN、高级架构
- **视频**：最新一期无新录像，看 **2022 版 YouTube**（仍是金标准）
- **前置**：会系统编程（15-213 级别）、线代、Python/C++、基础 ML
- **官方 AI 政策**：可用 ChatGPT/Copilot，但建议**裸做 HW0** 确认地基
- **对应「讲透」系列**：`讲透PyTorch`（自己造框架）+ `讲透GPU与系统级`（CUDA/autodiff）+ `讲透优化器`（AdamW 实现）
- **一句话**：想知道「PyTorch 内部到底怎么跑的」、想真正懂 autograd/CUDA，这是全球唯一一门。

## 五、推荐学习路径（串到本仓库「讲透」系列）

本仓库已有 6 个讲透系列 + 1 个总纲。下面是「**公开课 ↔ 讲透系列**」怎么配合最高效：

```
零基础入门
  ├─ MIT 6.S191 (2026)        → 全系列导览，8 周建立直觉
  └─ 李宏毅 ML (2025春)        → 中文配套，作业跟前沿
        │
        ▼
打地基（往底层钻，对应本仓库已写好的系列）
  ├─ 讲透激活函数   ← Karpathy Zero to Hero L1-L4
  ├─ 讲透反向传播   ← Karpathy micrograd + CS231n 反向传播笔记
  ├─ 讲透基础模型   ← CS224n Winter 2026 + 李宏毅 Pretrain
  └─ 讲透PyTorch/GPU ← DLSys (Fall 2025) HW1-HW3
        │
        ▼
调能力 / 用能力（后训练 + 推理时）
  ├─ 讲透微调      ← CS224n Post-training + 李宏毅 HW5-7
  ├─ 讲透Prompt    ← CS224n PEFT/Reasoning + fast.ai
  ├─ 讲透RAG       ← CS224n Agents/RAG + 李宏毅 HW1-2
  └─ 讲透Agent     ← CS285 Spring 2026 LLM RL + 李宏毅 AI Agent
        │
        ▼
深水区（自己造轮子）
  ├─ 讲透优化器     ← DLSys HW2 + fast.ai Part 2
  ├─ 讲透生成模型   ← fast.ai Part 2（DDPM→Stable Diffusion）
  └─ 讲透Transformer ← Karpathy nanoGPT + CS224n L5
```

**一句话策略**：公开课负责**广度和前沿更新**，本仓库「讲透」系列负责**把单个概念往底层钻透**。两者交叉验证，不要只看一个。
