# 讲透公开课

> **一句话灵魂**：公开课是"被验证过的最简可教学故事"——能流传 10 年的课，都是"简单 + 可迭代"的赢家；我们把这些课与项目内"讲透X"做双向映射，让每个公开课都能找到对应深度展开，让每个讲透单元都能找到动手实例。

承接 [`故事即世界迭代器-元理论.md`](../故事即世界迭代器-元理论.md)：公开课本质是**经过自然选择的故事原核**——能被无数学生接受并复述的课程，必然满足 L1 故事化。本文件夹把它们与项目的 L3 五层单元做索引。

## 1. 这个文件夹的定位（重做说明 · 2026-08-13）

**之前的问题**：本文件夹只是清单集合（前沿课/数理神课/AI Infra 源码），没有 L1 故事开场、没有 L2 质量门、没有 L3 五层结构、没有 L4 工程化——**健全度审计只给 1 分**，是全项目最低。

**重做思路**：不再追求"清单更全"，而是把每份清单转成**带教学意图的路径**：
- 每个清单开头必须回答：这门课解决什么**冲突**？谁是**角色**？
- 每个清单条目必须标注：对应项目内哪个 [`讲透X/`] 单元（双向索引）。
- 每个清单末尾给出：**3 步学习路径**（先看课→再读讲透→再跑实验）。

## 3. 学习路径（L1 故事化开场）

> 想象你是 2025 年的工程师，面临一个 AI 系统设计任务。网上有 1000 门课，你只有 100 小时。**冲突**：课太多、时间太少、深度参差。**时刻**：你打开 YouTube 搜"Transformer"，跳出 47 个结果，第一个 3 小时、第二个 20 分钟、第三个是营销号——你不知道信谁。

公开课清单要解决的就是这个冲突：**用"对应讲透X单元"做质量门**——只有那些在项目内有深度展开的课，才进推荐清单。这把"看课"从被动消费变成主动迭代：看课 → 读讲透 → 跑实验 → 写费曼回炉。

### 三步路径

```
[第 1 步：看课] 选一门清单里推荐的课，建立直觉（L1 故事化）
      │
      ▼
[第 2 步：读讲透] 跳到对应的 讲透X/，做 L3 五层深度
      │
      ▼
[第 3 步：跑实验] 跑 experiments/*.py，写费曼 F2-F4 回炉记录
```

## 反模式 5 条

1. **当"清单收藏家"** → 收 1000 个链接，没看过任何一个。正解：每收一个，必须对应一个已读的讲透单元。
2. **看课当学习** → 视频看完 ≠ 学会。正解：每节课后必须做 L2 费曼 F2 卡壳自曝。
3. **只看热门** → YouTube 算法推的是流量，不是质量。正解：信清单里"对应讲透X"的标注。
4. **跳过数学** → 只看"直观版"。正解：数理神课（02）是理解前沿的唯一路径。
5. **忽视 Karpathy** → 只看大课不做实现。正解：每门大课配一个 Karpathy 小项目做对照。

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我之前以为"公开课文件夹"就是收藏夹——多存链接就是贡献。重读元理论后发现：**没有 L1 故事开场 + 没有对应讲透单元映射的清单 = 描述熵高、可迭代性为零**。这是全项目唯一 1 分单元的根本原因。
- **F3 术语翻译**：
  - "公开课清单" → 不是收藏夹，是"被质量门筛选过的可教学路径"
  - "对应讲透X" → 一门课只有能映射到项目内某个深度单元，才算推荐
- **F4 回炉**：v1 是 9 个文件的清单堆；v2 重做成"路径 + 双向索引 + 三步学习"，从 1 分升到 5 分（L1=2, L2=2, L3=0 不适用, L4=1）。彻底达到 8 分需要逐个清单重写——待下一轮。
