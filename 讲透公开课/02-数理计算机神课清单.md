## 二、数学篇

> **为什么数学放在最前**：AI 里所有"调不通、不收敛、维度错、显存爆"的根，90% 是线代/概率/优化没打牢。Strang 18.06 + Stat 110 是底线，绕不过。

### M1. MIT 18.06 Linear Algebra — 🟡 长期稳定（永远推荐）

- **官网**：https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/
- **讲师**：Gilbert Strang（MIT 传奇，2023 年 retire 但课永存）
- **版本**：Strang 的 2010 Spring 录像是全球公认金标准；MIT 现已由 Anna Gilbert 等接手讲，但**入门就看 Strang 版**
- **核心**：矩阵消元 → 四个基本子空间 → 正交 → 行列式 → 特征值/特征向量 → SVD
- **配套书**：《Introduction to Linear Algebra》第 6 版（2023）
- **前置**：基本无（高中代数即可）
- **一句话**：全球学过线代的人，多半是 Strang 教的；这是数学公开课的"圣经"。

### M2. MIT 18.065 Matrix Methods in Data Analysis — 🟢 2024（Strang 最新）

- **官网**：https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/
- **讲师**：Gilbert Strang（退休前的最后一波系统录像，2024 版 OCW 重新挂出）
- **核心**：从 18.06 直接到 ML 用得上的——**SVD / PCA / 梯度下降 / 卷积 / Fourier / 低秩近似 / 推荐系统**
- **配套书**：《Linear Algebra and Learning from Data》（2019）
- **前置**：18.06 或等价线代
- **对应「讲透」系列**：直接对应未来 `讲透线代` 和 `讲透优化器` 的数学层
- **一句话**：Strang 亲自讲"线代怎么变成 ML"，看完对神经网络里所有矩阵运算的直觉会完全不一样。

### M3. Harvard Stat 110 Probability — 🟡 长期稳定

- **官网**：https://projects.iq.harvard.edu/stat110
- **讲师**：Joe Blitzstein（Harvard，概率教学界顶流）
- **视频**：YouTube 完整 2010 + 2021 + 2024 版（每年都重录）
- **配套书**：《Introduction to Probability》（Blitzstein & Hwang）全免费 PDF
- **核心**：条件概率 → 随机变量 → 期望/方差 → 大数律/中心极限 → 马尔可夫链 → **统计推断的入口**
- **前置**：微积分 + 一点线代
- **对应「讲透」系列**：`讲透反向传播`（概率视角）+ `讲透RAG`（检索概率）+ `讲透微调`（贝叶斯/不确定性）
- **一句话**：ML/AI 里所有"loss 是怎么来的""softmax 为什么这么设计""采样为什么有效"——根都在 Stat 110。

### M4. MIT 18.01 / 18.02 Calculus — 🟡 OCW 经典

- **官网**：https://ocw.mit.edu/courses/18-01-single-variable-calculus-fall-2006/ ；https://ocw.mit.edu/courses/18-02-multivariable-calculus-fall-2007/
- **讲师**：18.01 David Jerison / 18.02 Denis Auroux（Auroux 版是金标准）
- **核心**：单变量微积分 → 多变量 → 向量微积分 → Green/Gauss/Stokes
- **前置**：高中数学
- **一句话**：Auroux 的板书 + OCW notes，比绝大多数大学课本讲得清楚。

### M5. MIT 6.042J Mathematics for Computer Science — 🟡 韦顿

- **官网**：https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-fall-2010/
- **讲师**：Tom Leighton（Akamai 创始人，/MIT）、Marten van Dijk
- **核心**：证明技巧 → 数论/模运算 → 图论 → 离散概率 → 计数 → **密码学/算法的数学地基**
- **配套**：Lehman/Leighton/Meyer 合著讲义（500+ 页，比书还好）
- **前置**：基本无
- **一句话**：想读算法/CS 理论/密码学，这是地基中的地基。

### M6. MIT 18.330 Numerical Analysis — 🟡 notes 稳定

- **官网**：https://github.com/mitmath/18330
- **核心**：浮点数误差 → 解线性方程组 → 插值/积分 → ODE 数值解 → FFT → 优化
- **前置**：18.06 + 18.01/18.02 + 会 Julia/Python
- **一句话**：所有"数值不稳定""梯度爆炸""eps 设多少"的根都在这里。

### M7. 3Blue1Brown Math Series — 🟢 持续更新

- **官网**：https://www.3blue1brown.com/ ｜ YouTube 频道
- **代表作**：Essence of Linear Algebra / Essence of Calculus / Differential Equations / Neural Networks / **最近持续更新（2024-2025 仍在出）**
- **核心**：用动画把抽象概念变得"肉眼可见"
- **前置**：无
- **对应「讲透」系列**：`讲透激活函数`、`讲透反向传播`、`讲透注意力` 的最佳直觉先修
- **一句话**：先看 3B1B 建立直觉，再去看 Strang / Blitzstein 钻公式，效率最高。

## 三、物理篇

> **为什么 AI 工程师也要看物理课**：① 量子计算（QML）是下一波；② 扩散模型 = 反向随机微分方程，根在统计物理；③ 神经常微分方程直接来自数值 ODE；④ AI for Science（AlphaFold、AlphaFold 3、AI4Math、可控核聚变 ML）已经成主流。

### P1. MIT 8.01 / 8.02 Introductory Physics — 🟡 Lewin 现象级

- **官网**：8.01 https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/ ｜ 8.02 https://ocw.mit.edu/courses/8-02-physics-ii-electricity-and-magnetism-spring-2007/
- **讲师**：Walter Lewin（实验物理教学界的传奇，1999 版录像至今被反复推荐）
- **核心**：经典力学 → 电磁学（Maxwell 方程）
- **特点**：Lewin 亲自做危险实验（钟摆砸自己脸、电弧演示），现场感全网无竞品
- **前置**：高中物理 + 一点微积分
- **一句话**：物理直觉培养第一课，全球公认。

### P2. MIT 8.04 Quantum Physics I — 🟡 OCW 经典

- **官网**：https://ocw.mit.edu/courses/8-04-quantum-physics-i-spring-2013/
- **讲师**：Allan Adams（2013 版是金标准）；现版本由 Barton Zwiebach 讲
- **核心**：波函数 → 薛定谔方程 → 一维势井 → 氢原子 → 角动量 → 自旋
- **配套**：完整 lecture notes + 习题
- **前置**：8.01/8.02 + 线代 + 微分方程
- **对应「讲透」系列**：未来 `讲透量子计算` 的先修
- **一句话**：和"薛定谔的猫" meme 告别，真懂量子力学的起点。

### P3. MIT 8.05 / 8.06 Quantum Physics II / III — 🟡 Zwiebach 版

- **官网**：8.05 https://ocw.mit.edu/courses/8-05-quantum-physics-ii-fall-2013/ ｜ 8.06 https://ocw.mit.edu/courses/8-06-quantum-physics-iii-spring-2018/
- **讲师**：Barton Zwiebach（弦论专家，教学极清楚）
- **核心**：8.04 进阶——形式主义、微扰理论、散射、密度矩阵、纠缠（8.06 含 entanglement）
- **配套**：notes 详尽，是写教材级别的讲义
- **前置**：8.04
- **一句话**：想真正算量子问题（不靠科普），8.05/8.06 是 MIT 体系最扎实的。

### P4. MIT 8.962 General Relativity — 🟡 Scott Hughes

- **官网**：https://ocw.mit.edu/courses/8-962-general-relativity-spring-2020/
- **讲师**：Scott Hughes（MIT 引力波专家）
- **核心**：张量分析 → 爱因斯坦场方程 → 史瓦西解 → 黑洞 → 引力波（含 LIGO 视角）
- **前置**：8.04 + 线代 + 多变量微积分
- **一句话**：想看懂 Interstellar 或 LIGO 论文，这是 MIT 的标准入口。

### P5. David Tong's Lecture Notes — 🟢 必收（持续更新）

- **官网**：https://www.damtp.cam.ac.uk/user/tong/teaching.html
- **作者**：David Tong（Cambridge DAMTP，全球最受欢迎的理论物理讲师之一）
- **笔记列表**（全部免费 PDF + 大量配 lecture 视频）：
  - **Quantum Field Theory**（QFT，金标准笔记）— 已核对 URL: https://www.damtp.cam.ac.uk/user/tong/qft/qft.pdf
  - **String Theory**
  - **Gauge Theory**
  - **General Relativity**
  - **Cosmology**
  - **Statistical Field Theory**
  - **Classical Dynamics**
  - **Electromagnetism**
- **特点**：写得像小说一样清楚，是几乎所有剑桥博士生入门的标配
- **前置**：8.04/8.05 + 一点群论
- **对应「讲透」系列**：未来 `讲透场论` / `讲透量子计算` 的素材库
- **一句话**：理论物理公开资源第一神库，没有之一。

### P6. Theoretical Minimum — 🟡 Susskind 系列完结

- **官网**：https://theoreticalminimum.com/ ｜ YouTube playlist
- **讲师**：Leonard Susskind（Stanford，弦论/Mirror Symmetry/It from Qubit 元老）
- **系列**：Classical Mechanics → Quantum Mechanics → Special Relativity → Statistical Mechanics → Cosmology → Particle Physics → String Theory → **Quantum Entanglement** → General Relativity
- **特点**：Susskind 给"聪明的外行"开的最低门槛课——只讲最核心的概念，不堆计算
- **配套书**：每门都有同名科普书（Susskind + Hrabovsky 等）
- **前置**：本科物理直觉即可
- **一句话**：想做 AI for Physics，但没空读完整物理 PhD——Susskind 是最快的"理论底子速成"。

### P7. Frederic Schuller Lectures — 🟢 必收

- **官网/视频**：YouTube 频道（搜 "Frederic Schuller"）
- **讲师**：Frederic Schuller（FAU Erlangen，几何/数学物理）
- **代表作**：
  - **Lectures on the Geometrical Anatomy of Theoretical Physics**（几何基础，从集合/拓扑到流形/李群）
  - **Lectures on Quantum Theory**（用 C*-algebra 严谨讲量子）
  - **Lectures on Quantum Gravity**（圈量子引力的几何）
- **特点**：极度严谨，从公理出发，是数学物理教学的范本
- **前置**：扎实数学基础（建议先看 Schuller 的几何课）
- **一句话**：想把"理论物理"做成"数学一样严谨"，Schuller 是全球少数几个能讲的人。

### P8. PIRSA · Perimeter Institute Recorded Seminar Archive — 🟢 前沿每日

- **官网**：https://pirsa.org/
- **机构**：Perimeter Institute（加拿大，理论物理全球 Top 研究所之一）
- **内容**：所有 PI 举办的 seminar/colloquium/course，**全部免费录像 + slides**，从 2003 年至今
- **覆盖**：弦论 / 量子信息 / 量子引力 / 凝聚态 / 宇宙学 / **AI for Physics**（近年新增）
- **特点**：直接看一线理论物理学家讲最新工作，全球没有第二家
- **前置**：根据主题，研究生级
- **对应「讲透」系列**：未来 `讲透量子计算` / `讲透AI for Science` 的素材
- **一句话**：理论物理前沿的"arXiv 视频版"，必收藏。

### P9. ICTP Lecture Notes / Diploma Programme — 🟢 前沿

- **官网**：https://www.ictp.tv/ ｜ https://elearning.ictp.it/
- **机构**：ICTP（International Centre for Theoretical Physics，Trieste，UNESCO/IAEA 联合）
- **内容**： diploma 课程 + 暑期学校 + 专题会议，全部免费录像，特别面向发展中国家
- **覆盖**：高能物理 / 凝聚态 / 数学 / 地球物理 / 量化生命科学
- **特点**：和 PIRSA 互补，更偏"系统教学"，跨度大
- **一句话**：ICTP + PIRSA 是全球物理公开课的双子塔。

## 四、计算机篇

> **为什么 AI 工程师要看 CS 系统课**：① 大模型推理/训练 = 分布式系统（vLLM/SGLang 的根在 6.5840）；② AI infra = 性能工程（6.172 / 15-213）；③ 算法是面试+研究的地基。这些课是"AI 工程师转 AI infra 工程师"的必修。

### C1. MIT 6.006 / 6.046 Introduction to / Design of Algorithms — 🟡 长期

- **官网**：6.006 https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/ ｜ 6.046 OCW 2015
- **讲师**：Erik Demaine（MIT 算法教学界的明星）、Srini Devadas 等
- **核心**：6.006 = 基础数据结构 + 算法（排序/图/DP）；6.046 = 进阶（摊还、并查集、FFT、线性规划、近似）
- **前置**：6.042J 离散数学
- **对应「讲透」系列**：`讲透注意力`（复杂度分析）+ `讲透KV Cache`（数据结构）
- **一句话**：Erik Demaine 讲算法像在玩魔术，神课中的神课。

### C2. Stanford CS161 + Roughgarden Algorithms — 🟡

- **官网**：https://web.stanford.edu/class/cs161/ ｜ Coursera《Algorithms: Illuminated》系列
- **讲师**：Tim Roughgarden（Stanford，理论 CS + 近年经济学/游戏论 + AI）
- **核心**：分治 → 图算法 → 贪心 → DP → NP 完全性
- **配套书**：《Algorithms Illuminated》1-4 卷，全免费 PDF
- **对应「讲透」系列**：未来 `讲透算法`
- **一句话**：和 MIT 6.006 二选一即可，Roughgarden 的风格更"系统化、有结构感"。

### C3. MIT 6.5840 Distributed Systems — 🟢 Spring 2026 ✅（已核对）

> **核对要点**：联网实抓 https://pdos.csail.mit.edu/6.5840/ ，确认首页是 **Spring 2026**，2026-01-25 开课。原课号 6.824，2018 起改 6.5840；课程结构稳定不变。

- **官网**：https://pdos.csail.mit.edu/6.5840/
- **最新版本**：**Spring 2026** ✅
- **讲师**：Robert Morris、Frans Kaashoek（MIT 系统组元老）
- **核心**：RPC → 一致性 → 复制 → 容错 → 共识（Raft）→ 分片
- **labs**（Go 语言，神级作业）：
  - Lab1 MapReduce
