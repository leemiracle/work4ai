## §2 人工智能（经典 + 搜索）

### §2.1 双雄

#### ⭐ Berkeley CS 188 — *Pacman 实战派，edX 50 万学习者*

- **官网**：https://inst.eecs.berkeley.edu/~cs188/fa24/（每学期开，_faXX/ 命名）
- **讲师**：**Pieter Abbeel + Dan Klein**（Berkeley NLP/RL 双招牌；Abbeel 后创办 Covariant，Klein 长期 Berkeley NLP 组主任）
- **配套教材**：Russell & Norvig **《AIMA》4e**（2021）—— 全球 AI 课的默认教材
- **为什么是 #1**：4 个 Pacman 项目（Search / Multi-Agent / RL / Bayes）让 AI 概念**视觉化、可玩、可调试**——Pacman 形象全球家喻户晓，是 edX 历史上最受欢迎的 AI 课（50 万学习者）。
- **5 个项目**：
  1. **Search**（BFS/DFS/UCS/A*）→ Pacman 找豆子
  2. **Multi-Agent**（Minimax + αβ + Expectimax）→ Pacman 躲鬼
  3. **Reinforcement Learning**（Q-Learning）→ Pacman 学策略
  4. **Ghostbusters**（Bayes Net + 粒子滤波）→ 定位隐藏鬼
  5. **Tracking**（HMM/Viterbi）→ 跟踪运动鬼
- **本仓库实现**：[`berkeley-cs-projects/topic5-ai/ai_pacman.py`](../berkeley-cs-projects/topic5-ai/ai_pacman.py)（A* + Minimax+αβ + Value Iteration + Q-Learning + 贝叶斯网络枚举推断，纯 numpy）

#### ⭐ Stanford CS221 — *21 世纪重写版，加入 ML/DL 元素*

- **官网**：https://cs221.stanford.edu/
- **讲师**：**Dorsa Sadigh + Percy Liang**（Sadigh 做 robot learning/交互，Liang 是 HELM/Stanford CRFM 头）
- **和 CS 188 的区别**：CS221 是「**AI = 搜索 + 学习 + 推理 + 不确定性**」的现代整合版——CS 188 把四块分开教，CS221 强调四块的统一（teaching around "models + learning + inference" 三大抽象）。
- **选哪门**：想要 Pacman 视觉直觉 → CS 188；想要"AI 的统一抽象" → CS221。

### §2.2 学术视角差异（同档位的"另一种学法"）

| 学校 | 课程 | 视角差异 | 你学到的"另一种 AI" |
|------|------|---------|-------------------|
| **CMU** | 15-381 Artificial Intelligence | **更理论** | 搜索 + **decision theory** + RL 的数学化讲法，CMU 的"AI = 概率 + 优化"传统 |
| **MIT** | 6.034（**Patrick Winston**）| **经典 GOFAI** | 2010 年代仍用 Winston 的 *Strong Story* / Generate-and-Test / Constraint Propagation——**最纯粹的符号 AI 课**（Winston 2019 去世，但录像仍是 GOFAI 教学金标准）|
| **Toronto** | CSC 384 Introduction to AI | **逻辑推理 + planning** | 偏 STRIPS / SATPlan / 一阶逻辑——Toronto 的传统强项（Hinton 在隔壁搞连接主义，CSC 384 是符号派） |

**元洞察**：同一门「Intro AI」，Berkeley 教你**实战**（Pacman），CMU 教你**数学**（decision theory），MIT 教你**符号**（GOFAI），Toronto 教你**逻辑**（planning）——**4 家合起来才是完整 AI**。现代 LLM Agent 的兴起，恰恰是把"符号 planning + 学习"重新缝合，所以 CS221 这种"统一抽象"派正在赢。

### §2.3 学完后能力

- **CS 188 学完**：能写出**可玩 Pacman 的 5 种 agent**（搜索 + adversarial + RL + Bayes + HMM）——这正是本仓库 [`ai_pacman.py`](../berkeley-cs-projects/topic5-ai/ai_pacman.py) 的实现目标。
- **CS221 学完**：能搭一个 **end-to-end 推荐系统**（从特征工程 → 模型选择 → 推理 → 评估的全链条）。
- **横向比较**：CS 188 偏 agent / 决策，CS221 偏 models / 学习——前者打 RL 基础，后者打 ML 基础。

## §3 机器学习（经典）

### §3.1 双王

#### ⭐ Stanford CS229 — *吴恩达，行业事实标准*

- **官网**：https://cs229.stanford.edu/（Andrew Ng 创立，现 Summer 版由 TAs 维护，秋版吴恩达仍在）
- **讲师**：**Andrew Ng**（Stanford → Coursera 创始人 → DeepLearning.AI）—— 全球 ML 教学的"事实标准"代言人
- **配套三本笔记**（吴恩达亲自写，全免费）：[Linear Algebra](https://stanford.edu/~shervine/teaching/cs-229/refresher-probabilities-statistics) / Probability / PCA——**单这三本笔记就够自学一学期**
- **为什么是 #1**：CS229 是几乎所有中文 ML 博客 / B 站视频的源头——线性回归 → 逻辑回归 → GDA → SVM → 神经网络 → K-Means → EM → PCA 的骨架，被全球复制了 1000 遍。
- **覆盖**：监督（线性/逻辑/GDA/SVM/NN）+ 学习理论（bias-variance/VC/正则）+ 无监督（K-Means/EM/PCA/ICA）。

#### ⭐ CMU 10-701 — *Tom Mitchell / Matt Gormley，学术血统最纯*

- **官网**：https://www.cs.cmu.edu/~epxing/Class/10701/（每年讲师轮换）
- **讲师**：**Tom Mitchell**（《Machine Learning》教材作者，CMU ML 创立者之一）+ Matt Gormley（现主讲）
- **为什么和 CS229 并列**：CMU 是 ML 学术圈的"血统源头"——Mitchell 的《Machine Learning》(1997) 是第一本现代 ML 教材，CMU 10-701 是这本书的官方课。**学术圈招聘看 CMU ML PhD 几乎是默认加分项**。
- **和 CS229 的区别**：CS229 偏工程直觉（吴恩达风格），10-701 偏概率视角（CMU 风格——你看 10-701/10-715 用 Bishop PRML 作教材就懂了）。

## §4 深度学习

### §4.1 双雄

#### ⭐ Stanford CS231n — *Karpathy 时代传奇，历史最强 DL 教学*

- **官网**：https://cs231n.stanford.edu/（**注意不是** `web.stanford.edu/class/cs231n/`，那个已空）
- **金标准版**：**2015-2017 Karpathy 教的版本**——后来他去特斯拉 Autopilot、再后来去 OpenAI，**他教的 CS231n 至今被公认为"历史最强 DL 教学"**
- **现在（2025-2026）**：**Justin Johnson + Fei-Fei Li** 接续，PyTorch 化（Johnson 现已转密歇根大学但仍回 Stanford 讲；Fei-Fei Li 是 ImageNet 创立者）
- **配套笔记**：[cs231n.github.io](https://cs231n.github.io/)（Justin Johnson 写）—— **特别是 optimization-2（反向传播），全网被引用最多的 backprop 教材**，至今无人超越
- **作业 A1-A2 纯 numpy 手写**：kNN → SVM → Softmax → 2-layer NN → BatchNorm → Dropout → 优化器，**不用任何框架**——这是它和"调 PyTorch 库"课的根本区别
- **为什么是 #1**：CS231n 是几乎所有 DL 入门课的模板——Karpathy 后来基于它做了 Zero to Hero（本仓库 [`01`](./01-前沿课实时清单.md) §3 深核）

#### ⭐ MIT 6.S191 — *Alexander Amini，现代最强*

- **官网**：http://introtodeeplearning.com/
- **讲师**：**Alexander Amini + Ava Amini**（Amini 兄妹，MIT）—— 节奏快、MIT License 全开源、前置最低
- **节奏**：每年 1 月 IAP 短学期，**密集 4 周**，从"矩阵乘法是什么"到"微调 LLM"
- **2026 春 schedule**（本仓库 [`01`](./01-前沿课实时清单.md) §6 深核）：9 讲覆盖 DL 全领域（CV/序列/生成/RL/前沿/AI4Science/**大规模并行训练**）+ 3 个 Software Lab（音乐生成 + 公平性 + **Lab3 Fine-Tune an LLM**）
- **隐藏宝藏**：L9（**Mathias Lechner，Liquid AI CTO**）讲大规模并行训练（ZeRO/FSDP/张量并行/序列并行/MoE）——**这是其他入门课完全没有的内容**

| **Toronto** | **CSC 413 / 2547H** | **Hinton 母校** | Hinton 在 Toronto 工作近 **40 年**——**DBN / RBM / 反向传播推广 / Capsule Network** 都诞生于此。CSC 413 = 本科 DL 入门；**CSC 2547H 是 Hinton 退休前最后几年的研究生课**——学术血统全球最纯 |
| **Berkeley** | **CS 182 + CS 285**（**Sergey Levine**）| Deep RL 之父 | CS 182 = Deep Neural Nets（DL 基础）；CS 285 = **Deep RL**（Levine 的招牌，本仓库 [`01`](./01-前沿课实时清单.md) §2 深核 Spring 2026 版，已含 LLM RL） |

## §5 自然语言处理（NLP）

## §6 计算机视觉（CV）

### §6.1 双雄

#### ⭐ Oxford VGG — *Andrew Zisserman，历史最强*

- **官网**：https://www.robots.ox.ac.uk/~vgg/
- **实验室**：**VGG（Visual Geometry Group）**——**VGGNet / Double Caption / FlowNet** 的发源地
- **讲师**：**Andrew Zisserman**（VGG 实验室主任，**VGGNet 作者**——2014 ImageNet 亚军，但 VGGNet 因结构简洁被广泛用作 backbone 至今）
- **课程覆盖**：从 **SIFT / HOG** 经典特征 → 深度学习 → **Transformer**（VGG 实验室近年是 ViT / DETR 主推手之一）
- **配套圣经**：**Hartley & Zisserman《Multiple View Geometry》2e**（2003）—— 多视几何唯一圣经（Zisserman 是合著者）

#### ⭐ Berkeley CV — *Jitendra Malik，经典学派源头*

- **实验室**：Berkeley CV 传统（Malik 学生包括 Fei-Fei Li、 Trevor Darrell 等多位 CV 顶流）
- **讲师**：**Jitendra Malik**——**1999 年做 normalized cuts / shape context** 等开创工作，是 CV 经典学派的源头
- **现在（2025）**：和 **Pieter Abbeel**（CS 188 / CS 285 主讲）合作做**机器人视觉**——这正反映了 CV 从识别 → 检测 → 三维 → 具身的演进
- **课程**：Berkeley CS 280（CV 入门）+ CS 285（Deep RL，机器视觉决策结合）

### §6.2 工程派 vs 几何派（学术风格差异源）

| 学校 | 课程 | 流派 | 你学到的"另一种 CV" |
|------|------|------|-------------------|
| **CMU** | **16-385 / 16-720** | **工程派** | **Takeo Kanade** 在 CMU 几十年，CV 实验室规模**全球最大**。**16-720 (grad)** 覆盖 **bundle adjustment / 多视几何**——CMU 的"几何 + 工程实测"风格 |
| **ETH** | 3D Vision（**Marc Pollefeys**）| **几何派** | 多视几何圣经《Multiple View Geometry》(Hartley & Zisserman) 中的 Zisserman 后来到 Oxford，**Pollefeys 继承 ETH 几何传统**。强项是 **SLAM / 3D 重建**——ETH 是 SLAM 的欧洲旗手 |

**元洞察**：Oxford VGG 教你 CV = 几何 + 深度学习，Berkeley Malik 教你 CV = 经典特征 → 现代识别 → 机器人感知，CMU 教你 CV = 工程实测 + 大规模系统，ETH 教你 CV = 多视几何 + SLAM——**4 家拼起来 = 完整 CV**。2026 年 CV 的最热方向是 3D / 具身 / 生成（NeRF / Gaussian Splatting / Diffusion），而**这些恰恰都是几何 + 学习的结合**，所以 Oxford VGG 和 ETH 3D Vision 的传统强项正在重新成为主流。

### §6.3 学完后能力

- **ETH 3D Vision 学完**：能**从零写 SLAM**——ORB-SLAM / LSD-SLAM 类系统的实现能力。
