## 阅读顺序建议

```
入门者  : A → B → C1 → D → H（建框架 + 看对齐）→ K（跑实验巩固）
工程向  : F → G → D → E → B（系统/优化/数据/架构）→ K4/K8（算力与显存账）
研究向  : D → B → H → J（理论/架构/对齐/前沿）→ K5（拟合方法+矛盾）
速览    : 各文件只读 ⭐⭐⭐ 标记（~20 篇）+ K 总结表
```
