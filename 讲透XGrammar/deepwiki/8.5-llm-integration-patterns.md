## Bitmask Operations

 
### Bitmask Allocation and Format

 Token bitmasks are int32 tensors with shape `(batch_size, ceil(vocab_size / 32))`. Each int32 value contains 32 bits, where bit `i` represents whether token `(word_index * 32 + i)` is allowed. The bitmask is allocated on CPU to avoid synchronization overhead during generation.

 
```

```

 
| Function | Purpose | Returns |
|---|---|---|
| allocate_token_bitmask(batch_size, vocab_size) | Allocate CPU bitmask initialized to all-allowed | torch.Tensor (int32, CPU) |
| get_bitmask_shape(batch_size, vocab_size) | Calculate required bitmask shape | Tuple[int, int] |
| reset_token_bitmask(bitmask) | Reset all bits to 1 (all allowed) | None |

 - Indices must be valid and unique
 - Unspecified indices in the batch are left unmodified
