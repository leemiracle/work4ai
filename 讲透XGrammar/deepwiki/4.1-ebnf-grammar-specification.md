## Overview

 XGrammar implements Extended Backus-Naur Form (EBNF) syntax for defining context-free grammars. The EBNF parser consists of two components:

 
 - **`EBNFLexer`** ([cpp/grammar_parser.cc24-425](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L24-L425)): Tokenizes EBNF strings into token sequences
 - **`EBNFParser`** ([cpp/grammar_parser.cc427-1229](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L427-L1229)): Parses token sequences into `Grammar::Impl` AST structures
 
 The public entry point is `ParseEBNF()` ([cpp/grammar_parser.cc1224-1229](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L1224-L1229)), exposed in Python as `Grammar.from_ebnf()`.

 **Related formats:** JSON Schema conversion (page 4.2), Regular expressions (page 4.3), Structural tags (page 4.4).

## Basic Syntax and Rule Definitions

 
### Rule Declaration Syntax

 Production rules use the syntax:

 
```
rule_name ::= expression
```

 **Rule name requirements:**

 
 - Must start at beginning of line
 - Match `IsNameChar()` pattern: `[a-zA-Z0-9_.-]`
 - First character cannot be digit
 - Converted to `TokenType::RuleName` by lexer
 
 **Assignment operator:**

 
 - Syntax: `::=`
 - Token type: `TokenType::Assign` ([cpp/grammar_parser.cc336-340](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L336-L340))
 - Must be preceded by valid rule name on same line
 
 **Root rule:**

 
 - Specified in `ParseEBNF(ebnf_string, root_rule_name)`
 - Default: `"root"`
 - Must exist in grammar or parser error is raised

## Terminal Constructs

 
### String Literals

 String literals are enclosed in double quotes. Parsing is handled by `ParseStringToken()` ([cpp/grammar_parser.cc150-185](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L150-L185)), which:

 
 - Consumes opening `"` (line 155)
 - Calls `ParseNextUTF8OrEscaped()` for each character/escape sequence (line 159)
 - Accumulates codepoints (line 167)
 - Validates closing `"` (line 170-173)
 - Converts codepoints to UTF-8 bytes (line 179-182)
 
 
| Syntax | Description | Example | Token Value Type |
|---|---|---|---|
| "text" | Literal string | "hello" | std::string |
| "" | Empty string | "" | std::string (empty) |
| "\n\t\r" | Escape sequences | "\n" | Newline byte (0x0A) |
| "\uXXXX" | Unicode escape (4 hex digits) | "\u0041" | "A" |
| "\UXXXXXXXX" | Unicode escape (8 hex digits) | "\U0001F440" | "👀" |
| "\xXX" | Hex byte escape (2 hex digits) | "\xFF" | Byte 0xFF |

 String literals are stored as `TokenType::StringLiteral` with value type `std::string` containing UTF-8 encoded bytes.

 
### Character Classes

 Character classes define sets of acceptable characters. Parsing is handled by `ParseCharClass()` ([cpp/grammar_parser.cc574-625](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L574-L625)):

 **Syntax forms:**

 
| Syntax | Description | Produces |
|---|---|---|
| [a-z] | Character range | Range from 0x61 to 0x7A |
| [abc] | Individual characters | Three single-char ranges |
| [^a-z] | Negated class | Negated range 0x61-0x7A |
| [a-zA-Z0-9_] | Multiple ranges | Multiple CharacterClassElement |
| [\n\r\t] | Escaped characters | Escape codepoint ranges |
| [\u0041-\u005A] | Unicode ranges | Range from U+0041 to U+005A |

 **Dash handling:**

 
 - Between two characters: range operator `[a-z]`
 - At start/end: literal dash `[-a]` or `[a-]`
 - Escaped: literal dash `[\-]`
 - Token type: `TokenType::Dash` ([cpp/grammar_parser.cc211-215](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L211-L215))
 
 **Output structure:** Parser produces `GrammarBuilder::CharacterClassElement` ([cpp/grammar_builder.h113-116](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_builder.h#L113-L116)):

 **Parsing algorithm:**

 
 - Consume `TokenType::LParen` (line 657)

## Implementation Limits

 
| Limit | Value | Constant/Field | Rationale |
|---|---|---|---|
| Max integer | 10^15 | kMaxIntegerInGrammar (cpp/grammar_parser.cc37) | Prevents overflow in repetition count |
| Max nest layer | 1000 | max_nest_layer_ (cpp/grammar_parser.cc535) | Prevents stack overflow from deep () nesting |
| Repetition unzip threshold | 128 | kUnzipThreshold (cpp/grammar_parser.cc835) | Balance between explicit sequences and kRepeat node |

 **Nesting enforcement:**

 
 - Field: `nest_layer_guard_` (incremented on `(`, decremented on `)`)
 - Check: [cpp/grammar_parser.cc653-656](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L653-L656)
 - Error: "Nest layer exceeded the maximum limit"
 
 **Repetition strategy:**

 
 - Small ranges `{n,m}` where `m ≤ 128`: Unzipped via `LegacyHandleRepetitionRange()` ([cpp/grammar_parser.cc775-830](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L775-L830))
 - Large ranges `{n,m}` where `m > 128`: Use `GrammarExprType::kRepeat` via `HandleRepetitionRange()` ([cpp/grammar_parser.cc832-912](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/grammar_parser.cc#L832-L912))
