## Writing Tests

 
### Test Guidelines

 
 - **Test Structure**: Use descriptive test names starting with `test_`
 - **Fixtures**: Create reusable test fixtures for common setup (grammar, tokenizer, compiler)
 - **Assertions**: Use clear assertion messages
 - **Markers**: Use `@pytest.mark.hf_token_required` for tests requiring authentication
 - **Isolation**: Each test should be independent and not rely on global state
