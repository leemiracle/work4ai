 **EBNF Syntax Support:**

 
 - Character classes: `[A-Z]`, `[a-z]`, `[^0-9]`
 - Quantifiers: `*` (zero or more), `+` (one or more), `?` (optional)
 - Grouping: `(expr1 expr2)`
 - Choices: `expr1 | expr2`
 - String literals: `"literal text"`
 - Lookahead assertions: `(= expr)` (positive), `(! expr)` (negative)

## Token Bitmask Management

 The bitmask is a compressed representation of valid tokens, stored as `int32` where each bit represents one token.

 
```

```

 **Bitmask Operations:**

 
| Function | Purpose | Reference |
|---|---|---|
| allocate_token_bitmask(batch_size, vocab_size) | Allocates bitmask tensor on CPU | matcher.py27-50 |
| reset_token_bitmask(bitmask) | Resets all bits to 1 (all tokens valid) | matcher.py53-55 |
| fill_next_token_bitmask(bitmask, index) | Sets bits based on grammar state | matcher.py311-343 |
| apply_token_bitmask_inplace(logits, bitmask) | Masks logits by setting invalid to -inf | matcher.py58-189 |

 **Backend Selection:**

 The `apply_token_bitmask_inplace()` function supports multiple backends:

 
 - **CPU**: For CPU tensors ([kernels/apply_token_bitmask_inplace_cpu.py](https://github.com/mlc-ai/xgrammar/blob/c30554f7/kernels/apply_token_bitmask_inplace_cpu.py))
 - **Triton**: Default for CUDA tensors ([kernels/apply_token_bitmask_inplace_triton.py1-127](https://github.com/mlc-ai/xgrammar/blob/c30554f7/kernels/apply_token_bitmask_inplace_triton.py#L1-L127))
 - **CUDA**: Native CUDA implementation ([kernels/apply_token_bitmask_inplace_cuda.py1-120](https://github.com/mlc-ai/xgrammar/blob/c30554f7/kernels/apply_token_bitmask_inplace_cuda.py#L1-L120))
 - **Torch Compile**: For other devices (TPU, ROCm)
 - **Torch Native**: Fallback for additional backends
 
 Backend is auto-selected based on device type (line 149-156 in [python/xgrammar/matcher.py](https://github.com/mlc-ai/xgrammar/blob/c30554f7/python/xgrammar/matcher.py)).
