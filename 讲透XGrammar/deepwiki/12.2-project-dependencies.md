# Project Dependencies

  Relevant source files 
 - [CMakeLists.txt](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt)

  This page documents all third-party dependencies required by XGrammar, including Python runtime dependencies, build system requirements, C++ third-party libraries, and platform-specific considerations. For information about the build system configuration itself, see [Build System and Configuration](https://deepwiki.com/mlc-ai/xgrammar/12.1-build-system-and-configuration). For details on wheel building and distribution, see [Cross-Platform Wheel Building](https://deepwiki.com/mlc-ai/xgrammar/12.5-cross-platform-wheel-building).

 
## Overview

 XGrammar has a multi-layered dependency structure:

 
 - **Python runtime dependencies** required for using the package
 - **Build system dependencies** required for compiling from source
 - **C++ third-party libraries** vendored in the `3rdparty/` directory
 - **Optional dependencies** for testing, hardware acceleration, and development
 
 All dependencies are specified in [pyproject.toml1-161](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L1-L161) and [CMakeLists.txt1-145](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L1-L145)

 
## Python Runtime Dependencies

 
### Core Dependencies

 The following packages are required for all XGrammar installations:

 
| Package | Version Constraint | Purpose |
|---|---|---|
| pydantic | (no constraint) | JSON schema parsing and validation |
| torch | >=1.10.0 | Tensor operations and DLTensor interface |
| transformers | >=4.38.0 | Tokenizer integration via AutoTokenizer |
| numpy | (no constraint) | Array operations |
| typing-extensions | >=4.9.0 | Advanced type hints for Python <3.10 |
| triton | (no constraint) | GPU kernel compilation (Linux x86_64 only) |

 **Platform-Specific Note:** The `triton` dependency is conditionally included only on Linux x86_64 systems via the constraint `platform_system == 'Linux' and platform_machine == 'x86_64'` [pyproject.toml21](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L21-L21)

 **Python Version Requirement:** XGrammar requires Python `>=3.8, <4` [pyproject.toml16](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L16-L16)

## Build System Dependencies

 XGrammar uses `scikit-build-core` as its PEP 517 build backend, which orchestrates CMake-based C++ compilation:

 
```

```

 
| Package | Version Constraint | Purpose |
|---|---|---|

 **Version Pinning:** `nanobind` is pinned to exactly version 2.5.0 to ensure ABI compatibility between build and runtime [pyproject.toml44](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L44-L44)

### CMake Requirements

 CMake 3.18 or higher is required [CMakeLists.txt1](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L1-L1) The build system uses the following CMake features:

 
 - C++17 standard (`CMAKE_CXX_STANDARD 17`) [CMakeLists.txt30](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L30-L30)

 - Out-of-source builds via `build-dir = "build"` [pyproject.toml51](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L51-L51)

### Compiler Requirements

 XGrammar requires a C++17-compliant compiler with the following platform-specific configurations:

 **Linux/macOS:**

 
 - GCC or Clang with C++17 support
 - Compiler flags: `-Wall -Wextra -Werror -Wno-pedantic -Wno-unused-parameter -Woverloaded-virtual` [CMakeLists.txt67-68](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L67-L68)
 - Link-time optimization (`-flto=auto`) enabled by default on most platforms [CMakeLists.txt68](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L68-L68)
 - Optimization level: `-O3` for non-Debug builds [CMakeLists.txt52](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L52-L52)
 
 **Windows:**

 
 - MSVC with C++17 support
 - Compiler flags: `/Wall` [CMakeLists.txt49](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L49-L49)
 
 **Platform-Specific Exceptions:**

 
 - **RISC-V 64-bit:** LTO disabled to prevent linker errors [CMakeLists.txt54-55](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L54-L55)
 - **PowerPC 64-bit LE:** `-Wfree-nonheap-object` downgraded to warning [CMakeLists.txt59-61](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L59-L61)
 
 Sources: [CMakeLists.txt48-71](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L48-L71)

### DLPack

 **Purpose:** In-memory tensor structure standard for zero-copy tensor exchange

 **Location:** `3rdparty/dlpack/include`

 **Usage:** Enables zero-copy sharing of PyTorch tensors with C++ via `DLTensor` interface. Used by `apply_token_bitmask_inplace` kernels.

 **Integration:**

 
 - Included as system header [CMakeLists.txt73-75](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L73-L75)
 - Installed to system include directory [CMakeLists.txt100-106](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L100-L106)
 
 **Key Interface:** Provides `DLManagedTensor` structure for tensor metadata and memory management.

 Sources: [CMakeLists.txt73-75](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L73-L75) [CMakeLists.txt100-106](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L100-L106)

 **CUDA Support:** CUDA toolkit is optional. When available, enables CUDA kernels for `apply_token_bitmask_inplace`. Configured via `XGRAMMAR_CUDA_ARCHITECTURES` (default: `native`) [CMakeLists.txt25-28](https://github.com/mlc-ai/xgrammar/blob/c30554f7/CMakeLists.txt#L25-L28)

 **Build Architectures:** Both x86_64 and aarch64 are supported [pyproject.toml153](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L153-L153)

### macOS-Specific Dependencies

 **Deployment Target:** Minimum macOS version is 10.14 [pyproject.toml157](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L157-L157)

 **Architecture-Specific Features:**

 
 - **x86_64:** Standard CPU execution only. PyTorch stopped supporting macOS x64 in version 2.2, so Python 3.13 wheels are not available [pyproject.toml146](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L146-L146)

 **Transformers Version Constraint:** On all macOS builds, transformers is constrained to `<4.50.0` due to a bug in 4.50.0 [pyproject.toml39](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L39-L39)

 **Build Architectures:** Both x86_64 and arm64 [pyproject.toml156](https://github.com/mlc-ai/xgrammar/blob/c30554f7/pyproject.toml#L156-L156)
