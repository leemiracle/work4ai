## Purpose and Scope

 This page documents the Python-C++ binding layer implemented using the nanobind library. The binding layer exposes XGrammar's C++ core functionality to Python, enabling high-level Python APIs while maintaining C++ performance for compute-intensive operations. The bindings handle type conversions, zero-copy tensor operations via DLTensor/DLPack, and thread safety through GIL management.

 For information about the high-level Python API that users interact with, see [Python API Reference](https://deepwiki.com/mlc-ai/xgrammar/3-python-api-reference). For details on the C++ implementation being bound, see [C++ Implementation Details](https://deepwiki.com/mlc-ai/xgrammar/11-c++-implementation-details).

 **Sources:** [cpp/nanobind/nanobind.cc1-465](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/nanobind/nanobind.cc#L1-L465)

### Rationale

 GIL release is critical for:

 
 - **Multi-threaded performance**: Allows other Python threads to execute while C++ code runs
 - **Batch operations**: Enables parallel processing in `BatchGrammarMatcher`
 - **Long computations**: Prevents blocking during grammar compilation and FSM construction
 - **Thread pool usage**: Allows C++ thread pools to execute efficiently without GIL contention
 
 **Sources:** [cpp/nanobind/nanobind.cc1-465](https://github.com/mlc-ai/xgrammar/blob/c30554f7/cpp/nanobind/nanobind.cc#L1-L465)
