## Purpose and Scope

 This document explains the build system and configuration for xgrammar, covering the integration of scikit-build-core with CMake for building the Python package with native C++ extensions. Topics include Python package configuration in `pyproject.toml`, CMake build options and targets, compilation flags, and platform-specific settings.

 For information about project dependencies, see [Project Dependencies](https://deepwiki.com/mlc-ai/xgrammar/12.2-project-dependencies). For cross-platform wheel building, see [Cross-Platform Wheel Building](https://deepwiki.com/mlc-ai/xgrammar/12.5-cross-platform-wheel-building).

### Build Options

 CMake options can be configured via `config.cmake` or command-line arguments:

 
| Option | Default | Description |
|---|---|---|
| XGRAMMAR_BUILD_PYTHON_BINDINGS | ON | Build Python bindings (xgrammar_bindings module) |
| XGRAMMAR_BUILD_CXX_TESTS | OFF | Build C++ unit tests with GoogleTest |
| XGRAMMAR_ENABLE_CPPTRACE | OFF | Enable C++ stack traces (Linux only, Debug/RelWithDebInfo) |
| XGRAMMAR_ENABLE_COVERAGE | OFF | Enable code coverage with gcov |
| XGRAMMAR_ENABLE_INTERNAL_CHECK | OFF | Enable internal consistency checks |
| XGRAMMAR_CUDA_ARCHITECTURES | native | CUDA compute architectures to target |

 **Common flags across non-MSVC platforms:**

 
 - `-Wall -Wextra -Werror`: Strict warning enforcement

### xgrammar Static Library

 The core C++ library built from all source files (excluding nanobind code):

 
```

```

 **Key characteristics:**

 
 - **Target name**: `xgrammar`
 - **Type**: Static library (`.a` on Unix, `.lib` on Windows)
 - **Sources**: All `.cc` files in `cpp/` except `cpp/nanobind/`
 - **Public headers**: `include/` directory
 - **System headers**: picojson, DLPack

```

```

 - **Links to**: `xgrammar` static library
