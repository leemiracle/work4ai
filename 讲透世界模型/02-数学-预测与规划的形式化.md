# 📐 第 2 幕 · 数学：预测与规划的形式化

## 1. MDP：世界模型 = 转移函数

MDP 五元组 $(S, A, P, R, \gamma)$。**世界模型就是 $P$**：

$$P(s' \mid s, a) = \text{在 } s \text{ 做 } a, \text{ 下一刻状态分布}$$

有了 $P$，就能定义价值函数（Bellman 方程）：

$$V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, a_t) \mid s_0 = s, \pi, P\right]$$

$$V^*(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')\right]$$

**关键**：一旦有 $P$，你可以**在脑内** rollout 任意轨迹评估价值——不必真实交互。这就是 model-based RL 的力量。

## 2. Policy/Value Iteration

**Value iteration**：
$$V_{k+1}(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V_k(s')\right]$$

迭代到收敛，得 $V^*$。**复杂度 $O(|S|^2|A|)$ 每次迭代**——对大状态空间不实用。

**Policy iteration**：交替改进策略和评估。收敛更快但仍受 $|S|$ 限制。

**问题**：这些都需要 $P$ 已知。当 $P$ 未知 → model-based RL 要先学 $P$。

## 3. Monte Carlo Tree Search (MCTS)

AlphaGo 的核心。在状态 $s$ 选动作，build 一棵搜索树：

```
1. Selection:   从根按 UCT 公式选子节点下降
2. Expansion:   到叶节点, 展开一个未尝试动作
3. Simulation:  从新节点 rollout 到终局 (用快速策略)
4. Backprop:    把结果回传更新路径上的统计
```

**UCT 公式**（Kocsis/Szepesvári 2006）平衡探索-利用：

$$\text{UCT} = \underbrace{\bar{X}_j}_\text{平均价值} + c\sqrt{\frac{\ln N}{N_j}}$$

$N$ 是父节点访问数，$N_j$ 是子节点访问数，$c$ 是探索常数。第二项让未充分探索的节点有机会。

**MCTS 不需要完整 $P$**——只需一个可前向模拟的环境（真实或学到的世界模型）。这是 AlphaGo self-play 的引擎。

## 4. JEPA：抽象空间预测

LeCun 的 JEPA loss：

$$\mathcal{L}_{\text{JEPA}} = -\log \frac{\exp(\text{sim}(z_s', z_{s'}^*)/\tau)}{\sum_{s''} \exp(\text{sim}(z_s', z_{s''}^*)/\tau)}$$

其中 $z_s' = \text{predictor}(z_s, a)$ 是预测的下一抽象状态，$z_{s'}^*$ 是真实的下一抽象状态（从真实 $s'$ 编码），分母遍历负样本 $s''$。

**关键**：**不在像素空间算 loss**，只在抽象表征空间。所以不会因「云飘过」等无关像素细节被惩罚。

**难点**：避免表征坍缩（collapsing to constant）。解法：负样本对比 + 信息瓶颈 + 非对称架构。

## 5. Diffusion 作为世界模型

Diffusion 学的是「从噪声到数据」的去噪过程：

$$\mathcal{L}_{\text{diffusion}} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

$x_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t}\epsilon$ 是加噪版本，$\epsilon_\theta$ 是学到的去噪网络。

**作为世界模型**：把「下一帧」当 $x_0$，让模型从噪声生成下一帧。**这就是 Sora/Genie 的机制**。

**vs JEPA**：diffusion 在像素/潜在空间预测，监督明确（真实下一帧）；JEPA 在抽象空间，监督隐式。**前者好训但可能学无关细节，后者省算力但难收敛**。这是世界模型的核心张力。

## 6. MuZero：不学规则也能规划

Schrittwieser 2020 的 MuZero 神来之笔：**不学 $P(s'|s,a)$，学三个抽象函数**：

$$s' = h_\theta(\text{latent}, a), \quad \pi, v = g_\theta(\text{latent}), \quad r = f_\theta(\text{latent}, a)$$

在 latent 空间做 MCTS。**不知道真实状态、不知道规则**——完全在学到的表征里规划。Atari、围棋、象棋、将棋全部 SOTA。

**意义**：世界模型不必还原真实世界，只要**在抽象空间支持规划**。

## 🎬 本幕收束

> 世界模型数学 = $P(s'|s,a)$（转移）+ Bellman（价值）+ MCTS（规划）+ JEPA（抽象预测）+ diffusion（生成式预测）+ MuZero（latent 规划）。核心张力：**像素 vs 抽象**——前者好训但无用，后者有用但难训。
