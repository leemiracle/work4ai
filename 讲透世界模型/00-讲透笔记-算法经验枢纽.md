## §0 全局视角：世界模型 = "环境在脑中的内部模拟"

```
世界模型 = 编码器（感知 → 隐状态）
        + 转移模型（隐状态 → 下一隐状态）
        + 解码器（隐状态 → 预测）
        + Reward 模型（隐状态 → 奖励）
```

> 🔑 **核心 DNA**：**世界模型让 agent 在"脑内"模拟未来**——这是 LeCun 的 JEPA、Ha & Schmidhuber 的 world model、Dreamer 系列的共同思想。

## §1 八条算法经验

### 算法经验 WM1：模型预测控制 (MPC) 的 RL 版

> 有了世界模型，agent 可以**在脑内"试错"**：
> ```
> 1. 用世界模型预测多个动作的未来
> 2. 选最优动作序列
> 3. 执行第一步
> 4. 观察真实结果，更新世界模型
> ```
>
> 算法本质：**MPC（控制论）+ 学习的世界模型 = Model-based RL**（应用 D1 transition=MDP、DC3 DST=POMDP）。

### 算法经验 WM2：JEPA = 联合嵌入预测架构（LeCun 2022）

> LeCun 主张：世界模型应该预测**抽象表示**，不是像素：
> $$\text{loss} = \| \text{predictor}(s_t, a) - \text{encoder}(s_{t+1}) \|^2$$
>
> 算法本质：**预测 latent 比预测 pixel 容易，且更有用**——避免"预测无关细节"（应用 IT9 信息瓶颈、A2 核回归）。

### 算法经验 WM3：Dreamer = 在脑内做梦学习

> Dreamer (Hafner 2019-2024)：
> 1. 收集真实经验
> 2. 训世界模型
> 3. **在世界模型里"做梦"**（生成想象轨迹）
> 4. 在想象轨迹上训 actor-critic
> 5. 部署到真实环境
>
> 算法本质：**用世界模型做"数据增强"**——RL 的"梦"（应用 RL1 探索-利用、AG5 反思=经验回放）。

### 算法经验 WM4：Latent Dynamics = 在抽象空间做规划

> 世界模型的核心：**学一个 latent space，让 dynamics 简单**（线性或近线性）。
>
> 算法本质：**降维 + 简化动力学**——和科学计算的本征正交分解（POD）同源（应用 GM10 Latent Diffusion、S1 源-滤波分解）。

### 算法经验 WM5：视频生成 = 视觉世界模型

> Sora (OpenAI 2024) 本质是**视觉世界模型**：学视频的"物理规律"（重力、碰撞、遮挡）。
>
> 算法本质：**生成模型 + 时间维度 = 世界模型**（应用 GM12 多模态生成、A3 对齐）。

### 算法经验 WM6：Sora 的 scaling = 学到"涌现的物理"

> Sora 论文明确："我们没有教模型物理，只是用足够多视频，物理涌现了"。
>
> 算法本质：**足够大的生成模型 = 隐式世界模型**——这是 LLM"涌现能力"在视觉的版本（应用 TR7 Scaling Law、T1 试炼场）。

### 算法经验 WM7：世界模型 vs LLM 的关系

> | | LLM | 世界模型 |
> |---|-----|---------|
> | 输入 | token | 观察/状态 |
> | 输出 | token | 状态/动作 |
> | "理解世界" | 语言层面 | 物理层面 |
> | 推理 | next-token 预测 | next-state 预测 |
>
> 算法本质：**LLM 是"语言世界模型"，视觉/控制模型是"物理世界模型"**——两者结构相似，但模态不同（应用 A1 元架构、R1 参数化 vs 非参数化）。

### 算法经验 WM8：世界模型的工程挑战

> 1. **长期预测漂移**：误差累积
> 2. **分布外**：训练没见的场景
> 3. **奖励信号稀疏**：long-horizon 任务
> 4. **计算成本**：世界模型本身要训
>
> 解法：**层次化世界模型 + 多步监督 + 不确定性量化**（应用 AG3 记忆层级、N1 连乘→衰减）。
