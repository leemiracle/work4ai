## 方向 1：**World Model 的统一判定标准**

### 问题

什么是"真" world model？怎么区分"看起来像"和"真的"？给出可证伪的科学判定。

### 当前状态

- LeCun / Sora 团队各说各话
- 没有共识的 benchmark
- [A02](./02-视频生成是世界模型吗.md) 给出 L1-L8 框架，但**只是初步**

### 可能路径

1. **物理直觉 benchmark**：设计 1000 个简单物理场景测所有 world model
2. **反事实测试**：系统方法测反事实推理能力
3. **理论判定**：从理论上证明"什么样的模型架构能学到 world model"

### 为什么是博士级

- 影响整个 AI 圈的**话语体系**
- 跨学科（认知科学 + 物理 + ML）
- 工业界急需（投资 billions 在 world model）

本层 [A02](./02-视频生成是世界模型吗.md) + [`讲透可解释性`](../../讲透可解释性/) + [`讲透科学的现代性/03`](../../讲透科学的现代性/03-AI时代的科学哲学.md)

## 方向 2：**LLM 是 World Model 吗**

### 问题

文本训练出的 LLM（GPT-4/Claude）有 world model 吗？它能学到物理直觉吗？

### 当前状态

- **OthelloGPT**（2023）：8 层 transformer 玩 Othello，内部有棋盘表示——**LLM 能学简单 world model**
- **Groeneveld 等的 probing**：LLM 内部有部分 world 表示
- **反对**：LLM 在真物理任务（物理题、空间推理）差——证明只是统计模式

### 可能路径

1. **probe LLM 的物理表示**：用 mechanistic interpretability 找物理 circuit
2. **跨模态实验**：纯文本 vs 加图像，物理理解差多少
3. **理论分析**：next-token prediction 在什么条件下能学 world model

### 为什么是博士级

- 影响重大（如果 LLM 已经有 world model，scaling 就够；如果没有，需要新方法）
- 关联 [`讲透可解释性`](../../讲透可解释性/) 的核心问题

### 关联 work4ai

[`讲透基础模型/advanced`](../../讲透基础模型/advanced/) + [`讲透可解释性`](../../讲透可解释性/) + 本层

## 方向 3：**JEPA vs 像素生成——实证对决**

### 问题

LeCun 说 JEPA 更对，Sora 团队说像素生成更对——**怎么用实验判决**？

### 当前状态

- 两派都有论文，但**没有公平对决**
- 缺乏 controlled comparison（同算力、同数据）
- 都是各自宣称

### 可能路径

1. **controlled experiment**：同架构、同数据、同算力，只改"latent 预测 vs 像素预测"
2. **physics benchmark**：在物理任务上对比两派
3. **混合架构**：JEPA + 像素生成，能否两全？

### 为什么是博士级

- 2024-2026 最大争论，**理论空白**
- 实验设计挑战大（公平对决难）
- 结论影响整个方向

### 关联 work4ai

本层 [A01](./01-JEPA数学与LeCun路线.md) + [A02](./02-视频生成是世界模型吗.md)

## 方向 4：**World Model 的 Scaling Law**

### 问题

参数-数据-物理准确性的最优配比是什么？video generation 的 Chinchilla 在哪？

### 当前状态

- 训练 LLM 有 Kaplan/Chinchilla scaling law
- **Video generation / world model 没有严格 scaling law**
- 工程上靠经验

### 可能路径

1. **视频 scaling law**：loss ~ 参数-数据-视频长度的关系
2. **物理准确性 scaling**：物理错误率怎么随规模变
3. **动作维度 scaling**：robotics 的 scaling law

### 为什么是博士级

- 影响工业投资决策
- 理论空白
- 数据需求大（但可以小规模拟合）

### 关联 work4ai

[`讲透基础模型/advanced/01 ScalingLaw`](../../讲透基础模型/advanced/01-ScalingLaw-严格证明.md) + 本层

## 方向 5：**World Model 的因果性**

### 问题

world model 怎么学到因果，而不只是相关？

### 当前状态

- Pearl 的因果阶梯：观察 → 干预 → 反事实
- 当前 world model 主要在"观察"层
- 干预和反事实几乎没研究

### 可能路径

1. **干预训练**：训练时主动"修改"变量，让模型学因果
2. **反事实 benchmark**：测模型的反事实推理能力
3. **因果 circuit**：用 mechanistic interpretability 找"因果回路"

### 为什么是博士级

- 跨学科（因果推断 + ML + 哲学）
- 影响大（真 world model 必须有因果）
- 难度高（理论 + 实验都难）

### 关联 work4ai

[`讲透科学的现代性/03`](../../讲透科学的现代性/03-AI时代的科学哲学.md) + [`讲透可解释性`](../../讲透可解释性/)

## 方向 6：**Embodied World Model——机器人**

### 问题

通用机器人 world model——支持哪些任务？跨 embodiment 能泛化吗？

### 当前状态

- RT-2 / Octo / π₀ / GR00T 有进展
- 但**泛化差**——厨房学的拿到工厂失效
- 数据稀缺（机器人数据远少于视频）

### 可能路径

1. **跨 embodiment 学习**：让一个 model 控制多种机器人
2. **仿真到真实**（sim2real）：仿真训练 + 真实迁移
3. **触觉/力觉**：不只是视觉，加更多模态

### 为什么是博士级

- 5-10 年的产业方向（机器人是下一个万亿）
- 工程挑战大
- 跨学科（机械 + 控制 + ML）

### 关联 work4ai

[`讲透RL`](../../讲透RL/) + [`讲透Agent`](../../讲透Agent/)

## 方向 7：**World Model 与 Mechanistic Interpretability**

### 问题

用 interpretability 工具找 world model 内部的"物理表示"——证明它真理解 vs 假装理解。

### 当前状态

- [`讲透可解释性`](../../讲透可解释性/) 的 SAE / circuits 工具已成熟
- **但极少用于 video generation / world model**
- 没人知道 Sora 内部有没有"重力 circuit"

### 可能路径

1. **找 physics circuits**：在 world model 里找"重力"/"碰撞"的回路
2. **steering 实验**：激活"重力"特征，看视频是否反映
3. **对比 LLM vs World Model 的 internal representation**

### 为什么是博士级

- 直接关联 AI safety
- 2024-2026 interpretability 大爆发，机会窗口
- 跨学科（认知科学 + ML）

### 关联 work4ai

[`讲透可解释性`](../../讲透可解释性/) + [`讲透科学的现代性/03`](../../讲透科学的现代性/03-AI时代的科学哲学.md)

## 方向 8：**Hierarchical World Model**

### 问题

多层 world model——低层像素、中层物体、高层概念。怎么架构？

### 当前状态

- LeCun 提出 H-JEPA 概念
- 但**没有实现的 H-JEPA**
- 多层抽象的 world model 几乎没人做

### 可能路径

1. **H-JEPA 架构**：多层 latent，每层不同时间尺度
2. **物体级 world model**：基于 object-centric 表示
3. **概念级 world model**：用 LLM 做高层推理 + 视频做低层

### 为什么是博士级

- 接近人类认知结构
- 跨学科（认知科学 + ML）
- 理论空白（怎么定义"层"）

### 关联 work4ai

本层 [A01](./01-JEPA数学与LeCun路线.md) + [`讲透基础模型/advanced`](../../讲透基础模型/advanced/)

## 方向 9：**World Model 的 Sim2Real**

### 问题

仿真训练的 world model，怎么迁移到真实世界？

### 当前状态

- 仿真环境（Isaac Sim/Habitat）越来越好
- sim2real gap 仍然大（光照、摩擦、传感器噪声）
- domain randomization / adaptation 有进展但不完美

### 可能路径

1. **domain randomization**：在仿真里随机化所有参数
2. **可微仿真器**：让仿真器可微，端到端训练
3. **真实数据精调**：仿真预训练 + 少量真实数据微调

### 为什么是博士级

- 直接影响机器人/自动驾驶产业
- 工程挑战大
- 跨学科（仿真 + 控制 + ML）

### 关联 work4ai

[`讲透RL`](../../讲透RL/) + 本层

## 方向 10：**World Model 的 Safety**

### 问题

如果 world model 用于决策（机器人/自动驾驶），怎么保证安全？怎么防 deceptive alignment？

### 当前状态

- 传统 AI safety 主要针对 LLM
- **world model 的 safety 几乎没研究**
- 但 world model 决策风险更大（机器人伤人）

### 可能路径

1. **可验证 world model**：形式化方法验证物理一致性
2. **红队 world model**：找失败模式
3. **safety filter**：world model 决策上加安全层

### 为什么是博士级

- 影响部署（不能上路的 world model 没用）
- 跨学科（安全工程 + ML + 法学）
- 当前空白

[`讲透AI应用全景/07-AI for AI`](../../讲透AI应用全景/07-AI%20for%20AI.md) + [`讲透科学的现代性/02`](../../讲透科学的现代性/02-可重复性危机.md)

## 怎么从"读论文"过渡到"做研究"

### 阶段 1：选定方向（1-3 月）

- 选 2-3 个候选方向
- 各读 10 篇核心论文
- 找**你能想到的 1 个新问题**

### 阶段 2：小规模复现（3-6 月）

- 复现 1 个关键实验（如 DreamerV3 在 Atari）
- 改一个变量，看结果
- 找"现有论文没解释的现象"

### 阶段 3：提出假说（6-12 月）

- 提出可证伪假说
- 设计实验验证
- **证伪也是研究**

### 阶段 4：写论文（12-24 月）

- 整理发现，写第一作者论文
- 投 NeurIPS / ICML / ICLR / CoRL（机器人）/ RSS
- 接受率低（20-30%）

### 阶段 5：建立 track record（24-60 月）

- 持续产出（每年 1-2 篇一作）
- 成为 referenced expert

## 一句话总结

> 🎯 **博士级五句话**：
> 1. 10 个方向分 4 类：**判定**（1/2）、**方法**（3/5/8）、**工程**（4/6/9）、**安全**（7/10）。
