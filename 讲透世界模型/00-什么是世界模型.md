# 00 · 什么是世界模型——四派统一框架

> **第一性问题**：当 Sora 团队、LeCun、DeepMind、World Labs 都说自己在做"世界模型"——**他们说的是同一件事吗**？
>
> 答案：**不是**。这是 2024-2026 AI 圈最严重的概念混乱。本篇用一个**四派统一框架**把混乱讲清楚——并给出**什么是真正的世界模型**的判定标准。
>
> 配套：[`讲透世界模型/README`](./README.md) + [`讲透RL/00 MDP`](../讲透RL/00-为什么RL与MDP.md) + [`讲透科学的现代性/03`](../讲透科学的现代性/03-AI时代的科学哲学.md)

## 一、概念混乱的现状

### 1.1 同一个词，四种意思

**"World Model"** 在 2024-2026 AI 圈被用于至少四种完全不同的东西：

| 来源 | 用法 | 例子 |
|---|---|---|
| **OpenAI Sora 技术报告**（2024）| "Sora is a **world simulator**"——会生成看起来像物理世界的视频 | 文本→视频 |
| **Yann LeCun**（2022-）| "world model" = JEPA——在**抽象 latent 空间**预测，非像素 | I-JEPA / V-JEPA |
| **Hafner DreamerV3**（2023）| "world model" = RL agent 脑内的**环境模拟器**——能在脑内"想象"未来 | Minecraft 钻石 |
| **李飞飞 World Labs**（2024）| "world model" = **可交互的 3D 物理空间理解**——具身机器人的基础 | 大世界生成 |

**这四种用法**：
- 目标不同（生成视频 vs 学抽象 vs 决策 vs 控制）
- 方法不同（扩散 vs 自监督 vs RL vs 多模态）
- 评估不同（视觉真实性 vs latent 可预测 vs 回报 vs 物理准确）

### 1.2 混乱的代价

- **学术讨论低效**：A 说 "Sora 不是 world model"，B 反驳——其实两人在说不同事
- **投资误判**：投资人以为"做 world model"是单一赛道，其实是 4 条
- **理论停滞**：没有统一框架，难以积累知识

> 🎯 **本系列的核心使命**：**澄清"世界模型"到底是什么**——给出统一框架 + 真伪判定。

## 二、四派的世界模型

### 2.1 第一派：视频生成派（"生成即理解"）

**代表**：Sora（OpenAI 2024）、Genie 2（DeepMind 2024）、Diamond（2024）、Veo（Google 2024）

**核心宣称**：能生成看起来像物理世界的视频，**意味着模型理解了物理规律**——视频是世界的"模拟器"。

**Sora 团队的原话**（2024 技术报告）：
> "Sora... serves as a **simulator of the physical world**."

**证据**：
- Sora 生成的视频里，物体保持连贯（杯子不会消失）
- 摄像机运动符合 3D 几何
- 一些简单物理交互（碰撞、遮挡）合理

**反对方**（LeCun 等）：
- Sora 大量生成**违反物理**的视频（杯子穿墙、物体凭空消失）
- 像素生成 ≠ 物理理解——只是统计模式
- "能画 ≠ 能想"

详见 [`advanced/02-视频生成是世界模型吗`](./advanced/03-视频生成是世界模型吗.md)。

### 2.2 第二派：RL 内部模型派（"脑内模拟器"）

**代表**：Ha & Schmidhuber 2018（开山论文）、DreamerV3（Hafner 2023）、PlaNet、MuMo

**核心**：RL agent 学一个**环境的内部模型**——给定当前状态 + 动作，预测下一状态。让 agent 在**脑内"想象"未来**，无需真跑环境。

```
传统 RL:                  Model-based RL (Dreamer):
agent → 环境 → reward     agent → world model → "想象的未来" → 决策
        ↑                                       ↓
        真实交互                                不需要真环境
```

**DreamerV3 的成就**（2023, arXiv:2301.04104）：
- **150+ 任务**用同一配置解决
- **首次从零（无人类数据）在 Minecraft 收集钻石**——长期被视为 RL 重要里程碑
- 训练**比 model-free RL 高效 5-10 倍**

**为什么叫 world model**：它**真的是**环境的可执行模型——给定 (state, action)，rollout 出未来。

### 2.3 第三派：认知架构派（"抽象预测"）

**代表**：Yann LeCun 的 JEPA 系列——I-JEPA（2023）、V-JEPA（2024）、V-JEPA 2（2025）

**核心**：world model 应该预测**抽象表征（latent）**，而非像素。因为：
1. **像素预测太冗余**——预测每个像素的颜色是浪费（世界大部分细节不可预测也不重要）
2. **抽象才是认知**——人类不预测视网膜每个光子，预测"概念级"未来
3. **可预测性 + 抽象**：JEPA 在 latent 空间做预测，**保留概念、丢弃细节**

**JEPA 架构**（简化）：

```
输入 x（图像/视频）
    ↓ encoder
表征 s = f(x)
    ↓ predictor（给定 context + 动作/目标）
预测 ŝ_{t+1}
    ↓ 对比 真实 s_{t+1} = f(x_{t+1})
loss = ‖ŝ_{t+1} - s_{t+1}‖  （或 VICReg）
```

**关键**：预测在**latent 空间**——不重建像素，只学抽象关系。

**LeCun 的反像素生成立场**：
> "Generative models that predict pixels are **doomed** for world modeling."

详见 [`advanced/01-JEPA数学与LeCun路线`](./advanced/02-JEPA数学与LeCun路线.md)。

### 2.4 第四派：具身派（"可交互的物理空间"）

**代表**：RT-2（Google 2023）、Octo（2024）、π₀（Physical Intelligence 2024）、World Labs（李飞飞 2024）、NVIDIA GR00T

**核心**：world model 必须支持**机器人决策**——给定场景，预测动作的物理后果，能控制真实机器人。

**与前三派的区别**：
- vs 视频派：不只是生成视频，要**可控制**
- vs RL 派：不只是游戏环境，要**真实物理世界**
- vs JEPA：不只是抽象预测，要**可执行的动作空间**

**World Labs 的目标**（李飞飞 2024）：
> "Build **large world models** that understand, simulate, and interact with the 3D physical world."

## 三、四派的统一框架

### 3.1 共同本质：预测未来的内部表示

尽管四派方法差异大，**本质都是**：

> **World Model** = agent 内部的、能**预测未来状态**（给定当前状态 + 可能动作）的、**可用于决策或推理**的表示。

四个要素：
1. **状态表示** $s_t$
2. **转移模型** $T(s_{t+1} | s_t, a_t)$（或连续时间版本）
3. **动作空间** $a_t$（可能是 latent / discrete / physical）
4. **可用性**——能 rollout / 想象 / 决策

### 3.2 四派的差异点（决策树）

| 维度 | 视频派 | RL 派 | JEPA | 具身派 |
|---|---|---|---|---|
| **状态空间** | 像素 | 游戏状态 | latent | 3D 场景 + 机器人 |
| **预测对象** | 像素 | 状态/奖励 | latent | 物理 + 动作后果 |
| **动作空间** | 文本 prompt | discrete/continuous controls | 无（自监督）| 真实机器人关节 |
| **可用性** | 视频生成 | rollout 想象 | 表征学习 | 控制决策 |
| **评估** | 视觉真实性 | 任务回报 | linear probing | 物理准确 + 任务成功 |

### 3.3 一个统一图

```
                        通用 World Model 定义
                                ↓
                ┌───────────────┼───────────────┐
                ↓               ↓               ↓
        表示（state）       转移（T）        动作（action）
                ↓               ↓               ↓
    ┌───────┬───────┬───────┬───────────────────────────
    │ 像素   │ 像素   │ latent │ 3D 物理状态
    ↓       ↓       ↓       ↓
  Sora   Dreamer   JEPA   World Labs
```

## 四、什么是"真正的"世界模型——判定标准

### 4.1 三个判定准则

| 准则 | 含义 | 哪派满足 |
|---|---|---|
| **可执行（actionable）** | 能给定动作，预测后果 | RL 派 ✅、具身派 ✅、JEPA 部分、视频派 ❌ |
| **反事实推理（counterfactual）** | 能问"如果换一个动作会怎样" | RL 派 ✅、具身派 ✅、其他 ❌ |
| **物理一致性（physical consistency）** | 预测符合真实物理（不是统计拟合）| **没有派完全满足** |

> 🎯 **核心判定**：当前**没有任何系统完全满足三个准则**。视频派只满足"看起来像"，JEPA 满足"抽象表示"但缺动作，RL 派满足"可执行"但环境简单。

### 4.2 真正的世界模型——一个思想实验

**理想 world model** 应该：
1. 给定场景 + 动作 → 预测物理后果（精确到一定粒度）
2. 能反事实推理（"如果我不推这个杯子，会怎样"）
3. 能跨场景泛化（厨房学的物理用到客厅）
4. 能支持长期规划（"我做这顿饭的全过程"）
5. 能在抽象和具体间切换（"接住球"的物理 + 战术）

**当前没有任何 AI 系统接近**。所有四派都是部分逼近。

### 4.3 为什么没有——根本困难

- **物理世界高维**——比文本/视频复杂得多
- **因果性难学**——相关性 ≠ 因果（[`讲透科学的现代性/03`](../讲透科学的现代性/03-AI时代的科学哲学.md)）
- **长期预测误差累积**——小误差指数放大
- **动作空间连续 + 高维**——机器人 30+ 自由度

## 五、历史脉络——从 Ha&Schmidhuber 2018 到 2026

### 5.1 关键节点

```
2018  Ha & Schmidhuber, "World Models"（arXiv:1803.10122）
      - 提出"agent 在自己 dream 的环境里训练"
      - VAE + RNN + 简单 controller
      - 灵感来源，但效果有限

2019  Dreamer (Hafner)
      - 第一个真正可用的 model-based RL
      - recurrent state space model (RSSM)

2022  LeCun "A Path Towards Autonomous Machine Intelligence"
      - 提出 JEPA 框架
      - 公开反对像素生成派

2023  I-JEPA (LeCun), DreamerV3 (Hafner)
      - I-JEPA: 图像 JEPA，效果好
      - DreamerV3: 150 任务统一算法，Minecraft 钻石

2024  Sora (OpenAI), Genie (DeepMind)
      - Sora: "world simulator" 宣称引发争议
      - Genie: 从视频学可交互环境
      - World Labs (李飞飞) 融资 $230M

2024  V-JEPA (LeCun), π₀ (Physical Intelligence)
      - 视频版 JEPA
      - 通用机器人基础模型

2025  V-JEPA 2, Genie 2, Diamond
      - 更大规模、更多任务
      - 实时游戏 world model

2026  趋势：四派融合（latent + action + 物理约束）
```

### 5.2 当前争论焦点

- **LeCun vs Sora 团队**：像素生成是 world model 吗？
- **RL 派 vs 认知派**：是给 agent 用的，还是给人用的？
- **具身派 vs 文本派**：LLM 是 world model 吗？（OthelloGPT 等实验说部分是）

## 八、一句话总结

> 🎯 **四句话**：
> 1. **当前"世界模型"概念混乱**——四派（视频/RL/JEPA/具身）目标不同、方法不同、评估不同。
> 2. 统一定义：**agent 内部的、能预测未来、可决策的表示**——四派都是部分逼近。
> 3. 真正的 world model 需要：**可执行 + 反事实 + 物理一致**——**当前没有系统满足**。
> 4. 2024-2026 是爆发期（Sora/Genie/DreamerV3/JEPA/World Labs），但**距离真 world model 还远**。

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我长期卡在"为什么 LeCun 坚持 JEPA 反对像素生成"——直觉上能生成逼真视频不就说明懂物理了吗？重读 §2.3 LeCun 那句"pixel prediction is doomed"才顿悟：**像素里大部分细节是不可预测且无关的**（一片树叶在风中怎么摆、一片云下一秒长什么样），强行预测这些不可预测的像素会让模型把算力浪费在拟合噪声上；JEPA 在 latent 空间预测"树叶在动"这个概念而不预测"具体每片叶子在哪"，**保留了与决策相关的抽象、丢弃了与决策无关的细节**。这不是审美之争，是**预测目标的信噪比之争**。
- **F3 术语翻译**：
  - "world model（世界模型）" → agent 脑子里"如果做 A 会发生什么"的预测器，相当于下棋手脑中预演的几步棋——能 rollout 才算真有世界模型
  - "JEPA（联合嵌入预测架构）" → 不重建原始画面，只在"压缩后的抽象表征空间"做预测——丢掉像素细节，保留概念关系
  - "反事实推理" → 能问"如果当时换一个动作，世界会怎样"——数据里没有这种平行宇宙，必须靠模型脑补，是世界模型的最高判定标准
- **F4 回炉**：v1 我把四派写成"谁对谁错"的竞争关系——这是**二元对立误读**。v2 改成"四派是**同一个统一框架（state + transition + action + usability）在不同维度的投影**：视频派选像素当 state、RL 派选游戏状态、JEPA 选 latent、具身派选 3D 物理状态。它们不是对错关系，是**对'什么是 state'和'要不要支持 action'的不同选择**。真正的判定标准是 §4.1 的三准则（可执行 + 反事实 + 物理一致），目前没有派完全满足"。diff：从"四选一"改为"统一框架的不同投影 + 共同未达标"，对应 §3.1 的统一图和 §4 的判定准则。
