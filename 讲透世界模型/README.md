# 讲透世界模型（World Models）

> **2024-2026 AI 圈最热、最混乱的概念**——Sora 自称"world simulator"、LeCun 推 JEPA、DeepMind 出 Genie 2、World Labs（李飞飞）融资数亿……但**每个人说的"世界模型"不是同一件事**。
>
> 本系列做一件简单的事：**把这团混乱讲清楚**——四种"世界模型"定义、各自的代表系统、为什么它们其实**不是同一个东西**、以及什么是**真正的世界模型**。
>
> 一句话定位：[`讲透基础模型`](../讲透基础模型/) 讲"会预测文本"，本系列问"**会预测世界吗**"。
>
> **博士级 + 研究前沿级**：基础层（00-05）+ advanced 层（4 篇博士级深读）。涵盖 Ha&Schmidhuber 2018 → DreamerV3 → JEPA → Sora → Genie 2 → Diamond（2026 实时前沿）。
>
> 配套：[`讲透RL`](../讲透RL/)（Dreamer 系列）+ [`讲透生成模型`](../讲透生成模型/)（视频生成）+ [`讲透AI应用全景/07-AI for AI`](../讲透AI应用全景/07-AI%20for%20AI.md)（递归自我改进的"理解世界"）+ [`讲透科学的现代性/03`](../讲透科学的现代性/03-AI时代的科学哲学.md)（"模型理解世界吗"）

---

## 为什么单独开

- **概念混乱**：业界把"视频生成"/"RL 内部模型"/"认知架构"都叫 world model——必须澄清
- **资金疯狂**：World Labs（李飞飞）、Physical Intelligence、Skild AI 等都拿亿级融资
- **核心争议**：LeCun 说 Sora 不是 world model；Sora 团队说是——这是 2024-2026 最热的学术争论
- **通往 AGI 的关键**：理解物理世界 = 真智能（vs 只是文本预测器）

---

## 四种"世界模型"——本系列的核心框架

```
① 视频生成派     Sora / Genie 2 / Diamond —— "会生成看起来像世界的视频"
② RL 内部模型派  DreamerV3 / MBRL       —— "agent 脑内的环境模拟器"
③ 认知架构派     LeCun JEPA / H-JEPA    —— "预测抽象表征，非像素"
④ 具身派         RT-2 / Octo / π₀       —— "机器人理解物理 + 可行动"
```

**关键洞察**：这四派**目标不同、方法不同、评估不同**——把它们混为一谈是当前讨论混乱的根源。
