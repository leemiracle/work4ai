# 讲透世界模型

> **世界模型（World Model）= 学到的环境模型** $\hat P(s'|s,a), \hat r$。它是 **model-based RL 的核心组件**（Dreamer/MBPO），也是 **2024-2026 独立的核心范式**——Sora（视频生成）、Genie 2（可玩世界）、V-JEPA（LeCun 路线）都在抢"谁能让 AI 真正理解世界"。
>
> 本系列做三件事：①厘清"世界模型"的**概念混乱**（同一个词四种意思）；②深挖两大**路线之争**（LeCun JEPA vs OpenAI scaling）；③给出 **RL 内 world model 的算法基础**（配 [`讲透RL/08`](../讲透RL/08-Actor-Critic-SAC-ModelBased-OfflineRL.md)）。

## 核心：两派世界模型（本系列的主线）

```
        "怎么让 AI 真正理解世界？"
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
   显式预测派                 隐式涌现派
   (LeCun JEPA)              (OpenAI Sora/Scaling)
        │                       │
  预测抽象表征               预测像素
  理论可解释                 黑箱 + 赌 scaling
  落地：研究阶段             落地：已产品化
        │                       │
        └───────────┬───────────┘
                    ▼
          2024-2026 最大 AI 争论之一
```

**LeCun 的批评**：Sora 不"懂"物理，只是生成统计上像的视频——遇到分布外场景会崩。
**OpenAI 的回应**：足够大的模型 + 数据会涌现真物理理解。
**本系列立场**（[04 开放问题](./04-开放问题与研究方向.md)）：两者都没被证伪，评测"懂物理 vs 记模式"本身是开放问题。
