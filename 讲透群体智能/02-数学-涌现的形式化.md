# 📐 第 2 幕 · 数学：涌现的形式化

## 1. 元胞自动机：涌现的最纯粹形式

一个一维元胞自动机：每个格子的下一状态是其邻居状态的函数：

$$c_i^{t+1} = f(c_{i-r}^t, ..., c_i^t, ..., c_{i+r}^t)$$

$f$ 是局部规则，$r$ 是邻居半径。对二值格子（0/1），半径 1 邻居，有 $2^{2^3} = 256$ 种规则（Wolfram 编号 0-255）。

**Wolfram 的发现**：这 256 种规则分四类：
1. **均匀**（rule 0）：全死/全活
2. **周期**（rule 4）：简单重复
3. **混沌**（rule 30）：伪随机
4. **复杂**（rule 110）：**局部结构 + 长期演化 → 图灵完备**

**震撼**：rule 110 只是一条规则，却图灵完备。这就是「简单局部规则 = 任意复杂」的最硬证据。

## 2. Reynolds Boids：三条局部规则

鸟群模型（Reynolds 1987），每个个体基于邻居计算三个力：

$$\mathbf{v}_i^{t+1} = \mathbf{v}_i^t + \underbrace{w_s \mathbf{f}_{\text{sep}}}_\text{分离} + \underbrace{w_a \mathbf{f}_{\text{align}}}_\text{对齐} + \underbrace{w_c \mathbf{f}_{\text{coh}}}_\text{聚合}$$

- $\mathbf{f}_{\text{sep}} = -\sum_{j \in N_{\text{close}}} (\mathbf{x}_j - \mathbf{x}_i)$：避免太近
- $\mathbf{f}_{\text{align}} = \frac{1}{|N|}\sum_{j \in N} \mathbf{v}_j - \mathbf{v}_i$：朝邻居平均方向
- $\mathbf{f}_{\text{coh}} = \frac{1}{|N|}\sum_{j \in N} \mathbf{x}_j - \mathbf{x}_i$：朝邻居中心

**涌现**：没有任何一条规则说「群体转弯要同步」，但群体自动同步。这是「**整体 ≠ 部分之和**」的活体演示。

## 3. Stigmergy：通过环境的间接协调

蚁群找最短路径的数学：

设路径 $L$ 上信息素浓度 $\tau_L(t)$。每只蚂蚁以概率选路径：

$$P(\text{选 } L) = \frac{\tau_L^\alpha \eta_L^\beta}{\sum_{L'} \tau_{L'}^\alpha \eta_{L'}^\beta}$$

$\eta_L = 1/\text{length}(L)$（短路径启发式），$\alpha, \beta$ 是权重。

更新：$\tau_L \leftarrow (1-\rho)\tau_L + \sum_{\text{ants on } L} \Delta\tau$。$\rho$ 是挥发率。

**收敛**：短路径上蚂蚁往返快→信息素积累快→更多蚂蚁选它→正反馈。这就是 **Ant Colony Optimization**（ACO），可解 TSP 等组合问题。

## 4. 相变与临界

涌现常发生在**临界点**附近。Ising 模型：

$$E = -J\sum_{\langle i,j \rangle} s_i s_j$$

温度 $T$ 跨过 $T_c$ 时，系统从无序磁化跃迁到有序。**临界点附近，局部扰动能传播很远**（无标度相关）——这就是涌现的物理条件。

生物系统据推测维持在**临界点附近**（SOC, self-organized criticality）——既能响应又能存储。

## 5. 网络科学：小世界与无标度

**Watts-Strogatz 小世界**（1998）：少量长程连接，让网络同时高聚类 + 短路径。社交网络、神经网络都是。

**Barabási-Albert 无标度**：度分布 $P(k) \sim k^{-\gamma}$，少数 hub 连接大量节点。互联网、代谢网都是。

**涌现启示**：网络结构决定动力学。同样的局部规则，在不同拓扑上涌现出截然不同的集体行为。

## 6. Wolfram 计算等价性

> **任何非平凡的迭代系统，计算复杂度都差不多。**

形式化（弱版）：任何能支持通用计算的简单系统，等价于图灵机。所以 rule 110 能模拟任何计算——**智能不需要特殊基质**。

争议：这是「智能」还是「计算」？Wolfram 把两者等同，多数研究者认为太宽。但它解释了为什么涌现如此普遍：**它不是特例，是默认**。
