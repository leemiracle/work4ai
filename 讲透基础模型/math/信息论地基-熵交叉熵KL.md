# 信息论地基：熵、交叉熵、KL 散度

> 这是「讲透基础模型」的数学地基。基础模型预训练那个到处出现的 `cross_entropy_loss`，本质全是这一页的内容。你数学自评 0，所以我们**从三条公理一步步推**，不跳步。配套实验：`entropy_demo.py`。

---

## 0. 起点：什么叫「一个事件包含多少信息」？

1948 年 Shannon 想量化一件事：**「太阳今天东升」和「彩票今天中奖」给你带来的「信息量」显然不同**。前者你早知道，没信息；后者极度意外，信息量巨大。

他要找一个函数 $I(p)$，输入事件概率 $p$，输出"信息量"。这函数该长什么样？Shannon 提了**三条公理**，剩下的全是数学推出来的。

---

## 1. 自信息：三条公理 → $I(p) = -\log p$

### 三条公理

| 公理 | 含义 | 直觉 |
|---|---|---|
| **连续性** | $I(p)$ 关于 $p$ 连续 | 概率稍微变一点，信息量不该跳变 |
| **单调性** | $p$ 越小，$I(p)$ 越大 | 越罕见越意外 |
| **可加性** | $I(p_1 p_2) = I(p_1) + I(p_2)$ | 两个**独立**事件一起发生的信息 = 各自信息之和 |

### 推导（Cauchy 函数方程）

可加性是关键约束。设 $f(p) = I(p)$，则 $f(p_1 p_2) = f(p_1) + f(p_2)$。

这是著名的 **Cauchy 函数方程**。加上连续性，唯一解是
$$f(p) = c \log p \quad (c \text{ 为常数})$$

（*证明思路*：令 $g(x)=f(e^x)$，则 $g(x+y)=g(x)+g(y)$，连续解为 $g(x)=kx$，故 $f(p)=k\ln p$。）

再由单调性（$p$ 越小 $I$ 越大）要求 $c<0$。取 $c=-1$、对数底为 2（单位 bit），得到：

$$\boxed{I(p) = -\log_2 p}$$

### 实验验证（`entropy_demo.py` Part 1）

```
太阳东升   p=1      I=0.00 bit    (不意外, 不占编码)
硬币正面   p=0.5    I=1.00 bit    (二选一, 1 bit)
骰子点数6  p=1/6    I=2.58 bit    (= log2 6)
彩票中奖   p=1e-6   I=19.93 bit   (极罕见, 要长编码)
```

**自信息同时是两件事**：(a) 收到该事件的"意外程度"；(b) 最优编码它所需的最少比特数。这两者相等，是信息论最深的洞见之一——**意外 = 编码长度**。

---

## 2. 熵 $H(X)$：平均不确定性 = 压缩下限

随机变量 $X$ 取很多可能值，每个值有自信息。**平均**自信息就是熵：

$$H(X) = \mathbb{E}[I(X)] = -\sum_x p(x)\log_2 p(x)$$

### 熵的三种等价理解

1. **平均惊讶度**：长期观察这个随机源，每次平均"意外"多少
2. **平均最短编码长度**：最优编码下，每个符号平均占多少 bit
3. **最优是非题数**：要确定 $X$ 的取值，平均最少要问多少个 yes/no

### 实验验证（Part 2）

```
公平硬币 [0.5,0.5]  : H=1.000 bit  (就是 1 个是非题)
公平骰子 [1/6]*6    : H=2.585 bit  (= log2 6)
偏置硬币 [0.99,0.01]: H=0.081 bit  (几乎确定, 几乎不用问)
```

**熵是不可压缩的下限**。任何编码方案的平均长度 $\geq H(X)$（Shannon 信源编码定理）。这一句极其重要——它意味着：**熵以下的信息，是宇宙级别的"真实不确定性"，谁也消不掉**。基础模型训练时 loss 跌不破的那个值，就是训练数据的熵。

---

## 3. 交叉熵 $H(P,Q)$：模型 $Q$ 给真实 $P$ 造成的代价

现在有两个分布：真实分布 $P$（数据真实规律），模型分布 $Q$（模型以为的规律）。

如果我们**用 $Q$ 的编码去传 $P$ 的事件**，平均每个符号花多少 bit？这就是交叉熵：

$$H(P,Q) = -\sum_x p(x)\log_2 q(x) = \mathbb{E}_{x\sim P}\big[-\log_2 q(x)\big]$$

注意：事件按 $P$ 发生（用 $p(x)$ 加权），但编码长度按 $Q$ 算（$-\log q(x)$）。**模型认错了规律，就要多花比特**。

### 关键恒等式

$$\boxed{H(P,Q) = H(P) + D_{KL}(P\,\|\,Q)}$$

即 **交叉熵 = 真实熵 + KL 散度**。模型越准（$Q\to P$），KL→0，交叉熵降到 $H(P)$ 这个下限。

### 实验验证（Part 3）

真实 $P=[0.7,0.3]$，熵 $H(P)=0.8813$ bit：

| 模型 $Q$ | 交叉熵 | KL散度 |
|---|---|---|
| 完美匹配 [0.7,0.3] | 0.8813 | 0.0000 |
| 瞎猜均匀 [0.5,0.5] | 1.0000 | 0.1187 |
| **搞反了** [0.3,0.7] | 1.3702 | **0.4890**（罚最重） |
| 过度自信 [0.9,0.1] | 1.1030 | 0.2217 |

---

## 4. KL 散度：模型与真实的「额外代价」+ Gibbs 不等式

$$D_{KL}(P\,\|\,Q) = \sum_x p(x)\log_2\frac{p(x)}{q(x)} = \mathbb{E}_{x\sim P}\!\left[\log_2\frac{p(x)}{q(x)}\right]$$

### Gibbs 不等式：$D_{KL}(P\|Q) \geq 0$，等号当且仅当 $P=Q$

这是整个机器学习最重要的不等式之一。证明只用 **Jensen 不等式**（凸函数的期望 ≥ 期望的函数）：

**证明**：注意到 $-\log$ 是**凸函数**（$(-\log)'' = 1/x^2 > 0$）。

$$D_{KL}(P\|Q) = \mathbb{E}_{x\sim P}\!\left[-\log\frac{q(x)}{p(x)}\right] \;\geq\; -\log\!\left(\mathbb{E}_{x\sim P}\!\left[\frac{q(x)}{p(x)}\right]\right) \;=\; -\log\!\left(\sum_x p(x)\frac{q(x)}{p(x)}\right) \;=\; -\log\!\left(\sum_x q(x)\right) \;=\; -\log 1 = 0$$

等号成立 ⟺ $q(x)/p(x)$ 为常数 ⟺ $P=Q$。$\blacksquare$

### 实验验证（Part 4）

10 万组随机分布对，KL 最小值 = **0.000064**（永远 ≥0，仅 $P=Q$ 时≈0）。

> **直觉解读**：KL 是"用错的编码 $Q$ 比用对的编码 $P$ **多花**的比特数"。多花的当然 ≥0。而且它**同时惩罚两种错误**：方向错（[0.3,0.7]）和过度自信（[0.9,0.1]）都被罚。

---

## 5. 三合一：最大似然 = 最小交叉熵 = 最小 KL

这是深度学习里**到处写 `cross_entropy_loss` 的根本原因**。三者完全等价。

### 设定

真实数据分布 $P$（未知），模型参数 $\theta$ 给出分布 $Q_\theta$。观测到数据 $x_1,\dots,x_n \sim P$。

### (1) 最大似然

$$\hat\theta_{MLE} = \arg\max_\theta \prod_{i=1}^n Q_\theta(x_i) = \arg\max_\theta \sum_{i=1}^n \log Q_\theta(x_i)$$

### (2) 最小交叉熵

$$\arg\min_\theta H(P, Q_\theta) = \arg\min_\theta \mathbb{E}_{x\sim P}\big[-\log Q_\theta(x)\big]$$

由大数定律，$\frac1n\sum_i \log Q_\theta(x_i) \to \mathbb{E}_{x\sim P}[\log Q_\theta(x)]$。所以**最大化平均对数似然 ⟺ 最小化交叉熵**。

### (3) 最小 KL

$$D_{KL}(P\|Q_\theta) = H(P,Q_\theta) - H(P)$$

$H(P)$ 是数据的真实熵，**与 $\theta$ 无关**（常数）。所以**最小交叉熵 ⟺ 最小 KL**。

### 三者合一

$$\boxed{\arg\max_\theta \text{似然} \;=\; \arg\min_\theta H(P,Q_\theta) \;=\; \arg\min_\theta D_{KL}(P\|Q_\theta)}$$

### 实验验证（Part 5）

抛一枚真币 $p(\text{正})=0.7$，N 次：

```
N=10:   MLE 估计 q=0.900  交叉熵=1.1030
N=100:  MLE 估计 q=0.660  交叉熵=0.8865
N=1000: MLE 估计 q=0.712  交叉熵=0.8818  (真熵 H(P)=0.8813)
```

N 越大，MLE 越准（$q\to0.7$），交叉熵越逼近真实熵。**这就是模型训练在做的事**：用数据估计分布，让交叉熵（=损失）逼近熵（=下限）。

---

## 6. 微分熵（连续情况，简要）

token 是离散的，所以基础模型用上面的离散熵。但有时会碰到连续变量（如高斯），用**微分熵**：

$$h(X) = -\int p(x)\log p(x)\,dx$$

⚠️ 微分熵可以是**负数**（连续分布没有"最少 bit"的下限概念），且对坐标变换敏感。连续情况下 KL 散度仍 $\geq0$ 且与坐标无关，所以**机器学习里真正稳健的是 KL/交叉熵，不是微分熵本身**。

## 7. 收束：这一切如何接回基础模型

| 信息论概念 | 在基础模型里是什么 |
|---|---|
| 真实分布 $P$ | 互联网文本的真实统计规律（下一个词的真实分布） |
| 模型分布 $Q_\theta$ | 神经网络 softmax 输出的下一个词预测分布 |
| 交叉熵 $H(P,Q_\theta)$ | **就是预训练损失 `cross_entropy`** |
| 熵 $H(P)$ | 损失永远跌不破的下限（数据本身的不确定性） |
| KL 散度 | 模型与真实的差距，训练把它压向 0 |
| 自信息 $-\log Q_\theta(x)$ | 该 token 的最优编码长度 |
| **算术编码** | **用 $Q_\theta$ 对文本编码 ≈ 压缩；压得越短 = 模型越懂规律** |

所以基础模型预训练的物理意义是：**找一个分布 $Q_\theta$，使整个互联网文本的交叉熵最小——也就是把互联网压缩到最短**。而能压缩到最短的模型，必然已经"理解"了互联网的所有可学规律。这就是下一篇 `00-为什么预测下一个词能产生智能` 的核心。

## 8. 局限与批判（不要把它当万能）

1. **熵 ≠ 语义**。熵衡量的是统计可预测性，不是"真正理解"。一个完美记住训练集的模型交叉熵能到很低，但它只是背诵，没泛化。**压缩是理解的必要不充分条件**。
2. **KL 不对称**。$D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$。基础模型用 forward KL（mode-seeking vs mean-covering 有讲究）。
3. **真实分布 $P$ 未知**。我们只能用经验分布（数据）逼近，所以"最小化交叉熵"实际是"最小化经验交叉熵"，这才引入了**泛化、过拟合、数据量**等问题——这些是后续 Scaling Law 的主题。
4. **token 离散但嵌入连续**。语言模型把离散 token 映射到连续空间，连续空间的几何（余弦相似度等）不直接来自信息论，需要表示学习补充。
