# 05 — 从基座到助手：SFT → RLHF → DPO 的损失函数变迁

> 承接 00–04：我们讲完了"基座模型怎么训出来"——在海量文本上预测下一个词。但基座模型只是"博学但不懂规矩的怪物"：它会续写，但不会对话、可能骂人、不会遵循指令。这一篇讲透：**基座模型怎么变成听话、安全、有用的助手**，以及损失函数怎么一步步演化。
>
> 配套实验：`experiments/05_sft_dpo.py`。

---

## 1. 基座 vs 助手：差在哪？

| | 基座模型（Base） | 助手模型（Instruct/Chat） |
|---|---|---|
| 训练目标 | 预测下一个词（NTP） | 遵循指令 + 对齐人类偏好 |
| 行为 | 续写文本（可能跑题、有害） | 对话、拒答有害、有用 |
| 例子 | GPT-3、LLaMA-Base | ChatGPT、LLaMA-Chat |

你问基座"怎么做红烧肉"，它可能续写成"…红烧肉的做法。然后我们把猪肉…"——一段百科文本，而不是回答你。**助手模型是把基座"调教"成的产品**。

调教分三步进化：**SFT → RLHF → DPO**。

---

## 2. SFT：监督微调（仍是交叉熵）

最朴素：收集一批"指令-好回答"数据（人工写或 GPT-4 合成），在这些数据上**继续训练基座**，目标**仍是交叉熵**——只不过只在"好回答"的 token 上算 loss：

$$\mathcal{L}_{SFT} = -\sum_t \log Q_\theta(y_t \mid x, y_{<t})$$

（$x$ 是指令，$y$ 是好回答。和 00 篇的 NTP 一模一样，只是数据从"任意文本"变成"指令-回答对"。）

### 实验（`05_sft_dpo.py` Part 1）

```
初始 logits 均匀(基座啥都不会)
SFT 200步: P(好回答) 0.25 → 0.996
```

**SFT 让模型学会"好回答长什么样"**。但这有局限：
- 只能学到"模仿标注的好回答"，学不到"为什么这个比那个好"。
- 标注数据有限，覆盖不了所有偏好判断。
- 模型仍可能输出有害内容（如果没标注"不该说什么"）。

所以需要用**人类偏好**（A 好于 B）进一步对齐。

---

## 3. RLHF：经典三阶段（复杂但有效）

ChristianO et al. / InstructGPT（2022）的 RLHF（Reinforcement Learning from Human Feedback）：

```
① SFT 基座
   ↓
② 训练奖励模型 RM：人工给(A,B,C)排序 → RM 学会打分 r(x,y)
   ↓
③ PPO 强化学习：用 RM 的分数当奖励，优化策略 πθ，同时 KL 约束不偏离 SFT 太远
```

目标函数：

$$\max_{\pi_\theta}\; \mathbb{E}_{x\sim D, y\sim\pi_\theta}[r(x,y)] - \beta\, D_{KL}\big(\pi_\theta \,\|\, \pi_{\text{ref}}\big)$$

**问题**：
- **两阶段**（先 RM 后 PPO），工程复杂。
- **不稳定**：PPO 是 on-policy RL，超参敏感，奖励 hacking。
- **显存翻倍**：要同时放 policy、value、reference、reward 四个模型。

---

## 4. DPO：把 RLHF 一步搞定（Rafailov 2023 的漂亮数学）

DPO（Direct Preference Optimization）的核心洞察：**RLHF 的最优解有闭式表达，可以把奖励模型解析消去**。

### 推导（关键！）

RLHF 目标 $\max\;\mathbb{E}[r] - \beta\,D_{KL}(\pi\|\pi_{\text{ref}})$ 的最优解满足（变分法求导）：

$$\pi^*(y|x) = \frac{1}{Z(x)}\pi_{\text{ref}}(y|x)\exp\!\left(\frac{r(x,y)}{\beta}\right)$$

反过来解出奖励：

$$r(x,y) = \beta\log\frac{\pi^*(y|x)}{\pi_{\text{ref}}(y|x)} + \beta\log Z(x)$$

代入偏好模型（Bradley-Terry：$P(y_w \succ y_l) = \sigma(r(y_w)-r(y_l))$），**归一化常数 $Z(x)$ 相消**：

$$P(y_w \succ y_l \mid x) = \sigma\!\left(\beta\log\frac{\pi(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta\log\frac{\pi(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)$$

对这个偏好概率做最大似然，得到 **DPO 损失**（无需奖励模型！）：

$$\boxed{\mathcal{L}_{\text{DPO}} = -\log\sigma\!\left(\beta\Big[\underbrace{\log\tfrac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)}}_{\text{好回答相对提升}} - \underbrace{\log\tfrac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}}_{\text{坏回答相对提升}}\Big]\right)}$$

### 三层理解

1. **数学上**：DPO 和 RLHF 优化的是同一个目标，只是把 RM 这一步用闭式解消去了。
2. **直觉上**：让"好回答相对参考模型的提升" > "坏回答相对参考模型的提升"——即**提高好/坏的相对比**。
3. **工程上**：一阶段、无 RM、无 PPO、稳定——只比 SFT 多一个参考模型（冻结，不算梯度）。

---

## 5. DPO 实验（`05_sft_dpo.py` Part 3）

玩具：4 个候选词，偏好"词0 好于 词1"，用 DPO loss 优化：

```
step   0: DPO loss=0.693  P(好)=0.276  P(坏)=0.226
step 100: DPO loss=0.016  P(好)=0.969  P(坏)=0.000
step 300: P(好)=0.993  P(坏)=0.000
```

**⚠️ 诚实声明**：这个单偏好对玩具里，DPO 把 P(好) 也推到 0.993（和 SFT 一样激进），因为只有一个偏好 + 过训练。**真实 DPO 有海量偏好对 + β 约束 + 多样性，行为更温和稳健**——它会提高好/坏的相对比，但不会把某个回答推到 1（保留多样性，不过度偏离参考模型）。β 就是控制"偏离程度"的旋钮。

---

## 6. SFT vs DPO 对比

| | SFT | DPO |
|---|---|---|
| 数据 | 指令-好回答 | 偏好对（好 > 坏） |
| 损失 | 交叉熵（模仿） | DPO loss（相对偏好） |
| 学到 | "好回答长什么样" | "为什么这个比那个好" |
| 行为 | 激进模仿标注 | 相对调整 + KL 约束 |
| 显存 | 1 个模型 | 2 个（策略 + 冻结参考） |

**现代主流流程**：基座 → SFT（学会对话格式）→ DPO（对齐人类偏好）。LLaMA-3、Qwen、DeepSeek 都走这条路（部分还叠加在线 RLHF / GRPO 进一步打磨）。

---

## 7. 局限与前沿

1. **偏好数据是瓶颈**：DPO/RLHF 都需要"好 > 坏"的成对标注，昂贵且主观。合成偏好（用强模型当裁判，LLM-as-Judge）是当前主流，但引入裁判自身偏见。
2. **DPO 的过简单化假设**：Bradley-Terry 假设偏好可传递、可打分，但人类偏好常是矛盾/上下文相关的。
3. **新趋势 GRPO（DeepSeek）**：把 PPO 的 value 网络也省掉，用组内相对优势，更省显存——2024–2025 的推理模型（o1/R1）常用。

---

## 8. 一句话总结

> **基座模型通过后训练变成助手：SFT 在'指令-好回答'上做交叉熵学会对话格式（仍是 NTP 的 CE）；RLHF 用奖励模型+PPO 对齐人类偏好但复杂不稳定；DPO 通过闭式解消去奖励模型，把偏好对直接变成一个类似二分类的损失 $\,-\log\sigma(\beta[\Delta\log\pi_w - \Delta\log\pi_l])\,$，一阶段、稳定，成为现代主流。三者本质都是：从'模仿好回答'到'理解为什么好'。**

---

## ✍️ 练习（`05_sft_dpo.py`）

1. **β 的作用**：把 DPO 的 β 从 0.5 调到 0.05（更强 KL 约束），观察 P(好) 是否更难推高——亲手感受"β 越小，模型越不敢偏离参考"。
2. **多偏好对**：把实验改成 3 个偏好对（不同词），看 DPO 如何同时平衡多个偏好。
3. **DPO 失败模式**：构造一个"好回答在参考模型下概率极低"的偏好对，观察 DPO 是否难以提升（梯度饱和）——理解 DPO 的局限性。
