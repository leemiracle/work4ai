## 核心方法论（"讲透"标准）

1. **原理优先于 API**：先讲为什么，再讲怎么调库。
2. **每个结论都有可运行代码佐证**：不凭记忆下断言，数字都是跑出来的。
3. **批判性**：每篇结尾有「局限与争议」，不把漂亮理论当教条。
4. **离散 vs 连续分水岭始终强调**：从 MSE/回归跨到 CE/分类必须翻的坎。

---

## 贯穿全系列的七个核心洞见

1. **预测下一个词 = 压缩 = 理解**（00）：NTP 损失即编码长度，训练即找最优压缩机，压到最短逼出"理解"。
2. **交叉熵是分类的唯一正确目标**（信息论+00）：=最大似然=最小KL，有信息论根基；MSE 对离散 token 被 softmax 扭曲。
3. **attention 用点积衡量相关度，一步看全部上下文**（01）：淘汰 RNN 的根本，除√d 防饱和，代价是 O(n²)。
4. **loss 随规模幂律下降，可外推预测**（02）：α≈−0.076 极平缓但永不停；Chinchilla 最优 D≈20N。
5. **涌现一半是相变一半是度量幻觉**（03）：换连续度量突变就消失（mirage），但 CoT 等部分能力是真相变。
6. **RoPE 把绝对位置旋转成相对位置**（04）：兼顾表达力与长度外推，现代 LLM 标配。
7. **SFT→DPO 把"模仿好回答"升级为"理解为何好"**（05）；**KV Cache+量化+蒸馏**把大模型变成可部署产品（06）。

1. **讲透基础模型 防的是什么欺骗？** → 模型表面能力与真实能力的伪装。
