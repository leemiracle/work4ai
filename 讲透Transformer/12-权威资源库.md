## 🔴 A. 系统级/实现深度 (最接近 ezyang 风格)

这一类是"把 Transformer 拆到 GPU 寄存器/内存层次"的硬核博客, 与 ezyang 同源。

### 1. Ed Z. Yang — blog.ezyang.com ✅
- **身份**: Meta PyTorch 核心开发, GPU/编译器/分布式专家
- **风格**: 🔴 最硬核。深入 autograd 内部、mutation/aliasing、SPMD 分布式、PyTorch 编译
- **代表作**: *Autograd and Mutation* (2026) / *Global vs Local SPMD* / *AI-assisted programming*
- **对应**: 01 Self-Attention 深度 (理解 PyTorch 如何执行 attention)、09 推理 (系统级)
- **价值**: 想理解"PyTorch 到底怎么跑 Transformer", 这是第一站

### 2. Tri Dao — 三篇 FlashAttention 论文 + GitHub
- **身份**: FlashAttention 作者, Mamba 作者
- **风格**: 🔴 GPU 内核级。tiling/online softmax/SRAM-HBM 层次
- **代表作**: *FlashAttention: Fast and Memory-Efficient Exact Attention* (Dao 2022) / FA-2 / FA-3
- **对应**: 01 篇 FlashAttention 原理 / FlashMLA
- **链接**: github.com/Dao-AILab/flash-attention

### 3. GPU MODE — learngpu.com / github.com/gpu-mode
- **风格**: 🔴 CUDA 内核教学社区。从零写 attention kernel
- **价值**: 想真正理解 "softmax(QK^T)V 在 GPU 上怎么 tile", 在这学写 CUDA
- **对应**: 01/09 篇 (推理优化的底层)

### 4. Sasha Rush — srush.github.io / annotated-transformer
- **身份**: PyTorch/HuggingFace 关联学者, McGill 教授
- **风格**: 🔴 "逐行注解源码"。*The Annotated Transformer* 把原论文用 PyTorch 一行行注解
- **对应**: 11 篇源码对照的前身 / 00 全景
- **链接**: nlp.seas.harvard.edu/annotated-transformer

### 5. Modal Blog — modal.com/blog ✅ (CS25 V6 Frye)
- **身份**: Charles Frye (Full Stack Deep Learning)
- **风格**: 🔵→🔴 生产推理实战。Serving Transformers 的坑
- **对应**: 09 推理优化

### 6. Chip Huyen — huyenchip.com
- **身份**: ML 系统专家, 斯坦福教 ML Systems
- **风格**: 🔵 ML 系统工程。*Designing Machine Learning Systems*
- **对应**: 07 预训练 / 09 推理 (MLOps 视角)
