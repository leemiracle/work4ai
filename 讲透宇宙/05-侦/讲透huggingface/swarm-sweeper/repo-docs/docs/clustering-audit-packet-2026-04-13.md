## Review heuristic

Strong evidence that a cluster is useful:

- same issue target
- same file or module family
- same error string or crash
- same subsystem and same concrete fix
- multiple PRs clearly look like alternate attempts at one change

Strong evidence that a cluster is not useful for duplicate triage:

- only generic lexical overlap (`fix`, `refactor`, `test`, `xpu`, `model`)
- PR-only cluster with no clear issue anchor
- “campaign” or “initiative” grouping rather than one bug/fix
- large heterogeneous cluster spanning many model-specific chores
