# 讲透 NVIDIA/FastPhotoStyle

> ECCV 2018《A Closed-form Solution to Photorealistic Image Stylization》(arXiv:1802.06474) 官方 PyTorch 实现，CC BY-NC-SA 4.0（禁商用）。本克隆 @af0c8fe，"论文 artifact 型"小仓：价值在算法链路，工程现代化为零。

## 一、定位：两阶段照片级风格迁移

TUTORIAL.md:23-25 官方定义：① **PhotoWCT**——对内容/风格图深度特征做 whitening-and-coloring transform，产出带畸变的风格化图；② **Photorealistic Smoothing**——平滑滤波消畸变，得到如相机直出的照片。与艺术风格迁移追求笔触相反，本方法保持照片结构；相比 DPST（TUTORIAL.md:210 致谢）逐图优化分钟级，本方法纯前向+滤波秒级出图。

## 二、架构

### 2.1 PhotoWCT 网络（models.py + photo_wct.py）

骨架是 4 对层级自编码器（photo_wct.py:16-23 实例化 e1-e4/d1-d4）。

- `VGGEncoder`（models.py:8-187）：截断到第 k 层的标准化 VGG-16。关键细节是 `MaxPool2d(..., return_indices=True)`（models.py:28/43/68）保留池化索引；`if level<N: return` 逐级注册（:22/36/51）裁出 4 个深度；`forward_multiple`（:131-187）一次前向同时产出 relu4_1~relu1_1 四级风格特征。
- `VGGDecoder`（models.py:190-297）：论文称 feature invertor。用 `MaxUnpool2d` 按池化索引精确还原位置（models.py:201/225/239，消费见 :259/277/287），而非艺术化 WCT 的上采样——**消伪影、保结构的核心设计**（论文 §3.2）。

**transform 主循环**（photo_wct.py:25-54）：风格图经 e4.forward_multiple 一次编码（:28），内容图逐级 `e_k 编码 → __feature_wct → d_k 解码`——粗尺度注入全局色调，细尺度注入纹理。

**`__wct_core`**（photo_wct.py:122-164）：对 C×(H·W) 特征——去均值 → 协方差加单位阵正则（:132）→ `torch.svd`（:134）→ 特征值 1e-5 阈值截断（:138-142）→ 白化（:156-159）→ 风格特征重新上色（:161-162）→ 加回风格均值。即把内容特征二阶统计量整体换成风格的，全程无参数无需训练。

**分割感知 WCT**：`__compute_label_info`（photo_wct.py:56-68）预筛两图都出现、像素数>10、面积比<100 的标签（:65）；`__feature_wct`（:70-120）把分割图 NEAREST 缩放到特征分辨率（:81），逐标签 `torch.index_select` 抽特征列（:103-104）独立 WCT 再写回——天空只学天空的颜色；:109-116 是 PyTorch 0.4.0 `index_copy_` bug 绕道。

### 2.2 标签对齐（ade20k_semantic_rel.npy + SegReMapping）

`SegReMapping`（process_stylization_ade20k_ssn.py:43-121）加载 150×150 语义关系矩阵（ade20k_semantic_rel.npy，:45）：`self_remapping`（:94-121）把占比 <2% 的小标签归并到大标签，`cross_remapping`（:48-92）把对方图缺失的标签映射到语义最近标签，流水线串联调用（:162-164）。

### 2.3 Smoothing 管线（两层）

以 process_stylization.stylization 为准，第二阶段=传播+后处理：

- **传播层（二选一，鸭子接口 process(initImg, contentImg)）**：默认 `Propagator`（photo_smooth.py:15-99）构建闭式抠图拉普拉斯稀疏阵（:68-87，af0c8fe 即补 Marco Forte credit），对 `(I-β·S)` 稀疏分解逐通道求解（:43-56，β 默认 0.9999）；`--fast` 走 `GIFSmoothing`（photo_gif.py:13-45）的 `cv2.ximgproc.guidedFilter`（:42）廉价近似。
- **后处理层**：`smooth_filter`（smooth_filter.py:380-405）内嵌约 320 行 CUDA C 源码，运行时 pynvrtc 编译、cupy 加载（:327-328/335-336），依次启动 best_local_affine（每像素 12 参数局部仿射）→ bilateral_smooth → reconstruction_best（按仿射模型从内容图重建）三 kernel（:340-342）。论文 §3.3 的 smoothing step 本体：只允许局部仿射色彩变换，去畸变不抹结构。两条流水默认都调它，`f_radius=15, f_edge=1e-1`（process_stylization.py:118/135）。

## 三、入口全景（demo 与"训练"）

**实际入口 4 个，TUTORIAL 只写前 3 个**：

- **demo.py:11-48**：单对图无掩码（权重默认 :12），:28-33 按 `--fast` 延迟 import 选 GIF/Propagator；
- **demo_with_ade20k_ssn.py**：自动分割（150 类）+ 掩码风格化，平滑选择同上（:73-78）；
- **process_stylization_folder.py**：目录批量，五子目录约定（:27-31）、同名配对循环（:46-51），平滑选择 :39-44；
- **demo_example*.sh**：axel 拉图 + imagemagick 缩放再调上述 Python。

**本仓没有任何训练代码**：WCT 是闭式解无参可训；encoder 权重来自标准化 VGG，decoder 权重是作者发布的 feature invertor。converter.py 是 t7→pth 历史迁移工具，依赖 `torch.utils.serialization.load_lua`（converter.py:5，PyTorch 0.4.1 后已删）且 .t7 不在仓库，不可运行。**复现=下载预训练权重**：download_models.py 从 Google Drive 拉 models.zip（:33）；自动分割路径还需按 TUTORIAL.md:139 手工 clone 分割网络到 segmentation/——**非 submodule（仓内无 .gitmodules）**，demo_with_ade20k_ssn.py:36 help 文本"git submodule update"与实际不符；且 import 即读子模块数据（process_stylization_ade20k_ssn.py:17）。

## 四、与论文对应

两阶段框架 ⇔ 论文 Fig.2（TUTORIAL.md:23-25）；photo-decoder 用 unpooling 替代上采样 ⇔ models.py:201/259（消融显著降畸变）；多级 WCT 级联 ⇔ photo_wct.py:25-54；分割感知+标签对齐 ⇔ 论文 §3.4；最优局部仿射+双边平滑 ⇔ §3.3 的 smooth_filter.py 三 kernel。

## 五、使用建议与坑

1. **2018 环境钉死**：Dockerfile:1 基于 cuda9.1/ubuntu16.04、:26 装 pytorch 0.4.1、:30 装 cupy-cuda91，现代已无对应版本；photo_smooth.py:23/29/38 的 `scipy.misc.imread/imresize` 在 scipy≥1.3 已删。复现需替换 IO 层 + 新 cupy API 重写 kernel 加载，或用社区 fork。
2. **CPU 不可用**：process_stylization.py:113 显式 return，GPU 硬需求。
3. **尺寸钳制**：短边<256 放大、长边>960 缩小（process_stylization.py:42-43），输出再双线性还原（:105/125）——大图被悄悄降分辨率。
4. **隐藏 bug**：ReMapping 把 remapping 初始化为 `[]` 而 process 调 `.items()`（process_stylization.py:19/23），直接用必抛异常；smooth_filter 每次调用重编译 kernel 且硬编码 include 路径（smooth_filter.py:335-336）。
5. **demo 外链已老**：三个 sh 的图床大概率 404，建议自备图直接调 demo.py。

## 六、总结

"深度特征统计量替换 + 经典图像处理收尾"的教科书流水线：PhotoWCT 管风格颜色，unpooling 解码器管结构不崩，三层 smoothing 管输出像真照片。算法思想至今可迁移，工程外壳属于 2018——读代码学算法值得，直接部署需重写 IO 与 CUDA 层。
