# Reporting issues with the NVidia's GDB Toolbox

You are encouraged to report bugs, send feature requests, or report
documentation issues. To do so:
- File an [issue](https://github.com/NVIDIA/gdbscripts/issues/new/choose)
describing what you encountered or what you want to see changed.
- The Tegra Debug team will evaluate the issues and triage them, scheduling
them for a release. If you believe the issue needs priority attention
comment on the issue to notify the team.

## Contributing changes

All code and documentation submissions require a completed NVIDIA
Contributor License Agreement (CLA). Before opening a pull request, complete
the applicable agreement and email to swteg-debug-help@nvidia.com:
- [NVIDIA Individual Contributor License Agreement (ICLA)](CLA/ICLA.pdf), if you
are contributing on your own behalf.
- [NVIDIA Corporate Contributor License Agreement (CCLA)](CLA/CCLA.pdf), if you
are contributing on behalf of your employer or your employer has intellectual
property rights in your submission.
