# 02 · 生成与判别主体：Vid2VidModelG / Vid2VidModelD 的编排层

## 角色定位

如果说 explain/01 的 CompositeGenerator 是"网络本体"，本篇三文件就是"编排层"：`Vid2VidModelG`（models/vid2vid_model_G.py:15）把 n_scales 个金字塔生成器逐帧串起来管理时序状态，`Vid2VidModelD`（models/vid2vid_model_D.py:13）组装四类判别器与九项损失，`models/models.py` 的 `create_model`（models/models.py:61）在函数体内延迟 import 前两者（models/models.py:64）并按需构造冻结的 FlowNet（models/models.py:74），三模型各配独立优化器。

## 内部结构

G 侧维护 `netG0` 加 `n_scales-1` 个 Local 变体（ngf 逐级减半，models/vid2vid_model_G.py:38-43）；`n_frames_bp = 1`（models/vid2vid_model_G.py:58）声明截断 BPTT。D 侧四类判别器：单帧多尺度 `netD`（models/vid2vid_model_D.py:35）、face 域局部 `netD_f`（models/vid2vid_model_D.py:39）、`n_scales_temporal` 个时序 `netD_T{s}`（models/vid2vid_model_D.py:44-46），时序 D 输入通道 = `output_nc*n_frames_D + 2*(n_frames_D-1)`（models/vid2vid_model_D.py:43）。

## 外部连接

G 的首帧策略接 pix2pixHD 生态：`generate_first_frame`（models/vid2vid_model_G.py:231）四分支——`no_first_img` 自造零帧、训练态直接吃真实首帧（models/vid2vid_model_G.py:236）、`use_single_G` 经 `load_single_G`（models/vid2vid_model_G.py:261）加载单帧模型：'City' 数据按 loadSize 512/1024/2048 选 `label2city_single` 三档权重（models/vid2vid_model_G.py:264-274），face 域加载 `edge2face_single` 并附带实例编码器 netE（models/vid2vid_model_G.py:282-283）。face 域再经 `get_face_features`（models/vid2vid_model_G.py:290）从 features.npy 特征库做最近邻替换（models/vid2vid_model_G.py:310）注入实例风格。

## 数据流

训练帧循环 `generate_frame_train`（models/vid2vid_model_G.py:139）外层逐帧、内层 coarse-to-fine（models/vid2vid_model_G.py:156）；`t % n_frames_bp == 0` 时才 detach 历史（models/vid2vid_model_G.py:167-168），即只在帧边界截断反传。D 侧 `compute_loss_D_T`（models/vid2vid_model_D.py:181）把 tD 帧与 2×(tD-1) 通道参考光流 cat 进同一判别输入（models/vid2vid_model_D.py:187-188）——判别器同时核对图像序列与其光流。跳帧采样 `get_skipped_frames`（models/vid2vid_model_D.py:275）第 s 时间尺度间隔 `tDs = tD**s`（models/vid2vid_model_D.py:279），默认 tD=3（options/train_options.py:34）即 1/3 帧两尺度。Flow/Warp 损失用 MaskedL1Loss 按置信掩码加权（models/vid2vid_model_D.py:63-64；类在 models/networks.py:804）。

## 设计决策

其一，epoch 级课程学习集中在 `update_models`（models/models.py:151）：niter 后线性衰减学习率，`niter_step` 到点训练序列长度倍增（models/models.py:157-159），`niter_fix_global` 期满解冻粗尺度（models/models.py:163-164）——空间与时间两个粗到细同轴推进。其二，`n_gpus_gen < len(gpu_ids)` 时 G 与 D/FlowNet 分别 DataParallel 到不同 GPU 子集（models/models.py:16-23），batchSize=1 下生成器按帧切卡（models/vid2vid_model_G.py:151 的 gpu_id 计算）。其三，光流置信度既给损失加权又当判别输入，一份计算两处消费。

## 新人提示

读码顺序建议 models.py 装配 → model_G 的 139-196 帧循环与多卡切分 → model_D 的 93-166 forward 大分发。两个易混点：`n_frames_G=3` 是生成器回看窗口（options/base_options.py:58），`n_frames_D=3` 才是时序判别器帧数（options/train_options.py:34）；`n_scales_temporal` 代码默认 2 而 README 写 3（options/train_options.py:35，勘误详见组 README）。改序列长度实验先理清 `n_frames_load/n_frames_per_gpu/max_frames_per_gpu` 三者关系再动手。
