## 1. 这是什么项目：库+示例双层心智

OTK 是 NVIDIA 给 OptiX 渲染器开发者的工具箱。README 列六大 utilities：**DemandLoading**（按需加载稀疏纹理/几何/材质，`DemandLoading/`）、**Memory**（host/device 内存池，`Memory/`）、**NeuralTextures**（NTC 神经纹理加载，`NeuralTextures/`）、**OmmBaking**（不透明度微波图烘焙，`OmmBaking/`）、**ShaderUtil**（设备侧着色算法头文件库，`ShaderUtil/`）、**PyOptiX**（Python 绑定，外部子模块 `https://github.com/NVIDIA/otk-pyoptix`，见 `.gitmodules`——vcpkg 同为子模块；v1.0.0 起其余子模块已并入主仓）。示例层在 `examples/`：Gui/OTKAppBase/Util/Testing 公共框架 + 十二个轻量示例 + 旗舰 DemandPbrtScene。

理解本仓的一条主线是"按需加载"：device 侧 kernel 调 mapOrRequest 触发缺页 → host 侧感知请求 → 从 ImageSource 读 tile → 映射进稀疏纹理。其余库都是这条主线的外围（内存底座、算法兵器、烘焙加速）。新人先读 `DemandLoading/DemandLoading/README.md` 机制全景，再读 `README.md`（要求 CMake 3.27+/git LFS，`git submodule update --init --recursive` 初始化 vcpkg 与 PyOptiX）。

## 2. 构建与依赖治理：CMake/vcpkg 双轨

顶层 `CMakeLists.txt` + `CMakePresets.json` 驱动多库聚合构建。`CMake/` 模块库是依赖治理核心：`CMake/OptiXToolkitConfig.cmake.in` 是 find_package(OptiXToolkit) 安装模板；`CMake/FindOptiX.cmake` 定位本机 OptiX SDK、`CMake/FetchOptiX.cmake`（50 行）负责拉取；`CMake/FetchMdl.cmake`/`CMake/FetchOpenEXR.cmake`/`CMake/FetchRapidJSON.cmake`/`CMake/FetchGtest.cmake` 拉其余依赖；`CMake/embed_cuda.cmake` 做资源嵌入。vcpkg 轨：`vcpkg.json` + `vcpkg-configuration.json` + vcpkg-overlays（imath/openexr 的 fix-cuda.patch——CUDA 编译兼容补丁）。任何库的 CMakeLists 都能顺藤摸瓜回到这两个模板。
