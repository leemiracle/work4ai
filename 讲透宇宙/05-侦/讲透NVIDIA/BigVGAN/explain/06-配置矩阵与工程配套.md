# 06 · configs 九配置三族 + 工程配套（env/utils/tests）

## 角色定位

configs/ 九个 JSON 是仓内唯一"真超参源"：模型形状、判别器组合、损失权重全在这里，代码只读不写。工程配套四件套——env.py（配置容器）、utils.py（通用工具）、tests/（CUDA 一致性）、incl_licenses+nv-modelcard++（合规）——撑起训练/推理的可运行性与可发布性。

## 内部结构

**三族配置**：
- v1 论文版 ×2（`bigvgan_22khz_80band`/`24khz_100band`）：1536ch、upsample [4,4,2,2,2,2]=256x、snakebeta+logscale、MPD(`mpd_reshapes [2,3,5,7,11]`)+MRD(`resolutions` 三组)、batch 32/segment 8192、无 mel 多尺度键（代码默认 λ=45，train.py:526-528）。
- v1 base ×2：512ch、[8,8,2,2]=256x——14M 参数轻量档（demo/app.py:406/408 的 Parameters 列）。
- v2 ×5：1536ch、MPD+CQTD（`use_cqtd_instead_of_mrd:true`）+`use_multiscale_melloss:true`+`lambda_melloss:15`、batch 4/segment 65536、`clip_grad_norm:500`、`use_tanh_at_final:false`+`use_bias_at_final:false`（v1 无此二键，代码默认 True，bigvgan.py:348/359）。五件互相差异只在 sr(22050/24000/44100)、num_mels(80/100/128)、fmax(None/8000)、hop(256/512——`v2_44khz_128band_512x` 唯一 512x，upsample 首级 8)。

**env.py（18 行）**：`AttrDict`（dict 子类，`self.__dict__=self` 一行实现属性访问，env.py:8-11）+`build_env`（把 config 备份进 exp 目录，env.py:14-18）。**注意**：全仓无 wandb——requirements.txt 无此依赖，实验追踪只走 TensorBoard（train.py:272）。

**utils.py（99 行）**：谱图绘制两函数（matplotlib Agg 后端，utils.py:10）、`init_weights`（Conv 类 N(0,0.01)，utils.py:45-48）、`get_padding`（utils.py:57-58，全仓卷积 pad 公式）、checkpoint 三件套（load/save/scan，utils.py:61-92；scan 带 `renamed_file` 回退支持 HF 改名权重续训，utils.py:85-90）、`save_audio` int16 落盘（utils.py:95-99）。

**tests/ 三件**：test_activation.py / test_activation_snake_beta.py 结构相同，fused vs 纯 torch 同输入断言逐元素差 ≤1e-3（test_activation.py:37-44）——两者只差激活类一行；test_cuda_vs_torch_model.py 是正确性+速度基准（合成扫频信号 generate_soundwave 220→1760Hz，:27-37；加载真 checkpoint 对比两路径并测 kHz/RTF/VRAM，README.md:229-252 的表即出自它）。

## 外部连接

九配置被 train.py:746-750 读入 AttrDict、被 `BigVGAN(h)` 逐键消费（num_mels/upsample_*/resblock_*/activation 等）、被 e2e 推理的 mel 对齐约束引用；utils 被 train/inference/demo 三侧共依赖（fanOut=19 全仓最高之一）；`MAX_WAV_VALUE=32767.0`（meldataset.py:20，防 int16 溢出爆音）贯穿数据/推理/演示。

## 数据流

config.json → `AttrDict` → 三处消费：BigVGAN 构造（形状）、train.py 判别器/损失分派（`h.get` 带默认值的软键）、MelDataset mel 参数。训练时 `build_env` 把 config 快照进 checkpoint 目录，保证任何 g_*/do_* 与 config.json 同目录可追溯（inference.py:69 依赖此约定）。

## 设计决策

① 软键 `h.get(...)` 大量出现（use_cuda_kernel/use_mbd/use_cqtd/clip_grad_norm/lambda_melloss）——新旧配置同一份代码通吃，代价是"哪些键有效"要读代码才知道；② v2 发布 config batch=4 而非真训练 batch=32，为单卡可复现（README.md:212-214 自己说明）；③ 测试只测 CUDA 路径数值一致性——核心算子正确性外包给"与 torch 版对齐"这一根锚。

## 新人提示

自训新配置从 v2 24khz 模板改起；三个雷：小 batch 从头训先降 clip_grad_norm（README.md:216）、fmax8k 变体与全带模型 mel 不可混喂、base 与全尺寸判别器超参完全相同但生成器差 8 倍。查"某键有没有用"直接 grep train.py/bigvgan.py 的 `h.get(`。
