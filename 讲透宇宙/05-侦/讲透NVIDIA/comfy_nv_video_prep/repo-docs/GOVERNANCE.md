# Governance

## Project Governance

ComfyUI_VideoPrep is developed and maintained by the **NVIDIA AWD team**.

This project is **not accepting external contributions** at this time.

## Decision Making

All design decisions, feature additions, and release schedules are made
internally by the NVIDIA AWD team.

See [MAINTAINERS.md](MAINTAINERS.md) for the list of current maintainers.

## Changes to Governance

Changes to this governance model are made at the discretion of the NVIDIA AWD team.
