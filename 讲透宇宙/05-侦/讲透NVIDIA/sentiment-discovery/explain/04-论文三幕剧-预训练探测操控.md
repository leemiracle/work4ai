# 精讲四：论文三幕剧——预训练、探测、操控

## 角色定位

pretrain.py / transfer.py / generate.py 三个顶层入口按时间轴串成情感神经元的完整故事：第一幕在 Amazon 评论上无监督训练 LM，第二幕用 L1 逻辑回归扫描 4096 个 cell state 维度找出编码情感的神经元，第三幕生成时强行改写该神经元操控文本情感。transfer.py 的探测代码血统直接：logreg_utils.py:9 注明 "Modified version of openai implementation"——源自 OpenAI 官方仓 utils.py，本仓加多类/多指标/阈值/丢神经元消融（:10）。

## 内部结构

第一幕 setup_model_and_optim（pretrain.py:27）装配一切：mLSTM 或 Transformer 二选一（:29-34）、权重加载失败自动挂/卸 weight_norm（:51-59）、fp16 包装（:69-74）；get_batch 把同一批错位一刀切成输入与目标（data[:,:-1]/[:,1:]，:134-135）；reset_mask 逐时间步维持样本边界（:136）。第二幕 transform（transfer.py:83）批量抽特征，get_outs 对 RNN 先 reset 再做 1+num_hidden_warmup 遍预热前向（:114-116）；train_logreg（logreg_utils.py:20）默认 L1 惩罚扫 C=2^-8..2^0 九档（:21），一轮全特征回归（transfer.py:277）后 get_top_k_neuron_weights（:158）按 logreg 权重的 L1 范数排序取 top-k（:169-179，k 大小三分支选 argmax/argsort/argpartition），再用仅 k 个特征二次回归（:316）并可选丢神经元消融（--drop-neurons，logreg_utils.py:28-32）。第三幕 get_neuron_and_polarity（generate.py:98）从 checkpoint 的 classifier 权重取行最大绝对值定位神经元与极性（:111-117）；process_hidden 每步把最后层 cell 该维 fill 成 mask_value×polarity（:120-126）。

## 外部连接

三幕共用检查点协议：'lm_encoder'+'classifier' 双键（transfer.py:68-69 存、generate.py:102-105 读）；transfer.py 额外把 logreg 权重存成 torch 模型 classifier.pt（fp32）与 classifier.pt.16（fp16）双份（:295-308）。评估侧 threshold.py 供双阈值三态判定：binary 每类 linspace 200 档扫（:28）加 global_tweaks 随机微调（:50-70）；neutral 双输出 30² 网格（_neutral_threshold_two_output :164）。

## 数据流

操控态单步：input 字符 id → RNNModel 前向 → model.rnn.rnns[-1].hidden 取最后层 (h,c)（generate.py:131-135）→ 若 mask 则改写 c 的神经元维 → 记录该维原值作热力图数据（vals）→ 采样下一字符（temperature=0 走 argmax，否则 multinomial，:140-146）。预热文本经 process_text 逐字符喂入（:148-162）；bootstrap 用 '\n' 与空格两步起步（:213-223）；--visualize 时 make_heatmap 以 74 字符折行、RdYlGn 双色逐字符着色（:180-204）。

## 设计决策

其一，探测用 L1 而非 L2：稀疏解让"少数神经元携带情感"可读出——论文叙事（单神经元 91.7% SST）正依赖这个选择；top-k 按 |权重| L1 排序即其自然延伸。其二，特征口径锁 cell state（transfer.py:86 docstring 与 arguments.py:182-183 的 --get-hidden 开关互证）。其三，操控直接改写 cell 而非 logit——证明因果性的最短路径。其四，threshold.py 的 neutral_threshold_two_output 在 :128 与 :154 重复定义，后者静默覆盖（main 的 task_dict :193 拿 :154 向量版），且 logreg_utils.py:18 干脆 import 私有 `_neutral_threshold_two_output` 绕开公共入口。
