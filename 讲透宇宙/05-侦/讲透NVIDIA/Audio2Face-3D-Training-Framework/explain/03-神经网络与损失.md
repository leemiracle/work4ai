# 03 神经网络与损失：双架构与部位感知损失库

## 角色定位

`networks/` 与 `losses.py`、`layers.py` 构成本仓的模型层。双架构并列：**回归线** `conv_w2v_autocorr.py`（JAS 架构，逐音素回归面部动画，L35 `class Network(NetworkBaseRegression)`）与**扩散线** `diffusion_rnn.py`（607 行主力，L201 `class Network(NetworkBaseDiffusion)`）。两线共享 `layers.py` 的工具箱层与 `losses.py` 的部位感知损失库，但骨架哲学不同：回归线是"特征提取+逐帧回归"的一次前向；扩散线是"条件编码+RNN 主干+迭代去噪头"的多步采样。

## 内部结构

**扩散线**（diffusion_rnn.py）四大件：`CustomHubertModel`（L40）覆写 `_mask_hidden_states`（L41）控制 HuBERT 音频特征提取的掩码行为；`interp_input`（L91）做输入插值对齐；`EmbedGeometry`（L123）是几何条件编码器——把拼接的动画系数按 skin/tongue/jaw/eye 四段切开（L178-181），各自走专属嵌入（皮肤走 Linear+Conv1d k9，L141-146；舌/颌/眼走纯 MLP，L148-166），再拼接压缩回统一维度（L168-177）；`Network` 主干（L201）持有 GRU 隐状态与扩散头，`set_mode`（L363）在 5 种 forward 间切换——streaming（L455，隐状态留在 self.h）、streaming_stateless（L520，隐状态经 forward 传入传出）、offline（L402）、offline_onnx（L429，直接挂 onnxruntime session）等，stateless 模式还预计算 `space_timesteps` 的时间步索引供 GRU 选历史（L372-379）。

**回归线**（conv_w2v_autocorr.py）三路音频特征：wav2vec2 加权多层特征（L70-82，`w2v_feature_coeffs` 可学权重冻结骨干）、音频自相关特征（L83-92，5 层 freq 卷积栈，缩放因子 8.912 是注释自认的 legacy 数据集 std 魔数）、可选音素强制（L94-98，按语言建逐音素回归头）。时间卷积栈 time1-time5（L100-105）下采样后分头输出皮肤/颌/眼与舌头（L107-112）。`JAS` 辅助函数（L27）把时序维折进 batch 走逐帧算子再展开。

**损失库**（losses.py，231 行 12 个函数）：`motion_loss`（L25）预测-真值一阶差分（速度）MSE；`lip_dist_loss`（L38）在唇上下顶点对的 y 轴距离上加指数衰减权重（闭唇权重高，L48-49）；`lip_size_loss`（L58）约束唇形；`vol_stab_reg_loss`（L91）音量稳定性正则；`phoneme_loss`/`phoneme_motion_loss`（L117/L139）音素级监督；`expression_smooth_reg`（L191）配 `cal_mask_params`+`generate_vertex_weights_vectorized`（L153/L171）生成的上半脸软掩码做平滑；`r2`（L202）拟合优度指标；`LossNormalizer`（L209）滑动归一化。`layers.py` 工具箱：NormRelu（L23）、ConcatEmotion（L28）、EyeOpenMask 眼睑掩码（L46）、AutoCorr（L56）、GDropout（L108）、ImplicitEmotionDB 可查表情感库（L145）、CoeffsToPose 系数→顶点重建（L154）。

## 外部连接

两基类在 `networks/base.py`：`NetworkBaseRegression`（L19）与 `NetworkBaseDiffusion`（L34）都持有 EMA 副本并提供 `set_mode`（L28/L49）在训练权重与 EMA 推理权重间切换——**EMA 归网络管而非训练器管**是本仓的职责划分。上游：Trainer 经 `compose_network_params_from_dataset`（train_diffusion.py:68）把预处理产物（PCA 维数、actor 数、情感数）注入 params dict；`compose_network_extra_data`（L122）注入 PCA 基矩阵等张量。下游：diffusion 网络的 forward 签名直接被 `gaussian_diffusion.py:1253` 的 training_losses 与 WrapModel 消费。

## 数据流

扩散线前向：audio → CustomHubertModel 特征 → 与 EmbedGeometry(噪声系数) 的条件 token 拼接 → GRU 主干 → 扩散头输出 x0 预测 → `CoeffsToPose` 可选重建顶点供损失。回归线前向：audio → w2v 加权特征 ‖ autocorr 特征 → JAS 展平 → time 卷积栈 → 双头（皮肤颌眼 / 舌头）。损失侧：train_step 把 model_output 反归一化回顶点空间再调 lip_dist/motion/smooth 三件套（train_diffusion.py:292-332）。

## 设计决策

- **部位分治**：几何嵌入、输出头、损失、PCA、预处理五处都按 skin/tongue/jaw/eye 四段切分——部位是贯穿全仓的第一级正交轴。
- **音素强制是回归线特权**（`use_phoneme_forcing` L44 要求 w2v 特征在位）；扩散线不直接吃音素（音素供给在 dataset 层按需启用）。
- **可导出的 stateless 化**：把 GRU 隐状态从实例状态改为 forward 入出参（L520），是"研究代码→部署资产"的关键一步。
- **魔数不藏**：autocorr 缩放因子 8.912 等遗留常量均带来源注释，方便复核。

## 新人提示

读扩散线从 `Network.forward_streaming_stateless`（L520）进最清晰——输入输出张量形状全显式。调损失行为时注意三 α（LOSS_LIP_DIST_ALPHA/LOSS_VELOCITY_ALPHA/LOSS_EXP_SMOOTH_ALPHA，config_train_diffusion_base.py）任一为 None 即整支关闭对应损失（train_diffusion.py:315-332 的三元组条件）。改网络结构必须同步 `compose_network_info`（train_diffusion.py:84），否则推理端参数对不上。
