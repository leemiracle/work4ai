# 06 预处理三阶段与配置三层体系

## 角色定位

预处理把表演捕捉的原始网格缓存压成训练可用的 PCA 表示，是扩散线训练的前提；配置体系则是全仓"一切可调"的骨架。两条线在 `preproc/preproc.py` 交汇：`run()`（L51）先做配置校验合并（L71-74），再按 **skin → tongue → deploy** 顺序编排三阶段（L79-81）——deploy 是汇聚收口，非独立数据源。运行目录名带时间戳前缀（L58），训练端用 `PREPROC_RUN_NAME_FULL` 回填真名，占位值 `XXXXXX_XXXXXX` 会被显式拒绝（`train_diffusion.py:426-427`）。

## 内部结构

**skin**（`preproc_skin.py`）：四步管线——`pruneSimilarPoses`（L53，KD-tree L2 剪相似帧）→ `selectDistinctPosePca`（L126，迭代选区分性姿态）→ `runPca`（L241，截断 PCA）→ `computePcaCoeffs`（L316，全量回算系数），产出 `skin_pca_shapes.npz`/`skin_pca_coeffs_all.npz`（L360-361）。**tongue**（`preproc_tongue.py`）：`decoupleTransformDeformation`（L29，用下牙列刚体顶点表解耦整体位移与局部形变）+ `computePcaVectors`（L84）；**数据缺失可跳过**——L242-270 检测到舌头缓存/中性帧/刚体表任一缺失时写全零占位 PCA 并返回 `skipped: True`。**deploy**（`preproc_deploy.py`）：`run`（L159）加载前两阶段的 npz（L182-186），`compute_mean_geometry`（L108，颌 15 维=5 点×3、眼 4 维=2 角×2 眼）拼均值几何存 `mean_geometry.npy`（L270-272），并从系数反向生成 shot 清单与 CLIPS 模板（L281-300）。数学核心共用 `geometry/pca.py:21` 的 `pca_truncated`（方差阈值 0.9995，`config_preproc_base.py:51`）与 `geometry/xform.py:19` 的 `rigidXform`。

## 外部连接

**注意两个 deploy 不是一回事**：`preproc/preproc_deploy.py` 是预处理第三阶段；`audio2face/deploy.py`（`run` L110）是训练后的模型部署器，读训练产物的 `preproc_info.json`/`network_info.json`、断言 actor 名与预处理一致（L160-163）、按 actor 生成 SDK 侧 model config。Actor 专属参数一律 `{actor: value}` 字典、缺失回退默认（如 `SKIN_CACHE_SHOTS`，`preproc_skin.py:374-381`）；颌/眼/舌可选数据缺失时 `get_default_data`（`preproc_deploy.py:27`）补零，默认形状在 `config_preproc_base.py:70-79`。

## 数据流

主机侧 `run_preproc.py` 用**根 utils.py** 的 `load_config`（L54，按 `configs/<name>/config_<type>.py` 四类惯例，`importlib` 动态加载转 dict）序列化 JSON 转发容器（L35-40）；容器内 `preproc.py` 用 **audio2face/utils.py** 的 `validate_cfg_mod`（L331，未知键 ValueError）与 `module_to_easy_dict`（L83，基线+修饰器深合并，`dict_deep_update` L61）得到生效配置。三阶段产物落 `PREPROC_OUTPUT_ROOT/<时间戳_名>/pca/{skin,tongue}` 与 `deploy/`（`config_preproc_base.py:86`），训练从 deploy 产物组装数据集。

## 设计决策

- **配置即 Python 模块**：三层=基线层 `config_base/` 六模块全默认值 → 修饰器层 `configs/<name>/` 按键覆盖 → 白名单层 `exposed.py:18` 的 `EXPOSED_CONFIG_PARAMS`（partial exposure 模式下只许覆盖路径/actor 等发布安全键，且训练**不保存 weights.pth**，`train_diffusion.py:531-532`；开源版 `is_partial_exposure` 硬编码 False，`audio2face/utils.py:347-348`）。
- **双 utils 甄别**：根 `utils.py`（78 行，主机侧校验+加载+转发，`validate_identifier` L26 连 ".." 都拦）与 `audio2face/utils.py`（401 行，容器内 EasyDict/合并/校验）同名不同物；判别看 import：根包装器 `from utils import`（`run_preproc.py:20`），容器内 `from audio2face import utils`。
- 舌头跳过+零占位使无舌数据也能全链路跑通，代价是舌头通道学到噪声基底。

## 新人提示

跑 example-diffusion-min 只需填 `AUDIO_ROOT`/`SKIN_CACHE_ROOT`（`config_dataset.py:24/29`）；改超参先查基线层键名（校验器拦未知键）再放修饰器；重跑 preproc 必记新目录名回填训练配置；调试可利用 `preproc_deploy.py:168-173` 的 `run_name_full=None` 回退直指无时间戳路径。
