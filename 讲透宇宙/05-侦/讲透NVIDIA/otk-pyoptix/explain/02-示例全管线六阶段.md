# 02 · 示例全管线六阶段：ctx → module → PG → pipeline → SBT → launch

## 角色定位

`examples/` 六个示例（hello/triangle/sphere/curves/simpleMotionBlur/denoiser，另加 8 行的 path_util.py）是绑定 API 的可执行文档。它们共享同一条六阶段骨架，只换几何与着色——看懂 hello 一篇即可迁移到全部。

## 内部结构

**hello.py**（393 行）是骨架标本：`compile_cuda` NVRTC 在线编译 hello.cu（hello.py:97）→ `create_ctx` 里 `optix.deviceContextCreate(cu_ctx, ctx_options)`（hello.py:153）→ `create_module`（hello.py:168，moduleCreateFromPTX）→ `create_program_groups`（hello.py:210，raygen/miss 两组）→ `ctx.pipelineCreate`（hello.py:249）→ `create_sbt`（hello.py:280）→ `optix.launch(pipeline, ...)`（hello.py:347）；main（hello.py:371）串全流程并计时。**几何四兄弟**换求交不换骨架：triangle.py:160 与 sphere.py:177 各自 `create_accel`（球体走 AABB+内置 SPHERE 相交类型）；curves.py:207 `BuildInputCurveArray`（curves.py:219 accelComputeMemoryUsage、:224 accelBuild，SBT 在 curves.py:367）；simpleMotionBlur.py:213 `build_triangle_gas` 配 `MotionOptions`（numKeys/timeBegin/timeEnd，simpleMotionBlur.py:217-221），:304 `build_sphere_gas` 走 custom primitive + 相交程序，:366 `create_sphere_xform` 用 MatrixMotionTransform 双关键帧插值（:368-379）——唯一演示 IAS/GAS 层级加速结构的示例。**denoiser.py**（334 行）是另一条管线：EXR AOV 进（denoiser.py:8-13 OpenEXR/Imath/cupy imports；:91 load_exr；:66 `create_optix_image_2D` 包装 OptixImage2D）→ `denoiserCreate(DENOISER_MODEL_KIND_HDR)`（denoiser.py:248）→ `computeMemoryResources`（:250）→ `denoiser.setup`（denoiser.py:265）→ computeIntensity（:287）→ `invokeTiled`（denoiser.py:295）→ EXR 出。

## 外部连接

所有示例 `import path_util` 拿 NVRTC include 路径——path_util.py:4 的 `optix_include_path` 硬编码开发者家目录 `/home/kmorley/Code/support/optix/9.1.0/include/`，克隆后必改。denoiser 依赖 examples/data/ 六张 EXR（beauty/albedo + diffuse/glossy/specular/normal），是 OptiX Denoiser 标准 AOV 输入布局的固定测试载荷。

## 数据流

CPU 侧（Python）：EXR/顶点数据 → cupy/numpy buffer → 绑定对象。GPU 侧：.cu 着色器经 NVRTC 编译为 PTX → module → program group → pipeline；几何经 BuildInput 族 → accelComputeMemoryUsage → accelBuild 产出 GAS/IAS；SBT 打包 raygen/miss/hitgroup 记录后 launch 逐像素发射。

## 设计决策

- **一骨架多几何**：六示例的函数命名统一（create_ctx/create_module/create_accel/create_sbt/launch），diff 两篇即见几何类型差异，是理解 OptiX 抽象层次的最短路径。
- **NVRTC 在线编译而非预编译 PTX**：示例无构建步骤、跟机头文件走；测试则相反用预生成 PTX（见 03 篇）——两种策略各取所需。
- **cupy 而非自研内存层**：GPU 缓冲全部经 cupy 分配，绑定层只接收 device 指针。

## 新人提示

跑通顺序 hello→triangle→sphere→curves→simpleMotionBlur→denoiser；先改 path_util.py:4 再碰任何编译；denoiser 的 `--hdr` 语义由 DENOISER_MODEL_KIND_HDR 决定（denoiser.py:248），输入 EXR 必须含六通道。
