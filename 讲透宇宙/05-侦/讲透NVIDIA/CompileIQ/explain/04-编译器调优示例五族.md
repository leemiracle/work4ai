# 04 · 编译器调优示例：ptxas/nvcc/triton/nvbench/cutile 五族

## 角色定位
`examples/compilers/` 下五个目录（16 文件）是 CompileIQ 的"实战展示厅"：每族一个最短可跑闭环，覆盖不同工具链的接入姿势。它们的共同骨架是 objective 函数（编译/运行一次计一分）+ provider 搜索空间 + `Search` 组装——差异全在 objective 怎么写。

## 内部结构
五族各有代表锚点：**ptxas**——`ptx_spill.py` 的 `objective`（`ptx_spill.py:24`）用 `--apply-controls` 编译故意溢出的负载 `w8_spill.ptx`（`ptx_spill.py:21`，2772 行高寄存器压力内核），分数=溢出字节数，空间用 `PtxasSearchSpace(version=cuda_version)`（`ptx_spill.py:69`）；**nvcc**——`optimize_reduction.py` 对 `reduction.cu` 逐候选编译计时；**triton**——双变体对照：`triton_ptx.py` 纯加密空间（objective 在 `triton_ptx.py:112`，空间 `triton_ptx.py:147`），`mixed_triton.py` 加密+原语混合（objective 在 `mixed_triton.py:123`，空间为列表 `[user_space, PtxasSearchSpace(...)]`，`mixed_triton.py:158-160`）；**nvbench**——第三方基准框架对接（`optimize_reduction.py` 的 objective 是内嵌函数 `optimize_reduction.py:285`，空间 `optimize_reduction.py:300`）；**cutile**——单脚本 `cutile_autotune.py`（objective `cutile_autotune.py:133`，Search 组装 `cutile_autotune.py:172`）。

## 外部连接
每族配一篇深水区文档：`docs/ptx_spill_example.md`（207 行）、`docs/nvcc_example.md`（94 行）、`docs/triton_example.md`（224 行）、`docs/cutile_example.md`（120 行）、`docs/compilers_overview.md`（114 行总览）。上游依赖第 2 层的 provider（`compilers.py:66` 的 PtxasSearchSpace 是五族中四族的默认空间）与第 1 层的 Search 门面。图谱把 `nvbench_example/CMakeLists.txt` 归 document 节点而非 pipeline——构建由外部 CMake/nvbench 消费，无 CI 执行语义。

## 数据流
以 ptxas 为例：Search 拿加密空间候选（ACF 字符串）→ objective 子进程调 ptxas `--apply-controls` 编译 `w8_spill.ptx` → 解析输出抓 spill 计数 → 分数回流 → NSGA-III 逐代压溢出。nvbench 族多两段胶水：CMake 构建 benchmark 二进制 + 解析其 JSON 输出（`nvbench_utils.py`）取延迟。

## 设计决策
triton 双变体是教学设计：`triton_ptx.py` 展示"编译器域全托管"，`mixed_triton.py` 展示"用户超参与编译器控制项同场搜索"——混合空间的列表写法（原语 dict + provider 混排）是这类需求的模板。ptxas 族故意选一个**已知会大量溢出**的负载（w8），让搜索收益肉眼可见，是"演示效果优先"的取材决策。nvbench 族证明框架无关性：任何能吐 JSON 分数的基准工具都能当 objective。

## 新人提示
入门顺序：ptxas（README 两行命令可跑，`python ptx_spill.py --arch sm_90a`）→ nvcc → triton 双变体对照读 → nvbench（需要 CMake 环境）→ cutile。注意命名陷阱：脚本是 `ptx_spill.py`、负载是 `w8_spill.ptx`，两个"spill"指不同文件；引文档看 `docs/ptx_spill_example.md`，别与 `docs/` 下其他 `*_example.md` 混淆。
