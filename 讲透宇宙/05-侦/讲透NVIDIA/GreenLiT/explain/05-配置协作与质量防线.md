# 05 · 配置协作与质量防线：测试真身之外的工程骨架

> 测试代码回答"内核对不对"；配置层回答"这条测试在什么机器上算什么"；协作基建与质量防线回答"改动怎么被审、框架怎么不烂"。

## ① 角色定位

## ② 内部结构

**YAML 规则以测试 ID 为键。** `confs/glt-confs.d/00_default.yaml:1` 首键 `arm64:test_all_pmu_events` 正是 `src/modules/arm64/glt_test_pmu.py:683` 的同名函数——键即 `<category>:<test_name>`；condition 三型：`distro`+`release`、`kernel-uname`、inline `script`。`glt_conf.py:31` 的 `cond_to_func` 把 condition 编译成谓词闭包，`glt_conf.py:113` 的 `load_glt_yaml_files` 从 `/usr/share/greenlit/confs.d` 装载。

**systemd 集成。** `confs/greenlit.service:9` 即 `ExecStart=/usr/bin/glt-test-suite --resume -1`；`greenlit.service:6-8` 注明不用 `Type=oneshot`：oneshot 把 boot job 挂到套件退出，而套件又在等 boot，死锁。`greenlit.timer:5` 的 `OnActiveSec=10s` 延迟拉起；`install.sh:362-368` 拷单元，`install.sh:337-347` 拷 confs 到 `/usr/share/greenlit/`。

**manifest 黑名单。** `hardware-manifest.json` 给 tpm 挂 `dmi:bvnNVIDIA:bvr*:bd*:` 风格 glob；`nv_device.py:206` 读文件，`nv_device.py:209-215` 把 `*`/`.`/`(`/`)` 翻成 regex。

**CI 是转发器。** `.gitlab-ci.yml` 只有 `variables` 与 `include`：`.gitlab-ci.yml:2` 钉 `GREENLIT_CI_REF: "main"`，`.gitlab-ci.yml:5-7` include `dgx/mgx/greenlit-ci@main`；本仓零 job 定义。

**AI 评审四镜头。** `.ai-review-bot.yaml:16` 起：`.ai-review-bot.yaml:18-25` 定义双内核参照——`linux-mainline`（torvalds）与 `linux-nvidia`（NV-Kernels 的 `linux-nvidia-6.18-next` 分支）；lenses 四个：convention（gemini-flash，`.ai-review-bot.yaml:28`）、discriminator（grok，`.ai-review-bot.yaml:137`，`applies_to` 限 `src/modules/**`+`src/bin/**`+`external_tests/**`，`.ai-review-bot.yaml:138`）、common-helper-contracts（`.ai-review-bot.yaml:257`）与 discovery（`.ai-review-bot.yaml:313`）；lens 间以 Out-of-scope 互斥。注释还承载政策溯源：`:30-35`、`:140-145` 保留 `!379#note_69388553` 等 MR 讨论号，不送模型。

**.github 双轨制。** `ISSUE_TEMPLATE/` 9 文件成对：`bug_report.md`+`bug_report_form.yml` 等 md 版与 yml 表单版并存；`config.yml` 把提问导流 Discussions。

**质量防线。** `tests/` 53 个 .py 分四子目录：`common/`（helper 单测 mock I/O）、`greenlit/`（CLI/resume）、`modules/`（解析器）、`data/`；`tests/test_base.py:8` 的 `GLTTestBase` 供继承。`CLAUDE.md` 是 9 字节 symlink 指向 `AGENTS.md`，后者钉边界（不提交 poetry.lock、非 root 只跑 unit+lint、未加 `@GLTTestAttr` 禁调 fail/skip）。`pyproject.toml:12-18` 打包四包 `from="src"` 外加 `src/bin`→`greenlit/_runtime/bin`，`pyproject.toml:44` 注册 `glt-test-suite`，`pyproject.toml:21-36` include 打包 `external_tests/**` 与 C 探针——篇 04 武器随轮分发。

## ③ 外部连接

内部仓 greenlit-ci；Gemini/Grok 端点；torvalds 与 NV-Kernels 两个 git remote 供 discriminator 查源；`/var/cache/greenlit` 会话层——`glt_utils.py:725` 建时间戳目录，`glt_utils.py:730-740` 只认含 `test_progress.json` 的会话。

## ④ 数据流

YAML 规则生命周期：改 `confs/glt-confs.d/` → install 拷贝 → 装载编译闭包 → scheduler 求值，命中即改判 → 结果落 `/var/cache/greenlit/<时间戳>/` → 中途重启则开机 `--resume -1` 拾回。

MR 旅程：push → 转发器交给 greenlit-ci → 四镜头跑 diff（discriminator 可查双内核历史）→ 规则修订也是 MR，note 号写回 YAML 注释——政策与配置同文件闭环。

## ⑤ 设计决策

**转发器 CI** 把流水线从公开仓剥离，代价是排障须去 greenlit-ci。

**四镜头 applies_to 划界**防评审打架：discriminator 只看测试真身、discovery 只看 CLI 层、convention 明文排除前两者——全知单模型只会重复报告。

**政策溯源进注释而非提示词**：note 号不送模型——LLM 不需要 MR 链接，维护者需要。

**Type=simple 规避死锁**：resume 与 boot 完成互等，oneshot 焊死两者；注释把因果写死防改回。

**agent 指令双入口**：`CLAUDE.md -> AGENTS.md` 让各类 agent 读同一份边界，其"未装饰禁调 fail/skip"与 convention lens 互为镜像。

**打包边界即架构**：四包 `from="src"` 对应源码双导入根；include 清单让"非 Python 资产须显式声明"成为构建期检查——漏写一行探针就静默不随包分发。

## ⑥ 新人提示

- YAML 键须精确匹配 `<category>:<test_name>`，拼错只静默不生效；先读 `docs/user-guides/configuration.md`。
- 别删 `.ai-review-bot.yaml` 的 `!NNN#note` 注释（政策出处）；改提示词保持"注释不送模型"约定。
- CI 排障去 greenlit-ci；本仓 `.gitlab-ci.yml` 只在换 CI 版本时动。
- 非 root 只跑 `tests/` 单测与 lint；glt-test-suite 与 external_tests 需 root+真机。
- 别提交 `poetry.lock`；新 category 须同步 architecture.md。
