# Allenai S6ui

## How do I install these formulae?

`brew install allenai/s6ui/<formula>`

Or `brew tap allenai/s6ui` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "allenai/s6ui"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
