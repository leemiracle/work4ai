## 核心数字速览（来自 03 幕真跑）

| N 卡 | 环法每 rank 发送 | 朴素法 rank0 发送 | 环法负载不均衡 |
|---|---|---|---|
| 2 | 1.00×S | 2.0 MB | 1.0 倍 |
| 8 | 1.75×S | 8.0 MB | 1.0 倍 |
| 16 | 1.88×S | 12.8 MB | 1.0 倍 |

S=每卡消息大小。环法通信量随卡数只逼近 2S 封顶，朴素法线性爆炸。
