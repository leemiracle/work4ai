  This page provides a comprehensive overview of the key components and interfaces within the OpenHarmony Distributed Relational Database Management System (RDBMS). It explains how these components interact with each other and the various interfaces provided for application development.

 
## Overview

 The OpenHarmony Distributed RDBMS provides a comprehensive solution for relational database management with features for distributed operation, encryption, high availability, and multiple access interfaces. This component offers both native C++ interfaces and JavaScript interfaces through NAPI bridging, allowing developers to perform SQL database operations across different programming environments.

## Core Components

 The Distributed RDBMS is built around several key components that work together to provide database functionality:

 
### RdbStore and RdbStoreImpl

 The `RdbStore` interface defines the contract for database operations, while `RdbStoreImpl` provides the concrete implementation. This is the primary component that handles all database operations like querying, inserting, updating, and deleting data.

## Conclusion

 The OpenHarmony Distributed RDBMS provides a comprehensive, layered architecture for database operations with strong support for distributed scenarios. Key components include:

 
 - **Core Components**: RdbStore/RdbStoreImpl, ConnectionPool, and various result set implementations
 - **API Layers**: Native C++ API, JavaScript API (NAPI), and NDK interfaces
 - **Connection Management**: ConnectionPool with SqliteConnection and RdConnection types
 - **Distributed Features**: Data synchronization, remote queries, and notification mechanisms
 - **Transaction Management**: Support for atomic operations with different isolation levels
 
 These components work together to provide a robust database management system that supports both local and distributed operations, with multiple programming interfaces for application development.
