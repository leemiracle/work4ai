## 角色定位

memory/ 包里五个小适配器组成"后端族"。编码轴三实现：openai_encoder 真（远程 OpenAI/Azure embedding API）、mock_encoder 假（确定性哈希词袋）、本地 sentence-transformers 宿主在 VectorEncoder 包装类里（memory/vector_db.py:534），设备策略归 local_device；决策轴 laya_backend（Jev/TypeSafe 远程决策的本地 LLM 替身）；持久化轴 cache_compat（前身 sys1mem 命名迁移）。组织逻辑：核心对这些后端全走接缝注入，三档互换覆盖实验、离线、无 key 环境；且都不进 memory barrel 的 _MODULES（memory/__init__.py:19-28）——适配器按模块路径直连，"公共 API vs 内部接缝"刻意分层。

## 内部结构

### openai_encoder——真后端，防御范本

构造读模型名/维度（强制正数）/OPENAI_BASE_URL 三个环境口，client 可注入喂假件（memory/openai_encoder.py:9-14）。encode 把单字符串包列表后全走 encode_batch（memory/openai_encoder.py:16-17）。encode_batch 是防御堡垒（memory/openai_encoder.py:19-38）：batch_size 与空输入校验、带 timeout 派生"单请求超时=预算四分之一且零重试"的受限 client（memory/openai_encoder.py:26-27）、index 连续性与形状双校验。

### mock_encoder——假后端，鸭子接口最小面

docstring 立契约："Deterministic lexical embeddings for offline tests/demos, never experiments"（memory/mock_encoder.py:1）。dimension 类属性 128；encode 对 lower 后文本按 \w+ 切 token，每 token 的 sha256 前 4 字节对维度取模落桶、命中加一（memory/mock_encoder.py:15-17）——哈希词袋，确定性可复现。无 __init__/encode_batch/timeout：鸭子接口最小面。

### local_device——设备策略，单一函数

local_model_device(requested)（memory/local_device.py:6）：显式且非 "auto" 直接放行——调用方已验证过 runtime；None/"auto" 在 darwin 返回 "cpu"、其余平台返回 None（memory/local_device.py:14）。理由：macOS Metal 原生断言直接 abort 进程、无法触发异常回退（memory/local_device.py:7-10）。

### cache_compat——历史命名迁移，三函数

memory_config_path 双文件名择新：jev_mem_config.json 优先，退回 sys1mem_config.json（memory/cache_compat.py:8-12）。validate_cached_backend 加载旧图前拒绝异构构造：decision_backend 缺省按历史值 "jev" 解释，laya 系再比对 laya_model/laya_subfolder/jev_mock 三键（memory/cache_compat.py:22-30）。normalize_metadata 迁移节点元数据：旧 sys1mem 键与现 jev_mem 键合并且现字段优先、历史字符串改写（memory/cache_compat.py:38-43）。

### laya_backend——本地决策后端，deadline 语义

构造：按 decision_backend=="laya-mlx" 选 laya_mlx 或 laya，ModuleNotFoundError 转译成带安装指令的 ImportError——指令精确到 extras 名 `'.[mlx]'`（Apple Silicon）或 `'.[laya]'`（memory/laya_backend.py:13-18）；MLX 原生 runtime 不吃 PyTorch 的 macOS CPU 规避、torch 版走 local_model_device（memory/laya_backend.py:22-29）。predict（memory/laya_backend.py:33-60）：锁带超时获取、超时即 TimeoutError("laya_deadline")、agent 已关则 RuntimeError（memory/laya_backend.py:35-39）；batch 循环前后各查一次 deadline——后查把"算完但已过期"判死：本地推理无法安全中断，只能拒绝迟到结果（memory/laya_backend.py:44-50）；close 持锁置 agent=None（memory/laya_backend.py:62-64）。

## 外部连接

grep 实测。openai_encoder：唯一生产消费点是 VectorEncoder 的 use_openai 分支，构造失败被同处 catch 降级 SBERT（memory/vector_db.py:549-556）。mock_encoder：消费方清一色离线——demo 主编码器（jev_mem/demo.py:19）与单测，零生产引用。local_device：五处消费横跨三包——memory/vector_db.py:567、utils/utils.py:87 等，是本地推理设备的事实标准。cache_compat：graph_db 四个反序列化点全走 normalize_metadata（memory/graph_db.py:92）；memory_builder.load 先 validate 再读图（memory/memory_builder.py:1333-1334）；locomo 基准用 memory_config_path。laya_backend：唯一直接消费方 JevClient，laya 系且非 mock 才实例化（memory/jev_client.py:94-96）；retrieval_slot 为 laya 返回检索锁、排队到 deadline 起算前（memory/jev_client.py:108-117）。

## 数据流

写路径：memory_builder 按 embedding_model 选实现（memory/memory_builder.py:532-535），trg_memory 同款三分支另留 encoder= 注入口（memory/trg_memory.py:98-107）。检索带预算：jev_mem_retrieval hasattr 探测 encode_with_timeout（memory/jev_mem_retrieval.py:62）——OpenAI 实现换算成单请求超时，MockEncoder 无此方法自动落回无超时分支。决策路径：JevClient 调 predict → 拿锁 → batch 双 deadline 检查。持久化：load 先 validate 拒异构缓存，sys1mem 缓存无损升级不回写。

## 设计决策

组织决策：五文件是 memory 包里仅有的纯适配器，各自隔离一类外部依赖；可替换性两条机制——编码轴走 VectorEncoder 降级链（memory/vector_db.py:549-556），决策轴走 config 驱动选择；laya 的 ImportError 守卫与 openai_encoder 的可注入构造同构：把"外部世界不可用"翻译成带行动指引的错误或降级。

deadline 双检是本地推理时间语义的关键决策：远程超时可取消，本地 forward 无法安全中断——把"取消"改写成"拒绝迟到结果"（memory/laya_backend.py:44-50），测试名直说 does_not_cache_late_results（tests/test_laya_backend.py:86）；timeout 四分之一的换算同源（memory/openai_encoder.py:26-27）：留均分余量、杜绝 SDK 预算外重试。

批判点：其一，**MockEncoder 语义幻觉风险**——哈希词袋无语义，相似度约等于词重合度，混进实验产出无意义的指标，防线只有 docstring 一句（memory/mock_encoder.py:1）无机械闸；其二，降级链 catch Exception 过宽（memory/vector_db.py:553），key 配错与网络故障一律静默降级 SBERT，维度换档后已存向量库静默失配；其三，批语义两处真相——自行按 batch_size 切片（memory/openai_encoder.py:28）与包装层 min 夹紧（memory/vector_db.py:585）；其四，validate_cached_backend 与 validate_reuse_memory 两套字段口径（后者更长，jev_mem/benchmarks/locomo.py:54-58），同一缓存过两道相似但不同的闸，有测试兜底无统一实现；其五，predict 全程持锁串行（memory/laya_backend.py:35-60），吞吐上限=单模型串行，laya 多 worker 并行只是排队不是并行。
