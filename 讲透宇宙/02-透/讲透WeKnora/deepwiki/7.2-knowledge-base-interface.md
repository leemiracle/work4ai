  This document describes the frontend interface for managing knowledge bases in WeKnora. It covers the knowledge base editor, document list and card views, tag sidebar, upload UI, and settings panels.

 
## Purpose and Scope

 The Knowledge Base Interface enables users to:

 
 - View and browse documents and FAQ entries within knowledge bases.
 - Upload files, import URLs, and create manual documents via a markdown editor.
 - Configure RAG (Retrieval-Augmented Generation) parameters including chunking strategies, parser rules, and multimodal processing.
 - Organize content using tags, folders, and organization-level spaces.
 - Monitor document processing status (parsing, finalizing, indexing) and upload progress.
 - Perform bulk operations on knowledge items.
 - Navigate folders and manage folder trees.
 - Edit metadata and summaries of knowledge documents.
 - Access settings related to knowledge base configuration.
 
 
## Component Architecture

 The design is modularized into several Vue components that address different parts of the Knowledge Base interface:

 
 - **`KnowledgeBase.vue`**: The primary view container responsible for displaying knowledge base content tabs depending on the KB `type` (`document`, `faq`, `wiki`).
 - **`DocumentListView.vue`**: Renders knowledge documents in a table-like list with batch operations and status visualization [frontend/src/views/knowledge/components/DocumentListView.vue1-65](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/components/DocumentListView.vue#L1-L65).
 - **`DocumentCardView.vue`**: Displays knowledge documents as cards in a grid, with interactions for editing, tagging, and moving [frontend/src/views/knowledge/components/DocumentCardView.vue1-80](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/components/DocumentCardView.vue#L1-L80).
 - **`KbFolderTree.vue`**: Shows a collapsible hierarchical folder tree for document organization within a KB.
 - **`DocumentBatchBar.vue`**: Provides a batch action toolbar for multi-selection operations on documents [frontend/src/views/knowledge/components/DocumentBatchBar.vue1-35](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/components/DocumentBatchBar.vue#L1-L35).
 - **`ListSpaceSidebar.vue`**: Sidebar navigating spaces, including "All", "Favorites", "Recents", "Mine", and shared organizations.
 - **`DocumentActionMenu.vue`**: Context menu for document-specific actions such as edit, delete, reparse [frontend/src/views/knowledge/components/DocumentListView.vue6](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/components/DocumentListView.vue#L6-L6).
 - **`FolderPickerMenu.vue`**: Popup menu for selecting folders when moving documents `[frontend/src/views/knowledge/components/DocumentListView.vue:7-7]`, [frontend/src/views/knowledge/components/DocumentBatchBar.vue91-93](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/components/DocumentBatchBar.vue#L91-L93).

## Knowledge Base List View and Tag Sidebar

 
### Knowledge Base List View (`KnowledgeBaseList.vue`)

 
 - Displays knowledge base cards grouped by different contexts such as pinned, owned, and shared bases.
 - Shows upload progress for ongoing document ingestion, including completion percentages and errors.
 - Utilizes the `ListSpaceSidebar.vue` for filtering knowledge bases by space: "All", "Favorites", "Recents", "Mine" or by organization.
 - Supports creation of new knowledge bases visible for contributors.
 
 
```

```

 
 - The sidebar updates based on user selection; the `KBGrid` component requests filtered KB data correspondingly.
 - Upload progress panel dynamically appears based on inflight uploads, showing per-KB summaries.
 
 
### Tag Sidebar and Filtering

 
 - Tags are widely used for organizing knowledge documents.
 - Both `DocumentListView.vue` and `DocumentCardView.vue` components integrate tag display with overflow handling (`useTagChipsOverflow` composable) [frontend/src/views/knowledge/components/DocumentListView.vue79-84](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/components/DocumentListView.vue#L79-L84), [frontend/src/views/knowledge/components/DocumentCardView.vue84-90](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/components/DocumentCardView.vue#L84-L90).
 - Documents can be filtered by tag selection, status, source, and folder path.
 - Batch tagging is supported via batch dialogs, which allow managing tags on multiple documents at once.
 
 
### Folder Navigation Sidebar (`KbFolderTree.vue`)

 
 - Represents the folder hierarchy within a knowledge base.
 - Allows collapsing/expanding folders with persistent expanded state.
 - Inline renaming is supported with keyboard and blur commit handlers.
 - Uses helper functions in `folderTree.ts` for flattening and building the folder rows.

## Upload UI and Handling

 
### File Validation and Parser Engine Limits

 
 - Files selected for upload undergo client-side size verification against `MAX_FILE_SIZE_MB` (defaulting to 50MB, configurable via runtime config or environment variables) [frontend/src/utils/index.ts23-28](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/utils/index.ts#L23-L28).
 - File type verification checks files against allowed engine types retrieved dynamically via `getParserEngines` or static whitelists [frontend/src/utils/index.ts80-88](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/utils/index.ts#L80-L88), [frontend/src/components/AttachmentUpload.vue49-74](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/AttachmentUpload.vue#L49-L74).
 - Parser settings panels (`KBParserSettings.vue`) allow mapping specific file extensions (`pdf`, `docx`, `xlsx`, `pptx`, etc.) to parsing engines such as `builtin`, `markitdown`, `anydoc`, `mineru`, or `weknoracloud` [frontend/src/views/knowledge/settings/KBParserSettings.vue115-161](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/settings/KBParserSettings.vue#L115-L161).
 
 
### Upload Progress Indicator

 
 - `KnowledgeBaseList.vue` displays upload progress panels showing per-KB progress counts, completion, and errors.
 - Upload progress icons toggle between active upload and completion check-mark.
 - Progress bars dynamically reflect the ratio of completed to total files.
 
 
### Folder-Aware Uploads

 
 - Folder uploads include directory structure awareness by leveraging `webkitRelativePath`.
 - Target folders can be specified as batch upload destinations.
 - Folder structure is preserved inside knowledge bases.

# Summary

 The Knowledge Base Interface in WeKnora is a sophisticated Vue.js frontend subsystem providing:

 
 - Comprehensive listing, browsing, and management of knowledge documents and FAQs.
 - Flexible views via list and card layouts for knowledge items.
 - Detailed folder tree navigation with in-place editing.
 - Batch operations and bulk tagging support.
 - File type validation, engine rule configuration (`KBParserSettings.vue`), and directory path preservation.
 - Interactive upload progress feedback.
 - Integration of tagging and folder metadata deeply into the UI experience.
 - Modular composables and utilities that encapsulate stateful behaviors like tag overflow management and folder path construction.
 
 This set of components, utilities, and data flows work together to give users a powerful and intuitive interface to organize, upload, and curate knowledge resources effectively.
