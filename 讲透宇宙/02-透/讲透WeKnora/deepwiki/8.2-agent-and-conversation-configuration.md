## Agent Configuration Structure

 Persistent agent entities are represented by `types.CustomAgent`, while runtime parameters governing their execution are encapsulated in `types.CustomAgentConfig`.

 
### Core Agent Parameters

 
| Field | Type | Description | Default / Source |
|---|---|---|---|
| AgentMode | string | Operating mode: quick-answer (RAG) or smart-reasoning (ReAct multi-step reasoning). | internal/types/custom_agent.go36-41 |
| AgentType | string | Preset category under smart-reasoning mode (rag-qa, wiki-qa, hybrid-rag-wiki, data-analysis, custom). Pre-fills prompts and tool allowlists. | internal/types/custom_agent.go43-62 |
| SystemPrompt | string | System instructions text or a template reference (SystemPromptID). Supports placeholders like {{language}}. | internal/types/custom_agent.go133-136 |
| ModelID | string | LLM identifier used for driving conversations. | internal/types/custom_agent.go145 |
| MaxIterations | int | Maximum reasoning loop iterations in ReAct mode. | client/agent_manage.go86 |
| AllowedTools | []string | Whitelist of permitted tool names during agent execution. | client/agent_manage.go88 |
| KBSelectionMode | string | Knowledge base scope selection (all, selected, none). | client/agent_manage.go93 |

## Prompt Management and Templates

 WeKnora uses modular YAML templates for system prompts, intent classification, query rewriting, and fallback strategies.

 
### System Prompt & Intent Templates

 
 - **System Prompts**: Located in `config/prompt_templates/system_prompt.yaml`, defining personas such as `default_kb`, `expert_assistant`, `customer_service`, and `technical_support` [config/prompt_templates/system_prompt.yaml1-128](https://github.com/Tencent/WeKnora/blob/10973ed3/config/prompt_templates/system_prompt.yaml#L1-L128)
 - **Rewrite & Intent Prompts**: Located in `config/prompt_templates/rewrite.yaml`, controlling query coreference resolution, ellipsis completion, and intent routing (`kb_search`, `web_search`, `follow_up`, etc.) [config/prompt_templates/rewrite.yaml1-54](https://github.com/Tencent/WeKnora/blob/10973ed3/config/prompt_templates/rewrite.yaml#L1-L54)
 - **Fallback Templates**: Located in `config/prompt_templates/fallback.yaml`, specifying static text or model-delegated prompts when retrieval yields no results [config/prompt_templates/fallback.yaml1-117](https://github.com/Tencent/WeKnora/blob/10973ed3/config/prompt_templates/fallback.yaml#L1-L117)

## Built-in Agents Registry & Localization

 WeKnora provides pre-configured built-in agents defined in `config/builtin_agents.yaml` and registered via constants in `internal/types/custom_agent.go`.

 
### Built-in Agent Identifiers

 
 - `BuiltinQuickAnswerID` (`builtin-quick-answer`): Standard RAG quick response agent [internal/types/custom_agent.go16](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L16-L16)
 - `BuiltinSmartReasoningID` (`builtin-smart-reasoning`): ReAct framework multi-step agent [internal/types/custom_agent.go18](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L18-L18)
 - `BuiltinDataAnalystID` (`builtin-data-analyst`): Statistical analysis and SQL tool agent [internal/types/custom_agent.go21](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L21-L21)
 - `BuiltinWikiResearcherID` (`builtin-wiki-researcher`): Wiki knowledge base specialist [internal/types/custom_agent.go28](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L28-L28)
 - `BuiltinWikiFixerID` (`builtin-wiki-fixer`): Wiki page inspection and revision agent [internal/types/custom_agent.go30](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L30-L30)
 
 Localization overlays are applied dynamically at request time using `types.ApplyBuiltinAgentLocalization` based on request context.

## Conversation and Retrieval Configuration

 Conversation settings control history windowing, token budgets, and runtime context assembly.

 
### Conversation & Retrieval Parameters

 
| Parameter | Type | Description | Source |
|---|---|---|---|
| MultiTurnEnabled | bool | Enables inclusion of prior conversation history turns in context. | client/agent_manage.go112 |
| HistoryTurns | int | Number of previous dialogue rounds to include. | client/agent_manage.go113 |
| EmbeddingTopK | int | Number of vector chunks retrieved per search query. | client/agent_manage.go114 |
| KeywordThreshold | float64 | Minimum keyword match score threshold for sparse retrieval. | client/agent_manage.go115 |
| VectorThreshold | float64 | Minimum vector similarity score threshold for dense retrieval. | client/agent_manage.go116 |
| RerankTopK | int | Number of top documents retained after reranking. | client/agent_manage.go117 |

 History assembly and message preparation are handled in chat pipeline utility functions like `prepareMessagesWithHistory` and `loadAndProcessHistory`.
