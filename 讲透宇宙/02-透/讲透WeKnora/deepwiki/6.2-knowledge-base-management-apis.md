## Overview and Scope

 The Knowledge Base Management APIs expose the HTTP interface for managing knowledge base resources (`types.KnowledgeBase`) under the workspace/tenant scope [internal/application/service/knowledgebase.go118-120](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/knowledgebase.go#L118-L120)

 Key capabilities include:

 
 - **CRUD Operations**: Creating, retrieving, updating, and deleting knowledge bases via `KnowledgeBaseService` [internal/types/interfaces/knowledgebase.go18-86](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/interfaces/knowledgebase.go#L18-L86)
 - **Configuration Updates**: Managing chunking parameters, multimodal processing, immutable vector store bindings, and extraction rules [internal/types/knowledgebase.go58-124](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/knowledgebase.go#L58-L124)
 - **Cloning & Duplication**: Full content copying and settings-only duplication (`DuplicateKnowledgeBase`) [internal/types/interfaces/knowledgebase.go109-123](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/interfaces/knowledgebase.go#L109-L123)
 - **Hybrid Search**: Combining vector similarity with keyword ranking via `HybridSearch` [internal/types/interfaces/knowledgebase.go88-96](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/interfaces/knowledgebase.go#L88-L96)
 - **Access Management & Pinning**: Managing tenant ownership, RBAC permissions, and user-level UI pinning [internal/handler/knowledgebase.go39-41](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/knowledgebase.go#L39-L41) [internal/application/repository/knowledgebase.go112-145](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/repository/knowledgebase.go#L112-L145)

## Configuration Management & Data Structures

 The `KnowledgeBase` entity encapsulates various configuration structs that govern ingestion, chunking, storage, and indexing [internal/types/knowledgebase.go58-124](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/knowledgebase.go#L58-L124)

 
| Config Field | Type | Description |
|---|---|---|
| chunking_config | ChunkingConfig | Controls chunk size, overlap, separators, and parent-child chunking internal/types/knowledgebase.go79 |
| storage_provider_config | StorageProviderConfig | Selects backend provider (e.g., local, cos) internal/types/knowledgebase.go91 |
| vector_store_id | *string | Immutable binding to a dedicated vector store UUID (<-:create) internal/types/knowledgebase.go103 |
| auto_tag_config | *AutoTagConfig | Controls async auto-tagging of parsed documents internal/types/knowledgebase.go111 |
| faq_config | *FAQConfig | Indexing mode for FAQ knowledge bases internal/types/knowledgebase.go107 |
