  This section documents the WeKnora CLI commands related to knowledge bases (KB), documents, sessions (chat/agent), search, and Model Context Protocol (MCP) server commands. It covers key implementation details, internal data flow, command interfaces, recursive document upload support, Server-Sent Events (SSE) streaming with accumulation, and the agent-friendly JSON output format used for AI agent integration.

 
---

 
## Purpose and Scope

 The WeKnora CLI (`weknora`) is a command-line interface that allows users and AI agents to interact with a WeKnora RAG server. This leaf page provides full technical reference for:

 
 - **KB commands**: Managing knowledge bases (`kb list`, `kb view`, `kb create`, `kb delete`).
 - **Document commands**: Uploading documents (`doc upload`, `doc download`, recursive directory upload via `--recursive`).
 - **Session / Chat commands**: Streaming answers (`chat`, `session ask`).
 - **Search commands**: Hybrid search over chunks, documents, KBs, and sessions (`search chunks`, `search kb`, `search docs`, `search sessions`).
 - **MCP server commands**: Exposing a curated read-only tool surface via `weknora mcp serve`.
 - **Wire contracts & error handling**: JSON/NDJSON output envelopes and channel separation (stdout/stderr).

## 5. Search Subtree Commands

 The `search` package (`cli/cmd/search/search.go`) exposes a verb-noun command structure:

 
 - `search chunks "<q>" --kb X` — hybrid retrieval over chunks.
 - `search kb "<q>"` — find knowledge bases by name or description.
 - `search docs "<q>" --kb X` — locate documents inside a KB.
 - `search sessions "<q>"` — search chat history.

## 6. Model Context Protocol (MCP) Server Integration

 The CLI embeds an MCP server (`weknora mcp serve`) that registers a curated tool set in `cli/internal/mcp/tools.go` [cli/internal/mcp/tools.go:125-148].

 
### Registered MCP Tools

 
| Tool Name | Underlying Interface | Description |
|---|---|---|
| kb_list | knowledgeBaseService | List all knowledge bases visible to the tenant. |
| kb_view | knowledgeBaseService | Get details for a specific knowledge base. |
| doc_list | knowledgeService | List documents with filter options. |
| doc_view | knowledgeService | Get document metadata. |
| doc_download | knowledgeService | Download document source file. |
| search_chunks | knowledgeService | Run hybrid search over chunks. |
| chat | chatService | Run knowledge base chat QA. |
| agent_list / session_ask | agentService / sessionAskService | Execute custom agents or session queries. |
| chunk_list | chunkListService | Inspect document chunks for RAG debugging. |

 Sources: `cli/internal/mcp/tools.go:77-148`, `cli/internal/mcp/tools_test.go:193-203`

 Tool handlers wrap results using `successResult()` or `toolErrorResult()` to ensure consistent MCP payloads [cli/internal/mcp/tools.go:28-70].
