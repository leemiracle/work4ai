  This page documents the REST API endpoints for managing **chunks** (document segments) and **FAQ entries** (question-answer pairs) in WeKnora knowledge bases. These APIs enable CRUD operations, batch processing, search, and categorization of knowledge content.

## Chunk Management APIs

 Chunks are the fundamental retrieval units in WeKnora. Each document is segmented into chunks during processing. Chunk APIs enable listing, updating, and deleting these segments.

 
### List Chunks by Knowledge ID

 **Endpoint:** `GET /api/v1/chunks/:knowledge_id`

 Retrieves paginated chunks for a specific knowledge document via `ChunkHandler.ListKnowledgeChunks` [internal/handler/chunk.go99-152](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L99-L152) The system filters by status and type by default [internal/handler/chunk.go128-134](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L128-L134)

 **Parameters:**

 
 - `knowledge_id` (path, required): Document UUID [internal/handler/chunk.go103](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L103-L103)
 - `page` (query, optional): Page number [internal/handler/chunk.go92](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L92-L92)
 - `page_size` (query, optional): Items per page [internal/handler/chunk.go93](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L93-L93)
 - `chunk_type` (query, optional): Filter by type (e.g., `text`, `image_caption`) [internal/handler/chunk.go128-134](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L128-L134)
 
 Sources: [internal/handler/chunk.go99-152](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L99-L152)

 
### Get Chunk by ID

 **Endpoint:** `GET /api/v1/chunks/by-id/:id`

 Retrieves a single chunk by its UUID using `ChunkHandler.GetChunkByIDOnly` [internal/handler/chunk.go53-83](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L53-L83) The system supports a lookup that resolves the chunk regardless of the parent knowledge base, which is useful for permission resolution in shared contexts [internal/handler/chunk.go64-66](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L64-L66)

## FAQ Entry Management APIs

 FAQ entries are specialized chunks in FAQ-type knowledge bases. Each entry contains a standard question, optional similar/negative questions, and answers.

 
### Data Structure Mapping

### List FAQ Entries

 **Endpoint:** `GET /api/v1/knowledge-bases/:id/faq/entries`

 Retrieves paginated FAQ entries with specific field filtering. Access is validated via route-level guards [internal/handler/chunk.go18-23](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L18-L23)

 **Query Parameters:**

 
| Parameter | Description |
|---|---|
| keyword | Search term across questions or answers |
| search_field | Filter: standard_question, similar_questions, answers |
| tag_id | Filter by tag identifier |
| sort_order | asc for time ascending, default is descending |

## FAQ Batch Operations

 
### Batch Import (Upsert)

 **Endpoint:** `POST /api/v1/knowledge-bases/:id/faq/entries`

 Asynchronously imports or updates FAQ entries. This operation supports a `DryRun` mode for validation without committing changes [client/tag.go154-180](https://github.com/Tencent/WeKnora/blob/10973ed3/client/tag.go#L154-L180)

 Sources: [internal/handler/chunk.go16-38](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/chunk.go#L16-L38) [client/tag.go154-180](https://github.com/Tencent/WeKnora/blob/10973ed3/client/tag.go#L154-L180)

 
### Batch Field and Tag Updates

 **Endpoints:**

 
 - **Update Fields:** `PUT /api/v1/knowledge-bases/:id/faq/entries/fields`. Updates fields like `is_enabled` or `is_recommended` for multiple entries in batch.
 - **Update Tags:** `PUT /api/v1/knowledge-bases/:id/faq/entries/tags`. Updates tags for a set of FAQ entries based on their sequence IDs.
 
 Sources: [internal/handler/tag.go179-208](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/tag.go#L179-L208) [client/tag.go124-140](https://github.com/Tencent/WeKnora/blob/10973ed3/client/tag.go#L124-L140)

 
### Export FAQ Entries

 **Endpoint:** `GET /api/v1/knowledge-bases/:id/faq/entries/export`

 Generates an export of all FAQ entries. The service layer handles the transformation of chunk metadata into an exportable format.

## Tag Management

 Tags provide a mechanism for organizing both document knowledge and FAQ entries. They are managed at the knowledge base level through `TagHandler` and `knowledgeTagService` [internal/handler/tag.go18-43](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/tag.go#L18-L43)
