  This reference documentation details the architecture, authentication mechanisms, sync behaviors, and implementations for each supported external data source connector in WeKnora: Feishu Docs/Wiki/Drive, GitLab, Notion, Yuque, RSS feeds, and web crawlers.

## Architecture Overview

 All external connectors conform to the `datasource.Connector` interface defined in `internal/datasource/connector.go` [internal/datasource/connector.go11-53](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L11-L53) This interface standardizes lifecycle operations such as configuration validation, lazy resource discovery, ancestor resolution, full fetching, and incremental synchronization.

 
### Connector Interface Core Methods

 
 - `Type() string`: Returns the unique string identifier for the connector type (e.g., `"feishu"`, `"notion"`, `"yuque"`, `"gitlab"`, `"rss"`).
 - `Validate(ctx context.Context, config *types.DataSourceConfig) error`: Tests connectivity and authenticates credentials against the remote service [internal/datasource/connector.go11-17](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L11-L17)
 - `ListResources(ctx, config, parentID) ([]Resource, error)`: Enumerates selectable resources, supporting lazy-loading via `parentID` [internal/datasource/connector.go19-28](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L19-L28)
 - `ResolveResourceAncestors(ctx, config, resourceIDs) ([]string, error)`: Resolves ancestor paths for lazy-loaded UI pickers [internal/datasource/connector.go40-42](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L40-L42)
 - `FetchAll(ctx, config, resourceIDs) ([]FetchedItem, error)`: Performs a full sync of selected resources [internal/datasource/connector.go44-46](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L44-L46)
 - `FetchIncremental(ctx, config, cursor) ([]FetchedItem, *SyncCursor, error)`: Retrieves updated items since the previous sync cursor [internal/datasource/connector.go48-52](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L48-L52)
 
 Advanced connectors implement `StreamingConnector` (`FetchStream`) or `FullStreamingConnector` (`FetchFullStream`) to interleave fetching, ingestion, and cursor checkpointing, preventing memory exhaustion on large knowledge repositories [internal/datasource/connector.go82-105](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L82-L105)

## Feishu & Lark Connectors

 The Feishu (`feishu`, `feishu_drive`) and Lark (`lark`, `lark_drive`) connectors share a common codebase for integrating with Feishu and Lark Open APIs [internal/types/datasource.go17-27](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/datasource.go#L17-L27)

 
 - **Authentication**: Uses Internal App or Custom App credentials (`app_id` and `app_secret`) to mint a `tenant_access_token`. Credentials are encrypted at rest using AES-256-GCM and stored securely via the `/credentials` subresource [internal/types/interfaces/datasource.go27-37](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/interfaces/datasource.go#L27-L37)
 - **Resource Discovery**: Supports hierarchical lazy-loading. The root call lists accessible Wiki Spaces or Drive folders (`parentID == ""`), while deeper levels query children dynamically [internal/datasource/connector.go19-28](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector.go#L19-L28) Ancestor resolution (`ResolveResourceAncestors`) reconstructs selection paths in the UI tree picker.
 - **Sync Behavior**: Supports both full and incremental synchronization modes, leveraging streaming fetch interfaces to checkpoint cursors at page boundaries.

## Notion Connector

 The Notion connector interfaces with the Notion API to synchronize pages, databases, and blocks.

 
 - **Resource Mapping**: Enumerates top-level pages and databases. Database rows are automatically mapped as child items.
 - **Content Conversion**: Translates Notion block structures into standardized Markdown for ingestion into WeKnora's retrieval pipeline [internal/datasource/connector/notion/connector.go23-220](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector/notion/connector.go#L23-L220)
 - **Sync Logic**: Full sync pulls all selected pages and databases, while incremental sync relies on last-edited timestamps stored in sync cursors.

## Yuque Connector

 The Yuque connector (`yuque`) synchronizes documents from Yuque repositories (books) [internal/datasource/connector/yuque/connector.go22-140](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector/yuque/connector.go#L22-L140)

 
 - **Authentication**: Uses a personal access token passed via the `X-Auth-Token` header. Automatically detects whether the token belongs to a personal `User` or a team `Group` to adjust API traversal paths [internal/datasource/connector/yuque/connector.go68-120](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector/yuque/connector.go#L68-L120)
 - **Resource Discovery**: `ListResources` aggregates repositories from personal accounts and joined groups [internal/datasource/connector/yuque/connector.go53-140](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector/yuque/connector.go#L53-L140)
 - **Sync Filtering**: Only synchronizes published documents (`status == "1"`) of type `"Doc"`, ignoring drafts, sheets, and board files [internal/datasource/connector/yuque/connector.go182-198](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/datasource/connector/yuque/connector.go#L182-L198)

## GitLab Connector

 The GitLab connector (`gitlab`) allows users to ingest repository file trees and documentation from GitLab instances [internal/types/datasource.go39](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/datasource.go#L39-L39)

 
 - **Authentication**: Requires a Personal Access Token or OAuth token with repository read permissions.
 - **Sync Behavior**: Recursively walks repository files or specific subdirectories, converting code and markdown files into indexed knowledge documents.

## RSS Feed Connector

## Web Crawler Connector

 The Web Crawler connector (`web_crawler`) crawls arbitrary web URLs for document ingestion [internal/types/datasource.go35](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/datasource.go#L35-L35)

 
 - **Configuration**: Accepts target URLs, crawl depth limits, and filtering rules.
 - **Sync Behavior**: Tracks URL modification hashes and maintains a crawl cursor state to support incremental re-crawling.

## Authentication and Credentials Management

 
 - **Storage Security**: Connector credentials are encrypted using AES-256-GCM and stored separately from non-secret configuration parameters.
 - **API Redaction**: Normal data source API responses strip credential payloads. Management is handled via dedicated endpoints under `/credentials` [internal/types/interfaces/datasource.go27-37](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/interfaces/datasource.go#L27-L37)
 - **UI Management**: The frontend editor component (`DataSourceEditorDialog.vue`) provides status indicators and safe replacement or removal actions without exposing raw secrets [frontend/src/views/knowledge/settings/DataSourceEditorDialog.vue36-100](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/settings/DataSourceEditorDialog.vue#L36-L100)
