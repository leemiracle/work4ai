  The Internationalization (i18n) System in WeKnora provides structured multi-language support across both the Vue.js frontend and the Go backend services. It allows users to interact with the interface and receive system messages in their preferred language by mapping domain-oriented keys to localized strings.

 
---

 
## Architecture Overview

 WeKnora’s i18n system uses the Vue I18n library integrated into the Vue 3 frontend (`frontend/src/i18n/`) alongside backend middleware (`internal/router/router.go`) that extracts language headers. The frontend architecture relies on a hierarchical, key-based translation model grouped by functional namespaces.

## Translation File Structure and Supported Languages

 Translation resources reside in the `frontend/src/i18n/locales/` directory. Each supported locale exports a default TypeScript object defining nested translation keys.

 
### Supported Language Files

 
| Locale File | Language | Description |
|---|---|---|
| zh-CN.ts | Chinese (Simplified) | Primary Chinese UI text and base locale |
| en-US.ts | English (US) | Primary English UI text |
| ru-RU.ts | Russian | Extended Russian localization |
| ko-KR.ts | Korean | Extended Korean localization |
| ja-JP.ts | Japanese | Extended Japanese localization |

## Translation Key Namespaces

 Translation keys are grouped into fine-grained domain namespaces:

 
| Namespace | Purpose | Example Keys |
|---|---|---|
| menu | Navigation menus and sidebar labels | menu.newChat, menu.settings |
| newUserGuide | Onboarding walkthrough steps | newUserGuide.steps.welcome |
| platformApiKeys | Platform-level API key management UI | platformApiKeys.title, capability |
| tenantInvitation | Invitation lifecycle messaging and links | tenantInvitation.inviteSubmit |
| agent.editor | Agent creation and configuration modal | agent.editor.createTitle |

## Adding New Translations

 
### Implementation Steps

 
 - **Add Base Keys:** Add entries in `frontend/src/i18n/locales/zh-CN.ts` under the relevant namespace.
 - **Translate Parity:** Populate corresponding keys in `en-US.ts`, `ru-RU.ts`, `ko-KR.ts`, and `ja-JP.ts`.
 - **Invoke in Components:** Reference the key via `t('namespace.key')` or `{{ $t('namespace.key') }}`.
