## Purpose and Scope

 The **Settings and Configuration Interface** offers a unified, centralized modal-based UI for managing system-wide and tenant-specific configurations. It encompasses agent setup, conversation behavior, model selection, sandbox and skill management, web search providers, MCP services, and global system preferences. The interface is primarily implemented under Vue components such as `Settings.vue`, `ModelSettings.vue`, `McpSettings.vue`, and specialized drawers like `ModelEditorDialog.vue` [frontend/src/views/settings/ModelSettings.vue1-36](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/settings/ModelSettings.vue#L1-L36) [frontend/src/components/ModelEditorDialog.vue1-64](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/ModelEditorDialog.vue#L1-L64)

 The settings interface organizes configuration into:

 
 - **Workspace/Tenant-scoped configurations:** Stored and persisted in the database as entities (e.g., models via `ModelHandler`, sandboxes, MCP services) or as JSONB metadata within tenant tables [internal/handler/model.go66-123](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/model.go#L66-L123)
 - **System-wide configurations:** Available only to system admins, guarded server-side and via route meta tags; persisted in platform-wide tables [frontend/src/views/system/SystemSettings.vue1-34](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/system/SystemSettings.vue#L1-L34)
 - **Frontend UI preferences:** Language, theme, drawer widths, and other transient or local preferences stored in reactive Pinia stores and `localStorage`.
 
 The UI follows a declarative pattern where controls auto-save on user interaction (e.g., switch toggles, selects trigger immediate commits on change, inputs persist on blur).

## Settings Interface Structure and Navigation

 The settings modal uses tabbed navigation patterns to organize configuration areas. Common settings groups include:

 
| Section Key | Purpose / Content | Access Level |
|---|---|---|
| conversation | Conversation defaults and multi-turn settings | Tenant-level; editable by members |
| models | Model registration, selection, and configuration | Read-only for viewers, editable by admins frontend/src/views/settings/ModelSettings.vue9-21 |
| sandbox | Sandbox environment configs and skill installation management | Admin-only frontend/src/components/SandboxSkillsPanel.vue7-39 |
| skills | Skill catalog and skill execution environment settings | Admin-only |
| mcp | Model Context Protocol service integration and tool catalogs | Admin-only frontend/src/views/settings/McpSettings.vue29-39 |
| system | Platform-wide global settings (system admins only) | System admin only frontend/src/views/system/SystemSettings.vue1-34 |

 An embedded `SettingDrawer.vue` component supports resizable side panel drawers for detailed configurations (e.g., model editors, MCP service configs) with width persistence via `localStorage` and customizable header actions [frontend/src/components/ModelEditorDialog.vue2-7](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/ModelEditorDialog.vue#L2-L7) [frontend/src/views/settings/McpSettings.vue99-107](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/settings/McpSettings.vue#L99-L107)

## Agent Configuration and Conversation Settings

 The agent configuration UI allows tuning parameters such as:

 
 - Agent modes and reasoning patterns (e.g., Smart Reasoning with multi-turn enabled)
 - Conversation defaults (system prompts, history turns limits)
 - Query rewrite enablement (visible in non-agent mode)
 - Retrieval retention toggles (conditional on linked knowledge base presence)
 
 Within agent editors, conversation sections remain accessible, avoiding UI gating based on running mode. Multi-turn switches adapt to smart-reasoning mode where multi-turn execution is enforced by default.

## System Preferences and Global Settings

 - Sections for access control (admin email management via `t-tag-input`), tenant policies, runtime parameters, and security (such as SSRF whitelists) [frontend/src/views/system/SystemSettings.vue69-112](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/system/SystemSettings.vue#L69-L112)

## Summary

 The **Settings and Configuration Interface** integrates modular Vue components into a permission-aware modal and settings view system. It supports agent tuning, model CRUD operations, sandbox skill management, MCP configurations, and system-wide parameters backed by structured Go handlers and secure REST APIs.
