  The embedded chat channels subsystem enables administrators to publish custom AI agents as embeddable web chat widgets on external websites. This page documents backend configuration handlers, service layer logic, public session flow, anonymous visitor management, streaming chat sessions via `useEmbedChatSession`, and the frontend component architecture (`EmbedChatCore`, `EmbedBotMessage`, `EmbedUserMessage`).

 
---

 
### 5.7.1 Embed Channel Configuration and Management

 Embed channels are bound to specific custom agents within a tenant. Administrators configure these channels through the management UI (`AgentEmbedChannelPanel.vue`), where settings such as allowed origins, rate limits, UI themes, welcome messages, and toggleable features (web search, file uploads) are defined [frontend/src/components/AgentEmbedChannelPanel.vue:1-120] ([frontend/src/components/AgentEmbedChannelPanel.vue1-120](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/AgentEmbedChannelPanel.vue#L1-L120)).

 Backend CRUD operations are managed by `EmbedChannelHandler` in `internal/handler/embed_channel.go` [internal/handler/embed_channel.go:28-38] ([internal/handler/embed_channel.go28-38](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/embed_channel.go#L28-L38)) and executed through `embedChannelService` in `internal/application/service/embed_channel.go` ([internal/application/service/embed_channel.go](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/embed_channel.go)). When a channel is created via `CreateEmbedChannel` [internal/handler/embed_channel.go:119-172] ([internal/handler/embed_channel.go119-172](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/embed_channel.go#L119-L172)), the service generates a secure cryptographic publish token.

 Origin security is enforced during channel creation and updates via `validateAllowedOrigins()`, which rejects wildcard entries (`*`) in production mode and validates well-formed http/https origins or subdomain wildcards [internal/handler/embed_channel.go:94-128] ([internal/handler/embed_channel.go94-128](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/embed_channel.go#L94-L128)).

### 5.7.2 Public Session Flow and Authentication

 When an external website embeds the chat widget, the client-side widget initializes via `EmbedPage.vue` ([frontend/src/views/embed/EmbedPage.vue](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/embed/EmbedPage.vue)) using the embed bridge composable.

 
 - **Visitor Identification**: The client generates or retrieves a stable anonymous visitor UUID stored in `localStorage` scoped by the channel ID using `getOrCreateEmbedVisitorId()` [frontend/src/api/embed/index.ts:108-123] ([frontend/src/api/embed/index.ts108-123](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/api/embed/index.ts#L108-L123)).
 - **Session Token Issuance**: Short-lived session tokens prefixed with `ems_` (`EMBED_SESSION_TOKEN_PREFIX`) are minted by the backend to authenticate runtime requests without exposing master credentials [frontend/src/api/embed/index.ts:59-60,155-158] ([frontend/src/api/embed/index.ts59-158](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/api/embed/index.ts#L59-L158)).
 - **Protected File Access**: Because embed visitors do not possess standard Bearer user credentials, protected file rendering (such as inline images or attachments) is routed through an embed-scoped access context configured with the channel ID and token [frontend/src/views/embed/EmbedBotMessage.vue:165-171] ([frontend/src/views/embed/EmbedBotMessage.vue165-171](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/embed/EmbedBotMessage.vue#L165-L171)). Additionally, resource URL requests such as `resource_urls=public` are ignored or downgraded for embed traffic to prevent leakage of public assets [internal/handler/embed_resource_urls_test.go:57-69] ([internal/handler/embed_resource_urls_test.go57-69](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/handler/embed_resource_urls_test.go#L57-L69)).

### 5.7.4 External Site Integration and Styling Injection

 To integrate an embed channel into an external website, administrators embed an iframe or JavaScript snippet pointing to the public embed route.

 The frontend runtime dynamically injects custom theme variables—such as primary brand colors (`primary_color`)—into the document style root to ensure seamless visual alignment with the host site's branding guidelines. Additionally, session state persistence is managed via localStorage keys generated by `embedChatSessionStorageKey()` [frontend/src/api/embed/index.ts:125-127] ([frontend/src/api/embed/index.ts125-127](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/api/embed/index.ts#L125-L127)), with automatic mismatch clearing if the bound agent changes [frontend/src/api/embed/index.ts:139-153] ([frontend/src/api/embed/index.ts139-153](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/api/embed/index.ts#L139-L153)).
