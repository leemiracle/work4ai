## Purpose and Scope

 The chat interface provides the primary user interaction point for both standard knowledge QA and agent-based conversations. It handles:

 
 - **Real-time streaming message display**: Uses Server-Sent Events (SSE) to incrementally render content as it arrives from the backend [frontend/src/views/chat/index.vue89-96](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/index.vue#L89-L96)
 - **Dual-mode rendering**: Switches between standard knowledge QA mode and complex agent reasoning visualization based on message metadata [frontend/src/views/chat/components/botmsg.vue17-26](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/botmsg.vue#L17-L26)
 - **Historical message reconstruction**: Restores conversation state from the database, ensuring complex agent execution steps and thinking blocks are faithfully preserved while avoiding layout shifts by using stable keys [frontend/src/views/chat/index.vue68-76](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/index.vue#L68-L76)
 - **Tool call visualization**: Structured rendering of tool outputs such as web search results, knowledge retrieval, plans, and agent thinking within the agent workflow timeline [frontend/src/views/chat/components/AgentStreamDisplay.vue1-125](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/AgentStreamDisplay.vue#L1-L125)
 - **User input handling**: Supports `@mentions` of knowledge bases, tags, and tools, image uploads for multimodal models, and file attachments with preview capabilities [frontend/src/views/chat/components/usermsg.vue4-39](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/usermsg.vue#L4-L39)

### Message Data Structure

 The reactive `messagesList` array maintains the chat messages. Assistant messages include metadata to control advanced display modes:

 
| Property | Type | Description |
|---|---|---|
| role | string | Sender identity ("user" or "assistant") frontend/src/views/chat/index.vue81-87 |
| isAgentMode | boolean | Enables detailed agent step-by-step timeline visualization frontend/src/views/chat/components/botmsg.vue19 |
| isRagMode | boolean | Toggles RAG retrieval progress UI frontend/src/views/chat/components/botmsg.vue17 |
| knowledge_references | array | Chunks retrieved from knowledge bases during the conversation frontend/src/views/chat/components/botmsg.vue30 |
| mentioned_items | array | Explicitly mentioned KBs, tags, or tools tagged by the user frontend/src/views/chat/components/botmsg.vue5-16 |
| suggestionSet | object | Suggested follow-up questions generated by the system frontend/src/views/chat/index.vue95-102 |

## Message Rendering and Security

 
### Markdown, LaTeX, and Mermaid Integration

 
 - WeKnora uses `marked` with extensions for LaTeX math rendering (`marked-katex-extension`) and customized renderer functions defined in `chatMarkdownRenderer.ts` [frontend/src/utils/chatMarkdownRenderer.ts1-60](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/utils/chatMarkdownRenderer.ts#L1-L60)
 - Code blocks labeled `mermaid` are intercepted by `createMermaidCodeRenderer` and processed via `renderMermaidToSvg` using dynamically resolved theme variables based on the current document theme mode (`frontend/src/utils/mermaidShared.ts`) [frontend/src/utils/mermaidShared.ts14-230](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/utils/mermaidShared.ts#L14-L230)
 - Advanced stream preprocessing (`prepareStreamingMermaidMarkdown`, `replaceIncompleteImageWithPlaceholder`, `normalizeFullwidthMarkdownImageParentheses`, and `normalizeLegacyImageContextMarkup`) ensures unstable or partial markdown tags (such as incomplete image links or legacy `<image>` XML blocks) do not break the layout during real-time streaming [frontend/src/utils/chatMarkdownRenderer.ts63-170](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/utils/chatMarkdownRenderer.ts#L63-L170)
