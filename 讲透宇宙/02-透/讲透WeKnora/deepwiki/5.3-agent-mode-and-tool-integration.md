## Agent Modes and Architecture

 WeKnora supports a sophisticated agent system primarily driven by `AgentEngine` [internal/agent/engine.go28-35](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/engine.go#L28-L35) and orchestrated by `agentService` [internal/application/service/agent_service.go94-95](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/agent_service.go#L94-L95) Unlike standard RAG, Agent mode enables the model to reason iteratively about tool selection and information retrieval.

 The `AgentEngine` is stateless across turns; conversation history is rebuilt from the database once per turn by the caller via `LoadAgentHistory` and passed into `Execute` as `llmContext` [internal/agent/engine.go30-34](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/engine.go#L30-L34) [internal/application/service/session_agent_qa.go148-153](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/session_agent_qa.go#L148-L153)

 
### Agent Modes and Presets

 The system defines running modes and agent type presets in `internal/types/custom_agent.go`:

 
 - **Quick Answer (`AgentModeQuickAnswer`)**: A standard RAG mode for fast, single-turn Q&A [internal/types/custom_agent.go36-38](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L36-L38)
 - **Smart Reasoning (`AgentModeSmartReasoning`)**: A ReAct mode for multi-step reasoning and tool invocation [internal/types/custom_agent.go39-41](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L39-L41)
 - **Agent Types (`AgentTypeRAGQA`, `AgentTypeWikiQA`, `AgentTypeHybridRAGWiki`, `AgentTypeDataAnalysis`, `AgentTypeCustom`)**: Presets under smart-reasoning mode that bundle recommended system prompt templates, tool allowlists, and KB compatibility [internal/types/custom_agent.go43-62](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/custom_agent.go#L43-L62)
 
 
### ReAct Loop Architecture

 The engine implements a **Reason-Act** loop capped by `MAX_ITERATIONS` (default 100) [internal/application/service/agent_service.go30](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/agent_service.go#L30-L30) In each iteration, the LLM generates reasoning content and optional tool calls; the engine executes these tools and feeds results back into the context until a final answer is produced.

## Tool Registration and Catalog

## MCP Tool Integration

 WeKnora integrates with external services via the Model Context Protocol (MCP). MCP tools are dynamically discovered and registered into the agent's tool catalog based on tenant configuration and per-turn `@mention` pinning [internal/agent/engine.go123-126](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/engine.go#L123-L126)

 
### MCP Approval Gate

 Sensitive MCP tools are governed by a human approval gate implemented via `approval.MCPApproval`, pausing execution until user consent is granted [internal/application/service/agent_service.go115](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/agent_service.go#L115-L115)

## Agent Skills and Progressive Disclosure

 WeKnora implements a **Progressive Disclosure** pattern for skills to avoid polluting the system prompt with excessive static instructions [internal/agent/engine.go47](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/engine.go#L47-L47)

 
 - **Discovery**: The skills subsystem scans available skill bundles and libraries [internal/agent/skills/manager.go](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/skills/manager.go)
 - **Prompt Injection**: Lightweight metadata about available skills is formatted into the system prompt, enabling the LLM to understand what capabilities exist without loading full implementations [internal/agent/prompts.go191](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/prompts.go#L191-L191)
 - **Pinned Mentions**: Per-request `@mentions` force-include specific skills in the engine's active tool scope [internal/agent/engine.go123-126](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/engine.go#L123-L126)

## Advanced Execution Features

 
### Context Window Management and Compaction

 When conversation history or tool outputs push token counts past configured thresholds, `AgentEngine.manageContextWindow` and `runCompaction` summarize older history or trim oversized tool outputs [internal/agent/observe.go39-67](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/observe.go#L39-L67)

 
### Watchdog and Stream Stalls

 During LLM output generation, `streamLLMToEventBus` uses `watchStreamStall` to monitor stream responsiveness against configured stall timeouts, preventing hung connections from blocking execution threads indefinitely [internal/agent/think.go30-74](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/think.go#L30-L74)

 
### VLM Image Analysis in Tools

 When tool responses contain image artifacts, `AgentEngine` can leverage an injected image describer function (VLM) to generate inline text descriptions for downstream reasoning [internal/agent/engine.go49](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/engine.go#L49-L49)

## Prompting and Context

 
### System Prompt Templates

 Default system prompts are loaded from YAML templates (such as `pure_agent`, `progressive_rag_agent`, `data_analyst`, and `wiki_researcher`), supporting multi-language localization and role specialization [config/prompt_templates/agent_system_prompt.yaml4-106](https://github.com/Tencent/WeKnora/blob/10973ed3/config/prompt_templates/agent_system_prompt.yaml#L4-L106)

 
### Runtime Context Injection

 The engine injects structured XML context blocks into the user message turn to ground the agent:

 
 - **Knowledge Base Info**: Descriptions, types, and retrieval capabilities of bound KBs [internal/agent/prompts.go72-160](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/prompts.go#L72-L160)
 - **Selected Documents**: Metadata for individual documents referenced via `@` mentions [internal/agent/prompts.go47-55](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/prompts.go#L47-L55)
 - **Pinned Mentions**: Scope definitions for explicitly requested MCP services and skills [internal/agent/prompts.go57-70](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/prompts.go#L57-L70)
