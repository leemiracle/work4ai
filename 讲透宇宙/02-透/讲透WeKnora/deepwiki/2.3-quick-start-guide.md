## 3. Configure AI Models

 WeKnora mandates at least one embedding model for vectorization and one LLM for generation.

 **Model Management Workflow:** The frontend component `ModelEditorDialog.vue` manages model registration and credential validation [README.md69](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L69-L69)

 
 - **Connectivity Validation:** The UI invokes `checkRemoteAPI` to verify provider endpoints prior to database persistence [README.md69](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L69-L69)
 - **Security:** Sensitive API keys are encrypted at rest using AES-256-GCM [README.md69](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L69-L69)
 - **Ollama Integration:** Local models are fetched and instantiated through `OllamaService` initialized in `internal/container/container.go` [README.md62](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L62-L62)

## 4. Create a Knowledge Base

 - **Chunking Parameters:** Defines `chunkSize`, `chunkOverlap`, and hierarchical `parent-child` chunking strategies [README.md67](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L67-L67)

## 5. Upload and Process Documents

 Document ingestion runs asynchronously via background worker queues.

 **Ingestion Pipeline:**

 
 - **Upload:** Files are posted via the knowledge interface.
 - **Task Enqueue:** `KnowledgeHandler` dispatches background tasks via `Asynq` configured in `internal/container/container.go` [README.md60](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L60-L60)
 - **Parsing:** The gRPC `DocReader` service extracts text and structural elements [README.md61](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L61-L61)
 - **Chunking & Embedding:** `ChunkService` segments text, and `EmbedderPooler` generates vector arrays [README.md67](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L67-L67)
 - **Vector Indexing:** Embeddings are written to the configured vector store (`pgvector`, Qdrant, Milvus, etc.) [README.md62](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L62-L62)

## 6. Interaction Modes

 Open the chat workspace to query the initialized knowledge base.

 
| Interaction Mode | Execution Engine | Core Capabilities |
|---|---|---|
| Knowledge QA | Standard RAG Pipeline | Semantic vector retrieval combined with LLM prompt augmentation README.md54 |
| Agent Mode | ReAct Reasoning Loop | Autonomous tool orchestration, web search, and skill sandboxes README.md54 |
| Wiki Mode | Auto-Wiki Ingestion | Agent-driven Markdown generation and graph relationship extraction README.md60 |

 **Advanced Execution Features:**

 
 - **Temporary Attachments:** Pass transient files directly into chat sessions without persisting them to knowledge base storage [CHANGELOG.md69](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L69-L69)
 - **@Mention Scoping:** Constrain agent tool execution using `@Skill` or `@MCP` prefixes [CHANGELOG.md69](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L69-L69)

## Troubleshooting

 
| Symptom | Root Cause | Resolution Steps |
|---|---|---|
| Parsing stuck at "Processing" | Worker queue saturation or dead worker pool | Inspect the Runtime Queues dashboard for task backlogs CHANGELOG.md69 |
| Model execution errors | Invalid API credentials or concurrency limits | Verify connection settings in ModelEditorDialog.vue and model rate limits CHANGELOG.md69 |
| Ollama integration failure | Local service unreachable | Ensure Ollama container connectivity and check OLLAMA_API_BASE_URL in .env docs/QA.md24 |
