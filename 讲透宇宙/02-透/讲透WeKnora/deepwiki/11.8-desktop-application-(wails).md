  The WeKnora Desktop Application is a native cross-platform distribution of the WeKnora Lite edition. It leverages the [Wails](https://wails.io) framework to bundle the Go-based backend and Vue.js frontend into a single executable. This version is designed for local-first usage, featuring zero-dependency deployment, SQLite-based storage, and native OS integrations such as custom window management and tray support.

 
---

 
## Architecture Overview

 The desktop application combines a native OS webview container with an embedded Go backend. The system coordinates IPC messages via generated Wails bindings and launches an embedded Gin-based HTTP server locally.

## Implementation Details

 
### Application Startup and Lifecycle

 The entry point located in `cmd/desktop/main.go` configures the desktop environment:

 
 - On macOS `.app` bundles, it changes the working directory to the `Resources` folder to access bundled configuration files [cmd/desktop/main.go153-156](https://github.com/Tencent/WeKnora/blob/10973ed3/cmd/desktop/main.go#L153-L156)
 - It loads environment variables explicitly via `godotenv.Load()` to ensure desktop-specific parameters like `DB_DRIVER` are honored [cmd/desktop/main.go166-167](https://github.com/Tencent/WeKnora/blob/10973ed3/cmd/desktop/main.go#L166-L167)
 - Logger and Gin server modes are configured based on execution flags [cmd/desktop/main.go169-173](https://github.com/Tencent/WeKnora/blob/10973ed3/cmd/desktop/main.go#L169-L173)

## Lite Mode vs. Standard Edition

 The desktop application corresponds to the **Lite** edition of WeKnora, focusing on local-first capabilities.

 
| Dimension | Lite (Desktop) | Standard (Server) |
|---|---|---|
| Storage | SQLite (weknora.db) Formula/weknora-lite.rb54 | PostgreSQL / MySQL + Redis |
| Dependencies | Zero external dependencies | Requires Docker Compose, Redis, DB container |
| Network | Loopback by default, configurable public bind cmd/desktop/app.go53-71 | Multi-service gateway routing |
| Scope | Single-user, local-first | Multi-tenant organization structure |

## Packaging and Distribution

 
### CI/CD Release Automation

 Desktop and single-binary builds are automated through GitHub Actions workflows (`.github/workflows/release-lite.yml`). The workflow builds the frontend, compiles platform-specific binaries with CGO enabled, and bundles them into archives or native desktop installers (`wails build`) [.github/workflows/release-lite.yml138-220](https://github.com/Tencent/WeKnora/blob/10973ed3/.github/workflows/release-lite.yml#L138-L220)

 
### Homebrew Formula

 The `Formula/weknora-lite.rb` Homebrew script manages installation of the Lite single-binary edition on macOS and Linux, configuring environment paths (`$HOME/.config/weknora` and `$HOME/.local/share/weknora`) and service lifecycles [Formula/weknora-lite.rb37-74](https://github.com/Tencent/WeKnora/blob/10973ed3/Formula/weknora-lite.rb#L37-L74)
