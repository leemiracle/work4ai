## 一、定位：按"经典度"筛选的必读书目，而非顺序化教材

Terry Um 维护的 awesome 论文清单，定位在 `README.md:7`：**2012-2016 被引最高的深度学习论文精选**。理念见 `README.md:9`：存在不论领域都值得读的 classic 论文，宁缺毋滥地收 top 100。`README.md:13` 交代生态位：Deep Vision / Awesome RNN 按领域堆量、songrotek Roadmap 按学习顺序组织，本清单居中——**按被引门槛筛出的"经典度"组织**。

一个必须纠正的预期偏差：想象中的"前置数学→经典架构→领域分卷"三段式并不存在，源码实证**无数学前置节、无显式阅读顺序**。实际骨架（Contents `README.md:47`）是主榜 10 个领域分节 + "More than Top 100" 附属区（New papers / Old Papers / HW·SW·Dataset / Book·Survey / 视频课程 / Appendix）。最接近"前置"的是附属区书与综述（`README.md:264`，Goodfellow 书、Nielsen 书）和 Old Papers 前史（`README.md:233`，1997 LSTM、1998 LeCun、2006 DBN）。**当"经典书目"用，别当"教材"用**。

## 四、维护状态：已停摆的"时间胶囊"（这恰是价值所在）

`README.md:5` 顶部明示 **"not being maintained anymore"**——2017 年起停止维护。这是一切评估的前提：

- **优点**：冻结成 2016 年视角的时间胶囊，主榜经历史检验仍多为标准引用，不受后世热度通胀污染，是研究"复兴期知识结构"的好样本。
- **缺点**：2017 年后全部缺席（Transformer/BERT 皆无）；`README.md:42` 自述的配套工具已老化（下节）。
- **体检**：`top100papers.bib` 宣称覆盖 all top-100，实测 **101 条与主榜 100 篇对不齐**——多收 3 篇附录区论文（Chung character-level decoder、Girshick R-CNN 综述、DeepPose），漏收 2 篇主榜（Spatial Transformer Networks、Lample NER）。写引用前须自行补漏。`ReadingNotes.md:5` 是维护者个人笔记（一篇未入清单的 2017 机器人论文），与主线关系不大。

## 五、配套工具链：README 条目格式是隐式数据契约

三件工具消费同一约定——主榜条目 = `**标题** (年份), 作者 [[pdf]](直链)`：

1. **fetch_papers.py**（39 行模块级脚本）：按 `###` 节标题建目录，正则（`fetch_papers.py:27`）只抓加粗+pdf 的 100 篇下载，按文件已存在断点续传（`fetch_papers.py:32`）。今日仍可用，风险仅部分链接失效。
2. **get_authors.py**：抽标题 → 爬 Semantic Scholar 搜索页抽作者 → 按排名加权（score=Σ1/排名，`get_authors.py:102`）出 author.csv。**已不可用**：靠 DOM 标签路径匹配（`get_authors.py:47`），Semantic Scholar 早已改版；且有两处实证 bug——`get_authors.py:85` `paper.replace(" ", "%20")` 返回值被丢弃（字符串不可变，编码 no-op）、`get_authors.py:105` 写 CSV 缺换行符（行粘连）。
3. **top100papers.bib**：101 条 BibTeX（首条 `top100papers.bib:1` 为 Hinton Distilling），对账见上节。

## 六、作为学习路径的使用建议

1. **适用人群**：补深度学习"古典时期"（2012-2016）根基的人；目标若是 2020 后的 LLM/多模态栈，本清单只能当中层地基，Transformer 之后需另配路线。
2. **走法**：先 Old Papers 前史 3 篇建立时间感 → 按节读主榜，NLP/RNN 18 篇拆成 word2vec→seq2seq→attention→memory 四条小线 → More 2016 候补区选读。各节末 HTML 注释藏着 Key researchers 名单，可当"该方向关注谁"的索引。
3. **工程借鉴**：fetch_papers.py 用"格式约定代替解析器"是微仓工具范本；get_authors.py 是反例教材（DOM 依赖 + 字符串 bug）。
