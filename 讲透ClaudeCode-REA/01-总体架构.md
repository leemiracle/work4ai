## 2. 三进程/三形态产品线

同一二进制承载三种运行形态 [S]（系统提示词三变体实证）：

1. **CLI/REPL**（`claude` 交互式）——主形态，本报告主线；
2. **Claude Agent SDK**（`running within the Claude Agent SDK` 提示词变体）——
   嵌入宿主应用，headless `-p/--print` 模式同源；
3. **Orchestrator/Coordinator**（`orchestrates software engineering tasks across
   multiple workers` 变体）——多 worker 编排形态（`claude --bg` 后台会话 +
   workers/peers 体系，见 09 子代理文档）。

另有云侧姊妹产品线（内嵌文档实证 [D]）：**Managed Agents API**（服务端托管
agent：environments/memory stores/multiagent sessions/scheduled deployments/webhooks）
——CLI 是其本地对等物。

## 5. 五个"一页纸"结论

1. **核心极小、外围极大**：agent loop 本体 ~60 行概念代码；215MB 里 99% 是 Bun
   运行时、工业级安全网、UI、生态适配。（mini-claude 用 420 行复刻了核心 [S]）
2. **上下文窗口是一等公民**：所有系统（file-state 跟踪、autocompact、子代理
   隔离、WebFetch 小模型提炼）都在服务"窗口内信息的信噪比"。
3. **双 hooks 体系并存** [S]：shell 命令式 hooks（PreToolUse 等 12 事件）+
   function hooks 插件（JS 模块 + `register(on,options)` + `$.tool.call` 事件
   API + JSX UI 组件）——后者是插件市场生态的技术底座。
4. **文档内嵌** [D]：103 个 zstd 文档（API 手册/Managed Agents 全系列/eval
   指南/成本优化）随二进制分发，供 `claude-api` 等 skill 离线查询——agent 的
   知识不都在模型里，也在随包文档里。
5. **反馈回路完备** [S]：/bug、thumbs、SendFeedback 工具、遥测事件——产品级
   agent 的数据飞轮埋点齐全（详见 13-遥测与反馈文档）。
