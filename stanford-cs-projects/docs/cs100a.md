---

## 📚 定位

CS100A 是 CS106A 的 **1 单元配套解题 Lab**，面向编程初学者。通过额外的手把手练习，强化 CS106A 的核心编程思维，重点用 **Karel the Robot** 训练控制流、分解与逐步求精。

---

## 🎯 学习目标

1. 把抽象问题**分解**为可执行的小步骤
2. 熟练掌握 `while` / `for` / `if` 控制流
3. 学会用函数封装重复行为（逐步求精）
4. 建立"先想清楚再写代码"的工程直觉

---

## 📅 核心模块

1. **Karel 基本动作**：`move()` / `turnLeft()` / `pickBeeper()` / `putBeeper()`
2. **走到墙**：循环 + 边界检测（`frontIsClear()`）
3. **爬楼梯**：嵌套循环 + 复合动作
4. **棋盘放 beeper**：交替模式 + 条件判断
5. **走迷宫**：右手定则（right-hand rule）
6. **收集并排序 beeper**：状态管理 + 计数
7. **递归入门**：分形/简单回溯
