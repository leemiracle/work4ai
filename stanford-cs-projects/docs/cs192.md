# CS192 Programming Service Project

> Stanford University | 3-5 单元 / 学期 | 本科公益项目
> Type: **社区 / 非营利服务项目**
> Prerequisites: CS106B 或同等基础
> Difficulty: ⭐⭐⭐ (技术中等,但沟通 / 需求工程挑战大)

---

## 📚 定位

**Stanford CS 的"技术服务社会"课**。学生组队为**本地非营利组织 / 公益机构 / 学校**免费开发软件——典型项目包括:教育工具、医疗信息平台、社区资源目录、无障碍应用等。

是 Stanford **工程伦理教育**和 **CS+Social Good** 文化的具体载体。培养的不是"硅谷工程师",而是"有社会影响力的工程师"。

---

## 🎯 适用人群(什么时候选)

- 想用技术做点**有意义但不在简历头条**的事
- 对**产品管理 / 用户研究 / 公益科技**有兴趣
- 想训练**与真实客户(非工程师)沟通**的能力
- 想申请 **Rhodes / Truman / 公益类 fellowship** 的同学

---

## 📋 典型流程

1. **第 1-2 周**: 项目匹配 — 与本地 NPO (non-profit org) 配对
2. **第 3 周**: 现场访问客户,做**需求调研** (requirement gathering)
3. **第 4-6 周**: 与客户迭代设计原型,定期反馈
4. **第 7-9 周**: 开发 + 用户测试
5. **第 10 周**: **部署 + 培训客户使用** + 交接文档

**与 CS191 的核心区别**:
- CS191: 学生选自己喜欢的题目
- CS192: **客户(非工程师)的需求**,你要听懂并转化

---

## 💡 选课建议

### 选 CS192 的典型理由
1. **训练需求工程** — 比 CS191 难 10 倍的部分,因为客户说"我想要一个按钮"时往往根本不是这个意思
2. **真实部署压力** — 不能跑路,代码要上线给人用
3. **可持续性挑战** — 你毕业了谁来维护?这是工业界最现实的问题
4. **社会网络** — 你会认识本地 NPO / 政府机构的人脉

### 经典项目方向(历史案例)
- 给**低收入社区**做的食物银行库存系统
- 给**特殊教育学校**做的辅助沟通 App
- 给**流浪者服务机构**做的资源目录
- 给**老年人**做的健康提醒工具
- 给**残障人士**做的无障碍工具 (a11y)

### 常见坑
1. **客户不会用** — UI 没人测试,上线后没人用
2. **scope 漂移** — 客户每周改主意,学期结束做不完
3. **维护断档** — 毕业后代码没人接,客户白等一学期
