# CS103: Mathematical Foundations of Computing

> Stanford University | 本科核心 | 离散数学与理论 CS 入门
> 定位：CS 理论的第一门课，培养严格数学思维

---

## 📚 定位

CS103 是 Stanford **理论 CS 的入门课**，面向大二学生。教授离散数学、逻辑、证明技术、自动机理论，为 CS154（计算理论）和 CS161（算法）打基础。核心目标：学会**写严格数学证明**。

---

## 📅 核心模块

1. **命题逻辑与谓词逻辑**：真值表 / 蕴含 / 量化词 / 自然演绎
2. **证明技术**：直接证明 / 反证 / 数学归纳法（弱/强/结构归纳）
3. **集合论**：集合运算 / 幂集 / 基数 / 对角化（不可数性）
4. **关系与函数**：等价关系 / 偏序 / 单射满射双射
5. **图论基础**：无向/有向图 / 连通性 / 树 / 欧拉路径
6. **自动机**：DFA / NFA / 正则表达式 / 正则语言的泵引理
7. **可计算性入门**：图灵机 / 停机问题（衔接 CS154）

## 🎯 学习路径

1. **大量练习写证明**：CS103 的核心是证明能力——归纳法、反证法要练到肌肉记忆
2. **理解对角化**：Cantor 对角化证明实数不可数——这是理解停机问题的钥匙
3. **进阶**：CS103 → CS154（计算理论）→ CS161（算法设计）/ CS157（计算逻辑）
