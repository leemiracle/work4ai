# CS240: Advanced Operating Systems

> Stanford University | 研究生研讨 | 系统课链顶端
> 定位：分布式系统、虚拟化、数据中心架构

---

## 📚 定位

CS240 是 Stanford **最高阶的 OS 课**，研究生研讨形式。不写单机 OS（那是 CS140），而是读经典系统论文，理解**分布式系统、虚拟化、云计算**的设计权衡。每节课读 1-2 篇顶会论文（OSDI/SOSP/NSDI）。

---

## 📅 核心模块

1. **分布式系统基础**：RPC / 一致性 / 容错 / CAP 定理
2. **分布式存储**：GFS / Dynamo / Spanner / Bigtable
3. **分布式计算**：MapReduce / Spark / Dryad
4. **虚拟化**：VMware / Xen / 容器（Docker）
5. **云架构**：多租户 / 弹性伸缩 / 微服务
6. **一致性协议**：Paxos / Raft / 两阶段提交
7. **现代系统**：AI 训练系统（Megatron / Ray）/ serverless

## 💻 项目代码

📁 `supplementary/all_micro_projects.py::cs240_mapreduce()`

实现了 CS240 经典入门主题：**MapReduce 编程模型**（Word Count）：
- Map 阶段：文档 → (word, 1) 键值对
- Shuffle 阶段：按 key 聚合
- Reduce 阶段：求和输出词频

**运行**：
```bash
cd supplementary && python3 -c "from all_micro_projects import cs240_mapreduce; cs240_mapreduce()"
```
