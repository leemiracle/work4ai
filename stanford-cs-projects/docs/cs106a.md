## 📚 定位

CS106A 是 Stanford **最经典的入门编程课**，全校选课人数最多。用 Python（早期用 Java）教编程核心思维：抽象、分解、逐步求精。配 Karel the Robot 教机器人移动学控制流。

---

## 📅 核心模块

1. **Karel the Robot**：用机器人移动学控制流（move/turnLeft/pickBeeper）
2. **变量与表达式**：int / float / string / bool
3. **控制流**：if-else / while / for / 嵌套循环
4. **函数与分解**：自顶向下设计、参数传递、返回值
5. **数据结构**：list / dict / string 操作
6. **递归入门**：分形 / 迷宫求解
7. **图形与事件**：简单 GUI / 事件驱动编程
