# CS499P Advanced Reading and Research (Project-Oriented)

> Stanford University | 1-15 单元 | PhD / 高阶研究生
> Type: **CS499 的"项目导向"版**
> Prerequisites: PhD student / 高级 MS + faculty advisor
> Difficulty: ⭐⭐⭐⭐⭐

---

## 📚 定位

**CS499 的"工程项目版"**。CS499P 用于 PhD / 高级研究生**正式 RA 工作**中**工程导向**的部分——典型场景:
- PhD 做的**研究包含大型系统实现** (e.g. vLLM-style infra / 数据库 / OS)
- **Research Engineer** 路径 (Stanford 有 RA 职位给非 PhD)
- 与工业合作的 **R&D 项目** (Google / Meta / Anthropic 联合研究)

与 CS499 区别:CS499P 强调**软件交付** (系统 / 工具 / 框架) 而非纯论文。常见于**系统 / 编程语言 / AI infra** 方向的 PhD。

---

## 🎯 适用人群(什么时候选)

- PhD 学生研究**核心是系统 / 工具** (e.g. vLLM / Triton / TPU 编译器)
- **Research Engineer** (非 PhD 但做研究工程)
- advisor 重视 **artifact / tooling** (systems 文化)

---

## 📋 典型流程

CS499P 的"流程"是研究的工程化部分:

1. **第 1-2 周**: 与 advisor 定 project scope (目标用户 / 验收标准 / biweekly milestones)
2. **第 3-8 周**: 系统开发 — 设计 doc / 架构 review;实现 + 单元测试 + benchmark;与 paper 实验协同
3. **第 9-10 周**: 交付 + 报告 — 开源 release (GitHub);技术文档;Demo 视频;(与 CS499 协同) 论文 artifact

通常 PhD 在系统方向会**同时注册 CS499 + CS499P**:CS499 论文 / 实验部分,CS499P 系统 / 工具部分。

---

## 💡 选课建议

### 经典 CS499P 项目类型
1. **AI infra 系统**: 推理引擎 / 训练框架 / 编译器 (vLLM-style)
2. **数据库 / 系统**: 分布式系统 / 数据库内核 / OS 模块
3. **编程语言工具**: 编译器 / 静态分析 / IR framework
4. **研究工具**: 给 lab 写 experimental framework / 数据 pipeline

### CS499 vs CS499P
| 维度 | CS499 | CS499P |
|------|-------|--------|
| 输出 | 论文 / 实验 | 系统 / 工具 |
| 评估 | paper 投稿 | 开源 release + benchmark |
| 适合 | 所有 PhD | 系统 / infra 方向 |

### 常见坑
1. **混淆 CS499 / CS499P** — 与 advisor 商量清楚哪些算哪个
2. **scope 太大** — 学期 10 周做不了大系统,切 milestone
3. **没有 benchmark** — 系统 paper 没有 eval 等于没做
