# CS191W Senior Project (Writing Intensive)

> Stanford University | 3-5 单元 | 本科 capstone + WIM
> Type: **工程项目 + 强写作训练**
> Prerequisites: Senior 本科 + 满足 WIM 前置
> Difficulty: ⭐⭐⭐⭐⭐ (技术 + 写作 + 项目管理三重)

---

## 📚 定位

**CS191 的"硬核写作版"**。完成 WIM (Writing in the Major) 强制要求的路径之一。除 CS191 的工程交付外,**强制大量技术写作**——proposal / design doc / progress report / final report / 反馈修订。

适合**未来要读 PhD / 想发论文 / 想做技术写作 (DevRel / Tech Writer)**的同学。写作训练强度比 CS191 高 3-5 倍。

---

## 🎯 适用人群(什么时候选)

- **Senior 本科**,计划读研 / PhD,想训练学术写作
- 准备做 **technical writing / DevRel / 标准 / 规范**方向
- 想把 CS191 升级为"WIM 认证版"(满足学位要求)

---

## 📋 典型流程

与 CS191 相同的工程节奏,**叠加写作 deliverables**:

1. **第 1-2 周**: Project proposal (3-5 页,含 background / objectives / methodology / risks)
2. **第 3-4 周**: Design document (5-8 页,架构图 / 技术选型 / 测试计划)
3. **第 5 周**: Peer review — 同学互相批改对方的 design doc
4. **第 6-8 周**: Biweekly progress reports (1-2 页,迭代更新)
5. **第 9 周**: Final report draft (15-25 页) + 修订
6. **第 10 周**: Final report + presentation + demo

**写作评估维度**:
- 清晰度 (clarity)
- 受众适配 (audience awareness)
- 论证结构 (argument structure)
- 技术深度 (technical depth)
- 修订响应 (response to feedback)

## 💡 选课建议

### 选 CS191W 而不是 CS191 的信号
- 你想读 PhD — 写作训练对未来发论文至关重要
- 你想进**标准化组织** (W3C / IETF / TC39) 或**DevRel**
- 你已经有项目 idea 但**需要 systematize 成文档**
- 你 CS 核心课中 WIM 还没满足

### 不选 CS191W 的信号
- 你只想要一个 capstone 学分,WIM 已通过其他课满足
- 你讨厌写作,纯想做工程 — CS191 就够了
- 你时间紧 — CS191W 工作量 ≈ 1.5× CS191

### 经典项目类型
- **研究论文风格**: 接近 CS191 + mini 论文 (适合转 CS197/CS195 路径)
- **开源项目 + RFC**: 写标准 / 协议文档 (TC39 提案风格)
- **系统设计文档**: 像 Google design doc,可读性极强
