# CS191 Senior Project

> Stanford University | 3-5 单位 / 学期 | 本科毕业 capstone
> Type: **团队 / 个人大型工程项目**
> Prerequisites: 高年级本科 (Senior) + CS 核心基础课完成
> Difficulty: ⭐⭐⭐⭐ (技术 + 项目管理双考验)

---

## 📚 定位

**Stanford CS 本科的"毕业大戏"**。CS191 是高年级学生**自选主题**做一学期到一年的**实质工程项目**——可以是 App / 系统 / 工具 / 开源贡献。与 CS191W 区别:CS191 不强制写作分量,工程交付为主。

是 Stanford CS 学位 **WIM (Writing in the Major)** 要求的"二选一"路径之一(另一条是 CS191W)。

---

## 🎯 适用人群(什么时候选)

- **Senior 本科生**,准备毕业、需要一个 capstone
- 想做**工程 / 产品**方向(不是科研)
- 有意创业 / 进大厂 / 投产品经理岗的同学
- 通常 **2-4 人组队**,也可以个人

---

## 📋 典型流程

1. **第 1-2 周**: 找队友 + 找 faculty advisor (CS 系任何教授都可)
2. **第 3 周**: 提交 project proposal (1-2 页,目标 / 里程碑 / 验收标准)
3. **第 4-8 周**: 每 2 周一次 advisor check-in,持续开发
4. **第 9 周**: Mid-quarter review (advisor + 同学互评)
5. **第 10 周**: **Final Demo Day** — 公开演示 + 提交代码 / 报告 / 演示视频

**典型交付物**:
- 可运行的软件 / 系统
- 10-20 页 final report
- 10 分钟 live demo
- 公开 GitHub repo

---

## 💡 选课建议

### 什么时候选
- **Senior 秋 / 冬**: 最佳时机,留 spring 找工作 / 求研
- **跨学期版本**: 部分项目延到 2 学期,深度更足

### 选题方向(经典案例)
- **应用 / App**: iOS / Android / Web 应用
- **系统 / 工具**: 编译器 / 数据库 / OS 模块
- **AI 应用**: 基于 LLM / diffusion 的产品原型
- **开源贡献**: 给大型开源项目 (Linux / React / PyTorch) 提交 PR
- **硬件 + 软件**: 树莓派 / 机器人 / IoT

### 常见坑
1. **scope creep** — 一学期想做完 SpaceX,99% 失败。先做 MVP
2. **队友匹配** — 找"工作风格"互补的人,不只是"技术"互补
3. **advisor 不管你** — CS191 是 student-driven,要主动 push advisor
