## 📚 课程定位

**Stanford 产品管理方向的旗舰课程**，也是 CS 系中少数以 **"人际技能"（Interpersonal Skills）** 为核心的课程。与传统的技术课程不同，CS177 的核心命题是：

> "问任何产品专业人士什么定义了一个优秀的 PM，他们都会指向同一件事：**人际技能**——谈判、沟通、冲突解决、访谈等。"

课程通过 **以人为本的视角（Human-Centered Lens）** 探索产品管理，聚焦于塑造伟大产品的各种关系：从客户到同事。学生在一个学期的团队项目中，完整经历 **从问题识别到解决方案再到最终路演** 的产品全生命周期。

### Christina Wodtke 讲师

Wodtke 是 **资深产品管理实践者和教育者**：
- **工业经验**: 前 **Google** 产品经理、**Avery**（标签公司）产品总监、**LinkedIn** 高级总监
- **代表性著作**:
  - 🔴 *Radical Focus*（OKR 实战指南，全球畅销）
  - 🔴 *Information Architecture: Blueprints for the Web*
  - 🔴 *The Team That Managed Itself*（自组织团队）
- **教学风格**: 强调 **实战 > 理论**、**人际关系 > 流程工具**、**故事讲述 > 数据堆砌**
- **理念**: "PM 的工作不是做决定，而是创造让正确决定自然发生的条件"

> 与 CS147 的区别：CS147 是"怎么设计好交互"，CS177 是"怎么把一个产品从 0 到 1 做出来"。CS147 聚焦设计，CS177 聚焦商业+团队+策略。

## 🎯 学习目标

完成本课程后，学生应能：

1. **掌握** 产品管理全流程：Discovery → Synthesis → Definition → Development → Go-to-Market
2. **执行** 用户探索（Customer Discovery）：访谈技巧、竞品分析、TAM/SAM/SOM 市场评估
3. **构建** 商业模式画布（Business Model Canvas, BMC）和价值主张
4. **撰写** 用户故事（User Stories）、用户旅程图（Journey Map）、产品需求文档（PRD）
5. **设计** 产品路线图（Roadmap）和 OKR（Objectives & Key Results）
6. **分析** 产品漏斗（Funnel）和关键指标（Metrics）
7. **测试** 商业假设（Assumption Testing）：从假设到实验
8. **制定** Go-to-Market（GTM）策略
9. **路演** 向专业产品经理做 Pitch Presentation
10. **实践** 团队协作：团队规范（Team Norms）、冲突解决、同伴反馈

## 🧮 核心方法

### 用户故事（User Story）模板
```
As a [用户角色 / Persona],
I want [目标 / Goal],
so that [价值 / Benefit]
```

### Impact / Effort 优先级矩阵
```python
# 优先级评分
score = impact / max(effort, 1)

# 分类:
# - 高 Impact + 低 Effort = Quick Win（优先做）
# - 高 Impact + 高 Effort = Major Project（规划做）
# - 低 Impact + 低 Effort = Fill-in（有空做）
# - 低 Impact + 高 Effort = Thankless Task（不做）
```

### TAM / SAM / SOM 市场估算
- **TAM（总可服务市场）**: 如果所有潜在客户都购买，市场有多大
- **SAM（可服务市场）**: 你的商业模式能覆盖的市场子集
- **SOM（可获得市场）**: 你在短期内能实际获得的份额

### AARRR 海盗指标
```
Acquisition（获取）→ 用户从哪里来？
    ↓
Activation（激活）→ 用户有好的首次体验吗？
    ↓
Retention（留存）→ 用户会回来吗？
    ↓
Referral（推荐）→ 用户会推荐给朋友吗？
    ↓
Revenue（收入）→ 用户如何产生收入？
```

### OKR（Objectives & Key Results）
```
Objective: 定性的、鼓舞人心的目标
  KR1: 可量化的关键结果 1
  KR2: 可量化的关键结果 2
  KR3: 可量化的关键结果 3
```

### 商业模式画布（Business Model Canvas）
```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ Key      │ Key      │ Value    │ Customer │ Customer │
│ Partners │ Activities│ Propositions│Relationships│ Segments│
│          ├──────────┤          │          │          │
│          │ Key      │          │          │          │
│          │ Resources│          │          │          │
├──────────┴──────────┴──────────┴──────────┴──────────┤
│ Cost Structure          │ Revenue Streams             │
└─────────────────────────┴────────────────────────────┘
```

### 核心代码片段

```python
def cs177_demo():
    """HC 产品经理：用户故事 + 优先级"""
    # 用户故事
    stories = [
        ("作为一名 留学生", "我想看课程中文翻译", "以便快速理解内容"),
        ("作为一名 AI 研究员", "我想批量下载论文", "以便离线阅读"),
        ("作为一名本科生", "我想看到作业范例", "以便参考学习"),
    ]
    for persona, goal, benefit in stories:
        print(f"As {persona}, I want {goal}, so that {benefit}")

    # Impact / Effort 矩阵
    features = [("翻译", 9, 5), ("批量下载", 6, 3), ("范例", 7, 2)]
    for f, impact, effort in features:
        score = impact / max(effort, 1)
        print(f"{f}: impact={impact}, effort={effort}, score={score:.1f}")
```

## 💡 反思与批判

### 课程优势
1. **人际技能导向**的独特定位——大多数 PM 课程教工具（Jira / PRD 模板），CS177 教 **"如何与人协作"**
2. **双阶段项目设计精妙**——Phase 1（Discovery→Pitch）+ Phase 2（Test→PRD→GTM）完整覆盖产品生命周期
3. **PUSHUPS 微练习极具创意**——每次一个小型产品设计练习（Onboarding / Search / Error States），培养产品直觉
4. **ETHICS 穿插全程**——不是单独一节课讲伦理，而是在每个阶段融入伦理思考
5. **讲师团队多元**——Wodtke（OKR 专家）+ Collell（工业 PM）+ Morris（工程管理）+ 多位客座讲师
6. **双 Pitch Day 设计**——Prototype Fair（展会式）+ Presentations（路演式），模拟真实产品发布

### 潜在局限
1. **技术深度有限**——对数据分析、A/B 测试统计、SQL 等硬技能覆盖不足
2. **偏重 B2C 消费产品**——对 B2B / 企业级 PM 实践涉及较少
3. **团队项目依赖队友**——团队质量直接影响学习体验
4. **GTM 章节时间不足**——Go-to-Market 只在 Week 9 覆盖，但这是 PM 的核心技能
5. **缺少 AI 产品管理**——2025 版仅有一次 Gen AI Salesbot 讨论，但 AI PM 是当前最热方向

### 独特价值
- CS177 的最大价值在于 **"产品思维"的启蒙**——不是学工具，而是学 **"如何从用户痛点出发，系统性地产出一个解决方案"**
- **Wodtke 的实战经验**（Google / Avery / LinkedIn）让课程远离空洞理论
- **PUSHUPS 练习法**是独创的产品直觉训练方式——每天一个小练习，累积产品感觉
- **"PM 的工作是关系管理"** 这一理念颠覆了大多数人对 PM 的误解
