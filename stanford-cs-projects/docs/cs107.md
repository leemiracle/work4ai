# CS107: Computer Organization & Systems

> Stanford University | 本科核心 | CS 系系统课第一门
> 定位：从高级语言到底层硬件的桥梁

---

## 📚 定位

CS107 是 Stanford **系统课程链的基石**。从 C 语言内存模型出发，理解程序在机器上如何真正运行：内存布局、指针、系统调用、浮点数表示。衔接 CS106B（数据结构）与 CS110（操作系统）。

---

## 📅 核心模块

1. **C 语言与内存模型**：指针 / 数组 / 结构体 / 手动内存管理（malloc/free）
2. **数据表示**：整型（补码）/ 浮点数（IEEE 754）/ 字节序
3. **内存层次**：栈 / 堆 / 全局区 / 代码区
4. **汇编基础**：x86-64 指令 / 寄存器 / 调用约定
5. **高级主题**：函数指针 / 回调 / 虚函数表（C++ 底层）

## 💻 项目代码

📁 `supplementary/all_micro_projects.py::cs107_bitwise()`

实现了 CS107 经典主题：位运算与 IEEE 754 浮点数表示：
- XOR swap（不用临时变量交换）
- `float_to_bits()`：用 `struct` 查看 1.0 / 0.1 / +0.0 / -0.0 的 IEEE 754 位模式

**运行**：
```bash
cd supplementary && python3 -c "from all_micro_projects import cs107_bitwise; cs107_bitwise()"
```

**输出示例**：
```
1.0 的 IEEE 754 表示: 0x3f800000
0.1 的 IEEE 754 表示: 0x3dcccccd
-0.0: 0x80000000
```

1. **理解内存**：画栈帧图、跟踪指针——这是 CS107 最核心的技能

3. **进阶**：CS107 → CS110（操作系统）→ CS140（分布式系统）→ CS240（高级 OS）
