## 📚 课程定位

**Stanford HCI 的入门旗舰课**，也是全美最具影响力的 HCI 本科课程之一。Landay 教授将 d.school 的 **设计思维（Design Thinking）** 与计算机科学的 **工程方法（Engineering）** 完美融合，形成了独特的 "dt+UX" 教学模式。

课程核心命题：**好设计不是天赋，而是方法论**。通过一整个学期的团队设计项目，学生完整经历 **发现需求 → 定义问题 → 构思方案 → 快速原型 → 用户评估** 的设计思维五步法。

Landay 教授背景极其深厚——他是斯坦福 HCI 实验室（HCI Group）的负责人，曾任 **ISI（Information Sciences Institute）副总裁**，也是 **UC Berkeley 的教授**，共同发明了 **denim**（早期网站原型工具）和 **SILK**（UI 草图工具）。他的教学风格强调 **"Learn by Doing"**——在做中学。

> 与 CS347 的关系：CS147 是入门实践课（做项目），CS347 是研究前沿课（读论文）。两者互补。

## 🎯 学习目标

完成本课程后，学生应能：

1. **掌握** 设计思维五步法（Empathize → Define → Ideate → Prototype → Test）
2. **执行** 完整的用户研究流程：Needfinding（实地观察）→ Contextual Inquiry → 用户画像
3. **构建** 从低保真（纸面）到中保真（Figma）到高保真（可交互代码）的原型
4. **应用** Nielsen 十大启发式原则进行专家评估
5. **设计** 并执行正式的可用性测试（Usability Testing）
6. **理解** 人机认知模型（感知、注意、记忆、心智模型）
7. **制作** 概念视频（Concept Video）讲述设计故事
8. **遵循** 可访问性设计标准（WCAG）
9. **撰写** 专业的设计报告与设计模式文档

## 🧮 核心方法

### 设计思维五步法（Design Thinking）

| 步骤 | 方法 | 产出 |
|------|------|------|
| **Empathize** | Contextual Inquiry, 实地观察 | 用户洞察笔记 |
| **Define** | POV Statement, HMW Questions | 问题定义文档 |
| **Ideate** | 头脑风暴, "40 in 4 minutes" | 20+ 解决方案 |
| **Prototype** | Paper → Figma → Code | 可交互原型 |
| **Test** | Usability Testing, Heuristic Eval | 评估报告 |

### Nielsen 十大启发式原则

1. **系统状态可见性**（Visibility of system status）
2. **系统与现实世界的匹配**（Match between system and real world）
3. **用户控制与自由**（User control and freedom）
4. **一致性与标准**（Consistency and standards）
5. **错误预防**（Error prevention）
6. **识别优于回忆**（Recognition rather than recall）
7. **使用的灵活性与效率**（Flexibility and efficiency of use）
8. **美学与极简设计**（Aesthetic and minimalist design）
9. **帮助用户识别、诊断和恢复错误**（Help users recover from errors）
10. **帮助与文档**（Help and documentation）

### 可用性评估方法对比

| 方法 | 类型 | 优点 | 缺点 |
|------|------|------|------|
| **启发式评估** | 专家评估 | 快速、低成本 | 可能遗漏真实用户问题 |
| **可用性测试** | 用户测试 | 发现真实使用问题 | 需要招募用户 |
| **认知走查** | 专家评估 | 聚焦首次使用 | 耗时 |
| **A/B 测试** | 定量实验 | 统计显著 | 需要大量用户 |

# A/B 测试统计显著性（z-test）
def ab_test(a_conversions, b_conversions):
    p_pool = (sum(a) + sum(b)) / (len(a) + len(b))
    se = sqrt(p_pool * (1-p_pool) * (1/n_a + 1/n_b))
    z = (p_b - p_a) / se
    return abs(z) > 1.96  # p < 0.05

# SUS 评分（0-100，>68 可用，>80 优秀）
def sus_score(responses):
    # 奇数题: r-1, 偶数题: 5-r
    total = sum(r-1 if i%2==0 else 5-r for i, r in enumerate(responses))
    return total * 2.5

## 💡 反思与批判

### 课程优势
1. **项目驱动**的完整设计流程体验——从零到可交互原型
2. **Studio 制度**（小班辅导）提供了个性化反馈
3. **Concept Video** 环节独特——用视频讲述设计故事，培养叙事能力
4. **Project Expo** 模拟真实产品发布——评委包括业界专家
5. Landay 教授的 **"Get the design right, then get the right design"** 哲学深入人心

### 潜在局限
1. **偏重 Web/App 设计**——较少涉及 AR/VR/Voice 等新兴交互模式
2. **设计思维可能过度流程化**——不是所有问题都适合 DT 五步法
3. **团队项目依赖队友质量**——4-5 人团队中总有人搭便车
4. **技术深度有限**——高保真原型主要用 React/Vue，但教学不深入
5. **评估方法偏定性**——A/B 测试和定量分析涉及较少

### 独特价值
- CS147 的最大价值不在于教某个具体技能，而在于培养 **"设计思维"的思维方式**——永远从用户出发，先发散后收敛，快速迭代
- **IDEO Deep Dive 视频** 是 HCI 教育史上的经典，值得反复观看
