# CS242: Programming Languages

> Stanford University | 本科高阶 | 编程语言理论与实现
> 定位：理解编程语言的设计原理与类型系统

---

## 📚 定位

CS242 是 Stanford **编程语言理论**核心课。探索编程语言为什么这样设计：类型系统、lambda calculus、函数式编程、形式语义。衔接 CS143（编译器）与 CS243（程序分析）。

---

## 📅 核心模块

1. **Lambda Calculus**：Church numerals / Y combinator / 计算的数学基础
2. **类型系统**：静态 vs 动态 / Hindley-Milner / 类型推断
3. **函数式编程**：不可变性 / 高阶函数 / 惰性求值 / monad
4. **语义**：操作语义 / 指称语义 / 公理语义（Hoare 逻辑）
5. **OOP 理论**：子类型 / 多态 / 协变逆变
6. **并发模型**：actor model / CSP / 软件事务内存（STM）
