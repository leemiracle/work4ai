---

## 📚 定位

CS154 是 Stanford **理论计算机科学**的核心课。回答两个根本问题：（1）哪些问题计算机**能**解决？（可计算性）（2）哪些问题计算机**能高效**解决？（复杂性）。是 CS161（算法）的理论根基。

---

## 📅 核心模块

1. **有限自动机**：DFA / NFA / 正则表达式 / 正则语言性质
2. **下推自动机**：PDA / 上下文无关文法（CFG）/ 解析
3. **图灵机**：图灵机模型 / 通用性 / Church-Turing 论题
4. **可计算性**：停机问题 / 归约 / Rice 定理 / 不可判定性
5. **复杂性类**：P / NP / NP-完全 / PSPACE / EXP
6. **归约**：多项式归约 / Cook-Levin 定理 / SAT 是 NP-完全
