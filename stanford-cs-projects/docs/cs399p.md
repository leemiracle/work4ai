# CS399P Independent Project (Project-Oriented)

> Stanford University | 1-10 单元 | 研究生独立项目
> Type: **CS399 的"项目导向"版**
> Prerequisites: 找到 faculty advisor
> Difficulty: ⭐⭐⭐ - ⭐⭐⭐⭐⭐

---

## 📚 定位

**研究生版的"CS199P"**。CS399P 是 Stanford CS 研究生用于**实质性工程项目**的注册入口——典型场景:
- 与某 lab 合作开发**研究工具 / 框架**
- 给**开源项目**做 substantial 贡献 (作为独立学习)
- **个人 / 小团队工程项目** (App / 系统 / infra)
- 工业合作 R&D 项目

与 CS399 区别:CS399P 更强调**工程交付**,而非纯论文 / 自学。

---

## 🎯 适用人群(什么时候选)

- MS / Engineer 学生想做**工程项目** (而非纯研究)
- 想与 lab 合作开发**工具** (常见于 research engineer 路径)
- 想把**side project**正式化为学分
- 准备**工业就业** (简历项目)

---

## 📋 典型流程

1. **第 1 周**: Project proposal (2-3 页):
   - 目标 / 用户场景
   - 技术栈 / 架构
   - biweekly milestones
   - 验收标准
2. **第 2-9 周**: 敏捷开发:
   - 每 1-2 周 advisor review
   - GitHub repo (含 README / tests / CI)
   - Design doc + changelog
3. **第 10 周**: 最终交付:
   - 可运行软件 + 部署
   - 技术文档 (10-20 页)
   - Demo
   - (可选) 开源发布 / blog post

---

## 💡 选课建议

### 经典 CS399P 项目类型
1. **研究工具开发**: 给教授 lab 写实验框架 / pipeline;给开源项目 (PyG / HF / vLLM) 提 feature
2. **工业合作 R&D**: 与公司 (Google / Meta / Anthropic) 合作项目
3. **系统 / infra 工程**: mini DB / 编译器 / OS 模块 / 推理引擎
4. **个人作品集**: SaaS MVP / AI 应用 / 开发者工具

### CS399P vs CS399
| 维度 | CS399P | CS399 |
|------|--------|-------|
| 主题 | 工程 / 项目 | 任意 (含研究 / 学习) |
| Deliverable | 软件 + 文档 | 灵活 |

### 常见坑
1. **个人项目缺乏外部驱动** — 找 sponsor 时定好 review 节奏
2. **scope creep** — 学期 10 周做不了大系统
3. **没有用户** — 找真实用户提前验证
