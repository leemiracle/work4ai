# CS183E: Effective Leadership

> Stanford University, Autumn 2026
> 领域: 领导力 / 管理学
> Prerequisites: 无（面向高年级本科 / 研究生）
> Units: 3-4
> Difficulty: ⭐⭐

---

## 📚 定位

为技术背景学生设计的领导力课——从 OKR 到 Radical Candor，用框架驱动团队高效协作。

---

## 🎯 学习目标

- 掌握主流领导力框架与适用场景
- 理解 OKR 目标管理体系
- 能进行有效的 1:1 与反馈对话
- 发展个人领导风格

---

## 📅 核心模块

### Module 1: 领导力理论谱系
- 特质论 vs 行为论 vs 情境论
- 从管理者到领导者
- 服务型领导（Servant Leadership）

### Module 2: 目标管理（OKR）
- Andy Grove / John Doerr 的 OKR 体系
- Objective（方向）+ Key Results（度量）
- 季度规划与对齐
- OKR vs KPI

### Module 3: 反馈与沟通
- Radical Candor（Kim Scott）
- 非暴力沟通（NVC）
- 1:1 会议的艺术
- 困难对话框架

### Module 4: 团队建设
- 心理安全感（Amy Edmondson）
- Tuckman 团队发展阶段
- 招聘与文化塑造
- 冲突管理

### Module 5: 战略与决策
- 情境领导（Hersey-Blanchard）
- 决策框架（RAPID / DACI）
- 愿景传达与变革管理
- 危机领导
