# CS109: Probability for Computer Scientists

> Stanford University | 本科核心 | AI/ML 的数学基础
> 定位：概率论在 CS 场景的应用，CS229/CS231N 的前置

---

## 📚 定位

CS109 是 Stanford **概率论核心课**，专为 CS 学生设计。不讲纯数学证明，聚焦概率在算法、ML、系统中的应用。是 CS229（机器学习）、CS231N（深度学习）、CS228（概率图模型）的数学基础。

---

## 📅 核心模块

1. **概率基础**：样本空间 / 事件 / 条件概率 / 独立性
2. **贝叶斯定理**：后验概率 / 先验 / 似然（核心！）
3. **随机变量**：离散（Bernoulli/Binomial/Poisson）/ 连续（Uniform/Normal/Exponential）
4. **期望与方差**：线性性 / 方差分解
5. **联合分布与协方差**：相关 vs 独立
6. **极限定理**：大数定律 / 中心极限定理
7. **应用**：朴素贝叶斯分类 / PageRank / MLE / 蒙特卡洛
