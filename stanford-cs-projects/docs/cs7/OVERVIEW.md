# CS7: Personal Finance for Engineers

> Stanford University, Autumn 2026
> 领域: 个人理财 / 通识
> Prerequisites: 无
> Units: 1
> Difficulty: ⭐

---

## 📚 定位

为工科生设计的实用理财课——复利、投资、税务、保险，用数据思维管理个人财务。

---

## 🎯 学习目标

- 理解复利的力量与时间价值
- 掌握投资基础（股票、债券、指数基金）
- 理解税务优化策略
- 能制定个人财务计划

---

## 📅 核心模块

### Module 1: 财务基础
- 收入 / 支出 / 储蓄率
- 复利的力量（72 法则）
- 通货膨胀的侵蚀

### Module 2: 投资入门
- 资产类别：股票 / 债券 / 房产 / 现金
- 指数基金与 ETF
- 风险与收益的权衡
- 资产配置与再平衡

### Module 3: 退休与长期规划
- 401(k) / IRA / Roth IRA
- FIRE 运动（Financial Independence）
- 提款率（4% 法则）

### Module 4: 税务优化
- 资本利得税（短期 vs 长期）
- 税收优惠账户
- 慈善捐赠策略

### Module 5: 保险与风险管理
- 健康 / 寿险 / 残疾险
- 伞形保险
- 应急基金

## 📊 关键概念

| 概念 | 说明 |
|------|------|
| **复利** | 世界第八大奇迹（爱因斯坦） |
| **72 法则** | 72 ÷ 利率 ≈ 翻倍年数 |
| **指数基金** | 低成本、分散、长期最优 |
| **4% 法则** | 退休安全提款率 |
| **资产配置** | 风险分散的核心策略 |
