# CS106M: Enrichment Adventures in Programming

> Stanford University, Autumn 2026
> 领域: 算法进阶 / 编程拓展
> Prerequisites: CS106B（同步修读）
> Units: 1-2
> Difficulty: ⭐⭐⭐

---

## 📚 定位

CS106B 的荣誉拓展——为学有余力的学生提供更深的算法挑战，从回溯到动态规划的经典进阶。

---

## 🎯 学习目标

- 深入掌握经典算法范式（回溯、DP、贪心、图）
- 能解决中等难度的算法竞赛题
- 理解算法复杂度与优化策略
- 培养严谨的算法思维

---

## 📅 核心模块

### Module 1: 回溯算法
- 八皇后问题
- 数独求解器
- 子集 / 排列生成
- 剪枝优化

### Module 2: 动态规划
- 一维 DP（背包、LIS）
- 二维 DP（LCS、编辑距离）
- 区间 DP（矩阵链乘法）
- 状态压缩 DP

### Module 3: 贪心算法
- 活动选择问题
- Huffman 编码
- 最小生成树（Kruskal / Prim）
- 贪心的正确性证明

### Module 4: 图算法
- DFS / BFS 与连通分量
- 最短路径（Dijkstra / Bellman-Ford）
- 拓扑排序
- 网络流入门

### Module 5: 字符串算法
- KMP 模式匹配
- Rabin-Karp 哈希
- 后缀数组
- 正则表达式引擎
