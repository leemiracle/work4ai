---

## 📚 定位

CS109A 是 CS109 的 **1 单元配套解题 Lab**。CS109 讲概率论在 CS 中的应用；CS109A 用**蒙特卡洛模拟**把抽象的概率公式变成可看见的实验，帮助学生建立概率直觉，攻克贝叶斯定理等"反直觉"难点。

---

## 🎯 学习目标

1. 用蒙特卡洛模拟**验证**手算的概率答案
2. 直观理解贝叶斯定理（先验如何影响后验）
3. 用模拟体会大数定律与中心极限定理
4. 培养对"概率陷阱"的警惕（赌徒谬误 / 条件概率）

---

## 📅 核心模块

1. **蒙特卡洛基础**：用大数定律近似概率（投点法 / 重复试验）
2. **贝叶斯直觉**：罕见病阳性案例（阳性 ≠ 真患病）
3. **随机变量**：Bernoulli / Binomial / Poisson / Normal 分布模拟
4. **期望与方差**：用样本均值 / 样本方差验证理论值
5. **极限定理**：可视化 CLT（样本均值趋近正态）
6. **应用**：朴素贝叶斯分类 / PageRank / MLE
