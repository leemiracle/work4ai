# CS259Q: Quantum Computing

> Stanford University | 本科高阶 | 量子计算理论入门
> 定位：量子比特、量子算法与量子优越性

---

## 📚 定位

CS259Q 是 Stanford **量子计算入门课**。从量子力学基本公设出发，建立量子计算的形式化框架，学习经典量子算法（Shor / Grover），讨论量子优越性与量子纠错。

---

## 📅 核心模块

1. **量子比特（Qubit）**：叠加态 α|0⟩ + β|1⟩、布洛赫球
2. **量子门**：Hadamard / Pauli / CNOT / 通用量子门集
3. **量子纠缠**：Bell 态 / EPR 悖论 / 非局域性
4. **量子算法**：
   - **Deutsch-Jozsa**：量子并行性首次展示
   - **Grover 搜索**：O(√N) 无结构搜索加速
   - **Shor 因式分解**：多项式时间分解 → 威胁 RSA
5. **量子测量**：塌缩 / 不可克隆定理
6. **量子纠错**：Shor 码 / 表面码

## 💻 项目代码

📁 `supplementary/all_micro_projects.py::cs259q_quantum_superposition()`

- 单量子比特 α|0⟩ + β|1⟩ 表示
- 测量模拟（按 |α|² 概率得 0）
- |+⟩ = (|0⟩ + |1⟩)/√2 态的 1000 次测量
- Hadamard 门 H|0⟩ = |+⟩

**运行**：
```bash
cd supplementary && python3 -c "from all_micro_projects import cs259q_quantum_superposition; cs259q_quantum_superposition()"
```

