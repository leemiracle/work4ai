# CS100B: Problem-Solving Lab for CS106B

> Stanford University | 1 单元 | CS106B 配套解题 Lab
> Instructor: CS106B Section Leader 团队
> 先修: CS106A（或同等编程基础）
> 同修: CS106B（数据结构与抽象）
> 定位: 用数据结构练习强化递归、回溯与 STL 容器

---

## 📚 定位

CS100B 是 CS106B 的 **1 单元配套解题 Lab**。CS106B 讲授递归、回溯、树、图、哈希表等核心数据结构与算法；CS100B 提供额外的**动手练习**，帮助学生把这些抽象结构用 C++（早期）或 Python 实现并调试。

---

## 🎯 学习目标

1. 熟练实现递归与回溯（八皇后、数独、排列组合）
2. 理解并使用容器（vector / map / set / stack / queue）
3. 掌握经典算法模式（DFS / BFS / 贪心 / 动态规划入门）
4. 提升 C++ 调试与 STL 使用能力

---

## 📅 核心模块

1. **递归基础**：factorial / Fibonacci / 分形递归
2. **回溯**：八皇后 / 数独求解 / 子集枚举
3. **动态规划入门**：背包 / LCS / 编辑距离
4. **贪心算法**：活动选择 / Huffman 编码
5. **图算法**：DFS / BFS / Dijkstra 最短路
6. **字符串算法**：KMP / Rabin-Karp 模式匹配
7. **STL 实战**：迭代器 / lambda / 模板初步
