## 📚 定位

CS111A 是 CS111 的 **1 单元配套解题 Lab**。CS111 讲进程、并发、内存、文件系统等 OS 核心抽象；CS111A 用 `strace` 等工具**观察程序与内核的真实交互**，让"系统调用"从课本概念变成可追踪的运行时行为。

---

## 🎯 学习目标

1. 用 `strace` 追踪程序的**系统调用序列**
2. 理解 fork / exec / wait / signal 的工作机制
3. 用 `ltrace` 观察库函数调用
4. 把 OS 抽象（进程 / 文件 / 信号）与底层行为对应起来

---

## 📅 核心模块

1. **strace 入门**：`strace -e trace=read,write ./program`
2. **进程系统调用**：`fork()` / `execve()` / `wait()` / `exit()`
3. **文件 I/O**：`open` / `read` / `write` / `close` / `lseek`
4. **内存系统调用**：`mmap` / `brk` / `munmap`
5. **信号机制**：`kill` / `sigaction` / `sigprocmask`
6. **网络编程**：`socket` / `bind` / `listen` / `accept` / `connect`
