# CS265: Randomized Algorithms

> Stanford University | 研究生 | 算法理论高阶
> 定位：用随机性设计更快更简单的算法

---

## 📚 定位

CS265 是 Stanford **随机化算法**核心课。探索随机性如何成为算法设计的强大工具：用随机选择获得期望高效、用概率分析证明正确性。覆盖哈希、数据流、图算法、近似算法中的随机化技术。

---

## 📅 核心模块

1. **随机化基础**：Las Vegas（总对，期望快）vs Monte Carlo（可能错，总快）
2. **随机化快速排序/选择**：QuickSelect 期望 O(n) 找第 k 大
3. **哈希与指纹**：Universal hashing / 布隆过滤器 / Rabin-Karp
4. **数据流算法**：Count-Min Sketch / HyperLogLog / reservoir sampling
5. **随机图算法**：最小割随机化（Karger）/ 随机游走
6. **随机舍入**：LP relaxation + 随机化 → 近似算法
7. **概率工具**：马尔可夫 / 切尔诺夫界 / 耦合
