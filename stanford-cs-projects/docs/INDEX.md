## 🔍 快速查找

```
docs/
├── INDEX.md            ← 你在这里
├── cs329z/             ← 5 个文件（OVERVIEW + HW1A/HW1B/HW2/HW3）
├── cs{课程号}/OVERVIEW.md   ← 每门课一个目录 + OVERVIEW
├── cs{课程号}.md            ← 简洁文档（.md 在 docs/ 根目录）
```

**按主题浏览**：从上表的分类开始
**按课号查找**：`Ctrl+F` 搜 "CS" + 课号
**按代码查找**：每门课的文档里都有 "💻 项目代码" 部分
