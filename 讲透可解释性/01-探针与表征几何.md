## 直觉层

### 一个具体时刻

> 2022 年 11 月，Kevin Meng 在 MIT 推开 ROME 论文（"Locating and Editing Factual Associations in GPT"）预印本的瞬间。他做了件以前没人做成的事：**给 GPT 的某个具体层做了开颅手术**，把"埃菲尔铁塔在巴黎"改成"在罗马"——模型真的就答"罗马"了。
>
> ROME 的关键不是改权重，而是先**用探针定位**：到底哪一层、哪个 MLP 模块存了"埃菲尔铁塔 → 巴黎"这件事。结论是**中间层的某个 MLP**，而不是输出层。

**角色**：Meng（研究者）。**冲突**：以前所有"编辑知识"的方法都在乱改一通——几千个权重一起动，模型直接坏掉。**时刻**：用 ROME 改一个向量矩阵，模型只对这一个事实改口、其他能力不变。

### Probing 的根本问题

探针问的是：**模型的中间层激活里，到底编码了哪些属性？**

- 给 BERT 第 8 层喂 10000 个句子，每个句子标注"主语是谁"。
- 训一个**线性分类器**（logistic regression）：`hidden_state → 主语`。
- 如果分类器准确率高，说明**第 8 层"知道"主语这个属性**。

这就是 probing 的全部内核。看起来朴素，但 2018-2020 几乎所有关于 BERT 内部的认知都来自它（Tenney 2019 发现 BERT 的层构成"传统 NLP pipeline"：底层 POS、中层 dependency、顶层 NER）。

### 表征几何：把激活当作空间里的点

探针之上更深一步——**把所有激活看作高维空间里的点，研究它们的几何**。2020 年起研究者发现：

- **Anisotropy（各向异性）**：BERT 的激活不是均匀分布在球面上，而是挤在**一个窄窄的锥体**里。这导致 cosine similarity 全局偏高、表征退化。
- **Centering（中心化）**：把所有激活减去均值后，几何结构才显形——很多论文不写这一步就得出错误结论。
- **Tree-like structure**：句子的表征空间近似一棵**句法树**的几何嵌入。

## 数学层

### 线性探针 = logistic regression

给定模型中间层激活 $h \in \mathbb{R}^d$ 和属性标签 $y \in \{1, ..., K\}$，线性探针是：

$$\hat{y} = \arg\max_k \; W_k^\top h + b_k$$

训练目标（交叉熵）：

$$\mathcal{L}_{\text{probe}} = -\sum_i \log \frac{\exp(W_{y_i}^\top h_i + b_{y_i})}{\sum_k \exp(W_k^\top h_i + b_k)}$$

**关键**：只训 $W, b$，**模型权重冻结**。探针测的是"激活里**线性可分**的信息量"。

### 探针的控制变量

| 设计选择 | 测的是 |
|---|---|
| 线性 vs 非线性探针 | 信息是**线性可分**还是需要非线性 |
| 任意层数 vs 固定单层（selectivity）| 模型是真的"用了"还是只是冗余编码 |
| 控制 baseline（baseline accuracy）| 高 acc 是真有信息还是任务太简单 |

Hewitt & Liang 2019 提出 **selectivity**：探针不能太强——5 层 MLP 探针几乎能记住任意标签，等于没测。**只有线性探针高 acc 才有意义**。

### ROME 的秩-1 编辑

ROME 假设 GPT 把一个事实 $(s, r, o)$（主体、关系、客体，例如 (埃菲尔铁塔, 在, 巴黎)）存在中间层某个 MLP 的 **key-value 矩阵**里：

$$\text{MLP}(x) = W_{\text{down}} \; \sigma(W_{\text{up}} x) \approx W_{\text{down}} (k^* v^{*\top})$$

ROME 想把 $(s, r, o) \to (s, r, o')$，等价于找一个新矩阵 $\hat{W}$ 满足：

$$\hat{W} = \arg\min_W \| W - W_0 \|^2 \;\;\text{s.t.}\;\; W k^* \approx v'$$

闭式解（最小二乘 + 残差保留）：

$$\hat{W} = W_0 + \frac{(v' - W_0 k^*) k^{*\top}}{k^{*\top} C^{-1} k^*} C^{-1}$$

其中 $C = \mathbb{E}[k k^\top]$ 是 key 的协方差。**只改一个秩-1 的更新**——其他事实几乎不动。

### 表征几何：各向异性的形式定义

激活 $h$ 的协方差矩阵 $C = \mathbb{E}[h h^\top]$ 的特征值谱 $\{\lambda_1 \geq \lambda_2 \geq ...\}$，各向异性定义为：

$$\text{anisotropy}(h) = 1 - \frac{\text{有效秩}(C)}{d}$$

BERT 顶层各向异性常达 0.9 以上——**信息挤在一个低维子空间里**，cosine 全局偏高。

## 代码层

```python
import torch
import torch.nn as nn
from transformer_lens import HookedTransformer

# 加载 GPT-2 small
model = HookedTransformer.from_pretrained("gpt2-small")

# 取某层在某 prompt 上的残差激活
def get_residual(prompt: str, layer: int) -> torch.Tensor:
    _, cache = model.run_with_cache(prompt)
    # [1, seq, d_model] → 取最后一个 token
    return cache["resid_post", layer][0, -1]  # [d_model]

# 训练线性探针：从激活预测某属性
class LinearProbe(nn.Module):
    def __init__(self, d_model: int, n_labels: int):
        super().__init__()
        self.W = nn.Linear(d_model, n_labels)

    def forward(self, h):
        return self.W(h)

# 简化训练循环
def train_probe(probe, hidden_states, labels, epochs=50, lr=1e-2):
    opt = torch.optim.Adam(probe.parameters(), lr=lr)
    loss_fn = nn.CrossEntropyLoss()
    for _ in range(epochs):
        opt.zero_grad()
        loss = loss_fn(probe(hidden_states), labels)
        loss.backward()
        opt.step()
    return probe

# 测各向异性
def anisotropy(hidden_states: torch.Tensor) -> float:
    # hidden_states: [N, d]
    C = hidden_states.T @ hidden_states / hidden_states.shape[0]
    eigvals = torch.linalg.eigvalsh(C)
    effective_rank = (eigvals.sum() ** 2) / (eigvals ** 2).sum()  # = exp(entropy)
    return 1 - effective_rank / hidden_states.shape[1]

# ROME 风格的秩-1 编辑（伪代码）
def rome_edit(W0: torch.Tensor, k_star: torch.Tensor, v_prime: torch.Tensor, C: torch.Tensor):
    """把 W0 改成能输出 v_prime 的版本，只做秩-1 更新"""
    C_inv = torch.linalg.inv(C)
    delta = (v_prime - W0 @ k_star).outer(C_inv @ k_star) / (k_star @ C_inv @ k_star)
    return W0 + delta
```

**反直觉数字**：BERT 顶层各向异性常 > 0.95，但**模型能力不弱**——因为高维空间即使退到 10% 子空间仍有几百维可用。各向异性不是 bug 而是结构。

## 不足层

- **已证明**：
  - 线性探针的 acc 严格测度"激活中线性可分的信息量"（Hewitt & Liang 2019 给出了 selectivity 的形式化）。
  - ROME 在 GPT-2 small/medium/XL 上**对单事实编辑有效**，且不破坏其他能力（Meng 2022 论文实验数据）。

- **经验**：
  - 探针发现的属性**不一定被模型实际使用**——"信息存在"≠"被使用"（这是 probing 的根本争议）。
  - ROME 对**深层语义关系**（不只是 (s, r, o) 三元组）效果差，对 GPT-4 级别模型未验证。
  - 各向异性在不同模型族表现不同（GPT-2 vs BERT vs LLaMA）——不是普适规律。

- **未解**：
  1. **"信息 ≠ 使用"的形式化判据**：怎么从"探针能预测"上升到"模型实际计算时用了这个信息"？目前只有 intervention（因果干预）能部分回答。
  2. **表征几何与能力的因果关系**：各向异性 → 模型能力下降，是因果还是相关？没有结论。
  3. **大模型上 ROME 能 scale 吗**？GPT-4 级别的 MLP 维度是 12288，秩-1 更新是否还能精准定位单一事实？未验证。

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我一开始把 ROME 写成"修改注意力权重"——重读原论文后发现 ROME 改的是 **MLP 的 down 矩阵**，不是 attention。修正：事实知识主要存在 **MLP** 里（这是 Geva 2021 "Transformer Feed-Forward Layers Are Key-Value Memories" 的结论，ROME 站在它之上）。
- **F3 术语翻译**：
  - "linear probe" → 在模型中间层接一个小分类器，问"这层激活能不能线性分出某个属性"。
  - "anisotropy" → 所有激活挤在空间的一个窄角里，不是均匀铺开。
  - "selectivity" → 探针本身不能太聪明（不能上 5 层 MLP），不然任何标签都能记住，等于没测。
- **F4 回炉**：v1 把探针写成"测模型知不知道 X"——但严格说探针测的是"**线性可分的、selective 的信息**"。v2 强制加上 selectivity 和"信息≠使用"两个限定。
