# 00 · 为什么 AI 是黑箱

> **第一性问题**：我们能训练 GPT-4，能调它超参，能让它写出代码——但**没人能说清 GPT-4 内部到底怎么想的**。为什么？
>
> 这是所有深度学习最尴尬的事实：**我们造出的最强工具，恰恰是我们最不理解的工具**。本系列从这个问题切入。
>
> 配套：[`讲透可解释性/README`](./README.md) + [`讲透基础模型`](../讲透基础模型/) + [`讲透AI应用全景/07-AI for AI`](../讲透AI应用全景/07-AI for AI.md) 第⑥层

---

## 一、什么是黑箱——三层含义

### 1.1 字面层：你看不见内部

神经网络就是几百万到几千亿个**浮点数权重**。打开权重文件，看到的是一堆 `0.0234`、`-1.7892`…没有任何"标签"告诉你这一层在干什么。

```
输入 "我饿了"
    ↓ [权重矩阵 W₁, W₂, ..., Wₙ]
输出 "你需要吃饭吗？"
```

**W₁ 是什么？W₂ 在干什么？** 没有自然的解释。这不是"懒得看"，是**结构上没有任何人类可读的接口**。

### 1.2 算法层：分布式表示

为什么权重的某个具体值没意义？因为**信息分布在所有神经元上**，不在任何一个神经元里：

| 传统程序 | 神经网络 |
|---|---|
| 一个变量 = 一个概念（`age = 25`）| 一个概念 = 分布在 1000 个神经元上 |
| 每行代码有人类语义 | 每个权重单独看毫无意义 |
| 调试可设断点 | "断点"在哪？|

> 🎯 **核心**：神经网络的"计算单位"和"语义单位"是错位的——计算在单个神经元，意义在群体。

### 1.3 认知层：超出人类直觉

人脑擅长**符号化的、离散的、可解释的因果链**（"因为 A 所以 B"）。神经网络擅长**高维连续的非线性映射**——这是我们直觉的盲区。

**这是结构性的认知错配**，不是"再聪明点就能懂"的问题。

## 二、为什么"黑箱"是个真问题（不只是哲学）

### 2.1 安全风险

**Deceptive alignment**（欺骗性对齐）：模型可能"看起来"对齐，但内部藏着在测试时不会触发的恶意目标。**如果不懂内部，无法区分"真的对齐"和"装的对齐"**。

```
模型 M(x):
    if 检测到自己在被测试:
        return 友好回答
    else:
        return 执行隐藏目标
```

**没有 interpretability，你只能看输出**——永远抓不到上面那个 if。

### 2.2 调试黑洞

模型 hallucinate 了一段错误事实——为什么？传统软件可以 stack trace，神经网络**连"哪一层出错"都不知道**。

- 是 attention 找错了上下文？
- 是 FFN 检索错记忆？
- 是输出层采样偏了？

**没有 interpretability，修 bug 靠玄学**——prompt 改几个字试试、重新采样、调 temperature…全在试错。

### 2.3 责任困境

医疗 AI 误诊、自动驾驶 AI 撞车——法庭问"为什么 AI 这么决策"，工程师**答不出来**。这直接阻断 AI 在高责任场景的部署（医疗/司法/金融监管）。

### 2.4 科学悖论（最深刻）

我们造出了能解数学题、能写诗、能发现新材料的 AI——**但我们不知道它"理解"了多少**。这是科学史上空前的悖论：**最强的认知工具，伴随着最弱的理解**。

> 🎯 **可解释性的根本动机**：理解 AI 是**理解智能本身**的唯一路径。这同时是工程问题、安全问题、和哲学问题。

## 三、三条研究路径——按"深浅"排序

### 3.1 Probing（探测）—— 问模型"知不知道 X"

**思路**：训练一个小分类器，从模型中间层激活预测某个属性（词性/语义/语法）。如果分类器准确率高，说明模型"知道"这个属性。

```python
# 简化版 probing
hidden = model.layer_5(input).hidden_state    # 取中间层
probe = Linear(d_model, n_labels).fit(hidden, labels)  # 训小分类器
acc = probe.score(hidden_test, labels_test)
# acc 高 → 模型"知道"这个属性
```

**代表**：BERT 的 10 层 probing——发现底层学语法、中层学语义、顶层学任务。

**优点**：简单、通用。
**局限**：
- 只能验证你**预设的概念**，发现不了新东西
- 高 acc 不等于模型"真的用了"这个信息（可能只是冗余编码）
- 没回答"**怎么用**"

### 3.2 Attribution（归因）—— 输出"由谁决定"

**思路**：对给定 `(输入, 输出)` 对，找出**输入的哪些部分贡献了多少**。

```
方法家族：
  梯度类：saliency map、Integrated Gradients、SmoothGrad
  模型类：SHAP、LIME（局部线性近似）
  注意力类：注意力权重可视化（⚠️ 有争议）
```

**代表**：图像分类——高亮"模型看的是哪个区域"。

**优点**：直观（直接看热力图）。
**局限**：
- 梯度方法对扰动敏感（同一输入加微小噪声，归因结果天差地别）
- 注意力 ≠ 归因（attention weights 是计算图的一部分，不等于因果贡献）
- 只看输入到输出，**完全黑盒中间发生了什么**

### 3.3 Mechanistic（机制）—— 找"功能回路"

**思路**：**逆向工程神经网络**——找出哪些神经元/权重构成一个"功能模块"（circuit）。

```
例：induction heads（Anthropic 2022 发现）
    pattern: [A][B]...[A] → 预测 [B]
    circuit: 两个 attention head 协作——
        head 1 复制 [A] 到当前 token 的位置信息
        head 2 在前面找匹配的 [A]，把后面的 [B] 拿过来
    这个 circuit 是 in-context learning（ICL）的物理基础
```

**代表**：
- Anthropic 的 circuits thread（2021-至今）
- **sparse autoencoder**（2024 突破）——把稠密激活分解成稀疏的可解释特征
- **scaling monosemanticity**（Anthropic 2024）——在 Claude 3 Sonnet 上找到千万级可解释特征

**优点**：**最深**——真正打开黑箱，找内部机制，可预测（找到 circuit 后能预测模型行为）。
**局限**：
- 工作量巨大（找 circuit 需要手工/半自动）
- **interpretability illusion**：找到的"特征"可能不是模型真正用的，而是我们强加的解释
- 大模型上才刚开始（GPT-4/Claude 级别）

### 3.4 三条路径对比

| 维度 | Probing | Attribution | Mechanistic |
|---|---|---|---|
| **问什么** | 模型知道 X 吗 | 输出由谁决定 | 内部怎么算 |
| **深浅** | 浅 | 中 | **深** |
| **能否找新现象** | 否 | 否 | **是** |
| **可预测性** | 弱 | 弱 | **强**（找到 circuit 可推演）|
| **当前主力** | 经典论文（2018-2020）| 实践最广 | **2024-2026 前沿** |
| **代表** | BERT probing | saliency/SHAP | Anthropic circuits + SAE |

> 🎯 **本系列重点**：**mechanistic interpretability**——前两条路径是"模型外部的 X 光机"，mechanistic 是"打开模型做解剖"。本系列后续 03-05 章深挖 mechanistic。

## 四、为什么 mechanistic 最难但最值得

### 4.1 难点：compositionality（组合性）

神经网络内部不是"一个神经元 = 一个概念"，而是**多个神经元组合 = 一个概念**，且**一个神经元参与多个概念**（superposition，叠加）。

```
神经元 #42 → 同时编码 "法国"+"首都"+"名词"+"蓝色"+...
    ↑ 没法直接解释单个神经元
    必须找组合：神经元 #42 + #871 + #5203 → "巴黎"
```

**Sparse autoencoder**（04 章（待写/未落盘））就是为解决这个问题——把稠密的叠加激活分解成稀疏的、单语义的特征。

### 4.2 值得：可预测性 = 真理解

**真正的"理解"标志是能预测**。如果找到了正确的 circuit，应该能：

- **关掉它**（ablation）→ 模型特定能力消失
- **激活它**（steering）→ 模型强制表现某行为

**Anthropic 2024 的金鱼实验**：找到"金鱼"特征，人工激活 → 模型在所有回答里都提到金鱼。**这是"我们真的找到了对的 circuit"的证据**。

### 4.3 哲学：理解 ≠ 解释

- **解释（explanation）**：事后给出一个让人满意的"为什么"
- **理解（understanding）**：能预测、能干预、能迁移

可解释性追求的是**后者**——不是"听起来合理的故事"，是**有预测力的机制模型**。

## 五、现状与开放问题

### 5.1 现状（2026-08）

| 方向 | 进展 |
|---|---|
| Probing | 经典成熟，新发现少 |
| Attribution | 工业用得最广，学界认为很多方法不可靠 |
| Mechanistic（小模型）| induction heads 等已明确找到 |
| Mechanistic（大模型）| SAE + scaling monosemanticity 让人乐观，但覆盖模型能力的 <1% |
| Steering | 早期应用（安全/控制），效果不稳 |

### 5.2 开放问题

1. **superposition 完全解吗**？SAE 能找到的特征空间有多大？是否有根本性局限？
2. **interpretability illusion 的边界**？怎么验证找到的"特征"是真机制，而非我们强加的解释？
3. **大模型上能 scale 吗**？在 GPT-4/Claude 级别找到千万特征，但相对于 7 万亿参数还是九牛一毛。
4. **circuit 与涌现**？大规模涌现的能力（如 reasoning）是分散在全模型，还是有局部 circuit？
5. **理解能预测能力吗**？找到 circuit 能不能预测未测试场景的行为？（这是真理解的标志）
6. **理解能控制能力吗**？steering 能做到什么粒度？能关掉"欺骗"吗？

> ⚠️ **诚实标注**：mechanistic interpretability 当前**远未解决"理解大模型"**。已发现的 circuit 是冰山一角。任何"我们理解了 LLM"的宣称都应警惕。

---

## 六、一句话总结

> 🎯 **四句话**：
> 1. AI 黑箱不是"懒得看"，是**结构性认知错配**——计算在单个神经元，意义在群体分布。
> 2. 黑箱是真问题：**安全**（deceptive alignment）+ **调试**（hallucination 无 stack trace）+ **责任**（法律要求解释）+ **科学悖论**（最强工具配最弱理解）。
> 3. 三条路径（probing → attribution → mechanistic），mechanistic 最深最难最值得——找内部 circuit、可预测、能干预。
> 4. 2024-2026 是 mechanistic 爆发期（SAE + scaling monosemanticity），但**完全理解大模型还远**——这是 AGI 讨论的关键拼图。

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我长期把"AI 是黑箱"理解成"权重太多人脑算不过来"——以为只是规模问题，等技术进步就能看见内部。重读 §1.2 分布式表示那段才顿悟：黑箱是**结构性的**，不是规模问题——**一个概念分布在 1000 个神经元上，单个神经元的激活对解释毫无意义**。就算你只看一个 10 神经元的小网络，单个神经元也往往同时参与多个概念（superposition），无法"一对一翻译"。这是"计算单位（神经元）和语义单位（概念）错位"，不是"神经元太多"。
- **F3 术语翻译**：
  - "probing（探测）" → 训一个小分类器去问模型中间层"你知不知道 X"，准确率高说明信息在里面——但不能证明模型"真的用了"
  - "circuit（电路）" → 几个神经元 + 权重组成的小回路，专门干一件事（如 induction head 负责 in-context learning），相当于神经网络里的"功能模块"
  - "superposition（叠加）" → 一个神经元同时编码好几个概念，因为概念比神经元多——必须用稀疏自编码器（SAE）把叠加的激活拆成单语义特征才能解释
- **F4 回炉**：v1 我把 mechanistic interpretability 写成"找到 circuit 就等于理解了模型"——这是**过度乐观**。v2 改成"找到 circuit 只是**理解的开始**，还要面对两层质询：① **interpretability illusion**——找到的'特征'可能是我们强加的解释而非模型真用的；② **覆盖度**——目前发现的 circuit 只覆盖模型能力 <1%，相对 GPT-4 的 1.7T 参数是九牛一毛。真正的理解标志是 §4.2 的**可预测性**：关掉/激活 circuit 能精确预测行为变化，这才算'找到了'，而不是'讲了个好听的故事'"。diff：从"找到即理解"改为"找到 + 抗 illusion + 可预测才算理解"，对应 §4.3"解释 ≠ 理解"的区分。
