## §0 全局视角：统计学习理论 = "为什么 ML 能 work"

```
统计学习理论回答:
  Q1: 模型能学到的最坏情况边界?  → VC 维, Rademacher 复杂度
  Q2: 多少数据够?                → sample complexity
  Q3: 训练误差 vs 测试误差?       → 泛化界
  Q4: 何时会出现"过拟合"?         → bias-variance tradeoff
```

> 🔑 **核心 DNA**：**统计学习理论把"经验性 ML"提升到"可证明的 ML"**——它告诉你什么时候 ML 有保证，什么时候没有。

## §1 八条算法经验

### 算法经验 SL1：泛化误差 = 训练误差 + 复杂度惩罚

> $$\underbrace{R(\hat{f})}_{\text{测试误差}} \leq \underbrace{\hat{R}(\hat{f})}_{\text{训练误差}} + \underbrace{\sqrt{\frac{\text{complexity}}{n}}}_{\text{复杂度惩罚}}$$
>
> 算法本质：**测试误差 = 训练误差 + 模型复杂度的统计代价**——这是所有 ML 的根本权衡（应用 T2 数学不变性）。

### 算法经验 SL2：VC 维 = 模型"容量"的度量

> VC 维衡量模型**能 shatter（任意划分）多少点**。
> - 线性分类器在 $\mathbb{R}^d$：VC = $d+1$
> - 神经网络：VC ≈ 参数数量
>
> 算法本质：**VC 维越高，模型越强，但需要越多数据**（应用 OP1 凸 vs 非凸、N3 参数共享）。

### 算法经验 SL3：Rademacher 复杂度 = 数据相关的容量

> Rademacher 复杂度比 VC 维更精细——它**用实际数据衡量模型容量**。
>
> 算法本质：**容量不是模型的固有属性，是模型+数据的联合属性**（应用 T8 评测盲区、IT5 互信息）。

### 算法经验 SL4：bias-variance 权衡

> $$\text{MSE} = \text{bias}^2 + \text{variance} + \text{noise}$$
>
> - **bias 大**：欠拟合（模型太简单）
> - **variance 大**：过拟合（模型太复杂）
> - **sweet spot**：两者平衡
>
> 算法本质：**这是 ML 最经典的权衡图**（应用 #8 三段式、A6 温度）。

### 算法经验 SL5：PAC 学习 = Probably Approximately Correct

> PAC 框架：以高概率（$1-\delta$）学到误差小的假设（$\epsilon$）。
> $$P(R(\hat{f}) \leq \epsilon) \geq 1 - \delta$$
>
> 算法本质：**ML 不保证"完美"，只保证"大概率接近"**（应用 OP8 Langevin 采样）。

### 算法经验 SL6：没有免费的午餐（NFL）定理

> **对所有任务平均而言，所有算法表现相同**。
>
> 推论：**没有"万能算法"**——ML 必须有归纳偏置（inductive bias）。
>
> 算法本质：**归纳偏置 = ML 的"先验"**（应用 Ch14 S4 手工 vs 学习、Ch09 #1 设计空间在信号）。

### 算法经验 SL7：深度学习的"泛化悖论"

> 过参数化的深度网络**理论上应该严重过拟合**（VC 维远大于数据量），但实际上**泛化很好**。
>
> 解谜：**SGD 的隐式正则 + 平坦极小值偏好**（应用 OP3 SGD 噪声正则、Ch11 隐式正则）。

### 算法经验 SL8：双下降（Double Descent）

> 现代深度学习发现：**模型变大时，测试误差经历两次下降**：
> 1. 经典 bias-variance（小到中等模型）
> 2. 第二次下降（过参数化区域）
>
> 算法本质：**经典统计学习理论不足以解释深度学习**——需要新理论（应用 TR7 Scaling Law、T1 试炼场）。
