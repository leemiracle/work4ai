# 讲透统计学习理论（Statistical Learning Theory）

> **博士级地基**——所有 ML 理论的最深底层。Scaling law 物理解释、双层下降、过参数化为什么泛化、VC 维、Rademacher 复杂度——都从这里开始。
>
> 一句话定位：[`讲透泛化`](../讲透泛化/) 给现象（过参数化不崩），本系列给**严格数学**（为什么）。
>
> **博士级标准**：数学密集（概率论 + 测度论 + 凸分析）。比基础模型 advanced 更硬核。
>
> 配套：[`讲透泛化`](../讲透泛化/)（应用现象）+ [`讲透优化理论`](../讲透优化理论/)（优化-泛化联系）+ [`讲透基础模型/advanced/01 ScalingLaw`](../讲透基础模型/advanced/01-ScalingLaw-严格证明.md)

## 为什么单独开

- **理论根基**：scaling law 物理解释的唯一桥梁（[`讲透基础模型/advanced/01`](../讲透基础模型/advanced/01-ScalingLaw-严格证明.md) 的开放问题 #1）
- **博士必修**：任何 ML 博士资格考都考
- **被深度学习圈忽视**——但理解它才能看懂深度学习为什么 work
