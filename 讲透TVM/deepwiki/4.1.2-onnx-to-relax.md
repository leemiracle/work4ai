## Purpose and Scope

 This page documents the ONNX to Relax frontend importer, which converts ONNX (Open Neural Network Exchange) models into TVM's Relax IR. This is the modern import path for ONNX models in TVM, producing Relax IR functions that support first-class functions and symbolic shapes. For the traditional ONNX import path that produces Relay IR, see [ONNX to Relay (4.1.1)](https://github.com/apache/tvm/blob/b16cdecb/ONNX to Relay (4.1.1))

 The importer is implemented in Python and provides a flexible operator conversion system with opset versioning support. It handles dynamic shapes, constant folding, and parameter separation while translating ONNX operators to equivalent Relax expressions. By default, the importer retains dynamic shapes and attempts to resolve them to static shapes at compile time when possible.

## Entry Point: `from_onnx` Function

 The primary entry point for ONNX import is the `from_onnx` function. It orchestrates the conversion process by:

 
 - Parsing the ONNX model structure.
 - Building the Relax graph nodes.
 - Handling initializers and parameters via the `params` dictionary.
 - Creating the output `IRModule`.
 
 The function accepts parameters for:

 
 - `opset`: ONNX opset version to use for operator conversions.
 - `keep_params_in_input`: Whether to keep model parameters as function inputs or attach them as attributes.
 
 **Sources:** [tests/python/relax/test_frontend_onnx.py148](https://github.com/apache/tvm/blob/b16cdecb/tests/python/relax/test_frontend_onnx.py#L148-L148) [python/tvm/relax/frontend/onnx/onnx_frontend.py21-33](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/onnx/onnx_frontend.py#L21-L33)

## Type and Shape Utilities

 
### Type Conversion: `get_type`

 Converts ONNX integer datatypes to string-based Relax/NumPy datatypes using `onnx.helper.tensor_dtype_to_np_dtype`.

 **Sources:** [python/tvm/relax/frontend/onnx/onnx_frontend.py83-97](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/onnx/onnx_frontend.py#L83-L97)

 
### Symbolic Shape Handling: `parse_shape_name`

 The importer supports symbolic shapes through `tvm.tirx.Var`. The `parse_shape_name` function parses expressions in ONNX shape dimension names (e.g., `batch + 1`) and converts them into `tirx.Expr`.

### Constant Handling: `get_constant`

 The `get_constant` function attempts to convert a `relax.Var` to a `relax.Constant` if the variable's name exists in the provided parameter dictionary. This is crucial for constant folding and weight handling.

## Image Operators

 Relax provides specialized support for image operations often found in ONNX models, such as `Resize`, `GridSample`, and `AffineGrid`.

 
### Resize Operations

 The `resize2d` and `resize3d` operators handle spatial scaling. These are defined in C++ and exposed to Relax via Python wrappers.

 
| Attribute | Description |
|---|---|
| method | nearest_neighbor, linear, cubic |
| coordinate_transformation_mode | half_pixel, align_corners, asymmetric, etc. |
| layout | NCHW, NHWC, NCDHW, etc. |
