  The `nn.Module` frontend in TVM Relax offers a Python-native, PyTorch-like API for defining and composing models, enabling users to build neural network models directly in Python while targeting the Relax IR for compilation and optimization. This frontend abstracts away low-level Relax IR construction details, providing a user-friendly interface for creating models as Python classes with parameters and submodules.

 It includes:

 
 - Core abstractions for tensor and parameter management.
 - The `Module` class as a container for parameters and submodules with a model-style API.
 - Rich support for built-in NN modules like `Linear`, `Conv1D`, activation layers, and normalization layers.
 - An operators module exposing neural network tensor operations.
 - LLM-specific modules and kernels for KV cache management and position embedding (RoPE).
 - A compiler specification language to describe the input/output shapes for compilation.
 
 
---

 
## 1. Purpose and Scope

 The Relax `nn.Module` frontend provides:

 
 - A Python class hierarchy supporting parameter registration, submodule definition, and method binding.
 - A `Tensor` wrapper over Relax expressions for symbolic tensor representation with shape and dtype metadata.
 - `Parameter` objects representing learnable weights, which can be bound to actual data.
 - Facilities to export the module as a Tuneable, compilable Relax IRModule for subsequent compilation.
 - Integration with side effect modeling (e.g., IO side effects) via `IOEffect` [python/tvm/relax/frontend/nn/modules.py30-55](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/modules.py#L30-L55)
 - Built-in commonly used neural network components for rapid model prototyping.
 - Special support for Large Language Models (LLMs) including KV cache management modules and RoPE position embeddings optimized for attention.
 
 **Sources:** [python/tvm/relax/frontend/nn/core.py17-25](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L17-L25) [python/tvm/relax/frontend/nn/modules.py30-55](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/modules.py#L30-L55)

## 2. Core Architecture and Key Classes

 
### 2.1 Tensor and Parameter

 At the heart of the frontend is the `Tensor` class which wraps a Relax expression (`rx.Expr`) presumed to be a Relax Tensor type `TensorType` [python/tvm/relax/frontend/nn/core.py90-95](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L90-L95) It provides convenient access to shape and dtype metadata while remaining symbolic (non-materialized).

 
 - `Tensor` has properties for symbolic shapes which may include symbolic variables or primitive expressions [python/tvm/relax/frontend/nn/core.py189-205](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L189-L205)
 - Supports construction from constants [python/tvm/relax/frontend/nn/core.py115-117](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L115-L117) from symbolic types [python/tvm/relax/frontend/nn/core.py125-144](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L125-L144) or placeholders [python/tvm/relax/frontend/nn/core.py152-187](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L152-L187)
 - `Parameter` extends `Tensor` to represent model parameters [python/tvm/relax/frontend/nn/core.py21-22](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L21-L22)
 
 
### 2.2 Module

 `Module` is the container class representing a neural network model or subcomponent [python/tvm/relax/frontend/nn/core.py22](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/core.py#L22-L22) It:

 
 - Holds `Parameter` instances and nested submodules.
 - Supports a PyTorch-like API where users subclass `Module` and define a `forward()` method.
 - Automatically manages parameter registration and hierarchy for nested modules.
 - Exports to a Relax IRModule via `export_tvm()` [tests/python/relax/test_frontend_nn_op.py54-57](https://github.com/apache/tvm/blob/b16cdecb/tests/python/relax/test_frontend_nn_op.py#L54-L57)

## 4. Large Language Model (LLM) Extensions

 
### 4.1 KV Cache Modules (`nn.llm.kv_cache`)

 For efficient autoregressive decoding, the `PagedKVCache` stores key/value tensors across tokens to avoid recomputation [python/tvm/relax/frontend/nn/llm/kv_cache.py119-120](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/kv_cache.py#L119-L120)

 
 - **Backend Implementations**: `FlashInferPagedKVCache` and `TIRPagedKVCache` [python/tvm/relax/frontend/nn/llm/kv_cache.py22-23](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/kv_cache.py#L22-L23)
 - **Attention Interface**: `attention_with_fused_qkv` performs attention with fused query-key-value inputs and internal cached states [python/tvm/relax/frontend/nn/llm/kv_cache.py124-159](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/kv_cache.py#L124-L159)
 - **Runtime Integration**: The C++ implementation `PagedAttentionKVCacheObj` manages the actual physical memory and paging logic [src/runtime/vm/paged_kv_cache.cc131-182](https://github.com/apache/tvm/blob/b16cdecb/src/runtime/vm/paged_kv_cache.cc#L131-L182)
 
 
### 4.2 Position Embedding Operators (`nn.llm.position_embedding`)

 RoPE (Rotary Position Embedding) operators are implemented for various model architectures:

 
 - **Default RoPE**: `rope_freq_default` [python/tvm/relax/frontend/nn/llm/position_embedding.py32-67](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/position_embedding.py#L32-L67)
 - **Llama Variants**: `rope_freq_llama3` [python/tvm/relax/frontend/nn/llm/position_embedding.py130-161](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/position_embedding.py#L130-L161) and `rope_freq_llama4` [python/tvm/relax/frontend/nn/llm/position_embedding.py79-127](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/position_embedding.py#L79-L127)
 - **Advanced Scaling**: `rope_freq_longrope` [python/tvm/relax/frontend/nn/llm/position_embedding.py164-188](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/position_embedding.py#L164-L188) and YaRN support [python/tvm/relax/frontend/nn/llm/position_embedding.py191-203](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/nn/llm/position_embedding.py#L191-L203)
