  This document describes the organizational structure, governance model, and community roles within the Apache TVM project. It explains how decisions are made, how contributors advance through different roles, and how the project maintains its open-source community through the "Apache Way."

 
## Overview

 TVM operates as an Apache Software Foundation (ASF) top-level project. The project governs by merit, creating an inclusive community where everyone can influence the direction of the framework by earning merit through contributions [CONTRIBUTORS.md18-23](https://github.com/apache/tvm/blob/b16cdecb/CONTRIBUTORS.md?plain=1#L18-L23) The codebase is distributed under the Apache License, Version 2.0 [CONTRIBUTORS.md1-16](https://github.com/apache/tvm/blob/b16cdecb/CONTRIBUTORS.md?plain=1#L1-L16)

 **Sources:** [CONTRIBUTORS.md1-23](https://github.com/apache/tvm/blob/b16cdecb/CONTRIBUTORS.md?plain=1#L1-L23)

 
## Governance Model

 TVM follows the Apache Software Foundation's governance model, which is based on meritocracy. The Project Management Committee (PMC) provides oversight and makes binding decisions, while committers have write access and reviewers ensure code quality.

## Community Roles

 
### Project Management Committee (PMC)

 PMC members are responsible for the project's health, including approving new committers and overseeing releases. PMC members are identified in the contributor list by the `(PMC)` tag [CONTRIBUTORS.md26-101](https://github.com/apache/tvm/blob/b16cdecb/CONTRIBUTORS.md?plain=1#L26-L101)

### Committers

 Committers have write access to the repository and are encouraged to work on any area they are interested in, though they often have specific tags indicating familiarity with certain subsystems [CONTRIBUTORS.md26-30](https://github.com/apache/tvm/blob/b16cdecb/CONTRIBUTORS.md?plain=1#L26-L30)

 
### Reviewers

 Reviewers provide technical feedback and are essential for maintaining the project's high standards. The reviewer list includes active community members across all technical domains [CONTRIBUTORS.md102-110](https://github.com/apache/tvm/blob/b16cdecb/CONTRIBUTORS.md?plain=1#L102-L110)

## Release Process and Versioning

 The release manager is responsible for preparing release notes, cutting branches, and running the voting process [docs/contribute/release_process.rst27-47](https://github.com/apache/tvm/blob/b16cdecb/docs/contribute/release_process.rst#L27-L47)

 
### Versioning Logic

 TVM versions are derived automatically from Git tags using `setuptools_scm` [docs/contribute/release_process.rst52-56](https://github.com/apache/tvm/blob/b16cdecb/docs/contribute/release_process.rst#L52-L56)

 
 - **Main Branch**: Tagged as `vMAJOR.MINOR.devN` (e.g., `v0.7.dev0`) [docs/contribute/release_process.rst58](https://github.com/apache/tvm/blob/b16cdecb/docs/contribute/release_process.rst#L58-L58)
 - **Release Candidate**: Tagged as `v0.6.0.rc0` on a release branch [docs/contribute/release_process.rst63](https://github.com/apache/tvm/blob/b16cdecb/docs/contribute/release_process.rst#L63-L63)
 - **Formal Release**: Tagged as `v0.6.0` [docs/contribute/release_process.rst64](https://github.com/apache/tvm/blob/b16cdecb/docs/contribute/release_process.rst#L64-L64)

## Automated Governance: TVM Bot

 The project utilizes `github_tvmbot.py` to automate parts of the governance and merge process. The bot performs authorization checks and verifies CI status before allowing merges.

 
### Bot Logic and Authorization

 The bot uses GraphQL queries like `COLLABORATORS_QUERY` and `PR_QUERY` to inspect the state of a pull request [ci/scripts/github/github_tvmbot.py55-175](https://github.com/apache/tvm/blob/b16cdecb/ci/scripts/github/github_tvmbot.py#L55-L175)

 
| Function/Class | Role |
|---|---|
| PR class | Encapsulates PR data, including reviews, CI status, and author info ci/scripts/github/github_tvmbot.py191-204 |
| TestSuccessfulMerge | Simulates a successful merge trigger via @tvm-bot merge tests/python/ci/test_tvmbot.py116-123 |
| TestInvalidAuthor | Validates that non-committers cannot trigger merges tests/python/ci/test_tvmbot.py175-183 |
| TestBadCI | Ensures PRs with failed tvm-ci/pr-head jobs cannot be merged tests/python/ci/test_tvmbot.py126-141 |

 - **RFCs**: New features and major changes are discussed via the `tvm-rfcs` repository [tests/scripts/release/README.md47-53](https://github.com/apache/tvm/blob/b16cdecb/tests/scripts/release/README.md?plain=1#L47-L53)
 - **Release Notes**: Generated by gathering PRs since a specific commit [tests/scripts/release/gather_prs.py193-196](https://github.com/apache/tvm/blob/b16cdecb/tests/scripts/release/gather_prs.py#L193-L196) and categorizing them based on a tag dictionary [tests/scripts/release/make_notes.py33-95](https://github.com/apache/tvm/blob/b16cdecb/tests/scripts/release/make_notes.py#L33-L95)
