## Purpose and Scope

 Transform Operations are the fundamental tensor manipulation primitives in TVM's operator library. These operations provide basic functionality for reshaping, slicing, reordering, and combining tensors without performing mathematical computations. Transform operations are used extensively by all model import frontends to convert framework-specific tensor operations into TVM's intermediate representation.

 This document covers the tensor transformation operators implemented in TOPI (TVM Operator Inventory) and their corresponding Relax operator definitions. For neural network-specific operators like convolution and pooling, see [TOPI - TVM Operator Inventory](https://deepwiki.com/apache/tvm/3.2-topi-tvm-operator-inventory). For high-level Relax operators, see [Relax Operators](https://deepwiki.com/apache/tvm/3.3-relax-operators).

## Overview

 Transform operations form the foundation of tensor manipulation in TVM, providing the primitive operations needed to restructure data without changing its content. In the Relax IR, these are implemented as first-class operators that often legalize to TOPI implementations during the compilation pipeline.

## Core Transform Operations

 
### Shape Manipulation Operations

 Shape manipulation operations modify the dimensionality and shape of tensors without changing the underlying data layout in memory.

 
#### expand_dims

 The `expand_dims` operation inserts new axes of length 1 into a tensor at specified positions.

 
 - **Relax API:** `relax.op.expand_dims(x, axis)` [python/tvm/relax/op/manipulate.py76-96](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/manipulate.py#L76-L96)
 - **TOPI API:** `topi.expand_dims(a, axis, num_newaxis=1)` [python/tvm/topi/transform.py31-46](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/topi/transform.py#L31-L46)
 - **Legalization:** Maps `relax.expand_dims` to a TE compute function that reshapes indices [python/tvm/relax/transform/legalize_ops/manipulate.py77-97](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/transform/legalize_ops/manipulate.py#L77-L97)
 
 The operation supports negative axis indexing and validates that the axis is within the valid range `[-data.ndim - 1, data.ndim]` [include/tvm/topi/transform.h159-164](https://github.com/apache/tvm/blob/b16cdecb/include/tvm/topi/transform.h#L159-L164)

 
#### reshape

 The `reshape` operation changes the shape of a tensor while preserving the total number of elements.

 
 - **Relax API:** `relax.op.reshape(x, shape)` [python/tvm/relax/op/manipulate.py180-215](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/manipulate.py#L180-L215)
 - **TOPI API:** `topi.reshape(a, newshape)` [python/tvm/topi/transform.py357-371](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/topi/transform.py#L357-L371) (referenced via `cpp.reshape`)
 - **Legalization:** Uses `topi.reshape` via the `_reshape` helper [python/tvm/relax/transform/legalize_ops/manipulate.py34-49](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/transform/legalize_ops/manipulate.py#L34-L49)
 
 
#### permute_dims / transpose

 The `permute_dims` (Relax) or `transpose` (TOPI) operation reorders the dimensions of a tensor.

 
 - **Relax API:** `relax.op.permute_dims(x, axes=None)` [python/tvm/relax/op/manipulate.py161-177](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/manipulate.py#L161-L177)
 - **TOPI API:** `topi.transpose(a, axes=None)` [python/tvm/topi/transform.py110-125](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/topi/transform.py#L110-L125)
 - **Legalization:** Directly calls `topi.transpose` [python/tvm/relax/transform/legalize_ops/manipulate.py105-107](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/transform/legalize_ops/manipulate.py#L105-L107)
 
 
### Slicing and Indexing Operations

 
#### strided_slice

 Extracts a sub-tensor by specifying begin indices, end indices, and strides.

 
 - **Relax API:** `relax.op.strided_slice(x, axes, begin, end, strides=None)` [python/tvm/relax/op/index.py44-84](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/index.py#L44-L84)
 - **TOPI API:** `topi.strided_slice(a, begin, end, strides=None, axes=None)` [python/tvm/topi/transform.py176-232](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/topi/transform.py#L176-L232)
 - **Implementation:** Relax uses `StridedSliceAttrs` to store the `assume_inbound` flag [src/relax/op/tensor/index.cc167-168](https://github.com/apache/tvm/blob/b16cdecb/src/relax/op/tensor/index.cc#L167-L168)
 
 
#### take

 Extracts elements from a tensor using indices along a specific axis.

 
 - **Relax API:** `relax.op.take(x, indices, axis=None)` [python/tvm/relax/op/index.py23-41](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/index.py#L23-L41)
 - **TOPI API:** `topi.take(a, indices, axis=None, batch_dims=0, mode="fast")` [python/tvm/topi/transform.py449-480](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/topi/transform.py#L449-L480)
 - **Type Inference:** `InferTypeTake` ensures indices have integer dtype and calculates the resulting output shape [src/relax/op/tensor/index.cc63-127](https://github.com/apache/tvm/blob/b16cdecb/src/relax/op/tensor/index.cc#L63-L127)
 
 
### Combining Tensors

 
#### concatenate

 Joins a sequence of tensors along an existing axis.

 
 - **Relax API:** `relax.op.concat(tensors, axis=0)` [python/tvm/relax/op/manipulate.py53-74](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/manipulate.py#L53-L74)

#### stack

 Joins tensors along a new axis.

 
 - **Relax API:** `relax.op.stack(tensors, axis=0)` [python/tvm/relax/op/manipulate.py270-291](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/manipulate.py#L270-L291)
 - **Legalization:** Follows bindings to find the actual tuple and calls `topi.stack` [python/tvm/relax/transform/legalize_ops/manipulate.py124-143](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/transform/legalize_ops/manipulate.py#L124-L143)

## Advanced Transform Operations

 
### sliding_window

 Creates an operation to slide a window over the input tensor, often used for unfold/im2col.

 
 - **C++ API:** `topi::sliding_window(x, axis, window_shape, strides)` [include/tvm/topi/transform.h76-142](https://github.com/apache/tvm/blob/b16cdecb/include/tvm/topi/transform.h#L76-L142)
 - **Logic:** The new shape includes window dimensions appended to spatial dimensions. Index mapping uses `window_idx * stride + idx_within_window` [include/tvm/topi/transform.h128-134](https://github.com/apache/tvm/blob/b16cdecb/include/tvm/topi/transform.h#L128-L134)
 
 
### layout_transform

 Modifies the physical layout of a tensor using an `IndexMap`.

 
 - **Relax API:** `relax.op.layout_transform(x, index_map, pad_value=None)` [python/tvm/relax/op/manipulate.py115-158](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/manipulate.py#L115-L158)
 - **Implementation:** Registered as `relax.op.layout_transform` with `LayoutTransformAttrs` [src/relax/op/tensor/manipulate.cc46-74](https://github.com/apache/tvm/blob/b16cdecb/src/relax/op/tensor/manipulate.cc#L46-L74)
