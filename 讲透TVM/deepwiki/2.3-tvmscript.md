## Purpose and Scope

 TVMScript is TVM's Python-embedded domain-specific language (DSL) that allows writing TVM intermediate representations as executable Python code. It provides a readable, writable syntax for defining low-level tensor programs in **TensorIR (TIR)** and high-level computational graphs in **Relax IR**. Users can express optimized kernels, scheduling transformations, and tensor computations using Python syntax with special decorators and context managers.

 TVMScript functions by parsing Python AST and mapping it to TVM IR through an **IRBuilder** framework or by printing existing IR into a valid Python representation.

 
---

 
## Core Architecture: Parser and IRBuilder

 The TVMScript system consists of two main directions: **Parsing** (Python to IR) and **Printing** (IR to Python).

 
### The Parser Framework

 The parser is implemented in `python/tvm/script/parser/core/parser.py`. It uses a dispatch-based system to traverse the Python AST and invoke corresponding IRBuilder methods.

## IRBuilder Frame Management

 The `IRBuilder` maintains a stack of frames. When the parser encounters a `with` statement or a decorated function, it pushes a new frame onto the stack.

 
### TIR and IR Layer Frames

 The base IR layer (in `I.Module`) handles high-level structures, while dialects like TIR (in `T`) handle specific computation logic.

 
| Frame Class | File Path | Role |
|---|---|---|
| IRModuleFrame | src/script/ir_builder/ir/ir.cc40-45 | Manages functions and attributes within an IRModule. |
| PrimFuncFrame | src/script/ir_builder/tir/frame.cc46-81 | Context for defining a TIR primitive function. |
| SBlockFrame | src/script/ir_builder/tir/frame.cc83-105 | Context for a computation block with iterators. |

 **IR Layer Functions:**

## Dialect Support: TIR and Relax

 TVMScript supports multiple dialects through specialized namespaces (typically `T` for TIR and `R` for Relax).

 
### TIR Support

 TIR in TVMScript (often referred to as `T`) allows for low-level scheduling and memory management.

 
 - **`T.match_buffer`**: Used to match parameters to buffer regions [tests/python/tvmscript/test_tvmscript_printer_tir.py208-228](https://github.com/apache/tvm/blob/b16cdecb/tests/python/tvmscript/test_tvmscript_printer_tir.py#L208-L228)
 - **`T.alloc_buffer`**: Allocates memory within a block or function [tests/python/tvmscript/test_tvmscript_printer_tir.py89-99](https://github.com/apache/tvm/blob/b16cdecb/tests/python/tvmscript/test_tvmscript_printer_tir.py#L89-L99)
 - **`T.sblock`**: Defines a schedulable block of computation [tests/python/tvmscript/test_tvmscript_printer_tir.py182-205](https://github.com/apache/tvm/blob/b16cdecb/tests/python/tvmscript/test_tvmscript_printer_tir.py#L182-L205)
 
 
### Relax Support

 Relax in TVMScript (often referred to as `R`) handles high-level graph definitions and symbolic shapes.

 
 - **`R.function`**: Defines a high-level Relax function.
 - **`R.call_tir`**: Bridges the gap between Relax and TIR by calling a TIR PrimFunc from Relax.

## Advanced Features

 
### Macros

 TVMScript supports macros to allow code reuse within IR definitions. Macros can be hygienic (namespaced) or non-hygienic [python/tvm/script/parser/core/parser.py142-162](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/script/parser/core/parser.py#L142-L162)

 
### Metadata and Serialization

 When printing IR that contains large constant tensors or complex attributes, TVMScript uses a `metadata` dictionary. This is serialized as a JSON string and loaded via `tvm.ir.load_json` at the top of the script [src/script/printer/utils.h74-89](https://github.com/apache/tvm/blob/b16cdecb/src/script/printer/utils.h#L74-L89)

 
### TypeVar and Symbolic Shapes

 TVMScript supports PEP 695 style `TypeVar` for symbolic shapes, allowing users to define kernels that work across varying tensor dimensions [python/tvm/script/parser/core/parser.py46-111](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/script/parser/core/parser.py#L46-L111)
