  The Target System provides abstractions for specifying compilation targets and their hardware characteristics. A `Target` object encapsulates the hardware platform (CPU, GPU, accelerator) and compiler configuration (architecture, features, optimization flags) that guide TVM's code generation pipeline. This system enables cross-compilation, hardware-specific optimizations, and multi-target deployment.

 For information about code generation backends that consume target specifications, see [LLVM Backend](https://deepwiki.com/apache/tvm/6.2-llvm-backend). For build system configuration of target support, see [Build System](https://deepwiki.com/apache/tvm/8.1-build-system).

 
## Core Architecture

 The Target System consists of three primary abstractions: `Target` objects that represent specific compilation configurations, `TargetKind` objects that define categories of targets with their supported attributes, and `TargetTag` objects that provide named presets for common hardware configurations.

## Target Object Structure

 The `Target` class (defined in `TargetNode`) contains the complete specification for a compilation target. Each target includes a `TargetKind` that categorizes the target type, an array of `keys` for operator dispatch, an `attrs` map containing configuration parameters, and an optional `host` target for heterogeneous compilation.

 
| Field | Type | Purpose |
|---|---|---|
| kind | TargetKind | Target category (cuda, llvm, opencl, etc.) |
| tag | String | Optional tag name for the target |
| keys | Array<String> | Dispatch keys for operator selection |
| attrs | Map<String, Any> | Collection of attributes (includes feature.* keys) |
| host | Optional<Target> | Host target for device compilation |

 **Sources:** [include/tvm/target/target.h45-57](https://github.com/apache/tvm/blob/b16cdecb/include/tvm/target/target.h#L45-L57) [src/target/target.cc151-164](https://github.com/apache/tvm/blob/b16cdecb/src/target/target.cc#L151-L164)

 
### Common Target Attributes

 Target attributes are validated against a `ConfigSchema` defined in the `TargetKind`.

 
| Attribute | Type | Description |
|---|---|---|
| mcpu | String | Specific CPU/GPU model (e.g., "cortex-a72", "sm_80") |
| mtriple | String | LLVM target triple (e.g., "arm64-linux-android") |
| mattr | Array<String> | LLVM features (e.g., ["+avx512f", "+mmx"]) |
| libs | Array<String> | External libraries to use (e.g., ['cblas', 'mkl']) |
| system-lib | bool | Build module with self-registered functions |

### Canonicalization and Parsing

 Each `TargetKind` can register a `target_canonicalizer` (an `FTargetCanonicalizer`). This function is applied during creation to transform the input JSON-like configuration. For example, the `llvm` and `c` kinds use `tvm::target::canonicalizer::llvm::Canonicalize` to normalize attributes.

## TargetKind Registry

 The `TargetKind` registry defines categories of targets and their supported attributes. Each kind is registered with a default device type and default keys.

 
### Registered Target Kinds (Examples)

 
| Name | Device Type | Default Keys | Key Options |
|---|---|---|---|
| llvm | kDLCPU | {"cpu"} | mattr, mcpu, mtriple, fast-math, jit |
| cuda | kDLCUDA | {"cuda", "gpu"} | arch, max_num_threads, thread_warp_size |
| hexagon | kDLHexagon | {"hexagon"} | mcpu, mtriple, mattr |
| composite | kDLCPU | N/A | devices (Array of Targets) |

### Attribute Registration

 New attributes are added to a kind using `add_attr_option<T>(key)`. This enforces type safety during `Target` construction. For instance, `num-cores` in `llvm` must be an `int64_t`.

## Target Tags

 Target tags provide named presets for specific hardware. A tag maps a name (e.g., `"nvidia/nvidia-a100"`) to a complete configuration map.

 
 - **Registry:** Managed by `TargetTagRegistry` in `src/target/tag.cc`.
 - **Listing:** `TargetTag::ListTags()` returns all registered tags.
 - **Creation:** `TargetTag::AddTag(name, config)` allows dynamic registration of new hardware presets.
 
 **Sources:** [src/target/tag.cc46-58](https://github.com/apache/tvm/blob/b16cdecb/src/target/tag.cc#L46-L58) [src/target/tag.cc69-83](https://github.com/apache/tvm/blob/b16cdecb/src/target/tag.cc#L69-L83) [src/target/tag.cc77-82](https://github.com/apache/tvm/blob/b16cdecb/src/target/tag.cc#L77-L82)

 
## Heterogeneous Targets

 TVM supports heterogeneous compilation through the `host` field and `composite` targets.

 
### Target Host

 The `host` field in `TargetNode` allows specifying a different target for the host-side code (e.g., a CPU) while the main target specifies the device-side code (e.g., a GPU).

 
 - **Consistency Check:** `CheckAndUpdateHostConsistency` ensures the host and device targets are compatible.
 - **Stripping:** `Target::WithoutHost()` returns a copy of the target with the host field removed.
 
 **Sources:** [include/tvm/target/target.h49-50](https://github.com/apache/tvm/blob/b16cdecb/include/tvm/target/target.h#L49-L50) [src/target/target.cc71-74](https://github.com/apache/tvm/blob/b16cdecb/src/target/target.cc#L71-L74) [src/target/target.cc168-176](https://github.com/apache/tvm/blob/b16cdecb/src/target/target.cc#L168-L176)

 
### Composite Targets

 The `composite` target kind allows grouping multiple targets together, primarily used for multi-device execution environments. It contains a `devices` attribute which is an array of other `Target` objects.

 **Sources:** [src/target/target_kind.cc175-184](https://github.com/apache/tvm/blob/b16cdecb/src/target/target_kind.cc#L175-L184)

 
## Context Management

 TVM uses a thread-local stack to manage the "current" target context. This is essential for components like `GenericFunc` that dispatch implementations based on the active target.

 
 - **Enter Scope:** `Target::EnterWithScope()` pushes the target onto the `TVMTargetThreadLocalEntry` stack.
 - **Exit Scope:** `Target::ExitWithScope()` pops it.
 - **Current Target:** `Target::Current(allow_not_defined)` retrieves the top of the stack.
 
 **Sources:** [src/target/target.cc191-212](https://github.com/apache/tvm/blob/b16cdecb/src/target/target.cc#L191-L212) [include/tvm/target/target.h178-187](https://github.com/apache/tvm/blob/b16cdecb/include/tvm/target/target.h#L178-L187)
