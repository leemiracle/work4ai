## Purpose and Scope

 The PyTorch Frontend provides functionality to import PyTorch models into TVM's Relax IR for compilation and optimization. This document covers the translation from PyTorch's computational graph representations (ExportedProgram and FX graphs) to Relax IR, specifically focusing on the modern `torch.export` and `torch.compile` (Dynamo) integration.

 For information about the target Relax IR representation, see [Relax IR](https://deepwiki.com/apache/tvm/2.2-relax-ir). For details on specific operator implementations in Relax, see [Relax Operators](https://deepwiki.com/apache/tvm/3.3-relax-operators). For other deep learning framework importers, see [Other Model Format Importers](https://deepwiki.com/apache/tvm/4.3-other-model-format-importers).

## Operator Conversion System

 The PyTorch frontend dispatches operator translation through a conversion map.

 
### Unary Operations

 Unary operations convert element-wise PyTorch ops to corresponding Relax ops. A special case exists for `sqrt` and `rsqrt` where integer inputs are auto-converted to `float32` [python/tvm/relax/frontend/torch/exported_program_translator.py105-123](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/torch/exported_program_translator.py#L105-L123)

 
| PyTorch Operator | Relax Operator |
|---|---|
| torch.abs | R.abs |
| torch.nn.functional.gelu | R.nn.gelu |
| torch.sqrt | R.sqrt |
| torch.exp | R.exp |

 **Sources**: [python/tvm/relax/frontend/torch/exported_program_translator.py105-123](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/frontend/torch/exported_program_translator.py#L105-L123) [tests/python/relax/test_frontend_from_exported_program.py96-125](https://github.com/apache/tvm/blob/b16cdecb/tests/python/relax/test_frontend_from_exported_program.py#L96-L125)

 
### Neural Network Operations

 Neural network operators are legalized to `call_te` or `call_tir` after translation.

 
#### Convolution Operations

 Supported via `relax.nn.conv1d`, `relax.nn.conv2d`, etc. The importer handles layout strings like `NCW`, `NWC`, `NCHW`, and `NHWC` [python/tvm/relax/op/nn/nn.py33-34](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/op/nn/nn.py#L33-L34) Transposed convolutions are also supported [python/tvm/relax/transform/legalize_ops/nn.py118-121](https://github.com/apache/tvm/blob/b16cdecb/python/tvm/relax/transform/legalize_ops/nn.py#L118-L121)

 The frontend converts PyTorch data types and symbolic shapes to TVM internal representations.

|---|---|
| torch.float32 | "float32" |
| torch.bfloat16 | "bfloat16" |
| torch.int64 | "int64" |
