## §1 六条算法经验

### 算法经验 NS1：符号 vs 神经的互补

> | | 符号 | 神经 |
> |---|------|------|
> | 精确推理 | ✅ | △ |
> | 模式识别 | △ | ✅ |
> | 可解释 | ✅ | △ |
> | 鲁棒性 | △ | ✅ |
>
> 算法本质：**两者互补**——LLM 的弱点正是符号系统的强点（应用 C2 符号 vs 子符号、IN1 可解释性三层级）。

### 算法经验 NS2：LLM + Lean4 = 形式化推理

> Lean4（定理证明器）+ LLM = AI 数学证明。
> - LLM 提议 tactic
> - Lean4 验证
> - 闭环训练
>
> 算法本质：**LLM 的"直觉" + 形式化的"严谨"**（应用 RL8 RLVR、E4 SRL 谓词中心）。

### 算法经验 NS3：知识图谱 + LLM = GraphRAG（强化 G3）

> GraphRAG = LLM 抽取实体/关系 → 知识图谱 → 图检索 → LLM 答。
>
> 算法本质：**符号（图）+ 神经（LLM）的混合架构**（应用 G3 图结构、E1 远程监督）。

### 算法经验 NS4：神经-符号循环（Neuro-Symbolic Cycle）

> ```
> 神经学符号操作 → 符号执行验证 → 反馈给神经 → 改进
> ```
>
> 算法本质：**与 RL 的"采样-评估-更新"循环同构**（应用 G7 规划-执行-反思、CT6 反馈循环）。

### 算法经验 NS5：LLM 调用工具 = 隐式神经符号

> function calling / tool use：
> - LLM 决策（神经）
> - 工具执行（符号化、确定性）
> - 结果反馈给 LLM
>
> 算法本质：**现代 Agent 本质是神经符号系统**（应用 AG2 工具=action、P6 ReAct）。

### 算法经验 NS6：神经符号的极限

> 挑战：
> - 符号系统的"组合爆炸"
> - LLM 的"幻觉"污染符号推理
> - 两者的接口设计
>
> 算法本质：**neuro-symbolic 是通向 AGI 的可能路径之一**（应用 AG10 Agent 边界、T10 LLM 收编）。
