# 04 · 数据管道：Dataset / DataLoader

> 模型再好，喂数据不对也白搭。数据管道是训练的"血液系统"。PyTorch 的标准范式：**Dataset（取一条）+ DataLoader（拼批/打乱/并行）**。

---

## 一、自定义 Dataset

实现 `__len__` 和 `__getitem__` 即可：
```python
class MyDataset(Dataset):
    def __len__(self): return self.n
    def __getitem__(self, i): return self.x[i], self.y[i]
```
任何数据（图片/文本/表格）只要实现这两个方法就能用 DataLoader。

## 二、DataLoader：批量化 + 打乱 + 并行
```python
dl = DataLoader(ds, batch_size=32, shuffle=True, num_workers=4, pin_memory=True)
for x, y in dl:   # 训练循环里直接迭代
    ...
```
关键参数：
- `batch_size`：每批样本数（小 batch 泛化好但慢，见「讲透泛化02章」）
- `shuffle`：训练=True，验证=False
- `num_workers`：>0 多进程并行加载（大数据/IO 重时加速，注意 fork 开销）
- `pin_memory=True`：GPU 训练时加速 CPU→GPU 拷贝
- `drop_last`：训练时丢弃不满的最后一批（形状一致，利于 compile）

## 三、内置 TensorDataset（现成 tensor 最省事）
```python
ds = TensorDataset(X, Y)   # 已经是 tensor 的一行搞定
```

## 四、WeightedRandomSampler（类别不均衡救星）
检测/医疗/欺诈等少数类任务，给少数类更高采样权重，比过采样高效。

## 五、collate_fn（变长序列拼批，NLP 必备）
文本/图/点云等不规则数据，自定义 `collate_fn` 做 padding 等处理。
