# 03 · 训练循环的正确写法

> 本章是把前面（autograd/module/data）串成"能跑"的关键。PyTorch 训练 = 固定的**黄金 5 步循环**，但每一步都有新手坑。本章讲正确写法 + 三个最常见 bug + 三个进阶技巧（调度器/梯度累积/裁剪）。

---

## 一、黄金 5 步（所有 PyTorch 训练的骨架）

```python
for epoch in range(EPOCHS):
    for x, y in dataloader:
        optimizer.zero_grad()      # 1. 清零梯度(梯度累积, 见01章)
        logits = model(x)          # 2. 前向(建计算图)
        loss = loss_fn(logits, y)  # 3. 算 loss
        loss.backward()            # 4. 反向求梯度(图随后释放)
        optimizer.step()           # 5. 用梯度更新参数
```

这 5 步对应 autograd 机制（01章）：zero_grad（清零）→ forward（建图）→ loss → backward（反向+释放图）→ step（更新）。

---

## 二、三个最常见 bug（实验03 实测）

### Bug 1：忘了 `optimizer.zero_grad()`
梯度累积导致方向越来越乱。实验03 实测：不清零在 SGD 下会崩，Adam 有自适应还能撑但精度下降。
**铁律**：每步必须 zero_grad。

### Bug 2：记录 loss 忘了 `.item()`
```python
history.append(loss)        # ❌ 存了带 grad_fn 的 tensor, 计算图不释放, 内存泄漏
history.append(loss.item()) # ✅ 返回纯 float, 断开图
```
长训练必然 OOM。

### Bug 3：推理/评估忘了 `torch.no_grad()`
推理建图既慢又费内存，还可能污染梯度。
**铁律**：测试/评估一律 `with torch.no_grad():`。

## 三、三个进阶技巧（实验09 实测）

### 3.1 学习率调度器（收敛质量关键）
```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=EPOCHS)
# 每个 epoch 或每步在 step() 后调用 scheduler.step()
```
常用：`CosineAnnealingLR`（平滑衰减）、`OneCycleLR`（先升后降，super-convergence）、`LinearWarmup+Cosine`（大模型标配）、`ReduceLROnPlateau`（loss 不降自动降 lr）。
**铁律**：`scheduler.step()` 在 `optimizer.step()` 之后。

### 3.2 梯度累积（小显存模拟大 batch）
显存只够 batch=32，但想要 effective batch=128：
```python
opt.zero_grad()
for i, (bx, by) in enumerate(loader):
    loss = loss_fn(model(bx), by) / ACCUM_STEPS   # 注意 loss 要除以累积步数!
    loss.backward()
    if (i+1) % ACCUM_STEPS == 0:
        opt.step(); opt.zero_grad()
```
**关键**：loss 除以 ACCUM_STEPS，否则梯度被放大。

### 3.3 梯度裁剪（防爆炸，RNN/Transformer 必备）
```python
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
opt.step()
```
实验09 实测：gnorm 0.15 → 0.05（按比例缩放到 max_norm）。

with torch.autocast("cuda", dtype=torch.float16):   # 前向自动低精度

## 五、完整训练循环模板（整合所有技巧）
```python
scaler = torch.cuda.amp.GradScaler()
for epoch in range(EPOCHS):
    model.train()
    opt.zero_grad()
    for i, (x, y) in enumerate(loader):
        with torch.autocast("cuda"): loss = loss_fn(model(x), y) / ACCUM
        scaler.scale(loss).backward()
        if (i+1) % ACCUM == 0:
            scaler.unscale_(opt)
            clip_grad_norm_(model.parameters(), 1.0)
            scaler.step(opt); scaler.update(); opt.zero_grad()
    scheduler.step()
    # 评估
    model.eval()
    with torch.no_grad():
        ...  # 验证集
```

## 六、批判性视角

- **`model.train()` / `model.eval()` 别忘**：它切换 Dropout/BatchNorm 的行为。评估忘 `eval()` 会让 BN 用 batch 统计、Dropout 还在丢，结果错。
- **数据要 shuffle**（训练=True，验证=False），避免顺序偏差。
- **没有银弹组合**：AMP/scheduler/累积/裁剪按需用，过度堆砌反而难调。
