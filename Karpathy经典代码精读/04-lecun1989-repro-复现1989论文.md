## 0. 为什么复现一篇 35 年前的论文

1989 年 LeCun 这篇论文是深度学习史的里程碑：
1. **第一次**把反向传播 + 卷积网络用在真实工业任务（美国邮政邮编识别）；
2. **第一次**展示了"权重共享（weight sharing）"的威力——用极少参数（9760）做到实用精度；
3. **奠定了 ConvNet 的基本范式**：卷积层 + 下采样 + 全连接，这个范式一直用到 2012 AlexNet、甚至今天的 ResNet。

Karpathy 复现的价值不在"重温历史"，而在一个尖锐的实验问题：**用 1989 年的网络结构（同 9760 参数），加上 33 年后的优化技术（AdamW/dropout/data aug/ReLU），能提升多少？** 答案在 `modern.py` 开头的注释里——读完你会对"深度学习进步到底靠结构还是靠训练"有新认识。

## Step 1 · 1989 ConvNet 的结构（`modern.py` L58-132）

LeCun 的网络极其袖珍，4 层，共 9760 参数：

```
输入: 1×16×16   (邮编数字 16×16 灰度, 背景归一化为 -1)
  │
  ▼ pad 2 + H1: 12 个 5×5 卷积, stride 2
H1: 12×8×8     (12 个特征图, 每个由一个 5×5 核扫出来 → 权重共享)
  │
  ▼ pad 2 + H2: 局部连接（非标准卷积, 见 1.2）
H2: 12×4×4     (每 4 个 plane 各看 8 个输入 plane, 稀疏连接)
  │
  ▼ flatten → H3: 全连接 192→30
H3: 30
  │
  ▼ 输出: 全连接 30→10
out: 10        (10 个数字类别)
```

### 1.1 H1：标准卷积 + 权重共享（核心创新）

```python
self.H1w = nn.Parameter(winit(5*5*1, 12, 1, 5, 5))   # 12 个 5×5 卷积核
# forward:
x = F.conv2d(x, self.H1w, stride=2) + self.H1b       # → 12×8×8
```

一个 5×5 核在 16×16 图上滑动（stride 2），**同一个核的 25 个权重被整张图复用**。这是"卷积"的本质——**局部连接 + 权重共享**。9760 参数里，H1 只占 12×25=300 个。

> 🎯 **对比全连接**：若 H1 用全连接（每个输出像素连到整个输入），光是 H1 就要 (16×16)×(12×8×8) ≈ 200 万参数。权重共享省了 6000 倍。**这是 ConvNet 能用小数据训出来的根本原因**。

### 1.2 H2：稀疏局部连接（1989 的工程妥协）

```python
slice1 = F.conv2d(x[:, 0:8],  self.H2w[0:4],  stride=2)   # 前 4 plane 看 input 0:8
slice2 = F.conv2d(x[:, 4:12], self.H2w[4:8],  stride=2)   # 中 4 plane 看 input 4:12
slice3 = F.conv2d(torch.cat((x[:,0:4], x[:,8:12]), dim=1), self.H2w[8:12], stride=2)  # 后 4 交叉
```

H2 不是标准卷积——每 4 个输出 plane 只连到 8 个（不是全部 12 个）输入 plane。LeCun 1989 论文没写清具体连接模式，Karpathy 用"最合理的块状"猜测。这种**稀疏连接**在当年是为了省算力，今天已基本被稠密卷积取代（GPU 让稠密更高效）。

### 1.3 H3 + 输出：全连接分类头

```python
x = x.flatten(1) @ self.H3w + self.H3b    # 192 → 30
x = x @ self.outw + self.outb              # 30 → 10
```

标准全连接。H3 是参数最多的一层（192×30=5760，占 9760 的 59%），所以现代版在这里加 dropout。

## Step 3 · 33 年的优化进步（`modern.py` 开头注释的实验）

这是这个仓库最精彩的部分。`modern.py` L1-43 记录了 Karpathy 的 5 个实验：**保持网络结构（9760 参数）不变，逐步加现代优化技术**，看 test error 怎么变。数据集是 LeCun 1989 的 7291 训练 / 2007 测试邮编样本。

| 实验 | 改动 | train err | **test err** | misses |
|---|---|---:|---:|---:|
| **repro.py**（1989 忠实）| tanh + SGD + 手调 lr | 0.62% | **4.09%** | 82 |
| Change 1 | tanh 末层 → **softmax + CE** | 0.00% | 4.38% | 87 |
| Change 2 | SGD → **AdamW + lr decay** | 0.00% | **3.59%** | 72 |
| Change 3 | + **data augmentation**（±1 像素 shift）| 1.70% | **2.19%** | 43 |
| Change 4 | + **dropout(0.25) + ReLU** | 1.47% | **1.59%** | 32 |

**铁证**：同样的 9760 参数、同样的数据，**test error 从 4.09% 降到 1.59%——相对降幅 61%**，全靠 33 年积累的训练技巧。

### 三个关键观察

1. **Change 1 揭示"过拟合"**：softmax+CE 让训练集彻底记住（0.00% error），但 test 反而升到 4.38%——**优化太狠反而过拟合**。这是深度学习最常见的坑。

2. **Change 3 的 data aug 是最大单步提升**（3.59%→2.19%）。**平移 1 像素**这种简单增强，效果惊人。现代 CV 全靠 data aug（RandomCrop/Flip/Mixup/CutMix）撑泛化。

3. **Change 4 的 dropout+ReLU 收尾**。dropout 砍掉 H3 的随机 25% 神经元，强制网络不依赖单一路径；ReLU 替换 tanh 解决饱和梯度。两者联手把 test 压到 1.59%。

> 🤯 **反直觉**：你以为"更好的网络 = 更大的模型"？错。**这个实验证明：同样的模型，靠训练方法的进步就能把误差砍掉 61%**。深度学习的进步，**训练技术（优化器+正则化+数据增强）的贡献不亚于结构创新**。

## Step 4 · repro.py vs modern.py：忠实 vs 现代

仓库里有两个版本：

- **`repro.py`（167 行）**：**忠实复现 1989**。用 LeCun 当年的初始化、tanh、SGD、甚至尝试复刻当年的"weight perturbation"训练细节。test err 4.09% 是对论文结果的精确还原。
- **`modern.py`（210 行）**：**结构不变，换现代优化栈**。最终 1.59%。

**对比的教学价值**：你能清楚看到"什么是 1989 年的局限（训练算法），什么是 1989 年已定型（结构思想）"。很多初学者以为深度学习 = 大模型，这个实验打破这个迷思——**小模型 + 现代训练 = 强表现**。

## 三个关键洞察

### 洞察 1 · 权重共享是 ConvNet 的灵魂，1989 已定型

LeCun 的 H1 用 300 个参数（12×25）就能提取 12 种局部特征，靠的是"一个核扫全图"。这个思想比 2012 AlexNet 早 23 年，比"attention 权重共享"早 28 年。**权重复用是深度学习参数效率的根基**。

### 洞察 2 · 训练技术 ≈ 结构创新（进步的两条腿）

`modern.py` 的 5 个实验证明：同样结构，训练技术提升 61% 误差。深度学习的进步是**结构（ResNet/Transformer）+ 训练（AdamW/dropout/aug）两条腿**。只追结构、忽视训练，是新手最大误区。

### 洞察 3 · 历史是最好的祛魅器

很多人觉得"深度学习是 2012 年 AlexNet 之后的事"。LeCun 1989 告诉你：**反向传播 + 卷积 + 多层 + 邮编识别**在 35 年前就跑通且商用（美国邮政真的用了）。AlexNet 不是开天辟地，而是"GPU 让大网络可训 + ImageNet 让大数据可用"的工程突破。**思想早在 1989，爆发在 2012，繁荣在 2017+**。
