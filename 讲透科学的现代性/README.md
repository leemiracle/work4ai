# 讲透科学的现代性（Modernity of Science）

> AI 不只是科学的一个**新工具**——它正在改变"**科学是什么**"。
>
> 本系列是 work4ai 里**最哲学的一篇**——不钻技术细节，反思**科学本身**。三个视角合一：
>
> - **A. 第五范式**（AI 如何改变科学方法论）
> - **B. 可重复性危机**（科学自身的病，AI 是药还是毒？）
> - **C. 科学哲学**（库恩/波普尔/拉卡托斯，AI 的认识论冲击）
>
> 与 [`讲透AI应用全景/01-AI4Science`](../讲透AI应用全景/01-AI4Science.md) **互补**：前者讲"AI 做出了什么科学发现"，本系列问"**AI 改变了什么叫科学发现**"。
>
> 配套：[`讲透AI应用全景/01-AI4Science`](../讲透AI应用全景/01-AI4Science.md) + [`讲透AI应用全景/02-AI4Math`](../讲透AI应用全景/02-AI4Math.md) + [`讲透可解释性`](../讲透可解释性/)（理解 AI 才能谈 AI 科学）

## 为什么单独开

- work4ai 已有 14 个"技术组件"系列 + 1 个"应用全景"系列——**全是"怎么做"**，缺"**这意味着什么**"
- AI4Science 拿 Nobel Prize 2024（Hassabis/Jumper）——AI 不只是工具，是科学方法论的革命
- 可重复性危机是科学自身最大病——AI 同时是**毒**（造假/污染）和**药**（自动化复现）
- 科学哲学被多数 AI 教程忽略，但**库恩的范式转移正在 AI 时代重演**

## 反模式 5 条（L4 工程化）

1. **把 AI4Science 当纯进步叙事** → 忽视可重复性危机。正解：01 + 02 必须一起读。
2. **"AI 发现即理解"** → AlphaFold 给坐标不给理论。正解：读 03 §认识论冲击。
3. **忽视库恩范式转移** → 以为 AI 只是"科学工具升级"。正解：范式转移是"什么算科学"的标准变化。
4. **AI 复现不严格** → 跑一次出结果就发论文。正解：[02] §复现协议 + 多 seed。
5. **用 AI 解释 AI = 哲学终结** → 把 mechanistic interp 当终极理解。正解：[03] §Gödel 边界。

1. **讲透科学的现代性 防的是什么欺骗？** → 经院诡辩 / 选择性报告 / p-hacking。
