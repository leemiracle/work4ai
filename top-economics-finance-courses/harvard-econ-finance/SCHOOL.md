## 三、招牌人物（与本系列主题对应）

| 人物 | 领域 | 对应主题 / 张力 |
|---|---|---|
| **N. Gregory Mankiw** | 宏观经济学 / **《经济学原理》教科书** / 公共政策 | 主题② / 传播最广 |
| **Andrei Shleifer** | **行为金融** / 法与金融 / 制度与转型 | 主题⑦ / **张力①**（"非有效市场"学派代表）|
| **Jeremy Stein** | 公司金融 / 行为金融（曾任美联储理事）| 主题⑥⑦ |
| **Raj Chetty** | **大数据公共经济学** / 机会不平等（用税表数据做因果）| 主题③ / 大数据+因果 |
| **Kenneth Rogoff** | 国际宏观 / 金融（《这次不一样》800 年危机史）| 主题② / 张力③ |
| **Lawrence Summers** | 宏观 / 金融（前财长，影子 CEO of Economics）| 主题② |
| **Claudia Goldin** | 经济史 / 劳动（性别工资差距）| 主题①（2023 诺奖）|
| **David Laibson** | **行为经济学** / 延迟折扣 / 金融决策 | 主题⑦ / 张力① |

> ⭐ **Shleifer vs EMH**：Shleifer 是"市场并非有效"学派的旗手（与 Shiller 同列），其《Inefficient Markets》是反 EMH 的理论纲领。**Harvard 在张力②中站异象一侧**。

## 七、与其他校对比（跨校洞察）

- **vs MIT**：Harvard 偏**公共政策 + 行为 + 案例**（Mankiw/Shleifer/HBS）；MIT 偏**工程 + 因果 + 定量**（Lo/Duflo/Autor）。Harvard 更"面向大众/政策"，MIT 更"面向研究/工程"。
- **vs Chicago**：Harvard 在张力②中偏**异象/行为**（Shleifer），Chicago 偏 **EMH**（Fama）。两校代表 EMH vs 异象的两极。Harvard 宏观教科书（Mankiw）全球最流行，Chicago 价格理论传统更精英化。
- **vs Yale**：Harvard 行为金融靠 Shleifer（法与金融视角），Yale 靠 Shiller（叙事/泡沫视角）。Harvard 计量偏 **大数据应用**（Chetty），Yale Cowles 偏 **理论计量**。
