## 一、为什么要交叉学习

你的最终定位是 **AI 原生量化研究者**——既不是纯经济学家，也不是纯 ML 工程师。**两条腿走路**：

- **经济金融课**：补领域知识（市场结构、定价理论、因果识别、风险管理）
- **讲透 X 系列**：补工程与数学（PyTorch、Transformer、扩散模型、随机过程）

**单腿的问题**：
- 只学经济金融 → 会用 statsmodels/回归，但不会用深度学习定价 / LLM 解析财报
- 只学 ML → 能跑神经网络，但不懂无套利、不懂因果识别、回测必过拟合爆雷

## 三、双向学习建议

### 3.1 金融 → ML/数学 的「补基础」路径

每学一门金融课遇到不懂的工具，回去补对应讲透：

| 金融论文中的概念 | 补这篇 work4ai |
|---|---|
| **Black-Scholes 的 Itô 引理** | [`讲透高维概率`](../讲透高维概率/)（随机过程）+ top-math SDE |
| **因子模型的横截面回归** | [`讲透统计学习理论`](../讲透统计学习理论/)（OLS 几何 / 偏差方差）|
| **GARCH / 波动率建模** | [`讲透概率图模型`](../讲透概率图模型/)（隐马尔可夫 / 状态空间）|
| **DiD / 合成控制因果识别** | [`讲透因果推断`](../讲透因果推断/)（Pearl / 反事实）|
| **神经网络期权定价 (Neural SDE)** | [`讲透基础模型`](../讲透基础模型/) + [`讲透优化理论`](../讲透优化理论/) |
| **LLM 解析财报 (FinGPT)** | [`讲透LLM`](../讲透LLM/) + [`讲透RAG`](../讲透RAG/) + [`讲透微调`](../讲透微调/) |
| **RL 做市 / 组合优化** | [`讲透RL`](../讲透RL/)（DQN/PPO/RLHF）|
| **图神经网络反欺诈** | [`讲透多Agent协作`](../讲透多Agent协作/)（网络拓扑）|
| **多因子稳健性（过拟合）** | [`讲透泛化`](../讲透泛化/)（正则 / 双层下降）|
| **市场涌现（ABM）** | [`复杂系统学-处理work4ai`](../复杂系统迭代work4ai.md)（SOC / 相变）|

### 3.2 ML → 金融 的「快速验证」路径

每学完一篇 ML 主题，找一个金融场景验证：

| ML 主题 | 金融验证 |
|---|---|
| **讲透Transformer 的自注意力** | 时间序列预测（股价/GARCH 替代）|
| **讲透RL 的 PPO** | 简化做市 RL 环境（库存管理）|
| **讲透RAG 的检索** | 财报/新闻问答系统（FinGPT 雏形）|
| **讲透扩散模型 的 score matching** | 隐含波动率曲面生成 / 生成市场情景 |
| **讲透微调 的 LoRA** | 在财经语料上微调 LLM（BloombergGPT 思路）|
| **讲透优化器 的 SGD** | 组合优化（均值-方差 / 风险平价）|
| **讲透因果推断** | 因子因果识别（避免数据挖掘伪因子）|

## 六、典型学习路径示例

### 路径 A：从 0 到量化研究员（2-3 年）

```
第 1 阶段（地基，6 个月）
  ├─ MIT 14.01 微观 + 14.05 宏观              → 直觉
  ├─ MIT 14.32 计量 + 讲透因果推断            → 相关≠因果
  └─ 讲透PyTorch + 讲透基础模型               → 工程地基

第 2 阶段（定价，6 个月）
  ├─ Yale ECON 545 / Chicago FIN 552 资产定价  → CAPM/因子
  ├─ MIT 15.405 / CMU 46-944 衍生品           → Black-Scholes
  ├─ top-math SDE + 讲透高维概率              → 随机分析补强
  └─ finance_demos.py 实跑                    → 验证

第 3 阶段（量化，6 个月）
  ├─ Oxford OMI / Berkeley Haas 风险管理      → VaR/CVaR/压力测试
  ├─ 讲透RL + 讲透多Agent协作                 → RL 做市
  ├─ 讲透AIfor各学科/经济金融                 → AI for Finance 前沿
  └─ 复现 3 个经典因子（动量/价值/低波动）    → 回测训练

第 4 阶段（弯道超车，6+ 个月）
  ├─ LLM for Finance（FinGPT 复现）
  ├─ Neural SDE 定价
  └─ Kaggle / QuantConnect 实战
```
