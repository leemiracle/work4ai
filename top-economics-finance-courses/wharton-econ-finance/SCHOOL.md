## 三、招牌人物（与本系列主题对应）

| 人物 | 领域 | 对应主题 / 张力 |
|---|---|---|
| **Franklin Allen** | **公司金融**（《Principles of Corporate Finance》与 Myers 合著）/ 金融系统性 / 危机 | 主题⑥② / 张力③ |
| **Andrew Metrick** | 金融 / 对冲基金 / 影子银行（《The Financial Crisis Inquiry Report》贡献）| 主题⑥⑧ / 张力③ |
| **Jessica Wachter** | **资产定价** / 长期收益 / 不确定性与风险 | 主题④ |
| **Lu Zhang（张橹）** | **投资 q 因子理论**（Investment CAPM / q-theory）| 主题④⑧ / **张力② 前沿**（挑战 Fama-French）|
| **Itay Goldstein** | 金融中介 / 银行挤兑 / 系统性风险 | 主题⑧ / 张力③ |
| **Michael Roberts** | 公司金融 / 实证资产定价 | 主题④⑥ |
| **Nikolai Roussanov** | 资产定价 / 财富不平等 / 行为 | 主题④⑦ |
| **Uri Ronnen（Ron Kaniel）** | 金融 / 信息不对称 | 主题⑦ |

> ⭐ **Lu Zhang 的 q 因子理论（Investment Factor Model）**是 2010s 资产定价领域最重要的理论突破之一——它**挑战 Fama-French 因子的解释力**，提出用"投资增长率"替代"规模+价值"因子。**Wharton 是因子投资理论前沿的战场**（张力②）。Franklin Allen 的《Principles of Corporate Finance》（与 Brealey/Myers 合著，BBM 教科书）则是全球公司金融教学的标准教材。

## 七、与其他校对比（跨校洞察）

- **vs Chicago**：Wharton 资产定价靠 **Lu Zhang q 因子（挑战 Fama-French）**；Chicago 靠 **Fama-French 三/五因子（EMH 基础）**。**两校在张力②中形成"因子 vs q 因子"的理论对决**。Wharton 公司金融（BBM 教科书）全球第一，Chicago 公司金融相对低调。
- **vs MIT**：Wharton 金融偏 **公司金融 + 固定收益（实务/工程）**；MIT 金融偏 **衍生品 + 因果（研究/政策）**。Wharton 更"华尔街"，MIT 更"学术界"。
- **vs Yale**：Wharton 金融是**理性/因子派**（Lu Zhang 从投资理性推导因子）；Yale/Shiller 金融是**行为/叙事派**（泡沫/非理性）。两校在资产定价理念上形成张力①②的对立。
