## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透特殊教育学/                 GB/T 88064(无三级明细,自定主干支)
├── 讲透特殊需要教育/           自定支——理论层:谁被标记(SEN 通论/标签与鉴定/需要连续体/超常与双特殊)
├── 讲透融合与全纳教育/         自定支——制度层:在哪里学(回归主流-IDEA-萨兰斯克-全纳的范式迁移)
└── 讲透干预与辅助技术/         自定支——实践层:给什么支持(循证干预/RTI 分层/UDL/辅助技术)
```

> 三支的共同血统:**同一个分界问题的三层展开**——理论层问
> **谁**越过分界(标记),实践层问越过之后**给什么**(响应),
> 制度层问给的时候**在哪里**(安置)。三层合成"识别→响应→
> 安置"的完整回路,范式迁移(缺陷学→全纳)同时改写三层。
