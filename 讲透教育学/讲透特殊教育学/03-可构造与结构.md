# 03 · 可构造与结构:哪些特殊教育的对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:特殊教育学的对象沿一条**可构造谱系**排开——
> IEP 文档结构/干预方案 schema/进度监控数据表端**严格可构造**
> (表写得全、口径挂得上、可进数据库),鉴定标准与循证分级
> 端**半构造**(分级框架可造,成员判定与"循证"边界是判断),
> "适当的教育"/需要本体/全纳的"参与"端**不可构造**(只有
> 诠释与个案权衡,没有构造学);全谱系共享两条互为反相位的
> 结构引擎:**个别化**(把支持落到单生单案)与**标准化**
> (把干预做成可复制的处方)——这门学科的全部构造史,就是
> 这两台引擎互相较劲的历史。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手
> 构造一次**。

---

## 开篇:一条谱系,两个极端

想象把特殊教育学的所有对象按"能不能直接造出来"排一条线:

```
IEP 文档 schema ── 干预方案 schema ── 进度监控数据表 ── 安置连续体 ── 鉴定标准/循证分级 ── "适当的教育"/参与/需要本体
(目标/服务/安置/复评) (剂量/保真度/判据) (学生×波次×分数)  (有序等级表)   (框架可造,判定是判断)   (只有诠释与个案权衡)
严格可构造(可编码入库) ────────────────────────▶ 不可构造(只有案例学/诠释学)
  └── 表/schema/判据,可复核可复用                    └── 只能深描、权衡,禁止硬造参数
```

为什么会有这条谱系?**可构造的前提是"有限描述+公共语义+
可判定成员资格"**([教学论 03 章](../讲透教学论/03-可构造与结构.md)
的判据在此复用):IEP 的语义是"目标-服务-安置-复评"四栏,
一条记录进不进表,两个管理员可以判定;而"适当的教育"
(FAPE 的 appropriate)没有成员资格判定——它是判例法与个案
权衡的诠释对象,问卷能测其投影(满意度),不能构造其本体。
本章先盘家底(严格可构造三件+半构造一件),再看两条引擎,
最后数刚性。

## 一、可构造性家底盘点(四大构造物详解)

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| IEP 文档 schema | 表:现表现水平(基线)/年度目标+可测基准/服务与安置(分钟数/地点)/评估调整/转衔计划/参与者与复评日程;各国法定模板为其现实锚 | 低-中(模板一天建好,目标写得"可测"要做十年) | 目标的可测性:写"提高阅读能力"的目标进不了库——**不可测目标在 schema 层就是脏数据**;服务分钟数常是谈判结果而非服务真相 |
| 干预方案 schema | 处方式表:对象特征筛选/剂量(频率×时长×轮次)/实施者与培训/保真度检查表/结局测量/决策规则(响应判据);循证干预文献为其填充内容 | 中(方案化要求文献给出剂量与判据,很多"有效干预"给不出) | 名义保真与实际保真的缺口:**"采用了方案"可编码,"做对了没有"要另测**——缺保真度列的干预表是安慰剂容器 |
| 进度监控数据表 | 学生×波次×分数的纵向表(课程本位测量 CBM 的高频小测);斜率与决策规则挂在表上 | 低(表结构平凡,采集纪律昂贵) | 回归均值:初测极端者复测自然回落——**不挂测量误差与波次口径的进度表会制造假响应/假非响应**(02 章 §二) |
| 安置连续体(Deno 瀑布) | 有序等级表:普通班→普通班+辅助→资源教室→分离班→特殊学校→居家/医院,按"限制程度"排序 | 低 | **半构造**:等级排序可造,但"最少限制"的个案权衡不可造——同一名学生两个合法落点,表无法裁决(00 章 §四全纳边界) |

**亲手构造一次(三个最小样例)**:
- IEP:给一个熟悉的学生的学习困难写一行**可测**年度目标
  (条件+行为+标准+时限),再写服务列(谁/多少分钟/在哪)
  ——写不出可测标准的目标,就是"适当的教育"在 schema 层
  漏出来的形状。
- 干预方案:给一项你见过的教学补救写成处方:剂量(每周几次
  ×每次多久×共几周)+保真度怎么查+响应判据(几周后斜率
  不达多少算非响应)——**写不出剂量与判据的"方法",不是
  方案是愿景**。
- 进度表:给一组(虚拟)学生建 8 波次监测表,画两条决策线
  (目标线/双差异线),看谁被规则判为"非响应"——换一条
  决策线,名单就换一批(家族实验断言①的另一个化身)。

## 二、结构引擎 1:个别化——把权利落到单生单案

**直觉图像**:教育系统的默认单位是"班级-课程-年级";特殊
教育把默认单位打碎为"**单个儿童的单个方案**"——IEP 是这台
引擎的核心构造物:权利(IDEA/FAPE)必须经过它才能兑现成
具体的服务分钟数与安置地点。

- **可构造化身**:IEP schema 的四栏(基线/目标/服务/复评)
  是权利的**可机读投影**——没有这四栏,"适当的教育"只是
  一个形容词。
- **刚性从哪来**:**程序锁定**。IEP 是法律文件:会议法定、
  参与者法定、复评周期法定、争议有程序出口——刚性不是来自
  表格,而是来自表格背后的**举证责任结构**(00 章美之时刻 2)。
  代价是个别化的算术:一生一案×文书成本=教师负荷
  (01 章主线 D)——**个别化的刚性以劳动时间计价**。

## 三、结构引擎 2:标准化——把干预做成可复制的处方

**直觉图像**:个别化若无标准件,每案从零发明,则质量随教师
个人天赋漂移;标准化把"有效做法"翻成**剂量-步骤-判据**
的处方(RTI 三层是它在系统级的形态),使干预可培训、可复制、
可审计。

- **可构造化身**:干预方案 schema 与循证分级表(WWC 式的
  设计质量分级)——"循证"从形容词变成可核查的等级列。
- **刚性从哪来**:**复现的自锁**。一个方案一旦被标为"循证"
  并进入采购与培训体系,后续修订要重新过证据门槛——版本
  刚性与[教育管理学 03 章](../讲透教育管理学/03-可构造与结构.md)
  的指标路径锁死同构;代价是**好方案的半衰期被低估**
  (对象群体在变,处方的证据在老化)。
- **两台引擎的相位关系**:个别化引擎说"每个孩子都不同",
  标准化引擎说"好做法要可复制"——**IEP 的目标行(个案的)
  引用干预方案的标准件(处方的)**,是两台引擎的焊接点:
  焊得好是个别化的循证,焊不好是"千人一方的个别化"或
  "无从下手的标准化"。

## 四、反直觉发现(本章铁律)

**越靠近"需要"本体的构造物,越容易被 schema 的光洁度冒名**。
IEP 表格可以填得完美(四栏齐全、目标"可测"、分钟数清楚),
而"适当"本身无人能验——**文书完备性幻觉**:一份程序完美
的 IEP 可以包裹一套低于能力的教学(家族实验断言③的制度
形态)。这与[教育管理学 03 章](../讲透教育管理学/03-可构造与结构.md)
的正式结构完备性幻觉同一条铁律:**构造物的光洁度≠服务的
效度**;谱系上越靠右的构念(适当/参与/需要),谁宣称把它
"做成了系统",谁就在过度承诺。可构造的部分(表/处方/数据)
要尽力构造——但**判定权留在不可构造的那一侧**,是这门
学科的制度清醒。

## 五、谱系左端的三个对象,结构上长什么样(小结)

| 构造物 | 数学形状 | 一句话 |
|--------|---------|--------|
| IEP 文档 schema | 目标×服务×安置×复评的关系表(带法律元数据) | 权利的可机读投影 |
| 干预方案 schema | 剂量×保真度×判据的处方式表 | 教学法→可复制对象 |
| 进度监控数据表 | 学生×波次×分数的纵向表+决策规则 | 响应的证据容器 |

三个构造物合成特殊教育学的"可机读层"——04 章的代码走廊
全部建在这一层上;谱系右端(适当/参与/需要本体)则划出
走廊的边界。

## ✨ 美之时刻(彩蛋第 5 枚:可测目标列)

✨ **美之时刻 5:IEP 的目标列——把不可构造强行翻译的地方**
(极简)IEP 里最朴素的一列是年度目标,法定要求**可测**
(条件+行为+标准+时限)。"适当的教育"这个不可构造的构念,
在每一行目标上被强制翻译成可核查的句子——翻译处就是缝合
处:写得好的目标行,是教育意图与证据纪律的焊接;写得坏的
(学期末"有所提高"),是构念漏气的地方。为什么美:这一列
让"个别化"从哲学立场变成**可审计的写作行为**——评估、
期望、进步全部汇到一行句子上,学科的两难(个别 vs 标准)
在一行文字里短兵相接。亲历:把一条"提高社交能力"改写成
可测版本,数一数你被迫做出的决定(测什么/谁来测/多少算
够)——**每个决定都是一次微型教育哲学**。

## ✍️ 练习

1. ✋ 按 §一样例给一项学习困难写完整的 IEP 目标行(含基线),
   再自查:这条目标换个教师来判,达标与否会一致吗?
   不一致处即"可测性"的裂缝
2. ✋ 把你熟悉的一套教学方法写成处方(剂量/保真度/判据),
   标出哪几栏文献给不出来——给不出的栏,就是"经验"与
   "方案"的分界
3. ✋ 给一组(虚拟)学生建 8 波次进度表,用两条不同严苛度
   的决策线各判一遍"非响应"名单——两份名单的差异处,
   就是决策规则(而非儿童)在定义"响应不足"
4. ✋ 反驳练习:为"适当的教育也可以做成评估系统"写三条
   最强论据,再用 §四文书完备性幻觉给每条划出对与错的
   部分

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:构造分层之眼**——看到任何特殊教育数据
产品(IEP 模板/干预平台/监测看板),先问它住在谱系哪一段:
IEP 与干预 schema(可编码)、鉴定标准与循证分级(半构造,
判定在外)、"适当"与"参与"(只能诠释)。住在左端的可以进
数据库、可以被复核;住在右端的谁宣称把它"做成了系统",
谁就在过度承诺;住在中间的(安置连续体/鉴定标准)——形式上
最可复现,个案上最需要人的判断。
