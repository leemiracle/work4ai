> (扩大与替代沟通)。三支中**工艺气质最浓**的一支:它问的是
> 特殊教育的"处方层"——干预凭什么有效、保真度怎么测、技术

## 诞生

- **谁/何时**:谢根生理学方法(1846,任务分解+感官训练——
  行为干预的直系祖先);蒙特梭利(1898-1900,感官教育从
  "缺陷儿童"训练起步,1907 反哺普通教育);布赖叶盲文
  (1829,辅助技术的通约原型);单一被试实验设计传统(N=1
  的证据学);循证运动与 WWC 证据标准(2000s);RTI/MTSS
  (2004 入法);UDL(CAST 线,从建筑通用设计借来);AAC 与
  消费级辅助技术、AI 支持线(01 章主线 B)。
- **因什么问题**:①"有效"的主张凭什么被相信(证据等级)
  ②实验室有效的方案在普通学校走样怎么办(保真度与实施科学)
  ③支持的强度怎么分层(80/15-20/5 金字塔与转介减压)
  ④技术的目标:等价通道还是降级替代(通约 vs 替代)。

## 核心问题

**已解决**:
- 循证干预的证据基建:设计质量分级+效应量合成——WWC 通说
- RTI 三层体系:先教再测,鉴定与教学失败分离——2004 范式
- UDL 三网络:预先设计可及而非事后补救——框架通说
- AAC/辅助技术从专用硬件到系统内置(门槛数量级下降)
  ——趋势通说

**未解决/深水区**:
- **保真度缺位**:合成的常是"名义干预",实施走样算同一处理
  ——证据合成的系统性漏洞(02 章 §二)
- **调节变量**:"对谁、在什么条件下有效"的分层证据长期稀缺
  (01 章主线 B)
- **AI 的双面**:阅读支持/实时转写的通约加速 vs 评估辅助的
  越权与"技术替代人际支持"的成本论复现(04 章落点 3)
- **实施条件即效果**:第一层教学质量决定整个 RTI 鉴定体系的
  地基(00 章美之时刻 3 的债)

## ✨ 这支最美的一个事实

**蒙特梭利的反哺:特殊教育的方法两次喂养普通教育**(通说
转述)。1898-1900 年,意大利第一位女医学博士蒙特梭利在矫正
学校用感官教育训练"缺陷儿童",成效引起注意;1907 年她把
同一套教具与自组织课堂搬进罗马贫民区的儿童之家(Casa dei
Bambini)——蒙氏教育从此成为普通教育最著名的品牌之一。百年
后 UDL 是第二次反哺:为特殊需要设计的通用可及性(字幕/多
模态/多元表达)反哺为所有人的默认设计。为什么美:**特殊
教育不是普通教育的维修车间,而是普通教育的研发实验室**
——差异侧长出的工艺,一再成为通用侧的标准配置。
