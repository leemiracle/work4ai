# 讲透特殊需要教育 · 谁被标记——SEN 通论与分界之争

> **定位句**:这支负责"**理论层**"——特殊教育需要(SEN)的通论:
> 标签与鉴定、需要连续体、分界之争(类别/连续体/响应三种姿态,
> 家族 00 章 §四的完整展开)、超常与双特殊(2e)。三支中**理论
> 气质最浓**的一支:它问的是特殊教育的"宪法层"——谁算特殊、
> 由谁按什么程序判定、标签换资源的价格表。障碍的医学与心理
> 本体住医学/心理学(两宇宙未建,文字提及);分层的**实施**住
> [干预与辅助技术支](../讲透干预与辅助技术/README.md),
> 安置的**制度**住[融合与全纳教育支](../讲透融合与全纳教育/README.md)。
> GB/T 13745 88064 特殊教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透特殊教育学](../README.md)

## 诞生

- **谁/何时**:伊塔报告(1801/1806,个案化的起点);比奈-西蒙
  量表(1905,分类测量的双面里程碑);IDEA 十三类别(1975,
  类别的权利化);沃诺克报告(1978,SEN 概念:需要连续体,
  约 20% 在校期间某阶段有特殊教育需要);IDEA 修订(2004,
  RTI 允许替代差值鉴定——响应论入法);双特殊(2e)研究线
  (高能力与障碍并存的识别盲区)。
- **因什么问题**:①谁有权把一个儿童标记为"特殊"(鉴定的
  程序正义)②类别、程度还是响应——分界划在什么上(资源闸门
  的设计)③偏离不分方向:超常与双特殊把"特殊"从"低于常态"
  还原为"任何方向的偏离默认值"(中文教材通说:超常儿童属
  广义特殊儿童)。

## 核心问题

**已解决**:
- 沃诺克概念:需要是程度与阶段,不是身份与终身——教材共识
- 鉴定-服务链条的制度化(无鉴定则无服务的门票逻辑及其批评)
  ——通说
- RTI 把"落后"从儿童特质改为教学响应——2004 修订的范式转换
- 超代表(disproportionality)作为标签社会建构面的长期证据线
  ——综述级通说

**未解决/深水区**:
- **分界之争无终局**:类别/连续体/响应三姿态各治彼此的病
  (00 章 §四)——分界是资源配置的闸门,由预算与权利共同决定
- **标签的双刃计量**:资源入口的收益与污名/误标自证(实验
  断言③)的损失如何同表核算,没有公认方法
- **2e 双盲区**:高能力掩盖障碍、障碍掩盖高能力——两套类别
  体系对同一儿童都是测量盲区

## ✨ 这支最美的一个事实

**伊塔的 1801 年报告,是一份提前两百年出场的 IEP**(通说转述):
基线评估(维克多能做什么)、目标分解(社交/情感/语言分列)、
逐日实施(感觉训练方案)、进度检讨(第一年末与第五年的两次
总结)——个别化教育计划的全部要素在阿韦龙野孩身上首次同台。
1975 年 IDEA 把这套结构写进法律时,没有发明任何新东西,只是
给伊塔的格式加了强制力。为什么美:学科的"宪法文件"诞生于
一场自认失败的实验——**制度的光,常常是最初的失败点燃的**。
