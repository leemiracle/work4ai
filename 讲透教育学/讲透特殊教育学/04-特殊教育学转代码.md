# 04 · 特殊教育学转代码:把识别-响应-安置搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**。
>
> **本章一句话**:特殊教育学的可机读层(03 章谱系左端)几乎
> 可以无损转码,"适当的教育/需要本体/全纳的参与"不可转码;
> 三条代码走廊——**筛查权衡、分层减压、标签自证**——把
> "阈值划在哪、早干预省多少、误标会不会成真"分别变成可跑、
> 可断言、可做敏感性扫描的实验;外加一条防御走廊(证据合成)
> ——它模拟的不是教育,而是"循证"宣称的可复算底稿。

---

## 开篇:不是"能不能转",是"转到哪一层"

特殊教育学转代码要解决"**识别与响应的可形式化**":把"谁
被标记、支持怎么分层、标签怎么反馈到成就"先翻成明确的数据
结构与动力学规则,再翻成代码。翻译的损耗发生在**阈值与构念**
的建模上——所以本章第一条走廊不是模拟学校,而是模拟"筛查
这套读法本身漏掉了什么"(与高等教育学家族的阶段走廊同款
自觉)。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 特殊教育学概念 | 代码化身 | 备注 |
|----------------|---------|------|
| 筛查阈值敏感性 | 双分布风险分数+阈值扫描+TPR/FPR 曲线 | 家族实验断言①全程纯标准库;权衡是数学不是善意 |
| RTI 三层流量 | 全体-小组-个别的流模型+响应概率+转介率 | 断言②:第二层有效则第三层转介至少减半 |
| 标签的期望效应 | 指令匹配-成就动力学(误标→降档→缺口扩大) | 断言③:自我实现标签的机制玩具 |
| IEP/干预 schema | 结构校验(目标可测性/剂量/保真度列完备) | 03 章构造物 1/2 的直接实现 |
| 进度监控决策规则 | 波次表+双差异线/斜率判据 | 换判据换名单的敏感性演示 |
| 证据合成 | 效应量加权合成+异质性检查 | 防御走廊(循证宣称的复算) |

**转不动/转不动的边界(红色区)**:

1. **诊断与鉴定判定**:诊断是临床权限,代码只能提示风险
   与权衡——任何"从行为描述直接生成标签"的系统是越权品
   (落点 3 的红线)。
2. **"适当"与"最少限制"的个案权衡**:多目标不可通约
   (发展/尊严/资源),禁止合成单一优越安置分——合成即
   价值判断,不归代码管。
3. **干预效果的无保真度推断**:未测保真度的"无效"结论
   同样越权——模型分不开"方案无效"与"实施走样"
   (02 章 §二)。
4. **期望与污名的社会动力学全模型**:断言③只演示单机制
   的充分性,不做总量断言(实验纪律)。

**边界的一句话**:绿色区=03 章谱系左端三构造物+两条引擎的
参数化;红色区=谱系右端——**先问构造学,再谈转码**(与
[教育管理学 04 章](../讲透教育管理学/04-教育管理学转代码.md)
同一条铁律)。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:筛查权衡走廊(模拟"划线的语法")

```
风险分数 = 真实需要 + 测量噪声 ──阈值 τ──▶ 标记|不标记
      │                                    │
      └──阈值扫描──▶ TPR(τ) 与 FPR(τ) 同涨同落:分布重叠 ⇒
                      无 τ 同时达成 TPR≥0.90 且 FPR≤0.10(断言①)
```

- **理论→模型**:真实需要是潜在变量,筛查只能看带噪分数;
  两分布(多数低风险/少数高风险)重叠度决定权衡的松紧。
  阈值每降一档,多抓的真阳性与多收的假阳性同到——**权衡
  是结构性的,不是技术不过关**。
- **算法层**:阈值扫描+TPR/FPR 联动曲线+分布重叠度
  (分数序对的分离概率)校验;敏感性:改噪声量级,
  重叠升则权衡恶化。
- **本家族实现**:[`experiments/rti_tiers.py`](experiments/rti_tiers.py)
  断言①——高敏感档(TPR≥0.90)的假阳性率不低于既定下限,
  且不存在"双达标"阈值;降阈值 TPR 与 FPR 同升。
- **真实系统**:筛查工具选型的审计件(cut score 的两误
  并排呈现);"提高筛查敏感度"政策表述的代价核算。
- **性能工程要点**:TPR/FPR 必须同报——只报其一的报告
  是ROC 曲线上的一句真话加一句沉默。

### 走廊 2:RTI 分层走廊(早干预减压的算术)

```
第一层(全体)──筛查──▶ 第二层(约15-20%)──响应?─是─▶ 回第一层
                                        │否
                                        ▼
                              第三层(约5%:个别化+IEP)
对照世界:无有效第二层(标记直送第三层)──▶ 转介率对照(断言②)
```

- **理论→模型**:三层金字塔(80/15/5 量级);第二层有效性
  以响应概率参数化;转介率=第一层漏网+第二层非响应。
- **算法层**:两个世界并行跑(有效第二层 vs 直送式),
  转介率对照+金字塔占比校验;敏感性:响应概率从高到低
  扫描,减压效果单调减弱。
- **本家族实现**:断言②——第二层有效时第三层转介率降至
  对照世界的约一半以下;金字塔占比落在通说量级带内。
- **真实系统**:学校支持体系配置的推演(第二层容量/效果
  的两本账);"早干预减压"叙事的量化底稿。
- **性能工程要点**:第二层的**效果参数**是政策变量
  (培训/师训投入改变它)——把响应概率做成可调参数,
  是本走廊的正确用法(与高等教育学容量弹性同款纪律)。

### 走廊 3:标签自证走廊(期望-成就动力学)

```
误标(假阳性)──▶ 教学降档(目标/节奏/内容低于能力)
     │                                   │
     │ 对照:同能力正确教学 ──▶ 正常增长   ▼
     └──────▶ 成就缺口逐期扩大(自我实现标签,断言③)
```

- **理论→模型**:成就增长是指令匹配的函数;误标经由制度
  响应(降档教学)而非标签本身压低成就——**标签自证的
  通路是教学,不是心理魔法**。
- **算法层**:同能力两组对照+逐期缺口轨迹;敏感性:
  降档强度参数扫描(轻度降档即可起缺口,还是重度才起)。
- **本家族实现**:断言③——初测两组无差,终测缺口显著且
  逐期扩大;降档越重缺口越大。
- **真实系统**:鉴定-安置流程的伦理审计件(误标的下游
  不只是"白担心",而是真实损失);"层=支持强度还是能力
  等级"的执行检查。
- **性能工程要点**:对照组必须同分布(能力匹配)——随便
  找两组比缺口是选择偏差;降档机制要显式建模,否则结论
  变成"标签有魔法"的伪因果。

### 走廊 4:证据合成走廊(防御性:循证宣称的复算)

```
效应量表(k 研究)──加权合成──▶ 总效应 ──异质性检查──▶ 可转述|需分层
      │                                        │
      └──留一/加权扫描──▶ 总效应的稳定性(名字冒充证据的暴露面)
```

- **理论→模型**:循证宣称=效应量合成的结果;合成的稳定性
  (去掉最大研究后结论是否翻面)与异质性(总效应掩盖的
  条件差异)是宣称的暴露面。
- **算法层**:加权合成+留一稳定性+异质性粗检;与
  [比较教育学](../讲透比较教育学/04-比较教育学转代码.md)
  的排名敏感性走廊共用"扰动看翻面"方法论,特教版聚焦
  效应量(而非名次)。
- **真实系统**:干预产品"循证"宣称的复算工具;采购评审
  的底稿(证据等级与稳定性并排)。
- **性能工程要点**:轻;价值在**总效应从不单独说人话**
  ——并排呈现合成值与移除极值后的值,永远比单一数字诚实。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:IEP/干预数据管道——先装口径,再装数字

- 接入任何特教数据(鉴定/服务分钟/干预记录)的工程纪律:
  第一层表是**口径元数据**(类别体系版本/诊断代码表/服务
  分钟的计量口径/保真度是否有列),第二层才是数值;没有
  第一层的管道,下游一切"达标率/转介率/效果对比"都在
  裸奔(02 章口径纪律)。
- 快速诊断:一个特教看板若直接渲染"特教率"却不挂类别
  体系与鉴定程序版本,跨校比较就是口径事故现场
  (01 章主线 D)。

### 落点 2:筛查与分层的两误审计——把权衡摆上桌

- 走廊 1+2 可整体外借:任何"调整筛查标准/增设支持层"的
  方案,先跑两误并排与转介率推演——**多抓谁、多漏谁、
  第三层挤不挤**,三个数出来之后价值辩论才有靶子。
- 快速诊断:只给"更灵敏"不给假阳性清单的筛查升级方案,
  与不给账单的理念声明同构(00 章 §四立场句)。

### 落点 3:LLM 时代的红线——诊断越权与标签生成

- LLM 擅长把行为描述流畅地翻成诊断语言("注意力涣散→
  多动倾向")——它越权的地址恰是红色区:**诊断与鉴定
  判定不可构造**(§一第 1 条)。工程红线:面向家长/教师
  的系统禁止从自然语言描述生成标签或类别判断;个性化
  支持(UDL 式内容调整)是正业,诊断分类是禁区——两者
  的分界要在产品层硬编码,不靠提示词自觉。
- 走廊 2/3 的流模型与动力学是 LLM 的好搭档:把转介率与
  误标代价变成可核查的数字,而不是会议里的一句话。

   ——把筛查噪声从基准加大 50%,看断言①的"双达标禁区"
   如何放宽或收紧;再把第二层响应概率降到 0.30,看断言②
   的减压效果垮到多少——两处参数就是两种现实主张的化身
2. ✋ 用走廊 1 给一份真实筛查工具的 cut score 生成两误
   并排件:TPR/FPR 各多少?哪个群体为高敏感买单(假阳性
   的名单分布)?
3. ✋ 用走廊 4 的留一法复算一份干预元分析的结论:去掉
   最大的研究后总效应还站得住吗?并排呈现两个版本
4. ✋ 用走廊 3 写一份"误标代价"审计表:从误标到降档到
   缺口,链条上哪几环可以加保险(复评周期/降档审批/
   层级可逆)——逐环写出工程对策
