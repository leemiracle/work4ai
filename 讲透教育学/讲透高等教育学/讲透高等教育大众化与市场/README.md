# 讲透高等教育大众化与市场 · 规模怎么进入系统——阶段、分层与全球联赛

> **定位句**:这支负责"**规模层**"——扩张的大潮进入系统后发生
> 什么:特罗阶段论(精英/大众/普及的转型问题清单)、分层系统
> (加州规划式设计与自发声望排序)、市场化与评估(学术资本主义/
> 新公共管理)、排名与"世界一流"全球模板(ARWU/QS/THE 作为
> 研究对象)、中文语境的学科建设与"双一流"研究。三支中**政策
> 气质最浓**的一支:它问的是规模的分配正义——**增量去了哪一层、
> 谁为排名买单、市场逻辑改写了什么**。

> 家族:[讲透高等教育学](../README.md)

## 诞生

- **谁/何时**:加州高等教育总体规划(1960,三层系统+转学通道,
  "用分层吸收大众化"的制度样板);特罗阶段论(1973,GER 15%/50%
  阈值+转型问题清单,后经特罗本人修订);斯劳特-莱斯利《学术
  资本主义》(1997,院校为外部资金而市场行为化);ARWU(2003)/
  QS(2004)/THE 刊行,排名时代开启;中文语境"211/985 工程"
  及"双一流"建设(按文献通说作为研究对象)。
- **因什么问题**:①需求爆炸后规模与质量如何兼容(阶段论)
  ②扩张的增量如何分配(分层与 MMI/EMI)③全球可比的度量把大学
  变成了什么(排名构念与使命漂移)④市场与评估机制改写了办学
  逻辑吗(学术资本主义)。

## 核心问题

**已解决**:
- 阶段论成为全球对表工具(其启发式本义被特罗明确声明)——教材共识
- 分层吸收扩张的机制清楚:次线性容量增长+残差吸收=分层虹吸
  (家族实验断言②)——机制共识
- 排名的方法学批评成为教科书内容(科研主导/权重任意/聚合掩盖
  学科分布)——通说
- 加州规划的复制难度与语境依赖被记录(移植研究口径)——通说

**未解决/深水区**:
- **大众化与精英质之争**:分层是解药还是不平等的再生产
  (MMI 说增量不消灭差距,加州说分层接住洪峰)——两论并存无裁决
- **"一流"的构念效度**:排名量的是科研产出,政策说的是整所
  大学——构念搬家谁来验收(01 章主线 B)
- **文凭通胀 vs 人力资本**:扩张的社会流动净效应,两论长期并存
  ([教育社会学](../../讲透教育社会学/README.md)机制层互链)

## ✨ 这支最美的一个事实

**特罗的坦白:阈值是叙事构造**。15% 与 50% 被全世界当作阶段
界碑引用,而特罗本人反复声明阶段论是启发式、阈值不是自然断点。
家族实验把它形式化:GER 是单调连续曲线,穿越阈值年的一切状态量
变化都不超过自身常态的 1.15 倍——**唯一阶跃的对象是"阶段"
这个词**。为什么美:一个学者在自己最著名的数字上公开示弱,
反而让阶段论活了五十年:从预测模型降级为转型问题清单,
数字与叙事各归其位(与[比较教育学](../../讲透比较教育学/README.md)
"阈值-叙事"方法论互为镜像)。
