> **定位句**:这支负责"**劳动层**"——理念与规模的账单由谁支付:
> 学术劳动力市场(长聘/预聘/博士后/兼职的双重市场)、博士培养与
> 学术就业(博士产量与稳定教职的结构性缺口)、科研组织形态学
> (讲座-学系-实验室-研究中心-大科学的形态谱)、知识生产模式
> 转型(模式 2/三螺旋对组织的改写)。三支中**最像社会学**的一支:
> 它把"大学理念"翻译成岗位、编制与生涯——**洪堡统一的岗位单价**。

## 诞生

- **谁/何时**:柏林讲座制(1810,一学科一正教授掌全权——学术
  职业的普鲁士形态);霍普金斯研究生院(1876,科研训练=博士
  学徒制,学术职业的再生产行道);美国 AAUP 与 tenure 制度化
  (20 世纪初,长聘=筛选后的保障+学术自由装置);克尔时代的
  学术劳动力研究;博耶《学术水平反思》(1990,教学/发现/应用/
  整合四种学术,拓宽"学术工作"定义);吉本斯等模式 2(1994,
  知识生产向应用语境与非等级组织转移);21 世纪博士就业与双重
  劳动力市场研究成为主流(00 章 §七发现 3 的文献线)。
- **因什么问题**:①教学与科研两种工作打包在一个岗位上的成本
  (统一的岗位单价)②博士培养规模与教职供给的错配(学术职业的
  再生产危机)③科研组织形态随知识形态演变(讲座-系-实验室-
  中心的形态谱)。

## 核心问题

**已解决**:
- tenure 的双重功能被拆清:筛选(前)与保障(后),缺一即变形
  ——制度通说
- 博士=科研学徒制(研究生院装置的职业面)——克拉克框架通说
- 双重劳动力市场成为全球现象的定性判断(内圈长聘/外围流动)
  ——多国研究通说(比例以各国调查为准)
- 科研组织形态谱(讲座制欧洲型-学系美国型-实验室计划型-中心
  网络型)——组织形态学通说

**未解决/深水区**:
- **职位滞后的算术**:学生扩张×12.8 vs 教师扩张×6.3(实验断言③)
  ——滞后的账单主要由外围支付,双重市场是算术的社会形态还是
  治理选择,无裁决
- **博士后化**:过渡岗位职业化的临界点(筛选延长还是廉价劳动)
- **模式 2 的组织后果**:跨学科中心与传统学部的资源权之争
  (科研组织转型通说,效果未定)
- **学术忠诚与激励**:教学-科研-服务三元考核的设计空间
  (00 章 §四联结论的劳动面)

## ✨ 这支最美的一个事实

**双重市场的算术出身**:长聘内圈与兼职外圈常被讲成道德故事
(保护 vs 剥削),家族实验给出它的算术底稿——学生翻 12.8 倍、
教师按弹性 0.72 只翻 6.3 倍,师生比 1:14→1:29;分层弹性下
外围层恶化 ×3.10、内圈仅 ×1.07。为什么美:**一个乘法揭示了
道德叙事的结构基础**——双重市场不是谁变坏,是扩张系统的
资产负债表必然把波动放在外围;看清算术,才知道哪些是选择、
哪些是必然(改弹性参数=改政策,04 章走廊 3 的正确用法)。
