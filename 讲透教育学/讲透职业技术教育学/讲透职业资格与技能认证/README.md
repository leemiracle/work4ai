# 讲透职业资格与技能认证 · 通行之问:技能凭什么算数——分类、框架与认证链

> **定位句**:这支负责"**通行之问**"——技能的社会承认机制:
> 一个人的手艺,怎么从"自己知道"变成"所有人认"?它守着家族
> 宪法的信号半壁:**行会杰作(同行的承认)→ 国家证书(法律的
> 承认)→ 资格框架(跨域互认:EQF 型 8 级表)**。**证书是把
> 私有技能翻译成公共信号的翻译器——翻译必有损耗**:考得出的
> 是技能的可测切片,认证链每加一级,信号离实体远一分
> (证书化失真,00 章假设 3)。
> GB/T 13745 88061 职业技术教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透职业技术教育学](../README.md)

## 诞生

- **谁/何时**:中世纪行会杰作制度(作品即考试);19-20 世纪国家
  职业证书体系(考试权从行会移向国家与行业组织);1970s-80s
  胜任力本位(CBET/NVQ 型:按能力单元达标);2000s 资格框架化
  (EQF 2008/2017 等:学历与职业资格进同一张等级表,通说);
  当代微证书(micro-credential,发证主体多元化)。
- **因什么问题**:①劳动力市场无法挨个试手艺——需要低成本的
  技能信号(信息经济学的经典问题);②"会干"与"证说你会干"
  之间永远有缝——认证制度的一切设计都是在缝上搭桥或填缝。

## 核心问题

**已解决**:
- 认证链的部件学:学习成果→单元→模块→证书→资格等级→雇主
  承认,签发与承认规则可构造(家族 03 章构造物 2)
- 职业分类的公共语义:ISCO 型四层树,统计与匹配的坐标系
- 资格框架的互认逻辑:把异质资格放进同一张等级表(政策通说)

**未解决/深水区**:
- **证书化失真的度量**:信号与实体的距离怎么测(文凭效应/
  sheepskin 识别,02 章证据阶梯的独门难题)
- **微证书的信号质量**:链变短(少打包)但发证权分散(质量方差
  变大)——雇主承认是生死线(01 章主线 D)
- **跨体系互认**:非正规学习成果(工作经验)如何折算——
  先前学习认定(APEL/RPL 型)的效度之争(通说争议)

## ✨ 这支最美的一个事实

**八百年前,一件作品就是一场考试**。中世纪行会不发试卷,发题目:
金匠想当师傅,就做一件评议会指定的器物,同行验收——技能的
承认被压缩成一个动作:**把不可观察的能力,兑换成可检验的产出**。
学徒合同管输入(几年、教什么),杰作管输出(做得出什么),帮工
游历管迁移(换个城市还算数)——现代认证链的三环在行会里已经
配齐;今天的作品集、实操考核、技能大赛,全是杰作制度的后裔
(00 章美之时刻 1 的支级版)。
