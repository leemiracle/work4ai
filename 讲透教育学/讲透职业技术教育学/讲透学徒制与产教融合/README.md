# 讲透学徒制与产教融合 · 场域之问:技能在哪形成——从行会杰作到双元制到现代学徒制

> **定位句**:这支负责"**场域之问**"——技能形成的场域组织:
> 为什么有的技能必须在真实生产现场长出来,企业与学校各自能养
> 技能的哪一半,两个学习地点怎么咬合?它守着家族宪法的制度半壁:
> **行会学徒制(杰作与出师)→ 双元制(1969 BBiG 法源:企业培训
> 合同+职业学校两元咬合)→ 现代学徒制/产教融合(三角重构)**。
> **企业为什么愿意付钱培训,决定学徒制成不成立——双元制的引擎
> 是劳动制度,不是教育制度**(00 章之争二的家族立场)。

## 诞生

- **谁/何时**:中世纪行会(学徒-帮工-师傅,杰作出师考);1869 年
  《营业条例》培训自由(行会垄断终结→建制真空);凯兴斯泰纳
  1895 起慕尼黑(学校侧补位);德国 1953《手工业条例》/1969
  《职业教育法》(BBiG:两元咬合成典);21 世纪学徒制现代化
  (英格兰学位学徒等,通说);中文语境产教融合研究线(方向锚)。
- **因什么问题**:①培训自由后无人有义务办培训——技能形成的
  场域真空谁来填(学校?企业?两者?);②"企业与学校共同培养"
  的全部难点:合同、考核、津贴、时间表、师傅——两个学习地点
  的协调成本(00 章假设 1 的利息)。

## 核心问题

**已解决**:
- 学徒制的部件学:合同+年限+考核+认证,行会原型沿用至今
  ——历史定论(00 章节点一)
- 双元制的法源结构:私法培训合同×公法职业学校的咬合方式
  ——比较研究的标准对象(制度通说)
- 企业培训供给的四因子解释:生产性产出/合同约束/市场摩擦/
  集体协调——文献通说框架(01 章主线 B)

**未解决/深水区**:
- **可移植性**:五十年移植实验成功者寡——劳动制度与产业组织
  不配套时,学校形态的"假双元"为何必然(00 章之争二,白热)
- **合作办学的回路质量**:需求信息进课程的速度与真实度——
  家族实验断言③的属地(信息回路的价值依赖需求可预测性)
- **带教师傅**:企业侧的教学质量(师傅既非教师也非考核者)
  ——默会知识传递的关键人,研究证据最薄的一段

## ✨ 这支最美的一个事实

**双元制是劳动制度,不是教育制度**。各国移植双元制,先建学校、
引课程、派师资——五十年,成功者寡。比较研究的通说结论指向一个
冷门事实:双元制的引擎在企业培训岗位的供给——培训合同(津贴
换服务期)、行会主持的统一考试(培训质量有底线)、雇主组织的
集体协调(你不训我也不挖,搭便车被行规抑制)。这三样全是劳动
制度与产业组织的部件,一样都不写在教育法里;缺了它们,企业的
理性选择是"招成品、不育半成品",学校再像双元也只是布景
(00 章之争二;02 章对译表第一高危词的病灶)。
