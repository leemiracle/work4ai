# 讲透职业教育原理 · 认识之问:做中学的知识论——技能是"在做事中"长出来的知识

> **定位句**:这支负责"**认识之问**"——职业教育的知识论:技术技能
> 是一种什么知识,它与学术知识差在哪,凭什么要用不同的建制来
> 培养?它守着家族宪法的理论半壁:**劳作学校线**(凯兴斯泰纳:
> 劳作是心身一体的精神活动)与**做中学线**(杜威:经验与教育的
> 连续性),加上福斯特的需求导向之问("职业学校谬误",1965)
> ——三条线合成职教课程原理的地基。**技能不是"关于做事"的知识,
> 是"在做事中"的知识**——这一句是全支的宪法。
> GB/T 13745 88061 职业技术教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透职业技术教育学](../README.md)

## 诞生

- **谁/何时**:中世纪行会(学徒制的"做中学"原型);凯兴斯泰纳
  1895 起慕尼黑实验、《劳作学校的概念》(1912);杜威《民主主义
  与教育》(1916,occupational 与做中学);福斯特《职业学校谬误》
  (1965,职教供给必须需求导向的经典判词);1970s-80s ILO MES
  与 CBE/DACUM(课程技术化);当代工作过程系统化课程(中文语境
  教材线,通说)。
- **因什么问题**:①学校形态的职教天然"去情境化"(00 章假设 1)
  ——课程原理必须回答"如何在教室里教只能在现场长出来的东西";
  ②"需求导向"导向什么(岗位/技能族/生涯基础)——供给主义的
  老病每隔一代复发一次。

## 核心问题

**已解决**:
- 做中学的知识论地位:技能=程序性+情境性+默会成分的复合,
  纯讲授替代不了真实任务——教材共识(劳作学校-杜威线的现代版)
- 职业分析方法:DACUM/MES 把职业拆成可教学单元的公共技术
  ——课程技术的工具箱(1970s-80s 起)
- 需求导向的必要性:福斯特判词(计划式供给赶不上需求变化)
  ——发展教育学教材共识

**未解决/深水区**:
- **迁移之谜**:在 A 任务里学会的技能,凭什么迁移到 B 任务?
  "宽基础"到底宽在哪,没有通说答案
- **"更高技能还是更多证书"**(01 章主线 D):培养目标上移的
  实质之争——数字时代的做中学要什么样的"做"
- **工作过程系统化的证据面**:课程组织的范式之争(学科体系/
  工作过程/模块),证据多为实施研究,效应证据薄

## ✨ 这支最美的一个事实

**福斯特用一句话终结了一个时代**。1965 年,研究加纳教育的福斯特
写下"职业学校谬误"(the vocational school fallacy):办学校不等于
办教育供给——职校培养什么,取决于劳动力市场要什么,而不是教育
系统想给什么;脱离需求信号的职教扩张,培养的是"受过训的失业者"
(通说译述)。此后五十年,从 Cedefop 的供需预测到家族实验的时滞
模型,都是给这一句做注脚:**职教的第一原理不在教育学里,在需求
侧的信号回路里**。
