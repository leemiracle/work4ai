# 讲透职业技术教育学 · 技能层:工程师之外的技术技能人才怎么培养——做中学的制度化

> **本质一句话**:职业技术教育学=技能形成的建制学——它不先问
> "人怎么学习"(那是[教学论](../讲透教学论/README.md)与
> [成人教育学](../讲透成人教育学/README.md)的事),也不先问
> "学位体系怎么组织"(那是[高等教育学](../讲透高等教育学/README.md)
> 的事),它问:**一个社会需要的万千技术技能,如何被制度化地批量
> 形成、传递与承认**。行会学徒的杰作制度是这个问题的第一个答案,
> 双元制是它的现代形态,TVET 是它的全球议程。
>
> **三方分工声明**(技能形成三家族):[成人教育学](../讲透成人教育学/README.md)(88057)
> 管**学习本体**(终身层:成人怎么学、继续教育、andragogy);
> 本家族管**职业教育建制**(学校形态的职教与培训体系:分流/学徒制/
> 产教融合/资格认证);[高等教育学](../讲透高等教育学/README.md)(88054)
> 管**学位体系**(大学制度与学术轨道)。
>

## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透职业技术教育学/              GB/T 88061(无三级明细,自定主干支)
├── 讲透职业教育原理/          自定支——认识之问:职教的知识论(做中学/劳作学校/福斯特之问)
├── 讲透学徒制与产教融合/      自定支——场域之问:技能在哪形成(行会学徒制→双元制→现代学徒制)

```

> 三支的共同血统:**同一条建制链的三段**——技能怎么学(认识)、
> 在哪学(场域)、凭什么算数(承认)。行会时代三段合一(师傅带徒弟、
> 杰作定身份),现代性把三段拆开分给学校、企业与证书体系,
> 本家族的研究对象就是这条被拆开又不断重新缝合的链。
