# 04 · 职业技术教育学转代码:把技能层搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程
> 视角贯穿)。
>
> **本章一句话**:职教的可机读层(03 章谱系左端)几乎可以无损
> 转码,默会技能与校企信任不可转码;四条代码走廊——**分类匹配、
> 认证链、错配度量、供需滞后**——把"这人算哪行、证书到哪断、
> 错配有多少、需求多快进课程"分别变成可跑、可断言、可做敏感性
> 扫描的实验;其中后两条是本家族的独门:**在政策拍板之前,把
> "总量平衡掩盖结构错配"与"时滞造成周期性错配、合作办学压缩
> 峰值"复现出来**。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",[教学论](../讲透教学论/README.md)
转代码要解决"操作化",职教转代码要解决"**接口化**":把一段
职教宣称("校企精准对接")先翻成带场域、带信号链、带时滞的
模型(技能在哪形成/谁认证/需求信号几岁),再翻成代码。翻译的
损耗全部发生在第一步——所以本章先划清哪些对象第一步就走得通
(绿色区),哪些走不通(红色区),再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 职教概念 | 代码化身 | 备注 |
|------------|---------|------|
| 职业分类 | 四层树+描述字段+教育码↔职业码跨表(03 章构造物 1) | 走廊 1:匹配的骨架;版本化是生死线(树在漂移) |
| 认证链 | 模块-证书 DAG+签发/承认规则+断链检测(03 章构造物 2) | 走廊 2:学分银行/资历框架的核心逻辑(纯 schema 工程) |
| 技能错配 | 供给分布×需求分布的总变异距离(按粒度分层计算) | 走廊 3:家族实验属地(聚合敏感性断言) |
| 供需动态 | 配额调整模型(学制时滞+信息时滞+调整速度参数化) | 走廊 4:家族实验属地(时滞/合作办学断言) |
| 学徒合同 | 三方字段表的状态机(签约→轮换→中考→结业) | 03 章构造物 3 的直接实现(合同生命周期工程) |
| 对口率 | 岗位-专业的匹配函数×分类粒度参数 | 地基住[统计学宇宙](../../讲透统计学/README.md);本家族取口径定义 |

**转不动/转不动的边界(红色区)**:

1. **默会技能的自动评定**:"师傅觉得这徒弟能出师"的判断构念
   未构造化(03 章右端)——工程对策:机器做记录与对照(考核
   留痕),不做判定;宣称 AI 自动评技能等级的系统,评的是
   可测切片。
2. **校企信任**:合作办学的深度由信任与激励结构决定(00 §四
   之争二),签约数据测不出协同真实度——工程边界:可监测
   "信息是否进了课程"(课程修订滞后),不可监测"关系好不好"。
3. **分流的价值判断**:几岁分流、怎么分流是政治哲学问题
   (00 §四之争一)——模型可以比较回流成本,不可以替社会选边。
4. **"高质量的技能人才"的目的层**:对接市场算得出,教育为了
   什么人算不出——目的层送回[教育学原理](../讲透教育学原理/README.md)。

**边界的一句话**:绿色区=03 章谱系左端四构造物+它们的动态版;
红色区=谱系右端+价值层——**先问构造学,再谈转码**。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:分类匹配走廊(职业树+跨表)

```
岗位文本/专业名称 ──归一化──▶ 职业树节点(四位码) ──跨表──▶ 专业码
      │                                        │
      └──粒度参数(看几位码)                    └──匹配判定:对口/相邻/跨类 ──▶ 对口率(带粒度声明)
```

- **理论→模型**:03 章构造物 1 的机器化;输出的每个匹配结论
  必须带**粒度声明**(按几位码算的)——粒度是结论参数不是
  技术细节(03 §四)。
- **算法层**:树查询 O(depth);重点是**歧义岗位的落码规则**
  (同一职位名在不同企业指不同活)与**树的版本化**(新职业
  入库的滞后要进数据字典)。
- **真实系统**:招聘平台、就业统计、错配监测面板。
- **性能工程要点**:跨表(教育码↔职业码)是**多对多**映射,
  别建成一对一外键;落码规则要可解释(哪一步归到哪个码,
  审计要能回放)。

### 走廊 2:认证链走廊(模块 DAG+断链检测)

```
学习成果 ──组装──▶ 胜任力单元 ──组合──▶ 模块(学分) ──集合──▶ 证书 ──承认──▶ 资格等级/雇主
      │                                                                │
      └──先修 DAG(环检测)                                             └──断链检测:签了没人认/认了没岗位
```

- **理论→模型**:03 章构造物 2;断链检测是本走廊最值钱的输出
  ——**学分认了、证书没人认**的断环,是证书化失真的数据形态。
- **算法层**:DAG 的环检测/可达性 O(V+E);学分累计的重复
  计算防护(同一模块不许计入两张证书,除非声明互认规则)。
- **真实系统**:学分银行、资历框架平台、微证书钱包。
- **性能工程要点**:承认规则(谁认哪级)是**外部数据**不是
  内置常量——雇主承认随市场漂移,做成可版本化的规则表;
  链上每环留"承认半径"字段(本单位/行业/全国/跨国)。

### 走廊 3:错配度量走廊(聚合敏感性)——本家族实验·断言②

```
供给分布 S(类目) × 需求分布 D(类目) ──▶ 细类目错配 M_fine = 0.5·Σ|S−D|
      │                                        │
      └──聚合函数(类目→大类)                  └──粗类目错配 M_coarse = 0.5·Σ|agg(S)−agg(D)|
                                               ──▶ 断言:M_coarse ≤ M_fine(恒成立);差值=被聚合吞掉的结构错配
```

- **理论→模型**:00 §七发现 2 的机器化;聚合是总变异距离的
  收缩投影——**总量平衡(M_coarse≈0)与结构错配(M_fine 大)
  可以同时成立**,这不是数据矛盾,是度量的数学性质。
- **算法层**:两个层次的距离计算 O(K);敏感性扫描沿粒度参数
  (2/4/8/…类)做**粒度-错配曲线**——曲线的斜率就是"口径
  选择的自由度"有多大。
- **本家族实现**:[`experiments/skill_mismatch.py`](experiments/skill_mismatch.py)
  断言②+构造示例(总量完全平衡、结构错配 0.16 的静态例)。
- **性能工程要点**:任何错配面板必须**双口径并报**(总量+结构),
  只报一个口径的产品在替用户做口径选择——这是本走廊的产品伦理。

### 走廊 4:供需滞后走廊(时滞×合作办学)——本家族实验·断言①③

```
需求侧 D_t(产业结构+部门周期)                        供给侧:配额 Q_t ← α·(D_{t−d} − Q_{t−1})
      │                                                     │ 毕业构成 S_t = Q_{t−L}(学制时滞 L)
      └──周期性错配 M_t = dist(S_t, D_t) ◀── 短缺-过剩交替(蛛网摆动)
                        │
      合作办学 = 需求信息进课程:d↓、α↑、培养规格后段定向(L↓)
                        └─▶ 断言③:错配峰值压缩(需求不可预测时增益消失——边界自证)
```

- **理论→模型**:00 §七发现 1 的机器化——教育系统追移动靶:
  需求信号先滞后 d(统计发布+研判),学制再加 L 年;配额按
  惰性 α 调整。错配周期性发作(蛛网式),**短缺与过剩交替**
  是它的指纹。合作办学的机制版:把企业需求信息接进课程
  (d↓、α↑、后段定向 L↓)——回路变快,峰值变小;且三杠杆
  缺一不可,单动"调整加快"甚至过度修正、放大摆动(实验归因)。
- **算法层**:配额调整是一阶惯性环节+延迟线;周期检测用局部
  极值扫描;CRN 纪律:三个"世界"(基准/快回路/合作办学)
  跑**同一条需求路径**(共用随机数),组间差不受抽样运气污染
  (与[学前教育学](../讲透学前教育学/README.md)家族实验同纪律)。
- **本家族实现**:[`experiments/skill_mismatch.py`](experiments/skill_mismatch.py)
  断言①(时滞→周期性错配+蛛网交替)与断言③(合作办学压缩
  峰值;需求为不可预测噪声时增益消失——**信息回路的价值
  依赖于需求的可预测性**,这是产教融合的定量边界)。
- **性能工程要点**:时滞参数(L/d)与断言阈值成对版本化;
  输出永远带**机制归因**(峰值降了多少来自 d、多少来自 α、
  多少来自 β),只给一个总降幅的模拟是黑箱叙事。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:做招聘/HR 系统——职业分类是数据层,不是功能层

- 招聘平台的匹配质量上限由**职业树+跨表的数据质量**决定,
  不由推荐算法决定;树的版本化(新职业入库滞后)与落码规则
  的可解释性是第一优先级(走廊 1)。
- 快速诊断:系统里"专业↔岗位"的映射是一对一外键还是多对多
  规则表?前者是把口径焊死在 schema 里——粒度一变就得改库。

### 落点 2:建学分银行/微证书系统——断链检测先于发证功能

- 微证书平台的声誉核心不是发证多快,是**承认规则的真实性**
  (谁认、认到哪级、认多久)——承认规则做成可版本化外部数据,
  断链检测(签了没人认)做成常设报表(走廊 2)。
- 快速诊断:系统里"证书→岗位"有字段吗?没有这个字段,发出去
  的证书只有存储价值,没有信号价值。

### 落点 3:做职教数据治理——双口径是底线,不是加分项

- 任何供给-需求数字(招生计划/缺口报告)必须**总量+结构双口径
  并报**(走廊 3);发布粒度选择权留给读者,不留在发布者手里。
- 快速诊断:看一份"供需平衡"报告用的几位码——如果是大类口径,
  它证明的恰恰是什么也没证明(错配住在它看不见的地方)。
