# 讲透军事训练学 · 技能怎么练成:课目、迁移、模拟与压力的工程学

> **定位句**:这支负责"**技能怎么练成**"——训练体系的四件套:课目语法
> (任务-条件-标准)、训练迁移(共同要素说与保真度预算)、模拟训练
> (林克训练器到仿真时代)、压力与绩效(倒 U 与压力接种)。
> **自定主干支声明**:GB/T 88044 未列三级明细,本支为家族自定主干支之一。
> 家族:[../README.md](../README.md)(宇宙:[../../README.md](../../README.md))

## 诞生

- **谁/何时**:操典传统(戚继光《纪效新书》1560)给课目以语法;桑代克
  (1901+)给迁移以科学;林克训练器(1929)给模拟以工业;二战速成培训
  研究给整套工艺以规模;耶克斯-多德森(1908)与梅肯鲍姆压力接种
  (1985)给压力以曲线;SAT/ISD(至 1975)收编为系统化训练开发流程。
- **因什么问题**:①训了为什么用不上(迁移)②没钱没装备怎么训(模拟)
  ③练到什么程度算够(课目标准)④平时训的到了高压还算不算数(压力)。

## 核心问题

**已解决**:
- 课目的可判定语法(条件-标准句,操典四百年)——通说;任务分析→
  课程化→标准化考核的工程线由此成立
- 迁移由情境相似要素决定(共同要素说推翻形式训练说)——心理学共识;
  低保真可高迁移(林克训练器,相似要素稀疏)——技术史通说
- 高压退化与渐进接种(倒 U+SIT)、训练开发流程化(SAT→ADDIE)——通说

**未解决/深水区**:
- 保真度-迁移曲线的具体形状(线性/递减/阈值之争)
- 压力阶梯的剂量学(过陡即创伤,阈值因人因课目而异)
- "为上一场战争训练"——训练情境滞后于任务情境的结构性批评(军史通说)

## ✨ 这支最美的一个事实

**木头飞机教会真飞行**:1929 年的风箱装置赌"飞行技能的迁移由少数关键
要素决定,与木质机身无关"——赌赢了,相似要素的稀疏性由此成为一门
预算学(数值复现见[家族实验](../experiments/training_transfer.py)断言 1:
仿真度买迁移且边际递减)。
