# 讲透军校教育与军事职业教育 · 军官怎么养成:从兵学传承到三段式学制

> **定位句**:这支负责"**军官怎么养成**"——培养体系的三级跳:兵学传承
> (武举/武学的制度化)→近代军校建制(伍利奇/西点/圣西尔/桑赫斯特的
> 工程教育起源)→现代职业军事教育三段式(任命前-任职-高级的课程图);
> "教育"与"训练"的边界之争住这支。

## 诞生

- **谁/何时**:武举(702)与北宋武学(1043/1072 复设)开制度化选拔与培养;
  伍利奇(1741)、西点/圣西尔(1802)、桑赫斯特(1799 创/1802 迁)建近代
  军校(最初教的主要是数学与工程——炮术即弹道学);普鲁士参谋学院与
  军士学校传统(19 世纪)立三段式雏形;20 世纪后期各国军事教育立法
  塑造现代职业军事教育建制(公开立法史)。
- **因什么问题**:①军官靠门第、行伍还是学制②教技能还是教判断
  (教育-训练分家)③培养怎么接力成职业轨迹(三段式)④军校学位与
  国民大学怎么互通(军民融合)。

## 核心问题

**已解决**:
- 军官可经学制培养(职业化假设的制度化)——通说;高级军事教育与技能
  训练分家(参谋学院传统)——通说;工程教育反哺国民教育体系(西点谱系)
  ——教育史通说;GI Bill(1944)作为军事教育最大民用外溢——通说史实
- 三段式课程图与学位接口的可构造化(schema 与图工具)——本家族 03 章

**未解决/深水区**:
- 领导力可教吗(领导力课程的代际更替:品质论→情境论→发展论→综合,
  "教什么"仍无定论——与德育原理"美德可教吗"同构)
- 职业军事教育怎么评估(行为层与结果层证据稀缺;晋升选择效应)
- 学术性-职业性张力与军民融合边界(各国方案不同,通说只立坐标)

## ✨ 这支最美的一个事实

**军校最初教的是数学**:近代军校的起点课程是弹道学与筑城几何——
军事工程教育反过来喂养了 19 世纪的国民工程教育(西点是最早的工程师
产地之一,通说)。一门职业教育的起点竟是它最"学术"的科目:
**教判断先于教技能的建制表达**,此后两百年"教育-训练"边界之争的
第一块界碑。
