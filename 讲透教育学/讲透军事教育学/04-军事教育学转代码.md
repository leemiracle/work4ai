# 04 · 军事教育学转代码:把训练与养成的问题搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:军事教育学的可构造端(03 章谱系左半——课目、排课、
> 保真度、压力、迁移)几乎可以无损转码;**"该练什么"的内容选择与
> 养成目标永远不可转码**——练什么由军事学本体与公开审议决定,机器
> 只携带不产生;五条代码走廊——**课目 schema / 排课与资源 /
> 保真度-迁移扫描 / 压力阶梯 / 职业路径课程图**——把训练工程最硬的
> 结构变成可跑、可断言、可扫描的实验。本家族还有一条独有红线:
> **一切转码只做参数化玩具,不建任何真实部队训练数据库**。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",军事教育学转代码要解决"**双负载与
代理的剥离**":把训练管理语言(训练有效=课目达标+岗位胜任的混合承诺)
先翻成单负载的模型(达标率/迁移率/相关结构),再翻成代码——损耗全部
发生在代理环节(课目达标代理胜任、模拟任务代理任务环境)。本章先划清
哪些代理走得通(绿色区),哪些走不通(红色区),再给五条走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 军事教育概念 | 代码化身 | 备注 |
|---------|---------|------|
| 课目三件套 | schema+达标判定器:(任务,条件,标准,时限,合格线)→通过/不通过 | 03 章引擎 1 的直接编码;操典的数据库形态 |
| 训练计划/排课 | 约束满足:场地/器材/教官/课时/先修序 | 经典调度问题;先修边是教学假设,要显式存疑 |
| 保真度预算 | 三维保真度×成本×迁移增益的取舍矩阵 | 增益曲线形状用证据标注(不可先验断言) |
| 训练迁移 | 泛化场仿真:训练分布(中心,带宽)×任务距离→表现 | 03 章引擎 2;本家族实验全程纯标准库 |
| 压力-绩效 | 耶克斯-多德森简化的退化模型+接种阈值 | 03 章压力阶梯的数值侧;剂量学粗,断言写结构性质 |
| 评估层级 | 柯氏四级的数据埋点设计(每级指标显式分层) | 反"学习层数字冒充结果层"的工程护栏 |
| 职业路径课程图 | 岗位-课程-先修边三元组+覆盖度/悬空审计 | 03 章引擎 3;图工具复用教学论课程图谱 |

**转不动/转不动的边界(红色区)**:

1. **"该练什么"的内容选择**:课目清单由军事学本体与公开审议决定——
   把"选课目"外包给算法,实际是把**可测性当成了重要性**(古德哈特的
   训练版:达标率高的课目自动扩张,不可测的临机判断课目萎缩)。
   工程对策:权重显式化、人工签署、修订留痕。
2. **养成目标的判定**:品格与临机判断不可从行为片段判定(03 章铁律)
   ——荣誉积分类系统测到的是可记录片段;与德育原理 04 章红线同构:
   机器放大标准,从不产生标准。
3. **压力的剂量**:"过陡即创伤"的阈值因人与课目而异,无先验参数——
   仿真只能扫结构(接种优于突加),不能替真人定剂量(专家保留)。
4. **真实部队训练数据**:本家族独有红线——转码一律用参数化玩具数据;
   真实编制、演训与战备数据不入库、不建模(写作红线的技术版)。

**边界的一句话**:绿色区=03 章谱系左半段+三条引擎的可参数化部分;
红色区=内容选择+养成判定+剂量决定+真实数据。**红线:凡涉及"该练什么、
算不算养成",机器只能携带与呈现,不能产生。**

## 二、代码走廊清单(五条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:课目 schema 走廊(操典的数据库化)

```
课目三件套 ──schema化──▶ (任务,条件,标准,时限,合格线)行
      └─可判定性审计─▶ 双人判定一致性 ─▶ 课目库质量报告
```

- **理论→模型**:02 章可判定语法的数据化,槽位可参数化、可审计;
  真实系统:企业培训课目库/体育训练计划/职业资格考纲——操典语法的
  民用迁移(00 章反直觉 1 的当代延续)。
- **性能工程要点**:标准字段必须**机器可判**(数值或枚举),形容词入库
  即报警;课目版本化(操典修订的留痕传统)。

### 走廊 2:排课与资源走廊(约束满足的经典战场)

```
场地×器材×教官×课时×先修序 ──CSP/调度──▶ 周期训练计划
      └─冲突与瓶颈报告──▶ 资源扩容决策 ──▶ 训练经济学
```

- **理论→模型**:排课=带先修约束的资源调度,军事特色约束是**周期性
  与全员覆盖**(训练是循环的);真实系统:学校排课/生产倒班/健身
  课编排——同一数学。
- **性能工程要点**:先修边显式标注证据等级(政策/传统/实证)——
  无证据的先修序是排课里最贵的隐性假设。

### 走廊 3:保真度-迁移扫描走廊(本家族实验的主场)

```
共同要素说 ──参数化──▶ 泛化场:perf=峰值·exp(-距离²/2带宽²)
      └─仿真度/多样性扫描─▶ 迁移增益曲线 ─▶ 模拟器预算决策
```

- **理论→模型**:03 章引擎 2——训练分布的(中心,带宽)×任务距离
  决定表现;仿真度参数控制训练装置与任务环境的距离。
- **本家族实现**:[`experiments/training_transfer.py`](experiments/training_transfer.py)
  ——断言①仿真度单调(模拟器有效性);②带宽交换(迁移窄化);③压力
  退化与接种(高压退化,渐进接种减轻,接种有成本);断言写**单调性
  与交换律**(结构性质)不写点值,多 seed 平均防抽样偶然;真实系统:
  模拟器采购的预算论证(买哪一维保真)、VR 培训效果预估。

### 走廊 4:压力阶梯走廊(接种剂量的结构侧)

```
耶克斯-多德森+SIT ──参数化──▶ 退化因子=1/(1+k·max(0,压力-承受阈))
      └─承受阈×接种成本扫描─▶ 接种收益曲线 ─▶ 压力训练设计
```

- **理论→模型**:压力超过承受阈的部分按比例退化;渐进接种抬高承受阈
  但压低低压峰值(训练压力挤占打磨时间)——收益与成本同为曲线;
  真实系统:航空复训的应激科目、急救演练、公众演讲脱敏(SIT 民用化)。
- **性能工程要点**:模型只扫结构(接种组高压退化恒轻于常压组、低压
  略逊),**真人剂量永远红色区**(走廊红线 3)。

### 走廊 5:职业路径课程图走廊(资格图的审计工具)

```
岗位-课程-先修边 ──schema化──▶ 有向图
      └─覆盖度/悬空/环路检测─▶ 资格空转报告 ─▶ 课程体系年度审计
```

- **理论→模型**:03 章引擎 3——无课程供养的岗位=资格空转,无岗位
  出口的课程=悬空;先修环路=制度死锁;真实系统:企业岗位-培训体系
  审计、大学培养方案审计(军民融合的工程接口,01 章方向 D)。
- **性能工程要点**:加边(互认学分)的**合法性显式化**——谁有权加边
  是治理决定,报告只呈现图结构,不替审。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:企业培训系统(ADDIE 血统的当代兑现)

- 你的 LMS/培训平台是 SAT→ISD→ADDIE 谱系的当代形态(00 章反直觉 1)
  ——移植到低压场景要重新校准三样:压力参数(职场压力低,压力阶梯
  常可整层删除)、淘汰机制(黜陟件缺失是多数企业培训的第一短板,
  对照吴宫教战四件套)、周期性(军事训练是循环的,企业培训常一次性)。
- 评估埋点按柯氏四级显式分层:学习层仪表盘再漂亮,别让它冒充
  行为层结果(01 章证据天花板的产品化护栏)。

### 落点 2:严肃游戏与模拟训练产品设计

- 核心决策是走廊 3 的预算题:**买哪一维保真**(感知/物理/认知)——
  林克赌注的当代版:先列候选相似要素、按迁移贡献排序,再花预算;
  全维高保真几乎总是错的(增益边际递减+成本陡升)。
- 防负迁移:训练环境独有的线索(界面提示/暂停/回滚)会被一起学到,
  任务环境一撤线索技能就塌——上线前做一次"线索差异审计"。

### 落点 3:高压民用行业的训练迁移设计

- 航空复训、急救演练、应急响应是军事训练结构的民用同构:周期性、
  压力阶梯(渐进)、模拟代理(行为层证据的最优可得替代)——三条结构
  直接搬用;唯一不可搬的是剂量决定(红色区 3,专家保留)。
- 与 ../讲透职业技术教育学/(88061,波5待建)的产教融合议题在此汇合:
  训练环境的"仿真度"就是校企情境的相似度问题——同一门预算学。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:代理审计者之眼**——评估任何训练系统
(LMS/模拟器/严肃游戏/演练体系),先问三件事:它的达标代理什么
(课目→胜任的代理链断在哪)?效果在哪一层(学习层数字不得冒充
结果层)?内容权重谁签署(可测性冒充重要性即古德哈特)?训练可
工程化,内容与养成不可——这不是工程的自卑,是工程的红线:
**机器放大训练工艺,从不决定练什么;训练系统的第一行代码应是
课目清单的署名栏。**
