# 讲透军事教育学 · 教育学与军事学的交叉层——训练与养成怎么做成一门教育工程

> **本质一句话**:军事教育学=教育学宇宙的**交叉层**——把"人如何被教与学"
> 的学问放进**高压、高风险、强组织**的军事场景:一条线问**技能怎么练成**

> 军事训练是最早的教学系统设计。
