# 04 · 教育史转代码——扩张三律的最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:教育史的问题一旦变成「关于教育史数据的计算」就能进代码——学制变年表、移植变网络、扩张变曲线、观念变词频;**唯一不可外包给代码的,是史学判断本身(选样、归因、制度评估)**。

---

## 0. 开篇:三个教育学通说的受控审判

「初等教育总是最先扩张」「后发国家扩张更快」「性别差距最后在高教层收口」——这三句是教育史与发展研究的通说级直觉。它们对吗?在真实数据里,它们是统计倾向;在 `experiments/enrollment_waves.py` 里,它们是**被告**:脚本用一个受控机制(GDP 越过层级阈值→逻辑斯蒂扩张,性别用随时间衰减的门槛差建模)生成 1800-2020 年六国三层的毛入学率序列,然后断言三律——梯度律(启动次序+每层 S 型)、压缩律(后发国 20%→80% 用时更短)、残差律(性别差距收敛且高教层最大)。跑一遍,三律在同一套两参数机制下同时涌现。

但脚本同时在 docstring 里声明:**模拟证明的不是「世界如此」,而是「如此简单的机制足以如此」**——真实扩张还有政治动员、战争中断、汇率口径等未入模因素。这是数字教育史的第一课:代码替你生成结构,替不了你解释历史(与数学史、管理思想史家族 04 章同款纪律)。

## 1. 可机械化边界(三件套之一)

**能进代码的**(教育史数据化后的一切统计与生成):

| 任务 | 机械化形式 |
|------|-----------|
| 扩张三律检验 | 受控模拟序列 → 启动次序/S 型/用时对比断言(`enrollment_waves.py` 已实现) |
| 学制年表查询 | 表结构 → 按国/年/字段切片(走廊 C2) |
| 移植时滞 | 传播边年份差 → 时滞表(癸卯滞后明治 32 年,走廊 C2) |
| 文本考据 | 学制/课本文本 → 版本 diff、术语首现年(走廊 C3) |
| 建制谱系查询 | 学校 DAG → 分立/合并/升格的多跳追溯(03 章 §1.5 schema) |
| 建制「认古」检测 | 校庆始年 vs 法规首现年之差的分布(03 章 §2.3) |

**不能进代码的**(教育史的「不可判定域」):

1. **选样正当性**——哪些国家/学制入表是史学判断;代码只能做敏感性分析。
2. **归因**——扩张由工业化还是国家建设驱动,相关给不出;模拟给「机制充分性」,不给「历史因果」。
3. **反事实**——「若无废科举,近代学制会自发长出吗」不可模拟;凡模拟历史进程的程序,模拟的都是**作者的史观**。
4. **制度评估**——科举整体功过、义务教育百年成败,没有客观目标函数;把「入学率最大化」当目标函数,就是把一种价值观伪装成超参数。

> 边界的一句话:**代码是史料的显微镜,不是史学家**。镜头倍数越高,越要记得切片是谁选的。

## 2. 代码走廊清单(三件套之二)

本家族四条走廊(由浅入深):

| 走廊 | 输入 | 输出 | 对应实验/章 |
|------|------|------|------------|
| C1 扩张曲线走廊 | 国家参数(起点/增速/层级阈值/性别门槛差) | 三层毛入学率曲线、三律断言 | `experiments/enrollment_waves.py`(✅ 已实现) |
| C2 学制移植走廊 | 传播边表 (甲制, 乙制, kind, 年份) | 时滞表、轮辐中心检测 | 04 章 §2.2 示例代码 |
| C3 文本考据走廊 | 学制/课文文本两版 | 条文 diff、术语首现年 | 04 章 §2.3 示例代码 |
| C4 谱系查询走廊 | 学校 DAG | 多跳沿革追溯、认古偏差统计 | 03 章 §1.5 schema 的直接应用 |

### 2.1 C1 数据字典(`enrollment_waves.py` 的参数即此模式)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| start_year | int | 该国现代学制建制起点(通说锚:先行国 1800 附近,后发国 1950 附近) |
| gdp_growth | float | 人均 GDP 指数增速;后发国更高(赶超通说)——压缩律的机制源 |
| theta[level] | float | 层级激活阈值(初等<中等<高等,对数 GDP 尺度)——梯度律的机制源 |
| gender_gap0[level] | float | 初始性别门槛差;高等最大——残差律的机制源;随时间指数衰减(规范扩散) |

### 2.2 C2 最小示例:移植时滞(纯标准库)

```python
EDGES = [                       # (源, 目标, 目标颁布年)  通说锚,03 章 §1.6 的展开
    ("法国学区制", "明治学制", 1872),
    ("普鲁士师范", "明治学制", 1872),
    ("明治学制", "癸卯学制", 1904),
    ("美国六三三", "壬戌学制", 1922),
]
def lag_table(edges):
    return [(src, dst, year) for src, dst, year in edges]
# 时滞读法:明治学制(1872)→癸卯(1904) = 32 年(转采时滞);
#           六三三(约 1910s 定型)→壬戌(1922) ≈ 10 年内(直采时滞)
# ⚠ 断言语义:时滞度量『制度文本的旅行』,不度量『观念的旅行』——
#   观念(如"义务教育"理念)常早于文本数十年到达(02 章 §1.1)。
```

### 2.3 C3 最小示例:学制文本考据(纯标准库)

```python
OLD = {"初等小学堂 五年", "高等小学堂 四年", "体操为必修"}     # 癸卯框架示意词条
NEW = {"小学 六年", "初级中学 三年", "高级中学 三年", "童子军"} # 壬戌框架示意词条
def diff_terms(old, new):
    return {"仅旧": sorted(old - new), "仅新": sorted(new - old)}
# diff_terms(OLD, NEW) 的输出即「一次学制更替新增了什么话语」的最小标本——
# ⚠ 示意为教学词条,生产版须用条文全文(T1),并按 02 章 §3 术语表归一
#   (「小学堂→小学」是更名,不是新制;diff 前先做同义折叠)。
```

### 2.4 C4 最小示例:学校建制谱系两跳(纯标准库)

```python
GENEALOGY = {                      # 边=分立/合并/升格/谱系主张(03 章 §2.3 schema)
    "京师大学堂": ["壬戌体系下的北京大学", "京师优级师范学堂一脉"],
    "北京大学": ["1952 年调整后的北京大学"],   # 并入/分出边略
}
def trace(g, node, hops):
    out, frontier = {node: 0}, [node]
    for h in range(1, hops + 1):
        nxt = [c for p in frontier for c in g.get(p, []) if c not in out]
        for c in nxt:
            out[c] = h
        frontier = nxt
    return out
# trace(GENEALOGY, "京师大学堂", 2) -> 谱系一瞥
# ⚠ 第一课:谱系查询必须能区分 rename(同构改名)与 lineage_claim(跨形态追溯)
#   ——否则「认古」偏差会被查询结果「科学地」确认(03 章 §2.3)。
```

## 3. 工程师落点:学制知识底座(三件套之三)

把 C1-C4 的数据合流,得到本家族对工程师最有用的产物——**学制知识底座**(节点:国家/学制/学校/层级;边:移植/沿革;属性:年份/证据等级)。三个落点:

1. **教育产品与合规的「制度年表」组件**:任何面向学校的系统(学籍/排课/学分)都内嵌一国学制假设(学年长度/层级划分/证书衔接);把假设显式化为带年份的底座字段,是跨国教育产品少踩「学制硬编码」坑的工程手段——改版学制(如某国 8+4→6+3+3)只改数据,不改代码逻辑。
2. **教育 Agent 的制度出处层**:智能体回答教育问题(年限/入学/证书)时,知识来源常为流语料——「幻觉学制」(把 A 国年限安到 B 国)是真实事故面。学制底座作为受控词表+年代字段+证据等级层,是防幻觉的工程手段;每条答案可附「依据:某国某年某法(证据级 T1)」。
3. **数字教育史的研究流水线**:01 章热线三的落地——学制全文库→diff→术语首现→扩张曲线→可视化;开源语料(法规公报/统计年鉴/课本库)是数据地基,选样规则写进 README 与写进代码同等重要(03 章 §6 的教训:先定「行主体资格」)。

**工程接口三问**(接入任何系统前自问):①国家字段怎么定的(当代国界还是历史主体)?②颁布年/实施年分档了吗?③传播边带不带 kind(直采/转采/平行)?

## 4. 已解决与未解决(③的代码版)

**已解决**:扩张三律的受控模拟在 `enrollment_waves.py` 跑通(exit 0,纯标准库);时滞表与文本 diff 有 20 行内可复现实现(§2.2/§2.3);谱系查询是 DAG 遍历的直接应用。

## 7. 反直觉发现(⑥)

**最容易做的走廊(C1 模拟)恰好最不能当证据,最难做的走廊(C2 学制库)才最有证据价值**。模拟脚本一天写完,但它的输出只是「机制充分性演示」;学制全文库需要数年考订,但每一条都是 T1 硬史料。数字教育史的投入产出呈倒挂:**出活快的不出真理,出真理的不出活**——与管理思想史家族「文献计量走廊」的处境相同(商业引文库墙 vs 概念曲线的速成)。工程决策的推论:模拟用于教学与假设生成,建设用于证据;把前者当后者交付,是数字人文最常见的事故。

## ✨ 美之时刻(⑧)

**✨ 美之时刻:把「教育发展阶段论」从口号变成 assert**。「梯度/压缩/残差」三律在教学大纲里是三句要背的话,在脚本里是三个可失败的断言——参数调偏一个,断言红给你看。**为什么美(通说的可错化)**:教育学的经验通说第一次获得了「拒绝服务」的能力——能被代码拒绝的命题,才配叫经验规律;不能被拒绝的,只是口号(02 章症状一的镜像);**怎么亲历**:把脚本里后发国的增速参数改成与先行国相同,重跑——压缩律断言立即失败,你会亲眼看到「后发压缩」需要一个机制前提(更高增速),而不是从天上掉下来;这一分钟的操作,就是机制史学的基本功。
