# 教育史思维技能卡

## 1. 何时用此分支(触发词)

遇到以下特征的问题/困惑,切到教育史眼光:

- 「这个教育制度(**义务教育/高考/学分制/学位服)哪来的**?」——制度考古
- **中外分流**:为什么中国长出科举而欧洲长出大学?为什么近代学制是「抄日本转手的西方」?(癸卯 1904→壬戌 1922)
- **观念落地**:「以儿童为中心」「义务教育」「通识教育」这些口号,原著说了什么、落地时变形了什么?
- 「这个国家**为什么这样办学**」——先查它的学制进口路线(轮辐中心:法→普→美)
- **长时段问题**:教育变量半衰期以百年计(学制框架 50-100 年,学位符号 800 年)——用十年尺度评价教育=用天气谈气候
- 「历史证明该教改正确」——查它的选样与反例(辉格史防御)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **建制眼** | 见任何教育安排先问:它出生那年替代了什么?谁立法?谁付钱?——制度是有日期的合同 |
| **双线咬合** | 观念与建制互相落位:观念没建制=停在书页,建制没观念=失去辩护词;找交叉点(科举↔选贤任能) |
| **移植眼** | 近代教育建制多为移植件;问「进口路线+本土改装」,警惕「自主演进」叙事(抄的是已消化的二手版) |
| **暗面眼** | 扩张与排斥同卷;每读一段教育进步史,主动找沉默者(谁没被写进「国民」) |
| **证据阶梯** | T1 学制原文/学校档案/课本实物 > T2 同代记述 > T3 学术研究 > T4 纪念话语;纪念性材料默认降一级用 |
| **机制眼** | 历史规律两步问:统计上成立吗(数据)?需要多复杂的机制(受控模拟)?——模拟证机制充分性,不证历史因果 |

## 3. 工具箱

- **四波建制叙事**:私学(波1)→中世纪大学(波2)→义务教育/学制(波3)→大众高教(波4)——可加层不可跳层
- **双线编年表**:年份×建制事件×观念事件两列对齐,交叉点即解释力最大的观察位
- **学制年表 schema**:{国家, 颁布年, 法规, 修业结构, 义务教育年限, 外来模板}——教材附录可直接机器化(03 章 §1.5)
- **移植边三值**:adopt(直采)/mediate(转采)/parallel(平行形似)——「形似≠传播」(书院≈academy 无边)
- **扩张三律断言**:梯度律/压缩律/残差律(`experiments/enrollment_waves.py` 即受控实现)
- **断言阶梯 L1-L4**:事实断言/学界共识/竞争解释/家族判读——L1 干瘪准确,L4 显式标注,混层是第一罪
- **术语对译表**:compulsory(强制的)≠「义务」(伦理的);universitas=行会法人非「大学」;毛/净入学率不可混(02 章 §3)

## 4. 常见误区与禁忌

- ❌ **进步史观**:更多学校≠更多解放——扩张史同时是排斥与同化装置的扩张史(寄宿学校判例)
- ❌ **颁行=实践**:纸面学制≠实际办学;颁布年/实施年/覆盖完成年三档必分
- ❌ 把**形似当传播**:「中国自古有大学(书院)」——功能类似≠谱系相连
- ❌ **动机单选**:普鲁士强迫入学动机(兵源/虔信/行政)是并列候选,法条沉默处不得脑补
- ❌ **辉格资治**:从今日结论倒挑历史证据;教育史当实验室可以,必须按规程(断言先行/选样公开/敏感性分析)
- ❌ 用**当代国界**套历史主体:德意志诸邦/清末省办/殖民地法条会让「一国一行」的表崩裂(03 章 §6)
