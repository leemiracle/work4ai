# 讲透中国教育史 · 私学-科举-近代学制三千年:一个文明的教育建制长跑

> **定位句**:这支负责中国线的建制编年——从「有教无类」的私学突破,经科举 1300 年的选官-教育耦合,到近代学制的移植与再造;回答「今天中国的学校形态为什么长这样」。
> GB/T 13745-2009:88011 教育史(GB/T 说明含中国教育史;未列三级明细)· 本支为**自定主干支**。家族:[../README.md](../README.md)。

## 诞生

约公元前 500 年,孔丘以私学破「学在官府」——「有教无类」四个字(《论语》通说引述)把受教育资格从血缘里解放出来;战国稷下学宫(「不治而议论」,兴废年代存 L3 争议)示范了国家养士与学术自治的平衡。前 124 年汉武帝立太学,官学定型;605 年(隋设进士科,起点有 L3 争议)科举启幕,此后 1300 年「学校养士、科目取士」,教育建制围绕考试轴心旋转;唐宋书院兴而复盛(朱熹《白鹿洞书院揭示》),官学-私学-书院三轨并行。1898 京师大学堂;1902-04 壬寅/癸卯学制(第一个实施的全国学制,以日本为中介移植西方体系);**1905 一纸谕令废科举**——三千年建制在一周内换了地基(通说:废科举与兴学堂几乎同步互为条件)。此后 1912 壬子癸丑、1922 壬戌(仿美六三三),近代学制两度转舵;1952 院系调整与 1977 恢复高考(通说)完成当代形态的两块最后拼图。

## 核心问题

已解决:
- 科举制度框架(科目/层级/中额)与 605-1905 断代的基础考订成熟(教材共识)
- 近代学制的移植链条(癸卯仿日→壬戌仿美)与钦定章程文本俱在(T1)

未解决:
- **科举的整体功过**——选官理性与教育窄化的百年公案;1905 废除的社会震动(乡村读书人出路/绅学结构)是近代史经典悬案(家族 00 章 §4)
- **书院的现代命运**——建制谱系上书院是被消解方(新学堂嫁接日本-西方体系),但「书院精神」话语为何在当代复活?(记忆政治题,接家族 03 章 §2.3「认古」结构)
- 私学传统是否有制度连续性——从孔门到书院到当代民办教育,「线」是真实的还是追认的?(判读标注)

## ✨ 这支最美的一个事实

1905 年 9 月,清廷谕令自丙午科起停止一切乡试会试——运行约 1300 年的科举制,由一道上谕终结;同年《学务纲要》仍在强调「以忠孝为敷教之本」。**为什么美**:制度史上罕见的「一刀切换轴」——不是失败后被推翻,而是朝廷自己砍掉自己最成功的选官机器,换上一套抄自日本转手西方的学校体系;旧机器最深的烙印(考试中心)却活进了新机器(升学考试体系),完成了一次「躯体移植、神经保留」。废科举次年,中国留学生数激增(通说),「上学」的定义被永久改写。
