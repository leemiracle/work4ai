# 讲透教育史 · 教育建制与观念的双线编年——教育学的记忆部

> **本质一句话**:教育史=「学校形态×教育思想」的双线编年——它不发明新教学法,却回答每个教育制度背后的三个问题:**这制度从哪来、谁在什么张力中把它造出来、为什么长成这样而不是那样**。
> GB/T 13745-2009:880 教育学 → **88011 教育史**。GB/T 说明「包括中国教育史、外国教育史等」,未列三级明细 → 本家族自定 3 支主干(各支标注「自定主干支」)。
> 范围声明:教育经济学(88031)归入经济学宇宙 79045、教育统计学归入统计宇宙 91040(见宇宙 [../README.md](../README.md) 挂靠表),本家族不涉及。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透教育史/
├── 讲透中国教育史/     📝 私学-科举-近代学制三千年(孔丘私学→科举 1300 年→癸卯-壬戌学制移植)
├── 讲透外国教育史/     📝 希腊-中世纪大学-国民教育(博洛尼亚的学生行会→普鲁士义务教育→Trow 大众化)
└── 讲透教育观念史/     📝 教育思想的观念接力(博雅→自然教育→儿童中心→终身学习)
```

三支不是三块封地,而是同一部编年的三个**镜头**:建制线(学校形态怎么长出来)、观念线(「什么值得教、谁能学」的思想怎么接力)、落地点(观念如何变成学制条文与校舍)——中国支与外国支各给一条完整建制线,观念支横跨两线拆思想接力。

## 四、前置与路径

- **零门槛**:本家族不需要教育学前置——它是学校制度的「纪录片」,不是「教学法说明书」;没读过教育学反而更容易看清制度的地质层。
- 推荐看法:先读 00 章建立双线+四波地图 → 挑一条建制线(中或外)读支宪法 → 卡在「这词哪来的」(义务教育/学分/博雅)时回观念支查归口。
- 深度路径:读任何教育制度(高考/学分制/义务教育)时,先问「它出生那年替代了什么」——本家族 00 章 §6 联系表给归口。
