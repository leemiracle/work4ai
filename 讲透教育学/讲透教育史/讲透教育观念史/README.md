# 讲透教育观念史 · 教育思想的观念接力:从博雅到终身学习

> **定位句**:这支负责观念线——拆「什么值得教、谁能学、为什么而学」的思想如何在时间中接力、变形、落地;主线一句:**观念落地必变形**。
> GB/T 13745-2009:88011 教育史(GB/T 未列三级明细)· 本支为**自定主干支**。家族:[../README.md](../README.md)。

## 诞生

轴心时代双源头同时开题:孔丘「有教无类」破受教育资格的血缘限制;柏拉图学园定「自由人之学」对「工匠之学」的千年等级。此后是接力而非独跑:七艺定型(古典)→文艺复兴人文主义(humanitas;维多里诺「快乐之家」1423)重述古典→**卢梭《爱弥儿》(1762)**引爆「自然教育」,儿童被发现为一个独立的存在(阿利埃斯《儿童的世纪》1960 通说:「儿童」概念本身有历史)→裴斯泰洛齐-赫尔巴特《普通教育学》(1806)把教育思考推入学科化→**杜威《民主主义与教育》(1916)**把「儿童中心」与「教育即生活」送进公立学校时代→朗格朗(1965)提出终身教育,把教育的时间边界从学龄拆到全生命周期→20 世纪后半学习科学/建构主义接棒。每一棒都不是传递而是改写:《爱弥儿》是家庭导师的小说,落进公立学校成了「以儿童为中心」的课程口号——**原著与建制之间隔着一次变形**。

## 核心问题

已解决:
- 主要观念的首创文献与基本谱系(爱弥儿-普通教育学-民主主义与教育链)考订成熟(教材共识)
- 「儿童概念的历史性」「终身学习概念的政策化」有标准研究史(通说)

未解决:
- **变形律的机制**——观念落地为什么必然变形?(候选:观念的多义性在制度化时被单义化;建制的选择性采借;话语的本土改装——三说并存,L3)
- **同名漂移**:liberal arts(七艺→博雅/通识)古今义差、「自然教育」从卢梭到蒙台梭利的语义位移——谱系图上的「画错的边」无自动检测(家族 03 章 §3)
- 观念的「无建制漂流」期怎么研究——有些观念(如「因材施教」)两千年有话语无建制,谱系如何画?(判读:用教材-蒙学读物的话语层接续)

## ✨ 这支最美的一个事实

1762 年《爱弥儿》出版,卢梭在开篇写「出自造物主之手的东西,都是好的,而一到了人的手里,就全变坏了」(通说译文)——一句堕落的诊断书,却成为教育史上最大的解放宣言:它宣布**儿童不是缩小的大人**,教育应跟随自然的发展而非灌造成品。同年巴黎议会焚毁此书,日内瓦下令逮捕作者(通说)——一个观念的出生证明,常常由两份文件构成:正文与禁令。**为什么美**:观念史的家页——最深远的教育变革常常先以「反教育」的面目出现(顺其自然=当时看来不教);**怎么亲历**:把任一当代教育口号(「快乐学习」「减负」)倒回它观念链的源头,数一数中途换了几次含义。

## 假设与依赖

- 观念有谱系可循假设:接力叙事需要主线——代价是大师史观(集体心态/匿名实践被挤出);补救:教材史与蒙学读物的话语层(03 章)
- 文本中心假设:以奠基文献为节点——代价:口头传播的教育智慧(工匠/家庭)不可见
- **区分注记(与哲学侧教育哲学)**:本支研究教育观念**在时间中的接力与变形**(历史学问题:从哪来、怎么变);教育哲学研究教育的**哲学前提**(非时间性问题:什么是教育、教育的正义)——两者共享人物(柏拉图/卢梭/杜威)不共享问题。教育哲学的建制归属横跨教育学与哲学;哲学宇宙现未建教育哲学家族(文字提及),其伦理学/西方哲学史家族与本支在人物层互为邻人([../../../讲透哲学/README.md](../../../讲透哲学/README.md)),问题层各自为政。
