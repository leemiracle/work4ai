# 03 · 可构造与结构——教育史料作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:教育史里「可构造」的不是教育本身,而是教育的**制度痕迹**——学制年表、学校建制谱系、教育传播网络、入学率序列;而「结构」是扩张与移植自身的骨架:**梯度律、压缩律、残差律**与移植网络的拓扑。

---

## 0. 开篇:一张学制表就是一座数据库

拿任一本教育史教材附录的「近代学制沿革表」(壬寅 1902/癸卯 1904/壬子癸丑 1912-13/壬戌 1922),把每行拆成字段:颁布年、修业结构(如壬戌「六三三」)、义务教育年限、女子教育条款、职业教育地位、外来模板。四行拆完,你手里就有一张可以直接查询的表——**问「义务教育年限哪年从 X 改到 Y」「女子条款哪年首次出现」,眼睛扫表不如代码扫库**。这不是修辞:学制数据天然结构化(年-法-条文),是全部史学对象里离数据库最近的一类。本章的任务:把教育建制、观念、传播三线的痕迹全部变成可构造对象,把「扩张三律」从叙述变成可断言结构。

## 1. 什么是「可构造」的:四类史料对象

| 研究对象 | 数学化身 | 可构造性 | 构造中的坑 |
|---------|---------|---------|-----------|
| **学制年表** | 表: {(国家, 年份, 法规, 结构字段…)} | ✅ 完全可构造(教材附录即雏形) | 「颁布年≠实施年≠覆盖完成年」三档必分;纸面学制与实际办学的落差不可消 |
| **学校建制谱系** | 树/DAG(学校-学校:分立/合并/升格) | ✅ 可构造(校史档案+建制法规) | 谱系政治:校庆叙事普遍「认古不认近」,始年选择性追溯(合并校各自挑光荣祖先) |
| **教育传播网络** | 有向图(甲制→乙制, 边=移植/借鉴) | ✅ 可构造但边权主观(移植/借鉴/平行) | 「形似≠传播」(书院≈academy);转手移植(癸卯←日本←法美)的边要分直采与转采 |
| **入学率序列** | 时间序列 {(国家, 年份, 层级, 毛入学率, 性别)} | ✅ 长时段重建成熟(19 世纪国民教育起有统计;更早靠间接估计) | 早期数字口径不一(在校/注册/人口基数);毛/净不可混(02 章 §3);残缺段插值必须显式标注 |

**不可构造的**:课堂现场(教与学的实际过程,前近代几乎全佃——只能从课本批注、作业本等 T1 碎片侧写);受教育体验(口述史部分补救,记忆可塑);「教育的效果」(短期无对照组,长时段混杂太多——教育史只能给相关与机制,给不了因果定论)。

**代理变量的坑(前近代入学率的间接估计)**:19 世纪统计序列之前,「教育规模」只能用代理变量侧写——签名率/遗嘱画押率(识字的有损代理:会签名≠会读写全文)、科举应试人数(只覆盖男性精英轨道)、教区名册(口径随教会行政漂移)。通说做法是**多代理三角定位+区间表述**;单代理直接换算成「识字率 X%」的数字,是数据表里的隐形炸弹——构造入学率序列时,估计段必须与统计段分列(02 章 §3 的「估计」标签)。

### 1.5 最小数据模式(想动手者的 schema)

```yaml
# 学制年表条目
system: {country: str, year: int, statute: str, structure: str,
         compulsory_years: int|null, female_edu: str, template: [国家…], tier: T1}

# 学校建制谱系边(分立/合并/升格/改隶)
edge: {from_school: 学校A, to_school: 学校B, kind: split|merge|upgrade|rename,
       year: int, evidence: 法规/档案定位}

# 传播边(直采/转采/借鉴/平行形似)
edge: {from: 甲学制, to: 乙学制, kind: adopt|mediate|borrow|parallel,
       lag_years: int, evidence: 文献定位}

# 入学率观测点
obs: {country: str, year: int, level: primary|secondary|tertiary,
      ger_m: float, ger_f: float, source_tier: T1|T2|estimate}
```

### 1.6 工作例:癸卯学制的传播边按 schema 展开

```yaml
- from: 法国学区制
  to: 明治《学制》(1872)
  kind: adopt          # 中央学区框架直采(另混美英元素)
  lag_years: null
  evidence: 学制条文比较研究(T3 通说)
- from: 明治《学制》/日本近代学校体系
  to: 癸卯学制(1904)
  kind: mediate        # 转采:以日本为中介的西方制度包
  lag_years: 32
  evidence: 癸卯章程的日式术语与顾问痕迹(T1 条文+T3 通说)
- from: 美国六三三制
  to: 壬戌学制(1922)
  kind: adopt
  lag_years: null      # 直接仿美(1910s 美国体系定型后不久)
  evidence: 学制会议文献(T2/T3 通说)
```

注意:①边必须带 kind——把「转采」画成「直采」会凭空缩短时滞、虚构理解深度;②lag_years 只对有明确源头的边可算;③「中国书院→近代学校」**没有边**(建制谱系上,新学堂嫁接的是日本-西方体系,书院是被动消解方)——谱系图上敢于**留白**,是它区别于民族主义叙事图的地方。

## 2. 结构骨架:扩张三律与移植拓扑

### 2.1 扩张三律(实验脚本的骨架,04 章 C1)

教育扩张的长时段数据中有三条教科书通说级规律,`experiments/enrollment_waves.py` 把它们做成可断言结构:

| 律 | 断言内容 | 通说依据 |
|----|---------|---------|
| **梯度律** | 初等→中等→高等依次启动;各层级入学率增长均呈 S 型(慢-快-慢) | 国民教育先于中等扩张、中等先于高教大众化的全球序列;S 型为扩散过程通说 |
| **压缩律** | 后发国家同一层级从低覆盖率到高覆盖率的扩张用时短于先行国 | 二战后教育扩张数据的通说(「后发压缩」;发展与教育社会学经典结论) |
| **残差律** | 性别差距随扩张收敛,但高教层收敛最慢(残差最大) | 各国毛入学率性别 GPI 数据的长时段通说模式 |

**方法论地位**:三律在真实数据中是**统计倾向**,在实验脚本中是**受控模拟的涌现性质**——用 GDP 阈值+逻辑斯蒂增长生成扩张,检验三律是否在同一套简单机制下同时出现。模拟证明的不是「世界如此」,而是「如此机制足以如此」(04 章 §0 的读法纪律)。

### 2.1.5 工作例:特罗两线的手算(三律与阶段论的接口)

特罗阶段论的 15%/50% 两条线,在逻辑斯蒂框架下有闭式解:某层入学率达 p% 的年份 = 阈值年 + ln(p/(100−p))/(kappa·r)。以虚拟原型「后发·东亚型」(实验脚本参数)手算高教层:50% 线 = 阈值对应年 + 0;80% 线 ≈ 阈值年 + 1.386/(6×0.032) ≈ +7.2 年;先行原型同一算式 ≈ +19.3 年——**同一数学结构,后发的「阶段间耗时」被增速 r 压缩**,这正是压缩律的解析形式(04 章 C1 的模拟是它的数值版)。真实数据作业(00 章 §8 练习 2)就是把此式反过来:用两国实测跨越年差,反推「有效增速比」。

### 2.2 移植网络的拓扑:轮辐与世界化

把 19-20 世纪的学制传播边画成图,会看到**轮辐结构**:中心轮依次是法国(大革命后体系)、普鲁士(师范与实科)、美国(六三三与综合中学)、苏联(50 年代援建线)——每个时代有一个「被抄中心」,边缘国家大多经一个中介转抄。拓扑变化即时代变化:轮辐中心换位(法→美)的年份,与全球学制表的大修订潮同步(判读)。**可检验推论**:直接采用国与转手采用国的学制「骨架相似度」应高于同语言邻国——可作为 04 章 C2 走廊的断言候选。

轮辐中心的换位表(通说锚,示意):

| 时期 | 被抄中心 | 被抄走的构件 | 典型转手者 |
|------|---------|-------------|-----------|
| 19 世纪初-中 | 法兰西 | 学区制/中央集权/师范雏形 | 普鲁士(部分)、拉美诸国 |
| 19 世纪中-末 | 普鲁士 | 师范学校/实科教育/强迫入学立法 | 日本(明治)、美国(部分州) |
| 20 世纪初-中 | 美利坚 | 六三三制/综合中学/选修制 | 日本(昭和研究)、中国(壬戌 1922) |
| 20 世纪中-后 | 苏联(区域性) | 专才培养/对口援建院系 | 1950s 中国院系调整期(通说) |

**表的使用纪律**:被抄中心是**吸引子不是设计者**——中心国并不输出完整方案,转手者的拼装(如明治学制的法骨美皮)才是常态;把轮辐表读成「宗主-附庸」的传播帝国论,是对拓扑的过度诠释(L3 警示)。

### 2.3 建制谱系的「认古」结构

学校建制谱系有一个可统计的系统性偏差:合并与升格链条中,**始年选择性地追溯至链条里最古老的节点**(书院/讲习所),而不是办学形态实质改变的节点。可构造检验:对一组高校的「校庆始年 vs 建制法规首次出现年」做差,若差的中位数达数十年,即证实「认古」结构——谱系图的边权里藏着记忆政治(01 章热线一的数字版)。

**工作例**:某近代大学堂(1898 前后建制)合并了一所书院(明末讲学之地),校庆定年在书院一端——两节点间的「改朝换代式断裂」(课程/学位/师资全换)在谱系图上被画成一条平滑的继承边。schema 的处置:`kind: rename` 只允许用于「同构改名」;跨形态追溯必须用 `kind: lineage_claim`(谱系主张)并强制挂证据级——**把记忆政治从数据里显式分离出来,而不是假装它不存在**(家族判读,支层细化)。

## 3. 已解决与未解决(③的可构造版)

**已解决**:学制年表的结构化字段方案成熟(教材附录可机器化);入学率长时段重建的口径规范(毛/净、年龄段)已国际标准化(教科文序列);扩张三律的受控模拟可复现(实验脚本,exit 0)。

**未解决**:①「实施年」的量化——纸面学制何时变成实际办学,缺系统数据,只能逐国考订;②前近代入学率的间接估计(识字率代理变量)口径未统一;③传播边的 kind 自动判定(adopt/mediate/parallel)无算法——谱系最大缺口;④「课堂现场」的结构化(课本批注、作业本的数字人文处理)刚起步(01 章热线三)。

## 6. 反直觉发现(⑥)

**学制年表「最像数据库」的学科,反而最难做数据库**。字段如此结构化(年/法/年限),照理教育史应最早建成跨国学制库;实际上至今没有权威的全球学制全文数据库——因为「国家」字段先塌:德意志诸邦、清末民初的省自办学、殖民地的宗主国法条,都让「一国一行」的表结构崩裂。**结构教训**:数据Schema的第一难度不是字段,而是**行的主体资格**——谁算一个「国家」,是史学判断,不是工程决定。这与孔茨丛林同构:数不清的部分=主体未定的信号。

## ✨ 美之时刻(⑧)

**✨ 美之时刻:三条律在一个 250 行脚本里同时出现**。`experiments/enrollment_waves.py` 用「GDP 越过阈值→某层级逻辑斯蒂扩张」这一套机制,同时涌现出梯度、压缩、残差三律——没有为每条律单独写规则。**为什么美(机制的节俭)**:三个跨国经验通说,竟可以被一个两参数机制(阈值+增速)同时生成;复杂的历史图案背后可能站着极简的发生学——模拟的意义不在复刻世界,在**证伪「需要更复杂解释」的直觉**;**怎么亲历**:跑一遍脚本,再把某国的扩张增速参数调慢重跑,看三律哪些稳、哪些破——参数敏感性就是你对「机制是否唯一」的第一次亲手审判。
