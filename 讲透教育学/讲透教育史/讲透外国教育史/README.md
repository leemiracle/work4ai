# 讲透外国教育史 · 希腊-中世纪大学-国民教育:西方学校建制的三跳

> **定位句**:这支负责外国线的建制编年——从希腊的自由人之学,经中世纪大学的法权发明,到国民教育与大众高教;回答「现代学校的全球模板是从哪张图纸上复印出来的」。
> GB/T 13745-2009:88011 教育史(GB/T 说明含外国教育史;未列三级明细)· 本支为**自定主干支**。家族:[../README.md](../README.md)。

## 诞生

约前 387 年柏拉图立学园(Akademia),自由人之学(liberal,对工匠之学 banausic)定了「什么值得教」的千年等级;昆体良《雄辩术原理》(约 95 年)总结罗马雄辩教育,七艺(三学部+四学部)框架渐次定型(通说)。12 世纪,博洛尼亚(传统建校年 1088)与巴黎把罗马法的**法人**(universitas)概念挪用为学术行会——学生行会(博洛尼亚,学生雇教授)与教师行会(巴黎)两种母型,学位(学士-执教许可证-博士)与四系(文/法/医/神)自此成型;这套法权装置活过帝国与教派,是建制史上最长的连续法人(家族 00 章 §7.2)。宗教改革推识字(路德 1524《致市长们的信》,因果权重存 L3);普鲁士 1763 乡村学校规程首倡强迫入学;19 世纪国民教育定型——贺拉斯·曼公共学校运动(1830s-)、福斯特法案(英 1870)、费里法(法 1881-82);20 世纪进步主义(杜威芝加哥实验学校 1896)与大众高教(克尔「巨型大学」1963;特罗阶段论 1973)完成第四跳。

## 核心问题

已解决:
- 中世纪大学的法权起源(行会-法人-执教许可证链)与两种母型(学生/教师行会)的考订成熟(教材共识)
- 19 世纪各国义务教育立法序列(1763/1870/1881-82/1872)时间表稳定(T1 法规层)

未解决:
- **国民教育的动力之争**——国家建设/教会竞争/工业化/民主化四解释各有强证据区段,无一全胜(家族 00 章 §4;普鲁士先于工业化高峰是经济决定论的反例)
- **大学为何生于 12 世纪西欧而非罗马**——候选答案:罗马法复兴供出法人概念+教权-政权两强夹缝留出自治空间(判读)
- 西欧中心叙事的边界——拜占庭-阿拉伯教育线(智慧宫等)、殖民教育的层级化,是「外国教育史」的应有板块还是另一部全球史?(正典之争,接家族 01 章公共转向)

## ✨ 这支最美的一个事实

中世纪博洛尼亚的学生行会掌握着今人难以想象的权力:外邦学生组成法人(universitas scholarium),与市政当局谈判集体特权,并**雇佣教授**——合同定薪资课时,教授迟到罚款、讲义注水则面临学生集体「罢学」与解聘。「大学自治」的第一批受益者是学生集体,不是教授。**为什么美**:今天「学生是顾客」这句争议口号,在 12 世纪是字面制度;权力从学生行会转移到教师行会再到行政科层的三步,浓缩了大学八百年的组织史——你现在的师生关系,是这个八百年钟摆的当前位置。

## 假设与依赖

- 西欧主线假设:以希腊-中世纪-近代西欧为干线(全球模板的出处)——代价:拜占庭/阿拉伯/非西方线降为内节;殖民教育史按史实通说处理(家族 00 章 §5 暗面眼)
- 「外国」的界定:以学制母型谱系而非国别堆叠组织(轮辐中心:法→普→美;家族 03 章 §2.2)
- 教材通说为主轴,争议(如宗教改革与识字率的因果)显式标 L3
