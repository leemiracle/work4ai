# 讲透教育评价与问责 · 凭什么说这所学校好——测评-问责链

> **定位句**:这支负责"**测量层**"——从学校效能测量到问责制度:
  凭什么说这所学校好(效能指标/增值评价/识别三问)、
  测评结果怎么接上后果(问责链:指标+权重+审计+奖惩)、
  问责制为什么会反身性地伤害它想测的东西(古德哈特教育版)。
  三支中**测量气质最浓**的一支:治理的主张最终要在这支过秤。
> GB/T 13745 88034 教育管理学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透教育管理学](../README.md)

## 诞生

- **谁/何时**:科尔曼报告(1966,学校效应之问出生);埃德蒙兹等
  有效学校研究(1970s,特征清单);增值评价兴起(1990s-2000s,
  残差分离起点与贡献);标准与问责运动(1990s 末-2000s,
  按文献通说陈述为现象,不评价政策);古德哈特定律教育版的
  大量记录(2000s-)。
- **因什么问题**:①两所学校分数悬殊,差异是教出来的还是招出来的
  ②问责要有依据,依据要可测量、可比较、可复核
  ③测量一旦与利害挂钩,被测者开始优化指标而非质量——怎么办。

## 核心问题

**已解决**:
- 学校间效能差异真实存在(有效学校研究对"学校不重要"误读的回应)——共识级
- 增值思想:残差=超出生源期望的学校贡献,把中心混淆变成可估计量——方法共识
- 高利害指标引发应试窄化与博弈,被大量记录——现象共识(机制可参数化)

**未解决/深水区**:
- **识别的薄证据**:选择性(谁进哪所学校非随机)、教师效应与学校效应
  纠缠、增值估计跨年不稳定——"这所学校到底好不好"永远比政策想象薄
- **问责设计三教训的制度化**:多指标/分散权重/抽样深查在实验里干净
  (家族实验),落地时与成本、误判率、多期博弈竞速
- **"有效学校特征"的因果性**:特征清单是相关档案,常被当配方卖
- **低利害/高利害的分界**:诊断性使用与排名性使用是两种制度,
  边界画在哪(01 章判读 3)

## ✨ 这支最美的一个事实

**增值——把"教得好"从"收得好"里减出来**:先按学生先验成绩预测
后验成绩,实际减预测的残差就是"超出生源期望"的学校贡献。
一个减法,把教育管理学的中心混淆变成可估计的量;代价同源——
残差把一切未测因素也扫进"学校贡献"(家族 02 章彩蛋的展开)。
