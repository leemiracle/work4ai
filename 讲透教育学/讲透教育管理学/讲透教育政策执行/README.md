# 讲透教育政策执行 · 从政策文本到课堂的最后一公里

> **定位句**:这支负责"**落地层**"——政策决定之后发生的事:
  教育政策怎么经过教育行政部门、校长、教师层层转译才抵达课堂、
  实施缺口(implementation gap)为什么是常态而非事故、
  一线专业人员(街道层官僚)的事实裁量怎样悄悄重新制定政策。
  三支中**田野气质最浓**的一支:它蹲在治理链的末端,
  数每一层的损耗。
> GB/T 13745 88034 教育管理学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透教育管理学](../README.md)

## 诞生

- **谁/何时**:政策执行研究的兴起(1970s,从"重决策轻执行"的
  政策科学里分家);普雷斯曼-韦达夫斯基《执行》(1973,
  执行研究开山,联合计划在层层转译中溶解的经典案例);
  利普斯基街头层官僚理论(1980,一线人员的裁量即政策再制定);
  实施保真度(fidelity)测量与学校改进运动(1990s-2000s)。
- **因什么问题**:①政策通过了却什么都没变——落差出在哪
  ②同一个政策在不同学校长出不同样子,算失真还是适应
  ③"执行力差"是道德叙事,怎么变成可测量的问题。

## 核心问题

**已解决**:
- 实施缺口是结构性常态:多层转译的保真度近似连乘,每层 0.8,
  四层后只剩四成——乘法性损耗是机制不是失职(家族 04 章走廊 4)
- 一线裁量不可避免:政策不可能预先规定课堂的每个情境,
  教师的事实裁量就是政策的最终形态(街道层官僚通说)
- 保真度与适应性的二分:忠实执行 vs 情境再创造,是执行研究的
  标准分析框架——共识级

**未解决/深水区**:
- **保真度还是适应**:偏离政策到什么程度算走样、什么程度算
  本土化——无判据可裁,是执行研究的中心未决
- **测保真度靠谁**:自查有偏、观察昂贵——剂量数据(实施了没有、
  实施了多少)是整个证据链最薄的一段([教学论 02 章]同病)
- **执行研究的设计**:政策不能随机分发,因果识别难与
  家族 02 章三只拦路虎叠加
- **数字化执行**:平台直达(砍中间层)是解药还是新病
  (01 章方向锚:教育管理数字化)

## ✨ 这支最美的一个事实

**街头层官僚——政策的最终形态是一线的裁量**:政策文本写得再细,
也不能规定教师面对这节课这批学生的每个判断;教师在前线的
自主裁剪不是执行的偏差,而是政策在社会现实中的**再制定**。
这个构念把"基层不执行"的道德叙事翻转为"政策在哪一层被谁
改写"的经验问题——与家族"科层与专业双逻辑"同根:
执行层正是专业引擎与科层图纸的接缝处。
