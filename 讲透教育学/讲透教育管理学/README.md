# 讲透教育管理学 · 学校这台双引擎机器怎么治理——科层与专业的双逻辑

> **本质一句话**:教育管理学=教育场景的治理学——学校与教育系统
> 怎么被组织、被领导、被测量、被问责。它站在一个别的管理学科没有的
> 交叉口上:学校既是**科层组织**(有层级、有规章、有上级),又是
> **专业组织**(教师凭专业判断工作,像医生而不像流水线工人)——
> **科层逻辑要标准与服从,专业逻辑要自主与信任**,两套逻辑各有正当性;
> 教育治理的全部艺术,就是在两者之间设计接口。第一主题:
> **问责怎么设计才不伤害专业自主**。

## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透教育管理学/              GB/T 88034(无三级明细,自定主干支)
├── 讲透学校治理与领导力/   自定支——组织层:校长学/分布式领导/共治结构(卡伯莱-明茨伯格-利斯伍德线)
├── 讲透教育评价与问责/     自定支——测量层:测评-问责链/学校效能/增值评价(科尔曼-埃德蒙兹-标准运动线)
└── 讲透教育政策执行/       自定支——落地层:从政策文本到课堂实践的最后一公里(实施缺口-街道层官僚线)
```

> 三支的共同血统:**同一条问责链的三段分工**——治理层(决策权怎么配置)、
> 测量层(凭什么说学校好)、执行层(政策怎么落进课堂)。
> 三段合成教育治理的完整回路:治理定权,测量供据,执行交付。
