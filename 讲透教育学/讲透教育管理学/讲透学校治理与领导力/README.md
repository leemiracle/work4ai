# 讲透学校治理与领导力 · 决策权怎么配置——校长学与分布式领导

> **定位句**:这支负责"**组织层**"——学校这台双引擎机器的权力结构:
  校长学(校长做什么、凭什么起作用)、分布式领导(领导是实践不是职位)、
  共治结构(教师/家长/学生/社区怎么进入决策)。三支中**理论气质最浓**
  的一支:它问的是治理的"宪法层"——谁对什么有决定权,
  科层与专业的接口画在哪。
> GB/T 13745 88034 教育管理学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透教育管理学](../README.md)

## 诞生

- **谁/何时**:卡伯莱《公立学校管理》(1913,科层学校的管理学);
  盖策尔斯-古巴社会系统模型(1950s 理论运动);明茨伯格《结构在配置》
  (1979,学校=专业官僚制原型);利斯伍德等的学校领导力综合研究
  (1990s-2000s,"课堂之外最重要因素"+间接效应论断);斯皮兰
  《分布式领导》(2004,领导=领导者-跟随者-情境的实践);
  共治研究线(理事会/评议会结构,01 章主线 C/D 的素材地)。
- **因什么问题**:①学校既是科层又是专业,权力到底怎么摆
  ②"好校长"是天生的还是可培养的,校长凭什么影响学校
  ③教师/家长/学生该在多大程度上进入正式决策。

## 核心问题

**已解决**:
- 学校的组织类型判定(专业官僚制:操作判断权在专业侧,科层包支持结构)——类型学共识
- 领导力效应为正且以间接传导为主(经集体效能/教学组织等中介)——综述通说
- 决策权配置可表格化审计(权责真空/冲撞/死锁三查)——构造层共识(家族 03 章引擎 2)

**未解决/深水区**:
- **科层-专业接口画在哪**:哪些议题必须标准化(安全/底线/经费),
  哪些必须放权专业(内容/教法/评价)——情境化问题,无一般解
- **领导力可培养吗**:校长培训项目的效果证据薄弱(01 章方向锚的公开批评)
- **共治的信任条件**:正式参与结构完备而信任不足时共治空转(学生运动
  压力测试给出的证据;01 章主线 C)
- **非正式权力**:资深教师的事实否决、家长舆论——矩阵外的治理暗物质

## ✨ 这支最美的一个事实

**分布式领导的构念搬家**:"领导"从校长这个人身上搬到"领导实践"
——活动在领导者、跟随者、情境的交互中分布展开。一次换主语,
让"人人都有领导力"从口号变成可研究的问题(在哪里发生、如何分布、
何时更有效);它同时是方法论宣言:换个主语,整门研究重新开始
(家族 00 章美之时刻 2 的展开)。
