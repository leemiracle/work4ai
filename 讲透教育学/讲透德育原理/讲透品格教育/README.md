> 挫折(1928-1930)与元分析时代的实证回归**。

## 诞生

- **谁/何时**:亚里士多德《尼各马可伦理学》(美德=习惯);1920s 美国
  品格教育运动;哈特肖恩-梅《欺骗研究》(1928-1930,诚实跨情境低相关的
  世纪教训);里克纳《为品格而教育》(1991,回归纲领);1992 六大支柱
  (诚信/尊重/责任/公平/关怀/公民);2010s 起元分析线与美德伦理书系
  (Jubilee Centre 谱系)——实证转向(家族 01 章主线 A)。
- **因什么问题**:①教什么(清单谁定——多元社会的价值选择)②怎么养成
  (直接教/习惯/校风社区)③品格可测吗(实证转向的核心难题)。

## 核心问题

**已解决**:
- 美德分流(理智美德可教/道德美德靠习惯)——通说;品格教育=家庭×学校×
  社区合力(里克纳式综合)——运动内部共识
- 品格行为是情境化的(哈特肖恩-梅)——通说实证;此后一切品格测量
  都在这份调查的阴影下工作

**未解决/深水区**:
- 清单的合法性:多元社会没有选出价值清单的共识程序("谁的价值")
- 品格可测吗:自评↔行为证据弱耦合;元分析效应的解释(哪部分成分起效)
- 直接教与间接养成的配比:美德课、校风、社区服务各贡献多少

## ✨ 这支最美的一个事实

**一页清单压缩两千年的价值史**:六大支柱把亚里士多德式美德传统压进一页
可张贴的海报——传播力惊人,代价同样惊人:清单上每个词(如"尊重")背后
是一整场未结束的伦理学争论,而清单的语法(名词化、可张贴)恰恰把这些
争论藏了起来。词形即理论(家族 02 章美之时刻 4 的清单版现场)。

## 假设与依赖

- 品格可分解假设(整体美德可拆成可教的清单单元)——买到课程可操作性;
  付出:哈特肖恩-梅的反证——拆出来的片段恰恰失去整体性
- 习惯养成假设(重复的正当行为沉淀为稳定品格)——买到养成式教育学;
  付出:情境边界使"跨情境迁移"成为例外而非默认
- 价值内容由伦理学供:
