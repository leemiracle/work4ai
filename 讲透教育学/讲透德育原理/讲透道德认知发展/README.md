# 讲透道德认知发展 · 品德怎么形成:从他律到自律到关怀的三级接力

> **定位句**:这支负责"**品德怎么形成**"——道德判断沿可观察的序列长大:
> 皮亚杰他律→自律(1932)、科尔伯格六阶段(1958)、吉利根关怀之声(1982)
> 三级接力;测量学决定(**结论不计分,理由才计分**)住这支。
> **自定主干支声明**:GB/T 88021 未列三级明细,本支为家族自定主干支之一。

## 诞生

- **谁/何时**:皮亚杰《儿童的道德判断》(1932,对偶故事);科尔伯格
  (1958 博士论文起:道德判断访谈+海因茨两难+纵向追踪;雷斯特 DIT 为
  其标准化侧);吉利根《不同的声音》(1982,对计分标尺的内部批评)。
- **因什么问题**:①道德判断有没有可辨的发展序列 ②序列普遍还是文化
  ③只有"正义"一把标尺吗 ④测到推理,推理管得住行为吗(判断-行为差距)。

## 核心问题

**已解决**:
- 他律→自律;三水平六阶段+理由计分法;结论不含阶段信息(同一结论可出自
  不同阶段理由)——共识(描述层);关怀取向独立地位,后续实证:取向随
  情境切换、与性别弱相关——通说

**未解决/深水区**:
- 阶段序贯性证据仍以特定样本为主,纵向稀少;跨文化分层(前四阶段较稳,
  阶段5集中于特定人群——通说综述);"后习俗更高"是描述还是规范(之争)
- 推理-行为差距的机制:道德认同(Blasi)vs 情境力量,两线未合流

## ✨ 这支最美的一个事实

**答案不算分,理由才算分**:科尔伯格把测量对象从"对错"换成"结构"——
道德不再是答对答错的清单,而是理由形状标定的阶梯;认知发展线的教育学
全部建立在这一个计分决定上
(数值复现见[家族实验](../experiments/kohlberg_dilemmas.py)断言 1)。

## 假设与依赖

- 发展假设(沿序列向上)——买到阶段计分与"促进发展"的教育学;付出:
  阶段暗含价值等级,普遍性证据有分层
- 理由可编码假设(访谈理由可公共计分)——买到科学地位;付出:评分者
  信度与跨语言等值性是永久成本
- 工具上游:伦理学([../../../讲透哲学/讲透伦理学/](../../../讲透哲学/讲透伦理学/));
  发展心理学为母学科(宇宙未建,文字提及)
