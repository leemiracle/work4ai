# 讲透社会情感学习 · SEL:从非认知能力话语到全球建制化

> **定位句**:这支负责"**道德怎么教**"的当代形态——把道德教育改写成
> 能力教育:非认知话语(2000s 人力资本证据)催生 CASEL(1994)与五能力
> 框架(2013 修订),经元分析与跨国测量(SSES)完成建制化——同时引来
> "测的是什么、谁定的标准"的系统性质询。
> **自定主干支声明**:GB/T 88021 未列三级明细,本支为家族自定主干支之一。
> 家族:[../README.md](../README.md)(宇宙:[../../README.md](../../README.md))

## 诞生

- **谁/何时**:CASEL 1994 年成立;《促进社会和情感学习》(1997)奠基
  定义;五能力框架(自我意识/自我管理/社会意识/人际技能/负责任的决策)
  2013 年修订;Durlak 等 2011 元分析通说数字(学业成绩平均高出约 11 个
  百分位);OECD SSES 首轮结果 2021 年公布(通说事实);2020s 进入
  多国政策文件——建制化完成态。
- **因什么问题**:①认知测验解释不了的人生结果——"非认知"因素是否可教
  可投资 ②多元社会如何绕开"谁的价值"之争——能力化方案 ③绕开了吗。

## 核心问题

**已解决**:
- 五能力框架的建制共识:政策文件的通用语法
- SEL 干预的平均正效应(元分析层)——通说;哪部分成分起效仍开放

**未解决/深水区**:
- 测量之争:自评量表的社会赞许性、跨文化测量等值性(同一问卷在 A 文化
  测的是不是同一能力)
- "谁的价值"的回归:"负责任的决策""社会意识"的操作化里埋着规范性
  选择——声称中立,答案写进了细则(家族 01 章主线 B)
- 能力化是升级还是替换:把"道德"改写成"技能",换政策通行证、丢规范
  内核——定义之争(家族 00 章问题清单末行)

## ✨ 这支最美的一个事实

**一张矩阵让百年道德争论进入公文**:五能力×场景矩阵把"人怎么变好"
这个两千年的规范难题,改写成"格子里填什么"的管理问题——政策通行证
的语法由此诞生。同一动作的美与险:格子可派活、可验收,但列(场景)与
格(能力)的定义本身就是价值决定——史上最成功的德育话语工程,
内部藏着它声称绕开的那个问题。

## 假设与依赖

- 可能力化假设(道德/社会性可分解为可训练的心理技能)——买到政策可
  管理性与投资语言;付出:规范性被摊平(技能的语言装不下"为何值得")
- 可测假设(自评量表能测到能力)——买到跨国可比(SSES);付出:社会
  赞许性与等值性两大误差源随规模一起放大
- 证据底座依赖心理测量学与人力资本研究(心理学宇宙未建,文字提及);
  规范层上游是
