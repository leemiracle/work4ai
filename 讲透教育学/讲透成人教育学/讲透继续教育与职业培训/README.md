# 讲透继续教育与职业培训 · 组织层:在职学习与技能重塑

> **定位句**:这支负责"**组织层**"——离开学校后的学习大多发生在
> 职场:在职培训、非正式学习(70-20-10 是其口号版,当假设不当
> 定律)、行动学习、技能重塑(reskilling/upskilling)。它守着
> 本家族的第二铁律:**技能折旧是组织的隐形负债**——账本上看不到,
> 直到技术冲击把它变成裁员名单;而**转行难,难在卸载不在习得**
> (经验税:老手的旧框架是抵押品),所以"先失业再培训"贵过
> "在岗持续学习"(家族实验断言②)。
> GB/T 13745 88057 成人教育学 · **自定主干支**(GB/T 未列三级明细,
> 本家族自设以承组织层)。
> 家族:[讲透成人教育学](../README.md)

## 诞生

- **谁/何时**:德鲁克 1959 造"知识工作者"并预言继续教育成为
  最大产业(通说转述);雷文斯 1940s 起在医院与煤矿发展行动学习
  (L=P+Q:程序知识+洞察提问);马希克-沃特金斯 1990 系统化
  "工作中的非正式与偶然学习";圣吉 1990《第五项修炼》立学习型
  组织;2010s 起技能半衰期话语兴起,WEF《未来就业报告》线持续
  发布技能颠覆预估(2025 版:到 2030 约 39% 关键技能将改变——
  检索校准 2026-09-07,按素材转述);微证书成为学历外凭证新形态。
- **因什么问题**:①学历教育的一次性储备跟不上职业知识的加速
  折旧——继续教育制度化;②课堂培训覆盖不了职场学习的多数
  (岗位上/同侪间)——非正式学习进视野;③技术冲击下整段技能
  作废(不只贬值)——reskilling 从福利词汇变成生存词汇。

## 核心问题

**已解决**:
- 职场学习三来源的通说框架(岗位/同侪/课程——70-20-10 为口号版)
- 技能差距诊断的方法学:需求向量−供给向量=学习队列(家族 03 章)
- 培训效果的证据规范:自评膨胀三问(对照/口径/谁没来,02 章)

**未解决/深水区**:
- **通用培训的市场失灵**:企业怕培训完跳槽,个人付不起——
  谁付钱(个人/企业/国家),近五年政策设计的母题;经济侧住
  [人力资源开发与管理](../../../讲透管理学/讲透人力资源开发与管理/README.md)
- **非正式学习的认证边界**:占大头的工作学习,认证体系只认
  课堂——RPL 在"经验值多少钱"上反复拉锯
- **微证书的信号价值**:发证方互认=信号贬值,堆叠规则由谁定

## ✨ 这支最美的一个事实

**"70-20-10"是本家族最著名的数字,也是本家族最著名的未证实
数字**。七成学习发生在岗位、两成来自同侪、一成来自课程——
这个分布直觉可信、方向有据,但具体比例无严格实证,学界与
业界的引用纪律是"当假设,当定律"。它教会的是方法论:
**一个好假设的价值不在于对,而在于把"培训=上课"这个更坏的
默认假设打掉**——课程只占一成,组织却把学习预算几乎全押在
它上面。用假设打破迷信,再用证据修假设。
