# 04 · 成人教育学转代码:把终身学习搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:成人教育学的可机读层(03 章谱系左端)几乎可以
> 无损转码,转化体验与学习动机不可转码;四条代码走廊——**技能过时
> 模拟、差距诊断、学分账本、参与预警**——把"技能折旧多快、该学
> 什么、学分怎么算、谁被漏掉"分别变成可跑、可断言、可做敏感性
> 扫描的实验;其中第一条是本家族的独门:**在政策上线之前,把
> "预防性学习 vs 失业再培训"的价值差复现出来**。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",[教学论](../讲透教学论/README.md)
转代码要解决"操作化",[教育技术学](../讲透教育技术学/README.md)
转代码要解决"归因化",成人教育学转代码要解决"**账户化**":
把一段终身学习宣称("人人皆学")先翻成账户层的可查对象
(技能向量→差距→培训→认证→参与记录),再翻成代码。翻译的损耗
全部发生在第一步——本章先划清哪些对象第一步就走得通(绿色区),
哪些走不通(红色区),再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 成人教育学概念 | 代码化身 | 备注 |
|------------|---------|------|
| 技能折旧与需求漂移 | 技能向量随技术冲击参数 λ 演化的模拟 | 走廊 1:家族实验的属地 |
| 技能差距诊断 | 供给向量与需求向量的加权差分+学习队列 | 走廊 2:培训预算的算法原型 |
| 学分银行 | 双记账账本+转换规则引擎+防重复认证 | 走廊 3:账本可全自动,汇率是治理不是代码 |
| 参与逆选择 | 参与率×教育程度交叉表的逆梯度检测 | 走廊 4:马太效应的在线监测 |
| 微证书 | 发证-验证分离的凭证对象(签名/撤销/堆叠) | 03 章能力单元的加密化 |
| 培训效果计量 | 对照组差分(等待名单/断点)的管道化 | 02 章证据阶梯的工程实现 |

**转不动/转不动的边界(红色区)**:

1. **转化学习**:构念未构造化(03 章右端)——工程对策:退到
   叙事与量表(质性评估),不进仿真逻辑;宣称"转化学习平台"
   的产品在过度承诺。
2. **学习动机**:动机设计(游戏化/徽章)能操纵参与指标,不能
   造出内在动机——坎贝尔定律的培训版:徽章一旦成为目标,
   学习就退化为徽章。
3. **共同体氛围**:学习圈的"一壶咖啡"效应不可编码——工程上
   只能供基础设施(组队/日程/文本),氛围的生成是社会学事件。
4. **"谁该被再培训"**:资源分配的价值题——实证住[教育社会学](../讲透教育社会学/README.md)
   与公共审议,代码越位就是技术官僚化。

**边界的一句话**:绿色区=03 章谱系左端四构造物+它们的动态版;
红色区=谱系右端+价值分配——**先问构造学,再谈转码**。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:技能过时与再培训走廊——本家族实验

```
技能向量 s ──技术冲击(需求漂移 λ)──▶ 需求 D 演化 + 折旧 δ(λ)·s
      │                                        │
      ├──在岗持续学习: s ← s + h·η_job·(D−s)     ├──跌破门槛→失业→全日制再培训
      ▼                                        ▼
  双路径收入对比 ──▶ 断言:①折旧随 λ 单调升 ②预防>补救 ③低基础者更依赖培训强度
```

- **理论→模型**:技能向量化(03 章引擎 1)的动态版——需求漂移
  参数化技术变化速度,折旧率与之联动;学习者是含基础技能的
  供给向量,雇佣=供给在需求上的投影过门槛。
- **算法层**:凸组合更新(convex blend)保证向量有界,毫秒级;
  同随机数配对(CRN)让双路径逐学习者可比;λ 扫描给出
  折旧-技术速度的机制曲线。
- **本家族实现**:[`experiments/reskilling_churn.py`](experiments/reskilling_churn.py)
  ——断言三律(折旧单调/预防性学习的价值/低基础群体强度敏感)
  +Monte Carlo 敏感性。
- **性能工程要点**:纯标准库;1000 学习者×40 期×8 技能毫秒级;
  参数扫描天然可并行,seed 可复现。

### 走廊 2:差距诊断走廊(培训预算的算法原型)

```
岗位需求文本 ──挖掘──▶ 需求向量 D(技能本体上的权重)
学习者画像 ──自评/测评──▶ 供给向量 s
      │                        │
      └──── gap = w·(D−s)⁺ ────┴─▶ 学习队列(先学哪格)──▶ 培训完成后再差分(验收)
```

- **理论→模型**:03 章构造物 1 的运算化——诊断、定价、排序、
  验收四步全在一个差分上;需求向量从招聘文本挖掘是需求侧证据
  (对抗"认证即本体论"的存量课程偏置)。
- **算法层**:向量差分 O(K);难点在**本体对齐**(两份画像用的
  技能分类不一致——本体鸿沟是最大工程成本)与自评偏差的校准
  (他评/测评锚定)。
- **真实系统**:企业学习平台的技能矩阵、招聘匹配引擎、政策报告
  的技能缺口测算。
- **性能工程要点**:K 通常 <200,计算忽略不计;瓶颈是本体维护
  (技能树的版本管理)——本体变一次,全部历史向量要做迁移。

### 走廊 3:学分账本走廊(双记账与转换规则)

```
学习事件(课程/证书/经验)──入账──▶ 事件账(时间戳/证据/学分)
                                    │ 转换规则引擎(汇率表)
                                    ▼
                              资格账(证书/学位) ──提现──▶ 资格框架坐标系
   约束:防重复认证(一证据一入账)·汇率版本化(可追溯)·撤销传播
```

- **理论→模型**:03 章引擎 2的实现——账本与汇率分离:账本是
  数据结构(可全自动),汇率是治理契约(人审机执);版本化让
  "当年折算的学分"可追溯,防止规则追溯改动造成的历史崩塌。
- **算法层**:事件溯源(event sourcing)模式,天然支持审计与
  撤销传播;微证书的堆叠=图上的路径判定。
- **真实系统**:学分银行系统、微证书钱包(open badge 型:发证
  与验证分离)、企业内部学习账户。
- **性能工程要点**:账本规模小(人一生千级事件),性能无关紧要;
  **正确性是全部**——防重复认证与撤销传播的测试覆盖,比任何
  功能都值钱。

### 走廊 4:参与预警走廊(马太效应的在线监测)

```
项目参与记录 × 人口教育变量 ──▶ 交叉表(参与率×学历/年龄/职业)
      │
      ├──逆梯度检测:参与率随学历**上升**?(00 §七发现 1 的报警形态)
      ├──闸门归因:流失发生在哪道闸门(时间/心理/信息)——留存曲线×群体
      └──对照:目标人群覆盖率 vs 总参与量(总量繁荣+构成倾斜=放大器悖论)
```

- **理论→模型**:参与的逆选择(00 铁律)的监测化——终身学习
  体系的"健康指标"不是总量而是**构成的倾斜度**;闸门归因把
  流失分析(课程侧工具)借来做公平侧审计。
- **算法层**:交叉表与留存曲线,标准 BI;关键是口径纪律
  (02 章:自报"参与"≠"学习",须固定口径)。
- **真实系统**:学习型城市的监测仪表盘、AEL 型项目的招募审计、
  培训政策的公平影响评估。
- **性能工程要点**:输出必须是**构成分解+闸门清单**,不能只给
  总参与数——总数好看而目标人群占比下滑,正是放大器悖论的
  报表层版本。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:企业学习平台——技能本体先于课程目录

- 建任何学习产品(LMS/技能平台),**技能本体(03 章引擎 1)比
  课程目录先设计**:课挂技能,人挂技能,差距驱动推荐——没有
  本体的平台只能做内容仓库,做不了诊断。
- 快速诊断:产品宣称"千人千面"时,要它出示差距计算式
  (需求向量哪来、权重谁定)——拿不出计算式的个性化是打乱序。

### 落点 2:微证书系统——发证与验证分离

- 学分银行与微证书的工程红线:发证方与验证方分离(签名可独立
  验证),否则"银行"退化为机构的自记账;凭证要可撤销、可堆叠、
  可迁移(03 章能力单元三属性)。
- 红线:自动折算规则(经验→学分)必须有汇率版本与人工审核
  通道——汇率是治理契约,代码只是执行者(00 §七发现 3)。

### 落点 3:任何"培训成效"报表——先问口径与对照

- 看到任何培训成效数字,先过 02 章自评膨胀三问:对照在哪、
  口径是什么、谁没来;满意度报表与工资/留存变化常反向分离。
- 快速诊断:报表若只有参与总量,退回要求构成分解(按学历/
  年龄/岗位)——目标人群占比下滑的"增长",是体系在逆向选人
  (走廊 4 的报警形态)。
