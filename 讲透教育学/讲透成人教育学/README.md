# 讲透成人教育学 · 终身层:学校之后的学习

> **本质一句话**:成人教育学=**离开学校之后的学习之学**——把教育
> 的计量单位从"学校"换成"人生":从成人识字到在职培训,从技能
> 重塑到退休后的学习圈,凡不再被学制强制、只剩自愿的学习,都归它管。
> 它的宪法问题只有一个:**当学习失去强制、只剩自愿,学习如何仍然
> 可能**——**参与的逆选择(最需要的人最少来)是它的证据铁律**。
>
> GB/T 13745-2009:880 教育学 · 二级学科 **88057 成人教育学**。
> GB/T 未列三级明细 → 本家族**自定主干支**(3 支,各支标注「自定主干支」)。
> 宇宙:[../README.md](../README.md) · 建族日 2026-09-07 · 设计:[../../docs/superpowers/specs/2026-09-07-七学科GB13745扩展-design.md](../../docs/superpowers/specs/2026-09-07-七学科GB13745扩展-design.md)
>
> **兄弟分工声明**:[高等教育学](../讲透高等教育学/README.md)(88054)
> 管**学位体系**(大学理念/大众化/学术职业),本家族管**成人学习本体**
> (andragogy 之辨/继续教育/终身学习体系)——开放大学与继续教育学历班
> 这类交叠地带,制度侧归它,学习者与教学法侧归本家族,互指不重复。

## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透成人教育学/                 GB/T 88057(无三级明细,自定主干支)
├── 讲透成人学习理论/        自定支——个体层:成人为什么这样学(andragogy 之辨/自我导向学习/转化学习:林德曼-诺尔斯-梅齐洛线)
├── 讲透继续教育与职业培训/  自定支——组织层:在职学习怎么供给(70-20-10/行动学习/技能重塑:德鲁克-雷文斯-马希克线)
└── 讲透终身学习体系/        自定支——制度层:社会怎么组织终身学习(学习型城市/社区教育/学分银行:赫钦斯-法尔-德洛尔线)
```

> 三支的共同血统:**同一个"学校之后"问题的三层展开**——个体层
> (成人怎么学)、组织层(雇主与培训怎么供给)、制度层(国家与城市
> 怎么搭体系);三层各欠同一笔债:自愿参与筛掉了最需要的人。
