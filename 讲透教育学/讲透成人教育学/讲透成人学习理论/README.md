# 讲透成人学习理论 · 个体层:成人怎么学——andragogy、自我导向与转化

> **定位句**:这支负责"**个体层**"——成人学习者的画像与机制:
> andragogy 五假设(诺尔斯)、自我导向学习(SSDL 阶梯)、经验
> 学习与转化学习(梅齐洛)。它守着本家族的第一铁律:
> **成人学习与儿童学习之别是事实还是立场,决定你怎么教一切成人**
> ——把"应该自我导向"当"已经自我导向",是对弱者的二次抛弃;
> 而深度学习是**框架的转化**,不是信息的累加(经验既是资源也是抵押品)。
> GB/T 13745 88057 成人教育学 · **自定主干支**(GB/T 未列三级明细,
> 本家族自设以承个体层)。
> 家族:[讲透成人教育学](../README.md)

## 诞生

- **谁/何时**:林德曼 1926《成人教育的意义》(情境非科目、经验即
  资源——方法论宣言);卡普 1833 造词 andragogy,沉睡百年;
  诺尔斯 1968《Andragogy, Not Pedagogy!》/1970 成书(五假设:
  自我概念/经验/准备/取向/动机),1980 修订自让(与 pedagogy 是
  连续谱两端);塔夫 1971 成人学习项目研究(自我计划学习);
  格罗 1991 SSDL 阶梯(教法随自主性升级);梅齐洛 1978/1991
  转化学习(迷失性困境→批判反思→新框架)。
- **因什么问题**:①成人教学长期借用儿童教学法(科目中心/依赖
  教师),与成人生活脱节——林德曼与诺尔斯立画像;②"放手"全有
  全无,弱者失结构——格罗造阶梯;③有些成年学习无法用"获得信息"
  解释(离婚/重返校园/移民后的世界观重造)——梅齐洛立转化纲领。

## 核心问题

**已解决**:
- 学习者画像的表述共识:五假设是成人课程设计的标准检查单
- 自我导向是连续量不是站队:SSDL 四级(指导→激励→协作→授权)
- 经验学习圈的通说地位(具体经验→反思观察→抽象概括→主动检验)

**未解决/深水区**:
- **andragogy 之辨**(家族宪法问题,00 §四):五假设是经验概括
  还是规范主张——构念效度之争五十年未决
- **转化学习的可测性**:高值难测目标的本家族版——量表与叙事
  有,构造学无(家族 03 章谱系右端)
- **参与的动机机制**:为何明知有用仍不来(三道闸门的心理侧)

## ✨ 这支最美的一个事实

**诺尔斯五假设是一张五行检查单,不是五条定律**。自我概念/经验/
准备/取向/动机——它以五行的成本把"成人"从年龄类别变成教学类别,
又在四十年论战中输掉了"定律"身份、赢下了"检查单"身份:每设计
一门成人课程,沿五行问一遍"我按哪行假设在走",错配当场现形。
**一门学科的身份证可以同时是论战的靶子与工艺的尺子**——立场
未定不碍工具好用,这是实践学科的成熟形态。
