# 讲透终身学习体系 · 制度层:学习型城市、社区教育与学分银行

> **定位句**:这支负责"**制度层**"——社会的终身学习基础设施:
> 学习型城市(赫钦斯-教科文线)、社区教育(北欧学习圈/东亚社区
> 网络)、学分银行与资格框架(ECTS/韩国学分银行/微证书互认)。
> 它守着本家族的第三铁律:**学分银行的本质是让"学过的"变成
> "算数的"**——而难点不在记账在治理(互认的成本不是技术是
> 租金:发证机构靠稀缺性吃饭);以及**体系越完善,越向已受教育者
> 倾斜**(参与的逆选择:三道闸门都逆向筛选,最需要的人最少来)。
> GB/T 13745 88057 成人教育学 · **自定主干支**(GB/T 未列三级明细,
> 本家族自设以承制度层)。
> 家族:[讲透成人教育学](../README.md)

## 诞生

- **谁/何时**:赫钦斯 1968《学习型社会》;法尔报告 1972《学会生存》
  (终身教育+教育生命周期,政策语言换轴);OECD 1973 回归教育;
  德洛尔报告 1996 四大支柱;汉堡宣言 1997(成人学习=权利);
  ECTS 1989 试点→1999 博洛尼亚推广(学分累积+转移);韩国学分银行
  1998;教科文全球学习型城市网络(GNLC)2013 起网(首届大会北京);
  2015 联合国 2030 议程 SDG4 纳入全民终身学习;U3A 1973 图卢兹
  起源、英国 1981 互助变体(老年学习的制度长成)。
- **因什么问题**:①"教育=学校"的前端加载模型在长寿与技术变化
  时代破产——终身教育换轴;②碎片学习(工作/社区/晚年)跨机构
  跨年代无法累计——学分银行与资格框架造账本;③城市才是学习
  发生的真实尺度(图书馆/社区/职场/药店)——学习型城市把治理
  语言从"办学校"换成"配学习"。

## 核心问题

**已解决**:
- 政策框架的通说词汇:终身学习/学习型社会/四大支柱(法尔-德洛尔线)
- 学分累积与转移的制度技术(ECTS 运行三十余年;韩国学分银行)
- 学习型城市的操作化:监测仪表盘/国际联盟(方向锚,检索校准 2026-09-07)

**未解决/深水区**:
- **参与的逆选择**(家族证据铁律):体系完善≠公平触达——
  构成倾斜下的总量繁荣是放大器悖论的标准报表
- **互认的治理壁垒**:汇率是利益契约不是技术参数(00 §七发现 3)
- **非正式学习入账边界**:RPL 之外,工作与生活里学的"大头"
  永远在账本外折旧——账本选择性失明

## ✨ 这支最美的一个事实

**一个词的替换搬走一笔账单**。1972 年法尔报告用 lifelong
**education**——义务在制度,国家供给学习;1990 年代起国际组织
统一改口 lifelong **learning**——重心滑向个体,学习者为自己
负责。一词之差,福利义务悄悄改写成自我经营(02 章彩蛋)。
读任何终身学习政策,先查它用的是哪个词、哪一年的词——
**词的年代,就是账单的年代**:术语不是修辞,是成本分摊的
先行文书。
