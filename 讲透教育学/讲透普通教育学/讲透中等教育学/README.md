# 讲透中等教育学 · 中学段:分科与分化

> **定位句**:这支负责"**中学段**"——中学是 20 世纪的发明:
> 1893 年它还是精英的升学预备(十人委员会那张课表),二战后
> 大众化把它变成全民机构,从此被**三种委托拉扯**——升学预备/
> 全人教养/职前训练。**分科**(学科分化与选修制)是它的课程
> 形态,**分化**(分流/分轨/校内分层)是它的制度宿命,
> **综合中学 vs 分轨制**是它的百年选择题(科南特 1959 纲领)。
> GB/T 13745 88051 普通教育学 · **GB/T 注文明示支**(注文:
> "包括初等教育学、中等教育学等")。
> 家族:[讲透普通教育学](../README.md)

## 诞生

- **谁/何时**:1893 十人委员会(中学课程表与大学入学挂钩;
  卡内基单位随后把课程按在座时间计量);20 世纪初 6-3-3 制与
  初中独立(青少年期的发现把中学切成两段);1957 斯普特尼克
  →新数学(中学是课程改革主战场);科南特 1959《今日美国中学》
  (综合中学纲领:不按出身分轨、校内分科+辅导);各国大众化
  (中学毛入学率从精英到普及,20 世纪后半)。
- **因什么问题**:①全体青少年都被送进中学后,"给谁办学的中学"
  没了默认答案——三种委托争夺同一张课表;②青少年期的认知与
  身心巨变,要求课程既分化(学科深度)又统整(身份认同);
  ③毕业与选拔考试高利害,中学是反拨效应(washback)的最大现场。

## 核心问题

**已解决**:
- 综合中学与分轨制的制度谱系(推迟分轨/校内分层/普职融通的
  选项清单归[比较教育学](../../讲透比较教育学/README.md))
- 选修制的机理:选修=课程内部的分化阀门(学分制是其计量)
- 中学的年龄切割:初中/高中两段与青少年期发展的粗对应
  (心理学本体住 190 宇宙,未建,文字提及)

**未解决/深水区**:
- **分流时点**:普职分流的年龄选择——早分轨效率 vs 晚分轨公平
  (01 章主线 C;社会后果实证住[教育社会学](../../讲透教育社会学/README.md))
- **高厉害考试的驯化**:选拔功能与对齐功能共存一张蓝图——
  蓝图既要选拔区分度又要代表标准,两者可以冲突
- **分化与公平的边界**:校内分层(走班/快慢班)的正当条件
- **中学后衔接**:与高等/职业教育的接口(两家族波5待建,文字提及)

## ✨ 这支最美的一个事实

**中学是 20 世纪的发明**。义务教育造出小学,中学大众化造出
"青少年"这个人生阶段——1893 年十人委员会排课表时,中学毕业生
占同龄人口不足一成,课表只需回答"大学要什么";百年后全体
青少年都在校园里,同一张课表要同时回答"大学要什么/社会要什么/
这孩子要什么"。**不是青少年需要中学,是中学校舍里住满了
才被发明的"青少年"**——制度与人生阶段互相塑造的教科书案例。
