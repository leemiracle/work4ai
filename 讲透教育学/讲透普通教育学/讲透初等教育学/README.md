# 讲透初等教育学 · 小学段:读写算与全人

> **定位句**:这支负责"**小学段**"——初等教育的双重新托:
> 工具性奠基(读写算 3R:一切后续学习的操作系系统)+全人养成
> (身体/情感/审美/社会性的奠基窗口)。它的招牌张力:
> **小学课程越"整合"越贴合儿童,越"分科"越便于衔接**——
> 包班制、综合主题课与分科课的百年配置之争;
> 而母语读写是它的第一战场(阅读战争→Science of Reading 立法潮,
> 01 章主线 A)。
> GB/T 13745 88051 普通教育学 · **GB/T 注文明示支**(注文:
> "包括初等教育学、中等教育学等")。
> 家族:[讲透普通教育学](../README.md)

## 诞生

- **谁/何时**:裴斯泰洛齐(直观教学与要素教育:从声音/形状/
  数的最简要素起);福禄贝尔(幼儿园到小学的儿童观);杜威 1896
  实验学校与 1902《儿童与课程》(课程的心理化);20 世纪各国
  普及初等义务教育(小学成为第一个"人人经历"的制度);21 世纪
  早期读写研究(阅读战争 1990s→SOR 立法潮 2020s)。
- **因什么问题**:①读写算是最高的杠杆:不会读的孩子在三年级后
  "用阅读学习"全线受阻(通说的"三年级 slump");②全人目标
  (体育/艺术/劳动/社会性)在文件里从不在边缘,在课表里
  永远在边缘(窄化的初等版);③儿童中心与系统奠基如何两全
  ——进步主义的实验场在小学。

## 核心问题

**已解决**:
- 3R 的工具地位共识:读写算=后续学习的操作系统(不是"科目之一")
- 包班制与分科制的配置谱系:低段包班/高段渐分科的折中通例
- 早期读写的证据之争格局:自然拼读/平衡读写两条路线的实证分布
  (证据本体住[教学论](../../讲透教学论/README.md),本支取制度侧)

**未解决/深水区**:
- **读写立法的系统后果**:教学法写进法律后,实施缺口与教师
  能力如何(01 章主线 A 的传播链审计)
- **全人的时间政治**:评价环不考的(体育/艺术/劳动),课表
  靠什么守住——窄化的初等形态
- **幼小衔接**:游戏化学习到系统学习的坡度设计(梯度表的第一
  个边界差分,04 章走廊 4)
- **早期分层的正当性**:能力分组在小学的年龄下限

## ✨ 这支最美的一个事实

**三年级 slump(用阅读学习的临界点)**。低年级的孩子在
"学习阅读"(learn to read)——把文字变成声音与意思的工艺;
三年级前后切换为"用阅读学习"(read to learn)——阅读成为
一切科目的输入通道。临界点前后的读写差距,此后逐年被放大:
**初等教育学的全部杠杆,都压在这个切换点上**。为什么美:
一个时点概念就把"为什么小学低段的读写政策如此重要"与
"为什么高段的差距如此顽固"统一成一个故事。
