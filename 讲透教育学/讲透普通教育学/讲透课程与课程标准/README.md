# 讲透课程与课程标准 · 课程文件的层级——从教学计划到课程标准

> **定位句**:这支负责"**文件之环**"——课程不是心里想的,
> 是文件写的:教学计划/教学大纲→课程方案/课程标准的三代文件,
> 目标-内容要求-学业质量的层级结构,教材审定与空无课程。
> 它守着本家族的第一铁律:**改课程=改文件链**——课堂上多讲点
> 不在链上,不构成课程变革;而**没写进文件的内容,也在教
> "它不重要"**(艾斯纳的空无课程)。
> GB/T 13745 88051 普通教育学 · **自定主干支**(GB/T 注文未列,
> 本家族自设以承三层环的课程侧)。
> 家族:[讲透普通教育学](../README.md)

## 诞生

- **谁/何时**:博比特 1918《课程》(活动分析:课程编制科学化);
  泰勒 1949《课程与教学的基本原理》(四问成环);布卢姆 1956
  (目标有了坐标轴);1989 NCTM 课标→标准运动(文件形态换代:
  大纲→标准);2010 共同核心(跨州"学什么"统一定义);
  中国 2001 课程方案+课标(三级课程管理),2022 版以素养统领。
- **因什么问题**:①课程长期只是科目与时数的清单(教学计划),
  "为什么教这些"无从追问——泰勒把目标推上第一问;
  ②"教没教好"无公共标尺——标准运动用"内容+学业"双层规定
  把它变成可对齐问题;③谁控制文件——国家课程/地方课程/
  校本课程的分级,与教材审定制度。

## 核心问题

**已解决**:
- 课程文件的形态共识:培养目标→学段目标→内容要求→学业质量
  四层沉降链(03 章 schema)
- 逆向设计/建构性对齐的通说地位(从目标反推评价再反推教学)
- 教材是标准的第一执行者:教材研究=课程政策的显微镜(01 章主线 B)

**未解决/深水区**:
- **素养的沉降**:顶层概念落到学业质量的可行性与信效度
  (高值难测目标是蓝图的天然盲区——家族实验)
- **动词的可判性**:"理解/体会"类无判动词让对齐计算漏电
- **校本课程的定位**:分级课程管理中,校本是真课程还是装饰
- **空无课程的审计**:谁为"没写的内容"负责

## ✨ 这支最美的一个事实

**泰勒四问是一个闭环**。目标→经验→组织→评价,第四问
("这些目标正在得以实现吗")就是第一问的回检——课程学
的全部现代史,只是把这个环翻来覆去地拧紧:逆向设计把④搬到
①前,标准运动把①公示,蓝图把④机器化。**一个学科的四条公理
里藏着一条回路**,这就是"体系"二字的最低要求。

## 假设与依赖

- 站在家族假设 2 上(课程可预设)——本支是它的原产地:
  文件先行买到质量下限,欠下"预设滞后于学习者"的债
- 依赖家族的目标 ID 空间与蓝图构造(03 章);教材映射是本支的
  半构造对象

  只换学科内容;教学法本身的证据之争住[教学论](../../讲透教学论/README.md)
