# 04 · 普通教育学转代码:把三环机器搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:普通教育学的可机读层(03 章谱系左端)几乎可以
> 无损转码,素养的价值判断与课堂实施质量不可转码;四条代码走廊——
> **对齐度、课程图、蓝图审计、学段衔接**——把"教考评一致不一致、
> 课程图有没有断环、窄化有没有发生、衔接有没有跳变"分别变成
> 可跑、可断言、可做敏感性扫描的实验;其中第一条是本家族的独门:
> **在政策上线之前,把"为考而教"复现出来**。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",[教学论](../讲透教学论/README.md)
转代码要解决"操作化",[教育技术学](../讲透教育技术学/README.md)
转代码要解决"归因化",普通教育学转代码要解决"**链路化**":
把一段课程宣称("素养导向的课程改革")先翻成文件链上的可查对象
(标准条目→教材映射→课时分配→蓝图权重),再翻成代码。
翻译的损耗全部发生在第一步——所以本章先划清哪些对象第一步
就走得通(绿色区),哪些走不通(红色区),再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 普通教育学概念 | 代码化身 | 备注 |
|------------|---------|------|
| 建构性对齐 | 目标-教学-考试三层覆盖矩阵(对齐度计算) | 走廊 1:家族实验的属地 |
| 课程标准 | 四层 schema 的解析与校验(动词可判性检查) | 03 章构造物 1 的直接实现;目标 ID 空间=外键库 |
| 课程结构 | 知识点 DAG(先修边)+环检测+梯度单调性检查 | 走廊 2:课程图的图论化 |
| 考试蓝图 | 双向细目表的生成/求解/覆盖审计 | 走廊 3:权重矩阵的抽样问题 |
| 课程窄化 | 教学时间分配 vs 标准权重的偏离度监测 | 走廊 3 的报警器(坎贝尔定律的在线检测) |
| 学段衔接 | 梯度表差分与断点检测 | 走廊 4:衔接问题的差分运算 |

**转不动/转不动的边界(红色区)**:

1. **素养的整全性**:构念未构造化(03 章右端)——工程对策:
   退到测评学(表现性任务+评分量规),不进调度逻辑。
2. **课程的价值取舍**("什么值得教"):课程政治问题,证据只能
   列清单——判权送回[教育学原理](../讲透教育学原理/README.md)
   与公共审议;代码越位就是技术官僚化。
3. **教师实施质量**(标准的课堂再解读):观察问题——[教学论](../讲透教学论/README.md)
   课堂观察编码是它的测量侧;仿真是安慰剂世界。
4. **分流的公平后果**:因果与规范双重深水——实证住[教育社会学](../讲透教育社会学/README.md),
   本家族供结构参数(分流时点/序列),不代答价值题。

**边界的一句话**:绿色区=03 章谱系左端四构造物+它们的动态版;
红色区=谱系右端+价值因果——**先问构造学,再谈转码**。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:对齐度走廊(教考评一致的机器化)——本家族实验

```
课程标准(W_STD) + 考试蓝图(W_EXAM) + 应试系数 α
      │                                    │
      ▼                                    ▼
w_teach = α·w_exam + (1-α)·w_std ──▶ 凹生产 ──▶ 真实产出/考试分数双计
                             ──▶ 断言:①对齐最优 ②为考而教(分数繁荣/未考崩塌) ③结构>投入
```

- **理论→模型**:建构性对齐的教学版——教师分配跟蓝图走(反拨效应),
  学习按凹生产增长(边际收益递减);把 01 章的政策现象
  ("窄化""为考而教")翻成三状态变量(标准权重/蓝图权重/教学分配)。
- **算法层**:线性混合+指数生产,O(N·M);同随机数配对(CRN)
  让四系统逐学习者可比;α 扫描给出"个体理性 vs 系统最优"的
  机制边界。
- **本家族实现**:[`experiments/curriculum_alignment.py`](experiments/curriculum_alignment.py)
  ——断言三律(对齐最优/为考而教/结构>投入)+Monte Carlo 敏感性
  (200 次抖动,三律通过率 100%)。基准数字:错位蓝图的考试分数
  0.93 vs 真实产出 0.61(分离 0.32);修结构的产出增益是加课时的
  4.8 倍。
- **性能工程要点**:纯标准库;2000 学习者×8 目标毫秒级;
  参数扫描天然可并行,seed 可复现。

### 走廊 2:课程图走廊(课程结构的图论化)

```
课程标准条目 ──解析──▶ 知识点 DAG(节点=内容,边=先修)
      │                        │
      └──年级锚点              ├─环检测(先修死锁)
                               ├─梯度单调性(深度不倒退)
                               └─孤点检测(无先修也无后继=课程孤岛)
```

- **理论→模型**:03 章构造物 1 的图论版——课程=带年级坐标的 DAG;
  螺旋式课程在此可判定:同一主题的年级序列深度档必须单调不降。
- **算法层**:拓扑排序/环检测 O(V+E);梯度检查=按主题分组后
  的序列单调性判断;重点扫描两个文件参数:**动词可判率**
  (无判动词占比——对齐计算的漏电点)与**锚点密度**
  (多少内容要求没写年级)。
- **真实系统**:教育内容平台的知识图谱、教材电子化的结构化
  校验、课标修订的差异比对。
- **性能工程要点**:解析是文本工程(分词/动词表),瓶颈在
  人工校验;DAG 层毫秒级;断言"动词可判率"进文件 CI——
  低于阈值的课标修订不予合入(文件层的 lint)。

### 走廊 3:蓝图审计走廊(窄化的在线检测)

```
标准权重 W_STD + 蓝图权重 W_EXAM + 实际课时分配 W_TIME
      │                                │
      ▼                                ▼
覆盖差分 = W_EXAM − W_STD        偏离度 = W_TIME − W_EXAM
      └─────────▶ 窄化报警(两问:蓝图漏了谁?时间漏了谁?)◀────────┘
```

- **理论→模型**:03 章铁律(蓝图即本体论)的在线化——窄化
  有两个发生位:蓝图层(标准有、蓝图无)与教学层(蓝图有、
  时间无);两层各算一张差分表,负值格就是被删除的课程。
- **算法层**:全是向量差分,毫秒级;难点不在计算在**数据**:
  课时分配的真实测量(课表≠实际课时)是实施研究的活。
  与走廊 1 合读:偏离度≈α 的观测版——α 可以从数据反估
  (回归 W_TIME on W_EXAM)。
- **真实系统**:学区课程审计、问责指标的健康检查、
  教材-考试的覆盖报告。
- **性能工程要点**:输出必须是**两张差分表+被删目标清单**,
  不能只输出一个总分——总分好看而个别目标饿死,正是坎贝尔
  定律的报告层版本。

### 走廊 4:学段衔接走廊(梯度表的差分运算)

```
学段映射表(内容×年级矩阵)
      │
      ├──按主题取列 ──▶ 深度档序列 ──▶ 单调性检查(螺旋完整?)
      └──学段边界差分 ──▶ 衔接断点(边界格深度跳变>1 档)
                             ──▶ 断点清单:幼小/小初/初高各处
```

- **理论→模型**:03 章引擎 2 的运算化——衔接问题=矩阵的边界差分;
  螺旋问题=列的单调性。两个老议题(衔接断点/螺旋断裂)第一次
  有了可判定形式。
- **算法层**:矩阵差分 O(M·G);输出断点清单与断档主题;
  敏感性扫描档距定义(多少算"跳一档")。
- **真实系统**:课标修订的衔接自查、跨学段教材的梯度审查、
  转学/跳级的课程差距评估(给学生的"差距=哪些格")。
- **性能工程要点**:梯度表的小数据量决定这不是性能问题,
  是**档距校准**问题——深度档的判定规则必须成文,
  否则差分结果不可复现(03 章"画像防腐第一律"的同族)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:内容平台的标准库——目标 ID 先于功能

- 建任何教育内容产品(题库/课程/学习 App),**目标 ID 空间
  (03 章引擎 1)比功能先设计**:没有目标 id 的内容永远对不了齐;
  每条内容挂 id,题挂 id,进度记账到 id——这是"对齐能力"的
  全部基础设施。
- 快速诊断:产品宣称"覆盖课标"时,要它出示覆盖矩阵
  (目标×内容的 0/1 表)——拿不出矩阵的覆盖是文案。

### 落点 2:题库与蓝图的分离——蓝图是产品层最值钱的一张表

- 题库再大,决定产品气质的是**蓝图**(从题库怎么抽):同一题库,
  蓝图不同,教出来的结构不同(家族实验断言 B 的产品版);
  蓝图生成器与覆盖审计(走廊 3)应该是独立模块,不是命题的附属。
- 红线:高值难测目标(迁移/协作)在自动组卷里天然权重衰减
  (好出的题多)——自动组卷必须带**权重下限约束**,
  否则算法会替你悄悄决定课程。

### 落点 3:任何"学习成效"报表——先问计量口径

- 看到任何教育成效数字,先问它按什么权重聚合(按标准还是按
  考试蓝图)——口径不同,同一批学生可以同时"进步"与"退步"
  (家族实验的 0.93 与 0.61)。
- 快速诊断:报表若只有一个总分,把它退回要求附分布——
  总分改善+个别目标崩塌,是窄化时代的标准报表形态。
