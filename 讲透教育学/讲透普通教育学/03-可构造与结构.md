# 03 · 可构造与结构:哪些课程的东西能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:普通教育学的对象沿一条**可构造谱系**排开——
> 课程标准的层级结构/学段映射 schema/评价蓝图端**严格可构造**
> (可入库、可对齐、可审计),素养的整全体验与学校文化端
> **不可构造**(只有测评学与叙事学,没有构造学);全谱系共享
> 两条结构引擎:**目标 ID 化**(三环共享同一目标地址空间)与
> **学段梯度**(内容带年级坐标的渐进序列)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把普通教育学的所有对象按"能不能直接造出来"排一条线:

```
课程标准层级 ── 学段映射表 ── 评价蓝图 ── 知识点先修图 ── 教材映射 ── 素养的整全 ── 学校文化
(schema 四层)  (内容×年级)  (双向细目表)  (节点+先修边)  (页↔目标)    (高值难测目标)  (隐性课程)
严格可构造(可编码/可对齐/可审计) ────────────────────▶ 不可构造(只有测评学与叙事学)
  └── 表/图/矩阵,可机读可复用                                      └── 只能观察/问卷/作品间接测
```

为什么会有这条谱系?**可构造的前提是"有限描述+公共语义+可判定
成员资格"**(判据与[教学论](../讲透教学论/README.md) 03 章同源):
一条内容要求"属于不属于三年级"可以机器判定;而"具备协作素养"
没有成员资格判定——量表能测它,构造学造不出它。
本章先盘家底(三个严格可构造对象),再看两条引擎,最后数刚性。

## 一、可构造性家底盘点(三大构造物详解)

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| 课程标准层级 | schema 四层:**培养目标→学段目标→内容要求→学业质量**(每条内容要求带:学段/年级锚点、行为动词、认知层级) | 低(一天建表,写标准十年) | 行为动词的语义衰减:"理解/了解/体会"无判则,对齐计算在此漏电([教学论](../讲透教学论/README.md)目标语义问题的文件版) |
| 学段映射 schema | 内容点×年级坐标的矩阵(**scope & sequence 表**):每格=该内容该年级的深度档;学段衔接=相邻学段边界格的差分 | 中(格子好画,深度档难标) | 年级是行政坐标不是认知坐标(00 假设 1):映射表天然掩盖同年级内的巨大个体差 |
| 评价蓝图 | **双向细目表**:内容维度×认知维度(布卢姆轴)的权重矩阵,每格配抽样题数与分值;一条蓝图=一张卷子的基因 | 低-中(矩阵一小时,等值校准一年) | 蓝图决定什么被教:高值难测目标(迁移/协作)在蓝图里天然权重偏低——**蓝图是课程的隐形编辑器**(家族实验断言 B) |

**亲手构造一次(三个最小样例)**:
- 标准层级:把你领域的一份大纲(课标/培训大纲/教程目录)抄进
  四层表——顶层概念抄在第一层,把每条内容标上(学段/动词/层级);
  标不进表的内容,就是文件里的修辞性余量。
- 学段映射:给同一主题(如"分数"或"循环")列 3 个学段的深度档
  (具体操作/关系理解/形式定义)——填不出第三档,说明螺旋断了
  (00 美之时刻 3 的手工检查)。
- 蓝图:给你最近出的一份卷子(或考过的任何考试)画双向细目表,
  内容×认知层级,格子里写分值——画完即见价值分布:
  哪一层在养家,哪一层在缺席。

## 二、结构引擎 1:目标 ID 化——对齐的不变量

**直觉图像**:三环(课程-教学-评价)之所以能对齐,前提是
它们在谈**同一个目标**。目标 ID 化给每条内容要求一个唯一地址
(编号/URI),标准引用它、教材页对准它、试题挂上它、课时记账
到它——三环从"各说各话"变成**共享地址空间的三张表**。

- **可构造化身**:目标表(id/学段/内容/动词/层级)+教材映射表
  (页码→目标 id 集合)+试题标签(题号→目标 id)。
  三个可判定问题随之成立:这条内容教了吗(教材映射非空)?
  考了吗(蓝图权重>0)?教考一致吗(覆盖差分)?
  家族实验的全部计算都住在这一层上(04 章走廊 1)。
- **刚性从哪来**:地址空间一旦成为行业默认,它就从**记账工具**
  变成**课程定义**——没有 id 的目标自动出局(空无课程的数字版,
  艾斯纳构念的可机读化)。**对齐的代价**:你 ID 化了什么,
  就保护了什么;ID 化不下的(好奇心/审美体验)在系统里失语。
  国际上,能力框架的可互操作(competency framework 的机器
  可读标准)走的正是这条路——[教育技术学](../讲透教育技术学/README.md)
  SCORM 集装箱的近亲。

## 三、结构引擎 2:学段梯度——内容如何"往上走"

**直觉图像**:学段不是抽屉,是**斜坡**——同一内容在不同年级
有不同深度档,学段结构=全体内容的梯度总表。螺旋式课程
(布鲁纳)是它的教学法表达;scope & sequence 是它的表格化身。

- **可构造化身**:梯度表=每条内容的一列(年级→深度档)序列;
  可判定问题:梯度单调吗(有没有倒退)?衔接断点在哪
  (相邻学段边界格的深度跳变)?——幼小/小初/初高衔接的
  "断点检测"就是这张表上的差分运算(04 章走廊 4)。
- **刚性从哪来(本引擎的暗面)**:梯度一旦画进文件,年级进度
  就成了问责对象——"三年级该会 X"的表格化,把发展节奏的
  统计分布误读成每个儿童的及格线(00 假设 1 的构造学后果)。
  **梯度表的正确用法是描述典型轨迹,不是判决个体**;
  把它用作判决,制造的是年级-水平的系统性误配。

## 四、反直觉发现(本章铁律)

**蓝图即本体论**。双向细目表看似只是命题工具,实际是课程的
第二立法者:目标 ID 化让一切可对齐,而**蓝图决定对齐的方向**——
蓝图超采的目标,教学时间涌入(反拨效应);蓝图缺席的目标,
哪怕在标准里权重最高,也会在教学层饿死(家族实验:标准权重
0.40 的高值目标,蓝图记 0 后掌握度崩到对齐系统的 24%)。
这与[教育技术学](../讲透教育技术学/README.md) 03 章"verb 表是
先验承诺"是同一条铁律的制度版:**你画进蓝图的,才是课程;
画不进去的,正在被安静地删除**。对抗它的唯一方式:
蓝图的覆盖审计必须**对照标准权重**而非对照题库便利
(04 章走廊 3 的窄化报警)。

## 五、谱系左端的三个对象,结构上长什么样(小结)

| 构造物 | 数学形状 | 一句话 |
|--------|---------|--------|
| 课程标准层级 | 四层树+叶节点(内容要求)带(学段/动词/层级)标签 | 课程文件的数据库投影 |
| 学段映射 | 内容×年级的矩阵,格值=深度档(偏序) | 课程的时间坐标化 |
| 评价蓝图 | 内容×认知层级的权重矩阵(行和列各归一) | 一张卷子的基因型 |
| 目标 ID 空间 | 三张表共享的键空间(标准/教材/试题的外键) | 对齐的不变量 |

四个构造物合成普通教育学的"可机读层"——04 章的代码走廊
全部建在这一层上;谱系右端(素养整全/学校文化/隐性课程)
划出走廊的边界:那里只有测评学,谁宣称把右端"做成了产品",
谁就在过度承诺。

## ✨ 美之时刻(彩蛋第 5 枚:双向细目表)

✨ **美之时刻 5:双向细目表——一张矩阵审一张卷、一册书、一门课**
(极简)。内容×认知层级,两个维度各画一条轴,格子里填权重——
小学试卷分析的老工具,却是本家族构造学的皇冠:它把"这份卷子
考得全不全、深不深"从争吵变成**填表**,把"教考评对齐"从愿望
变成**矩阵运算**(家族实验的目标层与考试层就是它的两张投影)。
为什么美:**教育的价值取向平时藏在修辞里,在细目表里只能藏
在数字里**——数字藏不住。亲历:§一的"画一份卷子的细目表"
练习,画完那一刻你会重新认识这份卷子。

## ✍️ 练习

1. ✋ 把你领域的一份课程标准/大纲抄进四层 schema,统计行为动词
   分布:可判动词(写出/求解/设计)与无判动词(理解/体会/感受)
   的比例——这个比例就是该文件的可对齐上限
2. ✋ 给"你的学科的一条主线"(如编程里的循环)画三学段梯度表,
   找出衔接断点:哪一格到下一格深度跳变超过一档?
3. ✋ 画你最近一份考试的双向细目表,再画"标准应有权重"的
   对照矩阵——两张矩阵的差就是你的个人版"蓝图错位"
   (对照家族实验的 W_EXAM_MIS 与 W_STD)
4. ✋ 反驳练习:为"把每条目标 ID 化并全网共享"写三条最强论据,
   再用 §二(地址空间即课程定义)与空无课程构念逐条划出
   它对与错的部分

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:构造分层之眼**——看到任何课程系统,
先问它住在谱系哪一段:标准层级/学段映射/蓝图(可构造,可审计),
先修图/教材映射(半构造,需校准),素养整全/学校文化
(不可构造,只有测评)。住在左端的可以互操作、可以被问责;
住在右端谁宣称"已落地",谁就在过度承诺。
