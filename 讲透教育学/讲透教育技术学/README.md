# 讲透教育技术学 · 媒介层:技术怎么改学习——从教具到平台到 AI 的五代史与证据史

> **本质一句话**:教育技术学=教育的媒介学——每一次媒介革命
> (幻灯→广播电视→计算机辅助→在线平台→生成式 AI)都承诺"改变学习",
> 这门学科的宪法任务只有一条:**把承诺与证据分开**——
> 克拉克-考兹玛之争(媒体影响学习吗)是它的元问题,
> **"即时表现≠长期保持"是它的证据铁律**。
