# 讲透学习技术与媒体 · 克拉克-考兹玛之争与多媒体学习的认知理论

> **定位句**:这支负责"**媒体之问**"——技术本身能不能改变学习?
> 它守着家族的宪法之争(克拉克 1983"媒体只是运送教学的卡车" vs
> 考兹玛 1994"媒体与方法协同设计")与当代答卷:多媒体学习认知理论
> ——**效应归设计,不归盒子**;买设备不等于买学习。
> GB/T 13745 88041 教育技术学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透教育技术学](../README.md)

## 诞生

- **谁/何时**:普莱西 1920s(第一台教学机器);戴尔 1946(经验之塔:
  媒体=直接经验的替代物);斯金纳 1954(程序教学:小步子/主动作答/
  即时反馈/自定步调);克拉克 1983 与考兹玛 1991/1994(媒体之争);
  梅耶 2001(多媒体学习认知理论:双通道/容量有限/主动加工)。
- **因什么问题**:①每代新媒体都承诺"这次不一样",百年对照研究
  却多是"无显著差异"(拉塞尔汇编)——媒体到底有没有用?
  ②同一个屏幕,为什么有的课件帮学、有的毁学?

## 核心问题

**已解决**:
- 媒体主效应≈0 的判词(克拉克;实证底座=拉塞尔"无显著差异"汇编)
- 多媒体设计原则族(梅耶:多媒体/邻近/通道/一致性等,元分析中
  效应量居前,通说)——之争的正确问法:这个媒体怎么设计
- 经验之塔的历史地位(框架被认知取向取代,直觉仍流传)

**未解决/深水区**:
- **媒体×方法交互**:何时媒体不可替换(符号系统与认知过程的交互)
- **生成式 AI 的新回合**:AI 是呈现内容的盒子,还是替换认知活动的
  对话者——认知卸载让老之争以新形态复活(00 章 §四)
- **动画/交互的边界**:动画未必优于静态图(依任务而变,通说)

## ✨ 这支最美的一个事实

**卡车与冰淇淋**。克拉克一句话("媒体是不会改变冰淇淋味道的送货车")
让一个世纪的设备采购辩论失效;考兹玛的反击同样漂亮——该问的是
**这种卡车允许你造什么样的冰淇淋工厂**。四十年争论的净产出是一个
被改写的问题:"这个媒体**怎么设计**才有效"——问题的改写比答案更值钱。
