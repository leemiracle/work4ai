# 讲透在线与混合学习 · 平台之问:远程、混合与 MOOC 的承诺与退潮

> **定位句**:这支负责"**平台之问**"——技术能不能把好教学规模化?
> 它管第三至第四代史(CAI→LMS→MOOC)与它们留下的设计学问:
> **交互的类型**(内容/教师/同伴)、**完成率的结构**(谁坚持、为什么)、
> **混合的艺术**(面授时间怎么重新设计而不是被搬运)。MOOC 之年的
> 承诺与退潮是它的判例集:开放降低门槛,完成的成本(自律×时间×先备)
> 没有降低——规模化的红利常流向已占优者。

## 诞生

- **谁/何时**:PLATO 1960 起(远程交互教学的第一次系统实现);
  e-learning 与 LMS 1990s 末;SCORM 2000(内容集装箱化);联通主义与
  cMOOC 2008(西门思-唐斯);**MOOC 之年 2012**(Coursera/Udacity/edX
  同年创立);翻转课堂 2007 前后(伯格曼-萨姆斯,通说);2020 紧急
  远程教学(ERT,与"在线学习"的概念区分)。
- **因什么问题**:①优质教学稀缺而网络边际成本趋零——能否复制放大?
  ②学习者隔着屏幕,是什么在决定完成与放弃?

## 核心问题

**已解决**:
- 完课率的结构性画像:中位数常低于 10%,完成者多为已受教育者
  (哈佛/MIT 系追踪,通说)——"民主化承诺"的实证修正
- 交互三分(Moore:学习者-内容/教师/同伴)——在线课程质量的分析骨架
- 混合学习的要义:面授时间的**重新设计**(替换/增强/翻转),
  不是线上内容搬运;ERT≠在线学习设计(2020 的概念清算)

**未解决/深水区**:
- **完成的机制**:自定步调是解放还是放弃加速器?(时间管理与先备的交互)
- **同伴交互的规模**:论坛质量随规模衰减(阅读者远多于发帖者,通说)
- **混合的最优配比**:什么进面授、什么进线上——无通用处方

## ✨ 这支最美的一个事实

**为所有人开门,进门的是已经毕业的人**。MOOC 把"世界一流教育免费
开放"做到极致,追踪研究却发现完成者大多数已有大学以上学历,完课率
中位数低于 10%——开放是加法(资源+1),完成是乘法(资源×自律×
时间×先备)。这是家族"规模化假设的代价"(马太效应)最干净的
实证判例,也是[教育社会学](../../讲透教育社会学/README.md)数字鸿沟
框架的教育技术侧入口。
