# 04 · 教育技术学转代码:把媒介层搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:教育技术的可机读层(03 章谱系左端)几乎可以无损转码,
> 浸入体验与教育公平的因果不可转码;四条代码走廊——
> **自适应调度、学习分析、双通道模拟、延迟检验**——把
> "排程、预警、辅助效应、效应衰减"分别变成可跑、可断言、
> 可做敏感性扫描的实验;其中后两条是本家族的独门:
> **在上线之前,把"提分却蒸发保持"复现出来**。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",[教学论](../讲透教学论/README.md)
转代码要解决"操作化",教育技术学转代码要解决"**归因化**":
把一段技术宣称("AI 让学习更高效")先翻成可对照的模型
(即时表现通道 vs 独立保持通道),再翻成代码。翻译的损耗全部
发生在第一步——所以本章先划清哪些对象第一步就走得通(绿色区),
哪些走不通(红色区),再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 教育技术概念 | 代码化身 | 备注 |
|------------|---------|------|
| 知识追踪 | BKT 四参数 HMM / 简化 DKT | 算法本体住[教学论](../讲透教学论/README.md) 04 章走廊 2——本家族只引用,不重造 |
| 自适应调度 | 掌握阈值+遗忘预期的选题/排程规则 | 走廊 1:调度的输入是追踪,输出是下一个对象 |
| 学习分析 | xAPI 事件流→画像字段→预警规则 | 走廊 2:纯统计管道,纪律在参与代理 |
| 技术辅助效应 | 双通道模拟(即时表现/独立保持分离) | 走廊 3:家族实验的属地 |
| 效应衰减 | 新颖/实施的衰减参数化+延迟双终点设计仿真 | 走廊 4:上线前评测设计的机器化 |
| 内容互操作 | SCORM 打包/xAPI 语句的生成与校验 | 03 章构造物 1/2 的直接实现(纯 schema 工程) |

**转不动/转不动的边界(红色区)**:

1. **浸入与临场感**:构念未构造化(03 章右端)——工程对策:退到
   测量学(问卷/生理指标),不进调度逻辑。
2. **技术采用的因果**(学校为什么买、教师为什么不用):组织社会学
   问题——证据要准实验(02 章阶梯),仿真是安慰剂世界。
3. **公平的后果**(红利流向谁):分配正义不能被目标函数吞掉——
   工程对策:把公平作为**约束**写进调度(探索预算/强制内容多样性)。
4. **"好学习"的整体构念**:审计查得出空挂,查不出"值不值得学"
   ——目的层问题送回[教育学原理](../讲透教育学原理/README.md)。

**边界的一句话**:绿色区=03 章谱系左端四构造物+它们的动态版;
红色区=谱系右端+社会因果——**先问构造学,再谈转码**。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:自适应调度走廊(排程的机械化)

```
知识追踪(p(掌握)) + 遗忘预期(R=exp(−Δ/s)) ──▶ 优先级 = 风险×收益
      │                                            (快忘的×该练的先来)
      └──阈值判定 ──▶ 下一对象选择(难度/先修/变式) ──▶ 自适应引擎
```

- **理论→模型**:调度的目标函数=在有限时间内最大化总保持:
  快遗忘的高价值对象优先;先修约束(03 章知识图谱的边)决定可行性。
  这是[信息科学](../../讲透信息科学与系统科学/README.md)里
  带约束排程的教育版。
- **算法层**:每步 O(N) 评分(N=候选对象),堆可到 O(log N);
  重点扫描两个政策参数:**掌握阈值**(多确信算会)与**探索比例**
  (多大预算推画像外内容——用户感受"越用越窄"的防腐剂,
  03 章闭环暗面的工程解)。
- **真实系统**:自适应题库、SRS 复习队列([教学论](../讲透教学论/README.md)
  实验的调度原型)、掌握解锁式培训。
- **性能工程要点**:追踪更新是标量运算,瓶颈在**题库-知识点-目标表
  的对齐数据**;画像大表按学习者分片;断言"探索比例>0"进 CI。

### 走廊 2:学习分析走廊(预警的半机械化)

```
xAPI 事件流(actor-verb-object) ──聚合──▶ 参与指标 ──建模──▶ 画像字段
      │                                        │
      └──verb 表校验(03 章铁律)                └──阈值/预测 ──▶ 预警与干预
```

- **理论→模型**:03 章闭环的左半段;参与指标=行为层(登录/进度/
  论坛),认知层参与(是否深加工)不可直接观测——**指标全部
  是代理**(02 章参与代理),预警规则=代理上的阈值。
- **算法层**:流式聚合(滑动窗口计数)很轻;预测模型(掉队风险)
  的地基住[统计学宇宙](../../讲透统计学/README.md)——分类器不新,
  新的是**干预的公平审计**:预警组与对照组的内容轨迹是否系统性分叉
  (03 章自我实现回路的在线检测)。
- **真实系统**:早期预警系统、教师仪表盘、课程完成率看板。
- **性能工程要点**:事件流按周预聚合,明细冷存;verb 变更要版本化;
  **纪律**:上线前先在人工标注子集上报指标效度——跳过这步的
  仪表盘是把噪声画成了图。

### 走廊 3:双通道模拟走廊(辅助效应的机器化)——本家族实验

```
技术辅助宣称 ──操作化──▶ 双通道:即时表现(有辅助)+独立保持(无辅助)
      │                        │
      └──认知卸载参数化 ──▶ 三组对照(无辅助/纯辅助/混合)
                             ──▶ 断言:①提分 ②保持崩塌 ③混合兼得
```

- **理论→模型**:01 章主线 B 的证据(检索校准 2026-09-07:
  AI 提升即时测验、削弱延迟保持)翻成两状态变量——
  工具熟练度(两轮都能长)与独立记忆强度(只有检索能长,卸载绕过);
  延迟测验用艾宾浩斯衰减(与教学论实验同族曲线)。
- **算法层**:回合制仿真+同随机数配对(方差缩减:混合组对无辅助组
  逐回合随机占优,断言有结构保证而非抽样运气);
  卸载乘子扫描给出"部分卸载"的连续边界。
- **本家族实现**:[`experiments/tech_aid_decay.py`](experiments/tech_aid_decay.py)
  ——断言三律(辅助增益/卸载代价/混合解药)+Monte Carlo 敏感性
  (200 次抖动,工具增益共用同一因子:同一机制不许各自漂移)。
- **性能工程要点**:纯标准库;2000 学习者×16 回合毫秒级;
  参数扫描天然可并行,seed=base+learner_id 保可复现。

### 走廊 4:延迟检验走廊(效应衰减的机器化)——上线前评测设计

```
"新技术有效" ──拆解──▶ 2×2:测验时点(即时/延迟)×条件(有辅助/无辅助)
      │                        │
      └──新颖效应窗口(蜜月期长度)└──最小可检测效应(样本量/时长预算)
                             ──▶ 评测设计生成器(时点/样本/对照的网格)
```

- **理论→模型**:02 章衰减三重奏的机器化——给定新颖效应窗口、
  延迟保持的指数衰减假设与预算,反解"该在何时测多少人"
  才能把 d=0.2 的延迟效应从噪声里捞出来。
- **算法层**:功效计算(正态近似)+衰减参数网格;
  输出不是 p 值,是一张**设计表**(每个延迟点的样本量)。
- **真实系统**:A/B 平台的实验设计模块、教育 RCT 的预注册工具。
- **性能工程要点**:幂函数级联,O(参数网格)——它改的不是代码,
  是评测流程:**任何学习功能的上线必带延迟终点**,
  这是走廊 3 结论的制度化形态。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:评测任何"学习功能"——两张成绩单缺一不可

- 你给产品加的每个学习类功能(AI 提示/智能推荐/自动讲解),
  上线评测必须同时测:**使用时的表现**与**撤掉后的独立保持**——
  只测第一张的功能,是在给未来的流失率埋雷(家族实验就是这个
  评测的最小骨架,抄走即可)。
- 快速诊断:任何"辅助"功能,查它的**介入位置**——在检索之前
  给答案(卸载通道)、之后给反馈(加固通道)。位置比模型大小重要。

### 落点 2:平台数据治理——verb 表先于功能

- 建学习平台时,**事件 schema(03 章)比功能先设计**:verb 表漏了的
  行为永远测不回来;每个画像字段写判定规则,写不出判定规则的删掉。
- 快速诊断:预警/推荐系统必须有**探索预算**——画像闭环(03 章
  引擎 2)不加阀,系统会把自己的偏差当成学习者的命运越推越深。

### 落点 3:AI 教育产品的设计位——prompt 即辅助位置

- 给 AI 导师/学习助手写 prompt 时,你正在设计认知卸载的宽度:
  先问后答(苏格拉底式)还是先答后问(代做式),对应家族实验的
  混合组与纯辅助组——**这是产品层影响最大的一行代码**;
  教学法内核住[教学论](../讲透教学论/README.md) 04 章落点 3,
  本家族补媒介层的双通道纪律。
- 红线:宣称"AI 提效"必须落到延迟独立后测的对照上(走廊 4);
  "对话流畅"与"学到了"之间隔着认知卸载(01 章)。
