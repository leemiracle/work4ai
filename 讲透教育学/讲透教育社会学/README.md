# 讲透教育社会学 · 传送带与打破器——教育如何复制又如何动摇阶层

> **本质一句话**:教育社会学=把教育放回社会结构的学科——它研究同一枚硬币的两面:
> 教育如何**复制**不平等(出身→文化资本→学历→地位的传送带),
> 又如何**打破**不平等(扩张、补偿与选拔规则改写流动通道);
> 一句话:**学校既是社会的电梯,也是社会的复印件**——双面神学科。
>

## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透教育社会学/             GB/T 88024(无三级明细,自定主干支)
├── 讲透教育与社会分层/   自定支——结构层:流动传统(布劳-邓肯)与再生产传统(布迪厄)的对垒
├── 讲透学校组织社会学/   自定支——组织层:学校作为科层组织/班级社会体系/有效学校研究
└── 讲透教育与社会公平政策/ 自定支——政策层:补偿政策的证据史(科尔曼报告→补偿教育→EMI 之争)
```

> 三支的共同血统:**同一个"教育×分层"之问的三层分工**——
> 结构层问传送带在哪(谁经过谁被拦),组织层问传送带的机器怎么造(学校这台机器
> 的科层结构与校际差异),政策层问怎么改机器(什么干预真正改变转移概率)。
