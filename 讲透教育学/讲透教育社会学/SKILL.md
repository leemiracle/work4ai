# 教育社会学思维技能卡(讲透教育社会学 · GB/T 88024)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **复制类**:教育如何再生产阶层、文化资本、惯习、符号暴力、社会再生产、对应原理、反学校文化、《继承人》《学做工》
- **流动类**:教育扩张、社会流动、代际流动、转移矩阵、代际弹性、地位实现、OED 三角、绝对流动 vs 相对流动
- **公平类**:教育机会均等、科尔曼报告、起跑线、补偿教育、教育公平政策、分流/追踪、投入均等 vs 结果均等
- **组织类**:学校作为科层组织、松散耦合、有效学校研究、学校效应、增值评价、班级社会体系
- **争议类**:MMI/EMI(最大化/有效维持不平等)、扩张是否拉平机会、文凭主义、信号 vs 人力资本、比率 vs 差异

## ② 核心思维模式(这个分支怎么想问题)

1. **双面神检验**:任何教育制度/政策先问两面——传送带(复制不平等)转多快,
   打破器(制造流动)转多快?只报一面的叙述都在偷懒
2. **三段式补全**:任何教育叙事钉到"出身-获得-回报"三段上——
   缺哪段,错就在哪段(只讲回报的教育成功学缺前两段)
3. **边际/转移分离**:看到"入学率又升了"先问——转移概率变了吗?
   没变只是扩张(动 α),不是拉平(动 β);EMI 的日常用法
4. **关口思维**:学历是幸存链——每道升学关口问一次出身效应
   (主效应还是次级效应?哪道关最陡?)
5. **分母警惕**:读到"XX 解释了教育差异的 N%"先问——分母是什么?
   学校方差被压缩后家庭占比上升(残余不平等再集中),总差异与
   占比是两个量
6. **识别优先**:教育变量与结果的相关里永远煮着选择偏差与遗漏家庭
   背景——先问识别策略,再看效应量

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| OED 路径分析(布劳-邓肯) | 拆解出身→教育→职业的传递链,估计教育的中枢地位 |
| 流动表+对数比值比(log OR) | 度量机会结构;相对流动率的守恒检验 |
| 三明治分解(边际×转移) | 判断"结构变化"动的是总量还是机会(扩张 vs 拉平) |
| 序贯 logit(Mare 转换模型) | 各升学关口出身效应;主/次级效应分解 |
| MMI/EMI 检验设计 | 政策时间线+队列数据;"扩张期不平等是否保持" |
| 方差分解(校间/校内/个体) | 学校效应多大;均衡化政策的再集中推演 |
| 断点设计(录取线两侧) | 名校效应/分流效应的准实验识别 |
| 增值评价 | 剔除生源后的学校净效应(注意边界内生) |
| 民族志(威利斯传统) | 再生产的主动性/意义系统——回归到不了的地方 |

## ④ 常见误区与禁忌

- **把扩张当拉平**:入学率上升=边际右移;机会结构(log OR)可以纹丝不动——
  两词混用是公共讨论第一大错
- **MMI/EMI 当同义词**:MMI 守"能不能上"(量),EMI 说量拉平后优势
  转守"上哪一种"(质)——机制不同,政策含义不同
- **attainment/achievement 混同**:获得(学历)≠成绩;流动表与成绩表
  是两张不同的表
- **比率/差异之争装看不见**:log OR 不变时绝对差距可以扩大——
  两类指标答案相反时必须双报
- **给惯习上回归**:意义系统硬造参数=把自己假设回去;文化资本可测量
  不等于可构造、更不等于可注入
- **把校间当个体**:嵌套结构不处理,显著性是假的(04 章落点 4)
- **仿真替代识别**:模拟造"安慰剂世界",不能替代断点/随机化——
  因果识别是设计问题不是算力问题
