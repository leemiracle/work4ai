# 04 · 教育社会学转代码:把分层机器搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:教育社会学的流动表端(03 章谱系左端)几乎可以无损转码,
> 惯习端几乎不可转码;三条代码走廊——**流动表分析**、**序贯转换(EMI
> 结构表达)**、**学校效应分解**——把"出身-获得-回报"里的前两段变成
> 可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",教育社会学转代码要解决"**形式化**":
把一段分层语言(扩张没有拉平机会)先翻成模型(转移矩阵/序贯 logit/
方差分解),再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清
哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条走通了
的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 教育社会学概念 | 代码化身 | 备注 |
|------------|---------|------|
| 教育流动表 | 转移矩阵采样+行列归一化 | 父代×子代等级;家族实验幕一全程纯标准库 |
| 代际弹性 | OLS 斜率(子代年限~父代年限) | 继承模式弹性→1,机会模式→0,可断言 |
| 序贯转换模型(Mare) | 每关口一个 σ(α_t+β·出身) | 两条参数轴:α=总量可及性,β=出身优势 |
| MMI/EMI 结构表达 | 边际(α)与相对流动率(log OR)的分离检验 | 实验幕二:拨 α 不动 log OR,拨 β 才动 |
| 学校效应分解 | 方差分解(校间/校内/个体)+ R² 占比 | 实验幕三:压缩校间方差→家庭占比上升 |
| 教育扩张时间线 | 出生队列×政策参数的伪队列模拟 | 政策支的实验台(走廊 4) |
| 机会结构监控 | 流动表→log OR 仪表盘 | 工程师落点 2 |

**转不动/转不动的边界(红色区)**:

1. **惯习与意义系统**:没有状态方程——硬造"惯习参数"只会得到自己
   假设回去的结论。工程对策:退到民族志与代理测量,不当仿真变量用。
2. **因果识别**:选择偏差/遗漏家庭背景是**识别问题不是模拟问题**
   (02 章 §二)——仿真可以造"安慰剂世界"辅助直觉,不能替代
   断点/随机化设计。
3. **等级编码的语义**:ISCED/CASMIN 的映射是编码表不是算法——
   转码前必须人工定级,且跨制度比较要声明编码漂移。
4. **政策的价值权衡**:代码能算"哪种参数组合改变转移概率",算不了
   "该不该改"——规范问题留在公共讨论,不进实验台。

**边界的一句话**:绿色区=流动表端+分解端,恰好覆盖三段式的前两段
(出身→获得);第三段(回报)的因果识别是计量问题,正主在
[劳动经济学](../../讲透经济学/讲透劳动经济学/README.md)与数理统计侧。

## 二、代码走廊清单(三条主走廊+一条轻走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:流动表走廊(转移矩阵全机械化)

```
流动表理论 ──参数化──▶ 父代×子代转移矩阵 ──行归一──▶ 转移概率
      │
      └──统计量──▶ 对角占优/代际弹性/对数比值比 ──▶ 流动结构诊断
```

- **理论→模型**:父代教育三等级(初中及以下/高中/大学及以上),
  子代等级由行转移概率决定;继承模式=强对角矩阵,机会模式=行相同。
- **算法层**:蒙特卡洛采样(每代一行一个子代)→经验转移矩阵→
  对角占优检验+OLS 代际弹性(子代年限~父代年限)。
- **本家族实现**:[`experiments/mobility_matrix.py`](experiments/mobility_matrix.py) 幕一
  ——断言继承模式对角占优且弹性>0.9(→1),机会模式弹性≈0。
- **真实系统**:代际流动监测(官方统计的跨代链接表)、学区研究的
  出身-学业转移表。
- **性能工程要点**:采样天然可并行(按行分流 seed=base+行号保证可复现);
  统计量(弹性/log OR)与采样解耦成纯函数,便于缓存与差分。

### 走廊 2:序贯转换走廊(EMI 的结构表达——本家族招牌)

```
Mare 序贯 logit ──参数化──▶ 每关 P(过关|出身)=σ(α_t+β·出身)
      │
      ├──拨 α(扩张)──▶ 边际右移,log OR 不动 ──▶ MMI/EMI 结构演示
      └──拨 β(拉平)──▶ log OR 收敛 ──▶ "机会拉平"的唯一旋钮
```

- **理论→模型**:两道关口(超越高中/入大学),各自 logit;α 是
  总量可及性(扩张拉它),β 是出身优势(拉平动它)。**log OR(高出身
  vs 低出身)=2β,与 α 无关**——EMI 假说的代数核心。
- **算法层**:三情景蒙特卡洛(基准/扩张/拉平)→各关口经验 logit→
  断言:扩张情景列边际大幅右移而 log OR 不动;拉平情景 log OR 显著缩小。
- **本家族实现**:同实验幕二。
- **真实系统**:招生政策预演(扩名额=α,改选拔规则=β)、
  补偿项目的机制定位(它动的是哪个参数?)。
- **性能工程要点**:这是最便宜的政策实验台——两个标量参数、
  一条 sigmoid;关键是**把政策语言钉到参数**(扩招≠公平,除非动 β)。

### 走廊 3:学校效应分解走廊(方差分解端)

```
多层/方差分解理论 ──参数化──▶ 成绩=家庭项+学校项+个体噪声
      │
      └──方差压缩实验──▶ 校间方差↓ → 家庭 R²↑ ──▶ 残余不平等的再集中
```

- **理论→模型**:子代成绩 = γ_x·家庭背景 + γ_q·学校质量(均值随出身
  分隔+方差 σ_q)+噪声;等级由阈值切。
- **算法层**:两情景(σ_q 大/小)→总方差、家庭背景对等级的 R²;
  断言:σ_q 压缩→总差异下降**且**家庭占比上升(科尔曼推论的数值版)。
- **本家族实现**:同实验幕三。
- **真实系统**:学校均衡化政策的事前沙盘("抹平校际差异后,
  残余差异由什么解释?")、增值评价的方差基线。
- **性能工程要点**:在线累加(和/平方和)代替存样本,内存 O(1);
  R² 的抽样误差 ~1/√n,断言边际要预留在 5σ 以上。

### 走廊 4(轻):扩张时间线走廊(队列伪面板)

```
教育史时间线 ──队列暴露──▶ 出生队列×政策参数(α_t 随 t)──▶ 伪面板模拟
```

- 只需把走廊 2 的 α 从常数改成随出生队列的阶梯函数(对应 01 章主线 D
  的政策时间线),即可复现"扩张浪潮逐队列扫过"的列边际漂移;
  教学用一张热图+一行断言即可,不另设实验(留作 ✍️练习 3)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:教育数据管道——追踪调查的 schema 工程

- 教育类数据管道的核心不是量大而是**结构对**:个体 ID×出生队列×
  时点×(教育事件/家庭链接)。schema 设计先过 03 章 §四的三问
  (等级编码/流失/队列),流失必须建模(失访概率与出身相关,
  简单删除=给流动表加偏)。

### 落点 2:机会结构监控面板——别只看边际

- 给任何"教育公平"仪表盘配两个指标层:总量层(各等级毛入学率=边际)
  **加**机会层(关键转换的 log OR=转移)。只有第一层的面板,
  在 EMI 世界里会把"扩张"误报为"公平"——家族实验幕二是
  这个面板的最小验收用例。

### 落点 3:评估实验的工程化——断点与随机的功效

- 补偿项目评估(公平政策支证据史的当代形态)的工程件:录取线断点
  两侧的带宽选择、随机化的分层(按出身分层抽,别让随机化本身
  制造新的选择偏差)、预注册的指标(转移概率而非总量)。
- 仿真在这里的角色:造"安慰剂世界"检验功效(零效应下 p<0.05 的
  频率),不冒充识别。

### 落点 4:多层结构的数据纪律

- 学校数据天然嵌套(学生∈班级∈学校):把校间差异当个体差异回归,
  标准误系统性偏小(显著性的假阳)——工程对策:聚合检验或
  多层模型;最少要在 ETL 里保留学校 ID,让"可分层"成为可能。
