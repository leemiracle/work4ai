# 讲透教育与社会公平政策 · 从起跑线到终点线——补偿政策的证据史

> **定位句**:这支负责"政策层"——教育公平作为政策目标的**证据史**:
> 投入均等(科尔曼范式)→补偿教育(学前与补偿项目的评估)→分流与
> 选拔规则的证据→扩张与普及的证据边界(EMI 对政策时间线的含义);
> 它的纪律只有一条:**政策主张必须挂在一个可检验的识别上**。
> GB/T 13745 88024 教育社会学 · **自定主干支**(GB/T 未列三级明细,家族自定)。
> 家族:[讲透教育社会学](../README.md)

## 诞生

- **谁/何时**:科尔曼报告 1966《教育机会均等》(投入均等范式的建立与
  同时被推翻——家庭压倒学校资源);1960s 美国补偿教育计划
  (如"先行计划"Head Start 1965 等,按学术文献通说);詹克斯等
  《不平等》1972(再分配辩论的总账);布东 1974 与拉夫特里-豪特 1993/
  卢卡斯 2001(MMI/EMI:扩张政策的理论边界);2000s 以来评估革命
  (断点/随机化进入教育政策评估)。
- **因什么问题**:①投入均等为什么不等于结果均等(科尔曼之问)
  ②补偿的时机——起跑线差距在入学前已存在,何时介入(时机之问)
  ③什么干预改变的是**转移概率**而非只是边际(EMI 之问)。

## 核心问题

**已解决(通说)**:
- 投入均等范式及其局限:资源差异的解释力远小于家庭背景(1966 报告的方向性结论)
- 证据方法的演进史:投入指标→成果指标→因果识别(断点/随机化)三级跳
- 补偿项目评估的方法标准:对照组+随访,早逝的效应与衰减
  (compensatory education 文献的经典议题,通说)

**未解决/深水区**:
- 补偿时机的最优设计:学前干预的长期效应(纵向证据仍在积累)
- 扩张 vs 结构改革:动 α(总量)与动 β(转移)的政策组合学
- 评估的外推:一个时点的项目效应能否外推为制度效应

## ✨ 这支最美的一个事实

**科尔曼报告的方法论遗产**:它被派去回答"学校资源是否均等"
(窄问题),却回答了"机会不平等的主要来源在哪"(大问题)——
**问错了问题,答对了更大的问题**;政策评估由此从数投入
(生均经费/师生比)转向看机会结构(出身→获得的转移)——
这是评估史上罕见的范式转移案例。

## 假设与依赖

- 政策可映射到参数:扩张=拨 α(总量可及性),结构改革=拨 β(出身优势)
  ——家族实验幕二的参数语义在本支落地
- 评估的识别假设:断点/随机化的有效性;预注册与随访纪律
- 红线:涉各国教育政策仅按学术文献转述为**证据史**(现象与效应),
  不作规范性评价;政策的价值权衡留在公共讨论
