# 讲透教育与社会分层 · 流动与再生产两大传统的对垒

> **定位句**:这支负责"结构层"——教育在社会分层中扮演什么角色;
> 家族三支中的理论主战支,两大传统在此对垒:**流动传统**(学校是电梯,
> 布劳-邓肯系:教育是地位传递的中枢与上升通道)vs **再生产传统**
> (学校是复印件,布迪厄系:文化资本让复制穿着天赋的外衣)。
> GB/T 13745 88024 教育社会学 · **自定主干支**(GB/T 未列三级明细,家族自定)。
> 家族:[讲透教育社会学](../README.md)

## 诞生

- **谁/何时**:流动线——索罗金 1927《社会流动》(学校=阶梯的首次系统论述);
  布劳-邓肯 1967《美国职业结构》(OED 地位实现模型,路径分析立教);
  特雷曼工业化论题(教育与职业的普遍主义化侵蚀出身效应)。
  再生产线——布迪厄-帕斯隆 1964《继承人》1970《再生产》(文化资本/惯习/
  符号暴力);鲍尔斯-金蒂斯 1976(对应原理);威利斯 1977《学做工》
  (反学校文化的民族志:再生产中的主动选择)。
  调停线——布东 1974(主效应/次级效应;扩张悖论);拉夫特里-豪特 1993
  与卢卡斯 2001(MMI/EMI:把对垒形式化为可检验假说)。
- **因什么问题**:①出身多大程度决定获得(世袭之问)②学校在这条链上
  是纠偏器还是复印机(机器之问)③教育扩张会不会最终拉平机会(扩张之问)。

## 核心问题

**已解决(通说)**:
- OED 链条:教育是出身→职业传递的中枢(布劳-邓肯;路径分析成标准工具)
- 出身效应可分解为主效应(要不要继续读)与次级效应(读得怎样)(布东;Mare 形式化)
- 再生产的机制菜单:文化资本/对应原理/主动文化生产三家并列,各有证据域
- MMI/EMI:扩张期不平等保持的跨国证据成主导假说(边界条件仍在补)

**未解决/深水区**:
- 工业化论题 vs MMI:扩张最终是否拉平机会(学科身份级之争,00 章 §三)
- 文化资本的因果地位:投资→成绩,还是出身同时造两者(识别未决)
- 绝对流动与相对流动的指标之争(比率 vs 差异,两类答案可相反)

## ✨ 这支最美的一个事实

**布东分解**:同一句"出身影响教育"被拆成两个正交参数——主效应
(出身改变继续升学的决策)与次级效应(出身改变学业表现)——
"寒门难出贵子"从道德口号变成可分解、可跨国比较的参数表
(02 章彩蛋 4 的原产地;家族实验幕二的 β 是它的最小化身)。
