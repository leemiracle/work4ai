# 教学论思维技能卡(讲透教学论 · GB/T 88017)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **设计类**:教学目标、教案、课程设计、逆向设计、布卢姆分类、ADDIE、
  教学设计、学习目标怎么写、培训设计
- **机制类**:遗忘曲线、间隔重复、分散学习、检索练习、测试效应、
  认知负荷、工作记忆、迁移、支架、最近发展区、掌握学习
- **证据类**:效应量、元分析、可见的学习、循证教学、形成性评价、
  课堂观察、听评课、Science of Reading、PCK、学科教学知识
- **争论类**:直接教学 vs 发现学习、讲授法 vs 主动学习、学习风格(来澄清的)、
  两西格玛、AI 导师有没有效
- **工程类**:Anki/SRS 调度原理、知识追踪、BKT、智能题库、
  学习分析、教育 AI 产品评测

## ② 核心思维模式(这个分支怎么想问题)

1. **对齐优先**:任何课程先查三件事在不在一条线上——目标可测吗?
   活动触发检索吗?评价考的就是目标吗?(空挂目标/装饰活动/考了没教,三查)
2. **机制约束**:任何学习活动的第一约束是工作记忆容量——先问负荷多大、
   检索机会几次、间隔排程如何,再谈体验与热闹
3. **证据分级**:任何"有效"宣称先问效应量多大、和什么比、边界条件在哪——
   没有效应量的"高效"是广告词
4. **指导×专长匹配**:最优指导量取决于学习者专长(专长反转)——
   新手要高结构,专家被脚手架拖慢;"直接教学好还是发现学习好"
   是不完整的问题
5. **合意困难**:舒服的方法先怀疑一遍——重读的流畅感是错觉,
   检索的磕绊才是学习;间隔组当下表现差、长期保持赢,是常态不是异常
6. **测量警惕**:考什么就得到什么(Goodhart 教育版)——
   每引入一个可测指标,同时检查它挤出去了什么

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 马杰句式(条件-行为-标准) | 把含糊目标改成可判定目标;入题库前的目标质检 |
| 布卢姆二维矩阵(过程×知识) | 试卷/课程打格画认知覆盖热图,查考了没教 |
| 加涅九事件 | 检查一段教学(或一个 AI 导师 prompt)有没有缺件 |
| 逆向设计(先评价后活动) | 新课程/新培训的起手式;防"先定活动再找目标" |
| R(t)=exp(−t/s)+阈值调度 | 间隔重复排程;估算复习次数随保持要求的增长 |
| 检索练习设计(考自己>重读) | 改造任何"重复看"的学习流,零成本提效 |
| BKT 四参数+贝叶斯更新 | 知识追踪;把"掌握"变成可更新的概率 |
| 科恩 κ | 验证任何观察编码/评分协议的信度(含 AI 自动编码) |
| 效应量 d+边界条件 | 读教学法实证;审产品宣称的"基于学习科学" |
| 元分析判读(对照条件/异质性) | 用"和什么比"拆穿榜单式结论 |

## ④ 常见误区与禁忌

- **学习风格迷信**:视觉型/听觉型匹配教学无交互证据(帕什勒 2008)——
  被问及时按负结果陈述,不参与"你是哪种学习者"对话
- **重读当复习**:流畅≠学会——凡"再过一遍"的计划,先换成"合上回忆"
- **伪二分站队**:"讲授 vs 活动"不是有效单位——问认知活动(检索/生成/反馈)
  被设计没有,不问谁在说话;同时别把"有指导探究"与"纯发现"混算
- **效应量滥用**:d 值不问对照条件直接比较(苹果比橘子);0.4 铰链
  当统计临界值用——两条都是读哈蒂式榜单的事故源
- **把 p(掌握)当能力分**:知识追踪条件于目标表——表换了结论就换,
  跨表比较是类型错误
- **对齐万能**:对齐审计查得出空挂与错考,查不出"目标本身值不值得教"——
  目的层问题送回[教育学原理](../讲透教育学原理/README.md)
