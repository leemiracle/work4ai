# 讲透教学论 · 课堂的工艺学——课堂上到底发生什么

> **本质一句话**:教学论=课堂的工艺学——教育学原理回答"教育是什么/为了什么",
> 教学论回答**"怎么教"**:把一堂课拆成 目标-活动-评价 三元组,把"教得好"
> 从个人天赋变成**可设计、可观察、可检验**的工艺;它的现代纪律只有一条:
> **每个教学法主张都要拿出效应量**。

## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透教学论/                 GB/T 88017(无三级明细,自定主干支)
├── 讲透课程与教学设计/   自定支——教之前:目标-内容-方法-评价四件套怎么造(泰勒-布卢姆-加涅线)
├── 讲透学习科学与教学/   自定支——教之中:认知负荷/记忆/迁移的课堂机制(艾宾浩斯-斯威勒-检索练习线)
└── 讲透课堂教学评价/     自定支——教之后:课堂研究/观察量表/循证教学(弗兰德斯-布卢姆-哈蒂线)
```

> 三支的共同血统:**同一个"怎么教"之问的三段分工**——
> 设计前(把课造出来)、机制中(学习在认知层怎么发生)、证据后(怎么知道它有效)。
> 三段合成一条工艺流水线:设计供目标,机制供约束,评价供证据。
