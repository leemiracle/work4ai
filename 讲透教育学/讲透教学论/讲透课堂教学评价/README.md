# 讲透课堂教学评价 · 课堂研究、观察量表与循证教学

> **定位句**:这支负责"**教之后**"——怎么知道教学有效:
> 课堂怎么被观察(编码与量表)、反馈怎么变成课堂内的杠杆
> (形成性评价)、教学法的证据怎么被综合(效应量与元分析)。
> 它是教学论的**证据纪律部**:没有这支,设计只是意见,机制只是假说。
> GB/T 13745 88017 教学论 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透教学论](../README.md)

## 诞生

- **谁/何时**:弗兰德斯 1960s(课堂互动分析系统 FIAS:十类别、
  每 3 秒一码——课堂第一次变成可计数的数据);斯克里文 1967
  (形成性/终结性评价之分,原为课程评价术语;布卢姆移用于学生学习);
  TIMSS 1999 录像研究(跨国课堂的编码比较);布莱克-威廉 1998
  (《内部黑箱》综述:形成性评价的大效应);哈蒂 2009《可见的学习》
  (800+ 元分析汇成效应量排行榜,循证教学的旗舰)。
- **因什么问题**:①课堂是一个黑箱——用什么仪器看进去(观察)
  ②评了之后怎么用——评价怎样反哺教与学(反馈)
  ③千百个研究的结论怎样合成一句话(证据综合)。

## 核心问题

**已解决**:
- 观察编码协议+评分者一致性(κ)——课堂测量的仪器学
- 形成性评价的大效应共识(布莱克-威廉;反馈是效应量榜单前列的常客)
- 效应量语言(d 值+边界条件)——教学法证据的公共度量衡

**未解决/深水区**:
- **课堂的因果识别**:随机分班难、教师效应纠缠、实施缺口
  ——证据链天然比实验室薄(家族 02 章 X 光的整栏靶区)
- **元分析的异质性**:不同构念/测度的 d 直接排序("苹果比橘子")——
  哈蒂榜单的方法论批评持续发酵
- **PCK 的分科测量**(01 章主线 C):可测但测量昂贵,规模化受阻
- **教师增值模型的公平争议**:把学生增益归因到教师的统计努力,
  在方法与伦理两面被夹击

## ✨ 这支最美的一个事实

**可见的学习——一门学科第一次把全部效应摆上同一把尺**:
哈蒂把 800+ 元分析折算成可比的效应量,排出从"反馈"到"留级"的长队。
无论你同不同意排法(方法论批评见 02 章),这一步把教学论从
"引经据典的论断学"拽进"拿数字说话的测量学"——
一门学科给自己的全部知识做了一次体测。
