# 04 · 教学论转代码:把课堂工艺搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:教学论的可机读层(03 章谱系左端)几乎可以无损转码,
> 生成性与教学艺术不可转码;四条代码走廊——**间隔重复调度、知识追踪、
> 对齐检查、观察编码一致性**——把"记忆排程、掌握推断、课程审计、
> 仪器信度"分别变成可跑、可断言、可做敏感性扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",教学论转代码要解决"**操作化**":
把一段教学语言("分散复习优于集中")先翻成模型(遗忘曲线+调度规则),
再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清哪些对象
第一步就走得通(绿色区),哪些走不通(红色区),再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 教学论概念 | 代码化身 | 备注 |
|------------|---------|------|
| 遗忘曲线+间隔重复 | R(t)=exp(−t/s);保留率阈值触发调度 | 家族实验全程纯标准库;SM-2 算法本身就是几十行 |
| 知识追踪 | BKT(四参数 HMM)/简化 DKT;掌握概率更新 | 掌握判定=概率过阈值,可断言可回放 |
| 对齐(目标-教学-评价) | 布尔映射矩阵+三个审计断言(空挂/装饰/考了没教) | 03 章引擎 1 的直接实现 |
| 观察编码协议 | codebook+采样规则→事件串;评分者一致性(科恩 κ) | 03 章引擎 2 的直接实现 |
| 教学事件脚本 | 九事件序列的状态机/模板 | 骨架可编码;"每段的好坏"不在其中 |
| 掌握学习循环 | 形成性测验→诊断→矫正→复测的参数化仿真 | [教育学原理家族实验](../讲透教育学原理/README.md)已实现(bloom_two_sigma),本家族只读引用 |
| 课堂时间预算 | 负荷-时间的排程问题(如检索机会最大化) | 排程是工程,负荷估计是研究——分清 |

**转不动/转不动的边界(红色区)**:

1. **课堂生成性**(不按剧本的临场应对):无状态方程——工程对策:
   把"生成性"当作监控指标(偏离脚本的频度),不当控制变量。
2. **教学艺术与师生关系**:构念未操作化(02 章),转码无从谈起——
   工程对策:退到测量学(问卷/访谈),不进产品逻辑。
3. **教学法效果的社会因果**(同侪效应/家长投入/教师信念):准实验是
   统计问题不是模拟问题——仿真只能造"安慰剂世界"辅助直觉。
4. **"好老师"整体构念**:是三支的合成物,每个可测侧面各算各的,
   禁止把合成分当单一参数。

**边界的一句话**:绿色区=03 章谱系左端四构造物+它们的动态版;
红色区=谱系右端——**先问构造学,再谈转码**(与[管理理论家族](../../讲透管理学/讲透管理理论/README.md)
同一条铁律,组织转码的契约端/文化端分界是它的先例)。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:间隔重复走廊(记忆排程全机械化)

```
艾宾浩斯遗忘曲线 ──参数化──▶ R(t)=exp(−t/s),强度 s 为状态
      │
      └──保留率阈值触发 ──▶ 间隔=g(s)=s·ln(1/θ) ──▶ 复习间隔几何扩展
                                    ──▶ SRS 调度器(Anki/SM 族)
```

- **理论→模型**:记忆强度 s 是隐状态,保持率是其指数衰减;
  一次成功检索把 s 乘上增益(合意困难:低保留率处增益大但失败风险高),
  检索失败则强度回退——间隔效应与分散学习效应都是这套动力学的涌现结果。
- **算法层**:阈值触发调度(到 θ 就复习)+参数网格扫描(增益/阈值/失败回退)
  +蒙特卡洛(学习者的随机成败)。
- **本家族实现**:[`experiments/spacing_forgetting.py`](experiments/spacing_forgetting.py)
  ——断言三律:①集中练习的保持率衰减快于间隔(间隔效应);
  ②复习间隔随记忆强度自适应几何扩展(SRS 数学原理:间隔×保留率阈值触发,
  难项自动拿到更短间隔);③总学习时长固定时,分散安排的长期保持
  显著优于集中(分散学习效应)。
- **真实系统**:Anki/SM-18、多邻国式的复习队列、飞行员与医学知识的
  保持训练、你的个人知识库。
- **性能工程要点**:调度是 O(1) 每卡片每步,批量重算用堆;
  敏感性扫描天然可并行;随机数按学习者分流(seed=base+id)保可复现。

### 走廊 2:知识追踪走廊(掌握推断半机械化)

```
掌握学习(布卢姆) ──概率化──▶ BKT:四参数(初始/学习/猜对/失误)
      │                        的隐马尔可夫模型
      └──贝叶斯更新 ──▶ p(掌握|答题历史) ──▶ 阈值判定→下一个知识点
```

- **理论→模型**:03 章进度模型的概率化——"掌握"是隐状态,
  答题是带噪声的观测;每答一题做一次贝叶斯更新,
  p(掌握) 过阈值即判达标(标准参照的概率版)。
- **算法层**:四参数 BKT 用 EM 或网格拟合;工程上常先抄合理默认值
  (猜对率≈选项数的倒数),重点扫描**判定阈值**——它就是
  "多确信算掌握"的政策参数。
- **真实系统**:智能题库、自适应学习平台的排题引擎、
  培训系统的"掌握解锁"。
- **性能工程要点**:更新是标量运算,瓶颈在题库-知识点图谱的对齐数据
  (又是走廊 3);警惕把 p(掌握) 直接当"能力分"——它是
  **条件于这张目标表的掌握**,换表换结论。

### 走廊 3:对齐检查走廊(课程审计全机械化)

```
对齐(03 章引擎 1) ──数据化──▶ 目标表×活动表×试题表 三张表
      │
      └──映射审计 ──▶ 三个断言:无空挂目标/无装饰活动/不考没教的
                        ──▶ 课程覆盖热图
```

- **理论→模型**:对齐矩阵 A[i,j,k] 布尔化;三个可判定问题(§03)变三条
  查询;覆盖率按布卢姆格子聚合,就是认知覆盖热图。
- **算法层**:纯集合运算与计数,无拟合——**它是审计不是研究**,
  这正是它的价值:结果无统计噪声,分歧只来自编码(谁打的格子)。
- **真实系统**:课标-教材-考试一致性分析、企业培训课程的胜任力映射检查、
  文档/教程的"承诺-交付-考核"审计。
- **性能工程要点**:最轻的走廊——三张表+一次 join;重点在
  **编码协议**(两人独立打格算一致),不在算力。
  把"拍脑袋的课程"变成"可审计的映射",是本走廊的全部野心。

### 走廊 4:观察编码走廊(仪器信度半机械化)

```
观察编码协议(03 章引擎 2) ──规则化──▶ 事件串(有限字母表)
      │
      └──一致性检验 ──▶ 科恩 κ ──▶ 协议迭代(类别表/锚例/判定规则)
```

- **理论→模型**:两位编码员对同一课堂(视频)独立编码得两条事件串;
  κ=(观察吻合率−期望吻合率)/(1−期望吻合率)——它把"协议造得好不好"
  变成一个可断言的数(κ≥0.7 常作可用线)。
- **算法层**:混淆矩阵+κ;升级版按时间窗对齐(允许±1 码偏移)——
  否则 3 秒采样的两条串永远对不齐。
- **真实系统**:听评课量表的信度检验、AI 课堂分析工具的"人类基线"
  (自动编码器必须先打过人类 κ 这一关)、客服/医疗对话的质检编码。
- **性能工程要点**:自动编码(ASR+LLM 打码)是当前热点,但**纪律**:
  先在人工双编码子集上报 κ,再谈规模化——跳过这一步的产品
  把"编码可靠性"藏进了黑箱(01 章主线 D 的证据之争焦点)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:个人知识管理——给自己装一个调度器

- 你要长期保持的知识(领域术语/命令行/算法模板)按 SRS 排程:
  别的自己造,先读懂一条规则——**间隔=当前强度×ln(1/保留阈值)**,
  检索成功则强度倍增。理解了这条,任何背单词应用对你从黑箱变成参数。
- 快速诊断:任何"重复看"的学习流(重读笔记/刷视频)都在向
  流畅错觉交税——把它改成"合上再回忆"(检索练习),
  零成本拿到教学论里效应最稳的一条。

### 落点 2:教育/培训内容平台——目标表是一切的底座

- 题库、智能排题、掌握报告,全部悬在**目标表**上:目标写得含糊,
  下游全部失真(03 章语义传染)。工程纪律:目标先过马杰句式
  (条件-行为-标准)再入库;目标-试题映射双人打格。
- 快速诊断:一个学习平台如果没有显式的目标(知识点)表,
  它的"个性化"只是在题目难度维度上打转——知识追踪没得住。

### 落点 3:LLM 时代的教案与 AI 导师——prompt 即教学设计

- 给 AI 写教学类 prompt(导师/面试官/陪练)时,你正在写教案:
  目标(这场对话结束时学习者能做什么)、活动(提问=检索练习,
  而非直接给答案——认知负荷与合意困难对 AI 同样适用)、
  评价(何时探测掌握、何时收束)。**生成式 AI 降低了"生产内容"的成本,
  于是教学设计的稀缺点从内容移到对齐与证据**——评测 AI 导师,
  用的还是走廊 3 的三查(承诺了什么/练了什么/测了什么)。
- 工程师视角的红线:AI 导师的宣称必须落到**延迟后测上的对照**,
  "对话流畅"与"学到了"之间隔着流畅错觉(02 章)——
  这条红线就是两西格玛规模化的当代考场(00 章未解清单)。
