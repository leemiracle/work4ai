# 讲透学习科学与教学 · 认知负荷、记忆与迁移的课堂机制

> **定位句**:这支负责"**教之中**"——课堂设计受人类认知架构的硬约束:
> 工作记忆容量有限(负荷)、长时记忆按遗忘曲线衰减(记忆)、
> 学会的知识未必换情境能用(迁移)。它把"怎么教有效"从经验问题
> 变成**机制问题**:先问认知架构允许什么,再谈教学法。
> GB/T 13745 88017 教学论 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透教学论](../README.md)

## 诞生

- **谁/何时**:艾宾浩斯 1885(遗忘曲线,记忆的第一个定量定律);
  米勒 1956(短时容量 7±2,后修订为 4±1 左右);比约克 1994
  (合意困难与新记忆理论);斯威勒 1988(认知负荷理论);
  罗迪格-卡皮克 2006(检索练习效应);1991《学习科学杂志》创刊
  (认知科学家携实验室方法进入真实课堂)。
- **因什么问题**:①同一教法对不同材料效果悬殊(负荷结构不同)
  ②学过就忘——记忆的保持规律是什么(遗忘与巩固)
  ③学了不会用——迁移为什么这么少(迁移难题)。

## 核心问题

**已解决**:
- 认知负荷三分类(内在/外在/关联)——教学设计=削减外在负荷的管理术
- 间隔效应与检索练习的机制与边界(记忆研究最稳的两条)
- 反馈与形成性评价的机制位次(证据侧见[评价支](../讲透课堂教学评价/README.md))

**未解决/深水区**:
- **远迁移稀少**:训练迁移少于期望是百年级结论;如何可靠设计迁移,
  认知科学尚无处方共识
- **认知负荷的测量**:主观量表/双任务/眼动指标效度之争——理论热,测量冷
- **专长反转效应的机理**:为何同一种支持对新手是支架、对专家是拖累
- **最优间隔的定量规律**:随测验延迟变化的间隔函数(塞佩达 2006 之后仍在细化)

## ✨ 这支最美的一个事实

**检索练习——"考试"当学习**:提取不是只读的测量,而是**改变记忆的写操作**——
每一次成功检索都在加固记忆(而重读只制造流畅错觉)。
一个动词的及物性反转(考→被考加固),"以测促学"从此有了机制地基;
家族实验 [`spacing_forgetting.py`](../experiments/spacing_forgetting.py)
正是把这条机制参数化成调度器。

## 假设与依赖

- 站在家族假设 4 上(认知机制跨个体稳定——按"标准学习者"设计,
