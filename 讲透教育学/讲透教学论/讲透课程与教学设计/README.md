# 讲透课程与教学设计 · 目标-内容-方法-评价四件套怎么造

> **定位句**:这支负责"**教之前**"——把一堂课/一门课从意图造出来:
> 目标怎么写才可教可测、内容怎么选怎么组织、方法怎么匹配目标、
> 评价怎么嵌进设计。教学论三支中**工程气质最浓**的一支:
> 它把教学变成有流程、有图纸、可审计的设计活动。
> GB/T 13745 88017 教学论 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透教学论](../README.md)

## 诞生

- **谁/何时**:泰勒 1949《课程与教学的基本原理》(四个问题=课程设计的
  永恒模板);布卢姆 1956《教育目标分类学》(目标可编码);
  马杰 1962(行为目标句式:条件-行为-标准);加涅 1965/1974
  《学习的条件》《教学设计原理》(九大教学事件,设计自称科学);
  威金斯-麦克泰 1998《追求理解的教学设计》(逆向设计);
  ADDIE 流程(1970s 军事培训起源,后成企业培训工业标准)。
- **因什么问题**:①课程质量靠什么保证——从名师经验变成可复制设计
  ②"培养学生的 X"这类目标怎么落到可教可测 ③教学能不能像工程一样
  有需求-设计-实现-验收的流程。

## 核心问题

**已解决**:
- 目标分类学(布卢姆 1956/2001 二维矩阵)——目标的公共坐标系
- 行为目标句式与逆向设计流程——设计从"先想活动"改成"先想证据"
- 教学事件序列(加涅九事件)——教学流程的可核对清单

**未解决/深水区**:
- **目标模式 vs 过程模式**:泰勒"先定目标再选经验"对斯滕豪斯
  "目标是师生共同探索中生成的"——预设与生成的张力无判据可裁
- **可测性与教育性的张力**:考得出的才被设计,最要紧的常考不出
  (00 章 Goodhart 铁律在设计端的化身)
- **课程弹性 vs 对齐纪律**(01 章主线 D):弹性在哪个颗粒度上不破坏对齐
- **螺旋式课程的结构选择**:同一结构何时重访、加深多少,缺操作判据

## ✨ 这支最美的一个事实

**逆向设计——把评价从终点变成起点**:传统流程"定目标→选活动→最后出题",
威金斯-麦克泰倒过来"先想清楚凭什么算学会了(可接受的证据)→再设计教学"。
一个顺序调换,让"教了没考、考了没教"从常见病变成设计期就能拦截的
类型错误(家族 03 章对齐引擎、04 章走廊 3 的思想原产地)。
