## ② 核心思维模式(这个分支怎么想问题)

1. **先问年龄**:任何学前宣称先对分母——0-3/3-6/5-6 是
   三种制度、三种发展、三种风险;跨国数字先比分母再比大小
   (02 章对译表)
2. **发展与教学排队**:发展先于教学(阶段不可跳),但教学
   要走在发展前面(ZPD)——超出 ZPD 的承诺是营销,
   低于 ZPD 的等待是浪费
3. **游戏是引擎不是休息**:儿童在游戏中"高出一头"(维果茨基);
   看游戏先问三档形态(自由/引导/直接)的配比,
   "游戏本位"是一个可实测的比例,不是一种氛围
4. **两条通道**:智商/测验增益会衰减(学校等化),人生结果
   (毕业/健康/犯罪)会保留(非认知主导)——任何干预评估
   先问测的是哪条;只测认知代理的研究,结论上限是"暂时领先"
5. **敏感≠关键**:敏感期是利率更高的软窗口(错过可补,
   更贵),关键期是会关死的硬窗口——营销最爱把前者说成后者,
   因为只有"会关死"能制造抢购
6. **标签的长伤害半径**:给 3 岁孩子贴的发展标签会陪TA最长
   (终身档案第一页)——测量变成命运的风险在学龄前最大,
   仪器(量表/编码框)永远要留"框架外"的出口

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 分龄三问(年龄段/形态配比/测量通道) | 任何学前宣称、政策数字、产品文案的第一次分流 |
| ZPD 判定(独立水平 vs 帮助下水平) | 判断一个目标"装不装得进游戏"、支架该搭多高 |
| 三档形态观察(自由/引导/直接) | 实测"游戏本位"宣称的实施落差(01 章练习 1) |
| 双通道模型(认知衰减/非认知保留) | 读任何早期干预评估;预测其 20 年后的改判 |
| 三态里程碑判定(未到窗/过了/过窗未过) | 读发育筛查结果;做适龄产品的第一层逻辑 |
| 目标效率分解(挤出/参与缺口/补偿响应) | 分析"普遍 vs 定向"教育预算之争;跑家族实验 |
| 爱普斯坦六型参与表 | 诊断家园共育的层次(沟通密≠共育) |
| fadeout 三解释(真消失/天花板/通道转移) | 给"效应消失"类新闻写三种续写 |

## ④ 常见误区与禁忌

- **敏感期当关键期**:两者机制天壤之别(软窗 vs 硬门)——
  引用"错过来不及"前先问有没有硬窗口证据(99% 没有)
- **游戏本位当氛围**:自由/引导/直接是三种可实测的形态,
  报表合并成一个词即信息损失;放任与设计在报表上同姓
- **智商增益当干预成败**:佩里悖论——智商优势小学就消失,
  40 岁人生结果仍改善;只测认知通道的短评估会错杀好干预
- **Heckman 曲线当"三岁定终身"**:曲线说的是回报率排序,
  不是能力锁死;动态互补性≠关键期决定论(终身可塑仍在)
- **里程碑当及格线**:月龄窗是区间不是标准年龄;筛查工具
  被读成竞赛日程,是构造形态对工具目的的反噬(03 章)
- **评价现行幼教政策**:本家族纪律——政策按文献通说转述
  (ECEC/IDEA/Head Start 的结构),不做好坏评判;
  "哪国模式更好"送比较教育学
