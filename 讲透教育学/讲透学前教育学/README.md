# 讲透学前教育学 · 起点层:0-6 岁的教育——发展先于教学,游戏即课程

> **本质一句话**:学前教育学=教育的起点学——它不先问"怎么教一门课"
> (那是[教学论](../讲透教学论/README.md)的事),也不先问"教育为了什么"
> (那是[教育学原理](../讲透教育学原理/README.md)的事),它先问:
> **在正式学科学习开始之前,人是怎么被"准备好"的**。
> 它的宪法任务只有一条:**把发展与教学排队**——发展先于教学
> (皮亚杰:阶段不可跳),但教学要走在发展前面(维果茨基:最近发展区),
> 而游戏是学前儿童两者兼得的形态——**游戏即课程**。
> **"智商增益会蒸发,人生结果不会"是它的证据铁律**(佩里学前项目)。
>
> GB/T 13745-2009:880 教育学 · 二级学科 **88047 学前教育学**。
> GB/T 未列三级明细 → 本家族**自定主干支**(3 支,各支标注「自定主干支」)。

## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透学前教育学/              GB/T 88047(无三级明细,自定主干支)
├── 讲透儿童发展与游戏/    自定支——发展之问:儿童如何建构世界(皮亚杰-维果茨基线),游戏为什么是发展引擎
├── 讲透幼儿园课程与保教/  自定支——课程之问:0-6 岁"教"什么(游戏本位课程 vs 学术下移);保育与教育的合一
└── 讲透早期干预与家园共育/ 自定支——公平之问:早期差距与补偿(Head Start 传统);家庭作为第一教育环境
```

> 三支的共同血统:**同一条宪法的三个赛段**——发展(儿童是什么)、
> 课程(给儿童什么)、干预(给不平等的开端补什么)。
> 每个赛段的答法是同一条:先问**发展允许什么**(敏感期/准备度),
> 再问**游戏能不能装下它**——装不下的才轮到"教学"。
> 与兄弟家族的分工:[教学论](../讲透教学论/README.md)管课堂工艺层,
> 本家族管**起点层**(发展先于教学,学科学习之前的世界)。
