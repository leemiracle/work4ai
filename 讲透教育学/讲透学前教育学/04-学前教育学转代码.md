# 04 · 学前教育学转代码:把起点层搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:学前教育学的可机读层(03 章谱系左端)几乎可以
> 无损转码,游戏体验与家庭因果不可转码;四条代码走廊——
> **里程碑筛查、观察编码、衰减双曲线、定向分配**——把
> "筛查、看懂游戏、效应到期、预算投向"分别变成可跑、可断言、
> 可做敏感性扫描的实验;其中后两条是本家族的独门:
> **在政策拍板之前,把"智商增益蒸发而人生结果保留"与
> "定向优于普遍的机制边界"复现出来**。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",[教学论](../讲透教学论/README.md)
转代码要解决"操作化",学前教育学转代码要解决"**分龄化**":
把一段教育宣称("这个项目对幼儿好")先翻成带年龄分母、
带通道、带剂量的模型(哪个年龄段×哪条发展通道×多大剂量),
再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清
哪些对象第一步就走得通(绿色区),哪些走不通(红色区),
再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学前教育概念 | 代码化身 | 备注 |
|------------|---------|------|
| 发展里程碑 | 领域分层 DAG+月龄窗+红旗规则(过窗未过) | 走廊 1:筛查的骨架;窗是区间不是及格线(03 章 §四) |
| 游戏观察 | 帕滕六水平×皮亚杰三型的双轴编码器+时间取样 | 走廊 2:编码框是先验承诺,须留框架外自由栏 |
| 干预效应的衰减 | 双通道传递模型(认知衰减快/非认知保留久)+断言 | 走廊 3:家族实验属地(佩里的机制版) |
| 干预预算分配 | 剂量-收益响应+挤出/参与缺口+目标效率断言 | 走廊 4:同预算普遍 vs 定向的比较实验 |
| 家园沟通 | 三层字段(沟通×参与×一致性)的状态同步 | 03 章构造物 3 的直接实现(纯 schema 工程) |
| 入学准备预测 | 前阅读/前数学/执行功能→早期学业的风险模型 | 地基住[统计学宇宙](../../讲透统计学/README.md);本家族取特征定义 |

**转不动/转不动的边界(红色区)**:

1. **游戏体验(专注/心流)**:构念未构造化(03 章右端)——
   工程对策:退到测量学(观察编码+自由栏),不进调度逻辑。
2. **发展的因果**(什么让儿童发展快):家庭/遗传/机构混淆
   一切——证据要队列与随机(02 章阶梯),仿真是安慰剂世界。
3. **"好的童年"的价值层**:投资回报率算得出,童年值不值得
   活在测评里算不出——目的层送回[教育学原理](../讲透教育学原理/README.md)。
4. **质量的整体判定**:过程质量(师幼互动)靠人评,
   自动化的"AI 看课打分"在构念效度上不成立(02 章量表之争)
   ——工程边界:可做提醒,不可做判定。

**边界的一句话**:绿色区=03 章谱系左端四构造物+它们的动态版;
红色区=谱系右端+价值层——**先问构造学,再谈转码**。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:里程碑筛查走廊(DAG+红旗)

```
发展 DAG(节点=里程碑,边=先修) ──▶ 三态判定:未到窗/过了/过窗未过
      │                                    │
      └──月龄窗(区间,非及格线)            └──红旗:同领域连续两窗未过 ──▶ 转介(ECSE 鉴别入口)
```

- **理论→模型**:03 章引擎 1 的机器化;筛查的输出不是分数,
  是**分领域的三态表+红旗位**——红旗是异常检测规则,不是诊断
  (诊断权在临床,01 章主线 C 的制度边界)。
- **算法层**:查表 O(领域数);重点扫描**窗口宽度的展示参数**:
  面向家长的产品必须把区间渲染得比单点醒目(03 章 §四反直觉的
  工程对策——防筛查表变焦虑机器)。
- **真实系统**:发育监测 App、入园体检信息系统、ECSE 初筛工具。
- **性能工程要点**:里程碑库要**版本化**(常模漂移,03 章);
  文化适配是内容工程不是代码工程;断言"红旗≠诊断"进产品文案 CI。

### 走廊 2:观察编码走廊(看懂游戏的半机械化)

```
事件流(时间/可见行为/情境) ──编码──▶ 双轴落格:帕滕六水平 × 皮亚杰三型
      │                                        │
      └──框架外自由栏(强制字段)                └──聚合:形态配比(自由/引导/直接)
                                             ──▶ 课程自检(宣称 vs 实测的实施落差)
```

- **理论→模型**:03 章构造物 2;编码≠理解,机器做对齐与聚合,
  解读权留给人——**自由栏是必须字段**不是可选字段
  (编码框=先验承诺的防腐剂)。
- **算法层**:双轴查表 O(1)/条;聚合做**儿童主导占比**的
  滑动窗口(01 章"游戏本位宣称"的实测指标)。
- **真实系统**:电子成长档案、教师观察工具、教研复盘平台。
- **性能工程要点**:记录按学期分区;**解读字段与描述字段
  分库**(03 章练习 2 的制度化);别把编码聚合值喂给家长端
  排名——那是把仪器变赛跑(03 章 §四)。

### 走廊 3:衰减双曲线走廊(效应到期的机器化)——本家族实验

```
干预宣称 ──操作化──▶ 双通道:认知(学校等化,衰减快)+非认知(自我生产,保留久)
      │                        │
      └──剂量-收益响应(凹)    └──长尾结果(毕业/犯罪)= 非认知主导的阈值模型
                             ──▶ 断言:①组间差 ②认知衰减/长尾保留 ③定向>普遍
```

- **理论→模型**:00 章铁律(智商增益会蒸发,人生结果不会)翻成
  两状态变量:认知技能的传递系数 T_c(t)=exp(-λ_c·t)(学校给所有人,
  优势被等化),非认知 T_n(t)=exp(-λ_n·t)(skills beget skills,
  高保留);成年长尾走非认知主导的阈值模型(Heckman-Kautz 通说)。
- **算法层**:CRN 两世界配对(同儿童干预/对照共用随机数,
  组内差=干预效应,方差缩减——与教育技术学家族实验同纪律);
  长尾分组只按**干预前特征**分层(不能按结果分层,方法论纪律)。
- **本家族实现**:[`experiments/early_intervention_decay.py`](experiments/early_intervention_decay.py)
  ——断言三律(组间差/衰减与保留/目标效率)+机制边界
  (挤出与响应异质全关时定向反超)+Monte Carlo 敏感性
  (200 次抖动,传递率保持机制约束:λ_c≥0.14 保衰减过半、
  λ_n≤0.012 保高保留——同一机制不许自由漂移)。
- **性能工程要点**:纯标准库;4000 儿童×三世界毫秒级;
  seed=base+draw 保可复现;MC 抖动参数与断言阈值成对版本化。

### 走廊 4:定向分配走廊(预算投向的比较实验)

```
同预算 B ──▶ 普遍方案(全员剂量 B/N × 参与率) vs 定向方案(弱势 25% 剂量 4B/N × 外展)
      │                        │
      └──挤出(非弱势净增量×0.1-0.2)└──总成年结果增量 ──▶ 目标效率比(定向/普遍)
```

- **理论→模型**:01 章判读要点 3 的机器化——目标效率不是先验
  真理,由三个供给机制决定:非弱势挤出(公共供给替代自费)、
  普遍方案的参与缺口(信息/交通/信任)、弱势的补偿性响应。
  家族实验的机制边界段把它反过来证:**机制全关时"薄撒"占优**
  (凹响应的数学),这是本走廊最值钱的一行输出。
- **算法层**:剂量-收益凹响应(dose^α)+三机制乘子;
  扫描三个乘子得目标效率比的等值线——政策敏感性分析的
  最小骨架(真实版住[统计学宇宙](../../讲透统计学/README.md)
  的政策评估方法)。
- **真实系统**:教育预算模拟器、项目评估的机制分解报告。
- **性能工程要点**:外层 MC 循环天然可并行;**输出永远带机制
  归因**(哪个乘子贡献多少),只给一个比值的模拟是黑箱叙事。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:做幼儿产品——适龄映射是第一行代码

- 任何面向 0-6 岁的内容产品(故事 App/玩具/课程),第一层
  逻辑应该是**里程碑适配**:内容挂月龄窗与领域标签(03 章构造物 1),
  推荐按"窗内"而非"提前";"超前学"按钮在学段产品是营销,
  在学龄前产品是伤害(02 章敏感期→关键期的滑坡)。
- 快速诊断:产品里"几个月会什么"的展示,窗口区间比单点醒目吗?
  单点渲染的里程碑产品是在制造焦虑回头客。

### 落点 2:建家园/园所系统——观察 schema 先于功能

- 建成长档案/家园平台时,**观察记录 schema(03 章)比功能先设计**:
  描述与解读分栏、框架外自由栏强制——schema 定了,仪器就定了,
  后补的自由栏永远救不回丢失的观察。
- 快速诊断:家长端推送的"干预密度"——每日几张照片几条提醒
  在制造什么?通道做密是工程本能,"参与决策"一格留空是产品
  默认(01 章主线 D);反过来设计。

### 落点 3:幼儿数据治理——最高敏感级不是口号

- 幼儿发展数据是**终身档案的第一页**:标签(发育迟缓/行为问题)
  贴在 3 岁孩子身上,画像闭环的自我实现风险比任何学段都大
  (03 章引擎 2 的放大版)——保留期最短化、标签可撤回、
  转介类数据与教学类数据物理分域,这三条是底线不是加分项。
- 快速诊断:任何"幼儿发展预测"功能,先问预测结果喂给谁、
  能不能删——**测量变成命运**在学龄前的伤害半径最长。
