# 讲透幼儿园课程与保教 · 游戏本位课程:0-6 岁"教"什么、怎么教

> **定位句**:这支负责"**课程之问**"——把发展规律翻译成一日生活:
> 0-6 岁的"课程"长什么样,保育与教育为什么是一件事。它守着
> 家族宪法的形态半壁:**游戏即课程,但游戏本位不等于放任**——
> 自由游戏/有指导的游戏/直接教学三档各有所长,学前课程的
> 手艺在三档配比与 ZPD 支架;"小学化"是把一年级的课程表
> 向下搬,违反的不是情怀,是发展与证据(00 章之争一)。
> GB/T 13745 88047 学前教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透学前教育学](../README.md)

## 诞生

- **谁/何时**:福禄贝尔 1840(恩物:第一套"课程化玩具");蒙台梭利
  1907-1909(儿童之家:准备环境/教具/工作循环);1960s 直接教学派
  (贝瑞特-恩格尔曼)与高瞻 HighScope(韦卡特:计划-做-回顾,
  佩里项目的课程本体);瑞吉欧方案教学(马拉古齐,战后意大利);
  NAEYC 1987/2009(DAP 三适切);新西兰 Te Whāriki 1996/2017
  (编织毯式课程);中国 2001《幼儿园教育指导纲要》与 2012
  《3-6 岁儿童学习与发展指南》(五领域;编年事实,通说);
  安吉游戏(浙江安吉的真游戏模式,通说中性陈述)。
- **因什么问题**:①发展规律(哥哥支)怎样落成一日生活——
  "教什么"在 0-6 岁意味着什么;②保育(吃睡盥洗)与教育
  (游戏学习)为什么必须是一个整体(蒙台梭利与 ECEC 一体化的
  共同答案:生活即课程)。

## 核心问题

**已解决**:
- 三档形态的分工(通说):自由游戏管社会性与语言,有指导的游戏
  管概念与执行功能(不劣于直接教学且动机更优),直接教学管
  特定技能的短期增益
- DAP 三适切(年龄/个体/文化)——反"小学化"的专业底线(教材共识)
- 一日常规的结构价值:稳定的过渡与自主环节本身就是课程
  (蒙台梭利线与高瞻线的共识)

**未解决/深水区**:
- **配比问题**:三档各占多少、何时切换——没有跨情境处方,
  是每班每季的形成性决策
- **"游戏本位"的实施落差**:官方语汇与活动室现实的距离,
  怎么测(配比观察)怎么缩(教研)
- **幼小衔接的方向**:学前向小学靠(准备度),还是小学向学前靠
  (游戏化入学)——与普通教育学(波5待建)共管

## ✨ 这支最美的一个事实

**计划-做-回顾**。高瞻课程给自由游戏塞进两个结构化时刻:玩前
自己**计划**(玩什么、怎么玩),玩后自己**回顾**(做了什么、
明天改什么)——两个教师主导的十分钟,把自由游戏变成"执行功能
的自选练习场":计划是工作记忆,回顾是元认知。佩里项目用的正是
这套课程:游戏没有变,变的是游戏的**边框**——课程设计的手艺
不在选边(纯游戏/纯教学),在搭边框。
