# 讲透儿童发展与游戏 · 皮亚杰-维果茨基线:发展先于教学,游戏创造最近发展区

> **定位句**:这支负责"**发展之问**"——0-6 岁的儿童是如何建构世界的,
> 游戏在其中干了什么活?它守着家族宪法的理论半壁:
> 皮亚杰(阶段不可跳:发展先于教学)与维果茨基(教学走在发展前面:
> 游戏创造最近发展区,儿童在游戏中"高出一头")——两条线不是对手,
> 是排队规则的两半。**游戏是发展引擎,不是学习的间歇**。
> GB/T 13745 88047 学前教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透学前教育学](../README.md)

## 诞生

- **谁/何时**:卢梭 1762(发现儿童);福禄贝尔 1840(恩物与游戏课程);
  皮亚杰 1920s-1970(临床法/阶段论/发生认识论);帕滕 1932
  (游戏的社会性六水平);维果茨基 1933(游戏创造 ZPD;1978 英译);
  艾里克森 1950(0-6 岁三关口:信任/自主/主动);1970s- 起假装游戏
  与心理理论、执行功能的实验线(通说)。
- **因什么问题**:①"学前该教什么"取决于"儿童此时是什么"——
  发展规律是课程的地基;②游戏占幼儿清醒时间的大头,
  它是消遣还是工作?

## 核心问题

**已解决**:
- 阶段的顺序性(感知运动→前运算;顺序不变,年龄有弹性)——教材共识
- 游戏的发展功能:维果茨基判词(游戏中高出一头)+帕滕六水平
  (社会性参与的阶梯)——观察与课程的公共骨架
- 象征游戏与表征/心理理论、执行功能的关联(相关证据充分,通说)

**未解决/深水区**:
- **假装游戏→执行功能的因果方向**(玩游戏练出自控,还是自控强
  才玩得成?实验仍在拉锯)
- **皮亚杰系的能力低估批评**:幼儿比经典实验测得的更能干
  (方法改进后"错误"消失)——阶段边界在移
- **游戏的文化形态差异**:六水平阶梯在不同育儿文化中的普适性
  (通说争议)

## ✨ 这支最美的一个事实

**儿童在游戏中高出一头**。维果茨基 1933 年的判词:三岁孩子
在过家里"当妈妈"时,自我控制、语言复杂度、坚持性都超过日常
水平——游戏不是发展的回声,是发展的排练厅:儿童心甘情愿地
站在自己够不着的边缘上工作。直觉把游戏当休息,证据把游戏
当引擎;整个游戏本位课程(弟弟支的地盘)立在这一个事实之上。
