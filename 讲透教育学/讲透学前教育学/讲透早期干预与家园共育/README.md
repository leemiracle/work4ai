# 讲透早期干预与家园共育 · Head Start 传统:差距、补偿与第一环境

> **定位句**:这支负责"**公平之问**"——早期差距从哪来、补偿干预
> 买得到什么、家庭在其中是什么角色。它守着家族宪法的证据铁律:
> **智商增益会蒸发,人生结果不会**(佩里悖论);干预的主通道是
> 非认知技能,主伙伴是家庭——家庭是第一教育环境,家园共育是
> 干预的延长线;Heckman 曲线说的是回报率排序,不是"三岁定终身"。
> GB/T 13745 88047 学前教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透学前教育学](../README.md)

## 诞生

- **谁/何时**:佩里学前项目 1962-1967 入组(123 名弱势儿童随机分组,
  两年高质量课程+每周家访,追踪至今;40 岁报告 Schweinhart 等 2005);
  Head Start 1965(向贫困宣战:教育+健康+营养+家长参与综合服务);
  Westinghouse 评估 1969(智商衰减的第一份冷水报告);Abecedarian
  1972-(0-5 岁全日制,认知效应部分保留至成年);赫克曼 2000s
  Heckman 曲线与 skills beget skills(Heckman-Kautz 非认知);
  OECD Starting Strong 2001-;IDEA 学前段(3-5 岁 FAPE;01 章主线 C)。
- **因什么问题**:①早期差距出现得比直觉早(18-24 个月词汇差距
  已可测,Fernald 等 2013 通说)——公平的战场必须前移;②家庭既是
  差距的来源又是补偿的资源,干预怎么跟家庭结盟(佩里的每周家访
  是祖师爷)。

## 核心问题

**已解决**:
- 高质量早期干预对弱势儿童成年人生结果的正效应(佩里/
  Abecedarian 随机证据,通说)
- 双通道结构:认知增益衰减(学校等化),非认知增益保留
  (Heckman-Kautz)——家族实验的靶
- 家庭参与的层次骨架(爱普斯坦六型)与家访的有效方向
  (养育质量中等改善,通说综述)

**未解决/深水区**:
- **fadeout 的机制**:真消失/测量天花板/通道转移三解释之争
  ——决定"还要不要投"的关键参数
- **家园共育的因果**:家长参与与儿童结果的相关几乎总被家庭资本
  混淆,干净的因果证据稀缺
- **普遍 vs 定向**:目标效率由挤出/参与缺口/补偿响应三机制决定
  (家族实验机制边界),识别成本与污名效应在模型外
- **规模化保真**:123 人高保真项目推广到百万人,质量怎么不塌

## ✨ 这支最美的一个事实

**四十年的对账**。1962 年一张随机分组表,123 个名字;四十后年
变成 Heckman 曲线——早期投资回报随年龄递减,改写多国公共预算
优先级。智商优势小学就消失,若只测智商,结论是"失败";40 岁时
毕业率、就业、犯罪全面改善,结论是"成功"——**同一个项目,
两张考卷,两种历史评价**:干预的考卷要用人生的到期日。
