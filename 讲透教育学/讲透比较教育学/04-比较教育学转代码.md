# 04 · 比较教育学转代码:把镜子搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**。
>
> **本章一句话**:比较教育学的可机读层(03 章谱系左端)几乎可以
> 无损转码,"语境"与"借鉴的真实动机"不可转码;四条代码走廊——
> **排名重构、等值与口径、系统聚类、迁移链追踪**——把"排名里
> 混着什么、量尺怎么造、国家怎么分群、政策怎么流动"分别变成
> 可跑、可断言、可做敏感性扫描的实验;其中排名重构走廊是本家族
> 的独门:它模拟的不是教育系统,而是**读教育系统的那套跨国
> 比较语法**。

---

## 开篇:不是"能不能转",是"转到哪一层"

比较教育学转代码要解决"**比较的形式化**":把"谁比谁、控什么、
按什么口径"先翻成明确的数据结构与统计流程,再翻成代码。翻译的
损耗发生在**口径与等值**的建模上——所以本章第一条走廊不是模拟
教育,而是模拟"排名如何被读歪"。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 比较教育学概念 | 代码化身 | 备注 |
|----------------|---------|------|
| 跨国排名及其重构 | 分解模型(系统效应+背景效应+交互)+协变量调整+排序对比 | 家族实验全程纯标准库;排名即参数 |
| 测评口径档案 | schema 校验(年龄/年级/覆盖率/排除规则元数据) | 03 章构造物 2 的直接实现 |
| 等值链读法 | 锚题-量尺-标准误的传播计算(朴素版) | 真实系统用 IRT 软件链;朴素版足以讲清误差累积 |
| 系统聚类 | 多维特征编码+距离+层次聚类 | 替代排名的"分群不排队"读法 |
| 政策迁移图谱 | 有向图+出度/入度/掮客中介度 | 03 章构造物 3 的直接实现 |
| 趋势与不确定度 | 多轮聚合+置信区间对比 | 实验断言③的机制玩具 |

**转不动/转不动的边界(红色区)**:

1. **语境与"民族性"**:构念未操作化(03 章右端)——工程对策:
   退到案例学与过程追踪,不进产品逻辑。
2. **借鉴的真实动机**(外化论的判断):动机在政治过程里,
   文档只能留痕不能读心——图谱标注"文献可考",不做意图推断。
3. **"哪国教育更好"整体判断**:多目标不可通约(质量/公平/
   满意),禁止合成单一优越分——合成即价值判断,不归代码管。
4. **构念的跨国等价**:DIF 与翻译等价是心理测量专业件+语言学
   判断,通用代码只能做提醒不能做裁定。

**边界的一句话**:绿色区=03 章谱系左端三构造物+比较语法的
参数化;红色区=谱系右端——**先问构造学,再谈转码**(与
[教育管理学 04 章](../讲透教育管理学/04-教育管理学转代码.md)
同一条铁律)。

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:排名重构走廊(本家族独门:模拟"读排名的语法")

```
跨国分数 ──分解──▶ 学生成绩 = 系统效应 + 背景效应 + 交互 + 噪声
      │                        │
      │                        ▼
      │            原始排名(均值)vs 调整排名(扣除背景后的系统效应)
      └──追踪──▶ 多轮重复测量 ──▶ 系统效应的置信区间(轮间波动入账)
```

- **理论→模型**:每个国家有真实的系统效应(潜变量)与生源背景
  分布(构成);观测的总分=系统+背景×斜率(各国斜率=系统的
  公平缓释度,即交互项)+噪声;排名观察者只看得到总分。
- **算法层**:协变量调整回归(含国家哑变量)求系统效应估计;
  多轮抽样模拟测评轮次;不确定度=抽样误差+轮间波动。
- **本家族实现**:[`experiments/pisa_decomposition.py`](experiments/pisa_decomposition.py)
  ——断言三律:①同系统效应、不同背景分布→总分排名不同
  (构成掩盖);②调整前后排名显著不同(构成≠系统);③单轮
  比较高估系统差异,多轮追踪后置信区间展宽(单轮的"显著"
  有一部分是轮间波动冒充的)。
- **真实系统**:读任何国际测评排行榜/城市学区排名/医院 league
  table 前的防御性分析;口径辩论的参数化支撑。
- **性能工程要点**:断言用确定性基准+抖动 Monte Carlo 双层
  (结构结论与参数稳健分开报);调整回归注意哑变量共线
  (完全共线=构成完全混淆,不可识别)。

### 走廊 2:等值与口径走廊(可比性的工程审计)

```
口径档案 ──校验──▶ 年龄/年级?覆盖率?排除规则?轮间锚题?
      │
      └──误差传播 ──▶ 报告结论时:均值差 ± 合成不确定度(标准误⊕轮间波动)
```

- **理论→模型**:等值链每环有参数化误差(锚题漂移/抽样/翻译),
  合成不确定度按方差相加传播——**结论的可信度=链条最弱一环**。
- **算法层**:schema 校验+方差传播公式;对"两个国家差 d 分"
  自动产出"含不确定度的措辞模板"(显著/不可分/方向不明)。
- **真实系统**:国际指标仪表盘的置信标注;教育报告自动生成中
  的"负责任措辞"件(拒绝裸均值差)。
- **性能工程要点**:轻;价值在**把数字变成带口气的话**——
  d±s 的三个措辞区间,就是 02 章"方法口音"的代码化。

### 走廊 3:系统聚类走廊(分群不排队)

```
各国多维特征(分流年龄/集权度/测评参与/公私结构…) ──标准化──▶ 距离矩阵
      ──层次聚类──▶ 系统家族树 ──▶ 同群内比较(语境较近,可比性较强)
```

- **理论→模型**:替代"全球一张榜单"的读法——先分群再比较;
  同群国家语境较近,构成与制度混杂的识别负担较小(00 章 §七
  发现 3 的正面用法:群内差异比群间差异更有解释力)。
- **算法层**:标准化+欧氏/加权距离+凝聚层次聚类;对距离权重
  做敏感性扫描(权重谁定的,分群就偏向谁的价值观——03 章
  指标暗礁的再现)。
- **真实系统**:跨国政策研究的"可比组"构造;测评报告的
  "类似经济体"分组。
- **性能工程要点**:聚类结果的稳定性检验(bootstrap 群稳定度)
  必做——不稳定的分群是分析便利不是世界结构(02 章天敌)。

### 走廊 4:迁移链追踪走廊(借鉴史的网络化)

```
政策迁移图谱(03 章构造物 3) ──网络分析──▶ 出度(被借)/入度(借入)
      /掮客中介度 ──▶ 谁在转译 ──▶ 修辞型引用占比(外化论显影)
```

- **理论→模型**:每条引用边带改造类型(整体搬运/要素改造/
  仅作修辞);"仅作修辞"占比高=外化论在图谱上的直接检验
  (借鉴的外部形式服务内部议程)。
- **算法层**:纯图计算(度/中介中心性/路径);无拟合无噪声,
  分歧只来自**编码协议**(什么算一次引用)。
- **真实系统**:教育政策文献计量、国际组织技术援助流向分析、
  "改革是从哪儿来的"的溯源审计。
- **性能工程要点**:最轻的走廊;重点在编码协议的版本管理
  与"文献可考"边界声明(图谱完备性=文档留存,不是流动本体)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:跨国数据管道——先装口径,再装分数

- 接入任何国际教育数据(测评/统计年鉴)的工程纪律:第一层表
  是**口径元数据**(总体/排除/覆盖率/量尺版本),第二层才是
  分数;没有第一层的管道,下游一切图表都在裸奔。
- 快速诊断:一个国际比较看板如果只渲染均值不渲染标准误,
  它在制度上是一台**误读发生器**(走廊 2 是补丁)。

### 落点 2:排行榜防御工具——你是读者的统计保镖

- 走廊 1 可整体外借:任何"单位×平均分"的榜单(学校/医院/
  团队/模型基准),先跑构成分解再谈名次;构成变量换个口径
  榜单重排,不是丑闻,是榜样的本性。
- 快速诊断:把榜单的两个版本(原始/调整)并排呈现的工具,
  永远比单一"更正确"的榜单诚实——**不确定度是内容不是装饰**。

### 落点 3:LLM 时代的跨国叙事——翻译与摘要的越权点

- LLM 擅长把国际报告压缩成"该国教育如何"的叙事——它越权的
  地址恰是红色区:**语境不可构造**部分会被模型流畅地填平。
  工程红线:生成涉及国别比较的摘要时,强制携带口径与不确定度
  模板(走廊 2 的措辞件),禁止合成"最优教育制度"类判断。
- 迁移图谱(走廊 4)是 LLM 的正业:文献抽取+图构建+溯源审计
  ——让"这个改革借鉴自哪里"变成可核查的边,而不是文章里的
  一句话。

## ✍️ 练习

1. 🐍 跑 [`experiments/pisa_decomposition.py`](experiments/pisa_decomposition.py)
   ——把背景斜率减半(系统缓释更强),观察三律哪些松动;
   再把轮间波动标准差加大一倍,看断言③的区间展宽多少
2. ✋ 用走廊 2 的模板,给你最近看到的一条国际比较新闻生成
   "负责任措辞"版本(含不确定度与口径声明),对比两版的
   说服力与诚实度
3. ✋ 用走廊 3 给五~八个你熟悉的系统(国家/地区/学校类型)
   选四个特征做聚类,换一次权重重跑——分群变了吗?
   变化处就是你价值观进入分析的地址
4. ✋ 用走廊 4 的三类边(搬运/改造/修辞)给一项教育改革的
   "来源说法"做编码,并写出"文献可考"的边界声明一句
