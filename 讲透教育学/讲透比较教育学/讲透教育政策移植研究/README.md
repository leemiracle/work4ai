# 讲透教育政策移植研究 · 照完镜子怎么办——政策迁移的成功失败谱

> **定位句**:这支负责"**实践层**"——比较结论怎么变成本国行动:
> 政策借鉴的四阶段过程(外来吸引-决策-实施-内化/本土化)、
> "旅行改革"在搬运中的改造与再语境化、成功失败谱系(成功案例
> 几乎都=深度再语境化)。三支中**最贴近政策现场**的一支:它把
> "学某国"从一个口号拆成一个有阶段、有事故点、有失败统计的
> 过程。
> GB/T 13745 88037 比较教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透比较教育学](../README.md)

## 诞生

- **谁/何时**:萨德勒 1900("外部的事物"——移植警告的源头);
  康德尔 1933(民族性:同样的输入,不同的长成);菲利普斯-奥克斯
  《教育政策借鉴》四阶段模型(2004,吸引-决策-实施-内化);
  施泰纳-卡姆西"旅行改革/再语境化"研究线(2000s,改革在全球
  流动中被本地行动者重新组装);里兹维-林加德《全球教育政策》
  (2010,测评时代的证据借鉴与全球治理批判)。
- **因什么问题**:①为什么"照搬"很少成、"改造"常成(语境依赖)
  ②借鉴的政治学:外来模式在本国争论中当什么用(外化)
  ③全球化时代政策流动的速度与变形怎么追踪(旅行改革)。

## 核心问题

**已解决**:
- 移植是过程不是事件——四阶段框架把"失败"定位到阶段——标准框架
- 再语境化是常态而非事故(搬运必然伴随改造)——实证积累的通说
- "PISA 震惊"式危机叙事是外来吸引阶段的典型触发——通说
  (按文献陈述现象,不评价政策)

**未解决/深水区**:
- **改造量悖论**:改到多少就不叫移植了——移植与本土创新的
  边界无判定标准
- **成功的归因**:成功案例的"深度再语境化"是原因还是幸存者
  的事后描述——识别难题
- **修辞型借鉴**:仅把外国当论据用(外化)算不算移植——
  图谱编码的边界问题(家族 03 章引擎 2)
- **反向流动与南南借鉴**:全球南方之间的政策流动研究仍薄
  (家族 01 章主线 B)

## ✨ 这支最美的一个事实

**四阶段模型:把"移植失败"从新闻变成阶段常态**。此前失败被
当丑闻(学得不像/执行走样);菲利普斯-奥克斯把借鉴拆成四段后,
失败有了**地址**——吸引阶段没问条件(结构旅游)、实施阶段
没有本地转译者(照片式搬运)、内化阶段没有和本国传统焊接
(两张皮)。为什么美:一个流程框架替整个学科完成了对
"移植失败"的去道德化——失败不再是人的失败,是流程缺段的
必然(与[教育管理学](../../讲透教育管理学/README.md)的
"实施缺口是乘法性必然"互为表里)。
