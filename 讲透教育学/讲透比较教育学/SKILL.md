## ② 核心思维模式(这个分支怎么想问题)

1. **语境先检**:看到任何"某国做法有效",先问**外部的事物**
   (萨德勒)——哪些条件使它在来源国有效;没有条件句的
   "国际经验"都是结构旅游的门票
2. **构成-系统两分**:看到任何跨国排名,先问均值里混着什么
   ——生源构成还是系统水平?不做构成调整的排名是构成报告
   (实验断言①②)
3. **趋势纪律**:单轮波动与测量误差让排名抖动——只认
   趋势链+不确定度;单轮"显著"有一部分是轮间波动冒充的
   (实验断言③)
4. **捆绑拆包**:国名是制度与文化的捆绑包——跨国差异先问
   制度(可改)还是文化(难搬),拆不开的结论只能算描述
5. **过程化移植**:移植不是事件是过程——外来吸引→决策→
   实施→内化/本土化四阶段;失败多发生在被跳过的阶段,
   成功案例几乎都=深度再语境化
6. **议程反问**:比较结论生产本身就是权力——谁出资、谁定义
   指标、谁被排进表尾;外化论:借鉴的外部形式服务内部议程
   (看他国镜子里照出的是拿镜子的人)

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 三关借鉴声明(来源条件/本国对照/改造过程) | 审任何"该学某国"的主张;发借鉴许可证 |
| 贝雷迪四步法(描述-解释-并置-比较) | 组织一次国别研究;"比较"放第四步不是第一步 |
| 菲利普斯-奥克斯四阶段(吸引/决策/实施/内化) | 拆解移植案例;定位失败与被跳过的阶段 |
| 构成调整回归(背景项+国家哑变量) | 重构排名;把"构成差异"从"系统差异"里减出来 |
| 轮间波动入账的不确定度(抽样⊕轮间) | 读多轮测评趋势;判断"显著"是否冒充 |
| 口径三问(年龄/年级?覆盖率?排除规则?) | 接入任何国际数据前的第一层校验 |
| 三层课程模型(打算的-实施的-获得的) | 课程侧跨国比较的取景框 |
| 再语境化编码(搬运/改造/仅修辞) | 政策来源审计;外化论显影 |
| 系统聚类(先分群再比较) | 替代全球一张榜;构造"可比组" |
| 世界文化/同构读法(名义趋同≠实际变异) | 审"各国都这样"的制度比较 |

## ④ 常见误区与禁忌

- **排行榜当系统效能量表**:不控构成的排名是广告——构成-系统
  两分是读数前提,不是学术洁癖
- **"学芬兰"式整体搬运**:排名领先证明该体系在该语境有效,
  不证明可拆卖;移植失败是常态不是执行事故
- **只比文件不比运行**:名义趋同/实际变异(松散耦合)——
  改革文本全球相像,课堂与结果未必;结构照片≠运行
- **国家平均主义**:"某国教育如何"平均掉了它自己最要紧的
  方差——国内差异常大于国间差异
- **量尺自信**:等值链的光洁掩盖构念等价与总体可比两个链外
  缺口——分数有九位小数,不等于比较有一成把握
- **把 PV 当个人分数**:合理值是测量分布的抽样,不是点估计;
  只报均值不报标准误是双重丢弃
