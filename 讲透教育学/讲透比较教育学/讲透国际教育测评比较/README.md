# 讲透国际教育测评比较 · 镜子本身怎么造——PISA/TIMSS 的读法与批评

> **定位句**:这支负责"**证据层**"——跨国比较的数据从哪来、错在哪:
> PISA(OECD 线,15 岁人口,测"为生活做准备"的能力)与
> TIMSS/PIRLS(IEA 线,按年级抽样,锚定课程)的**构造**(总体-
> 抽样-题册-等值-量表)与**读法批评**(测量误差/构成效应/题目
> 跨国功能等价/覆盖率)。三支中**技术密度最高**的一支:它不问
> "哪国更好",它问"排名这个制品的公差是多少"。
> GB/T 13745 88037 比较教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透比较教育学](../README.md)

## 诞生

- **谁/何时**:IEA 1958 年成立(跨国测评的民间学会线),1964 年
  首轮国际数学研究;TIMSS 1995 起(三层课程模型:打算的-实施的-
  获得的课程);PIRLS 2001 起(阅读);OECD 主导 PISA 2000 首轮
  (政府间组织线,不考课程只测素养);2001 年德国"PISA 震惊"
  开启测评驱动的政策时代(通说按文献陈述);PISA-D 类适配测评
  向中低收入国家扩展(2010s)。
- **因什么问题**:①各国教育产出不可通约,需要同一把尺
  (等值技术)②尺子造出来后,怎么读才不误读(方法论批评)
  ③尺子本身隐含什么"教育质量"观(批判层)。

## 核心问题

**已解决**:
- 轮内可比的技术链(抽样-题册螺旋-IRT 标定-等值-趋势锚题)
  ——技术共识
- 分数带测量不确定度(合理值方法:分数是分布不是点)——技术共识
- PISA 与 TIMSS 的口径差(年龄 vs 年级)及其后果——方法论文献通说

**未解决/深水区**:
- **构念的跨国等价**:题目经翻译后是否还测同一构念(测量不变性/
  DIF)——批评与官方回应长期并存(按方法论文献客观呈现双方)
- **构成效应的调整口径**:调到什么程度算公平比较——每种调整
  都是价值选择(家族实验断言②的深层)
- **被测总体的比资格**:入学率/分流/排除规则的国别差异——
  "谁在表内谁在表外"
- **单轮与趋势**:轮间波动多大程度是真实变化——疫后单轮的
  解读风险(家族 01 章主线 A)

## ✨ 这支最美的一个事实

**合理值(plausible values)**:跨国测评不为每个学生报一个分数,
而是抽出一组"合理值"——测量论上的诚实:你的分数是一个分布,
国家均值是分布的聚合。为什么美:一套让**不确定度从数据结构的
底层设计就住进去**的工程决策;多数公开误用(把 PV 当个人分数、
只报均值不报标准误)都是丢弃了构造物自带的诚实(家族 03 章
彩蛋的展开)。
