# 讲透比较教育理论与方法 · 怎么照镜子不失真——可比性与借鉴-语境化

> **定位句**:这支负责"**方法层**"——比较凭什么成立:可比性问题
> (什么算"可比",可比是给定的还是造出来的)、借鉴-语境化传统
> (从萨德勒的警告到施瑞尔的外化论)、学科自己的方法史(贝雷迪
> 四步-诺亚-埃克斯坦科学化-批判转向)。三支中**理论气质最浓**
> 的一支:它问的是比较的"宪法层"——一条跨国断言要满足什么条件
> 才配叫知识。
> GB/T 13745 88037 比较教育学 · **自定主干支**(GB/T 无三级明细)。
> 家族:[讲透比较教育学](../README.md)

## 诞生

- **谁/何时**:朱利安《比较教育的研究计划与初步设想》(1817,
  事实采集+问卷表+国际机构的超前设想);萨德勒 1900 演讲
  ("外部的事物"——语境优先于移植);康德尔《比较教育》(1933,
  民族性与历史条件);贝雷迪《比较方法在教育中的应用》(1964,
  描述-解释-并置-比较四步);诺亚-埃克斯坦《走向比较教育的科学》
  (1969,假设-数据-检验);施瑞尔比较教育方法论(1990s,外化论:
  借鉴的外部形式服务内部合法化问题)。
- **因什么问题**:①各国的教育事实凭什么放在同一张表里(可比性)
  ②为什么"看外国"总被当成"抄外国",抄又总失败(借鉴-语境化)
  ③人文描述传统与科学化主张如何共存(方法论多元)。

## 核心问题

**已解决**:
- 比较不是起点是终点——四步法把"并置"立为独立步骤——方法共识
- 语境优先原则("外部的事物"制约校内事物)——学科立法句
- 借鉴什么由内部问题决定(外化论)——解释框架通说
- 方法论多元共存(人文-科学-批判三传统并行)——教材共识

**未解决/深水区**:
- **可比性的判定标准**:可比是语义问题(翻译/构念)还是结构问题
  (制度功能等价)——两路判据长期并行无裁决
- **"语境"的刻画**:语境是因素清单(因素分析)还是剩余项
  (不可列尽的背景)——操作化未完成
- **单国深描的概括权限**:案例知识能外推到哪里,无一般答案
- **比较知识的不对称**:谁比较谁——与去殖民思潮正面相接
  (家族 01 章主线 D)

## ✨ 这支最美的一个事实

**贝雷迪的"并置"步**:四步法(描述-解释-并置-比较)的第三步——
把各国材料摆进同一张对照表,让差异自己站出来,**比较(第四步)
此时才获得资格**。为什么美:它把两百年最常见的事故(拿一个
印象直接开比)变成流程错误——在"并置"之前的任何"比较",
都是印象对印象。一步之立,学科的门槛立起来了(家族 00 章
五镜头之三的展开)。
