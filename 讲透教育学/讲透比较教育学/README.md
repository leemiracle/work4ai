# 讲透比较教育学 · 镜子层:以他者为镜看本教育——借鉴与语境化的百年张力

> **本质一句话**:比较教育学=教育的镜子学——它不回答"什么是好教育"
> (那是[教育学原理](../讲透教育学原理/README.md)的事),它回答
> **他者的教育能照出本教育的什么、又凭什么比较**。这门学科两百年
> 的全部教训可以压成一句话——**发现"镜子会变形"**:排名里混着
> 构成差异,借鉴里藏着语境依赖,可比性不是给定的而是造出来的。
> 第一主题:**教育能移植吗**(可比性问题——本家族的母题)。
>

>

## 〇、家族树(GB/T 无三级明细 → 自定主干支)

```
讲透比较教育学/              GB/T 88037(无三级明细,自定主干支)
├── 讲透比较教育理论与方法/   自定支——方法层:怎么照镜子不失真(可比性/借鉴-语境化;朱利安-萨德勒-康德尔-贝雷迪-施瑞尔线)
├── 讲透国际教育测评比较/     自定支——证据层:镜子本身怎么造(PISA/TIMSS 的读法与批评;IEA-OECD 线)
└── 讲透教育政策移植研究/     自定支——实践层:照完镜子怎么办(政策迁移的成功失败谱;菲利普斯-奥克斯-施泰纳-卡姆西线)
```

> 三支的共同血统:**同一面镜子的三段分工**——方法层(比较凭什么成立)、
> 证据层(比较的数据从哪来、错在哪)、实践层(比较结论怎么变成本国
> 行动)。三段合成比较教育的完整回路:造镜,照镜,用镜。
