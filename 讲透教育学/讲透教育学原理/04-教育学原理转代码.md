# 04 · 教育学原理转代码:把教育的基本问题搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:教育学原理的可构造端(03 章谱系左半)几乎可以无损转码,
> 规范端永远不可转码——价值前提不可从数据推出(02 章界河的机器版);
> 四条代码走廊——**两西格玛仿真 / 掌握学习循环 / 目标分类对齐 / 素养-课程映射**——
> 把"教学法的效应结构"与"目标链的分解结构"变成可跑、可断言、可扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",教育学原理转代码要解决"**形式化**":
把一句双负载的教育语言(素养=知识+技能+态度的情境化运用)先翻成
单负载的模型(四元组/效应参数/达标循环),再翻成代码。
翻译损耗全部发生在第一步——所以本章先划清哪些对象第一步走得通(绿色区),
哪些走不通(红色区),再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 教育学概念 | 代码化身 | 备注 |
|------------|---------|------|
| 两西格玛/教学法效应 | 三组对照仿真(课堂/辅导/掌握),效应参数化 | 本家族实验全程纯标准库;布卢姆 1984 通说数字做断言锚 |
| 掌握学习 | 标准参照循环:测验→诊断→矫正→复测(参数:难度/循环增益/次数/标准线) | 卡罗尔-布卢姆模型的直接编码(03 章引擎 2) |
| 教育目标分类 | 二维矩阵打点器:题干/目标→(认知过程,知识类型)坐标 | 题库工业的公共数据结构;规则版几十行,LLM 版做预标注 |
| 素养框架 | (领域,素养,水平,证据)四元组+课程图谱对齐 | 对齐=图匹配问题(哪个教学单元贡献哪条素养的哪档证据) |
| 学习进步的追踪 | 标准参照的纵向数据(达标时间/矫正次数) | 可作掌握学习的遥测;注意常模信息被有意丢弃 |
| 教育生产函数的**框架** | 成绩=f(家庭/学校/同伴)的回归脚手架 | 计量问题,不是仿真问题——框架可编码,识别要靠统计侧(教育统计学归 91040,见宇宙 README) |

**转不动/转不动的边界(红色区)**:

1. **教育目的本身**:价值前提不可从数据推出(休谟铡刀的机器版)——
   任何把"什么是好的教育"外包给优化目标的系统,实际是把**写代码者的
   价值前提编译成了默认设置**(01 章主线 C 批判教育学的代码层论断)。
   工程对策:目的参数显式化、可审计、可争辩(谁改目标,谁留名),不当训练损失藏起来。
2. **"全面发展的人"等理念型**:不可分解为参数表(03 章谱系右端)——
   硬造指标必得参数表不得人。对策:退到目的链的**可构造层**(课程目标),
   理念层留给论证与人审。
3. **主体性/师生关系的现场**:可编码其外显(话语轮次/提问类型),
   不可编码其意义——对话的"教育性"是诠释判断;对策:编码做证据,
   判断留给人。
4. **因果识别**:教育回报的因果效应(上好学校是否改变人生)是计量问题,
   仿真只能造"安慰剂世界"辅助直觉,不能替代准实验设计。

**边界的一句话**:绿色区=03 章谱系的左半段+两条引擎的可参数化部分;
红色区=规范端+理念型。**红线:凡涉及"应当",机器只能携带与呈现价值,
不能产生价值。**

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:两西格玛走廊(教学法效应的全参数化)

```
布卢姆 1984 通说 ──参数化──▶ 三组生成模型(课堂/一对一辅导/掌握学习)
      │
      └──敏感性扫描──▶ 效应 vs 师生比曲线 ──▶ 规模化成本的结构分析
```

- **理论→模型**:学习结果 = 初始差异 + 教学法效应(均值移位)+
  个体化程度(方差压缩);一对一辅导把三个结构条件(即时诊断/即时矫正/
  自定进度)全部拉满→均值 +2σ 且方差收窄;掌握学习只参数化其中一部分。
- **本家族实现**:[`experiments/bloom_two_sigma.py`](experiments/bloom_two_sigma.py)
  ——断言①辅导组均值高出传统组约 2σ(通说数字);②掌握学习收回差距一半
  左右、且方差收敛更慢;③效应随师生比单调衰减(1:5 约折半,大班趋近课堂)。
- **真实系统**:家教/小班/分层教学的效果预算;AI 导师的"两西格玛承诺"审计。
- **性能工程要点**:三组生成天然可并行(按组分流 seed 保证可复现);
  效应曲线扫描是 embarassingly parallel;输出分布而非单轨迹。

### 走廊 2:掌握学习走廊(标准参照循环的编码)

```
卡罗尔-布卢姆模型 ──循环参数化──▶ (标准线, 循环增益β, 循环次数k)
      │
      └──收敛扫描──▶ 均值收敛 vs 方差收敛速度 ──▶ 单元设计与课时预算
```

- **理论→模型**:每单元形成性测验,未达标者进入矫正活动后复测;
  学习程度=f(所用时间/所需时间),矫正提高时间利用率→逼近全员达标。
- **算法层**:循环 k 次的生成模型;关键输出是**收敛的双速度**
  (均值快、方差慢——家庭实验断言 2),直接对应"补差为什么比提优贵"。
- **真实系统**:单元测验+矫正包的课程设计;Mastery-based 的自适应练习系统。
- **性能工程要点**:循环可参数扫描(k=1..6);断言写成"均值收敛分数>
  方差收敛分数"这一条结构不等式,而不是只比终值。

### 走廊 3:目标分类走廊(布卢姆矩阵的对齐器)

```
2001 修订版二维矩阵 ──编码──▶ (认知过程×知识) 坐标系
      │
      └──打点/审计──▶ 试卷与课程的分布图 ──▶ 目标链一致性检查
```

- **理论→模型**:把题干/教案/课程标准条目映射到二维坐标;
  分布图=课程的实际意图画像(03 章美之时刻 5 的自动化)。
- **算法层**:规则版(行为动词表+内容关键词)几十行标准库即可教学;
  生产版用 LLM 预标注+人工抽检(标注一致性 kappa 是质量闸门)。
- **真实系统**:题库打标、课程标准审计、"高阶目标空缺"报告。
- **性能工程要点**:这是最轻的走廊;重点不在算力,在于把"评卷形容词"
  (批判性/综合性)变成可审计坐标——**审计胜过生成**。

### 走廊 4:素养-课程对齐走廊(schema 的图匹配)

```
素养框架四元组 ──schema化──▶ 素养节点(领域,素养,水平,证据)
      │
      └──图匹配──▶ 课程单元 × 素养证据 的对齐矩阵 ──▶ 覆盖度/孤点/复用度报告
```

- **理论→模型**:课程图谱(单元-单元先修关系)与素养框架(层级节点)
  做二部图对齐;证据栏空缺的素养=宣言节点(03 章暗礁的自动探测)。
- **算法层**:对齐矩阵+覆盖度统计;孤点分析(无单元供养的素养/
  无素养归属的单元)是学校课程审计的现成工具。
- **性能工程要点**:证据多元是红线(同一素养至少两条证据通道),
  防止单指标古德哈特化(03 章铁律);重审周期写进 schema 元数据。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:教育/学习类产品的目标审计——你是目的链的守门人

- 做学习产品先过两问:**目标挂在谱系哪一端**(目标分类端可优化,
  目的端只能呈现不可优化)?**优化指标是谁写的价值前提**?
  把"应当"藏进 loss function 的产品,是 01 章主线 C 的批判对象原型。

### 落点 2:AI 导师——两西格玛问题的最新应试者

- 布卢姆把"找到与一对一辅导同样有效的大班组教学法"命名为**两西格玛问题**
  (1984),这个问题是整个教育技术行业的创始问题;生成式 AI 是第四次冲击
  (广播/电视/MOOC 之后)。工程上的审计点照抄实验断言:它改变了反馈结构吗
  (诊断速度/矫正精度/进度自主)——只改变内容包装的方案,
  效应上限在课堂水平(实验断言 3 的曲线)。
- 性能工程视角:一对一是"教师容量的 1:1 独占",AI 导师的真实主张是
  **把反馈结构的边际成本压到近零**——审计时看延迟(诊断是否即时)、
  质量(矫正是否对症)、自主(进度是否学生可控)三项,不看演示视频。

### 落点 3:技能图谱与素养 schema——招聘/培训系统的同一数学

- 公司能力模型、岗位技能图谱与素养框架是同一构造物(四元组);
  走廊 4 的孤点分析直接复用:无证据支撑的"能力"与无培养路径的"能力"
  都是宣言节点。红线同 03 章:**度量什么就得到什么**——
  把不可测素养硬接进考核指标,得到注水证据(古德哈特的教育版,
  与管理学多任务扭曲同构,对照讲透管理理论 04 章 OKR 落点)。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:结构审计者之眼**——评估任何教育技术(产品/制度/APP),
先看它改变了**反馈结构的哪一项**(诊断速度/矫正精度/进度自主),
再看它的优化指标把谁的价值前提编译成了默认设置。
规范性不可机械化——这不是工程的自卑,是工程的红线:
机器放大目的,从不发明目的。
