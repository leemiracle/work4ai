## 三、教材锚(通说,按血统)

- 夸美纽斯《大教学论》(1632):教育民主化的第一份纲领
- 赫尔巴特《普通教育学》(1806):第一本以科学自命的教育学
- 杜威《民主主义与教育》(1916):现代教育派的总纲
- 弗莱雷《被压迫者教育学》(1970):批判教育学的原点
- 联合国教科文组织报告三部曲:《学会生存》(1972)→《教育:财富蕴藏其中》(1996)→《一起重新构想我们的未来》(2021)
- 中文教材锚:叶澜《教育原理》;全国十二所重点师范大学联编《教育学基础》
