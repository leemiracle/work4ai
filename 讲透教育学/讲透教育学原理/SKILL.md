# 教育学原理思维技能卡(讲透教育学原理 · GB/T 88014)

## ① 何时读此分支(问题特征触发词)

看到这些词,先来本家族:

- **本质类**:教育是什么、教育的本质、教育与社会、教育与人的发展、教育与生产劳动、教化/社会化/训练的分界
- **目的类**:教育目的、培养目标、个人本位/社会本位、全面发展、什么值得教、什么知识最有价值、素养本位、核心素养、21 世纪技能
- **主体类**:教师中心/学生中心、双主体、主导与主体、师生关系、主体间性、AI 与教师、学习共同体
- **流派类**:传统教育派/现代教育派、实用主义教育、批判教育学、存钱式教育、建构主义、掌握学习、终身教育、新社会契约
- **语言类**:教育学的规范性/应然与实然、教育定义之争、"素质教育"对译

## ② 核心思维模式(这个分支怎么想问题)

1. **三问定位**:任何教育议题先归位——它是"是什么"(本质)、"为了什么"(目的)还是"靠谁"(主体)之争?归错位的讨论必然错频
2. **双轨拆分**:听到任何教育主张,先拆"应当/能够/值得"三层措辞,再找它的价值大前提(常藏在"好的教育"这类未论证的定语里)
3. **钟摆识别**:任何目的宣言,标出它在个人本位↔社会本位钟摆的哪一极、上一极是谁、会召唤怎样的回摆
4. **反馈结构优先**:评估任何教学法/教育技术,先问它改了反馈结构吗(诊断速度/矫正精度/进度自主)——效应上限由结构决定,与内容包装无关
5. **端点匹配**:教育主张的对象在可构造谱系哪一端(目标分类可编码/素养框架要证据/目的本质只可论证)?端点与工具错配是教育软件与教育口号共同的失败模式

## ③ 工具箱(概念/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 三问地图(是什么/为了什么/靠谁) | 给任何教育争论定位与归档;判断一场争论为何总谈不拢 |
| 赫尔巴特双根基(伦理学定目的/心理学定方法) | 拆教育学论证:哪半在过"是-应当"的河,桥搭在哪 |
| 目的-手段链(泰勒四问:目的/经验/组织/评价) | 审计培养方案/课程标准:目标链断在哪一层、语义衰减多少 |
| 布卢姆二维矩阵(2001 修订版:认知过程×知识) | 给试卷/课程打点,查"高阶目标空缺";题库打标 |
| 标准参照 vs 常模参照 | 判断一套评价在测"达标"还是"排名";掌握学习的结构前提 |
| 两西格玛参数化(效应=Δ_max·注意力份额) | 预算任何辅导/小班/AI 导师的效应上限与规模化成本 |
| 素养四元组(领域,素养,水平,证据) | 把能力模型/素养框架做成可审计结构;探测宣言节点 |
| 存钱式/提问式编码 | 给一节课/一个学习产品做批判教育学速写 |
| 钟摆模型(个人本位↔社会本位;UNESCO 三部曲对读) | 给教育政策话语/全球议程做历史定位 |

## ④ 常见误区与禁忌

- **把规范断言当经验发现**:"研究表明应当……"式短路——先补价值大前提再引用
- **漫画化阵营**:赫尔巴特≠只会灌输(多方面兴趣论者),杜威≠放任自流(《经验与教育》专门批评过)——引标签前先对原著
- **素养当技能**:丢掉"知识+技能+态度×情境"的整合义,素养框架退化成技能清单
- **给理念型造参数**:"全面发展"不可参数表化;量表上没有的,不等于课程里不该有
- **单证据通道**:素养只接一条可测指标,必得注水证据(古德哈特的教育版)
- **混淆广义/狭义教育**:与"教化/社会化/训练"混界,争论变伪分歧
- **把 UNESCO 倡议当结论**:全球报告的规范层(契约倡议)与经验层(指标监测)交替出现,分层读
