# 讲透教育目的论 · 个人本位与社会本位的百年钟摆

> **定位句**:这支负责"**为了什么**"——教育该把人带向哪里:为个人的人生完满
> (个人本位)还是为社会的延续与秩序(社会本位)——两极交替如钟摆;
> 杜威"生长即目的"是最著名的停摆方案,UNESCO"共同利益"是最新一次。
> **自定主干支声明**:GB/T 88014 未列三级明细,本支为家族自定主干支之一。

## 诞生

- **谁/何时**:柏拉图《理想国》(教育为国家培养护卫者——社会本位原型);
  卢梭《爱弥儿》(1762,教育遵循自然本性——个人本位原型);涂尔干
  《教育与社会学》(成年一代对未成熟一代的系统影响,使其符合社会要求);
  凯兴斯泰纳(公民教育,国家主义教育观);斯宾塞《教育论》(1861,
  "什么知识最有价值"——功利主义入场);杜威《民主主义与教育》(1916,
  教育过程在自身之外无目的——停摆方案)。
- **因什么问题**:①培养什么人(内容之争)②目的该由谁定(立法权之争)
  ③目的与过程能否统一(杜威对二元论的攻击)。

## 核心问题

**已解决**:
- 两极谱系化:个人本位(卢梭/裴斯泰洛齐/福禄贝尔/罗杰斯)与社会本位
  (柏拉图/涂尔干/凯兴斯泰纳)的代表、论证与制度形态——教材通说
- 调和形态:文化本位说、生活本位说(斯宾塞"预备说"及其批评)、
  马克思主义人的全面发展学说(中文教育学原理的教育目的理论基础)

**未解决/深水区**:
- 钟摆会不会停:杜威停摆方案被批评为"把目的问题偷换成过程问题"
- 目的的立法权分层:国家课程文本与全球议程(UNESCO 新社会契约,家族 01 章
  主线 A)——多边文书是不是新的立法者;"什么值得学"在生成式 AI 时代的整体重估(01 章主线 D)

## ✨ 这支最美的一个事实

**钟摆的节律**:每一极摆到尽头都会自己召唤回摆——极致个人本位
(放任的儿童中心)召唤纪律与标准,极致社会本位(整齐划一)召唤个性与解放。
杜威的方案美在换轴:不问"目的在个人还是社会",问"目的是内在的还是外在的"——
**生长之外无目的**:每一次生长为下一次生长创造条件,目的即过程的自我超越。
一个概念的替换(外在→内在),让两千年两极之争露出第三维度。
