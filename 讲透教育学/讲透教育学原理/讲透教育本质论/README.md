# 讲透教育本质论 · 教育是什么:一场关于"存在"的两千年追问

> **定位句**:这支负责"**是什么**"——教育与教化/社会化/训练的分界;
> 教育是传递(文化复制)、生长(经验改造)、再生产(社会复制)还是培养(人的生成)
> ——本质之争的四个候选答案住这支。
> **自定主干支声明**:GB/T 88014 未列三级明细,本支为家族自定主干支之一。
> 家族:[讲透教育学原理](../README.md)(宇宙:[../../README.md](../../README.md))

## 诞生

- **谁/何时**:柏拉图《理想国》(洞穴喻:教育非灌输,乃灵魂转向);
  卢梭《爱弥儿》(1762,教育即自然发展);杜威《民主主义与教育》(1916,
  教育即生活、即生长、即经验的持续改造);雅斯贝尔斯《什么是教育》;
  中文侧:20 世纪 80 年代**教育本质大讨论**(教育是上层建筑还是生产力等,
  全国性论争十余年,见家族 00 章问题清单)。
- **因什么问题**:①给"教育"下定义(与教化/社会化/训练划界)
  ②教育与社会结构谁决定谁 ③反本质主义挑战后,"本质"还问得吗。

## 核心问题

**已解决**:
- 广义/狭义教育的工作定义(广义:有意识地增进人的发展的社会活动;狭义:学校教育)——通说
- 四个候选本质的谱系化:传递说/生长说/培养说/再生产说各自的代表与推论

**未解决/深水区**:
- 教育有没有单一本质(反本质主义:维特根斯坦家族相似——"教育"或许只有
  交叉重叠的用法,没有共同本质)
- 教育与教化(Bildung)的分界是否可译、可操作化(02 章海关表的活案例);
  数字环境是否产生"教育"的新本质候选(在线/人机共存情境的划界)

## ✨ 这支最美的一个事实

**一场"本质大讨论"把一门学科的地基翻了出来**:80 年代的论争(上层建筑说/
生产力说/社会实践活动说/培养人说等)表面在争定义,实际在争"教育与政治、
经济谁先谁后"——每个定义背后是一套教育治理的授权逻辑。定义学即政治经济学:
**给"教育"下什么定义,就授权谁来办教育、按什么标准办教育**。
这是规范性语言力量的第二现场(家族 00 章美之时刻 1 的镜像)。

## 假设与依赖

- 本质主义假设(教育有可追问的本质)——买到概念的严格性;
  付出:可能把流动的实践钉死在定义上(反本质主义的批评)
- 定义可划界假设(教育与教化/社会化/训练可分)——买到学科对象;
  付出:边界案例(家庭教育/自媒体学习/AI 对话)持续冲击划界
- 概念工具主要来自哲学:存在论与概念分析上游在
  [../../../讲透哲学/README.md](../../../讲透哲学/README.md)
