## §0 全局视角：算法 = 算法，但要跑在 GPU 上

```
理论算法 (paper) → GPU 实现 (production) 有巨大鸿沟:
  - 显存层级（HBM/SRAM/寄存器）
  - 并行模式（SIMT/warp/grid）
  - 通信成本（NVLink/PCIe/网络）
```

> 🔑 **核心 DNA**：**很多 SOTA 算法不能 scale，是因为没考虑 GPU 物理特性**。FlashAttention 的成功证明：**算法 + 硬件协同设计 = 真正的突破**。

## §1 十条算法经验

### 算法经验 GS1：显存层级 = AI 性能的关键

> GPU 显存层级（速度递减、容量递增）：
> - 寄存器（~1 cycle, KB 级）
> - SRAM / L1/L2 cache（~10 cycle, MB 级）
> - **HBM**（~400 cycle, GB 级）
> - 主机内存（~1000+ cycle, TB 级）
>
> 算法本质：**算法要"显存感知"——避免 HBM 反复读写**（应用 KV1 KV Cache、OP6 条件数）。

### 算法经验 GS2：FlashAttention = 算法 + IO 协同

> 标准 attention 反复读写 HBM → 慢。
> FlashAttention 把 attention 切块在 SRAM 算 → IO 减少 $O(n^2)$ → $O(n)$。
>
> 算法本质：**数学等价，IO 优化**——同样的算法，IO-aware 版本快 2-4×（强化 TR3 attention 变体、KV1）。

### 算法经验 GS3：算子融合（Operator Fusion）

> 把多个小算子合并成一个大 kernel，减少中间 tensor 写回 HBM：
> ```python
> # 差: 多次 HBM 读写
> x = x + b; x = x * w; x = relu(x)
> # 好: 融合成一个 kernel
> x = fused_bias_mul_relu(x, b, w)
> ```
>
> 算法本质：**减少 IO = 加速**（应用 PT6 TorchCompile、OP3 SGD）。

### 算法经验 GS4：并行模式 = SIMD 的层级

> GPU 并行层级：
> - **Thread**：单个 CUDA thread
> - **Warp**（32 threads）：同步执行
> - **Block**：共享 SMEM，可同步
> - **Grid**：跨 SM，需 global sync
>
> 算法本质：**并行度 = 算法的"GPU 友好度"**（应用 N3 参数共享、A1 元架构）。

### 算法经验 GS5：通信是分布式训练的瓶颈

> 多 GPU 训练的通信：
> - **All-Reduce**（DDP 梯度同步）
> - **All-Gather / Reduce-Scatter**（FSDP）
> - **P2P**（pipeline 并行）
>
> 算法本质：**通信-计算重叠（overlap）是分布式训练的核心优化**（应用 PT5 分布式）。

### 算法经验 GS6：混合精度 = GPU 的硬件特性

> 现代 GPU（A100/H100）的 Tensor Core 专门加速 fp16/bf16：
> - fp32 算力 19.5 TFLOPS（A100）
> - **fp16 算力 312 TFLOPS（16×）**
> - int8 算力 624 TOPS（32×）
>
> 算法本质：**用精度换算力——硬件设计本身就鼓励低精度**（应用 PT4 AMP、KV5 量化）。

### 算法经验 GS7：推理引擎的三大优化

> vLLM/TensorRT 等推理引擎的核心：
> 1. **Batching**：连续批处理（continuous batching）
> 2. **KV Cache 管理**：PagedAttention
> 3. **量化**：INT8/INT4 推理
>
> 算法本质：**吞吐 vs 延迟的权衡**（应用 KV1-KV8、PT10 研究到生产）。

### 算法经验 GS8：GPU 架构趋势

> - **More SRAM, less HBM**：H100 的 L2 cache 比 A100 大几倍
> - **Specialized units**：Transformer Engine、视频解码器
> - **Chiplet**：多芯片封装
> - **CXL**：内存解耦
>
> 算法本质：**硬件演进决定了什么算法能 scale**（应用 TR3 attention 变体、A10 attention 边界）。

### 算法经验 GS9：边缘部署 vs 数据中心

> | 场景 | 设备 | 算法选择 |
> |------|------|---------|
> | 数据中心 | H100/B100 | 全精度大模型 |
> | 边缘服务器 | A10/L40 | INT8 量化 |
> | 手机 | 神经引擎 | DistilBERT、量化 |
> | 嵌入式 | 微控制器 | TinyML、感知量化 |
>
> 算法本质：**部署环境决定模型选择**（应用 M6 成本-能力权衡、Ch10 BERT 至今没死）。

### 算法经验 GS10：硬件-算法协同设计

> 经典案例：
> - **FlashAttention**：算法为 SRAM 设计
> - **Transformer Engine**：硬件为 Transformer 设计
> - **Diffusion 专用芯片**：硬件为扩散模型设计
>
> 算法本质：**未来 AI 的突破在硬件-算法协同**——纯算法或纯硬件都不够（应用 T1 试炼场、TR3）。
