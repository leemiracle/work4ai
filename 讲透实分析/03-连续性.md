## 一、直觉层：连续到底是什么

### 1.1 中学课本的"骗人"定义

课本说："**函数图像不断开**就叫连续。"

问题：什么叫"不断开"？画图能骗你——$y = x \sin(1/x)$ 在 0 附近看起来断但其实连续，Dirichlet 函数画不出但其实存在。

### 1.2 极限视角的连续

$f$ 在 $a$ 连续 $\iff \lim_{x \to a} f(x) = f(a)$。展开 ε-δ：

$$\forall \epsilon > 0, \exists \delta > 0, \forall x: |x - a| < \delta \Rightarrow |f(x) - f(a)| < \epsilon$$

**与极限定义的差别**：没有 $0 < |x - a|$——连续允许 $x = a$。

### 1.3 三种"坏"函数（反直觉）

| 函数 | 在 0 处？ | 为什么 |
|------|---------|--------|
| $f(x) = x$ | ✅ 连续 | 极限 = 函数值 = 0 |
| $\sin(1/x)$（令 $f(0)=0$）| ❌ 不连续 | $\lim_{x\to 0}$ 震荡不存在 |
| Dirichlet: $\mathbb{Q}$ 上 1，无理数上 0 | ❌ 处处不连续 | 任意点极限都不存在 |

### 1.4 Weierstrass 的恐怖（深化 00 章）

$W(x) = \sum a^n \cos(b^n \pi x)$ **处处连续**（一致收敛级数）但**处处不可微**。

> 💡 **反直觉发现 1**：连续 ≠ 光滑。19 世纪数学家以为"连续差不多就可微"，Weierstrass 1872 摧毁了 200 年直觉。

## 二、数学层：连续的 4 大定理

### 2.1 四种等价定义

1. **ε-δ 形式**：$\forall \epsilon, \exists \delta, |x-a| < \delta \Rightarrow |f(x) - f(a)| < \epsilon$
2. **序列形式**：$x_n \to a \Rightarrow f(x_n) \to f(a)$
3. **开集形式**（拓扑）：开集的原像是开集
4. **闭集形式**：闭集的原像是闭集

推广到一般拓扑空间时，**开集形式最一般**（这是 ML 中 GNN、流形学习的语言）。

### 2.2 一致连续（更强）

- **点连续**：每个 $a$ 单独连续（$\delta$ 可依赖 $a$）
- **一致连续**：$\delta$ **不依赖** $a$：$\forall \epsilon, \exists \delta, \forall x, y: |x-y| < \delta \Rightarrow |f(x) - f(y)| < \epsilon$

**反例**：$f(x) = 1/x$ 在 $(0, 1]$ 连续但**不一致连续**——$x$ 越接近 0，越小的 $\delta$ 才够。

### 2.3 闭区间上连续函数的 4 大定理

| 定理 | 陈述 | 直觉 |
|------|------|------|
| **介值定理** | $f(a)<0<f(b) \Rightarrow \exists c, f(c)=0$ | 连续从负变正必过 0 |
| **极值定理** | $f$ 在 $[a,b]$ 取到 max/min | 闭区间不"逃" |
| **有界性定理** | $f$ 在 $[a,b]$ 有界 | 同上 |
| **Heine-Cantor（一致连续）** | 紧致集上连续 ⟹ 一致连续 | 局部→全局 |

> 💡 **关键**：紧致（闭+有界）让**局部**性质（连续）变**全局**性质（一致连续 / 极值）。这是 ML 泛化、优化收敛、数值稳定性的基础。

### 2.4 反例：开/无界集上定理失效

| 情形 | 定理 | 失效 |
|------|------|------|
| $1/x$ on $(0,1]$ | 有界性 | 无界 ✗ |
| $x$ on $(0,1)$ | 极值 | sup=1 不在 ✗ |
| $x^2$ on $\mathbb{R}$ | 一致连续 | 不一致 ✗ |

**反直觉发现 2**：定理失效的根源是"不紧致"。"闭"是关键。

## 三、Python 实验：可视化 4 大概念

跑 `python3 -u experiments/03_continuity.py`，看到：

```
[1] 连续 vs 不连续 vs Dirichlet
    sin(1/x) 在 0 附近震荡 → 极限不存在 → 不连续

[2] 一致连续性（固定 ε=0.1，找每个 x 需要的 δ）
    f(x)=x² on [0,1]: δ 下界 ≈ 0.05 → 一致连续 ✓
    f(x)=1/x on (0,1]: x→0 时 δ→0 → 不一致 ✗

[3] 极值定理
    闭区间 [0,1]: 极值取到 ✓
    开区间 (0,1): sup/inf 不在区间 → 取不到 ✗

[4] Lipschitz 与 ML 泛化
    sigmoid 导数 max = 0.25 ✓（理论值）
    Lipschitz 网络 ⟹ 泛化误差 ≤ L·R
```

**反直觉发现 3**：1/x 在 $(0,1]$ 上"看起来连续"，但**不一致连续**——δ 随 x 漂移。ML 里这对应"局部稳定 ≠ 全局稳定"。

## 五、不足与应用

### 5.1 连续的局限

- **不保证可微**（Weierstrass）
- **不保证好计算**（Dirichlet 函数不可有效计算）
- **闭区间要求**（开区间定理失效）

### 5.2 应用

| 领域 | 用到什么 |
|------|---------|
| **ML 泛化** | Lipschitz ⟹ 泛化界（spectral norm regularization）|
| **优化** | 凸 + 连续 ⟹ 收敛（SGD 在凸函数上）|
| **数值分析** | 条件数 / 数值稳定性（连续误差传播）|
| **拓扑** | 连续是拓扑不变量（同胚 = 双射+连续+逆连续）|
| **微分方程** | 解的存在性（Picard-Lindelöf 需要 Lipschitz）|
