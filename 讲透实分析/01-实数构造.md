# 01 - 实数构造：Dedekind 怎么填满有理数的"洞"

> 上一章我们看见：$\mathbb{Q}$ 在数轴上**到处是洞**（如 $\sqrt{2}$）。这一章看 Dedekind 怎么把这些洞填满，**从 $\mathbb{Q}$ 严格构造出 $\mathbb{R}$**。
>
> 这是实分析的"创世记"——一切定理的地基。

---

## 一、直觉层：Dedekind cut 是什么

### 1.1 一个 19 世纪 21 岁年轻人的洞察

1872 年，Richard Dedekind（21 岁，Gauss 的学生）在想：**怎么从有理数 $\mathbb{Q}$ 构造出 $\mathbb{R}$？**

他的洞察：**不要试图定义"实数是什么"，而是定义"实数把 $\mathbb{Q}$ 切成两半的方式"**。

> **Dedekind cut**：一个实数 = 一个把 $\mathbb{Q}$ 分成 $(L, R)$ 两部分的方式，其中 $L$ 的每个数 < $R$ 的每个数，且 $L$ 没有最大元素。

例：
- 实数 $\sqrt{2}$ = 切法 $L = \{q \in \mathbb{Q} : q^2 < 2 \text{ 或 } q < 0\}$，$R = \{q \in \mathbb{Q} : q^2 > 2, q > 0\}$
- 实数 $0$ = 切法 $L = \{q \in \mathbb{Q} : q < 0\}$，$R = \{q \in \mathbb{Q} : q \geq 0\}$

**反直觉发现 1**：每个有理数 $q$ 也能用切法表示（$L = \{r \in \mathbb{Q} : r < q\}$）。所以 $\mathbb{Q} \subset \mathbb{R}$ 自然嵌入。新加的是那些"切在有理数的洞上"的实数（如 $\sqrt{2}$）。

### 1.2 为什么"切割"比"小数"更好

你可能想：实数不就是无限小数吗？如 $\sqrt{2} = 1.41421356\ldots$

**问题**：小数表示有歧义（$1.000\ldots = 0.999\ldots$），而且"无限小数"本身需要先定义"极限"——循环论证。

Dedekind cut 避开这个：它**只用 $\mathbb{Q}$ 的语言**（"小于"关系），不需要先有"实数"概念。从 $\mathbb{Q}$ 出发，定义切法的集合，构造出 $\mathbb{R}$。

> 💡 **教训**：数学构造的优雅 = 用最少的假设得到最多的结构。Dedekind cut 只用 $\mathbb{Q}$ 的序，构造出 $\mathbb{R}$ 的完备性。

## 二、数学层：Dedekind cut 的严格定义

### 2.1 形式定义

**Dedekind cut** 是 $\mathbb{Q}$ 的子集 $\alpha$，满足：
1. $\alpha \neq \emptyset$ 且 $\alpha \neq \mathbb{Q}$
2. **向下封闭**：$p \in \alpha, q < p \Rightarrow q \in \alpha$
3. **无最大元素**：$p \in \alpha \Rightarrow \exists r \in \alpha, p < r$

**定义**：$\mathbb{R} := \{所有 Dedekind cut\}$

### 2.2 运算的定义

实数 = cut。那么加法 / 乘法 / 序怎么定义？

**序**：$\alpha < \beta \iff \alpha \subsetneq \beta$（真子集）

**加法**：$\alpha + \beta := \{p + q : p \in \alpha, q \in \beta\}$

**乘法**（对正 cut）：$\alpha \cdot \beta := \{p \cdot q : p \in \alpha, p > 0, q \in \beta, q > 0\} \cup \{q \in \mathbb{Q} : q \leq 0\}$

**乘法（含负）**：需要分情况，繁琐，见 Tao《Analysis I》Ch 5 或 Rudin Ch 1。

### 2.3 关键定理：$\mathbb{R}$ 完备

**定理（Dedekind 完备性）**：$\mathbb{R}$ 的每个非空有上界的子集都有上确界（supremum）。

证明要点：设 $S \subset \mathbb{R}$ 有上界。令 $\alpha^* = \bigcup_{a \in S} a$（所有 cut 的并）。验证 $\alpha^*$ 是 cut，且是 $S$ 的上确界。

**反直觉发现 2**：$\mathbb{Q}$ **不**完备。例：$S = \{q \in \mathbb{Q} : q^2 < 2\}$ 在 $\mathbb{Q}$ 中有上界但没有上确界（$\sup S = \sqrt{2} \notin \mathbb{Q}$）。

### 2.4 另一种构造：Cauchy 序列

Cantor（同时期，1872）给出另一种构造：**实数 = 有理 Cauchy 序列的等价类**。

- Cauchy 序列：$a_1, a_2, \ldots$ 满足对任意 $\epsilon > 0$ 存在 $N$，对所有 $m, n > N$，$|a_m - a_n| < \epsilon$
- 等价类：两个序列 $(a_n), (b_n)$ 等价 $\iff \lim |a_n - b_n| = 0$
- $\mathbb{R} := \{所有有理 Cauchy 序列的等价类\}$

**两种构造的等价性**：Dedekind cut 和 Cauchy 序列构造出的 $\mathbb{R}$ 同构（差一个唯一同构）。这本身是一个深刻定理。

| 构造 | 优点 | 缺点 |
|------|------|------|
| Dedekind cut | 只用序，几何直观 | 乘法定义繁琐 |
| Cauchy 序列 | 自然推广到度量空间 / 拓扑 | 需先定义极限（轻微循环）|

> 💡 **Tao《Analysis I》**用 Cauchy 序列法（Ch 5）。**Rudin** 用 Dedekind cut 法（Ch 1 附录）。两种都学一遍，理解更深。

## 三、Python 实验层：感受 Dedekind cut

### 3.1 实验：用有理数逼近 + 切法可视化

```python
# 在 experiments/00_irrational_density.py 已展示 Q 的洞。
# 这里演示 Dedekind cut 怎么"捕获" sqrt(2)。
```

下面是核心逻辑（完整脚本在 `experiments/01_dedekind_cut.py`，本系列后续完善）：

```python
from fractions import Fraction  # 精确有理数

# Dedekind cut 的左集 L（逼近 sqrt(2) 的所有有理数 q 使得 q^2 < 2 或 q < 0）
def in_L_sqrt2(q: Fraction) -> bool:
    if q < 0: return True
    return q * q < 2

# 测试：1.41 在 L 里吗？1.42 呢？
print(in_L_sqrt2(Fraction(141, 100)))   # True (1.41²=1.9881 < 2)
print(in_L_sqrt2(Fraction(142, 100)))   # False (1.42²=2.0164 > 2)

# L 没有最大元素：对任何 L 中的 q，都能找到 L 中更大的
def find_larger_in_L(q):
    # 二分搜索找 L 中比 q 大的
    lo, hi = q, q + 1
    for _ in range(100):
        mid = (lo + hi) / 2
        if in_L_sqrt2(mid): lo = mid
        else: hi = mid
    return lo

print(find_larger_in_L(Fraction(141, 100)))  # 逼近 1.41421... 但永不达到
```

**反直觉发现 3**：L 是无穷集，没有最大元素。每次你找到 L 中一个有理数 $q$，都有比 $q$ 大但还在 L 中的有理数。**$\sqrt{2}$ 不在 L 里，也不在 R 里**——它就是 L 和 R 之间的"切割"本身。

### 3.2 实验：Cauchy 序列视角

```python
# 用 Newton 法构造 sqrt(2) 的 Cauchy 序列
def newton_sqrt2():
    x = Fraction(1)
    while True:
        yield x
        x = (x + Fraction(2) / x) / 2  # Newton 迭代

gen = newton_sqrt2()
seq = [next(gen) for _ in range(10)]
for i, x in enumerate(seq):
    diff = abs(float(x) - 2 ** 0.5)
    print(f"  x_{i} = {float(x):.15f}, 误差 = {diff:.2e}")
```

**反直觉发现 4**：Newton 法的每次迭代误差大约减半（二次收敛）。但**误差永远不为 0**——序列的"极限"$\sqrt{2}$ 不在 $\mathbb{Q}$ 里，只能用 Cauchy 等价类表达。

## 五、不足与应用

### 5.1 这个构造的不足

- **效率低**：实际计算用浮点数（IEEE 754），不用 Dedekind cut
- **抽象**：构造 $\mathbb{R}$ 后，几乎没人再回去用 cut。它是个"一次性"的理论装置
- **但**：完备性定理（$\mathbb{R}$ 完备）是**所有后续分析的基础**——值这个代价

### 5.2 应用

- **数值分析**：浮点数 ≠ $\mathbb{R}$。浮点数的"不完备"导致数值误差
- **泛函分析**：Banach 空间 = 完备的赋范空间。实数的完备性是模板
- **p-adic 数**：对每个素数 $p$，可类似从 $\mathbb{Q}$ 构造 $\mathbb{Q}_p$（p-adic 完备化），数论基础
- **构造主义**：Dedekind cut 是构造性的，可形式化（在 Lean / Coq 里）
