# 04 - 微分：从"瞬时变化率"到中值定理（配 Tao Ch 10）

> 学完连续，本章讲微分。核心不是"怎么求导"（你会），而是**为什么导数是这个定义**，以及中值定理的威力。
>
> 这是 Tao《Analysis I》Ch 10 的讲透版。

---

## 一、直觉层

### 1.1 瞬时变化率的悖论

"物体在时刻 $t$ 的瞬时速度"——严格地说，**瞬时不存在**（任何测量都在一段时间内）。Newton 用"流数"，Leibniz 用"无穷小"。Berkeley 骂"已死量的幽灵"。

### 1.2 现代定义（Cauchy 1821）

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

> 💡 导数**就是极限**。你已会 ε-δ，所以已会严格证导数。

---

## 二、数学层

### 2.1 可微 ⟹ 连续（反方向不成立）

证：$f(a+h) - f(a) = h \cdot \frac{f(a+h)-f(a)}{h} \to 0 \cdot f'(a) = 0$。

反例：$|x|$ 在 0 连续但不可微（左 -1，右 +1）。

### 2.2 微分法则

- 和/积/商法则
- **链式法则**：$(f \circ g)'(x) = f'(g(x)) \cdot g'(x)$——**反向传播的数学本质**

### 2.3 中值定理（MVT）★

$$f \text{ 在 } [a,b] \text{ 连续}, (a,b) \text{ 可微} \Rightarrow \exists c \in (a,b): f'(c) = \frac{f(b)-f(a)}{b-a}$$

**直觉**：开了 100km 用 1h，某一刻速度表读数必是 100km/h。

**为什么重要**：连接"导数"（局部）和"函数值"（全局）的桥梁。

### 2.4 MVT 的 4 个推论

| 推论 | 陈述 |
|------|------|
| $f' \equiv 0 \Rightarrow f$ 常数 | 在区间上 |
| $f' = g' \Rightarrow f - g$ 常数 | 不定积分基础 |
| $f' > 0 \Rightarrow f$ 严格递增 | 单调性判据 |
| $f' \geq 0 \Rightarrow f$ 递增 | 弱版 |

### 2.5 Taylor 定理

$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x), \quad R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$$

**直觉**：用多项式逼近函数。$n$ 越大越准（在收敛半径内）。

## 五、不足与应用

| 应用 | 用到 |
|------|------|
| **ML / 反向传播** | 链式法则（PyTorch `backward`）|
| **优化** | 梯度下降（导数指向最大上升）|
| **数值分析** | Newton 法（用导数找根）|
| **物理学** | 速度 / 加速度 = 一阶 / 二阶导数 |

**局限**：
- 导数要求函数"光滑"——但很多 ML 函数不可微（ReLU）
- "几乎处处可微"是 ML 的妥协（不是严格可微）
