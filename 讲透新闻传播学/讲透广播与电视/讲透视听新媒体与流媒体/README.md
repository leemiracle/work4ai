# 讲透视听新媒体与流媒体 · 播→流转型:门户时代的视听产业

> **定位句:这支负责「这条流被平台拆散之后怎么重组」——门户平台、
> 点播与时移、推荐与可见性分配、FAST 线性重生、平台化对国家/地方
> 制作体系的冲击;家族的「现在进行时」支,直接承接 01 章五条战线。**
> 🆓 自定主干支(GB/T 86050 未列本体三级,按学界通行教学分类自定)。
> 家族:[讲透广播与电视](../README.md)

## 诞生

- **谁/何时**:2007 Netflix 开通流媒体服务(从 DVD 租赁到「看现在」);
  2013《纸牌屋》全季放送立「平台原创+算法可见性」模式;2016 Netflix
  同步上线 130 个新市场(全球同发);2019 Disney+/Apple TV+ 入场,
  三巨头格局成形;同期 FAST 频道(Pluto TV/Roku Channel/Samsung TV Plus)
  把线性流搬回平台;中国线:爱优腾长视频平台+IPTV/OTT+短视频(2016 起)
  三层结构,与「台网融合」政策并行——同一个播→流转型,不同的制度解
- **因什么问题**:①电视经济怎么从「窗口+时刻」变成「目录+订阅」
  (稀缺到丰裕的范式转移)②平台化如何重分配叙事生产的权力
  (本地化前移/国家体系失血)③线性形态在云端会不会重生(FAST 之辩)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 门户范式的理论化(Lotz 2021):排播经济→门户经济的框架已成学科共用坐标系 |
| ✅ 已解决 | 平台价值链重写的基本事实(Chalaby 2025 等):制作全球寻源、发行全球同发、版权一次性全球买断 |
| 🔄 进行中 | 平台化对国家/地方制作的冲击测量(《Streaming Europe》现场:制作公司从「给频道供片」变「给平台打工」;欧洲视听观察所年度数据) |
| 🔄 进行中 | 本地化的范式之辩:产业范式已转移(本地原创+全球发行),工艺范式未转移(译配技术延续)——Sánchez-Mompeán 2025 |
| ❓ 未解决 | 「广播」存续形态:FAST 是线性广播的平台化重生,还是长尾回收站;公共时间要不要存在成为制度题(家族中心战场的产业面) |

**最美事实(一句)**:洛茨的「窗口→门户」一词之变——
一对词写尽七十年电视经济史:稀缺经济靠**时刻**定价(窗口/排播/黄金时段),
丰裕经济靠**可见性**定价(目录/算法/首页)——范式转移的全部秘密
压缩在一个名词的替换里。
