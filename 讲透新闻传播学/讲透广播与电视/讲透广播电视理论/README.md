# 讲透广播电视理论 · 线性流、共同在场与公共广播:时间对齐的本体论

> **定位句:这支负责「广播电视是什么、凭什么公共」——线性流(flow)的
> 媒介本体论、共同在场的仪式价值、陪伴感与日常性、频谱稀缺与公共广播
> 的规范理论;家族的「第一公设」(时间对齐机器)在此展开成体系。**
> 🆓 自定主干支(GB/T 86050 未列本体三级,按学界通行教学分类自定)。
> 家族:[讲透广播与电视](../README.md)

## 诞生

- **谁/何时**:思想源头两头同时开工——1920s 里斯(BBC)的
  「告知、教育、娱乐」与执照费制度(公共广播的非市场定价实验);
  学理化在 1970s 之后:威廉斯 1974《电视:技术与文化形式》立
  「流」(planned flow);斯坎纳尔 1996《广播、电视与现代生活》立
  「日常性」(dailiness)与「为任何人而如同为某个人」;西尔弗斯通
  的「驯化」(domestication)把电视接入家庭研究;频谱侧,
  1969 年美国 Red Lion 案把「频谱稀缺→管制正当」写进判例传统
- **因什么问题**:①广播电视作为媒介的本体是什么(流?事件?房间?)
  ②线性播出的共同在场在社会里起什么作用(仪式/认同/公共时间)
  ③频谱稀缺凭什么派生公共问责(公共广播的规范地基)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 流的理论化:观众经验的基本单位是频道流不是节目(威廉斯);日常性:广播把日程编织进生活节奏(斯坎纳尔) |
| ✅ 已解决 | 频谱稀缺→受托经营的规范链:牌照制度的正当性论证(判例与学理双重定型) |
| 🔄 进行中 | 时移/点播是否同一媒介:门户时代的「电视」定义之争(Lotz 框架与批判) |
| 🔄 进行中 | 公共广播转型:从「占有一条流」到「在所有流上被找到」的合法性换锚(家族 01 章战线 5) |
| ❓ 未解决 | 共同在场的社会价值可否延续:公共时间被算法个人化之后,共同体还剩下什么时间结构(家族中心战场的理论面) |

**最美事实(一句)**:斯坎纳尔的「为任何人而如同为某个人」——
广播电视对千万人说话的语法,却让每个听众觉得在对自己一个人说:
**大众性与亲密感在同一句话里成立**,这是印刷媒介从未做到的。
