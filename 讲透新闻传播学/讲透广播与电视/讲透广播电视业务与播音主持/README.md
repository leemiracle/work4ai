## 诞生

- **谁/何时**:播音制度随电台诞生(1940 延安新华广播电台开播即有
  人民广播播音员);主持制度在中国落地于 1980s——1983 沈力主持央视
  《为您服务》,被公认为中国第一位电视节目主持人,把「播」变成
  「说给一个人听」;1986 珠江经济广播电台「大板块+热线电话+直播」
  (珠江模式)重造了广播业务流程;1994 张颂《中国播音学》出版,
  播音由手艺升格为有教材体系的学科
- **因什么问题**:①每天十几小时的流用什么流程填(采编播/制播分离/
  直播与录播)②声音如何标准化又如何个性化(播音规范 vs 主持风格)
  ③时段与形态如何匹配(排播的业务侧:新闻整点/晚间综艺/深夜谈话)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 播音发声训练体系:气息(胸腹联合式)、吐字归音(字头/字腹/字尾)、内外部技巧(内部:情景再现/对象感/内在语;外部:停连/重音/语气/节奏)——「好听」被拆成可考核的工序 |
| ✅ 已解决 | 节目形态库:消息/专题/访谈/综艺/真人秀/板块/热线/民生新闻的形态谱系与制作规程 |
| 🔄 进行中 | AI 合成主播对播音岗位的重构:语音合成的「字正腔圆」免费化之后,人的价值剩哪一层(对象感?责任主体?) |
| 🔄 进行中 | 融媒体业务流程:一次采集多元分发(大屏+小屏+竖屏)对传统制播流程的重写 |
| ❓ 未解决 | 主持人的「人格资产」能否被平台复用:主持人 IP 与机构频道的关系(个别机构的实验 vs 系统性制度安排) |

**最美事实(一句)**:沈力 1983 年的《为您服务》——
把播音员的「对全国广播」改造成主持人的「为您服务」,
一字之差,广播电视找到了斯坎纳尔说的「为任何人而如同为某个人」
的中文业务形态。

## 假设与依赖

- 声音可训练假设:播音是技术体系不是天赋(吐字归音把汉语音节工程化)
- 工作语言假设:国家通用语言文字为广电基本播音用语(播音员普通话
  等级要求由此而来;方言节目与民族语言节目是成文例外)
