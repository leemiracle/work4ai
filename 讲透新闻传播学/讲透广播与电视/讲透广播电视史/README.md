# 讲透广播电视史 · 从 KDKA 到流媒体平台:线性流的百年编年

> **定位句:这支负责「广播电视从哪来」——世界线×中国线双轨编年,
> 以技术代际(电波→电缆→卫星→数字→平台)为主轴,兼记体制与节目形态
> 的断代;家族里唯一以「时间顺序」为学科方法本身的支。**
> 🆓 自定主干支(GB/T 86050 未列本体三级,按学界通行教学分类自定)。
> 家族:[讲透广播与电视](../README.md)

## 诞生

- **谁/何时**:1920-11-02 美国匹兹堡 KDKA 以固定节目表开播(第一家
  商业电台,大选之夜);1922 英国广播公司(1927 获皇家特许改组为 BBC);
  1936-11-02 BBC「高清」电视(405 行)开播;中国线:1940-12-30 延安新华
  广播电台(XNCR)开播(人民广播起点),1958-05-01 北京电视台试播
  (中国电视诞生,1978 改称中央电视台),1973 彩色电视试播(PAL),
  1983 首届春晚直播,1986 珠江经济广播电台「大板块+热线+直播」
  (珠江模式),1996 凤凰卫视开播,2006 地面数字电视国标 DTMB 发布,
  2008 北京奥运高清开播
- **因什么问题**:①技术代际如何切分断代(电波/电缆/卫星/数字/平台)
  ②中国广电史的特殊压缩(六十年走完别国百年:事业体制→集团化→
  台网融合)③每代「新媒介杀死旧媒介」的预言为何总是错(广播活过电视)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 断代框架:制式(1941/1953 NTSC·1966/1967 SECAM/PAL)、有线电视(1948 共用天线起)、卫星(1962 Telstar/1965 晨鸟)、数字化(1993 DVB 起各国 2000s 整转)的编年链基本定型 |
| ✅ 已解决 | 中国广电史的史料整理:从延安台到四级办电视、从模拟关停到媒体融合的通史脉络 |
| 🔄 进行中 | 数字整转与模拟关停的收尾史(各国 2008-2020s):「关停」本身作为史实如何书写 |
| 🔄 进行中 | 流媒体断代的归属:平台时代(2007 Netflix 流播起)是广电史的延续章还是终章——与家族 01 章「播→流转型」共用战线 |
| ❓ 未解决 | 「广播的百年」如何整体叙述:技术史、体制史、节目史三种写法的合流无共识范式 |

**最美事实(一句)**:1958 年北京电视台开播时,全国的电视机保有量
以几十台计——**「广播」可以先于它的观众存在**,然后等观众追上来:
媒介史的起点未必是需求,可以是意志。
