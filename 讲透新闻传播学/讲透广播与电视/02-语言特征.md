# 02 · 语言特征:广播电视说什么话

> **本章回答五问之三:表达力(能说什么)/逻辑性质(对错如何判定)/
> 规范化程度(公理化到哪一级)。** 三栏齐答——广播电视的母语由三种语汇织成:
> **节目语**(排播的世界:频道/栏目/时段/收视率/份额)、**声音语**
> (可听的世界:响度/音色/吐字/清晰度)、**信号语**(物理的世界:
> 制式/带宽/调制/码率)。三种语汇的主语不同:节目语的主语是「时段里的观众」,
> 声音语的主语是「耳朵」,信号语的主语是「信道」——混用主语是这门学科
> 大部分争吵的根源(「节目好」是节目语,「信号好」是信号语,
> 「收视高」两样都不证明)。

---

## 开场:一句台词看懂广电的母语

**📖 场景**:编播会。制片人拍桌:「这个节目做得这么好,凭什么放在深夜档?」
(节目语:内容质量与时段价值之争);播音指导说:「这段响度超标 3 个 LU,
重录」(声音语:播出链的技术合规);总工程师插话:「这档高清码率不够,
卫星转发器装不下」(信号语:物理容量)。三个人**没有吵架,他们在说
三种不同的语言**——而一条节目能否播出、何时播出、以什么质量到达,
取决于三种语言如何折中。广电的语言学,就是把这三种话的语法、
边界与翻译规则一次讲清。

## 一、表达力:这门语言能说什么、说不出什么

**基本词汇表**(母语核心名词,每个都答「为什么必须发明它」):

| 词汇 | 直觉图像 | 为什么必须发明它 |
|------|---------|----------------|
| 频道 | 一条永不间断的流 | 稀缺射频管道的单位化:「台」是机构,「频道」是流本身 |
| 节目表/排播 | 一周的时间格 | 机构对国民闲暇时间的立法——错过即失去的语法来源 |
| 黄金时段 | 晚间最贵的时刻 | 社会作息与节目表的乘积(本章主角) |
| 收视率/份额 | 看的人有多少 | 排播经济的通货:广告定价的计量单位 |
| 覆盖/到达 | 能收到/收过 | 发行的两把尺:物理可能 vs 实际发生 |
| 直播 | 正在发生 | 时间对齐的极致形态(00 章美之时刻 1) |
| 时移/点播 | 我想现在看 | 反抗节目表的两种语法(录放→流播) |
| 伴随收听 | 干活时开着 | 广播独有:不占眼睛的注意力(00 章反直觉 1) |
| 制式 | 信号的合同 | 千万台接收机与一个发射系统的兼容约定 |
| 响度 | 多响 | 声音语的核心量:可测、可规、可罚( LUFS) |

### 本节主角:「黄金时段」的可操作化

黄金时段是广电最日常也最被误用的词——它听起来在夸内容,实际在描述社会的钟。

**三步法——「黄金时段」的可操作化**:
1. 直觉:晚上八点打开电视,好节目多、广告贵、全家都在看——
   「黄金时段=好节目时段」
2. 严格:黄金时段的严格定义来自**观众可用性**(availability):
   可自由收看电视的人口比例的日内曲线,在晚间(中国通常 19:00-22:00,
   美国东西岸 20:00-23:00,英国另配 21:00「分水岭」成人内容线)
   达到峰值;排播者把最强节目放进峰值,是**追逐**时段,不是**创造**时段。
   收视研究的标准分解(Webster & Phalen 一系):收视 ≈ 可用性 × 偏好 × 排播
   ——黄金时段只由第一项决定,与内容质量正交
3. 最小例子:家族实验 `experiments/00_primetime.py`——只给观众一条
   可用性钟形曲线与几张节目单,**不给任何「质量」信息**,黄金时段
   照样在总收视曲线里涌现;再开「社交协调」项(大家都在看时看更值),
   峰值进一步磨尖——黄金时段是社交协调的产物(00 章反直觉 2 的机器版)

**可操作化的经济重述(与排播经济的互译)**:黄金时段是**时间对齐的
稀缺性定价**——同样一分钟广告,放在亿万人共同空闲的时刻与放在
周二上午,价格差一个数量级(央视黄金资源广告招标的「标王」竞价,
买的不是节目是时刻)。门户经济恰恰废掉这一层:点播没有时刻,
只有目录位置与算法可见性——**「黄金时段」是排播经济独有的资产,
流化即清算**(01 章战线 1)。

**说不出的话**(表达力边界——为什么是这样):

- **排播语说不出「我现在就要看」**:线性语法里观众的需求必须等到
  自己的时段;时移需求在语言内部没有合法句式——这正是录像机、
  点播、流媒体接连被发明的语言学原因:它们不是技术升级,
  是给这句话造句法
- **收视率说不出「陪伴」**:测量的是暴露(开机+在台),不是意义;
  伴随收听的广播在收视/收听调查里与专注收听同权——广播的真正产品
  「有人在场感」在这门语言的字典里没有词条
- **信号语说不出内容价值**:同一制式装得下杰作与垃圾;码率、带宽、
  制式合规全部达标,对「节目好不好」一言不发——信号层的「好」
  是传输保真,不是内容价值
- **声音语说不出画面**:广播把「没有画面」变成**想象力的带宽**
  (广播剧的怪物永远比电视里的可怕)——这是缺项的表达力,
  不是缺项的缺陷

## 二、逻辑性质:广电结论的「真值」如何判定

| 性质 | 广播电视里的对应 | 说明 |
|------|-----------------|------|
| 覆盖≠到达≠收看 | 物理可能≠开机≠看进去 | 发行三层的经典滑坡;「覆盖 13 亿」是信号语,「收看 3 亿」是测量语 |
| 收视率≠份额 | 占总体的比 vs 占开机观众的比 | rating=收看某节目人数/目标总体;share=某频道观众/当时开机观众;深夜档份额可以很高而收视率很低 |
| 直播≠零延迟 | 直播感是制度造物 | 电视直播常带数秒延时不哨(为切换与合规留窗口);「直播」判定的是排播结构(不预录、按时序播出),不是延迟为零 |
| 时移改变因果结构 | 排播单向→点播双向 | 线性时代「节目在先、收看在后」因果单向;点播让收看行为反向进入排播决策(数据回流)——同一句话换了逻辑方向 |
| 响度可测,「好听」不可测 | LUFS 合规≠音质审美 | 声音语的可判定层止于测量(响度/峰值/动态);审美层开放——测量管得住「不超标」,管不住「动人」 |
| 排播即配给 | 时段分配是零和 | 黄金时段只有三小时,给了 A 就给不了 B——排播表是具有分配效力的语言行为(像「判决」一样改变世界) |

**为什么是这样**:广电的真值分三层——信号层(可测,近乎数学)、
节目层(可测暴露,不可测意义)、排播层(制度事实,由规则与合同判定)。
三层各自有完备的判定程序,但**没有一层到另一层的推理通道**
(信号全绿推不出内容好,收视高推不出价值高)——这与数学家族
「定义→定理」的单向透明完全相反,是工程制度语言的典型形状。

**⑥ 反直觉:「调频音质好所以取代调幅」只对了一半**。
FM 频带宽、抗噪强、立体声,音质全面胜 AM——但 FM 的胜利还有两块
被忽略的语法:①**频谱经济**:调频波段(约 87.5-108 MHz)传播距离短、
靠视距中继,一个频率可在全国复用——频道数变多,格式随之细分
(音乐台/交通台),广播从「大众同听」转向格式化窄播;②**场景锁定**:
车载接收把通勤时段铸成 FM 的护城河。同理,AM 没有死:大功率中波的
远距离覆盖(农村、跨区域应急广播)至今无可替代——**媒介更替从不按
参数表优胜劣汰,按场景语法重新分工**(00 章反直觉 1 的频谱版)。

## 三、规范化程度:公理化到哪一级——三层三档

广电是本宇宙中**信号层真正公理化**的罕见家族:

### 第一档:信号层(真·公理系统)

- 数字电视与音频的标准体系:ITU-R 建议书族(视频 BT.601/BT.709 取样、
  音频响度 BS.1770)、传输标准(DVB/ATSC/ISDB/DTMB 国标 GB 20600-2006)、
  响度规约(EBU R128:-23 LUFS 目标)
- 特征:**定义精确到比特、全球可互操作、违反即不可解码**——
  与数学公理系统同构:任意两台合规接收机对同一码流解码结果一致
- 这是「制式」一词的分量:一份千台厂商、亿台设备共同签署的形式合同
  (00 章反直觉 3:兼容存量是这份合同最贵的条款)

### 第二档:业务层(行会化规范)

- 编播规程(播出安全、广告时长上限、未成年人保护时段——英国 21:00
  分水岭是成文制度)、播音规范(国家级台播音员普通话一级甲等的
  岗位要求)、主持人的语言伦理(名诃读音、方言与普通话的关系)
- 特征:**成文、可考核、可问责,但修订靠行会与监管的互动**——
  类似职业规范而非公理;同一行为在不同法域判罚不同

### 第三档:评价层(前范式)

- 「什么算好节目」至今无共识判据:收视率是通货不是价值(高收视
  推不出好,「叫好不叫座/叫座不叫好」是这层撕裂的标准症状);
  公共广播的「公共价值」测度(每块钱执照费换回什么)争论至今
- 特征:**多判据并存、无可裁决程序**——与新闻理论「总体平衡无公理」
  同构(那边是「什么值得报」,这边是「什么值得排」)

**📖 故事框**:英国 1936 年开播的 405 行「高清」,今天连标清都算不上;
但 BBC 1946 年确立的电视执照费至今仍在收。**信号层的合同五十年一换,
制度层的合同能撑一百年**——越靠近物理的语言越硬,也越短命;
越靠近价值的语言越软,也越耐用。读广电史,先分清你在读哪一层。

## 四、三大句型的语言解剖(广电的三种话)

| 句型 | 语法 | 例 | 陷阱 |
|------|------|----|------|
| **节目句** | 时段+节目+观众 | 「周五 20:00 综艺档收视 2.1、份额 8%」 | 收视率与份额混用;把排播事实说成内容价值 |
| **声音句** | 声学量+规范值 | 「响度 −23 LUFS±1,真峰值 ≤ −2 dBTP」 | 把合规当审美;把响度当音量旋钮 |
| **信号句** | 制式+参数+合规 | 「8MHz 带宽、64QAM、装 4 路标清」 | 参数达标推内容达标;容量约束当质量上限 |

| 对面 | 互译字典 |

| 数学·调和分析(../../讲透数学/,文字提及) | 调制↔频谱搬移;滤波↔乘法窗;「一切信号=正弦叠加」是音频链每一步的母语 |

## 六、一张话术对照表(错句 → 语法修正)

广电的高频事故多不是**说错数**,而是**说错层**——下表是高频错句与语法诊断:

| 错句 | 语法诊断 | 修正句式 |
|------|---------|---------|
| 「黄金时段节目最好」 | 把作息产物说成内容属性 | 「黄金时段可用观众最多;排播者把强节目放进峰值」 |
| 「收视率 8% 超过对手」 | rating 与 share 混用 | 「收视 8%(占总体)/开机观众中份额 15%——两个分母」 |
| 「电视已死」 | 把线性退潮说成媒介死亡 | 「线性排播退潮,视听消费迁移到门户与短形态——屏幕更多,频道更少」 |
| 「直播就是零延迟」 | 把排播结构当延迟参数 | 「直播=按时序不预录播出;延迟窗口常为数秒,是制度选择」 |
| 「流媒体就是网络电视台」 | 把门户当排播经济 | 「门户按需分发、个人账户、算法可见性——定价与测度全部换轨」 |
| 「调频音质好所以全面替代调幅」 | 参数决定论(§二反直觉) | 「FM 赢在频谱经济+车载场景;AM 的远距覆盖仍是刚需」 |
| 「响度达标=声音好听」 | 把合规当审美 | 「响度合规(−23 LUFS)管动态公平;『好听』在测量之外」 |
| 「覆盖全国=全国能看」 | 覆盖/到达/收看三层滑坡 | 「信号覆盖≠开机到达≠看进去——三层各有测量」 |

**这张表的用法**:每个错句对应本章一节——黄金时段(§一)、收视与份额
(§二)、媒介更替(§二反直觉)、直播与时移(§二)、三层语言
(§一/§三)。说对广电的语言,一半功课在这张表里。

## 📌 收束 + 🧭 这章给了你什么新眼睛(认知升维)

**这章给了你什么新眼睛**:

- **分层眼**:听到任何广电判断先辨层——信号层(可测)、节目层(可测暴露)、
  排播层(制度事实);跨层推理(「参数好所以内容好」)是第一类错误
- **分母眼**:见到收视数字先问分母——总体还是开机观众?
  覆盖、到达、收看是三个不同的滑坡台阶
- **合同眼**:见到「制式」就想到它是一份亿万设备签署的形式合同——
  升级的第一约束是存量兼容,不是参数表。

✨ **美之时刻 3:公共广播的非市场定价实验**(制度)——
BBC 从 1923 年起向每台收音机(后为电视机)收执照费:它**不向用户出售
任何内容**,向公民征收的是「没有人可以被排除在公共领域之外」这件事的
费用——一场持续百年、被反复攻击却仍在运行的非市场定价实验。
为什么美:它给「公共时间值多少钱」造了一个真实的价格发现机制——
不靠广告(注意力市场)、不靠订阅(意愿付费市场),靠政治程序给
「全体同时可及」定价;广电史上最大胆的制度设计,与香农的信道数学
同属这个家族最硬的两种语言。亲历:做一个思想实验——用维克里拍卖
问自己「若公共广播按真实意愿定价,你出多少?」,再对比执照费的实际
数字——两者的差就是「公共性」在你身上的定价残差。
