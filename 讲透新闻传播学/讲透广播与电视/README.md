# 讲透广播与电视 · 把时间变成公共体验的媒介——线性流的工程学与政治学

> **本质一句话**:广播电视=**把时间变成公共体验的媒介**——用一条对全体同时播出的
> 线性流,把亿万人对齐到同一秒;它的全部理论、业务与产业,都是这台
> 「时间对齐机器」的工程学(信号与排播)与政治学(频谱与公共性)。
>
> GB/T 13745-2009:860 新闻学与传播学 · 二级学科 **86050 广播与电视**
> (GB/T 三级系声学条目继承——编纂归属,双轨处理,见 §〇 说明框;
> 本体四支为自定主干支)。
>
> **定位张力声明**(先读这个再读本家族):广电家族管「**流**」——线性播出的时间
> 结构、生产这条流的手艺、以及这条流被平台拆散之后的重组。**新闻侧的规范住
> 新闻理论家族,效果机制住传播学家族**(同波兄弟,文字提及),**声学的物理本体
> 住物理宇宙·讲透声学**。本家族详答四件事:百年编年(史)、时间对齐的结构
> (理论)、采编播与播音主持(业务)、播→流转型(视听新媒体);
> 声学技术按底座支归入声明挂靠,不重复建设。

> 同波兄弟家族(新闻理论 86010/新闻史 86020/新闻业务 86030/
> 新闻事业经营管理 86040/传播学 86060)见 [../README.md](../README.md) 全景表,
> 此处仅文字提及不互链。

> **⚠️ GB/T 特殊归类说明框(必读)**

> (共 16 条):普通线性声学;非线性声学;流体动力声学;超声学量子声学和声学效应;
> 次声学;水声和海洋声学;结构声学和振动;噪声;建筑声学与电声学;声学信号处理;
> 生理心理声学和生物声学;语言声学和语音信号处理;音乐声学;声学换能器声学测量;
> 声学材料;信息科学中的声学问题——**系编纂归属(标准原文如此)**,
> 并非广播电视的本体分类。本家族按**双轨**处理:
> ①**本体轨**:广播电视史/广播电视理论/广播电视业务(含播音与主持艺术)/

> 声的物理基础(普通线性/非线性/流体动力)|极端频段(超声与量子·次声)|

> 换能与测量/声学材料)|声学信号处理(含信息科学中的声学问题)|
> 听感与节目(生理心理与生物声学/音乐声学)|播音的语音底座(语言声学与语音
> 信号处理)——**不在本家族建目录**,归入声明挂靠
