# 传播学思维技能卡(讲透传播学 · GB/T 86060)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **效果类**:传播效果、媒介效果、说服、态度改变、知晓度、议程、涵化、知沟、极化、回音室、过滤泡、信息茧房
- **扩散类**:病毒式传播、走红、爆款、口碑、增长曲线、K 因子、临界质量、冷启动、采用率、S 曲线、网络效应
- **过程类**:把关、意见领袖、两级传播、弱关系、编码/解码、噪声、反馈、使用与满足
- **语境类**:跨文化、高低语境、文化维度、国际传播、世界信息秩序、组织沟通、人际沟通
- **算法类**:推荐算法的社会效应、个性化分发、平台治理、信息流规制、算法审计、成瘾设计

## ② 核心思维模式(这个分支怎么想问题)

1. **四元组化**:一切效果断言拆成对象/层级(认知→态度→行为)/指标/时窗
   ——缺件的效果句是修辞,不是知识
2. **条件化**:效果永远带"在什么条件下"(调节)与"经由什么路径"(中介)
   ——魔弹论的破产就是无条件效果句的破产
3. **双传染分诊**:先问传的是**知晓**(简单传染:一次接触即染,hub 管用)
   还是**采纳**(复杂传染:需多重背书,簇宽管用)——"病毒式"是隐喻,双传染是语法
4. **供血分解**:增长=外部点火 p(媒介/广告)+内部口碑 q(人际/邀请)
   ——归因先于加码;带 p 的扩散无阈值,行为采纳(阈值传染)才有临界线 θ
5. **气候≠民意**:一切可测的是**表达气候**;沉默者分布未知,
   多数感知会自增强(螺旋)——输出"面板",不输出"民意结论"
6. **设计优先**:效果的可信度=研究设计的可信度(面板/实验/自然实验/断点)
   ——设计与结论同权重,不是附件

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 香农模式(信源-编码-信道-噪声-解码-受者) | 画任何传播过程的第一笔;找噪声与把关的位置 |
| 5W(谁/说什么/何渠道/对谁/何效果) | 快速拆解传播现象的五部门体检表 |
| Bass 模型 dF/dt=(p+qF)(1−F) | 增长归因与预测;峰值时点 t\*=ln(q/p)/(p+q);峰值渗透率 F\*=(q−p)/2q |
| 临界大多数/logistic 阈值 | 网络效应产品的自持线判断;冷启动成败的动力学 |
| SIR(β/γ,R₀) | 会"过气/痊愈"的潮流扩散;终规模墙 1−r=e^(−R₀r);降权=升 γ |
| 复杂传染阈值模型 | 行为采纳类扩散;种子放密集簇不放散点;解释"大 V 知晓高转化低" |
| 议程设置(显著性→想什么) | 传播的省力效果路线:动认知不动态度 |
| 沉默的螺旋(感知→表达) | 解释"表达分布的自我强化";一切舆情读数的说明书 |

| A/B 纪律(预注册+护栏+簇随机) | 任何传播干预的评估;SUTVA 违反的社交场景必按簇随机 |
| 使用与满足 | 受众带着需求来——产品侧的"用户任务"理论前身 |
| 文化维度/高低语境 | 跨文化讯息的本地化;同一句话的默认信息量因地而异 |

## ④ 常见误区与禁忌

- **说无条件效果句**:"算法让人变蠢/广告有效/直播带货好"——先补四元组
- **把"传遍全网"当饱和**:到达≠采信≠行动;曝光常集中于少数簇
- **病毒式隐喻一把梭**:信息与行为的传染机制相反,干预手段相反
- **把舆情读数当民意**:沉默者未测;多数感知本身压低异见表达
- **把相关性当效果**:选择性暴露让观察数据的效果句永远沾染反向因果
- **单指标上 KPI**:时长/点击做唯一目标的尽头是成瘾与社会负外部性
  (Goodhart);护栏指标必须与主指标同时上桌
- **只管算法不管社交结构**:回音室的主力织工常是自选择,拆算法不拆圈子拆不掉茧房
