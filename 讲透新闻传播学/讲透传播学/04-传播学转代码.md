## 一、可机械化边界:什么能算、什么算不了

**能机械化的**(有原理保证或明确程序对应的"算"):

| 传播学动作 | 机械化形态 | 保证来自 |
|-------------|-----------|---------|
| 扩散预测 | Bass 模型拟合与外推(t\*/F\*/峰值) | 解析解+跨行业经验参数带(p≈0.03,q≈0.3-0.5) |
| 扩散模拟 | ABM/网络 SI/SIR/阈值模型 | 03 章层 2 的构造传统 |
| 网络测量 | 中心性/社区/桥的批量计算 | 图论([../../讲透数学/讲透图/](../../讲透数学/讲透图/) 直供) |
| 内容量化 | 词频/词证/话题聚类/情感分类 | 内容分析的统计传统(兄弟家族走廊 1 共用) |
| 效果评估 | A/B 实验、断点、双重差分、面板 | 03 章层 1 的设计公理 |
| 曝光审计 | 对照账号/数据捐赠日志的差分比较 | 平台审计方法(01 章战线 5) |
| 意见气候 | 表达分布+多数感知代理 | 沉默的螺旋的操作化(表达气候层) |

**机械化不了的边界**(为什么——原理级回答):
1. **真实民意不可直接算**:一切可计算的都是**表达气候**(发声、点赞、
   转发),沉默者的态度是结构性的盲区(03 章层 3 构造极限)——
   "舆情系统读出民意"在语法上夸大其辞,它读出的是**愿意表达者的分布**
2. **效果的历史反事实不可算**:印刷术/电视/推荐流的社会长效应没有
   对照组——只能多源证据三角定位,不能"跑一遍没有 Facebook 的 2016"
3. **语义效果不可完全算**:同一曝光量,意义不同则效果天壤之别——
   香农剥离意义的债在效果层兑现(02 章);点击是行为层代理,
   不是语义层的度量
4. **平台黑箱内的分配不可外算**:推荐函数的真实权重只有平台可见;
   外部研究永远是代理测量(01 章战线 5)——**测量权的不对称是制度问题,
   不是算力问题**

## 二、代码走廊清单(从零到一的三条走廊)

**走廊 1:传播模拟(机制→动力学)**

家族实验 [`experiments/00_diffusion.py`](experiments/00_diffusion.py):
Bass 扩散 + SIR 对照——p/q 扫描,S 曲线形态、峰值时点 t\*=ln(q/p)/(p+q)、
峰值渗透率 F\*=(q−p)/2q、无阈值性(p>0 零火种仍起飞)全部 assert 自验证;
SIR 路给出终规模<100%、峰值后移的对照断言。骨架:
```python
def bass_step(f, p, q, dt):          # dF/dt = (p + qF)(1-F)
    return f + (p + q * f) * (1 - f) * dt

def sir_step(s, i, r, beta, gamma, dt):   # 纯接触传染 + 康复
    new_i = beta * s * i * dt
    new_r = gamma * i * dt
    return s - new_i, i + new_i - new_r, r + new_r
```
扩展方向:把 i 的"康复"读作"内容过气/平台降权"(01 章练习 3);
把 p 读作广告投放、q 读作邀请机制的乘数——**每读一次参数表,
就是一次机制归因**。

**走廊 2:网络扩散(结构→速度)**

在图上跑两种传染,看结构×类型的匹配刚性(03 章钢筋 3)。纯标准库
最小版(邻接表+队列即可):
```python
def simple_contagion(graph, seeds):        # 知晓:一次接触即染(SI)
    infected, frontier = set(seeds), list(seeds)
    while frontier:
        v = frontier.pop()
        for u in graph[v]:
            if u not in infected:
                infected.add(u); frontier.append(u)
    return infected

def complex_contagion(graph, seeds, threshold=3):  # 采纳:需 k 个邻居背书
    adopters, changed = set(seeds), True
    while changed:
        changed = False
        for u in set(graph) - adopters:
            if sum(1 for v in graph[u] if v in adopters) >= threshold:
                adopters.add(u); changed = True
    return adopters
```
对照实验:同一图,数一数 hub(高度节点)对两路扩散的增益——
简单传染吃 hub,复杂传染吃簇宽;再随机重连 10% 的边(制造长程桥),
看复杂传染**萎缩**(03 章反直觉的机器版)。意见领袖=中心性计算
(`degree`/`betweenness` 各一行,生产级用 networkx)。

**走廊 3:A/B 测文化传播(效果→证据)**

在线实验的最小骨架与纪律:
```python
import random
def ab_split(users, seed=20260907):
    rng = random.Random(seed)
    return {u: ("treat" if rng.random() < 0.5 else "control") for u in users}

# 两样本检验(纯标准库):正态近似 z 检验,先报效应量再报 p 值
def two_proportion_z(xt, nt, xc, nc):
    pt, pc = xt / nt, xc / nc
    pbar = (xt + xc) / (nt + nc)
    se = (pbar * (1 - pbar) * (1 / nt + 1 / nc)) ** 0.5
    return (pt - pc) / se                       # |z|>1.96 → p<0.05 近似
```
**传播学特有的三条实验纪律**(02 章学科规范的工程版):
① **SUTVA 违反**:实验对象在社交网络里互相传染——对照组会被处理组
   "溢出"(处理组转发的内容对照组也看得到),直接污染因果差;
   补救:按**社交簇整体随机**(cluster randomization),或对溢出建模
② **多重比较**:一次实验测几十个指标,5% 假阳率会"发现"一堆假效果——
   预注册主指标,其余算探索性
③ ** Goodhart**:主指标上 KPI(点击/时长)必被优化——社交产品的
   北极星指标是时长,社会效应(多样性/福祉)从来不在其中,这正是
   01 章战线 1/4 的病根,护栏指标必须与主指标同时上桌

**走廊间自检断言清单**(exit-0 纪律):
```python
assert 0 <= f <= 1 and monotone(cumulative)     # 扩散语法:单增有界
assert abs(t_peak_measured - math.log(q/p)/(p+q)) < 0.5   # 峰值刚性(走廊 1)
assert final_sir < 0.97                          # 康复墙:终规模<100%(走廊 1 对照)
assert len(complex) <= len(simple)               # 复杂传染永远不快过简单传染(走廊 2)
assert abs(pt - pc) < 0.5                        # A/B 量纲与方向检查(走廊 3)
```
断言失败的位置=机制假设被凿的位置——与数学家族"断言看守定理"同构。

**最小工具栈**:

| 层 | 首选 | 一句话理由 |
|----|------|-----------|
| 教具级 | 纯标准库(math/random/statistics/collections) | 家族做法:透明第一,能 assert 自验证 |
| 图分析 | networkx(中心性/社区/生成模型) | 走廊 2 生产级;BA/WS 生成器一行 |
| 实验统计 | scipy.stats + statsmodels(功效/回归/DID) | 走廊 3 生产级;面板与断点在此 |
| 大规模模拟 | mesa(ABM 框架)/ndlib(网络扩散库) | 层 2 全尺寸版 |

## 三、工程师落点(性能工程视角)

| 落点 | 传播学原理 | 工程现场 |
|------|-------------|---------|
| **增长工程** | Bass p/q+临界大多数(03 章钢筋 2) | 增长曲线拟合定节奏;K 因子=q 的工程转写(每用户经口碑带来的新用户数,K>1≈过自持线);冷启动买的是"过线"不是用户数;投放(p)提峰值时点,不提终规模天花板 |
| **内容推荐的社会效应** | 多样性/偶然暴露(01 章战线 3)、弱关系的信息功能(00 章反直觉 2) | 推荐目标=时长是单目标优化;社会效应侧的护栏指标:曝光异见率、跨域内容占比、弱关系触达保留——**多样性约束不是道德装饰,是信息生态的结构维护**;Goodhart:时长 KPI 优化的尽头是 01 章战线 1 的三大负外部性 |
| 病毒式产品机制 | 复杂传染需簇宽(03 章钢筋 3) | 邀请机制的 K 因子是简单传染语法,采纳是复杂传染——冷启动种子放**密集簇**不放散点;大 V 投放涨知晓不涨转化,转化要本地冗余 |
| 平台治理与审计 | 规制=现场实验(01 章战线 2/4) | 降权/限流干预按 A/B 纪律评估:预注册主指标+护栏指标;审计系统=对照账号差分(走廊 3 变体);**干预的代价先于干预的善意**(权衡结构) |
| 舆情系统 | 表达气候≠民意(03 章层 3) | 一切"舆情读数"的说明书第一行:测的是表达分布;沉默者分布未知,多数感知会自增强——输出"气候面板",不输出"民意结论" |

**性能工程特别提示**:走廊 2 的传染模拟是批量位运算友好的
(感染状态=bitmask,前沿=队列,整图一步一世代);大图中心性用近似算法
(近似 betweenness)先行;A/B 平台的关键路径是**分流的均匀性与
日志的对齐**——分流有偏=一切下游统计作废,先审计随机性再谈显著性。

## 四、一个完整案例:从问题到代码的全链路

**问题**:一款协作工具上市 6 个月,增长平缓,市场部主张加大广告投放,
增长团队主张做邀请奖励。谁对?

1. **翻译成传播学问题**:扩散的供血项哪个不足——外部影响 p(广告)
   还是内部影响 q(口碑)?有没有过临界大多数?
2. **拟合**(走廊 1):用累计采用序列拟 Bass,得 p̂=0.011(偏低,
   经验带 0.03)、q̂=0.42(正常)——诊断:**外部点火不足,内部口碑健康**
3. **推演**:参数扫描显示,广告加倍(p→0.022)主要把峰值时点提前约 30%,
   终规模不动;且当前 F 已过自持线——加大 q 的边际收益递减
4. **干预设计**(走廊 2+落点 1):邀请奖励提升 q 的**有效接触率**
   (给邀请加结构化触点);同时投放保 p——但按复杂传染纪律,
   奖励种子投放选**密集簇**(同公司/同社区)不撒散点
5. **度量**(走廊 3):邀请机制按簇随机 A/B,主指标=28 日留存采纳率
   (行为层),护栏指标=邀请打扰投诉率;预注册,禁多重比较
6. **复盘**:每季度重拟 p/q——扩散参数是**活的市场诊断**,不是一次性拟合

一条链走完家族三层:机制归因(03 章层 2)、结构干预(钢筋 3)、
效果证据(层 1)——这就是"传播学的语法,工程的句子"。

## 五、为什么不直接"全部交给 LLM"

常见混淆:LLM 能读能写能聊,模拟与调研直接端到端——三条原理级反驳:
① **LLM 是被试的失真复制品**:"硅样本"(用 LLM 模拟受访者)方向有希望,
   但其分布偏差(训练数据的人群偏斜、顺从偏差)未经校准前,
   效应量不可信——用它做**预实验的预演**可以,做**证据**不行;
② **效果证据必须来自真实暴露**:传播效果的定义里含"真实的人被真实地
   暴露"(02 章四元组的对象与时窗)——LLM 实验里没有暴露,只有生成;
③ **模拟的价值在机制不在叙事**:走廊 1 的价值是参数扫描的**刚性**
   (t\* 只依赖 q/p),LLM 讲得再好也只是叙事——**模拟管机制,实验管证据,
   LLM 管草稿**,三者不可互相顶替。
