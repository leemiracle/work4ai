# 讲透国际传播 · 国界之间的信息流:世界信息秩序与传播权力

> **定位句:这支负责"传播的国界"——信息如何跨国流动、流量结构
  谁说了算、国际舆论战场怎么打;传播权力的政治经济学现场。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「国际传播」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:短波国际广播(1920s-40s)与冷战宣传研究开出主题;
  **席勒《大众传播与美帝国》(1969)**立"文化帝国主义"批判传统:
  跨国信息流是单向的(中心→边缘),单向流重塑依附结构;
  **世界信息与传播秩序(NWICO)论战**(1970s-80s,教科文组织
  麦克布莱德委员会 1980《多种声音,一个世界》):发展中国家
  首次把"信息流结构"当成国际秩序问题提出;互联网时代议题转为
  平台霸权、数据主权与"数字鸿沟"
- **因什么问题**:①国际信息流量的结构与偏向(谁的新闻、谁的议程)
  ②传播权力与经济依附的关系③国家在信息秩序中的能力与正当性

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 国际新闻流的单向度确证:国际新闻供给高度集中于少数通讯社(经典流量统计稳定复现) |
| ✅ 已解决 | 议程的国际级联:大国媒体议程向邻国/小国媒体的瀑布式下渗(级联模型) |
| 🔄 进行中 | 平台时代的传播权力:从"通讯社集中"到"平台基础设施集中"的结构更替(方向锚) |
| ❓ 未解决 | 国家传播能力的有效性:国际传播投入与国家形象改善之间的因果链证据薄弱 |

**最美事实(一句)**:麦克布莱德委员会 1980 那份报告的标题——
**《多种声音,一个世界》**——把一个流量统计问题升维成文明秩序命题:
信息流结构不是技术问题,是"谁的声音被听见"的正义问题。

## 假设与依赖

- 流量结构假设:国际信息流有稳定的中心-边缘结构,结构自带偏向
- 依附假设:传播结构与经济结构同构(批判传统的地基,亦是最大争议点)
- 硬依赖:家族 00 章(把关的国际嵌套:层层把关的国际版);
  政治学本体(GB/T 810,宇宙外,归入声明)
