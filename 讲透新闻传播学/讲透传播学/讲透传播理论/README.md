# 讲透传播理论 · 效果动物园与理论谱系:议程/涵化/知沟/编码解码

> **定位句:这支负责"传播改变人的什么、怎么改变"——效果研究的主战场,
  家族三根支柱中效果论的旗舰;一切效果理论的证据语法以此为总纲。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「传播理论」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:两级传播(拉扎斯菲尔德 1944《人民的选择》)与说服研究
  (霍夫兰耶鲁学派 1950s)开出效果研究;1970s 强效果回归三连——
  **议程设置**(McCombs & Shaw 1972 教堂山研究)、**涵化理论**
  (格伯纳 1969 起:重度电视观众的"卑鄙世界综合症")、**知识沟**
  (蒂奇诺等 1970:信息流入越多,社会经济层间的知识差距可能越大);
  **编码/解码**(霍尔 1973)从文化研究侧杀入:讯息的三种读法
  (主导-协商-对抗);**使用与满足**(卡茨等 1973)倒转视角:
  受众带着需求来"用"媒介
- **因什么问题**:①媒介到底改变人的什么(认知/态度/行为哪一层)
  ②效果在什么条件下发生(中介/调节)③受众是靶子还是猎手
  (被动接受 vs 主动使用)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 议程设置经典验证(1972 教堂山相关约 0.97,数千后续研究跨国复现);属性议程设置(第二层)拓展 |
| ✅ 已解决 | 知识沟假设的经典验证(教育/社会经济地位的调节作用稳定复现);涵化的剂量-效应验证(重度观众更怕世界) |
| ✅ 已解决 | 使用与满足的谱系确立:受众动机(信息/认同/消遣/社交)先于效果 |
| 🔄 进行中 | 算法媒介下的效果条件迁移:同质化主力是自选择还是推荐(家族 01 章战线 3 的证据分叉) |
| ❓ 未解决 | 语义效果的量化(同一曝光量,意义不同则效果天壤之别——香农剥离意义留下的债,家族 02 章) |

**最美事实(一句)**:议程设置给媒介权力画出了最省力的路线——
**不求改变你怎么想,只锁定你想什么**(Cohen 1963 警句 → 1972 实证):
效果的省力顺序(认知→态度→行为)恰是直觉的倒序(家族 00 章反直觉 3)。

## 假设与依赖

- 效果层级假设:认知→态度→行为有惰性梯度(一切效果句的骨架)
- 可检验性代价:能操作化的效果(即时/可测)被高估,慢/弥散效果被低估
  (家族 00 章钟摆解毒剂)
- 硬依赖:家族 02 章(效果句四元组语法)、04 章走廊 3(A/B 纪律);
  意见气候类效果与兄弟家族舆论学支共用概念(规范面在彼,机制面在此)

## 教材锚

- 麦奎尔《大众传播理论》(McQuail's Mass Communication Theory,多版)
  ——效果动物园的标准图谱,家族教材锚之一
- Katz, Blumler & Gurevitch 1973(使用与满足)、Hall 1973(编码/解码)
  ——谱系原始文献双锚
