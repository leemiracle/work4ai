# 讲透传播技术 · 媒介技术与社会互构:从印刷术到推荐系统

> **定位句:这支负责"技术这条腿"——每一代传播技术(印刷/电报/广播/
> 互联网/推荐算法)如何被社会塑造,又如何反向重写社会的知识、权力
> 与日常;技术决定论与社会建构论的永恒谈判场。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「传播技术」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:印刷术研究(爱森斯坦 1979)与电报研究(凯里《作为文化的传播》
  1989:电报把"运输"与"通信"分家)开出技术-社会互构题;**可供性
  (affordance)视角**2010s 进入传播研究(Gibson 生态心理学借词):
  技术提供行动的可能空间,但可能性不等于决定;推荐系统时代,
  "排序函数"成为第一个**不可见的把关技术**(算法即媒介基础设施)
- **因什么问题**:①技术是原因还是结果(决定论 vs 建构论——SCOT
  社会建构技术论的反题)②新技术扩散自身的规律(创新扩散的元应用:
  传播技术自己就是最经典的扩散对象,家族实验的主角)③技术特征
  (带宽/异步性/可复制性/可排序性)如何对应传播形态

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 技术特征→传播形态的映射确证:带宽与同步性决定媒介形态(广播=高带宽单向,短信=低带宽异步) |
| ✅ 已解决 | 可供性的操作化:平台特征可编码为行动可能性的维度集 |
| 🔄 进行中 | 推荐排序作为"把关技术"的可见性治理:黑箱基础设施如何问责(家族 01 章战线 2) |
| ❓ 未解决 | 技术决定论与社会建构论的裁决:算法媒介的"技术必然性"边界在哪——AI 生成内容的把关换岗正在现场检验 |

**最美事实(一句)**:电报史给出的第一个"技术-社会"标本——
电报不仅加速消息,还**发明了"客观性"的语法**(倒金字塔:按重要性
递减排列,因为线路随时断,断在哪哪结尾)——技术约束沉淀为
职业规范,规范再沉淀为认知风格(兄弟家族 03 章的刚性同款)。

## 假设与依赖

- 互构假设:技术与社会互相塑造,单因论(纯技术决定/纯社会建构)都是语法错误
- 可供性假设:技术的意义=使用中开显的行动空间,不在技术物内部
- 硬依赖:家族 00 章(香农信道=一切传播技术的数学骨架,
  [../../../讲透数学/讲透信息论/](../../../讲透数学/讲透信息论/) 直供);
  技术自身的扩散规律(家族实验 00_diffusion.py 的元对象)
