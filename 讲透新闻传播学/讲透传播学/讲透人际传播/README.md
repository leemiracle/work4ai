# 讲透人际传播 · 两人之间的信息与关系:不确定性、表露与演进

> **定位句:这支负责"传播的最小单元"——两个人之间,信息如何被交换、
  关系如何被信息一点点造出来;一切大尺度传播理论的微观地基。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「人际传播」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:格夫曼《日常生活中的自我呈现》(1956/1959)以戏剧隐喻立
  互动研究(前台/后台/印象管理);**不确定性削减理论**
  (Berger & Calabrese 1975):初遇的核心动机是降低对对方的不确定性,
  信息寻求随关系推进从低风险到高风险;**社会渗透理论**
  (Altman & Taylor 1973):关系深化=自我表露的**广度×深度**双维展开
  (洋葱模型);关系维持与 dissolution 的阶段模型(1980s)随后补全
- **因什么问题**:①陌生人如何变成熟人(不确定性的削减路径)
  ②"亲近"在信息上是什么(表露的对等与渐进)③关系如何在对话中
  被维持、修复与拆解

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 表露对等律的经典验证:表露深度大致互惠,失衡即关系信号 |
| ✅ 已解决 | 初遇的信息交换顺序:人口学→态度→价值观的渐进入口(低风险先行) |
| 🔄 进行中 | 媒介化的人际传播:文字/语音/表情包的不确定性削减效率比较(线索消除与超个人模型之争) |
| ❓ 未解决 | "关系质量"的测量学根基:自报量表的循环性(用关系语言测关系)未破 |

**最美事实(一句)**:不确定性削减理论把"初次见面的尴尬"翻译成
信息问题——**尴尬=对对方行为预测的高熵**;聊天=互相压低对方分布的
熵。香农的熵(家族 00 章美之时刻 1)在这里从电话线走进饭桌。

## 假设与依赖

- 关系即传播假设:关系不存在于传播之外——关系是传播的累积产物
  (皮尔斯:传播创生关系)
- 表露风险假设:信息交换有梯度,违反梯度(过早过深)触发防御
- 硬依赖:家族 00 章(编码/解码与噪声的微观现场);自我呈现的社会学本体
  住社会学宇宙([../../../讲透社会学/README.md](../../../讲透社会学/README.md),
  相应家族建设中文字提及)

## 教材锚

- 格夫曼《日常生活中的自我呈现》(The Presentation of Self in Everyday Life, 1959)
  ——互动研究的奠基书(社会学-传播学双归属)
- Berger & Calabrese 1975(不确定性削减)、Altman & Taylor 1973(社会渗透)
  ——双理论原始文献锚
