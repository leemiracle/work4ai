# 讲透新媒介传播 · 算法媒介的传播:个性化分发、可供性与数据化

> **定位句:这支负责"被算法重写的传播"——当把关人换成排序函数、
  受众画像由数据实时铸造,传播的每个环节都被平台重新实现;
  家族 01 章核心议程(算法媒介效果)的专论现场。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「新媒介传播」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:互联网研究 1990s 起步;2010s 平台化转向——
  **范·迪克等《平台社会》(2018)**立总纲:平台按**数据化
  (datafication)、商品化(commodification)、选择性(selection)**
  三机制重造传播生态;个性化推荐成为主导分发机制,
  "把关人"让位于"算法架构";隐私、成瘾、茧房、平台治理
  随之成为核心议题
- **因什么问题**:①算法分发如何重排能见度(谁被看见由什么决定)
  ②数据化的传播(点赞/停留/转发成为传播的"读数")如何反塑传播行为
  ③平台的基础设施权力如何问责(治理与规制)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 个性化分发的机制解析:排序目标函数→能见度分配的映射(平台文档与审计双源) |
| ✅ 已解决 | 数据化反馈环的确证:平台指标(点赞/流量)成为内容生产的隐式目标函数(流量逻辑) |
| 🔄 进行中 | 算法媒介效果的净效应:成瘾/睡眠/社会比较(社会驱动×算法机制合流,家族 01 章战线 1)——因果识别进行中 |
| ❓ 未解决 | 过滤泡/回音室的净效应:证据分叉未合拢(自选择 vs 排序的贡献分解,家族 01 章战线 3)——测量权不对称是硬约束 |

**最美事实(一句)**:把关人理论的转世——卢因 1947 的"门边之人"
在算法时代变成**没有人的门**:同一道门为每个人开合不同的角度,
而门的开合逻辑(目标函数)从不在选票上出现。

## 假设与依赖

- 平台架构假设:能见度由架构(排序/推荐/界面)分配,架构即权力,
  且架构天然偏向平台目标(时长/参与)
- 数据化假设:传播行为的持续数据化改变传播本身(测量改变被测者)
- 硬依赖:家族 01 章(检索校准四战线);家族 04 章落点 2
  (推荐的社会效应与护栏指标);兄弟家族的把关与审核线(文字提及合璧)
