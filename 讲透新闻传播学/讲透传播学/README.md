# 讲透传播学 · 信息在人间的社会学——效果、扩散与媒介之变

> **本质一句话**:传播学=**信息在人间的社会学**——它不问"这条消息真不真"
> (那是同波兄弟家族讲透新闻理论的地盘,见 [../README.md](../README.md) 全景表),
> 它问的是**消息在人堆里怎么走、走到谁那里、走完之后人变了什么**:
> 媒介如何塑造认知、创新如何穿过人群、舆论如何在恐惧与沉默中成形。
>
> GB/T 13745-2009:860 新闻学与传播学 · 二级学科 **86060 传播学**
> (GB/T 列三级明细 → 九支实名逐条落子,末类「传播学其他学科」槽位
> **改为方法支**并兼任兜底,声明见 §〇与 §三)。
>
> **定位张力声明**(先读这个再读本家族):传播学与新闻理论(86010)共用议程设置、
> 把关、沉默的螺旋等概念,但问的问题不同——**新闻理论管制度与真实性**
> (新闻*应当*是什么、凭什么可信,规范之学),**传播学管机制与效果**
> (信息如何流动、效果如何产生,经验之学)。概念的规范源头与极简议程模拟
> 在兄弟家族舆论学支,效果机制的实证大战场、扩散与网络动力学、方法宪法
> 住本家族——两部词典合订,领土互不侵占。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透传播学/
├── 讲透传播史/        GB/T 三级——从口语、印刷到算法媒介的传播革命编年(媒介环境学派)
├── 讲透传播理论/      GB/T 三级——效果动物园与理论谱系:议程/涵化/知沟/编码解码/使用与满足
├── 讲透传播技术/      GB/T 三级——媒介技术与社会互构:印刷术、广播、互联网、推荐系统
├── 讲透组织传播学/    GB/T 三级——组织内的信息流:正式网络/小道消息/危机传播/领导力
├── 讲透人际传播/      GB/T 三级——两人之间的信息与关系:不确定性/自我表露/关系演进
├── 讲透国际传播/      GB/T 三级——国界之间的信息流:世界信息秩序/国际舆论/传播权力
├── 讲透跨文化传播/    GB/T 三级——文化之间的意义协商:高低语境/文化维度/文化调适
├── 讲透网络传播/      GB/T 三级——网络化的传播结构:病毒扩散/网络舆情/平台社会
├── 讲透新媒介传播/    GB/T 三级——算法媒介的传播:个性化分发/可供性/数据化生存
└── 讲透传播学方法/    GB/T 三级槽位声明:「传播学其他学科」改为方法支——调查/实验/计算方法
```

> 十支的共同血统:**效果问题**(一切理论的最终指向是"传播改变了什么")+
> **过程语言**(信源-讯息-渠道-受者的香农母语法及其人际修正)+
> **可测量性**(经验学科的自尊心:不能操作化的命题不算知识)。
> 支代码与落子依据见 [../README.md](../README.md) §四;GB/T 三级末类槽位改造
> 是建族设计决定(经验学科的方法应有一等公民的支,而非埋进"其他")。
