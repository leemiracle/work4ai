# 讲透传播史 · 从口语到算法媒介:传播革命编年与媒介环境学派

> **定位句:这支负责"传播的时间维度"——媒介如何一轮一轮地革命
> (口语→文字→印刷→电报→广播→电视→互联网→算法),以及每次革命
> 如何重塑社会的权力结构与知识形态。家族的史观供应商。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「传播史」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:学科化的传播史有两条线——①事件史线:从施拉姆建制起
  回溯四大奠基人的研究史(罗杰斯《传播学史》1994 收官);②媒介史线:
  **伊尼斯《传播的偏向》(1951)**与**麦克卢汉《谷登堡星汉璀璨》(1962)**
  开出媒介环境学派:传播史的主角不是讯息是**媒介本身**——
  每种媒介有时间/空间偏向,偏向重塑文明
- **因什么问题**:①为什么某些文明知识垄断、某些文明知识扩散(偏向问题)
  ②印刷术与宗教改革/科学革命/民族主义是什么关系(伊丽莎白·爱森斯坦
  《作为变革动因的印刷机》1979 给出编年证据)③"媒介即讯息"——
  媒介的形式比内容更深刻地改写社会(麦克卢汉 1964)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 印刷术与宗教改革/标准化的编年确证(爱森斯坦);电报与新闻"客观性"语法共生的史实梳理 |
| ✅ 已解决 | 传播学自身建制史:四大奠基人+施拉姆的谱系(罗杰斯口述史方法) |
| 🔄 进行中 | 互联网/算法媒介的"长时段"定位:它是如印刷术级的革命,还是如电报级的加速器——史观之争未定 |
| ❓ 未解决 | 反事实的历史不可检验:没有印刷术的欧洲会怎样——媒介史断言永远停在"叙事合理"级(家族 02 章"说不出的话") |

**最美事实(一句)**:麦克卢汉 1964 把千年媒介史压进四个字
"媒介即讯息"——**媒介的形式本身就是最大的内容**;半个世纪后
推荐算法成为这句话的最强注脚(排序的形式改写亿万人议程)。

## 假设与依赖

- 媒介偏向假设:每种媒介内嵌时间或空间的偏向,偏向非中立
- 长时段假设:媒介的社会效应以百年计,短期舆论波动是噪声
- 硬依赖:家族 00 章(香农模式=媒介的形式骨架);反事实边界自觉(家族 02 章)

## 教材锚

- 罗杰斯《传播学史:传记式的写法》(A History of Communication Study, 1994)
  ——建制史正典,四大奠基人谱系的定本
- 麦克卢汉《理解媒介》(1964)、伊尼斯《传播的偏向》(1951)——媒介史观双源头
