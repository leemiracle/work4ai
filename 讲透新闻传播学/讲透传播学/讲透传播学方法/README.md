## 诞生

- **谁/何时**:方法与学科同生——**伊里面板研究**(拉扎斯菲尔德 1940,
  600 人逐月重测)把面板追踪带进传播;**内容分析**(拉斯韦尔
  战时宣传分析 1927-40s)立"讯息的系统计数"传统;**调查法**
  (盖洛普 1935 民意测验建制化)供给受众测量;**实验法**从霍夫兰
  耶鲁说服研究(1950s)传入;罗杰斯《创新的扩散》(1962)示范
  跨个案综合;2010s 起**计算方法**(网络爬取/文本挖掘/平台审计)
  成为新家当
- **因什么问题**:①效果怎么测才不被自选择污染(因果识别)
  ②讯息怎么变成可计数的证据(内容分析信度)③现在:平台黑箱
  里的曝光怎么测(审计与数据捐赠,家族 01 章战线 5)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 内容分析信度标准(双人独立编码一致率);面板与交叉滞后的方向识别框架 |
| ✅ 已解决 | 调查抽样与加权标准;实验设计(随机/对照/盲法)的学科规范 |
| 🔄 进行中 | 平台审计方法标准化:对照账号/数据捐赠的偏差校准(现场进行) |
| ❓ 未解决 | 平台测量权不对称:真实曝光分布外部不可得——制度问题,方法学只能绕行不能解决 |

**最美事实(一句)**:伊里调查立下的方法学第一戒律——
**让数据推翻你的图**:预设"媒介→选民"的直线,数据摇头,
就从废墟里画出两级传播。方法不是结论的修辞,是结论的出生地。
