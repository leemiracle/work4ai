# 讲透跨文化传播 · 文化之间的意义协商:高低语境、维度与调适

> **定位句:这支负责"意义的文化边界"——同一句话在不同文化携带的
  默认信息量不同;跨文化的传播不是翻译问题,是意义系统的协商问题。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「跨文化传播」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:**霍尔(Edward T. Hall)《无声的语言》(1959)/《超越文化》
  (1976)**立支:文化与传播是一体两面;**高/低语境**二分——
  高语境文化(意义大量内嵌于语境与关系)vs 低语境文化(意义必须
  显式编码进讯息);**霍夫斯泰德文化维度**(1980 起:个人主义/权力距离/
  不确定性规避/男性化/长期取向等)给出跨国比较的量化坐标系;
  **文化适应研究**(贝里 Berry 1980s:整合/同化/分离/边缘化四策略)
  补齐移民与接触情境
- **因什么问题**:①为什么"把话说清楚"在有些文化里是效率、
  在有些文化里是冒犯(编码默认值不同)②文化差异可测吗、怎么测
  ③长期接触中文化与身份如何变(调适)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 高低语境的操作化与国别测量;沟通风格的直接/间接维度验证 |
| ✅ 已解决 | 文化适应四策略的经典验证(整合策略与心理健康稳定相关) |
| 🔄 进行中 | 维度框架的效度之争:国家均值抹平国内差异,维度框架(霍夫斯泰德 vs 施瓦茨 vs GLOBE)互不相让 |
| ❓ 未解决 | "文化"作为解释变量的循环风险:用文化差异解释传播差异,再用传播差异测量文化——测量学的自指问题未破 |

**最美事实(一句)**:霍尔的高低语境用一句话说穿了无数跨文化事故:
**误解不在词里,在默认值里**——高语境的"再考虑一下"是拒绝,
低语境听成"还有希望";两个编码器都工作正常,错的是默认参数。

## 假设与依赖

- 编码默认假设:文化=讯息编码的默认参数集(语境依赖度/直接度/
  关系权重),参数无优劣只有匹配
- 维度假设:文化差异可降维成有限可比的连续轴
- 硬依赖:家族 00 章(编码/解码的文化参数版:同一讯息,
