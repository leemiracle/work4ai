# 讲透网络传播 · 网络化的传播结构:病毒扩散、舆情与平台社会

> **定位句:这支负责"传播的结构维度"——讯息不走空气走网络,
  网络的形状(中心/桥/簇)决定什么传得动、传多快、传给谁;
  家族实验与代码走廊 2 的直连现场。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「网络传播」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:格兰诺维特《弱关系的力量》(1973)与米尔格拉姆
  小世界实验(1967 六度分隔)开出网络视角;瓦茨《六度分隔》
  (1998 小世界模型)与巴拉巴西(1999 无标度网络)给传播以
  **网络科学**的数学骨架;2000s 在线社会网络数据爆发,
  级联(cascade)研究成为可能;卡斯提尔斯《网络社会的崛起》
  (1996)给出社会学总纲:**网络化逻辑**重塑权力、生产与经验
- **因什么问题**:①为什么有些讯息"病毒式"引爆、大多数无声无息
  (结构与内容的联合概率)②意见领袖在网络里的形状
  (hub?桥?还是簇?)③平台如何把传播基础设施私有化(平台社会)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 弱关系的信息功能经典验证(新信息经弱关系到达);hub 对信息扩散的加速确证 |
| ✅ 已解决 | 双传染的分野(Centola & Macy 2007/2010):知晓走简单传染(hub/长桥),采纳走复杂传染(簇宽/冗余)——实验确证 |
| 🔄 进行中 | 级联的结构归因:病毒传播里内容、结构、时机、运气的贡献分解(大规模级联数据可及,归因未完) |
| ❓ 未解决 | 网络舆情与真实民意的关系:表达气候的结构性偏差(沉默+级联选择偏差)无修正通解 |

**最美事实(一句)**:Centola 2010 实验——给同一行为扩散造两种网络,
**长程边更多(更"小世界")的网络扩散反而更小**:信号跑得远
不如信号在邻里间的冗余堆得厚——"病毒式传播"这个流行语
被一个实验干净地拆成两种病(家族 03 章反直觉)。

  干预手段因此相反
