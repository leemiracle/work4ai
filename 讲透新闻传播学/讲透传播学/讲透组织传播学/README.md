# 讲透组织传播学 · 组织内的信息流:正式网络、小道消息与意义建构

> **定位句:这支负责"组织这个容器里的传播"——科层、团队、危机现场
  里信息怎么流、失真在哪、谣言为什么快过公文;组织=传播的系统
  (韦克:组织过程就是意义建构过程)。**
> GB/T 13745-2009:860 新闻学与传播学 · 86060 传播学 · **三级学科「组织传播学」**。
> 家族:[讲透传播学](../README.md)

## 诞生

- **谁/何时**:霍桑实验(1924-32)发现非正式组织;**韦克《组织社会心理学》
  (1969,后版《组织中的意义建构》1995)**立核心命题:组织活动=沟通与
  意义建构(equivocity 消减:组织是在模糊中抽出可行动意义的过程);
  组织传播网络研究 1970s 兴起:谁跟谁说话的社会计量图
- **因什么问题**:①正式结构(科层/流程)与非正式网络(小道/派系)
  的双重信息流②消息在层级传递中如何失真(串联失真实验传统:
  每过一层,细节丢失、框架加固)③危机中意义建构的失败链
  (韦克:曼恩峡谷山火,组织解体的传播学解剖)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 小道消息(grapevine)的结构确证:单链/闲聊/概率/集群四型,速度常快于正式渠道且常更准 |
| ✅ 已解决 | 串联失真的经典验证:层层转述中,消息标准化、细节丢失、文化框架吸收 |
| 🔄 进行中 | 远程/混合办公的组织传播:异步化对非正式网络密度的影响(现场进行) |
| ❓ 未解决 | 组织"内部透明"的边界:透明与保密、心理安全与信息过载的最优权衡无通解 |

**最美事实(一句)**:韦克的曼顿峡谷案例(1993)——消防队长在山火
反转时喊的不是指令是"扔掉工具!":**组织解体的瞬间,意义建构崩溃,
人抱着工具(旧身份)跑不过火;活下来的人先扔掉旧意义**——
组织传播的最小悲剧标本。

## 假设与依赖

- 双重结构假设:正式(职权)与非正式(关系)两张网同时载流,互不可替代
- 意义建构假设:组织的信息处理=对模糊性(equivocity)的削减,
  不是对不确定性的计算(后者是数学,前者是解释)
- 硬依赖:家族 00 章(把关/噪声在组织内的多重嵌套);
