# 讲透新闻史 · 新闻事业的自我意识——媒介如何兴衰,新闻如何成为制度

> **本质一句话**:新闻史=新闻事业的自我意识——它不生产新闻,却回答每条新闻背后的三个问题:**人们什么时候开始需要「定期知道远方」,这个需要养出了什么制度,每次新技术到来时旧制度为什么先预言自己死亡、然后活下来或真的死掉**。
> GB/T 13745-2009:860 新闻学与传播学 · 二级学科 **86020 新闻史**(GB/T 三级:中国新闻事业史/世界新闻事业史/新闻思想史/传播技术史/其他——前四者逐条落子,兜底见 §三)。
> 家族:[讲透新闻传播学](../README.md) 宇宙;五问五章为家族总纲,四支子系列各自由宪法 README 起步。

## 〇、家族树(Q1 的答案 = 这棵树,GB/T 三级四支落子)

```
讲透新闻史/
├── 讲透中国新闻事业史/  📝 GB/T 三级——从进奏院状到融媒体(713-今):
│                              邸报的千年官报传统 + 近代报刊的三次浪潮
├── 讲透世界新闻事业史/  📝 GB/T 三级——从古登堡到平台(1450-今):
│                              印刷报纸的全球扩散与「报纸死亡」的五次预言
├── 讲透新闻思想史/      📝 GB/T 三级——从「喉舌论」到「社会责任论」:
│                              新闻自由/客观性/党性,思想随媒介制度走
└── 讲透传播技术史/      📝 GB/T 三级——印刷→电报→广播→电视→互联网:
                              每代技术如何改写新闻的时间、空间与成本
```

> 四支不是四段封闭历史,而是四个**视角**:中国线看「官报传统如何遭遇商业报刊」,世界线看「报纸如何从特许走向市场再走向平台」,思想线看「为谁说话的问题吵了两百年」,技术线看「载体革命如何决定新闻的物理形态」。四线在 19 世纪(电报+大众报)与 20 世纪末(互联网)两度大交汇。
