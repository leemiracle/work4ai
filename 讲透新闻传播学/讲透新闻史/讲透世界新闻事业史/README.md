# 讲透世界新闻事业史 · 从古登堡到平台(1450-今)

> **定位句**:这支负责世界新闻事业的编年主线——**特许报刊(王权许可)→政党报刊
> (津贴供养)→大众报刊(1833 便士报,广告养报)→垄断报团→平台时代**;
> 一条「报纸的忠诚对象从王权到政党到读者再到算法」的转移史,
> 外加「报纸死亡」的四次预言与一次真伤。
> GB/T 13745-2009:86020 新闻史 · 三级「世界新闻事业史」。家族:[讲透新闻史](../README.md)。

## 诞生

三步建制:古登堡(约 1450)把复制成本砸下数量级,1605/1615 印刷报纸两说起步
(裁决标准本身是史学问题);1833《纽约太阳报》便士报完成商业模式革命(读者=商品);
1848-1870 通讯社制度(AP/路透/哈瓦斯/沃尔夫)与三社四边协定把新闻变成全球批发商品;
1980 CNN 至 2007 后平台,时间优势与广告基础先后被夺。

## 核心问题

- 「第一份报纸」为什么吵了四百年没有终审?(定义之争:印刷/周期/售卖)
- 便士报革命:读者的民主化与新闻的煽情化为何同时发生?(黄色新闻悖论)
- 通讯社如何把「客观性」从商业策略造成全球职业伦理?
- 平台时代:报纸失去的是读者还是商业模式?五次死亡预言错在哪、对在哪?

## ✨ 这支最美的一个事实

1895-96 年的纽约:赫斯特挖走《世界报》整版人马连人带「黄孩子」,
普利策另请画家续画,两个黄孩子在两条街上对骂——发行量战把漫画变成了头版武器。
被史书骂了一个世纪的「黄色新闻」,恰恰是工人阶级第一次成为报纸目标读者的时刻
(家族 00 章反直觉 1);而普利策用黄色新闻赚的钱设立了新闻职业伦理的最高奖。

## 假设与暗面

- 假设:四段论(特许→政党→大众→垄断)全球通用——代价:各国进程极不同步
  (德日授权模式/英国公共广播传统/拉美报业-政治家族化),正典以英美为骨干。
- 暗面:殖民地的报业史长期是宗主国史的注脚;英语中心偏差是本支最大的选样债
  (家族 00 章 §4)。
