# 讲透新闻思想史 · 从「喉舌论」到「社会责任论」——为谁说话的两百年论战

> **定位句**:这支负责新闻思想的论战序列——**出版自由(弥尔顿 1644/第一修正案 1791)
> →集权与苏联模式(喉舌/党性)→客观性与专业主义(1890s-1920s)→社会责任论
> (哈钦斯 1947)→发展新闻学与全球南方→平台时代的信任危机**;
> 思想不是从书本到书本,它跟着媒介制度走:每种报业生态位都产自己的主义。
> GB/T 13745-2009:86020 新闻史 · 三级「新闻思想史」。家族:[讲透新闻史](../README.md)。

## 诞生

三步建制:1644 弥尔顿《论出版自由》与 1791 第一修正案立起自由主义一侧;
1840s-1917 集权批判与苏维埃党报理论(列宁 1901→1942 延安改版中国化)立起另一极;
1890s 客观性(通讯社商业策略)→1922 李普曼《舆论》(拟态环境)→1947 哈钦斯委员会
《一个自由而负责的新闻界》(社会责任论)完成 20 世纪中叶的正反合。

## 核心问题

- 「第四权力」论(新闻作为制衡)与「喉舌」论(新闻作为机构)如何各自制度化?
- 客观性为什么诞生在通讯社而不是哲学系?它被批判后由谁接棒(透明性)?
- 中国新闻思想的本土线:从「耳目喉舌」古义到「舆论监督」术语(1980s)再到融合传播,
  概念三步法怎么写(家族 02 章 §3)?
- 后真相时代:新闻职业伦理的下一站是专业主义 2.0 还是彻底重构?

## ✨ 这支最美的一个事实

1947 年,哈钦斯委员会用四年时间回答一个问题:「新闻自由处于危险中,危险来自
新闻界自己。」报告标题给出了答案——《一个自由而负责的新闻界》。它没有诉诸政府
管制,而是发明了「社会责任论」:**自由伴随义务,新闻界须自律以保自由**。
二十世纪下半叶全球新闻伦理文件的母版,来自一场基金会资助的哲学讨论(时代-塞勒姆
的传记是它的注脚:危机感的另一半是广播电视的崛起,不是报纸的堕落)。

## 假设与暗面

- 假设:思想史=论战序列(正题反题合题)——代价:非论战形态的思想(默会惯例、
  编辑部习惯法)不可见;思想与制度的因果常是双向甚至倒置的。
- 暗面:「新闻自由」概念史与大西洋奴隶贸易时代的报业利益、殖民宣传史缠绕;
  全球南方在经典思想史叙事中长期只是「接受者」。
