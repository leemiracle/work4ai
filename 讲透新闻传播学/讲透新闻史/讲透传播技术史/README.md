# 讲透传播技术史 · 印刷→电报→广播→电视→互联网——载体如何改写新闻

> **定位句**:这支负责传播技术的代际编年——**每一代载体如何压缩新闻的时间
> (周→小时→即时)、扩张新闻的空间(城市→大陆→行星)、改写新闻的成本
> (复制→传输→分发→生产)**;技术给边界条件,广告与管制决定形态,
> 替代曲线是分离的:先夺时间,再夺场景,最后夺钱。
> GB/T 13745-2009:86020 新闻史 · 三级「传播技术史」。家族:[讲透新闻史](../README.md)。

## 诞生

五步代际:古登堡印刷(约 1450,复制成本数量级下降);电报(1844,
新闻与运输分离——时间被压缩,通讯社=时间的批发商);广播(1920,
即时+无远弗届,报纸第一次被预言死亡);电视(1936,
+图像,1962 卫星把「现场」全球化);互联网与移动(1989/2007,
分发与生产解耦,节拍消失);生成式 AI(2022)第一次冲击生产端——谱系树上没有先例的第四个问号。

## 核心问题

- 每代技术的「时间/空间/成本」三参数怎么变?谁受益(新闻机构/读者/平台)?
- 为什么新技术不替代旧媒介的信息职能,而只夺走其时间优势?
- 同一互联网,各国报业结局为何不同?(管制与报业结构是隐藏变量——反媒介决定论)
- 生成式 AI 是第六代吗:当生产的边际成本趋零,「新闻」还剩什么不可生成?

## ✨ 这支最美的一个事实

1866 年大西洋电缆贯通前,纽约报纸上的「欧洲消息」是两周前的旧闻,靠邮船运送;
电缆贯通后,洲际时滞从周级骤降到小时级——新闻史上最陡峭的一次**时间坍缩**。
路透(1851)们卖的本质上是「时间差」:通讯社是 19 世纪的时间套利商,
而倒金字塔文体正是电报时代的产物(按断讯风险排序,最重要的先发)。

## 假设与暗面

- 假设:技术代=自然代(谱系按载体分叉)——代价:同代内部的制度差异被抹平
  (家族 00 章 §5 媒介决定论的代价)。
- 暗面:技术史的正典叙事(发明-扩散-革命)天然偏爱「第一」,忽略改造与互嵌
  (广播没有杀死报纸,而是被报纸的广告养大);军方的角色(电报/卫星/互联网的
  军事出身)常被和平叙事稀释。

## 教材锚
