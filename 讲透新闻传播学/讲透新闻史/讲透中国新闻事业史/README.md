# 讲透中国新闻事业史 · 从进奏院状到融媒体(713-今)

> **定位句**:这支负责中国新闻事业的全程编年——**一条千年官报传统(进奏院状→邸报→京报)
> + 近代报刊三浪(传教士报刊→维新政论报刊→商业大报)+ 当代体系(党报→晚报都市报→融媒体)**;
> 官报、政党、商业三种生态位的消长,是中国近现代史的媒介侧等高线。
> GB/T 13745-2009:86020 新闻史 · 三级「中国新闻事业史」。家族:[讲透新闻史](../README.md)。

## 诞生

三步建制:古代官报自唐(进奏院状,约 8 世纪末存世实物)经宋(邸报制度化)
至明清(京报民间报房翻印),1912 随帝制终结;近代报刊 1815《察世俗每月统记传》
(马六甲)起步、1872《申报》立起商业中文日报范式、1895-1919 政论报刊三浪
(维新→革命→五四);1927 戈公振《中国报学史》为学科奠基,1992-99 方汉奇
《中国新闻事业通史》三卷为正典建制。

## 核心问题

- 中国古代有没有报纸?(邸报定性之争:官报算不算「报纸」——判据在公众性与批评权)
- 近代报刊为什么由传教士与外商起步,国人自办报刊如何后来居上?
- 政论传统(王韬→梁启超→张季鸾)与党报传统(红中社→1942 改版)如何分流与合流?
- 1978 后晚报/周末报/都市报三浪如何重建商业生态位?2014 融媒体战略意味着什么?

## ✨ 这支最美的一个事实

一张报纸活了七十七年:1872-1949,《申报》从美查的商业冒险变成中国报业的度量衡——
它的版面几乎是一部中国近现代史的全息底片(四次抢劫式的战乱中馆舍被占、1949 停刊),
而「申报体」(新闻+言论+副刊+广告四版结构)塑造了此后中文日报的基本形制。

## 假设与暗面

- 假设:政治断代(1840/1919/1949/1978)可作分期骨架——代价:邸报之死(1912)
  与任何刀口都不齐;媒介自身节律被抹平(家族 02 章 §2)。
- 暗面:沦陷区报刊、汪伪报刊在正史叙事中长期缺位;「十年断层」(1966-76)
  只作事实性概述——史料断层本身就是史料。

## 教材锚

- 方汉奇主编《中国新闻事业通史》(三卷,1992-1999)——正典;
  戈公振《中国报学史》(1927)——学科奠基;李彬《中国新闻社会史》——社会文化史范式样本。
