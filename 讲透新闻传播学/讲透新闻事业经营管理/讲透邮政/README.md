# 讲透邮政 · 网点与普遍服务的生意——薄支(GB/T 历史归类)

> GB/T 13745-2009:86040 新闻事业经营管理 三级「8604040 邮政」
> **定位句**:这支在 GB/T 里挂在新闻事业经营管理之下,是**历史归类**——
> 邮电部时代「邮电合一」的地层化石(邮政与电信同部管理,故同序列归类);
> 现代邮政经济的主阵地在物流网络优化与网络型产业规制,本支只立宪法、
> 标注沿革、指路。
> 家族:[讲透新闻事业经营管理](../README.md)(三薄支之一)

## 历史沿革(为什么它在这棵树上)

计划体制下邮政与电信同属邮电部门,学科分类随行政序列走——「新闻事业经营管理」
收留了整条邮电线。学科实质亲缘在**网络型产业**(network industries):
邮路规划、普遍服务义务、交叉补贴——与新闻业的真交叠只有一条:
**发行网络**(报刊发行长期搭邮政网络的车,「邮发合一」是两家最真实的握手)。

## 诞生(这支最美的一个事实)

**普遍服务(Universal Service)的制度设计**:用赚钱线路的利润交叉补贴
亏损线路,让最偏远的居民享受同价服务——「同一个国家,同一张邮票」。
这是网络型产业「效率 vs 公平」的标准教案,也是后来电信普遍服务基金的母版。

## 核心问题

- 已解决(在他家解决):邮路规划与枢纽选址(运筹学/物流优化)、
  普遍服务的交叉补贴与基金化设计
- 未解决(在他家前沿):邮政网络在电商时代的转型(包裹化/金融化)、
  末端配送的成本共配机制

## 假设与依赖

- 依赖:运筹学(选址/路由/库存)、产业组织(规制与补贴设计)
- GB/T 归类代价:同电信支——学术共同体不在本家族,深挖请走「关系」指路
