# 讲透传媒经济 · 注意力的市场结构——二次售卖与双边市场

> GB/T 13745-2009:86040 新闻事业经营管理 三级「8604010 传媒经济」
> **定位句**:这支负责「注意力如何被定价、交易与再分配」——
> 二次售卖、双边市场、平台经济:新闻业市场结构的全部经济学。
> 家族:[讲透新闻事业经营管理](../README.md)(两厚支之一)｜五问模板家族成员

## 诞生

1833 年便士报把报价压到成本以下,用广告侧利润补贴发行侧规模——**二次售卖**定型
(第一次卖内容给读者,第二次卖读者给广告主)。学术化分两步:
1989 年前后皮卡德(R. Picard)《媒介经济学》把它从新闻学附录变成独立研究领域;
2003 年 Rochet-Tirole 双边市场理论给出形式语言:价格结构≠价格水平,补贴侧是设计变量。

## 核心问题

已解决:
- 二次售卖定价:发行价与广告负载的联合最优(p_发行<成本仍可最优)
- 规模经济:首份成本高/边际成本趋零→市场自然趋向寡头与连锁化
- 计量基础设施:审计发行量/收听率让注意力可交易

未解决/前沿:
- 平台时代广告-发行双轮的地基重建(注意力被平台中介后的定价权问题)
- 新闻公共品属性的市场失灵与补贴设计(理论共识已立、政策未收敛)
- AI 摘要截流与内容授权的定价(检索校准 2026-09-07:Sjøvaag 2024)

## 这支最美的一个事实

**同一组参数,两个世界**:双边市场存在「冷寂/起飞」双均衡,终态由初值选择——
分水岭两侧,种子差 1 个广告主,终态差 900 个读者。
(亲历:[`../experiments/00_two_sided.py`](../experiments/00_two_sided.py) 临界规模扫描)

- 依赖:微观经济学(价格理论/产业组织)、信息经济学(审计=可信信号)、博弈论(平台议价)
- 假设代价:注意力可计量(代理变量挤出真价值);广告主隐假设(出资方影响内容边界);
  平台中介假设(分发让渡=主权让渡)——三条隐藏账单见[家族 00 章 §五](../00-体系结构.md)
