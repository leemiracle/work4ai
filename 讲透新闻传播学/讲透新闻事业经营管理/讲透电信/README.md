> **定位句**:这支在 GB/T 里挂在新闻事业经营管理之下,是**历史归类**——
> 邮电部时代「宣传传播-邮电通信」同序列管理的地层化石;现代电信经济与管理
> 的主阵地在信息产业组织与通信工程管理,本支只立宪法、标注沿革、指路。
> 家族:[讲透新闻事业经营管理](../README.md)(三薄支之一)

## 历史沿革(为什么它在这棵树上)

旧版学科分类把邮电通信与新闻出版事业同归一个管理序列(计划体制下
「宣传-邮电」一家亲),2009 版修订时按原文保留。学科的实质亲缘却在别处:
**电信的经营学=容量工程+资费设计+网络规制**,与新闻事业经营管理共享的
只有「频谱与渠道的稀缺管理」一条血脉。

## 诞生(这支最美的一个事实)

**1909 年,哥本哈根电话公司的 Erlang**问「多少条线路才既不堵也不浪费」——
Erlang B/C 公式成为电信经营学的第一块基石,也是整个运筹学的最早定量成果。
一支被归错家的学科,产出了邻居家最漂亮的定理。

## 核心问题

- 已解决(在他家解决):多服务台容量规划(Erlang B 损失制/C 等待制)、
  网络资费的结构设计(两部资费/捆绑)
- 未解决(在他家前沿):频谱拍卖机制的设计与配置效率、网络中立规制的福利边界

## 假设与依赖

- 依赖:排队论/运筹学(容量)、产业组织(规制)、频谱工程
- GB/T 归类代价:读者若在本家族内深挖电信,会错失其学术共同体所在地——
  故本支**不设厚章**,血脉指路见「关系」
