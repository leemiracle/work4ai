# 04 · 新闻事业经营管理转代码:把钱包结构跑起来

> **本章回答五问之五(家族层):这个学科的问题怎么变成 code 问题?**
> **本质一句话**:本学科的工程化三进制——
> **结构已知的写成恒等式与映射(直接算),结构半知的写成预测问题(学),
> 价值敏感的写成约束(不许全自动)**;

## 〇、开篇:一个媒体技术栈的解剖

把一家现代媒体的收入机器拆开,你会看到三层全都能落代码:

```
   获客(流量)      →   转化(付费墙)     →   变现(广告/订阅)
        │                    │                     │
   推荐与分发系统        订阅流失预测           广告库存与拍卖
   (经济学:bandit)     (经济学:LTV)          (经济学:双边定价)
```

三层的共同底座是 03 章的四件骨架:恒等式给变量、映射给动态、临界质量给
增长战略的「何时烧钱」、公共品条件给「哪里不该自动化」。
本章的三条代码走廊正是沿这三层各切一刀。

## 一、可机械化边界(哪些能变 code,哪些变不了)

| 问题类型 | 可机械化程度 | 边界说明 |
|----------|------------|---------|
| 收入分解与 cohort 报表 | ✅ 完全 | 恒等式直接翻 SQL/GroupBy——零模型,只有口径 |
| 广告库存计量 | ✅ 完全 | 库存=流量×广告位×展示率;确定性算术 |
| 拍卖结算(二价/一价) | ✅ 完全 | 规则引擎;机制性质(激励相容)有定理背书 |
| 订阅流失预测 | ⚠️ 实践可行 | 监督学习;但因果性弱——预测「谁要走」≠知道「为何走」,干预效果需实验验证 |
| 付费墙动态定价 | ⚠️ 实验可行 | bandit/强化学习可行,但价值敏感(价格歧视的公平争议)+探索代价真实存在 |
| 推荐系统(参与度目标) | ⚠️ 技术完全/目标存疑 | 优化点击≠优化信任——Goodhart 反噬(§四);新闻推荐必须带价值约束 |
| 双边市场战略模拟 | ⚠️ 情景工具 | 结构模拟(本家族实验)能定性与定盆域,不能当预报器 |
| 采编资源分配 | ❌ 不许全自动 | 编辑判断=价值判断;代码只给数据看板,扣扳机的必须是人 |
| 「新闻的社会价值」评估 | ❌ 不可机械化 | 公共品收益不可观测(03 章 §四)——强行量化=古德哈特进新闻室 |

**边界的经济学本质**:可机械化 ⟺ 「03 章意义上的结构在场且价值中立」。
拍卖有机制定理、库存有恒等式 → 精确带;流失只有相关性结构 → 学习带;
编辑与公共价值连结构都没有(是规范问题) → 人类在环带。
**三带的分界不是技术成熟度,是「该不该」**——这是本家族与纯技术家族最大的不同。

## 二、代码走廊清单(本家族的动手路线)

风格约定:单文件、标准库优先、自验证 assert、文件头注明对应章
(师承 [../../讲透数学/讲透运筹学/](../../讲透数学/讲透运筹学/) 的实验风格)。

| # | 走廊 | 做什么 | 关键结构 | 对应章 |
|---|------|--------|---------|--------|
| 0 | [`experiments/00_two_sided.py`](experiments/00_two_sided.py) | 双边市场:临界规模扫描+赢者通吃+补贴设计 | 差分映射+不动点(已建,纯标准库) | 00/03 |
| 1 | **订阅流失预测** | cohort 留存曲线 → 特征(登录频次/阅读深度/付费档)→ 逻辑回归打分 → 干预分组 | 恒等式:存量×(1−流失)+新增;监督学习 | 01/02 |
| 2 | **广告库存与拍卖** | 库存=流量×广告位×展示率 的月度推演;二价 vs 一价拍卖的结算模拟(真值出清验证) | 恒等式+机制设计 | 00/02 |
| 3 | **推荐系统经济学** | 多臂 bandit:探索-利用权衡;把「点击奖励」换成「点击+留存」复合奖励,对比长期收益 | bandit+Goodhart 对照 | 01/03 |
| 4 | 五钱包 cohort 报表 | 恒等式分解+钱包周期属性的微型报表引擎 | 恒等式 | 03 |

**走廊 1 的最小骨架**(订阅流失,伪码即文档):

```python
# 特征:最近30天登录数、平均阅读时长、订阅档位、距上次续费天数
# 标签:未来30天是否退订(0/1)
# 模型:逻辑回归(标准库可实现梯度下降,或 numpy 十行)
# 产出:风险分 → 分层干预(高险档:人工回访/优惠;低险档:不打扰)
# 铁律:预测分数不能直接当干预依据——先 A/B:干预组 vs 对照组的留存差才是真效果
```

**走廊 2 的机制要点**(广告拍卖):二价拍卖「按第二名价格结算」在单库存位下
让报真价成为占优策略(激励相容);程序化广告转向一价后,**说真话不再占优**,
出价策略变成博弈问题——一次规则改动,整个市场的行为模式重写
(机制设计最生动的大规模实拍;[../../讲透数学/讲透博弈论/](../../讲透数学/讲透博弈论/README.md)
的占优策略概念直接落地)。

**走廊 2 的最小可跑骨架**(库存恒等式,十行内可自验证):

```python
# 月度广告库存推演:库存 = 流量 × 广告位 × 展示率;收入 = 售出库存 × eCPM/千次
pv_day, slots, view_rate = 1_000_000, 5, 0.70          # 日 PV / 广告位 / 展示率
inv_month = pv_day * slots * view_rate * 30             # 月度可用展示量
for fill, ecpm in ((0.8, 20.0), (0.5, 20.0), (0.8, 12.0)):
    revenue = inv_month * fill * ecpm / 1000            # eCPM 按千次计
    print(f"填充率 {fill:.0%} × eCPM {ecpm:.0f} 元 → 月收入 {revenue:,.0f} 元")
# 断言式自检:填充率跌 37.5% 与 eCPM 跌 40% 对收入的打击同阶——
# 分解式让你立刻看到「哪一环在漏钱」比均值报表诚实
```

**走廊 0-4 的共同纪律**:每条走廊都必须先写**口径注释**(指标定义+时间窗+豁免),
再写计算——本行业的代码评审,口径错误是算法错误的一百倍。

**走廊 3 的价值对齐要点**:纯点击奖励的 bandit 会把推荐位推向标题党——
不是算法坏,是**奖励函数缺项**;把 7 日留存项加进奖励,「点击-留存剪刀差」
立刻显形。这条走廊的产出不是更准的模型,而是**一张奖励函数的设计图纸**。

## 三、工程师落点:增长与变现分析

本家族的工程岗位画像=**增长与变现分析**(媒体/内容平台/订阅业务的通用引擎室):

| 场景 | 家族概念 | 一句话 |
|------|---------|--------|
| 留存曲线与 cohort 分析 | 订阅经济学(走廊1) | 「日活涨了留存崩了」是假增长的标准化诊断——按注册周分层画曲线,一眼辨真假 |
| LTV/CAC 与 NRR | 五钱包恒等式 | LTV/CAC>3 才可加投放;NRR>100% 才是真订阅生意(01 章「关系思维」的仪表盘) |
| 付费墙 A/B 实验 | 价格歧视(计量墙) | 墙的硬度/免费篇数/价格是三因子实验空间——媒体业最大的定价实验室 |
| 广告填充与 yield 优化 | 库存恒等式(走廊2) | 填充率×eCPM×展示量的分解式定位「哪一环在漏钱」 |
| 推荐/分发调控 | 双边负载(α 符号) | 广告负载是平台侧旋钮:转太紧(α<0)读者流失,转太松库存浪费 |
| 增长战略的「烧钱线」 | 临界质量(03章) | 补贴该不该加:算分水岭两侧的终态差,不是看短期 ROI |
| 平台合同收入的风险 | 反身性(01章) | 把大客户收入占比做成集中度告警——单一钱包占比>50% 即黄旗 |

**仪表盘分层**(增长与变现分析的交付物,自下而上三层):

| 层 | 内容 | 更新频率 | 受众 |
|----|------|---------|------|
| 数据层 | 口径冻结的事件表(阅读/订阅/广告展示),cohort 打标 | 实时/日 | 工程与数据 |
| 指标层 | 留存曲线、NRR、LTV/CAC、填充率×eCPM、五钱包饼图 | 日/周 | 增长与变现团队 |
| 决策层 | 烧钱线(临界质量)对照、钱包集中度告警、A/B 结论台账 | 周/月 | 主编+CEO |

分层铁律:**指标层只准引用数据层的冻结口径,决策层只准引用指标层的
实验结论**——跳层引用(拿原始数据直接上会)是本行业数据事故的第一大来源。

**三条施工守则**(踩坑总结):

1. **口径先于模型**:本行业每个指标都有三种口径(02 章三栏),先冻结口径再谈预测——
   口径漂移导致的「模型失灵」比算法缺陷多一个数量级。
2. **预测与干预分离**:流失分只排序,不决策;干预效果必须经对照组验证——
   预测相关、干预因果,两门功课分开交卷。
3. **奖励函数要年检**:任何「优化 X」的系统,每年问一次「X 还代理着我们想要的
   东西吗」——古德哈特定律在推荐/广告/增长三处各设一个瞭望哨。

## 四、反直觉发现(工程版)

- **点击率优化会反噬长期留存**:纯 CTR 目标下标题党胜出、深度读者流失,
  流量先涨后崩——剪刀差在 3-6 个月才显形(走廊 3 的对照实验可复现其形状)。
- **平均 eCPM 掩盖库存的结构性贬值**:头部位置 eCPM 稳、长尾库存暴跌,
  均值持平→误判「行情稳定」;分解(位置×时段×人群)是唯一诚实的读法。
- **补贴的账不能只算当期**:03 章多稳态结构下,补贴期的亏损是「移盆成本」,
  用单期 ROI 评估补贴=用边际分析闯非线性区——必错。
