# 03 · 可构造与结构:恒等式、反馈回路与临界质量

> **本章回答五问之四(家族层):这个学科里什么是「结构」——可构造、可复用、可验证的骨架。**
> **本质一句话**:本学科的结构不是定理群,而是**四件可构造的骨架**——
> 收入恒等式(分解)、双轮反馈(映射)、临界质量(多稳态)、公共品条件(市场失灵的结构);
> 每一件都能从「行业直觉」构造到「可跑的模型」,而构造的终点是
> [`experiments/00_two_sided.py`](experiments/00_two_sided.py)。
>
> **讲法纪律(三步法)**:每个结构走直觉→严格陈述→最小例子三步。

## 〇、开篇:什么算这个学科的「结构」

数学家族的结构是同构与不变量(离散数学家的闭包与不动点);
本学科的对象是**组织与市场**,它的「结构」是四件东西:

```
①收入恒等式——把任何媒体拆成五只钱包的会计恒等式(分解结构)
②双轮反馈——读者↔广告主互相抬升/压低的差分映射(动态结构)
③临界质量——同一参数下的多个均衡与它们的分水岭(多稳态结构)
④公共品条件——市场失灵发生的精确条件(制度结构)
```

判别标准:一个说法算「结构」,当且仅当它能被写成**恒等式、映射或条件**,
并且能构造出最小可跑实例。四件骨架全部满足——这是本家族
「可构造性」远超一般文科分支的原因,也是 04 章代码走廊的地基。

## 一、结构一:收入恒等式(一切分析的出发点)

**直觉**:任何新闻机构的生死都写在一行会计式里。
**严格陈述**:

```
总收入 R = R_发行/订阅 + R_广告 + R_平台交易 + R_慈善/补贴 + R_其他(授权/活动/电商)
```

恒等式的力量不在「加总」,而在**分解出结构参数**:每只钱包 = 规模 × 单价 × 转化率,
于是诊断=看哪项在塌、预测=假设哪项可救、战略=选哪项重注。
**最小例子**:`R_订阅 = 订阅者数 × ARPU`,而订阅者数 = 存量 ×(1−流失率)+新增
——一行恒等式立刻给出 04 章走廊一(订阅流失预测)的全部特征变量。

**五钱包的周期属性**(结构记忆法):广告顺周期、订阅抗周期、慈善顺周期
(讽刺但实证反复出现:经济差时捐赠也缩)、平台交易随对方产品周期、
补贴随政治周期。**钱包组合=资产组合**,多样性本身就是收益。

## 二、结构二:双轮反馈(把二次售卖写成映射)

**直觉**:读者多→广告主多→收入多→内容好→读者更多——马太轮;
反方向转也一样:读者流失→广告流失→内容缩水→读者更流失——死亡螺旋。
**严格陈述**(差分映射,与实验同构):

```
读者参与量: N_R(t+1) = f(N_A(t)) = F_R · clip01(( q0 − p_R + α·N_A(t) ) / θmax_R)
广告主参与: N_A(t+1) = g(N_R(t)) = F_A · clip01(( r·N_R(t) − p_A ) / θmax_A)
```

其中 q0=内容基础价值、p_R=发行价(补贴设计变量)、α=读者从每个广告主处得到的
**净外部性**(广告收入反哺内容的价值 − 广告骚扰成本)、r=每个读者给广告主的价值、
p_A=广告刊例价、F_R/F_A=两侧群体容量、θmax=参与门槛分布的上限(异质受众)。
**最小例子**:取 F_R=1000、F_A=200、q0=3、p_R=2、α=0.09、r=0.02、p_A=5、
θmax_R=10、θmax_A=8——这正是 [`experiments/00_two_sided.py`](experiments/00_two_sided.py)
的默认参数;迭代三步就能看到「双轮」是转起来还是停下来。

**符号表的行业翻译**:α>0(读者欢迎广告的反哺)=广告模式黄金年代;
α<0(广告负载过重,骚扰成本压倒内容反哺)=双轮反转,死亡螺旋——
**免费互联网媒体的广告负载困境就是 α 由正转负的实拍**。

## 三、结构三:临界质量(多稳态与分水岭)

**直觉**:冷清的平台没人来,火爆的平台挤破头——中间地带站不住。
**严格陈述**(以 §二的默认参数为例):联立 N_R=f(N_A)、N_A=g(N_R) 解不动点,

```
稳定均衡 A(冷寂):  N_A* = 0,    N_R* = 100   ——「无广告→低质→少读者→无广告」
不稳定不动点(分水岭):N_A* ≈ 21, N_R* ≈ 293  —— basin 边界
稳定均衡 B(起飞):  N_A* = 200,  N_R* = 1000  ——「满广告→高质→满读者」
```

**同一组参数,两个世界,由初值(或政策)选择**——这就是平台经济学
「赢者通吃」与「先烧钱后盈利」的结构根源:烧钱的本质是**把系统推过分水岭**。
**最小例子与三步法收尾**:实验里的临界规模扫描(种子 0→40)精确找到
「21 崩、22 起」的分水岭;种子差 1,终态差 900 读者——**多稳态是非线性市场的
第一课:边际分析在分水岭附近全部失效**。

**补贴的设计定理**(00 章反直觉 1 的结构化):把 p_R 从 2 降到 0.2(低于成本的
发行价=广告侧补贴),冷启动读者量从 100 升到 280,**分水岭被抹平**——
系统从任何初值都能起飞。低价发行不是降价促销,是**移动分水岭的市场设计**。
(实验的「补贴组」断言正是这一条。)

## 四、结构四:公共品条件(市场失灵的精确形状)

**直觉**:好新闻像路灯——我付钱照亮,路人白得光;于是没人愿意付钱。
**严格陈述**:新闻的消费非竞争(我读不妨碍你读)、受益非排他(知情的社会收益
外溢给不付费者),社会边际收益 ΣMBᵢ 超过任何单个人的 MBᵢ——
市场均衡产量 q_mkt 满足「最后一个读者的私人边际收益=价格」,
而最优产量 q_opt 满足「社会边际收益=边际成本」,**q_mkt < q_opt 结构性成立**。
**最小例子**:一篇调查报道成本 100 万、直接付费读者愿付 40 万——市场判死;
但若百万公民每人外溢受益折合 0.5 元,社会愿付 50 万+——缺口 10 万由谁补,
就是 01 章四只新钱包的全部公共经济学。

**制度的结构响应**:强制付费不可能(非排他)→ 只能改结构——补贴(财政)、
税收优惠(慈善钱包的免税设计)、公共媒体(直接公共供给)、平台交易
(把外溢给平台的受益内部化)。四种药对应市场失灵的四种「补法」,
没有一种是免费的(各自的隐藏账单见 01 章 §六)。

## 五、结构引擎总表(本学科怎么「造」知识)

| 引擎 | 输入 | 输出 | 对应家族 |
|------|------|------|---------|
| 恒等式分解 | 财报/行业数据 | 诊断与预测的变量集 | 传媒经济/传媒管理 |
| 反馈映射 | 外部性参数 (α, r) | 双轮/螺旋的定性判断 | 传媒经济 |
| 不动点分析 | 映射+容量 | 均衡集、分水岭、补贴设计 | 传媒经济(平台) |
| 公共品条件 | 受益结构 | 补贴/规制的设计空间 | 传媒经济+行业规范 |
| 代理与激励设计 | 采编-经营信息结构 | 墙的厚度与 KPI 的选择 | 传媒管理 |

**与其他家族的结构对照**:离散数学的引擎是「闭包与不动点」,运筹学的引擎是
「对偶与边际」;本学科的引擎是**「恒等式+回路」**——先用恒等式定变量,
再用回路定动态。三个家族在「不动点」处握手:多稳态分析本质就是
复合映射 f∘g 的不动点分类([../../讲透数学/讲透博弈论/](../../讲透数学/讲透博弈论/README.md)
的均衡概念在这里落地)。

## 六、假设与代价(本章特写:结构的适用范围)

| 结构 | 隐含假设 | 失效场景 |
|------|---------|---------|
| 收入恒等式 | 钱包可分、口径干净 | 平台「流量换广告」捆绑时科目互相渗透 |
| 双轮映射 | 两侧同期响应、参数平稳 | 广告合同有粘滞(实验用惯性系数刻画)、α 随负载漂移 |
| 临界质量 | 单一市场、读者单归属 | 垂直细分市场可容纳多家共存——分水岭是市场级不是行业级 |
| 公共品条件 | 受益真外溢 | 若新闻排他化(付费墙)成功,公共品问题转化为准入不平等问题 |

## 七、反直觉发现

**均衡可以被「历史」选择,而政策的力量在于改写历史**。同一参数下冷寂与起飞
并存(§三),意味着行业的终态不完全由效率决定,而由**谁先越过 293 个读者**决定——
先发优势不是营销口号,是多稳态的数学性质;反过来,补贴/立法的作用不是
「改善均衡」,而是**移动分水岭或直接把系统放入另一个盆域**。评估媒体政策,
问的不是「效率提高了多少」,而是「盆域变了吗」。

## ✨ 美之时刻:平台双边网络效应的完整数学(00 章时刻 2 的展开)

✨ **为什么美**:交叉外部性 (α, r) 把「定价」从单变量问题变成**结构设计问题**——
你设计的不是价格水平,而是**谁补贴谁**的整张流向图。分水岭的存在说明:
市场可以被「造」出来(推移初值),这既是平台烧钱的合法性,也是它的危险性。
**亲历**:跑 [`experiments/00_two_sided.py`](experiments/00_two_sided.py) 的
四组实验——临界扫描(分水岭)、赢者通吃(单归属+多稳态)、补贴设计(移盆)——
十五分钟跑完平台经济学的核心定理群。
