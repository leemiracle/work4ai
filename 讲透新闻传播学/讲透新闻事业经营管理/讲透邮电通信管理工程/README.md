# 讲透邮电通信管理工程 · 合营时代的管理工程——薄支(GB/T 历史归类)

> GB/T 13745-2009:86040 新闻事业经营管理 三级「8604050 邮电通信管理工程」
> **定位句**:这支在 GB/T 里挂在新闻事业经营管理之下,是**历史归类**——
> 「邮电合营」时代(邮政+电信同部经营管理)的工程学科地层;邮电分营后
> (电信政企分开、邮政独立运行),其实体已在电信/邮政两支各自演化,
> 本支只立宪法、标注沿革、指路。
> 家族:[讲透新闻事业经营管理](../README.md)(三薄支之一)

## 历史沿革(为什么它在这棵树上)

「邮电通信管理工程」= 用管理工程方法(标准化/网络规划/资费工程/工程建设管理)
经营「邮+电」合营网络——行政序列决定学科归类的又一实例。邮电分营后,
这套方法分化为通信工程管理与物流管理两条线;本支作为 GB/T 原文名目保留,
是分类学上的**过渡化石**:名字里同时住着邮政(8604040)与电信(8604030)。

## 诞生(这支最美的一个事实)

**合营网络的管理工程本身**:同一个组织同时经营「实物传递网络」(邮政)
与「信号传递网络」(电信),共用规划-建设-运维-资费四段式管理框架——
「网络型产业管理工程」的原型实验室,后来扩散到铁路、电力、广电。

## 核心问题

- 已解决(在他家解决):网络规划与建设的标准流程(管理工程通法)、
  多业务交叉补贴的会计分摊
- 未解决(在他家前沿):分营后的剩余协调问题(普遍服务基金的跨网络核算)——
  已随两支各自演化,不再有独立学术共同体

## 假设与依赖

- 依赖:管理工程通法(预算/规划/标准化)、系统工程、运筹学
- GB/T 归类代价:这是一支**实体已散**的名目——深挖请直走电信/邮政/管理工程
