> 采编与经营之墙、成本中心、战略与治理:把新闻理想装进组织结构的学问。
> 家族:[讲透新闻事业经营管理](../README.md)(两厚支之一)｜五问模板家族成员

## 诞生

18C 富兰克林的印刷所网络是雏形(媒体=有账本的生意);19C 末报团
(普利策/赫斯特系)带来第一个真管理问题:**赚钱的部门能不能指挥说真话的部门?**
「采编与经营分离」(church and state)作为制度答案在 20 世纪英美报业定型;广电牌照
制度又加上「受规制的经营」一层。平台时代的新题型:平台合作经理与编辑部的关系重组。

## 核心问题

已解决:
- 采编-经营之墙的制度设计:预算保障编辑独立,广告销售不干预版面
- 成本中心与预算管理:采编/印务/发行/广告四条线的会计切分
- 集团化与范围经济:多刊共享后台(印刷/发行/法务/数据)

未解决/前沿:
- 增长团队进新闻室:订阅 KPI 与编辑判断的边界(付费墙党风险)
- 非营利新闻室的治理:理事会/捐赠人/编辑部三方权力设计
- AI 工具进采编流程的成本-质量-信任三角(2024 起行业实验期)

## 这支最美的一个事实

**「墙」是产权设计,不是伦理口号**:把编辑预算从广告波动中隔离出来,
等于给「说真话」这份资产买了保险——管理结构本身就是编辑独立的载体,
慈善钱包的制度化(非营利治理)沿同一逻辑展开。

## 假设与依赖

- 依赖:管理学(组织/战略/人力资源)、会计学(成本中心)、代理理论(激励设计)
- 假设代价:预算隔离假设「钱干净即独立」——出资人结构(广告主/平台/基金会)
  仍通过生存压力渗透内容;KPI 假设「可计量=可管理」——古德哈特定律在新闻室营业
