# 讲透新闻事业经营管理 · 让真相可持续生产的经济学——新闻业的钱从哪来、往哪去

> **本质一句话**:新闻事业经营管理=**让真相可持续生产的经济学**——
> 新闻是公共品,市场按私品定价;这门学科研究的是「真相的再生产」如何在
> 广告、发行、订阅、慈善与平台交易五种钱包之间搭起可持续的结构。
>
> GB/T 13745-2009:860 新闻学与传播学 · 二级学科 **86040 新闻事业经营管理**
> (GB/T 三级:传媒经济 8604010 / 传媒管理 8604020 / 电信 8604030 / 邮政 8604040 /
> 邮电通信管理工程 8604050 / 其他 8604099)。
>
> **定位张力声明**(先读再读本家族):GB/T 把**电信/邮政/邮电通信管理工程**三支也
> 归在 86040 之下——这是学科分类的历史地层(邮电部时代「新闻-出版-邮电」同属
> 宣传传播事业管理序列,旧版分类沿袭至今)。本家族按 GB/T 原文落子保留三支为**薄支**
> (只出宪法占位、标注历史沿革),厚答的只有**传媒经济/传媒管理**两支——
> 它们才是当代「新闻事业经营管理」的实际所指(媒介经济学+传媒管理学的合体)。
