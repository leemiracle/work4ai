# 讲透新闻采访 · 事实怎么到手:提问、消息源与证据链

> **定位句:这支负责"事实怎么到手"——线索、提问技术、消息源经营、证据链管理,
> 一切后续工序(写/编/评/摄)的原料合法性都在本支领地上决定。**
> GB/T 13745-2009:860 新闻学与传播学 · 86030 新闻业务 · **GB/T 三级**。
> 家族:[讲透新闻业务](../README.md)

## 诞生

- **谁/何时**:1830s 便士报把"出去打听"变成全职岗位;1846 年港口新闻社(美联社前身)
  把采访网络化;19 世纪中叶"访谈"(interview)成为标准技术;
  1972-1974 年水门报道确立调查采访范式(上门、电话、逐条核对)
- **因什么问题**:①"不在场的报纸凭什么知道"(采访的合法性=证据链)
  ②"陌生人为什要对你说话"(信任的建立)③"信源在说谎怎么办"(多源印证与核实)——
  采访技术的全部历史就是这三问的工程解

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 提问类型学(开放/闭合/漏斗/追问);消息源分级(具名一手>匿名一手>转述);多源印证规程 |
| ✅ 已解决 | 三档保密语法(on/off/background record)——匿名是契约不是偷懒 |
| 🔄 进行中 | 授权匿名规则与匿名信源治理的机构化;暗访与隐性拍摄伦理边界(检索校准 2026-09-07:方向锚,各新闻评议会判例体系) |
| 🔄 进行中 | AI 时代"到场"的价值重估——多 agent 能生成线索表,证实仍须人到场(家族 01 章战线 5) |
| ❓ 未解决 | 不可接近信源(危机地区/组织内幕)的远程验证方法;本地新闻荒漠化下采访在地性的替代 |

**最美事实(一句)**:1972-1974,两个年轻记者用最朴素的方法——
上门、电话、逐条核对——撬动了一位总统:
采访技术的胜利不是技巧的花活,是"**核对**"二字的工业化。

## 假设与依赖

- 信源愿意说话(信任可建立——采访是关系工程,不是提问清单)
- 在场可获知(现场存在不可转述的信息——身体在场本身是信息)
- 多源可印证(独立信源存在且可定位——孤证不立的新闻版)
- 硬依赖:家族 [00-体系结构.md](../00-体系结构.md) 的工序观;
  教具 [../experiments/00_inverted_pyramid.py](../experiments/00_inverted_pyramid.py)
  (信息单元=采访要取回的最小证据颗粒)

## 教材锚

- 梅尔文·门彻《新闻报道与写作》(News Reporting and Writing)——采访与报道一体的定典
- Ken Metzler《创造性采访》(Creative Interviewing)——提问技术的操作手册
- 科瓦奇、罗森斯蒂尔《新闻的十大基本原则》——"新闻的目的:核实"(本支的规范上游)
