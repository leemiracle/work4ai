## 诞生

- **谁/何时**:1860s-1890s 倒金字塔在电报约束下定型(起源说有存疑脚注,见家族 00 章);
  1920s 客观性革命带来归因语法;《华尔街日报》体定型特稿范式;新华体在中国党报体系内成熟
- **因什么问题**:①"稿子被随时砍掉还剩什么"(截断保真——倒金字塔)
  ②"立场相反的读者如何共用同一文本"(客观语法)③"巨型议题如何让人读得进去"
  (特稿的个体舷梯)——三大问题各造一种文体
