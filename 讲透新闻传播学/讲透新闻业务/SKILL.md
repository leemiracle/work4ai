# 新闻业务思维技能卡(讲透新闻业务家族 · GB/T 86030)

## ① 何时用此分支(触发特征,一眼对号)

- 你在**写新闻**:导语、5W1H、倒金字塔、标题、特稿结构、华尔街日报体
- 你在做**采访**:提纲设计、消息源经营、多源印证、匿名信源的三档保密语法
- 你在管**编辑部流程**:选题会、把关漏斗、三审三校、改稿、版面、更正制度
- 你在做**事实核查**:claim 抽取、证据检索、判定分级、ClaimReview 式留痕
- 你在做**数据新闻**:数据管线、清洗聚合、视觉编码、"每个数可溯源"
- 你在处理**编辑部 AI 分工**:机器人写稿、自动摘要、AI 辅助的边界与披露
- 你在装配**融合报道**:多媒材(文/图/数据/交互)的编辑装配

*不是这里*:新闻伦理与客观性的规范本体→新闻理论(86010);受众与效果研究→传播学(86060);
虚构叙事的自由写作→文学宇宙;熵与率失真的数学→信息论;视听节目制作→广播与电视(86050)。

## ② 核心思维模式

1. **工序性**:可信度是流水线的产物,不是作者人格魅力——采(取证)写(成形)编(把关)评(立论)摄(定格)五道工序各管一段信任
2. **前置原则**:按"随时被截断"设计文本——导语=全文的压缩映射,倒金字塔=不等错误保护;截稿/版面/注意力三种不可靠信道逼出同一个结构
3. **归因纪律**:每个事实句挂来源,来源等级降级则断言强度同步降级;无来源=删句子
4. **把关漏斗**:线索→选题→初稿→改稿→签发,每级是一道可检查的判定;判定可 checklist 化,但警惕清单反噬(Goodhart)
5. **核查工序化**:claim→证据→判定→署名——诚实从美德变成可交接、可复跑的工序;但只有"可判定的"才被核查(失效区常在)
6. **机器填结构,人签判断**:数据结构化+断言护栏+人审签署=可机械化三条件;在场、判定责任、价值立场不可外包

## ③ 工具箱(方法名 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| 5W1H 导语公式 | 硬新闻第一句:最小完备事实集,判定标准=截断保真 |
| 倒金字塔层序 | 稿子可能被砍/读者只扫前三段;按信息单元权重降序装填 |
| 延迟导语/华尔街日报体 | 特稿与巨型议题:先场景后要点,个体作舷梯 |
| 提问漏斗(开放→闭合) | 采访提纲:先让信源自由叙述,再钉具体细节 |
| 消息源分级表 | 断言强度对齐:具名一手>匿名一手>转述;多源印证再上版 |
| 三档保密协议 | on/off/background record——匿名是契约不是偷懒 |
| 新闻价值清单(Harcup–O'Neill) | 选题决策可讨论可审计;同时监测清单内卷 |
| 平衡的证据权重语法 | 双方证据不对等时,程序平衡+共识度标注,防假平衡 |
| 核查流水线(claim→证据→判定→署名) | 言论核查、辟谣留痕;判定人不可为 auto |
| 数据新闻管线(取数→清洗→聚合→编码) | 表格变洞察;每个数拖"怎么来的"字段 |
| 模板+断言的结构化写作 | 财报/体育/气象快讯:字段校验先行,缺字段拒发 |
| 更正框 | 错误返回值:固定格式认错,可回链原稿 |

## ④ 常见误区与禁忌

- **无归因断言**——"据悉/有网友称"是来源黑箱;逃逸舱越密,文体越失血
- **细节双刃**——细节密度≠可信度:具体细节正是假消息的可信度信号;逐条问"可溯源吗"
- **假平衡**——把 97:3 的证据格局报成 50:50 辩论;程序正确≠实质真实
- **无分母的数字**——"多达 300 人"必须问分母与占比
- **"拒绝置评"当立场**——必须补程序事实:何时何渠道给的置评机会
- **把 AI 生成文本直接署名发布**——署名=逐字责任担保;生成物必须过断言护栏+人审签署
- **混淆抽取式与生成式摘要**——可断言场景用抽取式;生成式摘要必须过细节溯源闸
- **把点击率当新闻价值**——CTR 最大化系统性偏向耸动;价值清单是护栏不是竞速表

## ⑤ 与相邻分支的判别表 + 组合接口

| 邻居 | 分界 | 组合模式 |
|------|------|---------|
| 新闻理论(86010,同波兄弟) | 规范本体 vs 执行工序 | 它定"为什么这样才可信",本家族出操作手册;伦理守则→编采规范条款 |
| 传播学(86060,同波兄弟) | 生产工序 vs 效果机制 | 把关漏斗与新闻价值清单是议程设置研究的上游机器 |
| 文学宇宙(../../讲透文学/) | 自由叙事 vs 可溯源叙事 | 叙事语法整体借入,借入时加装归因零件;非虚构写作是两家的合资口岸 |
| 信息论(../../讲透数学/讲透信息论/) | 数学本体 vs 文本应用 | 熵=意外度(新闻价值),率失真=导语设计,不等错误保护=倒金字塔 |
| 广播与电视(86050) | 平面/静态工序 vs 视听工序 | 摄影支管静态影像采编,视频与节目制作住广电 |
| 数据科学/AI 工程 | 预测与生成为目标 vs 可信为约束 | 数据管线、claim 匹配、多 agent 线索表由本家族出断言护栏与签署制度 |
