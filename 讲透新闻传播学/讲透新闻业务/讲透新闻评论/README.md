# 讲透新闻评论 · 立场怎么获得合法语法:从社论到评论员制度

> **定位句:这支负责"立场怎么获得合法语法"——社论、评论员文章、专栏、时评的
> 立论工序;评论不是"有观点的文章",是观点与事实分轨运行的制度产物。**
> GB/T 13745-2009:860 新闻学与传播学 · 86030 新闻业务 · **GB/T 三级**。
> 家族:[讲透新闻业务](../README.md)

## 诞生

- **谁/何时**:政党报刊时代整张报纸都是评论(新闻与观点不分家)→ 1920s 客观性革命
  后观点制度性退守社论版 → 1970《纽约时报》开设 op-ed(社论版对页)——
  把"对面那一页"开放给外部作者 → 专栏评论员制度把署名观点做成品牌 →
  中国党报社论写作组与评论员文章制度(机构署名+个人署名的分层责任制)
- **因什么问题**:①"机构观点与个人观点如何分账"(版面产权)
  ②"观点文章凭什么可信"(与消息共用证据纪律)③"评论怎么批评又不越界"
  (立论语法与法律边界)——三问共同造出"立场的合法语法"

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 论点-论据-论证-落点的立论骨架;社论与消息的分版制度(观点的事实基础可审计) |
| ✅ 已解决 | op-ed 制度:机构立场的边界与外部声音的入口 |
| 🔄 进行中 | 评论员个人 IP 与机构立场的张力;评论区治理与"评论的评论"(算法排序的价值观) |
| 🔄 进行中 | AI 代写评论的禁令边界——机构立场不可代笔(家族 04 章边界 4) |
| ❓ 未解决 | 后真相语境下评论的公共职能重建:当读者把评论当消息读、把消息当评论读,分轨制度怎么活(家族 00 章未解清单的评论面) |

**最美事实(一句)**:1970 年 op-ed——社论版发明了**制度化的自我批评**:
把自己版面的背面开放给反对者,立场从此有了边界,也因此有了重量。

## 假设与依赖

- 事实共享假设:评论与消息共用同一证据层(评论的事实断言走消息的归因纪律)
- 价值可辩论假设:分歧在价值层可被论证(而非仅被声明)——评论存在的理由
- 硬依赖:[讲透新闻写作](../讲透新闻写作/README.md)(证据纪律);
  新闻理论家(同波兄弟,舆论学与言论自由的规范本体)
- 借用:逻辑学(论证规范)——GB/T 72040 逻辑学,见哲学宇宙(跨宇宙文字提及)
