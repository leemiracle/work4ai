## 诞生

- **谁/何时**:殖民地时期的排版匠兼主编(printer-editor)→ 1890s 报团工业化拆出编辑台
  分工(城市编辑/版面编辑/文字编辑)→ 1947 Lewin 提出"把关人"概念 →
  1950 White 的 Mr. Gates 研究把把关变成可测机制 → 平台时代的多屏编辑台
  (一条稿装配成 文/图/视频/推送/专题 五种产品);中国的三审三校制度是同源的制度化
- **因什么问题**:①"什么有资格进版面"(把关判定)②"版面有限怎么办"
  (裁剪与装配)③"编辑部怎么对错误负责"(更正与追责)——
  三问合起来=编辑是把关漏斗(家族 03 章层 2)的运营者
