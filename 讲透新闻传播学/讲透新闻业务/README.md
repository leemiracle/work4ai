# 讲透新闻业务 · 把世界转写成可被相信的故事——采写编评摄的手艺

> **本质一句话**:新闻业务=把世界转写成可被相信的故事的手艺——
> 采访取证、写作成形、编辑把关、评论立论、摄影定格,
> 五道工序共同回答同一个问题:**事实如何变成可以被公众相信的文本**。
>
> GB/T 13745-2009:860 新闻学与传播学 · 二级学科 **86030 新闻业务**
> (GB/T 列三级 → 五支逐条落子,第六类「其他」兜底,见 §三)。
>
> **定位张力声明**(先读这个再读本家族):新闻业务与新闻理论(86010,同波兄弟)
> 是同一枚硬币的两面——**新闻理论管规范**(为什么这样写才可信),
> **本家族管手艺**(怎么采、怎么写、怎么编、怎么评、怎么拍)。
> 与传播学(86060,同波兄弟)的分工:传播学研究信息流动的**效果机制**,
> 本家族研究信息生产的**工序**。写作的叙事内核与文学共享血统但纪律相反:
> 文学可以虚构,本家族的每一句都要能被来源背书。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透新闻业务/
├── 讲透新闻采访/   GB/T 三级——事实怎么到手:线索、提问、消息源经营与证据链
├── 讲透新闻写作/   GB/T 三级——事实怎么成形:倒金字塔、导语公式与文体语法(数据新闻内节)
├── 讲透新闻编辑/   GB/T 三级——稿子怎么变成产品:把关、改稿、标题与版面装配(融合报道内节)
├── 讲透新闻评论/   GB/T 三级——立场怎么获得合法语法:从社论到评论员制度
└── 讲透新闻摄影/   GB/T 三级——瞬间怎么成为证据:抓取、图片编辑与影像伦理
```

> 五支的共同血统:**工序性**(可信度不是个人品德,是流水线的产物)+
> **截稿刚性**(一切手艺在 deadline 的时间盒里完成)+
> **归因纪律**(每个事实句都要有来源背书,删来源=删句子)。
> 同波兄弟家族(新闻理论 86010/新闻史 86020/新闻事业经营管理 86040/
> 广播与电视 86050/传播学 86060)见 [../README.md](../README.md) 全景表,
> 此处仅文字提及不互链。
