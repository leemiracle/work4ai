# 讲透比较新闻学 · 从四种理论到三种模式:媒介制度的类型学

> **定位句:这支负责"把'好新闻'的争论变成可测的制度比较"——不同政治经济
> 结构下媒介体制的类型学;双谱系(家族 02 章)在此从立场之争转为维度测量。**
> GB/T 13745-2009:860 新闻学与传播学 · 86010 新闻理论 · **三级学科「比较新闻学」**。
> 家族:[讲透新闻理论](../README.md)

## 诞生

- **谁/何时**:Siebert/Peterson/Schramm《报刊的四种理论》(1956)——集权主义/
  自由主义/社会责任/苏维埃共产主义的规范类型学(冷战印记深,后世批判多);
  MacBride 报告《多种声音,一个世界》(1980)开国际信息流动不平等议题(NWICO);
  **Hallin & Mancini《比较媒介体制》(2004)**——用四个经验维度
  (媒介市场/政治平行性/专业化/国家干预)对欧美画出三种模式
  (极化多元主义/民主法团主义/自由主义)——类型学从规范宣言变成经验科学
- **因什么问题**:①"新闻自由"的标准是唯一的吗(规范相对化)②制度差异
  从哪些维度可测(类型学的维度学)③模式之外(非西方)怎么安放(比较的边界)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 比较维度的定型:Hallin & Mancini 四维度成为领域公用量表;三模式对欧美的强拟合 |
| ✅ 已解决 | 国际新闻流动不平等的测量传统(从 NWICO 到当代平台依赖研究) |
| 🔄 进行中 | 模式的非西方扩展:中国/拉美/海湾/撒哈拉以南非洲——"第四模式"还是维度连续谱上的新位置 |
| 🔄 进行中 | 数字平台对四维度的重写:政治平行性在算法分发下怎么测;国家干预的新形态(内容治理) |
| ❓ 未解决 | 全球同构(平台化)与路径依赖(体制惯性)的赛跑——比较研究正在追一个移动靶 |

**最美事实(一句)**:从"四种理论"到"三种模式",比较的成熟不是分出更多类,
而是维度更细——把"东西方对立"的规范宣言改造成可测量、可证伪的连续谱。

## 假设与依赖

- 可比性假设:存在跨体制通用的比较维度(四维度就是这条假设的产物)
- 路径依赖假设:媒介体制的历史起点约束其演化空间(模式稳定性由此而来)
- 硬依赖:家族 02 章双谱系表(谱系 A/B 就是两种体制的规范语法);
  马克思主义新闻观支与西方新闻理论支(比较的两极素材)

## 教材锚

- Hallin & Mancini《Comparing Media Systems: Three Models of Media and Politics》
  (Cambridge University Press, 2004;中译本《比较媒介体制》)——领域定典
- Siebert, Peterson & Schramm《Four Theories of the Press》(1956)——类型学的起点与靶子
