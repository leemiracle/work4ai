# 讲透新闻理论 · 新闻是什么、凭什么可信——制度的理想与真实的重量

> **本质一句话**:新闻理论=回答「新闻是什么、凭什么可信」——
> 它把每天汹涌的报道流当成一个**制度**来审视:新闻与宣传、谣言的分界线画在哪里,
> 这条线靠什么职业规范、伦理守则与法律结构守住,守不住时社会付出什么代价。
>
> GB/T 13745-2009:860 新闻学与传播学 · 二级学科 **86010 新闻理论**
> (GB/T 列三级 → 七支逐条落子,第八类「其他」兜底,见 §三)。
>
> **定位张力声明**(先读这个再读本家族):新闻理论与传播学(86060)共用大量概念,
> 但问的问题不同——**新闻理论管制度与真实性**(新闻*应当*是什么、凭什么可信,
> 规范之学),**传播学管机制**(信息如何流动、效果如何产生,经验之学)。
> 议程设置的**概念源头与规范性**在本家族舆论学支,它的**效果机制大战场**(受众/中介/认知加工)
> 住传播学家族(同波兄弟,文字提及);本家族不重复建设机制侧,详答规范与真实。
