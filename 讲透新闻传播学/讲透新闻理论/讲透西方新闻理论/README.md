# 讲透西方新闻理论 · 自由主义、社会责任与第四权力的谱系

> **定位句:这支负责"新闻自由的正当性根据及其自我修正"——从弥尔顿到哈钦斯委员会
> 到宣传模式批判,规范性自下而上行会化的谱系 B(家族 02 章双谱系之一)。**
> GB/T 13745-2009:860 新闻学与传播学 · 86010 新闻理论 · **三级学科「西方新闻理论」**。
> 家族:[讲透新闻理论](../README.md)

## 诞生

- **谁/何时**:弥尔顿《论出版自由》(1644)立"观点的自由市场"(真理在交锋中自胜);
  第一修正案(1791)把自由变成法;客观性程序(1920s)把自由变成职业方法;
  **哈钦斯委员会《一个自由而负责的新闻界》(1947)**——自由主义报业理论自我批评,
  社会责任论诞生;Siebert/Peterson/Schramm《报刊的四种理论》(1956)把谱系编成教科书;
  Herman & Chomsky《制造共识》(1988)以宣传模式五过滤器从左翼批判同一谱系
- **因什么问题**:①新闻自由凭什么(对谁的自由)②自由滥用怎么办(黄色新闻/垄断)
  ③自由的名义下有没有结构性操纵(五过滤器:所有权/广告/消息源/反制/意识形态)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 谱系定型:自由主义→社会责任→专业主义的教科书链条;"第四权力"的合法性叙事 |
| ✅ 已解决 | 客观性程序作为职业规范的确立(家族 00 章美之时刻 2) |
| 🔄 进行中 | 第四权力前提的重估:经济独立/专业共同体/信息垄断三前提被平台同时抽走(家族 00 章 §五) |
| 🔄 进行中 | 宣传模式批判在算法时代的扩展:五过滤器之后,第六过滤器是不是推荐系统 |
| ❓ 未解决 | 平台时代"新闻自由"的重述——自由从不被压制的自由,到不被**淹没**的自由(饱和轰炸,家族 01 章战线 2) |

**最美事实(一句)**:哈钦斯委员会的诊断——"新闻自由处于危险之中,
危险主要不来自政府干预,而来自新闻业自身未能履行责任":
一个理论体系公开给自己开诊断书,社会责任论由此而生。

## 假设与依赖

- 自由市场假设(观念的市场如货物市场趋向良序)——已被信息不对称与注意力经济反复凿穿
- 第四权力三前提(经济独立/专业共同体/信息稀缺垄断)——家族 00 章 §五的代价表
- 硬依赖:家族 00 章(客观性诞生史);新闻法支(第一修正案的实在法面);
  传播学家族(同波兄弟,效果研究)
