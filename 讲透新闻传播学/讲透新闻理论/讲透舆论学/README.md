# 讲透舆论学 · 拟态环境、议程设置与沉默的螺旋:公众议程的学问

> **定位句:这支负责"公众在想什么事、怎么想、为什么不敢说"——舆论的形成、
> 测度与引导;家族里唯一配了极简模拟实验的支(公众议程的可构造主场)。**
> GB/T 13745-2009:860 新闻学与传播学 · 86010 新闻理论 · **三级学科「舆论学」**。
> 家族:[讲透新闻理论](../README.md)

## 诞生

- **谁/何时**:卢梭"公意"(volonté générale,1750s-60s)与洛克"意见法则"
  开出思想源头;**李普曼《舆论》(1922)**以"拟态环境+刻板成见"立学科地基
  (公众响应的是头脑里的图像,不是世界);Cohen 1963 点破媒体权力所在——
  "在告诉人们想什么上未必成功,在告诉人们**想什么事**上惊人地成功";
  McCombs & Shaw 1972 教堂山研究确证议程设置(媒体议程×公众议程相关约 0.97);
  Noelle-Neumann 1974 立沉默的螺旋(害怕孤立→准统计感官→少数派沉默)
- **因什么问题**:①"公众意见"是什么、可测吗(测度问题)②媒体如何塑造它
  (议程/框架/螺旋三大机制)③多数显现如何反噬少数表达(舆论的社会皮肤功能)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 议程设置的确证:数千项后续研究,跨国家跨媒体稳定复现;属性议程设置(第二层)的拓展 |
| ✅ 已解决 | 沉默的螺旋的机制表述:准统计感官+孤立恐惧+表达螺旋 |
| 🔄 进行中 | 网络时代螺旋条件的变化:匿名与圈层是否松开"孤立恐惧"(部分失灵论战) |
| 🔄 进行中 | 拟态环境的算法化:搜索与推荐让人手一份拟态环境——共识地基的流失(家族 00 章 §五) |
| ❓ 未解决 | 后真相舆论的机制:普遍怀疑(家族 01 章战线 2)如何被测量、被干预 |

**最美事实(一句)**:Cohen 1963 的那句"想什么 vs 想什么事"是史上最精确的
研究方向说明书——九年后教堂山研究按图索骥,把一个警句变成一个研究领域。
