# 讲透新闻伦理学 · 客观性、最小伤害与透明性:职业规范之学

> **定位句:这支负责"新闻工作者的应当"——客观性、公正、最小伤害、独立、问责
> 五大守则及其冲突裁决;把伦理从美德改造为程序,是本支最深的学理贡献。**
> GB/T 13745-2009:860 新闻学与传播学 · 86010 新闻理论 · **三级学科「新闻伦理学」**。
> 家族:[讲透新闻理论](../README.md)

## 诞生

- **谁/何时**:1923 年美国报纸编辑协会(ASNE)《新闻界信条》——首个成文行业伦理;
  1926 年起 SPJ(职业记者协会)伦理守则成形,现行版四条:追求真相并报道之/
  最小伤害/独立行动/可信且透明;Ward《新闻伦理学的发明》(2004)把客观性
  追溯为一部**历史的发明史**而非永恒原则,并提出透明性范式升级
- **因什么问题**:①信任破产后的职业自救(黄色新闻→守则,家族 00 章三段史)
  ②守则冲突怎么裁(知情权 vs 隐私/速度 vs 核实/透明 vs 消息源保护)
  ③守则管得了心灵管不了结构吗(假平衡/精英源依赖是**程序性**盲点,不是道德瑕疵)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 守则体系的定型:四条目的+细目,全球行业变体互相可译;客观性的程序化定义(事实意见分离/可核查/更正) |
| ✅ 已解决 | 匿名消息源的授予程序(最后手段/利益说明/编辑知悉)与最小伤害的操作清单 |
| 🔄 进行中 | 客观性→透明性范式迁移:程序不再自动产出信任,改为公开程序本身(家族 01 章战线 5;Ward 谱系) |
| 🔄 进行中 | 建设性新闻/解困式新闻的规范地位(长尾归属在本支,家族 README §三) |
| ❓ 未解决 | 冲突裁决无公理:守则给清单不给排序,每案皆案例法;AI 采编的问责主体(谁替算法"最小伤害") |

**最美事实(一句)**:客观性是**方法**不是心灵——它作为对"记者也是人、必有偏见"
的承认而被发明:既然偏见不可根除,就把偏见关进程序的笼子。
伦理从美德转向程序,与程序正义的哲学同构。
