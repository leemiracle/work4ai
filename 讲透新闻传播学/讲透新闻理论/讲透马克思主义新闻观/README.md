## 诞生

- **谁/何时**:马克思《摩泽尔记者的辩护》(1842-43)提出"报刊的有机运动"——
  真实在连续报道中逐步展开;《新莱茵报》(1848-49)的办报实践;
  列宁《党的组织和党的出版物》(1905)立出版物的党性原则;
  毛泽东对晋绥日报编辑人员的谈话(1948)与"政治家办报"(1957);
  2016 年"2·19"讲话提出 48 字职责使命——谱系定型为党性人民性统一的规范体系
- **因什么问题**:①新闻业在阶级社会中的位置(为谁发声)②真实性与导向性的关系
  (报道真事实与坚持立场矛盾吗)③舆论场怎么组织(监督与正面宣传的统一)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 谱系的文献定型:党性原则/政治家办报/48 字方针,条条有文献出处(家族 02 章"可引用"之评) |
| ✅ 已解决 | "报刊的有机运动":真实的**过程论**——单篇的片面在连续报道的总量中被纠正 |
| 🔄 进行中 | 党性与人民性的统一表述("从来都是一致的、统一的");舆论监督与正面宣传统一的实践形态 |
| 🔄 进行中 | 新媒体环境下的舆论引导:平台化、圈层化、算法分发对"有机运动"的新考验 |
| ❓ 未解决 | 全球平台时代谱系 A 与谱系 B(西方规范理论)的对话框架——比较新闻学支的接口题 |

**最美事实(一句)**:"报刊的有机运动"比西方"更正制度"早半个世纪给出
过程性真实观——真实不是一个截面的准确,是一个序列向总量的收敛。

## 假设与依赖

- 规范来源假设:新闻的正当性由政治理论与人民立场授予(对照谱系 B:由程序与市场授予)
- 真实性假设:事实的最终呈现是报道序列的函数(单篇可片面,序列趋于真实)
- 硬依赖:政治理论与经典文献研读;家族 00 章(三段史);02 章(双谱系表)
