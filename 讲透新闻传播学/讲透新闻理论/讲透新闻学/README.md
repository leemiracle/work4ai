# 讲透新闻学 · 学科总论:新闻的定义、真实、价值与功能

> **定位句:这支负责"新闻自身是什么"——新闻本体论(定义/真实)、价值论(什么值得报)、
> 功能论(新闻事业干什么),学科的第一块基石,全家族其余六支都踩在它上面。**
> GB/T 13745-2009:860 新闻学与传播学 · 86010 新闻理论 · **三级学科「新闻学」**。
> 家族:[讲透新闻理论](../README.md)

## 诞生

- **谁/何时**:1918 年北京大学新闻学研究会成立,徐宝璜授课讲义 1919 年成书《新闻学》
  ——中国第一部新闻学著作(蔡元培许为"破天荒");西方同期由报业管理研究
  (普利策 1908 创哥伦比亚新闻学院)走向独立学科
- **定义的定型**:陆定一 1943《我们对于新闻学的基本观点》——
  "新闻是新近发生的事实的**报道**":事实(本体)×新近(时间)×报道(形式)三要素
  成为中文世界最通行的定义
- **因什么问题**:政论报刊时代"新闻=宣传"不言自明;便士报把新闻变成商品后,
  "新闻与评论/宣传/谣言的区别是什么"必须正面回答——本体论由此立项

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 新闻定义的共识句式(事实的报道);新闻价值五要素的可操作化(时新/重要/显著/接近/趣味);环境监测等社会功能清单(Lasswell 1948) |
| ✅ 已解决 | 把关研究传统:White 1950"Mr. Gates"实测筛选过程,Gans 1979《什么算新闻》给出价值判断的民族志 |
| 🔄 进行中 | 个别真实 vs 整体真实(单篇皆真、总体失真的框架问题——与家族 02 章假平衡语法同源) |
| 🔄 进行中 | 平台/AI 时代"新闻"的再定义(算法聚合算新闻吗?AI 生成算报道吗?) |
| ❓ 未解决 | 新闻价值的总体平衡无公理(02 章 §一表达力边界:这一层停在"我知道当我看到它") |

**最美事实(一句)**:定义里那个"报道"——新闻不是事实,是事实的**报道**:
一个学科在自己的第一定义里就承认了与世界的认识论距离(李普曼拟态环境的本土回声)。

## 假设与依赖

- 本体假设:事实独立存在且可报道(客观性程序的形而上前提)
- 价值假设:新闻价值要素可判定的前提是**注意力稀缺**(信息论互译:意外×相关,家族 02 章)
- 硬依赖:新闻思想编年事实由新闻史(86020,同波兄弟)供给;
  亲历教具 [../experiments/00_agenda_sim.py](../experiments/00_agenda_sim.py)(功能论的动态版)

## 教材锚

- 李良荣《新闻学概论》(复旦大学出版社)——中文世界使用面最广的新闻总论教材
- Gans《Deciding What's News》(1979)——价值判断的新闻室民族志经典
