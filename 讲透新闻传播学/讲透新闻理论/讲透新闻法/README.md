# 讲透新闻法 · 表达自由、诽谤与隐私的法定边界

> **定位句:这支负责"规范落到法条与判例"——新闻自由与人格权、国家秘密、
> 公共利益在实在法里的划界技术,伦理守则的硬边界。**
> GB/T 13745-2009:860 新闻学与传播学 · 86010 新闻理论 · **三级学科「新闻法」**。
> 家族:[讲透新闻理论](../README.md)

## 诞生

- **谁/何时**:1695 年英国印刷执照法到期不再续——事先约束制度退场;
  1791 年美国第一修正案入宪;1931 年 Near v. Minnesota 确立"事先限制原则"
  (出版前审查原则上违宪);1964 年**纽约时报诉沙利文案**——公共官员指控诽谤
  须证明"实际恶意"(明知虚假或罔顾真假),批评权获得"喘息空间";
  1966 年美国《信息自由法》(FOIA)立知情权;Warren & Brandeis 1890 首创隐私权
- **中国路径**:1984 年新闻法起草启动,数易其稿至今未颁行——以宪法 35 条与出版管理
  条例等法规群、民法典人格权编共同承担规制功能;"有之名无之法"本身是比较新闻法经典案例
- **因什么问题**:①表达自由不是绝对(伤害他人/公共安全时止于何处)②真话也可能违法
  (隐私/秘密/国家安全)③谁承担证明责任(事前审查 vs 事后追责)④边界由谁划(法官/平台)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 事先限制禁止原则;公共人物诽谤的实际恶意标准;真话性抗辩与公共利益抗辩的框架 |
| ✅ 已解决 | 权利位阶的分析框架:表达自由×人格权×公共利益的类型化权衡 |
| 🔄 进行中 | 平台责任的重写:网络平台是"出版者"还是"管道"(230 条款之争的全球版本) |
| 🔄 进行中 | 算法分发的法律定性:推荐是不是"编辑行为"(把关的外包是否外溢责任) |
| ❓ 未解决 | AI 生成内容的署名、追责与更正义务——"谁报道谁负责"在无记者处的落点 |

**最美事实(一句)**:沙利文案判决书为公共辩论保留"喘息空间"——
错误言论受保护,因为要求批评者永不错误等于取消批评:
用**可谬主义**给自由定刻度,与更正制度的真值观(家族 02 章)同源。

## 假设与依赖

- 事后追责假设(出版自由靠事后问责而非事前审查来平衡)
- 公共/私人的二分(公共事务强保护批评,私人领域强保护人格)——二分本身正被平台消融
- 硬依赖:家族 02 章(规范语);伦理学支(法是伦理守则的硬边界);宪法学与民法学的法理本体(哲学/政法侧,文字提及)
