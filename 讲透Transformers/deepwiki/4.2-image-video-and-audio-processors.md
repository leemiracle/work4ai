  Processors in the `transformers` library are responsible for preparing non-textual data—or combinations of text and other modalities—for model consumption. While tokenizers handle text, `ImageProcessingMixin`, `BaseVideoProcessor`, and `FeatureExtractionMixin` provide the foundation for handling images, videos, and audio signals respectively. For multimodal models (e.g., LLaVA, PaliGemma, Qwen2-VL), the `ProcessorMixin` acts as a high-level orchestrator that composes these individual components.

 
## Core Abstractions and Hierarchy

 The processing infrastructure is built on a set of mixins that define standard APIs for loading, saving, and executing preprocessing transformations.

 
### Class Hierarchy

 
 - **`ProcessorMixin`**: The top-level class for multimodal models. It typically wraps a tokenizer and one or more modality-specific processors (e.g., an image processor). It manages the `from_pretrained` and `save_pretrained` lifecycle for all sub-components [src/transformers/processing_utils.py91-92](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/processing_utils.py#L91-L92)
 - **`ImageProcessingMixin`**: The base class for image preprocessing. It defines the interface for operations like resizing, normalization, and center cropping [src/transformers/processing_utils.py136](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/processing_utils.py#L136-L136)
 - **`BaseVideoProcessor`**: Inherits from `TorchvisionBackend` and provides utilities for temporal sampling of video frames and spatial transformations [src/transformers/video_processing_utils.py80-102](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/video_processing_utils.py#L80-L102)
 - **`FeatureExtractionMixin`**: Used primarily for audio models to extract features like Mel-spectrograms from raw waveforms [src/transformers/feature_extraction_utils.py55](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/feature_extraction_utils.py#L55-L55)
 - **`BatchFeature`**: The standard output container for processors, inheriting from `UserDict`. It holds tensors (e.g., `pixel_values`, `input_features`) and provides a `convert_to_tensors` method for easy transfer to accelerators [src/transformers/feature_extraction_utils.py58-84](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/feature_extraction_utils.py#L58-L84)

## Image and Video Processing

 
### Image Processing Lifecycle

 Image processors handle the conversion of various formats (`PIL.Image`, `numpy.ndarray`, `torch.Tensor`) into normalized tensors. Key functions in `image_utils.py` facilitate this:

 
 - **`make_list_of_images`**: Ensures input is a list of images regardless of whether a single image or a batch was passed [src/transformers/image_utils.py164-199](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/image_utils.py#L164-L199)
 - **`is_scaled_image`**: Checks if pixel values are already in the `[0, 1]` range [src/transformers/image_utils.py153-162](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/image_utils.py#L153-L162)
 - **`ChannelDimension`**: An `ExplicitEnum` used to track if tensors are `channels_first` (torch standard) or `channels_last` (numpy/PIL standard) [src/transformers/image_utils.py85-88](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/image_utils.py#L85-L88)
 
 
### Video Processing and Sampling

 The `BaseVideoProcessor` introduces temporal logic to the vision pipeline.

 
 - **`sample_frames`**: Implements uniform sampling. It can sample a fixed `num_frames` or a specific `fps`. These arguments are mutually exclusive [src/transformers/video_processing_utils.py135-186](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/video_processing_utils.py#L135-L186)
 - **`VideoMetadata`**: A dataclass that stores total frames, duration, and sampled indices, which is crucial for models that require temporal timestamps [src/transformers/video_utils.py79-120](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/video_utils.py#L79-L120)
