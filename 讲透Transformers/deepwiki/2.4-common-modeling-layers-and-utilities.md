  This section details the shared building blocks and utility functions used across model implementations in the Transformers library. These utilities ensure architectural consistency, provide optimized implementations for common operations like Rotary Positional Embeddings (RoPE), and manage complex logic such as gradient checkpointing and attention masking.

 
## Gradient Checkpointing Infrastructure

 The library provides a standardized way to handle gradient checkpointing via the `GradientCheckpointingLayer` base class. This utility allows models to trade compute for memory during training by not storing intermediate activations during the forward pass and recomputing them during the backward pass.

 
### Implementation Details

 
 - **Reentrant vs. Non-Reentrant**: When `use_reentrant=True`, inputs requiring gradients (e.g., hidden states) must be passed as positional arguments (`*args`) to ensure proper gradient propagation [src/transformers/modeling_layers.py60-72](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/modeling_layers.py#L60-L72)
 - **KV Cache Compatibility**: By default, layers that write to the KV cache cannot be checkpointed because the cache would be updated twice. Layers that only read the cache can set `_can_checkpoint_with_cache = True` [src/transformers/modeling_layers.py77-78](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/modeling_layers.py#L77-L78)
 - **Automatic Cache Disabling**: The `__call__` method automatically sets `use_cache=False` and clears `past_key_values`, `past_key_value`, or `layer_past` when gradient checkpointing is active during training to prevent state corruption [src/transformers/modeling_layers.py80-114](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/modeling_layers.py#L80-L114)
 
 **Sources:** [src/transformers/modeling_layers.py52-116](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/modeling_layers.py#L52-L116)

## Masking Utilities

 Masking utilities in `masking_utils.py` provide standardized functions for generating attention masks across different hardware backends (Eager, SDPA, Flash Attention).

 
 - `create_causal_mask`: Generates a standard lower-triangular mask for autoregressive decoding [src/transformers/modeling_layers.py29](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/modeling_layers.py#L29-L29) [src/transformers/models/gemma4/modular_gemma4.py108](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/gemma4/modular_gemma4.py#L108-L108)
 - `blockwise_overlay`: Applies a blockwise bidirectional mask overlay, often used in multimodal models like Gemma 4 [src/transformers/models/gemma4/modular_gemma4.py128](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/gemma4/modular_gemma4.py#L128-L128)
 - `sliding_window_overlay`: Applies a sliding window constraint to an existing mask [src/transformers/models/gemma4/modular_gemma4.py129](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/gemma4/modular_gemma4.py#L129-L129)
 - `maybe_pad_block_sequence_ids`: Handles padding of block sequence identifiers to match KV cache length [src/transformers/models/gemma4/modular_gemma4.py119-121](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/gemma4/modular_gemma4.py#L119-L121)

## Pytorch & Generic Utilities

 Foundational helpers are located in `pytorch_utils.py` and `generic.py`.

 
### Framework Agnostic Helpers (`generic.py`)

 
 - `is_tensor(x)`: Checks if `x` is a `torch.Tensor`, `np.ndarray`, or `mlx.array` [src/transformers/utils/generic.py142-156](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/utils/generic.py#L142-L156)
 - `ModelOutput` Pytree Registration: Registers model outputs with PyTorch's Pytree system via `register_pytree_node` to allow models to be used within `torch.compile` and `torch.distributed` [src/transformers/utils/generic.py63-85](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/utils/generic.py#L63-L85)

 - `prune_linear_layer`: Removes specific indices from a linear layer's weights and biases, used for head pruning [src/transformers/pytorch_utils.py61-92](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pytorch_utils.py#L61-L92)
