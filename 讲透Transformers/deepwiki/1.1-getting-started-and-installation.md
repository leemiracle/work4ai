  This page provides a technical overview of how to set up the Hugging Face Transformers library, manage its extensive dependency graph, and execute initial inference. Transformers is designed as a model-definition framework that bridges various execution backends, primarily focusing on PyTorch 2.5+ in its latest iterations following the removal of TensorFlow and JAX in Version 5.

 
## Environment Setup

 Transformers requires **Python 3.10 to 3.14** [setup.py51](https://github.com/huggingface/transformers/blob/8f542025/setup.py#L51-L51) It is highly recommended to use a virtual environment to manage the complex dependency requirements of modern machine learning libraries.

 
### Core Dependencies

 The library maintains a central dependency table in `setup.py` which is used to generate `src/transformers/dependency_versions_table.py` via the `make fix-repo` command [setup.py69-72](https://github.com/huggingface/transformers/blob/8f542025/setup.py#L69-L72)

 Key mandatory and optional dependencies include:

 
 - **Core:** `huggingface-hub` (Hub interaction), `numpy`, `packaging`, `pyyaml`, `regex`, and `safetensors` [setup.py73-164](https://github.com/huggingface/transformers/blob/8f542025/setup.py#L73-L164)
 - **Backends:** `torch` (>= 2.5) and `accelerate` (>= 1.1.0) are the primary execution drivers [setup.py74-151](https://github.com/huggingface/transformers/blob/8f542025/setup.py#L74-L151)
 - **Tokenization:** `tokenizers` (>= 0.23.1) for Rust-based fast tokenizers [setup.py150](https://github.com/huggingface/transformers/blob/8f542025/setup.py#L150-L150)
 
 **Sources:** [setup.py51-164](https://github.com/huggingface/transformers/blob/8f542025/setup.py#L51-L164) [src/transformers/dependency_versions_table.py1-92](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/dependency_versions_table.py#L1-L92)

## Installation via Extras

 Transformers uses `setuptools` extras to allow users to install only the necessary components for their specific modality (Text, Vision, Audio, Video).

 
### Optional Extra Configurations

 The `extras` dictionary in `setup.py` defines these logical groupings:

 
| Extra | Dependencies | Purpose |
|---|---|---|
| torch | torch, accelerate | Basic PyTorch modeling and device placement setup.py178 |
| vision | torchvision, Pillow | Image processing and computer vision models setup.py179 |
| audio | torchaudio, librosa, pyctcdecode, phonemizer | Speech-to-text and audio processing setup.py180 |
| video | av | Video frame decoding and processing setup.py183 |
| quality | datasets, ruff, GitPython, urllib3, libcst, rich, ty, tomli, transformers-mlinter | Development tools for linting, type checking, and code quality setup.py185-187 |
| sentencepiece | sentencepiece, protobuf | Support for SentencePiece-based tokenizers setup.py190 |
| tiktoken | tiktoken, blobfile | Support for OpenAI tiktoken-based tokenizers setup.py191 |

## Repository Structure & Metadata

 The repository uses `pyproject.toml`, `setup.py`, and a custom `Makefile` to define its packaging, quality metadata, and CI/CD triggers.

 
 - **`setup.py`**: Contains the master list of dependencies (`_deps`) and extra requirements (`extras`) [setup.py72-176](https://github.com/huggingface/transformers/blob/8f542025/setup.py#L72-L176)
 - **`pyproject.toml`**: Configures modern tooling including `ruff` for linting/formatting [pyproject.toml16-20](https://github.com/huggingface/transformers/blob/8f542025/pyproject.toml#L16-L20) and `pytest` for test markers like `generate`, `bitsandbytes`, or `flash_attn_test` [pyproject.toml74-87](https://github.com/huggingface/transformers/blob/8f542025/pyproject.toml#L74-L87) It also includes configurations for the `ty` type checker [pyproject.toml105-124](https://github.com/huggingface/transformers/blob/8f542025/pyproject.toml#L105-L124)
 - **`src/transformers/dependency_versions_table.py`**: An autogenerated mapping of package names to version strings used for consistency checks [src/transformers/dependency_versions_table.py4-92](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/dependency_versions_table.py#L4-L92)
 - **`Makefile`**: Orchestrates repository consistency checks (`check-repository-consistency`) including `docstrings`, `modular_conversion`, and `deps_table` [Makefile17-54](https://github.com/huggingface/transformers/blob/8f542025/Makefile#L17-L54)
 - **`.circleci/create_circleci_config.py`**: Dynamically generates CircleCI configurations, managing environment variables like `TRANSFORMERS_IS_CI` and `PYTEST_TIMEOUT` [.circleci/create_circleci_config.py24-33](https://github.com/huggingface/transformers/blob/8f542025/.circleci/create_circleci_config.py#L24-L33)
