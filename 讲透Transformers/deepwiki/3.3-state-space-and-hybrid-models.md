  State Space Models (SSMs) and their hybrid counterparts represent a shift away from pure Attention-based architectures. These models utilize selective recurrence to achieve linear scaling with sequence length while maintaining high performance on long-context tasks. This page covers the implementation of Mamba, Mamba2, and hybrid architectures like Jamba, Bamba, Zamba, and GraniteMoEHybrid within the `transformers` library.

 
## SSM Recurrence and Selective State Spaces

 The core of the SSM family is the **Selective State Space** layer, which discretizes continuous differential equations into a recurrent form that can be computed efficiently via parallel scans or associative scans.

 
### Mamba & Mamba2 Architecture

 Mamba introduces the `MambaMixer` which implements the selective scan algorithm. Mamba2 evolves this into the `Mamba2Mixer`, utilizing a "Structured State Space Duality" (SSD) approach that connects SSMs to semi-separable matrices.

 **Key Components:**

 
 - **Discretization:** Parameters $A$ and $B$ are discretized using a step size $\Delta$ (delta). In `Mamba`, this is performed in `mamba_selective_scan` [src/transformers/models/mamba/modeling_mamba.py214-216](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba/modeling_mamba.py#L214-L216)
 - **Causal Convolution:** A 1D convolution layer typically precedes the SSM to provide local context. Implemented in `causal_conv1d_fn` [src/transformers/models/mamba/modeling_mamba.py82-101](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba/modeling_mamba.py#L82-L101)
 - **Selective Scan:** The mechanism that allows the model to "select" which information to propagate or forget based on the input. `mamba_selective_scan` handles the parallel scan implementation [src/transformers/models/mamba/modeling_mamba.py175-189](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba/modeling_mamba.py#L175-L189)
 - **SSD Chunking:** Mamba2 optimizes the scan by splitting the sequence into chunks. `reshape_into_chunks` handles the padding and reshaping of tensors for block-parallel processing [src/transformers/models/mamba2/modeling_mamba2.py53-71](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba2/modeling_mamba2.py#L53-L71)

## Hybrid Attention-SSM Models

 Hybrid models interleave standard Transformer Attention layers with SSM layers to combine the global modeling capabilities of Attention with the efficiency of SSMs.

 
### Jamba and Bamba

 
 - **Jamba:** Interleaves `JambaAttentionDecoderLayer` and `Mamba2Mixer` blocks. It also incorporates Mixture-of-Experts (MoE) in its MLP layers [src/transformers/models/jamba/modeling_jamba.py2-6](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/jamba/modeling_jamba.py#L2-L6)
 - **Bamba:** A hybrid architecture combining `LlamaAttention` and `Mamba2Mixer` components, utilizing RoPE for the attention segments. It specifically uses `BambaRotaryEmbedding` to handle inverse frequencies [src/transformers/models/bamba/modular_bamba.py52-71](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/bamba/modular_bamba.py#L52-L71)
 
 
### Zamba and NemotronH

 
 - **Zamba/Zamba2:** Features a "shared attention" mechanism. Zamba2 uses `Zamba2RMSNormGated` to apply gating to hidden states before normalization [src/transformers/models/zamba2/modeling_zamba2.py51-69](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/zamba2/modeling_zamba2.py#L51-L69)
 - **NemotronH:** A hybrid utilizing `Mamba2Mixer` and gated RMSNorm components, often using the combined kernel `mamba2_split_conv1d_scan_combined` for performance [src/transformers/models/nemotron_h/modeling_nemotron_h.py163-185](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/nemotron_h/modeling_nemotron_h.py#L163-L185)
 
 
### GraniteMoEHybrid

 
 - **GraniteMoEHybrid:** Combines Mamba2 blocks with sparse Mixture-of-Experts (MoE) layers. It uses `GraniteMoeHybridAttention` which is a hybrid variant capable of opting out of RoPE via configuration [src/transformers/models/granitemoehybrid/modeling_granitemoehybrid.py123-150](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/granitemoehybrid/modeling_granitemoehybrid.py#L123-L150)
 
 
### Hybrid Layer Interleaving Logic

 The model configuration defines the frequency of attention layers. ## Implementation Details

 
### Optimized Kernels

 SSM operations are computationally expensive in pure PyTorch. The library uses the `use_kernel_func_from_hub_with_fallback` decorator to load optimized CUDA kernels (like `causal_conv1d` and `mamba_ssm`) when available [src/transformers/models/mamba/modeling_mamba.py61](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba/modeling_mamba.py#L61-L61) [src/transformers/models/mamba/modeling_mamba.py128](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba/modeling_mamba.py#L128-L128)

 
### State Management (Caching)

 Unlike Transformers which cache KV pairs, SSMs cache the recurrent state.

 
 - **Mamba Cache:** Stores `conv_states` and `ssm_states`. During generation, `mamba_selective_state_update` updates the state for a single token [src/transformers/models/mamba/modeling_mamba.py129-171](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba/modeling_mamba.py#L129-L171)
 - **Hybrid Cache:** `Jamba` and `Bamba` manage both KV caches for attention layers and recurrent states for SSM layers within the `Cache` object [src/transformers/models/jamba/modeling_jamba.py33](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/jamba/modeling_jamba.py#L33-L33)
 
 
### Segment Sum Computation

 Mamba2 utilizes a stable `segment_sum` calculation to handle chunked processing of sequences. It uses a lower triangular mask and cumulative sums to compute the segment contributions [src/transformers/models/mamba2/modeling_mamba2.py73-90](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/mamba2/modeling_mamba2.py#L73-L90)
