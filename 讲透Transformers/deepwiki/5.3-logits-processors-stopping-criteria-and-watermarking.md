  This section covers the modular components used by `GenerationMixin.generate()` to control the output distribution, determine when to halt generation, and embed/detect statistical watermarks in generated text. These utilities allow for fine-grained control over decoding strategies like Top-K, Top-P, and repetition penalties.

 
## Logits Processors and Warpers

 Logits processors are classes that modify the prediction scores (logits) of a language model head before the next token is sampled. They are organized into a `LogitsProcessorList`, which sequentially applies each processor [src/transformers/generation/logits_process.py63-68](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/logits_process.py#L63-L68)

 
### Core Abstractions

 
 - **`LogitsProcessor`**: The base class for all processors. It implements a `__call__` method that takes `input_ids` and `scores` and returns modified `scores` [src/transformers/generation/logits_process.py49-61](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/logits_process.py#L49-L61) It includes a `supports_continuous_batching` flag to indicate compatibility with high-throughput inference (e.g., vLLM-style batching) [src/transformers/generation/logits_process.py54](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/logits_process.py#L54-L54)
 - **`LogitsProcessorList`**: A container that inherits from `list` and iterates through a list of processors, passing the output of one to the next. It supports passing additional `kwargs` to specific processors by inspecting their signatures [src/transformers/generation/logits_process.py63-98](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/logits_process.py#L63-L98)
 - **`LogitsWarper`**: A specific type of processor typically used for sampling (e.g., Temperature, Top-P) that acts on the distribution to "warp" the probabilities [src/transformers/generation/utils.py98-102](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L98-L102)

## Stopping Criteria

 Stopping criteria determine when the generation loop should terminate, independent of the model's `eos_token_id`. These are managed by a `StoppingCriteriaList` [src/transformers/generation/utils.py111](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L111-L111)

 
### Implementation Details

 
 - **`StoppingCriteria`**: Abstract base class. The `__call__` method returns a `torch.BoolTensor` of shape `(batch_size,)` indicating which sequences in a batch should stop [src/transformers/generation/utils.py110](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L110-L110)
 - **`MaxLengthCriteria`**: Stops when the sequence reaches `max_length`. For decoder-only models, this includes the prompt [src/transformers/generation/utils.py108](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L108-L108)
 - **`MaxTimeCriteria`**: Stops generation if a specific time limit (in seconds) is exceeded [src/transformers/generation/utils.py109](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L109-L109)
 - **`StopStringCriteria`**: Terminates generation when a specific string (or list of strings) is detected in the output [src/transformers/generation/utils.py112](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L112-L112)
 - **`EosTokenCriteria`**: The standard criterion that stops when an `eos_token_id` is generated [src/transformers/generation/utils.py107](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L107-L107)

## Watermarking

 The library provides tools for statistical watermarking, including the SynthID approach and standard green-list/red-list biases. This allows for the detection of machine-generated text by biasing the logits in a way that is invisible to humans but detectable via statistical tests.

 
### Watermark Components

 
 - **`WatermarkLogitsProcessor`**: Biases logits during generation by splitting the vocabulary into "green" and "red" lists based on a hash of the preceding tokens [src/transformers/generation/configuration_utils.py62](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/configuration_utils.py#L62-L62)
 - **`SynthIDTextWatermarkLogitsProcessor`**: Implements SynthID watermarking, which uses a pseudo-random scoring system to bias logits [src/transformers/generation/configuration_utils.py62](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/configuration_utils.py#L62-L62)
 - **`WatermarkDetector`**: Analyzes a generated sequence to calculate statistical metrics (like z-scores), determining the likelihood that the text contains a specific watermark [tests/generation/test_utils.py109](https://github.com/huggingface/transformers/blob/8f542025/tests/generation/test_utils.py#L109-L109)
 - **`WatermarkingConfig` & `SynthIDTextWatermarkingConfig`**: Configuration classes for defining watermark parameters like `gamma` and `delta` [tests/generation/test_utils.py108-110](https://github.com/huggingface/transformers/blob/8f542025/tests/generation/test_utils.py#L108-L110)

## Streamers

 Streamers allow for token-by-token output during the generation process, which is critical for real-time user interfaces and low-latency applications.

 
 - **`BaseStreamer`**: Abstract class for all streamers, defining `put` (for new tokens) and `end` (for generation finish) [src/transformers/generation/utils.py120](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/generation/utils.py#L120-L120)
 - **`TextStreamer`**: A standard streamer that decodes tokens and prints them to the console in real-time.
 - **`TextIteratorStreamer`**: Stores generated tokens in a queue, allowing them to be iterated over in a separate thread. This is useful for web servers (e.g., FastAPI) to stream responses.
