  The `pipelines` subpackage provides high-level abstractions for complex inference tasks involving non-textual modalities. These pipelines encapsulate preprocessing (feature extraction, image processing), model execution, and post-processing (decoding, result formatting) into a single callable interface.

 
## Automatic Speech Recognition (ASR)

 The `AutomaticSpeechRecognitionPipeline` supports both Connectionist Temporal Classification (CTC) and Sequence-to-Sequence (Seq2Seq) models like Whisper. It handles audio file loading via `ffmpeg`, resampling to the model's expected frequency, and chunking for long-form audio [src/transformers/pipelines/automatic_speech_recognition.py146-177](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/automatic_speech_recognition.py#L146-L177)

 
### Whisper Implementation Details

 Whisper pipelines utilize a specialized `WhisperGenerationMixin` to handle features like timestamp prediction and language identification [src/transformers/models/whisper/modeling_whisper.py48-49](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/whisper/modeling_whisper.py#L48-L49)

 Key components include:

 
 - **Timestamp Processing**: The `WhisperTimeStampLogitsProcessor` ensures valid timestamp token sequences [src/transformers/models/whisper/generation_whisper.py32-33](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/whisper/generation_whisper.py#L32-L33)
 - **Long-form Chunking**: The pipeline uses `chunk_iter` to process audio in overlapping segments [src/transformers/pipelines/automatic_speech_recognition.py95-119](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/automatic_speech_recognition.py#L95-L119) then merges results using `_find_longest_common_sequence` to maintain coherence across boundaries [src/transformers/pipelines/automatic_speech_recognition.py121-143](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/automatic_speech_recognition.py#L121-L143)
 - **Alignment**: For token-level timestamps, `_dynamic_time_warping` measures similarity between input audio frames and output tokens [src/transformers/models/whisper/generation_whisper.py64-115](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/whisper/generation_whisper.py#L64-L115)
 - **Padding & Segmenting**: The utility `_pad_to_max_length` handles segment concatenation and manages edge cases like double ending timestamp tokens [src/transformers/models/whisper/generation_whisper.py126-190](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/whisper/generation_whisper.py#L126-L190)

## Text-to-Audio & Text-to-Speech (TTS)

 The `TextToAudioPipeline` (aliased as `text-to-speech`) manages the generation of audio waveforms from text prompts. It supports models that output raw waveforms (e.g., Bark, MusicGen) and models that require an external vocoder (e.g., SpeechT5) [src/transformers/pipelines/text_to_audio.py46-97](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/text_to_audio.py#L46-L97)

 
 - **Vocoder Integration**: If the model belongs to `MODEL_FOR_TEXT_TO_SPECTROGRAM_MAPPING`, the pipeline automatically loads a default vocoder like `SpeechT5HifiGan` [src/transformers/pipelines/text_to_audio.py117-122](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/text_to_audio.py#L117-L122)
 - **Sampling Rate Resolution**: The pipeline attempts to resolve `sampling_rate` from the model config, generation config, or the feature extractor [src/transformers/pipelines/text_to_audio.py132-152](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/text_to_audio.py#L132-L152)
 - **Multimodal Audio Generation**: For models like `SeamlessM4T`, the pipeline returns waveforms via `SeamlessM4TGenerationOutput` [src/transformers/models/seamless_m4t/modeling_seamless_m4t.py121-141](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/seamless_m4t/modeling_seamless_m4t.py#L121-L141) SeamlessM4Tv2 uses a similar structure with `SeamlessM4Tv2GenerationOutput` [src/transformers/models/seamless_m4t_v2/modeling_seamless_m4t_v2.py122-141](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/models/seamless_m4t_v2/modeling_seamless_m4t_v2.py#L122-L141)

## Vision Pipelines

 Vision pipelines utilize `ImageProcessor` classes to handle resizing, normalization, and patch extraction. These pipelines interface with the `AutoImageProcessor` to resolve the correct processing logic for specific architectures.

 
### Common Vision Tasks

 
| Pipeline Class | Purpose | Model Mapping Example |
|---|---|---|
| ImageClassificationPipeline | Predicts class labels for an image. | AutoModelForImageClassification |
| ObjectDetectionPipeline | Detects bounding boxes and labels. | DetrForObjectDetection |
| DepthEstimationPipeline | Predicts depth maps (monocular). | DPTForDepthEstimation |
| VideoClassificationPipeline | Classifies video sequences using frame sampling. | VideoMAEForVideoClassification |
| ZeroShotImageClassification | Classifies images based on text labels (e.g., CLIP). | CLIPModel |
| MaskGenerationPipeline | Generates segmentation masks (e.g., SAM). | SamModel |

## Multimodal Pipeline Utilities

 
### Document Question Answering

 The `DocumentQuestionAnsweringPipeline` combines vision and text. It typically extracts text and bounding boxes from images before passing them to models like LayoutLM [src/transformers/pipelines/document_question_answering.py166-180](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/document_question_answering.py#L166-L180)

 
 - **Box Normalization**: The `normalize_box` function scales OCR coordinates to a 0-1000 range required by document models [src/transformers/pipelines/document_question_answering.py53-59](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/document_question_answering.py#L53-L59)
 - **Span Decoding**: `decode_spans` filters impossible answer spans and ranks candidates by probability [src/transformers/pipelines/document_question_answering.py62-109](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/document_question_answering.py#L62-L109)
 
 
### Zero-Shot Tasks

 `ZeroShotImageClassificationPipeline` and `ZeroShotAudioClassificationPipeline` leverage models like CLIP or CLAP. They process a candidate set of text labels and the input modality (image/audio) to calculate similarity scores in a shared embedding space. The audio variant uses `SequenceFeatureExtractor` to process waveforms into mel-spectrograms or raw features before similarity computation [src/transformers/pipelines/audio_classification.py](https://github.com/huggingface/transformers/blob/8f542025/src/transformers/pipelines/audio_classification.py)
