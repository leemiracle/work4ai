# ① 补充层 · 控制层（Control）全算法

> 控制是最成熟、最工程化的一层：把规划轨迹转成方向盘+油门+刹车。算法来自百年经典控制理论，瓶颈不在算法在调校。端到端革命对它冲击最小（保留为"安全执行器"）。

---

## 1. 基础：车辆模型

**自行车模型（Bicycle Model）**—— AD 控制标准简化：
$$\dot{x} = v\cos\theta,\quad \dot{y} = v\sin\theta,\quad \dot{\theta} = \frac{v}{L}\tan\delta,\quad \dot{v} = a$$

- **运动学模型**（低速 <10m/s，忽略轮胎侧滑）
- **动力学模型**（高速，含轮胎侧偏/质量/惯性）
- 已在 `pure_pursuit.py` 中实现并用 S 弯验证。

## 2. 横向控制（转向）全家桶

| 算法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **Pure Pursuit** | 盯路径前方前瞻点 $L_d$，几何算转角 $\delta=\arctan\frac{2L\sin\alpha}{L_d}$ | 极简稳定 | 急弯滞后；$L_d$ 需调 |
| **Stanley**（Stanford DARPA）| 横向误差 + 航向误差几何法 | 低速精准 | 高速震荡 |
| **后轮反馈** | 基于后轮位置反馈 | 泊车 | — |
| **LQR** | 线性化 + 二次代价，$u=-Kx$ 闭式解 | 平滑、理论最优（线性域）| 约束处理弱 |
| **MPC** | 滚动优化 N 步执行第一步 | **显式约束**（转角/加速度上限）、前瞻 | 计算重（每 10–50ms 解一次 QP）|

**Pure Pursuit 关键调校**：$L_d = k\cdot v$（速度自适应前瞻）——高速看更远，低速看更近（练习已布置）。

## 3. 纵向控制（油门/刹车）

| 算法 | 说明 |
|------|------|
| **PID** | 速度误差→油门，量产 ACC 核心 |
| **增益调度 PID** | 不同速度/坡度不同参数 |

## 4. 集成方案（量产主流）

- 低端：PID + Pure Pursuit
- 中端：LQR + PID
- 高端（L2+/L4）：**MPC**（Tesla/Waymo/国内高阶）——求解器 OSQP / qpOASES
- 新趋势：**Diff-MPC**（可微 MPC，梯度进神经网络端到端训练）

## 5. LQR 数学（离散，需会推）

系统 $x_{k+1} = A x_k + B u_k$，代价 $J = \sum x_k^T Q x_k + u_k^T R u_k$：
1. 解 **代数 Riccati 方程**：$P = A^TPA - A^TPB(B^TPB+R)^{-1}B^TPA + Q$
2. 增益 $K = (B^TPB+R)^{-1}B^TPA$
3. 控制 $u_k = -Kx_k$

## 6. MPC 数学（线性时不变版）

$$\min_{u_{0:N-1}} \sum_{k=0}^{N-1}\left(\|x_k - x_k^{ref}\|_Q^2 + \|u_k\|_R^2\right) + \|x_N - x^{ref}\|_P^2$$
$$\text{s.t. } x_{k+1}=Ax_k+Bu_k,\; u_{min}\le u_k \le u_{max}$$
每步解 QP，只执行 $u_0$，滚动向前。等价于带约束的 LQR（终端项用 Riccati P）。

## 7. 为什么控制层"最不 AI"但最难

- 算法 50 年没大变，但**调校**（权重/前瞻/滤波/延迟补偿）是纯工程艺术。
- 车辆延迟（CAN 总线 ~50ms）、执行器饱和、路面附着——教科书模型都不含。
- FAIL 模式：震荡、稳态误差、高速发散——每个都要工程手段（前馈、增益调度、抗饱和）。
