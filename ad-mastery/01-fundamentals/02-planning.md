# ① 补充层 · 规划层（Planning）全算法

> 规划是 AD 的"大脑"：输出未来几秒的可执行轨迹。它是**最工程化、最难学术化**的一层——量产栈不是单一算法，而是"搜索找粗解 + 优化平滑 + 规则/安全兜底"的组合拳。

---

## 1. 三层结构

```mermaid
flowchart LR
    A[行为决策 Behavior<br/>变道?超车?让行?] --> B[运动规划 Motion<br/>候选轨迹生成+筛选] --> C[轨迹生成<br/>平滑可执行曲线]
```

## 2. 行为决策

| 方法 | 代表 | 现状 |
|------|------|------|
| **有限状态机 FSM** | 车道保持/变道/跟车/应急 | **90% 量产车** |
| **行为树** | Autoware | 模块化可复用 |
| **规则+代价** | Apollo 决策 | 每个候选行为算 cost（安全/舒适/效率）选优 |
| **学习型** | ChauffeurNet（Waymo'18）| 模仿学习轨迹，开创 IL 决策 |

> ⚠️ 纯规则的天花板：规则没覆盖的 corner case 会卡死——这正是端到端想替代的部分。

## 3. 运动规划算法全家桶

### A. 搜索类（离散/连续空间）
| 算法 | 空间 | 特点 | 用途 |
|------|------|------|------|
| **Dijkstra** | 网格 | 无启发式，保证最短 | 教学基线 |
| **A\*** | 网格 | $f=g+h$ 启发式加速 | 全局路径 |
| **Hybrid A\*** | 连续 $[x,y,\theta]$ | 运动原语保证可执行（最小转弯半径）| **泊车/掉头标配** |
| **RRT / RRT\*** | 连续随机采样 | 高维空间，RRT* 渐近最优 | 复杂避障 |
| **RRT-Connect** | 双树 | 快 | 机械臂/泊车 |

### B. 优化类（连续，高速主流）
**核心思想**：轨迹参数化（多项式/B样条），带约束优化：
$$\min_{\text{traj}} \int \underbrace{w_{\text{obs}}d_{\text{obs}}}_{\text{安全}} + \underbrace{w_{\text{comf}}\,\text{jerk}^2}_{\text{舒适}} + \underbrace{w_{\text{eff}}(v-v_{\text{ref}})^2}_{\text{效率}} \,dt$$

| 方法 | 创新 |
|------|------|
| **Apollo EM Planner**（2017）| **里程碑**：path-speed 解耦（两个 1D 问题），EM 迭代。**国产量产规划鼻祖** |
| **QP 轨迹优化** | 多项式参数化 + OSQP/IPOPT 求解 |
| **时空联合规划** | $(x,y,t)$ 不解耦（更优更难），Apollo 后期/小鹏 |

### C. 采样/最优控制类
| 方法 | 特点 |
|------|------|
| **MPC** | 滚动优化 N 步只执行第一步，显式处理约束；**规划+控制一体** |
| **CEM** | 交叉熵采样优化，Tesla/Cruise 用于轨迹采样 |
| **iLQR / Diff-MPC** | 可微规划，梯度能回流感知（UniAD planner 的思想源头）|

### D. 安全过滤器（Safety Filter）
| 方法 | 原理 |
|------|------|
| **CBF（Control Barrier Function）** | 构造安全集，保证状态不离开（可证安全）|
| **RSS（Mobileye）** | 把"安全驾驶"形式化为数学约束，业界最早可证安全框架 |
| **BarrierNet** | CBF 嵌入网络最后一层 = **端到端 + 可证安全** |

## 4. 核心难点

1. **静动混合**：停着的车（空间约束）+ 移动车（时空约束）。
2. **多目标权衡**：安全>舒适>效率>合规，权重是玄学。
3. **不确定性**：感知/预测有误差，规划要鲁棒。
4. **计算预算**：10ms 内出结果。

## 5. 端到端对规划层的冲击

- UniAD/VAD：规划头很小（MLP），靠端到端梯度从规划流回感知。
- EMMA/DriveVLM：VLM 直接生成轨迹（文本 token）。
- 量产现实（2025）：**神经网络出轨迹 + 规则/MPC 兜底校验**——学习型的上限 + 确定性的安全。
