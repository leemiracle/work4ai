# 批次 19：社区与其他清单（12 条）

本批覆盖 awesome-ebpf 清单尾部的 Development and Community（6 条）、Other Lists（3 条）、Acknowledgement（2 条）与 License（1 条），是全流水线最轻的一批。核心价值在于"去哪问问题"：BPF/networking 内核开发的主战场是 netdev 与 bpf 两个 mailing list（均以 lore.kernel.org 为权威归档），XDP 新手有专门的 xdp-newbies 列。抓取质量参差：git.kernel.org 三条（277/278/279）全被 Anubis 反爬拦截成壳页，285/286 为同一 URL 重复条目，287 为 GitHub 个人主页壳页；真正有实质内容的是 280（openwall netdev 归档索引）、281（vger 邮件列表总表）与两个已浅克隆的 repo。

## [277] The bpf-next tree

- 类型 [md]，url=https://git.kernel.org/pub/scm/linux/kernel/git/bpf/bpf-next.git/，本地 web/md/277.md

## [280] The netdev mailing list

- 类型 [md]，url=http://lists.openwall.net/netdev/，本地 web/md/280.md（内容完整）
- openwall 托管的 netdev 归档索引：**总计 1,248,768 封邮件，月度索引从 2006-11 覆盖到 2026-11**，每月 6000-15000+ 封（2026 年 9 月高达 15937 封，流量持续攀升）。
- 抓取日（2026-11-06）当天实时贴均为典型 netdev 内容：af_unix fix 系列、vsock/virtio credit、RDS 连接生命周期重构 v11、Nebulamatrix NIC 新驱动 v33，以及 Alexei Starovoitov 的 `[PATCH bpf] bpf: lwt: Don't let bpf_lwt_push_encap() wrap gso_size`——可见 BPF patch 直接走 netdev。
- 消费建议：提问/发 patch 用 vger netdev@vger.kernel.org（订阅 1085 人，见 281 表），查历史优先 lore.kernel.org/netdev/（权威、带 Patchwork 集成），openwall 此站适合按月翻阅归档。

## [282] The XDP Collaboration Project

- 类型 [repo]，github.com/xdp-project/xdp-project，本地浅克隆；最新 commit **2026-08-12**（`9e714d1`，merge cpumap02_eval_AMD_cross_NUMA），仍在活跃维护。
- 顶层是 Emacs org-mode 工作区而非代码仓：README.org 明言这是"work-in-progress workspace"，用 git 可追踪的方式共享笔记/benchmark/半成品。任务管理走 org-mode（Bernt Hansen 风格 + OWNER 属性认领），GitHub issues/PR 仅用于需多人直接协调的事。
- 内容分布：`areas/`（core/drivers/cpumap/devmap/arm64/dma/latency/mem/tsn 等子系统调研笔记）、`conference.org`、`people.org`、`student-projects.org`、`brainstorm.org`——XDP 内核开发上游讨论的第一手过程档案，与 xdp-project 旗下 xdp-tools/xdp-tutorial 等代码仓互补。

## [285] Dive into BPF: A List of Reading Material

- 类型 [md]，url=qmonnet.github.io/whirl-offload/2016/09/01/dive-into-bpf/，本地 web/md/285.md（全文 637 行，Other Lists 章节）
- Quentin Monnet（后加入 Isovalent/Cilium）写的**eBPF 阅读材料总目**，2016-09 首发、最后更新 2019-01-10——本质上是 awesome-ebpf 清单的前身/姊妹篇（同一作者）。
- 正文结构：先 4 段"BPF 是什么"速览（1992 cBPF→2013 Alexei Starovoitov eBPF→tracing 与网络两应用域→XDP/IO Visor），然后按 Generic presentations（BPF/XDP/相关组件）、Documentation（BPF/tc/XDP/flow dissector/P4）、Tutorials、Examples（kernel/iproute2/bcc/手册页）、The code（内核 BPF 代码/XDP hooks/bcc/LLVM backend/userspace 实现/commit logs）、Troubleshooting（编译期与加载运行期错误）、杂项（Vim 补全、XDP Vagrant 测试环境）分层列出。
- 实用干货在 Troubleshooting 节：verifier 报错解读（"verifier 不运行程序，报 invalid access 是静态估计而非实际发生"）、tc verbose 模式、bcc debug 三 flag、`llvm-objdump -S` 反汇编对照 verifier 日志、bpf-map（Go/Cilium，dump 内核 map）。快照停在 2019 初，链接有陈旧，与 awesome-ebpf 互补使用。
