## Model Setup

 DeepSeek-Prover-V1.5 provides three model variants with increasing capabilities:

 
| Model | Description | Performance (miniF2F) | Hugging Face Path |
|---|---|---|---|
| DeepSeek-Prover-V1.5-Base | Base model pre-trained on mathematical content | 42.2% | deepseek-ai/DeepSeek-Prover-V1.5-Base |
| DeepSeek-Prover-V1.5-SFT | Supervised fine-tuned model | 57.4% | deepseek-ai/DeepSeek-Prover-V1.5-SFT |
| DeepSeek-Prover-V1.5-RL | Reinforcement learning optimized model | 60.2% | deepseek-ai/DeepSeek-Prover-V1.5-RL |

 The models will be automatically downloaded from Hugging Face when you first run the system. For optimal performance, it's recommended to use the RL model with the RMaxTS algorithm.

## Troubleshooting

 
### Lean 4 Installation Issues

 If you encounter problems with Lean 4 installation:

 
 - Ensure all system dependencies are installed (GCC, CMake, Git, Python)
 - Try installing with elan: `curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh`
 - Verify the installation with `lean --version`
 
 
### Mathlib4 Build Failures

 If the mathlib4 build fails:

 
 - Ensure Lean 4 is correctly installed and in your PATH
 - Try cleaning previous build artifacts: `lake clean`
 - Retry the build: `lake build`
 - If problems persist, try increasing the memory limit: `LEAN_MEMORY_LIMIT=10240 lake build`
 
 
### Python Dependency Issues

 If you encounter Python dependency issues:

 
 - Create a virtual environment: `python -m venv venv && source venv/bin/activate`
 - Upgrade pip: `pip install --upgrade pip`
 - Reinstall dependencies: `pip install -r requirements.txt`
