# 讲透信息声学 · 声波作为信息载体

> 用声波传比特：水下通信（电磁波到不了的地方）、近场声学通信、声纹身份、acoustic swarm 定位。
> GB/T 13745：14020 三级「信息科学中的声学问题（含通信声学、声学微机电系统、声学信道）」。家族：[讲透声学](../README.md)·信息生命群。支占位（七要件种子，内容逐支后批）。

## 诞生

1945 水声电话；1970s 水声数字通信；2000s 近场声学数据交换（NFC 的声学表亲）。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 水声信道容量与时变多径 | 🔄 | 多普勒+长时延扩展：通信最难信道之一 |
| 声纹识别 | ✅工程 | 声道'指纹'身份认证（攻防均活跃） |
| 声学室内定位（swarm/微型机器人） | 🔄 | 厘米级纯声学互定位，2021- 热点 |
| 声学隐蔽信道与设备安全 | 🔄 | 超声信标/跨设备追踪的攻防 |

## 假设与依赖

信道=时变滤波器（多径+多普勒）；安全侧=声学传感器的物理可及性。
