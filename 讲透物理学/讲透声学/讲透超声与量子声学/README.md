# 讲透超声与量子声学 · 20kHz 以上：从成像到声子量子态

> 超声=频率高于人耳上限的机械波：医学成像、清洗空化、无损检测；量子声学=GHz 声子成为量子信息载体。
> GB/T 13745：14020 三级「超声学、量子声学和声学效应」。家族：[讲透声学](../README.md)·物理群。支占位（七要件种子，内容逐支后批）。

## 诞生

Galton 1876 超声哨；压电换能（Curie 1880）；Sokolov 1929 超声探伤构想；2010s 声子-超导量子比特耦合。
