# 讲透语言声学 · 语音的物理学：从声道到音素

> 语音=肺气流过声道这根'时变弯管'的声学输出——源-滤波理论一句话解释了元音与辅音的全部菜单。
> GB/T 13745：14020 三级「语言声学和语音信号处理」。家族：[讲透声学](../README.md)·信息生命群。支占位（七要件种子，内容逐支后批）。

## 诞生

Helmholtz 元音共振理论；Fant 1960《声道的声学理论》；1960s Bell 实验室语音识别起步。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 源-滤波理论 | ✅ | 声带源×声道传递=语音合成的总公式 |
| 声道面积函数↔共振峰 | ✅ | 语音的'指纹'是前三个共振峰 |
| 协同发音与连续语音变异 | 🔄 | 音素边界模糊是 ASR 永恒难点 |
| 语音产生-感知的运动理论 | 🔄 | 听话与说话共享运动表征？认知科学前沿 |

## 假设与依赖

一维管道近似（4kHz 以下足够）；发声器官的解剖学约束。

## 教材锚

- Fant《Acoustic Theory of Speech Production》
- Stevens《Acoustic Phonetics》
- Ladefoged《A Course in Phonetics》
