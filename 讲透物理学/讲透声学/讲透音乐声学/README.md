# 讲透音乐声学 · 乐器的物理学与律制

> Pythagoras 问题的现代版：弦长比 2:3 为什么'好听'？答案是边界条件量子化的模式+耳朵的对数感知。
> GB/T 13745：14020 三级「音乐声学」。家族：[讲透声学](../README.md)·信息生命群。支占位（七要件种子，内容逐支后批）。

## 诞生

Pythagoras（音程整数比）；Mersenne 1637 弦振动定律；Helmholtz 1863 打感；Fletcher & Rossing 1998 集大成。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 管/弦/膜的模式理论 | ✅ | 乐器音高=几何+边界条件 |
| 音色=模式包络+起音瞬态 | ✅ | 同音高不同乐器的物理 |
| 律制（纯律/十二平均律） | ✅ | 2 的 7/12 次方≈3/2：听感对数与整数比的千年妥协 |
| 弓弦 stick-slip 与吹奏自振 | ✅ | 非线性自激振荡：乐器是'声学激光' |

## 假设与依赖

线性模式理论+关键非线性（激振机制）；听感对数（十二律的感知根据）。
