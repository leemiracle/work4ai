# 讲透非线性声学 · 大振幅波：谐波生成与激波

> 声压不再小时，叠加原理失效：波峰跑得比波谷快——谐波累积、自陡化、激波、声辐射力。
> GB/T 13745：14020 三级「非线性声学」。家族：[讲透声学](../README.md)·物理群。支占位（七要件种子，内容逐支后批）。

## 诞生

Riemann (1858)/Earnshaw (1860) 的有限振幅理论；Fay (1931) 稳态激波解；现代超声治疗推动精准非线性模型。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 谐波累积与波形陡化（Burgers 方程） | ✅ | 非线性传播的总方程 |
| 激波结构（弱激波厚度=非线性/耗散平衡） | ✅ | 时域冲击波的普适画像 |
| 声辐射力与声流（streaming） | ✅ | 声镊/超声操控的物理 |
| 含气泡/空化介质的统一平均化建模 | 🔄 | 前线：强非线性多相介质 |

## 假设与依赖

非线性项保留（对流加速度）+耗散（粘性/热）平衡；Goldberg 数判'谁赢'。

- Beyer《Nonlinear Acoustics》
