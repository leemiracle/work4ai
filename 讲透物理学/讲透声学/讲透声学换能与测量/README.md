# 讲透声学换能与测量 · 声与电的边界：换能器、标准与材料

> 一切声学工程的入口和出口都是换能器：压电（超声/水声）、电动式（扬声器/动圈麦）、MEMS（手机麦）；测量标准让全行业说同一种话。
> GB/T 13745：14020 三级「声学换能器、声学测量及方法（含声学测量方法、声学材料）」。家族：[讲透声学](../README.md)·信息生命群。支占位（七要件种子，内容逐支后批）。

## 诞生

压电效应 Curie 1880；动圈扬声器 Rice-Kellogg 1925；MEMS 麦克风随 2000s 智能手机普及。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 换能器等效电路（Mason 模型） | ✅ | 机电声三域统一建模 |
| 互易校准 | ✅ | 不用'标准声源'的绝对校准（物理自洽的礼物） |
| 阵列换能器与 cMUT | ✅ | 超声探头的当代主力 |
| 声学材料表征（阻抗管/混响室） | ✅ | 吸声系数=工程输入数据 |

## 假设与依赖

压电/电磁本构方程+机械阻抗匹配；测量=标准环境+标准方法的协议栈。
