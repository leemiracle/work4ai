# 讲透水声与海洋声学 · 声呐的物理：海洋里唯一的远距离感官

> 电磁波在海水中寸步难行，声是唯一能跑远距的信号——SOFAR 声道让爆炸声传上万公里。
> GB/T 13745：14020 三级「水声和海洋声学（原名水声学）」。家族：[讲透声学](../README.md)·介质场群。支占位（七要件种子，内容逐支后批）。

## 诞生

Richardson 1919 冰山回声设想；Langevin 一战压电声呐；WWII 大西洋反潜战催生整套理论。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 深海声道（SOFAR）传播 | ✅ | 声速剖面极小值=自然波导 |
| 浅水/海岸复杂环境传播 | 🔄 | 边界交互+沉积层，抛物方程数值主力 |
| 混响与目标强度 | ✅半经验 | 声呐方程的核心项 |
| 海洋声层析（测温度/流场） | ✅ | 用声学给海洋做 CT |

## 假设与依赖

声速剖面 c(z)（温盐深）决定一切；声呐方程把物理折成工程预算。

## 教材锚

- Urick《Principles of Underwater Sound》（圣经）
- Jensen et al.《Computational Ocean Acoustics》
