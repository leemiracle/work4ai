# 讲透噪声及其控制 · 不想要的声音的物理学与工程学

> 噪声=错误时间地点的声音：从职业听力保护法规到有源降噪耳机，治理它需要源-路径-接收者三线作战。
> GB/T 13745：14020 三级「噪声、噪声效应及其控制」。家族：[讲透声学](../README.md)·介质场群。支占位（七要件种子，内容逐支后批）。

## 诞生

工业革命的锅炉车间；1936 Lueg 有源降噪专利；1970s 职业噪声立法；1989 Bose 民用 ANC 耳机雏形。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 质量定律与隔声 | ✅ | 重墙隔声的物理（TL≈20log(mf)） |
| 有源噪声控制（ANC） | ✅ | 反相波相消：控制理论在声学的最大落地 |
| 吸声材料机理（多孔/共振/微穿孔） | ✅ | 工程输入数据的来源 |
| 噪声地图与城市声环境 | ✅ | ISO/CNOSSOS 标准模型 |

## 假设与依赖

接受'噪声'是政策概念（法规定限值）；控制三问：源/路径/接收者哪个最便宜。

- ISO 9613 户外传播标准
