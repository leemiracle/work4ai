# 讲透声学 · 弹性介质中机械波的科学

> 声学：**机械波的产生、传播、接收与信息利用**——从琴弦振动到声呐、超声成像、
> 语音 AI。它是物理最老的分支（Pythagoras 2600 年前研究音程），也是最新材料革命
> （声学超构表面）的现场。
>
> GB/T 13745：14020（物理学·二级学科）。宇宙：[讲透物理学](../README.md)。
> 本 README=家族宪法；五章=五问详答；15 支=GB/T 三级落子。

## 一、本质一句话

声学研究的对象只有一句话：**介质偏离平衡态后的自我恢复运动**——弹性+惯性的
合谋以波的形式传播。一切分支都是这句话在不同介质（空气/水/固体）、不同频率
（次声 20Hz 以下→超声 20kHz 以上→量子声学 GHz）、不同目的（ hearing vs 工程）
上的展开。

## 二、诞生

- **Pythagoras（约前 500 年）**：琴弦长度与音程的整数比——第一个物理定律级的声学发现
- **Newton（1687）**：推导声速（等温近似差一口绝热修正）；Laplace 1816 修正
- **Rayleigh《The Theory of Sound》（1877）**：两卷立典，声学成为数理学科
- **20 世纪三引擎**：水声（两次世界大战声呐）、超声（医学成像）、电声（唱片/电话/扬声器）
- **21 世纪**：超构材料改写"材料声学属性天然给定"的假设

## 三、核心问题清单

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 波动方程与声速推导 | ✅ 已解 | 声学的牛顿定律；c=√(K/ρ) 一式定乾坤 |
| 驻波与模式理论 | ✅ 已解 | 乐器的音高离散性=边界条件的本征值（详见 00 章） |
| Lighthill 声类比（1952） | ✅ 已解 | 湍流噪声的半经验框架——喷气式飞机降噪的理论根据 |
| 湍流声场的从头预测 | ❌ 未解 | 声学最大的"原理性裂缝"：声源项比声场本身难算 |
| 听觉感知的完备模型 | ❌ 未解 | 心理声学是经验规律集，"好听"没有公理系统 |

## 四、假设与代价

- **线性化假设**（声压 << 静压）：买到叠加原理与模式分解，付出"激波/谐波失真/
  声 streaming"要另起炉灶（非线性声学）
- **连续介质假设**：波长 >> 分子间距。GHz 以上（量子声学）逐步失效
- **无粘无频散近似**：理想流体中声不衰减——真实介质用吸收系数修正
