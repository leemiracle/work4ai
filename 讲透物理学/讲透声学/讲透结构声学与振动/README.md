# 讲透结构声学与振动 · 固体中的波：从 NVH 到无损检测

> 固体既能推（纵波）又能剪（横波），还能沿表面和板走导波——汽车的'路噪'与飞机的'疲劳'都是它。
> GB/T 13745：14020 三级「结构声学和振动」。家族：[讲透声学](../README.md)·介质场群。支占位（七要件种子，内容逐支后批）。

## 诞生

Rayleigh 表面波 (1885)、Lamb 板波 (1917)；汽车工业把'噪声-振动-声振粗糙度'(NVH)变成一级产品指标。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 纵/横波与界面反射透射 | ✅ | 与地震勘探同源的理论 |
| 导波族（Lamb/Scholte/Love） | ✅ | 管道与板材无损检测 |
| 统计能量分析（SEA） | 🔄半经验 | 高频复杂结构'不数模式'的能量流法 |
| 结构-声耦合（辐射效率） | ✅ | 哪块钣金在'唱歌' |

## 假设与依赖

弹性本构+几何边界；高频模式密度爆炸→统计方法接管理论方法。

## 教材锚

- Cremer et al.《Structure-Borne Sound》
- Fahy & Gardonio《Sound and Structural Vibration》
