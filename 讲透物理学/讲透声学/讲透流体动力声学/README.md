# 讲透流体动力声学 · 流动如何发声（Lighthill 的遗产）

> 湍流没有声音方程——Lighthill (1952) 把 Navier–Stokes 重组为'等效声源+波动方程'，喷气时代由此可以计算噪声。
> GB/T 13745：14020 三级「流体动力声学（含航空声学、流体运动与声波相互作用）」。家族：[讲透声学](../README.md)·物理群。支占位（七要件种子，内容逐支后批）。

## 诞生

Lighthill 1952 英国皇家学会论文；Ffowcs Williams & Hawkings 1969 推广到运动表面（旋翼/叶轮机械）。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Lighthill 声类比 | ✅ | 湍流噪声的半经验总框架 |
| 喷流噪声速度八次方律 | ✅ | 降噪 1 dB 为什么要拼命 |
| FW-H 方程（运动边界发声） | ✅ | 飞机/风扇噪声工程标准 |
| 湍流声源的从头预测 | ❌ | 本支最大裂缝：声源项依赖湍流闭包 |

## 假设与依赖

等效源思想：声场小扰动+源项由流动提供；马赫数与远场假设。

## 教材锚

- Lighthill 1952 原典（Proc. R. Soc. A）
- Howe《Theory of Vortex Sound》
