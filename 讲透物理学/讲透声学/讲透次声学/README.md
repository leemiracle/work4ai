# 讲透次声学 · 20Hz 以下：听不见的全球波

> 频率低于人耳的波绕射全球：核爆监测、火山、陨石、极光、大象与鲸的长波通信。
> GB/T 13745：14020 三级「次声学」。家族：[讲透声学](../README.md)·物理群。支占位（七要件种子，内容逐支后批）。

## 诞生

Krakatoa 火山 1883 全球气压波记录；1996 年 CTBT 把次声监测变成国际基础设施（60 台站网络）。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 大气导波与远程传播 | ✅ | 平流层/热层波导模型 |
| 核爆/火山/陨石源定位 | ✅ | IMS 国际监测系统实战 |
| 次声源的自动分类 | 🔄 | 深度学习分类器正在替换人工判读 |

## 假设与依赖

大气分层模型+低衰减（频率低吸收小）；台站阵列测向。
