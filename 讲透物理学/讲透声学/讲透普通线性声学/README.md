# 讲透普通线性声学 · 波动方程的全部经典内容

> 干涉、衍射、驻波、散射、射线与波动两种图像——线性声学是全家族的普通话。
> GB/T 13745：14020 三级「普通线性声学（原名物理声学；含射线/波动/大气声学）」。家族：[讲透声学](../README.md)·物理群。支占位（七要件种子，内容逐支后批）。

## 诞生

Rayleigh《The Theory of Sound》(1877) 两卷立典；20 世纪飞机时代推动射线声学与大气声学。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 波动方程解结构（d'Alembert/分离变量） | ✅ | 全家族的演绎地基 |
| Snell 折射与分层介质射线追踪 | ✅ | 大气/海洋远程传播的工程语言 |
| Rayleigh 散射 k⁴ 普适律 | ✅ | 小尺度散射的频率标度 |
| 复杂介质格林函数 | ✅ | 一切正问题/逆问题的总接口 |

## 假设与依赖

线性化（声压≪静压）+连续介质假设；上游=[家族层 00 章](../00-体系结构.md)与数学 PDE。
