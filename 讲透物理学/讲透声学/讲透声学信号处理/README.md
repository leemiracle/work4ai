> 把声场变成数据后的全部数学：STFT、波束形成、盲源分离、回声消除——智能音箱的第一道智能。
> GB/T 13745：14020 三级「声学信号处理」。家族：[讲透声学](../README.md)·信息生命群。支占位（七要件种子，内容逐支后批）。

## 诞生

二战声谱仪（可见语音）；1965 FFT 让频域处理实时化；1990s 阵列信号处理成熟（借雷达/地震学方法）。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 波束形成（DAS/MVDR/GSC） | ✅ | 空域滤波=定向拾音 |
| 回声消除（AEC）与自适应滤波 | ✅ | NLMS/RLS 仍是产品基石 |
| 盲源分离与去混响 | 🔄 | 统计方法→神经方法交替领先 |
| 远场+多说话人+强噪场景 | 🔄 | 2021- 深度学习前端的正面战场 |

## 假设与依赖

信号模型=平面波+噪声；实际房间=卷积混响（RIR），模型失配是永恒主题。
