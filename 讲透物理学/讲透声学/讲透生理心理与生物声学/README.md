# 讲透生理心理与生物声学 · 耳朵、大脑与蝙蝠的声学

> 听觉是一台机械傅里叶分析器（耳蜗）+一台模式识别器（听觉通路）；蝙蝠与鲸把它做成了声呐。
> GB/T 13745：14020 三级「生理、心理声学和生物声学」。家族：[讲透声学](../README.md)·信息生命群。支占位（七要件种子，内容逐支后批）。

## 诞生

Helmholtz 1863《论音的感觉》（共振理论）；Békésy 1961 Nobel（基底膜行波）；Griffin 1938 发现蝙蝠回声定位。

## 核心问题

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 耳蜗行波分频机制 | ✅ | 位置-频率映射的机械实现 |
| 响度/掩蔽/临界频带 | ✅经验 | 感知编码（MP3 等）的根据：听不见的就删 |
| 双耳定位（ITD/ILD） | ✅ | 微秒级时差检测的神经奇迹 |
| 语音与音乐感知的高层组织 | 🔄 | 心理声学最深的未竟之地 |

## 假设与依赖

听觉心理物理方法（强制选择/适应）；'听感'无第一性模型（家族裂缝二）。

- Yost《Fundamentals of Hearing》
