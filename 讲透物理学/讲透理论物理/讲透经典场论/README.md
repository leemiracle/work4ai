# 讲透经典场论 · 场作为基本对象

> **定位**：把"系统的历史"压缩成一个作用量泛函的纲领——
> 最小作用量原理+Noether 定理构成全部理论物理的写作规范，
> 量子理论与引力论都继承这套语法。
>
> GB/T 13745：14015 三级"经典场论"。家族：[讲透理论物理](../README.md)。

## 诞生

Euler/Maupertuis 18 世纪的最小作用量之争；Lagrange 1788《分析力学》
把牛顿力学改写为变分形式；Noether 1918 证明对称性⟺守恒律——
场论获得自己的宪法。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 最小作用量原理 | ✅ 已解（量子路径积分给出其"为什么"：驻相） | 全部动力学的最压缩表述 |
| Noether 定理 | ✅ 已解 | 守恒律是对称性的发票——定律的立法程序 |
| 逆变分问题（哪些方程有拉格朗日量） | 🔄 部分 | 不是所有动力学都能写成作用量——边界仍在前线 |
| 有egelund结构/多对称性系统 | 🔄 前线 | 约束系统的狄拉克分析（通往规范理论） |

## ✨ 这支最美的一个事实

Noether 定理：能量守恒不是宇宙的额外规定，只是"物理不随时间平移改变"
的自动发票——**最深的不平凡藏在最平凡的均匀性里**。

## 假设与依赖

作用量存在性（多数物理系统满足，但非逻辑必然）；变分法是数学母机
（[变分分析](../../../讲透数学/讲透分析/讲透变分分析/)）。
