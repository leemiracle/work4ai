# 讲透理论物理 · 定律的写作层

> **本质一句话**：理论物理不是"很难的物理"，而是把自然界**全部写进最少几条
> 数学定律**的事业——一个拉格朗日量换一整个世界。
>
> GB/T 13745：14015（物理学·二级"理论物理学"）。家族：[讲透物理学](../README.md)宇宙。
> 六支：数学物理·电磁场理论·经典场论·相对论·量子力学·统计物理学。

## 诞生（怎么产生的）

三幕剧：**牛顿综合**（1687，天上地下同一套定律）→ **麦克斯韦综合**（1865，光=电磁波，
但与牛顿冲突）→ **两朵乌云**（1900 Kelvin）逼出二十世纪双革命：
狭义相对论（1905，时空不绝对）与量子力学（1925-26，测量不确定）。
此后百年是"统一之路"：电弱统一（1967）→ 标准模型（1970s）→ 弦/M 理论与量子引力（进行中）。

## 核心问题清单

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 黑洞存在与引力波 | ✅ 已解（LIGO 2015 直接探测；EHT 2019 成像） | 广义相对论最强预言落定——诺奖级实验闭环 |
| 希格斯机制 | ✅ 已解（2012 CERN 发现希格斯玻色子） | 标准模型最后一块拼图：质量从哪来 |
| 贝尔不等式检验 | ✅ 已解（2015 以上 loophole-free；2022 诺奖） | 自然界真的非定域——EPR 之争实验定谳 |
| 量子引力 | ❌ 圣杯未解 | 广义相对论×量子力学在最深处冲突——弦论/圈量子引力/全息对偶三条路均未收官 |
| 测量问题 | ❌ 未解 | 波函数塌缩是物理过程还是知识更新——诠释之争近百年无实验判决 |
| 暗物质/暗能量本质 | ❌ 未解 | 宇宙 95% 的成分 unknown——理论物理最大的"账实不符" |

## 假设与代价

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 对称性原理优先 | 相互作用被规范对称**决定**（不是猜出来的） | 被对称性锁死：超对称为何不显形成为难题 |
| 拉格朗日/作用量表述 | 全部动力学浓缩一个标量泛函 | 路径积分无严格数学定义（一般情形） |
| 有效场论心态 | 每个理论声明适用能标，不必一步到位 | 终极理论是否存在被搁置 |
