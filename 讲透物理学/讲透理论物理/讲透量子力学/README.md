# 讲透量子力学 · 测量前没有答案的世界

> **定位**：20 世纪第一场物理革命——微观世界的语言：叠加、干涉、纠缠。
> 它不是"更准的经典力学"，而是换掉了"状态"与"测量"两个词的含义。
>
> GB/T 13745：14015 三级"量子力学"。家族：[讲透理论物理](../README.md)。

## 诞生

1900 普朗克量子假说（被迫的）；1905 爱因斯坦光量子；1925-26 集中爆发：
海森堡矩阵力学、薛定谔波动方程、玻恩概率诠释、狄拉克统一表述——
两年内换掉全部微观语法。1927 索尔维会议"上帝掷不掷骰子"开战，至今余音。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 形式体系完备性 | ✅ 已解（von Neumann 1932 公理化） | 语法无歧义——争议全在诠释 |

| 测量问题 | ❌ 未解 | 塌缩是物理还是知识？诠释之争近百年无实验判决 |

## ✨ 这支最美的一个事实

双缝实验：电子"同时走两条路"自己与自己干涉；一旦看它走哪条，干涉立刻消失——
**问一个"哪条路"的问题，就杀死"都走"的答案**。费曼说它藏着量子力学唯一的奥秘。

## 假设与依赖

四公设（态=希尔伯特空间矢量/演化=酉/测量=玻恩规则/复合=张量积）；
线性性是命门（也是量子计算威力的来源）。前置：线性代数（母语）、
[泛函分析](../../../讲透数学/讲透分析/讲透泛函分析/)（无限维严格化）。
