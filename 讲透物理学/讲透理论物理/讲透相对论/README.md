# 讲透相对论 · 时空不是舞台而是演员

> **定位**：狭义（1905）动"同时性"，广义（1915）动"引力=几何"——
> 相对论把时空从背景提升为动力学变量，是理论物理最大胆的一次地基改造。
>
> GB/T 13745：14015 三级"相对论"。家族：[讲透理论物理](../README.md)。

## 诞生

爱因斯坦 1905 狭义相对论：为保麦克斯韦方程动牛顿的绝对时间；
1907"一生最快乐的想法"（等效原理：自由下落者感觉不到引力）；
1915 广义相对论：引力=时空弯曲。百年验证链：水星进动→光线弯折→
引力波（LIGO 2015）→黑洞成像（EHT 2019）。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 引力波存在 | ✅ 已解（2015 直接探测，2017 诺奖） | 强场广义相对论通过最严检验——时空真的会涟漪 |
| 黑洞视界成像 | ✅ 已解（EHT 2019/2022） | 广义相对论的"暗"预言变成照片 |
| 引力的量子化 | ❌ 圣杯 | 与量子力学的语法冲突——理论物理最深裂缝（家族 README 核心问题表） |
| 宇宙学常数问题 | ❌ 未解 | 真空能的理论值与观测值差 ~120 个数量级——史上最失败的理论预言 |

## ✨ 这支最美的一个事实

广义相对论的全部内容可以写成一行：$G_{\mu\nu} = 8\pi T_{\mu\nu}$——
"物质告诉时空怎么弯，时空告诉物质怎么走"（惠勒语录），
一个张量方程替换掉牛顿的"力"概念。

## 假设与依赖

广义协变原理（物理定律在任意坐标变换下形式不变）；
等效原理（局部引力=加速度）；几何语言依赖[微分几何](../../../讲透数学/)
（度规/联络/曲率——爱因斯坦为引力论现学了黎曼几何）。
