# 讲透电磁场理论 · 第一个场论

> **定位**：麦克斯韦方程组——人类第一个"场"理论：作用通过空间逐点传递，
> 光被识破为电磁波。它是所有规范理论的模板。
>
> GB/T 13745：14015 三级"电磁场理论"。家族：[讲透理论物理](../README.md)。

## 诞生

Faraday 用力线直觉推翻超距作用；Maxwell 1865 年把力线写成四组方程，
预言电磁波并以波速=光速识破光的身份；Hertz 1887 实验证实——
理论-实验-技术的三连击模板。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 电磁波=光 | ✅ 已解（Maxwell 1865/Hertz 1887） | 第一次大统一：光学并入电磁学 |
| 规范结构（U(1)） | ✅ 已解 | 电磁力=最小规范群的执法成本——后世全部规范理论的母版 |
| 磁单极存在性 | ❌ 未解 | 找到则解释电荷量子化（Dirac 1931 论证）；至今零俘获 |
| Aharonov-Bohm 效应 | ✅ 已解（理论 1959/实验 1960） | 势比场更基本——"不可积相因子"进教科书 |

## ✨ 这支最美的一个事实

方程组无源解的波速恰好等于光速——Maxwell 写下方程的那晚，
三种千年互不相认的现象（电、磁、光）被一行速度常数统一。

## 假设与依赖

线性叠加原理（真空麦克斯韦）；经典近似（光子数大、量子修正可忽略——
量子版归量子电动力学 QED）。前置：矢量分析、[经典场论](../讲透经典场论/)的作用量语言。
