# 讲透数学物理 · 物理定律的数学骨架

> **定位**：给物理理论做"数学质检"的分支——定律背后的方程何时适定、
> 解何时存在、谱何时离散。它是希尔伯特第 6 问（物理公理化）的正主。
>
> GB/T 13745：14015 三级"数学物理"。家族：[讲透理论物理](../README.md)。

## 诞生

Hilbert 1900 年第 6 问"物理公理的数学处理"；Weyl 与 von Neumann 在 1920s
给刚出生的量子力学配上希尔伯特空间语法；Courant-Hilbert《数学物理方法》
两卷成为代代教材母本。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 量子力学公理化 | ✅ 已解（von Neumann 1932） | QM 有严格数学语法——分支里公理化最成功者 |
| 算子谱与测量 | ✅ 已解（谱定理） | "可观测量=自伴算子、测量值=谱点"有了定理级根据 |
| QFT 的严格构造（4 维交互） | ❌ 未解（=Clay 千禧 YM 问题核心） | 量子场论至今没有完整数学户口 |
| 可积系统理论 | 🔄 部分 | "为什么这些方程恰好可解"仍是结构之谜 |

## ✨ 这支最美的一个事实

自伴算子的谱定理：把"可能测到哪些值"从实验问题变成纯数学问题——
**物理学的可观测性 = 泛函分析的谱**。

## 假设与依赖

站在 [泛函分析](../../../讲透数学/讲透分析/讲透泛函分析/)（算子理论母机）与
[偏微分方程](../../../讲透数学/讲透分析/讲透偏微分方程/)（适定性语言）上；
对物理理论的"数学化"是理想化——多数活跃物理工作并不等待严格化。
