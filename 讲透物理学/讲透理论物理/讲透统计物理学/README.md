# 讲透统计物理学 · 从微观到宏观的桥

> **定位**：$10^{23}$ 个微观自由度折叠成温度、压强、熵的科学——
> "温度是什么"的唯一严格答案在这里：概率分布的参数。
>
> GB/T 13745：14015 三级"统计物理学"。家族：[讲透理论物理](../README.md)。

## 诞生

Boltzmann 1877：熵=微观态计数 $S = k\log W$（刻在墓碑上）；
Gibbs 系综理论（1902）把"一个系统"换成"全同系统的概率分布"；
Wilson 1970s 重整化群把统计物理变成相变的普适理论——
三次跃迁：从热现象到概率，到分布，到尺度流。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 熵的微观解释 | ✅ 已解（Boltzmann/Gibbs） | 时间之箭=概率，不是新定律 |
| 相变与普适类 | ✅ 已解框架（Wilson RG，1982 诺奖） | 微观不同的系统共享临界指数——宏观忘记微观 |
| 非平衡态统计力学 | 🔄 部分（涨落定理/大偏差已成型） | 生命系统、活性物质的前线——"时间之箭的动力学" |
| 玻璃态本质 | ❌ 未解 | 最老的未解相变问题——"结构像液体、力学像固体"无共识理论 |
| 高温超导机制 | ❌ 未解 | 1986 年发现至今无公认理论——凝聚态最强悬案（→[凝聚态物理](../../讲透凝聚态物理/)） |

## ✨ 这支最美的一个事实

普适性：液气临界点、磁体相变、合金有序化——微观完全不同，
临界指数却相同到小数第三位。**大自然在临界点只记得维度和对称性，
忘掉其余一切**——这是统计物理最深的结构定理。

## 假设与依赖

等概率假设（微正则系综：孤立平衡态各微观态等概率——无法从力学导出，
是统计的独立公设）；遍历假设（时间平均=系综平均，多数系统"大概成立"）。
前置：概率论、[量子力学](../讲透量子力学/)（量子统计）。
