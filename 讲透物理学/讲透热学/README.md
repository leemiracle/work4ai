# 讲透热学 · 能量流动与转化的科学

> **热学 = 研究能量以"热"的形式如何流动与转化的科学**——温度、热量、熵的学科。
> 它从蒸汽机的效率之问长出来，用四大定律回答"什么过程可能发生"，
> 用三模式（传导/对流/辐射）回答"热往哪跑、跑多快"。
>
> GB/T 13745：14025（物理学·二级学科）。宇宙：[讲透物理学](../README.md)（2026-09-07 GB13745 扩展波2 建族）。

## 〇、家族树

```
讲透热学/
├── 讲透热力学/      公理层：四大定律·熵·势·循环（"什么可能发生"的宪法）
├── 讲透热物性学/    材料层：热导率·热容·热膨胀·相变焓（每种材料的热性格）
└── 讲透传热学/      输运层：传导·对流·辐射（"热往哪跑跑多快"的动力学）
```

三层分工一句话：**热力学判案（能不能）、传热学算账（多快）、热物性学供弹药（用什么数）**。

## 一、诞生

蒸汽机开出三问：①效率有没有上限（卡诺 1824）②热到底是什么（焦耳 1845 热功当量，
热质说死刑）③一杯咖啡为什么自己凉、从不自己热（克劳修斯 1865 熵）。
傅里叶 1807 为研究热传导发明傅里叶级数——**热学问题催生了整个调和分析**
（见 [讲透数学·调和分析](../../讲透数学/讲透分析/讲透调和分析/)）。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 卡诺效率上限（1824） | ✅ 已解 | 不知道热是什么就算对了效率天花板——只依赖"有高温有低温" |
| 熵增定律（1865） | ✅ 已解 | 给"时间之箭"定了物理方向：唯一带时间不对称的基本定律 |
| 绝对零度不可达（能斯特 1906/1912） | ✅ 已解 | 第三定律：可无限逼近、永不能到达 |
| 负温度系统（Purcell-Pound 1951） | ✅ 已解 | β=1/T 视角下负温度比 +∞ 还"热"——温度定义反转的教材级反例 |
| 湍流对流封闭 | ❌ 未解 | 对流换热系数至今靠实验关联式，不是推导——工程热学的圣杯缺口 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 连续介质 | 傅里叶定律/NS 方程可用 | 纳米尺度失效（声子弹道输运，见 01 章） |
| 局域平衡 | "局部温度"有意义 | 远离平衡（激波/燃烧）处失效 |
| 近线性输运 | 傅里叶/菲克/牛顿冷却三定律 | 高热流密度下非线性热导 |
