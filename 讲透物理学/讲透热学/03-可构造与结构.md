# 03 · 可构造与结构：势的生成器与四大定律的刚性

> **本章回答五问之四（本支：讲透热学）。** 可构造？结构？
> 热学的可构造性 = **知道一点点，就能造出整套热力学势**（状态方程+一个热容 ⟹
> U/H/F/G 全家族）；热学的结构 = **Legendre 变换的对称群 + Maxwell 关系的恒等式网**——
> 一个"输入极少、输出极多"的构造学范本。

---

## 一、可构造：从两个输入造出整座势的大厦

### 1.1 直觉：热力学势的"生成器"

**最小输入**：①状态方程 p(T,V)（如理想气体 pV=nRT）②一个热容（如 C_V(T)）。
**生成器**：dU = TdS − pdV + μdN（热力学基本等式）。
**输出**：内能 U、焓 H=U+pV、亥姆霍兹自由能 F=U−TS、吉布斯自由能 G=U+pV−TS
——四个势全部可构造，加上全部偏导数（T、p、S、V 互相的导数关系）。

**为什么这算"可构造"的典范**：实验上只需测两个函数（可测！），
理论机器自动吐出**这个物质全部的平衡态热力学**——磁化、表面张力、
化学反应平衡常数（van't Hoff）、相变线（Clausius-Clapeyron）……
输入输出比在物理学科里名列第一（对比：凝聚态要算能带才能出热容）。

**最小具体例子**（理想气体全程手推三行）：
```
dU = C_V dT（理想气体 U 只依赖 T）
H  = U + pV = U + nRT   ⟹ C_p = C_V + nR   （一句推出 C_p−C_V=nR）
S  = ∫C_V dT/T + nR ln V （熵显式构造完成）
```
到这一步，四个势全部闭式可写。这就是"热力学=换坐标的机器"的全部含义。

✨ **美之时刻 ①：Clausius-Clapeyron 方程**
陈述：相图中相界线斜率 dp/dT = L/(TΔV)，只用"两相平衡时化学势相等"一步导出。
为什么美：**极简**——不知道任何物质的潜热数值，却给出了所有物质相图的
普适斜率公式；气象学用它算"海拔每升高 100m 沸点降 ~3°C"，冰川学用它算冰的熔点随压强。
怎么亲历：用 L=2.26MJ/kg、T=373K、ΔV≈1.7m³/kg 代入，得 dp/dT ≈ 3.6 kPa/K——
和标准大气 1km 降 ~10kPa 对上，沸点降 ~2.8°C。

### 1.2 可构造清单（分级）

| 可构造 | 输入 | 方法 | 输出 |
|--------|------|------|------|
| ✅✅ 全套热力学势 | EOS + C_V | 基本等式积分 | U/H/F/G 及全部偏导 |
| ✅✅ 相图 | 势的全家比较 | 每点取最小势的相 | p-T 相图全图 |
| ✅ 循环效率曲线 | 工质物性 | 逐过程记账 | 热泵 COP/发动机 η |
| ✅ 辐射场 | T | 普朗克分布 | 光谱+总功率 |
| ⚠️ 对流换热系数 | 几何+流态 | 关联式拟合（半构造） | h（±20% 就是好关联式） |
| ❌ 湍流 h 第一性计算 | — | 未封闭 | — |
| ❌ 非平衡势 | — | Onsager 区外无定义 | — |

**反直觉发现**：⎧越接近"定律层"越可构造，越接近"输运层"越靠拟合⎫——
可构造性与离平衡的距离成反比，不是与技术难度成正比。

## 二、结构：对称生成的恒等式网

### 2.1 Legendre 变换群：一座山的四个坐标系

**直觉图像**：U(S,V) 是一座山。你可以换坐标描述同一座山：
用"山的斜率"代替"山的自变量"——H(S,p)、F(T,V)、G(T,p)。
**四个势 = 同一座山的四张地图**，信息完全等价，选哪张只看实验条件
（实验室恒 T 恒 p？→ G 是你最省事的地图）。

**为什么这是"结构"**：Legendre 变换不增不减信息——它是一族**精确可逆的重参数化**。
"哪个势最小决定稳定相"在四张地图上说法一致（结构刚性来自变分原理：
稳定态 = 相应自然变量下势的极小）。

### 2.2 Maxwell 关系：对称性的利息

**直觉**：S(V,T)ₜ 这类混合二阶偏导与求导次序无关（Schwarz 定理）——
把 1.1 的势代入，立刻得到四条"免费"恒等式：

```
(∂T/∂V)_S = −(∂p/∂S)_V        (∂T/∂p)_S = (∂V/∂S)_p
(∂S/∂V)_T = (∂p/∂T)_V          (∂S/∂p)_T = −(∂V/∂T)_p
```

**为什么美（✨美之时刻 ②）**：**统一**——左边是"熵随体积怎么变"（难测！
熵没有熵计），右边是"压强随温度怎么变"（好测，一支温度计一支压力表）。
Maxwell 关系把**不可测量翻译成可测量**，是热力学实验与理论的换汇通道。
怎么亲历：用它推 (∂S/∂p)_T = −(∂V/∂T)_p = −Vα——测热膨胀系数 α 就得到
"加压时熵怎么变"，不用任何熵的直接测量。

📖 **故事框：记忆术的文化层**
Maxwell 关系的记忆口诀流传了上百年（"Good Physicists Have Studied Under Very Fine Teachers" 的方阵记忆法）——
一个学科需要记忆术，恰说明它结构的规整：四条关系出自同一个 Schwarz 对称，
不是四件独立的事实。

### 2.3 结构刚性的三个来源

| 来源 | 刚性表现 |
|------|---------|
| 变分原理（势极小=稳定） | 相变点=两势相等——一级相变的全部行为由势的几何决定 |
| 量纲/标度（对应态原理） | 不同物质按临界参数归一后落在同一曲线族（van der Waals 普适性） |
| 微观对称（统计物理输入） | 吉布斯佯谬的消解依赖全同粒子对称——宏观恒等式背后有微观刚性 |

**反直觉第二击（吉布斯佯谬）**：两种气体混合，熵增公式给出一个值；
同种气体"混合"，熵增应为零——但宏观公式分不出这两种情况！
必须**微观地**知道"是不是同一种粒子"才能算对宏观熵。
一个 10²³ 尺度的量，敏感性竟能到单粒子的全同性——宏观结构藏着微观底牌。

## 五、不足层

- 势机器只覆盖平衡态；非平衡态的"势"（如超导/激光的工作态）要靠最大熵产生
  等原理性猜想，规范度远低

  热力学机器的进料口堵在别家
- Maxwell 关系的教学常止于推导，缺"难测→好测"的换汇直觉（本章补救）
