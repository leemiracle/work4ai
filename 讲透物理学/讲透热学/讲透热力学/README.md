# 讲透热力学 · "能不能发生"的判案宪法

> 这支负责：**四大定律 + 态函数演算 + 循环分析**——不问热跑多快，
> 只裁决过程可不可能、上限在哪里。公理层，家族的大脑。

## 诞生

1824 卡诺（效率上限，热质说时代）→ 1850 克劳修斯/开尔文（第二定律两种表述）→
1865 熵命名 → 1960 Callen 公理化收官（四条熵公理挂起全学科，见家族 [02 章](../02-语言特征.md)）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 卡诺效率上限 / 熵增 / 三定律 | ✅ 已解（判案体系完备） |
| 㶲（能量品质）分析框架 | ✅ 已解（教育普及欠账） |
| 非平衡态热力学一般理论 | ❌ 未解（Onsager 近平衡区是唯一规范区） |

## ✨ 这支最美的一个事实

卡诺在**错误的热质说**框架下算出了**正确的**效率上限 η=1−T_c/T_h——
错的物理直觉、对的数学结构；后来热质被埋葬，定理纹丝不动。

## 假设与依赖

平衡态+局域平衡（远离平衡时"温度"失效）；不依赖任何微观模型（这正是它
作为一切热工计算的"最后上诉法院"的资格）。

## 教材锚

Callen《Thermodynamics and an Introduction to Thermostatistics》（公理化正典）；
Zemansky《Heat and Thermodynamics》。
