# 04 · 热学转代码：从势生成器到芯片热设计

> **本章回答五问之五（本支：讲透热学）。**
> 热学资产的代码化分四条走廊：**物性库（势生成器的工程化）→ 传热求解器
> （傅里叶定律的数值化身）→ 热阻网络（电路类比，热设计的日常武器）→
> 辐射/蒙特卡洛（几何+光谱计算）**。可机械化边界清晰得罕见：
> 平衡态与传导几乎全自动，湍流对流卡在物理未封闭，非平衡基本无门。

## 一、四条走廊总表

| # | 走廊 | 输入→输出 | 代表工具/方法 | 自动化档位 |
|---|------|----------|--------------|-----------|
| 1 | 物性库 | (T,p,组分)→任何热力学量 | CoolProp（IAPWS-95 等 EOS 标准） | ✅ 全自动 |
| 2 | 传热求解器 | 几何+边界条件→温度场 | FTCS/FEM/FVM/有限体积（OpenFOAM 系） | ✅ 全自动（湍流模型除外） |
| 3 | 热阻网络 | 功耗+网络拓扑→结温 | 欧姆定律类比（Spice 热网络/RC ladder） | ✅ 全自动，秒级 |

## 二、逐条速写

### 走廊 1：物性库——03 章"势生成器"的一行流

```python
from CoolProp.CoolProp import PropsSI
h = PropsSI('H', 'T', 400, 'P', 101325, 'Water')   # 400K 水@1atm 的焓，J/kg
s = PropsSI('S', 'T', 400, 'Q', 1,   'Water')      # 饱和蒸汽熵
```

背后是 03 章的构造学：IAPWS-95 = 国际标准化的"EOS+热容→全部势"机器。
**为什么是这样**：热力学平衡态的可构造性（03 章 1.1）保证了这条走廊
可以做成纯函数库——确定性、无网格、无拟合残留。

**循环分析**（热泵/朗肯循环）= 走廊 1 的组合调用：四个状态点 +
两个过程查表（等熵/等压），COP/效率两行算出——"热力学判案"的代码形态。

### 走廊 2：传热求解器——本章实验主场

**直觉**：热方程 ∂u/∂t = α ∂²u/∂x² 的显式格式 FTCS：

```
u_i^(n+1) = u_i^n + r·(u_{i+1}^n − 2u_i^n + u_{i-1}^n),   r = αΔt/Δx²
```

**宪法**：r ≤ 1/2 才稳定（CFL 条件）——这不是数值技巧，是抛物型 PDE 的
物理因果性（信息传播速度）在离散世界的法典（详见
[讲透数学·偏微分方程](../../讲透数学/讲透分析/讲透偏微分方程/)）。

本家族实验 [experiments/heat_conduction_ftcs.py](experiments/heat_conduction_ftcs.py)
做两件那边的 heat_cfl.py 没做的事：
①**收敛阶实测**（L2 误差随网格加密的斜率——验证 FTCS 时间一阶/空间二阶）；
②**物性量纲全程显式**（α 单位 m²/s、域长 m——工程代码的第一纪律）。

**工业档位**：FVM（有限体积，保证守恒到离散级）是 CFD 商软/开源
（OpenFOAM/fluent）的标准内核；FEM 在结构-热耦合（芯片封装翘曲）占优。

### 走廊 3：热阻网络——电路类比的降维打击

**直觉**：稳态传导 q = ΔT·(kA/L) 与欧姆定律 I = ΔV/R 同构：

```
温度差 ΔT ↔ 电压    热流 Q ↔ 电流    热阻 R_th = L/(kA) ↔ 电阻
热容 C = mc ↔ 电容  （瞬态 = RC 阶梯，"热时间常数" = R_th·C）
```

**为什么工程师人手一套**：芯片→管壳→散热器→环境的每一段都是热阻，
串并联组合出结-环境总热阻，结温 = 功耗 × 总热阻 + 环境温——**一页纸算完
一整套散热方案**，是概念设计阶段的秒级武器（FEM 精算前的 80/20）。

**最小例子**（你的主场）：GPU 300W，结-壳热阻 0.15 K/W，壳-散热器 0.05，
散热器-环境 0.10 → T_junction = 300×0.30 + 25 = **115°C**——超典型上限 95°C，
结论：要么降功耗要么砍热阻，一步看出设计缺口。

### 走廊 4：辐射计算

- 角系数代数：封闭腔内 F₁₂ 互易性/守恒式，解析可得（房间/炉膛级）
- 蒙特卡洛光线追踪：复杂几何发光子数命中（航天器/卫星热设计标准做法）
- 光谱积分：普朗克函数 × 发射率谱 × 大气窗口——01 章辐射制冷的设计计算本体

## 三、可机械化边界（热学的特色：边界即物理）

| 任务 | 档位 | 边界由谁把守 |
|------|------|-------------|
| 平衡态物性/循环 | 全自动 | 03 章势机器（物理已解决） |
| 导热（线性） | 全自动 | 热方程适定性（数学已解决） |
| 共轭传热（层流） | 全自动 | NS+能量方程联解 |
| **湍流对流** | 半自动 | **物理未封闭**——RANS/LES 是带模型误差的近似，重要场合要实验校核 |
| **非平衡过程** | 基本无门 | 局域平衡失效，理论本身缺位 |
| 相变的界面追踪 | 半自动 | 数值上 Stefan 条件可用 level-set/enthalpy 法，但物性跳变+网格各向异性要小心 |

**为什么热学的边界特别清晰**：可机械化程度与"离平衡多远"严格单调——
这是 02 章公理/方言分界的代码投影。

## 四、工程师落点（性能工程视角）

1. **芯片热设计 = 性能的地基**：功耗墙/热节流是算力上限的一半（01 章纳米传热的
   工程缘由）；3D 堆叠的堆叠间热阻直接决定可堆几层
2. **热阻网络是每秒级的 profiler 思维**：先粗模型定位瓶颈、再精模型算准——
   和性能分析"先火焰图后微基准"同构
3. **FTCS/CFL 是数值稳定的通用教案**：显式格式的稳定性代价（时间步受网格平方限制）
   在任何领域重演——DP 训练中的梯度爆炸、控制系统的采样率，同款直觉
4. **数据中心级**：PUE 的热力学账本（卡诺电池/余热利用是 01 章方向四）——
   机房散热是"最大规模的热学工程问题"
