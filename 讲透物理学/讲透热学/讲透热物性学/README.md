# 讲透热物性学 · 材料的热性格档案

> 这支负责：**热导率、热容、热膨胀、发射率、相变焓**——热工计算的弹药库。
> 每个物性背后都有微观机制（声子/电子/光子谁在搬运），材料层，家族的仓库。

## 诞生

物性测量与工业革命同步（锅炉钢的强度-温度表救了 19 世纪锅炉工的命）；
20 世纪微观化：Debye 1912 声子比热理论、Wiedemann-Franz 电子导热-导电关联；
21 世纪计算化：从第一性原理预测 k(T)。

## 核心问题

| 问题 | 状态 |
|------|------|
| 声子比热/热导的微观理论（德拜/声子气体） | ✅ 已解（常规材料定量） |
| 超低/超高热导材料设计（金刚石级/气凝胶级） | 🔄 前线（纳米结构声子工程，见家族 [01 章](../01-近五年创新.md)） |
| 强关联/非晶热输运统一理论 | ❌ 部分未解（非晶热导的"最小热导"之争） |

## ✨ 这支最美的一个事实

**金刚石热导率（~2200 W/m·K）是铜的 5 倍，却是电绝缘体**——
轻原子+强键让声子跑得比金属电子还快。"导热好必须导电好"只是金属宇宙内的经验律。

## 假设与依赖

声子气体图像（晶格振动量子化）；驰豫时间近似（输运系数可定义）；
纳米尺度两假设均松动——家族三层中离"失效即前沿"最近的支。

## 教材锚

Kittel《固体物理》热学章；Berman《Thermal Conduction in Solids》。
