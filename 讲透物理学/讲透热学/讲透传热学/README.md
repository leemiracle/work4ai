# 讲透传热学 · "热往哪跑跑多快"的动力学

> 这支负责：**传导/对流/辐射三模式 + 换热器设计**——温度场的时空演化。
> 输运层，家族的腿。热学家族离工程最近的一支。

## 诞生

1807 傅里叶《热的传播》（热方程+傅里叶级数，调和分析的出生证明，链
[家族 00 章](../00-体系结构.md) 故事框）；1701 牛顿冷却（对流唯象起点）；
1900 普朗克（辐射封顶）；Nusselt 1915 量纲分析立对流方法论。

## 核心问题

| 问题 | 状态 |
|------|------|
| 热方程适定性/数值格式（FTCS-FEM 谱系） | ✅ 已解 |
| 层流解析解（Poiseuille-Couette 族） | ✅ 已解 |
| **湍流对流封闭**（h 的第一性计算） | ❌ 未解——关联式文化代偿（家族最老的圣杯缺口） |
| 近场辐射突破黑体极限的工程化 | 🔄 前线（纳米间隙光子隧穿，[01 章](../01-近五年创新.md)） |

## ✨ 这支最美的一个事实

**辐射传热不需要任何介质**——太阳隔着一亿五千万公里的真空把地球晒热。
同一支里最慢的模式（传导靠分子碰撞接力）和最快的模式（辐射以光速）共用一个能量守恒账本。

## 假设与依赖

傅里叶定律（近线性输运）；连续介质（纳米尺度失效=声子弹道区）；
湍流模型（RANS/LES 带模型误差——传热计算"最后两个 9"的守门人）。
