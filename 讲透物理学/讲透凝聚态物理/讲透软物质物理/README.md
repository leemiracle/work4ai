# 讲透软物质物理 · 生命的物理学

> 这支负责：**柔软的物质**——高分子、液晶、胶体、表面活性剂、膜。
> 你身体里除骨骼外的几乎所有物质都是软物质；de Gennes 说它是"复杂流体的简单物理"。
>
> GB/T 13745：14050 三级"软物质物理学（原液晶物理学）"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

液晶 1888 Reinitzer（胆甾相双熔点之谜）；高分子物理 1930s-50s
（Flory/Kuhn：链的熵弹性和自回避行走）；de Gennes 1991 诺奖把三块合成
"软物质"学科——他用临界现象的普适语言统一了聚合物与液晶。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 高分子链统计（SAW 标度） | ✅ 已解（Flory/de Gennes） | 链尺寸 R~N^ν，ν 由维度与排除体积决定 |
| 液晶相的分类学 | ✅ 已解（向列/近晶/胆甾+序张量理论） | 各向异性流体的完备语法（LCD 的物理） |
| 胶体结晶与熵力 | ✅ 已解 | "硬球无相互作用也能结晶"——熵驱动有序 |
| 膜与自组装 | ✅ 基本已解 | 双亲分子为何自己长成细胞膜形状 |
| 活性物质（游动细菌/细胞骨架） | 🔄 前线 | 打破细致平衡的"活性软物质"统计物理 |
| 蛋白质折叠的物理 | ❌ 未彻底 | 软物质物理最硬的堡垒 |

## ✨ 最美的一个事实

**熵力**：把硬球胶体挤到一定浓度，它们自发排成晶体——球之间没有任何
吸引力，驱动有序的是**系统其余自由度的熵**（给小球让出更多可及空间）。
"无序产生有序"最赤裸的演示：有序的代价由别处的无序买单。
