# 讲透凝聚态物理 · 10²³ 个粒子如何商量出相变

> 凝聚态物理：**大量粒子聚集后涌现的新规律**——10²³ 个原子谁也不认识谁，
> 却能集体决定"今天是磁铁"或"今天是超导体"。它是物理最大家族（从业者过半），
> 也是**离芯片、电池、量子计算最近**的物理。

## 〇、家族定位（本质一句话）

一个铜原子不导电也不反光——"导电""反光""超导"都是**亿万原子的集体行为**。
凝聚态物理就是研究这种集体行为如何从微观规则中**涌现**，又如何被温度、压力、
掺杂、维度这些旋钮拧来拧去。它把"多体问题"从灾难变成了金矿。
