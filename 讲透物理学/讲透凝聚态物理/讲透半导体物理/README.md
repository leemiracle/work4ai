# 讲透半导体物理 · 能隙工程——芯片文明的物理层

> 这支负责：**把能隙当旋钮拧**——掺杂、pn 结、MOSFET。
> 你正在用这台设备读这段话，物理原理就在这支里。
>
> GB/T 13745：14050 三级"半导体物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1947 贝尔实验室晶体管（Bardeen-Brattain-Shockley，1956 诺奖）；
1960 平面工艺+集成电路（Kilby/Noyce，2000 诺奖）——半导体的历史就是
信息文明的硬件史。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| pn 结与整流理论 | ✅ 已解（1940s-50s） | 一个结=一个二极管，一切固态电子学的细胞 |
| MOSFET 缩放定律 | ✅ 已解（1974 Dennard）五十年验证 | "晶体管每两年小一半"的物理契约（现已终结） |
| 激光二极管/LED | ✅ 已解（1962/1989 蓝光中村，2014 诺奖） | 直接带隙复合发光=照明与光通信革命 |
| 欧姆接触/界面态控制 | ✅ 已解（工程化） | 实用化的真正瓶颈曾是"金属摸上去不漏" |
| 亚 1nm 沟道与新沟道材料 | 🔄 前线 | 2D 材料/CFET——摩尔定律续命竞赛 |
| 热载流子/自旋输运极限 | 🔄 前线 | 器件物理的下一层天花板 |

## ✨ 最美的一个事实

**掺杂十亿分之一**就足以把硅从绝缘体调成导体——在 10⁹ 个硅原子 里
换 1 个磷原子，电导率涨百万倍。化学配比意义上的"杂质"，物理意义上的
"主角"：载流子浓度是半导体最灵敏的旋钮。

## 假设与依赖

有效质量近似；载流子统计（费米分布的玻尔兹曼极限）；能带论的弱关联有效性。
