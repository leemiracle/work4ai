# 讲透量子调控 · 用相干性做计算的物理

> 这支负责：**量子态的制备、操控与读出**——量子比特、门操作、纠错。
> 它是凝聚态物理与量子信息工程的接口层：本支给"量子计算机"提供硬件物理。

## 诞生

1995 Shor 算法+量子纠错码（理论立项）；1999 超导量子比特首次实现
（Nakamura）；2019 谷歌"量子优越性"（Sycamore）；2024- 谷歌 Willow
宣称纠错阈值之下（逻辑比特随码距增大而变好）——凝聚态工程的长跑兑现。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 退相干的物理来源 | ✅ 主要已解 | 噪声谱学：1/f 噪声/准粒子/光子损耗各有对策 |
| 超导/transmon 比特 | ✅ 已解（工程成熟） | 非线性 LC 电路=人工原子，可扩展性最好 |
| 量子纠错阈值定理 | ✅ 已解（理论 1996-97） | 物理错误率低于阈值→任意长计算可行 |
| 表面码达到阈值 | 🔄 2024- 宣告跨越 | 大规模逻辑比特的工程长跑刚开始 |
| 比特间串扰与规模化布线 | ❌ 工程未闭环 | 千-百万物理比特的真正瓶颈 |
| 拓扑量子比特 | ❌ 未实现 | Majorana 零模候选仍待确证（微软路线） |

## ✨ 最美的一个事实

**量子纠错把"错误"变成"可编码的信息问题"**：不阻止错误发生，而是用
几十个脆弱的物理比特"投票"保护一个稳健的逻辑比特——只要错误率低于阈值
（~1%），加比特反而让逻辑错误率**指数下降**。2024-25 的实验第一次
看到"加码距、错更少"的曲线拐头：**用数量对抗质量的哲学第一次跑赢**。
