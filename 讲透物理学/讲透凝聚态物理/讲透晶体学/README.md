# 讲透晶体学 · 原子周期性排布的完备分类学

> 这支负责：**周期性本身**——230 空间群、X 射线衍射、结构测定。
> 一切能带论的地理前提（没有晶格就没有 Bloch 定理）。
>
> GB/T 13745：14050 三级"晶体学（包括晶体生长、晶体化学等）"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1912 von Laue 发现 X 射线衍射（晶格=天然光栅，1914 诺奖）；
Bragg 父子 1913 解出第一个晶体结构（NaCl，1915 诺奖）；
230 空间群 1891 已由 Fedorov/Schoenflies 纯数学推出——**分类先于观测二十年**。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 230 空间群完备分类 | ✅ 已解（1891） | 三维周期性的全部可能，无第 231 种 |
| 结构测定（相位问题） | ✅ 已解（直接法，1985 诺奖 Hauptman-Karle） | 从衍射强度反推原子坐标的算法 |
| 蛋白质晶体学 | ✅ 已解（方法学，1962/2003 诺奖链） | 分子生物学的物理引擎 |
| 准晶 | ✅ 已解（1984 Shechtman，2011 诺奖） | 五重对称"不可能"却存在——周期性边界外的第一块领土 |
| 预测任意化学式的晶体结构 | 🔄 AI 时代快进中 | 见家族 [03 章](../03-可构造与结构.md) |

## ✨ 最美的一个事实

**衍射即傅里叶变换**：晶体的衍射图样=电子密度的傅里叶系数（结构因子）。
拍一张衍射照片=对 10²³ 个原子做了一次大自然自带的大规模并行傅里叶分析——
晶体学是[../../讲透数学/讲透分析/讲透调和分析/](../../../讲透数学/讲透分析/讲透调和分析/)最老的工程应用。

周期性假设（准晶/非晶是它的两块界外领土）；弱相位物体近似（电子衍射需修正）。
