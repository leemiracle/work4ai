# 讲透凝聚态理论 · 家族的总骨架

> 这支负责：**给整个凝聚态家族提供理论语言**——能带、声子、准粒子、
> 对称破缺、格林函数，全部概念军火库的产地。它是 17 支的"理论首都"。
>
> GB/T 13745：14050 三级"凝聚态理论"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

Bloch 1928（周期势中电子）、Landau 1937（相变统一语言）、Landau 1956
（费米液体：相互作用系统仍像自由系统）——三个"语言发明时刻"立起这支。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 能带论与金属分类 | ✅ 已解（1928-33） | 一切导电性的分类学 |
| Landau-Ginzburg-Wilson 范式 | ✅ 已解（1937/1971） | 常规相变的万能钥匙（诺奖×2） |
| 费米液体理论 | ✅ 已解（1956） | 为什么"电子气"概念在金属里成立 |
| 非费米液体/奇异金属 | ❌ 未解 | 铜氧化物正常态不服从费米液体——高温超导的锁 |
| 拓扑序的完备分类 | 🔄 前线 | 长程纠缠的数学分类仍在进行 |

## ✨ 最美的一个事实

朗道十万个原子没人指挥也能选出同一个磁化方向——**对称破缺**这个概念
同时解释了磁铁、晶体、超流和宇宙早期（希格斯机制同款结构）：
一支理论语言跨界到粒子物理与宇宙学。

## 假设与依赖

低能/长波假设（有效理论只在此窗口合法）；绝热连续性（费米液体的根基）。
前置：量子力学+统计物理（[讲透理论物理](../../讲透理论物理/)）。
