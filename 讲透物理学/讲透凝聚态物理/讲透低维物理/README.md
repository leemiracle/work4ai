# 讲透低维物理 · 降维打击的新相

> 这支负责：**把维度当旋钮**——量子霍尔、石墨烯、纳米管/线。
> 降低维度不是缩小系统，是**改变哪些现象被允许**（Mermin-Wagner 禁令、
> 分数量子霍尔、任意子——全是二维特供）。
>
> GB/T 13745：14050 三级"低维物理"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1980 von Klitzing 整数量子霍尔效应（1985 诺奖）——二维电子气在强场下
电阻量子化到 10⁻⁹ 精度；1982 崔琦-施特默分数量子霍尔（1998 诺奖）；
2004 Geim-Novoselov 胶带撕出石墨烯（2010 诺奖）——低维三连击定义了这支。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 整数量子霍尔（TKNN 拓扑解释） | ✅ 已解（1982 Thouless 等，2016 诺奖） | 电阻量子化=拓扑不变量（陈数）首次登场 |
| 分数量子霍尔与任意子 | ✅ 已解（Laughlin 波函数，1998 诺奖） | 分数电荷+统计缠结——新的粒子可能性 |
| 石墨烯的狄拉克锥 | ✅ 已解 | 电子在石墨烯里质量为零——"桌面上的粒子物理" |
| 二维超导/磁性极限 | 🔄 前线 | Mermin-Wagner 边界上的工程 |
| 任意子拓扑量子计算 | 🔄 前线 | 非阿贝尔任意子的编织=量子门（见家族 01 章） |
| 转角石墨烯平带工程 | 🔄 前线 | moiré = 设计相互作用强度的新旋钮 |

## ✨ 最美的一个事实

**量子霍尔电阻的精度**：R_K = h/e² ≈ 25.8kΩ，实验测到小数点后九位
与理论一致——因为这个值被**拓扑**（陈数）保护，样品的杂质、形状、
大小统统不影响它。**拓扑不变量是可以用万用表测的**。
