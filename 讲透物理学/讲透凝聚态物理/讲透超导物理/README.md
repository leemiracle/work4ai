# 讲透超导物理 · 零电阻神话与配对之谜

> 这支负责：**最壮观的宏观量子现象**——零电阻、迈斯纳效应、约瑟夫森结。
> BCS 是老谜的完美答案；高温超导 38 年仍是无解的新谜。
>
> GB/T 13745：14050 三级"超导物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1911 Onnes 氦液化后测汞电阻——4.2K 突然归零（"在尽可能低的温度下
测电阻"这个朴素愿望撞出了新物态）；1957 BCS 理论（1972 诺奖）；
1986 Bednorz-Müller 铜氧化物高温超导（1987 诺奖，诺奖史上最快）；
2015 后氢化物近室温超压超导（争议区，见家族 01 章风波）。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 迈斯纳效应（完全抗磁） | ✅ 已解 | 超导≠完美导体：排磁是独立于零电阻的宪法条款 |
| BCS 与同位素效应 | ✅ 已解（1957） | 电子借声子配对——三支柱合体的杰作 |
| 约瑟夫森效应 | ✅ 已解（1962/1973 诺奖） | 超流相位差的电压-频率关系=电压标准 |
| 第二类超导与磁通钉扎 | ✅ 已解（Abrikosov 1957/2003 诺奖） | 强磁场超导磁体的工作原理 |
| **高温超导机制** | ❌ 未解（1986-） | 非声子配对是什么？d 波对称性谁定的？凝聚态最响的悬案 |
| 室温常压超导 | ❌ 零例 | 每一次宣称都掀翻科学圈（LK-99 教训见家族 01 章） |

## ✨ 最美的一个事实

**相位刚体**：超导体里那支复数序参量 ψ=|ψ|e^{iθ} 的相位 θ 空间上
**锁死成一块刚体**——磁通量子、约瑟夫森振荡、超导量子比特（quibit 的
物理载体）全部是这块"相位刚体"的动力学。零电阻只是它最表层的症状。
你可以说：**超导是宏观世界里的量子相位显形**。

## 假设与依赖

配对假设（一切超导都是配对的——至今无一反例）；相位相干长度>晶格
尺度（本征宏观量子性）。前置：[凝聚态理论](../讲透凝聚态理论/) 三支柱。
