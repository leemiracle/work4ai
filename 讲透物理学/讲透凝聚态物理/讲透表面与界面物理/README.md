# 讲透表面与界面物理 · 固体的脸面

> 这支负责：**固体的最外几层原子**——表面重构、吸附、隧穿。
> 催化、电镀、摩擦、芯片接触——一切"固体与外界打交道"的物理都在脸上。
>
> GB/T 13745：14050 三级"表面与界面物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1960s-70s 超高真空+低能电子衍射（LEED）使人第一次"看清"表面；
1981 扫描隧道显微镜（Binnig-Rohrer，1986 诺奖）——给表面物理学配了眼睛和手指；
表面科学催生了半导体界面工程与多相催学的物理层。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 表面重构与表面能 | ✅ 已解（表面晶格≠体内晶格，硅(7×7) 重构是标志例） | 脸的皮肤和身体不一样 |
| STM/AFM 成像与操控 | ✅ 已解（1981/1986 诺奖） | 单原子可见、可推（" IBM "原子拼字） |
| 吸附与脱附动力学 | ✅ 已解 | 催化反应器设计的物理输入 |
| 界面态与费米钉扎 | ✅ 已解（Bardeen 1947 起） | 半导体接触为什么"不听话" |
| 多相催化的第一性原理设计 | 🔄 前线 | d 带中心描述符→催化剂筛选（2021- AI 加速） |
| 摩擦的微观理论 | 🔄 前线 | 纳米摩擦学：摩擦定律在单接触下的失效 |

## ✨ 最美的一个事实

**STM 不仅看见原子，还能推动原子**——针尖电场可以把吸附原子"拎起来放下"
（1989 IBM 用 35 个氙原子拼出"IBM"三个字母）。量子隧穿电流对距离的
指数敏感性（每埃变一个量级）使得"显微镜"同时是"机械手"：
**测量的物理与操控的物理是同一个**。

## 假设与依赖

超高真空/洁净表面假设（真实空气表面 1 秒内蒙上污染物单层）；
隧穿近似（barrier 高/宽条件）。前置：[凝聚态理论](../讲透凝聚态理论/)。
