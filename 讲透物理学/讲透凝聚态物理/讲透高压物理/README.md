# 讲透高压物理 · 把原子压到重新谈判

> 这支负责：**压力这个旋钮**——金刚石对顶砧、金属氢、超高压下的新物态。
> 压力改写能带与配对：加压可以让绝缘体变金属、让"熟悉"的材料变成陌生的。
>
> GB/T 13745：14050 三级"高压物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1955 通用电气人造金刚石（Bridgman 毕生高压技术+GE 团队攻坚）；
Bridgman 大腔体压机（1946 物理诺奖）；1970s 金刚石对顶砧（DAC）把
极限压强推到百万大气压级；2015- 氢化物高温超压超导（Dias 系风波，
见家族 01 章——高压领域近年最大的声誉事件也在这）。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 石墨→金刚石相变 | ✅ 已解/已工业化 | 高压物理最著名的落地（工业金刚石） |
| 压致金属化 | ✅ 多例已解 | 碘/硅等绝缘体压成金属——能带被压塌 |
| **金属氢** | ❌ 争议未决 | 理论预言 1935；至今每次宣称都陷测量争议 |
| 氢化物超导（H₃S/LaH₁₀ 等） | ✅ 高压下可信（203K/260K） | "近室温超导"在兆巴压强下确有其事 |
| 压强标定与原位测量 | ✅ 已解（红宝石荧光等） | 万一大气压下怎么知道压多少 |
| 超高压下的行星物质 | 🔄 前线 | 冰巨星内部的超离子水——行星科学接口 |

## ✨ 最美的一个事实

**H₃S 在 203K（-70°C）超导**（Drozdov 2015，可信）——比任何常压超导
高近百度。代价是 155 万大气压（地球中心级）。**室温超导不是不存在，
是住在压强监狱里**——这门学科的全部戏剧：怎么把"高压里的奇迹"
解压释放到一杯常压里（至今未解）。

## 假设与依赖

静水压近似（非静水压是误差与假信号的温床——多次"室温超导"翻车都栽在
压强梯度/杂质相）；微样品测量（DAC 腔内样品微克级，测量误差被放大）。
