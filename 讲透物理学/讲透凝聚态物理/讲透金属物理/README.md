# 讲透金属物理 · 自由电子海与费米面考古

> 这支负责：**金属为什么是金属**——自由电子气、费米面、输运。
> 人类文明的主要结构材料（钢/铝/铜）的物理层。
>
> GB/T 13745：14050 三级"金属物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

Drude 1900 把电子气当理想气体处理（经典、惊人地管用）；Sommerfeld 1927
换成费米-狄拉克统计（量子修正）；Ashcroft-Mermin 1976 把这门课写成圣经。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Wiedemann-Franz 定律 | ✅ 已解（1853/1928 解释） | 热/电导率之比为普适常数——电子同时搬运热与电的铁证 |
| 费米面测绘 | ✅ 已解（de Haas-van Alphen 等） | 金属的"指纹"可完全实验测出 |
| 电子-声子电阻的温度依赖 | ✅ 已解（Bloch-Grüneisen） | 为什么电阻高温线性、低温 T⁵ |
| 重费米子与 Kondo 效应 | ✅ 已解（1970s-，多体理论杰作） | 磁杂质使电子"变重千倍" |
| 高温超导机制 | ❌ 未解 | 铜氧化物正常态就已是理论灾场 |

## ✨ 最美的一个事实

Drude 1900 年**不知道电子是费米子、甚至不知道电子质量对不对**，用经典
气体模型却算出了数量级正确的电导率——因为很多金属性质只依赖"有可移动
的带电粒子"这一件事。错误的模型给出正确的物理：有效理论之韧性的教科书案例。
