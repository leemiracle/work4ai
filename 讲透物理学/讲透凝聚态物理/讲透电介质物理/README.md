# 讲透电介质物理 · 极化的秩序

> 这支负责：**不导电的材料如何被电场组织**——极化、介电响应、铁电。
> 从电容器的介质到铁电存储（FRAM），"绝缘体也有戏份"。
>
> GB/T 13745：14050 三级"电介质物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

Faraday 的介电常数概念（1837）；铁电性 Rochelle 盐 1920；钛酸钡 BaTiO₃
1943-46（陶瓷铁电，实用化起点）；铁电疲劳与薄膜铁电 1980s-。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Clausius-Mossotti 关系 | ✅ 已解 | 微观极化率↔宏观介电常数的桥 |
| 铁电相变（位移型） | ✅ 已解（软模理论，1960 Cochran） | 一个声子频率软化到零=相变 |
| 铁电尺寸效应 | ✅ 基本已解 | 薄到几个晶胞仍保持铁电（FRAM 可用） |
| 反铁电/弛豫铁电的统一图像 | 🔄 前线 | 储能与介电调谐的设计空间 |
| 多铁（磁+铁电共存） | ❌ 设计未闭环 | 为什么磁与铁电互斥（对称性之争）与破局 |

## ✨ 最美的一个事实

**软模**：把钛酸钡降温到相变点，其中一个晶格振动模式的频率不断降低——
到相变温度恰好降到零，"振动不动了"的那个模式冻结成静态位移，就是
自发极化。**相变=一个声子阵亡**——动力学的死即结构性的生。
