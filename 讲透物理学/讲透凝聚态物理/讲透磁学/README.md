# 讲透磁学 · 自旋的集体舞

> 这支负责：**磁性的一切**——铁磁/反铁磁/自旋波/自旋电子学。
> 从指南针（人类第一个"高科技"）到硬盘读头与 MRAM，最老的物理搭上最新的车。
>
> GB/T 13745：14050 三级"磁学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

中国古代司南/1600 Gilbert《论磁体》（第一个"物理专著"级研究）；
1907 Weiss 分子场理论（铁磁的平均场鼻祖）；1928 Heisenberg 交换相互作用
（磁性的量子根源：不是磁荷，是泡利不相容+库仑）；1988 巨磁阻发现
（2007 诺奖）开启自旋电子学。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 磁性的量子起源（交换作用） | ✅ 已解（1928） | 铁磁=静电库仑+泡利，不是"磁偶极吸引" |
| 自旋波/磁振子 | ✅ 已解（1930s-40s） | 磁的 Goldstone 模式 |
| 反铁磁与磁结构 | ✅ 已解（中子衍射 1949 测定） | 自旋的晶体学 |
| 巨磁阻 GMR/TMR | ✅ 已解（1988/2007 诺奖） | 自旋阀：自旋极化电流的开关 |
| 磁斯格明子 | 🔄 前线 | 拓扑保护的自旋涡流——下一代存储候选 |
| 稀土永磁的无稀土替代 | 🔄 前线 | 能源战略级材料问题 |

## ✨ 最美的一个事实

**磁力的真身是静电力的量子马甲**：两个电子若自旋平行（泡利禁止靠太近），
它们平均距离更远、库仑排斥能更低——"自旋对齐更省能量"。
指南针指北，追到根上是**库仑排斥+泡利不相容**的合谋。宏观磁性是
量子力学最大的日常显形（你冰箱贴上贴着的就是它）。

## 假设与依赖

局域矩或巡游电子两种图像（各自适用域）；自旋-轨道耦合（各向异性的来源）。
