# 讲透固体发光 · 光子从固体里挤出来

> 这支负责：**固体如何发光**——发光二极管、激光二极管、荧光、磷光。
> 蓝光 LED 一项发明拿了 2014 诺奖，并重塑了全球照明与显示。
>
> GB/T 13745：14050 三级"固体发光"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1907 Round 记下碳化硅"发光"（第一份 LED 报告，被忽视半世纪）；
1962 红外/红光 LED 与激光二极管；1993 中村修二蓝光 LED 破局
（氮化镓，三十年没人看好的材料，2014 诺奖）——白光 LED=照明革命。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 辐射复合与发光效率 | ✅ 已解 | 电子空穴复合：直接带隙效率碾压间接带隙 |
| 激光二极管原理 | ✅ 已解（1962） | 粒子数反转+谐振腔做进 pn 结——光通信的引擎 |
| GaN 蓝光材料工程 | ✅ 已解（1990s，两步缓冲生长） | "做不出来的材料"被工程攻坚做出来 |
| 荧光粉与白光合成 | ✅ 已解 | 蓝 LED+黄荧光粉=最省电的白光 |
| 高效深紫外 LED | 🔄 前线 | AlGaN 体系的p型掺杂难题 |
| 钙钛矿 LED/量子点显示 | 🔄 前线 | 溶液工艺+高色纯度（2023- 量子点诺奖关联） |

## ✨ 最美的一个事实

**氮化镓蓝光的代价**：GaN 与蓝宝石衬底失配 16%（正常薄膜早该碎成渣），
中村修二用"两步生长+低温缓冲层"驯服了它；更早的赤崎勇用了 20 年做
别人都放弃的材料。**诺奖级的物理发现有时纯粹是"死磕不体面材料"**——
固体发光是实验材料学的励志部。

## 假设与依赖

载流子注入（电极/结质量决定一切）；直接带隙优势（硅发光弱是能带结构的
判决不是工程问题——硅光子学绕路用锗/III-V）。前置：
[半导体物理](../讲透半导体物理/)。
