# 讲透介观物理 · 量子输运的中间舞台

> 这支负责：**比原子大、比宏观小的量子领地**——量子点、量子线、弹道输运。
> "介观"= 尺寸小于相位相干长度，欧姆定律开始失效，量子干涉成为主角。
>
> GB/T 13745：14050 三级"介观物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1980s 量子霍尔与 Aharonov-Bohm 振荡在半导体微结构中显现；1985-
Landauer-Büttiker 公式把电导写成量子化通道的透射率；1990s 单电子晶体管
与库仑阻塞——"一个电子的户口本"工程；量子点激光器与单光子源接棒。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 电导量子化 G₀=e²/h | ✅ 已解 | 电导的基本单位——通道透射的语言（Landauer） |
| 库仑阻塞 | ✅ 已解 | 岛上多一个电子都要"付钱"——单电子操控 |
| 弱局域化与 AB 振荡 | ✅ 已解 | 量子干涉修正经典电导——"回波"可测 |
| 量子点能级（人工原子） | ✅ 已解 | 三维全限制=重建原子能级谱，旋钮式的 |
| 拓扑保护的输运通道 | 🔄 前线 | 量子霍尔边缘态=无损耗布线 |
| 介观超导/杂化系统 | 🔄 前线 | Majorana 零模候选（仍存争议） |

## ✨ 最美的一个事实

**电导有基本单位**：G₀ = 2e²/h ≈ 77.5 μS。一根比头发细千倍的线，
电导是 G₀ 的整数倍（每开通一个量子通道贡献一份）——欧姆定律里
"电阻随长度连续变化"的日常直觉，在介观世界被**量子化台阶**取代。
电阻不是流的阻碍，是通道的**计数**。

## 假设与依赖

相位相干（低温/小尺寸保住量子相位）；通道近似（无相互作用或可控相互作用）。
