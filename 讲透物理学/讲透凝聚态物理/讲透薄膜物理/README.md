# 讲透薄膜物理 · 二维化的固体

> 这支负责：**薄到量子效应现形的固体**——外延生长、异质结、量子限制。
> 半导体激光、LED、MRAM 硬盘读头全部诞生在这层的厚度里。
>
> GB/T 13745：14050 三级"薄膜物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1970s 分子束外延（MBE，Bell/IBM）实现"原子级抹刀"——一层一层堆单原子平面；
超晶格概念 1970（江崎玲於奈与 Tsu，人工周期势）；
巨磁阻薄膜 1988（Fert/Grünberg，2007 诺奖——硬盘密度革命）。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 外延生长模式 | ✅ 已解（Frank-van der Merwe/Volmer-Weber 等） | 薄膜怎么长：一层层/岛状/混合，由界面能与失配决定 |
| 量子限制效应 | ✅ 已解 | 厚度<电子波长时能级量子化（量子阱激光器的原理） |
| 应变工程 | ✅ 已解（工业级） | 拉晶格调能带（高迁移率沟道的钥匙） |
| 巨磁阻（GMR/TMR） | ✅ 已解（1988/2007 诺奖） | 电子自旋进电路——自旋电子学开端 |
| 2D 材料的可控大规模生长 | 🔄 前线 | 石墨烯/hBN 单晶薄膜的 wafer 级生长 |
| 界面失配位错的彻底抑制 | 🔄 工程前线 | 异质集成的永恒课题 |

## ✨ 最美的一个事实

**超晶格**：把两种半导体按几纳米周期交替堆叠，人为制造一个自然界不存在
的晶体周期——电子的行为由设计师的层厚决定。人类第一次**把能带当图纸画**
（江崎 1973 已因隧道效应获诺奖，超晶格是他下半场的加时赛）。

## 假设与依赖

界面质量假设（粗糙度<电子相干长度才有"干净"量子效应）；连续介质弹性近似
（处理失配应变）。前置：[半导体物理](../讲透半导体物理/)、[表面与界面物理](../讲透表面与界面物理/)。
