# 讲透非晶态物理 · 没有晶格的固体

> 这支负责：**玻璃与一切非周期固体**——玻璃化转变、无序局域化、金属玻璃。
> 凝聚态的"体制外领土"：能带论在此部分失效，方法自成一格。
>
> GB/T 13745：14050 三级"非晶态物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

玻璃工艺五千年（人类最老的"高科技"）；1960 Duwez 液态金属急冷得金属玻璃；
1971 Philip Anderson 发表《Amorphous Solids: Low-Temperature Properties》——
异常低温热容（TLS 两能级系统）确立非晶为独立研究对象。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 非晶的普适低温反常 | ✅ 已解（TLS 标准模型 1972） | 一切非晶固体低温比热~T、热导~T²——与化学成分无关 |
| Anderson 局域化 | ✅ 已解（1958，1977 诺奖） | 无序本身能把波函数锁死（导电→绝缘） |
| 金属玻璃的形成判据 | ✅ 经验已解 | 深共晶+多组元=玻璃形成能力 |
| **玻璃化转变的本质** | ❌ 未解（全家族最大悬案之一） | 液→玻璃是相变吗？有没有隐藏序参量？ |
| jamming 与屈服 | 🔄 前线 | 颗粒物质/泡沫的堵塞物理 |

## ✨ 最美的一个事实

一切非晶固体（玻璃/聚合物/干燥蛋白质/氧化物）在低温下表现出**同一种**
反常：比热 ∝ T。原因竟是材料内部到处都是"两能级系统"（原子集团的双稳
翻转）——化学上毫无关系的材料，缺陷统计却给出普适律。
**普适性不是晶体的专利**（对照家族 00 章临界普适性）。

## 假设与依赖

无长程序（只有短程序）；平衡态方法部分失效（玻璃是非平衡的"冻结液体"）。
前置：[凝聚态理论](../讲透凝聚态理论/)（但注意它能用的工具有限）。
