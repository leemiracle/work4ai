# 讲透低温物理 · 接近绝对零度的技术与文化

> 这支负责：**怎么冷、冷下来做什么**——氦液化、稀释制冷、极低温下的新物态。
> "每一次降温技术的突破都解锁一批诺奖"是这支的历史规律。
>
> GB/T 13745：14050 三级"低温物理学"。家族：[讲透凝聚态物理](../README.md)。

## 诞生

1908 Onnes 氦液化（1.4mK 记录三保持，1913 诺奖）；³He-⁴He 稀释制冷
（1951 London 提议，1965 实现，mK 级无磁室温预冷）；彭杜勒（稀释+核绝热
去磁组合）达 μK；现代稀释制冷机是超导量子计算机的机房标配。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| ⁴He 超流（λ 转变） | ✅ 已解（1938/2003 诺奖，玻色凝聚） | 液氦爬壁、无粘度流——宏观量子流体 |
| ³He 超流 | ✅ 已解（1972/1996 诺奖） | 费米子也要"配对"才能凝聚——BCS 的超流版 |
| 稀释制冷原理 | ✅ 已解 | ³He 溶进 ⁴He 的"渗透热"=mK 冷源（无运动部件） |
| 低温温标与测温学 | ✅ 已解（PLTS-2000） | mK 区的温度怎么定义、怎么测 |
| μK 以下的极限 | 🔄 前线 | 核去磁极限与量子基态制备 |
| 无氦低温技术 | 🔄 前线 | 氦资源稀缺下的替代制冷（脉冲管等） |

## ✨ 最美的一个事实

**超流氦会爬墙**：⁴He 在 2.17K 以下沿容器壁形成爬行膜、翻出杯口自流到
更低处——因为"全部原子进入同一量子态"后，液体的表面膜是**一个**波函数，
毛细作用它整体响应、粘度对它整体失效。降温不是"让分子变慢"那么简单：
是让 10²³ 个原子签订同一份量子合同。

## 假设与依赖

绝热/漏热控制（低温物理=与热漏的永恒战争）；量子统计类型决定低温行为
（玻色积聚 vs 费米配对）。前置：统计物理（[讲透理论物理](../../讲透理论物理/)）。
