# 讲透粒子宇宙学 · 把粒子表写进宇宙

> 这支负责：**粒子物理×宇宙学的合流**——暗物质本质、暴胀的粒子物理、
> 中微子宇宙学、早期宇宙的相变与引力波；"最大与最小的两门学科互为望远镜"。

> GB/T 13745：14070 三级。家族：[讲透高能物理](../README.md)。占位即种子（2026-09-07）。

## 诞生

1970s 大爆炸核合成（BBN）用轻核丰度反推宇宙参数——粒子物理第一次
给宇宙学当尺子；1980 暴胀理论（Guth）把粒子物理相变写进宇宙最初 10⁻³⁶ 秒；
1998 暗能量发现后，"粒子表+宇宙学常数"成为两学科的共同资产负债表。

## 这支最美的一个事实（一句）

**宇宙微波背景的光子数密度 ~410 个/cm³——每立方厘米的宇宙里，
大爆炸的余晖比地球上任何灯都均匀**；而它的温度涨落只有十万分之一——
这十万分之一里写着全部结构形成的种子（也是粒子物理在 38 万岁宇宙上的投影）。
