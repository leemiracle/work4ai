# 讲透高能物理 · 最小砖块，最大加速器

> 高能物理（粒子物理）：**把宇宙拆到最小砖块，再问砖块为什么恰好是这些**——
> 在对撞机里重现大爆炸后一皮秒的能量，用对称性书写万物之理的候选项表。
> 它是物理学里**最贵**的分支（一台对撞机=一个国家的科学预算），
> 也是**最简**的分支（标准模型一页纸写完，精确到千万分之一）。

> GB/T 13745：14070（二级学科）。宇宙：[讲透物理学](../README.md)。
> 五问模板家族成员 · 九要件宪法（2026-09-07 生产）。

## 诞生

三记炮响：①1897 Thomson 阴极射线管发现电子——第一块"砖"；
②1950s-60s 回旋加速器时代"粒子动物园"爆发（强子几百种，看似无序）；
③1964 Gell-Mann 夸克模型 + 1967 Weinberg-Salam 电弱统一——动物园收拢成
三代夸克轻子×三种力的标准模型，2012 希格斯玻色子落定为最后一块拼图。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 基本粒子有哪些 | ✅ 标准模型（1970s 定型，2012 完成） | 三代夸克轻子+四种相互作用媒介粒子，一页纸的元素周期表 |
| 质量从哪来 | ✅ 希格斯机制（2012 LHC 发现，2013 诺奖） | 对称性自发破缺给粒子"上户口"——真空不是空的 |
| 缪子反常磁矩 g-2 | 🔄 4.2σ 张力（Fermilab 2021 0.46 ppm） | 实验-理论偏差若坐实=标准模型第一道裂缝 |
| 中微子质量序 | 🔄 JUNO 2024 投运（~6 年窗口） | 正常序还是倒序——决定质量起源模型生死 |
| 暗物质粒子是什么 | ⧜ 圣杯 | 占宇宙 27% 的东西，直接探测 30 年未捕获 |
| 强 CP 问题/物质反物质不对称 | ⧜ 圣杯 | 为什么宇宙有物质剩下——轴子是最大候选 |

## 假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 点粒子（无内部结构） | 计算可重整、理论封闭 | 无法回答"为什么这些质量/代数"——参数 19 个全是手填 |
| 微扰展开（费曼图） | 几乎一切可算且极准 | 强耦合区（QCD 低能）失效——需格点非微扰 |
| 对称性定相互作用 | 理论几乎被唯一确定 | 对称性从哪来无答案；引力拒不入表 |
