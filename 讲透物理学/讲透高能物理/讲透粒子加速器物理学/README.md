# 讲透粒子加速器物理学 · 人类最精密的机器

> 这支负责：**如何把粒子加速、聚束、对撞**——同步辐射、束流动力学、
> 亮度工程；它是物理与工程的合金（本家族"可构造"的机械底座）。

> GB/T 13745：14070 三级。家族：[讲透高能物理](../README.md)。占位即种子（2026-09-07）。

## 诞生

1930 Lawrence 回旋加速器（巴掌大，1939 诺奖）→ 同步加速器原理突破能量-刚性瓶颈
→ 1954 欧洲核子中心成立 → 1989 LEP（27 km 隧道）→ 2008 LHC（复用同一条隧道，
13.6 TeV）。每一代加速器半径×10，亮度×100——摩尔定律的粒子物理版。

## 这支最美的一个事实（一句）

**LHC 两束质子对撞亮度所需的束流控制精度，相当于让两根相距 10 km 的针
对穿——而针以光速飞行、每秒 4000 万次**。（束团截面 ~μm 级交叠控制）

## 假设与依赖

同步辐射损失 ∝ E⁴/ρ（环形轻子机的天罚）→ 能量越高越被迫"直线化或重型化"；
超导磁体+超高真空+精密定时三大工程支柱（任一短板=整机失效）。
