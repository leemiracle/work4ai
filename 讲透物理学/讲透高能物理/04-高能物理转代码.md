# 04 · 高能物理转代码：数据洪水中的物理

> **本章回答五问之五（本支：讲透高能物理）。**
> 高能物理是**第一个被数据淹没的学科**（LHC 每年 ~100 PB），也是
> 第一个把"分析流水线"做成基础设施的学科——万维网本身就是 CERN
> 为解决它的数据共享问题发明的（1989）。三件套：
> 可机械化边界 / 代码走廊 / 工程师落点——每栏答"为什么是这样"。

---

## 一、可机械化边界

| 环节 | 可机械化程度 | 为什么 |
|------|-------------|--------|
| 事例筛选（触发） | ✅ 全自动+必须全自动 | 40 MHz→1 kHz 实时裁决，人不可能介入——机器看每秒 4000 万次对撞，挑 1000 个 |
| 探测器响应模拟 | ✅ 高保真（Geant4） | 电磁/强子簇射的输运方程已知，逐粒子追踪蒙特卡洛 |
| 不变质量/截面重建 | ✅ 教科书级机械化 | 守恒律的会计学，[实验脚本](experiments/invariant_mass_demo.py) 即最小版 |
| 径迹重建 | 🔄 半自动（ML 介入中） | 高占有量事例的组合爆炸，图神经网络正在换掉卡尔曼滤波的天下 |
| 新信号统计判定 | 🔄 半自动 | 5σ 判定框架固定，但"找哪个道"与盲分析设计仍靠物理判断 |
| 理论本身（哪个新模型对） | ❌ 不可机械化 | 19 参数之上的模型选择=科学判断，EFT 全局拟合只提供证据不给判决 |
| 强耦合 QCD 数值 | 🔄 可机械化但代价天文 | 格点=可算，但连续极限外推×物理体积×手系质量三重计算墙 |

**边界的一句话**：凡能写成"守恒律+概率分布+大数据流"的环节全部可机械化；
涉及"该问什么问题"的环节（模型选择、盲分析设计）留在人手里。

## 二、代码走廊（问题类 → 算法 → 工具）

| 走廊 | 问题类 | 算法/方法 | 工具 |
|------|--------|----------|------|
| ① 事例分析 | 分布对比/找峰 | 直方图统计/拟合/盲分析 | **ROOT**（CERN 六代人的框架）+ Python 新栈（awkward array/coffea） |
| ② 探测器模拟 | 簇射/噪声仿真 | 逐粒子输运蒙特卡洛 | **Geant4**（物理引擎级精度，NASA 也拿去算太空辐射） |
| ③ 理论计算 | 截面/衰变宽度 | 费曼图自动生成与积分 | **MadGraph/FeynArts/Form**——画图→代码→数字全自动 |
| ④ 格点 QCD | 强耦合非微扰 | 蒙特卡洛+外推 | 专用超算（QCD 专用机常居 Green500 顶） |
| ⑤ ML 重建/分类 | 径迹/喷注/触发 | GNN/Transformer | PyTorch+自研插件（[讲透模型](../../讲透模型/) 宇宙的天然接口） |
| ⑥ 快速模拟 | 理论→伪数据快速扫参 | 参数化/生成式 | Delphes（把 Geant4 慢千倍的问题换成毫秒级近似） |

📖 **故事框：ROOT 与万维网**。CERN 的两大软件遗产：ROOT（数据分析框架，
"物理学家用 C++ 写的 Excel"，争议缠身但统治三十年）与 WWW（Berners-Lee
1989 年为让全球合作者共享事例数据而发明）。本学科被迫两次重塑软件文明。

## 三、工程师落点（性能工程视角）

用户是性能工程背景，本节按"这学科在 HPC/系统圈的存在感"写：

1. **触发=极端实时系统**：μs 级延迟预算内的多级流水线（L1 硬件/FPGA→HLT GPU 场）——
   延迟与吞吐的教科书权衡现场，现代 FPGA+GPU 异构的祖师爷级 workload。
2. **ROOT I/O 与列式扫描**：事例数据"每事例一档"转"每字段一列"
   （awkward/RDataFrame）——本质是 OLAP 列存思想在 PB 级科学数据上的重演。
3. **格点 QCD 吃超算**：持续数月的 MPI+SIMD 跑规范场组态——
   Green500 榜单常客，多 GPU 通信与算子调优的深度战场（与
   [讲透高性能计算](../../讲透高性能计算/) 直接对口）。
4. **生成式快速模拟**：Geant4 全模拟太慢→GAN/扩散模型学习探测器响应，
   千倍提速——生成模型在工业界火之前的最大科学买家之一。
5. **全局 EFT 拟合**=高维贝叶斯后端，计算图与自动微分直接复用
   ML 基建（[讲透PyTorch源码](../../讲透PyTorch源码/) 的反向传播即其引擎）。

✨ **美之时刻 ②：一张费曼图到一列数字的全自动管线。**
MadGraph 输入拉格朗日量→自动生成全部费曼图→积分出截面→Delphes 快模拟
→伪数据与真实对撞数据对比——**理论的语法直接编译成可执行对比**。
**为什么美**：从"美学的对称性"到"机器吐出的 p 值"零人工翻译。
**怎么亲历**：MadGraph 网页版跑 e⁺e⁻→μ⁺μ⁻，改一个耦合常数看截面变多少。

## 四、裂缝清单（不可转/转不好的）

| 裂缝 | 性质 |
|------|------|
| 蒙特卡洛误差与系统误差的分层 | 统计框架可编码，但"系统差怎么定"是实验组政治+物理判断的混合物 |
| 盲分析的"盲" | 防止人为偏向的分析纪律——恰恰要**防止**机械化（防止分析者偷看答案） |
| 事例级解释 | 单事例只能给似然比，"这个事例是什么"在原理上无答案（量子叠加） |
| 格点→连续极限 | 外推路径（格距→0）无算法保证，是"数值分析+领域直觉"的缝合地带（[讲透数学/讲透分析/讲透数值分析](../../讲透数学/讲透分析/讲透数值分析/) 的收敛理论在此验货） |

## 五、Python 层

[experiments/invariant_mass_demo.py](experiments/invariant_mass_demo.py)：
走廊①的最小实现（纯 numpy）——A 解析对照 / B 洛伦兹不变性 / C 探测器 smearing
下的找峰。三段正是真实分析的微缩：精确校准→不变量保护→统计重建。

## 六、不足层

- 软件栈的老龄化：ROOT/Geant4 的核心是上代 C++/Fortran，社区在
   Python 新栈与传统栈之间长期分裂——迁移成本与科学连续性打架；
- ML 重建的"可解释性债"：触发里用 GNN 意味着发现声明的一部分
   挂在黑箱上——系统性误差的认定标准尚未跟上工具换代。

## ✍️ 练习

1. 触发为什么必须分两级（L1 硬件+HLT 软件）？如果只用软件触发，
   40 MHz 的数据流需要多大网络带宽（粗算）？
2. 把实验脚本 C 段改造成"盲分析"：先在质量窗 [130,140] 之外拟合背景，
   再开窗看峰——为什么这个顺序能防骗？（这叫"侧带法"）
3. 比较 ROOT RDataFrame 与 Spark：科学事例数据与商业日志数据在
   访问模式上最根本的差别是什么？

## 📌 收束 · 认知升维

这章的新眼睛：**数据流水线是科学仪器的延长**。对撞机只是"光源"，
真正的实验是那 100 PB 数据上的整条流水线——流水线的设计决定了你能问什么。
迁移到工程：你的系统里，"日志/遥测→决策"的那条链路，
就是你的科学仪器——它的分辨率、盲区与延迟，就是你认知的分辨率、盲区与延迟。
