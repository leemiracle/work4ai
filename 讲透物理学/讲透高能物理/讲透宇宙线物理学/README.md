# 讲透宇宙线物理学 · 免费的粒子束

> 这支负责：**天送来的粒子束**——能量远超人造对撞机（最高观测 ~10²⁰ eV，
> 比 LHC 高千万倍），却免费且全天候；代价是束流"不可调、不可控、不可重复"。

> GB/T 13745：14070 三级。家族：[讲透高能物理](../README.md)。占位即种子（2026-09-07）。

## 诞生

1912 Hess 乘热气球带验电器上天——海拔越高电离越强，"穿透辐射来自天上"
（1936 诺奖）。正电子（1932 Anderson）、μ子、π介子都在宇宙线里首现——
宇宙线是 1930-50s 的"天然对撞机"，加速器时代到来后转为甚高能前哨。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 宇宙线起源（哪里加速的） | 🔄 膝区（~10¹⁵eV）起源尚无定论；PeV 蟹状星云已证认一批 |

## 这支最美的一个事实（一句）

**每秒约有几百个缪子穿过你的身体**——它们是上层大气宇宙线的二代产物，
寿命 2.2 μs，靠相对论时间膨胀（γ 延寿）活着抵达地面——
狭义相对论最日常的证据就写在你头顶的粒子雨里。

## 假设与依赖

束流各向同性+幂律谱（E^-2.7）假设；广延大气簇射（EAS）的蒙特卡洛
（Auger 数据的解读全部挂在簇射模型上——模型差一点，结论差很多）。
