# 讲透粒子物理学 · 砖块与力的本体论

> 这支负责：**基本粒子有哪些、靠什么法则相互作用、标准模型为何如此**——
> 高能物理的"理论本体论"主线（实验侧见高能物理实验支）。

> GB/T 13745：14070 三级。家族：[讲透高能物理](../README.md)。占位即种子（2026-09-07）。

## 诞生

1964 Gell-Mann & Zweig 夸克模型（从"粒子动物园"收拢出三种味）；
1967 Weinberg《轻子模型》3 页纸统一电磁弱；1973 QCD 渐近自由——
三代物质×三种力的标准模型骨架成型，2012 希格斯封顶。
