# 讲透高能物理实验 · 探测器与数据分析方法论

> 这支负责：**怎么"看见"**——探测器物理（径迹/量能/粒子鉴别）、
> 触发/重建/统计分析的全流水线；家族层 [04 章](../04-高能物理转代码.md) 的学科正主。

> GB/T 13745：14070 三级。家族：[讲透高能物理](../README.md)。占位即种子（2026-09-07）。

## 诞生

闪烁体+云室时代（1930s 宇宙线发现正电子/μ子）→ 气泡室（1950-70s，
Glaser 1960 诺奖，手工扫描百万照片）→ 电子学探测器+多丝正比室
（Charpak 1968，1992 诺奖——数字化革命的起点）→ LHC 时代的
"软件定义实验"（触发+重建+统计=实验的一半）。

## 这支最美的一个事实（一句）

**2012 年 7 月 4 日大屏上那个 125 GeV 的小鼓包，横轴是人类造出的
最大机器、纵轴是统计学的 5σ 门槛——"发现"一词的当代定义**。

## 假设与依赖

（本地化 p 值+look-elsewhere 修正——在 80-600 GeV 搜遍，运气费要交）。
