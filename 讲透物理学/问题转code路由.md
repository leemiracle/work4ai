# 讲透物理学 · 问题转 code 路由表

> **本表定位**：把物理学的真实问题/任务**逐条翻译成 code 任务**。
> 家族 04 章（如 [理论物理](讲透理论物理/04-理论物理转代码.md)、[凝聚态物理](讲透凝聚态物理/04-凝聚态物理转代码.md)）管**边界与走廊**——哪类问题走哪条走廊、可机械化到什么档位、裂缝在哪；
> 本表管**具体问题怎么接单**——一句话问题进来，形式化、code 任务、工具、坑、落点家族一行查清。
> 全表覆盖 15 家族；走廊口径取理论物理四走廊（符号/数值 PDE/蒙特卡洛/ML）与凝聚态三走廊（第一性原理/原子模拟/有效模型）。
> 姊妹表：[讲透历史学 · 问题转 code 路由表](../讲透历史学/问题转code路由.md)。

## 〇、使用方法（三步）

1. **查表**：找到最接近你问题的一行，先读"形式化后"列——
   这一步写不出来，说明问题还没到接代码的成熟度（回尾部工作流第 1 步回炉）。
2. **对读**：跳到"落点家族"的 04 章，在其可机械化边界表确认档位
   （全自动/半自动/不能）；[C] 层问题接单前必读对应裂缝清单。
3. **接单**：按"算法/库"列的最轻项起步——50 行最小标本跑通，再换重型工具。

**层标**（标于"领域问题"列首）：

- **[A] 可直接编码**：问题即数学，算法与库现成，课内一天量级；
- **[B] 需先建模**：成败主体在建模选择（泛函/势函数/线型/边界条件），编码是后半程；
- **[C] 研究级开放**：顶刊进行中，或撞在复杂度墙与裂缝上——可做周边，不可做本体。

**查不到怎么办**：先看能否拆成表内两行以上的组合（如"算器件能带"+"拟合光谱"=表征闭环）；
拆不动的问题多半缺形式化或缺数据，先补前者。

## 二、覆盖与走廊分布

**覆盖声明**：15 家族全落子（每家族至少 1 行）。按理论物理四走廊归类——

- **② 数值 PDE/本征值**为最大宗（约 20 条）：能谱（#2、#5）、场仿真（#13、#14、#19、#20）、
  光线与波传播（#15-#18、#24、#26）、拟合类（#8、#29、#34）皆此走廊；
- **③ 蒙特卡洛**次之（5 条）：输运（#12）、临界采样（#6）、系综（#4、#30）、误差传播（#34）；
- **① 符号**最少（1 条）：#28——符号走廊的产出物是解析表达式，多数物理用户
  拿到的已是成品库（MadGraph 内嵌），独立写符号代码的场景集中在振幅研究组内部；
- **④ ML** 在表内只作组件出现（#30 的 MLIP 势函数、#34 的 MCMC 采样）：
  物理问题里 ML 目前是嵌进前三条走廊的零件，独立成单的"逆向设计"仍属观察项——
  与 [理论物理 04 章](讲透理论物理/04-理论物理转代码.md)对走廊④"方法论热身期"的档位判定一致。

## 五、通用工作流（问题→形式化→选走廊→写断言）

1. **问题→形式化**：把一句话问题改写成"输入/输出/判据"三元组；
   判据写不出（说不清"算对了"长什么样）→ 回炉，不许带病接单。
2. **形式化→选走廊**：查本表定落点家族与 code 任务；进家族 04 章
   在可机械化边界表确认档位；跨家族问题按"最重物理在哪"归队
   （#3 物理在电子结构→归凝聚态，不归软件所在的计算物理）。
3. **选走廊→写 code**：最轻工具起步（50 行标本），跑通后升级重型工具；
   [B] 层预算分配参考：建模选择七成、编码三成。
4. **写断言**：每个数值结果配一条解析极限或第二方法对拍——
   守恒量监控（#1）、精确解极限（#2、#6）、收敛阶检验（#17、#18）；
   单方法数字不是结果。

### 接单示范（#8 拟合光谱定成分，A 层走完全程）

1. **形式化**：输入=多组分混合光谱（波长×强度）+ 候选组分线状表；
   输出=各组分比例±误差；判据=合成谱残差呈白噪声、无系统波形。
2. **选走廊**：走廊②（数值拟合），落点原子分子物理；04 章档位=全自动。
3. **写 code**：lmfit 叠加 Voigt 线型，50 行起步；
   坑=线型选择（Gauss/Voigt）与仪器展宽卷积，先卷再拟合。
4. **写断言**：单组分标样回灌→比例须 100%±3%；
   两组分近邻线（间距≈线宽）须报告分辨失效，不许硬拟合出比例。
