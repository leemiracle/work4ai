# 讲透低温等离子体 · 沉默的工业主力

> 这支负责：**非平衡等离子体**——电子热（万度）而离子冷（近室温），
> 用"高能电子化学"在低温下干高温的活。没有它就没有现代芯片。

## 诞生

1830s Faraday 研究放电管辉光；1920s Langmuir 的等离子体命名现场
（气体放电研究）就是低温等离子体；1980s 半导体工业发现反应离子
刻蚀（RIE）是摩尔定律的隐形生产线——从实验室玩具变成万亿产业基石。

## 核心问题（3-5 条）

| 问题 | 状态 |

| 辉光放电分区结构（暗区/亮区机制） | ✅ 经典已解 |

| 等离子体医学/农业的机理 | ❌ 早期（活性粒子 RONS 的生物效应） |

## ✨ 这支最美的一个事实

同一根放电管里电子温度 ~5 eV（≈5万度）而气体整体接近室温——
"温度"这个词在非平衡等离子体里**分裂成好几个数**，麦克斯韦分布
这个统计力学默认假设被工业界日常违反。

## 假设与依赖

- 非平衡（eV 级电子 vs meV 级离子）——由低气压+高频驱动维持
- 化学网络：等离子体=电子碰撞化学的加速器（上千种反应通道），
  数据库（LXCat）是学科公共基础设施

## 教材锚

- Raizer《Gas Discharge Physics》/ Lieberman & Lichtenberg《Principles of Plasma Discharges and Materials Processing》
