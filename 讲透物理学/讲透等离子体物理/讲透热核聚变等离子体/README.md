# 讲透热核聚变等离子体 · 劳森判据的战场

> 这支负责：**把核聚变反应装进"容器"**——磁场瓶（磁约束）或激光锤
> （惯性约束），核心 KPI 只有一条：劳森判据 nTτ > 3×10²¹ keV·s/m³。

## 诞生

1950 苏联 Sakharov & Tamm 提出托卡马克概念；1951 美国 Spitzer 提出
仿星器；1958 年"日内瓦解密"（各国公开聚变研究换和平利用承诺）——
冷战双方各造了一个瓶子，比赛跑了七十年。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 托卡马克 H 模约束改善（1982 ASDEX） | ✅ 已解（发现+经验定标） |

| α 粒子自加热主导的燃烧等离子体 | ❌ 未解（ITER/SPARC 的下一关） |

## ✨ 这支最美的一个事实

氘氚聚变截面在 ~64 keV 达峰，但最优"点火温度"远低于此——因为
**温度再高截面反而缓降，而 bremsstrahlung（轫致辐射）损失单调上升**：
宇宙把反应窗口开在了 1-2 亿度，宽得刚好够工程学够一够。

## 假设与依赖

- DT 燃料循环（氚增殖包层自持）——氚在地球上不存在天然库存，堆必须
  自己"造氚"，这是比等离子体物理更硬的工程前提
- 第一壁材料承受 14.1 MeV 中子轰击——材料学是隐形合伙人
