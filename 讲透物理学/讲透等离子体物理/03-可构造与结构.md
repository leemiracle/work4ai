# 03 · 可构造与结构：可算、可反演、不可预测的三分天下

> **本章回答五问之四（本支：讲透等离子体物理）：可构造？结构？**
> 把本家族的"能算"分成三个王国：**轨道王国**（完全可构造）、
> **平衡王国**（可反演构造）、**湍流王国**（第一性预测仍是圣杯）。

---

## 一、轨道王国：完全可构造

单粒子在给定场中的运动是常微分方程——数值上"算到底"：

- 回旋运动 + 三大漂移（E×B / 梯度 / 曲率）——解析到闭式
- **磁镜反射**与香蕉轨道（环形装置中捕获粒子的经度振荡）——
  由磁矩守恒（绝热不变量）统治
- Boris 推进器：轨道王国的标准算法——体积守恒、长期无能量漂移
  （[04 章](04-等离子体物理转代码.md)详写）

**买到**：加热（回旋共振）、诊断（粒子轨道反推）、损失机制分析。
**代价**：场必须是"给定的"——自洽性全靠外循环。

## 二、平衡王国：可反演构造

托卡马克平衡（Grad-Shafranov 方程：二维椭圆 PDE）——给定压强剖面与
电流分布，解出磁面。**EFIT** 及其衍生（如 eqdsk 数据格式）是
每一台装置的日常工具：实验测得边界+内部诊断 → 反演平衡 →
输出 q 剖面（安全因子）、剪切、磁阱深度。

- 结构的"身份证"：**磁面**（嵌套环面）+ 安全因子 q（磁力线绕大环/
  小环的圈数比）——约束的拓扑骨架
- **✨美之时刻 ③**：**q 剖面是"有理数编织的鸟笼"**——整数 q 面
  （q=2, 3/2, ...）上是共振磁岛，无理 q 面之间是 KAM 环。
  为什么美：**统一**——等离子体约束位形与太阳系稳定性（KAM 定理）、
  与[讲透动力系统](../../讲透数学/讲透分析/讲透动力系统/)共享同一套
  哈密顿力学骨架。怎么亲历：用场线追踪代码画 q=2 磁岛，
  或玩 PyPlasma 的平衡可视化。

## 三、湍流王国：第一性预测的圣杯

- 湍流输运（ITG/TEM 模）主导堆芯能量损失——回旋动理学模拟
  （GENE/XGC）能算，但一个放电秒的物理要烧几十万核时
- **不可构造的核心**：多尺度非线性耦合（电子尺度→离子尺度→
  MHD 尺度的级联），没有干净的闭合近似；定标律仍是设计主力
- 破裂（disruption）预测：从"不可预测"被 ML 推到"可预警"
  （[01 章](01-近五年创新.md)方向三）——工程上"预警+ mitigation"
  先于"第一性预测"，这是复杂系统的普遍路径

**结构刚性的来源**（本家族版）：

1. **磁场拓扑**：磁面/磁岛/随机区的划分决定输运底色——拓扑不变量
   （螺旋度）在理想极限下守恒
2. **共振结构**：波-粒子共振条件（ω - k∥v∥ = nω_c）像激光的
   选择定则一样挑出谁和谁交换能量
3. **绝热不变量**（磁矩 μ）：快回旋/慢漂移的时间尺度分离
   "焊死"了轨道的分类学

## 四、可构造性分层表（家族总账）

| 对象 | 可构造性 | 工具 |
|------|---------|------|
| 单粒子轨道 | ✅✅ 完全 | Boris/引导中心 |
| 平衡位形 | ✅ 反演构造 | EFIT/Grad-Shafranov 求解器 |
| MHD 稳定性（理想模） | ✅ 谱问题 | 线性 MHD 码（MARS/CASTOR） |
| 波传播/线性响应 | ✅ 谱+共振 | 动理学色散关系数值解 |
| 非线性湍流输运 | △ 超算可算、实时不可 | GENE/XGC + 定标律兜底 |
| 破裂预测 | △ ML 预警 | 数据驱动（DISFA/FRNN） |
| 堆级多物理耦合 | 🔄 在建 | 中子学×热工×电磁×等离子体（IMAS 生态） |

## 不足层

- "可构造"的边界在移动：十年前湍流是"不可算"，现在超算上可算——
  但"可算"≠"可用于设计闭环"（验证确认 V&V 体系仍是半成品）
- 凝聚态等离子体支（金属电子气→等离激元）的"可构造"地图未展开

## ✍️ 练习

   并说明它为什么给磁镜约束上了"泄漏上限"（损失锥）
2. EFIT 反演是病态问题——边界约束+内部诊断不完备时解不唯一：
   这与 CT（计算机断层成像）逆问题的数学结构同在哪里？

   第一类积分方程不适定性）
3. 为什么破裂预警先于破裂理解？（工程规律：可预测性差的系统，
