## 二、逐条速写：为什么是这些算法

- **Boris 推进器（走廊①）**：时间中心差分 + 把速度旋转精确拆成
  两个半步——**体积守恒**（相空间不压缩），长期能量漂移为零。
  为什么是它：辛几何特性使它在万亿步下仍然稳定，四十年未被
  "更精确"的 Runge-Kutta 取代（RK 有耗散相位误差）。
  **工程师落点**：粒子推进是"读网格场→算力→写粒子"的流，
  GPU 上完美并行、显存带宽受限——与深度学习 kernel 同构
  （用户性能工程背景的天然接口）。
- **PIC（走廊②）**：连续 f(x,v) 换成宏粒子云——统计噪声 ~1/√N，
  λ_D ≥ Δx 是铁律（网格加热/不稳定性，见实验脚本注释）。
  信号/噪声比决定宏粒子数——本家族实验用 40 万宏粒子换 ~25%
  精度的屏蔽长度测量。
- **MHD（走廊③）**：守恒律+约束输运（8 波/CT 格式）保证 ∇·B=0
  到机器精度——与[讲透计算物理](../讲透计算物理/)的 CFD 骨架共享。
- **回旋动理学（走廊④）**：把回旋角积掉（5D 代替 6D），是本学科
  自己的"模型降阶"——但计算仍然爆炸，这就是"湍流王国"的
  现金价格（[03 章](03-可构造与结构.md)）。
- **集成建模（走廊⑤）**：不是解一个方程，是把几百个组件模型
  编排成工作流——数据标准（IMAS/IDS）比算法更关键——
  工程学问题而非物理问题。

## 三、可机械化边界

| 任务 | 机械化程度 | 边界原因 |
|------|-----------|---------|
| 线性色散关系（波谱） | 全自动 | 本征值问题，闭式+数值成熟 |
| 轨道/极光追踪 | 全自动 | ODE，Boris 即标准 |

| 破裂预警 | ML 数据驱动 | 物理第一性缺位，可预警≠可解释 |
| 新位形设计优化 | 前沿（代理模型/贝叶斯优化） | 多目标+多保真度混合 |

**裂缝清单**（原则上/工程上不可转）：

1. 湍流的实时数字孪生——计算量与放电时间尺度的鸿沟（原则可算，
   工程不可达；量子计算也未承诺）
2. 破裂的第一性预测——非线性阈值行为，数据先行
3. 边界等离子体（SOL/偏滤器）的完整动理学——开放场线+中性粒子+
   壁相互作用，多物理纠缠

## 四、Python 层：本家族实验的走位

[experiments/debye_shielding.py](experiments/debye_shielding.py) = 走廊② 的
最小完整标本（~160 行，纯 numpy+scipy），三幕：

- **Part A（方程路线）**：线性化 P-B 方程三对角解 vs 精确解
  sinh(L-x)/sinh(L)——最大误差 3.8×10⁻⁷（恰为二阶差分截断 O(h²) 量级）
- **Part B1（频率标定）**：密度正弦扰动激发等离子体振荡，谱分析实测
  ω_p = 0.524（本归一化的真值，不背标称）
- **Part B2（屏蔽涌现）**：中央固定测试电荷，40 万宏粒子自发重排，
  势剖面衰减成 exp 形，拟合 λ_fit = 7.40；能量漂移 0.08%（稳定性自证）

**核心断言（实证自洽）**：λ_fit = 7.40 vs v_th/ω_p,实测 = 7.64，
偏差 **3.2%**——模拟自己测出振荡频率与屏蔽长度，然后发现它们被
λ_D = v_th/ω_p 焊在一起（[00 章](00-体系结构.md) ✨美之时刻① 的计算化呈现）。

### 坑清单（本实验开发中逐一踩过——每条都值一次断言失败）

1. **λ_D ≥ Δx**：网格有限不稳定性（本例 λ_D=16Δx 安全）
2. **v_max·dt ≤ Δx**：Maxwellian 尾部粒子单步跳 3 格 → 力采样混叠 →
   相干加热爆出 ±12 的对称驻波（与源强度无关，最迷惑的一坑）
3. **E 的谱法符号**：E=-dφ/dx → E_k = **-i**ρ_k/k。写反 = 反向力 =
   负质量不稳定性：势飙至数百、与 Q 无关、随机装载同样发生——
   症状群与"神秘非线性"一模一样，其实是一行代码
4. **宏粒子保持真实荷质比**（q/m 不随权重缩放）；CIC 沉积按密度语义（÷Δx）；
   离散 FFT→连续变换（×Δx）
5. **等距"安静启动"与网格共振**（N/NG 为整数时 CIC 走样相干叠加出假势）——
   教科书 quiet start 必须打破格点共振

**为什么三幕**：A 证明"方程是那个方程"，B2 证明"那个方程从粒子动力学里
自己长出来"，B1 给出**独立的第二把尺**——三条腿互证，任何一条坏了
（符号、稳定性、归一化）都逃不过自洽断言。

等离子体的代码史=数值方法史的平行卷：Boris（1970）、PIC（Dawson 1962）、
谱法（FFT）、超算回旋动理学——每一代计算硬件都给这门学科开了一层新
楼层。承接：[讲透计算物理](../讲透计算物理/)（方法论母港）、
../../讲透高性能计算/（超算正主）、[讲透电磁学](../讲透电磁学/)
（场论的宪法层）。

**认知升维**：算法-物理共生眼——看到"算得动/算不动"的分界线时，
问一句"是物理难，还是算法还没找到它的 Boris？"很多学科的
"不可算"只是"还没遇到它的保结构算法"。
