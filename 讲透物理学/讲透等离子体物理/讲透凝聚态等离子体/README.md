# 讲透凝聚态等离子体 · 学科的哲学边境

> 这支负责：**固态里的"等离子体"**——金属传导电子气、半导体载流子、
  等离激元。GB/T 把它归入等离子体家族，物理上它是等离子体物理与
  凝聚态物理的两国界碑。

## 诞生

1928 年 Sommerfeld 金属自由电子气理论；1950s Bohm & Pines 把金属中
电子气的集体振荡（等离激元 plasmon）与屏蔽（屏蔽长度=金属里的德拜
长度，Thomas-Fermi 1927）纳入等离子体语言——同一套 ω_p、λ_D
在金属里全部适用，只是量子化接管。

## ✨ 这支最美的一个事实

一块铜的电子密度对应 ω_p ~ 10¹⁶ rad/s（紫外！）——**金属之所以有
金属光泽，是因为可见光频率低于它的等离子体频率，被整层电子云
集体反射**。"黄金为什么发光"的答案是"黄金是一面等离子体镜"。
