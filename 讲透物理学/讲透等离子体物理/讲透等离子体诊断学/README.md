# 讲透等离子体诊断学 · 看不见的东西怎么测

> 这支负责：**给第四态做体检**——一亿度、强辐射、不可接触的介质里，
> 温度、密度、电流、湍流每一样都要"隔空测量"。没有诊断就没有等离子体物理。

## 诞生

Langmuir 1924 静电探针（朗缪尔探针至今仍是教科书第一章）；
二战雷达技术反哺微波诊断；激光发明后汤姆逊散射（1960s）成为
托卡马克温度测量的金标准——诊断学史=物理与技术的接力赛。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 朗缪尔探针 I-V 曲线反演（密度/温度） | ✅ 经典已解（鞘层理论） |
| 汤姆逊散射（激光→谱展宽→T_e） | ✅ 金标准（但贵：大激光+弱信号） |
| 电子回旋辐射成像（ECE）剖面测量 | ✅ 常规化 |
| 湍流关联测量（束发射光谱 BES/反射计） | 🔄 前线（对比模拟谱） |
| 燃烧 α 粒子诊断 | ❌ 未解（ITER 关键缺口：14 MeV 中子/γ 本底中抓 α） |

## ✨ 这支最美的一个事实

测量一亿度电子温度的原理与测路灯温度相同——**多普勒展宽的谱线
宽度就是温度计**：热运动越乱，谱线越胖。宇宙尺度（恒星光谱分类）
与实验室尺度（托卡马克）共用同一支温度计。

## 假设与依赖

  天然不适定，正则化是日常
