# 讲透等离子体物理 · 物质第四态的集体行为

> **等离子体 = 大量带电粒子组成的、表现出集体行为的准中性气体。**
> 地球上它稀缺（闪电、极光、荧光灯），宇宙中它是常态——可见物质的 99% 以上
> 处于等离子体态。学科的全部戏剧在"集体"二字：每个粒子只受电磁力，
> 但亿万粒子的重新排布会产生气体永远做不到的事——**屏蔽电场、自我组织磁面、
> 集体振荡**。
>
> GB/T 13745：14055。宇宙：[讲透物理学](../README.md)·波2 家族（2026-09-07 建）。
> 五问模板家族成员；内容宪法=九要件（含 ✨美之时刻 与 认知升维）。

## 诞生

- **1928**：Langmuir 命名 plasma（血浆之喻——它"流动包裹电极如血包裹血球"）
- **1929**：Tonks & Langmuir 发现等离子体振荡——集体行为的第一性证据
- **1950s**：受控聚变两个源头同年出生——苏联 Sakharov & Tamm 提出托卡马克（1950），
  美国 Spitzer 提出仿星器（1951）；"和平利用原子能"日内瓦会议（1955）开启全球竞赛
- **推动力至今未变**：太阳的能量机制（Eddington 1920 之问）+ 能源终极方案

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 德拜屏蔽（Debye, 1923） | ✅ 已解 | 等离子体把电场"折叠"进 λ_D 尺度——准中性的来源，本家族第一课（见实验） |
| 等离子体振荡与朗道阻尼（Landau, 1946） | ✅ 已解 | 无碰撞的阻尼——共振粒子偷走波的能量；2018 年首次被直接实验证实 |
| 惯性约束点火 | ✅ **2022-12 NIF 达成** | 2.05 MJ 激光入 → 3.15 MJ 聚变出（增益 1.5）——人类首次"点火" |
| JET DT 脉冲 59 MJ（2021） | ✅ 已解 | 磁约束侧能量纪录；2023 年复现 |
| 磁约束 Q>1（聚变功率>加热功率） | ❌ 未解（ITER 在途） | ITER 目标 Q=10；2024 新基线推迟首次 DT 到 2039 年代 |
| 磁重联的快时间尺度 | 🔄 前线 | 理想 MHD 说磁场"冻结"不许断——但日冕耀斑毫秒级重联，机制仍未定论 |
| 湍流输运第一性预测 | ❌ 未解 | 托卡马克约束的核心损失通道；回旋动理学模拟（GENE/XGC）仍在超算上追实验 |

## 假设与代价（本家族站在哪）

| 假设 | 买到 | 付出 |
|------|------|------|
| 准中性（尺度 ≫ λ_D） | 可用流体/动理学连续描述 | λ_D 内的物理（鞘层）要单独理论 |
| 磁流体力学（MHD）单流体近似 | 一组方程管全局位形 | 丢掉速度空间结构（朗道阻尼、驱动电流全没了） |
| 碰撞足够频繁（经典输运） | 输运系数可推导 | 聚变堆芯恰恰是**无碰撞**的——输运被湍流主导，半经验接管 |
