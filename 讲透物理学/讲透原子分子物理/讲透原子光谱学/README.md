# 讲透原子光谱学 · 听原子报数

> 这支负责：原子的发射与吸收谱——能级差的直接读出，精度的世界纪录场。
>
> 家族：[讲透原子分子物理](../README.md)（14060·三级支）

## 诞生

1814 夫琅禾费记录太阳暗线；1859 基尔霍夫-本生确立"每种元素有自己的指纹"；
1885 巴尔末凑出氢的公式；1913 玻尔量子化解释之；1947 兰姆用微波
测出狄拉克方程之外的第 1057 MHz——光谱学两次改写物理学（量子力学、QED）。

## 核心问题（已解/未解）

- ✅ 氢原子光谱全谱系（Balmer/Lyman/Paschen…= 跃迁表）
- ✅ 精细结构与超精细结构（狄拉克方程；原子钟跃迁在超精细层）
- ✅ 兰姆位移（QED 的出生证明）
- ✅ 激光冷却的闭环（吸收-自发辐射循环）
- 🔄 质子半径之谜的收敛（μ氢 vs 电子氢，2010-2020s）
- ❌ R∞ 与 α 的最终位（测量精度仍在推进）

## 这支最美的一个事实

**真空本身会把能级推开**：兰姆位移不是原子内部的力，而是真空涨落
晃动了电子的位置——"空"的量子场有可测的力学效果（1057.8 MHz）。

## 假设与依赖

孤立原子（无碰撞展宽的理想）、二能级近似（拉比模型）、光源相干性。
依赖：[原子与分子理论](../讲透原子与分子理论/)（能级表）。
