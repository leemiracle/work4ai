# 讲透原子分子碰撞 · 原子如何相遇

> 这支负责：散射——截面、相移、碰撞参数：原子分子世界的"相互作用指纹"。
>
> 家族：[讲透原子分子物理](../README.md)（14060·三级支）

## 诞生

1911 卢瑟福散射（α 粒子打金箔——原子核的发现，散射实验的范式原点）；
1921 Ramsauer-Townsend 反常（低能电子散射截面出现极小——纯量子效应）；
1932-34 相移分析（部分波方法确立）——**碰撞是这个家族最早的"触觉"，
比冷却操控早了半个世纪**。

## 核心问题（已解/未解）

- ✅ 卢瑟福截面（经典库仑散射——原子核的存在证明）
- ✅ 部分波与相移 δ_l（散射 = 每个角动量道各转一个相位）
- ✅ Ramsauer-Townsend 极小（量子隧穿干涉，经典绝无）
- ✅ 超冷碰撞（s-波主导，散射长度 a 成为唯一参数——BEC 与 Feshbach 的地基）
- 🔄 冷碰撞的理论-实验对照（Feshbach 共振位置的高精度预测）
- ❌ 高激发态（里德堡）碰撞的完整理论（长程相互作用的复杂性）

## 这支最美的一个事实

**散射截面可以比"几何尺寸"还小**：Ramsauer-Townsend 极小处，
电子仿佛"穿过"了原子——不是躲开，而是围绕原子的物质波前后相消。
经典粒子永远做不到"存在却测不到"，量子波可以。
