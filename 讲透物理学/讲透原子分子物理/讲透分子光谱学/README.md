# 讲透分子光谱学 · 化学键的指纹

> 这支负责：分子的转动/振动/电子光谱——识别分子结构的最强探针。
>
> 家族：[讲透原子分子物理](../README.md)（14060·三级支）

## 诞生

1900s 红外与拉曼光谱起步；1928 年拉曼效应发现（光的非弹性散射读出
分子振动，1930 诺奖）；微波谱学（1930s-40s）测出键长键角到 5 位——
**"看"不见的分子被光谱量出几何**。

## 核心问题（已解/未解）

- ✅ 刚性转子/简谐振子模型（转动µeV、振动 meV、电子 eV 的三重分层）
- ✅ 拉曼散射选择定则（与红外互补：对称性镜像）
- ✅ 转动光谱→键长反演（分子几何学）
- ✅ 飞秒化学（Zewail，1999 诺奖——过渡态第一次被拍照）
- ❌ 大分子光谱的完全第一性预测（振转耦合的密集谱线）

## 这支最美的一个事实

**能量尺度三分天下相差约 10³ 倍**：转动（微波，~10⁻⁴ eV）、
振动（红外，~10⁻¹ eV）、电子（可见/紫外，~eV）——三种运动几乎不混合，
所以分子的"指纹"天然分三个波段，一张谱读出全部结构。

## 假设与依赖

玻恩-奥本海默近似（电子快、核慢——三重分层的来源）、谐性近似（低振级）。
依赖：[原子与分子理论](../讲透原子与分子理论/)（势能面）。
