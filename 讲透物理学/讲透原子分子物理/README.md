# 讲透原子分子物理 · 单个原子是最干净的实验室

> 原子分子物理：把一个原子从环境里**孤立**出来，量子力学就在它身上现出原形——
> 光谱是原子的语言，冷却是把语言放大的麦克风。
>
> GB/T 13745：14060（物理学·二级）。宇宙：[讲透物理学](../README.md)（GB13745 扩展·2026-09-07）。

## 诞生

📖 **夫琅禾费的暗线（1814）**：一位慕尼黑光学师的玻璃上刻着几百条神秘的太阳暗线。
没人知道它们是原子在"报自己的名字"。1885 年巴尔末从氢的四条可见光谱线里
凑出一个公式；1913 年玻尔用量子化把它"解释"出来——**原子的内部结构第一次
被光泄露**。此后的百年：卢瑟福散射（原子核）、斯特恩-盖拉赫（空间量子化）、
兰姆位移（QED 的出生证明）、拉比振荡（原子钟的母体）、1995 年 BEC（宏观量子物体）。
本家族的全部历史就是一部"越来越会跟单个原子对话"的历史。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 氢原子解析解（薛定谔 1926） | ✅ 已解 | 量子力学第一个全对的系统——教科书的地基 |
| 兰姆位移（Lamb–Retherford 1947） | ✅ 已解 | 狄拉克方程的小裂缝→重整化→QED 落地 |
| 氦原子基态（变分法/Exner 1926 系） | ✅ 已解（数值级） | 多电子世界的入场券——1 个电子就能解析，2 个就要近似 |
| BEC 实现（Cornell–Wieman–Ketterle 1995，诺奖 2001） | ✅ 已解 | 千万个原子共享一个波函数——物质的第五态 |
| 质子半径之谜（2010 起） | 🔄 争议收敛中 | μ氢与电子氢测出的质子半径长期不一致→新实验逐渐靠拢小子 |
| 精细结构常数 α≈1/137 为何是此值 | ❌ 未解 | 无量纲、出现在每一层原子理论里、无人知道其来源 |
| 强关联电子体系精确解 | ❌ 未解 | 多体薛定谔方程指数墙——量子化学全部近似方法的边界 |

## 假设与代价

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 孤立原子（与环境解耦） | 量子现象不被退相干抹平 | 实验代价极高：真空、囚禁、激光冷却 |
| 玻恩–奥本海默近似（核不动） | 分子问题降为电子问题 | 同位素效应、超快核运动被抹掉 |
| 微扰展开（修正项小） | 从氢出发逐级修到真实原子 | 强耦合时级数失控（QED 的朗道极点、强关联体系） |
