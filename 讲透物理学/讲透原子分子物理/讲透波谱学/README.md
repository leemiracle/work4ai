# 讲透波谱学 · 自旋在磁场里唱歌

> 这支负责：磁共振——NMR/EPR，用射频听自旋，原子钟与 MRI 共同的母体技术。
>
> 家族：[讲透原子分子物理](../README.md)（14060·三级支）

## 诞生

1938 年拉比实现原子核磁共振（分子束，1944 诺奖）；1946 年 Bloch 与
Purcell 在凝聚态中独立观测 NMR（1952 诺奖）；1960s-70s FT-NMR 与
MRI 概念（Lauterbur/Damadian）——**从物理系的地下室到医院的临床**，
波谱学是"物理技术变成医学基础设施"的最佳样本。

## 核心问题（已解/未解）

- ✅ 拉比振荡（二能级系统的驱动响应——一切磁共振的心跳）
- ✅ 布洛赫方程（弛豫 T₁/T₂ 的现象学）
- ✅ 化学位移与 J 耦合（NMR 区分化学环境——结构鉴定的原理）
- ✅ 傅里叶变换 NMR（灵敏度跃升）
- 🔄 量子传感（NV 色心自旋测磁，单分子灵敏度）
- ❌ 复杂耦合网络的全自动解谱

## 这支最美的一个事实

**一个自旋 ½ 就是一台量子比特**：能级差由磁场旋钮控制（ΔE=γℏB），
拉比振荡把自旋从"静态量子数"变成"可操控的量子门"——NMR 是量子计算
第一批实现的物理载体（1990s 液态 NMR QC）。

## 假设与依赖

二能级近似、玻尔兹曼布居（极化率 γℏB/2kT，室温下仅 ~10⁻⁵——
NMR 灵敏度低的根源）、弱耦合。依赖：[原子光谱学](../讲透原子光谱学/)
（超精细结构）。
