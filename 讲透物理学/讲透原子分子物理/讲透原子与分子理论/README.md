# 讲透原子与分子理论 · 算出能级与波函数的大脑

> 这支负责：给定原子/分子，把能级、波函数、跃迁元**算出来**——从解析解到
> 量子化学近似阶梯的全部理论工艺。
>
> 家族：[讲透原子分子物理](../README.md)（14060·三级支）

## 诞生

1926 年薛定谔方程解出氢原子（能与光谱对到第 5 位）；
1927 年海特勒-伦敦用变分法解 H₂ 化学键——**量子力学接管化学**；
1928 年 Hartree 提出平均场自洽场（SCF），1930 年福克加上交换——
现代量子化学的两块基石在同三年内立起。

## 核心问题（已解/未解）

- ✅ 氢原子与类氢离子解析解（薛定谔 1926）——教科书地基
- ✅ 氦基态变分解（精度竞赛延续至今，−2.903724377… Ha）
- ✅ HARTREE-FOCK 自洽场（多电子的平均场近似）
- 🔄 DFT 泛函的" Jacob 阶梯"逐级爬升（化学精度仍是工程圣杯）
- ❌ 强关联体系的系统化方法（指数墙）

## 这支最美的一个事实

**变分法永远不会猜过头**：任何试探波函数的能量期望 ≥ 真基态——
所以 90 年来氦原子能量是一个单调逼近的世界纪录榜。
