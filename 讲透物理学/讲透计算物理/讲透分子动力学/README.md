# 讲透分子动力学 · 逐帧解牛顿方程

> 定位句：**把 N 个原子的牛顿方程逐步积分，让温度、压强、相变从纯力学里自己长出来。**
>
> 自定主干支（GB/T 14075 无三级明细）。家族：[讲透计算物理](../README.md)。

## 诞生

Alder & Wainwright 1957（Livermore）：32 个硬球在计算机里碰撞，第一次看见
"计算机里的相变"——没有任何实验输入，集体行为从 F=ma 涌现。
Rahman 1964 把硬球换成连续势（LJ 液体氩），现代 MD 的模板就此定型。

## 这支最美的一个事实

单条轨迹在混沌下**指数失真**（Lyapunov），但温度/压强/扩散系数稳如泰山——
**你算的从来不是轨迹，是轨迹的统计**。（亲历：家族实验 lj_md.py 的能量曲线。）
