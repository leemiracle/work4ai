## 诞生（为什么有这门课）

1946 Ulam 的轮盘赌（蒙特卡洛）→ 1957 Alder-Wainwright 硬球（分子动力学）→
1964-85 Hohenberg-Kohn/Kohn-Sham/Car-Parrinello（第一性原理）——
三条线汇成"物理方法的第三根支柱"（Feynman 1982《用计算机模拟物理》是宣言书）。
