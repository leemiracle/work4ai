# 讲透第一性原理计算 · 不许调参数的物理

> 定位句：**从量子力学出发算材料——不拟合实验、不偷参数，ab initio 字面意思是"从开始"。**
>
> 自定主干支（GB/T 14075 无三级明细）。家族：[讲透计算物理](../README.md)。

## 诞生

Hohenberg-Kohn 1964（基态能量是密度的泛函——存在性）+ Kohn-Sham 1965
（变成可解的单粒子方程——构造性）→ 化学奖 1998。Car-Parrinello 1985
让电子与核同步演化，DFT+MD 焊成一体。

## 这支最美的一个事实

10²³ 个电子的多体问题被换成 N 个"有效单电子"方程——**多项式时间算指数问题**，
代价只是把全部多体智慧装进一个未知泛函 E_xc[ρ]："用一个小小的未知函数，
买断了整座希尔伯特空间。"

## 核心问题

| 问题 | 状态 |
|------|------|
| HK 定理 + KS 方程（1964-65） | ✅ |
| 平面波/缀加波/数值原子轨道基组 | ✅ 工具箱成熟 |
| 交换关联泛函的圣杯（LDA→GGA→meta-GGA→?） | ❌ 悬赏——强关联体系失灵 |
| O(N³) 对角化墙的突破（线性标度 DFT） | 🔄 大体系已可用，精度/稳定仍在磨 |

## 假设与依赖

玻恩-奥本海默 · 单电子近似（KS 图像）· 交换关联泛函的物理猜测——
第三条是全部精度争议的居所（误差不是数值的，是模型的）。
