# 讲透蒙特卡洛方法 · 用赌场打维度诅咒

> 定位句：**按概率抽样、数出现次数——误差 1/√N 且对维度免疫，是高维积分的唯一活路。**
>
> 自定主干支（GB/T 14075 无三级明细）。家族：[讲透计算物理](../README.md)。

## 诞生

Ulam 1946 病床上玩牌问概率 → "玩一百局数一数"；von Neumann 把它写上 ENIAC
算中子扩散；Metropolis et al. 1953（MANIAC 机）给出 `min(1,e^{-ΔE/T})`——
统计力学的抽样宪法诞生，史上被引最多的物理算法之一。

## 这支最美的一个事实

确定性格点积分 1 维天下第一、6 维已经力竭；蒙特卡洛 **100 维和 1 维同样从容**——
误差只看抽样次数 N，不看维度 d。"赌场免疫维度"。

样本独立性（自相关时间 τ：有效样本数 N/2τ）。
