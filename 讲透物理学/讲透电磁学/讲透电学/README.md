# 讲透电学 · 流动的电（唯象层）

> **定位句**：这支负责"电的流动学"——电流、电路、欧姆与 Kirchhoff，
> 把连续的场压缩成导线和元件上的电压电流（**集总抽象**——工程电磁学的第一发明）。

## 诞生

Volta 1800 年堆出电堆（第一个稳恒电源——"电流"从瞬间火花变成可持续的流）；
Ohm 1827 在贫困与冷遇中给出 V=IR；Kirchhoff 1845（21 岁，学生论文）写下两定律。

## 核心问题

| 问题 | 状态 |
|------|------|
| 欧姆定律的微观根据（电子漂移 vs 晶格散射） | ✅ 已解（Drude 1900 模型，量子修正归凝聚态） |
| Kirchhoff 两定律的地位 | ✅ 已解（=电荷守恒+能量守恒的电路化身） |
| 电阻的量子极限 | ✅ 已解（Landauer：电导量子 e²/h——介观物理） |
| 室温超导 | ❌ 未解（凝聚态物理家族主场，本支消费其结论） |

## 这支最美的一个事实

**Kirchhoff 两定律不是新物理**：节点定律=电荷守恒，回路定律=能量守恒——
两条宇宙级守恒律在电路图上的两行化身。

## 假设与依赖

集 lumped 抽象假设：元件尺寸 ≪ 波长（买到"场退化成路"，付出高频失效——
频率一高，导线变天线，须回到全波）。
