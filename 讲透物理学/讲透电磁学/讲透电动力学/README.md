# 讲透电动力学 · 场的电影：波、辐射与相对论

> **定位句**：这支负责"时变场"——麦克斯韦方程组全本、位移电流、电磁波、
> 辐射与相对论协变形式：整个家族的高潮章，物理学的第一个统一场论。

## 诞生

Faraday 1831 发现感应；Maxwell 1861-65 以位移电流补全方程组并算出
电磁波速=光速；Hertz 1887 用火花证实波的存在；Einstein 1905 从麦克斯韦
方程的协变性出发建立狭义相对论——**电磁学是相对论的产房**。

## 核心问题

| 问题 | 状态 |
|------|------|
| 电磁波的存在与光速 | ✅ 已解（1865 预言/1887 验证） |
| 辐射反作用（加速电荷如何反作用于自身） | ✅ 已解（Abraham–Lorentz；经典层的自洽税） |
| 洛伦兹协变形式 | ✅ 已解（Fμν/张量语言——02 章导演剪辑版） |
| 电磁质量的自洽性 | ✅ 已解（量子层：QED 重整化，经典层无解但被量子接管） |
| 磁单极子 | ❌ 未解（家族悬案，Dirac 1931 起） |

## 这支最美的一个事实

**c = 1/√(ε₀μ₀)**：实验室里测电容器（ε₀）和线圈（μ₀）的两个常数，
算出了光的速度——光被"算"出来，不是被"看"出来的。

## 假设与依赖

真空线性假设（买到波动方程与叠加，付出介质色散/非线性归光学与凝聚态）；
经典场假设（买到连续能量流，付出光子离散——QED 门槛，交棒 [讲透理论物理](../../讲透理论物理/)）。
