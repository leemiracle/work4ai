# 讲透静电学 · 静止电荷的场

> **定位句**：这支负责"静止电荷学"——库仑定律、Gauss 定律、电位、Poisson 方程、
> 镜像法与电容：电磁学中唯一完全进入"平衡态"的分支，也是对称性方法的大本营。

## 诞生

Coulomb 1785 用扭秤测出电力与距离平方成反比（精度 3%；与 Cavendish 的未发表
实验暗合）；Poisson 1813 引入电位把"力"翻译成"地势"；Green 1828 自费小册子
埋下格林函数（后被 Thomson 挖出，成为全部场论的解法母机）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 平方反比律的精度上限 | ✅ 已解至极高水平（偏离指数 <10⁻¹⁶，光子静止质量的上限——若非平方反差，光子有质量） |
| 导体静电平衡的唯一性 | ✅ 已解（唯一性定理——镜像法合法性的根据） |
| 一般电荷分布的解析场 | ❌ 原则上不可（可分坐标系仅 11 种——数值是正途） |

## 这支最美的一个事实

**Gauss 定律：对称性一选，积分不用做**——球对称选球面、轴对称选柱面、
无限大平板选药盒，通量被电荷一句锁定：三行字算出别人三页积分的场。

## 假设与依赖

静止假设（买到保守场与电位 φ，付出时变全灭——Faraday 感应会把 ∮E·dl 变非零）；
点电荷理想化（买到 1/r² 解析式，付出 r→0 奇点——量子电动力学来收拾）。
