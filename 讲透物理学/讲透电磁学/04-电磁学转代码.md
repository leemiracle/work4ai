# 04 · 电磁学转代码：正问题全自动、逆问题半自动、构造边界即前线

> **本章回答五问之五（本家族：讲透电磁学）。**
> 直觉图像先行：电磁问题进代码分三种命运——**正问题**（给源算场）像查地图，
> 全自动且成熟；**逆问题**（给场反源）像根据照片找拍摄地点，模糊要靠先验救；
> **解析解**（符号）像背下所有地图，只在少数对称城镇可行。
> 三件套：可机械化边界 · 代码走廊 · 工程师落点。

---

## 一、可机械化边界（为什么是这样：边界=问题良定型，不是"难不难"）

| 问题类 | 机械化档位 | 为什么 |
|--------|-----------|--------|
| 静电正问题（给 ρ 求 φ/E） | **全自动** | 椭圆型 PDE 良定，叠加+松弛/有限元成熟收敛 |
| 时域正问题（给初始场推演） | **全自动** | 双曲型+FDTD：显式步进，一阶精度起步可任意升 |
| 频域/谐振（天线 S 参数、腔体模式） | **全自动但贵** | 良定，但每个频点一次大规模稀疏求解——计算量的来源是物理（共振的锐度）不是算法 |
| 集总电路（电路图→响应） | **全自动**（SPICE 七十年工程） | Kirchhoff 两定律=线性代数——场的压缩已经人工完成 |
| **逆设计**（要响应反结构） | **半自动** | 病态：积分磨平细节；靠伴随梯度+先验正则化（01 章主战场） |
| 符号解析解（一般几何） | **不可机械化** | 边界条件组合爆炸；分离变量只对 11 种经典可分坐标系成立 |
| 拓扑效应（AB 相位、磁通量子化） | **原则上可算、构造上隐形** | FDTD 解的是 E/B，看不见 A 的轨道结构——结构信息要人为注入 |

**为什么是这样**：正/逆的分界=PDE 的适定性（Hadamard 三条件：解存在、唯一、
连续依赖数据）。电磁正问题全家族适定；逆问题天然不适定——这不是技术欠账，
是物理：远场对源的细节做了一次"低通滤波"，信息真的丢了，机器找不回不存在的东西。

## 二、代码走廊（问题类→算法→库/工具）

| 走廊 | 算法 | 工具生态 |
|------|------|---------|
| 静电/静磁 | 库仑叠加（粒子法）/松弛迭代/有限元 | 自写 NumPy（教学首选）/FEniCS |
| 时域全波 | **FDTD（Yee 交错网格）** | Meep（MIT，开源标杆）/自写（见下） |
| 频域全波 | FEM/矩量法 MoM | FEniCS/商业 HFSS·CST（工业标准） |
| 集总电路 | 改进节点法（MNA）+稀疏 LU | SPICE 系（ngspice/PySpice） |
| 逆设计 | 伴随优化/拓扑优化/代理模型+贝叶斯 | Meep 伴随/自写；01 章 AI 路线 |
| 符号 | 分离变量代码化/格林函数表 | SymPy（有限）；查表为先 |
| 快速远场 | 多极加速（FMM 思想） | 与 [讲透高性能计算](../../讲透高性能计算/) 共享 |

**教学最短路径**（本家族 experiments/ 的立场）：NumPy 手写——
叠加原理+欧拉步进，两页纸看到"场"从公式变成数组。工业路径再换 Meep/FEM。

## 三、工程师落点（性能工程视角）

1. **FDTD 是 stencil 计算的教科书 workload**：每步只访问邻格——**访存受限**，
   算术强度 O(1)。优化三板斧=时间分块提升数据复用、向量化（SIMD）吃掉内层
   空间维、多 GPU 面切分（与 [讲透GPU与系统级](../../讲透GPU与系统级/) 的
   stencil 优化同源——电磁仿真是 CUDA 课堂的常驻例题）。
2. **CFL 条件是电磁版"稳定阈值"**：显式格式稳定要求 Δt ≤ Δx/(c√d)。这是
   [讲透数学/讲透分析/讲透偏微分方程](../../讲透数学/讲透分析/讲透偏微分方程/)
   实验 heat_cfl 的波动方程兄弟——但注意方向相反：热方程超阈值**爆**、欠阈值稳；
   波动方程 CFL 是精度与稳定的共同约束（数值色散随 Δt 接近阈值恶化）。
3. **频域=大规模稀疏线性代数**：谐振问题的求解器谱（直接法 vs Krylov）选择
   直接决定仿真吞吐——[讲透数学/讲透分析/讲透泛函分析](../../讲透数学/讲透分析/讲透泛函分析/)
   的 Krylov 走廊在此落地。
4. **信号完整性/EMI/天线**：计算电磁的工业三大主场——手机里每根走线的阻抗
   都是一次微型全波求解。

## 四、Python 层：本家族实验速览

`experiments/fields_and_rc.py` 演示两条最短走廊：

```
走廊A（场叠加）：偶极子 = 两个点电荷场数组相加 → 与解析式 |E_轴| = 2kp/r³ 对照
走廊B（集总步进）：RC 充电 dQ/dt = (V−Q/C)/R 欧拉步进 → 与 Q(t)=CV(1−e^{−t/τ}) 对照
```

断言含义：**走廊的正确性可以用另一条走廊交叉验证**（数值 vs 解析=免费单元测试）——
这是电磁学"可构造性最好"的直接工程红利。

## 五、裂缝清单（原则上不可/工程上难转）

| 裂缝 | 性质 |
|------|------|
| 逆问题的信息损失 | 原理性（低通滤波）——正则化是补先验，不是找回信息 |
| 一般几何解析解 | 原理性（可分坐标系穷尽表就 11 种） |
| 拓扑量的自动发现 | 工程性——求解器算 E/B，不知道 A 的轨道；需人工把拓扑荷塞进模型 |
| 量子发射/光子关联 | 原理性——经典方程组无此自由度（QED/计算物理侧） |
