# 讲透静磁学 · 恒定电流的磁场

> **定位句**：这支负责"恒定电流生磁"——Biot–Savart、Ampère 环路定理、矢势 A：
> 静磁是静电的"不对称孪生"（有电流源却无磁荷汇，∇·B=0 从出生就写进户口）。
> 注：磁性物质（铁磁/顺磁等）属 GB/T 14050 凝聚态物理的"磁学"三级——本支只讲电流的磁。

## 诞生

Oersted 1820 发现电流磁效应（[家族 00 章故事框](../00-体系结构.md)）；
Biot–Savart 同年给出定量律；Ampère 两周内建立电流间作用力的数学；
1825 Ampère 猜想"磁就是环电流"——分子电流假说，超前于原子论一个世纪。

## 这支最美的一个事实

**∇·B=0 的厨房验证**：把条形磁铁切两半，得到的永远是两根小磁铁——
"磁极单分离"在宇宙中从未发生，每一步切割都在复述"无磁荷"公理。

## 假设与依赖

恒定电流假设（买到 ∇×B=μ₀J 的静态自洽，付出位移电流=0 的近似）；
连续电流密度假设（买到积分计算，付出穿透深度的皮肤效应修正——时变归电动力学）。
