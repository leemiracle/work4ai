# 讲透电磁学 · 电与磁是一枚硬币

> **本质一句话**：电与磁不是两门学科，是一种场的两种表现——光是它俩握手的涟漪。
> 库仑的静电、奥斯特的电流磁效应、法拉第的感应，最终被麦克斯韦四条方程收编，
> 并被赫兹的火花和爱因斯坦的相对论双重加冕。
>
> GB/T 13745：14035（物理学·二级）。宇宙：[讲透物理学](../README.md)。
> 九要件宪法（母版 [数学 GB13745 全景 spec §5](../../docs/superpowers/specs/2026-09-06-讲透数学GB13745全景-design.md)）。

## 诞生（三个原生问题 + 关键人物链）

| 问题 | 事件 |
|------|------|
| 摩擦过的琥珀为什么吸稻草？ | Thales 记录静电；Gilbert 1600《论磁》区分电与磁 |
| 天上的闪电与地上的电是一回事吗？ | Franklin 1752 风筝实验（统一天电地电） |
| 电流能让罗盘偏转，磁能生电吗？ | Oersted 1820 → Faraday 1831 电磁感应 → Maxwell 1865 方程组 → Hertz 1887 电磁波 → Einstein 1905：电磁学天然是相对论的 |

## 核心问题清单（详 00 章）

已解决：库仑定律（1785）· 电磁感应（1831）· **麦克斯韦统一与光=电磁波（1865/1887）** ·
规范不变性与相对论形式（1905）· QED 重整化（1940s-50s，理论物理侧重）
未解/悬置：**磁单极子**（Dirac 1931 预言，至今零发现——但其存在可解释电荷量子化）·
真空 ε₀/μ₀ 数值的终极解释（标准模型参数问题）

## 假设与代价（详 00/02 章）

宏观连续介质假设：买到偏微分方程的可解性，付出隐藏电荷量子离散；
规范势 A 的不可观测假设：买到规范自由度的计算便利，付出 AB 效应式的拓扑惊喜。
