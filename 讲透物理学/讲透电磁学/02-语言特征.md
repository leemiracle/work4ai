# 02 · 语言特征：场语言、微分形式与规范原理

> **本章回答五问之三（本家族：讲透电磁学）。** 表达？逻辑？规范化？
> 直觉图像先行：电磁学有三层语言，像同一部电影的三个版本——
> **矢量分析**（大众版，E/B 两个箭头场）、**张量版**（专业版，Fμν 一个 4×4 矩阵）、
> **微分形式**（导演剪辑版，dF=0、d★F=J 两行）。语言越高级，电与磁的界限越模糊，
> 最后消失在"只是一个场"里。

---

## 一、表达力：场语言能说什么、说不了什么

**能说的**：

| 语言层 | 陈述样例 | 表达力来源 |
|--------|---------|-----------|
| 积分形式（Gauss/Ampère 的通量环流量） | "穿过这面的通量=面内电荷"——**拓扑式陈述**，不依赖度量 | 对称性场合秒杀（球形对称选球面，积分不用做） |
| 微分形式（div/curl） | ∇·E=ρ/ε₀——每点的局部律 | 局域因果：一点的场由无穷近邻决定 |
| 相对论张量 Fμν | 一条短方程；E、B 是同一矩阵在不同参考系投出的影子 | 统一电与磁（"磁=电的相对论妆容"的严格版） |
| 势语言（φ,A） | F=dA——**两个势分量生成六个场分量** | 预言权：势有方程组还没看到的自由度（规范） |

**说不了的**（表达力边界——诚实清单）：

- 经典麦克斯韦说不了**光子的离散性**（黑体辐射、光电效应——QED 的地盘，14015 理论物理侧）
- 说不了**电荷为什么量子化**（q 全是 e 的整数倍这一事实在方程组外）
- 场本身的力学介质（"电磁以太"）——被相对论判了死刑：场自己就是"物质"，不需要介质

## 二、逻辑性质：超定而相容的方程组

麦克斯韦方程组有个罕见的逻辑品格：**四个方程、两个未知矢场，表面超定**——
但恰好被电荷守恒（连续性方程）缝合得严丝合缝：

```
∇·B = 0            （无磁荷——比类磁场缺失更深刻的对称破缺）
∇·E = ρ/ε₀
∇×E = −∂B/∂t       （Faraday）
∇×B = μ₀J + μ₀ε₀ ∂E/∂t （Ampère+Maxwell 位移电流 ★）
```

取第四条的散度，左边=∇·(∇×B)=0 恒成立，于是右边逼迫 ∇·J = −∂ρ/∂t——
**电荷守恒不是额外公理，是方程组的自洽税**。（这正是位移电流被"数学地"逼出来的地方。）

- **规范不变性=冗余自由度**：A→A+∇χ 后一切可观测量不变。物理=商空间
  （规范轨道的集合）——这是整个粒子物理标准模型的母模板（U(1) 规范理论）。
- **因果结构**：方程是双曲型——信息以 c 传播，解有光锥结构（与狭义相对论互为表里）。

## 三、规范化：从实验律到公理组的完成度

| 阶段 | 形态 | 完成度 |
|------|------|--------|
| 唯象层（1785-1831） | 库仑/毕奥-萨伐尔/法拉第——一条条实验律 | 各自成立，互不相干 |
| 统一层（1865） | Maxwell 方程组——**电磁学自己的"公理"** | 物理学中第一个达到数学级公理化的场论 |
| 协变层（1905） | 洛伦兹不变的张量/形式语言 | 规范化封顶：换参考系方程形式不变 |
| 量子层（1948-） | QED：U(1) 规范场论的重整化完成 | 本家族止步于门口（交棒理论物理） |

**为什么是这样**（02 章每栏必答）：电磁学能率先完成规范化，因为它处理的是
**线性**场+**长程**作用——方程足够简单到被完全写下，又足够丰富到包含波、
辐射、因果与拓扑（AB 效应）的全部结构。它是唯一一门"可以整个装进两行微分形式
还保留全部物理"的宏观场论。

## 四、Python 层

`experiments/fields_and_rc.py` 的第一部分就是"场语言"的可执行版：
把偶极子场写成每点一个矢量的数组操作（NumPy 广播=场语言的原生口音），
解析式 E_轴 = (1/4πε₀)·2p/r³ 与数值叠加互相验证——语言说的和算的对上了。

## 不足层

- 本家族的语言=**经典**电磁；进入 QED 后"场"的含义升级为算符值分布，语言换血
  （[讲透理论物理](../讲透理论物理/) 接力）
- 微分形式语言的美以"介质均匀"为代价；复杂介质（张量 ε、μ）下 ★ 算子携带了
  材料信息，两行的极简被打破

✨ **美之时刻 2：∇·B = 0 的孤独**　四条方程里只有它是"没有源"的。
为什么美：**意外**——对称性要求磁荷存在的地方，宇宙留了空位；它还是拓扑守恒的
保证（磁通量守恒 ⇔ 无磁单极）。怎么亲历：拿一个条形磁铁切两半，永远得到两根
完整磁铁——你在厨房里验证 ∇·B=0。
