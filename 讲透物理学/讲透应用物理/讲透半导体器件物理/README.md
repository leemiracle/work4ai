# 讲透半导体器件物理 · 把能带论装进开关

> **定位**：这支负责"如何在固体里造出可控的电流开关与放大器"——
> 从 PN 结到 FinFET，全部现代计算的物理底座。

## 诞生

1947 年平安夜前夜，Bell 实验室 Bardeen–Brattain 点接触晶体管演示成功；
Shockley 随后以结型晶体管给出可制造版本（三人 1956 年诺奖）。
1960 年 MOSFET、1968 年 Intel 成立——能带论（1927–33 年的纯理论）落地为产业。

## 核心问题（3-5 条）

- ✅ 已解：PN 结整流方程（Shockley 1949）；MOSFET 缩放律（Dennard 1974）——"缩小即提速降价"统治五十年
- ✅ 已解：量子隧穿从敌人变工具（隧穿二极管、Flash 存储、隧穿场效应管）
- 🔄 前线：亚阈值摆幅 60 mV/dec 室温热物理锁的绕行（负电容/隧穿器件）
- ❌ 未解：摩尔之后——新沟道材料（二维半导体）与三维堆叠的经济学平衡

## ✨这支最美的一个事实

MOSFET 的栅氧化层只有**十几个原子厚**，电子隧穿电流大到足以被仪器直接测量，
器件却仍按规格工作数十年——人类最大的工业，建立在一层"不该可靠却可靠"的玻璃薄层上。

## 假设与依赖

能带论+有效质量近似（来自[凝聚态物理](../../讲透凝聚态物理/)）；
尺寸缩小假设"电场形状不变"（Dennard 缩放——2005 年后漏电流终结了这条假设的普适性）。

## 教材锚

- Streetman《Solid State Electronic Devices》（入门）
- Pierret《Semiconductor Device Fundamentals》
