# 讲透应用物理 · 从定律到产业的中转站

> 应用物理：**把"理解了"变成"造出来"**——物理原理→工程器件→产业规模的翻译层。
> GB/T 13745 原注："具体应用入有关学科"——所以本家族不是内容分支，是一张**通道卡**：
> 三条主干通道（半导体器件物理·激光应用·医学物理）各通向一个万亿级产业。

## 定位声明（本家族怎么读）

本宇宙其他家族讲"物理知道什么"；本家族讲"物理怎么变成东西"。
GB/T 把 14080 设为出口而非仓库——任何物理分支落地成器件，就从这里出发。

## 诞生（三个原生问题）

| 问题 | 年代 | 结局 |
|---|---|---|
| 电话需要放大器，真空管又大又脆 | 1947 | 晶体管（Bardeen–Brattain–Shockley，1956 诺奖）→ 半导体产业 |
| 雷达与通信需要纯度极高的光 | 1960 | 梅曼红宝石激光 → 光通信/加工/医疗/引力波探测 |
| 想看穿人体又不想切开 | 1895→1971 | X 射线（伦琴）→ CT（Hounsfield，1979 诺奖）→ 医学影像产业 |

## 核心问题清单（详 00 章）

已解决里程碑：晶体管（1947）· 激光（1960）· CT 重建（1971）· 光伏 S-Q 极限理论（1961）。
悬而未决：聚变能量增益到商用（Q_engineering≫1）· 量子计算的纠错开销 · 摩尔之后是什么。

## 假设与代价

本家族假设：**物理定律可以封装进器件**。买到规模（一个方程变成十亿件产品）；
付出工况复杂性（温度/噪声/老化/良率——实验室里不存在的东西，产线上全是）。
