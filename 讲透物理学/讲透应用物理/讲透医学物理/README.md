# 讲透医学物理 · 看穿与杀死之间的精确制导

> **定位**：这支负责"用物理原理诊断与治疗人体"——影像（看穿）与放疗（杀死癌细胞不伤好人）。
> 它的伦理特别之处：错误直接以患者计费。

## 诞生

1895 年伦琴发现 X 射线，三周后即用于骨折拍摄——物理学史上"发现到应用"最短纪录。
1971 年 Hounsfield 首台 CT（1979 诺奖）；1951 年第一台医用直线加速器放疗；
1977 年 MRI 成像（2003 诺奖）。

## 核心问题（3-5 条）

- ✅ 已解：从投影重建图像（Radon 1917 → CT 1971——数学等了机器 54 年）
- ✅ 已解：适形调强放疗（IMRT）——剂量分布雕刻到与肿瘤形状共形
- ✅ 已解：质子治疗 Bragg 峰（射线在设定深度集中释能，出口剂量近乎零）
- 🔄 前线：FLASH 放疗（超高剂量率下正常组织损伤反常降低——机理仍未定论）
- ❌ 未解：实时剂量验证（"边照边看"的在线成像-剂量闭环）

## ✨这支最美的一个事实

CT 的数学（Radon 变换）1917 年发表时**没有任何应用预期**，
54 年后才被 Hounsfield 用来重建大脑切片——纯数学与救命之间，
隔着一台机器的距离，和半个世纪的等待。

## 假设与依赖

核衰变与粒子输运（来自[原子核物理](../../讲透原子核物理/)）、原子光谱（[原子分子物理](../../讲透原子分子物理/)）、
磁共振（量子力学角动量+经典射频工程）；剂量学站在统计生物学（细胞存活曲线 LQ 模型）上——
物理精确，生物效应只能统计近似，这是本支永久的张力。
