## 〇、本质一句话（要件①）

**原子核物理研究"核子（质子+中子）如何被强相互作用捆成一滴、这滴如何裂变/聚变/衰变"**——
它是唯一一门"对象小到飞秒费米、后果大到战争与能源"的物理分支。

## 一、诞生（要件②）

📖 **1896-1932 的三十六年连环剧**：贝克勒尔抽屉里的铀盐让底片感光（1896，放射性）；
卢瑟福用 α 粒子打金箔发现"原子几乎全空、质量集中在一颗核"（1911）；
查德威克找到那个"失踪的中子"（1932）——从此质子+中子的图像成立，
核物理在三年内同时解释了同位素、写下了中子俘获的核合成剧本。

## 四、假设与代价（要件④，详表见 00/02 章）

核物理没有"从 QCD 直接解"的 luxury——所有模型都是**分层近似**：
买"可算"，付"每层有适用边界"。液滴买直觉付细节；壳层买幻数付关联能；
集体模型买转动振动谱付单粒子图像。
