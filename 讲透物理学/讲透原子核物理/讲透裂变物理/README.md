# 讲透裂变物理 · 液滴的断裂力学

> **定位**：这支研究重核如何一分为二（或三）——裂变势垒、碎片分布、
> 中子倍增、链式反应。核能的反应堆侧全部物理。
>
> GB/T 13745：14065·三级"裂变物理"。家族：[讲透原子核物理](../README.md)。

## 诞生

Hahn & Strassmann 1938 化学实锤（钡出现在铀辐照产物里）；
Meitner & Frisch 1939 圣诞雪夜用液滴模型算出 ≈200 MeV 并命名 fission；
Zr 1939（Zeldovich-Khariton 苏联侧）与 1942 CP-1（Fermi）把链式反应变成工程。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 液滴形变→断裂的机制图像 | ✅ 一级图像成立（细节由密度泛函 TD-DFT 精化） |
| 碎片质量分布（双峰）成因 | 🔄 多体动力学仍在算（马赫波/断裂涨落） |
| 链式反应临界理论 | ✅ 工程百年 |
| 延发中子与堆控 | ✅ 缓发临界是反应堆安全的全部余量（k_eff 差 0.65%） |

## ✨ 这支最美的一个事实

**全世界的反应堆都靠"迟到 13 秒的中子"安全运行**——裂变中子 99.35% 瞬发、
0.65% 由碎片衰变缓发（秒级）。只靠瞬发中子临界=炸弹；缓发中子让 k_eff
能被机械控制棒追上——文明级别的安全余量，来自 0.65% 的迟到者。

## 假设与依赖

液滴+壳修正（双峰碎片分布需要幻数碎片 ¹³²Sn 的壳效应）；链式反应依赖
中子代时间与缓发份额的分离（点堆动力学方程组）。
