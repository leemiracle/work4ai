# 讲透核结构 · 核的解剖学

> **定位**：这支回答"一个核为什么是这么大、这么稳、这个形状"——质量、半径、
> 形变、能级体系的全景。液滴→壳层→集体三层模型是它的骨架。
>
> GB/T 13745：11065→14065 原子核物理学·三级"核结构"。家族：[讲透原子核物理](../README.md)。

## 诞生

Weizsäcker 1935 用液滴五项公式写出第一条结合能曲线；Mayer 与 Jensen 1949
各自发现自旋-轨道耦合让幻数立正（Nobel 1963）；Bohr & Mottelson 1950s
补上集体转动与振动（Nobel 1975）。三十年三层楼。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 幻数 2/8/20/28/50/82/126 的起源 | ✅ 已解（1949） |

| 质量公式 A>250 区预言 | ❌ 模型分歧数量级（稳定岛之争） |

## ✨ 这支最美的一个事实

**一个平均势阱 + 一项 l·s 耦合 = 幻数整队立正**——没有可调余地，要么全对要么全错；
它对了（2, 8, 20, 28, 50, 82, 126）。

## 假设与依赖

平均场近似（每个核子感受其余核子的平均作用）——买到可算性，付出关联能
（对能与长程关联需另补 BCS/投影）。
