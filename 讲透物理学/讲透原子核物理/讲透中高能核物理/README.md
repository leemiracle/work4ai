# 讲透中高能核物理 · 核熔化成夸克的地方

> **定位**：这支问"当能量高到核子不再是刚体，核会发生什么"——核子内部结构
> （EMC 效应）、介子自由度、夸克-胶子等离子体（QGP）。它是核物理与
> [讲透高能物理](../../讲透高能物理/) 的界桥。
>
> GB/T 13745：14065·三级"中高能核物理"。家族：[讲透原子核物理](../README.md)。

## 诞生

Hofstadter 1950s 电子散射测核子半径（Nobel 1961）；1983 EMC 效应
（束缚核子内部结构与自由核子不同）；1986-2000s CERN SPS 与 BNL RHIC
先后宣称/确证 QGP；2010s LHC 重离子项目——QGP 成为"最热的物质"
（数万亿 K，宇宙大爆炸后微秒级重演）。

## ✨ 这支最美的一个事实

**QGP 是人类造出的最完美的液体**——粘度/熵密度比逼近理论下限（AdS/CFT
全息对偶预言 KSS 下限），比水"完美"十几个数量级：把两颗金核撞到几万亿度，
得到的不尘气散的气体，而是近乎零粘滞的液体。反直觉之冠。

## 假设与依赖

相对论性重离子动力学（流体力学+输运双层描述）；信号读出依赖多重关联
（椭圆流 v₂、喷注淬火、J/ψ 压制）——单粒子信号在 QGP 研究中几乎不存在。
