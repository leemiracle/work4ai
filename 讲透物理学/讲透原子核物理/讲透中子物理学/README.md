# 讲透中子物理学 · 无电荷的探针与火种

> **定位**：这支研究中子本身——产生、慢化、衍射、俘获、探测。
> 中子无电荷：既能当探针（不受库仑势垒阻挡）、又是链式反应的火种（每次裂变放 2-3 个）。
>
> GB/T 13745：14065·三级"中子物理学"。家族：[讲透原子核物理](../README.md)。

## 诞生

Chadwick 1932 发现中子；Fermi 1934 中子辐照慢化发现超铀元素（实为裂变，错过诺奖的著名乌龙）；
Hahn-Strassmann 1938 裂变 + Meitner 解释；Fermi 1942 CP-1 首个链式反应堆——
"意大利航海家登陆新大陆"。

## ✨ 这支最美的一个事实

**中子寿命两种测量法差 8 秒且都不让步**——束流数中子 vs 材料数质子（衰变产物），
两种方法各自系统误差极小却互相矛盾：可能是"中子→质子+电子+反中微子"之外
还藏着不可见衰变道的信号。一个 8 秒的缺口，通向新物理。

## 假设与依赖

中子=电中性强子（β 衰变 t₁/₂≈10.2 min）；探测靠次级电离（反冲质子/核反应）——
中子本身不直接电离，探测永远是间接艺术。
