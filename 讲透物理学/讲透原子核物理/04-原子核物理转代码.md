# 04 · 原子核物理转代码：核数据库、输运蒙卡与质量公式工程

> **本章回答五问之五（本支：讲透原子核物理）。**
> 核物理是**最早把学科资产数据化**的物理分支：全世界反应堆设计共用一套核数据库、
> 粒子输运蒙特卡洛是 HPC 史上最长寿的 workload 之一。走廊清楚、边界也清楚。

---

## 一、可机械化边界总表

| 任务 | 可机械化 | 形态 |
|------|---------|------|
| 结合能/质量估算 | ✅ 全自动 | Weizsäcker/Frankfurt-Dresden FRDM 查表或公式 |
| 衰变链演化 | ✅ 全自动 | Bateman 方程 ODE（确定性）或蒙卡 |
| 中子/光子输运 | ✅ 全自动（工程级） | 蒙特卡洛（MCNP/GEANT4/OpenMC）或 SN 确定论 |
| 壳层模型能级 | 🔄 半自动 | 大空间对角化要专家截断（03 章指数墙） |
| 截面评估 | 🔄 半自动 | 实验+R 矩阵拟合+模型外推——评估员判断在内环 |
| 核力从 QCD | ❌ 原则可算工程不可 | 格点 QCD 计算量（⑤档墙） |
| 超重核半衰期 | ❌ 模型分歧数量级 | 稳定岛经纬度未定（01 章） |

**为什么是这样**：核物理的"数据先行"文化（ENDF 1950s 起）让工程侧走廊异常平整；
而理论侧的指数墙（03 章）让"从第一性算截面"留在研究侧。

## 二、代码走廊清单

### 走廊 1：核数据库（学科的"标准库"）

- **ENDF-6 格式**（评价核数据库国际格式）／**ENSDF**（能级数据）
- 消费方式：NJOY 加工成群常数/连续库 → 输运程序吃
- Python 侧：`openmc.data` 读写 ENDF；IAEA/NNDC 在线 API

### 走廊 2：输运蒙特卡洛（本支工程主战场）

- 蒙特卡洛中子/光子/电子输运：**OpenMC**（开源、Python API、社区活跃）/
  MCNP（美国国宝闭源）/ GEANT4（高能侧通用，[讲透高能物理](../讲透高能物理/) 共用）
- 静态质量公式走廊：Weizsäcker → 本家族实验即其最小实现
- 衰变链：Bateman 方程 `dN/dt = A·N`（系数矩阵三角化求解）；
  Python `radioactivedecay` 库现成

### 走廊 3：核反应网络（天体物理侧）

- r-process/pp 链/CNO：数千核素联立 ODE——`SkyNet`/`WinNet` 开源
- 输入=质量+截面+半衰期（走廊 1 的数据），输出=丰度曲线（01 章的"金从哪来"数值版）

### 走廊 4：壳层模型计算

- `BigStick`/`KSHELL`/`NuShellX`——大空间 Lanczos 对角化；
  门槛=模型空间与相互作用的专家选择（可机械化边界外的半自动区）

## 三、工程师落点（性能工程视角）

1. **输运蒙卡=HPC 祖师爷**：粒子历史相互独立→天然并行；但"计数箱"归约与
   蒙特卡洛去方差（权重窗）是真优化点。OpenMC 在 GPU 上的迁移是近年系统侧热点——
   与 ../../讲透高性能计算/ 的 workload 谱直接相接
2. **数据表=内存带宽问题**：连续能量库的点查+插值是访存受限 workload——
   与深度学习 embedding 查表同构（cache 友好布局的同一门手艺）
3. **衰变 ODE=刚性系统**：半衰期跨 40 个数量级→刚性问题专治（隐式积分器/BDF），
   与化学动力学同款数值病
4. **核数据不确定度传播**：蒙卡抽样×协方差矩阵——抽样设计即统计工程
   （../../讲透数学/讲透高维概率/ 的应用现场）

## 四、裂缝清单（不可转/慎转）

- **"查 ENDF 就有截面"的错觉**：评估值含模型外推（未测能区=理论填的）——
  工程使用必须看协方差与评估注释
- **蒙卡结果的沉默偏倚**：几何/源项/库版本的系统性错误不在统计误差棒里
- **跨档混用**：拿①档质量公式做同位素甄别级应用（如同位素比质检）是档位错配——
  那是质量表（AME2020 量级实验评估）的辖区
- **壳层模型"一键运行"的幻觉**：程序能跑≠空间选对了——构造力③档的门槛在输入端

## 不足层

- 工程走廊平整是"数据侧"的平整；理论侧（③-⑤档）没有走廊只有登山路线
- 开源生态断层：MCNP 闭源半个世纪，OpenMC 补位但认证生态（监管级）仍在重建
- 核数据协方差的完整传播到终端应用（剂量/临界安全）仍是半手工环节

## ✍️ 练习

1. 用 Bateman 方程推 3 代衰变链的解析解，验证数值积分器（scipy solve_ivp）——
   并找出"刚性感"来自哪一项
2. 为什么输运蒙卡的并行效率在"计数归约"处掉坑？（粒子独立=计算并行；
   计数箱=共享写——Amdahl 定律现场）
3. 反直觉：截面单位是"面积"（barn），为什么工程上真正限制产能的是"亮度"
   （luminosity=束流×靶密度）？（截面是概率密度，产出率=亮度×截面——
   pb 时代的瓶颈从来不在概率而在机器）
