# 讲透聚变物理 · 恒星的燃烧室

> **定位**：这支研究轻核如何合一——库仑垒隧穿、等离子体约束、点火自持。
> 核能的太阳侧：能量密度冠军 + 燃料取之海水 + 无长寿命高放废料。
>
> GB/T 13745：14065·三级"聚变物理"。家族：[讲透原子核物理](../README.md)。

## 诞生

Eddington 1920 提出恒星烧氢（被同代物理学家嘲笑"太玄"）；
Atkinson-Houtermans 1929 量子隧穿点燃聚变理论；Bethe 1938 pp 链/CNO（Nobel 1967）；
1950s 氢弹与受控聚变分岔；Spitzer 仿星器与苏联托卡马克路线之争六十年。

## ✨ 这支最美的一个事实

**太阳烧得这么慢，全靠 β⁺ 衰变当"节流阀"**——pp 链第一步 p+p→d+e⁺ν 是弱作用
（截面 ~10⁻²³ barn 量级），慢到每颗质子平均等 90 亿年才聚变一次：
太阳因此烧 100 亿年而不是 100 亿天。弱相互作用的"慢"是生命的时钟。

## 假设与依赖

量子隧穿（Gamow 因子）给出可聚变截面；麦克斯韦尾×截面×密度=反应率
（Gamow 峰=两者乘积的窄窗口）；磁约束假设等离子体准中性+磁面拓扑。
