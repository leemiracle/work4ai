> **定位**：这支用最简单的炮弹（核子/氘/α）打最简单的靶，读出**核力本身**——
> NN 相移、氘基态、三核子体系。它是核物理的"原子物理"：对象小到可以较真。
>
> GB/T 13745：14065·三级"轻粒子核物理"。家族：[讲透原子核物理](../README.md)。

## 诞生

1930s 氘核发现（Chadwick 1932 旁证中子-质子束缚）；1950s NN 散射相移分析
（phase shift analysis）黄金期；1957-60 氘基态性质（电四极矩→张量力）；
Faddeev 1960 三体方程——少体物理的可解化。

## ✨ 这支最美的一个事实

**氘核只有一个束缚态且没到基态谱的底**——两核子体系仅 2.2 MeV 一条束缚能级，
激发全在连续区：核力"勉强够绑一对，绝不富余"。对比原子核深势阱的丰富谱，
氘是核力的"临界案例"——这也是为什么三体（³H/³He/⁴He）结合能才是检验三体力的量尺。

## 假设与依赖

两体相移分析假设"核力=两体可加"（三体力当微扰处理）——三体破缺正是这个
假设的测量仪；手征有效场论（chiral EFT）给核力以 QCD 一致的分级展开。
