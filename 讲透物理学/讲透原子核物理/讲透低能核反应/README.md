# 讲透低能核反应 · 撞出来的知识

> **定位**：这支回答"用炮弹撞核能知道什么"——散射、共振、复合核、光学模型。
> 核物理的实验语言学：截面 σ(E,θ) 是它的一切。
>
> GB/T 13745：14065·三级"低能核反应"。家族：[讲透原子核物理](../README.md)。

## 诞生

Rutherford 1911 的 α 散射是第一课（一扇金箔撞出一个原子核）；
Bohr 1936 复合核假说（入射粒子先被"吸收"成过热复合体再衰变）；
Feshbach-Porter-Weisskopf 1954 光学模型把核当成"半透明的玻璃球"。

（探针变粗）+ 共振窗效应。反直觉之冠。
