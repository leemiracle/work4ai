# 讲透量子无线电物理 · 接收的量子极限

> 当光子能量 hf 追上热能量 kT，**接收机的物理账本必须换记法**：
> 经典 Johnson 噪声让位于量子噪声——6 GHz@室温正是这条线。
> 它是量子测量理论在射频的应用前沿（量子雷达、微波单光子探测）。
>
> GB/T 13745：14040 无线电物理·三级"量子无线电物理"。
> 家族：[讲透无线电物理](../README.md)。

## 诞生

1946 年 Dicke 的辐射计方程把接收灵敏度推向"噪底在哪"之问；
1950-60 年代激光/微波激射器（Townes 等）把量子相干性带进射频；
1980 年代量子非破坏测量（QND）理论成型。**本支是"噪声不再是工程问题
而是物理极限"的学问**。
