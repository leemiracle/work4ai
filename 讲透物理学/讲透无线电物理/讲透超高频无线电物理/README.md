# 讲透超高频无线电物理 · 雷达与毫米波工程

> UHF/SHF/EHF（300 MHz-300 GHz）的**工程物理学**：雷达、卫星通信、
> 毫米波成像——"用波测量世界"的最大现役体系。
>
> GB/T 13745：14040 无线电物理·三级"超高频无线电物理"。
> 家族：[讲透无线电物理](../README.md)。

## 诞生

雷达方程 1940 年代成形（"radar"=radio detection and ranging）；
1957 年 Sputnik 开启空间通信；2019 年毫米波 5G 商用把本支推进每个人的手机。
**本支的历史=电子战史的一半**（侦察/干扰/反干扰的物理军备竞赛）。
