# 00 · 体系结构：场→波→路的三层大厦

> **本章回答五问之一（本支：讲透无线电物理）：整个体系结构长什么样。**
> 无线电物理的大厦有三层楼：**场**（麦克斯韦方程，真理层）、**波**（波动方程与传播，
> 现象层）、**路**（传输线与微波电路，设计层）。每一层都是上一层的"驯化"——
> 把偏微分方程驯化成工程师能在图纸上画的电路。

---

## 一、为什么需要三层：波长这把尺子

整个体系的组织原则只有一条：**拿波长和器件尺寸比大小**。

| 尺度关系 | 有效理论 | 设计语言 |
|---------|---------|---------|
| 器件 ≪ λ | 集总电路（Kirchhoff） | R、L、C，电压电流处处同相 |
| 器件 ~ λ | 分布电路（传输线） | 特征阻抗、反射系数、S 参数 |
| 器件 ≫ λ 或求场细节 | 全波（Maxwell） | 场解、数值电磁 |

📖 **故事框**：1890 年代的工程师用集总电路思维设计 1 MHz 的设备毫无问题
（λ=300 m，实验室里一切器件都是"点"）；二战雷达把频率推到 3 GHz（λ=10 cm），
导线变成天线、电容变成谐振腔——"路"的直觉集体失效，传输线理论正是在
这种疼痛中被迫长出来的。

## 二、第一层：场——麦克斯韦方程组（真理层）

四个方程（真空、无源区域用两个最简形式表达）：

- ∇·**E** = ρ/ε₀（高斯定律：电荷是电场源头）
- ∇·**B** = 0（无磁单极）
- ∇×**E** = −∂**B**/∂t（法拉第：变化的磁场产生涡旋电场）
- ∇×**B** = μ₀**J** + μ₀ε₀∂**E**/∂t（安培-麦克斯韦：位移电流补全了最后一块拼图）

**位移电流是麦克斯韦的纯粹理论发明**——为了让方程组自洽而加的一项，
它预言了电磁波。这是"数学美感先于实验"的著名案例（见 02 章）。

## 三、第二层：波——传播的现象学

由麦克斯韦方程在无源区域导出波动方程 ∇²**E** = μ₀ε₀ ∂²**E**/∂t²，
解以光速 c=1/√(μ₀ε₀) 传播。本层回答三组问题：

### 3.1 传播机制（[讲透电磁波物理](讲透电磁波物理/)）

- **自由空间传播**：功率密度按 1/r² 衰减（Friis 公式——链路预算的祖师爷）
- **地面波/天波**：中波沿地球表面绕射；短波靠电离层反射实现超视距
- **散射与多径**：城市环境的无线信道=多条路径的相干叠加（瑞利衰落由此来）

### 3.2 边界上的波：反射与折射

平面波打到介质界面：部分反射部分透射，菲涅耳系数给出配比。
入射角、极化、材料参数共同决定——天线罩、吸波材料、隐形涂层设计的核心。

### 3.3 波动到电路的桥：TEM 波与传输线

双导体结构（平行线/同轴线/微带）支持 TEM 模：场横向分布与静态解相同，
传播行为可以完全用电压电流描述——**这是"场"合法降级为"路"的唯一通道**。

## 四、第三层：路——传输线理论（设计层）

把 TEM 波的场量积分为电压电流，麦克斯韦方程变成**电报员方程**：

```
∂v/∂z = −L ∂i/∂t        ∂i/∂z = −C ∂v/∂t
```

稳态解给出本层全部设计语言：

- **特征阻抗** Z₀=√(L/C)：波的"路面属性"（同轴线 50Ω 是行业标准）
- **反射系数** Γ=(Z_L−Z₀)/(Z_L+Z₀)：阻抗失配=波撞墙反弹
- **驻波比** VSWR=(1+|Γ|)/(1−|Γ|)：失配的工程温度计
- **史密斯圆图**：Γ 平面=归一化阻抗的共形映射——一张图统治射频实验室一百年

### 4.1 反直觉发现：λ/4 阻抗反转

传输线上看进去的输入阻抗是位置的函数：

  Z_in(l) = Z₀ (Z_L + j Z₀ tan βl)/(Z₀ + j Z_L tan βl)

当 l=λ/4 时 tan βl→∞，Z_in = Z₀²/Z_L——**负载阻抗被"倒"了**：
短路(0Ω)在 λ/4 处看是开路(∞)，100Ω 负载配 λ/4、Z₀=√(50×100)=70.7Ω 的线段
变成完美 50Ω 匹配。四分之一波长=阻抗世界的负一次方。（本章实验实测验证。）

### 4.2 微波电路（[讲透微波物理学](讲透微波物理学/)）

波导、谐振腔、功分器、耦合器、滤波器——全部是"驯化了的场结构"。
设计语言的标准化（S 参数：端口波的散射矩阵）让微波电路像数字电路一样可级联。

## 五、天线：波与路的转换器

天线是本家族的"器官"：把导波（传输线里的波）变成自由空间波（辐射），
或反向。Balanis 体系按口径分类（线天线/面天线/阵列），核心指标：
方向图、增益、带宽、极化。**天线是三维场问题**——它是"路"的设计语言
管不到的地方，也是全波仿真最吃算力的环节。

## 六、分支地图（GB/T 三级）

```
电磁波物理（传播/散射/信道）
    ↑喂养
微波物理学（波导/电路） ←→ 超高频无线电物理（雷达/卫星工程）
    ↑地基                        ↑统计
统计无线电物理（噪声/检测） → 量子无线电物理（量子极限）
```

## ✍️ 练习

1. 手机 Wi-Fi 工作在 2.4 GHz（λ≈12.5 cm）。你的手机主板 10 cm——
   它是集总电路还是分布电路？（答案决定为什么手机主板布线是射频难题。）
2. 用 Z_in 公式证明：λ/2 传输线是"透明"的（Z_in = Z_L），与 Z₀ 无关。
3. Γ=1/3 时，反射功率占比多少？为什么 VSWR=2 通常被认为"可用"？
4. **反直觉挑战**：一段短路传输线，在某个频率呈现开路——用 4.1 的公式算出
   最短的这样的线长，并解释"一段导线怎么可能是绝缘体"。
