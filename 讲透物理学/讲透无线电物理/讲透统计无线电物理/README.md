# 讲透统计无线电物理 · 噪声、检测与估计

> 接收机的世界没有干净信号：**热噪声、量子噪声、杂波、干扰**层层裹住信息。
> 本支回答"在随机性里如何下判决"——检测（有没有）、估计（是多少）、
> 跟踪（在哪儿变）三连。它是统计推断在物理层的化身。
>
> GB/T 13745：14040 无线电物理·三级"统计无线电物理"。
> 家族：[讲透无线电物理](../README.md)。

## 诞生

1943 年 North 匹配滤波器（雷达检测最优滤波器）；1948 年 Shannon 信息论
同源的统计接收理论；1960 年代 Kalman 滤波（轨道跟踪）与
Van Trees 检测估计三部曲把本支公理化。**冷战的跟踪需求
（卫星/导弹）是它最大的历史推手**。

## 核心问题（3-5 条）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 匹配滤波与最优检测 | ✅ 已解（North 1943） | SNR 最大化的滤波器=信号时间反转：雷达/GPS/通信接收的通用芯 |
| 参数估计的 Cramér-Rao 界 | ✅ 已解 | 估计精度的物理下限 |
| Kalman/粒子滤波 | ✅ 已解 | 动态状态跟踪的标准机（导航/制导/金融全在用） |
| 微弱信号检测极限 | 🔄 前线 | 长积分/非线性/量子增强——向物理噪底逼近 |

## 假设与依赖

噪声=高斯平稳（中心极限定理给的礼物，失效场景：脉冲噪声/α 稳定分布）；
信号模型已知。前置：概率论（[讲透数学/讲透高维概率](../../../讲透数学/讲透高维概率/)）、
家族 [02 章](../02-语言特征.md)。
