# 讲透电磁波物理 · 传播的机制学

> 电磁波离开天线后的一切：**自由空间、地面、电离层、城市峡谷里波怎么走**。
> 它是无线通信、广播、遥感、雷达共用的"信道物理学"。
>
> GB/T 13745：14040 无线电物理·三级"电磁波物理"。
> 家族：[讲透无线电物理](../README.md)。

## 诞生

Hertz 1887 的柱面波实验之后，人们花了三十年搞清楚"波去了哪"：
Heaviside 1902 猜想电离层（Kennelly 同年）解释马可尼跨大西洋之谜——
波不是沿直线走了，是被天上那层"镜子"反射了。1924 年 Appleton 用
变频干涉实验证实电离层（诺贝尔奖 1947）。**信道=地球环境给的免费基础设施**
这一认识由此开始。
