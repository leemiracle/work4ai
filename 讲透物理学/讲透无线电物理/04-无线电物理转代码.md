# 04 · 无线电物理转代码：从史密斯圆图到 FDTD

> **本章回答五问之五（本支：讲透无线电物理）：问题怎么变成 code？**
> 本支是全物理学家族里**代码化最彻底**的分支：传输线一页公式就能跑，
> 全波仿真撑起了整条商业软件产业。可机械化的边界不在"能不能算"，
> 在"算得起吗"与"反向设计"两道坎上。

## 二、逐条速写

### 2.1 走廊①：传输线——一页纸的 DSL

本章实验 [experiments/transmission_line.py](experiments/transmission_line.py)
示范：Z_in 公式+numpy 复数运算，λ/4 匹配设计三行代码出数。
工程升级版=scikit-rf（`skrf`）：S 参数对象代数、史密斯圆图绘制、
网络级联一行完成——射频工程师的 Python 标配。

```python
import skrf as rf
line = rf.media.DefinedGammaZ0(frequency=freq, z0=50, gamma=1j*beta)
match = line.line(d=rf.meters_2_dbeta(lam/4), z0=70.71) ** load
```

### 2.2 走廊④：全波仿真——把麦克斯韦变成 for 循环

FDTD 的核心（Yee 1966）优雅到可以写在名片上：**E 和 H 在时空交错网格上
蛙跳推进**——空间上错开半个格，时间上错开半个步：

```
for t:  H += -(Δt/μ)·curl(E);   E += (Δt/ε)·curl(H)
```

- 开源栈：meep（MIT，FDTD）/ openEMS（FDTD）/ nec2（MoM 天线祖师）
- 商业栈（HFSS/CST）闭源——本支是少数"物理分支直接孵化商业软件产业"的案例

### 2.3 走廊③⑤：统计与信道

误码率蒙特卡洛（numpy 随机数+判决）、瑞利衰落采样（复高斯包络）、
射线追踪（几何+反射系数链式相乘）——全部可脚本化，
[讲透统计无线电物理](讲透统计无线电物理/)支的天然领地。

## 三、可机械化边界（哪三条线划死了）

### 3.1 正向问题全可机械化（设计图纸→场解）

结构给定 → 仿真出数 → 精度换算力：FDTD 网格每加密一倍，内存×8、时间×16
（三维 CFL 条件）。**"能算"没问题，"算得起"是工程边界**——
电大尺寸（≫λ）问题至今靠高频近似（物理光学/PO、一致性绕射理论/UTD），
这是"全波算不起"逼出来的独立理论体系。

### 3.2 反向设计半机械化（想要的方向图→结构）

拓扑优化、机器学习天线设计：非凸优化+昂贵目标函数，能给出候选，
不能给出保证——**与数学宇宙的讲透优化接口**（局部最优/全局最优的边界）。
成熟度：论文级→初级工业尝试。

### 3.3 测量-模型闭环最难机械化

矢量网络分析仪校准（12 项误差模型）→ 去嵌入 → 材料参数提取：
每一步有成熟算法，但**流程编排与异常判断仍是老师傅手艺**——
本支的"暗知识"集中区。

## 四、工程师落点（性能工程视角）

- **FDTD/MoM 内核=高性能计算的教科书 workload**：规则网格+局部 stencil →
  SIMD 友好、GPU 加速比高、MPI 域分解直接——与
  [讲透高性能计算](../../讲透高性能计算/) 的挂靠天然成立
  （时域推进=流式访存；MoM 矩阵填充=稠密线性代数；快速多极子=树算法）
- 射频测量数据管道（VNA 扫频 GB 级数据）→ 向量化后处理
- 通信物理层（OFDM/波束赋形）是 GPU 上"物理公式变 kernel"的最大现役案例群

## 五、裂缝清单（原则上不可/工程上极难的转换）

| 裂缝 | 为什么 |
|------|--------|
| 量子极限接收的仿真 | 量子测量算子维度爆炸，经典计算机只能模拟极小系统 |
| 电大+精细结构的混合尺度 | 网格需求跨 4+ 个量级，任何单一方法破产（多尺度=开放前线） |
| 反向设计的全局保证 | 非凸+约束复杂，理论缺失 |
| 信道模型的"真实感" | 统计模型构造系综，单次实测的确定性细节原则上不可复现 |

## ✍️ 练习

1. 把走廊①扩展成"单枝节匹配"求解器：给定 Z_L 与目标 Z₀=50，
   在史密斯圆图上求短路枝节的两个解（距离 d、枝节长 l）——
   numpy 数值搜索 10 行内可解，与圆图手工作图对照。
2. FDTD 的 CFL 稳定性条件 Δt ≤ Δx/(c√3)（三维）——它从哪来？
   （提示：显式格式的因果律，违反它=数值超光速=爆炸，与
   [讲透偏微分方程](../../讲透数学/讲透分析/讲透偏微分方程/) 的 CFL 实验同源。）
3. 为什么 MoM 的矩阵是稠密的而 FDTD 不需要解方程组？
   从"离散化对象"（表面积分 vs 时空微分）推它们的复杂度结构。
4. 反直觉挑战：仿真一个手机天线的全波问题网格 ~10⁷，一次仿真 ~小时级；
   把它放进优化循环迭代 10³ 次——算一下需要什么规模的计算资源，
   再判断"AI 设计天线"为什么先从代理模型（surrogate）入手。
