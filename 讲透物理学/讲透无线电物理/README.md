# 讲透无线电物理 · 电磁波作为信息载体

> 无线电物理：**从麦克斯韦方程到收音机**——电磁波的产生、传播、接收与调控。
> 它是经典场论最有工程产出的分支：天线、雷达、微波电路、移动通信的物理层全部由此生长。
>
> GB/T 13745：14040（物理学·二级学科）。宇宙：[讲透物理学](../README.md)。

## 诞生

Maxwell 1865 年方程组预言电磁波以光速传播；Hertz 1887 年在实验室用火花隙
产生并接收了电磁波——"我看到的不过是无可置疑的真理的传播"；Marconi 1901 年
让电磁波跨过大西洋。**理论预言（1865）→实验证实（1887）→工程应用（1901）**
这条 36 年的链路是"物理学到技术"的经典样板。二战雷达把本学科推进到微波；
战后射频集成电路把它塞进每个人的口袋。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 电磁波存在性与传播 | ✅ 已解（Hertz 1887） | 麦克斯韦方程组的实验判决——经典场论成立 |
| 波导/传输线理论 | ✅ 已解（1890s-1940s） | 把"场"驯化为"路"——微波电路的设计语言 |

| 太赫兹频段工程化 | 🔄 前线 | 0.1-10 THz"最后一片空频谱"——6G 载波候选，器件与信道建模双缺口 |

## 假设与代价

宪法=麦克斯韦方程组（经典、线性介质近似）。工程层代价：**集总电路假设
在波长与器件尺寸可比时破产**——这正是传输线理论存在的理由（见 00 章）。
统计层假设：噪声=高斯平稳过程（统计无线电的简化）。
