# 讲透微波物理学 · 波导、谐振腔与微波电路

> 300 MHz-300 GHz 的电磁波**关进金属管道里驯养**的科学：波导、谐振腔、
> 定向耦合器、滤波器——把"场"标准化成可级联的电路积木。
>
> GB/T 13745：14040 无线电物理·三级"微波物理学"。
> 家族：[讲透无线电物理](../README.md)。

## 诞生

二战雷达（1940s）把微波从实验室逼成工业：速调管、磁控管、波导网络
在战时以曼哈顿工程级的强度发展（MIT 辐射实验室）。战后
《Radiation Laboratory Series》二十八卷成为本支的法典——
**战争是本支的产房，这是技术史上无争议的一页**。
