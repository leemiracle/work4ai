# 讲透近代物理学史 · 1895-1945：双重革命的三十年战争

> 支：[讲透物理学史](../README.md) 自定主干支。X 射线到原子弹——相对论与量子论
> 如何在两代人之内重建时空与因果。

## 定位句

本支负责**两大革命的编年与解释**：旧量子论的绝望（1900-1925）、
矩阵/波动力学的会师（1925-27）、解释之争的制度化（1927 索尔维→今）、
相对论的两级跳（1905 狭义/1915 广义）、以及物理学 militarization 的起点（1942 曼哈顿）。

## 诞生与关键事件

- 1895-1897：X 射线/放射性/电子——"物理学晴空的两朵乌云"其实是三连击
- 1905 爱因斯坦奇迹年：三篇论文三个方向（分子/光量子/狭义相对论）
- 1911 第一届索尔维会议：量子问题成为国际议程
- 1927 索尔维："上帝掷骰子"之争开场，延续至今
- 1942-45：芝加哥反应堆→曼哈顿——物理学家从此是国家资产
