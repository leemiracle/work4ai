# 讲透物理学史 · 物理学如何成为物理学

> 物理学史：**研究"物理学的知识与社会如何随时间演变"**——它把物理学自身当作
> 研究对象：概念从哪来、实验如何说服人、仪器如何改写问题、学科边界如何移动。
>
> GB/T 13745：14010（二级学科，无三级明细——自定主干三支）。
> 宇宙：[讲透物理学](../README.md) · 薄家族（章精简不注水）。

## 诞生

物理学史作为学科：19 世纪末 Whewell/ Mach 的"批判史"开创；20 世纪
爱因斯坦-英费尔德《物理学的进化》(1938) 确立大众叙事传统；
Koyré 用思想史方法重读伽利略（1939-1965），把"史"变成专业研究；
1968 年后社会建构论转向（Forman 论魏玛文化与量子力学），
物理学史成为科学史最大的子领域。

## 假设与依赖

本学科站在三条假设上：①史料可获得且可考据（档案/期刊/仪器/口述）；
②"物理学"有可追溯的连续身份（这一条本身被不断质疑——"physics"一词
19 世纪才固定）；③分期不是任意的（经典/近代/现代三分法是教学便利，
史学上处处例外）。
