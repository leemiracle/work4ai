# 讲透现代物理学史 · 1945-今：大科学与物理学的膨胀

> 支：[讲透物理学史](../README.md) 自定主干支。加速器、半导体、激光、引力波——
> 物理学从个人手艺变成国家工程，并把边界推到宇宙与凝聚态的两极。

## 定位句

本支负责**物理学的规模化与边界移动**：大科学工程（加速器/空间望远镜/LIGO）、
固态物理学的崛起（物理学家人口的最大板块）、物理学的跨学科输出
（天体物理/生物物理/计算物理），以及"物理学是否在衰落"的元叙事。

## 诞生与关键事件

- 1947 晶体管：贝尔实验室模式=产学研新制度
- 1954-57 杨-Mills/宇称破坏：理论物理学的黄金一代
- 1965-83 大爆炸宇宙学 vs 稳恒态：天体物理被物理学收编
- 1986-87 高温超导：凝聚态的"第三次革命"叙事
- 2012 希格斯 / 2015 GW150914：大科学的两次凯旋与"下一步是什么"的焦虑
- 2024 诺奖授神经网络：物理学边界被颁奖实践重划（见家族 01 章）
