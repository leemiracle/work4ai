# 讲透经典物理学史 · 1600-1900：钟表宇宙的组装

> 支：[讲透物理学史](../README.md) 自定主干支。伽利略的斜面到麦克斯韦的方程组——
> 物理学从自然哲学中"分家独立"的三百年。

## 定位句

本支负责**物理学的创世与经典纲领**：运动学革命（伽利略）、力学综合（牛顿）、
能量守恒（1847 前后五人独立发现）、场的发明（法拉第-麦克斯韦）。

## 诞生与关键事件

- 1638《两门新科学》：实验+数学的结合体诞生
- 1687《原理》：万有引力把天上地下统一——第一个物理学纲领
- 1847 Helmholtz 能量守恒：工业时代的"力"变成可清算的账
- 1865 麦克斯韦方程：场作为实体登场，为相对论埋线
