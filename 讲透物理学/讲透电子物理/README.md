# 讲透电子物理 · 电子作为波、作为束、作为工具

> **本质一句话**：电子物理研究如何**产生、操控并利用电子（与离子）**——
> 量子电子学让电子吐出相干光子（激光），真空物理制造"没有分子的空间"，
> 带电粒子光学用磁场当透镜把电子聚焦成人类看得最细的眼睛。
>
> GB/T 13745：14045 电子物理学（二级）。家族：[讲透物理学](../README.md)宇宙 · 三级 3 支全落子。

## 诞生（要件②）

1. **J.J. Thomson 1897** 发现电子——"电"从此有了颗粒。
2. **de Broglie 1924** 物质波 + **Davisson–Germer 1927** 电子衍射：电子是波，
   波长比可见光短 10⁵ 倍——**Ruska 1931 电子显微镜**由此而生（1986 诺奖，迟到 55 年）。
3. **Einstein 1917 受激辐射** → **Townes 1954 微波激射器** → **Schawlow–Townes 1958
   激光原理**——量子电子学立科：让电子在能级间受控跃迁，吐出全同光子。

## 核心问题清单（要件③）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 粒子数反转与激光条件（1958） | ✅ 已解 | 相干光的开关被找到——20 世纪最伟大的工具发明之一 |
| 电子显微镜分辨率极限 | ✅ 已解（持续下探） | 德布罗意波把衍射极限压缩 10⁵ 倍：亚埃成像（球差校正后 0.05 nm） |
| **Scherzer 定理**（1936） | ✅ 已证（不可能性定理！） | 旋转对称电子透镜球差恒正、不可消除——"完美电子透镜不存在" |
| 球差校正器（Haider 1998） | ✅ 已解 | 打破对称性（六极校正器）绕过 Scherzer——亚埃时代开启 |
| 自由电子波函数工程 | 🔄 前线 | 把电子波函数当光学元件整形——free-electron quantum optics（见 01 章） |

## 假设与代价（要件④）

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 受激辐射 + 粒子数反转（量子电子学） | 相干光子雪崩=激光 | 需泵浦能量持续"抬水"，增益介质有寿命与热问题 |
| 德布罗意波 + 电磁透镜（电子光学） | 比光镜细 5 个量级的分辨 | 电子带电→与样品互毁（生物样品难点）、透镜像差恒正（Scherzer） |
| 真空 = 碰撞率管理（真空物理） | 电子平均自由程≫器件尺度 | 一切都要"抽空"：真空腔体是电子器件的隐形一半 |
