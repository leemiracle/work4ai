# 讲透量子电子学 · 让电子吐出相干光子

> **这支负责什么**：受激辐射的工程化——从 maser 到激光到腔 QED，
> 研究如何让电子在能级间受控跃迁，吐出全同光子。
> GB/T 13745：14045 三级"量子电子学"。家族：[讲透电子物理](../README.md)。

## 诞生

Einstein 1917 理论上发现受激辐射（一个光子进来，两个全同光子出去）；
38 年后 Townes 1954 造出微波激射器（maser），Schawlow–Townes 1958 给出激光
原理与阈值条件——1960 Maiman 红宝石激光器点亮。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 粒子数反转与激光阈值条件 | ✅ 已解（1958）——相干光的开关 |
| Schawlow–Townes 线宽极限 | ✅ 已解——激光线宽的量子下界 |
| 腔 QED 强耦合区（g>κ,γ） | ✅ 已解——单原子激光到 Jaynes–Cummings 振荡 |
| 频率梳（Hänsch 2005 诺奖） | ✅ 已解——光钟的齿轮 |
| 非经典光场（压缩态/单光子源）按需产生 | 🔄 前线——量子信息的光源层 |

## ✨ 这支最美的一个事实

激光不是"很亮的光"，而是**同一个光子的雪崩**——受激辐射克隆入射光子的
全部量子性质（频率/相位/方向），所以激光束是自然界最接近"全同副本"的宏观物。

## 假设与依赖

粒子数反转（买到增益，付出泵浦能量与热管理）+ 光学腔（买到模式选择，
付出腔长稳定性）+ 增益介质能级结构（买到工作波长，付出波长离散不可调）。
