# 讲透带电粒子光学 · 磁场当玻璃，电子当光

> **这支负责什么**：用电磁场做"透镜"聚焦电子/离子束——电子显微镜、
> 聚焦离子束（FIB）、加速器束流光学的共同基础。
> GB/T 13745：14045 三级"带电粒子光学"。家族：[讲透电子物理](../README.md)。

## 诞生

Busch 1926 证明轴对称磁场对电子有透镜作用（"磁透镜"概念的出生证）；
Ruska 1931 造出第一台电子显微镜（1986 诺奖）；Crewe 1970s 场发射扫描电镜；
Haider 1998 球差校正器打破 Scherzer 铁笼——亚埃时代。

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 磁透镜聚焦原理（Busch 1926） | ✅ 已解——磁场是电子的玻璃 |
| **Scherzer 定理**（1936） | ✅ 已证（不可能性）：旋转对称透镜球差恒正 |
| 球差校正（Haider/Rose 1998） | ✅ 已解——六极校正器破坏对称性获得负球差 |
| 色差校正 | ✅ 已解（组合式单色器+校正器） |
| 电子显微镜信息极限推进 | 🔄 前线——0.05 nm 已至，逼近电子源相干性预算 |

## ✨ 这支最美的一个事实

玻璃透镜可以正负球差配对抵消，而**旋转对称磁透镜的球差被 Scherzer
定理锁死为恒正**——"完美电子透镜"被数学证明不存在。人类只好破坏对称性
（六极场）来"绕过"不可能——亚埃分辨率的胜利是一次对不可能性定理的工程越狱。

## 假设与依赖

德布罗意波（分辨率资格）+ 轴对称场假设（Scherzer 的笼子——破坏它才有校正器）
+ Liouville 定理（发射度守恒：束流品质由源决定，透镜只能保持）。
