# 讲透电子离子与真空物理 · 制造"没有分子的空间"

> **这支负责什么**：电子器件的生存环境学——真空的获得与测量、
> 电子从固体里被"请出来"的三种方式（热/场/光）、气体放电。
> GB/T 13745：14045 三级"电子离子与真空物理"。家族：[讲透电子物理](../README.md)。

## 诞生

Geissler 1855 玻璃工吹出真空泵放电管——"阴极射线"由此被研究，
最终引出电子的发现（Thomson 1897）；Langmuir 1915 高真空技术体系化。
真空不是"空"，是**碰撞率的管理**——这支的工程本质。

## ✨ 这支最美的一个事实

10⁻¹⁰ Pa 的"超高真空"里，每平方厘米表面**每秒仍撞上 ~10⁶ 个分子**——
"空"是相对的：真空工程的全部艺术在于把碰撞率压到你的器件容忍线以下，
而不是压到零（零不存在）。

## 假设与依赖

麦克斯韦-玻尔兹曼统计（气体动理论）+ 量子隧穿（场发射）+ 表面科学
（出气/吸附决定真空下限——"你的真空室最脏的部分是它自己的内壁"）。
