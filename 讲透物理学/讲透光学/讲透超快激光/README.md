# 讲透超快激光 · 把时间切到阿秒

> 这支负责：**飞秒（10⁻¹⁵s）与阿秒（10⁻¹⁸s）脉冲**——
> 人类最快的"快门"，2023 诺奖的现场（01 章方向一）。
>
> GB/T 14030·三级"超快激光及应用"。家族：[讲透光学](../README.md)。

## 诞生

1981 Fork- Shank 首个亚百飞秒脉冲；1985 CPA 啁啾脉冲放大
（Strickland-Mourou，2018 诺奖——"先展宽放大再压缩"绕开损伤阈值）；
2001 阿秒脉冲串（Krausz/Agostini 路线，高次谐波 HHG）→ 2023 诺奖。

## 核心问题

- ✅ 已解：CPA 放大到拍瓦；载波包络相位稳定；阿秒条纹术（streaking）
- 🔄 前线：阿秒泵浦-探测电子电影；芯片化阿秒系统（01 章校准点）；
  阿秒计量（时间轴的原子钟）
- ❌ 未解：zepto（10⁻²¹s）区间的物理与技术路线

## ✨ 这支最美的一个事实

**阿秒的数量级**：阿秒之于 1 秒 ≈ 1 秒之于宇宙年龄（~10¹⁸ 倍双向）。
人类造出了与宇宙年龄成"对折"关系的时间分辨率——
快门速度触及电子运动的本征时标。

## 假设与依赖

时间-带宽不确定（ΔνΔt≥1——超短脉冲必然宽带宽，CPA 的前提）；
非线性光学链（放大-压缩-谐波全靠 [../讲透非线性光学/](../讲透非线性光学/)）。
