# 讲透光学 · 光的科学——从射线到光子

> 光学：**研究光的产生、传播、探测与物质相互作用**的物理学分支——
> 从费马的"光走最快路径"到激光、光纤通信与阿秒脉冲，它是物理学中
> **与工程互喂最深**的家族。
>
> GB/T 13745：14030 光学（17 个三级学科）。宇宙：[讲透物理学](../README.md)。

## 〇、家族定位

| 维度 | 内容 |
|------|------|
| 本质一句话 | 光 = 电磁波 + 光子流；光学就是在这两种语言间自由切换的学科 |
| 诞生问题 | ①光是波还是粒子（牛顿-惠更斯之争 300 年）②为什么彩虹有颜色（光谱）③能否让光"受激辐射放大"（激光，1917 爱因斯坦理论→1960 Maiman 实现） |
| 核心问题（已解） | 干涉衍射的波动理论（Young 1801/Fresnel 1818）；Maxwell 方程证明光是电磁波（1865）；激光（1960）；全息（1948）；光频梳（Hänsch，2005 诺奖） |
| 核心问题（未解/前线） | 阿秒之下电子运动的实时观测（2023 诺奖刚开闸）；光的量子非定域应用（量子通信/量子计算）；衍射极限之下成像（超分辨） |
| 假设与代价 | 几何光学假设 λ→0（买到直觉，丢掉干涉）；标量波理论假设偏振可忽略（买到简单，丢掉矢量效应）；量子光学假设场量子化（买到全谱现象，付出计算重量） |
| 反直觉发现 | **泊松亮斑**：Fresnel 理论预言圆盘阴影中心有亮斑——泊松以之为荒谬反杀，实验却真看到（1818）：直觉错得最响的地方，恰是理论最亮的地方 |
