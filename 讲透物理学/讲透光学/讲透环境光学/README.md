# 讲透环境光学 · 用光监测地球

> 这支负责：**光学手段的环境监测**——污染遥测、水质光学、激光雷达大气探测。
>
> GB/T 14030·三级"环境光学"。家族：[讲透光学](../README.md)。

## 诞生

1960s 激光雷达（lidar）问世即被用于大气探测（气溶胶分层）；
1978 CZCS 卫星开启水色遥感的长期记录；2000s 起 DOAS
（差分光学吸收光谱）成为污染气体柱浓度标准技术。

## 核心问题

- ✅ 已解：差分吸收光谱反演（DOAS）；米/拉曼散射 lidar 分层；水质参数的光学反演
- 🔄 前线：星载多普勒测风 lidar（风场的全球测绘）；温室气体卫星（CO₂/CH₄ 柱浓度）
- ❌ 未解：近地面污染的三维实时成像（垂直分辨率 vs 卫星几何的矛盾）

## ✨ 这支最美的一个事实

**一束光测出污染层的高度**：lidar 回波是"距离-时间"的时域记录——
每个高度的气溶胶都留下一圈回声。光学雷达把大气的"CT"变成现实。

## 假设与依赖

Beer-Lambert 定律（吸收∝浓度×路径——一切定量遥测的地基）；
反演的正问题建模（反问题病态性：解不稳定——Tikhonov 正则化常客，见
[../../../讲透数学/讲透分析/讲透积分方程/](../../../讲透数学/讲透分析/讲透积分方程/)）。
