# 讲透发光学 · 材料如何发光

> 这支负责：**光从物质中产生的机制分类**——热辐射、荧光、磷光、电致发光。
> 量子论的出生地在这支。
>
> GB/T 14030·三级"发光学"。家族：[讲透光学](../README.md)。

## 诞生

1852 Stokes 荧光定律（发射波长>激发波长）；1900 Planck 黑体辐射公式——
"绝望的行为"（被迫引入能量量子）成为量子论元年；1960s-90s LED 从红到蓝
（赤崎勇/中村修二，2014 诺奖）——照明革命。

## 核心问题

- ✅ 已解：黑体辐射谱（Planck）；荧光/磷光的能级机制（单线态/三线态）；LED 与 OLED
- 🔄 前线：钙钛矿 LED/光伏；量子点发光（色纯度里程碑）；超荧光与相干辐射
- ❌ 未解：激子复合动力学的全量子处理（强耦合区）

## ✨ 这支最美的一个事实

**普朗克公式**：一个公式同时吞下维恩（短波）与瑞利-金斯（长波）两个近似，
全域拟合黑体谱——代价是假设能量不连续。物理学史上最贵的一次"假设"。

## 假设与依赖

热平衡（黑体）；二能级/多能级模型；速率方程（发光动力学的常微分系统——
[../../../讲透数学/讲透分析/讲透动力系统/](../../../讲透数学/讲透分析/讲透动力系统/) 接口）。
