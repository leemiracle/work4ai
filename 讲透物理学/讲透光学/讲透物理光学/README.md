# 讲透物理光学 · 干涉、衍射、偏振

> 这支负责：**光的波动性三件套**——干涉、衍射、偏振。光学的"心脏层"。
>
> GB/T 14030·三级"物理光学（原名波动物理学）"。家族：[讲透光学](../README.md)。

## 诞生

1801 Young 双缝（"光会干涉"一锤定音）；1818 Fresnel 数学化（惠更斯-菲涅尔原理）；
同年**泊松亮斑**闹剧——泊松用"影子中心有亮斑"的荒谬推论反讽 Fresnel，
Arago 实验一看：真有。波动说靠对手的神助攻登基。

## 核心问题

- ✅ 已解：衍射统一理论（Fresnel-Kirchhoff）；薄膜干涉（增透膜 1930s）；偏振的 Jones/Stokes 表示
- 🔄 前线：结构光场（轨道角动量光束）；非衍射光束（Bessel/Airy）
- ❌ 未解趣题：光子"走哪条缝"——测量问题的光学现场（归量子光学层）

## ✨ 这支最美的一个事实

**泊松亮斑**：圆盘阴影中心有亮斑。因为中心到盘边所有点等距——
所有子波同相叠加。直觉最抗拒的地方，波动理论最闪亮。

## 假设与依赖

标量近似（偏振旁置→强聚焦/金属处失效）；相干性（干涉的燃料——
热光源相干长度 µm 级，激光 km 级）。

## 教材锚

Hecht《Optics》后半 / Goodman《Introduction to Fourier Optics》（衍射+系统）
