# 讲透激光物理 · 受激辐射的亿万人合唱

> 这支负责：**光放大的物理**——粒子数反转、谐振腔、相干性工程。
> 20 世纪光学的起搏器。
>
> GB/T 14030·三级"激光物理"。家族：[讲透光学](../README.md)。

## 诞生

1917 爱因斯坦提出受激辐射（理论上顺手一笔）；1958 Townes-Schawlow 条件；
1960 Maiman 红宝石激光——**从理论到实现 43 年**，中间隔着"二能级不行、
要三能级反转"等一串观念障碍。Townes 1964 诺奖。

## 核心问题

- ✅ 已解：粒子数反转与增益；谐振腔模式（Fox-Li 稳态）；锁模（ps→fs）
- 🔄 前线：拍瓦激光装置（ Weinstein 量级场强——真空极化可测）；超稳激光（10⁻¹⁶ 线宽，引力波探测心脏）
- ❌ 未解趣题：X 射线激光的自由电子之外路线； gamma 激光

## ✨ 这支最美的一个事实

**激光的单色性是"造"出来的**：谐振腔每往返一次就筛选一次频率——
亿万个原子被同步成一支合唱团。自然界从未有过如此相干的光：
每米光程相位抖动小于原子直径的亿亿分之一。

## 假设与依赖

增益>损耗（激光的生死线）；三能级/四能级系统（反转的工程学）；
腔的稳定性条件（ABCD 矩阵的辛几何判据 0<(A+D)/2<1——03 章 ABCD 现场应用）。
