# 讲透几何光学 · 射线与成像

> 这支负责：**λ→0 极限下的光学**——光线、成像、像差。直觉最强、工程最重的一层。
>
> GB/T 14030·三级"几何光学学"。家族：[讲透光学](../README.md)。

## 诞生

欧几里得《光学》（反射律）；托勒密测折射；1621 斯涅尔折射律；
1657 费马把全部几何光学收进"光走最短时间"一条原理——
**一条变分原理生成一族定律**，比牛顿力学还早一百年示范了这个范式。

## 核心问题

- ✅ 已解：折射律与反射律（费马推论）；理想成像条件（阿贝正弦条件）；三级像差理论（Seidel 1856）
- 🔄 前线：自由曲面透镜设计（非球面自由度×计算设计）；end-to-end 光学-算法联合设计
- ❌ 未解趣题：完美成像（无像差）在几何层可证不可能——除非引入衍射层（而衍射又设新极限）

## ✨ 这支最美的一个事实

**费马原理**：反射律、折射律、大气光线路径、光纤中光线——全部是
"传播时间取极值"这一句话的推论。光学天生就是变分法的第一现场。

## 假设与依赖

λ→0（丢掉干涉衍射）；光线=波前法线（射线是导数，不是实体）。

## 教材锚

Hecht《Optics》前半 / Born & Wolf 第 4 章 / Smith《Modern Optical Engineering》（工程侧）
