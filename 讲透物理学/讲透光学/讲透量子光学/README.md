# 讲透量子光学 · 光子的量子态

> 这支负责：**光的量子性**——光子统计、压缩态、纠缠。新物理与量子技术的入口。
>
> GB/T 14030·三级"量子光学"。家族：[讲透光学](../README.md)。

## 诞生

1956 Hanbury Brown-Twiss 测到热光的光子聚束；1963 Glauber 建立
光的量子相干理论（2005 诺奖）；1977 Kimble 测到**反聚束**——
单光子一个一个来，光的粒子性最干净的证据。

## 核心问题

- ✅ 已解：光子统计三分类（聚束/相干/反聚束）；压缩光（1985 实验）；量子纠缠分发
- 🔄 前线：确定性单光子源；光量子计算（boson sampling → 容错路线）；量子网络的中继协议
- ❌ 未解：光子-光子直接相互作用的有效实现（通常需介质中转）

## ✨ 这支最美的一个事实

**反聚束**：g⁽²⁾(0)<1——任何经典波动理论都写不出的不等式。
它比光电效应更"量子"：半经典理论能解释光电效应，却解释不了
"光子排队一个个过"。

## 假设与依赖

电磁场量子化（Fock 空间）；探测的von Neumann 测量/POVM 框架；
光源的相干性分类（Glauber P 表示）。
