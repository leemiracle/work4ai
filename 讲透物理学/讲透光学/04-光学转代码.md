## 一、四条走廊总表

| 走廊 | 对应层 | 核心算法 | 复杂度 | 代表软件/库 |
|------|-------|---------|--------|------------|
| ① 光线追迹 ray tracing | 几何层 | 射线求交+折射递推（ABCD/蒙特卡洛） | O(光线数×面数) | Zemax/CodeV（商业）；self-host 可写 |
| ② 傅里叶光学 FFT optics | 波动层 | 衍射积分=两个 FFT×相位因子 | O(N log N) | 自写 50 行；scipy.fft |
| ③ 时域有限差分 FDTD | 电磁层 | Yee 网格上 leapfrog 推进 Maxwell | O(格点×步数)，内存大 | Meep（开源）/Lumerical（商业） |
| ④ 蒙特卡洛光子传输 MC | 量子/颗粒层 | 光子随机游走（散射吸收抽样） | O(光子数)，天然并行 | MCML 生物光学/TRT 风格自写 |

## 二、逐条速写

### 走廊①：光线追迹——"几何层的编译器"

把光学系统写成曲面序列，光线状态 (x,y,dx,dy) 逐面折射递推。
ABCD 矩阵版是**线性系统专用**（近轴），非近轴用 3D 矢量折射律。
输出：点列图/像差曲线。**可机械化边界**：λ→0——干涉衍射全不可见
（这就是镜头设计软件算完像差还要补物理光学分析的原因）。

### 走廊②：傅里叶光学——"波动层的免费午餐"

标量衍射理论下，自由空间传播 = 频域乘传递函数 exp(ik_z z)，透镜 = 乘相位
exp(-ik r²/2f)。整个 4f 系统就是两次 FFT 夹一次滤波——**本家族实验
[experiments/fresnel_diffraction.py](experiments/fresnel_diffraction.py) 是这条走廊的最小实现**。
**可机械化边界**：标量近似（偏振丢失）+ 薄透镜近似。

### 走廊③：FDTD——"电磁层的暴力美学"

把 Maxwell 方程在 Yee 网格上时域离散化，电场磁场错半格交替推进——
无需求解边值问题，"让方程自己跑"。**可机械化边界**：网格分辨率须
≪λ（典型 λ/10），内存 ∝ 空间体积；电大尺寸系统（几十λ）就开始吃 HPC。

### 走廊④：蒙特卡洛光子传输——"颗粒层的赌徒"

每个光子按散射相函数/吸收概率随机游走，累积统计量。
生物组织光学（漫射近似失效区）与放射剂量学的主力。
**可机械化边界**：噪声 ∝ 1/√N——精度靠光子数堆，方差缩减是核心技巧。

## 三、可机械化边界总账

| 问题类 | 机械化 | 为什么 |
|--------|--------|--------|
| 面型系统像差 | ✅ 全自动 | 几何层闭式递推 |
| 衍射图样 | ✅ 全自动 | 积分存在+FFT 加速 |
| 任意介电结构的场分布 | ✅ 但贵 | FDTD/FEM，HPC 问题而非原理问题 |
| 组织内光分布统计 | ✅ 统计意义 | MC 收敛慢但无偏 |
| **逆设计**（给定输出反求面型/结构） | 🔄 半自动 | 梯度法（伴随方法）可用，全局最优无保证 |
| **相位恢复** | 🔄 迭代无保证 | 反问题病态 |
| 湍流实时校正 | 🔄 控制闭环 | 自适应光学=光学×[控制理论](../../讲透信息科学与系统科学/讲透控制理论/) |

## 四、工程师落点（性能工程视角）

1. **FDTD 是内存带宽 workload 之王**：每步全场刷新、无局部性可挖——
   与 CFD 同列"HPC 照妖镜"；优化路径=向量化（AVX/SIMD）+ 域分解 MPI，
   GPU 版本（如 meep 的加速尝试）常受制于电场/磁场交错的访存模式
2. **FFT 光学的访存坑**：大 N 频域乘法是 bandwidth-bound；多做几次 in-place
   FFT 与 bit-reversal 的 cache 行为值得用 perf 实测（呼应
   [../../讲透高性能计算/](../../讲透高性能计算/) 的 roofline 方法）
3. **MC 光子传输=embarrassingly parallel**：光子间零交互——GPU 上万线程吞吐
   线性扩展，是入门 GPU 计算的最好 workload 之一
4. **逆向设计伴随方法的工程红利**：一次正仿真+一次伴随仿真=全部梯度
   （对百万设计变量！）——这个"2 次仿真换百万梯度"的杠杆与深度学习的
   反向传播同构（[../../讲透模型/](../../讲透模型/) 的计算图视角）

✨**美之时刻**（本章）：**伴随方法（adjoint method）**
**陈述**：求 J(设计) 的全部梯度只需两次全场仿真（一次正向+一次伴随）。
**为什么美**：**意外+极简**——直觉上百万变量的梯度要百万次扰动仿真，
伴随方程把方向完全反过来，成本与变量数无关。**怎么亲历**：
把走廊②的衍射传播写成可微程序（PyTorch/autograd），自动得到对任意
面型参数的梯度——亲手摸到"伴随=自动微分"的等价性。

## Python 层

[experiments/fresnel_diffraction.py](experiments/fresnel_diffraction.py)：
走廊②最小实现。数值 Fresnel 积分 vs 解析 sinc² 包络（夫琅禾费极限），
断言相对误差 < 2%——**波动层的构造性当场兑现**。

## 不足层

- 光学计算的"四走廊"覆盖线性 Maxwell 世界；非线性/量子态层的通用仿真
  仍无标准工具（研究级代码为主）
- 商业软件（Zemax/Lumerical）的护城河在工程细节（公差分析/多物理耦合），
  开源栈只覆盖主干
- 光学逆设计的全局最优性是 NP 型困难——行业用经验+局部梯度混着过
