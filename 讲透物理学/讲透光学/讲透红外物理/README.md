# 讲透红外物理 · 不可见的热光

> 这支负责：**红外辐射（0.75µm-1mm）的产生、探测与物质相互作用**——
> 一切温热物体都在"说"红外。
>
> GB/T 14030·三级"红外物理"。家族：[讲透光学](../README.md)。

## 诞生

1800 Herschel 用温度计在太阳光谱红端之外测到"看不见的加热射线"——
第一次发现"看不见的光"；1880s Langley 发明测辐射热计；
20 世纪军事与天文双引擎推动（夜视/红外天文）。

## 核心问题

- ✅ 已解：红外辐射定律（维恩位移/斯特藩-玻尔兹曼）；大气红外窗口（8-14µm）测绘；
  量子型探测器（HgCdTe）
- 🔄 前线：室温工作红外探测器（免制冷）；太赫兹空隙的填补；红外天文（JWST 的主场）
- ❌ 未解：太赫兹波段（0.1-10THz）便宜相干源——"最后的空隙"

## ✨ 这支最美的一个事实

**维恩位移律**：λ_max×T = 2898 µm·K——恒星温度、宇宙微波背景（2.7K→1mm）、
体温（310K→9.3µm）全都用同一条乘法读出。一支温度计量宇宙。

## 假设与依赖

热辐射（普朗克谱）；大气透过窗口（遥感布局被大气分窗——
遥感卫星的波段表其实是"大气的透射谱"）。
