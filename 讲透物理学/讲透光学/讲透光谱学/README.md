# 讲透光谱学 · 光的指纹学

> 这支负责：**把光分解成谱，从谱读出物质**——元素、温度、速度、磁场，全在谱线上。
>
> GB/T 14030·三级"光谱学"。家族：[讲透光学](../README.md)。

## 诞生

1814 Fraunhofer 在太阳光谱里数出 574 条暗线；1859 Kirchhoff-Bunsen 破译：
每条线对应一种元素——**天体化学从此不需要取样**。1885 Balmer 用一个公式
钉死氢的四条可见线，1889 里德伯推广——量子论的前奏曲。

## 核心问题

- ✅ 已解：原子发射/吸收定性定量分析；光谱线系公式（氢原子完全解析）；激光光谱（饱和/双光子）
- 🔄 前线：频率梳光谱（精度 10⁻¹⁸ 级光钟）；单分子光谱；天文光谱系（系外行星大气）
- ❌ 未解：复杂分子（蛋白质级）振动谱的完全正问题模拟

## ✨ 这支最美的一个事实

**氢的巴耳末系**：四条可见光波长被 λ=B·n²/(n²−4) 一个公式锁死——
小学生能验的规律，直通量子力学的能级 E_n=−13.6/n² eV。谱线=能级的可见签名。

## 假设与依赖

跃迁定则（角动量/宇称守恒）；谱线展宽机制（自然/多普勒/压力——
每条线都有一篇小传记）；光与物质相互作用见
[../../讲透原子分子物理/](../../讲透原子分子物理/)。
