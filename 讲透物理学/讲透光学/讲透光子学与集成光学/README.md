# 讲透光子学与集成光学 · 光路芯片化

> 这支负责：**把光学系统缩进芯片**——波导、调制器、探测器单片集成。
> 01 章方向二的现场（TFLN/微腔孤子）。
>
> GB/T 14030·三级"光子学与集成光学"。家族：[讲透光学](../README.md)。

## 诞生

1969 Miller 提出"集成光学"概念；1990s 硅光起步（CMOS 兼容是最大卖点）；
2010s 薄膜铌酸锂（TFLN）异军突起——电光调制的速度之王回到牌桌。

## 核心问题

- ✅ 已解：硅基波导与耦合器；马赫-曾德调制器；片上探测器（Ge-on-Si）
- 🔄 前线：TFLN 调制器（100GHz+）；孤子微腔光频梳；光子-电子协同封装（CPO）
- ❌ 未解：片上低损耗可调光源（激光器仍是"外挂"痛点）；光子芯片的通用编程模型

## ✨ 这支最美的一个事实

**微环谐振器**：半径几十 µm 的环让光转圈上百万次——
等效光程一米、器件尺寸微米。光在芯片上"跑圈"跑出了
光学钟与数据中心的新引擎。

## 假设与依赖

CMOS 兼容工艺（决定一切工程取舍）；波导模式理论
（[../讲透导波光学/](../讲透导波光学/) 的芯片版）；耦合损耗
（每个界面 ~0.5-1dB 的"过路费"）。
