# 讲透信息光学 · 光作为信息载体

> 这支负责：**光携带、变换与处理信息**——全息、衍射光学元件、光学信息处理。
> "透镜就是傅里叶变换器"是本支全部戏剧。
>
> GB/T 14030·三级"信息光学"。家族：[讲透光学](../README.md)。

## 诞生

1948 Gabor 提出全息术（为改良电子显微镜，却因激光缺席沉寂至 1960s 复活，
1971 诺奖）；1960s VanderLugt 滤波器让"光学计算机"一度与电子计算机
同台竞技——后来退守成像与光互连，如今以光计算之名回潮（01 章方向三）。

## 核心问题

- ✅ 已解：4f 系统与空间滤波；全息记录与重现；衍射光学元件（DOE）设计
- 🔄 前线：计算成像（end-to-end 光学+算法设计）；衍射神经网络；光学加密
- ❌ 未解：非线性光学计算的通用架构（乘法易、非线性难——光计算的命门）

## ✨ 这支最美的一个事实

**透镜的后焦面=物的傅里叶谱**：一片玻璃做一次二维傅里叶变换，
零功耗、光速、完全并行。人类造出 FFT 计算机之前，
透镜已"计算"了亿万年。

## 假设与依赖

相干照明（全息的前提）；空间带宽积（etendue 的信息版——
系统通信息量的硬上限）；抽样定理（离散化光电混合系统的地基）。
