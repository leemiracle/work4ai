# 讲透光学遥感 · 从天上看地球

> 这支负责：**用光（可见-红外-雷达）从远距离成像地球**——
> 卫星对地的"眼睛学"。
>
> GB/T 14030·三级"光学遥感"。家族：[讲透光学](../README.md)。

## 诞生

1972 Landsat-1（第一颗民用对地观测卫星——开启 50 年连续地球相册）；
1978 合成孔径雷达 SEASAT（云层不再是盲区）；2000s 高分辨率商业星座
（亚米级民用）。**地球第一次有了"体检影像科"**。

## 核心问题

- ✅ 已解：多光谱分类；合成孔径原理（运动小天线→等效大天线）；
  辐射定标与大气校正流程
- 🔄 前线：高光谱（数百波段连续谱）与 AI 解译；SAR 与光学融合；
  视频卫星（动态目标）
- ❌ 未解：全天候全天时多物理量同步成像（传感器互补的极限拼图）

## ✨ 这支最美的一个事实

**合成孔径**：一颗 10m 天线的低轨卫星靠"边飞边采"合成出
等效数公里天线的分辨率——**运动不是干扰，运动是孔径**。
这是把多普勒历史变成图像的魔法（信号处理与光学的联姻）。

## 假设与依赖

大气窗口（[../讲透大气光学/](../讲透大气光学/) 分窗）；辐射传输正模型
（反演的前置）；几何定标（像点↔地面坐标的严密换算）。
