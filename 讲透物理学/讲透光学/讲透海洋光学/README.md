# 讲透海洋光学 · 水下与水色的光学

> 这支负责：**光在海水中的传播、水色遥感与水下成像**——
> 占地球 71% 表面的光学。
>
> GB/T 14030·三级"海洋光学"。家族：[讲透光学](../README.md)。

## 诞生

1930s 开始系统测量海水固有光学量；1978 CZCS 卫星（第一台水色仪）
让"从太空看懂海洋生产力"成真；1990s Mobley 的辐射传输数值模型
（Hydrolight）确立正问题标准。

## 核心问题

- ✅ 已解：海水固有/表观光学量分类体系（IOP/AOP）；水色反演（叶绿素a浓度）
- 🔄 前线：超高分辨率水色（10m 级，近岸二类水体）；水下激光成像（距离选通）
- ❌ 未解：二类水体（浑浊近海）反演的鲁棒性（多组分耦合病态）

## ✨ 这支最美的一个事实

**卫星读出浮游生物**：海洋表层浮游植物的叶绿素吸收蓝光、反射绿光——
水色比值的微小变化暴露了全球碳泵的脉搏。卫星光谱仪是
**海洋的全球听诊器**。

## 假设与依赖

辐射传输方程（与大气光学同构——RTE 是介质的通用语法）；
纯海水+黄色物质+悬浮物三组分模型（反演的参数化基础）。
