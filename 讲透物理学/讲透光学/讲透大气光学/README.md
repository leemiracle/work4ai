# 讲透大气光学 · 天空的光学

> 这支负责：**光在大气中的传播与散射**——蓝天、晚霞、海市蜃楼、视宁度。
> 自适应光学的战场。
>
> GB/T 14030·三级"大气光学（归 17015 大气科学——双归属，GB/T 编码在光学侧列名）"。
> 家族：[讲透光学](../README.md)。

## 诞生

1871 瑞利散射公式（天空为什么蓝——短波散射 ∝1/λ⁴）；1900s 湍流折射
（星象抖动=视宁度问题）；1953 Babcock 提出自适应光学构想，
1990s 在军事与天文双线成熟（凯克望远镜用它剥掉星点的模糊）。

## 核心问题

- ✅ 已解：分子散射（瑞利）与气溶胶散射（Mie）；大气折射修正；湍流统计（Kolmogorov 谱）
- 🔄 前线：激光导星（人造参考星）；多层共轭自适应光学；自由空间光通信（FSO）的湍流对抗
- ❌ 未解：极端湍流的实时全补偿（自由度×速度的双重压力）

## ✨ 这支最美的一个事实

**天为什么是蓝的、晚霞为什么是红的**：同一公式（1/λ⁴）的正反面——
抬头看蓝天=看散射光（短波胜出）；迎着夕阳看晚霞=看透射光（短波被散射殆尽）。
一个公式解释天空的颜色学。

## 假设与依赖

散射粒子尺度分档（瑞利≪λ / Mie≈λ / 几何≫λ）；湍流的统计均匀假设
（Kolmogorov 2/3 律——与湍流理论共享，[../../讲透等离子体物理/](../../讲透等离子体物理/) 邻居）。
