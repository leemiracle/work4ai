# 讲透非线性光学 · 强光之下，介质不再温顺

> 这支负责：**光强到一定程度，介质的响应变成光强的函数**——倍频、混频、
> 自聚焦、光孤子。激光时代的开山学科。
>
> GB/T 14030·三级"非线性光学"。家族：[讲透光学](../README.md)。

## 诞生

1960 激光问世；1961 Franken 把红宝石激光穿过石英晶体，
出来的光里混着 **2 倍频的紫外**——非线性光学元年。
（轶事：论文投稿时倍频信号太弱，排版工以为是灰尘擦掉了光谱峰——
"最弱的信号开启最强的领域"。）

## 核心问题

- ✅ 已解：二次/三次谐波；光学参量振荡（可调谐相干光）；自相位调制与孤子（1973）
- 🔄 前线：微腔中的非线性频率梳；非线性超构表面；高次谐波（HHG，通往阿秒的门）
- ❌ 未解：强场下介质电离的完整动力学（多尺度耦合）

## ✨ 这支最美的一个事实

**倍频**：1+1=2 在光场成立——两个红光光子穿晶体合成一个紫外光子。
"光子算术"的第一次展示，全部晶体光学（相位匹配）都是为它服务。

## 假设与依赖

极化展开 P=χ⁽¹⁾E+χ⁽²⁾E²+…（微扰级数）；相位匹配 Δk=0（动量守恒的光学版）；
依赖中心对称破缺（χ⁽²⁾ 只在非中心对称晶体存在——为什么玻璃不倍频）。
