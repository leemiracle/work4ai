# 讲透导波光学 · 把光关进波导

> 这支负责：**光在受限结构中的传播**——光纤、平面波导、光子晶体。
> 互联网的物理本体就在这支里。
>
> GB/T 14030·三级"导波光学"。家族：[讲透光学](../README.md)。

## 诞生

1842 Colladon 演示水流导光（全内反射）；1966 高锟预言玻璃纤维可通信用光
（"把杂质降到 ppm 级"被当幻想，2021 光纤损耗已低至 0.14 dB/km，
高锟 2009 诺奖）；1970 康宁拉出第一根低损耗光纤——信息时代的脐带。

## 核心问题

- ✅ 已解：阶跃/梯度光纤模式理论；单模条件；光纤放大器 EDFA（1987，免中继跨洋）
- 🔄 前线：空分复用（多芯/少模光纤）；空芯光纤（降时延与非线性）；片上波导（→集成光子）
- ❌ 未解趣题：光纤的"终极损耗"——瑞利散射极限还能再压多少

## ✨ 这支最美的一个事实

**高锟的预言**：玻璃只要足够纯，光能跑几十公里不衰减——
当时最好的玻璃 1 dB/m（跑 1 公里剩 10⁻⁴³⁴）。
工程上"把不可能做到够好"，与理论上"发现可能"同等级伟大。

## 假设与依赖

全内反射（几何层直觉）；模式本征值问题（波动层真相——单模条件 V<2.405）；
色散（时延展宽的元凶——色散管理是系统设计的中心词）。
