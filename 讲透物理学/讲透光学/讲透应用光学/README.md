# 讲透应用光学 · 从望远镜到光刻机

> 这支负责：**光学仪器的工程科学**——镜头设计、公差、制造检验。
> 摩尔定律的物理上限（光刻分辨率）住在这支。
>
> GB/T 14030·三级"应用光学（具体应用入有关学科）"。家族：[讲透光学](../README.md)。

## 诞生

1608-09 望远镜（Lippershey/伽利略）；1840s 蔡司-阿贝科学化镜头设计
（"理论先行制造"的工业范式）；1938 起 DUV 光刻——
**ASML 的 EUV（13.5nm）是本支当代巅峰**。

## 核心问题

- ✅ 已解：像差分类与校正（Seidel 五级）；光学传递函数 MTF 评价体系；公差分析
- 🔄 前线：EUV 与 High-NA EUV；自由曲面量产；计算光刻（源-掩模联合优化 SMO）
- ❌ 未解：光刻之后（NA 与波长都到极限，下一代图案化技术未知）

## ✨ 这支最美的一个事实

**阿贝公式** CD = k·λ/NA——芯片最小线宽被波长与数值孔径锁死。
几十年的半导体 roadmap 本质上是这条公式的参数爬坡史
（λ: 436→365→248→193→13.5nm；NA: 0.4→0.55→1.35→0.33 反射式）。

## 假设与依赖

几何+波动双层并用（设计用几何、极限用波动）；制造公差
（设计到制造的信息损失）；etendue 守恒（03 章：聚光的宪法）。
