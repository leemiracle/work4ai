# 16 · 随机优化：SGD 及其方差政治学

> **一句话**：SGD 用一个 mini-batch 的噪声梯度换取百倍步数——噪声从敌人变成隐式正则，步长日程从细节升格为生死。这是机器学习对优化理论的最大改写。
>
> 实验配套：[`experiments/sgd_lab.py`](./experiments/sgd_lab.py)（SGD 噪声双面性/方差缩减/large-batch 泛化演示）

---

**2011 年前后，一个反常被发现。** 全批量的 L-BFGS 在小数据集上把训练损失压得更低、测试却更差；SGD 的噪声反而泛化更好——"噪声是正则化剂"从民间智慧升格为研究对象。十年后回顾，这揭示了机器学习与经典优化的根本分歧：**经典优化问"多快到最优点"，ML 优化问"停在哪里泛化最好"——目标函数本身只是代理**。SGD 的噪声不再是需要消灭的障碍（方差缩减技术仍要它退场——各有各的战场），而成了隐式模型选择机制。理解这对矛盾（同一步噪声，两种身份）是本章的全部。

---

## 一、直觉层：噪声的三张脸

1. **免费加速的脸**：算 1% 样本就能走一步——单位算力下步数 ×100。凸世界里 SGD 以 O(1/√t) 到达 O(1/ε²) 样本复杂度，常优于 GD 的 O(1/ε) 迭代 × O(n) 全批
2. **正则化的脸**：噪声把参数从尖锐极小值震出来，偏向平坦盆地（泛化更好的居住区——19 章深化）
3. **麻烦制造者的脸**：方差让最后阶段在最优点周围布朗游走，永远不收敛——**步长日程必须衰减**才能安家

**步长日程=噪声的货币政策**：前期大步（噪声是探索）、后期小步（噪声需平息）——O(1/t) 理论日程、cosine 工程日程、warmup 深度学习日程，全是同一政治的不同手腕。

## 二、数学层

### 2.1 SGD 的收敛定理（凸基准）

无偏梯度估计 g_t（E[g_t]=∇f(x_t)，方差 σ² 有界），步长 η_t：

$$\mathbb{E}[f(\bar{x}_t)] - f^* \;\le\; O\!\left(\frac{1}{\sqrt{t}}\right)\cdot(\text{依赖 } L,\sigma^2, D)$$

与 GD 的线性收敛（强凸 O(ρ^t)）对比——**方差项挡住了指数收敛**：噪声不衰减，就永远到不了任意精度（这正是方差缩减的动机）。证明主脉：期望意义下的压缩 + 噪声项累加，步长求和与平方和的博弈（√t 的来源）。

### 2.2 方差的政治：三方势力

- **全批 GD**：零方差、每步 O(n) 样本——精确但慢
- **SGD**：方差 O(σ²)、每步 O(1)——快而不精
- **方差缩减派**（SVRG/SAGA）：**用历史梯度的差分抵消方差**——每步 O(1) 且恢复线性收敛（凸有限和的最优解法族）。直觉：∇f_i(x_t)−∇f_i(x̃) 的方差随 x_t 靠近快照点 x̃ 消失——**噪声被"相对化"掉了**

### 2.3 Large-batch 的泛化陷阱

线性缩放规则（大 batch ×k → lr ×k）保持每样本噪声尺度，但**参数空间的随机游走半径随 batch 增大而缩小**（步长方差 ~ σ²/(kB)）——大 batch 训练倾向停在尖锐极小值。经验律：batch 超过某阈值（几千），测试精度掉点，需补偿（更大 lr/更多 epoch/LARS）。**"通用批量大小不存在"——它由噪声-泛化平衡决定，不是纯并行问题**（与讲透高性能计算的吞吐视角互补：那里要大 batch 喂饱硬件，这里要小 batch 喂饱泛化——两难的真实张力）。

### 2.4 非凸 SGD：驻点保证与逃离鞍点

光滑非凸：SGD 的 min E‖∇f‖ ≤ O(1/t^{1/4})（比 GD 的 1/√t 差——噪声的税）。但噪声的**功劳簿**：严格鞍点被噪声以概率 1 逃逸（GD 理论上可能卡鞍点，SGD 不会）——"噪声帮你避开鞍点"使 SGD 成为非凸默认选择的理论正当性（06 章合流）。

## 四、不足与边界（批判）

1. **噪声正则在深度学习常被夸大**：显式正则（ augmentation/dropout）到位时，噪声的边际泛化贡献常常消失——"SGD 隐式正则"的神话在影像分类大体成立、在 LLM 尺度未充分验证
2. **O(1/ε²) 的死缓**：高精度需求（如分布式共识优化）下方差缩减/加速才是正道——SGD 不是万金油
3. **异步与一致性**：分布式 SGD 的 stale gradient（异步）引入第二重噪声——一致性优化理论（20 章）远未指导完工程
4. **自适应×泛化的暗面**：Adam 的自适应缩放在某些任务伤泛化（更少隐式正则）——AdamW 的权重空间修复是局部解
