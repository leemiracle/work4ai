# 22 · 无梯度优化：黑箱世界的搜索术

> **一句话**：当梯度不可得（黑箱仿真/AB 测试/HPO）、不可信（噪声观测）、或不可微（离散决策）——0 阶优化是唯一的船。贝叶斯优化是这艘船的头等舱。
>
> 实验配套：[`experiments/gradient_zoo.py`](./experiments/gradient_zoo.py)（Nelder-Mead vs 贝叶斯式 bandit 竞速）

---

**1978 年，Jones 等人研究热轧钢工艺。** 每次实验成本以小时万美元计——怎么用最少实验找最优工艺？他们没有梯度（工厂不给解析式），只有昂贵观测。这条现实约束线在 1990 年代汇成贝叶斯优化（Mockus；Jones 1998 EGO 论文成为正典），在 2010 年代被 Google 调深度学习超参（Gaussian Process贝叶斯 HPO）后爆发——**今天每个 AutoML/HPO 系统的内脏都是本章**。而更早更朴素的 Nelder-Mead 单纯形法（1965）至今仍是 MATLAB fminsearch 默认——黑箱优化是"老方法活得最好"的地带。

---

## 一、直觉层：三种找宝藏的方式

- **Nelder-Mead（单纯形反射）**：牵一群探测点当"形状"——找到最差点就把它**翻个面**（反射/拉伸/收缩）。像变形虫在山谷里蠕动：不导数、不模型，只靠形状伸缩
- **贝叶斯优化（BO）**：先花小钱建**地图**（高斯过程 surrogate），地图上"哪里可能更好"（均值低）与"哪里没看过"（方差大）**讨价还价**（采集函数 acquisition），只在最值钱处花真钱——**采样经济学**
- **CMA-ES（协方差自适应进化）**：维护一个**可变形的搜索云**（多元高斯）——好样本拉高概率密度、坏样本淘汰，协方差矩阵自己学习**地形的主轴方向**（隐式二阶信息！）

**共同哲学**：把"每步信息量最大化"替代"每步方向最优"——0 阶世界里，**样本就是货币**。

## 二、数学层

### 2.1 贝叶斯优化的两件套

**Surrogate**（高斯过程）：观测集 D_t → f 的后验（每点均值 μ_t(x) 与方差 σ_t(x)）。GP 的核选择决定"地形假设"（RBF=光滑、Matérn=粗糙——HPO 常用 Matérn 5/2）。

**Acquisition**（采样经济学）：

| 采集函数 | 公式直觉 | 性格 |
|---|---|---|
| **PI**（改善概率） | Pr(f < f*−ε) | 贪婪挖已知好区 |
| **EI**（改善期望） | E[max(0, f*−f)] | **工业默认**——概率×幅度并重 |
| **UCB** | μ_t(x) − κσ_t(x) | 乐观主义（"往没看过的地方赌好"） |

EI/UCB 的 regret 界：**贝叶斯优化是 bandit 的连续版**（UCB 的 GP 版 regret O(√(Tγ_T))，γ_T=信息增益）——25 章在线优化的直系血亲（hpc-agent ② 的 C1 理论根基就在这条线：GP-UCB = 无梯度 × 在线 × 无遗憾）。

### 2.2 维数诅咒与缓解

0 阶方法的有效维数 ~10-20 封顶（每维需要的样本数指数涨）：TPE（树结构 Parzen）用密度比绕开 GP 的 O(n³)；高维靠：随机嵌入（子空间搜索）、additive GP（假设可分组）、Hyperband（早停暴力筛）。**Hyperband 的洞见：HPO 的真实成本是训练预算不是评估次数——用"半途掐死"换带宽**（与 MLSys 2020 异步 HPO 系统同思想，挂讲透高性能计算 C08 簇）。

### 2.3 何时 0 阶反而是优势

| 场景 | 0 阶胜出的原因 |
|---|---|
| 仿真黑箱（工艺/风洞/芯片） | 无解析导数，一次评估贵 |
| A/B 测试 / 在线服务调参 | 观测带噪声且不可重放 |
| 离散/混合空间（架构搜索） | 梯度未定义 |
| 对抗鲁棒性（黑盒攻击） | 目标模型只给输出 |
| 系统 knob（线程/批大小/内核参数） | 目标函数=真实系统，评估=实验——**hpc-agent ① 的 keep/revert 的数学母体** |

## 四、不足与边界（批判）

1. **维数是死刑台**：>30 维无结构问题，所有 0 阶法集体失能——"维度灾难不是玄学是数学"
2. **No Free Lunch（23 章深化）**：不利用问题结构的黑箱法在"所有可能函数"上平均等价于随机猜——**BO 的胜利全部来自"光滑性先验"这个假设**，先验错了比随机还糟
3. **并行化尴尬**：BO 的序贯性（下一步依赖上一步后验）天然反并行——异步 BO/批量采集是补丁
4. **元启发式的重灾区**：遗传/蚁群/退火在 0 阶包装下充斥不可复现的论文（不可复现调参赢基线）——50 章批判的正面战场
