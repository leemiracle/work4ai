# 07 · 约束优化技术：投影、罚金与 ADMM 的分工

> **一句话**：约束进目标有四种搬法——投影（可行域外的人被拉回）、罚函数（越界者交罚款）、增广拉格朗日（罚款+身份登记双管齐下）、**ADMM**（把问题拆成两半交替优化——分布式优化的发动机）。
>
> 实验配套：[`experiments/constrained_lab.py`](./experiments/constrained_lab.py)（lasso 四法对照：投影梯度/近端/罚/ADMM）

---

**1975 年，Gabay-Mercier 提出 ADMM。** 它的思想源头是 1950 年代的**交替方向**（把变量分块逐块优化）与**对偶上升**（乘子迭代）的结合，尘封数十年后，在 2010 年代被 Boyd 等人的综述《Distributed Optimization and Statistical Learning via ADMM》引爆——因为**大数据时代恰好需要"分块求解+稀疏通信"**：ADMM 把分布式机器学习、图像复原、统计估计的一大批问题装进同一个模板。今天它是 OSQP（QP 求解器）、分布式 RPC、联邦早期的标准算法。**它慢（一阶收敛）但极稳、极易并行**——工程界的"可靠慢牛"。

---

## 一、直觉层：四种监狱管理术

可行域 𝒳 是监狱，优化者想出去：

- **投影梯度法（PGD）**：每走一步都**被强行拉回监狱**（投影 Π_𝒳）——简单粗暴；当投影好算（box/单纯形/球）时首选
- **罚函数法**：不修墙，改为**越界收费**——二次罚 ρ·dist(x,𝒳)² 把墙变成陡坡；罚金 ρ→∞ 时解收敛到真解，但 ρ 太大数值病态（条件数爆炸）
- **增广拉格朗日（ALM/Multiplier 法）**：罚金+**拉格朗日身份登记**（λ 追踪约束的"违规历史"）——比纯罚好在 ρ 不必无限大（λ 收敛承担了精确性），比纯对偶好在增广项保证单调收敛
- **ADMM**：把 x 拆成两个角色（原始变量 x 与"影子变量 z"），**x-步最小化、z-步投影、λ-步记账**循环——三人分工，各管一段

## 二、数学层

### 2.1 投影：可行域的度量几何

PGD 迭代：x_{k+1} = Π_𝒳(x_k − η∇f(x_k))。投影算子的存在唯一性=𝒳 闭凸；投影的**不动点**恰好是约束最优性的必要条件（x* 是 PGD 驻点 ⟺ ∇f(x*) 与法锥条件——变分不等式 VI 的特例）。常用投影：box（截断）、单纯形（排序+阈值算法 O(n log n)）、球（径向缩放）、半正定锥（特征值谱投影——XXᵀ 世界的大门）。收敛率：与无约束 GD 相同（凸集上），但**条件数被投影"有效改善"**的说法是谣言——κ 不变，只是每步贵了投影。

### 2.2 罚与障碍：外罚与内点的性格差异

- **二次外罚**：P_ρ(x)=f(x)+ρΣ[max(0,g_i(x))]²——迭代序列从**不可行侧**逼近（每步都可违反，ρ→∞ 才收敛）；
- **对数障碍（barrier，内点法之心）**：B(x)=f(x)−(1/t)Σlog(−g_i(x))——迭代**严格内部**（越界=无穷大），t→∞ 时贴边。内点法的中心路径 x*(t)：t 每放大，解精度提高一档，**duality gap ≤ m/t**（m=约束数）——障碍参数就是精度的旋钮。
- 病态性对比：外罚 ρ→∞ 条件数→∞；障碍 t→∞ 同样病态但自愈（Newton 步的仿射不变性）——**内点法赢在"病态但牛顿免疫"**。

### 2.3 增广拉格朗日（ALM）：对偶+罚的合体

对等式约束 min f s.t. Ax=b：

$$\mathcal{L}_\rho(x,\lambda) = f(x) + \lambda^\top(Ax-b) + \tfrac{\rho}{2}\|Ax-b\|^2$$

迭代：x-步（对 x 最小化增广拉格朗日）→ λ ← λ + ρ(Ax−b)（**乘子上升**）。对照纯对偶上升：增广项 (ρ/2)‖·‖² 使 x-步强凸化——**收敛不再需要苛刻的步长条件**（对偶上升的死穴）。收敛率：对偶间隙 O(1/k)（原始可行性线性、对偶最优性次线性）。

### 2.4 ADMM：分块分工的完全体

问题形如 min f(x)+g(z) s.t. Ax+Bz=c（两块目标，各自好解）：

```
x ← argmin_x  L_ρ(x, z, λ)      # x-步（只看 f 与耦合）
z ← argmin_z  L_ρ(x, z, λ)      # z-步（只看 g 与耦合）
λ ← λ + ρ(Ax + Bz − c)          # 对偶上升（记账）
```

三大性质：①**各步常闭式**（f=二次/线性项时 x-步=线性方程；g=‖·‖₁ 时 z-步=软阈值）②**收敛保证宽**（f,g 凸+完整秩条件即收敛——对步长几乎不敏感）③**天然分布式**（数据按样本分块时 x-步各分块并行、只有 λ 汇总）。收敛率 O(1/k)（慢！）但**每步便宜+稳健**——大规模与分布式的甜点。

### 2.5 ADMM 的招牌应用：lasso 全流程

min ½‖Ax−b‖²+λ‖x‖₁ 改写为 ½‖Au−b‖²+λ‖v‖₁ s.t. u=v：

- x(u)-步：解 (AᵀA+ρI)u = Aᵀb+ρ(v−w)（**固定矩阵可预分解**——每步回代即可）
- z(v)-步：v = S_{λ/ρ}(u+w)（**软阈值** S_τ(x)=sign(x)max(|x|−τ,0)——prox 的明星）
- w(λ)-步：w ← w+u−v

→ 每步代价两行代码+一次回代——**"把难题拆成两半，每半都平凡"**是 ADMM 全部魔力的来源。

## 四、不足与边界（批判）

1. **ADMM 的收敛率之殇**：O(1/k) 在精度要求高时惨败给内点法（O(log(1/ε))）——OSQP 处理大规模 QP 靠 ADMM 的伸缩性，但要高精度时切换/加速（如加速 ADMM 的 O(1/k²) 变体，常需强凸假设）
2. **三块以上不保收敛**：经典 ADMM 只保证 2-block；多块需额外假设或改写——工程里"多约束拆多块"的直觉常踩坑
3. **ρ 的调参玄学**：收敛速度对 ρ 敏感（大 ρ 约束守得紧但 x-步病态；小反之）——自适应 ρ 是实用补丁但破坏某些理论
4. **非凸 ADMM**：理论仍碎片化（部分条件下局部收敛）——非凸正则（如 ℓ₀ 近似）上"能跑"与"有保证"之间有鸿沟
