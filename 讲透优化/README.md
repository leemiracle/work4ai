# 讲透优化：权衡的科学与工程（三卷 · 52 篇）

> **优化的终极定义**（本系列宪法第一句）：在**物理定律（硬件）、计算复杂性（数学）、数据分布（信息）和社会规范（伦理）**的多重约束下，通过算法（逻辑）与系统（工程）手段，寻找满足人类意图的最优决策的动态过程。最凝练的一个词：**权衡（Trade-off）**——数学中的对偶间隙、系统中的时空转换、社会中的效率与公平、AI 中的探索与利用，全是同一件事的方言。
>
> **三卷结构**：卷一（理论：哲学与数学）→ 卷二（算法与系统：从公式到晶体管）→ 卷三（智能、伦理与应用：优化的现代战场）。**边界**：性能物理层全谱在 [`讲透高性能计算`](../讲透高性能计算/README.md)，本系列 26 章造方法论之桥。
