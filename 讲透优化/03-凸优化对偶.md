# 03 · 凸优化与对偶：影子价格的数学

> **一句话**：每个约束最优化问题都藏着一个"影子价格"问题——原问题问"怎么配最好"，对偶问题问"资源每单位值多少钱"。强对偶定理说：两边的账必须算平（间隙为零）。
>
> 实验配套：[`experiments/convex_lab.py`](./experiments/convex_lab.py)（LP 对偶间隙数值验证 + KKT 条件实测）

---

**1961 年，Karush-Kuhn-Tucker 条件被重新发现。** 1939 年 Karush 的硕士论文无人问津，1951 年 Kuhn-Tucker 独立发表后成为现代优化理论的基石——条件以三人命名，错过的二十年里，经济学已自己长出了同样的思想：**Lagrange 乘子是资源的影子价格**。一个工厂最大化利润（原始问题），等价于给每种资源定一个"内部价"使利润全部来自资源售卖（对偶问题）——线性规划对偶在 Dantzig 与 Kantorovich（1975 诺贝尔经济学奖）手里成了计划经济与市场定价的数学桥梁。**对偶不是技巧，是同一个决策问题的两种记账法**。

---

## 一、直觉层：监狱、罚金与影子价

原问题（P）：min f(x) s.t. g_i(x) ≤ 0——"在监狱（可行域）里找最低点"。

**Lagrange 的移监为罚**：把约束搬进目标——

$$L(x, \lambda) = f(x) + \sum_i \lambda_i g_i(x), \qquad \lambda_i \ge 0$$

读法：**每条监狱规则换成罚金**（λ_i=违反单位 g_i 的价格）。对偶函数 q(λ) = min_x L(x,λ)：任何罚金下"自由身的最低花费"都是原问题值的**下界**（罚轻了自由者占便宜、罚重了保守）——**对偶=寻找最紧的罚金体系**。强对偶：存在恰好算平的罚金（λ*），此时下界贴上原值——**λ* 就是每条约束的影子价格**（松一单位约束，最优值改善 λ_i*）。

## 二、数学层

### 2.1 弱对偶与强对偶

$$q(\lambda^*) = d^* \;\le\; p^* \quad\text{（弱对偶恒真，非凸也真——LP 对偶剪枝的根基）}$$

**强对偶定理（Slater 条件版本）**：凸问题 + 存在严格内点（relint 可行）⟹ p*=d*。**几何直觉**：若间隙>0，由 02 章分离超平面可在 (t, x) 空间切一刀造出改进的 λ——**强对偶=分离定理的应用题**（凸分析兑现时刻）。

### 2.2 KKT 条件（最优性的完全证书）

x*, λ* 最优 ⟺ 四条联立：

1. **原始可行**：g_i(x*)≤0
2. **对偶可行**：λ_i*≥0
3. **梯度平衡**：∇f + Σλ_i∇g_i = 0（罚金体系下 x* 是无约束驻点）
4. **互补松弛**：λ_i* g_i(x*) = 0——**不顶到边界的约束罚金为零**（"监狱里离墙远的人感觉不到墙"）

**互补松弛是全部经济学**：稀缺（绑定）资源有正价格、闲置资源免费。线性规划里它给出"哪些约束在主导"的灵敏度分析。

### 2.3 LP 对偶（两行模板）

$$\max c^\top x,\; Ax\le b \;\;\Longleftrightarrow\;\; \min b^\top \lambda,\; A^\top\lambda = c,\;\lambda\ge0$$

——每条原始约束 ↔ 一个对偶变量；每个原始变量 ↔ 一条对偶约束。**min-max 对称翻转**。这就是"产品定价"与"资源估值"的两面（Dantzig-Kantorovich 桥）。

### 2.4 对偶的算法化身

- 对偶上升法：x-步与 λ-步交替（ADMM 的祖先，07 章）
- 内点法：沿**中心路径**（barrier 参数 t→∞）逼近 KKT 点——每步解一个"罚函数化的凸问题"
- 对偶间隙做**停机证书**：gap=原-对偶值，求解器报 gap<1e-9 才算数（不是"跑完迭代数"）——**可证最优性是凸优化的工业尊严**

## 三、代码层（bash 实跑验证）

```python
# experiments/convex_lab.py 节选 —— LP 对偶与 KKT 三重验证
from scipy.optimize import linprog
# P: min -x1-2x2  s.t. x1+x2≤4, x1+3x2≤6, x1,x2≥0
r = linprog(c=[-1,-2], A_ub=[[1,1],[1,3]], b_ub=[4,6], bounds=[(0,None)]*2)
# 对偶值 = linprog 结果的 marginals（λ）
lam = r.ineqlin.marginals                      # 影子价格（≤0 惯例取负）
dual_obj = (np.array([4,6]) * -lam).sum()
print(r.fun, dual_obj)                          # 相等 ✓ 强对偶数值验证
# KKT 互补松弛：λ_i>0 ⟹ 对应约束顶满（残差≈0）
for i, l in enumerate(-lam):
    resid = (np.array([[1,1],[1,3]])@r.x - np.array([4,6]))[i]
    assert l * resid < 1e-8                     # 互补松弛 ✓
```

## 四、不足与边界（批判）

1. **Slater 可以失效**：退化问题（无可行内点）强对偶可能破——LP 恒强对偶是特权，一般凸要条件
2. **对偶变量维度=约束数**：约束百万级时对偶问题同样巨大（对偶不是降维魔法，是换视角）
3. **非凸时弱对偶仍是下界**——这正是 Goemans-Williamson Max-Cut 的 0.878（12 章：SDP 松弛=先凸化再对偶），**"松弛-对偶-舍入"三段是组合优化的标准军礼**
4. **影子价格的可信域**：λ* 只在局部灵敏（约束微松时线性预测）——大改约束要用参数规划重解，不能外推（经济学误用重灾区）
