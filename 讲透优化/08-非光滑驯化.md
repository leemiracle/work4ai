# 08 · 非光滑的驯化：次梯度、近端与最优复杂度

> **一句话**：L1 正则、hinge 损失、约束指示函数——现实目标处处带棱角。次梯度把导数推广成"方向集合"，近端算子把"带棱角的极小化"变成一次闭式求解——而 Nesterov 证明：非光滑的代价恰好是一个 √κ 因子，无法再省。
>
> 实验配套：[`experiments/nonsmooth_lab.py`](./experiments/nonsmooth_lab.py)（次梯度 vs 近端梯度在 lasso 上的慢舞对照）

**1960 年代，Shor 与苏联学派。** 凸分析的黄金十年里，次梯度（subgradient）几乎同时被苏联（Shor 1962，用于整数规划的对偶）与西方（Moreau 1963/1965 的近端映射，Rockafellar 的推广）发展。Moreau 的洞见超前时代半个世纪：**带正则的极小化 min f(x)+g(x) 中，g 的贡献可以预解为一个单变量算子**——"Moreau 包络/近端算子"是今天整个稀疏优化（lasso 全家）、分裂算法（ADMM/FISTA 的 z-步）与单调算子理论的地基。Nesterov 与 Nemirovski 在 1980 年代给出复杂度定论：一阶法在非光滑凸上的下界 O(1/ε²)，光滑是 O(1/ε)——**棱角恰好贵一个平方根**。

## 一、直觉层：棱、电梯与烫手山芋

- **次梯度 ∂f(x₀)**：所有"在 x₀ 支撑着图像的直线斜率"的集合。光滑点：单元素={f'(x₀)}；**折点（如 |x| 在 0）：整段区间 [−1,1]**——折点处"导数不唯一"不是病，是几何事实（所有既不上穿也不下漏的切线都合法）
- **次梯度法的慢**：−g（任选一个次梯度）不保证下降方向（|x| 在 0 处选 g=1 会往 −走但 f 已最小）——只能保证**距离收敛**（函数值 O(1/√k) 龟速），像在楼梯上横着蹭
- **近端算子**：prox_g(v) = argmin_x g(x)+½‖x−v‖²——**"把 v 向 g 的低价区温和拉一把"**：g=ℓ₁ 时是软阈值（小幅直接归零——稀疏性的来源）、g=指示函数时是投影、g=ℓ₀ 近似时是硬阈值。直觉：拿着 v（当前梯度步结果）这块**烫手山芋**，问"g 规则下最划算的落点在哪"
- **近端梯度法**：f 光滑+g 非光滑的**分而治之**——光滑部分走梯度，非光滑部分过 prox（一次闭式解）

## 二、数学层

### 2.1 次微分的正式定义与三性

$$\partial f(x_0) = \{g : f(x) \ge f(x_0) + \langle g, x-x_0\rangle,\ \forall x\}$$

（全体全局支撑斜率——注意是**全局**下界，比"切线"强）。三条核心性质：①凸函数在定义域内部 ∂f≠∅ ②x* 最优 ⟺ 0 ∈ ∂f(x*)（最优性的统一形式——约束、正则全部并入）③∂f 是单调算子：⟨g_x−g_y, x−y⟩ ≥ 0（单调性的算法化：近端点法=momentum 的非光滑版）。

经典例：∂|x₀|={sign(x₀)}（x₀≠0）、[−1,1]（x₀=0）；∂‖x‖₁=∂|x₁|×…×∂|x_n|（坐标分离——近端可并行）；**ℓ₁ 正则的最优性**：0∈∂(f+λ‖x‖₁) ⟺ |∇f_i|≤λ（小于 λ 的坐标直接归零——**软阈值制造稀疏的机制**）。

### 2.2 近端算子：三大恒等式与计算库

**Moreau 恒等式**：v = prox_g(v) + prox_{g*}(v)（g 与共轭 g* 的近端互补——对偶的 prox 化身）。

| g | prox_g(v) | 名字 |
|---|---|---|
| λ‖x‖₁ | sign(v)·max( \|v\|−λ, 0 ) | **软阈值**（lasso 之心） |
| 指示函数 ι_C | Π_C(v) | 投影（07 章） |
| λ‖x‖₀ | v·1[\|v\|>λ] | 硬阈值（非凸，ISTA 的亲戚） |
| λ‖x‖₂ | max(1−λ/\|v\|,0)·v | 块软阈值（group lasso） |
| λmax(0,x)（hinge 梯度型） | max(v−λ, 0) | 单边截断 |

——**prox 可算性=近端法的入场券**；不可解时用 ADMM 拆（07 章 z-步就是 prox）。

### 2.3 近端梯度法与 FISTA（加速的非光滑版）

复合结构 min F(x)=f(x)+g(x)（f 光滑 L-Lipschitz 梯度、g 闭凸可 prox）：

$$x_{k+1} = \operatorname{prox}_{\eta g}\big(x_k - \eta\nabla f(x_k)\big)$$

收敛率：**O(1/k)**（对比次梯度 O(1/√k)——prox 换来的一个 √k）。FISTA（Beck-Teboulle 2009）=Nesterov 加速的 prox 版：O(1/k²)——**非光滑项不拖累加速**（加速只作用于光滑部分）。收敛证明骨架：Lyapunov 函数（能量序列）的递推——与 04 章 ODE 视角同构。

### 2.4 Nesterov 光滑化：把棱角磨圆的技术

任意凸（真非光滑）的 g 的 **Nesterov smoothing**：用共轭+强凸项构造 g_μ(x)=max_u ⟨x,u⟩−g*(u)−(μ/2)‖u‖²——**μ-光滑且 |g_μ−g|≤O(μD)**。先磨圆（μ）再加速（√L/μ），取 μ~ε 得**最优 O(1/ε) 复杂度**（对结构性非光滑，如 max 函数/SVM 的 hinge 损失族）——这是加速方法在一般非光滑问题上"绕过下界"的唯一通道：**下界针对任意非光滑；结构（可光滑化的）非光滑可以更快**。

### 2.5 复杂度总表（一阶法的完全地形）

| 问题类别 | 下界 | 达标算法 | 达标者 |
|---|---|---|---|
| 光滑强凸 | O(√κ log 1/ε) | NAG | Nesterov 1983 |
| 光滑凸 | O(1/√ε) | NAG | Nesterov 1983 |
| 复合（光滑+可prox非光滑） | O(1/√ε) | FISTA | Beck-Teboulle 2009 |
| 结构性非光滑 | O(1/ε) | Nesterov smoothing | Nesterov 2005 |
| 任意非光滑凸 | **O(1/ε²)** | 次梯度法 | Shor/Nemirovski-Yudin |

→ **√ 因子的阶梯**：每降一档结构，代价乘一个 1/√ε。非光滑世界的税则是 Nesterov 时代最漂亮的结果之一。

## 四、不足与边界（批判）

1. **prox 不可解则全盘卡住**：近端法的美梦止于"g 的 prox 没有闭式"——此时 ADMM 再拆（07 章）或内层迭代（不再精确 prox，收敛证需 inexact 分析）
2. **非凸 g（ℓ₀/排名函数）无理论**：硬阈值 ISTA 类算法只有"收敛到驻点"的弱保证——稀疏恢复的 RIP 理论在优化之外单独补票
3. **次梯度的选择歧义**：∂f 是集合，"选哪个"影响实践但理论只对平均/任意都鲁棒的保证——实现细节成了性能来源（坏味道）
4. **随机近端（prox-SGD）的两难**：g 精确 prox 与 f 的随机梯度耦合时方差进入 prox——正则化训练（AdamW 的 weight decay 其实是 prox-SGD 的近似）的理论仍活跃
