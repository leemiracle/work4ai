  The `ui-conversation` package provides the target-neutral conversation assembly and browser shell for DeepSeek Harness. It implements the conversation skeleton, the streaming chat transcript, and the extensible composer system. It is designed to be session-agnostic at the root level while providing strict session-scoped views and controls once a session is active [packages/client/ui-conversation/README.md1-12](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L1-L12)

 
## Conversation Skeleton & Root

 The `ConversationRoot` serves as the primary layout container for the chat interface. It manages the transition between the "Hero" state (no active session, showing a workspace picker) and the "Active" state (session transcript and composer) [packages/client/ui-conversation/src/client/skeleton/ConversationRoot.tsx1-3](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/src/client/skeleton/ConversationRoot.tsx#L1-L3)

 
### Implementation Details

 
 - **Phase Management**: The shell phase is calculated by combining session lifecycle state with the active-target set [packages/client/ui-conversation/README.md39](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L39-L39) The `ConversationRoot` determines if the phase is `blank` or derived from `conversationPhase` [packages/client/ui-conversation/src/client/skeleton/ConversationRoot.tsx140-142](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/src/client/skeleton/ConversationRoot.tsx#L140-L142)
 - **Adaptive Width Axis**: The transcript and composer share a centered width axis (`--dsh-chat-content-width`). It defaults to 64% of the column width (clamped between 680px and 920px) or follows a user-dragged preference [packages/client/ui-conversation/src/client/skeleton/ConversationRoot.module.css28-31](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/src/client/skeleton/ConversationRoot.module.css#L28-L31)
 - **Width Handles**: Symmetric resize handles allow users to drag the content width. These handles publish the pointer's Y-coordinate as a CSS variable for the glow indicator [packages/client/ui-conversation/src/client/skeleton/ConversationRoot.tsx46-56](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/src/client/skeleton/ConversationRoot.tsx#L46-L56)
 - **Hero State**: Without a session, the composer surface remains mounted but inert, acting as a trigger for the Workspace picker [packages/client/ui-conversation/README.md41](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L41-L41)

## Conversation Assembly & Streaming

 The `UiConversation` service manages the assembly of `SessionEventLikeEntry` feeds into a materialized conversation snapshot [packages/client/ui-conversation/README.md28-30](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L28-L30)

 
### Key Features

 
 - **Target Neutrality**: The assembler owns context matching, turn/step locations, and target node materialization, but specific targets like `chat` are registered separately [packages/client/ui-conversation/README.md30-32](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L30-L32)
 - **Registries**: `UiConversation.events` and `UiConversation.views` are the single registries for event definitions and target snapshot builders [packages/client/ui-conversation/README.md28](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L28-L28)
 - **Incremental Assembly**: Contiguous revisions use incremental assembly without expanding packed members, while gaps trigger a full rebuild from the loaded window [packages/client/ui-conversation/README.md30](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L30-L30)
 - **Image Cache**: A per-session durable image URL cache (`ctx.uiConversation.imageUrl`) resolves session-authorized browser URLs and revokes them when the session binding is disposed [packages/client/ui-conversation/README.md12](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L12-L12)

## Composer & Input System

 The composer is a slot-based chain (`conversation.composer`) that allows plugins to take over the input area for specific interactions like approvals [packages/client/ui-conversation/README.md50-62](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/README.md?plain=1#L50-L62)

 
### InputBar

 The default occupant of the composer chain. It uses a Lexical-based editor for the text surface [packages/client/ui-conversation/src/client/skeleton/InputBar.tsx1-14](https://github.com/deepseek-ai/deepseek-harness/blob/cd5ef814/packages/client/ui-conversation/src/client/skeleton/InputBar.tsx#L1-L14)
