# 01 · 图的解剖学：节点、边、类型边——为什么偏偏是图

> 讲透Graph 第 01 章 | 实验 E1（`experiments/E1_typed_vs_similarity.py`）

## 1. 直觉层：气质相投 vs 明媒正娶

向量检索说：这两个东西**气质相投**（嵌入空间邻近）。
类型边说：这两个东西**明媒正娶**——而且结婚证上写着关系类型。

"ADR-007 在嵌入空间里靠近 ADR-003" 是一个需要人猜的邻近信号；
"ADR-007 **supersedes** ADR-003" 是一条可以据此行动的声明。
这就是 vanja.io 的核心洞察：**"需要图的问题都是藏着动词的问题"**——caused / replaced / depends on / approved / blocked，那些动词就是穿着人类衣服的边。

什么时候必须用图？问自己：**这个问题的答案取决于"什么东西跟什么东西怎么相关"，还是"什么东西跟问题长得像"？** 前者图赢，后者向量赢。

## 2. 数学层：从度量空间到关系结构

**图**：$G = (V, E, \phi)$，其中 $V$ 是节点集，$E$ 是边集，$\phi: E \to V \times V \times \Sigma$ 是关联函数，$\Sigma$ 是**类型字母表**（supersedes / depends_on / ...）。

三个关键观察：

1. **相似度活在度量空间，图活在关系结构**。Jaccard/余弦相似度 $s(a,b) \in [0,1]$ 是对称的、无类型的：$s(a,b) = s(b,a)$，且不回答"怎么相关"。而 $\phi$ 有向、有类型：$(A,\text{supersedes},B) \neq (B,\text{supersedes},A)$；
2. **类型边的价值 = $\log_2 |\Sigma|$ 比特/边**。从"相关"（1 bit：有边/无边）到"怎么相关"（$|\Sigma|$ 种），每条边多携带 $\log_2|\Sigma|$ 比特。E1 里 6 种关系类型 ≈ 2.6 bit——恰好是把"模型猜测"变成"确定遍历"的那点信息；
3. **查询复杂度**。类型边查询是一次索引查找 $O(1)$（哈希表 `(src, relation) → dst`）；相似度查询是最近邻搜索 $O(\log n)$（ANN 索引）+ **事后消歧**（top-k 里哪个才是答案？）——消歧这一步没有理论保证，全靠模型猜。

## 3. 代码层：E1 实测

实验设计（诚实标注：规则模拟，Jaccard 模拟向量检索）：9 个节点（7 个 ADR + 事故 + 证书）、6 条类型边、5 道"隐藏动词"问题。结果（`E1_result.json`）：

```
类型边 precision@1 = 5/5     相似度 top-3 候选池精确率 = 0/5
```

最扎眼的一条：ADR-006（see_also）与 ADR-007（supersedes）的主题标签几乎相同（都是 cache/redis/queue 邻域）——**相似度永远分不清"参见"和"替代"，类型边一个字段就分开**。相似度检索每题都能召回 gold 进 top-3，但候选池里混着 2 个噪声，模型还得猜——这正是 Ch07 要量化的 per-hop 精度问题的源头。

最小代码骨架（类型边的全部威力就是一个哈希表）：

```python
edge_index = {}
for src, rel, dst in edges:
    edge_index.setdefault((src, rel), []).append(dst)
# "谁替代了 ADR-003?" → 反向查一次
[s for (s, r), d_ in ... if r == "supersedes" and "ADR-003" in d_]  # → ADR-007
```

## 4. 不足与坑

- **schema 冻结成本**：$\Sigma$ 要先定义（Ch09 本体工程的全部痛苦从这里开始）；
- **抽取噪声**：LLM 抽边会抽错——一条错误的 supersedes 边会让 agent 理直气壮地用废弃决策（错误沿着边**传播**，而相似度的错误只是噪声）；
- **维护税**：边会过期（ADR-008 又替代了 007 呢？）——这是 Ch03 bi-temporal 要解的问题；
- **别把图当锤子**：主题聚类、模糊探索、开放式摘要类问题，向量仍然是对的工具（Ch07 三路由）。

## 5. 与姊妹篇接口

- 讲透Prompt 的结构化输出（JSON mode）= 抽取类型边的产出端：让 LLM 以 `(subject, relation, object)` schema 吐出边；
- 讲透Context：图的查询结果序列化成文本进窗口——**图管窗口外的结构，context 管窗口内的呈现**。
