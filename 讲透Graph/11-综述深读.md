## 1. 骨架：三层智能 + 五工程

综述的地图（Fig.1/2/4/5 的文字版）：

```
模型智能 Model Intelligence     —— PE 引出能力 + CE 管理信息（+预训练/后训练）
        ↓
个体智能 Individual Intelligence —— Harness 组织工具 + Loop 持续反思（+记忆/技能/运行时编排）
        ↓
系统智能 System Intelligence     —— ★ Graph Engineering（+ Ontology Engineering 作语义层）
```

**核心论题**：个体智能有结构性上限。当任务内在地需要**异构专长、相互依赖的子任务、并行执行、独立验证、持久状态**时，这五项需求超出任何单 agent 的组织容量——"增强单个 agent 的能力或上下文无法解决这种**架构性错配**"，智能必须分布到多个专门组件并在系统层组织。

这句话是整个领域的宣言，也是本单元存在的理由：Prompt/Context/Harness/Loop 四环优化的是"一次交互/一个 agent"；Graph 是第一个把**关系本身**当作设计对象的工程范式。

## 2. 三支柱细读（GE 的正式定义域）

综述把 Graph Engineering 定义为解决三个组织问题（+一个演化维度）：

**(i) Task Organization（结构化"做什么"）**：全局目标 → 可执行单元的图分解；边编码先序/数据/逻辑约束；支撑并行分支调度与工作流精化。（→ 本单元 Ch05）

**(ii) Agent Coordination（组织"谁来做"）**：工作单元到异构组件的映射；通信、委派、同步、结果集成的结构化。（→ Ch06）

**(iii) Runtime State Management（维护"到哪了"）**：事件、依赖、状态转移的图化记录；追踪进度、调和并发更新、保存溯源、隔离失败、恢复/适配。"把散落在 context 和日志里的运行信息，转化为**可审计、可恢复的系统状态**"。（→ Ch08）

**(iv) System Evolution（系统怎么长大）**：综述 §5 承认这是实践中最稀缺的一环——应用遍地都是，持续演化罕见。

## 3. 未来方向（§6-7：最值钱的部分）

- **Capability graphs（能力图）**：把 models/tools/skills/memories/data sources/verifiers/execution environments 全部表示为 typed nodes，边描述 dependency / compatibility / composition / substitution / **authorization / cost / reliability**。难点不是每个能力族各自成图，而是**能力图与任务图/agent 图/状态图的联动**：任务分解应暴露能力需求，agent 分配应参考可用能力子图，执行结果应更新能力可靠性；
- **Cross-graph evolution（跨图演化）**：三张图不能独立演化——改任务图可能改变 agent 团队需要的能力；换 agent 可能作废通信关系/权限/运行时假设。结构演化必须在溯源、版本、校验、replay、rollback 的**治理**下进行。"长期目标不是无限制自我修改，而是既能积累组织经验、又能防止不可靠结构蔓延"；
- **Graph-native agent OS（图原生操作系统）**：任务/agent/能力/状态成为 typed+versioned 的一等系统对象；共享运行时提供图调度、能力发现、状态存储、事件溯源日志、**结构事务**、权限执行、checkpoint/replay/rollback、图级可观测性（→ Ch08 已展开）；
- **Ontology Engineering 作共享语义层**（→ Ch09）。

## 4. 批判性阅读（本单元立场）

**强处**：
- 35 作者跨 10+ 机构的联盟综述 = 社区共识的快速快照；分类学三层（Model/Individual/System）是目前最干净的谱系；
- 诚实标注了实践缺口（System Evolution 罕见）——不是纯 hype 文献。

**弱处与偏见**：
1. **收录偏差**：联盟作者的自身工作占据分类学关键位置（综述的通病，Awesome 仓库同样如此）；
2. **双分支失衡**：综述以 execution graph 为主轴（任务/协调/状态），context graph（知识/记忆图）被收编进"状态管理"和背景章节——而工业界（Neo4j/Zep）的图谱重心恰恰在后者。**读这份综述时要把 Zep/Graphiti/Neo4j 这支自己补回第一等公民**（本单元 Ch03/04 就是补这一票）；
3. **术语战争的政治**：把 PE/CE/HE/LE 正名为"前四代"客观上服务于"GE 是第五代"的叙事——谱系是真的，但"代际"的暗示（取代关系）是营销的。本单元的立场：**五环是分工不是世系**，图不取代前四环，图给它们搭骨架；
4. **评测缺席**：综述列了 benchmarks 附录，但没有回答"怎么证明图系统比非图系统好"——GEM 2026 的 9 场景对照实验反而是更硬的证据（→ Ch12）。
