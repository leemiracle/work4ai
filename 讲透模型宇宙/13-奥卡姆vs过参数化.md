# 13 · 奥卡姆剃刀 vs 过参数化悖论

> "如无必要，勿增实体。"——奥卡姆剃刀，科学方法论的基石之一。它说：**简单的解释更好**。在机器学习里，这变成了"简单模型泛化更好"——几十年的统计学习理论都这么教。然后 **double descent** 现象出现了，狠狠打了它一巴掌：**最差的不是最复杂的模型，而是"刚好够参数"的模型；过了临界点，越复杂反而越好。** 本章带你亲眼看这个悖论，并理解现代大模型为什么能 work。

## 13.1 奥卡姆剃刀：简单更好的直觉

奥卡姆剃刀（Occam's Razor）：当多个解释都能拟合观察时，**选最简单的**。

在 ML 里，它表现为：
- **正则化**（L1/L2）：惩罚复杂模型，偏好简单解；
- **VC 维理论**：模型容量（复杂度）越高，泛化 gap 越大，所以要控制复杂度；
- **经典泛化曲线**（U 形）：模型从太简单（欠拟合）→ 刚好 → 太复杂（过拟合），test error 呈 U 形，**最低点在"刚好"**。

这套理论统治了 1990s-2010s。它的图景是：

```
test error
  │  ╲       ╱
  │   ╲     ╱      经典 U 形
  │    ╲   ╱       "刚好"处最优
  │     ╲_╱
  └────────── 模型复杂度 →
       欠  刚好  过拟合
```

据此，研究者长期相信：**模型不能太大，否则过拟合**。

## 13.2 现象：double descent 打脸奥卡姆

2019 年，Belkin et al.（*Reconciling modern machine-learning practice and the bias-variance trade-off*）系统刻画了一个反常现象——**double descent**（双重下降）：

当模型复杂度**继续增加**，越过"刚好"的临界点后，test error **不升反降**：

```
test error
  │  ╲       ╱╲
  │   ╲     ╱  ╲    double descent
  │    ╲   ╱    ╲   临界点峰值, 然后又降!
  │     ╲_╱      ╲___
  └────────────────── 模型复杂度 →
       欠  刚好  临界  过参数化
```

三段：
1. **欠拟合区**（太简单）：train/test 都高；
2. **临界区**（刚好够参数插值训练集）：train→0，但 test **达到峰值**（最差！）；
3. **过参数化区**（参数远超数据）：train=0，test **反而下降**。

**反直觉核心**：最差的模型不是最复杂的，而是**"刚好能插值"**的那个。一旦参数足够多（过参数化），模型反而泛化更好。现代深度学习（大模型）就活在第三区。

## 13.3 数学：为什么过参数化反而好？

直觉：过参数化时，训练集能被**无穷多个**解插值。梯度下降（最小范数解）会**隐式地**选其中**最简单**的那个——而"最简单的插值解"恰恰接近真实函数。

形式化（线性回归）：当参数 $d \gg$ 数据 $N$，方程 $Xw = y$ 欠定，有无穷多解。**最小范数解**（$\min \|w\|$ s.t. $Xw=y$）是：

$$
w^* = X^\top (XX^\top)^{-1} y
$$

这个解虽然完美插值（$Xw^* = y$），但因为**偏好小范数**，它不会"剧烈震荡"——它平滑地穿过数据点，这种平滑性让它**在新数据上也准**。

> **奥卡姆没死，它变形了**：过参数化模型不是"不简单"，而是"在所有插值解里隐式选了最简单的"。剃刀从"限制复杂度"变成了"在足够表达力下偏好平滑"。

## 13.4 现代 LLM：极端过参数化

GPT-4 估计有 1.8 万亿参数，训练数据约 13 万亿 token——参数远超"刚好"。它活在 double descent 的第三区。它泛化好，不是**因为**奥卡姆（简单），而是**因为**过参数化 + 隐式正则化（SGD 偏好平滑解）。

这解释了"为什么大模型不严重过拟合"——经典理论预测它应该过拟合到死，但它在第三区。

## 13.5 实验：亲眼看到 double descent

见 `experiments/13_double_descent.py`。它：
1. 生成 sin 函数 + 噪声的数据；
2. 用多项式回归，复杂度（阶数）从 1 扫到远超数据点数；
3. 打印 train/test error 曲线。

你会看到：test error 先降（欠拟合改善）→ 在"阶数≈数据点数"处**冲到峰值**（临界最差）→ 继续增加阶数，test error **又降**（double descent）。反直觉：**最差在中间，不在最复杂**。

## 13.6 奥卡姆剃刀的修正版

double descent 没否定奥卡姆，而是**修正**了它：

| | 经典奥卡姆 | 修正版 |
|---|----------|--------|
| 信条 | 简单模型泛化好 | 在**同容量**下偏好简单解 |
| 复杂度 | 越小越好 | 有个"危险临界点"；过了反而好 |
| 适用 | 数据 ≫ 参数 | 数据 ≪ 参数（过参数化）|
| 工具 | L1/L2 正则化 | 隐式正则化（SGD/早停/架构）|

> **研究者的工具**：两个区域都重要。小数据场景（如医学、金融），经典奥卡姆 + 正则化仍然对；大数据 + 大模型场景，过参数化 + 隐式正则化才是现代范式。**不要用 1990s 的小数据直觉，套 2020s 的大模型现象**——这是最常见的认知错位。

## 13.7 批判与未解

- **double descent 不是万能**：它依赖**各向同性**的数据分布和**最小范数**的隐式偏好。真实数据有长尾，过参数化的好处可能被噪声吃掉。
- **"临界点"危险**：在临界区，模型对 seed/数据极敏感（见 Ch08 相变、Ch14 可复现性危机）。研究者要**主动跳过临界区**（要么用更小、要么用更大模型）。
- **理论仍在发展**：为什么 SGD 恰好偏好"好"的解？这背后的**隐式正则化理论**仍是开放问题。
