# 15 · 模型研究者工具箱

> Part I-III 给了你三组武器：丈量（生态/排行榜）、解剖（探针/SAE/模型生物/缩放）、看穿（第一性原理/费曼/奥卡姆/批判）。本章把它们整合成**一条端到端的研究工作流**——拿到一个模型，从"选"到"改"的完整 pipeline。这是全系列的方法论收口。

## 15.1 五步研究工作流

研究一个模型（无论别人的还是自己的），走这五步：

```
[选] 选模型 ─→ [评] 评估 ─→ [探] 探测 ─→ [懂] 理解 ─→ [改] 改进
  Ch01-02      Ch03-04      Ch06-07      Ch08-11      循环回到评
```

每一步都有"工具 + 方法 + 陷阱"。下面逐一展开。

## 15.2 第一步：选（Select）

**目标**：从模型宇宙里选出值得研究的对象。

- **工具**：HuggingFace Hub（按 downloads+likes 筛）、Epoch AI（看算力）、本系列 Ch01 的家族图。
- **方法**：先按任务（pipeline_tag）筛，再按"活跃维护 + 社区验证"排序，选 2-3 个候选。
- **陷阱**（Ch02）：license 陷阱、自报分数不可信、数据污染。
- **研究者加分**：选**中等规模开源权重模型**（1B-14B）——大到有研究价值，小到你能在单卡上跑可解释性。

## 15.3 第二步：评（Evaluate）

**目标**：独立评估模型的真实能力，不信自报分数。

- **工具**：Arena（人类对战，注意 style control）、Open LLM Leaderboard、lm-eval-harness、LIVEBench（防污染）。
- **方法**：多榜交叉验证 + 自己跑几个手写测试。
- **陷阱**（Ch03-04）：刷榜、style bias、数据污染、度量假象、Goodhart。
- **研究者加分**：用 **§14.6 八问**审每个分数。分数只是"信号"，不是"真相"。

## 15.4 第三步：探（Probe）

**目标**：钻进模型内部，测量它的表征。

- **工具**：transformers（`output_hidden_states=True` 拿激活）、线性探针、SAE（SAELens）、t-SNE/PCA 可视化。
- **方法**：先 probing 找"哪些层编码了什么"，再上 SAE 分解特征。
- **陷阱**（Ch06-07）：**probe 准 ≠ 因果**；SAE 有死特征 + 77% 惰性。
- **研究者加分**：每个"发现"都过**干预验证**（ablation/steering）——这是从相关到因果的关键一跃。

## 15.5 第四步：懂（Understand）

**目标**：把"探测到的现象"变成"理解的机制"。

- **工具**：第一性原理推导（Ch11）、费曼检验（Ch12）、模型生物/玩具模型（Ch08/10）。
- **方法**：探测发现现象 → 用玩具模型孤立机制 → 用第一性原理推导为什么 → 用费曼方法确认自己真懂。
- **陷阱**：把相关当因果（Ch14）、把术语当理解（Ch12）、把经验当原理（Ch11）。
- **研究者加分**：能用 §12.2 的七问 + 一段外行能懂的话，讲清你发现的机制。

## 15.6 第五步：改（Improve）

**目标**：基于理解，改进模型（或改进研究方法）。

- **工具**：steering（调特征方向）、structured pruning、新训练目标、新架构（Ch01 模型可能性）。
- **方法**：改 → 回到[评]看效果 → 回到[探]看机制变化 → 循环。
- **陷阱**：改了分数但不懂为什么（不可复现）、改了一个能力伤了另一个（trade-off）。
- **研究者加分**：每次改动都**记录机制变化**（不只看分数），积累成你自己的"算法经验库"。

## 15.7 端到端示例：研究"某模型为什么会拒绝"

把这五步套到一个真实问题上：

1. **选**：Qwen-2.5-7B-Instruct（开源、中等、有拒绝能力）。
2. **评**：用一组有害 prompt 测拒绝率，对比 base/instruct 版本。
3. **探**：在有害/无害 prompt 的激活上训探针，发现"拒绝"在第 N 层线性可分（Ch06）。
4. **懂**：找到"拒绝方向" $w$（refusal direction，Arditi 2024）；投影掉它，拒绝率从 99.9% → 25.5%；用费曼方法讲清"拒绝 = 一个线性方向"。
5. **改**：用这个方向做 activation steering，**可控地**调节模型的拒绝强度——既可减弱过度拒绝，也可（警示）绕过安全。

> 这五步走完，你就不只是"用"了 Qwen，而是**研究**了它——你知道它的拒绝机制、能验证因果、能可控干预。这就是使用者到研究者的跨越。

## 15.8 研究者的"日常"

把五步流程变成习惯：
- **每周**：跑一遍 Daily Papers（Ch04），用三级阅读制筛 1-2 篇精读；
- **每月**：做一个 mini 研究（五步走一遍一个小问题），产出一段费曼讲解；
- **每季**：把积累的"算法经验"整理进自己的经验库（呼应 work4ai 的算法经验库体系）。

> 研究不是天才的特权，是**方法的产物**。本系列给你的就是这套方法。
