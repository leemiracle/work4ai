> **理解模型，是为了驾驭模型。**
>
> 本系列的第一目的，是让你在**工作场景**里能**建、调、改、用、优化**模型——并准确把握+复现论文、在领域里与人专业沟通、用模型把工作扩到新场景。为此，你得先理解模型：它是一个可以被**丈量的宇宙**、被**解剖的生物**、被**推导的方程**。理解是地基（Part I-III），**驾驭是目的（Part IV）**。

**灵魂一句话钉死：**

> **理解模型（丈量+解剖+看穿）是为了驾驭模型（建+调+改+用+优化+复现+沟通+拓展）。地基在前 14 章，目的在后 8 章。只会理解不会驾驭，是书呆子；只会驾驭不理解，是调包侠。本系列要你两者皆有。**

## 这份教程为谁而写

- 想在工作中**真正驾驭模型**（建/调/改/用/优化），而不是只会调 API 的人。
- 读论文觉得"看懂了"，但**复现不出来**、讲不清核心思想的人。
- 能用模型解决一个问题，但**不知道怎么把模型能力扩到新场景**的人。
- 在领域对话里**听不懂术语、插不上话**，想具备专业沟通力的人。
- 想知道"模型内部到底怎么运作"，**只为把工作做得更好**（而非纯学术）的人。

## 教学宪法（每章遵守）

每个概念按三层呈现：**直觉（比喻）→ 数学/方法（公式与边界）→ 代码（bash 跑通的实证）/ 落地（决策框架）**。诚实标注哪些是"已证明"、哪些是"经验"。每章配能跑出**反直觉结论**或**可用工具**的实验。结尾固定给出 **📌 下一步** 与 **✍️ 练习**。

**四条研究/工程伦理（贯穿全书）：**
1. **原理优先于 API**：先讲为什么，再讲怎么调库。
2. **诚实优先于漂亮**：SAE 提取的特征有 77% 是因果惰性的——本系列不藏这种坏消息。
3. **怀疑优先于权威**：排行榜会骗人、scaling law 会失效、"涌现"可能是度量假象。
4. **驾驭优先于理解**：Part I-III 的理解，最终要能转化为 Part IV 的工作能力，否则就是空谈。

## 🎭 欺骗动力学视角：Goodhart 之欺骗

> 承接 [`欺骗动力学-社会进步的隐秘引擎.md`](欺骗动力学-社会进步的隐秘引擎.md) §5。

### 三问

1. **讲透模型宇宙 防的是什么欺骗？** → benchmark 刷分——模型在榜单上高分而真实能力没提升。
2. **被什么攻破？** → benchmark 污染 / 过拟合榜单 / 评测 leakage。
3. **沉淀进哪条主链？** → 验证主链——反刷分的评测设计 / 动态 benchmark / 私有测试集。

### 一句话

> 当评测变成目标，它就不再是好评测——Goodhart 定律是模型宇宙的根本欺骗。
