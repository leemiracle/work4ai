# 20 · 新兴技术（AI 硬件 / 机器人 / Web3 / 太空）

> 这些是 AI 应用的"前沿边疆"——技术新、风险高、潜力大。多数还在早期，但代表了 AI 与物理/数字世界融合的方向。本类 4 领域 × 3 场景 = 12 场景。**铁律**：前沿领域诚实标注"早期/实验"，别把演示当生产。

---

## 一、AI 硬件

### 场景 128：AI 原生设备（眼镜 / 别针 / 伴侣硬件）
- **痛点**：手机交互重；想" ambient AI"。
- **输入 → 输出**：语音/视觉 → 即时信息/操作（不掏手机）。
- **模型方案**：**端侧小模型 + 云端大模型混合 + 语音/视觉多模态**。
- **真实方向**：Meta Ray-Ban 智能眼镜、Humane AI Pin、Rabbit R1、Friend；端侧 SLM（见 12 NVIDIA ACE 同源）。
- **陷阱**：续航/发热；隐私（always-on 摄像头）；杀手级应用待验证。

### 场景 129：边缘 AI 推理芯片
- **痛点**：端侧推理需低功耗高性能。
- **模型方案**：**专用 NPU + 量化模型**（INT4/稀疏）。
- **方向**：Apple Neural Engine、高通 Hexagon、NVIDIA Jetson、RKNN。

### 场景 130：AI PC / 端侧 LLM
- **痛点**：隐私/离线/延迟 → 本地跑 LLM。
- **模型方案**：**本地 SLM（7B-13B 量化）+ NPU**。
- **方向**：Phi/Gemma/Qwen 小模型 + llama.cpp；与 20 端侧 AI 压缩同源。

## 二、机器人

### 场景 131：人形 / 通用机器人
- **痛点**：通用机器人难（感知+决策+操作）。
- **输入 → 输出**：视觉 + 指令 → 抓取/移动/操作。
- **模型方案**：**VLA 模型（视觉-语言-动作）+ 端到端/分层控制**。
- **真实方向**：Figure、Tesla Optimus、1X、Apptronik、Unitree；RT-2/π0 类 VLA。
- **陷阱**：长尾物理场景；安全；数据采集成本。

### 场景 132：具身智能 / 仿真训练
- **痛点**：真实数据采集贵且慢。
- **模型方案**：**仿真环境（Isaac Sim/MuJoCo）+ 强化学习 + sim-to-real**。
- **方向**：NVIDIA Isaac/GR00T；Google RT 系列。

### 场景 133：服务机器人（配送 / 清洁 / 巡检）
- **痛点**：重复物理劳动缺人。
- **模型方案**：**导航 + 感知 + 任务规划**。
- **方向**：配送机器人、清洁机器人、电力/安防巡检。

## 三、Web3 / 加密

### 场景 134：链上数据分析 / 安全
- **痛点**：链上数据复杂；欺诈/漏洞难检测。
- **输入 → 输出**：链上交易 → 异常/漏洞/洗钱模式。
- **模型方案**：**图分析 + ML 异常检测 + LLM 报告**。
- **方向**：Chainalysis、TRM Labs；与 18 SecOps 同源。

### 场景 135：智能合约审计
- **痛点**：合约漏洞代价巨大。
- **输入 → 输出**：合约代码 → 漏洞 + 风险标记。
- **模型方案**：**LLM + 形式化验证 + 静态分析**。
- **方向**：与 13 代码安全审计同源，但加形式化（见 `讲透形式化验证`）。

### 场景 136：DeFi / 链上 agent
- **痛点**：DeFi 操作复杂。
- **模型方案**：**agent 自主执行 DeFi 策略**（套利/流动性管理）。
- **陷阱**：资金安全；合约风险；监管。

## 四、太空 / 卫星

### 场景 137：卫星影像分析 / 地球观测
- **痛点**：卫星影像海量；人工解译慢。
- **输入 → 输出**：卫星影像 → 地物分类/变化检测/目标识别。
- **模型方案**：**遥感 CV 模型 + 多模态**。
- **方向**：农业估产、灾害评估、城市规划、军事情报；与 16 精准农业/14 AI for science 交叉。

### 场景 138：轨道 / 碎片管理
- **痛点**：太空碎片威胁；轨道规划复杂。
- **模型方案**：**轨道力学 + 优化 + ML 碰撞预测**。

### 场景 139：任务规划 / 自主航天器
- **痛点**：深空通信延迟 → 需自主。
- **模型方案**：**自主规划 + 故障自愈 agent**。
- **方向**：NASA/JPL 用 AI 规划（火星车）；与 11 Agent 同源。

## 新兴技术 AI 的三条铁律
1. **诚实标注成熟度**——演示 ≠ 生产；前沿别过度承诺。
2. **物理/资金/生命风险最高**（机器人/DeFi/太空）——冗余 + 人审 + 仿真验证。
3. **数据采集是新瓶颈**（机器人/太空）——仿真 + sim-to-real 是关键路径。
