# 05 · 法务 / 合规场景

> 法律是"文档密集 + 高合规要求"领域。AI 不替代律师判断，但能把律师从重复审阅解放。本类 5 个场景。**治理铁律**：凡有法律效力的动作（签字/赔付/申报），human-in-the-loop 不可省。

---

### 场景 21：合同审查 / 风险标记
- **痛点**：合同审阅耗时；非标准条款/风险条款易漏。
- **输入 → 输出**：合同 → 偏离标准/缺条款/风险点清单。
- **模型方案**：**LLM + 标准条款库（RAG）+ playbook 规则**。Agent 串起"读→比对→标记"。
- **真实案例**：行业数据——法律 AI 审查省 **240 小时/年/专业人士**，审查周期降 **50-70%**（AliceLabs/Swiftwater，2026）。**Harvey Workflow Agents** / **Leah AgenticOS** / **GC AI Playbooks** 是代表产品（Swiftwater，2026）。
- **工具栈**：Harvey / Leah / 自建（LLM + CLM 集成）；Word 内 → GC AI。
- **陷阱**：模型漏看隐含风险 → 必须律师复核；条款库过时 → 定期更新。
- **起步 MVP**：拿一份标准合同 + 一份待审合同，让 LLM 列偏离点，对比律师标记。

### 场景 22：法规检索 / 变化监控
- **痛点**：法规多变，合规团队跟不上；影响判断难。
- **输入 → 输出**：监管源 → 与本企业相关的变化 + 影响评估。
- **模型方案**：**NLP 监控监管源 + LLM 相关性判断 + 告警**。
- **真实案例**：AliceLabs 列"监管变化监控"为法律 AI 标准用例（2026）—— 持续监控 EU 官方公报/FCA/ESMA，按行业/辖区告警。
- **工具栈**：监管源订阅 + LLM 过滤 + 告警；自建 → RAG + 定时抓取。
- **陷阱**：误报多 → 调相关性阈值 + 白名单；漏报风险高 → 多源交叉。
- **起步 MVP**：订阅一个监管源 RSS，用 LLM 过滤出与你行业相关的，人工核对。

### 场景 23：合规检查（内部文档/通讯）
- **痛点**：内部材料合规检查覆盖率低；违规风险。
- **输入 → 输出**：文档/通讯 → 潜在违规标记。
- **模型方案**：**LLM 对照政策/法规 rubric 检查**。
- **真实案例**：AliceLabs"政策合规检查"——审内部文档/通讯对照现行政策，事件前预警（2026）。
- **工具栈**：LLM + 合规规则库 + DLP 集成。
- **陷阱**：隐私——监控员工通讯需合法基础；误报骚扰 → 人工复核流程。
- **起步 MVP**：对 20 份对外文档，用 LLM 按合规 checklist 扫，看能否抓已知风险。

### 场景 24：尽职调查自动化
- **痛点**：尽调要聚合大量来源（财报/新闻/制裁/受益所有权），耗时数天。
- **输入 → 输出**：目标公司 → 结构化尽调报告。
- **模型方案**：**Agent 多源聚合 + LLM 综合**（KYC 反洗钱场景核心，`kyc-doc-parse`/`kyc-rules` skill）。
- **真实案例**：AliceLabs——尽调从数天压缩到数小时（2026）；BFSI 的 KYC/AML 是 agentic AI 头号用例（aihive，2026）。
- **工具栈**：Agent（LangGraph）+ 多数据源 API + LLM 报告生成。
- **陷阱**：来源可信度不一 → 标注来源 + 置信度；制裁名单必须实时 → API 实时查。
- **起步 MVP**：对一家公司，用 LLM + 搜索聚合"基本面+风险点"，对比人工尽调模板。

### 场景 25：法律知识管理 / 先例检索
- **痛点**：内部先例/经验散落；新案子查不到历史。
- **输入 → 输出**：案件描述 → 相关先例/内部经验。
- **模型方案**：**RAG（内部案件库）+ LLM 检索**。
- **真实案例**：Swiftwater 列"知识管理"为法律 agentic AI 五大用例之一（2026）。
- **工具栈**：内部案件库 RAG + 权限控制（角色分级）。
- **陷阱**：权限——不同律师能看不同案件 → 严格 RBAC；保密案件别上公网模型。
- **起步 MVP**：把历史案件摘要做 RAG，测"找相似案件"的召回率。

## 🔧 深度实操要点（本类场景）

> 本类场景的实操指引。通用骨架代码/评估清单/排错指南见 [00 深度实操手册总纲](00-深度实操手册总纲.md)。

- **决策速查**：合同审查→RAG+playbook规则(B)；尽调→多源Agent(D)；监控→NLP
- **关键骨架**：骨架 B (RAG) + D (多源聚合)
- **评估要点**：审查周期降幅；漏报率；律师复核一致率
- **头号陷阱**：漏看隐含风险→必须律师复核；条款库过时→定期更新
- **进阶路径**：RAG审查→Agent尽调→全生命周期执行

---

**本类共性建议**：法律 AI **不替代律师**，而是"AI 执行重复任务 + 律师专注判断/策略/风险"（Swiftwater，2026）。**治理前提**：CLM/eBilling/案件系统要先集成、数据要干净、API 要通——否则 agentic AI 不可靠。ISO 42001 认证正在成为法律 AI 上生产的门槛。
