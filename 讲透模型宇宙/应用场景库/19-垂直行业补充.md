# 19 · 垂直行业补充（法律科技 / 保险 / 物流 / 电信 / 航空 / 汽车）

> 这是把前面按"职能"切的场景库，补充按"垂直行业"切的特化场景。每个行业有独特监管/数据/物理约束，AI 落点不同。本类 6 个行业 × 3-4 场景 = 22 场景。**铁律**：垂直行业的 AI 落地，90% 难度在"行业数据 + 监管"，而非模型。

---

## 一、法律科技（LegalTech）/ RegTech

### 场景 110：诉讼策略 / 判例预测
- **痛点**：判例海量；案件结果难预测。
- **输入 → 输出**：案件事实 + 历史判例 → 结果预测 + 相似判例 + 策略建议。
- **模型方案**：**判例 RAG + LLM 论证**。注意：预测非定论，是辅助。
- **真实方向**：Lex Machina（判例分析）、Casetext/CoCounsel（诉讼助手）；Harvey/Leah（合同，见 05）。
- **陷阱**：判例偏见/过时；预测被当定论 → 必须律师解读。

### 场景 111：eDiscovery / 证据审查
- **痛点**：海量电子证据审查耗时。
- **输入 → 输出**：文档集 → 相关性分级 + 特权保护标记 + 主题聚类。
- **模型方案**：**ML 相关性排序 + LLM 特权检测**。
- **陷阱**：漏判关键证据；特权误标 → 人工复核高风险。

### 场景 112：监管科技（RegTech）/ 合规监控
- **痛点**：跨辖区监管变化难跟踪；交易合规难实时。
- **输入 → 输出**：监管源 + 交易 → 相关变化告警 + 合规风险评分。
- **模型方案**：**NLP 监管监控 + 实时交易筛查**。
- **方向**：与 05 法务/15 政务同源；BFSI 监管报送自动化（见 06）。

## 二、保险

### 场景 113：理赔分诊 / 定责自动化
- **痛点**：标准理赔处理慢；复杂案定责难。
- **输入 → 输出**：理赔材料 → 标准案自动处理 / 复杂案定责 + 路由。
- **模型方案**：**分级自主**：标准案模型处理，复杂案 LLM 辅助定责 + 人工。
- **真实案例**：**Sedgwick** Sidekick agent（与 Microsoft）理赔处理效率 +30%；一家险企 80 个 AI 模型跨理赔，复杂案定责快 **23 天**、投诉 **-65%**（见 05）；**Aviva** AI 理赔优化年价值 **$80M**。

### 场景 114：核保 / 风险定价
- **痛点**：核保凭经验；定价未充分利用数据。
- **输入 → 输出**：投保信息 + 历史数据 → 风险评分 + 定价建议。
- **模型方案**：**风险模型 + LLM 解释**（可解释性是监管要求）。
- **陷阱**：歧视/公平性（红线）→ 公平审计；数据偏见。

### 场景 115：承保文档 / 智能审核
- **痛点**：保单/核保文档审查耗时。
- **输入 → 输出**：保单文档 → 条款抽取 + 风险标记 + 合规检查。
- **模型方案**：**LLM + 条款库 RAG**。

## 三、物流 / 运输

### 场景 116：路线 / 运力优化
- **痛点**：路线/承运选择复杂；成本高。
- **输入 → 输出**：订单 + 运力 + 实时条件 → 最优路线/承运方案。
- **模型方案**：**运筹求解器 + AI 启发式 + LLM 解释**。
- **真实案例**：**General Mills** AI 评估 5000+/日出货省 **$20M**（见 10）。

### 场景 117：最后一公里 / 配送调度
- **痛点**：城市配送效率低；客户在场时间窗。
- **输入 → 输出**：订单 + 交通 + 客户偏好 → 配送序列 + 时间窗。
- **模型方案**：**VRP 求解 + ML 预测**（到达时间/客户在场）。
- **真实案例**：**DoorDash** 语音 agent 支持司机（见 03）。

### 场景 118：货运异常 / 损失检测
- **痛点**：货损/丢失/延误难追溯。
- **输入 → 输出**：IoT 传感器 + 物流数据 → 异常告警 + 根因。
- **模型方案**：**IoT 时序异常检测 + LLM 报告**。

## 四、电信

### 场景 119：网络运维 / 故障自愈
- **痛点**：网络故障影响大；排查慢。
- **输入 → 输出**：告警/日志 → 根因 + 自愈动作（受限）。
- **模型方案**：**AIOps agent**（自主诊断→人审→受限修复）。
- **方向**：与 11 DevOps/18 SRE 同源。

### 场景 120：客户流失预测 / 挽留
- **痛点**：用户流失难提前发现。
- **输入 → 输出**：使用行为 → 流失风险 + 挽留建议。
- **模型方案**：**行为模型 + LLM 个性化挽留**。

### 场景 121：客服 / 套餐推荐
- **痛点**：套餐复杂；客户难选。
- **模型方案**：**RAG + 推荐**（见 03 客服）。

## 五、航空

### 场景 122：航班延误预测 / 调度
- **痛点**：延误连锁；调度复杂。
- **输入 → 输出**：天气 + 历史 + 实时 → 延误预测 + 调度建议。
- **模型方案**：**预测模型 + 优化调度**。

### 场景 123：维修 / 航材预测
- **痛点**：航材库存贵；AOG（飞机停场）代价大。
- **输入 → 输出**：传感器 + 历史 → 维修预测 + 航材备货。
- **模型方案**：**预测性维护**（见 10/16）。

### 场景 124：客户服务 / 不正常航班
- **痛点**：不正常航班时客服爆量。
- **模型方案**：**agent 自主改签/通知**（见 03）。

## 六、汽车 / 出行

### 场景 125：自动驾驶 / ADAS
- **痛点**：感知/决策/规划难。
- **输入 → 输出**：传感器 → 感知 + 预测 + 规划 + 控制。
- **模型方案**：**端到端/模块化驾驶模型**（视觉+激光雷达+规划）。
- **真实方向**：Tesla FSD/Waymo/华为/小鹏；端到端是 2024-2026 趋势。
- **陷阱**：长尾安全；监管；伦理。

### 场景 126：智能座舱 / 车载助手
- **痛点**：车内交互僵化。
- **输入 → 输出**：语音 + 车辆状态 → 自然对话 + 控制 + 推荐。
- **模型方案**：**车载 LLM + 语音 + 车控 API**。
- **真实方向**：**NVIDIA ACE** 车载（见 12 游戏 NPC 同源技术）。

### 场景 127：车队管理 / 出行优化
- **痛点**：车队调度/定价。
- **模型方案**：**供需预测 + 动态定价 + 调度**。

---

## 垂直行业 AI 的三条铁律
1. **行业数据 + 监管是 90% 难度**——模型已不是瓶颈，行业数据获取 + 合规才是。
2. **公平性/可解释性是监管红线**（保险核保/信贷/司法）——必须公平审计 + 可解释。
3. **物理/安全约束最高**（航空/汽车）——AI 决策涉人命，必须冗余 + 人审 + 监管认证。
