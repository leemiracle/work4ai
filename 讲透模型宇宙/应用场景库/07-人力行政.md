# 07 · 人力 / 行政场景

> HR 是"高事务量 + 法律/文化敏感"领域——AI 处理重复、人专注策略。本类 5 个场景。

---

### 场景 32：简历筛选 / 人岗匹配
- **痛点**：海量简历，筛选耗时；匹配主观。
- **输入 → 输出**：简历 + 岗位 → 匹配分 + 排序 + 理由。
- **模型方案**：**LLM 结构化简历 + 规则匹配**。注意公平性审计。
- **真实案例**：HR 是 agentic AI 标准用例（aihive，2026）；`resume-screening` 类 skill 的 AI 化。
- **工具栈**：LLM 抽取 + ATS（Greenhouse/Lever）集成；公平性 → bias 审计。
- **陷阱**：**歧视风险**（性别/年龄/院校）→ 必须公平审计 + 去敏感属性；漏判好简历 → 人工抽检。
- **起步 MVP**：50 份简历，LLM 按岗位 JD 评分排序，对比 HR 判断。

### 场景 33：招聘 / 面试辅助
- **痛点**：安排面试繁琐；面试评价不一。
- **输入 → 输出**：岗位/候选人 → 面试题 / 评估 rubric / 面试纪要。
- **模型方案**：**LLM 出题 + 面试 ASR 纪要 + 评估**。
- **真实案例**：HR agent 标准用例含"面试协调"（Algolia，2026）。
- **工具栈**：LLM 出题（基于 JD）；ASR + LLM 纪要/评估。
- **陷阱**：面试题模板化 → 针对简历定制；评估主观 → 用结构化 rubric。
- **起步 MVP**：为一个岗位生成 10 道基于 JD 的面试题 + 评分标准。

### 场景 34：HR helpdesk / 员工自助
- **痛点**：HR 高频问题（福利/请假/政策）占大量时间。
- **输入 → 输出**：员工问题 → 政策答案 / 自助操作。
- **模型方案**：**RAG（HR 政策库）+ Agent（请假/查余额）**。
- **真实案例**：**AMD**（Kore.ai）—— HR 解决时间 **-80%**，50% 查询自助，员工满意度 **+70%**（aihive，2026）。**Rippling** 多 agent（read/RAG/action）百万用户，6 个月上生产（LangChain，2026）。
- **工具栈**：RAG + HRIS 集成；权限分级（员工看自己数据）。
- **陷阱**：薪酬等敏感 → 严格 RBAC；政策变 → 知识库即时更新。
- **起步 MVP**：HR FAQ 做 RAG，员工问"年假剩多少"秒答。

### 场景 35：入职 / 离职自动化
- **痛点**：入职流程跨系统（账号/设备/培训）；易漏。
- **输入 → 输出**：新员工信息 → 开账号/申设备/排培训清单。
- **模型方案**：**Agent 编排跨系统工作流**（IT/HR/设施）。
- **真实案例**：**Rivian** 含"供应商 onboarding"自动化；**Rippling** 设备配置/入职是核心（AWS/LangChain，2026）。
- **工具栈**：Agent + ITSM/HRIS API；checklist 化。
- **陷阱**：跨系统权限错配 → 人工审批关键步；离职工单遗漏 → 模板+校验。
- **起步 MVP**：把入职 checklist 做 Agent，跑 3 个新员工，看漏项。

### 场景 36：培训 / 知识管理
- **痛点**：内部知识散落；培训内容 outdated。
- **输入 → 输出**：知识库 → 个性化学习路径 / 即时问答。
- **模型方案**：**RAG + LLM 个性化学习**。
- **真实案例**：HR agent 标准用例含"知识管理"（Swiftwater，2026）。
- **工具栈**：内部 wiki RAG + LLM；学习路径 → 个性化推荐。
- **陷阱**：知识过时 → 指派 owner 定期更新；权限 → RBAC。
- **起步 MVP**：把部门 wiki 做 RAG，新人问"报销流程"秒答。

## 🔧 深度实操要点（本类场景）

> 本类场景的实操指引。通用骨架代码/评估清单/排错指南见 [00 深度实操手册总纲](00-深度实操手册总纲.md)。

- **决策速查**：HR helpdesk→RAG+RBAC(B)；简历筛选→LLM+公平审计；入职→Agent编排
- **关键骨架**：骨架 B (RAG, 严格RBAC)
- **评估要点**：解决时间(AMD -80%)；自助率；公平性审计(简历)
- **头号陷阱**：薪酬等敏感→严格RBAC+私有部署；简历歧视→公平审计(法律红线)
- **进阶路径**：RAG helpdesk→Agent入职→全生命周期

---

**本类共性建议**：HR 数据**敏感**——薪酬/绩效/健康，务必私有部署 + RBAC + 审计。从"场景 34 HR helpdesk"起步（AMD 验证 ROI 最快）。**公平性审计**在简历筛选（场景 32）是法律红线。
