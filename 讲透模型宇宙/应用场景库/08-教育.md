# 08 · 教育场景

> 教育是"个性化 + 规模化"的矛盾。AI 让"因材施教"成本趋零。本类 3 个场景。**注意**：教育场景要警惕"学生用 AI 代做"的诚信问题，以及未成年保护。

---

### 场景 37：个性化辅导 / 答疑
- **痛点**：1 对 1 辅导贵；学生问题千差万别。
- **输入 → 输出**：学生问题/错题 → 引导式解答（非直接给答案）/ 个性化讲解。
- **模型方案**：**LLM + 苏格拉底式 prompt**（引导而非给答案）+ 学情上下文。
- **真实案例**：Khan Academy Khanmigo 是代表；2026 教育 AI 普遍用"引导式"而非"代答"。
- **工具栈**：LLM + 学情系统；prompt 工程是关键（`讲透Prompt`）。
- **陷阱**：直接给答案（学生不思考）→ 苏格拉底 prompt；学生用 AI 代作业 → 检测/改作业形式。
- **起步 MVP**：写一个"苏格拉底辅导"prompt（只问引导问题，不给答案），试辅导一个知识点。

### 场景 38：作业批改 / 反馈
- **痛点**：批改量大；反馈不够细。
- **输入 → 输出**：学生作业 → 评分 + 具体反馈 + 改进建议。
- **模型方案**：**LLM + rubric**（评分标准 + 逐条评）。
- **真实案例**：教师普遍用 AI 辅助批改；关键是用 rubric 保证一致。
- **工具栈**：LLM + rubric 模板；学科 → 微调。
- **陷阱**：评分不一致 → 严格 rubric + 抽检；漏判创意解 → 人工复核高分项。
- **起步 MVP**：一份作文 rubric，让 LLM 批 20 篇，对比教师评分。

### 场景 39：内容生成 / 课程设计
- **痛点**：备课/出题/做课件耗时。
- **输入 → 输出**：教学目标 → 教案 / 题库 / 课件大纲。
- **模型方案**：**LLM + 课标约束**。
- **真实案例**：教师用 ChatGPT 备课已成常态。
- **工具栈**：LLM + 课标/教材 RAG。
- **陷阱**：题目事实错 → 人工校对；难度不准 → 标注难度梯度。
- **起步 MVP**：为一个知识点生成"3 难度 × 5 题 + 1 教案"。

## 🔧 深度实操要点（本类场景）

> 本类场景的实操指引。通用骨架代码/评估清单/排错指南见 [00 深度实操手册总纲](00-深度实操手册总纲.md)。

- **决策速查**：辅导→苏格拉底prompt(A)；批改→rubric+LLM；内容→LLM+课标
- **关键骨架**：骨架 A (API few-shot, 苏格拉底式prompt)
- **评估要点**：学习效果(对照)；批改一致率；学生参与度
- **头号陷阱**：直接给答案(学生不思考)→苏格拉底prompt；代作业→检测/改形式
- **进阶路径**：苏格拉底辅导→个性化路径→全科学情

---

**本类共性建议**：教育 AI 的核心矛盾是"**辅助 vs 代劳**"。设计时始终站在"增强学习者"而非"替代学习者"（McLeod Health 的 AMD 同理：增强人非替代人）。**未成年保护**：数据合规（COPPA/GDPR-K）+ 内容过滤是红线。
