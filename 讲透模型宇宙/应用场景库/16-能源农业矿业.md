# 16 · 能源 / 农业 / 矿业（重资产）

> 重资产行业的特点：**设备昂贵、停机代价巨大、物理风险高、数据来自传感器/卫星/地质**。AI 在这里的价值是"**预测 + 优化 + 把不可见的地下/设备状态变可见**"。本类 6 个场景，ROI 常以"避免停机/省燃料/增产"计。**铁律**：物理验证不可省（AI 给候选，实验/钻井定夺）。

---

### 场景 91：精准农业 / 智能灌溉
- **痛点**：灌溉凭经验，水/能浪费大；小农户无传感器。
- **输入 → 输出**：传感器+卫星+天气+作物数据 → 灌溉时机/量建议。
- **模型方案**：**传感器 + 卫星混合 + ML 作物模型**；无传感器农户用卫星模型外推。
- **真实案例（2026）**：**SupPlant**（IBM watsonx.data + Confluent）—— 14 国 / 33 作物 / **10 万+农户**，通过 WhatsApp 实时推送灌溉建议；传感器农场作"ground truth"训练卫星模型，外推到无传感器大区域；Growth-Based Irrigation 模型支持自主灌溉（植物状态驱动）。**ANN-GA 太阳能-柴油混合灌溉**（2026 研究）：预测辐照 R²=0.94，柴油运行 **-52%**、燃料 **-53%**、CO2 **-53%**。
- **工具栈**：IoT 传感器 + 卫星影像 + ML 作物模型 + WhatsApp/短信推送。
- **陷阱**：低辐照区效率降 → 补储能/互补能源；小农户数字鸿沟 → 用 WhatsApp/短信而非 App。
- **起步 MVP**：用公开卫星+天气数据为一个作物建灌溉建议模型，对比农户实际。

### 场景 92：地热 / 可再生能源勘探
- **痛点**：勘探风险高、钻井贵；老厂资源枯竭。
- **输入 → 输出**：地质/地球物理数据 → 高潜力钻井位点。
- **模型方案**：**AI 地下建模 + 随机资源建模**，定位被地表迹象掩盖的资源。
- **真实案例（2026）**：**Zanskar**（地热 startup）—— AI 建模发现新墨西哥 Lightning Dock 老厂现有井只戳到储层顶部（2500ft 浅）；模型预测深位钻井，新井 8000ft 进断裂带，**单井复活全厂满负荷 15MW**（美国最高产泵送地热井），收购 8 个月内投产；2026-01 获 $115M C 轮（累计 $180M）。模式可复制到美国西部数十个老地热厂。
- **工具栈**：地质/地球物理数据 + AI 建模 + 随机资源模型 + 定向钻井。
- **陷阱**：地质不确定性 → 概率建模非单点预测；老厂复刻需逐个验证。
- **起步 MVP**：用公开地质数据对一区域做"地热潜力评分"模型。

### 场景 93：天然氢 / 矿产勘探
- **痛点**：新资源（天然氢/关键矿产）勘探耗年；传统方法慢。
- **输入 → 输出**：地质/地球物理大数据 → 勘探靶区 + "lookalike"相似位点。
- **模型方案**：**AI 地质评估平台**（大地球模型集成），处理大地质/地球物理数据集。
- **真实案例（2026）**：**Max Power**（加拿大萨斯喀彻温）—— 发现加拿大首个天然氢系统（Lawson），用 AI 平台 **Maxx Lemi**（Large Earth Model Integration）识别扩区靶位，"把传统选址缩数月-数年"；已识别多个 lookalike 位点；融资近 $50M CAD。
- **工具栈**：地质/地球物理数据集成 + ML 靶区识别 + 相似性模型。
- **陷阱**：地质数据稀疏/异质 → 数据融合难；AI 靶区必须钻井验证。
- **起步 MVP**：用历史勘探数据训练"矿/氢潜力"分类器，回测已知矿点。

### 场景 94：矿业预测性维护（数字孪生）
- **痛点**：关键设备（SAG 磨机）故障致昂贵非计划停机。
- **输入 → 输出**：传感器时序 → 异常检测 + 根因 + 失效预警。
- **模型方案**：**混合架构**：经典 ML（梯度提升分类器做异常筛）+ 深度学习（LSTM 做时序预测）+ **运营数字孪生**（可靠性状态同步非几何）。
- **真实案例（2026）**：**SAG 磨机预测性维护**（MDPI 研究）—— 1 年/99,854 小时记录/154 特征；MICMAC 系统思维降维；GBClassifier+LSTM 混合，提前 **3-48h（均 17h）** 预警，**防 219.5h 停机/年**；F1=81%（10h 窗）；Streamlit 数字孪生四层架构（紧急/计划/预防）。可跨设备/跨行业。
- **工具栈**：IoT 传感器 + ML/DL 混合 + Streamlit/数字孪生仪表盘。
- **陷阱**：极端类别不平衡（故障罕见）→ 混合架构解；传感器噪声 → 因果特征工程（非纯统计）。
- **起步 MVP**：一台关键设备的传感器历史，训异常检测，回测能否提前预警历史故障。

### 场景 95：电网故障定位 / 智能配电网
- **痛点**：矿区/电网故障定位靠人工，耗时长、停机损失大。
- **输入 → 输出**：电网传感器数据 → 故障实时定位。
- **模型方案**：**传感器 + 高级算法实时定位**，直推控制室 + 外勤手机。
- **真实案例（2026）**：**Safegrid IGS**（PT Vale 印尼矿业，30km 配电网）—— 故障定位 **6.4h→1.8h（-71%）**，非生产搜索时间 63%→22%，每次故障省 **Rp4.78B**，6 次省 **Rp28.7B**，**首次故障即回本**，人力 2 技术员→1，CO2 145→40kg/次；已扩到网络其他部分，成印尼标杆。
- **工具栈**：智能电网传感器 + 故障定位算法 + 控制室仪表盘 + 外勤 App。
- **陷阱**：传感器覆盖盲区 → 分期部署；与既有 SCADA 集成。
- **起步 MVP**：一段馈线的历史故障数据，测算法能否定位。

### 场景 96：能源系统优化 / 混合系统调度
- **痛点**：多能源（光/柴/储）调度难；燃料/碳成本高。
- **输入 → 输出**：发电/负荷/天气预测 → 源切换/调度决策。
- **模型方案**：**预测控制**（ANN 预测 + GA/优化调度）。
- **真实案例**：ANN-GA 太阳能-柴油混合（见场景 91）；矿区独立光/风/柴/储系统优化（文献综述）。
- **工具栈**：负荷预测 + 源调度优化 + EMS。
- **陷阱**：低可再生时段效率降 → 储能/互补源；预测误差 → 鲁棒优化。
- **起步 MVP**：一个混合系统的历史负荷+发电，优化调度对比实际燃料消耗。

## 重资产行业 AI 的四条铁律
1. **物理验证不可省**——AI 给钻井/矿/材料候选，实验/钻井定夺（Zanskar/Max Power 都靠实际投产验证）。
2. **数据基础设施是前提**——传感器/卫星/地质数据先打通，AI 才有用（SupPlant 传感器+卫星双轨）。
3. **混合架构胜过单模型**——经典 ML 筛异常 + DL 预测，解极端不平衡（SAG 磨机）。
4. **ROI 以"避免停机/省燃料/增产"计**——重资产停机代价巨大，AI 防停机的 ROI 极高（Safegrid 首次即回本）。

> **重资产行业的心法**：AI 最大价值在"**把不可见的变可见**"（地下资源、设备即将故障、作物缺水），从而**预测 + 优化**。这是 Ch22"规模杠杆"在物理资产上的体现——但每个 AI 预测都要物理闭环验证。
