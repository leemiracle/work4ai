# 04 · 营销 / 内容场景

> 营销是"创意 + 规模化"的矛盾体——既要个性化又要海量。AI 同时解这两端。本类 4 个场景。

---

### 场景 17：内容生成（文案 / 社媒 / SEO）
- **痛点**：多渠道内容需求大；SEO/本地化要量。
- **输入 → 输出**：产品/主题 → 多版本文案 / 社媒帖 / SEO 文。
- **模型方案**：**API + 品牌 few-shot**。多语言 → 同模型直接译写。
- **真实案例**：**Sanofi** Concierge 秒级生成原本要数周+外包代理的内容（AWS，2026）。
- **工具栈**：ChatGPT Enterprise / Jasper / 自建 API + 品牌指南。
- **陷阱**：内容同质化/像 AI → 喂品牌声音样本 + 受众约束；SEO 灌水 → 加事实约束 + 引用。
- **起步 MVP**：给一个产品，让 LLM 出 5 版不同渠道文案，挑可用的。

### 场景 18：个性化推荐 / 营销
- **痛点**：千人一面难；推荐/营销相关性低。
- **输入 → 输出**：用户行为/画像 → 个性化推荐 / 营销文案。
- **模型方案**：**LLM 个性化文案 + 推荐系统召回**（混合）。LLM 不替代推荐算法，而是个性化"表达"。
- **真实案例**：**Wayfair** 属性补全 → A/B 测试 impressions/clicks/page rank 显著升（OpenAI，2026）。**Breuninger** VTO 个性化（Google，2026）。
- **工具栈**：推荐召回（双塔/协同）+ LLM 重写文案；CDP + LLM。
- **陷阱**：LLM 编用户没的行为 → 只用真实行为数据；冷启动 → 用 LLM 从有限信息推断。
- **起步 MVP**：对 10 个用户，用 LLM 基于其历史写个性化邮件主题，对比通用版打开率。

### 场景 19：用户画像 / 情感分析
- **痛点**：评论/反馈海量，情绪/主题难量化。
- **输入 → 输出**：评论文本 → 情感/主题/意图结构化。
- **模型方案**：**LLM 抽取**；量大 → **微调小模型**降本。
- **真实案例**：**Trustpilot** fine-tune Gemma-2-9b，百万评论/日做 NER/情感/分类，性能近 Gemini 教师模型，固定基础设施替代 per-token 计费（Google Cloud，2026）。**Kogan** 用真实通话数据持续调优（Salesforce，2026）。
- **工具栈**：LLM 抽取 + vLLM 服务；蒸馏 → 小模型（`讲透端侧AI压缩`）。
- **陷阱**：讽刺/反讽误判 → 领域微调；长尾主题 → 分层分类。
- **起步 MVP**：用 LLM 给 200 条评论打情感+主题标签，看分布是否合理。

### 场景 20：多模态内容（图 / 视频生成 / 虚拟试穿）
- **痛点**：商品图拍摄贵；个性化视觉体验难。
- **输入 → 输出**：商品图 / 用户自拍 → 试穿图 / 营销视频 / 多角度图。
- **模型方案**：**生成模型 API**（VTO / 图生视频 / 文生图）。
- **真实案例**：**Breuninger**（Google VTO API）—— "be your own model"，用户自拍试穿，6 周 A/B 测试转化率与贡献毛利显著升，3 个月上线（Google Cloud，2026）。
- **工具栈**：Google VTO / Imagen / Veo；商品图 → 批量生成多角度。
- **陷阱**：生成图质量不稳 → 预处理 + 后筛选；品牌一致性 → 加风格约束。
- **起步 MVP**：用 VTO/Imagen 给 10 个商品生成多角度图，看是否可直接用于详情页。

## 🔧 深度实操要点（本类场景）

> 本类场景的实操指引。通用骨架代码/评估清单/排错指南见 [00 深度实操手册总纲](00-深度实操手册总纲.md)。

- **决策速查**：文案→few-shot API(A)；个性化→LLM+推荐；图/视频→生成模型API
- **关键骨架**：骨架 A (API few-shot) + 生成模型
- **评估要点**：A/B测试(打开率/转化率)；品牌一致性；量产成本
- **头号陷阱**：内容同质化→品牌声音样本+受众约束；SEO灌水→事实约束
- **进阶路径**：API文案→个性化→多模态→A/B驱动优化

---

**本类共性建议**：营销场景要**A/B 测试驱动**（Breuninger/Wayfair 都靠 A/B 验证）。AI 内容必须**量化效果**（打开率/转化率），不能只看"写得像不像人"。多模态（场景 20）是 2026 新增长点，ROI 需 A/B 验证。
