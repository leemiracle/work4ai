# 讲透计算机辅助设计 · 设计对象的数字表示

> **这支负责什么**：把"设计师脑子里的形状"变成机器可存储、可修改、可制造的
> 精确数字对象——几何造型是核心。GB/T 52060 三级"计算机辅助设计"（CAD）。

## 诞生

Sketchpad（1963）首开交互绘图；MIT 的 Coons 曲面（1964）与
Bézier（法国雷诺，1960s，为汽车车身造曲线）奠基自由曲线曲面；
NURBS（1980s 统一表示）与 B-rep/CSG 成为工业标准内核；
1990s 参数化设计（Pro/E）让"改一个尺寸、全图联动"成为现实。

## 核心问题

| 问题 | 状态 |
|------|------|
| 自由曲线曲面的统一表示 | ✅ NURBS：一个公式统一直线/圆弧/自由曲面 |
| 实体的无歧义表示 | ✅ B-rep/CSG 理论完备（点集拓扑保证） |
| 参数化与约束求解 | 🔄 约束求解器仍在进化（几何约束=图论+代数） |
| 生成式设计（AI 提案） | 🔄 前线（拓扑优化+LLM 前端） |

## ✨ 这支最美的一个事实

NURBS 的"有理"两个字换来一个奇迹：**精确表示圆**——
普通 Bézier 曲线永远只能逼近圆（误差不为零），加上权重的有理化后
圆弧被一个二次 NURBS 段**分毫不差**地表示。设计世界从此一种几何语言。

## 假设与依赖

几何=边界表示（B-rep 假设：物体由边界面定义）；
参数化依赖约束系统的良定性（过约束/欠约束检测）。
