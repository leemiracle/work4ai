# 讲透中文信息处理 · 汉字进机器的六十年

> **这支负责什么**：让中文被计算机编码、切分、理解与生成——从"汉字能否进计算机"
> 到"中文大模型的母语能力"。GB/T 52060 三级"中国语言文字信息处理"。

## 诞生

1950s 中俄机器翻译立项；1970s-80s 汉字信息处理工程——**王选的激光照排**（1980s，
"汉字印刷术第二次革命"，2001 国家最高科技奖）解决了"汉字排版"；
GB2312（1980）→GBK（1995）→GB18030/Unicode 统一了"汉字编码"；
1990s 统计分词与 NLP 兴起，2020s 进入 LLM 时代。

## 核心问题

| 问题 | 状态 |
|------|------|
| 汉字编码统一 | ✅ Unicode 全收（9 万+ CJK 统一表意文字） |
| 中文分词（无空格语言） | ✅ 实用级（词典+统计→LLM 端到端） |
| 分词歧义消解（"南京市长江大桥"） | 🔄 开放（语言固有歧义不可穷举） |
| 中文 LLM 与英文的能力差距 | 🔄 前线（语料比例 vs 语言特性之争） |

## ✨ 这支最美的一个事实

GB2312 的 6763 字覆盖当时语料的 99.99%——**开放的语言被一个近封闭的字集近似**，
这是中文信息处理独有的组合数学奇观（英文词汇表做不到）。
