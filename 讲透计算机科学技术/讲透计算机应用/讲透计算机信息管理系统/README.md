# 讲透计算机信息管理系统 · 事实的存取与一致性

> **这支负责什么**：把组织的运营事实变成**永不撒谎**的数字账本——
> 建模、存取、并发、恢复。GB/T 52060 三级"计算机信息管理系统"（MIS）。

## 诞生

1960s IBM 提出 MIS 概念（管理者的信息供给系统）；
**Codd 1970** 的关系模型论文（"数据独立性"宣言，图灵奖 1981）把数据从
导航式存取中解放；Chen 1976 的 ER 模型给业务世界与关系表之间修了桥；
Gray 1980s 的事务理论（图灵奖 1998）立下 ACID 宪法。

## 核心问题

| 问题 | 状态 |
|------|------|
| 数据的逻辑独立性 | ✅ 关系模型（存取路径无关） |
| 业务世界的建模语言 | ✅ ER 模型→关系范式（1NF→BCNF 规范化理论） |
| 并发与故障下的一致性 | ✅ ACID 事务理论（可串行化/两阶段锁/WAL） |
| 一致性 vs 可用性 | ✅ 定界（CAP——分布式下的不可能三角） |
| 海量分析负载 | 🔄 前线（列存/HTAP：OLTP 与 OLAP 的再统一） |

## ✨ 这支最美的一个事实

关系代数七运算（并/差/积/选择/投影/交/除）与 SQL 核心、
受限一阶逻辑**三方等价**——"查询"被纯代数化后，
查询优化器才能像编译器一样做等价变换（选择下推、投影合并）。
一篇数据库论文里的代数定理，换来两个图灵奖。

## 假设与依赖

事务可串行化（买到 ACID，付出吞吐代价）；关系封闭性（一切皆表——
半结构化数据曾长期不服，JSON 支持是妥协产物）；范式化的代价是 join。

## 教材锚

Silberschatz《数据库系统概念》/ Codd 1970 原论文 / 《Designing Data-Intensive Applications》
