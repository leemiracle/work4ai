# 讲透计算机过程控制 · 计算机进物理回路

> **这支负责什么**：让计算机直接驾驭物理过程——温度、压力、流量、位置，
> 毫秒级闭环。GB/T 52060 三级"计算机过程控制"。

## 诞生

Minorsky 1922 为美国海军设计船舶自动驾驶，提炼出 **PID** 三项结构；
1959 工业计算机控制元年（Texaco 炼油）；1962 DDC（直接数字控制）取代气动仪表；
1970s PLC（Modicon 084，回应通用汽车的继电器替换需求）让控制逻辑可编程；
SCADA 架起"传感器-控制器-执行器"的工业神经网络。

## 核心问题

| 问题 | 状态 |
|------|------|
| 无模型控制 | ✅ PID：三个参数控制全球约 90% 工业回路 |
| 整定的系统化 | ✅→🔄 Ziegler-Nichols 到自整定（仍在实用化） |
| 离散化与采样控制 | ✅ 采样控制理论（香农采样定理的工程化） |
| 网络化控制的时延 | 🔄 前线（工业互联网/5G 进回路） |
| 安全性（故障安全设计） | 🔄 永恒（IEC 61508 功能安全标准持续演进） |

## ✨ 这支最美的一个事实

PID **不需要知道系统是什么**就能控制它——P 补现在（误差）、I 补过去（累积）、
D 补未来（趋势），反馈结构本身提供了鲁棒性。一个不识模型的控制器统治工业一百年，
这是"结构胜过知识"的工程宣言。

## 假设与依赖

反馈线性化假设（小误差区内近似有效）；采样定理（连续过程→离散回路的条件）；
执行器物理极限（控制量饱和是真实世界的摩擦力）。
