# 讲透计算机决策支持系统 · 从数据到选择

> **这支负责什么**：MIS 存事实，本支**算选择**——模型库、OLAP、专家系统，
> 直到 LLM 时代的 RAG 与 Agent。GB/T 52060 三级"计算机决策支持系统"（DSS）。

## 诞生

Gorry & Scott Morton 1971 造词 DSS（对 Simon **有限理性**的工程回应：
人脑算不动，机器来"支持"而非替代）；1980s 模型库+数据库+对话三部件架构成型；
Codd 1993 提出 OLAP（多维分析）；专家系统（MYCIN 1970s）走完
符号主义第一轮；2020s RAG/Agent 让自然语言直达决策。

## 核心问题

| 问题 | 状态 |
|------|------|
| 决策的分解（结构化/半结构化/非结构化） | ✅ Simon 谱系——DSS 的地盘是中间带 |
| 多维分析的理论化 | ✅ OLAP 代数（cube/rollup/drill-down） |
| 知识进机器（专家系统路线） | ✅→🔄 规则库方法论成立；知识获取瓶颈被 LLM 缓解、未消除 |
| 可解释的建议 | 🔄 前线（LLM 进决策回路后，解释与审计问题重临） |
| 决策权与责任的归属 | ❌ 不可机械化（04 章裂缝：最后一环必须是人） |

## ✨ 这支最美的一个事实

"支持"二字是 1971 年那代人最深的洞察：Simon 已证明人类理性的带宽有限
（有限理性，1978 诺奖），所以 DSS 的宪法从一开始就是**放大判断、不替代判断**——
五十年后 LLM 进决策回路，这条宪法仍是唯一的护栏。

## 假设与依赖

有限理性假设（人脑是瓶颈→机器补位）；模型库假设（世界可用模型族近似）；
依赖 MIS 的事实供给（垃圾进垃圾出的古老诅咒）。
