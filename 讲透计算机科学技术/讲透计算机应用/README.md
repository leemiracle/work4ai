# 讲透计算机应用 · 计算机的非数值应用面

> **本质一句话**：前五个家族（基础/人工智能/系统结构/软件/工程）回答"计算机是什么"，
> 本家族回答"**计算机替人做什么**"——合成图像、理解图像、处理文字、复现世界、
> 驾驭流程、支撑决策。它是 GB/T 52060 的八块应用领地，也是离产业最近的家族。
>
> GB/T 13745：52060（二级学科，8 个三级）。宇宙：[讲透计算机科学技术](../README.md)·六家族之一。

## 家族树（八支）

```
讲透计算机应用/
├── 讲透中文信息处理/     汉字编码·分词·中文 NLP（语言应用）
├── 讲透计算机仿真/       离散事件·连续系统·蒙特卡洛·数字孪生
├── 讲透计算机图形学/     建模·渲染·动画（模型→图像）
├── 讲透计算机图象处理/   滤波·增强·分割·重建（图像→模型）
├── 讲透计算机辅助设计/   几何造型·参数化·NURBS/B-rep
├── 讲透计算机过程控制/   PID·DDC·SCADA（计算机进物理回路）
├── 讲透计算机信息管理系统/ ER·关系·OLTP·ACID
└── 讲透计算机决策支持系统/ 模型库·OLAP·专家系统→LLM Agent
```

两条大动脉贯穿八支：**图形-视觉管线**（图形学与图象处理互为正逆问题，CAD 供几何，
仿真供动态）与**信息-决策管线**（MIS 存事实、DSS 算选择、中文 NLP 接语言、
过程控制接物理）。详见 [00-体系结构](00-体系结构.md)。
