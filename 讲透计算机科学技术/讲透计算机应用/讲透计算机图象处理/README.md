# 讲透计算机图象处理 · 从像素反推世界

> **这支负责什么**：给定图像，**分析**出结构与内容——滤波、增强、分割、重建。
> 与图形学互为逆问题（图像→模型）。GB/T 52060 三级"计算机图象处理"。

## 诞生

1964 年 NASA 处理"旅行者"探月图像（几何畸变校正）是第一课；
CT 重建（Cormack/Hounsfield，**1979 诺贝尔生理学或医学奖**）把本支推上
"救人无数"的巅峰——Radon 1917 的纯数学在 60 年后救人性命；
2010s 深度学习重写分割/识别范式。

## 核心问题

| 问题 | 状态 |
|------|------|
| 从投影重建三维（CT/MRI） | ✅ Radon 变换理论与工程双成熟 |
| 去噪/增强的经典理论 | ✅ 频域滤波完备（采样定理地基） |
| 分割与识别 | ✅ 深度学习实用级——但可解释性倒退 |
| 图像语义的形式化 | ❌ 未解（04 章裂缝正主："看懂"无不含循环的定义） |

## ✨ 这支最美的一个事实

CT 重建：一束 X 光只知道"沿途物质的总密度"（一维投影），
但把无穷多个角度的"总和"用 Radon 逆变换一卷，
三维人体结构被**精确**还原——从"和"反推"每个"，纯数学的魔术。

## 假设与依赖

像素=平面投影的强度采样（丢掉了深度与语义）；
线性系统理论（卷积/频域）是经典半壁的地基，深度学习打破了它又继承了它的直觉。
