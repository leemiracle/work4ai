# 02 · 语言特征：接口、表示与工业标准当语法

> **本章回答五问之三（本家族：讲透计算机应用）。**
> 本家族的母语不是定理与证明，而是**表示**（怎么把世界编码成数据）与
> **接口**（模块之间怎么对话）。规范化程度不在公理层而在**工业标准层**——
> 这是它与其他数理家族最大的语言差异。

---

## 一、表达力：每种表示都在画地为牢

| 支 | 核心表示 | 能说什么 | 说不了什么 |
|---|---------|---------|-----------|
| 图形学 | 几何+材质+光（三角形网格） | 一切可光栅化的表面 | 头发/雾/次表面散射需 hacks（表示不完备） |
| 图象处理 | 像素数组/频域 | 平面投影上的强度 | 三维与语义（"理解"超表示范围） |
| 中文信息处理 | 字→词→句→篇章层级 | 结构可枚举的语言现象 | 歧义与语用（"意思意思"） |
| CAD | B-rep/CSG/NURBS | 边界与体素的确切几何 | 意图（为何这样设计） |
| MIS | 关系表（Codd） | 可串行化的事务事实 | 半结构化与"为什么查" |
| 仿真 | 状态+转移规则/微分方程 | 可复现的动力学 | 未建模的世界（模型之外皆黑暗） |

**表达力三段论**：选表示 = 选世界观的切面。表示之内的一切皆可计算，
表示之外的一切皆不存在——这不是 bug，是本家族的第一原理。

## 二、逻辑性质：工程规范而非数学公理

数理家族问"完备/一致/可判定"；本家族的语言裁决者是**工业标准**：

| 标准 | 裁决域 | 类比公理处 |
|------|--------|-----------|
| IEEE 754 / OpenGL/Vulkan | 数值与渲染语义 | 跨厂商行为一致=工程的"一致性" |
| Unicode（GB18030 强制） | 汉字编码 | 字集封闭性=中文信息处理的地基公理 |
| SQL 标准 / ACID | 事务语义 | 隔离级别=一致性的分级弱化 |
| IEC 61131-3（PLC 语言） | 过程控制 | 五种标准语言=控制的"五条公理" |

**反直觉发现**：本家族最"数学"的语言藏在最工程的地方——关系代数
（并/差/投影/选择/积/交/除）在表达力上等价于 SQL 的核心，
而 Codd 用它证明了"关系模型可以不做导航式存取"——
一个数据库论文里的代数等价定理，换来了两个图灵奖（Codd 1981、Gray 1998）。

## 三、规范化：三级台阶

1. **事实标准**（de facto）：Photoshop 格式、Figma 协议——市场裁决
2. **工业标准**（de jure）：OpenGL/Unicode/SQL——委员会裁决
3. **数学内核**：渲染方程、Radon 变换、关系代数——证明裁决

八支所处台阶不同：图形学已走完 1→2→3 全程；数字孪生还在 1→2 爬坡
（每个厂商一个"标准"）；MIS 早已停在 2/3 的稳态。

## ✨ 美之时刻（本家族 ×1）

> **关系代数七运算**。为什么美：极简的极致——七种集合运算拼出一切查询，
> 且与一阶逻辑（受限版）、SQL 三方等价；"存取路径无关性"让它像几何之于坐标，
> 把本质从实现里剥出来。怎么亲历：把一条复杂 SQL 手工展开成代数表达式，
> 再用等价律（选择下推/投影合并）优化它——你在重演数据库查询优化器。

## Python 层

[`experiments/sobel_edge_demo.py`](experiments/sobel_edge_demo.py) 演示本家族
最常见的"语法转换"：同一个边缘事实，在**空域语言**（卷积核）与
**频域语言**（高频分量）里是同一个对象的两种说法——表示可换，信息守恒。

## 不足层

工业标准当语法的代价：**标准滞后于研究十年是常态**（3DGS 2023 落地标准层预计 2030s）；
且标准由巨头博弈产生，语言里埋着商业权力——这不是数学的领地，讲透必须诚实标注。

## ✍️ 练习

1. 证明（或说服自己）：关系代数的选择 σ 与投影 π 满足交换律 σ_p(π_A(R)) = π_A(σ_p(R))（当 p 只涉及 A 中属性）。查询优化器的哪条规则在用它？
2. 汉字"圕"（túshūguǎn，图书馆的合字）在 Unicode 中存在。讨论：编码字集的封闭性原则与生僻字/新造字的张力。
3. 为什么说"表示之外皆不存在"？用一个自动驾驶感知失败案例说明。
