# 讲透计算机图形学 · 模型到图像的合成艺术

> **这支负责什么**：给定场景描述（几何/材质/光/相机），**合成**图像——
> 与图象处理互为逆问题。GB/T 52060 三级"计算机图形学"。

## 诞生

Sutherland 的 Sketchpad（1963，交互图形开山，图灵奖 1988）→
Utah 四大件年代（1960s-70s：Gouraud/Phong 明暗、隐藏面）→
渲染方程（Kajiya 1986）统一一切 → 皮克斯与 GPU 时代（硬件光栅化）→
可微渲染与神经表示（NeRF 2020 / 3DGS 2023，SIGGRAPH 换血）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 真实感成像的统一理论 | ✅ 渲染方程（一个积分=一切光照现象） |
| 实时渲染该方程 | 🔄 永恒（30fps 预算 vs 全局光照；3DGS 首次实时新视角合成） |
| 几何表示的通用语言 | 🔄 NURBS/网格/点云/高斯——表示之争未完 |
| 可微渲染（梯度穿过成像） | ✅ 近年成熟——图形-视觉边界消失的技术原因 |

## ✨ 这支最美的一个事实

渲染方程 $L_o = L_e + \int f_r L_i \cos\theta\, d\omega$：阴影、镜面、焦散、
全局光照全是这一个积分方程的特例——图形学的"麦克斯韦方程组"，
三十年硬件史就是它的求解器进化史。

## 假设与依赖

像素离散网格（00 章）、几何逼近（三角形网格表示不完备头发/散射）；
实时渲染额外站在"人眼 30fps、每帧 16ms"的生理预算上。
