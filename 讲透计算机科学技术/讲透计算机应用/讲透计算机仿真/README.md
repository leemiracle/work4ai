# 讲透计算机仿真 · 用模型复现世界

> **这支负责什么**：不解析求解、不实物实验——在计算机里**运行**一个世界模型，
> 从蒙特卡洛赌桌到数字孪生工厂。GB/T 52060 三级"计算机仿真"。

## 诞生

Ulam 与 von Neumann 在曼哈顿计划（1946）发明蒙特卡洛方法——中子扩散算不动，
就掷骰子问统计；1960s Simula 语言（Dahl/Nygaard，面向对象的意外发明地）
奠基离散事件仿真；2010s 数字孪生把仿真推向实时双向。

## 核心问题

| 问题 | 状态 |
|------|------|
| 随机数质量（伪随机的"伪"何时致命） | 🔄 永恒（Mersenne Twister 之后仍在演化） |
| 离散事件系统的正确性 | ✅ 事件调度理论成熟 |
| 仿真的统计推断（置信区间） | ✅ 重复/删除法/批均值法 |
| 模型可信性（V&V：验证与确认） | 🔄 开放——确认本质是归纳问题 |
| 数字孪生的实时标定 | 🔄 前线 |

## ✨ 这支最美的一个事实

蒙特卡洛估计 π：往单位正方形撒 N 个随机点，落进四分之一圆的比例 → π/4——
**用一个随机实验回答一个确定性常数问题**，且收敛速度 O(1/√N) **与维度无关**。

## 假设与依赖

模型≈现实（00 章假设表：买到可实验，付出模型误差随用途放大）；
随机模型还依赖"伪随机数≈真随机"这一永远只能近似的前提。
