## 诞生

📖 1980s MIPS/MFLOPS 的滥用→SPEC 基准组织成立(1988);
2006「最快的超级计算机」Linpack 之争 vs Bennett 的「HPC 挑战」;
2010s 手机/云尾延迟(p99)成为商业指标;2020s 大模型训练
MLPerf 把基准测试变成采购语言。

## 核心问题

已解决:
- **均值陷阱的命名与治理**:算术/几何/调和平均各自合法的量纲场景
  (H&P 教科书的经典节);几何平均=多基准归一的诚实选择
- **roofline 模型**(2008 Williams-Waterman-Patterson):
  一页纸定位计算墙/访存墙——性能归因的通用语言
- **Little 定律**(1961):L=λW,排队论的万有引力(排队系统的恒等式)

未解决:
- 多租户干扰下的可复现测量(云上跑分≠用户到手)
- LLM 推理服务的基准语言(tokens/s 的延迟-吞吐曲线没有 SPEC 式共识)

## ✨ 这支最美的一个事实

**Little 定律 L=λW**:系统里的平均数=到达率×停留时间——
不需要任何分布假设、对任何稳定系统成立。
一条恒等式同时解释了排队长度、并发度、反向压力设计,
是性能工程里最接近「物理定律」的存在。
