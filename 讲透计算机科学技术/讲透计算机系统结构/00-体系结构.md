# 00 · 体系结构:计算机系统结构的全图

> **本章回答五问之一:整个体系结构长什么样。**
> 本质一句话:计算机系统结构 = **在「程序员看到的机器」与「晶体管组成的物理世界」
> 之间,搭一座可以谈判的桥**——指令集是合同,存储层级是舞台,
> 「快」是被局部性和并行度定价的商品。

---

## 开篇:一份 1945 年的报告,一次 1964 年的豪赌,一场 2018 年的加冕

📖 **场景一(1945,洛斯阿拉莫斯边缘)**。冯·诺依曼给 ENIAC 小组写了份报告:
把**程序和数据放进同一个存储器**。今天看是常识,当时是革命——在此之前的机器
「编程」要靠重新接线。这份「EDVAC 报告」定义了此后八十年几乎所有计算机的骨架:
存储器+控制器+运算器+输入输出。「冯诺依曼架构」这个名字,把本家族的第一块
基石钉在了 1945 年。

📖 **场景二(1964,IBM)**。小沃森押上公司年收入的 5 倍,造 System/360——
不是为了快,是为了**让同一个程序跑在一整族不同性能的机器上**。「体系结构
(architecture)」一词由此诞生:Amdahl、Blaauw、Brooks 在 1964 年的论文里
第一次把它定义为「程序员可见的机器属性」——**抽象层级从此成了产品**。
同篇论文还顺手给出了 Amdahl 定律:串行部分封死并行加速的上限。

📖 **场景三(2018,洛杉矶)**。Hennessy 与 Patterson 领图灵奖,演讲题目是
**「计算机体系结构的新黄金时代」**:Dennard 缩放终结+摩尔定律减速=通用 CPU
免费提速的时代结束;出路是**领域专用架构(DSA)+开放指令集+敏捷开发**。
此后五年,TPU/NPU/CXL/RISC-V 逐一兑现——本家族从「通用引擎」转入
「专用协奏」的新纪元。01 章讲这五年的战况。

## 一、层级塔:本家族的国土全在这座塔的中段

```
应用      ← 讲透计算机应用(52060)
算法/语言 ← 讲透计算机软件(52040):编译器把高级语言翻成 ISA
────────────────────────────────────────
ISA(合同) ← ★系统结构的地盘开始:程序员可见的机器
微架构    ← ★流水线/乱序/缓存:同一 ISA 的不同实现(360 家族的本义)
RTL/逻辑  ← 讲透计算机工程(52050)的边境
器件/物理 ← 物理学宇宙
────────────────────────────────────────
```

**为什么是这座塔**:每一层只对上一层讲一种语言、把下层全部藏掉。
系统结构的独门问题是:**藏掉的东西会从性能侧漏出来**——你写的是 C,
但缓存行/预取器/分支预测器全在暗中定价。本家族的戏剧性大多来自
「抽象漏了」:02 章专讲这种语言的暧昧。

## 二、存储层级:一切的中心舞台

```
寄存器(~1 cycle) → L1(~4) → L2(~12) → L3(~40) → DRAM(~200) → SSD(μs) → 网络(远端)
 容量:  KB            KB       MB        MB        GB        TB        ∞
```

- **局部性原理**(时间+空间)是整个层级的合法性证明:程序访问模式足够有偏,
  才配得上金字塔。它不是定理,是**经验事实+工程信仰**——反例(Splay 树的
  伪共享、随机哈希访问)会让层级失效。
- 层级每加一层,「快」的价格就换一种货币:寄存器稀缺→指令调度;缓存→
  局部性重构;DRAM→算术强度(roofline);网络→通信/计算比。
- ✨ **美之时刻(00-1)**:金字塔本身——**用 30 年的工艺史固化成 7 层金字塔,
  让程序以为自己有一个又大又快的统一内存**。一层都不会对上层说真话,
  但合谋结果近乎魔法。亲历方式:跑本家族实验
  [`experiments/roofline_cache.py`](experiments/roofline_cache.py),
  看同一个数组求和,按行/按列遍历差出 10-30 倍——金字塔在向你收费。

## 四、相互喂养图

```
计算机基础(可计算性) ──「能算」──▶ 本家族 ──「算多快」──▶ 软件层(OS/编译按 ISA 与缓存写)

```

## 五、这章给了你什么新眼睛(认知升维)

1. **结构眼**:看系统先看层级——每层对上撒了什么谎,谎言从哪里漏性能。
2. **合同眼**:ISA 是合同不是机器——「兼容」是商业与工程的双重发明(360 的本义)。
3. **货币眼**:「快」在不同层级用不同货币计价(周期→局部性→算术强度→通信比),
   优化前先问自己在哪一层花钱。
