# 讲透自然语言处理 · 语言这台机器的接口

> 这支负责：**人类最大知识载体（语言）的机器处理**——从分词到对话到推理。
> 家族：[讲透人工智能](../README.md)（GB/T 52020·20）。

## 诞生

1950 图灵测试就用对话（语言=智能的界面）；1954 Georgetown-IBM 俄英机器翻译演示
启动资助；1970s 统计革命（Jelinek名言："每解雇一个语言学家，翻译质量涨一分"）；
2017 Transformer 由机器翻译任务催生——本支是当代 AI 引擎的出生地。

## 核心问题

| 问题 | 状态 |
|------|------|
| 语法分析（句法树自动构造） | ✅ 基本解决（解析器工业级） |
| 指代消解/篇章理解 | 🔄 部分（大模型大幅提升但无保证） |
| 开放域常识推理 | ❌ 未解 |
| 机器译文的"信达雅" | 🔄 部分（"信"近达成，"雅"主观） |

**这支最美的一个事实**：语言模型只需要"预测下一个词"这一条训练信号，
就把语法、语义、事实知识、一点推理全部装进权重——最平淡的任务，
最深的涌现（正主[讲透模型](../../../讲透模型/)）。
