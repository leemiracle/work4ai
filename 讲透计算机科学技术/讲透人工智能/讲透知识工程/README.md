# 讲透知识工程 · 符号派大本营

> 这支负责：**知识的表示、获取与使用**——专家系统、本体、知识图谱；
> 第一代引擎的主车间，在大模型时代以"外挂记忆与工具"身份重返牌桌。
> 家族：[讲透人工智能](../README.md)（GB/T 52020·70）。方法论正主：[讲透符号主义](../../../讲透符号主义/)。

## 诞生

1965 DENDRAL（第一个专家系统，从质谱推分子结构）；1977 Feigenbaum 造出
"Knowledge Engineering"一词；1980s 专家系统产业化（XCON 每年为 DEC 省数千万美元）
与知识获取瓶颈暴露（"瓶颈在知识不在推理"）；2012 Google 知识图谱把本体装进搜索。

## 核心问题

| 问题 | 状态 |
|------|------|
| 知识表示的通用形式（框架/逻辑/图） | 🔄 部分（各有疆域，无统一） |
| 自动知识获取 | 🔄 部分（信息抽取工业可用；本体构建仍人工重） |
| 大规模一致性推理 | ✅ 部分解决（描述逻辑可判定片段，OWL-DL） |
| 常识知识库（Cyc 之路） | ❌ 未解（40 年积累仍不够用） |

**这支最美的一个事实**：描述逻辑的可判定性换算——表达力每加一分，
可判定复杂度可能指数跳（NEXPTIME）；OWL-DL 是精心选的"恰好还能推理"的
切片——知识工程的核心智慧不是"能表达多少"而是"敢表达多少"。

## 假设与依赖

知识可显式陈述且可形式化（符号方言宪法）；知识源（专家/文本）可得。
