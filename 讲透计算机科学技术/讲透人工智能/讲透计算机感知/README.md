# 讲透计算机感知 · 视听触觉的机器化

> 这支负责：**把感官给机器**——视觉、听觉、触觉的信号到语义的转换；
> AI 三大学派竞争的第一试验场（"让机器看懂猫"曾是三代引擎共同的圣杯）。
> 家族：[讲透人工智能](../README.md)（GB/T 52020·50）。

## 诞生

1966 MIT Summer Vision Project（一个夏天让计算机"描述场景"——又一个乐观
错六十年）；1982 Marr《Vision》立视觉计算理论（学科宪法书）；
2012 AlexNet（ImageNet 错误率 26%→15%）终结特征工程；
2021 CLIP 开视觉-语言对齐时代。

## 核心问题

| 问题 | 状态 |
|------|------|
| 物体识别（分类/检测） | ✅ 基本解决（工业级；正主[讲透模型](../../../讲透模型/)） |
| 分割 | ✅ 基本解决（SAM 2023 达到"可分割一切"） |
| 三维重建与 SLAM | ✅ 基本解决（NeRF/3DGS，2020-23 革命） |
| 视觉常识（"她正要放下杯子"） | ❌ 未解 |
| 触觉的机器化 | 🔄 部分（传感器滞后于算法） |

**这支最美的一个事实**：卷积权重与猫视觉皮层（Hubel-Wiesel 1959 的
方向感受野）同构——Neocognitron（1980 福岛邦彦）照着大脑皮层画网络，
三十多年后大脑的结构直觉被 ImageNet 证明是对的；神经科学给工程递过一次图纸。

## 假设与依赖

感官信号有层次组合结构（边缘→纹理→部件→物体）；数据充足。
依赖：[调和分析](../../../讲透数学/讲透分析/讲透调和分析/)（卷积/小波=信号数学）、
[计算机神经网络](../讲透计算机神经网络/)。
