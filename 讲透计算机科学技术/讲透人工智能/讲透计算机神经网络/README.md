# 讲透计算机神经网络 · 连接主义引擎

> 这支负责：**AI 的方法论心脏**——神经网络的理论与结构；
> 当代 AI 的全部产业成果都建立在这台引擎上。GB/T 三级里的"发动机车间"。
> 家族：[讲透人工智能](../README.md)（GB/T 52020·60）。
> 分工声明：架构工程正主在 [讲透Transformer](../../../讲透Transformer/)，本支管学科侧脉络。

## 诞生

1943 McCulloch-Pitts 神经元（逻辑门用神经画）；1958 感知机；1969 XOR 反例
（寒冬）；1986 反向传播（PDP 学派）；1998 LeNet；2012 AlexNet；
2017 Transformer——七十五年一条线：**加层、加数据、加算力**。

## 核心问题

| 问题 | 状态 |
|------|------|
| 通用逼近（表达力） | ✅ 已解（1989；家族 00 章美之时刻①） |
| 训练可行性（梯度不消失） | ✅ 基本解决（ReLU/LN/残差，2011-16） |
| 深度为什么优于宽度 | 🔄 部分（深度分离定理只覆盖特殊函数类） |
| 泛化的理论（过参数化不记忆） | ❌ 未解（双下降现象 2019 后仍无定论） |
| 训练动力学的一般理论 | ❌ 未解（与[优化](../../../讲透数学/讲透优化/)共前线） |

**这支最美的一个事实**：残差连接（ResNet 2015）——学 F(x)+x 而不是 F(x)，
一行加法让千层网络可训；等价于把网络变成"每层只需学修正量"的微分方程
离散格式（dx/dt=F(x) 的 Euler 步）——工程补丁与数学结构撞了个满怀。
