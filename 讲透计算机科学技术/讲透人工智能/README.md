# 讲透人工智能 · 让机器做需要智能的事

> **本质一句话**：人工智能是"让机器做需要人类智能之事"的学科——
> 六十九年历史上它换过三套引擎（符号推理→连接主义→统计学习+大模型），
> 但学科宪法从未变过：**智能可以被人工造出来**。
>
> GB/T 13745：52020（计算机科学技术·二级）。宇宙：[讲透计算机科学技术](../README.md)。
> 本家族定位：**GB/T 框架下的 AI 学科总纲与挂靠枢纽**——AI 的工程内容正主在
> work4ai 的 AI 系列群（挂靠表），本家族五问答"AI 作为一门学科"。
