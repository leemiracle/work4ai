# 讲透模式识别 · 从特征工程到深度表示

> 这支负责：**让机器认出"这是哪一类"**——模式识别是深度学习的曾用名，
> 也是中国学科建制的特色支（"模式识别与智能系统"二级学科至今在工科目录里）。
> 家族：[讲透人工智能](../README.md)（GB/T 52020·40）。

## 诞生

1957 Rosenblatt 感知机（学会认字的最小机器）；1968 傅京孙（K.S. Fu）
把句法方法引入模式识别并立学科（华人对本支建制的关键人物）；1990s 统计学习
三驾马车（SVM/boosting/随机森林）巅峰；2012 AlexNet 让"特征工程"职业消失。

## 核心问题

| 问题 | 状态 |
|------|------|
| 线性可分性判别 | ✅ 已解（感知机收敛定理 1962：可分必收敛） |
| 维数灾难下的泛化 | ✅ 已解（SVM 边际+核，1995；统计学习理论 VC 维） |
| 表示学习（特征自动化） | ✅ 已解（深度学习 2012） |
| 小样本识别 | 🔄 部分（度量学习/元学习有效但未根治） |

**这支最美的一个事实**：核技巧——把数据隐式映射到无穷维空间再找最宽分割面，
"升维反而更好分"违反直觉，一行内积替换就实现了它（正主[统计学习理论](../../../讲透数学/讲透统计学习理论/)）。

## 假设与依赖
