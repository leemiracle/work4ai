# 讲透机器翻译 · 三朝代活标本

> 这支负责：**语言的终极 NLP 任务**——规则→统计→神经三朝代在同一任务上的
> 完整标本，AI 史的微缩胶片。
> 家族：[讲透人工智能](../README.md)（GB/T 52020·30）。

## 诞生

1954 Georgetown-IBM 演示（6 条规则、250 词）点燃第一代信心；
1966 ALPAC 报告判其失败（第一次寒冬的 NLP 分支）；1990s IBM 统计模型
（Candide）复活；2014 seq2seq（Sutskever）与 2017 Transformer（论文标题
就是 "Attention Is All You Need"——为翻译而生）开启神经朝代。

## 核心问题

| 问题 | 状态 |
|------|------|
| 词对齐（统计朝代核心） | ✅ 已解（IBM Models 1-5） |
| 短语级翻译质量 | ✅ 已解（BLEU 时代，工业可用） |
| 低资源语言 | 🔄 部分（回译/迁移有效，长尾仍缺） |
| 文学级"雅"译 | ❌ 未解（评价体系本身未共识） |

**这支最美的一个事实**：统计翻译的核心等式 argmax P(e|f) = argmax P(f|e)P(e)
——把"翻译"翻译成"生成最像人话的句子"，语言学的先验被一条贝叶斯展开式替代；
"噪声信道"这个物理隐喻养活了一个朝代。

## 假设与依赖

平行语料可得（有监督）；翻译质量可用自动指标近似（BLEU 的争议即此假设的裂缝）。
依赖：[概率论](../../../讲透数学/讲透高维概率/)、[信息论](../../../讲透数学/讲透信息论/)。
