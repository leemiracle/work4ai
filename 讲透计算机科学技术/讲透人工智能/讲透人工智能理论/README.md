# 讲透人工智能理论 · 学科的数学系

> 这支负责：**智能的形式骨架**——搜索、推理、规划、学习理论；AI 的"什么可被算出来"的边界部门。
> 家族：[讲透人工智能](../README.md)（GB/T 52020·10）。

## 诞生

1950 图灵之问给出可操作定义；1956 Logic Theorist 用搜索证明定理——
搜索即智能的第一数学化；1970s A* 与可采纳性证明（Hart-Nilsson-Raphael）让
"找得快"成为定理而非运气。

## 核心问题

| 问题 | 状态 |
|------|------|
| A* 可采纳性（最优解保证） | ✅ 已解（1968） |
| P vs NP 对启发式搜索的意味 | ❌ 未解（继承千禧问题，正主[计算复杂度](../../../讲透数学/讲透计算复杂度/)） |
| RL 收敛性（表格情形） | ✅ 已解（Watkins Q-learning 1992） |
| 深度 RL 全局最优保证 | 🔄 部分（仅特定条件） |
| 通用智能的形式定义 | ❌ 未解（学科至今无"能量守恒"级定律） |

**这支最美的一个事实**：A* 的最优性证明只用一行不等式——f(n)=g(n)+h(n)
只要 h 不高估，第一个扩展到的目标就是全局最优；"聪明的乐观"被数学豁免。
