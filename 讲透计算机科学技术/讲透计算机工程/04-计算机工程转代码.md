# 04 · 计算机工程转代码：开源 EDA、FPGA 与延迟阶梯

> **本章回答五问之五（本支：讲透计算机工程）。**
> 硬件工程的几乎每一步都已被软件化——EDA 就是硬件的编译器。本章给三条走廊：
> 开源 EDA 全链（造芯片）、FPGA（硬件的 REPL）、性能测量（消费硬件的必修课），
> 并划清可机械化的边界。

---

## 一、可机械化边界（为什么是这样）

| 环节 | 可机械化程度 | 边界原因 |
|------|-------------|---------|
| RTL→网表→版图（数字） | ✅ 全自动 | 布尔代数+确定性算法；人类最长自动构造链 |
| 布局布线优化 | 🔄 启发式 | NP 难（时序收敛无最优保证，只有"好"） |
| 模拟电路综合 | ❌ 基本人工 | 非线性微分系统的设计空间搜索无通用算法 |
| 物理验证 DRC/LVS | ✅ 全自动规则 | 规则集可判定（几何规则明确） |
| 良率/工艺学习 | 🔄 统计模型 | 数据在代工厂手里（信息不对称是制度边界） |
| 功能正确性证明 | 🔄 形式验证 | 状态机穷举可行，但 spec 完备性不可自动 |

**判断**：数字链是全工程界自动化最深的流水线；**模拟与经济学（NRE）**
是两个至今"人"与"钱"不可替代的环节。

## 二、代码走廊总表

| 走廊 | 工具链 | 一句话 |
|------|--------|--------|
| 开源 EDA 全链 | **Yosys**（综合）→ **OpenROAD**（布局布线）→ **KLayout/Magic**（版图）→ **OpenLane**（一键 flow）→ SkyWater PDK（130nm 开放工艺） | 从 RTL 到 GDSII 零license走通（2010s 的"不可能"） |
| 仿真验证 | **Verilator**（RTL 编译成 C++，比商业仿真器快 10-100×）、cocotb（用 Python 写 testbench）、GTKWave（波形） | 验证吃掉项目 60-70% 工时——这里是效率战场 |
| FPGA | yosys+**nextpnr**（开源）、Vivado/Quartus（商用）、HDL→比特流→上板 | FPGA=硬件的 REPL：改了就烧，烧了就跑 |
| 体系结构模拟 | **gem5**（周期级 CPU 模拟）、SystemC-TLM（ESL）、DRAMSim2/ Ramulator（内存时序） | 论文级架构研究的标准实验台 |
| 性能测量 | perf/PAPI/**likwid**（硬件计数器）、自己写延迟微基准（见实验） | 消费侧：不懂硬件的调优是占卜 |
| 开源芯片实录 | SERV（RISC-V 五级流水线 ~350 行 Verilog 也有硅）、OpenTitan（安全 MCU，从 RTL 到量产的开源全流程） | 开源硬件已过"玩具线" |

📖 **故事框｜330 美元造一颗自己的芯片**：Google/Efabless 的 Open MPW 计划
（TinyTapeout 延续）把 130nm 小 die 的掩模成本摊给全球爱好者——学生交一份
RTL 就能收到寄回来的真芯片。2010 年代这话是科幻；开源 EDA+开放 PDK 把
"人人可造芯"从口号变成了邮费问题。

## 三、工程师落点（性能工程视角）

1. **延迟阶梯必须自己量一遍**：教科书数字（L1 ~1ns / DRAM ~100ns）在你的机器上
   有具体值——[01_delay_ladder.py](experiments/01_delay_ladder.py) 三分钟出你机器的
   阶梯表。所有性能问题都是这个阶梯上的搬运问题
2. **硬件计数器是免费的显微镜**：perf stat 一行命令读 cache miss / branch miss /
   IPC——调优前先看计数器，别猜
3. **并发思维的免费训练营**：写 HDL 是练习"真并发"思维的捷径（比学一门并发
   语言便宜），回过头写 CUDA/异步 IO 会突然通透（→ [讲透GPU与系统级](../../讲透GPU与系统级/)）
4. **cache-friendly 代码是硬件知识变现**：行对齐、伪共享、预取——这些词都是
   本家族的存储层级在向你收税或退税（→ [讲透高性能计算](../../讲透高性能计算/)）
5. **AI 时代的硬件素养**：读懂 HBM 带宽/算力比（ arithmetic intensity 与 roofline），
   才能判断一个模型是算力瓶颈还是带宽瓶颈——这是 2026 年工程师的分水岭技能

✨ **美之时刻｜两条实验脚本就是两台显微镜**：一台量你机器的时空（延迟阶梯），
一台验证宇宙的许可（NAND 造一切）——[experiments/](experiments/) 里
`python` 一下，抽象全部落地。

## 四、裂缝清单（不可转/难转）

- 模拟电路自动设计（前述）；工艺数据壁垒（先进 PDK 不开源，物理真相被商业隔离）
- 光刻/制造环节只能模拟不能"编译"（制造物理只能逼近不能编排）
- 经济约束（NRE/产能）无代码表达——但 chiplet 时代它决定架构，架构师必须读财报
