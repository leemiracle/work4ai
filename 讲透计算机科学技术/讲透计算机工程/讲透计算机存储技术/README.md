# 讲透计算机存储技术 · 记住一切的工程（GB/T 52050 三级）

> **定位句**：这支负责"机器怎么记住"——SRAM/DRAM/NAND/HBM/磁与光存储，
> 以及把它们串成金字塔的**存储层级**。性能工程的第一课在这支：一切快慢
> 都是存储层级上的搬运。

## 诞生

1950s 磁芯存储（王安专利，手工穿线时代）→ 1966 年 Dennard 发明单管单电容 DRAM
（一篇专利撑起一个产业）→ 1980 Fujio Masuoka（东芝）发明 Flash →
2013 韩厂 3D V-NAND 把存储单元盖成高楼 → 2013+ HBM 把 DRAM 摞到 GPU 旁边。

## 核心问题

| 问题 | 状态 |
|------|------|
| 存储层级为什么有效 | ✅ 已解（局部性定律：时间+空间局部性，1980s 定论） |
| DRAM 电容漏电问题 | ✅ 已"解"（64ms 刷新纪律——制度化而非消除） |
| 内存墙（CPU 快过 DRAM 六个数量级） | 🔄 前线（HBM/PIM/CIM 各路攻墙，未破） |
| NAND 3D 堆叠极限（层数=经济性） | 🔄 前线（200+ 层，刻蚀深宽比逼近工艺极限） |
| 存算一体（CIM/PIM）通用化 | ❌ 未解（编程模型未定型） |

## 这支最美的一个事实

DRAM 是一个**漏电的水桶**：电容里的电荷几十毫秒就漏光，所以全世界的内存
每 64ms 被强制刷新一遍——人类把全部数字记忆托付给一群"必须不停续水的桶"，
并且管这叫工程。

## 假设与依赖

假设"局部性成立"（程序 tend to 重用邻近数据）——买到小快贵+大慢贱的
金字塔组合拳，付出缓存一致性协议与程序员心智税。
依赖元器件支的电容/晶体管；被处理器支当乐谱消费。
