# 讲透处理器技术 · 开关的编排艺术（GB/T 52050 三级）

> **定位句**：这支负责"开关怎么被编排成会思考的机器"——CPU/GPU/NPU/DSP/SoC
> 的微架构与实现。隔壁 [系统结构家族](../../讲透计算机系统结构/) 讲"怎么设计"的
> 学问，本支讲"设计怎么落进硅"的工程。

## 诞生

1971 年 Intel 4004：2300 个晶体管、740kHz、4 位——人类第一颗单片微处理器。
同年 Booth 的乘法算法早已就绪，但把"算法变成开关编排"这一步等了平面工艺十年。
此后五十年：单核狂奔（→4GHz 墙）→ 多核（2005）→ 异构（GPU 通用计算）→ 专用（TPU 2017）。

## 这支最美的一个事实

流水线把"装配线"搬进芯片：五级流水让 5 条指令同时在流水线上不同工位——
**机器没有变快，机器学会了不停工**。同一思想的变体（SIMD/多核/TMA）
统治了此后四十年的性能故事。
