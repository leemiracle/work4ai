# 讲透计算机外围设备 · 机器的手脚与感官（GB/T 52050 三级）

> **定位句**：这支负责"机器怎么触碰世界"——键盘/显示/SSD/网卡/打印/GPU 加速卡，
> 以及它们的通用协议：总线、中断、DMA。CPU 之外的每一个"亲戚"都住这支。

## 诞生

外设先于计算机存在（打孔卡/纸带是 1890 人口普查的遗产）。
1964 年 IBM System/360 引入**通道**（channel，DMA 雏形）——外设从此不必
打扰 CPU 搬数据；1981 IBM PC 的 ISA 总线让"插卡"成为产业；
1999 NVIDIA 把 GeForce 256 命名为 "GPU"——外设反客为主的开端。

## 核心问题

| 问题 | 状态 |
|------|------|
| I/O 接口的抽象（设备无关性） | ✅ 已解（OS 设备驱动模型，Unix 一切皆文件） |
| 中断/DMA 机制 | ✅ 已解（外设自搬数据，CPU 只签字） |
| GPU 从外设进化为主计算器官 | ✅ 已发生（CUDA 2007 之后，架构见系统结构家族） |
| I/O 墙：SSD/网络快过 CPU 处理能力 | 🔄 前线（DPU/智能网卡/NVMe 直连） |
| 外设安全（DMA 攻击面） | 🔄 前线（Thunderbolt/PCIe DMA 攻击与 IOMMU 防御） |

## 这支最美的一个事实

**DMA**：外设拿到总线主权自己搬数据，CPU 只在完工单上签字——
"老板不搬砖，老板审批"。这个 1964 年的发明让今天 400G 网卡与 NVMe SSD
不至把 CPU 变成搬运工。

## 假设与依赖

假设"总线协议标准化"——买到即插即用生态，付出协议栈的复杂税
（PCIe/NVMe/USB/Thunderbolt 每个都是一部标准史）。
依赖处理器/存储支；由 [讲透计算机软件](../../讲透计算机软件/) 的 OS 支驯服。
