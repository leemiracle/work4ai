> **本质一句话**：计算机工程是计算机的**物理实现层**——从一枚晶体管到一台整机的
> 全部工程学。隔壁 [讲透计算机系统结构](../讲透计算机系统结构/) 回答"机器该怎么设计"，

> 怎么连外设、怎么在硅上制造、怎么封装散热。

## 〇、家族树（GB/T 52050 六支全量落子）

```
讲透计算机工程/
├── 讲透计算机元器件/          晶体管·FinFET/GAA·忆阻器（开关的最小物理实现）
├── 讲透处理器技术/            CPU·GPU·NPU·SoC 微架构（开关组成的思想机器）
├── 讲透计算机存储技术/        SRAM·DRAM·NAND·HBM·存储层级（记住一切的工程）
├── 讲透计算机外围设备/        I/O·DMA·网络接口·显示（机器的手脚与感官）
├── 讲透计算机制造与检测/      光刻·刻蚀·良率·DFT 测试（在指甲盖上印一座城）
└── 讲透计算机高密度组装技术/  封装·2.5D/3D·chiplet·散热（把城市立起来并通电）
```

六支是一条**物理实现流水线**：元器件（开关）→ 处理器（开关的编排）→ 存储（开关的状态保持）
→ 外设（开关的世界接口）→ 制造（开关的批量印刷）→ 组装（开关的立体化）。
