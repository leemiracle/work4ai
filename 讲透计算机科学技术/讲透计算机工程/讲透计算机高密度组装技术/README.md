# 讲透计算机高密度组装技术 · 把城市立起来并通电（GB/T 52050 三级）

> **定位句**：这支负责"裸片之后的一切"——封装（引线键合→倒装→2.5D/3D 混合键合）、
> chiplet 互连、PCB 与供电、散热、信号完整性。**2020s 的性能进度条在这支手里**：
> 摩尔缩水，封装接管。

## 诞生

1958 Kilby 的锗模块→1959 Noyce 平面 IC（封装随之出生）。
2012 台积电 CoWoS（Chip-on-Wafer-on-Substrate）把"硅插花泥"商业化；
2019 AMD Zen2 chiplet 验证经济学；2022 UCIe 标准立互连公约——
封装从"保护壳"升格为"性能器官"。

## 核心问题

| 问题 | 状态 |
|------|------|
| 引线键合→倒装→TSV 硅穿孔 | ✅ 已解（三维化的三级台阶） |
| 2.5D 中介层（CoWoS-S/-R/-L 家族） | ✅ 已解（HBM 与 GPU 肩并肩的地基） |
| 混合键合（Cu-Cu 直连，DBI Ultra） | ✅ 量产（Sony/AMD/Intel 采用，室温键合） |
| 散热：功耗密度逼近"电炉丝" | 🔄 嫌疑未决（液冷/浸没/微流道，AI 时代头号瓶颈） |
| chiplet 已知好裸片（KGD）测试 | ❌ 未解（拆开前怎么证明每片是好的？） |
| 光互连进封装（铜线之后） | 🔄 前线（CPO 共封装光学初步商用） |

## 这支最美的一个事实

CoWoS 是一块**硅插花泥**：GPU、HBM、IO die 像花枝一样"种"在同一块硅中介层上，
芯片间走硅上细线（比 PCB 快百倍）——**芯片之间第一次实现了"同城宽带"**，
大模型训练的带宽命脉就踩在这块泥上。

## 假设与依赖

假设"热必须搬走"（热力学不谈判）——买到立体堆叠的自由，付出散热与
信号完整性（趋肤/串扰/电源完整性）双重税。
依赖制造支供裸片；成品交给系统/数据中心。
