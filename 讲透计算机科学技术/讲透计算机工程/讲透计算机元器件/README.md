# 讲透计算机元器件 · 开关的最小物理实现（GB/T 52050 三级）

> **定位句**：这支负责"用什么物理物件表示 0 和 1"——一切计算的原子层：
> 晶体管（MOSFET/FinFET/GAA）、电阻电容电感、忆阻器、自旋器件。
> 没有这支，计算机是数学；有了这支，计算机是**机器**。

## 诞生

1947 年圣诞前两天，贝尔实验室的 Bardeen、Brattain 做出第一个点接触晶体管
（Shockley 随后给出结型理论）——三人 1956 年获诺贝尔物理学奖。
1960 年 Kahng/Atalla 的 MOSFET 让"开关"可以大规模印刷，信息时代的种子发芽。

## 核心问题

| 问题 | 状态 |
|------|------|
| 场效应晶体管放大/开关理论 | ✅ 已解（MOSFET 1960，平面工艺 1959） |
| 平面→立体栅（FinFET 2011 Intel 量产→GAA 2020s） | ✅ 已解（绕开短沟道效应） |
| 亚 3nm 后量子隧穿失控 | ❌ 未解（物理终点逼近） |
| 后 CMOS 器件（忆阻器 2008 HP/自旋/CNTFET） | 🔄 前线（尚无一个撼动硅） |

## 这支最美的一个事实

MOSFET 是一个"**电压控制的水龙头**"：栅极电压隔着一层氧化物"隔空"打开通道，
动件为零——这个没有活动部件的开关，人类已印了 ~10²¹ 个，是史上产量最高的人造物。

## 假设与依赖

站在半导体能带论与量子力学上（→ [讲透物理学](../../../讲透物理学/) 凝聚态/电子物理支）。
假设"硅基+电荷编码"——买到全产业链成熟，付出与量子效应的持久缠斗。
