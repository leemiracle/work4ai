# 讲透计算机制造与检测 · 在指甲盖上印一座城（GB/T 52050 三级）

> **定位句**：这支负责"怎么把设计批量印到硅上并证明印对了"——
> 晶圆制造（光刻/刻蚀/沉积/离子注入）、良率科学、可测性设计（DFT）与
> 自动测试（ATE）。人类最精密的批量制造工艺全在这支。

## 诞生

1959 年 Fairchild 的 Hoerni 发明平面工艺、Noyce 发明单片集成电路——
"印"电路而非"焊"电路。1965 Moore 立下预言；1982 ASML 创立；
2019 EUV（13.5nm 极紫外光刻）量产——从"印"到"以光刻光"六十年。

## 核心问题

| 问题 | 状态 |
|------|------|
| 平面工艺→EUV 光刻链 | ✅ 已解（DUV→浸没式→EUV→High-NA 2024 首交付） |
| 良率模型（缺陷随机分布→成品率预测） | ✅ 已解（泊松/Murphy/Seed 模型族） |
| 冗余修复（DRAM 行列备胎/cache way 修复） | ✅ 已解（良率与冗余的经济学平衡） |
| DFT：千亿晶体管怎么测得完 | ✅ 已解（扫描链/BIST/压缩测试，开机自检的来源） |
| 3nm 后掩模成本与周期（NRE 危机） | ❌ 未解（经济墙，chiplet 是绕行不是解） |

## 这支最美的一个事实

缺陷像雨点随机落在硅片上，良率随 die 面积**指数衰减**——工程师的回答不是
追求零缺陷，而是**留备胎**：坏行熔丝换修、缓存按坏 way 裁剪分级出售。
用可控的坏，换不可控的好——与纠错码同一种智慧，长在硅上。

## 假设与依赖

假设"缺陷密度统计可学"——买到良率爬坡的可预测性，付出每代工艺重学一次。
依赖物理（光学/材料/化学：→ [讲透物理学](../../../讲透物理学/)）；
被 [讲透计算机高密度组装技术](../讲透计算机高密度组装技术/) 接棒。
