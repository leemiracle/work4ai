# 讲透软件理论 · 程序的数学骨架

> 这支负责：**"程序是什么"的严格回答**——形式语义（意义）、类型论（安全）、
> 程序逻辑（正确性）。软件家族其他六支都在"造"，这支在"定义"。
>
> GB/T 13745：52040·软件理论。家族：[讲透计算机软件](../README.md)。

## 诞生

Floyd 1967（流程图断言）与 Hoare 1969（公理语义）几乎同时把"程序正确性"
变成数学；Scott/Strachey 1964 起的指称语义回答"程序等于什么数学对象"；
Milner 1970s-80s 把并发也形式化（CCS/π 演算）。

## 核心问题（已解决/未解决）

- ✅ Curry–Howard 对应：类型=命题、程序=证明——两大领域是一个对象
- ✅ 结构化操作语义与指称语义的一致性定理
- ✅ Hindley–Milner 类型推断（线性时间可判定）——ML 系语言的引擎
- 🔄 并发程序的组合验证（线程交错状态爆炸）——不变式/分离逻辑是部分答案
- ❌ 通用程序等价性（不可判定，Rice 定理——永久边界而非待解问题）

## 这支最美的一个事实

**证明一个程序正确和写一个正确程序，是同一件事的两次打印**（Curry–Howard）——
所以"验证"不是软件的质检工序，而是软件的数学本体。
