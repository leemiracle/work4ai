# 讲透操作系统 · 资源虚拟化：机器的分身术

> 这支负责：**一台机器怎么变成千台**——进程（CPU 分身）、虚拟内存（内存分身）、
> 文件（存储分身）、并发（时间的分身）。OS 是软件家族里离硬件最近的宪法层。
>
> GB/T 13745：52040·操作系统与操作环境（支名轻规范化）。
> 家族：[讲透计算机软件](../README.md)。

## 诞生

Atlas 1962（虚拟内存，"一层抽象喂饱一代程序"）；UNIX 1969（Thompson/Ritchie，
从 Multics 的过度工程中提炼出"小而美"）；Linux 1991（一个学生的邮件宣告
开源时代的 OS 内核）；seL4 2009（第一个全功能正确性证明的内核——理论与工程的合流点）。

## 核心问题（已解决/未解决）

- ✅ 虚拟内存与页表：给每个程序"独占内存"的幻觉
- ✅ 进程/线程抽象与抢占式调度
- ✅ POSIX 标准：Unix 接口的行业宪法（1990 年二进制兼容至今）
- 🔄 调度器的公平-吞吐-延迟三角（没有最优解，只有场景站位）
- 🔄 内核验证（seL4 之后，主流内核的验证仍是长跑）
- ❌ 并发程序的正确性成本（竞态检查/无锁结构的可用性仍是手艺）

## 这支最美的一个事实

**"一切皆文件"三个字统一了磁盘/键盘/网络/进程间通信**——好抽象的力量：
一个 syscall 词汇表（open/read/write/close）覆盖所有 IO，四十年不过时。
