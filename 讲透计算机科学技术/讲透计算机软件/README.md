# 讲透计算机软件 · 家族总纲（软件是什么：程序、语言与构造的纪律）

> 计算机软件 = **让硬件变得可编程的一切中间层**——语言（人怎么说）、
> 操作系统（机器怎么分）、数据库（数据怎么活）、编译器（翻译怎么自动）、
> 软件工程（千百人怎么合写一个还不崩的东西）。
> 硬件一年一个样，软件五十年还是这五件套——这就是本家族要讲透的稳定结构。
>
> GB/T 13745-2009：520·52040 计算机软件（三级 7 支全列）。
> 建族日 2026-09-07（六学科扩展 lane，设计文档见
> [../../docs/superpowers/specs/2026-09-07-六学科GB13745扩展-design.md](../../docs/superpowers/specs/2026-09-07-六学科GB13745扩展-design.md)）。
