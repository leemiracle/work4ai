# 讲透程序设计语言 · 人机接口的语法与语义

> 这支负责：**人类意图如何变成机器可执行的文本**——文法、类型系统、
> 范式（函数式/命令式/逻辑式）、内存模型。语言设计是软件家族的"制宪"环节。
>
> GB/T 13745：52040·程序设计及其语言（支名轻规范化）。
> 家族：[讲透计算机软件](../README.md)。

## 诞生

FORTRAN 1957（第一个高级编译器，32 人年）；Algol 60（BNF——语言第一次有了
形式文法，"语法"从此是数学对象）；Lisp 1958（代码即数据，λ 演算落地）；
Simula 67（对象）；C 1972（可移植汇编）；ML/Haskell 系（类型推断与纯度）；
Rust 2010s（所有权——类型系统吞下内存安全）。七十年一场"约束迁移"：
**把运行时错误逐步搬进编译期**。

## 核心问题（已解决/未解决）

- ✅ 形式文法与自动分析（LR/LL——文法可判定层）
- ✅ Hindley–Milner 类型推断（无需注解的全局推断）
- ✅ 语义三派（操作/指称/公理）及其协调
- ✅ 所有权与借用检查（Rust：数据竞争在类型层绝迹）
- 🔄 渐进类型（动态语言的类型渐进补装——TypeScript/mypy 的理论与实践）
- ❌ "最好的语言"（伪问题——语言=约束组合的选择题，无全序最优）

## 这支最美的一个事实

**λ 演算（1936，丘奇）比计算机早诞生、比大多数语言更长寿**——一门为
逻辑发明的三符号语言（变量/抽象/应用），是今天一切函数式语言的本体。
