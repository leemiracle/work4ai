# 01 · 近五年创新方向：2021-2026 软件家族的三台新机器

> **本章回答五问之二（家族层）。** 这五年，软件家族进了一台前所未有的大机器——
> **LLM 写代码**，外加两台小机器（验证进内核、AI 基础设施反哺数据库）。
> 检索标注：部分检索校准 2026-09-07（Semantic Scholar 1 次成功 + 1 次限流降级，
> 其余为模型知识+公开事实，未逐条核实——沿讲透分析八支的限流降级协议）。

## 方向一：LLM 重写软件工程——写代码的活正在被接管

主线事件链（检索锚点：Codex/HumanEval，Chen et al., arXiv 2021）：

- **Codex 评估论文**（2021）：GPT 微调 GitHub 代码后，HumanEval 基准
  单次通过 **28.8%**（GPT-3 为 0%）；惊人发现——**重复采样 100 次，
  覆盖率升到 70.2%**。"生成-验证"范式从此立住：模型负责生成多样性，
  测试负责筛选正确性。
- **程序合成规模化**（2021，MBPP 基准）：性能随模型规模对数线性提升；
  人机对话反馈能把错误率砍半——"生成+反馈"就是后来的 Agent 编程。
- **In-IDE 实证**（TOSEM 2021）：把代码生成装进 PyCharm 做受控实验——
  开发者**体验**好评，但**生产力度量不显著**。这条"体感 vs 度量"的裂缝
  直到 2024-2025 的 SWE-bench（真实 GitHub issue 解决率）才部分弥合：
  从个位数到 40%+ 只用了两年。
- **判断**：写代码的"打字"部分正在消失，留下的是规格、验证与架构决策——
  这恰好把软件工程的重心推向本家族 00 章说的"未解问题"（正确性与生产力度量）。
  工程现场全貌见 [`../../讲透代码生成/`](../../讲透代码生成/)。

## 方向二：验证进内核——"对"开始被证明而不只是测试

- seL4（2009 全功能正确性证明）之后，形式化验证从航天/军工走向大众基础设施；
  2021-2025 的推进线：RISC-V 生态验证、TLS 协议可验证实现、密码库证明
  （HACL*系→量产 OpenSSH 采用）。
- 动力结构变化：**证明的成本被 Proof Automation 降低**——LLM 辅助证明搜索
  （Lean mathlib 生态，见数学宇宙的 [计算机数学 01 章](../../讲透数学/讲透计算机数学/01-近五年创新.md)）
  让"写证明"开始像"写代码"。
- 本家族的接口：软件理论支的形式语义 + 就地成员 [`讲透形式化验证`](../../讲透形式化验证/)。

## 方向三：AI 基础设施反哺数据库——数据的宪法被重写需求

- **向量数据库**爆发（2021-2024）：LLM 的记忆层（ANN 索引/混合检索）催生
  一批新数据库与老库的新索引（pgvector 等）——数据库家族十年里最大的一次品类扩张。
- **learned components**（自学习索引/查询优化器）从论文走向系统默认项的边缘：
  核心思想"数据分布是可学习的"与 04 章的"数据走廊"直接接轨。
- **判断**：数据库家族五十年回答"数据怎么存取"，这五年新问题是
  "语义怎么存取"——答案还没定型，正是进入这个领域的窗口期。

## 方向四：供应链安全与 SBOM——软件工程的地基审计

- Log4j（2021.12）是一记行业警报：一个开源组件的漏洞波及全球。
- 2021-2025：SBOM（软件物料清单）从倡议变法规（美国行政令起步）；
  依赖图扫描、签名（Sigstore）成为默认。软件工程支新增一整块"供应链"内容。

## 方向五：本家族各支的纯技术前线（采样，非穷尽）

| 支 | 2021-2026 动向 |
|---|---|
| 程序设计语言 | 语言级数据竞争检查（Rust 模式被 Swift/Go 吸收）、渐进类型论工程化 |
| 编译系统 | MLIR 多级中间表示成为新基础设施；LLVM 生态与 AI 编译器（XLA/TVM）合流 |
| 操作系统 | 异构内存（CXL）、io_uring 重写 IO 栈、eBPF 成内核可编程层 |
| 数据库 | HTAP、云原生存算分离、向量检索（方向三） |
| 软件工程 | AI 结对（方向一）、平台工程、DORA 度量体系化 |

## 判断：三台机器改变的是什么

LLM 改变的是**写的成本**，验证机器改变的是**对的成本**，AI 基建改变的是**存的语义**——
三者分别砸在软件家族七支的三个根假设上（表达力假设/测试假设/数据假设）。
**没有变的是分层结构本身**：中间件不会消失，只是每一层都在换材质。
