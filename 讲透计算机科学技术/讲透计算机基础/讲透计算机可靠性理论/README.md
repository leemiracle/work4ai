# 讲透计算机可靠性理论 · 出错是常态的科学（GB/T 52010 三级）

> **定位**：在物理故障与软件缺陷常态化的前提下，系统仍给出正确服务的理论——
> 冗余、容错、表决、验证、测试的谱系。一句话：**假设会坏，设计不坏**。
>
> 家族：[讲透计算机基础](../README.md)｜宇宙：[讲透计算机科学技术](../../README.md)

## 诞生

von Neumann 1956《概率逻辑与不可靠元件合成可靠机体》；Apollo 制导计算机三模表决
（1960s 实战）；Hamming 1950 纠错码（本支与通信理论的接口）；软件侧从
 Floyd–Hoare 验证思想到 seL4（2009 全形式化微内核）。

## 核心问题（3-5 条）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 纠错码的存在性与界（Hamming/Singleton） | ✅ | 冗余换正确的定量科学 |
| 拜占庭容错 3f+1 下界（FLP/ consensus） | ✅ | 异步+一故障⟹共识不可能的精确边界（分布式侧正主：讲透分布式AI系统） |
| 软件正确性证明 | ✅ 方法/🔄 规模 | seL4/CompCert 全验证存在，规模化仍在路上 |
| 共模故障消除 | 🔄 工程难题 | 冗余的冗余才是可靠（N 版本程序设计的教训） |

## 假设与依赖

故障独立性假设（独立性失败=共模故障）；故障模型（崩溃/拜占庭）决定成本。
