# 02 · 语言特征：自动机是语法，不变式是语义

> **本章回答五问之三（本家族：讲透计算机基础）。**
> 表达？逻辑？规范化？本家族的语言是 CS 里最接近数学的——
> **乔姆斯基层级给"能说什么"造了显微镜，证明义务给"说对了没"造了法庭**。

---

## 一、表达力：能说什么，不能说什么

直觉图像：把"语言"（字符串集合）想成"一台机器认得出的所有句子"。
机器的记忆越大，认得越多——**表达力 = 记忆的函数**。

| 语言类 | 表达力护照（能说） | 边检章（不能说） | 为什么不能 |
|--------|------------------|----------------|-----------|
| 正则（DFA） | 模式匹配/词法/离子序列 | aⁿbⁿ（计数） | 有限状态必重访 → 泵引理 |
| 上下文无关（PDA） | 括号配对/语法树/回文 | aⁿbⁿcⁿ（两种独立计数） | 单栈只有一层记忆 |
| 递归可枚举（TM） | 一切可识别的 | —（表达力顶格） | 但判定要付不可判定税 |

**为什么是这样**：每级的"不能说"都不是工程欠缺，而是**定理**（泵引理/Ogden 引理/
对角线）。这与其他学科"暂时说不了"不同——层级边界是永恒的墙。
（表达力的现代消费方：正则引擎/解析器组合子/类型系统，见 04 章。）

✨ **美之时刻：描述复杂度（Fagin 定理）**。NP = 存在二阶逻辑可表达的性质——
"非确定性多项式时间"这个**机器概念**，与"存在量词叠在关系上"这个**逻辑概念**
完全重合。为什么美：**统一**——计算与逻辑两种世界观在 NP 握手。
怎么亲历：3-着色写成 ∃c₁c₂c₃(每条边两端不同色)，一阶之外恰差一个"存在关系"量词。

## 二、逻辑性质：可判定的阶梯

直觉图像：问题排成天梯，越上越"烫手"——

```
真代数闭域理论（Tarski，可判定）
  → Presburger 算术（可判定，超指数复杂度）
    → 一阶 Peano 算术（不可判定：Gödel/Turing）
      → 程序等价性/停机（Π₂ 完全）
        → Rice 定理：程序的任何非平凡语义性质皆不可判定
```

**为什么是这样**：表达力每上一级，可判定性就掉一档——逻辑的"能说"与算法的
"能判"呈精确的反比交错（正则的 MSO 可判定 ⟷ 图灵完备的等价不可判）。
反直觉之最：**Rice 定理**——不只停机不可判定，程序"是否总输出素数"这类
**任何非平凡语义性质**全部不可判定；可判定的只剩语法层（行数/是否含 while）。
这就是为什么 lint 只能查风格，语义 bug 得靠测试/验证（[可靠性支](讲透计算机可靠性理论/)）。

## 三、规范化：不变式与证明义务——CS 的公理化巅峰

直觉图像：数学家用公理锁住结构，本家族用**三元组**锁住程序：

```
{前置条件 P} 程序 C {后置条件 Q}
    循环配: 不变式 I（每圈保真）+ 变体函数 V（每圈递减、自然数值域）
```

**Hoare 逻辑**把"程序是对的"变成"公式是可证的"——这是 CS 中规范化程度
最高的语言，比绝大多数数学分支更接近 Hilbert 设想的完全公理化（代价：
语义层不可判定的墙仍在，所以验证是**半自动**的：机器查证明，人/搜索供不变式）。

| 层 | 规范化武器 | 状态 |
|----|-----------|------|
| 词法/语法 | 正则/CFG 文法（完全规范：语言=文法） | 工业日常（每一个编译器） |
| 算法语义 | Hoare 三元组/分离逻辑 | 高规范，半自动（[形式化验证](../../讲透形式化验证/)） |
| 抽象数据类型 | ADT 公理（栈/队列的公理化） | 教科书标准（CLRS/TAOCP） |
| 并发 | 时序逻辑/TLA+ | 设计期验证（AWS 工业实践） |

**为什么是这样**：程序是人造语言，没有"自然现象"要妥协——所以它能做到
纯数学般的规范化；而语义不可判定又逼出"规范+半自动证明"的独特形态。

## 这章给了你什么新眼睛（认知升维）

1. **层级眼**：接到任何解析/匹配任务，先定位目标语言在哪层——用对层级的工具
   （正则能办别上 CFG），工程难度立减
2. **不变式眼**：读循环先找不变式——找到不变式=看懂循环的一半；
   写循环先写不变式，bug 率对半砍
3. **Rice 眼**：凡是号称"全自动分析程序语义"的工具，先想想它一定悄悄
   放弃了什么（sound 但不完备/只查某类性质）
