# 讲透可计算性理论 · 计算的绝对边界（GB/T 52010 三级）

> **定位**：哪些问题**原则上**存在机械解法——可判定/不可判定、递归/递归可枚举、
> 归约与完全性。一句话：**给"算法"画边界**，边界之外给出不可能性证书。
>
> 家族：[讲透计算机基础](../README.md)｜宇宙：[讲透计算机科学技术](../../README.md)

## 诞生

希尔伯特判定问题（1928）→ Turing 1936 图灵机+停机不可判定；
Church λ-演算同期等价（丘奇-图灵论题）；Rice 定理 1951 封顶。

## 核心问题（3-5 条）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 停机不可判定（对角线） | ✅ Turing 1936 | 计算的第一道绝对边界 |
| Rice 定理 | ✅ 1951 | 一切非平凡语义性质皆不可判定 |
| 丘奇-图灵论题 | 🧭 论题（非定理） | 一切合理计算模型等价（量子是压力测试） |
| 算术层级/图灵归约度结构 | ✅/🔄 | 不可判定问题自身分阶层（0′, 0″…） |

## 假设与依赖

图灵机模型（无限带+有限程序）；非确定性不增表达力只增效率（与复杂度分界处交接给
[讲透计算复杂度](../../../讲透数学/讲透计算复杂度/)——正主）。
