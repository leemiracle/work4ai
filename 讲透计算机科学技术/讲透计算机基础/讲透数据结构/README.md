# 讲透数据结构 · 组织决定代价（GB/T 52010 三级）

> **定位**：数据怎么摆，决定操作多贵——ADT 公理化（栈/队列/优先队列/映射）
> 与实现谱系（数组/链表/哈希/平衡树/堆/并查集/图）。一句话：**复杂度承诺的兑现层**。
>
> 家族：[讲透计算机基础](../README.md)｜宇宙：[讲透计算机科学技术](../../README.md)

## 诞生

随 1950s 语言学课程与 Knuth TAOCP 卷 1（1968）的"信息结构"章成科；
AVL 树 1962（第一批自动文献检索的产物）；B 树 1972（磁盘时代）；
哈希从 1953 IBM 内部备忘录到今日云存储索引。
