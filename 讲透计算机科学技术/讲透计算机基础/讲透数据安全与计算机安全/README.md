# 讲透数据安全与计算机安全 · 对抗环境下的计算（GB/T 52010 三级）

> **定位**：对手在场时的计算科学——密码学（机密性/完整性/不可伪造）、
> 协议安全、系统安全（访问控制/侧信道）。一句话：**把"难"变成资源**。
>
> 家族：[讲透计算机基础](../README.md)｜宇宙：[讲透计算机科学技术](../../README.md)

## 诞生

Shannon 1949（保密系统的信息论）；Diffie–Hellman 1976/RSA 1977（公钥革命）；
GMR 1985 零知识证明（后获图灵奖）；侧信道时代 1996（Kocher 时序攻击）至今。

## 核心问题（3-5 条）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 单向函数存在性 | ❌ 未解（⇔平均情形 P≠NP） | 全部现代密码的地基悬空 |
| 后量子密码标准化 | ✅ 2024 落地 | FIPS 203/204/205——量子威胁的工程回应（家族 01 章方向一） |
| 零知识证明与验证计算 | ✅ 理论/🔄 效率 | zk-SNARK：证明短于计算本身 |
| 形式化协议验证 | ✅ 方法 | Tamarin/ProVerif：协议即定理 |

## 假设与依赖

计算困难性假设（归约塔基）；Kerckhoffs 原则（公开系统）；实现侧信道是
理论模型的物理泄漏（常数时间编程=安全对性能的征用）。
