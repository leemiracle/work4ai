# 讲透自动机理论 · 有限记忆的语法学（GB/T 52010 三级）

> **定位**：研究"有限状态的机器能认出/生成什么"——正则语言与它的自动机族
> （DFA/NFA/带输出的 Moore/Mealy 机）、乔姆斯基层级的下三层入口。
> 一句话：**把"语言"变成"机器"来研究**。
>
> 家族：[讲透计算机基础](../README.md)｜宇宙：[讲透计算机科学技术](../../README.md)

## 诞生

Kleene 1951（正则事件与神经网事件）；Rabin–Scott 1959（非确定性引入，
DFA↔NFA 等价，图灵奖级）；Huffman/Moore 1956（顺序电路的数学模型）。

## 核心问题（3-5 条）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| DFA↔NFA↔正则表达式三方等价 | ✅ Kleene/Rabin–Scott | 三种世界观（机器/语法/代数）一个对象 |
| Myhill–Nerode 定理与最小化 | ✅ | 语言自带唯一最小自动机 |
| 泵引理及各级划界 | ✅ | 表达力的永恒之墙 |
| 自动机学习的下界（查询复杂度） | 🔄 前线 | Angluin L* 之后的最小查询学习 |

## 假设与依赖

有限状态（无外存）；确定性/非确定性的转换代价为指数（子集构造）。
