## 〇、定位一句话

在动手写任何代码之前，先回答六个问题：这个问题的**可判定性**（自动机理论·可计算性理论）、
**资源代价**（算法理论）、**数据组织**（数据结构）、**运行保障**（可靠性理论）、
**对抗环境下的生存**（安全）——这就是本家族的全部地盘。

## 一、诞生（怎么产生的）

1936 年图灵为回答希尔伯特"判定问题"发明图灵机——**计算机的数学模型先于计算机八年**；
1960-70 年代算法与数据结构随计算机产业化成科（Knuth《TAOCP》1968-）；
安全一支从 Shannon 1949 保密系统理论到 1977 RSA 公钥革命，成为对抗科学。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 停机问题不可判定（Turing 1936） | ✅ 已解 | 存在明确定义但任何程序都解不了的问题——计算的第一道绝对边界 |
| 乔姆斯基层级（正则/上下文无关/递归可枚举） | ✅ 已解 | 表达力的层级金字塔，泵引理逐级划界 |
| Cook–Levin 定理 + NP 完全理论（1971-72） | ✅ 已解 | SAT 是 NP 完全的——"一个问题难=一大类问题难" |
| DFA 最小化（Myhill–Nerode） | ✅ 已解 | 每个正则语言有唯一最小自动机——结构与语言互定 |
| 公钥密码（Diffie–Hellman 1976 / RSA 1977） | ✅ 已解 | 单向函数假设下，保密通信无需共享秘密 |
| P vs NP | ⧜ 千禧未解 | 本家族乃至全部 CS 的中心引力源（正主在[讲透计算复杂度](../../讲透数学/讲透计算复杂度/)） |
| 单向函数存在性 | ❌ 未解 | 与 P≠NP 的平均情形版等价——现代密码的地基悬空 |
| 程序终止性自动判定 | ❌ 不可判定（本质） | 一般程序无法自动证明终止——半自动工具（终止性分析器）活跃 |

## 三、假设与代价

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 图灵机/丘奇-图灵论题 | 模型普适稳健（一切合理模型等价） | 忽略物理资源连续性——量子计算是最大挑战者 |
| 最坏情形分析 | 对所有输入的硬保证 | 平均性能被误判（快排最坏 O(n²) 却是实践之王） |
| 字 RAM 模型 | 算法分析可操作 | 缓存/流水不感知——工程性能需再校准 |
| Kerckhoffs 原则（系统公开，仅密钥保密） | 密码学可公开评审 | 安全性完全押在计算困难性假设上 |
