# 讲透工效学 · 人机接口的工程:让机器迁就人

> **定位句**:这支负责"**人与机器的接口**"——工效学/人因工程:
> 显示与控制的匹配、生理与认知负荷、人的差错与可靠性——
> 工程造机器,工效学管"机器怎么迁就人"这个反向问题。
> GB/T 13745 63050 管理工程 · 三级 **6305055 工效学**。家族:[讲透管理工程](../README.md)

## 诞生

- **谁/何时**:前史是泰勒时间-动作研究(1911)与 Gilbreth 夫妇的动素分析
  (therbligs,1920s);二战是真正产房——设备跑赢了人(飞机座舱仪表看错、
  高炮跟不上),"human engineering" 1945 年前后定型;
  1949 年英国工效学学会成立,"ergonomics" 一词 1950 年启用(Murrell);
  1954 年 Fitts 定律(瞄准运动的时间公式);1960s-70s 人-机-环境系统
  理论扩展;1983 年 Card-Moran-Newell《人机交互心理学》立 HCI 学科
  (GOMS 模型);1986 年切尔诺贝利后人因可靠性分析(HRA)大发展;
  1988 年诺曼《设计心理学》(示能/可供性与差错设计);中国线:
  1980s 起人类工效学标准化(ISO 6385 对应国标体系)。
- **因什么问题**:①机器性能超出人的感知运动极限,错在设计不在人
  ②人的差错是系统的正常输出,要设计防御而不是骂人
  ③界面/工具/环境要按人的尺度(生理+认知)定制 ④作业组织轮班/负荷的健康边界。

## 核心问题

**已解决**:Fitts 定律(MT=a+b·log₂(2D/W),瞄准时间的可算公式)与
Hick 定律(选择反应时间随选项数对数增长)——认知运动的两个基本定律;
显示-控制兼容性原则(自然映射:旋钮方向=结果方向);人的差错分类
(失误 slips vs 错误 mistakes,Reason);HRA 技术(THERP 等给"人的失误概率"
定标);轮班与疲劳的生理节律模型;ISO 6385 与人体测量百分位设计。

**未解决/深水区**:自动化下的人的失控(ironies of automation,Bainbridge
之问:自动化把人变成失能的监工,出事时恰恰最需要人);AI 系统的心智模型
对齐(人构的模型 vs 机器真行为,可解释性战场);认知负荷的实时测量
(无创无扰的读数仍未定型);虚拟/远程作业的新人机几何。

## ✨ 这支最美的一个事实

**Fitts 定律:"好用"第一次有了公式**。
点击一个又大又近的按钮比又小又远的快,快多少?
MT=a+b·log₂(2D/W)——时间随"距离/宽度"之比对数增长。
为什么美:一句设计直觉被压成可计算的公式——按钮要做多大、
放在哪、热区留多少,全都变成代入运算;今天手机上的每个拇指热区、
游戏里的每个准星,都在付这笔"对数账"。工效学的雄心由此一斑:
**把"以人为本"从口号做成尺子**。

## 假设与依赖

- 人的常数假设(人的感知运动与认知参数可测可复用):买到设计规范,
  付出人群差异的百分位覆盖问题(P5 女工到 P95 男工都要装得下)
- 差错可结构化假设:失误有模式、可分类、可防御——反驳来自高可靠性
  组织理论的"差错是系统共振"观点(两者互补)
