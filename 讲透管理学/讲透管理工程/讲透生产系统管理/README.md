# 讲透生产系统管理 · 造东西的现场:流量与波动怎么兼得

> **定位句**:这支负责"**造东西的现场**"——生产系统的设计与管理:
> 布局、排程、瓶颈、在制品、量产体系;把订单变成产品的物理转换过程的工程学。
> JIT/精益/TOC 三大现场哲学都在这支的地图上。
> GB/T 13745 63050 管理工程 · 三级 **6305010 生产系统管理**。家族:[讲透管理工程](../README.md)

## 诞生

- **谁/何时**:1913 年 Ford 流水线(节拍化装配,量产范式定型);
  1931 年 Shewhart 把统计请进车间(过程控制);1950-80 年代丰田大野耐一
  逐步建成 TPS(准时化+自働化+看板,通说以丰田生产方式为精益源头);
  1960-70 年代 MRP 把车间计划搬进计算机(Orlicky);
  1984 年 Goldratt《目标》以小说体传播瓶颈理论(TOC);
  1990 年 Womack 等人《改变世界的机器》命名 lean。
- **因什么问题**:①多品种批量下排程是组合爆炸(车间调度 NP 难)
  ②过量生产的浪费藏在"效率"指标里(机器要转满=在制品堆山)
  ③瓶颈决定系统产出,改善力气该往哪使 ④波动在工序间传导放大。

## 核心问题

**已解决**:Little 定律(在制=产出率×周期时间)钉死三个量的铁三角;
TOC 的聚焦五步(找瓶颈-榨瓶颈-服从瓶颈-扩瓶颈-循环)成为改善的标准动作;
拉动式生产(看板=下游拉上游的信号)证明**控制在制品上限**就能同时改善
周期时间与产出;精益浪费七分类(过量/等待/搬运/过剩加工/库存/动作/不良)
给现场改善提供了通用清单。

**未解决/深水区**:车间排程的组合爆炸——工业求解器与启发式的军备竞赛没有终局;
**流动效率 vs 资源效率的权衡**(让机器转满 vs 让件流快)无一般解,依产品谱系而变;
需求剧烈波动下产能/库存/响应时间的三角取舍(柔性产线的投资论证);
行为运营(操作工与班组的真实行为 vs 模型假设,2020 年代活跃方向)。

## ✨ 这支最美的一个事实

**看板:用一块卡片把计划经济换成市场经济**。
推动式系统里,中央计划(MRP)算好一切、上游不顾下游死活地造;
拉动式系统只立一条法——**没有看板不许造,看板数=在制品上限**——
生产什么、何时生产,由下游的真实消耗发出信号决定。
为什么美:不重排组织、不换机器,只改**信息流的方向**,过量生产的浪费
就从制度上失业了;加上 Little 定律,在制品上限一降,周期时间自动跟着降
——精益的全部魔法是这两条结构定律的组合。
