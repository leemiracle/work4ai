# 讲透研究与开发管理 · 不确定性的前端:创新怎么分批下注

> **定位句**:这支负责"**不确定性的前端**"——研发项目管理、技术组合、
> 创新过程管理:从门径(Stage-Gate)到研发组合的实物期权,管理"未来产品"
> 这件最不确定的资产。
> GB/T 13745 63050 管理工程 · 三级 **6305015 研究与开发管理**。家族:[讲透管理工程](../README.md)

## 诞生

- **谁/何时**:1940-70 年代企业实验室黄金时代(贝尔/杜邦/IBM 的中央研究院,
  通说以企业内部研发建制为大公司时代标志);1958 年美国海军北极星计划
  创 PERT(不确定工期下的网络计划);Kline & Rosenberg 1986 链式创新模型
  (线性模型的替代品);Cooper 1990 年代定型 Stage-Gate 门径管理;
  Christensen 1997《创新者的窘境》把"良好管理杀死突破创新"结构化;
  2000s 开放式创新(Chesbrough)与研发组合的实物期权视角。
- **因什么问题**:①研发结果高度不确定,大额预算怎么分批承诺
  ②探索(新技术)与利用(现有业务)争资源 ③项目失败率与止损纪律
  ④"更快更高"的进度压力与创造力的冲突(PERT 之问)。

## 核心问题

**已解决**:门径管理把"一次豪赌"拆成"阶段+门"的分期投资——每个门是
一次重新定价与再决策(止损/继续/转向),已成为实业研发流程的国际通说;
PERT 三点估计(乐观/最可能/悲观→β 分布期望)把不可计划的研发变成
"带不确定性的计划";技术路线图与组合地图(风险×回报九宫格)成为
研发资源配置的标准视图。

**未解决/深水区**:**探索 vs 利用**没有最优配比(组织学习理论的永恒张力);
颠覆式创新在财务指标上天然劣势(毛利率低的市场看不上眼)——
Chandrasekaran 式"双元组织"怎么设计仍在试验;研发生产率怎么度量
(专利数/新产品收入比都有古德哈特风险,纪律见
[../../讲透管理计量学/README.md](../../讲透管理计量学/README.md));
AI 加速研发(AI for R&D)重组创新流程是 2020 年代新题。

## ✨ 这支最美的一个事实

**Stage-Gate 的门=分期投资的实物期权**。
传统研发预算像一次性全款买房,Stage-Gate 像分期带退出权:
每个阶段末的门,买入的是"下一阶段的期权"而非承诺到底。
为什么美:它把金融工程的核心思想(不确定性下,保留灵活性本身有价值)
翻译成了研发流程的**治理结构**——失败项目的"早死"不是浪费,
是整张期权组合里已经付清的权利金。
