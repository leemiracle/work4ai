# 讲透管理工程 · 决策的基建层:管理决策的支持系统与工具链

> **本质一句话**:管理工程=**给管理决策修基建的工程**——把运筹、统计、信息、仿真
> 工程化地装进组织的日常决策流程:从排产表与控制图,到 MIS/ERP 的信息主干,
> 到 DSS 的模型服务,再到数字孪生与流程挖掘的实时镜像。
> 管理计量学(63025)研究仪器怎么造,管理工程把仪器**铺进组织、天天运转**。
>
> GB/T 13745-2009:630 管理学 · 二级学科 **63050 管理工程**(三级 11 条:
> 10 条建支 + **6305060 部门管理工程**为归属注记——各部门管理工程按 GB/T 分别
> 入有关学科,如同兄弟家族[讲透部门经济管理](../讲透部门经济管理/README.md)的归属型处理,不建支)。
>
> **分工声明**(先读这个再读本家族):本家族是管理学宇宙的**工程方法层**——
> 与[讲透管理计量学](../讲透管理计量学/README.md)是**方法学 vs 工程化**(它管仪器原理与证据纪律,
> 本家族管仪器在决策流程里的部署与集成);与企业管理(63040)是**工程工具 vs 职能现场**
> (本家族供给排产/质量/物流/决策工具链,职能现场的管理学在企业管理家族——波4建设中,文字提及)。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透管理工程/
├── 讲透生产系统管理/          6305010 生产函数的工程现场:布局/排程/JIT/精益/瓶颈
├── 讲透研究与开发管理/        6305015 不确定性的前端:门径/项目组合/技术管理

├── 讲透战略管理/              6305030 长周期的决策工程:定位/资源/动态能力
├── 讲透决策分析/              6305035 单次决策的语法:决策树/效用/EVPI/有限理性
├── 讲透决策支持系统/          6305040 把模型装进决策现场:三库架构→BI→决策智能
├── 讲透管理信息系统/          6305045 组织的信息基建:TPS→MRP→ERP→数字化
├── 讲透管理系统仿真/          6305050 管理的风洞:离散事件/系统动力学/蒙特卡洛
└── 讲透工效学/                6305055 人机接口的工程:Fitts 定律/人因可靠性/认知负荷
```

> 十支的共同血统:**一切管理工程 = 模型(世界怎么抽象)× 系统(模型怎么装进流程)
> × 人(流程里的人怎么接)**。生产/质量/物流/研发/工效是运营现场的五类工具链,
> 决策分析→决策支持系统→管理信息系统是决策工具链的三层递进,仿真给全部支当风洞,
> 战略管理把工具链对准长周期的大题。
