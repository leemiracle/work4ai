# 管理工程思维技能卡(讲透管理工程 · GB/T 63050)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **模型部署类**:排产、排程、选址、补货、批量、安全库存、订至点、EOQ、看板、瓶颈、TOC、OEE
- **系统类**:MIS、ERP、MRP、TPS、BOM、主数据、系统集成、实施、BPR、中台、一网通办
- **决策支持类**:DSS、三库架构、BI、OLAP、决策智能、仪表盘、what-if 分析、决策支持系统
- **仿真与镜像类**:数字孪生、流程挖掘、RPA、BPM、离散事件仿真、系统动力学、存量-流量、蒙特卡洛
- **现场类**:JIT、精益、六西格玛、SPC、控制图、田口、稳健设计、FMEA、可靠性、MTBF、牛鞭效应、VMI
- **人机类**:工效学、人因工程、Fitts 定律、认知负荷、人的可靠性、人机接口、人在回路

## ② 核心思维模式(这个分支怎么想问题)

1. **schema 化**:一切重复决策先填四句类——目标/约束/状态/策略;
   填不满的题,先补数据再谈智能
2. **结构优先于参与者**:组织失灵先找结构(延迟回路/瓶颈/死锁),
   再找人——牛鞭教会的事:理性人放进坏结构一样全链失控
3. **基建分层**:任何数字化先定位层次——手工作业/单点工具/集成系统/实时镜像;
   跳层建设(没有主数据就上孪生)是烂尾楼的标准配方
4. **部署成本对半**:模型的成功一半在算法,一半在参数管道与组织接住的能力
   (约束采集、实施变革、口径治理)——预算按此分配
5. **状态登记本能**:管理问题先找"共享事实层"(谁在何时占着什么)——
   订票/库存/占座同构,登记处电子化是 MIS 的第一性原理
6. **信息共享看方差不看速度**:上游下游之间,共享的价值在压波动(POS 直达),
   不在抢时间——评估任何"打通数据"项目先算方差账

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 数学规划(LP/MIP)+ 对偶影子价格 | 资源分配/排产/选址;对偶解=瓶颈与松绑价值 |
| MRP 倒排(BOM×时间轴) | 从交期反推开工/下单时间;项目排程同构(CPM) |

| 控制图(±3σ/判异规则) | 区分工序的异常与噪声(管过程不管产品) |
| 田口稳健设计/参数设计 | 把质量设计进参数公差(对波动不敏感) |
| FMEA | 事前列故障模式与优先数,防患于设计期 |
| 可靠性(浴盆曲线/冗余) | 寿命与故障率建模;MTBF 与维修策略 |
| 决策树+效用+EVPI | 单次重大决策;信息采集的定价上限 |
| 离散事件仿真+公共随机数 | 解不动的排队/流程系统;方差缩减做对照 |
| 系统动力学(存量-流量) | 振荡/放大/迟滞类动力学;牛鞭诊断 |
| Petri 网/工作流+可达性 | 流程死锁/越权/变体的静态体检 |
| 流程挖掘(α 算法族) | 事件日志→真实流程;应然 vs 实然对账 |
| 五力/价值链/VRIO/情景法 | 战略的结构分析与长周期推演 |
| Fitts/Hick 定律、GOMS | 界面与操作的时间预算;认知负荷的量化 |

## ④ 常见误区与禁忌

- **模型最优=现场最优**:没列进模型的约束(惯例/政治)一直在起作用——
  约束采集不到位,最优解会被例外逐条架空
- **把实施当安装**:ERP/系统上线的难点是组织适配(变革管理),半数困境在此
- **检验当质量**:末端全检改变不了过程——质量靠设计与过程控制(SPC 管工序)
- **仿真当证据**:没做过 V&V(历史对账/压力测试)的仿真只是动画
- **给烂流程上 RPA**:先用流程挖掘对账真实路径,再造,后自动化——顺序不能反
- **跳层建基建**:没有一致的主数据与状态登记(ERP 层),直接上孪生/决策智能=镜中花
- **把自动化边界交给算法**:AI 建议给到哪、人保留什么否决权是治理决策,
  代码只执行边界不设定边界
- **共享数据只图快**:信息共享的收益主项是方差压缩(牛鞭抑制),不是响应提速
