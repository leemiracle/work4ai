# 讲透质量控制与可靠性管理 · 质量是设计进去的,不是检出来的

> **定位句**:这支负责"**质量的工程学**"——统计过程控制(SPC)、稳健设计、
> 质量体系与可靠性工程:研究怎么让过程稳定输出合格品、让产品在寿命期内
> 不坏,以及"合格"这个词的数学含义。
> GB/T 13745 63050 管理工程 · 三级 **6305020 质量控制与可靠性管理**。家族:[讲透管理工程](../README.md)

## 诞生

- **谁/何时**:1924 年 Bell 实验室的 Shewhart 画出第一张控制图(异常 vs 噪声
  的统计判决);二战美军抽样检验标准(MIL-STD-105)把统计质检送上战场;
  1950 年 Deming 与 Juran 赴日讲座,浇灌出日本质量革命(通说);
  Feigenbaum 1961 提全面质量控制;1957 年美国 AGREE 报告奠基可靠性工程
  (军用电子设备的寿命科学);1970-80 年代田口玄一稳健设计+质量损失函数;
  1986 年 Motorola 创六西格玛(通说),1987 年 ISO 9001 首版。
- **因什么问题**:①检验救不了坏过程(检验悖论)②公差内也有优劣
  (质量损失连续)③产品会坏,寿命与冗余怎么设计 ④质量活动的成本与收益怎么算。

## 核心问题

**已解决**:控制图理论(±3σ 与判异规则)——工序的状态监测有了标准仪器;
田口方法(信噪比+参数设计)——把"对制造波动不敏感"变成可优化的目标函数;
可靠性工程全家桶(浴盆曲线/MTBF/故障树 FTA/FMEA/冗余设计);
质量成本四分类(预防+鉴定+内损+外损)——预防性投入有了会计语言。

**未解决/深水区**:**零缺陷的经济学边界**(多好算够好:质量成本的权衡无定理,
Deming 与 Juran 传人争了几十年);小批量/单件生产的控制图(无足够样本可攒);
软件与服务质量(不可库存的"过程"怎么定义公差);六西格玛的组织学
(项目制的改进怎么不被 KPI 化掏空——又见古德哈特)。

## ✨ 这支最美的一个事实

**田口损失函数:质量不是阶跃,是二次曲线**。
传统合格观:公差内=零损失,公差外=报废——一条悬崖。
田口:偏离目标值就有一切损失,近似二次函数 L=k(y−m)²。
为什么美:一个函数形状的改动,重写了整个制造业的价值观——
所有零件都"合格"但都偏向一侧的产线,装配质量照样崩塌;
"瞄准目标、压缩散布"从此成为设计与制造的共同语言,
稳健设计(选参数让输出对噪声不敏感)全部由此一念展开。

  漏报权衡(第一类/第二类错误的经典戏码,上游在
  [../../../讲透数学/讲透数理统计/](../../../讲透数学/讲透数理统计/))

- 大样本假设:3σ 判异规则对大样本过敏,粒度要随 n 调
  (同 [../../讲透管理计量学/README.md](../../讲透管理计量学/README.md) 控制图课)
