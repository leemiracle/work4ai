# 04 · 管理思想史转代码——思想编年的最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:管理思想史的问题一旦变成「关于思想史数据的计算」就能进代码——编年变时间轴、学派变交叉表、概念兴衰变曲线、人物变网络;**唯一不可外包给代码的,是史学判断本身(选样、归因、正典)**。

---

## 0. 开篇:92 条记录检验三个百年直觉

「管理学的诞生期密度惊人」「二战后学派爆炸」「最近三十年是科技在驱动」——这些是每本教科书都默认的叙事。它们对吗?

`experiments/00_mgmt_timeline.py` 用 92 条大事记录(1776-2025,年代×学派×人物×概念)做了最朴素的检验:按分期切片、数事件、对比密度、数新学派的出现年代。跑一遍,你会看到:**1911-1932 双奠基窗口的事件密度是此前 135 年的约 6-7 倍;1950 年之后首发的学派比之前更多;2000 年后科技驱动事件扎堆**——三个直觉全部被数据确认。

但脚本同时打印了**选样声明**:这 92 条是「入选正史的著名事件」,密度曲线度量的是**正史关注度**,不是「管理智慧产出」。脚本的 assert 断言的是前者,不是后者——**这是数字思想史的第一课:代码替你算数,替不了你解释数**(与数学史家族 04 章同款纪律,选样规则换管理版)。

## 1. 可机械化边界(三件套之一)

**能进代码的**(思想史数据化后的一切统计与可视化):

| 任务 | 机械化形式 |
|------|-----------|
| 编年密度/分期检验 | 事件点列 → 分期直方图、密度比断言(00_mgmt_timeline.py 已实现) |
| 学派爆炸检验 | 「学派→首发年份」映射 → 1950 前后首发学派数对比(已实现) |
| 概念兴衰曲线 | 词频时间序列 → 峰值定位、半衰期拟合(走廊 C2) |
| 传播链时滞 | 事件链年份差 → 时滞表(戴明环路:1931→1951→1980→1986) |
| 引文网络 | 文献对 → 中心性、社团检测、HBR/AMJ 双宇宙分离度 |
| 教科书框架 diff | 版次职能清单 → 增删条目表(02 章 §3 的数据化) |

**不能进代码的**(思想史的「不可判定域」):

1. **选样正当性**——哪些事件「值得」入库是史学判断;代码只能做敏感性分析(换选样规则,结论稳不稳?)。
2. **归因与动机**——「霍桑转向」的原因(梅奥的诠释 vs 数据混杂)不能由年份相关推出;代码给相关,人给归因。
3. **反事实评估**——「若无二战,决策学派会晚二十年吗」不可模拟;凡是模拟思想进程的程序,模拟的都是**作者的史观**。
4. **正典排序**——「谁是第一思想家」没有客观函数;被引加权=把正典判断伪装成超参数。

> 边界的一句话:**代码是史料的显微镜,不是史学家**。放大倍数越高,越要记得镜头是谁选的。

## 2. 代码走廊清单(三件套之二)

本家族的四条走廊(由浅入深):

| 走廊 | 输入 | 输出 | 对应实验/章 |
|------|------|------|------------|
| C1 思想编年走廊 | 事件列表 (年份, 学派, 人物, 概念) | 分期×学派交叉表、密度断言 | `experiments/00_mgmt_timeline.py`(✅ 已实现) |

### 2.1 C1 数据字典(`00_mgmt_timeline.py` 的 TIMELINE 即此模式的实例)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| year | int | 事件年(著作=出版年;实验=启动年);范围断言 ≥1776 |
| school | str | 15 个闭集标签(科学管理/古典组织/人际-行为/决策学派/…)——标签本身是史学判断的产物 |
| person | str | 人物或机构;「传说」类归因必须显式写进字符串 |
| concept | str | 一句话事件;含数字的断言(47.5 吨)写进文本,便于人工复核 |

### 2.2 C2 最小示例:概念半衰期(纯标准库)

```python
# 概念兴衰的最小模型:给定 (年份, 提及量),求峰值年与半衰期
CONCEPT_CURVE = {          # "企业再造" 在管理期刊索引中的示意词频(教学用假数据)
    1990: 3, 1991: 12, 1992: 60, 1993: 150, 1994: 200, 1995: 170,
    1996: 120, 1997: 80, 1998: 50, 1999: 35, 2000: 25, 2001: 18,
}

def half_life(curve):
    peak_year = max(curve, key=curve.get)
    peak = curve[peak_year]
    tail = [y for y in curve if y > peak_year and curve[y] <= peak / 2]
    return peak_year, (min(tail) - peak_year if tail else None)

# half_life(CONCEPT_CURVE) -> (1994, 4):峰值 1994,约 4 年衰减一半
# ⚠ 用途断言:该值度量『正史/媒体关注度半衰期』,不是概念实际使用时长——
#   "reengineering" 在工程语境里 1993 之前就存在(同名异物,03 章 §1 谱系坑)。
```

这正是 01 章热线 1.5(计算文献综述)与 03 章 §2.3(时尚循环)的接口:换真实数据源(HBR 标题/教科书索引/引文库)即成生产工具;**数据源的选择决定你测的是哪个宇宙的关注度**。

### 2.3 C3 最小示例:概念谱系的一跳两跳(纯标准库)

```python
GENEALOGY = {
    "泰勒制":       ["精益生产"],              # 反叛式继承:精益保留秒表,下放定义权
    "霍桑效应":     ["组织行为学", "员工敬业度"],
    "有限理性":     ["行为经济学", "满意原则"],
    "精益生产":     ["敏捷开发", "精益创业"],
    "敏捷开发":     ["规模化敏捷", "DevOps 管理"],
}
def descendants(g, node, hops):
    out = {node: 0}
    frontier = [node]
    for h in range(1, hops + 1):
        nxt = [c for p in frontier for c in g.get(p, []) if c not in out]
        for c in nxt: out[c] = h
        frontier = nxt
    return out
# descendants(GENEALOGY, "泰勒制", 2)
# -> {'泰勒制': 0, '精益生产': 1, '敏捷开发': 2, '精益创业': 2}
# ⚠ 管理知识图谱的第一课:同一次两跳查询里出现「泰勒制→精益→敏捷」时,
#   必须能区分 inherit(继承)与 rebel(反叛)边——这是 03 章的「画错的边」问题。
```

## 3. 工程师落点:管理知识图谱(三件套之三)

把 C1-C4 的数据合流,得到本家族对工程师最有用的产物——**管理知识图谱**(节点:人物/学派/概念/机构;边:师承/引用/演化/反叛;属性:年代/证据等级)。三个落点:

1. **企业培训与咨询知识库**:把管理思想编年变成可查询的概念谱系——新人问「赋能的祖辈是谁」,图谱两跳给出「授权←Y 理论←社会人」及其证据等级;咨询公司的方法论页面从此可附「本概念的学术出身」字段。
2. **Agent 的管理知识底座**:智能体执行管理任务(写 OKR、做复盘、生成绩效反馈)时,知识来源常为流行语料——幻觉管理学(把金句当定理,02 章 §4 的归因灾难被 LLM 放大)。知识图谱作为受控词表+证据等级层,是防幻觉的工程手段;与挂靠读本 [../../讲透管理/06-管理与Agent.md](../../讲透管理/06-管理与Agent.md) 的 Agent 议题直接衔接(读本给场景,本家族给知识本体)。
3. **文献计量的生产化**:综述作者的计算工具链——爬取→清洗→聚类→时序→可视化,把 01 章 Kraus/Rousseau 方向锚变成流水线;开源引文库与语料(HBR 存档、教科书索引)是数据地基。

**工程接口三问**(接入任何系统前自问):①选样规则公开了吗(哪个数据库、哪个时间段)?②证据等级带了吗(T1 原著还是 T4 大师叙事)?③继承边与反叛边区分了吗?

## 4. 已解决与未解决(③的代码版)

**已解决**:编年密度、学派计数、传播时滞——最小实现全部在 `00_mgmt_timeline.py` 跑通,exit 0;概念曲线与谱系查询有 20 行内的可复现实现(§2.2/§2.3)。

## 7. 反直觉发现(⑥)

**把 92 条编年交给最朴素的分组统计,学派会自动按「时代」而不是「教义」聚集**。看 `00_mgmt_timeline.py` 的输出:科学管理 9 条全部落在 1895-1917;大师综合横跨 1954-2001;数字与AI 11 条全部在 2001 后——**「学派」在时间维上是「世代」**:多数思想标签的第一属性是「哪代人」,教义差异反而其次。这给孔茨丛林一个冷酷的计算注脚:学派数的增长部分只是**人口增长**(每代学者都需要自己的旗帜)——统一丛林的难度,等效于让不同世代共用一面旗。

## ✨ 美之时刻(⑧)

**✨ 美之时刻:250 年思想史装进一个可被 assert 检验的文件**。`experiments/00_mgmt_timeline.py` 用 92 条记录+三个断言,把「双奠基」「学派爆炸」「科技驱动」从教科书修辞变成可复现检验;任何人换选样规则重跑,就能挑战本家族的叙事。**为什么美(思想史的可检验化)**:史学结论通常只能被「再解释」,这里却能被「再运行」——把争论从修辞层拉到数据层;**怎么亲历**:删掉编年里你最不服的一条大事,重跑脚本,看三个断言是否仍然成立——这一分钟里你完成的操作,就是史学方法论里的「敏感性分析」。
