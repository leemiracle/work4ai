# 讲透行为科学与决策学派 · 人回来了:从霍桑灯下到满意解(1930s-1970s)

> **定位句**:这支负责管理学的「哥白尼转向」——霍桑把「人」放进管理方程,西蒙把「理性」拉回人的尺度;士气与决策双线并进,中间站着福列特与巴纳德两座桥。
> GB/T 13745-2009:63010 管理思想史 · 本支为**自定主干支**。家族:[讲透管理思想史](../README.md)。

## 诞生

1924 年,西部电气霍桑工厂想测「多亮的灯让工人更快」,照明实验失败;梅奥介入后转向继电器装配室与访谈计划(1927-32),1933 年《工业文明的人的问题》宣布:产量由**群体规范与被关注的感受**决定——人际关系运动诞生。同年段:福列特的建设性冲突(1918 起)被追认为先声;巴纳德《经理人员的职能》(1938)把组织定义为**合作系统**。战后第二条线:西蒙《管理行为》(1947)提出**有限理性与满意原则**——管理人不是经济人,「管理就是决策」;西叶特-马奇(1963)把它做成企业行为理论;1978 年西蒙获诺贝尔经济学奖。

## 核心问题

已解决:
- 人际关系与古典三家的对立叙事已稳定(尽管「霍桑效应」本身证据不稳,见下)
- 有限理性的学术正典化(经济学诺奖+行为经济学的下游繁荣)

未解决:
- **霍桑效应的真伪**:照明实验原始数据重分析(Franke & Kaul 1978;Levitt & List 2011)显示产量与照明无系统关系,原始效应可能主要是统计 artifact——转向真实发生,解释是错的?
- 满意原则的规范化:能否给出「何时 satisfice 优于 optimize」的可计算判据(与决策科学/运筹边界,文字提及管理计量学家族)

## ✨ 这支最美的一个事实

一次失败的实验开创了一个范式:工程师们想测照明,五年测不出结果;把「失败数据」认真记录并重新解释,才发现真正的变量是**人在被观察时的感受与非正式群体**。霍桑留给管理学两份遗产——一份是光鲜的(把人放进方程),一份是隐藏的(它同时示范了**实验数据可以被重新分析并推翻流行解释**:2011 年经济学家用原始数据挑战了 1930 年代的故事本身)。**思想史上少有的「同一批数据养活两代学者八十年」的现场。**
