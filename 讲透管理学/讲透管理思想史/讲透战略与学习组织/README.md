# 讲透战略与学习组织 · 竞争与知识:定位、能力与学习(1960s-2000s)

> **定位句**:这支负责管理学的「环境转向」——当市场从求过于供翻转为供过于求,「把事做对」让位于「做对的事」:战略、质量、能力、学习四部曲。
> GB/T 13745-2009:63010 管理思想史 · 本支为**自定主干支**。家族:[讲透管理思想史](../README.md)。

## 诞生

1962 年钱德勒《战略与结构》用企业史证明「结构追随战略」;安索夫(1965)给出第一代战略工具箱。真正的引爆是环境:1970s 石油危机+日本制造冲击,波特(1979/1980/1985)把产业组织经济学改造成**五力与价值链**——分析单位从组织内部移到行业结构。同期质量线:戴明-朱兰 1950 年代赴日播下的种子长成 TPS(大野耐一),1980 年 NBC 纪录片让它回流美国,1990 年《改变世界的机器》命名为「精益」。1990s 第三波:圣吉《第五项修炼》(1990)的学习型组织、普拉哈拉德-哈默的核心竞争力(1990)、野中郁次郎的 SECI(1995)、克里斯滕森的颠覆式创新(1997)与蒂斯的动态能力(1997)——**竞争优势从「位置」移到「能力与知识」**。

## 核心问题

已解决:
- 战略教学的标准框架链(五力→价值链→RBV→动态能力)已建制化
- 戴明环路(美国发明→日本制度化→回流)成为技术转移的标准案例

未解决:
- **定位 vs 能力之争**:行业结构决定命运(波特)还是内部资源决定命运(巴尼)?30 年未决,动态能力是调和尝试
- 学习型组织能否制度化——圣吉的五项修炼至今更像修行纲领而非管理制度
- 管理时尚循环为何加速(本支贡献了最多的时尚标本:再造/平衡计分卡/核心能力)

## ✨ 这支最美的一个事实

戴明环路:休哈特 1931 年的控制图与戴明 1950 年的日本讲学,在这个没人预期到的地方(战败国的废墟工业)被制度化为国家奖项(1951 戴明奖)与全员实践(TPS),三十年后以「管理哲学」身份荣归故里(1980 纪录片→1986《走出危机》→1987 波奖)。**同一思想,三次变态(工具→制度→哲学),一次跨太平洋往返**——思想的命运由接收方的制度管道决定,这个传播结构是管理思想史最干净的实证标本(家族 03 章 §2.2)。

## 假设与依赖

- 复杂人假设(权变);竞争优势的可分析性假设(战略可被规划)——明茨伯格的「涌现战略」(emergent strategy)是对它的著名修正
- 依赖企业档案、案例库与畅销书销量数据(思想产业在此支全面登场)

## 教材锚

- 雷恩《管理思想史》;郭咸纲《管理学说史》(中文视角,现代部分)
- 波特《竞争战略》;圣吉《第五项修炼》;野中郁次郎《知识创造企业》
- 德鲁克《管理的实践》(1954)——本支与前支共同的思想坐标原点
