# 管理思想史思维技能卡

## 1. 何时用此分支(触发词)

遇到以下特征的问题/困惑,切到管理思想史眼光:

- 「这个管理概念(**赋能/OKR/敏捷/飞轮/颠覆)哪来的**?」——概念考古
- **流派之争**:泰勒 vs 梅奥、定位 vs 能力、X vs Y、丛林 60 年未决——先查各方的人性假设
- **思想家谱系**:德鲁克与西蒙为何双正典?西蒙为何拿的是经济学诺奖?戴明在日本经历了什么?
- **范式演变**:从科学管理到算法管理的主线是什么?(管动作→管人→管决策→管系统→管学习与演化)
- 「这个管理方法**为什么长这样**?」——每个工具都带着出生时的组织困境(OKR 是 MBO 的儿子)
- 「新管理概念又火了」——先查祖辈与半衰期(管理时尚循环),再判断是再包装还是真升维

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **假设眼** | 每派管理学=一条人性假设(经济人/社会人/自我实现人/有限理性人/复杂人);先定位假设,再评价工具 |
| **升维包含** | 判断真创新还是再包装的判据:新范式是否把旧范式包含为特例(精益包含秒表=升维;换词不换机制=包装) |
| **产业眼** | 思想是被制造的(商学院-咨询-畅销书三引擎);读概念先问谁在卖、卖给谁、走 HBR 语域还是 AMJ 语域 |
| **传播管道眼** | 思想的内容由发送方决定,命运由接收方制度管道决定(奖项/课程/咨询合同);追踪管道而非天才 |
| **重写眼** | 每代学派都在重写前史;你读到的「泰勒」是某一派的泰勒——找原始文本(T1)对照 |
| **证据分级** | T1 原著/档案 > T2 同代记述 > T3 学术研究 > T4 大师叙事;被引量只证明流行度不证明真值 |

## 3. 工具箱

- **八阶段主线**:前科学→科学管理→一般管理→科层→人际→定量/决策→系统/权变→战略→质量/精益→学习/平台/AI(与挂靠读本对齐,可加层不可跳层)
- **编年交叉表**:年代×学派×人物×概念切片(`experiments/00_mgmt_timeline.py` 即最小实现,92 条)
- **概念谱系 DAG**:继承/借喻/反叛三档边;警惕画错的边(同名异物/异名同物)
- **三栏语域分析**:思想语言(隐喻)/理论逻辑(命题)/学科规范(体裁)——多数管理争论是语域错位
- **传播时滞表**:事件链年份差(戴明环路 1931→1951→1980→1986)
- **半衰期拟合**:词频曲线峰值与衰减——区分「正史关注度半衰期」与「实际使用时长」

## 4. 常见误区与禁忌

- ❌ **进步史观**:管理学不是线性进步——梅奥没有淘汰泰勒(精益还在用秒表);升维=包含,不是取代
- ❌ **大师神话**:概念多非命名者独创(「科学管理」是律师布兰代斯在法庭上命名的);警惕畅销书的追加册封
- ❌ 把**传说当史实**:霍桑「照明实验发现霍桑效应」的重分析(Levitt & List 2011)显示原始效应证据薄弱——讲故事前先标证据等级
- ❌ **概念 anachronism**:把「赋能」直接连到法约尔;名字连续≠概念连续
- ❌ 忽视选样:任何「大师榜/趋势榜」度量的是关注度与产业推力,不是思想质量
