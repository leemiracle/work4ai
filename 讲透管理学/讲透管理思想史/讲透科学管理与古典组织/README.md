# 讲透科学管理与古典组织 · 秒表与蓝图:效率如何成为信仰(1911-1930s)

> **定位句**:这支负责管理学的「创世纪」——泰勒的秒表、法约尔的蓝图、韦伯的铁笼,三大古典支柱如何把「凭经验的艺术」变成「自称的科学」。
> GB/T 13745-2009:63010 管理思想史 · 本支为**自定主干支**。家族:[讲透管理思想史](../README.md)。

## 诞生

1881 年,亨利·唐恩在 ASME 宣读《工程师作为经济学家》,问出「车间管理难道不该用科学研究?」;三十年后泰勒用《科学管理原理》(1911)给出回答——时间动作研究、标准化、差别计件工资、one best way。同年段:法约尔(1916)从矿业高管视角给出**企业整体**的五职能+14 条原则;韦伯(《经济与社会》1922 遗作)从社会学给出大型组织的理想类型——**科层制**;穆尼-雷利(1931)与古利克(POSDCORB,1937)完成古典综合。三大支柱层次互补:泰勒管**作业**,法约尔管**企业**,韦伯管**官僚机器**。

## 核心问题

已解决:
- 古典三家的互补结构(分层不竞争)已成教科书共识
- 「科学管理」命名权的来龙去脉(布兰代斯 1910 法庭命名,02 章 §7)

未解决:
- **one best way 真的存在吗?**——权变学派说「视情况」,但精益/敏捷至今仍在用泰勒的测量内核;百年悬案在本支内终审(见家族 00 章 §5「丛林」条)
- 泰勒的「精神革命」(劳资两利)为何被劳资双方同时拒绝——1911 沃特敦罢工与国会听证的制度史细节

## ✨ 这支最美的一个事实

泰勒的铁锹实验:伯利恒的装卸工各自带自家铁锹,铲煤末时一锹 3 磅、铲铁矿石时一锹 38 磅。泰勒测出**每锹 21 磅左右最优**,于是给厂里配了一堵「铁锭墙」——十余种标准化铁锹,按物料分发;结果 140 人干完了原来 400-600 人的活,装卸成本降了一半。**为什么美**:把「工人自带工具」这个千年默认变成一个可计算的变量——管理学诞生时刻的思维方式,浓缩在一把铁锹的重量里。
