# 讲透管理思想史 · 「通过他人成事」的观念编年——管理学的自我意识

> **本质一句话**:管理思想史=「通过他人成事」的观念编年——它不生产新的管理技术,却回答每个技术背后的三个问题:**谁在什么组织困境中、用什么人性假设、在什么争论中把它造出来的**。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透管理思想史/
├── 讲透科学管理与古典组织/   📝 秒表与蓝图:效率如何成为信仰(1911-1930s)
├── 讲透行为科学与决策学派/   📝 人回来了:从霍桑灯下到满意解(1930s-1970s)
├── 讲透战略与学习组织/       📝 竞争与知识:定位、能力与学习(1960s-2000s)
└── 讲透数字与AI管理/         📝 算法接管「通过他人成事」?(2000s-)
```

四支不是四段封闭历史,而是四个**现场**:古典支看「效率如何变成信仰」,行为支看「人与决策如何取代秒表成为主角」,战略支看「环境动荡如何逼出竞争与学习」,数字支看「算法与智能体如何重写『他人』的定义」。主线一句话:**管动作 → 管人 → 管决策 → 管系统 → 管学习与演化**(与挂靠读本八阶段对齐:升维不否定,而是包含——精益仍用泰勒的秒表,只是把「谁来定办法」还给了人)。

## 四、前置与路径

- **零门槛**:本家族不需要任何管理学前置——它是管理的「纪录片」,不是「教科书」;不懂管理反而更容易看清思想的地形。
- 推荐看法:先读 00 章建立四支地图 → 对照挂靠读本 [01-历史脉络-八阶段.md](../../讲透管理/01-历史脉络-八阶段.md)(同一主线的通论版)→ 挑感兴趣的支读宪法 README。
