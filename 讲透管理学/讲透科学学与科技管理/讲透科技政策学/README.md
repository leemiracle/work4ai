# 讲透科技政策学 · 6303520:国家这台钱袋子怎么定向科学

> **定位句**:这支管"**财政与方向盘**"——国家为什么给科学花钱(市场失灵论证)、
> 怎么给(资助工具箱)、给多少(投入规模)、往哪给(优先领域与使命)。
> 从布什报告到使命导向,六十年政策范式的一线观察者与工具箱仓库。
> GB/T 13745 63035 科学学与科技管理 · 三级 **6303520 科技政策学**。家族:[讲透科学学与科技管理](../README.md)

## 诞生

- **谁/何时**:Bush《科学:无尽的前沿》(1945)给出公共资助的体制蓝图;
  Nelson(1959)与 Arrow(1962)补上经济学地基(基础研究=公共品,市场失灵);
  Freeman/Lundvall/Nelson(1987-1993)把政策单元升维成国家创新系统;
  Mazzucato《创新型国家》(2013)开当代使命导向(mission-oriented)议程;
  美国科学政策学(science of science policy)运动主张用科学方法研究政策本身。
- **因什么问题**:①市场为什么不资助基础研究(不可占有性/不确定性)
  ②政府该怎么组织资助(自治基金 vs 定向计划)③创新为什么是系统现象而非项目现象。

## 核心问题

**已解决**:
- 公共资助的合法性论证:市场失灵+溢出——"国家为什么要给钱"有定论
- 政策工具箱成文:直接资助/税收优惠/政府采购/需求规制/信息与平台,
  各自的适用面与失灵面(通说框架)
- 创新系统视角:产学研政的互动结构成为各国政策设计的默认底图

**未解决/深水区**:
- **投入刻度**:基础研究占 R&D 多少"合适"——线性模型给方向不给数(家族 00 章 §五)
- **挑选悖论**:定向资助靠评议选"可预期成功",突破恰不可预期——组合无理论最优
- 使命的可操作性:里程碑设计与评估标准仍在试验(家族 01 章主线 D)
- 政策证据本身:政策干预的因果评估远未穷尽

## ✨ 这支最美的一个事实

**一张 1945 年的报告定义了此后八十年的经费流向**:布什用"基础研究是技术进步的
资本"一个论证,造出 NSF 与全球仿效的资助体制——**一个思想实验变成每年
数千亿级的预算科目**。此后每一次范式更替(系统论、使命导向)都还在跟这份报告对话。
政策的半衰期,比论文长得多。

## 假设与依赖

- 线性模型假设(基础→应用的因果链)——被网状知识流反复修正,但政治上依旧好用;
- 国家能力假设:政府能识别方向、能执行使命(使命导向的新前提);
- 依赖 [讲透科学社会学](../讲透科学社会学)的规范诊断(自治健康度决定问责强度)
  与经济学宇宙的创新经济学(文字提及互链)。

## 教材锚

- Bush《Science, The Endless Frontier》(1945,中译《科学:无尽的前沿》)——本支原典
- Nelson(1959)/Arrow(1962)——市场失灵双论文
- Freeman《Technology Policy and Economic Performance》(1987);Nelson 编《National Innovation Systems》(1993)
- Mazzucato《创新型国家》(2013);OECD 科技政策手册系列(工具箱口径)
