## 诞生

- **谁/何时**:二战后科研规模化管理起步(曼哈顿工程与国家实验室体系是
  大科学管理的原型);1980 年美国《拜杜法案》把"财政资助成果的产权归属"
  变成技术转移的制度引擎,各国仿效;1980-90 年代各国科研院所改革、
  项目制与课题制普及;2000 年代起项目组合管理与开放合规进入日常。
- **因什么问题**:①自由探索怎么装进项目制的表格而不窒息
  ②公共经费的合规与科学的不确定性如何相容 ③成果怎么走出实验室(转化通道)。

## 核心问题

**已解决**:
- 项目全周期标准工艺:立项(评议)/执行(节点-经费)/结题(验收)/转化——与一般项目管理同构,
  但"研究失败"的合法地位是本领域特有条款
- 技术转移的制度通道:产权安排(拜杜式)/技术许可办公室(TTO)/孵化器/产学合作(通说框架)
- 大科学工程的组织工艺:分解-接口-里程碑管理(曼哈顿以来叠代的工程政治学)

**未解决/深水区**:
- **表格化悖论**:合规表格越多,自由探索的时间越少——平衡点无理论,只有国际经验的松紧带
- 转化的"死亡之谷":成果到产品之间的资金与激励断带,各国都在填、都没填平
- 开放科学合规(DMP/FAIR)进项目周期的落地摩擦(家族 01 章主线 B)

## ✨ 这支最美的一个事实

**拜杜法案用一条产权规则撬动了转化率**——把财政资助成果的专利权默认交给
承担单位,科研人员从"为国家做研究"变成"为自己的发明跑手续"。
**一个默认值(default rule)的改变,重排了几十万人的行为**——制度设计的杠杆率,
常常不在给多少钱,而在把默认值放在哪。
