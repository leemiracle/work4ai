# 00 · 体系结构:科学学与科技管理家族的全图

> **本章回答五问之一(家族层):整个体系结构长什么样。**
> **本质一句话**:科学学与科技管理=**把科学自身当成研究对象与管理对象**——
> 这台知识生产机器怎么组织(建制)、怎么读数(计量)、怎么给钱(政策)、怎么运转(管理)。
>
> 它在管理学宇宙里的独特位置:别家管理的是企业、政府、员工,本家族管理的是
> **一群比自己更懂数学的人**——评估指标会被研究对象反向研究、反向优化。
> **评估反身性**是本家族全部独特性的来源。

---

## 一、开篇故事:一门学科被点燃了五次

📖 **1938 年,默顿把科学自己摆上解剖台**。哥伦比亚大学的社会学家
Robert K. Merton 在《Osiris》上发表《十七世纪英格兰的科学、技术与社会》:
为什么近代科学恰在十七世纪的英格兰加速?他给出的社会学答案——
清教伦理(功利、经验、理性的气质组合)与科学职业的兴趣亲和,
皇家学会早期成员的教派构成成为第一批证据。
**"默顿命题"的真正遗产不是结论本身,而是提问方式**:科学不是悬浮在真空里的真理机器,
它有社会根系、可以被社会科学研究。科学学的时间纪元从这篇论文开始。

📖 **1942/1968 年,规范的成文与马太效应的发现**。默顿接着给这台机器写"操作手册":
《科学的规范结构》(1942)提出四条精神规范——**普遍主义**(真理不看出身)、
**公有性**(发现是公共财产)、**无私利性**(求真而非求利)、
**有组织的怀疑主义**(一切断言接受同行 scrutiny)——后人缩写为 CUDOS。
1968 年他又在《科学》上描述奖励系统的运行偏差:**马太效应**——
"凡有的,还要加给他"。同一项工作,大人物署名获得加倍承认,
资源与荣誉像滚雪球一样向少数人集中(§七反直觉之一)。

📖 **1945 年,布什给国家写了一张设计图**。罗斯福的科学顾问 Vannevar Bush
提交《科学,无尽的前沿》:基础研究是"技术进步的长期资本",
市场不会为它付钱(回报不可占有),所以要国家来付——
设立国家研究基金,让科学家自治地花这笔钱。这份报告直接孕育了美国国家科学基金会(1950),
也种下了影响至今的**线性模型**:基础研究→应用研究→开发→应用。
不管后人对线性模型有多少批判(知识流动其实是网状多向的),
有一件事是它定义的:**公共资助科研第一次有了完整的理论论证与体制蓝图**。

📖 **1953 年,双螺旋与诺奖光环下的数据共享**。沃森与克里克的 DNA 双螺旋模型
(《自然》1953 年 4 月)用到了伦敦国王学院富兰克林的晶体学数据——
那张著名的"51 号照片"经由机构间报告流转到剑桥,按当时的规范
并未经过数据生产者的直接知悉。富兰克林 1958 年早逝,
1962 年诺奖授予沃森、克里克、威尔金斯时,她已无缘分享(诺奖不授逝者)。
这个案例成了科学社会学的经典切片:**公有性规范(数据应当共享)与优先权竞争
(荣誉归于先发表者)在同一件事上正面相撞**——现代数据共享规范
(许可、引用、署名)的建制化,正是从这类历史教训里长出来的。

📖 **1963 年,普赖斯之问**。科学史家 Derek de Solla Price 出版《小科学,大科学》:
用两张图(论文数、科学家数的对数坐标)证明科学按**指数律**增长,约十五年翻一番;
由此推出那句名言——"至今活着的科学家,约占历史上科学家总数的八九成"。
科学从学者的业余爱好膨胀成国家级产业,于是他留下了本家族的总问题:
**科学这么大的事业,还能让科学家自己随便管吗?社会能不能管理科学、
应该管到什么程度?**("普赖斯之问")。普赖斯自己还泼了冷水:指数不可能永续,
科学正逼近自己的"饱和极限"。科学学与科技管理,就是这个问题六十年来的学科化尝试。

**五次点燃之后**,1980-2000 年代补上两块地基:Freeman/Lundvall/Nelson 的
**国家创新系统**(1987-1993,政策单元从"项目"变成"系统")与加菲尔德 **SCI**(1964)
带来的评估时代——直到 2012 年 DORA、2015 年莱顿宣言、2022 年 CoARA,
学界开始给自己立"负责任指标"的规矩。中国线:1970 年代末科学学复起,
1980 年《科学学与科学技术管理》创刊,赵红州等提出"科学能力学"——
本家族六支里"科学体系学"的中文语境即源于此脉。

**五次点燃的共同基因**:把科学从"真理的自动售货机"变成
**一台可观察、可计量、可设计、也会出故障的社会机器**。

## 三、体系结构图:科学之轮

```
   ┌────────────────────── ① 投入侧 ──────────────────────┐
   │   公共资助(布什式论证)    人才管道(教育供给)    设施装置   │
   └───────────────────────────┬─────────────────────────┘
                               ▼
   ┌────────────────── ② 知识生产过程 ────────────────────┐
   │  共同体:规范(CUDOS→PLACE 之争)+ 奖励(优先权/承认)      │
   │  质量控制:同行评议(合法性装置)                          │
   │  组织:实验室/研究所/大科学装置/虚拟团队(体系学支)        │
   │  人的因素:动机/创造/压力(心理学支)                      │
   └───────────────────────────┬─────────────────────────┘
                               ▼
   ┌────────────────── ③ 产出与影响 ──────────────────────┐
   │   论文/专利/数据/人才 ──(时滞 5-10 年)──▶ 技术·经济·社会影响 │
   └───────────────────────────┬─────────────────────────┘
                               ▼
   ┌────────────────── ④ 评估与反馈 ──────────────────────┐
   │   计量(引文/指标,计量学支)──▶ 评估(评议/排名)           │
   │        ──▶ 政策调整(资助结构,政策学支)──▶ 回到 ①        │
   └───────────────┬─────────────────────────────────────┘
                   │
                   ▼ 反身回路(本家族第一定律的所在)
        评估指标一旦与资源挂钩,科学家立即优化指标——
        指标被堆叠、切片、择刊;评估改变被评估的系统。
        (被管理者比管理者更懂数学,治理必须计价这一条)
```

**为什么是轮**:科学不是线性管道(布什模型的原始意象),是带反馈的闭环——
评估读数反过来改写生产行为。这张图里最要命的是最下面那条反身回路,
它与 [管理计量学 00 章](../讲透管理计量学/00-体系结构.md)的古德哈特回流线同构,
但在科学界更锋利:被测对象是职业的解题者。

## 四、核心问题清单(已解决/未解决,带地位)

**已解决的里程碑**:

| 年代 | 人物 | 结果 |
|------|------|------|
| 1938/1942 | Merton | 科学建制成为可研究对象;规范结构(CUDOS)成文 |
| 1945 | Bush | 公共资助科研的体制蓝图与线性模型;NSF 的思想源头 |
| 1957/1968 | Merton | 优先权争论与马太效应:奖励系统的运行规律 |
| 1959/1962 | Nelson/Arrow | 基础研究的公共品与市场失灵论证——"国家为什么给钱"的经济学地基 |
| 1963 | Price | 科学增长的指数律与大科学;科学计量学的开端 |
| 1964 | Garfield | SCI 上线:科学产出第一次全网可数、可回溯 |
| 1987-1993 | Freeman/Lundvall/Nelson | 国家创新系统:政策单元从项目升维到系统 |
| 2012/2015/2022 | DORA/莱顿宣言/CoARA | 评估改革的自我立法:负责任使用指标开始建制化 |

**悬而未决的大问题(都带地位)**:

- **默顿规范在 Big Science 时代的适用性之争——开放中,学科身份级问题**。
  Ziman 指出"后学院科学"的规范反转(CUDOS→PLACE:私有、地方、权威、委托、专家化),
  Gibbons 等提出 Mode 2 知识生产(应用情境中生产、跨学科、要问责);
  反方认为规范从未被真正遵守、它是理想型而非描述。**这场争论决定本家族的底色:
  科学到底是需要保护的共和国,还是需要治理的产业?**
- **同行评议的预测效度——未解决**。评分者间信度低是反复发现的经验事实;
  突破性工作在评议中常获平庸评分(克雷布斯循环 1937 年被《自然》拒稿,
  后来拿了诺奖——通说典故,个案不构成统计,但方向与模拟一致);
  开放评议、双盲、抽签等改革的效果正在测量中(见家族实验)。
- **资助的挑选悖论——开放**。同行评议天然偏爱"可预期成功",
  而突破的定义就是不可预期;集中资助(押注少数明星)与分散资助
  (广种薄收)的权衡没有理论最优解——资助组合理论是空地。
- **基础研究的"最优"投入规模——未解决**。线性模型给方向不给刻度;
  社会收益率的估计散布在很宽的区间,资助强度更多由国际比较与政治过程决定。
- **评估反身性的均衡理论——开放**。指标-激励-行为没有一般化定量模型
  (与管理计量学共享的开放问题);DORA/莱顿是原则宣言,不是定理。
- **科研诚信的治理结构——治理中**。撤稿量上升、"论文工厂"式工业化造假
  (通说匿名化表述)倒逼治理从道德训诫走向建制化(编辑政策、图像筛查、
  机构调查程序),路径未定型。

## 五、假设与代价(本家族站在什么之上)

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| **同行评议假设**(专业同行能预判质量与价值) | 合法性装置+质量过滤:科学界的"同行主权" | 信度低(评分者分歧大)、保守偏差(偏爱稳妥方案)、利益冲突、费用与时滞——四个病都建制化了 |
| **线性模型假设**(基础→应用→开发单向流动) | 公共资助基础研究的政治论证(无尽的前沿) | 知识流动实际多向;使命导向反例(需求牵引基础研究);刻度缺失——"给多少"它答不了 |
| **指标可代理假设**(引文/论文数/影响因子代理科学质量) | 可比、可排序、可预算、可问责 | Goodhart 病:指标成为目标即失真——切片发表、引文堆叠、择刊先于择题(02 章 §二专论) |
| **科学自治假设**(共同体自我监管优于外部管理) | 自由探索的土壤、内部人懂行 | 与公共问责的永久张力;内部纠错对系统性失范迟缓 |
| **增长外推假设**(科研规模可持续扩张) | 资源规划的基线(指数律惯性) | 普赖斯自己指出指数必饱和;科研成本增速长期超经济增速——"科学的可持续性"之问 |

**一句话**:本家族的每一条假设,都是**社会对科学的一笔投资条款**——
条款换来体制,违约金(评议误判、指标失真、增长撞墙)在 §七和 02 章结算。

## 七、反直觉发现(讲透铁律,本家族三枚)

**发现 1:马太效应——科学界的回报分布比财富分布更不平等**。
直觉上,科学是最 meritocracy 的行当:成果说话,不看出身。默顿 1968 年的发现恰好相反:
承认的分配**高度向已获承认者集中**——同样的工作,知名作者获得更多引用与奖励;
资源带来产出,产出加固知名,循环累积。多重发现的优先权规则(先到者通吃)
进一步放大赢家。这不是腐败,是奖励系统**正反馈**的结构性质——
理解它,才能理解为什么"青年科学家的第一笔大资助"是整个体制的关键杠杆。

**发现 2:拒稿≠质量差——低录用率下,噪声主导录用决定**。
直觉上,顶刊拒掉的稿子就是不够好。统计结构不支持这个读法:
录用率 8%、审稿噪声大于质量分歧时,**录用决定的大部分方差来自噪声**
——同一批稿子交给两个独立的编辑部,录用名单重合度很低;
真质量前 10% 的稿子被拒是大概率事件。这不是编辑部失职,
是"低基率+高噪声"制度的数学后果。数值实拍:跑
`experiments/peer_review_bias.py` Part 3(两编辑部对同一批稿的一致性、
真前十名被拒概率、录用率扫描)。

**发现 3:期刊影响因子的分布陷阱——用小区均房价推断住户**。
期刊影响因子(IF)是**期刊层**的均值指标;而论文被引分布严重右偏
(通说估计:一家期刊约 15% 的论文贡献了其引文总量的一半上下)。
用 IF 推断**单篇**论文质量,等于用小区平均收入推断某一户——生态谬误的标准案例。
IF 的合理用途是图书馆馆藏决策(它出生时的使命),越位到人才评价即触发 02 章的指标病。

## ✨ 美之时刻(全家族合计 ≥3 之前两枚,第三枚在 02 章)

✨ **美之时刻 1:两百年科学长成一条直线**(极简)
论文数、期刊数、科学家数,在半对数坐标上排成一条笔直的线,约十五年翻一番——
人类最庞大、最自诩不可预测的集体事业,服从最朴素的增长律。
为什么美:**"不可预测的真理探索"在总量上像晶体生长一样规整**;
个体狂野,总体守律,这正是统计物理式的美在社会科学里的稀有兑现。
更妙的是普赖斯顺手外推:直线不会永远直,科学正逼近自己的饱和——
一页对数纸同时装下乐观与忧患。亲历:普赖斯《小科学,大科学》全书不过百页,
拿一张半对数纸就能复核他的主图。

✨ **美之时刻 2:学术公正变成了实验参数**(必然)
"同行评议公不公平"原是茶歇里的道德争论;本家族把它搬进实验室:
噪声方差、利益冲突偏置、录用率——三个参数,一组蒙特卡洛,
公正性第一次有了**可调节、可复现的旋钮**。
为什么美:一门最古老的学术黑箱制度,被自己领域生长出来的工具照亮;
