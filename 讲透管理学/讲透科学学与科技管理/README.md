# 讲透科学学与科技管理 · 科学这台机器怎么组织、评估与资助

> **本质一句话**:科学学与科技管理=**把科学自身当成研究对象与管理对象的学科**——
> 知识生产这台机器怎么组织(建制)、怎么读数(计量)、怎么给钱(政策)、怎么运转(管理)。
> 它是普赖斯之问「科学能管理吗」的学科化回答:能,但前提是先弄清它的规范、奖励与偏差结构。
>
> GB/T 13745-2009:630 管理学 · 二级学科 **63035 科学学与科技管理**(三级 6303510-6303550 六支全落子)。
>
> **定位张力声明**(先读这个再读本家族):本家族是管理学宇宙里唯一**以知识生产本身为管理对象**的门——
> [管理计量学](../讲透管理计量学/)管"怎么测",本家族管"科学这台机器本身"。
> 它与被管理对象之间还有一场别处没有的缠斗:**被管理的科学家比管理者更懂数学**,
> 一切评估指标都会被研究对象反向研究、反向优化(评估反身性)——
> 所以本家族一半是建制设计(资助/评议/评估),另一半是**建制与被建制者的军备竞赛**。

> 社会学支供操作系统,政策学支供方向盘,体系学支供底盘,心理学支供发动机,
> 计量学支供仪表盘,管理学支供驾驶手册——六件套合起来回答同一个大问题:
> **这台机器,到底该怎么开?**
