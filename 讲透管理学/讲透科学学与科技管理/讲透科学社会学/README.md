# 讲透科学社会学 · 6303510:科学共同体的操作系统

> **定位句**:这支管"**共同体**"——科学靠什么自我运转:精神规范(默顿四条)、
> 奖励系统(承认与优先权)、马太效应、无形学院、科学与社会的互构。
> 它是本家族的**理论主干之一**:别的支管钱和表,这支管科学的"操作系统源代码"。
> GB/T 13745 63035 科学学与科技管理 · 三级 **6303510 科学社会学**。家族:[讲透科学学与科技管理](../README.md)

## 诞生

- **谁/何时**:Merton《十七世纪英格兰的科学、技术与社会》(1938)开题;
  《科学的规范结构》(1942)立四规范(普遍主义/公有性/无私利性/有组织的怀疑主义);
  《科学社会学》(1973 文集)集大成。默顿学派(学生含 Cole 兄弟、Zuckerman、
  Hagstrom)把奖励系统做成实证纲领;对立面:爱丁堡学派"强纲领"(1970s,
  科学知识社会学 SSK)与拉图尔-伍尔加《实验室生活》(1979)把镜头转向知识内容本身。
- **因什么问题**:①科学为何在特定社会土壤加速(默顿命题)②没有老板与合同,
  几百万学者靠什么协调(规范与奖励)③承认怎么分配(优先权/多重发现/马太效应)。

## 核心问题

**已解决**:
- 规范结构成文:四规范作为共同体"宪法条文",可观察可检验(违反有成本)
- 奖励系统运行律:优先权通吃、多重发现常态化、马太效应(累积优势)——
  承认分配高度右偏是结构性质不是事故(家族 [00 章](../00-体系结构.md) §七)
- 有形/无形学院二分:正式机构+非正式网络双层结构(SCI 让后者现形)

**未解决/深水区**:
- **规范之争**:CUDOS 是描述还是理想型?Ziman 的 PLACE 反转与 Mode 2
  是否意味着操作系统已换(家族 00 章 §四悬案)
- SSK 与默顿传统未合流:社会结构研究与知识内容研究仍是两张皮
- 数字共同体的规范生成:预印本/开放评审/社交媒介上的"新 CUDOS"会长什么样

## ✨ 这支最美的一个事实

**科学家没有签过任何合同,却高度守序**——普遍主义、公有性、怀疑主义
没有警察执行,靠承认这一种通货流通:你把数据给别人,别人把引用给你,
怀疑你=承认你值得怀疑。
**一个只发行"承认"一种货币的百万人口经济体,稳定运转了三百多年。**

## 假设与依赖

- 规范有效性假设:规范约束真实行为(不只是修辞)——Big Science 反复考验它;
- 承认可测假设:引用/奖项/职位能代理"承认"——代理链正是家族
  [02 章](../02-语言特征.md)的指标病素材;方法上个案史与统计并用(社会学上游)。

## 教材锚

- Merton《科学社会学》(1973,文集)——本支原典;《十七世纪英格兰的科学技术与社会》(1938/1970)
- Ziman《Real Science》(2000)——规范之争的现代回合
- Ben-David《科学家在社会中的角色》(1971)——建制比较史的紧凑教材
