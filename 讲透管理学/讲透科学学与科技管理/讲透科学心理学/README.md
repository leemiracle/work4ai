# 讲透科学心理学 · 6303530:发动机的心理

> **定位句**:这支管"**人**"——科学家的动机(好奇/承认/实用)、创造力与顿悟、
> 年龄-产出关系、科研压力与心理健康、科研生涯的明暗面。
> 制度设计的一切参数(奖励/评估/资助)最终都作用在这台生物发动机上。
> GB/T 13745 63035 · 三级 **6303530 科学心理学**。家族:[讲透科学学与科技管理](../README.md)

## 诞生

- **谁/何时**:课题化始于 1950s——Lehman《年龄与成就》(1953)画出各领域
  创造峰值年龄段;心理学家 J. M. Cattell 自 1903 年起编《美国科学人物志》,
  率先对科学家群体做统计研究;Simonton《科学天才心理学》(1988)集大成的"创造计量学";
  Hagstrom《科学共同体》(1965)研究竞争与焦虑。
- **因什么问题**:①承认与好奇哪个是第一动力(内外动机之争)
  ②创造力有无年龄规律、可否培养 ③竞争体制对科学家心理的代价。

## 核心问题

**已解决**:
- 产量分布规律:科学家一生的产量高度右偏(少数人多产),近似幂律——洛特卡学科分布律的个体版
- 年龄-产出通说图景:峰值随领域系统化程度移动(理论物理早,历史学晚);个体差异远大于年龄效应
- 动机结构:内在动机对创造性工作更有效,外在强激励有时反噬(动机挤出的证据链,通说综述)

**未解决/深水区**:
- 顿悟机制:双过程/无意识酝酿的实证仍在堆积,无定论
- **科研劳动力心理健康**:博士生抑郁焦虑比例偏高是跨国反复发现(通说),
  成因(不确定生涯/导师关系/评估压力)与干预都在半途
- AI 助手对科学家认知分工的影响(家族 01 章主线 A)

## ✨ 这支最美的一个事实

**产量分布的个体-总体同构**:洛特卡 1926 年发现少数作者写就大部分论文(学科层);
创造计量学发现单个科学家一生也如此(少数高产年份贡献大部分代表作)。
**无论横向比人还是纵向比年,创造力都是同样的右偏形状**——"灵感"在统计上
像地震:小震不断,大震稀少且不可预约。政策含义:评估周期若短于"大震间隔",
必然惩罚未来的人才。

## 假设与依赖

- 可计量假设:动机/创造可用产量、问卷、生涯数据代理——代理链自带噪声
  (家族 [02 章](../02-语言特征.md)的通用病);
- 个体主义假设:把科学家当独立个体研究——团队科学化后"个体产量"
  越来越是团队的函数(与 [讲透科学体系学](../讲透科学体系学)交界);
- 方法依赖心理测量与纵向数据(心理学宇宙上游,文字提及互链)。
