# 讲透科学体系学 · 6303525:这台机器的底盘与传动

> **定位句**:这支管"**结构与能力**"——学科体系怎么划、科研组织形态怎么演化
> (个人→实验室→研究所→大科学装置→虚拟团队)、科学资源怎么在体系里配置、
> 一个国家的"科学能力"由什么构成。GB/T 13745 自身就是这支的标本:学科分类体系
> 是分蛋糕的刀(家族 [03 章](../03-可构造与结构.md)引擎 2)。
> GB/T 13745 63035 科学学与科技管理 · 三级 **6303525 科学体系学**。家族:[讲透科学学与科技管理](../README.md)

## 诞生

- **谁/何时**:Price《小科学,大科学》(1963)定组织形态问题(规模跃迁);
  Ziman 论"集体化科学";中文脉络——赵红州等 1980 年代提出**科学能力学**
  (科学作为一种社会建制的生产能力:队伍/装备/图书情报/组织管理),
  与苏式"科学学"体系观合流;1990s 后 team science/大科学工程管理接棒。
- **因什么问题**:①科学从手工作坊变成国家级产业,结构怎么随之变形
  ②学科边界与组织边界怎么互相塑造 ③体系的能力用什么刻画、怎么补短板。

## 核心问题

**已解决**:
- 组织形态谱系成文:小科学/大科学/巨型科学;实验室-研究所-国家实验室-
  大科学装置-虚拟组织的演进序列(通说框架)
- 科学能力的要素分解:人力(结构/年龄/学位)、经费(来源/类型)、装备设施、
  信息基础、组织管理——统计口径见科技统计(正主互链,见"关系")
- 学科-组织映射:院系建制、学部制、跨学科中心的各自适用期

**未解决/深水区**:
- 跨学科工作的坐标系问题:按学科切块的资源分配挤压交叉地带(结构性,非态度问题)
- 大科学的治理:巨型装置的立项-运行-退出机制,国际分摊的政治学
- AI4S 组织形态(自驱实验室/人机团队)的体系位置(家族 [01 章](../01-近五年创新.md)主线 A)

## ✨ 这支最美的一个事实

**学科分类体系不是地图,是分蛋糕的刀**——GB/T 13745 这样的分类表
决定预算切块、学位点、职称序列、期刊归类;反过来,科学前沿年年越界。
**描述知识的树与分配资源的树是同一棵树**——所以每次学科目录修订都是
一次利益再分配,"交叉学科"每次都是谈判出来的新格子。

## 假设与依赖

- 体系可分解假设:能力可拆要素、结构可画图——分解方式本身携带立场;
- 形态演化假设:组织形态沿"复杂度上升"单向演化——小科学的再生
  (个人计算/自媒体时代)提供反例;
- 依赖 [讲透科学计量学](../讲透科学计量学)的结构测量。
