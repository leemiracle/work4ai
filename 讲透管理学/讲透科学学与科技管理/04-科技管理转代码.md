# 04 · 科技管理转代码:把指标、评议与组合装进生产

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角)。

---

## 开篇:别的分支在"翻译定理",本分支在"铺制度"

理论学科转代码,是把纸面结论翻译成算法;本家族转代码,
是把制度装进**每天运行的生产系统**——投稿系统里跑着评议流程,
机构知识库里跑着开放合规,评估平台跑着指标管道。
本学科的"制度"如果不跑在系统里,就只剩文件柜里的一份文档。

所以本章的问题不是"能不能转"(大半能),而是"**怎么转得可信**":
指标要防口径漂移,评议要防利益冲突,模拟要防被当成判决。
**可信性工程**取代算法难度成为主战场——这句话在
[管理计量学 04 章](../讲透管理计量学/04-管理计量学转代码.md)同样成立,
但本家族多一层:系统承载的是**学术生涯**,错误的代码化制度会直接写进一代人的简历。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 本家族概念 | 代码化身 | 备注 |
|---------|---------|------|
| 指标口径 | 指标字典(语义层):弗拉斯卡蒂字段+版本+负责人 | 口径的字典化是跨机构可比的工程前提(03 章家底表) |
| 文献计量计算 | 引文表→IF/FWCI/h/被引分布→共被引聚类 | 纯组合计算;**输出必须带分布与学科归约**(莱顿纪律) |
| 审稿人匹配 | 利益冲突筛查(合作/同机构/竞争关系图)+负载均衡 | 匹配=图上的过滤问题;CoI 图的完备性是天花板 |
| 评议流程编排 | 状态机:初筛→评审→汇谈→决定,全链留痕 | 制度即工作流;时序数据反哺评议研究 |
| 评议制度沙盘 | 蒙特卡洛模拟(本家族实验) | 制度参数(噪声/偏置/录用率)的事前试验场 |
| 开放科学合规 | DMP 模板校验、FAIR 自检、DOI/ORCID 对账 | 低难度高价值;防"合规=填表"的异化靠指标设计,不靠代码 |
| 资助组合看板 | 预算-工具格-配比的可视化与情景推演 | 组合结构(03 章引擎 2)的仪表盘 |

**转不动/只能半转(红色区)**:

1. **科学价值的判断**:什么题值得做——评议的"同行主权"核心无法算法化;
   AI 辅助评分(01 章主线 A)只能做初筛与异常提示,决定权留人。
2. **资助优先级**:学科之间怎么切蛋糕是**政治+认识论**的混合判断;
   代码供情景(如果预算+10% 给谁),不供答案。
3. **诚信裁定**:调查与裁定是程序正义问题,代码只做取证
   (图像筛查、文本相似度、数据核验)。
4. **指标的"该不该用"**:反身回路(03 章第三根梁)的治理是管理层决策——
   仪表盘只能报警,不能改方向盘。

**边界的一句话**:绿色区负责**算得对与跑得动**,红色区负责**判得公**——
本家族的事故几乎全在越界:把绿色区的输出(分数)当成红色区的答案(裁决)。

## 二、代码走廊清单(四条走廊,每条=对象→数据结构→算法→真实系统)

### 走廊 1:文献计量(从引文表到指标与地图)

```
原始引文表 (citing→cited, 年份, 学科) ──▶ 指标计算层(IF/FWCI/h/被引分布)
        │                                        │
        └──清洗(自引策略/文献类型过滤)            └──▶ 共被引/耦合聚类 ──▶ 学科地图
                                                输出纪律:指标必带分布+归约方案
```

- **对象→结构**:引文数据=有向多重图;指标=图上的聚合量;
  学科地图=聚类(共被引/耦合)的连通结构。
- **算法层**:指标计算全是排序与计数;FWCI 要学科-年份归约表;
  聚类可用 Louvain 类社区发现(工程上直接用图库)。
- **真实系统**:引文数据库(商用与开放)、机构评估平台、学科画像报告。
- **莱顿防御工事**(本走廊的灵魂):①报中位数不报均值(右偏,02 章 §一);
  ②机构层结论锁死在机构层(生态谬误);③自引与引用窗口的策略**显式声明**。
  口径本体与统计方法的上游:[统计学宇宙·科技统计](../../讲透统计学/讲透科学技术统计学/)。

### 走廊 2:指标合成(从口径到仪表盘)

```
口径字典(Frascati 字段+版本)──▶ 采集管道(报表/爬取/对账)──▶ 指标计算
   │                                                      │
   └──双跑期(新旧口径并行)                                  └──▶ 投入-产出-影响链看板
                                                        (影响段只标注不归因)
```

- **对象→结构**:指标=带元数据的计算列(03 章构造文档的数据库化);
  影响链=分层看板,**影响段强制灰显**(02 章"链上读不出值不值")。
- **算法层**:对账(报表 vs 数据库的双源校验)、PPP/不变价折算、
  时序对齐;无高深算法,全是口径纪律。
- **真实系统**:政府科技统计平台、大学科研管理驾驶舱、国际序列(OECD MSTI/NSF SEI)。
- **性能工程要点**:批处理负载、正确性苛刻——报表错一个数,
  上层政策文件全错;管道要**可追溯**(每个数能回查到源记录)。

### 走廊 3:评议模拟(从制度参数到沙盘)

```
制度参数(审稿人数 R/噪声 σ/偏置 b/录用率 α)──▶ 论文总体生成(质量分布)
        ──▶ 蒙特卡洛评议 ──▶ 录用决定 ──▶ 统计读数(效度/一致性/阵营差)
用途: 制度设计的事前试验场(多审稿人?双盲?抽签?)——不是对任何真实评审的复算
```

- **对象→结构**:评议=随机函数(质量→分数),制度=该函数的参数组;
  决策=阈值截断。结构简单,结论全靠**大数定律**。
- **算法层**:本家族 `experiments/peer_review_bias.py` 全纯标准库:
  Part 1 多审稿人平均降噪;Part 2 系统性偏置不因平均而消失;
  Part 3 低录用率下噪声主导("拒稿≠质量差")。
- **真实系统**:评审政策的研究支撑(评议改革的效果估计)、
  编辑部的流程设计演练;红队演练"新指标发布前先沙盘"。
- **防御工事**:模拟结论是**制度层**的统计性质,禁止用于个体申诉
  ("我被拒是噪声"不成立——那是把总体结论读成个体判决)。

### 走廊 4:资助组合(从申请池到分配结构)

```
申请池(评分+预算+风险标签)──▶ 分配规则(择优/配额/抽签试点)──▶ 组合
        │                                                      │
        └──红队:这个规则会被怎么"合规地"优化?                    └──▶ 多样性指标(集中度/探索占比)
```

- **对象→结构**:组合=预算在(项目×工具格)上的分配矩阵;
  多样性=分配的集中度(如 HHI)与探索/利用占比。
- **算法层**:约束分配(预算、学部配额、单笔上限)——
  线性规划够用(上游 [运筹学](../../讲透数学/讲透运筹学/));
  抽签=过线集合内的均匀抽样。
- **真实系统**:资助机构的分配决策支持、科研管理部门的年度预算推演。
- **组合纪律**:集中度约束(反马太:同一 PI 份额上限)、
  容错预算(允许失败率)、跨学科通道(分类体系的刀口外留口,03 章引擎 2)。

## 三、工程师落点(评估平台与科研基础设施)

| 落点 | 内容 | 为什么是工程问题 |
|------|------|----------------|
| **评审系统** | 投稿-匹配-评审-决定的状态机;CoI 图谱;负载均衡 | 匹配质量决定评议质量;CoI 图的完备性是天花板——数据治理问题不是算法问题 |
| **机构知识库/CRIS** | 成果、项目、人员的全息记录;FAIR 合规;DOI/ORCID 对账 | 机构评估的数据地基;元数据一致性是永恒的主战场 |
| **评估平台** | 指标字典+莱顿式输出纪律+版本留痕 | 口径漂移是第一大事故源;字典=口径的单向数据流(复用计量学走廊 1 的思路) |
| **开放科学设施** | DMP 校验、数据仓储、预印本互联 | 合规的摩擦要降到"顺手就合规",否则必被绕过 |
| **撤稿与诚信工具** | 图像筛查、文本相似度、异常合作网络探测 | 取证自动化,裁定留人(红色区边界) |

**性能工程的分工观**:走廊 1 是**大规模图计算**(离线、吞吐优先);
走廊 2 是**批处理管道**(正确性优先);评审系统是**低延迟表单+匹配服务**;
走廊 3/4 是**蒙特卡洛/优化沙盘**(弹性算力)。四类负载别用同一套架构伺候。

## 四、可机械化的检验仪式(把本家族用成瑞士军刀)

遇到任何科研制度/评估体系,做三问:
1. **指标问**:每个数字的口径字典在哪?版本几?分布报了吗(还是只报了均值)?
2. **评议问**:谁评的?盲不盲?CoI 怎么筛的?决定里多少是噪声(沙盘跑过吗)?
3. **组合问**:钱在工具格上怎么配?集中度有约束吗?跨学科留口了吗?

三问过完,制度的骨架就裸露了——剩下的才是真正的难点(价值判断与政治)。
