# 科学学与科技管理思维技能卡(讲透科学学与科技管理 · GB/T 63035)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **建制类**:科学共同体、默顿规范、马太效应、优先权、无形学院、大科学、后学院科学
- **政策类**:科研资助、科技政策、使命导向、基础研究投入、研发强度、有组织科研
- **指标类**:影响因子、h 指数、FWCI、引文分析、科学计量、科研评估、学科排名、DORA
- **评议类**:同行评议、审稿、拒稿、录用率、双盲、利益冲突、评审改革
- **治理类**:科研诚信、撤稿、论文工厂、开放科学、FAIR、数据共享、预注册
- **管理类**:科研项目全周期、经费管理、成果转化、技术转移、科研团队管理

## ② 核心思维模式(这个分支怎么想问题)

1. **建制化**:科研现象先看奖励结构——行为是共同体奖励的影子(规范×优先权×马太)
2. **链式读数**:科技数字先定位链段(投入/过程/产出/影响)——影响段时滞 5-10 年,链上读不出归因
3. **反身性警报**:指标一旦挂资源就被职业解题者反向优化——每个指标自带攻击面,要配护栏与轮换
4. **噪声解耦**:顶刊拒稿/基金落选先看基率与噪声,再看质量——制度统计结构≠个人判决
5. **组合思维**:资助=不确定性下的组合设计——工具格(项目/机构/人才/设施)×配比(探索/利用)×集中度约束
6. **总体-个体锁**:组群层指标结论锁死在组群层(生态谬误),个体结论另起评议证据

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 默顿规范分析(CUDOS/PLACE 对照) | 判断一条制度在奖励什么、惩罚什么 |
| 投入-产出-影响链(logic model) | 拆解任何资助计划的指标体系与归因断点 |
| 弗拉斯卡蒂口径(GERD/FTE/三分类) | 一切投入侧数字的口径底账 |
| 指标病理分型(目标置换/口径博弈/择刊错位/度量排除) | 诊断考核与评估指标的 Goodhart 病 |
| 评议沙盘(蒙特卡洛:R/σ/b/录用率) | 制度设计事前试验:多审稿人、双盲、抽签的效果 |
| 引文分析+莱顿纪律(报分布/锁层级/声明口径) | 读文献计量指标不踩生态谬误 |
| 资助组合分析(工具格+集中度 HHI+容错预算) | 体检任何科研预算的分配结构 |
| 政策工具选型(资助/税收/采购/规制) | 把"支持创新"翻译成可执行工具 |
| 使命倒排(使命→里程碑→评议标准) | 设计与审查使命导向计划 |

## ④ 常见误区与禁忌

- **把影响因子用于个人评价**:期刊层均值+右偏分布+生态谬误三重罪(DORA 的立论)
- **把"拒稿/落选"读成质量判决**:低录用率+审稿噪声下,决定方差大头是噪声
- **多审稿人当万能药**:平均只降噪声,不除利益冲突等系统性偏置(实验 Part 2)
- **影响段提前收割**:成果发表当年就要"社会影响",链的时滞结构不允许
- **新指标裸奔上线**:每加一个指标加一寸攻击面——先红队演练再发布
- **单一指标重赏**:切片发表/引文堆叠的机器;指标要成组+护栏+定期回测
- **把模拟结论用于个体**:沙盘输出是制度层统计性质,不是个案平反依据
- **评估对象当被动数据源**:科学家会研究评估者——反身回路必须计价
