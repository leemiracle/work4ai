# 讲透科学计量学 · 6303540:仪表盘,以及它的读法

> **定位句**:这支管"**读数**"——普赖斯-加菲尔德传统:指数增长律、洛特卡-齐普夫幂律、
> 引文网络、期刊指标、科学地图、替代计量;以及这些读数**怎么用才不闯祸**
> (影响因子病理、DORA/莱顿纪律)。**口径与统计本体在统计学宇宙**(分工见"关系"),
> 本支是它的**政策与管理化身**:仪表盘装进资助、评估、聘岗驾驶舱之后的一切。
> GB/T 13745 63035 · 三级 **6303540 科学计量学**。家族:[讲透科学学与科技管理](../README.md)

## 诞生

- **谁/何时**:Lotka(1926)作者产量幂律;Price《小科学,大科学》(1963)立指数增长律;
  Garfield 1964 年上线 SCI
  (灵感来自法学界谢泼德引证);1978 年《Scientometrics》创刊,学科建制化;
  Hirsch(2005)提出 h 指数;2012/2015 年 DORA 与莱顿宣言开启"负责任指标"时代。
- **因什么问题**:①科学这台机器的产出与结构能不能测(能:幂律/指数/网络)
  ②测出来的数字能不能用于评价(另一回事——本支后半部的主战场)。

## 核心问题

**已解决**:
- 三大经验律:指数增长(普赖斯)、产量幂律(洛特卡)、引文网络的连通结构(Price 1965:学科抱团成区)
- 指标族谱成文:数量类(论文/专利)、引用类(IF/FWCI/h)、结构类(共被引)、替代类(下载/提及)——边界清楚
- 指标病理学:右偏分布→均值失真;期刊层≠论文层(生态谬误);反身性→指标挂资源即被优化(家族 [02 章](../02-语言特征.md) §二)

**未解决/深水区**:
- **质量本体**:引文之外,"科学质量"没有共识测度;突破性/颠覆性指标
  (如 CD 指数)效度仍在检验
- AI 时代的新计量:作者数膨胀、AI 生成文本占比、引用行为机器化——经验律是否在漂移(家族 01 章检索锚)
- 指标组合理论:多指标怎么组才不放大博弈面(与管理计量学共享的开放问题)

## ✨ 这支最美的一个事实

**科学家没投过票,但引文就是选票**——加菲尔德把脚注聚合成网,无形学院
第一次成为可指认的连通分量;普赖斯顺着网看出科学的"新陈代谢"(文献老化与
半衰期)。**一套无人设计的选票系统,六十年不断地给整个科学界画像**——
社会科学里罕见的自组织测量装置。

## 假设与依赖

- 引用=影响代理假设:引用行为大体反映知识使用(礼貌引/互引/负引是噪声项)——
  挂上资源后噪声项变成策略项(反身性);
- 数据库覆盖假设:收录即世界——收录策略先于一切指标决定谁能被看见;
- **分工依赖**:口径与统计本体住 [../../../讲透统计学/讲透科学技术统计学/](../../../讲透统计学/讲透科学技术统计学/)(三支:R&D 统计与科技指标/科学计量学与引文分析/科研评价与开放科学指标);
  本支管读数的**建制使用与后果**——两侧互链不重叠。
