## 三、特征速查

- 泰勒到德鲁克的思想编年 → 管理思想史
- 组织理论/行为科学/系统管理 → 管理理论
- 管理中的定量模型 → 管理计量学(上游:数学宇宙)
- 行业管理(各业入有关学科) → 部门经济管理(归属型)
- 区域规划/城市管理 → 区域经济管理
- 科研管理/创新体系/科学计量 → 科学学与科技管理
- 生产/财务/营销/人力资源部内管理 → 企业管理
- 政府治理/危机管理/行政管理 → 公共管理
- 物流/战略/质量管理/信息系统 → 管理工程
- 招聘/绩效/人才学 → 人力资源开发与管理
- 预测学/技术评估 → 未来学
- ESG/可持续战略 → 可持续发展管理
