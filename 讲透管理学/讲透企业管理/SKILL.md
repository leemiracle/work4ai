# 企业管理思维技能卡(讲透企业管理 · GB/T 63040)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **职能类**:生产管理、经营管理、财务管理、成本管理、劳动人事、技术管理、
  营销管理、物资管理、设备管理、质量管理——企业内部职能怎么建制运转
- **价值链类**:价值链、利润池、微笑曲线、议价能力、进入壁垒、外包还是自制、
  产业链哪个环节赚钱
- **系统类**:ERP、MRP、BOM、S&OP、MES、上系统、主数据、账实一致
- **运营类**:排产、库存、安全库存、订货批量、缺货、牛鞭效应、产能、节拍、
  看板、准时化、七大浪费
- **财务成本类**:预算、标准成本、差异分析、本量利、盈亏平衡、作业成本、
  杜邦分析、ROE 分解
- **质量设备类**:控制图、SPC、过程能力、PDCA、六西格玛、TPM、OEE、
  MTBF、预测性维护

## ② 核心思维模式(这个分支怎么想问题)

1. **价值链化**:看到任何企业先拆活动链,问利润池沉在哪环、凭什么
  (议价能力×进入壁垒——分配是结构变量)
2. **一树多读**:BOM/KPI 树等可构造对象让多职能读写同一数据——
  能统一数据结构的问题,别用开会解决
3. **库存即膏药**:任何缓冲(库存/缓存/冗余)先问它掩护什么根因;
  能修根因就别加缓冲
4. **追过程不追人**:波动先分共同原因 vs 异常原因(控制图之眼),
  再决定是改系统还是查个案
5. **各果最优≠树最优**:每个 KPI 都达标而整体受损时,查分解树丢掉的
  互补性与互动
6. **职能 vs 流程**:部门摩擦先问是专业化的合理代价,还是流程错配的病
  ——百年母题只有情境匹配,没有定理答案

## ③ 工具箱(方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 价值链 schema+微笑指数(实验) | 判断壁垒/议价变化后利润池向哪迁移;自制-外包-定位决策的沙盘 |
| EOQ Q*=√(2DS/H) | 批量权衡的第一近似(订货成本 vs 持有成本) |
| 报童临界分位数 Cu/(Cu+Co) | 单期不确定备货(季节品/一次性资源) |
| (s,Q)/(s,S) 策略+安全库存 | 持续补货+服务水平目标的库存策略 |
| BOM 展开+提前期偏移(MRP 核心) | 由成品需求倒推零部件计划;依赖树的排期同构 |
| SPC 控制图(±3σ+判异规则) | 区分正常波动与异常;告警/监控的基线设计 |
| 标准成本差异=价差+量差 | 把"超了"切成可指派的责任 |
| 杜邦分解 ROE=净利率×周转×杠杆 | 把职能 KPI 钉到同一棵树上做归因 |
| 本量利(CVP)/盈亏平衡 | 定价、产量、降本决策的速算骨架 |
| OEE=可用×性能×良率 | 区分"设备很忙"与"设备有效"(六大损失) |
| Stage-Gate 门径 | 把高不确定项目的继续/终止决策切碎 |
| STP+4P | 营销决策的通说骨架(细分-目标-定位→组合) |

## ④ 常见误区与禁忌

- **拿微笑曲线当宿命论**:分配由结构决定,但结构可被创新改写
  (实验断言②);同理,别拿"最佳实践"当处方——那是别家企业史的结果
- **库存一刀切**:财务语言说库存是资产,TPS 语言说是浪费——先定口径
  (成本目标 vs 韧性目标,01 章主线 A)再谈压不压
- **KPI 单指标强激励**:考核什么就得到什么;不可测任务必被挤掉
  (多任务扭曲,机制见[../讲透管理理论/](../讲透管理理论))
- **ERP 当软件项目**:ERP 的难点在主数据与流程咬合(互补性),
  不在代码——03 章 §五是失败原因清单
- **控制图误用**:控制限必须用稳态期数据;拿含异常的全历史估 σ,
  图就废了
- **仿真当现实**:利润池/库存仿真的价值在单调性与方向,不在绝对数值;
  参数靠标定的模型禁止单点结论
