# 讲透技术管理 · 知识的职能:把不确定性装进管线

> **定位句**:这支负责"**技术**"——研究与开发管理、技术转移与引进、
  技术创新组织、知识产权、新产品开发流程(门径):十大职能里
  唯一以"不确定性"为原料的一支,与经营管理(以确定性为前提)构成
  一对张力。
> GB/T 13745 63040 企业管理 · 三级 **6304035 技术管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:熊彼特 1912/1942(创新=生产要素的重新组合;创造性破坏);
  1958 北极星导弹 PERT(大型研发项目的网络计划工具);
  Cooper 1986 门径管理 Stage-Gate(新产品开发分阶段决策);
  Kline & Rosenberg 1986 链式创新模型(非线性:设计-反馈-研究循环);
  Chesbrough 2003《开放式创新》(研发边界外置)。
- **因什么问题**:①研究十年、产品两年,两套时钟怎么装进一个组织
  (两时钟之问);②模糊的创意怎么变成可决策的项目(管线之问);
  ③自研、买技术还是合作(边界之问)。

## 核心问题

**已解决**:
- 门径流程:创意→概念→开发→验证→上市的"继续/终止"门决策
- 技术路线图:技术-产品-市场三层时间对齐(跨职能共同语言)
- 知识产权的制度工具箱(专利/商业秘密/许可)

**未解决/深水区**:
- 创新的度量:专利数≠创新力(指标与目标错位)
- 探索(长期研究)与利用(产品迭代)的资源分配悖论
  (March 框架,理论侧见 [../../讲透管理理论/](../../讲透管理理论))
- 开放与保护的边界:生态位决定开放度,无一般解

## ✨ 这支最美的一个事实

**每道门都是一次期权行权**:门径管理把"要不要继续"切碎到每个阶段——
小额投入买下一阶段的"继续权",信息越多行权越准。
**实物期权的思想,在 1986 年的流程图里已经画好了**;研发预算的谈判,
本质是买期权还是买确定性的谈判。

## 假设与依赖

- 不确定性可分阶段削减(买到决策纪律,付出好创意死在早期门)
- 技术可沿路线图对齐(买到协同,付出路线锁死)
- 国家创新体系与科技政策侧归兄弟家族
  [../../讲透科学学与科技管理/](../../讲透科学学与科技管理)
  (本支只管企业内部管线)
