# 讲透劳动人事管理 · 人的职能侧:岗位、薪酬与劳动关系

> **定位句**:这支负责"**人(职能侧)**"——岗位分析与设计、招聘录用、
> 薪酬考勤、培训、劳动关系(合同/争议/协商):把"人"翻译成组织可运转的
> 结构化对象;它管**流程与事务**,人的资本化与测量归横切层兄弟家族。
> GB/T 13745 63040 企业管理 · 三级 **6304030 劳动人事管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:科学管理时代的企业人事办公室建制化(1910s-20s;
  福特社会学部管理"5 美元日薪"的家访条款是早期标本,通说);
  人际关系学派梅奥 1924-32 霍桑实验(把"人"带回管理议程);
  1980s 前后"人事管理"更名"人力资源管理"(战略化的语言事件);
  Ulrich 1997 三支柱(COE/HRBP/SSC)是共享服务化的组织版(归横切层)。
- **因什么问题**:①活儿该怎么描述、给多少工钱(岗位之问);
  ②人和企业的关系用什么规则维系(劳动关系之问);
  ③考核怎么做到既分得清又不打架(绩效之问)。

## 核心问题

**已解决**:
- 岗位分析:职责-汇报-任职资格的结构化描述(人事全部流程的起点)
- 劳动关系制度化:合同/工时/社保/争议处理的规则闭环
- 薪酬结构:岗位价值×能力×绩效的三元组合成为通说骨架

**未解决/深水区**:
- 绩效评估的评分者偏差与强制分布之争
- AI 进驻人事的公平边界(算法简历筛选的歧视传导——
  横切层实验 [../../讲透人力资源开发与管理/experiments/hiring_fairness.py](../../讲透人力资源开发与管理/experiments/hiring_fairness.py)
  有桌面版)
- 研究-实践鸿沟(01 章主线 C):量表精致与系统规则的裂缝

## ✨ 这支最美的一个事实

**一页岗位说明书翻译了"人"**:把一个人要做的事拆成
职责/权限/汇报关系/任职资格四格——招聘、定薪、考核、培训全部从这页纸
出发。人事管理的工业化,始于把"干活的人"变成**可描述、可定价、可比较的
对象**(代价:把人当对象的伦理张力,正是横切层家族的首页问题)。
