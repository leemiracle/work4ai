# 讲透成本管理 · 成本的职能:从算得清,到管得住,再到设计得出

> **定位句**:这支负责"**成本**"——标准成本与差异分析、本量利、
  作业成本法(ABC)、目标成本法、质量成本:财务数字与现场行为之间的
  翻译科,专治"成本算得清却管不住"。
> GB/T 13745 63040 企业管理 · 三级 **6304025 成本管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:1910s-20s 标准成本制(与科学管理配套:定额+差异归因);
  本量利分析与盈亏平衡的图式化(1930s 经济学-会计合流,通说);
  丰田 1960s 目标成本/成本企划(市场价−目标利润=允许成本,倒逼设计);
  Cooper & Kaplan 1988 作业成本法(制造费用按"作业动因"分摊,
  修正机器小时一刀切的失真);朱兰质量成本(预防+鉴定+内损+外损)。
- **因什么问题**:①成本为什么超了、超在谁身上(归因之问);
  ②卖多少才不亏(决策之问:本量利);
  ③间接费用占比越来越高,传统分摊为什么算出"赔钱的产品拼命造"(失真之问)。

## 核心问题

**已解决**:
- 差异分解恒等式:总差异=价格差异+数量差异,不重不漏可指派
  (家族 02 章美之时刻的原产地)
- 本量利:收入线与成本线交出盈亏平衡点,定价/产量/降本决策的速算骨架
- ABC:成本动因取代单一分摊基准,产品成本画像大幅修正

**未解决/深水区**:
- 成本信息的行为后果:知道精确成本反而诱发扭曲定价/砍长线产品
- 目标成本的组织落地(跨职能协同,依赖互补性,家族 03 章 §五)
- 数字化下成本动因的自动识别(01 章方向锚)

## ✨ 这支最美的一个事实

**一个恒等式结束一场吵架**:"这月成本超了 37 万"——
总差异≡(实际价−标准价)×实际量+(实际量−标准量)×标准价:
价差归采购,量差归车间,**代数恒等、不重不漏**。
责任会计的全部文明,是把争吵变成分工的一道恒等式。
