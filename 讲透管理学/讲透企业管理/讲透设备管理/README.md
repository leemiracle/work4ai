# 讲透设备管理 · 能力的职能:维护、可靠性与更新

> **定位句**:这支负责"**能力**"——设备的选择与购置、使用与维护
> (事后/预防/预测)、TPM、可靠性工程(MTBF/MTTR/OEE)、更新决策:
> 生产能力的守护科;一支与性能工程深刻同构的职能(维护策略=系统运维)。
> GB/T 13745 63040 企业管理 · 三级 **6304050 设备管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:工业革命以来"坏了再修"的事后维修为默认;
  1950s 前后预防维修建制化(定期检查/更换——苏联计划预修制与美国
  预防维护并行,通说);日本 JIPM 1971 提出 TPM 全员生产维护
  (中岛清一:维护责任分给操作者,目标"故障为零");
  1960s-80s 可靠性工程成熟(MTBF/故障树/RCM 以可靠性为中心的维修);
  1990s- 状态监测与预测性维护(传感器+诊断)。
- **因什么问题**:①什么时候修最划算(维护策略之问);
  ②设备的"忙"与"有效"怎么分开(效率之问——OEE);
  ③这台机器还值不值得留(更新之问——经济寿命)。

## 核心问题

**已解决**:
- 维护策略三分与经济权衡:事后(便宜但停机)/预防(稳但过度)/
  预测(准但贵)——期望成本模型可算
- OEE=可用率×性能率×良率:六大损失把"设备很忙"与"设备有效"分开
- TPM 的组织创新:操作者自主维护+专业维修分工

**未解决/深水区**:
- 预测性维护的数据门槛:故障标签稀缺(设备好好的=没数据)
- 维护与生产的排程冲突(停机窗口的博弈)
- 更新决策的税务-技术双重视角(折旧政策扭曲真实经济寿命)

## ✨ 这支最美的一个事实

**忙碌≠有效**:一台 24 小时连轴转的设备,扣除计划停机、故障停机、
换型调整、降速空转、启动损耗与不良返工,OEE 常常只剩五六成。
**三个损失率相乘(不是相加)的残酷**:每项 90% 的优秀,
乘起来只剩 73%——"每一环都不错"的系统可以整体平庸,
这是乘法结构给所有管理者上的课(家族 02 章 §二的复式逻辑近亲)。
