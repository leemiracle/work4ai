# 讲透生产管理 · 转换的职能:把投入变成产出的现场学

> **定位句**:这支负责"**转换**"——生产计划(主生产计划 MPS/排产)、
> 生产组织(流水线/单元/项目式)、生产控制(进度/在制品/瓶颈):
> 企业全部职能里离物理世界最近的一支,精益思想的原产地。
> GB/T 13745 63040 企业管理 · 三级 **6304010 生产管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:泰勒 1911《科学管理原理》(标准作业与时间研究);
  福特 1913 移动流水线+1914"5 美元日薪"(大规模生产定型,家族 00 章故事);
  大野耐一 1950s-70s 丰田生产方式(准时化/自働化/平准化);
  Goldratt 1984《目标》(约束理论 TOC:瓶颈定节拍)。
- **因什么问题**:①怎么把活干得又快又省(效率之问);
  ②多品种小批量怎么不牺牲规模(柔性之问——丰田对福特的反题);
  ③瓶颈在哪、系统真正能出多少(产能之问)。

## 核心问题

**已解决**:
- 大规模生产的效率范式(流水线:单位成本数量级下降)
- 精益的浪费语言(七大浪费:过量生产/等待/搬运/过度加工/库存/动作/不良)
- 瓶颈聚焦:非瓶颈的改善不改变产出(TOC 第一定律式结论)
- 计划分层:主生产计划 MPS→物料需求(接 MRP)→车间排产

**未解决/深水区**:
- 规模与柔性的权衡无定理解(单元制造/延迟差异化都是部分解)
- 车间调度最优解 NP 难(工程实践=启发式+滚动重排)
- 需求波动下的产能决策(韧性 vs 效率,01 章主线 A 的当代版)

## ✨ 这支最美的一个事实

**减库存反而提升质量**:库存是掩盖问题的膏药——设备故障、换型太慢、
来料不良全被缓冲住,于是永远不修;看板拉动把缓冲拿掉,问题当场暴露
(家族 00 章反直觉 2 的原产地)。**拆保险,反而更安全——因为保险的
真正功能是延迟暴露病因。**
