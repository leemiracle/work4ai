# 讲透财务管理 · 钱的职能:筹资、投资与资金的进出场

> **定位句**:这支负责"**钱**"——筹资(股权/债权)、投资决策(NPV/IRR)、
> 营运资金管理、利润分配与财务报表:企业这台机器的"血液循环科",
> 也是十大职能里最早被数学化的一支(1914 年就有杜邦分解)。
> GB/T 13745 63040 企业管理 · 三级 **6304020 财务管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:唐纳森·布朗 1914 前后在杜邦发明投资回报率分解
  (ROE=净利率×周转率×杠杆),后随斯隆进入通用成为事业部考核的标尺
  (管理史通说);Modigliani & Miller 1958(资本结构无关性定理,公司金融
  的公理化起点);Markowitz 1952 与 Sharpe 1964(组合与 CAPM);
  WACC/自由现金流估值体系 1980s-90s 咨询工业化。
- **因什么问题**:①钱从哪来、配到哪去(资本之问);
  ②一个项目该不该投(投资之问——货币时间价值);
  ③钱在体内怎么转(营运资金之问:应收/存货/应付的三角)。

## 核心问题

**已解决**:
- 货币时间价值与 NPV 准则(教科书共识:NPV 最大化)
- 杜邦分解:把整家企业的职能装进一行等式
- 资本结构理论(MM 无关性+税盾修正:杠杆有边界)
- 三张报表的勾稽闭环(利润表/资产负债表/现金流量表)

**未解决/深水区**:
- 不确定下的资本预算:折现率怎么定(风险溢价之谜)
- 实物期权的估值落地(战略柔性难进报表)
- ESG/气候因素对资本成本的定价(01 章方向锚;
  跨家族见 [../../讲透可持续发展管理/](../../讲透可持续发展管理))

## ✨ 这支最美的一个事实

**一行等式管理整家企业**:ROE=净利率×总资产周转率×权益乘数。
净利率背后是成本/质量/定价(成本管理与营销支),
周转率背后是库存/设备/生产(物资/设备/生产支),
杠杆是财务自己的工具——**十个职能的 KPI 全部挂在这棵三叉树上**
(家族 03 章构造 3 的原型)。
