# 讲透物资管理 · 流入的职能:采购、库存与供应商

> **定位句**:这支负责"**流入**"——采购管理、库存控制、仓储物流、
> 供应商管理、MRP:价值链主线的第二棒(技术→**物资**→生产);
> 一门被一个平方根公式奠基、又被一台信息系统重写的职能。
> GB/T 13745 63040 企业管理 · 三级 **6304045 物资管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:Harris 1913 EOQ 公式(库存论第一文:订货成本与持有成本
  的平方根平衡);Orlicky、Wight 等 1960s-70s 在 IBM/APICS 推动物料
  需求计划 MRP(用 BOM 把独立需求转相关需求);1980s JIT 采购与
  供应商伙伴关系(丰田系);1990s 供应链管理(SCM)把视角从仓库扩到全链。
- **因什么问题**:①一次订多少、什么时候订(批量之问);
  ②成品的料怎么倒推(相关需求之问——MRP 的立足点);
  ③链上的不确定怎么应对(韧性之问——后疫情主导题)。

## 核心问题

**已解决**:
- EOQ:一个平方根同时否定"一次订光"和"零库存"两个极端
- ABC 分类:少数物料占多数金额,管理精力聚焦少数
- MRP:BOM 展开把"该买什么料"变成可计算问题(家族 03 章构造 2)

**未解决/深水区**:
- 牛鞭效应:各环节独立预测+批量订货放大上游波动(信息共享 vs 激励
  的双处方,至今两难)
- 韧性 vs 效率的权衡:库存是成本还是保险,取决于你信哪个目标函数
  (01 章主线 A:Culot 2024)
- 全球采购的风险定价(断链概率没法从历史学)

## ✨ 这支最美的一个事实

**一个 1913 年的平方根管了一百年**:Q*=√(2DS/H)——
订货成本(分子)越大越该多订,持有成本(分母)越大越该少订,
平衡点是两者的几何平均而不是折中一半。**EOQ 的真正遗产不是公式,
是"库存是两类成本的权衡"这个思维方式**——今天一切缓冲设计
(缓存/队列/安全库存)仍在它的延长线上(家族 04 章落点 2)。

## 假设与依赖

- 需求与提前期可知(买到最优批量,付出波动下的失配→安全库存补丁)
- BOM 与库存数据准(买到联动,付出主数据治理成本——账实相符是
  MRP 能跑的前提,不是结果)
- 库存论/排队论的严格数学住
