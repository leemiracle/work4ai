# 讲透经营管理 · 统筹的职能:把战略翻成一张所有职能都读的账

> **定位句**:这支负责"**统筹**"——经营计划、全面预算、产销协同(S&OP)、
  经营分析与绩效体系:十大职能的"总调度",专治"各职能各自最优、
  企业整体受损"的合成谬误(家族 00 章悬而未决清单的常驻项)。
> GB/T 13745 63040 企业管理 · 三级 **6304015 经营管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:法约尔 1916(计划与预算进入管理语言);斯隆 1920s
  ("分散经营+集中控制":总部靠政策、财务数字与协调管事业部,
  家族 00 章故事);德鲁克 1954《管理的实践》(目标管理 MBO);
  平衡计分卡 Kaplan & Norton 1992(财务之外补客户/流程/学习三维);
  S&OP 于 1980s 前后从产销会议演化为正式机制(Oliver Wight 一线,通说)。
- **因什么问题**:①多事业部/多职能的目标怎么对齐(统筹之问);
  ②钱和产能该配给谁(资源配置之问);
  ③销售要的与生产能做的怎么合流(产销协同之问)。

## 核心问题

**已解决**:
- 预算作为通说配置语言:战略→数字→责任中心→执行→差异分析闭环
- MBO/平衡计分卡:目标从财务单维扩到因果链多维
- S&OP 机制:单一数字计划(one number plan)约束销售/生产/采购同一口径

**未解决/深水区**:
- 预算的年度僵化 vs 市场月度变化(滚动预测/beyond budgeting 之争)
- 集权-分权的均衡无定理(斯隆式的永恒调节)
- 计划的"仪式化":预算沦为博弈筹码(隐藏产能、压低目标——
  委托代理视角见 [../../讲透管理理论/](../../讲透管理理论))

## ✨ 这支最美的一个事实

**一张预算表让十个职能说同一种话**:销售报量、生产报产能、采购报物料、
财务报钱——全部折算进同一张可以加减乘除的账。部门墙没有消失,
但争论从"谁的嗓门大"变成"哪个假设错"(家族 00 章母题的最便宜解药)。

## 假设与依赖

- 未来可计划(买到对齐与控制,付出僵化与环境失配的代价)
- 数字可信(买到可比性,付出博弈性报数——代理问题的复现)
- 组织愿意被一个口径约束(S&OP 失败的主因从来不是算法)

## 教材锚

- Kaplan & Norton《平衡计分卡》(1996,多维目标体系)
- Hope & Fraser《超越预算》(2003,僵化批判一线)
- 斯隆《我在通用的岁月》(1964,统筹事业部制的第一手记录)
