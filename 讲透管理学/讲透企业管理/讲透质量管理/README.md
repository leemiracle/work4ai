# 讲透质量管理 · 过程的职能:追过程,不追人

> **定位句**:这支负责"**质量**"——从检验(把关)到统计过程控制(管过程)
> 到全面质量管理(管体系)到六西格玛(管变异):唯一横跨全部九个职能的
> 保障支;一门由一张统计图改变命运的学科。
> GB/T 13745 63040 企业管理 · 三级 **6304055 质量管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:休哈特 1924 控制图/1931《制造品质量的经济控制》
  (±3σ 区分正常波动与异常);戴明 1950 起在日本讲学
  (管理十四要点+PDCA 循环);朱兰质量三部曲(策划-控制-改进)
  与质量成本;费根堡姆 1961 全面质量控制;石川馨 1960s 因果图+QC 小组;
  Crosby 1979 零缺陷;摩托罗拉 1986 六西格玛;1987 ISO 9001。
- **因什么问题**:①质量是检验出来的还是制造出来的(关口之问——
  检验只分好坏,不产生好);②正常波动与异常波动怎么分(变异之问——
  控制图的全部);③质量的成本算得清吗(质量成本之问)。

## 核心问题

**已解决**:
- SPC:把假设检验画成车间挂图;判异规则让操作工可执行
- 质量成本四分类(预防/鉴定/内部损失/外部损失):质量从道德变会计
- 体系化:ISO 9001 把"组织怎么保证质量"文件化、可审核
- 六西格玛的 DMAIC:变异缩减的项目化管理

**未解决/深水区**:
- 流程纪律(六西格玛)与探索自由(创新)的张力
- 感知质量 vs 符合性质量:符合标准≠顾客满意(期望管理是营销侧问题)
- 软件与 AI 产品的质量定义(无"标准件"可检——概率输出的质量语言
  在重构中,01 章方向锚)

## ✨ 这支最美的一个事实

**一张图把"追人"变成"追过程"**:1924 年休哈特在贝尔实验室画出
控制图——中心线±3σ 控制限,点在限内=共同原因(别动,动了更乱),
出限/违判异规则=异常原因(查!)。**管理者对波动的本能反应是问责,
控制图证明大多数波动是系统固有的**——责怪操作工改变不了正态分布,
改进过程才可以。戴明把这一课讲成日本质量革命的第一课
(编年见 [../../讲透管理思想史/](../../讲透管理思想史))。

## 假设与依赖

- 过程在统计受控状态下波动近似可估(买到判异依据,付出非稳态下的误判)
- 质量的"符合性"定义先行(买到可检,付出标准过时的盲区)
- 统计内核上游:[../../../讲透数学/讲透应用统计数学/](../../../讲透数学/讲透应用统计数学)
