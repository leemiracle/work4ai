# 讲透企业管理 · 企业职能层:把管理理论装进企业这台机器的十大职能

> **本质一句话**:企业管理=**管理学的"企业职能层"**——管理理论家族回答
> "组织为何存在、如何协调",本家族回答"**协调的机器具体怎么造**":把一家企业
> 沿价值链拆成生产/经营/财务/成本/劳动人事/技术/营销/物资/设备/质量十个职能,

> "职能制 vs 流程制"是本家族贯穿百年的母题。

## 一、家族树(GB/T 三级逐条落子,630 宇宙最大家族)

```
讲透企业管理/                 GB/T 三级「企业管理」十支
├── 讲透生产管理/       6304010——计划/排产/精益/约束(福特-大野-Goldratt 线)
├── 讲透经营管理/       6304015——经营计划/全面预算/S&OP 统筹(法约尔-德鲁克线)
├── 讲透财务管理/       6304020——筹资/投资/营运资金/报表(杜邦分析-MM 线)
├── 讲透成本管理/       6304025——标准成本/ABC/目标成本(科学管理-Cooper-Kaplan 线)
├── 讲透劳动人事管理/   6304030——岗位/薪酬/劳动关系(与人力资源家族横切互链)
├── 讲透技术管理/       6304035——研发管线/门径/开放式创新(熊彼特-Cooper 线)
├── 讲透营销管理/       6304040——STP/4P/品牌/渠道(Levitt-Kotler 线)
├── 讲透物资管理/       6304045——采购/库存/EOQ/MRP(Harris-Orlicky 线)
├── 讲透设备管理/       6304050——维护策略/TPM/OEE/可靠性(预防维修-TPM 线)
├── 讲透质量管理/       6304055——SPC/TQM/六西格玛/体系(休哈特-戴明-石川线)
└── (6304099 企业管理其他学科)   兜底,不设支,见 §五
```

> 十支的共同血统:**同一条价值链上的十种分工**——五支在主线(技术→物资→生产
> →营销+经营统筹),五支贴身保障(质量/设备/财务/成本/劳动人事)。
