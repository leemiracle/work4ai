# 讲透营销管理 · 需求的职能:从卖东西,到设计位置

> **定位句**:这支负责"**需求**"——市场调研、STP(细分-目标-定位)、
> 4P 组合、品牌与渠道、客户关系:企业面向市场的接口层;
> 微笑曲线右端(品牌/渠道)的经营者。
> GB/T 13745 63040 企业管理 · 三级 **6304040 营销管理**。家族:[讲透企业管理](../README.md)

## 诞生

- **谁/何时**:Smith 1956 市场细分;Levitt 1960《营销近视症》
  (卖的是钻孔不是钻头——从产品中心到需求中心);
  McCarthy 1960 4P 组合(产品/价格/渠道/促销);
  Kotler 1967《营销管理》(学科定型);Aaker 1991 品牌资产;
  1990s 关系营销与服务营销(Grönroos 等);2000s 数字营销/平台/直连。
- **因什么问题**:①卖给谁(细分与目标之问);
  ②在顾客心智里占哪个格子(定位之问);
  ③四个杠杆(产品/价/渠道/促销)怎么配(组合之问)。

## 核心问题

**已解决**:
- STP+4P 作为通说决策骨架(全部营销课的目录)
- 品牌作为信号资产:降低顾客的搜索与信任成本
- 渠道结构的通说分类(直销/分销/平台/直连)

**未解决/深水区**:
- 数字广告的效果归因(最后一触点之谜;增量效应难识别)
- 个性化与隐私的平衡(超个性化的伦理边界,01 章主线 B)
- 4P 在服务与平台情境的失效(人/过程/有形展示的 7P 修补)

## ✨ 这支最美的一个事实

**先切市场,再占心智**:STP 三步把"卖东西"变成"设计位置"——
细分(市场不是一块)/目标(我打哪块)/定位(顾客脑中的格子)。
**此后的一切营销决策(定价/渠道/创意)都只是这三步的展开**;
跳过 STP 直接做 4P,是营销浪费的第一大来源。

## 假设与依赖

- 市场可细分且段间可辨(买到聚焦,付出伪细分/错细分风险)
- 定位可在心智中建立(买到复购与溢价,付出改变定位极慢)
- 需求侧的经济学上游(消费者理论/产业组织)见
  [../../../讲透经济学/README.md](../../../讲透经济学/README.md)
