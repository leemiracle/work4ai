# 公共管理思维技能卡(讲透公共管理 · GB/T 63044)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **公共侧管理**:公共管理、行政管理、官僚制、科层制、文官/功绩制、POSDCORB、行政效率
- **服务侧**:政务服务、办事大厅、排队、一网通办、一站式、最多跑一次、兜底通道
- **价值侧**:公共价值、问责、回应性、公平、合法性、绩效预算、绩效指标扭曲
- **数字侧**:数字政府、电子政务、政府即平台、整体政府、算法行政、数字鸿沟、数字包容
- **危机侧**:应急管理、危机管理、突发事件、减缓-准备-响应-恢复、韧性、应急预案、危机沟通
- **比较侧**:新公共管理(NPM)、新公共服务(NPS)、治理(governance)、政府失灵、寻租

## ② 核心思维模式(这个分支怎么想问题)

1. **分配效应优先**:任何公共效率改进(线上化/合并/自动化),先问谁受益、谁被甩下、
   兜底通道在哪——均值改善与分布恶化可以同时发生(家族实验的断言)
2. **委托链计数**:看到公共服务先数委托层级(公民→立法→行政→一线),
   每加一层信息损耗一次、问责稀释一度
3. **口径切换**:同一个"好",企业口径(利润)与公共口径(公共价值)不是一把尺;
   看到效率主张先问哪个口径、牺牲了哪个对立构念(速度 vs 程序正义)
4. **四层塔定位**:听到公共部门的话,先定位它在法规/政策/程序/服务哪一层
   (效力、寿命、问责方式随之确定)
5. **Campbell 预检**:指标成为目标就不再是好指标——写 KPI 前先写 gaming 场景
6. **钟摆意识**:效率口径与公共价值口径约 20-30 年一摆(NPM→NPS→数字治理);
   每一摆救上次的失灵又造新失灵——今天的方案是钟摆的哪一格?

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| POSDCORB 七职能清单 | 检查任何行政改革提案的完整性(漏哪个字母,哪个字母变问题回来) |
| 穆尔战略三角(公共价值/合法性授权/运作能力) | 公共项目体检:最弱一角即下一次危机坐标 |
| 逻辑模型(投入→活动→产出→结果→影响) | 设计绩效体系;产出可装配、结果靠评估,两轨分立 |
| 排队仿真(到达/服务/耐心/渠道分流) | 窗口与渠道政策实验:均值+P90+分组完成率三件套 |
| Kingman 公式(利用率×变化性×服务时间) | 解释"人没少、队变长":变动性才是排队的主因 |
| 背包/LP 预算选片 | 绩效预算的边际分析(权重只扫区间不给单值) |
| 法条"要件-效果"解析 | 表单自动核验与条文冲突检测 |
| 公共选择模型(预算最大化/寻租) | 分析官僚膨胀与规制俘获:改信息结构,不寄望道德 |
| PPRR 全周期(减缓-准备-响应-恢复) | 应急体制检查:减灾投入最便宜也最被忽视 |

## ④ 常见误区与禁忌

- **拿企业逻辑整套政府**:顾客≠公民(公民是权利主体);利润底线不存在,
  多目标不可通约——可以借工具,不能借口径
- **效率单一口径**:平均等待下降可以与最弱人群可及性恶化同时发生;
  不看分布与分组的效率汇报不完整
- **把指标当目标**:办件时长/办结率被考核后必然被 gaming(拆件/拒收难件)
  ——先设计防扭曲再上指标
- **数字万能论**:线上化不是中性工具,它重分配可及性;砍兜底通道省的钱
  是把风险记在账外
- **把程序当浪费**:科层的规则与非人格是平权与问责装置(同案同办),
  简化流程≠废除程序正义
- **仿真当预测**:排队/系统仿真的角色是把不可测的分布命题化,不是预测;
  不做敏感性扫描就下结论是滥用
