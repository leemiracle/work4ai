# 00 · 体系结构:公共管理家族的全图

> **本章回答五问之一(家族层):整个体系结构长什么样。**
> **本质一句话**:公共管理=公共部门侧的管理学——它研究政府与其他公共组织
> **怎么花钱**(预算与绩效)、**怎么办事**(流程与窗口)、**怎么用人**(文官与功绩制)、
> **怎么扛住坏日子**(危机与韧性);而这一切活动都悬在同一个张力之下:
> **效率与公共价值**——企业有利润底线兜底,公共组织没有,
> 于是"什么算好"本身成了学科的第一问题。
>
> 讲法按三步法走:每个建制/理论先问**为什么需要它**(它救了哪个治理危机),
> 再说**它到底是什么**,最后给**亲手验证的入口**(实验或现实对照)。

---

## 一、开篇故事:一部"钟摆史"(这个体系怎么产生)

公共管理不是从理论开始的,是从**丑闻**开始的。

📖 **1881 年,美国总统加菲尔德被一名求官不遂的落魄律师枪杀**。当时的官职分配
实行"政党分肥制"(spoils system)——竞选获胜的政党把职位当战利品分发给支持者,
"战利品属于胜利者"。求官者古提奥在领事职位落空后行凶,举国哗然:
**把国家机关当分赃品,连总统都会被"求职者"杀死**。1883 年《彭德尔顿文官法》
顺势通过:以公开考试选官、按功绩晋升、文官政治中立——**功绩制**取代分肥制。
"行政"第一次被当成一门需要**专业标准**的手艺,而不是政治恩赐。

📖 **1887 年,威尔逊在《行政学研究》里给这门手艺发了出生证**。他提出
**政治-行政二分**:政治决定目标("制定政策"),行政执行目标("执行政策")——
执行可以科学化、可以有效率研究,不必卷入党争。这篇 28 岁学者写的短文,
后来被称为整个学科的起点(学科通说)。1900 年古德诺《政治与行政》把二分写成
教科书框架:一门叫"行政学"的科学自此合法。

📖 **1937 年,古立克用七个字母装下一门学科**。罗斯福的行政管理委员会
(布朗洛委员会)重整联邦机构,古立克为其撰写备忘录《组织理论笔记》,把
法约尔的企业职能主义翻译给政府:**POSDCORB**——计划(Planning)、组织(Organizing)、
人事(Staffing)、指挥(Directing)、协调(Coordinating)、报告(Reporting)、预算(Budgeting)。
公共组织的管理职能第一次有了零件清单;此后一切行政改革提案,
几乎都是这七个词的重新组合。

📖 **1930 年代,纽约市开始按"买了什么结果"记账**。传统预算按支出对象列
(办公用品多少、工资多少);纽约的改革者把支出改按**活动与成果**编列——
养路费对应"修复了多少英里路面"。1949 年胡佛委员会把它推向联邦层面,
后经 1960 年代"规划-计划-预算"(PPBS)到当代绩效预算,迭代至今:
**把"花了多少钱"翻译成"买到了什么结果"**,是本家族最长寿的工程。

但钟摆很快回摆。**1948 年,沃尔多《行政国家》发出总批判**:政治-行政二分
在现实中不可维持——执行政策就是在做价值判断;"效率"本身就是一个价值,
不是价值中立的尺。与此同时,学术的两翼长了出来:**1951 年拉斯韦尔喊出
"政策方向"**,政策科学成立(政策怎么被制定、执行、评估);
**1962-1971 年,布坎南-塔洛克《同意的计算》与尼斯坎南的官僚模型**把经济学
的理性人假设带进政治与官僚领域——市场会失灵,政府也会失灵(寻租、预算最大化),
**政府失灵理论与市场失灵理论同框**(布坎南 1986 年诺奖)。

📖 **1980-90 年代,新公共管理(NPM)把企业方法请进政府**(学科文献通说)。
英国、新西兰等国的行政改革为典型样本:外包与私有化、绩效合同、标杆管理、
"顾客导向"。胡德 1991 年《一种适合所有季节的公共管理?》为其命名——
问号不是装饰:效率口径全面凯旋之日,就是公共性口径开始反攻之时。
**2000 年,登哈特夫妇提出新公共服务(NPS)**:"服务于公民,而非服务于顾客"——
公民是权利主体不是消费者,回应性、公平、民主对话重新入列。
**1995 年,穆尔《创造公共价值》**给出正面纲领:政府管理者的任务是像企业
CEO 创造股东价值那样**创造公共价值**——"值得吗(公共价值)、允许吗(合法性授权)、
做得到吗(运作能力)"的战略三角。**2006 年,马格特斯与邓利维宣告
"数字时代治理"**:数字技术不是又一轮 NPM 工具,而是政府组织形态本身的重组。
**2020 年代,联合国《电子政务调查》与《世界公共部门报告》**把这场重组
编目为国际通说(01 章全景)。

百年钟摆一句话:**每一摆都救上一次的失灵,又制造新的失灵**——

```
1887 二分法 ──1937 POSDCORB── 1948 行政国家批判 ── 1960s 政策科学+公共选择
     │                                              │
     │        效率口径 ◀═══════ 张力 ═══════▶ 公共价值口径
     │                                                │
1980s NPM(企业方法入政府)──2000 NPS+公共价值──2006+ 数字治理──2020s 数字政府
     钟摆周期约 20-30 年:救失灵 → 造新失灵 → 再摆
```

## 三、核心问题清单(已解决/未解决,带地位)

**已解决的里程碑**:

| 年代 | 人物/建制 | 结果 | 地位 |
|------|-----------|------|------|
| 1883 | 彭德尔顿文官法 | 功绩制取代分肥制(考试选官/政治中立) | 建制共识;现代文官制度的通说起点 |
| 1887/1900 | 威尔逊/古德诺 | 政治-行政二分:行政可科学研究 | 学科通说(学科的出生证);二分本身后被修订为"理想类型" |
| 1937 | 古立克 | POSDCORB 职能清单 | 教材共识;行政改革提案的字母表 |
| 1930s-40s | 纽约市/胡佛委员会 | 绩效预算:支出按活动与成果编列 | 建制共识;PPBS→项目预算→新绩效预算迭代至今 |
| 1962/1971 | 布坎南-塔洛克/尼斯坎南 | 政府失灵的可分析化(寻租/官僚预算最大化) | 共识(诺奖 1986);官僚模型的实证参数仍在争论 |
| 1980s-90s | 胡德等 | NPM 工具箱(外包/标杆/顾客导向)的国际扩散 | 文献通说;效果评价两派并存(效率侧证据多、公共性侧证据弱) |
| 1995/2000 | 穆尔/登哈特夫妇 | 公共价值战略三角;新公共服务纲领 | 理论地位稳固;操作化(怎么测公共价值)未完成 |
| 2006 | 马格特斯-邓利维 | 数字时代治理:技术重组组织而非工具叠加 | 成为 2020 年代数字政府研究的主框架(01 章) |

**悬而未决的大问题**:

- **公共价值的度量**(地位:公开)。战略三角给了"值得吗"这个问题,没给尺子——
  满意度、信任度、获得感各测一角,至今没有统一测度(03 章可构造谱系的右端)。
- **政治-行政二分的现实不可能**(地位:共识性批判,替代框架未定)。沃尔多之后,
  二分退为规范主张;数字时代"算法执行政策"让裁量权进了代码,问题以新形态重现(01 章)。
- **数字化的分配效应**(地位:白热)。Haug 2024 综述指出:数字化结果测度偏效率侧,
  公平侧(数字鸿沟、谁被甩下)证据稀薄——本家族实验正是补这个空(§六反直觉 1)。
- **危机与常态的切换**(地位:活跃)。韧性(resilience)要求冗余与松弛,
  效率要求削冗余——同一组织的两种最优互相矛盾,切换机制无定理(危机支)。
- **绩效指标的自我扭曲**(地位:进行中)。Campbell/Goodhart 定律的公共版:
  指标成为目标就不再是好指标——防扭曲设计(多指标/抽查/数据透明)在积累但无通说。

## 四、假设与代价(本家族站在什么之上)

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| **政治-行政二分**(执行可科学化、可去政治化) | 行政专业中立(文官功绩制的理论地基);效率研究有了无菌室 | 现实不可维持:执行即价值判断(沃尔多批判);二分退化为理想类型,但功绩制已按它建成 |
| **经济人假设进公域**(公共选择:官僚与选民都最大化自身效用) | 政府失灵可分析:寻租、预算最大化、投票悖论全有模型 | 公共服务动机被挤出解释;犬儒风险——把一切公职行为解释为算计,制度信任的规范基础受损 |
| **绩效可测假设**(结果可指标化,指标可问责) | 问责有抓手:绩效预算/绩效合同/排名的整套工程 | Campbell 定律:指标成为目标即被 gaming(窗口拆件凑时长、考核凑件数);多维公共价值被压缩成单维 |
| **数字可及假设**(公民都能用数字渠道) | 规模效率:24/7、零排队边际成本、全程网办 | **数字鸿沟=分配效应**:均值口径全面改善,分布口径恶化——老年/低设备/低技能人群被甩下(家族实验的断言主题) |

**一句话**:本家族用"行政可科学化"换来了专业政府,用"人会算计"换来了政府失灵
理论,用"绩效可测"换来了问责工程,用"数字可及"换来了规模效率——
每一条假设都在其对立面上收取利息,而收息的常常是公民中最弱的那部分人。

## 六、反直觉发现(讲透铁律)

**发现 1:均值改善,分布恶化——效率与可及性可以反向而行**。政务服务数字化分流后,
现场等待均值与 P90 尾部双双下降(负载被线上移走、预约平滑了到达、自助终端
缩短了服务)——平均意义上人人受益。但若把数字能力弱的人群(老年/低设备/低技能)
**强制**在线化,其线上失败率高、失败后再赴现场成本高,有效完成率坍塌:
**数字化的收益记在均值上,代价记在分布上**。这是企业管理没有的问题形态——
企业可以放弃不赚钱的客户,公共组织不能放弃公民。亲历:跑
[`experiments/service_queue_triage.py`](experiments/service_queue_triage.py),
亲眼看"等待统计全面变好"与"鸿沟人群完成率坍塌"同时发生。

**发现 2:科层制不是低效的代名词,而是理性与平权的装置**。日常语言把"官僚"当
贬义词,韦伯的原意恰相反:科层=规则优先、非人格、可预测——**同案同办**本身
就是平权(不看脸办事)与问责(可追责到环节)的装置。程序既是成本也是权利。
NPM 批"官僚病"批的是僵化,不是程序本身;NPS 回摆强调的恰是程序里的对话。
把"简化流程"与"废除程序正义"混为一谈,是本家族最常见的范畴错误。

**发现 3:官僚预算膨胀是均衡,不是道德事故**(尼斯坎南)。拨款者不知道项目的
真实成本函数,官僚知道——信息不对称下,"多要预算、少报能力"是官僚作为
理性代理人的最优策略,恰如企业经理的代理成本(管理理论家族的同型结论,
换了委托人而已)。治理它要改**信息结构**(绩效信息、独立审计、竞争性供给),
而不是寄望于道德说教——这正是绩效预算百年迭代的深层动机。

## ✨ 美之时刻(全家族合计≥3,本章三枚打底)

✨ **美之时刻 1:七个字母装下一门学科**(极简)
POSDCORB——计划、组织、人事、指挥、协调、报告、预算。古立克在一份
政府备忘录里,把法约尔的企业职能主义压缩成一个可背诵的缩写,公共组织
的管理第一次有了**零件清单**:此后无论"大部制改革""流程再造""数字政府",
拆开看都是这七个零件的重新装配。为什么美:**一门学科的复杂度被压进
一个缩写,而这个缩写至今仍是检查行政改革提案完整性的清单**——
任何改革方案漏了哪个字母,哪个字母就会以问题形态回来。
亲历:拿任一份行政改革新闻稿,逐字母对表,找出它没提的那个 P 或那个 B。

✨ **美之时刻 2:绩效预算——把"花了多少钱"翻译成"买到了什么结果"**(翻译)
传统预算是记账语言:钱按投入对象分类;绩效预算换成结果语言:钱按
"修复的路面里程""办结的许可件数"申报与审计。为什么美:**两种语言的词典
就是逻辑模型**(投入→活动→产出→结果),这个翻译自 1930 年代纽约起步,
迭代近百年仍在半途——"结果"的归因之难(03 章)保证了这门翻译永远无法
一次译完,但每一次翻译都把问责向前推一格。亲历:任选一份部门预算公开表,
判断它停在"投入语言"还是走到了"产出语言",离"结果语言"还差几环。

✨ **美之时刻 3:战略三角——"好政府"成为三约束问题**(对称)
穆尔的公共价值战略三角:值得吗(公共价值)、允许吗(合法性与授权)、
做得到吗(运作能力)。任何一个角的短板都否决项目:不值得的效率是浪费,
不被允许的好事做不成,做不到的承诺是失信。为什么美:**它把"什么是好政府"
这个哲学问题变成三约束的工程问题,单一效率口径在这里结构性出局**——

## 📌 收束 + 🧭 这章给了你什么新眼睛(认知升维)

百年钟摆、两支落子、一份带地位的问题清单。本章之后你应该带走的**公共部门之眼**:

- **公共价值之眼**:看到任何公共效率改进(合并窗口/线上化/无人化),
  先问分配效应——谁受益、谁被甩下、兜底通道在哪。
- **委托链之眼**:看到任何公共服务,数一数它背后的委托层级——每加一层,
  信息损耗一次、问责稀释一度。
- **口径之眼**:看到"提高政府效率"的说法,先问哪个口径的效率——
  企业的效率(成本产出比)与公共的效率(公共价值/公共资源)不是同一把尺。
