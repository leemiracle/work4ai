# 讲透公共管理 · 公共部门侧的管理学——用有限公共资源创造公共价值

> **本质一句话**:公共管理=管理学的**公共部门应用面**——政府与其他公共组织如何
> 配置公共资源、提供公共服务、在效率/公平/回应性/问责的多重目标之间折冲;
> 与企业管理家族(波4待建)构成管理学的**两个应用面**。第一主题是
> **效率与公共价值的张力**:企业可以放弃不赚钱的顾客,公共组织不能放弃公民——
> 每一次效率改进都要先回答"谁受益、谁被甩下"。
