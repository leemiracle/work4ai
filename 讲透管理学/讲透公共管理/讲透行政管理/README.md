# 讲透行政管理 · 常态机器:组织、人事、预算、程序怎么转

> **定位句**:这支负责"**常态**"——政府这台机器在平常日子怎么运转:组织怎么设(结构)、
> 人怎么进(文官与功绩制)、钱怎么分(公共预算与绩效)、事怎么办(行政程序与流程);
> 家族两支中工程化最深、与数字政府衔接最紧的一支。
> GB/T 13745 63044 公共管理 · 三级 **6304410 行政管理**(GB/T 注:代码原为 63045)。
> 家族:[讲透公共管理](../README.md)

## 诞生

- **谁/何时**:威尔逊 1887《行政学研究》(政治-行政二分,学科通说起点);
  古德诺 1900《政治与行政》系统化;古立克 1937 POSDCORB(职能清单);
  沃尔多 1948《行政国家》(对二分与效率主义的总批判);胡德 1991 命名新公共
  管理(NPM);穆尔 1995 公共价值;2006 起数字时代治理接棒。
- **因什么问题**:①政党分肥腐蚀政府(1881 加菲尔德遇刺→1883 彭德尔顿文官法)
  ②机构膨胀与协调失灵(布朗洛委员会→POSDCORB 零件清单)③"花钱不见结果"
  (1930s 纽约市绩效预算起步,后经胡佛委员会与 PPBS 迭代)④效率改革牺牲
  公共性(NPM 之问→NPS 与公共价值回摆)。

## 核心问题

**已解决**:功绩制取代分肥制(考试选官/政治中立)——现代文官制度的通说地基;
行政职能的清单化(POSDCORB=行政改革的字母表);绩效预算的语言翻译(投入语言→
活动与成果语言,家族 00 章美之时刻 2);NPM 工具箱的国际扩散谱系(文献通说,
效果评价两派并存)。

**未解决/深水区**:政治-行政二分的现实不可能——执行即价值判断,数字时代
"算法执行政策"让裁量权进代码(家族 01 章);官僚自主权的控制(预算最大化是
均衡不是事故,治理靠改信息结构);公共价值的度量(战略三角有问无尺);
数字政府的组织重组:大部制→平台制?"政府即平台"的授权与责任链。

## ✨ 这支最美的一个事实

**七个字母装下一门学科**:古立克在 1937 年的一份政府备忘录里,把法约尔的
企业职能主义压缩成 POSDCORB——计划、组织、人事、指挥、协调、报告、预算。
此后近百年的一切行政改革提案(大部制/流程再造/数字政府),拆开看都是这七个
零件的重新装配;**任何方案漏了哪个字母,哪个字母就会以问题形态回来**——
一个缩写至今仍是改革提案的完整性检查表(家族 00 章美之时刻 1 的原产地)。
