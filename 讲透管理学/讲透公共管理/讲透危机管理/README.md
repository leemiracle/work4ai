# 讲透危机管理 · 坏日子:突发事件的全周期怎么管

> **定位句**:这支负责"**坏日子**"——突发事件(自然灾害/事故灾难/公共卫生/
> 社会安全事件)的全周期管理:**减缓-准备-响应-恢复**(PPRR);研究常态机器
> 在极端工况下如何不失灵:预警、预案、指挥、协同、危机沟通与韧性。
> GB/T 13745 63044 公共管理 · 三级 **6304420 危机管理**(GB/T 注:也称"应急管理")。
> 家族:[讲透公共管理](../README.md)

## 诞生

- **谁/何时**:多源汇流——民防传统(战时体制转民用);1979 年美国组建联邦应急
  管理署(FEMA)归口分散职能,独立建制的"应急管理"定型(学科通说);灾害社会学
  1950s 起积累(夸兰泰利/戴恩斯:灾害中的真实行为);联合国 1990-1999 国际减灾
  十年→2005 兵库行动框架→2015 仙台减灾框架(风险治理国际通说锚);危机决策侧
  阿利森 1971 古巴导弹危机三模型;危机沟通侧库姆斯情境危机传播理论(SCCT)。
- **因什么问题**:①灾害损失随城市化指数放大,事后救援不够,必须灾前干预
  (减缓/准备入列)②跨部门跨层级的临时协同难③不确定性下的决策失灵
  (群体思维/时间压力)④公众沟通的信任杠杆。

## 核心问题

**已解决**:全周期阶段论(PPRR)成为国际通说框架——从"救援学"扩展为
"减缓最优先的治理学";预警-预案-演练-指挥链的工程化建制;灾害行为的实证
基座(恐慌稀有、亲社会行为普遍,灾害社会学共识)。

**未解决/深水区**:**计划悖论**——预案越多≠应对越好,不确定性下详细计划
制造虚假胜任感,何时该计划、何时该练适应力无定理;突发事件催生的临时多组织
网络(生成与解体规律仍在建模);**韧性的操作化**(吸收-适应-转型怎么测;
冗余=浪费 vs 冗余=保险的权衡无最优解);数字应急:预警与信息传播的社交化,
既加速预警也加速谣言(家族 01 章方向锚)。

## ✨ 这支最美的一个事实

**灾害损失的大头在灾前决定**:全周期四阶段里,"减缓"(设防标准、土地利用
管制)最便宜、最有效,也最被忽视——它的工作成果是**没有发生的灾害**,在
政绩与新闻里都不可见;而"响应"(救援)最贵、最可见、最被褒奖。
**为什么美**:一条时间轴把"管理的可见性"与"管理的有效性"排成反序——
理性上应把钱投在无事发生的那一端,激励上钱总流向镜头对准的那一端:
公共价值与可见性的经典错配(与家族 00 章"绩效测什么"一脉相承)。

## 假设与依赖

- 全周期可分段假设:买到检查清单与建制分工,付出阶段边界的模糊(现实是循环
  与嵌套);灾害行为可预期假设:预案建立在行为假设上,灾害社会学的实证恰是
  对朴素假设的修正
- 依赖上游:常态机器(本家族行政管理支)、组织理论([../../讲透管理理论/README.md](../../讲透管理理论/README.md),
  临时组织与协同)、灾害社会学([../../../讲透社会学/README.md](../../../讲透社会学/README.md));
  法制侧:应急法制([../../../讲透法学/README.md](../../../讲透法学/README.md))
