## 诞生

- **谁/何时**:舒尔茨 1960 演说+贝克尔 1964《人力资本》(投资语言);
  德文纳-丰布伦-蒂奇 1981"匹配模型"(HR 与战略/结构的第一次系统挂钩);
  巴尼 1991 资源基础观(人=难模仿资源);尤里奇 1997《人力资源冠军》
  (四角色,后定型为 COE/HRBP/SSC 三支柱);胡塞德 1995 高绩效工作系统
  (HPWS 与财务绩效的实证锚点)。
- **因什么问题**:①培训的钱怎么算回报(投资之问);②人事部怎么从
  办手续的变成战略桌上的(职能之问);③三年后的关键岗位谁来干
  (管道之问)。

## 核心问题

**已解决**:
- 人力资本的度量语言:教育回报/培训通用-专用之分(明瑟方程正主在
  [../../../讲透经济学/讲透劳动经济学/](../../../讲透经济学/讲透劳动经济学/))
- HPWS 与组织绩效的正相关(相关网络大样本反复出现)
- 继任与人力规划的算法化:漏斗+马尔可夫转移矩阵(家族 03 章构造 2)

**未解决/深水区**:
- HPWS 的因果方向(好系统造好绩效,还是好绩效买好系统?实验化进行中)
- 人力资本为何不入资产负债表(不拥有/不可处置——度量止步于统计)
- 技能本位组织(01 章主线 B)的分类法维护成本能否长期收敛

## ✨ 这支最美的一个事实

**继任计划=容量规划**:把组织的人看成存量(在岗)与流量(招聘/晋升/流失),
用转化率连乘反推入口流量,用转移矩阵幂推十年结构——
组织的"软"问题(谁升谁走)被写成一个随机矩阵,
断层年份在矩阵的幂里早已写好(家族 00 章美之时刻 2/03 章美之时刻 4 的原产地)。

## 假设与依赖

- 人=可投资资产(买到战略话语权,付出资本隐喻的伦理张力——家族 00 章假设表)
- 战略-结构-HR 可匹配(匹配假设;注意事后拟合风险,同管理理论家族的权变批评)
- 管道参数可外推(**暗礁**:参数是政策的函数,改政策必重估)
