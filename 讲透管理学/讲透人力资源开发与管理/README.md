# 讲透人力资源开发与管理 · 人的层:把人当资本,还是当资源

> **本质一句话**:人力资源开发与管理=**管理学的"人的层"**——它问的不是
> "某个部门怎么招人发薪"(那是职能侧),而是**"人作为一种会增值的资产,
> 怎么度量、怎么投资、怎么在组织间配置"**。全部张力在一句话里:
> **把人记在成本栏还是资产栏**——人力资本革命(舒尔茨/贝克尔)把人搬进资产栏,
> 而"资产"这个词本身(会折旧、可处置)又在提醒你:人终究不是资产负债表上的物。
>
> GB/T 13745-2009:630 管理学 · 二级学科 **63055 人力资源开发与管理**。
