# 讲透人才学 · 资产侧:人才怎么识别、怎么成长、怎么辈出

> **定位句**:这支负责"**资产侧**"——人才的识别(胜任力/评估)、成长规律
> (培训转移/发展轨迹)、辈出机制(环境怎么让人才成批出现);
> 它回答"人这笔资产**本身**怎么长",是 00 章四副眼镜里
> **测量之眼**的大本营。
> GB/T 13745 63055 人力资源开发与管理 · 三级 **6305520 人才学**。
> 家族:[讲透人力资源开发与管理](../README.md)

## 诞生

- **谁/何时**:麦克利兰 1973《测量胜任力而非智力》(胜任力运动:从测智力
  到测区分优秀者的深层特征,冰山模型的起点);中国学者 1979 年前后提出
  建立"人才学"(学科史通说:人才成长规律与辈出机制的本土议题);
  奥博伊尔-阿吉尼斯 2012(23 万+样本:个体绩效呈幂律而非正态——
  "明星研究"的统计地基);埃德蒙森 2012 亚里士多德计划(心理安全:
  人才发挥的环境条件)。
- **因什么问题**:①智力测验为什么测不出干得好的人(识别之问);
  ②培训为什么常常不转移(成长之问);③为什么有的环境天才成批出现、
  有的环境互相消耗(辈出之问)。

## 核心问题

**已解决**:
- 胜任力可建模:冰山分层+行为锚定,选人从占星术走向测量学(家族 03 章构造 1)
- 绩效分布形态:幂律(尾部即全部)——人才管理的重心从"管理平均"
  转向"识别与保护极端值"(家族 00 章反直觉 1)
- 明星的情境依赖:跳槽后星光平均大幅衰减,组织专属资本带不走
  (家族 00 章反直觉 2)

**未解决/深水区**:
- 个体绩效的预测上限(信号+情境+运气,效度长期停在 0.5 上下)
- 潜力构念的操作化(学习敏捷度的效度之争仍在审)
- 辈出机制的因果识别:环境(心理安全/师承/竞争结构)与人才涌现的
  鸡蛋问题——田野实验刚起步

## ✨ 这支最美的一个事实

**绩效不是正态,是幂律**:绩效管理默认能力呈钟形(所以有强制分布),
而 23 万+样本显示个体绩效是幂律——极少数人贡献了产出的绝大部分。
一个分布假设的更换,推翻了整套"管理平均数"的制度设计:
识别尾部、保护尾部、并接受尾部预测的极限。
