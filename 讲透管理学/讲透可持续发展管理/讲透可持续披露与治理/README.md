# 讲透可持续披露与治理 · 怎么说清且被怎么评:口径、评级与漂绿

> **定位句**:这支负责"**怎么说清且被怎么评**"——披露层:报告框架的语法
> (GRI/ISSB/TCFD)、范围一二三的核算口径、评级工业的分歧、漂绿的识别与
> 问责建制(鉴证/治理结构)。它是三层中最"语言学"的一支:口径即立场;
> 也是母题"绿化还是漂绿"的解剖台。

> (GB/T 2009 版该条目无代码亦无三级明细,宇宙 spec 处理为新码家族,支为主干自定)。

## 诞生

- **谁/何时**:CERES 1989(重大海上溢油事故后的投资者-环保联盟)推动 GRI
  于 1997 立项、2000 年首版指南(影响导向语法);SASB 2011(行业口径的
  财务重要性语法);TCFD 2017(气候四支柱:治理/战略/风险管理/指标与目标);
  ISSB 2021 成立、2023 年 IFRS S1/S2(投资者导向全球基线,收编 SASB 与
  TCFD);评级工业(MSCI、Sustainalytics 等)同期把企业可持续性压成分数;
  学术两大奠基:Berg-Kölbel-Rigobon 2022 分歧三分解(实证共识)与
  Delmas-Burbano 2011 漂绿驱动框架。
- **因什么问题**:①信息不对称——外部人看不见内部实质,需要翻译层
  ②翻译层自己成了利益相关方(机构卖口径,口径即产品)③没有金标准⟹
  "译得对不对"不可直接检验④强制化后披露从加分项变成合规底线
  (数据工程与内控问题)。

## 核心问题

**已解决**:披露语法的工程化(GRI 影响语/ISSB 财务语/TCFD 支柱/范围一二三);
评级分歧的现象学与分解(两两平均相关约 0.54 vs 信用评级 0.99,测量差为主);
漂绿的概念化(披露-实质缺口;Delmas-Burbano:外部制度压力×内部治理弱×
媒体放大的三重驱动)。

**未解决/深水区**:**双重重要性的操作化**(财务轴×影响轴能否一张矩阵);
**鉴证的等级扩展**(有限→合理保证的成本曲线);**漂绿的识别与惩戒**
(市场自律 vs 制度化问责;被误判的真转型同样有社会成本);**评级透明度
悖论**(方法学全公开⟹被博弈,全黑箱⟹不可问责);披露-实质缺口是否随
强制化收敛(母题的经验检验,家族 01 章方向锚)。

## ✨ 这支最美的一个事实

**分歧即仪器**:评级互相打架是病,但两套方法学独立的评级相减,
残差恰好滤掉"大家都看到的实质",剩下披露-实质错位——漂绿的候选信号。
为什么美:在没有金标准的领域,不一致性是唯一免费的对照实验——
测量的失败被反转成检测工具。亲历:家族实验
[../experiments/esg_rater_divergence.py](../experiments/esg_rater_divergence.py)
断言③(漂绿组缺口增量 +9.6 vs 对照组 0.0,precision@K=1.00)。
