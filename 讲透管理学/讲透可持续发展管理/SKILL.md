# 可持续发展管理思维技能卡(讲透可持续发展管理 · 630 宇宙新码家族)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **评级类**:ESG 评级为什么互相打架、评级分歧、评级套利、哪家机构的分、
  评级与信用评级的对照、precision@K 筛漂绿
- **核算类**:范围一二三、碳账户、排放因子、活动数据、范围三估算路径、
  供应链碳数据、碳数据平台
- **披露类**:GRI/ISSB/SASB/TCFD、双重重要性、净零 vs 碳中和、鉴证等级、
  披露监管化(只述学科通说,不评具体政策)
- **漂绿类**:greenwashing、披露-实质缺口、信号工程、口径博弈、漂绿雷达
- **运营类**:循环经济、物料流分析(MFA)、逆向物流、产品即服务、再制造、
  工业共生、循环率、9R、净环境收益核算
- **战略类**:ESG 战略、利益相关者整合、共享价值、三重底线、重要性矩阵、
  波特假说、使命章程化、business case 之争

## ② 核心思维模式(这个分支怎么想问题)

1. **三层定位**:任何可持续主张先问它在哪层——战略(为什么做)/运营(做什么)/
   披露(说多少);跨层引用=营销话术
2. **口径优先**:任何 ESG 分数/碳数字先问——谁的口径、哪个范围、哪条估算路径;
   没有口径的数字是修辞不是测量
3. **缺口之眼**:披露信号↑时先问实质动没动;两套独立口径的差分=漂绿候选信号
4. **守恒打底**:物料与碳的账先闭平衡(输入=输出+累积)再谈指标;
   闭不上的循环率是物质错误不是语气问题
5. **最弱一跳**:数据链强度=最弱一跳;鉴证等级按跳数赋值
6. **双赢存疑**:"做好事又赚钱"先查选择偏差与口径;真权衡要诚实入账

## ③ 工具箱(方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 评级三分解(测量/范围/权重差) | 归因评级分歧;设计"换机构"稳健性检验 |
| 披露-实质缺口差分 | 漂绿候选名单;对外指标 vs 内部实测的同屏雷达 |
| 范围三双引擎(活动法×因子/支出×投入产出) | 估算价值链排放并输出区间;区间宽度=数据投资排序 |
| MFA 物料平衡表+守恒断言 | 建循环率/再生含量指标并使其可证伪 |
| 重要性矩阵(财务×影响双轴) | 披露什么与管什么的议程设定(终判留给治理) |
| 9R 阶梯(拒用→再生) | 循环策略的优先级语言(减量优先于末端回收) |
| LCA 生命周期评价 | 产品级环境账(警惕单指标冒充全口径) |
| 两两相关 vs 同机构自相关 | 判断一套评级面板的分歧是结构性还是噪声性 |

## ④ 常见误区与禁忌

- **单评级当真理**:换一家机构结论可能翻号——引用 ESG 实证必须带口径
- **范围三报点值**:路径不同数量级可变——只能报带路径标签的区间
- **循环=减碳**:回收有运输与再处理能耗,净收益要算能源结构与物流半径
- **净零/碳中和混用**:两词差一个战略的重量(深度减排为主 vs 允许大量抵消)
- **缺口当判决**:差分只给候选信号,裁决权在治理(无金标准的诚实条款)
- **评具体政策/公司**:本分支按学术通说讨论评级分歧与漂绿识别,
  不评价任何国家现行监管政策与具体公司(家族红线)
