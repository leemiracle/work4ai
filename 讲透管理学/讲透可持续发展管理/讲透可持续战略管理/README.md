## 诞生

- **谁/何时**:Freeman 1984《战略管理:利益相关者方法》(目标函数从股东扩到
  利益相关者网络);Elkington 1997 三重底线(战略的三栏账语言);Porter 一线
  两篇——van der Linde 1995《绿色与竞争》(规制-创新假说)与 Kramer 2011
  《创造共享价值》(社会问题内生化为企业机会集);2010s 重要性矩阵实践
  (GRI 影响轴×SASB 财务轴);2022 巴塔哥尼亚股权入使命信托——
  使命章程化的学科史标本(事实陈述,不作经营评价)。
- **因什么问题**:①末端治理解不了系统性风险(监管/社区/供应链随时掐断经营)
  ②股东单一目标函数装不下多主体问责③"做好事"与"做好企业"的关系
  没有战略层答案(成本?风险?机会?)。

## 核心问题

**已解决**:利益相关者识别与显著性判定(权力/合法性/紧迫性三属性)成为
教材共识;三重底线把可持续翻译成战略语言;重要性矩阵把议程设定流程化;
ESG 战略解释框架四分(制度/利益相关者/代理/RBV——Martiny 等 2024 盘点,
经[../../讲透管理理论/01-近五年创新.md](../../讲透管理理论/01-近五年创新.md)转引)。

**未解决/深水区**:**双赢假说的因果识别**(相关≠因果,选择偏差是内生病;
真权衡该被诚实承认而非掩饰——战略层最硬的未解问题);**波特假说的边界**
("适当设计的规制"难操作化,支持与反证长期并存);**使命漂移与锁定**
(章程化锁得住承诺,也可能锁死调整);强制披露时代的信号重构(合规化后
战略差异化空间在哪)。

## ✨ 这支最美的一个事实

**约束与竞争力的因果倒置**(波特假说):常识说环保规制抬成本;
假说说适当设计的规制倒逼创新,效率收益可能超过合规成本。为什么美:
它不否认约束,而是重写约束的传导机制——战略层的全部工作就是找那条
"约束→创新"的窄门(重要性矩阵/共享价值都是窄门的工程化)。
亲历:家族 [00 章](../00-体系结构.md)美之时刻 2 的原产地。
