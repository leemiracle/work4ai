# 讲透循环经济运营 · 怎么做:物料怎么闭环

> **定位句**:这支负责"**怎么做**"——运营层:把线性的"开采-制造-废弃"
> 重设计为闭环:物料流账户(MFA)、逆向物流、产品即服务、再制造、工业共生;
> 它是三层中物质性最强的一支:一切承诺最后都要在这里变成吨、流与工序。
> GB/T 13745 630 管理学 · 「可持续发展管理」**自定主干支**
> (GB/T 2009 版该条目无代码亦无三级明细,宇宙 spec 处理为新码家族,支为主干自定)。
> 家族:[讲透可持续发展管理](../README.md)

## 诞生

- **谁/何时**:Stahel 1976《产品寿命因素》(卖性能不卖物,产品即服务的原型);
  丹麦卡伦堡工业共生网络 1960-70 年代自发演化(一家的废热/废石膏=另一家的
  原料,"工业共生"的命名案例);Boulding 1966 宇宙飞船经济(封闭系统观,
  概念本体在[../../../讲透经济学/讲透生态经济学/](../../../讲透经济学/讲透生态经济学/));
  2010 年后艾伦·麦克阿瑟基金会理论化散点实践——2012《迈向循环经济》
  "蝴蝶图"(技术+生物两条循环);9R 阶梯(Potting 等 2017)排策略优先级;
  逆向物流(Rogers 与 Tibben-Lembke)把"回流"做成运营学科。
- **因什么问题**:①末端回收救不了线性系统(废弃是设计出来的)②物料价格
  与供应波动是实打实的运营风险③监管与客户开始为"闭环"付钱(再生含量/
  回收费任)④废弃物=放错位置的资源,但组织化回流没有现成运营学。

## 核心问题

**已解决**:MFA/LCA 核算方法学(物料账怎么记、环境账怎么算);
工业共生匹配原理(副产品-输入的物料-能量-地理三维匹配);
9R 优先级语言(减量>再用>再生,末端回收排最后)。

**未解决/深水区**:**回流质量不确定性**——回收品分级定阶与定价
(正向链知道卖什么,逆向链收到的每一件都不同);**产品即服务的代价**
(所有权留卖方→耐久性内化,但资本回收周期拉长、总量可能不降反升);
**净环境收益核算**(循环≠减碳:能源结构与物流半径决定总账,家族 00 章
反直觉 3);数字产品护照等循环信息基础设施的落地(01 章方向锚)。

## ✨ 这支最美的一个事实

**产权一改,激励全变**:产品即服务把所有权留在卖方——耐久性、可维修性、
可拆解性从买方的麻烦变成卖方的利润表科目(设备越耐用,服务商每期成本越低)。
为什么美:它没有劝任何人环保,只改了一纸产权安排,就让"把东西做结实"
从道德命题变成财务命题——产权经济学的运营应用(与
[../../讲透管理理论/](../../讲透管理理论/) 交易成本一支遥相呼应)。

## 假设与依赖

- 质量守恒可追踪(物料可记账、可分级)——买到可运营与可审计,
  付出数据边界(厂级易、链级难)与分级折损的口径成本
- 回流可组织(逆向网络在成本内建得起来)——买到闭环,
  付出密度经济性约束(低密度回收物的物流半径天花板)
- 依赖上游:[../../../讲透经济学/讲透生态经济学/](../../../讲透经济学/讲透生态经济学/)
  (物质约束与减量优先)、[../../讲透管理理论/](../../讲透管理理论/)(组织与契约);
  算法本体:运筹学(文字提及);管理工程家族(波4待建,文字提及)
