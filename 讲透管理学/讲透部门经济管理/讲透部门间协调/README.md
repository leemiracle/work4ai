# 讲透部门间协调 · 投入产出与部门间网络——格子之间的流怎么算

> **定位句**:这支负责"**网**"——部门是格子,价值在格子之间流动;
> 投入产出表把部门间流织成一张可计算的网,乘数、波及、断供冲击都在网上读。
> 没有一门"部门间经济学"认领格子之间的流量——它是本家族的独有资产。
> GB/T 13745 63030 部门经济管理 · **自定主干支**(GB/T 未列三级,家族自定)。
> 家族:[讲透部门经济管理](../README.md)

## 诞生

- **谁/何时**:Leontief 1936 年论文+1941《美国经济结构》创立投入产出分析,1973 年 Nobel;
  1949 Hawkins–Simon 可解性条件;1958 Ghosh 供给侧对偶;1961 Stone 定型 RAS。
- **因什么问题**:①"一个部门的扩产会牵动谁"(计划与战后的部门间算账);
  ②"数据不齐的年份怎么办"(RAS 延长表);③"抽掉一个部门全网多疼"(断供测痛)。
- **中国线**:1973 首张实物型表,1987 首张普查价值表,逢 2/7 编表、0/5 延长(2020 表,检索校准 2026-09-07)。

## 核心问题

**已解决**:
- 列昂节夫逆 (I−A)⁻¹=I+A+A²+… 的乘数体系;Hawkins–Simon/ρ(A)<1 可解性证书
- RAS 双比例拟合:行列合计约束下的延长表构造(最大熵解释)
- 假想抽取(HEM):部门系统重要性的标准测法

**未解决/深水区**:
- 分类粒度与聚合偏误:细表并粗表会改乘数
- 乘数的时变性:系数漂移无共识修正(动态 IO 方向活跃)
- MRIO 口径协调:各国表对接的 harmonization 损耗(时效声明见家族 01 章)

## ✨ 这支最美的一个事实

**(I−A)⁻¹ 的一列=一元最终需求在全系统的无穷回响**——间接效应一轮轮衰减,
无穷轮回收敛成有限数字:制造业 1 元拉动全社会 2.5 元总产出(家族实验 3×3 例)。
"乘数"从总量直觉变成**逐部门可查的账**。

## 假设与依赖

- **同质性假设**(每部门一种产品)与**系数短期不变**——部门平均、冻结技术(家族 00 章 §五)
- **生产性假设**:ρ(A)<1,否则级数发散、经济不可自持(先证书后迭代)
- 上游数学:线性代数(逆/谱);家族实验 [../experiments/00_input_output.py](../experiments/00_input_output.py) 全流程验证
