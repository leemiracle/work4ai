# 讲透部门管理通则 · 体制/结构/绩效——各部门管理问题的共同模具

> **定位句**:这支负责"**模具**"——工业、农业、运输、金融……每个部门的管理
> 换汤不换药:体制怎么设、结构怎么调、绩效怎么评,三栏重复出现。
> 本支提炼共性,不替各部门立说(本体见 [../../../讲透经济学/README.md](../../../讲透经济学/README.md))。
> GB/T 13745 63030 部门经济管理 · **自定主干支**(GB/T 未列三级,家族自定)。
> 家族:[讲透部门经济管理](../README.md)

## 诞生

- **谁/何时**:苏联**部门经济学**传统(отраслевая экономика,计划经济一科一部委);
  1950 年代随苏联教材体系整体移植中国(人大等设工业经济/农业经济/贸易经济系)。
- **因什么问题**:①部委治国需要"每部门一册"的管理学(移植期);
  ②市场化后部门大合并、行业大洗牌,"各部门各自一套"讲不通,提炼**横向通则**;
  ③2008-2018 三轮大部制改革把"部门边界本身"变成管理对象——通则支的当代问题。

## 核心问题

**已解决**:
- 部门管理通则的提炼框架:体制(归口与权责)/结构(集中度与组织形态)/绩效(目标与评估)三栏
- 归口—调节—评估的政策闭环在各部门语境的可复用模板
- 部门分析的标准件:行业口径对表、部门间流量定位(配 [讲透部门间协调](../讲透部门间协调))

**未解决/深水区**:
- 部门边界怎么划:行业分类追技术永远慢半拍(平台经济/数据要素的归口悬案)
- 部门壁垒与统一市场之张力:切块便于归口,切块利益生出壁垒(2022 统一大市场直面的老题)

## ✨ 这支最美的一个事实

**千差万别的部门背后是同一组管理问题**——农业部的粮食安全、工信部的产业链安全、
交通运输部的网络畅通,拆开看是**同一张三栏表**在填不同的词。
"部门经济学们"是一套模具压出来的——**模具的存在本身,就是通则支的全部理由**。

## 假设与依赖

- 站在**部门切块假设**之上:经济可按行业归口——代价是外部性归属模糊、边界滞后(家族 00 章 §五)
- 上游管理四维(激励/协调/控制/演化)来自 [../../../讲透管理/](../../../讲透管理)(挂靠读本)
- 各行业自身的经济规律**不在本支**:工业组织→79055,农业供给→79059,运输→79061……

## 教材锚

- 部门经济学综述文献(苏联部门经济学教材传统与中国部门经济管理教科书脉络)
- 里昂惕夫《投入产出经济学》(部门间流量是通则的算术底座)
- 历轮国务院机构改革方案(大部制的一手文本——部门边界的谈判实录)
