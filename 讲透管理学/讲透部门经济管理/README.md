# 讲透部门经济管理 · 行业管理的横向方法层——本体住在各经济学科的归属型家族

> **本质一句话**:部门经济管理=各行业管理问题的横向方法层——
> 本体住在各经济学科(工业/农业/运输……的经济与管理研究),本家族只管两件留在家里的事:
> **部门怎么管有通则**(体制/结构/绩效),**部门之间怎么协调**(投入产出与网络)。
>

> 一句话:**条条(部门)放走,条条之间的网和模具留下。**
