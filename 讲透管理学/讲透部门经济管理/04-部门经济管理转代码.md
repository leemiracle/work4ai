# 04 · 部门经济管理转代码:把部门间流算成乘数与冲击

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(行业分析视角)。
> 归属型家族的转代码几乎=投入产出转代码:对象是矩阵,运算就是线代。

---

## 开篇:别的管理学分支在"翻译",本家族在"加载"

管理学大多数分支转代码要做三重翻译:概念操作化、关系模型化、算法实现。
本家族往往只剩第三重——**对象在两边长得一模一样**:
部门间流就是二维数组,直接消耗系数就是列归一化,乘数就是解一个线性方程组。
官方统计体系已经把数据做成矩阵形状,拿到的即是"机器母语"(与离散数学家族同款待遇)。

所以本章的问题不是"能不能转"(几乎全能),而是"**转到哪一层**":
从"算得出"到"算得稳"(证书先行),再到"算得有用"(行业分析落点)。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 部门经济管理概念 | 代码化身 | 备注 |
|----------------|---------|------|
| 部门间中间流量 | n×n 矩阵(嵌套列表/CSV) | 稀疏性可观:真实大表多数格子近零 |
| 直接消耗系数 A | 流量矩阵按**列**归一化 | a_ij=x_ij/X_j,列=投入结构 |
| 列昂节夫逆 (I−A)⁻¹ | Gauss–Jordan/线性求解 | 百部门表毫秒级;手写见本家族实验 |
| Neumann 级数 I+A+A²+… | 迭代累加 | 波及"逐轮"显形,教学与审计利器 |
| 产出乘数 | 逆矩阵**列和** | 行业带动效应/系统重要性一列读出 |
| 政策/需求冲击 ΔX=(I−A)⁻¹Δy | 改需求向量重解 | 线性叠加,多方案零边际成本 |
| 断供冲击(HEM) | 抽掉部门行列重解 | 删点测痛;实验脚本有最小版 |
| 延长表更新(RAS) | 双比例因子迭代 | 只需行列合计;最大熵解释(03 章) |
| 部门聚合/细化 | 分块矩阵乘 | 粗表读乘数要防聚合偏(03 章) |

**转不动/转不动的边界(红色区)**:

1. **部门内企业异质响应**:同一部门里头部与小微对冲击的反应完全不同,
   IO 系数是部门平均。对策:配企业微观数据做分布分析,或上代理模型。
2. **价格内生与行为响应**:乘数世界没有涨价、替代与预期——
   长期/大冲击要交给 CGE(可计算一般均衡)或计量模型,IO 只管短期物量波及。
3. **系数演化**:技术进步让 A 缓慢漂移,乘数有时效。
   对策:按时序表做局部更新,引用乘数必报年份(02 章口径之眼)。
4. **部门边界本身的动态**:新业态无格可归,分类修订即数据断点。
   对策:跨版本引用走 concordance 对照表,并声明损耗。

**边界的一句话**:绿色区=**短期、物量、部门平均**的波及算术;
红色区=**长期、价格、异质**的行为世界——本家族把前者做成默认值,
把后者诚实地留给邻居(→经济学宇宙计量与 CGE 各家族)。

## 二、代码走廊:投入产出乘数走廊(本家族唯一深挖的走廊)

```
中间流量表(官方统计)
   │ 列归一化
   ▼
技术系数 A ──证书检查──▶ 谱半径 ρ(A)<1 ?(Hawkins–Simon,03 章)
   │                        │否 → 拒算:系统不可自持,数据或口径有错
   │是                      ▼
   ├────直接求逆──────▶ (I−A)⁻¹ ──读列──▶ 乘数/波及/系统重要性
   └────级数迭代──────▶ I+A+A²+…(波及逐轮显形;收敛速度=谱半径)
   │
   └──RAS 更新(每逢小年)──▶ 延长表 ──▶ 冲击模拟 ΔX=(I−A)⁻¹Δy / HEM 抽取
```

- **对象→结构**:流量表=矩阵;A 的**列**=部门的投入结构(上游账本),
  A 的**行**=产品的销售结构(下游账本);逆矩阵元素 b_ij=完全需求系数
  ——部门 j 的 1 元最终需求,直接+间接共需要部门 i 生产多少。
- **算法层**:
  - 手写 Gauss–Jordan 求逆(本家族 `experiments/00_input_output.py`,
    含列主元交换,教学级清楚);
  - Neumann 级数迭代:一边乘一边加,亲眼看"第 k 轮波及"逐项落表;
  - HEM:抽行抽列降一维重解,总产出差=抽取效应;
  - RAS:行因子 r 与列因子 s 交替缩放,直至吻合行列合计(双比例拟合)。
- **真实系统**(方向锚,检索校准 2026-09-07):
  国家统计局投入产出表(2020 年表,百余产品部门);
  OECD TiVA(76 经济体增加值贸易);WIOD/Eora/Exiobase(MRIO);
  开源生态 pymrio(Python 的 MRIO 工具链)。
- **性能工程要点**:
  - **证书先行**:迭代前先估谱半径(幂法一页纸),ρ≥1 立刻停——
    03 章 Hawkins–Simon 是"先验收敛再跑迭代"的工程纪律;
  - **稀疏化**:真实大表近零格子占比高,百部门以上用稀疏存储+稀疏求解,
    别让稠密 n³ 白烧;
  - **重解复用**:线性叠加意味着多方案共享同一个逆矩阵——先求逆、后批量读列,
    比"每方案从头解"快一个量级。

**参考实现:10 行 RAS**(03 章延长表的算法骨架,练习 2 的答案):

```python
def ras(A_old, row_tot, col_tot, rounds=50):
    """双比例拟合:交替缩放行与列,直至吻合新合计(最大熵解释)。"""
    A = [row[:] for row in A_old]
    for _ in range(rounds):
        for i, rt in enumerate(row_tot):              # 行因子 r
            s = sum(A[i])
            if s:
                A[i] = [a * rt / s for a in A[i]]
        for j, ct in enumerate(col_tot):              # 列因子 s
            s = sum(A[i][j] for i in range(len(A)))
            if s:
                for i in range(len(A)):
                    A[i][j] *= ct / s
    return A
```

## 三、工程师落点:行业分析速查表

| 你遇到的问题 | 部门间工具 | 落点 |
|-------------|-----------|------|
| 这个行业 1 元需求带动多大总产出? | 产出乘数 | 读 (I−A)⁻¹ 第 j 列列和 |
| 某上游断供,我的行业掉多少产出? | HEM/Ghosh 供给冲击 | 抽取上游部门或行清零重解 |
| 我的行业上游集中在哪几个部门? | 直接+完全消耗系数 | A 第 j 列 + (I−A)⁻¹ 第 j 列取 top-k |
| 我的行业下游卖给谁? | 分配结构 | A 第 i 行 + 逆矩阵第 i 行 |
| 一笔行业补贴的系统性波及? | 需求注入 | ΔX=(I−A)⁻¹Δy,分部门读增量 |
| 两个行业谁更"系统重要"? | 乘数/中心性对比 | 列和(需求侧)vs 行和(供给侧)双榜 |
| 引用一个乘数数字前 | 口径检查 | 哪张表/哪一年/进口渗漏扣了没(02 章) |

**行业分析三问仪式**(把本家族用成瑞士军刀):

1. **上游问**:谁供我?——A 第 j 列取重仓部门,再读逆矩阵同列放大倍数;
2. **下游问**:我供谁?——A 第 i 行看销售结构,识别需求端的集中风险;
3. **系统问**:我在网里多重要?——乘数列和与 HEM 抽取痛感,两个角度互证。

三问过完,一个行业的部门间骨架就裸露了——剩下的才是真正难的部分
(技术、竞争、政策博弈——去经济学宇宙对应家族)。

**四个高频坑(踩过的人都沉默了)**:

| 坑 | 症状 | 解药 |
|----|------|------|
| 引乘数不扣进口渗漏 | 带动效应虚高 | 报国内系数口径(实验第 5 段有对照) |
| 跨版本硬接时序 | 分类断点被当经济波动 | 走 concordance 对照并声明损耗(02 章案例 4) |
| 粗表读细结论 | 聚合偏误污染乘数 | 回原粒度表重算(03 章 §一家底) |
| 不查谱就迭代 | 级数装死循环/发散 | 幂法先验证书,ρ≥1 拒算(03 章 §四) |

## 四、与两条供应链的合流

同一张部门网,两个倍率:本家族读**宏观倍率**(部门间,逆矩阵),
兄弟家族管理工程读**微观倍率**(企业间,BOM 与库存传导)。
2023-24 韧性议题(01 章主线 B)同时激活两条:国家层面用 HEM 测"断供的宏观痛",
企业层面用供应链工具测"断供的微观痛"——两个痛感的差,正是产业政策的空间。
