# 讲透区域经济管理 · 块块:经济活动的地理落点怎么管理

> **本质一句话**:区域经济管理=**空间层的经济管理**——
> 经济活动落在地图上从来不均匀(集聚),差距会自我强化(循环累积因果),
> 本家族管三件事:**规划画格子**(功能分区)、**协调平差距**(转移支付/对口协作)、
> **创新造动能**(创新系统/集群政策);再加一件贯穿的:**预见看远处**(区域预期)。
>
> GB/T 13745-2009:630 管理学 · 二级学科 **63032 区域经济管理**(GB/T 未列三级 → 本家族自定主干支 3 支)。
>
> **分工声明**(先读这个再读本家族):兄弟家族 [讲透部门经济管理](../讲透部门经济管理)(63030)是
> **条条**——部门横向方法薄层;本家族是**块块**——区域这个空间单元的纵向管理层。
> 经济侧正主在经济学宇宙:[讲透经济地理学](../../讲透经济学/讲透经济地理学)(79019)给区位与集聚的理论本体,
> [讲透城市经济学](../../讲透经济学/讲透城市经济学)(79047)管城市单元的经济学——
> 本家族管**空间单元的治理与政策工具**,互链不抢地盘。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透区域经济管理/
├── 讲透区域经济规划/   🆓 自定主干支——画格子:空间规划、主体功能区逻辑、规划落地工具
├── 讲透区域协调发展/   🆓 自定主干支——平差距:转移支付、对口协作、差距度量与收敛诊断
└── 讲透区域创新管理/   🆓 自定主干支——造动能:区域创新系统、集群政策、S3 智能专业化
```

> 三支的共同血统:**一切区域经济管理 = 空间单元(格子怎么画)× 流量(钱与人怎么流)
> × 动能(产业与创新怎么育)**。母题只有一句:**地方竞争 vs 区域协调**——
> 竞争是引擎也是摩擦,协调是解药也是代价。
