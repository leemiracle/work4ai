# 讲透区域协调发展 · 平差距:转移支付、对口协作与差距度量

> **定位句**:这支负责"**再分配的水管**"——区域差距怎么量、钱怎么流、
> 协作怎么组织:转移支付(纵向)、对口协作(横向)、区域合作机制、
> 差距度量与收敛诊断。母题"地方竞争 vs 区域协调"的制度侧全部落在这支。
> GB/T 13745 63032 区域经济管理 · **自定主干支**(GB/T 未列三级,家族自定)。
> 家族:[讲透区域经济管理](../README.md)

## 诞生

- **谁/何时**:理论正当性——缪尔达尔 1957 循环累积因果/赫希曼 1958 极化-涓滴
  (市场不自动收敛,干预有理由);建制化——欧盟结构基金 1975 创设、1988 改革
  (集中/伙伴/规划/附加/效率五原则,超国家区域政策最大实验场);
  中国线——1994 分税制重建央地财政关系,一般性/专项转移支付体系成型,
  对口支援制度在灾害重建与区域帮扶中扩展(通说,中性陈述)。
- **因什么问题**:①分权之后地区财力悬殊,基本公共服务要拉平;
  ②帮扶要有载体(钱、项目、人);③"拉平了吗"要能度量。

## 核心问题

**已解决**:
- 差距度量技术:Theil 组间/组内分解、Gini、β/σ 收敛检验(家族 02 章美之时刻 3)
- 转移支付的公式化分配:均等化(标准收支缺口)与专项两分,从讨价还价到公式(财政学通说)
- 协作的组织形式谱系:对口协作(结对)、联席会议、飞地园区、生态补偿

**未解决/深水区**:
- 转移支付的激励效应:均等化会不会松懈地方税收努力(补助的道德风险,无一般解)
- place-based vs place-neutral(2009 双报告对峙未决,家族 00 章 §四)
- 差距的口径之争:人均 GDP/可支配收入/多维福祉各说各话,MAUP 雪上加霜
- 跨界治理:协作机制的约束力弱,合作收益分摊无定价公式

## ✨ 这支最美的一个事实

**Theil 指数把"东西差距"变成一道可加法分解的账**——
总差距 T 恰好等于组间差距+各组内差距的加权和:三十年差距的起落,
多少来自大区之间、多少来自同区省际,一笔一笔查得出来。
**修辞进了代数,政治辩论才有了共同的账本**(与辛普森悖论互为表里:
聚合藏信息,分解还回来)。

## 假设与依赖

- 差距可度量且人均口径代表区域福利(Goodhart 风险:口径被考核即被博弈);
- 转移支付不显著扭曲地方政府行为(道德风险是永远的违约金);
- 协作双方有稳定的剩余可分(否则协作靠行政动员维持);
- 上游:财政学([财政学](../../../讲透经济学/讲透财政学)的分税与均等化本体);
  度量工具上游 [管理计量学](../../讲透管理计量学)
