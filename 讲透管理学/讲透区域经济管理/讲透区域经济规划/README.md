> **定位句**:这支负责"**格子**"——空间上哪里干什么:空间规划、主体功能区、

## 诞生

- **谁/何时**:1933 美国田纳西河流域管理局(TVA)——流域综合开发的建制原型;
  1963 法国设立国土整治与区域行动代表团(DATAR),"国土整治"成为政策语汇;
  德国空间秩序规划(Raumordnung)传统自 1965 年《联邦空间秩序法》定型;
  中国:五年计划中的区域布局 → 1999/2000 西部大开发 → 2010《全国主体功能区规划》
  → 国土空间规划体系改革("多规合一",通说)。
- **因什么问题**:①经济活动空间失衡需要顶层布局(差距与集聚并存);
  ②开发与保护的冲突需要事先划界(不能等建成再拆);
  ③规划互相打架(土地/城建/主体功能各自成图)需要一张图管总。

## 核心问题

**已解决**:
- 功能分区的分类学:按资源环境承载力与开发潜力分级(优化/重点/限制/禁止开发,通说框架)
- 规划编制的程序化:现状评价→战略定位→空间结构→分区管制→项目清单→实施评估
- 规划-土地接口:用地指标与功能区政策的联动工具(开发区模式)

**未解决/深水区**:
- 承载力参数的价值判断藏在科学外观之下——"测度"与"认定"的边界(家族 03 章暗礁)
- 规划的刚性弹性之辨:管制太刚阻碍调整、太柔形同虚设;规划期限与不确定性的错配
- 跨行政区规划的实施主体缺位:都市圈规划"有图无主体"的治理难题

## ✨ 这支最美的一个事实

**主体功能区把"该不该发展"与"能不能发展"拆成两个问题**——
不是每块地都要工业化,限制开发区承担生态与农业功能同样是"发展"(分工意义);
一张图把无限增长假设换成**空间分工假设**。规划思想从"增长极撒胡椒面"
到"功能分工"的转折点,美在它承认:**不发展也是一种被规划的发展**。

## 假设与依赖

- 资源环境承载力可测可比(参数层嵌价值判断——报告必须附敏感性分析);
- 功能可事先认定且相对稳定(技术变迁会翻转功能认定,如页岩气/远程办公);
- 规划有实施工具(土地/财政/考核),否则分区只是着色的纸;
- 上游:区位与集聚理论([经济地理学](../../../讲透经济学/讲透经济地理学));
  城市群内部细部归 [城市经济学](../../../讲透经济学/讲透城市经济学)
