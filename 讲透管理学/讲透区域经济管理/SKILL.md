# 区域经济管理思维技能卡(讲透区域经济管理 · GB/T 63032)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **集聚类**:产业集聚、集群、区位熵、专业镇、产业园区、锚定项目、总部经济
- **差距类**:区域差距、转移支付、对口协作、财政均等化、区域协调发展、收敛
- **规划类**:空间规划、主体功能区、功能区划、都市圈、城市群、国土空间
- **创新类**:区域创新系统、产学研、智能专业化、S3、企业家发现、创新走廊
- **竞争类**:地方竞争、招商引资、重复建设、市场分割、区域合作机制
- **口径类**:注册地 vs 经营地、区域 GDP 归属、产业地图、区域统计口径

## ② 核心思维模式(这个分支怎么想问题)

1. **格子化**:一切区域判断先定位格子——哪个区域×哪个部门,对着全国镜子照(离开基准谈强弱是第一禁忌)
2. **机制化**:增长=大势+结构+本事(转移份额三连);政策效果先问"动了哪一项"
3. **循环化**:差距不是静态而是循环累积因果的瞬间截面——问回波与扩散哪个在主导
4. **口径化**:区域数字先问注册还是经营、边界版本几——考核挂钩的口径必被博弈(古德哈特区域版)
5. **单元敏感**:换聚合层级结论会翻(MAUP)——多尺度报告,聚合方案随结论声明
6. **发现优于蓝图**:选产业是组织发现(EDP)不是委员会拍板——政府当放大器,不当先知

## ③ 工具箱(方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 区位熵 LQ=(区域部门份额)/(全国部门份额) | 集聚识别第一量尺;>1.25 常用参考线;**必须双口径并行** |
| 转移份额分解 ΔE=NS+IM+RS | 增长诊断:拆出大势/结构/本事;恒等零残差,全国 ΣRS=0 |
| Theil 指数(组间/组内分解) | 差距度量与结构透视:"东西差距"变成可分解的账 |
| β/σ 收敛检验 | 差距在缩还是在扩的统计判词(面板) |
| 循环累积因果分析 | 解释差距自我强化/政策逆势事倍功半的机制 |
| 均等化转移支付公式(标准收支缺口法) | 协调支的资金分配设计 |
| DiD/合成控制(空间版) | 区域政策评估:给政策区配"没有政策的平行自己"(上游 [管理计量学](../讲透管理计量学)) |
| 空间权重矩阵+空间计量 | 溢出污染观测时的正确标准误 |
| EDP(企业家发现程序)设计 | S3 式产业方向选择:试探-留痕-放大-退出 |
| 区域情景预见(三情景/地平线扫描) | 不确定性下的规划滚动(方法本体在未来学,波4待建) |

## ④ 常见误区与禁忌

- **离开全国镜子谈区域强弱**:"制造业强市"必须写成"市×部门 LQ 值"——全国结构一变,同一市的读数反转
- **总量排名当本事**:增长亮眼可能全是结构红利(IM 项)——先分解再下结论
- **单口径考核集聚度**:注册地迁移造名义集聚;就业/税收双口径交叉验证是最低防线(家族实验 Part 3)
- **假装政策随机**:先行区多选在本来就要赢的地方——"政策区增长快"≠"政策有效",先配反事实
- **换层级不声明**:按省/市/县聚合结论可合法相反(MAUP)——聚合方案是裁判权,必须随报告声明
- **学硅谷/学深圳**:集聚机制可分析,形态不可移植——政策文献的长期教训(通说)
- **互联互通当万能药**:市场整合期常态是先极化后扩散——不配补偿干预的修路是集聚加速器
- **规划当蓝图一次编定**:不确定性下规划是滚动的情景管理,不是确定性的施工图

| 症状像区域经济管理,其实是… | 判别 |

| 预见方法本体(情景法/德尔菲) | → 未来学(63060,波4待建);本家族只管预见怎么嵌进区域制度 |

| 政府内部治理/府际关系 | → 公共管理(63044,波4待建) |
