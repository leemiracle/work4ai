# 讲透系统管理理论 · 组织=开放系统、反馈与权变:组织的动力学

> **定位句**:这支负责"**动态**"——把组织当作开放系统(与环境交换物质/能量/信息),
> 用存量、流量、反馈与延迟解释组织行为的惯性、振荡与政策抵抗;
> **权变理论为支内节**(权变=开放系统论的比较静态版)。
> GB/T 13745 63015 管理理论 · 三级 **系统管理理论**。家族:[讲透管理理论](../README.md)

## 诞生

- **谁/何时**:贝塔朗菲 1930s-1968 一般系统论(整体大于部分之和的正式表达);
  博尔丁 1956 一般系统论层级;福瑞斯特 1961《工业动力学》(存量-流量-延迟
  的系统动力学);劳伦斯与洛尔施 1967《组织与环境》(权变:分化-整合随环境);
  圣吉 1990《第五项修炼》(学习型组织;系统思考的大众化)。
- **因什么问题**:①局部合理的管理动作为什么整体失灵(部门优化→全局恶化)?
  ②为什么好政策会反弹(政策抵抗:降价→需求激增→服务崩→流失)?
  ③有没有普遍最优的组织结构(权变答:没有,只有匹配)?

## 核心问题

**已解决**:
- 反馈结构决定行为模式:一阶库存调整可解析、加延迟即二阶过冲振荡
  (读本 [../../../讲透管理/](../../../讲透管理/) 02/03 章有闭式与实测,牛鞭 7177× 放大)
- 权变命题族:环境动荡度→结构分化度;技术例行性→集权度的系统调查
- 学习型组织的四修炼框架(系统思考/共同愿景/团队学习/自我超越)的教学化

**未解决/深水区**:
- 系统思考的可操作化:因果回路图至今无标准化语法,仿真校准依赖直觉
- 权变的可证伪性翻修(01 章主线 C:连续错配指数方向)
- 社会技术系统的尺度律:反馈回路在多大组织规模上仍可被管理者感知

## ✨ 这支最美的一个事实

**今天的问题是昨天的解决方案**(圣吉):库存积压源自上月的促销,人员流失
源自去年的降本——沿着反馈回路而不是因果直线找原因,管理归因的整个坐标系
旋转 90 度。

## 假设与依赖

- 组织是开放系统:不与环境交换即死(封闭系统假设在本支非法)
- 反馈结构可建模:人的行为可用政策参数近似(强假设——行为科学支会抗议)
- 权变内节假设:环境-结构可匹配,匹配→绩效(可证伪性弱点两章已记账)
