# 讲透管理哲学 · 组织的目的、管理与人性:一切管理理论的第一因

> **定位句**:这支负责"**为什么**"的层层追问——组织为了什么而存在、
> 管理对人做了什么假设、效率与人性冲突时站在哪边;其他四支给出组织的形式,
> 本支追问组织的意义。
> GB/T 13745 63015 管理理论 · 三级 **管理哲学**。家族:[讲透管理理论](../README.md)

## 诞生

- **谁/何时**:巴纳德 1938《经理人员的职能》把组织定义为"有意识地协调两人以上
  力量与行为的合作系统",首问组织存续的条件;德鲁克 1954《管理的实践》
  确立"管理是一门人文学科";马奇(与塞尔特合著《公司行为理论》1963,
  独著《论组织》1988)把管理哲学带入"组织作为有组织的无序"与"管理者即诗人"。
- **因什么问题**:①科学管理(泰勒制)把人当机器——人的位置在哪?
  ②效率至上与人的尊严冲突时,管理理论的规范立场是什么?
  ③组织的"目的"是谁的目的(股东/利益相关者/组织自身存续)?

## 核心问题

**已解决**:
- 组织存续三条件(共同目的/协作意愿/沟通)的语言学定型(巴纳德)
- "有效性(达成目的)≠ 效率(满足个人动机)"的二分(巴纳德)
- 管理是一种实践(知行合一),不是纯科学也不是纯艺术(德鲁克)

**未解决/深水区**:
- 股东至上 vs 利益相关者的规范之争(01 章 ESG 四框架之争的哲学根)
- 管理知识的地位:它是科学、技艺还是制度化的常识?
- 算法管理的伦理边界:当权威交给代码,责任留给谁

## ✨ 这支最美的一个事实

**组织是反熵的合作**:一个个自由且自利的个体,仅凭"共同目的+沟通+协作意愿"
三要素就能维持一个持续对抗瓦解倾向的系统——巴纳德用三个词写出了
组织版的热力学第二定律及其对抗条件。

## 假设与依赖

- 人有自由意志且值得被当作目的(康德式底色)——与行为科学支的"刺激-反应"人、
  经济学支的"最大化"人构成三种人观,本支的工作之一就是审视这些人观
- 不承诺价值中立:哲学问题问"应然",与实证问题的"实然"分层处理

## 教材锚

- 巴纳德《经理人员的职能》(1938,组织哲学的原典)
- 德鲁克《管理:任务、责任、实践》(1973,管理作为人文学科的系统陈述)
- 马奇 & 奥尔森《重新发现制度》(Rediscovering Institutions, 1989)/马奇《论组织》(组织决策的诗性面)
