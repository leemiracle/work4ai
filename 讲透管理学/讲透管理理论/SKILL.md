# 管理理论思维技能卡(讲透管理理论 · GB/T 63015)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **存在类**:企业为何存在、组织边界、外包还是内建、纵向一体化、平台治理、M 型结构
- **激励类**:委托代理、道德风险、信息租金、代理成本、激励合同、期权设计、提成、绩效考核扭曲
- **交易类**:交易成本、资产专用性、敲竹杠、机会主义、治理结构、合同期限设计
- **认知类**:有限理性、满意即止、启发式与偏差、前景理论、框架效应、群体决策失误
- **动态类**:组织惯性、能力刚性、牛鞭效应、学习型组织、权变匹配、环境-结构适配
- **行为类**:动机、满意度、组织承诺、群体动力、霍桑效应

## ② 核心思维模式(这个分支怎么想问题)

1. **交易成本化**:任何"组织 vs 市场"的选择先问——专用性多高?谈判监督贵不贵?贵则内化
2. **IC 优先**:任何制度先问两条约束——值得留下吗(IR)?值得卖力吗(IC)?租金给了谁?
3. **可观测性上限**:激励只能挂在可观测的信息上——度量不到的任务拿不到激励,这是结构限制不是设计失误
4. **多任务警惕**:强激励单一可测指标,必然扭曲不可测任务(产量↑质量↓是定律不是意外)
5. **满意即止**:真实决策是搜索+阈值,不是全局最优——先问"阈值从哪来",再谈"最优是什么"
6. **惯性追问**:组织失灵先问——这是昨日成功机制(流程/文化/能力的咬合)在今天的延续吗?

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 科斯边界条件(边际治理成本=边际交易成本) | 判断一项交易该市场化、合同化还是内化 |
| 威廉姆森三维(专用性/不确定性/频率) | 给外包/自建决策打分,治理形式匹配 |
| IC/IR 约束求解(线性/两态合同) | 设计提成、奖金、期权结构;估代理成本与租金 |
| Holmström 信息量原则 | 只有含努力信息的指标才配进合同 |
| Holmström-Milgrom 多任务模型 | 强激励前先查:不可测任务会被挤到哪里 |
| 显示原理(上游:博弈论家族) | 把复杂制度重写成"报价单+真话约束"再分析 |
| 权变匹配(动荡分权/稳定集权) | 组织设计的分类学起点(注意可证伪性弱点) |
| 前景理论 v(x)=x^0.88/−2.25(−x)^0.88 | 解释损失厌恶驱动的管理决策偏差 |
| 系统动力学(存量-流量-延迟) | 过冲/振荡/牛鞭/政策抵抗的诊断图 |
| 组织 ABM(Schelling/March 探索-利用) | 宏观形态(隔离/锁定)当作涌现来检验 |

## ④ 常见误区与禁忌

- **把理论当选票**:同一现象,制度派与代理派预测相同机制相反——先定框架再读结论,别混用
- **强激励迷信**:激励强度不是越大越好——代理人风险厌恶时强激励=贵保险,过度则委托人应放弃激励
- **拿 KPI 套知识工作**:可测性结构决定激励形式;多任务/难测任务上强 KPI 必然扭曲(OKR 弱绑定的机制设计理由)
- **事后匹配当预测**:权变解释几乎不可证伪——引用时必须带上边界条件
- **机会主义泛化**:把一切合作解释为算计会丢掉信任/认同的解释力——经济学语言与心理学语言是互补工具
- **仿真当现实**:ABM 的涌现是寓言不是预测;不做敏感性扫描就下结论是滥用
