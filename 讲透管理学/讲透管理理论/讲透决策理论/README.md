# 讲透决策理论 · 有限理性、满意度与偏差:组织的认知学

> **定位句**:这支负责"**判断与选择**"——管理者如何在信息不全、认知有限、
  时间不够下做决定(满意即止),判断在哪里系统性出错(启发式与偏差),
  群体决策何时放大错误(群体思维);管理学里诺奖血缘最直接的一支。
> GB/T 13745 63015 管理理论 · 三级 **决策理论**。家族:[讲透管理理论](../README.md)

## 诞生

- **谁/何时**:西蒙 1947《管理行为》(有限理性+满意度;诺奖 1978)——
  "管理学就是决策科学";卡尼曼与特沃斯基 1974/1979(启发式与偏差、前景理论;
  诺奖 2002);詹尼斯 1972(群体思维);克莱因 1993(自然决策学派:专家在
  真实压力下的识别启动决策,对偏差学派的建设性反题)。
- **因什么问题**:①完全理性假设解释不了真实组织的规则、例规与"够用即止"
  ②判断错误是随机噪声还是系统性可预测的偏差?
  ③一群聪明人开会,为什么做出没人单独会做的蠢决定?

## 核心问题

**已解决**:
- 满意即止:决策=搜索+阈值,不是全局优化(西蒙;组织例规是"冻结的搜索")
- 前景理论:损失厌恶(≈2.25 倍)/参照点依赖/框架效应的参数化
- 群体思维的病理清单(高凝聚+强领导+隔离→症状→决策失误)
- 启发式的"生态理性":少线索启发式在匹配环境下可胜过复杂模型(吉仁泽勒)

**未解决/深水区**:
- 偏差消除的边界:去偏训练 vs"助推" vs 选择架构,长期效果证据仍薄
- 算法建议下的人机决策:自动化偏差(盲信算法)与算法厌恶(拒信算法)并存
- 群体极化的机制分解(信息 cascade vs 声誉顾虑的权重未定)

## ✨ 这支最美的一个事实

**满意度之刀**:把"最优"换成"满意",决策立刻从不可计算的(全局比较无穷选项)
变成可计算的(搜索到过阈值即停)——一刀同时解开了"决策怎么可能是科学"
与"组织为什么靠规则运行"(规则=上一轮搜索结果的冻结)两个死结。

## 假设与依赖

- 认知有限+环境有结构(西蒙的剪刀:行为=认知刃×环境刃),反对"偏差=愚蠢"的
  贬义解读——启发式是适应,不是故障
- 参数化依赖实验与问卷(前景理论数值如 v(x)=x^0.88 有读本实测:见
  [../../../讲透管理/](../../../讲透管理/) 02 章)
- 与[行为科学](../讲透行为科学/)支分界:本支管个体/群体"怎么判断",那支管"为什么肯干"
