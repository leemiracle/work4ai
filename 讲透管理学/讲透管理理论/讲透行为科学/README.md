# 讲透行为科学 · 动机、满意度与群体动力:组织的心学

> **定位句**:这支负责"**人**"——员工为什么愿意努力(动机)、什么让人留任(承诺)、
> 群体里发生了什么(动力/政治/冲突);把组织从结构图还原成一群活人。
> GB/T 13745 63015 管理理论 · 三级 **行为科学**。家族:[讲透管理理论](../README.md)

## 诞生

- **谁/何时**:梅奥 1924-1932 霍桑实验(照明与产量无关、关注即有效——人际关系的
  起点);马斯洛 1943 需求层次;赫茨伯格 1959 双因素(激励因素/保健因素);
  弗鲁姆 1964 期望理论;洛克与莱瑟姆 1990 目标设置理论;卡尼曼-特沃斯基
  1979 前景理论把偏差带回组织决策。
- **因什么问题**:①科学管理与"经济人"解释不了霍桑数据——人到底为什么干活?
  ②高满意度=高绩效吗(二者因果方向的世纪争论)?
  ③正式结构之外,非正式群体如何左右产出?

## 核心问题

**已解决**:
- 目标设置定律:具体且难的目标>模糊的"尽力而为"(效应量最稳的 OB 结论之一)
- 期望理论的路径化:努力→绩效→奖酬→效价,缺一环则动机断
- 组织承诺三维度(情感/持续/规范)的量表化与留任预测
- 双因素的结构性发现:消除不满(保健)≠制造满意(激励)

**未解决/深水区**:
- 满意度→绩效 还是 绩效→满意度(因果箭头至今未定论)
- 经典效应的可复制性缩水(自我损耗等组织版复制失败;01 章主线 C)
- 跨文化效度:美国样本的量表搬到集体主义文化的测量等价性

## ✨ 这支最美的一个事实

**满意的对立面不是不满意,而是"没有满意"**(赫茨伯格):让员工不抱怨靠工资与
制度(保健因素),让员工投入只能靠成就、认可与成长(激励因素)——
两根轴、两套工具, managers 用错工具箱是最常见的浪费。

## 假设与依赖

- 人是"追求意义与关系的有机体",既非经济人(最大化)也非机器(刺激-反应)
- 方法上依赖心理测量学(量表/信效度)——构念操作化规范见家族 [02 章](../02-语言特征.md)
- 前景理论/偏差研究在本支与[决策理论](../讲透决策理论/)支共用,分工:
  本支管"动机与群体",那支管"判断与选择"
