# 讲透组织理论 · 组织为何存在、结构如何选、边界在哪:组织的形学

> **定位句**:这支负责"**形式**"——组织以什么结构存在(科层/矩阵/M 型/网络/平台)、
> 边界画在哪(市场/合同/一体化)、结构怎么随战略与环境演化;
> 家族五支中数学骨血最浓、诺奖密度最高的一支。
> GB/T 13745 63015 管理理论 · 三级 **组织理论**。家族:[讲透管理理论](../README.md)

## 诞生

- **谁/何时**:科斯 1937《企业的性质》(交易成本解释企业存在);钱德勒 1962
  《战略与结构》(结构跟随战略,M 型公司的历史证明);威廉姆森 1975/1985
  《市场与科层》《资本主义经济制度》(交易成本经济学完成体);汉南与弗里曼
  1977 组织生态学(结构随环境被选择)。
- **因什么问题**:①市场那么好,为什么还有企业(存在之问)
  ②同样的业务,为什么长出不同的结构(结构之问)
  ③多样化经营该不该拆分(边界之问——M 型结构的直接催生者)。

## 核心问题

**已解决**:
- 企业存在与边界的交易成本解释(科斯;诺奖 1991)
- 治理结构与交易属性匹配的三分法(市场/混合/科层;威廉姆森,诺奖 2009)
- 结构跟随战略的历史规律(钱德勒:杜邦/通用/标准石油的 M 型演化)
- 组织形态的种群选择动力学(组织生态学的密度依赖等可检验命题)

**未解决/深水区**:
- 平台/算法治理是不是"第四种治理结构"(00 章 §三;01 章主线 B)
- 知识工作的科层失灵:不可编码活动何时自组织优于科层
- 结构与绩效的因果识别(好结构↔好绩效的反向因果泥潭)

## ✨ 这支最美的一个事实

**一个成本概念统一企业与市场**:从现货市场、长期合同、合资到全资子公司,
全部组织形式排在"交易成本 vs 治理成本"的一条连续谱上——组织形式的选择
从意识形态问题变成一道单调比较题(家族 00 章美之时刻 1 的原产地)。

## 假设与依赖

- 机会主义假设(追求私利且施诡计)——买到敲竹杠的可分析性,付出犬儒风险
- 有限理性——合同必然不完备,治理结构是"不完备合同的补丁"
- 数学骨血来自 [../../../讲透数学/讲透博弈论/](../../../讲透数学/讲透博弈论/)(契约理论)
