# 00 · 体系结构:管理计量学家族的全图

> **本章回答五问之一(家族层):整个体系结构长什么样。**
> **本质一句话**:管理计量学=用数据回答管理问题的纪律——
> **测量**(数据从哪来)、**优化**(方案怎么算)、**评价**(谁更好怎么定)三条河道,
> 汇入同一个入海口:**这个做法,到底比那个做法好多少。**
>
> 它是管理学宇宙里离数学最近的门,但测量对象是活的组织——
> **仪器和被测对象会互相改造**,这是本家族全部独特性的来源。

---

## 一、开篇故事:一门学科被点燃了五次

📖 **1911 年,泰勒的秒表**。费城的机械师 Frederick Taylor 出版《科学管理原理》。
他做的事在今天看来朴素得惊人:把工人的操作拆成动作元素,用秒表逐个计时,
找出"唯一最佳方法",再配上差别计件工资。铲生铁的工人日均装载量从 12.5 吨提到 47 吨。
不管后人对泰勒制有多少批判(去人性化、劳资对抗),有一件事是他定义的:
**管理问题第一次被变成测量问题**——管理计量学的计时纪元从这枚秒表开始。

📖 **1924-1932 年,霍桑的灯与它的统计学纠纷**。西电公司霍桑工厂,
研究员做照明实验:调亮灯光,产量升;调暗,产量**还升**;甚至把灯泡换回原样,产量仍升。
Mayo 与 Roethlisberger 的解读——"被关注本身就是激励"(霍桑效应)——
催生了人际关系学派,改写了整个管理学。但故事没完:
继电器装配测试间只有 **5 名工人**,中途两人被换掉(一人产量低、一人不服从),
样本被污染;几十年后经济学家 Levitt 与 List(2011)重新分析原始照明数据,
发现经典的"霍桑效应"在数据里**站不住**——产量趋势更多是实验安排的伪影。
一次塑造了百年管理学的实验,自己却是统计课的反面教材:
**没有干净的对照与足够的样本,组织实验连自己的历史都骗过了。**

📖 **1939-1945 年,布莱克特的马戏团**。二战英国,物理学家 Blackett 带着一队
科学家(人称"布莱克特的马戏团")替军队做"作业研究"(operational research):
深水炸弹定深从 100 英尺改 25 英尺,攻击效率翻倍;扩大护航船队,损失率反而下降。
战后这批人进入工厂与航空公司,**军事计量变身管理计量**;
1947 年 Dantzig 给出单纯形法,线性规划让"资源怎么分"第一次变成一道能算的题。

📖 **1978 年,Charnes、Cooper 与 Rhodes 的效率前沿**。数学家 Charnes 与
管理学家 Cooper 师徒(与学生 Rhodes)在 EJOR 发表《测度决策单元的效率》:
不问价格、不设权重,只用投入产出数据,用**线性规划**把一批同类的银行/医院/学校
"包"出一条生产前沿——前沿内的叫低效,前沿上的叫有效。DEA(数据包络分析)诞生,
"谁更有效率"从拍脑袋变成解方程。

📖 **2000 年代,A/B 测试的互联网重生**。Google、Microsoft、Amazon 把
泰勒的秒表换成日志与分流器:一个按钮的颜色、一条广告标题的长度,
从会议室的争吵变成 24 小时内的统计判决。Microsoft 的实验平台每年跑上万场实验;
一条加长广告标题的实验为 Bing 带来约 12% 的收入提升——**泰勒精神,
规模化到了亿级用户**。霍桑用 5 个工人回答不了的问题,现在用五百万人回答。

**五次点燃的共同基因**:把管理判断交给**可检验的证据**。
秒表、对照组、规划表、前沿、分流器——五件仪器,一门纪律。

## 三、体系结构图:测量→优化→评价的证据循环

```
   管理问题(怎么办才好?)
        │
   ┌────┴─────────────┬──────────────────┐
   ▼                  ▼                  ▼
【测量侧】         【优化侧】          【评价侧】
 实验/抽样/A/B      规划/排队/统筹       DEA/AHP/绩效计量
 生产证据          生产候选方案          生产名次与基准
   │                  │                  │
   └──── 方案 ──实验──▶ 数据 ──评价──▶ 名次 ──▶ 新管理问题
                    (证据循环闭合)
        ▲                                    │
        └──── 被测组织对指标的反应(古德哈特)◀─┘
              ——循环不是中立的,测量会改变被测系统
```

**为什么是循环**:管理计量不是给自然画像,是给一个**会读仪表盘的司机**画像——
指标一旦与奖惩挂钩,组织行为立刻改变。这张图里最要命的是最下面那条回流线,
它是本家族的第一定律(见 §七反直觉)。

## 四、核心问题清单(已解决/未解决,带地位)

**已解决的里程碑**:

| 年代 | 人物 | 结果 |
|------|------|------|
| 1911 | Taylor | 管理操作的测量化:时间-动作研究——"最佳方法"可计时可比 |
| 1926/1935 | Fisher | 随机化+区组+析因:实验设计的一般方法(田间革命,后来整个搬进组织) |
| 1924 | Shewhart | 3σ 控制图:把"异常还是噪声"变成统计判决(质量管理的地基) |
| 1947 | Dantzig | 单纯形法:线性规划可解,资源分配进入可算时代 |
| 1957/1978 | Farrell→Charnes-Cooper-Rhodes | 效率=前沿距离,前沿=线性规划的包络——DEA 可构造 |
| 1977/1980 | Saaty | AHP:两两比较→最大特征向量出权重,CR<0.1 卡一致性 |
| 2000s | Google/Microsoft 实验 | 分流-检验-护栏的 A/B 工业流水线:亿级用户、万级实验/年 |

**悬而未决的大问题(都带地位)**:

- **管理效应量的可重复性——危机中,未解决**。对顶级战略管理期刊的审计
  (Bergh 等,2017)发现统计功效普遍不足、报告错误常见;心理学百年复现计划
  (OSC,2015)里约百项研究只有三四成复现显著——组织行为研究首当其冲。
  注册报告、数据共享正在推开,**证据改革进行到中段,结局未定**。
- **观察数据的因果推断——开放前沿**。组织内数据几乎全是观察数据:
  自选择(好员工才参加培训)、共同方法偏差(同一张问卷测因果两端)、
  SUTVA 违背(同团队互相传染)三重障碍。DiD/断点/工具变量/倾向得分在移植,
  经济学的"可信度革命"尚未在管理学完成。
- **指标博弈的均衡理论——开放**。古德哈特/坎贝尔定律人人会背,
  但"指标在什么激励强度下会被博弈到什么程度"没有一般化的定量模型——
  这是机制设计与计量的交叉空地。
- **DEA 的维度灾难——已知未解**。决策单元少、指标多时几乎所有单位都"落在前沿上",
  判别力崩溃;惩罚型 DEA 与降维是活跃补救方向。
- **小样本组织实验——方法活跃**。团队级随机化的 n 常常不足 50,
  多层模型(人嵌套于团队)的功效分析仍是痛点(见 `experiments/00_goodhart_ab.py` 功效曲线:小效应要每臂近万人)。

## 五、假设与代价(本家族站在什么之上)

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| **可控实验假设**(个体结果互不影响、依从分配、不被"被关注"改变) | 因果解释权:组间差=处理效应 | 组织现实反复违背:团队传染(SUTVA 崩)、实验被知晓(霍桑还魂)、政治干预改分配——实验室干净,组织脏 |
| **样本量换功效** | 小效应也能检出(亿级用户时代的管理学特权) | 伦理与成本:实验即干预,员工/用户是被试;知情同意会污染实验,不知情又越伦理红线——A/B 的每一场大实验都在这条线上走 |
| **参数平稳**(运筹模型:需求分布、到达率已知且不变) | 解析解与最优解(EOQ/M/M/1 的全部优雅) | 组织会变:竞争、政策、组织重组让昨天的分布作废;鲁棒/随机优化是补丁,代价是解变保守 |
| **前沿存在且同质**(DEA:决策单元可比、投入产出同向) | 无价格、无权重的客观效率名次 | 单位不同质时前沿失真;指标一多全员"有效"(维度灾难) |
| **指标=目标**(可测的才被管理) | 可执行、可考核、可对齐 | 真目标(长期价值/组织健康)常不可测,只好测代理——错位角一开,奖惩越狠失真越大(§七) |

**一句话**:管理计量用"假装组织是实验室"换来了全部的精确——
每一行假设,都是它跟组织现实签下的不平等条约,违约金在 §七结算。

## 七、反直觉发现(讲透铁律,本家族两枚)

**发现 1:古德哈特定律——管理计量最大的敌人是自己的成功**。
直觉上,指标越精确、奖惩越挂钩,管理越科学。错。
**一旦测量成为目标,测量就不再是好的测量**(Goodhart 定律的 Strathern 版;
社会学双胞胎叫 Campbell 定律,1976):老师被升学率考核就劝差生弃考,
客服被通话量考核就匆匆挂断,工程师被代码行数考核就注水。
本家族的仪器越锋利(指标、实验、前沿),被测组织的"应试"越精准。
失真不来自测量误差,来自**指标方向本身与目标错位**——
错位角超过 90°,优化指标就是在优化损害。数值实拍:跑
`experiments/00_goodhart_ab.py`(损失 L=1−cosφ 随错位角单调上升,
同一批用户代理指标显著赢、真目标显著输的两份判决书)。

**发现 2:辛普森悖论在绩效考核里埋伏**。
按部门看,每个部门里 A 组的绩效均分都高于 B 组;合并到全公司,A 组反而低——
因为 A 组集中在"打分严"的部门,权重被聚合改写。
**聚合层级的选择就是一个决策**:分层看还是合并看,结论可以合法地相反。
经典原型是 1975 年伯克利研究生录取的性别数据(院系分层后录取差距消失),
绩效考核的分层汇总与之同构——做汇总报表的人,手里握着一项自己未必察觉的裁判权。

## ✨ 美之时刻(全家族合计 ≥3 之前两枚,第三枚在 02 章)

✨ **美之时刻 1:随机对照把管理直觉变成可检验命题**(极简)
"我觉得培训有用"→"培训效应 = +2.1 个百分点,95% CI [0.8, 3.4],p=0.003"。
为什么美:一句不可反驳的直觉被翻译成一句**可被证伪**的陈述——
从此"有用"不再是修辞,是一个带不确定度报告的数字。
亲历:跑 `experiments/00_goodhart_ab.py` 的 Part 2,亲眼看同一个实验
在两个指标上给出方向相反的判决书——可检验性越强,选指标的担子越重。

✨ **美之时刻 2:DEA 用线性规划画出效率前沿**(必然)
不问价格、不设权重、不做回归,只用投入产出矩阵,解一组线性规划,
就把二十家医院的相对效率**包络**出一条前沿:前沿上的无可指摘,
前沿内的给出"该学谁、差在哪个投入产出上"(对偶解=影子价格)。
为什么美:**帕累托前沿从抽象概念变成了每次可解的方程组**——
排名不再需要评委,只需要包络。亲历:04 章走廊 3 有纯标准库的最小 DEA 实现骨架。
