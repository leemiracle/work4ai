# 讲透管理统计与实验设计 · 证据从哪来:组织的数据、实验与对照

> **定位句**:这支负责"**测量**"——抽样调查、管理/现场实验、A/B 平台、
> people analytics、统计过程控制;管理计量的全部证据都从这道门进来。
> GB/T 13745 63025 管理计量学 · **自定主干支**(GB/T 未列三级,家族自定)。家族:[讲透管理计量学](../README.md)

## 诞生

- **谁/何时**:Taylor(1911,秒表)开启测量纪元;Shewhart(1924,3σ 控制图)给出第一张
  统计判决;霍桑工厂(1924-1932)留下正面(人际关注)与反面(5 人样本/无对照)双遗产;
  Fisher(1926/1935)的随机化-区组-析因体系在 2010 年代随"现场实验运动"进入组织;
  Kohavi 等(2000s)把对照实验做成互联网平台;氧气项目(2008)开启 people analytics。
- **因什么问题**:①管理主张如何裁决(直觉 vs 证据)②产量波动是噪声还是异常(Shewhart)
  ③亿级用户的每个改动该不该上线(A/B 平台)。

## 核心问题

**已解决**:
- Fisher 设计体系:随机化消混杂、区组缩方差、析因找交互——实验设计的一般方法
- 控制图:±3σ 判异规则把"异常 vs 噪声"变成统计判决
- 检验的工程化:SRM 质检、CUPED 缩方差、序贯/FDR 校正成为平台标配

**未解决/深水区**:
- 组织内溢出:同团队/同市场互相传染(SUTVA 违背)——switchback/geo/整群设计是进行时
- 小样本团队实验:n<50 的功效灾难与多层模型推断
- 管理效应量的可重复性(危机中,见家族 00 章 §四);观察数据因果:DiD/RDD/IV 的组织版移植未完成

## ✨ 这支最美的一个事实

**随机化=可交换性**——骰子分组的数学后果是两组先验可交换,
于是对照组合法地成为实验组"没有吃药的自己":
**因果的钥匙不在统计公式里,在分组那一刻的设计里**。

## 假设与依赖

- 可控实验三假设:个体结果互不影响(SUTVA)、依从分配、不被"被关注"改变(霍桑还魂)
- 伦理即约束:实验=干预,员工/用户是被试;知情同意会污染实验,不知情越伦理红线
- 推断引擎全部来自数理统计:[../../../讲透数学/讲透数理统计/](../../../讲透数学/讲透数理统计/)
