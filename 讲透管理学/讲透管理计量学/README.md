# 讲透管理计量学 · 用数据回答管理问题的纪律

> **本质一句话**:管理计量学=**用数据回答管理问题的纪律**——把"怎么办才好"
> 从会议室的争论,变成可测量、可计算、可检验、可复盘的命题。
> 泰勒的秒表、运筹学的规划表、DEA 的效率前沿、A/B 测试的分流器,都是这同一门纪律的仪器。
>
> GB/T 13745-2009:630 管理学 · 二级学科 **63025 管理计量学**(GB/T 未列三级 → 本家族自定主干支)。
>
> **定位张力声明**(先读这个再读本家族):本家族是管理学宇宙里**离数学最近的门**,
> 但它的测量对象是**活的组织**——人会对指标做出反应(古德哈特定律)、部门会为口径谈判、
> 实验会在组织里传染。所以本家族一半是仪器(统计/优化/评价的技术),
> 另一半是**仪器与被测对象的缠斗**(指标被博弈、实验被污染、前沿被注水)。
> 应用武器库读本挂靠在 [../../讲透管理/](../../讲透管理)(其 03 章二十余算法全实测),零改写。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透管理计量学/
├── 讲透管理统计与实验设计/  🆓 自定主干支——测量侧:抽样、管理实验、A/B 测试、people analytics(组织的数据从哪来、怎么比)
├── 讲透运筹与优化模型/     🆓 自定主干支——优化侧:规划、排队、库存、统筹、仿真(把"怎么办"变成一道能算的题)
└── 讲透评价与决策计量/     🆓 自定主干支——评价侧:DEA 效率前沿、AHP/TOPSIS 综合评价、绩效计量(给"谁更好"定基准)
```

> 三支的共同血统:**一切管理计量 = 对照(拿什么比)× 模型(用什么算)× 指标(拿什么说话)**。
> 测量侧生产证据,优化侧生产方案,评价侧生产名次——三侧合起来,
> 回答管理学的同一个大问题:**这个做法,到底比那个做法好多少?**
