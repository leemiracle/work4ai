# 讲透评价与决策计量 · 谁更好:效率前沿、综合评价与绩效计量

> **定位句**:这支负责"**评价**"——DEA 效率前沿、AHP/TOPSIS 综合评价、绩效计量、
> 标杆管理;一切"打分排名"的计量学:评委要么是权重,要么是数据,要么是前沿。
> GB/T 13745 63025 管理计量学 · **自定主干支**(GB/T 未列三级,家族自定)。家族:[讲透管理计量学](../README.md)

## 诞生

- **谁/何时**:Farrell(1957)提出生产效率的前沿测度;Charnes-Cooper-Rhodes(1978,
  EJOR《Measuring the Efficiency of Decision Making Units》)用线性规划把它做实——DEA 诞生;
  Saaty(1977/1980)AHP 铸成特征向量;Hwang & Yoon(1981)TOPSIS;
  Kaplan & Norton(1992)平衡计分卡把绩效计量装进战略框架。
- **因什么问题**:①多投入多产出且无价格时,谁更有效率(银行/医院/学校)
  ②多准则冲突时怎么排优先级(AHP/TOPSIS)③组织绩效怎么落到可计量指标(BSC/KPI)。

## 核心问题

**已解决**:
- CCR/BCC 模型:分式规划→线性规划,前沿可构造;对偶解=影子价格(差在哪)
- AHP:权重=最大特征向量(Perron-Frobenius 保证正解),CR<0.1 一致性闸门;
  TOPSIS:正负理想解距离排序——有权重时的机械评委

**未解决/深水区**:
- 维度灾难:单元少指标多→全员前沿化,判别力归零(惩罚型/网络 DEA 是补救,未根治);
  评价博弈:指标即目标即博弈(古德哈特)——无均衡理论,见家族 00 章 §四
- 权重客观性:熵权/变异度法换汤不换药——权重是判断的数学化,不是判断的消失;
  动态前沿:跨期效率演化与"学习曲线"的联合建模仍在途

## ✨ 这支最美的一个事实

**DEA 让每个单元自选最有利的权重,仍然到不了前沿,才叫真的低效**——
不预设价格、不请评委、不做回归,一张投入产出矩阵包络出帕累托前沿;
**排名的公信力来自"让被告自选武器"**。

## 假设与依赖

- 决策单元同质(可比:同为银行网点/同为医院),不同质先分层再各自包络;
  投入产出同向(投入越多产出应越多),前沿存在且可达
- 权重类方法(AHP/TOPSIS)依赖专家判断的一致性;对偶理论来自
  [../../../讲透数学/讲透运筹学/](../../../讲透数学/讲透运筹学/)的 LP
