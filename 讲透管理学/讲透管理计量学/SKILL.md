# 管理计量学思维技能卡(讲透管理计量学 · GB/T 63025)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **指标类**:KPI、北极星指标、护栏指标、口径、指标体系、看板、绩效指标、OKR 度量
- **实验类**:A/B 测试、对照组、随机化、分流、实验设计、试点评估、现场实验、管理实验
- **评价类**:效率评价、DEA、数据包络分析、前沿、AHP、层次分析、TOPSIS、综合评价、标杆
- **量化决策类**:数据、模型与决策、运筹建模、排产/选址/排班、功效分析、效应量
- **风险类**:指标被博弈、刷量、应试、口径不一致、辛普森悖论、可重复性

## ② 核心思维模式(这个分支怎么想问题)

1. **对照化**:一切"多少"都靠称——先问"跟谁比"(过去/他人/最优/反事实四级对照),再谈数字
2. **口径化**:数字先问口径(分子/分母/窗口/版本)——口径即政治,字典即治理
3. **效应量优先**:报告顺序=效应量→置信区间→p 值;统计显著≠管理显著,大样本下尘埃也显著
4. **错位角意识**:指标与真目标有夹角,奖惩越狠失真越大(古德哈特);错位>90° 时优化指标=损害目标
5. **前沿化**:排名不请评委请包络——自选权重仍到不了前沿,才是真的低效(DEA 公信力来源)
6. **嵌套意识**:组织数据人嵌套于团队——有效样本量按团队算,聚合层级的选择就是裁判权

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 随机对照实验(RCT)+ 区组/配对 | 因果问题;Fisher 设计:骰子分组→混杂平均掉;同部门配对再随机压缩噪声 |
| 功效分析 n=2σ²(z_α+z_β)²/δ² | 开实验**之前**算样本量;小效应要每臂近万人 |
| Welch t 检验(大样本正态近似) | A/B 两臂均值/比率比较;不假定等方差 |
| SRM 卡方检验 | 设计 50/50 实测 51/49 即停机——统计之前先验管道 |
| CUPED 方差缩减 | 用实验前协变量缩方差,同样功效省一半流量 |
| DEA(CCR/BCC) | 多投入多产出、无价格场景的相对效率排名;对偶解=影子价格(差在哪) |
| AHP 特征向量权重 + CR<0.1 | 把两两比较判断转成权重;一致性闸门(不挡系统性偏见) |
| TOPSIS | 有权重时的正负理想解距离排序;与 DEA 互补 |
| DiD/断点/工具变量/合成控制 | 实验做不了的观察数据因果;平台时代注意 SUTVA 违背 |
| 控制图(±3σ/判异规则) | 区分异常与噪声;大样本要调判异规则 |
| 黄金分割 0.618 优选 | 无公式无导数的车间调参;保留内部对照点折叠区间 |
| 多层(混合效应)模型 | 人嵌套于团队;整群随机化的推断 |

## ④ 常见误区与禁忌

- **只报 p 值不报效应量**:亿级流量下 +0.01% 也 p<0.001——先问值多少钱
- **把"不显著"读成"没效应"**:小样本功效不足时这是双倍错误(先算功效)
- **偷看与多次检验**:边跑边看 p 值、多指标各测各的——用序贯校正/FDR 兜住
- **单一指标重赏**:必被博弈(古德哈特);指标要成组+护栏+定期回测错位角
- **DEA 指标堆太多**:维度灾难,全员前沿化;指标数 ≤ 单元数/3 起步
- **AHP 当客观**:CR 只挡逻辑矛盾,不挡集体偏见;权重是判断的数学化不是判断的消失
- **个体随机化乱用于传染场景**:司机/用户互相溢出时用 switchback/geo/整群设计
- **聚合层级随手选**:分层与合并可合法地结论相反(辛普森)——聚合方案要随报告声明
