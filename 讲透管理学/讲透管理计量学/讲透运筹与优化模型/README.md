# 讲透运筹与优化模型 · 方案怎么算:把"怎么办才好"变成一道能算的题

> **定位句**:这支负责"**优化**"——线性/整数规划、排队、库存、统筹、仿真进管理情境;
> 管理计量学的方案生产线:目标、约束、随机性三件套一装,最优解可解。
> GB/T 13745 63025 管理计量学 · **自定主干支**(GB/T 未列三级,家族自定)。家族:[讲透管理计量学](../README.md)

## 诞生

- **谁/何时**:1940 年,物理学家 Blackett 的"马戏团"替英军做作业研究
  (深水炸弹定深从 100 英尺改 25 英尺,攻击效率翻倍;扩大护航船队损失率反降);
  1947 年 Dantzig 单纯形法;1948-1953 年战后运筹进入工厂与航空(ORSA/TIMS 成立);
  中国线:1965 年起华罗庚在全国推广"双法"——优选法(0.618)与统筹法(CPM 中国化)。
- **因什么问题**:①有限资源怎么分配最优(规划)②等待与库存怎么控制(排队/库存)
  ③工期怎么排(CPM/PERT)④系统太复杂解不动时怎么办(仿真)。

## 核心问题

**已解决**:
- LP 可解且带对偶(单纯形 1947;椭球法 1979 证多项式可解)
- 解析解全家桶:EOQ、M/M/1 与 Little 定律 L=λW、CPM 关键路径
- 离散事件仿真:解不动的系统可以"跑出来"

**未解决/深水区**:
- 数据驱动优化:参数未知时的分布鲁棒/随机规划(与机器学习的边界仍在谈判)
- 行为运筹:模型里的人是理性的,车间里的人不是
- 大规模整数规划:理论上 NP 难,工业求解器与分解算法的军备竞赛

## ✨ 这支最美的一个事实

**对偶理论:每个约束都有一个影子价格**——
解完规划,对偶变量直接告诉你"哪个约束卡着脖子、放松它值多少钱":
**最优解回答怎么办,对偶解回答瓶颈在哪**——一题双答案,管理语言里叫"洞察"。
