# 未来学思维技能卡

## 1. 何时用此分支(触发词)

遇到以下特征的问题/困惑,切到未来学眼光:

- 「预测、预见、规划有什么区别?」——三动词三态(可能/或然/可取)地基(00 章 §2)
- 「**情景规划**怎么构造?」——选轴→2×2→叙事→早期指标;为什么不以命中率记功
- 「**德尔菲法**为什么有效?」——匿名×迭代×统计反馈压掉群体思维污染;离群者为什么值得存档
- 「**预测怎么算对**?」——布里尔评分/校准/分辨率;为什么单发预言无对错
- 「专家说得那么笃定,该信吗?」——笃定语气的信息量为负;先要账本(T1 事前登记)
- 「这个预言会自己实现/自己破产吗?」——反身性:发布即干预(默顿悖论)
- 「趋势会一直涨下去吗?」——外推假设不入数据;断点恰在区间之外
- 「AI 能帮我们预见吗?」——红利(穷尽性)与代价(神谕语法自动化)及三层闸门

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **概率眼** | 把每个「会/不会」改写成「主体+事件+期限+概率」;无期限的「趋势」先问「到何时」 |
| **账本眼** | 没记录的预测等于没预测;先查 T1 事前登记,再看命中率(命中率是小样本的劣质统计量) |
| **情景眼** | 单一预测是多可能世界的坍缩;重要决策先画 2×2(重要且不确定的两轴),四格各配叙事+早期指标 |
| **反身眼** | 预测发布即干预:高命中率可能是「改变未来」而非「知道未来」的产物 |
| **组合眼** | 实战预见=方法组合(扫描+情景+德尔菲+回推),不是单方法;问「谁做锚」 |
| **模态眼** | 可能/或然/可取对号入座:谁在用「或然」的语气卖「可取」的货 |

## 3. 工具箱

- **三种合法句型**:趋势句(区间+概率)、情景句(边界条件+成套)、野牌句(低概率×高冲击×前兆);神谕句(「十年内必……」)一律先翻译再讨论
- **评分三件**:布里尔评分 Σ(p−o)²/N;校准(说 70% 是否七成发生)×分辨率(敢不敢给区分度);严格正当=说真话是最优策略
- **情景构造五步**:驱动变量清单→选两条轴(重要且不确定)→2×2→每格叙事+不变量→早期指标;两格雷同=轴相关,重选
- **德尔菲规范**:匿名/多轮/只反馈中位数与 IQR;停止规则事前写定;离群意见存档
- **回推法**:从可取未来倒推今日必做(与外推方向相反)
- **评分实验**:`experiments/forecast_scoring.py`——亲眼看裸命中率怎么输给布里尔,反身性怎么虚增命中
- **参考类预测**:估计一个项目,先找同类项目的分布(外部视角),再允许个案修正

## 4. 常见误区与禁忌

- ❌ 用**命中率**论预测英雄:小样本+幸存者偏差+基线策略全在骗你——用布里尔与校准
- ❌ 用**命中**考核情景:情景是排练,不是预测;四者至多一个「发生」(消防演习不用票房评价)
- ❌ 把**共识**当正确:德尔菲的收敛≠真值;对齐是政治美德,估计是认识过程
- ❌ 迷信**复杂模型**:M 竞赛长期结论——简单/组合方法不输复杂模型;瓶颈常在问题定义
- ❌ 迷信**专家笃定度**:名气、资历、置信度与准确率几乎无关(通说);要 T1 账本
- ❌ 忘了**反身性**:一切「发布即干预」的预测(市场/舆论/组织内),其记录不能按标准评分解释
- ❌ 让 AI 裸写情景:LLM 是天生的神谕生成器(无概率、无期限、语气笃定)——模板强制+人审+留痕三闸门
