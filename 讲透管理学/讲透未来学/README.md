# 讲透未来学 · 时间层:把未来从玄学变成方法

> **本质一句话**:未来学 = 给一切决策供时间纵深的学科——它不预言未来,而是把「谈论未来」这件事本身变成**可检验的方法**:预测(forecast)、预见(foresight)、评估(assessment)三套手艺的学科化。
> GB/T 13745-2009:630 管理学 → **63060 未来学**(三级 4 支全落子;6306099 其他学科为兜底,不设系列)。
> 建族日 2026-09-07(七学科 GB13745 扩展·波4,fork 产出一手);宇宙全景:[../README.md](../README.md)。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透未来学/
├── 讲透理论预测学/   📝 预测的理论内核:外推/模型/专家判断,与深度不确定性(6306010)
├── 讲透预测评价学/   📝 预测怎么算对:Brier/校准/分辨率,与预测竞赛(6306020)
├── 讲透技术评估学/   📝 技术的社会后果先行审计:从 OTA 到参与式 TA(6306030)
└── 讲透全球未来学/   📝 全球议题长期趋势的研究方法:人口/资源/技术(6306040)
```

四支是同一门手艺的四个工序:**造预测**(理论预测学)→**给预测记分**(预测评价学)→**审计技术后果**(技术评估学)→**拉到全球与代际尺度**(全球未来学)。与管理学宇宙其他家族的关系一句话:**别人生产决策,本家族生产决策的时间纵深**——战略、研发、规划都要回答「未来会怎样」,未来学把这个问题从直觉变成工艺。
