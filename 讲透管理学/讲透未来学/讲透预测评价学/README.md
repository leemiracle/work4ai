# 讲透预测评价学 · 给预测记分:评分、校准、竞赛与审计(6306020)

> **定位句**:这支负责未来学的「裁判端」——预测怎么算对:严格正当的评分规则、校准与分辨率、预测竞赛的实证体系、以及把「专家」拉下神坛又把「普通人」训练上墙的记录制度。
> GB/T 13745-2009:63060 未来学 → **6306020 预测评价学**。家族:[讲透未来学](../README.md)。

## 诞生

1950 年,气象学家布里尔(G. Brier)为天气预报的概率验证写下 mean(p−o)²;1973 年墨菲把它分解为可靠性(校准)+分辨率+不确定度——评分理论从此有了解剖学。1982 年起,马克里达基斯的 M 系列竞赛把「方法准不准」变成公共数据集上的长期对局;2005/2015 年,泰特洛克的两部著作(《专家政治判断》《超预测》,通说)把同一套尺子量到人类专家身上:「专家≈基线、名气无关、训练+聚合可救」三连判词,把预测评价推入可测量时代。2010s 中期以来在线预测平台让校准记录规模化,本家族实验 `../experiments/forecast_scoring.py` 即其最小教学版。

## 核心问题

已解决:
- 评分规则的数学理论:严格正当性(如实报告概率是唯一最优策略)与分解定理(校准/分辨率/不确定度)
- 竞赛方法论:同题、事前登记、统一结算——「准」从轶事变成数据
- 概率区间的评价(区间评分等)进入业务规范(气象/能源领域,通说)

未解决:
- **情景的有用性度量**:评分管趋势句,情景与扫描的价值无观测器(00 章 §7.3)
- **长周期结算**:五十年尺度的预测,评价者活不到结算日——跨代评分无制度
- **评价的反身性**:公开记录筛选「易测的短期问题」,扭曲预测行为(01 章 §2 悬案)

## ✨ 这支最美的一个事实

布里尔评分的「道德性质」:平方罚分让过度自信的代价超线性——报 0.9 而未发生罚 0.81,报 0.6 只罚 0.36。于是**唯一不被系统惩罚的策略是如实报告自己的不确定性**。一个 1950 年的气象验证公式,同时是数学对象与诚实装置:机制设计里要费大力气才能逼出来的「说真话占优」,在这里是平方项的免费赠品。家族实验的 B 段(裸命中率在小样本下分不出技能与运气,布里尔稳定区分)是它在制度层的回声。

## 假设与依赖

- 可重复性假设:单发事件无对错,必须概率化后靠大数定律转成可统计——离开记录量,评分退化为轶事
- 依赖事前登记(T1 纪律,02 章 §2):无时间戳的「预测」不可评
- 反身性声明:发布即干预的预测,评分解释有先天盲区(实验 C 段)
