# 讲透理论预测学 · 造预测的手艺:外推、模型、专家与情景(6306010)

> **定位句**:这支负责未来学的「生产端」——预测作为一门手艺的理论内核:趋势外推、因果模型、专家判断、情景推演四大方法的统一理论,及其共同的敌人(断点、深度不确定性)。
> GB/T 13745-2009:63060 未来学 → **6306010 理论预测学**。家族:[讲透未来学](../README.md)。

## 诞生

1950 年代,兰德公司把「估计未来」工程化:系统分析+专家聚合(德尔菲法,1953/1963)+情景推演(卡恩 1960s)。1970-80 年代,两条线合流:管理侧的预测学(马克里达基斯的预测竞赛体系 1982 起)与方法论侧的原理化(阿姆斯特朗《预测原理》2001,139 条可检验原则)。同一时期,奈特(1921)的「风险/不确定性」之分被重新激活为「深度不确定性」研究——预测理论从「怎样算得准」进化到「算不准时怎么办」(情景、稳健决策、回推法)。

## 核心问题

已解决:
- 外推的统计理论(指数平滑/ARIMA 类)与预测区间构造;组合预测(Bates & Granger 1969:两个平庸模型的平均常胜过各自)
- 德尔菲流程规范与情景构造规范(壳牌式五步)成为标准工艺

未解决:
- **断点预测**:范式转移恰恰落在一切外推的盲区——没有理论,只有工程替代(区间+情景保险)
- **深度不确定性下的决策理性**:稳健决策(在多数情景下不太糟)与「最优解」的哲学冲突
- 长尺度问题:技术预测的「到达年份」估计系统性偏差的成因(激励?锚定?)

## ✨ 这支最美的一个事实

组合预测的发现(1969,通说):把两个各自平庸的预测模型简单平均,常常**同时胜过两个母模型**。原因是结构性的——各模型的误差方向不同,平均把互相抵消的部分消掉了。这一发现后来在 M 系列竞赛中反复放大:几十万条时间序列上,「组合+简单」长期不输「单一+复杂」。**预测精度的可购买性极低,精度的最大来源是「别把赌注押在一个脑子/一个模型上」**——一句能改写一切「找最强专家」直觉的定理级事实。

## 假设与依赖
