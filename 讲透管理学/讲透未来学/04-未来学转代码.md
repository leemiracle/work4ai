# 04 · 未来学转代码——预见工艺的最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:未来学的问题一旦变成「关于预见数据的计算」就能进代码——外推可拟合、情景可生成、德尔菲可聚合、预测可评分;**唯一不可外包给代码的,是问题定义(什么值得预测)与价值判断(哪个未来可取)**。

## 0. 开篇:一个实验分辨「技能」与「运气」

「这位分析师去年八成的预测都中了,该重仓他的判断吗?」——这是每个决策者都问过的问题。

`experiments/forecast_scoring.py` 用纯标准库给出答案的骨架:模拟两类预测者各几千个「二十题的小生涯」——技能型(信号准确率略高于基线,按贝叶斯后验报价)与运气型(无信号,凭直觉喊 75%/25%)。跑一遍你会看到:**裸命中率在二十题的尺度上频繁分不出两类(甚至偶尔反向),而布里尔评分以明显更高的胜率把两者分开;技能型的校准曲线贴着对角线,直觉型的呈平台状偏离**;脚本最后一段演示更狠的一课:让「预言」影响行为(正反馈),无技能者的命中率也会虚高——**命中率里混着的从来不只是知识,还有预言对世界的作用**。

这是数字未来学的第一课,与史学家族同款:**代码替你算数,替不了你解释数**——尤其当数被反身性污染的时候。

## 1. 可机械化边界(三件套之一):预测市场的边界

未来学里最接近「全自动预见」的设想是预测市场——用价格聚合分散信念(哈耶克式的信息装置;学术综述见 Wolfers & Zitzewitz 2004,通说)。它是可机械化边界的最佳教学案例,因为它的失效点恰好就是未来学的失效点:

| 机制 | 市场能做的 | 边界(为何不能全自动化) |
|------|-----------|------------------------|
| 价格=概率 | 聚合分散信息,比专家平均更准(短期、有流动性的事件) | **流动性约束**:小池子可被操纵;长尾事件(真正的野牌)没人愿意持仓,定价系统性失真 |
| 激励=真话 | 说谎亏钱(评分规则的金融版) | **激励错位**:参与者优化的是赚钱,不是「预见质量」——套利时限与结算时限不匹配时,价格与信念脱钩 |
| 结算=真相 | 用真金白银强制结算 | **反身性**:大额持仓本身改变事件概率(00 章悖论的金融版);市场是系统的一部分,不是旁观者 |

**能进代码的**(预见数据化后的一切):外推拟合与区间、情景组合的枚举与一致性检查、德尔菲轮次统计与收敛检验、信号库的扫描-去重-复查调度、预测评分与校准曲线、路线图 DAG 的关键路径。

**不能进代码的**(预见的「不可判定域」):①**问题定义**——什么值得预测、什么不值得,是价值观;②**轴选择**——情景矩阵的「重要且不确定」无自动判据(03 章 §3);③**可取未来的排序**——回推法的终点是规范判断;④**反身性的剥离**——「命中率是技能还是影响」在记录层不可分(实验 C 段就是证明)。

> 边界的一句话:**代码是预见工艺的车床,不是预见本身**。全自动化的「预见机器」若出现,它优化的一定是可测的东西——而可测的恰恰不是最值钱的。

### 2.1 C1 最小示例:外推的陷阱(纯标准库)

```python
# 趋势外推的最小模型:线性外推 vs 饱和曲线——「看不见的房顶」
HISTORY = [(2015, 8), (2017, 14), (2019, 20), (2021, 26), (2023, 32)]  # 某指标示意

def slope(pts):                        # 最小二乘斜率(教学版)
    n = len(pts); mx = sum(x for x, _ in pts)/n; my = sum(y for _, y in pts)/n
    return sum((x-mx)*(y-my) for x, y in pts) / sum((x-mx)**2 for x, _ in pts)

k = slope(HISTORY)
linear_2030 = 32 + k * (2030 - 2023)              # 直线:一路向上
logistic_2030 = 40 / (1 + (40/8 - 1) * 2.718 ** (-0.25 * (2030-2015)))  # 饱和上限40

# linear_2030 ≈ 50+,logistic_2030 ≈ 38
# ⚠ 用途断言:两条曲线对同一段历史同样拟合,外推却分道扬镳——
#   差异不在数据里,在「有没有上限」这个假设里(02 章:外推假设不入数据)。
#   S 曲线拟合需要上限先验;这就是「简单外推的陷阱」的最小标本。
```

### 2.2 C2 最小示例:情景生成(纯标准库)

```python
AXES = {"经济增长": ["高增长", "低增长"], "监管强度": ["收紧", "宽松"]}

def scenarios(axes):
    names = list(axes)
    out = []
    for v1 in axes[names[0]]:
        for v2 in axes[names[1]]:
            out.append((v1, v2))       # 4 格 = 2^2 组合空间的投影(03 章 §2.1)
    return out

# scenarios(AXES) -> [('高增长','收紧'), ('高增长','宽松'), ('低增长','收紧'), ('低增长','宽松')]
# ⚠ 生成的是骨架不是情景:每格还需叙事+不变量+早期指标(03 章 schema);
#   检查四格叙事若有两格雷同 → 轴相关,投影秩亏,重选轴。
```

### 2.3 C3 最小示例:德尔菲聚合(纯标准库)

```python
ROUNDS = [[2032, 2041, 2038, 2035, 2050],    # R1(03 章 §1.6 的数据)
          [2034, 2040, 2037, 2035, 2046],
          [2035, 2039, 2037, 2036, 2043]]

def iqr(vals):
    s = sorted(vals); n = len(s)
    return s[(n+1)//4], s[3*(n+1)//4]         # 粗四分位(教学版)

for r, vals in enumerate(ROUNDS, 1):
    q1, q3 = iqr(vals)
    print(f"R{r}: 中位数 {sorted(vals)[len(vals)//2]}, IQR [{q1}, {q3}], 宽度 {q3-q1}")
# 输出:IQR 宽度 11 → 6 → 3,收缩率约 45%/50% —— 收敛中,但离群者(2043)仍在
# ⚠ 停止规则(收缩率阈值)须事前写定;离群意见必须存档(03 章 §6:离群者常常是对的)。
```

## 3. 工程师落点:风险雷达与预见底座(三件套之三)

三个落点,把走廊接到真实系统:

1. **组织风险雷达**:C5 走廊的生产化——订阅源+关键词规则+去重+复查队列,做成内部信号库;工程要点是**复查调度**(信号的半衰期管理:无复查制度的信号库一个月后就没人信)与强度分级的人工关卡。对应角色:战略部/风险部的「地平线扫描」职能(01 章热线 1.1 的「进入」在企业侧的形态)。
2. **预测账本与评分服务**:把「拍脑袋会」改造成「登记-结算-评分」管线(事前登记的时间戳是 T1 证据的工程保证,02 章 §2);给内部专家与外部报告建校准档案。对应角色:决策支持/经营分析团队的「预测审计」职能——布里尔评分是它唯一经得起复核的 KPI。
3. **LLM 辅助预见的幻觉治理**:AI 生成情景初稿/扫描摘要时的三层闸门——①**概率化模板强制**(输出必须带 p/期限/条件,无「必将」类词,02 章语法眼);②**人审关卡**(轴选择与叙事一致性,03 章 §3 的不可自动化项);③**全程留痕**(哪个格是机器生成、哪个是人改的,审计可回溯)。对应角色:企业知识工程/AI 应用的治理层——**LLM 是天生的神谕生成器,治理它的手段与治理人类神谕的千年手段同构**。

**工程接口三问**(接入任何预见系统前自问):①问题池谁定的(值得预测的东西,还是容易测的东西)?②事前登记了吗(时间戳)?③反身性声明了吗(这个预测发布后,世界会动吗)?

## 7. 反直觉发现(⑥)

**给「命中」记分的系统,会自动惩罚说真话的人——除非评分规则先行**。想象只按命中率论英雄:最优策略是永远预测基线一侧(50% 的世界里全押「发生」,长期命中率恰 50%,且零信息);而说「60%」的人会周期性「错」而蒙羞。**结构解释**:命中率是对概率陈述的有偏统计量(把连续的 p 压成 0/1 再计数,信息全毁);布里尔评分保留 p 的刻度,才让「如实报告」成为占优策略(02 章 §1.2)。这也是实验的断言 B:**不是技能变难测了,是尺子本身坏了**——管理制度里最常见的一类错误,是把好尺子换成了坏尺子。

## ✨ 美之时刻(⑧)

**✨ 美之时刻:几千个平行小生涯,一小时内跑完一种制度的对错**。`forecast_scoring.py` 没有预测任何未来——它模拟的是**评价制度本身**:同样的技能与运气,放进「命中率考核」与「布里尔考核」两种制度,命运分布完全不同。**为什么美(制度的可实验化)**:真实世界里要分辨技能与运气需要几十年的 track record,而在这里,「换个 KPI 会怎样」成了一个下午可以跑几千次的受控实验;**怎么亲历**:把实验里的 `M_PER_CAREER` 从 20 改成 200,重跑——看裸命中率的胜率怎样缓慢爬升、却始终追不上布里尔——这一分钟你会直观理解「样本量」与「尺子」是两件不同的事。
