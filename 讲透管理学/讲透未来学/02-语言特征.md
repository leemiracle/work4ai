# 02 · 语言特征——三栏:未来话语的表达力/预言的证据学/术语对译

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)**。
> **本质一句话**:谈论未来只有三种合法句型——**趋势句**(带置信区间的时间陈述)、**情景句**(带边界条件的可能世界)、**野牌句**(低概率高冲击的前兆报告);而「预测怎么算对」是一门独立的证据学:**单发事件无对错,概率化陈述才有优劣**。

---

## 0. 开篇:同一个未来的三种写法

假设要谈「未来十年某项能源技术的命运」,三种合法写法:

- **趋势句**(预测体):「按过去十五年的装机曲线外推,该技术在 2032 年前达到 X 规模的概率约 70%(区间 Z)。」——有时间戳、有数值、有概率,可记账。
- **情景句**(预见体):「若碳价机制收紧且储能成本沿低位曲线下行,则(情景 A)……;若两者皆否,则(情景 B)……。」——内部一致的可能世界,四个一起用,不以命中率记功。
- **野牌句**(扫描体):「若某实验室的异常结果可复制,该技术可能在三年内被替代性路线挤出——目前强度:弱信号。」——低概率×高冲击×可指认的前兆。

以及一种**非法但最流行**的写法——神谕句:「十年内,该技术必将重塑格局。」——无期限坐标、无概率、无边界条件,任何结局都能对上(00 章开篇的克罗伊索斯语法)。本章的任务:把三种合法句型的语法、判定与对译讲清楚,让你能把任何神谕句翻译过来。

## 1. 三栏总表:每种话能说什么、不能说什么

| 栏 | 基本单位 | 能说 | 不能说 | 代表场景 |
|----|---------|------|--------|---------|
| **表达力**(趋势/情景/野牌的语法) | 概率化未来陈述:主体+事件+期限+概率 | 压缩不确定性、可聚合、可监测(设早期指标) | 给出确定性——概率句的本质就是放弃「必」字 | 预测报告、路线图、扫描简报 |
| **逻辑性质**(预言的证据学) | 可记分断言:(p, 期限, 结局) | 累积 track record;分辨技能与运气;诊断校准 | 判定单发断言的「对错」——二值预言无优劣只有幸存者 | 评分账本、竞赛、审计 |
| **规范化**(术语与体裁) | 合法的话语形式(术语对译、情景集规范、德尔菲报告体) | 跨机构可比、可审计、可进课程 | 真相本身——规范决定「什么算预测」,不决定「什么会发生」 | 期刊、议会报告、企业 foresight 文档 |

### 1.1 三栏的表达力对照(表达力)

- **趋势句的 表达力=可记账**:一个数值+一个区间+一个期限,预测从此有账本。代价:只能谈「可量化的连续量」,断点(范式转移)恰好落在区间之外。
- **情景句的 表达力=可排练**:一个内部一致的可能世界,让决策在四重世界里各跑一遍(「风洞试验」)。代价:四个情景至多一个「发生」,它的价值无法用命中率度量(00 章 §7.3)——表达力换了一种货币。
- **野牌句的 表达力=可预警**:低概率高冲击事件配上**可指认的前兆**(weak signal),把「不可预测」转化为「可监测」。代价:野牌清单极易膨胀成科幻集——每条都需要强度分级与复查制度。
- **神谕句的 表达力=可动员**:模糊+笃定=传播力最强。它不是要被消灭的敌人,是要被**隔离**的语域:动员场合用神谕体,决策场合必须翻译。

### 1.2 三栏的逻辑性质(逻辑性质):预测怎么算对

这是本家族最独特的一栏——**预言的证据学**:

| 性质 | 二值预言(「X 会发生」) | 概率化陈述(「X 以 p 发生」) |
|------|----------------------|---------------------------|
| 单次结算 | 有对错——但对错≠技能(运气) | 无对错——只有「这次 p=0.7 没中」的信息点 |
| 多次结算 | 命中率(受幸存者偏差污染) | **布里尔评分** Σ(p−o)²/N:越低越好 |
| 技能分解 | 不可分解 | **校准**(说 70% 的事是否七成发生)×**分辨率**(敢不敢对不同的事给不同的数) |
| 策略性质 | 无 | **严格正当**:如实报告真概率是唯一最优策略——说谎必然丢分 |
| 反身性 | 强(自我实现/自我否定) | 发布后世界移动,p 本身失效(00 章 §4 悖论;实验 C 段) |

三个推论值得背下来:①**裸命中率是小样本的劣质统计量**——运气与技能在几十次结算内无法区分(本家族实验的断言核心);②**校准可以零技能**(永远报基线频率的人校准完美、分辨率全无——「 calibrated 破钟」);③**评分规则是诚实装置**——正当性的意思是:骗评分者必先骗自己。

**模态语法的补全**(承 00 章 §2):可能/或然/可取三态对应三种句型的规范用法——趋势句只许谈「或然」,情景句谈「可能」,回推句(从可取未来倒推路径)谈「应当」。混用即语域错误:用趋势句谈可取未来=偷偷夹带价值观;用情景句谈或然=拒绝记分。

### 1.3 规范化:术语对译表(规范化)

未来学的中英术语错位极重,对译表是本学科的「度量衡」:

| 英文 | 中文(本家族用) | 一句话辨析 |
|------|---------------|-----------|
| foresight | 预见 | 面向决策的前瞻**过程**总称;不以命中记功 |
| forecasting | 预测 | 给未来事件配概率/数值;可记分 |
| prediction | 预言/预测(慎用) | 日常混用;学科内留给「单点断言」,与 fuzziness 同罪 |
| projection | 推演 | 条件化外推:「**若**假设成立,则……」——把条件写在明处 |
| scenario | 情景 | 内部一致的可能世界;成套使用(3-4 个) |
| Delphi (method) | 德尔菲法 | 匿名×多轮×统计反馈的专家聚合 |
| horizon scanning | 地平线扫描 | 系统性搜弱信号的过程 |
| weak signal | 弱信号 | 变化的早期征兆(安索夫) |
| wild card | 野牌 | 低概率×高冲击×有前兆的事件 |
| backcasting | 回推法 | 从可取未来倒推今日必做之事;与 forecasting(从过去外推)方向相反 |
| technology assessment (TA) | 技术评估 | 技术后果的先行审计(议会/参与式/建构式) |
| la prospective | (法国)前瞻学派 | 贝尔热开创的欧陆路线 |
| futuribles | 可能未来集 | 德·儒旺内尔术语:可能/或然/可取三分的容器 |
| reference class forecasting | 参考类预测 | 用同类历史项目的分布校正单点估计(「外部视角」) |
| Brier score | 布里尔评分 | (p−o)² 的均值;概率预测的通用货币 |
| calibration / resolution | 校准 / 分辨率 | 说 70% 是否七成发生 / 敢不敢给出区分度 |
| deep uncertainty | 深度不确定性 | 连概率分布都不可信的领域(奈特不确定性) |
| robust decision making | 稳健决策 | 不押单一未来,选「在多数情景下不太糟」的选项 |
| three horizons | 三地平线 | H1 衰退系统/H2 过渡/H3 涌现未来的框架 |
| causal layered analysis (CLA) | 因果分层分析 | 表层/系统/世界观/神话四层拆解(伊纳亚图拉) |
| roadmapping | (技术)路线图 | 时间轴上的技术-产品-市场依赖图 |

**译名纪律**:「预测/预见/评估」三词在本家族严格分工(00 章 §2);「forecasting vs prediction」在中文里塌缩成同一个「预测」,翻译文献时必须回查原文。

## 2. 预测话语的证据约束(track record 的证据学)

与管理思想史家族的史料分级对称,预测记录有自己的等级:

| 等级 | 对应物 | 例 |
|------|-------|----|
| T1 事前登记 | 结算前写下的(断言, 概率, 期限) | 竞赛平台的时间戳提交 |
| T2 事前公开 | 结算前公开发表但格式松散 | 报告里的「预计」「大致」 |
| T3 事后追认 | 结算后声称「早就说过」 | 回忆录里的精准预言(幸存者偏差重灾区) |
| T4 传说 | 无出处流传的名言 | 「某大师预言了 X」——查无原文 |

**底线**:只有 T1/T2 可进评分账本;T3/T4 是修辞弹药。预言史的「十大神准」榜单几乎全由 T3/T4 构成——**把榜单还原成 T1 账本,命中率通常塌缩回基线**(这正是预测评价学支的正题)。

**断言阶梯**(承管理思想史家族写作纪律,未来学版):L1 事实断言(某预测在某日以某概率登记)→ L2 学界共识(正当评分规则的性质)→ L3 竞争解释(壳牌 1973 表现归因:情景之功 vs 其他经营决策)→ L4 家族判读(「预见的产品是感知的改变」)。混层是第一罪。

## 3. 已解决与未解决(③的语言版)

**已解决**:概率陈述的评分与分解理论(正当评分规则/校准-分辨率)数学上完备;情景集的构造规范稳定;术语对译表(§1.3)可在机构间通用。

**未解决**:①**情景的有用性没有度量语法**——评分管趋势句,情景句的「风洞价值」至今只有叙事性评价;②**野牌句的强度分级**无标准(「弱信号」的强弱是修辞判断);③**翻译层的失真**:咨询报告把情景偷换成预测(客户要确定性)——预见话语的最大失真发生在商业翻译层。

## 4. 假设与代价(④)

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 未来可概率化 | 全部评分与聚合工艺 | 深度不确定性被伪装成风险;「分布之外」不可见 |
| 概率如实可得(评分正当) | 诚实成为最优策略 | 人们并不真持有稳定概率——「内在概率」本身是理想化 |
| 情景与预测分工 | 两套表达力各得其所 | 公众与客户永远要求「给个准话」——翻译压力永恒 |
| 术语对译可行 | 跨机构可比 | 中英文义场错位:prospective/foresight/预测 在中文里部分塌缩 |

## 6. 反直觉发现(⑥)

**「说 60%」的专家比「说肯定」的专家更值得信——即使前者错了这一次**。概率化不是软弱,是把每次结算变成一个数据点而非一场审判:说 90% 而连续十次全中,是校准灾难(该说 100% 或运气);说 60% 而十次中六,是完美校准。**笃定语气的信息量是负的**——它与准确率的相关在长期研究中接近零甚至为负(通说)。这就是神谕句必须被翻译的根本理由:它把「置信度」这个最重要的参数直接焊死在语气里,让你无法记账。

## ✨ 美之时刻(⑧)

**✨ 美之时刻:布里尔公式的道德性质**。(p−o)² 平方项的深意:预测 0.9 而未发生,罚 0.81;预测 0.6 而未发生,只罚 0.36——**过度自信的代价超线性增长**。一个气象学的验证公式,暗合了从寓言到伦理学的全部教训(伊索的狼、金融危机的模型)。**为什么美(数学与德性的巧合)**:唯一的占优策略是如实报告你的不确定性——诚实在此不是美德,是解析解。**怎么亲历**:取你最近的十个「我觉得」,硬给它配概率并想象被平方罚分——多数人第一次配数时就会自动调低置信度,公式在你脑内完成了它的规制作用。

## 8. 这章给了你什么新眼睛(⑨升维)

- **语法眼**:听到任何未来话语,先判句型(趋势/情景/野牌/神谕)——神谕句一律先翻译再讨论。

- **译名眼**:中文「预测」一词塌缩了英文三个词的分工;读翻译文献先回查原文。
