# 讲透技术评估学 · 后果的先行审计:从国会 OTA 到公民共识会议(6306030)

> **定位句**:这支负责未来学的「审计端」——技术的社会后果如何在落地前被系统研究:议会建制(OTA)、参与式程序(丹麦共识会议)、建构式路线(荷兰学派),以及「早期预警」的双刃。
> GB/T 13745-2009:63060 未来学 → **6306030 技术评估学**。家族:[讲透未来学](../README.md)。

## 诞生

1960s 末,美国议员达达里奥(E. Daddario)提出 technology assessment 概念:像评估财务报表一样评估技术的后果。1972 年国会立法设立技术评估办公室(OTA),1974 年运转,为国会提供技术后果的独立研究,1995 年被裁撤——二十余年档案成为学科的标准案例库。欧洲走了另一条路:荷兰(1986 年起,后为 Rathenau 研究所)、丹麦(1980s 中期起的技术委员会)发展**参与式 TA**,丹麦的共识会议把普通公民(经材料与听证)请进评估;1990s 荷兰学派又发展**建构式 TA**(Rip/Schot):与其预测技术的后果,不如介入技术的塑形过程本身。当代接口是 FTA(未来导向技术分析)伞形框架(家族 01 章热线 1.3 方向锚)。

## 核心问题

已解决:
- 程序设计:共识会议的公民小组、听证、书面问答流程标准化——「外行能否参与复杂技术判断」有肯定答案(程序得当即可)
- 议会 TA 的组织模式(独立于行政与产业)在多国落地

未解决:
- **效果归因**:TA 报告对立法/技术路线的影响无法干净识别——评估者自己的「命中率悖论」
- **早期定形风险**:过早的评估可能把技术锁死在单一想象里(评估本身是干预)
- 参与的代表性:谁有资格代表「公众」?

## ✨ 这支最美的一个事实

丹麦共识会议把「外行公民」请进技术评估:一群普通人,经数周材料阅读与专家听证后,对复杂技术议题给出结构化的书面意见,且意见质量获得议会采纳。**为什么美**:它证明技术判断的门槛不在知识存量而在程序——材料、听证、质询、修改的流程让普通人的「价值敏感性」(专家最缺的部分)进入评估。信任的来源从「专家权威」换成「程序正当」,这是与德尔菲匿名化同一族的制度发明:用流程设计补人的局限。

## 假设与依赖

- 技术后果可前瞻:评估假设后果在落地前可辨识——技术决定论的隐患(塑形派因此主张「介入」而非「预测」)
- 依赖议会/机构的委托与独立性;参与式 TA 依赖招募与程序预算
- 红线:本支写程序与方法的学科史,不评价任何具体现实技术的政策取舍
