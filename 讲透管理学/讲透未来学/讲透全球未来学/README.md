# 讲透全球未来学 · 长尺度大尺度:全球议题长期趋势的研究方法(6306040)

> **定位句**:这支负责未来学的「长焦端」——全球尺度、数十年到百年尺度议题(人口、资源、环境、技术)长期趋势的**研究方法学**:全球模型、概率区间、情景集、敏感性分析。**只写方法,不做预言**(家族红线)。
> GB/T 13745-2009:63060 未来学 → **6306040 全球未来学**。家族:[讲透未来学](../README.md)。

## 诞生

两条源头。其一是全球建模:1972 年罗马俱乐部委托的《增长的极限》(梅多斯等)用福雷斯特系统动力学构造世界模型 World3,把人口-粮食-资源-污染装进可运行的存量-流量网络——纵然其数据与假设遭到猛烈批评(诺德豪斯「没有数据的测量」,《毁灭的模型》1973),「把地球变成可运行对象」的方法论一步不可逆。其二是长期预测的统计传统:联合国人口司自 1950s 起持续发布长期人口预测,后来发展出概率区间方法(多条历史预测的事后对照给出不确定性的经验刻度)。加上卡恩《2000 年》(1967)的宏观情景传统与千年项目(Glenn & Gordon,《Futures Research Methodology》方法总库)的当代整合,全球未来学成为「N=1 的经验科学」的方法学(见下)。

## 核心问题

已解决:
- 全球模型的透明度标准:假设公开、情景条件声明、敏感性分析成为发表门槛(1973 年之争的直接遗产)
- 长期人口预测的概率区间方法:以历史预测误差校准未来区间(通说)
- 情景集用于跨代议题(能源/气候情景族)的构造规范

未解决:
- **N=1 验证困境**:只有一条已实现的历史曲线,全球模型无法做样本外检验——方法论核心因此是敏感性分析与情景,而非拟合优度
- 跨代公平的形式化:贴现率之争表明,「怎么对待尚未出生的人」在伦理学与数学之间悬而未决
- 指标可比性:跨时空统计口径的断裂是长期曲线的第一噪声源

## ✨ 这支最美的一个事实

全球未来学是一门**只有一个样本点的回归**:人类历史是全球尺度问题的唯一一次实现,没有重抽样的余地。于是它发明了一整套「不可验证者的验证术」——把模型拆成可分别攻击的假设(透明度),把未来拆成条件声明的情景族(条件化),把结论拆成对参数的导数(敏感性分析)。这套「无对照组科学」的方法论遗产,反哺了一切只能观察一次的学科(宏观史、演化、行星科学)。

## 假设与依赖

- 指标可比性假设:百年曲线要求统计口径跨时空可接——常不成立,需逐段校订
- 依赖国际统计体系与公开模型代码;情景族依赖机构持续维护(过期情景比没有情景更糟)
- 写作红线(家族治理):本支按学科文献通说写全球议题的**研究方法**;不载任何具体人口/资源/技术预言,不涉现实政策评价
