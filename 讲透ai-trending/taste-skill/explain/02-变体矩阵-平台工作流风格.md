# 02 · 变体矩阵：平台×工作流×风格语言

> 对象：宪法之外的 7 支实现类变体——平台变体 gpt-tasteskill、工作流变体 image-to-code-skill 与 redesign-skill、风格变体 soft/minimalist/brutalist，外加遗留 taste-skill-v1。共同回答：**默认宪法不合适时替换哪个维度**。README.md:109-118 决策指南即此矩阵的用户视图。

## 一、角色定位

变体不是功能补丁而是**维度替换**：默认宪法假设"Claude/Cursor 系 agent、绿地新站、风格未定"，变体各自改一个假设——平台维度（gpt-taste 假设 GPT/Codex，其统计偏差：窄容器 6 行标题、bento 留空洞、廉价 meta 标签、隐形按钮、左右布局复读，skills/gpt-tasteskill/SKILL.md:7-9）；工作流维度（image-to-code 假设设计先行，"image is the design source, code is the translation layer"，skills/image-to-code-skill/SKILL.md:128-129；redesign-skill 假设存量库在场，skills/redesign-skill/SKILL.md:10-14）；风格维度（三支假设视觉方向已定，README.md:116——可组合的宪法补丁）；时间维度（v1 冻结旧版，README.md:89）。

## 二、内部结构

**gpt-tasteskill（74 行 8 节）**密度最高，四件独门武器：①**Python 伪随机引擎**（:13-20）——agent 须在 `<design_plan>` 里以 prompt 字符数取模为确定性种子模拟 `random.choice()` 选 Hero 架构/字体栈/组件架/GSAP 范式，"You are forbidden from defaulting to the same UI twice"（:20），机制性破解"LLM 永远选列表第一项"；②**AIDA 结构强制**（:22-29）：Navigation→Attention→Interest→Desire→Action，`py-32 md:py-48` 电影分章；③**H1 两行铁律**（:31-34）：6 行标题是"catastrophic failure"，修法=容器加宽（max-w-5xl/6xl）+clamp 字号收小；④**gapless bento**（:42-44）：`grid-flow-dense` 数学互锁"No grid shall have a missing corner"。§8 五项 design_plan 前置核验（:67-74）全过才准写 UI 代码。

**image-to-code-skill（1228 行 38 节）**全仓最长：§1 九刻度盘（:73-92，ANALYSIS_PRECISION 与 IMAGE_GENERATION_EAGERNESS 双 10）；§4 Codex"每节一图"逐条列 1-10 节对应 1-10 图（:162-179）；§5 禁裁旧图——裁剪破坏间距比例必须重生成（:202-217）；§21-25 五类提取规范（text/typography/spacing/button/color）；§29 反模式五类（:897-956）；§33 默认节包 4/8/12 三档（:1033-1065）。

**redesign-skill（179 行）**=3 步序+9 类审计+修复优先级：Scan 读框架→Diagnose 跑清单→Fix 在现有栈上改"Do not rewrite from scratch"（:14）。九类审计中"战略性遗漏"最见功力（:123-130）：法律链接/返回导航/自定义 404/表单校验/skip-link/cookie consent——AI 常忘的六件。修复按收益/风险比排序字体替换第一（:159-169）。

**风格三支**共享骨架（禁令→参数→组件规格→动效→检查表）。soft（install name high-end-visual-design）走 15 万美元代理风（skills/soft-skill/SKILL.md:10）："绝对零"禁令 Inter/厚描边 Lucide/生硬投影/线性缓动全禁（:13-19），三氛围×三布局掷骰（:21-35），Double-Bezel 双嵌套边框（:41-44）。minimalist（minimalist-ui）走 Notion/Linear 极简：禁阴影禁渐变禁 pill 容器（skills/minimalist-skill/SKILL.md:12-22），四色淡化粉彩（:36-40），卡片 `1px solid #EAEAEA` 铁律（:45）。brutalist（industrial-brutalist-ui）双视觉原型二选一禁混用（skills/brutalist-skill/SKILL.md:13）——瑞士工业印刷（:15-17）与 CRT 遥测终端（:19-21）互斥；零 border-radius（:71）、grid gap 1px 刻线（:90）、扫描线劣化（:82-87）。三支禁令几乎不重叠：soft 禁廉价感、minimalist 禁装饰、brutalist 禁柔化——taste=约束下的取舍而非通用审美。

## 三、外部连接

全部变体经 skills/llms.txt:2-12 一行定位、README.md:86-97 选型表挂 install name、skill.sh:6-17 注册本地路径（键名体系不一致，唯 gpt-taste 取 install name）。与宪法的继承分三种：gpt-taste/redesign 独立成文靠术语重叠维持一致（AI-purple 禁令在 redesign:37 复现）；风格三支基本自包含；image-to-code 直接继承三盘扩为九盘（:75-77 与 v2 基线同源）。上下游：imagegen 三支是 image-to-code 生成端弹药（README.md:124-126）；redesign 与 v2 §11 互补（宪法判模式 :787-790，redesign 给工具箱）；跨 skill 复用度最高的是视口稳定性铁律 `min-h-[100dvh]`：soft:37、redesign:49、v2:153 四处一致。

## 四、数据流（三支代表性消费链）

①**gpt-taste 链**：brief 进→§1 在 design_plan 模拟 Python RNG（确定性种子+choice 输出四项选择）→§8 五项核验（RNG/AIDA/Hero 数学/网格密度/标签清扫）→UI 代码出。随机化发生在**规划文本层**——agent 用伪代码"掷骰"再执行结果，可审计。②**image-to-code 链**（:63-69 强制顺序）：生成参考图（每节一图、禁裁剪）→深度分析（§21-25 五类提取）→实现（§27 反漂移 :860-878，§28 缺失细节解析 :880-895）；三步顺序"mandatory"（:69），先写码即违规。③**redesign 链**：Scan 读 stack→Diagnose 产问题列表→Fix 按 :161-169 优先级逐级升级（字体→色彩→hover 态→布局→组件→三态→排版细修），每级可停——与 v2 §11.D "stop when the brief is satisfied" 同构。

## 五、设计决策

- **独立成文而非配置开关**：每变体一份完整 SKILL.md，收益是可单发安装（`--skill "minimalist-ui"`）且禁令可平台定制（gpt-taste 措辞更命令式："You MUST"/"catastrophic failure"）；代价是规则漂移——soft 检查表 11 项（skills/soft-skill/SKILL.md:88-98）对比 v2 六十余项。
- **随机化三梯度**：gpt-taste 强制模拟 Python（最重可审计）；soft"silently roll the dice"（:22，轻量不可见）；image-to-code §12 七维组合引擎（:415-489）。梯度反映对该平台复读倾向的判断。
- **审计先于修复**：redesign 把 60% 篇幅给审计清单（:16-130）而非修法，且显式约束"Do not break existing functionality. Test after every change"（:174）——存量场景风险结构（回归>美学）决定配比。
- **风格变体不预设栈**：三支只给 CSS/Tailwind 级指令不绑 React，栈决策仍归宪法——组合时正交互补。
- **v1 冻结而非删除**：226 行旧版保留成本近零，给依赖精确行为的项目逃生门（README.md:112"Use only if the v2 default breaks something specific"）。

## 六、新人提示

1. 选型从 README.md:109-118 八条指南起步；变体可组合（宪法+一支风格+output-skill 是常见三件套）。
2. 读 gpt-taste 重点看 §1+§8 的 design_plan 闭环——"规划显式化再校验"范式可迁移到任何非设计任务。
3. image-to-code 的"每节一图""禁裁旧图"动机在 :217-231：裁剪破坏间距排版比例，提取质量塌方，重生成才是省。
4. 各变体检查表项数差异大（gpt 5/soft 11/v2 六十余），组合安装以最严者为准，v2 §14 是超集。
5. 对比三支风格禁令表是理解 taste 内涵最快的练习（见二节末对照）。
