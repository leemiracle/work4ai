# 03 · 懒惰研究线：root-causes × remediation × findings

> 对象：`research/` 12 个文件（总索引+主题导读+根因 4+补救 4+发现 2）与产品化落地 `skills/output-skill/SKILL.md`。回答：**为什么 LLM 交付半成品，工程上能做什么**（README.md:180"Background writing that shaped these skills lives in research/"）。

## 一、角色定位

研究线是全仓唯一非提示词资产内容，却是多份 skill 的直接思想来源：output-skill 的占位符禁令与断点续写协议取材于 remediation/reference-prompts.md 的模板；skills/ 目录的 frontmatter 懒加载架构在 remediation/architectural-patterns.md 有量化自证（NOTES-DIGEST 第 3 条称该文"同时是对本仓 skills/ 目录架构的理论自证"）；gpt-taste 的"LLMs are inherently lazy"断言（skills/gpt-tasteskill/SKILL.md:14）可在根因篇找到出处。结构是标准证据分层：research/laziness/README.md 给根因(Why)/补救(How)/证据(What)导读——**why-how-what 三分是可复用骨架**：先证明问题是机制而非玄学，再按干预层级给方案，最后受控实验钉死结论。

## 二、内部结构

**根因四篇**（root-causes/）按训练侧→数据侧→推理侧→产品侧排布：①**RLHF 与算力经济学**——每 token 约 $0.0001 成本（rlhf-and-compute.md:5）使供应商有内在动机压输出，RLHF 奖励"短而自信的总结"而非完整推理（:10-12），并提出"stopping pressure"激进校准——模型学会中途抛"let me know if you want me to continue"；②**训练数据偏差**——Stack Overflow/GitHub 的"# implement auth here + pass"被内化为合法职业格式（training-data-bias.md:5-10），教程式部分实现/省略号文档/论坛骨架四路强化；③**认知捷径**——LazyBench 证前沿模型感知任务简单或上下文过长时**主动**降低计算深度（cognitive-shortcuts.md:5-10"retains the information but chooses not to process it"）；季节性异常：2023-12 输出显著变短，系统提示写明 "It is May" 即恢复（:19-23）；错误规避作第二截断激励（:25-27）；④**输出上限**——200 万输入对 8 千输出窗口不对称（output-limits.md:5-7）迫使预防性压缩，消费级中间件再叠 32K 历史静默截断（:11-13）。

**补救四篇**（remediation/）按干预层级：参数级（parameter-tuning.md 的 softmax 原理+温度 1.5 与 ~0.0 概率对照表 :21-23；Gemini thinking_level 与 legacy thinking_budget 互斥同用 HTTP 400）；提示级（prompt-engineering.md 心理刺激表"$200 tip +45%""take a deep breath 34%→80%"，:5-13，机制=措辞与训练数据中高质量长输出统计相关 :15；语法绑定两件套=强制工具执行+证据块前置 :19-25；三类验证循环 CoVe/反向提示/自评分）；架构级（architectural-patterns.md:5-17 **本仓自证之文**：SKILL.md 懒加载 frontmatter ~100 token 发现钩子+正文按需加载，文档化 35% 上下文节省，描述具体度 68%→90% 发现率 :14-17；后接 MCP 三组件与分块执行）；模板级（reference-prompts.md 五份即用提示：全量输出/代码生成/分析文档/分步推理/续写处理，:7-15，全部围绕禁占位符禁压缩收尾）。

**发现两篇**（findings/）：empirical-results.md 是证据核心——2025-12 三项受控实验：实验 A 多部分指令合规（无一模型同时满足长度要求与全部子指令 :7-14）；实验 B 解码次优性（截断输出与最高置信解一致→截断是**主动行为选择**而非解码失败 :16-22）；实验 C 上下文退化（200 轮对话韧性超预期 :24-30）。合并结论（:32-38）："Laziness is not a failure of memory, context processing, or core model capabilities. It is a behavioral artifact"，三触发器=指令复杂度超内部努力阈值/激进停止压力/对齐层经济约束。references.md 收录 EmotionPrompt（Microsoft）/LazyBench/复合错误规避/季节性冬季假说/2025 受控实验五项引用与延伸阅读。

## 三、外部连接

**output-skill 是产品化出口**（skills/output-skill/SKILL.md，49 行）：Baseline"A partial output is a broken output"（:8-10）；代码九类+话术七类+结构捷径占位符硬失败清单（:12-20，"Let me know if you want me to continue"正是根因①点名的停止压力症状）；Scope-Build-Crosscheck 三步（:22-26 数清交付物→全部生成→回对计数）；长输出协议（:28-41）不压缩不跳结论，写满到干净断点后输出 `[PAUSED — X of Y complete]`（:38），continue 后精确接续无回顾——与 reference-prompts.md 续写模板逐条对应。研究线还自证 skills/ 架构：architectural-patterns.md 解释本仓为何坚持"frontmatter 精简+正文厚重"，llms.txt 是同思想枚举层。对 skill 措辞的反哺：心理刺激表解释多份 skill 的高利害措辞（gpt-taste"catastrophic failure" :34）；"截断是行为选择"支撑检查表"机械可数"设计——模型会主动偷懒，验收谓词必须是无法含糊的计数与二值判断。

## 四、数据流（证据如何变成规则）

三段翻译：①**现象→机制**：根因四篇把"AI 偷懒"拆成四个可命名机制（经济激励/数据分布/认知捷径/窗口不对称），各附可检验证据（成本数字/LazyBench/季节回归/窗口规格）。②**机制→干预**：经济激励与数据分布不可改（训练侧），干预集中在推理侧（调温拉大 token 概率差）与提示侧（语法绑定剥夺裁量权、心理刺激切换分布、验证循环兜底）；架构侧（懒加载/分块）绕开问题——不让长上下文发生。③**干预→产品**：output-skill 把模板级方案压进 49 行并补运行时协议。三实验各对应一条产品决策：实验 B（截断是选择）→占位符定为"hard failures"非警告；实验 A（多部分指令必失）→Scope 步骤强制先数交付物；实验 C（上下文韧性）→断点协议敢依赖"continue 后精确接续"。

## 五、设计决策

- **研究放产品仓内**：README.md:180 的组织让"规则有出处"可追溯；代价是研究压到 425 行，每篇只留机制骨架+关键数据。
- **Why-How-What 而非论文式结构**：根因/补救/发现的目录名直白对应决策链，对 agent 与人都比 introduction/related work 更可导航。
- **结论克制**：empirical-results.md:32-38 限定为"behavioral artifact triggered by"并列三触发器，未把 RLHF 经济学从假说升格定论——口径经得起"这些是推测吗"的质询。
- **模板即代码**：reference-prompts.md 把补救写成可粘贴提示块（代码围栏非散文），研究→工程零摩擦；output-skill 只是把它装进 skill 分发体系。
- **季节性发现的定位**：cognitive-shortcuts.md 的"It is May"最病毒化，但作者只用作"任意上下文信号可移动简洁校准"的论据（:23），没鼓吹往系统提示塞月份。

## 六、新人提示

1. 阅读顺序：research/laziness/README.md → empirical-results.md（先看结论的实验基础）→ 根因四篇 → remediation 四篇 → output-skill 49 行；反向也行但会错过"为什么恰好这九类占位符"的对应。
2. 心理刺激表不是玄学：prompt-engineering.md:15 给了机制（措辞与高质量长输出的统计相关），是分布切换不是"贿赂"。
3. architectural-patterns.md:14-17 的 68%→90% 表是写 SKILL.md frontmatter description 的实操指南——具体到任务域，别写"Helps with X"。
4. 只带走一页：核心结论+实验 B"截断是行为选择而非能力失败"——对付懒惰的正确姿势是**流程约束与验收谓词**，不是换更大模型。
5. 研究线与图像线零交集：懒惰研究针对文本/代码截断，图像 skill 防视觉复读——共享反 slop 哲学但机制不同，别混用结论。
