---

## 📚 定位

CS107A 是 CS107 的 **1 单元配套解题 Lab**。CS107 讲 C 语言、内存模型、指针、数据表示；CS107A 专注于**调试实践**——用 `gdb` 找段错误、用 `valgrind` 抓内存泄漏，把"指针恐惧"转化为"内存掌控"。

---

## 🎯 学习目标

1. 熟练使用 **gdb** 设断点 / 单步 / 查看内存 / 检查栈帧
2. 用 **valgrind** 检测内存泄漏与非法访问
3. 理解栈帧布局，能徒手画指针 / 数组的内存图
4. 建立系统性 debug 方法论（复现 → 最小化 → 定位 → 修复）

---

## 📅 核心模块

1. **gdb 入门**：`break` / `run` / `next` / `step` / `print` / `backtrace`
2. **段错误调试**：`gdb` 定位 segfault 的调用栈
3. **内存泄漏**：`valgrind --leak-check=full` 解读报告
4. **指针陷阱**：野指针 / 悬垂指针 / 越界访问 / 二次释放
5. **数据表示**：补码 / IEEE 754 / 字节序（大小端）
6. **缓冲区溢出**：栈溢出原理与防护
