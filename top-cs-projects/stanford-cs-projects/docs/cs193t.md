# CS193T: Thinking with AI

> Stanford University | 本科 1-2 单位选修 | 2025 新增
> 定位：面向非 CS 专业 / 初学者的 AI 工具实践课

---

## 📚 定位

CS193T 是 Stanford 面向**全校学生**的 AI 实用技能课，不讲原理，教你怎么**用 AI 工具提升学习/工作效率**。涵盖 prompt 工程、AI 辅助编程、AI 辅助写作、批判性使用 AI。

---

## 📅 核心模块

1. **Prompt 工程模式**：Zero-shot / Few-shot / CoT / Role-play / ReAct / Tree-of-Thought
2. **AI 辅助编程**：GitHub Copilot / Cursor / Claude Code 工作流
3. **AI 辅助写作与研究**：文献检索 / 摘要 / 改写 / 引用规范
4. **批判性使用**：识别幻觉 / 验证事实 / 学术诚信
5. **AI 伦理与隐私**：数据安全 / 偏见 / 学术抄袭红线

---

## 💻 项目代码

📁 `supplementary/all_micro_projects.py::cs193t_prompt_patterns()`

实现了 6 种核心 prompt 模式的模板对比：
- Zero-shot: `Summarize: <text>`
- Few-shot: `Example → text`
- Chain-of-Thought: `Think step by step`
- Role-play: `You are an expert doctor`
- ReAct: `Thought → Action → Observation`
- Tree-of-Thought: `Explore 3 branches, pick best`

**运行**：
```bash
cd supplementary && python3 -c "from all_micro_projects import cs193t_prompt_patterns; cs193t_prompt_patterns()"
```
