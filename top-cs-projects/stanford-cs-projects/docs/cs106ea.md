# CS106EA: Exploring AI

> Stanford University | 本科入门 | CS106 系列 AI 探索版
> 定位：面向零基础学生的 AI 编程入门

---

## 📚 定位

CS106EA 是 CS106 系列（Programming Methodology）的 **AI 探索变体**。面向零编程基础学生，用 Python + AI 工具（Copilot/ChatGPT）入门计算思维，同时理解 AI 基本概念。

---

## 📅 核心模块

1. **Python 编程基础**：变量 / 条件 / 循环 / 函数 / 列表
2. **AI 辅助编程**：用 ChatGPT / Copilot 写第一行代码
3. **数据处理入门**：读取文件 / 简单数据分析 / 可视化
4. **AI 概念直觉**：什么是机器学习 / 训练 vs 推理 / AI 能做什么不能做什么
5. **小项目实践**：聊天机器人 / 图片分类器（调库）/ 数据报告

---

## 🎯 学习路径

1. **零基础**：从 Karel 学编程思维 → Python 基础语法 → AI 辅助编程
2. **有基础**：直接做 AI 小项目（聊天机器人 / 图片分类），跳过编程基础
3. **进阶**：完成 CS106EA 后修 CS106A/B 巩固，再修 CS221/CS229 学 AI 原理
