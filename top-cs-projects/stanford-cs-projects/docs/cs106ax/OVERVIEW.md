# CS106AX: Programming Methodology in JavaScript and Python (Accelerated)

> Stanford University, Autumn 2026
> 领域: 编程入门（加速版）
> Prerequisites: 少量编程经验或自学基础
> Units: 3-4
> Difficulty: ⭐⭐

---

## 📚 定位

CS106A 的加速版——同时用 JavaScript 和 Python 双语教学，为有基础的学生提供高效入门路径。

---

## 🎯 学习目标

- 掌握编程核心概念（变量、控制流、函数、数据结构）
- 能在 JS 和 Python 之间灵活切换
- 理解异步编程基础
- 完成与 CS106A 同等难度的项目

---

## 📅 核心模块

### Module 1: 双语言起步
- JS vs Python 语法对比
- 变量、类型、运算符
- 开发环境配置（Node.js / Python）

### Module 2: 控制流与函数
- 条件、循环、异常处理
- 函数定义与调用
- 递归入门

### Module 3: 数据结构
- 数组 / 列表
- 对象 / 字典
- 集合与迭代

### Module 4: 面向对象与模块
- 类与对象
- 继承与组合
- 模块化与包管理（npm / pip）

### Module 5: 异步与 Web
- 异步编程（async/await）
- HTTP 请求与 API 调用
- 简单 Web 应用

```
循环       for(let i=0;i<n;i++){}          for i in range(n):

```

## 📊 关键概念

| 概念 | JavaScript | Python |
|------|-----------|--------|
| **作用域** | let / const / var | 函数级 + global/nonlocal |
| **异步** | Promise / async-await | async-await / asyncio |
| **类型** | 动态 + TS 可选静态 | 动态 + type hints |
| **生态** | npm（前端+Node） | pip（科学计算强） |
