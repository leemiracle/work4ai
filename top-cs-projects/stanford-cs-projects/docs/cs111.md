# CS111: Operating Systems

> Stanford University | 本科核心 | 系统课链核心一环
> 定位：理解程序如何与操作系统交互

---

## 📚 定位

CS111 是 Stanford **操作系统入门课**，衔接 CS107（系统基础）与 CS140（完整 OS 实现）。聚焦进程管理、并发、内存、文件系统等 OS 核心抽象，强调**系统编程实践**。

---

## 📅 核心模块

1. **进程与调度**：进程概念 / 上下文切换 / CPU 调度算法（FCFS/SJF/RR）
2. **线程与并发**：pthread / 互斥锁 / 条件变量 / 死锁
3. **内存管理**：虚拟内存 / 分页 / TLB / 页面置换
4. **文件系统**：inode / 目录结构 / 日志文件系统
5. **I/O 与网络**：系统调用 / 管道 / socket 编程
6. **系统编程**：fork / exec / signal / 共享内存

## 💻 项目代码

📁 `supplementary/all_micro_projects.py::cs111_process_scheduling()`

实现了 CPU 调度算法对比（CS111 经典主题）：
- **FCFS**（先来先服务）：简单但平均等待时间长
- **SJF**（最短作业优先）：最优平均等待时间，但需预知时长

**运行**：
```bash
cd supplementary && python3 -c "from all_micro_projects import cs111_process_scheduling; cs111_process_scheduling()"
```

**输出示例**：
```
FCFS:  Avg wait: 5.00
SJF:   Avg wait: 2.75  ← SJF 显著优于 FCFS
```
