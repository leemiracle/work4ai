# CS199P Independent Work (Project-Oriented)

> Stanford University | 1-10 单元 | 本科独立项目
> Type: **CS199 的"项目导向"变体**
> Prerequisites: 找到 faculty sponsor
> Difficulty: ⭐⭐⭐ - ⭐⭐⭐⭐⭐ (项目决定)

---

## 📚 定位

**CS199 的"Project"版本**。Stanford 课程编号中带 **P** 后缀表示 **Project-based / Practical**,更强调**可交付的工程项目**而非纯研究或自学。

CS199P 用于:学生想做**实质性软件项目**;与 lab / 教授合作**开发真实工具**;把**side project**正式化为学分。

---

## 🎯 适用人群(什么时候选)

- 想做**实际工程项目** (App / 系统 / 工具) 而非纯研究
- 已有**清晰的 project idea** 和实施计划
- 想给**简历加一个 substantial 项目** (比 CS191 更聚焦,可只做个人)
- 与 lab 合作开发**研究工具**

---

## 📋 典型流程

1. **第 1 周**: Project proposal (2-3 页) — 目标 / 用户场景 / 技术栈 / biweekly milestones / 验收标准
2. **第 2-9 周**: 敏捷开发 — 每 1-2 周与 sponsor 评审;维护 GitHub repo (README / tests / CI);写 design doc
3. **第 10 周**: 最终交付 — 可运行软件 + 部署 + 技术文档 (10-20 页) + Demo

---

## 💡 选课建议

### 经典 CS199P 项目类型
1. **Lab 工具开发**: 给教授 lab 写实验框架;给开源项目 (PyG / HF) 写 feature
2. **个人作品集**: SaaS MVP / CLI 工具 / AI 应用 (LLM agent / RAG)
3. **系统 / infra**: mini 编译器 / 数据库 / OS 模块 / 推理引擎
4. **开源贡献**: 给大型开源项目提 PR (作为正式贡献者)

### CS199P vs CS191 vs CS199
| 维度 | CS199P | CS191 | CS199 |
|------|--------|-------|-------|
| 形式 | 个人 / 小组 | 团队为主 | 个人 |
| 主题 | 工程 / 项目 | 工程为主 | 任意 |
| 结构 | 中等 | 高度结构 | 低结构 |

### 常见坑
1. **个人项目缺乏 review** — 没有 peer pressure,容易拖
2. **scope creep** — 学期 10 周想做 Slack,99% 失败
3. **没有用户** — 写完没人用等于白做 (提前找用户)
