# CS399 Independent Project

> Stanford University | 1-10 单元 | 研究生独立项目
> Type: **研究生版 CS199**
> Prerequisites: 找到 faculty advisor
> Difficulty: ⭐⭐ - ⭐⭐⭐⭐⭐ (自定义)

---

## 📚 定位

**研究生版的"独立项目"通用容器**。CS399 是 Stanford CS 研究生用于**任何独立学习 / 研究项目**的注册入口——读论文 / 学新技术 / 做 mini research / 工程项目 / 准备 qualifying exam。

是 MS 和 Engineer 学生**最常见的"自由学分"**——典型用法:
- 想跟某教授做研究但还没正式 RA (CS399 顶替)
- 学一门**学校没开**的技术 (如 vLLM / TPU programming)
- 准备**prelim / qualifying exam**
- 与工业合作项目

---

## 🎯 适用人群(什么时候选)

- **MS / Engineer / 早期 PhD** 学生
- 想做**有 advisor 但无正式 RA 的研究**
- 想学**学校未开**的技术 (guided self-study)
- 想给某教授"试合作" (转 RA 的前置)

---

## 📋 典型流程

1. **找 advisor** (学期前 / 第 1 周):
   - 任何 CS faculty 都可
   - 商量目标 / 工作量 / deliverable
2. **签 CS399 form**:
   - 单元数 (1-10) 由双方定
   - 1 单元 ≈ 3-4 小时/周
3. **学期中执行**:
   - 定期与 advisor 1-on-1 (1-4 周 1 次)
   - 维护 repo / 笔记
4. **期末 deliverable**:
   - 研究报告 / 论文 draft
   - 代码 + 文档
   - presentation
   - (RA 候选) 转 RA 的依据

## 💡 选课建议

### 典型 CS399 用法
1. **research trial**: 跟某教授做 1 学期,看是否适合转 RA / PhD
2. **prelim 准备**: PhD 早期读 area paper
3. **guided 深入**: 学一门技术 (PyTorch 源码 / vLLM 内部) + 写 review
4. **跨学科项目**: 与医学院 / 商学院 / 法学院合作的 CS 项目

### CS399 vs CS499
- **CS399**: 一般独立项目 (MS / 早期 PhD)
- **CS499**: **Advanced Reading & Research**,通常用于 **PhD 学生**做正式研究,常作为 RA 注册载体

### 常见坑
1. **advisor 摆烂** — 找真的关心你的教授
2. **scope 太大** — 一学期别想做 NeurIPS 论文,先做 workshop
3. **单元数虚高** — 1-3 单元就够,5+ 单元一般不允许
