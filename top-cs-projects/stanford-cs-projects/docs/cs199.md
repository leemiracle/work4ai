# CS199 Independent Work

> Stanford University | 1-10 单元 (可累计) | 本科独立学习
> Type: **个人自学项目 / 独立研究**
> Prerequisites: 找到 faculty sponsor (但比 CS195 宽松)
> Difficulty: ⭐⭐ - ⭐⭐⭐⭐⭐ (完全自定义)

---

## 📚 定位

**Stanford 本科的"自学课"通用容器**。CS199 用于**任何不属于标准课程的独立学习**:深读一本书、学一门在线课、复现一篇论文、做一个小工具、为开源项目贡献。

与 CS195 区别:CS195 是**在 lab 内做研究** (advisor 必须是 research faculty);CS199 是**任何独立工作**,sponsor 可以是任何 CS faculty,主题更自由。

---

## 🎯 适用人群(什么时候选)

- 想学一门**学校没开**的技术 (Rust / Zig / Mojo / Lean)
- 想**深读经典书** (SICP / TAOCP / dragon book)
- 想做**小型独立项目** (开源工具 / 个人作品集)
- 想**做研究**但找不到 lab,先自己跑

---

## 📋 典型流程

1. **找 sponsor** (学期前 / 第 1 周): 任何 CS faculty / lecturer 都可;提交 proposal (学习目标 + 计划 + 评估方式)
2. **签 CS199 表格**: 单元数 (1-10) 由双方协商;通常 1 单元 ≈ 3-4 小时/周
3. **学期中自学**: 定期 (每 2-4 周) 与 sponsor check-in;维护学习笔记 / 代码仓库
4. **期末 deliverable** (双方商定): 书评 / 笔记集;代码 + 文档;短报告 (3-10 页);演示

---

## 💡 选课建议

### 经典 CS199 用法
1. **学一门新语言/技术**: Rust / Mojo / Haskell / Lean
2. **深读经典书**: SICP / CSAPP / TAOCP / Dragon Book / CLRS
3. **复现论文**: 选 1-2 篇经典 (Transformer / BERT / DDPM) 用 numpy 复现
4. **开源贡献**: 给 Linux / React / PyTorch / vLLM 提 PR
5. **side project**: 个人 SaaS / 工具 / 博客系统

### 常见坑
1. **sponsor 摆烂** — 找真的关心你的教授,不是"挂名"
2. **scope 太大** — "我要实现一个 PyTorch" 99% 失败,先实现一个 mini autograd
3. **没有 deliverable** — 学期结束啥都没产出,白拿学分
