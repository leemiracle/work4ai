---

## 📚 定位

CS157 是 Stanford **计算逻辑**课，聚焦**逻辑如何用于自动推理和问题求解**。从一阶逻辑到 Prolog 编程，再到定理自动证明与知识表示。衔接 CS103（离散数学）与 CS154（计算理论）。

---

## 📅 核心模块

1. **命题逻辑回顾**：CNF / DNF /归结（Resolution）
2. **一阶逻辑（FOL）**：量词 / 谓词 / 前束范式 / Skolem 化
3. **合一（Unification）**：Prolog 的核心机制——模式匹配变量绑定
4. **归结原理**：Robinson 归结 / 归结反演证明
5. **Prolog 编程**：事实 / 规则 / 查询 / 回溯搜索
6. **知识表示**：本体（Ontology）/ 描述逻辑 / 语义网
7. **自动定理证明**：DPLL / SAT 求解 / SMT 求解

## 💻 项目代码

📁 `supplementary/all_micro_projects.py::cs157_unification()`

实现了 CS157 核心主题：**Unification（合一算法）**——Prolog 的基础机制：
- 变量绑定（大写 = 变量）
- 复合项递归合一
- 示例：`unify(parent(X, alice), parent(bob, alice))` → `{X: bob}`

**运行**：
```bash
cd supplementary && python3 -c "from all_micro_projects import cs157_unification; cs157_unification()"
```

**输出示例**：
```
unify parent(X, alice) with parent(bob, alice): {'X': 'bob'}
```
