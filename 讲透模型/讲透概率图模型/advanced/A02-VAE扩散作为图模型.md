# A02 — VAE / 扩散作为图模型：当代生成模型的祖父学

> 「讲透概率图模型」博士级第三篇。命题：**VAE 和扩散模型不是"深度学习新发明"，而是概率图模型的当代形态**——图结构照旧，因子换成神经网络，推断照旧走 ELBO/采样。配套：[`讲透生成模型/`](../../讲透生成模型/)（生成范式五流派全景）。

## 1. VAE：贝叶斯网络的深度参数化

### 1.1 图结构（与 1988 年无异）

```
z ~ N(0, I)  ──→  x        生成方向：p(x|z) 由解码器网络给出
z ←──  x                  推断方向：q(z|x) 由编码器网络近似 p(z|x)
```

这就是 [01](../01-贝叶斯网络.md) 的两节点网络：先验 $z$ → 观测 $x$。**新东西只有一件**：条件分布由神经网络参数化（$\theta$）。

### 1.2 ELBO 照抄（03/A01 的公式）

$$
\log p(x) \geq \underbrace{\mathbb{E}_{q(z|x)}[\log p(x|z)]}_{\text{重构项}} - \underbrace{\mathrm{KL}(q(z|x) \,\|\, p(z))}_{\text{正则项}}
$$

- **重构项** = 自编码器的损失；**KL 项** = 把 $q$ 拉向先验——变分下界就是"自编码器 + 几何正则"
- **重参数化技巧**（Kingma-Welling 2013）：$z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon,\ \epsilon \sim N(0, I)$——把采样移出梯度路径，ELBO 变可反传
- 几何视角（[A01](A01-变分推断的几何.md)）：**amortized VI**——不为每个 $x$ 解一次投影，而是学一个"投影仪" $q_\phi(z|x)$，一次训练处处推断

## 2. 扩散模型：T 步贝叶斯网络 + 朗之万动力学

### 2.1 正向 = 固定的马尔科夫链

$$q(x_{t-1} | x_t, x_0) = \mathcal{N}\left(\mu, \sigma^2\right) \quad \text{（后验有闭式——高斯共轭）}$$

前向加噪链 $x_0 \to \cdots \to x_T$ 是**手工设定的 DBN**（→ [06](../06-HMM.md)：时间上的贝叶斯网）。

### 2.2 反向 = 学出来的转移，训练目标是 ELBO 的重排

$$L = \mathbb{E}_t \| \epsilon_\theta(x_t, t) - \epsilon \|^2 \quad \text{（简化版，原身是变分下界）}$$

- $\epsilon_\theta$ 预测的**噪声 = score**（$\nabla_x \log p_t(x)$）——学的是能量模型的梯度场
- 采样 = 从 $x_T$ 起**逐步用学到的转移去噪**：朗之万动力学版的 MCMC（→ [05](../05-MCMC.md) §4）

### 2.3 三代一统表

| 概念 | PGM 原型 | 深度形态 |
|---|---|---|
| 生成模型 | 图因子分解 $\prod_c \psi_c$ | 网络参数化的 $p_\theta(x|z)$ / $\epsilon_\theta(x_t,t)$ |
| 推断 | 变分/采样 | 编码器 amortized VI / 反向链采样 |
| 学习 | EM（Baum-Welch 家族）| ELBO + 重参数化 + SGD |
| 配分函数 $Z$ | 不可解的敌人 | 从未出现（MRF→score 直接绕开）|

> **洞察**：[00](../00-概率图模型是什么.md) 说 Pearl 的图因子化思想"30 年后在 ELBO 与反向链里被重新激活"——本篇就是那句线头的展开。**PGM 没有被深度学习取代，它换了个马甲住在每一代生成模型里。**

## 3. 批判性（图模型视角看深度生成模型的固有缺陷）

- **VAE 的模糊**：高斯 $q$ + mean-field 式单峰 → 多模态真后验缩成单峰（[A01](A01-变分推断的几何.md) 的 M-投影病），生成样本糊
- **扩散的慢**：采样 = 长链 MCMC，混合时间由步数付——加速采样器（蒸馏/一致性模型）本质是"学一个好的提议分布"（MCMC 加速的老思路新做）
- **可辨识性**：神经网络因子失去 PGM 的模块语义——你能画出 VAE 的图，却读不出 $z$ 的含义（这是可解释性方向的核心痛点，→ [`讲透可解释性/`](../../讲透可解释性/)）
