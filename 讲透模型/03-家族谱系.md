## 1. 灵魂：训练目标决定能力

$$
\boxed{\text{同架构 + 同规模 + 不同训练目标} = \text{不同的模型家族}}
$$

Transformer 大家族按训练目标分四派：

```
┌──────────────────────────────────────────────────────┐
│                Transformer 大家族                     │
├──────────────┬───────────────────────────────────────┤
│ Encoder-only │ Decoder-only │ Encoder-Decoder │  MoE  │
│ (BERT 系)    │ (GPT 系)     │ (T5 系)         │       │
│ 双向 attn    │ 单向 attn     │ Enc 双向        │ 稀疏  │
│ mask 预测    │ next-token    │ Dec 单向        │ 激活  │
│ 理解为主     │ 生成为主      │ seq2seq         │ 大参  │
│              │               │                 │ 小算  │
└──────────────┴───────────────┴─────────────────┴───────┘
```

## 2. 实验：同架构不同训练目标

### 2.1 任务

学周期序列 $[a, b, a, b, \ldots]$ 长度 8。给序列 $[1, ?, 1, ?, 1, ?, 1, ?]$，看能否补 mask 位置。

### 2.2 同架构（小 Transformer），不同训练目标

| 训练目标 | mask 位置 acc | 设计哲学 |
|---------|:----------:|---------|
| **BERT 风格**（双向 mask）| **100%** | 用其他位置补 mask（理解）|
| **GPT 风格**（单向 next）| **0%** | 用前一个预测后（生成）|

### 2.3 关键观察

- **BERT 100%**：双向看到所有非 mask 位置（1, 1, 1, 1），轻松推断 mask 必为 0。
- **GPT 0%**：单向训练，看到 $[1, ?, 1, ?, \ldots]$ 时，被 mask 的 ? 没有上文，预测失败。

**这就是家族差异的本质**：BERT 学"用上下文补缺"，GPT 学"用上文生下文"。**能力迁移到下游任务时表现完全不同**。

## 3. 四大家族的设计哲学

| 家族 | 训练目标 | 代表模型 | 擅长 | 劣势 |
|------|---------|---------|------|------|
| **Encoder-only** | 双向 mask 预测 | BERT/RoBERTa | 理解/分类/NER | 不擅长生成 |
| **Decoder-only** | 单向 next-token | GPT/Llama/Qwen | 生成/对话/代码 | 理解稍弱 |
| **Encoder-Decoder** | seq2seq | T5/BART | 翻译/摘要 | 开销大 |
| **MoE** | 稀疏激活 | Mixtral/DeepSeek-MoE | 大参数小计算 | 训练难 |

### 3.1 Encoder-only（BERT 系）

**目标**：随机 mask 15% token，用上下文预测。

```
输入: the [MASK] brown fox jumps
目标: quick
```

**优势**：双向 attention，看到全部上下文 → 理解能力强。
**劣势**：不能直接生成（需要适配）。
**典型应用**：分类、NER、句子相似度。

### 3.2 Decoder-only（GPT 系）

**目标**：用前 $t$ 个 token 预测第 $t+1$ 个。

```
输入: the quick brown
目标: fox
```

**优势**：天然生成模型 + in-context learning 涌现。
**劣势**：单向 attention，理解稍弱（但 GPT-4 级别已基本解决）。
**典型应用**：聊天、代码、推理。

### 3.3 Encoder-Decoder（T5 系）

**目标**：seq2seq，输入序列 → 输出序列。

```
输入: translate English to French: Hello world
目标: Bonjour le monde
```

**优势**：统一所有任务为"text-to-text"。
**劣势**：参数效率低（encoder 和 decoder 各占一半）。
**典型应用**：翻译、摘要。

### 3.4 MoE（稀疏激活）

**架构改造**：每个 FFN 层换成 N 个 expert，每个 token 只激活 top-2。

```
token → Router → 选 2 个 expert → 只算这 2 个
其他 6 个 expert 不算 → 计算量 ≈ 13B, 但参数量 = 47B
```

**优势**：参数爆炸但计算不变 → 性能接近 dense 大模型，推理成本低。
**劣势**：训练难（负载均衡）、显存大（所有 expert 都要载入）。
**典型**：Mixtral 8x7B、DeepSeek-V3 671B（37B active）。

## 4. 为什么 Decoder-only 统一 LLM 江湖？

2020 年后，**所有主流 LLM 都是 Decoder-only**：GPT、Llama、Qwen、DeepSeek、Claude、Gemini。

### 4.1 四大原因

1. **生成 = 通用接口**：聊天、代码、推理、翻译都能统一为"生成下一个 token"。
2. **in-context learning 涌现**（[Brown 2020](https://arxiv.org/abs/2005.14165)）：175B+ 的 Decoder 突然能"给几个例子学新任务"，Encoder 做不到。
3. **工程简单**：单架构 + 单目标，最容易 scale。
4. **Scaling Law 研究最透**：OpenAI 的 Kaplan 2020 用的就是 Decoder。

### 4.2 BERT 系的退场

2020 年后，BERT 系基本停止大版本更新。原因：
- in-context learning 让 Decoder 也能做"理解"任务
- BERT 的 fine-tune 范式被 prompt engineering 取代
- 工业界统一到 Decoder-only 降工程成本

> 但 BERT 系没有死——在**专门任务**（如向量化、文本分类、NER）上仍广泛使用，因为效率高。Sentence-BERT、ModernBERT 等仍在迭代。

## 5. 历代模型谱系（2018-2024）

```
2018  BERT (Google)         Encoder, 340M
2018  GPT-1 (OpenAI)        Decoder, 117M
2019  T5 (Google)           Enc-Dec, 11B
2019  GPT-2 (OpenAI)        Decoder, 1.5B
2020  GPT-3 (OpenAI)        Decoder, 175B (ICL 涌现)
2021  Switch Transformer    MoE, 1.6T
2022  Chinchilla (DeepMind) Decoder, 70B (Chinchilla 定律)
2022  PaLM (Google)         Decoder, 540B
2023  Llama-2 (Meta)        Decoder, 7B/13B/70B (开源)
2023  Mixtral (Mistral)     MoE, 8x7B (开源 MoE)
2023  GPT-4 (OpenAI)        疑似 MoE, ~1.7T
2024  Llama-3 (Meta)        8B/70B/405B (开源 SOTA)
2024  Qwen-2.5 (阿里)       0.5B-72B + MoE
2024  DeepSeek-V3           MoE 671B (37B active) — 开源 MoE 里程碑
2024  Claude-3.5            闭源 SOTA
2024  Gemini 2              多模态原生
```

### 5.1 2024 年趋势

1. **MoE 成大模型标配**：DeepSeek-V3、Mixtral、Qwen-MoE 都用 MoE
2. **开源追上闭源**：Llama-3 405B 接近 GPT-4
3. **多模态原生**：Gemini、GPT-4o、Claude 3.5 不再是"视觉模块 + 语言模型"
4. **挑战者出现**：Mamba/Jamba 挑战 Transformer

## 6. 一句话总结

> **同架构 + 同规模 + 不同训练目标 = 不同家族。BERT 双向 mask（理解）、GPT 单向 next-token（生成）、T5 seq2seq（翻译）、MoE 稀疏激活（大参小算）。实验实证：BERT 风格 100% 补 mask、GPT 风格 0%（单向看不到 mask）。Decoder-only 统一 LLM 江湖的四大原因：生成 = 通用接口、in-context learning 涌现、工程简单、Scaling Law 透。2024 趋势：MoE 成标配、开源追上闭源、多模态原生、Mamba 挑战 Transformer。**
