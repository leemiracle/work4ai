# 附录 B — 朴素贝叶斯分类：用贝叶斯定理做文本分类

> 对应 SLP3 附录 B。朴素贝叶斯 (NB) 是文本分类最简单的概率方法——训练只需要“数数”，预测只需要“比大小”。它“朴素”得令人发笑，却至今在垃圾邮件过滤和情感分析中打平 logistic 回归。
>
> 配套实验：`experiments/B_naive_bayes.py`

---

## 1. 直觉：贝叶斯定理 + 一个“天真”的假设

你想判断一封邮件是不是垃圾邮件。朴素贝叶斯的思路：

> **反过来想**：不看“垃圾邮件长什么样”来判别，而是问“假设这封是垃圾邮件，它长这样的概率有多大” vs “假设这封是正常邮件，它长这样的概率有多大”。

这就是**贝叶斯定理**的核心翻转：

$$P(c \mid d) = \frac{P(c) \cdot P(d \mid c)}{P(d)}$$

- $P(c \mid d)$：给定文档 $d$，类别是 $c$ 的**后验概率**（我们想要的）
- $P(c)$：类别 $c$ 的**先验概率**（垃圾邮件的总体比例）
- $P(d \mid c)$：**似然**——如果这封是垃圾邮件，它长这样的概率

### “朴素”在哪？

文档 $d$ 是一堆词 $w_1, w_2, \ldots, w_n$。计算 $P(d \mid c) = P(w_1, w_2, \ldots, w_n \mid c)$ 需要知道这些词的**联合分布**——组合爆炸。

**朴素假设**：给定类别，词与词之间**条件独立**：

$$P(w_1, w_2, \ldots, w_n \mid c) = \prod_{i=1}^{n} P(w_i \mid c)$$

这当然是错的！“免费”和“中奖”在垃圾邮件里高度相关。但 NB 出奇地好用——因为它只需要**排序**正确（谁的分数更高），不需要概率精确。

> **类比**：你判断一个人的职业，假设“穿格子衫”“戴眼镜”“会用 Python”这三个特征相互独立。当然不独立（都是程序员的特征），但如果你的目标是区分程序员和律师，这三个特征的乘积已经够用了——即使概率值不精确，排序是对的。

## 2. 数学：完整推导

### 2.1 从贝叶斯定理到分类规则

文档 $d$ 的最可能类别：

$$\hat{c} = \arg\max_{c \in C} P(c \mid d) = \arg\max_{c} \frac{P(c) P(d \mid c)}{P(d)}$$

$P(d)$ 对所有类别一样（分母不随 $c$ 变），可以扔掉：

$$\hat{c} = \arg\max_{c} P(c) \cdot P(d \mid c)$$

代入朴素假设：

$$\boxed{\hat{c} = \arg\max_{c} \ P(c) \prod_{i=1}^{n} P(w_i \mid c)}$$

### 2.2 对数空间

$n$ 个小概率相乘会下溢。取 $\log$ 变加法：

$$\hat{c} = \arg\max_{c} \Big[\log P(c) + \sum_{i=1}^{n} \log P(w_i \mid c)\Big]$$

### 2.3 多项式模型（Multinomial NB）

把文档看成“词袋”（忽略顺序），用词频：

$$P(w \mid c) = \frac{\text{count}(w, c)}{\sum_{w' \in V} \text{count}(w', c)}$$

即：在类别 $c$ 的所有训练文档中，词 $w$ 出现的次数 / 类别 $c$ 的总词数。

**问题**：如果测试文档里有个训练集没见过的词，$\text{count}(w, c) = 0$，则 $P(w \mid c) = 0$，整个乘积变成 0。

### 2.4 加一平滑（Add-1 / Laplace）

$$P(w \mid c) = \frac{\text{count}(w, c) + 1}{\sum_{w'} \text{count}(w', c) + |V|}$$

给每个词的计数加 1，分母加 $|V|$（词表大小）保证概率和仍为 1。永远不会有零概率。

## 3. 训练 = 数数

朴素贝叶斯的训练没有梯度下降、没有迭代、没有反向传播——**纯粹数数**：

```
训练：
  对每个类别 c：
    prior[c] = 该类文档数 / 总文档数
    对每个词 w：
      likelihood[w][c] = (w 在 c 类文档中的总出现次数 + 1)
                         / (c 类文档的总词数 + |V|)
```

**一步完成。** 这是 NB 对 logistic 回归的最大优势：训练是 $O(n)$ 一次扫描，而 logistic 需要 $O(n \cdot T)$（$T$ 轮迭代）。

## 4. 朴素贝叶斯 vs 逻辑回归：生成式 vs 判别式

| | 朴素贝叶斯（生成式） | 逻辑回归（判别式） |
|---|---|---|
| 建模对象 | $P(c) \cdot P(d \mid c)$ | $P(c \mid d)$ 直接 |
| 条件独立假设 | 有（“朴素”） | 无 |
| 训练 | 数数，一遍 | 梯度下降，多轮迭代 |
| 需要数据量 | 少（先验 + 计数即可） | 多（学权重需要足够样本） |
| 收敛速度 | 立即 | 慢（需多轮） |
| 概率输出 | 不精确（条件独立假设错） | 精确（直接优化 $P(c \mid d)$） |

### Ng & Jordan (2002) 的经典理论结论

> 当训练数据 $\to \infty$，**判别式模型（logistic）的上界更高**——它不做错误假设。
> 但当训练数据**有限**时，**生成式模型（NB）更快达到自己的上界**——因为“朴素”假设是强先验，相当于大量正则化。

这解释了一个**反直觉现象**（也是配套实验的核心发现）：

> **在文本分类中，朴素贝叶斯和 logistic 回归的准确率出奇地接近。** 数据少时 NB 赢（数数即收敛），数据多时 logistic 微赢或持平。Wang & Manning (2012) 在多个情感分析数据集上验证了这一点。

## 6. 二值 Bernoulli NB vs 多项式 NB

SLP3 区分两种 NB 模型：

| | 多项式 NB | Bernoulli NB |
|---|---|---|
| 文档表示 | 词频（词出现几次） | 二值（词是否出现） |
| 似然 | $P(w \mid c) = \text{count}(w,c) / \text{total}(c)$ | $P(w \mid c) = \text{含 w 的 c 类文档数} / \text{c 类文档数}$ |
| 缺失词 | 不影响 | 显式计算 $P(\text{不出现} \mid c)$ |
| 适用 | 长文本（邮件、评论） | 短文本（推文、标题） |

**经验法则**：绝大多数文本分类用**多项式 NB**效果更好，因为词频携带信息（“垃圾邮件里 `free` 出现 3 次”比“`free` 出现过”更有信息量）。

## 7. 局限与批判

1. **条件独立假设错误**：词之间高度相关。“New” 和 “York” 几乎总是一起出现。NB 忽略这种关联，导致概率估计不精确（但分类排序通常仍对）。

2. **词频 vs 语义**：NB 纯看词频，不理解语义。“not good” 和 “good” 都贡献正向分数，除非特征工程（bigram、否定处理）。

3. **被 LLM 取代但未被 logistic 取代**：在极简场景（垃圾过滤、路由分类）中 NB 仍在生产中运行——因为训练成本极低、推理只需查表。但在精度要求高的场景，已被 BERT/LLM 取代。

4. **“朴素”既是优点也是缺点**：作为强先验，它在小数据上抗过拟合（优点）；在大数据上限制上限（缺点）。这正是生成式 vs 判别式的本质权衡。
