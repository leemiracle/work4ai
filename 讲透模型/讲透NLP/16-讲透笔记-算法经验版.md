## §0 全局视角：TTS = ASR 的逆问题，但更难

ASR 是**判别**（音频→文本，找最可能的文本），TTS 是**生成**（文本→音频，生成合理音频）。

**为什么 TTS 更难？**
1. **一对多**：同一文本有无数种合理音频（不同人、不同情绪、不同语速）
2. **连续高维输出**：1 秒音频 = 16000 个采样点
3. **主观评估**：质量难以自动评测

| 时代 | 算法 | 算法本质 |
|------|------|---------|
| 共振峰合成 | 源-滤波参数化 | 手工物理建模 |
| 拼接合成 | 单元选择 + 平滑 | 数据驱动 + 插值 |
| 参数合成 (HMM) | 统计建模 + vocoder | 概率生成 |
| 神经 TTS (Tacotron) | attention seq2seq + mel | 端到端 |
| 声码器 (WaveNet) | 自回归采样 | 因果 LM 思想 |
| 端到端 (VITS, NaturalSpeech) | flow + VAE + diffusion | 概率生成 |

## §1 六条算法经验

### 算法经验 TS1：生成 vs 判别的根本差异

> ASR（判别）：给音频，找最可能文本 → 用 argmax 即可
> TTS（生成）：给文本，**生成**合理音频 → 必须建模分布
>
> **生成任务的核心难题：如何评估？如何处理一对多？**

可迁移：
- **MT**（Ch12）：判别式（seq2seq + argmax）vs 生成式
- **图像生成**：GAN/VAE/diffusion 都是生成式
- **推荐**：CTR 判别 vs 用户行为生成

### 算法经验 TS2：两阶段 vs 端到端

> 神经 TTS 标准架构：
> - **Stage 1**：文本 → mel 谱（Tacotron/Transformer-TTS）
> - **Stage 2**：mel 谱 → 波形（vocoder：WaveNet/HifiGAN）
>
> 为什么两阶段？**mel 谱是文本和波形之间的"中间表示"，降维 + 可解释**。

可迁移（对应 T6 端到端 vs 流水线）：两阶段用中间表示降低难度，端到端损失精度可控性。**所有"超长跨度生成"任务都考虑两阶段**：
- **文本→图像**：text → latent → image（Stable Diffusion）
- **文本→视频**：text → keyframe → video（Sora）
- **代码→执行**：spec → code → test

### 算法经验 TS3：自回归生成在波形上太慢

> WaveNet 用**自回归**生成波形：每个采样点依赖前面所有点。1 秒音频 = 16000 步生成 → **太慢**。
>
> 解法谱系：
> - **WaveNet**（自回归）：质量好但极慢
> - **Parallel WaveNet**（flow）：用知识蒸馏加速
> - **WaveGlow**（flow）：可并行但模型大
> - **HifiGAN**（GAN）：完全前向，速度快质量好
> - **Diffusion**（去噪）：质量极高但慢

可迁移（对应 Ch12 T9 自回归）：**自回归生成的瓶颈是"无法并行"，所有序列生成都面临这个权衡**——LLM 生成、视频生成、音频生成都是。

### 算法经验 TS4：声音克隆 = 少样本学习

> 现代 TTS（VALL-E, NaturalSpeech 2）：用**3 秒**音频克隆任意人声。
>
> 算法本质：**少样本学习 + 说话人嵌入**。
> - 训练时：在百万小时多说话数据上预训练
> - 推理时：用 3 秒音频算说话人嵌入，条件化生成

可迁移：
- **图像生成**：DreamBooth 用几张图定制主体
- **代码助手**：用几个例子定制代码风格
- **Few-shot learning**：所有大模型的 in-context learning

### 算法经验 TS5：评估生成模型的主观性

> TTS 评估不能用单一指标：
> - **MOS**（平均意见分）：人工打分，准但贵
> - **CMOS / AB test**：相对比较
> - **客观指标**（MCD, PESQ）：自动但有偏
>
> **生成任务的评估本质上是主观的**——这与 BLEU（Ch12 T8）、FID 一致。

可迁移：**所有生成任务（文本/图像/音频）都需要主观评估 + 客观指标双轨制**。

### 算法经验 TS6：声码器的演化 = ML 框架的演化史

> vocoder 演化完美对应 ML 框架演化：
> - **WaveNet**（2016）：自回归 → 因果卷积
> - **Glow**（2018）：normalizing flow → 可逆变换
> - **HifiGAN**（2020）：GAN → 对抗训练
> - **Diffusion**（2022）：去噪扩散 → 迭代采样
>
> **每种 ML 框架都能用来做声码器**——TTS 成了 ML 框架的"试炼场"。

可迁移（强化 T1）：**新框架先在小生成任务（音频/图像）上验证，再上 LLM**。
