## 0. 为什么从 logistic 回归开始

文本分类（text classification / text categorization）是 NLP 里**最古老、最常见、也最赚钱**的任务：给一段文字，输出一个标签。

> SLP3 开篇引用了博尔赫斯笔下那部「想象中的古代百科全书」，把动物分成「属于皇帝的 / 标本 / 难以计数的 / 用极细驼毛笔画出来的 / 刚刚打碎花瓶的 /……」——好在我们语言处理要分的类，没有这么疯。

现实里你天天见它：

| 任务 | 输入 | 输出（标签） |
|------|------|------------|
| **垃圾邮件检测**（spam detection） | 一封邮件 | 垃圾 / 正常 |
| **情感分析**（sentiment analysis） | 一条影评 | 正面 / 负面 |
| **主题分类**（topic classification） | 一篇新闻 | 政治 / 体育 / 科技 / … |
| **意图识别**（intent detection） | 用户一句话 | 订票 / 查询 / 退订 |
| **毒性检测**（toxicity） | 一条评论 | 有害 / 无害 |

SLP3 选 **logistic regression（逻辑回归）** 作为第一个分类器来教，理由极其充分：

1. **它最简单**：一层线性 + 一个 sigmoid，没有隐藏层、没有非线性。
2. **它最优**：损失函数是**凸的（convex）**——梯度下降从任何起点出发都保证找到全局最优，不像神经网络那样陷入局部极小。这一点在 SLP3 里被反复强调。
3. **它最透明**：每个特征对应一个权重，权重正负与大小直接告诉你「这个词怎么影响分类」——可解释性至今不可替代。
4. **它是一个 0 隐藏层的神经网络**：logistic 回归 = 没有隐藏层的神经网络。**神经网络的输出层，本质上就是一个 softmax 回归。** 学会这一章，你就掌握了所有分类器（包括 LLM 的 next-token 输出层）的最后一步。

> 🎯 本章的核心信息只有一句：**logistic 回归是把「线性打分」变成「概率」，再用「交叉熵」把它拉到正确答案上——整套机制会原封不动地复现在每一个深度学习分类器的输出层。**

## 一、直觉层：从「打分」到「概率」

### 1.1 监督学习的四件套

SLP3 把任何**概率分类器**（包括 logistic 回归、朴素贝叶斯、神经网络）拆成**四个组件**。这是全章的总框架，记住它，后面所有模型都往里填：

1. **特征表示（feature representation）**：把输入 $x$ 变成一个数值向量 $[x_1, x_2, \dots, x_n]$。比如「这条影评里 `awesome` 出现了几次」。
2. **分类函数（classification function）**：把特征向量算成一个概率 $P(y\mid x)$。本章是 **sigmoid**（二分类）和 **softmax**（多分类）。
3. **目标函数（objective / loss function）**：衡量「预测 $\hat y$ 离真实 $y$ 有多远」。本章是**交叉熵损失（cross-entropy loss）**。
4. **优化算法（optimizer）**：调参数让损失最小。本章是**梯度下降（gradient descent）**。

它有两个阶段：

- **训练（training）**：用带标签的训练集 $\{(x^{(1)},y^{(1)}), \dots, (x^{(m)},y^{(m)})\}$ 学权重 $w$ 和偏置 $b$。
- **测试 / 推断（test / inference）**：拿到新输入 $x$，算 $P(y\mid x)$，取概率最大的标签。

### 1.2 一个比喻：带权重的「证据天平」

把分类想象成一架**天平**：

- 每个特征 $x_i$（比如「`free` 出现 1 次」）是一颗**砝码**。
- 每个砝码有自己的**权重** $w_i$（`free` 这个砝码很重、而且偏向「垃圾」那一端）。
- 把所有「砝码 × 权重」加起来，再加一个基准偏置 $b$，得到一个**总分** $z$。
- $z$ 大于 0 偏向正类，小于 0 偏向负类。

$$
z = w \cdot x + b = \sum_{i=1}^{n} w_i x_i + b
$$

问题来了：$z$ 是个 $(-\infty, +\infty)$ 的实数，**它不是概率**。我们要的是 $[0,1]$ 之间的、能说「$87\%$ 是垃圾邮件」的东西。

### 1.3 sigmoid：把任意实数「挤」进 [0,1]

**sigmoid 函数**（也叫 logistic function，整个方法的名字就来自它）：

$$
\sigma(z) = \frac{1}{1+e^{-z}}
$$

它的形状是一条「S」：

- $z=0$ 时 $\sigma=0.5$（五五开，决策边界）。
- $z\to+\infty$ 时 $\sigma\to 1$。
- $z\to-\infty$ 时 $\sigma\to 0$。
- 在 0 附近近似线性，两端把离群值「压扁」到 0 或 1。

于是我们直接把这个概率当成 $P(y=1\mid x)$：

$$\boxed{\;P(y=1\mid x) = \sigma(w\cdot x + b),\qquad P(y=0\mid x) = 1 - \sigma(w\cdot x+b)\;}$$

> 为什么 $P(y=0)$ 正好是 $1-\sigma$？因为 sigmoid 有个绝妙性质 $\sigma(-z)=1-\sigma(z)$，所以两类概率天然相加为 1。

**决策**：$\hat y = 1$ 当且仅当 $P(y=1\mid x) > 0.5$，也就是 $w\cdot x + b > 0$。**决策边界是一条（超）平面**——这就是它叫「线性分类器」的原因。

## 二、数学层：损失、梯度、正则化

### 2.1 损失 = 负对数似然 = 二元交叉熵

我们知道每条样本的真实标签 $y\in\{0,1\}$，模型给出预测 $\hat y=\sigma(z)\in(0,1)$。要学 $w,b$，需要一个衡量「$\hat y$ 与 $y$ 差多远」的量。SLP3 的做法是**条件最大似然（conditional maximum likelihood）**：选能让「训练集里真实标签出现概率最大」的参数。

对单条样本，因为只有 0/1 两种结果，这是一个**伯努利分布**，可以一句话写成：

$$
P(y\mid x) = \hat y^{\,y}\,(1-\hat y)^{1-y}
$$

（验证：$y=1$ 时退化为 $\hat y$；$y=0$ 时退化为 $1-\hat y$。）取对数、取负，得到**单样本损失**：

$$
L_{\text{CE}}(\hat y, y) = -\big[\,y\log\hat y + (1-y)\log(1-\hat y)\,\big]
$$

这就是**二元交叉熵（binary cross-entropy, BCE）**，也叫**负对数似然（negative log-likelihood, NLL）**。两个名字、同一个东西——一个从信息论来（见 `../讲透信息论/`），一个从统计来。

直觉：

- 若 $y=1$：损失 $=-\log\hat y$。$\hat y$ 越接近 1，损失越接近 0；$\hat y\to0$ 时损失 $\to\infty$（**自信地答错，重罚**）。
- 若 $y=0$：损失 $=-\log(1-\hat y)$，对称地惩罚。

整个训练集的损失取平均：$L = \frac{1}{m}\sum_{i=1}^{m} L_{\text{CE}}(\hat y^{(i)}, y^{(i)})$。

### 2.2 梯度下降推导：一个「极简到优美」的结果

我们要 $\arg\min_{w,b} L$。用链式法则求 $\partial L/\partial w_j$。先记一个**关键恒等式**——sigmoid 的导数：

$$
\sigma'(z) = \sigma(z)\big(1-\sigma(z)\big) = \hat y(1-\hat y)
$$

一步步走（单样本）：

$$
\frac{\partial L}{\partial \hat y} = -\frac{y}{\hat y} + \frac{1-y}{1-\hat y} = \frac{\hat y - y}{\hat y(1-\hat y)}
$$

再乘上 $\partial\hat y/\partial z = \sigma'(z)$：

$$
\frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat y}\cdot\sigma'(z) = \frac{\hat y - y}{\hat y(1-\hat y)}\cdot\hat y(1-\hat y) = \hat y - y
$$

分母被完美约掉！再对 $w_j$ 求导（$z = \sum_k w_k x_k + b$，故 $\partial z/\partial w_j = x_j$）：

$$\boxed{\;\frac{\partial L}{\partial w_j} = (\hat y - y)\,x_j,\qquad \frac{\partial L}{\partial b} = \hat y - y\;}$$

> 🎯 **这是全章最美的结论**：梯度 = **（预测 − 真实）× 输入**。预测对了（$\hat y=y$）梯度为 0、不动；预测错了，误差 $(\hat y - y)$ 越大、对应特征 $x_j$ 越大，权重就被纠正得越多。**这个形式会一字不差地复现在每个神经网络的输出层**——记住它，后面到处是它。

**梯度下降更新**（学习率 $\eta$）：

$$
w_j \leftarrow w_j - \eta(\hat y - y)x_j,\qquad b \leftarrow b - \eta(\hat y - y)
$$

**随机梯度下降（SGD）** 是其在线版本：每看一条样本就更新一次（而不是攒满整个训练集）。SLP3 主推 SGD。

> **凸性（convexity）**：logistic 回归的交叉熵损失是**凸函数**，只有一个全局最小值。所以梯度下降保证收敛到最优——这是它比神经网络「乖」的根本原因（神经网络的损失非凸）。

### 2.3 多分类：softmax 回归（与二分类的关系）

当类别 $>2$（比如主题分类有 5 类），把 sigmoid 换成 **softmax**。每个类 $k$ 有自己的权重向量 $w_k$ 和偏置 $b_k$，先算每类的得分 $z_k = w_k\cdot x + b_k$，再归一化成概率：

$$
\hat y_k = P(y=k\mid x) = \frac{e^{z_k}}{\sum_{k'=1}^{K} e^{z_{k'}}}
$$

损失换成**分类交叉熵**（$y$ 是 one-hot）：

$$
L = -\sum_{k=1}^{K} y_k \log \hat y_k
$$

梯度同样是那个优美形式：$\dfrac{\partial L}{\partial z_k} = \hat y_k - y_k$。

**softmax 和 sigmoid 的关系**（关键桥梁）：当 $K=2$ 时，softmax 回归在数学上**等价于**二元 logistic 回归。因为 softmax 对所有得分加同一个常数不变（$e^{z_k+c}$ 里 $c$ 约掉），两个类的权重向量可以减成「差向量」$w_1 - w_0$，恰好就是二分类里那个 $w$。换句话说：

$$
\text{sigmoid 是 softmax 的 }K{=}2\text{ 特例。}
$$

这也是为什么 PyTorch 里二分类既可以写 `sigmoid+BCE`，也可以写「2 个 logit + `CrossEntropyLoss`」——两者等价，后者只是没用上那个自由度。

### 2.4 正则化：L2 收缩，L1 稀疏

文本分类的词典动辄上万维，但样本可能只有几千条——**极易过拟合**。做法是在损失上加一个惩罚项：

| | 惩罚项 | 梯度（对 $w$） | 效果 |
|---|---|---|---|
| **L2（ridge）** | $\tfrac{\lambda}{2}\lVert w\rVert_2^2$ | $+\lambda w$ | 把所有权重**整体缩小**，平滑 |
| **L1（lasso）** | $\lambda\lVert w\rVert_1$ | $+\lambda\,\mathrm{sign}(w)$（次梯度） | 把大量权重压成**精确的 0**，稀疏 |

**为什么 L1 会稀疏？** 几何直觉：L1 约束区域是「菱形」（坐标轴对齐的尖角），损失等高线（椭圆）更可能在**尖角**处与之相切，而尖角意味着某些坐标恰好为 0。L2 约束区域是「球」，相切点一般不落在轴上，所以权重都小但都不为 0。

> 工程细节：要让 L1 产生**精确**的 0（而不只是接近 0），通常用 **proximal 梯度 / 软阈值（soft-thresholding）**：先做一步普通梯度，再把每个权重朝 0 拉一个 $\eta\lambda$，拉过 0 就截断成 0。本实验就是这么实现的。

### 2.5 特征工程：BoW 与 TF-IDF

在神经网络之前，「特征」要**手工设计**。文本最经典的两种：

**词袋（Bag of Words, BoW）**：忽略词序，把文档表示成「每个词出现几次」的向量。

$$
x_i = \text{count}(\text{词 } i \text{ 在文档中出现次数})\quad(\text{或二值 } x_i\in\{0,1\})
$$

**TF-IDF（Term Frequency–Inverse Document Frequency）**：在 BoW 上加权——**在这个文档里常出现、但在整个语料里少见**的词，更有区分力。

$$
\mathrm{tfidf}(t,d) = \underbrace{\mathrm{tf}(t,d)}_{\text{词频}} \cdot \underbrace{\log\frac{N}{\mathrm{df}(t)}}_{\text{逆文档频率 idf}}
$$

- $\mathrm{df}(t)$：有多少篇文档含词 $t$。
- `the/a/is` 这种到处都有的词，$\mathrm{df}$ 大、idf 小、被压低。
- `casino/guaranteed` 这种只在少数文档出现的词，idf 大、被抬高。

> BoW / TF-IDF 是**稀疏、离散、手工**特征——它们属于「前神经时代」。第 5 章 word2vec 之后，特征变成「学出来的稠密向量」。但别小看它们：本实验会证明，在干净任务上它们能把「冻结的稠密 embedding」打得找不到北。

## 三、代码层：从零的 logistic 回归

```bash
cd 讲透NLP && python3 -u experiments/04_logistic_textclass.py
```

脚本只用 NumPy + 标准库，从零实现 sigmoid、交叉熵、梯度下降、L1/L2、TF-IDF。**没有 sklearn，没有 torch。** 核心三段（完整版见 `experiments/04_logistic_textclass.py`）：

**① 数值稳定的 sigmoid**（避免 `exp` 上溢）：

```python
def sigmoid(z):
    out = np.empty_like(z)
    pos = z >= 0
    out[pos] = 1.0 / (1.0 + np.exp(-z[pos]))
    ez = np.exp(z[~pos])
    out[~pos] = ez / (1.0 + ez)
    return out
```

**② 梯度下降核心**（直接用第 2.2 节那个优美公式，L1 用软阈值）：

```python
gz = (sigmoid(X @ w + b) - y) / m
grad_w = X.T @ gz + l2 * w
w = w - lr * grad_w
if l1 > 0:
    w = np.sign(w) * np.maximum(np.abs(w) - lr * l1, 0.0)
```

**③ TF-IDF 从零**（sklearn 风格的平滑 idf + L2 行归一化）：

```python
df = (X_counts > 0).sum(axis=0)
idf = np.log((N + 1) / (df + 1)) + 1
X_tfidf = X_counts * idf
X_tfidf /= np.linalg.norm(X_tfidf, axis=1, keepdims=True)
```

**结果 2 & 反直觉 1 · 三种特征 × logistic（20 次随机划分，平均测试准确率）**：

| 特征表示 | 平均测试准确率 | std |
|---|---|---|
| 二值 BoW | **100.0%** | 0.0% |
| TF-IDF（手写） | **99.6%** | 1.8% |
| 8 维稠密投影（frozen） | **68.3%** | 12.8% |

> 👉 **反直觉 1**：把 TF-IDF 经过一个**固定**随机矩阵压成 8 维稠密向量（generic frozen embedding 的玩具替身），再喂给同一个 logistic 回归，准确率从 ~100% 掉到 **68.3%**。同样的分类器、同样的数据，只是「特征从稀疏可解释变成稠密固定」，性能就崩了。
>
> 这正是真实世界里 **冻结的 BERT embedding + 线性头常常打不过 TF-IDF + logistic** 的同一机制（见第 4 节引用的 MDPI 2024、SemEval 2024 真实数字）。**稠密语义表示 ≠ 更好的判别特征**；没有针对任务做梯度更新（fine-tune），语义信息反而稀释了任务信号。

**结果 3 & 反直觉 2 · L1 vs L2 的稀疏性**：

```
L2 正则：非零权重 = 99 / 99   （只整体缩小，几乎不产生精确的 0）
L1 正则：非零权重 = 27 / 99   （软阈值 → 大量精确 0）

L1 幸存的非零权重 = 自动学出的「关键词」：
    free     +5.993  →垃圾      the     -5.024  →正常
    click    +3.622  →垃圾      attached -3.435  →正常
    money    +3.398  →垃圾      team    -2.438  →正常
    claim    +3.062  →垃圾      for     -2.002  →正常
    prize    +2.734  →垃圾      please  -1.929  →正常
    cash     +2.553  →垃圾
```

> 👉 **反直觉 2**：L1 不只是「防过拟合」，它在做**特征选择**——把 99 个词里真正有用的十几个挑出来，而且每个权重都能直接读成「这个词对垃圾/正常的贡献」。L2 把 99 个权重全留着、只是都变小了，你得另外排序才能看出谁重要。**这就是线性模型至今在可解释性 / 合规 / 医疗场景不可替代的原因。**

## 四、局限与争议

### 4.1 线性 + 词袋的根本极限

BoW 把一篇文档压成一个**无序的多重集**——词序信息彻底丢失。这带来几个硬伤：

- **否定无法表达**：`not good` 和 `good` 的 unigram-BoW 几乎一样，但情感相反。要靠 bigram（`not_good`）才能勉强补救。
- **语序/句法无关**：`dog bites man` 与 `man bites dog` 在 BoW 里完全相同。
- **组合性 / 多义 / 反讽**：全是线性模型的结构性盲区。

所以**情感分析这种「语序敏感」任务，线性模型的天花板明显**；而主题分类这种「主要看出现了哪些词」的任务，线性模型几乎是上限。

### 4.2 为什么 BoW + logistic 至今难以被深度学习大幅超越

这是本章最重要的实证结论。**在主题分类这种「信号≈词频」的任务上，TF-IDF + logistic 已接近贝叶斯最优**，深度学习的提升往往只有几个百分点，代价却是几十到几百倍的算力。真实数字（2024 年发表）：

| 任务 / 数据 | TF-IDF + Logistic | 冻结 embedding + Logistic | 说明 |
|---|---|---|---|
| AI 生成作文检测（MDPI 2024） | **99.82%** | distilBERT 句向量 93.78–96.63% | **TF-IDF+LR 反超冻结 BERT 句向量** |
| 机器文本检测 SemEval 2024 | BoW+LR **60.22%** | BERT embedding+LR 63.48% | 冻结 embedding 只领先 3 个点 |
| IMDb 情感（多份研究） | LR+TF-IDF ≈ 88–93% | BERT 微调 ≈ 93–94% | 微调后才拉开 |

**两条铁律**：
1. **冻结的预训练向量 + 线性头，在小 / 专业数据上经常输给 TF-IDF + logistic。** 稠密通用语义把「任务相关的稀疏词频信号」稀释了。
2. **真正让 Transformer 赢的是 fine-tune（梯度流过整个表示），不是「用了 embedding」本身。** 一旦只取冻结向量接线性头，优势常常蒸发。

### 4.3 什么时候仍然首选 logistic + BoW/TF-IDF

- **资源极紧**：端侧 / 嵌入式 / 移动端，几 KB 模型、微秒级推理（垃圾邮件网关每天过滤几十亿封）。
- **可解释性 / 合规**：金融、医疗、法律——必须能说清「为什么判这一类」，L1 稀疏权重直接给出关键词清单。
- **超大规模稀疏数据**：词表 10 万维、样本上千万，线性模型是少数能在合理时间训完的选择，且性能接近上限。
- **强基线**：任何新方法（包括 LLM）上线前，先拿 TF-IDF + logistic 当 baseline——它经常出乎意料地难超越。

### 4.4 LLM 时代的位置

零样本 prompting 让「文本分类」几乎免费：给 LLM 一句话「这是正面还是负面？」就出标签。但 logistic + BoW 在上述四类场景仍是**生产正解**：便宜、快、可解释、可复现、不怕 prompt 漂移。**它是 baseline，也是很多场景的终解。**

## 五、与深度学习的桥梁（一句话点透）

> **Logistic 回归 = 一个没有隐藏层的神经网络。**

把本章的公式和神经网络逐项对照：

| 本章（logistic） | 神经网络里的对应 |
|---|---|
| 特征 $x$（手工 BoW/TF-IDF） | 第 5 章起改为**学出来的**稠密 embedding |
| $z = w\cdot x + b$ | 神经网络每一层都是这个形式（`nn.Linear`） |
| sigmoid / softmax | **任何分类网络的最后一层**就是它 |
| 交叉熵损失 | 神经网络分类任务的标准损失 |
| 梯度 $(\hat y - y)x$ | **输出层的梯度**，一字不差 |

所以神经网络相对 logistic 回归**只多了两样东西**：
1. **隐藏层 + 非线性激活**（让决策边界不再是超平面）；
2. **特征是学出来的**（不再手工 BoW）。

输出层的那套数学（softmax + 交叉熵 + $(\hat y-y)$ 梯度）**本章已经全部讲完**。这就是为什么 SLP3 把 logistic 回归放在神经网络之前——**它是神经网络的输出层，单独抽出来先讲透。**
