# 00 · 为什么需要激活函数

> 本章是「前置补课」。原对话开篇就说「没有激活函数，神经网络会坍缩成线性矩阵乘法」——这句话是后面一切的根。但对数学零基础的读者，我们要先讲清楚：**什么是线性、为什么线性不够用、激活函数到底改变了什么。**

---

## 一、直觉层：线性 vs 非线性

### 1.1 一个比喻

想象你要用积木搭一座桥：

- **线性积木**：每一块都是直的平板。无论你叠多少块直平板，拼出来的还是一条直线（顶多更长更斜），永远弯不出弧形。
- **非线性积木**：有一块是「弯的」。有了它，你才能搭出拱桥、波浪、任何形状。

神经网络里的「线性层」就是直平板，「激活函数」就是那块弯积木。**没有激活函数，再多层的网络也只能拟合直线/平面。**

### 1.2 为什么线性叠加还是线性？（关键代数事实）

一个**线性层**做的事是：

$$
y = Wx + b
$$

其中 $W$ 是权重矩阵，$b$ 是偏置。这就是「先做矩阵乘法，再加个常数」——本质是**仿射变换**（线性 + 平移）。

现在把两个线性层**直接**串联（中间不加任何激活函数）：

$$
h = W_1 x + b_1 \quad \text{(第一层)}
$$
$$
y = W_2 h + b_2 = W_2(W_1 x + b_1) + b_2 \quad \text{(第二层)}
$$

展开括号：

$$
y = \underbrace{(W_2 W_1)}_{W_{\text{eff}}} x + \underbrace{(W_2 b_1 + b_2)}_{b_{\text{eff}}}
$$

**结论**：两层串联合成一个新的线性层 $y = W_{\text{eff}} x + b_{\text{eff}}$。无论你串 10 层、100 层，反复展开括号后**永远还是一个线性层**。深度毫无意义。

> 🎯 **一句话**：线性函数的复合还是线性函数。要让「深度」有意义，必须在层与层之间塞进**非线性**——这就是激活函数存在的唯一理由。

### 1.3 实验验证

```bash
cd experiments && python3 00_why_activation.py
```

实验做两件事：
1. **代数验证**：构造三层线性网络，逐层算 vs 合成单矩阵算，结果完全一致（差 ~1e-7，纯浮点误差）。
2. **拟合验证**：用纯线性网络和带 ReLU 的网络去拟合 $y=\sin(x)$。

实测输出：

```
逐层前向结果:     [-6.2070155..., -2.9232258...]
合成单矩阵结果:    [-6.2070150..., -2.9232254...]
最大绝对差:        4.77e-07   ==> 多层线性恒等于单层线性!

纯线性网络  最终 MSE: 0.1994   (无法拟合 sin，loss 居高不下)
ReLU 网络   最终 MSE: 0.000005 (成功逼近 sin)
```

带 ReLU 的网络 MSE 比纯线性网络低 **4 万倍**——这就是非线性的力量。

## 二、数学层：激活函数在计算图中的位置

### 2.1 一个神经元到底在算什么

一个**完整**的神经元（含激活函数）分两步：

$$
z = Wx + b \quad \text{(线性聚合：把输入加权求和)}
$$
$$
a = f(z) \quad \text{(激活：套一个非线性函数)}
$$

- $z$ 叫**预激活值**（pre-activation），是线性的。
- $a$ 叫**激活值**（activation），是非线性的。
- $f$ 就是**激活函数**，本教程的主角。

> 注意：很多人把「$f(z)$」这一步叫做激活函数，也有人把整个「$z \to a$」连同权重叫激活。我们统一指 $f$ 本身。

### 2.2 多层网络的真正结构

一个 $L$ 层网络长这样：

$$
x \xrightarrow{W_1,b_1} z_1 \xrightarrow{f_1} a_1 \xrightarrow{W_2,b_2} z_2 \xrightarrow{f_2} a_2 \cdots \xrightarrow{f_L} a_L = \hat{y}
$$

每一层是「**线性 → 非线性**」的交替。如果任何一个 $f_i$ 是恒等函数 $f(z)=z$（即等于没有激活），那这两层就退化成纯线性串联，深度红利打折。

### 2.3 激活函数的三项硬指标

一个激活函数好不好，看三点（后面每章都会反复用到）：

1. **非线性强度**：能否让网络拟合复杂边界。（恒等函数 $f(z)=z$ 不合格。）
2. **导数行为**（决定能否训练）：反向传播要把损失对参数求导，导数要「不太小」且「好算」。详见第 01、02 章。
3. **数值范围 / 稀疏性**（决定数值稳定性与系统效率）：输出是否有界？是否会引发数值爆炸？详见第 03、04 章。

## 三、代码层：用 1 行代码看清差别

```python
import torch, torch.nn as nn

# 线性层：y = Wx + b （直平板）
linear = nn.Linear(4, 4)

# 加了 ReLU 的层：y = max(0, Wx+b) （弯积木）
activated = nn.Sequential(nn.Linear(4, 4), nn.ReLU())

x = torch.randn(4)
print(linear(x))    # 输出可正可负，本质是仿射变换
print(activated(x)) # 负数被"掰"成 0 —— 这一下就引入了非线性
```

ReLU 做的事看起来微不足道：`max(0, x)`，把负数砍成 0。但正是这个「砍」的动作，打破了线性性，让网络能拟合任意连续函数（**万能逼近定理** Universal Approximation Theorem）。

> **万能逼近定理（直觉版）**：只要有一层足够宽的非线性隐藏层，网络就能以任意精度逼近任何连续函数。ReLU 虽然简单，但它够「弯」（在 0 处有尖角），足以担当此任。

## 四、批判性视角：激活函数不是万能药

- **非线性≠一定能学好**。万能逼近定理只说「存在」这样的权重，没说梯度下降能找到。所以激活函数的「导数好不好传」（第 01、02 章）才是工程上的生死线。
- **激活函数的选择是妥协**：表达能力（GELU 强）vs 训练稳定性（ReLU 稳）vs 部署友好度（ReLU 量化最香）。没有银弹，只有场景。这也是为什么本教程要从原理一路讲到量化部署。

## 费曼回炉记录（L2 自检 · 已迭代）

- **F2 卡壳点**：
  - **卡点 A**：长期以来"背了"一句"激活函数给网络加非线性"，但说不清**为什么线性层串联会坍缩**。重读第 1.2 节那个代数推导才钉死：两个线性层 $W_2(W_1 x + b_1) + b_2$ 展开括号就是 $(W_2 W_1)x + (W_2 b_1 + b_2)$——**合成后仍是一个线性层** $W_{\text{eff}}x + b_{\text{eff}}$。所以"深度"在纯线性网络里**毫无意义**，10 层和 1 层等价。这个证明只用中学代数，但很多人没真的展开过括号。
  - **卡点 B**：以为"激活函数越复杂越好"，所以 ReLU 这么"傻"（就是把负数砍成 0）怎么会有用。重读第 3 节才抓住：ReLU 在 $x=0$ 处那个**尖角**就是它的非线性来源——只要有这个"弯"，万能逼近定理就保证它够用。复杂的激活（GELU/SwiGLU）是为了**训练更稳/梯度更好传**，不是"必须更弯"。

- **F3 术语翻译**：
  - "线性（Linear）" → **图像是直线**——$y = kx + b$ 长什么样？一条直板。
  - "非线性（Non-linear）" → **图像弯了**——只要有任何一处不是直线（如 ReLU 在 0 处那个折角），就叫非线性。
  - "万能逼近定理" → **只要有一层够宽的"弯积木"，就能拼出任何连续形状**——存在这样的权重，但梯度下降能不能找到是另一回事。

- **F4 回炉**：
  - **v1（错误直觉）**：以为"层数越多网络越强"，所以堆 100 层线性网络应该很强。
  - **v2（修正后）**：钉死"100 层纯线性 = 1 层线性，深度红利为零"。第 1.3 节那个实验数字打脸：纯线性网络 MSE 0.1994，加一个 ReLU 后 MSE 0.000005——**差 4 万倍**。diff 在于把"深度"从堆层数升级为**"线性-非线性"交替的层数**——只有塞了激活函数的层才算真深度。
