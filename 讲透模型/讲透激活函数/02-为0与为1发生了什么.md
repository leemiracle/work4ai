# 02 · 为 0 与为 1 时，到底发生了什么

> 对应原对话 **Q2：为 0 时会更新 x 的值吗？** / **Q3：那为 1 的时候呢？**
>
> 这两个追问把 ReLU 的两面性彻底暴露：**为 0** 是 ReLU 的「死穴」（Dead ReLU），**为 1** 是 ReLU 的「封神之钥」（解决梯度消失）。理解了这对矛盾，你就理解了为什么激活函数要不断演进。

---

## 第一部分：为 0 时——链式法则断裂与 Dead ReLU

### 一、直觉层

回顾第 01 章：ReLU 在 $x\le0$ 时局部导数为 0，反向传播时把上游梯度截断成 0。

现在问：**当某条路径上 ReLU 的梯度恒为 0，会产生什么后果？**

直觉：梯度是「告诉参数该往哪改、改多少」的信号。梯度为 0 = 没有信号 = 参数不知道该改 = **参数不更新**。

### 二、数学层：链式法则在哪里断裂

神经网络里，传进 ReLU 的 $x$ 通常**不是要更新的参数本身**，而是上一层（比如线性层）的输出：

$$
x = W \cdot a_{\text{prev}} + b
$$

真正要更新的是权重 $W$ 和偏置 $b$。按链式法则，损失对 $W$ 的梯度是：

$$
\frac{\partial L}{\partial W} = \frac{\partial L}{\partial x} \cdot \frac{\partial x}{\partial W}
$$

当 ReLU 处 $x\le0$，门关闭，$\frac{\partial L}{\partial x} = 0$。代入上式：

$$
\frac{\partial L}{\partial W} = 0 \cdot \frac{\partial x}{\partial W} = 0
$$

于是梯度下降 $W_{\text{new}} = W_{\text{old}} - \text{lr}\cdot\frac{\partial L}{\partial W}$ 中，$W$ 不变。**这条路径上的权重收不到任何来自当前数据的更新信号。**

### 三、Dead ReLU：神经元永久死亡

如果某个神经元的权重陷入了这样一种状态——**无论输入什么训练数据，算出的 $x$ 恒 $\le0$**——那么：

- 每次 ReLU 输出恒为 0。
- 每次反向传播，该神经元分到的梯度恒为 0。
- 它的权重**永远不会更新**。
- 这个神经元「死」了，变成一个毫无作用的废节点。

**常见诱因**：
- 学习率太大，某次更新把权重「踹」进了恒负区。
- 权重初始化不当（偏置初始就太负）。

这就是著名的 **Dead ReLU 问题**，也是 Leaky ReLU / GELU / PReLU 等变体被发明的直接动因（见第 03 章）。

### 四、实验复现 Dead ReLU

```bash
cd experiments && python3 02_dead_relu.py
```

第一部分故意给一个神经元设巨大负偏置 $b=-100$，使其恒死：

```
step 0: 线性输出=[[-97],[-94],[-91]]  ReLU输出=[[0],[0],[0]]  dW=[[0,0]]  db=[0]
step 1: 线性输出=[[-97],[-94],[-91]]  ReLU输出=[[0],[0],[0]]  dW=[[0,0]]  db=[0]
step 2: 线性输出=[[-97],[-94],[-91]]  ReLU输出=[[0],[0],[0]]  dW=[[0,0]]  db=[0]
==> 线性输出恒为负 -> ReLU 恒为 0 -> 梯度恒为 0 -> W/b 完全不更新 (神经元死亡)!
```

连续 3 步，权重和偏置的梯度**纹丝不动**。

### 五、严谨特例：优化器惯性（梯度为 0 ≠ 权重绝对不变）

「梯度为 0 则权重不更新」这句话**只在最朴素的纯 SGD、无正则时成立**。如果你的优化器有「惯性」或「衰减」，即使当前梯度为 0，权重仍可能变化：

#### 5.1 动量（Momentum）

带动量的优化器（SGD+Momentum、Adam）会累积历史梯度的指数滑动平均。即使当前步梯度为 0，「历史惯性」仍会推动权重滑动。

#### 5.2 权重衰减（Weight Decay / L2 正则）

权重衰减相当于给梯度额外加了一项「把权重拉向 0」的力：$\frac{\partial L}{\partial W} \mathrel{+}= \lambda W$。即使原始梯度为 0，只要 $W\ne0$，衰减项就会让权重持续缩小。

#### 5.3 实验验证

```
[纯SGD]      step 0: grad=[[0,0]]  权重=[[5.0, 7.0]]
[纯SGD]      step 1: grad=[[0,0]]  权重=[[5.0, 7.0]]   <- 纹丝不动

[SGD+Momentum] 建立动量后权重: [[3.69, 5.69]]
[SGD+Momentum] step 0: grad=[[0,0]]  权重=[[3.32, 5.32]]  <- 梯度0但权重仍在变!
[SGD+Momentum] step 1: grad=[[0,0]]  权重=[[2.99, 4.99]]

[AdamW+WD]    step 0: grad=[[0,0]]  权重=[[4.95, 6.93]]  <- 衰减让权重变小
[AdamW+WD]    step 1: grad=[[0,0]]  权重=[[4.90, 6.86]]
```

> ⚠️ 面试/系统分析时要严谨：**「ReLU 截断梯度为 0 → 当前数据对相关权重零贡献」**是数学事实；但「权重绝对不变」要加前提（纯 SGD、无衰减）。

## 第二部分：为 1 时——无损通行与梯度消失的终结

### 一、直觉层

当 $x>0$，ReLU 局部导数为 1。代入链式法则：

$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot 1 = \frac{\partial L}{\partial y}
$$

ReLU 在正轴扮演一根**完美导线**：上游传来多少误差信号，就一滴不漏地传给上一层，既不放大也不缩小。

### 二、数学层：为什么「导数=1」是革命性的

这是理解整个深度学习史的关键。反向传播在 $L$ 层网络里是**局部导数的连乘**：

$$
\text{到达浅层的梯度} \propto \prod_{i=1}^{L} f_i'(z_i)
$$

#### 2.1 sigmoid 的灾难

Sigmoid 的导数最大值只有 $0.25$（在 $x=0$ 处），稍微偏离 0 就更小。连乘 20 层：

$$
0.25^{20} \approx 9 \times 10^{-13}
$$

梯度衰减到几乎为零——这就是**梯度消失**（Vanishing Gradient）。浅层权重根本学不动，深层网络无法训练。这是 2006 年之前深度学习停滞的核心原因。

#### 2.2 ReLU 的救赎

ReLU 正轴导数恒为 1：

$$
1 \cdot 1 \cdot 1 \cdots 1 = 1
$$

连乘不衰减——**梯度可以无损穿越极深的网络**。这正是 2012 年 AlexNet 用 ReLU 引爆深度学习浪潮的根本原因。

### 三、实验：梯度消失对比

```bash
cd experiments && python3 03_gradient_vanishing.py
```

构造 20 层全连接网络，分别用 Sigmoid / ReLU，测量反向后每层权重的梯度范数：

```
[Sigmoid] 浅层/深层 梯度比 = 3.99e-17   <- 浅层梯度几乎归零
  Linear  0 (最浅): 5.7e-15  (完全学不动)
  Linear 19 (最深): 1.4e+02

[ReLU] 浅层/深层 梯度比 = 1.21e-07
  Linear  0 (最浅): 5.96e-07  (比 sigmoid 高 8 个数量级! 可训练)
  Linear 19 (最深): 4.93e+00
```

> 注：ReLU 浅层梯度仍会随深度衰减，但速率**远小于** sigmoid 的 $0.25$ 连乘——主要因为 ReLU 的稀疏性（部分神经元落在负区被截断）减少了有效梯度通路。即便如此，ReLU 浅层梯度比 sigmoid 高 **8 个数量级**，这是「能训练」与「不能训练」的鸿沟。

核心数字：

```
Sigmoid 最大导数 f'(0) = 0.25 -> 0.25^20 ≈ 9.09e-13 (梯度消失)
ReLU    正轴导数 f'(x) = 1.00 -> 1.00^20  =  1.00e+00 (梯度不消失)
```

### 四、权重正常更新的完整链路

既然传到 $\frac{\partial L}{\partial x}$ 的梯度被完整保留（$x>0$ 时），那么上一层的参数梯度：

$$
\frac{\partial L}{\partial W} = \frac{\partial L}{\partial x} \cdot \frac{\partial x}{\partial W} = \frac{\partial L}{\partial x} \cdot a_{\text{prev}}
$$

只要上一层输入 $a_{\text{prev}}$ 不全为 0，权重 $W$ 就能获得一个**真实、有效的梯度**，优化器据此减小误差——模型真正「学」到了东西。

---

## 批判性视角：为 1 也不是没有代价

ReLU 正轴导数恒为 1 解决了梯度消失，但也带来新问题：

- **没有梯度裁剪**：正轴梯度完全无衰减，深层网络里也可能出现梯度爆炸（虽然比消失少见，用 LayerNorm / 梯度裁剪可解）。
- **非零中心化**：输出恒 $\ge0$，导致后续层梯度更新方向被「捆绑」，呈轻微 zig-zag。这是后来 GELU/Swish 等平滑函数的改进点之一。

> 永恒的权衡：sigmoid 梯度太小（消失），ReLU 梯度太大（可能爆炸+稀疏过度），GELU/Swish 在中间找平衡。
