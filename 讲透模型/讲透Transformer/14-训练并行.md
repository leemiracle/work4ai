# 14 训练并行：大模型训练的系统基础

> 单卡装不下 70B 模型, 更别说训练。**并行**是让大模型训练成为可能的系统工程。
> 五种并行: **数据并行 (DP) / 张量并行 (TP) / 流水线并行 (PP) / 专家并行 (EP) / 序列并行 (SP)**。

---

## 为什么必须并行?

LLaMA-70B 训练: 70B 参数 × (FP16 2字节 + 梯度 + 优化器状态 ~12字节) ≈ **840 GB**。单卡 H100 只有 80GB。所以必须把模型**切**到多卡上, 还要让多卡**协同计算**。

---

## 五种并行 (三层讲透)

### 1. 数据并行 (Data Parallelism, DP) — 最简单
**思路**: 每张卡有**完整模型副本**, 处理**不同 batch**。
```
GPU0: 完整模型, batch0 ──┐
GPU1: 完整模型, batch1 ──┼──> 梯度 all-reduce 平均 ──> 同步更新
GPU2: 完整模型, batch2 ──┘
```
- **优点**: 简单, 加速 batch 维度
- **限制**: 每卡要装下完整模型 → 大模型不行
- **进阶**: ZeRO (DeepSpeed) 把优化器状态/梯度/参数也切分, 退化 DP 的显存压力

### 2. 张量并行 (Tensor Parallelism, TP) — 切权重矩阵
**思路**: 把单个大权重矩阵**按列/行切开**, 分到不同卡, 各算一部分再拼接。
```
Linear(d, 4d):  W = [W1 | W2 | W3 | W4]
GPU0 算 x@W1, GPU1 算 x@W2, ...  → all-gather 拼接结果
```
- **优点**: 单层就能切, 显存线性下降
- **缺点**: 每层都要通信 (all-reduce/all-gather), **通信开销大**, 通常只在节点内 (NVLink 高带宽) 用
- **典型**: TP=8 (一个 8 卡节点)

### 3. 流水线并行 (Pipeline Parallelism, PP) — 切层
**思路**: 把模型的**不同层**放到不同卡, 数据像流水线一样流过。
```
GPU0: layer 0-15  →  GPU1: layer 16-31  →  GPU2: layer 32-47  →  GPU3: layer 48-63
```
- **优点**: 显存按层切, 通信只在层边界 (小)
- **缺点**: **气泡** (bubble)——前向时后面的卡闲置, 反向时前面的卡闲置
- **解法**: micro-batching (把一个 batch 切成多份, 流水填满), GPipe / 1F1B 调度

### 4. 专家并行 (Expert Parallelism, EP) — MoE 专属
**思路**: 把**不同的专家**放到不同卡, token 被路由后跨卡送到对应专家。
```
GPU0: expert 0,1   GPU1: expert 2,3   ...
token → router 决定 → all-to-all 送到目标专家卡 → 算完 all-to-all 送回
```
- **关键**: 路由引入 **all-to-all 通信**, 是 MoE 训练的主要通信开销
- **配套**: 负载均衡 (06 篇), 防止 token 全挤到少数专家/少数卡

### 5. 序列并行 (Sequence Parallelism, SP) — 长上下文
**思路**: 把**序列维度**切开 (不同 token 段在不同卡), 用于超长上下文。
- Megatron-SP / DeepSpeed-Ulysses / Ring Attention
- 配合 TP, 把 attention/FFN 的序列维也切, 突破单卡序列长度限制

---

## 现代大模型: 三维/四维并行 (3D/4D Parallelism)

实际训练一个 LLaMA-70B / DeepSeek-V3, 同时用多种并行:
```
节点内:  TP=8  (NVLink 高带宽, 切权重)
节点间:  PP=跨节点 (切层, 通信小)
全局:    DP=数据并行 (不同 batch)
MoE:     EP=专家并行 (切专家)
```
例: DeepSeek-V3 用 **2048 张 H800**, TP=8 × PP=多 × DP=多 × EP=多。

**调度复杂度极高**: 不同并行的通信模式不同 (all-reduce / all-gather / all-to-all), 要重叠计算和通信才能不浪费 GPU。这是大模型训练"系统工程"的核心 (07 篇提到的"算力战争")。

---

## 速查

| 并行 | 切什么 | 通信 | 主要场景 |
|------|--------|------|---------|
| DP | batch | all-reduce (梯度) | 通用加速 |
| ZeRO | 优化器/梯度/参数 | all-gather | 显存省 |
| TP | 权重矩阵 | all-reduce (每层) | 节点内 (NVLink) |
| PP | 层 | 点对点 (层边界) | 跨节点 |
| EP | 专家 | all-to-all | MoE |
| SP | 序列 | all-to-all/all-gather | 长上下文 |
