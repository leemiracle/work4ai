# 04 — 位置编码：attention 没有位置感，怎么注入顺序？

> 承接 01：attention 公式 $\text{softmax}(QK^\top/\sqrt d)V$ 只看**内容相似度**，完全不知道词的顺序。把"猫 追 狗"和"狗 追 猫"喂进去，attention 的输出只会在相应位置间互换——**它分不清主谓宾**。本篇讲透：位置信息怎么注入，以及为什么 RoPE 成了现代 LLM 的标配。
>
> 配套实验：`experiments/04_positional.py`。

---

## 1. 问题：attention 是「置换等变」的

纯 attention 有一个数学性质叫**置换等变（equivariance）**：把输入序列按排列 $\pi$ 打乱，输出也按同样的 $\pi$ 打乱。

$$\text{Attn}(\pi \cdot X) = \pi \cdot \text{Attn}(X)$$

### 实验铁证（`04_positional.py` Part 1）

```
把输入按 [2,0,3,1] 打乱后重算 attention,
与原输出按同序打乱之差: 2.98e-08   (≈0, 纯浮点误差)
```

**含义**：attention 对"谁在第几位"完全无感——打乱输入等价于打乱输出。这对"词袋"任务（如情感分类）没问题，但对**顺序敏感**任务（语法、时序、代码）是致命的。"我 打 你"和"你 打 我"对纯 attention 是一回事。

所以必须**额外注入位置信息**。

---

## 2. 第一代：正弦绝对位置编码（Vaswani 2017）

Transformer 原论文的做法：给每个位置 $m$ 预先生成一个固定的位置向量 $p_m$，加到 token 嵌入上：

$$\tilde{x}_m = x_m + p_m, \quad p_m = (\sin(m\theta_1), \cos(m\theta_1), \sin(m\theta_2), \cos(m\theta_2), \dots)$$

其中 $\theta_i = 10000^{-2i/d}$ 是一组从大到小的频率。

**为什么用正弦？**
- 不同维度用不同频率，像时钟的时针/分针/秒针，能组合表达任意位置。
- $\sin/\cos$ 有平移关系：$\sin((m+k)\theta)$ 能用 $\sin(m\theta),\cos(m\theta)$ 线性表示，暗示模型可能学到"相对位置"。
- 无需学习，且理论上可外推到训练时没见过的更长序列（虽然实际外推效果一般）。

### 实验验证（Part 2）

"复制第 2 个位置"任务，无 vs 有正弦位置编码：

```
无位置编码:    测试准确率 46.0%   (随机基线 17%)
正弦位置编码:  测试准确率 82.5%
```

（无位置编码没完全卡在 17%，是因为 mean-pool + 内容注意力给了部分信息；但仍远低于有位置编码——它无法稳定定位"第 2 个"。）

---

## 3. 第二代：可学习绝对位置编码（GPT-2/BERT）

把正弦的"固定"改成"可学习"：直接给每个位置初始化一个可训练向量 $p_m \in \mathbb{R}^d$，随模型一起训。

- **优点**：灵活，表达力强。GPT-2、BERT 都用这个。
- **缺点**：位置数固定（如训 2048 就只能用 2048），**无法外推**到更长序列——超出训练长度的位置没有学到。

---

## 4. 第三代：RoPE 旋转位置编码（现代 LLM 标配）

Su et al. 2021（RoFormer）提出的 **Rotary Position Embedding**，是 LLaMA、Qwen、DeepSeek、ChatGLM 等几乎所有现代开源 LLM 的标配。核心思想：**用旋转把绝对位置编码进 Q/K，使它们的点积自然只依赖相对位置**。

### 数学

对位置 $m$ 的向量，施加一个旋转矩阵 $R_m$（把相邻两维成对旋转角度 $m\theta_i$）：

$$q_m \to R_m q_m, \qquad k_n \to R_n k_n$$

于是注意力分数：

$$\langle R_m q,\; R_n k \rangle = q^\top R_m^\top R_n k = q^\top R_{n-m} k$$

**只依赖相对距离 $(n-m)$！** 而且是用"绝对位置旋转"实现的——每个位置独立旋转，无需查询时算相对位置。

### 实验铁证（Part 3）

旋转后 $q\cdot k$ 在不同绝对位置但相同相对距离下完全一致：

```
位置 (0,0) (1,1) (2,2) (3,3)  相对距离 0:  q·k = +1.801  (全部相同!)
位置 (1,0) (2,1) (3,2)        相对距离 1:  q·k = -1.063  (全部相同!)
位置 (5,3)                     相对距离 2:  q·k = -2.492
```

### 为什么 RoPE 赢了

1. **相对位置**：$q_m\cdot k_n$ 只看 $(m-n)$，符合"语言里相对位置比绝对位置重要"（"我很开心 昨天" vs "昨天 我很开心"，关键关系是词与词的距离）。
2. **长度外推**：因为是相对的 + 旋转的平滑性，配合 NTK-aware 插值等技术，RoPE 能外推到训练长度之外（如训 4k 外推到 32k、128k）。这是现代长上下文 LLM 的基础。
3. **高效**：旋转是逐位置的，不破坏 attention 的并行性。

---

## 5. 另一条路：ALiBi（Attention with Linear Biases）

Press et al. 2021 的 ALiBi 走了完全不同的路：**不改嵌入，直接在 attention 分数上加一个与距离成正比的惩罚**：

$$\text{score}_{m,n} = q_m \cdot k_n - s \cdot |m - n|$$

其中 $s$ 是每层不同的斜率（按几何序列预设）。

- **优点**：极简，无额外参数，**外推性极强**（训 1024 直接外推到 8192 仍表现良好）。
- **缺点**：强加了"距离越远注意力越弱"的归纳偏置，对某些任务不一定最优。
- **代表**：MPT、Falcon、部分长上下文模型。

### RoPE vs ALiBi

| | RoPE | ALiBi |
|---|---|---|
| 作用位置 | 嵌入（旋转 Q/K） | attention 分数（加偏置） |
| 相对/绝对 | 相对 | 相对 |
| 额外参数 | 无 | 无 |
| 外推性 | 好（需插值技巧） | 极好（开箱即用） |
| 主流采用 | **LLaMA/Qwen/DeepSeek 系** | MPT/Falcon |

---

## 6. 一句话总结

> **纯 attention 是置换等变的，分不清词序，所以必须注入位置信息。三代方案：①正弦绝对位置（固定、可外推但弱）；②可学习绝对位置（强但不外推）；③RoPE 旋转位置（把绝对位置旋转编码进 Q/K，使点积自然只依赖相对距离，兼顾表达力与长度外推，成为现代 LLM 标配）。ALiBi 则用"距离惩罚偏置"提供另一条简洁的外推路线。**
