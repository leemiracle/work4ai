# 01 — Transformer 与注意力：为什么 softmax(QK^T/√d)V 能替代 RNN

> 承接 `00-为什么预测下一个词能产生智能`：那篇的玩具模型是 **bigram（只看前 1 个词）**。但真实语言里，预测下一个词常常要**看很远的上文**（"她养了三年的___跑了" → 缺"猫/狗"，而线索"养"在好几个词之前）。本篇讲透：Transformer 用什么机制让模型"一眼看全部上下文"，以及那个看着吓人的公式为什么是这个样子。
>
> 配套实验：`experiments/01_attention.py`。

---

## 1. 问题的来源：bigram 的天花板

00 篇的 `TinyLM` 用"前一个词"预测"下一个词"，这在数学上等价于学一张**转移概率表**。它能学会 `a→b(70%)` 这种**局部**规律，但遇到需要**远距离线索**的任务就彻底无能为力。

实验 `01_attention.py` Part 1 把这个天花板量化了：

```
任务: 序列 [线索, 干扰, 干扰, 干扰, 干扰, 目标] —— 目标由第0位的线索决定
bigram 训练后测试准确率 = 51%   (纯瞎猜, 随机基线50%)
```

bigram 只看到最后一个干扰词，**根本看不到第 0 位的线索**，所以学不会。要突破，必须有一个机制让"目标位"能**直接看到第 0 位**。

RNN 的做法是：把信息从第 0 位**逐步传递**到末位（5 步）。问题是：传递路径长 → 梯度消失 + 信息衰减。Attention 给出了完全不同的答案：**一步到位，所有位互相看见**。

---

## 2. 直觉：attention = 「内容相关的加权平均」

### 图书馆比喻

想象你在写论文，要为当前这句话（**query 查询**）找参考资料。书架上每本书有一个标题/标签（**key 键**）和正文内容（**value 值**）。你拿 query 去和每本书的 key 比对，**越相关的书权重越大**，最后把所有书的内容按权重混合，得到你要的参考。

**attention 就是这个过程**：每个词都当一次"查询者"，去和所有词（包括自己）的 key 打分，按分数加权聚合 value。

### 三个矩阵的角色

把每个词的嵌入 $x_i$ 用三个不同权重矩阵投影成三种角色：

| 角色 | 含义 | 类比 |
|---|---|---|
| $Q = x W_Q$（**Query 查询**） | "我在找什么样的信息" | 你手里的问题 |
| $K = x W_K$（**Key 键**） | "我能提供什么样的信息" | 书的标题/标签 |
| $V = x W_V$（**Value 值**） | "我实际携带的信息" | 书的正文 |

**为什么不是同一个矩阵？** 因为"我想找什么"（Q）、"我能被找到的标签"（K）、"我真正的内容"（V）是三件不同的事。分开投影让模型能分别学习这三种角色。

---

## 3. 数学：点积 = 相似度，softmax = 归一化

### 完整公式

对序列 $X \in \mathbb{R}^{n \times d}$（$n$ 个词，每个 $d$ 维）：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

其中 $Q=XW_Q,\; K=XW_K,\; V=XW_V$，$d_k$ 是 key 的维度。

### 逐项拆解

**① $QK^\top$：相似度矩阵**

$QK^\top \in \mathbb{R}^{n \times n}$，第 $(i,j)$ 元素是 $q_i \cdot k_j$ —— **词 $i$ 的查询 与 词 $j$ 的键 的点积**。

点积的几何意义：两个向量越"同向"（夹角越小），点积越大。所以 $q_i \cdot k_j$ 大 ⟺ 词 $i$ 在找的信息正是词 $j$ 能提供的。**点积就是"相关度"的可微度量**。

实验 Part 2 可见：这是一个 $4\times4$ 的矩阵，每行代表"某词对所有词的关注度"。

**② 除以 $\sqrt{d_k}$：防饱和（见第 4 节，关键）**

**③ softmax(dim=-1)：归一化成权重**

对每行做 softmax，使 $\sum_j \text{attn}_{ij} = 1$。这样注意力权重就是一组概率——"词 $i$ 把多少注意力分给每个词"。

**④ $\times V$：加权聚合**

$\text{attn} \cdot V$：每个词的新表示 = 全部词的 value 按注意力权重加权求和。**于是每个词都"吸收"了整个序列的相关信息**。

实验 Part 2 的权重矩阵展示了这一点：词 3 主要关注自己（0.59）和词 1（0.24）——内容相关的分配，不是平均。

---

## 4. 为什么必须除以 $\sqrt{d_k}$？（最容易被忽略的关键）

这是 Transformer 原论文（Vaswani 2017）的一个 footnote，但极其重要。实验 `01_attention.py` Part 4 把它量化了：

```
d=8:   点积std=0.86 | 不除sqrt(d): max权重=0.378 | 除sqrt(d): max权重=0.174
d=64:  点积std=1.53 | 不除sqrt(d): max权重=0.320 | 除sqrt(d): max权重=0.126
d=512: 点积std=4.96 | 不除sqrt(d): max权重=0.995(饱和!) | 除sqrt(d): max权重=0.144
```

### 数学原因

设 $q_i, k_j$ 各分量独立、均值 0、方差 1，则点积 $q_i \cdot k_j = \sum_{m=1}^{d_k} q_{im}k_{jm}$ 的**方差 = $d_k$**（$d_k$ 个独立项之和）。

所以**维度越大，点积数值越大**。当 $d_k=512$ 时，点积标准差 ~22，softmax 会**极度饱和**——最大那项接近 1，其余接近 0。

### 饱和为什么致命

softmax 在饱和区（输入差距很大时）的**梯度趋于 0**。这意味着：模型一旦"过早自信"地只关注一个词，就再也学不动了（梯度消失）。

除以 $\sqrt{d_k}$ 把点积方差从 $d_k$ 拉回 1，softmax 输出温和（max 权重 ~0.14），梯度健康。**这个除法不是调参，是数值稳定性的必需品**。

---

## 5. 为什么 attention 淘汰了 RNN？

实验 Part 5 给出直接对比：同一个远距离依赖任务——

```
bigram:    准确率 51%   (看不到远处线索)
attention: loss → 0     (一步看到第0位线索, 完美学会)
```

attention 胜出的两个根本原因：

### (1) 任意远依赖，一步直达

RNN 要把第 0 位的信息**逐 token 传递**到第 5 位，路径长度 = 距离。距离越远，梯度越消失、信息越衰减。

Attention 里，**任意两个位置的"距离"都是 1**（直接点积）。第 5 位直接"看"第 0 位，不分远近。实验还打印了目标位的注意力权重——它**集中在第 0 位线索上**，证明模型学会了"看远处"。

### (2) 完全并行

RNN 第 $t$ 步必须等第 $t-1$ 步算完（**串行**），无法利用 GPU 并行。

Attention 的 $QK^\top$ 是**一次矩阵乘法**，所有位置同时算（**并行**）。训练时这带来数量级的加速——这是 Transformer 能训到千亿参数的工程前提。

| | RNN | Attention |
|---|---|---|
| 长程依赖 | 逐步传递，易衰减 | 一步直达 |
| 并行性 | 串行，慢 | 全并行，快 |
| 复杂度 | $O(n)$ 每步 | $O(n^2)$（见局限） |

---

## 6. 多头注意力：不同的"关注模式"

一个 attention 头只学一种"关注模式"（比如语法依赖）。语言里同时有多种关系（主谓、修饰、指代……），所以把它做成**多头**：

$$\text{MultiHead} = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W_O, \quad \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

把 $d$ 维拆成 $h$ 个 $d/h$ 维子空间，每个头在子空间里独立做 attention，最后拼接。**不同头学不同关系**（有的看语法、有的看语义、有的看局部、有的看全局），是模型的"多视角"。

（实验里用的是单头简化版；真实 GPT 用 32–96 头。）

---

## 7. 局限与代价（attention 不是免费的）

### (1) $O(n^2)$ 复杂度

$QK^\top$ 是 $n \times n$ 矩阵，序列长 $n$ 时计算和显存都是 **平方增长**。这是为什么长上下文（10万 token）极贵，也是 FlashAttention、稀疏注意力、线性注意力等后续工作的核心战场。

### (2) attention 本身没有位置感

$QK^\top$ 只看内容相似度，**完全不知道词的顺序**——把句子打乱，attention 输出可能不变（置换等变）。所以必须**额外注入位置信息**：位置编码（RoPE、ALiBi 等）。这是下一篇（或后续）的主题。

### (3) 一个 Transformer block 不止 attention

完整的 Transformer = 多头注意力 + 残差连接 + LayerNorm + 前馈网络（FFN）。attention 负责"聚合上下文信息"，FFN 负责"对聚合后的信息做非线性变换"（记忆知识就在 FFN 里）。两者缺一不可。本篇聚焦 attention，FFN 留待后续。

---

## 8. 一句话总结

> **Attention 让序列中每个词用 Query 去"查询"所有词的 Key，用点积衡量相关度，softmax 归一化成权重后对 Value 加权求和——从而每个词都一步获得全局上下文。点积天然衡量相似度；除以 √d 防止高维下 softmax 饱和导致的梯度消失；全并行 + 任意远依赖这两点让它淘汰了 RNN，成为所有现代基础模型的骨架。代价是 O(n²) 复杂度，且它本身没有位置感，需配合位置编码使用。**

## ✍️ 练习（`01_attention.py`）

1. **位置无关性**：把 Part 2 的输入 `x` 打乱行顺序，重算 attention 输出，观察 attention 权重矩阵如何随之置换。这会帮你理解"attention 是置换等变的"——为什么需要位置编码。
2. **去掉 √d**：把 Part 5 的 AttnModel 里 `/math.sqrt(dk)` 去掉，把维度 `d` 调到 128，观察训练是否变难（loss 下降变慢甚至停滞）。亲手验证第 4 节。
3. **多头**：把 AttnModel 改成 2 头（把 d=16 拆成两个 d=8 子空间，各做 attention 再拼接），看能否学得更快或更稳。
