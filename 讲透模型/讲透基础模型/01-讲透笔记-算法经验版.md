## §0 全局视角：Transformer 是现代 ML 的"统一架构"

| 领域 | Transformer 怎么用 | attention 的对齐对象 |
|------|------------------|--------------------|
| **NLP（GPT/BERT）** | decoder/encoder-only | token ↔ token |
| **CV（ViT）** | 把图切成 patch，当 token | patch ↔ patch |
| **语音（Whisper）** | 把音频切成 frame，当 token | frame ↔ frame |
| **多模态（CLIP/Flamingo）** | 图文 cross-attention | 图 patch ↔ 文 token |
| **蛋白质（AlphaFold）** | 氨基酸残基当 token | 残基 ↔ 残基（结构对齐）|
| **代码（Codex）** | token 当 token | token ↔ token（语法/语义）|
| **数学（AlphaGeometry）** | 几何元素当 token | 元素 ↔ 元素 |
| **推荐（BST/BST-Transformer）** | 用户行为序列当 token | 行为 ↔ 行为 |

> 🔑 **核心洞察**：**Transformer 不是"为 NLP 设计"的架构，是"为对齐设计"的架构**。只要你能把任务抽象成"一组东西要互相找关系"，Transformer 就能用。

### 算法经验 A1：Transformer = 模式匹配的元架构

> Transformer 之所以通用，是因为它的核心**self-attention 是"任意两个 token 的对齐"**——这个抽象足够通用，可以套到任何"一组实体要互相找关系"的场景。

可迁移：**当面对一个新领域，先问"它的实体是什么？实体间要对齐什么？"——回答了这两个问题，Transformer 就能套用**。

## §1 Attention 的算法 DNA：三层抽象

### 1.1 第一层：内容相关的加权平均（直觉）

$$\text{out}_i = \sum_j \alpha_{ij} v_j, \quad \alpha_{ij} = \text{softmax}_j(\text{score}(q_i, k_j))$$

**直觉**：每个位置 $i$ 根据 query $q_i$ 和所有位置的 key $k_j$ 算相似度，对 value $v_j$ 加权求和。

### 1.2 第二层：核回归（数学）

attention 在数学上是**核回归 (kernel regression)** 的一种：

$$\text{out}_i = \frac{\sum_j \kappa(q_i, k_j) v_j}{\sum_j \kappa(q_i, k_j)}$$

其中 $\kappa(q, k) = \exp(q \cdot k / \sqrt{d})$ 是一个**指数核**。

> 这意味着 attention 可以替换成**任何核函数**：
> - **Gaussian 核** → 平滑的注意力
> - **Laplacian 核** → 更稀疏
> - **线性核** → Performer 的线性 attention
> - **学习型核** → viral attention / learnable kernel

### 1.3 第三层：信息检索（IR）

| Attention 概念 | IR 概念 |
|---------------|---------|
| Query $q$ | 用户查询 |
| Key $k$ | 文档索引/标题 |
| Value $v$ | 文档正文 |
| $\text{softmax}(qk^\top)$ | 相关度排序 |
| Top-k attention | 稀疏检索 |
| Cross-attention（decoder→encoder）| RAG 检索（query→doc）|

> 🔑 **深层洞察**：**attention 就是可微的信息检索**。

### 算法经验 A2：attention = 核回归 = 可微 IR

> 三个层次的抽象：
> 1. **直觉层**：内容相关的加权平均
> 2. **数学层**：核回归（指数核的特例）
> 3. **工程层**：可微的信息检索

可迁移：
- 看到"加权平均"的任务 → 可以用 attention
- 看到"检索"的任务 → 可以用 cross-attention
- 看到"核方法"的任务 → 可以用 attention 替换核

## §2 与 Ch12 MT 横向打通：attention = 可微对齐

这是 Transformer 最深刻的概念联系。

### 2.1 对齐的演化（Ch12 §4）

| 阶段 | 对齐表示 | 是否可微 |
|------|---------|---------|
| IBM Model 1（1993）| $\gamma_j(i) \in \{0,1\}$ 硬对齐 | ❌ |
| Bahdanau attention（2014）| $\alpha_{t,i} \in [0,1]$ 软对齐 | ✅ |
| Transformer self-attention（2017）| 自对齐（每对 token）| ✅ |

### 2.2 数学同构

IBM Model 1 的 E-step：
$$\gamma_j(i) = \frac{t(f_j|e_i)}{\sum_{i'} t(f_j|e_{i'})}$$

Bahdanau attention：
$$\alpha_{t,i} = \frac{\exp(a(s_t, h_i))}{\sum_k \exp(a(s_t, h_k))}$$

**结构完全同构**——都是"对一组候选算分数，归一化成权重"。

### 2.3 算法经验 A3：attention = 可微对齐（对应 Ch12 经验 T4 + T5）

> attention 不是新东西，是**离散对齐（IBM Model 1）的连续松弛版**。
> - 离散版用 EM（坐标上升）
> - 连续版用梯度下降（端到端反向传播）
>
> 连续化的红利：**梯度可以从 decoder 流回 encoder，端到端训练**。

可迁移（Ch12 经验 T4 的具体应用）：
- **离散检索 → 神经检索**（BM25 → DPR）
- **硬聚类 → 软聚类**（k-means → GMM）
- **离散路由 → 软路由**（MoE 的 soft routing）

## §3 与 Ch10 BERT 横向打通：自注意力 vs 交叉注意力

### 3.1 三种 attention 的对照

| 类型 | 公式 | Q 来自 | K/V 来自 | 应用 |
|------|------|--------|---------|------|
| **Self-attention** | $\text{softmax}(XX^\top)X$ | 序列自身 | 序列自身 | BERT、GPT 的"看上下文" |
| **Masked self-attention** | 上三角置 -∞ | 序列自身 | 序列自身（仅左侧）| GPT 的"只看左边" |
| **Cross-attention** | $\text{softmax}(XY^\top)Y$ | decoder 状态 | encoder 输出 | seq2seq、Flamingo、CLIP |

### 3.2 BERT vs GPT 的根本差异（Ch10 §2）

```
GPT (causal mask):          BERT (无 mask):
q1·k1  -∞    -∞    -∞        q1·k1 q1·k2 q1·k3 q1·k4
q2·k1 q2·k2  -∞    -∞        q2·k1 q2·k2 q2·k3 q2·k4
q3·k1 q3·k2 q3·k3  -∞        q3·k1 q3·k2 q3·k3 q3·k4
q4·k1 q4·k2 q4·k3 q4·k4      q4·k1 q4·k2 q4·k3 q4·k4
（上三角 -∞，softmax→0）       （全满，所有 token 互看）
```

> 🔑 **就这一个 mask 差别**——决定了 BERT 是理解模型、GPT 是生成模型（Ch10 经验 M4）。

### 3.3 算法经验 A4：mask 是 attention 的"任务定义器"

> 同一个 attention 架构，加什么 mask 就变成什么任务：
> - **无 mask**：双向理解（BERT）
> - **上三角 mask**：自回归生成（GPT）
> - **prefix mask**：prefix-LM（用于 encoder-decoder 风格的生成）
> - **band mask**：长文档（Longformer）
> - **block mask**：高效长上下文（BigBird）

可迁移：**看到 Transformer 架构，先看它的 mask 设计——这决定了它能做什么**。

## §4 与 Ch11 RAG 横向打通：双塔 vs 交叉编码器

### 4.1 Cross-attention 就是 cross-encoder

Ch11 的 cross-encoder rerank 本质上就是 cross-attention：

```
bi-encoder (双塔, 召回):     q 塔独立 + d 塔独立 → cos(v_q, v_d)
cross-encoder (rerank):      [CLS] q [SEP] d → BERT → score
                              ↑ 这就是 cross-attention
```

### 4.2 Self-attention 也能做检索？

**ColBERT（2020）的洞察**：用 self-attention 计算 query 和 doc 的 token-level 对齐，然后 max-pool。这比 mean-pool 的双塔精度高，比 cross-encoder 快。

### 4.3 算法经验 A5：attention 是检索系统的核心计算单元

| 检索架构 | 用的什么 attention | 速度 | 精度 |
|---------|------------------|------|------|
| 双塔（DPR, BGE）| 不用（只算余弦）| 快 | 中 |
| Cross-encoder（rerank）| 全交叉 attention | 慢 | 高 |
| **ColBERT（late interaction）** | **token-level 交叉** | **中** | **高** |

可迁移（对应 Ch11 经验 R4 + R5）：**两阶段检索 = 召回（双塔）+ 精排（cross-attention）。attention 是精排阶段的核心计算**。

## §5 与 Ch9 后训练横向打通：softmax + KL 的算法同构

### 5.1 Attention 的 softmax 与 DPO 的 softmax

Attention：
$$\alpha_{ij} = \text{softmax}_j(q_i \cdot k_j / \sqrt{d})$$

DPO（Ch9 §3）：
$$P(y_w \succ y_l) = \sigma(\beta \cdot \Delta\text{log-ratio})$$

**共同点**：都是"算分数 → 归一化/squash → 权重/概率"。

### 5.2 Attention 的 √d 与 DPO 的 β

| | attention | DPO |
|---|----------|-----|
| 控制量 | √d 缩放 | β 温度 |
| 作用 | 防止 softmax 饱和 | 控制 KL 约束强度 |
| 太大 | softmax 太软（信息丢失）| 太保守（学不动）|
| 太小 | softmax 饱和（梯度消失）| 太激进（KL 爆炸）|

### 5.3 算法经验 A6：温度参数是 ML 的"旋钮"

> 几乎所有"算分数 → 归一化"的算法都有一个温度参数：
> - **attention**：√d
> - **DPO**：β
> - **softmax 分类**：T (temperature scaling)
> - **knowledge distillation**：T
> - **PPO**：β（KL 约束强度）
> - **Gibbs sampling**：T

可迁移：**任何带 softmax 的算法都要调温度——三段式行为（过冷/刚好/过热）是普遍规律（对应 Ch9 经验 #8）**。

## §6 Attention 的家族：从软到稀疏到线性

原 01 笔记只讲了"标准 attention"。实际工程有大量变体：

### 6.1 标准 attention 的问题

- $O(n^2)$ 复杂度——长上下文（10万 token）显存爆炸
- 全软（dense）注意力——可能关注无关 token

### 6.2 变体谱系

| 类型 | 代表 | 核心改动 | 解决什么 |
|------|------|---------|---------|
| **标准 dense** | 原版 Transformer | 无 | 基线 |
| **稀疏 (sparse)** | BigBird, Longformer | 只 attend 局部 + 全局 token | 长上下文 |
| **线性 (linear)** | Performer, Linear Attention | $\phi(Q)\phi(K)^\top \phi(V)$，可结合律降阶 | 线性复杂度 |
| **Flash** | **FlashAttention** | 算法等价，IO 优化 | 显存 + 速度（不改数学）|
| ** grouped** | Grouped-query, Multi-query | Q 共享 K/V | 推理显存 |
| **Sliding window** | Mistral, Gemma | 滑动窗口 + 少量全局 | 长上下文 |
| **Mamba (state space)** | Mamba, RWKV | 用 RNN-style 状态替代 attention | $O(n)$ + 长程 |

### 6.3 算法经验 A7：标准 attention 不是终点，是起点

> 标准 attention 是 $O(n^2)$，**工程优化方向**有三个：
> 1. **数学等价 + IO 优化**（FlashAttention）—— 2-4× 提速
> 2. **稀疏化**（Longformer/BigBird）—— 复杂度降到 $O(n \log n)$
> 3. **替换为线性/状态空间**（Performer/Mamba）—— 复杂度降到 $O(n)$，但精度可能下降

可迁移：**当一个核心算法成为瓶颈，优化方向永远是"等价优化 / 稀疏化 / 替换"三选一**。

## §7 √d 缩放的算法意义：温度的通用套路

原 01 笔记讲了 √d 的"防饱和"机制。补充它的算法本质：

### 7.1 √d 是温度的实例

$$\text{softmax}(z/T), \quad T = \sqrt{d}$$

### 7.2 温度的通用作用

| T 值 | softmax 行为 | 类比 |
|------|-------------|------|
| $T \to 0$ | argmax（hard）| 贪心 |
| $T$ 小 | 较陡（peaky）| 自信 |
| $T$ 适中 | 平滑 | 平衡 |
| $T$ 大 | 接近均匀 | 不确定 |

### 7.3 算法经验 A8：温度参数是 ML 的"通用旋钮"（强化 A6）

> 温度不是 attention 特有，几乎所有带 softmax 的地方都有：
> - **采样温度**（GPT 生成）：T=0 贪心，T=1 默认，T>1 多样
> - **知识蒸馏**：T=4 让 teacher 的软标签更"软"
> - **PPO**：KL 惩罚的 β 是 reciprocal temperature
> - **Gumbel-softmax**：T 控制离散化强度
> - **calibration**：温度缩放校准分类置信度

可迁移：**看到 softmax，就想到温度——它通常是个"自由的旋钮"**。

## §8 多头的算法本质：子空间分解

原 01 笔记讲了多头是"多视角"。补充它的算法本质：

### 8.1 多头 = 子空间分解

把 $d$ 维向量拆成 $h$ 个 $d/h$ 维子空间，每个子空间独立做 attention：

$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V), \quad \text{MultiHead} = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W_O$$

### 8.2 类比卷积的多通道

多头 attention 类似 CNN 的多通道——每个头学不同的"特征图"：
- 某些头学语法依赖（主谓、修饰）
- 某些头学语义关系（同义、反义）
- 某些头学局部模式（n-gram）
- 某些头学全局模式（段落主题）

### 8.3 算法经验 A9：多视角 = 子空间分解

> 多头的本质是**子空间分解 + 多视角集成**。这个模式反复出现：
> - **CNN 多通道**：每通道学不同特征
> - **MoE 多专家**：每专家学不同子任务
> - **集成学习**：多模型投票
> - **多任务多 head**：每个任务一个 head
> - **多语言多 head**：每语言一个 head（XLM-R）

可迁移：**当任务有多种"模式"要学，就用子空间分解（多头/多通道/多专家）**。

## §9 批判性：attention 的代价与边界

### 9.1 attention 不是免费的

| 代价 | 表现 | 缓解 |
|------|------|------|
| $O(n^2)$ 复杂度 | 长上下文显存爆炸 | FlashAttention / 稀疏 / 线性 |
| 没有位置感 | 置换等变 | 位置编码（RoPE, ALiBi）|
| 训练不稳定 | 容易饱和 | √d + LayerNorm + warmup |
| 推理慢 | 自回归生成串行 | KV cache + 投机解码 |

### 9.2 attention 不是万能的

| 任务 | attention 弱 | 替代方案 |
|------|-------------|---------|
| **极长上下文（>1M token）** | $O(n^2)$ 显存爆 | Mamba / RWKV / 状态空间 |
| **精确数值计算** | attention 是模糊的 | 符号执行器 / 工具调用 |
| **结构化输出** | 自由生成不保证结构 | grammar constraint / function calling |
| **时序强依赖** | attention 看不到严格顺序 | RNN / 状态空间 |

### 9.3 算法经验 A10：attention 是"现代 ML 的中央计算单元"，但有边界

> **attention 不是终极架构**——它是"目前最通用的对齐计算"。当它的 $O(n^2)$ 或模糊性成为瓶颈，新的架构（Mamba / RWKV / 神经符号）就会出现。

可迁移：**任何"统治性架构"都有边界——CNN 被 Transformer 替代，Transformer 未来可能被状态空间模型部分替代**。

### 横向打通的关键洞察

通过这次"基础模型 Transformer 深度版"，最重要的发现是：

> **51 条算法经验不是孤立的，它们围绕几个核心抽象形成网络**：
>
> 1. **softmax + 温度**（A6, A8, #8）：从 attention 到 DPO 到蒸馏，都是同一套
> 2. **对齐**（A3, T5, R4）：从 MT 到 RAG 到 CLIP，都是 attention 的应用
> 3. **离散→连续**（A3, T4）：从 IBM Model 到 attention 到 soft routing
> 4. **稀疏 vs 稠密**（A7, R8）：从 attention 变体到检索双塔
> 5. **端到端 vs 流水线**（A5, T6, R5）：从 NMT 到 RAG 两阶段
> 6. **可微化**（A2, A3）：所有 ML 进展的一半动力

**这就是"算法经验库"的真正价值——它让你看到不同领域的方法其实是同一套算法 DNA 的不同化身**。
