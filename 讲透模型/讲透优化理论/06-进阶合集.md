## 06 - 凸优化应用

### 经典应用

| 问题 | 形式 | 求解 |
|------|------|------|
| **LP**（线性规划）| $\min c^T x$ s.t. $Ax \leq b$ | 单纯形 / 内点 |
| **QP**（二次规划）| $\min \frac{1}{2}x^T Q x + c^T x$ | 内点 / 活跃集 |
| **SOCP**（二阶锥）| $\|A_ix + b_i\| \leq c_i^T x + d_i$ | 内点 |
| **SDP**（半定规划）| $\min \text{tr}(CX)$ s.t. $A_i \bullet X = b_i$, $X \succeq 0$ | 内点 |

### ML 中的凸优化

- **LASSO**：$\min \|Ax - b\|^2 + \lambda \|x\|_1$（QP）
- **SVM**：$\min \|w\|^2/2$ s.t. $y_i(w^T x_i + b) \geq 1$（QP）
- **Logistic 回归**：$\min \sum \log(1 + e^{-y_i w^T x_i})$（凸）

### 反直觉

LASSO 的 $\ell_1$ 正则产生**稀疏解**（$\ell_2$ 不会）。→ 特征选择。

## 07 - 非凸优化

### 非凸为什么难

- 多个局部最小
- saddle point 多（高维更多）
- NP-hard（一般）

### 凸 relax

把非凸问题 relax 为凸：例 SDP relaxation（MAX-CUT / 流形学习）。

### 高维非凸的祝福

**反直觉**（Belkin et al. 2018）：高维非凸问题大多"无害"——saddle 多但 bad local min 少。

→ 过参数化 NN 的 loss landscape 几乎所有局部 min 都是 global（好的）。

### ML 应用

- **神经网络训练**：非凸 SGD
- **矩阵补全**：非凸核范数 → 凸
- **Phase retrieval**：非凸 → 凸 relax

## 08 - 一阶方法（SGD / Adam / Momentum）

### SGD

$x_{k+1} = x_k - \eta \nabla f(x_k)$（+ 随机噪声）

收敛：凸 $O(1/\sqrt{T})$，强凸 $O(1/T)$。

### Momentum

$v_{k+1} = \beta v_k + \nabla f$, $x_{k+1} = x_k - \eta v_{k+1}$

加速凸函数到 $O(1/T^2)$（Nesterov 最优）。

### Adam

自适应学习率（按梯度平方累积）。**实际最好用**但理论收敛性微妙（Reddi et al. 2018 反例）。

### Lion（Google 2023）

$\phi_t = \beta_1 \phi_{t-1} + (1-\beta_1) g_t$, $x_t = x_{t-1} - \eta \cdot \text{sign}(\phi_t)$

只用 sign（无幅度）→ 内存省。

### 应用

- **LLM 训练**：AdamW + warmup + cosine schedule
- **强化学习**：PPO / SAC 的优化器
- **Diffusion 训练**：AdamW

## 10 - 二阶与自然梯度

### Newton 法

$x_{k+1} = x_k - H^{-1} \nabla f$。$O((\log 1/\epsilon))$ 步（极快），但 $H^{-1}$ 昂贵。

### 拟牛顿（BFGS / L-BFGS）

近似 $H^{-1}$，不用显式 Hessian。L-BFGS 内存 $O(n)$。

### 自然梯度

$x_{k+1} = x_k - \eta F^{-1} \nabla f$，$F$ = Fisher 信息矩阵。

**直觉**：在"概率分布空间"而非参数空间走。

### K-FAC

近似 Fisher 为 Kronecker 积。用于大 NN。

### 应用

- **科学计算**：Newton / L-BFGS
- **变分推断**：自然梯度
- **NN**：二阶在深度网络不实用，但 K-FAC / Shampoo 有用
