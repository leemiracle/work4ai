# 04 - Lagrange 对偶与 KKT：Boyd Ch 5 的讲透版

> 对偶是凸优化的**最美结果**。它告诉你：每个优化问题都藏着一个"对偶问题"，两者最优值相等（凸情况下）。
>
> 基于 Boyd《Convex Optimization》Ch 5（免费 PDF + Stanford EE364A 视频）。

---

## 一、直觉

### 1.1 一个简单观察

你要最小化 $f(x)$，约束 $g(x) \leq 0$。

**想法**：把约束"价格化"——违反多少，罚多少。

$$L(x, \lambda) = f(x) + \lambda g(x), \quad \lambda \geq 0$$

对固定 $\lambda$，最小化 $L$（无约束）→ 得 $g(\lambda) = \min_x L(x, \lambda)$。

**对偶问题**：最大化 $g(\lambda)$ over $\lambda \geq 0$。

**反直觉**：原问题（min $f$ s.t. $g \leq 0$）变成对偶问题（max $g(\lambda)$ s.t. $\lambda \geq 0$）。两个问题最优值相等（凸情况）。

### 1.2 为什么对偶有用

- 对偶问题可能**更容易解**（变量更少 / 凸）
- 对偶变量 $\lambda$ 有**经济学解释**（"影子价格"）
- SVM 的对偶让 kernel trick 成为可能

## 二、数学层

### 2.1 Lagrange 函数

原问题：$\min f(x)$ s.t. $h_i(x) \leq 0$, $i=1,\ldots,m$; $\ell_j(x) = 0$, $j=1,\ldots,p$.

$$L(x, \lambda, \nu) = f(x) + \sum_i \lambda_i h_i(x) + \sum_j \nu_j \ell_j(x)$$

### 2.2 Lagrange 对偶函数

$$g(\lambda, \nu) = \inf_x L(x, \lambda, \nu)$$

**性质**：$g$ 是凹函数（即使原问题非凸）。

### 2.3 对偶问题

$$\max g(\lambda, \nu) \text{ s.t. } \lambda \geq 0$$

### 2.4 弱对偶

$$g(\lambda, \nu) \leq f^*$$（对偶值 ≤ 原问题最优值）

差 $f^* - g^*$ 叫**对偶间隙**。

### 2.5 强对偶 ★

凸问题 + **Slater 条件**（存在严格可行点）⟹ 强对偶：$g^* = f^*$（间隙 = 0）。

### 2.6 KKT 条件（强对偶时的最优性条件）

若强对偶成立，最优 $(x^*, \lambda^*, \nu^*)$ 满足：

1. **梯度为零**：$\nabla f + \sum \lambda_i \nabla h_i + \sum \nu_j \nabla \ell_j = 0$
2. **原可行**：$h_i(x^*) \leq 0$, $\ell_j(x^*) = 0$
3. **对偶可行**：$\lambda_i \geq 0$
4. **互补松弛**：$\lambda_i h_i(x^*) = 0$（要么约束紧，要么 $\lambda_i = 0$）

**反直觉**：互补松弛说"不紧的约束 $\lambda = 0$"——经济学上，没限制的资源价格是 0。

## 三、应用：SVM 的对偶（经典案例）

### 3.1 原问题

$$\min_{w,b} \frac{1}{2}\|w\|^2 \text{ s.t. } y_i(w^T x_i + b) \geq 1, \forall i$$

### 3.2 对偶问题

$$\max_\alpha \sum_i \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^T x_j$$
$$\text{s.t. } \alpha_i \geq 0, \sum_i \alpha_i y_i = 0$$

**关键**：对偶只依赖 $x_i^T x_j$（内积）→ 换成 kernel $K(x_i, x_j)$ → **kernel SVM**。

**反直觉**：原问题在特征空间（可能无穷维），对偶让你**不需要显式计算特征**——只要 kernel。

## 四、Python 实验：SVM 对偶

### `experiments/04_duality.py`

```python
"""
讲透优化理论 04 章实验：SVM 的对偶（强对偶验证）。
"""
import numpy as np
from scipy.optimize import minimize


def part1_svm_primal():
    """SVM 原问题：min ||w||²/2 s.t. y_i(w·x_i+b) ≥ 1"""
    print("=" * 65)
    print("[1] SVM 原问题（线性可分数据）")
    print("=" * 65)
    # 生成可分数据
    np.random.seed(42)
    X_pos = np.random.randn(20, 2) + [2, 2]
    X_neg = np.random.randn(20, 2) + [-2, -2]
    X = np.vstack([X_pos, X_neg])
    y = np.array([1]*20 + [-1]*20)

    # 原问题：min ||w||² s.t. y_i(w·x_i+b) >= 1
    def primal_obj(params):
        w = params[:2]
        b = params[2]
        return 0.5 * np.dot(w, w)

    constraints = [{'type': 'ineq', 'fun': lambda p, i=i: y[i] * (np.dot(p[:2], X[i]) + p[2]) - 1} for i in range(40)]
    res = minimize(primal_obj, [0, 0, 0], constraints=constraints)
    print(f"  原问题最优 w = {res.x[:2]}, b = {res.x[2]:.4f}")
    print(f"  原问题最优值 = {res.fun:.4f}")
    return res.x, X, y


def part2_svm_dual(X, y):
    """SVM 对偶问题"""
    print()
    print("=" * 65)
    print("[2] SVM 对偶问题（验证强对偶）")
    print("=" * 65)
    n = len(y)
    # 对偶：max sum α_i - 0.5 sum α_i α_j y_i y_j x_i·x_j
    # 等价 min 0.5 α^T Q α - 1^T α, 其中 Q_ij = y_i y_j x_i·x_j
    Q = np.outer(y, y) * (X @ X.T)
    def dual_obj(alpha):
        return 0.5 * alpha @ Q @ alpha - alpha.sum()
    constraints = [{'type': 'eq', 'fun': lambda a: np.dot(a, y)}]
    bounds = [(0, None)] * n
    res = minimize(dual_obj, np.ones(n)/n, constraints=constraints, bounds=bounds)
    alpha = res.x
    # 从对偶解恢复 w
    w = (alpha * y) @ X
    # 找 support vector（α > 0）恢复 b
    sv = np.argmax(alpha > 1e-5)
    b = y[sv] - np.dot(w, X[sv])
    print(f"  对偶最优 α 的非零个数 = {(alpha > 1e-5).sum()}")
    print(f"  对偶恢复 w = {w}, b = {b:.4f}")
    print(f"  对偶最优值 = {-res.fun:.4f}")
    return w, b, -res.fun


def main():
    print("讲透优化理论 04 章实验：SVM 对偶 + 强对偶验证")
    (w_p, b_p), X, y = part1_svm_primal() if False else (None, None, None)
    # 实际跑
    primal_x, X, y = part1_svm_primal()
    primal_val = 0.5 * np.dot(primal_x[:2], primal_x[:2])
    dual_w, dual_b, dual_val = part2_svm_dual(X, y)
    print()
    print("=" * 65)
    print(f"  原问题最优值 = {primal_val:.4f}")
    print(f"  对偶最优值   = {dual_val:.4f}")
    print(f"  对偶间隙     = {primal_val - dual_val:.6f}")
    print(f"  → {'强对偶 ✓（凸 + Slater）' if abs(primal_val - dual_val) < 0.1 else '有间隙 ✗'}")
    print("=" * 65)


if __name__ == "__main__":
    main()
```

## 五、不足

- 对偶**不一定强**（非凸问题有间隙）
- KKT 是**必要**条件，凸情况下才**充分**
- 对偶问题可能**变量更多**（样本数 > 特征数时）
