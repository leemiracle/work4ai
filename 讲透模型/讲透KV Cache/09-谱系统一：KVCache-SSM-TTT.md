## 一、直觉层：一张图看清"上下文"的三种物化

自回归模型每读一个 token，都要把"历史"放在**某个地方**。2026 年的答案不是一个，是一个谱系：

```
            "上下文"物化谱系（同一数学对象的两端与内点）

  ◄─── 精确外存 ─────────────────────────────── 压缩状态 ───►
  KV Cache（softmax attention）          SSM/线性注意力/TTT
  · 历史显式存为 K,V 矩阵                · 历史压进固定大小状态 S/W
  · 线性增长显存                          · 常数显存
  · 精确检索（无损）                      · 有损（但可学习"压什么"）
  · 读代价：注意力扫描                    · 读代价：一次矩阵乘
              ▲                                    ▲
              │              ▼ 内点                │
              │      混合架构（Qwen3.5：75% 线性层   │
              │      + 25% softmax 层；Kimi/K2 等）  │
              └──── 数学上被 2602.21204 统一 ────────┘
```

一句话：**KV cache 和"TTT fast weights"不是竞争技术，是"上下文"这个数学对象在精确-压缩谱系上的两端**。生产架构已经在谱系内部取内点。

## 二、数学层：统一定理与它的精确边界

### 2.1 核心定理（2602.21204，Theorem 5.1-5.3）

设 TTT 内环函数 $f(x) = \phi(x;\Theta)W$（**末层线性无偏置**），每步对 KV binding 损失做一步梯度下降。则对任意查询 $q$，更新后的输出**精确等于**线性注意力算子：

$$o_t = \hat q_t\Big(S_0 + \sum_{i \le t} \hat k_i^\top \hat v_i\Big), \quad \hat q_t = \phi_{t+1}(q_t),\ \hat k_i = \phi_i(k_i),\ \hat v_i = g_i(k_i)$$

**读法**：TTT 的"记忆"（fast weights $W$）展开后就是线性注意力的关联矩阵 $S = \sum \hat k^\top \hat v$——**KV cache 里存的 $\sum k^\top v$ 结构，TTT 用梯度下降在线构造同一结构**。这就是"secretly"的含义：不是类比，是代数恒等（在限定条件下）。

三个推论直接解释了 KV cache 视角下的怪现象：
- **梯度上升无害**：符号翻转被 $\hat v$ 吸收（$-\hat v$ 也是合法 value）；
- **Q/K 分布错位无害**：$\hat q$ 与 $\hat k$ 走不同的映射 $\phi_{t+1}$ vs $\phi_t$，本来就不需要同空间；
- **内环步数多了反而伤**：改变了训练时的算子（train-test mismatch），不是"记得更多"。

### 2.2 边界（诚实版——引用必读）

| 限定 | 内容 | 证据 |
|------|------|------|
| **只覆盖 TTT-KVB** | 内环优化 KV binding 损失（MSE/内积），**非任务损失** | 论文 §3 明示 |
| **末层线性无偏置** | 非线性末层 = 论文自认 open（附录 I 不可约情形） | 结论节原文 |
| **TTT-E2E 完全不在射程** | 而后续工作（2512.23675）显示 **E2E 损失显著优于 KVB**——被统一的恰是次优设计 | 2512.23675 Table 1 |
| **29× 是终点吞吐** | 性能最优点是 Variant 1（只更新末层），不是完全简化 | Table 2 逐格读 |

**正确引用姿势**：该文证明"**KVB 型 TTT ≈ 带可学习核的线性注意力**"，不证明"TTT 范式 ≈ 线性注意力"。

### 2.3 谱系的经济学（与 01 章内存账的对接）

| | KV Cache | SSM 状态 | TTT fast weights |
|---|---------|---------|------------------|
| 每 token 显存 | $O(n)$（线性涨） | $O(d^2)$ 常数 | $O(d_h \times d_{out})$ 常数 |
| 读一个信息 | 精确（在 context 内） | 有损检索 | 有损但**可学**（核 $\phi$ 可学） |
| 写入代价 | 一次投影（便宜） | 一次状态更新 | 一次梯度步（贵，但 E2-TTT 闭式核已降到 chunk 并行） |
| 工程代表 | MLA（57× 压缩仍线性） | Mamba-2/3、GDN | Titans、LaCT、E2-TTT |

## 四、谱系的谱系：三个尚无人回答的问题

1. **非线性末层的可约性**（论文 open #1）：GLU 核之外，什么内环结构逃出线性注意力类？（张量网络视角：逃出=关联矩阵变成高阶张量）
2. **KVB 为何次优**（2512.23675 现象无理论）：内环目标函数设计是 TTT 最大自由度——next-token 损失胜出的机制是什么？（猜测：它优化的是**混合算子本身**而非"重建"）
3. **softmax vs 线性族的分离定理**：带可学习核+数据依赖 value 的扩展线性族，表达力上界到底在哪？（连接讲透模型/讲透NLP 的表达力线）

## 五、对 agent 设计的落点（回接 08 章）

agent 的"记忆"设计空间因这个统一而重构：
- system prompt/工具结果（稳定复用）→ **KV cache 端**（prefix caching/CacheScout 在线学习调度）；
- 会话沉淀的能力/偏好（慢变化）→ **TTT 端**（fast weights 持续吸收，Titans 式惊喜度写入）;
- 混合是常态：**agent = 沿谱系按信息变化速率分层放置记忆**——这和讲透Loop Ch06 的 state file（盘上）/memory block（上下文）分层完全同构，只是发生在架构层。

> 收尾句：KV cache 教的是"历史放在哪里的经济学"；谱系统一教的是——**放哪里都是同一个数学，选位置=选压缩率**。
