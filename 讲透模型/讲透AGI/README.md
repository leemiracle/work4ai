# 讲透 AGI（通用人工智能）

> **AGI 是 AI 的圣杯，也是这个时代最大的技术命题**。但它承载太多：是工程目标？哲学命题？商业故事？存在性风险？每一派都在用"AGI"这个词，说的却不是同一件事。
>
> **本系列要做四件事**：①把"AGI 到底是什么"讲清楚（定义的迷雾）；②把"通往 AGI 的所有路径"列全（六大技术路线 + 算法百科）；③把"我们离 AGI 多远"量化（2026 最新 benchmark 全景）；④把"该不该、怎么追、风险多大"的多视角交锋摆开（五大学派 + 风险治理）。
>
> 🆕 **2026-08-14 新建**：作为 `讲透X` 系列的**顶层鸟瞰**——把 LLM/世界模型/RL/Agent/多模态/神经符号/具身全部串成"通往 AGI 的赛道"，单点深入时知道去哪。

**核心定位**：AGI 不是某一项技术，而是**所有当前 AI 子领域的收敛点**。每个子领域都解决 AGI 的某一块拼图：
- LLM 解决「语言与知识压缩」
- RL 解决「决策与规划」
- 世界模型解决「对物理/动态环境的预测」
- Agent 解决「长程任务的执行」
- 神经符号解决「严格推理与可验证性」
- 具身智能解决「感知与运动」
- 多模态解决「跨模态理解」

→ **AGI = 把这些拼图拼起来，且每一块都达到人类水平**。

## 🔑 全系列 10 个核心洞察（速览）

1. **AGI 没有统一定义**——6 种主流定义（人类水平/超越人类/通用/自主学习/经济价值/多任务），不同定义下"是否到了 AGI"答案完全不同。Chollet 给出最锋利的定义：**AGI = 一个能匹敌人类学习效率的系统**。
2. **AGI ≠ 一个大模型**——它是一个**系统能力**：感知 + 记忆 + 推理 + 规划 + 行动 + 学习的闭环。当前 LLM 只覆盖「语言理解+部分推理」，离 AGI 缺：长程规划、持续学习、世界模型、具身行动。
3. **七次浪潮**：符号 AI → 连接主义复兴 → 统计学习 → 深度学习 → LLM → 推理时计算（o1/R1）→ Agent/世界模型。每一波都解决了前一波的瓶颈。
4. **六大路径并存**：①LLM scaling（OpenAI/Anthropic）②世界模型（LeCun JEPA/DeepMind）③神经符号（AlphaProof）④具身（机器人 VLA）⑤进化/自我博弈（AlphaZero）⑥全新架构（SSM/Hyperdimensional/类脑）。**没有人知道哪条会先到**。
5. **2026 年关键事实**：GPT-5.6 Sol 在 ARC-AGI-3 仅 **7.78%**（人类几乎满分）→ 这是"AGI 北极星"，证明 scaling 远未到 AGI；但 GPT-5.5 发现 **Ramsey 数新证明**（Lean 验证）→ AI 已能做创造性数学研究。
6. **算法不止 Transformer**——从经典 A*、MCTS，到 RL 的 PPO/SAC/AlphaZero，到世界模型的 JEPA/Dreamer，到对齐的 RLHF/DPO/GRPO，再到推理的 CoT/ToT/PRM。**AGI 需要全部**。
7. **强化学习是 AGI 的核心引擎**——AlphaGo/AlphaZero 证明 self-play 能超越人类；DeepSeek-R1 证明纯 RL（无人类示范）能激发 reasoning；RLVR（verifiable reward）是 2025-2026 最大突破。
8. **推理时计算是新的 scaling 维度**——o1/o3/R1 把"训练时多算"转向"推理时多想"，让模型在数学/代码上从"碰运气"变成"系统求解"。这是与 LLM scaling 并行的第二条曲线。
9. **世界模型是 AGI 的最大缺口**——LLM 缺乏对物理世界的因果理解。LeCun 主张 JEPA（抽象表征预测），Sora/Cosmos 主张像素级生成。两条路线在 2025-2026 激烈交锋。
10. **风险与时间表严重分歧**——乐观派说 2027-2030，怀疑派说几十年或永远不会，风险派说可能在 5-10 年内带来存在性威胁。**没有共识**——这是本系列要呈现的核心张力。

## 🧭 与"讲透"系列的写作原则

本系列遵循 `讲透X` 宇宙的统一原则（见 [`讲透LLM/README`](../讲透LLM/README.md)）：

1. **三层讲透**：直觉 → 数学 → 代码/实例
2. **批判性**：每一派都给出最强论证 + 反驳
3. **多视角**：技术/哲学/社会/经济/风险
4. **新鲜度**：所有数据锚定 2026-08，标注来源与日期
5. **可导航**：每篇结尾指向相关专题
