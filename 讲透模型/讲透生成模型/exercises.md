# 练习题汇总 · 讲透生成模型

> 输出倒逼输入。这里的练习分三类：**概念题**（检验直觉）、**动手题**（改代码看结果）、**洞察题**（连接章节）、**进阶题**（挑战理解）。建议每章学完立刻做对应题目，不要囤着。

---

## 第 0 章 · 统一视角

1. **[概念]** 用一句话向没学过 ML 的人解释"判别模型"和"生成模型"的区别。
2. **[洞察]** 实验里 GAN 只命中 1/8 模态。如果要缓解，你会往哪个方向想？（提示：00 章 4.2"漏模态惩罚弱"。）
3. **[动手]** 把 `00_unified_view.py` 里 GAN 的判别器训练从 1 步/轮改成 **3 步/轮**，重跑，观察模态覆盖变化。
4. **[思考]** 为什么用"8 个高斯团"而不是"1 个高斯团"当目标？（提示：单模态看不出模式崩溃。）

## 第 1 章 · 自回归 AR

1. **[概念]** 贪心 AR 会无限复读。用"覆盖 vs 清晰"语言解释这是哪种问题。
2. **[动手]** 把 `generate` 的 `temperature` 调到 `2.0`，观察输出变化并解释。
3. **[思考]** exposure bias 在本实验里有可观察的现象吗？如果没有，说明什么？
4. **[进阶]** 换成 5 万 token 词表 + 12 层 Transformer，训练目标和损失函数变了吗？

## 第 2 章 · VAE

1. **[概念]** 一句话解释"为什么 AE 不能生成、VAE 能"。
2. **[动手]** 给 `02_vae.py` 加一个 β=0.3，预测它落在 β=0.01 和 β=1.0 之间的哪里，再验证。
3. **[洞察]** β=10 时 KL=0.000。此时 $q_\phi(z\mid x)$ 等于什么？
4. **[进阶]** 重参数化 `z=μ+σ⊙ε` 中，为什么梯度能穿过 $\mu,\sigma$ 却不能穿过"直接采样"？

## 第 3 章 · GAN

1. **[概念]** 为什么"判别器只看局部假钞像不像"会导致模式崩溃？
2. **[动手]** 把 WGAN 的 weight clipping 上限 `c` 从 0.01 改成 0.1，覆盖变好还是变差？为什么？
3. **[洞察]** JS 散度在分布不重叠时梯度为 0，Wasserstein 仍有梯度。画图想清楚这句话。
4. **[进阶]** 为什么 WGAN 必须去掉判别器的 sigmoid？

## 第 4 章 · 标准化流 Flow

1. **[概念]** 为什么 Flow 能算精确似然，VAE 只能算下界？
2. **[动手]** 把 coupling 层数从 6 改成 12，NLL 会更低吗？
3. **[洞察]** 如果每一层 coupling 都改同一半会怎样？
4. **[进阶]** 变量替换公式里 $|\det J|$ 的几何含义是什么？

## 第 5 章 · 扩散 Diffusion

1. **[概念]** 为什么前向不用学、反向要学？
2. **[动手]** 把 $T$ 从 100 改成 20，生成质量变好还是变差？
3. **[洞察]** 为什么"学会去噪"等价于"学会生成"？
4. **[进阶]** Stable Diffusion 在潜空间而非像素空间做扩散，省了什么？

## 第 6 章 · 统一 Score·SDE

1. **[概念]** 为什么学分数 $\nabla\log p$ 比学密度 $p$ 容易？
2. **[动手]** 把朗之万步数从 200 改成 50，生成点更集中还是分散？
3. **[洞察]** 朗之万采样去掉随机扰动项 $\sqrt{\eta}\varepsilon$ 会怎样？
4. **[进阶]** DDPM 为什么用多个噪声水平 $t$ 训练，而不是一个？

## 第 7 章 · 横评与选型

1. **[应用]** "实时把用户的脸换成明星"的 App，选哪个模型？为什么？
2. **[应用]** "检测信用卡交易异常"的系统，选哪个？（提示：要算 $p(x)$。）
3. **[批判]** 从 2D 玩具到真实图像，最大的工程挑战是什么？
4. **[思考]** 为什么文本被 AR 独占、图像被 Diffusion 独占？

## 第 8 章 · 批判与未解

1. **[批判]** 生成**医学 X 光片**的模型，FID 还可信吗？该怎么评估？
2. **[伦理]** 扩散能复现训练图，对版权/隐私/deepfake 防御意味着什么？
3. **[洞察]** 举一个你常用的 AI 产品，说明它"工程跑在理论前面"。
4. **[展望]** 基于 4、6 章，猜 Flow Matching 怎么统一 Flow 和 Diffusion？

## 综合大作业（可选，给想深挖的人）

> **任务**：把 `00_unified_view.py` 扩展成"五大流派同台"——加上 **AR** 和 **Flow** 学 8-高斯，画一张 1×6 的对比图（真实 / AR / VAE / GAN / Flow / Diffusion），统计各自的模态覆盖。
>
> **挑战点**：
> - AR 在连续 2D 上要离散化（把平面分格子，按格子顺序生成）——体会 AR 对连续数据的别扭。
> - Flow 用 `04_flow.py` 的 RealNVP 直接接上。
> - 把六者放在**完全相同**的容量、步数、seed 下对比，才算公平。
>
> 做完后你应该能用一张图回答："哪个模型在 8-高斯上覆盖最好、质量最高、训练最快？"——这就是本教程的终极答案（剧透：没有银弹，各有取舍）。
