# 01 · 模型宇宙全景图

> "太阳底下没有新东西。"——传道书 1:9
>
> 这句话套在 AI 架构上，准确得令人不安：你今天惊呼的"新架构"，大概率能在 30 年前的论文里找到它的骨架。

## 1.1 直觉：模型宇宙的"星系"

如果模型是一个宇宙，那它不是一堆散乱的星星，而是分成几个**星系**。划分星系的轴有几个，但最本质的两个是：

- **处理什么形态的数据？**（输入的几何结构）
- **怎么生成输出？**（输出的概率形式）

把这两个轴一交叉，模型宇宙就分成几大星系：

```
                    输出
          判别(给标签)        生成(给分布)
        ┌──────────────┬──────────────┐
   序列 │ RNN/LSTM     │ GPT/AR       │
输      │ Transformer  │ Diffusion    │
入      │ Mamba/SSM    │ Flow/VAE     │
序列    │              │              │
        ├──────────────┼──────────────┤
   空间 │ CNN/ResNet   │ GAN          │
(图/像) │ ViT          │ Diffusion    │
        │              │              │
        ├──────────────┼──────────────┤
   图/  │ GNN/GCN      │ GraphRNN     │
   关系 │ Equivariant  │              │
        └──────────────┴──────────────┘
```

还有几个横切的"维度"不属于上面这张表：**强化学习**（按奖励学习，不分输入形态）、**世界模型**（预测未来状态）、**神经符号**（混合符号推理）。

**关键洞察**：这张表里的每个格子，骨架都是几十年前定下的。真正"新"的东西，往往是**把老骨架用新数据/新规模重新组合**。

## 1.2 五波浪潮：模型宇宙的演化史

把时间轴拉长，AI 模型的演化是清晰的五波：

### 第一波：符号与感知机（1958-1986）
- **1958** Rosenblatt 感知机——第一个"学习"的模型。但 Minsky 1969 证明它连 XOR 都学不会，直接引发第一次 AI 寒冬。
- 这波的遗产：**模型 = 参数化的函数 + 从数据学参数**。这个范式至今未变。

### 第二波：反向传播与浅层网络（1986-1998）
- **1986** Rumelhart-Hinton-Williams 重新发现反向传播——让多层网络可训练。
- 这波的遗产：**梯度下降 + 链式法则**。这就是今天 PyTorch 的底层原理。

### 第三波：CNN/RNN/SVM（1998-2014）
- **1998** LeCun LeNet（CNN 用于手写数字）。
- **1997** Hochreiter LSTM（RNN 解决长依赖）。
- **1995** Vapnik SVM（核方法巅峰）。
- 这波的遗产：**卷积（局部+平移不变）**、**循环（时序记忆）**。

### 第四波：深度学习 + 注意力（2014-2017）
- **2012** AlexNet（GPU + 深度 CNN + ReLU + Dropout，ImageNet 革命）。
- **2014** GAN（Goodfellow）、VAE（Kingma）——生成模型两大家族。
- **2015** ResNet（残差连接——让百层网络可训）。
- **2017** Transformer（Vaswani，*Attention is All You Need*）。
- 这波的遗产：**残差**、**注意力**、**生成对抗**。这三个是真正的"新发明"。

### 第五波：基础模型与世界模型（2018-2026）
- **2018** BERT/GPT——预训练范式确立。
- **2020** Scaling Laws（Kaplan，`arXiv:2001.08361`）——"越大越准"成为科学。
- **2022** ChatGPT、Diffusion 图像生成爆发。
- **2022** Toy Models of Superposition（`arXiv:2209.10652`）——可解释性成科学。
- **2024-2026** Mamba/SSM 复兴、MoE 普及、世界模型（JEPA）、reasoning model（o1/o3）。

## 1.3 反直觉：80% 的"新架构"是老想法回流

这是本章的核心发现，也是 `experiments/01_family_timeline.py` 要量化的。

把每个"热门新架构"和它**真正的学术起源**对一遍：

| 今天的热门 | "新"在哪 | 真正起源 | 间隔 |
|-----------|---------|---------|------|
| Transformer Attention (2017) | 自注意力 | **Hopfield 网络 (1982) / 现代注意力 (Bahdanau 2014)** | 3-35 年 |
| Mamba/SSM (2023) | 状态空间 | **线性时不变系统/卡尔曼滤波 (1960s); HiPPO (2020)** | 3-60 年 |
| MoE 混合专家 (2024 普及) | 稀疏路由 | **Jacobs et al. 1991 (混合专家原论文)** | 33 年 |
| Diffusion (2022) | 去噪生成 | **扩散过程 (Sober 1994); score matching (Vincent 2011)** | 11-28 年 |
| ResNet 残差 (2015) | 残差连接 | **Highway Networks (Srivastava 2015, 同年更早)** | 0 年（真新）|
| LoRA 微调 (2021) | 低秩适配 | **矩阵低秩分解 / adapters (Houlsby 2019)** | 2-几十年 |
| 世界模型 JEPA (2022) | 预测潜在空间 | **预测编码 (Rao 1999); world models (Ha 2018)** | 4-23 年 |
| Test-time scaling (o1, 2024) | 推理时多算 | **搜索 (Minsky 1960s); AlphaGo MCTS (2016)** | 8-60 年 |

**数一数**：8 个"热门"里，真正"新"的（起源和流行同年）只有 1 个（ResNet）。其余 7 个都是**老想法 + 新规模/新数据的重新组合**。比例 **87.5%**。

这不是贬低——**组合创新是真创新**。但它纠正一个幻觉：

> **不要因为一个架构"新名字"就以为它"新原理"。研究模型的第一步，是看穿名字、找到骨架。** 这正是本系列 Part III"第一性原理"要练的能力。

## 1.4 为什么会"回流"？三个结构原因

1. **算力解锁**：很多老想法在 1990s 因算力不够而搁置。MoE 1991 年就提出，但路由训练需要大量参数和样本，直到 2020s 的 GPU 才喂得起。
2. **数据形态变了**：注意力 2014 年用于机器翻译（小数据），2017 年把它放到超大语料上才显出威力。
3. **理论补上了**：Diffusion 的数学（SDE、score）1940s 就有，但直到 2020 Song & Ermon 把 score matching 和 SDE 统一，才成为可用的生成框架。

> 研究者的目光：看到一个"新架构"，先问三件事——**(1) 它的老祖宗是谁？(2) 是什么算力/数据/理论让它现在能 work？(3) 它的归纳偏置（inductive bias）比上一个强在哪？** 答得出这三问，你就看穿了名字。

## 1.5 实验：量化"新瓶装旧酒"

见 `experiments/01_family_timeline.py`。它把上面那张表编码成数据，计算并打印：
- 每个热门架构的"回流间隔"（流行年 - 起源年）；
- 全行业"新瓶装旧酒"比例；
- 反直觉结论：中位回流间隔超过 **20 年**。

## 1.6 批判与不足

- **"回流"不等于"无创新"**：组合创新、规模创新、理论补全都是真创新。本节的"反直觉"是**纠正命名幻觉**，不是否定贡献。
- **起源归属有主观性**：一个想法往往有多人独立提出。本表取"最常被引的最早公开文献"，不唯一。
- **真正的颠覆性创新存在但稀少**：反向传播、注意力机制、残差连接、扩散的 score 统一——这些是几十年一遇的"新原理"。
