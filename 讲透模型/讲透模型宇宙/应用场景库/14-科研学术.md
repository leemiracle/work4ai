# 14 · 科研 / 学术（AI for Science + 文献 + 写作）

> 科研是 AI 最具变革性的领域——不是"提效"，而是**做原来做不到的科学**（AlphaFold 解 50 年难题、GNoME 把人类已知材料扩 10 倍）。本类 8 个场景，分三组：AI for science（造新知识）、文献工具（消化已有知识）、写作（产出新论文）。**铁律**：AI 是科研"副驾"，验证责任永远在人；高风险判断必须披露（Cochrane/Campbell/JBI/CEE 2025 RAISE 声明）。

---

## 一、AI for Science（造新知识）

### 场景 76：蛋白质结构预测与药物设计
- **痛点**：实验解析一个蛋白结构要数年+数十万美元；药物设计依赖结构。
- **输入 → 输出**：氨基酸序列 → 3D 结构 + 分子相互作用。
- **模型方案**：**专用基础模型**（AlphaFold 类）+ 专用服务器。
- **真实案例（2024-2026）**：**AlphaFold**（2024 诺贝尔化学奖）—— 2 亿+蛋白结构（近乎所有已知蛋白），**3 百万+研究者/190 国**；AF2 使研究者新结构提交 **+40%**，相关研究被临床文章引用概率 **2x**、被专利引用概率显著升。**AlphaFold 3** 预测所有生命分子（蛋白/DNA/RNA/配体）相互作用；AlphaProteo 设计新蛋白结合体（靶向癌症/糖尿病靶点）。**Isomorphic Labs** 基于 AF 建 AI 药物设计引擎。
- **工具栈**：AlphaFold Server（免费非商业）/ ColabFold / 本地 AF3。
- **陷阱**：AF 给的是**静态结构**非动态；蛋白-配体亲和力预测仍需实验验证；不能直接当"药物"。
- **起步 MVP**：用 AlphaFold Server 预测你研究蛋白的结构，对比已知实验结构。

### 场景 77：材料 / 能源发现
- **痛点**：新材料（电池/光伏/芯片）靠试错，慢且贵。
- **输入 → 输出**：化学空间 → 稳定候选材料 + 合成路径。
- **模型方案**：**图神经网络 + 主动学习 + DFT 验证**的数据飞轮。
- **真实案例**：**GNoME**（Merchant et al. 2023, *Nature* doi:10.1038/s41586-023-06735-9）—— 发现 **381,000 个新稳定材料**（人类已知稳定材料 **10 倍**扩张），736 个已被独立实验合成；学到精确到 11 meV/atom 的能量预测。**AlphaFold 模板**外推到能源/材料（DeepMind 路线）。
- **工具栈**：GNoME（开源）/ Materials Project / OQMD；学习型原子间势。
- **陷阱**：发现 ≠ 可合成——相变/动力学稳定性/可合成性仍是开放问题；需实验闭环。
- **起步 MVP**：用 GNoME Colab 探索某化学体系的稳定相。

### 场景 78：AI 辅助科研假设生成与实验设计（Co-Scientist）
- **痛点**：提出新假设、缩小实验搜索空间耗时。
- **输入 → 输出**：研究问题 → 候选假设/靶点/药物重定位。
- **模型方案**：**多 agent 科研助手**（假设生成→批评→迭代）。
- **真实案例**：**Google Co-Scientist** —— Gary Peltz 用它找肝纤维化药物重定位，发现被忽视的候选，实验中**阻断 91% 瘢痕相关反应**（发表于 *Advanced Science*）；Clare Bryant 用它缩小跨物种传播（流感/COVID 动物→人）蛋白搜索到特定氨基酸，"把数年实验压到数月"。
- **工具栈**：Google Co-Scientist / Gemini for Science / 自建多 agent。
- **陷阱**：AI 假设≠正确——必须实验验证；过度信任会浪费资源在错靶点。
- **起步 MVP**：用 LLM 对你的研究问题生成 5 个可验证假设 + 实验设计建议。

### 场景 79：天气 / 气候 / 灾害预测
- **痛点**：传统数值天气预报算力大、精度有上限。
- **输入 → 输出**：大气状态 → 高精度预报（路径/强度/风场）。
- **模型方案**：**AI 天气基础模型**（端到端学习大气动力学）。
- **真实案例（2026）**：**WeatherNext**（Google DeepMind，2026-08 *Nature* doi:10.1038/s41586-026-10953-2）—— 气旋路径/强度/风场 SOTA，**多给 1 天预警**（≈10 年气象进步）；2025 飓风 Melissa 历史性登陆牙买加预报（NHC 用它发预警）；1000 成员集合；**开源** WeatherNext 2 + Cyclones。
- **工具栈**：WeatherNext（开源）/ GraphCast / Pangu-Weather。
- **陷阱**：极端事件罕见样本少；AI 预报仍需与传统集合融合；决策需人解释。
- **起步 MVP**：对比 WeatherNext 与传统预报在你所在地区一次台风路径上的表现。

## 二、文献工具（消化已有知识）

### 场景 80：文献发现 / 引用图谱
- **痛点**：找不到相关论文；关键词搜不全。
- **输入 → 输出**：种子论文引用邻域 → 相关工作图谱。
- **模型方案**：**引用图遍历 + 语义搜索**。
- **真实案例**：**Connected Papers / ResearchRabbit**（引用图谱）；**Semantic Scholar**（AI 语义搜索，2 亿+论文）。
- **工具栈**：Connected Papers / ResearchRabbit / Semantic Scholar / Inciteful。
- **陷阱**：只看引用邻域会错过跨学科；补关键词 + 专家推荐。
- **起步 MVP**：用 Connected Papers 画你最近一篇论文的引用邻域，找 3 篇你漏看的。

### 场景 81：文献综合 / 证据合成（系统综述自动化）
- **痛点**：系统综述要读几百篇、提数据、PRISMA 流程重。
- **输入 → 输出**：研究问题 → 结构化证据表 + 综合报告 + 句级引用。
- **模型方案**：**RAG + 结构化抽取 + PRISMA 工作流**。三工具分工：发现（Elicit）、综合（Consensus）、引用验证（Scite）。
- **真实案例（2026）**：**Elicit**（138M 论文）—— 系统综述省 **80% 时间**；994 Cochrane 评测：**95% 召回 / 97% 摘要筛 / 99% 全文筛 / 96% 抽取**；支持 PRISMA 2020；Research Agent + API/MCP。**Consensus**（共识表 yes/no/mixed，200M+论文）。**Scite**（Smart Citations——区分支持/反对/提及；reference check 查撤稿/更正）。**最佳实践**：Consensus 快速测证据倾向 → Elicit 结构化抽取 → Scite 验证引用。
- **工具栈**：Elicit（系统综述）/ Consensus（证据快答）/ Scite（引用验证）/ NotebookLM（综合）。
- **陷阱**：**幻觉/虚构引用**——所有工具都可能给假引用，验证永远在人；厂商准确率是"起点非替代"；系统性综述仍需可复现检索策略 + 偏倚评估。
- **起步 MVP**：用 Consensus 测一个 yes/no 研究问题的证据倾向，再 Elicit 抽 5 篇关键数据。

## 三、论文写作

### 场景 82：论文写作 / 润色 / 引用管理
- **痛点**：非母语写作；引用格式烦；投稿准备。
- **输入 → 输出**：草稿 → 学术英语润色 + 引用格式 + 期刊就绪检查。
- **模型方案**：**学术专用写作助手**（训于已发表论文）+ 引用管理。
- **真实案例**：**Writefull / Paperpal**（训于期刊论文，Word/Overleaf 集成，含期刊就绪检查）；**Jenni AI**（行内引用建议 + 下句预测）；**Grammarly**（通用，基础校对免披露）。
- **工具栈**：Writefull / Paperpal / Jenni AI / Zotero（管理）/ Tesify（论文写作）。
- **陷阱**：**AI 披露合规**——实质性起草/改写需披露（Elsevier/T&F 政策）；基础语法免披露；Cochrane RAISE：做"判断"的 AI 用途必须披露（系统名/版本/目的/局限）。
- **起步 MVP**：用 Writefull 润色一段你的论文，对比改前改后；查目标期刊的 AI 披露政策。

### 场景 83：自主科研 Agent（端到端研究助手）
- **痛点**：科研全流程（搜文献→提假设→设计实验→分析→写）耗力。
- **输入 → 输出**：研究问题 → 多步研究流程（检索/抽取/综合/起草）。
- **模型方案**：**科研 agent**（多步规划 + 工具调用 + 句级引用）。
- **真实案例（2026）**：**Elicit Research Agent**（高stakes决策环境）；**Google Co-Scientist**（假设迭代）；学术界 AI Scientist 类原型。`research-companion`/`deep-research` skill 的 agent 化。
- **工具栈**：Elicit Research Agent / 自建（LangGraph + 检索 + LLM）。
- **陷阱**：agent 自主越久越易漂移/幻觉；高风险结论必须人验证；学术诚信——AI 贡献必须披露，作者责任不可委托给工具。
- **起步 MVP**：用 Elicit Research Agent 对一个研究问题生成结构化报告，逐条核对引用真实性。

## 科研领域 AI 的四条铁律
1. **AI 是副驾不是驾驶员**——假设/结论必须人验证（Co-Scientist 给候选，实验定夺）。
2. **幻觉/虚构引用风险最高**——所有文献工具都可能造假引用，验证责任永远在作者。
3. **披露是硬要求**——实质性 AI 用途（起草/综合/判断）必须披露（Cochrane RAISE / 出版商政策）。
4. **AI for science 的价值在"做原来做不到的"**（AlphaFold/GNoME/WeatherNext）而非仅提效——这才是范式变革。
