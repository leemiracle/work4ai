# 17 · 房地产 / 建筑 / BIM

> 建筑业生产率长期落后于其他行业（碎片化、手工流程几十年未变）。AI 在这里的杠杆：**把数十年非结构化数据（合同/估值/图纸）变可查、把工地现场变可监控、把设计变可生成**。本类 6 个场景。**铁律**：建筑涉安全/合规（RICS/Building Safety Act/ISO 19650），AI 必须符合专业标准。

---

### 场景 97：生成式设计 / 方案探索
- **痛点**：早期方案探索慢；多约束（成本/碳/法规）难平衡。
- **输入 → 输出**：需求 + 约束 → 多个设计备选（对齐/分级/路由）。
- **模型方案**：**参数化生成式设计**，自动产出多备选平衡成本/碳/法规。
- **真实案例（2026）**：**Autodesk** 25+ 专家趋势——生成式设计加速 optioneering，自动产出对齐/分级/路由方案，平衡成本/碳/法规；**RIBA 2026 报告**：**74%** 建筑事务所至少部分项目用 AI，用于早期设计探索/可视化。
- **工具栈**：Autodesk Forma / Rhino+Grasshopper / 自定义参数化 + LLM。
- **陷阱**：生成方案不合规 → 嵌法规约束；千篇一律 → 多样性激励。
- **起步 MVP**：一个场地的容积率/朝向约束，生成 5 个体量方案对比。

### 场景 98：工地安全监控（计算机视觉）
- **痛点**：工地事故多；靠人眼监控全覆盖不了。
- **输入 → 输出**：CCTV/无人机/可穿戴视频 → 实时危险识别（坠落/设备临近/缺 PPE/闯禁区）。
- **模型方案**：**CV 实时识别 + 即时告警**；4D BIM + 进度做预测性安全。
- **真实案例（2026）**：Autodesk 趋势——CV 从摄像头/无人机识别不安全状态/PPE 违规/危险行为，近实时告警；**SiteSync AI**（Gemini 3 Pro）实时分析摄像头帧识别结构偏差（12mm）/未护边缘/PPE 违规/碎片，**自动生成并派发 RFI**。4D BIM + 进度预测流程冲突/设备路径干扰/工人暴露风险。
- **工具栈**：CV 模型（YOLO/检测）+ CCTV/无人机 + BIM 集成 + 告警。
- **陷阱**：隐私（工人监控）→ 合规+同意；误报多 → 阈值+人工复核。
- **起步 MVP**：一个工地摄像头流，CV 检测 PPE 违规，测召回。

### 场景 99：质量比对 / Scan-to-BIM / 缺陷检测
- **痛点**：施工偏差发现晚，返工贵。
- **输入 → 输出**：LiDAR/无人机扫描 vs 设计模型 → 偏差/缺陷自动检测。
- **模型方案**：**点云 vs BIM 自动比对**，早发现偏差减返工。
- **真实案例（2026）**：Autodesk——AI 比 LiDAR/无人机扫描与设计模型，自动检测缺陷/偏差；SiteSync AI 宣称 **99.9% 设计保真度** + 12mm 偏差检测；Scan-to-BIM 流程自动化（2026 行业标准进展）。
- **工具栈**：LiDAR/无人机扫描 + 点云处理 + BIM 比对算法。
- **陷阱**：扫描噪声/遮挡 → 多次扫描融合；模型与现场坐标对齐。
- **起步 MVP**：一个房间的扫描点云 vs BIM，自动列偏差表。

### 场景 100：工程量自动提取 / 估算
- **痛点**：人工算量慢、易错；多格式（PDF/DWG/IFC/点云）难统一。
- **输入 → 输出**：图纸/模型 → 自动工程量 takeoff + 估算。
- **模型方案**：**ML 工程量抽取**，从 PDF/DWG/IFC/点云自动 takeoff。
- **真实案例（2026）**：Autodesk 趋势——ML 工程量抽取自动化 takeoff，显著减人工、提一致准确性；建筑 workflow 嵌入 AI 模型协调/生成 takeoff。
- **工具栈**：Document AI/OCR + ML takeoff + 估算引擎。
- **陷阱**：图纸不规范 → 抽取错；地区定额差异 → 本地化。
- **起步 MVP**：10 张 PDF 图纸，AI 抽主要工程量，对比人工。

### 场景 101：房地产估值 / 尽调 / 资产智能
- **痛点**：估值靠表格+直觉；尽调文档海量非结构化；组合数据孤岛。
- **输入 → 输出**：市场/可比/文档 → 估值 + 风险 + 组合洞察。
- **模型方案**：**多 agent**（估值 ML + 尽调文档 AI + 地理 + 视觉）+ 组合数据基础设施。
- **真实案例（2026）**：**Build.inc**（世界首个自主建造服务公司，2026-06 发布）—— agentic AI + 专家，预开发（选址/可行性/尽调/设计）**快 90%**，把数月变数小时；**150+ 项目/18 国**，服务财富 500/超大规模商/政府；获 $8.5M 种子（Index/Pebblebed/Tishman Speyer）。**Norvik**：尽调文档 AI + AI 估值模型 + 施工风险智能 + BIM/组合资产数据基础设施。**Deep Agent Real Estate**（开源）：多 agent（ReAct+MCP+A2A）超本地估值，XGBoost+SHAP 可解释 + 视觉损伤评估 + 地理便利度。
- **工具栈**：多 agent（LangGraph）+ XGBoost 估值 + 文档 AI + 向量搜索 + 地理 API + SHAP 可解释。
- **陷阱**：估值偏见（历史数据偏特定人群）→ 公平审计；尽调文档质量差 → 先清洗。
- **起步 MVP**：一个区域的成交数据训估值模型，SHAP 解释关键因子。

### 场景 102：预开发 / 可行性自动化
- **痛点**：选址/可行性/尽调耗月；决定项目能否建。
- **输入 → 输出**：需求 + 数据源 → 选址/可行性/尽调报告。
- **模型方案**：**agentic AI + 领域专家**，并行（非串行）多专业，连 2000+ 数据源。
- **真实案例（2026）**：**Build.inc** —— "neofirm"模式（多数工作由技术做+专家层出机构级产出）；partner 像聘顾问一样邮件/电话接入，数天（非数周）拿验证交付物；用于数据中心建设潮（"这代最大工业项目"）。
- **工具栈**：agentic AI + 多数据源连接 + 专家审 + 系统记录平台。
- **陷阱**：并发专业冲突 → 协调 agent；交付物需专家验（尤其中介/法律）。
- **起步 MVP**：一个项目的选址，让 AI 并行出"规划/市场/风险"三视角简报。

## 建筑/房地产 AI 的四条铁律
1. **专业标准是硬约束**——RICS（估值）/ Building Safety Act（安全记录）/ ISO 19650（BIM 信息管理）必须符合。
2. **数据基础设施先行**——BIM/组合/文档数据先打通（Norvik：生命周期数据基础设施）。
3. **AI 不替代建筑师/估值师判断**——RIBA：AI 改变工作方式但创造力/专业责任不可替代；AI 是"决策基础设施"非"工具"。
4. **安全第一**——工地安全监控（场景 98）是 2026 最突出进展，从被动响应到主动预防。

> **建筑/房地产的心法**：AI 把建筑业从"碎片化手工流程"推向"**数据驱动的决策基础设施**"——从设计探索、工地监控、质量比对到估值尽调全链条。Build.inc 的 neofirm 模式（agentic AI 做大部分+专家验证）是这行业的新范式。
