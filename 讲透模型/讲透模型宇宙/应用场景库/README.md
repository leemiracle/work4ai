## 卡片格式（每张统一）

```
### 场景 N：标题
- 痛点：一句话
- 输入 → 输出：具体格式
- 模型方案：API / RAG / 微调 / Agent + 决策理由（呼应 Ch18）
- 真实案例：公司 + 数字 + 来源（2026）
- 工具栈：具体模型/框架
- 陷阱：常见坑
- 起步 MVP：今天就能做的最小验证
```

## 怎么用本库（三步）

1. **带着痛点找卡片**：你的工作里有什么"重复/慢/要专家"的事？在场景地图找对应卡片。
2. **照决策链选方法**：读卡片的"模型方案"，对照 Ch18 的决策树，确认 API/RAG/微调/Agent 哪个合适。
3. **跑 MVP**：照卡片的"起步 MVP"，今天做一个最小验证（通常是 API + prompt，1 小时）。

## 行业基准（2026 一手，来自 KXN/AliceLabs/Deloitte 调研）

- **生产部署率**：67% 企业 agentic AI 已上生产（2024 仅 31%）；金融 74% 最高。
- **中位首年净省**：$2.4M；3+ agent 工作流 >$4M；62% 企业 12 个月回本。
- **按用例年省**：文档处理 $1.1M ＞ 客服 $890K ＞ 合规 $780K ＞ 供应链 $650K。
- **成本降幅**：财务/HR 流程 20-30%（McKinsey）；客服单次成本 -25%、CSAT +20%。
- **治理**：78% 企业要求 Tier2+ 决策 human-in-the-loop；ISO 42001 认证率 31%+47% 在路上。
- **最大障碍**：遗留系统集成（61%）、数据质量与治理。

> **关键洞见**：2026 年的赢家不是"用最新模型"的，而是"**选对场景 + 治理到位 + 数据干净**"的。模型能力已不是瓶颈，集成/数据/治理才是。
