# 10 · 制造 / 供应链场景

> 制造/供应链是"实物 + 数据"领域。AI 在视觉质检、需求预测、出货优化上 ROI 显著但需成熟数据基础。本类 5 个场景。**注意**：供应链 ROI 慢（依赖数据基础设施），先评估成熟度再上。

---

### 场景 44：视觉质检
- **痛点**：人工质检慢、疲劳漏检；缺陷多样。
- **输入 → 输出**：产品图像 → 缺陷类型/位置/严重度。
- **模型方案**：**CV 模型（检测/分割）**；少样本缺陷 → 小样本学习 + 合成数据。
- **真实案例**：制造 AI 质检已成标配（2026）；关键是缺陷样本少时的数据增强。
- **工具栈**：YOLO/检测模型 + 边缘部署（`讲透端侧AI压缩`）；合成数据 → Diffusion 生成缺陷。
- **陷阱**：罕见缺陷漏检 → 合成数据 + 人工复核；光照/角度变化 → 数据多样化。
- **起步 MVP**：100 张缺陷图，训检测模型，测漏检率。

### 场景 45：需求预测
- **痛点**：预测不准导致库存积压/缺货。
- **输入 → 输出**：历史销量/促销/外部信号 → 需求预测。
- **模型方案**：**时序模型 + LLM 解释**（融合新闻/天气等文本信号）。
- **真实案例**：AliceLabs 列需求预测为供应链标准用例（2026）；需 90-180 天上生产。
- **工具栈**：Prophet/Temporal Fusion Transformer；外部信号 → LLM 抽取。
- **陷阱**：数据质量是前提（断档/口径不一）；新 SKU 冷启动 → 相似品迁移。
- **起步 MVP**：一个品类历史销量，训时序模型，对比当前预测方法误差。

### 场景 46：设备预测性维护
- **痛点**：设备故障停机损失大；定期维护浪费。
- **输入 → 输出**：传感器时序 → 故障预警 / 维护建议。
- **模型方案**：**异常检测 + 剩余寿命预测**。
- **真实案例**：供应链 agent 标准用例（aihive，2026）。
- **工具栈**：时序异常检测 + IIoT 平台。
- **陷阱**：误报多伤信任 → 阈值调优 + 置信度；罕见故障样本少。
- **起步 MVP**：一台关键设备传感器数据，训异常检测，回测历史故障能否提前预警。

### 场景 47：出货优化 / 物流决策
- **痛点**：每日海量出货决策（路线/承运/分仓），人工难全局最优。
- **输入 → 输出**：订单/库存/运力 → 出货方案 + 成本预测。
- **模型方案**：**优化求解器 + AI 启发式 + LLM 解释**。
- **真实案例**：**General Mills** —— AI 每日评估 **5000+** 出货（厂→仓），自 FY2024 累计省 **$20M**（运输成本 + 客服水平），来自公开财报披露（aihive，2026）。供应链异常处理中位年省 **$650K**（KXN，2026）。
- **工具栈**：运筹求解器 + ML 预测 + LLM 决策解释。
- **陷阱**：约束建模不全 → 与运营专家共建约束；模型建议不被信 → LLM 解释 + 人工可覆盖。
- **起步 MVP**：一条物流线，对比 AI 建议与人工决策的成本差异。

### 场景 48：供应商管理 / 风险监控
- **痛点**：供应商多、风险信号散；评估耗时。
- **输入 → 输出**：供应商信息 → 风险评分 / 续约建议 / 异常告警。
- **模型方案**：**多源聚合 + LLM 评估**（新闻/财报/制裁）。
- **真实案例**：**Rivian** 含供应商 onboarding 自动化（AWS，2026）；IBM Enterprise Advantage 列采购自动化为标准用例（2026）。
- **工具栈**：Agent + 数据源 API + LLM 评分；`buyer-list`/`dd-checklist` skill 的 AI 化。
- **陷阱**：风险漏报 → 多源交叉；数据时效 → 实时监控。
- **起步 MVP**：top 10 供应商，用 LLM + 搜索聚合"财务/舆情/制裁"风险评分。

## 🔧 深度实操要点（本类场景）

> 本类场景的实操指引。通用骨架代码/评估清单/排错指南见 [00 深度实操手册总纲](00-深度实操手册总纲.md)。

- **决策速查**：质检→CV模型；需求预测→时序ML；出货优化→运筹+AI；预测维护→IoT+ML
- **关键骨架**：骨架 C (预测ML) + 运筹求解器
- **评估要点**：成本节省(General Mills $20M)；漏检率；预测误差
- **头号陷阱**：数据基础设施是前提(KXN:遗留系统61%最大障碍)；玩具看不出量化损失→真实大模型测
- **进阶路径**：单点预测→出货优化→全链协同

---

**本类共性建议**：制造/供应链 **数据基础设施是前提**（KXN：遗留系统集成是 61% 企业最大障碍）。**先评估数据成熟度再上 AI**。**从场景 47 出货优化起步**——General Mills 证明 ROI 巨大（$20M）且可量化。视觉质检（44）需边缘部署能力（`讲透端侧AI压缩`）。
