# 09 · 医疗 / 健康场景

> 医疗是"高风险 + 高文档量"领域。AI 不替代医生诊断，但能把医生从文档解放、提升照护质量。本类 4 个场景。**铁律**：临床决策必须医生复核（McLeod：Tier 4 全自主永不批）。

---

### 场景 40：病历结构化 / 摘要
- **痛点**：病历海量非结构化；提取临床信息耗时。
- **输入 → 输出**：病历文本/扫描件 → 结构化诊断码/用药/检验/就诊记录。
- **模型方案**：**OCR + LLM 抽取 + 临床规则校验**。
- **真实案例**：**Aetna** AI Medical Chart Review —— HEDIS 年审超 **1000 万** 份病历，人工审阅减少 **65%**，处理 **1400 万** 文档，6 个月从想法到 PoC 处理百万记录（CIO，2026）。行业基准：大型支付方年审需 ~5 万工周。
- **工具栈**：OCR + LLM + FHIR/ICD 结构化；Bedrock/Vertex。
- **陷阱**：诊断码错 → 临床校验；隐私 HIPAA → 私有/合规云。
- **起步 MVP**：100 份病历脱敏，LLM 抽"诊断+用药"，对比人工。

### 场景 41：辅助诊断 / 医学影像
- **痛点**：影像判读耗时；漏诊风险。
- **输入 → 输出**：影像/检验 → 异常标记 / 风险评分（辅助医生，非替代）。
- **模型方案**：**专业医学影像模型 + LLM 报告**。需 FDA/CE 认证（医疗器械）。
- **真实案例**：医学影像 AI 已获批临床；**Johns Hopkins** 等 agent 模式：agent 标风险、医生定夺（aihive，2026）。
- **工具栈**：医学影像模型（GE/Philips）+ LLM 报告；必须临床验证 + 监管批准。
- **陷阱**：**监管**（医疗器械认证）；**偏见**（训练数据人群偏）；必须医生复核。
- **起步 MVP**：非临床——用影像模型做研究性病灶检出，不用于诊断。

### 场景 42：ambient AI 临床记录
- **痛点**：医生花大量时间写病历（认知倦怠、"睡衣时间"）。
- **输入 → 输出**：就诊对话 → 结构化病历 SOAP note。
- **模型方案**：**ASR + LLM 生成 SOAP**（集成 EHR）。
- **真实案例**：**McLeod Health**（Suki）—— 每医生净省 **$2,600/月**，患者满意度 **+6%**，30 人试点 3 月后扩全院；按使用量计费是关键（避免license空转）（HCI，2026）。
- **工具栈**：Suki / Nuance DAX / Abridge；集成 Epic/EHR。
- **陷阱**：专科术语 → 专科微调；note bloat → 精炼 prompt；EHR 集成是瓶颈。
- **起步 MVP**：调研 Suki/DAX 试用，选 5 名高文档负担医生试点。

### 场景 43：患者沟通 / 随访
- **痛点**：患教/随访量大；依从性跟踪难。
- **输入 → 输出**：患者问题/状态 → 通俗解答 / 随访提醒 / 风险标记。
- **模型方案**：**RAG（患教库）+ Agent（随访/告警）**。
- **真实案例**：Aetna 用 AI 优先排序"照护缺口可闭合"的记录转人工（CIO，2026）。
- **工具栈**：RAG + 患教内容 + 随访自动化；多语言。
- **陷阱**：误诊风险 → 不给诊断建议，只引导就医；隐私 → 合规通道。
- **起步 MVP**：常见病 FAQ 做 RAG，患者问"药副作用"秒答（附"咨询医生"）。

## 🔧 深度实操要点（本类场景）

> 本类场景的实操指引。通用骨架代码/评估清单/排错指南见 [00 深度实操手册总纲](00-深度实操手册总纲.md)。

- **决策速查**：病历结构化→OCR+LLM抽取(A)；ambient记录→ASR+SOAP；诊断→专用模型+人审
- **关键骨架**：骨架 A (OCR+抽取) + 专用医学模型
- **评估要点**：人工降幅(Aetna -65%)；每医省时(McLeod $2600/月)；患者满意度
- **头号陷阱**：监管(FDA/CE认证)；隐私(HIPAA)；临床决策必须医生复核(McLeod:Tier4永不批)
- **进阶路径**：文档类(低风险)→ambient→辅助诊断(需认证)

---

**本类共性建议**：医疗 **监管 + 隐私 + 人命** 三重红线。**从文档类（场景 40/42）起步**——风险低、ROI 快（Aetna -65% 人工、McLeod 省时）。诊断类（41）必须监管认证 + 医生复核。**治理分级**（McLeod 四级 Tier）：临床影响的必须 human-in-the-loop，全自主永不批。McLeod 的教训："别只给效率高的医生用——真正需要的是效率低的那位"。
