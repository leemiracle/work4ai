## 一、为什么"RL + 形式化证明"是独特赛道

### 1.1 形式化证明给了 RL 一个"完美奖励"

RL 的核心难题是**奖励设计**（reward design）：游戏有分数、对话没标准答案。但**形式化证明**（Lean4 / Coq / Isabelle）天然给了一个**二元、自动、零主观**的奖励：

$$
r(\text{proof}) = \begin{cases} 1 & \text{证明被 Lean4 内核接受} \\ 0 & \text{否则} \end{cases}
$$

> 🎯 **一句话**：形式化证明是 RL 的"**圣杯奖励**"——自动、客观、无噪声。这正是为什么 2024-2026 所有 RL 前沿都涌向这里。

### 1.2 和"RL 对齐 LLM"的本质区别

| 维度 | RL 对齐（RLHF/DPO/GRPO，[03 篇](./03-RLHF-DPO-GRPO.md)）| RL 形式化证明（AlphaProof 谱系）|
|------|-------------------------------------------|----------------------------|
| 奖励来源 | 奖励模型 / 人类偏好 | **Lean4 内核**（机器检查）|
| 奖励性质 | 连续、有偏、可被 hack | **二元、客观、不可 hack** |
| 动作空间 | 整个词表 $V^T$ | Lean4 tactic 序列（结构化）|
| 验证成本 | RM 一次前向 | Lean 编译（秒级）|
| 可信度 | RM 错就全错 | **证明成立 = 数学真理** |

形式化域的奖励是**数学真理**，不是模型猜测——这是 RL 在这里比在对话域更"干净"的原因。

### 1.3 为什么 2024-2026 突然爆发

三件事让"RL 证定理"从学术玩具变成顶会主流：
1. **Lean4 生态成熟**（mathlib 百万定理 + LeanDojo 工具链）
2. **DeepSeek-R1 的 GRPO**（[03 篇](./03-RLHF-DPO-GRPO.md)）证明 RL 能训 reasoning
3. **AlphaProof（Nature 2025）** 拿 IMO 2024 银牌——RL 第一次在世界级数学竞赛立足

## 二、AlphaProof：范式确立者（Nature 2025-11）

### 2.1 核心配方

AlphaProof（DeepMind，Nature doi:10.1038/s41586-025-09833-y ✅）的闭环像 AlphaGo：

```
自然语言题目（IMO/Putnam）
    ↓ autoformalization（NL → Lean4）   ← LLM 把英文题翻译成 Lean4
        生成 80× 变体（每题）
    ↓ MCTS + RL（AlphaZero 式）           ← 在 Lean4 tactic 空间搜索
        二元奖励：Lean 接受 = 赢
    ↓ TTRL（Test-Time RL）                ← 推理时对难题生成变体再训练
    ↓ 证明
```

**三个关键创新**：
- **Autoformalization**：把 100 万道自然语言数学题自动翻译成 Lean4，生成 ~8000 万形式化问题（这是数据规模的根基）
- **MCTS + 在线 RL**：AlphaZero 式自我博弈，在 tactic 空间搜索
- **TTRL（Test-Time RL）**：推理时对解不出的难题生成变体，再聚焦训练——P1/P2/P6 各烧 2-3 TPU-days

### 2.2 战绩与代价

| 指标 | 结果 |
|------|------|
| IMO 2024 | **银牌（28/42）**，解 P1/P2/P6（最难的三题，全球仅 5 人满分）|
| 组合题 P3/P5 | **未解**（组合是 RL 的盲区，[§五](#五rl-在形式化域的失败模式) 详述）|
| 单题算力 | 2-3 TPU-days |
| 开源 | ❌ 闭源，无后续论文 |

### 2.3 AlphaProof 的真正贡献

不是"RL 能证 IMO 题"（这是结果），而是**确立了范式**：
- autoformalization → RL/MCTS → Lean 奖励 的闭环**可行**
- TTRL 是"推理时算力换性能"的新维度
- 但**组合域是硬墙**——暴露了 RL 的结构盲区

## 三、开源三强：逼近闭源的配方

闭源 AlphaProof 后，三个开源 prover 在 2025 把 miniF2F（形式化数学基准）刷到饱和：

| 模型 | arXiv | miniF2F-test | 核心配方 |
|------|-------|-------------|---------|
| **DeepSeek-Prover V2-671B** | 2504.21801 ✅ | 88.9% | GRPO + 子目标分解冷启动 |
| **Goedel-Prover V2-32B** | 2508.03613 ✅（ICLR 2026）| 90.4% | scaffolded 合成数据 + verifier-guided self-correction |
| **Seed-Prover**（字节）| 2507.23726 ✅ | **99.6%**（饱和）| VAPO + 三档 test-time（heavy=5000 猜想池）|

> 📌 **关键洞察**：这三强的本质都是 **expert iteration + 轻量 GRPO**，**不是** AlphaProof 式在线 MCTS。开源路线用"数据合成 + 离线迭代"替代了"在线 MCTS + TTRL"——更省算力，但探索性弱。

### 3.1 Seed-Prover 的猜想池（最接近"规则生成"的模板）

Seed-Prover 的 **heavy 模式**是规则自动生成的最直接模板：

```
批量生成 5000 个 conjecture（候选引理）
    ↓ 闭环：Lean4 逐一 prove/disprove
证成的 → 进入 lemma pool（增强后续证明）
证否的 → 作为反例反馈
```

这种"猜想 → 验证"的 self-play 是后续 [讲透神经符号](../讲透神经符号/) 的核心模式。

### 3.2 IMO 2025 现场战绩

- **Seed-Prover**：现场 4/6，赛后 5/6 ⭐
- **AlphaProof 2**（二手博客，未 arXiv 核实 ⚠️）：声称 5/6

开源已经追上甚至在某些维度超过闭源。

## 四、In-Context / Agent 路线：不训练也能证

不用 RL 微调，纯靠**通用大模型 + 工具调用**也能证定理——2025 这条路线崛起：

| 系统 | arXiv | 配方 | miniF2F |
|------|-------|------|---------|
| **COPRA** | 2310.04353 ✅ | GPT-4 + 回溯搜索 + 失败字典（穷人版 AlphaProof）| 超 ReProver |
| **LeanDojo-v2** | NeurIPS 2025 | 统一框架，集成 GRPOTrainer + Pantograph REPL，可调 DeepSeek-Prover-V2-671B | — |
| **Delta-Prover**（字节）| 2507.15225 ✅ | 通用 LLM + 自建 Lean4 DSL，**零微调** | **95.9%**（pass@16384）|

> 🎯 **反直觉发现**：Delta-Prover（通用 LLM + agentic 结构）在 miniF2F 上**超越所有需专模的方法**。证明"通用大模型 + 紧闭环 + DSL"比"专用小模型 + 微调"在形式化域有巨大未开发潜力。

这与 [05 篇](./05-RLVR的极限.md) 的结论呼应：**RL 微调的增益可能被高估了**。

## 五、RL 在形式化域的失败模式

光看战绩会以为 RL 是万能的，但有三个结构性失败模式：

### 5.1 稀疏 reward 的长程信用分配

二元 reward（证成=1/证否=0）是**全有或全无**。一个 100 步的证明，第 1 步走错，要到第 100 步才知道——这是 RL 的经典 credit assignment 难题，在形式化域更严重（证明轨迹非线性）。

**缓解**：过程奖励（Process-Verified RL，arXiv:2606.20068 ✅）用 Lean 作 symbolic oracle 做 first-error propagation——但仍属研究阶段。

### 5.2 🚨 基准自验证神话破灭（最致命）

三个独立审计（2025-2026）证明 **"Lean4 自验证" ≠ "规则正确"**：

| 审计 | arXiv | 致命发现 |
|------|-------|---------|
| **atp-checkers** | 2606.29493 ✅ | 5 个 Lean 基准共 **398 个机械可证缺陷**；Lean <4.20.0 的 `apply?` bug 让合成 sorry 绕过内核；**DeepSeek-Prover-V2 的 3 个"证明"实为假证明** |
| **miniF2F-v2** | 2511.03108 ✅（NeurIPS 2025）| 修正 300+ 语句，16 个根本不可证；端到端真实精度仅 **36%**（非头条的 90%+）；autoformalization 实测精度 66%（文献报 97%）|
| **ProofGate** | ICML 2026 | Goedel-Prover-V2"发布的证明"是 `:= by sorry` 占位符，不可复现 |

> 🟥 **铁律**：**RL prover 会找到并利用任何能提升 reward 的验证漏洞**（atp-checkers 原文）。二元 Lean reward 只判"证明是否被接受"，不判"规则是否建模真实语义"。**生成 ≠ 判别**。

### 5.3 FormalRewardBench：专门 prover 评估最差

FormalRewardBench（arXiv:2605.10141 ✅）专门测"模型判断证明质量"的能力：

| 模型类型 | 证明质量判别准确率 |
|---------|------------------|
| 专门 prover（DeepSeek-Prover 等）| **24.4%**（最差！）|
| Frontier LLM（GPT-4 等）| 59.8%（最好）|

**反直觉**：能生成证明的模型，反而**最不会判断证明好坏**——因为 RL 把它训练成"生成机器"而非"判别机器"。这是 [05 篇](./05-RLVR的极限.md) "分布锐化"的另一面。

### 5.4 组合盲区

AlphaProof IMO 2024 解了 P1/P2/P6（代数/数论），但**组合题 P3/P5 未解**。组合数学需要**构造性思路**（构造例子 / 反例），而 RL 在"生成式搜索"上强，在"构造性洞察"上弱。系统软件域（OS/编译器）大量是组合问题——这是 RL 在系统域会更难的根因之一。

## 六、能力边界：RL 是"锐化器"还是"发现器"？

这是 2025-2026 最核心的争议，详见 [05 篇](./05-RLVR的极限.md) 的完整论证。这里给结论：

| 问题 | 答案 | 证据 |
|------|------|------|
| RLVR 提高了 pass@1 吗？ | ✅ 是 | 所有 benchmark 都升 |
| RLVR 扩展了推理边界（pass@k 大 k）吗？ | 🟥 **没有** | base 在 k=256/1024 反超 RLVR model |
| RLVR 教会模型 base 采不到的新路径吗？ | 🟥 **没有** | AIME24 上 RLVR 能解而 base 不能的问题 = **0.0%** |
| 蒸馏能扩展边界吗？ | ✅ 能 | DeepSeek-R1-Distill pass@k 一致高于 base |

> 🎯 **收敛结论**：RLVR 是**激活器/锐化器**，不是**发现器/创造器**。它把 base 已有的正确路径的概率调高，代价是覆盖率收缩。**真正引入新推理模式的是蒸馏，不是 RL**。

这个结论对"系统域 RL"尤其致命——见 [06 篇](./06-RL与系统软件.md)。

## 七、选型建议

如果你要做"RL + 形式化"项目，怎么选？

| 场景 | 推荐 | 理由 |
|------|------|------|
| 想刷 miniF2F 分 | Seed-Prover heavy / Delta-Prover | 已饱和 99.6% / 95.9% |
| 想做规则/猜想生成 | Seed-Prover heavy 模式（猜想池）| 唯一"生成新规则"的成熟模板 |
| 系统域（OS/编译器规则）| **不要微调数学 prover** | 系统域形式数据极稀缺（LEAN-GitHub 仅 0.13B tokens），微调过拟合 |
| 通用、低算力 | Delta-Prover / COPRA（Agent 路线）| 零微调，通用大模型 + DSL |
| 想要 ground truth | Lean4 内核 + 独立 checker | 防范 [§5.2](#57-基准自验证神话破灭最致命) 的基准漏洞 |

**六条引入 RL 的铁律**（从生产经验提炼，[06 篇](./06-RL与系统软件.md) 详述）：
1. 约束学习问题（动作空间极窄）
2. 训练与服务分离
3. 为失败设计（硬 timeout + 回退）
4. 尊重操作现实（产出可审计）
5. 有可程序化 evaluator
6. 只重排已合法的选项，不覆盖 correctness

**只要违反任一条，就不要用 RL。**

## 八、一句话总结

> 🎯 **三句话**：
> 1. **AlphaProof 确立范式**：autoformalization → MCTS/RL → Lean 二元奖励 → TTRL，IMO 2024 银牌；开源三强（DeepSeek-Prover V2 / Goedel V2 / Seed-Prover）逼近饱和，但本质是 expert iteration + 轻量 GRPO。
> 2. **In-Context 路线崛起**：Delta-Prover 通用 LLM + DSL 零微调达 95.9%，超越专模——"通用大模型 + 紧闭环"可能比"专用小模型 + 微调"更适配。
> 3. **RL 是锐化器不是发现器**：基准自验证神话破灭（atp-checkers 398 缺陷 / DeepSeek 假证明），专门 prover 判别能力反而最差（24.4%）——形式化域的 RL 增益被高估。
