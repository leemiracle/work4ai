# 📐 第 2 幕 · 数学：对齐的形式化

## 1. InfoNCE：对比对齐的核心 loss

CLIP / SigLIP / 任何双塔对齐都用 InfoNCE 变体。给定 batch 内 $N$ 个正对 $(x_i^v, x_i^t)$（图-文）：

$$\mathcal{L}_{\text{InfoNCE}} = -\frac{1}{N}\sum_{i=1}^N \log \frac{\exp(\text{sim}(z_i^v, z_i^t)/\tau)}{\sum_{j=1}^N \exp(\text{sim}(z_i^v, z_j^t)/\tau)}$$

$z_i^v = f_v(x_i^v)$, $z_i^t = f_t(x_i^t)$ 是模态编码器输出，$\tau$ 是温度。

**信息论解读**：最大化正对的互信息下界。InfoNCE 的对数底数等价于**负样本数 +1 的对数**——负样本越多，互信息下界越紧。

## 2. Cross-Attention：融合模态

Flamingo/BLIP 把图像特征作 K/V 注入 LLM：

$$\text{CrossAttn}(Q, K_v, V_v) = \text{softmax}\left(\frac{Q K_v^T}{\sqrt{d}}\right) V_v$$

$Q$ 来自文本 token，$K_v, V_v$ 来自图像 token。**文本决定「看图的哪里」**。

**vs 双塔**：双塔对齐是静态（编码后算 cosine），cross-attention 是动态（每个文本 token 重新决定关注哪部分图）。后者更强但更贵。

## 3. Vision Tokenizer：VQ-VAE

把连续图像变成离散 token（Chameleon 的基石）。VQ-VAE：

```
1. encoder: x → z_e (连续)
2. 量化: z_q = z_e 最近邻查表 (codebook)
3. decoder: z_q → x_hat
4. loss = ||x - x_hat||² + ||sg[z_e] - z_q||² + β||z_e - sg[z_q]||²
```

$sg$ 是 stop-gradient。**codebook 是学到的「视觉词表」**——图像变成 token 序列后，可以和文本 token 一样进 Transformer。

**关键参数**：codebook 大小（如 8192）决定视觉词的丰富度。太小丢细节，太大难学。

## 4. Modality Gap：几何的真相

Liang 2022 发现：CLIP 训练后，图像和文本嵌入**仍分两个簇**，中间有空带。

**原因**：不同模态的**初始化 + 梯度方向**不同，让两个嵌入空间有系统性偏移。即便 loss 拉近正对，整体仍各自成簇。

**形式化**：设图像中心 $\mu_v$，文本中心 $\mu_t$。modality gap $= \|\mu_v - \mu_t\|$。训练后这不为零。

**后果**：
- 零样本分类时，决策边界可能落在 gap 里，性能不稳
- 用「图找文」和「文找图」结果不对称（gap 方向性）

**缓解**：训练时显式对齐中心，或用 early-fusion（Chameleon）彻底绕过双塔。

## 5. LLaVA 投影层：最简融合

LLaVA 把视觉特征 $\mathbf{H}_v$ 用一个 MLP 投影：

$$\mathbf{H}_v' = W_2 \cdot \text{GELU}(W_1 \cdot \mathbf{H}_v)$$

然后把 $\mathbf{H}_v'$ 当视觉 token，和文本 token 拼接送进 LLM。

**这就是 LLaVA 的全部「多模态融合」**——一个两层 MLP。**简单到让人怀疑**，但有效：复用了 LLM 的全部推理能力。

**为什么有效**：CLIP 视觉编码器已经把图像压成「语义向量」，投影层只做维度对齐。重活在编码器和 LLM 那里。

## 6. Early-Fusion：Chameleon 的 token 统一

Chameleon 把图和文都变成同一词表的 token 序列：

$$\text{sequence} = [t_1, t_2, v_1, v_2, v_3, t_3, ...]$$

$t$ 是文本 token，$v$ 是视觉 token（来自 VQ-VAE）。**一个 Transformer 处理一切**，无模态分支。

**loss 就是标准 next-token**：
$$\mathcal{L} = -\sum_i \log P(x_i \mid x_{<i})$$

**为什么难**：
- 视觉 token 和文本 token 的**信息密度差异大**（一张图几百 token，一句话几十）
- loss 权重要精细平衡，否则一种模态主导训练
- 数据配比敏感

**收益**：真正统一的表示，模态间无缝交织——这是 GPT-4o 原生多模态的方向。

## 7. 对齐的统一视角

| 方法 | 机制 | 对齐空间 | 谁主导 |
|---|---|---|---|
| CLIP | 双塔对比 | 共享嵌入空间 | 无（对等）|
| Flamingo | cross-attn | LLM 注意力 | 文本 |
| LLaVA | 投影层 | LLM token 空间 | LLM |
| Chameleon | early-fusion | 统一 token 词表 | 无（真统一）|

**方向**：从「两个空间对齐」到「一个统一空间」。**核心熵减越来越彻底**——把多模态收敛到一种表示。

## 🎬 本幕收束

> 多模态数学 = InfoNCE（对比对齐）+ cross-attention（动态融合）+ VQ-VAE（视觉 tokenizer）+ modality gap（几何真相）+ early-fusion（统一 token）。核心张力：**双塔对齐有 gap，early-fusion 难训**。世界级多模态 = 找到既能统一又不难训的中间路线。
