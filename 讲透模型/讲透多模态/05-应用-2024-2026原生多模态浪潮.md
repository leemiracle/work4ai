# 🚀 第 5 幕 · 应用：2024-2026 原生多模态浪潮

## 浪潮地图

| 系统 | 路线 | 突破 |
|---|---|---|
| **GPT-4o** (OpenAI 2024) | 原生多模态，端到端 | 实时语音+视觉，延迟 ~300ms |
| **Chameleon** (Meta 2024) | early-fusion token 化 | 图文混合 token，一个模型 |
| **Qwen2-VL** (Alibaba 2024-2025) | 任意分辨率 + 动态 token | 解决 VLM 分辨率折中 |
| **Gemini 2.5** (Google 2025) | 原生多模态 + 长上下文 | 统一图/视频/音频/文 |
| **Sora 2 / Veo 3** (2025) | 视频+音频生成 | 文生视频工业化 |
| **3D 多模态** (GS+LLM) | 3D 场景理解 | 空间智能兴起 |
| **SEED-X / Any-to-Any** | 任意模态互译 | 朝统一模型走 |

## 四代演化的工业实践

| 代 | 代表 | 何时用 |
|---|---|---|
| 双塔对比 (CLIP) | CLIP/SigLIP 2 | 检索/零样本分类 |
| 融合+跨注意力 | Flamingo | 图像问答（已少用）|
| 投影+LLM (LLaVA) | LLaVA/Qwen2-VL | 快速搭 VLM |
| 原生 (GPT-4o/Chameleon) | GPT-4o/Gemini 2.5 | 实时/统一交互 |

## 应用场景选型

| 场景 | 推荐 |
|---|---|
| 图文检索 | CLIP/SigLIP 2 + 向量库 |
| 图像问答/VQA | Qwen2-VL / GPT-4V / Claude vision |
| 文生图 | Stable Diffusion 3 / DALL-E 3 |
| 文生视频 | Sora 2 / Veo 3 |
| 实时多模态交互 | GPT-4o（贵）/ Gemini 2.5 |
| 3D 理解 | NeRF/GS + LLM |
| 自建 VLM | LLaVA 范式（视觉编码器 + 投影 + 开源 LLM）|

## 五条经验法则

1. **能用现成 VLM 就别自建**（GPT-4V/Claude/Qwen2-VL 够强）。
2. **自建用 LLaVA 范式**（视觉编码器 + MLP 投影 + 开源 LLM）。
3. **分辨率敏感任务用 Qwen2-VL**（任意分辨率）。
4. **防幻觉用 grounding**（让模型标出在哪）。
5. **组合性任务用结构化 prompt + ControlNet**。

## 与已有资产

- **`讲透CV/`**：视觉感知本身
- **`讲透上下文缓存/`**：多模态 token 多，缓存更关键
- **`讲透世界模型/`**：视频生成模型是不是世界模型

## 前沿方向（2025-2026）

- **原生多模态普及**（GPT-4o/Gemini 路线下沉）
- **Any-to-Any**（任意模态互译，SEED-X）
- **3D 空间智能**（World Labs / Fei-Fei Li）
- **实时低延迟**（端侧小模型）
- **具身多模态**（VLA，机器人）

## 🎬 五幕收束

> 多模态的本质 = **给不同模态找共同语义语言**。CLIP 词典对照 → LLaVA 翻译机 → Chameleon 世界语。**越统一 = 核心熵减越彻底 = 边缘能组合的跨模态故事越多**。
>
> 维特根斯坦最终回响：**AI 能统一多少模态，它的世界就有多大**。modality gap 提醒我们统一不是免费午餐——但方向不可逆：**多模态正在从「拼接」走向「原生统一」**。
