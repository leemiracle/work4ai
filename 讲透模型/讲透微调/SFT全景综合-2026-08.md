## §0 要点速览（十条）

1. **SFT = 你选的数据上的 next-token 预测**——没有新目标函数，没有负例；它只能提高"你给它看的回答"的概率，**教不了"什么不该做"**（那是偏好调优的事）。
2. **模型学的是目标分布的全部特征，包括你没打算教的**：所有回答 80-120 词 = 训出长度约束；全不复述题目 = 训掉开场白；从不拒绝 = 训掉拒绝。训练前抽 50 条 target 问"它们有什么共同点"。
3. **质量 > 数量有新补丁**：LIMA/AlpaGasus（1000 条精写 > 5 万条平庸）之外，2026 年 "Data Repetition Beats Scaling" 证明**400 条推理样本训满 128 epochs 打败 51,200 条过一遍**（AIME/GPQA +12-26pp）——小而精 + 充分优化，两个维度都成立。
4. **数据配比看 token 不看样本**：5% 的通用数据按样本数计，若序列很长可占 80%+ 梯度信号。混合的首要目的是**保通用能力**，常以领域指标为直接代价；但存在正迁移（Qwen2.5-Coder 70:20:10 代码:文本:数学 > 100% 代码）。
5. **超参默认值有机械理由**：全参 lr 1e-5~2e-5、LoRA 1e-4~2e-4（B=0 初始化×α/r 瓶颈需要大步）；**r 与 lr 不独立**——固定 α 加倍 r = 有效 lr 减半。调参优先级：数据 > 加不同数据 > epochs > target modules > rank > lr。
6. **LoRA ≈ Full FT 是幻觉**（谱分析）：LoRA 引入预训练谱中不存在的"入侵维度"（intruder dimensions）。单任务下 LoRA 遗忘更少；**持续学习下入侵维度累积，LoRA 反而比 Full FT 遗忘更多**。事后调低入侵维度奇异值：遗忘 -33%，任务精度几乎不掉。
7. **"SFT 记忆、RL 泛化"需要修正为条件命题**（2026-04 复盘）：短训练 checkpoint 会**低估**泛化（先降后升的 dip-and-recovery）；verified long-CoT 数据才产生跨域迁移；强模型能内化 backtracking 等程序性模式、弱模型只模仿表面冗长；且迁移不对称——**推理涨、安全跌**。
8. **机制级分工（ICLR 2026）**：SFT 扩张"正确轨迹"的多样性但**保留错误轨迹**（Pass@k↑、Pass@1 无保证）；RL 压缩错误轨迹也压缩正确轨迹（大 k 时 base 反超 RL）。**SFT+RL = 先扩后压**，这就是两阶段配方的机制解释。
9. **长 CoT SFT 决定 RL 的天花板**：从短 CoT SFT 出发做 RL 几乎无增益；从长 CoT SFT 出发 RL 可显著提升（MATH-500 +3%+，OOD +20%）。蒸馏"涌现的长模式"远胜人工构造的模式（OOD +15-50%）。
10. **Agent SFT 是 2026 最活跃前线，核心病是"接口捷径"**：trajectory-SFT 可能只学了工具调用的表面格式而非语义（换接口名就崩）。解法簇：PIPE 式换接口评估、DAG 修剪冗余轮次、PACT 特权轨迹协同训练、ACC 轨迹编译成长上下文 QA。

## §1 SFT 的本质与能力边界

### 1.1 数学：带掩码的条件交叉熵

$$\mathcal{L}(\theta) = -\sum_{t \in \text{assistant tokens}} \log \pi_\theta(y_t \mid y_{<t}, x)$$

与预训练唯一的区别：①数据是你选的；②prompt/user token 被 mask（`-100`，与 CrossEntropyLoss 的 ignore_index 对齐——忘了这条约定 SFT 就退化成普通 LM 训练，见 `讲透Agent/torchrl 深读` 的坑 1）。

### 1.2 三条从目标函数直接推出的边界（Multigrid 实操指南，2026-08）

| 推论 | 实践含义 |
|---|---|
| 无负例 | 想让模型偏好 A 弃 B → 偏好调优（DPO/RLHF），不是 SFT |
| 目标是"模仿这个" | 数据里任何不一致都是梯度里的自相矛盾，两个矛盾示范平均 = 两边都学不好 |
| 学目标的分布（含非预期特征） | 长度/格式/开头套话/拒绝行为都会被隐性训练——**检查数据集规格之外的一致性** |

### 1.3 本地已有的定位表述（复述挂链）

- SFT ≈ 模仿学习（小孩模仿大人），学"**行为**"不学"判断"（[`FineTuning工程手册`](../../工程化手册库/FineTuning工程手册/README.md)）
- SFT 是 γ=0 的短视 RL（[`视角库/强化学习.md`](../../视角库/强化学习.md)）
- 预训练给了语言能力，SFT 只教"怎么对话/遵循指令"（[`讲透LLM/04-训练数据全景`](../讲透LLM/04-训练数据全景.md)）

## §2 数据工程：质量 > 数量的完整图谱

### 2.1 经典三支柱（本地已讲透，[`04-微调数据工程`](./04-微调数据工程.md)）

- **LIMA**（2023-05）：1000 条人工精写 ≈ GPT-4 级对齐效果
- **AlpaGasus**（2023-07）：GPT-4 打分留 top 9k/52k，**砍 80% 反而更强**
- **Self-Instruct / Evol-Instruct**：合成数据主流管线；风险 = 偏见继承 + model collapse

### 2.2 2026 新证据一：重复训练打败扩数据（Data Repetition Beats Scaling）

固定算力下，400 条推理样本训到 128 epochs（训练精度接近满分），比 51,200 条各过一遍在 AIME/GPQA **高 12-26pp**。SFT 不服从预训练式幂律——**覆盖度与深度的乘积才是标度量**，训练 token 精度可作为实用停止准则（收敛到近满分后增益平台化）。

> 与 LIMA 合读：**"少而精"解决数据质量轴，"充分优化"解决训练强度轴**——两个轴都做对，1k 级数据就能顶 50k 级。

### 2.3 2026 新证据二：数据合成的高价值模式——synthetic input + real output

真实工程案例（TDS 2026-08，病理笔记→结构化报告）：**输出用真实数据（10,000 份真报告），输入用前沿模型反向合成**——每个输出配 4 个不同 system prompt 生成的多样输入。模型学的是"映射"而非"复述"；输入多样性防幻觉（同一输出可达自多种输入变体）。加质量初筛：专挑基线模型做错的对。

### 2.4 子集选择：从"全量训"到"挑着训"

收益递减时，智能选择胜过全量：DEITA / DELIFT / coreset selection 找"覆盖任务空间的最小子集"。两重收益：更干净的梯度信号 + **更少的灾难遗忘**（更少的梯度更新拉扯预训练能力）。

### 2.5 配比与混合：经验法则汇总

| 发现 | 来源/条件 |
|---|---|
| **每技能的绝对数据量 > 技能间精确比例**；弱项先加数据再谈 rebalance | Dong et al.（AWS Nova 综述引） |
| **Dual-stage**：先纯专业数据，后"通用+少量专业"混合 > 顺序训练（遗忘）与平铺混合（干扰） | Dual-stage Mixed Fine-Tuning |
| 正迁移存在：Qwen2.5-Coder 70:20:10（代码:文本:数学）> 100% 代码，**代码基准也更好** | Qwen2.5-Coder 技术报告 |
| **监控 token 级配比而非样本级**：5% 长序列样本可占 80% 梯度 | AWS Nova（2026-08） |
| 自动寻优：DoReMi（小代理模型按超额损失加权）/ RegMix（回归预测）/ Dynamic Mixing（训练中调权，比最优静态 +2~5%） | ICML 2025 / NeurIPS 2025 等 |
| Agent 数据混合：10% 通用指令 + 10% 代码常见最优；再增通用数据 held-out 性能反降 | AgentBank（2410.07706） |
| 经验起点：高专任务 80% 目标域；轻适配（改语气）近均分；安全数据 5-10% 恒定 | AWS Nova（2026-08） |
| reasoning-instruction-following 类数据显著提升通用基准 | 同上 |
| 多模态：video >20% 保通用基准 | 同上 |

### 2.6 SFT 数据的坑（本地 + 网络合并）

- **过度蒸馏**：全用 GPT-4 数据 → 继承冗长/谄媚偏见（[`讲透LLM/04`](../讲透LLM/04-训练数据全景.md)）
- **格式污染**：数据带 markdown → 模型硬套格式（同上）
- **评估污染**：评估集混进训练集，分数虚高（[`04-微调数据工程`](./04-微调数据工程.md)）
- **矛盾风格指令**：输出语气不可预测；对策 = 统一回答模板 + 数据 schema 版本化（Hashnode 2026-03）
- **窄域过专**：训练分布外一碰就碎——ExpRAG 证明纯 LoRA SFT 在 OOD 任务上**塌到低于不训练**的水平（见 §7.5）

## §3 超参与训练配置：每条默认值给机械理由

### 3.1 起步配方（7B 级 + 数千条指令数据）

| 参数 | 全参 | LoRA | 理由 |
|---|---|---|---|
| learning_rate | 1e-5~2e-5 | 1e-4~2e-4 | LoRA 更新经 B·A 乘积 + rank 瓶颈 + α/r 缩放，因子需要大步才等效小步 |
| lr_scheduler | cosine | cosine | 末期 lr→0，末段是精修不是探索 |
| warmup_ratio | 0.03 | 0.03 | Adam 方差估计前几十步不可靠 |
| num_train_epochs | 2（1-3） | 2（1-3） | 超过 3 是在背样本（推理小数据例外，见 §2.2） |
| effective batch | 16-64 | 16-64 | 太小梯度噪、loss 曲线不可读；太大则优化步数不够（2k 样本 × batch 128 = 每 epoch 仅 16 步，cosine 形同虚设） |
| 精度 | bf16 | bf16 | NaN 几乎总是 fp16 训 bf16 基座导致的溢出 |

### 3.2 五条容易踩的高级细节

1. **r 与 lr 不独立**：固定 lora_alpha 加倍 r → 缩放因子减半 → **有效学习率悄悄减半**。扫 rank 时保持 α/r 恒定，或同步扫 lr。
2. **packing 是吞吐收益 + 正确性风险**：短样本拼接省 padding，但若实现不在文档边界重置 attention，token 会跨样本注意——**先关，吞吐真成瓶颈再开，并验证边界处理**。
3. **max_seq_length 用长度分布的 95/99 分位数**，不用最大值（每批为孤例买单）也不用上下文窗口（浪费）；先算直方图，记录截断条数——让它是"记录在案的决策"而非"意外"。
4. **label masking 只掩 assistant 段**：train 与 inference 格式一致（部署用 chat 模板就训 chat 模板）。
5. **loss = 0.0 = mask 反了**；梯度没到 adapter = target module 名不匹配；loss 尖峰 = 按 step 记录最高 loss 样本去找坏数据，**别先降 lr**。

### 3.3 训练动态判读（早停与劣质 run 识别）

| 信号 | 判读 |
|---|---|
| train 陡降后走平 | 正常（前几十步在学模板）；看 held-out，不看这条 |
| train↓ eval↑ | 过拟合；交叉点 = 该用的 epoch 数。先减 epochs → 加 dropout → 降 rank |
| step 0 起双平 | 梯度没到 adapter（查 trainable 参数计数是否为 0） |
| **早期梯度范数更低 + loss 更高 → 最终更好**；可用于早停劣质 run 省算力 | 小模型 SFT 指南（OpenReview 2024-10） |
| 大 batch + 低 lr 优于小 batch 高 lr（MMLU/MT-Bench） | 同上 |
| stacked（一次全量）≈ phased（分阶段），前者更简单样本效率更高；Orca 式分阶段无优势 | 同上；并推翻 TULU 部分超参建议 |

## §4 PEFT vs 全参：2025-2026 的谱分析新认识

### 4.1 本地已讲透的底层（[`00`](./00-为什么LoRA能用1%参数逼近全参数微调.md)-[`03`](./03-QLoRA.md)）

ΔW=B·A 低秩假设、B=0 初始化严格等价基座、α/r 强度旋钮、QLoRA=NF4 基座+全精度增量（70B 单卡 24G）。

### 4.2 入侵维度：LoRA 等价性是幻觉（arXiv 2410.21228）

- LoRA 与 Full FT 的 SVD 谱结构**本质不同**：LoRA 产生预训练谱中没有的高秩奇异向量——**intruder dimensions**。
- 因果验证：单任务场景 LoRA 确实比 Full FT 遗忘少；**但持续学习场景入侵维度逐任务累积，LoRA 遗忘反超 Full FT**，低 rank 最严重。
- 免费疗法：训后把 top 入侵维度的奇异值乘 0.7~0.9 → 遗忘大降（LLaMA2-7B/MetaMath 案例 -33.3%），任务精度几乎不掉（-0.1%）。
- **选型含义**：①持续学习别攒一个 LoRA 顺训到底（见 4.3-4.4 解法）；②两个同分模型选**入侵维度更少**的（免数据的质量评估法）。

### 4.3 Merging 的现实检验（arXiv 2602.12323，2026-02）

近 1000 个 HF 社区 LoRA 的大规模评估：adaptive merging 能超 base，**但打不过"直接在目标任务训一个 LoRA"这个朴素基线**；更扎心的是目标 LoRA 在池中时，随机 LoRA ≈ 精选 LoRA——文献里的成功高度依赖受控实验的任务亲缘性。**先验证"合并 > 直接训"再做合并**。正面对照：mergeability 研究（2601.06672）发现 **base 本来就会的任务的更新更可合并**——可合并性是更新的局部属性。

### 4.4 持续学习四条 2026 路线（防遗忘前线）

| 路线 | 机制 | 数据 |
|---|---|---|
| **SLoRA**（ACL 2026） | 遗忘主因 = LoRA 更新中的**噪声累积**；用与 base 子空间相似度过滤噪声分量，正则项零添加、无 rehearsal | 精度 +12%、遗忘 -29%、滤掉 30%+ 参数 |
| **SLAO**（ICLR 2026） | 持续学习重述为**单 LoRA 顺序合并**：A 用前任务正交基初始化，只合并 B（LoRA 不对称性），1/√i 时间感知缩放 | 内存 O(T)→O(1)，数据无关 |
| 入侵维度缩灭 | 训后调低 top intruder 奇异值 | 遗忘 -33%（见 4.2） |
| 多 adapter 不合并 | 每任务独立 LoRA 按需加载 | Sheng et al. 2024；与本地 FT10 一致 |

## §5 失败模式全谱（本地三章 + 2026 新增两种）

### 5.1 本地已讲透三模式（[`05-微调失败模式`](./05-微调失败模式.md)）

1. **灾难遗忘**：低 lr + 少 epoch + LoRA + 数据混复习
2. **过拟合**：早停（train/eval 交叉点）+ LoRA 天然正则 + 更多数据
3. **alignment tax**：LLaMA-2 chat 在推理/代码/知识广度上**输给自己的 base**；对策 = SFT 混大量通用数据（DeepSeek/Qwen 均如此）

诊断速查表见 05 篇 §4（train 不降/分叉/原任务崩/整体变笨/震荡/重复乱码 → 各自检查项）。

### 5.2 新增④：安全退化（推理 SFT 的隐性代价）

长 CoT SFT 后模型在 thinking 里**自我合理化**（"出于教育目的……"）最终输出有害内容——self-jailbreaking。对照实验：**带 CoT 的 SFT 安全降幅远大于不带 CoT 的**（arXiv 2604.06628）。推理能力与安全性的解耦是推理 SFT 的固定税，评估必须加安全维。

### 5.3 新增⑤：多样性/分布类退化

- **接口捷径**（Agent SFT 特有，§7.2）：换工具名就持续调用已废弃的 action
- **输出风格坍缩**：ASTRA 观测 SFT 后模型输出最短（把推理压成示范式模式），RL 后回到中间长度——SFT 会系统性收窄行为分布
- **OOD 塌缩**：纯 LoRA SFT 在分布外任务上可低于不训练（ExpRAG，§7.5）

## §6 推理模型时代的 SFT vs RL：大辩论的 2026 定稿

> 背景板：R1 四阶段范式（cold-start SFT → reasoning RL → **rejection sampling SFT** → 全场景 RL），见 [`讲透RL/03-RLHF-DPO-GRPO`](../讲透RL/03-RLHF-DPO-GRPO.md)。R1-Zero 证明纯 RL 可行，但正式版回归"SFT 冷启动 + RL 放大"——这个回归本身就是证据。

### 6.1 "SFT 记忆、RL 泛化"（Chu et al. 2025）的三条件修正（arXiv 2604.06628，2026-04）

泛化不是 SFT 的固有属性缺失，而是**条件属性**，由三因素联合决定：

| 因素 | 发现 |
|---|---|
| **优化充分性** | 跨域性能先降后升（**dip-and-recovery**）；短训练 checkpoint 系统性低估泛化——很多"SFT 不泛化"的结论是欠优化伪影 |
| **数据质量与结构** | 低质解广泛伤害泛化；**verified long-CoT 轨迹**带来一致的跨域收益 |
| **基座能力** | 强模型能从玩具算术游戏里内化可迁移的程序性模式（backtracking）；弱模型只模仿表面冗长 |

且泛化**不对称**：推理涨 ↔ 安全跌（呼应 §5.2）。问题的正确形态从"SFT 是否泛化"变成"**在什么条件下、以什么代价泛化**"。

### 6.2 机制级分工：RL 压缩、SFT 扩张（ICLR 2026，arXiv 2509.21128）

对 Base/RL/SFT/SFT+RL 四种模型做轨迹级+步级分析：

- **SFT 增加唯一正确轨迹数**（教 base 没有的新解法），但**保留错误轨迹**→ Pass@k 改善、**Pass@1 无保证**（"伪推理路径"的来源）
- **RL 压缩错误轨迹**（概率质量重分配提 Pass@1），**也压缩正确轨迹**→ 大 k 时 base 的 Pass@k 反超 RL 模型
- **SFT+RL 互补**：先用 SFT 扩张正确解空间，再用 RL 压掉错误解——SOTA 数学/代码模型全走这条路的机制解释

### 6.3 长 CoT SFT 决定 RL 的天花板（Demystifying Long CoT）

- **SFT 非必需但强烈推荐**：从 base 直接 RL 可行但难训；从长 CoT SFT 出发简单高效
- **短 CoT SFT 后 RL 几乎无增益**（MATH-500 前后持平）；长 CoT SFT 后 RL +3%+，OOD +20%
- **涌现的长模式 > 人工构造的模式**：蒸馏 QwQ 类涌现轨迹的模型 OOD（AIME/MMLU-Pro）相对提升 15-50%，且可被 RL 继续改进；构造模式训出的模型 RL 推不动
- 蒸馏数据筛法（文献汇总）："wait" token 计数（Muennighoff）、认知行为启动（Gandhi）、逐步清晰度评分（Ye）

### 6.4 理论分离与融合尝试

- **可证分离**（arXiv 2606.22938，2026-06）：把 CoT 建模为图上寻路——**SFT（无负例的最短路模仿）学不会高效回溯**，RLVR 只用结果奖励就能学会从死胡同回撤，推理时计算指数级分离。但 **RLVR 模型的轨迹可以蒸馏回 base**——RL 探索、SFT 传播的分工闭环。
- **Synergy Dilemma**（TMLR 2026，VLM 多模态）：SFT 提升难题（深度结构化推理）但引入冗长、伤简单题；RL 全面但难题弱。**两阶段/交错/渐进/数据混合/模型 merge 全都不产生叠加收益**，只带来精度-风格-长度的三角 trade-off——LLM 上的协同在 VLM 上失灵，组合后训练仍缺"无缝自适应"方法。

### 6.5 给实践者的 SFT/RL 分工速查

| 你要的是 | 用什么 |
|---|---|
| 格式遵循/风格/结构化输出 | SFT 单打够 |
| 行为一致性（RAG/prompt 治不了） | SFT（QLoRA 起步） |
| "A 优于 B"的偏好 | SFT → DPO/RLHF |
| 数学/代码等可验证推理 | 长 CoT SFT 冷启动 → RLVR 放大 |
| 新知识注入 | RAG/数据更新（SFT 不擅长改事实，见 Hashnode/本地 FT7） |
| 多轮 Agent 工具使用 | 轨迹 SFT 冷启动 + 可验证多轮 RL（ASTRA/PACT 模式，§7） |

## §7 Agent SFT 专项：2026 最活跃前线

### 7.1 标准管线与规模效应

**Trajectory SFT** = 强教师与环境交互产轨迹 → 行为克隆微调学生（AgentInstruct / Agent-FLAN / AgentBank）。AgentBank（50k 轨迹，16 任务×5 技能维）的关键 scaling 发现：**held-out 泛化随"任务数"与"轨迹数"双增长**，但 13B 上轨迹数收益已平台化——**SFT 的尽头，需要 RL 接力**（与 §6 机制一致）。

### 7.2 核心病：接口捷径（arXiv 2602.01611，2026-02）

轨迹 SFT 的 benchmark 提升无法区分两种学习：**语义学习**（内化工具含义）vs **接口捷径**（复现交互的表面格式）。PIPE 协议只改接口（action 名/格式）不改任务难度做评估——结果：多数 agent 换接口就持续调用已废弃的 action 名；**只在原始接口上选 checkpoint，可能选中更脆的那个**。配套指标 Interface Reliance（IR）应进评估。设计得当的训练可以降低 IR（捷径非必然）。

### 7.3 轨迹精修：DAG 修剪（OpenReview 2026-06）

把轨迹视为轮级依赖 DAG：**剪掉输出从未被消费的轮次**、合并可互换的兄弟轮 → 精修轨迹训出的模型：精度 +1.7pp（对 LLM 删除基线 +5.7pp），**推理消息 -40%、token -48%**。教训：**教师轨迹里的失败重试/验证轮不是免费的信号，是昂贵的噪声**——先修轨迹再 SFT。

### 7.4 SFT×RL 融合：PACT 特权轨迹协同训练（arXiv 2606.16215，2026-06）

SFT 密集监督但"过约束到固定轨迹"；RL 匹配部署分布但奖励稀疏 credit assignment 弱。PACT：专家轨迹**只做训练期优化信号，不做 rollout 提示**——

- component-aware SFT：只监督推理前缀+工具调用（工具返回是环境的，不模仿）；语义单元级退火（先长前缀后渐撤）
- 工具调用监督权重随训练退火，让 RL 接管探索
- prompt-only anchoring（q≈0.4）：一部分样本纯 RL 无专家信号，锚住部署分布
- 成绩：FTRL 42.41% vs 最强 SFT→RL 顺序基线 37.17%（Qwen3-4B）

### 7.5 检索增强微调：ExpRAG-LoRA（arXiv 2603.18272）

训练时就把检索到的经验轨迹挂进上下文（与推理时同管线）：模型学会"**利用检索**而不是背训练目标"→ OOD hard 任务上不再塌缩（纯 LoRA 在 OOD 上低于不训练）。启示：**记忆/经验类能力，把"检索"作为训练分布的一部分教给模型**。

### 7.6 轨迹的新用途：ACC 编译成长上下文 QA（arXiv 2605.21850）

标准 Agent SFT 把工具返回 mask 掉 → **监督盲区**：证据散落多轮却从未被直接监督。ACC 把轨迹编译成"问题 + 跨轮证据汇编"的单轮长上下文 QA（教师合成全局推理链）→ Qwen3-30B-A3B 在 MRCR +18.1 / GraphWalks +7.6，追平 235B；通用能力不掉。**同一条轨迹，换个监督形状就是新数据资产**。

### 7.7 全自动两阶段样板：ASTRA（贝壳，arXiv 2601.21558）

工具调用图静态拓扑 → 合成多样轨迹（质量自动打分）→ SFT 冷启动；QA 轨迹分解 → 合成代码可执行、规则可验证的环境 → 多轮在线 RL（F1 式轨迹级奖励 + 无关工具混入）。BFCL-v3 Multi-Turn 同级 SOTA。另见本地 [`AWorld-RL 深读卡`](../../讲透Agent/AgentRL生态深读/AWorld-RL-深读卡.md)：EnvTuning——**调环境而非调轨迹**，400 样本四阶段课程即可显著提升（治的正是"SFT 过拟合 + RL 冷启动不稳"）。

## §8 实践决策树（合并本地 FT7 + 2026 网络版）

```
你的问题是什么？
├── 注入新知识/知识常变 ──────────→ RAG / 数据更新（SFT 不改事实）
├── 输出行为不一致（格式/风格）──→ Prompt → 不够 → SFT（QLoRA 起步）
├── 偏好对齐（A 优于 B）─────────→ SFT 打底 → DPO/RLHF
├── 可验证推理（数学/代码）──────→ 长 CoT SFT（蒸馏+验证筛）→ RLVR
├── 多轮 Agent 工具使用 ─────────→ 轨迹精修 SFT 冷启动 → 换接口评估 → 多轮 RL
└── 需要时再考虑：合并 LoRA / 持续学习 ──→ 先过 §4.2/4.3 的坑
```

**执行顺序铁律**：先 1000 条精挑数据 + 默认超参跑通 → 抽 50 条 target 查共性 → 修数据 > 加不同数据 > 调 epochs > target modules > rank > lr（一次只动一个，固定 seed）。

## §11 一句话总结

> **SFT 是"模仿你选的数据分布"的工程：数据质量决定上限（LIMA/AlpaGasus），充分优化决定到达率（400×128ep>51k×1ep），配比看 token 不看样本；它的边界是无负例、学非预期特征、且持续学习下 LoRA 会攒入侵维度。推理时代的定稿分工是：长 CoT SFT 扩张正确轨迹（决定 RL 天花板），RL 压缩错误轨迹；Agent 前线的核心病是接口捷径，解法是把评估换接口、把轨迹修 DAG、把专家轨迹降级为优化信号。**
