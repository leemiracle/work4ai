## 1. 微调全流程

```
① 数据准备 (指令JSON) → ② 基座加载(QLoRA) → ③ LoRA 配置挂载
   → ④ 训练 → ⑤ 评估 → ⑥ 合并(可选) → ⑦ 部署
```

---

## 2. 数据格式（Alpaca 格式，最通用）

```json
{"instruction": "把下面句子翻译成英文", "input": "今天天气真好", "output": "The weather is nice today."}
{"instruction": "写一个 Python 函数计算斐波那契数", "input": "", "output": "def fib(n):\n    ..."}
```

每行一条 JSON。也可用 ShareGPT 多轮格式。数据质量见 04 篇——**宁少而精**。

## 3. 代码骨架：PEFT + QLoRA（最主流）

```python
# pip install transformers peft trl bitsandbytes accelerate
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training
from trl import SFTTrainer, SFTConfig
from datasets import load_dataset

# ① 加载基座 (QLoRA: 4bit)
base_id = "Qwen/Qwen2.5-7B"
tok = AutoTokenizer.from_pretrained(base_id)
model = AutoModelForCausalLM.from_pretrained(base_id,
        load_in_4bit=True, device_map="auto", torch_dtype=torch.bfloat16)
model = prepare_model_for_kbit_training(model)        # 为量化基座做准备

# ② LoRA 配置 (00/01 篇的 r, alpha 在这里)
config = LoraConfig(
    r=8, lora_alpha=16, lora_dropout=0.05,
    target_modules=["q_proj","k_proj","v_proj","o_proj","gate_proj","up_proj","down_proj"],
    task_type="CAUSAL_LM",
)
model = get_peft_model(model, config)
model.print_trainable_parameters()   # 可训练占比 ~0.5%

# ③ 数据 + 训练
ds = load_dataset("json", data_files="train.json")["train"]
trainer = SFTTrainer(model=model, tokenizer=tok, train_dataset=ds,
    args=SFTConfig(output_dir="./out", per_device_train_batch_size=4,
                   num_train_epochs=3, learning_rate=2e-4, save_strategy="epoch"))
trainer.train()

# ④ 只存 LoRA (几十 MB, 不存整个模型!)
model.save_pretrained("./lora_ckpt")
```

## 4. 训练后：合并 or 直接部署

```python
# 方案A: 合并 LoRA 进基座 (推理无额外开销, 01篇讲过)
merged = model.merge_and_unload()
merged.save_pretrained("./merged_model")

# 方案B: 不合并, 推理时动态加载 LoRA (省存储, 多任务热插拔)
from peft import PeftModel
base = AutoModelForCausalLM.from_pretrained(base_id, device_map="auto")
served = PeftModel.from_pretrained(base, "./lora_ckpt")
```

## 6. 超参经验值

| 超参 | 推荐值 | 说明 |
|---|---|---|
| r | 8–16 | 通用任务够用；难任务可到 64 |
| lora_alpha | 2×r | 保持 scale=2（01 篇） |
| learning_rate | 1e-4 ~ 3e-4 | LoRA 比全参 FT 用更大 lr |
| epochs | 1–3 | 数据多 1 epoch，少则 3 |
| target_modules | all-linear | 默认挂所有 Linear 最稳 |
| batch | 4–8 × grad_accum | 受显存限制 |

## 7. 评估（别忘了 05 篇的教训）

- **目标任务指标**（你的微调目标：准确率、人工评分）
- **原能力指标**（通用基准 MMLU/C-Eval，确认没崩——抗 alignment tax）
- **对比基座**：微调版 vs 原版，看净增益

## 8. 一句话总结

> **一次完整 LoRA 微调：①Alpaca 格式精编数据；②PEFT+QLoRA 加载基座挂 LoRA（r=8/α=16/lr=2e-4）；③SFTTrainer 训 1–3 epoch；④存 LoRA（几十MB）或合并；⑤评估时同时看目标能力和原能力。零代码可用 LLaMA-Factory。整个流程在一台消费级 GPU（如 4090）上跑 7B 模型，几小时完成。**
