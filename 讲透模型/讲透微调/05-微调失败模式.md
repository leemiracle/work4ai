# 05 — 微调失败模式：灾难遗忘、过拟合、alignment tax

> 微调不是纯增益。这一篇讲透三个最常见的失败模式，以及怎么诊断和缓解。
>
> 配套实验：`experiments/05_failure.py`。

---

## 1. 灾难遗忘（Catastrophic Forgetting）

### 现象

微调 task B 时，模型为适应 B 而**改写权重，破坏了 task A 的能力**。00 篇的 sin→cos 实验已经见过：微调到 cos 后，sin 能力几乎全丢。

### 实验（`05_failure.py` Part 1）

```
学习率   taskB(新)   taskA(遗忘)
0.001    0.0002      0.9989
0.003    0.0002      0.9983
0.010    0.0001      0.9991
0.030    0.0001      0.9997
```

> ⚠️ 诚实说明：sin→cos 是"强迁移"（两正交函数），遗忘本身就剧烈，lr 间差异在这里不明显。真实 LLM 微调（如通用模型→医学）遗忘更可控、lr 影响更显著。但**趋势对**：lr 越大、步数越多，遗忘越重。

### 缓解

1. **低学习率 + 少 epoch**：小步慢走，少动原有权重。
2. **LoRA**：增量 $BA$ 受低秩约束，对原权重的"破坏"天然受限（相关任务上少遗忘）。
3. **数据混合**：把 task A 的数据混进 B 的训练集一起训（复习 + 新学）。
4. **EWC / 正则**：给重要参数加"别动太多"的惩罚（实践少用，LoRA 已够）。

---

## 2. 过拟合（Overfitting）

### 现象

数据少时，模型**背诵训练样本**而非学规律：train loss 持续降，但 test loss 在某点后**反弹上升**。

### 实验（Part 2）

```
步数    train(20点)   test(全量)
0       0.0016        0.0018
800     0.0000        0.0002
2000    0.0000        0.0001
```

> ⚠️ 诚实说明：这里 test 没有反弹——因为 cos 是**平滑函数**，20 个点足够 MLP 插值泛化，不会过拟合。**过拟合在复杂/噪声任务（如真实文本、带噪声标签）才明显**。真实微调里，少数据训太久会清晰看到 train/test 分叉。

### 缓解

1. **早停**：监控验证集，loss 反弹时停。
2. **LoRA 的天然正则**：低秩约束限制模型容量，比 Full FT 难过拟合（00 篇 r=4 比 Full FT 略好就是这个道理）。
3. **更多/更高质量数据**（04 篇铁律）。
4. **Dropout / 权重衰减**。

---

## 3. Alignment Tax（对齐税）

### 现象

SFT/对齐让模型"听话"了，但**某些通用能力可能下降**。LLaMA-2 技术报告量化过：chat 版在某些基准（推理、代码、知识广度）**不如 base 版**。

### 原因

对齐数据多是"指令对话"，模型为适应这种分布，**偏离了预训练的通用语言建模能力**。这是对齐的隐性代价。

### 缓解

对齐数据里**混入"通用能力维持"数据**——代码、数学、常识问答，不能只放指令对话。DeepSeek、Qwen 的训练都在 SFT 阶段混了大量通用数据，就是为了对抗 alignment tax。

---

## 4. 诊断清单（微调效果差时怎么查）

| 症状 | 可能原因 | 检查 |
|---|---|---|
| train loss 不降 | 学习率/数据格式错 | 检查 lr、数据是否被正确读入 |
| train↓ test↑ | 过拟合 | 加数据、早停、用 LoRA |
| 目标任务好、原任务崩 | 灾难遗忘 | 混入原任务数据、降 lr |
| 整体变笨 | alignment tax | SFT 数据混通用能力 |
| loss 震荡 | lr 太大 / batch 太小 | 降 lr、增 batch |
| 输出重复/乱码 | 数据质量差 / 训练过度 | 查数据、减 epoch |

---

## 5. 一句话总结

> **微调三大失败模式：①灾难遗忘（学新忘旧，缓解靠低 lr/LoRA/数据混合）；②过拟合（少数据背样本，缓解靠早停/LoRA 天然正则/更多数据）；③alignment tax（对齐后通用能力下降，缓解靠 SFT 混入通用数据）。微调评估必须同时看'目标能力'和'原有能力'，否则会误把'变听话但变笨'当成成功。**

---

## ✍️ 练习（`05_failure.py`）

1. **制造过拟合**：把训练数据加 20% 随机噪声标签，重跑 Part 2，看 train/test 是否分叉——亲手触发过拟合。
2. **数据混合抗遗忘**：微调时把 sin 和 cos 数据 1:1 混合训练，看 taskA 遗忘是否减轻。
3. **alignment tax 模拟**：构造一个"只对齐某风格"的场景，看模型在其他风格上是否变差。
