# 👁️ 第 1 幕 · 直觉：视觉的三次范式更迭

## 视觉的根本困难：逆图形学

先用一句话说清 CV 为什么难：

> **相机拍到的是 2D 像素，但世界是 3D 的。从 2D 反推 3D 是「病态问题」（ill-posed）——同一张 2D 图对应无限多种 3D 场景。**

一张「桌上有杯子」的照片：杯子可能是大杯远放，也可能是小杯近放；光照可能来自窗外，也可能来自灯。**像素本身不足以唯一确定场景**。

CV 的全部历史，就是**给这个病态反演问题加上不同的「先验」**（prior），让它变得可解。每次范式更迭，本质就是**换了一种先验**。

---

## 三次范式更迭：换的是「先验」

```
范式 1 · CNN 时代 (2012-2020)
  先验: 局部性 + 平移不变性 + 层次抽象
  信念: 视觉 = 层层提取特征

范式 2 · 基础模型时代 (2020-2022)
  先验: 把图切块当 token, 用 Transformer 全局聚合
  信念: 数据 > 归纳偏置；规模解决一切

范式 3 · 多模态/生成时代 (2022-)
  先验: 用语言对齐语义 + 用扩散学分布
  信念: 视觉理解需要语言；视觉创造需要生成模型
```

**关键观察**：先验从「最死板」（CNN 的卷积）到「最灵活」（扩散的通用生成先验）。**越灵活的先验 = 核心越简单 = 边缘越能发散**——这是 `故事原语/02-熵论辩证` 在 CV 的直接体现。

---

## 范式 1 · CNN 时代（2012-2020）：卷积的黄金十年

### 起点：AlexNet 2012

2012 年 ImageNet 比赛上，AlexNet 把错误率从 26% 砍到 15%。**这是深度学习的引爆点**——CNN 之前在学术界沉睡了 20 年，AlexNet 之后统治了 CV 十年。

### CNN 的三大归纳偏置

卷积网络把人类对视觉的直觉**硬编码进了架构**：

1. **局部性**（locality）：一个像素只和它周围的像素相关 → 用小卷积核扫
2. **平移不变性**（translation invariance）：猫在左上角和右下角都是猫 → 卷积核权值共享
3. **层次抽象**（hierarchy）：浅层学边缘，中层学部件，深层学物体 → 多层堆叠

这三大偏置让 CNN **极其样本高效**——不需要看遍所有位置的猫就能学会「猫」。

### 巅峰与极限

- **巅峰**：ResNet（2015，152 层）、EfficientNet、目标检测（YOLO 系列）、分割（U-Net/DeepLab）。ImageNet top-5 错误率从 15% 降到 2% 以下，**超越人类**。
- **极限**：
  - **感受野有限**——CNN 看不远，长距离依赖弱
  - **需要标注**——监督学习，标注贵
  - **判别 only**——只能分类/检测，不能生成
  - **预训练-微调范式遇瓶颈**——ImageNet 预训练迁移到下游的增益见顶

2017 年 Transformer 出现后，CV 人开始问：**视觉能不能也「一切皆 token」？**

---

## 范式 2 · 基础模型时代（2020-2022）：放弃卷积

### ViT 2020：把图像当句子

Dosovitskiy 2020 年的 ViT（Vision Transformer）做了一个激进决定：

> **把图像切成 16×16 的 patch，每个 patch 当一个 token，塞进标准 Transformer。完全放弃卷积。**

结果：**在足够大数据上，ViT 超过 CNN**。这颠覆了「卷积归纳偏置是视觉必需」的共识——**数据足够多时，模型可以自己学到这些偏置**。

**这是 CV 的「规模胜过手工设计」时刻**，和 GPT-3 在 NLP 的时刻同构。

### CLIP 2021：视觉-语言对齐

OpenAI 的 CLIP 做了另一件事：**用对比学习把图像和文本对齐到同一空间**。

```
训练: 「一只金黄色的狗」的文本 ↔ 狗的图片  → 拉近
       「一只金黄色的狗」的文本 ↔ 猫的图片  → 推远
```

结果：**零样本分类**——CLIP 见过「猫」这个词和猫的图，能零样本认出新类别的猫。这是基础模型「一个模型做所有任务」的早期范本。

### 自监督：MAE / DINOv2

He 2022 的 MAE（Masked Autoencoder）：挡住图像 75%，让模型重建。**视觉版的 BERT**。

DINOv2（Meta）：自监督训练的视觉 backbone，**质量高到可以直接当特征提取器用于各种下游**，无需微调。

**范式 2 的遗产**：视觉有了「通用基础模型」——一个预训练的 ViT/CLIP/DINOv2，能迁移到几乎所有视觉任务。但它们仍是**判别模型**，不能生成。

---

## 范式 3 · 多模态/生成时代（2022-）：从识别到创造

2022 年起，CV 进入第三次范式更迭——**视觉不只是「看懂」，还要「创造」和「结合语言推理」**。三股力量：

### 力量 A · SAM：分割万物（2023）

Meta 的 SAM（Segment Anything）把分割做到了「零样本」：你给它任何图，给它一个提示（点/框/文本），它分割出对应物体。**分割任务的 GPT 时刻**。

SAM 的核心：在 11 亿掩码上训练，学到了「什么是一个物体」的通用概念。SAM 2（2024）扩展到视频。

### 力量 B · Diffusion：生成模型的新王

DDPM（Ho 2020）和 Latent Diffusion（Rombach 2022，Stable Diffusion）让生成质量飞跃。**核心机制**：训练一个网络预测「加了多少噪声」，然后反向去噪生成图像。

为什么 Diffusion 打败 GAN：**训练稳定、多样性好、可控性强**（ControlNet/LoRA/提示词）。

这是 Sora/Stable Diffusion/Midjourney/DALL-E 的共同引擎。

### 力量 C · VLM：视觉-语言模型

LLaVA（2023）：视觉编码器 → 投影层 → LLM，让 LLM「看图说话」。GPT-4V、Claude vision、Qwen2-VL 把它产品化。

**范式 3 的核心信念**：**视觉理解需要语言**。纯视觉的「猫」概念不如「这是一只金黄色的猫在追球」丰富——语言给了视觉以推理能力。

---

## 三次更迭的本质：先验的演化

把三次更迭放一起，会看到一个清晰的模式：

| 范式 | 先验 | 死板度 | 灵活度 |
|---|---|---|---|
| CNN | 局部性+平移不变（硬编码） | 最死板 | 低 |
| ViT | 通用 attention（数据学偏置） | 中 | 中 |
| Diffusion/VLM | 通用生成/对齐（最灵活） | 最灵活 | 高 |

**方向**：**先验越来越通用，对数据的依赖越来越大**。这就是为什么 CV 越来越像 NLP——**架构趋同于 Transformer，差别在数据和目标**。

**这和 `故事原语/02-熵论辩证` 完全一致**：世界级 = 核心简单（通用先验）+ 边缘丰富（海量数据组合）。CV 从 CNN 到 Diffusion，核心在熵减（先验更通用），边缘在熵增（能生成的视觉空间指数级扩大）。

## 2024-2026 前沿速览

| 系统 | 突破 | 意义 |
|---|---|---|
| **SAM 2** (Meta 2024) | 视频分割万物，零样本 | 分割的工业化 |
| **SigLIP 2** (Google 2025) | 改进 CLIP 对比学习 | 更强的视觉-语言 backbone |
| **Florence-2** (Microsoft 2024) | 统一视觉基础模型 | 一个模型做所有视觉任务 |
| **Qwen2-VL** (Alibaba 2024-2025) | 任意分辨率处理 | 解决 VLM 的分辨率折中 |
| **Sora / Veo 3** (2024-2025) | 视频生成 + 音频 | 「是不是世界模型」争议 |
| **Gaussian Splatting / NeRF** | 3D 重建 | 从 2D 重建 3D 场景 |
| **DINOv3 / 自监督** (2025-) | 无标注训练视觉 backbone | 降低标注依赖 |

**注意一个趋势**：CV 正在和 `讲透世界模型/` `讲透多模态/` 合流——纯 CV（识别/分割）已经基本解决，前沿在「视觉+生成+推理+3D」。

## 一个让你直觉理解的实验

闭上眼睛，想象你看到一只「猫」。

- **CNN 想到**：边缘 → 纹理 → 猫耳 → 猫脸 → 猫（层次特征）
- **ViT 想到**：一堆 patch，每个 patch 投票，全局聚合得出「猫」
- **Diffusion 想到**：从噪声里慢慢「去噪」出一只猫（生成视角）
- **VLM 想到**：「这是一只猫，它在晒太阳」（语言锚定的语义）

四种「想到」对应四种范式。**它们不是替代，是互补**——现代 CV 系统常常组合使用。

---

## 与其他宇宙的连接

- **`讲透多模态/`**：CV 讲「视觉感知本身」，多模态讲「视觉与语言/音频对齐」。本宇宙专注感知，那边专注对齐。
- **`讲透模型宇宙/` `讲透基础模型/`**（已有）：ViT 是基础模型在视觉的化身。
- **`讲透世界模型/`**：视频生成模型（Sora/Veo）是不是视觉世界模型？这是两宇宙的交叉争议。
- **`故事原语/02-熵论辩证`**：CV 三次更迭 = 先验的熵减重构（核心越来越简单通用）。

## 🎬 本幕收束

> **CV 的 14 年（2012-2026），是「先验」从死板到灵活的 14 年。** CNN 把人类视觉直觉硬编码（卷积）；ViT 放弃硬编码、让数据学（attention）；Diffusion/VLM 用最通用的生成/对齐先验。**越通用的先验 = 核心熵减越彻底 = 边缘能组合的视觉故事越多。**
>
> 但病态问题没消失——我们只是用更强的先验+更多数据，把它压到「够用」。真正的「视觉理解」可能需要世界模型（知道杯子会碎），那是 `讲透世界模型/` 的领地。
