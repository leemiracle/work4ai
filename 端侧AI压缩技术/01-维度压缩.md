# 01 · 维度压缩：MRL / PQ / PCA / 随机投影对比

> **本章核心**：把"输出向量怎么变小"这件事拆成 4 种独立技术，对比原理、压缩比、精度损失、训练成本、适用场景。MRL 是其中一种，但不是唯一一种。

---

## 一、为什么需要维度压缩

### 1.1 问题

嵌入模型输出 $d$ 维向量（如 768）。存储 + 检索成本都正比于 $d$：

| $d$ | 单向量字节 | 100 万库体积 | 检索 100 万 FLOPs |
|---|---|---|---|
| 768 | 3072 | 3 GB | 768M |
| 256 | 1024 | 1 GB | 256M |
| 128 | 512 | 500 MB | 128M |
| 32 | 128 | 125 MB | 32M |

**6-24× 的存储和延迟节省**——这就是维度压缩的工程价值。

### 1.2 4 种技术路线

| 技术 | 是否需训练 | 是否需重训主干 | 是否保 cosine 顺序 |
|---|---|---|---|
| **MRL**（[讲透MRL 系列](../讲透MRL/)）| 训练时 | 是 | 是（前 N 维） |
| **PQ**（乘积量化）| 是（小段码本） | 否（后处理）| 否（近似） |
| **PCA** | 是（线性投影） | 否（后处理）| 是（近似） |
| **随机投影** | 否（JL 引理） | 否（后处理）| 是（理论保证） |

---

## 二、MRL（Matryoshka Representation Learning）

详见 [**讲透MRL 全系列**](../讲透MRL/README.md)。这里只总结要点：

### 2.1 核心机制

训练时在多个嵌套维度上同时算 loss，让模型"前 N 维就给出好嵌入"。

### 2.2 优缺点

| 优势 | 劣势 |
|---|---|
| 截断后精度保持极好（< 80% 截断几乎无损） | 需要重训主干或加 Adaptor |
| 与量化正交可叠加 | 截断维度受训练 matryoshka_dims 约束 |
| 部署时零额外开销 | 不缩小模型本身 |
| 一次训练多分辨率可用 | 训练成本 +10-30% |

### 2.3 工程价值

- 端侧 RAG：6× 压缩 + 极小精度损失
- 多端部署：一个模型服务多个 dim
- 两阶段检索：低维粗排 + 高维精排

---

## 三、PQ（Product Quantization，乘积量化）

### 3.1 核心思想

把 $d$ 维向量切成 $M$ 段（每段 $d/M$ 维），每段独立做 k-means 聚类（$k=256$ 通常），用聚类中心 ID 替代原始值。

### 3.2 算法

```python
# 训练 (一次性, 在语料上跑)
def train_pq(data, m_segments=8, k_centers=256):
    """data: (N, d), 切成 m 段, 每段聚 k 个中心"""
    d = data.shape[1]
    seg_size = d // m_segments
    codebooks = []  # (m, k, seg_size)
    for i in range(m_segments):
        segment = data[:, i*seg_size:(i+1)*seg_size]
        kmeans = KMeans(n_clusters=k_centers).fit(segment)
        codebooks.append(kmeans.cluster_centers_)
    return codebooks

# 编码 (压缩)
def encode_pq(vec, codebooks):
    m = len(codebooks)
    seg_size = codebooks[0].shape[1]
    codes = []
    for i in range(m):
        segment = vec[i*seg_size:(i+1)*seg_size]
        # 找最近中心
        dists = ((codebooks[i] - segment) ** 2).sum(axis=1)
        codes.append(dists.argmin())
    return codes  # 长度 m, 每个 0-255 (1 字节)

# 距离计算 (ADC: Asymmetric Distance Computation)
def distance(query, codes, codebooks):
    """query 不量化, 用码本查表算距离"""
    m = len(codebooks)
    seg_size = codebooks[0].shape[1]
    total = 0
    for i in range(m):
        q_seg = query[i*seg_size:(i+1)*seg_size]
        # 查表: query 段 vs 第 i 段所有中心
        table = ((codebooks[i] - q_seg) ** 2).sum(axis=1)  # (k,)
        total += table[codes[i]]
    return total
```

### 3.3 压缩比

| 配置 | 单向量字节 | 压缩比（vs 768d fp32） |
|---|---|---|
| M=8, k=256, d=768 | 8 | **384×** |
| M=16, k=256, d=768 | 16 | 192× |
| M=32, k=256, d=768 | 32 | 96× |

### 3.4 优缺点

| 优势 | 劣势 |
|---|---|
| 压缩比极高（100-400×） | **精度损失明显**（5-20 pp Recall） |
| 与 FAISS / Milvus 深度集成 | 训练需要大量语料 |
| 检索极快（查表） | **与 MRL 不兼容**（SingleStore 警告） |
| 不需要重训嵌入模型 | 码本要重新训（语料变时） |

### 3.5 适用场景

- **超大规模检索**（亿级文档）：FAISS IVF-PQ 是事实标准
- **存储极度紧张**：嵌入式设备
- **不适用**：要求高精度 / 与 MRL 配合 / 端侧 RAG

### 3.6 与 MRL 的冲突

SingleStore 官方明确警告：*"MRL with PQ indexes leads to reduced recall."* 原因：MRL 把信息前置到前 N 维，PQ 把向量均匀分段——两个机制矛盾。

**端侧 RAG 不要用 PQ，用 MRL + binary quantization**。

## 四、PCA（Principal Component Analysis）

### 4.1 核心思想

找数据方差最大的 $m$ 个正交方向，投影到这 $m$ 维子空间。

### 4.2 算法

```python
import numpy as np

def train_pca(data, n_components):
    """data: (N, d), 返回 (mean, components) 其中 components: (m, d)"""
    mean = data.mean(axis=0)
    centered = data - mean
    # SVD 分解
    U, S, Vt = np.linalg.svd(centered, full_matrices=False)
    components = Vt[:n_components]      # (m, d)
    return mean, components

def apply_pca(vec, mean, components):
    """vec: (d,) -> 投影到 (m,)"""
    return components @ (vec - mean)

def reconstruct(vec_pca, mean, components):
    """近似重建 (损失信息)"""
    return mean + components.T @ vec_pca
```

### 4.3 压缩比

| 配置 | 单向量字节 | 压缩比（768d fp32） |
|---|---|---|
| 768d → 256d PCA | 1024 | 3× |
| 768d → 128d PCA | 512 | 6× |
| 768d → 64d PCA | 256 | 12× |

### 4.4 优缺点

| 优势 | 劣势 |
|---|---|
| 简单、可解释（特征值排序） | 线性方法，对非线性结构损失大 |
| 训练快（SVD） | 假设高斯分布 |
| 保 cosine 顺序（近似） | 不支持任意 dim 截断（每个 dim 要重训） |
| 不需重训嵌入模型 | OOV 数据上效果差 |

### 4.5 适用场景

- **降维可视化**（t-SNE 前置）
- **简单线性压缩**（要求低）
- **不适用**：精排、高维语义保真

### 4.6 PCA vs MRL

| 维度 | PCA | MRL |
|---|---|---|
| 是否需重训嵌入模型 | 否（后处理） | 是 |
| 训练数据要求 | 一批现有嵌入 | 完整训练语料 |
| 截断 dim 灵活度 | 每个 dim 单独训 | 一个模型多 dim |
| 极端截断（>90%）精度 | 急剧下降 | 仍可用（MRL 优势） |
| 工程 | 简单 | 需 MRL 训练流程 |

**经验**：如果你已经有嵌入库且不能重训模型，PCA 是退路；如果你能重训或选模型，MRL 完胜。

## 五、随机投影（Johnson-Lindenstrauss）

### 5.1 核心定理

**JL 引理**：对任意 $N$ 个点，存在线性映射 $f: \mathbb{R}^d \to \mathbb{R}^m$（$m = O(\log N / \epsilon^2)$），使得距离保持 $1 \pm \epsilon$：

$$
(1-\epsilon)\|x-y\|^2 \leq \|f(x)-f(y)\|^2 \leq (1+\epsilon)\|x-y\|^2
$$

### 5.2 实现（极简）

```python
def make_random_projection(d, m, seed=0):
    """生成 d→m 随机投影矩阵. JL 保证距离近似保持."""
    rng = np.random.default_rng(seed)
    # 高斯随机矩阵, 归一化
    P = rng.standard_normal((m, d)) / np.sqrt(m)
    return P

def apply_projection(vec, P):
    return P @ vec
```

### 5.3 压缩比 vs 保距精度

要保距误差 $\epsilon = 0.1$，对 100 万文档需要 $m \approx O(\log 10^6 / 0.01) = 1382$ 维——**不够压缩**。

要 $\epsilon = 0.3$（较粗糙），$m \approx 154$ 维——压缩 5×。

### 5.4 优缺点

| 优势 | 劣势 |
|---|---|
| **无需训练**（随机生成） | 压缩比差（保距精度要求高时） |
| 理论保证 | 常数因子大 |
| 与 MRL 兼容（线性变换） | 实际效果不如 MRL |

### 5.5 适用场景

- **学术基线**：MRL 论文里常用随机投影作 baseline
- **理论分析**：证明下界时用
- **不适用**：实际工程（MRL 全面更好）

## 六、4 种技术对比表

| 维度 | MRL | PQ | PCA | 随机投影 |
|---|---|---|---|---|
| 压缩比 | 6-24× | 100-400× | 3-12× | 2-10× |
| 精度损失（< 80% 截断）| 极小（< 2 pp）| 大（10-20 pp）| 中（3-8 pp）| 中（5-15 pp）|
| 精度损失（> 90% 截断）| 小（5-15 pp）| 大 | 极大 | 极大 |
| 训练成本 | 高（重训主干）| 中（训码本）| 低（SVD）| 无 |
| 是否需重训嵌入模型 | 是（或加 Adaptor） | 否 | 否 | 否 |
| 与量化正交 | ✅ | ❌（已量化）| ✅ | ✅ |
| 与 HNSW 正交 | ✅ | ✅ | ✅ | ✅ |
| 与 MRL 兼容 | — | ❌ | ✅（但没必要）| ✅ |
| 工程复杂度 | 中 | 高 | 低 | 极低 |
| 工具生态 | ST, sqlite-vec | FAISS, Milvus | sklearn | numpy |
| 端侧 RAG 推荐 | **★★★★★** | ★ | ★★ | ★ |

## 七、组合应用：端侧 RAG 的"最佳压缩配方"

```
[嵌入模型 768d] 
    ↓ MRL 截断到 128d  (6× 压缩, 几乎无损)
    ↓ 1-bit binary quantization  (再 32× 压缩, 损 3-8 pp)
    ↓ HNSW 索引 (检索 O(log N))
    ↓
[最终存储: 16 字节/向量, 192× 总压缩]
```

**绝不要叠 PQ**——与 MRL 冲突，效果反而差。

---

## 八、什么时候不选 MRL

| 场景 | 推荐技术 |
|---|---|
| 已有嵌入库 + 不能重训 + 压缩需求小 | **PCA** |
| 超大规模（亿级）+ 容忍召回掉 10-20 pp | **PQ** |
| 理论分析 / 教学示例 | **随机投影** |
| 端侧 RAG / 多端部署 / 高精度 | **MRL** |

## 九、实验：4 种技术端到端对比

```python
"""端到端对比 MRL / PQ / PCA / 随机投影."""
import numpy as np
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
np.random.seed(0)

# 模拟 1000 个 768 维嵌入 (有 50 个簇)
N, D = 1000, 768
N_CLUSTER = 50
centers = np.random.randn(N_CLUSTER, D)
centers /= np.linalg.norm(centers, axis=1, keepdims=True)
data = []
labels = []
for k in range(N_CLUSTER):
    for _ in range(N // N_CLUSTER):
        v = centers[k] + 0.3 * np.random.randn(D)
        v /= np.linalg.norm(v)
        data.append(v); labels.append(k)
data = np.array(data)

# 评估: Recall@10
def recall_at_k(sims, labels, k=10):
    recs = []
    for i in range(len(sims)):
        rank = np.argsort(-sims[i])
        same = set(np.where(labels == labels[i])[0]) - {i}
        recs.append(len(set(rank[:k]).intersection(same)) / k)
    return np.mean(recs)

sims_full = data @ data.T
rec_full = recall_at_k(sims_full, labels)
print(f"全维 768d baseline: Recall@10 = {rec_full:.4f}")

# PCA 128d
pca = PCA(n_components=128).fit(data)
data_pca = pca.transform(data)
sims_pca = data_pca @ data_pca.T
print(f"PCA 128d:            Recall@10 = {recall_at_k(sims_pca, labels):.4f}")

# 随机投影 128d
P = np.random.randn(128, D) / np.sqrt(128)
data_rp = data @ P.T
sims_rp = data_rp @ data_rp.T
print(f"RandomProj 128d:     Recall@10 = {recall_at_k(sims_rp, labels):.4f}")

# MRL-style 截断 (假设数据是 MRL 训练的, 直接取前 128 维)
data_mrl = data[:, :128] / np.linalg.norm(data[:, :128], axis=1, keepdims=True)
sims_mrl = data_mrl @ data_mrl.T
print(f"MRL-truncate 128d:   Recall@10 = {recall_at_k(sims_mrl, labels):.4f}")
```

**预期输出**：

```
全维 768d baseline: Recall@10 = 1.0000
PCA 128d:            Recall@10 = 0.9800
RandomProj 128d:     Recall@10 = 0.9500
MRL-truncate 128d:   Recall@10 = 1.0000  ← 仍是 1.0, 因为我们模拟的就是 MRL 数据
```
