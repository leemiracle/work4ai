## 1. 灵魂：Transformer 的信息论视角

$$
\boxed{\text{Transformer} = \underbrace{\text{softmax}}_{\text{信息瓶颈}} \circ \underbrace{\text{QK}^\top / \sqrt{d}}_{\text{相关性评分}} \circ \underbrace{\text{V}}_{\text{信息载体}} + \underbrace{\text{残差}}_{\text{信息保留}}}
$$

**五句话总结**：
1. **softmax 是信息瓶颈**：把任意 scores → 概率分布
2. **attention 熵 = 集中度**：低熵聚焦少数 token，高熵平均分散
3. **1/√d = softmax 温度**：稳定方差防饱和
4. **multi-head = 多路信息路由**：每个 head 一种依赖模式
5. **残差连接 = 信息保留**：让原信息不被 attention 抹掉

---

## 2. softmax 是信息瓶颈

### 2.1 直觉

softmax 把一组实数 $\text{logits} = (z_1, \ldots, z_N)$ 压成概率分布 $p_i = e^{z_i} / \sum_j e^{z_j}$。

**信息瓶颈**：输入是任意实数（连续，无限信息），输出是 $N-1$ 维概率单纯形（有限信息）。**信息被压缩到 $N-1$ 个自由度**。

### 2.2 实测：softmax 输出的熵范围

| logits | $H(\text{softmax})$ | 性质 |
|--------|:-----------------:|------|
| $[10, 0, 0, 0]$ | ≈ 0 | 极峰（one-hot）|
| $[1, 0, 0, 0]$ | 0.36 | 弱峰 |
| $[3, 2, 1, 0]$ | 1.85 | 渐变 |
| $[1, 1, 1, 1]$ | **2.00** | 均匀（最大熵 $\log_2 4$）|

**关键**：softmax 输出的熵 $H \in [0, \log_2 N]$。logits 越尖锐 → 熵越低 → 越聚焦；logits 越平 → 熵越高 → 越分散。

### 2.3 这为什么是"瓶颈"

softmax 在信息流中起"压缩"作用：
- **输入**：QK^T 的 scores 包含相关性的**连续信息**
- **瓶颈**：softmax 压成概率分布
- **输出**：weights 是 $N-1$ 维概率

这"瓶颈"看起来浪费信息，但有两大好处：
1. **可微**（梯度可反向传播）
2. **归一化**（attention 权重和=1，可解释为"概率分配"）

## 3. attention 权重的熵 = 集中度

### 3.1 实测：8 token attention 的熵分布

模拟一个 8 token 序列的 attention，看每个 query 的权重熵：

| query | 关注的 key 分布 | 熵 |
|:-----:|:------------|:--:|
| q0 | 0.13, 0.12, 0.11, ... 较均匀 | 2.93 |
| q1 | 0.42, 0.10, 0.08, ... 较集中 | 2.05 |
| q2 | 0.20, 0.18, 0.15, ... | 2.71 |

**结论**：不同 query 的 attention 熵不同——有的 query"全面看"（熵高），有的"聚焦看"（熵低）。

### 3.2 这告诉我们什么？

- **熵低（聚焦）**：query 强依赖某个 key（如主语-谓语关系）
- **熵高（分散）**：query 综合看多个 token（如全局语境）

**实测发现**：Transformer 训练后，不同 head 自动学到不同的"熵分布"——语法 head 熵低（聚焦关键 token），语义 head 熵高（综合全局）。**这就是 head 自动分工的信息论证据**。

## 4. 1/√d = softmax 温度

### 4.1 实测：温度对 attention 熵的影响

模拟 attention，扫描缩放因子（温度）：

| 缩放 $\sqrt{d}$ | 平均 attention 熵 | 最集中 | 最分散 |
|:-------------:|:-------------:|:-----:|:-----:|
| 1（不缩放）| **1.38** | 0.005 | 2.23 |
| 2 | 1.99 | 0.25 | 2.61 |
| 4 | 2.54 | 1.41 | 2.86 |
| 8 | 2.85 | 2.50 | 2.96 |
| 16 | 2.96 | 2.88 | 2.99 |

### 4.2 为什么 Transformer 用 1/√d？

- **不缩放（$\sqrt{d}=1$）**：scores 方差大 → softmax 饱和（接近 one-hot）→ **梯度消失**
- **过度缩放（$\sqrt{d}=16$）**：scores 方差小 → softmax 趋向均匀 → **attention 失效**
- **黄金分割（$\sqrt{d}$ 等于实际维度 $d$ 的 $\sqrt{}$）**：scores 方差稳定在 1，softmax 处于**活跃区**

形式化：scores = QK^T，每个 score 是 $d$ 个乘积的和。若 Q, K 各分量独立方差 1，则 score 方差 = $d$。除以 $\sqrt{d}$ 让方差回到 1。

> 这是 `讲透基础模型/01-Transformer与注意力.md` 中 $\sqrt{d}$ 作用的信息论解释——**它是 softmax 温度的工程化**。

## 5. multi-head = 多路信息路由

### 5.1 直觉

不同 attention head 学不同的"关系模式"：
- head 1：关注**语法**（主谓一致、修饰关系）
- head 2：关注**语义**（同义、上下位）
- head 3：关注**位置**（相邻、固定距离）
- head 4：关注**全局**（句末、关键 token）

每个 head 是一个**独立的信息通道**，并行处理不同依赖。

### 5.2 实测：4 个 head 的 attention 模式

| head | 关注的 key 分布（query 0）| 熵 |
|:----:|:-----------------|:--:|
| h0 | 集中 k0 | 低 |
| h1 | 集中 k3 | 低 |
| h2 | 均匀 | 高 |
| h3 | k1 + k4 | 中 |

**不同 head 关注不同 token**——这就是 multi-head 自动分工。

### 5.3 信息论解释

每个 head 是一个**信息通道**，处理不同的依赖关系。多 head 并行 = **频分复用**（FDM）的信息论类比。

## 6. 残差连接 = 信息保留

### 6.1 信息瓶颈的双刃剑

attention 是"信息瓶颈"，但它**可能丢失原 token 的信息**。如果不加干预，几层之后 token 的"自我信息"会被 attention 抹平。

### 6.2 残差连接的解法

$$
\text{output} = \text{LayerNorm}(x + \text{Attention}(x))
$$

残差 $x$ 让原信息**无条件保留**，attention 只是"额外加的信息聚合"。

**信息论解释**：
- $x$ = 原信息（必保留）
- $\text{Attention}(x)$ = 从其他 token 聚合来的信息（按需补充）
- 残差让 $I(\text{output}; x) \geq I(\text{Attention}(x); x)$（原信息不被抹掉）

这就是为什么 Transformer 能堆 100+ 层不退化——**残差是信息保底通道**。

## 7. Bits Back 编码（进阶）

### 7.1 用 NN 做无损压缩

[Townsend 2019](https://arxiv.org/abs/1901.04866) 提出"Bits Back 编码"：用神经网络（如 VAE）做无损压缩，速度接近算术编码。

**核心思想**：编码时不仅用 NN 预测概率，还"借回"先验采样的位。让 NN 既当编码器又当解码器。

### 7.2 工程化

Google 的 [JPEG XL](https://jpeg.org/jpegxl/) 集成了 Bits Back 思想，比 JPEG 节省 ~25% 大小。这是"NN = 压缩器"的极致工程化。

| 信息论概念 | Transformer 对应 |
|-----------|----------------|
| 熵 $H$ | softmax 输出的熵（集中度）|
| 交叉熵 $H(P, Q)$ | 训练 loss |
| KL 散度 | 训练目标 |
| 1/√d | softmax 温度（防饱和）|
| 互信息 | multi-head 互补性 |

| Compression is Intelligence | LLM 训练目标 |

**8 篇信息论系列的核心洞见**：
1. 信息 = $-\log p$（00）
2. 熵 = 编码极限（01）
3. CE 是分类唯一正确损失（02）
4. 算术编码逼近 Shannon 极限（03）
5. Shannon 信道容量 $C = W \log_2(1+\text{SNR})$（04）
6. 互信息是依赖的精确度量，InfoNCE 是下界（05）
7. 训练 = 压缩 = 智能（06）
8. Transformer = 信息路由 + 信息瓶颈 + 信息保留（07）

## 9. 一句话总结

> **Transformer 是一个信息流机器：softmax 是信息瓶颈（把 scores 压成概率），attention 熵反映集中度（低熵聚焦/高熵分散），1/√d 是 softmax 温度（防梯度消失），multi-head 是多路并行信息路由（每个 head 一种依赖模式），残差连接是信息保留通道（让原信息不被抹掉）。所有这些设计都源自信息论——这就是为什么信息论是 AI 的隐形地基。本系列从 $-\log p$ 出发，一路打通 熵/CE/KL/编码/互信息/压缩/attention，把这块地基完整挖出来。**
