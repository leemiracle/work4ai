# 00 · 概率图模型是什么

> **第一性问题**：高维概率分布 $P(X_1, X_2, ..., X_n)$ 难以表达——指数级复杂。**怎么用图结构压缩**？
>
> 这是概率图模型（PGM）的核心。它是 VAE / 扩散 / 大模型推理的**理论祖父**。
>
> 配套：[`讲透生成模型`](../讲透生成模型/) + [`讲透因果推断`](../讲透因果推断/) + [`讲透信息论`](../讲透信息论/)

---

## 一、问题：高维分布的诅咒

### 1.1 难题

$n$ 个二元随机变量的联合分布需要 $2^n - 1$ 个参数：

```
n=10  → 1023 参数
n=100 → 10^30 参数（不可能）
n=1000 → 宇宙原子数
```

**但**：真实世界变量之间**有结构**——独立 / 条件独立。

### 1.2 PGM 的核心思想

**用图表示变量间的依赖**——把联合分布**分解**为局部因子的乘积。

```
P(X_1, ..., X_n) = (1/Z) · ∏_c ψ_c(X_c)
                   ↑        ↑
                  归一化   局部因子（c = clique）
```

**关键**：图结构 = 条件独立结构。

---

## 二、三大派

### 2.1 贝叶斯网络（Bayesian Network, BN）

- **有向无环图（DAG）**
- 节点 = 随机变量
- 边 $A → B$ = "A 直接影响 B"
- 联合分布：$P(X_1, ..., X_n) = \prod_i P(X_i | \text{parents}(X_i))$

**例子**：疾病诊断
```
吸烟 → 肺癌 → X 光异常
       ↓
      咳嗽
```

**关键概念**：**d-分离**——给定观察集 Z，X 和 Y 是否条件独立？

### 2.2 马尔可夫随机场（Markov Random Field, MRF）

- **无向图**
- 节点 = 随机变量
- 边 = "相关性"（无方向）
- 联合分布：$P(X) = (1/Z) \prod_c \psi_c(X_c)$

**例子**：图像去噪
```
每个像素 = 节点
相邻像素 = 边（相关性）
```

**Hammersley-Clifford 定理**：正分布 + Markov 性 ⟺ Gibbs 分布。

### 2.3 因子图（Factor Graph）

- 二部图：变量节点 + 因子节点
- 最通用——能表示 BN 和 MRF
- 信念传播（belief propagation）的标准框架

## 三、推断——三大类问题

### 3.1 精确推断

| 算法 | 用途 |
|---|---|
| **变量消除** | 推边际分布 |
| **信念传播** | 树结构上精确 |
| **Junction Tree** | 一般图精确（计算量大） |

**问题**：精确推断对一般图是 #P-hard。

### 3.2 变分推断（Variational Inference）

**核心思想**：把推断变成**优化**。

$$\log P(X) \geq \mathbb{E}_q[\log P(X, Z)] - \mathbb{E}_q[\log q(Z)] = \text{ELBO}$$

- $q(Z)$：变分分布
- ELBO = Evidence Lower Bound
- 最大化 ELBO ⟺ 最小化 KL(q‖posterior)

**mean-field**：假设 $q(Z) = \prod_i q(Z_i)$（完全分解）。

> 🎯 **VAE 的祖父**：VAE = 神经网络参数化的变分推断。详见 [A02](./README.md)。

### 3.3 MCMC（Markov Chain Monte Carlo）

**核心思想**：采样近似。

| 算法 | 用途 |
|---|---|
| **Gibbs** | 逐变量采样 |
| **Metropolis-Hastings** | 通用 MCMC |
| **HMC（Hamiltonian）** | 连续变量高效 |
| **NUTS** | HMC 自适应 |

**优势**：渐近精确。
**劣势**：慢，难诊断收敛。

## 四、为什么 PGM 是 VAE/扩散的祖父

### 4.1 VAE 的本质

VAE = 变分推断 + 神经网络参数化。

```
传统变分推断：q(Z) 是简单分布（如高斯），手推 ELBO
VAE：q(Z|X) = 神经网络(X)，用 SGD 优化 ELBO
```

**核心数学没变**——还是 ELBO + KL。

### 4.2 扩散模型

扩散 = 一种特殊的隐变量模型 + 变分推断。

```
forward: x_0 → x_1 → ... → x_T（加噪）
reverse: x_T → ... → x_0（去噪 = 推断）
```

**reverse process 是变分推断**——学一个神经网络近似真实 reverse。

### 4.3 大模型推理

- LLM 的 next-token prediction 是简单 PGM
- 但**长程推理 / 多步思考**需要 PGM 思想（隐变量、因果链）

---

## 五、PGM 的现代价值

| 应用 | PGM 的角色 |
|---|---|
| **VAE / 扩散** | ELBO 是变分推断 |
| **因果推断** | Pearl 的 do-calculus 在 BN 上 |
| **强化学习** | POMDP / 信念状态 |
| **多智能体** | 博弈论 + 图 |
| **大模型推理** | chain-of-thought = 隐变量推理 |

> 🎯 **博士级洞察**：PGM 不是过时技术——它是**深度学习很多方法的隐藏祖父**。

## 七、一句话总结

> 🎯 **四句话**：
> 1. PGM 用**图结构压缩高维分布**——三大派：BN（有向）/ MRF（无向）/ Factor Graph。
> 2. 推断三法：精确（变量消除/信念传播）/ 变分（ELBO）/ MCMC（采样）。
> 3. **VAE / 扩散都是 PGM 的现代版**——ELBO 是变分推断的直接后代。
> 4. PGM 在大模型时代**依然根本**——它是理解深度生成模型的钥匙。
