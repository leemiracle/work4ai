# A03 — 开放问题：大模型时代的 PGM

> 「讲透概率图模型」收官。[00](../00-概率图模型是什么.md) §结尾问过"大模型时代的 PGM 还有什么用"；本篇正面回答——四条活着的前线 + 一条哲学余响。

---

## 1. 前线一：LLM 推理 = PGM 推理？

[00](../00-概率图模型是什么.md) 的对照表已经埋了钩子：**CoT = 隐变量推理**。

- LLM 直出答案 = 点估计；CoT 把隐变量链显式写成 token——每步推理是给隐变量赋值
- 形式化：把"推理"看作在隐变量图上的后验搜索 $P(\text{结论}|\text{证据})$，CoT/ToT/SC = 不同调度策略（→ [`激活大语言模型能力-总结.md`](../../激活大语言模型能力-总结.md) §3.4 机制视角）
- 开放问题：LLM 的隐式推理能恢复 PGM 的**全局一致性**吗？（自回归的局部贪婪 vs 图的全局推断——证据双向：CoT 有效但会编造推理链）

## 2. 前线二：概率化 LLM（uncertainty & calibration）

- LLM 输出的"概率"校准差（verbalized confidence ≠ 真实后验）：PGM 的校准/共轭工具回炉
- 贝叶斯 LLM / Laplace 近似 / 深度集成的理论根都在 VI（[A01](A01-变分推断的几何.md) 的几何照用）
- 幻觉的一种 PGM 解释：模型对 $P(\text{事实}|\text{上下文})$ 与 $P(\text{流畅}|\text{上下文})$ 混淆——显式分离这两个因子是结构化方案的原点

## 3. 前线三：神经符号与显式图回归

- 神经符号系统（→ [`讲透神经符号/`](../../讲透神经符号/)）：LLM 出提议，符号层（PGM/SAT/求解器）保全局一致性——"LLM 提意图，确定性层做决定"（[用例库](../../用例库/README.md)横断公理）的数学版
- 知识图谱 + 概率语义：Problog/PSL 一脉在 LLM 时代反而活跃（LLM 抽取事实，PGM 管一致性）

## 4. 前线四：世界模型中的 PGM

- [00](../00-概率图模型是什么.md) 的开放问题"PGM 在 world model 中的角色"：状态空间模型（SSM/卡尔曼家族）正在 Transformer 内复活（→ [`讲透模型可能性/02-LinearAttention`](../../讲透模型可能性/02-LinearAttention.md)：线性注意力=隐状态递推=连续 DBN）
- 因果世界模型：LeCun JEPA 之外，因果图学派主张世界模型必须有显式因果结构（→ [`讲透世界模型/advanced/04`](../../讲透世界模型/advanced/04-开放问题与研究方向.md) + [`讲透因果推断/`](../../讲透因果推断/)）

## 5. 哲学余响：图作为"理解"的语法

三代范式对"模型里有什么"的回答：

| 范式 | 可读性 | 位置 |
|---|---|---|
| 符号规则 | 全可读，不可学 | GOFAI |
| PGM | 图可读（结构=独立性），因子可学 | 1988-2012 |
| 深度网络 | 全可学，不可读 | 2012- |

**PGM 是唯一同时拥有"结构可解释 + 参数可学习"的世代**——这正是它在可解释性与因果推断中不可替代的原因。当机械可解释性（→ [`讲透模型宇宙/07`](../../讲透模型宇宙/07-机械可解释性.md)）试图给深度网络"重新长出图结构"（SAE 特征图、回路图），某种意义上是在把第三代翻译回第二代。

> **收官结论**：PGM 作为"主流建模工具"的时代结束了；作为"推断算法库（BP/EM/采样）、几何视角（ELBO/投影）、可解释语法（图=独立性）"的时代没有结束。学 PGM 不是怀旧，是给当代模型配上 X 光。
