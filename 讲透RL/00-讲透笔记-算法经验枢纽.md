## §0 全局视角：RL = "在反馈中学习决策"

```
RL = Agent（决策器）
   + Environment（环境）
   + Reward（反馈信号）
   + Policy（决策策略 π）
   + Value（长期价值估计 V/Q）
```

> 🔑 **核心 DNA**：RL 与监督学习根本不同——**没有"正确答案"，只有"好/坏反馈"**。这让它能解决"无法标注但能评估"的任务（游戏、对话、推理）。

## §1 十条算法经验

### 算法经验 RL1：探索 vs 利用的永恒权衡

> RL 的根本两难：
> - **Exploit**：用已知最优动作（短期收益）
> - **Explore**：试新动作（长期可能更好）
>
> 解法谱系：ε-greedy / UCB / softmax 探索 / intrinsic motivation / curiosity-driven。

可迁移：所有"动态决策"场景都有这个权衡（推荐、广告、A/B 测试）。

### 算法经验 RL2：策略梯度定理 = log-derivative trick

> $$\nabla_\theta J = \mathbb{E}[\nabla_\theta \log \pi(a|s) \cdot G]$$
>
> 这是 ML 最重要的数学技巧之一：**把"概率的期望"变成"对数概率的加权和"**——可微、低方差、易采样。

可迁移（应用 #7 配分函数消去）：
- **变分推断**的 reparameterization trick
- **GAN** 的 generator 梯度
- ** diffusion** 的 score matching

### 算法经验 RL3：方差缩减是 RL 训练的核心工程

> REINFORCE 方差极大，无法训练。三阶段降方差：
> 1. **Baseline**：减去 V(s)（无关常数）
> 2. **优势函数**：A(s,a) = Q(s,a) - V(s)
> 3. **GAE**：广义优势估计（bias-variance 权衡）
>
> 算法本质：**用"相对好坏"代替"绝对好坏"**（应用 Ch9 #8 三段式）。

### 算法经验 RL4：PPO 的 clip 是工程杰作

> PPO 用 `clip(ratio, 1-ε, 1+ε)` 限制策略更新幅度——**简单、稳定、可扩展**。
>
> 算法本质：**信任域约束的近似实现**（比 TRPO 简单 10×，效果相当）。
>
> 这是 OpenAI 的工程胜利——**简单胜过精巧**（应用 #6 KL 约束极大化 → Gibbs）。

### 算法经验 RL5：Actor-Critic = 2-tower 的 RL 版（强化 R4 双塔）

> Actor（策略）+ Critic（价值）= 双塔架构。
>
> 这与推荐的双塔（user 塔 + item 塔）、检索的双塔（query 塔 + doc 塔）**同构**——都是"两个网络协作"的设计模式。

### 算法经验 RL6：RLHF 的算法本质（深化 Ch9）

> RLHF = SFT + RM + PPO。**RM 学的是"偏好标量"，PPO 优化的是"策略概率"**——两者通过 RL 闭环。
>
> DPO 通过重排，**跳过 RM 直接从偏好学策略**——应用 #7（配分函数消去）的典范。

### 算法经验 RL7：GRPO 的创新 = 群组相对优势

> DeepSeek 的 GRPO：用一个 prompt 采样 N 个回答，**用群组内的相对优势代替 value 网络**——省一个模型。
>
> 算法本质：**用"采样群组"代替"学习的 critic"**（应用 R7 用排名做融合）。
>
> 这是 R1（DeepSeek-R1）训练的核心算法。

### 算法经验 RL8：RLVR（RL with Verifiable Rewards）

> 当任务**有可验证的奖励**（数学有答案、代码能编译、证明能 lean 验证），RL 训练极其有效。
>
> 算法本质：**反馈信号的"可验证性"决定了 RL 的天花板**——这是 R1/o1 的核心秘密。

可迁移（应用 T8 评测盲区、F5 任务难度档）：
- **数学推理**：Lean/Coq 验证
- **代码生成**：单元测试验证
- **定理证明**：形式化验证

### 算法经验 RL9：MDP = 时序决策的数学语言

> MDP（马尔可夫决策过程）= (S, A, T, R, γ) 五元组。它是**所有时序决策问题的统一抽象**：
> - 对话系统（DC3 DST = POMDP）
> - 机器人控制
> - 游戏 AI
> - 推荐（multi-step 推荐）
> - 自动驾驶

可迁移：任何"状态→动作→奖励→新状态"的任务都是 MDP。

### 算法经验 RL10：Offline RL vs Online RL

> - **Online RL**：边探索边学（如 AlphaGo）
> - **Offline RL**：从固定数据集学（如 DPO 从偏好对学）
>
> 算法本质（应用 T6 端到端 vs 流水线）：**数据来源决定算法选择**——Online 探索性强但不稳定，Offline 稳定但不探索。
