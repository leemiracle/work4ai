## 一、RL 和监督学习的本质区别

### 1.1 一张表看懂

| 维度 | 监督学习（SL）| 强化学习（RL）|
|------|--------------|--------------|
| 数据 | $(x_i, y_i)$ 有标签 | 只有奖励信号 $r$，没有"正确动作" |
| 目标 | 拟合 $y = f(x)$ | 最大化累计奖励 $\sum \gamma^t r_t$ |
| 反馈 | 即时（每条样本）| **延迟**（一局游戏结束才知道输赢）|
| 决策 | 单步预测 | **序列决策**（当前动作影响未来）|
| 探索 | 不需要 | **核心难题**——要试错才知道哪个动作好 |

> 🎯 **一句话**：监督学习是"**有标准答案的考试**"，RL 是"**没有答案、只能试错、最后给个总分的生活**"。

### 1.2 为什么 RL 难

1. **延迟反馈（credit assignment）**：一局围棋 200 步，最后输了——**哪一步走错了？** 这是 RL 的核心难题
2. **探索 vs 利用（exploration-exploitation）**：是去常去的好餐厅（利用），还是试新餐厅（探索，可能更好也可能更差）？
3. **数据分布会变**：你改了策略，未来的状态分布就变了——监督学习的数据是固定的，RL 的数据是自己"生成"的

### 1.3 为什么 RL 在 LLM 时代复兴

2012-2020 RL 的代表是 AlphaGo/游戏 AI，离大众远。2022 后三件事让 RL 重新成为核心：

1. **ChatGPT 的 RLHF**（2022）：让 LLM 从"续写"变成"对话助手"——RL 是那块关键拼图
2. **DeepSeek-R1 的 GRPO**（2025）：纯 RL（不需要 SFT）训出 reasoning 能力，震惊业界
3. **Agent 时代**：LLM 调工具、做规划，本质是序列决策——RL 是 Agent 的理论基础

## 二、MDP：所有 RL 问题的统一语言

### 2.1 MDP 五元组

所有 RL 问题（围棋、机器人、LLM 对齐）都能抽象成**马尔可夫决策过程（MDP）**：

$$
\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, R, \gamma)
$$

| 符号 | 含义 | 例子（围棋）| 例子（LLM 对齐）|
|------|------|-----------|---------------|
| $\mathcal{S}$ | 状态空间 | 棋盘局面 | prompt + 已生成内容 |
| $\mathcal{A}$ | 动作空间 | 下一步落子位置 | 下一个 token |
| $P(s'\|s,a)$ | 转移函数 | 对手回应 | 生成模型本身的概率 |
| $R(s,a)$ | 奖励函数 | 赢 +1/输 -1 | 人类偏好打分 |
| $\gamma$ | 折扣因子 | 0.99 | 1（无折扣）|

**马尔可夫性质**：未来只依赖当前状态，不依赖历史——$P(s_{t+1} | s_t, a_t, s_{t-1}, ...) = P(s_{t+1} | s_t, a_t)$。这让问题可解。

### 2.2 策略、值函数、回报

**策略**（policy）$\pi(a|s)$：在状态 $s$ 下选动作 $a$ 的概率。RL 的目标就是找最优策略 $\pi^*$。

**回报**（return）$G_t$：从时刻 $t$ 开始的累计折扣奖励：

$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + ... = \sum_{k=0}^{\infty} \gamma^k R_{t+1+k}
$$

**状态值函数** $V^\pi(s)$：在状态 $s$、按策略 $\pi$ 行动的期望回报：

$$
V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]
$$

**动作值函数** $Q^\pi(s,a)$：在状态 $s$ 做动作 $a$、之后按 $\pi$ 的期望回报：

$$
Q^\pi(s,a) = \mathbb{E}_\pi[G_t | S_t = s, A_t = a]
$$

> 🔑 $V$ 和 $Q$ 的关系：$V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s,a)$。RL 的两大流派就是分别学 $Q$（值函数方法）或直接学 $\pi$（策略方法）。

### 2.3 Bellman 方程——RL 的"牛顿定律"

所有 RL 算法的根基。把 $G_t$ 拆成"即时奖励 + 下一状态的值"：

$$
\boxed{V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma V^\pi(s') \right]}
$$

**直觉**：当前状态的价值 = 所有动作的（即时奖励 + 下一状态价值）的期望。

**最优 Bellman 方程**（取 max 而不是期望）：

$$
V^*(s) = \max_a \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma V^*(s') \right]
$$

> 🎯 **一句话**：Bellman 方程把"求无穷步的回报"分解成"即时奖励 + 下一状态"——这是所有 RL 算法的递归根基，就像反向传播是深度学习的根基。

## 三、两大流派

### 3.1 值函数方法（Q-Learning 家族）

**思路**：先学 $Q^*(s,a)$，然后策略 $\pi(s) = \arg\max_a Q^*(s,a)$。

- 代表：Q-Learning → DQN → Rainbow
- 适合：**离散动作**（棋类、Atari 游戏）
- 详见 [01 Q-Learning/DQN](./01-Q-Learning与DQN.md)

### 3.2 策略方法（Policy Gradient 家族）

**思路**：直接学 $\pi_\theta(a|s)$，用梯度上升最大化期望回报。

- 代表：REINFORCE → TRPO → **PPO** → RLHF 用的就是 PPO
- 适合：**连续动作 + 大规模**（机器人、LLM）
- 详见 [02 策略梯度/PPO](./02-策略梯度与PPO.md)

### 3.3 两者对比

| 维度 | 值函数（Q-Learning）| 策略（Policy Gradient）|
|------|-------------------|----------------------|
| 学什么 | $Q^*(s,a)$ | $\pi_\theta(a\|s)$ |
| 动作空间 | 离散好 | 连续/离散都行 |
| 方差 | 低（off-policy）| 高（on-policy）|
| 样本效率 | 高（能重放经验）| 低（每条经验用一次）|
| LLM 时代 | 不用（动作空间太大）| **主流**（PPO/GRPO）|

> 📌 **关键**：LLM 的动作空间是词表（~10 万 token），太大且连续语义——所以 **LLM 对齐几乎全用策略方法**（PPO/GRPO）。值函数方法主要留在游戏/机器人。

## 四、RLHF 复兴：RL 怎么进入 LLM

### 4.1 三阶段（InstructGPT/ChatGPT，2022）

```
① SFT（监督微调）     ：用人写的高质量回答微调 LLM
        ↓
② 奖励模型（RM）      ：用人类偏好对（A > B）训一个打分模型
        ↓
③ PPO（RL 微调）      ：用 RM 的分数当奖励，PPO 优化 LLM
```

详见 [03 RLHF/DPO/GRPO](./03-RLHF-DPO-GRPO.md)。

### 4.2 2024-2026 的演化

| 方法 | 时间 | 创新 |
|------|------|------|
| **RLHF（PPO）** | 2022 | RM + PPO，ChatGPT 用 |
| **DPO** | 2023-05 | **直接偏好优化**——不要 RM，直接用偏好对训，数学等价 RLHF |
| **GRPO** | 2024（DeepSeek）| **去掉 critic**，用组内相对优势，省一半显存 |
| **纯 RL（R1-zero）** | 2025（DeepSeek-R1）| 不要 SFT，纯 GRPO 训出 reasoning |

**趋势**：从"重 RM + PPO"到"轻量/无 RM + 高效"。详见 03 篇。

## 六、一句话总结

> 🎯 **三句话**：
> 1. RL 学"怎么做决策拿最多奖励"，和监督学习（学"是什么"）本质不同——难点在延迟反馈 + 探索 + 数据分布会变。
> 2. 所有 RL 问题是 MDP 五元组，Bellman 方程是递归根基（像反向传播之于深度学习）。
> 3. LLM 时代让 RL 复兴：RLHF（PPO）→ DPO（去 RM）→ GRPO（去 critic）→ 纯 RL（R1-zero），全在策略路线上。
