### 主题 ② · RLVR & Reasoning RL（o1 → R1 → RLVR 极限）

**核心进展**：RLVR（RL with Verifiable Rewards）是 2024-2026 reasoning model 的训练范式。奖励是"答对=1/答错=0"的可验证奖励（数学/代码题有标准答案）。

**两大阵营**：
- **正方**：DeepSeek-R1 / Kimi-1.5 / o1 用 RLVR 训出强 reasoning
- **反方**：[Limit of RLVR](https://arxiv.org/abs/2504.13837)（NeurIPS 2025 Oral）证明 RLVR 只是"分布锐化器"——pass@1 赢 base，但 pass@k（大 k）被 base 反超

**关键论文**（全部一手核实）：
| 论文 | arXiv | 核心结论 |
|------|-------|---------|
| DeepSeek-R1 | [2501.12948](https://arxiv.org/abs/2501.12948) ✅ | GRPO + RLVR 训 reasoning，开源里程碑 |
| **Limit of RLVR** | [2504.13837](https://arxiv.org/abs/2504.13837) ✅ | NeurIPS 2025 Oral，RLVR 是锐化器不是发现器 |
| Diversity Collapse（反-反方）| [2606.15455](https://arxiv.org/abs/2606.15455) ⚠️ | 争论中，认为 overtraining 掩盖了 gain |

**项目内对应**：
- 🟢 [05-RLVR的极限](./05-RLVR的极限.md)（完整的 pass@k 反转论证 + 6 算法对比 + 数学根因 + 工程含义）
- 🟢 [04-RL与形式证明](./04-RL与形式证明.md)（Limit of RLVR 在形式化域的延伸）

**缺口**：o3 / Gemini 3 Deep Think 的 RL 配方细节（闭源未公开，靠 [`访谈姚顺宇`](../访谈及其他/张小珺访谈精读/第140集-姚顺宇-在Anthropic与Gemini训模型.md) 的内部视角拼凑）。

### 主题 ③ · RL 训练加速（让 RLVR 更快更省）

**这是 2026 最热的工程方向**——RLVR rollout 太贵，所有工作都在"用更少 rollout 提取更强信号"。

**关键工作**（项目内 [`高效AI前沿-全行业热点地图`](../高效AI前沿-全行业热点地图.md) §六已整理）：

| 工作 | 来源 | 核心创新 | 效果 |
|------|------|---------|------|
| **ARRoL** | ACL 2026 | 在线 rollout 剪枝（轻量 quality head 预测 + 早剪枝 + 重平衡）| **1.7× 训练加速** + 准确率 +2.3~2.99 |
| **OM-GRPO** | 2026 | **label-free RLVR**（mask answer span 梯度，防 reward hacking 答案 token）| test-time training 比 majority vote **+4.24** |
| **Spec-RL / FastGRPO** | 2026 | speculative decoding 加速 rollout 生成 | 工程加速 |
| **FlashRL / QeRL** | 2026 | 低精度/量化 rollout | 工程加速 |

**核心矛盾**（来自 [`高效AI前沿`](../高效AI前沿-全行业热点地图.md) 洞察 5）：RLVR 需要大量 rollout（贵）↔ 训练信号稀疏（很多 rollout 全对/全错，弱信号）。2026 的工作都在"**少 rollout 强信号**"——这决定 reasoning model 能不能平民化训练。

**项目内对应**：🟢 [`高效AI前沿-全行业热点地图`](../高效AI前沿-全行业热点地图.md) §六（agent RL 加速）+ §十（热点速查表）

### 主题 ④ · Test-Time Compute Scaling（新的 scaling 维度）

**核心论断**（[Noam Brown](https://en.wikipedia.org/wiki/Noam_Brown_(computer_scientist)), Stanford CS224R 2026 / OpenAI）：reasoning model 开辟了 scaling 的新维度——**推理算力**。从 o1（秒级）→ o3（分钟级）→ IMO 金牌（小时级）→ scaffold（天/周级）。

**三种 test-time scaling 范式**：

| 范式 | 机制 | 代表 | 特点 |
|------|------|------|------|
| **单轨迹顺序** | 延长单一推理链 | DeepSeek-R1 / s1 budget forcing | 串行，延迟瓶颈 |
| **叶级并行** | 采样多候选 + 投票/验证 | Best-of-N / self-consistency | 并行，compute 效率低 |
| **前缀级并行** | 搜索未完成部分状态 | Tree-of-Thoughts / RAP / value-guided | 最强但最贵 |

**2026 关键工作**（ACL 2026，项目内 [`高效AI前沿`](../高效AI前沿-全行业热点地图.md) §三）：
- **PaCoRe**（Parallel Coordinated Reasoning）：8B 模型靠**多轮并行探索 + message-passing 协调**，HMMT 2025 达 **94.5% 超 GPT-5 的 93.2%**——有效 TTC 扩到 ~200 万 token
- **Timely Machine**：把 test-time 从"生成长度"重定义为 **wall-clock time**（agent 场景工具延迟使两者脱钩），训 **Timely-RL** 让模型感知时间预算
- **多 Agent 推理**：debate / mixture-of-agents 在等 compute 预算下比 self-consistency **+1.3~2.7 点**

**Brown 的战略洞察**：inference compute 被严重低估——今天 $1M 的能力明年可能 $100。**安全评估必须 project test-time compute**（dedicated state actor 可花 $10M 推理）。

**项目内对应**：🟢 [`高效AI前沿-全行业热点地图`](../高效AI前沿-全行业热点地图.md) §三 + 🟢 [`高效AI前沿-2025-2026顶会精选`](../高效AI前沿-2025-2026顶会精选.md)（KV 压缩换推理 token）

**缺口**：Brown 的 CS224R 完整讲义未公开抓取（建议关注 [Stanford CS224R](https://cs.stanford.edu/people/noambrown/)）。

### 主题 ⑤ · RL + 形式化证明（AlphaProof 后时代）

**核心进展**：RL + Lean4 形式化证明是 2024-2026 RL 最风光也最争议的赛道。AlphaProof 拿 IMO 2024 银牌后，开源三强把 miniF2F 刷到饱和——但 [Limit of RLVR](./05-RLVR的极限.md) + atp-checkers 揭露 RL 增益被高估。

**关键进展**（项目内 [04](./04-RL与形式证明.md) 深度覆盖）：

| 工作 | arXiv | 战绩 | 角色 |
|------|-------|------|------|
| **AlphaProof** | [Nature 2025-11](https://www.nature.com/articles/s41586-025-09833-y) ✅ | IMO 2024 银牌（28/42）| 范式确立者 |
| **DeepSeek-Prover V2-671B** | [2504.21801](https://arxiv.org/abs/2504.21801) ✅ | miniF2F 88.9% | 开源 GRPO + 子目标 |
| **Goedel-Prover V2-32B** | [2508.03613](https://arxiv.org/abs/2508.03613) ✅ | miniF2F 90.4%（ICLR 2026）| 开源 scaffolded 数据 |
| **Seed-Prover**（字节）| [2507.23726](https://arxiv.org/abs/2507.23726) ✅ | miniF2F **99.6%**（饱和）| VAPO + 猜想池 |
| **Delta-Prover**（字节）| [2507.15225](https://arxiv.org/abs/2507.15225) ✅ | **95.9%**（零微调）| 通用 LLM + DSL + agent |

**🚨 2026 的反方发现**（项目内 [04](./04-RL与形式证明.md) §五）：
- **atp-checkers**（[2606.29493](https://arxiv.org/abs/2606.29493) ✅）：5 个 Lean 基准共 **398 个机械可证缺陷**；DeepSeek-Prover-V2 的 3 个"证明"实为假证明
- **miniF2F-v2**（[2511.03108](https://arxiv.org/abs/2511.03108) ✅, NeurIPS 2025）：端到端真实精度仅 **36%**（非头条的 90%+）
- **FormalRewardBench**（[2605.10141](https://arxiv.org/abs/2605.10141) ✅）：专门 prover 判别能力反而**最差 24.4%**

**收敛结论**：**生成 ≠ 判别**。RL prover 会找任何验证漏洞，二元 Lean reward 只判"证明是否被接受"不判"规则是否建模真实语义"。

**项目内对应**：🟢 [04-RL与形式证明](./04-RL与形式证明.md)（完整覆盖）+ 🟢 [`讲透形式化验证`](../讲透形式化验证/)（Lean4 背景）+ 🟢 [`讲透神经符号`](../讲透神经符号/)（AlphaProof 式闭环）

### 主题 ⑦ · World Model（Dreamer 谱系 → Genie 2 → 具身 world model）

> ⚠️ **本节部分内容基于训练知识，未当场联网核实。建议用 `zread` / `paper-mastery` skill 复核 arXiv ID。**

**核心进展**：World Model（学习环境的动力学模型用于 planning/想象）是 model-based RL 的核心。2024-2026 因视频生成模型成熟而大爆发。

**演化时间线**：
```
2018 World Models (Ha & Schmidhuber)      — VAE + MDN-RNN + 简单 controller
   ↓
2019 Dreamer (Hafner)                     — latent imagination，RSSM
   ↓ Dreamer V2 (2021) / Dreamer V3 (2023, 统一 scaling)
2024.12 Genie (DeepMind)                  — 从视频学可控 game engine
   ↓
2024.12 Genie 2 (DeepMind)                — 单图生 3D 可交互世界
   ↓
2024-2025 DIAMOND (ETH)                   — diffusion 作 world model
   ↓
2025-2026 具身 world model：
   - 机器人 world model（Levine / Koushil）⚠️
   - 视频生成模型作 world model（Sora / Veo）⚠️
   - Genie 系列后续 ⚠️
```

**关键论文**（部分待核）：
| 工作 | 来源 | 角色 |
|------|------|------|
| **Dreamer V3** | Hafner et al. 2023 ✅（已知）| 统一 scaling 的 world model，跨越 150+ 任务 |
| **Genie** | DeepMind 2024-01 ✅（已知）| 从无标注视频学可控 game engine |
| **Genie 2** | DeepMind 2024-12 ✅（已知）| 单图生 3D 可交互世界，基础 world model |
| **DIAMOND** | ETH 2024 ⚠️ | diffusion 作 world model |
| **IRIS / Transformer World Models** | ⚠️ | Transformer-based world model |

**2026 的核心问题**：

### 主题 ⑧ · VLA & 具身 RL（机器人 RL 的 LLM 时代）

## §7 一句话总结（截止 2026-08-12 的 RL 全景）

> 🎯 **七句话**：
> 1. **地基不变**：MDP / Bellman / 值函数 / 策略梯度（[00](./00-为什么RL与MDP.md) [01](./01-Q-Learning与DQN.md) [02](./02-策略梯度与PPO.md)）——100 年数学根基。
> 2. **方法成熟**：DQN / PPO / SAC / model-based（[01](./01-Q-Learning与DQN.md) [02](./02-策略梯度与PPO.md)）——10 年 Deep RL 工具箱。
> 3. **LLM RL 是 2024-2026 最大热点**：RLHF → DPO → GRPO → DAPO（[03](./03-RLHF-DPO-GRPO.md)）——ChatGPT/DeepSeek-R1 的核心。
> 4. **RLVR 是 reasoning model 的引擎，但是"锐化器"不是"发现器"**（[05](./05-RLVR的极限.md) NeurIPS 2025 Oral）——pass@k 反转，AIME24 上 RLVR 能解而 base 不能的问题 = 0.0%。
> 5. **2026 的核心矛盾是 RLVR 太贵**：ARRoL/OM-GRPO/Spec-RL 都在"少 rollout 强信号"（主题 ③）——决定 reasoning model 能否平民化。
> 6. **Test-time compute 是新 scaling 维度**（Noam Brown）：o1→o3→小时级，安全评估必须 project 推理算力（主题 ④）。
> 7. **生产系统里纯 DRL 是"生产弃儿"**（[06](./06-RL与系统软件.md)）：AlphaEvolve 进化算法 > RL，因为可审计性 > reward 高。
