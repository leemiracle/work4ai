# 📐 第 2 幕 · 数学：复杂系统的核心数学

## 1. 幂律（Power Law）：复杂系统的指纹

$$P(x) \propto x^{-\gamma}$$

幂律意味着「**无典型尺度**」（scale-free）——大大小小的事件都有，没有特征大小。

**为什么幂律如此普遍**：
- **优先连接**（Barabási-Albert）：富者愈富 → 网络度分布幂律
- **自组织临界**（Bak）：系统自发到临界 → 雪崩大小幂律
- **相变临界**：关联长度发散 → 临界指数幂律

**测幂律的方法**：log-log 图上线性。但小心——少量数据点容易假拟合。需用 Clauset 等人的极大似然法（2009）。

**复杂系统的判据**：如果某系统的多个量（事件大小、度、寿命）都服从幂律，**它可能在临界点**——这是 SOC 的标志。

## 2. 网络科学

### 小世界（Watts-Strogatz 1998）
$$L \sim \log N \quad (\text{平均路径}), \quad C \gg L \quad (\text{聚类系数高})$$

少量「长程连接」让网络既高聚类又短路径。社交网、神经网络、互联网都是。

### 无标度（Barabási-Albert 1999）
度分布 $P(k) \propto k^{-\gamma}$（通常 $2 < \gamma < 3$）。少数 hub 连接大量节点。

**生成机制**：优先连接 $P(\text{连到 } i) \propto k_i$——新节点倾向连已有连接多的节点。

**鲁棒性悖论**：对随机失效极鲁棒（大部分节点度小，失效影响小）；对针对性攻击脆弱（干掉几个 hub 系统崩）。

## 3. 相变与临界指数

Ising 模型的序参量（磁化）随温度：

$$m(T) \propto (T_c - T)^\beta \quad (T \to T_c^-)$$

$\beta$ 是**临界指数**。**普适性**：不同系统（水、磁铁、人流）在临界点附近有相同的临界指数——只依赖维度和序参量维度（普适类）。

**关联长度发散**：$\xi \propto |T-T_c|^{-\nu}$。临界点处局部扰动影响任意远——这就是相变时「蝴蝶效应」的来源。

## 4. 混沌（Chaos）

Logistic map：$x_{t+1} = r x_t(1-x_t)$。
- $r < 3.57$：收敛到不动点/周期
- $r \approx 3.57$（Feigenbaum 点）：分岔到混沌
- **混沌区**：对初始条件敏感——**Lyapunov 指数 $\lambda > 0$**

$$|x_t - x_t'| \approx |x_0 - x_0'| e^{\lambda t}$$

$\lambda > 0$ 意味着小偏差指数放大——「蝴蝶效应」。

**混沌边缘**（Langton）：$\lambda \approx 0$ 时计算/适应最优。**复杂系统据推测运行在 $\lambda \approx 0$**。

## 5. 熵（已见 `故事原语/02`，这里补充网络熵）

Shannon 熵 $H = -\sum p \log p$。对网络：

$$H_{\text{deg}} = -\sum_k P(k) \log P(k)$$

度分布越均匀熵越高（混乱）；越集中熵越低（秩序）。**健康复杂系统的熵在中间**（临界）。

## 6. 自由能原理（Friston）

$$F = \underbrace{-\mathbb{E}_q[\ln p(o \mid m)]}_{\text{精度（负）}} + \underbrace{D_{KL}(q(m) \| p(m))}_\text{复杂度}$$

**最小化 F = 最大化精度 + 最小化复杂度**。Friston 主张：**任何持久系统都在最小化自由能**——生命、大脑、社会、（我们主张）知识系统。

**与 LLM 的连接**：next-token prediction 就是最小化预测误差 = 最小化自由能。**LLM 是自由能最小化机器**。

## 7. 标度律（West-Brown-Enquist）

生物学的 WBE 标度律：代谢率 $B \propto M^{3/4}$。3/4 来自分形输送网络的几何。

**LLM scaling law**（Kaplan 2020）：loss $\propto N^{-\alpha}$（参数）$\propto D^{-\beta}$（数据）$\propto C^{-\rho}$（算力）。

**两者同构**：都是**底层网络结构决定的标度**。生物是分形血管，LLM 是 Transformer 架构。

## 8. 同步（Strogatz）

振子耦合自发同步（萤火虫闪烁、心脏起搏、鼓掌）。

Kuramoto 模型：
$$\dot\theta_i = \omega_i + \frac{K}{N}\sum_j \sin(\theta_j - \theta_i)$$

耦合强度 $K$ 跨过 $K_c$，系统从无序跃迁到部分同步——**相变**。

**与多 agent 的连接**：多 agent 系统的「共识」就是同步。

## 🎬 本幕收束

> 复杂系统数学 = 幂律（指纹）+ 网络（拓扑）+ 相变（跃迁）+ 混沌（敏感）+ 熵（测度）+ 自由能（原理）+ 标度律（规律）+ 同步（协调）。**它们在不同领域反复出现，因为复杂系统都在临界点附近**。
