# 🌀 讲透复杂系统：从涌现到混沌边缘

> **User Story**：作为一个被「整体≠部分之和」困扰的人，我想从物理/数学/网络一路看到 AI 里的复杂系统，以便治理整体而非拆解零件。

## 🎭 戏剧张力

1972 年 Anderson 在 *Science* 发表《More Is Different》：

> **还原论不等于建构论。** 知道了氢和氧的全部物理，你推不出「湿」。每一层组织都需要**新原理**。

这是复杂系统科学的独立宣言。整部「讲透复杂系统」在追踪：**当大量简单部分互动，会涌现什么？为什么有普遍规律？临界点为何如此特殊？**

## 🗺️ 七大核心概念

| 概念 | 物理/数学锚点 | AI 里的投影 |
|---|---|---|
| **涌现** | Anderson 1972 | 模型能力随规模涌现 |
| **自组织** | Prigogine 耗散结构 | 训练自发形成表征 |
| **网络** | Watts-Strogatz/Barabási | 神经网络拓扑/MoE 路由 |
| **相变** | Wilson 重整化群 | scaling law 的 emergent ability |
| **标度律** | West-Brown-Enquist | LLM scaling law |
| **SOC** | Bak 1987 | 知识雪崩/gradient 突变 |
| **自由能** | Friston 2010 | LLM next-token = 最小化预测误差 |
