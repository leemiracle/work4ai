# 🚀 第 5 幕 · 应用：复杂系统在 AI 里的七大投影

## 1. Emergent Abilities（涌现能力 = 相变）
Wei 2022 发现：模型规模跨过阈值，某些能力**突然出现**（如思维链推理）。
**复杂系统视角**：这是**相变**——序参量（能力）从 0 跃到非 0，临界点关联长度发散（小 prompt 扰动影响大）。
**启示**：涌现能力不可从模型成分（参数/层）预测，必须整体观察。

## 2. Scaling Law（标度律）
Kaplan 2020 / Chinchilla 2022：loss ∝ compute^α。
**复杂系统视角**：标度律是复杂系统的指纹（West-Brown-Enquist 在 LLM 的投影）。**底层架构（Transformer）决定了标度**，正如血管分形决定了生物代谢标度。
**启示**：架构变（如 MoE/线性 attention）会改标度指数——这是 SambaNova/Mistral 等 MOE 的理论赌注。

## 3. Double Descent（双下降）
Belkin 2019：模型越大，测试误差先降后升再降——经典 bias-variance 的反例。
**复杂系统视角**：非线性动力系统的分岔/振荡。**「过拟合」概念在双下降区失效**。

## 4. Neural Scaling 的网络拓扑
大脑皮层是小世界网络。LLM 的注意力矩阵是全连接（非小世界）。
**启示**：稀疏/MoE 架构可能更接近生物网络拓扑，从而有更好的标度。

## 5. Multi-Agent 涌现
LangGraph/AutoGen/Swarm：多个 LLM agent 互动，涌现出集体行为。
**复杂系统视角**：这是**swarm**（`讲透群体智能/`）。临界、多样性、防群体幻觉——复杂系统原则直接适用。

## 6. LLM = 自由能最小化机器
Next-token prediction = 最小化预测误差 = 最小化 Friston 自由能。
**复杂系统视角**：LLM 是复杂系统科学里**自由能原理**的实现。
**启示**：世界模型（`讲透世界模型/`）= 学到的「内部模型」用于预测 = FEP 的核心。

## 7. 训练动力学 = 动力系统
Loss landscape = 能量景观（崎岖，自旋玻璃式）。
- SGD = 模拟退火（带温度的下降）
- Batch size = 温度的倒数
- Learning rate schedule = 退火曲线
**复杂系统视角**：训练 = 在崎岖景观里找全局最优。**模拟退火策略直接适用**——周期性升温逃离局部最优。

## 八条工程启示（复杂系统 → AI 实践）

1. **规模到相变点**：能力涌现需要跨阈值。不够大就别期望 emergent ability。
2. **稀疏 + 模块化**：小世界/MoE 拓扑可能比全连接更优。
3. **训练用退火**：周期性升温（增 batch noise / 学习率涨落）逃离局部最优。
4. **多 agent 要多样性**：同质 agent → 群体幻觉。异构才稳健。
5. **守临界**：探索（高 T）和固化（低 T）交替，别永远单相。
6. **防紧耦合**：系统越大越要模块化，否则局部失效雪崩。
7. **幂律是健康标志**：事件大小服从幂律 → 系统在 SOC（有创造力）。
8. **预测分布而非点**：复杂系统不可精确预测，做概率预测。
