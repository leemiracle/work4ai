# 讲透科学革命观念史 · 从静力学宇宙到数学化:观念断裂还是连续谱系

> **定位句**:这支负责讲清 16-17 世纪那场"科学革命"的**观念内容**——从亚里士多德的目的论宇宙(自然位置/性质变化)到伽利略的数学化自然(《试金者》1623:"自然之书用数学语言写成")到牛顿的综合(1687),断的到底是什么;以及"科学革命"这个概念本身怎么被科瓦雷一代造出来、又被连续性论战拆开——**断裂还是连续,是本支的元争论**。
> **自定主干支声明**:GB/T 13745 无「科学技术史」一级(宇宙按学位目录 0712 自定);本支为家族自定主干支。家族:[讲透科学思想史](../README.md)。

## 诞生

观念史写法始于迪昂《中世纪宇宙论体系》(1913-1959,遗著十卷):从中世纪手稿挖出布里丹冲力说,主张"革命不革命"(连续论题);科瓦雷《伽利略研究》(1939)用同一批史料写断裂;黄金一代确立"科学革命"为西方思想最大转折(巴特菲尔德《近代科学的起源》1949、霍尔《科学革命》1954);迪杰克赫伊斯《世界图景的机械化》(1950)给出"机械化"总账;夏平《科学革命》(1996)开篇翻案:"从来就没有什么科学革命"——概念史本身成为研究对象。

## 核心问题(带年代锚)

- 断裂的内容清单:宇宙论(封闭世界→无限宇宙,科瓦雷 1957)/运动观(性质变化→位置变化)/方法(思辨→数学+实验)——骨架已立
- 连续 vs 断裂:迪昂连续论题 vs 霍尔断裂论战(1954)——悬而未决
- 哥白尼的保守性:《天球运行论》(1543)保留本轮体系,为何仍算革命起点——概念史进行中
- "长科学革命"说:窗口拉到 14-18 世纪则"革命"散架——窗口即立场(家族窗口眼的支内主场)
- 第二次科学革命(19-20 世纪)是否同构——进行中,本支管到 1687+余波,断代接口归科技通史(波 4 在建)

## ✨ 这支最美的一个事实

1543 年《天球运行论》的匿名序言是出版商奥西安德尔私加的:宣布"日心只是方便计算的数学假设,不是物理真理"——哥白尼本人的序言(致教皇保罗三世)则坚持天文学是关于真实宇宙的学问。**一本书自带两篇互相打架的序言**:观念断裂时代的自我保护策略,被出版商的"安全声明"抢了话筒。今天判断"作者真信什么",版本学比哲学更硬——观念史考据的第一课。

## 假设与依赖

概念史以文本为中心(纸面革命≠实验室革命,家族假设①);1543-1687 的窗口是通说选样,"长革命"改写边界;翻译链(希腊-拉丁-各现代语)的概念漂移必须标注;教会语境的体制互动面归[科学与宗教关系史支](../讲透科学与宗教关系史/)与科技社会史(波 4 在建)。
