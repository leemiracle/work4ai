# 讲透科学方法论史 · 归纳-演绎-假说-证伪-贝叶斯的五棒接力

> **定位句**:这支负责讲清"科学方法"这个观念自己的历史——方法不是科学的常量,是接力棒:亚里士多德的归纳-演绎双轨,培根的排除归纳法(1620),笛卡尔的演绎之路(1637),牛顿的"不作假说"宣言,休谟的归纳难题(1739),惠威尔的一致论,皮尔士的溯因,波普尔的证伪(1934),贝叶斯复兴(1954-)——每一棒都宣称解决了上一棒,而每一棒的失效现场就是下一棒的起点站。**方法论史=方法自身的病历**。
> **自定主干支声明**:GB/T 13745 无「科学技术史」一级(宇宙按学位目录 0712 自定);本支为家族自定主干支。家族:[讲透科学思想史](../README.md)。

## 诞生

亚里士多德《工具论》立归纳(epagoge)与演绎(apodeixis)双轨;培根《新工具》(1620)以"蚂蚁-蜘蛛-蜜蜂"讽单纯经验与单纯思辨,立排除归纳法;笛卡尔《方法谈》(1637)立演绎四规;牛顿《原理》(1687)"我不杜撰假说"挑起假说之战;休谟《人性论》(1739)捅破归纳无辩护;十九世纪归纳逻辑建制(赫舍尔、惠威尔《归纳科学哲学》1840、穆勒《逻辑体系》1843);皮尔士提出溯因(约 1877-1903);波普尔《研究的逻辑》(1934)以证伪回应休谟;拉卡托斯(1970)以纲领调解;萨维奇《统计学基础》(1954)开启贝叶斯复兴,豪森-厄尔巴赫《科学推理:贝叶斯进路》(1993)把它送进方法论正典。

## 核心问题(带年代锚)

- 归纳辩护问题(休谟 1739):未决——贝叶斯是工程回应非哲学了结
- "不作假说"之争:牛顿本人用没用假说(万有引力的超距性质)——已立:口号与实践的两张脸
- 证伪判据的过窄与过宽(占星术式的"可证伪姿态"骗过判据)——悬而未决
- 溯因的地位:皮尔士"猜的本能"是方法论还是心理学——进行中
- 贝叶斯是不是归纳的救赎:旧证据问题/先验主观性/频率-贝叶斯之争——进行中(形式面归[统计学的统计学史](../../../讲透统计学/讲透统计学史/))
- 方法的规范 vs 科学家的实际行为(方法论自然主义转向)——进行中

## ✨ 这支最美的一个事实

惠威尔的"一致论"(consilience,1840):归纳的支持度不是加法,是**跳变**——开普勒的定律、伽利略的落体、月亮的潮汐,三条独立的归纳线在牛顿引力律上会合的那一刻,理论可信度的增量大于三条证据之和。惠威尔的比喻:证据不是把石头堆上山,是把拱顶石放进拱——**放进去之前每块石头都在滑落,放进去之后整座拱自己站住**。这个十九世纪的直觉,今天活在贝叶斯确证的"旧证据问题"争论里:一条好理论的本事,是让原本互不相干的事实变得相关。

## 假设与依赖

"接力"叙事自带辉格风险(实际科学家混用方法,方法论文献≠实践——家族假设④的支内主场);规范层论证正主在[哲学·自然辩证法](../../../讲透哲学/讲透自然辩证法/);归纳与概率的形式工具正主在[逻辑学·归纳逻辑](../../../讲透哲学/讲透逻辑学/讲透归纳逻辑/)与[数学宇宙](../../../讲透数学/README.md)。
