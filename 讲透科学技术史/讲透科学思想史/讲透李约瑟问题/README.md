# 讲透李约瑟问题 · 为什么近代科学不在中国发生——争论史本体

> **定位句**:这支负责讲清一个问题七十余年的争论史——李约瑟在《中国科学技术史》(SCC)导言提出的成对之问:为什么在把人类自然知识应用于实际需要方面,中国曾长期领先欧洲,而近代科学(数学化+实验方法的科学)却诞生在欧洲、没有在中国发生?本支不卖答案,经营**争论史本体**:制度说、思想说、经济地理说、反问题路线各自的长处与软肋,以及这个问题本身的构造方式(把"未发生"当作需要解释项的反事实结构)。
> **自定主干支声明**:GB/T 13745 无「科学技术史」一级(宇宙按学位目录 0712 自定);本支为家族自定主干支。家族:[讲透科学思想史](../README.md)。

## 诞生

李约瑟(Joseph Needham,1900-1995),剑桥生物化学家(化学胚胎学学部奠基),1937 年与中国留学生鲁桂珍的交往使他把研究重心转向中国科学史;SCC 第一卷 1954 年问世,至 1995 年出至七卷数十册,身后由合作者续完。导言即问题宣言:既要解释中国为何长期领先(第一问),又要解释近代科学为何缺席(第二问)——李约瑟自己的答案雏形是社会经济取向(官僚封建制抑制了商人阶级与实验-数学结合的可能)加思想取向(中国有机自然观缺少"自然法则由立法者制定"的观念传统)。

## 核心问题(带年代锚,争论史格式)

- **制度说**:科举吸纳智力资源/大一统缺乏欧洲式多国竞争/重农抑商——进行中
- **思想说**:名墨逻辑传统中断/伦理优先于自然探究/有机自然观与数学化路径不合——进行中
- **经济地理说**:伊懋可"高水平均衡陷阱"(1973)——人口-资源结构使省力创新无利可图;彭慕兰《大分流》(2000)把问题改写为"为什么是英格兰"(煤炭与殖民地资源的偶然)——进行中
- **反问题路线**:席文(Sivin,1982)的经典反问——把"没发生"当需解释项,隐含欧洲路径为常态的反事实预设;史学上"未发生的事"原则上不可单独解释——方法论批判已立,问题仍在被研究(争论史自己的辩证法)
- 红线纪律:以上按学术争论史呈现各方,**不引申文明优劣论**;问题的构造方式(反事实/欧洲中心预设)本身是本支的一级研究对象

## ✨ 这支最美的一个事实

李约瑟的学术转身本身:一位在生物化学领域已功成名就的皇家学会会员(《化学胚胎学》三卷 1931),因为认识了几位中国科学家而开始学汉语、跑战时中国(1943-1946 年任英国驻华科学联络处主任),再用四十一年写一部没有尽头的大书——SCC 的索引与目录体系本身成为一座学科基建。**一个问题的最好命运是被一个人用一生来问**:争论史的第一页不是答案,是这场转身。

## 假设与依赖

反事实结构:为什么"没发生"需要解释而"发生了"不需要?——元问题贯穿全支;"近代科学"的定义先行(数学化+实验方法的标准本身来自欧洲个案);SCC 汉译与文献考订的依赖(中国科技史料考据正主在科技考古与文献家族,波 4 在建,文字提及);术语译名(官僚封建制/有机自然观)的概念漂移须标注。
