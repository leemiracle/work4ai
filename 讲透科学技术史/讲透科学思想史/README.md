## 四、教材锚

- 惠威尔《归纳科学史》(1837,三卷——"科学史"成为一门学问的起点;
  "scientist"一词的造词人)
- 迪昂《物理学理论的目的与结构》(1906)与《中世纪宇宙论体系》
  (1913-1959,遗著十卷——整体论与连续论题的双料源头)
- 波普尔《研究的逻辑》(1934;英译《科学发现的逻辑》1959)
- 库恩《科学革命的结构》(1962;1970 第二版附《后记》)
- 拉卡托斯《科学研究纲领方法论》(1970 论文,1978 文集)
- 李约瑟《中国科学技术史》(SCC,1954-1995,七卷;导言即问题宣言)
- 科瓦雷《伽利略研究》(1939)与《从封闭世界到无限宇宙》(1957)
- Shapin《科学革命》(1996——开篇"从来就没有什么科学革命")
