# 03 · 可构造与结构——范式图、比较结构与规则集:观念作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:科学思想史里"可构造"的不是思想本身,而是
> **观念的组织方式**——范式是带四成分的概念图、理论选择是
> 多准则比较结构、研究纲领是规则集+账本、方法论史是接力线;
> 而"结构"是这门学科自己的骨架:五棒接力、常规-反常-危机-
> 革命四段循环、问题转移的进步/退化判定。

---

## 0. 开篇:把《结构》压成一张图

库恩 1970《后记》亲手把"范式"拆成可检查的四件东西:符号概括
(F=ma 式的共享公式)、形而上学承诺("宇宙由粒子构成"式的
世界图景)、价值(精确/一致/广泛/简单/富饶)、范例(教科书
习题的示范解法)。这四件东西**每件都可列表、可对勘、可跨范式
比较**——"范式"从修辞性大词变成数据结构的距离,只隔一步
结构化。本章就是把这一步走完:观念的组织方式变成 schema,
观念的变迁变成时间线,观念的争论变成比较结构。

## 1. 什么是"可构造"的:六类观念对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **范式记录** | 概念图(四成分+共同体边界) | ✅ 高度可构造(库恩自己拆的四件) | 共同体边界谁划:引文网络近似(自引≠认同) |
| **理论比较结构** | 多准则决策表(五价值×两理论) | ✅ 可构造 | 五价值加权=价值排序,排序即立场,必须声明 |
| **方法论规则集** | 规则库(纲领=硬核+启发法) | ✅ 可构造(§1.5) | "硬核不可反驳"是约定,输入谁定硬核就归谁——参数=史观 |
| **纲领账本** | 时间线(预测/解释事件序列) | ✅ 可构造 | 进步/退化只能事后评估,窗口选择决定结论 |
| **概念谱系** | DAG(概念-文本-引文边) | ✅ 可构造(04 章 C1) | "影响"动词的违规高发区(02 章 §2.6) |
| **复现统计结构** | 概率模型(功效×发表门槛) | ✅ 完全可构造(家族实验) | 零模型口径必须标注,不得冒充实证 |

**不可构造的**:顿悟(第一人称体验,孤证不可外推)、"影响"的
因果强度(传播链可考,强度不可称)、不可通约的"程度"(框架
选择不是测量量)、"革命真发生了吗"的裁定(断裂/连续是透镜
不是事实层)、以及规范判断本身(什么"应该"算好科学——
那是[自然辩证法·科学哲学](../../讲透哲学/讲透自然辩证法/讲透科学哲学/)的正主)。

### 1.5 四类对象的最小数据模式(动手者的 schema)

```yaml
# 范式记录(库恩 1970《后记》四成分的结构化)
paradigm: {name: str, community: str, period: [起, 止],
           generalizations: [str],      # 符号概括(F=ma)
           commitments: [str],          # 形而上学承诺
           values: [精确, 一致, 广泛, 简单, 富饶],   # 五价值(权重另行声明)
           exemplars: [str],            # 范例(教科书示范解)
           source_tier: T1..T6}

# 理论比较记录(多准则结构;加权即立场)
comparison: {theory_a: str, theory_b: str, year: int,
             scores: {精确: [a 得分, b 得得], ...},   # 序数,非基数
             weighting_declared: bool}   # 未声明加权的表不可入正文

# 纲领记录(拉卡托斯三件套)
programme: {name: str, hard_core: [str],       # 不可反驳的约定
            protective_belt: [str],            # 可修改的辅助假设
            heuristics: {positive: [str], negative: [str]},
            ledger: [ {year: int, event: str, kind: 预测|解释} ],  # 账本
            verdict_window: [起, 止],           # 评估窗口(结论的敏感参数)
            source_tier: T1..T6}

# 概念记录(概念谱系 DAG 的节点)
concept: {term: str, lang: zh|en, sense: 判例|母体|滥用义,   # 02 章对译表
          first_use: {year: int, text: str, version: str},
          edges: [ {to: 概念, kind: 传承|平行|误读, chain: str} ]}  # 影响条款
```

注意 `version` 与 `chain` 两个必填项:把 02 章的语言纪律(版本
声明/影响链条)写进数据结构——**数据层自带版本与链条义务,
是观念史计算区别于普通文本分析的第一特征**(与法律史学/军事史
家族"数据层自带证据等级"同款纪律)。

## 2. 骨架一:五棒接力结构(方法论史的组织)

00 章 ASCII 图的数据形态:每棒=一个方法论方案,带三字段——
**回答**(归纳出规律/猜想与反驳/…)、**靶刺**(它要拔掉上一棒
的哪根刺:休谟问题/归纳独断…)、**失效现场**(它自己被下一棒
拔掉的刺:迪昂-奎因/辅助假设逃逸/暴民心理学…)。这个三字段
结构让"方法论史"成为可检查的表而非故事:任何新方法论主张
(今天的"贝叶斯超推断/机器经验主义")入表前必须填满三字段
——**没有靶刺的主张不是方法论,是口号**。

## 3. 骨架二:常规-反常-危机-革命四段循环

| 段 | 可观测信号 | 数据代理 |
|----|-----------|---------|
| 常规科学 | 教科书统一、解谜论文主导 | 范例引用集中度 |
| 反常 | 解谜失败被搁置、特设修补 | 辅助假设增殖率(账本 kind=解释 占比) |
| 危机 | 学派分裂、哲学论文激增、跨范式引用 | 共同体引文网络极化 |
| 革命 | 教科书改写、老文献重新归档 | 术语更替率+教科书版本 |

四段循环是**解读框架**不是自然类别:同一时期可同时有"常规"
领域与"危机"领域;断代敏感性(把窗口挪十年,四段边界移动)
与军事史"换锚重跑"同款——使用时必须声明窗口。

## 4. 骨架三:问题转移账本(进步/退化的判定结构)

拉卡托斯账本的最小可计算形态:每个纲领一条时间线,事件分
**预测**(先预言后被证实,加分)与**解释**(事后补课,不加
分);滑动窗口内预测占比持续高=进步,持续低=退化。三个构造
警告:

1. **窗口=结论**:太短的窗口人人进步,太长的人人退化——
   评估窗口是敏感参数,必须随结论声明
2. **预测的认定**:"预测"是否先于证据,考据成本极高
   (拨浪鼓式的"事后预言家"是账本的头号污染源)
3. **账本不裁生死**:拉卡托斯明言退化纲领可能复活——
   账本给的是**理性的事后重建**,不是科学家的实时指令
   (这正是 01 章 Rubin 镜头把复现失败放进"常规数据点"的
   结构依据)

## 5. 从结构到比较:这套骨架买到了什么

- 五棒接力表 → 任何新方法论主张的入门检查(靶刺三字段)
- 四段循环 → 共同体状态的诊断框架(危机的社会信号清单)
- 账本结构 → 复现危机事件的定位器(单失败=数据点,模式化
  退化才=危机——01 章热线的结构面)
- 范式四成分 → "范式转换"滥用的过滤器(四件都没变的,
  只是大变化,不是范式转换)

## 6. 构造合法性清单(动手前三问)

把任何观念史材料变成数据结构之前,先过三问——本家族的
"类型检查":

1. **版本齐了吗**:概念节点带 first_use 版本了吗?
   ——不带版本的"范式"节点会把 1962/1970/1974 三代混进
   同一个节点(库恩自己最想避免的事)
2. **链条齐了吗**:每条"影响"边有最小传播链吗?
   ——没有 chain 的边自动降级为"平行"
3. **声明齐了吗**:加权、评估窗口、共同体边界的划法,
   三个敏感参数写进数据集头部了吗?——换参数换结论,
   不同声明的数据集不可直接拼接比较

三问全过,数据才获得进入 [04 章走廊](04-科学思想史转代码.md)
的资格。**观念史计算的第一特征不是算法,是版本与链条义务**
——这一条把它与普通文本挖掘划开界河。

## 📌 收束

可构造的是**组织方式**(范式图/比较表/规则集/账本/谱系),
不可构造的是**顿悟、影响强度与革命裁定**;结构不是装饰,
是给"危机""革命""进步"这些大词装上分辨率。下一章把 schema
接上代码:引文-概念谱系、复现统计结构等走廊:
[04-科学思想史转代码](04-科学思想史转代码.md)。

**🧠 认知升维**:

- **四成分眼**:听到"范式转换"先数四件(概括/承诺/价值/范例)
  ——四件都没动,就只是大变化
- **靶刺眼**:评估方法论主张先问三字段——回答什么、拔谁的刺、
  自己的刺在哪;填不满的不是方法论
- **窗口眼**:一切"进步/退化"结论先看评估窗口——窗口即立场
