# 04 · 科学思想史转代码——谱系、账本与统计结构的最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。

> 网络、纲领评估变时间线账本、复现危机变功效×发表门槛的
> 零模型;**唯一不可外包给代码的,是观念判断本身**

## 0. 开篇:三条教科书直觉的机器检验

「文献里的效应量被发表门槛抬高了」「复现失败说明造假泛滥」
「范式转换这个词被用烂了」——三个流行论断,能不能让机器先算
一遍再下结论?

`experiments/replication_structure.py` 用零模型回答前两个:
一个人人诚实、只有"显著才发表"一条规矩的世界,自动长出
已发表效应量夸大 1.5×(断言①)、复现成功率随效应量/样本双降
(断言②)、六成复现失败与方向翻转(断言③)——**"危机"的
相当一部分是统计结构的形状,不需要任何人道德败坏**。
但脚本同时打印零模型声明:参数=教学选择,输出不指涉任何真实
文献群。**代码替你算结构,替不了你判语境**——科学思想史
数字化的第一课。

## 1. 可机械化边界(三件套之一)

**能进代码的**(观念数据化后的一切结构计算):

| 任务 | 机械化形式 |
|------|-----------|
| 概念谱系追踪 | 文本-引文网络 → 传播链子图、术语历时频率 |
| 范式结构检查 | "范式转换"宣称 → 四成分逐项比对(03 章过滤器) |
| 纲账本评估 | 纲领事件时间线 → 滑动窗口预测占比曲线 |
| 复现统计结构 | 功效×发表门槛 → 赢家诅咒/双降律/失败基线(家族实验) |
| 五价值比较表 | 理论对 → 多准则排序枚举(枚举全部加权方案) |
| 术语对译校验 | 译本语料 → 关键词对齐冲突报告 |

**不能进代码的**(本学科的"不可判定域"):

1. **版本与语义裁定**——1962/1970/1974 三代"范式"的分寸,
   机器能标年份,分寸仍是文献学的活
2. **影响认定**——传播链的机器候选(共现+引用)只是线索;
   "谁真的读了并接受"永远需要人证(02 章影响条款)
3. **革命裁定**——四段循环的窗口选择、断裂/连续的透镜选择,
   是史学判断;机器只能做敏感性分析(换窗口重跑)
4. **划界立场**——可证伪度/可复现性作为判据的规范辩护,
   是[科学哲学](../../讲透哲学/讲透自然辩证法/讲透科学哲学/)的正主;
   代码只呈现判据的后果,不辩护判据本身

> 边界的一句话:**代码是观念史的检证器,不是裁判官**。
> 谱系图跑十遍,不如版本对勘读一次。

## 2. C1 引文-概念谱系走廊(最小示例)

```python
# 概念谱系的最小结构:传播链检查(02 章 §2.6 影响条款的机器面)
CHAIN = [  # 迪昂 → (中介) → 科瓦雷:传承与分歧并存的最小案例
    dict(frm="迪昂《中世纪宇宙论体系》", to="迈耶中世纪力学研究",
         kind="史料供给", evidence="手稿考据系列"),
    dict(frm="迈耶中世纪力学研究", to="科瓦雷《伽利略研究》",
         kind="引用+反驳", evidence="科瓦雷引用其史料,反驳其连续结论"),
]

def influence_check(edges):
    """传播链检查:凡 kind 含'影响'的边,evidence 必须给出最小链。"""
    bad = [e for e in edges
           if "影响" in e["kind"] and not e.get("evidence")]
    assert not bad, f"无证据传播链:{bad}"
    return len(edges)

assert influence_check(CHAIN) == 2
print("谱系走廊:每条边带证据,链条可检查——'影响'不再靠气势")
```

十行完成的事:一条观念史断言 → 带证据的边表。扩展方向:
接 01 章 SEP 条目的参考书目,把"迪昂-奎因""库恩-SSK"几条
主链做成带 T 级的可查子图。史学红线:边只到"史料供给/引用/
反驳"这种**可考动作**,不到"影响"——影响是人脑的收尾动作。

## 3. C2 复现危机统计结构走廊(✅ 已实现)

成品=[experiments/replication_structure.py](experiments/replication_structure.py)
(数据+断言一体,纯标准库 random/math):

- **断言① 赢家诅咒**:小样本×低先验领域,已发表观测效应
  夸大真效应(实测约 1.5×),同一先验放大样本后夸大消失
  (约 1.0×)——**效应量的文献分布是门槛的形状**
- **断言② 双降律**:3×2 网格上复现成功率逐格逼近解析功效
  Φ(d√n−1.96)(六个格差均 ≤0.007)——**复现成功率是设计
  变量,不是道德变量**
- **断言③ 失败≠造假**:零造假世界里,真效应研究复现失败
  ≈1−功效(实测 0.59);假阳性原件(零真效应混过门槛)复现
  方向翻转 ≈50%、"成功"率 ≈2.5%——**纯抽样波动即生产
  "危机"量级的失败结构**

走廊警告(与 C3/C4 共用):

1. **口径义务**:零模型输出必须随附"教学参数"声明,
   冒充实证是数字时代新型硬错误(00 章"模型化红线"同款)
2. **基线≠开脱**:基线解释"没有造假也有失败",不解释
   "基线之上的失败"——01 章 Feest/Rubin 争论的分界线
3. **单侧口径**:z≥1.96=双侧 0.05 且方向一致;换口径换数值,
   口径必须随代码声明

## 4. C3 纲领账本走廊(拉卡托斯的表最小化)

```python
LEDGER = [  # 纲领账本最小例:预测与解释两类事件
    (1687, "预测", "地球扁率/岁差由同一引力律给出"),
    (1758, "预测", "哈雷彗星按引力律回归"),
    (1846, "预测", "海王星从摄动反推先算后见"),
    (1859, "解释", "水星近日点进动'稍后处理'"),
]
def problemshift(ledger, window):
    """滑动窗口内预测占比:拉卡托斯进步/退化的序数代理。"""
    seg = [e for e in ledger if window[0] <= e[0] <= window[1]]
    return sum(k == "预测" for _, k, _ in seg) / max(1, len(seg))

r1 = problemshift(LEDGER, (1687, 1846))   # 牛顿纲领进步期:0.75
r2 = problemshift(LEDGER, (1859, 1859))   # 退化窗口:0.00
assert r1 > r2
print(f"账本走廊:窗口 [{1687},{1846}] 预测占比 {r1:.2f} > "
      f"窗口 [1859,1859] 的 {r2:.2f}——但换窗口换结论,窗口必声明")
```

此例的史学讽刺自带教学价值:牛顿纲领有大量"解释"事件(彗尾、
月球运动),事后账本永远比当事人宽裕——**账本是事后理性重建
(03 章警告三条),不是给科学家的实时评分**。

## 5. C4 术语历时频率走廊(滥用史的数据面)

"范式转换"滥用史(00 章反直觉①)的数据化路径:语料(期刊
全文/学位论文库)按年代切片 → "paradigm shift/范式转换"的
频率与共现词("管理/市场/政治" vs "科学/共同体")分布 →
**词义的漂移曲线**。本家族不内置数据(语料授权与清洗是工程
大头),给出走法:①频率曲线(词何时起飞)②共现漂移(词义
何时换域)③与 02 章对译表比对(哪层意思占上风)。红线:
频率度量"流行度",不度量"用对了"——用对率要人工抽样标注,
机器只供候选层。

## 6. 工程师落点

- **读文献的本能**:拿到"效应量"先问功效与发表门槛
  (家族实验断言①)——性能工程同款:A/B 测试的胜出组平均
  提升自带赢家诅咒,多吃一次复核再上量
- **多重比较免疫**:六个功能指标挑一个显著的汇报=
  家族实验里"显著才发表"的单研究版;预注册式的"先声明再看数",
  是方法论史给工程流程的直接馈赠
- **零模型习惯**:给任何"危机/异常"先算零模型基线
  (纯波动能产多少),再定位剩余——复现危机走廊的通用化

## 📌 收束

四条走廊:谱系(C1)管"谁传给谁",统计结构(C2)管"危机有多少
是结构",账本(C3)管"纲领算不算进步",词频(C4)管"术语
怎么漂移";四条共用一条边界——**版本、影响、窗口、立场永远
留在人脑**。跑到这里,回头再看 00 章那句钉住本质的话:科学
思想史给"科学怎么知道自己在对"写编年;代码能替你算编年的
形状,编年还得文献学来签。

**🧠 认知升维**:

- **零模型眼**:看到"危机/异常/失败率"先问纯结构基线——
  基线之上的部分才值得解释
- **口径眼**:任何统计断言先查口径(单双侧/窗口/加权)——
  口径即立场,随代码声明
- **检证器眼**:代码是检证器不是裁判官——机器出候选层,
  版本、影响与裁定由人收尾
