# 讲透科学与宗教关系史 · 冲突论/复杂论之争——两本书打了一百年的仗

> **定位句**:这支负责讲清"科学与宗教必然冲突吗"这个观念的历史与它的史学论战——德雷伯《宗教与科学的冲突史》(1874)与怀特《科学-神学论战史》(1896)立"冲突论"正典;二十世纪修正路线以"复杂论"回应(布鲁克 1991:既非必然冲突亦非笼统和谐,每个案例都得拆开看)。伽利略事件、达尔文反应史、布鲁诺案是三块试金石。**本支管观念争论史;教会建制/教育体制的互动面归科技社会史(波 4 在建)**。
> **自定主干支声明**:GB/T 13745 无「科学技术史」一级(宇宙按学位目录 0712 自定);本支为家族自定主干支。家族:[讲透科学思想史](../README.md)。

## 诞生

冲突论的史学正典由两本书立起:化学家德雷伯(1874)把教会写成科学的系统性压迫者;历史学家怀特(1896)以"论战史"体例给出弹药库(伽利略/布鲁诺式的案例串),"冲突模型"随两书畅销成为大众常识。二十世纪中叶起修正:林德伯格与纽姆伯格编《上帝与自然》(1986)重建中世纪-近代科学与神学的多线互动;布鲁克《科学与宗教》(1991)立"复杂论题"——范畴本身就是历史产物(科学的/宗教的作为成对范畴,很大程度是十九世纪冲突论的遗产);《伽利略进监狱了吗》(2010)逐条拆解流行神话(伽利略实为软禁而非入狱;布鲁诺因神学异端受审,日心说非其主要罪名——通说,案卷级 T2/T3)。

## 核心问题(带年代锚)

- 冲突论为何在 1870 年代成书:维多利亚时局(教皇绝无谬误谕 1870 的论战气候)与科学职业化——语境研究已立
- 伽利略事件的再解读:学术政治/圣经解释权/人物冲突的多因结构——复杂论读法已立,内情仍在细化
- 达尔文反应史:英国教会反应光谱化(反对/有神进化论/自由派神学),"开战"叙事不成立——已立
- "边界作业"(boundary-work):双方如何在争论中**定义**什么算科学、什么算宗教(Gieryn 1983 概念)——进行中
- 两范畴的历史性:前近代行动者不以"科学与宗教"二分自居——范畴考古进行中
- 红线纪律:涉及当代信仰议题一律按学术争论史呈现各方,教科书式中性学术语体,不作信仰评价

## ✨ 这支最美的一个事实

1615 年伽利略给克里斯蒂娜大公夫人的信,写下被冲突论与复杂论共同引用的第一文本:"圣灵的意图是教导我们如何上天堂,而不是天堂如何运转"(此句本出自巴罗尼奥枢机,伽利略引作靠山)。**同一句话,冲突论读出"划界宣言",复杂论读出"体制内辩护"**——伽利略不是在向教会宣战,是在用教会的权威资源为哥白尼辩护。一个文本养活两派一百年:观念争论史的最佳解剖标本。

## 假设与依赖

案例选样偏置:冲突案例更可叙述,合作与互不干涉的日常不上书(家族幸存者偏置的支内版);"宗教"作为单数范畴的简化(教派差异巨大);译名与教制术语(绝无谬误/异端审理)的规范使用;体制互动(教会与大学/教育建制)正主在科技社会史(波 4 在建,文字提及)。

## 教材锚

- 德雷伯《宗教与科学的冲突史》(1874)、怀特《科学-神学论战史》(1896)——作为**史料**读(冲突论正典本身是论战文献)
- 林德伯格、纽姆伯格编《上帝与自然》(1986);布鲁克《科学与宗教:若干历史视角》(1991——复杂论正典)
- 纽姆伯格等《伽利略进监狱了吗》(2010——神话修正手册)
- 原典:伽利略《致克里斯蒂娜大公夫人的信》(1615)
