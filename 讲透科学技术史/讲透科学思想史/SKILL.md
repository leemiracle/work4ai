# 科学思想史思维技能卡(0712 自定主干家族 · 讲透科学思想史的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「库恩的范式到底是什么」——术语三代制(1962/1970/1974)
  与四成分过滤器
- 「XX 是不是范式转换」——先数四件:符号概括/形而上学承诺/
  价值/范例;四件都没变=大变化不是范式转换
- 「这个理论被这个实验推翻了」——上迪昂-奎因整体论:
  被推翻的永远是"理论+辅助假设"整体
- 「科学和非科学怎么分界」——划界之争史(可证实→可证伪→
  判据多元),规范层去科学哲学
- 「复现失败率这么高,是不是造假」——先跑统计结构基线
  (功效×发表门槛零模型),再谈实践与激励
- 「李约瑟问题有答案了吗」——争论史本体:制度说/思想说/
  经济地理说/反问题路线按谱系呈现
- 「归纳法/证伪法/贝叶斯哪个对」——方法论接力眼:没有终点
  站,只有接棒与拔刺
- 「伽利略/达尔文是不是被教会迫害」——冲突论/复杂论之争,
  案例按史学通说拆解

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **接力眼** | 方法论主张=接棒:先问它拔谁的刺(靶刺三字段:回答什么/拔谁的刺/自己的刺) |
| **整体论免疫眼** | 单判决不可能——听到"一实验定生死",先问辅助假设在谁身上背锅 |
| **四成分眼** | "范式"拆四件逐项查——滥用义(=大变化)自动出局 |
| **版本眼** | 引库恩必带年代;不带版本的"库恩认为"默认不合规 |
| **链条眼** | "X 影响 Y"要最小传播链(谁在哪读了什么);给不出=平行 |
| **基线眼** | "危机"先算零模型基线——纯抽样波动贡献多少,基线之上才解释 |
| **窗口眼** | 一切进步/退化结论先看评估窗口;窗口即立场 |
| **双层眼** | 观念史叙事层(谁在何时怎么想)×方法论概念层(这算什么),隐喻落在哪层先分清 |

## 3. 工具箱(何时用什么)

- **五棒接力表**:归纳(培根/惠威尔)→假说-演绎→证伪(波普尔)
  →范式(库恩)→纲领+贝叶斯(拉卡托斯/萨维奇)——新方法论
  主张的入门检查器
- **四段循环**:常规→反常→危机→革命;危机的社会信号
  (学派分裂/哲学论文激增/教科书改写)
- **五价值表**:精确性/一致性/广泛性/简单性/富饶性——理论
  比较的多准则结构,加权必须声明
- **纲领账本**:硬核+保护带+启发法;预测占比作进步/退化的
  序数代理,窗口必声明
- **术语对译表**(02 章):paradigm/incommensurability/
  falsification/research programme 的陷阱(范式=判例不是大变化;
  normal=规范内不是正常;不可通约≠不可比较)
- **复现零模型**(家族实验 `experiments/replication_structure.py`):
  赢家诅咒/双降律/失败≠造假三断言,assert 自验证
- **断言阶梯 T1-T6 观念史版**:T1 引文级→T2 语境级→T3 谱系级
  →T4 通说(顿悟故事的天花板)→T5 逸闻→T6 反事实;
  影响宣称必须带最小传播链

## 4. 常见误区与禁忌

- ❌ **"范式转换"滥用**:管理/营销义(=随便什么大变化)冒充
  库恩义——四成分过滤器先过
- ❌ **把顿悟故事当心理学证据**:库恩 1947 顿悟是 T4 自述,
  不是"格式塔转换机制"的实证
- ❌ **影响胶水**:"A 影响了 B"无链条直写——观念史头号违规
- ❌ **基线开脱/基线恐慌两个方向**:零模型既不能证明"人人
  造假",也不能证明"无人造假"——它只给结构基线
- ❌ **辉格史观**:把失败理论写成蠢货——燃素与以太当年的
  合理性恰是理解观念变迁的钥匙
- ❌ **李约瑟问题引申文明优劣**:按学术争论史呈现,反事实
  结构(为什么"没发生")本身是元问题,不落地为文明判分
- ❌ 政治化素材转述夹带评价:方法论判据进入权力场(如援引
  复现危机的政策叙事)按来源客观转述,立场留给读者
