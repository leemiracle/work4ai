# 03 · 可构造与结构——建制、信任与政策链:科学的社会形态作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:科技社会史里"可构造"的不是"信任"或"自主性"
> 本身,而是**建制的可观测形态**——建制年表是点列、建制指标是
> 面板、信任调查是分波次的题项-量表结构、政策咨询是文档链条图;
> 而"结构"是三百年建制史自身的骨架:信任装置四段改版、资助
> 组合、政策接口类型学。

---

## 0. 开篇:一国科学建制是一张可填的表

打开 NSF《科学与工程指标》(Science & Engineering Indicators,
1972 年起两年一卷),你会发现一个国家的科学建制被填成了一张
表:R&D 经费与 GDP 之比、研究员人数、博士产出、资助渠道结构。
这张表的存在本身就是命题的证明:**建制可测量**。2018 年起
Wellcome Global Monitor、2025 年 68 国调查(01 章热线一)又把
"被信任程度"填成了新一列——信任也从修辞变成数据。本章的
任务:这些表怎么设计才合规,骨架怎么抽出才可比较。

## 1. 什么是"可构造"的:六类建制对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **建制年表** | 点列 {(年, 建制, 事件, 类型)} | ✅ 完全可构造(00 章四段骨架) | 断代=离散化;法定年与运作年分开(02 章 §3) |
| **建制指标** | 面板数据(国家×年×指标) | ✅ 高度可构造(弗拉斯卡蒂口径) | 口径不一致的面板不可拼接;Goodhart 律 |
| **信任调查** | 题项×量表×抽样×国家×波次 | ✅ schema 成熟(§1.5) | 跨文化等价性;极化藏在分布里不在均值里(01 章) |
| **政策咨询链** | 文档图(报告→委员会→决策) | ✅ 可构造(链条节点+边) | 链条可见性随保密程度骤降;越接近决策越难证 |
| **共同体网络** | 会员/通信/引文图 | ✅ 可构造(会员名录/通信集) | 名录是纸面建制,活跃度须另行代理 |
| **资助组合** | 拨款记录集(机构×机制×额度×年) | ✅ 可构造(账本最硬) | 混合资助时代"谁的钱"越来越难归一 |

**不可构造的**:科学自主性(没有函数)、信任的因果归因
(调查给分布不给机制)、规范的"真实性"(CUDOS 是应然还是实况
是解释之争)、以及"如果"的一切(T6 反事实——本家族实验的
极化模拟是零模型,不是历史重放,04 章边界)。

### 1.5 六类对象的最小数据模式(动手者的 schema)

```yaml
# 建制记录(建制年表的行)
institution: {name: str, kind: 学会|科学院|大学|实验室|资助机构|平台,
              found_year: int, charter_year: int,        # 法定年与运作年分开
              funding: 宫廷庇护|会费|基金会|国家预算|混合,
              trust_device: 绅士信用|期刊评议|panel 制|调查测度,   # 00 章四段
              region: str, source_tier: T1..T6}

# 信任调查记录(信任史支的正主对象)
trust_survey: {wave: str, year: int, country: str,
               item: str,                # 题项原文必存(02 章口径纪律)
               scale: str, sampling: str,          # 量表与抽样设计
               mean: float, dist_summary: {p10: float, p90: float},
               subgroup_means: [ {group: str, mean: float} ],   # 极化藏在子组
               source_tier: T1..T6}

# 政策咨询链节点(政策与公众支的对象)
policy_node: {doc: str, year: int,                # 如 布什报告 1945
              author_kind: 科学家|委员会|官僚|公众,  # 共识会议=公众作者
              output: 报告|建议|预算案|立法,
              edges: [上游节点], source_tier: T1..T6}
```

注意 `subgroup_means` 与 `item`/`scale` 的强制存在:把 02 章的
口径纪律与 01 章的极化眼写进数据结构——**只有均值的信任记录
是残废记录**;不带题项原文的调查数据不可二次比较(承军事史
03 章"数据层自带证据等级"同款精神,社会史版多了子组分布)。

## 2. 骨架一:信任装置四段表(00 章 §二的构造形态)

四段表不只是分期,是有内部规律的结构:

1. **账本先行律**:每段资助形态先出现,信任装置滞后一代补上
   (期刊评议晚于学会一个多世纪普及;panel 制与国家资助同步
   而普及迟于二战)——滞后=信任装置的制度建设期
2. **装置不删除律**:新装置叠加而不取代旧装置——今天绅士信用
   (声誉)仍在运作,只是被评议与调查包了三层;**信任装置史是
   地层学,不是更替史**
3. **危机驱动改版**:每次装置改版的触发器是信任事件(优先权
   之争催评审;战时保密催顾问委员会;造假风波催撤稿与复现
   建制;信任骤降催调查)——危机是装置的选型压力

## 3. 骨架二:资助组合与增长结构

- Price 增长律的构造形态:建制指标(论文数/科学人口)的指数
  段与 logistic 饱和段——04 章 C2 走廊的最小实现
- 资助组合=自由探索/任务导向/设施平台三类拨款的配比;配比是
  政策接口的类型签名(布什型国家 vs 任务型国家 vs 混合型),
  只做序数比较,不做优劣裁定(02 章"不能说的")
- 中国线压缩样本:基金委(1986,自由探索+评议)与任务计划
  (863,1986,任务导向)同年设立——两类接口同年落子,是
  资助组合研究的天然对照(中性学科史陈述)

## 4. 骨架三:政策咨询链(线性模型→象限→使命)

- 链条的标准形状:**报告→常设委员会→预算/规制**;布什报告
  →NSF 是模板案例(报告造建制);PSAC→废除(1973)→重建
  (OSTP,1976)是链条可断可续的样本
- 接口类型学:线性模型(基础→应用)/巴斯德象限(应用激发
  基础)/使命导向(社会任务定义问题)——三代资助修辞的
  类型学,不是三段时间表(同代并存)
- 参与式节点的构造:共识会议把"公众"写进 author_kind——
  链条图里出现公众作者,是参与转向最干净的构造证据
  (政策与公众支)

## 5. 从结构到比较:这套骨架买到了什么

- 信任装置四段表 → 任何国家科学建制的"装置年龄"速查
  (中国线的压缩:四段在一百年内走完)
- 账本先行律 → 一切"资助改革"的先验检查单:钱改了,装置呢?
- 政策接口类型学 → 读任何资助机构年报的解码器
- 资助组合 → 国家比较的非评价坐标(避免"谁更好"的越权)

## 6. 构造合法性清单(动手前三问)

把任何建制材料变成数据结构之前,先过三问——本家族的
"类型检查":

1. **口径声明写了吗**:建制指标注明弗拉斯卡蒂口径与年度;
   信任数据注明题项/量表/抽样——无口径不入库
2. **子组分布齐了吗**:信任记录只有总均值一律退回;极化结构
   (子组均值/分位差)是第一公民(01 章热线一)
3. **纸面与运作分开记了吗**:章程年与运作年、纸面建制与
   活跃度代理变量分列——纸面建制≠运作建制(02 章 T1 警告)

三问全过,数据才获得进入 [04 章走廊](04-科技社会史转代码.md)
的资格。**社会史计算的第一特征不是算法,是入库纪律**。

## 📌 收束

可构造的是**建制的可观测形态**(年表/指标/调查/链条/网络/
账本),不可构造的是**自主性与信任的因果**;结构不是装饰,
是国家比较与装置诊断的坐标系。下一章把这些 schema 接上代码:
信任调查分析/建制增长曲线/参与式计数三条走廊:
[04-科技社会史转代码](04-科技社会史转代码.md)。

**🧠 认知升维**:

- **装置地层眼**:看到任何质量担保制度,先问它是哪一层的
  ——绅士信用/评议/委员会/调查叠了几层,哪层在承重
- **子组眼**:一切信任数字先看子组分布——均值是极化的
  遮羞布(实验断言①)
- **口径眼**:跨比较的建制数字,没有口径就没有意义
