## 0. 开篇:三个教科书论断的机器化

「总体信任高,但极化在扩大」「均值平稳恰恰可能掩盖分化」
「危机冲击后,低信任群体恢复更慢」——这三个来自 2024-2025
信任研究(01 章热线一)的结构性论断,能不能用最小模型说清楚?

`experiments/trust_polarization.py` 把它们做成可跑的结构课:
两个群体(初始信任不同),信息环境参数化——中性媒体(信号
只反映真相)vs 极化媒体+选择接触(媒体反映受众,个体对远方
信号打折)。三组断言:①中性环境组间差收敛,极化环境总体均值
平稳而组间差扩大;②选择接触反馈使组间差(近似)单调扩大
——回音室的机器化;③公共危机事件后,高信任组恢复快、
低信任组恢复慢(体制归因降低修复信号接受率),组间差超过
危机前——**危机放大既有分化**。

但脚本同时打印警告:这是**零模型**,不是历史重放;参数=史观
的同款纪律在此完全适用。代码替你算结构,替不了你查档案。

## 1. 可机械化边界(三件套之一)

**能进代码的**(建制数据化后的一切统计):

| 任务 | 机械化形式 |
|------|-----------|
| 信任调查聚合 | 均值+子组均值+分位差 → 极化指数(组间差/组内差) |
| 极化机制零模型 | 个体更新规则 → 均值/组间差时间序列(家族实验) |
| 建制增长拟合 | 指标序列 → 指数段/logistic 饱和段(C2) |
| 参与式科学计数 | 项目/贡献记录 → 参与规模与贡献分布(C3) |
| 政策链条图 | 报告-委员会-决策边 → 链条拓扑与断点年表 |
| 建制年表断言 | 事件点列 → 间隔序列与先行-滞后检验(账本先行律) |

**不能进代码的**(本家族的"不可判定域"):

1. **信任的因果归因**——调查与模拟给分布与结构,给不了
   "为什么"(选择效应/遗漏变量在门槛外等着)
2. **装置优劣裁定**——panel 制是否"好于"期刊评议不是计算
   问题;代码只能给两类装置的成本结构对照
3. **规范真伪**——CUDOS 是应然还是实况,是解释之争
   (思想史家族的地盘)
4. **政策建议**——"应该提高透明度"超出学科权限;建制史供
   先例与结构,不处方(与[科学学与科技管理](../../讲透管理学/讲透科学学与科技管理/README.md)
   的分工:彼处方,本家族病史)

> 边界的一句话:**代码是建制史的望远镜,不是传声筒**。
> 望远镜里看到的极化,不等于听诊器听到的民情。

## 2. C1 信任调查分析走廊(✅ 已实现)

成品=`experiments/trust_polarization.py`。核心参数表
(03 章 trust_survey 的机制版):

| 参数 | 含义 | 中性媒体 | 极化媒体 |
|------|------|---------|---------|
| media_endogeneity | 媒体反映受众的程度 | 0 | >1(放大) |
| selectivity | 选择接触强度(远方信号打折) | — | >0 |
| attribution | 危机后低信任组对修复信号的折扣 | — | <1 |

三组断言对准三个史学命题:均值掩盖极化(01 章极化眼)/回音室
(选择接触反馈)/危机不对称恢复(危机放大分化)。**读输出的
正确姿势:先看组间差序列,再看均值序列**——顺序反了就会被
均值安慰到(实验打印顺序即纪律)。

## 3. C2 建制增长曲线走廊(最小示例)

Price 增长律:建制指标指数增长直至饱和(logistic)。最小可运行
示例——用生成-拟合的闭环演示"指数幻觉":

```python
# Price 曲线最小课:指数段拟合会在饱和段系统性地高估未来
K, r, t0, n = 1000.0, 0.35, 20.0, 40            # 容量/增长率/拐点/步数
series = [K / (1 + math.exp(-r * (t - t0))) for t in range(n)]  # logistic 建制指标

def fit_exp_growth(xs, ys, upto):
    """对数斜率法:前 upto 段拟合指数增长率。"""
    k1 = math.log(ys[upto]) / xs[upto]           # 起点≈0 时的简化
    return k1

k_half = fit_exp_growth(list(range(n)), series, upto=t0 - 8)   # 只看指数段
doubling = math.log(2) / k_half                                 # 翻番期
assert series[35] < 0.9 * K < series[39]         # 饱和:后段逼近容量
assert doubling < 5.0, "指数段的翻番期看起来很快"
print(f"指数段翻番期 {doubling:.1f} 步;但第 39 步仅 "
      f"{series[39]:.0f}/{K:.0f} —— Price 饱和:外推者破产")
```

十行完成的事:一条 logistic 建制曲线 → 指数段与饱和段的分段
错觉。史学用途:检验"某国科研规模仍指数增长"之类宣称——
**先问容量 K 在哪,再谈增长率**(指标工程师的 03 章口径纪律
落地)。

## 4. C3 参与式科学计数走廊(最小示例)

公民科学的构造问题:参与规模与贡献分布。最小示例——贡献的
集中度(少数人做绝大多数分类):

```python
# 参与的幂律课:公民科学的贡献分布高度集中(众包通说结构)
weights = [1.0 / (i + 1) ** 1.5 for i in range(1000)]   # 幂律权重
total = sum(weights)
top10 = sum(weights[:10]) / total                        # 前 10 人占比
half_owner = next(j for j in range(1, 1000)
                  if sum(weights[:j]) / total >= 0.5)    # 一半贡献来自几人
assert top10 > 0.5, "前 10 名贡献者应占过半(集中度结构)"
assert half_owner < 100, "一半贡献来自不到百人"
print(f"前 10 人贡献 {top10:.0%};50% 贡献来自前 {half_owner} 人"
      "——参与规模≠参与均质,公民科学的双账本由此起算")
```

史学用途:01 章热线三的"参与换合法性"交易——账本上写的
"百万人参与",分布上是"百人主力";**参与度指标与贡献分布
必须并报**(03 章双账本的代码面)。

## 5. 工程师落点(三件套之三)

- **数据工程师**:接手调查 microdata(68 国调查/Wellcome)
  ——先跑 03 章三问(口径/子组/纸面-运作);极化指数(组间差
  与组内差之比)进默认报表,别只给均值
- **平台工程师**:参与式科学平台的计数设计——贡献分布天然
  幂律,"活跃用户数"是最容易自欺的指标;留存与贡献分位并报
- **指标工程师**:资助机构的资助组合看板——Goodhart 律在此
  全速运转(指标一旦成为目标,建制就会优化指标;承[科学学与
  科技管理 02 章](../../讲透管理学/讲透科学学与科技管理/README.md)
  的反身性分析对读)

**走廊三警告**(与 01 章测度循环同源):

1. 零模型不是预测:实验的极化结构用于解释机制,不用于预报
   任何国家的信任走势
2. 参数=史观:媒体内生化系数谁定,分化速度就归谁——引用
   模拟结果必附参数与敏感性
3. 分布先于均值:任何汇总统计之前,先看子组与分位——
   **这是本家族实验全部三条断言共享的一条纪律**

## 📌 收束

三条走廊:C1(已成)管"信不信、差多少",C2 管"长多快、
何时饱和",C3 管"谁在参与、做了多少";三条共用一条边界
——**归因、裁定、处方永远留在人脑**。跑到这里,回头再看
00 章那句钉住本质的话:每次账本升级,信任装置跟着改版;
代码能帮你算账本与装置的错位,社会契约还得史学来读。

**🧠 认知升维**:

- **零模型眼**:模拟的正确用法是"与史实对勘的对照物",
  不是"结论发生器"(与军事史兵棋走廊同款纪律)
- **容量眼**:读任何增长曲线先问 K(容量)再问 r(增长率)
  ——指数外推是建制史里的技术决定论
- **分布眼**:先子组后均值,先分位后总量——参与与信任的
  真相都住在分布的尾部
