# 科技社会史思维技能卡(0712 自定 · 讲透科技社会史家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「科学共同体是怎么组织起来的」「大科学怎么来的」——建制解剖
- 「公众为什么(不)信科学家」「信任危机是真的吗」——信任装置读法
- 「同行评议凭什么可靠」「评审能担保什么」——评议的边界
- 「公民科学是什么/算不算科学」「公众参与科学怎么做」——参与接口
- 「布什报告/线性模型/基础研究怎么进政策」——政策链条
- 「伽利略案=科学与宗教的战争吗」——冲突论解毒
- 信任调查数字可疑(均值很高/骤降/跨国比较)——极化眼+口径检查
- 建制年表/资助数据/调查微数据要做结构化——schema 级需求
- 学科学学/科技政策时缺历史地基——本家族是它们的病史档案

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **账本眼** | 看任何科学建制先问"钱从哪来、按什么流程给"——账本决定组织形态 |
| **装置眼** | 信任不是态度,是装置(身份→评议→委员会→调查);看"信任危机"先问"哪台装置在坏" |
| **滞后眼** | 信任装置改版滞后于账本升级——资助改革先问监督与评议补上了没有 |
| **极化眼** | 一切信任均值先看子组分布——均值平稳而组间差扩大是结构性坏消息 |
| **双层眼** | 建制叙事(发生了什么)与建制分析(意味着什么)分开读,中介词挂证据级 |
| **地层眼** | 信任装置叠加而不取代(绅士信用/评议/委员会/调查四层共存)——诊断先定哪层承重 |
| **反身眼** | 研究建制的学科自己也建制化;一切指标会被研究对象反向优化(Goodhart) |

## 3. 工具箱(何时用什么)

- **建制四段骨架**:学会(1660)→实验室(1810)→国家体系(1940s)→
  参与(1970s-)——任何国家科学建制的"装置年龄"速查表
- **信任装置四段表**:绅士信用/期刊评议/panel 制/信任调查——
  每段配套的资助形态与危机触发器(00 章 §二)
- **断言阶梯 T1-T6 社会史版**:T1 建制档案→T2 学会官方史(荣誉
  动机降半档)→T3 科学家回忆录(强降档)→T4 通说→T5 冲突论式
  神话→T6 反事实;动词即类型签名
- **四段式建制叙事语法**:设立→章程→账本→危机;**账本段是建制史
  的心脏**,设立段是动机叙事(最薄处)
- **调查数据三问**:口径(题项/量表/抽样)声明了吗?子组分布齐了吗?
  纸面建制与运作建制分开记了吗?
- **极化指数**:组间差与组内差之比——只报均值的信任记录是残废记录
- **家族实验** `experiments/trust_polarization.py`(零模型最小实现):
  均值掩盖极化/回音室单调分化/危机不对称恢复三组断言
- **政策接口类型学**:线性模型/巴斯德象限/使命导向——三代资助
  修辞并存,读年报的解码器

## 4. 常见误区与禁忌

- ❌ **冲突论复辟**:「科学与宗教打了几百年仗」——德雷伯-怀特(1874/
  1896)神话在专业史学已破产;伽利略案是建制管辖权之争(T5 叙事)
- ❌ **同行评议拜古**:「评议自古担保科学质量」——现代投稿-外审制
  普及于 20 世纪中叶,先成型于资助官僚制;「最古老的担保」是
  追溯性神话
- ❌ **均值直读**:把"平均信任度尚可"读成"没有信任问题"——
  极化藏在子组分布里(实验断言①)
- ❌ **调查当因果**:调查给分布不给机制;参与提升信任的口号
  先问选择效应
- ❌ **纸面=运作**:章程、年报、纪念文集都是应然文本;账本
  才是建制史最硬的证据
- ❌ 数字越权:涉具体国家的信任变化数字按来源客观转述,
  **不引申政治评价**(本家族红线)
- ❌ 零模型当预测:极化模拟解释结构,不预报任何国家信任走势
