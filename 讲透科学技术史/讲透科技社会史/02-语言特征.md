# 02 · 语言特征——建制叙事×建制分析的双层语法

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)**。
> **本质一句话**:科技社会史说两种语言——**建制叙事语言**
> (学会档案/章程/资助记录的记叙:谁设立、谁出钱、谁签字)与
> **建制分析语言**(分析语汇:共同体/规范/同行评议/信任装置/
> 政策接口);这门学科的全部手艺,就是让一段"NSF 于 1950 年
> 由法案设立"的记叙,与"国家资助把评议官僚化"的判断在同一篇
> 文章里各司其职、互不越权。

---

## 0. 开篇:优先权之争的第一份仲裁文书(1712)

📖 **故事框:皇家学会《通信集》裁决(1712)**。牛顿与莱布尼茨的
微积分优先权之争打到皇家学会,学会设委员会审查双方通信,出报告
《Commercium Epistolicum》——注意它裁决的是什么:**不是"谁先
发明"(事实),而是"通信记录支持谁"(程序)**。建制语言在此
诞生:学会不敢以真理机关自居,只能以档案与程序说话
(后世史学指出委员会由牛顿一方主导,裁决常被读作程序不公的
样本——两种读法并存,恰好说明**信任装置的诞生与它的偏置
同胎**)。仲裁语言里,证据意识比真相意识更老——这就是本家族
语言的性格。

## 1. 表达力:这两种语言各能说什么(三栏之一)

**建制叙事语言能说的**:

| 能力 | 例 |
|------|-----|
| 建制编年 | "皇家学会 1660 成立,1662 获特许状"——时间×机构×法定行为 |
| 章程与账本记叙 | "院士年金××利弗;学会经费来自会费与庇护"——钱与规则的事实链 |
| 档案记事 | 注册簿/评审记录/合同——"某年某月某日,评审人出具意见" |
| 建制事件 | 立法(NSF 法案 1950)、设委(PSAC 1951)、改制(学会评议会) |

**建制分析语言能说的**:

| 能力 | 例 |
|------|-----|
| 共同体判断 | "职业科学家角色于 1810-1870 间定型"(本-戴维) |
| 规范表述 | CUDOS 四规范:普遍主义/公有性/无私利性/有组织的怀疑 |
| 信任装置 | "绅士信用→期刊评议→panel 制→信任调查"四段改版(00 章) |
| 政策接口 | 线性模型/巴斯德象限/使命导向——资助修辞的类型学 |
| 分层机制 | 马太效应、优先权之争的奖励系统解释(默顿学派) |

**两种语言都不能说的**:

- **不能进个体的动机皮肤**:"布什写报告时想让科学家掌权"是
  传记猜测;建制史只能写"报告的措辞产生了何种组织后果"
- **不能给"自主性"上秤**:科学自主了多少,没有客观函数
  (00 章百年张力;03 章不可构造对象)
- **不能裁定建制的好坏**:NSF 模式"优于"科学院模式不是史学
  命题,是比较制度分析的地盘(管理学宇宙的活)

## 2. 逻辑性质:社会史断言的证据约束(三栏之二)

| 性质 | 科技社会史断言 | 备注 |
|------|--------------|------|
| "真值" | 分级(证据支持度),随档案开放可修订 | 评议史随档案研究多次重写 |
| 底线一致性 | 叙事不得与引证的档案文本矛盾;章程与实况的差距须显式摆出 | "纸面建制≠运作建制"是合法发现 |
| 完备性 | 永不完备——建制档案为成功者生成 | 失败的学会、被除名者、非西方建制系统性沉默(00 章④) |
| 反事实 | 可用但须显式标记(T6) | "若无战时动员则无大科学"是分析工具不是结论 |
| 可重复性 | 无——但可对勘:章程×账本×通信×回忆录四方逼近 | 建制史版"对照组" |

### 2.5 断言强度的写法阶梯(社会史版)

承[史学理论](../../讲透历史学/讲透史学理论/README.md)证据分级,
本家族把确定性编码在措辞里——**动词就是类型签名**(与军事史 02
章同款纪律,社会史版两处特有降档):

| 阶梯 | 措辞 | 证据状态 | 社会史特有注意 |
|------|------|---------|---------------|
| T1 档案级 | "档案载/注册簿载/合同载" | 原始建制文献在场 | 章程是应然文本——纸面建制≠运作建制,须与账本对勘 |
| T2 建制官方史级 | "学会官方史/年报载" | 建制整理文献 | 纪念文集有荣誉动机,降半档使用 |
| T3 回忆录级 | "当事人回忆/自传载" | 一手但动机性强 | 科学家回忆录的功劳重排是通病,必须与 T1 对勘 |
| T4 通说级 | "学界一般认为" | 多源二手趋同 | 教科书叙事默认档(如"冲突论破产") |
| T5 神话级 | "相传/流行叙事称" | 科普神话与争议叙事 | 德雷伯-怀特冲突论式叙事是 T5 不是 T4 |
| T6 反事实 | "倘若……则" | 不存在的证据 | "若无布什报告则无 NSF"标记后使用 |

**误用告示**:把 T5(冲突神话/宏大危机叙事)当 T4 通说,
是科学-社会读物的头号病;把调查数字(T2 数据)当因果结论,
是测度时代的新病(01 章热线一的纪律)。

### 2.6 建制叙事的内部语法:四段式

建制史的写作收敛到同一个记叙骨架——**设立→章程→账本→危机**:
先写建制为何设立(需求叙事,证据最薄处),次列章程规则(应然
文本,证据最厚处),再算账本(钱与人员,建构制史最硬的证据),
终于危机与改制(叙事与分析交汇)。**设立段永远是动机叙事,
账本段才是建制史的心脏**——读建制史先看它有没有账本段,
一眼识别这本书的档位。

## 3. 规范化程度:术语、口径与对译(三栏之三)

- **建制术语标准化**:国际组织口径(OECD《弗拉斯卡蒂手册》
  的 R&D 定义)是跨国建制指标的事实标准——写"科研经费占比"
  必须声明口径
- **调查口径**:信任题项(如"对科学家的信任程度")的量表与
  波次必须注明;跨调查比较先做等价性检查
- **建制成名与法定年份分开**:皇家学会 1660(成立)与 1662
  (特许)并用是规范写法;NSF 1950(法案)与 1951(开局)
  同理

**术语规范与对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 大科学 | Big Science | Weinberg 1961 命名,Price 1963 定型;不是"大项目的科学",是资助形态 |
| 小科学 | Little Science | Price 书名的前半;指学会-大学时代的分散资助 |
| 科学共同体 | scientific community | 共同体的边界本身是研究对象,不是给定容器 |
| 默顿规范 | Mertonian norms (CUDOS) | CUDOS 缩写为齐曼后起,默顿原文无此缩写 |
| 同行评议 | peer review | 指资助评议(panel)还是期刊评审(refereeing),中文一律压成一词,须声明 |
| 马太效应 | Matthew effect | 默顿 1968;奖励系统累积优势的机制名 |
| 线性模型 | linear model | 基础→应用→开发的资助修辞;不是经验规律 |
| 巴斯德象限 | Pasteur's quadrant | Stokes 1997;"应用激发的基础研究"象限名 |
| 后学院科学 | post-academic science | 齐曼 1994;学院科学之后的混合资助形态 |
| 知识生产模式 2 | Mode 2 knowledge production | 吉本斯等 1994;勿译"第二种模式"丢掉生产二字 |
| 三螺旋 | Triple Helix | 政府-大学-工业;Etzkowitz & Leydesdorff 1995 |
| 公民科学 | citizen science | 一词双源(欧文 1995 批判义/邦尼 1990s 参与义)——引用即立场(政策支) |
| 公众理解科学·缺陷模型 | PUS · deficit model | 博德默报告 1985;"缺陷"是后人的批评标签 |
| 共同生产 | co-production | 贾萨诺夫习语:知识秩序与社会秩序一同生成;勿译"合作生产" |
| 边界工作 | boundary work | 吉尔因 1983;科学划界作为一种劳动 |
| 规制科学 | regulatory science | 贾萨诺夫 1990;为规制目的生产的科学 |
| 科学技术论/科学技术研究 | STS | Science and Technology **Studies**(建制与互动研究);与"科学史与科学哲学"HPS 分开 |
| 对科学的信任 | trust in science / trust in scientists | 泛科学与具体科学家是不同题项,调查不可混 |

## 📌 收束

科技社会史的语言=**叙事层管"建制发生了什么"(四段式+账本),
分析层管"建制意味着什么"(共同体/规范/信任装置/政策接口)**,
中间靠证据分级粘合;章程与实况分开,回忆录降档使用,调查数字
只做描述不做归因。下一章把这套语言压成数据:建制指标、信任
调查、政策链条怎么变成可构造对象:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **双层眼**:读建制史先分层——这段是记叙还是分析?中介词
  ("因此评议官僚化")挂在几级证据上?
- **账本眼**:任何建制的最硬证据是钱与人——章程会撒谎
  (应然),账本更难(实然)
- **口径眼**:一切跨比较的数字先问口径(弗拉斯卡蒂?哪个
  调查的哪一题?)——没有口径的建制指标是修辞
