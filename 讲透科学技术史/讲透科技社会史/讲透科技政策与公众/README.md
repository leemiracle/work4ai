# 讲透科技政策与公众 · 从布什报告到参与式转向(自定主干支)

> **定位句**:这支负责讲清科学与政策、公众之间的三个接口——
> **政策咨询**(科学怎么进决策:报告→委员会→预算的链条)、
> **公众参与**(决策怎么向公众开门:共识会议/参与式评估)、
> **公民科学**(公众怎么进知识生产本体)。主线是接口演化:
> 展示→教育→对话→参与,每一版都以科学的自主性为谈判筹码。
> **自定主干支声明**:0712 不设官方二级,本支为[讲透科技社会史](../README.md)
> 家族自定主干支(宇宙出处:[../../README.md](../../README.md),
> GB/T 13745 无此一级,0712 自定)。

## 诞生

Bush《科学:无尽的前沿》(1945)立政策咨询模板(报告造建制:
NSF);博德默报告(1985,《公众理解科学》)立缺陷模型与"公众
接口"问题;丹麦共识会议(1980s)与"公民科学"术语双源命名立
参与转向;Jasanoff《第五部门》(1990)立规制科学,《自然的设计》
(2005)的"共同生产"是方法论顶点:知识与秩序一同生成。

## 核心问题(带年代锚)

- 线性模型的兴衰:作为修辞的成功 vs 作为规律的多舛(1945→
  巴斯德象限 1997→使命导向 2010s)——进行中
- 顾问的独立性:PSAC 兴废(1951/1973)与 OSTP 重建(1976)——
  链条可断可续的建制样本——方法已立
- 缺陷模型之争:公众缺知识还是专家缺信任(1985-2000s 对话模型
  接力)——进行中
- 公民科学双账本:数据质量账 vs 参与价值账,AI 时代更难分开
  (EU-Citizen.Science 2025-08 辩论,检索校准见家族 01 章)——
  悬而未决
- 参与换合法性:OECD/UNESCO 把参与挂到信任议程(2024-2025),
  因果方向待证——进行中

## ✨ 这支最美的一个事实

"公民科学"这个词被**两次独立发明**,且两义相反:欧文(1995)
用它指"公民自己发起的科学"——对建制科学的温和批判;邦尼(1990s,
康奈尔鸟类实验室)用它指"专业机构主导的公众众包观测"——建制的
扩张工具。**同一个词,一部微缩的参与政治学**:今天每份公民科学
立项书都在两个义之间选边,多数不自觉——引用即立场(家族 02 章
对译表此条)。

## 假设与依赖

"公众"不是给定的整体(分群体/分议题/分国家,极化眼同样适用);
政策文本是应然(承诺≠落地,纸面建制≠运作建制);参与仪式化风险
(参与作为表演而非决策权转移)是参与转向的内置代价;涉具体政策
按文献通说中性呈现,不做政策建议(家族 04 章边界)。
