# 讲透科学体制化与大科学 · 从学会到国家资助体系(自定主干支)

> **定位句**:这支负责讲清科学怎么从绅士的业余爱好变成国家资助的
> 职业建制——三个模板接力:学会(1660,荣誉共同体)→研究型大学
> 与实验室(1810,职业角色)→国家资助体系与大科学(1940s,合同制
> 铁三角)。**体制化=给知识生产装上入口、账本与淘汰机制**,
> 大科学是第三级火箭,不是异类。
> **自定主干支声明**:0712 不设官方二级,本支为[讲透科技社会史](../README.md)
> 家族自定主干支(宇宙出处:[../../README.md](../../README.md),
> GB/T 13745 无此一级,0712 自定)。

## 诞生

默顿《十七世纪英格兰的科学、技术与社会》(1938)立"建制的
社会条件";本-戴维《科学家的角色》(1971)立职业化比较史;
Weinberg(1961)命名与 Price《小科学,大科学》(1963)定型
"大科学";Kevles《物理学家》(1978)与 Galison & Hevly 编
《大科学》(1992)补齐案例正典。

## 核心问题(带年代锚)

- 体制化三条件(角色合法/组织成型/自我延续)的各国走序:英国学会
  先发/德国大学后来居上/美国战时跳级——进行中
- 大科学的账本:任务实验室(RADLAB/曼哈顿)与常设资助(NSF/NIH)
  的合同制如何复制为战后模板(1940s-50s)——方法已立
- Price 之问:指数增长撞上饱和,科学进入"稳定态"后建制怎么活
  (1963-)——悬而未决
- 默顿规范与大科学实况的落差(无私利性 vs 任务导向)——进行中
  (规范之争的哲学层归科学思想史家族,波 4 在建)
- 中国压缩版:学会-国家-基金三模板百年走完(1928-1986,中性
  学科史叙述)——进行中

## ✨ 这支最美的一个事实

大科学首先是合同,不是设备——雷达实验室(RADLAB,1940-45)真正
的产出是"政府出钱、大学干活、工业转化"的合同制模板,战后被 NSF
(1950)与 NIH 逐条复制;曼哈顿的铀与阿波罗的火箭只是这套社会
合同的载荷。**改写科学史的不是那栋楼,是那份合同的格式**——
本支口号:先读账本,再读仪器。

## 假设与依赖

建制档案偏置(失败的建制不留档);西欧-大西洋选样(三模板叙事以
英美为主线,中国/苏联路径是修正线);大科学批判话语(1970s 起)
与建制史叙述分层标注,不混装。
