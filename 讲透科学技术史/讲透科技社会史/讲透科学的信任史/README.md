# 讲透科学的信任史 · 从绅士信用到同行评议到信任危机(自定主干支)

> **定位句**:这支负责讲清科学凭什么被相信——**信任的生产装置**
> 演化史:身份装置(绅士信用,17 世纪)→程序装置(同行评议,成型
> 于 20 世纪中叶的资助官僚制)→测度装置(信任调查建制化,2010s-)。
> 每一版装置都有配套危机:优先权之争、造假与复现风波、今天的极化
> 与骤降。**信任不是科学的燃料,是科学的操作系统**。
> **自定主干支声明**:0712 不设官方二级,本支为[讲透科技社会史](../README.md)
> 家族自定主干支(宇宙出处:[../../README.md](../../README.md),
> GB/T 13745 无此一级,0712 自定)。

## 诞生

Shapin《真理的社会史》(1994)立"身份装置"正典(绅士信用=17
世纪的证据技术);评议史研究(Burnham 1990 等)与 Zuckerman
《科学精英》(1977)立"程序装置"(评议-奖励-分层);Wellcome
Global Monitor(2018-)、NSF《科学与工程指标》(1972-)与
Cologna 等的 68 国调查(Nature Human Behaviour,2025,检索校准见
家族 01 章)立"测度装置"——三装置三段即本支骨架。

## 核心问题(带年代锚)

- 绅士信用怎么退位:身份担保→程序担保的动因(优先权之争/论文
  洪流/职业化,1712-20 世纪中)——方法已立
- 同行评议担保什么:担保"值得发表"≠担保"正确";偏置研究
  (保守偏置/熟人网络/机构偏置)——进行中
- 评议的经济学:评审人无酬劳动=建制的隐性补贴——进行中
- 信任测度的循环:问卷生产它声称记录的东西;跨文化等价性
  (2018-2025 测度建制化)——进行中
- 极化结构:全球总体高信任与组内/国别极化并存;均值平稳掩盖
  组间差扩大(2025 年 68 国调查;美国同期骤降为高收入国家中的
  显著例外——按来源客观转述,不引申政治评价)——悬而未决
  (家族实验的三组断言即此题的结构课)

## ✨ 这支最美的一个事实

同行评议**不是科学的古老传统**:1665 年起的两个世纪里,期刊发表
主要由编辑拍板;皇家学会 1752 年才设论文委员会;现代"投稿-外审-
修改"制普及于 20 世纪中叶,且先成型于战后资助机构(NSF/NIH 的
panel 官僚制),再反哺期刊。**我们最信赖的那道程序,是账本逼出来
的,不是原理推出来的**——信任装置跟着账本走(家族骨架第一律)
最干净的一例。

## 假设与依赖

"信任"跨时代的等价性存疑(信任建制/信任个人/信任知识是三种
题);测度装置本身参与建构对象(家族 03 章测度循环);危机叙事
有生成机制(媒体与政策话语放大),须与调查数据对勘;涉具体国家
信任变化数字按素材来源转述——本支写作红线。
