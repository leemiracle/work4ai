> **科技社会史=把科学从"知识"翻到"建制"那一面的学科**:谁出钱、
> 谁把关(评议)、谁被信任、政策怎么接进来。科学共同体不是天然的,

> 同行评议→信任调查。本家族解剖这条共演化线。
