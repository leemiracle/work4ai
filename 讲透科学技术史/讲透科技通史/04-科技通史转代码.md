## 0. 开篇:三个教科书直觉的统计审判

「切时代有统计收益」「断点年是叙事构造」「单代理不可信」——
三个通史方法论论断,能不能用数据说话?
[experiments/periodization_bursts.py](experiments/periodization_bursts.py)
构造两条模拟序列(出版物年产量+学会成立数,1665-2020),给出
三组断言(实测值):

- **断言① 断代有统计收益**:三断点(1687/1832/1945)分段拟合的
  总残差平方 2.548,单一趋势拟合 101.530——**残差砍到 2.5%**;
  分段增速 1.0%→2.2%→3.0%→5.5%/年,倍增期 68→32→23→13 年
  (Price 律的通史版)
- **断言② 断代稳健,断点年不稳健**:断点整体平移 ±15 年,
  拟合收益保留 98.5%+;但窗口内 SSE 起伏仅总收益的 1.6%,
  数据最优平移 −5 年——**1687 与 1682 在统计上不可区分**;
  教科书"1687 年转折"的年份精度是叙事构造
- **断言③ 双代理同向**:学会成立速率在三节点前后 ×1.5/×1.7/×2.1
  ——两条独立代理序列对同一断代给出同向证据

但脚本同时打印史学纪律:数据是教学版模拟,它检验的是**断代
方法论的统计性质**,不产出历史结论。**代码替你算收益,
替不了你选锚**——通史数字化的第一课。

## 1. 可机械化边界(三件套之一)

**能进代码的**(通史数据化后的一切统计与拟合):

| 任务 | 机械化形式 |
|------|-----------|
| 断代定量检验 | 断点集 → 分段 vs 单一趋势拟合、SSE 比较(家族实验) |
| 换锚敏感性 | 断点平移扫描 → 收益保留曲线(实验断言②) |
| 双代理对勘 | 两条代理序列 → 节点前后速率比(实验断言③) |
| 年表聚合 | 三实体事件流 → 地点×十年×学科立方体、强度榜(§3) |
| 长时段趋势 | 增速段 → 倍增期、指数外推的饱和警报(§4) |
| 纪年换算 | BC/AD(无 0 年)/地方历 → 统一时间轴 |
| 领域起源检测 | 学科标签序列 → 新领域 burst(HSSC 2025 的真实版) |

**不能进代码的**(通史的"不可判定域"):

1. **选锚正当性**——1687 还是 1660 还是 1703 当锚,是史学判断;
   代码只能证明"锚移 ±15 年结论不变",不能证明"该切三段"
2. **图景综合**——四层(建制/知识/人物/器物)如何加权合成,
   是写作判断;矩阵每格可取证,合成不可外包
3. **"革命"裁定**——够不够格叫革命没有目标函数(00 章);
   代码只能给"前后结构差异"的效应量
4. **叙事压缩**——把 150 年压成"一个时代"的修辞决策;
   压缩比是史观(02 章 §0)

> 边界的一句话:**代码是通史的绘图仪,不是通史家**。
> 曲线画得再准,刀口还得史学来切。

## 3. C2 知识地理数据结构走廊(最小示例)

把附录年表聚合成地理立方体——03 章 schema 的最小落地:

```python
EVENTS = [  # 三实体年表最小切片(示例值;真实库=学会/期刊/机构名录)
    ("伦敦", 1660, "综合"), ("巴黎", 1666, "综合"), ("吉森", 1826, "化学"),
    ("柏林", 1810, "综合"), ("伦敦", 1831, "综合"), ("剑桥", 1874, "物理"),
]

def cube(events):
    """事件流 → 地点×十年格 强度立方体(03 章 schema 的聚合)。"""
    cell = {}
    for place, year, _disc in events:
        key = (place, (year // 10) * 10)
        cell[key] = cell.get(key, 0) + 1
    return cell

def top_places(cell, decade):
    """某十年格的强度榜。代理声明:建置密度≠知识密度(03 章 §6)。"""
    rows = [(p, n) for (p, d), n in cell.items() if d == decade]
    return sorted(rows, key=lambda r: -r[1])

c = cube(EVENTS)
assert sum(c.values()) == len(EVENTS), "聚合守恒:格值和=事件数"
print("1830 年代强度榜:", top_places(c, 1830))   # → [('伦敦', 1)]
```

八行完成的事:年表 → 立方体 → 强度榜。扩展方向:接入 01 章
四转向的 digital 线(期刊库/机构名录),强度榜连成**重心轨迹**
(03 章 §4);全球转向的工序=给非欧洲节点补数据(**名录增补
先于图景重画**)。史学红线:榜只回答"哪里建置密",
不回答"哪里科学强"——代理的越权在代码里最隐蔽。

## 4. C3 长时段趋势走廊(Price 律最小实现)

```python
import math

def doubling_time(rate):
    """Price 倍增期:T2 = ln2 / r(《小科学,大科学》1963)。"""
    return math.log(2) / rate

for era, r in [("科学革命后期", 0.022), ("学院化", 0.030), ("大科学", 0.055)]:
    print(f"{era}:增速 {r:.1%}/年 → 倍增期 {doubling_time(r):.1f} 年")

assert abs(doubling_time(0.055) - 12.6) < 0.05    # 家族实验同款实测
# 饱和悖论的算术面(00 章 §六反直觉三):大科学段外推一百年
base, r = 1_000_000, 0.055
assert base * math.exp(r * 100) > 200 * base       # 百年两百余倍
# ——任何按指数增长的建制,终将吃掉全部预算:外推即警报
```

**走廊三警告**:

1. **参数=史观**:增速与断点谁定,结论就归谁——引用拟合结果
   必附参数来源与标定声明
2. **指数不可外推**:Price 律是历史段的拟合,不是未来的预言;
   当代段倍增期 13 年撞经费天花板是结构性事实(团队化=增长
   换挡的组织表现,01 章热线六)
3. **代理≠知识**:出版量对质变沉默——1925 年的量子力学与十篇
   常规论文在曲线上等重(00 章假设三)

## 5. §4.5 换锚重跑:使用断代的正确姿势

断代是离散化,锚是史观。三个合法的"换锚"实验:

- **全球锚假说**:若 1687 换成全球环流锚(如马尼拉大帆船航线
  确立的知识环流节点),欧洲书本锚降为局部事件——Poskett 线的
  操作化(01 章热线三)
- **建制锚假说**:若断点改用建制锚(1660 皇家学会/1810 柏林
  大学/1950 NSF),书本锚的戏剧性下降而建制因果链变短——
  图景重心从"英雄著作"移向"建制器官"
- **连续论假说**:若取消全部断点(迪昂线),拟合收益按实验
  断言①损失 97% 的解释力——**连续论不是数据发现,是叙事
  立场**;反向同理(02 章:单复数都是立场)

家族实验脚本把史学纪律打印在结果之后——先看数字,再看声明,
这个顺序不许反。

凡是强度榜单,都要挂 C2 的代理声明。

## 📌 收束

三条走廊:C1(已成)管"切得值不值",C2 管"哪里密",C3 管
"涨多快";三条共用一条边界——**选锚、划界、综合、裁定永远
留在人脑**。跑到这里,回头再看 00 章那句钉住本质的话:时代是
研究者切的,图景是研究者合的;代码能替断代算收益、验稳健、
对代理,保险单还得史学来签。

**🧠 认知升维**:

- **三件套眼**:任何"阶段划分"结论先问三件套——收益、稳健、
  双代理;缺件自动降为假说
- **断点即参数眼**:看到任何分期结论,第一件事找断点是谁选的,
  第二件事才是看结论
- **外推警报眼**:一切指数拟合的终点画到未来,都是警报不是
  预报(Price 饱和悖论的工程版)
- **代理越权眼**:代码输出"哪里密",人类读成"哪里强"——
  这一步越权最常发生在读图的人,而不是写代码的人
