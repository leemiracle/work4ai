# 科技通史思维技能卡(学位目录 0712 自定 · 讲透科技通史家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「某时代的科学**整体图景**什么样」——断代横断面需求(按时入座五支)
- 「科学革命真的存在吗」「为什么断在 1687」——断代方法论问题
- 「李约瑟问题」「为什么近代科学在欧洲」——文明比较的断代压力测试
- 通史数字可疑(某时代出版量/增长倍数无来源)——代理指标纪律
- 给断代/年表/知识生产数据做结构化或定量检验——schema 与走廊需求
- 判断"某新事物够不够格开启新时代"——锚类型与三件套检验
- 学某学科史时缺时代背景板——横断面给纵断面供坐标系

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **断代眼** | 看到"时代"先问刀口谁切的、锚什么类型(书本/建制/事件)——时代是分析工具,不是历史本体 |
| **图景眼** | 整体图景=四层合成(建制/知识/人物/器物),不是学科史加和——读通史先数层 |
| **锚眼** | 断代锚=叙事压缩比标记;越事件化(某书某年)戏剧性越强、稳健性越可疑 |
| **代理眼** | 一切通史曲线先问代理变量(出版量≠知识量,增速≠革命) |
| **天平眼** | 断代合法性三件套:统计收益×换锚稳健×双代理同向;缺件自动降为假说 |
| **标签年眼** | 历史标签先问"这词那年出生了吗"——"1687 年的科学家"是硬伤(1833 造词) |
| **尺度眼** | 通史讲多大(尺度)是立场选择不是技术参数(Poskett 尺度政治论) |

## 3. 工具箱(何时用什么)

- **五时代骨架**:古代与中世纪(—1500)/科学革命(1543-1687)/
  工业革命与十九世纪(1810-1900)/二十世纪大科学(1895-1945)/
  当代科学(1945- );每格四层独立取证(5×4 矩阵=不漏层写作清单)
- **三类锚**:书本锚(《原理》1687)/建制锚(皇家学会 1660/
  柏林大学 1810/NSF 1950)/事件锚(曼哈顿 1945)——1945 双锚纪律
- **断言阶梯 T1-T6 通史版**:T1 原典→T2 学科史→T3 通史(引用
  自动降半档)→T4 综述(断代框架默认档)→T5 科普故事→
  T6 反事实;动词即类型签名
- **断代三件套**(家族实验 `experiments/periodization_bursts.py`
  为最小实现):①分段 vs 单一趋势的 SSE 收益②断点平移 ±15 年
  的收益保留与断点年不可辨识③双代理同向(学会速率节点前后比)
- **Price 倍增期**:T2=ln2/r;分段倍增期 68→32→23→13 年
  (通史版加速律);指数外推即警报(饱和悖论)
- **知识地理立方体**:(地点,十年,学科,强度)四元组+代理声明
  ——重心轨迹与名录增补的标准容器
- **断代表 schema**:era 记录带类型化锚列表(书本/建制/事件)
  +四层字段+source_tier(03 章 §1.5)

## 4. 常见误区与禁忌

- ❌ **时代实体化**:把"科学革命时代"当历史本体而非分析工具——
  Shapin:根本不存在科学革命这种**东西**
- ❌ **精确断点直读**:"1687 年转折"的年份精度是叙事构造
  (实验:±15 年不可辨识)——断代年一律加"约"
- ❌ **黑暗中世纪神话**:"希腊衰落→千年沉睡"已被通说改写为
  翻译运动接力+大学诞生——革命的前史比革命长十倍
- ❌ **代理越权**:出版量/建置密度读成"知识强度";增速读成"革命"
- ❌ **框架作证据**:"正如 1687 年革命所证明"——断代框架(T4)
  不能当原典(T1)引用
- ❌ **时代错置标签**:给 1833 年前的活动者贴"科学家"、给
  中世纪套"近代早期"而不声明立场
- ❌ **当代争论站队**:全球转向/去殖民科学史的争论按文献通说
  呈现各方论点,不站队不引申现实政治
