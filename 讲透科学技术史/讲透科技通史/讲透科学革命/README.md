# 讲透科学革命 · 16-17 世纪:1543 到 1687,一个时代的铸成与受审

> **定位句**:这支负责讲清 16-17 世纪的整体图景——哥白尼到牛顿的
> 天地重构、学会与期刊的建制诞生、实验方法与机械论世界观的成型;
> **"革命"既是本支的展品也是本支的被告**:断代正典(Butterfield)
> 与其自我批判(Shapin)同台。理论之争(范式概念/革命论 vs
> 连续论的哲学层)**外判给科学思想史家族**(波 4 在建),本支取
> 其断代结论、做历史图景。
> **自定主干支声明**:GB/T 13745 无此学科;本支为[科技史宇宙
> 0712](../../README.md)自定主干家族[讲透科技通史](../README.md)的
> 五支之一。宇宙:[讲透科学技术史](../../README.md)。

## 诞生

巴特菲尔德《近代科学的起源》(1949)把"科学革命"铸成断代正典
("它使基督教兴起以来的一切都相形见绌");柯瓦雷《伽利略研究》
(1939)与《从封闭世界到无限宇宙》(1957)给出概念内史的范式写法;
Shapin《科学革命》(1996)以"根本不存在科学革命这种东西"开篇,
把本支的正典变成方法论悬案;Poskett《地平线》(2022)再把地理
版图全球重画——本支是通史宇宙争论密度最高的支。

## 核心问题(带年代锚)

- **革命存在吗**(本支主问题):单一连贯事件,还是异质过程的
  压缩叙事——悬而未决(通说:有用的框架,非事件;家族实验
  断言②的统计版同款结论)
- 为什么是欧洲、为什么是那时(1543-1687):默顿命题(清教与
  科学趣味,1938)与欧洲特殊性之争——悬而未决(李约瑟问题的
  欧洲面)
- 建制层革命:皇家学会 1660/《哲学汇刊》1665——知识生产长出
  "发表"器官(00 章美之时刻②);重复实验与见证的社会学——进行中
- 机械论世界观的确立:从亚里士多德质料到数学化的自然——进行中
  (理论层归思想史家族)
- 全球参与:奥斯曼天文、明清历法改革、阿兹特克观测在"革命"中
  的位置——争鸣中(按文献通说呈现各方论点,01 章热线三)

## ✨ 这支最美的一个事实

1687 年 7 月,哈雷自费督印《自然哲学的数学原理》——开普勒的天
与伽利略的地收进同一组公理。但通史视角的下半句更美:这本书是
一张建制网络的收敛点(学会运行 27 年、期刊出到 22 卷、弗拉姆斯
蒂德的月数据、胡克与雷恩的通信刺激)——**一个时代被一本书
合拢,而书是网络织的**(00 章美之时刻①)。

## 假设与依赖

断代即史观(本支是全家族压力测试的常客):1543 与 1687 都是
书本锚,锚移 ±15 年结论不变(实验断言②);"科学家"一词 1833
年才造——本支人物一律称"自然哲学家"("physician-astrologer-
mathematicus"式复合身份照录);欧洲锚偏置在本支最重(Poskett
批判的正面射程),名录增补持续进行。依赖:思想史家族(波 4
在建)的理论层;史学理论上游。
