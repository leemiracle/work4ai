# 讲透古代技术史 · 农桑冶金水利:手艺自成体系(自定主干支)

> **定位句**:这支负责讲清**技术不需要科学也能积累、也能大成**——
> 农业、冶金、水利与手工业在无科学理论的时代自成体系地演进:
> 经验积累、行会传承、官府标准化。手艺不是科学的童年,
> 是另一种成熟。
> **出处声明**:学位目录 0712 不设官方二级,本支为**自定主干支**
> (宇宙[全自定主干支说明](../../../讲透科学技术史/README.md))。
> 家族:[讲透技术史](../README.md)。

## 诞生

19 世纪器物图谱传统与德国器物史(Sachsgeschichte)为先声
(家族 00 章 §1.1);20 世纪考古学成熟后,勒鲁瓦-古朗
《环境与技术》(1943-45)确立"技术为人类学常数"的写法;
李约瑟《中国科学技术史》卷四(1965 起)把中国工程传统接入
世界技术史正典。本支的独有依托:技术体系演进脉络的史学叙事
——**复原与实验考古方法**的正主在科技考古与文献家族
(宇宙波 4 在建,文字提及),本支接其复原结果。

## 核心问题(带年代锚)

- 新石器农业包:驯化组合(谷物+牲畜+工具)如何打包扩散——通说
  多中心独立起源,进行中
- 青铜-铁矿冶链:为什么冶铁晚于冶铜近两千年(炉温门槛),
  铁器普及的社会条件——通说已立,断代细节进行中
- 水利与治水组织:大规模灌溉工程的劳动组织从何而来
  (通说按文献呈现,理论争论归技术史理论支)
- 手工业标准化:《考工记》式的官府工艺规范与行会传承——
  古代技术知识的载体问题(文字/师徒/器物三轨)
- 中国技术传统的高峰与转折:《天工开物》(1637)式的体系总结
  为何未导向工业化技术体系——李约瑟题技术版(家族 00 章问题表)

## ✨ 这支最美的一个事实

都江堰(前 256 起)无坝引水:鱼嘴分流、飞沙堰排沙、宝瓶口
控量,三大件没有一件是"高技术";它活到今天的理由是
"深淘滩,低作堰"六字诀与两千年**连续岁修**——最长寿的技术
不是最坚固的,是被维护得最好的(与维护与报废史支共用此证词:
维护转向的古代文本)。

## 假设与依赖

幸存者偏置最重的一支(家族 00 章④之一):存世器物稀疏且偏
王侯墓葬,日常技术与失败技术近乎全灭——文献与器物必须对读
(02 章三本词典);工艺复原因果须标注"可行性证明≠历史发生证明"
(T6 纪律)。
