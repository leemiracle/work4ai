# 技术史思维技能卡(0712 自定 · 讲透技术史家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「某类技术**怎么演进**的」(农业/冶金/动力/信息/某具体器物)
  ——断代与谱系需求
- 「新技术会不会改写 X」——先上决定论免疫眼与动量眼,再谈革命
- 「维护/修理/报废/二手/计划性报废」——维护转向的正题
- 「专利数据怎么用」——专利≠实施的降档纪律(计量前必读)
- 「为什么有的技术普及快」——S 曲线/网络效应/罗杰斯属性
- 「旧技术为什么不死」(改装/兼容/迁移)——Retrofit 协商眼
- 器物描述对不上文献——三本词典一致性检查
- 学技术史理论(SCOT/ANT/无缝之网)缺地图——00 章 §一学科史

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **履历眼** | 任何技术先问五段:生产-流通-挪用-维护-报废;缺段处即叙事的意识形态 |
| **决定论免疫眼** | 听到"X 改写 Y",先问 Y 的制度土壤会把 X 长成什么(柏林-芝加哥双城思维) |
| **动量眼** | 技术早期可塑、成熟锁定;判断建构窗口先问成熟度(休斯中介方案) |
| **三词典眼** | 器物描述对齐功能/结构/使用脚本,打架处即研究入口(阿克里奇脚本) |
| **降档眼** | "专利显示"自动降一档:权利主张≠实施,实施≠扩散,扩散≠依赖 |
| **幸存者眼** | 存世≠主流;专利≠实施;烟花(创新)≠三餐(维护) |
| **病历眼** | 长命技术先看维护记录——连续岁修比辉煌发明更能解释长寿 |
| **协商眼** | 新旧相遇先问协商条件:替代不是替换,常是两个都活(retrofit) |

## 3. 工具箱(何时用什么)

- **五关键词框架**:生产-流通-挪用-维护-废弃(叙事审计器:
  数任何技术叙事讲了几段)
- **Kranzberg 六定律**:第一定律"技术无善无恶,但也从不中性"
  审一切技术新闻;第二定律"发明乃需要之母"审"应需而生"叙事
- **SCOT 三步**:解释柔性→相关社会群体→收束(自行车案例
  为母版)——分析一项技术的争论史
- **休斯系统工具**:无缝之网/系统建造者/反向滞后——分析
  大型技术系统(电网/铁路/互联网)
- **技术动量**:决定论之争的中介假说——分析"锁定"与"窗口"
- **证据阶梯 T1-T6 技术史版**:T1 器物→T2 生产档案→T3 专利
  (特有降档)→T4 通说→T5 广告→T6 反事实;动词即类型签名
- **S 曲线+Retrofit 定量走廊**:家族实验
  `experiments/diffusion_s-curves.py` 为最小实现
  (相对优势单调/网络效应拐点左移/Retrofit 右移且上限下移)
- **专利计量红线**:计量的是"声称的活动",外推到实施
  每一步都要新证据

## 4. 常见误区与禁忌

- ❌ **技术决定论**:「技术一出手,社会跟着走」——00 章中心
  之争的通说结论:动量说为中介,单向决定论两头都站不住
- ❌ **专利直读**:把专利当生产记录(T3 当 T2)——
  技术史计量的头号病
- ❌ **发明中心主义**:只写烟花不写三餐——维护转向批判的
  正是它;还有全球北方偏置(去殖民议程的病灶)
- ❌ **存世当主流**:博物馆里剩的是耐战的器物,不是日常
  (幸存者偏置)
- ❌ 模拟当档案:S 曲线拟合输出是机器化 T6 零模型,
  冒充史实是数字时代新病
- ❌ **革命话语直用**:"第 N 次工业革命"是离散化+宣传结构,
  引用即须标断代敏感性
