## 诞生

先声是格雷厄姆与思里夫特《失序:理解修理与维护》(2007,
文化研究侧)与 Cowan《母亲更忙了》(1983,家务维护劳动);
建制肇始是拉塞尔与文塞尔的"维护者"会议(2016)与 2018 年
文集——**维护转向**得名;近五年实证化(2025 圣地亚哥修理者
研究,EJCPS)与哲学化(《Technology Over Time》文集)、
建制化(SHOT 之 SIGMaP 研究群)三线并进(家族 01 章热线四)。
本支是家族四支中最年轻的一支,也是断代革命的承担者:
不给技术分时代,给技术的关系分阶段。

## 核心问题(带年代锚)

- 维护为何在史学中隐形:劳动结构(谁做谁隐形——性别/殖民
  劳动分工)与档案结构(工单散、专利亮)双重原因——进行中
- 计划性报废的出生证明:1924-1939 日光灯泡卡特尔(Phoebus)
  约定寿命 1000 小时;1932 伦敦小册子正式命名——档案已立
  (公司协议+小册子,T2/T4 双证),动机解释有争议
- 修理的政治经济学:修理权运动(right to repair)、
  垄断维修与模块化设计——当代进行中
- 数字维护:软件维护占工程工作量一半以上(通说)——
  legacy 系统史是本支的数字主战场
- Retrofit 的协商结构:老技术加装新组件=同时延长旧生命
  与压低新上限(家族实验断言③的史学面)——进行中
- 废弃物流向:电子废弃物贸易、二手降级再用、遗产化
  (博物馆化回到幸存者偏置源头)——进行中

## ✨ 这支最美的一个事实

灯泡卡特尔(1924-1939):日内瓦的 Phoebus 联盟把灯泡寿命
**约定在 1000 小时**——成员按配额罚款、工程师奉命"优化"
更短的寿命。"计划性报废"从此有了出生证明:它不是消费者
被害妄想,而是有公司档案的生意模式——**报废也可以被设计**。

## 假设与依赖

维护记录稀疏是结构性的(多数维护不留痕,存档是幸存者——
02 章 T2 金矿与它的稀缺并存);修理者口述与情感材料
(2025 圣地亚哥范式)证据等级参差,须逐条挂 T 级;反向偏置
警惕:维护转向若滑向"维护崇拜"(一切创新皆虚妄),就重演了
它所批判的单向叙事。
