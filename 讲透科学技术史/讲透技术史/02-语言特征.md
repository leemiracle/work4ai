# 02 · 语言特征——功能·结构·使用脚本:器物的三本词典

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)**。
> **本质一句话**:技术史说三种语言——**人工物语言**
> (这件东西是什么:功能/结构/使用脚本)与**史学语言**
> (证据与叙事:这东西何时被谁造、被谁用、何以见得)的
> 双层语法;这门学科的全部手艺,就是让"这是一台四冲程内燃机"
> 的描述与"它扩散至江南船埠的证据是船行日志"的论证
> 在同一篇文章里各司其职、互不越权。

---

## 0. 开篇:读器物如读剧本

📖 **故事框:阿克里奇的"剧本"(Akrich,1992)**。技术社会学家
阿克里奇(Madeline Akrich)提出一个精巧的读法:设计者把
**使用者预先写进器物**——相机的防呆快门假定你不想读说明书,
婴儿奶瓶的通气孔假定母亲的持姿,道路的限宽石墩假定谁能通过。
她把这种内嵌的假定叫做**使用脚本**(script):读一件技术物,
就是给它做"再描述"(de-scription),把写进去的用户读出来。
**器物是凝固的社会关系**(与拉图尔的"技术是凝固的社会"
一脉相承)——人工物语言因此不是工程说明书的专利,它是
社会史的第一手文本。

## 1. 表达力:这三种语言各能说什么(三栏之一)

**人工物语言能说的**:

| 能力 | 例 |
|------|-----|
| 功能陈述 | "水轮将水位差转换为轴功"——做什么(功能≠意图,意图要证据) |
| 结构陈述 | "焦炭高炉:炉缸-炉身-料钟上料"——怎么构成(可直接对物证) |
| 使用脚本 | "面板只留两个按钮"——预设的用户、技能与劳动分工(阿克里奇) |
| 系统陈述 | "珍珠街电站=发电机+电网+电表+计价"(休斯无缝之网的语言) |
| 谱系陈述 | "T 型车是福特制的一个节点"——父型与改型的演化关系 |

**史学语言能说的**:

| 能力 | 例 |
|------|-----|
| 断代叙事 | "动力-材料-信息三波"(00 章四级水位) |
| 建构叙事 | "安全自行车收束了两类骑行群体的争论"(SCOT 分析语汇) |
| 证据论证 | "存世三台,工艺痕迹一致"——器物本体的对勘 |
| 维护叙事 | "岁修记录连续 74 年"——技术生命的下游同样可考 |

**两种语言都不能说的**:

- **不能进工人的皮肤**:操作的手感、车间噪音与工伤痛感
  在两种语言里都近乎不可传递(口述史是补丁,不是解)
- **不能自动裁定"谁决定谁"**:决定论之争是理论判断
  (00 章中心问题),语言本身不输出立场
- **不能给"重要"上秤**:一项技术多重要没有客观函数
  (专利被引≠社会后果,03 章半可构造对象)

## 2. 逻辑性质:技术史断言的证据约束(三栏之二)

| 性质 | 技术史断言 | 备注 |
|------|-----------|------|
| "真值" | 分级(证据支持度),随档案开放可修订 | 专利实施率随公司档案开放常被下修 |
| 底线一致性 | 不得与器物本体矛盾:宣称的工艺须过材质检测 | 器物是"不会说谎的证人"(但会被误读) |
| 完备性 | 永不完备——维护与使用几乎不留痕 | 修理多无记录,是结构沉默(非偶然缺失) |
| 反事实 | 可用但须显式标记(T6),不可当结论 | "若有蒸汽机则罗马工业化"是思想实验 |
| 可重复性 | 部分——工艺可实验复原,采用不可重跑 | 复原实验=技术史的"重演"(归科技考古家族方法) |

### 2.5 断言强度的写法阶梯(技术史版)

承[史学理论](../../讲透历史学/)证据分级,技术史把确定性
编码在措辞里——**动词就是类型签名**(军事史/法律史家族同款
纪律,技术史版有两处特有改动):

| 阶梯 | 措辞 | 证据状态 | 技术史特有注意 |
|------|------|---------|---------------|
| T1 器物级 | "存世器物/工艺痕迹显示" | 物证在场 | 幸存者偏置(00 章④):存世≠主流 |
| T2 生产档案级 | "公司档案/图纸/工单载" | 建制一手文献 | 维护记录是金矿:技术的"病历" |
| T3 专利级 | "专利文件声称" | 法律主张文本 | **技术史特有降档**:专利≠实施,实施≠扩散——专利是发明人权利主张,不是生产记录 |
| T4 通说级 | "学界一般认为" | 多源二手趋同 | 教科书叙事默认档 |
| T5 宣传级 | "广告/说明书/展会称" | 营销文本 | 说明书描述的是理想脚本,不是实际使用 |
| T6 反事实 | "倘若……则" | 不存在的证据 | 模拟输出(S 曲线拟合)常被冒充 T2,实为机器化 T6 |

**误用告示**:把 T3 当 T2(专利当实施)是技术史计量的头号病
(04 章 C1 边界);把广告脚本当使用实录(T5 当 T2)是第二病。

### 2.6 人工物描述的内部语法:三本词典的一致性

合规的器物描述须三本词典对齐:功能句(做什么)↔ 结构句
(靠什么做到)↔ 脚本句(假定谁来用)。三本互相矛盾即红旗:
"此犁专为小农设计(脚本),但需三畜牵引(结构)"——
要么改断代,要么找协作组织的证据。**读器物先对三本词典,
等于史学文本的"先查引证"**。

## 3. 规范化程度:术语、分类与对译(三栏之三)

- **分类标准化**:专利分类号(IPC/CPC)与技术标准文献是
  本学科事实上的数据交换格式(03 章 schema 直接来源);
  跨库比较必须声明分类版本
- **器物描述规范**:材质/工艺/形制/铭文的著录有博物馆
  著录规范;测绘图与照片是标配证据
- **计量规范**:产能/功率等古今单位(石/马力/千瓦)须换算
  并注明换算率;估计值必须带"约"与生成机制
- **命名规范**:以首个**可证实施**者命名而非首个声称者
  (爱迪生是白炽灯系统的建造者而非灯丝的首个发明人——
  命名即断代)

**术语规范与对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 技术手段/工艺 | technics | 芒福德用词,≠ technology(制度化的技术);常被混译丢掉"人与技术之分" |
| 技术的社会建构 | SCOT (Social Construction of Technology) | 不是"社会建设技术"的口号,是一套分析程序(解释柔性→相关社会群体→收束) |
| 行动者网络理论 | ANT (Actor-Network Theory) | "行动者"含器物与生物;译"行为者"丢掉广义对称性 |
| 解释柔性 | interpretive flexibility | 不是"解释的灵活性"(修辞),是同一器物在不同群体中的不同存在方式 |
| 收束 | closure | 借自数学词头但非数学义:争论平息的**社会**过程,再无弹性可言 |
| 无缝之网 | seamless web | 休斯术语:技术-经济-政治不分经纬;不是"紧密网络" |
| 反向滞后 | reverse salient | 军事借词(战线突出部的反面);误译"逆向突出"则义失 |
| 技术动量 | technological momentum | 不是"技术惯性";是决定论与建构论之间的中介假说 |
| 维护转向 | maintenance turn | 不是"维修转型"(行业升级义);是史学范式的转向 |
| 混血技术 | creole technologies | 埃杰顿术语:异地挪用中再发明;译"混合"丢失殖民史语境 |
| 使用脚本 | script (of use) | 阿克里奇术语;不是"使用说明" |
| 计划性报废 | planned obsolescence | 有具体出生锚(1932 伦敦小册子);不是泛指"不耐用" |

## 📌 收束

技术史的语言=**人工物层管"这东西是什么"(功能/结构/脚本
三本词典),史学层管"何以见得"(T1-T6 阶梯)**,中间靠
"专利≠实施"的降档纪律粘合。下一章把这套语言压成数据:
谱系、专利与维护记录怎么变成可构造对象:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **三词典眼**:读任何器物先对齐功能-结构-脚本,
  三本打架处即研究入口
- **降档眼**:看到"专利显示"四个字,自动降一档再读
  ——声称与实施之间隔着一条生产史
- **脚本眼**:任何界面都在预定用户——问"谁被写进去了,
  谁被写出去了",设计即社会结构
