## 诞生

决定论之争的前史是战后技术批评(原子弹阴影下的"技术自主论");
1984 年平奇与比克以自行车案例立 SCOT,1987 年三方合编
《技术系统的社会建构》成纲;ANT 自卡龙扇贝研究(1986)与
拉图尔"技术是凝固的社会"(1991)另立一军;1994 年史密斯与
马克思编《技术驱动历史吗?》把争论结集定格。家族 00 章 §1.5
即本支的学科史(全家族共用这段出生证明)。

## 核心问题(带年代锚)

- **技术决定论之争**(中心问题):强决定论/弱决定论/社会建构
  三方角力;休斯技术动量(早期可塑-成熟锁定)为通说中介
  ——悬而未决(1989/1994 锚)
- 技术物有政治吗:Winner 命题(1980,纽约低架桥案例;该案例
  后遭 Joerges 等实证质疑——通说按"经典+争议"双标注)
- SCOT 的软肋:被批评为"社会决定论"的翻版(忽视技术物
  自身的阻力)与宏观权力缺位——进行中
- ANT 的代价:广义对称性把人与物等权,解释力换表述成本
  (文本争议大)——方法论争论
- 后现象学与技术哲学:伊德-维尔贝克一系"技术如何中介经验"
  ——与哲学宇宙技术哲学侧的接口(未建,文字提及)

## ✨ 这支最美的一个事实

克兰兹伯格第一定律:**"技术无善无恶——但技术也从不中性"**
(1986)。一句话同时击倒两头的懒惰:中性工具论("刀只看谁拿")
与技术恶魔论("技术自带暴政")——每一件人工物都是
带着社会结构的凝固物,善恶不在物里,中性也不在。
技术史全部争论可以看作这一定律的展开证明。

## 假设与依赖

理论即选样:用 SCOT 看世界,看到相关社会群体;用 ANT 看世界,
看到网络——框架先于事实,研究者必须显式声明工具(02 章
术语对译表的纪律);STS 与科学-政治理论的建制正主在
科技社会史家族(宇宙波 4 在建,文字提及),本支只用其理论
工具做技术侧的史学分析,不越界建理论。
