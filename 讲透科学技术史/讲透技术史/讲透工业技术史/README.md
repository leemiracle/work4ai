# 讲透工业技术史 · 动力-材料-信息三波:手艺变系统(自定主干支)

> **定位句**:这支负责讲清技术从手艺变成**系统**的那一刻——
> 动力革命(蒸汽/内燃/电)、材料革命(铁-钢-合成材料)、
> 信息革命(电报-计算机-网络)三波把"一件器物的改进"
> 变成"一个系统的建造";工业革命不是更快的纺车,
> 是另一种技术组织方式。
> **出处声明**:学位目录 0712 不设官方二级,本支为**自定主干支**
> (宇宙[全自定主干支说明](../../../讲透科学技术史/README.md))。
> 家族:[讲透技术史](../README.md)。

## 诞生

兰克式史学不看车间,本支正典由经济史家与史家合铸:
兰德斯《解除束缚的普罗米修斯》(1969)确立西欧工业技术
通史叙事;莫基尔《富裕的杠杆》(1990)把"宏观发明-微观改良"
二分引入;休斯《能量之网》(1983)以电气化立系统转向
(家族 00 章 §1.4)——三波框架是本支的承重结构,
但每波的断代都是可议的离散化(假设与依赖)。

## 核心问题(带年代锚)

- 英国之谜:为什么是英国、为什么是 18 世纪后半(煤/工资/
  专利/文化诸解并存,通说多元)——悬而未决
- 实验室如何进入工业:合成染料(1856 苯胺紫)起的
  科学型工业——研发建制化的起源,进行中
- 福特制与泰勒制:量产组织本身就是技术(系统建造者视角)——
  通说已立
- 三波是接力还是叠层:信息波是否重写前两波的组织逻辑
  (平台/网络化)——进行中
- "第 N 次工业革命"话语批判:断代离散化+宣传结构
  (维护转向的批判面,家族 00 章④之三)

## ✨ 这支最美的一个事实

爱迪生不是"发明灯泡的人":白炽灯的可专利原型早有一串;
他建造的是**珍珠街电站系统**(1882)——发电机、电网、电表、
保险丝、计价与消防规程一次交付。系统视角的洞见:**单项发明
的竞争是系统的选择**——煤气管线竞争者输掉的不是灯,
是整套基础设施的组织方式(休斯系统建造者的教科书案例)。

## 假设与依赖

三波断代=研究者强加的离散化(换锚换曲线,家族 04 章 §7
同款敏感性);英国中心叙事的偏置(去殖民议程的病灶,
01 章热线一);档案条件最好的一支(公司档案/专利/标准文献),
因此也最重地背着"专利≠实施"的降档纪律(02 章 §2.5)。
