# 04 · 科技考古与文献转代码——错误传播·谱系·年代:史料管线的最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:史料问题一旦变成"关于记录/矩阵/语料的
> 计算",就能进代码——识别错误变成传播统计、共享读法变成
> 谱系树、衰变残留变成年代估计;**唯一不可外包给代码的,
> 是考据判断本身(选样、断代裁定、谱系裁剪、归因)**。

## 0. 开篇:一张矩阵跑出一棵家谱

「两本抄本是否同祖」「HTR 错误会不会毁掉计量」「这块骨头
距今多少年」——三个考据级问题,能不能用代码说话?

[experiments/manuscript_stemma.py](experiments/manuscript_stemma.py)
把第一个问题做成了成品:模拟祖本经多轮抄写(形近趋同讹+
独有错)长出抄本树,再只用学者能看到的证据(读法矩阵)
聚类谱系,跑出三组断言:

- **谱系信号成立**:子树内共享罕见错误≫子树间,互配法
  恢复真实谱系;多数票临时定本≈84% 复原祖本——作统计
  底座够用,作校勘定本不够(断言①)
- **方法双边界**:错误率推向极端时信号淹没(祖传错误被
  覆盖+趋同讹增长);错误率过净时无错可共享——方法只活
  在中间区间(断言②)
- **HTR 稳健与质量门槛**:现实级识别噪声(随机误读+写手
  私有噪声)叠加后聚合仍稳健(单证人噪声被"全库恰 2 例"
  筛自动剔除);转录劣化过门槛,重建照样崩——数字化不是
  护身符,是管线纪律(断言③)

但脚本同时打印史学纪律:模型输出是零模型(机器化 T6),
真实传统的污染(混合抄本)未入模——**代码替你算结构,
替不了你裁谱系**。

## 1. 可机械化边界(三件套之一)

**能进代码的**(史料数据化后的一切统计):

| 任务 | 机械化形式 |
|------|-----------|
| 转录与识别 | 图像 → HTR/OCR 全文 + CER 评估 |
| 错误传播分析 | CER → 下游词频/共现偏差的传播统计(C1) |
| 谱系重建 | 变体矩阵 → 共享错误聚类/树搜索(C2) |
| 年代估计 | 残留比例/树轮序列 → 年龄+校准(C3) |
| 组合分析 | 器物共现 → 组合网络/相似度(C4) |
| 文本计量 | 语料 → 词频时序/关键词共现/主题(C5) |

**不能进代码的**(考据的"不可判定域"):

1. **选样正当性**——哪些器物入组合、哪些文本入语料,
   是史学判断;代码只能做敏感性分析
2. **断代裁定**——多法互证(碳十四/层位/类型学/天文回推)
   打架时,采信哪一票是人脑的活(02 章 T4 断代敏感性)
3. **谱系裁剪**——污染抄本该拆该合、趋同讹该认该剔,
   树搜索给候选,裁定给学者
4. **复原归因**——"按此工艺可制成"永远推不出"古人即用
   此工艺"(可行≠发生,T6 纪律)
5. **物质目验**——手感、墨色、刮痕的直接经验不出现在
   任何 surrogate 里(00 章反直觉③)

> 边界的一句话:**代码是史料的放大镜,不是考据官**。
> 放大一百万倍,断句还是学者的。

## 2. C1 HTR 错误传播走廊

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| engine / model | str | 不同引擎错误结构不同,换引擎=换数据 |
| cer | float | 无 CER 的全文不可入库引用(02 章 T5) |
| error_type | 随机/系统性 | 写手相关错误高度相关——不是独立噪声 |
| post_corrected | bool | 人工后校状态;校对范围须声明 |

典型问题:8% 的字符错误率会把词频统计改变多少?
关键结构(实验断言③的机理):识别错误**多为单证人私有
变体**——在跨证人比较里被稀有性筛自动剔除;但**写手
系统性错误**(同一引擎对同一写手反复认错)会伪装成
"共同特征",必须在管线里按写手分层评估。红线:计量
结论必须能追溯到转录层与 CER 标签(03 章三层结构)。

## 3. C2 文本聚类与谱系走廊(✅ 已实现)

本家族实验 `experiments/manuscript_stemma.py` 即本走廊成品:
变体矩阵 → 多数票临时定本 → 共享罕见错误 → 互配聚类;
对照全距离法演示稀有性筛的过滤价值;双边界(错误率过高/
过净)与 HTR 门槛一并跑通。扩展方向:污染(混合抄本)
建模——把树搜索换成网搜索,是真实校勘的前沿难题。

## 4. C3 年代估计走廊(最小示例)

```python
# 碳十四年代最小例:衰变定律 → 测量年龄(C3 走廊的种子)
HALF_LIFE = 5730.0   # 半衰期(年);Libby 半衰期 5568 为历史口径,引用须声明

def age_from_fraction(fraction_modern):
    """残留比例(相对活度)→ 距今年龄:N = N0·(1/2)^(t/T),
    返回 BP(基准 1950)。注意:这是"测量年龄"——树轮校准前
    不能直接当日历年龄用(校准曲线非线性,同一年龄可对应
    多段日历区间;报告须分列测量/校准两栏,02 章计量规范)。"""
    import math
    return -HALF_LIFE * math.log(fraction_modern, 2)

assert abs(age_from_fraction(0.5) - 5730) < 1     # 一个半衰期自检
assert abs(age_from_fraction(0.25) - 11460) < 1   # 两个半衰期
```

五行核心完成的事:物理定律 → 年代数字。史学的用法是**多法
互证的一票**:碳十四、层位、类型学、天文回推(如古记录
日食回推王表)各算各的,打架处即研究入口(00 章互证眼);
样品污染与老碳效应是这一票的已知偏差源,声明字段不可省。

## 5. C4 器物组合与共现走廊

器物登记表 → 共现矩阵(哪些器物总是同出)→ 组合相似度
(Jaccard 式集合交并)→ "技术套装"网络。史学价值:**把
奥兹行囊式的"一个人的全部技术"推广为可统计对象**——
孤品说"存在",组合说"生活"(02 章语境眼的可算版)。
坑:共现≠同时(扰坑混层,03 章);墓选偏置(葬俗筛选
组合,00 章④)。

## 6. C5 文本计量走廊

语料 → 词频时序、关键词共现、术语兴衰曲线。史学价值:
概念史/知识传播的规模读法(远读)。红线三连:**词频≠
意义**(同一概念换名即失踪);**元数据错则全线错**
(19 世纪文章标进 20 世纪的经典暗坑);**许可与选样**
(存世≠当时;许可锁死造成语料偏置——RHS 障碍表,
01 章热线四)。

## 7. 错误率即史观:管线参数的判断含量(使用本家族工具的正确姿势)

与技术史家族"参数即史观"同款警告,本家族版本落在管线上:

- **CER 阈值谁定**:不同的研究问题容忍不同的错误率
  (词频趋势可容 5%,异文比对不可容)——阈值是研究设计的
  一部分,不是工程缺省值
- **稀有性筛的"恰 2 例"**:随证人库扩容会变(新抄本入库,
  昔日的"罕见"变"常见")——筛参数绑定语料版本
- **写手分层**:把全部证人当一个总体评估识别质量,会
  系统性低估少数写手的损伤(01 章写手眼)

## 8. 工程师落点(三件套之三)

- **数字馆藏基建**:IIIF 图像接口、TEI 转录编码、元数据
  质量门禁——本家族 03 章 schema 的工业实现,博物馆/
  图书馆数字化项目的核心工程面
- **HTR 后校管线**:识别→置信度分层→人工校对队列→
  CER 监控,本质是带错误率标签的数据管线;众校平台
  (crowdsourcing)的队列与仲裁设计直接决定语料质量
  (实验断言③的工程面)
- **今天的工程是明天的 T2 档案**:部署日志、数据字典、
  决策记录写得可考,是工程师对本学科的供货
  (与[工程与技术科学基础](../../讲透工程与技术科学基础/README.md)
  的接口)
- **LLM 时代的新抄工**:大模型转录/翻译正在进入史料管线
  ——评估纪律照旧:没有错误率标签与人工抽检的输出,
  一律当 T5 机器抄本处理,不得升档

**🧠 认知升维**:

- **传播眼**:错误不是常数是变量——它在管线里走多远、
  被哪层筛掉,是可以算的结构
- **互证眼**:多法打架不是事故是常态——每票自带偏差源,
  裁决在人脑
- **管线眼**:看任何"数字人文结论",先看它的转录层与
  许可字段——结论的上游决定结论的成色
