# 讲透数字化与文本计量 · 规模读法:数字人文·HTR·文本挖掘(自定主干支)

> **定位句**:这支负责讲清**数字化这面透镜的放大与像差**——
> HTR 把手稿变成可检索全文(真放大),识别错误沿管线传播
> (像差);文本计量把细读换算成规模(远读),但词频≠意义、
> 许可锁语料、存世≠当时。本支的座右铭:数字化不是护身符,
> 是管线纪律。
> **出处声明**:学位目录 0712 不设官方二级,本支为**自定主干支**
> (宇宙[全自定主干支说明](../../../讲透科学技术史/README.md))。
> 家族:[讲透科技考古与文献](../README.md)。

## 诞生

三波谱系(家族 00 章 §1.6):布萨与 IBM 打孔卡启动《托马斯
著作索引》(1949-),计量时代开山;1990s-2000s 数字馆藏把
1665 年以来的期刊库存搬上网,surrogate 成常态;2010s- 手写
文本识别(HTR,Transkribus/READ 项目群)与"远读"
(莫莱蒂 2000/2005)让规模读法与细读并立。同期皇家历史学会
盘点"The Trouble with Text Mining"(文本挖掘的长期性与
加速条件)——能力清单与障碍清单并排,是本支的建制画像
(家族 01 章五热线即本支近史)。

## 核心问题(带年代锚)

- HTR 错误传播:识别错误多为单证人私有变体(可过滤),
  写手系统性错误伪装共同特征(须分层评估)——家族实验
  断言③的机理
- 机器抄本的证据级:T5 档,带 CER 标签方可引用(家族 02 章)
- 词频≠意义:同一概念换名即失踪——远读的语义边界(2000-)
- 语料许可与选样:存世≠当时,许可锁死造成语料偏置
  (RHS 障碍表)
- 非拉丁书写系统的 HTR:阿拉伯/婆罗米等传统的门槛更高
  (2025-12 阿拉伯文本分析 DH 会议,家族 01 章热线五)
- 虚拟复原(三维/数值模拟)的证据级标注——进行中,
  与科技考古支共用问题

## ✨ 这支最美的一个事实

"全库恰 2 例"的筛子:谱系学百年老方法里的稀有性筛
(只有恰好两个证人共享的读法才算谱系证据),在数字时代
意外获得第二职业——**同一道筛子既挡抄工的趋同讹,又滤
机器的单证人识别噪声**(家族实验断言③可跑)。最老的
考据纪律给最新的管线当质检:方法不死,只换对手。

## 假设与依赖

数字化忠实假设(家族 00 章④之三):surrogate 是有损代理,
物质性证据只活在原件上;HTR 低错且均匀的假设不成立
(写手相关)。分工:数字方法的技术史切面正主在
[讲透AI历史](../../../讲透AI历史/README.md),史料应用正主
在本支;期刊建制的社会面归科技社会史家族(宇宙波 4 在建,
文字提及);障碍表须随年份滚动校准(01 章热线四的代价)。
