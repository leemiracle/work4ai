# 讲透技术史文献与手稿 · 文本有谱系:手稿学·专利文献·期刊史(自定主干支)

> **定位句**:这支负责讲清**科技文本怎么考据**——科技史的
> 文本侧不止"读书":手稿有谱系(共同错误重建家谱),专利是
> 特殊文体(权利主张≠技术实施),期刊是 1665 年以来科学知识的
> 出厂形态。文本会撒谎(抄错/仿造/散佚),也会无意中说出
> 家世(错误即指纹)。
> **出处声明**:学位目录 0712 不设官方二级,本支为**自定主干支**
> (宇宙[全自定主干支说明](../../../讲透科学技术史/README.md))。
> 家族:[讲透科技考古与文献](../README.md)。

## 诞生

方法主干与古典学同源:马比荣《古文书学论》(1681)立文书
鉴定,拉赫曼 19 世纪以共同错误重建文本谱系,毛斯《文本考据》
(1927)成手册体(家族 00 章 §1.5)。科技文本自己再添两支:
专利制度(威尼斯 1474/英国垄断法 1624)制造出"技术的法律
自我描述"这一新文体;1665 年《哲学会刊》与《学者杂志》同年
创刊,科学知识获得定期出厂的出版形态。达芬奇手稿的研究史
(镜面字/散佚/重聚)是科技手稿考据的极限案例与百年现场。

## 核心问题(带年代锚)

- 共同错误原则的适用域:污染(混合抄本)使树成网——
  硬边界(家族实验断言②的极端演示)
- 原件-抄本-辑本-译本的降档链:隔一手降一档(家族 02 章
  阶梯 T3)
- **图文混排手稿**:文字可校勘,机械图重摹无共同错误可用
  ——图的谱系是开放难题(达芬奇手稿即典型)
- 专利文献:权利主张≠实施(与技术史家族共用降档,1474/1624 锚)
- 期刊作为证据:创刊宗旨/审稿演变/传播范围——建制面归
  科技社会史家族(宇宙波 4 在建,文字提及),文献面归本支
- 学者通信作为史料类型:非正式知识渠道与正式出版对读

## ✨ 这支最美的一个事实

达芬奇手稿的千年漂流:左右镜像书写(通说按左撇子避蹭墨
解释,无定论),继承人梅尔齐守护未刊,身后散伙——《莱斯特
手稿》1994 年被盖茨以 3080 万美元购得并数字化公开。
**一个人的私人笔记,走了五百年从工作室到云端**:科技手稿
的存世从来不是技术问题,是继承、战争、市场与偶然的接力
(00 章文本选样链的活标本)。

## 假设与依赖

传承选样链(家族 00 章④之二):存世是接力事故,祖本几乎
必失;谱系结论受污染与趋同讹双威胁。分工:通用校勘学与
版本学方法正主在[历史学宇宙·历史文献学](../../../讲透历史学/讲透历史文献学/README.md),
本支只取科技文本(手稿/专利/期刊)
的特有问题;思想内容的解读正主在
[讲透科学思想史](../../../讲透科学技术史/讲透科学思想史/README.md),
本支管载体。

## 教材锚

- Maas《文本考据》(Textkritik,1927——谱系方法手册体正典)

- 《考工记》(先秦)——科技文本与实测器物对读的经典案例
  (家族 02 章六齐之谜)
