# 讲透科技考古 · 实物无言:实验考古·器物复原·田野方法(自定主干支)

> **定位句**:这支负责讲清**器物怎么开口说话**——实物不会
> 自报年代、用途与工艺,一切属性靠"提问"获得:检测问材质,
> 类比问功能,复原实验问可行。科技考古是双关:用科技手段读
> 考古材料(XRF/CT/AMS),也考"科技"本身的古(古代技术知识
> 的物质遗存)。
> **出处声明**:学位目录 0712 不设官方二级,本支为**自定主干支**
> (宇宙[全自定主干支说明](../../../讲透科学技术史/README.md))。
> 家族:[讲透科技考古与文献](../README.md)。

## 诞生

古物著录两先河(吕大临《考古图》1092 与欧洲古物学,家族 00
章 §1.1)只到著录为止;方法生于 19 世纪:汤姆森三期法(1816
起/1836 刊)给器物排序,地质层位思想进入遗址,田野考古成形。
20 世纪两翼齐飞:科技检测入考古(碳十四测年 1949 起,各类
光谱与成像跟进),实验考古学立规范(阿舍尔 1961 呼吁,科尔斯
《实验考古学》1973 成书)。"科技考古"由此成为建制名词。

## 核心问题(带年代锚)

- **实物无言三问**:某属性靠检测、类比还是复原得出?——
  方法论核心(00 章中心问题)
- 组合与孤品:离开共出语境,单件器物还能说什么——奥兹行囊
  (1991)为范式案例
- 断代多法互证:碳十四(1949-)/层位/类型学/天文回推打架时
  怎么裁——每票自带偏差源
- 复原的证明力:**可行≠发生**(科尔斯 1973 纪律);虚拟复原
  (三维/数值模拟)的证据级如何标注——进行中
- 使用痕与微痕分析:工具怎么被用(磨损证据)——进行中
- 金属回收与幸存偏置:存世青铜器是"逃过回炉"的样本
  (家族 00 章反直觉①)——估古代技术水位的系统性难题

## ✨ 这支最美的一个事实

奥兹冰人的行囊(约前 3300):铜斧、未完成的弓与箭、桦皮
容器、火绒草药、皮衣草鞋七十余件——**一个普通技术使用者
一天的全套技术,被冰川无筛选地封存**(与家族 00 章美之时刻
③共用此证词)。没有王侯葬俗的筛选,没有回收炉:史前技术
生活第一次以"组合"而非"孤品"面目出现——语境眼的极致样本。

## 假设与依赖

幸存偏置最重的一支(家族 00 章④之一):埋藏筛选+金属回收
双重过滤;复原结论一律标 T6(可行≠发生),检测结论标 T1、
类比断代标 T4 并声明比对基型。分工:复原方法正主在本支,
技术演进叙事正主在[讲透技术史](../../../讲透科学技术史/讲透技术史/README.md)
(已链前查证);地层与田野方法的本体
上游在[历史学宇宙](../../../讲透历史学/)。
