# 科技考古与文献思维技能卡(0712 自定 · 讲透科技考古与文献家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「这件古代器物是干嘛的/某古代工艺怎么复原」——
  实物无言三问(检测可答/类比可推/复原假设)
- 「某抄本/某辑本/某译本可信吗」——数手眼+谱系眼
- 「两个版本哪个更接近原貌」——共同错误原则
- 「OCR/HTR 全文能不能直接用来研究」——T5 机器抄本
  纪律(CER 标签/写手系统性错误)
- 「文本计量/远读能发现什么」——能力与障碍双清单
  (词频≠意义;RHS 障碍表)
- 「碳十四/类型学断代打架信谁」——多法互证,每票带偏差源
- 「复原实验证明了古人怎么做吗」——可行≠发生(T6)
- 器物描述与文献记载对不上——双轨互证眼(冲突即入口)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **无言眼** | 器物不自报属性;一切属性是被提问问出来的——检测、类比、复原各答一层,问什么决定得到什么 |
| **数手眼** | 传世文本先数"这是第几手";隔一手降一档,谱系未明当末梢 |
| **好错眼** | 共享的显著错误=共同祖先的签名;一个好错胜过十处相同的正确 |
| **语境眼** | 孤品无词,组合成句;层位先于类型学,语境先于形制 |
| **三层对齐眼** | 器物描述对齐材质工艺/功能推断/语境组合,打架处即研究入口 |
| **幸存眼** | 存世≠主流:埋藏筛选+金属回收+传承选样链,三重过滤后的样本 |
| **CER 眼** | 看到"数字全文"先问错误率标签;无标签的机器抄本不可引用 |
| **互证眼** | 实物与文献对不上时先别裁决——冲突处即研究入口(六齐之谜) |

## 3. 工具箱(何时用什么)

- **T1-T6 考据断言阶梯**:T1 出土物证→T2 流转档案→T3 抄本
  (隔手降档)→T3' 专利(主张≠实施)→T4 类比通说→T5 机器
  抄本(带 CER)→T6 复原反事实(可行≠发生);动词即类型签名
- **共同错误原则**:两证人共享显著错误≈共祖;配多数票
  临时定本+稀有性筛(全库恰 2 例)——家族实验
  `experiments/manuscript_stemma.py` 为最小实现
- **复原三问**:该结论靠检测、类比还是复原实验得出?
  复原只证可行,永证不了发生
- **双轨互证法**:实物链与文本链各自成链,并轨前先问
  它们是否在回答同一个问题
- **多法断代互证**:碳十四(BP/校准分列)/层位/类型学/
  天文回推各算各,每票声明偏差源
- **语料三层结构**:图像/元数据/转录层——计量只碰第三层,
  引用必引第二层与 CER

## 4. 常见误区与禁忌

- ❌ **复原直读**:把实验复原当古代工艺实录(T6 当 T2)
  ——可行≠发生是本家族第一纪律
- ❌ **抄本当原件**:引传世文本不数手数、不问谱系
  (T3 一路当 T2 用)
- ❌ **无标签机器抄本**:OCR/HTR 全文直接引用不附 CER
  与后校状态(数字时代头号病)
- ❌ **词频直推意义**:同一概念换名即失踪;远读与细读
  是互补不是替代
- ❌ **孤品讲故事**:单件器物说"存在",共出组合才说
  "生活";脱离层位的器物自动降档
- ❌ **数字化=保存**:surrogate 是有损代理;物质性证据
  (刮改/墨色/装订)只活在原件上
- ❌ **单票断代**:只引一种断代法不声明偏差源
  (类比断代自带断代敏感性)
