# 03 · 可构造与结构——器物、谱系与语料:史料作为数据对象

> **本章回答五问之 Q4(可构造性与结构)**。
> **本质一句话**:本家族里"可构造"的不是历史本身,而是
> **史料的组织方式**——器物是带语境的记录、文本是带谱系的
> 矩阵、语料是带错误率标签的分层文档;而"结构"是史料世界
> 自己的骨架:双轨(实物/文本)各自成链,数字化把两条链
> 接进同一座仓库。

---

## 0. 开篇:一张变体矩阵就是一棵家谱的影子

打开任何一部古籍的校勘记,你都会看到同一张表:**行=存世
抄本(证人),列=变体位点(locus),格=该本在该处的读法**。
这张"变体矩阵"就是谱系树的影子——两行在多位点共享同一
罕见读法,这两行大概率同祖。器物侧有完全同构的东西:器物
登记表(行=器物,列=材质/形制/纹饰/层位),类型学就是在
这张表上做聚类。**史料研究的"可构造",几乎全部落在
这两张表上**——这是 01 章数字管线有浪可乘的根本原因。

## 1. 什么是"可构造"的:五类史料对象

| 对象 | 数学化身 | 可构造性 | 构造中的坑 |
|------|---------|---------|-----------|
| **器物记录** | 结构体 (器物号/材质/形制/层位/组合/检测) | ✅ 完全可构造(著录规范) | provenance 断链即降档(02 章 T2→争议) |
| **变体矩阵** | 表 (证人×位点→读法) | ✅ 高度可构造(校勘记即其印刷形态) | 转录粒度之争(逐字/逐词);图的变体不可表 |
| **手稿谱系树** | 树 (祖本→抄本) | ✅ 可构造(04 章 C2,实验成品) | 污染(混合抄本)使树变图;趋同讹制造假边 |
| **文本计量语料** | 文档集+元数据+转录层 | ✅ 可构造(03 章 schema) | HTR 错误沿管线传播;许可锁死造成选样 |
| **年代测定** | 数值 (年龄±误差, 校准前后) | ✅ 可构造(贝叶斯校准管线) | 测量年龄≠校准年龄;样品污染须声明 |

**不可构造的**:工匠的手感与口诀(身体知识不出现在任何
矩阵里)、"典型性"的客观函数(幸存样本无随机性可言)、
机械图的重摹谱系(重摹无共同错误可用——00 章 §1.5)、
以及一切"谁影响了谁"的思想因果(文本谱系只证传抄)。

### 1.5 五类对象的最小数据模式(动手者的 schema)

```yaml
# 器物记录(科技考古支的字段源)
find: {id: str, material: str,          # 材质(检测报告编号引用)
       technique: str, form: str,       # 工艺/形制(类型学比对单位)
       stratigraphic_unit: str,         # 层位号:语境即证据(可空=馆藏品)
       assemblage: [str],               # 共出组合:语境的单位
       measurements: {dim: float},      # 测绘尺寸与单位口径
       c14: [{age_bp: float, error: float,
              calibrated: bool}],       # BP 基准 1950;校准分列
       provenance: [str],               # 流转链;断链处显式标注
       source_tier: T1..T2}             # 出土=T1;馆藏断链自动降档

# 证人(手稿/抄本)与变体矩阵(文献与手稿支)
witness: {siglum: str, repository: str, shelfmark: str,
          date: str, script: str,       # 书体(古文书学断代依据)
          extant: bool, folios: int,
          source_tier: T3}              # 抄本默认 T3:隔一手降一档
collation: {loci: [[str]],              # 每位点的各证人读法(矩阵主体)
           transcription: {agent: 人|HTR,
                            cer: float}}  # 机器抄本必须带 CER 标签

# 语料文档(数字化与文本计量支)
corpus_doc: {doc_id: str, year: int, author: str,
             venue: str,                 # 期刊/手稿库(1665- 期刊史锚)
             tokens: [str],              # 分词层(粒度声明)
             ocr_htr: {engine: str, cer: float,
                       post_corrected: bool},   # 无标签不可引用
             license: str,               # 许可状态:RHS 障碍表的字段
             source_tier: T2..T5}
```

注意三条自带纪律:器物的**层位与流转分列**(出土语境和
收藏经历是两条链);证人与语料的**转录状态必填**(人工/
HTR/CER/是否后校);每条记录自带 `source_tier`——
**数据层自带证据等级与错误率标签,是史料计算区别于普通
数据分析的第一特征**(技术史家族同款纪律,本版多了
CER 标签与 provenance 断链声明)。

## 2. 骨架一:双轨证据链(实物与文本各自成链)

- 实物链:出土(层位/组合)→ 检测(材质/工艺)→ 著录
  (博物馆)→ 数字化(三维/影像)——每一环都可能断
  (provenance 断链)或失真(清洗破坏)
- 文本链:著者手稿(autograph,几乎必失)→ 祖本(推定)
  → 中间支本 → 存世抄本 → 印本 → 数字转录——每一环
  都引入错误(抄写)并做选样(收藏/焚毁)
- **双轨的用法是互证而不是并轨**:六齐文本与青铜实测对不上,
  不是谁错,是两链回答不同问题(00 章互证眼);强行并轨
  (拿文献"校正"器物数据,或反之)是本家族头号方法错误

## 3. 骨架二:变体矩阵与谱系树(文本的家谱几何)

- 变体矩阵(证人×位点)是原始事实,谱系树是它的**生成
  模型**:树解释了矩阵里的大部分共享读法
- 罕见读法的分布=树形的指纹:两位点仅存于一对证人
  →他们的共同祖先引入了它(实验断言①的可跑版)
- 树失效的两处:**污染**(抄本据两本拼合,证据成网不成树)
  与**趋同讹**(独立发生的相同错误,假边)——真实校勘
  的两大硬边界,实验断言②演示后者的极端情形
- 器物侧同构:类型学=变体矩阵上的聚类;**但堆积会混层
  (扰坑/回填),层位学先于类型学**——先证语境再比形制,
  顺序不可反

## 4. 骨架三:语料的三层结构(文档/元数据/转录)

- 第一层**文档图像**(surrogate,有损代理);第二层
  **元数据**(作者/年份/载体/许可);第三层**转录层**
  (文本本体,人工或 HTR,带 CER)
- 计量只许碰第三层,引用必须同时引第二层(元数据错则
  全线错——"19 世纪的期刊文章被元数据标进 20 世纪"是
  文本计量的经典暗坑)与第三层的错误率标签
- 语料结构里藏着**幸存声明的字段位**:哪些存世、哪些被
  扫描、哪些锁在许可里(01 章热线四:RHS 障碍表的结构化
  收纳)——选样链没有终点,只有显式声明

## 5. 从结构到比较:这套骨架买到了什么

- 双轨链 → 实物与文献的对勘坐标(六齐式冲突的系统化)
- 变体矩阵+谱系树 → 文本传统的"体检表":哪段抄写密集、
  哪段静默(断档)
- 语料三层 → 计量结论的可追溯性:每个词频都能回到那张
  图像与那次转录(错误率可查)
- 器物组合 → 语境统计:共现网络里的"技术套装"(奥兹
  行囊的结构化推广)

## 6. 构造合法性清单(动手前三问)

把任何史料变成数据结构之前,先过三问——本家族的
"类型检查":

1. **语境分离了吗**:出土信息与馆藏流转是两个字段吗?
   provenance 断链声明写了吗?——没有层位的器物是
   "孤品",孤品无词(02 章语境眼)
2. **转录声明了吗**:转录是人还是引擎?CER 多少?
   后校过吗?——无标签的机器抄本不可入库
3. **幸存声明了吗**:这批数据从哪条选样链来(存世/扫描/
   许可),头部写了吗?——不同选样链的数据不可直接
   拼接比较(军事史/技术史家族同款纪律,本版落在
   provenance 与许可字段)

三问全过,数据才获得进入 [04 章走廊](04-科技考古与文献转代码.md)
的资格。**史料计算的第一特征不是算法,是入库纪律**。

## 📌 收束

可构造的是**史料的组织方式**(记录/矩阵/树/语料),
不可构造的是**身体知识与典型性**;结构不是装饰,是
双轨互证的坐标系。下一章把这些 schema 接上代码:
HTR 错误传播/谱系重建/年代估计走廊:
[04-科技考古与文献转代码](04-科技考古与文献转代码.md)。

**🧠 认知升维**:

- **矩阵眼**:任何校勘记/器物表先看成矩阵——行间共享的
  罕见值就是结构的指纹
- **断链眼**:读任何馆藏器物先找 provenance 断点——
  断点之前的叙事都是附会的高发区
- **标签眼**:数据没有错误率标签,就等于没有出生证
