# 02 · 语言特征——原件·抄本·层位:考据语言的语法与阶梯

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)**。
> **本质一句话**:这门学科说三种话——**著录语言**(这件东西
> 是什么:材质/形制/层位/组合)、**谱系语言**(这个文本从
> 哪来:原件/抄本/祖本/异文/讹)与**论证语言**(何以见得:
> 证据分级)。全部手艺在于:描述与推断不断线,推断与证据
> 不越权——"存世铜斧显示"与"通说认为"永远不是同一句话。

---

## 0. 开篇:六齐之谜——配方文本与器物各说各话

📖 **故事框:《考工记》"金有六齐"**。先秦工艺典籍《考工记》
记青铜配比六方("六分其金而锡居一,谓之钟鼎之齐"……)。
现代实测商周青铜器成分,却与六齐配比对不上——学界至今
解释纷纭:理想配比方?"金"指铜还是合金?度量口径不同?
**文本说了配比,器物说了另一个配比**——科技文本考据的
日常正是这种对峙:两边都是真的,错的是我们以为它们在回答
同一个问题(00 章互证眼:冲突即入口;T3 文本与 T1 实测
的降档各记各的账)。

## 1. 表达力:考据语言能说什么(三栏之一)

**著录语言能说的**(器物侧):

| 能力 | 例 |
|------|-----|
| 材质与工艺陈述 | "斧刃为近乎纯铜,铸造组织,锻打痕迹见于銎部"——可检测可复核 |
| 形制陈述 | "双耳三足,饕餮纹带见于颈部"——类型学的比对单位 |
| 层位陈述 | "出土于第 3 层,压于第 2 层下,与 B 组陶器共存"——语境即证据 |
| 组合陈述 | "七十余件器物与衣物同出"(奥兹行囊)——横断面样本 |
| 流转陈述 | "1902 年入藏,购自古董商,出土记录缺失"——provenance 链 |

**谱系语言能说的**(文本侧):

| 能力 | 例 |
|------|-----|
| 载体陈述 | "羊皮纸重写本,下层 10 世纪,上层 1229 年" |
| 传抄陈述 | "甲乙二本同讹'若'作'苦',共祖可立"——共同错误原则 |
| 校勘陈述 | "底本从众,异文出注;讹脱衍倒分类著录" |
| 科技文本特有 | 数值表(星表/历表)与图说(机械图)——文字可校勘,**图的重摹无共同错误可用**(00 章 §1.5) |

**两种语言都不能说的**:

- **不能进工匠的皮肤**:手感、口诀、师徒面授——文字与器物
  双双沉默的部分(口述与民族志是补丁,不是解)
- **不能自证"典型"**:存世样本经过幸存过滤(00 章④),
  "典型器物"永远是幸存者中的典型
- **不能给"影响"上秤**:谁学了谁,文本谱系只证传抄,
  不证思想影响(思想史家族的题)

## 2. 逻辑性质:断言的证据约束(三栏之二)

| 性质 | 考据断言 | 备注 |
|------|---------|------|
| "真值" | 分级(证据支持度),随检测与新出材料可修订 | 六齐之争即活例 |
| 底线一致性 | 不得与器物本体及层位矛盾 | 检测结果压倒文献通说(器物不会改口) |
| 完备性 | 永不完备——传承链断档是常态 | 祖本几乎必失(00 章④之二) |
| 反事实 | 可用但须显式标记(T6) | 复原实验"可行"即反事实级 |
| 可重复性 | 检测可重复,发掘不可重复 | 遗址挖开即毁——记录纪律的根源 |

### 2.5 断言强度的写法阶梯(科技考古与文献版)

承[史学理论](../../讲透历史学/讲透史学理论/README.md)证据
分级,本家族把确定性编码在措辞里——**动词就是类型签名**
(与技术史/法律史家族同款纪律,本版有四处特有改动):

| 阶梯 | 措辞 | 证据状态 | 本家族特有注意 |
|------|------|---------|---------------|
| T1 出土物证级 | "出土器物/层位关系显示" | 物证+埋藏语境在场 | 幸存者偏置:存世≠主流;孤品≠组合 |
| T2 流转档案级 | "发掘记录/馆藏档案载" | 建制一手文献 | provenance 断链的器物自动降到争议档 |
| T3 抄本谱系级 | "某抄本载/异文作" | 传世二手文本 | **隔一手降一档**:抄本≠祖本;谱系未明先当末梢 |
| T3' 专利级 | "专利文件声称" | 法律主张文本 | 权利主张≠实施(与技术史家族共用降档) |
| T4 类比通说级 | "与某期形制相近/学界一般认为" | 类型学比对/多源趋同 | 类比断代自带断代敏感性,须标比对基型 |
| T5 机器抄本级 | "HTR 转录作/数字全文作" | 识别输出 | **数字时代特有档**:机器抄本带 CER 错误率标签方可引用;引擎系统性错误须声明 |
| T6 复原反事实级 | "按此工艺可以制成" | 实验或模拟输出 | **可行≠发生**;虚拟复原更须标注成像→推断链 |

**误用告示**:三大头号病——①把 T5 当 T2(OCR/HTR 全文
当原件转录直接引用);②把 T6 当 T2(复原实验当古代工艺
实录);③把 T4 当 T1(类型学类比当实测断代)。

### 2.6 器物描述的内部语法:三对齐

合规的器物描述须三层对齐:**材质工艺**(靠什么做的)↔
**功能推断**(用来做什么)↔**语境组合**(在哪、与什么
同出)。三层打架即红旗:斧刃合金太软(材质)却推为武器
(功能)、又出于随葬组合(语境)——要么改推断,要么补
证据。**读器物先对三层,等于史学文本的"先查引证"**
(与技术史家族"三本词典"同构,考古版把"脚本"换成
"语境")。

## 3. 规范化程度:术语、著录与对译(三栏之三)

- **著录标准化**:博物馆/考古著录规范(器物号、层位号、
  测绘图、检测报告编号)是事实上的数据交换格式;三维模型
  与影像是标配证据(03 章 schema 直接来源)
- **计量规范**:碳十四年代必须带误差与"BP(以 1950 年为
  基准)"标注,树轮校准前后须分列;古今单位(石/斗/斤/
  马力)换算须注明换算率与口径
- **命名规范**:器物以"出土地+层位/单位号"建档而非以
  传言命名;手稿以藏书机构+编目号立档(达芬奇手稿的
  "莱斯特手稿"式私人命名须附流转链)

**术语规范与对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 手写文本识别 | HTR (handwritten text recognition) | 不等于 OCR(印刷体识别);HTR 错误与写手相关且系统相关 |
| 实验考古学 | experimental archaeology | 不是"体验式考古":演示/体验≠假设检验(阿舍尔-科尔斯规范) |
| 溯源/递藏 | provenance | 双义:出土语境与收藏流转链;拍卖行 provenance ≠ 考古 provenance |
| 谱系树 | stemma (codicum) | 借自家谱而无基因;谱系可重建但须防污染(混合抄本) |
| 祖本 | archetype | ≠"原著":祖本是**推定的**共同祖先,几乎必已亡佚 |
| 作者手稿 | autograph | 与祖本分立:达芬奇手稿是 autograph,不是 archetype |
| 对校/定本 | collation / recension | collation=机械比对,recension=判断定本;中文"校勘"兼两义,引用时须分 |
| 变体位点 | locus | 非"地点":文本的可变异单位(词/字位) |
| 层位学 | stratigraphy | 借自地质学;"地层"推"遗址堆积层",压叠关系=时间关系 |
| 器物组合 | assemblage | 不是统计"聚合":指共出的器物群,语境的单位 |
| 碳十四年龄 | radiocarbon age (BP) | BP 以 1950 为基准,"距今年"不是"公元前";须区分测量年龄与校准年龄 |
| 重写本 | palimpsest | 刮掉重写的羊皮卷;引申义("层积")使用须标借用 |
| 数字替身 | digital surrogate | 不译"数字副本":surrogate 自认有损代理(00 章反直觉③) |
| 远读 | distant reading | 不是"粗读":规模化读法与细读互补,不相对立 |
| 字符错误率 | CER (character error rate) | 转录质量的标配标签;无 CER 的 HTR 全文不可直接引用 |

## 📌 收束

考据语言=**著录层管"这东西是什么"(材质/形制/层位),
谱系层管"这文本从哪来"(原件/抄本/异文),论证层管
"何以见得"(T1-T6 阶梯)**,中间靠"隔一手降一档"与
"机器抄本带错误率标签"两条纪律粘合。下一章把这套语言
压成数据:器物、谱系与语料怎么变成可构造对象:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **数手眼**:读任何传世文本先数"这是第几手"——
  隔一手降一档,谱系未明当末梢
- **CER 眼**:看到"数字全文"先问错误率标签——
  无标签的机器抄本不可引用
- **语境眼**:孤品无词,组合成句——单件器物说"存在",
  共出组合才说"生活"
- **三层对齐眼**:材质/功能/语境打架处即研究入口
  (六齐之谜的读法)
