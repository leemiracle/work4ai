## 学习范式（2024-2026 主流）

### 1. 模仿学习（Behavior Cloning / DAgger / ACT）
- **ACT**（Action Chunking Transformer）：阿里 ALOHA 系统的核心，chunk 动作减少误差累积
- **Mobile ALOHA**（2024）：移动 + 双臂，开源，B 站有大量复现
- **Diffusion Policy**（2023）：把动作生成当 diffusion，处理多模态分布

### 2. 强化学习（RL）
- 在仿真里大量训练 + domain randomization（OpenAI 手立方体路线）
- **宇树/智元**的 locomotion 大量用 sim2real RL

### 3. 大模型驱动（VLA / LLM Planning）
- LLM 做高层任务规划（SayCan/VoxPoser/Code as Policies）
- VLM 做视觉理解
- 低层控制用 RL/模仿

### 4. 世界模型 + 想象
- DayDreamer（Dreamer V3 在机器人上）
- NVIDIA Cosmos 物理世界模型

## 选型决策树

```
你的机器人应用是?
│
├─ 单一重复任务(分拣/焊接/扫地)
│  → 专用机器人 + 传统控制/简单视觉(成熟便宜)
│
├─ 半结构化(物流/装配)
│  → 协作机器人 + 力控 + 简单 RL
│
├─ 非结构化需要泛化(家庭/服务)
│  → VLA + 模仿学习 + 大量示教数据
│
└─ 通用具身(赌未来)
   → 人形 + VLA + 世界模型
   (注意: 这是高风险高回报, 离生产还远)
```

## 五条经验法则

1. **能上专用就别上通用**——专用成熟便宜。
2. **Sim2Real 必须做 domain randomization**——否则部署即崩。
3. **VLA 是趋势但还不成熟**——2026 年仍处 demo→早期部署。
4. **数据是最大瓶颈**——比模型本身更重要。
5. **媒体 demo 打 3-5 折**——看「30 分钟自主操作」才算数。

## 🎬 五幕收束

> 机器人 = 物理世界的 Agent。难度在物理（Moravec 悖论），不在算法。**2024-2026 浪潮**：VLA 把大模型接入机器人，人形机器人百花齐放（中国宇树/智元/银河通用等是全球重要玩家）。
>
> **当前阶段**：专用机器人成熟，人形处于 demo→早期部署。**别信「通用机器人全面替代人工」——至少 5-10 年**。但 VLA + 世界模型 + 具身数据的合流，正在快速逼近临界点。
>
> 用 Moravec 收尾：**对人容易的对 AI 极难，但亿万年进化的能力正被深度学习逐步攻克**。机器人是 AI 的下一座大山。
