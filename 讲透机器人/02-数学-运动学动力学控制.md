# 📐 第 2 幕 · 数学：运动学、动力学、控制、李群

## 1. 运动学（Kinematics）：关节角 → 末端位置

### 正运动学（FK）
给定关节角 $\theta$，求末端执行器位置 $T \in SE(3)$。

**DH 参数法**（Denavit-Hartenberg）：每个连杆 4 个参数 $(a, \alpha, d, \theta)$，变换矩阵：

$$T_i^{i-1} = \text{Rot}_z(\theta_i) \text{Trans}_z(d_i) \text{Trans}_x(a_i) \text{Rot}_x(\alpha_i)$$

总变换：$T_n^0 = T_1^0 T_2^1 \cdots T_n^{n-1}$。

### 逆运动学（IK）—— 难题
给定目标位置 $T$，求关节角 $\theta$。

- **解析解**：特殊结构（如 6 轴工业臂有 Pieper 解）。快但限特定几何。
- **数值解**：Jacobian 迭代。通用但可能不收敛、有多解/无解。

$$\dot{x} = J(\theta) \dot{\theta} \Rightarrow \dot{\theta} = J^+ \dot{x} + (I - J^+ J) z$$

$J^+$ 是伪逆，$(I-J^+J)z$ 是零空间项（冗余自由度自运动）。

### POE 公式（指数积）
Modern Robotics 推崇：用 SE(3) 的指数坐标

$$T = \prod_i e^{[\mathcal{S}_i]\theta_i}$$

$[\mathcal{S}_i]$ 是旋量 $\mathcal{S}_i$ 的 $4\times4$ 反对称矩阵。比 DH 更几何、无连杆坐标系累赘。

## 2. 李群李代数：刚体变换的语言

### SE(3) 与 SO(3)
- $SO(3)$：旋转群（3D 旋转）
- $SE(3)$：刚体变换群（旋转+平移），$4\times4$ 齐次矩阵

### 指数映射
$$e^{[\omega]\theta} = I + \sin\theta [\omega] + (1-\cos\theta)[\omega]^2 \quad (\text{Rodrigues 公式})$$

$[\omega]$ 是单位旋转向量 $\omega$ 的反对称矩阵。这把「旋转角度」变成「旋转矩阵」。

### 为什么李群对机器人重要
- **避免欧拉角的万向锁**（Gimbal Lock）
- **插值自然**：球面线性插值（SLERP）
- **求导自然**：在李代数 so(3) 上做（避免流形上求导的复杂性）
- **优化自然**：SLAM 后端在李代数上做高斯-牛顿

**国内教材推荐**：高翔《视觉 SLAM 十四讲》第 3-4 章讲得最透，B 站有配套视频。

## 3. 动力学（Dynamics）：力与运动

### 拉格朗日方程
$$L = T(q, \dot q) - V(q)$$
$$\frac{d}{dt}\frac{\partial L}{\partial \dot q_i} - \frac{\partial L}{\partial q_i} = \tau_i$$

$q$ 广义坐标，$\tau$ 广义力。展开成操作臂标准形式：

$$M(q)\ddot q + C(q, \dot q)\dot q + G(q) = \tau$$

- $M(q)$：惯性矩阵（关节耦合）
- $C(q, \dot q)\dot q$：科氏力+向心力
- $G(q)$：重力项

### 牛顿-欧拉
递归算法：从基座向前算速度/加速度（递归），从末端向后算力（递归）。计算 $O(n)$，工业仿真用。

**为什么动力学重要**：要精准控制高速运动，必须补偿 $M/C/G$。否则会有振荡/过冲/能量浪费。

## 4. 控制（Control）

### PID（最常用）
$$u(t) = K_p e(t) + K_i \int_0^t e \,d\tau + K_d \dot e(t)$$

$e = r - y$ 误差。简单鲁棒，但不知系统模型→对非线性系统（机器人）性能有限。

### 计算力矩控制（Computed Torque）—— 机器人专用
利用动力学模型补偿非线性：

$$\tau = M(q)\ddot q_d + C(q,\dot q)\dot q + G(q) + K_p e + K_d \dot e$$

选 $\ddot q_d$ 让误差 $e$ 收敛。**理论上把非线性系统线性化**——如果模型准，性能极好。

### LQR（线性二次型调节器）
线性系统 $\dot x = Ax + Bu$，最小化：
$$J = \int_0^\infty (x^T Q x + u^T R u) dt$$

最优控制律 $u = -Kx$，$K$ 由 Riccati 方程解出。**用于倒立摆/平衡控制**。

### MPC（模型预测控制）—— 现代主流
每一步求解有限时域最优控制：
$$\min_{u_{0:N-1}} \sum_{k=0}^{N-1} \ell(x_k, u_k) + V_f(x_N)$$
约束：$x_{k+1} = f(x_k, u_k),\ u \in \mathcal{U},\ x \in \mathcal{X}$

**优点**：能处理约束（关节限位、避障）；**缺点**：每步求解 QP/NLP，算力消耗大。

### 阻抗控制（Impedance）
让机器人末端表现得像「弹簧-阻尼」：
$$F = M_d \ddot x + B_d \dot x + K_d (x - x_d)$$

**用于接触任务**（装配、擦拭）：避免刚性碰撞损坏工件。

## 5. SLAM：感知的核心

### 贝叶斯滤波
$$bel(x_t) = \eta \, p(z_t | x_t) \int p(x_t | u_{t-1}, x_{t-1}) bel(x_{t-1}) dx_{t-1}$$

预测 + 更新两步。

### EKF（扩展卡尔曼滤波）
非线性系统一阶泰勒展开。SLAM 经典方法。

### 图优化（现代 SLAM 主流）
把 SLAM 变成因子图最小二乘：
$$\min_X \sum_i \|h_i(X) - z_i\|_{\Sigma_i}^2$$

**g2o / GTSAM / Ceres** 是主流库。高翔《视觉 SLAM 十四讲》后半本讲这个。

## 6. 规划（Planning）

### 路径规划（构型空间）
A* / Dijkstra 在栅格；RRT/RRT* 在连续空间；CHOMP/TrajOpt 用轨迹优化。

### 运动规划
考虑动力学约束的轨迹生成：minimum-jerk、Time-Scaling。
