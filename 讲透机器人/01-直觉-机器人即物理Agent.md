# 🤖 第 1 幕 · 直觉：机器人即物理 Agent

## 一个根本性区分：屏幕智能 vs 物理智能

迄今你学过的所有 AI（LLM/CV/RL/Agent）大多是**屏幕智能**——它们在数字世界里运行，错误了重来，没成本。

机器人是**物理智能**——它要在真实世界里**动**。动的代价是真实的：
- 撞了 → 设备坏了（钱）
- 砸到人 → 受伤了（法律责任）
- 错了 → 物理过程不可 Ctrl+Z

**整部「讲透机器人」的核心张力**：把数字智能搬到物理世界，要付出指数级增加的难度。

## 感知-决策-行动：机器人的三段闭环

任何机器人系统，本质是这个闭环：

```
        感知 Perception
       (我在哪? 世界什么样?)
              ↓
        决策 Decision
       (目标是什么? 怎么到?)
              ↓
        行动 Action
       (每个关节怎么动?)
              ↓
    ┌────────────────────┐
    │   物理世界执行      │ ← 摩擦、惯性、噪声、接触、延迟
    └────────────────────┘
              ↓
        新的感知 ────→ 回到顶部
```

三个子问题各自是一门大学问：
- **感知**：SLAM（同时定位与建图）、物体识别、姿态估计
- **决策/规划**：路径规划（A*/RRT）、运动规划、任务规划
- **行动/控制**：PID、MPC、力控、阻抗控制

**关键**：三者**强耦合**。感知错→决策错→行动错→感知更错。这是机器人比纯 AI 难的根源。

## 控制论：机器人的思想起源

Norbert Wiener 1948 年的《控制论》（Cybernetics，希腊语「舵手」）提出：

> **机器和生物共享同一原理：负反馈闭环。** 系统感知自身状态，与目标对比，调整行动减小偏差。

这是 PID 控制的思想源头，也是「感知-决策-行动」闭环的鼻祖。Wiener 当时在研究**高射炮瞄准**（预测飞机轨迹）——战争催生了控制论。

**机器人 = 控制论 + 物理执行器**。一切机器人都是 Wiener 闭环的物理实现。

## Moravec 悕论：为什么走路比下棋难

Hans Moravec 1988 年指出反直觉现象：

| 任务 | 对人 | 对 AI（1988 年）| 进化年龄 |
|---|---|---|---|
| 下棋、数学、写代码 | 难（要训练）| **易**（深蓝 1997 击败卡斯帕罗夫）| 几千年文化 |
| 走路、抓取、认脸 | 易（不假思索）| **极难** | 几亿年进化 |

**为什么**：进化把感知运动能力深度优化到潜意识里，它们**感觉容易**恰恰因为大脑把它自动化了。抽象推理是进化新近发明（几千年），所以显得「难」——它没被自动化。

**对机器人的启示**：**别低估「抓起一个杯子」的难度**。它需要的感知-控制精度，远超下棋的搜索深度。这就是为什么机器人 60 年了还没普及——核心难题没解决。

## 物理让一切变难的七大原因

| 难题 | 数字 AI | 机器人 |
|---|---|---|
| **摩擦** | 无 | Coulomb/粘性/静摩擦，非线性，建模难 |
| **接触** | 无 | 接触瞬间动力学突变，混合系统 |
| **惯性** | 无 | 加速减速都要力，过冲、振荡 |
| **传感器噪声** | 低 | IMU 漂移、编码器累积误差、视觉遮挡 |
| **执行器延迟** | 毫秒级 | 几十毫秒，控制带宽受限 |
| **磨损/故障** | 无 | 关节磨损、传感器失效、断电 |
| **不可逆** | Ctrl+Z | 物理过程不可撤销，错了就坏了 |

每一个都让控制理论从「漂亮」变「肮脏」。整部机器人学就是**和这七个敌人作战**。

## Rodney Brooks 的反叛：行为机器人学

1980 年代主流是「**感知→建模→规划→行动**」的瀑布（Stanford/Shakey 路线）。Rodney Brooks 1989 年论文《Elephants Don't Play Chess》反叛：

> **大象不下棋，但大象会做很多下棋机器人做不到的事。** 别再追求「全建模再规划」，让机器人直接用简单行为反应世界。

他提出**包容架构**（subsumption）：多层简单行为叠加，底层（避障）优先于高层（导航）。这是 Roomba 扫地机器人的原理——**不建图也能扫好地**。

**洞察**：机器人不需要「完全理解世界」才能行动。**反应式智能足够解决很多实际问题**。这预示了现代端到端学习（VLA）的哲学。

## 具身智能的兴起（Embodied AI）

2022 年后，「具身智能」成为热词。核心主张：

> **真正的智能需要身体。** 纯文本训练的 LLM 缺乏「物理直觉」（不知道杯子会碎、推会倒）。给 AI 一个身体，让它「体验」物理世界，才能涌现出真正的理解。

这是 Fei-Fei Li 创立 World Labs（2024）的动机，也是宇树/智元/特斯拉做人形机器人的赌注：**人形 + 大模型 = 通用具身智能**。

**核心争议**：人形真的必要吗？专用机器人（扫地/焊接/分拣）更实用。但人形的优势是「**适配人类设计的环境**」（楼梯、门把手、工具）——这是 Optimus/Figure/宇树 赌人形的逻辑。
