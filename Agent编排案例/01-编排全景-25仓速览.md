## 三、横向结论（跨 25 仓）

1. **编排的本质收敛为三件事**：分解（DAG/团队）、纪律（重试/状态持久/完成审计）、裁决（合并/冲突/人审）。G1 用调度器做、G2 用 DSL 做、G3 用 lead-agent 做——**G3 的创新只是把这三件事重新交给 LLM 当大脑**。
2. **G3 是 opencode 直接生态**：OmO/wshobson/paseo/superset 四仓显式适配 opencode；orca 适配 claude-code/codex/cursor-agent。装它们 = 给 opencode 换舰队。
3. **星数 ≠ 可偷密度**：Airflow 46.5k★ 但对 agent 工程只有 2 个原语；12-factor-agents 25.3k★ 几乎条条可偷（原则类）。
4. **TypeScript 统治 G3**（8/25 仓是 TS），Python 统治 G1/G2——编码 agent 编排器天然长在 CLI 工具生态上。
