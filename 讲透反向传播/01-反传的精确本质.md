# 01 · 反传的精确本质：反向模式自动微分

> 很多人把"反向传播 = 链式法则"当口头禅。这是**不精确**的。链式法则是 200 年前的数学定理，反传是它的**一个高效计算算法**。钉死这个区别，是真正理解反传的第一步。

---

## 一、直觉层：反传到底在算什么

反传的终极目标：**算出损失 $L$ 对每个参数 $\theta_i$ 的偏导数 $\partial L/\partial\theta_i$**（梯度），供梯度下降用。

朴素办法（数值微分）要"扰动一个参数、算一次 loss"，参数百亿就要算百亿次——不可行（见 00 章）。

反传的精明：**利用链式法则，只跑 1 次前向 + 1 次反向，就把所有参数的梯度一次性算出来**。但"链式法则"只是数学原理，**反传是把它变成 O(前向同阶) 算法的具体执行方式**。

## 二、数学层：反传 = 反向模式自动微分

### 2.1 精确定义

给定可微函数 $f:\mathbb{R}^n \to \mathbb{R}^m$，反传一次算出的是**雅可比-向量积（VJP, Vector-Jacobian Product）**：

$$
\boxed{\;\text{反传输出} = J_f^\top \bar{v}, \quad J_f \in \mathbb{R}^{m\times n},\ \bar{v}\in\mathbb{R}^m\;}
$$

- $J_f$ 是 $f$ 的**雅可比矩阵**（函数在某点的最佳线性近似，$\partial f_i/\partial x_j$）。
- 反传**不显式构造 $J_f$**（太大），而是把它的转置直接作用在一个向量 $\bar v$ 上。
- $\bar v$ 是"上游梯度"（最终是 $\partial L/\partial L = 1$）。

> 🎯 **这一行公式就是反传的全部数学本质。** 所有手算推导（"局部梯度 × 上游梯度"）都是它的具体展开。

### 2.2 链式法则 vs 反传

| | 链式法则（数学）| 反传（算法）|
|---|---|---|
| 是什么 | 定理：$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\frac{\partial y}{\partial x}$ 成立 | 算法：O(前向同阶) 算出所有 $\partial L/\partial\theta_i$ |
| 作用 | 告诉你等式**成立** | 告诉你**怎么高效算出来** |
| 关系 | 反传是链式法则在计算图上的**系统性、高效执行** |

### 2.3 雅可比的直觉

雅可比 $J_f$ 是"函数在当前点最接近的线性近似"。在反传里，每一层算子都有一个局部雅可比，反传做的事 = **沿图反向，在每个节点用该节点的局部雅可比转置乘以上游梯度**。

## 三、代码层：90 行手写反传

```bash
cd experiments && python3 01_autograd_from_scratch.py
```

90 行纯 Python 实现一个 `Value` 类，每个运算记录 `_backward`（局部导数怎么算 = 该节点的 VJP）和 `_prev`（依赖谁）。`backward()` 做拓扑排序逆序调用：

```
f = relu(a*b + c); f.backward()
手写: df/da=0 df/db=0 df/dc=0
torch: 完全一致 ✓ (0 误差)
```

还能用它训练 MLP 拟合 $y=x^2$（loss 0.22→0.005）。**这就是 `loss.backward()` 的全部本质**——PyTorch 只是用 C++ 在张量级高效重做这 90 行。

## 四、批判性视角

- **反传不是唯一求导方法**，只是深度学习场景（$m\ll n$）下最高效的。输入维度小的场景，前向模式 AD 反而更快（见 02 章）。
- **反传要求函数可微**。不可导点（ReLU 在 0）用次梯度约定；不可微操作（采样）要 reparameterization 绕过（见 09 章）。
- **反传是"数学理想 + 工程边界"的合体**。数学上是 VJP，工程上还要解决 mutation/view/version（见 08 章）。
