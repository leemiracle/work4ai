## 〇、为什么代数拓扑

### 0.1 用代数研究"形状"

拓扑学研究空间"在连续变形下不变的性质"。

**代数拓扑**：把空间关联一个**代数对象**（群 / 环 / 模），用代数工具研究拓扑。

例：球面 $S^2$ vs 甜甜圈 $T^2$——它们有什么本质不同？

答案：**洞的数量**。
- $S^2$：1 个 2 维洞（内部）+ 0 个 1 维洞
- $T^2$：1 个 2 维洞 + 2 个 1 维洞

这些"洞"被编码到**同调群** $H_0, H_1, H_2, \ldots$

### 0.2 应用

- **数据科学**：**拓扑数据分析**（TDA）—— 用持续同调分析数据形状
- **物理**：拓扑相（2016 诺贝尔物理奖）
- **机器人**：configuration space 的拓扑
- **ML**：拓扑正则化（topological loss）
