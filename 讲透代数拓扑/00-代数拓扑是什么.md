# 00 - 代数拓扑是什么：用代数研究"形状"

> 拓扑学是"橡皮膜几何"——你可以拉伸、扭曲，但不能撕开或粘合。代数拓扑把"形状"翻译成代数（群）。

---

**1895 年，巴黎。** Henri Poincaré 抛出一个冒犯所有几何学家的提议：**不要测量形状，只要数洞**。圆盘和点"一样"（没有洞），咖啡杯和甜甜圈"一样"（都是一个洞的曲面）——只要能连续变形互相转换，它们就拓扑等价。同行质疑：代数怎么"看见"形状？Poincaré 的回答是 *Analysis Situs*（位置分析）——给每个空间配上一组群（同调、基本群），把"洞"翻译成代数。两个空间同伦等价 ⟺ 对应的群同构。"形状"第一次变成了可计算的对象。100 多年后，这同一套语言走进了深度学习（拓扑数据分析、持续同调）。

---

## 一、直觉层

### 1.1 拓扑等价（同伦等价）

**直觉**：两个空间能"连续变形"互相转换，则拓扑等价。

- 圆盘 $\approx$ 点（缩成一点）
- 圆环 $\approx$ 圆（中线）
- 咖啡杯 $\approx$ 甜甜圈（经典！）

**反直觉**：咖啡杯和甜甜圈"一样"——拓扑学家眼里，都是"1 个洞的曲面"。

### 1.2 "洞"的分类

| 空间 | 0 维洞（连通分量）| 1 维洞（环路）| 2 维洞（空腔）|
|------|-----------------|-------------|-------------|
| 点 | 1 | 0 | 0 |
| 线段 | 1 | 0 | 0 |
| 圆 $S^1$ | 1 | 1 | 0 |
| 圆盘 $D^2$ | 1 | 0 | 0 |
| 球面 $S^2$ | 1 | 0 | 1 |
| 甜甜圈 $T^2$ | 1 | 2 | 1 |

### 1.3 代数拓扑的核心思想

**把空间关联代数对象**：
- **基本群** $\pi_1(X)$：1 维洞的代数
- **同调群** $H_n(X)$：$n$ 维洞的代数
- **上同调** $H^n(X)$：同调的对偶

两个同伦等价的空间有相同的代数不变量。

## 二、数学层

### 2.1 拓扑空间

$(X, \tau)$：集合 $X$ + 开集族 $\tau$（满足并/交/含空全集）。

### 2.2 连续映射

$f: X \to Y$ 连续 ⟺ 开集的原像是开集（见 [`../讲透实分析/03-连续性.md`](../讲透实分析/03-连续性.md)）。

### 2.3 同伦

$f, g: X \to Y$ 同伦（$f \simeq g$）⟺ 存在连续 $H: X \times [0,1] \to Y$ 使 $H(-, 0) = f$, $H(-, 1) = g$。

直觉：$f$ 能"连续变形"到 $g$。

### 2.4 同伦等价

$X \simeq Y$ ⟺ 存在 $f: X \to Y$, $g: Y \to X$ 使 $f \circ g \simeq \text{id}_Y$, $g \circ f \simeq \text{id}_X$。

---

## 三、基本群 $\pi_1$（速览，详见 01）

### 3.1 环路

基于 $x_0$ 的环路：连续 $\gamma: [0,1] \to X$，$\gamma(0) = \gamma(1) = x_0$。

### 3.2 基本群

$\pi_1(X, x_0)$ = 所有环路 / 同伦（环路可以"变形"则等价）。运算 = 环路拼接。

### 3.3 经典结果

- $\pi_1(\mathbb{R}^n) = 0$（平凡）—— $\mathbb{R}^n$ 没洞
- $\pi_1(S^1) = \mathbb{Z}$ —— 圆有 1 个 1 维洞
- $\pi_1(S^n) = 0$ for $n \geq 2$ —— 球面没有 1 维洞

**反直觉**：$S^2$（球面）的环路可以"滑过球面"收缩成点——所以 $\pi_1(S^2) = 0$。但球面有 2 维洞（$H_2(S^2) = \mathbb{Z}$）。

"""
讲透代数拓扑 00 章实验：拓扑等价 + 洞的数量。

import numpy as np


def part1_coffee_mug_torus():
    """咖啡杯 ≈ 甜甜圈（拓扑等价）"""
    print("=" * 65)
    print("[1] 咖啡杯 ≈ 甜甜圈：1 个洞的曲面")
    print("=" * 65)
    print("  咖啡杯：1 个把手 = 1 个洞")
    print("  甜甜圈：1 个中心 = 1 个洞")
    print("  → 两者亏格 g = 1，同伦等价 ✓")
    print()
    print("  Euler 示性数 χ = 2 - 2g（闭曲面）")
    for g in [0, 1, 2, 3]:
        chi = 2 - 2*g
        name = {0: "球面 S²", 1: "甜甜圈 T²", 2: "双甜甜圈", 3: "三甜甜圈"}[g]
        print(f"    g={g} ({name}): χ = {chi}")


def part2_homology_table():
    """同调群表"""
    print()
    print("=" * 65)
    print("[2] 同调群 H_n（洞的代数）")
    print("=" * 65)
    print(f"  {'空间':<14} {'H_0':<8} {'H_1':<14} {'H_2':<8}")
    spaces = [
        ("点", "Z", "0", "0"),
        ("圆 S¹", "Z", "Z", "0"),
        ("球面 S²", "Z", "0", "Z"),
        ("球面 S³", "Z", "0", "0"),
        ("甜甜圈 T²", "Z", "Z⊕Z", "Z"),
        ("Klein 瓶", "Z", "Z⊕Z/2", "0"),
        ("RP²", "Z", "Z/2", "0"),
    ]
    for name, h0, h1, h2 in spaces:
        print(f"  {name:<14} {h0:<8} {h1:<14} {h2:<8}")
    print()
    print("  → H_0 = 连通分量数（Z = 1 个）")
    print("  → H_1 = 1 维洞（环路）")
    print("  → H_2 = 2 维洞（空腔）")
    print("  → Klein 瓶和 T² 有相同 H_0/H_2，但 H_1 不同（前者非定向）")


def part3_euler_characteristic():
    """Euler 示性数 = 顶点 - 边 + 面"""
    print()
    print("=" * 65)
    print("[3] Euler 示性数：V - E + F")
    print("=" * 65)
    print(f"  {'多面体':<14} {'V':<5} {'E':<5} {'F':<5} {'χ=V-E+F':<10}")
    polyhedra = [
        ("四面体", 4, 6, 4),
        ("立方体", 8, 12, 6),
        ("八面体", 6, 12, 8),
        ("十二面体", 20, 30, 12),
        ("二十面体", 12, 30, 20),
    ]
    for name, v, e, f in polyhedra:

        print(f"  {name:<14} {v:<5} {e:<5} {f:<5} {chi:<10} {'= 球面 χ ✓' if chi == 2 else ''}")
    print("  → 所有凸多面体 χ = 2（都同伦等价于球面）")


def main():
    print("讲透代数拓扑 00 章实验：拓扑等价 + 洞的数量")

    part2_homology_table()
    part3_euler_characteristic()
    print()
    print("=" * 65)
    print("✓ 代数拓扑入门完成。")
    print("  → 拓扑 = 形状的'橡皮膜'几何")
    print("  → 同调群把'洞'变成代数")
    print("  → Euler 示性数 V-E+F 是拓扑不变量")
    print("=" * 65)


if __name__ == "__main__":
    main()

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我卡在"为什么用**群**研究拓扑"——群是代数概念，拓扑是几何概念，跨域怎么连？重读后发现关键：**连续映射保持群的同态**。两个空间之间的连续函数 $f: X \to Y$ 自动诱导 $\pi_1(X) \to \pi_1(Y)$ 的群同态。这就是为什么"代数"能"看见形状"——连续性是桥梁。
- **F3 术语翻译**：
  - "同伦（homotopy）" → 两个东西能"连续滑过去"变成彼此，像橡皮泥不撕开地捏
  - "基本群（fundamental group）$\pi_1$" → 绕空间里某个点的所有"圈"，能连续变形互相变的算同类，按"先绕 A 再绕 B"做乘法，构成群
  - "同调群 $H_n$" → 数"n 维洞"的代数记号：$H_0$ 数连通分量、$H_1$ 数 1 维洞（甜甜圈孔）、$H_2$ 数 2 维空腔（球内空腔）
- **F4 回炉**：v1 写"拓扑等价 = 都能连续变形"；v2 加 Poincaré 故事后意识到，**单纯"等价"是空话，必须给出可计算的判据**——Poincaré 的贡献正是把"等价"翻译成"对应群同构"。故事的冲突点在这里。

## 反模式 5 条（L4 工程化）

1. **混淆"同胚"与"同伦等价"** → 同胚要求双连续一一映射，同伦等价更宽松。圆和带点的圆不同胚但同伦等价。
2. **忽视维数** → 只学 1 维洞（$\pi_1$）。正解：高维洞（$H_2, H_3$）才区分球面与甜甜圈。
3. **Poincaré 猜想当已知** → 3 维单连通闭流形同胚于 $S^3$ 是 Perelman 2003 证的，不是显然。
4. **同调群当万能** → 同调只看"洞的代数"，分不出某些空间。正解：要严格区分用基本群或更高阶同伦。
5. **直接学持续同调（TDA）跳过经典** → TDA 是经典同调的"扰动版"。正解：先懂 simplicial homology 再学 TDA。
