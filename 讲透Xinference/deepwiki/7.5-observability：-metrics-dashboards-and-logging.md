## Metrics System

 Xinference exposes metrics via independent `/metrics` endpoints on the Supervisor and Worker processes.

 
### Metric Isolation and Scoping

 
| Process | Endpoint | Scope |
|---|---|---|
| Supervisor | Same as API (default 9997) | Cluster-wide view, worker resource usage, model metadata, and security audit. |
| Worker | Dedicated port (--metrics-port) | Per-node inference quality, token throughput, and request latency. |

## OpenTelemetry (OTEL) Integration

 Xinference supports pushing traces and metrics to an OTLP-compatible backend. This is disabled by default and can be enabled via `XINFERENCE_ENABLE_OTEL=true`.

 **Configuration Variables:**

 
 - `XINFERENCE_OTLP_BASE_ENDPOINT`: Base URL for OTLP collector (default: `http://localhost:4318`) [monitor/metrics/README.md59](https://github.com/xorbitsai/inference/blob/d97e0970/monitor/metrics/README.md?plain=1#L59-L59)
 - `XINFERENCE_OTEL_METRIC_EXPORT_INTERVAL`: Interval in ms for pushing metrics [monitor/metrics/README.md65](https://github.com/xorbitsai/inference/blob/d97e0970/monitor/metrics/README.md?plain=1#L65-L65)

## Dashboards and Alerts

 
### Grafana Dashboards

 Xinference provides 6 sub-dashboards (located in `monitor/dashboard/`) covering different aspects of the system:

 
 - **Cluster Overview**: Node count, total models, and aggregate resource usage.
 - **Model Performance**: TTFT, tokens/sec, and error rates per model.
 - **GPU Metrics**: Detailed per-GPU utilization and memory tracking.
 - **Security Audit**: API key usage, authentication failures, and rate-limiting status.
 - **Node Resources**: CPU, RAM, and Disk metrics.
 - **Inference Engine**: Engine-specific metrics (e.g., vLLM cache usage).
 
 Sources: [monitor/dashboard/security-audit/xinference-grafana-dashboard-security-audit-en.json1-10](https://github.com/xorbitsai/inference/blob/d97e0970/monitor/dashboard/security-audit/xinference-grafana-dashboard-security-audit-en.json#L1-L10)

 Alert rules are defined in `monitor/alert/rules.yml` (and localized versions). Key alerts include:

 
| Alert Name | Severity | Condition |
|---|---|---|
| GPUMemoryHigh | critical | GPU memory usage > 90% for 5m monitor/alert/README_zh-CN.md18-22 |
| ModelRequestErrorRateHigh | warning | Error rate > 5% for 3m monitor/alert/README_zh-CN.md24-28 |
| WorkerOffline | critical | Online workers < 1 monitor/alert/README_zh-CN.md36-40 |
| ReplicaUnexpectedTerminated | critical | A model replica crashed unexpectedly monitor/alert/README_zh-CN.md61-65 |

## Logging and Audit System

 
### Logging Configuration

 The system uses a unified factory, `create_rotating_handler`, to manage application and audit logs.

 **Log Rotation Strategy:**

 
 - **Size-based**: Rotates at 100MB (`XINFERENCE_LOG_MAX_BYTES`) [xinference/api/oauth2/advanced/audit.py27](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/api/oauth2/advanced/audit.py#L27-L27)
 - **Time-based**: Supports daily rotation [xinference/core/log.py53-59](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/core/log.py#L53-L59)
 - **Retention**: Keeps up to 30 backup files by default [doc/source/getting_started/logging.rst20](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/getting_started/logging.rst#L20-L20)

### Slow HTTP Protection

 To prevent Slowloris DoS attacks, Xinference uses a `RequestDeadlineMixin` in its HTTP protocol.

 
 - **`XINFERENCE_HTTP_REQUEST_TIMEOUT`**: Enforces an absolute deadline (default 120s) for receiving a complete HTTP request [xinference/core/http_protocol.py37](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/core/http_protocol.py#L37-L37) [doc/source/getting_started/environments.rst75-81](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/getting_started/environments.rst#L75-L81)
 - **Behavior**: The connection is closed if headers and body are not fully received within the timeout [xinference/core/http_protocol.py103-117](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/core/http_protocol.py#L103-L117) Streaming responses are unaffected once the request is received [xinference/core/http_protocol.py32-34](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/core/http_protocol.py#L32-L34)
