| Extra | Purpose | Key Dependencies |
|---|---|---|
| dev | Development and Quality | ruff, black, mypy, pytest |

## Build Process and Frontend Compilation

 Xinference includes a React-based Web UI. For development, the frontend must be compiled into static assets that the backend serves from `xinference/ui/web/dist`.

 
### Static Asset Generation

 The build process is managed by `build_web.py` and `build_backend.py` [MANIFEST.in7-8](https://github.com/xorbitsai/inference/blob/d97e0970/MANIFEST.in#L7-L8)

 
 - **Clean and Install**: Navigate to `frontend/` and clear existing artifacts.
 - **Build**: Run `npm run build` to generate the static export.
 - **Stage**: Assets are moved to `xinference/ui/web/dist` [MANIFEST.in15](https://github.com/xorbitsai/inference/blob/d97e0970/MANIFEST.in#L15-L15)

## Platform-Specific Considerations

 
### Linux (GPU/CPU)

 
 - **vLLM**: Requires `vllm>=0.2.6` and CUDA [.github/workflows/docker-cd.yaml63-100](https://github.com/xorbitsai/inference/blob/d97e0970/.github/workflows/docker-cd.yaml#L63-L100)
 - **Audio**: Requires system libraries like `libsndfile1` and `ffmpeg` [xinference/deploy/docker/requirements_cpu/requirements_cpu-base.txt29](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/deploy/docker/requirements_cpu/requirements_cpu-base.txt#L29-L29)
 
 
### Apple Silicon (macOS ARM64)

 
 - **MLX Backend**: Specifically uses `mlx-lm`, `mlx-vlm`, and `mlx-audio` [pyproject.toml168-176](https://github.com/xorbitsai/inference/blob/d97e0970/pyproject.toml#L168-L176)
 - **Installation**: `pip install -e ".[mlx]"`
 
 
### Docker-based Development

 The project maintains separate Dockerfiles for CPU and GPU environments to ensure reproducible development setups.

 
 - **GPU**: `xinference/deploy/docker/Dockerfile` [.github/workflows/docker-cd.yaml98](https://github.com/xorbitsai/inference/blob/d97e0970/.github/workflows/docker-cd.yaml#L98-L98)
 - **CPU**: `xinference/deploy/docker/Dockerfile.cpu` [.github/workflows/docker-cd.yaml136](https://github.com/xorbitsai/inference/blob/d97e0970/.github/workflows/docker-cd.yaml#L136-L136)
