## Purpose and Scope

 This page describes how to integrate Xinference with external client libraries and third-party tools. Xinference provides OpenAI-compatible RESTful API endpoints, enabling seamless integration with any tool or library that supports the OpenAI API protocol. This includes popular frameworks like the OpenAI SDK, LangChain, LlamaIndex, and specialized AI applications such as Dify and FastGPT. [README.md78-86](https://github.com/xorbitsai/inference/blob/d97e0970/README.md?plain=1#L78-L86) [doc/source/user_guide/client_api.rst64-87](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/user_guide/client_api.rst#L64-L87)

## Framework Integrations

 Xinference is deeply integrated into the modern LLM ecosystem. [README.md64-69](https://github.com/xorbitsai/inference/blob/d97e0970/README.md?plain=1#L64-L69) [READMES/README_zh_CN.md80-81](https://github.com/xorbitsai/inference/blob/d97e0970/READMES/README_zh_CN.md?plain=1#L80-L81)

 
### LangChain

 LangChain provides a provider for Xinference, supporting LLMs, Chat Models, and Embeddings. [README.md84](https://github.com/xorbitsai/inference/blob/d97e0970/README.md?plain=1#L84-L84) It uses the RESTful API to manage model execution.

 
### LlamaIndex

 LlamaIndex supports Xinference for local deployment, enabling RAG (Retrieval-Augmented Generation) pipelines using local embedding and LLM models. [README.md85](https://github.com/xorbitsai/inference/blob/d97e0970/README.md?plain=1#L85-L85)

 
### Dify

 Dify is an LLMOps platform that can use Xinference as a model provider. Developers can configure Xinference endpoints in Dify to build visual AI workflows. [README.md66](https://github.com/xorbitsai/inference/blob/d97e0970/README.md?plain=1#L66-L66)

 
### FastGPT & RAGFlow

 
 - **FastGPT**: A knowledge-based platform that invokes Xinference models for data processing and workflow orchestration. [README.md67](https://github.com/xorbitsai/inference/blob/d97e0970/README.md?plain=1#L67-L67)
 - **RAGFlow**: Uses Xinference for deep document understanding and RAG capabilities. [README.md68](https://github.com/xorbitsai/inference/blob/d97e0970/README.md?plain=1#L68-L68)
