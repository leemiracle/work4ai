## Purpose and Scope

 This document describes the audio model system in Xinference, covering model specifications, instantiation, and inference capabilities. Audio models in Xinference support three primary capabilities: **audio-to-text transcription**, **audio translation**, and **text-to-speech synthesis**. For information about deploying audio models in distributed clusters, see [Distributed Deployment](https://deepwiki.com/xorbitsai/inference/7.2-distributed-deployment). For API authentication and access control, see [Authentication and Authorization](https://deepwiki.com/xorbitsai/inference/5.5-authentication-and-authorization).

## Model Specification System

 
### AudioModelFamilyV2 Schema

 Audio models are defined using the `AudioModelFamilyV2` class, which extends `CacheableModelSpec`. It defines how a model is identified, cached, and which abilities it possesses.

 
| Field | Type | Description |
|---|---|---|
| version | Literal[2] | Specification version xinference/model/audio/core.py52 |
| model_family | str | Family identifier (e.g., "whisper", "CosyVoice") xinference/model/audio/core.py53 |
| model_name | str | Unique model name xinference/model/audio/core.py54 |
| model_ability | Optional[List[str]] | Capabilities: audio2text, text2audio xinference/model/audio/core.py59 |
| multilingual | bool | Supports multiple languages xinference/model/audio/core.py57 |
| engine | Optional[str] | Backend engine override (e.g., "vLLM" for Qwen3-ASR) xinference/model/audio/core.py62 |
| virtualenv | Optional[VirtualEnvSettings] | Package requirements for isolation xinference/model/audio/core.py63 |

## Model Family Implementations

 
### Audio-to-Text (ASR)

 Xinference supports several ASR engines:

 
 - **Whisper**: Uses `pipeline("automatic-speech-recognition")` from Transformers [xinference/model/audio/whisper.py99-110](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/audio/whisper.py#L99-L110)
 - **FunASR**: Supports `SenseVoiceSmall` and `Paraformer` variants [doc/source/models/model_abilities/audio.rst58-59](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/models/model_abilities/audio.rst#L58-L59)
 - **Qwen3-ASR**: Supports `vLLM` backend for high-performance transcription [doc/source/models/model_abilities/audio.rst75-85](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/models/model_abilities/audio.rst#L75-L85)
 
 
### Text-to-Speech (TTS)

 TTS models are categorized by their synthesis capabilities:

 
#### 1. Zero-Shot TTS

 Direct synthesis without reference audio.

 
 - **ChatTTS**: Uses fixed seeds or embeddings to define speakers [xinference/model/audio/chattts.py92-102](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/audio/chattts.py#L92-L102)
 - **CosyVoice (SFT/Instruct)**: Uses pre-trained speaker IDs like "中文女" [xinference/model/audio/cosyvoice.py116-131](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/audio/cosyvoice.py#L116-L131)
 - **Kokoro**: High-quality synthesis using language codes (e.g., "en-us", "zh") [doc/source/models/model_abilities/audio.rst96-98](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/models/model_abilities/audio.rst#L96-L98)
 
 
#### 2. Voice Cloning

 Requires reference audio via `prompt_speech`.

 
 - **CosyVoice 2.0**: Supports `inference_zero_shot` and `inference_cross_lingual` [xinference/model/audio/cosyvoice.py90-114](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/audio/cosyvoice.py#L90-L114)
 - **FishSpeech**: Uses a Llama-based architecture with VQ-GAN decoder [xinference/model/audio/fish_speech.py93-113](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/audio/fish_speech.py#L93-L113)
 - **IndexTTS2**: Supports cloning with advanced emotion control [xinference/model/audio/indextts2.py27](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/audio/indextts2.py#L27-L27)

## Voice Cloning and Emotion Control with IndexTTS2

 `IndexTTS2` is a sophisticated TTS model integrated into Xinference that provides fine-grained control over the generated speech.

 
### Core Implementation

 The `Indextts2` class in `xinference/model/audio/indextts2.py` wraps the `IndexTTS2` engine defined in `xinference/thirdparty/indextts/infer_v2.py`.

 
### Key Features:

 
 - **Zero-shot & Voice Cloning**: Synthesize speech from text using a reference audio clip (`prompt_speech`) [doc/source/models/model_abilities/audio.rst107](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/models/model_abilities/audio.rst#L107-L107)
 - **Emotion Vector**: Control emotions via an 8-float vector: `[happy, angry, sad, afraid, disgusted, melancholic, surprised, calm]` [doc/source/models/model_abilities/audio.rst674-678](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/models/model_abilities/audio.rst#L674-L678)
 - **Emotion Reference**: Use a separate audio file (`emo_audio_prompt`) to provide the emotional tone [doc/source/models/model_abilities/audio.rst643](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/models/model_abilities/audio.rst#L643-L643)
 - **Text-based Emotion**: Infer emotion automatically from the input text content using `use_emo_text=True` [doc/source/models/model_abilities/audio.rst724](https://github.com/xorbitsai/inference/blob/d97e0970/doc/source/models/model_abilities/audio.rst#L724-L724)

## Multilingual Support

 Xinference provides extensive multilingual support across audio models:

 
| Model Family | Language Support | Mechanism |
|---|---|---|
| Whisper | Multilingual | Native model support; language parameter in _call_model xinference/model/audio/whisper.py147 |
| CosyVoice | ZH, EN, JP, KR, Cantonese | inference_cross_lingual method xinference/model/audio/cosyvoice.py112 |
| MeloTTS | Specific models per language | melotts-chinese, melotts-french, etc. doc/source/models/builtin/audio/index.rst50-65 |
| Kokoro | Multilingual | Uses lang_code (e.g., a for American English, z for Chinese) doc/source/models/model_abilities/audio.rst438-444 |
