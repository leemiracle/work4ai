## Purpose and Scope

 The Web UI is a browser-based graphical interface for managing and interacting with Xinference deployments. It provides visual tools for launching models, monitoring cluster status, executing inference requests, and managing model lifecycles. The interface is built with React and TypeScript, communicating with the Xinference Supervisor via the RESTful API.

 This document covers the Web UI's architecture, key components, and data flow. For details about the underlying API endpoints, see [RESTful API](https://github.com/xorbitsai/inference/blob/d97e0970/RESTful API) For Python-based programmatic access, see [Python Client Library](https://github.com/xorbitsai/inference/blob/d97e0970/Python Client Library)

 
## Architecture Overview

 The Web UI is a client-side application that operates as a single-page application (SPA). It is served as static assets by the FastAPI server and uses `axios`-based request utilities to interact with the backend.

## Key UI Components

 
### 1. Model Launch Dialog (`LaunchDialog`)

 The `LaunchDialog` component is the primary interface for deploying models. It dynamically fetches available engines and formats for a selected model family.

 
 - **Engine Indexing**: It uses `buildEngineIndex` to map model engines to their supported formats, sizes, and quantizations [frontend/src/components/pages/launch-model/utils.tsx58-101](https://github.com/xorbitsai/inference/blob/d97e0970/frontend/src/components/pages/launch-model/utils.tsx#L58-L101)
 - **Dynamic Fields**: Renders form fields based on the model type (LLM, Embedding, etc.) using `renderLaunchFields` [frontend/src/components/pages/launch-model/utils.tsx162-170](https://github.com/xorbitsai/inference/blob/d97e0970/frontend/src/components/pages/launch-model/utils.tsx#L162-L170)
 - **Resource Validation**: Checks GPU availability via `/v1/cluster/info` to ensure the selected `n_gpu` configuration is valid [frontend/src/components/pages/launch-model/launch-dialog/launch-dialog.tsx103-117](https://github.com/xorbitsai/inference/blob/d97e0970/frontend/src/components/pages/launch-model/launch-dialog/launch-dialog.tsx#L103-L117)

## Authentication and Security

 The Web UI respects the cluster's authentication settings:

 
 - **JWT Handling**: Stores and retrieves access tokens from storage, decoding payloads to determine user permissions [frontend/src/lib/utils.ts160-178](https://github.com/xorbitsai/inference/blob/d97e0970/frontend/src/lib/utils.ts#L160-L178)
 - **Menu Authorization**: The `useMenuAuth` hook controls the visibility of sidebar items (e.g., User Management, API Keys) based on the user's scopes [frontend/src/components/layout/sidebar.tsx150-155](https://github.com/xorbitsai/inference/blob/d97e0970/frontend/src/components/layout/sidebar.tsx#L150-L155)
 - **Admin Views**: Specific administrative pages like `UserManagement` are only visible if `clusterUIConfig.auth_advanced` is enabled [frontend/src/components/layout/sidebar.tsx237-250](https://github.com/xorbitsai/inference/blob/d97e0970/frontend/src/components/layout/sidebar.tsx#L237-L250)

## Internationalization (i18n)

 Xinference supports multiple languages through a locale-based system. Each locale file (e.g., `en.ts`, `zh.ts`, `ja.ts`, `ko.ts`) contains a nested object of translation strings.

 
| Locale File | Language | Reference |
|---|---|---|
| en.ts | English | frontend/src/i18n/locales/en.ts1 |
| zh.ts | Chinese | frontend/src/i18n/locales/zh.ts1 |
| ja.ts | Japanese | frontend/src/i18n/locales/ja.ts1 |
