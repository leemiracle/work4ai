  The Python Client Library provides high-level, programmatic interfaces to interact with a Xinference cluster. It abstracts the underlying RESTful API and actor-model communication, offering both synchronous (`RESTfulClient`) and asynchronous (`AsyncRESTfulClient`) implementations.

## Client Architecture

 The client library is structured into three layers: the **Client**, which manages cluster-level operations; **Model Handles**, which provide model-specific inference methods; and **Common Utilities**, which handle data transformation and streaming.

## RESTfulClient (Synchronous)

 The `RESTfulClient` is the primary entry point for synchronous applications. It manages authentication, model lifecycle (launch/terminate), and model discovery.

 
### Key Methods

 
 - `launch_model()`: Requests the `SupervisorActor` to start a new model instance. [xinference/client/restful/restful_client.py611-667](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/restful_client.py#L611-L667)
 - `get_model()`: Returns a specific `RESTfulModelHandle` based on the `model_uid`. It automatically detects the model type (LLM, Embedding, Image, etc.) by querying the server. [xinference/client/restful/restful_client.py694-750](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/restful_client.py#L694-L750)
 - `list_models()`: Returns a dictionary of all currently running models. [xinference/client/restful/restful_client.py575-585](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/restful_client.py#L575-L585)
 
 Sources: [xinference/client/restful/restful_client.py540-850](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/restful_client.py#L540-L850)

 
## AsyncRESTfulClient (Asynchronous)

 The `AsyncRESTfulClient` uses `aiohttp` for non-blocking I/O, making it suitable for high-concurrency environments or integration with frameworks like FastAPI.

 
### Implementation Details

 
 - **Session Management**: Uses `aiohttp.ClientSession` with a `TCPConnector` configured to `force_close=True` to prevent connection leakage. [xinference/client/restful/async_restful_client.py79-81](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/async_restful_client.py#L79-L81)
 - **Timeouts**: Defaults to a total timeout of 1800 seconds to accommodate long-running inference tasks. [xinference/client/restful/async_restful_client.py78](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/async_restful_client.py#L78-L78)

## Model Handles

 Model handles provide the specific inference methods for different model families. When `get_model` is called, the client returns a subclass of `RESTfulModelHandle`.

 
### Handle Types and Data Flow

 
| Handle Class | Supported Operations | API Endpoint |
|---|---|---|
| RESTfulChatModelHandle | chat(), generate() | /v1/chat/completions |
| RESTfulEmbeddingModelHandle | create_embedding() | /v1/embeddings |
| RESTfulRerankModelHandle | rerank() | /v1/rerank |
| RESTfulImageModelHandle | text_to_image() | /v1/images/generations |

## Streaming and Iterators

 Xinference supports Server-Sent Events (SSE) for streaming. The client library handles the parsing of these streams into Python generators.

 
 - **Sync Streaming**: Uses `streaming_response_iterator` to yield `ChatCompletionChunk` objects. [xinference/client/common.py46-70](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/common.py#L46-L70)
 - **Async Streaming**: Uses `async_streaming_response_iterator` to yield objects via `async for`. [xinference/client/common.py73-98](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/common.py#L73-L98)
 
 Sources: [xinference/client/common.py20-100](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/common.py#L20-L100)

 
## Authentication

 If the cluster has advanced authentication enabled (`is_auth_advanced()`), the client must provide credentials.

 
 - **Login**: `client.login(username, password)` exchanges credentials for a JWT. [xinference/client/restful/restful_client.py549-573](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/restful_client.py#L549-L573)
 - **Persistence**: Tokens are stored locally in `XINFERENCE_AUTH_DIR` based on a hash of the endpoint URL. [xinference/deploy/cmdline.py87-92](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/deploy/cmdline.py#L87-L92)
 - **Headers**: Authenticated requests include the `Authorization: Bearer <token>` header. [xinference/client/restful/restful_client.py57](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/client/restful/restful_client.py#L57-L57)
