  This page documents the embedding model subsystem in Xinference. Embedding models convert text inputs into dense vector representations for semantic similarity, search, and retrieval tasks. The system supports multiple inference backends, including `sentence-transformers`, `FlagEmbedding`, and `vLLM`, providing automatic engine selection based on model format and hardware capabilities.

 For other model types, see [Large Language Models](https://deepwiki.com/xorbitsai/inference/4.1-large-language-models), [Image Generation Models](https://deepwiki.com/xorbitsai/inference/4.3-image-generation-models), [Audio Models](https://deepwiki.com/xorbitsai/inference/4.4-audio-models), and [Reranking Models](https://deepwiki.com/xorbitsai/inference/4.5-reranking-models).

 
## System Architecture

 The embedding model subsystem consists of:

 
 - **Model Registry**: `EmbeddingModelFamilyV2` definitions loaded from [xinference/model/embedding/model_spec.json](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/embedding/model_spec.json)
 - **Engine Selection**: `match_embedding()` and engine-specific `match()` methods match models to backends.
 - **Cache Management**: `EmbeddingCacheManager` handles model file downloads and caching.
 - **Inference Backends**: Multiple engine implementations for different model formats.

## Batching and Memory Management

 
### Batching Strategies

 Engines like `VLLMEmbeddingModel` and `SentenceTransformerEmbeddingModel` inherit from `BatchMixin` [xinference/model/batch.py](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/batch.py) This allows the system to aggregate multiple embedding requests into a single inference pass, significantly improving throughput.

 
### Memory Management

 The `_clean_cache_if_needed()` method at [xinference/model/embedding/core.py293-307](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/embedding/core.py#L293-L307) implements automatic cache cleanup to prevent OOM errors:

 
 - **Counter-based**: Every `EMBEDDING_EMPTY_CACHE_COUNT` requests (default: 10) [xinference/model/embedding/core.py39-41](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/embedding/core.py#L39-L41)
 - **Token-based**: When processed tokens exceed `EMBEDDING_EMPTY_CACHE_TOKENS` (default: 8192) [xinference/model/embedding/core.py42-44](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/embedding/core.py#L42-L44)
 
 Cleanup calls `gc.collect()` and `empty_cache()` to free GPU/CPU memory [xinference/model/embedding/core.py306-307](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/embedding/core.py#L306-L307)
