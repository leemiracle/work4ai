## Purpose and Scope

 This document explains how Xinference handles chat templates and prompt formatting for Large Language Models (LLMs). Chat templates are Jinja2-based templates that convert structured conversation messages into the specific text format expected by each model. This is critical because different LLM families (Qwen, Llama, Mistral, etc.) expect different prompt formats.

 For information about model registration and specifications, see **8.1 Custom Model Registration** and **8.2 Model Specifications and Schemas**.

## Implementation: ChatModelMixin

 The `ChatModelMixin` class is the primary utility for template processing, inherited by most LLM engine implementations (vLLM, SGLang, Transformers).

 
### Key Functions

 
 - **`_compile_jinja_template(chat_template)`**: Uses `ImmutableSandboxedEnvironment` from Jinja2 to safely compile the template string. It includes an LRU cache to optimize repeated calls [xinference/model/llm/utils.py159-180](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/utils.py#L159-L180)
 - **`_normalize_tool_call_arguments_to_dict(messages)`**: Qwen3-Coder and similar templates require tool arguments as dictionaries to iterate via `|items`. This method converts JSON-encoded strings in `tool_calls` to Python dicts [xinference/model/llm/utils.py192-230](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/utils.py#L192-L230)
 - **`check_system_role_order(messages)`**: Enforces "system-first" ordering for specific models (like Qwen3) that raise errors if a system message appears mid-conversation [xinference/model/llm/utils.py67-91](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/utils.py#L67-L91)

## Stop Tokens and Generation Control

 Xinference handles stop sequences at multiple levels:

 
 - **Model Definition**: Default stop sequences are stored in the model family JSON [xinference/model/llm/llm_family.json145-148](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/llm_family.json#L145-L148)
 - **Sanitization**: During the inference request, `_sanitize_generate_config` merges user-provided stop tokens with the model's defaults [xinference/model/llm/vllm/core.py764-815](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/vllm/core.py#L764-L815)
 - **Engine Execution**: 
 - **vLLM**: Stop strings and IDs are passed into `vllm.SamplingParams` [xinference/model/llm/vllm/core.py124-152](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/vllm/core.py#L124-L152)
 - **SGLang**: Stop sequences are passed to the SGLang runtime config [xinference/model/llm/sglang/core.py77-90](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/sglang/core.py#L77-L90)

### System Constraints

 Xinference supports a `STRICT_SYSTEM_FIRST_MARKERS` list. If a template contains strings like "System message must be at the beginning", the system validates the message order before sending it to the GPU to prevent engine-level crashes [xinference/model/llm/llm_family.py57-70](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/llm_family.py#L57-L70)

 
## Model-Specific Formatting Logic

 While Jinja2 handles most cases, some models require Python-side preprocessing:

 
 - **DeepSeek Tool Calling**: Xinference identifies `DEEPSEEK_TOOL_CALL_FAMILY` and uses specific logic to format tool definitions into the prompt [xinference/model/llm/utils.py135-140](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/utils.py#L135-L140)
 - **Qwen Tool Symbols**: The system uses `QWEN_TOOL_CALL_SYMBOLS` (`<tool_call>`, `</tool_call>`) to identify and parse structured tool requests from the model output [xinference/model/llm/utils.py142](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/utils.py#L142-L142)
 - **Context Length Detection**: The utility `get_context_length_from_config` scans model configurations for keys like `max_position_embeddings` or `sliding_window` to set the correct context window for the prompt [xinference/model/llm/utils.py122-134](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/llm/utils.py#L122-L134)
