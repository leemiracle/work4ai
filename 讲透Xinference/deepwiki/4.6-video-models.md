  This page documents the Video Model system in Xinference. Video models are one of the primary model types supported by the platform, enabling text-to-video and image-to-video generation tasks. The system utilizes the `diffusers` library as the primary backend and supports advanced features like GGUF quantization for specific model families.

 For information about other model types, see [Model Types](https://deepwiki.com/xorbitsai/inference/4-model-types). For details on the model registry and cache management shared across all model types, see [Model Registry and Cache Management](https://deepwiki.com/xorbitsai/inference/2.4-model-registry-and-cache-management).

 
---

 
## Purpose and Scope

 The video model system provides:

 
 - **Comprehensive Model Support**: Built-in support for CogVideoX, HunyuanVideo, and Wan2.1/2.2 families [xinference/model/video/model_spec.json1-284](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/model_spec.json#L1-L284)
 - **Multi-Modal Abilities**: Supports `text2video`, `image2video`, and `firstlastframe2video` capabilities [xinference/model/video/diffusers.py73-186](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/diffusers.py#L73-L186)
 - **Quantization Support**: Integration with GGUF for reduced memory footprint, particularly for HunyuanVideo [xinference/model/video/model_spec.json99-115](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/model_spec.json#L99-L115)
 - **Automated Pipeline Handling**: Encapsulates complex `diffusers` pipelines (e.g., `CogVideoXPipeline`, `HunyuanVideoPipeline`, `WanPipeline`) [xinference/model/video/diffusers.py132-185](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/diffusers.py#L132-L185)

## Model Specifications and Families

 Video models are defined in `model_spec.json`. Each entry specifies the model's architecture, required packages, and default configurations.

 
### Supported Model Families

 
| Family | Abilities | Dtypes Supported | Source |
|---|---|---|---|
| CogVideoX | text2video | float16, bfloat16 | xinference/model/video/model_spec.json1-73 |
| HunyuanVideo | text2video | float16, bfloat16, GGUF (Q3-Q8) | xinference/model/video/model_spec.json76-141 |
| Wan (2.1/2.2) | text2video, image2video | bfloat16 | xinference/model/video/model_spec.json144-284 |

 
### Technical Specifications

 
 - **Virtual Environments**: Video models require specific dependencies like `diffusers>=0.33.0`, `imageio-ffmpeg`, and `ftfy` [xinference/model/video/model_spec.json16-24](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/model_spec.json#L16-L24)
 - **Quantization**: HunyuanVideo supports GGUF quantization (e.g., `Q4_K_M`, `Q8_0`) via the `city96/HunyuanVideo-gguf` repository [xinference/model/video/model_spec.json99-115](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/model_spec.json#L99-L115)

## Data Flow: Text-to-Video Inference

 
 - **Request Reception**: The `WorkerActor` receives a generation request with a prompt and parameters (e.g., `guidance_scale`).
 - **Configuration**: `DiffusersVideoModel` merges `default_generate_config` from the JSON spec with user-provided `kwargs` [xinference/model/video/diffusers.py117-118](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/diffusers.py#L117-L118)
 - **Pipeline Execution**: The internal `self._model` (a diffusers pipeline) runs the diffusion process on the GPU.
 - **Post-Processing**: The generated frames are passed to `export_to_video_imageio()` [xinference/model/video/diffusers.py42](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/diffusers.py#L42-L42)
 - **Output**: The resulting video file path is returned, typically stored in the directory defined by `XINFERENCE_VIDEO_DIR` [xinference/model/video/diffusers.py30](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/model/video/diffusers.py#L30-L30)
