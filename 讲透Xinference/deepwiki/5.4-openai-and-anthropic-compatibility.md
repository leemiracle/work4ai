## Purpose and Scope

 This document explains how Xinference provides API compatibility with OpenAI and Anthropic services, enabling seamless integration with existing client applications and SDKs. Xinference exposes RESTful endpoints that mirror OpenAI's API specifications for chat completions, text completions, embeddings, and more, while also offering optional Anthropic-compatible endpoints for Claude-style message interactions.

 For information about the underlying RESTful API implementation details, see [5.2 Inference Endpoints](https://github.com/xorbitsai/inference/blob/d97e0970/5.2 Inference Endpoints) For authentication mechanisms, see [5.5 Authentication and Authorization](https://github.com/xorbitsai/inference/blob/d97e0970/5.5 Authentication and Authorization) For client library usage, see [6.1 Python Client Library](https://github.com/xorbitsai/inference/blob/d97e0970/6.1 Python Client Library)

### Core OpenAI Endpoints

 Xinference implements the following OpenAI-compatible endpoints defined in `RESTfulAPI` class:

 
| Endpoint | Method | Handler Function | OpenAI Equivalent | Response Type |
|---|---|---|---|---|
| /v1/chat/completions | POST | create_chat_completion() | Chat Completions API | ChatCompletion |
| /v1/completions | POST | create_completion() | Text Completions API | Completion |
| /v1/embeddings | POST | create_embedding() | Embeddings API | Embedding |
| /v1/models | GET | list_models() | List Models | List[ModelDescription] |
| /v1/models/{model_uid} | GET | describe_model() | Retrieve Model | ModelDescription |
| /v1/audio/transcriptions | POST | create_transcriptions() | Audio Transcriptions | Transcription |
| /v1/audio/translations | POST | create_translations() | Audio Translations | Translation |
| /v1/audio/speech | POST | create_speech() | Text-to-Speech | Audio Data |
| /v1/images/generations | POST | create_images() | Image Generation | ImageList |

## Client SDK Integration

 
### OpenAI Python SDK

 Xinference is designed to be a drop-in replacement. By pointing the `api_base` to the Xinference endpoint (defaulting to port 9997), standard OpenAI SDK calls function normally.

 **Sources:** [xinference/core/tests/test_restful_api.py21-26](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/core/tests/test_restful_api.py#L21-L26) [xinference/core/tests/test_restful_api.py97-106](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/core/tests/test_restful_api.py#L97-L106) [xinference/deploy/cmdline.py65-66](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/deploy/cmdline.py#L65-L66)

## Request Validation and Error Handling

 
### Input Validation

 The API layer uses `pydantic` (via `xinference._compat`) and `fastapi` for request validation. The `_validate_replica` function ensures integer values for scaling.

 **Sources:** [xinference/api/restful_api.py99-139](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/api/restful_api.py#L99-L139) [xinference/api/restful_api.py80-93](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/api/restful_api.py#L80-L93) [xinference/_compat.py19-24](https://github.com/xorbitsai/inference/blob/d97e0970/xinference/_compat.py#L19-L24)

## Authentication Integration

 Endpoints are protected by JWT-based authentication when `is_auth_advanced()` returns true. The `AdvancedAuthService` manages token validation for all OpenAI and Anthropic compatible routes.
