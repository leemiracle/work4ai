### astrid-runtime/astrid（10.3K · Rust · 2026 · 14-topic噪声）
- **定位**：可组合软件的**可移植能力安全操作系统**——「把组件当进程对待：每个能力是密封的 WebAssembly 胶囊，只授显式权限，可替换而不扩权」[README]
- **内核哲学**：**小而故意笨**——路由事件/强制能力/跑沙箱/记审计；**不含模型、工具 schema 或业务逻辑**。「越狱、投毒工具或普通 bug 都无法读文件/联网/起进程超出其授权——权限是内核强制的能力，不是 prompt 里的指令」[README]
- **工程决策**：① 「不绑定产品/模型/agent loop/UI/分发」——中立运行时层；② distro 机制（astrid init --distro）——内核与发行版分离（类 Linux 发行版模型）
- **教学映射**：讲透Agent（能力安全 OS 谱系：openfang 同期）+ 安全工程（capability-based security）
- **一句话本质**：一个「笨到不会被骗」的 Agent 内核。
