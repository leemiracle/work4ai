## 组内横断发现

1. **行为外置为文件是本批最强共识**：Toonflow 的 `data/skills/*.md` 决策/执行/监督提示词、claude-seo 的 skills+agents 双目录、opencode 的 `contextPaths` 吃 11 种约定文件（CLAUDE.md/opencode.md/.cursorrules）、cc-haha 的 Skill 市场——四家不约而同把 agent 人格从代码搬进 Markdown，"提示词即配置即版本管理对象"。
2. **agent-as-tool（子代理即工具）三连**：opencode `agentTool` 起只读 Task 子代理并回填父会话成本、Toonflow `run_sub_agent_*` 工具族+XML 标签回写工作区、claude-seo `/seo audit` fan-out 15 专家；但监督层设计对立——Toonflow 显式三层(决策/执行/监督)，opencode 只有 coder/task 两级无审阅层。
3. **对立设计：白盒 vs 框架**。litgpt 以 "no abstractions" 单文件实现 20+ 模型，RD-Agent 却用五层抽象(Loop/CoSTEER/Env/Workspace/Trace)包住同一个"写代码-跑实验"动作——同为 Lightning/AI 教学向项目，一个拆到最小，一个堆到最全；同为 Claude Code 类工具，opencode 是 Go 原生重写、cc-haha 是泄漏源码修补发行版，出身决定架构。
4. **"防自己人"的反滥用工程成新赛道**：hermes-desktop 给密钥 helper 设 1s spawn 地板、"宁可降级 null 也不缓存明文"；cc-haha denial tracking 让被拒命令自动升级 ask、WebFetch 域名预检；claude-seo 用 83 个测试钉死 SSRF——渲染层/用户自身被当作威胁模型的一等公民。
5. **记忆三层结构趋同**：Toonflow（shortTerm+每 3 条递归摘要+本地 ONNX RAG）、hermes（entries+user profile+SOUL.md+可插拔 provider）、opencode（SummaryMessageID 截断+95% 自动 compact）、RD-Agent（Trace+Knowledge 库）——"短期消息/滚动摘要/语义召回"正在成为 agent 记忆的事实标准分层。
