### langchain4j/langchain4j（12.9K · Java · 2023 · 04-Agent框架）
- **定位**：JVM 上的惯用 Java LLM 库——统一 20+ provider 与向量库 API [README]
- **分层**：低层（prompt 模板/chat 记忆管理/函数调用）→ 高层模式（Agents/RAG）；「每个抽象=接口+多个即用实现」[README]
- **工程决策**：① 社区模式提炼路线（2023 起把社区实践精炼成代码——LangChain 思想晚一年但更克制）；② 深度集成 Quarkus/Spring Boot 企业 Java 生态——**企业存量代码是 Java 的护城河**；③ 与 Spring AI 的竞争定义了「JVM AI 层」双格局
- **教学映射**：讲透Agent（Java 路线）+ 讲透LLM 03-全栈（企业集成）
- **一句话本质**：给八年老 Java 工程师递的 AI 梯子。

### codexu/note-gen（12.6K · TypeScript · 2024 · 13-垂直）
- **定位**：本地优先 Markdown 笔记应用——「**先捕获，后整理**」：一句话/语音/截图/链接随手存，之后 AI 归拢成结构化笔记 [README]
- **机制**：捕获与整理**分离**（不必先选标题/文件夹/结构）；按标签/时间/类型过滤→圈选相关记录→选模板或描述意图→AI 组织成 summary/report/article/Markdown→编辑器里改结构、补自己的思考 [README How it works]
- **工程决策**：① 价值宣言反「AI 代写」：「目标不是让 AI 写一切，而是**让有用的碎片在你能写成完整作品前不消失**」[README]——AI 收敛而非 AI 生成的产品哲学；② 场景具体（会议录音+两截图=会后纪要；一周链接碎片=研究笔记）
- **教学映射**：知识管理（与本项目的「故事原语」收集问题同构）+ 讲透AI应用全景
- **一句话本质**：给灵感修的临时停车场，AI 负责排队。

### axolotl-ai-cloud/axolotl（12.4K · Python · 2023 · 02-训练微调）
- **定位**：开源 LLM 微调框架——「Go ahead and axolotl questions」（社区梗式标语）[README]
- **前沿密度**（Updates 即分布式训练技术雷达）：**NVFP4 4-bit MoE LoRA 训练**（ScatterMoE W4A16/SonicMoE W4A4，adapter 可并回 NVFP4 checkpoint，2026-07）/ **DeepEP 专家并行**+Tinker 兼容远程训练+**混合 SSM 模型上下文并行**（Nemotron-H/Falcon-H1/Bamba）+**BitNet 1.58-bit 微调**（2026-06）/**Async GRPO 提速 58%**+Flash Attention 4+EBFT（2026-04）/MoE 专家量化训练（`quantize_moe_experts: true` 大幅降 VRAM，FSDP2 兼容，2026-03）[README Latest Updates]
- **工程决策**：① 新架构/新算法的首发支持速度极快（GLM-4.7-Flash/Gemma 4/Shieldstral 都在当月支持）——「微调界的 day-0 选手」；② uv-first 包管理升级；③ yaml 配置驱动的训练描述成为社区习惯
- **教学映射**：讲透微调（前沿微调技术雷达）+ 讲透RL（Async GRPO）
