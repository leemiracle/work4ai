## 组内横断发现

1. **Skill.md 文件化成为事实标准的"Agent 可读层"**：stas00 为整本书维护 SKILL.md（README:L78-82）、LifeOS 每个能力包=SKILL.md+INSTALL.md+VERIFY.md+src/（DW 6.1 Pack Structure）、agent-zero 用 skills/a0-create-plugin/SKILL.md 教 Agent 自己写插件、iii 以 `npx skills add` 分发原语文档、nuclear 为 MCP 配 zip 技能包——5/10 仓把"给 AI 读的说明书"升为一等交付物，与"给人读的 README"双轨并行。
2. **127.0.0.1 本地桥是打破沙箱/CORS 的万能胶**：nuclear 的 Rust `stream_server` 把外源流包装成本地回环 URL 绕 CORS（useStreamResolution.ts:L25-31）、agent-zero 的 A0 CLI Connector 把宿主机文件/shell 桥进 Docker 容器（DW 6.5）、LifeOS 的 Hermes sidecar 以独立进程持密钥只回传结果（HERMES/__init__.py:L73-77）、iii 的 sandbox-daemon 经 engine WebSocket 代理进 microVM——"能力在墙外、执行在墙内、回环当门缝"是共同拓扑。
3. **不可信执行的隔离舱三档位**：bit capsule（文件系统级：独立目录+自装 node_modules，isolator.main.runtime.ts）、agent-zero 双 venv（Python 环境级：/opt/venv-a0 vs /opt/venv）、iii libkrun microVM（硬件虚拟级：crash-isolated 子进程，app.rs:L257）——同一"capsule"思想的三种实现粒度，代价与安全强度正交递增。
4. **记忆/知识的三派对立**：agent-zero 是"向量库派"（FAISS+LLM 整固 MERGE/REPLACE+语义级联遗忘）；LifeOS 是"文件系统派"（Cortex 分层目录+Synapse 输入路由+Amber Ledger，git 可回滚）；DocsGPT 是"元数据差分派"（directory_structure 做增量基座，只动变化的 chunk）——三者对"Agent 该记住什么"给出物理形态完全不同的答案。
5. **教学仓与生产仓的 prompt 卫生代差**：llama-cookbook 保留手工 prompt 原始痕迹（"I'll give you a harsh punishment"server.py:L47、遗留 dead code 与 bug）；而同批 LifeOS 把策略编译成代码（Policy.ts 单源生成 guard）、DocsGPT 把配置规范化成纯函数（db_uri.py 双向改写）——"prompt 当代码 vs 代码管 prompt"是 AI 工程成熟度的一把标尺。
