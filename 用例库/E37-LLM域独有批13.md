### nidhinjs/prompt-master（11.2K · — · 2026 · 09-LLMOps）
- **定位**：Claude 技能——为任何 AI 工具写出准确 prompt；「零 token 浪费、全上下文记忆保持、不用反复 re-prompt 到第 4 次才对」[README]
- **痛点经济学**：模糊 prompt→错输出→再试→再试→第 4 次才对 = **3 次浪费的 API 调用 × 每天 50 个 prompt = 真金白银** [README The Problem]
- **关键洞见**：「最好的 prompt 不是最长的，是**每个词都承重**的」——多数 prompt 生成器让 prompt 更长，本技能让它更锋利 [README The key insight]
- **工程决策**：① 兼容面大而全（Claude/ChatGPT/Gemini/Cursor/Copilot/Devin/Midjourney/ComfyUI/Sora…30+ 工具）；② 安装走 claude.ai 技能上传（浏览器端）优先——**技能分发的无 CLI 路径**
- **教学映射**：讲透Prompt（「承重词」原则的工程化）+ skills工程手册
- **一句话本质**：把「 prompt 要短而准」卖成省钱的算术题。
