### memvid/memvid
- **DeepWiki**：46 章；深读 1-Home + 5.x 架构族索引
- **架构模式**：单文件 `.mv2` 便携 AI 记忆引擎（Rust 核心 + CLI/Node/Python 三 SDK），"无数据库、无 sidecar 文件"——数据、索引、元数据全打包进一个文件（DW 1-Home，README.md:L58-65）。
- **核心数据结构**：`.mv2` 文件八区：512B Header（magic `MV2\0`+WAL/TOC 指针）→动态 WAL 区→Zstd 压缩 Frame 数据区→Lex 段（Tantivy BM25）→Vec 段（HNSW 图）→Clip 段（CLIP 视觉向量）→Time 段→TOC/Footer（magic `MV2FOOT!` 支持从尾部反向扫描恢复）（DW 1-Home 文件结构表）；Smart Frame=不可变记忆单元：content+单调时间戳+checksum+ACL 元数据，append-only 永不修改。
- **核心算法/协议**：帧生命周期：`put_bytes_with_options`→WAL 追加（pending 可恢复）→`commit()` 物化为不可变 Frame→四索引器（Tantivy/HNSW/Time/Clip）建索引→TOC 更新+fsync（DW 1-Home，CLAUDE.md:L80-117）；`Doctor::run()` 六阶段修复用 footer 反扫救活损坏文件。本地 Cargo.toml 依赖即架构自白：`tantivy 0.25(optional)`+`hnsw 0.11`+`ort`(ONNX)+`candle-core`(Whisper)+`blake3`+`ed25519-dalek`(签名)+`argon2/aes-gcm`(加密 .mv2e)+`symphonia/rubato/rustfft`(音频重采样)——11 个 feature flag 把多模态做成编译期裁剪。
- **设计模式与工程决策**：① "视频编码"隐喻：Frame 组压缩比 10-50x，类比 I/P 帧；② 时间旅行查询：单调时间戳+`temporal_track` feature 支持自然语言日期（"last Tuesday"）；③ 不可变帧=无锁并行读+审计链。
- **教学映射**：记忆（单文件记忆的物理层教科书）+ RAG（lex+vec+clip 三索引混合检索）
- **一句话本质**：把整个向量数据库+全文索引+时间线压成一个自带 WAL 的自愈式文件。

- **核心算法/协议**：七步管线：GitHub API 取默认分支+recursive tree+README（截断/超限**在建模前拒绝**）→模型一流式英文架构解释→模型二产出 size-bounded AST→服务端验证 id/图连通性/限制/每个链接路径是否真实存在，**非法输出带着聚焦反馈重试**→确定性编译器转全转义 Mermaid（仅 GitHub 域链接）→浏览器 DOMPurify 双重消毒（源码+渲染后 SVG）+链接白名单二次执行→制品与审计态持久化（免二次模型调用）。本地 package.json 印证：`@mermaid-js/layout-elk` 布局引擎、`dompurify`、bun ≥1.3.11、`perf:budget` 性能预算脚本、`patchedDependencies` 补 minimatch。
- **设计模式与工程决策**：① "AST→验证→编译"而非"LLM 直出 Mermaid"：把 LLM 当规划器、语法正确性交给确定性编译器；② Mermaid 完整 parser 只留在测试套件当编译器契约测试，不进生产 bundle；③ 300s Vercel 函数预算内留出配额对账与持久化的应用级 deadline。
- **教学映射**：世界模型（repo 树坍缩为架构图=代码库的世界表示）+ 透视Agent系统工程（LLM+确定性验证器的混合管线范式）
- **一句话本质**：让 LLM 只画草图、编译器落墨——repo 架构图的安全生成流水线。

## 组内横断发现

1. **记忆物理形态三极分化**：memvid 把记忆压成自带 WAL 的单文件（.mv2），Memori 寄生在用户已有 SQL 库（反向 FFI 桥），SurfSense 用 pgvector+RRF 集群检索——同一"Agent 记忆"命题在便携性/零侵入/可协作三个轴上各自登顶，互不兼容。
2. **LangGraph 状态卫生的两个互补惯用法**：mayooear 用 `{docs:'delete'}` sentinel 用完即焚大载荷，SurfSense 用 `safe_exclude_tools+PRUNE_PROTECTED` 剪工具上下文——同一框架内"减状态"与"减工具面"两种上下文预算术。
3. **FFI 反转桥是跨语言核心的通用范式**：Memori 让 Rust 引擎把 SQL 抛回 Node 执行（JSON 协议+oneshot+30s 超时+catch_unwind），与 kubesphere 的 CRD"期望态外置"同构：核心只做编排，副作用全部还给宿主环境。
4. **声明式清单分发复现于三域**：mcp-toolbox 的 tools.yaml 六 kind、camenduru 的 README badge 矩阵、kubesphere 的 init() 控制器注册表——从数据库工具、AIGC 模型到云原生控制器，"数据驱动的清单"都是对抗规模复杂度的同一答案。
5. **DeepWiki 快照时滞必须双源对冲**：gitdiagram 的 DW（2025-06）仍描述已删除的 FastAPI/Postgres 架构，README 已是 Vercel 单体——单信源架构结论不可信，本册双源法的核心价值即在此。
