## 组内横断发现

1. **嵌入的"存 vs 算"谱系出现两极**：LEANN 把嵌入贬为可重算派生数据（ZMQ 按需现算，省 97% 存储），InsForge/txtai 则全量落 pgvector/HNSW——"存储-计算交换"正在成为 RAG 物理层设计的第一轴心，而非单纯的索引选型问题。
2. **记忆三层化收敛**：MiMo-Code（MEMORY.md 文件栈+FTS5+token 预算注入）、InsForge（LLM extract→reconcile 去重→title 常载层/recall 按需层，阈值 0.45/0.5 离线调参）、txtai（session 分区 deque 滑窗）、nofx（Track Record 回喂自身推理）——"抽持久事实+廉价索引+按需召回"成为跨形态共同范式。
3. **"LLM 输出=不可信输入"成为工程公理**：InsForge sanitizeCandidates 逐字段 coerce、nofx 把 AI 决策 JSON 与 Go 硬风控分层、eino 用 FanInMergeConfig/防御式 handler 收敛多源数据——AI 只建议、确定性系统执行的权责分离在四个仓库中各自独立发明。
4. **图执行引擎升格为 agent 框架地基**：eino 的 channel/task 双模（Pregel waitOne vs DAG waitAll）+originalInput 中断重跑、agent-framework 的 checkpoint workflow、MiMo-Code 的 workflow engine——编排层普遍收敛到"可中断、可恢复、带控制/数据双前驱"的数据流图，agent loop 反而成为图上的一种节点模式。
5. **模型管道从 P2P 走向链上**：dalai（2023）用 webtorrent+isomorphic-git 做 P2P 模型分发，nofx（2026）用 x402/USDC 微支付买推理——"模型即资产"的流通层三年内从极客互传演进为自托管钱包按次结算，两仓恰好钉住这条演化线的两端。
