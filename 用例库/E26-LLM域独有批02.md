### rtk-ai/rtk（76.2K · Rust · 2026 · 08-token经济 · 星/月榜 #7）
- **定位**：CLI 代理，在命令输出到达 Agent 上下文**之前**过滤压缩——最高砍 90% bash 输出，单 Rust 二进制，100+ 命令支持，<10ms 开销 [README]
- **机制**：按命令语义定制压缩：ls/tree→带文件计数的树形；cat→签名与结构而非全文；grep→按文件分组截断长行；git diff→剥头减上下文；pytest/cargo test→只留失败、通过折叠成计数；ruff→按规则+文件分组 [README 操作表]
- **工程决策**：① 位置决定价值——拦截点在「输出→上下文」边界而非「上下文→模型」，与 headroom（压缩工具输出库）互补分层；② 单二进制零依赖分发（对齐 Go/Rust 工具哲学）；③ 不改语义只减冗余——保答案不变（README 强调 same answers 类比见 headroom）
- **教学映射**：讲透上下文缓存（token 经济学三件套之「入口压缩」）+ Agent上下文案例
- **一句话本质**：给 Agent 的眼睛装一个按命令语义定制的消音器。
