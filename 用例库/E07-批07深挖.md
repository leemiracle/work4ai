## 组内横断发现

1. **文件即记忆的谱系**：openclaude(结构化 markdown 会话记忆+memdir)、cognee(知识图)、ai-job-search(7 文件画像)不约而同选"人类可读文件"为记忆介面，与 onyx 的 Vespa 企业索引形成黑盒/白盒对立。
2. **多 agent 两极**：cloner 用 worktree 做空间并行(Foreman 分派)，job-search 用 Drafter-Reviewer 做时间迭代(起草-批评-修订)——同一协作问题的坐标轴两端。
3. **权限下沉到不同层**:onyx 把 ACL 编进检索过滤器，cognee 用租户 pin 管引擎生命周期，composio 用禁重试防副作用——安全分别落在数据层、资源层、网络层。
4. **工件即协议跨仓共识**:`.spec.md`(cloner)、frontmatter 记忆文件(openclaude)、LaTeX 模板(job-search)、SVG XML(roadmap)：agent 间契约普遍选人类可读文件而非内部 API。
5. **同一问题的两种解**：配置→组件装配上，Lightning connector 选择"前置校验拒绝"，cognee `_GraphEngineHandle` 选择"惰性解析自愈"——编译期防错 vs 运行期容错的教科书对照。
