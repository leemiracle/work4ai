  This page documents how to integrate WebLLM with Chrome Extensions, enabling browser-based LLM functionality within a Chrome extension context. For information about other worker integrations, see [Web Worker Integration](https://deepwiki.com/mlc-ai/web-llm/3.1-web-worker-integration) and [Service Worker Integration](https://deepwiki.com/mlc-ai/web-llm/3.2-service-worker-integration).

 
## Overview

 Chrome Extension Integration allows running WebLLM models within a Chrome extension context, enabling LLM-powered features directly within the browser. This integration supports two approaches:

 
 - Standard Chrome Extension - Running the model in the extension's popup
 - Service Worker-based Extension - Running the model in a persistent background service worker
 
 Both approaches provide access to WebLLM's capabilities while conforming to Chrome's extension architecture and security model.

 Sources: [examples/chrome-extension/README.md](https://github.com/mlc-ai/web-llm/blob/632d3472/examples/chrome-extension/README.md?plain=1)

## Implementation Comparison

 
### Standard vs Service Worker Approach

 
| Feature | Standard Approach | Service Worker Approach |
|---|---|---|
| Persistence | Model is unloaded when popup closes | Model persists in background |
| Memory Usage | Only active when popup is open | Continuously runs in background |
| Performance | Requires reload on each popup open | Ready immediately |
| Implementation | CreateMLCEngine() | CreateExtensionServiceWorkerMLCEngine() |
| Complexity | Simpler implementation | Requires additional message passing |

## Summary

 Chrome Extension Integration enables WebLLM functionality within Chrome extensions, with two implementation approaches: standard and service worker-based. Both approaches provide similar capabilities but with different persistence and performance characteristics.

 The integration requires specific manifest configurations, particularly for WebGPU and WASM execution. The examples provided in the repository demonstrate complete implementations that can be used as starting points for custom extensions.
