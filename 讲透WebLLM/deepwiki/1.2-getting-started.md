## Built-in Models

 WebLLM comes with several pre-built models that you can use immediately. The major model families include:

 
| Model Family | Available Models |
|---|---|
| Llama | Llama 3, Llama 2, Hermes-2-Pro-Llama-3 |
| Phi | Phi 3, Phi 2, Phi 1.5 |
| Gemma | Gemma-2B |
| Mistral | Mistral-7B-v0.3, Hermes-2-Pro-Mistral-7B, and others |
| Qwen (通义千问) | Qwen2 0.5B, 1.5B, 7B |

 You can view the complete list of supported models at [MLC Models](https://mlc.ai/models) or access the built-in model list programmatically through `prebuiltAppConfig.model_list`.

 Sources: [README.md54-67](https://github.com/mlc-ai/web-llm/blob/632d3472/README.md?plain=1#L54-L67)

## Advanced Usage with Workers

 For better UI performance, WebLLM allows running computations in background threads using Web Workers or Service Workers. The basic approach involves:

 
 - Creating a handler in the worker thread that communicates with the frontend
 - Creating a Worker Engine in your main application that sends messages to the handler
