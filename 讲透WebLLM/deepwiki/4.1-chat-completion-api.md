 For information about Text Completion API, see [Text Completion API](https://deepwiki.com/mlc-ai/web-llm/4.2-text-completion-api), and for Embedding API, see Embedding API.

 
## Overview

 The Chat Completion API enables developers to interact with language models in a conversational manner. It accepts a series of messages representing a conversation and generates appropriate responses from the model. The API supports both synchronous (non-streaming) and asynchronous (streaming) response modes, allowing for flexibility in application design.

### Key Parameters

 
| Parameter | Type | Default | Description |
|---|---|---|---|
| messages | Array | (Required) | List of messages comprising the conversation |
| stream | boolean | false | Whether to stream partial message deltas |
| n | number | 1 | Number of chat completion choices to generate |
| temperature | number | 1.0 | Controls randomness (0.0-2.0) |
| max_tokens | number | - | Maximum tokens to generate |
| stop | string\|array | - | Sequences where generation stops |
| top_p | number | 1.0 | Controls diversity via nucleus sampling |
| frequency_penalty | number | 0.0 | Penalty for token frequency (-2.0 to 2.0) |
| presence_penalty | number | 0.0 | Penalty for token presence (-2.0 to 2.0) |
| logit_bias | object | - | Modifies likelihood of specified tokens |
| seed | number | - | For deterministic generation |
| model | string | - | Model ID to use (optional if only one loaded) |

## Comparison with OpenAI API

 WebLLM's Chat Completion API closely follows the OpenAI API specification, making it straightforward to migrate existing applications. Key differences include:

 
 - Model loading is handled separately with `CreateMLCEngine()` or `engine.reload()`
 - Additional performance metrics in the `usage.extra` field
 - Browser-specific optimizations for WebGPU
 - Support for worker integrations (Web Worker, Service Worker)
 
 This compatibility allows developers to leverage their existing knowledge while benefiting from the advantages of running models directly in the browser.
