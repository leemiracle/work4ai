  MLCEngine is the core component of WebLLM that provides the primary interface for applications to interact with language models directly in the browser. It handles model loading, inference execution, resource management, and provides OpenAI-compatible APIs for chat completions, text completions, and embeddings.

 For information about the Chat System that MLCEngine uses internally, see [Chat System](https://deepwiki.com/mlc-ai/web-llm/2.2-chat-system). For details on embedding functionality, see [Embedding Pipeline](https://deepwiki.com/mlc-ai/web-llm/2.3-embedding-pipeline). For worker integrations that can host MLCEngine in background threads, see [Worker Integrations](https://deepwiki.com/mlc-ai/web-llm/3-worker-integrations).

## Resource Management

 MLCEngine carefully manages GPU resources and handles concurrency:

 
 - **Model Maps**: Tracks loaded models, their configurations, and pipeline instances
 - **Custom Locks**: Ensures only one request is processed per model at a time
 - **WebGPU Resources**: Properly initializes and disposes of GPU resources
 - **Caching**: Uses IndexedDB or Browser Cache API for model artifacts

## Worker Integration

 MLCEngine can run in different execution contexts:

 
 - **Main Thread**: Default execution in the browser's main thread
 - **Web Worker**: Offloaded execution using WebWorkerMLCEngine
 - **Service Worker**: Persistent execution using ServiceWorkerMLCEngine
 
 The Worker variants provide the same interface as the base MLCEngine but communicate with the actual MLCEngine instance running in a worker thread through a message-passing protocol.

## Error Handling

 MLCEngine provides comprehensive error handling with specific error classes for different scenarios:

 
| Error Type | Description | Examples |
|---|---|---|
| Environment Errors | Issues with browser capabilities | WebGPUNotAvailableError, ShaderF16SupportError |
| Resource Errors | Problems with GPU resources | DeviceLostError |
| Configuration Errors | Invalid configuration parameters | ConfigValueError, WindowSizeConfigurationError |
| Input Validation Errors | Invalid API parameters | StreamingCountError, InvalidResponseFormatError |
| State Errors | Incorrect engine state | ModelNotLoadedError, EngineNotLoadedError |

## Performance Considerations

 MLCEngine includes several performance optimizations:

 
 - **Caching**: Model artifacts are cached in IndexedDB or the browser's Cache API
 - **KV-Cache Reuse**: Maintains KV cache between chat turns for efficiency
 - **Prefill Chunking**: Processes large prompts in manageable chunks
 - **Resource Cleanup**: Properly disposes of GPU resources to prevent memory leaks
 - **Locks for Concurrent Requests**: Ensures model resources aren't oversubscribed
