## Documentation System Overview

 The WebLLM documentation is built using a combination of two documentation systems:

 
 - **Sphinx** - A powerful documentation generator that converts reStructuredText (RST) files into HTML
 - **Jekyll** - A static site generator used for the WebLLM website
 
 These systems work together to produce the complete documentation suite for WebLLM.

## Documentation Deployment Process

 The WebLLM documentation is automatically deployed to GitHub Pages when changes are pushed to the `main` branch. Here's how the deployment process works:

 
```

```

 The deployment script performs the following steps:

 
 - Builds the Sphinx documentation with `make html`
 - Builds the Jekyll site with `jekyll b`
 - Copies the Sphinx HTML output to the Jekyll site's `_site/docs` directory
 - Commits the combined site to the `gh-pages` branch
 - GitHub Pages then serves the content from this branch

## Contributing to Documentation

 When contributing to the WebLLM documentation, follow these guidelines:

 
### File Formats

 
 - Use `.rst` (reStructuredText) files for Sphinx documentation
 - Use Markdown (`.md`) for simpler content when appropriate
 
 
### Adding New Documentation

 
 - Create new `.rst` files in the appropriate directory (`user/` or `developer/`)
 - Add the new file to the table of contents in `docs/index.rst`
 - Build locally to test your changes
 
 
### Documentation Style Guide

 
 - Use clear, concise language
 - Include code examples when explaining APIs
 - Add cross-references to related documentation
 - Add diagrams when explaining complex systems
