# 讲透迁移与城镇化统计 · 最难数的一环(迁移度量/城镇化率/城乡口径)

> **定位句**:这支管人口三大事件中唯一没有全球统一登记基础设施的一件——迁移:
> 出生与死亡各有登记,迁移只有口径;本支管迁移的度量(净迁移/迁移率/迁移流估计)、
> 城镇化统计(城镇化率/城乡划分标准)与两者共用的口径技术学。
> GB/T 13745-2009:91045 人口统计学 · 本支为**自定主干支**。家族:[讲透人口统计学](../README.md)。

## 诞生

1885 年 Ravenstein 基于英国普查数据提出迁移七法则(距离/阶梯/流对偶——
迁移研究的第一组经验定律);1946 年 Zipf 的重力模型(迁移流∝P₁P₂/D,相互作用论的
极简版);1966 年 E. S. Lee 的推拉理论(出发地/目的地/中间障碍/个人因素四件套)。
制度侧:1998 年联合国《国际迁移统计建议》试图统一各国口径(常住时长 3/6/12 个月的
定义差至今未消除);中国 2008 年《统计上划分城乡的规定》统一了国内口径,
2020 年七普的流动人口规模成为世界最大规模的国内迁移观测。模型侧:2012 年 Simini 等
的辐射模型(Nature)用人口分布的「吸收」过程替代重力隐喻——从拟合走向生成机制。

## 核心问题

- 无登记处的事件怎么数:残差法(净迁移=人口变动−自然增长,平衡方程的反演)、
  普查询问法(出生地/五年前居住地)、行政大数据(社保/学籍/手机信令)三路线的
  各自偏差结构
- 迁移流矩阵的估计:从边际(各地净迁移)反推流向(谁到谁)——重力/辐射模型是
  补全矩阵的标准工具
- 城乡定义之争:联合国无统一定义,城镇化率不可跨国直接比;中国口径(2008 规定)
  与 UN 口径的换算陷阱
- 迁移预测:三大人口输入(TFR/寿命/迁移)中最粗糙的一环——
  发达国家自然增长转负后,迁移升格为人口方程主变量,而它的度量缺口最大

## ✨ 这支最美的一个事实

**残差法之美**:一次迁移都不用数,只用两次普查+出生死亡登记,就把净迁移逼出来——
净迁移 = 期末人口 − 期初人口 − 出生 + 死亡。会计恒等式的反演:数不清的事件,
用数得清的事件相减得到。它与凯恩斯宏观恒等式的逻辑同构——
代价是残差同时吸收普查误差(「垃圾桶项」),数字越准的错觉越危险(家族 03 章 §6)。

## 假设与暗面

- 常住口径假设:迁移的「定义」(离开发记地多久算迁移)由口径决定——口径变,数字变
- 时期迁移率可重复假设:历史迁移率外推未来——劳动力市场突变即失效
- 城乡二元假设:城乡划分把连续的聚落谱切成两截;结合部(城乡结合带)最容易被错分
- 漏报集中:流动人口恰是普查最难数的人群(人户分离/多居所/无固定居所)——
  迁移数据的质量与迁移人群的边缘性负相关
