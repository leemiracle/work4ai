# 03 · 可构造与结构——Lexis 图、Leslie 矩阵与死亡率因子

> **本章回答五问之 Q4(天然可构造的结构)**。
> **本质一句话**:人口数据天然长着三种可计算结构——**Lexis 图**(年龄×时间的坐标格,
> 每个事件有唯一格位)、**投影矩阵**(Leslie:率打包成矩阵,动力学=Perron-Frobenius
> 主特征值)、**因子结构**(Lee-Carter:年龄×年份死亡率矩阵的低秩分解);
> 外加一个会计骨架(平衡方程)——四者一起,把「数人」变成线性代数。

---

## 0. 开篇故事:三行矩阵决定两件事

📖 打开 [`experiments/00_leslie.py`](experiments/00_leslie.py),跑一遍。三个年龄组、
一个 3×3 矩阵、60 步迭代,你会看到:

```
周期  1  增长率 1.166000(初始非稳定结构的暂态)
周期  2  增长率 1.238250(回声振荡)
  …
周期 60  增长率 1.145710   ← 收敛
解析主特征值 λ1 = 1.145710(特征多项式二分求根)
年龄结构收敛到 (λ1², s0·λ1, s0·s1)/‖·‖ = (38.8%, 33.2%, 28.1%)
```

**稳定人口定理的数值版**:任意初始结构,增长率的极限与年龄结构的极限都由矩阵唯一决定
——「结构」在这里不是比喻,是线性代数。本章把这个现象连同另外两种天然结构一一拆开。

## 1. 会计结构:平衡方程是最朴素的骨架

```
P_{t+1} = P_t + B − D + I − E
(存量下一期 = 存量本期 + 出生 − 死亡 + 迁入 − 迁出)
```

| 结构要素 | 数据化形式 | 判断藏在哪 |
|---------|-----------|-----------|
| 存量 P | 普查/登记的时点数 | **口径**:常住还是户籍(02 章 §2) |
| 流量 B/D | 生命事件的期间登记 | **完整性**:漏报率;死因归类 |
| 流量 M | (多数国家没有直接登记) | **残差项**:M = P_{t+1}−P_t−B+D,吸收一切误差——「垃圾桶项」之险 |

会计结构的两用:正向做**预测**(队列要素法=平衡方程按年龄展开),反向做**校验**
(残差=迁移+误差;残差异常大→某项数据有假)。人口会计与国民账户同源同纪律:
恒等式不可辩驳,可辩驳的只是往恒等式里填的数。

## 2. Lexis 图:人口事件的坐标系

年龄(纵轴)×日历时间(横轴)的坐标格,是人口统计学的**专利发明**(Wilhelm Lexis,1875):

```
 年龄
  3 ┤\      \       \
  2 ┤ \  队列(对角线) \
  1 ┤  \      \       \
  0 ┼───┴──────┴───────┴──→ 时间
      2024   2025   2026
      (横线=时期切;竖线=年龄切;对角线=队列切)
```

- **一个事件三个坐标**:2025 年、2 岁组、出生于 2022 年的队列——时期/年龄/队列恰好
  两两确定第三个;任何年龄别事件都能且只能落在一个格位(02 章「可数性」的几何版)。
- **三种切法=三种研究**:横切(时期分析:今年死亡率)、纵切(定点分析:某岁死亡率
  的百年轨迹)、斜切(队列分析:一代人的完整传记)。
- **实战价值**:HMD/HFD 的全部数据按 Lexis 方格组织;「队列效应」(某代人的特殊命运,
  如饥荒 cohort)只有在对角线切法下才显形;数据错位(事件被记进错格)是微观个体数据
  清洗的第一类 bug。

## 3. 矩阵结构:Leslie、稳定人口与动量

**Leslie 矩阵**(1945):首行放各年龄组生育率,次对角线放组间存活率:

```
        ⎡ f0  f1  f2 ⎤        n_{t+1} = L · n_t
    L = ⎢ s0   0   0 ⎥   ⟺   特征多项式 λ³ = f0λ² + s0f1λ + s0s1f2
        ⎣  0  s1   0 ⎦        (Euler-Lotka 方程的矩阵化)
```

| 结构事实 | 人口学含义 |
|---------|-----------|
| Perron-Frobenius:不可约本原矩阵有唯一正特征值 λ₁>0 | **长期增长率唯一**;实验断言 A1:60 步经验增长率收敛到二分求根的 λ₁ |
| 对应右特征向量 v₁=(λ₁², s0λ₁, s0s1) | **稳定年龄结构唯一**;断言 A2:年龄份额收敛到 v₁/‖v₁‖ |
| 次主特征值模 |λ₂|<λ₁,比值≈0.53(实验参数) | 收敛速率与暂态振荡的衰减;|\lambda₂/λ₁| 越小,「忘掉初始结构」越快 |
| **Keyfitz 动量**:初始结构≠稳定结构时,率变而结构滞后 | 生育率骤降到更替水平(λ→1),人口仍按旧结构的惯性增长——实验动量段:60 年才停 |
| Caswell 推广(1980s-):阶段结构(.stage-classified) | 幼体/成体/繁殖期分类的生命表——生态学反向借走本家族的矩阵 |

> 结构视角的妙处:Lotka(1907)用解析方法证明的稳定人口定理、Keyfitz(1971)的动量
> 公式、Leslie(1945)的矩阵——三条历史线在**同一个特征值**上会师。
> 亲历:把实验里的 F1 从 0.90 改成 0.45,重跑——λ₁ 立即下移,稳定结构的「底座」
> 随之收窄:**政策改的是矩阵第一行,命运改的是特征值**。

## 4. 因子结构:Lee-Carter 与死亡率的低秩真相

把年龄×年份的死亡率排成矩阵 M(x,t),取对数减去年龄均值,**这个矩阵惊人地接近秩 1**:

```
log m(x,t) ≈ a_x + b_x · k_t
    a_x:年龄谱形(各年龄的基准对数死亡率,几乎不随时间变)
    b_x:年龄敏感度(哪个年龄随时代起舞:中年心血管 vs 老年癌症)
    k_t:死亡率年代指数(一年一个数,百年一条下行曲线)
```

| 结构事实 | 方法含义 |
|---------|---------|
| 估计=中心化矩阵的 SVD 第一因子+归一约束(Σb=1, Σk=0) | 可识别性:三组参数有冗余,约束即规范化(02 章⑤层) |
| 低秩假设=各年龄死亡率**共动**(共享一个 k_t) | 死亡率改善高度同步——这是 20 世纪的实证事实,不是先验 |
| 外推 k_t(随机游走带漂移)→ 概率化死亡率预测 | Lee-Carter 系=概率走廊的死亡率入口(01 章 1.1) |
| 破坏低秩的事件:COVID 类冲击、各年龄不同步(如毒品/肥胖疫情的年龄特异性) | 后继修正:Li-Lee 相干模型(各国共动)、CoDA/函数型版本 |

✨ **美之时刻 3:Lee-Carter 用两个参数画百年死亡率**(必然)。为什么美:一整个国家
一百年、上百个年龄×年份的死亡率,被压缩成**一条时间曲线 k_t** 加一个固定的年龄指纹——
1900 年瑞典与 2000 年瑞典的死亡率谱,是「同一形状被整体平移+弯折」。
这是 SVD 在真实世界最干净的一次显灵:低秩不是近似技巧,是死亡率历史的**本性**。
亲历:取 HMD 任一国家 log 死亡率矩阵,做秩 2 奇异值分解,看第一奇异值占比
(通常 >95%)——两个参数之外,剩下的全是小事(03 章练习 2)。

## 5. 数据结构:三支柱与「数据质量本身可计算」

| 支柱 | 提供 | 结构弱点 |
|------|------|---------|
| 普查(census) | 年龄结构全景(每 5/10 年) | 净误差(漏/重)——双系统估计(普查后调查 PES)修正 |
| 生命登记(vital registration) | 出生/死亡的连续账本 | 漏报(尤其发展中国家死亡登记);死因归类口径 |
| 抽样调查(survey) | 普查间隔年的率(DHS/MICS 类) | 抽样误差;回顾期偏差 |

数据质量不是脚注而是结构:**年龄堆积**(数字偏好:报 30/40/50 的人异常多)用
Whipple 指数、Myers 混杂指数量化——「这个国家的年龄数据可信到第几位」本身是一个
可计算的数;婴儿死亡率缺口用出生史分布法(GGB/SAGE、Brass logit 系统)回填。
HMD 的贡献正在于此:**输入检查协议**(暴露人年×率=死亡数的逐格核对)让一个数据库
同时成为方法学校。

## 6. 假设与代价:结构视角的盲区

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 年龄分组(5 岁/组或 15 岁/组) | 表格规整、矩阵小型 | 组内进度信息丢失;组界效应(队列在组内老化被冻结一个周期) |
| 率恒定(矩阵投影) | 收敛定理、解析特征值 | 现实率随时间漂移;外推=把今天冻结到未来(00 章 §五) |
| 低秩(Lee-Carter) | 两个参数可解释可外推 | 假设各年龄共动;结构性冲击(疫情/新疗法的不均匀受益)打破假设 |
| 会计恒等(残差=迁移) | 无迁移登记也能反推 M | 残差吸收一切误差——普查错一点,「迁移」就虚高一点(垃圾桶项) |

> **一句话**:四种结构各买一个便宜——规整、定理、参数少、免登记——账单统一由
> 「假设现实配合结构」支付;结构越优雅,越要问现实什么时候不配合。
