# 00 · 体系结构:人口统计学家族的全图

> **本章回答五问之一(家族层):整个体系结构长什么样。**
> **本质一句话**:人口统计学=用数刻画人的生老病死与迁徙——三个可数事件(出生 B、死亡 D、
> 迁移 M)沿年龄轴 x 滚动,一切指标、生命表、矩阵与预测都是四元组 (B, D, M, x) 的函数。
>
> 它是统计学里**对象最诚实**的家族:别的领域先造模型再找数据,本领域的数据(人)
> 生下来就是整数,事件生下来就是可数的——剩下的全部难题,都在「怎么数清」与「怎么外推」。

## 一、开篇故事:一门与统计学共同出生的学科

人口统计学没有自己的创世纪——**它的起点就是统计学的起点**。

📖 **1662 年,伦敦,Graunt 的死亡表**。纽扣商人 John Graunt 出版《关于死亡公报的自然与
政治观察》,把五十年教区死亡烂账变成推断:反推伦敦人口约 38.4 万、发现男女比约 14:13、
构造了第一张生命表雏形。这一张表同时是三个学科/家族的零点:**统计学**(数据→推断的方法,
通史见本宇宙统计学史家族)、**人口统计学**(本家族——生老病死的度量术)、
**精算**([../../讲透数学/讲透应用统计数学/](../../讲透数学/讲透应用统计数学/)保险数学侧——
寿命的金融化)。一个家族的族谱页脚可以只写一行:1662。

📖 **1693 年,Halley 的布雷斯劳生命表**。天文学家 Halley(那颗彗星的主人)用西里西亚
布雷斯劳市的出生死亡登记,造出第一张**精算级**生命表,并当场用它计算终身年金的现值——
一张表同时回答「人能活多久」与「长寿风险值多少钱」。1762 年伦敦公平人寿(Equitable)
成立,首次按生命表给寿险定价:**生命表与精算的联姻就此制度化**。死亡率数据从国家账本
变成金融产品的原料。

📖 **1798 年,马尔萨斯的人口原理**。Malthus 断言人口按几何级数增长而生活资料按算术级数
增长——**第一次把人口当成有动力学的系统**来提问。他的几何级数预言被两百年历史证伪
(他没想到生育率会自愿下跌),但他把「人口增长率由生育与死亡两股力决定」的动力学框架
留给了后人:Lotka 的稳定人口理论(1907)就是这个框架的严格化。

📖 **人口普查史:国家实验室**。1790 年美国把普查写进宪法(每十年一次,议席按人口分配——
普查数字直接就是政治权力);1801 年英格兰-威尔士首次现代普查;1953 年中国第一次现代普查,
到 2020 年第七次(七普)。普查是本家族的**国家实验室**:登记提供连续账本,普查提供定期全景,
两者互相校验(净误差用普查后调查 PES 的双系统估计——捕获-再捕获的人口学版)。

**四段故事的共同基因**:先有账(教区登记/普查),再有率(生命表),再有模型(稳定人口/矩阵),
最后有概率(贝叶斯分层)。这条「账→率→模型→概率」的四级台阶,就是本家族的体系结构。

## 二、家族树血肉(三支各三行:地盘/招牌定理/招牌工具)

## 三、领土谈判:人口统计学 vs 人口学(一面劈成两半)

「demography」一词 1855 年由法国人 Guillard 首创(demos 人民 + graphia 描写)——
本义并无「统计」与「研究」之分。GB/T 把它劈成两半:

```
                demography(描写人民)
                /                  \
   GB/T 84071 人口学              GB/T 91045 人口统计学
   (社会学宇宙)                   (本家族,统计学宇宙)
   「为什么」:人口思想史、         「怎么数」:度量、生命表、
   生育意愿、老龄化社会、          矩阵投影、概率化预测、
   人口政策、迁移社会学            普查与登记的口径技术
```

**谈判结果**:解释与政策归人口学(社会学宇宙,见
[../../讲透社会学/README.md](../../讲透社会学/README.md));度量与预测归本家族。
两边的接口:人口学的一切争论(生育率为何走低、老龄化如何应对)最终都要经过本家族的
度量与预测才能落地。与数理统计的分家同理:率的推断本体(抽样误差、双系统估计的
统计理论)住数学宇宙;与经济统计的分家:劳动力与养老金的经济模型在兄弟家族,
本家族只提供人口输入。

## 四、核心问题清单(已解决/未解决)

**已解决的里程碑**:

| 年代 | 人物/机构 | 结果 |
|------|----------|------|
| 1662 | Graunt | 死亡表+人口反推:由账到人的推断引擎 |
| 1693 | Halley | 精算级生命表+年金定价:寿命的金融化 |
| 1907/1911 | Lotka | 稳定人口理论:恒定率⇒人口指数增长+年龄结构收敛(Euler-Lotka 方程) |
| 1930s-40s | Whelpton 等 | 队列要素法(cohort-component):官方预测的标准骨架 |
| 1945 | Leslie | 矩阵投影:三代人压进一个矩阵,增长率=主特征值 |
| 1966 | Coale-Demeny | 模型生命表:用少量参数插补数据缺口国家的死亡率 |
| 1971 | Keyfitz | 人口动量:生育率降到更替水平后人口仍增长数十年(可解析计算) |
| 1992 | Lee-Carter | 死亡率因子模型:log m(x,t)=a_x+b_x·k_t,两个参数画百年死亡率 |
| 2015- | UN(WPP) | 官方预测全面概率化:贝叶斯分层给区间不给点值(01 章详述) |

**悬而未决的大问题**(带地位):

- **超长期人口预测**(地位:官方机构自己都在反复失手)。联合国的世界人口展望每一版都
  把峰值预期向下、向早修订——生育率下降快于预期(Spears 2024,检索校准 2026-09-07),
  峰值共识窗口收缩到 2060-2090。概率化把「预测失手」包装成「区间管理」,
  但 100 年尺度的区间宽到几乎不含信息。
- **生育率为何持续走低**(地位:整个预测链条最软的一环)。经济学解释(养育成本)、
  文化解释(第二次人口转变)、性别公平解释各说中一部分,没有一个能**预测**——
  东亚 TFR≈1.3(2023,World Bank,全球最低区域)在二十年前的主流预测里几乎无人料到。
  B 端(生育)不可预测,人口预测的上限就被锁死。
- **迁移统计**(地位:三大事件中唯一没有全球统一登记基础设施的)。各国常住口径不一
  (3 个月/6 个月/12 个月),国际迁移流数据靠估计;对城市而言迁移恰恰是主导项。
- **健康预期寿命(HALE)的测度**(地位:老龄化争议的核心口径)。活得久≠活得健康,
  自评健康/失能年限的跨国可比性仍是方法论工地。

## 五、假设与代价(本家族站在什么之上)

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| **封闭人口**(无迁移) | 生命表与稳定人口理论的全部漂亮定理成立 | 对城市与短期国家人口机械外推**全错**——迁移主导时,封闭模型必然系统性偏差 |
| **时期数据≈队列行为**(虚拟队列) | 一年登记数据即可造生命表、算 TFR | 时期 e_0 不是今年出生者将活的岁数;生育推迟会人为压低 TFR(Bongaarts-Feeney 进度效应) |
| **率的平稳性**(外推) | 线性外推一行代码 | **线性外推的百年失败史**:1970s 各机构对 2000 年全球人口的预测普遍高估;联合国逐版下修就是「外推诱惑」的账单 |
| **单性/两性对称简化** | Leslie 矩阵减半、模型可解释 | 出生性别比波动与性别选择(「失踪的女性」)需要显式建模才能看见 |

**一句话**:人口统计学用「封闭」换定理,用「时期」换数据可得,用「平稳」换外推的便宜,
用「单性」换矩阵的干净——四个便宜没有一个是白拿的,而每一个的账单都由预测误差支付。

## 七、反直觉发现(讲透铁律)

**发现 1:人口动量——急刹车后火车仍在走**。直觉上,生育率降到更替水平(≈2.1)人口
就该停止增长——错。**Keyfitz(1971)**:育龄人群的规模由过去 20-30 年的出生数决定,
存量已定;即使生育率**今天**降到更替水平,人口仍将再增长数十年才见顶。
亲历:跑 [`experiments/00_leslie.py`](experiments/00_leslie.py) 的动量段——三年龄组人口
在生育率骤降到更替水平(净再生产率=1)后**60 年内始终高于初始水平**
(先增、后带年龄结构回声振荡,第 30 年见峰 1.0585 倍),才在新平台上停住。
全球现实:二战后所有完成生育转变的国家,都先经历了「生育率达标、人口照涨」的动量期。

**发现 2:预期寿命不是你以为的那个数**。媒体三读:①「今年死的人平均活 73.3 岁」——错,
那是**平均死亡年龄**(受年龄结构影响,老龄化社会它自然上升);②「今年出生的孩子将平均
活 73.3 岁」——错,那要等**队列生命表**(等这一代真死完);③正解:**虚拟队列**——假设
未来每一年都重复今年的年龄别死亡率,一个今天出生的人平均活 73.3 岁。一个指标,
三层语言(02 章 §0 的解剖标本)。

**发现 3:更替水平不是 2.0,是 ≈2.1,而且不是常数**。TFR=2.0 恰好替代父母?不对:出生
性别比约 105:100(每 100 个女儿对应 105 个儿子),再加女婴存活到育龄的死亡损耗——
发达国家更替水平≈2.1;高死亡率环境更高(2.3-3.0)。「2.1」是死亡率的函数,不是宇宙常数。

## ✨ 美之时刻(全家族合计 ≥3 之前两枚,第三枚在 03 章)

✨ **美之时刻 1:一列数字算出预期寿命**(极简)。生命表的灵魂只有一列——存活人数
l_x(l_0=100000 名新生儿,逐岁递减)。把相邻两行取平均、逐行加总,再除以 l_0:
**e_0 = Σ L_x / l_0**。为什么美:一列单调递减的整数,同时编码了死亡率分布、寿命分布、
养老金缺口与寿险费率的全部定价基础——Halley 1693 用它算年金,Graunt 1662 用它读瘟疫。
亲历:任取一张生命表(如 HMD 任意国家),把 l_x 列用五行代码加一遍,亲手算出 e_0,
与官方值对到小数点后一位。

✨ **美之时刻 2:Leslie 矩阵把三代人压进一个矩阵**(必然)。三个年龄组,第一行放生育率,
次对角线放存活率,得到 3×3 矩阵 L;人口演化就是一个矩阵乘法 n_{t+1}=L·n_t。
Perron-Frobenius 定理保证:无论初始结构多离谱,增长率收敛到主特征值 λ₁,
年龄结构收敛到主特征向量——**一个代数方程锁死一代人的命运形状**(03 章 §三)。
亲历:`00_leslie.py` 断言 A1/A2 就是这条定理的数值版,解析解与 60 步迭代对到 1e-9。
