# 讲透人口统计学 · 用数刻画人的生老病死与迁徙

> **本质一句话**:人口统计学=用数刻画人的生老病死与迁徙——出生、死亡、迁移三个可数事件,
> 沿年龄这条轴滚动,聚成一个群体的时钟(预期寿命)、河流(增长与缩减)与年龄金字塔(结构);
> 它与统计学共享同一个起点:1662 年 Graunt 的死亡表。
> GB/T 13745-2009:910 统计学 · 二级学科 **91045 人口统计学**(GB/T 未列三级 → 本家族三支均自定主干支)。
> 家族:[讲透统计学](../README.md) 宇宙。**与 84071 人口学的关系声明**:社会学宇宙管人口学本体
> (人口思想/人口问题/人口政策/迁移社会学),本家族管**统计技术面**——怎么测、怎么建模、怎么预测。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透人口统计学/
├── 讲透生育与死亡分析/    🆓 自定主干支——生与死两端的度量术:生育率族(ASFR/TFR/NRR)
│                           与生命表(q_x/l_x/e_x);一列存活人数定寿命,一族率定生育
├── 讲透人口预测/          🆓 自定主干支——把今天的年龄结构推到明天:队列要素法/Leslie 矩阵/
│                           Lee-Carter 死亡率因子/贝叶斯概率化
└── 讲透迁移与城镇化统计/  🆓 自定主干支——三大事件中最难数的一环:净迁移估计/迁移流/
                            城镇化率与城乡口径
```

> 三支的共同血统:**平衡方程 P_{t+1} = P_t + B − D + M**——生育死亡分析管 B 与 D,
> 迁移统计管 M,人口预测把三者连同年龄结构 x 装进同一个引擎;一切指标、模型与预测
> 都是四元组 (B, D, M, x) 的函数。
