# 讲透人口预测 · 把今天的年龄结构推到明天(Leslie/队列要素/Lee-Carter/概率化)

> **定位句**:这支管本家族的旗舰产品——预测:把已出生者的年龄结构(惯性,准)
> 与未出生者的生育死亡假设(信仰,不准)装进同一个引擎;从 Malthus 的几何级数提问,
> 到 Lotka 的稳定人口定理、Leslie 的矩阵、Lee-Carter 的死亡率因子,
> 再到联合国 WPP 的贝叶斯概率化——一支「把不确定性本身建模」的进化史。
> GB/T 13745-2009:91045 人口统计学 · 本支为**自定主干支**。家族:[讲透人口统计学](../README.md)。

## 诞生

1798 年 Malthus 首次把人口当动力学系统提问(人口几何级数 vs 生活资料算术级数——
预言错了,框架留下了);1907/1911 年 Lotka 证明恒定率⇒人口渐近指数增长且年龄结构
收敛(稳定人口理论,Euler-Lotka 方程);1930s-40s Whelpton 等发展队列要素法
(cohort-component)——至今仍是所有官方预测的标准骨架;1945 年 Leslie 把它写成矩阵,
增长率=主特征值;1971 年 Keyfitz 给出动量的解析计算(生育率骤降到更替水平,
人口仍增长数十年);1992 年 Lee-Carter 用两个参数画百年死亡率并给出概率化外推;
2015 年起联合国 WPP 全面概率化(TFR/寿命/迁移各配贝叶斯分层模型,给区间不给点值),
2024 版延续该框架并逐版下修峰值预期(检索校准 2026-09-07)。

## 核心问题

- 已解决:短中期(≤20 年)预测靠**已知年龄结构**的惯性可达高精度;
  动量可解析(Keyfitz 公式,家族实验 `00_leslie.py` 数值实拍);
  死亡率长期预测可用 Lee-Carter 系(低秩结构+时间序列外推)
- 未解决(地位):超长期生育率走向——没有方法能从数据内决定,贝叶斯先验=穿概率外衣的
  判断;预测区间的覆盖率回验(80% 区间真的覆盖 80% 吗);迁移预测(三大输入中最粗糙的)
- 方法论之争:情景(SSP/变体)与概率(贝叶斯区间)的语义边界——混用即事故

## ✨ 这支最美的一个事实

**一个代数方程锁死一代人的命运形状**:Leslie 矩阵的特征多项式
λ³=f0λ²+s0f1λ+s0s1f2(三年龄组情形)有唯一正根 λ₁——无论初始人口结构多离谱,
增长率收敛到 λ₁、年龄结构收敛到主特征向量(Perron-Frobenius)。政策改的是矩阵
第一行(生育率),命运改的是特征值——动力学与代数在人口学最干净的一次会师
(家族 03 章 §三 + 实验 A1/A2 断言)。

## 假设与暗面

- 率外推假设:矩阵投影把今天的率冻结到未来——现实率随时间漂移,误差随预测时长放大
- 封闭人口假设:标准投影中迁移是外生假设项,不是模型内生量——城市级预测的主导项
  恰恰是它
- 概率化包装的风险:区间管理≠预测能力;100 年尺度的区间宽到几乎不含信息
- 修订序列的沉默:引用预测不带版本号,等于引用幻影
