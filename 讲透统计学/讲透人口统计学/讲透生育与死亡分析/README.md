# 讲透生育与死亡分析 · 生与死两端的度量术(生命表与生育率族)

> **定位句**:这支管人口三大事件中最「配合统计」的两件——出生与死亡都有登记传统,
> 于是长出了本家族最精致的度量术:死亡端的**生命表**(q_x→l_x→e_0 的流水线)与
> 生育端的**率族**(ASFR→TFR→NRR);一个把寿命变成一列可加总的数,
> 一个把生育变成一个可跨国比较的数。
> GB/T 13745-2009:91045 人口统计学 · 本支为**自定主干支**。家族:[讲透人口统计学](../README.md)。

## 诞生

1662 年 Graunt 用伦敦死亡公报造出第一张生命表雏形(本家族与统计学的共同起点);
1693 年 Halley 的布雷斯劳生命表达到精算级并当场算出年金现值;1762 年伦敦公平人寿
按生命表给寿险定价——生命表与精算联姻。生育端滞后两百年:20 世纪初各国出生登记
完善后,年龄别生育率与总和生育率(TFR)成型;1998 年 Bongaarts-Feeney 区分生育的
**数量(quantum)**与**进度(tempo)**,给 TFR 装上修补贴。数据基础设施侧:
1966 年 Coale-Demeny 模型生命表(为缺数据国家插补死亡率);2002 年人类死亡率数据库
(HMD)建立——生命表研究有了全球标准实验室。

## 核心问题

- 从死亡登记到 e_0:一列年龄别死亡率如何**合法地**变成「预期寿命」?
  (q_x 与 m_x 的换算、开口组的处理——每步都是一个口径决定)
- 生命表到底测什么:时期表(虚拟队列)与队列表(一代人真传记)的差距有多大?
- TFR 的时期扭曲:生育推迟年代,TFR 低估了多少真实生育水平?(tempo 调整)
- 缺数据怎么办:模型生命表(Coale-Demeny/UN)、Brass logit 系统、
  出生史法估计婴儿死亡率——用有数据国家的规律给无数据国家插值
- 更替水平的严格口径:为什么 NRR=1 才是定义,TFR≈2.1 只是近似?

## ✨ 这支最美的一个事实

**一列存活人数 l_x 决定一切**:给定 l_0=100000 与逐岁 l_x,预期寿命就是把相邻两行
取平均再逐行加总——e_0=ΣL_x/l_0。一列单调递减的整数,同时是死亡率分布、寿命分布、
寿险费率与养老金缺口的全部分析起点;Halley 1693 年用它算年金,Graunt 用它读瘟疫,
今天精算师用它定价长寿风险——一张表,360 年,三个行业。

## 假设与暗面

- 虚拟队列假设:时期生命表把一年截面当一代传记——死亡率改善年代,e_0 系统性低估
  新生儿的真实前景(02 章 §0 的三读之谜)
- 登记完整性:发展中国家死亡漏报普遍;婴儿死亡漏报最重——交叉检验
  (平衡方程残差、出生史回顾)是必需品而非奢侈品
- 死因归类口径随医学与政治变化:时间序列对接前先读死因编码史( ICD 版本断层)
- 年龄堆积:自报年龄偏好 0/5 结尾——Whipple/Myers 指数先行体检
