# 讲透数字经济测度 · GDP 量不到的新大陆:免费品/数据资产/平台

> **定位句**:这支负责"**表盘之外的新经济**"——搜索与社交网络零价格提供服务、
> 数据成为企业的"油田"、平台撮合多边市场;现行 GDP 对这三样几乎失明,
> 本支研究怎么给它们装仪表。GB/T 13745 91030 · **自定主干支**。家族:[讲透经济统计学](../README.md)

## 诞生

- **谁/何时**:Griliches 1960 年代提出"服务与质量测度危机";**BEA 1985** 起对
  计算机做 hedonic;**Brynjolfsson & Oh 2012**"注意力经济"用选择实验给免费服务
  定价;**BEA 2019** 首版数字经济卫星账户;**GDP-B**(2019 起)补免费品消费者
  剩余;**SNA 2025**(2025-03 通过)把数据资本化为生产资产;OECD 2023 起测度系列。
- **因什么问题**:①零价格服务在现行语法里记零;②平台多边市场价格信号失真;③数据资产的存量与折旧从未入账。

## 核心问题

**已解决**:
- 卫星账户框架落地(BEA:总量/价格/就业)
- 数据资产入表(SNA 2025:企业数据资本化)
- 选择实验方法成熟(大规模在线实验给免费品出价)

**未解决/深水区**:
- 免费品福利如何进官方序列(GDP-B 无国际标准),与 Beyond GDP 首脑指标议程合流
- 数据资产的估值与折旧(成本法 vs 收益法;数据不磨损但会过时)
- 平台多边市场的真实价格分解(广告主付费+用户免费)

## ✨ 这支最美的一个事实

**GDP-B 的零价格定价**:问用户"要付多少钱才愿一个月不用搜索引擎?"——
实验答案是每月数十美元量级(方向锚):"免费"服务的福利藏在 GDP 的零里。
GDP-B 用选择实验把零换回货币数,并发现传统 CPI 对数字品相对价格变动系统性
漏记——**不是经济没有增长,是仪表没有指针**。

## 假设与依赖

- **零价格≠零价值**:平台以注意力/数据为对价——"市场交易"的边界模糊处
- 选择实验外推假设:实验补偿≈真实福利(时间贴现/策略性应答是噪声源)
- 数据资产的成本法假设:价值≈生产成本(SNA 2025 务实选择,争议中)
