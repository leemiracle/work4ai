# 讲透国民经济核算 · GDP 的制造车间:SNA 账户体系

> **定位句**:这支负责"**总量测度的生产线**"——GDP 及其账户家族
> (生产/收入分配/资金流量/资产负债)怎么从千万笔交易拼成一本平的账。
> GB/T 13745 91030 经济统计学 · **自定主干支**。家族:[讲透经济统计学](../README.md)

## 诞生

- **谁/何时**:配第 1676《政治算术》立下"国家可计算"的预言;**Kuznets** 1934 年
  向美国会提交首份国民收入报告,**Stone** 1941 年为英国战时财政造出复式记账
  国民账户并主持 **SNA 1953**(后四次改版);两人分获 1971/1984 诺贝尔奖。
- **因什么问题**:①政府需知经济总量(战时动员/宏观调控);②国际可比
  (马歇尔计划要求 OEEC 各国统一报账);③凯恩斯宏观需要操作变量。

## 核心问题

**已解决**:
- 三面等值体系(生产/收入/支出互相钳制的自检结构)
- 不变价核算(双缩减法):真实增长与价格变化的分离
- 从流量到存量的全套账户(资金流量表→资产负债表;国际收支 BPM 同一屋檐)

**未解决/深水区**:
- 数据资产入表(SNA 2025 通过,各国实施与历史重订中)
- 全球化生产的归属(转口/无形资产跨境/跨国公司内部定价)
- 福利与可持续卫星账户的标准化(Beyond GDP 议程)

## ✨ 这支最美的一个事实

**四式记账**:你买电脑的一笔交易,在买方记两格(资产+、存款−)、
卖方记两格(存货−、存款+)——**任何一方漏记,另一方的账立刻凸出来**。
15 世纪威尼斯商人防奸商的技术,升级成国家级数据质量的防伪水印:
全球 ~200 个经济体因此能互相记账、互相核对。

## 假设与依赖

- **生产边界**(市场交易+少量自给)决定表盘视野——家务/志愿/免费品出局(家族 README §五)
- **市场价格=福利代理**:政府/国防产出无市价,以投入成本代理——效率越高读数越低的悖论
- **常住单位**口径决定"谁的 GDP":领土原则 vs 归属原则的裂缝被全球化撕大
