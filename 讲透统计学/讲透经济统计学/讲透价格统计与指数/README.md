# 讲透价格统计与指数 · 价格变化的提纯术:CPI/PPI/PPP

> **定位句**:这支负责"**把『贵了』提纯出来**"——观测到的价格变动里混着
> 质量变化、替代行为、渠道迁移;指数理论是把"纯价格运动"分离出来的整套装置。
> GB/T 13745 91030 经济统计学 · **自定主干支**。家族:[讲透经济统计学](../README.md)

## 诞生

- **谁/何时**:Lowe 1822 首个固定篮子指数;**Laspeyres 1871**(基期权数)与
  **Paasche 1874**(当期权数)对峙;**Fisher 1922**《指数的编制》把指数变成
  公理学对象("理想指数");**Konüs 1924** 证明拉氏/帕氏是真生活成本指数的上/下界;
  **Boskin 委员会 1996** 断言美国 CPI 年高估约 1.1 个百分点,推动链式 CPI 落地。
- **因什么问题**:①通胀的货币契约化(工资/租金/国债挂钩指数——公式选择变成法律问题);②生活成本的经济学定义;③PPP 需要全球同一套价格语法。

## 核心问题

**已解决**:
- Konüs 包络:拉氏 ≥ 真生活成本 ≥ 帕氏(替代方向的定理化)
- 公理检验体系:时间反演/因子反演/传递性/一致性(Fisher 传统)
- ICP 全球比价与季节性衔接(链式与年距指数的工程化)

**未解决/深水区**:
- hedonic 的哲学边界(可观测特征之外的质量——新药延寿值多少降价?)
- 新品偏倚(新品入篮滞后多年,早期降价记录不到)
- 零价格/免费品(→[../讲透数字经济测度/](../讲透数字经济测度/))

## ✨ 这支最美的一个事实

**Konüs 包络**:只要消费者理性替代,拉氏(旧篮子)必然高估、
帕氏(新篮子)必然低估真生活成本——**两个"有偏"的指数恰好把真值夹在中间**。
你永远算不出真值,却永远知道它的区间;几何平均(费雪)成为标准调和。
亲历:家族 `experiments/00_chain_index.py` 实拍帕氏 ≤ 费雪 ≤ 拉氏的序。

## 假设与依赖

- **代表性消费者**(效用函数存在且稳定)——Konüs 界的前提;横截面异质性使"一个 CPI"先天有争议
- **采价规格同质**:规格品必须"同一东西",质量漂移由 hedonic 兜底
- **质量可观测**:hedonic 只能调整"列得出特征"的质量——体验类质量先天漏网
