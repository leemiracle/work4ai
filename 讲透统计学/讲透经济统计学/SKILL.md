# 经济统计学思维技能卡(讲透经济统计学 · GB/T 91030)

## ① 何时用此分支(触发特征,一眼对号)

- 你在处理 **GDP/GNI/国民账户/资金流量/国际收支** 数据
- 出现 **CPI/PPI/平减指数/通胀率/生活成本/指数化合同**(通胀挂钩租金/养老金)
- 要做**不变价换算、实际 vs 名义增速、基期换算、PPP 跨国比较**
- 指标数据来自 **FRED/世行/Eurostat/国家统计局**,要建管道或仪表盘
- 你在争论"GDP 该不该算 X""免费 App 算不算产出""GDP 高估还是低估了增长"
- 要做**季节调整**、比较**同比 vs 环比**、或解释**数据修订**

*不是这里*:从数据估计模型/检验理论→计量经济学(../../讲透经济学/);
抽样误差/推断方法→../../讲透数学/讲透数理统计/。

## ② 核心思维模式(这个家族怎么想问题)

1. **构造先于推断**:数字不是给定的,是被生产出来的——先问生产线
   (调查/行政数据/口径),再问置信区间
2. **恒等式不是理论**:三面等值/储蓄≡投资是记账定义,永真;
   事前均衡才是经济学假设——两套命题永不相混
3. **口径即镜头**:公式选择(固定 vs 链式权重)、质量调整(hedonic 有无)、
   SNA 版本(2008 vs 2025)各自改写读数;数字对不上的第一嫌疑人永远是口径
4. **边界意识**:生产边界决定什么被看见——家务/志愿/免费品/环境在表盘外;
   卫星账户是扩视野的正式渠道
5. **数字有版本号**:GDP 初值至少三修,季调历史会回漂——
   用数据先锁 vintage,防前视偏差

## ③ 工具箱(方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 三面等值核对 | 验证国民账户数据质量;定位薄弱环节 |
| 拉氏/帕氏/费雪指数 | 任何价格或数量比较;Fisher 过公理检验最多 |
| 链式指数 | 长时段比较/权重大幅漂移;牺牲传递性换及时性 |
| 几何平均(Jevons) | 类内价格聚合——一步修正 ~0.2-0.3 pp/年替代偏差 |
| hedonic 回归 | 质量变化剧烈的商品(IT/新车);ln(price)~特征 |
| 双缩减法 | 名义增加值→不变价(产出与投入分别平减) |
| PPP/ICP 因子 | 跨国水平比较(勿用市场汇率比生活成本) |
| X-13 三步法(移动平均) | 季节调整;先摘离群值再估季节因子 |
| 卫星账户框架 | 新现象(数字/环境/旅游)不动主表另立账 |
| vintage 存档 | 回测与管道;只用"当时可见"的初值 |

## ④ 常见误区与禁忌

- **把 GDP 当福利读**:GDP 量的不是幸福——不计家务/志愿/环境,
  却计军火;灾难重建会推高它
- **名义当实际**:跨年比较必须平减;基期不同年的"实际值"不可直接比
- **市场汇率比生活水平**:汇率被资本流动主导,水平比较必须 PPP
- **固定权重算长时段通胀**:替代偏差系统性高估(实拍见
  `experiments/00_chain_index.py`,十年可漂移 27 点)
- **混季调与非季调序列**:join 前必查 seasonal_adjusted 字段
- **忽略修订**:用最终值回测"当时"的决策=前视偏差
- **口径切换当真实增长**:SNA 改版/R&D 资本化/SNA 2025 数据入资产
  都会一次性抬高 GDP 水平——跨年序列要看脚注
