# 讲透经济统计学 · 家族总纲(给市场经济装仪表盘的家族)

> **本质一句话**:经济统计学=给市场经济装上仪表盘——GDP、CPI、失业率不是世界上
> "天然存在的数",而是本家族**设计并制造**的仪表;仪表怎么造、读数准不准、
> 表盘之外还有什么没量到,全是本家族的领地。
>
> GB/T 13745-2009:910 统计学 · 二级学科 **91030 经济统计学**(GB/T 未列三级 → 本家族自定主干支)。

**定位张力声明**(先读这个再读本家族):经济统计学夹在两门大学科之间——
数理统计(../../讲透数学/讲透数理统计/)给它**推断工具**(抽样/估计/时序),
经济学(../../讲透经济学/)给它**测度对象**(什么是"生产"、什么是"价格")。
本家族自己独有的东西是**测度的构造术**:把一个模糊的经济概念(生活水平、总产出)
变成一个可生产、可复核、全球可比的数字。推断住数学宇宙,解释住经济学宇宙,
**造仪表住这里**。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透经济统计学/
├── 讲透国民经济核算/    🆓 自定主干支——SNA 国民账户:GDP 的制造车间(生产边界/三面等值/不变价)
├── 讲透价格统计与指数/  🆓 自定主干支——CPI/PPI/PPP:把"价格变化"从"数量与质量变化"里提纯
└── 讲透数字经济测度/    🆓 自定主干支——GDP 量不到的新大陆:免费数字品/数据资产/平台经济
```

> 三支的共同血统:**一个概念定义 × 一套生产管线 × 一份全球标准**。
> 核算支是骨架(账户体系),指数支是标尺(价格测量),数字经济支是前沿(边界扩张)。
