# 科学技术统计学思维技能卡(讲透科学技术统计学 · GB/T 91035)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **投入类**:R&D 经费、研发强度、GERD/BERD/HERD、FTE 研究人员、基础研究占比、科技统计年鉴、GBAORD
- **口径类**:Frascati 手册、OECD 口径、MSTI、S&E Indicators、研发资本化、R&D 入 GDP
- **产出类**:论文数、专利统计、被引量、影响因子、JCR、FWCI/学科归一化、期刊排序
- **网络类**:引文网络、共被引、文献耦合、科学地图、睡美人论文、科学计量学
- **分布类**:Lotka 定律、科研生产力幂律、普赖斯定律、15 年翻倍、马太效应/累积优势
- **评价类**:h 指数、科研考核、绩效评价、大学排名、DORA、莱顿宣言、负责任评价
- **新指标类**:CD 指数/颠覆性、altmetrics、开放科学指标、数据共享率、卓越指标

## ② 核心思维模式(这个分支怎么想问题)

1. **口径先行**:任何数字先问定义域——什么算 R&D?什么算一篇论文?哪个手册哪一版?
2. **代理链意识**:投入代理产出、引用代理影响——每环失真单独记账,链条越长越可疑
3. **可比性设计**:跨国跨时比较要校汇率/PPP、口径断点、学科结构;排名必须附敏感性
4. **分布先于均值**:引用与产出是幂律,均值被头部绑架——报中位数与百分位
5. **反身性警觉(古德哈特)**:指标变 KPI 即变形;评价设计=制度设计,不是算术

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| Frascati 五判据(新颖/创造/不确定/系统/可转移) | 裁决一个活动算不算 R&D |
| GERD/BERD/HERD/GOVERD + 强度(GERD/GDP) | 国家/部门投入四件套与国际对比 |
| Lotka 幂律 / Price 增长 / 累积优势(Simon-Price urn) | 产出分布与增长的基准模型;判"多产者恒少"与翻倍减速 |
| 对数-线性回归→翻倍期;对数-对数回归→幂律斜率 | 增长与分布拟合的最小标准库实现 |
| 影响因子 / h 指数 / 归一化被引(FWCI) | 各期刊/个体/领域指标的正确用途与失效条件(IF≠个体命运) |
| CD 指数(Funk–Owen-Smith 2017) | 颠覆性测度;引用惯例敏感,结论附效度声明 |
| 共被引/文献耦合/科学地图 | 领域结构分析与综述冷启动 |
| 莱顿十条 / DORA / 负责任使用原则 | 设计或审计科研评价制度时的元规则 |
| OECD/JRC 复合指标构造流程(权重敏感性+不确定性分析) | 造任何"一个数"的排名/指数之前 |
| 文献库 API 管道(Crossref/OpenAlex/S2:分页/退避/缓存/DOI 对齐) | 批量采集与实体链接 |

## ④ 常见误区与禁忌

- **拿期刊 IF 评个人**:期刊均值≠论文被引,幂律下多数论文低于刊均(Seglen)
- **用投入论产出**:经费高≠产出好——"加油量"与"里程"必须分帐
- **跨学科直接比被引**:引用文化差异(数学 vs 生物医学可差一个量级),先归一化
- **接断点时间序列**:口径修订(Frascati 换版/换库/换分类)后硬接历史序列=造假
- **把排名当真理**:权重微调首尾互换;复合指标的权重是价值判断
- **指标当 KPI 后忘了变形**:篇数考核→拆篇灌水;古德哈特税迟早要缴
- **无视文献库覆盖偏差**:英语/商业库≠科学全体;预印本、数据集、软件在帐外
- **对幂律数据只报均值**:被引分布报均值是误导的标准形态
