# 讲透R&D统计与科技指标 · 投入侧:Frascati 口径与 GERD 四件套

> **定位句**:这支负责"**钱和人怎么数**"——R&D 经费、研究人员、政府预算、
> 强度与国际对比;一切科技政策的定量对话都从这支的口径出发。
> GB/T 13745 910 统计学 · 91035 科学技术统计学 · **自定主干支**(GB/T 未列三级,家族自定)。家族:[讲透科学技术统计学](../README.md)

## 诞生

- **谁/何时**:史前是 **Bush《Science, the Endless Frontier》(1945)**——战时科研的胜利
  说服美国设立 NSF,国家资助科研需要国家统计科研;**OECD 专家会议(1963,罗马近郊
  Frascati 镇)**敲定《研究与试验发展调查的标准实践建议》(Frascati 手册首版),
  后由 NESTI 工作组迭代至 2015 年第七版。
- **因什么问题**:①"各国花了多少钱搞研究,怎么比"(战后科技竞赛的记帐需求)
  ②"什么算研究、什么不算"(边界判例)③"研究投入如何进经济核算"(SNA 2008/资本化)。

## 核心问题

**已解决**:
- R&D 的国际口径:五判据+三分法(基础研究/应用研究/试验发展)+部门分类,全球可比
- 投入四件套:GERD(总量)/BERD(企业)/HERD(高校)/GOVERD(政府)+GBAORD(政府预算)
- 强度指标 GERD/GDP 成为国家创新竞赛的标准记分牌
- R&D 资本化入 GDP(SNA 2008;BEA 2013 起、我国 2016 年起核算改革)

**未解决/深水区**:
- 基础研究占比的政策解读(占比低=短视,还是结构合理?)
- 跨国企业 R&D 的归属地拆分(在哪记账:总部还是实验室?)
- 知识资产的折旧率(R&D 资本化的核算参数,各国不一)
- 政府预算口径(GBAORD)与实际支出(GERD)之间的时滞与偏离

## ✨ 这支最美的一个事实

**一个意大利小镇的名字成了全球实验室的通用语**——"Frascati 口径"让
"研究"这个各说各话的词第一次变成可以跨国相加的数字;
手册迭代七版,每一版都是一场定义谈判:口径学即外交学。

## 假设与依赖

- 三分法(基础/应用/试验发展)可由专家稳定判定——边界判例支撑,主观性未根除
- 投入=资源的代理:经费与人年是"加油量",不承诺"里程"
- FTE 折算(工时→人年)假设工时可跨项目、跨国可比地分摊
