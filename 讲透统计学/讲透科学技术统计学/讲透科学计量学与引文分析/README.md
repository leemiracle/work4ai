# 讲透科学计量学与引文分析 · 产出侧:文献、引文与科学地图

> **定位句**:这支负责"**文怎么数**"——论文、专利、期刊与它们织成的引文网络;
> 从 Lotka 的姓氏名单到开放图谱,科学结构的显微镜装在这支。
> GB/T 13745 910 统计学 · 91035 科学技术统计学 · **自定主干支**(GB/T 未列三级,家族自定)。家族:[讲透科学技术统计学](../README.md)

## 诞生

- **谁/何时**:**Lotka(1926)**从《化学文摘》A-B 姓氏名单发现产出逆幂律(1/n²);
  **Price(1963)《Little Science, Big Science》**确立指数增长定律并奠基科学计量学,
  又在 1976 年提出"累积优势过程"(优选依附先于网络科学 23 年);
  **Garfield** 1955 年在《Science》鼓吹引文索引,1964 年建成 SCI——
  法律界 Shepard's 引证索引(1873)的灵感变成科学界的基础设施。
- **因什么问题**:①"科学长多快、长得什么形状"(增长与分布)
  ②"怎么顺着引用找到相关论文"(检索)③"学科结构能不能算出来"(共被引科学地图)。

## 核心问题

**已解决**:
- 三条经验规律:指数增长(Price)、逆幂律产出(Lotka)、累积优势机制(Simon/Price)
- 引文索引与期刊指标:SCI/JCR、影响因子、共被引与文献耦合聚类
- 科学地图:引文网自动浮现学科结构与前沿(Small & Griffith 1974 共被引分析)
- 睡美人现象(早发晚醒)的识别与统计刻画(van Raan 2004)

**未解决/深水区**:
- 引用动机不可分(礼貌/负面/定义性引用在数据里同形)——效度的天花板
- 长时窗影响测度(引用窗口多长才公平?学科差异如何归一)
- 引文与"实际使用"的分离(专利引用、临床指南引用、软件复用各居异籍)
- 开放图谱时代的实体链接:作者消歧与机构归属(红色区,无金标准)

## ✨ 这支最美的一个事实

**Garfield 的一张网重构了科学地图**:引文数据为检索而生,
连成图做共被引聚类后,学科边界与流派前沿自动浮现——
**地图不是画出来的,是算出来的**;副产品比主产品更伟大。

- 出版=产出(不发表的劳动在帐外——"文件抽屉问题"是本支的影子)
