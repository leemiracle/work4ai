# 讲透科研评价与开放科学指标 · 使用侧:h 指数、负责任评价与开放计量

> **定位句**:这支负责"**数怎么用**"——个体/机构/国家的科研绩效评价,
> 指标滥用与改革(DORA/莱顿),以及开放科学时代的新计量对象;
> 本家族的古德哈特主战场。
> GB/T 13745 910 统计学 · 91035 科学技术统计学 · **自定主干支**(GB/T 未列三级,家族自定)。家族:[讲透科学技术统计学](../README.md)

## 诞生

- **谁/何时**:**Garfield(1972,JCR 公开化)**——影响因子本为选刊工具,
  被机构挪用为评价尺,一部异化史由此开演;**Hirsch(2005,PNAS)**用 h 指数
  把个体评价压缩成一个数,评价研究就此爆发;**DORA(2012,旧金山)**
  宣告"不用期刊指标评个人";**Hicks 等《莱顿宣言》(Nature 2015)**十条原则
  给出量化评价的元规范;**UNESCO《开放科学建议书》(2021)**把"开放行为"
  本身变成统计对象。
- **因什么问题**:①"凭什么给你钱/升你职"(资源分配的合法性)
  ②"指标被玩坏了怎么办"(古德哈特与评价改革)③"开放科学怎么计量"(新口径工地)。

## 核心问题

**已解决**:
- 三层指标工具箱:个体(h 指数及变体)/期刊(IF、SJR)/机构与国家(归一化被引、卓越浓度)
- 负责任评价的元规范:莱顿十条+DORA 原则(评价制度的"宪法层")
- 复合指标构造的正道流程(OECD/JRC 手册:权重敏感性+不确定性分析)

**未解决/深水区**:
- 质量 vs 数量:卓越指标(高被引浓度)仍只是质量的价格,不是质量本身
- 开放科学指标:预注册/数据共享/开放评审尚无 Frascati 级国际口径(UNESCO 2021 后的工地)
- 评价的反身性治理:怎么设计"不被玩坏"的考核——制度设计与统计设计的接缝
- altmetrics 效度:使用计量(下载/提及/政策引用)与学术影响的关系仍待证据

## ✨ 这支最美的一个事实

**h 指数一发不可收**:Hirsch 2005 的定义三行——"有 h 篇论文各被引至少 h 次"——
一个数同时封顶数量与质量;随后十余年上百个变体(g、m 商、i10…)被提出、
比较、推翻,**评价研究本身成了幂律产出最干净的样本**:
指标的自反性从警告变成了活体实验。

## 假设与依赖

- 可比=公平(跨领域/跨职业阶段直接比,忽略结构与生命周期差异)
- 单一数字可压缩多维绩效(排名的传播溢价与失真同源)
- 指标使用方式可以被制度约束(DORA/莱顿的乐观假设——落地仍在途中)
- 依赖上游两支:投入帐([讲透R&D统计与科技指标](../讲透R&D统计与科技指标/))、
  产出指标([讲透科学计量学与引文分析](../讲透科学计量学与引文分析/))
