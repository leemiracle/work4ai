## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透科学技术统计学/
├── 讲透R&D统计与科技指标/      🆓 自定主干支——投入侧:钱怎么数(Frascati 口径、GERD/BERD、MSTI 双支柱)
├── 讲透科学计量学与引文分析/   🆓 自定主干支——产出侧:文怎么数(Price 指数增长、Lotka 幂律、Garfield 引文网)
└── 讲透科研评价与开放科学指标/ 🆓 自定主干支——使用侧:数怎么用(h 指数、DORA/莱顿宣言、开放科学与 altmetrics)
```

> 三支的共同血统:**一切科技统计 = 口径(定义)× 代理(以可测代不可测)× 可比(跨时跨国)**。
> 投入侧记帐、产出侧读帐、使用侧审计——一个完整的会计循环。
> 三支合起来回答一个大问题:**科学这台机器,值不值、转得快不快、出不出活。**
