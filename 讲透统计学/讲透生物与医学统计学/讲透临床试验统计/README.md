# 讲透临床试验统计 · RCT:用随机化把因果解释买到手

> **定位句:这支负责「证明疗效」——从样本量到入场券,随机对照试验的设计、监测与分析的全流程统计。**

> 家族:[讲透生物与医学统计学](../README.md)

## 诞生

- **谁/何时**:1747 Lind 坏血病试验(同期对照的鼻祖)→ 1935 Fisher《试验设计》
  (随机化/重复/区组,洛桑试验田直系)→ **1948 MRC 链霉素试验**(Hill):
  第一例现代 RCT(随机+双盲+安慰剂)→ 1960s 序贯试验(Armitage)与伦理学一起成军
  (《赫尔辛基宣言》1964)→ 1970s-80s group sequential(Pocock/O'Brien–Fleming)
  与生存终点(logrank/Cox)进临床 → 2020s 主方案/平台试验与自适应设计成典(ICH E20)
- **因什么问题**:①「疗效是真的吗」(随机化买因果)②「几条命换一个答案」
  (样本量与期中伦理)③「能不能少花病人多回答问题」(平台与信息借用)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 随机化/盲法/区组的理论;样本量与功效(logrank 事件数公式);alpha 消耗与期中边界;生存终点的分析标准件;多重性的层级(HM/门控/图形法) |
| ✅ 已解决 | ITT 与随机化的法理关系(按分组分析保因果解释) |
| 🔄 进行中 | 主方案(平台/篮子/伞式)的共享对照与平台级 alpha 记账(01 章战线 1——检索校准 2026-09-07:Kaizer 2023 综述);贝叶斯信息借用的度(ICH E20/FDA) |
| ❓ 未解决 | 个体化治疗效应(HTE)的识别;复合终点与替代终点的解释;富集设计的富集边界 |

**最美事实(一句)**:随机化把一切未知混杂(包括还没被科学发现的)的期望一次性归零——
用一粒骰子给「无知」上了全险,不看数据就赢了一半。
