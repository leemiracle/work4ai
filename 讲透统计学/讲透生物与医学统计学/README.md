# 讲透生物与医学统计学 · 在生死数据上做推断——临床试验、流行病与组学的统计引擎

> **本质一句话**:生物与医学统计=在生死数据上做推断——
> 每个数据点背后是活人,结论错一寸、代价以人命计价,于是这门手艺把「推断的纪律」
> 锻造成**伦理、法规与算法的三层铠甲**:随机化买因果、删失语法保信息、多重检验守发现。
>
> GB/T 13745-2009:910 统计学 · 二级学科 **91060 生物与医学统计学**(GB/T 未列三级 → 本家族自定主干支)。
> **GB/T 注明:医学统计学(31057)· 卫生统计学(33072)归入本学科**——承接声明见 §三。
>
> **定位张力声明**(先读这个再读本家族):推断的数学本体住数学宇宙的数理统计(11067),
> 工程存活与可靠性住应用统计数学(11071),疾病的临床与公共卫生描述住医学各科。
> 本家族不重复建设这些地盘,只详答生医统计自己独有的三件事:
> **怎么在不能随意做实验的人身上证明因果**(临床试验统计)、
> **怎么在没做试验的观察人群里逼近因果**(流行病统计)、
> **怎么在百万变量对几十个样本的基因组上守住发现纪律**(组学与生物信息统计)。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透生物与医学统计学/
├── 讲透临床试验统计/        🆓 自定主干支——RCT:用随机化把因果解释买到手的全部手艺
├── 讲透流行病统计/          🆓 自定主干支——观察人群里的病因逼近(33072 卫生统计承接)
└── 讲透组学与生物信息统计/  🆓 自定主干支——p≫n 世界的发现纪律:FDR 与经验贝叶斯
```

> 三支的共同血统:**结局带生死权重**(效应量差一点,讣告多几页)+ **数据天生带伤**
> (删失/混杂/高维,没有一种生医数据是干净的 iid)+ **每个结论都要过伦理与法规的审**
> (别的统计分支错结论丢面子,这里错结论丢执业资格)。
> 同波兄弟家族(统计学史 91010/经济统计 91030/科技统计 91035/社会统计 91040/
> 人口统计 91045/环境统计 91050)见 [../README.md](../README.md) 全景表,此处仅文字提及不互链。
