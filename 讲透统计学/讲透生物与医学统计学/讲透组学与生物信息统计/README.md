## 诞生

- **谁/何时**:1995-2001 微阵列与人类基因组计划把「一次测一个基因」变成
  「一次测全部基因」——p 从 1 跳到 10⁴,样本量仍是几十 → **1995 Benjamini–Hochberg**
  FDR 准则恰好先于组学十年备好(发现纪律的法定出口)→ 2001-2010 Efron
  经验贝叶斯/大规模推断:相关结构下重估 null、shrinkage 借方差 →
  limma(2004-)/DESeq2(2014-):线性模型+经验先验成为差异表达标准管线 → 2015- 单细胞/空间/多模态:p 变成「每细胞两万基因×百万细胞×多层」
- **因什么问题**:①「两万次检验里 p<0.05 的有上千个,哪些是真的」②「每个基因只有几个重复,方差估不准」→全库借力 ③「今天的发现明天复现不出来」→null 重估与管线冻结

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | BH 在独立/正相关 p 值下 FDR≤q;qvalue 的 π₀ 估计;limma 线性模型+经验贝叶斯收缩(小重复方差问题的工业解) |
| ✅ 已解决 | 对照设计(配对/区组)与批次效应校正(combat 类)的分析框架 |
| 🔄 进行中 | 组学高维统计纵深:单细胞多模态整合、空间统计、结构化检验(基因集/通路的组合检验)——**方向锚,时效声明见家族 01 章战线 4**(检索校准 2026-09-07) |
| ❓ 未解决 | 高维多重检验的全能解:任意相依结构下同时「稳+不亏功效」的校正不存在共识;发现集的可复制性(跨队列/跨平台的组合证据) |

**最美事实(一句)**:BH 一行阈值 p₍ₖ₎≤(k/m)·q 把「发现集里错误的比例」
变成可控量——组学时代「发现」一词从形容词变回名词,靠的是这条不等式。

## 假设与依赖

- 检验间独立或正相关(BH 的稳健域;负相关会让 FDR 超标——组学多为正相关,幸运)
- null 的正确建模(理论 null 不可靠时经验重估——Efron 的核心警告)
- 重复的结构:生物学重复 vs 技术重复不可互换(样本量按前者计)
