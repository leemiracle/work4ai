# 生物与医学统计思维技能卡(讲透生物与医学统计学家族 · GB/T 91060)

## ① 何时用此分支(触发特征,一眼对号)

- 你在做**临床试验**:样本量、随机化、盲法、期中分析、提前终止、CONSORT
- 出现**生存数据**:KM 曲线、中位生存、删失/失访、logrank、Cox、HR、风险函数
- 你在做**流行病统计**:RR/OR/SMR、人年、标准化、队列/病例对照、偏倚与混杂
- 面对**组学高维数据**:差异表达、几万~百万个检验同时做、FDR/qvalue/火山图
- 有人拿**真实世界证据**(电子病历/医保/登记库)要下**因果**结论
- 医学测量问题:诊断试验(敏感度/特异度/ROC)、替代终点、HTE(谁真正受益)

*不是这里*:推断方法本体→数理统计;可靠性/失效率(工程)→应用统计数学;
疾病的临床决策面→临床医学;数据生成后纯预测不问推断→统计学习。

## ② 核心思维模式

1. **随机化=因果的门票**:分组怎么来的决定一切——随机化把未知混杂一次付清;
   非随机的比较都要过混杂安检(目标试验仿真)
2. **删失是语法不是损失**:数据单元=(T,δ)「至少/恰好」;失访者贡献区间信息,
   当缺失删掉就系统性偏倚
3. **风险以幸存者为分母**:HR 是瞬时死亡速度之比,不是生存概率之比;
   比例风险假设塌了,一个 HR 就是不存在的平均
4. **每个假设都在换伦理或因果**:随机化买因果付伦理;ITT 保因果付保守;
   借历史信息省病人付先验风险——没有免费的推断
5. **显著性要付税**:偷看数据/多终点/多臂/多基因,每次多看一眼都要记
   alpha 账本;早期停止条件性地高估疗效(winner's curse)
6. **结论强度=链路最弱一环**:数据怎么来(GCP)、分析预注册没(SAP)、
   报告全不全(CONSORT)——p 值只是链条末端

## ③ 工具箱(方法名 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| Kaplan–Meier | 生存数据的非参数估计:阶梯曲线+中位生存,零分布假设 |
| logrank(含分层/加权) | 两组(或多组)生存比较的标准件;事件驱动 |
| Cox 比例风险模型 | 要调协变量的生存比较;不指定基线风险;先验 PH 检验(Schoenfeld) |
| 竞争风险 CIF | 有多种死因时,别把「死于别因」当独立删失 |
| Schoenfeld 公式 | 事件数 d=4(z_{α/2}+z_β)²/(ln HR)²——试验设计的第一笔账 |
| alpha 消耗(O'Brien–Fleming/Pocock) | 期中分析/序贯设计的显著性预算 |
| 随机化检验/置换检验 | 小样本/罕见事件/分布可疑:洗牌标签让无效应世界现身 |
| RR/OR/Mantel–Haenszel | 流行病测量与分层合并;罕见病 OR≈RR |
| 直接/间接标准化(SMR) | 跨人群比率先换共同人口结构(防 Simpson/构成效应) |
| BH-FDR/qvalue | 高维多重检验(组学/多终点监控):控制发现集错误比例 |
| 目标试验仿真(七要素+克隆-删失-加权) | 观察数据要下因果结论的纪律化管线 |
| E-value/敏感性分析 | RWE 申报「多强的未测混杂才能翻案」 |
| ITT 分析 | 随机化试验的主分析:按分组分析,不管依从——保因果的诚实语法 |

## ④ 常见误区与禁忌

- **p<0.05≠有效**:效应量+临床结局换算才是完整答案;HR 是速度比不是概率比
- **删失≠缺失**:剔除失访者的「完整案例分析」是系统性偏倚的温床
- **偷看数据不付税**:反复期中分析+择机停止=I 类错误膨胀+效应高估;
   必须预设 alpha 消耗
- **聚合数据会撒谎**:分层翻盘(Simpson/肾结石案);比率先问「分谁头上」
- **观察数据的相关不能直译因果**:先写目标试验协议,再谈结论强度
- **CONSORT 流程图不是装饰**:随机化的人流向哪,是审计的核心账目
- **按治疗后特征重分组=作废随机化**:ITT 的语法决定就是为了焊死这条暗道
- **组学 p 值不校正=假发现工厂**:几万检验里 p<0.05 的零假设基因就有几百个
   (实测见 [../../讲透数学/讲透数理统计/experiments/00_fdr.py](../../讲透数学/讲透数理统计/experiments/00_fdr.py))
- **替代终点≠临床结局**:降了血压不等于少了卒中;桥的断裂要生物学证据
