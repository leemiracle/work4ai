## 诞生

- **谁/何时**:1854 Snow 宽街水泵(霍乱自然实验,统计地图学的开端)→
  **1950 Doll & Hill 吸烟与肺癌病例对照**(罕见病病因的成本革命)→
  1951 英国医生队列研究(随访五十年钉死因果链)→ 1959 Mantel–Haenszel 分层合并 →
  Rothman/Greenland 现代流行病方法学(偏倚分类学)→ 2010s Hernán 等**目标试验仿真**
- **因什么问题**:①「伦理上不能随机化的暴露(吸烟/职业毒物)怎么研究」
  ②「率不可直接比」(人口结构/随访起点都在捣乱)③「观察比试验低几等」——仿真的回答:低多少取决于模仿得像不像

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | RR/OR/SMR/人年的测量语言;直接/间接标准化(防 Simpson/构成效应);Mantel–Haenszel 分层合并;病例对照的统计理论(发病密度抽样下 OR 精确=RR) |
| ✅ 已解决 | 偏倚三分法(混杂/选择/信息)与混杂的可判定条件 |
| 🔄 进行中 | 目标试验仿真进临床主流(检索校准 2026-09-07:JAMA 2023 特讯;PMC 12077415 因果推断 1986-2024 文献计量) |
| ❓ 未解决 | 真实世界证据的因果强度上限(未测混杂不可排除,只能敏感性分析申报);生态谬误的自动检测 |

**最美事实(一句)**:病例对照设计用「得病的人往回看」,把罕见病病因研究的成本
从「追踪几十万人几十年」压到「几百对病例与对照」——统计设计的红利第一次以研究可行性的形式兑现。

## 假设与依赖

- 可交换性(无未测混杂)/无测量误差(或误差方向已知)/选择机制的透明
- 病例对照的对照必须「代表产生病例的人群」(源队列)——抽样设计的合法性枢轴
- 硬依赖:标准化与合并的代数承 [数理统计](../../../讲透数学/讲透数理统计/README.md);
  逆概率加权承 [讲透抽样理论](../../../讲透数学/讲透数理统计/讲透抽样理论/README.md)
