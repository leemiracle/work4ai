# 环境与生态统计思维技能卡(讲透环境与生态统计学家族 · GB/T 91050)

## ① 何时用此分支(触发特征,一眼对号)

- 你在做**环境监测**:站点布设、传感器网络、QA/QC、缺测插补、AQI/水质指数
- 面对**气候变化统计**:趋势检测、变点、"变暖暂停"、极端事件归因、概率句
- 在算**生态指标**:多样性指数(Shannon/Simpson)、占有-检测模型、生物多样性监测、红名单
- 在做**碳核算/环境核算**:排放清单(活动×因子)、MRV、SEEA 资产账户、SDG 环境指标
- 处理**时空数据**:站点→格点插值、卫星像元×地面验证、再分析数据集的版本修订
- 要解释**"N 年一遇"**、检出限下的 0、"未检出"与"不存在"的区别

*不是这里*:分布与推断的数学本体→数理统计;插值与克里金的数学→空间统计支;
disease-response 流行病统计→生物与医学统计;SNA 生产账户→经济统计学。

## ② 核心思维模式

1. **三道工序**:监测(采血)→检测归因(看化验单)→指标入账(开健康档案)——任何环境数都生于其中一道
2. **每个数拖着"怎么测的"尾巴**:站怎么布/检出限多少/质量位几档/哪个数据集版本——先读尾巴再读数
3. **站点代表性是假设不是事实**:换站=换总体;插值图是期望场不是真实场(平滑抹峰)
4. **找过最大值的统计量要重新定价**:CUSUM/滑动 t 的显著性必须置换检验,不能直接查表
5. **趋势陈述必须声明窗口**:短窗趋势是自然变率发的随机礼物(变暖"暂停"幻觉)
6. **频率因果语法**:归因能说"这类事件风险翻倍",不能说"这场雨是人造的"
7. **没看见≠不在**:检测概率 p<1 时,占有模型先估 p 再估分布——承认看不见,才看得见
8. **预警原则与统计显著是两套语法**:不可逆损害面前,"未检出显著"≠"没问题"

## ④ 常见误区与禁忌

- **把 0 当真值**——"<检出限"是删失不是零;"没看见"是检测概率不是不在
- **直接比较再分析的不同版本**——版本升级会改写历史序列,对版本要先公告再比较
- **站点数当样本量**——时空强相关下有效样本量远小于名义量,显著性按 iid 算必然虚高
- **把 N 年一遇读成 N 年保证不遇**——百年内撞上"百年一遇"至少一次的概率≈63%
- **拿卫星像元当站点**——面-点支撑不同,验证是两种观测的统计比较不是"对答案"
- **归因句越界**——"风险至少翻倍"合法,"这场就是人造的"非法(频率因果的语法极限)
- **指标断点埋进代码**——AQI 断点/SDG 口径是决策数据,外置配置+版本号,立场要可审计
- **插值图无方差图**——克里金最优但抹峰,发布期望场必须配不确定性表达
