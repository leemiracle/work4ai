# 讲透环境监测统计 · 站点、采样与把环境算进账本

> **定位句:这支负责"环境的数怎么来、怎么变成质量数、怎么入账"——
> 从布点采样到 QA/QC,从 AQI 到 SEEA 资源环境核算,给地球采血的全部手艺都在本支领地上。**
> GB/T 13745-2009:910 统计学 · 91050 环境与生态统计学 · **自定主干支**(GB/T 未列三级,家族自定)。
> **GB/T 更名承接:资源统计(原名为自然资源统计)由本支资源环境核算内节承接。**
> 家族:[讲透环境与生态统计学](../README.md)

## 诞生

- **谁/何时**:1952 伦敦大雾(约 1.2 万人死)→1956 英国《清洁空气法》,浓度站点监测
  从科研爱好变成国家义务——"数字先于法案";1967 日本《公害对策基本法》(水俣病推动)
  把介质-链-人的全路径监测写进制度;1970 US EPA 成立后空气质量统计标准化;
  1993/2012/2021 联合国 SEEA(初版手册→中央框架→生态系统核算)把环境请进国民账户
- **因什么问题**:①"环境质量立法之前,先得测得出、比得了"(监测网络化)
  ②"测了不算等于白测"(指标化+入账:资源统计/自然资源核算由此汇入 SEEA)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 站网设计的分层/空间平衡抽样;AQI 族分段线性指数(多污染物→一个可比的数);SEEA 资产账户表式(期初+增−减=期末) |
| ✅ 已解决 | 检出限与删失数据的处理语法;"未检出"≠零(家族 02 章 §一) |
| 🔄 进行中 | 廉价传感器网络的漂移标定与双站交叉校准(04 章落点 1);指标口径的跨国统一(SDG 环境指标集群) |
| ❓ 未解决 | 站点代表性的量化外推(换站=换总体);稀疏区(远海/荒漠/深层)覆盖偏差的系统性订正 |

**最美事实(一句)**:1952 年之后,人类第一次为一个非人类对象建立了全国性的
例行体检制度——测什么、多密、多准,从此是可以立法谈判的统计问题。

## 假设与依赖

- 站点代表性假设:监测点代表周边环境场——城市站的选址是政治也是统计(家族 00 章 §五)
- iid 失效:时空强相关,有效样本量远小于站点数×天数

## 教材锚

- Chatfield《The Analysis of Time Series》(时间序列分析入门经典——监测序列的语法书)
- Gilbert《Statistical Methods for Environmental Pollution Monitoring》(污染监测统计的领域标准书:布点、删失、趋势)
- United Nations《SEEA Central Framework 2012》/《SEEA Ecosystem Accounting 2021》(环境核算的国际标准)
