# 讲透生态统计与生物多样性指标 · 群落、占有与给生态开账

> **定位句:这支负责"生命的世界怎么变成可比的数"——多样性指数、占有-检测模型、
> 生物多样性指标化与生态系统服务估值,把"物种少没少、生态值多少"从感叹变成数。**
> GB/T 13745-2009:910 统计学 · 91050 环境与生态统计学 · **自定主干支**(GB/T 未列三级,家族自定)。
> 家族:[讲透环境与生态统计学](../README.md)

## 诞生

- **谁/何时**:1921-1943 群落生态学的定量化(Gleason/Simpson 多样性测度起步);
  1948 Shannon 熵给出信息论版本的多样性;1967 Preston 种-面积曲线的统计形态学;
  2002-2006 MacKenzie 等建立占有-检测模型(检测概率 p<1 显式化,"没看见≠不在");
  2005 千年生态系统评估(MA)首试全球服务估值;2012 SEEA 中央框架+2021 SEEA
  生态系统核算(生态资产与服务正式入账);IPBES(2019/2024)把指标化推到全球政策桌
- **因什么问题**:①"一个群落多少种、多均匀、在收缩吗"(多样性测度与监测设计)
  ②"调查看不见的部份怎么办"(检测概率)③"生态对人类值多少、能不能入账"(服务估值与 SEEA EA)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 多样性指数体系(Shannon/Simpson/均匀度)与种-面积关系的测度理论;占有-检测模型(多次访问分离 p 与占有);红名单指数(RLI)的构造 |
| ✅ 已解决 | SEEA EA 三张表(范围/条件/服务)成为国际统计标准(2021) |
| 🔄 进行中 | 全自动监测(eDNA/声学/相机陷阱×AI)的统计语法——高分辨率揭示生物多样性下降(检索校准 2026-09-07,PMC 9828790);假阳性参数显式化 |
| ❓ 未解决 | **生物多样性 headline 单指标**(经济有 GDP,生态没有——各维度下降方向不一致,任何加权都是立场);**生态系统服务估值的方法收敛**(三条估值路线结果差数量级,货币化层仍是"实验性账户") |

**最美事实(一句)**:占有-检测模型用"有-无-有"的访问模式把"看不见"本身变成
可估的参数——承认看不见,才看得见;这是统计学对生态调查谦逊的一次方法学纠偏。

## 假设与依赖

- 封闭总体假设(占有模型在调查季内物种不迁移——开 Population closure 违反时模型失真);
  检测概率在访问间独立(现实中调查员会学习/疲劳)
- 实物量可测、价值化悬置:公顷/吨/人次可入账,货币化是带价值判断的可选层(家族 03 章 §四)

  多层模型的数学承自 [../../../讲透数学/讲透数理统计/](../../../讲透数学/讲透数理统计/README.md);
