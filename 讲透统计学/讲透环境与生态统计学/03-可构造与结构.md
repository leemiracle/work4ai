# 03 · 可构造与结构:指数怎么搭、变点怎么算、账本怎么配平

> **本章回答五问之四:这个分支的对象哪些是可构造的——能一步步手工造出来?
> 背后靠什么结构引擎?**
> **本质一句话**:环境与生态统计的大部分"名牌数"都是**构造物**——
> AQI 是构造、多样性指数是构造、变点统计量是构造、SEEA 账本是构造;
> 两大引擎撑着全部构造:**加性分解**(把信号拆成趋势+季节+变率再各归各处理)
> 与**层级结构**(个体→站点→区域→全球的嵌套)。

---

## 开篇:所有名牌数都是你自己搭出来的

数理统计给你的是估计量的性质(无偏、有效、相合)——那是语法学。
环境与生态统计的日常是**造词法**:把仪器读数、物种名录、排放活动数据,
一步一步搭成一个能上报纸、进条约、入账本的名牌数。

这一章把三个名牌(AQI、Shannon 指数、CUSUM)的**构造流水线**全部拆开,
你会发现它们没有魔法:每一步都是初等运算,难的不是算,是**每一步都是一个决定**。

## 一、指数的可构造性(三个名牌的流水线全拆)

### 构造 1:AQI——分段线性 + 取最大

输入:各污染物 24h 均值/P98 等统计量。构造五步:

1. 每种污染物浓度 c → 按该污染物的**分段线性映射**变成分指数 I(c)
   (断点表是官方定的,如 PM2.5 的 0-35-75-115 对应 0-50-100-150)
2. 段内线性插值:I(c) = (I_hi−I_lo)/(c_hi−c_lo) × (c−c_lo) + I_lo
3. 取各污染物分指数的**最大值**为 AQI(木桶原理:最差的说话)
4. 主导污染物 = 达到最大值的那个
5. 映射到健康建议档(优/良/轻度污染…)

**构造即立场**:断点在哪、用哪组统计量(均值还是 P98)、是否纳入 CO——
每一项都是环境医学与政策的谈判结果。改一格断点,超标天数年报就变一次。
(02 章"阈值句是决策句"的构造现场。)

### 构造 2:Shannon 多样性——从名录到熵

输入:一次调查的物种计数 n₁,…,n_S(总个体 N)。构造三步:

1. 频率 p_i = n_i / N
2. H = −Σ p_i ln p_i(每"抽出"一个个体,平均信息量)
3. 均匀度 J = H / ln S(同物种数下排均匀程度的修正)

**结构基因**:Shannon 指数就是信息熵(→[../../讲透数学/讲透信息论/](../../讲透数学/讲透信息论/README.md)
同源)——多样性=群落给你的不确定性。Simpson 指数 λ=Σp_i² 是"两次抽到同种的概率",
对优势种更敏感:H 看 richness,Simpson 看 dominance,选哪个=你想强调什么。
**反直觉小例**:一台 AI 声纹监测把某优势鸟种多认了 10%,H 几乎不动,
Simpson 明显动——指数的选择先于数据的善恶。

### 构造 3:CUSUM——把"变没变"变成一条累计和

输入:时序 x₁,…,x_n,怀疑均值发生一次突变。构造三步(家族实验 `experiments/00_changepoint.py` 亲手跑):

1. 对全序列求总均值 x̄
2. 累计离差 S_t = Σ_{i≤t}(x_i − x̄)
3. 变点 = argmax|S_t|;显著性用**置换检验**(打乱重排整条序列 N 次,
   看原始 max|S| 在零假设分布里的分位)

**结构基因**:S_t 是随机游走的离差累积——均值不变时它在 0 附近游走,
突变年两侧一升一降形成"峰"。滑动 t 检验(同一实验的第二方法)是它的孪生:
逐点问"前后两段均值差几个标准误"。两者都要被置换检验重新定价,
因为**找了最大值的 t 不再服从 t 分布**(多重比较的时序版)。

### 构造 4:指纹回归——归因的最小构造

检测归因(分支家族的招牌)骨架只有一行:y = Σβ_i × 指纹_i + 噪声。
指纹=各强迫(温室气体/气溶胶/火山/太阳)模式响应的空间-时间形状;
约束 β=(信号幅度)并检验"内部变率能否解释"。
**结构基因**:这就是带物理约束的线性反问题(→[../../讲透数学/讲透计算数学/](../../讲透数学/讲透计算数学/README.md)
的 Tikhonov 家族)——响应模式是猜的形,β 是估的量,"指纹不吻合"本身是诊断。

## 二、结构引擎 1:加性分解(把混在一起的世界拆开)

**为什么它是引擎**:环境序列永远是多声部合唱——趋势(气候变迁)、
周期(季节/昼夜)、事件(火山/El Niño)、噪声(天气)。不拆开就没法回答
任何"变化"问题。标准分解:

```
x(t) = 趋势 f(t) + 季节 S(t) + 内部变率/噪声 ε(t)
```

- **基林曲线的三层**:上升直线(趋势)+锯齿(季节)+小毛刺(天气)——
  00 章美之时刻 1 的那条曲线,就是加性分解的活教材
- **归因的加性观**:观测变暖 = 人为信号 + 自然变率;归因问题=把和式里的
  两项分账(β 估计),而不是对总和讲故事
- **极端事件的分解**:风险 = 均值移动(气候变迁)+ 方差变化 + 尾部形状——
  PR 概率比句(01 章战线 1)就是分解后对尾部的重定价
- **流域水量/碳预算**:流入=流出+Δ储量,收支恒等式是加性分解的会计化身

**代价**:各分量**正交性/独立性假设**经常只是近似——El Niño 影响趋势估计,
季节振幅本身在变(非平稳)。分解越干净,世界越"方便",也越可能被修剪掉真信号。

## 三、结构引擎 2:层级结构(嵌套的世界)

**为什么它是引擎**:环境数据天然分层——个体在样方里、样方在站点里、
站点在区域里、区域在半球里;物种在群落里、群落在生态系统里。
层级模型(贝叶斯多层的看家结构)把每一层的**抽样方差与过程方差分开记账**:

```
全球参数 → 区域偏移 → 站点偏移 → 单次观测(含检测概率)
```

- **占有-检测模型**:观测"看见"= 在场(生态过程)× 检测(观测过程)——
  两层显式分开,"没看见≠不在"(00 章 §七发现 3)从口号变成可估的量
- **病面制图(disease mapping)的表亲**:空间统计支的 CAR 随机效应
  (→[../../讲透数学/讲透数理统计/讲透空间统计/](../../讲透数学/讲透数理统计/讲透空间统计/README.md))
  把"邻域.borrowing strength"形式化——稀疏数据的站点向邻居借力
- **SEEA 的嵌套**:资产账户(存量)嵌套流量账户嵌套服务账户,且每一层
  都要和 SNA 经济账对接——层级不仅是统计结构,也是**核算结构**

**代价**:层数=假设数;错误层级(把本该站点的异质性推给区域)造成
生态谬误的环境版——"区域平均值"从来不是任何一个真实地点的状态。

## 四、不可构造清单(结构刚性的边界)

- **生态系统服务的"总价值"**:可以选择估值路线(旅行成本/条件价值/当量因子)
  构造出**一个**数,但"正确的那一个"不存在——价值判断环不是统计能闭合的
  (00 章 §四未解决之二)。能构造的是**实物量账户**(公顷、吨、人次),货币化只是其上一个可选层
- **生物多样性 headline 单指标**:综合指数必然压扁维度(物种/遗传/生态系统),
  各维下降方向不一致时,任何加权都是立场——IPBES 至今用指标**仪表盘**而非单数
- **"最优"监测网**:给定预算与目标函数可解(克里金方差最小化一类),
  但目标函数(保护什么?为谁监测?)不在统计手里

## ✨ 美之时刻(SEEA 的配平之美,00 章时刻 3 的构造展开)

**期初存量 + 增加量 − 减少量 = 期末存量**——环境资产账户与你的银行存折
共享同一个恒等式。为什么美:一行会计恒等式,让"砍了多少林、补了多少林"
从政治修辞变成**可审计的账**;任何一栏造假,另一栏必须跟着说谎——
复式记账是最古老的统计防伪术,SEEA 把它请进了森林与渔场。

## 五、反直觉发现(讲透铁律):最优插值会抹平真实世界

克里金是"最优线性无偏插值"(BLUE),但"最优"的代价:**插值场的方差
系统性小于真场**——极值(污染峰值、热点物种)被平滑掉,因为插值本质是
邻域加权平均,而平均天然削峰。站点越稀,场越"温顺",看图的人越容易
低估极端事件的严重性。同族效应:再分析的均质化(00 章 §五)也在做同构的抹平。
**教训:插值图是期望场,不是真实场;读图要带方差图。**

## 📌 收束 + 🧭 新眼睛(认知升维)

**构造之眼**:看到任何名牌数(AQI/H/红名单指数/碳汇量)自动放映它的流水线——
输入哪些数、过了哪几步、哪一步藏着立场断点;看到任何环境结论先做**分解眼**:
趋势多少、周期多少、变率多少,还是把三声部当成了一句话;
看到任何"没测到"先做**层级眼**:是过程层不在,还是观测层没看见。
