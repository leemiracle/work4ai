# 讲透环境与生态统计学 · 给地球做体检的学问——监测、归因与把自然算进账本

> **本质一句话**:环境与生态统计学=给地球做体检的学问——
> 空气干不干净、气候变没变、物种少没少、森林值多少钱,
> 这门手艺让它们从感叹变成**可测量、可追踪、可问责**的数。
>
> GB/T 13745-2009:910 统计学 · 二级学科 **91050 环境与生态统计学**(GB/T 未列三级 → 本家族自定主干支);
> **GB/T 更名声明:资源统计原名为自然资源统计**——由本家族 [讲透环境监测统计](讲透环境监测统计/README.md)
> 的资源环境核算内节承接(见 §三)。
>
> **定位张力声明**(先读这个再读本家族):环境的"物"住在生态学/大气科学/环境科学,
> 推断的数学本体住在数学宇宙的数理统计(11067)——空间统计支与时间序列分析支是本家族的
> 直系工具箱。本家族不重复建设这些地盘,只详答环境与生态统计自己独有的三件事:
> **怎么布点采样、怎么把观测变成环境质量与生态状况的数**(环境监测统计)、
> **怎么从噪声里检出气候变化并归因于人类**(气候变化检测与归因)、
> **怎么把生物多样性与生态系统压成可比的数并估值**(生态统计与生物多样性指标)。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透环境与生态统计学/
├── 讲透环境监测统计/          🆓 自定主干支——站点布设、采样与QA/QC、AQI与环境质量指数、SEEA资源环境核算
├── 讲透气候变化检测与归因/    🆓 自定主干支——趋势检测、变点、最优指纹归因、极端事件概率化(基林曲线的直系后代)
└── 讲透生态统计与生物多样性指标/  🆓 自定主干支——群落监测、多样性指数、占有-检测模型、生态系统服务估值
```
