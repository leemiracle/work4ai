# 讲透气候变化检测与归因 · 从基林曲线到概率句

> **定位句:这支负责"变化是真的吗、是谁干的"——趋势/变点检测把信号从内部变率里
> 剥出来,归因方法把极端天气从感叹号变成概率句,基林曲线是全支的祖证词。**
> GB/T 13745-2009:910 统计学 · 91050 环境与生态统计学 · **自定主干支**(GB/T 未列三级,家族自定)。
> 家族:[讲透环境与生态统计学](../README.md)

## 诞生

- **谁/何时**:1958 Keeling 在冒纳罗亚开始逐日测 CO₂(基林曲线:锯齿=地球呼吸,
  上升直线=人类记账);1979-1995 Hasselmann 等建立最优指纹法,检测(变化超出自然变率)
  与归因(归账给强迫)从此分开回答;2004 Stott 等首次单一极端事件归因:
  人为变暖使 2003 欧洲热浪风险至少翻倍;
  2020s 世界天气归因(WWA)把周期从数年压到数周(家族 01 章战线 1)
- **因什么问题**:①"变暖是噪声还是信号"(检测)②"人类份额多少"(归因)③"这场灾难与气候有关吗"(概率句革命)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 气候变化检测归因的方法体系(最优指纹/指纹回归,IPCC 评估报告的统计脊梁);"变暖暂停"被解释为窗口选择+内部变率效应 |
| ✅ 已解决 | 单事件归因的概率比(PR)框架:两世界集合对比,风险变化可估 |
| 🔄 进行中 | 快速归因的稳健性(小尺度强对流/复杂洪水过程模式分辨率不足);归因句对模式误差的敏感性报告 |
| ❓ 未解决 | 单次事件的个体化归因(频率因果的语法极限——只能改"这一族"的分布,不能指认"这一场");内部变率的不可约不确定性 |

**最美事实(一句)**:2004 年起,极端天气的定性从"天灾感叹号"变成
"若无人为强迫,此类事件风险减半以上"的概率句——统计学没阻止任何一场风暴,
却改变了风暴的责任语法。

## 假设与依赖

- 信号-噪声可分假设:观测=强迫响应+内部变率的加性分解(家族 03 章 §二);
  内部变率的估计来自控制模拟,模式低估变率则归因过度自信
- 再分析资料的均质化代价:观测系统换代会以"气候变化"面目出现(家族 00 章 §五)

## 教材锚

- Zwiers & von Storch《Statistical Analysis in Climate Research》(气候统计的领域圣经:检测/指纹/极端统计)
- IPCC AR6 WGI(2021)第 1 章与第 11 章(检测归因与极端事件的官方方法综述;IPCC 统计方法文献体系)
