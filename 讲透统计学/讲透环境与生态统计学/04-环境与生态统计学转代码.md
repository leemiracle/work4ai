# 04 · 环境与生态统计学转代码:把体检流水线跑成系统

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角)。
> 三条走廊:**时序异常检测**(传感器流)、**空间插值思路**(站点到场)、
> **SDG 指标**(数据到仪表盘);两个落点:**监测传感器网络**与**碳核算**。

---

## 开篇:别的分支在"翻译",本分支在"值班"

数理统计转代码,通常是一次性翻译:定理写完,函数写完,论文投完。
环境统计转代码,产物是**常年值班的系统**——监测网 7×24 进数、
QA/QC 滤波、超限报警、月报年报流水线、SDG/SEEA 年度盘点。

所以本章的问题不是"能不能转"(大部分能),而是:
**管道怎么防脏数据、插值怎么对得起方差、指标怎么对得起口径、系统怎么活得过
仪器换代与标准升级。**

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 环境统计概念 | 代码化身 | 备注 |
|-------------|---------|------|
| 分段线性指数(AQI/UVI) | 断点表+线性插值,纯查表 | 断点是数据不是代码——外置配置,标准升级只改表 |
| 3σ/滑动 t/CUSUM 异常检测 | 流式统计量+滚动窗口 | 单文件可实现(家族实验即证据);工程难点在阈值标定不在算法 |
| 缺测标记/检出限删失 | NULL 语义+左删失标记位 | 千万别用 0 或 −999 当"没测到"——那是 02 章的三种 0 之灾 |
| IDW/薄板样条插值 | 空间权重平均,纯几何 | O(站×格),可并行;克里金要解线性系统(→走廊 2) |
| 多样性指数(H/Simpson/均匀度) | 名录计数+对数运算 | 一行公式;难点在名录规范化(同物异名) |
| 排放清单(活动×因子) | 矩阵乘+不确定性传播(Tier 1) | 因子库是数据资产;层级方法向上换更细的模型 |
| 账户配平(SEEA 恒等式) | 表约束校验(断言) | 存量恒等式做成 invariant 检查,账不平就拒绝发布 |

**转不动/转不动的边界(红色区)**:

1. **占有-检测模型的完整贝叶斯推断**:MCMC 采样无解析式——
   工程对策:调用成熟统计栈;纯标准库只做单层近似。
2. **归因反问题**:依赖模式集合输出与强迫指纹数据,不是"算法"是"数据+模型制度"——
   代码只做最后的回归与显著性;工程师角色是数据管道而非数学。
3. **指标口径的谈判**:断点、权重、纳入哪些污染物——写不成代码,
   只能外置成配置+版本号,让立场显式可审计(把不可机械化变成**可审计化**)。
4. **再分析/同化**:变分与 Kalman 滤波是计算数学的地盘
   (→[../../讲透数学/讲透计算数学/](../../讲透数学/讲透计算数学/README.md)),
   统计侧只接"订正后的产品"。

## 二、代码走廊清单(三条走廊,每条=数据→结构→算法→真实系统)

### 走廊 1:时序异常检测走廊(传感器流)

```
仪器 → 原始流(1-5 min) → QA/QC 滤波(量程/跳变/卡值/缺测) → 小时聚合
     → 异常检测(3σ/滑动 t/CUSUM) → 报警 & 变点台账 → 均一化存档
```

- **数据→结构**:时序=(时间戳, 值, 质量位) 三元组;质量位是第一公民——
  原始值永远保留,清洗只动"可用位"(审计要求)
- **算法层**:量程检查(物理界)、跳变检查(|Δ|>k·滚动σ)、卡值检测
  (传感器死循环输出常数——环境统计特有的"假平稳")、
  CUSUM/滑动 t(家族实验 `experiments/00_changepoint.py` 全流程可跑)、
  显著性用置换检验定价(别拿找过最大值的 t 直接查表——03 章构造 3 的教训)
- **真实系统**:各国空气质量/水质自动站的联网中心、工业 CEMS 排放连续监测、
  气象 CLIMAT 报文流
- **性能工程要点**:流式统计量用滑动窗口的增量更新(和/平方和增删 O(1),
  不要每步重扫);报警要**去抖**(连续 k 点越限才报,否则 El Niño 级的毛刺
  把值班员训练成狼来了免疫);变点台账(仪器何时换过)是均一化的生命线

### 走廊 2:空间插值走廊(站点到场)

```
站点观测(点) → (剔重/质控) → 插值引擎(IDW → 克里金) → 格点场/等值线
            ↘ 交叉验证(留一站) → 精度证书 → 发布
```

- **数据→结构**:站点=(经纬, 高程, 值);场=规则格网或面元。
  **高程是第二坐标**——山谷与山脊的水平近邻可能是两个气候
- **算法层**:IDW(距离幂次权重,零假设零参数,基线);回归-插值混合
  (先拿高程/海岸距回归再插残差——环境场大多非平稳,IDW 假设的平稳是奢望);
  克里金=变差函数建模+线性系统求解
  (数学本体在 [../../讲透数学/讲透数理统计/讲透空间统计/](../../讲透数学/讲透数理统计/讲透空间统计/README.md));
  验证=留一站点交叉验证,报告 MAE/RMSE 而不是只发图
- **真实系统**:各国气象局的格点分析产品、空气质量实时发布地图、
  NOAA NCEI 气候监测格点产品线(01 章战线 6)
- **性能工程要点**:克里金 O(n³) 解系统——大规模用局部邻域(每格只用最近 k 站)
  或低秩近似;插值场方差<真场(03 章 §五抹平效应),发布要带不确定性图;
  卫星像元≠站点支撑(面-点匹配,01 章战线 2),直接当同一种数互喂是常见事故

### 走廊 3:SDG 指标走廊(数据到仪表盘)

```
监测/统计/行政数据 → 口径层(定义/方法/来源三登记) → 指标计算(公式可配置)
    → 排放/资产账户(配平断言) → 报告(SDG 年度/ETF 双年/SEEA 账户)
```

- **数据→结构**:指标=(定义元数据, 计算管道, 数据源, 版本);碳清单=
  活动数据矩阵 × 排放因子矩阵,误差传播按 Tier 层级声明
- **算法层**:全是"平凡"运算(乘法/加总/配平断言),难在**口径层**——
  同一个"森林覆盖率"三种定义差 5 个百分点;MRV 的"报告-核证"环节
  在代码层=版本化+第三方可复算(把 01 章战线 5 的对账做成 CI 里的断言)
- **真实系统**:各国 SDG 报送管线、UNFCCC 透明度报告、SEEA 资产账户工作簿、
  全球碳预算年度流水线
- **性能工程要点**:这是**数据工程>算法**的走廊——管道要幂等可重跑
  (上游数据集回溯修订,01 章版本纪律);指标定义外置成声明式配置;
  账户恒等式(期初+增−减=期末)做成发布前 invariant;每次口径变更
  自动生成"重算差异报告"

## 三、工程师落点(两个最值钱的岗位)

### 落点 1:监测传感器网络(物联网×统计)

你将面对:廉价传感器漂移快、断电断网缺测成片、多源仪器混布。
统计落点清单:

- 质量位三态(好/可疑/坏)+ 永不改原始值(审计底线)
- 双站/参比站交叉标定:同址放一台参考仪,漂移=两序列差值的变点
  (走廊 1 的方法反过来用)
- 缺测插补用**邻站+背景场**而非时序内插(空间比时间慷慨)
- 报警阈值上线前用历史数据回放标定误报率——报警系统是统计产品,
  不是 if 语句

### 落点 2:碳核算(MRV 数据系统)

你将面对:活动数据(能源账/流水)×排放因子库×不确定性报告,双年透明度周期。

- 因子库是版本化数据资产(因子更新=历史重算,要可追溯)
- 不确定性:Tier 1 用误差传播(乘法式的相对方差相加)先做对,
  再谈蒙特卡洛
- 自上而下(大气反演)对账:两条证据链的差异要有仪表盘
  (01 章战线 5 的"账本不平衡警报器")
- 组织碳核算(范围一二三)与国家清单同构,同一套乘法管道换口径层

## 四、值班检验仪式(把本家族用成瑞士军刀)

接管任何环境数据系统,做三问:
1. **零问**:系统里"没测到"怎么存?0、−999、NULL、缺行——各有几处消费者?
2. **窗口问**:每个"趋势/异常"结论的窗口与基线在哪声明?版本升级会不会静默改历史?
3. **方差问**:发布的每张图,有没有配对的不确定性表达(区间/分位/留一验证)?

三问过完,系统的统计骨架就裸露了——剩下的才是真正的难点(并发、IO、组织政治)。
