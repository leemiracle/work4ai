# 讲透数字经济测度 · GDP 量不到的新大陆:免费品/数据资产/平台

> **定位句**:这支负责"**表盘之外的新经济**"——搜索引擎与社交网络
> 零价格提供服务、数据成为企业的"油田"、平台把买卖双方撮合在一个
> 多边市场里;现行 GDP 对这三样东西几乎失明,本支研究怎么给它们装仪表。
> GB/T 13745 91030 经济统计学 · **自定主干支**。家族:[讲透经济统计学](../README.md)

## 诞生

- **谁/何时**:Griliches 1960 年代提出"服务与质量测度危机"(计算机时代的
  测度隐忧);**BEA 1985** 起对计算机做 hedonic 质量调整;
  **Brynjolfsson & Oh 2012**"注意力经济"用选择实验给免费服务定价;
  **BEA 2019** 发布首版数字经济卫星账户;**GDP-B**(Brynjolfsson, Collis,
  Diewert, Fox 等,2019 起)把免费品消费者剩余补成平行指标;
  **SNA 2025**(2025-03 通过)把数据正式资本化为生产资产;
  OECD 2023 起发布数字经济测度系列(方向锚,检索校准 2026-09-07)。
- **因什么问题**:①零价格服务的产出在现行语法里记零;
  ②平台多边市场(广告补贴免费服务)的价格信号失真;
  ③数据作为资产的存量与折旧从未入账——国民财富缺一大块。

## 核心问题

**已解决**:
- 卫星账户框架落地(BEA 数字经济卫星账户:总量/价格/就业)
- 数据资产入表(SNA 2025:企业持有/可用于生产的数据资本化)
- 选择实验方法成熟(大规模在线实验给免费品出价)

**未解决/深水区**:
- 免费品福利如何进官方序列(GDP-B 仍在研究期,无国际标准)
- 数据资产的估值与折旧(成本法 vs 收益法;数据不磨损但会过时)
- 平台多边市场的真实价格分解(广告主付费+用户免费)
- Beyond GDP 仪表盘上数字福祉该怎么表示(与联合国首脑指标议程合流)

## ✨ 这支最美的一个事实

**GDP-B 的零价格定价**:问用户"要付多少钱你才愿意一个月不用搜索引擎?"
——实验答案是每月数十美元量级(方向锚)。一个"免费"的服务,
福利贡献藏在 GDP 记录的零里。GDP-B 用选择实验把这些零换回货币数,
并发现:传统 CPI 对数字品的相对价格变动系统性漏记——**不是经济没有增长,
是仪表没有指针**。测度科学的尊严在于:先承认失明,再造眼睛。

## 假设与依赖

- **零价格≠零价值**(免费品假设):平台以注意力/数据为对价——正是"市场交易"的边界模糊处
- 选择实验的外推假设:实验补偿金额≈真实福利(时间贴现/策略性应答是噪声源)
- 数据资产的成本法假设:数据价值≈生产成本(SNA 2025 的务实选择,争议中)
