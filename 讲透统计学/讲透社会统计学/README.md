# 讲透社会统计学 · 把社会状况变成可比的数——抽样、指标与不平等测度的手艺

> **本质一句话**:社会统计学=把社会状况变成可比的数——
> 谁穷谁富、谁上学谁失学、谁活得好谁活得难,这门手艺让它们从轶事变成**可比较、可追踪、可问责**的数。
>
> GB/T 13745-2009:910 统计学 · 二级学科 **91040 社会统计学**(GB/T 未列三级 → 本家族自定主干支);
> **GB/T 注明:教育统计学(88031)归入社会统计学**——由本家族 [讲透教育与社会统计](讲透教育与社会统计/README.md) 承接(见 §三)。
>
> **定位张力声明**(先读这个再读本家族):「社会」比任何统计总体都大——收入分配与
> 国民核算长得像(经济统计学 91030 管),人口规模结构过程归人口统计学(91045)管,
> 推断的数学本体在数学宇宙的数理统计(11067)。本家族不重复建设这些地盘,
> 只详答社会统计自己独有的三件事:**怎么从社会里抽出能说话的样本**(抽样调查方法)、
> **怎么把"社会好不好"压成可比的数**(社会指标体系)、**怎么把教育与生活质量接进同一张表**(教育与社会统计)。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透社会统计学/
├── 讲透抽样调查方法/    🆓 自定主干支——从抽样框到权数:一份调查数据的全流程合法性
├── 讲透社会指标体系/    🆓 自定主干支——HDI/基尼/贫困线:把社会状况压成可比的数的度量衡
```
