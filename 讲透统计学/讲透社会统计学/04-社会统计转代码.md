## 一、可机械化边界:什么能算、什么算不了

**能机械化的**(有原理保证的"算"):

| 社会统计动作 | 机械化形态 | 保证来自 |
|-------------|-----------|---------|
| 加权估计 | HT 权数/事后分层/raking 三件流水线 | 设计基无偏性(Neyman/HT) |
| 方差评估 | 设计效应 deff=1+cv²;分层方差公式 | 方差分解恒等式 |
| 不平等测度 | 基尼/Lorenz/Theil 的排序算法(O(n log n)) | 平均差/熵的代数恒等式 |
| 标准化 | 直接/间接标化的矩阵乘法 | 恒等式分解 |
| 季节调整 | X-13ARIMA-SEATS 的回归+滤波 | 信号提取模型(假设担保,非设计担保) |
| 指标聚合 | min-max 归一+加权聚合(HDI 几何平均) | 构造规范(国际手册) |

**机械化不了的边界**(为什么——原理级回答):
1. **MNAR 偏差不可由数据内部修正**:应答依赖目标变量时,信息根本不在数据里——
   代码只能做敏感性分析(扫假设区间),不能"算出"修正(实验场景 C 的机器形态)
2. **效度不可自动检验**:指标测没测到构念,机器只能查信度(内部一致性/重测),
   效度需要构念网络的外部证据——自动"验证问卷"的代码只能验证一半
3. **口径选择不可自动化**:用哪个贫困线、哪种标准人口、要不要季节调整——
   每个都是**带价值立场的决策**;把决策写死在管道里=把立场藏进代码。
   社会统计代码化的第一戒律:**先写口径说明书,再写管道**

## 二、代码走廊清单(从零到一的三条走廊)

**走廊 1:调查数据管道**(从原始应答到分析数据集)
```
raw 应答(问卷系统导出)
  → 清洗(时长过滤/straight-liner 侦测/逻辑校验)
  → 派生变量(年龄分组/教育编码映射 ISCED)
  → 权数合并(join 样本框架,挂上设计权+事后分层权)
  → 分析数据集(每行一个应答者,列=变量+权数+层标识+PSU)
```
要点:**每一步留审计字段**(为什么被剔/权数从哪来)——官方调查的"方法学附录"
就是这条管道的日志文件。样本量从 raw 到 analysis 的衰减瀑布(接触率×合作率×应答率)
应当与 01 章的偏差体检表一起输出。

**走廊 2:加权——权数三件套与代价核算**(对应 03 章层 2,家族实验 Part2)
```python
w = 1 / p_included                      # 设计权:入样概率的倒数
w_post = W_h / w_hat_h                  # 事后分层:已知人口结构/样本结构
est = sum(w_post * y) / sum(w_post)     # 加权估计(比率形式)
deff = 1 + cv(w_post) ** 2              # 代价核算:有效样本量 = n / deff
```
四行=加权估计与代价核算的最小骨架。assert 自检:权数按层聚合后应精确复现人口结构
(raking 的收敛判据),deff>1.5 时报告必须注明"有效样本量缩水"。
**先看 deff 再看样本量**——这是走廊 2 的读数纪律。

**走廊 3:指标计算——基尼/贫困率/标准化的纯手实现**(对应 03 章层 1/层 3)
```python
def gini(y, w=None):                    # 排序加权平均差的 O(n log n) 实现
    ...
pov_rate = sum(w * (y < pov_line)) / sum(w)     # 加权贫困率(FGT 族 α=0)
tfr_std = sum(s_age * m_age)                    # 直接标准化(标准人口×年龄别率)
```
要点:指标计算的代码都很短,**难点全在口径**(贫困线怎么定/标准人口选谁/权数挂没挂)——
指标函数应当强制把口径作为参数而非埋成常数。

**走廊间自检断言清单**(三条走廊通用的 exit-0 纪律):
```python
assert set(df.layer) <= set(pop.layer)                 # 样本层 ⊆ 人口层
assert abs(df.groupby('layer').w.sum() / df.w.sum()
           - pop.layer_share).max() < 1e-9             # 权数复现人口结构(raking 判据)
assert (df.y.isna() & df.responded).sum() == 0         # 应答者的关键变量无缺
assert 0.5 < df.w.mean() * len(df) / pop.N < 2.0       # 权数规模合理(防爆炸)
```
四条断言分别看守:覆盖合法性、配平收敛、逻辑一致、权数健康——
对应 00 章 §五的四条假设;断言失败的位置=假设被凿的位置。

**最小工具栈**(走廊从零到一的装配顺序):

| 层 | 首选 | 一句话理由 |
|----|------|-----------|
| 教具级 | 纯标准库 random/math | 家族实验的做法:透明第一,能 assert 自验证 |
| 单机生产 | pandas/numpy | 管道与 raking 迭代的现役标配;权数列必须全程随行 |
| 方差层 | replicate weights 自实现 或 samplics/statsmodels | 调查方差≠iid 公式,必须按设计(层/PSU)算 |
| 指标层 | wquantiles/自写排序基尼 | 加权分位数是指标计算的地基件,别用无权版本 |

装配纪律:任何一层换库,断言清单重跑——**工具链的默认值不是中立**的
(多数统计库默认无权、默认 iid,正好踩中社会统计的两条禁令)。

## 三、工程师落点(性能工程视角)

| 落点 | 社会统计原理 | 工程现场 |
|------|-------------|---------|
| **用户调研** | 抽样框/配额/事后加权 | 满意度调查回收率 8%?先问应答机制再问样本量;自愿应答样本按用户分层加权(走廊 2),别拿原始百分比汇报 |
| **社会听感**(social listening) | 大数据代表性(01 章战线 4) | 舆情监控的"全网声量"≠公众意见——发言者是自选样本;用调研数据给听感模型配"校准锚点" |
| NPS/满意度看板 | 测量层级(02 章)/Simpson 分组 | NPS 是定序数据压成数;分群看与合并看结论可反转,看板必须显式声明分组口径 |
| A/B 实验中的问卷 | 方差/偏差分离 | CUPED 思想同源:先验分层减方差;无应答按层分析防"幸存者偏差" |
| 面板(panel)维护 | 轮换/损耗加权 | 用户面板的"活跃偏差"=调查业的应答率危机同款——分层 refresh 是解药 |
| 大规模调查 ETL | 管道可并行 | 抽样模拟/重加权/Bootstrap 方差天然并行(重样本独立);注意 RNG 流管理(seed spawn) |

**性能工程特别提示**:调查管道的重计算热点在 raking 迭代与方差估计(重复包含/剔除的
jackknife 要重跑整条加权链 B≥50 次)——把加权函数写成无副作用的纯函数,
才能安全地并行重放;这与社会调查机构的"复制权重"(replicate weights)发布惯例同构。

## 四、一个完整案例:从问题到代码的全链路

**问题**:产品满意度调查,发 10 万份回收 8000 份(回收率 8%),重度用户占比明显超高——
"满意度 4.6/5"能报吗?

1. **翻译成社会统计问题**:非概率样本(自愿应答)+结构倾斜——回收率低不是原罪,
   应答机制才是(01 章战线 3)
2. **偏差体检**(走廊 1 出衰减瀑布):拿平台用户注册数据(近似总体)对比应答者的
   活跃度/注册时长/地区分布,算各维度的标准化偏差——超 10% 的维度必须处理
3. **加权**(走廊 2):按活跃度×地区 raking 到用户总体,检查权数 cv;
   deff=1.3 → 有效样本 6150,别吹 8000
4. **稳健性双报告**:加权 4.6 / 未加权 4.6?——一致则结论稳;不一致则报区间并解释
   倾斜方向(实验场景 B 的机器形态)
5. **敏感性**:若重度用户系统性高 0.3 分(MNAR 假设),结论怎么动——扫一个假设区间
   (不可识别≠不可讨论)
6. **制度**:下一轮改分层抽样配额+激励分层(适应性设计的 04 章化身)——
   修管道优于修权数

一条链走完三支:抽样调查方法(1-3)、社会指标体系(4-5)、测量与口径(6)——
这就是"社会统计的语法,工程的句子"。

## 五、为什么不直接"全部交给大数据/ML"

常见混淆:海量数字脚印 vs 概率样本——
大数据有 n 没有框(覆盖误差)、有量没有机制(自选进入)、有信号没有口径(定义漂移);
概率样本反过来。**两者是互补不是替代**:大数据供时效与颗粒度,概率样本供
代表性锚点(01 章战线 4 的合流格局)。把"全网声量"直接当公众意见汇报,
等于 1936 年《Literary Digest》换了个数据库再犯一次——
样本质量>样本数量的下半节课(01 章),在 ML 时代仍然必修。
