# 社会统计思维技能卡(讲透社会统计学家族 · GB/T 91040)

## ① 何时用此分支(触发特征,一眼对号)

- 你在做**抽样调查**:抽样框、分层、配额、无应答、应答率、权数
- 出现**社会指标**:贫困线、基尼系数、Lorenz 曲线、HDI、生活质量、主观幸福
- 要把问卷/用户调研数据**加权**或汇报(回收率低、样本偏斜、要配平人口结构)
- 要**比较**社会数:跨群体/跨国/跨年——标准化、季节调整、口径声明
- 面对**大数据替代调查**的提议:舆情声量、平台脚印能不能代表公众
- 设计用户满意度/NPS 调查,或为非概率样本辩护/体检

*不是这里*:分布与推断的数学本体→数理统计;人口规模结构→人口统计学;
问卷措辞与研究设计→社会学方法(姊妹宇宙);GDP 核算→经济统计学。

## ② 核心思维模式

1. **三道工序**:抽(样本合法性)→压(指标构造)→比(口径可比)——任何社会数都要过三关
2. **机制先于率**:应答率/回收率/覆盖量是健康指标,不是偏差指标——MCAR/MAR/MNAR 三分决定偏差命运
3. **构造即选择**:归一→加权→聚合,每步都是价值立场(算术 vs 几何平均=可否补偿的哲学)
4. **拿已知换未知**:权数用人口结构等已知边换无应答的未知倾斜;但 MNAR 时无解,只能敏感性分析
5. **分解恒等式**:总量必有组内+组间去处——归因的合法性靠恒等式,不靠讲故事
6. **样本质量>样本数量**:1936 年 240 万输给 5 万;n 买方差,买不回偏差

## ③ 工具箱(方法名 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| 分层抽样(比例/最优分配) | 层内同质、层间异质——白拿层间方差那块精度 |
| Horvitz–Thompson 权数 | 不等概率抽样,要无偏复原总体总量 |
| 事后分层/raking | 应答结构倾斜,有人口边缘可配平(MAR 可修) |
| 设计效应 deff=1+cv² | 汇报前核算:有效样本量=n/deff,权数不是免费的 |
| 基尼/Lorenz/Theil | 测收入或任何不平等;要精确组分解时用 Theil |
| 直接/间接标准化(ASR/SMR) | 比较率之前先换共同人口结构(防 Simpson/构成效应) |
| 季节调整(X-13-SEATS 思想) | 月度序列要读趋势,必须先吸走日历项 |
| 偏差体检(标准化偏差/衰减瀑布) | 拿到任何调查数据的第一件事:覆盖/应答/权数三问 |
| 敏感性分析(无应答机制扫描) | MNAR 嫌疑:扫假设区间,报告"如果机制如此,结论怎么动" |
| 适应性设计思想 | 预算有限、应答率分层悬殊:按偏差最小化分配接触资源 |

## ④ 常见误区与禁忌

- **低回收率≠必然有偏**——偏差看机制不看率;反之高回收率也可能有偏(MNAR)
- **加权不是免费的**——cv 悬殊的权数把有效样本量打折(deff=1+cv²)
- **不指定分组的比较没有真值**——Simpson 悖论埋在分组切换里(生态谬误同源)
- **指标≠构念**——贫困线测的是代理;数一旦成为考核目标就不再是好数(Goodhart 律)
- **定序数据禁谈倍数**——"满意度 7 分是 3.5 分的两倍"是尺度语法错误(Stevens 层级)
- **聚合公式即立场**——算术平均允许维度互换,几何平均惩罚短板;换聚合=换世界观
- **大数据没有抽样框**——海量声量是自选样本,代表性要靠概率样本锚点校准
- **先写口径说明书再写管道**——贫困线/标准人口/调整规格都是决策,埋进常数=藏立场
