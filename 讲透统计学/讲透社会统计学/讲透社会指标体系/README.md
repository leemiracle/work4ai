# 讲透社会指标体系 · HDI、基尼与贫困线:社会状况的度量衡

> **定位句:这支负责"社会好不好怎么变成可比的数"——指标→指数→体系,
> 把多维的社会状况压进仪表盘的全部手艺都在本支领地上。**
> GB/T 13745-2009:910 统计学 · 91040 社会统计学 · **自定主干支**(GB/T 未列三级,家族自定)。
> 家族:[讲透社会统计学](../README.md)

## 诞生

- **谁/何时**:1889-1903 Booth 用贫困线与贫困地图点数伦敦贫困(第一条线、第一张地图);
  1905 Lorenz 画分配曲线、1912 Gini 把它压成一个数;
  1966 Bauer 主编《Social Indicators》开社会指标运动(OECD/联合国 1970s-80s 建体系,
  UN《社会指标手册》1989 成文);1990 UNDP 首份人类发展报告发布 HDI(Sen/ul Haq);
  2009 Stiglitz–Sen–Fitoussi 委员会报告《Mismeasuring Our Lives》把"超越 GDP"推成官方议程
- **因什么问题**:①"GDP 之外,社会状况如何被看见"(指标运动的母题)
  ②"多维福利能不能压成一个数还不失真"(HDI 的聚合难题)
  ③"蛋糕怎么分"(基尼/贫困线的分配测度)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 贫困线三构造(绝对/相对/多维);基尼/Lorenz/Theil 的测度理论;HDI 的几何平均构造(2010 定型) |
| ✅ 已解决 | Lorenz 支配判据:曲线不相交时一切合理不平等指数同判(03 章 §二) |
| 🔄 进行中 | 主观幸福测度的规范化(量表/文化应答校准——OECD 指南体系仍在演化,时效声明) |
| 🔄 进行中 | 分配测度的实时化(行政税务记录直接算 top 份额——DINA 一脉,01 章战线 4) |
| ❓ 未解决 | 指标的 Goodhart 化免疫(数成考核目标即失真);多维贫困阈值与权重的共识化 |

**最美事实(一句)**:HDI 用几何平均把收入、教育、寿命压进一个 0-1 的数,
任一维度趋零整体趋零——"发展是自由、能力不可偏废"的哲学被一个聚合公式数学化。
