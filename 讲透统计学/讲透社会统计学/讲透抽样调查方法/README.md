# 讲透抽样调查方法 · 从抽样框到权数:一份调查数据的全流程合法性

> **定位句:这支负责"数怎么来才配说话"——抽样设计、接触与应答、无应答、权数与估计,
> 一份社会调查的全部生命周期都在本支领地上。**
> GB/T 13745-2009:910 统计学 · 91040 社会统计学 · **自定主干支**(GB/T 未列三级,家族自定)。
> 家族:[讲透社会统计学](../README.md)

## 诞生

- **谁/何时**:1895 Kiaer 在 ISI 提出"代表性方法"引发三十年论战;1934 Neyman 论文
  确立概率抽样+设计基推断,现代调查的地基;1936 年《Literary Digest》240 万自荐样本
  预测错大选、Gallup 5 万配额样本答对——行业用一次世纪惨败学会"样本质量>样本大小";
  2009 Groves 等《Survey Methodology》第二版把调查方法定型为一门跨抽样/测量/认知的独立学科
- **因什么问题**:①"不数全员能否知道全员"(抽样的合法性)②"抽到了访不到怎么办"
  (无应答)③"问出来的可信吗"(测量误差)——调查误差理论的三大源头

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 概率抽样的方差理论(分层/整群/多阶段);Horvitz–Thompson 无偏加权;事后分层与 raking 的构造 |
| ✅ 已解决 | 误差分解框架(覆盖误差/抽样误差/无应答误差/测量误差的总方差账本) |
| 🔄 进行中 | 应答率危机与适应性调查设计(01 章战线 1/2——检索校准 2026-09-07:欧洲跨国调查二十年下滑、UK 统计当局列首要风险) |
| 🔄 进行中 | 低应答率与偏差的脱钩诊断(应答率≠偏差指标,HESA 2025) |
| ❓ 未解决 | MNAR 无应答的识别与修正(只能敏感性分析);非概率样本+大数据混合的推断框架 |

**最美事实(一句)**:1936 年,240 万份问卷输给 5 万份——
从此行业知道:代表性是抽样框与机制的性质,不是 n 的函数。

## 假设与依赖

- 抽样框覆盖总体(框漏了谁,样本永远替谁沉默——1936 年的电话簿是原型教训)
- 应答机制可诊断:MCAR 白丢方差、MAR 可加权修、MNAR 无解只能扫假设

## 教材锚

- Groves, Fowler, Couper, Lepkowski, Singer & Tourangeau《Survey Methodology》(Wiley, 2nd ed. 2009)——调查误差总账本的定典
