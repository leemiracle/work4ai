## 诞生

- **谁/何时**:1900s 教育测验运动(Thorndike"凡存在皆有数"、Binet 智力量表 1905)让"学力"可测;
  1958 ISEA(国际教育成绩评价,IEA 前身)起步跨国比较,1992 起 OECD《Education at a Glance》
  年鉴定型教育指标体系,2000 年首轮 PISA 把"跨国可比的学习成果"变成全球治理工具;
  生活质量一脉从 1970s 北欧福利研究(Allardt"有/爱/存在"三维度)到 2012 起《世界幸福报告》
  与各国官方主观幸福感题组(如英国 ONS 四问)
- **因什么问题**:①"教育产出怎么量"(投入好数,产出难测——学力/素养/成就的测量)
  ②"各国学生怎么考同一张卷子"(跨国可比性)③"过得好不好怎么数"(生活质量/幸福)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 教育参与与投入指标体系(入学率/师生比/教育经费);矩阵抽样(PISA:每人只做题册一角,拼出总体) |
| ✅ 已解决 | 年龄别入学率的标准化比较;量表信度(Cronbach α)与效度框架 |
| 🔄 进行中 | 学习成果的跨国等值(题册轮转+IRT 链接);教育加值测量(value-added,剔除背景的"学校净效应") |
| 🔄 进行中 | 主观幸福官方化(0-10 题组入国家统计——文化应答校准未定谳,时效声明) |
| ❓ 未解决 | 教育的长期回报与能力形成的因果测度;"幸福"的共识度量(00 章 §四) |

**最美事实(一句)**:PISA 用矩阵抽样让 70+ 国学生"考同一张卷子"却没人做完全部题——
抽样设计直接造出了跨国可比性:每个学生考的题目不同,各国比的是同一个潜变量。

## 假设与依赖

- 潜变量假设:测的是题目背后的"素养/能力"(IRT 的测量模型),不是题目本身
- 可比性假设:跨国等值链(锚题链接)无漂移——链断了,年份间的"进步"就是幻觉
- 硬依赖:[讲透社会指标体系](../讲透社会指标体系/README.md)(生活质量是它的福利维度延伸);
  量表与抽样工具承自 [../../../讲透数学/讲透数理统计/](../../../讲透数学/讲透数理统计/README.md)

## 教材锚

- OECD/UNESCO/UIS《OECD Handbook for Internationally Comparative Education Statistics》(2017)——教育统计跨国口径的现役规范
- Sen《以自由看待发展》(1999)——生活质量/可行能力框架(承接姊妹支的哲学母体)
- OECD《Guidelines on Measuring Subjective Well-being》(2013)——主观幸福官方测度的起点文本
