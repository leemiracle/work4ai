# 04 · 统计学史转代码——编年与论战的两条走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:统计学史的问题一旦变成「关于史料的计算」,就能进代码——
> 编年变时间轴、论战变词频消长、机构变网络;**唯一不可外包给代码的,是史学判断本身
> (选样、归因、优先权裁决)**。本章三件套:可机械化边界 → 两条代码走廊 → 工程师落点。

---

## 0. 开篇:83 条记录检验两个百年判断

「Graunt 之后统计学才起飞」「1885 年前后是统计学的启蒙时刻」——这是两段写在
几乎所有通史里的叙事。它们对吗?

`experiments/00_stats_timeline.py` 用 83 条大事记录(1539-2025,年代×学派×人物×事件)
做了最朴素的检验:按世纪切片、数事件、算窗口密度。跑一遍你会看到:

```
密度比检验:1662 年前  4 件 =  3.25 件/百年
           1662 年后 79 件 = 21.70 件/百年
           密度比 = 6.7×
统计启蒙检验:1880-1935 窗口内 KPF 及其下游 31 件
           窗口总密度 62.5 件/百年 ≈ 全期基准的 2.9×
```

两段直觉都被数据确认。但脚本同时打印**选样声明**:这 83 条是「入选正史的著名事件」,
密度曲线度量的是**史料与正史的关注度**,不是「统计知识产出」。断言 A1/A2 检验的是前者。
**这正是代码走廊的第一课:代码替你算数,替不了你解释数**——而「替你算数」已经足以
把一段修辞变成一个可反驳的命题。

## 1. 可机械化边界(三件套之一)

**能进代码的**(史料数据化后的一切结构计算):

| 任务 | 机械化形式 | 走廊 |
|------|-----------|------|
| 编年密度/分期检验 | 事件点列 → 世纪直方图、窗口密度比 | C1 |
| 人物中心度粗测 | 人物字段出场频次 → 频次表、共现表 | C1 |
| 学派兴替 | 术语词频的时间消长(如 likelihood 取代 inverse probability) | C2 |
| 论战时间线 | 双方文献年份+关键主张 → 对撞表 | C2 |
| 制度网络 | 期刊/学会/讲席沿革 → 有向图(03 章 §3 的数据化) | C2 延伸 |

**不能进代码的**(统计学史的「不可判定域」):

1. **选样正当性**——哪些事件值得入库是史学判断;代码只能做敏感性分析
   (换窗口重跑,见 §5)。本编年库的 83 条是「正史选样」的自白。
2. **归因与动机**——「Pearson 的 r 是为了优生学」是证据+解释的合成;
   代码给共现与年代,人给归因(00 章 §六反直觉 1 的论证不能被 assert)。
3. **优先权裁决**——Gauss 声称 1795 年用过最小二乘,出版物日期可查,
   「使用优先 vs 发表优先」的**裁决标准之争**不可计算(03 章 §5)。
4. **价值排序**——「双重遗产怎么并陈」没有目标函数;把伦理判断写成超参数
   是对两头的同时冒犯(01 章 §3 三条军规)。

> 边界的一句话:**代码是史料的显微镜,不是史学家**。放大倍数越高,
> 越要记得镜头(选样)是谁选的。

## 2. 走廊 C1:编年数据库(三件套之二)

**成品已实现**:[`experiments/00_stats_timeline.py`](experiments/00_stats_timeline.py)(✅ 纯标准库,exit 0)。

**数据字典**(TIMELINE 即此模式的实例;扩展约束写在最后一列):

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| year | int | 公元年份;**跨公元前要处理无 0 年**(本库起点 1539,暂免) |
| school | 枚举 | 10 学派枚举表本身=**史学选样判断**;增删必须记入变更说明 |

| (建议加) source_tier | T1一手/T2二手/T3转述 | 无此字段的编年库一律视为 T2;Graunt 死因表的三级标注是原型 |

(补入女性贡献者与俄意印线)再重跑密度比;对窗口 1885-1933 重跑断言 A2(00 章练习 3)。

## 3. 走廊 C2:文本挖掘学派论战

论战史料(论文、通信、书评)是统计学史最富的矿。最小可用分析:**词频对撞**——
两个术语在同一时段的消长,就是一次学派兴替的文本证据。

**五行起步**(纯标准库,跑在任何标点化语料上):

```python
from collections import Counter
corpus = {  # 时段: 文本(示意:各取自该年代代表作的摘要)
    "1901-1920": "inverse probability prior posterior bayes ...",
    "1922-1935": "likelihood sufficient efficiency estimation ...",
}
for period, text in sorted(corpus.items()):
    words = Counter(text.split())
    print(period, words.most_common(5))
```

**示范问题:Fisher 1922 的术语革命**。Fisher 在《理论统计学的数学基础》里刻意
弃用当时主流的 **inverse probability(逆概率)**,改用 likelihood——并把两者明确切割
(概率=参数固定数据变;似然=数据固定参数变)。你若把 1890-1940 年主要统计期刊文本
分桶统计这两个词的频率,会看到一条交叉曲线:**术语替换的完成年份,就是频率派
方法论确立的文本侧时间戳**。词频曲线是概念史的体温计(02 章 §3 三步法的计量版)。

**C2 数据字典**(论战语料表):

| 字段 | 类型 | 说明 |
|------|------|------|
| year | int | 文献年份 |
| side | 枚举 | 论战方(如 fisher/k_pearson/neyman) |
| term | str | 追踪的术语(中文或原文) |
| freq | int | 频次(按千词归一更好) |

**断言的史学版**:「1925 年后 likelihood 词频反超 inverse probability」——
先手工核对 3-5 篇关键文献,再让代码全量验证。**代码验证假设,不生成假设。**

## 4. 工程师落点(三件套之三):默认参数考古学

工程师读统计学史,最划算的不是背年表,而是掌握一门手艺:**每个默认参数都是考古现场**。
三个直接落点:

**落点 1:p<0.05 与 95% 的来历**。0.05=Fisher 1925 教科书为省版面只排了 5%/1%
两档显著性表(农业试验精度下的经验分档);95% 置信=Neyman 框架下 1.96σ 的圆整。
你的 A/B 测试平台里那个红色阈值,祖籍是洛桑的马铃薯田。**知道了来历,你才敢问
「我的场景该不该用这个默认值」**——高吞吐线上实验的合理显著性可能要 Bonferroni,
生死攸关场景可能要 0.005。默认值是历史给的开局,不是法律。

**落点 2:方法选型=知道包袱才敢卸**。频率 vs 贝叶斯之争是 200 年论战史
(Laplace 逆概率→Fisher 切割→Savage 复兴→MCMC 复活→Stan 平民化)。
选工作流时,「大家都这么用」的深层原因常常是一场历史战争的停战线,不是数学必然。
懂史的工程师做选型时能把「数学理由」与「历史惯性」拆开报账。

**落点 3:用官方数据先查口径史**。GDP/失业率/人口数这类官方统计,每次口径修订
(国民账户的国际改版、普查问卷措辞变更)都是一次结构断点。**时间序列对接前先读
「口径说明」一页**——这是 Broadbalk 田 180 年不断档的启示:**连续性是制度维护出来的,
不是天然的**;不查修订史,你就是在把 1931 年的亩产和 2025 年的遥感估算焊在一起。

> 一句话:**读史的工程师,是唯一能在参数面板前保持清醒的人**。
