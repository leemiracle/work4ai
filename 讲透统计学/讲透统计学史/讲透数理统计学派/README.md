# 讲透数理统计学派 · K-P-F 引擎室(1880-1930)

> **定位句**:这支负责统计学从「描述国家」到「推断总体」的引擎室——
> **G**alton 出问题(遗传如何量化)、**P**earson 出工具(矩法/χ²/相关 r)、
> **F**isher 出重构(似然/ANOVA/实验设计),三代人五十年把「数账」造成科学
> (Stigler:统计启蒙 1885-1935)。
> GB/T 13745-2009:91010 统计学史 · 本支为**自定主干支**。家族:[讲透统计学史](../README.md)。

## 诞生

三步建制:Galton《自然遗传》(1889)把变异与相关问题移交数学家;Weldon+K. Pearson
合流(1893)开跑《演化论的数学贡献》系列;Biometrika 创刊(1901)+UCL Galton
Laboratory 成立(1904)——学派有了期刊与讲席。Fisher 1919 入驻洛桑试验站,
1922《理论统计学的数学基础》单篇定义似然/一致性/充分性/有效性,1925《研究工作者的
统计方法》把方法送进全世界实验室。下游:Neyman+E. S. Pearson 检验决策理论(1928-33)
与 Wald 序贯分析(1945)。

## 核心问题

- 相关与回归如何**度量与解释**?(Galton 概念 1886-88→Pearson r 定型 1896→Yule 虚假相关警告 1897)
- 分布曲线族怎么拟合?(Pearson 矩法/分布族 vs Fisher 似然——两代方法之争)
- 小样本怎么办?(Gosset 匿名 t 分布 1908→Fisher 精确分布 1915)
- 实验如何设计才有推断力?(随机化区组/拉丁方/ANOVA——「无随机化无检验」)
- 推断的本质是什么?(Fisher 显著性 vs NP 两类错误——未和解的哲学之争)

## ✨ 这支最美的一个事实

Fisher 1922 年单篇论文同时给「似然」正名并定义一致性、充分性、有效性——统计推断
从一堆特例技艺变成有公理基础的科学,一次投稿完成「独立宣言」。而同一论文刻意弃用
inverse probability 一词——术语革命与理论革命在 30 页里同时发生(04 章 C2 追踪对象)。

## 假设与暗面(双重遗产)

- 假设:大样本(Pearson 矩法)→被 Gosset/Fisher 小样本革命修正;正态=同质→被分布族自身瓦解。
- 暗面:Galton 1883 造词 eugenics;Pearson 首任优生学讲席教授;Fisher 终身为优生学
  辩护——本支问题意识(变异/遗传/选择)与优生学深度绑定。双重遗产军规(家族 01 章 §3):
  并陈、不删词、先语境后公式。
