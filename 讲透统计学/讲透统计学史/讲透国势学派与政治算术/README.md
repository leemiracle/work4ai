# 讲透国势学派与政治算术 · 名字与方法的双胞胎出生(17-18C)

> **定位句**:这支负责统计学的「双源出生」——德国国势学派给了学科**名字**
> (Statistik=国势学,先于数字),伦敦政治算术给了学科**方法**(从死亡公报做推断,
> 先于名字);两股在 19 世纪凯特勒手里合流之前,各自独立跑了一个世纪。
> GB/T 13745-2009:91010 统计学史 · 本支为**自定主干支**。家族:[讲透统计学史](../README.md)。

## 诞生

双起点:1660 年前后 Conring 在黑尔姆施泰特大学开设国势学讲座(系统比较各国宪制、
财力、习俗的「国家学」,尚无数字);1749 年 Achenwall 首创 **Statistik** 一词
(统计学的命名时刻)。另一边,1662 年伦敦商人 Graunt 出版《关于死亡公报的自然与政治
观察》——用五十年死亡烂账推断人口与寿命,**统计方法的零点**;Petty 喊出
「用数字、重量与尺度说话」的纲领;Halley 1693 造出精算级生命表;Playfair 1786
发明折线图与条形图,给数据配上图形语言。

## 核心问题

- 国家的「国势」如何**系统比较**?(国势学派的条目式方案为何最终输给了数字?)
- 残缺的死亡公报能否支撑**推断**?(Graunt:能——反推人口约 38.4 万、男女比 14:13、
  城乡死亡率差,一张生命表开创生存分析)
- 比率的**平稳性**从何而来?(「生死有稳定比率」=平稳性假设的祖先)
- 数字与描述,哪种更接近国家真实?(两条路线的百年竞争,以数字路线胜出告终)

## ✨ 这支最美的一个事实

Graunt 用「约每 11 个生育年龄妇女年产 1 个死亡…」等几条朴素比率,从死亡数**反推**
出伦敦人口约 38.4 万——后世复算误差小得惊人。一个人、一本书、一年,
给一门学科装上了「由账到人」的推断引擎;皇家学会为此破格吸纳一个纽扣商人。

## 假设与暗面

- 假设教区登记≈全体(不从国教者、流动人口系统性缺席);假设过去之比可用于未来(平稳性);
  假设死因归类可信(Graunt 自承一半死因是「惊厥」式传闻归并——他给出的可信度分层
  是数据分级的原点,家族 02 章 §2)。
- 暗面:政治算术服务于重商主义国家的算计;「数得清=管得住」的治理逻辑自此发端。
