# 讲透统计学史 · 统计学的自我意识——数据如何长成一门科学

> **本质一句话**:统计学史=统计学的自我意识——它不生产新公式,却回答每个公式背后的三个问题:**这个问题当初为谁而设、这场论战谁赢了、这个名词的原始含义是什么**。
> GB/T 13745-2009:910 统计学 · 二级学科 **91010 统计学史**(GB/T 未列三级 → 本家族三支均自定主干支)。
> 家族:[讲透统计学](../README.md) 宇宙首家族;五问五章为家族总纲,三支子系列各自由宪法 README 起步。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透统计学史/
├── 讲透国势学派与政治算术/  🆓 自定主干支——名字与方法的双胞胎出生(17-18C):
│                                   德国国势学派出名字,伦敦政治算术出方法
├── 讲透数理统计学派/          🆓 自定主干支——K-P-F 引擎室(1880-1930):
│                                   Galton 的问题→K. Pearson 的工具→Fisher 的重构
└── 讲透官方统计制度化/        🆓 自定主干支——另一半学科:普查/学会/国民账户,
                                    把数数变成国家基础设施(1790-今)
```

> 三支的共同骨架:**统计学不是从数学里分出来的,是从「国家治理的麻烦」里长出来的**——
> 先有要数的账(死亡公报/人口/收成),后有数账的方法(生命表/相关/检验),最后才有方法的数学。
> 社会物理(凯特勒,19C)是政治算术与数理学派之间的桥——家族 00 章内节详述,归口前两支。
