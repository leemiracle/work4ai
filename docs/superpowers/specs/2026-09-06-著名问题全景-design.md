## 1. 背景与目标

用户要求在讲透数学宇宙中**穷举当前所有数学相关的著名问题**。经 brainstorm 四问定型：宇宙级全景文档（三档范围 + 希尔伯特23问百年史），顺手清欠宇宙 README（合并设计的提交3），时效以全领域逐域检索保障。

## 2. 决策记录（均已用户确认）

| # | 决策 | 选择 | 备选与理由 |
|---|------|------|-----------|
| D1 | 产出形式 | **宇宙级全景文档** `讲透数学/著名问题全景.md`，挂宇宙 README 第8节 | 对话内穷举（不落盘）/ 新系列骨架（最重）/ 并入 README 一节（不展开）均被否 |

| D3 | 宇宙 README | **按合并设计§3.4全量建出**（清欠提交3，含根 README 挂网） | 只建全景（孤儿）/ README 最小骨架（动两次）被否 |

## 4. 全景文档结构（四部曲）

```
著名问题全景.md
├── 第〇部 导言：选录标准成文（"著名"的边界规则）+ 时效声明（截至2026-09）
├── 第一部 希尔伯特23问百年史
├── 第二部 千禧悬赏档（7问逐个，庞加莱已解计入）
├── 第三部 各领域开放名题档（穷举主体，按D6九领域分组）
└── 第四部 已解决里程碑档（~30个）
```

各部字段：

| 部 | 表格字段 |
|----|---------|
| 一 希尔伯特 | 编号 \| 问题 \| 现状（已解·部分·未解·独立·被证伪）\| 一句意义 |
| 二 千禧 | 问题 \| 状态与近年进展 \| 悬赏 \| 宇宙承接 |
| 三 各领域 | 问题 \| 一句话陈述 \| 状态与最好进展 \| 宇宙承接 |
| 四 里程碑 | 问题 \| 解决年 \| 解决者 \| 一句意义 \| 宇宙承接 |

**第〇部选录标准（成文要求）**：
- 千禧档：克雷所2000年七问，穷举无争议
- 开放名题档（满足任一即收）：①主流教材/综述有专节 ②有公开悬赏（如 Beal $1M、Erdős 问题表）③领域综述公认的代表性问题 ④进入 ICM 报告/大事记。目标规模每领域 8-15 个（与千禧档重复的问题不重复计入第三部），总数约 70-110
- 里程碑档（满足任一即收）：①菲尔兹/阿贝尔/沃尔夫级认可 ②主流媒体头条 ③教科书改写。上限 ~30

**宇宙承接列取值**：`系列名→章名` / `系列名（通读）` / `⧜ 缺位（候选：数论|PDE|微分几何…）`。填列前通读 14 个系列 README 篇目表。

## 5. 检索计划（写入前执行，≈10轮 WebSearch）

| 轮 | 域 | 聚焦 |
|----|----|------|
| 1 | 数论 | Landau四问/柯拉兹/abc/奇完全数等状态 |
| 2 | 组合与离散 | Ramsey/Hadwiger–Nelson/union-closed/lonely runner 等 |
| 3 | 分析与PDE | Kakeya 2025 等近年突破 |
| 4 | 几何与拓扑 | 光滑4D庞加莱/望远镜猜想后续等 |
| 5 | 代数 | Kaplansky系/Jacobian/inverse Galois 等 |
| 6 | 逻辑与集合论 | Vaught/CH 后续/连续统研究现状 |
| 7 | 概率与随机 | 随机矩阵/相变名题 |
| 8 | 计算复杂性 | P vs NP 邻域（UGC/log-rank/矩阵乘指数ω） |
| 9 | 千禧动态 | 2024-2026 七问任何进展 |
| 10 | 希尔伯特23问现状考 | 逐问主流共识（含争议项如第13问） |

冲突处理：检索与模型知识冲突时以检索为准，正文行内注来源。
