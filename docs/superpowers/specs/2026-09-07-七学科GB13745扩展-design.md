## 3. 模式(全盘沿母版+姊妹,差异如下)

1. **形态**:每学科=仓库根宇宙目录;二级=家族目录(名=GB/T 二级名轻规范化);三级=支宪法占位(40-60 行七要件:定位/诞生/核心问题/最美事实/假设/教材锚/五问章目表📝/互链)
2. **家族层全量**:README+五章(150-450 行/章,九要件沿数学 spec §5 终版)+`experiments/`≥1——非数理家族实验=**最小可跑数据/文本/模拟脚本**(文学=词频共现/版本对读;哲学=三段论检查器/论证图;新闻=词频熵;教育=学习曲线/间隔重复;社会=Schelling 隔离/网络小模型),纯标准库优先,assert 自验证
3. **SKILL.md** ×93(数学 D7 规格:frontmatter `name: <universe-slug>-<family-slug>`;五件套)
4. **宇宙 README**:全景表(二级代码逐条映射+支落子+挂靠表+归入声明+兜底声明+穷尽声明)+特征速查节(数学 D8 的 README 内嵌版,姊妹先例;不另立路由文件)
5. **01 章检索**:主会话**集中预取**(每波 WebSearch 串行 1 查询/家族,限流自等待),素材内联进 fork 任务包,标注「检索校准 2026-09-07」;贫瘠者方向锚+时效声明
6. **fork 纪律(限速适配)**:subagent_type=**general-purpose**(全新 context,任务包自足,省 token);**≤4 并发**;429 死亡者 SendMessage 续命;git 零写操作,主会话统一**原子化** scoped commit(`add+diff--cached 核对+commit` 一气呵成,记忆铁律)
7. **挂靠**:就地成员零迁移零改写;跨宇宙链接波0 先立 7 宇宙 README 使目标存在
8. **薄学科纪律**:部门经济管理/国别文学等材料薄者章可精简至下限不注水;教材锚可换权威综述/经典文献
9. **多 lane 边界**:不碰六学科 lane 的六个宇宙目录与其 M 文件;`讲透管理/`(既有系列)只链接不改写
