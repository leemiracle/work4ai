> 背景：用户给出 19 个活跃形式化方法工具（Z3/cvc5/CBMC/ESBMC/CPAchecker/Dafny/PRISM/Storm/mCRL2/TLA+ TLC/LearnLib/AutomataLib/automata-lib/pyformlang/CUDD/Sylvan/dd/Spin/Alloy），要求以「讲透」系列覆盖。经头脑风暴确定三决策：**合并进现有《讲透形式化验证》**（不新建系列）、**理论主线+工具作仪器**（同生态工具同章对比）、**双轨实验**（Python 保底 + 原生工具可选）。

## 1. 定位与一句话宪法

现有 3 篇（00-02，偏 Lean4/神经符号）升格为**卷零 · 引论**；新增四卷 12 章 + 收尾 1 篇，编号续接 03。

**系列宪法（扩写进 README 开头）**：形式化验证是"**在可判定性边界的这一侧，为每类系统性质找到可计算的检查方法**"的工程学科。本系列的组织原理不是工具清单，而是**复杂度地图**：卷一攻 NP/coNP（求解器与程序断言），卷二攻 PSPACE（显式/符号模型检查），卷三攻 P（概率定量），卷四参观引擎室（BDD/进程代数/自动机学习），收尾把 19 个工具归位到 Complex Zoo 的格子里，给出两问定位选型法。

**复杂度格标注**：每章核心锚点末尾标注该章理论的复杂度位置（NP/PSPACE/P/NP∩coNP/不可判定），是全系列的横向主线——回答用户两问"怎么识别问题在 Complexity Zoo 的哪一格""为什么这么多工具怎么选"（收尾 50 章正面合拢）。

**造桥条款**（README 边界声明，模仿博弈论系列）：
- 03（SMT）→ 卷零 00 的 Lean4 saturn/Duper 外部求解器桥；04 的 CDCL 复用于 03
- 06（Dafny 全自动）↔ 卷零 Lean4（交互式）哲学对比
- 12（BDD/CUDD）→ 10/11 的 PRISM/Storm 符号引擎底层（生态闭环）
- 50 的复杂度地图 → `讲透优化` 的 NP 难度章、`讲透复杂系统`
- 现有卷零内容**只重排 README 归类，不改语义**
