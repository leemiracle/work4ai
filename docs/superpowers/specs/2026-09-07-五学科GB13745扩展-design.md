## 4. 模式(全盘沿母版+姊妹,差异如下)

1. **形态**:每学科=仓库根宇宙目录;二级=家族目录(名=GB/T 二级名,讲透前缀);三级=支宪法占位(40-60 行七要件:定位/诞生/核心问题/最美事实/假设/教材锚/五问章目表📝/互链);GB/T 无三级者自定 2-4 支标"自定主干支"
2. **家族层全量**:README+五章(150-450 行/章,九要件沿数学 spec §5 终版)+`SKILL.md`(D7 规格:frontmatter `name: <universe-slug>-<family-slug>`;五件套)+`experiments/`≥1——纯标准库优先,assert 自验证;非数理家族实验=最小可跑数据/模拟脚本(军事学=兰彻斯特方程平方律/线性律数值积分;法学=法条命题一致性检查器或判例引用 DAG 环检测;413=经典密码频率分析破译/PID 离散仿真/GPS 三球定位最小二乘;410=公差累积蒙特卡洛/测量不确定度传播;科技史=编年数据/诺奖统计)
3. **宇宙 README**:全景表(二级代码逐条映射+支落子+挂靠表+归入声明+兜底声明+穷尽声明)+特征速查节+消歧框(涉 §3 者)
4. **01 章检索**:主会话**集中预取**(每波 WebSearch 串行 1 查询/家族,限流自等待),素材包落 `.research/GB13745扩展-法军系科/校准素材包-波N-*.md` 并内联进 fork 任务包,标注「检索校准 2026-09-07」;贫瘠者方向锚+时效声明
5. **fork 纪律(限速适配)**:subagent_type=**general-purpose**(全新 context,任务包自足);**≤4 并发**(与七学科 lane 共检出期,遇 429 降至 2 并等待);429 死亡者 SendMessage 续命;git 零写操作,主会话统一**原子化** scoped commit(`add`+`diff --cached 核对`+`commit` 一气呵成)
6. **链接就低不就高**:跨宇宙链接目标家族已存在→链精确路径;未建(含本批后波)→退一级链宇宙 README 并文字注明;波内链检只对本波新增文件
7. **薄学科纪律**:军队政治工作学/工程图学/照相技术等材料薄者章可精简至下限不注水;教材锚可换权威综述/经典文献
8. **敏感内容纪律**:军事学/法学涉中国法制史与军事思想(马恩列斯军事理论/毛泽东军事思想等 GB/T 原名三级)——按学科史实中性学术呈现,不评价不引申
