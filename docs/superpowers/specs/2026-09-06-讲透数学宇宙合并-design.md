## 1. 背景与动机

work4ai 的数学向讲透系列已长到 14 个，散落在仓库根目录，与 AI/系统系列混居：

实分析、分析进阶、群论、Artin抽代、代数拓扑、高维概率、统计学习理论、

同时用户要求创刊 **讲透集合**——集合论是全部 13 个系列的公共地基，且用户给出了
五问骨架（体系结构 / 近五年创新 / 语言特征 / 可构造与结构 / 问题→代码），
该骨架升级为宇宙级模板。

### 3.2 搬移与链接修复（同一提交，原子）

`git mv 讲透X 讲透数学/讲透X` ×14（中文名加引号）。git 重命名检测保留历史。

链接修复脚本（Python，确定性），设搬移集 M（14 目录）：

| 情形 | 处理 |
|------|------|
| 文件在 M 外，链接目标在 M 内 | 重写路径段指向 `讲透数学/X` |
| 文件在 M 内，链接目标在 M 外（根级/其他目录） | 按文件深度 `../` → `../../`（逐链接计算新相对路径） |
| M ↔ M（兄弟互链） | **不动**（平铺红利，免疫） |
| M 外 ↔ M 外 | 不动 |

保留链接锚点（`#`）与显示文本；只改 href 路径段。
扫描范围：全库 `.md`（排除 node_modules/.git/__pycache__/cache/mermaid-render）。

### 3.3 验证（与修复器独立实现）

1. 搬移前先跑基线扫描：全库相对链接解析计数，留档断链数 B₀
2. 搬移+修复后重跑：断链数 B₁ ≤ B₀（**不新增**即为通过；预存断链不修——不扩大范围）
3. `.py` 文件 docstring/注释中的相对路径引用：warn-only 扫描，逐条人工裁决
4. `git status` 干净（除预期新增/改名文件）；`git diff --stat` 抽查改名识别

实测数据（2026-09-06 扫描，14 系列全搬）：入向断链 73 + 出向断链 150 = **~223 条预期修复**。
