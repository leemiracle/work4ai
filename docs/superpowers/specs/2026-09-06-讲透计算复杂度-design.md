## 3. 数据管线（图鉴生产的准确性防线）

1. **抓取**：27 个字母页 `?action=raw`（已验证可直连；GitHub 类资源才走镜像/代理）→
   缓存 `.research/complexity-zoo/raw/`（本地工作区，不入库）
2. **解析**：确定性 Python 脚本按 `===== <span id="...">类名</span>: 全称 =====` 切分 →
   `{id, 类名, 英文全称, 原文}`；按 span id 去重得**权威清单**
3. **分卷**：字母序连续切分使每卷 ~90 类，切点取整字母边界（**预计 6 卷，实际 ±1 随去重总数定**，卷名以切分结果为准）
4. **蒸馏**：中文词条，格式——
   ```
   ### 类名 — 英文全称（中文义）
   一两句定义（自原文蒸馏）。
   - 关键关系：包含于/包含（原文明示者）
   - 主题章 → [[0X-…]] · 原文：complexityzoo.net/Complexity_Zoo:P#p
   ```
   每条 3–6 行；原文链接锚点用解析出的 span id。
5. **总目**：`图鉴/00-总目与口径.md` = 权威清单全量索引（id/类名/卷归属）+ 计数口径声明，
   兼作"所有类已覆盖"的可验证凭据
