## 1. 背景与动机

宇宙 README 第五节已把「分支X光五问」定为新系列入场宪法，三例落地（讲透集合首例、
讲透证明第二例、讲透应用数学第三例）——但三例都是**单系列**用五章回答五问。

用户本次要求（2026-09-06）：以**分析学整个分支家族**为对象做第四例——
穷尽全部分支、每分支一个子目录（讲透xx）、每支回答五问。这实质是把五问模板
从"系列骨架"升格为"分支图鉴"。

现状缺口：

- 分析书架现只有两个系列：`讲透实分析`（本科 Tao/Rudin，🔄 6/16）、
  `讲透分析进阶`（Stein-Shakarchi 4卷，📝 1/9）——复分析/泛函分析在其中
  仅有两章占位，**无独立系列**。
- `著名问题全景.md` 明确标注 **⧜ PDE 缺位**（"无 PDE 分析理论系列"）。
- 数值分析、变分分析、调和分析等主分支在宇宙中无正主。

同时存在张力：宇宙合并 spec 的 D3 决策是"平铺，不建书架子目录"。本设计
通过**辨析**而非推翻解决：`讲透分析/` 是一个**新系列**（伞形图鉴系列，
类比 `讲透计算复杂度/图鉴/` 的系列内部结构），不是书架的物理容器；
现有 18 系列拓扑一个不动（用户已确认，见 D1）。

### 4.2 近5年创新·种子钩子（agent 检索/展开起点，非答案）

- 数学分析：本体稳定，创新在**教学形式化**（Lean mathlib 覆盖度）与直觉化教材
- 实分析（衔接卡）：几何测度论活跃侧记
- 复分析：与复动力系统/Teichmüller 理论交叉
- 泛函：高维与无穷维（度量嵌入/concentration）、非交换与量子信息交叉
- 调和：**restriction 猜想 2025 突破**（王虹-Zahl 三维情形）、decoupling 后续
- 数值分析：SciML/PINN、并行-in-time、混精度、随机数值方法
- 变分：非光滑分析×ML（次微分进训练理论）、ADMM 复兴
- PDE：不可压 Euler 有限时间爆破构造（Chen-Hou 数值→严格）、最优输运、
  2025 微观动力学→流体方程严格推导（希尔伯特第6问部分落定，
  见著名问题全景第一部#6）
- 动力系统：KAM 验证数值、mixing rates、SINDy 数据驱动
- 逼近论：神经网络逼近理论（Barron 空间）、superresolution、Chebfun
- 算子代数：Connes 嵌入推翻（MIP*=RE，2020）余波、自由概率×大随机矩阵
- 多复变：CR 几何、corona 型问题
- 随机分析：路径签名×ML（rough paths 进深度学习）、神经 SDE
- 可计算分析：AI-for-math 形式化分析库、分析的反推数学
- 正则性结构：KPZ 普适性、重整化的代数化（Hopf 代数）

### 4.3 卡模板（统一体例，写入总纲）

```markdown
# 讲透X · 五问图鉴卡

> 一句话定位 + 分析学大图中的位置（核心/延伸/跨向 + 编号 + 依赖）

## 一、体系结构：大厦长什么样
子领域地图（树/表）· 主干定理链（A→B→C，每环节一句意义）· 代表教材锚点

## 二、近五年创新方向（2021-2026）
3-5 条，每条：谁在哪做了什么、为什么重要
（核心七支：Semantic Scholar 检索校准；延伸八支：标时效声明）

## 三、语言特征
表达力（能说什么/不能说什么）· 逻辑性质（完备/一致/可判定档位）·
规范化程度（公理化到哪级：ZFC 内形式理论？结构化定义？约定俗成？）

## 四、可构造性与结构
哪些对象可构造（显式/算法/存在性非构造）·
结构刚性从哪来（对称/极值/刚性定理）

## 五、问题→代码转换
可机械化边界（全自动/半自动/不能）·
代码走廊（问题类→算法→库，清单）·
工程师落点（性能工程视角一句）·
示例脚本（experiments/，主干支配 1 个）

## 六、宇宙承接
正主/侧挂/消费方（../X/ 链接），⧜ 规则沿著名问题全景
```

**衔接卡变体**（02 实分析、06 数值分析）：〇定位 → 一至五**简答**
（每问 3-5 句精华，不抢正主内容）→ 深链正主与侧挂系列 → 六宇宙承接。

### 4.4 agent 任务包（每 agent 一支）

   衔接卡（02/06）不配脚本

（卡型/编号/教材锚点/检索状态）——fork 继承主会话上下文，天然共享体例语境。
