## 6. 事故教训（治理入册）

多会话并行协议补一条：**commit 前必查 staged 区**——
`git diff --cached --name-only` 必须为空或仅含本任务文件才能 commit。
共享分支上的 staged 变动属于其他会话的进行中工作，`git add <path> && git commit`
不带路径过滤时会把它们整体吞入。
