## 1. 定位与一句话宪法

**博弈论的终极定义**：在**利益交织（结构）、信息不对称（信息）、理性层次（认知）和重复互动（时间）**的约束下，研究**策略性决策**如何达成、如何演化的学问。最凝练的一个词：**策略互动（Strategic Interaction）**——纳什均衡中的相互最优、机制设计中的激励相容、演化中的稳定策略、AI 自博弈中的收敛，全是同一件事的方言。

**受众与深度**：对标「讲透优化」——每章"直觉 → 数学 → 代码 → 不足 → 应用"五幕内嵌，证明主脉完整，实验诚实校准。读者画像：AI 研究者/工程师，经得起公式，但需要直觉钩子与 AI 连接。

**边界**：博弈论×多智能体强化学习的算法工程细节归本系列卷五；「讲透优化」负责一般优化算法（两系列在 no-regret/在线学习处互桥）。

## 4. 验证方式

1. **每章理论闭环**：定义 → 直觉例子 → 数学（证明主脉）→ 代码（对应 lab 的 E 编号互引）→ 不足 → 应用（AI 连接）
2. **每个 lab 独立可跑**：`python experiments/labXX.py` 出 png + 控制台结论；理论值与实验值并列打印（诚实校准，延续讲透优化传统）
3. **挂网**（AGENTS.md 规范）：README 篇目表收录全部章节与程序；孤儿文件 = 死亡内容；与「讲透优化」（no-regret 桥）、「讲透Agent」（multi-agent 桥）、「讲透信息论」（信息设计桥）互链
4. **CLI 程序冒烟**：每個 cli 程序提供 `--demo` 模式（机器人对机器人自动对局）用于无人工干预验证

## 5. 明确不做（YAGNI）

- 不做 Web UI/notebook（仓库无此惯例）
- 不做 OpenSpiel Windows 原生支持（官方不支持）
- 不覆盖组合博弈论（Sprague-Grundy）、微分博弈、均值场博弈的完整理论（在 17/50 章指路即可）
- 不自研求解器——手写仅限教学算法（CFR/fictitious play/replicator/Gale-Shapley），通用求解一律交给库
