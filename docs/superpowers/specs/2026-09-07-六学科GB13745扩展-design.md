## 3. 模式（全盘沿母版，差异如下）

1. **形态**：每学科=仓库根宇宙目录（与 讲透数学/ 平级）；二级学科=家族目录
   （名=GB/T 二级名轻规范化，如"计算机科学技术基础学科"→`讲透计算机基础`）；
   三级=支目录宪法占位（40-60 行七要件：定位/诞生/核心问题/假设/教材锚/五问章目表📝/互链）
2. **家族层全量**：README+五章（150-450 行/章）+`experiments/`≥1
   ——非数理家族实验=**最小可跑数据/模拟脚本**（历史=编年数据、政治=投票/决策模拟、
   经济=公开数据或经典模型复现），母版"数学史编年脚本"先例的推广
3. **内容宪法**：七要件（母版 §5 原文适用）+可读性规范
4. **01 章检索**：fork 自查（1-2 次 Semantic Scholar，英文关键词），限流自主降级
   （等待重试或 WebSearch，讲透分析八支实证先例），01 章头如实标注校准方式
5. **挂靠**：就地成员零迁移零改写，家族 README 成员表单向链接
   （`../../讲透xx/` 相对路径——宇宙在仓库根）；跨宇宙链接（经济→数学）波0 先立
   六宇宙 README 使目标存在，避免波间断链
6. **兜底类**（XX 其他学科）不设系列，全景表声明；三级缺明细的二级（如 81030 行政学）
   家族 README 内自定主干支（标"自定主干支"）
7. **薄学科纪律**：部门经济学/区域史等教学属性强、材料薄者——章可精简至下限，
   不注水，如实标注（T7 先例）；教材锚可替换为权威综述/经典文献
