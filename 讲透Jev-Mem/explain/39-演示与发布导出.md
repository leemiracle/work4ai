> 标题：离线演示与公开发布导出——对外开放的两道门面（合集） · 源文件：jev_mem/demo.py（39 行）+ scripts/export_public_repo.py（64 行） · 图谱标签：应用入口层 / 发布基建

## 角色定位

这对文件站在公开流水线的两端。jev_mem/demo.py 是**零依赖首跑入口**：docstring 定调 "Run the Jev-Mem pipeline offline with explicitly mocked Jev and embeddings"（jev_mem/demo.py:1），用三重替身绕开 embedding API、System-Two 生成、远程 Jev，装包后三十秒看到建图→存证→检索全链路。scripts/export_public_repo.py 是**公开发布生产器**："Create a new allowlisted source tree and ZIP; never include private history"（scripts/export_public_repo.py:2）——导出只含 allowlist 文件的干净树加 ZIP。

为什么放在一起讲：两者是同一件事的两面——"对外"要求依赖面与内容面都显式收敛。demo 收敛依赖（mock 替身不碰网络），export 收敛内容（manifest 闭集不带历史）；且二者首尾相接：导出树里含 demo.py（public-release-files.txt:41），新用户首跑往往就是它——导出器亲手把演示送出门。与篇 27 的配合：demo 产物目录 jev_mem_cache 命中 cache 子串黑名单（scripts/check_public_release.py:63）永不入导出；export 直接 import 三个函数复用扫描器（scripts/export_public_repo.py:10-12）——check 审判、export 执行，规则单一实现。

## 内部结构

**jev_mem/demo.py——main 一气呵成**。唯一参数 --cache-dir，默认 ./jev_mem_cache/demo（jev_mem/demo.py:17）。组装段（jev_mem/demo.py:19-23）：MockEncoder 喂给 NumpyVectorDB 与 TRG，llm_backend=None 关图叙述；JevMemConfig 开读写、jev_mock=True、带 decisions.jsonl 审计路径、anchor_count 压一（jev_mem/demo.py:21-22）；MemoryBuilder 显式传 trg_memory 与 llm_enabled=False（jev_mem/demo.py:23），短路构造器的 LLMController 分支（memory/memory_builder.py:84-86）。写路径：四条手工观察带递增时间戳逐条 build，打印 STORED 或 REJECTED（jev_mem/demo.py:29）——诚实展示准入可能拒收。读路径（jev_mem/demo.py:31-35）：QueryEngine 复用 trg、node_index 与 builder.jev（jev_mem/demo.py:31；jev 即构造器按 config 建的 JevClient，memory/memory_builder.py:65），mock 模式下 evaluate 返回合成分布、来源标 "mock"（memory/jev_client.py:197）；查询打印证据与 context.metadata，末行脚注声明 System-Two 未被调用（jev_mem/demo.py:35）。

**scripts/export_public_repo.py——export 单函数扛全部逻辑**。双形态 import（scripts/export_public_repo.py:9-12）：先试包内相对导入，失败退平铺导入；manifest 专门列了 scripts/__init__.py（public-release-files.txt:78）保住包形态。export（scripts/export_public_repo.py:15-46）先是 freshness 守卫：output 不得等于或嵌套于 root，目录与 zip 均不得已存在（scripts/export_public_repo.py:19-22）——宁拒跑不覆盖已验证产物；拷贝前全量预扫，有 finding 即抛。拷贝循环只遍历 manifest names（scripts/export_public_repo.py:29-38）——闭集语义，多带文件结构上不可能；每文件拷贝前复扫 scan_content（scripts/export_public_repo.py:34），源在扫描与拷贝间被改即抛（TOCTOU 防护）；copymode 保权限、逐文件累积 sha256 后落盘 SHA256SUMS，再对 output 树整体复扫（scripts/export_public_repo.py:40-42）——manifest 把自己也列进清单（public-release-files.txt:73），导出树里 public_paths 才能解析；最后 zip 以排他模式 x 打包（scripts/export_public_repo.py:43-45）。

## 外部连接

demo import 六件全来自 memory 包（jev_mem/demo.py:7-12）。MockEncoder 自我定位 "for offline tests/demos, never experiments"（memory/mock_encoder.py:1），128 维词袋哈希（memory/mock_encoder.py:8），测试与演示共用。demo fanIn：console script jev-mem-demo（pyproject.toml:29）、README.md:139 与 docs/evaluation.md:18 指引、tests/test_project_layout.py:45 的 --help 守卫、public-release-files.txt:41 清单。export fanIn：docs/releasing.md:22 手册、MANIFEST.in:80 与 public-release-files.txt:81（导出器把自己也导出）、tests/test_public_release.py:12 单测；fanOut 唯一：scripts/check_public_release.py 的 ROOT/scan_content/scan_worktree——判定单一实现永不漂移。

## 数据流

demo 全程无网：观察文本 → MockEncoder 的 sha256 词袋哈希（memory/mock_encoder.py:15-17）→ NumpyVectorDB 向量检索 → TRG 建节点与边 → MemoryBuilder.build 走 mock 准入与巩固 → 决策追加进 decisions.jsonl（jev_mem/demo.py:22）→ save 落盘 → QueryEngine.query 返回 (QueryContext, evidence)（memory/query_engine.py:686）→ 打印；demo 同时演示审计链——mock 决策也留痕。export 是"扫描-拷贝-复扫"三明治：scan_worktree 产 (names, findings)（scripts/check_public_release.py:110-115）→ 逐名拷贝复扫摘要 → SHA256SUMS → 复扫 → zip。与 --all-files 的接力在手册写死（docs/releasing.md:23-24），而 scan_all_files 的 allowlist 恰把校验和视为合法新增（scripts/check_public_release.py:143）——SHA256SUMS 不会被判越界，两工具在闭集语义里咬合。

## 设计决策

**demo 反幻觉脚注**（jev_mem/demo.py:35）：输出的是检索证据不是生成答案，一行 print 把"这是记忆系统不是聊天机器人"讲给最不熟悉的用户——宁少演示不误导预期。**三重替身独立可拆**：MockEncoder 换 embedding API（确定性哈希可复现）、llm_backend=None 换图叙述 LLM、jev_mock 换远程决策。**anchor_count 压一**（jev_mem/demo.py:22）让 mock 准入尽量收下观察，首跑即见 STORED 主路径。**export 拒绝覆盖**加 zip 排他（scripts/export_public_repo.py:43）：半途产物宁作废重来，不给"部分验证"留错觉。

批判三点。其一，**失败残留无清理**：预扫通过后 output.mkdir（scripts/export_public_repo.py:27）到拷贝中途抛错的窗口留下半成品目录，重跑必须换名或手动清残留——没有 finally 清理或原子收尾。其二，SHA256SUMS 只生成不回读校验，价值要等下游 `sha256sum -c` 兑现。其三，demo 的四条观察与期待输出无测试固化（tests/ 只守 --help，tests/test_project_layout.py:49-52）——改坏 MockEncoder 维度或 build 签名 CI 不红，动构造签名时记得手跑。
