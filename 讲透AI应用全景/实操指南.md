# AI 应用全景 · 实操指南

> 配套 [`00-AI应用的统一框架`](00-AI应用的统一框架.md)。每章给了"是什么/为什么"，本篇补"**怎么做**"——每个应用领域的入门→进阶→生产级路径 + 推荐工具。

---

## 1. AI4Science 实操

### 入门（1-2 周）
- 跑通 [AlphaFold Colab](https://colab.research.google.com/github/deepmind/alphafold/blob/main/notebooks/AlphaFold.ipynb)，预测一个蛋白结构
- 读 Google AI for Science 博客（近 12 个月）

### 进阶（1-3 月）
- 学 PyTorch + 基础 GNN（PyG 库）
- 跑 [PDBbind](https://www.pdbbind.org.cn/) 分子结合亲和力预测
- 学等变神经网络基础（讲透模型可能性 14 章）

### 生产级
- 领域特异数据集（分子/材料/基因组）
- 多模态融合（序列 + 结构 + 文本）
- 可解释性要求高（FDA 审批需解释）

### 推荐工具
PyTorch Geometric / RDKit / BioPython / DeepMind AlphaFold2 / OpenFold / SchNet / Equiformer

## 2. AI4Math 实操

### 入门
- 用 Lean 4 证明一个简单定理（自然数加法交换律）
- 读 AlphaProof（DeepMind 2024）博客

### 进阶
- 学 Lean 4 + Mathlib
- 用 LLM（GPT-4/Claude）辅助证明（生成 tactic）
- 了解自动定理证明（ATP）历史

### 生产级
- 形式化验证（Coq/Isabelle/Lean）
- Lean-Agent：LLM + Lean 闭环（证明-验证-修正）
- 数学发现（AI-Feynman / 跨领域类比）

### 推荐工具
Lean 4 / Mathlib / Copilot for Lean / GPT-4 + Lean / LeanDojo

---

## 3. AI4Code 实操

### 入门
- 装 Cursor / GitHub Copilot，用它写一个完整小项目
- 用 Claude Code / aider 做一个跨文件重构

### 进阶
- 学 SWE-bench（自动修 GitHub Issue 的 benchmark）
- 实现一个 ReAct Agent（讲透 Prompt 07 章）调代码工具
- 理解 AST（抽象语法树）——讲透 PyTorch 的 `ast_grep` 工具

### 生产级
- Devin / OpenHands / SWE-Agent 级别的自主编码 Agent
- 代码安全（讲透 Prompt 08 的 Prompt 注入对代码 Agent 的风险）
- 多 Agent 协作（Coder + Reviewer + Tester，讲透系统论 05 CAS）

### 推荐工具
Cursor / Claude Code / Copilot / aider / Cline / OpenHands / SWE-bench

---

## 4. AI4Medicine 实操

### 入门
- 跑 Med-PaLM / GPT-4 在 USMLE 样题上的表现
- 了解 DICOM（医学影像标准）/ FHIR（电子病历标准）

### 进阶
- 学医学影像 AI（CNN/Segmentation/U-Net）
- 跑 [MedMNIST](https://medmnist.com/) 数据集
- 了解 FDA 510(k) 审批流程

### 生产级
- HIPAA 合规（患者隐私）/ CE 标志（欧盟）
- 多中心验证（数据多样性）
- 人机协同（AI 辅助 + 医生签字）

### 推荐工具
MONAI / Med-PaLM / Microsoft DAX / Abridge / 3D Slicer / nnU-Net

## 5. 创意 AI 实操

### 入门
- 用 Midjourney / DALL-E 3 生成 10 张不同风格的图
- 用 Suno / Udio 生成一首完整歌曲
- 用 Runway Gen-3 / Pika 生成一段视频

### 进阶
- 学 Stable Diffusion 本地部署（ComfyUI / Automatic1111）
- 学 LoRA 微调（讲透复用权重 04 章）——定制风格
- ControlNet / IP-Adapter——精确控制构图/姿势/风格

### 生产级
- 版权合规（AI 生成物的法律地位）
- 品牌一致性（保持跨作品的风格统一）
- 工作流自动化（API 批量生成 + 人工筛选）

### 推荐工具
Midjourney / Stable Diffusion / ComfyUI / Runway / Suno / Adobe Firefly / Topaz

## 6. 企业 AI 应用实操

### 入门
- 用 ChatGPT/Claude 处理一个真实业务文档（合同审查/会议纪要/报告）
- 搭一个简单 RAG（讲透 RAG 全系列）回答内部知识

### 进阶
- LangChain/LlamaIndex + 向量数据库（Pinecone/Weaviate）搭建知识库
- Agent 框架（LangGraph/AutoGen）做多步任务
- 评估（RAGAS / 人工标注 / LLM-as-judge）

### 生产级
- LLMOps：监控（延迟/成本/质量）/ 版本管理 / A/B 测试
- 安全（讲透 Prompt 08：Prompt 注入/数据泄漏/合规）
- 成本优化（模型路由：简单用小模型，复杂用大模型）

### 推荐工具
LangChain / LlamaIndex / Pinecone / Weaviate / LangGraph / AutoEn / Arize / LangSmith

## 7. AI for AI（元应用）实操

### 入门
- 用 GPT-4 做文献综述（给它 5 篇论文让它对比/总结）
- 用 AI Scientist（Sakana AI）跑一个自动实验

### 进阶
- NAS（神经架构搜索）基础——用 NNI/NATS-Benchmark
- AI 发现新优化器（Google Lion 论文方法）
- LLM 做数据标注/清洗/增强

### 生产级
- AI Agent 自主做研究（提出假设 → 实验 → 写论文）
- Constitutional AI（自我修正/自我评估）
- 注意 Model Collapse（AI 生成的数据训 AI → 退化）

### 推荐工具
Sakana AI Scientist / NNI / W&B / Elicit / Semantic Scholar API

## 8. 通用学习路径（从 0 到生产）

```
第 1 周：体验（用 ChatGPT/Claude 做日常任务）
第 2-4 周：Prompt 工程（讲透 Prompt 全系列）+ RAG 基础
第 2-3 月：领域深入（选上述 1 个方向）+ 微调（讲透微调）
第 3-6 月：生产部署（LLMOps + 安全 + 评估）
第 6 月+：创新（Agent / 多模态 / AI4Science 前沿）
```

> 🎯 **关键原则**：**从 Prompt 开始（最便宜），不够再加 RAG（注知识），再不够微调（固化行为），最后 Agent（自主复杂任务）**——参考 [横向打通决策框架](../横向打通-能力获取决策框架.md)。
