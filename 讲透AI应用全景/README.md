# 讲透 AI 应用全景

> 现有 14 个讲透系列都是「**技术组件**」——激活函数、Transformer、KV Cache、微调、RAG…把单个技术往死里钻。
>
> 本系列换一个视角：**「应用场景」**——AI 到底在**改变哪些领域**？每个领域的方法论、代表系统、前沿突破、共性挑战是什么？
>
> 一句话定位：**技术组件是「能做什么」，应用全景是「在改变什么」。两者交叉验证，才看得到 AI 的全貌。**

---

## 为什么单独开一个应用系列

- 技术深钻系列回答"**这个东西怎么实现的**"（内功）
- 应用全景系列回答"**这个东西在改变哪个世界**"（外功）
- 同一个技术（比如扩散模型）在蛋白结构预测（AlphaFold 3）、图像生成（Midjourney）、天气预报里长出**完全不同**的形态——只有应用视角才看得到这种"同源异构"
- AI4Science / AI4Math 是 2024-2026 最有突破感的方向（AlphaFold 3、AlphaProof），值得专门深讲
