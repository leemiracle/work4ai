# 02 · AI4Math — AI 做数学

> AI4Math 是所有 AI 应用里**方法论最深刻、最接近"通用推理"**的方向。AlphaProof 在 2024 IMO 拿到银牌、AlphaGeometry 解出几何金牌——但真正震撼的不是成绩，是它的方法：**Lean 形式化 + 强化学习的搜索**。
>
> 本章深入讲 AI4Math 为什么难、Lean 形式化的本质、AlphaProof 的双系统（生成 + 验证）架构，以及为什么这条路是通向"AI 真推理"的关键。

---

## 一、为什么 AI4Math 比其他 AI 应用都难

### 1.1 数学是"思维的语言"，不是数据

| 应用 | 数据来源 | 学习方式 |
|------|---------|---------|
| AlphaFold | PDB（实验结构）| 监督学习 |
| ChatGPT | 互联网文本 | 监督 + RLHF |
| **AI4Math** | **数学本身**（无 ground truth，靠推理）| **自我对弈 + 形式化验证** |

数学的特殊性：
- **没有"数学数据集"**：定理证明不是统计模式，是**逻辑必然**
- **正确性可以验证**（这是关键！）：Lean/Coq 可以**机器验证**证明的正确性
- **错误不可接受**：不像 ChatGPT 说错一句话，数学证明错一步就崩

### 1.2 为什么 LLM 直接做数学不行

GPT-4 / Claude 等大模型做数学题（GSM8K、MATH）能到 80%+，但：
- **会"幻觉"出错的中间步骤**——LLM 是模式匹配，不是推理
- **不能保证正确**——给个看起来对的答案，无法验证
- **长证明崩溃**——超过 10 步的逻辑链，错误累积到无法挽回

> 🎯 **关键洞察**：纯 LLM 的"数学能力"是**统计拟合**，不是**逻辑推理**。AI4Math 的突破必须解决"**怎么让 AI 真正推理 + 怎么验证推理正确**"——答案是 **形式化数学语言（Lean）+ 搜索 + RL**。

## 二、Lean 形式化：数学怎么变机器可验证

### 2.1 为什么需要形式化

数学家用自然语言写证明，但自然语言有歧义。**Lean**（及 Coq/Isabelle）是**形式化数学语言**——每一步推理都被机器验证，要么对要么错，没有"差不多对"。

```
数学家证明（自然语言）：
  "由 Cauchy-Schwarz 不等式，立即得到..."
  → 人能看懂，但可能有隐藏假设/笔误

Lean 证明（形式化）：
  theorem cauchy_schwarz ... : by
    have h1 := ...
    apply ...
  → 计算机编译验证，要么 100% 对，要么编译失败
```

### 2.2 Lean + mathlib：全球数学的形式化工程

**mathlib**（leanprover-community/mathlib）是全球最大形式化数学库，由几百位数学家协作建设，包含：
- 大学数学（微积分、线代、拓扑）
- 研究生数学（交换代数、微分几何、范畴论）
- 现代数学前沿（如 Kevin Buzzard 在推动把 IMO 题、Fields Medal 工作形式化）

**Lean 4**（2023+）是当前主流版本，性能 + 元编程能力大幅提升。Kevin Buzzard（帝国理工）等顶级数学家在推动"**形式化整个本科数学 + 经典定理**"。

### 2.3 形式化的代价

- **写起来慢**：一个定理形式化可能比纸笔证明慢 10-100 倍
- **需要双重技能**：既要懂数学，又要懂 Lean 编程
- **但收益巨大**：一次形式化 = 永久可验证 + 机器可搜索 + AI 可学习

> 🔑 这就是为什么 Lean 是 AI4Math 的关键基础设施——**它把"数学推理"变成"机器可验证的程序生成"**，正好契合 LLM 的能力。

## 三、AlphaProof（2024）：Lean + RL 的双系统

### 3.1 成绩（2024-07-25 宣布）

DeepMind 的 AlphaProof + AlphaGeometry 2 参加 **IMO 2024**（国际数学奥林匹克）：
- **解出 6 题中的 4 题**
- 其中一题（代数 5）获**满分**
- **总分相当于 IMO 银牌**（42 分满分，得 28 分）

这是 AI 数学推理的历史性突破——**之前最好的 LLM 在 IMO 级别只能解 1-2 题**。

### 3.2 架构：生成 + 验证的双系统

AlphaProof 的方法论是 **AlphaGo 式的"自我对弈 + RL"** 套到数学上：

```
问题（自然语言）
    ↓ 自动形式化（NL → Lean）
Lean 形式化问题
    ↓
AlphaProof（基于 Gemini 的证明搜索网络）
    ├─ 生成 Lean 证明步骤候选（policy network）
    └─ Lean 编译器验证（environment）  ← 关键！
    ↓ 强化学习（RL）
在 Lean 里搜索证明，找到正确路径
    ↓
Lean 验证通过 = 数学上一定正确
```

**关键创新**：
1. **Lean 编译器 = perfect reward model**：不像 RLHF 要人类打分（有噪声），Lean 验证是二值的、绝对正确的——**这是 AI4Math 比 RLHF 更干净的根本原因**
2. **无监督数据生成**：AlphaProof 在 IMO 之前没用 IMO 题训练，而是**自己在 Lean 里生成证明，自我对弈**
3. **自动形式化**：把自然语言问题翻译成 Lean（这本身是 LLM 任务）

### 3.3 为什么是 Lean 不是 Coq/Isabelle

DeepMind 选 Lean 是因为：
- **mathlib 庞大**：训练数据多
- **活跃社区**：持续推进
- **现代设计**：Lean 4 性能好、元编程强
- **谷歌内部已有 Lean 工具链积累**

> 🎯 **方法论洞察**：AlphaProof 证明了一件事——**形式化语言（Lean）+ RL 是当前最接近"真推理"的 AI 范式**。LLM 不直接推理，而是**在形式化空间里搜索**，靠形式化系统保证正确。这和 LLM 的"统计拟合"是本质不同。

## 四、AlphaGeometry（2024）：几何的双系统

### 4.1 几何为什么特殊

IMO 几何题：
- 有图形（不是纯符号）
- 需要作"辅助构造"（添辅助线/辅助点）——**这是人类数学直觉的体现，AI 最难**
- 可以用"演绎数据库"（symbolic rule engine）做严格推理

### 4.2 AlphaGeometry 的双系统（2024-01 Nature）

```
几何问题（图 + 描述）
    ↓
┌─────────────────────────┐
│ 语言模型（LM）           │ ← 生成"辅助构造"建议（直觉）
│ "试试添加一条平行线"     │
└───────────┬─────────────┘
            ↓
┌─────────────────────────┐
│ 推理引擎（DDAR）         │ ← 严格符号推理（验证）
│ 用几何公理推导           │
└───────────┬─────────────┘
            ↓
        推不动？回到 LM 生成新建议
            ↓ 循环
        证出 / 用尽预算
```

**关键**：语言模型负责"**直觉式的构造建议**"，符号引擎负责"**严格的推理验证**"——两者分工互补，模拟人类数学家的"直觉 + 严格"。

**成绩**：IMO 2000-2024 的 30 道几何题，AlphaGeometry 解出 **25 题**（金牌水平）。**AlphaGeometry 2**（2024-07）和 AlphaProof 联合，IMO 2024 几何题满分。

## 五、其他重要 AI4Math 工作

### 5.1 AIMO Prize（2024）—— 竞赛驱动

**AIMO**（AI Math Olympiad Prize）是顶尖 AI 数学竞赛，总奖金 500 万美元。2024 年 7 月由 **NuminaMath** 团队（新加坡，开源）获奖——他们用 LoRA 微调 + 大量合成数据 + self-improve。**开源路线的代表**。

### 5.2 DeepSeek-Prover（2024）

DeepSeek 出的 Lean 自动证明生成。和 AlphaProof 思路类似（Lean + RL），但是开源。证明了 AI4Math 不只是 DeepMind 的游戏。

### 5.3 LeanDojo + ReProver（2023）

开源的 Lean 交互环境 + 数据集 + 证明检索模型。把 Lean 证明生成做成可研究的标准任务。

### 5.4 LLEMMA（2023）

EleutherAI 的数学预训练数据集 + 模型——在 ArXiv 数学论文 + Math StackExchange 上训练。**数学领域的"基础模型"尝试**。

### 5.5 OpenAI o1（2024-09）—— 非形式化路线

o1 不是用 Lean，而是用**纯 LLM 的 CoT + RL**（强化学习"想得更久"）。在竞赛数学（AIME 2024）达到前 20% 高中生水平。**和 AlphaProof 是两条路**：
- AlphaProof：形式化 + 绝对正确，但覆盖慢
- o1：自然语言 + 高概率正确，但覆盖广

**两条路可能最终融合**。

## 六、AI4Math 的方法论：三件套

把所有突破放一起，提炼出 AI4Math 的三件套：

```
┌──────────────────────────────────────┐
│  形式化（Formalization）              │
│  自然语言 ↔ Lean/Coq                  │
│  把"数学"翻译成"机器可验证的程序"    │
├──────────────────────────────────────┤
│  搜索（Search）                       │
│  在巨大的证明空间里找路径            │
│  MCTS / beam search / best-first     │
├──────────────────────────────────────┤
│  强化学习（RL）                       │
│  用形式化验证作为完美 reward         │
│  自我对弈 / 无监督数据生成           │
└──────────────────────────────────────┘
```

> 🎯 **核心**：形式化 = perfect reward。这解决了 LLM 的根本问题（"怎么知道我对了"）。**只要有形式化系统，AI 就能"知道自己对不对"，从而自我提升**——这是 AlphaGo 在围棋上做的事，现在套到数学上。

## 七、开放问题：AI 能证出未解之谜吗

### 7.1 短期（1-3 年）

- IMO 金牌水平（AlphaProof 已接近）
- 自动形式化大规模成熟（自然语言 → Lean 自动转换）
- 大学数学作业 AI 能稳定解

### 7.2 中期（3-5 年）

- 解开一些研究级开放问题（数论/组合）
- 形式化整个本科数学课程
- AI 成为数学家的"标准工具"（自动验证、自动找引理）

### 7.3 长期（5-10+ 年）

- **能否证出 Riemann 假设 / P vs NP？** —— 这是 Fields Medal 级别
- 能否**提出**新概念/新理论（不只是证明已有猜想）—— 这是真正的"原创数学"
- 形式化整个现代数学（Kevin Buzzard 推动的 mathlib 长期目标）

> ⚠️ **限制**：当前 AI4Math 还局限在"形式化语言能描述的数学"——但有些现代数学（如物理几何的直觉、抽象代数的"美感"）还很难形式化。**形式化的边界，是 AI4Math 的边界**。

## 八、一句话总结 + 配套

> 🎯 **三句话**：
> 1. AI4Math 之所以深刻，是因为它逼出了"**怎么让 AI 真推理 + 怎么验证推理正确**"的解：**形式化（Lean）+ 搜索 + RL**。
> 2. AlphaProof 用 Lean 编译器作为 perfect reward，做自我对弈 RL——IMO 2024 银牌。AlphaGeometry 用 LM（直觉）+ 符号引擎（验证）双系统。
> 3. 形式化是 AI4Math 的关键基础设施——它把"数学推理"变成"机器可验证的程序生成"，正好契合 LLM 的能力。

**配套**：
- 形式化根基：学 Lean（Kevin Buzzard 的《The Mechanics of Proof》入门，Kevin Buzzard YouTube 系列）

**国内追踪**：北大田刚/许晨阳团队、清华丘成桐数学科学中心、复旦上海数学中心都在跟进 AI4Math。
