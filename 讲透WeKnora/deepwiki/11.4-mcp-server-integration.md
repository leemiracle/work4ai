  This page covers two complementary aspects of Model Context Protocol (MCP) in WeKnora:

 
 - **WeKnora as an MCP consumer** — the backend connects to external MCP servers and exposes their tools to agents at runtime.
 - **WeKnora as an MCP provider** — a standalone Python server in `mcp-server/` implements the MCP protocol over WeKnora's REST API, making the platform itself accessible to other MCP-compatible clients.
 
 
---

 
## Architecture Overview

 The integration bridges the Go-based backend (Consumer) and multiple Provider implementations. The backend manages connections to external services, handles human-in-the-loop approvals, and manages OAuth state.

### MCP Service Data Model

 External MCP servers are registered as `types.MCPService` entities [internal/types/mcp.go24-45](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/mcp.go#L24-L45) This configuration defines how WeKnora connects to, authenticates with, and interacts with the external tool provider.

 
| Field | Type | Description |
|---|---|---|
| ID | string (UUID) | Primary key internal/types/mcp.go29 |
| TenantID | uint64 | Owning tenant for isolation internal/types/mcp.go30 |
| Name | string | Display name used in tool registration internal/types/mcp.go31 |
| Enabled | bool | Whether this service is active internal/types/mcp.go33 |
| TransportType | types.MCPTransportType | sse, http-streamable, or stdio internal/types/mcp.go16-22 |
| URL | *string | Endpoint URL for SSE/HTTP internal/types/mcp.go35 |
| Headers | types.MCPHeaders | Custom HTTP headers internal/types/mcp.go36 |
| AuthConfig | *types.MCPAuthConfig | Authentication strategy and credentials internal/types/mcp.go37 |
| AdvancedConfig | *types.MCPAdvancedConfig | Timeout and retry settings internal/types/mcp.go38 |

 The `types.MCPAuthConfig` struct supports multiple authentication strategies [internal/types/mcp.go59-73](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/mcp.go#L59-L73):

 
 - **None**: No authentication (`types.MCPAuthNone`) [internal/types/mcp.go63-64](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/mcp.go#L63-L64)
 - **API Key**: Injects a key into a configurable header (`types.MCPAuthAPIKey`, default `X-API-Key`) [internal/types/mcp.go65-66](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/mcp.go#L65-L66)

 - **OAuth**: Performs RFC 9728 flow with dynamic client registration and PKCE (`types.MCPAuthOAuth`) [internal/types/mcp.go69-72](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/mcp.go#L69-L72)

### MCPClient Interface and Transport

 The `mcp.MCPClient` interface in `internal/mcp/client.go` abstracts underlying transport logic [internal/mcp/client.go24-52](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/mcp/client.go#L24-L52) The `mcp.mcpGoClient` implementation handles the connection lifecycle and protocol handshakes [internal/mcp/client.go70-78](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/mcp/client.go#L70-L78)

 Key implementation points:

 
 - **Transport Dispatch**: The factory function `mcp.NewMCPClient` creates the appropriate client implementation depending on the `TransportType` configured in the service [internal/mcp/client.go154-192](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/mcp/client.go#L154-L192)

### MCPTool and Human-in-the-Loop Approval

 The `tools.MCPTool` struct implements the `types.Tool` interface so MCP-exposed tools can be invoked as callable tools in the WeKnora agent framework [internal/agent/tools/mcp_tool.go21-36](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/mcp_tool.go#L21-L36)

 Notable design and flow:

 
 - **Tool Naming**: Tools are registered in the format `mcp_{service_name}_{tool_name}` for stable, globally unique naming [internal/agent/tools/mcp_tool.go53-88](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/mcp_tool.go#L53-L88)
 - **Approval Gate**: If a tool requires explicit user approval before execution (configured via `RequireApproval`), the system enforces a wait for user consent via `approval.MCPApproval` [internal/agent/tools/mcp_tool.go26-30](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/mcp_tool.go#L26-L30) [internal/agent/tools/mcp_tool.go168-189](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/mcp_tool.go#L168-L189)
 - **Execution Flow**: On `Execute()`, the approval gate validates policy constraints and blocks execution if user confirmation is pending [internal/agent/tools/mcp_tool.go141-189](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/mcp_tool.go#L141-L189)

## Part 2: WeKnora as MCP Provider

 
### Python MCP Server (`mcp-server/`)

 WeKnora includes a standalone MCP server implemented in Python (`mcp-server/weknora_mcp_server.py`) [mcp-server/weknora_mcp_server.py1-6](https://github.com/Tencent/WeKnora/blob/10973ed3/mcp-server/weknora_mcp_server.py#L1-L6) This server exposes the WeKnora API surface as MCP tools to external clients.

 Key implementation details:

 
 - **WeKnoraClient**: A Python client wrapping `requests.Session` with thread-local storage to support concurrent tool execution in MCP 2.x worker threads without session conflicts [mcp-server/weknora_mcp_server.py126-161](https://github.com/Tencent/WeKnora/blob/10973ed3/mcp-server/weknora_mcp_server.py#L126-L161)
 - **Authentication**: Secured by `MCPAuthMiddleware`, which enforces clients to send a shared secret token via `Authorization` or `X-MCP-Auth-Token` headers [mcp-server/weknora_mcp_server.py64-100](https://github.com/Tencent/WeKnora/blob/10973ed3/mcp-server/weknora_mcp_server.py#L64-L100)
 - **Transport Support**: Supports standard transport modes: `stdio`, `sse`, and `http` [mcp-server/main.py143-156](https://github.com/Tencent/WeKnora/blob/10973ed3/mcp-server/main.py#L143-L156)
 - **Stateless HTTP**: Configured default for HTTP transport to be stateless, matching the MCP specification [mcp-server/weknora_mcp_server.py40-43](https://github.com/Tencent/WeKnora/blob/10973ed3/mcp-server/weknora_mcp_server.py#L40-L43) [mcp-server/test_mcp_transports.py16-25](https://github.com/Tencent/WeKnora/blob/10973ed3/mcp-server/test_mcp_transports.py#L16-L25)
