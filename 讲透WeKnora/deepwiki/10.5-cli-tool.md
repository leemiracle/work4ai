## Purpose and Scope

 The `weknora` command-line interface (CLI) located under `cli/` provides a terminal client for interacting with the WeKnora RAG server [cli/AGENTS.md1-3](https://github.com/Tencent/WeKnora/blob/10973ed3/cli/AGENTS.md?plain=1#L1-L3) It is designed to serve both human users and automated AI agents (such as Claude Code, Cursor, and Gemini CLI) by supporting structured JSON envelopes, predictable exit codes, and robust error contracts [cli/AGENTS.md3-12](https://github.com/Tencent/WeKnora/blob/10973ed3/cli/AGENTS.md?plain=1#L3-L12)

 As a PARENT page, this document outlines the high-level architecture, command organization, output contracts, and safety mechanisms of the CLI. For deep dives into specific workflows, refer to the child pages:

## Architecture and Command Structure

 The CLI is built using the [spf13/cobra](https://github.com/Tencent/WeKnora/blob/10973ed3/spf13/cobra) framework (`github.com/spf13/cobra`) for command parsing and dispatch [cli/go.mod12](https://github.com/Tencent/WeKnora/blob/10973ed3/cli/go.mod#L12-L12) Command trees are initialized via `NewRootCmd` in `cli/cmd/root.go` and executed through `Execute(ctx)` which handles early format resolution and error mapping [cli/cmd/root.go42-93](https://github.com/Tencent/WeKnora/blob/10973ed3/cli/cmd/root.go#L42-L93)

## Safety and Exit Codes

 To protect automated agents and production environments, destructive operations support `--dry-run` previews and require explicit confirmations [cli/CHANGELOG.md94-105](https://github.com/Tencent/WeKnora/blob/10973ed3/cli/CHANGELOG.md?plain=1#L94-L105) High-risk mutations (such as `api DELETE` or resource deletion without `-y/--yes`) trigger exit code 10 (`input.confirmation_required`) [cli/AGENTS.md154-159](https://github.com/Tencent/WeKnora/blob/10973ed3/cli/AGENTS.md?plain=1#L154-L159)

 
### Exit Code Summary

 
| Exit Code | Error Class | Description |
|---|---|---|
| 0 | Success | Operation completed successfully. |
| 2 | input.* | Flag parse, argument count, or usage errors. |
| 3 | auth.* | Authentication failure or insufficient permissions. |
| 5 | input.* | Typed value validation or safe-argument check failure. |
| 10 | input.confirmation_required | High-risk action requires human confirmation (-y). |
| 124 | operation.timeout | Timeout encountered during polling or waiting. |
| 130 | operation.cancelled | Interrupted by external signal (SIGINT / SIGTERM). |
