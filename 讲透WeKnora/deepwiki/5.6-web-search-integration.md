## Purpose and Scope

 This page documents the web search integration capabilities within WeKnora, covering the pluggable search provider architecture, dynamic tenant configuration, the web fetch tooling (`web_fetch`), security safeguards (such as SSRF protection and encrypted credentials), and execution workflows within agents and the chat pipeline. Supported search providers include Brave, Bing, Google, DuckDuckGo, Tavily, Ollama, Baidu, Searxng, Keenable, Zhipu, Metaso, Exa, and Bocha [internal/types/web_search_provider.go17-32](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/web_search_provider.go#L17-L32).

## Web Fetch Tooling (`web_fetch`)

 The `WebFetchTool` enables agents to read public web pages as Markdown, preserving headings, links, tables, and code structures [internal/agent/tools/web_fetch.go24-41](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/web_fetch.go#L24-L41).

 
### Key Features of `web_fetch`

 
 - **Batch Processing**: Accepts up to 8 items per call with character offset pagination (`offset` and `limit`, default/max 8000 characters) [internal/agent/tools/web_fetch.go31-32](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/web_fetch.go#L31-L32).
 - **Caching & Inflight Deduplication**: Caches retrieved pages for the duration of the Agent run (up to 8 pages) and deduplicates concurrent fetches using `pageFlight` coordination [internal/agent/tools/web_fetch.go21](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/web_fetch.go#L21-L21), [internal/agent/tools/web_fetch.go70-71](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/web_fetch.go#L70-L71), [internal/agent/tools/web_fetch.go119-128](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/web_fetch.go#L119-L128).
 - **SSRF Protection & Chromium Fallback**: Powered by `internal/infrastructure/web_fetch` which validates URLs against SSRF policies, pins IP addresses during dialing, and falls back to headless Chromium rendering for dynamic JavaScript-heavy pages [internal/infrastructure/web_fetch/fetcher.go132-146](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/infrastructure/web_fetch/fetcher.go#L132-L146), [internal/infrastructure/web_fetch/fetcher.go184-195](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/infrastructure/web_fetch/fetcher.go#L184-L195).
 
 Sources: [internal/agent/tools/web_fetch.go19-74](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/web_fetch.go#L19-L74), [internal/infrastructure/web_fetch/fetcher.go92-147](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/infrastructure/web_fetch/fetcher.go#L92-L147)

## Security and Data Privacy

 
### Credential Management

 The system enforces strict security boundaries for sensitive credentials like API keys.

 
 - **Encryption**: API keys are encrypted using a system-level AES key before database insertion [internal/types/web_search_provider.go97-104](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/web_search_provider.go#L97-L104).
 - **Subresource Pattern**: Credentials are managed via a dedicated `/credentials` subresource (`PUT /api/v1/web-search-providers/:id/credentials`) [frontend/src/api/web-search-provider.ts99-105](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/api/web-search-provider.ts#L99-L105).
 - **Response Masking**: The standard provider response DTO omits the `api_key` field; the frontend only receives a `configured: true/false` status [internal/types/web_search_provider.go77-80](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/web_search_provider.go#L77-L80), [frontend/src/api/web-search-provider.ts21-22](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/api/web-search-provider.ts#L21-L22).
 
 
### SSRF Protection

 
 - **URL Validation**: Both `BaseURL` (for SearXNG) and `ProxyURL` are validated using `utils.ValidateURLForSSRF` [internal/types/web_search_provider.go85-90](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/web_search_provider.go#L85-L90).
 - **Proxy Support**: Providers explicitly support optional outbound proxies for tunneling requests securely [internal/types/web_search_provider.go88-90](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/web_search_provider.go#L88-L90), [internal/application/service/web_search.go146-153](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/web_search.go#L146-L153).
