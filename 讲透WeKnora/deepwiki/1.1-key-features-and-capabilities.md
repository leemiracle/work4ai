## Feature Overview

 WeKnora is a modular, open-source knowledge framework empowered by Large Language Models (LLMs). It centers on four major axes:

 
 - **Knowledge Ingestion and Indexing**: A versatile ingestion pipeline that parses 10+ formats (PDF, Word, images, Excel, EPUB, MHTML, XMind, etc.) [README.md55](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L55-L55) It performs adaptive 3-tier chunking, in-process `anydoc` Office parsing [CHANGELOG.md12](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L12-L12) document auto-tagging [CHANGELOG.md19](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L19-L19) and indexes data in multiple vector stores [README.md64](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L64-L64)
 - **Retrieval and QA**: Implements a hybrid retrieval-and-generation (RAG) pipeline combining vector similarity search, BM25 keyword search, and knowledge graph traversal. Queries trigger optimized fan-out retrieval across multiple vector stores [README.md63](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L63-L63)
 - **Autonomous Reasoning & Agents**: The `AgentEngine` [internal/application/service/agent_service.go190](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/agent_service.go#L190-L190) orchestrates multi-step reasoning workflows, multi-tool invocation (built-in, MCP protocol tools), web search integrations [internal/application/service/agent_service.go171-178](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/agent_service.go#L171-L178) session-persistent sandbox execution [CHANGELOG.md9](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L9-L9) and cross-session long-term memory [CHANGELOG.md11](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L11-L11)
 - **Wiki Mode**: An innovative mode where agents autonomously distill raw documents into interlinked, structured Markdown wiki pages with an interactive knowledge graph visualization [README.md53](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L53-L53) manual editing, revision history, and one-click rollback [README.md60](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L60-L60)

## Multimodal Document Processing and Parsing

 WeKnora supports rich multimodal content processing across documents and agent interactions:

 
 - **In-Process anydoc Parser**: Office documents (doc, docx, ppt, pptx) are parsed directly inside the Go application via `third_party/anydoc-go` without requiring an external docreader round-trip [CHANGELOG.md12](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L12-L12)
 - **Image Processing and OCR**: Supports PDF scanned-page OCR override, embedded image SMask recovery, and PaddleOCR-VL or VLM integration [CHANGELOG.md32](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L32-L32)
 - **ASR (Automatic Speech Recognition)**: Audio attachments are processed for transcription, indexing, and retrieval [README_CN.md69](https://github.com/Tencent/WeKnora/blob/10973ed3/README_CN.md?plain=1#L69-L69)
 - **VLM Integration**: Vision-Language models analyze tool output images (e.g., from MCP tools), generating textual descriptions appended to the conversation [internal/application/service/agent_service.go203-207](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/agent_service.go#L203-L207)
 - **Multimodal Formats**: Support for EPUB, MHTML, and XMind outline parsing with structure preservation [CHANGELOG.md17](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L17-L17)
 - **Temporary Attachments**: Session-scoped temporary attachments allow one-off Q&A with asynchronous image and document parsing [CHANGELOG.md60](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L60-L60)

## Agent Modes, Runtimes, and ReAct Engine

 WeKnora features advanced agent capabilities powered by the `AgentEngine` and robust runtime sandboxing.

 
### ReAct Reasoning Loop and Memory

 The engine implements a ReAct (Reasoning and Acting) loop, executing iterative reasoning steps [internal/application/service/agent_service.go27](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/agent_service.go#L27-L27) It supports **Cross-Session Long-Term Memory** (`profile`, `preference`, `fact`, `task`, `interest`) with automatic extraction and user confirmation [CHANGELOG.md11](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L11-L11)

 
### Sandbox Runtimes and Tenant Skill Catalog

 
 - **Session-Persistent Sandboxes**: Agent skills and code execution run in session-persistent sandboxes using backends like **Docker**, **E2B**, or **CubeSandbox** managed via `RemoteSandboxClient` [CHANGELOG.md9](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L9-L9) Admins can configure per-workspace network policies (default-deny egress, allow/deny lists) [CHANGELOG.md9](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L9-L9)
 - **Tenant Skill Catalog**: Skills are workspace-scoped resources installable from ClawHub, SkillHub, GitHub/GitLab URLs, or zip uploads [CHANGELOG.md10](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L10-L10) Supports live circular progress, file browsing/editing via `write_skill_file` / `edit_skill_file`, and execution environment variable injection [CHANGELOG.md10](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L10-L10)
 
 
### Tool & MCP Integration

 
 - **Tool Registry**: Manages built-in tools like `ToolKnowledgeSearch` [internal/agent/tools/knowledge_search.go23](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/knowledge_search.go#L23-L23) and `shell_exec` [CHANGELOG.md9](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L9-L9)
 - **MCP (Model Context Protocol)**: Supports remote MCP services with multiple transports (stdio, SSE, HTTP) and mid-conversation OAuth flows [CHANGELOG.md60](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L60-L60)

## Wiki Mode and Knowledge Graph

 WeKnora's Wiki Mode transforms documents into a structured knowledge base:

 
 - **Autonomous Generation**: Agents distill raw document chunks into interlinked Markdown pages [README.md53](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L53-L53) The `wikiIngestService` [internal/application/service/wiki_ingest.go192](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/application/service/wiki_ingest.go#L192-L192) orchestrates this process, using LLMs to extract entities, concepts, and summaries.
 - **Hierarchy & Navigation**: Supports folder trees and directory layout management [README.md62](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L62-L62) The `WikiBrowser.vue` frontend component [frontend/src/views/knowledge/wiki/WikiBrowser.vue1-10](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/wiki/WikiBrowser.vue#L1-L10) provides the UI.
 - **Knowledge Graph**: Generates an interactive graph of entities and relations rendered in `WikiBrowser.vue` [frontend/src/views/knowledge/wiki/WikiBrowser.vue3-114](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/wiki/WikiBrowser.vue#L3-L114)
 - **Wiki Linting and Revision History**: Automated checks for broken links and duplicate slugs, accompanied by snapshots, line-level diffs, and one-click rollbacks [README.md67](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L67-L67)

## Hybrid Retrieval and RAG Pipeline

 The RAG pipeline supports complex retrieval strategies:

 
 - **Multi-Source Fan-out**: Queries search across multiple vector stores concurrently [README_CN.md64](https://github.com/Tencent/WeKnora/blob/10973ed3/README_CN.md?plain=1#L64-L64)
 - **Hybrid Search**: Combines semantic/vector search with BM25 keyword matching [internal/agent/tools/knowledge_search.go24-45](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/agent/tools/knowledge_search.go#L24-L45)
 - **Parent-Child Chunking**: Maintains context by retrieving child chunks while surfacing parent context [README.md72](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L72-L72)
 - **Reranking**: Integrates rerankers like **Volcengine** (with automatic request batching) and **Tencent LKEAP** [CHANGELOG.md10](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L10-L10)
 - **Chunk Editing**: Enables direct UI editing of retrieval chunks with version history, diffing, and automatic reindexing [README.md67](https://github.com/Tencent/WeKnora/blob/10973ed3/README.md?plain=1#L67-L67)

 - **Multi-Instance Storage Backends**: Support for multiple storage instances per workspace with per-KB binding [CHANGELOG.md69](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L69-L69)
 - **Observability**: Full **Langfuse** integration with OTLP/OTel tracing for agent reasoning, pipeline traces, and token usage attribution [CHANGELOG.md15](https://github.com/Tencent/WeKnora/blob/10973ed3/CHANGELOG.md?plain=1#L15-L15)
