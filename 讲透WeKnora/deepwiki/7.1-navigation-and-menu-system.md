## Purpose and Scope

 The Navigation and Menu System serves as the primary structural interface for WeKnora's frontend application (`frontend/`). It manages layout states, collapsible sidebar rendering ([frontend/src/components/menu.vue2-59](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/menu.vue#L2-L59)), workspace switching ([frontend/src/components/TenantSelector.vue1-30](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/TenantSelector.vue#L1-L30)), user profile actions ([frontend/src/components/UserMenu.vue2-30](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/UserMenu.vue#L2-L30)), session list organization ([frontend/src/stores/menu.ts104-163](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/stores/menu.ts#L104-L163)), and client-side routing ([frontend/src/router/index.ts11-200](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/router/index.ts#L11-L200)). This system enforces multi-tenant access control, role-based visibility, and adapts between Standard and `lite` deployment modes.

## Menu Structure, Visibility Rules, and Data Models

 Menu items are centralized inside `useMenuStore` ([frontend/src/stores/menu.ts10-37](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/stores/menu.ts#L10-L37)) and rendered dynamically by `menu.vue` ([frontend/src/components/menu.vue79-101](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/menu.vue#L79-L101)).

 
### Primary Navigation Mapping

 
| Menu Identifier | Icon Resource | Visibility & Access Control Rule | Target View / Route |
|---|---|---|---|
| creatChat | prefixIcon | Always visible; initiates a new conversation session. | /platform/chat |
| knowledge-bases | zhishiku | Always visible; links to document and knowledge base management. | /platform/knowledge-bases |
| agents | agent | Visible if user has agents capability or required role. | /platform/agents |
| organizations | organization | Hidden in lite mode or for users lacking admin permissions; displays pending join request counts (frontend/src/components/menu.vue93-96). | /platform/organizations |
| settings | setting | Always visible; links to configuration dashboards. | /platform/settings |

## Session Management and Routing Structure

 
### Session Management UI

 Chat sessions are grouped and rendered beneath the primary navigation items in `menu.vue` ([frontend/src/components/menu.vue104-113](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/menu.vue#L104-L113)).

 
 - `useMenuStore` provides methods like `updateSessionTitle(sessionId, title)` to dynamically update session headings upon generation or renaming.
 - Contextual actions include session renaming ([frontend/src/i18n/locales/en-US.ts130](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/i18n/locales/en-US.ts#L130-L130)), message clearing ([frontend/src/i18n/locales/en-US.ts127](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/i18n/locales/en-US.ts#L127-L127)), and bucket filtering ([frontend/src/components/menu.vue109-112](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/menu.vue#L109-L112)).

## Global Command Palette and Quick Navigation

 WeKnora features an integrated command search palette accessible across the application:

 
 - Triggered via `Cmd/Ctrl + K` or by clicking the search icon button in the header ([frontend/src/components/menu.vue17-21](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/menu.vue#L17-L21) [frontend/src/components/menu.vue62-78](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/menu.vue#L62-L78)).
 - Managed via `commandPaletteStore`, allowing users to jump directly to resources, knowledge bases, or agents without navigating deep hierarchical menus.
