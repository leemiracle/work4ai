  This page documents the chat interface components, user interaction patterns, streaming response mechanisms, message attachments, tool result rendering, and agent visualization in WeKnora. It covers the frontend UI/UX layer of the chat system, including the input composer, message history layout, RAG pipeline progress, real-time streaming via Server-Sent Events (SSE), and tool output handling.

 For backend query processing logic, see [Knowledge QA Mode](https://deepwiki.com/Tencent/WeKnora/5.2-knowledge-qa-mode) and [Agent Mode and Tool Integration](https://deepwiki.com/Tencent/WeKnora/5.3-agent-mode-and-tool-integration). For session lifecycle management, see [Session Management and Context](https://deepwiki.com/Tencent/WeKnora/5.4-session-management-and-context).

## Architecture Overview

 The chat interface is built with Vue.js and Pinia stores (`frontend/src/stores/settings.ts`), consisting of primary containers for conversation history, user query entry with context selection (`frontend/src/components/Input-field.vue`), assistant response rendering (`frontend/src/views/chat/components/botmsg.vue`), and agent execution stream visualization (`frontend/src/views/chat/components/AgentStreamDisplay.vue`). Messages are delivered via SSE and organized inside the main view container (`frontend/src/views/chat/index.vue`).

## Input Field Component and User Messages

 The input field ([frontend/src/components/Input-field.vue1-61](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/Input-field.vue#L1-L61)) serves as the primary user interaction point for context selection, agent configuration, and query submission. User messages (`[frontend/src/views/chat/components/usermsg.vue:1-70]`) display the submitted text, mentioned items, uploaded images, and file attachments.

 
### Multimodal Input and Attachments

 
 - **Images:** Supported via drag-and-drop or file selection, validated against size/type constraints ([frontend/src/components/Input-field.vue86-155](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/Input-field.vue#L86-L155)), and rendered as thumbnails with click-to-preview via `picturePreview` ([frontend/src/views/chat/components/usermsg.vue16-19](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/usermsg.vue#L16-L19)).
 - **Attachments:** Managed by `AttachmentUpload.vue` and represented on user messages as file cards displaying file extension, size formatting, and preview drawers ([frontend/src/views/chat/components/usermsg.vue21-42](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/usermsg.vue#L21-L42)).
 - **Backend Prompt Construction:** File attachments are serialized and injected into LLM prompts using structured XML format in `MessageAttachments.BuildPrompt()` ([internal/types/message.go98-142](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/types/message.go#L98-L142)), wrapping file metadata and content in `<attachments>` tags with explicit security instructions.

## Assistant Message Rendering and RAG Pipeline Progress

 Assistant messages ([frontend/src/views/chat/components/botmsg.vue1-114](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/botmsg.vue#L1-L114)) manage the display of RAG pipelines, mentioned knowledge items, thinking blocks, markdown content, and action toolbars.

 
### RAG Pipeline Progress Timeline

 The `RagPipelineProgress.vue` component renders retrieval steps (such as search queries, document fetching, and reranking) in a collapsible timeline ([frontend/src/views/chat/components/RagPipelineProgress.vue1-140](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/RagPipelineProgress.vue#L1-L140)).

 
 - **Pre-pipeline Wait & Model Waiting:** Displays pending states while awaiting model connection or response generation ([frontend/src/views/chat/components/RagPipelineProgress.vue21-37](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/RagPipelineProgress.vue#L21-L37), [frontend/src/views/chat/components/RagPipelineProgress.vue86-103](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/RagPipelineProgress.vue#L86-L103)).
 - **Collapsed Root View:** After the answer arrives, the retrieval timeline collapses into a summary header with expansion toggles ([frontend/src/views/chat/components/RagPipelineProgress.vue142-167](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/RagPipelineProgress.vue#L142-L167)).
 - **Memory Row Integration:** Manages conversation memories via `ChatMemoryStep` ([frontend/src/views/chat/components/RagPipelineProgress.vue11-19](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/RagPipelineProgress.vue#L11-L19)).
 
 
### Answer Toolbar & Artifacts

 The answer toolbar provides copy actions, bookmarking into knowledge bases, fallback indicators, and skill artifact drawers. When a skill execution generates files, the `answer-toolbar__artifact` indicator appears with an animated badge displaying the file count ([frontend/src/views/chat/components/botmsg.vue52-81](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/botmsg.vue#L52-L81), [frontend/src/components/css/chat-message-shared.less92-155](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/components/css/chat-message-shared.less#L92-L155)).

## Streaming Response and Agent Visualization

 In Agent Mode, `AgentStreamDisplay.vue` visualizes the agent's ReAct loop execution as a tree of intermediate events ([frontend/src/views/chat/components/AgentStreamDisplay.vue1-123](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/AgentStreamDisplay.vue#L1-L123)).

 
 - **Event Types:** Supports `plan_task_change`, `context_compacted`, `thinking`, `tool_call`, `tool_approval_required`, and MCP OAuth authorization prompts ([frontend/src/views/chat/components/AgentStreamDisplay.vue35-121](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/AgentStreamDisplay.vue#L35-L121)).
 - **Human-in-the-Loop Approval:** Renders `ToolApprovalCard` for pending actions requiring explicit user grant or denial ([frontend/src/views/chat/components/AgentStreamDisplay.vue115-121](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/chat/components/AgentStreamDisplay.vue#L115-L121)).
