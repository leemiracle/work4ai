## System Layer Architecture

 WeKnora adopts a modular multi-tier architecture with strict separation of concerns across presentation, API gateway, handler orchestration, business services, data repositories, and persistent storage layers.

 The dependency injection container builder function `container.BuildContainer` located in `internal/container/container.go` wires all system components together and manages their lifecycles [internal/container/container.go100-108](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/container/container.go#L100-L108)

## Frontend Layer

 The frontend is implemented as a Vue.js Single Page Application (SPA) located in the `frontend/` directory [docker-compose.yml2-14](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.yml#L2-L14) It delivers localized user interfaces for knowledge base curation, chat interactions, agent configuration, and administrative control [frontend/src/views/knowledge/KnowledgeBase.vue1-60](https://github.com/Tencent/WeKnora/blob/10973ed3/frontend/src/views/knowledge/KnowledgeBase.vue#L1-L60)

 
### Frontend Technology Stack

 
| Component Group | Implementation | Description |
|---|---|---|
| Core UI | tdesign-vue-next | Enterprise-grade UI component library |
| State Management | Pinia | Reactive state management for stores (menu, ui, auth, etc.) |
| Internationalization | vue-i18n | Multi-language localization (e.g., zh-CN, en-US, ru-RU, ko-KR, ja-JP) |
| Streaming | @microsoft/fetch-event-source | Server-Sent Events (SSE) handling for real-time chat responses |
| Visualization | mermaid | Knowledge graph and diagram rendering within documents and chats |

## Backend Application Layer

 The backend is a Go application (v1.26+) orchestrating core RAG execution pipelines, autonomous agent reasoning loops, tool registries, and sandboxed execution environments [go.mod1-5](https://github.com/Tencent/WeKnora/blob/10973ed3/go.mod#L1-L5)

 
### Dependency Injection Container (`internal/container/container.go`)

 The application container uses `uber/dig` to register and resolve dependencies [go.mod79](https://github.com/Tencent/WeKnora/blob/10973ed3/go.mod#L79-L79):

 
 - **Core Infrastructure**: `config.LoadConfig`, `initLangfuse`, `initDatabase`, `initRedisClient`, and `initAntsPool` for high-performance goroutine management [internal/container/container.go117-127](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/container/container.go#L117-L127)
 - **External Clients**: `initDocReaderClient` for gRPC document parsing and `initOllamaService` for local LLM integration [internal/container/container.go139-141](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/container/container.go#L139-L141)
 - **Search Registry**: `initRetrieveEngineRegistry` for managing multi-backend vector retrieval drivers [internal/container/container.go135](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/container/container.go#L135-L135)
 
 
### Key API Handlers and Routing

 Routing is initialized in `internal/router/router.go` via `NewRouter` receiving `RouterParams` injected from the `dig` container [internal/router/router.go28-94](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/router/router.go#L28-L94) Key domains include:

 
 - **Knowledge Management**: `handler.KnowledgeBaseHandler`, `handler.KnowledgeHandler`, `handler.ChunkHandler`, `handler.FAQHandler`, `handler.TagHandler`.
 - **Chat and Sessions**: `session.Handler`, `handler.MessageHandler`, `handler.MessageSuggestionHandler`.
 - **System and Administration**: `handler.TenantHandler`, `handler.AuditLogHandler`, `handler.ModelHandler`, `handler.SystemHandler`.
 - **Advanced Tools**: `handler.SkillHandler`, `handler.SandboxConfigHandler`, `handler.MCPServiceHandler`, `handler.WebSearchHandler`.

## External Integrations & Advanced Subsystems

 
### Document Processing & Parsers

 
 - **DocReader**: External gRPC microservice parsing complex documents (`DOCREADER_ADDR`, `DOCREADER_TRANSPORT`) [.env.example94-96](https://github.com/Tencent/WeKnora/blob/10973ed3/.env.example#L94-L96)
 - **anydoc**: In-process Office document parser (`WITH_ANYDOC=1`) embedded within the Go application for parsing doc, docx, ppt, and pptx files [.env.example37](https://github.com/Tencent/WeKnora/blob/10973ed3/.env.example#L37-L37)
 
 
### Sandbox Runtimes & Skill Catalog

 
 - **Sandbox Backends**: Session-persistent code execution backends supporting **Docker Engine API**, **E2B**, and **CubeSandbox** sharing a unified client protocol [go.mod38-63](https://github.com/Tencent/WeKnora/blob/10973ed3/go.mod#L38-L63)
 - **Tenant Skill Catalog**: Workspace resource management enabling the installation of skills from ClawHub, SkillHub, Git repositories, or ZIP bundles with background cleanup and transcript management.
 
 
### Agent Tools and Connectors

 
 - **MCP Server**: Implements the Model Context Protocol (`github.com/mark3labs/mcp-go`) for secure external tool integration [go.mod37](https://github.com/Tencent/WeKnora/blob/10973ed3/go.mod#L37-L37)
 - **Web Search**: Integrates web search providers like DuckDuckGo, Exa, Metaso, and Zhipu AI.
 - **Connectors**: Automated data connectors for Feishu (Docs/Wiki), GitLab, Notion, Yuque, RSS feeds, and web crawlers [internal/container/container.go58-68](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/container/container.go#L58-L68)

 Full-chain tracing is provided via Langfuse tracking LLM calls, token usage, and RAG pipeline spans, built on OpenTelemetry OTLP exporters [go.mod75-78](https://github.com/Tencent/WeKnora/blob/10973ed3/go.mod#L75-L78) [docker-compose.yml146-150](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.yml#L146-L150)

## Summary

 The WeKnora system integrates several cohesive subsystems:

 
 - **Frontend (Vue.js SPA)** provides responsive interfaces for Knowledge Bases, Chat, and Agent configuration.
 - **Backend (Go / Gin / Dig)** coordinates the RAG pipeline, REST APIs, event bus, and asynchronous task execution via Asynq.
 - **Storage & Vector Engines** support multi-backend flexibility across PostgreSQL, Redis, Neo4j, and numerous vector stores via `RetrieveEngineRegistry`.
 - **Sandbox & Skills** deliver secure code execution and modular extensibility for autonomous agents.
