## Purpose and Scope

 This document details the step-by-step instructions for installing and deploying WeKnora using Docker Compose. It covers system requirements, environment configuration via `.env`, service profile selection for optional components, container dependency orchestration, and image architecture.

## Deployment Overview

 WeKnora deployment utilizes containerized microservices managed via Docker Compose. The core architecture comprises the Vue.js frontend, Go backend application, ParadeDB (PostgreSQL 17 with extensions), Redis, and DocReader.

 The `app` container loads environment variables through the `env_file` directive in [docker-compose.yml75-76](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.yml#L75-L76). ## Step 3: Understanding Service Profiles

 Optional subsystems are controlled via Docker Compose profiles:

 
 - `minio`: S3-compatible object storage [docker-compose.dev.yml84-106](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.dev.yml#L84-L106)
 - `qdrant`, `milvus`, `weaviate`, `doris`: Alternative vector retrieval engines [docker-compose.dev.yml107-121](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.dev.yml#L107-L121) [docker-compose.dev.yml177-205](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.dev.yml#L177-L205)
 - `neo4j`: Knowledge graph storage [docker-compose.dev.yml206-213](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.dev.yml#L206-L213)
 - `langfuse`: Observability platform [internal/container/container.go122](https://github.com/Tencent/WeKnora/blob/10973ed3/internal/container/container.go#L122-L122)
 - `searxng`: Web search provider [docker-compose.dev.yml54-82](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.dev.yml#L54-L82)

## Step 4: Service Dependencies and Startup Order

 Container sequencing relies on health check conditions to ensure dependent services are fully initialized.

 
```

```

 
 - The `app` service waits for `postgres` and `docreader` health states ([docker-compose.yml29-34](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.yml#L29-L34)).
 - The `frontend` service depends on `app` health ([docker-compose.yml29-31](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.yml#L29-L31)).
 - Application readiness is verified via `GET /health` ([docker-compose.yml59-64](https://github.com/Tencent/WeKnora/blob/10973ed3/docker-compose.yml#L59-L64)).
