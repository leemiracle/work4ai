# 讲透递归论 · 什么是「可计算」:从 λ 到图灵机到不可判定地图

> **定位句:这支负责给「算法」下数学定义,然后立刻画出算法迈不过去的墙。**
> GB/T 11014 三级「递归论(可计算性理论)」｜家族:[讲透数理逻辑](../README.md)
>
> 1936 年,三个互不相识的年轻人各自给出「可计算」的定义:Church(λ 演算)、
> Gödel(一般递归)、Turing(图灵机)——结果全部等价。Turing 的论文顺便发明了
> 「存储程序计算机」(通用图灵机),并证明**停机问题不可判定**:
> 计算机的出生证明与第一张禁令,印在同一篇论文里。

## 核心问题

已解决:
- Church–Turing 论题的可操作化:可计算 = 图灵可算(一切合理模型等价)
- 停机问题不可判定;对角化方法确立
- 递归可枚举(r.e.)与递归的区分;停机集 r.e. 而非递归
- 算术层级 Σₙ/Πₙ:不可判定也分层,「更不可判定」有严格意义
- 度理论:不可判定问题之间的归约偏序(Turing 度)

未解决/进行中:
- r.e. 度的结构全局图(如 Sacks 猜想类问题)
- 反推数学:一条定理需要多强的存在公理(与证明论交界)
- 算法信息论(Kolmogorov 复杂度)的随机性定义之争

## 这支最美的一个事实

**✨ 通用图灵机**:存在一台机器 U,读入「程序+数据」就能模拟任何机器——
**软件**这个概念在数学上的一刻诞生。可数台机器的对角化表格,
既是停机不可判定的证明现场,也是「解释器/虚拟机/DSL」的祖师爷。
(亲历:家族 04 章走廊 D;或写 20 行 Python 的迷你解释器。)

## 假设与依赖

- Church–Turing 论题是**定义不是定理**(不可证明;物理超计算是开放话题)
- 「可计算」默认处理自然数/有限符号串;连续对象的版本=可计算分析(→../../讲透分析/ 04 章)
