# 02 · 语言特征:推理的语言能说什么、不能说什么

> **本章回答五问之三(家族层):表达力?逻辑性质?规范化程度?**
> 本质一句话:**数理逻辑的语言是一台「故意造得保守」的机器**——
> 说得越少,可推得越多;每一点表达力都是拿可判定性换的。

---

## 〇、先给直觉:为什么「说不出话」是优点?

想象一个证人,只会回答三种问题:「是」「不是」「看情况(存在某对象使…)」。
你嫌他笨——他连「案发时只有有限个人在场」都说不清楚。
但正因为**说不清楚**,关于他的证词我们有一整套完备的法律程序:
**所有能说的陈述,都能机械地判定能否从前提推出**(Gödel 完备性定理)。

一阶逻辑(First-Order Logic, FO)就是这位证人。它只会:
- 谈论**个体**(`x, y, z`)与它们的性质/关系(`P(x)`, `R(x,y)`);
- 用量词说「所有/存在」(`∀x ∃y`);
- 用联结词组合(`∧ ∨ ¬ → ↔`)。

就这么多。下面三栏逐一解剖:它能说什么(表达力)、它推理的秉性(逻辑性质)、
它给全数学定下的语言等级(规范化程度)。

## 一、第一栏:表达力(能说什么/不能说什么)

### 能说(样例)

| 想说的 | 一阶句子 |
|--------|---------|
| 群公理 | `∀x∀y∀z (x∘y)∘z = x∘y∘z ∧ ∀e …`(三条) |
| 「≤ 是全序」 | `∀x∀y x≤y ∨ y≤x` + 反对称 + 传递 |
| 实闭域(Tarski) | 有序域 + 每个奇次多项式有根 + 每个正数有平方根 |
| 「存在无穷多素数」 | 无穷句集 `{∃n: n>2 ∧ n 是素数}` |
| 图不连通 | `∃x∃y ¬(x∼*y)`(可达性要无穷公理组) |

### 不能说(著名失语症)

| 想说的 | 为什么说不 出 |
|--------|--------------|
| 「X 是有限的」 | FO 只能说「至多 n 个」(每个 n 一句),说不出「存在一个上界」 |
| 「G 与 H 同构」 | 同构要说「存在双射 f 使…」——量词不能跑在**函数**上 |
| 「连续统假设」 | 涉及「所有子集」;量词只能跑在元素上,不能跑在子集上 |
| 「本结构自身的基数」 | 被下面第二个反直觉锁死 |

> **直觉→严格→例子 三步法**:「量词只能量化个体」这句话的直觉是——
> 证人只见过村民,没见过「村民名单」。严格陈述:一阶量词只约束个体变元,
> 不约束谓词/函数/集合变元(那是二阶逻辑 SOL 的地盘)。最小例子:
> 「每个非空子集有最小元」(良序)在 FO 里**一个句子写不下**,必须无穷多条。

### 反直觉发现:一阶逻辑「看不见」基数(Löwenheim–Skolem)

**定理(LST,向下的 LS)**:若一句话集有**任意大**的无限模型,那它必有**每个无限基数**
大小的模型——包括可数个!

**实例**:ZFC 有模型 ⟹ ZFC 有**可数模型**。但 ZFC 能证明「存在不可数集合」。
可数模型里「不可数」的集合,从外面数是可数的——因为「x 不可数」说的是
「**不存在把 x 数完的双射**」,而模型里的「双射」库存不足。
**「不可数」是一阶句子在模型内部说的一句真话,外部数起来可以撒谎。**

📖 Skolem 1923 就预言这会是「集合论的终身尴尬」;它直接孕育了 Skolem 悖论
与后来的非标准分析(模型论支详)。

### 表达力的价目表

| 语言 | 表达力 | 代价 |
|------|--------|------|
| 命题逻辑 | 真值函数 | 连「存在」都说不 出;可判定 |
| 一阶逻辑 FO | 个体+量词 | 半可判定(定理集递归可枚举);不可判定 |
| 二阶逻辑 SOL | 量词跑在关系上 | **没有完备的证明系统**;紧致性失效 |
| 无穷逻辑 L∞ω | 无穷长句子 | 与集合论纠缠;几乎无模型论工具 |

**规律:每上一级台阶,买表达力,卖完备性/紧致性/可判定性。** 这就是
「故意造得保守」的含义。

## 二、第二栏:逻辑性质(推理的秉性)

| 性质 | 一阶逻辑 | 为什么是这样(不是罗列) |
|------|---------|------------------------|
| **可靠性** Soundness | ✓ 可证 ⟹ 真 | 证明规则保守:只许沿保真方向走,想错都难 |
| **完备性** Completeness | ✓ 真(语义有效)⟹ 可证 | Gödel 1929:证明系统不多不少——推理规则清单恰好穷尽了「真」 |
| **紧致性** Compactness | ✓ 句集每个有限子集可满足 ⟹ 全体可满足 | 证明靠超积/超滤:把无限问题压成有限片的「极限」;00 章对角化之外的第二个跨支血液 |
| **LST** | ✓ | 见上文反直觉 |
| **不完备性**(针对算术) | ✗ PA(及更强系统)有真不可证句 | 对角化:把「证明」本身编码进算术;注意与「完备性」不矛盾——完备性谈**逻辑有效**,不完备性谈**算术真理** |
| **可判定性** | ✗ FO 有效式不可判定(Church–Turing 1936);但命题逻辑可判定 | 递归论支:一旦语言富到能谈自然数,停机问题就藏进来 |

> ✨ **美之时刻 2|Gödel 编码**:为什么美?**统一**——把「证明」(语法对象)
> 编码成自然数,让算术(语义世界)能够**谈论自己的证明系统**,
> 不完备定理 = 算术照镜子。怎么亲历:Gödel 句 G ≡「G 的 Gödel 数不是某证明的
> 结论的 Gödel 数」——亲手展开这一定义一遍(纸笔 20 分钟),
> 你会经历「自指不爆炸」的瞬间:G 说的是**数字**间的关系,只是这个关系恰好刻画证明。

## 三、第三栏:规范化程度(全数学的语言等级)

本家族给全宇宙的分支发「规范化牌照」。从裸语言到机器可检,五级:

| 级 | 形态 | 例子(宇宙内) |
|----|------|--------------|
| L0 | 自然语言论证 | 大部分教材/论文 |
| L1 | 非形式公理化(概念+公理,推理仍靠人) | 群/拓扑/测度的本科定义 |
| L2 | 一阶公理化 | ZFC(../讲透集合/)、PA、群公理 |
| L3 | 形式系统+证明论账本 | Gentzen 自然演绎/序贯演算(../讲透证明/) |
| L4 | 机器可检(依赖类型论) | Lean 4 + mathlib(../讲透Lean4数学/) |

**读法**:一个分支的「公理化到哪一级」= 它离 L4 有多远。分析家族的多数分支
在 L1-L2;数理逻辑自家分支全部到 L2,证明论/Lean 天生 L3/L4——
**本家族是宇宙里唯一把牌照发到 L4 的**。

## 四、假设与代价(本章补遗)

| 选择 | 买到 | 卖掉 |
|------|------|------|
| 只用 FO | 完备+紧致+LST 整套模型论 | 良序/有限性/CH 全部失语 |
| 用 SOL 表达数学 | 一次说清「极小闭包」类概念 | 无完备证明系统——推理退回人肉 |
| 把 PA 形式化 | 不完备定理适用的最小舞台 | 「真」与「可证」永久裂开一道缝 |
