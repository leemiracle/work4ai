# 讲透数学基础 · 三大流派的世纪之争与 ZFC 的边界

> **定位句:这支负责追问「数学的房子盖在哪」**——地基检测报告的持有者。
> GB/T 11014 三级「数学基础」｜家族:[讲透数理逻辑](../README.md)
>
> 1900 年 Hilbert 站上巴黎讲台问:「谁能解开连续统假设?」60 年后答案揭晓:
> Cohen 用力迫法证明 CH **独立**于 ZFC——「真值」从此成了信仰问题。
> 这支就是那场世纪争论(逻辑主义/形式主义/直觉主义)与今天地基工程的编年史。

## 核心问题

已解决:
- 三大流派的纲领边界:逻辑主义(Frege–Russell)被悖论击伤、由 ZFC 续命;
  形式主义(Hilbert 纲领)被不完备定理限位;直觉主义(Brouwer)存活为构造性数学
- CH 独立(Gödel L,1938;Cohen 力迫,1963)——地基不止一种,等你说完再选
- 相对一致性方法:Con(ZF) ⟹ Con(ZFC+CH) 等(Zermelo/Gödel 传统)

未解决/进行中:
- 「新公理」之战:力迫公理(PFA 判 ¬CH)vs 内在模型计划(Ultimate L 判 CH)——Woodin 纲领
- HoTT/单值基础(Univalent Foundations)能否成为下一代地基(方向锚)
- 大基数层谱的内模型覆盖(每加一层大基数,L 要长出多少肉)

## 这支最美的一个事实

**✨ 独立性=「地基可选」的宣告**:连续统假设不是「不知道真假」,
而是**ZFC 这套公理本来就没规定**——你住在 ZFC+CH 的房子和 ZFC+¬CH 的房子都合法,
房价(定理)95% 相同。数学第一次显式展示「公理是**选择**而非**发现**」。
(亲历:读 Gödel 1938 论文前两页——可构造宇宙 L 的定义只有一个自然段。)
