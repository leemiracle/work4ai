# 讲透演绎逻辑学 · 推理规则的形式化:从三段论到概念文字

> **定位句:这支负责「推理本身能不能算」**——把「如果…那么…」从修辞变成符号演算。
> GB/T 11014 三级「演绎逻辑学(亦称符号逻辑学)」｜家族:[讲透数理逻辑](../README.md)
>
> 1879 年 Frege《概念文字》(Begriffsschrift)用二维符号把推理写成机械操作——
> 罗素称它「自 Aristotle 以来逻辑学最重要的进步」。三百年前莱布尼茨之梦
> 「吵架时拿出纸笔算一算」第一次有了可用的字母表。

## 核心问题

已解决:
- 一阶语言的语法与严格语义(Tarski 真值定义,1933)
- 可靠性与完备性:可证 ⟺ 逻辑有效(Gödel,1929)
- 范式定理:每个命题公式有唯一的规范形(电路综合的理论根基)

未解决/进行中:
- 非经典逻辑(模态/线性/直觉)各自的可判定性与复杂度精细图
- 一阶逻辑片段(两变元片段 FO²、保词片段等)的可判定孤岛测绘(SMT 理论菜单的来源)

## 这支最美的一个事实

**✨ 完备性定理说:推理规则清单「不多不少」**——教科书里那十几条推理规则,
恰好穷尽了「在一切可能结构里都真」的全体规律。规则清单是一台刚好够用的机器:
少一条漏掉真理,多一条产假真理。(亲历:对 ⊨ 与 ⊢ 各写一个最小例子,体会两者咬合。)

## 假设与依赖

- 站在「真值函数语义」上(经典二值);换成多值/直觉语义,规则清单随之改变
- 一阶量词只量化个体(表达力价目表的起点,家族 02 章)
