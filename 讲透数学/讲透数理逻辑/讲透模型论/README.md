# 讲透模型论 · 真值住在哪个结构里:造模型的工厂

> **定位句:这支负责「句子与结构的配对市场」**——同一句话在不同结构里真值不同,
> 模型论研究这个市场的规律:什么时候必有买主(可满足),什么时候两个结构「看起来一样」(初等等价)。
> GB/T 11014 三级「模型论」｜家族:[讲透数理逻辑](../README.md)
>
> Tarski 学派(1930s)创立。1950s 起「模型论=代数的显微镜」:
> Ax–Grothendieck(代数几何命题经超积从有限域搬到特征 0)、
> Robinson 造出 *ℝ(1960,非标准分析的出生)、Shelah 谱系定理(分类理论,1970s)。

## 核心问题

已解决:
- 紧致性 + LST + 完备性:一阶模型论三脚架
- 量词消去:Presburger、实闭域(Tarski)、代数闭域——「可判定孤岛」的制造机
- Keisler–Shelah:初等等价 ⟺ 同构超幂(超积的判据地位)
- 分类理论(Shelah):理论按稳定性分类,决定其模型谱的形状

未解决/进行中:
- 简单理论(simple theories)与非交换几何的对应(Zilber 猜想系)
- o-minimal 结构的丢番图应用深化(André–Oort 型定理;家族 01 章主线二)
- 模型论×算子代数(C*-dynamics 一脉)

## 这支最美的一个事实

**✨ 紧致性造无穷小**:给实数理论加一句「存在大于一切标准自然数的 N」,
每个有限子集都在 ℝ 里有模型(有限的「一切」够用),紧致性给出整体模型——
**含无穷小的 *ℝ 就这样被「造」出来了**。
不可构造的存在(家族 03 章)在这里不是污点,是产品线。
(亲历:写出该无穷公理组,亲手验证每个有限子集可满足——20 分钟纸笔。)
