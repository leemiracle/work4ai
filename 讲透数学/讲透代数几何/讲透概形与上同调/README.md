# 讲透概形与上同调 · 现代语言:几何的操作系统

> **定位句**:这支负责「怎么说」——概形、层、上同调,
> Grothendieck 重建的地基;现代代数几何、算术几何与几何表示论的公共操作系统。
> 〔自定主干支 · GB/T 11024 未列三级,本家族按学科内在结构划支〕
> 家族:[讲透代数几何](../README.md) · 五问模板家族成员

## 诞生

- 1955–1967:Grothendieck 以 EGA/SGA 为舞台,把「空间」重定义为
  带结构层的环化空间(X,𝒪_X),再进一步=它代表的全变形函子——
  动机:Weil 猜想需要一个在**任意基域**上都好用的上同调(étale 上同调),
  为此整个几何必须重写。
- 1974 Deligne 用这套语言证明 Weil 猜想收官——语言自证其身。

## 核心问题

**已解决**
- Weil 猜想(Deligne 1974):有限域点计数 ζ 函数=上同调的语言
- 概形论的完备工具链:层/态射/平坦/正规/固有等性质的完备刻画
- 对偶理论(Grothendieck–Serre)与六函子形式体系

**未解决/进行中**
- Motives 统一理论:所有上同调的公共母体(Grothendieck 圣杯,未完工)
- 导出代数几何/棱镜上同调(Bhatt–Scholze 线)持续改写「上同调」本身
- 几何 Langlands 的技术遗产标准化(见家族 01 章热线①)

## 这支最美的一个事实

`Spec ℤ`——全体素数排成一条「数轴」,每个素数是一个闭点,
零理想是一般点:数论的地基被证明**本身就是一个代数簇式的几何对象**。

## 假设与依赖

- 允许「点=素理想」的抽象;依赖交换代数(环/模/局部化)与点集拓扑(层论);
  收益:族、非闭域、退化情形全吃进同一框架。
