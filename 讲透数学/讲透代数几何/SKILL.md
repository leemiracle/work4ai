# 代数几何思维技能卡

## ① 何时用此分支(触发特征)

- 问题里出现**多项式方程组**,且关心的不是单个解而是**解集的整体**
  (有几个分量/交点/洞;随参数怎么变)
- 谈到**椭圆曲线、双线性配对、ECC/后量子同源**等曲线密码话题
- 要问「方程有没有**有理数/整数**解、有多少」(算术几何:有理点/Mordell/高度)
- 需要**Groebner 基/理想运算/符号消元**做机器求解或定理机器证明
- 读到概形(scheme)、层(sheaf)、上同调、模空间等现代几何语言需要解码
- 遇到「形状的分类」问题(曲线按亏格、曲面按双有理类型)

## ② 核心思维模式

1. **整体观**:丢掉单个解,看解集的形状与不变量(亏格/上同调/相交数)。
2. **对译**:方程 ↔ 几何来回翻译(坐标环/Nullstellensatz);
   几何卡住时译回代数,反之亦然。
3. **相对化**:不问「X 是什么」,问「族 X→S 怎么变」——把变化本身当对象。
4. **分级刚性**:先问手里不变量的硬度(拓扑 < 上同调 < 周环 < motive),
   再说「同/不同」。
5. **基域意识**:结论依赖基域(代数闭?特征?ℚ?)——换基域,定理与可计算性都会变。

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| Bezout 定理 | 数两条曲线交点(次数×次数,计重数/复点/无穷远) |
| Nullstellensatz | 判定方程组在代数闭域上是否有解(1∈理想 ⟺ 无解) |
| Groebner 基 | 理想成员判定/消元/解多项式系统(注意双指数复杂度) |
| Riemann-Roch | 曲线上函数空间计数;理解 Weierstrass 形式从哪来 |
| 亏格 + Faltings(Mordell) | 亏格 ≥2 ⟹ 有理点有限——先看亏格再谈整数解 |
| Hasse/Weil 界 | 有限域点计数的理论区间——工程参数校验的 cheap check |
| 椭圆曲线群律 | 曲线上点加(割线/切线);ECC/配对的内核 |

## ④ 常见误区与禁忌

- 把「代数曲线」当光滑实曲线看——它是(常为复的、射影的)整体对象,
  实图只是投影;交点数要在代数闭域+射影化里数。
- 忘查**判别式/奇点**:4a³+27b²=0 的「椭圆曲线」群律崩塌(密码学死亡区)。
- 在 ℚ/ℤ 上直接搬代数闭域的结论(有解判定/交点数)——基域不同,定理不通用;
  ℤ 上解存在性**不可判定**(Matiyasevich),ℚ 上开放。
- 把「有限个」当「可列出」——Mordell 给存在性,不给可计算的界。
