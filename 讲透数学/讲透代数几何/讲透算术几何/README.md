# 讲透算术几何 · 方程遇上整数:有理点的科学

> **定位句**:这支负责「数域上的几何」——多项式方程的**有理数/整数解**:
> 有没有、有几个、怎么分布、怎么算。
> 〔自定主干支 · GB/T 11024 未列三级,本家族按学科内在结构划支〕
> 家族:[讲透代数几何](../README.md) · 五问模板家族成员

## 诞生

- 古源:丢番图《算术》(约公元 250 年)——「在分数里解方程」的祖训。
- 1922 Mordell 定理:椭圆曲线的有理点群有限生成;
  1928 升级为 **Mordell 猜想**(亏格 ≥2 ⟹ 有理点有限)——本支的百年主线。
- 1983 Faltings 证明 Mordell 猜想;1984 Frey 把 FLT 曲线塞进椭圆曲线,
  1986 Ribet 证明其模性蕴含 FLT,1994–95 Wiles(与 Taylor)补完模性桥
  ——**费马大定理的 357 年终局就是算术几何的加冕礼**。

## 核心问题

**已解决**
- Mordell 猜想(Faltings 1983;新证 Lawrence–Venkatesh 2022,见家族 01 章热线③)
- FLT(Wiles 1994):半稳定椭圆曲线模性路线
- Hasse–Minkowski:二次型有理可解性的局部-全局判别

**未解决/进行中**
- **BSD 猜想**(千禧七问):椭圆曲线秩与 L 函数 s=1 行为的对译
- 有效 Mordell:给出可计算的有理点界(「有限」≠「可列」)
- abc 猜想(争议中)、有理点的一致界(Uniformity,飞扶壁计划线)

## 这支最美的一个事实

椭圆曲线的全体有理点构成一个**有限生成的交换群**(Mordell 1922)——
方程的整数解不再是一盘散沙,而是一个有秩、有挠的结构化社会。

## 假设与依赖

- 基域是 ℚ 或数域(非代数闭!)——几何定理必须「下降」后才有意义;
- 依赖概形语言(二楼)+ 类域论/伽罗瓦表示(数论侧)。
