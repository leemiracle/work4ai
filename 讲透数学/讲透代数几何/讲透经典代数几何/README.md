## 诞生

- 古希腊:阿波罗尼奥斯的圆锥曲线——**形状先于方程**两千年。
- 1637 笛卡尔坐标系:方程 ↔ 曲线对译术问世。
- 1704 牛顿将三次曲线分 72 类;十九世纪意大利学派
  (Castelnuova/Enriques/Severi)把双有理分类推到高峰,直觉过度引发 rigor 危机——
  本支的「经典」二字,既是宝藏(直觉)也是教训(重建地基的需求催生了概形)。

## 核心问题

**已解决**
- 亏格是双有理不变量;曲线按亏格完全分类(g=0 有理曲线/1 椭圆/≥2 一般型)
- Bezout 定理:交点数=次数之积(射影化+计重数)
- 奇点溶解:任意曲线双有理等价于光滑曲线(正规化)

**未解决/进行中**
- 曲面的双有理分类完成(意大利学派+Kodaira 维数框架),高维(MMP)仍在推进——见家族 01 章热线②
- 实代数几何:实平面上 H₁⁶ 曲线最多几个卵形?({H16 问题},部分纪录持续刷新)

## 这支最美的一个事实

光滑三次曲面上恰好有 **27 条直线**(Schläfli 1858)——
不多不少,连同其组合模式(E₆)被曲面形状完全锁定。

## 假设与依赖

- 基域代数闭(复数最佳)——实点只是投影;依赖交换代数(理想/根式/局部化)。

- Fischer《Plane Algebraic Curves》 · Reid《Undergraduate Algebraic Geometry》
