# 00 - 群论是什么：对称性的代数

> 群论是**对称性的语言**。本章用 3 个例子让你"看见"群。

---

**1832 年 5 月 29 日夜，巴黎。** 20 岁的 Évariste Galois 知道自己活不过明天清晨——一场动机至今成谜的决斗已定。他通宵疾书，把过去五年被 Cauchy 抄丢、被 Fourier 带进坟墓、被 Poisson 退回的"五次方程"手稿重写一遍，在页边反复写下 *Je n'ai pas le temps*（我没有时间）。他要做的事听起来无害：用"对称性的群"判断一个多项式能否用根式求解。但他真正留下的，是把"对称"从几何直觉变成了**可计算的代数结构**——群。次日凌晨他中弹身亡，手稿由友人 Chevalier 整理、14 年后才被 Liouville 发表、震动数学界。群论的全部起点，是一个 20 岁青年的最后一夜。

---

## 一、直觉：3 个对称的例子

### 1.1 等边三角形的对称 $D_3$

哪些操作让三角形"看起来一样"？6 个：恒等 / 旋转 120° / 旋转 240° / 3 条中线翻转。它们构成**群** $D_3$。

4 条性质：**封闭** + **单位** + **逆** + **结合** = 群的定义。

### 1.2 整数加法群 $\mathbb{Z}$

无限 Abel 群。

### 1.3 钟表群 $\mathbb{Z}/12\mathbb{Z}$

$7 + 8 = 3$（mod 12）。**有限**循环群。

**反直觉**：群可以有限。有限群是抽象代数的核心。

---

## 二、数学：群的定义 + Lagrange 定理

### 2.1 定义

群 $(G, \cdot)$：结合律 + 单位元 + 逆元。满足交换律则 Abel。

### 2.2 阶 / 子群

$|G|$ = 元素数。$H \leq G$ 是子群。

### 2.3 Lagrange 定理 ⭐

**定理**：有限群 $G$，子群 $H$，则 $|H|$ 整除 $|G|$。

**反直觉**：6 阶群没有 4 阶子群（4 不整除 6）。

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我最初以为"群的封闭性"是显然的废话——两个东西运算完还在群里，这不是定义的一部分吗？重读后发现：**封闭性是约束，不是必然**。两个整数相乘还是整数（封闭），但两个无理数相加可能是整数（破坏封闭性）。群的封闭性是对"运算"的约束，不是"集合"的属性。
- **F3 术语翻译**：
  - "群的单位元" → 那个"和谁结合都等于谁自己"的元素（整数加群里是 0，钟表加群里是 12 点即 0 点）
  - "Abel 群（交换群）" → 运算顺序无关的群，像穿袜子左右脚可以换（但穿鞋袜不行）
  - "同构" → 两个群表面符号不同但结构完全一样，像"1,2,3"和"一,二,三"是同一回事
- **F4 回炉**：v1 把群论写成"对称性的语言"直接讲 3 个例子；v2 加 Galois 故事后才意识到"对称性的语言"是结果不是起点——起点是"多项式能否根式求解"这个具体问题。冲突在前，定义在后，故事才讲得通。

## 反模式 5 条（L4 工程化）

1. **把群论当抽象装饰** → 说"对称性"就完事，不计算。正解：每个群论概念必须配一个具体群（$D_3$ / $\mathbb{Z}/n\mathbb{Z}$ / 对称群 $S_n$）验证。
2. **混淆群与集合** → 群是"集合 + 运算"，缺一不可。$\mathbb{Z}$ 配加法是群，配乘法不是（无逆）。
3. **忽视有限群** → 只学无限群（$\mathbb{Z}$, $\mathbb{R}$）。正解：有限群（如 $\mathbb{Z}/7\mathbb{Z}$）是密码学/编码论的地基。
4. **Abel 群当默认** → 大多数重要群（$S_n$、$GL(n)$）非交换。矩阵乘法不交换 = 群论为什么有"非 Abel"分类。
5. **跳过同构直接抽象** → 不具体算两个群同构就谈结构。正解：先算 $\mathbb{Z}/4\mathbb{Z} \cong$ 4 阶旋转群，再谈抽象。
