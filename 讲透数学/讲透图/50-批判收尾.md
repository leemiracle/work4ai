# 50 · 批判收尾：图的边界

> 全系列 34 章讲"图能干什么"。最后一章讲三件事：**图不能干什么**、图方法的三难困境、以及无结构数据的反击。
>
> 复杂系统视角：图是"关系的形式化"——但形式化即减损。知道减损了什么，才知道图模型的适用域。

---

## 一、关系≠全可图化：四种"图化失真"

1. **关系有强弱，边是二值的**：加权图是补丁，但"闺蜜/熟人/点头之交"的语义梯度没有天然边权（社会学的老问题：Granovetter 弱连接理论在图模型里被压扁成实数）
2. **关系有方向与时间**：对话（交替）、引用（滞后）、感染（因果）——静态无向图把时序碾平；时序图（27 章）是正确但昂贵的方向
3. **关系有语境**：A 和 B 在工作是上下级、在球场是队友、在家族是姻亲——**多重图/异质图（27 章）**是对语境的承认，但"多少层才算画完"没有原则性答案
4. **最重要的关系可能是潜藏的**：因果图（37 章）里，相关之边易得、因果之边难证——把可见关系图误当因果结构，是图思维的最高级误用

## 二、图方法的三难困境（expressivity–complexity–scalability）

```
        表达力（能表示/能分辨）
              /\
             /  \
            /    \
   复杂度 ——●—————— 可扩展性
```

- **1-WL/GNN**：可扩展满分（线性）、表达力及格（23 章的天花板）
- **k-WL**：表达力上阶梯、复杂度跳悬崖（n^k）
- **全图精确方法**（同构判定/精确推断）：表达力满、规模上死于组合爆炸
- **没有免费午餐**：三难的松弛点选取就是每个研究方向的出生地（谱方法=用代数结构买复杂度折扣；采样=用无偏性买规模；子结构注入=用特征工程买表达力）

**这个三角与本库其他三角的同构性**：讲透高性能计算的 roofline（算力-带宽-内存）、讲透Loop 的速度-质量-遗忘——**工程学科的成熟标志是找到自己的"不可能三角"并给出松弛谱系**。图学科的三角是 Xu、Morris 一代人在 2019-2024 逐步显影的，仍在显影中。

## 三、无结构数据的反击

图方法 presuppose：结构重要。但两条反击线值得敬畏：

1. **Transformer 的教训**：在序列上，注意力机制**不建图也学到了关系**（全连接注意力=隐式全图）——GNN 在 NLP 领地几乎全面失守；graph transformer（28 章几何深度学习的内部论战）正在把这场战争打到图自己的主场：位置编码 vs 消息传递的路线之争未分胜负
2. **Scaling 的钝感力**：暴力规模化的 MLP/Transformer 在很多图任务上逼近精细 GNN——**结构归纳偏置在小数据是杠杆、在大数据是枷锁**（GNN 的甜区：分子/物理模拟等结构本质、数据贵的领域）

## 四、给实践者的决策清单

| 场景 | 用图吗 | 用什么 |
|---|---|---|
| 分子/材料（关系本质+数据贵） | ✅ 强烈 | GNN（22/23 章）+ 谱特征（02） |
| 社交/推荐（关系显著+规模巨大） | ✅ | 采样 GNN（25）+ 嵌入检索（21/43） |
| 文本关系（结构可提取但语言原生非图） | ⚠️ | GraphRAG 按需（26），别为图而图 |
| 图像/音频（规则网格） | ❌ | CNN/注意力——图是泛化，不是替代 |
| 不确定关系 | ⚠️ | 概率图（讲透概率图模型），别用硬边伪装确定 |

## 五、系列闭环

```
数学之图（01-10）：语言与不变量 —— 谱（02）是心脏
网络科学（11-14）：真实世界的图 —— 幂律与社群
学习之图（21-28）：图 × 学习 —— WL（23）是宪法
状态之图（31-37）：图 × 时间 —— 马尔可夫（32）是引擎
应用之图（41-43）：检验一切
```

六象限中本系列占五部；系统之图（讲透Agent/讲透Graph）与概率之图（讲透概率图模型）各成宇宙——**图的知识没有中心，只有不断增殖的象限**。这本身就是图论教给我们的世界观。
