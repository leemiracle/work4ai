# 23 · GNN 表达力与 Weisfeiler-Lehman：分不开的图对

> **一句话**：消息传递 GNN 的分辨力上限 = **1-WL 图同构测试**（1968 年的一台"颜色传球机"）。分得开 1-WL 就分得开所有 GNN；分不开——神仙网络也没辙。而**谱间隙**可以作为"哪些图对难分"的定量指纹。
>
> 实验配套：[`experiments/wl_test.py`](./experiments/wl_test.py)（1-WL 实现 + 经典不可分图对实测，出图 `wl.png`）

---

**1968 年，Boris Weisfeiler 和 Andrei Lehman 在苏联写下算法。** 他们研究图同构（两张图是否只是同一个图的两种画法）——计算机科学的少数至今没有多项式算法也没有 NP 难证明的"孤岛问题"之一。他们的迭代细化算法（后来称 1-WL/色彩细化）对绝大多数图立竿见影，却在**正则图**（所有节点同度）上瞬间失明：第一轮所有人颜色相同 → 永远相同。2018 年 Xu 等人（GIN）与 Morris 等人分别证明：**消息传递 GNN 的表达力严格不超过 1-WL**——深度学习最热的架构，天花板钉在五十年前的苏联算法上。这枚钉子催生了整个"高阶 GNN"研究方向，也在本库作者的 math-agent 研究里长出了新枝：**WL 分离谱间隙**（详见 2.4）。

---

## 一、直觉层：颜色传球机

1-WL 是台机器，重复执行"看邻居、报颜色"：

1. **初始**：所有节点同色（或按度/标签着色）
2. **每轮**：每个节点收集邻居的多重集（multiset）颜色 → 哈希成新颜色 → **自己的新颜色 = hash(旧颜色, 邻居颜色多重集)**
3. **终止**：整图的颜色直方图不再变化

**判同构**：两图各跑若干轮，比较颜色直方图——不同 ⟹ 必不同构（**可靠的"否证"**）；相同 ⟹ *可能*同构（1-WL 说不出"是"，正则图上集体失明）。

**为什么它就是 GNN**：把 hash 换成可学习的聚合+更新（22 章公式），"颜色"变成实数向量——**GNN = 可微分的 1-WL**。所以 GNN 的能耐与局限，都从这台传球机继承。

**正则图为什么是盲区**：正则图（如 Petersen 图、所有点度=3）第一轮后人人同色、邻居多重集也全同——机器从此静止。而**绝大多数分子图不是正则图**（原子度各异），所以 GNN 在化学里够用；但**生成对抗样本图/某些组合设计图**恰好落在盲区。

## 二、数学层

### 2.1 1-WL 的形式化

第 t 轮节点 v 的颜色 c_v^(t)：

$$c_v^{(t+1)} = \operatorname{HASH}\Big(c_v^{(t)},\; \big\{\!\!\big\{ c_u^{(t)} : u \in \mathcal{N}(v) \big\}\!\!\big\}\Big)$$

（{{·}} 表示多重集——同色邻居计次数。）两图 G,H 在第 t 轮 WL-**可分** ⟺ 颜色直方图不同。**定理（Xu et al. 2019 / Morris et al. 2019）**：任何消息传递 GNN 若要把任意两图映到不同表示，当且仅当 1-WL 能分开它们——即 **GNN ⊑ 1-WL**。

### 2.2 GIN：把天花板顶到 1-WL 的架构

要让 GNN 恰好等于 1-WL，聚合必须是**单射**（不同多重集→不同输出）。均值/最大值聚合都会撞车（{(a,a),(a)} 与 {(a)} 均值相同——邻居数量信息丢失）。Xu 的答案：**GIN = MLP( (1+ε)·h_v + Σ h_u )**——求和保多重性 + MLP 学单射。**实践警钟**：GCN 的均值聚合严格弱于 GIN，但实际任务里常打平——**表达力是理论上限，不是性能保证**（任务里的图大多远离盲区）。

### 2.3 破局三路

1. **高阶 k-WL / k-GNN**：颜色刻画 k 元组——表达力阶梯 k-WL ⊑ (k+1)-WL，复杂度 n^k 起跳（k=2 已 O(n²)，Morris 的 k-GNN 是可行折中）
2. **结构特征注入**：手动加子结构计数（三角形/环计数作为额外特征）——等价于把部分高阶信息"外包"给特征工程
3. **位置/距离注入**：随机游走沉积（P-GNN）、 landmarks 距离——把 1-WL 看不到的全局位置塞进去

### 2.4 WL 分离谱间隙（挂 math-agent C1 研究）

本库作者团队（math-agent 项目）在 2026 年的发现给"可分性"提供了**定量工具**：

- 定义图对 (G,H) 的 **WL 分离度**：1-WL 在第 t 轮首度区分它们的量化间隔（如色直方图的 L1 差）
- **谱间隙作为指纹**：WL-难分的图对，其**代数谱间隙**（02 章的工具）落在窄带内。实证锚（本库实验实测，`experiments/graph_universe.py` E4）：**Petersen λ₂(L)=2.000、λmax(L)=5.000（3-正则，1-WL 全盲）vs Pentagonal Prism λ₂(L)=1.382、λmax(L)=5.618（同为 3-正则、同为 WL-hard，标准谱已不同）**——同为盲区，谱给出"盲区内还能不能区分"的次级判据（注：math-agent loops/ 原报 7.000/5.472 为其项目内部 gap 量纲，非标准 λmax(L)；标准拉普拉斯谱实测 Petersen λ₂=2.000/λmax=5.000，Prism λ₂=1.382/λmax=5.618——两图谱可分结论不变，量纲以 loops/ 原定义为准）
- **假说（研究前沿）**：谱间隙 + 度特征 + 少量子结构计数 ⊇ 1-WL 之外的大部分实用可分性——"WL-hard 谱带"（414,060 图零违反的实证筛）正在被系统验证

→ 本章因此是**连接三个宇宙的桥**：1-WL（逻辑/算法宇宙）· 谱（代数宇宙）· GNN 实践（学习宇宙）。

### 2.5 与 WL 相邻的判定层级

| 层级 | 判定力 | 复杂度 |
|---|---|---|
| 度序列 | 最弱（同度即平） | O(n) |
| **1-WL / 消息传递 GNN** | 严格强于度序列，弱于 2-WL | O(n+m) 每轮 |
| 2-WL / 3-WL | 阶梯上升 | n²/n³ |
| 图同构精确判定 | n^(log n) 级（Babai 2015 准多项式） | 理论可解工程难 |

## 三、代码层（bash 实跑验证）

```python
# experiments/wl_test.py 节选 —— 1-WL 与经典不可分对
def wl_colors(G, rounds=5):
    colors = {v: G.degree(v) for v in G}          # 初始按度
    for _ in range(rounds):
        new = {v: hash((colors[v],
                        tuple(sorted(colors[u] for u in G[v])))) for v in G}
        colors = new
    return sorted(Counter(colors.values()).values())

# ① 可分对：随机树 vs 不同构树 → 直方图第 1-2 轮即分
# ② 不可分对：Petersen vs PentagonalPrism（均 3-正则，10 节点）
#    → 每轮直方图 [10]（全同色）——1-WL 彻底失明 ✓ 复现
# ③ 谱判据补救：np.linalg.eigvalsh(laplacian) 均值差
#    λmax(L): Petersen=5.000 vs Prism=5.618 → 谱看见了 WL 的盲区（λ₂: 2.000 vs 1.382 同）
```

## 四、不足与边界（批判）

1. **1-WL 上界 ≠ 任务性能**：真实数据集上 GIN 常不胜 GCN——表达力研究与实践之间存在"够用就好"的鸿沟（理论家的痛）
2. **k-WL 的复杂度墙**：表达力阶梯的每一级都是复杂度的悬崖；k≥3 几乎只有理论价值
3. **WL-hard 谱假说尚未定理化**：414,060 图零违反是强实证，但反例空间（更大图/构造图）未穷尽——这是 open problem，也是机会
4. **有向图/异质边的 WL 推广**（Dir-WL 等）理论碎片化，工程界各自为政
