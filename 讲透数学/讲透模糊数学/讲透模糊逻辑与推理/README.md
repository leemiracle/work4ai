> 让"有点热"既能被定义,又能被推理。

## 诞生

- **1920s-30s**,Łukasiewicz 无限值逻辑:真值连续化的公理化先声(模糊逻辑的公理老家)
- **1973-75**,Zadeh:语言变量 ⟨x,T,U,G,M⟩ 与模糊推理的提出——"程度词"成为五元组机器
- **1975**,Mamdani–Assilian:第一个模糊控制器(蒸汽机)——min-max 推理的工程首秀
- **1985**,Takagi–Sugeno–Kang(TSK):结论端函数化,推理与经典控制无缝
- **1998-2007**,Hájek BL → Esteva–Godo MTL:t-norm 逻辑拿到标准完备性——规范化的封印

## 核心问题

已解决:
- 语言变量的形式化(词=曲线,程度词=算子:μ_很=μ²,μ_有点=μ^0.5)
- 推理机三件套:蕴含(min/乘积)、聚合(max)、解模糊(重心/最大平均)
- t-norm 逻辑的完备性:Ł_∞/MV 代数(Chang 1958)、BL(Hájek 1998)、MTL(Esteva–Godo 2006)
- 模糊系统的通用逼近定理(Wang 1992)——工程合法性的理论封印

未解决:
- μ 的语义锚(可能性/真度/偏好)无统一理论——语义层是规范化地图最大空白
- 规则库自动生成的可靠性(归纳规则要人审)
- 与概率推理的公理统一(1995 论战无裁决,实务和解=分工)

## ✨ 这支最美的一个事实

**Mamdani 推理 = 把专家口语编译成控制器**:"IF 热且风小 THEN 风扇大"经
min-蕴含→max-聚合→重心解模糊五步,直接变成连续控制曲面——
知识的表达形式就是知识的执行形式。

## 假设与依赖

- 排中律可失效(A∩Aᶜ≠∅ 是特性:半冷半热合法)——与经典逻辑的根本分岔
- 合取必须幸存 t-norm 四公理(交换/结合/单调/单位元)——谱系而非独苗的根源
- 每个左连续 t-norm 带剩余 →(modus ponens 的代数化身)——剩余格是推理的安全带
