## 诞生

- **1975**,Mamdani–Assilian 蒸汽机模糊控制:第一条口语规则驱动真实装置
- **📖 1987,仙台地铁(Hitachi,Yasunobu & Miyamoto)**:24 条模糊规则驾驶地铁——
  停车误差、能耗、舒适度全面胜过精细调校的传统控制器;模糊控制从论文走进专利墙,
  "fuzzy"从贬义词变成家电广告词(1990s 松下/日立洗衣机"模糊逻辑"卖点浪潮)
- **1993**,Jang ANFIS:神经网络学隶属函数——数据反哺的开端

## 核心问题

已解决:
- 控制器设计四件套:输入输出语言变量 / 规则库 / 推理机 / 解模糊器(设计手册成熟)
- 通用逼近定理(1992):模糊系统可逼近任意连续函数——理论合法性
- 量产形态:**离线预计算控制曲面 + ROM 查表**(推理都在编译期,运行时 O(1))

未解决:
- 稳定性的一般理论(Lyapunov 型结果逐类给出,无统一判据)
- type-2 降型的实时代价(精确降型是迭代优化;区间近似是折中)
- 规则库规模与可解释性的平衡(规则多了查表快但语义糊)

## ✨ 这支最美的一个事实

**仙台地铁的 24 条规则打赢了精细 PID**:少而对的口语规则,胜过多而精的参数堆——
鲁棒性的另一种来源:**粗而不脆**(min-max 的分段平滑性让局部误差不扩散)。
数值形态见家族 [experiments/00_mamdani.py](../experiments/00_mamdani.py) 的鲁棒性演示。

## 假设与代价

- 专家经验可口语化且基本正确(规则库是先验,错了控制器跟着错)
- 传感器噪声被 min-max 平均化吸收(噪声容忍是买来的,不是免费祈祷来的)
- 精度上限受网格/隶属函数分辨率约束(高精度场景退场给经典控制)
