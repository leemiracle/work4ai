# 讲透模糊集与隶属函数 · 基石支:把 0/1 烫弯成 [0,1]

> 定位句:这支负责**对象层**——μ 怎么定义、模糊集怎么运算、模糊数怎么做算术。
> GB/T 13745-2009:11084「模糊数学」三级未列 → **自定主干支**
> 家族:[../README.md](../README.md) ｜ 全景:[../../GB-T13745全景.md](../../GB-T13745全景.md)

## 诞生

- **1965**,Lotfi Zadeh(伯克利,控制理论家)《Fuzzy Sets》,《Information and Control》8(3):338-353——
  一刀把特征函数 χ:{0,1} 烫弯成 μ:[0,1],动机:"高个子"这类集合在经典集合论中不存在
- 思想前史:Łukasiewicz 多值逻辑(1920s,真值连续化)、Black《Vague sets》(1937)——
  Zadeh 是把"程度"做成**集合论对象**的第一人
- 内节义务:**type-2 模糊集**(隶属度的隶属度——把"μ 谁定的"主观性内化为带宽,近五年主线,
  见家族 [01 章](../01-近五年创新.md));**粗糙集对比**(Pawlak 1982:不可分辨的上下逼近 vs 程度隶属)

## 核心问题

已解决:
- 模糊集的运算公理化:Zadeh 算子组(min/max/1-μ,1965)与 t-norm 谱系
- **扩展原理**(Zadeh 1975):任意经典函数自动提升为模糊函数——经典家当免费搬运
- **分解定理**:模糊集 = 嵌套 α-截集的堆叠(A=⋃α·A_α)
- 凸模糊数算术:支集/spread 的可控行为

未解决:
- 隶属函数的**客观性**:专家 μ vs 数据 μ 的调和(学习是现役主线)
- type-2 的降型计算代价(精确 type-reduction 的复杂度)
- 非凸"信念"(双峰)对象如何当数用

## ✨ 这支最美的一个事实

**扩展原理**:μ_{f(A)}(v)=sup{μ_A(u): f(u)=v}——一条公式,加法、sin、max、
积分核……全部经典运算**自动**获得模糊版。你不重造世界,只规定搬运法。

## 假设与依赖

- 隶属函数可选取(主观性是显式代价,换来自然语言建模力)
- 交并用 t-norm 谱系(min 只是默认,不是天命)
- 结构骨架:全体模糊集=完全分配格;配 De Morgan 对合 → De Morgan 代数(见家族 [03 章](../03-可构造与结构.md))
