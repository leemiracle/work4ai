# 03 · 可构造与结构:一扇旋转门,一条搬运法

> **本章回答五问之四:模糊世界里哪些对象可构造?结构刚性从哪来?**
> 两个主角:**α-截集**(模糊↔清晰的旋转门)与**扩展原理**(经典运算的自动模糊化)。

---

## 一、开篇:模糊世界里怎么算 2+3?

经典数学的家当都在清晰世界:加法、乘法、sin、max……现在论域上住的是模糊数——
"大约 2"加"大约 3"等于什么?总不能让 60 年的全部经典运算重新发明一遍。

**📖 故事框 · Zadeh 的第二条定律(1975)**

Zadeh 1965 定义模糊集,1975 给出**扩展原理(extension principle)**:
任何经典函数 f: U→V,自动提升为模糊函数 f̃:

> μ_{f̃(A)}(v) = sup { μ_A(u) : f(u) = v }

直觉:**"大约等于 v"的程度 = 所有能推出 v 的输入里,隶属度最高的那个"。**
一条原理,把整个经典函数世界打包搬进模糊世界——这是模糊数学最像"构造性大爆炸"的时刻。

**直觉图像先行**:把经典函数想成一台**投币机**(投入清晰硬币 u,吐出清晰结果 f(u));
扩展原理给每枚"模糊硬币"(一摞按隶属度加权的硬币)规定了结算规则——
输出是**各次投币结果按最高隶属度取包络**。机器不用改装,改的只是结算单。

## 二、可构造性清单(什么能造、怎么造)

| 对象 | 构造方法 | 依赖 |
|------|---------|------|
| 模糊集 | 直接给 μ:U→[0,1]（专家曲线/三角/梯形/高斯） | 无 |
| 模糊数的算术(+ − × ÷) | 扩展原理作用于 ℝ 上的经典四则 | 扩展原理 |
| 模糊函数值 | 扩展原理作用于任意经典 f(sin、max、积分核……) | 扩展原理 |
| 清晰集合(从模糊的) | α-截集 A_α={x: μ_A(x)≥α} | 无(逐点比较) |
| 模糊集(从截集的) | 分解定理:A = ⋃_α α·A_α | α-截集 |
| 模糊关系与合成 | 扩展原理作用于关系复合 sup-min | 扩展原理 |
| 规则库的推理输出 | Mamdani(min-蕴含-max-聚合)+ 解模糊 | 全部上述 |

**为什么可构造性这么好**:模糊数学的对象**生来就是函数**(μ 是一个 [0,1] 值函数),
而函数世界是构造主义者的乐土——构造 μ 不需要选择公理,不需要无穷争议,
画一条曲线就是。**可构造性是它与集合论地基系列最不同的气质**(对照
[../讲透集合/](../讲透集合/)的公理雷区,这里几乎无雷)。

**反直觉发现 ⑥**:两个**正则凸**模糊数相加,"大约 2"+"大约 3"确实得到"大约 5"
(支集位置相加、 spreads 相加)——但对**乘除**,结果会"变胖"得不成比例
(相对误差放大):模糊算术对加法温和,对乘法残忍。**不确定性在算术里有自己的通货膨胀率**。
亲历:μ_2 = 三角(1.8,2,2.2),μ_3 = 三角(2.7,3,3.3),算 μ_2×μ_3 的支集宽度。

## 三、结构刚性从哪来(三个结构定理)

模糊世界不是松散的——它有三层刚性:

### 1. 格结构:全体模糊集是完全分配格

逐点定义 (A∧B)(x)=min(μ_A,μ_B)、(A∨B)(x)=max,则 [0,1]^U 构成**完全分配格**
(complete distributive lattice),配 De Morgan 对合 ¬A(x)=1−μ_A(x) 得 **De Morgan 代数**。

**为什么刚性**:Boole 代数 = De Morgan 代数 + 排中律(x∨¬x=1)。
模糊集是 Boole 世界**恰删一条公理**的最大邻居——不是任意松弛,是受控松弛:
分配律、结合律、单位元全部幸存。**结构刚性的来源:删得最少**。

### 2. α-截集:嵌套的清晰影子(decomposition 定理)

A_α 随 α 上升而**单调收缩**(α₁<α₂ ⟹ A_α₂ ⊆ A_α₁)——模糊集 = 一摞嵌套的清晰集合。
**为什么刚性**:每个截集都是经典集合(享有全部经典集合论权利),
分解定理 A=⋃α·A_α 说明模糊对象**完全由清晰影子决定**——模糊不是清晰的反叛,是清晰的**堆叠**。
(第一、第二、第三表现定理是这条定理的三种包装。)

### 3. 扩展原理的唯一性约束

不是随便搬运都合法:扩展原理是**与 α-截集相容**的唯一自然提升
(经典函数作用于 A_α 恰得 f(A_α))。三件套(扩展原理/截集/分解定理)互相锁定——
这解释了为什么 60 年来没有出现"竞争性搬运法":**结构自洽把自由度封死**。

## 四·五、模糊算术实算(看通货膨胀率的第一手数据)

取两个三角模糊数(数字为 a,b,c):
- A = "大约 2" = (1.8, 2.0, 2.2),spread=0.2
- B = "大约 3" = (2.7, 3.0, 3.3),spread=0.3

| 运算 | 结果(三角近似) | 新 spread | 通胀 |
|------|---------------|----------|------|
| A+B | (4.5, 5.0, 5.5) | 0.5 | 和平共处:0.2+0.3=0.5,线性叠加 |
| A−B | (−1.5, −1.0, −0.5) | 0.5 | 同上,温和 |
| A×B | (4.86, 6.0, 7.26) | ≈1.2 | **变胖**:相对不确定度从 ~10%/10% 涨到 ~20% |
| 1/A | (0.303, 0.5, 0.556) | 相对 spread 翻倍 | 除法最狠 |

(严格结果由扩展原理逐点取 sup;三角近似给出直觉。)
**读数**:加法的不确定性按**绝对量**叠加,乘法按**相对量**放大——
这就是"模糊算术对加法温和、对乘法残忍"的数值形态,也是工程里
"先加减后乘除、能比值就不差值"的信条来源。

## 四·六、三 representation 定理(结构自洽的三种包装)

模糊集与清晰世界之间有三座等价的桥(教材称表现定理 representation theorems):

1. **分解定理**(α-截集族):A = ⋃_α α·A_α——"CT 扫描"视角
2. **第一表现定理**(嵌套集合族):模糊集 ↔ 单调族 {A_α}——"家谱"视角
3. **第二表现定理**(集合映射):模糊集 ↔ 保并的映射——"函数式"视角

三桥互译、信息无损。**为什么重要**:任何想在模糊世界上定义新操作的人,
只需检查"作用于每个 α-截集时与经典世界相容"——三桥保证这样的定义**至多一个自然解**。
(扩展原理正是这么被"锁死"的唯一性来源——自由度被结构封死,见 §三·3。)

## ✨ 美之时刻(本章)

**分解定理 = 模糊世界的 CT 扫描**:一个三维的模糊对象,切成一片片二维清晰截面(A_α),
每片都完全经典、可以放进任何教科书检查;叠回去,模糊集毫发无损。
**你不必发明"模糊集合论"——把经典集合论按 α 扫描一遍就够了。**
亲历:取 μ(x)=max(0, 1−|x−2|/2),手画 α=0.25/0.5/0.75 的三个截集,验证嵌套。

## 五·七、可构造性 vs 公理雷区(与集合论地基的对照)

对照 [../讲透集合/](../讲透集合/) 的 ZFC 世界:那里"哪些对象存在"是公理谈判的产物
(选择公理买到 Zorn 引理、付出不可测集);模糊世界完全不同——

| | ZFC 世界 | 模糊世界 |
|---|---------|---------|
| 对象存在性 | 公理授予(争议处靠选择公理) | **画出来即存在**(μ 是显式函数) |
| 构造主义立场 | 常被排斥(排中律强) | 天然亲和(一切皆算法对象) |
| 无穷的角色 | 实无穷是舞台 | 论域有限/连续均可,无穷不添乱 |

**为什么重要**:这让模糊数学成为"构造主义数学的匿名盟友"——
每一个模糊对象都自带算法化身(μ 的求值程序),转代码(04 章)不需要翻译,只需要抄写。
**可构造性不是这个分支的成就,是它的出厂设置。**
