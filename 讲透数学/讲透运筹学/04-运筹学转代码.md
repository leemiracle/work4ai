## 〇、开篇:同一条产线的三道工序

直觉图像:一个真实的运筹问题(比如 GPU 集群的请求调度)从数学到代码有三条传送带:

```
       结构已知(凸/生灭/报童)          结构半知(非凸/非平稳)         结构未知(黑箱环境)
            │                              │                              │
      ┌─────▼─────┐                 ┌──────▼──────┐               ┌──────▼──────┐
      │ 精确解带    │                 │ 仿真带       │               │ 学习带       │
      │ 求解器/闭式  │                 │ 离散事件模拟  │               │ RL/bandit    │
      └───────────┘                 └─────────────┘               └─────────────┘
       特点:可复现、可验证            特点:一次一条轨迹              特点:策略泛化
       风险:模型≠现实                 风险:方差、慢                  风险:分布漂移
```

**判据一句话**:闭式/多项式结构在 → 走求解器;只有分布模型在 → 走仿真;
连分布都没有只有交互 → 走学习。三带常串联:学习带产策略,仿真带打分,求解带兜底。

## 一、可机械化边界(哪些能变 code,哪些变不了)

| 问题类型 | 可机械化程度 | 边界说明 |
|---|---|---|
| 线性规划 LP | ✅ 完全 | 多项式算法;工业求解器(Gurobi/HiGHS/ortools)百万变量级 |
| 凸优化(光滑) | ✅ 完全 | 内点/一阶法;ML 训练的地基(它自己就是凸优化消费者) |
| 整数规划 MILP | ⚠️ 实践可行、最坏指数 | 分支定界+割平面;NP-难但不等于解不动(实例结构常救你) |
| 排队系统性能(M/M/*) | ✅ 闭式/矩阵法 | Erlang B/C、生灭平稳分布——查表即得 |
| 一般排队(G/G/c、非平稳) | ⚠️ 只能仿真/近似 | 离散事件模拟是唯一通用武器;流体/扩散极限给近似 |
| 多级库存(级联结构) | ✅ 结构+数值 | base-stock 形状闭式,水位数值解 |
| 马尔可夫决策过程(小状态) | ✅ 动态规划 | 值迭代/策略迭代,贝尔曼方程直接翻代码 |
| MDP(大状态) | ⚠️ 需要学习 | 表格爆 → 函数逼近(RL);收敛保证弱化 |
| 纳什/均衡计算 | ❌ PPAD-完全 | 一般情形无高效算法;实际问题用特殊结构或近似 |
| 「最优策略对分布漂移鲁棒」 | ❌ 不存在银弹 | DRO/在线学习给部分答案;这是 2026 仍在动的前沿 |

**边界的数学本质**:可机械化 ⟺ 「问题有 03 章意义上的刚性」。
凸性/马尔可夫性/级联性是刚性的三个名牌;无刚性(均衡计算、非平稳、黑箱)就是三条传送带
依次降级:精确→仿真→学习。

## 三、工程师落点(性能工程视角)

运筹学是性能工程的**数学后台**——三者共用一张词汇表:

| 性能场景 | 运筹概念 | 一句话 |
|---|---|---|
| GPU 排队(K8s/推理服务) | M/G/c 排队、Erlang C | 「多少副本才扛住 P99?」——等待概率公式直接回答容量规划 |
| 负载均衡 | 什么最小负载/随机选择(power of two choices) | 随机选 2 台挑闲的那台,队长从 O(log n)/O(1) 量级改善——排队论最实用的定理之一 |
| 缓冲区/背压 | 有界队列+丢弃策略 | Little 定律给你守恒,上限决策=队长分布分位数 |
| 尾延迟 P99/P999 | 均值≠分位数 | 「平均快」和「99% 快」是两个目标——排队论给分位数公式,优化目标自己选 |
| 批处理/调度 | 整数规划/装箱 | Triton/CUDA graph 的 kernel 装配、tile 调度本质是组合优化 |
| 自动扩缩容 | 在线排队(01 章) | λ 漂移 → 容量也要在线——预测器+控制器闭环 |
| 灰度/实验设计 | 决策论(信息价值) | 「这个实验还值不值得跑?」=信息的期望价值 vs 成本 |

**三条施工守则**(踩坑总结):
1. **先建模后编码**:把变量/目标/约束写进注释(02 章「模型即文档」),代码只是模型的投影——
   模型错的代码跑得再快也是错得更快。
2. **闭式优先**:有 Erlang/P-K/报童闭式就别蒙特卡洛——仿真误差 O(1/√n),闭式零误差零成本;
   仿真只留给闭式覆盖不到的(G/G/非平稳)。
3. **策略形状先行**:先从结构定理拿到策略形状(base-stock/critical fractile),数值交给数据;
   这比端到端学习稳得多(03 章「形状比数值值钱」)。

## 四、反直觉发现(工程版)

- **加机器可能更堵**:Braess 悖论的分布式版本——某类负载均衡策略下,增加容量反而抬升均衡时延
  (自治路由的经典病)。容量规划要检查「策略×容量」组合,不是容量单变量。
- **平均利用率 100% 是灾难**:M/M/1 在 ρ=1 处 W→∞;ρ=0.7~0.8 是时延-成本悬崖的舒适区,
  「压榨利用率」在排队论里是自伤行为。
