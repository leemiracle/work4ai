# 讲透随机规划 · 不确定性直接进模型——二阶段、机会约束与分布鲁棒

> GB/T 13745-2009:11074 运筹学 三级「随机规划」
> **定位句**:这支负责「把随机性写进约束/目标本身,而不是先估参数再当确定性问题解」——
> 随机版的 min s.t.。
> 家族:[讲透运筹学](../README.md)｜五问模板家族成员

## 诞生

Dantzig 1955《Linear Programming under Uncertainty》——线性规划发明者本人指出:
确定性问题(min s.t.)把数据当已知,而**数据是随机的**;他给出二阶段模型
(第一阶段决策→自然掷骰→第二阶段追偿 recourse)。Charnes–Cooper 1959 机会约束
(约束以概率 ≥α 成立);Wets、Birge 一系把凸性、对偶、算法()L 形/Benders 分解)建成体系。

## 核心问题

已解决:
- 二阶段问题关于第一阶段决策是**凸的**(期望追偿函数凸——Wets):随机不破坏可解性
- SAA(样本平均近似)的一致性与收敛速率(大数定律+一致收敛)
- L-形/Benders 分解:场景分解的可扩展算法

未解决/前沿:
- 多阶段问题的时序一致性(time consistency)——什么情况下「今天的计划」明天还认账
- 分布不确定:数据驱动 DRO(分布鲁棒优化)与 SAA 的边界(2021-2026 热线)
- 高维场景下的稀有事件(机会约束的蒙特卡洛估计)

## 这支最美的一个事实

**期望追偿是凸的**:无论随机性多狂野,「第一阶段决策 x → 期望第二阶段成本 Q(x)」
的 Q 总是凸函数——随机性不但没有摧毁优化结构,反而**自动生成**一个凸目标。
(必然之美:inf 运算保凸,随机规划天生站在凸的世界里。)
