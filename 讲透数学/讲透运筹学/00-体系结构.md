# 00 · 体系结构:运筹家族的全图

> **本章回答五问之一(家族层):整个体系结构长什么样。**
> **本质一句话**:运筹学 = 把「怎么办才最好」变成一道能算的题——
> 给我一个**目标**(最小化什么)、一组**约束**(资源只有这么多)、一个**不确定性模型**(世界会怎么掷骰子),
> 我还你一个**可执行的决策**。
> 它和分析学相反:分析学问「这个东西是什么」(极限/连续),运筹学问「这件事怎么办」(最优决策)。

---

## 一、怎么产生的:三封信、一场战争、一个电话局

运筹学不是从公理推出来的,是被三个真实的麻烦**逼**出来的。

📖 **故事 1 · 哥本哈根的电话局(1909)**。Agner Krarup Erlang 是哥本哈根电话公司的工程师。
公司头疼的问题朴素至极:接多少条线、雇多少个接线员,才既不让顾客等太久、又不浪费钱?
线路是排他的——你占线,别人就打不进来。Erlang 用概率论算出了著名的 Erlang B 公式
(损失制:M/M/n/n 系统的阻塞概率)与 Erlang C 公式(等待制:顾客需要等待的概率)。
**排队论诞生了——比「运筹学」这个名字早 38 年。**
他的论文标题诚实地写着「The Theory of Probabilities and Telephone Conversations」:
一门数学分支,始于人们想打电话。

📖 **故事 2 · Blackett 马戏团(1940-1945)**。二战,英国。物理学家 Patrick Blackett
(后来的诺贝尔奖得主)被请去解决一个致命问题:高射炮的雷达该怎么布防?护航舰队该编多大阵型?
他拉起一支梦之队——三个生理学家、两个物理学家、一个天体物理学家、一个普通物理学家、
两个数学家、一个军官、一个测量员。报纸戏称「Blackett 马戏团」(Blackett's circus)。
他们的第一个发现令人尴尬:**高射炮阵地平均发射几千发才击落一架飞机,而炮弹的**引信设置**有系统偏差**——
调一个参数,效率翻倍。运筹学(Operation Research)由此得名:对「正在运行的作业」做研究。
战后这门手艺被原封不动搬进工厂、银行、 airline——排队没有消失,只是换了队形。

📖 **故事 3 · Dantzig 与单纯形(1947)**。George Dantzig 在美国空军审计处,
面对的是同一个问题的确定性版本:几十种活动,分有限的预算和人力,**怎么组合让效能最大?**
他把这类问题写成「线性规划」(目标线性、约束线性),并发明了单纯形法(the simplex method)求解。
他后来说:线性规划「为规划决策提供了统一语言」。
1984 年 Karmarkar 的内点法、1979 年 Khachiyan 的椭球法相继证明:**线性规划是多项式时间可解的**。
一门从军事帐篷里走出来的数学,成了现代供应链、芯片设计、广告竞价的地基。

**三块基石的分工**:电话局给了「随机模型」(排队/库存),马戏团给了「问题姿态」(研究运行中的系统),
Dantzig 给了「确定性语言」(min s.t.)。运筹学 = 三者的合流。

## 三、相互喂养图(依赖经济)

```
概率论(马尔可夫过程/条件期望) ──随机性──▶ 排队论 / 库存论 / 搜索论
../讲透优化/ ──对偶与凸性──▶ 随机规划(二阶段问题本质是凸优化)
排队论 ──平稳分布──▶ 库存论(补货即服务) / 性能工程(时延分析)
库存论 ──临界分位数──▶ 供应链 / 随机规划(多阶段特例)
决策论 ──效用语言──▶ 博弈论(单人→多人) / 搜索论(停止即决策)
统筹论 ──网络语言──▶ ../讲透图/(最长路径)
参数规划 ──灵敏度──▶ 一切规划模型(解怎么随数据动)
```

**一句话经济**:概率论卖随机性,优化卖对偶,排队卖守恒律,库存卖临界值,
决策卖效用,搜索卖停止规则,统筹卖关键路径。

## 四、核心问题清单(已解决 / 悬而未决)

**已解决的里程碑**:

| 年代 | 问题 | 解 |
|------|------|---|
| 1909 | 「多少条电话线够用?」 | Erlang B/C 公式(排队论第一定理) |
| 1947 | 「线性约束下线性目标最优?」 | Dantzig 单纯形法(实践中极快) |
| 1951 | 「不确定需求下订多少货?」 | 报童模型:订到临界分位数 F⁻¹(τ),τ=CU/(CU+CO) |
| 1961 | 「队长、到达率、逗留时间什么关系?」 | Little 定律 L=λW——任意排队系统通用守恒 |
| 1979/1984 | 「线性规划是多项式可解的吗?」 | 椭球法(Khachiyan)/内点法(Karmarkar):是 |
| 1970s-80s | 「多级库存怎么协调?」 | Clark-Scarf 级联分解:base-stock 策略最优 |

**悬而未决的大问题**:

- **线性规划的强多项式算法**(是否存在算法,运算次数的多项式只依赖维数、不依赖输入数字的位数?)
  ——这是 Smale 问题清单第 9 问,「线性规划自己的 P vs NP 级悬案」。单纯形法指数最坏但实践飞快,
  内点法多项式但依赖位数——完美算法至今缺席。
- **一般均衡的计算复杂性**:Arrow-Debreu 均衡存在性已证,但 PPAD-完全(与纳什均衡同命运)——
  「市场会自己找到价格」在计算上没有保证。
- **网络均衡的 Braess 悖论边界**:什么样的网络拓扑对「自私路由」免疫?
- **数据驱动决策的样本复杂度**:只知道分布的样本、不知道分布本身时,离最优决策还差多少样本?

## 五、假设与代价(本家族站在哪些假设上)

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 平稳性(到达率/需求分布不变) | 解析解:生灭过程平稳分布、Erlang 公式闭式 | 非稳态(早高峰/大促)全部失效——这正是在线学习进排队的动机 |
| 分布已知(知道 λ、知道需求分布) | 期望可写进目标,「最优」有定义 | 现实分布是估计出来的——模型误差伪装成最优解(分布鲁棒优化的出发点) |
| 独立性(到达相互独立) | 泊松到达的解析可乘性 | 突发流量(重尾/相关)下队长爆炸——f(internet) 教训:真实流量是自相似的 |
| 期望准则(平均最优即可) | 单一数字可比,数学好处理 | 平均最优≠尾部安全——金融与可靠性场景必须换分位数/条件风险值准则 |
| 凸性(可行域/目标凸) | 局部最优=全局最优,对偶间隙为零 | 整数决策(订 3.7 架飞机?)天然非凸——组合爆炸回来收租 |

## 六、反直觉发现(讲透铁律)

1. **Braess 悖论(1968)**:路网里**加一条快路**,所有人 selfish 路由的均衡时延反而**变大**。
   Wardrop 均衡不等于系统最优——纳什式的「各自最优」可以被一条新路推离整体最优。
   亲手验证:构造两支路网络,算均衡前后总时延(04 章代码走廊第 3 项)。
2. **Little 定律的「不因果」**:L=λW 里没有服务率、没有分布、没有优先级——
   队长只由「进入流」和「逗留时间」决定,与系统内部怎么运作**完全无关**。
   它像热力学第零定律一样,是超越机制的守恒。
3. **报童订得少反而赚**:当超储成本(CO)高于缺货成本(CU)时,最优订货量**低于**需求均值——
   「备多点总没错」在期望值世界里是错的。

## 七、✨ 美之时刻(全家族五章合计 ≥3 之三)

✨ **美之时刻 1 · Little 定律 L=λW**(为什么美:**极简**——三个字母管住一切排队系统,
从超市到 CPU 流水线到 TCP;怎么亲历:跑 [`experiments/00_mm1_little.py`](experiments/00_mm1_little.py),
看模拟点落在解析直线上)。

✨ **美之时刻 2 · 对偶性=同一问题的两面镜子**(为什么美:**统一**——
原问题问「资源最少花多少」,对偶问题问「资源最多值多少」,最优处两面镜子照同一个数;
影子价格让「值多少钱」变成数学量;怎么亲历:任取一个两变量 LP,图解原问题与对偶问题,
看两个最优值咬合)。

✨ **美之时刻 3 · 排队网络的乘积形式**(Jackson 1957:n 个耦合的服务站,
联合平稳分布竟然等于各站分布的**乘积**——耦合被「流量守恒」解开;
怎么亲历:两站串联的 M/M/1→M/M/1,模拟验证联合分布=边缘分布乘积)。

## 九、怎么读这个家族

- **顺序派**:排队论(实验最直观)→ 库存论 → 决策论 → 随机规划 → 参数/搜索/统筹

## 📌 收束与认知升维

**这章给了你什么新眼睛**:
- **守恒眼**:看到队列先问「流的进出守恒吗」,Little 定律比任何机制分析都快
- **假设眼**:每个「最优解」背后都有一份假设合同——问「分布谁给你的」比问「解是多少」更重要
