# 运筹学思维技能卡(讲透运筹学)

## ① 何时用此分支(触发特征,一眼对号)

- 有**等待**:队列、排队、时延、P99、SLA、背压、拥塞 → 排队论
- 有**补货**:库存、订货、补货点、安全库存、缺货、备件 → 库存论
- 有**一次性拍板**:选方案、投标、上线与否、信息值不值钱 → 决策论
- 有**容量问题**:多少台机器/人/线程才够 → 排队论(Erlang C/利用率悬崖)
- 有**调度/分配**:任务排程、装箱、路由、指派 → 优化(整数/组合规划)
- 有**工期/依赖**:项目排期、关键路径、里程碑 → 统筹论(CPM/PERT)
- 有**找东西**:搜索、探测、最优停止(何时停) → 搜索论
- 不确定性要**直接进模型**(不是事后补偿) → 随机规划

## ② 核心思维模式(这个分支怎么想问题)

1. **流的守恒**:任何「系统」先画进/出/驻留三股流——Little 定律 L=λW 先行,
   机制无关的守恒律比任何内部建模都快。
2. **随机模型的平稳态**:关心长时间行为,先问「稳吗」(ρ<1?),
   再问平稳分布长什么样(生灭→乘积形式)。
3. **边际分析**:最优解在「多一单位的收益=多一单位的成本」处——
   报童临界分位数、影子价格、价值迭代全是边际语言。
4. **地形先于算法**:拿到问题先判碗(凸)/格点(整数)/雾(非凸),
   地形决定武器(求解器/组合技巧/仿真/学习)。
5. **假设即合同**:每个「最优解」都签了分布已知、平稳、独立、期望准则的隐藏条款——
   参数漂移时合同作废。

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|---|---|
| Little 定律 L=λW | 知两量推第三;一切排队系统的速算与 sanity check |
| Erlang B/C 公式 | 多服务台容量规划(B=损失制,C=等待制) |
| Pollaczek–Khinchine 公式 | M/G/1 单服务台,一般服务分布的等待时间 |
| 报童临界分位数 F⁻¹(CU/(CU+CU短)) | 单期订货/产能预订(超储 vs 缺货权衡) |
| (s,S)/base-stock 策略 | 多期库存;结构先验嵌学习(Structure-informed) |
| 决策树+期望效用(vN-M) | 单人风险决策;计算信息的期望价值(EVPI) |
| 关键路径 CPM/PERT | 工期估计与压缩;PERT 给不确定工期三估计 |
| 二阶段随机规划/SAA | 随机性进约束;样本平均近似 |
| 价值迭代/策略迭代 | 小状态 MDP;贝尔曼方程直接翻代码 |
| power of two choices | 负载均衡:随机选 2 挑闲者,队长量级改善 |

## ④ 常见误区与禁忌

- **均值≠分位数**:平均快不代表 P99 快;排队性能语言是分位数。
- **利用率压到 100%**:M/M/1 的 W~1/(1-ρ),ρ→1 时延爆炸;70-85% 是舒适区。
- **predict-then-optimize 在非平稳流量下失效**:λ 在漂移就得在线学习+控制联合设计。
- **独立性假设遇到突发流量即碎**:真实流量自相似/重尾,泊松模型低估尾延迟。
- **「最优」的分布鲁棒性没检查**:分布是估出来的,先问 SAA 之外要不要 DRO。
- **把整数问题当连续解**:订 3.7 架飞机不算解;离散的税(对偶间隙)要认。

## ⑤ 与相邻分支的判别表 + 组合接口

| 症状像… | 判别 | 
|---|---|
| 优化 | 都是 min s.t.;**无随机性** → 优化;**随机性进模型** → 运筹(随机规划/排队) |
| 博弈论 | **单人**(自然掷骰)→ 运筹决策论;**多人互动**(对手会反应)→ 博弈论 |
| 概率论 | 概率论给「随机现象的描述」,运筹给「随机下的最优动作」;前者供料后者消费 |
| 应用数学/建模 | 建模给翻译手艺(量纲/渐近/适定性),运筹给决策内核;常见流水线:建模→运筹 |

**组合接口**:
- 运筹 × 概率论 → 排队论/库存论的地基(马尔可夫过程)
- 运筹 × 优化 → 二阶段随机规划本质是凸优化族
- 运筹 × 博弈论 → Wardrop 均衡/Braess 悖论(自私路由)
- 运筹 × 计算复杂度 → LP 强多项式、均衡计算 PPAD-完全
- 运筹 × AI → AI4OR(建模端 LLM、求解端 RL)、在线排队、DRL 库存
