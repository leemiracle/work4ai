# 讲透统筹论 · 工期的数学——关键路径与网络计划

> GB/T 13745-2009:11074 运筹学 三级「统筹论」
> **定位句**:这支负责「一大堆有依赖的工序,总工期多长、哪条链是命门、怎么压缩」——
> 中国名「统筹」(统筹兼顾),国际名 network planning/CPM/PERT。
> 家族:[讲透运筹学](../README.md)｜五问模板家族成员

## 诞生

1956-58 美国:DuPont 与 Remington-Rand 为化工厂检修排期发明 **CPM**(关键路径法,
工序时长确定);几乎同时美国海军「北极星」导弹项目(北极星潜艇计划)发明 **PERT**
(计划评审技术,工序时长三估计:乐观/最可能/悲观,应对不确定性)——
两大方法同月(1958)分别发表,史称巧合的双诞生。华罗庚 1960s 在中国推广「统筹法」,
田间地头讲 CPM,是为中文名「统筹」的来历。

## 核心问题

已解决:
- 关键路径定理:总工期=源到汇的最长路径;非关键工序有松弛(slack/浮动时间)
- 工期-费用权衡:压缩哪个工序最便宜(linear time-cost tradeoff 是 LP)
- PERT 的概率工期:三估计→β 分布→按期完工概率

未解决/前沿:
- 资源受限项目调度(RCPSP):工序还要抢人/机——NP-难,启发式与精确的拉锯
- 不确定工期的鲁棒调度(鲁棒性 vs 期望工期的 Pareto)
- 多项目/多代理的协同排期

## 这支最美的一个事实

**工期=最长路径**:总工期不由「平均工序」决定,而由最长链(关键路径)决定——
整个项目管理只有一条链在跑表,其余全是带缓冲的观众;
压缩任何非关键工序一毫秒都不缩短总工期。
(必然之美:并行世界的守恒——瓶颈即一切。性能工程师应在 Amdahl 定律里认出这张脸。)
