# 讲透参数规划 · 解随参数走——灵敏度分析的数学本体

> GB/T 13745-2009:11074 运筹学 三级「参数规划」
> **定位句**:这支负责「当目标系数/约束右端/系数矩阵里有参数在动,最优解怎么连续地跟着动」——
> 把「一个解」升级为「一族解」。
> 家族:[讲透运筹学](../README.md)｜五问模板家族成员

## 诞生

运筹学的实际客户从不问「最优解是多少」,他们问「**如果预算再多点呢?需求再低点呢?**」——
参数规划是对这个问题的正式化:Dantzig 学派 1950s 起把 (P(θ)) 的解 x*(θ) 作为 θ 的函数研究;
参数线性规划给出**临界域**(critical regions)分解:θ 空间被切成多面体片,
每片内最优基不变、影子价格不变——参数一跨片,世界换一副面孔。

## 核心问题

已解决:
- LP 参数解的全局刻画:临界域分解,解 x*(θ) 分片线性(参数 LP 完整理论,1950s-70s)
- 灵敏度分析:单个系数的允许变动区间(每个 LP 求解器输出的一部分)

未解决/前沿:
- MILP 的参数化解(整数解不连续,临界域理论碎片化)
- 多参数 MILP 与鲁棒优化的接口(盒不确定集⟺参数域)
- 大规模参数空间的主动学习(哪几个 θ 值值得真解一次)

## 这支最美的一个事实

**最优值函数是分片线性的**:min c(θ)^T x 的最优值 v(θ) 在 θ 空间上是有限片线性函数的拼图——
两个影子价格的世界在超平面上交接,像晶体的晶面。
(统一之美:LP 的全部解几何,压缩成一张凸的分片线性图。)
