# 讲透库存论 · 补货的数学——什么时候订、订多少

> GB/T 13745-2009:11074 运筹学 三级「库存论」
> **定位句**:这支负责「面对不确定需求,何时补货、补多少,让持有成本与缺货成本的总账最小」。
> 家族:[讲透运筹学](../README.md)｜五问模板家族成员

## 诞生

两个源头:报纸贩卖员的日常(单期订货,卖不完贬值、卖少了错过——「报童问题」名入教科书);
Arrow–Harris–Marschak 1951 把它一般化((s,S) 策略的最优性研究),
Clark–Scarf 1960 证明多级库存的级联分解——供应链科学的数学地基。

## 核心问题

已解决:
- 单期最优订量:临界分位数 F⁻¹(CU/(CU+CO))(报童闭式)
- 多期固定成本:(s,S) 策略最优( Scarf 1960,凸性/KB 函数法)
- 多级可分解:Clark–Scarf 级联,base-stock 策略

未解决/前沿:
- 需求非平稳/分布未知的库存控制——深度强化学习进仓库(2022 Gijsbrechts;
  2024 Geevers 多级 DRL;2025 Structure-informed:结构先验×学习)
- 可挽回性/替代性/时鲜品(降价策略)的多品种耦合

## 这支最美的一个事实

**最优订货量只是一个分位数**:订到 F⁻¹(CU/(CU+CO))——成本比(不是需求的均值!)
决定你该多备还是少备;需求分布只出借一个分位点,其余全部无关。
(极简之美:全分布的信息被两个成本数字压缩。)

## 假设与依赖

- 依赖:概率论(需求分布)、排队论(补货即对库存的「服务」)
- 假设代价:需求分布已知且稳(促销/季节即违)、提前期确定(随机提前期要重算)、
  单品种(多品种共享容量进入耦合)
