# 讲透排队论 · 等待的数学——到达×服务×容量的守恒律

> GB/T 13745-2009:11074 运筹学 三级「排队论」
> **定位句**:这支负责「为什么有等待、等多久、加多少容量才够」——一切排队系统的性能定律。
> 家族:[讲透运筹学](../README.md)(工程视角最近的一支)｜五问模板家族成员

## 诞生

Agner Krarup Erlang,1909,哥本哈根电话公司——「多少条线路/多少接线员才既不堵也不浪费」。
他给出的 Erlang B(损失制)与 Erlang C(等待制)公式是**运筹学最早的定量成果**,
比「运筹学」这个名词早 38 年。Kendall 记号(A/B/c/K,1953)与 Little 定律(1961)
随后把语言统一。

## 核心问题

已解决:
- 单/多服务台的平稳队长与时延(M/M/*闭式、M/G/1 的 P-K 公式)
- 稳定判据:ρ<1 才有平稳(否则队列爆开)
- 网络的乘积形式(Jackson 1957:耦合被流量守恒解开)

未解决/前沿:
- 非平稳(时变 λ)排队的精确分布——只有流体/扩散近似
- 重尾/自相似到达(真实互联网流量)下的尾延迟——泊松模型系统性低估
- 数据驱动排队:λ 未知时的在线调度(2023 起 Operations Research 主线)

## 这支最美的一个事实

**Little 定律 L=λW**:队长=到达率×逗留时间——不需要任何分布、任何服务规则、任何优先级假设,
从超市到 CPU 流水线到 TCP 连接池全部成立。(亲历:[`../experiments/00_mm1_little.py`](../experiments/00_mm1_little.py))

## 假设与依赖

- 依赖:概率论(马尔可夫过程、指数分布的无记忆性、更新理论)
- 假设代价:平稳性(冷启动失效)、独立到达(突发流量失真)、指数服务(一般分布走 P-K/M/G/1)
