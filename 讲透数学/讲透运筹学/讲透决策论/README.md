# 讲透决策论 · 单人决策的数学——期望效用、信息价值与最优停止

> GB/T 13745-2009:11074 运筹学 三级「决策论」
> **定位句**:这支负责「只有一个决策者、世界在掷骰子时,怎么选才理性」——
> 效用公理化、信息值多少钱、什么时候停止收集信息。
> 家族:[讲透运筹学](../README.md)｜五问模板家族成员

## 诞生

Bernoulli 1738(圣彼得堡悖论:为什么人们不愿为期望无穷的赌局付高价——效用概念的胚胎);
von Neumann–Morgenstern 1944《Theory of Games and Economic Behavior》给四条公理⟹期望效用表示定理,
决策论从此有公理地基;Savage 1954 把它推到主观概率;Wald 1950 统计决策论把「决策」
变成统计学自身的骨架。

## 核心问题

已解决:
- 期望效用表示:vN-M 四公理 ⟹ 存在效用函数使「选期望效用最大」(1944)
- 信息的价值:EVPI/VPI 的精确定义与计算(决策树回滚)
- 最优停止:秘书问题(1/e 律)、卖房问题的停止规则

未解决/前沿:
- 非期望效用(前景理论/秩依赖效用)的行为公理化与运筹模型的合流
- 部分可观测(POMDP)的信息获取决策——「做实验 vs 直接拍板」的一般理论
- 多目标下的偏好 elicitation(问几次能问出你的效用函数)

## 这支最美的一个事实

**秘书问题的 1/e 律**:n 个候选人依次到来、看完即走,最优策略是「先放前 1/e≈37% 不录用、
之后取首个比前面都好的」——成功概率竟与 n 无关,恒为 1/e。
(必然之美:有限信息下的最优探索-利用平衡,常数竟浮出。)
