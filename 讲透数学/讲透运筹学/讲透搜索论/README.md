# 讲透搜索论 · 寻找的数学——搜索力最优分配与最优停止

> GB/T 13745-2009:11074 运筹学 三级「搜索论」
> **定位句**:这支负责「目标藏在哪、我的搜索力有限,怎么分兵找到它的概率最大;
  以及什么时候该停止寻找」。
> 家族:[讲透运筹学](../README.md)｜五问模板家族成员

## 诞生

二战,美国海军反潜战分析组(ASWORG):德国 U 舰在大西洋,飞机搜哪里、搜多久?
Bernard Koopman 1946《Search and Screening》——搜索论的开山;
把「探测概率×密度」做成**探测函数**,搜索力分配变成一个(通常是凸的)最优分配问题。
它的近亲是最优停止理论(Chow-Robbins-Siegmund 1971 体系化)。

## 核心问题

已解决:
- 静态目标的最优搜索力分配(Koopman:凸探测函数下,边际增益均等化分配最优)
- 最优停止的存在性:单调问题停时存在(秘书问题 1/e、卖房阈值)
- 序贯检测(Wald 的 SPRT:假设检验的最快停时)

未解决/前沿:
- 移动目标搜索(moving target search)的一般理论——目标也博弈时(搜索博弈)
- 网络化的搜索(多智能体协同覆盖)
- 学习型探测函数(探测模型未知,边搜边学)

## 这支最美的一个事实

**Koopman 分配的边际均等**:最优搜索方案下,每块区域再多花一小时探测的边际发现率
彼此相等——沙漠搜救、海域扫雷、天文巡天共用这同一条「分兵法则」。
(极简之美:与报童分位数同宗——边际语言再次统治。)
