## 0 直觉：为什么"来源"必须分六层

### 0.1 混层穷举必然翻车

问"数学建模有哪些来源"，随手就能列出：微分方程、拟合、随机、图论、比例性、博弈、实验……但这张清单**必然重复且遗漏**——因为"随机"既是方法（Ⅲ）又是形态（Ⅵ）；"微分方程"既是理论（Ⅴ）又是"对变化建模"（Ⅳ）的载体；"比例性"根本不是"对什么建模"而是"怎么建"（Ⅲ）。**穷举之前先分层，MECE 才可能。**

### 0.2 纠错存档（为什么本章存在）

本系列初版分类把"比例性、几何性"当作"对象层（对什么建模）"的条目。核查发现：这两个词逐字来自 Giordano 教材 Ch2《The Modeling Process, **Proportionality**, and **Geometric Similarity**》——它们是**模型构建的初步方法**（怎么建），不是建模对象的类别（对什么建）。同类错误还有把"实验"轻并入"拟合"：Giordano 里 Experimental Modeling 是独立的章级方法。**教训：分类学的每一格都要有出处锚点，凭感觉归类必错。**

### 0.3 领土与地图：分类学不是本体（回应"建模是方法论"之问）

数学建模的本体是**方法论**——翻译的生产环与假设的手艺（[07 章](07-建模思维.md)），不是任何分类体系。本章六层坐标是这方法论的**地图**：帮建模者在"结构选择"一格定位决策，但户口本不等于工厂。方法论谱系中的位置：

- **广义应用数学**（学科目录义：数值/统计/优化/运筹/建模/金融数学…）：数学建模是其一员（教学 canon 如此）；
- **狭义应用数学**（Lin-Segal 手艺义：量纲/渐近/适定/稳定——[讲透应用数学](../讲透应用数学/) 的取义）：建模是其**上游半程**——管道为 `现实 → 建模(翻译) → 应用数学手艺(分析计算) → 决策`，两者互补不包含。

### 0.4 六层链条

```
Ⅰ 需求来源（谁要建模）──Ⅱ 领域来源（问题住哪）──Ⅲ 认识论来源（怎么得到）
                                                      │
Ⅵ 形态属性（先验分类）──Ⅴ 数学理论来源（用什么数学）──Ⅳ 对象来源（对什么建模）
```

前三层答"从现实到建模任务"，后三层答"从任务到数学结构"。任一现实模型 = 六维坐标（§7）。

## Ⅱ 领域来源：问题住哪个领域？

**[姜]** 中文教材传统的第一分类维度即"按应用领域"。穷举（开放集——领域无法真正穷尽，此处列主干）：

| 领域 | 领域特有结构 | 代表模型 |
|------|-------------|---------|
| 力学/物理 | 守恒律、场 | 弹簧振子、Navier-Stokes |
| 化学 | 反应速率律 | 反应动力学方程 |
| 生物 | 种群交互、遗传 | Lotka-Volterra、SIR |
| 医学/药理 | 房室、剂量 | 药代动力学房室模型 |
| 生态 | 承载力、网络 | 生态位、食物网 |
| 经济 | 均衡、激励 | 供求均衡、CGE |
| 金融 | 无套利、波动 | 期权定价（Black-Scholes） |
| 社会 | 传播、聚集 | 舆论动力学、ERGM |
| 军事 | 对抗、兰彻斯特 | Lanchester 作战方程 |
| 气象/海洋 | 多尺度场 | 数值天气预报（GCM/AIFS） |
| 地质 | 渗流、构造 | 油藏模拟 |
| 交通 | 流、排队 | 元胞传输模型 |
| 制造/物流 | 工序、库存 | 排队网络、EOQ |

**要点**：领域决定**先验结构的密度**——物理领域守恒律密集（机理来源占优），社会领域结构稀疏（数据来源占优）。这是"为什么物理学家瞧不起计量经济学模型"的分类学解释：不是水平差距，是**领域可供给的机理密度**差距。

## Ⅲ 认识论来源：模型怎么得到？（本章重心）

### Ⅲ.A 姜启源三大途径 **[姜]**

1. **机理分析**——从内部规律推导结构。工具箱：
   - 守恒律/平衡原理（质量/能量/动量守恒 → 微分方程）
   - 微元法（取小微元列平衡）
   - 变分原理（最小作用/最小能耗 → Euler-Lagrange）
   - **类比法**（把成熟定律迁移到新域：热传导↔粒子扩散↔舆情传播）
   - **量纲分析法**（Buckingham π：不求精确解也锁定无量纲群结构）
2. **测试分析**——从数据反推关系。统计回归是其主体；**对动态系统的测试分析特称系统辨识**（辨识出状态空间模型的参数）。
3. **机理 + 测试结合**——结构用机理定、参数用测试定（SIR 的方程来自机理，β/γ 由发病数据拟合）——工程实践的主流形态。

### Ⅲ.B Giordano 构建工具链 **[Gio]**（"怎么建"的初阶清单）

| 工具 | 一句话 | 典型用法 |
|------|--------|---------|
| 图解法 | 先画散点/曲线看形态 | 变量筛选第一步 |
| **比例性** | 假设 y=kxⁿ，log 变换线性化拟合 | 风阻∝v²、代谢∝体重^{3/4} |
| **几何相似** | 形状同、大小异（对应角相等、对应边成比例） | 船模→实船阻力换算、动物骨骼承重 |
| **量纲分析** | π 定理强制无量纲群 | Re 数、马赫数 |
| **拟合**（Ch3） | 最小二乘/插值定参 | 回归家族 |
| **实验建模**（Ch4） | 设计实验主动产数据（DOE） | 响应面法 |
| **仿真**（Ch5+） | 蒙特卡洛/离散事件/代理基 | 无法解析时兜底 |

> **纠正存档**：比例性、几何相似、拟合、实验四项在本系列初稿曾被错位到"对象层"——它们是 Ch2-Ch4 的章级**方法**，出处见 [Gio 目录](https://faculty.cengage.com/works/9781285050904)。

### Ⅲ.C 现代扩展 **[标注：传统三途径之外的新增]**

- **数据驱动/AI**：黑箱函数族拟合（神经网络）——[00 章](00-什么是数学建模.md) 第三产线；
- **混合建模**：PINN/UDE——机理骨架+数据血肉（[06 章](06-AI建模新范式.md)）；
- **符号发现**：SINDy/PySR 从数据反推可解释方程（拟合与机理的合流）；
- **LLM 辅助**：自然语言→模型草稿——六条动线中最不成熟者（[08 章 §2](08-分支X光五问.md)）。

### Ⅲ.D 认识论决策树

```
机理已知？──是──→ 机理分析（守恒/变分/类比/量纲）
   │否
数据可得？──是──→ 拟合/实验建模/系统辨识
   │部分           └─ 结构机理定、参数数据定（姜三途径之"结合"）
   └──部分已知 ──→ PINN/UDE 混合
都不行？     ──→ 仿真（蒙特卡洛/离散事件/agent-based [T23]）
```

## Ⅵ 形态属性：模型的先验分类

**[HEC]**/[英文通说] 六对属性（+箱色），每对独立打分：

| 属性对 | 判别问题 | 左例 | 右例 |
|--------|---------|------|------|
| 线性↔非线性 | 叠加原理成立？ | LP | SIR |
| 确定↔随机 | 同输入同输出？ | 轨道方程 | 蒙特卡洛 |
| 连续↔离散 | 变量取连续值？ | ODE | 差分/图 |
| 静态↔动态 | 含时间？ | 回归截面 | 动力系统 |
| 解析↔仿真 | 有闭式/数值解？ | M/M/1 解析 | agent-based |
| 白↔灰↔黑 | 机理透明度？ | 守恒律 | 神经网络 |

**[待考]** 目的二分（prescriptive 规范型 vs descriptive 描述型）见于英文维基传统，本轮未核到一手教材出处，暂列待考。
另见 [T23]：微分方程 vs 代理基（agent-based）是仿真范式之争的主轴——形态属性的选择本身是范式承诺。

## 7 坐标系：任一模型 = 六维坐标

| 模型 | Ⅰ需求 | Ⅱ领域 | Ⅲ认识论 | Ⅳ对象 | Ⅴ理论 | Ⅵ形态 |
|------|------|-------|---------|-------|-------|-------|
| SIR | 科研/政策 | 流行病 | 机理+测试结合 | 变化 | ODE | 确定·连续·动态·白 |
| PageRank | 商业 | 互联网 | 类比（随机游走） | 关系结构 | 图/马尔可夫 | 确定·离散·静态·灰 |
| Black-Scholes | 商业 | 金融 | 机理（无套利） | 不确定性 | 随机微积分 | 确定·连续·动态·解析 |
| 物流仓储仿真 | 工程 | 物流 | 仿真 | 过程流程 | 排队/离散事件 | 随机·离散·动态·仿真 |
| PINN 求解器 | 工程/科研 | 物理 | 混合 | 变化 | PDE+神经网络 | 黑中嵌白 |
| CUMCM 获奖论文 | 竞赛 | 年度主题 | 拟合+机理拼装 | 视题 | 多理论组合 | 组合态 |

**用法**：读任何论文的模型节，先在心里打六个格子——格子全满即"来源清晰"；某格含糊（常见：Ⅲ 说不出是机理还是拟合）通常是模型可辩护性最弱的角落。
