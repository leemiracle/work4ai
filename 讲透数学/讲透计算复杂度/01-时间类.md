## 1 直觉：预算决定世界

把计算想成旅行：**时间类 = 给你多少预算，你能到达哪些城市**。

- **P**（多项式时间）：预算随地图大小平缓增长（n, n², n³…）。这是"现实可行"的数学代名词——n 翻倍，预算只多项式翻倍。
- **NP**：你可以**免费猜**一条路线，只需验证它通。猜不要钱、验要钱——这是"证明可验证"的世界：答案是 yes 当且仅当存在一张多项式长的"通行证"。
- **PH**（多项式层谱）：允许**猜与驳交替**——"存在一条路，使得对所有反对意见，存在反驳之反驳……"。猜的轮数是层数。
- **EXP / NEXP**：预算指数增长的世界。戏剧性的是：**从 P 到 EXP 的每一步鸿沟，我们只知道其中一道是真的**（P ⊊ EXP）。

四个反常识的直觉校准：

1. P ≠ NP 未证，但 **P ⊊ EXP 已证**（谱系定理）——所以"资源多确实多算"在足够大的尺度上成立，只是 polynomial 尺度上不知道；
2. NP 不是"不可解"——NP 里的每个问题都有指数暴力算法，NP 是"**验证**便宜"的世界；
3. PH 可能塌成第二层甚至 NP——层谱的"高"极其脆弱（见 2.3）；
4. **NP ∩ coNP**（双向都有证明的问题）里住着整数分解——它难，但难得"有分寸"，这正是密码学选它的原因。

### 2.2 定理一：时间谱系定理（Hierarchy Theorem）

**定理**（Hartmanis-Stearns 1965）：对任意可构造 f(n) > n，

```
DTIME(f) ⊊ DTIME(f · log f · log log f)
```

**证明骨架**（对角化）：枚举所有 f 时间内的机器 M₁, M₂, …，构造 D(i) = 反转 Mᵢ(i) 的答案。D 在 DTIME(f·log f·log log f) 内可算（带模拟开销），但与每个 Mᵢ 在输入 i 上不同——D 不在任何 DTIME(f) 机器的语言里。

> **反直觉发现**：谱系定理**无条件成立**——不需要任何假设，纯对角化就赢了。但同样的对角化遇到 P vs NP 就失灵（见 2.5）。**同一把刀，砍得动确定时间、砍不动非确定性**——非确定性破坏了"模拟 Mᵢ 再反转"的确定节奏（模拟非确定机需枚举路径，开销爆炸）。

**推论链**：P ⊊ EXP；NTIME 也有谱系（SFM78，且条件更弱：f(n+1)=o(g) 即可）——所以 NP ⊊ NEXP。这两个"隔层分离"是我们唯一无条件拿到的 polynomial 世界边界。

### 2.3 定理二：Cook-Levin 与 NP 完全性

**定理**（Cook 1971 / Levin 1973）：SAT 是 NP-完全的——NP 里每个问题都可在多项式时间内归约到 SAT。

**骨架**：非确定图灵机的每一步是局部选择；把"输入 x 上存在接受计算"编码为"这组布尔变量（每格每步的内容）满足这堆子句（每步的合法转移）"。**计算的历史表本身就是一张巨大的 SAT 实例**。

> **反直觉发现**：Cook-Levin 的本质是"**计算可以把自己变成公式**"。此后 3000+ 个 NP-完全问题（TSP、团、着色、整数规划……，见 [`NPC`](图鉴/卷4-M至O.md) 词条）本质上都是同一张历史表的化妆舞会。Karp 1972 展示了这场舞会的规模，复杂度理论从此从"研究机器"转向"研究问题之间的归约网络"。

### 2.4 定理三：Ladner——中间地带必在

**定理**（Ladner 1975）：若 P ≠ NP，则存在 NP 中既非 P 也非 NP-完全的问题（NPI）。

**骨架**：对角化地"挖洞"——构造一个语言，它在 P 里被人为推迟（每层只对足够长的输入激活），又不够硬到能归约 SAT。

> **反直觉发现**："不全则必有中间"听起来像废话，但**构造**这个中间语言需要精心的"自阻"工程。候选住客：图同构（[`GI`](图鉴/卷3-F至L.md)，在 NP ∩ coAM）、整数分解（在 NP ∩ coNP）——都"疑是 NPI"，但证明任何一个都蕴含 P ≠ NP。**NPI 是 P≠NP 的免费赠品，但我们一个都指认不了。**

### 2.5 定理四：Baker-Gill-Solovay——相对化障碍

**定理**（BGS 1975）：存在 oracle A 使 P^A = NP^A，也存在 oracle B 使 P^B ≠ NP^B。

**骨架**：取 A 为 PSPACE-完全（则 NP^A ⊆ P^A 因为 P^A 可问遍多项式空间）；取 B 为对角化构造的"稀疏难语言"。

> **反直觉发现**：这是 2.2 的谱系定理的"反面镜子"——对角化能证 P ⊊ EXP，但 BGS 说明：**任何只依赖"模拟+反转"的黑箱技术，都不可能区分 P 与 NP**，因为它在两个 oracle 世界里会同时"成功"。1975 年这一发现把 P vs NP 从"难题"升格为"需要新方法的问题"。50 年后，新方法（交互证明、代数化）攻克了 IP=PSPACE、MIP*=RE，却仍未回到 P vs NP 本尊——见 05 章。

### 2.6 PH：会塌的塔

PH 的每一层 Σ_kP 有完全问题（Σ_k-SAT：k 层量词交替的 SAT）。三条塌缩定理（每条都是"反直觉发现"级别的）：

- **Karp-Lipton**（1980）：NP ⊆ P/poly ⇒ PH 塌到 Σ₂P。（"NP 有多项式电路"这么一个电路世界的命题，竟能压塌整个层谱——03 章展开）
- **塌一级全塌**：Σ_kP = Π_kP ⇒ PH = Σ_kP。
- **Toda**（1991）：PH ⊆ P^#P（一次计数统治全塔——05 章主角）。

没有人知道 PH 是否无限。**主流猜想：PH 无限**（它是"量词交替=更多能力"的信仰化身）。

## 3 Python：谱系定理的体感

`experiments/01_time_hierarchy.py` 做一件朴素的事：固定运算预算 B，对每个增长率 f（n, n log n, n², n³, 2ⁿ），求"预算内可处理的最大输入规模 n_max"。输出一张表：

```
预算 1e6:  n→1e6   n·logn→~6e4(迭代测得)  n²→1e3  n³→1e0x  2ⁿ→~20
预算 1e9:  n→1e9   ...                    n²→~3e4 n³→1e3  2ⁿ→~30
```

每一行的相邻列是"同一预算下不同资源阶级能吃下的世界大小"——**谱系定理说的"严格分离"在实践预算里就是这些触目惊心的数量级差**。多项式之间差 3 个数量级尚可喘息，多项式碰上 2ⁿ直接是两个宇宙。（注意：实验给的是直觉而非证明——谱系定理的分离是"存在语言"，不是"所有语言"。）

## 4 不足

1. **P vs NP 本体未解**，且三大障碍（00 章总览）中相对化障碍直接命中本章武器库——对角化在此止步；
2. **亚指数世界**（SUBEXP 与 NP 的关系）几乎全空：NP 是否有 2^{o(n)} 算法（SEH/ETH 话题，06 章细粒度侧）悬而未决；
3. **均匀性 vs 非均匀性**：P 是均匀的（一台机器服务所有长度），P/poly 不是（每长度一套电路）——两者之间隔着"建议串"的整个宇宙（03 章）；
4. 实践与理论的错位：SAT 求解器（CDCL）在百万变量实例上飞快，而理论只保证指数最坏情形——**"最坏情况复杂度"对实践的钝感**是 07 章的主题。

## 5 应用

- **密码学**：单向函数 ⟺ P ≠ UP（[`UP`](图鉴/卷6-R至Z.md)）——最坏情形单向性是密码学的复杂度地基；NP ∩ coNP 里的分解问题撑起 RSA；
- **数据库/验证**：CSP、SAT 求解器是 NP 完全性理论"反向盈利"的样板——知道 NP-难，才有了 30 年的启发式与参数化投资（06 章）；
- **AI**：LLM 的推理链长度 ↔ 计算步数；"猜证结构"（先猜后验）正是 NP 的直觉在提示工程里的投影；
- 兄弟系列：[讲透优化 12-松弛舍入](../讲透优化/12-松弛舍入.md)消费 NP-难度判定；[讲透博弈论](../讲透博弈论/)的机制设计以 NP-难为"防策略操纵"之盾。
