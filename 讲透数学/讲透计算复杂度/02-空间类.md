## 1 直觉：空间可以反复利用，时间不能

时间是一条单行道——花掉的步数回不来；空间是一块黑板——**写满、擦掉、再用**。这个看似平凡的区别，造就了空间类与时间类的三大性格差异：

1. **空间比时间便宜**：PSPACE ⊆ EXP（多项式空间只有指数多种格局，重复格局即入循环可剪）。反过来不成立吗？不知道——EXP ⊆ PSPACE 未被排除（但主流认为不可能）。
2. **非确定性对空间特别温柔**：Savitch 定理说 NSPACE(f) ⊆ DSPACE(f²)——只是平方，不是指数。对比时间侧 NTIME 与 DTIME 的天堑。
3. **空间类对补封闭得出奇整齐**：NL = coNL、SL = L、PSPACE = NPSPACE——每一个"非确定=补封闭"定理在当年都是意外。

直觉锚点：**可达性问题**是空间类的心脏。L = "无向图可达的确定版"，NL = "有向图可达的非确定版"，PSPACE-完全 = "量词交替的可达"（博弈）。整个空间世界可以读成"**图上行走的四种方式**"。

### 2.2 定理一：Savitch 定理

**定理**（Savitch 1970）：对 f(n) ≥ log n，NSPACE(f) ⊆ DSPACE(f²)。特别地 **PSPACE = NPSPACE**。

**骨架**（分治可达）：定义 PATH(a, b, t) = "从 a 经 ≤2^t 步到 b"。递归：PATH(a,b,t) ⟺ ∃m: PATH(a,m,t−1) ∧ PATH(m,b,t−1)。递归深度 t = O(log 步数)，每层存 O(f) 格局的描述——空间 O(f²)。**用同一个 m 变量反复调用，黑板擦了再用**——这正是空间可复用直觉的定理化。

> **反直觉发现**：非确定性在时间上可能价值连城（P vs NP），在空间上**只值一个平方**。更妙的是证明根本没用概率、没用博弈——纯分治。四年后人们才知道非确定空间的补封闭（2.3），但 Savitch 已经预示：空间世界的非确定性"没那么神秘"。

### 2.3 定理二：Immerman-Szelepcsényi 定理

**定理**（Imm88/Sze87，两人独立同时）：**NSPACE(f) 对补封闭**（f ≥ log n）。特别地 NL = coNL。

**骨架**（非确定地数出不可达）：要证"v 从 u 不可达"，非确定地**数出**从 u 可达的顶点总数 c，逐步核对每个顶点是否可达（可达性另有 NL 算法），最后验证 v 不在这 c 个里。计数用二进制记在 O(log n) 空间里。

> **反直觉发现**："猜"怎么可能证明"不存在"？——直觉上非确定性擅长证存在、补封闭该靠确定性。1987 年前整个社区默认 NL ≠ coNL（对比时间侧 NP vs coNP 的公认定式）。Szelepcsényi 是位来自匈牙利的博士生，据传审稿人第一反应是"这肯定错了"。**"数出全世界，再看你不在这里"——非确定性用记账打败了量词。**这也是第一个重要的**非相对化**结果（其证明打开了非确定机器的内部结构），为后来 IP=PSPACE 的非相对化证明埋了伏笔。

### 2.4 定理三：Reingold 定理

**定理**（Reingold 2004）：**SL = L**——无向图 s-t 连通性（USTCON）在确定对数空间可解。

**骨架**：随机漫步对数空间可解（AKL+79 的 RL 算法）；Reingold 用 **zig-zag 乘积**（Reingold-Vadhan-Wigderson 的-expanders 构造）把随机漫步"去随机化"：把图逐层替换为度数规则、谱隙可控的膨胀图，让确定性走法覆盖与随机漫步同样的混合效果。

> **反直觉发现**：这是**无条件的去随机化**——不靠任何电路下界假设，直接把一个天然随机的问题（醉汉游走）用确定算法解决。BPP = P 的去随机化猜想（04 章）至今依赖硬度假设，而 L = SL 说明**在最低资源档位，去随机化是免费的**。顺带的教训：连接器（expander）这个纯组合对象，成了复杂度理论的万能零件（它还出现在 UST外 的 PCP 构造、RAM 分析、极值图论……）。

### 2.5 定理四：PSPACE 的四张脸

PSPACE 同时是：

1. **量词交替时间**：AP = PSPACE（CKS81）——交替图灵机多项式时间 = 图灵机多项式空间（AL = P、APSPACE = EXP 一起构成时间↔空间对偶三联）；
2. **交互证明**：IP = PSPACE（Shamir 1990，05 章主角）；
3. **博弈**：TQBF（量词布尔公式，"与神对弈存在必胜策略吗"）是 PSPACE-完全的；**多项式空间=有限完美信息博弈可解性的精确度量**；
4. **逻辑**：FO(2^{n^{O(1)}}) = FO(PFP) = SO(n^{O(1)}) = SO(TC)（00 章 Fagin 谱系的空间端）。

> **反直觉发现**：第 3 张脸最深远——**国际象棋/围棋式的博弈求值天然 PSPACE-难**（严格说 EXPTIME，因棋局长度），而"简单"的一阶量词交替（QBF）已经 PSPACE-完全。空间类的完全问题几乎全是**博弈**：QBF、地理游戏（Geography）、隐式图可达。**空间买到的不是"更多步数"，而是"更深的对抗"。**

### 2.6 DET 与行列式的地位

DET（Cook 1985）：L-归约到 n×n 整数行列式计算的类。已知 NL ⊆ DET ⊆ NC²。行列式是 GapL-完全（[`DET`](图鉴/卷2-C至E.md)/[`GapL`](图鉴/卷3-F至L.md) 词条）——**一个线性代数原语悄悄统一了对数空间非确定世界的下界**。同时 BPL ⊆ DET（Coo85）：随机对数空间也能被行列式（积分/计数）驯服。工程侧的呼应：BDD 状态空间操作（形式化验证）几乎全是线性代数与图可达——**02 章是形式化验证工具箱的复杂度地基**。

## 3 Python：空间预算的体感

本章没有独立实验（空间对数直觉弱），改用两个"脑内实验"+一个回指：

- **格局图**：把 NL 机器的"格局"（工作带内容+头位置）当顶点、转移当边——一切空间类的证明都是在这张指数大的隐式图上做文章（Savitch 分治、IS 计数、Reingold 漫步都是"怎么在看不见全图时走图"）。
- **对数空间有多大**：输入 n 位，工作带 log n 位 = 只够存一个**指针**。L 类的算法本质是"指着输入绕圈"——这就是为什么 USTCON 在 L 里令人震惊：**没有栈、没有递归、只有一个指针**的机器学会了判断连通。
- 回指 [`experiments/06_fpt_branching.py`](experiments/06_fpt_branching.py)（06 章）：分支搜索的递归深度就是空间预算——FPT 的 f(k) 深度递归正是"参数化空间"的实践。

## 4 不足

1. **L vs NL 未解**——有向图可达是否有确定对数空间算法，是对数空间世界的 P vs NP（甚至 RL =? L 也未解，但 RTV05 给了强证据）；
2. **PSPACE vs EXP 未分离以外的几乎所有关系都开着**：P = PSPACE 未被逻辑排除（虽然没人信）；
3. Savitch 的 f² 目前仍是最优上界方向之一——**非确定空间的"真实价格"（可能就是 f 本身）悬而未决**；
4. 实践侧的"状态爆炸"（state explosion）：模型检测工具（见 §5）处理的正是 PSPACE/EXPTIME 完全问题的中低规模实例——理论边界与工程规模之间的**缓冲带**由 BDD、SAT 编码、抽象解释（升高保真换取可判定）填补。
