  按 `===== <span id="…">` 词条标题切分得 614 个词条，同页重复 id 丢弃 4 个
  （`distnp` / `o2p` / `p` / `rg` 各出现两次，取首个），**去重后 610 个类**。
- 解析脚本：[`../experiments/00_zoo_pipeline.py`](../experiments/00_zoo_pipeline.py)
  （确定性、可复跑：raw 缓存 + 脚本 = 任何人都可重验本口径）。

  每条附原文锚点链接（`Complexity_Zoo:<字母>#<span-id>`）。
