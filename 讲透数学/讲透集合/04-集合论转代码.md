## 二、走廊详解

### 2.1 对象 → 数据结构（已在手）

frozenset = 良基集合；秩 = 树高（00 章实验）；Mostowski 塌缩 = 图到集合的规范化编译（03 章实验）。
边界：只能表达遗传有限集；无穷对象要靠**描述**（代码）而非**枚举**（数据）。

### 2.2 证明 → 类型

Lean/Coq/Agda 的世界：命题即类型、证明即程序。集合论的 Mathlib 层：
`Set α`（子集即谓词 `α → Prop`）、`Ordinal`/`Cardinal` 全套序数算术、ZFC 的 pSet 编码。
本章实战：Cantor 定理的 **纯 core Lean 证明**（无 Mathlib，本机 v4.33.1 编译通过，见第四节）。

### 2.3 独立性 → 布尔值模型（Flypitch 路线）

力迫的机器友好改写：不造新模型，而是**把真值从 {0,1} 换成完备布尔代数 B**——
宇宙照旧，逻辑多值。CH 在 Cohen 代数里的真值既非 1 也非 0 ⟹ 不可判定。
Flypitch（Han–van Doorn）用这条路把"ZFC⊥CH"整个塞进 Lean（`pSet` → 布尔值集），
**绕开了元理论里的可数传递模型与泛型滤子**——算法化独立性的样板。
（01 章方向四；Lean 4 移植收录于 Palomar 注册表。）

### 2.4 Borel 集 → Borel code（描述集合论的程序观）

> **Borel 集不是点集，是程序**：`("interval", a, b) | ("compl", c) | ("union", c₁, c₂) | ("bigunion", k ↦ cₖ)`
> ——一棵良基树。Borel 运算 = 根节点的模式匹配；成员判定 = 树递归。

这就是 02 章"可定义性层级"的可执行形态：Borel 层级 = **程序嵌套深度**。
实验 A 实现解释器并演示一个意外的诚实发现：**成员判定是半可判定的**
（"在集合里"会停机，"不在集合里"可能跑 forever）——算术层级 Σ₁ 在 Borel code 上的直投影。

### 2.5 无穷组合 → SAT

无穷组合命题（Ramsey 型：任染色必有单色团）的**有限碎片**是有限组合问题，
编码成 SAT 实例交给求解器。战绩：Schur 数 S(5)=160（Heule 2018，200PB 证明）、
部分 Van der Waerden 数的更新都靠 SAT。走廊的性质：**SAT 只能证有限陈述**，
但"对一切 n"的归纳外壳仍要人写——机器证 k，人证 k→k+1。

### 2.6 力迫 → 迭代逼近（对角化的超穷推广）

力迫的算法骨架（Rasiowa–Sikorski 定理）：

```
条件 = 信息的有限片段 p（如：实数前 k 位）
偏序 = 片段加信息（p ≤ q ⟺ q 扩展 p）
密集集 D = "某项要求迟早要被满足"的条件的集合
泛型对象 = 与每个密集集都相遇的信息片段链的并
```

**定理**：对任何**可数**多个密集集，总能逐个相遇地把片段接长——这是纯算法。
（不可数密集集才需要存在性论证——见边界一节。）

> **反直觉发现**：单步力迫**就是**对角论证——
> "逃逸集 S={x : x∉f(x)}" ⟺ "条件 p 强迫 g≠f"。
> **对角论证是力迫的一步特例；力迫是对角论证的超穷次串联。**（实验 B 可执行地展示这一点。）

## 四、Lean 层：纯 core 编译 Cantor（无 Mathlib）

本机 Lean v4.33.1（独立工具链）单文件编译通过：

```lean
-- 集合的 Cantor 定理（谓词版）：没有 f : α → (α → Prop) 是满射
-- （本机 v4.33.1 独立工具链编译通过，2026-09-06）
theorem cantor_theorem (f : α → α → Prop) : ∃ s, ∀ x, f x ≠ s := by
  refine ⟨fun x => ¬ f x x, fun x h => ?_⟩
  have e : f x x = ¬ f x x := congrFun h x
  have np : ¬ f x x := fun p => e.mp p p
  have p : f x x := e.mpr np
  exact e.mp p p
```

证明体对应对角论证四步：设 s 为逃逸谓词（`fun x => ¬ f x x`）、反设 f x₀ = s、
在 x₀ 处得到 `e : P = ¬P`（自指方程）、用 e 两面各构造一次让 `¬P` 与 `P` 相撞（`e.mp p p`）。
> 写作教训：`np` 的构造（`fun p => e.mp p p`）容易误写成 `fun np => np (…)`——
> 那是在构造 `¬P → False` 而不是 `¬P` 本身，类型系统当场抓出来。**这就是 Lean 层存在的意义。**
Mathlib 侧继续检索 `cantor`、`SetTheory.Cardinal.*`、`Ordinal.*`（配 `../讲透Lean4数学/`）。

## 五、边界：三层不可机械化（诚实清单）

1. **哥德尔层（制度性）**：不存在一致的、递归可枚举的、足以含算术的理论能证明自己的所有真命题
   ——"数学全自动化"不是工程难题，是被证明禁止的目标
2. **对角层（单步不可约）**：对角论证是**每个**机械化努力内部的不可约步骤——
   任何证明搜索程序都有自己的逃逸命题。它是机器的对手戏，不是机器的障碍物
3. **力迫层（可数性断层）**：Rasiowa–Sikorski 只保证**可数**多个密集集可算法性相遇；
   完整力迫的泛型滤子对不可数密集集的存在性靠偏序完备性/AC——**泛型对象原则上不是算法产物**。
   （布尔值模型走廊 2.3 正是为此而生：把"造泛型对象"改写成"算真值"，绕开断层）
