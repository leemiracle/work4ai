# 讲透集合 · 从悖论到宇宙 V（ZFC 体系结构）

> 集合论不是"数学的一个分支"——它是**全部数学的地基语言**。分析、代数、概率的每一个对象，最终都是集合。
>
> 本系列用「直觉 → 数学 → Python 实验 → Lean 形式化 → 不足 → 应用」六层讲透它，
> 并作为**分支X光五问**模板的首例（见 [宇宙 README](../README.md#五分支x光五问新系列入场宪法)）。

---

## 〇、这个系列回答什么

一切数学对象都能写成集合吗？——能，而且只用了 **一页纸的公理**。但这页纸：

- 造出过悖论（罗素 1901：`R = {x : x ∉ x}`，R∈R ↔ R∉R，一行毁掉朴素集合论）
- 欠着债（连续统假设 CH：ZFC 既证不了它也证不了它的否定——数学最著名的未决不是难题，是**体系设计的留白**）
- 藏着引擎（对角论证——哥德尔不完备、图灵停机、Cantor 定理，同一台机器的三次点火）
