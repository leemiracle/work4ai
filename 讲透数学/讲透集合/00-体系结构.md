## 一、直觉层：为什么"体系结构"是集合论的第一问题

### 1.1 朴素集合论的一行死刑（罗素 1901）

Cantor 之后三十年，数学家的共识是：**任何性质都能定义一个集合**——

> "所有满足性质 φ 的东西"构成一个集合：`{x : φ(x)}`（朴素概括公理）

罗素把 φ 取成 `x ∉ x`：

```
R = {x : x ∉ x}
R ∈ R  ⟺  R 满足"x ∉ x"  ⟺  R ∉ R        ←→  R ∉ R
```

一行，无解，朴素集合论死。**注意死刑的执行方式**：不是算错，是"表达本身自相矛盾"——
这预示了本系列的中心命题：**集合论的体系结构 = 对"造集权限"的权限管理**。

### 1.2 悖论不是 bug，是边界探测器（反直觉发现 #1）

> **啊，原来如此**：罗素悖论、Cantor 悖论（|V| 问题）、Burali-Forti 悖论（最大序数）——
> 三个悖论不是三起事故，而是**同一台机器（对角论证）在不同位置的读数**。
> 它们精确标出了"朴素造集权限"的三处越界。后来哥德尔不完备定理、图灵停机问题，
> 还是这台机器。**学会对角论证 = 学会集合论的引擎。**（跑 `experiments/00_cantor_diagonal.py`）

### 1.3 体系结构的答案：公理化 = 权限收窄

ZFC 的设计思想一句话：**不再允许"无中生有"造集，只允许从已有集合出发按白名单操作造集**。
白名单就是下面那十条公理——它们分三类干三种活。

## 二、数学层：ZFC 公理逐条地图（挡住什么 / 买到什么）

> 通行版本列 8-10 条（空集公理可由无穷+分离推出，故有的书 9 条有的 10 条）。本表按 **10 条** 列出。

### 2.1 三类分工总览

| 类 | 公理 | 干什么活 |
|----|------|---------|
| **建设类**（造新集的权限） | 配对、并、幂集、无穷、选择 | 从小造大 |
| **限制类**（挡悖论的围栏） | 分离、替换、正则 | 控制造集越界 |
| **同一类**（身份判定） | 外延 | 定义什么叫 `=` |

### 2.2 逐条：挡住什么 / 买到什么

| # | 公理 | 一句话内容 | 挡住什么 | 买到什么 |
|---|------|-----------|---------|---------|
| 1 | **外延** Extensionality | 元素相同则集合相等 | —（不挡东西） | `=` 的定义：集合无序、无重复、无"隐藏属性" |
| 2 | **配对** Pairing | 任给 a,b 存在 {a,b} | — | 二元组→关系→函数的起点 |
| 3 | **并** Union | 任给族 F 存在 ⋃F | — | 把"集合的集合"摊平；序数加法的原料 |
| 4 | **幂集** Power Set | 任给 X 存在 P(X)={X 的全体子集} | — | **Cantor 定理的舞台**：\|X\|<\|P(X)\|；ℝ 的构造（实数=自然数的子集）；测度论要有"所有可测集"可用 |
| 5 | **无穷** Infinity | 存在归纳集（含 ∅ 且对后继封闭） | — | ℕ 的存在性。**它是承诺不是限制**——有限主义者拒绝它，而全部现代分析建立在它上面 |
| 6 | **分离** Separation（模式） | 已有集合 A 内，可切出 {x∈A : φ(x)} | **罗素悖论**：只能从已有集里切，不能全域圈地。"所有集合的集合"造不出来了 | 子集的存在性；空集（从无穷集切 ∅） |
| 7 | **替换** Replacement（模式） | 函数的定义域是集合 ⟹ 值域是集合 | 间接限制：函数不能把集合"吹爆"成真类 | **超穷构造的许可证**：ℵ_ω、V_α 层级都靠它（1922 Fraenkel/Skolem 补上，Z→ZF 的关键升级） |
| 8 | **正则** Foundation | 每个非空集 A 有元素与 A 不相交 | **自指循环**：x∈x、x∈y∈x、无限下降 ∈ 链全部禁止 | 宇宙分层 V_α 与秩函数：每个集合有"出生层"，真类与集合有了分界线 |
| 9 | **选择** Choice (AC) | 两两不交的非空集族存在选择函数 | （不挡，是**付出代价**：Banach-Tarski 分球悖论） | 良序定理、Zorn 引理、**任意向量空间有基**、Tychonoff 定理。等价形式一抓一把 |
| 10 | （空集） Empty Set | 存在 ∅ | — | 起点（亦可由 5+6 推出，列出来是为了叙事完整） |

### 2.3 两栏读法示范（怎么背这页纸）

不用背——记住**三类分工 + 每条一句话**：

- 悖论围栏三件套：**分离**（不许全域圈地）、**替换**（不许吹爆）、**正则**（不许自指）
- 建设五件套：**配对/并/幂**（三个初级造集术）+ **无穷**（一次大胆承诺）+ **选择**（一次昂贵的团购）
- 身份一件套：**外延**（没有别的相等标准）

> 📌 02 章（语言特征）会展开：分离/替换是"模式"（schema）——一阶语言写不下"对每个公式"，
> 只能给每个公式各写一条公理。这个技术妥协本身塑造了集合论的表达力边界。

## 三、宇宙 V：集合世界的分层结构

### 3.1 秩累积层级（cumulative hierarchy）

正则公理保证每个集合有"出生证明"。按出生层把宇宙摊开：

```
V₀ = ∅
V_{α+1} = P(V_α)        ← 幂集是升层发动机
V_λ = ⋃_{α<λ} V_α      ← 极限层（λ 是极限序数）取并
V = ⋃_α V_α             ← 全体集合（α 跑遍所有序数）
```

每一层只容纳"元素都已出生"的集合——**你要造的集合的所有元素必须比你先存在**。
（跑 `experiments/00_zfc_finite_model.py`：亲手构造 V₀…V₄ 并逐条检查公理在有限层的行为。）

### 3.2 两种"大小"：序数与基数

- **序数（ordinal）**：良序集的"序型"——超穷世界的计数法。ω（自然数序型）之后是 ω+1, ω+2, …, ω·2, …, ω², …, ω^ω, …, ε₀, …
- **基数（cardinal）**：忽略顺序只看多少——ℵ₀=|ℕ|, ℵ₁=下一个, …；**CH 就是问 ℵ₁=?=|ℝ|**
- 序数是"计数的手指"，基数是"数出来的数"

### 3.3 集合 vs 真类：分界线在哪

"所有集合的集合 V"、"所有序数"——它们**太大**，不是集合，叫**真类**。
判断标准：能塞进某个 V_α 的是集合，塞不进的是真类。
罗素悖论的 R 恰好是真类——朴素集合论错在把真类当成集合使用。

### 3.4 无穷的大小等级（反直觉发现 #2）

> **啊，原来如此**：|ℕ| = |ℚ|（分数不比整数多——配对函数可枚举一切分数），
> 但 |ℕ| < |ℝ|（对角论证），且对任何 X 都有 |X| < |P(X)|（Cantor 定理）——
> **无穷不止一级，是无穷层塔**：ℵ₀ < 2^ℵ₀ < 2^(2^ℵ₀) < …，没有最大无穷。
> 直觉说"无穷就是无穷"，结构说"无穷是一座没有顶的塔"。

以 2026 年的活数学为坐标，ZFC 之上的集合论研究分四大支：

```bash
python3 -u experiments/00_cantor_diagonal.py    # 对角论证三连：|ℕ|=|ℚ|、|ℕ|<|ℝ|、Cantor 定理
```

第二个实验的关键发现（反直觉发现 #3）：**Python 的 `frozenset` 是正则公理的工程化身**——
你要构造 `x ∈ x`？构造器要求元素在集合之前就已存在，无限下降链在数据结构层面被禁死。
集合论的正则公理不是数学家的怪癖，是**可实现的数据结构不变量**。

## 七、不足层：这套体系结构的裂缝（诚实清单）

1. **不完备是制度性的**：哥德尔第二不完备——ZFC 证不了自己的一致性。地基无法自我担保，这是定理不是缺陷
2. **CH 欠债百年**：Gödel 1940（L 中 CH 成立）+ Cohen 1963（力迫造 ¬CH 模型）= CH 独立于 ZFC。
   "2^ℵ₀ 到底等于几"这个问题，当代数学没有共识答案——体系结构在这里**故意留白**
3. **AC 的代价**：接受选择公理就要吞下 Banach-Tarski（一球拆有限块重组成两个同大的球）。
   用 AC 是工程共识，但对它的哲学争论从未停止
4. **大基数的递归风险**：补 CH 靠新公理（大基数），新公理的一致性又靠更大的基数担保——地基下面还有地基，没有最底层
5. **实践陷阱**：日常写 `{x : φ(x)}` 是在用真类记号伪装成集合——多数时候无害，但每一本集合论教材的悖论章都是这种"无害"翻车的案例集
