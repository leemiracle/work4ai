# 02 · 语言特征：这套语言能说什么、逻辑性格如何、规范化到哪级

> **本章回答五问之三：该分支的语言特征（表达？逻辑？规范化？）。**
> 集合论的"语言"不是符号游戏——它是**数学世界的宪法用语**。
> 语言能说什么 = 数学能问什么。本章三节对齐五问原文的三个子问题。

## 一、表达：∈ 一阶语言的表达力地图

### 1.1 这门语言穷得惊人

一阶集合论语言 **L = { ∈ }**：没有函数符号、没有常量符号（∅ 可定义后充当），
只有两种原子句 `x ∈ y`、`x = y`，加 ¬∧∨∃∀。

**全部数学对象都是用这一个二元关系编码出来的**：
有序对 (a,b) = {{a},{a,b}} → 关系 = 有序对的集 → 函数 = 单值关系 →
ℕ = 最小归纳集 → ℤ/ℚ = ℕ 上的等价类 → ℝ = ℚ 的 Dedekind cut → 函数空间 → ……

> **反直觉发现 #1**：语言越穷，宇宙越富。一门只有一个符号的语言，
> 表达力覆盖全部数学——代价是编码深度：一个"实数"在这门语言里是一棵
> 深约 ω·3 层的集合树。**表达能力没丢，表达的人体工学丢了。**

### 1.2 量词预算：Δ₀ / Σ₁ / Π₁ 公式层级

表达力的真断层线在**量词是否受限（bounded）**：

| 层级 | 定义 | 例子 | 关键性质 |
|------|------|------|---------|
| **Δ₀**（受限） | 一切 ∃∀ 都写成 ∃x∈y、∀x∈y | "x 是序数"（传递+∈线性）；"x 是后继基数" | **绝对性**：在传递模型之间真假不变（见实验） |
| **Σ₁** | Δ₀ 前加无界 ∃ | "x 可数"（∃f: ω↠x 的分解版）；"x≠∅" | 向上绝对（小模型真 ⟹ 大模型真） |
| **Π₁** | Δ₀ 前加无界 ∀ | "x 无穷"（∀f: x→ω 非单射…） | 向下绝对 |
| 全量词公式 | 任意交替 | "x 是 ℝ 的非空完备子集"；CH 本身 | 无绝对性，模型相关 |

为什么 Δ₀ 重要：**只有受限公式才有跨模型的稳定真值**——
这是 00 章"公理是权限管理"在语言层的镜像：公理管造集，量词预算管提问。

### 1.3 说不出的话（表达力的硬边界）

| 想说的 | 能否一阶表达 | 为什么 |
|--------|------------|--------|
| "关系 R 良基" | ❌ | 需要"每个非空集有 R-极小元"——量词跑遍 P(域)，二阶；一阶化后只能是模式（紧性定理给出反模型） |
| "V 的真谓词" | ❌ | Tarski 不可定义：满足关系在内部不可定义 |
| "x 是全体集合" | ❌（成真类） | 说出来就罗素 |
| "x 传递" | ✅ Δ₀ | ∀y∈x ∀z∈y z∈x |
| "x 是序数" | ✅ Δ₀ | 传递 + ∈ 线序 |
| V=L | ✅（单句） | 但极长；ZFC 本身**不可有限公理化**（Montague：替换/分离是模式） |

> 模式（schema）这个技术妥协塑造了整门学科：ZFC 公理集是**无穷多条公理**的清单，
> "对每个公式 φ 各来一条"——一阶语言写不下"对一切公式"，只能批发。02.5 节的类理论就是来修这个的。

## 二、逻辑：完备 ↔ 不完备——精确边界在哪

### 2.1 三条基本定理（性格底座）

1. **完备性**（Gödel 1929）：句法可证 ⟺ 语义永真。集合论的证明论与模型论**严丝合缝**
2. **紧性**：一组公理的任意有限子集可满足 ⟹ 整组可满足——造反模型的工厂
3. **Löwenheim–Skolem 下降**：有无穷模型 ⟹ 有可数模型

### 2.2 Skolem 悖论（反直觉发现 #2）

> ZFC **证明**"ℝ 不可数"，但 ZFC 有**可数模型** M——M 里的 ℝ 当然可数（M 整个才可数！）。
> 悖论解法：M 内部**不存在** ω→ℝ_M 的双射——那个外部看得见的双射**不在 M 里**。
> **"不可数"是模型内的属性，不是上帝视角的属性。**
> 推论刻薄而深刻：一阶语言**管不住自己的模型**——你写下的公理永远收编不了你意图的那个宇宙。

### 2.3 不完备（Gödel 1931）落在集合论哪里

ZFC 含算术 ⟹ 对任何一致 r.e. 扩张 T⊇ZFC：
- T 有不可判定的 G(T)（"我在 T 中不可证"）
- T ⊬ Con(T)——**地基无法自我担保**（00 章不足层已记账）

**CH 独立性是完备性+不完备性的联合出品**：
Gödel 1940 用**内模型**（L：ZFC+CH 的最小宇宙）+ Cohen 1963 用**力迫**
（ZFC+¬CH 的扩张）——两边都是"造一个满足你要的一致性的模型"的完备性定理应用。
独立性不是"数学无能为力"，是**一阶语言的权限边界被精确定位**。

### 2.4 性格小结

| 性质 | ZFC 的答案 |
|------|-----------|
| 完备（语义=句法） | ✅ 每句要么可证要么有反模型 |
| 可判定 | ❌（含算术） |
| 完备（一切句子可判定） | ❌ CH 即证人 |
| 有限可公理化 | ❌（模式不可压缩） |
| 分类自己的模型 | ❌（Skolem） |

## 三、规范化：公理化的三条路线之争

| 路线 | 一句话 | 修好了什么 | 付出什么 |
|------|--------|-----------|---------|
| **ZFC**（一阶集合论） | 只有集合，公理是模式 | 最小主义，全部数学可编码 | 不可有限公理化；管不住模型；类无处安放 |
| **NBG**（von Neumann–Bernays–Gödel） | 集合+真类，类可作量化对象但受限 | **有限可公理化**；"所有集合的集合 V"是合法对象（真类）；保守于 ZFC（不增定理） | 类上的概括受限 |
| **MK**（Morse–Kelley） | 类上的概括放开 | 类论更强，大基数理论顺手 | 非保守；一致性强度高于 ZFC |
| **CZF/IZF**（构造主义） | 分离限制为受限公式，排中律默认不给你 | 与计算兼容：存在 = 可构造；直觉主义逻辑的程序解释（Curry-Howard 直通） | AC 崩坏；经典定理大面积重证 |
| **类型论**（Lean 的 CIC；HoTT/立方） | 不谈"全体集合"，谈宇宙分层内的类型 | 天生无罗素集（类型即围栏）；证明即程序，机械化原生 | "集合"成为派生概念；外延性要额外公理（univalence/quotient） |

> **反直觉发现 #3**：工程世界选了哪条？——**类型论**。每一个定理证明器（Lean/Coq/Agda）
> 都是"规范化路线之争"中类型论阵营的产品。你在 Lean 里写的每行证明都在投票：
> "数学的地基用分层围栏比用全域 ∈ 更适合机器"。详见 `../讲透Lean4数学/` 与 04 章。

## 五、Lean 层

- Lean 没有裸 ∈——`Set α` 是 `α → Prop`（子集即谓词），命题即类型
- 绝对性/层级这些模型论概念在 Mathlib 里以 `FirstOrder` 语言框架存在（`Mathlib.ModelTheory.*`）
- 本章概念的形式化对照表落在 04 章

## 六、不足层

1. **语言先于问题**：换语言（类论/类型论）会改变"什么问题可问"——地基选择不是中立操作
2. **绝对性的脆弱**：只有传递模型之间才享受 Δ₀ 绝对性；Skolem 模型大多不传递
3. **CZF 的代价常被低估**：构造性集合论与程序对应漂亮，但经典数学的迁移成本巨大
