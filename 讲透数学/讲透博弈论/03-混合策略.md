# 03 · 混合策略：无差异的艺术

> 混合策略 = 纯策略上的概率分布；混合策略均衡 = **互为无差异**的不动点。你混合不是为了自己更好，是为了让对手猜不透——而均衡里对手的混合恰好也让你猜不透。本章手推 2×2 混合公式、完整手算罚点球 4/7、给出支撑集法的一般流程，然后兑现 02 章的承诺：**全系列唯一完整走通的存在性证明主脉 Sperner → Brouwer → Kakutani → Nash**。

**点球大战的第 12 轮**。守门员知道你惯用右脚，你知道他知道，他知道你知道他知道——02 章的塔楼在这里只剩一个问题：**往哪边踢？**数据说话（同侧扑救得分率低）：踢左被扑住只得 0.65，踢右被扑住更惨，0.55；猜对方向则各得 0.95。若你总踢右（自己顺脚），守门员终将只扑右；若你按"上周骗过他"的剧本踢，你的剧本也在被读。唯一不被剥削的踢法是**掷骰子**——而骰子不是均匀的：本章将算出踢左 4/7、踢右 3/7。为什么偏偏是这两个数？因为**你的概率由对手的无差异决定**——整章的钥匙就这一句。

## 一、混合策略：把决策变成分布

**定义**：玩家 i 的混合策略 σᵢ 是纯策略集 Sᵢ 上的概率分布（全体混合策略构成概率单纯形 Δ(Sᵢ)）；纯策略是退化混合（概率 1 压一点）。收益按期望计算——由 vNM 定理（01 章）背书：

$$u_i(\sigma_i, \sigma_{-i}) = \sum_{s_i}\sum_{s_{-i}} \sigma_i(s_i)\,\sigma_{-i}(s_{-i})\, u_i(s_i, s_{-i})$$

关键结构性质：**期望收益对自身概率是线性的**。这一个词（线性）将在 §五的证明主脉里两次出场（凸值 + 上半连续）。

猜拳（02 章 9 格全灭的博弈）给出混合的必要性证明：均匀混合 σ = (1/3, 1/3, 1/3) 下，对手出任何纯策略的期望收益都是 (+1)(1/3) + (−1)(1/3) = 0——**你被完全"抹平"**：对手没有任何可剥削的规律，无论他多聪明，博弈值就是 0。这就是混合策略的第一身份：**防剥削装置**。

## 二、无差异原理：你的概率由对手的无差异决定

逻辑链要倒着读。你愿意混合（支撑集里多个纯策略都真出手），当且仅当这些纯策略在你自己眼里**无差异**；而均衡要求**双方**同时愿意混合——于是：

> **均衡中的混合概率是这样解的：我的概率向量，恰使对手在我的概率下各纯策略期望收益相等；反之亦然。** 你混合是为了让对方猜不透——对方"猜不透"的数学定义就是"无差异"。

### 2.1 2×2 混合公式手推（一般和，两矩阵版）

设行玩家收益 A = [[a₁₁, a₁₂], [a₂₁, a₂₂]]、列玩家收益 B 同型；行玩家以概率 p 取顶行、列玩家以概率 q 取左列。

**列玩家的无差异决定 p**（行玩家出顶行的概率）：列玩家出左列期望 B₁₁p + B₂₁(1−p)，出右列期望 B₁₂p + B₂₂(1−p)。令两者相等：

$$p^* = \frac{B_{22}-B_{21}}{B_{11}-B_{12}-B_{21}+B_{22}}$$

**行玩家的无差异决定 q**（对称地，用 A）：

$$q^* = \frac{A_{22}-A_{12}}{A_{11}-A_{21}-A_{12}+A_{22}}$$

性别战争套 A=[[2,0],[0,1]]、B=[[1,0],[0,2]]：p* = (2−0)/(1−0−0+2) = **2/3**（行玩家歌剧）、q* = (1−0)/(2−0−0+1) = **1/3**（列玩家歌剧）——02 章预告的 (2/3, 1/3) 到账。

### 2.2 零和/常和特例与一个必须立起的警示牌

常和博弈（B = k − A，零和是其特例 k=0）中 B 的分量可用 A 的写出：B₂₂−B₂₁ = c−d、B₁₁−B₁₂−B₂₁+B₂₂ = −(a−b−c+d)（记 A=[[a,b],[c,d]]），代入得教科书标准形：

$$x^* = \frac{d-c}{a-b-c+d} \quad(\text{行玩家的均衡概率，零和/常和专属})$$

> ⚠ **警示牌：这个紧凑公式只对零和/常和成立，别套进对称或一般和博弈。** 两个反例都已亲手验证：对鹰鸽 A=[[−1,2],[0,1]] 硬套得 x* = (1−0)/(−1−2−0+1) = **−1/2**——概率为负，当场报警；对性别战争硬套得 1/3，而正确答案是行玩家 2/3（1/3 是**列玩家**的概率——错而不显，更危险）。诊断书一句话：公式推导用了"对手的收益 = k − 我的收益"，对称博弈的对手矩阵是 Aᵀ 而非 k−A，一般和则什么都不是。**规矩永远是无差异原理本身；公式只是它在常和世界的特例。**

## 三、罚点球完整手算（nashpy 对拍，差 1e−16）

收益矩阵（得分概率；行=射门方向，列=扑救方向，同侧低）：

| | 扑左 | 扑右 |
|---|---|---|
| **踢左** | 0.65 | 0.95 |
| **踢右** | 0.95 | 0.55 |

这是**常和**博弈（B = 1 − A），§2.2 公式合法。记 a=0.65, b=0.95, c=0.95, d=0.55：

$$p^*_{\text{踢左}} = \frac{d-c}{a-b-c+d} = \frac{0.55-0.95}{0.65-0.95-0.95+0.55} = \frac{-0.40}{-0.70} = \frac{4}{7} \approx 0.5714$$

无差异验算（守门员视角，扑左 0.35p+0.05(1−p) vs 扑右 0.05p+0.45(1−p) 相等）给出同一个 4/7——常和结构下双方概率对称。博弈值（射手均衡得分率）：

$$v = 0.65\cdot\tfrac{4}{7} + 0.95\cdot\tfrac{3}{7} = \tfrac{5.45}{7} \approx 0.7786 \quad(\text{双路验算 } 0.95\cdot\tfrac{4}{7}+0.55\cdot\tfrac{3}{7} = \tfrac{5.45}{7}\ \checkmark)$$

**数值直觉**：p_左 : p_右 = (d−c) : (a−b) = 0.40 : 0.30 = 4 : 3。0.40 是"对手扑右时你踢右的代价"（0.95−0.55），0.30 是"对手扑左时你踢左的代价"（0.95−0.65）——**哪一侧被猜中更惨（右侧 0.55），你越少踢哪一侧**：均衡频率恰好按对手的堵截代价反向配平。

**与 nashpy 对拍**（01 章工具箱的三行代码，本机实测）：

```
nashpy: P1=(0.5714, 0.4286)  P2=(0.5714, 0.4286)      # 4/7 = 0.5714285714285714…
→ 手算 vs nashpy：一致 ✓（差 1e−16，浮点尾数级别）
```

真实世界跟不跟？lab02 将把 Chiappori-Levitt-Groseclose（2002）的真实罚点球数据与模型预测并排成条形图——结论预告：频率**接近**混合均衡但带系统性偏差（人不是精确随机化器），这份偏差的正式名字叫 QRE，50 章 II 幕收账。另注意一个反直觉点：0.7786 高于两条对角线（0.65/0.55）——**混合的价值不在"均值"，在"不可预测"堵死了对手的针对性**。

## 四、支撑集法：猜支撑 → 解无差异 → 验证

2×2 有公式，一般的 m×n 博弈需要一般算法——**支撑集法**（nashpy `support_enumeration()` 的数学内核，01 章已上手）：

1. **猜支撑集**：猜双方均衡混合的支撑（真正以正概率出手的纯策略集合），等支撑优先；
2. **解无差异方程组**：对每个玩家，令支撑内各纯策略期望收益相等——**关于对手概率的线性方程组**（线性第二次出场）；
3. **验证**：解出的概率全部 ≥ 0；支撑外每个纯策略的期望收益 ≤ 均衡期望（否则它是更优偏离，支撑猜错，回炉重猜）。

用囚徒困境演示第 3 步的否决权：猜全支撑，套常和公式？——非法（PD 非常和）；老实走两矩阵公式，列玩家无差异给出 p* = (1−0)/(3−5−0+1) = **−1 < 0**：负概率，全支撑解不存在，支撑降级为 {D}×{D}——01 章的"唯一 (D,D)"由此在算法层面复现。性别战争与鹰鸽则通过全部三步（2/3-1/3 与 1/2-1/2，lab01 E2 对拍 ✓）。

**边界标注**：支撑集法只找**等支撑**均衡。简并博弈存在支撑不等的均衡——02 章陷阱博弈里 (U, 任意σ) 连续统（对手固定出 U 时列玩家 L、R 同收益 1，随便混都无差异；行玩家在列玩家 L 概率 ≤ 1/2 时驻留 U）——支撑枚举会如实漏报它们：nashpy 只报出两个纯均衡并附带简并警告（lab01 E2/E3 的诚实标注）。更重的机器（Lemke-Howson、顶点枚举）管简并，nashpy 都有。

## 五、Nash 定理的证明主脉：Sperner → Brouwer → Kakutani → Nash

02 章陈述了定理，现在走通它。先看地图：

```
Sperner 引理(1928, 组合)  →  Brouwer 不动点(1911, 连续)  →  Kakutani(1941, 集值)  →  Nash(1950/1951)
   门径论证：奇数扇门         反证 + 标号 + 取极限            凸值对应的不动点        BR 映射套 Kakutani
```

历史注脚（真实账本）：Nash 1950 年那页半的 PNAS 论文用的是 **Brouwer**（直接构造一个自身映射），1951 年 Annals 完整版才改用 **Kakutani**（对最优反应对应）——后者成了教科书写法。50 章将回到这张地图算账：这条证明路径正是 PPAD 复杂度的原型（存在 ≠ 多项式可找）。

**Kakutani 不动点定理（陈述）**：S ⊆ Rⁿ 非空紧凸，对应 φ: S ⇉ S 非空值、凸值、上半连续（图像封闭），则存在 s* ∈ φ(s*)。

**Nash 的应用（核对表）**——取 S = Δ₁ × … × Δₙ（各玩家混合策略单纯形之积，非空紧凸 ✓），定义 φ(σ) = BR₁(σ₋₁) × … × BRₙ(σ₋ₙ)：

| Kakutani 条件 | 在 φ 上为何成立 |
|---|---|
| 非空值 | BRᵢ(σ₋ᵢ) 是连续函数在紧单纯形上的 argmax（Weierstrass：最大值取得到） |
| 凸值 | §一的关键结构：期望收益对自身概率**线性** → 最优集是单纯形与若干半空间的交 → 凸 |
| 上半连续 | 收益对**所有**玩家的概率连续（双线性），Berge 极大值定理 |

于是存在 σ* ∈ φ(σ*)，即 σ*ᵢ ∈ BRᵢ(σ*₋ᵢ) 对每个 i——这正是 02 章的定义：**纳什均衡就是最优反应映射的不动点**。定理证毕（以 Kakutani 为黑箱）。

### 附录 · Sperner → Brouwer 两步证明梗概

**第一步：Sperner 引理（二维版）**。把大三角形剖分成小三角，给所有顶点标号 1/2/3，唯一规则：外边上的点不得标"对面的号"（边 12 上禁标 3，等等）。**断言**：必有某个小三角形三号齐全。

*门径论证*：把两端标号恰为 {1,2} 的小边看作"门"。边界上的门只可能落在外边 12 上（边 13、23 禁标对面的号，不含 1-2 组合）；沿外边 12 从顶点 1 走到顶点 2，标号序列只含 1 与 2、以 1 开头以 2 收尾，故 1 与 2 的交替次数必为**奇数**——外面挂着奇数扇门。从每扇外门走进剖分：每个小三角形的门数只能是 0、1 或 2（门 = 它的 1-2 边数；三号齐全的恰有 1 扇，标号 {1,2,2} 型的恰 2 扇，其余 0 或 2）。于是每条路径穿过中间三角形时必然"一门进、另一门出"，不可能在只有 0 或 2 扇门的地方停下；奇数条外门出发的路径不能两两配对返回外面，**至少一条路径必须终止——终止点只能是恰好 1 扇门的三角形，即三号齐全者**。∎

**第二步：Brouwer 不动点（二维，反证 + 标号 + 取极限）**。设 f: Δ₂ → Δ₂ 连续且**无**不动点。对每点 x：因 f(x) ≠ x 且 Σᵢfᵢ(x) = Σᵢxᵢ = 1，至少有一个分量下降，给 x 标号"某个使 fᵢ(x) < xᵢ 的 i"。验证 Sperner 边界规则：顶点 i 的对边上 xᵢ = 0 而 fᵢ ≥ 0，标不出 i ✓；顶点 eᵢ 处若也标不出 i，则 fᵢ(eᵢ) ≥ 1，迫使 f(eᵢ) = eᵢ，与无不动点矛盾 ✓。于是每个剖分都适用 Sperner：必有三色小三角（顶点 v¹,v²,v³ 分别 f₁(v¹)<v¹₁、f₂(v²)<v²₂、f₃(v³)<v³₃）。令剖分直径 → 0，三顶点挤向同一点 x*（紧性保证子列收敛），连续性给出 fᵢ(x*) ≤ x*ᵢ 对所有 i；两边求和：Σfᵢ(x*) = Σx*ᵢ = 1，三个 ≤ 同时取等——f(x*) = x*，与反证假设矛盾。∎

**Brouwer → Kakutani**（本系列停在陈述）：用分段线性凸值选择逼近集值对应，对每个逼近套 Brouwer 得近似不动点，紧性取极限、上图性传递封闭——细节见任何不动点教材。

**走通这条路的回报**：01 章猜拳留下的"存在性危机"至此结案（有限博弈必有混合 NE，纯 NE 只是退化特例）；50 章的账单也在此预订——Sperner 的门径论证"从给定门走到三色房"最坏只能逐扇捋，**证明的结构预支了计算的复杂度**（PPAD）。存在的证明与找到的算法之间，隔着一条鸿沟。

## 六、混合策略的四种解释：到底是谁在掷骰子

"概率"在博弈论里不是一个比喻，而是四种不同的实体——分清它们，后面十几章的引擎差异就清楚了：

| 解释 | 谁在随机 | "混合均衡"的含义 | 主场章 |
|---|---|---|---|
| **故意随机化** | 个体真的掷骰子 | 防剥削装置：罚点球、扑克诈唬、审计抽查 | 03/04（诈唬的数学） |
| **种群比例** | 没有人随机；混合 = 群体中各纯策略占比 | 单体各自出纯策略，**频率**停在 x* | 11（演化/ESS：没人算均衡，种群会投票） |
| **信念** | 没人随机；混合 = **对手**对我行动的不确定（贝叶斯信念） | 我的"混合"是他人信念的最优反应；Harsanyi 1973 证明可"纯化"——微小收益扰动下纯策略均衡承接一切混合均衡 | 08（不完全信息的入口） |
| **经验频率** | 时间在随机；混合 = 长期博弈中行为的频率极限 | no-regret 学习的平均行为收敛到 CCE ⊇ 混合 NE | 15（学习不动点） |

边界照例先立此存照：人类不是精确随机化器（罚点球实测频率系统性偏离 4/7 的方向可预测——Chiappori 2002；QRE 是 50 章的旋钮）；一般和博弈里混合均衡的收益可以劣于纯均衡（性别战争各得 2/3 < 1）——混合不是"更优"，是"防剥削"，这笔账在零和里是收益，在协调世界里是纯损耗。
