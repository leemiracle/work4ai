# 04 · 零和与 minimax：LP 的方言

> 零和 = 严格竞争的极端世界：你得的每一分都是我失的——没有协调空间，只剩算计。本章证出它的主定理（von Neumann 1928）：混合策略下 **minimax = maxmin = 博弈值 v**，"安全策略"与"最优策略"合二为一；再掀开定理的底牌——**它就是线性规划的强对偶**：行玩家 LP 的对偶恰是列玩家 LP（scipy.linprog 十行手解罚点球，与 03 章手算、nashpy 三方对拍到 0.00e+00）；最后用同一台无差异发动机拆解**诈唬的数学**：你的骗术频率不由胆量决定，由对手的无差异决定。

---

**1928 年，《数学年刊》。** 24 岁的冯·诺伊曼发表《博弈论》（Zur Theorie der Gesellschaftsspiele），证明了那个他自认足以立身的定理（他晚年的大意自评："没有 minimax，就没有值得发表的博弈论"——转述见博弈论史文献）：两个利益完全对立的人，各自筑起"最坏情况里最好"的防线，两条防线恰好交于同一点。十九年后的 1947 年，Dantzig 带着刚发明的单纯形法拜访冯·诺伊曼，问题没讲完就被打断——对方当场讲了对偶理论及其与二人零和博弈的等价（Dantzig 1982 年回忆的口径："像彩排过一样"）。这则轶事就是本章的地图：**minimax 定理与 LP 强对偶是同一枚硬币**——[讲透优化 09](../讲透优化/09-线性规划.md) 与本章在同一块基石上打了两口井，井底相通。

## 一、零和：严格竞争的极端世界

**定义**：两人博弈零和（zero-sum），若每个策略组合下 u₁(s) + u₂(s) = 0（常和 k 同法处理：B = k − A，移位不改变均衡——03 章罚点球 B = 1 − A 即此）。它是"严格竞争"的正式化：**两人对结果的排序完全相反**——不存在让双方同时改善的移动，分配问题退化为纯粹对抗。

哪些博弈真的落在这个类里，哪些只是看着像：

| 博弈 | 零和？ | 判词 |
|---|---|---|
| 罚点球（03 章主角） | ✓（常和 1） | 得分率与扑救成功率互补 |
| 匹配硬币 / 猜拳 | ✓ | 输赢对称转移 |
| 囚徒困境（T5R3P1S0） | ✗ | **纯冲突 ≠ 零和**：(D,D) 和为 2 ≠ (C,C) 的 6——直觉在这里骗人 |
| 性别战争 / 鹰鸽 | ✗✗ | 存在共同利益或分配空间，是协调/反协调世界 |

零和是 03 章"混合的四种解释"表第一行（**故意随机化**）的主场：罚点球、扑克诈唬、审计抽查——防剥削装置清单都在本章兑付。它也是全书最"像优化"的一章：对手仍在，但他的意志被压缩成一个最坏情况，博弈退化成一次带约束的最大化。

## 二、安全策略：maximin——不赌对手犯错

行玩家先选定混合 x，列玩家看清后选 y——保守主义者的问法：**最坏情况下我能保证多少？**

纯策略版先立标尺：踢左的保证 = min(0.65, 0.95) = 0.65（对手扑左时最惨）；踢右的保证 = 0.55。纯 maximin = **0.65**（踢左保险）。列玩家反过来：扑左把射手按到 max(0.65, 0.95) = 0.95，扑右也是 0.95，纯 minimax = **0.95**。差距 0.30 就是"被读"的价格：你若可预测，对手把你按到 0.65；你想反把他按到 0.95 以下？纯策略办不到。

混合版把"保证"写成双线性形式：

$$\text{maximin} = \max_x \min_y\; x^\top A y \qquad\qquad \text{minmax} = \min_y \max_x\; x^\top A y$$

**maximin ≤ minmax 永远成立**，一行证明：对任意 x′, y′，min_y x′ᵀAy ≤ x′ᵀAy′ ≤ max_x xᵀAy′——左端对 x′ 取 max、右端对 y′ 取 min，夹逼即得。（这正是 LP 弱对偶的博弈身份证，§四对号入座。）全部悬念浓缩成一句：**等号何时成立？**

（maximin 的心智是 Wald 式极悲观准则。在零和里它不是过度保守而是精确：对手真的在逐点最大化你的损失。把它搬出零和世界去用，才是过度保守——§七第 3 条。）

## 三、von Neumann 1928：minimax = maxmin = v

**定理（minimax）**：任何有限两人零和博弈，在混合策略上

$$\max_x \min_y\; x^\top A y \;=\; \min_y \max_x\; x^\top A y \;=\; v$$

v 叫**博弈值**；达到它的 x*、y* 叫**均衡策略**——互为最优反应，(x*, y*) 是纳什均衡（02 章定义在零和的化身），v 即均衡下射手的期望得分率。罚点球数值兑现：纯策略 gap 0.30，混合后两条防线交于 v = 5.45/7 ≈ 0.7786（03 章手算；lab02 E1/E2 三方对拍至 1e−16 级）。

> 03 章"混合的价值不在均值，在不可预测"在 minimax 几何里现出原形：lab02 `mixed.png` (b) 面板中，射手期望是 x 的两条线，**下包络**（最坏情况）恰在 x* = 4/7 处达到峰值 v——混合就是把安全下界的山峰推到最高的动作。

零和红利三连（每一项都将在一般和世界**作废**，05 章起逐条收账）：

| 红利 | 内容 | 一般和的下场 |
|---|---|---|
| **值唯一** | 所有均衡共享同一个 v | 性别战争三个均衡三种命运：(2,1)/(1,2)/(2/3,2/3) |
| **均衡可交换** | (x¹,y¹)、(x²,y²) 均衡 ⟹ (x¹,y²)、(x²,y¹) 也是（混搭无代价） | BoS 交叉组合 (歌剧,足球) 全灭（02 章逐格表） |
| **鞍点** | xᵀAy* ≤ v ≤ x*ᵀAy：行玩家悲观侧 ≤ 值 ≤ 列玩家悲观侧 | 无对应物 |

## 四、LP 对偶视角：行玩家的对偶恰是列玩家

把"保证值最大"逐字翻译成 LP——**行玩家原始问题 (P)**：

$$\max\; v \qquad \text{s.t.}\quad \underbrace{\textstyle\sum_i a_{ij} x_i \,\ge\, v \;\;(\forall j)}_{\text{防住对手第 } j \text{ 个纯策略}}，\qquad \textstyle\sum_i x_i = 1，\qquad x \ge 0，\quad v \text{ 自由}$$

（v 是自由变量——若坚持全非负标准形，教科书的老技巧是 v > 0 时换元 p = x/v 化为 min Σpᵢ，或给 A 加常数移位；§五的代码直接保留自由变量交给 highs，两种手续同解。）

**对偶三行推出**：给"防住第 j 列"配乘子 **yⱼ ≥ 0**、给"Σx = 1"配自由乘子 λ，写 Lagrangian：

$$L = v + \sum_j y_j\Big(\sum_i a_{ij}x_i - v\Big) + \lambda\Big(1-\sum_i x_i\Big) = v\Big(1-\underbrace{\textstyle\sum_j y_j}_{\text{令}=1}\Big) + \sum_i x_i\Big(\underbrace{\textstyle\sum_j a_{ij}y_j - \lambda}_{\text{令}\le 0}\Big) + \lambda$$

L 对 (v, x) 的下确界有限 ⟺ **Σⱼyⱼ = 1 且 (Ay)ᵢ ≤ λ**——对偶问题恰是：

$$\max\; \lambda \qquad \text{s.t.}\quad (Ay)_i \le \lambda\;(\forall i)，\quad \textstyle\sum_j y_j = 1，\quad y \ge 0$$

**这正是列玩家的问题**：最优 λ* = min_y maxᵢ (Ay)ᵢ = minmax。行玩家 LP 的对偶 = 对手。对偶表逐行对照（这张表 05 章刻画相关均衡、13 章拍卖的信号结构时还要回来查）：

| 原始（行玩家 max v） | 对偶（列玩家 min w） |
|---|---|
| 变量 v（自由；博弈值候选） | 约束 Σⱼ yⱼ = 1（概率归一） |
| 变量 xᵢ ≥ 0（行玩家混合） | 约束 (Ay)ᵢ ≤ w（压住行玩家每个纯策略） |
| 约束 v ≤ (xᵀA)ⱼ ∀j（防住第 j 列） | 变量 yⱼ ≥ 0（列玩家混合——**乘子即对手**） |
| 约束 Σᵢ xᵢ = 1 | 变量 w（自由；博弈值的另一写法） |

[讲透优化 09](../讲透优化/09-线性规划.md) 的对偶四定理在博弈语言里全员有身份证：**弱对偶** = maximin ≤ minimax（§二的一行证明）；**强对偶** = von Neumann 1928（v = w）；**互补松弛** = 支撑判据（yⱼ > 0 ⟺ 第 j 列约束取等 ⟺ j 在列玩家的均衡支撑里——03 章 §四"验证"一步的对偶语言；y 是"防住每一列"这件事的影子价格）；**对偶的对偶 = 原始** = 你的对偶是对手。**LP 对偶 = 影子价格 = minimax，同一件事的三种方言。**

## 五、scipy.linprog 手解罚点球（代码层）

标准形翻译（scipy 只认 min cᵀz s.t. A_ub z ≤ b_ub、A_eq z = b_eq、bounds）：max v → min −v；v 自由 → bounds=(None, None)；变量 z = (v, x_踢左, x_踢右)。罚点球的两条不等式写出矩阵就是 [[1, −0.65, −0.95], [1, −0.95, −0.55]]：

```python
from scipy.optimize import linprog
PEN = np.array([[0.65, 0.95], [0.95, 0.55]])
# 行玩家：max v ⇔ min −v；约束 v − Σᵢ aᵢⱼxᵢ ≤ 0（j = 扑左/扑右）；Σx = 1；x ≥ 0
r = linprog(c=[-1, 0, 0],
            A_ub=np.hstack([np.ones((2, 1)), -PEN.T]), b_ub=[0, 0],
            A_eq=[[0, 1, 1]], b_eq=[1],
            bounds=[(None, None), (0, None), (0, None)], method="highs")
# 对偶 = 列玩家：min w；约束 (Ay)ᵢ − w ≤ 0（i = 踢左/踢右）
r2 = linprog(c=[1, 0, 0],
             A_ub=np.hstack([-np.ones((2, 1)), PEN]), b_ub=[0, 0],
             A_eq=[[0, 1, 1]], b_eq=[1],
             bounds=[(None, None), (0, None), (0, None)], method="highs")
```

实跑输出（[`experiments/lab02_mixed_penalty.py`](./experiments/lab02_mixed_penalty.py) E2，本机实测）：

```
行玩家 LP（highs）：v = 0.7785714286，x = (0.571429, 0.428571)   ← 理论 4/7, 3/7, 5.45/7
对偶/列玩家 LP（highs）：w = 0.7785714286，y = (0.571429, 0.428571)   ← 强对偶 ⟺ minimax 定理
→ 对拍 1：LP 值 vs nashpy 均衡值 = 0.7785714286 vs 0.7785714286（差 0.00e+00，< 1e-6 ✓）
→ 对拍 2：对偶间隙 v − w = +0.00e+00（强对偶/minimax 定理的数值兑现）
→ 互补松弛读法：y = (4/7,3/7) 全支撑 ⟹ 两列约束同取等：松紧量 = (+0.00e+00, +0.00e+00) ✓
```

三行读数：**值** 0.7785714286 = 5.45/7（03 章手算、nashpy、linprog 三方同点）；**策略** (4/7, 3/7)；**对偶** w 同值、y 同为 (4/7, 3/7)——本矩阵恰对称（两个跨对角都是 0.95），双方均衡概率相同是巧合而非一般规律。互补松弛逼出"两列约束同时取等"，正是 03 章的无差异验算；对偶间隙 0.00e+00——1928 年的定理在 1947 年的算法里跑出了机器精度。

## 六、诈唬的数学：让对手无差异的工程学

简化到只剩骨头的扑克。规则：先验强手/弱手各 1/2；底池各 1 注，加注 1；**强手必下注**，弱手可选**诈唬**下注或认输；应对方见注后选择跟注或弃牌。各格期望收益（按先验折半）：

| 局面 | 下注方 | 应对方 |
|---|---|---|
| 强手下注、对方跟注 | +2 | −2 |
| 强手下注、对方弃牌 | +1 | −1 |
| 弱手诈唬、被跟 | −2 | +2 |
| 弱手诈唬、对方弃 | +1 | −1 |
| 弱手认输 | −1 | +1 |

下注方的两个纯策略：**全下注**（强注+弱注）与**诚实**（强注+弱弃）；应对方：跟注/弃牌。期望矩阵（零和，只写下注方）：

| | 跟注 | 弃牌 |
|---|---|---|
| **全下注** | ½·2 + ½·(−2) = **0** | ½·1 + ½·1 = **1** |
| **诚实** | ½·2 + ½·(−1) = **½** | ½·1 + ½·(−1) = **0** |

套 03 章 §2.2 零和公式（a, b, c, d = 0, 1, ½, 0）：

$$x^* = \frac{d-c}{a-b-c+d} = \frac{0-\tfrac12}{0-1-\tfrac12+0} = \frac{-1/2}{-3/2} = \frac{1}{3}， \qquad v = \frac{1}{3}$$

**诈唬概率 1/3、应对方跟注概率 2/3、博弈值 +1/3（下注方优势）。** 双向无差异验算（行为策略口径）：

- **应对方**：见注的后验 P(弱|注) = (½·⅓)/(½·1 + ½·⅓) = **1/4**（贝叶斯更新，08 章入口）。跟注 EV = ¾·(−2) + ¼·(+2) = −1 = 弃牌 EV（−1）——**恰好无差异**。赔率语言：跟 1 注博 3 注底池，盈亏平衡抓诈率 = 1/4；诈唬频率 1/3 正是把后验压到 1/4 的那只旋钮。
- **弱手**：诈唬 EV = (2/3)(−2) + (1/3)(+1) = −1 = 认输 EV——**恰好无差异**（这个等式是应对方的 2/3 跟注率造出来的）。
- **强手**：必注 EV = (2/3)(2) + (1/3)(1) = 5/3；整体值 = ½·(5/3) + ½·(−1) = 1/3 ✓。

这是无差异原理（03 章钥匙句）在欺诈工程里的化身：**诈唬太少，对手永弃，诈唬无利可图；诈唬太多，对手永跟，诈唬变成自毁——均衡频率恰好停在对手"抓与不抓都一样"的那一点。** 16 章 Kuhn 扑克里 J 以 1/3 诈唬-bet，是同一台发动机的亲戚；lab07/lab08 的 CFR 将把这个 1/3 从遗憾迭代里**学**出来而非算出来。防剥削装置全家福：

| 装置 | 均衡频率 | 配方 |
|---|---|---|
| 罚点球（03 章） | 踢左 4/7 | 按对手两侧堵截代价 0.40 : 0.30 反向配平 |
| 扑克诈唬（本章） | 弱手诈唬 1/3 | 把"见注即弱"的后验压到跟注赔率的盈亏平衡点 1/4 |
| 审计/稽查抽查 | 按逃税收益配平 | 抽查率 = 违规者的无差异点 |
| 反兴奋剂抽检 | 赛外飞行检查 | 同上——"不可预测"本身就是威慑 |

## 七、边界与展望

1. **零和是特例**：值唯一、均衡可交换、鞍点三红利在一般和全灭——性别战争让你在 (2,1) 与 (1,2) 间站队、混合均衡人人 2/3。下一章处理"多均衡选哪个"。
2. **值 ≠ 公平**：v = 5.45/7 是射手视角；常和世界里守门员的份额 = 1 − 5.45/7 = 1.55/7 ≈ 0.2214。"公平"不是零和理论的词汇表里的词。
3. **maximin 的滥用**：把 Wald 式极悲观带出零和（对手并非恶魔的普通决策）= 系统性过度保守；把正和互动硬读成零和（贸易、平台生态）= 建模事故第五型（接续 00 章四事故表）。
4. **可计算性的分水岭**：零和均衡 = 一张 LP，多项式可解（[讲透优化 09](../讲透优化/09-线性规划.md) 的单纯形/内点）；一般和 NE = PPAD-完全（50 章第二堵墙）。**"均衡能不能算"的答案，取决于你站在本章之内还是之外。**
5. **学习视角**：fictitious play 在零和收敛到均衡（Robinson 1951——lab02 (a) 面板的轨迹），一般和连 CCE 都只是收敛目标——15 章 no-regret 接手。真实罚点球对 4/7 的系统性偏差叫 QRE——50 章 II 幕收账（lab02 E3 已立此存照）。
