# 06 · 扩展式与逆向归纳：蜈蚣的背叛

> 卷二开门：把"同时出招"松开成"有先后"——时序进入博弈，博弈树粉墨登场。本章立起扩展式（节点/枝/**信息集**，后者是 08 章不完全信息的伏笔），给"计划"与"行为"两种策略方言各发一张身份证（Kuhn 1953：完美回忆下等价），然后证出有限完美信息博弈的求解器——**逆向归纳**（Zermelo 1913：象棋要么先手必胜、要么后手必胜、要么双方必和，三者必居其一）；再用它撞上本系列第一堵行为之墙：**蜈蚣博弈**（SPE 说节点 1 立即 take 拿 4，人类传 3~5 轮去博 128）与**最后通牒**（SPE 说出价 → 0，人类出 40~50%）——理性人假设第一次被数据摁在地上，Fehr-Schmidt 公平效用出场救场。

---

**1992 年，加州理工**。McKelvey 与 Palfrey 让受试者成对玩那只后来出名的"蜈蚣"：六次抉择，罐子每传一次翻一倍，随时可以 take 走大头。逆向归纳的推理链像多米诺：最后一节必 take → 倒数第二节必 take → …… → 第一节就该 take。**实验室里第一节点就 take 的对局不足一成**，中位对局要传过 3~5 个节点。理论与数据当面对质——而本章的立场是：不是逆向归纳这把刀钝了，是"人只关心自己的钱"这块磨刀石错了。先磨刀（§一~三），再对质（§四~五），最后把 pygambit 发给你（§六）。

## 一、博弈树：给时序一个正式的骨架

00 章"建模四事故"的第一条（忘记时序）在此兑付解药。**扩展式（extensive form）**用一棵树描述整个博弈：**决策节点**（谁在动）、**枝**（他此刻可选的动作）、**终端节点**（各玩家的收益向量）、**信息集**（下面马上说）。蜈蚣 n=6（全系列沿用此收益结构，与 McKelvey-Palfrey 1992 实验同构，常被引用的整数刻度）：

| 节点 | 当前玩家 | take →（自己，对手） | pass → 走向 |
|---|---|---|---|
| n1 | P1 | (4, 1) | n2 |
| n2 | P2 | (2, 8) | n3 |
| n3 | P1 | (16, 4) | n4 |
| n4 | P2 | (8, 32) | n5 |
| n5 | P1 | (64, 16) | n6 |
| n6 | P2 | (32, 128) | 终局 (128, 32)（按 80/20 归 P1） |

罐子从 5 起、每 pass 翻倍；taker 拿走 80%、给对手留 20%；最后一节仍 pass 则按镜像分账。**每个数字都声明在案**——本系列的公约是改结构必先亮结构。

**信息集**：轮到你动时，你以为自己可能所处的**节点集合**。蜈蚣里每个信息集都是单点（"我完全知道自己站在 n3"）——这叫**完美信息**；象棋、围棋同属此列。一旦信息集装了多个节点（你听见对手出价却看不见他的成本），完美信息就断了——那是**不完全信息**的疆域，Harsanyi 将在那里接手（[08 章](./08-不完全信息与贝叶斯均衡.md)）。本章的每一台机器都只在完美信息上运转；**记住信息集这个概念是在单点上学会的，08 章它会裂开成多点**。

## 二、策略的两种方言：计划与行为

树上的"策略"有两种写法。**策略式（纯策略 = 完整应变计划）**：预先给**自己每一个**信息集配好动作——哪怕那个信息集按计划根本到不了；蜈蚣里 P1 有 2³ = 8 份计划（n1/n3/n5 各 take/pass）。**行为策略**：在每个信息集上放一个当前动作的概率分布——走到哪、随机到哪。

> **Kuhn 1953**：完美回忆的扩展式博弈中，两种方言一一对应，均衡的预言完全相同。一句话收编，细节进 16 章（CFR 的对象恰是行为策略）。与 03 章"混合的四种解释"接线：那里 Harsanyi 1973 的"纯化"把混合读作微小收益扰动下的纯策略——同一件事在树上的版本就是：**计划与行为的差别可以被不确定性吸收**。

两个工程细节（pygambit 实测，§六可直接抄）：其一，求解器给策略自动编号时把"到不了的部分"打星号——蜈蚣 P1 只有 4 份**化简策略**：`1**`（take@n1，后两只通配）、`21*`（pass@n1, take@n3）、`221`、`222`——**策略是计划，不可达处免费通配**，这也是 2ⁿ 爆炸的一剂解药。其二，树转矩阵后，04 章 nashpy/LP 那套机器全能照用——但代价是**树上直接读 NE 会读到假货**：NE 只对"实际发生的路径"上的行为负责，计划书里那些永远不被执行的条款没人审计。审计官叫子博弈完美，下一章上岗（蜈蚣恰好是审计过关的良民，进入威慑博弈才是惯犯）。

## 三、逆向归纳：从终点往回算（Zermelo 1913）

算法一句话：**从最深的决策节点开始，让当值玩家留下最优枝、剪掉其余，把子博弈折算成一个终端，然后对折算后的树重复**——直到树根。它就是在时间里做的动态规划（[讲透优化 13](../讲透优化/13-动态规划.md) 的 Bellman 逆推换了个皮）：终局的价值定义倒数第二步的最优，倒数第二步的价值定义再往前一步的最优。

**定理（Zermelo 1913，象棋式陈述）**：有限、完美信息、无机会的两人博弈（如国际象棋）**必居其一**：先手存在必胜策略、或后手存在必胜策略、或双方都存在至少逼和的策略。证明就是对博弈步数做归纳：任何有限子博弈都可解，根节点的当值玩家取其中对自己最优的枝，解随之向上一层传递。∎（1913 年论文处理的是象棋的"必胜/必和"判定；"有限步"在真实象棋里靠 50 步规则等条款兜底。）**注意这枚定理的旌旗上写的是"存在"，不是"是哪个"**——它保证三择一，不告诉你哪一支，标注具体赢家通常是 PSPACE 级的苦役。

逆向归纳的路径就是**子博弈完美均衡**（07 章正式化）在完美信息博弈上的化身。它的哲学重量在推理链本身："最后一节他会 take，所以我这节该 take，所以他上一节该 pass……"——每一环都是"**我知道他知道我知道**"的倒序展开，公共知识（01 章蓝眼睛岛）以时间倒流的姿势全部到场。链条越长，对"人人无限理性且人尽皆知"的索求越狠——蜈蚣将在下一节把这根链条当场拉断。

## 四、蜈蚣博弈悖论：SPE 说 take，人类说 pass

手推逆向归纳（take/pass 的**当前玩家**收益对照；每行都用"下游全 take"定价 pass）：

| 节点 | 当前 | take 得 | pass 导致 | 决策 |
|---|---|---|---|---|
| n6 | P2 | 128 | 32 | **take**（严格优） |
| n5 | P1 | 64 | 32 | **take** |
| n4 | P2 | 32 | 16 | **take** |
| n3 | P1 | 16 | 8 | **take** |
| n2 | P2 | 8 | 4 | **take** |
| n1 | P1 | 4 | 2 | **take** |

**SPE = 节点 1 立即 take，结局 (4, 1)**。对照反事实：若人人 pass 到底，(128, 32)——**P1 与 P2 各得 32 倍**。逆向归纳的判决冷酷而精确：理性的人得到最少的结局。

pygambit 实跑验证（[`experiments/lab03_centipede_qre.py`](./experiments/lab03_centipede_qre.py) E1，本机实测；建模范式见 §六）：

```
pygambit enumpure_solve：纯均衡个数 = 1（化简策略标签 * = 不可达信息集，'1**' 即 take@n1）
  P1 策略质量 {'1**': 1}
  P2 策略质量 {'1**': 1}
  均衡收益 = (4, 1)
→ 手推 vs enumpure 对拍：唯一均衡 = ('1**','1**')（双双 take@n1）、收益 (4, 1) —— 完全一致 ✓
```

**实验室的账单**：McKelvey-Palfrey 1992 的 6 节点蜈蚣里，第一节点就 take 的对局**不足一成**，中位对局传 3~5 节点才收手；且止步节点对奖金结构敏感——人类不是乱玩，是在系统性地偏离 SPE。三条修法（50 章第一堵墙的三件工具提前各亮一次相）：

| 解释 | 一句话 | 主场 |
|---|---|---|
| **level-k** | 大家都在猜"别人会传几轮"——0 级瞎传、1 级比别人多传一步，实测层级只有 1~2 | 00 章 §三 |
| **社会偏好** | 效用函数写错了：人还关心对手拿多少（§五的 Fehr-Schmidt） | 本章 §五 |
| **QRE** | 理性是有限 λ 的对数线性噪声：λ→∞ 回到 NE，λ 小则行为发散 | 50 章；lab03 E2 |

lab03 E2 把 QRE 装进蜈蚣跑了一遍（手写不动点递归与 pygambit logit 求解器全程对拍，maxdiff 5.7e−11）：λ = 0.1 时 q(take@n1) 只有 0.248，**首个 take 的节点被推到 n4**——"游戏走远"正是实验室形态；λ ≥ 0.56 后节点 1 即 take，λ = 100 全线 ≈1.0 收敛 SPE ✓。一条诚实标注：q(n6) 在全部 λ 下都 >0.5——终节点的 take 是确定性占优（128 > 32），噪声只能模糊它；**λ 变小侵蚀的是靠"下游也会合作"支撑的早期节点**。还有一处如实记录的非单调：q(n1) 在 λ ≈ 0.14→0.20 间有个小谷（0.250 → 0.235）——下游陆续转 take 先压低"传下去"的价值，而 λ 的放大作用随后才把它抬回来。

## 五、最后通牒：10 美元怎么分

规则一句话：P1 提议怎么分 10 美元，P2 见价定夺——接则照分，拒则双输。逆向归纳三步：P2 对任何正出价都该接受（白得 > 0）→ P1 知道这一点 → 出价趋向 0。**SPE 预测：分给对方一毛钱，自己拿走 9.99。**

**实验**（Güth-Schmittberger-Schwarze 1982 开山，后续四十年反复复制）：真实出价集中在 **40~50%**，低于 ~30% 的出价**约一半被拒**（50 章口径表已立此存照）。SPE 在这里不是"有偏差"，是**方向性阵亡**。

修法出场——**Fehr-Schmidt 不公平厌恶（1999）**：给效用函数补两条刀口，$u_i = x_i - \alpha_i\max(x_j - x_i,\,0) - \beta_i\max(x_i - x_j,\,0)$——**嫉妒项** α 惩罚"我比他少"、**内疚项** β 惩罚"我比他多"；校准普遍 α > β：人对吃亏的不公平远比占便宜的不公平敏感。重写 responder 的收益后，接受 x 的条件是 $x \ge \theta := \frac{10\alpha}{1+2\alpha}$（由 $x - \alpha(10-2x) \ge 0$ 移项即得）——**低于公平门槛 θ 就拒绝变成了理性**。门槛方向与直觉对齐：α = 0 → θ = 0，见钱就收；α = 1 → θ ≈ 3.33；α → ∞ → θ → 5——**嫉妒越强，门槛越高**，但封顶在五五开（再嫉妒的人，给到对半也就没了拒绝的理由）。

lab03 E3 按门槛模型重跑最后通牒（responder 拒绝 iff offer < θ，θ~U[0,4]，为 Fehr-Schmidt 嫉妒项的单参数投影；本机实测）：

```
SPE 预测：任何正出价都应被接受 → 最优出价 → 0（proposer 得 ≈10）
知情提议人最优出价（θ~U[0,4]）：max_o (10−o)·min(1, o/4) → o* = 4.00（蛋糕 40%，期望净得 6.00；出价 0 的期望净得 = 0.00）
异质信念总体模拟（n=20000，c~U[2,8] → o*=min(c,5)）：
  平均出价 = 4.25（理论 E[min(c,5)] = 4.25，即蛋糕 42%）；拒单率 = 8.4%
  出价 < 蛋糕 30%（o<3）的拒单率 = 37.2%（对照实验'低于 ~30% 常被拒'方向一致）
→ 对照：SPE 出价 → 0 vs 公平门槛模型出价 ≈ 4~4.2（40~50%）——实验站行为模型一边，SPE 被数据拒绝
```

读数：知情提议人的最优出价 = **蛋糕的 40%**（θ 均匀域的上沿——出到 4 接受概率推满 1，再让利只赔不赚），异质信念总体均值 42.5%——双双落在实验 40~50% 区间；低出价高拒率（37%）与实验方向一致。诚实账：模拟总拒单率 8.4% 低于实验室汇总值（约 1/6 量级，Camerer 综述口径）——真实 θ 分布比均匀更厚，模型方向对、幅度保守。**建模教训（00 章"收益拍脑袋"事故的正式解药）**：效用函数不是神圣教条，是可检验、可替换的建模选择——SPE 没错，错的是把"自利"当成人类效用的全部。

顺带一笔通向下一章：最后通牒里 responder 若能**承诺**"见钱必收"，他自己反而能落袋（0.01 也好过 0）——**承诺的价值**（给谁、在哪一节点值多少）是 07 章的主角。

## 六、pygambit 工具箱：EFG 文本 → read_efg → solve

16.7.0 实测（绕坑声明）：`pygambit.Game.new_tree()` 建出的树**只读**——Node 没有 append 方法，**程序化建扩展式博弈的唯一通道是手写 EFG 文本 + `read_efg`**（lab04 将沿用同一范式）。且 EFG 词法器**不认 `#` 行内注释**——注释混进字符串会当场解析失败（实测 `Parse error in game file`），模板必须保持纯 EFG：

```python
import pygambit

EFG = '''EFG 2 R "mini centipede" { "Player 1" "Player 2" }
p "n1" 1 1 "P1s" { "take" "pass" } 0
t "t1" 1 "o1" { 1 0 }
p "n2" 2 1 "P2s" { "take" "pass" } 0
t "t2" 2 "o2" { 0 2 }
t "t3" 3 "o3" { 2 1 }'''
open("mini.efg", "w", encoding="utf-8").write(EFG)
g = pygambit.read_efg("mini.efg")
```

逐行格式（对照读）：首行 = `EFG` + 版本 `R` + 标题 + `{ 玩家名表 }`；`p` 行 = 决策节点：标签、玩家号、信息集号、信息集标签、`{ 动作 }`、末尾 `0`（未附结局，收益全在 `t` 行）；`t` 行 = 终端：标签、结局号、结局标签、`{ 收益1 收益2 }`；节点按**前序遍历**排列——决策点先于它的子树。

| API | 干什么 | 实测注意 |
|---|---|---|
| `pygambit.read_efg(path)` | 读树 | 导入名是 `pygambit`（`import gambit` 直接 ModuleNotFoundError）；路径用 Windows 实路径，别喂 `/tmp`；**EFG 内不认 `#` 行内注释**（实测解析报错） |
| `pygambit.nash.enumpure_solve(g)` | 纯策略 NE 枚举 | 返回的均衡按 **Strategy 对象**索引：`e[strategy]`；策略标签自带通配（`'1**'`）；`e.payoff(player)` 取收益 |
| `pygambit.qre.logit_solve_lambda(g, lam)` | 单点行为 QRE | 返回**列表**（`[LogitQREMixedBehaviorProfile]`）；flat 概率序 = P1 的信息集依次各 (take, pass)，再 P2 的——蜈蚣 12 个分量 n1/n3/n5/n2/n4/n6 |
| `pygambit.nash.logit_solve(g)` | 整条 logit 路径 | `result.equilibria[0]` 是 MixedBehaviorProfile，**可按 Action/信息集对象取概率**：`e[action]` |

三个通用坑：玩家容器**只认标签不认整数**——用 `list(g.players)[0]` 或 `g.players["Player 1"]`，`g.players[0]` 会抛 TypeError；库不校验"结局号唯一"以外的形式语义，EFG 写错收益不会报错只会给出错的均衡——**理论锚点必须像 E1 那样手推对拍**；最后，运行方式：`python experiments/lab03_centipede_qre.py`（`讲透博弈论/` 目录下），产出 `extensive.png` 与可复用的 `centipede6.efg` 模板。

## 七、不足与边界

1. **逆向归纳对"理性公共知识"的索求随链条长度线性上涨**：蜈蚣六节就断了，几十节的链条（10 章的重复博弈有 δ∞ 节）更无从谈起——但 10 章也会反过来展示：未来足够重要时，合作在 SPE 里活得很好。
2. **实验数据否证的是"效用=钱"，不是逆向归纳本身**：换上 Fehr-Schmidt 效用，同样的算法给出不同的预测——刀没钝，是磨刀石换了。
3. **QRE 的 λ 不是免费午餐**：λ 无法先验确定、事后拟合易过拟合——50 章的旋钮有自己的税。
4. **信息集在本章是单点装饰**，它的全部重量（信念、贝叶斯更新、序贯理性）压到 08/09 章；前向引用立此存照：[08 章](./08-不完全信息与贝叶斯均衡.md)。
5. **外部效度一句话**：实验室低额一次性博弈是 SPE 最差的考场，市场与重复互动是它最好的（00 章理性五档表"实验室常败、市场常胜"）；别拿前者的战绩否定后者。
