> **定位句**:这支负责"**统计结论背后的计算是否可信**"——随机数发生器、EM、MCMC、
> 大规模似然的数值——把推断理论变成可执行、可审计的算法。| GB/T 13745 · 11071 三级「统计计算」
> 家族:[讲透应用统计数学](../README.md) · 五问模板支成员

## 诞生

1953 年 Los Alamos,Metropolis 与 Ulam 团队的 Metropolis 算法把"按概率分布采样"
变成普适算法(MCMC 之祖);1977 年 Dempster–Laird–Rubin 的 EM 算法
把缺失数据下的极大似然变成不动点迭代——
统计推断的计算复杂度从此本身成为数学对象,这一支就是研究它的。

## 核心问题

已解决:
- Metropolis–Hastings/Gibbs 的遍历性与不变分布定理(1953/1970/1984)
- EM 的单调收敛性(每步似然不减)
- 随机数发生器的质量体系(TestU01 小碰撞/大碰撞测试)

未解决:
- 大规模后验的**混合时间常数界**——"跑多久才够"理论上仍靠诊断(R-hat/耦合平行链是工程答案)
- 高维分布间距离的可用度量(样本级 Wasserstein 的计算极限)

## ✨ 这支最美的一个事实

**MCMC 的普适性**:只要你写得出目标密度(差一个常数都行),
Metropolis 就能从任何起点采样它——"写得出概率,就采得到样本",
这是蒙特卡洛方法的万能钥匙,也是现代贝叶斯复兴的发动机。

## 假设与依赖

- 随机数"真随机"(伪随机缺陷会在高维显形为晶格伪影)
- 马氏链不可约+常返(否则遍历定理整体失效)
