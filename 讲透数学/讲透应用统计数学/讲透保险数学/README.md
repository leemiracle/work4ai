## 诞生

1903 年,瑞典精算师 Filip Lundberg 的博士论文写下盈余过程的随机视角——
比随机过程理论正式诞生早约半个世纪;1930 年 Harald Cramér 补上严格数学,
"Cramér–Lundberg 模型"成为保险数学的牛顿力学,至今仍是精算教育的骨架。

## 核心问题

已解决:
- Lundberg 上界 ψ(u) ≤ e^{−Ru} 与调节系数理论(1903/1930)
- 经典模型破产概率的 Pollaczek–Khinchine 表达
- 重尾索赔的 subexponential 渐近 ψ(u) ~ C·F̄(u)(轻尾指数界→重尾多项式界,两套文明)

未解决:
- **相依索赔的精细破产界**——飓风/疫情式理赔扎堆下经典界失效(2021-2026 主战场,见家族 01 章)
- 最优再保险在相依重尾下的全刻画

## ✨ 这支最美的一个事实

**Lundberg 不等式**:保险公司数十年的命运——资本金、保费率、理赔律——
被压缩成一条指数上界 e^{−Ru}。极简、锋利、可审计,监管资本制度的数学祖先。
(亲历:跑 [../experiments/00_ruin_mc.py](../experiments/00_ruin_mc.py),看模拟直方图被红线压住。)
