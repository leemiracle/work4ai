## 〇、家族树(五支 = GB/T 11071 三级逐条)

```
讲透应用统计数学/
├── 讲透统计质量控制/   🆓 生产线上的统计法庭(Shewhart 控制图/抽样验收/AQL)
├── 讲透可靠性数学/     🆓 寿命与失效的科学(故障率浴盆/Weibull/MTBF/系统结构)

```

五支一句经济:质量控制**盯过程**,可靠性**盯寿命**,保险数学**盯盈余**,
统计计算**供弹药**,统计模拟**供裁判。
