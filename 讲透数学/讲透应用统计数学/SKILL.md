# 应用统计数学思维技能卡

> 家族:[讲透应用统计数学/](README.md)(GB/T 11071)| 上游:[../讲透数理统计/](../讲透数理统计/) · [../讲透概率论/](../讲透概率论/)

## 一、何时用此分支(问题特征触发词)

- 提到 **MTBF / 失效率 / 浴盆曲线 / MTTR / 可用性 99.9% / SLI / SLO / 误差预算**
- 提到**破产概率 / 盈余过程 / 保费 / 理赔 / 再保险 / VaR / CVaR / 偿付能力**
- 要做**蒙特卡洛 / 仿真实验 / bootstrap / 重抽样 / 置信区间估计**且要报误差棒
- 生产场景要做**质量控制图 / 抽样验收 / AQL / Cpk / 过程能力**
- 关心**稀有事件**(10⁻⁶~10⁻⁹ 概率)的估计
- 问题形态是"**平均没问题,但极端情况会死**"——尾部问题

## 二、核心思维模式(这个分支怎么想问题)

1. **尾部眼**:均值无关紧要,命运在尾部——先问分布尾部厚度(矩母函数存在吗?),再谈一切指标
2. **承诺即概率**:一切指标(MTBF/SLO/资本金)本质是对未来的统计承诺,承诺要标保质期(哪层保证:长期频率 vs 单次)
3. **仿真即实验**:算不出来→估出来;估出来→必报 σ/√n 误差棒;误差不够小→方差缩减(不是加样本)
4. **冗余审计**:看到冗余先问共因失效——结构图并联≠失效物理并联
5. **循环白拿**:系统有更新循环(故障→修复)就能用更新报酬定理锁死长期指标,与分布形状无关

## 三、工具箱(方法名 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| Weibull 拟合(三参数) | 寿命数据建模;β<1/≈1/>1 对应浴盆三段 |
| Lundberg 界 ψ(u)≤e^{−Ru} | 轻尾盈余过程的风险上界;求 R 先验矩母函数存在性 |
| Pollaczek–Khinchine 公式 | M/G/1 型等待与破产的精确表达 |
| 极值理论(GPD 超阈值) | 数据不够看尾部但必须外推极值分位时 |
| bootstrap | 统计量分布难推导、数据独立时;相依数据必须换区块 bootstrap |
| 重要性采样/控制变量 | 稀有事件 MC 方差降数量级(大偏差理论定向倾斜) |
| 更新报酬定理 | 求长期平均指标(稳态可用度 A=MTBF/(MTBF+MTTR)) |
| Shewhart 3σ 图 / ARL | 过程在线监测;ARL₀≈370 是 3σ 的暗号 |
| 序贯检验(Wald SPRT) | 抽样费用高、想边抽边判(破坏性检验) |

## 四、常见误区与禁忌

- ❌ 把 MTBF 读成"平均寿命"直觉(它倒挂了失效率;浴盆期解释完全不同)
- ❌ 把 95% 置信区间读成"真值有 95% 概率在区间里"(是造区间动作的长期命中率)
- ❌ 相依数据(时间序列/集群事件)上用朴素 bootstrap
- ❌ 重尾索赔下套 Lundberg 指数界(R 不存在——必须先报警)
- ❌ 冗余设计不做共因失效审计就宣称提升可靠性
- ❌ MC 不报误差棒;或用加样本质疑精度(1/√n:样本×100 才少一个 0,杠杆在方差缩减)
