# 02 · 语言特征:应用统计数学说什么话

> **本章回答五问之三:表达力?逻辑性质?规范化程度?**
> 三步法先给直觉:数理统计说的是"**证据**"的语言(样本→总体,给置信度);
> 应用统计数学把它翻译成"**承诺**"的语言——MTBF 是对客户的承诺,Lundberg 界是对监管的承诺,
> 置信区间是对决策者的承诺。**承诺一旦出口,就要有人兑现——这是本分支语言的全部性格。**

---

## 一、表达力(能说什么 / 不能说什么)

**能说**:
1. **风险的单调比较**:"A 系统比 B 可靠"(随机序)、"A 组保险比 B 组危险"(凸序)——
   不需要算出具体概率,只比分布的形状。随机序(stochastic ordering)是本家族的"不等式文化"入口。
2. **时间的平均律**:"长期平均故障率≈λ"(更新定理)、"破产概率有指数上界"(大偏差)。
3. **样本量的兑换率**:"误差 ∝ 1/√n,四倍样本换一半误差"——蒙特卡洛的明码标价。
4. **可信承诺**:"以 95% 置信,MTBF>8000 小时"——把不确定性和决策阈绑在一起出口。

**不能说**(表达力的边界,每条都是一堵墙):
1. **单次事件的命运**:一切结论是分布层面/平均层面的。"这台服务器明天会不会坏"——模型闭嘴。
2. **没有数据时的尾部**:Weibull 拟合的是你见过的失效;**超越经验分位数的极端事件**只能靠假设外推(00 章"尾部错配")。
3. **黑天鹅的结构**:破产理论给"给定分布下"的界;分布本身错了,界再优雅也失效(模型风险,model risk)。
4. **相依的全谱**:"任意相依"下的结论往往只剩保守上界——精确刻画难。

**能说的三种句式(语法表)**:
- 存在句:"存在 R>0 使 ψ(u)≤e^{−Ru}"(在假设下必然成立)
- 比较句:"X ≥_{st} Y"(随机序:对一切阈值 t,P(X>t)≥P(Y>t))——不用算出概率就能排序
- 换算句:"误差减半 ⟺ 样本 ×4"(σ/√n 的明码标价)——工程谈判的通用货币

## 二、逻辑性质(推断的保证级别)

直觉:统计推断的"逻辑"不是演绎,是**带标价的归纳**——每个结论都挂着一个"保质期条款"。
本家族的语言把保质期写成了制度:

| 层级 | 语句形态 | 保证逻辑 |
|------|---------|---------|
| 定理层 | ψ(u)≤e^{-Ru}(Lundberg) | **演绎**:给定模型假设,数学必然 |
| 方法层 | 95% CI 覆盖真值 | **频率保证**:长期重复使用时 95% 的区间抓住真值(单次无保证!) |
| 检验层 | p<0.05 拒绝 H₀ | 控制第一类错误率(假阳性率)——**不承诺 H₁ 为真** |
| 仿真层 | MC 估计 ±σ/√n | 以概率收敛(大数定律)+ 渐近正态(CLT)——**n 有限时只有近似** |

反直觉发现:**置信区间的"95%"不意味着"真值落在此区间的概率是 95%"**——
真值是死的(定点),区间是活的(随机)。95% 说的是造区间这个**动作**的长期命中率。
工程上最常见的语言事故就是把方法层保证读成了单次承诺。

**一致性**:模型族选错时,MLE 照样"一致地收敛到错的值"(QMLE)——自洽但不真。

## 三、规范化程度(公理化到哪一级)

三步法直觉:数学的规范化阶梯=公理→定义→定理→标准。本家族罕见地**爬完了整个梯子**:

1. **数学公理层**:Kolmogorov 概率公理(继承自 ../讲透概率论/)+ 风险过程的公理化
   (盈余过程 U(t)=u+ct−S(t) 的定义框架)——规范化高。
2. **模型族层**:Weibull/Gamma/对数正态/泊松——参数化家族=可交流的"普通话"。
3. **方法标准层**(本家族特色,别的分支少见):
   - MIL-HDBK-217 / Telcordia(电子可靠性预计手册)
   - IEC 61508(功能安全,SIL 等级=失效概率的法定分档)
   - Solvency II / 偿二代(监管资本=Lundberg 语言的法律化)
   - ISO 7870(控制图国标族)
4. **可判定性**:不存在"输入数据自动输出唯一正确模型"的算法——模型选择没有规范化终点,
   只有 AIC/BIC/交叉验证这类**带哲学立场的裁判**。

**规范化的一句话诊断**:本家族是数学宇宙里"**定理变成法条**"比例最高的分支——
这既是它的力量(工程可信),也是它的枷锁(标准滞后于数学前沿,见 01 章相依转向)。

**规范化阶梯(从公理到法条的四级跳,文字版)**:

```
Kolmogorov 公理(概率论)            ← 一切的地基(../讲透概率论/)
   ↓ 参数化
模型族(Weibull/泊松/复合泊松)      ← 可交流的"普通话"
   ↓ 定理化
结构定理(Lundberg/更新报酬/ARL)   ← 本家族的硬通货
   ↓ 制度化
法条(IEC 61508/Solvency II/ISO 7870) ← 别的分支没有的第四级
```

四级跳的每一跳都有折损:公理→模型(假设可能假)、模型→定理(条件可能不满足)、
定理→法条(滞后一拍且保守化)。**读法条时要能沿梯子爬回公理——这就是本家族的"溯源阅读"。**

## 四、语言的性格总结(对比表)

| 维度 | 数理统计(上游) | 应用统计数学(本家族) |
|------|----------------|---------------------|
| 语句主语 | 总体参数 θ | 系统/公司/过程的**指标**(MTBF, ψ(u), ARL) |
| 典型量词 | 对重复实验平均 | 对**时间**平均(更新定理)/对**路径**保证(破产界) |
| 输出物 | 定理 | 定理+**法条**(SIL/Solvency/ISO) |
| 失败模式 | 推不出 | 假设过期(独立/轻尾假设被现实击穿) |

## 五、一个完整翻译示范(SLO 语句的解剖)

工程语言:"本服务月度可用性 SLO=99.9%。"
逐层翻译:
1. 指标层:可用性 A = 1 −(不可用时长/总时长)——更新报酬定理的直译(A=MTBF/(MTBF+MTTR) 的时段版)
2. 承诺层:99.9% 是**过程能力**陈述,不是单月保证——单月实现值是随机变量,会波动
3. 法条层:误差预算 = 1−SLO 对应的允许失效时长(月度 ≈43.8 分钟)——预算耗尽触发变更冻结
4. 假设层(最常被略过):失效间隔近似独立;修复时长分布稳定;**没有共因模式**(机房级故障直接击穿)
5. 验证层:要用控制图/趋势检验监督 SLO 本身——指标自己也要被统计监视

一句工程口号,五层统计语言——**本家族的职业动作就是把第五层补上。**

## 六、术语的考古学(词源即思想史)

| 术语 | 词源 | 思想含量 |
|------|------|---------|
| actuarial(精算) | 拉丁 actuarius(元老院记录官) | 记录风险是最古老的职业之一 |
| bathtub curve(浴盆曲线) | 工程绰号,形即名 | 数学中罕见的"看图识字"命名——好模型自己会取名 |
| bootstrap(靴襻) | 谚语"拎靴襻自举上天" | Efron 的自嘲:像不可能的自助,数据自己举自己 |
| Monte Carlo(蒙特卡洛) | 摩纳哥赌场 | Ulam 起名时想的是"概率与运气的神殿" |
| control chart(控制图) | Shewhart 原文 "control" 借自质量工程 | "受控"=可归因变异只剩随机项——词比概念先行了一步 |

## 七、逐层保证的反例集(每层怎么"说谎")

| 层 | 反例(保证怎么被误读) |
|----|---------------------|
| 定理层 | 假设不满足时套 Lundberg 界——演绎没错,前提是空的 |
| 方法层 | 95% CI 连续 20 次独立实验,期望 1 次不盖住——"我 95% 确定"连着说就是错的 |
| 检验层 | p=0.049 vs p=0.051 被读成"成败两重天"——p 值是连续量,不是开关 |
| 仿真层 | 没报误差棒的 MC 数字=没有小数点的精确谎言 |

## 八、三步法示范:一个定理怎么被"讲人话"

以 Lundberg 不等式为例,完整走一遍概念呈现三步法:

**第一步·直觉图像**:保险公司是一个"水库"——保费是入水,理赔是抽水;
轻尾世界每次抽水都有"单次上限",所以坏运气要连续中很多次才能抽干水库——
连续中很多次小概率事件的概率是**指数级小**的。资本金每翻一倍,把水库抽干的难度平方一次。

**第二步·严格陈述**:设安全负荷 θ>0,调节系数 R>0 满足 λ+cR=λM_X(R)(M_X 为索赔矩母函数),
则最终破产概率 ψ(u) ≤ e^{−Ru}。

**第三步·最小例子**:u=8, R≈0.167(指数索赔,θ=0.2)→ ψ(8) ≤ e^{−1.33} ≈ 26.4%;
家族实验 MC 实测 ψ(8) ≈ 21.7%——上界宽松但方向与量级全对,且 u 翻倍时 ψ 掉一个数量级(指数压缩实拍)。

三步的分工:图像给"为什么",陈述给"是什么",例子给"多少"——**缺任何一步都是没讲透**。
