## 诞生

1924 年 5 月 16 日,Bell 实验室的 Walter Shewhart 在一份备忘录上画下第一张控制图——
把"合格/不合格"的二值审判升级为"过程分布漂移"的连续监测。
二战 MIL-STD-105 抽样验收体系把它制度化;战后 Deming 把它带到日本,重塑了整个制造业的质量哲学。

## 核心问题

已解决:
- 3σ 控制图的 ARL₀≈370(受控状态下平均 370 点误报一次)—— Shewhart/常规结论
- 破坏性检验下的抽样验收理论与 OC 曲线(Dodge–Romig 1920s;Wald 序贯 SPRT 1943)

未解决:
- 高维传感流(工业 4.0 每秒千维)的在线监测:多重比较下的误报控制与检测延迟的权衡
- 相依过程(批次相关)的控制限最优性

## ✨ 这支最美的一个事实

**控制图本质是"每 370 次才误报一次的自动哨兵"**——
一条中心线加两条 3σ 线,把 CLT 变成了工厂里人人会读的图。
(亲历:掷 1000 个均值各含 5 个样本的点,数数落在 ±3σ/√n 外的个数,应约 1000/370≈2.7 个。)

## 假设与依赖

- 过程受控时数据独立同分布、近似正态(样本均值层面 CLT 兜底)
- 代价:过程自相关时 ARL 失真;小批量生产 3σ 图过钝
