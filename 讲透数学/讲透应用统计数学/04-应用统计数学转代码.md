# 04 · 应用统计数学转代码:从风险定理到可跑的数字

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套结构:**可机械化边界 → 代码走廊清单 → 工程师落点**。
> 三步法直觉:应用统计数学天然亲和代码——它的三母题(寿命/盈余/重抽样)**本来就是算法**:
> 寿命=计数过程仿真,盈余=随机游走循环,bootstrap=对样本数组重洗。
> 反过来,它也是"纸笔数学先死、代码数学后生"的最佳标本: Lundberg 1930 年代的解析艺术,
> 今天一个下午的 numpy 就能全部复核。

## 一、可机械化边界(什么能自动、什么永远要人)

| 环节 | 可机械化 | 原因 |
|------|---------|------|
| 分布拟合(参数估计) | ✅ 全自动 | MLE=优化问题,scipy 一行 |
| MC 估计与误差棒 | ✅ 全自动 | 大数定律+CLT 兜底 |
| bootstrap 置信区间 | ✅ 全自动(独立数据) | 重抽样=带放回的 index 采样 |
| Lundberg 界计算 | ✅ 半自动 | 调节系数 R=解一个方程;**方程无解(重尾)时机器必须停下来报警** |
| 破产概率(任意模型) | ✅ 仿真可算 | 复合泊松路径模拟 |
| **模型族选择** | ❌ 不可机械化 | 没有唯一正确模型的判定算法——AIC/BIC 是带立场的裁判(02 章) |
| **相依结构的设定** | ❌ 不可机械化 | Copula 选择=因果/机制判断,数据只能否决不能发明 |
| **风险度量的选择** | ❌ 不可机械化 | VaR vs CVaR vs 期望效用——价值观问题,数学只负责翻译 |

**边界一句话**:**计算证据全自动,选择世界观必须人**。
本家族 01 章的"相依转向"之所以是数学前沿而非工程配置项,正是因为它撞在最后两条上。

## 二、代码走廊清单(从定理到函数的翻译表)

| 定理/方法 | 代码化身 | 最小实现骨架 | 验收断言 |
|-----------|---------|-------------|---------|
| 复合泊松盈余过程 | `ruin_paths(u, c, λ, claims, n)` | 外循环 t,内循环跳泊松到达 | 路径斜率≈c−λμ |
| Lundberg 不等式 ψ(u)≤e^{−Ru} | `lundberg_bound(R, u)` | 指数函数 | 模拟 ψ 落在界内 |
| 调节系数存在性 | `solve_R(mgf, c, λ)` | 数值求根;无根→raise | 重尾时抛异常(=数学事实) |
| MC 误差 ∝ 1/√n | `mc_error(n, σ)` | σ/sqrt(n) | n×4 → 误差×0.5 |
| bootstrap CI | `bootstrap_ci(data, stat, B)` | 重抽样 B 次,取分位数 | 覆盖率≈名义(独立数据) |
| Weibull 拟合 | `scipy.stats.weibull_min.fit` | MLE | β=1 退化为指数 |
| 稳态可用度 A=MTBF/(MTBF+MTTR) | `availability(mtbf, mttr)` | 一行 | 更新定理对照仿真收敛 |
| 3σ 控制图 | `xbar_chart(samples)` | 均值±3σ/√n | ARL₀≈370(理论) |
| 重要抽样(稀有事件) | `importance_sampling(tilt)` | 加权重求期望 | 方差比朴素 MC 降数量级 |

家族实验 `experiments/00_ruin_mc.py` 覆盖走廊前三行(盈余过程+Lundberg 界+重尾报警),纯 numpy。

## 三、工程师落点(性能工程视角)

本家族对现代工程系统的价值集中在四处——每一处都是**把纸面定理变成治理动作**:

### 落点 1:SRE 的误差预算(可靠性数学→运维宪法)
- SLI 的月度误差预算消耗=**盈余过程**:`u=预算,索赔=事故消耗的预算,保费=每月新预算`
- 错误预算政策(消耗过半→冻结发布)= **带阈值的序贯检验**——Lundberg 语言直译成 CI/CD 规则
- 容量冗余设计(n+1/n+2)= 并联可靠性公式的工程化,但**必须过一遍共因失效审计**(00 章反直觉 1)

### 落点 2:混沌工程=主动破产试验
- 故障注入实验(FiT)本质是**对可靠性模型做 MC**——把"预计失效率"换成"实测失效率"再回填模型
- 与 03 章对照:混沌实验构造的是"证据的证据"(对模型的元校准)

### 落点 3:量化风控的监管计算
- VaR/CVaR 回测(BCBS 973 号文)= 覆盖率检验的制度化——统计假设检验长成了法条
- 尾部情景加压= EVT 分位数外推的合规版本

### 落点 4:仿真先行的容量规划
- 排队/负载仿真→ P99 延迟的分布(不只均值!)→ 按**尾部**配容量(03 章尾部眼落地)
- 快速心法:**凡 SLA/SLO/风险限额,先问尾部;凡尾部,先仿真;凡仿真,先报误差棒**

## 四、性能工程视角的特别提示(给 CUDA/系统背景的读者)

1. MC 是**天然可并行**的(路径独立)——GPU 上万路径/秒,把"不可构造"的稀有事件逼成"可构造";
   但 RNG 并行流的选择(seed 跳跃/Counter-based 如 Philox)本身是统计计算支的正经课题。
2. bootstrap 的 B 次重抽样=**同数据不同索引的 gather**——一次拷贝、B 次索引,内存访问模式极友好。
3. 大偏差定向的重要性采样=**用数学换算力**:倾斜函数把 10¹¹ 样本的问题压成 10⁵——
   这是"先验物理直觉代码化"在统计领域的镜像。

## 四'、家族实验代码走读(00_ruin_mc.py 的解剖)

```python
# 核心走廊三件套(与 §二 表格逐行对应):

# 1) 复合泊松盈余过程 → 生成理赔时刻与索赔额
waits  = rng.exponential(1.0/lam, size=(n_paths, n_arr))   # 泊松到达间隔
claims = claim_sampler(size=(n_paths, n_arr))              # 索赔额(可换分布)
arr_t  = np.cumsum(waits, axis=1)                          # 理赔时刻

# 2) 破产判定 → 只在理赔时刻检查(保费连续、索赔跳变,极小值必在跳变点)
surplus = u + c*arr_t - np.cumsum(claims, axis=1)
ruined  = (np.where(arr_t < T_max, surplus, np.inf) < 0).any(axis=1)

# 3) Lundberg 界 → 数学失效分支必须显式报警
R = lundberg_R_exp(beta, theta)   # 轻尾闭式;重尾时矩母函数发散、R 不存在 → 拒绝输出假界
```

走读要点:
- **离散事件视角**:不必逐步推进时间,只检查状态跳变点——一次向量化算 2 万条路径
- **报警路径即数学**:R 无解(重尾)时,正确的代码行为是 raise,不是输出一个"看起来合理"的数
- **验收断言即定理**:ψ_MC ≤ e^{−Ru}+3se(Lundberg 成立)、ψ_重尾>ψ_轻尾(尾部效应)——
  把 00/03 章的两条定理写成 assert,跑过即实证

## 四''、A/B 测试=本家族的第五个落点

在线实验(新功能灰度)全栈是应用统计数学:
- 样本量计算 → 1/√n 换算率(显著性×功效 → 最小样本)
- 序贯窥视问题 → Wald SPRT/随时有效 p 值(mSPRT)——"忍不住提前看数据"的合法化
- 多重比较 → Bonferroni/BH-FDR(同 ../讲透数理统计/ 假设检验支)
- SLO 仲裁 → 效果量+置信区间,不只 p 值

## 五、反直觉:代码层的三个陷阱

1. **伪随机的伪影**:坏 RNG 的低维晶格让高维 MC 悄悄偏——换 RNG,答案变,你以为在测模型其实在测发生器
2. **默认分布的暴政**:库函数默认 `weibull_min.fit` 给出 β,小样本下 β 的置信区间宽得没用——自动化≠可交付
3. **1/√n 的诱惑**:误差棒只降 1/√n——样本×100 才少一个 0;方差缩减(重要抽样/控制变量)才是杠杆

## 五'、最小可运行栈(从零复现本章走廊)

```
依赖:仅 numpy(全部走廊可加 scipy 提速)

1. numpy.random.default_rng(seed)      # 现代RNG入口(PCG64):先换掉裸random
2. rng.exponential / rng.lognormal / rng.pareto   # 三种命运(轻尾/重尾/极重尾)一键切换
3. np.cumsum(axis=1)                   # 盈余过程/更新过程的离散事件骨架
4. (x<0).any(axis=1).mean()            # 首穿时事件 → 蒙特卡洛点估计
5. np.sqrt(p*(1-p)/n)                  # 二值事件的标准误——报数字必配这一行
6. idx=rng.integers(0,n,(B,n))         # bootstrap 一行:重抽样索引矩阵
7. np.quantile(stat[idx].sum/…)        # 分位数法置信区间
```

七行代码=一整套风险实验台。第 5 行是职业操守:任何 MC 数字不带 se 不许出门。

## 五''、何时不要仿真(仿真的反适用清单)

| 情形 | 为什么别仿真 | 该用什么 |
|------|-------------|---------|
| 有解析式可推(如指数索赔的 ψ) | 解析解精确+零成本,仿真只有误差 | 纸笔/符号计算 |
| 稀有事件概率 <10⁻¹⁰ 且无方差缩减方案 | 朴素 MC 一辈子见不到一次事件 | 大偏差渐近/分裂法 |
| 需要上界保证而非点估计 | MC 给估计不给保证 | Lundberg 界/集中不等式 |
| 维数低(≤3)的期望积分 | 格点/自适应求积更快更准 | 数值积分 |
——仿真是"别无选择时的最优",不是"永远的第一选择"。
