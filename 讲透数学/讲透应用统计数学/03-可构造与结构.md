# 03 · 可构造与结构:哪些风险对象可构造,刚性从哪来

> **本章回答五问之四:可构造性?结构性?**
> 三步法直觉:应用统计数学的"构造"有一把独特的尺子——**别的分支构造对象(证明它存在),
> 本分支构造证据(让存在性变成可交付的数字)**。
> 你不能构造"这台机器不坏"这个事实,但你能构造"以多大概率信它不坏"的完整论证链。
> 结构刚性则来自一个词:**尾部**——轻尾给指数级的刚,重尾给多项式级的柔。

---

## 一、可构造性清单(从"存在"到"可交付")

| 对象 | 可构造吗 | 构造方法 | 构造的代价 |
|------|---------|---------|-----------|
| 均值/方差估计 | ✅ 直接 | 样本均值/样本方差 | 无偏,但对重尾极慢收敛 |
| 置信区间 | ✅ 直接 | CLT 或 pivot 或 bootstrap | 95% 只是**动作**的命中率(02 章) |
| 破产概率(轻尾) | ✅ 半解析 | Lundberg 界/Pollaczek–Khinchine 公式 | 需调节系数 R 存在(矩母函数条件) |
| 破产概率(重尾) | ⚠️ 渐近 | subexponential 渐近 ψ(u)~C·F̄(u) | 只有"无穷远处"的形状,有限 u 靠仿真 |
| 最优再保险 | ✅ 有解 | 凸优化/随机控制(方差最小→成数,尾部截断→超额) | 解依赖"风险度量选择"——没有免立场的最优 |
| Weibull 参数 | ✅ 数值 | MLE+数值解(无闭式) | 小样本形状参数 β 方差巨大——浴盆分段点难定 |
| 控制图限 | ✅ 直接 | 3σ 原则/ARL 反解 | 多变量/相依过程无最优限 |
| 稀有事件概率(10⁻⁹) | ⚠️ 需技巧 | 重要抽样/分裂法 | 朴素 MC 需要 ~10¹¹ 样本——不可构造,除非用大偏差定向 |

**关键分野**:**矩母函数存在与否**是构造性的悬崖——
指数尾(轻尾)世界:调节系数 R 存在,Lundberg 界、Cramér 渐近全可构造;
重尾世界(对数正态/Pareto):R=∞,指数界全体失效,只剩次指数渐近——**一个积分条件的差异,两套文明**。

**可构造性速查卡(打印贴墙版)**:

```
拿到一个风险对象,依次问:
1 尾部厚吗? ──薄(指数)──▶ 指数界/精确公式:纸笔可构造 ✓
│              └─厚(对数正态/Pareto)──▶ 渐近+仿真:半构造 ⚠(先报警)
2 有更新循环吗? ──有──▶ 长期指标=期望收支比:一行公式白拿 ✓
│                └─无(暂态)──▶ 仿真,且形状参数敏感 ⚠
3 事件多稀有? ──p≥10⁻³──▶ 朴素 MC 即可 ✓
│              └─p<10⁻⁶──▶ 必须方差缩减(大偏差定向)⚠
4 数据独立吗? ──是──▶ bootstrap 合法 ✓
               └─否──▶ 区块化/建模相依 ⚠
答完四问,构造路线自动确定。
```

## 二、结构:刚性的三个来源

### 来源 1:指数压缩(轻尾的刚性)

✨ **之美 3:Cramér–Lundberg 世界里破产概率的指数衰减 ψ(u)≤e^{-Ru}**
为什么美:**必然中的意外**。破产需要大量"坏运气"连续堆积,而轻尾让每次坏运气都指数昂贵,
乘起来就是双重指数的压制——随机性越被压,资本金的边际价值越确定。
怎么亲历:`experiments/00_ruin_mc.py` 里把 u 翻倍,看破产概率掉的数量级 vs 上界预言。

### 来源 2:更新结构(过程的结构定理)

更新报酬定理(renewal reward theorem)说:长期平均报酬率 = 单周期期望报酬/周期期望长。
**结构刚性来自"循环"**:只要过程不断重来,长期指标被单一周期的期望锁死——
稳态可用度 A = MTBF/(MTBF+MTTR) 这个 SRE 口头禅就是它的直译,与分布形状无关(刚性!)。

**最小数字例(亲历刚性)**:取故障间隔~Exp(均值 100h),修复~Exp(均值 1h):
- 稳态可用度 A = 100/101 ≈ 0.9901
- 换成 Weibull(β=2, 同均值 100h)故障+固定 1h 修复:A **完全不变** = 0.9901
——分布形状天翻地覆,长期指标纹丝不动:这就是"循环锁死"。
(为什么?指数的无记忆性 vs Weibull 的老化,只改变"何时坏",不改变"坏-修循环的期望收支"。)

### 来源 3:大偏差的变分结构(稀有事件的几何)

大偏差原理(LDP):P(路径偏离典型集 ε)≈e^{−n·I(偏离)},速率函数 I 是"偏离的价格表"。
它给稀有事件仿真**自动设计重要性采样**的倾斜系数——
结构刚性来自变分:最省力的逃逸路径(最小 I)主导一切。这与 ../讲透概率论/ 极限理论支、
../讲透计算数学/ 随机数值支共享同一副骨架(大偏差=概率的力学)。

## 三、不可构造的硬墙(以及墙边的设计)

| 硬墙 | 墙边设计(工程绕法) |
|------|-------------------|
| 极端分位数(超越数据)直接估计 | 极值理论(EVT)外推:GPD 拟合超过阈值的部分——承认"外推",但把外推的形状参数化 |
| 最优停时(何时卖/何时修)无闭式 | 动态规划数值解+策略结构定理(τ 的单调性往往可证) |
| 非参数相依过程的 bootstrap | 区块 bootstrap/平稳 bootstrap——把相依打包成"准独立"块 |
| 模型风险本身 | 鲁棒统计/情景加压测试(stress test)——不选模型,问"模型错多少我死" |

**硬墙的数字感**(墙有多硬):
- 估计 10⁻⁹ 失效率:朴素 MC 需 ~10¹¹ 样本(10 亿次仿真才能见几百次事件)——
  重要抽样可压到 10⁵~10⁶:墙没拆,但开了窗
- 估计 P(Z>6)(正态 6σ):朴素命中率 ~10⁻⁹,与上同量级;倾斜分布后单样本即可贡献信息
- 小样本 Weibull 的 β:n=20 时 β 的 95% CI 可以横跨 [0.6, 4]——浴盆期还是耗损期都判断不了,墙内的日常

## 四、反直觉:结构对参数的背叛

1. **均值相同的两条寿命分布,可靠性可以天壤之别**——决定性结构量是尾部形状参数,
   不是期望。买设备只看 MTBF=买彩票只看奖金池。
2. **并联系统的失效率不可能低于"共因底座"**——结构图上的并联,在失效物理上可能是串联。
3. **Cramér 渐近与 Lundberg 上界可以同时"对"却给出差数量级的数**——上界保守,
   渐近只管无穷远:工程在两者之间的地带裸奔。

## 五'、两个完整数字例(把结构算给你看)

**例 1:调节系数 R 怎么把三个世界分开**(索赔 E[X]=1,λ=1,θ=0.2,c=1.2):
- 指数索赔 X~Exp(1):R = θ/(1+θ)·β = 0.2/1.2 ≈ 0.1667 → ψ(10) ≤ e^{−1.67} ≈ 18.9%
- 确定性索赔 X≡1:R 满足 λ+cR=M_X(R) → 1+1.2R=e^R,数值解 R≈0.26 → ψ(10) ≤ 7.4%(方差更小,R 更大,更安全)
- 对数正态(σ=1):M_X(t)=∞ 对一切 t>0 → **R 不存在,界整体消失**
同一安全负荷,三种命运——"结构的刚性=尾部的厚度的减函数"。

**例 2:更新循环锁死长期指标(与形状无关的刚性)**:
故障~Exp(μ=100h)、修复~Exp(μ=1h):A = 100/101 ≈ 0.990099
换成 Weibull(β=3, 同均值 100h)故障 + 固定 1h 修复:A = 100/101 ≈ 0.990099(**一位小数都不变**)
——分布形状自由换,长期可用度被 (E[故障], E[修复]) 两个数锁死。
反例警示:换的是**短窗口指标**(如"下周可用性"),形状立刻起作用——刚性只属于"无限长期"。

## 五''、构造失败的三次历史(承认边界的历史)

| 年代 | 构造失败 | 后果与教训 |
|------|---------|-----------|
| 1980s | 用正态近似套衍生品尾部(轻尾假设) | 1987 黑色星期一:22σ 事件发生——正态世界它 10⁻¹⁰⁰ 年一遇 |
| 2000s | 高斯 Copula 把相依压缩成一个相关系数(CDO 定价) | 2008 次贷:相依在危机中趋于 1,"分散化"幻觉破产 |
| 2010s | 长期资本式风险模型忽略 regime 切换 | 尾部 + 相依 + 时变三者联手,单因素模型全体失明 |
——三次失败同一病根:**用可构造(轻尾/单参数相依)替代了真结构(重尾/多元相依)**。

## 六、结构与参数的分辨清单(拿到模型先跑一遍)

| 问题 | 答"结构" | 答"参数" |
|------|---------|---------|
| 改动它,长期指标变吗? | 变(如引入共因) | 不变(如改分布形状,见 §五' 例 2) |
| 改动它,结论的形式变吗? | 变(重尾→指数界消失) | 不变(只改常数,如 θ 0.2→0.3) |
| 需要数据估计吗? | 不需要(是模型形态选择) | 需要(是拟合) |
| 错了的后果等级? | 灾难级(工具箱整体失效) | 误差级(数值偏差) |

**职业直觉**:**先锁结构,再估参数**——顺序反了,精度再高也是在错误的世界上做精算。
