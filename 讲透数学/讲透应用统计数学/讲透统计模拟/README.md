# 讲透统计模拟 · 仿真即实验:蒙特卡洛与重抽样

> **定位句**:这支负责"**算不出来就估出来**"——蒙特卡洛、bootstrap、方差缩减,
> 把不可解的概率问题变成可估、可审计的数值实验。| GB/T 13745 · 11071 三级「统计模拟」
> 家族:[讲透应用统计数学](../README.md) · 五问模板支成员

## 诞生

1946 年 Stanislaw Ulam 病中玩纸牌(.Canfield solitaire)想算成功概率,
组合爆炸让他转向"洗一万次牌数一数"——蒙特卡洛方法在病床上诞生,名字取自摩纳哥赌场;
1979 年 Efron 的 bootstrap 把同一思想转回数据本身:**把样本当总体,重抽样即推断**。
两次诞生的共同底色:计算便宜了,推断的方式就该变。

## 核心问题

已解决:
- MC 误差 ∝ σ/√n + 中心极限定理渐近正态(误差棒的理论依据)
- bootstrap 的渐近一致性(独立数据;Singh 1981 等)
- 方差缩减家族:重要性采样/控制变量/对偶变量/条件期望(Rao-Blackwell 化)

未解决:
- **相依数据的 bootstrap**——时间序列/网络数据的重抽样仍是活跃前沿(区块法只是权宜)
- 稀有事件仿真的复杂度常数(大偏差给方向,常数难求)

## ✨ 这支最美的一个事实

**1/√n 的明码标价**:样本×100,误差才少一个零——
朴素 MC 的"诚实"与"低效"同源;而重要性采样用数学(大偏差的速率函数)直接换算力,
一出手就是数量级。公平定价与杠杆套利,在同一个定理里。

## 假设与依赖

- 样本独立(bootstrap 一致性的底线;相依时换区块 bootstrap)
- 估计量方差有限(重尾下 CLT 失效,误差棒本身失效)
