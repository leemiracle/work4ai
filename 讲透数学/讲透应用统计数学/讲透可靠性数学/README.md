# 讲透可靠性数学 · 寿命与失效的科学

> **定位句**:这支负责"**这东西能活多久**"——把寿命的不确定性写成分布、把系统的存亡写成结构。| GB/T 13745 · 11071 三级「可靠性数学」
> 家族:[讲透应用统计数学](../README.md) · 五问模板支成员

## 诞生

二战德国 V-1/V-2 与美军装备的"十发两哑"逼出可靠性工程;
1957 年美国 AGREE 报告给出 MIL-STD 定义,Weibull(1951)的分布族
把婴儿夭折期、随机失效期、耗损期统一进一个形状参数——**浴盆曲线**从此是工程界的通灵图。

## 核心问题

已解决:
- Weibull 族统一三段失效模式(Weibull 1951)
- 串联/并联/混联系统的可靠度组合公式(R = ∏Rᵢ 或 1−∏(1−Rᵢ))
- 稳态可用度 A = MTBF/(MTBF+MTTR)(更新报酬定理直译)

未解决:
- 共因失效(common cause)的公理化建模——为何冗余系统实际失效率远超理论值(挑战者号 O 型圈是教材案例)
- 软件/复杂系统的可靠性增长模型(失效不再是物理老化)

## ✨ 这支最美的一个事实

**MTBF 的 63.2% 之谜**:指数失效下,寿命超过 MTBF 的概率只有 e^{−1}≈36.8%——
"平均无故障时间"的直觉读法(大多数设备能撑到 MTBF)恰好反了。
一条指数曲线,治好一个工程界的集体误读。

## 假设与依赖

- 寿命分布族可参数化(Weibull/指数/对数正态)——买到外推,付出尾部错配
- 组件失效独立——买到组合公式,付出共因盲区
