## 02 - QR 分解

### 定义

$A = QR$，$Q$ 正交（$Q^T Q = I$），$R$ 上三角。

### 算法

- **Gram-Schmidt**：列向量正交化（经典 / 修正版）
- **Householder**：反射变换（更稳定）
- **Givens**：旋转（稀疏矩阵友好）

### 反直觉

经典 Gram-Schmidt **数值不稳定**（误差累积）。修正版（Modified GS）和 Householder 更好。

### 应用

- 解 $Ax = b$（QR 比 $A^{-1}$ 稳定）
- 最小二乘（`np.linalg.lstsq`）
- 特征值算法（QR algorithm）

## 03 - 条件数与稳定性

### 条件数（problem 属性）

$\kappa(A) = \|A\| \|A^{-1}\| = \sigma_{\max}/\sigma_{\min}$

### Backward 稳定性（algorithm 属性）

算法 backward stable ⟺ 精确解邻近问题。

### 总误差

forward error ≤ $\kappa$ × backward error

### 反直觉

- 即使算法 backward stable，病态问题的解仍可能完全错
- 例：$H_{15} x = b$ 的解毫无意义（即使 `np.linalg.solve` 是 backward stable）

### 应用

- **数值分析**：所有数值算法的误差分析
- **ML**：为什么 float16 训练困难

## 04 - 特征值算法

### QR algorithm ⭐

迭代：$A_0 = A = QR$，$A_1 = RQ$，$A_2 = Q_1 R_1$, ... → 收敛到对角（特征值）。

**收敛**：线性（一般），加速用 shift。

### 反直觉

计算特征值**不**通过特征多项式（数值灾难）——用 QR 迭代。

### Schur 分解

$A = UTU^*$（$U$ 酉，$T$ 上三角）。→ 任何矩阵可酉三角化。

### 应用

- **PCA**：协方差矩阵的特征向量
- **Google PageRank**：最大特征向量
- **NN**：谱归一化

---

## 05 - 迭代法（Krylov 子空间）

### 大型稀疏矩阵

直接法（LU/QR）$O(n^3)$——大稀疏矩阵不可行。迭代法 $O(nnz)$ 每步。

### 共轭梯度（CG）

对称正定 $Ax = b$。$O(n)$ 内存，$O(\sqrt{\kappa})$ 步收敛。

### GMRES

非对称。$O(n)$ 内存每步，但可能不收敛。

### 反直觉

CG 收敛速度依赖 $\sqrt{\kappa}$——预处理（preconditioning）降 $\kappa$ 是核心。

### 应用

- **科学计算**：PDE 离散化
- **ML**：大型线性系统（如 kernel method）
- **优化**：二阶方法（K-FAC / Hessian-free）

## 06 - ML 应用

### PCA

数据 $X = U \Sigma V^T$。主成分 = $V$ 的列（按 $\sigma$ 排序）。

### LoRA

$W \approx U \Sigma V^T$，只学 $U, V$（低秩）。节省内存。

### Word2vec / GloVe

共现矩阵的 SVD（Levy-Goldberg 2014 证明等价于 word2vec）。

### 注意力数值稳定

大 softmax 数值下溢 → 减去最大值（`x - max(x)`）。

### Spectral normalization

每层权重除以最大奇异值 → 强制 $\|f\|_{\text{Lip}} \leq 1$。

### 应用汇总

| ML 技术 | 数值线代 |
|---------|---------|
| PCA / 降维 | SVD |
| LoRA / 低秩微调 | 截断 SVD |
| 推荐系统 | 矩阵补全 |
| Spectral norm | 特征值 |
| Kernel methods | 大线性系统（CG）|
| PageRank | 幂迭代 |
