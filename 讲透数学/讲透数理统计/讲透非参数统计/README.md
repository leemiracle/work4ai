# 讲透非参数统计 · 不猜形状的统计

> **定位句:这支负责"当分布形状可疑时仍能推断"——免假设保险。**
> GB/T 11067 三级「非参数统计」

## 诞生

- 1945 Wilcoxon 秩和检验(化学工业中的便捷法);1947 Mann–Whitney 独立发展
- 1963 Parzen/Rosenblatt 核密度估计——"让数据自己画出分布"
- 1979 Efron bootstrap 把"非参数"推到极致:连统计量的分布都不需要知道

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 秩检验的分布无关精确零分布;Glivenko–Cantelli(经验分布一致收敛);核估计的 MSE 最优带宽(h~n^(-1/5));DKW 不等式(经验分布的浓度) |
| ✅ 已解决 | Kolmogorov–Smirnov 检验(整个分布形状的比较) |
| 🔄 进行中 | 高维非参数(维数灾难的正面强攻);conformal(分布无关区间)归此谱系 |
| ❓ 未解决 | 免调带宽的自适应估计;非参数贝叶斯的先验选择理论 |

**最美事实(一句)**:把数据换成秩再检验,功效只损失一点点(渐近相对效率 0.955),
却换来对一切连续分布的精确检验——"少假设一点点,稳健一整片"。

## 假设与依赖

- "非参数"≠无假设:仍有连续性/交换性/光滑性(带宽)要求;独立同分布仍是默认底盘
- 代价:收敛更慢(n^(-1/5) vs 参数的 n^(-1/2));维数灾难=光滑性的账单
- 依赖:[讲透抽样理论](../讲透抽样理论/)(经验分布);[讲透统计推断](../讲透统计推断/)(检验框架)
