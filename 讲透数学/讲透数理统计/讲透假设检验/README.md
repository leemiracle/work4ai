# 讲透假设检验 · p 值的家

> **定位句:这支负责"证据够不够定罪"——统计判决的第一句型。**
> GB/T 11067 三级「假设检验」

## 诞生

- 1900 Pearson χ² 拟合检验——第一个"显著性检验"
- 1925 Fisher 系统化显著性(p 值/0.05 阈值的出处);1933 Neyman–Pearson
  《On the Problem of the Most Efficient Tests of Statistical Hypotheses》
  引入两类错误与功效——Fisher 的"证据度量"与 NP 的"决策程序"两套语义合流为现代检验

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | Neyman–Pearson 基本引理(简单假设的最优检验=似然比);UMP/UMPU 存在性刻画;似然比/Wald/Score 三大渐近检验 |
| ✅ 已解决 | 置换检验与秩检验的分布无关精确性 |
| 🔄 进行中 | 高维检验(渐近分布失真→重抽样/bootstrapped 修正);选择性推断("看了数据再检验"的自动校正) |
| ❓ 未解决 | p 值的"效应量语义"统一;组合证据的完全理论(证据合成) |

**最美事实(一句)**:Neyman–Pearson 引理证明"似然比检验最优"——
定罪的最优证据规则,竟与直觉的"比较哪种假设更像数据"完全一致。
