# 讲透方差分析 · 多组均值比较的方差分解术

> **定位句:这支负责"三组以上怎么比"——把总方差按来源拆账,各组差异自然现形。**
> GB/T 11067 三级「方差分析」

## 诞生

- 1918-1925 R. A. Fisher 在 Rothamsted 农业试验站发明 ANOVA:
  田间地块肥力不均→"区组+随机化+方差分解"三件套;1925《Statistical Methods for Research Workers》
  把它带给一切实验科学。F 检验以 Fisher 命名——一个人写下这支的上游(设计)与本体(分解)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | Cochran 定理(平方和分解与独立 χ² 的对应)——ANOVA 的数学心脏;单/多因素、交互效应、随机效应与混合模型 |
| ✅ 已解决 | 多重比较(Tukey HSD/ contrasts)——拆账后的比价问题 |
| 🔄 进行中 | 高维 ANOVA(组数/维数超过样本);F 检验的稳健替代(置换/自助) |
| ❓ 未解决 | 异方差/非平衡设计的统一最优检验;ANOVA 与因果图选择的自动结合 |

**最美事实(一句)**:SST=SSA+SSE 的恒等式——不需要任何分布假设,"总变异=组间+组内"
纯代数成立;分布假设只在"比值 F 服从什么"时才进场,分解的美先于概率。

## 假设与依赖

- 经典 ANOVA 三假设:独立、正态、方差齐——违反时 F 的名义水平失真(稳健版见非参支)
