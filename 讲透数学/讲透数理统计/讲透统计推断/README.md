# 讲透统计推断 · 家族心脏:一切推断的总纲

> **定位句:这支负责"从样本到结论的通用语法"——估计、区间、似然、信息,全家各支都讲它的方言。**
> GB/T 11067 三级「统计推断」

## 诞生

- 1922 Fisher《On the Mathematical Foundations of Theoretical Statistics》——
  首次把"统计问题"本身定义为数学对象:似然、充分统计量、一致性、有效性一字排开
- 1945 Rao / 1946 Cramér 独立给出信息下界;1949 Lehmann–Scheffé 定理(Rao-Blackwell+完备性=UMVU)
- 1958 Kallenberg/Le Cam 的渐近理论把"大样本"变成严格学科

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 因子化定理(充分性);Rao–Blackwell 定理(条件化只减方差);Cramér–Rao 下界;Lehmann–Scheffé(UMVU 存在性);MLE 渐近正态与有效性 |
| ✅ 已解决 | 指数族的完全推断闭环(共轭/充分/MLE 三位一体) |
| 🔄 进行中 | 高维/无穷维参数空间的推断(半参数效率理论);分布无关推断(conformal 谱系) |
| ❓ 未解决 | 非正则模型的统一渐近理论;“信息"在相依数据下的定义 |

**最美事实(一句)**:Rao–Blackwell 定理——对任何无偏估计按充分统计量取条件期望,
方差只会降不会升:"数据里与参数无关的部分,扔掉只赚不赔"。
