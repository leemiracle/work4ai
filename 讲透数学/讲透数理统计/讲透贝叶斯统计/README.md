# 讲透贝叶斯统计 · 信念的微积分

> **定位句:这支负责"先验×数据=后验"——把学习本身写成概率的更新语法。**
> GB/T 11067 三级「贝叶斯统计(包括参数估计等)」

## 诞生

- 1763 Bayes 遗作(由 Richard Price 整理发表)《An Essay towards solving a Problem in the Doctrine of Chances》
- Laplace 1812 系统化(实用贝叶斯第一人);20 世纪被频率派压制;
- 1958 后复兴三连:de Finetti 交换性定理(1931/1937)给先验以数学合法性、
  Jeffreys 无信息先验、Savage 主观期望效用公理化
- 1990s MCMC 革命(Gelfand–Smith 1990;BUGS 1989)让后验"算得动"——贝叶斯从哲学变成工业

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 共轭先验代数(指数族闭环);Bernstein–von Mises(大样本后验≈频率渐近,两派秘密和解);后验一致性理论 |
| ✅ 已解决 | MCMC 的遍历性保证(Geoman–Gelman 收敛诊断谱系);变分推断的 ELBO 下界 |
| 🔄 进行中 | 可扩展贝叶斯(NVC/MCMC 变分混合);贝叶斯深度学习(权重后验);先验的自动选择 |
| ❓ 未解决 | 无信息先验的完全理论;模型错设下的后验行为(稳健贝叶斯) |

**最美事实(一句)**:Bernstein–von Mises 定理——数据足够多时,贝叶斯后验与频率抽样分布
殊途同归:两派吵了两百年,大样本处握手言和。

## 假设与依赖

- 先验的选取是语法的一部分(不是耻辱,是明码标价的假设);模型族正确+可交换性
- 依赖:[讲透统计推断](../讲透统计推断/)(似然公用);概率论条件期望
