## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透数理统计/
├── 讲透抽样理论/       数据进门的第一关(抽样分布/抽样调查)
├── 讲透假设检验/       p 值的家(显著性/功效/两类错误)
├── 讲透非参数统计/     不假设分布形状的统计(秩/核/光滑)
├── 讲透方差分析/       多组均值比较的方差分解术(ANOVA)
├── 讲透相关回归分析/   变量关系建模(相关≠因果的故乡)
├── 讲透统计推断/       家族心脏(点估计/区间估计/似然理论)
├── 讲透贝叶斯统计/     先验×数据=后验(信念的微积分)
├── 讲透试验设计/       让数据自己说话之前,先设计好问题(Fisher 的田间革命)
├── 讲透多元分析/       高维数据的经典武器库(PCA/因子/判别/聚类)
├── 讲透统计判决理论/   统计的博弈论化(损失/风险/Wald)
├── 讲透时间序列分析/   按时间排队的观测(ARMA/谱/状态空间)
└── 讲透空间统计/       带坐标的数据(克里金/点过程/空间自相关)
```
