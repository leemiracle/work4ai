# 讲透相关回归分析 · 变量关系的建模(与"相关≠因果"的故乡)

> **定位句:这支负责"一个变量如何随另一些变量变"——统计建模的骨架,也是因果之问的起点。**
> GB/T 11067 三级「相关回归分析」

## 诞生

- 1885-1889 Galton"回归平庸"(regression towards mediocrity)——高个子父母的孩子
  平均没那么高;"回归"这个词从此背负着它的原罪(其实说的是均值收缩)
- 1809 Gauss/1805 Legendre 最小二乘(天文测轨道);19 世纪末 Yule 把回归带入社会科学
- 1922 Fisher 用 ANOVA 重写回归的推断理论;1972 Nelder–Wedderburn GLM 把响应类型全面放开

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | Gauss–Markov 定理(OLS=BLUE);回归的方差分解与 R²;加权/广义最小二乘;模型选择(AIC/BIC/交叉验证谱系) |
| ✅ 已解决 | 诊断学(残差/杠杆/影响点:Cook 距离) |
| 🔄 进行中 | 高维回归(Lasso/弹性网→正则化统计);缺失数据(多重插补);分布式回归 |
| ❓ 未解决 | 高维 p≫n 的变量选择一致性边界;因果结构的可学性(与因果推断合流) |

**最美事实(一句)**:Gauss–Markov——在一切线性无偏估计里,OLS 方差最小,
且不需要正态假设;"最小二乘好用"不是经验,是代数。

- 经典线性模型四假设(线性/独立/同方差/正态推断);回归系数=共变不是因果——
  因果需要额外词汇(随机化/工具变量/潜在结果,00 章因果内节)
