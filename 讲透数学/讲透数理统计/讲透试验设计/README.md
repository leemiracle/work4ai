# 讲透试验设计 · 收数据之前的设计学

> **定位句:这支负责"让数据开口之前,先把问题问对"——统计里唯一一门发生在数据之前的分支。**
> GB/T 11067 三级「试验设计」

## 诞生

- 1926-1935 Fisher 在 Rothamsted 农业试验站:"问问自然界,先得会提问"——
  随机化、重复、区组三原则;1935《The Design of Experiments》(女士品茶实验=随机化检验第一例)
- 1935-40s Yates/FINNEY 因子设计;1950s 田口玄一稳健参数设计(工业日本);
- 2020s 科技公司把 DOxE 变成 A/B 平台流量调度——"田间统计学"变成"机房统计学"

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 随机化检验的分布无关精确性;完全随机/随机区组/拉丁方/因子/分式的构造与方差配比;最优设计理论(Elfving/信息矩阵最大化) |
| ✅ 已解决 | 功效与样本量计算(正态近似+仿真两条路) |
| 🔄 进行中 | 自适应设计(多臂老虎机/响应自适应随机化);序贯检验的 alpha 消耗 |
| ❓ 未解决 | 网络干扰下的设计(个体处理效应溢出到邻居);观测性"设计"(无法随机化时的次优选择) |

**最美事实(一句)**:Fisher 随机化——仅仅是"随机分组"这个动作,
就把一切未知混杂因子的系统性偏倚变成了可计算的随机误差:不看数据就赢了一半。
