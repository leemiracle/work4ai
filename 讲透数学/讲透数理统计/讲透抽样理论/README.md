# 讲透抽样理论 · 数据进门的第一关

> **定位句:这支负责"数据怎么来才配做推断"——一切统计结论的合法性从抽样开始。**
> GB/T 11067 三级「抽样理论(包括抽样分布、抽样调查等)」

## 诞生

- 抽样分布:Gosset("Student")1908 发现小样本均值的 t 分布——统计量自己也有分布,这门学问自此开始
- 抽样调查:1934 Neyman 论文确立"基于设计的推断"(随机化+代表性别于大样本),
  现代民意调查与官方统计的方法论地基(A. L. Bowley 与 Kiaer 的早期论战是它的史前史)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 统计量的抽样分布(χ²/t/F 的精确推导);分层/整群/多阶段设计的方差公式;Horvitz–Thompson 估计(不等概率抽样的无偏加权) |
| ✅ 已解决 | 有限总体校正与设计效应(design effect)——"有效样本量"的换算 |
| 🔄 进行中 | 无响应与自适应抽样(A/B 平台的动态分流);网络样本(图抽样)的代表性 |
| ❓ 未解决 | 高度偏斜总体的稳健设计;小域估计(small area estimation)的边界 |

**最美事实(一句)**:中心极限定理让"随机抽 1000 人"足以推断一个亿级总体,误差 ~3%——
民主国家的民调与统计署的全部魔法都建立在这一条定理的"平方根加速"上。

## 假设与依赖

- 随机化=合法性的唯一来源(抽样概率已知);违背则需模型辅助(倾向得分)
- 硬依赖:[讲透统计推断](../讲透统计推断/)(抽样分布是推断的原料);概率论 CLT

- Casella & Berger《Statistical Inference》第 5 章(抽样分布);Cochran《Sampling Techniques》(经典)
