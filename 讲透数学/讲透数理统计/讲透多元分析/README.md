# 讲透多元分析 · 高维数据的经典武器库

> **定位句:这支负责"变量很多时的降维、分组与结构发现"——机器学习之前的高维统计正规军。**
> GB/T 11067 三级「多元分析」

## 诞生

- 1897 Pearson 多元相关;1928 Wishart 分布(样本协方差阵的分布)——多元正态理论成型
- 1933 Hotelling PCA(主成分分析);1936 Fisher 判别分析(鸢尾花数据从此不朽)
- 1950s-60s 因子分析(心理学)与聚类分析(数值分类学)合流成"多元统计"建制

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | PCA 最优性(Eckart–Young:最优秩 k 逼近=前 k 主成分);Hotelling T²(多元均值检验);MANOVA;Fisher 判别与贝叶斯判别 |
| ✅ 已解决 | 谱系聚类/k-means 的算法学;因子分析与 PCA 的语义区分(隐变量 vs 方差分解) |
| 🔄 进行中 | 高维渐近谱理论(随机矩阵入场,见概率论家族);稀疏 PCA;函数型数据分析 |
| ❓ 未解决 | 潜因子个数的可辨识;聚类数目的相合选择理论 |

**最美事实(一句)**:Eckart–Young 定理——把数据矩阵截断到前 k 个奇异值,
就是**一切**秩 k 逼近中误差最小的:PCA 的"降维最优"是线数代给的铁证,不是经验。

## 假设与依赖

- 多元正态假设(经典理论);样本量 n>维度 p 的经典前提(高维情形移交随机矩阵/学习理论)
- 依赖:[讲透相关回归分析](../讲透相关回归分析/)(协方差结构);线性代数(谱分解=命根子)
