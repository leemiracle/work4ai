# 数理统计思维技能卡(讲透数理统计家族 · GB/T 11067)

## ① 何时用此分支(触发特征,一眼对号)

- 你有**数据**和**不确定性**,要回答"多大可能/差多少/可信吗"
- 出现 p 值、置信区间、显著性、功效、样本量、A/B 测试
- 要**估计**参数(点/区间)、**比较**组间差异、**检验**假设
- 要把**先验信念+新证据**融合更新(贝叶斯)
- 数据带**时间**(时序)、**坐标**(空间)、**高维**(多元)结构
- 同时做**很多次检验**(告警风暴/组学/多指标看板)——多重比较问题

*不是这里*:纯预测不问推断→统计学习理论;纯随机建模不反推→概率论。

## ② 核心思维模式

1. **逆向概率**:数据=果,分布=因;似然=固定数据、遍历假设打分
2. **数据=随机变量的实现**:一切结论都是"程序在重复使用下的长程性质"
3. **保证-功效-代价三角**:任何方法都是"某假设换某保证,再牺牲多少功效"
4. **损失驱动**(判决观):估计/检验/区间都写成"行动+损失",统计=风险最小化
5. **信息守恒**:Cramér–Rao 提醒你——分辨力不够时,没有 estimator 能凭空变准

## ③ 工具箱(方法名 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| MLE(极大似然) | 有参数模型、要"最像这份数据"的参数 |
| 置信区间(精确 t/χ²/F) | 小样本+近正态,要教科书级严格 |
| Bootstrap | 不想推公式、统计量任意(中位数/比值),样本≥几十 |
| Neyman–Pearson 检验/似然比 | 两假设二选一,要控制第一类错误 |
| BH-FDR | 多重检验(几十~百万个),要控制"发现集错误比例" |
| 贝叶斯层次模型/MCMC | 有分层结构/小样本借力/要后验分布本身 |
| GLM(广义线性模型) | 响应非正态(计数/比例/存活)的回归 |
| CUPED/方差缩减 | A/B 实验要提功效省流量 |
| ARMA/状态空间 | 时序预测与监测 |
| Conformal | 黑箱预测要"分布无关"的覆盖率保证 |

## ④ 常见误区与禁忌

- **p 值不是"H₀ 为真的概率"**——它是频率语义,单次结论无"对错概率"
- **显著≠重要**:效应量+区间才是完整答案;p 值随 n 涨,含义不变
- **相关≠因果**:无随机化/无 do- 演算,回归系数只是共变
- **多重比较必校正**:不校正=假发现工厂(实测见 `experiments/00_fdr.py`)
- **iid 是假设不是事实**:时序/空间/网络数据要先处理相关性再套公式
- **bootstrap 不是万能**:非光滑统计量、强依赖数据会失效
- **对同一份数据选模型+做推断**=选择性偏差,要选择性推断修正或留出验证
