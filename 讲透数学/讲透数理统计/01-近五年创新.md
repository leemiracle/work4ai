## 一、总览:一张动能表

| 动能 | 一句话 | 为什么是现在 |
|------|--------|-------------|
| **Conformal prediction 走向生产** | 给任何黑箱预测配上"分布无关的置信区间" | 保险/医疗/LLM 评测需要"有保证的不确定性",而深度模型没法经典推断 |
| **个体化推断兴起** | 平均处理效应→"我这个人"的处理效应 | 精准医疗/个性化推荐要的是 ICE(个体因果效应),不是 ATE |
| **UQ 工程化** | 不确定性量化从论文变成库 | PyTorch 生态出现 Torch-Uncertainty 一类标准件,统计被"编译"进工具链 |
| **选择性推断成熟** | "用数据选模型+用同一数据做推断"的自动校正 | data snooping 从禁忌变成可计算问题 |
| **高维自适应检验** | minimax deficiency 视角重写检验理论 | 传统 χ²/似然比在高维渐近失真 |

## 二、四条战线细看

### 战线 1:Conformal Prediction——分布无关的置信(2015 苗头,2021-2026 爆发)

**直觉图像**:你有一个任意黑箱预测器(哪怕是大模型),conformal 只做一件事——
用一小撮"校准数据"给预测套一个壳:保证在交换性假设下,**真值落进壳里的概率 ≥ 95%**,
不管黑箱内部是什么妖魔鬼怪。

**为什么重要**:经典置信区间依赖模型正确;conformal 只依赖数据可交换——这是
"模型无关 guarantee"在工业界第一次大规模落地(2021-2026 从论文走进 scikit-learn
conformal 生态、保险定价、LLM 事实性检测)。它把统计推断的"保险"属性从参数模型中解放出来。

**未竟**:交换性在分布漂移下失效——online conformal 是当前热战区。

### 战线 2:个体化分位数处理效应的 minimax 推断(检索校准落点)

**[2025·arXiv 2503.18523]《Minimax Rate-Optimal Inference for Individualized Quantile Treatment Effects》**
——为"个体化分位数处理效应"(QTE)建立 minimax 最优率:置信区间的期望长度与检测边界
同时达到理论下界。为什么重要:个体化推断是"平均效应时代"的接替者,
而 minimax 率=给这类推断方法颁发了"不可改进"证书——方法论的封顶之作。

**✨ 美之时刻 3(必然)**:minimax 的哲学之美——一个方法在最坏情况下的表现,
恰好等于任何方法能达到的最好水平。攻击(下界)与防守(上界)在同一处会师。
怎么亲历:读 Cramér–Rao 下界的一维版本(03 章),体会"不可再好"如何被证明。

### 战线 3:UQ 的工程化——统计变成库(检索校准落点)

**[2025·NeurIPS] Torch-Uncertainty**——深度学习不确定性量化的标准化库
(集成/MC-Dropout/校准损失一站式)。为什么重要:它标志着统计理论(校准/锐度分解、
ECE 指标)被"编译"为可 pip install 的工程件——上一代教科书里的大样本理论,
这一代以 API 形式存活。对讲透范式的启示:统计的 04 章(转代码)正在从"实验"变成"出厂配置"。

### 战线 4:选择性推断与多重检验的深化

家族实验 `experiments/00_fdr.py` 演示的 BH-FDR(1995)在 2021-2026 迎来两件新事:
①**选择性推断**("检完再估计"的修正置信区间,数据窥探的自动补偿)从方法论文
走向临床试验/组学标准流程;②高维情形的**自适应检验**(以 minimax deficiency 为标尺,
检索方向锚:陈松蹊组工作)重写了"什么检验在什么维度下还合法"。

## 三、近五年大事年表(压缩版)

- 2021-2022 Conformal 进入工业部署(保险/风控/AIOps);batch→adaptive 变体涌现
- 2022 Efron 获首届国际统计奖级别的终身荣誉周期,bootstrap 哲学被全面回顾
- 2023 LLM 评测危机→非参数校准方法(statistical guarantee for model eval)需求井喷
- 2024 高维检验的 deficiency 理论成型;FDR 控制成为组学与 A/B 平台默认配置
- 2025 个体化 QTE 的 minimax 率(arXiv 2503.18523);Torch-Uncertainty @ NeurIPS
- 2026 方向:online/漂移下的 conformal、因果+UQ 融合、LLM-as-judge 的统计校正

## 四、这些动向对"学统计"意味着什么

1. **推断的语法没变,词表在扩**:似然/充分性/Cramér–Rao 仍是地基(03 章),
   但"分布无关 guarantee"(conformal)和"决策化"(判决理论)是新的两个极点
2. **计算即统计**:bootstrap→MCMC→conformal 校准,三代方法共同的姿势是
   "与其推公式,不如让数据自己跑出来"——统计与仿真从未如此亲密
3. **个体化是共同靶心**:平均效应→个体效应,贯穿处理效应/贝叶斯层次模型/学习理论
4. **可复现性成为统计的第一公民**:多重检验校正、选择性推断、预注册——
   2010s 的"复现危机"把"统计诚信"本身变成了研究对象

📖 **故事框**:1995 年 Benjamini–Hochberg 的 FDR 论文最初被普遍冷落
("控制'错误发现比例'?为什么要放弃家族错误率 FWER?");三十年后它是
全基因组关联研究(GWAS)与 A/B 测试平台的默认法律。统计观念的胜利常常滞后方法三十年。

## 📌 收束与认知升维

**这章给了你什么新眼睛**:
- **Guarantee 眼**:读任何新方法先问"它的保证是什么假设换来的"(分布无关?渐近?稀疏?)
- **工程化眼**:统计理论正在变成 API 默认值——懂原理的人才改得动默认值
- **个体化眼**:平均数时代的统计结论,在"对你"这件事上越来越不够用。
