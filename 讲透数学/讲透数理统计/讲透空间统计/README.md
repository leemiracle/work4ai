# 讲透空间统计 · 带坐标的数据

> **定位句:这支负责"近处的事物更相似"——把空间相关性变成信息而不是麻烦。**
> GB/T 11067 三级「空间统计」

## 诞生

- 1951 Krige(南非矿业工程师)金矿品位的经验插值;1960s Matheron 把它数学化
  成"地质统计学"(regionalized variable + kriging),命名致敬 Krige
- 1952 Moran 指数(空间自相关);1970s Ripley K 函数(点格局);
- 1990s-2000s 空间流行病学/遥感/气候科学把这门学科推向数据科学前沿,
  Tobias 增长与"地理加权回归"扩展了非平稳版图

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 变差函数建模与克里金 BLUE(最优线性无偏插值=广义最小二乘的几何);空间点过程(Poisson/Cox/Thomas 过程);Moran/K 函数检验 |
| ✅ 已解决 | 病面模型(disease mapping)与 CAR 随机效应(贝叶斯空间模型的工业级应用) |
| 🔄 进行中 | 大规模空间数据(低秩近似/最近邻高斯过程);时空联合建模;空间+conformal |
| ❓ 未解决 | 空间相关下的有效样本量理论(地理数据的"信息折扣"定价);fill-in 采样设计最优性 |

**最美事实(一句)**:克里金=在空间上解一个广义最小二乘——"最优预测权重只由
你建模的变差函数决定",一块矿石品位预测,内里是 Hilbert 空间投影。

## 假设与依赖

- 平稳性/各向同性假设(变差函数有意义的前提);空间相关违背 iid——
  本支的全部技术=给"相关结构"明码标价再利用
- 依赖:[讲透多元分析](../讲透多元分析/)(协方差结构);[讲透贝叶斯统计](../讲透贝叶斯统计/)(CAR/层次空间模型)
