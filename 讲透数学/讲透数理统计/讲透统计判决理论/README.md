# 讲透统计判决理论 · 统计的博弈论化

> **定位句:这支负责"给统计行动标价"——估计、检验、区间在损失函数下统一成决策问题。**
> GB/T 11067 三级「统计判决理论」

## 诞生

- 1939 Wald(从数学逃难者到哥伦比亚大学教授)把统计问题写成三元组 (Θ,A,L);
  1945-1950 完备类定理、minimax 与 Bayes 解的关系、admissibility 理论;
  1950《Statistical Decision Functions》出版,两年后 Wald 空难早逝——
  这门分支几乎是一个人写完的
- 1961 Stein 悖论/James–Stein 估计:三个以上均值的 MLE 竟然是 inadmissible——判决理论的惊世第一枪

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | 完备类定理(Bayes 解的极限构成本质完备类);Rao–Blackwell+判决框架=UMVU;minimax 与 Bayes 的对偶 |
| ✅ 已解决 | Stein 效应(收缩估计优于 MLE);admissibility 判据(Blyth 方法/极小极大) |
| 🔄 进行中 | 个性化决策(2021-2026 个体化处理效应的 minimax 率=本支的最新回声,见家族 01 章);联邦学习的分布式决策 |
| ❓ 未解决 | 非渐近 admissibility 的完整刻画;计算约束下的最优决策(与在线学习边界的模糊) |

**最美事实(一句)**:James–Stein 估计——估计三个以上无关正态均值时,
"把每个估计往总均值方向压一点"严格优于各自单独的样本均值:
贪心的频率派最优在多维居然可击败,统计直觉的三观修正器。

## 假设与依赖

- 损失函数是显式输入(选损失=选世界观);风险=对 θ 与数据双重平均
- 依赖:博弈论(minimax 定理同源);[讲透统计推断](../讲透统计推断/)(被判决化的对象)
