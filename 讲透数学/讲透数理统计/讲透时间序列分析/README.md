# 讲透时间序列分析 · 按时间排队的数据

> **定位句:这支负责"今天与昨天有关时的统计"——把相关性当成结构而不是噪声。**
> GB/T 11067 三级「时间序列分析」

## 诞生

- 1927 Yule 提出 AR(自回归)解释太阳黑子;1931 Walker ARMA;
- 1938 Wold 分解定理(一切平稳序列=线性确定性+线性创新——理论的定音锤);
- 1970 Box–Jenkins《Time Series Analysis》把 ARIMA 变成工程流水线;
  同期 Kalman(1960)状态空间把时序送进阿波罗导航舱
- 1982 Engle ARCH/1986 Bollerslev GARCH——波动率建模(金融的百年刚需)

## 核心问题

| 状态 | 问题 |
|------|------|
| ✅ 已解决 | Wold 分解;平稳性检验(Dickey–Fuller 谱系);ARMA 定阶(信息准则/ACF-PACF);Kalman 滤波最优性 |
| ✅ 已解决 | 谱估计(周期图/窗);GARCH 族波动率;SARIMA 季节结构 |
| 🔄 进行中 | 高频/不规则采样;时序的深度模型与统计保证的接驳;预测区间(conformal 时序版) |
| ❓ 未解决 | 非平稳的统一理论(结构突变 vs 单位根之辨);长记忆参数的稳健推断 |

**最美事实(一句)**:Kalman 滤波——一阶马尔可夫+高斯假设下,递推更新即全局最优,
复杂度不随时间增长:五十年后它仍在你的手机 GPS 里每秒运转。

## 假设与依赖

- 平稳性(严/宽)是经典方法的入场券;非平稳须差分/分解(趋势-季节-残差)
- 依赖:概率论(马尔可夫链/谱理论);[讲透相关回归分析](../讲透相关回归分析/)(自回归=带滞后项的回归)
