# 讲透泛代数 · 一切代数结构的"元结构":同余、簇与 CSP 的复杂度判官

> **定位句**:这支负责"研究代数结构这门学问本身"——群/环/格各自的定理,哪些其实是"任何运算+任何公理"的普遍规律?泛代数给出元层答案,并意外成为约束满足问题(CSP)复杂度分类的判官。
> GB/T 11021 三级「泛代数理论」| 家族:[讲透代数学](../README.md)

## 诞生
1935 Birkhoff《On the structure of abstract algebras》(术语泛代数来自 Whitehead 1898 的未竟尝试);1950s-60s Tarski学派(簇、超积);2017 Bulatov 与 Zhuk 独立证明 CSP 二分定理(有限域 CSP 要么 P 要么 NP-完全)——泛代数 80 年功底一击入主流。

## 核心问题
**已解决**:同余格刻画(HSP 定理:Birkhoff,一个簇=同态像×子代数×直积闭包);CSP 二分定理(2017,两大独立证明,依赖泛代数不变量:循环条件/潺溶代数)。
**未解决/活跃**:自然语言的簇理论;与范畴论/模型论的继续合流(本质上"泛代数+关系"=模型论的一部分)。

## 这支最美的一个事实
**HSP 定理**:一个代数类是公理可定义的(簇)⟺ 对同态像(H)、子代数(S)、直积(P)封闭。"能被方程刻画"被"封闭性"精确刻画——**元数学自己的结构定理**,证明却是初等的五页。

## 假设与依赖
只谈"泛代数"(带运算的结构)不谈关系(那是模型论);有限 vs 无限是 CSP 定理的边界(二分定理在有限域上成立,无限 CSP 尚有中间带)。依赖全部兄弟支做"素材库"。

## 教材锚
Burris & Sankappanavar《A Course in Universal Algebra》(免费经典)/ Bergman《Universal Algebra》(现代)/ CSP 侧:Bulatov–Jeavons–Krokhin 综述。
