# 代数学思维技能卡(讲透代数学 · GB/T 11021)

> 用法:当问题出现下列触发特征,先读本卡校准思维,再进入 [README](README.md) 与对应支。

## 1. 何时用此分支(触发特征)

- 出现**对称**("这个配置为什么对称/旋转后不变")→ 群
- 要判断**方程能不能解**(根式解/尺规作图/可解性)→ 域论/伽罗瓦
- 对象**可加可乘**(多项式、矩阵、函数、变换)且关心运算律 → 环/模
- 要问"**有哪些种**/怎么分类/不变量是什么" → 分类定理(03 章)
- 系统间要**保结构地翻译**(同构/同态/表示)→ 结构主义方法
- 需要**精确符号解**而非数值近似(消元/理想成员) → 04 章 Groebner 走廊
- 密码/纠错/量子线路需要**有限域或格**上的硬结构 → 格论/代数编码

## 2. 核心思维模式(代数眼)

1. **结构优先**:丢掉元素"是什么",只留运算律——同构的东西是同一个东西
2. **找对称=找群**:任何"保持某性质的变化全体"是一个群,对称群的结构决定问题的命运(可解性/守恒律/选择规则)
3. **分类三问**:同构类有多少?不变量是什么?刚性从哪来(单性/双线性型/有限对偶)?
4. **构造四工艺**:自由对象(从零造)→商(从多造少)→局部化/完备化(从粗造细)→张量积(从二造一);一切复杂代数对象是四工艺的复合
5. **重写即证明**:代数证明=合法重写序列;先问重写系统收敛吗(=问题可判定吗),再动笔

## 3. 工具箱(定理 + 何时用)

| 工具 | 何时用 |
|------|-------|
| 同态基本定理($G/\ker\cong\mathrm{im}$) | 见"保持结构的映射"就用——一切商结构的合法性证书 |
| Sylow 定理 | 有限群计数/存在性问题:素数幂阶子群必有 |
| 伽罗瓦对应 | 中间域 ↔ 子群反序一一对应;判定可解性/尺规可能性 |
| PID 上有限生成模结构定理 | 把 Abelian 群/Jordan 标准型/整数矩阵一次讲完的母定理 |
| Hilbert 基定理 + Noether 条件 | 确认"有限步内结束"(升链稳定)——归纳法合法性 |
| Groebner 基 | 多项式方程组的结构 X 光:消元/维数/理想成员(双指数红线,变量多慎用) |
| 张量积万有性质 | 造"积型"对象/把双线性问题线性化 |
| Yoneda 引理 | "对象=它与外界的一切关系"——范畴接口的总开关 |
| LLL 格基约简 | 格上最近向量问题的多项式时间近似(密码攻防) |

## 4. 常见误区与禁忌

- ❌ 把"群"默认为 Abel 群——顺序敏感是非交换世界的第一定律;非交换处通用算法往往不存在(字问题不可判定)
- ❌ 结构存在 ≠ 可计算:有基(选择公理)≠能写出基;有分类 ≠ 有算法检索
- ❌ 分类定理滥用:CFSG/ADE 只覆盖**给足公理**的类;一般群不可分类,别硬找"所有的群"
- ❌ Groebner 当万能消元器:最坏双指数;高变量时先换线性化/数值混合
- ❌ "同构即相等"到模空间失灵:带自同构的族有 twist,分类问题会升级成几何问题
- ❌ 张量积当笛卡尔积:$\dim(V\otimes W)=\dim V\cdot\dim W$(相乘不是相加)

## 5. 与相邻分支的判别 + 组合接口

| 症状像代数但其实是 | 判别 |
|--------------------|------|
| 关心"多大/多近/误差" | 分析(代数无距离语言) |
| 关心"连续变形下不变" | 拓扑(代数无连续;李群=两者混血) |
| 要解的是具体数值 | 数值计算(〔../讲透数值线代〕);代数管结构不管浮点 |
| 要"族"随参数连续变化 | 代数几何(单对象语言谈不了族) |

| 组合接口 | 产物 |
|---------|------|
| 代数 × 数论 | 代数数论/类域论/朗兰兹(〔讲透数论·代数数论支〕) |
| 代数 × 几何 | 代数几何/李变换群(Klein 纲领) |
| 代数 × 拓扑 | 同调代数/代数拓扑(同调=可计算的不变量) |
| 代数 × 逻辑 | 模型论(造非标准对象的机床)/泛代数(CSP 复杂度分类) |
| 代数 × 计算 | Groebner/CAS/格密码/量子线路表示 |
