# 讲透同调代数 · 「差多少才算零」的度量衡:正合列、Ext 与 Tor

> **定位句**:这支负责给"不严格相等的东西"记账——一个映射不是满射,差多少?一个核不等于像,漏了多少?同调代数把这些"差"变成可计算、可比较的代数对象,是当代数学的通用度量衡。
> GB/T 11021 三级「同调代数」| 家族:[讲透代数学](../README.md)

## 诞生
1890s-1920s Poincaré(拓扑同调)→1940s Eilenberg–Mac Lane(范畴语言+群上同调)→1950s Cartan–Eilenberg《Homological Algebra》(1956,学科命名)与 Grothendieck(Tohoku,1957:Abelian 范畴+谱序列统一)。驱动问题:拓扑不变量的代数化;"非正合"能否系统测量。

## 核心问题
**已解决**:导出函子(Ext/Tor)理论;谱序列(Grothendieck 谱序列是"计算器");Abelian 范畴公理化;同调维数理论。
**未解决/活跃**:导出范畴/稳定 ∞-范畴的重铸(见家族 01 章);各领域"上同调理论"的统一(Grothendieck 的 t-结构观);prismatic cohomology 的几何化。

## 这支最美的一个事实
**蛇引理**:一条"之"字穿过后,ker/im 自动连成正合列——**在任意 Abelian 范畴成立,证明纯图表追逐**。为什么美:**必然**——不依赖任何具体对象,只依赖"交换图表"这一接口;它是电影《It's My Turn》(1980)开场的那个证明(流行文化里唯一出镜的引理)。

## 假设与依赖
Abelian 范畴(加法+核像存在)是底线;正合性假设换谱序列的收敛(不完全正合时谱序列可能不坍缩);计算复杂度警告:谱序列"手算友好、机算昂贵"(家族 [04 章](../04-代数学转代码.md) 红线)。依赖 [讲透模论](../讲透模论/)+[范畴论](../讲透范畴论/)。

## 教材锚
Weibel《An Introduction to Homological Algebra》(标准)/ Rotman(友好)/ Gelfand–Manin(方法本位);薄入门:任一本 Abelian 范畴讲义前置 Cartan–Eilenberg 前两章。
