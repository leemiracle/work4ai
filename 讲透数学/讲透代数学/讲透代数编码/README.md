# 讲透代数编码 · 有限代数工程化:纠错码、RS 码与可靠性数学

> **定位句**:这支负责"用代数结构对抗噪声"——把信息嵌进有限域的代数结构,让错误可检、可纠、可证极限;QR 码、深空通信、RAID、5G 控制信道,底层全是它。
> GB/T 11021 三级「代数编码理论」| 家族:[讲透代数学](../README.md)

## 诞生
1948 Shannon《通信的数学理论》(编码理论的存在性宪法:容量);1950 Hamming 码(第一个实用码,纠 1 位);1960 Bose–Chaudhuri–Hocquenghem(BCH)与 Reed–Solomon 码(多项式求值造码——纯代数首度工程落地);1980s Goppa(代数几何码);1993 Turbo/1995 LDPC(逼近 Shannon 极限);2021-2023 LTC 大突破(见下)。

## 核心问题
**已解决**:Hamming 界/Singleton 界(码的物理极限);RS 码最优(MDS);代数几何码超 GV 界(Tsfasman–Vlăduţ–Zink 1982);列表译码(Guruswami–Sudan 1999 代数算法)。
**未解决/活跃**:**locally testable codes 的 $c^3$ 构造**(2021-2023,Dinur 等:常数率+常数距离+常数查询——布尔函数与扩张图的合流,见家族 01 章);量子 LDPC 的渐近好码(2021-2022, Panteleev–Kalachev:升纠缠码面);码与复杂度(PPC 猜想)。

## 这支最美的一个事实
**RS 码=在曲线上求值**:信息=多项式系数,码字=多项式在多点求值——"任意 k 个点定 k-1 次多项式"(拉格朗日插值)直接变成"任意 e 个错误可定位纠错"。一条中学定理,撑起从 CD 到深空探测的一切纠错——**代数冗余=物理保险**的最纯演示。

## 假设与依赖
底域=有限域 $\mathbb{F}_{2^m}$([讲透域论](../讲透域论/) 的工程分公司);随机噪声模型(Shannon 假设)换容量定理;对抗性错误模型换列表译码视角(复杂度上升)。依赖 [线性代数](../讲透线性代数/)(生成/校验矩阵)。
