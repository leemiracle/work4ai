# 讲透微分代数 · 带导子的环:微分方程的伽罗瓦理论

> **定位句**:这支负责"把求导变成代数运算"——环上配一个导子 δ(满足 Leibniz 律),微分方程变成方程论,可解性有了伽罗瓦式的判决书。
> GB/T 11021 三级「微分代数」| 家族:[讲透代数学](../README.md)

## 诞生
Ritt 1950《Differential Algebra》(学科命名;动机:微分方程解的"解析不可通约");Kolchin 1973《Differential Algebra and Algebraic Groups》(集大成);Picard–Vessiot 理论(19 世纪末的微分版伽罗瓦思想被 Ritt/Kolchin 严格化)。

## 核心问题
**已解决**:Picard–Vessiot 理论——线性 ODE 的解空间有伽罗瓦群(线性代数群),"LIouvillE 可解 ⟺ 群可解"(伽罗瓦判决书的 ODE 版);Ritt–Noether 定理(DP 上的准素分解);微分 Galois 对应。
**未解决/活跃**:非线性微分方程的伽罗瓦理论(Malgrange 的 Lie 伪群版本,严格化仍在推进);差分代数(δ→移位算子)与模型论的深对话(见家族 01 章:ACFA 的模型论繁荣)。

## 这支最美的一个事实
**不可积性的代数判决**:Liouville 定理——$\int e^{-x^2}dx$ 无初等原函数,不是"技巧不够",而是其微分伽罗瓦群(加法群上的伸缩)不满足可解性结构。**"积不出来"升格为定理**——中学时代每个"积不出来"的挫败,在这里得到结构性正名。

## 假设与依赖
导子的 Leibniz 律是公理核心(一切求导性质的种子);常域假设(常数域代数闭)换 Picard–Vessiot 扩张的良定;依赖 [讲透环论](../讲透环论/)+[讲透李群](../讲透李群/)(伽罗瓦群=线性代数群)。

## 教材锚
Ritt《Differential Algebra》(原典)/ Kolchin(标准)/ van der Put–Singer《Galois Theory of Linear Differential Equations》(现代+算法)/ Singer 讲义(免费)。
