# 讲透线性代数 · 万物第一结构:向量空间与线性映射

> **定位句**:这支负责"能加能数乘的一切系统"——从 n 元方程组到量子态空间到深度学习的权重,线性结构是全宇宙被消费最多的一种代数结构。
> GB/T 11021 三级「线性代数」| 家族:[讲透代数学](../README.md)
> **消歧**:本支=**本体**(空间/映射/标准形/张量);计算面(浮点/SVD/条件数)在 [`../../讲透数值线代/`](../../讲透数值线代/)。

## 诞生
古巴比伦泥板已有二元方程消元(约 BC1800);中国《九章算术》方程术=高斯消元(公元 1 世纪);现代公理化:Peano(1888)与 20 世纪初(Hamilton/Cayley/Sylvester 的矩阵论在前)。驱动问题:解线性方程组→"解的结构由什么决定"→秩。

## 核心问题
**已解决**:方程组解结构(秩定理);特征值/对角化(Jordan 标准形 1870);内积空间谱理论;张量积运算律。
**未解决/延伸**:张量秩计算(NP-hard;矩阵乘法指数 $\omega$,当前 <2.373——代数复杂度圣杯);无限维接泛函分析(〔`../../讲透分析/`](../../讲透分析/)·泛函分析)。

## 这支最美的一个事实
**秩-零化度定理** $\dim V=\mathrm{rank}+\mathrm{nullity}$:一条维数守恒律,一行的证明,撑起此后一切结构定理(它正是模论中结构定理的胚胎)。

## 假设与依赖
底域任意(实/复/有限域皆可);核心结论对任意域成立——这正是"抽象"的红利。有限维是分水岭:有限维一切良定,无限维让位给泛函分析。

## 教材锚
Axler《Linear Algebra Done Right》(算子本位)/ Strang《Introduction to Linear Algebra》(矩阵本位)/ Artin《Algebra》前半 / Roman《Advanced Linear Algebra》(张量与典范形)。
