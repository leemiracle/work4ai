# 讲透李群 · 连续对称性的家园:旋转、守恒与物理定律的形状

> **定位句**:这支负责"能连续转动的对称"——旋转群、洛伦兹群、规范群;凡是" smoothly 变形的对称全体"都是李群,物理定律的形状由它们决定。
> GB/T 11021 三级「李群」| 家族:[讲透代数学](../README.md)

## 诞生
1870s Sophus Lie:把 Galois 的思想搬到微分方程——方程的连续对称群决定其可解性(替代"根式解"的"群作用可解");1888 Killing 预分类、1894 Cartan 严格完成半单李代数分类;1927 Weyl(量子力学中的群论)把它送进物理。

## 核心问题
**已解决**:半单李群分类(Killing–Cartan);Peter–Weyl 定理(紧群=完整正交系);表示的最高权分类(1930s Weyl)。
**未解决**:一般李群的表示论(非半单/非紧——Harish-Chandra 纲领延续);朗兰兹纲领的实/李群侧(几何 Langlands 的姊妹篇,见家族 [01 章](../01-近五年创新.md))。

## 这支最美的一个事实
**Klein–Cartan 纲领**:一种几何=一个变换群+其不变量。欧氏几何=刚体群,射影=射影群,相对论时空=Lorentz 群——"空间"这个词被李群彻底重新定义。

## 假设与依赖
依赖微积分(〔`../../讲透分析/`](../../讲透分析/)·数学分析)与拓扑(流形结构);"群×流形"双重身份,光滑相容性是公理核心。紧致性假设换来表示论的完整(非紧则病态)。

## 教材锚
Hall《Lie Groups, Lie Algebras, and Representations》(最友好)/ Rossmann / Kirillov Jr. / Fulton & Harris(表示论本位)。
