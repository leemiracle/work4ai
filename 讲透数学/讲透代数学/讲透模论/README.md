# 讲透模论 · 环作用在群上:表示论的语言、结构定理的发动机

> **定位句**:这支负责"让环去作用"——Abel 群配上环的乘法就是模;向量空间是"域上的模",数论里的理想、拓扑里的上同调群、表示论里的一切,全是模。
> GB/T 11021 三级「模论」| 家族:[讲透代数学](../README.md)

## 诞生
1890s Dedekind/Weber(理想作为模的雏形);1920s Noether(模的抽象化+升链);1929 Emmy Noether 把表示论统一为模论($KG$-模=群表示)。驱动问题:线性代数(域)换成任意环(整数、群环、多项式)后,结构定理还能剩多少?

## 核心问题
**已解决**:主理想整环(PID)上有限生成模结构定理——一网打尽 有限生成 Abel 群分类+Jordan 标准型+有限生成 Abel 群的自同态;半单模 Wedderburn–Artin;injective/projective 分解。
**未解决/活跃**:一般环上模的表示有限性(Auslander–Reiten 理论及其边界);矩阵分解(Matrix Factorizations)与镜像对称(见家族 01 章副线)。

## 这支最美的一个事实
**结构定理的"一箭三雕"**:同一个定理,取 $R=\mathbb{Z}$ 得 Abel 群分类,取 $R=k[x]$ 得 Jordan 标准形,取 $R=\mathbb{Z}[G]$ 得有限群表示——**换一个环,换一个宇宙,定理纹丝不动**。这是"结构主义红利"的最纯样本。

## 假设与依赖
环的条件直接决定模的命:半单环上一切模可拆(天堂);Noether+Artin 环有长度理论;一般环上模可以无法无天。依赖 [讲透环论](../讲透环论/)+[线性代数](../讲透线性代数/)。

## 教材锚
Anderson & Fuller《Rings and Categories of Modules》/ Rotman《An Introduction to Homological Algebra》(模论→同调的桥)/ Aluffi《Algebra: Chapter 0》(范畴化视角)。
