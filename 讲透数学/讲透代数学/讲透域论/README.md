# 讲透域论 · 数系的解剖学:扩域、尺规与伽罗瓦的舞台

> **定位句**:这支负责"把数系当洋葱剥"——从一个域出发添加元素得到扩张,扩张的层层结构裁决了"哪些方程可解、哪些作图可能"。
> GB/T 11021 三级「域论」| 家族:[讲透代数学](../README.md)

## 诞生
1832 Galois(根的对称→群对应域);1871 Dedekind(域的抽象定义/理想);1910 Steinitz《域的代数理论》(完全分类:素域+超越基)。驱动问题:五次方程为什么无根式解;两千年的希腊尺规三问。

## 核心问题
**已解决**:尺规三不可能(倍积/三等分/化圆为方,$\pi$ 超越性 Lindemann 1882);有限域完全分类(Galois 域 $\mathbb{F}_{p^n}$ 唯一);Steinitz 代数闭包理论;类域论(交换扩张的完全描述,Artin 1927 互反律)。
**未解决**:**逆伽罗瓦问题**($\mathbb{Q}$ 上每个有限群是否实现为伽罗瓦群——可解群已知,一般开放);非交换类域论=朗兰兹纲领(家族 [01 章](../01-近五年创新.md))。

## 这支最美的一个事实
**伽罗瓦对应**:中间域 ↔ 子群,反序双射。两千年的"能不能",塌缩成一张群格图——00 章开篇、实验 `00_galois_s3.py` 全程实拍。

## 假设与依赖
依赖群论(〔`../../讲透群论/`](../../讲透群论/))与 [线性代数](../讲透线性代数/)(扩张=向量空间);代数闭包存在性依赖选择公理(03 章 B/C 档分界样本)。特征 p 与特征 0 是两个平行宇宙(有限域/数域)。

## 教材锚
Artin《Algebra》Galois 理论章 / Dummit & Foote / Milne《Fields and Galois Theory》(免费讲义)/ Cox《Galois Theory》(含作图史)。
