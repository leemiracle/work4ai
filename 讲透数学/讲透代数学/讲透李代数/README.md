# 讲透李代数 · 李群的线性化切影:括号积 [x,y] 的世界

> **定位句**:这支负责"连续对称的微分学"——李群太大看不动,看它在单位元处的切空间:一个带括号积的向量空间,所有非线性对称被压成双线性运算。
> GB/T 11021 三级「李代数」| 家族:[讲透代数学](../README.md)

## 诞生
1870s Lie(连续群→无穷小生成元);1888-1894 Killing/Cartan:分类复半单李代数(根系/Dynkin 图);1930s Weyl/Chevalley 抽象化。驱动问题:李群的局部结构能否完全线性化?答案是 Lie 三定理(几乎能)。

## 核心问题
**已解决**:复半单分类(Cartan 子代数→根系→Dynkin 图);Levi 分解(任意李代数=可解⊕半单);Kac 的特征标公式;顶点算子代数与 Monster 月光(Borcherds 1992,1998 Fields)。
**未解决**:一般域上的分类;模李代数(特征 p)结构理论;affine 李代数表示的组合精细结构(catalytic combinatorics 交界)。

## 这支最美的一个事实
**单李代数=字母表**:无限族 $A_n,B_n,C_n,D_n$ 是"常见字母",例外 $E_6,E_7,E_8,F_4,G_2$ 是"神造字母"——此后物理(规范场)与数学(奇异点)反复在同一个五例外集上撞车,仿佛宇宙只有这一套积木。

## 假设与依赖
括号的双线性+Jacobi 恒等式是全部公理(反交换+Jacobi);依赖 [线性代数](../讲透线性代数/)(ad 算子/Killing 型)。特征 0 假设换来整套分类理论(特征 p 崩塌成 mod 李代数独立王国)。

## 教材锚
Humphreys《Introduction to Lie Algebras and Representation Theory》(标准)/ Erdmann & Wildon(本科友好)/ Kac《Infinite Dimensional Lie Algebras》(走向 Kac-Moody)。
