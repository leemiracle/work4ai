# 讲透代数学 · 家族总纲(结构与对称的语法:GB/T 11021 十四支穷尽)

> **本质一句话**:代数学=**结构与对称的语法**——不问"这个数是几",问"这些对象放在一起服从什么运算规律"。
> 一个方程解不出来?看它的对称群。两个系统"本质一样"?看有没有保结构的映射。代数眼=**看结构,不看个体**。
>
