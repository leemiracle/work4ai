# 03 · 可构造与结构：显式解的孤岛、离散化的陆地、能量的骨架

> **本章回答五问之四（本支：讲透偏微分方程）。** 本支的可构造图景是一张
> **群岛地图**：显式解是几座孤岛（热核/球平均/行波），离散化是连片的陆地
> （FDM/FEM 把任何适定问题变成可算的有限维系统），而最深的存在性证明
> 恰恰**不构造**（紧性方法只宣布"有"）。结构的一侧靠三条骨架：
> 能量守恒、对称性、极值原理。

---

## 一、可构造：三级构造力（显式 → 算法 → 存在性非构造）

### 第一级：显式解孤岛（可列清单）

| 方程 | 显式解 | 构造手法 |
|------|--------|---------|
| 热方程 $\mathbb{R}^n$ | $u = G_t * u_0$，热核 $G_t = (4\pi t)^{-n/2}e^{-|x|^2/4t}$ | 卷积 |
| 波动 1D | d'Alembert：$u = \frac{1}{2}[\phi(x+t)+\phi(x-t)] + \frac{1}{2}\int_{x-t}^{x+t}\psi$ | 特征线叠加 |
| 波动 3D | 球平均（Kirchhoff 公式） | 球面对称化 |
| Laplace 圆盘 | Poisson 积分公式 | 边值的核积分 |
| 守恒律 | 行波/自相似解 | ODE 约化 |

这批孤岛是**全部直觉的来源**（传播速度、衰减率、极值原理都先在孤岛上看见），
但测度为零——一般初值/区域/系数立刻出局。

> 反直觉发现 ①：**最可构造的对象恰是"最不可构造问题"的钥匙**——
> Chen–Hou 爆破证明（[01 章](01-近五年创新.md)方向一）构造的正是
> **自相似解**（孤岛居民），用它的存在证明一般解的奇性。
> 孤岛不是陆地的对立面，是登陆的跳板。

### 第二级：算法构造陆地（离散化=可执行的构造）

任何适定线性问题都可**有限维化**后求解（04 章主场）：FDM 造出
$u^{n+1} = A u^n$ 的迭代，FEM 造出 $K\vec{u} = \vec{f}$ 的线代系统。
关键：离散化的**合法性由本支结构定理背书**——Lax–Richtmyer 定理：
**相容 + 稳定 ⟹ 收敛**（线性问题的等价定理）。
"你算的收敛于真解"不是祈祷，是定理（但仅限线性适定问题，见不足层）。

### 第三级：存在性非构造（"有"但不"给"）

本支存在性证明的两大引擎都是**非构造**的：

- **紧性方法**：极小化序列 ⟹ 弱收敛子列（Rellich 紧嵌入）⟹ 下半连续性
  保住极小性 ⟹ 极小元存在。哪个子列？极限长什么样？**不告诉你**
  （[../讲透变分分析/](../讲透变分分析/)直接法的 PDE 兑现）
- **不动点方法**：把 PDE 改写为 $u = \Phi(u)$，用 Schauder/Banach 不动点
  宣布解存在。Banach（压缩）情形可以迭代构造；Schauder（紧凸）情形
  存在性来自 Brouwer 拓扑，**无算法**

三级的兑换关系：

```
显式解   ——→ 给公式（分析操作：卷积/积分核）
算法构造 ——→ 给代码（数值操作：迭代/线代）
存在性   ——→ 给保证（逻辑操作：紧性/拓扑）
            ——后者是前两者的"存在性许可证"
```

**为什么本支容忍非构造**：因为先验估计（02 章）已经把解"框定"得足够紧
——范数、光滑度、奇点集全有界。知道解被框在哪个小笼子里，
即使拿不出它，工程上也够用（数值把它逼出来）。

## 二、结构：三条骨架（能量、对称、极值）

### 骨架一：能量结构（守恒/耗散二象）

- 守恒系（波动/Schrödinger/Hamiltonian PDE）：$E = \frac{1}{2}\int(|u_t|^2+|\nabla u|^2)$
  沿解**不变**——能量是解的"不变量行李"，决定长时行为（周期/散射/爆破的判据）
- 耗散系（热/阻尼波动）：$E$ 单调递减——解被吸入全局吸引子
  （[../讲透动力系统/](../讲透动力系统/)的接口：吸引子的维数估计）

### 骨架二：对称性（Noether：每份对称兑换一条守恒律）

方程的 Lie 群对称（平移/旋转/伸缩/Gauge）经 Noether 定理兑换为守恒量。
**可构造性红利**：对称性把 PDE 降维——轴对称假设把 3D 压成 1D
（Euler 爆破的可行性来源）；自相似对称把 PDE 变 ODE（爆破剖面方程）；
行波对称把演化问题变边值问题。**找解先找对称**是本支的构造心法。

### 骨架三：极值原理（结构刚性的极致）

椭圆/抛物方程的解**不能在内部取严格最大**（弱极值原理）；
强形式：非常数调和函数在内部连局部最大都取不到。

> 反直觉发现 ②：极值原理是**刚性定理**——边界数据完全钳制内部行为，
   "一点的最大值都不许私自出现"。它的工程化身是**比较原理**
   （造上下解夹逼真解——又一条构造路径：上解+下解 ⟹ 解被夹出），
   它的概率化身是**布朗运动表示**（$u(x) = \mathbb{E}_x[\text{边界报酬}]$，
   调和函数=鞅——PDE 与随机过程的双向翻译，位势论的深层身份）。

## 三、可构造 × 结构的乘法表（谁给谁上发条）

| 结构 | 提供的构造力 |
|------|-------------|
| 能量守恒 | 辛格式/能量守恒格式的合法性（离散能量恒等式可机器验证） |
| 对称性 | 降维构造、自相似/行波解、等变数值格式 |
| 极值原理 | 比较原理夹逼、单调迭代格式、最大值耗散格式的稳定性证明 |
| 紧性（Rellich） | 有限元收敛性、Gamma-收敛的极限识别 |

**反例警示（不可构造的硬墙）**：

- **NS 光滑性（千禧）**：3D 情形连"解是否全局光滑"都未决——
  构造性逼近（[01 章](01-近五年创新.md)方向一的 Euler 爆破是邻近进展）
  与超幂估计的失败（Tao 2014 的障壁分析）双向围剿仍无突破
- **湍流统计闭包**：矩层级不闭合，统计量的严格推导只有零星结果——
  轨道不可预测（混沌）之外，**统计也半不可构造**

## 不足层

1. Lax–Richtmyer（相容+稳定⟹收敛）只对**线性**适定问题成立；
   非线性问题的格式收敛性证明仍是一门手艺（守恒律的 Lax–Wendroff 定理
   只保证"收敛则收敛于弱解"，不保证收敛）
2. 非构造存在性与算法之间存在鸿沟：存在性证完，数值照算，但
   "数值解接近真解"的严格验证（computer-assisted proof）需要完全另起炉灶
   （区间算术，01 章方向一）——常规数值分析与严格数学之间的接口仍是窄门
3. 三条骨架覆盖二阶方程较全；色散/完全非线性方程上骨架残缺
   （无极值原理、能量临界），构造力天然降档
