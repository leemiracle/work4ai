# 02 · 语言特征：估计的方言、Sobolev 的母语、适定性的规范化

> **本章回答五问之三（本支：讲透偏微分方程）。** 本支的表达力、逻辑性质、
> 规范化程度可以用三句话总括：**说"估计"的方言**（先验界先于解）、
> **以 Sobolev 空间为母语**（分部积分是语法）、**用适定性完成规范化**
> （Hadamard 三问 = 本支的公理级验收标准）。

---

## 一、表达：估计的方言（解还没出生，先给它的肖像画界）

本支的行话不是"求解"而是**估计（estimate）**。看一段本支的典型对话：

```
普通分析：  "求出 u"           —— 等式文化（求值）
PDE 方言：  "证 \|u\|_{L^\infty} ≤ C\|f\|_{L^2}" —— 不等式文化（估计）
```

**为什么本支不得不说方言**：显式解几乎不存在（球平均/热核/Green 函数
是仅有的几个"全集"），于是提问方式整体降维——从"解是什么"降到
"解被什么控制"。控制住了 = 拿到了解的一切可用信息。

三层估计的阶梯（从粗到细）：

| 层 | 问题 | 典型结论 | 兑换什么 |
|----|------|---------|---------|
| 能量估计 | 解的范数被数据控制？ | $\|u(t)\| \le \|u(0)\|$ | 唯一性+稳定性 |
| 正则性估计 | 解有多光滑？ | $\|u\|_{C^{2,\alpha}} \le C\|f\|_{C^{0,\alpha}}$ | 经典解复活 |
| 渐近估计 | 解的衰减/爆破率？ | $\|u(t)\| \sim t^{-\alpha}$ | 长时行为/散射 |

**表达力的边界（能说什么/不能说什么）**：

- ✅ 能说：解的范数、光滑度、衰减率、奇点集的测度与维数
- ❌ 不能说：解的显式表达（一般方程）、奇点的精确位置（NS 的困境：
  连"有没有奇点"都无法判定）、逐点的精确值

一句总结：**本支把"求解"重写为"框定"——框得越紧，知道得越多。**

## 二、逻辑：分部积分——把语法成本转嫁给测试函数

本支的语法核心是一次分部积分：

$$\int (\Delta u)\,\varphi = -\int \nabla u \cdot \nabla \varphi \quad (\text{边界项注销})$$

读法：**$u$ 不必二阶可导，导数的负担被转移给了测试函数 $\varphi$**。
这一手"转嫁"产生三连后果：

1. **解的概念自动扩容**：$u$ 只需要 $W^{1,2}$（Sobolev 空间）——弱解诞生
2. **函数类成为逻辑变量**：同一方程在不同函数类里**真值不同**——
   热方程弱解存在（Leray），光滑性未知；换更强的函数类，存在性可能**失败**。
   "方程+函数类"才是一个完整的命题，本支的真假是**相对于语言**的
   （对照 00 章弱解不唯一：熵条件=在函数类上再加一条不等式约束）
3. **对称性可计算**：分部积分暴露方程的变分结构（方程=某泛函的 Euler–Lagrange）
   ⟹ Noether 定理把每个对称兑换成一条守恒律（能量/动量/荷）——
   这是结构信息的免费提款机（详见 [03 章](03-可构造与结构.md)）

**逻辑性质档位表**（与家族 02 章的量词机器对照）：

| 性质 | 本支表现 |
|------|---------|
| 可判定性 | ❌ 一般 PDE 的适定性不可判定（无算法统一判定）；按方程逐族裁决 |
| 存在性 | 大量**非构造**（紧性/不动点/连续性方法——Zorn 级的"存在但不展示"） |
| 唯一性 | 依赖函数类+附加条件（熵条件/单调性），不是方程内禀属性 |

## 三、规范化：Sobolev 空间是母语，适定性是宪法

**母语层（Sobolev 空间 $W^{k,p}$）**：本支全部陈述用统一记号系统书写：

$$W^{k,p}(\Omega) = \{u : \|u\|_{W^{k,p}} < \infty\}, \quad H^k = W^{k,2}$$

配三件语法装备：**嵌入定理**（$W^{1,p}$ 的函数自动有 $L^q$ 范数，$1/q = 1/p - 1/n$——
光滑度兑换可积性）、**迹定理**（边界值有意义——边值问题的入场券）、
**紧嵌入**（Rellich——弱收敛序列有强收敛子列的来源，直接法的燃料）。

> 反直觉发现：Sobolev 嵌入把"导数次数"和"可积指数"变成**同一货币的两种面额**
> ——$W^{1,4}$ 和 $L^\infty$ 在 $n=4$ 边界上等价（临界嵌入）。
> 临界指数 $s_c = n/2 - 1/\sigma$ 为什么在色散方程里那么关键
> （[01 章](01-近五年创新.md)方向四）？因为恰好在嵌入临界线上，
> 能量范数与守恒范数**平**——多一分能量可控，少一分失控。

**宪法层（适定性）**：Hadamard 三问（存在/唯一/连续依赖）是本支的
**规范化验收标准**——一个 PDE 问题只有通过三问才算"数学上良置"。
这相当于把"什么算一个好问题"本身公理化。后续发展：

- **弱形式**：方程⟺对一切测试函数的积分恒等式（ Galerkin 有限元与
  变分法的公共接口，04 章主场）
- **半群形式**：$u_t = Au \mapsto u(t) = e^{tA}u_0$（Hille–Yosida 定理
  把"PDE 的适定性"约化为"算子生成压缩半群"——泛函分析的接口，
  见 [../讲透泛函分析/](../讲透泛函分析/)）

**规范化的层级**（本支到第几级？）：

```
第0级 约定俗成（古典：一切光滑，隐式假设）
第1级 结构化定义（弱解/分布——解的概念被显式定义）      ← 本支主体在此
第2级 公理化验收（适定性三问/熵条件——问题良置性被公理化） ← 本支的最高规范
```

对照：数理逻辑到第 3 级（形式系统），本支止步第 2 级——方程族之间没有统一形式理论，
这是"一群学科合租"的代价（00 章不足层）。

## Python 层

本支三件语法装备在代码里的化身（[`experiments/heat_cfl.py`](experiments/heat_cfl.py)）：
显式格式**就是** $u^{n+1} = e^{\Delta t \cdot \Delta_h}u^n$ 的离散半群；
CFL 条件 $\Delta t \le \Delta x^2/2$ **就是**"离散版的能量估计"——
它保证离散解范数不增（连续依赖的离散形态）。跑实验时注意 (b) 情形
解的 $\ell^2$ 范数单调不增：那是能量估计在数值上的呼吸。

## 不足层

1. 母语过载：Sobolev 记号系统对非线性/临界问题常显不足
   （需要 BMO/Hardy 空间/形状导数等方言扩容），没有普适语言
2. 逻辑上"函数类相对真值"使文献充满隐式约定——同一"解"字跨章节可能不同含义，
   是初学者的最大坑
3. 规范化停留在问题级（适定性），无方程族级的统一形式理论——
   本支的"宪法"是一州一法

## ✍️ 练习

✋ 1. 把 $u_t = u_{xx}$ 乘 $u$ 积分，亲手推出能量估计
$\frac{d}{dt}\|u\|^2 = -2\|u_x\|^2$。哪一步用了分部积分？边界项为何消失？
✋ 2. 同一方程 $u_t + (u^2/2)_x = 0$，说明为什么"弱解存在"与"弱解不唯一"
不矛盾——函数类的宽窄如何同时影响存在性和唯一性？
✋ 3. 临界嵌入 $W^{1,n} \hookrightarrow L^q\ (\forall q<\infty)$ 但
$\not\hookrightarrow L^\infty$：用 $u = \log\log(1/|x|)$ 型函数体会临界线的危险。
🐍 4. 改 [`experiments/heat_cfl.py`](experiments/heat_cfl.py) 的 $r=\Delta t/\Delta x^2$
从 0.2 扫到 0.55，画（打印）$\log\|u^n\|_\infty$ 随步数的斜率——
斜率符号翻转的那一点就是 CFL 阈值的实验定位。
