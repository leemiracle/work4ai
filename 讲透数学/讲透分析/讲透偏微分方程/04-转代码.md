# 04 · 转代码：四代走廊与一条宪法（CFL）

> **本章回答五问之五（本支：讲透偏微分方程）。** 本支是分析家族里
> **离工程最近的一支**——CFD、气象、结构力学、芯片散热全是它的代码化身。
> 转换的主线是四代走廊（FDM→FEM→谱→PINN），而贯穿四代的宪法只有一条：
> **CFL/稳定性条件——"连续依赖"在离散世界的镜像**。违宪者爆破，无例外。

---

## 一、四代走廊总表（每代一句话本质 + 主场问题）

| 代 | 本质一句 | 主场问题 | 代表生态 |
|----|---------|---------|---------|
| **FDM 有限差分** | 在网格点上用差商逼近导数 | 规则区域、效率优先 | 手写 numpy / climate codes |
| **FEM 有限元** | 在弱形式里把解投影到分片多项式空间 | 复杂几何、工程结构 | FEniCS / deal.II / COMSOL |
| **谱方法** | 在全局基（Fourier/Chebyshev）里展开 | 光滑解、高精度 | FFTW / Dedalus / Chebfun |
| **PINN/算子学习** | 用网络表示解或解算子，方程残差进损失 | 无网格/反问题/方程族 | DeepXDE / FNO / DeepONet |

**代际关系不是淘汰**：FDM 快糙猛（宇宙 CFD 内核仍是它）、FEM 吃几何
（航空/汽车工业标准）、谱方法吃光滑（湍流直接数值模拟）、PINN 吃反问题
（没有网格、测量数据直接进损失）。选走廊的判据是**问题结构**
（区域形状/解的光滑度/数据形态），不是代际新旧的时尚。

**四代共享同一个接口——弱形式/残差**：FDM 残差=差商代入、FEM 残差=测试函数投影、
谱=模态截断、PINN=配点残差。02 章的"分部积分语法"在四代里全部在场。

## 二、一条宪法：CFL 条件（稳定性的代码形态）

显式热格式（网格 $x_j = j\Delta x$，时刻 $t_n = n\Delta t$）：

$$u_j^{n+1} = u_j^n + r\,(u_{j+1}^n - 2u_j^n + u_{j-1}^n), \qquad r = \frac{\Delta t}{\Delta x^2}$$

放大因子分析（把初值按傅里叶模 $e^{ik j\Delta x}$ 分解）：
每模每步乘 $g(k) = 1 - 4r\sin^2(k\Delta x/2)$。要求**一切模** $|g|\le 1$：

$$\boxed{r \le \frac{1}{2}} \quad\text{即}\quad \Delta t \le \frac{\Delta x^2}{2}$$

- 这就是 **CFL/稳定性条件**（抛物显式情形；双曲显式是 $\Delta t \le \Delta x/a$
  型——CFL 数 $= a\Delta t/\Delta x \le 1$）
- 宪法含义：**时间步长被空间步长钳制**——网格加密一倍（$\Delta x\to\Delta x/2$），
  显式格式的成本翻**四倍**（$\Delta t\to\Delta t/4$）。这就是为什么抛物问题
  实战都用**隐式格式**（Crank–Nicolson：无条件稳定，代价是每步解线代系统）
- 与适定性的关系：CFL 是 Hadamard"连续依赖"的**离散镜像**——
  超阈值，数值解对舍入噪声指数敏感（不适定），格式自身的动力学
  放大噪声（00-03 章的实验现场）

> 反直觉发现：超 CFL 的爆破**不是 bug，是格式在忠实解另一个方程**——
> 不稳定格式 = 在积分一个反向扩散方程（热方程的时间之箭被倒转，
> 02 章"逆时不适定"的数值现身）。数值噪声被物理式地放大：
> 你看到的是放大器的频率响应，不是"计算误差"。

## 三、走廊清单：问题类 → 格式/方法 → 库

| 问题类 | 首选 | 库/工具 |
|--------|------|--------|
| 抛物（热/扩散） | 隐式 CN / 显式小网格 | `scipy`（手写三对角）、FEniCS |
| 双曲（波动/声） | 显式 leapfrog / 有限体积 | 手写、ClawPack |
| 椭圆（Laplace/Poisson） | FEM/谱 | FEniCS、Chebfun |
| 守恒律（激波） | 有限体积+Riemann 求解器（Godunov 系） | ClawPack / Athena |
| 色散（Schrödinger/NLS） | 谱（分裂算子 Strang） | Dedalus / 自写 FFT |
| 刚性/大系统 | 隐式 BDF/IMEX | `scipy.integrate.solve_ivp(method='BDF')` |
| 反问题/无网格 | PINN/算子学习 | DeepXDE / DeepONet |
| 高维（>4D） | 张量/FNO（网格诅咒的出路） | FNO 系 |

**工程师落点（性能工程视角）**：本支的计算内核 = **模板迭代**（stencil）+
**稀疏线代**——两者都是内存带宽受限 workload，SU(3) 格点 QCD、气象谱元、
CFD 求解器与深度学习的 conv kernel 共享同一套性能指纹（访存局部性、
算术强度、向量化宽度）。写 stencil 内核的技巧（tiling/融合/时间分块）
与 CUDA kernel 优化手册直接互译——**PDE 格式就是最早的高性能 kernel**。

## 四、可机械化边界（什么能全自动、什么不能）

| 层 | 能否机械化 | 说明 |
|----|-----------|------|
| 格式稳定性（线性常系数） | ✅ 全自动 | von Neumann 分析=符号计算；工具链成熟 |
| 收敛性与误差阶（线性） | ✅ 半自动 | Lax–Richtmyer 保证存在；阶数可机器验证 |
| 网格自适应 | ⚠️ 半自动 | 误差估计子驱动，但策略人定 |
| 非线性问题的收敛性证明 | ❌ | 手艺（[03 章](03-可构造与结构.md)不足层） |
| 解的真值验证（区间算术） | ⚠️ 贵 | computer-assisted proof：能，但仅小规模（[01 章](01-近五年创新.md)方向一） |
| 最优格式选择 | ❌ | 问题定制知识，无算法 |
| PINN 误差界 | ❌ | 训练解无定理级误差保证（家族 01 章不足 3 的支层现身） |

边界一句话：**线性世界的宪法和执法都自动化了；非线性世界的宪法（收敛定理）
缺失，执法（误差验证）昂贵**——这就是本支数值分析的真实法治水平。

## Python 层

[`experiments/heat_cfl.py`](experiments/heat_cfl.py) 完整上演本章宪法：

- **(a) 违宪**：$r=0.55 > 1/2$，随机初值 200 步后 $\|u\|_\infty$ 膨胀
  超过初值 10 倍（断言发散）——不稳定模 $|1-4r\sin^2|$ 的复利
- **(b) 守宪**：$r=0.40$，单模初值 $\sin\pi x$，与解析解
  $e^{-\pi^2 t}\sin\pi x$ 对照，衰减行为被格式忠实继承（断言误差界）
- **(c) 放大器谱**：扫描 $r$ 画出最坏放大因子 $1-4r$ 与 1 的关系——
  CFL 阈值的实验定位

## 不足层

1. 四代走廊都是**正问题**走廊（给方程求解）；反问题（给解反推系数/初值）
   的机械化严重依赖正则化先验——自动化的天花板低得多
2. 高维诅咒（$n>4$）下网格法全灭，张量/神经表示是唯一出路但理论
   （逼近误差界）刚起步——FNO 的"方程族压缩"缺乏收敛定理背书
3. 格式→高性能 kernel 的映射靠人力；自动生成的 stencil 代码
   （FEniCS/Loopy 一线）与手调 kernel 的性能差距仍是数量级
4. 本支实验（单文件 numpy）只到"教学演示"级；生产级 CFD 的验证与确认
   （V&V：网格收敛研究+基准对照）是另一门工程学科，本章未覆盖

## 📌 收束

**四代走廊是四条生产线，CFL 是唯一宪法。** FDM/FEM/谱/PINN 各吃一类问题，
但"离散化继承连续依赖性"这条铁律四代通杀。本支转代码的最终图景：
线性适定问题已进入"定理背书+工具链自动化"的成熟期，非线性与高维
是活的战线——而这正是 [`../讲透数值分析/`](../讲透数值分析/) 的
方法论主场与 [`../../讲透应用数学/`](../../讲透应用数学/) 的工程现场。
