# 讲透分析 · 家族总纲（十个子系列穷尽分析学）

> 分析学是数学宇宙最大的家族——研究**极限、连续、无穷与逼近**的一切数学。
> 本系列是**家族总纲**：每个分支一个子目录（讲透xx），穷尽主干十支 + 长尾归属表，
> 五问在家族层面回答一遍，各分支子系列再各自深答。
>
> 2026-09-06 建族：`讲透实分析`、`讲透分析进阶` 自宇宙根迁入，八支新建。

## 〇、家族树（Q1 的答案 = 这棵树）

```
讲透分析/
├── 讲透数学分析/     🆓 高中→大学的桥（极限/连续/级数，计算与分析的交界）
├── 讲透实分析/       🔄 测度与 Lebesgue 积分（Tao+Rudin，宇宙创刊元老，自根迁入）
├── 讲透复分析/       解析、全纯、留数——一维的奇迹之地
├── 讲透泛函分析/     无穷维空间上的线性代数（算子/谱/三大定理）
├── 讲透调和分析/     Fourier 与分解的艺术（含小波/群上调和）
├── 讲透数值分析/     分析的计算面（插值/求积/方程求根/微分方程数值）
├── 讲透变分分析/     极值与直接法（变分法/泛函极小/Ekeland）
├── 讲透动力系统/     随时间演化的定性理论（含遍历理论）
├── 讲透偏微分方程/   多变量分析的主战场（守恒律/位势论/几何分析入口）
└── 讲透分析进阶/     Stein-Shakarchi 四卷统读线（Fourier/复/实/泛函的编年串联）
```

## 三、子系列穷尽表（含长尾归属）

| 讲透调和分析 | Stein I–III / Grafakos | **小波分析**、群上调和、时间频率分析 |
| 讲透数值分析 | Trefethen《NUMAL》（线代篇由 [`../讲透数值线代/`](../讲透数值线代/) 承担） | **逼近论**、求积、刚性 ODE |
| 讲透变分分析 | Evans 附录 / Mordukhovich | **凸分析桥**（通 [`../讲透优化/`](../讲透优化/)）、Γ-收敛 |
| 讲透动力系统 | Strogatz / Katok-Hasselblatt | **遍历理论**、分岔、混沌 |
| 讲透偏微分方程 | Evans《PDE》/ DiBenedetto | 守恒律、**几何分析入口**、正则性理论 |
| 讲透分析进阶 | Stein-Shakarchi 四卷 | 四卷统读线（跨复分析/实分析/调和/泛函） |
| （家族长尾表） | — | **非标准分析**（模型论侧入口，哲学性强，暂不设子目录）；**概率位势**（归概率书架） |
