# 03 · 可构造与结构：分析的构造臂，和它造不出的三样东西

> **本章回答五问之四（本支：讲透数值分析）。** 在分析家族里本支的
> 认识论地位独特：**别人证存在性，本支把存在性变成算法**——
> 但浮点宇宙给构造臂立了三块"此路不通"的碑：病态的原罪、
> 精度的天花板、不可有效估计的常数 C。

---

## 一、可构造：存在性定理的算法含量

把家族的存在性定理排队过一遍"算法含量"：

| 家族定理 | 存在性证明的引擎 | 算法化身 | 构造质量 |
|---------|----------------|---------|---------|
| 多项式插值存在唯一 | 线性代数（Vandermonde 非奇异） | Lagrange/重心公式 | **显式闭式** |
| 压缩不动点存在 | 完备性 + 迭代 | 不动点迭代 | 误差几何衰减可预算 |
| IVT（连续函数零点存在） | 紧性 + 连通性 | 二分法 | 每步一位，契约级稳 |
| ODE 解存在（Picard–Lindelöf） | 完备性 + 不动点 | Euler 折线 / RK | 一致收敛 O(h^p) |
| 隐函数存在 | 压缩映射局部化 | 牛顿迭代 | 局部 2 阶 |
| Lax–Milgram（弱解存在） | 变分直接法（[`../讲透变分分析/`](../讲透变分分析/)） | 有限元 Galerkin | 最佳逼近性质 |

**观察**：分析的存在性证明引擎（紧性、完备性、压缩、下有界+弱闭）
**几乎每一台都能改造成算法**——这是数值分析作为"构造臂"的本体论依据。
[`../03-可构造与结构.md`](../03-可构造与结构.md) 家族层说"完备化即构造"，
本支是那句话的产业部门。

反例（诚实记账）：纯存在性、无算法后代的证明也存在——
[`../讲透泛函分析/`](../讲透泛函分析/) 的 Hahn–Banach 依赖
Zorn 引理（非构造重镇），可分情形可算、一般情形只能靠选择公理。

## 二、三块"此路不通"碑

### 碑一：病态的原罪（Wilkinson 1963）

多项式 w(x) = ∏_{k=1}^{20} (x−k)，根是整数 1..20，人畜无害。
把 x²⁰ 的系数扰动 **10⁻¹⁰**（相对扰动 10⁻¹⁰ 量级）——
根成对崩进复平面，部分根位移超过 2。

判决书：求根的条件数 κ = 1/|p′(r)|（02 章练习 1），重根附近 κ→∞。
**病态是问题的属性**：换任何算法（那怕全程符号精确）都救不了
"输入本身带着 10⁻¹⁶ 相对尘埃"的现实问题。Wilkinson 本人的评语：
"这把我对浮点的天真烧了个干净。"

> 与 00 章 Runge 现象对照：Runge 的病态在**节点选择**（可救，
> 换 Chebyshev 节点）；Wilkinson 的病态在**问题本身**（不可救，
> 只能改提问方式：别问"根在哪"，问"根的信赖域"）。

### 碑二：精度的天花板（两债对冲的定量化）

00 章的 U 形曲线定量化：格式截断 O(h^p) + 舍入 O(ε/h) ⟹
最优 h* ≈ ε^{1/(p+1)}，可达精度 ≈ ε^{p/(p+1)}。

| 操作 | p | 可达精度（ε≈10⁻¹⁶） |
|------|---|--------------------|
| 数值积分（复化 Simpson） | 4 | ~10⁻¹³（宽松） |
| 一阶差分 | 1 | ~10⁻⁸（√ε） |
| 中心差分 | 2 | ~10⁻¹⁰（ε^{2/3}） |
| 二阶差分 | 2（但常数 1/h²） | ~10⁻⁵（天花板塌方） |

**结构性结论**：微分是天然病态操作（放大高频噪声，κ~1/h），
积分是天然良态操作（抹平噪声）。所以数值世界流行"能积不微"——
变分方法（[`../讲透变分分析/`](../讲透变分分析/)）把 PDE 写成积分型
（弱形式）再离散，正是绕开这块碑的家族级策略。

### 碑三：常数 C 的不可有效性

定理说 ‖误差‖ ≤ C h^p，证明给的 C 常常来自"最坏情况放缩链"，
比真实误差悲观几个数量级。后果：**先验界不能当工程预算用**。

对症药是**后验误差估计器**（残余型/梯度重构型）：算完之后用
残差本身估计误差 → 自适应加密。这是近三十年本支最深的
方法论运动（chebfun 的"截断即精度"、FEniCS 的自适应、
Gauss–Kronrod 的嵌套误差对——全部是它的化身）：
**从"跑之前证明"转向"跑之后审计"**——与软件工程从
瀑布到测试驱动的转向同构。

## 三、结构：条件数谱系与刚性的几何

### 3.1 条件数谱系（问题难度的元素周期表）

| 问题 | κ | 结构解释 |
|------|---|---------|
| 求和/积分 | ~1 | 平均=抹平，天然良态 |
| 求根 | 1/\|f′(r)\| | 根越平（近重根）越病态 |
| 数值微分 | 1/h | 差分=高通滤波，放大噪声 |
| 线性方程组 Ax=b | ‖A‖‖A⁻¹‖ | 奇异度=几何共线度（姊妹支主场） |
| 求特征值 | 1/谱间隙 gap | 特征值交叉处病态 |
| 非最简 Jordan 块 | ∞ | 可对角化性=数值稳定性（结构刚性） |

谱系的结构味：**κ 全是某种"退化距离"的倒数**——离奇异/重根/交叉
越近越病态。病态 = 问题的相变临界点。

### 3.2 刚性：多尺度结构对步长的绑架

刚性 ODE 的判据不是"非线性强度"而是**尺度分离度**：
stiffness ratio = |λ_max|/|λ_min|（快慢特征时间之比）。
显式格式的稳定域把 h 绑架到快尺度，精度只需慢尺度——
结构性诊断：**这是稳定域（算法结构）与解轨道（问题结构）的几何错配**。
隐式格式的解法 = 用大稳定域的算法结构去匹配问题结构（A-稳定：
稳定域盖住整个左半平面——02 章 Dahlquist 屏障说这种多步法最多 2 阶，
禁止与许可在这里交汇）。

### 3.3 与家族其余支的结构接口

- 本支的**收敛阶** = 家族其余支的**收敛速度**的工程化
  （[`../讲透数学分析/`](../讲透数学分析/) 级数的收敛阶、
  迭代法的阶利率是同一结构的三个化身）
- **Lax 等价**（一致性+稳定⟺收敛）是本支独有的三段式结构——
  把家族其余支"定义→定理"的两段式拆成"逼近→控制→极限"三段，
  每段可独立验证（这是它与
  [`../../../讲透形式化验证/`](../../../讲透形式化验证/) 的天然接口：
  三段各是一个可形式化的 lemma）

## 不足层

本章把"不可构造"归成三块碑，但边界地带仍模糊：① 病态与算法失败的
司法划分在**非线性迭代**（牛顿盆地、混沌吸引域）里失效——那里
κ 的定义本身依赖收敛与否（先有鸡还是先有蛋）；② 后验估计器自身的
可靠性常数（估计器的 κ）在自适应闭环里有罕见的共振失稳案例——
"审计员谁来审计"；③ 刚性的操作定义（stiffness ratio）只在线性
常系数情形严格，非线性/时变情形靠局部线性化类比支撑。
