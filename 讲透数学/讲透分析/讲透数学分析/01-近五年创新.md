# 01 · 近五年创新方向：老学科的两台新机器

> **本章回答五问之二（本支：讲透数学分析）。**
> 数学分析的本体（极限/连续/微积分/级数）是三百年成熟学科，**理论本体近五年无新增定理层**
> ——这是诚实判断，不是贬低。真正的动土在两处：**证明助手**把本支的每一步搬进机器，
> **AI** 把「写证明」变成「人机协作」。
> 检索校准 2026-09-06（Semantic Scholar 3 查询：形式化/教学技术/Lean 教学三条线；
> 命中度均低——教学侧索引被泛化 STEM 文献淹没，正文以可核实的公开事实为主，标注局限）。

## 方向一：Mathlib 微积分层的指数增厚（家族基建在本支的落点）

家族层 [`../01-近五年创新.md`](../01-近五年创新.md) 方向四记录了 Mathlib 的形式化基建潮。
本支的落点格外具体：

- **滤波子（Filter）API 重构了 ε-δ**：`Tendsto f 𝓝 a 𝓝 L` 把"邻域语言"公理化，
  00 章的量词机器在 Lean 里是一个组合子代数——量词顺序错误直接变成类型错误
- **微积分主干全覆盖**：`deriv`/`integral`/`HasSum`/一致收敛 `UniformConvergenceOn`
  进 Mathlib 主干；Spivak 级教材的主定理（IVT/MVT/FTC/判别法体系）已可 sorry-free
- **本科教材的 Lean 化**：Tao《Analysis I》配套 Lean 练习（宇宙
  [`../../讲透Lean4数学/`](../../讲透Lean4数学/) 的路线锚）意味着本支成为
  **第一个"教材与形式化库同步"的数学分支**

> **反直觉发现 #1**：形式化最深的分支恰是**最老的分支**——
> 不是因为简单，而是因为语言最规范（量词游戏可机械检查）。
> 越是"手艺活"的分支（如不等式放缩的品味）越难进 Mathlib。

## 方向二：教学游戏化——从 NNG 到 Real Number Game

- Natural Number Game（NNG）证明了"证明可以上瘾"；其续作们把本支内容做成游戏：
  **Real Number Game** 让玩家从 Cauchy 列等价类亲手**构造 ℝ**——00 章的地基搬进了关卡
- Lean Game Server 把这类游戏变成在线基础设施（2023- 起稳定服务），
  大学先修/大一分析课的"ε-δ 之痛"有了可玩的解法：**量词错误从"扣分"变成"关卡失败"**
- 教学法研究侧（如 IJRUME 系列对本科证明课堂的实证研究）持续确认：
  证明入门的瓶颈在量词阅读而非数学内容——与滤波子 API 的设计哲学互相印证

## 方向三：AI 进证明课（人机协作写作现场）

- 自动形式化（autoformalization）把自然语言陈述转成 Lean——本科分析陈述
  是当前最可靠的转换层级（语言规范红利，同 #1）
- LLM 辅助证明写作：草稿→Lean 检查的循环在本科内容上已实用化；
  「AI 写、机器查」的分工让 ε-δ 证明的**批改**第一次可扩展
- AlphaProof 级系统（2024-）虽瞄准竞赛，其副产品（经典引理库、搜索策略）
  持续下沉到本科定理空间——本支是第一受益人

## 判断：两台机器改变的是什么

| 层面 | 改变了 | 没改变 |
|------|--------|--------|
| 定理本体 | 无新增（成熟封闭） | ✅ 全部 |
| 语言 | ε-δ → 滤波子 API（方言标准化） | 数学内容 |
| 学习 | 失败可玩化、批改可扩展 | 手写证明的品味仍靠人 |
| 生产 | 教材↔形式化库同步成新常态 | 论文级新结果仍由人驱动 |

**一句话**：本支近五年的创新全部是**接口创新**（把老内容接到新机器上），
不是内容创新——这正是成熟学科的标准姿态，也是它成为"宇宙入口支"的资格。

## 不足层

1. 检索覆盖局限：教学技术侧的实证文献被泛化 STEM 研究淹没，
   本方向的引文密度低是索引问题也是信号——形式化教学的效应研究仍稀薄
2. 自动形式化的本科级可靠性是"陈述级"而非"证明级"：AI 写整段 ε-δ 论证
   仍频繁量词错序（恰是最该错的地方也是最难批改的地方）
3. 游戏化证据主要是经验报告，缺严格对照实验——「NNG 提高证明能力」
   尚无 RCT 级证据
