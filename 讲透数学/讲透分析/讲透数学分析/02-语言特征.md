## 一、表达：本支方言的四张合法牌照

ε-δ 量词机器（00 章）能合法表达的四类断言，构成全部后续方言的母版：

| 牌照 | 句式 | 本支实例 | 后代方言（哪支继承） |
|------|------|---------|-------------------|
| 逐点性质 | ∀x P(x) | 处处连续、可导 | 实分析加 "a.e." 修饰 |
| 局部性质 | ∀x ∃δ … | 连续的 ε-δ 定义 | 拓扑的开邻域语言 |
| 一致性质 | ∃δ ∀x … | 一致连续/一致收敛 | 泛函的算子范数（‖T‖=上确界版的一致性） |
| 收敛陈述 | ∀ε ∃N ∀n≥N … | 数列/级数/积分和收敛 | 测度收敛/弱收敛（弱化量词换广度） |

> **反直觉发现 #1**：**一致性不是连续性的加强，是另一个量词句子。**
> "一致连续"（∀ε∃δ∀x）与"连续"（∀x∀ε∃δ）在二阶逻辑里不可互相定义——
> 换序即换世界。这就是为什么一致收敛要单独一整章讲：它不是新对象，是新**句型**。

边界即接口：本支的四个"说不了"正是四支下游的**开场白**。

## 二、逻辑：不等式文化的起手式

家族层判词"分析证明 90% 是不等式"在本支的原生形态是**三招起手式**：

1. **三角不等式** ‖x+y‖ ≤ ‖x‖+‖y‖——绝对值的存在理由；
   一切"拆项估计"的许可证（MVT 不等式版、误差传递全是它）
2. **Young / Cauchy–Schwarz**——乘积换幂：ab ≤ aᵖ/p + bᑫ/q 是
   Hölder 梯子（泛函 Lᵖ 理论的祖先）在 ℝ 上的第一步
3. **Abel 求和 / 分部积分**——把导数从一边搬到另一边；
   级数的 Dirichlet 判别与积分的 FTC 是同一招的两个剧场

> **反直觉发现 #2**：本支的核心恒等式（FTC：∫f′=f(b)−f(a)）其实是
> 不等式的极限——对每个分划有 |上和−下和| ≤ ε，让 ε→0 **挤出**等号。
> **分析里等式是不等式的极限态**，不是独立公民。
> （实验 `series_convergence_decision.py` 的数值收口复刻这一幕：
> 部分和以 1e-5 误差逼近 π²/6——等式由不等式逼近见证）

### 逻辑性质的档位

| 性质 | 状态 | 说明 |
|------|------|------|
| 一致性 | ✅（相对 ZFC） | 本支全部定理在 ZFC 内可形式化，Mathlib 已实体化大半 |
| 完备性 | ➖ 无关（非形式系统） | "完备"在本支指**度量完备**（Cauchy 列收敛），是分析词不是逻辑词——同词两义是新手第一坑 |
| 可判定性 | ❌ 实闭域理论可判定但代价爆炸 | Tarski：一阶实数语句可判定；但 ε-δ 定义带函数量词，超出该理论——「这个级数收敛吗」不可判定 |

## 三、规范化：钉到了哪一级——"完备有序域"的唯一性

本支的规范化是全宇宙最彻底的样板，分三级钉死：

| 级别 | 内容 | 钉死程度 |
|------|------|---------|
| 对象层 | ℝ = 唯一（同构意义下）完备有序域 | **唯一性定理**：三种构造（Dedekind/Cauchy/区间套）殊途同归 |
| 语言层 | ε-δ 量词句式 = 标准语法 | 200 年共识 + Mathlib 滤波子 API 机器标准化 |
| 工具层 | 判别法/中值/FTC 定理包 | 教材全球趋同（Spivak/Zorich/Rudin PMA 三大锚） |

> **反直觉发现 #3**：钉得最死的学科**最适合机器化**——01 章两台新机器
>（证明助手/AI）都从本支下手，不是巧合：规范化程度 = 可机械化程度的先行指标。
> 滤波子 API 能把量词错误变成类型错误，前提是量词句式早已全球统一。

## Lean 层

ε-δ 进 Lean 的标准形态：`∀ ε > 0, ∃ δ > 0, ∀ x, |x - a| < δ → |f x - L| < ε`。
Mathlib 用 `Filter.Tendsto` 把这张量词脸收编成一个组合子——
**方言标准化的当代工程版**，也是 01 章方向一的落点。

## 不足层

1. 量词句式对**函数性质**的表达是二阶的（量词掠过函数），Tarski 可判定性罩不住——
   自动判收敛/自动放缩至今无解（〔04 章〕裂缝清单详述）
2. 不等式证明的**品味**（先放缩哪一项）无算法——Mathlib 里最厚的也是最难自动化的一段
3. "完备"一词跨语义（度量完备 vs 逻辑完备）在本支与
   [`../../讲透证明/`](../../讲透证明/) 之间制造了持续的术语混淆成本
