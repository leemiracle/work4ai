# 讲透积分方程 · 未知函数藏在积分号下

> 未知函数出现在**积分号内**的方程——微分方程之外的"方程第三形态"。它把边值问题、
> 信号重建、逆散射串成一门理论；更戏剧的是：**正是它催生了泛函分析**
> （Hilbert 从 Fredholm 方程走到了 Hilbert 空间）。
>
> GB/T 13745：11054（二级学科）。家族：[讲透分析](../README.md)·补缺支（2026-09-06 按国标穷尽补建）。

## 诞生

Abel 1823 年问等时线：珠子沿什么曲线滑下最快？答案归结为
**Abel 积分方程**——第一道积分方程。Fredholm 1900 年研究位势边值问题，
给出 Fredholm 二择一，直接启发 Hilbert 建立 Hilbert 空间理论。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Fredholm 二择一（1900） | ✅ 已解 | 紧算子方程"唯一可解或齐次方程有非零解"——泛函分析的接生婆 |
| Abel 反演（1823/1923 Riemann-Liouville） | ✅ 已解 | 分数微积分的出生证明 |
| 逆散射变换（GGKM 1967） | ✅ 已解 | 积分方程反解 KdV 孤子——"非线性 Fourier 分析" |
| 第一类方程不适定性 + Tikhonov 正则化（1963） | ✅ 已解 | 反问题的标准灭火器 |
| Riemann–Hilbert 问题一般理论 | 🔄 部分 | 奇异积分方程的前线，可积系统与组合数学的通用引擎 |

## 假设与依赖
