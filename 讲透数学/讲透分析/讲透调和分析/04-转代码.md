# 04 · 转代码：频域走廊与它的裂缝

> **本章回答五问之五（本支：讲透调和分析）。** 本支是全家族
> **代码化最彻底的支**——"Fourier 变换可执行"养活了半个现代
> 计算世界。本章给走廊总表、逐条速写（含工程师视角的 FFT 内脏）、
> 与两条原则上不可机械化的裂缝。

---

## 一、可机械化边界（三档）

| 档 | 问题形态 | 判据 |
|----|---------|------|
| **全自动** | 变换/卷积/滤波/带限采样 | 有快速算法 + 有保证误差界 |
| **半自动** | 最优基选择、稀疏恢复、振荡积分 | 算法存在，但超参数/基库选择靠经验 |
| **不能** | restriction 型先验估计、最优常数 | 输出是定理不是数据，AI 也不产（[家族 01 章](../01-近五年创新.md)不足层） |

## 二、代码走廊总表

| # | 走廊 | 问题类 | 算法/对象 | 库/生态 |
|---|------|--------|----------|--------|
| 1 | **FFT/卷积** | 卷积、相关、大数乘法 | Cooley–Tukey 分治、Bluestein | `numpy.fft`、FFTW、cuFFT |
| 2 | **谱方法** | PDE、插值、微分 | 频域对角化（导数=乘 $i\xi$） | NumPy/SciPy、Chebfun、Dedalus |
| 3 | **小波/多分辨率** | 压缩、去噪、奇性检测 | Mallat 算法（滤波器组） | PyWavelets、JPEG2000 |
| 4 | **时频表示** | 语音、振动、雷达 | STFT/Gabor、再分配 | `scipy.signal.stft`、librosa |
| 5 | **采样/重构** | 带限采样、压缩感知 | Shannon 定理、随机矩阵 | `scipy.signal.resample`、CVXPY |
| 6 | **振荡积分** | 高频散射、激光 | Filon/Levin、驻相 | 自实现居多（数值分析支界面） |

## 三、逐条速写

### 3.1 FFT——本支的工业长子（工程师落点）

数学一句话：DFT 是 $\mathbb{Z}_N$ 上的 Fourier 变换，
FFT 是它的 $O(N\log N)$ 分治实现。

**性能工程内脏**（本宇宙读者的主场）：

```
bit-reversal 重排 → N/2 个 2 点蝶形 → log N 级蝶形网络
缓存：四步法（Cooley-Tukey 递归展开为矩阵转置+小 FFT）
SIMD：real-to-complex 打包（实信号 FFT 只需一半计算）
GPU：cuFFT 批量 FFT = 深度学习里 attention/卷积的隐藏引擎
```

- 大数乘法（Schönhage–Strassen 的应用面）、长卷积、谱微分全走此走廊
- 工程师一句话：**FFT 是"分治+对称性利用"的祖师爷级 workload**——
  它的缓存模式（转置与重排）与计算模式（蝶形）是性能优化教科书

### 3.2 谱方法——PDE 的频域方言

导数在频域=乘 $i\xi$（对角化！）⟹ 微分方程变代数方程。
周期/光滑问题此路最优（指数收敛）；非周期用 Chebyshev（[数值分析支]
(../讲透数值分析/)的地盘，本质同为谱思想）。
现代延伸：**FNO（傅里叶神经算子）**——在 Fourier 域学算子，
是本走廊与 ML 的合流点。

### 3.3 小波压缩——刚性的商业兑现

JPEG2000 的管线：小波变换 → 量化 → 熵编码。
**为什么是本支的胜利**：[03 章](03-可构造与结构.md)的 Balian–Low
张力说明没有通用最优基——小波按尺度分配分辨率，恰好匹配图像的
"低频全局+高频局部"统计，成为静态图像压缩的数学最优解之一
（JPEG 的 DCT 是它的均匀网格简化版）。

### 3.4 STFT/Gabor——语音的宪法

滑动窗 FFT：$X(\tau,\xi) = \int f(t) g(t-\tau) e^{-it\xi} dt$。
窗宽=不确定性原理的工程菜单（[03 章](03-可构造与结构.md)第三节）。
声纹、雷达 chirp、机械故障诊断全住此走廊。

## 四、裂缝清单（原则上/工程上不可转）

1. **先验估计不可机械化**（原则上）：restriction / decoupling 型定理
   的证明是"对所有函数的联合论证"，没有可枚举的输入——
   它们给代码的不是输出而是**许可证**（告诉你哪个算法合法），
   不是产物
2. **逐点收敛预测**（原则上）：Carleson 定理是存在性的；"给定 $f$，
   它的级数在这点收不收敛、多快"——无算法，甚至无一般刻画
3. **非均匀采样的稳定重构**（工程上）：理论上（非均匀采样理论）
   有解，但条件数爆炸；实践退回均匀采样+窗函数的世界
4. **常数盲**（工程上）：定理的 $C$ 不明 ⟹ 工程界靠经验定安全裕度
   （防走样的采样率留多少余量是行业玄学区）

## 五、走廊选择树（实践快查）

```
信号是周期的/稳态的？
 ├─ 是 → 走廊 1（FFT）+ 2（谱方法）
信号是瞬态的/有奇性（边缘、冲击）？
 ├─ 是 → 走廊 3（小波）
需要"什么时候发生"（时间定位）？
 ├─ 是 → 走廊 4（STFT）
只有少量测量要重构（采样受限）？
 ├─ 是 → 走廊 5（采样/压缩感知）
被积函数高频振荡？
 ├─ 是 → 走廊 6（振荡积分）
```

## Python 层

[`experiments/gibbs_fft.py`](experiments/gibbs_fft.py) 把两条主走廊
做成可跑标本：(a) 部分和的 Gibbs 过冲（走廊 1 的收敛税）；
(b) FFT 卷积 vs 直接卷积的计时对照（走廊 1 的复杂度红利，
$n=2^{12}$ 实测加速两个数量级）。

## 不足层

1. 走廊 6（振荡积分）无成熟库——社区靠论文附代码，是
   [数值分析支](../讲透数值分析/)的应建工程
2. GPU 上的非 2 幂 FFT（Bluestein）生态弱于 CPU（FFTW），大素数尺寸
   的迁移成本常被低估
3. 采样理论给的是充分条件（带限+均匀）——真实信号（非带限、
   有噪声）的"理论-工程"换算仍靠行业经验，教科书答案与实践
   之间的沟没有桥

## ✍️ 练习

✋ 1. 用 DFT 做 $10^6$ 位大数乘法：为什么系数表示→点值表示→
   逐点乘→回来，比竖式快？（点值表示=对角化；乘法在点值域是
   $O(n)$——走廊 1 的对角化哲学）
✋ 2. 为什么 JPEG 用 DCT 而不是小波（JPEG2000 才用）——
   工程约束（块结构、算力）如何压过数学最优？
🐍 3. 跑 `experiments/gibbs_fft.py`，把 $n$ 从 $2^{12}$ 扫到 $2^{16}$：
   绘制加速比曲线（文本输出即可），观察 FFT 优势随 $n$ 的增长——
   $O(n\log n)$ vs $O(n^2)$ 的剪刀差
