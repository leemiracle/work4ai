# 02 · 语言特征：ε-δ、不等式文化与完备化

> **本章回答五问之三（家族层）：表达？逻辑？规范化？**
> 分析的母语只有三件：**量词游戏**（ε-δ）、**不等式**（放缩的艺术）、
> **完备化**（把极限造出来的动作）。十支方言全部由这三件派生。

---

## 一、表达：ε-δ 是一台量词机器

### 1.1 极限的定义 = 量词的精确排列

```
lim_{x→a} f(x) = L :
∀ε>0 ∃δ>0 ∀x ( 0<|x−a|<δ ⟹ |f(x)−L|<ε )
```

分析的入门之痛不在 ε 和 δ，在**量词的顺序**：ε 先于 δ（δ 可以依赖 ε），
x 最后（δ 不得依赖 x）。交换量词 = 交换数学：

| 断言 | 量词排列 | 含义 |
|------|---------|------|
| 连续 | ∀x ∀ε ∃δ ∀y | δ 可以逐点挑 |
| **一致连续** | ∀ε ∃δ ∀x ∀y | **一 δ 通吃全域** |
| 逐点收敛 | ∀x ∀ε ∃N ∀n | N 依赖 x |
| **一致收敛** | ∀ε ∃N ∀x ∀n | N 通吃 |

> **反直觉发现 #1**：x² 在 ℝ 上连续但**不一致连续**——
> 量词交换的失败不是修辞，是数学事实：δ(ε,x) = ε/(2|x|+1)，x→∞ 时 δ→0，
> **全局 δ 不存在**。（实验 `02_quantifier_game.py` 数值实拍这一幕）

### 1.2 表达力的家族分级

| 方言层 | 加了什么表达 | 哪支用 |
|--------|------------|--------|
| ε-δ | 邻域语言 | 数学分析 |
| 测度语言 "a.e." | 忽略零测集 | 实分析（"几乎所有"成为合法量词） |
| 范数/算子语言 | 无穷维的"大小" | 泛函 |
| 频率语言 | 分解为叠加 | 调和 |
| 弱形式 | 分部积分换边站 | 变分/PDE |

## 二、逻辑：不等式文化——用"估计"代替"求值"

分析证明 90% 的篇幅是不等式。其逻辑结构与代数"等式链"根本不同：

| 等式文化（代数味） | 不等式文化（分析味） |
|------------------|---------------------|
| a = b = c ⟹ a = c | a ≤ b ≤ c+ε，**ε 任意** ⟹ a ≤ c |
| 精确 | **任意精度**（"证明即逼近程序"） |
| 计算 | **放缩**（丢掉不要的、保住要紧的） |

三大家族放缩武器：三角不等式（∥·∥ 的存在理由）、Young/Cauchy-Schwarz
（乘积换幂）、分部积分/Abel 求和（搬移导数）。

> **反直觉发现 #2**：ε-δ 证明是一台**对局机器**——∀ε 是对手出题，
> ∃δ 是你应答。对手可以任意刁难，但你的应答策略是递归可计算的函数 δ(ε)。
> 把这局写成代码就是"证明的算法内容"（实验 02 正是这个对局的数值版；
> 构造主义把这一点推向极致——证明=程序，见 [`../讲透证明/03-可构造与结构.md`](../讲透证明/03-可构造与结构.md)）。

## 三、规范化：完备化——把极限**造**出来的动作

### 3.1 一个动作，三次出场

| 舞台 | 不完备的对象 | 完备化 | 买到了什么 |
|------|------------|--------|-----------|
| ℚ 中的根 | {1, 1.4, 1.41, …} 无极限 | **ℝ**（Dedekind cut / Cauchy 列） | 极限存在性（连续性） |
| Riemann 积分的函数空间 | 有理阶梯函数不完备 | **L²**（等价类） | Hilbert 空间结构 → Fourier 理论 |
| 连续函数空间 | 逐点极限跑出去 | （按范数）C[0,1] 已完备；换拓扑得各种 Banach | 依问题选拓扑 |

> **反直觉发现 #3**：完备化的机制是**等价类打包**——两个 Cauchy 列"极限相同"
> 就视为同一个实数。ℝ 的每个点是一整个序列的**户口本**。
> （实验 `03_constructive_reals.py`：把 √2 做成一个真正的可计算对象——
> 它不是数，是"精度供应合同"）

### 3.2 完备化 = 分析家族的"规范化"总纲

其他学科的规范化是"写公理"（集合论的 ZFC、证明论的矢列演算）；
分析的规范化是**"补洞"**：任何"应该在而不在"的极限，都通过完备化合法化。
十支共享这一个动作：测度完备化（实分析）、Sobolev 空间（PDE/变分——
"弱导数"就是先分部积分再完备化）、C*-代数完备化（跨界）。

## 五、Lean 层

ε-δ 在 Lean 里是 `∀ ε > 0, ∃ δ > 0, ∀ x, ...`——量词嵌套即 Prop 嵌套；
Mathlib 的 `Filter` API 把"邻域语言"公理化（滤波子——把 ε-δ、收敛、连续统一成
一个对象）。**Mathlib 用滤波子重构 ε-δ，是"方言标准化"的当代工程版**。

## 六、不足层

1. ε-δ 语言的**非构造气味**：经典分析允许"∃δ"不给公式——构造分析（Bishop）要求可计算 δ
2. 不等式文化难以机器化：自动放缩是形式化分析的圣杯级难题（01 章方向一的余波）
3. 完备化不唯一方向：选哪个拓扑完备化 = 选哪个数学（Sobolev vs Hölder 的分野是品味不是定理）
