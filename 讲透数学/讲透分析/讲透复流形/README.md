# 讲透复流形 · 复几何的分析舞台

> 局部像 ℂⁿ、转移映射全纯的流形。**复一维就是黎曼面，复高维却远远不是
> "实 2n 维流形加一个复结构"那么简单**——可积性条件是实几何没有的紧箍咒。
>
> GB/T 13745：11041 函数论·三级"复流形"。家族：[讲透分析](../README.md)·补缺支（2026-09-06 按国标穷尽补建）。

## 诞生

Weyl 1913 年给黎曼面第一个严格定义（一维复流形）；Chern 1946 年的示性类
把复结构的整体不变量算了出来；Calabi 1954 提出猜想、Yau 1976 解决——
复流形成为分析与几何的正式交汇点。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Newlander–Nirenberg 定理（1957） | ✅ 已解 | 近复结构何时可积——复流形的出生证 |
| Calabi 猜想（Yau 1976，Fields） | ✅ 已解 | 第一陈类代表 Ricci 形式——"复 Monge–Ampère 方程的可解性"，Calabi–Yau 流形由此而来 |
| Hodge 猜想 | ⧜ 千禧未解 | 代数闭链哪些是上同调的 (p,p) 块——著名问题全景千禧档 |
| 非 Kähler 复流形分类 | ❌ 未解 | Kähler 世界很整齐，外面还是旷野 |

## 假设与依赖

Kähler 度量（复结构×辛结构相容）是本支黄金假设：买到 Hodge 分解与
Hodge 理论，付出"只覆盖复流形的一小部分"。
前置：[多复变](../讲透多复变/)、[泛函分析](../讲透泛函分析/)（椭圆估计解 Monge–Ampère）。
