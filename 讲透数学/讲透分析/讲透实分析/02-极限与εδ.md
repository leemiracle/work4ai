## 一、直觉层：为什么需要 ε-δ

### 1.1 一个让你不舒服的问题

老师问你："$\lim_{x \to 2} x^2$ 等于几？"

你说："$4$。"

老师追问：**"为什么？"**

你可能说："$x$ 接近 $2$ 时，$x^2$ 接近 $4$。"

老师继续追问：**"什么叫'接近'？多近算接近？"**

——这就是 19 世纪数学家卡了几十年的问题。"接近"是模糊的日常语言，不是数学语言。

### 1.2 Weierstrass 的解法（1860s）

Karl Weierstrass 的洞察：**把"接近"翻译成对偶的游戏**。

> 极限 $\lim_{x \to a} f(x) = L$ 是这样一个游戏：
> - **对手**（Adversary）给你任意小的容忍度 $\epsilon > 0$
> - **你**（Prover）必须找到一个范围 $\delta > 0$
> - 让对手选任何 $x$ 只要 $0 < |x-a| < \delta$
> - 你必须保证 $|f(x) - L| < \epsilon$
>
> 如果你**对任意** $\epsilon$ 都能找到 $\delta$ —— 你赢，极限成立。
> 如果对手能找到一个 $\epsilon$ 让你**永远找不到** $\delta$ —— 你输，极限不成立。

**关键**：$\epsilon$ 在前（对手选），$\delta$ 在后（你选）。**$\delta$ 依赖 $\epsilon$**。

### 1.3 一个直觉例子

证明 $\lim_{x \to 2} x^2 = 4$。

对手说："我要求 $|x^2 - 4| < 0.1$（即 $\epsilon = 0.1$）"
你算：$|x^2 - 4| = |x-2||x+2|$。如果 $x$ 接近 2（比如 $|x-2| < 1$），则 $x+2 \in (1, 5)$，所以 $|x+2| < 5$。于是 $|x^2 - 4| < 5|x-2|$。要 $< 0.1$，需 $|x-2| < 0.02$。你回："$\delta = 0.02$"。

对手说："我要求 $\epsilon = 0.001$"
你回："$\delta = 0.001 / 5 = 0.0002$"

对手给任意 $\epsilon$，你都能回 $\delta = \epsilon / 5$。**你赢**。

## 二、数学层：$\epsilon$-$\delta$ 的严格定义

### 2.1 函数极限的定义

$$\lim_{x \to a} f(x) = L \iff \forall \epsilon > 0, \exists \delta > 0, \forall x \in \text{dom}(f): 0 < |x - a| < \delta \Rightarrow |f(x) - L| < \epsilon$$

读法（**逐字**）：
- "对所有 $\epsilon$ 大于 0"（对手给任意容忍度）
- "存在 $\delta$ 大于 0"（你能找到范围）
- "对所有 $x$ 在 $f$ 的定义域内"
- "如果 $x$ 满足 $0 < |x-a| < \delta$"（$x$ 在 $a$ 的 $\delta$-去心邻域）
- "则 $|f(x) - L| < \epsilon$"（$f(x)$ 落在 $L$ 的 $\epsilon$-邻域）

### 2.2 量词顺序为什么关键

**$\forall \epsilon, \exists \delta$** —— $\delta$ 可以依赖 $\epsilon$（通常 $\delta$ 是 $\epsilon$ 的函数）。

**反例**：如果改成 $\exists \delta, \forall \epsilon$，意思是"有一个固定 $\delta$ 对所有 $\epsilon$ 都管用"——这只在 $f$ 是常数时成立。完全不同的命题。

### 2.3 三个完整证明例子

**例 1（线性）**：$\lim_{x \to 3} (2x) = 6$

**证明**：
给定 $\epsilon > 0$。取 $\delta = \epsilon / 2$。
对任意 $x$ 满足 $0 < |x - 3| < \delta$：
$$|2x - 6| = 2|x - 3| < 2 \cdot \delta = 2 \cdot (\epsilon/2) = \epsilon. \quad \checkmark$$

**例 2（二次）**：$\lim_{x \to 2} x^2 = 4$

**证明**：
给定 $\epsilon > 0$。**先假设** $\epsilon$ 不太大（如 $\epsilon < 1$，否则取 $\min$），取 $\delta = \min(1, \epsilon/5)$。
对任意 $x$ 满足 $0 < |x - 2| < \delta$：
- 由 $\delta \leq 1$：$|x - 2| < 1 \Rightarrow 1 < x < 3 \Rightarrow 3 < x + 2 < 5 \Rightarrow |x + 2| < 5$
- $|x^2 - 4| = |x-2| \cdot |x+2| < \delta \cdot 5 \leq (\epsilon/5) \cdot 5 = \epsilon. \quad \checkmark$

**例 3（用归结到定义）**：$\lim_{x \to 0} \sin(x)/x = 1$（不证，要用几何，见 Rudin 或 Tao）

### 2.4 序列极限的定义

序列 $a_1, a_2, \ldots$ 收敛到 $L$：
$$\lim_{n \to \infty} a_n = L \iff \forall \epsilon > 0, \exists N \in \mathbb{N}, \forall n > N: |a_n - L| < \epsilon$$

序列极限和函数极限的关系（Heine 定理）：$\lim_{x \to a} f(x) = L \iff$ 对所有序列 $x_n \to a$（$x_n \neq a$），有 $f(x_n) \to L$。

### 2.5 反直觉发现

**反直觉 1**：极限 $\lim_{x \to a} f(x) = L$ **不要求 $f(a)$ 存在或等于 $L$**。

例：$f(x) = \begin{cases} 0 & x \neq 0 \\ 1 & x = 0 \end{cases}$。$\lim_{x \to 0} f(x) = 0$，但 $f(0) = 1$。

这就是定义里 $0 < |x - a|$（去心邻域）的原因——**极限看的是 $a$ 附近，不看 $a$ 本身**。

**反直觉 2**：函数可以在 $a$ 点没定义，但极限仍存在。

例：$f(x) = \sin(x)/x$ 在 $x = 0$ 没定义（0/0），但 $\lim_{x \to 0} \sin(x)/x = 1$。

**反直觉 3**：左极限 ≠ 右极限，则极限不存在。

例：$f(x) = |x|/x$。$x \to 0^+$ 时 $f(x) = 1$，$x \to 0^-$ 时 $f(x) = -1$。$\lim_{x \to 0} f(x)$ 不存在。

## 三、Python 实验层：可视化 ε-δ 游戏

### 3.1 实验：`experiments/02_epsilon_delta.py`

下面是核心逻辑（完整脚本跑 bash）：

```python
import numpy as np

def verify_limit(f, a, L, eps_candidates, find_delta):
    """
    玩 ε-δ 游戏：
    - f: 函数
    - a: 极限点
    - L: 声称的极限
    - eps_candidates: 对手给的 ε 列表
    - find_delta(eps) -> delta: 你的策略
    """
    print(f"验证 lim_{{x→{a}}} f(x) = {L}")
    print(f"  {'ε':<12} {'δ (你的)':<15} {'最大 |f(x)-L| (随机抽样)':<25} {'< ε?'}")
    for eps in eps_candidates:
        delta = find_delta(eps)
        # 在 (a-delta, a+delta) 里随机抽样 1000 个 x，找最大 |f(x) - L|
        xs = a + (np.random.rand(1000) - 0.5) * 2 * delta
        xs = xs[xs != a]  # 去心
        max_diff = max(abs(f(x) - L) for x in xs)
        ok = "✓" if max_diff < eps else "✗"
        print(f"  {eps:<12.4f} {delta:<15.6f} {max_diff:<25.10f} {ok}")

# 例 1: lim_{x→3} 2x = 6, 策略 δ = ε/2
verify_limit(f=lambda x: 2*x, a=3, L=6,
             eps_candidates=[0.1, 0.01, 0.001, 1e-6],
             find_delta=lambda eps: eps/2)

# 例 2: lim_{x→2} x^2 = 4, 策略 δ = min(1, ε/5)
verify_limit(f=lambda x: x**2, a=2, L=4,
             eps_candidates=[0.1, 0.01, 0.001, 1e-6],
             find_delta=lambda eps: min(1, eps/5))
```

**反直觉发现**：随机抽样测出的"最大 $|f(x) - L|$"通常**远小于** $\epsilon$——因为你的 $\delta$ 策略是保守的（worst-case bound）。真实的 $\max$ 可能比 $\epsilon$ 小 10 倍以上。这就是 ε-δ 证明的"安全余量"。

### 3.2 实验：失败案例（极限不存在）

```python
# 验证 lim_{x→0} |x|/x 不存在（左极限 ≠ 右极限）
def show_no_limit():
    print("\n反例：lim_{x→0} |x|/x 不存在（左右极限不等）")
    print(f"  {'x':<15} {'|x|/x':<10}")
    for x in [0.1, 0.01, 0.001, -0.001, -0.01, -0.1]:
        print(f"  {x:<+15.4f} {abs(x)/x:<+10.0f}")

show_no_limit()
```

## 四、Lean 层：极限的形式化

### 4.1 Mathlib 的极限定义

Mathlib 用 **filter** 抽象表达极限（比 ε-δ 更一般）：

```lean
import Mathlib

-- Mathlib 的极限定义（简化）
-- `Tendsto f (𝓝 a) (𝓝 L)` 读作"f 在 a 的邻域 filter 下趋于 L 的邻域"
#check Tendsto (fun x : ℝ => 2 * x) (𝓝 3) (𝓝 6)

-- 但你可以展开成 ε-δ 形式
def HasLimAt (f : ℝ → ℝ) (a L : ℝ) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ x, 0 < |x - a| → |x - a| < δ → |f x - L| < ε
```

### 4.2 一个完整的 Lean 证明（lim 2x at 3 = 6）

```lean
theorem lim_2x_at_3 : HasLimAt (fun x => 2 * x) 3 6 := by
  intro ε hε
  use ε/2
  constructor
  · apply div_pos hε (by norm_num : (0:ℝ) < 2)
  intro x _ hx
  have key : |2 * x - 6| = 2 * |x - 3| := by
    rw [show 2 * x - 6 = 2 * (x - 3) by ring, abs_mul]
  rw [key]
  calc 2 * |x - 3|
      < 2 * (ε/2) := (mul_lt_mul_of_pos_left hx (by norm_num))
    _ = ε := by field_simp
```

**关键 tactic**：
- `intro ε hε`：引入 ε 和它的正性假设
- `use ε/2`：给出 δ 的选择
- `ring`：自动证明多项式等式（如 $2x - 6 = 2(x-3)$）
- `field_simp`：自动化简域（field）运算
- `norm_num`：自动算数值

## 五、不足与应用

### 5.1 ε-δ 的不足

- **门槛高**：第一次接触 ε-δ 的人会困惑"为什么这么绕"。需要 1-3 个月适应
- **慢**：写一个 ε-δ 证明比"显然"慢 10 倍。但这是为了严格
- **不直接计算**：ε-δ 是验证，不是计算工具

### 5.2 应用

| 应用 | 怎么用 |
|------|--------|
| **ML 泛化界** | "以 ≥ $1-\delta$ 概率，泛化误差 ≤ $\epsilon$"——$\epsilon$-$\delta$ 的对偶直接出现 |
| **数值分析** | 算法的"近似"必须严格定义（用 ε-δ）|
| **概率收敛** | 几乎处处收敛 / 依概率收敛 / 依分布收敛——全用 ε-$N$ 或 ε-$\delta$ |
| **优化收敛** | "SGD 在 $T$ 步后误差 $\leq O(1/\sqrt{T})$"——$\epsilon$-$N$ 语言 |
| **拓扑学** | 极限的推广（filter / net），ε-δ 是特殊情况 |

> 💡 **ML 中的 $\epsilon$-$\delta$**：你看 ML 论文时遇到的"$\forall \epsilon > 0, \exists N, \forall n > N$"——这就是序列极限定义。学过实分析再看 ML 论文会突然"豁然开朗"。
