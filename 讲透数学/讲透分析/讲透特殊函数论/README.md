# 讲透特殊函数论 · 明星函数的名人堂

> Γ、ζ、超几何、Bessel、椭圆函数、正交多项式——在数论、物理、组合里
> 反复出现的"明星函数"。它们不是零散工具，而是**微分方程+对称性+渐近术**
> 三条线拧成的一门理论。
>
> GB/T 13745：11041 函数论·三级"特殊函数论"。家族：[讲透分析](../README.md)·补缺支（2026-09-06 按国标穷尽补建）。

## 诞生

Euler（Γ/Β 函数、五次幂和公式）；Gauss 1812（超几何级数——第一个被
"系统研究"的函数族）；Riemann 1859（ζ 函数把数论变成分析）；
20 世纪物理（量子力学/广义相对论）与组合（生成函数）双引擎扩容。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Γ 函数的唯一性（Bohr–Mollerup 1922） | ✅ 已解 | 对数凸性唯一确定"阶乘延拓"——性质选函数，不是公式选函数 |
| Ramanujan 猜想 | ✅ 已解（Deligne 1974，Weil 猜想推论） | Δ 函数系数的增长界——通往 étale 上同调的入口之一 |
| 黎曼假设（ζ 零点） | ⧜ 千禧未解 | 分析学最著名的未解问题——素数分布的中心引力源 |
| 渐近展开的严密化（Watson 引理等） | ✅ 已解 | 为什么发散的渐近级数反而比收敛级数更有用 |

## 假设与依赖

每类特殊函数背后是一个**二阶 Fuchs 型微分方程**——超几何是万函数之源
（Gauss/微分方程视角）；正交多项式站在 Hilbert 空间正交性上。
