# 讲透算子代数 · 空间即代数

> 把算子当点、把代数当空间研究——C*-代数与 von Neumann 代数，
> 谱理论的非交换升华。核心顿悟：**交换 C*-代数 = 局部紧空间**
> （Gelfand 对偶）——几何被完全编码进代数，"非交换几何"由此启程。
>
> GB/T 13745：11057 泛函分析·三级"算子代数"。家族：[讲透分析](../README.md)·补缺支（2026-09-06 按国标穷尽补建；原为泛函长尾声明，按国标目录级穷尽原则升支）。

## 诞生

von Neumann 1929（约化环理论：弱闭算子代数——量子力学的数学骨架）；
Gelfand–Naimark 1943（C*-恒等式 ‖a*a‖=‖a‖²——一条等式立起一个学科）；
Connes 1980s 把它推成非交换几何与循环同调。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Gelfand 对偶 + GNS 构造（1943） | ✅ 已解 | 交换=空间；每个代数是某 Hilbert 空间算子的忠实画像 |
| von Neumann 代数分类（I/II/III 型） | ✅ 已解（Murray–von Neumann 1936-43, Connes 1976） | III 型分类用了模理论——Fields 级工程 |
| Connes 嵌入猜想 | ✅ **被推翻**（MIP*=RE，Ji et al. 2020；独立验证 2025） | 纯数学猜想倒在量子复杂性理论手里——量子信息反哺数学的分水岭事件 |
| Elliott 分类纲领 | 🔄 部分 | 可分核 C*-代数何时被 K-理论完全分类——纲领仍在前线 |

## 假设与依赖

C*-范数公理是本支"宪法"（一条等式买到全部谱理论）；von Neumann 代数
站在双交换子定理上（Bicommutant Theorem：代数闭包=弱闭包）。
