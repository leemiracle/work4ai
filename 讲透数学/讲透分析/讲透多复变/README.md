# 讲透多复变 · 一维奇迹的断裂现场

> 把复分析搬到 n≥2 个复变量：**一维的全部奇迹在这里集体失效**，
> 长出独属于高维的新现象——Hartogs 延拓、拟凸、∂̄ 方法。
>
> GB/T 13745：11041 函数论·三级"多复变函数论"。家族：[讲透分析](../README.md)·补缺支（2026-09-06 按国标穷尽补建）。

## 诞生

Hartogs 1906 年发现：ℂⁿ（n≥2）的球壳上全纯函数**必然**延拓到实心球——
一维不存在的事。Poincaré 1907 年证明 ℂ² 的球与双圆盘不双全纯等价——
**Riemann 映照定理死了**。两记重锤砸出了新学科。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| Hartogs 现象（1906） | ✅ 已解 | 高维全纯函数"天然延拓"——域的几何开始管函数 |
| Levi 问题（拟凸域=全纯域） | ✅ 已解（Oka 1942-53） | 哪些域是全纯函数的"天然辖域"——Oka 干掉了它 |
| ∂̄-Neumann 问题 | 🔄 部分 | ∂̄ 方程何时有好解——高维的"柯西公式"候补，亚椭圆性至今未完全判明 |
| CR 嵌入性问题 | 🔄 部分 | 实超曲面何时能实现为 ℂⁿ 的边界——CR 几何前线 |

## 假设与依赖

一维的恒等定理、最大模、留数在 n≥2 需要重写；核心引擎从围道积分换成
**∂̄ 方程的 L² 估计**（Hörmander 权方法——分析味远浓于几何味）。
