# 讲透非标准分析 · 无穷小的平反

> 用模型论造出超实数系 *ℝ，让莱布尼茨的**无穷小**成为合法的数——
> 微积分的另一种地基。戏剧点：它更"直觉"，却**不能证明更多定理**
> （保守扩张）；但作为工具箱，它在概率与经济学里拿下了标准方法难及的战果。
>
> GB/T 13745：11037（二级学科）。家族：[讲透分析](../README.md)·补缺支（2026-09-06 按国标穷尽补建；原家族长尾表"暂不设子目录"，按国标目录级穷尽原则升支）。

## 诞生

Leibniz 1684 用无穷小发明微积分，被 Berkeley 主教讥为"消失量的幽灵"；
Weierstrass 的 ε-δ 把无穷小逐出分析。Robinson 1961/1966 用**模型论的
紧致性定理**构造超实数——幽灵获得户口，"牛顿-莱布尼茨的原始直觉在逻辑上完全严格"。

## 假设与依赖

**构造依赖超滤子/选择公理**——*ℝ 的存在是非构造的（哪个无穷小"存在"无法显式点名，
这是它最被诟病处）。一阶 vs 二阶语言的切分是命门：转移原理只对一阶陈述生效。
