# 讲透广义函数 · 让 δ 合法化的语言

> 把"函数"放宽成"对试探函数的连续线性泛函"——δ 函数、点电荷、
> 白噪声统统获得户口。戏剧点：**放宽之后，每个分布都无穷可微**
> （求导永远合法），但乘法坏了（δ² 不存在）——放宽一处，收紧一处。
>
> GB/T 13745：11057 泛函分析·三级"广义函数论"。家族：[讲透分析](../README.md)·补缺支（2026-09-06 按国标穷尽补建；原为泛函长尾声明"分布"，按国标目录级穷尽原则升支）。

## 诞生

Heaviside 1890s 的运算微积分被当代数学家围剿；Dirac 1930 为量子力学
强行引入 δ；Schwartz 1945 给出严格理论（分布理论）——**1950 年 Fields 奖**，
"为数学物理工作四十年的野路子正名"。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 分布的无穷可微性 | ✅ 已解 | 任意分布可任意阶求导——PDE 弱解理论的通行证 |
| Sobolev 空间理论 | ✅ 已解 | 分布的正则性阶梯——现代 PDE 的度量衡 |
| 结构定理（分布=函数的导数） | ✅ 已解 | 每个分布局部是某连续函数的有限阶导数——"广义"得有限度 |
| 分布的乘法 | ❌ 未解（本质困难） | δ² 无法自洽定义；Colombeau 代数等修补各有代价—— Schwartz 不可能定理（1954）划了边界 |

## 假设与依赖

分布 = **对试探函数空间 C_c^∞ 的连续线性泛函**——一切定义系于"连续"二字
（拓扑线性空间理论）。换试探空间就换理论（缓分布 S′ 配 Fourier 变换——
[调和分析](../讲透调和分析/)的天然接口）。
前置：[泛函分析](../讲透泛函分析/)（拓扑线性空间）、[数学分析](../讲透数学分析/)（分部积分——分布的"分部积分"是定义的发动机）。
