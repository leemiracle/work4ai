# 04 · 转代码：极小化这门手艺的机械化走廊

> **本章回答五问之五（本支：讲透变分分析）。**
> 本支问题→code 的总纲：**"泛函极小"翻译成"损失函数极小"是零成本的
> ——难的从来不是表达，是求解**。可机械化边界由凸性划线：
> 凸线以上全自动（convex solver/DSL），凸线以下半自动
> （一阶方法+局部保证），全局最优无通用算法。

---

## 一、可机械化边界（三档划分）

| 档 | 判据 | 典型 | 机械化程度 |
|----|------|------|-----------|
| **全自动** | 凸+可 prox（近端友好） | LASSO/SVM/SDP/_LP | 写出问题即解出：DSL（cvxpy）编译成锥规划，**多项式时间+全局最优证书** |
| **半自动** | 非凸但光滑/次微分可用 | 深度网络训练、非凸拟合 | 一阶方法保证到驻点/极小值稳定；**无全局证书** |
| **不可机械化** | 一般非凸全局最优 / quasiconvex 判定 / 一般 Γ-极限构造 | 弹性微结构、全局 ML 训练 | NP-难或不可判定；只能松弛/物理实验 |

> **反直觉发现 #1**：三档的边界**不在"问题难不难"上，在"问题的凸性声明
> 能不能被机器验证"上**——cvxpy 的 DCP（disciplined convex programming）
> 规则就是一套"凸性语法检查器"：它能验证的表达式才允许进入。
> **凸分析的定理（组合规则保凸）被编译成了类型系统**——
> 本支是全家族"数学定理变编译器 pass"的最纯样本。

## 二、代码走廊总表

| 走廊 | 数学输入 | 代码化身 | 生态 |
|------|---------|---------|------|
| **凸 DSL** | $\min f(x)+g(Ax)$（凸） | cvxpy/CVXPY-jit、JuMP | 全局最优+证书 |
| **近端分裂** | $\min f+g$（都可 prox） | proximal/ADMM/PRS | scico、POCS 系 |
| **一阶非凸** | 光滑/可路径微 $J$ | SGD/Adam/L-BFGS | JAX/optax/PyTorch |
| **隐微分** | $y=\arg\min$ 层 | implicit diff API | JAXopt(deq)、torchdiffeq 邻域 |
| **有限元** | $J[v]=\int L(Dv)$（变分形式） | FEM 求解器 | FEniCS/Skfem/Feel++ |
| **Γ/均匀化** | 微观能量族 | 多尺度数值/在线松弛 | 学术代码为主（无标准库） |
| **Wasserstein 流** | JKO 步进 | OT 库 | POT、geomloss |

**走廊选择的决策树**：

```
问题自带泛函 J[v]=∫L(Dv) ──是──▶ FEM 走廊（本支正统，见实验）
        │否
J 凸且能写进 DCP 语法 ──是──▶ 凸 DSL（全局证书）
        │否
J = f + g 且 g 有闭式 prox ──是──▶ 分裂法（ADMM/PGD）
        │否
J 光滑或可路径微 ──是──▶ 一阶法（局部保证）
        │
        └─ 都不满足 ──▶ 松弛（凸化/松弛能量）后再走上面某条
```

## 三、三条主走廊详写

### 3.1 有限元 = 直接法的代码化身

变分问题 $J[v]\to\min$ 的标准计算路径（**不是**离散化 PDE，是离散化**泛函**）：

$$\min_{v_h\in V_h} J[v_h],\quad V_h = \text{分片多项式}$$

对 $J[v]=\int(\frac12|v'|^2 - fv)$ 求驻点 ⟹ 线性方程组 $K u = F$
（刚度矩阵=离散 E-L）。**存在性来自直接法（连续层），收敛性来自
Γ-收敛（$J_h\to J$），求解是线性代数（离散层）**——
本支 00/03 章的三层理论在一个 `solve` 里兑现。见 `experiments/direct_method_fem.py`。

### 3.2 梯度下降 = 变分下降流的离散

$$u_{k+1} = u_k - \eta \nabla J(u_k) \;\approx\; \partial_t u = -\nabla J(u)$$

- 能量耗散结构：$J(u_{k+1})\le J(u_k)-\frac{c\eta}{2}\|\nabla J\|^2$
  （凸+适当步长）——**每一步都是一个小型直接法**
- 亚梯度版（$0\in\partial J$）处理非光滑：proximal point
  $u_{k+1}=\mathrm{prox}_J(u_k)$ 是"显式极小一步"，
  **prox 算子=单变量变分问题的闭式解表**（softmax/软阈值/投影……
  每个 prox 都是一道做好的变分小题）
- 随机版（SGD）= 噪声亚梯度流；训练动力学的变分语言
  （01 章方向一的消费侧）

### 3.3 ADMM = 对偶理论的算法化身

$$\min f(x)+g(z)\ \text{s.t.}\ Ax=z \;\Longleftrightarrow\; \text{增广拉格朗日鞍点迭代}$$

x-步/z-步各自是**小变分问题**（常可闭式），对偶变量上升=约束定价。
ADMM 的收敛证明就是 Fenchel 对偶+单调算子理论——
**00 章 §四的对偶语法，逐行翻成了迭代格式**。
分布式 ML 的数据并行/联邦学习的 consensus 形态全是它的变体。

## 四、工程师落点（性能工程视角）

1. **你的训练循环就是变分法**：`loss.backward()` 是 $\nabla J$ 的自动微分，
   Adam 是预条件噪声亚梯度流——读本支=读懂你每天在调的东西的**理论铭牌**
2. **凸层当编译器用**：超参搜索/资源分配/调度这类内层问题若凸，
   用 DSL 拿全局证书，别让它进训练循环
3. **FEM/数值走廊吃 BLAS/LAPACK**：刚度矩阵组装是稀疏算子，
   大规模 FEM 的性能热点=稀疏三角分解与 MPI 通信，
   接 [`../../../讲透高性能计算/`](../../../讲透高性能计算/) 与
   [`../../../讲透GPU与系统级/`](../../../讲透GPU与系统级/) 侧的经验
4. **ADMM 的并行红利**：分裂=天然并行块（x-步/z-步/对偶步），
   多 GPU 的一致性优化里它是老兵
5. 大模型训练的显存/通信优化本质是在改**变分问题的表述**
   （重参数化=换等价能量、梯度检查点=时间-空间换底的松弛）——
   本支语法直接可用的地方比想象多

## 不足层

1. 走廊总表的"Γ/均匀化"行没有标准库——多尺度变分的计算
   仍是论文代码经济，工业级封装缺位
2. 隐微分走廊（deq）的内存/稳定性实践远超理论覆盖（01 章不足层同款）
3. 非凸走廊的"保证"只是驻点级；工程师实际依赖的 landscape 知识
   （batch 大小/学习率热身）在变分理论中没有对应物
4. 自动微分对非光滑函数"能跑但语义错"（Clarke Jacobian vs
   自动选择一个次梯度）——语义正确性工具链刚起步
