# 03 · 可构造与结构：直接法即算法、凸性即刚性、Γ-收敛即正确性

> **本章回答五问之四（本支：讲透变分分析）。可构造？结构？**
> 本支的可构造= **直接法可以离散化执行**（有限元存在性=它的代码化）；
> 本支的结构刚性= **凸性**（局部极小=全局极小的唯一来源）与
> **紧性变现**（存在性定理本质是紧性的期货交易）。

---

## 一、可构造账本：本支逐条盘点

把 00 章 §五的资产逐条做"可构造性审计"：

| 对象/定理 | 可构造性 | 说明 |
|-----------|---------|------|
| 极小化序列 | ✅ 完全可构造 | 任何下降算法都生成它（这是最便宜的一档） |
| 极小元存在性（直接法） | ⚠️ **半构造** | 证明给"收敛子列存在"，不给找它的算法 |
| 极小元的方程（E-L） | ✅ 可构造 | 离散化=有限元方程，线性代数可解 |
| 凸问题的全局极小 | ✅ 可构造+多项式 | prox/内点法，收敛定理完备（下游 [`../../讲透优化/`](../../讲透优化/README.md)） |
| 非凸问题的全局极小 | ❌ 无封闭算法 | 一般 NP-难；只能局部保证或松弛 |
| 对偶最优变量 | ✅（强对偶时） | saddle 迭代/ADMM 的副产物 |
| Γ-极限 | ⚠️ 个案构造 | 恢复序列要手工造（00 章 §五） |
| Ekeland ε-驻点 | ✅ 可构造 | 下降法自动到达（定量版本） |

> **反直觉发现 #1**：本支存在性证明（直接法）与算法（下降法）是
> **同一件事的两个投影**——
> 直接法的三步（下有界/极小化序列/紧性+lsc）恰是下降算法收敛分析的
> 三要素（能量下界/单调下降/聚点论证）。
> **证明即程序**在本支不是口号，是字面事实（Curry–Howard 的变分版）。
> 分裂只在最后一步：证明说"子列收敛到极小"，算法只保证"越来越接近 inf"
> ——**极限点是否可计算**是真正的分水岭（家族 03 章 Specker 折扣的同型）。

## 二、结构：凸性——本支唯一的"全局刚性制造机"

### 2.1 为什么凸性是万恶之源的解药

| 病 | 凸性的药 |
|----|---------|
| 驻点≠极小（非凸多稳态） | 凸：一阶条件=全局最优 |
| 局部极小≠全局极小 | 凸：局部=全局（刚性！） |
| 强/弱拓扑语法不翻译 | Mazur：凸+强lsc⟹弱lsc |
| 对偶间隙 | Fenchel：凸+条件⟹零间隙 |
| 训练景观多如牛毛的假极小 | 凸损失（如 logistic）无此病 |

**凸性的刚性来源一句话**：凸集/凸函数被**支撑超平面**完全外部确定——
"每一点都能被一个全局线性不等式抓住"，局部信息自动全局化。
这是无穷维世界里**最廉价的全局结构**。

### 2.2 凸性之外的结构阶梯（刚性递减）

```
凸 (convex)
  ▼ 松弛
 polyconvex（弹性：行列式项；Morrey）—— 弱 lsc 保住
  ▼ 松弛
 quasiconvex（rank-1 凸包意义；弱 lsc 的充要方向）—— 判定不可计算!
  ▼ 松弛
 rank-1 convex —— 严格更弱（Šverák 反例）
  ▼
 无结构：弱 lsc 失效，极小逃逸/振荡（microstructure 涌现）
```

> **反直觉发现 #2**：quasiconvexity 是弱 lsc 的"正确"条件，
> 但**判定一个函数是否 quasiconvex 是不可计算的**（算法上不可判定，
> 只能对特殊结构验证）——
> **本支最重要的结构性质本身逃出了可计算世界**。
> 弹性微结构（材料科学中观察到的精细振荡解）正是这个不可判定性
> 在物理世界的显影。

### 2.3 结构的第三来源：对称性与 Noether

变分对称性 ⟹ 守恒律（Noether 定理）：力学的时间/空间/旋转对称
给出能量/动量/角动量。结构的刚性也来自对称：
- 极小元的对称性问题（对称的问题是否取对称的解？**否**——
  对称破缺：buckling、Ginzburg–Landau 涡旋）
- 守恒律作为"免费的第一积分"进入数值格式的保结构设计
  （辛/变分积分子，[`../讲透动力系统/`](../讲透动力系统/README.md) 侧接口）

## 三、Γ-收敛：把"收敛性"本身变成结构

Γ-收敛不只是收敛概念，它是**数值正确性的理论形态**：

1. **离散→连续的正确性证书**：有限元/差分格式的极小收敛到连续极小，
   需要的是离散能量族对连续能量的 Γ-收敛（不是逐点收敛！）——
   **数值格式的收敛性证明=一次 Γ-收敛构造**
2. **松弛（relaxation）**：非凸能量的"有效替代品"是其凸/拟凸松弛
   （relaxed energy）——材料计算中真实求解的是松弛问题
3. **均匀化**：微观振荡材料的有效能量=Γ-极限——结构从极限中**涌现**

实验（`direct_method_fem.py`）演示的就是第 1 条的最小实例：
P1 有限元能量族 $\{J_h\}$ Γ-收敛到 $J$（$h\to0$），
所以数值极小 $u_h\to u$——**收敛不是巧合，是结构**。

## 四、结构树：本支对象的三层身份

（接家族 03 章"三身份证"框架，本支变体）

| 层 | 身份 | 代表 |
|----|------|------|
| 空间层 | 自反 Banach（Sobolev $W^{1,p}$, $1<p<\infty$） | 紧性的容器 |
| 泛函层 | 积分泛函 $J[v]=\int L(x,v,Dv)$ | 问题的载体 |
| 结构层 | 凸/quasiconvex + lsc + coercive | 存在性的三个开关 |

三个开关全亮 ⟹ 极小元存在（直接法）；任何一个灭 ⟹ 逃逸/振荡/松弛。

## Python 层

```bash
python3 -u experiments/direct_method_fem.py
```

直接法可执行化：一维泊松能量在加密网格族上离散极小化，
$H^1$ 误差 $O(h)$ 收敛——**存在性证明（直接法）与数值方法（有限元）
在同一个脚本里合体**，Γ-收敛的第 1 条现场可触。

## Lean 层

- 凸分析层（lsc/共轭/次梯度）是 Mathlib 较成熟的分析组件之一
- Sobolev 弱收敛 + 积分泛函 lsc 的直接法全链路形式化尚未完成——
  弹性材料的 polyconvex lsc（Ball 定理）是著名的形式化空白
- Γ-收敛无标准形式化——"收敛概念的收敛"对类型论是高阶抽象挑战

## 不足层

1. quasiconvex 判定不可计算 ⟹ 弹性变分的"可解版"永远是松弛版——
   原问题与求解问题**系统性错位**
2. 直接法的收敛子列在算法上不可提取（无有效的子列选择器）——
   半构造的"半"字在计算复杂度意义上比直觉更严重
3. 凸性的刚性太贵：现实问题（深度学习）非凸，本支定理只能
   提供"比喻层"（能量景观）而少提供"定理层"
4. Noether/保结构变分积分子与一般变分理论的两套文献严重分居
