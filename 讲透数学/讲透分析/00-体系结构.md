## 二、相互喂养图（家族内的依赖经济）

```
数学分析 ──给语言──▶ 全家（ε-δ 是方言基础）
实分析 ──测度──▶ 调和(积分变换) / 动力系统(遍历测度)
复分析 ──解析工具──▶ 调和(边界值) / 数论(跨界)
泛函分析 ──空间语言──▶ 调和(算子插值) / PDE(弱解) / 数值(格式收敛)
调和分析 ──分解技术──▶ PDE(Strichartz) / 概率(跨界)
变分分析 ──直接法──▶ PDE(弱解存在性) / 优化(凸分析桥)
动力系统 ──定性论──▶ PDE(长时间行为)
数值分析 ──消费一切──▶ 把全家的定理变成可跑代码
分析进阶 ──编年统读──▶ Fourier→复→实→泛函的历史缝合线
```

**一句话经济**：数学分析卖方言，实分析卖测度，泛函卖空间，调和卖分解，
变分卖存在性，PDE 卖战场，数值卖兑现。

## 三、家族内循环的三个枢纽定理（跨支血液）

1. **完备化**：ℚ→ℝ（数学分析/实分析）→ L² 完备化（泛函）→ 每一步都是同一个动作
   （03 章实验把 ℝ 本身做成代码）
2. **对偶性**：Riesz 表示（泛函）⟷ Plancherel（调和）⟷ 弱形式（变分/PDE）——
   "换边站"是家族通用战术
3. **紧性**：Heine-Borel（数学分析）→ Arzelà-Ascoli（变分）→ Banach-Alaoglu（泛函）——
   紧性 = 把无穷压回有限的家族信条
