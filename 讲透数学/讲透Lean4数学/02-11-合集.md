## 02 - 类型论最小入门

### 依赖类型论（Lean 的基础）

- `Prop`：命题（Type universe 0）
- `Type u`：类型层级（universe）
- `Π x : A, B x`：依赖函数类型
- `Σ x : A, B x`：依赖对类型

### Curry-Howard 对应

| 逻辑 | 类型论 |
|------|-------|
| 命题 $A$ | 类型 $A$ |
| $A \to B$ | 函数类型 |
| $A \wedge B$ | 积类型 $A \times B$ |
| $A \vee B$ | 和类型 $A \oplus B$ |
| $\forall x, P(x)$ | `Π x, P x` |
| $\exists x, P(x)$ | `Σ x, P x` |
| 证明 | 程序 |

**反直觉**：证明 = 程序。证 $\forall n, P(n)$ = 写一个接受 $n$ 返回 $P(n)$ 证据的函数。

### 应用

- 理解 Lean 的错误信息
- Mathlib 的设计哲学

## 04 - 数学 tactic 速查

### 基础（你已会）

`intro / apply / exact / rw / simp / rfl / induction`

### 进阶（本章新）

| Tactic | 作用 | 例子 |
|--------|------|------|
| `ring` | 证多项式等式（交换环）| `2*x + 3*x = 5*x` |
| `linarith` | 线性算术 | `a < b, b < c → a < c` |
| `nlinarith` | 非线性 | `a*b ≤ (a+b)^2/4` |
| `polyrith` | 用 polyhedra 证 | 进阶 |
| `decide` | 用 decision procedure | 有限情况 |
| `norm_num` | 数值计算 | `2 + 2 = 4` |
| `omega` | Presburger 算术 | 整数线性 |
| `mv_biwedge` / `aesop` | 自动化 | 大型 |

### 反直觉

`ring` 解决几乎所有"显然"的代数等式（哪怕看起来复杂）——它是 Lean 数学的"瑞士军刀"。

## 05 - 在 Lean 里做集合论

### Set 类型

```lean
def Set (α : Type*) := α → Prop
```

集合 = 谓词。$x \in S$ = `S x` 成立。

### 操作

- `S ∪ T`：`fun x ↦ S x ∨ T x`
- `S ∩ T`：`fun x ↦ S x ∧ T x`
- `Sᶜ`：`fun x ↦ ¬ S x`

### 经典定理

```lean
example : ∀ S : Set α, (Sᶜᶜ) = S := by
  ext x; simp

example : ∀ S T : Set α, S ∩ T = T ∩ S := by
  ext x; simp [and_comm]
```

### 反直觉

De Morgan：$(S \cup T)^c = S^c \cap T^c$。在 Lean 里用 `simp` 自动证。

## 09 - 给 Mathlib 提 PR

### 流程

1. Fork `mathlib4`（GitHub）
2. `git clone` + `lake build`
3. 改代码 + 测试
4. `git push` + 提 PR
5. Reviewer review（可能 3-5 轮）
6. 合并

### 风格

- 遵守命名约定（`mathlib-naming`）
- 加 `@[simp]` / `@[mono]` 标签
- 写 docstring
- `lint` 通过

### 第一 PR 建议

找 `good first issue` 标签的 issue。或自己加一个数学 lemma。

## 11 - 形式化项目实战

1. 选一个数学论文 / 教材
