# 04 · 应用数学转代码：SciML 全栈与 V&V 文化

> **本章回答五问之五：怎么将该领域的问题转换为 code 问题？**
> 应用数学的"转代码"有六层现代栈——从 60 年前的数值库到 2024 年的 PDE 基础模型，
> 每一层都对应 00 章三环的一环。本章同时给出这门手艺的**验收文化**（V&V）
> 与**边界清单**（哪些问题原则上算不动）。

---

## 一、六层转换栈（按年代叠起来的地层）

| 层 | 年代 | 转换方式 | 对应三环 | 代表 |
|---|------|---------|---------|------|
| ①数值库 | 1960s- | 方程→离散代数（FDM/FEM/谱），Lax 发照 | 计算 | LAPACK/FFTW/FEniCS |
| ②符号计算 | 1970s- | 演算→代数重写（量纲检查/摄动展开自动化） | 分析 | sympy/Mathematica |
| ③自动微分 | 2018- | **一切可微**：格式/仿真器对参数可导 | 计算×建模 | JAX/PyTorch |
| ④PINN | 2019- | PDE→损失函数（残差用 autodiff 算） | 建模×计算 | Raissi-Perdikaris-Karniadakis |
| ⑤算子学习 | 2021- | 解一个方程→学一族方程的映射 | 建模×计算 | FNO/DeepONet |
| ⑥PDE 基础模型 | 2024- | 预训练底座+微调到新方程族 | 全环 | Poseidon/DPOT（01 章） |

> **反直觉发现 #1**：③是地层翻转的震源——
> 传统栈里"求导"是手艺（格式推导全靠人），JAX 把求导变成**免费商品**，
> 于是④⑤⑥全部成为可能。**一次基础设施降价，催生三代范式**——
> 与编译器之于软件工程、GPU 之于深度学习同构。

## 二、逐层速写

### ②符号层：本章方言的机器化

量纲检查（pint/sympy.units——"单位类型系统"的编译器）、
摄动展开自动化（sympy 逐阶代入）、渐近验证（级数与数值解在重叠区对表）。

### ③自动微分层：可微仿真

格式对参数 θ 可导 ⟹ **反问题=梯度下降**（参数辨识、形状优化、
数据同化——AI 天气的训练底座就是把整个大气模式写成可微程序）。

### ④PINN：PDE = 损失函数

```
L(θ) = Σᵢ‖R[u_θ](xᵢ)‖²  +  ‖u_θ−g‖²_边界  +  ‖u_θ−u₀‖²_初值
        └── 残差：R = PDE 左右两边之差，u 的导数由 autodiff 给
```

（实验 `04_physics_informed.py` 是**裸核版**：多项式基+最小二乘，
没有神经网络——先看清"物理进损失函数"这一步本身，再谈 N。）
**已知病灶**：谱偏差（高频学不好）、训练非凸、精度难敌 FEM——
01 章的诚实面在此落地。

### ⑤⑥算子层与基础模型层：见 01 章（方向二/三）

工程要点：离散不变性换网格自由、预训练摊薄成本、
**代价是失去逐层误差控制**（FEM 有后验误差估计，算子模型没有——V&V 的洞）。

## 三、验收文化：V&V——转代码之后必须回答的两问

| | Verification 验证 | Validation 确认 |
|---|------------------|-----------------|
| 问 | **代码解对了方程吗** | **方程描述了世界吗** |
| 手段 | 收敛阶测试、守恒律监测、MMS（制造解法） | 与实验对表、外推检验、盲测 |
| 陷阱 | 把 validation 的失败当 bug 调 | 把 verification 的失败当模型缺陷 |

> V&V 是应用数学对"all models are wrong, some are useful"的工程回应：
> **分开记账**——代码的错、离散的错、模型的错、数据的错，四本账。
> ML 侧的 train/test 分账只是它的弱化版（没有离散误差账本——⑥层的治理缺口）。

## 四、边界：哪些算不动（原则性，不是工程性）

1. **维数诅咒**：网格点数 ∝ d 维指数——高维 PDE（量子多体、定价）传统方法死刑，
   正是算子学习/蒙特卡洛的地盘（但误差分析换了个更弱的形态）
2. **混沌**：误差按 Lyapunov 指数倍增——**长 horizon 逐点预报原则性不可能**，
   AI 天气的解法是改问集合概率（GenCast 一类生成式集合）——改问题而非解问题
3. **刚性**：显式格式步长被最快尺度绑架——隐式格式解线性方程赎身（账单：[`../讲透数值线代/`](../讲透数值线代/)）
4. **湍流闭合**：尺度分离失败的地方（Re 大到无级可摄动）——百年未决，
   机器学习参数化（NeuralGCM 的 learned physics）是"用数据补结构"的豪赌
5. **不适定**（03 章）：任何算法都救不了，只能正则化改问题

## 五、Python 层：四实验归位

```bash
python3 -u experiments/04_physics_informed.py   # PINN 裸核：−u″=f 的物理知情最小二乘
```

基函数 φₖ=x(1−x)xᵏ（边界条件编码进基——与 PINN 把边界写进损失同思想）、
配点最小二乘、导数**手推**（autodiff 的替身——诚实注记），
与精确解 sin(πx) 对照，误差随基数衰减。
