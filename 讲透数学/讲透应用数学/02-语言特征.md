# 02 · 语言特征：渐近记号、量纲代数与"estimate-justify"文化

> **本章回答五问之三（表达？逻辑？规范化？）。**
> 应用数学有一门自己的方言：**渐近记号**（O/o/~/≪）管表达，
> **量级论证**管逻辑，**无量纲化**管规范化——
> 三件套合起来，让应用数学家"不解方程先知道答案"。

---

## 一、表达：渐近记号——一门按"精度等级"说话的语言

### 1.1 五个符号的方言表

| 记号 | 读法 | 精确含义 | 方言用法（日常口语级） |
|------|------|---------|----------------------|
| f = O(g) | 大 O | \|f\| ≤ C\|g\|（常数 C） | "同量级或更小"——误差的**帽子** |
| f = o(g) | 小 o | f/g → 0 | "小到可以扔" |
| f ~ g | 渐近等价 | f/g → 1 | "领头阶就是它" |
| f ≪ g | 远小于 | （口语）o 的文学化 | "没得比" |
| f = g + O(h) | 带余项 | f−g = O(h) | "精确到 h 这一层" |

> **反直觉发现 #1**：这门语言里 "=" **不对称**——
> x = O(ε) 与 O(ε) = x 后一句根本不是话。等号在这里是"属于误差类"的**单向断言**。
> 第一次读 Bender-Orszag 的人都会被这个语法坑——它是集合成员关系披了等号的外衣。

### 1.2 语言的表达力：说误差就像说天气

同一句话的纯数学版与应用数学版对照：

- 纯数学："对充分小的 ε 存在 δ(ε) 使…"
- 应用数学："x(ε) = 1 − ε + 2ε² + O(ε³)，所以 ε=0.01 时精确到 10⁻⁶"

后者**信息密度更高**：不只说收敛，还说**每多算一项买多少精度**——
渐近级数是"精度菜单"：第 n 项标价 εⁿ（实验 `02_asymptotics.py` 实测这个标价）。

### 1.3 表达的边界

| 想说 | 能说吗 | 备注 |
|------|--------|------|
| 领头阶形态 | ✅ ~ | 量纲+dominant balance 主场 |
| 误差定量 | ✅ O(εⁿ) | 但常数 C 通常未知——"O 的常数是哑谜"是方言内笑话 |
| 非渐近区域 | ❌ | ε~1 时 O 记号哑火——纯数学接管 |
| 混沌/长期行为 | ❌ | 渐近是局部的，长时行为归稳定性/遍历论 |

## 二、逻辑：estimate-justify——不是"证明"的证明文化

### 2.1 与定理-证明文化的对照

| 维度 | 纯数学证明 | 应用数学 justification |
|------|-----------|----------------------|
| 目标 | 真理确证 | **可信度构筑**（哪项可信多少） |
| 材料 | 公理+推理规则 | 量级比较+数值证据+物理直觉+渐近论证 |
| 产物 | QED | "consistent to leading order" |
| 失败模式 | 反例 | **误差失控区标注**（"ε<0.1 内可信"） |

**核心操作三连**：
1. **量级估计**：方程各项谁主谁次（dominant balance）
2. **自洽检验**：假设 ε≪1，解出来验证残差确实 O(ε²)——**假设吃自己的狗粮**
3. **交叉验证**：渐近解 ↔ 数值解在重叠区对表（实验 02 正是这个动作）

> **反直觉发现 #2**：这个文化的最强武器是 **toy model**——
> 故意简化到"错"的模型（无粘性、二维、线性化）却是论证的核心组件。
> 逻辑地位：toy model 是**反例的镜像**——纯数学用反例划边界，
> 应用数学用 toy model 划"机制的边界"：在 toy 里成立的机制，
> 才值得在完整模型里找。Strogatz 全书就是这个写法。

### 2.2 validity（有效性）≠ rigor（严格性）

应用数学的"真"有四级：
1. 量纲有效（单位对）→ 2. 量级有效（主导平衡对）→
3. 渐近有效（误差序对）→ 4. 严格有效（证明在）
**每升一级成本跳一档，需求常止步于 2-3 级**——这不是懒，是工程判断：
风洞实验等不了 Navier-Stokes 的存在性证明。

## 三、规范化：无量纲化——单位即类型系统

### 3.1 Buckingham π 定理（规范化主菜）

> n 个有量纲量、k 个独立基本量纲 ⟹ 物理定律只依赖 **n−k 个无量纲群**（π 群）。

摆的问题：T, L, m, g（n=4），量纲 T, L, M, L/T²（k=3）⟹ **只剩 1 个 π 群** ⟹
T = √(L/g)·Φ(θ₀)——周期公式中 √(L/g) 这个因子**不做任何动力学就知道**。

### 3.2 单位=类型（给系统工程师的桥）

> **反直觉发现 #3**：量纲同质性检查 = **类型检查**。
> 加法两边类型必须相同（3 米 + 5 秒 编不过）；函数对参数类型敏感
> （sin 只吃无量纲数——sin(t) 若 t 有量纲，方程"编译不过"）；
> e^x、log x 的参数必须无量纲——**超越函数是"无量纲类型专属方法"**。
> 工程版实现就是 `pint`/sympy.units 的单位检查器（04 章练习）。
> 应用数学家心算单位，就像 ML 工程师心算 shape——**同一门手艺的两个方言**。

### 3.3 无量纲化的三重收益

1. **消假参数**：参数个数从 n 降到 n−k，自由度坍缩
2. **暴露小参数**：Reynolds 数 Re、Péclet 数…都是"两个效应的比值"——
   ε=1/Re 就是摄动展开的入口（03 章边界层）
3. **相似律**：模型实验与真实对象 π 群相等 ⟹ 水槽里的 1:100 桥梁可信——
   **整个风洞/水洞实验工业建立在这条定理上**

python3 -u experiments/02_asymptotics.py

摄动解与精确解对照、**误差按 O(εⁿ⁺¹) 标价实测**（log-log 斜率 = 误差阶数）、

## 五、Lean 层

渐近记号的机器化：Lean/Mathlib 有 `Asymptotics` 模块（`IsBigO`/`IsLittleO`/`IsTheta`）——
方言已进形式化词典；但"量级估计的证明策略"仍是研究前沿（04 章边界）。

## 六、不足层（诚实清单）

1. **O 记号的常数不可见**——工程上常数 10 与 10⁶ 天壤之别，方言对它装聋
2. **estimate 文化可被滥用**——"看起来对"到"证明对"的距离常被低估（湍流模式论的教训史）
3. **无量纲化不唯一**——π 群的选法是艺术，选错群=白忙
4. 本章的"类型系统"类比有边界：单位代数无子型/多态，比真类型系统贫瘠得多
