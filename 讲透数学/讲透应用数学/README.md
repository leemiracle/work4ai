# 讲透应用数学 · 方法论总纲（量纲、渐近、适定性与它们的时代）

> 应用数学不是"数学的应用"——它是一门有独立手艺、独立语言、独立审美观的学科。
> 纯数学问"什么是真的"，应用数学问**"什么是可算的、什么是可估的、什么是稳的"**。
>
> 定位：本系列是宇宙**应用书架的方法论总纲**——
> 优化/数值线代/信息论/博弈论/数学建模各是一门工具，本系列讲用工具的人的**手艺**：
> 量纲分析、渐近展开、摄动方法、适定性、稳定性、尺度结构——外加这些手艺在
> 2021-2026 被 SciML（科学机器学习）重写的现场。

## 〇、这个系列回答什么

- 为什么应用数学家看一眼方程就能说出解的量级、形态、会不会爆？（量纲+渐近+稳定性的三连直觉）
- "适定"（well-posed）到底是什么？为什么不适定的问题连数值方法都救不了？
- 摄动级数不收敛为什么还能用？（渐近级数——发散但前几项神准）
- 2021-2026：PINN → 算子学习 → PDE 基础模型 → AI 气象业务化——应用数学的地基被 ML 重挖了一遍？
- V&V（验证与确认）：模型永远错，为什么还能用？

## 二、实验脚本（experiments/）

| 文件 | 用途 | 状态 |
|------|------|------|
| `experiments/00_dimensional_pendulum.py` | Buckingham π 定理从单位推摆周期 T∝√(L/g)，再用 RK4 数值验证指数 0.5——"不解方程先知道答案" | ✅ |
| `experiments/02_asymptotics.py` | 正则摄动解 εx²+x−1=0 与精确解对照、误差按 O(εⁿ⁺¹) 实测；Richardson 外推把有限差分从 2 阶抬到 4 阶 | ✅ |
| `experiments/03_wellposedness.py` | 热方程正向（适定）vs 反向（Hadamard 不适定）：高频小扰动一个衰减一个指数爆炸——数值实拍 | ✅ |
| `experiments/04_physics_informed.py` | "PINN 去掉 N"：物理 informed 最小二乘解 −u″=f（多项式基+配点），与精确解对照误差谱 | ✅ |

## 四、教材锚点

- **天书级**：Lin & Segel《Mathematics Applied to Deterministic Problems》（应用数学的圣经，Courant 传统）
- Bender & Orszag《Advanced Mathematical Methods for Scientists and Engineers》（渐近方法的狂欢）
- Strogatz《Nonlinear Dynamics and Chaos》（稳定性与分岔的最好入门）
- 前沿线：SciML 论文群（01 章文献表：PINN/FNO/Poseidon/AIFS）
