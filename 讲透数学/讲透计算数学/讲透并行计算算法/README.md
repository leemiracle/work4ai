# 讲透并行计算算法 · 一万张卡上的数学

> GB/T 13745 11061 三级「并行计算算法」
> 定位句:这支负责**规模的最后一公里**——任何单机算得动的算法都不是终点;并行算法研究"把一个数学问题拆给一万张卡"之后,通信、同步与不确定性如何重塑算法本身。

## 诞生

📖 两场革命催生这支:①1980s 超级计算机向量化(Seymour Cray:"任何人都可以造一台快计算机,难的是造一台**能并行**的");②1990s MPI 标准化+消息传递模型定型。标志性思想:**域分解**(Schwarz 交替法 1870 年的数学,1980s 被重新发现为并行求解 PDE 的天然切法)——百年前的纯数学直接变成万卡架构。

## 核心问题

已解决:
- 并行模型与复杂度:BSP(logP)、通信复杂度下界(数据要搬家,带宽是硬通货)
- 并行归约/扫描(scan)的树形结构:O(log P) 深度
- 并行迭代法:块雅可比/加性 Schwarz/代数多重网格(AMG)的伸缩性理论
- 大规模特征值:Lanczos 并行化;随机 SVD 的分块分布式版本

未解决/前沿:
- 强伸缩(strong scaling)的极限:Amdahl 定律的串行尾部不可消除
- 异步迭代的收敛与一致性(参数服务器/异步 SGD 的理论保证仍是半经验)
- 逐位确定性 vs 吞吐的统一谈判(见家族 04 章"确定性税")
- 通信规避算法(communication-avoiding):能否少搬家多算?

## ✨ 这支最美的一个事实

**通信与计算的物理学对偶**:在真实超算上,搬一个数到隔壁卡的能耗≈在本地做一万次浮点乘法。所以并行算法设计的黄金律不是"多算少算"而是"**算了别搬**"——数学复杂度从此要用焦耳重写(亲历:写矩阵乘分块实验,比较通信量随块大小变化的总耗时)。

## 假设与依赖

- 部分失败与乱序执行假设:并行世界没有原子性免费午餐→归约顺序不定=结果不定(与家族 02 章"无结合律"联手)
- Amdahl(1967)/Gustafson 定律是规模预测的两条宪法
- 依赖:图论(任务 DAG)、线代(分块)、体系结构(兄弟宇宙 HPC/GPU)
