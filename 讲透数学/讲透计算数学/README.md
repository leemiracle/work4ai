# 讲透计算数学 · 误差的科学与艺术

> **本质一句话**:计算数学=把连续数学变成可执行、并且**知道错多少**的学问——它不问"这个定理真不真",它问"这个算法算出来的数,离真值有多远,凭什么"。
> GB/T 13745-2009:11061 计算数学(三级 14 条:6 支新建落子,其余就地/归属)。
> 家族=讲透系列成员;五问五章为家族总纲,支系列各自由宪法 README 起步。

## ⚠️ 消歧框:讲透计算数学(11061) vs 讲透计算机数学(11085)

两个名字只差两个字,内容分属两条国标代码——见 [`../GB-T13745全景.md`](../GB-T13745全景.md) §三:

| | 讲透计算数学(本家族,11061) | 讲透计算机数学(11085) |
|---|---|---|
| 问的问题 | **算得准不准、快不快**(给定一个数学问题,怎么数值地解) | **什么可算、怎么保证对**(可计算性/算法分析/程序验证) |
| 招牌词 | 条件数、稳定性、收敛阶 | 停机问题、大 O、形式验证 |
| 消费关系 | **消费**后者(可计算性划定它能做的边界) | 为前者提供理论地基 |
