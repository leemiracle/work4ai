# 讲透误差分析与区间算法 · 把不确定本身变成数

> GB/T 13745 11061 三级「误差分析与区间算法」(原名:误差分析)
> 定位句:这支是全家族的**公尺工坊**——别支问"怎么算",这支问"算出来的数凭什么可信":向前/向后误差的语言在这里锻造,而区间算术更进一步,让误差自己参加运算,算完即证书。

## 诞生

📖 1963 年,Wilkinson《Rounding Errors in Algebraic Processes》把舍入误差从工程烦恼升格为数学对象;三年后(1966),Ramon Moore 的《Interval Analysis》走得更远:既然每个数都带误差,那就把"包含真值的区间"本身定义成一种数,规定区间四则——**不确定不再被分析,而被计算**。两本书,一支的两个半场。

## 核心问题

已解决:
- 向后误差框架:算法=精确解某个邻近问题;前向误差≤κ·η 的标准分解
- 区间算术的包含单调性:任何浮点区间运算结果必含真值区间
- 有效数字的丢失规律:相近数相减(灾难性消去)的定量刻画
- Kahan 补偿求和:误差从 O(nε) 压到 O(ε)

未解决/前沿:
- 区间宽度爆炸(依赖问题/包装效应):区间算术常把"其实很准"算成"巨宽"——宽度控制仍是手艺
- 验证式计算(verified computing)与浮点 SMT 可满足性(UINT)结合(2021-2025 活跃)
- 神经网络的误差证书:NN 与区间/抽象解释的融合尚无成熟理论

## ✨ 这支最美的一个事实

区间算术的除法必须定义成 [a,b]÷[c,d](含 0 时发散/裂成两支)——因为区间是一个**集合**,运算要对集合里一切可能负责。一旦接受这个观点,"数"的定义被永久拓宽:一个数可以是一个保证包围真值的盒。验证式计算、计算机辅助证明的精度根基全在这一步(亲历:mpmath.iv 算 √2,读区间宽度自报精度)。

## 假设与依赖

- IEEE 754 的舍入方向(向外)= 区间算术的合法性来源(下界向下舍、上界向上舍)
- 最坏情况框架:包含保证是 ∀ 的,代价是宽度保守
- 依赖:浮点系统协议(家族 02 章)、分支定界(与符号计算/验证接壤)
