# 讲透随机数值方法与统计计算 · 用随机性对付高维

> GB/T 13745 11061 三级「随机数值方法与统计计算」(原名:随机数值实验)
> 定位句:这支负责**维数诅咒的第一出口**——确定性方法点数随维数指数爆炸,随机方法的误差却只看 √N:用掷骰子换高维通行证。

## 诞生

📖 1946 年,洛斯阿拉莫斯。Stanislaw Ulam 病中玩单人纸牌,反复"玩一把数一数"估算成功概率,突然意识到:对算不动的量,模拟它几次也许是最快的算法。他与 von Neumann 把这个想法装进刚通机的 ENIAC,给中子输运问题做模拟——蒙特卡洛(Monte Carlo,以摩纳哥赌场命名)诞生。随机数从此成为一种**计算原语**。

## 核心问题

已解决:
- MC 误差定律:σ/√N 与维数无关(Ulam-von Neumann);方差缩减(重要性采样/对偶变量/分层)
- MCMC 可用性:Metropolis(1953)/Hastings(1970)给出一般构造;Gibbs 采样(1984)
- 拟蒙特卡洛:低差异序列(Kronrod/Sobol)在有效维数低时全面胜出随机点
- 美之事实:σ/√N 意味着"精度翻十倍,代价×百"——慢但**公正**:对任何维数一视同仁

未解决/前沿:
- MCMC 混合时间的可验证判据(实际能跑≠证明收敛)
- 高维贝叶斯反演的维度自适应采样
- 随机化线性代数(RandNLA)的精度-速度最优权衡

## ✨ 这支最美的一个事实

importance sampling:在"重要的事件"上多撒点,误差可以从 σ/√N 的 σ 上动手脚——选对分布,同样的样本量精度翻数倍。**随机不是躺平,是排兵布阵**(亲历:用均匀采样 vs 重要性采样估计 E[e^{-X²}] 在尾部贡献下的差异)。

## 假设与依赖

- 独立性/马尔可夫性假设换来大数定律的护航;偏离(相关样本)→有效样本量缩水
- 伪随机数发生器的周期与统计品质是全部合法性的地基(先有可靠骰子,再谈赌术)
- 依赖:概率论(大数定律/马尔可夫链)、统计计算(Bootstrap 等,通应用统计数学家族)
