# 02 · 语言特征:计算数学说什么方言

> **本章回答五问之三:表达力?逻辑性质?规范化程度?——三栏作答,每栏先答"为什么是这样"。**
> 概念呈现三步法贯穿全章:每个概念先给直觉图像,再给严格陈述,再给最小例子。

## 开篇:一个学科的宪法写在硬件手册里

数学的各分支里,有一门学科的"语言规范"不在教材里,而在一份**电气与电子工程师学会的标准文档**里——IEEE 754(1985 年首次发布)。任何一台计算机上的任何一次浮点加法,都要遵守这份标准对"数的格式、舍入的方向、异常的行为"的逐 bit 规定。换言之:计算数学是唯一一个**语言被工业标准规范化到 bit 级**的数学分支。为什么?因为它的读者不只是数学家,还有硅——两亿颗芯片按同一份规格出厂,数学方言必须先变成协议。这一章讲这个方言的三个侧面。

## 一、表达力:这个方言能说什么、不能说什么

**为什么是这样**:计算数学的目标不是描述理想对象,而是描述**"理想对象与机器表示之间的落差"**——所以它的语句天然带误差量词,它的结论天然是"区间里的真"而非"点上的真"。

**能说的(表达力强项)**:
| 语句类型 | 标准形式 | 直觉图像 |
|---------|---------|---------|
| 误差界 | ‖x̂−x‖ ≤ C·h^p·(条件项) | "答案在真值周围半径 C·h^p 的球里" |
| 收敛阶 | ‖e_{k+1}‖/‖e_k‖^p → c | "每迭代一步,误差自乘 p 次方"(p=2 牛顿:错 0.1→错 0.01→错 0.0001) |
| 复杂度 | 乘法次数 ~ (9/2)n³ | "规模的账单" |
| 稳定性 | 向后误差 η(â) = ‖r‖/‖A‖‖x̂‖ 小 | "算的是近处某个问题的精确解" |
| 包含性(区间) | x ∈ [a,b](机器自证) | "真值在盒子里,盒子是算出来的" |

**不能说的(表达力盲区)**:
- **具体常数**:最坏情况界的常数 C 常大得离谱,实际误差好千百倍——方言会说"≤10⁶",实际是 10⁻³。会说界,不会说"实际"。
- **"哪个算法对我的问题最好"**:没有定理替你选算法——选择靠经验规则+试算(这是 04 章走廊清单存在的原因)。
- **超出现范围的现象**:混沌系统长期行为、逐位可复现性,在最坏情况框架里几乎说不出有意义的话。

**三步法示例——条件数**:直觉图像(把输入轻轻推一下,输出摔多远;地陷区vs平地)→ 严格陈述(‖δx‖/‖x‖ ≤ κ(A)·‖δb‖/‖b‖,κ=‖A‖‖A⁻¹‖)→ 最小例子(Hilbert 5 阶:κ≈10⁵,b 扰动 10⁻⁸,解动 10⁻³——放大一万倍)。

## 二、逻辑性质:条件句文化与它的可判定性边界

**为什么是这样**:数值定理要在机器上兑现,前提必须**可验证或可假设成立**——所以本方言的定理几乎全是条件句:`IF(稳定 ∧ 相容) THEN 收敛`。纯数学的"存在定理"在这里必须改写成"构造+误差证书"才有意义。

**三大逻辑特征**:

1. **等价定理是宪法级语句**。Lax–Richtmyer 等价定理(1956,线性发展方程):对相容的有限差分格式,**收敛 ⟺ 稳定**。一个"⟺"值一座金矿:不必直接证收敛(难),证稳定(可操作)即可。这解释了方言的形状——大家都在练"证稳定"的手艺,因为等价定理担保它通兑。
2. **不等式文化,最坏情况逻辑**。一切界对一切输入成立→量词是 ∀;而实用结论常来自实验(∃ 一个好例子)。理论界与工程实践的张力是本方言的日常。
3. **不可判定性照样埋伏在门口**。并非一切都可机械化判定:例如,一般矩阵序列的数值稳定性、某些迭代格式的全局收敛性,可以归约到不可判定问题;浮点运算的可满足性判定(UINT 方向,2021-2025 活跃)甚至成为 SMT 求解器的新前线(与 [`../讲透数理逻辑/`](../讲透数理逻辑/)·递归论支、SAT 求解器文化接轨)。方言的边界由可计算性划走——这正是 11085(计算机数学)为 11061(计算数学)守门的地方。

**反直觉发现(本章招牌)**:**"快而稳定"可以胜过"慢而准"**。直觉上精度高的方法更可靠;实际中,带部分主元的高斯消去**向后稳定**(算的是附近问题的精确解)但**前向误差**被条件数放大;而某些"更精确"的格式不向后稳定,反而在病态问题上雪崩。→ 教训以定理形式落地:**稳定性优先于精度**——先保证解的是"某个近处的问题",再谈那个问题离目标多远。配套反直觉:(0.1+0.2)+0.3 ≠ 0.1+(0.2+0.3) 在 IEEE 754 下成立——**结合律失效**,这是方言的第一课生词。

## 三、规范化程度:从公理到 bit

**为什么是这样**:别的分支规范化到"公理系统"为止(ZFC、群公理);计算数学被规范化到**协议层**——因为它的话要被硬件执行,而硬件是全球分布制造的。

**规范化的四级阶梯**:
| 级 | 规范 | 内容 |
|---|------|------|
| 数学层 | 向后误差框架 | Wilkinson 1963:"精确解了哪个附近问题"的标准问法 |
| 协议层 | IEEE 754(1985;2008/2019 修订) | 数的格式/五种舍入方向/NaN 语义/次正规数 |
| 软件层 | BLAS 三级接口(1990) | 矩阵运算的"插座"标准:LAPACK、NumPy、cuBLAS 说同一种插座语言 |
| 基准层 | LINPACK→HPL→TOP500(1993-) | "算得快"的全球公尺:每半年世界超算排名=解一个 n 阶线性方程组 |

一个思想实验体会规范化之深:你可以买两台不同厂商的机器,用不同语言各写 `(0.1+0.2)==0.3`,它们会**一致地**返回 False——数学方言被硅统一到了这个程度。代价同样真实:规范锁死了浮点语义,GPU 为了吞吐引入非确定性归约,就要在"遵守标准"与"统计复现"之间重新谈判。

**规范化带来的独特文化**:benchmark 文化(LINPACK/NAS/HPCG)——数学分支里只有计算数学用"公开打榜"推进学科;打榜催生的方法学(稀疏化、分块、通信避免)又反哺理论。这是方言的另一个稀有特征:**它的进度条是全球联网可见的**。

## 四、三栏合账

| 栏 | 一句话 | 为什么是这样 |
|---|--------|-------------|
| 表达力 | 说得出"误差多大、收敛多快",说不出"实际多准、该选哪个算法" | 面向最坏情况的语言天生悲观,选择问题不存在定理 |
| 逻辑性质 | 条件句文化:IF 稳定∧相容 THEN 收敛;等价定理把难证折兑成可证;边界处有不可判定性 | 机器兑现要求前提可操作;可计算性为它划界 |
| 规范化 | 公理→协议→接口→基准,四级;唯一被规范到 bit 级的数学分支 | 读者包括硅;全球制造的硬件需要同一份数学方言说明书 |
