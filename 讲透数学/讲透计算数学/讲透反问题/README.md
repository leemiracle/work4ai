# 讲透反问题 · 从果推因的病态世界

> GB/T 13745 11061 三级「反问题计算方法」
> 定位句:这支负责**因果箭头的反转**——正问题由因推果(模型→数据),反问题由果推因(数据→模型);反转天然病态(信息被物理过程磨掉了),这支的手艺是用正则化把"不可救"变成"可赎"。

## 诞生

📖 1905 年,Hadamard 给"适定性"立法:解存在、唯一、连续依赖。然后他亲自找到一个"不适定"的例子并断言此类问题**没有物理意义**——历史开了个玩笑:CT 扫描(反散射)、地震勘探(反演)、图像去模糊,全是 Hadamard 判过死刑的问题。1950-60 年代苏联学派(Tikhonov、Ivanov、Lavrentiev)为它们发明正则化,1977 年 Tikhonov 正则化理论成熟——**被判死刑的问题成了医学与工业的心脏**。

## 核心问题

已解决:
- Tikhonov 正则化 min‖Ax−y‖²+λ‖Lx‖²:谱滤波 σ/(σ²+λ) 的收敛理论
- 正则化参数选择三法则:偏差原理、L 曲线、广义交叉验证(GCV)
- 迭代正则化:Landweber/CG 早停的半收敛现象(迭代次数本身即正则化参数)
- 贝叶斯反演框架:正则化=先验分布,后验=正则化解的统计版

未解决/前沿:
- 非线性反问题的局部极小与多解性(全局反演仍是硬骨头)
- 不确定性量化(UQ):反演解的置信集如何高效构造
- 深度先验:用网络学先验替代手工正则(learned regularizer)——理论保证缺口

## ✨ 这支最美的一个事实

正则化的谱视角:病态算子的奇异值从大到小排成一列楼梯,楼梯尽头的小 σ 方向把噪声放大成海啸;Tikhonov 滤波 σ/(σ²+λ) 恰好给每个方向配一张闸门——大 σ 全过、小 σ 全拦,**一张光滑的单调闸门曲线同时解决"保信号、拦噪声"**(亲历:跑家族实验 `experiments/00_tikhonov.py`,看 λ 扫描中误差的 U 形谷:欠正则与过正则的两头都是悬崖)。

## 假设与依赖

- 先验信息假设(光滑性/稀疏性/统计分布)——没有先验,反问题在数学上无解可救;正则化=把先验写成罚项
- 噪声模型假设(随机?有界?)决定误差界的形状
- 依赖:泛函分析(紧算子谱)、数值线代(SVD)、概率论(贝叶斯支线)
