# 讲透符号计算与计算机推理 · 精确的代数

> GB/T 13745 11061 三级「符号计算与计算机推理」
> 定位句:这支负责**零误差的计算**——数值分支把无穷扔掉(近似),这支把无穷**编码**进有限的符号表达式;它的天敌是组合爆炸,它的护城河是"算出来就是精确的"。

## 诞生

📖 1965 年,Bruno Buchberger 在他的博士论文里(导师 Gröbner)发明 Gröbner 基:给多项式理想一组"好基",使成员判定、消元、方程组求解变成机械过程——并**证明了算法终止性**。这是符号计算的登基时刻:从此"用机器做代数"从技巧变成数学。1970s Macsyma、1990s Mathematica/Maple、开源 SymPy/Singular 相继把这支变成日用品。

## 核心问题

已解决:
- Gröbner 基:理想成员判定/消元定理/多项式系统解的几何刻画(终止性=可计算性的胜利)
-柱形代数分解(CAD, Collins 1975):实闭域上量词消去的一阶可判定(Tarski 定理的算法化)
- 符号-数值混合:符号预处理(化简/消元)+数值精修的流水线
- 计算机推理:定理证明的项重写系统;SMT 求解器(接 11085 的验证侧)

未解决/前沿:
- 双重指数复杂度墙:Gröbner 基/CAD 的复杂度是双指数——精确的代价,大规模问题只能退回数值
- 中间表达式膨胀(intermediate expression swell):算着算着表达式指数变长
- 机器学习引导的符号回归/猜想生成(回归欧拉-高斯式的实验数学)

## ✨ 这支最美的一个事实

CAD 证明:初等代数+实数上的命题,**可判定**——存在机械过程对任何此类命题回答真/假(Tarski 1948 定理,Collins 1975 算法化)。这是数学宇宙里罕见的"完整可判定"大陆;但复杂度双指数,像一座**看得见山顶却几乎爬不完的山**——可判定性与可行性的鸿沟在此一目了然(亲历:sympy 的 `solve` 解 3 变量多项式系统秒出精确根;加到 5 个变量看它陷入沉思)。

## 假设与依赖

- 精确表示假设:一切数必须是有限可表示的对象(有理数/代数数),实数连续统只能被绕开
- 终止性/复杂度:能算≠算得动;复杂度理论划定可用边界
- 依赖:交换代数(../讲透代数学/·环论支)、数理逻辑(量词消去,../讲透数理逻辑/·模型论支)
