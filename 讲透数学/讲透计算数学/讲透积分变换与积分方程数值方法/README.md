# 讲透积分变换与积分方程数值方法 · 把核方程变成小线代

> GB/T 13745 11061 三级「积分变换与积分方程数值方法」(原名:积分方程数值解)
> 定位句:这支负责**未知函数藏在积分号下**的数值世界——积分方程是"无穷维的线性方程组",这支的手艺是把它变成机器吃得下的有限维,且知道丢弃了什么。

## 诞生

📖 Fredholm 1900 年代在斯德哥尔摩研究积分方程 x(s)−∫K(s,t)x(t)dt=f(s),发现它的解论像有限线代一样干净( Fredholm 二择一),直接启发了 Hilbert 建造 Hilbert 空间——**泛函分析生于积分方程**。数值侧的成熟标志:Nyström 1930 用求积规则直接离散核;边界元法(1960s-)把边界积分方程变成工程主力。

## 核心问题

已解决:
- Fredholm 第二类的收敛性:Nyström/乘积积分法收敛定理(核光滑+求积收敛⟹离散解收敛)
- 快速核求和:快速多极(FMM,1987)与 H-矩阵把稠密核矩阵的 O(N²) 压到近线性
- 变换数值化:FFT(1965)让卷积定理从纸面走进每一台机器

未解决/前沿:
- 高振荡核(光学/声学,Helmholtz 高 k)的求积——每波长点数降不下来
- 边界元+有限元耦合的稳定框架(虚构域/FEM-BEM 界面)
- 核相关的机器学习核矩阵(KK 等)的压缩与反演

## ✨ 这支最美的一个事实

卷积定理:时域的卷积=频域的乘法。一个 Fourier 变换,让"平滑滤波"这种看似天生 O(n²) 的运算变成三次 FFT 的 O(n log n)——**同一个积分,换个坐标系,难度坍缩**(亲历:`scipy.signal.fftconvolve` vs 直接卷积计时)。

## 假设与依赖

- 核的光滑性/衰减性决定一切:光滑核→高阶收敛;弱奇异核→乘积积分加权
- 依赖:求积理论(数值分析)、线代引擎(数值线代)、位势论(理论侧,../讲透分析/)
