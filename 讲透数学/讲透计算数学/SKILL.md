# 计算数学思维技能卡

## ① 何时用此分支(问题特征触发词)

- 出现"浮点/精度/有效数字/0.1+0.2/舍入"类困惑或 bug
- 解对输入**极其敏感**(病态:条件数、Hilbert、近乎奇异、CT/成像/由果推因)
- 迭代法**收敛慢或不收敛**(谱半径、预条件、共轭梯度、牛顿)
- 要做**正则化/防过拟合的数学面**(Tikhonov、岭回归、早停=正则化)
- 高维积分/高维 PDE(维数诅咒、蒙特卡洛、稀疏网格)
- 多卡/多机计算结果**不可复现**(归约顺序、原子加、确定性)
- 混合精度/量化训练的**误差预算**设计
- 选数值库/算法(网格 vs 无网格、直接法 vs 迭代法、显式 vs 隐式)

## ② 核心思维模式

1. **问责二分**:错误先分"问题的锅(条件数 κ)还是算法的锅(向后误差 η)"——好算法救不了病态问题,只能正则化换问题。
2. **稳定性优先于精度**:先保证解的是"某个近处的问题"(向后稳定),再谈离目标多远。
3. **误差预算思维**:精度/时间/确定性是三种预算;系统设计=预算分配表(哪里粗、哪里细、哪里必须确定)。
4. **条件句阅读**:一切数值定理是 IF 稳定∧相容 THEN 收敛;用任何结论先查 IF 从句。
5. **结构决定走廊**:对称/稀疏/低秩/正交——数学结构决定用哪条算法走廊,规模只改参数。

## ③ 工具箱(方法名 + 一句话何时用)

| 工具 | 何时用 |
|------|-------|
| 条件数诊断 κ(A) | 任何解漂移事故的第一问;κ 定价"最多能信几位" |
| SVD / 截断 SVD | 病态、低秩、伪逆;正则化的谱视角 |
| 向后误差分析 | 评估算法品格(而非问题难度) |
| Tikhonov 正则化 + L 曲线 | 病态问题的标准救赎;λ 拐角≈平衡偏差与放大 |
| Kahan 求和 / 成对归约 | 长数组求和精度问题;GPU 归约稳定化 |
| 蒙特卡洛 / QMC | 维数 ≥4 的积分;误差 ~1/√N 与维数无关 |
| 自适应求积/步长 | 低维积分、ODE;让机器自己折半达标 |
| Gröbner 基(sympy/Singular) | 多项式系统要**精确**解时(小规模) |
| 区间算术(mpmath.iv) | 要机器自证的误差证书、验证式计算 |
| FFT | 任何卷积/相关/频谱;O(n log n) 不是可选项 |

## ④ 常见误区与禁忌

- **精度=准确**:高精度格式不能修复病态问题(信息在输入端已丢失)
- **空间越大越好**:等距高次插值 Runge 发散;好基(Chebyshev/分片/稀疏)>高次
- **逐位复现是免费的**:确定性归约有 5-30% 吞吐税;先声明复现口径(逐位/统计/验证式)
- **理论界=实际误差**:最坏情况界悲观千百倍,作安全论证而非性能预期
- **默认容差是你的容差**:库默认值=别人的误差预算
- 禁忌:对未诊断 κ 的问题争论算法优劣(先量问题,再选方法)

## ⑤ 与相邻分支的判别 + 组合接口

| 判别 | 组合 |
|------|------|
| vs **优化**(算最优值):优化找最优点,本分支保证"算出的点离真值多远;病态优化问题仍回到这里 | 优化提供算法框架,本分支提供收敛的谱分析与数值实现 |
| vs **计算机数学**(11085,可计算性):它问"什么可算",本分支问"算出来错多少" | 它划定可机械化边界(04 章),本分支在界内施工 |
| vs **分析学**(存在性):分析证存在,本分支造出"带证书的近似" | 分析给 Sobolev 空间结构→有限元;本分支回馈数值反例 |
| vs **概率论**:概率描述随机对象,本分支用随机性当**工具**(MC/QMC) | 随机数值方法=MCMC 的收敛率分析(谱方法) |
| 组合范式 | 随机×优化→随机规划;病态×学习→岭回归/早停;确定×多卡→并行归约协议 |
