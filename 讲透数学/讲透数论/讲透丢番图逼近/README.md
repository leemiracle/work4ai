# 讲透丢番图逼近 · 无理数能被"追"到多近(距离与分母的博弈)

> **定位句:这支负责量化"有理数对无理数的逼近极限"——分母为 q 的分数能离无理数多近,答案是 q² 量级,再近就被代数性拒绝。**
> GB/T 13745-2009:11017 数论 · 三级「丢番图逼近」| 家族:[讲透数论](../README.md)

## 诞生

Dirichlet(1842,鸽笼原理证 |α-p/q|<1/q² 无穷多解)创世;**Roth(1955,代数无理数的逼近指数恰为 2,Fields 1958)** 封顶;Thue–Siegel–Roth 阶梯是本支的主脊梁。

📖 诞生故事:Thue(1909)研究的原因很"实用":他想证丢番图方程解数的有限性——逼近上界越紧,方程解越少。一支"纯逼近"的学科,动机竟是解方程,"动机与结果不同域"的典型。

## 核心问题

已解决:
- Dirichlet 定理(1842:任意实数有 |α-p/q|<1/q² 的无穷逼近)
- Thue–Siegel–Roth(1955:代数无理数逼近指数 >2 只有有限解)
- Schmidt 子空间定理(1970,Roth 的多维推广)

未解决:
- Littlewood 猜想(|‖nα‖·‖nβ‖| 是否无穷多 n 接近 0——2026 仍开放)
- Duffin–Schaeffer 猜想已被 Koukoulopoulos–Maynard(2019)解决——本支十年来最大胜利;其"加权版本"续集中

## ✨ 这支最美的一个事实

黄金比 φ=(1+√5)/2 是"最难逼近的数"(其连分数全为 1,逼近常数最差)——最美的数与最"顽固"的数是同一个。

## 假设与依赖

- 依赖:连分数理论(逼近的完备语言)+ 测度论(几乎处处的行为)
- 代价:上界定理(Roth 类)是非有效的——常数不可算,只能证存在
