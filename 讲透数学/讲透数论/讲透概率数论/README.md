# 讲透概率数论 · 把素数当随机序列(启发式为何如此准)

> **定位句:这支负责"用随机模型预测确定性整数对象的行为"——Cramér 模型是它的世界观,Erdős–Kac 是它的第一座灯塔。**
> GB/T 13745-2009:11017 数论 · 三级「概率数论」| 家族:[讲透数论](../README.md)

## 诞生

Hardy–Ramanujan(1917,素因数个数的正常阶)播种;**Erdős–Kac(1939,素因数个数渐近正态)** 宣告"数论也有中心极限定理";**Cramér(1936 随机素数模型)** 提供了统一直觉框架。

📖 诞生故事:Erdős 20 岁出头在普林斯顿遇 Kac(概率学者),两人一个不懂概率一个不懂数论,聊天聊出 Erdős–Kac 定理——Kac 回忆说:"这大概是数学里第一次,确定的对象表现得像随机变量。"从此"概率启发式"成为数论猜想的头号发生器。

## 核心问题

已解决:
- Erdős–Kac(1939:ω(n) 渐近正态,均值/方差 ln ln n)
- Cramér 随机模型预测 Mertens 定理与(小尺度)间隔统计
- Maier 定理(1985)——**反直觉发现**:Cramér 模型在短区间会系统性偏差(机器也会骗人)

未解决:
- Cramér 间隔猜想(相邻素数间隔 O((ln p)²))——纯模型预测,证明无门
- Chowla 猜想(Liouville 函数的相关性=0——解析数论×概率的总枢纽)

## ✨ 这支最美的一个事实

"整数是宇宙中最确定的东西,而它们的统计行为精确到小数点地服从概率定律"——确定性长出了随机性的脸。

## 假设与依赖

- 依赖:概率论(极限定理/随机过程)+ 测度论
- 代价:模型≠定理(Maier 定理警告);启发式的"置信度"没有形式化刻度

## 教材锚

- Kuipers–Niederreiter《Uniform Distribution of Sequences》(一致分布侧)
