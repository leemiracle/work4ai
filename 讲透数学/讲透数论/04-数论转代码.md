# 04 · 数论转代码:整数的可计算化身

> **本章回答五问之五:数论的问题怎么变成 code 问题?可机械化边界在哪,代码走廊有哪些,工程师落点是什么。**
> **本质一句话:数论是"计算机科学之前的计算机科学"——同余算术完全可机械化,分解之难撑起了密码工业,而"没有万能解方程器"本身是定理。**
> 三件套:可机械化边界 / 代码走廊清单 / 工程师落点(性能工程视角)。

---

## 〇、开场的画面:你的 CPU 每天在做数论

你打开一个 HTTPS 网页:TLS 握手做椭圆曲线 Diffie–Hellman(每秒几千次点乘);
你收一条消息:消息认证码跑素域乘法;你解锁手机:Secure Enclave 里的 RSA/ECC。
**数论是离钱和离 CPU 最近的数学之一**——本章讲这条"整数→硅"的转换链。

## 一、可机械化边界:哪些能自动化,哪些被逻辑禁止

**直觉图像**:一道看不见的墙把数论问题分成两个世界——
墙这边,机器全能;墙那边,连"万能机器"的定义都被定理否决。

| 边界 | 内容 | 依据 |
|------|------|------|
| ✅ 全自动化(多项式) | gcd/模逆/线性同余/中国剩余/素性(AKS)/模幂 | 欧几里得、快速幂、AKS 2002 |
| ⚠️ 可算但(猜)非多项式 | 整数分解、离散对数(经典模型) | 数域筛/指标法为现实最优;多项式算法存在性=悬案——**这是"可机械化"与"工程可行"的缝隙,密码学住在缝里** |
| 🌀 量子模型重排 | 分解与离散对数在量子多项式(Shor 1994) | 后量子密码(NTRU/格基/同源)的研发动因——数论内"难"的资产重组 |
| ❌ 逻辑禁止 | **判定任意丢番图方程有无解——无算法**(Hilbert 第十问题,Matiyasevich 1970) | 多项式=图灵完备;万能解方程器被 Gödel/Turing 式对角化否决 |
| ⚠️ 不可判定内的局部胜利 | 固定次数/固定变元数(如二元二次)有算法 | 界限被精确刻画:变元数与次数的二维地图上"可解带"极窄 |

**为什么是这样**:数论问题的机械化程度 = 它离"通用计算"多远。
加法(远)→可判定;乘法+量词(近)→不可判定;介于其间(Factoring)=复杂性理论的教科书样本。
**转代码的第一课:先查问题在边界地图上的位置,再谈实现。**

## 二、代码走廊清单:从恒等式到系统

**直觉图像**:走廊=每个数论构造对应一条"可执行通道",恒等式即算法。

| 走廊 | 数学恒等式 | 代码化身 | 复杂度/要点 |
|------|-----------|---------|------------|
| 模幂 | $a^{2k}=(a^k)^2$, $a^{2k+1}=a\cdot a^{2k}$ | `pow(a, e, m)`(平方-乘) | O(log e) 次乘法;**密码学第一热点函数** |
| gcd/扩展 gcd | $\gcd(a,b)=\gcd(b, a\bmod b)$;Bézout | `math.gcd`;扩欧求模逆 | O(log min) 迭代;逆元存在 ⟺ gcd=1 |
| 中国剩余 CRT | 两两互素模系 ⟺ 单模系 | 逐对合并 | 大数计算的分治基础(见 NTT) |
| 素性 | Fermat 小定理逆否+强伪素强化 | Miller–Rabin(概率)/AKS(确定) | MR:O(k·log³n) 概率 4⁻ᵏ;工程默认 |
| 筛法 | 合数=小素数倍数的划除 | Eratosthenes/线性筛/分段筛 | π(x) 表与 [00_prime_counting.py](experiments/00_prime_counting.py) |
| 椭圆曲线点运算 | 群律(弦切/倍点公式, mod p) | 仿射/雅可比坐标点加 | 安全核心=ECDLP;恒定时间实现是难点 |
| 数论变换 NTT | $\omega^n\equiv1$ 的原根替代 i | 在 $\mathbb{Z}/p$ 上做 FFT | **大整数乘法/多项式乘法的引擎**(见下) |
| 格归约 | Minkowski 的算法化身 | LLL/BKZ | 攻击 RSA(Coppersmith)与后量子密码(LWE)双栖 |

**最小例子(请手跑)**:计算 $2^{100} \bmod 101$——
不是把 2^100 写出来再取余,而是反复平方:2²→2⁴→…→2⁶⁴,按 100 的二进制
(1100100)挑三次相乘,总共 ~9 次乘法。**"先约简再计算"是数论代码的第一习惯**
(与分析家族"实数用浮点"的习惯互为镜像)。

📖 故事框:1994 年 Arjen Lenstra 组织 RSA-129 分解,动员 600 人 600 台机器八个月;
2020 年,同一量级用 CADO-NFS 在普通云上几小时。**算法没变(数域筛),
变的是工程**——走廊修好之后,速度属于工程师。

## 三、工程师落点(性能工程视角)

数论代码的三条工程铁律,与性能工程([`../讲透应用数学/`](../讲透应用数学/) 的渐近手艺)直接对口:

1. **大整数运算的成本模型**:两个 n-limb 大数相乘,学校乘法 O(n²),Karatsuba O(n^1.585),
   FFT/NTT O(n log n)。**python 内建大整数、GMP 是 C 世界标准**;
   性能工程的第一课是知道自己的乘法在哪一档。
2. **常数时间(constant-time)与侧信道**:模幂的分支(平方-乘的"乘"是否执行)
   会泄露指数比特——真实漏洞(Spectre 时代之前就有 OpenSSL 时序攻击史)。
   工程解法:恒定时间双线性(montgomery ladder)、盲化。**数学正确 ≠ 实现安全**,
   数论代码的安全边界在微架构层。
3. **并行与硬件**:模乘的 SIMD/CUDA 化(蒙哥马利乘的脉动阵列)、NTT 在 GPU 上的布局
   (ZK 证明系统 prover 的热点就是大規模 NTT)——**2021-2026 的 ZK/全同态热潮
   把"数论变换工程"推成了显学**:FHE 的每一次密文乘法都是多项式环上的 NTT,
   与 [`../讲透计算复杂度/`](../讲透计算复杂度/) 的电路复杂度、[`../讲透高维概率/`](../讲透高维概率/) 的随机性工程在三线交汇。

**落点速查表**:

| 你在做 | 数论给你的工具 | 入口 |
|--------|--------------|------|
| 公钥加密/签名 | RSA/ECC/Ed25519 | 模幂、点乘、域参数选择 |
| 大数/多项式乘法 | Karatsuba/Toom/NTT | 乘法档位选择 |
| ZK 证明/FHE | 素域/扩域上的多项式承诺 | NTT、格、椭圆曲线配对 |
| 随机性与哈希 | 素数的伪随机分布、模素域结构 | 素数选择、域算术 |
| 分布式一致(哈希环) | 一致性哈希的模运算结构 | 数论只是背景板,但 mod 是主角 |

## ✨ 美之时刻(本章)

**$\pi(x) < \mathrm{Li}(x)$ 会翻转**(Littlewood 1914 证明存在交叉,首次交叉在
Skewes 数~10^10^10^34 量级):**"Li 一直领先"这个百万内、亿内都对的事实是假的**。
为什么美:意外——数值证据与真理的边界被数论精确画出。怎么亲历:跑实验,
看到所有尺度 Li 领先后,查 Littlewood 定理陈述,体会"数值即证据"的失效时刻。
