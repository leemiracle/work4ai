# 数论思维技能卡(讲透数论 · GB/T 11017)

> 本文是分支的抽象层:不看细节,只装"眼睛和反射"。
> 深入时回到家族总纲 [`README.md`](README.md) 与五问五章。

## 1. 何时用此分支(触发特征,一眼对号)

- 问题里出现**整数解/正整数解/存在整数**(丢番图方程)——先想局部-整体,再想 Hasse 原理会失败
- 出现**整除、余数、模运算、周期、钟表/循环节**——同余机器启动
- 出现**素数、素性、因子、分解**——素数分布直觉+计算数论走廊
- 出现**RSA、椭圆曲线密码、离散对数、大数运算性能**——直接进 04 章代码走廊
- 出现"这个数是不是代数数/超越数"或"无理数逼近"——超越数论/丢番图逼近支
- 出现**格点、判别式、Minkowski**——数的几何支
- 出现**"为什么这个猜想看起来随机但没证明"**——概率数论的启发式文化

## 2. 核心思维模式(数论怎么想问题)

1. **局部-整体原则**:全局整数问题 → 逐素数 p(和 ∞)的局部问题 → 问局部解能否拼回整体。
   警觉:二次型可以(Hasse 原理),椭圆曲线会失败——"局部全对≠全局有解"是数论第一警句。
2. **升维修补**:分解唯一性破了(ℤ[√-5])→ 升到理想层恢复。遇到结构破缺,先问"升哪一层能救"。
3. **有限性即刚性**:类数有限、单位群有限生成、Mordell–Weil——见到无穷对象,找把它压进
   有界格点区域的那个几何引理(Minkowski)。
4. **难的资源化**:没有快速算法 ≠ 坏消息;分解之难=公钥密码的全部价值。
5. **随机启发式**:把素数当随机序列建模(Cramér)先猜答案,再找证明;
   但牢记 Skewes 式"数值证据会骗人"的先例。

## 3. 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 欧几里得算法/扩展 gcd | 一切整除问题;求模逆(`modinv` 的唯一正统) |
| 中国剩余定理 CRT | 多模系统一;大数计算分治;解同余方程组 |
| 费马小定理/欧拉定理 | 化简大指数模幂(`pow(a,e,m)` 的理论根基) |
| 二次互反律 | 判断 p 是否 mod q 的二次剩余;ℤ[i] 等扩域中素数行为 |
| 原根与离散对数 | 乘法群的结构;密码学难度来源 |
| Miller–Rabin(强伪素) | 快速素性(概率);确定版用 AKS/小基确定性区间 |
| 连分数 | 最佳有理逼近;解 Pell 方程;丢番图逼近入门 |
| ζ 函数/欧拉乘积 | 任何"素数有多少/多密"的统计问题 |
| Minkowski 凸体 | 证明任何"只许有限个"的结构定理 |
| LLL 格归约 | 攻击低指数 RSA(Coppersmith);格密码 |

## 4. 常见误区与禁忌

- ❌ 用浮点做大整数幂/精确同余——必须整数类型+模约简(python 原生支持,乘法先 mod)
- ❌ 把概率素性测试(Miller–Rabin)当确定性——错误率 4⁻ᵏ 可忽略但非零;确定场景用确定性基表/AKS
- ❌ 忘了 Carmichael 数会骗过纯 Fermat 测试——永远用"强伪素"版本
- ❌ 在丢番图问题上找"通用求解器"——Hilbert 第十问题已证明不存在;
  只能按次数/变元数的可判定窄带处理
- ❌ 把 Cramér 随机模型的预测当定理(它是极准的启发式,不是证明)
- ❌ 实现密码代码忽视常数时间(数学对 ≠ 实现安全)

## 5. 与相邻分支的判别与组合

| 邻居 | 怎么区分 | 怎么组合 |
|------|---------|---------|
| 代数学 | 谈任意群/环/域结构=代数;只谈整数与代数数=数论 | Galois 理论是代数数论的语言(组合成类域论) |
| 代数几何 | 变量在域上任意取值=几何;只在整数/有理数取值=数论 | 组合=算术几何(费马大定理的家) |
| 组合数学 | 数"对象个数"=组合;数"解的个数且解有算术结构"=数论 | 加性组合(哥德巴赫的现代武器) |
| 概率论 | 对象本身随机=概率;对象确定、用随机建模=概率数论 | Erdős–Kac、随机素数启发式 |
| 计算复杂性 | 问"什么可算/多快"=复杂性;问"整数事实"=数论 | Factoring/DL 是复杂性动物园的明星展品 |
| 分析(ζ 函数) | 极限/连续对象为主=分析;用于素数统计时=解析数论 | 素数定理=分析收数论房租 |

**组合接口速查**:随机×整数→概率数论;几何×整数格→数的几何;方程×整数根→代数数论;
安全×难→计算数论×密码工程;形式化×数论→Lean/mathlib(FLT 项目)。
