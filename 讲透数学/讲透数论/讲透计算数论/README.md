# 讲透计算数论 · 数论的算法面(密码学的矿山)

> **定位句:这支负责"把数论对象变成算法"——素性/分解/离散对数/类群计算,以及这一切换来的密码工业。**
> GB/T 13745-2009:11017 数论 · 三级「计算数论」| 家族:[讲透数论](../README.md)

## 诞生

Eratosthenes(筛)与孙子定理是远古;**RSA(1977)是现代创世**——"分解难"从缺陷变成资产;AKS(2002)证明素性测试本质上多项式,是理论终章。

📖 诞生故事:1977 年 MIT,Rivest 宿醉后的清晨把 RSA 草稿放在 Shamir 桌上——三人此前两年的"不可能方案"全部失败,这次成了。同年 Martin Gardner 在《科学美国人》专栏公开挑战(RSA-129),预测 4 亿亿年,1994 年被分布式计算 8 个月攻破——**"难"的工程相对性从此成为本支的常识**。

## 核心问题

已解决:
- AKS 素性测试(2002:确定性多项式时间)
- Miller–Rabin(1976):概率素性,工程默认
- 椭圆曲线分解法 ECM(Lenstra 1987)、数域筛 NFS(当代分解主力)
- Shor(1994):量子模型下分解/离散对数多项式

未解决:
- **经典模型下分解是否多项式**——21 世纪密码学的存在性前提
- 类群计算的亚指数→多项式(格密码分析的现实瓶颈)
- 同源密码(SIDH)2022 被攻破后,后量子替代者的安全证明链仍在重建

## ✨ 这支最美的一个事实

AKS 的核心是初等恒等式 $(x+a)^n \equiv x^n + a \pmod n$——三千年素性问题的最优解,藏在高中二项式定理里,2022 年之前的 26 个世纪无人捡起。

## 假设与依赖

- 依赖:全家(all of 数论)+ 复杂性理论;工程侧=密码学/大数库(GMP)
- 代价:结果分"conditional"两档(GRH 假设下更快是本支口癖)
