# 讲透数的几何 · 格点上的凸几何(Minkowski 的望远镜)

> **定位句:这支负责"用凸几何看格点"——Minkowski 凸体定理是全代数数论有限性定理的证明发动机。**
> GB/T 13745-2009:11017 数论 · 三级「数的几何」(Geometry of Numbers)| 家族:[讲透数论](../README.md)

## 诞生

Minkowski(1889《数的几何》讲义起,1896 成书)一人创支——把"格点+凸体"的图像引入数论,连克二次型/代数数论的老大难。

📖 诞生故事:Minkowski 与 Hilbert 是哥尼斯堡同乡挚友。Hilbert 说他是"数的几何的莫扎特"——直觉如泉,可惜 45 岁早逝(1909);他未竟的"凸体纲领"至今还在产出定理。

## 核心问题

已解决:
- Minkowski 凸体定理(ℤ^n 中 vol>2^n·covol 的中心对称凸体必含非零格点)
- Minkowski 线性型定理 ⟹ 判别式下界(Hermite 常数存在)
- Dirichlet 单位定理的几何证明(单位=对数格点)

未解决:
- 高维球最密堆积(1-3 维已知:Kepler 猜想 Hales 1998/2005 形式化 2014;8 维 Viazovska 2016 Fields;24 维同 2016;**9-23 维等多数维数开放**)
- 覆盖密度与最薄覆盖问题

## ✨ 这支最美的一个事实

Viazovska 用"魔法函数"(模形式造的插值)一举解决 8 维与 24 维球堆积——300 年老题在两周内连下两城(2016),证明短到"像被施了魔法"。

## 假设与依赖

- 依赖:线性代数(格/行列式)+ 凸性(体积论证)——全家族最"可视化"的支
- 代价:非构造(凸体定理只担保存在,找格点要算法兜底)
