## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透数论/
├── 讲透初等数论/    同余、原根、二次互反——不用极限的整数化学(整除的显微镜)
├── 讲透解析数论/    ζ 函数与素数分布——把算术泡进分析(素数的统计学)
├── 讲透代数数论/    代数整数、理想、类域论——为救唯一分解发明的结构层
├── 讲透超越数论/    哪些数不是代数方程的根——存在性 proofs 的极简与困难
├── 讲透丢番图逼近/  无理数能被有理数逼近到什么程度——距离与分母的博弈
├── 讲透数的几何/    Minkowski 凸体定理——几何看格点,格点还结构
├── 讲透概率数论/    把素数当随机序列建模——启发式为何如此准(与概率论互链)
└── 讲透计算数论/    算法与复杂度——素性/分解/类群计算,密码学的矿山
```
