# 讲透代数数论 · 分解破缺的补救史(理想、类群、类域论)

> **定位句:这支负责"整数之外还像整数的东西"——代数整数环的结构,理想类群与单位群是它的两大支柱。**
> GB/T 13745-2009:11017 数论 · 三级「代数数论」| 家族:[讲透数论](../README.md)

## 诞生

Kummer(1847,为攻费马大定理发明"理想数")与 **Dedekind(1871,把理想数公理化为理想论)** 是创世二人;Hilbert《数论报告》(1897)定纲;**类域论(Artin/Takagi/Hasse,1920s)** 完成第一次大统一;朗兰兹(1967-)把它抛向无穷远方。

📖 诞生故事:Kummer 发现 ℤ[ζ_p] 里唯一分解破裂直接卡死了费马的路线,于是造出"理想数"——他以为是权宜之计,后人发现这是 20 世纪代数的种子(理想论=整个交换代数之母)。

## 核心问题

已解决:
- 理想唯一分解(Dedekind:元素层破缺在理想层恢复)
- 类数有限 & Dirichlet 单位定理(单位群 ≅ 挠 × ℤ^{r+s-1})
- 类域论(二次互反的无穷推广:阿贝尔扩张 ⟺ 理想群)
- 虚二次域 h=1 完全分类(Heegner 1952/Baker–Stark 1966,九个域)

未解决:
- 类数 1 问题的高维版(实二次域 h=1 有无穷多个?——Cohen–Lenstra 启发式说"是")
- 本支真圣杯在朗兰兹纲领侧:非阿贝尔类域论(非阿贝尔扩张的"类域论"尚不存在)
- Gauss 类数猜想(Gauss 记 h(d)≥d^{1/2-ε} 类的问题已由 Goldfeld–Gross–Zagier 解决,但显式下界的工程化仍活)

## ✨ 这支最美的一个事实

虚二次域 ℚ(√-d) 中唯一分解(h=1)只发生在 d=1,2,3,7,11,19,43,67,163 这九座孤岛——"完美的世界"在数学里是有名额的。

## 假设与依赖

- 依赖:交换代数(理想/模)、Galois 理论(扩域语言)——本支是最"代数"的数论支
- 代价:对象抽象(理想/adele),计算要靠类的有限性定理兜底
