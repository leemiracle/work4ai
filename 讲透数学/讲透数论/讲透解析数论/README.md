# 讲透解析数论 · 素数的统计学(把算术泡进分析)

> **定位句:这支负责"素数(及乘性对象)如何分布"——用 ζ/L 函数与筛法,把离散的素数变成可统计的连续对象。**
> GB/T 13745-2009:11017 数论 · 三级「解析数论」| 家族:[讲透数论](../README.md)

## 诞生

Euler(1737,欧拉乘积:ζ=素数积)播种;**Dirichlet(1837,用 L 函数证等差数列素数无穷)** 是学科独立的标志——第一次用分析工具征服纯算术命题;Hadamard/de la Vallée Poussin(1896,素数定理)是第一座丰收纪念碑。

📖 诞生故事:Dirichlet 那年证的是"2,5,8,11,…里有无穷多素数"这类小学生问题,用的却是复变函数——同行为之震动:原来"算术问题可以租分析的机器"。此后 150 年,这台机器越租越大。

## 核心问题

已解决:
- 素数定理 π(x)~Li(x)(1896,等价于 ζ 在 Re=1 无零点)
- Dirichlet 定理(1837:互素等差数列素数无穷)
- 素数定理初等证明(1949,Selberg–Erdős——存在但无人想用,反衬解析工具的力量)
- 有界素数间隔(张益唐 2013:7000 万→Polymath 246)

未解决(全部千禧级地位):
- **黎曼假设**(ζ 非平凡零点全在 Re=1/2)——素数统计精度的总开关
- 哥德巴赫猜想(1742)与孪生素数猜想的最后一步
- Elliott–Halberstam 猜想(筛法威力的理论上限)

## ✨ 这支最美的一个事实

欧拉乘积 $\sum n^{-s}=\prod_p(1-p^{-s})^{-1}$:左边是加法世界的级数,右边是乘法世界的素数——一个等号把两个宇宙焊接;素数定理、黎曼假设全是这条等号的后续剧情。

## 假设与依赖

- 依赖:复分析(全纯函数/解析延拓)与渐近分析——本支是数论里"最分析"的支
- 代价:方法重;且大量最优结果依赖未证的 RH/GRH(标注"conditional"是本支日常)
