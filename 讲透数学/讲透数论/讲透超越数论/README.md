# 讲透超越数论 · "不是任何方程的根"(存在性证明的极简与困难)

> **定位句:这支负责区分"代数数"与"超越数"——证明一个数(如 e、π、Liouville 数)不满足任何整系数多项式。**
> GB/T 13745-2009:11017 数论 · 三级「超越数论」| 家族:[讲透数论](../README.md)

## 诞生

Liouville(1844,第一个手工构造的超越数)是创世;**Hermite(1873,e 超越)与 Lindemann(1882,π 超越)** 完成两次世纪命中——后者一刀终结了两千年的"化圆为方";Gelfond–Schneider(1934)解决 Hilbert 第七问题。

📖 诞生故事:Lindemann 证明 π 超越的那一刻,"尺规化圆为方"(给定圆作等积正方形)从"难题"变成"已被定理否决的题"——超越数论最著名的"负结果改变数学"案例。

## 核心问题

已解决:
- Liouville 数存在(1844)、e 超越(1873)、π 超越(1882)⟹ 化圆为方不可能
- Gelfond–Schneider 定理(1934:a^b 型数的超越判据,Hilbert 第七问题)
- Lindemann–Weierstrass 一般化

未解决(本支的圣杯群):
- **e+π、e·π、Euler 常数 γ 是否超越——全部开放**(2026 年连"e+π 是无理数"都未证!)
- Schanuel 猜想(本支的"黎曼假设":几乎蕴含上述一切)
- 2^√2^√2(Gelfond 问题的第三层)

## ✨ 这支最美的一个事实

几乎所有实数都是超越数(勒贝格意义:代数数可数、零测),但 2026 年人类能"点名"的超越数屈指可数——满地都是,抓不住一只。

## 假设与依赖

- 依赖:代数数域的有限维结构 + 逼近论(用"太好了的逼近"反证代数性)
- 代价:方法极其特化(辅助多项式),离普适判据(Schanuel)尚远
