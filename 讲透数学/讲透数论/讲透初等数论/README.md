# 讲透初等数论 · 同余世界的语言课(不用极限的整数化学)

> **定位句:这支负责"整除与同余"的一切初等结构——它是数论的方言课,也是全家族唯一不要求微积分的入口。**
> GB/T 13745-2009:11017 数论 · 三级「初等数论」| 家族:[讲透数论](../README.md)

## 诞生

欧几里得(~300 BC,素数无穷+gcd 算法)是远祖;**秦九韶《数书九章》(1247)"物不知数"与 Gauss《算术研究》(1801)** 把同余变成自觉语言——"mod"记号属 Gauss,一次定义了整门学科的口语。

## 核心问题

已解决:
- 素数无穷(欧几里得反证法,~300 BC)
- 算术基本定理(唯一分解;Gauss 严格化 1801)
- 二次互反律(Euler 猜想,Gauss 1796 首证,人称"黄金定理")
- 原根存在定理(Gauss:mod p 的乘法群是循环群)

未解决:
- 高斯复合域上的类数二 Pension 猜想之外,本支的"未解"多已升级到解析/代数支
- Artin 原根猜想(给定 a,以 a 为原根的素数密度——仍是猜想)

## ✨ 这支最美的一个事实

二次互反:$p$ 是否 $q$ 的二次剩余,与 $q$ 是否 $p$ 的二次剩余,其关系只由 $p,q \bmod 4$ 决定——两个素数互相尊重到只用对方"除以 4 的余数"表态。

## 假设与依赖

- 只依赖整数的基本性质(可完全不依赖实分析/复分析成立——"初等"之意)
- 代价:工具威力有限,素数分布这类"统计问题"必须升级到解析数论

## 教材锚

- Hardy & Wright《An Introduction to the Theory of Numbers》(数论导引)前半
- Gauss《Disquisitiones Arithmeticae》(算术研究,学科创世文档)
- 配套:LeetCode/竞赛数论题单(同余机器的手感训练)
