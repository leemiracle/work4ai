# 组合数学思维技能卡(讲透组合数学)

> 本卡把分支抽象成可复用思维。深读走 [README.md](README.md) → 五问五章;
> 触发后按 §一 判断支路,按 §三 取工具,按 §五 组合。

## 一、何时用此分支(触发特征,一眼对号)

1. 问"**有多少种**"——方案数/路径数/安排数/概率分母(数不清就找双射)
2. 问"**存不存在**"一种安排/配置/着色——满足一堆互斥约束
3. 问"**最坏情形多大**"——"不管怎么安排都必然出现什么"(Ramsey 式阈值)
4. 出现**鸽笼信号**:东西比格子多、碰撞、上限、必有重复
5. 对象带**对称性**(旋转/置换后重复计数)——要消对称才算真数
6. 有**递推关系**要封口——生成函数把序列装进函数
7. 工程侧:哈希容量/测试覆盖/采样生成/排班装箱的**参数界**

## 二、核心思维模式(这个分支怎么想问题)

| 模式 | 口诀 | 反例警示 |
|------|------|---------|
| **双射即证明** | 数不清→找"已知个数的东西"一一对应 | 硬数到组合爆炸是外行为 |
| **换种数法** | 同一集合两种数法,等式即定理(双计数) | 数错边/漏对称是最常见 bug |
| **概率证存在** | 随机采样,期望<1 ⇒ 存在零例外 | 得到存在≠得到实例 |
| **极值即形状** | 最优构形几乎总是简单对称形(星形/中间层/平衡部图) | 别在"歪"的构形里找最优 |
| **占比思维** | 存在性问题先估"好对象占比" | 占比极低的稀有结构,随机摸不到(第一矩失明区) |

## 三、工具箱(定理/方法 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| 鸽笼原理 | 要"必有重复/共居"的点名式结论 |
| 双计数/握手引理 | 度数和=2·边数这类"必然等式" |
| 容斥原理 | 计数带禁位/排除条件 |
| 生成函数 | 递推要闭式、级数要系数(F=x/(1-x-x²)→Binet) |
| Burnside/Pólya | 对称群作用下数"本质不同"对象 |
| Erdős 概率方法 | 证下界/存在:期望或占比论证 |
| 局部引理(LLL) | 局部坏事件少量相依时证"全避开"存在 |
| Turán/EKR/Sperner | "不含某结构 ⇒ 大小上限"的极值断言 |
| Ramsey 定理 | "规模够大必有单色规则子结构" |
| 线性代数方法(Frankl–Wilson) | 交限制⇒族大小上界(秩压扁) |
| 树宽/DP 豁免 | 能排成链/树的计数:指数压成线性 |
| rank/unrank + Boltzmann 采样 | 只要第 k 个/随机一个,不要全部 |

## 四、常见误区与禁忌

1. **枚举≠计数**:先问能否双射/递推/闭式,itertools 穷举只配小规模
2. **对称要除掉,但不是直接除以 |G|**——Burnside 用不动点平均(轨道长度不一时直接除是错的)
3. **存在≠构造**:概率方法给出的对象,别假装"已经拿到";显式与随机可能差指数级
4. **判定≠计数**:有无解在 NP,数多少在 #P——"顺便数一下"可能是指数级更难
5. 渐近语言要规矩:n! ~ (n/e)^n√(2πn),别用 e^n 蒙混
6. 罕见结构采样摸不到:逃逸染色占比 1% 时,几千样本才见一次;占比 2^{-100} 时永远别赌采样

## 五、与相邻分支的判别 + 组合接口

| 症状像组合,其实是 | 判别 | 接口 |
|---|---|---|
| 图的问题 | 对象是"点+边"本身 → 图论 [`../讲透图/`](../讲透图/) | 极值图论两边跑:户口在图,方法在组合 |
| 连续/极限/渐近分析 | 出现 ~ 与鞍点深算 → 分析系 | 生成函数的解析方法(奇点分析)住分析侧 |
| 概率问题 | 要的是分布/期望数值 → 讲透概率论(建族中) | 计数给概率以分母;概率方法反向证存在 |
| 数论味道 | 对象是素数/等差数列 → 数论(建族中) | 加性组合是界河(Szemerédi/Green–Tao) |
| 要"搜出最优解" | 目标函数+约束要解 → [`../讲透优化/`](../讲透优化/) | 组合给搜索空间几何,优化给搜法 |
| 复杂度下界 | 问"难在哪里" → [`../讲透计算复杂度/`](../讲透计算复杂度/) | #P/NP 的户口在复杂度动物园 |

**组合接口(跨支配方)**:随机×组合=概率方法;代数×组合=RSK/拟阵;逻辑×组合=模型计数;优化×组合=整数规划;对称×组合=Pólya。
