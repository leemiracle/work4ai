## 开篇:2^64 个世界

给 K_{100} 的 4950 条边染两色,染色方案数 2^4950 ≈ 10^{149}——宇宙原子数约 10^{80}。**枚举即死**,这是组合问题的第一物理定律。但组合同时是**最适合机器的分支**:对象天然可编码(01 串/邻接表/位掩码),存在性天然可转 SAT,计数天然可转 #SAT/DP/生成函数。矛盾的两面合起来就是本章:**哪里可以放心交给机器,哪里必须请结构上场**。

## 一、可机械化边界(三件套之一)

### 判定(存不存在)——NP 的主场

存在性问题(有无合法染色/ packing/ 设计)→ SAT/ILP 一比一转译:变量=选择,子句=约束。**边界**:NP-complete 几乎是组合问题定义出来的(SAT 本尊就是(真值组合上的)存在性)。实务上 SAT 求解器远强于理论悲观:工业实例常秒解,难例集中在相变点附近(随机 3-SAT 在子句/变量比 ≈ 4.26 处最难——本身就是组合统计物理成果,方向锚)。

### 计数(有多少)——#P 的天堑

精确计数 #P-complete(比 NP 更硬:Toda:PH ⊆ P^#P)。**边界与豁免**:
- **DP 豁免**:结构有"好序"(树宽/区间性)⇒ 指数变线性(树上计数、区间 DP)
- **FPRAS 豁免**:随机近似可采(DNF 计数有 FPRAS;#SAT 除非 NP=RP 无)
- **代数豁免**:生成函数系数=符号计算(小规模精确闭式,sympy 可解)

### 枚举与采样——rank/unrank 与 Boltzmann

- **rank/unrank**:组合对象可**编址**——第 10^{18} 个组合不必生成前面 10^{18} 个(懒生成是工程刚需)
- **Boltzmann 采样**(Duchon–Flajolet–Louchard–Schaeffer,2004):按"重量"随机生成指定规模的组合对象——结构文本/测试数据生成的标准件
- **拒绝采样+概率方法实证**:Erdős 式存在性证明的**可执行化身**——见 `experiments/00_ramsey_random.py`

### 优化的边界

组合优化(TSP/背包/排班)整个移交 [`../讲透优化/`](../讲透优化/):本家族提供"搜索空间几何",那边提供"搜的技术"。

## 二、代码走廊清单(三件套之二)

| 走廊 | 一行说明 | 代表入口 |
|------|---------|---------|
| `itertools` | permutations/combinations/product/cartesian:小规模枚举的瑞士军刀 | 标准库,零依赖 |
| 生成函数→幂级数 | sympy `series`/`Poly`:递推的闭式封口 | F(x)=x/(1-x-x²)→Binet |
| 双射=算法 | Prüfer 序列:树↔序列,`encode/decode` 十几行 | 网络协议里的树编码至今在用 |
| 网络流/匹配 | Hall 定理的算法化身:二部匹配=存在性的构造性版本 | `networkx.max_weight_matching` |
| SAT 转译器 | 存在性→CNF(pysat/MiniSat):组合条件的机器可读语言 | Schur 数/Ramsey 下界的机器证明 |
| 位掩码 DP | 状态=子集:20 个元素以内的全组合遍历唯一通用解法 | 旅行商精确解的入门实现 |
| 蒙特卡洛概率方法 | "存在性占比"的实证测量 | 本家族实验脚本 |
| Burnside/Pólya 枚举 | 对称消去的程序化:先算不动点,再除 | `experiments` 练习 3 |

**走廊法则**:一条组合性质若能翻译成上表任一走廊,就从"数学事实"变成"可执行资产";翻译不过去的,回到 03 章找结构(或接受它是纯数学)。

## 三、工程师落点(三件套之三,性能工程视角)

| 落点 | 组合定理 | 工程含义 |
|------|---------|---------|
| **哈希碰撞/生日界** | 鸽笼原理:√N 个样本即 50% 碰撞 | 64 位哈希在 2^32 个对象处碰撞率已 ~50%——哈希表容量、随机 ID 长度、生日攻击的全部参数学;先算 √N 再写代码 |
| **组合测试(pairwise/t-wise)** | 极值组合:覆盖所有 t 维交互只需 ~v^t·log k 个用例 | 参数空间 10^{20} 的配置测试,3-wise 可压到数千用例(微软/谷歌工业标准) |
| **Bloom filter 容量** | 位数组 m、哈希 k 次:误报率 (1-e^{-kn/m})^k | "存在性判定的近似缓存"——用 3% 误报换 99% 内存,组合设计的选择题 |
| **显式 expander 图** | 03 章的裂缝:随机好造显式难 | 纠删码/LDPC/分布式哈希表/伪随机生成器的**可部署性**全押在显式构造上——"存在性免费,构造性天价"的工程账单 |
| **排班/装箱/切割** | 组合优化建模 | ILP 建模=把约束翻译成代数;[`../讲透优化/`](../讲透优化/) 的主场,本家族出"约束的组合学" |
| **负载均衡的球与箱** | 最大箱负载:投 n 球入 n 箱,最重箱 ~log n/log log n | 一致性哈希的虚拟副本数、随机化负载的保证全部由此读出 |

**性能工程师的三句口诀**:
1. **先问 √N**:任何涉及"唯一性/碰撞/覆盖"的系统,鸽笼先于设计文档
2. **爆炸处找 DP 或采样**:能排序成链就 DP,不能就 Boltzmann/蒙特卡洛——枚举永远是下策
3. **显式胜过随机**:随机化协议上线前,问一句"它的显式替代品存在吗"——expander/提取器的产业史就是答案

## 附录A · 生日界的完整账单(工程师必修)

P(无碰撞) = ∏_{k=1}^{N-1}(1-k/365) ≈ e^{-N²/(2·365)} ⇒ 50% 碰撞点 N ≈ 1.177√365 ≈ 22.5 → **23 人**。

| 场景 | 域大小 | 50% 碰撞规模 | 工程参数 |
|------|--------|-------------|---------|
| 生日 | 365 | 23 | 直觉以为是 183——差 8 倍 |
| 32 位哈希 | 2³² | ≈ 77,000 | 大文件集合必碰撞:别拿 int 哈希当 ID |
| 64 位哈希 | 2⁶⁴ | ≈ 5.1×10⁹ | 全球级 ID 池已到危险区 |
| 128 位 UUID | 2¹²⁸ | ≈ 2.2×10¹⁹ | 宇宙尺度内安全 |

**写代码前先算 √N**:这是鸽笼原理写进设计评审的形态。

## 附录B · pairwise 测试的账单(组合爆炸的工程解)

10 个参数、每参数 10 值:全组合 10¹⁰。但 bug 几乎总由 **2-3 个参数的交互**触发——覆盖全部参数对的用例数只需 ~v²·log k ≈ 10²·2.3 ≈ 数百(正交表/贪心覆盖可达)。微软的组合测试工具 Pairwise 与 AETG 的商业史就是这条定理的变现史。**纪律**:先问"bug 由几维交互引发"(t-wise),再选 t——t+1 一档,用例数翻一个参数量级。

## 附录C · 位掩码 DP 十五分钟版(TSP 精确解的入门实现)

状态 = (已访问集合 S, 当前点 v),转移 = min over 未访问 u。2^n·n² 复杂度:n=20 时约 4×10⁸ 步——**恰好够跑**;n=25 就死(2×10¹⁰)。这个"20 的墙"是每个工程师该亲手撞一次的墙:它把 #P 的冷冰冰定理变成一次真实的等待。走廊法则的现场教学:能 DP(有可分解结构)与不能 DP 的分界,就在 bitmask 的指数上。

## 附录D · 复杂度户口速查(转码时的问路图)

| 你的问题形态 | 户口 | 实务动作 |
|--------------|------|---------|
| 有没有一个合法安排 | NP(常 complete) | SAT/ILP 转译,先跑求解器再谈理论 |
| 有多少个 | #P | DP(有结构)/ FPRAS(可采样)/ 放弃精确 |
| 最优是哪个 | NP-hard 优化 | [`../讲透优化/`](../讲透优化/):近似/分支限界/启发式 |
| 第 k 个/随机一个 | 编址/采样 | rank/unrank、Boltzmann |
| 必然出现什么 | 极值/Ramsey | 查表(Sperner/EKR/Turán)再建模 |

> **✨ 美之六 · 生日悖论的实测**:23 人即 50% 同生日——√365 ≈ 19.1,鸽笼原理的"平方根魔法"。为什么美:极简(一个抽屉)× 意外(直觉坚持要 183 人)。亲历:实验脚本加一段"随机抽 k 人群,统计同生日频率",k=23 处看曲线过半。

## 📌 认知升维(新眼睛)

1. **爆炸眼**:看到指数,先别怕——问"结构能不能压扁它"(树宽/对称/DP);压不扁才是真爆炸(#P)
2. **占比眼**:存在性问题先采样估占比——占比高,随机即答案;占比低,才需要真求解器
3. **编址眼**:组合对象可以像数组一样随机访问(rank/unrank)——枚举的_linear_ 替身

## ✍️ 练习

## 附录E · Prüfer 序列:双射变协议的样板(代码走廊的解剖课)

Cayley n^(n-2) 的 Prüfer 证明同时是一个**能直接写进网络协议的算法**:

```
encode(树):重复 n-2 次——摘掉标号最小的叶子,记录它的邻居;剩两边即止
decode(序列):度数表=出现次数+1;重复取标号最小、度数为 1 的点与序列头连边
```

十几行代码,双向可逆,树 ↔ 序列一一对应——**计数定理、证明、工程协议三位一体**。生成树协议(STP)的邻居协商、最小生成树的表示,用的就是这一族编码。组合学的"双射即证明"在工程界读作"双射即编解码器"。

## 附录F · 练习答案要点

1. 50% 同生日最小 n:N≈1.177√365 ⇒ n=23(精确计算 23 时 P≈0.507)
2. 8 皇后 CNF:64 个布尔变量 x_{ij};约束族:(a) 每行至少一后(8 子句×8 文字);(b) 每列至多一后(28×8 对);(c) 每对角线至多一后——变量数 64,子句数数百,pysat 秒解
3. K₅ 逃逸率对齐:40000 样本经验 0.01115 vs 理论 0.01172(偏差 4.9%);要压到 1% 需 ~5×10⁵ 样本(σ ∝ 1/√N 的现场课)
4. 星形树的 Prüfer 序列 = (1,1,…,1)(n-2 个 1):每次摘掉的都是最小叶子,记录的邻居永远是中心——与"n^(n-2) 中星形恰占 n-2 份"的计数相印证
