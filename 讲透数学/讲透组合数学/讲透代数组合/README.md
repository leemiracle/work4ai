# 讲透代数组合 · "结构会说话":对象内藏的自动计算器

> **定位句:这支负责证明"组合对象里预先埋着代数结构——结构常常替你把账算完"。**

## 诞生

- 1900 Frobenius 特征标理论 → 群与对称函数的组合学伏笔
- 1961 Schensted 的 RSK 对应(Knuth 1970 推广):排列↔杨表对,最长递增子序列获得代数坐标
- 1960s-70s Rota 把拟阵(matroid)与不变量理论组合化;"组合交换代数"由 Hochster/Stanley 在 1970s-80s 立为学科
- 2014 起 Keevash 存在性设计理论(方向锚):组合设计的存在-计数一体化纲领

## 核心问题

- ✅ 已解决:RSK 对应与对称函数主定理;Hook 长度公式(标准杨表计数);拟阵并定理
- ✅ 已解决(纲领级):Steiner 系统/设计组合存在性的充要条件(Keevash,方向锚)
- 📌 未解决:拟阵的 Rota 猜想消解程序(有限禁子构型刻画,Whittle 学派推进中)
- 📌 未解决:Schubert 多项式/几何表示组合化的全部正面推论(与代数几何界河,互链家族全景表)

## ✨ 这支最美的一个事实

**RSK 的对话**:任何排列 ↔ 一对同形标准杨表;于是"最长递增子序列长度"="杨表第一行长度"。纯顺序概念(递增)与纯形状概念(表的行)被一个双射永久绑定——两个世界互为镜像,数一个等于数另一个。
