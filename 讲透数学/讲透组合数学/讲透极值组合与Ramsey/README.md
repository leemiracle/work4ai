# 讲透极值组合与Ramsey · "最坏多大":无序必藏序

> **定位句:这支负责回答"最坏情形有多大"——阈值之上没有例外,阈值之下没有保证。**
> 自定主干支(GB/T 13745 11077 组合数学未列三级;家族宪法 2026-09-06)
> 家族:[讲透组合数学](../README.md)

## 诞生

- 1928 Ramsey:一阶逻辑可判定性研究的副产品——"足够大的集合任意染色必现单色规则子集"
- 1935 Erdős–Szekeres:单调子序列定理与"美满结局问题"(平面上足够多点必有凸 n 边形;81 年后 Suk 2016-17 近似收口,方向锚)
- 1946-47 Turán(极值图论)/ Erdős(概率方法下界 R(k,k)>2^{k/2}):极值问题的上下界夹击范式成型
- 2021 ALWZ 向日葵引理 60 年突破(检索校准,见家族 01 章)

## 核心问题

- ✅ 已解决:R(3,3)=6;Turán 定理(1941);EKR(1961);Sperner(1928);向日葵引理界 (w+1)^w→(log w)^w(2021)
- 📌 未解决:**R(5,5)**(43–48,外星人问题)/ **R(6,6)**(算力宇宙级);**向日葵猜想完整版 c^w**(Erdős 悬赏 $1000)
- 📌 未解决:Erdős–Szekeres 凸多边形猜想精确常数;Ramsey 数渐近阶(上下界仍隔多项式-指数鸿沟)
- 📌 未解决:R(4,t) 渐近阶(方向锚:近年下界 Ω(t³/log⁴t) 有突破)

## ✨ 这支最美的一个事实

**Ramsey 定理 = 无序的宿命**:任给 K₆ 的 15 条边任意染两色,单色三角形必然出现——秩序不需要设计者,**规模本身就是设计者**。有限版的它看似玩具,无限版却能推出集合论的大基数方向,一个"染色游戏"两头都通向深渊。
