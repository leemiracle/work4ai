# 讲透计数组合 · "多少种":双射、容斥与生成函数的会计学

> **定位句:这支负责回答"恰好多少种"——把数不清变成换一种数法。**
> 自定主干支(GB/T 13745 11077 组合数学未列三级;家族宪法 2026-09-06)
> 家族:[讲透组合数学](../README.md)

## 诞生

- 1654 Pascal–Fermat 点数通信:数等可能情形=算概率的第一步(与概率论同源)
- 贾宪三角(11 世纪)早 Pascal 600 年载录二项系数;印度 Pingala(约公元前 200)在诗律中已数组合
- 1730s de Moivre 发明母函数(生成函数雏形);1937 Pólya 把群作用接入计数——对称从敌人变武器

## 核心问题

- ✅ 已解决:Cayley n^(n-2)(1889,Prüfer 双射 1918);错排公式;Pólya 计数定理(1937)
- ✅ 已解决:Catalan 数统一(n 种结构同一序列:括号/格路/三角剖分/二叉树)
- 📌 未解决:无对称对象的渐近普适性(unlabelled 计数的解析理论仍在建设)
- 📌 未解决:与解析组合学(Analytic Combinatorics)的完全整合——奇点分析给出渐近,但多元情形远未完成

## ✨ 这支最美的一个事实

**Catalan 数的万物归一**:括号匹配、不越对角线的格路、凸多边形三角剖分、二叉树、非交叉配对——几十种"风马牛不相及"的结构,个数全是同一个序列 1,1,2,5,14,42,…,因为它们之间**全都有双射**。数列相等不是巧合,是同构的影子。

## 假设与依赖

- 依赖:高中计数(排列组合)、线性代数(Pólya 需要群作用,互链 [`../../讲透群论/`](../../讲透群论/))
- 假设:对象有限可枚举;对称群有限(无限对称的计数通向其它数学)
