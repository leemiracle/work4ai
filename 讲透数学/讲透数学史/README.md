# 讲透数学史 · 数学的自我意识——思想如何长成

> **本质一句话**:数学史=数学的自我意识——它不生产新定理,却回答每个定理背后的三个问题:**谁在什么动机下、用什么工具、在什么冲突中把它造出来的**。
> GB/T 13745-2009:110 **数学史**(GB/T 未列三级→本家族自定主干支,各支标注「自定主干支」)。
> 家族:讲透系列;五问五章为家族总纲,四支子系列各自由宪法 README 起步。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透数学史/
├── 讲透古代与中世纪数学史/  📝 泥板、纸草、羊皮卷:数学的文字化时代(前1800-1450)
├── 讲透近代数学史/          📝 符号化与无穷:从三次方程解到分析的严格化(1450-1900)
├── 讲透现代数学史/          📝 公理化、结构主义与计算转向(1900-今)
└── 讲透中国数学史/          📝 独立起源与汇入主流:《九章》到华罗庚(前200-今)
```

四线分期不是四段封闭历史,而是四个**视角**:古代线看「数学如何从计数劳动中脱离」,近代线看「符号如何解放思维」,现代线看「基础危机与结构革命」,中国线看「一条独立河流如何汇入世界海洋」。
