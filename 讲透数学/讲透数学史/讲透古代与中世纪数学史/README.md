# 讲透古代与中世纪数学史 · 泥板、纸草、羊皮卷:数学的文字化时代

> **定位句**:这支负责「数学如何从计数劳动中脱离、变成可传承的文字对象」——从前 1800 年的巴比伦泥板到 1450 年的抄本时代。
> GB/T 13745-2009:11011 数学史 · 本支为**自定主干支**(GB/T 未列三级)。家族:[讲透数学史](../README.md)。

## 诞生

本支作为一个学科方向,诞生于 **19 世纪破译潮**:楔形文字(1850s 起)与埃及圣书体(Champollion 1822)的解读让「古代数学」从传说变成可研究的一手领域;Otto Neugebauer(1930s)刊布《Mathematische Keilschrift-Texte》,建立古代精确科学史——**学科的诞生方式决定了它的证据观:泥板先于叙事**。

## 核心问题

已解决:
- 巴比伦「代数」的实际水平(二次方程常规操作、Plimpton 322 勾股数表)——Neugebauer 学派奠基性刊布与解读
- 希腊「证明」的制度化时间线(Euclid《原本》约前 300 为成熟标志,Thales/Eudoxos 为形成期)
- 中国《九章算术》成书于汉代、刘徽注(263)的极限思想地位(吴文俊路线重估)

未解决:
- **为什么证明只在希腊制度化?**(城邦辩论/贵族无功利/宗教哲学——无公认解释)
- Plimpton 322 的作者意图(教学用表?理论探索?)仍在争
- 失传文本的规模下界(《方法》靠一本重写本幸存=幸运下界,不是全集)

## ✨ 这支最美的一个事实

巴比伦泥板 YBC 7289(约前 1800 年)上,一个无名书吏把 √2 写成六十进制 1;24,51,10——**精确到小数点后六位**。比毕达哥拉斯学派早一千三百年,在一个完全没有「无理数」概念的文化里。

## 假设与依赖

- 依赖释读学(文字破译)与考古层位学(断代)
- 假设「泥板内容代表实践水平」——但泥板多为练习/行政副本,**理论尖峰可能未留下痕迹**(幸存者偏差在古代段最烈)
