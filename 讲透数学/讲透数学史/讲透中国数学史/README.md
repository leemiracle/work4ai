# 讲透中国数学史 · 独立起源与汇入主流:《九章》到华罗庚(前 200-今)

> **定位句**:这支负责讲清一条独立河流的全程——中国数学的独立起源、宋元高峰、明代衰落之谜、与近代主流的汇流,以及「算法取向」传统对今日数学的启示。
> GB/T 13745-2009:11011 数学史 · 本支为**自定主干支**。家族:[讲透数学史](../README.md)。

## 诞生

作为现代学科,本支诞生于两场接力:李俨与钱宝琮(1910s-1960s)在战乱中系统收集整理中国算书,奠定文献基础;**吴文俊(1970s 起)**提出「数学机械化」史观——指出中国传统数学是**算法化**路线(与希腊公理化路线平行),并从古算法(出入相补、大衍求一术)反哺机械化数学研究。吴的洞见让中国数学史从「民族志」变成「方法论」。

## 核心问题

已解决:
- 《九章算术》→刘徽注(263)→宋元四大家(秦九韶 1247/李冶 1248/杨辉/朱世杰 1303)的正史骨架
- 大衍求一术=中国剩余定理的算法形态;天元术=中国的符号代数;祖冲之密率 355/113 的精度地位
- 1607《几何原本》前六卷(利玛窦-徐光启)=与欧氏传统的正式接触边

未解决:
- **李约瑟问题数学版**:为什么宋元高峰后 14 世纪骤衰?(八股取士说/筹算技术锁定说/社会需求说,仍在争——家族 00 章 §5)
- 《九章》各章的层积成书过程(哪些是先秦遗产,哪些是汉人增补)
- 明代失传与清初中西会通的细节(《几何原本》后九卷为何拖到 1857 才译完)

## ✨ 这支最美的一个事实

1247 年,秦九韶在《数书九章》里给出「大衍求一术」——一次同余方程组的完整解法,与 Gauss 1801 年的规则同构,**领先 554 年**;1852 年伟烈亚力(A. Wylie)把它介绍到西方时,欧洲数学家起初不肯相信一个宋代文官已经解决过这个问题。

## 假设与依赖

- 依赖版本目录学(算书传世稀少,善本考据是地基)
- 假设「中算=独立传统」与「汇流=单向输入」都要小心:明末清初的会通派(梅文鼎)实际做了大量双向调和——汇流不是水管,是化学反应
- 警惕两个对称的坑:民族主义拔高(什么都「早于西方」)与欧洲中心贬低(算法传统「不算数学」)——**两条都是史学错误**
