# 数学史思维技能卡

## 1. 何时用此分支(触发词)

遇到以下特征的问题/困惑,切到数学史眼光:

- 「这个概念/记号/定义**怎么来的**?为什么这么定义?」(定义=历史的妥协)
- 「谁先发明」**优先权之争**(微积分/三次方程/最小二乘的经典判例)
- **学派与师承**:布尔巴基是什么、Göttingen 为什么神话、某人的学术血统
- **手稿与文本**:重写本、失传与复原、版本考据(《方法》/《九章》版本)
- **危机史**:三次数学危机到底危机了什么、怎么收场
- **传播与中心转移**:知识怎么从巴格达到巴黎到普林斯顿;中国数学何时汇入
- 「学这个定理卡住了,想看**诞生现场**找直觉」——历史语境是最好的直觉锚

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **语境主义** | 回到当时的工具/记号/制度再评价——用今天的标准判古人是「辉格史观」错误 |
| **路径依赖** | 记号与制度塑造思想(希腊几何化两千年、英国自闭于点记号)——「必然性」多为事后追认 |
| **传播路线** | 追翻译事件/留学群体/期刊创立三条可构造信号,而不是只追天才 |
| **证据分级** | 一手>二手>传说;每条断言的可信度写在句子里 |
| **幸存者警觉** | 留下的≠发生的;问「谁没被写下来」 |

## 3. 工具箱

- **一手文献法**:Oeuvres/Corpus 标准刊本;通信档案(优先权判定金标准)
- **编年对照**:世纪×领域切片表(本家族 `experiments/00_timeline.py` 即最小实现)
- **概念谱系**:概念依赖 DAG;警惕 anachronism(把现代概念名贴古代实践)
- **三方对勘**:文本A×文本B×实物/天文记录(年代学的「公理」来源)
- **谱系网络**:Mathematics Genealogy Project——收束率与断代裂缝(1933)
- **纪年换算**:儒略/格里/回历/年号干支;改元边界与无零年陷阱

## 4. 常见误区与禁忌

- ❌ **辉格史观**:把历史写成对今天的彩排;❌ **英雄史观**:只有主角没有结构
- ❌ 编造对话/心理(「他一定想到了…」)——文学化≠虚构,传说必须标注「传说」
- ❌ 反事实当结论:「若《方法》未失传则积分提前千年」只能作为标记过的反事实
- ❌ 忽视选样:任何「大事记」曲线度量的是关注度,不是产出
