# 讲透射影几何 · 透视的数学:平行线在无穷远重逢

> **定位句**:这支负责"投影下不变"的几何——画家怎么把三维世界压进画布,
> 数学就怎么把无穷远点拉进可触摸的范围;交比与对偶是它的两枚勋章。
> GB/T 13745 11027 三级「射影几何学」|家族:[讲透几何学](../README.md)

## 诞生

**Brunelleschi 1415** 佛罗伦萨洗礼堂透视实验(艺术史与数学史共享的奇点);
**Desargues 1639** 写出第一本射影几何专著,生前几乎无人理睬;
**Poncelet 1822** 在俄国战俘营(拿破仑征俄被俘)写《论图形的射影性质》——
数学史上最传奇的"狱中著作";Klein 用射影圆盘给双曲几何造模型(1871)。

## 核心问题

- 已解决:交比不变量;对偶原理(点↔线互换定理自动为真);Desargues/Pappus 定理;
  射影平面=仿射平面+无穷远直线;齐次坐标(Plücker)
- 未解决:有限射影平面的存在性(12 阶射影平面不存在 1989 计算机证明;
  一般阶数仍是组合数学的开放矿——接口在组合/离散家族)

## ✨ 这支最美的一个事实

**对偶原理**:把射影平面上任何定理的"点"与"线"互换,结论自动成立——
两千条定理免费翻倍。而这一切的代价只是:承认平行线相交于一个"无穷远点"。

## 假设与代价

加无穷远元素:买到对偶+无例外(没有"平行"这个特区);付出可定向性
(射影平面单侧——蚂蚁爬一圈就翻面)与"内外"的绝对意义。
