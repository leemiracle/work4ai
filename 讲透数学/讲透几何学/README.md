# 讲透几何学 · 空间的语法:从欧几里得到宇宙的形状

> **本质一句话**:几何学=研究空间、形状与位置的数学——它告诉你"直"是什么、"弯"怎么量、
> 宇宙可能是什么形状。Klein 1872 年一言以蔽之:**一种几何 = 某个变换群下的不变量理论**。
>
> GB/T 13745-2009:11027 几何学(三级 10 支,本家族全落子)|家族=讲透系列;
> 五问五章在家族层回答一遍,十支子系列各自由宪法 README 起步。

## 〇、家族树(Q1 的答案 = 这棵树)

```
讲透几何学/
├── 讲透几何学基础/    公理方法本身(Euclid 尝试→Hilbert 1899 完成;独立性/一致性/完备性)
├── 讲透欧氏几何/      《几何原本》两千年:三角形/圆/作图的综合几何
├── 讲透非欧几何/      第五公设的解放:双曲(Lobachevsky/Bolyai)与椭圆(Riemann)
├── 讲透球面几何/      航海与星空:正曲率的原型,内角和>π 的世界
├── 讲透向量与张量分析/ Gibbs/Heaviside 解放向量;张量=广义相对论的语言
├── 讲透仿射几何/      保持平行性的几何:线性变换+平移,Euler/Möbius
├── 讲透射影几何/      文艺复兴透视画法→Desargues;交比与对偶;含无穷远点
├── 讲透微分几何/      曲面的微积分:高斯曲率/测地线/Gauss–Bonnet/黎曼几何
├── 讲透分数维几何/    分形:海岸线悖论与自相似,Mandelbrot
└── 讲透计算几何/      几何的算法面:凸包/Voronoi/Delaunay(与计算数学双归属)
```
