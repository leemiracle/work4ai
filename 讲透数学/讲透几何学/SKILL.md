# 几何学思维技能卡(讲透几何学)

## ① 何时用此分支(问题特征触发词)

遇到下列特征,先想到几何学:

- **"弯曲/曲面/曲率"**——对象有形状,且"弯的程度"是关键变量(镜头、时空、网格、表面拟合)
- **"最短路径/测地/航线"**——在弯曲空间或带约束的空间里问"怎么走最近"
- **"对称/旋转/变换/不变量"**——问题里某些操作(旋转、平移、投影)前后"什么没变"是核心
- **"投影/透视/齐次坐标/相机"**——3D→2D 或维度变化的表示问题(渲染、视觉)
- **"距离/度量/邻近划分"**——点集之间的几何关系(最近邻、Voronoi、聚类几何)
- **"网格/三角剖分/离散表面"**——几何对象的计算表示(CFD/图形学)
- **"分形/自相似/尺度依赖"**——测量结果随尺度变化(海岸线、网络拓扑粗糙度)
- **"公理可以换吗/这套假设独立吗"**——想检验假设体系本身的自由度

## ② 核心思维模式

1. **不变量优先**:任何分类/比较问题,先找"变换下不变的东西"——不变量是硬通货
   (Klein:一种几何=一个变换群的不变量理论);
2. **内蕴视角**:判断性质先问"住在空间内部的居民能否发现它",而非"从外面看像什么"
   (Gauss 绝妙定理:曲率是内蕴的);
3. **公理可换**:天经地义=一组可选假设;换掉一条,评估"买到什么/付出什么"(平行公设的教训);
4. **曲率当数据**:弯曲不是缺陷,是载荷信息的量(角盈正负号=曲率指纹);
5. **软硬分层**:拓扑(软)→共形→度量(硬)逐层问"这层信息由上层决定了多少"(刚性)。

## ③ 工具箱(方法名 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| Gauss–Bonnet(∫K dA=2πχ) | 把逐点弯曲与全局拓扑对账(离散版=角亏求和) |
| 测地线方程 / 大圆 | 弯曲空间里的"直线"与最短路径问题 |
| Erlangen 纲领(群+不变量表) | 识别问题属于哪层几何(欧氏/仿射/射影/拓扑) |
| 齐次坐标与 4×4 矩阵 | 一切渲染/机器人变换管线 |
| 交比 | 射影场景下唯一幸生的量(透视校正) |
| 域塔判据(Galois) | 判断某量能否尺规/折纸构造 |
| Voronoi/Delaunay | 邻近划分、网格生成("最不瘦三角形") |
| 离散微分几何(cotangent 权重) | 网格上估计法向/曲率/拉普拉斯 |
| Hausdorff/盒维数 | 分形对象的"稳定测量" |
| 指数映射/李群积分器(SE(3)) | 刚体运动不漂移的数值保证 |

## ④ 常见误区与禁忌

- **把嵌入当内蕴**:纸卷成圆柱"看起来弯",高斯曲率仍为 0——先问性质是否内蕴;
- **在欧氏地图上解球面问题**:航线/大圆距离用平面图会系统性出错;
- **以为双曲几何是"假想"**:它是逻辑上与欧氏同等自洽的几何,且是复分析/数论的日常工具;
- **离散化时只顾精度丢对称**:破坏几何结构的离散格式会出伪影/数值不稳定;
- **把"不可构造"当"没找到"**:尺规不可能性是定理不是懒惰(Wantzel/Galois)。

## ⑤ 与相邻分支的判别 + 组合接口

**判别表**:

| 如果问题重心是… | 去 |
|----------------|---|
| 洞/连通/粘合,不问距离 | 拓扑学(讲透拓扑学家族;现有 [`../讲透代数拓扑/`](../讲透代数拓扑/)) |
| 多项式方程的解集形状 | 代数几何(讲透代数几何家族) |
| 方程的解/极值(分析对象) | [`../讲透分析/`](../讲透分析/README.md) |
| 对称群的代数结构 | [`../讲透Artin抽代/`](../讲透Artin抽代/) |

**组合接口**:
- 几何×PDE = 几何分析(极小曲面/Ricci 流,01 章主战场);
- 几何×代数 = 代数几何/变换群(Erlangen 的代数面);
- 几何×概率 = 高维几何/最优传输(数据科学的几何面);
- 几何×算法 = 计算几何(本家族 [讲透计算几何](讲透计算几何/),与计算数学双归属);
- 几何×逻辑 = 公理独立性/Tarski 可判定(02 章)。
