# 讲透向量与张量分析 · 有方向的代数:从四元素战争中解放

> **定位句**:这支负责"带方向的量"的代数——向量怎么合法运算、张量怎么成为
> 坐标无关的多线性对象;它是几何家族的**计算方言**,也是广义相对论的母语。
> GB/T 13745 11027 三级「向量和张量分析」|家族:[讲透几何学](../README.md)

## 诞生

Grassmann 1844《扩张论》(生前被无视的杰作)创立线性代数+外积雏形;
Hamilton 1843 在都柏林运河桥上刻下四元数公式 i²=j²=k²=ijk=−1;
**Gibbs 与 Heaviside 1880s** 从四元数"内积/外积"解放出实用向量分析
(与四元数派的"向量大战"是数学史上著名的路线之争);
**Ricci–Levi-Civita 1900** 张量分析(绝对微分学)——爱因斯坦 1915 直接取用。

## 核心问题

- 已解决:向量空间公理化(20 世纪);梯度/散度/旋度的坐标无关本质(微分形式);
  张量=多线性映射;爱因斯坦求和约定
- 未解决(工具面):教学之痛——指标记法对新手的高墙(几何代数/无坐标方法能否替代是持续争论)

## ✨ 这支最美的一个事实

**梯度/散度/旋度其实是同一个对象**:外微分 d 作用在不同阶微分形式上——
grad=d on 0-forms,curl=d on 1-forms,div=d on 2-forms,
而 d∘d=0 正是"梯度的旋度为零、旋度的散度为零"的统一原因。
三张面孔,一个算子(深挖入口:[`../../讲透分析/`](../../讲透分析/README.md) 的微分形式)。

## 假设与依赖

线性代数本体(域上向量空间)在讲透代数学家族(并行建族中)的线性代数支;
本支取其几何面:度量/对偶/正交群;[`../../讲透数值线代/`](../../讲透数值线代/) 承担计算面。
