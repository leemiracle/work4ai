# 04 · 几何学转代码:把"空间"搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?
> **本质一句话**:几何学是**最早被机器化的数学**之一——Tarski 证明了初等几何可判定,
> 吴文俊造出了定理机器证明的中国学派,而你的 GPU 每秒执行几十亿次射影变换;
> 几何与代码之间,从来不缺桥。

## 〇、开场故事:吴文俊与"数学定理的生产线"

📖 1977 年,吴文俊在一台国产计算机上跑出了第一批结果:初等几何定理的**机器证明**。
方法(吴方法/Wu's method):把几何命题的假设与结论全部多项式化,
再用**特征列**(characteristic set)算法做"几何版的消元法"——
假设多项式整除结论多项式(在非退化条件下),定理即证。
数百个非平凡的欧氏几何定理(包括不少连数学家都没见过的新定理)被机器批量"生产"出来。
2000 年,吴文俊获首届国家最高科学技术奖。
他的洞见至今闪闪发光:**几何定理的"难度"很多时候是语言的难度——
换成多项式语言,推理变成整除**。这和 Leibniz 三百年前的梦(characteristica geometrica)
隔空击掌。

## 一、可机械化边界(三件套之一):哪些几何问题机器能"判决"

### 能机械化的

| 问题类 | 方法 | 边界说明 |
|--------|------|---------|
| **初等几何定理判定** | Tarski 决策程序(量词消去);吴方法(多项式整除);Gröbner 基 | Tarski 证明一阶初等几何**可判定**(02 章);复杂度高达超指数,但"原则上可判" |
| **坐标计算** | 一切能写成方程组的问题(求交点、求变换、求投影) | 线性/多项式方程组=数值线代/符号计算的领地:[`../讲透数值线代/`](../讲透数值线代/) |
| **测地线/曲率流** | ODE/PDE 数值解(欧拉、RK、有限元) | 逼近而非精确——存在性与数值稳定性是两本账(见三) |
| **离散几何算法** | 凸包/最近点对/Voronoi 等 | 组合算法,复杂度有硬下界(凸包 O(n log n)):[计算几何](讲透计算几何/) |

### 不可(或尚不能)机械化的

| 问题类 | 卡在哪 |
|--------|--------|
| 高阶存在性(极小曲面/正质量类) | 证明靠紧性/min-max 等软论证,机器只能**数值见证**特例(01 章的定理本体不可批量) |
| 尺规可构造性判定 | 可机械化(Galois 群计算)但依赖符号代数引擎的健壮性——sympy 可做小例 |
| 大规模网格上的曲率估计 | 离散微分几何(DDG)给出**一致估计**,但"哪个网格上哪个公式收敛"仍有开放问题 |

**判别式**:几何问题能机械化 ⟺ 能把"真"归约为**有限符号计算的可满足性**
(判定)或**方程组的可解性**(构造)。一旦要"对所有 X 存在 Y 且 Y 连续"这类多层量词+连续性,
机器就只能退居数值见证。

## 二、代码走廊清单(三件套之二):几何学的六条代码走廊

```
走廊1 坐标变换线:仿射/射影齐次坐标 → 4×4 矩阵乘法(GPU 每帧都在跑)

走廊4 离散微分几何线:网格上估计法向/曲率/拉普拉斯(cotangent 权重)——图形学的数学内核
走廊5 机器证明线:多项式消元(吴方法/Gröbner)——几何定理批量生产
走廊6 距离几何线:SVD/最近正交矩阵/等距嵌入近似(Procrustes/MDS)——数据科学的几何面
```

## 三、工程师落点(三件套之三,性能工程视角)

| 场景 | 几何定理 | 工程兑现 |
|------|---------|---------|
| **图形渲染管线** | 齐次坐标(射影几何) | 顶点着色器=4×4 矩阵乘;透视除法=射影规范化;深度缓冲的透视校正插值=交比校正 |
| **机器人学** | SE(3)=欧氏×旋转群;指数映射 | 正/逆运动学=群上的方程;李群积分器保证"转完还是正交的"(避免漂移) |
| **GIS/导航** | 大圆=测地线;Girard 盈余 | 航线规划用球面三角不用平面地图;椭球修正(Vincenty 公式)是精度工程 |
| **网格生成(CFD/CG)** | Delaunay 空圆性质 | "最不瘦三角形"=数值稳定性(避免有限元刚度矩阵病态);Voronoi 自然的邻近划分 |
| **GPU/张量核** | 等距不变性 → 正交矩阵 | SVD/QR 的数值稳定性来自正交性——几何性质=数值性质 |
| **神经网络几何** | 流形假设/最优传输 | 表示学习=学习数据流形;Wasserstein 距离=度量几何+概率 |

**性能工程的两条硬经验**(供 [`../讲透应用数学/`](../讲透应用数学/) 的读者):
1. **几何不变量=数值稳定的来源**:凡是保持正交/体积的算法(QR/SVD/辛积分器),
   误差不放大——**刚性即稳定**;
2. **离散化必须尊重对称性**:网格上算拉普拉斯要用 cotangent 权重(它在三角形翻转下表现正确),
   朴素差分破坏对称→伪影。离散几何的教训:**先保结构,再谈精度**。

## 四、家族实验:Gauss–Bonnet 三连测(本章的落地)

本家族实验 [`experiments/00_gauss_bonnet.py`](experiments/00_gauss_bonnet.py) 演示三件事:

1. **多面体角亏(Descartes 定理)**:立方体每个顶点缺 90°,8 个顶点正好缺 4π=2π·χ——
   Gauss–Bonnet 的离散原型;
2. **球面三角形(Girard)**:内角和−π = 面积——曲率为 +1 时"角度就是面积";
3. **双曲三角形(Poincaré 圆盘)**:蒙特卡洛积分测面积,与 π−角和对照——
   同一本账,曲率换成 −1,盈余变亏损。

跑法:`python 讲透数学/讲透几何学/experiments/00_gauss_bonnet.py`
(纯标准库;三幕断言全部自验证)。

## 五、反直觉发现(讲透铁律)

**反直觉:图形学根本不画三维,它画的是射影几何。**
屏幕上的一切先被投到二维裁剪空间(w 除法),深度只是 z/w 的一个比值;
"透视校正纹理插值"的本质是**交比不变量**——文艺复兴画家凭直觉遵守的法则,
在 GPU 里是硬件电路。**你以为在玩 3D 游戏,其实你在玩射影几何。**

## 📌 收束 + 认知升维

几何是机器化最早、工程兑现最深的数学家族之一:判定(Tarski/吴)、
构造(坐标/算法)、逼近(DDG/数值测地)、渲染(射影矩阵)。

**这章给了你什么新眼睛**:
- **可判定预算眼**:拿到几何问题,先估"判定类 or 构造类 or 见证类"——
  三类问题的算法期望完全不同;
- **结构保真眼**:离散化/工程实现时,先问"我保住了哪个不变量"(正交?交比?对称?)——
  保结构比保精度更根本;
- **几何即性能眼**:数值稳定性、GPU 管线、机器人运动学,底座都是几何定理——
  几何不是"数学里的绘图课",是工程世界的隐性基础设施。
