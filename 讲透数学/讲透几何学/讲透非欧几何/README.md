# 讲透非欧几何 · 第五公设的解放:从"异端"到宇宙的语法

> **定位句**:这支负责平行公设被换掉之后的几何——双曲几何(过线外一点有无穷多平行线)
> 与椭圆/黎曼几何(没有平行线),以及"换公理"这件事本身带来的思想地震。
> GB/T 13745 11027 三级「非欧几何学」|家族:[讲透几何学](../README.md)

## 诞生

Gauss 私下研究终身不发表(怕"波哀提亚人的叫嚷");**Lobachevsky 1829** 首发双曲几何;
**Bolyai 1832** 独立发表(豪言:"我从虚无中创造了一个全新的世界");
**Riemann 1854** 就职演讲引入椭圆几何(无平行线)与任意弯曲空间;
**Beltrami 1868** 造出伪球面模型,证明双曲几何相对一致——"异端"转正。

## 核心问题

- 已解决:双曲几何相对一致性(Beltrami 模型);双曲三角学(Lobachevsky 自己发展);
  三种常曲率几何的分类;Klein 圆盘/Poincaré 上半平面两大模型
- 未解决:双曲几何在数论中的应用仍有新矿(模形式/双曲 3 维流形,Mostow 刚性下游;
  见 [../03-可构造与结构.md](../03-可构造与结构.md))

## ✨ 这支最美的一个事实

双曲世界里**所有"理想三角形"(顶点在无穷远的三角形)面积相等(=π)**——
"大小"由"角度"单方面决定,相似而不全等的三角形不存在。
一面镜子照出欧氏几何里"大小与形状独立"这件事根本不是宇宙定律。

## 假设与代价

换掉平行公设:买到一族几何+广义相对论舞台;付出全局相似、平行直觉、
"矩形存在"(双曲无矩形!)。模型实现依赖 [讲透射影几何](../讲透射影几何/README.md)
(Klein 模型=射影圆盘)与 [`../../讲透分析/讲透复分析/`](../../讲透分析/讲透复分析/)
(上半平面模型=复分析主场)。

Geometry》(双曲可视化章)
