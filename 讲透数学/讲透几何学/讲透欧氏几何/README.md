# 讲透欧氏几何 · 两千年的教科书:三角形、圆与作图的艺术

> **定位句**:这支负责《几何原本》的遗产——用综合方法(图与公理,不用坐标)研究
> 三角形/圆/多边形,以及"尺规能做什么"这门精确的手艺学。
> GB/T 13745 11027 三级「欧氏几何学」|家族:[讲透几何学](../README.md)

## 诞生

Euclid《原本》约公元前 300 年汇编成 13 卷 465 命题,此后两千年是西方世界
发行量仅次于《圣经》的书。中国系统的几何传统见《周髀算经》《九章算术》
(勾股特例早有记载)——东西方对"直角三角形"的独立发现是文明史的平行实验。

## 核心问题

- 已解决:勾股定理(卷 I 命题 47);三角形五心(重心/外心/内心/垂心/九点圆);
  圆幂定理;Ceva 与 Menelaus;**三大作图不可能性**(倍立方/三等分角/化圆为方,
  Wantzel 1837/Lindemann 1882,见 [../03-可构造与结构.md](../03-可构造与结构.md))
- 未解决:欧氏几何的"漂亮定理矿脉"没有枯竭期(新定理至今每年出现——
  计算机辅助发现,见 [../04-几何学转代码.md](../04-几何学转代码.md) 吴方法)

## ✨ 这支最美的一个事实

勾股定理有 **400+ 种已知证明**:Euclid 的面积拼图、Garfield(美国未来总统)1876 的
梯形法、爱因斯坦 12 岁的自创法、中国古代的"弦图"出入相补——
**一个事实,四种文明的四种思路**,是"定理的多重宇宙"最佳展品。

## 假设与依赖

平行公设(买到相似理论/勾股;付出曲率锁死);严格性靠
[讲透几何学基础](../讲透几何学基础/README.md) 的公理机器兜底。

## 教材锚

Hartshorne《Geometry: Euclid and Beyond》后半 · 《几何原本》中译本( stout 直读体验)
