# 讲透微分几何 · 曲面的微积分:从高斯的绝妙定理到宇宙的曲率

> **定位句**:这支负责"用微积分研究几何"——曲线曲面的弯、测地线的直、
> 黎曼度量的坐标无关;它是几何家族的**枢纽支**:向上接非欧(常曲率=特例),
> 向外接物理(广义相对论)与机器学习(流形假设)。
> GB/T 13745 11027 三级「微分几何学」|家族:[讲透几何学](../README.md)

## 诞生

**Gauss 1827**《曲面的一般研究》:高斯曲率+绝妙定理(曲率是内蕴的);
**Riemann 1854** 就职演讲把维度与度量彻底解放;
Ricci/Levi-Civita 1900 张量分析;**Einstein 1915** 广义相对论兑现;
**Chern(陈省身)1944** 内蕴证明高斯–博内定理——现代整体微分几何的开门之作。

## 核心问题

- 已解决:绝妙定理;Gauss–Bonnet(局部→全局对账);测地线方程;常曲率分类;
  三维流形几何化(Perelman 2003,Ricci 流);**Yau 猜想主项(Song 2023,无穷多极小超曲面)**
- 未解决:光滑 4 维 Poincaré;Ricci 流奇点的完整分类(2020s 持续推进,Bamler 地基);
  Willmore 型泛函的深层结构

## ✨ 这支最美的一个事实

**绝妙定理(Theorema Egregium)**:高斯曲率只依赖曲面自身的度量,
与它嵌在空间里的方式无关——纸卷成圆柱曲率仍是 0,球面怎么摊都摊不平。
蚂蚁不用跳出曲面就能测出世界的曲率;同理,我们不用跳出宇宙就能测时空弯曲——
**广义相对论的方法论就藏在这条定理里**。
