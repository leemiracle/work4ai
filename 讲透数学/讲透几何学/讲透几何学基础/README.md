# 讲透几何学基础 · 公理方法本身:几何的"立法学"

> **定位句**:这支不管任何具体几何,它管**公理系统这台机器**——独立性、一致性、完备性怎么证,
> "换一条公理会怎样"怎么系统化。
> GB/T 13745 11027 三级「几何学基础」|家族:[讲透几何学](../README.md)

## 诞生

Euclid《原本》(~300 BC)首次把一门学问立法(5 公设+5 公理);
两千年后人发现法条有漏洞(叠合公理缺位、"介于"未定义),直到 **Hilbert 1899《几何基础》**
(Geometry: Euclid and Beyond 的前半即此)给出完全公理化:关联/顺序/叠合/平行/连续五组公理,
并逐条用**造模型法**证明独立性与(相对)一致性。公理从"自明真理"正式降格为"可选立法"。

## 核心问题

- 已解决:各公理组的独立性(Hilbert 模型法);欧氏几何相对一致性(解析模型→算术);
  Tarski 初等几何的一阶化(完备+可判定)
- 未解决:几何直觉与形式系统的"界面"问题(什么值得形式化/代价是什么——数学哲学常青题)

## ✨ 这支最美的一个事实

要证公理 A 独立,**造一个模型:其余公理全真、A 假**——非欧几何(否定平行公设的模型)
把"独立性证明"升格为通用方法论:**反例空间本身就是数学对象**。
