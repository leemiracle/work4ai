# 讲透计算几何 · 几何的算法面:凸包、Voronoi 与扫描线

> **定位句**:这支负责"几何问题怎么算"——给定点集/线段/多边形,
> 设计有复杂度保证的算法:凸包 O(n log n)、Voronoi 图、Delauany 三角剖分、点定位。
> 与「讲透计算数学」(11061)双归属:本支管**几何内核**的算法设计,
> 对面管数值算法的分析传统(消歧见 [`../../GB-T13745全景.md`](../../GB-T13745全景.md) §三)。
> GB/T 13745 11027 三级「计算几何学」|家族:[讲透几何学](../README.md)

## 诞生

**Shamos 1975** 博士论文命名"计算几何"(computational geometry);
Voronoi 图概念 1908(Voronoi)/1850(Dirichlet)早有;
Delaunay 1934 给出对偶;1970s–80s MIT/Stanford 建军
(Graham 扫描 1972、Fortune 扫描线 1986 平面扫荡);自此几何问题有了"复杂度"这一考核指标。

## 核心问题

- 已解决:凸包(排序下界 O(n log n));最近点对(分治 O(n log n));
  Voronoi/Delaunay(Fortune 扫描线 O(n log n));点定位(持久化数据结构 O(log n))
- 未解决:高维最近邻的"维数诅咒"下界(高维几何=近似算法/LSH 的战场——
  接口在 [`../../讲透高维概率/`](../../讲透高维概率/));动态几何数据结构的完整Tradeoff表

## ✨ 这支最美的一个事实

**Voronoi 图与 Delaunay 三角剖分互为对偶**:n 个邮局的"势力范围划分"与
"最不瘦三角剖分"是同一枚硬币的两面——空圆性质保证 Delaunay 三角形不会太瘦,
这正是有限元网格不病态的几何保证。**一份数据,两份产品,都免费**。

## 假设与依赖

实数 RAM 模型(算术免费)或字长模型;退化处理(共线/重合)是工程地狱,
symbolic perturbation 是救命稻草;复杂度分析依赖
[`../../讲透计算复杂度/`](../../讲透计算复杂度/) 的语言。
