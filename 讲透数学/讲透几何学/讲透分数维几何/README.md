# 讲透分数维几何 · 分形:云不是球,山不是锥,海岸线不是直线

> **定位句**:这支负责"粗糙与自相似"的几何——测量结果随尺度变化的对象,
> 维数可以是分数;它把"长度"这个两千年的默认量词请下神坛,换上"维数"。
> GB/T 13745 11027 三级「分数维几何」|家族:[讲透几何学](../README.md)

## 诞生

Cantor 1884 三分集(第一只"病态怪物");von Koch 1904 雪花曲线;
**Richardson 1961** 实测各国海岸线:长度取决于尺子(L(ε)∝ε^(1−D));
**Mandelbrot 1967《英国海岸线有多长?》** 一锤定音,1975 造词 fractal,
1982《大自然的分形几何学》宣布:**经典几何是数学家的玩具,分形才是大自然的语言**。

## 核心问题

- 已解决:盒子维数/Hausdorff 维数的定义与基本性质;迭代函数系统(IFS)拼贴定理;
  Mandelbrot 集的连通性(Douady–Hubbard)
- 未解决:Mandelbrot 集边界是否局部连通(MLC——分形的千禧级悬案);
  分形维数的有效估计(实测对象的 D 估计是统计难题)

## ✨ 这支最美的一个事实

Koch 雪花:面积有限(小于外接圆),周长**无穷**——
一条"围住有限面积的无限长篱笆"。"长度"这个量词在分形面前失效,
而维数 D=log4/log3≈1.26 稳定存在——**换量词,世界重新可测**。
