# 讲透仿射几何 · 平行性的几何:欧氏与射影之间的中间层

> **定位句**:这支负责"保持平行性"的几何——线性变换+平移下不变的性质;
> 它是欧氏(去距离)与射影(挖一条线)之间的台阶,也是图形学"均匀拉伸"的数学名。
> GB/T 13745 11027 三级「仿射几何学」|家族:[讲透几何学](../README.md)

## 诞生

Euler 1747 用 affine 概念研究曲线仿射变换下的性质;**Möbius 1827**《重心计算》
引入重心坐标,给仿射几何以系统工具;Klein 1872 Erlangen 纲领给它正名:
**仿射群 = 一般线性群+平移**,不变量=平行性、共线单比、面积比。

## 核心问题

- 已解决:仿射不变量清单(平行/单比/面积比/中点);重心坐标;仿射变换=矩阵+平移;
  凸集理论(分离定理——优化理论的几何地基)
- 未解决(形态面):仿射微分几何的活跃度远低于黎曼,但其凸几何分支(CMU 学派)
  仍在产出(等周问题的稳定性等)

## ✨ 这支最美的一个事实

所有三角形在仿射几何眼里**等价**——任一三角形仿射等价于任一其他三角形。
于是"椭圆内接 n 边形面积何时最大"这类问题可以仿射地把椭圆拍成正圆、
把问题变成圆的问题再拍回去——**仿射变换是几何题的"换元法"**。
