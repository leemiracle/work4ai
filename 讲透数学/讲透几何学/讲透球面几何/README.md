# 讲透球面几何 · 星空与航海:正曲率世界的第一现场

> **定位句**:这支负责球面上的几何——大圆、球面三角形、球面三角学;
> 它是人类第一门"非欧"几何(虽然两千年来没人这么叫它):我们本来 就住在一个球上。
> GB/T 13745 11027 三级「球面几何学」|家族:[讲透几何学](../README.md)

## 诞生

Menelaus(~100 AD)《球面学》立球面三角学;托勒密天文表;
大航海时代(Vespucci/哥伦布航线)让它成为"救命数学";**Girard 1629** 证明
球面三角形面积=内角盈余——比 Gauss 一百年多前就摸到了曲率与角盈的关系。

## 核心问题

- 已解决:球面正弦/余弦定理;Girard 盈余定理(面积=盈余,单位球);
  大圆=测地线;地图投影学(Mercator 等角投影 1569)
- 未解决(工程面):椭球修正的高效算法(GPS 时代 Vincenty/Karney 迭代的精度-速度权衡)

## ✨ 这支最美的一个事实

三直角三角形:三条两两垂直的大圆围出八分之一球面,内角和 270°——
**盈余 90° 恰好等于面积 π/2**。"角度里藏着面积"第一次被写进定理
(可跑 [../experiments/00_gauss_bonnet.py](../experiments/00_gauss_bonnet.py) 幕二实测)。
