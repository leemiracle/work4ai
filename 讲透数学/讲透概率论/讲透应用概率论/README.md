# 讲透应用概率论 · 概率的工具出口

> **定位句**:排队、可靠性、网络、流行病——把全家定理装进工程问题的接口层。
> GB/T 11064 三级「应用概率论(具体应用入有关学科)」。家族:[讲透概率论](../README.md)|五问模板家族成员

## 诞生

📖 Erlang 1909 在哥本哈根电话公司算「一个接线员能接多少路电话」——
泊松过程+生灭方程诞生**排队论**,运筹学的前身(比「运筹学」这个词早 40 年)。
二战后可靠性工程、库存论相继成型;2020 年疫情把 SIR/分支过程推成公众词汇。

## 核心问题

- 已解决:Little 定律 L=λW(**零分布假设**的守恒律);生灭过程与 M/M/1 全解;
  可靠性的 MTBF/失效率浴盆曲线;Poisson 鞅的破产界(Cramér–Lundberg,保险数学接口);
  流行病阈定理 R₀>1 ⟹ 爆发(分支过程灭绝的对偶)
- 未解决/活跃:数据中心/LLM 推理服务的新排队形态(重尾到达、弹性容量——性能工程现场);
  网络可靠性在高维下的可扩展计算;流行病模型的随机终结(stochastic extinction)精细理论

## 最美的一个事实

**Little 定律 L = λW**:系统内平均人数 = 到达率 × 平均停留时间。
为什么美:**不需要任何分布假设**(不用知道到达是不是泊松、服务是不是指数)——
一条几乎纯逻辑的守恒律,却是从超市排队到 TCP 拥塞控制通用的「欧姆定律」。
(本支家族级实验可三行验证:模拟 M/M/1,L̂=λ̂·Ŵ。)

## 假设与依赖

- 稳态假设(系统运行足够久)是 Little 定律的票价;非稳态(启动/崩溃)要瞬时版
- 「具体应用入有关学科」(GB/T 释义):工程侧的深水区归各应用家族(排队深读→运筹家族·排队论支,建设中)
