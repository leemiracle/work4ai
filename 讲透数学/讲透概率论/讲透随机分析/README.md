# 讲透随机分析 · 布朗运动上的微积分

> **定位句**:布朗轨道没有速度(变差爆炸),经典微积分失效——**再造一套带二阶修正的新微积分**,
> 就是随机分析。GB/T 11064 三级「随机分析」。家族:[讲透概率论](../README.md)|五问模板家族成员
> **两岸声明**:[../../讲透分析/](../../讲透分析/) 家族长尾表声明「概率侧本体归概率书架」——本支即本体家,
> 其 SPDE/动力系统内节为对岸入口。

## 诞生

📖 Itô 1942-1944 在战时日本独立创立随机积分与 Itô 引理——为了给 Kolmogorov 扩散方程以轨道意义。
70 年代金融发现它:Black-Scholes(1973)的骨架就是 Itô 引律+无套利,1997 诺奖。
Lyons 1998 粗糙路径、Hairer 2014 正则性结构(Fields)把「新微积分」从一维时间推到无穷维场——
2021-2026 已成 SPDE 的「本质上完备的解理论」(家族 01 章检索校准)。

## 核心问题

- 已解决:Itô 积分对 adapted 被积函数的构造;Itô 公式(链式法则的二阶修正);
  SDE 强/弱解存在唯一(Yamada-Watanabe);Girsanov 变换(换测度=换漂移);
  停时与反射布朗运动的刻画;Black-Scholes 完备市场定价
- 未解决/活跃:粗糙路径/正则性结构的重整化代数化;SPDE 解的结构性质(大偏差、扩散近似);
  随机流体力学方程的整体解;波湍流动能方程的严格推导(2026 Fields·Yu Deng 线,见家族 01 章)

## 最美的一个事实

**Itô 引律 df(B_t) = f'(B_t)dB_t + ½f''(B_t)dt**:比经典链式法则**多出半项**。
为什么美:二次变差 [B]_t = t 把「噪声的平方」兑换成「时间」——这半项是随机世界的弯曲时空;
没有它,Black-Scholes、滤波理论、随机控制全部崩塌。一个 ½ 因子支撑一个行业。

## 假设与依赖

- 被积函数必须 adapted(不能偷看未来)——可料性是积分存在的纪律
- Itô vs Stratonovich 之选:金融(自融资)用 Itô,物理(极限逼近)用 Stratonovich——语境决定语言
