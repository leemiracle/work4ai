# 讲透马尔可夫过程 · 忘掉历史只看当下

> **定位句**:假设未来只依赖现在、不依赖过去的来路——一条「无记忆」假设买到整座定理大厦,
> 并换来 MCMC 这台计算引擎。GB/T 11064 三级「马尔可夫过程」。家族:[讲透概率论](../README.md)|五问模板家族成员

## 诞生

📖 Markov 1906 研究普希金《叶甫盖尼·奥涅金》元音/辅音的字母序列,
证明「相依链」也有大数定律——**第一次把独立性假设拆松**。
1953 年 Metropolis 在核武器实验室把遍历定理反过来用:造一条以目标分布为平稳分布的链,
让数学定理变成随机数发生器(MCMC)——20 世纪最被引用的算法家族之一。

## 核心问题

- 已解决:离散链的遍历定理(不可约+正常返⟹唯一平稳分布+时间平均=空间平均);
  细致平衡与可逆性;收敛速率的谱隙/耦合刻画;扩散过程=连续时间极限
- 未解决/活跃:混合时间的普适下界(指数尾 vs 多项式尾的分界);
  非可逆链/确定性提升混合加速;图上随机游走的覆盖时间;与统计物理(Gibbs 采样)的界面

## 最美的一个事实

**细致平衡 π(x)P(x→y) = π(y)P(y→x)**:概率流像无摩擦环形水渠,正逆不可分辨。
为什么美:一条**等式**同时是物理(平衡态)、算法(Metropolis 接受率的设计依据)、
代数(自伴算子/可逆矩阵谱理论)的公共交点——把三門学科焊在同一个对象上。

## 假设与依赖

- 马尔可夫性:未来⊥过去|现在——最贵假设「独立性」的**分期付款版**(只保留一步记忆)
- 状态空间可数(链)或 Polish 空间(一般过程);遍历性另需不可约+正常返(或相应连续版)
