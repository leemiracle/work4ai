# 讲透概率分布 · 随机变量的指纹库

> **定位句**:把「随机」物化成一个函数对象——分布函数;认识分布 = 认识随机变量的**指纹**。
> GB/T 11064 三级「概率分布」。家族:[讲透概率论](../README.md)|五问模板家族成员

## 诞生

📖 de Moivre 1733 年为算二项概率的近似,顺手画出正态曲线(比 Gauss 早 76 年);
Gauss 1809 误差理论+Laplace 分析工具把它加冕为「误差法则」;
Poisson 1837 发表稀疏极限——分布族第一次显示出**族谱结构**(一个分布是另一个的极限)。

## 核心问题

- 已解决:三大离散(二项/泊松/几何)+三大连续(正态/指数/均匀)的完全刻画;
  特征函数/母函数作为分布的「条形码」(Lévy 连续性定理:分布收敛⟺特征函数逐点收敛);
  矩问题与可定性(Carleman 条件);重尾世界的分类(幂律/次指数)
- 未解决/活跃:高维分布的可刻画性(维数灾难下「分布」不可显式写出——交给 [../../讲透高维概率/](../../讲透高维概率/) 的结构假设);
  矩问题的边界判定;自由概率意义下的「自由分布」(非交换版本的指纹学)

## 最美的一个事实

**Poisson 分布是二项的「稀疏自首」**:n→∞、p→0、np=λ 不变时,二项悄悄变成泊松——
**罕见事件的总体却服从一条普适律**。为什么美:极限不是近似,是身份转换;一个分布的极限是另一个分布的存在证明。

## 假设与依赖

- 分布函数的刻画以 Lebesgue-Stieltjes 测度为地基(../讲透实分析 侧)
- 「密度存在」是额外假设(奇异分布存在,如 Cantor 分布)——指纹可以是纯分形的

## 教材锚

- Johnson, Kotz & Balakrishnan《Discrete/Continuous Univariate Distributions》(族谱百科)
- Durrett《Probability: Theory and Examples》(特征函数技术主锚);Feller 两卷(叙事经典)
