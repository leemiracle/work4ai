# 讲透极限理论 · 随机性的长跑纪律

> **定位句**:单次试验无纪律可言,**无穷多次**才有——大数定律、中心极限、大偏差、重对数律,
> 是随机世界的四条宪法。GB/T 11064 三级「极限理论」。家族:[讲透概率论](../README.md)|五问模板家族成员

## 诞生

📖 Jacob Bernoulli 花了 20 年证明大数定律(频率→概率),没等到出版就去世(1713 年遗著《猜测术》),
把公式刻在了自己的墓碑上——**极限定理的第一份代价**。
Kolmogorov 1929 重对数律把纪律精确到常数因子;Cramér 1938 大偏差理论问出更细的问题:
「频率偏离概率 3% 的概率衰减多快?」——指数级,且速率函数是新的数学对象。

## 核心问题

- 已解决:弱/强大数定律(频率稳定性);CLT 全谱(Lindeberg 条件的充要版);
  重对数律(精确包络);Cramér 大偏差原理;Berry-Esseen 定理(CLT 的收敛速度,三阶矩登场)
- 未解决/活跃:**KPZ 普适性的严格化**(00 章清单挂着:为什么不同系统共享同一极限);
  重尾(无穷方差)世界的极限理论(MoM 估计量的非高斯极限,α 稳定律);
  依赖结构的极限理论(mixing 条件的边界在哪)

## 最美的一个事实

**中心极限定理:万物归于高斯**。不管骰子、寿命还是股价涨跌——只要有限方差、近乎独立,
标准化均值全部收敛到**同一条**钟形曲线。为什么美:这是数学里罕见的「万物平等宣言」,
初始分布的细节在极限处被彻底遗忘——而重对数律紧随其后补上「遗忘得多干净」的精确账本。

## 假设与依赖

- 有限方差是 CLT 的票价;无穷方差 → 稳定律的世界(纪律变松,但仍在)
- 独立/弱依赖是全套经典定理的地基;重尾与强依赖各需专用工具(本支的现代战场)
