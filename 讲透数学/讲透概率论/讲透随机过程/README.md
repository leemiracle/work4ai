# 讲透随机过程 · 随时间展开的随机性

> **定位句**:把一族随机变量排进时间轴,问**整条轨道**的事——过程是「随机函数」,
> 单点分布不够用了。GB/T 11064 三级「随机过程(含正态过程与平稳过程、点过程等)」。
> 家族:[讲透概率论](../README.md)|五问模板家族成员

## 诞生

📖 Einstein 1905 用分子碰撞解释布朗运动(物理出生证);Wiener 1923 构造出严格数学对象(数学出生证);
Kolmogorov 扩张定理回答「无穷维相容 = 过程存在」,Poisson/Markov 早年工作把「事件流」纳入同一家族。
随机过程 = 概率论从「静态分布」升维到「动态随机」的那一步。

## 核心问题

- 已解决:布朗运动存在性与基本性质(连续但处处不可微——反直觉铁证);
  Kolmogorov 扩张定理与连续性修饰;泊松过程的完全刻画(稀疏事件的标准钟);
  平稳过程的谱表示;点过程(事件时刻的测度语言)
- 未解决/活跃:分形结构与过程路径维数的精细刻画;高斯随机场的正则性(PDE 随机位势);
  过程的大偏差与扩散近似(与 [../讲透随机分析/](../讲透随机分析/) 共管)

## 最美的一个事实

**布朗运动连续但处处不可微,且变差无穷**——一条「没有速度」的曲线。
为什么美:直觉说连续该有切线,布朗轨道把「连续」与「可微」这两件直觉上绑定的事**彻底撕开**,
这个撕裂正是后来整个随机分析(Itô 二阶修正)存在的原因。

## 假设与依赖

- 过程 = (Ω,F,P) 上带指标集的随机变量族;全部严格性依赖测度论(../讲透实分析 侧)
- 「轨道性质」(连续/跳变)不是有限维分布决定的,要额外修饰(Kolmogorov 连续性判据)

## 教材锚

- Durrett《Probability: Theory and Examples》;Billingsley《Convergence of Probability Measures》
- 泊松/点过程:Kingman《Poisson Processes》(小而精)
