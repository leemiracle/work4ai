# 讲透几何概率 · 概率必须先定测度的第一课

> **定位句(这支负责什么问题)**:当「随机」落在连续几何对象(线/圆/球/平面)上时,
> 概率怎么算——以及怎么会算错。GB/T 11064 三级「几何概率」。
> 家族:[讲透概率论](../README.md)(GB/T 11064 · 首支)|五问模板家族成员

## 诞生

📖 Buffon 1777 年(思路 1733 年)「投针问题」:平行线间距 d,针长 l≤d,相交概率 = 2l/(πd)——
**π 第一次被从随机实验里「量」出来**,概率反过身来服务几何测量(Monte Carlo 估计 π 的鼻祖)。
Bertrand 1889 年「悖论」补上第二块基石:同一句「随机取弦」给三个答案,逼出「先定测度」的学科纪律。

## 核心问题

- 已解决:Buffon 投针与 Laplace 推广(π 的实验估计);Bertrand 悖论的测度论解释(不同对称群=不同测度);
  积分几何的基本公式(Cauchy-Crofton:凸体周长 = 直线截距测度的积分);随机几何基础(Crofton 公式家族)
- 未解决/活跃:随机密铺与随机图形的渐近几何;随机平铺模型(lozenge tiling)的极限形状(通往 KPZ/GFF 前线);
  高维随机凸体的极值几何(与 [../../讲透高维概率/](../../讲透高维概率/) 接壤)

## 最美的一个事实

**Buffon 投针**:扔一根针,就能「算出」π。为什么美:**随机性本身成为测量仪器**——
期望的无偏性把几何常数从噪声里提炼出来,这是 200 年后蒙特卡洛方法的完整预言。

## 假设与依赖

- 「随机投放」必须指定不变测度(平移/旋转群下的 Haar 测度)——本支的纪律即由此立
- 依赖:初等概率(家族层)、测度论(../讲透实分析 侧)、一点积分几何
