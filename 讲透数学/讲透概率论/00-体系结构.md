# 00 · 体系结构:概率论的全图

> **本章回答五问之一:整个体系结构长什么样。**
> **本质一句话:概率论 = 不确定性的微积分**——给「随机」造出可以加、可以积、可以取极限的对象,
> 然后像分析学一样对它做一切。本章 = 八支地图 + 三百年建城史 + 核心问题清单。

---

## 一、这座城怎么起来的(怎么产生的:三个原生问题)

**📖 故事框① · 1654 年的信:赌桌上的出生证明**
帕斯卡与费马围绕德·梅雷骑士的「分赌本问题」通信:两人技力相当,赌局打到 2:1 时被迫中断,赌本该怎么分才算公平?
直觉说按已赢局数 2:1 分——错。正确答案要算**如果继续赌下去各自的获胜概率**:3:1。
这封信第一次把「公平」翻译成「期望」,概率论由此出生——**它出生时不是数学,是公正的算术**。

**原生问题一(赌术)**:不确定性可以计算吗?——大数定律、期望、组合计数。
**原生问题二(误差)**:望远镜的读数每次都不同,真值在哪里?——高斯 1809 误差理论:误差服从正态,最小二乘=最大似然。
**概率第一次证明自己是科学的仆人,而不只是赌徒的仆人。**
**原生问题三(物理)**:布朗 1827 年显微镜下的花粉为何乱舞?——Einstein 1905 给出扩散解释,Wiener 1923 构造出严格数学对象「布朗运动」。
**随机性第一次有了严格的连续时间样本。**

**📖 故事框② · 1933 年:赌术终于变成数学**
Kolmogorov《概率论基础》60 页小册子:概率=**全测度为 1 的测度**,随机变量=可测函数,期望=Lebesgue 积分。
三百年积累的全部赌术一夜之间获得了测度论的严格性——概率论从「关于随机现象的学问」升格为**数学的一个分支**。
这个动作(把一个直觉领域嫁接到严格地基上)后来被泛函分析、数理经济反复模仿。

## 三、相互喂养图(家族内的依赖经济)

```
概率分布 ──指纹语言──▶ 全家(一切支都要先认识随机变量)
几何概率 ──不变测度直觉──▶ 随机过程(泊松过程=平移不变性落地)
极限理论 ──长跑纪律──▶ 全家(没有 CLT 就没有渐近统计)
随机过程 ──样本轨道──▶ 随机分析(布朗运动=它的地基) ──▶ SPDE(../讲透分析/ 对岸)
马尔可夫过程 ──结构假设──▶ 随机分析(扩散=连续时间马氏过程)
鞅论 ──抽象骨架──▶ 极限理论(鞅 proof 是现代 LLN/CLT 的标准姿势)/随机分析(Itô 积分=鞅变换)
应用概率论 ──消费一切──▶ 把全家的定理变成排队时长/失效率/疫情曲线
高维概率(就地) ──d→∞ 桥──▶ 数理统计/机器学习理论(姐妹家族)
```

**一句话经济**:分布卖词汇,极限卖纪律,过程卖时间,马尔可夫卖结构,鞅卖对称,
随机分析卖新微积分,应用概率卖兑现,高维概率卖边疆。

## 四、核心问题清单(这座城解决过什么、正在为什么而战)

### 已解决的里程碑(带年代人物)

| 年代 | 定理 | 它买到什么 |
|------|------|-----------|
| 1713 | Bernoulli 大数定律 | 频率→概率:经验世界的稳定性首次被证明(20 年心血,刻在墓碑) |
| 1733-1901 | de Moivre→Laplace→Lyapunov 中心极限定理 | 「万物归于高斯」:为什么误差总像正态 |
| 1923 | Wiener 布朗运动存在性 | 随机性有了第一个严格的连续样本对象 |
| 1929 | Kolmogorov 重对数律 | 随机游走的**精确跑道**:limsup Sₙ/√(2n loglog n)=1 |
| 1933 | Kolmogorov 公理化 | 全学科严格化(见故事框②) |
| 1937 | Doob/可知 1940s 鞅收敛定理 | 「公平性」这一对称性本身足以保证长期秩序 |
| 1953 | Metropolis 算法 | 遍历性→采样器:数学定理变成计算引擎(MCMC) |
| 1944 | Itô 随机积分 | 布朗运动上可以做微积分(Black-Scholes 的地基,1997 诺奖) |

### 悬而未决的大问题(带地位)

| 问题 | 地位 |
|------|------|
| KPZ 普适性严格化 | 「为什么一大类随机增长模型共享同一极限」——几何 Langlands 级别的开放纲领,2021-2026 专场会议主题 |
| 自回避行走(self-avoiding walk) | 二维严格结果(SLE 时代,Hara-Slade 高维已解),三维仍是物理直觉;聚合物数学的核心 |
| 非厄米随机矩阵普适性 | Wigner-Dyson-Mehta 对称矩阵理论已成熟;非厄米/奇异值边缘的普适性 = EU 立项级前沿 |
| Dirichlet 原理的概率化版式、随机 Navier-Stokes 整体解 | 与 PDE 界共管的深水区 |

## 八、反直觉发现(讲透铁律)

**贝特朗悖论(1889)**:「在圆内随机取一条弦,长度超过内接等边三角形边长的概率是多少?」
- 按端点均匀 → 1/3;按半径均匀 → 1/2;按中点均匀 → 1/4。
- **同一个问题三种「正确」答案**——因为「随机取弦」根本没定义测度。
- 悖论的解药不是更小心,而是 Kolmogorov:**概率不是对象的属性,是测度的属性**。先问「在哪个测度下」,再谈概率。
- 这是 02 章语言分析的起点:概率论的第一课是学会先验地固定语言。

**零概率 ≠ 不可能**:可数无穷个零概率事件的并仍零概率,但「首次返回原点的时刻≠任意有限值」这类事件概率为零却**逻辑上可能**——
「几乎处处」的「几乎」是数学精确的,不是修辞。

## 九、怎么读这个家族(三条路线)

- **顺序派**:概率分布 → 极限理论(纪律)→(随机过程 ∥ 鞅论)→ 马尔可夫 → 随机分析。
  几何概率可作开胃菜(只要微积分),应用概率论可随时插入当「学以致用」的奖励关。
- **问题派**:带着问题倒进来——
  「我的模拟靠谱吗」→ 极限理论+04 章;「我的系统排队多长」→ 应用概率论;
  「怎么从难分布采样」→ 马尔可夫过程;「怎么给随机定价/滤波」→ 随机分析;
  「怎么证明我的随机算法快」→ 鞅论(Azuma)+ 高维概率(就地)。
- **历史派**:按 00 章故事线走(1654 赌桌 → 1713 大数定律 → 1905 物理 → 1933 公理 → 1944 Itô → 1953 MCMC → 2024 Abel),
  每站读对应支的宪法 README,数学史深读见 [../讲透数学史/并行建设中,经 ../GB-T13745全景.md](../GB-T13745全景.md)。

## 十、领海划分:概率论 vs 数理统计 vs 应用数学

| 问题 | 归属 | 理由 |
|------|------|------|
| 已知分布,推出行为(平均/极限/尾部) | **本家族** | 正问题:模型→性质 |
| 已知数据,反推分布/参数 | 姐妹家族·数理统计(建设中) | 反问题:数据→模型 |
| 已知机理,把世界翻译成方程 | [../讲透应用数学/](../讲透应用数学/) | 建模手艺,概率是其中一范式 |
