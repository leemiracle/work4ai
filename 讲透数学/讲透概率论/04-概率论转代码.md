# 04 · 概率论转代码:从定理到采样器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> **本质一句话:概率论的代码化身 = 采样器 + 估计器 + 诊断器**——
> 「算一个概率」几乎总是变成「估一个期望」;估期望,几乎总是变成「造一个采样器」。

---

## 一、可机械化边界(什么能交给机器)

### 能机械化(定理→算法的直达通道)

| 数学对象/定理 | 代码化身 |
|--------------|---------|
| 分布函数/分位数 | `random` + 逆变换法(先造 U(0,1),再 F⁻¹)——万物之源 |
| 期望/概率 | Monte Carlo 估计:Sₙ = (1/n)Σf(Xᵢ),误差 O(1/√n)(大数定律+CLT 给出置信区间) |
| 高维正态/协方差结构 | Cholesky 分解 Σ=LLᵀ,X = L·Z |
| 复合事件(小概率) | 重要度采样/条件采样(方差缩减,§三) |
| 马尔可夫链平稳分布 | MCMC(Metropolis-Hastings):链的遍历定理=收敛保证 |
| 布朗运动/SDE | Wiener 级数 / Euler-Maruyama(步长 h,强收敛阶 h^{1/2}) |
| 尾概率界 | 采样估计 + 集中不等式双重夹逼(见 [../讲透高维概率/](../讲透高维概率/)) |

### 不可/难机械化(诚实边界)

| 边界 | 为什么 |
|------|--------|
| 精确概率(连续状态空间的符号值) | 积分无闭式时只能数值;「精确」本身与浮点世界冲突 |
| 小概率事件直接模拟 | 10⁻⁹ 量级事件需 ~10¹⁸ 样本——必须换测度(重要度采样)或换不等式(大偏差) |
| 一般 MCMC 的收敛时刻判定 | 不可判定问题(停机问题的表亲)——只能诊断(§三),不能证明 |
| 最优耦合/最优传输显式解 | 对偶解存在,显式构造 NP-hard 档(离散情形) |
| 「单条轨道的未来」 | 定理是分布性的;单轨道预测是算命(02 章) |

**判别口诀**:先问「我要的是概率、期望还是分位?」——三者都能化归为期望估计;
再问「能直接采样吗?」——能则 MC,不能则 MCMC;再问「方差可接受吗?」——否则方差缩减。

## 二、代码走廊清单(从入门到工程)

```
走廊 0 · 造随机源     逆变换法:U(0,1) → 任意一维分布        [experiments/00 第 0 步]
走廊 1 · 估期望       蒙特卡洛 + CLT 置信区间(√n 律的实测)
走廊 2 · 造过程       泊松过程(指数钟表)/布朗运动(游走插值) [experiments/00 主体]
走廊 3 · 造链         Metropolis-Hastings 目标分布采样(MCMC)
走廊 4 · 省方差       对偶变量/控制变量/重要度采样/QMC
走廊 5 · 驯 SDE       Euler-Maruyama + 强/弱收敛检查
走廊 6 · 做诊断       自相关时间、Gelman-Rubin、有效样本量(ESS)
走廊 7 · 上并行       流分割 RNG(seed 跳跃)——独立流=独立钢梁的工程化
```

## 三、走廊的核心代码形状(三段最小伪码)

```
# 走廊 0 · 逆变换采样          # 走廊 3 · Metropolis-Hastings       # 走廊 4 · 对偶变量
u = rng.uniform(0,1)          x = x0                                z = rng.uniform(0,1)
x = F_inverse(u)              for _ in range(n):                    y = 1 - z            # 与 z 反相关
                                  y = q.propose(x)                  est = (f(z)+f(y))/2   # 方差近乎减半
                                  if rng.uniform(0,1) < min(1, π(y)q(y→x)/(π(x)q(x→y))):
                                      x = y                        # 样本流 x 趋于 π
```

三段代码对应三句定理:概率积分变换、细致平衡、负相关配对——**每段代码背后只有一条定理,反之亦然**;
这是「转代码」最健康的比例:不是把数学翻译成代码,而是挑那些**天生就是算法的定理**。

## 四、性能工程视角(工程师落点)

这是概率论转代码里**最像性能工程**的部分——因为蒙特卡洛的经济学完全由方差和并行度决定:

1. **误差 −∝ √n 律 = 性能预算公式**:MC 误差 O(σ/√n),多算 4 倍样本只买 2 倍精度——
   **暴力堆样本是 O(n^{-1/2}) 的穷途**。三条出路:
   - **方差缩减** = 换算法不换硬件:对偶变量(近 −1 相关配对)可近乎白拿 √2 倍;
     控制变量(减去一个已知期望的相关量)在金融定价里是标配——这是「算法优化 vs 硬件优化」的教科书案例;
   - **拟蒙特卡洛(QMC)**:低差异序列把 O(n^{-1/2}) 抬到接近 O(n^{-1})(低维);
   - **重要度采样**:小概率事件模拟的唯一活路(方差换偏倚,需重加权)。
2. **并行 RNG 的纪律**:多线程共享一个 RNG = 毁掉独立性钢梁(相关性悄悄进来)。
   工程正解:每个流独立播种(跳跃流,如 Philox/PCG64+jump),**独立性是采样器的内存安全**。
3. **MCMC 诊断是消防规范**:不能证明收敛(§一),只能观测——ESS(有效样本量)=「这些样本实际值多少独立样本」;
   多链发散诊断(Gelman-Rubin R̂)是上线前的必跑检查。**未诊断的 MCMC 输出 = 未测试的代码**。
4. **SDE 的收敛阶直觉**:Euler-Maruyama 强收敛 1/2 阶——比 ODE 的 Euler(1 阶)慢一档,
   二次变差是摩擦源(03 章);需要轨道精度用强格式,只要分布用弱格式,两者成本差一个量级。

## 五、完整案例拆解:MC 估计 π 的全链路(定理→代码→误差→优化)

Buffon 变体(00 章几何概率支的现代版):向单位正方形撒点,落入四分之一圆的比例 →π/4。

```python
import random
rng = random.Random(7)
n = 100_000
hits = sum(1 for _ in range(n)
           if (rng.random()**2 + rng.random()**2) <= 1.0)
est = 4 * hits / n            # 期望 = π(大数定律)
# 误差 = 4·σ/√n ≈ 4·0.41/316 ≈ 0.005  (CLT 给出)
```

全链路对照(一章浓缩):
| 环节 | 数学定理 | 代码动作 |
|------|---------|---------|
| 无偏性 | E[1_圆]=π/4(测度=面积比) | `hits/n` 的期望正确 |
| 收敛 | 强大数定律 | n→∞ 估计→π,a.s. |
| 误差棒 | CLT:√(p(1-p)/n) | 95% CI:±1.96·SE |
| 提速 4 倍 | 对偶变量/分层(方差缩减) | 按象限分层采样 |
| 换赛道 | 拟 MC(低差异序列) | O(n^{-1}) 替代 O(n^{-1/2}) |
| 边界 | 若问「恰好小数后 10 位」 | MC 无能为力——精确计算不属于本走廊(§一) |

这个 10 行案例同时踩过 00 章故事(Buffon 1777)→02 章(测度语义)→03 章(采样即构造)→04 章本章(误差与优化),
是全家族的最小完整标本。

## 七、📖 故事框:Ulam 的病床与蒙特卡洛的出生

1946 年,Ulam 病床上玩单人纸牌,问「成功布局的概率有多大?」组合算不动,他想:
**「玩一百局,数一数」**——随后与 von Neumann 在洛斯阿拉莫斯把它变成中子输运的算法,
代号「蒙特卡洛」(摩纳哥赌城)。值得记住的转折:概率论为赌徒而生,三百年后**用赌术计算了原子弹**——
语言还是那个语言,主语换了。

## 八、反直觉发现

**伪随机数「不随机」却完全够用**:现代 RNG 是确定性混沌(给定 seed 完全可复现),
但它们通过的统计学检验比真随机源(物理噪声)还稳定——「随机性」在算法语境下只需要
「统计上不可区分」,不需要「形而上学随机」。这既是解放(可复现实验、流分割),也是陷阱
(密码学必须用 CSPRNG,因为「统计不可区分」≠「计算不可预测」)。

## 九、常见坑清单(工程侧的「例外集治理」)

| 坑 | 症状 | 正解 |
|----|------|------|
| 多线程共享 RNG | 样本悄悄相关,方差估计失效 | 每流独立播种(seed 跳跃/Philox) |
| 收敛判据用「跑够多步」 | MCMC 未混合就报数 | ESS/R̂ 诊断,报告有效样本量而非样本量 |
| 重要度采样权重爆炸 | 个别 w→∞,估计量方差无限 | 重采样/截断权重;先看 ESS(w) |
| 忘了 CLT 条件 | 重尾分布的置信区间纯装饰 | 先验检查矩存在;重尾用 bootstrap-t 或改述问题 |
| 单调函数用 MC | 慢且浪费 | 拟 MC 或对偶变量(单调性是免费午餐) |
