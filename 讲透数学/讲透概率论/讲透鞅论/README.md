# 讲透鞅论 · 公平赌博的绝对对称

> **定位句**:只假设「游戏的期望公平」(条件期望不变),就能推出收敛、停止、集中一整墙定理——
> 鞅是概率论最强的一根结构钢梁。GB/T 11064 三级「鞅论」。家族:[讲透概率论](../README.md)|五问模板家族成员

## 诞生

📖 「martingale」本是法国赌场术语(翻倍下注策略,赌徒相信它能必胜)。
Lévy 1934 引入数学概念,Doob 1940s 系统化成理论,并顺手写下判决书:
**可选停时定理——公平游戏里任何策略都不能改变期望**,「必胜法」在数学上被判死刑。
此后鞅渗透到金融(定价基本定理)、算法(势函数分析)、统计(似然比)的一切角落。

## 核心问题

- 已解决:Doob 鞅收敛定理(L¹ 有界⟹a.s. 收敛;上穿不等式做引擎);
  可选停时/可选采样定理;Doob 最大不等式与 Azuma-Hoeffding 集中;
  局部鞅与半鞅分解(Itô 积分的地基)
- 未解决/活跃:局部鞅的精细结构(SDE 解类的边界);粗糙鞅(Skorokhod 嵌入的现代版式);
  鞅 Hardy 空间与 BMO 的对偶地貌(调和分析与概率的共管区)

## 最美的一个事实

**公平性即秩序**:E[X_{n+1}|F_n]=X_n 这一条对称,加上一点有界性,竟强制轨道收敛——
「不偏不倚」本身是结构。为什么美:它把「公平」从伦理词变成几何词(条件期望=L² 投影,
鞅=垂直于信息增量的轨道),伦理直觉与希尔伯特几何在同一对象上重合。

## 假设与依赖

- 可积性是门票:条件期望要求 E|X|<∞;L¹ 有界才能谈收敛(缺失时看局部鞅)
- 停时定理的一致可积条件不是装饰——圣彼得堡式无限期望正是裂缝处

## 教材锚

- Williams《Probability with Martingales》(公认最优入门,故事线极强)
- Doob《Classical Potential Theory and Its Probabilistic Counterpart》(源头巨著)
