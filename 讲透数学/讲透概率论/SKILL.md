# 概率论思维技能卡(讲透概率论 · GB/T 11064)

## 一、何时用此分支(触发特征词,一眼对号)

- 出现「概率/期望/方差/分布/随机/不确定」且要**推理**而非仅计算
- 要建模**随时间演化的随机性**(噪声、抖动、排队、扩散、价格)
- 要**采样**:从一个难以直接写的分布产生样本(MCMC、生成模型)
- 要**估计小概率事件**或给模拟结果**配误差棒**
- 要问「平均而言/长期而言会怎样」(大数定律、遍历、稳定性)
- 关键词:概率分布、马尔可夫、布朗、鞅、大偏差、中心极限、蒙特卡洛、MCMC、泊松过程

## 二、核心思维模式(这个分支怎么想问题)

1. **测度视角**:先问「在哪个测度/概率空间下」再谈概率(贝特朗悖论的教训:概率是测度的属性,不是对象的属性)。
2. **期望是主角**:概率=期望的特例(P(A)=E[1_A]);把问题翻译成期望,就能用线性、Jensen、条件期望全套工具。
3. **条件期望即投影**:E[X|G] 是 X 在「已知信息」上的正交投影——L² 几何一图流。
4. **先找钢梁再推理**:独立性/马尔可夫性/鞅,哪个钢梁在场决定哪套定理可用(03 章)。
5. **采样即构造**:证明分布存在/使用分布,统一为「写出采样它的算法」(04 章)。
6. **例外集治理**:a.s. 结论要追问例外集多坏、能否诊断(MCMC 的收敛问题)。

## 三、工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 大数定律 + CLT | 平均行为的稳定性;给蒙特卡洛配 √n 置信区间 |
| Chebyshev/Markov 不等式 | 只要矩就要尾界(粗但万能);精修用集中不等式(→../讲透高维概率/) |
| Borel-Cantelli 引理 | 「事件发生无穷多次吗」的一锤定音 |
| 重对数律 | 随机游走/涨落的**精确**包络(比 CLT 细一级) |
| 可选停时/鞅收敛 | 带策略的公平游戏分析;算法势函数论证 |
| 细致平衡 π(x)P(x→y)=π(y)P(y→x) | 设计/检验 MCMC 的核心等式 |
| Poisson 过程=指数钟表串联 | 稀疏事件建模(到达/故障/突变) |
| Itô 引理 d f(B)=f'dB+½f''dt | 布朗运动驱动的函数演化(含二阶修正!) |
| 重要度采样/对偶变量 | 小概率事件模拟;方差缩减=算法级性能优化 |

## 四、常见误区与禁忌

- **独立 ≠ 不相关**:不相关只是线性意义;独立性是 σ 代数级的强结构。反向(独立⟹不相关)才成立。
- **期望存在才能谈**:重尾(Cauchy/圣彼得堡)下「平均」无意义,样本均值不收敛——先查矩。
- **零概率 ≠ 不可能**:连续分布每个单点都是零测;「几乎处处」的「几乎」是精确数学,不是修辞。
- **概率不是算命**:定理约束分布,不预言单条轨道;对单次事件说「必赢/必输」越出了语言边界。
- **MCMC 未诊断 = 代码未测试**:混合时间不可精确判定,ESS/R̂ 诊断必跑。
- **相关不是因果**:概率语言对称于时间方向;因果要额外结构。

## 五、与相邻分支的判别 + 组合接口

| 判别 | 分界 |
|------|------|
| vs 数理统计 | 概率=正问题(模型→数据);统计=反问题(数据→模型)。采样器是两岸的桥 |
| vs 测度论/实分析 | 全测度为 1 的测度论;纯分析问题(不加概率语义)不归本分支 |
| vs 组合数学 | 古典概型=计数÷计数;样本空间有限且等可能时才退化为组合题 |
| vs 优化/运筹 | 随机性×决策=随机规划/排队论(经 [../GB-T13745全景.md](../GB-T13745全景.md) 组合表路由) |

**组合接口**:随机×优化→随机规划;随机×动力→随机分析(SDE);随机×几何→随机几何/SLE;
概率×高维→集中理论(../讲透高维概率/);随机×计算→MCMC/随机数值方法。
