# 讲透递推与生成函数 · 把序列变成幂级数再读系数:算法分析的心脏

> **定位句**:这支负责"**下一步由这一步决定**"的数学——递推关系定义序列,
> 生成函数把整条序列打包成一个对象再代数求解;复杂度分析、计数 DP、
> 组合恒等式全部由这台引擎驱动。
> GB/T 13745 11081 离散数学 · **自定主干支**。家族:[讲透离散数学](../README.md)

## 诞生

- **谁/何时**:生成函数由 **Euler(1740s,分拆问题)** 发明;系统化由 **Laplace** 与
  **de Moivre**(概率论的母函数)推进;**Knuth(1968 起,TAOCP)**把它变成 CS 的主食。
- **因什么问题**:①"数一数有多少种方式"(分拆/排列组合)②"线性递推的显式解"
  (de Moivre 解 Fibonacci)③"算法到底跑多快"(Knuth 的递推分析)。
- 📖 故事框:Fibonacci 数列 1202 年就出现(兔子问题),但它的闭式 φⁿ 要等
  600 年——**换语言(生成函数)比换问题更能推进数学**,是本支的祖训。

## 核心问题

**已解决**:
- 常系数线性递推 = 特征方程求根(生成函数视角下这是**必然**:极点决定系数)
- 生成函数的四则=序列的卷积/移位/求和——序列运算的"对数表"
- Master 定理:分治递推 T(n)=aT(n/b)+f(n) 的查表解法
- Pólya 计数理论:群作用下的计数(生成函数+Burnside 的合体技)

**未解决/深水区**:
- 非线性递推的普遍理论(不存在)——logistic 递推通向混沌,闭式往往不存在
- 整数分拆的精确渐近(Rademacher 公式已有,但"为什么这么准"的组合解释仍开)
- 高阶 P-递归(holonomic)序列的可判定性边界(与数论/特殊函数论交叉)

## ✨ 这支最美的一个事实

**欧拉五边形数定理**:1/∏(1−xⁿ) = Σ(−1)ᵏ x^(k(3k±1)/2)——
"n 的分拆数"这个看似纯计数的东西,被生成函数一行代数焊死在"五边形数"这个
几何对象上。**计数与几何在幂级数里秘密结婚**。
