# 讲透关系与序 · 二元关系、偏序与格:数据库和一切依赖系统的数学本体

> **定位句**:这支负责"**配对与层级**"的数学——任何两个事物之间"有没有关系、谁先谁后、谁和谁一组",
> 都是本支的领地;数据库、构建系统、分类学全部住在这块地基上。
> GB/T 13745 11081 离散数学 · **自定主干支**(GB/T 未列三级,家族自定)。家族:[讲透离散数学](../README.md)

## 诞生

- **谁/何时**:概念的史前史是 Leibniz 的 universal characteristic(未遂);现代形态由
  **Peirce 与 Schröder**(19 世纪末,关系代数)奠基,**Codd(1970)**把它变成数据库工业,
  **Birkhoff(1940《Lattice Theory》)**把序与格铸成代数。
- **因什么问题**:①"推理能不能算术化"(逻辑的关系化)②"海量数据怎么不靠指针查询"(Codd 的关系模型)
  ③"部分可比的结构长什么样"(格论)。

## 核心问题

**已解决**:
- 关系的三种闭包(自反/对称/传递)均可构造(Warshall 1959,O(n³))
- 偏序⇔Hasse 图⇔覆盖关系(有限偏序的无损压缩表示)
- Szpilrajn:任何偏序可扩成全序(选择公理的友好面孔)
- 等价关系⇔划分一一对应(数学中最干净的字典之一)

**未解决/深水区**:
- 数一个偏序的线性扩展(#P 完全);均匀随机生成线性扩展(需马尔可夫链)
- 高维偏序的 extremal 问题(Sperner 型定理的推广——与组合数学共管)
- 无限格的分类(格论的一直在途的圣杯)

## ✨ 这支最美的一个事实

**等价关系与划分是同一个对象的两个名字**——"怎么分块"和"谁与谁同组"互为镜像;
数学中很少有如此彻底的一一对应,它让"分类学"从此有了代数本体。

## 假设与依赖

- 依赖集合论的语言(有序对、笛卡尔积)——地基来自 [`../../讲透集合/`](../../讲透集合/)
- 偏序/格的"好性质"全是**外加公理**(自反/传递/反对称……),一般关系不自动拥有
- 与 [`../../讲透图/`](../../讲透图/) 互为表里:关系=有向图,偏序=DAG,闭包=可达性
