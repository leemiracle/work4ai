# 讲透离散数学 · CS 视角的结构数学——连续世界之外的一切数学地基

> **本质一句话**:离散数学=把"结构"从连续数学里提纯出来——关系、序、格、Boole 代数、递推,
> 这些不靠极限靠**有限组合**说话的对象,恰好是计算机能直接吞下的全部数学。
>
> GB/T 13745-2009:110 数学 · 二级学科 **11081 离散数学**(GB/T 未列三级 → 本家族自定主干支)。
>
> **定位张力声明**(先读这个再读本家族):「离散数学」在 GB/T 里是一个独立二级学科,
> 但在数学实践中它更像一个**聚合视角**——逻辑住数理逻辑家、图住讲透图家、组合住组合数学家、
> 代数结构住代数学家。本家族不重复建设这些成员的地盘,只**详答离散数学自己独有的三支**:
> 关系与序(数据库与排序的数学本体)、Boole 代数(数字电路的数学本体)、递推与生成函数(算法分析的引擎)。
> 成员系列以互链挂靠(见 §三),物理迁移记入全景表待办。

```
讲透离散数学/
├── 讲透关系与序/        🆓 自定主干支——关系运算、偏序、格:数据库与依赖排序的数学本体
```
