# 离散数学思维技能卡(讲透离散数学 · GB/T 11081)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **关系类**:依赖关系、传递依赖、可达性、"间接影响"、分组归并、等价类
- **序类**:偏序、拓扑排序、调度顺序、构建顺序、Hasse、极大元/极小元、上确界/下确界
- **两值类**:真值表、逻辑化简、卡诺图、权限位、位掩码、最小项、主析取范式、卡诺、`x&(x-1)`
- **序列类**:递推、递归式、复杂度递推 T(n)=aT(n/b)+f(n)、Fibonacci、状态转移、计数 DP、生成函数
- **结构类**:格、对偶律、De Morgan、不动点、归纳定义、闭包

## ② 核心思维模式(这个分支怎么想问题)

1. **有限化**:一切对象可枚举、可穷举验证——先问"能暴力验证吗",再问"贵不贵"
2. **结构化**:任意关系是素材;等价/偏序/格是**外加公理套餐**——好结构是选择,不是默认
3. **对偶化**:每条定理免费送对偶定理(∨↔∧,0↔1,≤↔≥)——证一半得两份
4. **不动点化**:递归定义=格上单调映射的最小不动点(Knaster–Tarski)——循环/Datalog/文法同源
5. **渐近化**:没有极限,但有 Θ 增长率——下标里的无穷取代测度里的无穷

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| Warshall 传递闭包 O(n³) | "谁间接连通谁";bitset 位并行可 64× |
| Kahn 拓扑排序 O(V+E) | 偏序→线性顺序;免费环检测 |
| 并查集(union-find) | 等价类动态归并;近 O(1) 均摊 |
| Szpilrajn 扩张定理 | 任何偏序可扩成全序——"不可比"总有合法裁决 |
| 主析取范式 / Quine–McCluskey / 卡诺图 | Boole 函数标准化与最小化(电路/条件判断) |
| Sheffer 单门完备性(NAND) | 只想用一种运算表达全部逻辑时 |
| 特征根法(常系数线性递推) | 递推要闭式;Fibonacci 型 |
| 矩阵快速幂 O(k³ log n) | 第 n 项很大时;自动机计数 |
| 生成函数 A(x)=Σaₙxⁿ | 序列运算→幂级数代数;卷积=乘法 |
| Master 定理 | 分治递推 T(n)=aT(n/b)+f(n) 查表定阶 |
| Knaster–Tarski | 证递归定义存在唯一;语义分析 |

## ④ 常见误区与禁忌

- **拿连续直觉硬套**:对离散量求"导数"无意义;改用差分 Δ 与求和(离散微积分)
- **以为"构造易=计数易"**:找 1 个拓扑排序 O(n),数全部是 #P 完全——报价前分清
- **忘对偶免费**:卡诺图 0/1 对换、电路与或互换后忘记复用已证的另一半
- **位运算炫技失控**:位技巧的前提是语义恒等式成立;先证后用,加注释
- **把"任意关系"当"偏序"用**:传递性不是白给的——先验公理套餐,再跑算法
- **非线性递推乱用特征根**:特征根法只保常系数线性;logistic 型递推可能混沌(初值敏感)

## ⑤ 与相邻分支的判别表 + 组合接口

| 症状像离散数学,其实是… | 判别 |
|------------------------|------|
| 要"证明"而不只要"计算" | → 数理逻辑(证明技术住那边) |
| 对象是"图"的算法与结构 | → 讲透图(本家族只把图当关系载体) |
| 要数"多少种安排" | → 组合数学(生成函数双归属:计数是它的主业) |
| 要"群环域"的一般结构 | → 代数学(Boole 代数是最穷的环,但环论住那边) |
| 要"多值/概率/模糊"断言 | → 三值逻辑/概率论/模糊数学(两值表达不了的世界) |
| 要"下界证明/复杂度分级" | → 讲透计算复杂度 |

**组合接口**:离散×逻辑=数字电路与 SAT;离散×算法=复杂度分析;离散×数据库=SQL 语义;
离散×概率=随机图与近似计数;离散×ML=参数化复杂性发合格证(2026 前沿);
离散×物理=Ising 类模型的 Boole 函数分析。
