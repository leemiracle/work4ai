# 讲透证明 · 从天书到 Gentzen（证明的科学与美学）

> 证明是什么？数学家有两种回答。
> **美学回答**（Erdős）：存在一本"天书"，里面记着每个定理最美的证明——
> Aigner–Ziegler《数学天书中的证明》就是人类对天书的临摹。
> **理论回答**（Hilbert–Gentzen–Curry–Howard）：证明本身是数学对象，
> 可以被写成树、被消解、被赋序数、被当作程序运行——**证明论**研究这门学问。
>
> 本系列两个灵魂一起讲透，五问骨架（分支X光五问第二例）：

## 〇、这个系列回答什么

- 为什么同一个定理有"美"与"不美"的证明？美感能被形式化吗？
- Gentzen 的切割消去为什么被称为"证明论的中心定理"？
- 证明 = 程序（Curry–Howard）——这条对应为什么养出了 Lean/Coq 整个产业？
- 2024-2025：LLM 证明器把 miniF2F 打到饱和——"证明的自动化"到哪一步了？
- 哪些证明任务**原则上**不可自动化？（与讲透集合 04 章的边界清单对照）

## 四、教材锚点

- **美学线**：Aigner–Ziegler《数学天书中的证明》（Proofs from THE BOOK）——每章至少一件天书展品
- **理论线**：Arai《Ordinal Analysis with an Introduction to Proof Theory》（Springer）；
  Takeuti《Proof Theory》经典；Negri–von Plato《Structural Proof Theory》
- **前沿线**：Towsner 2024（Z₂ 序数分析）+ AI 证明器论文群（01 章文献表）
