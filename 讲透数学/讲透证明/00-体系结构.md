# 00 · 体系结构：证明系统的三大范式与证明论的版图

> **本章回答五问之一：整个体系结构长什么样。**
> 读完后你应能画出：三大证明系统怎么互相翻译、两大元定理划出什么领地、
> 切割消去为什么是整个学科的中心定理、以及"天书"在这张地图的哪个位置。

---

## 一、直觉层：从"天书"出发——同一个定理，六种证明

《数学天书中的证明》第一章：**素数无穷的六个证明**。取四个品味：

| 证明 | 风格 | 用到的世界 |
|------|------|-----------|
| Euclid：p₁…pₙ 之外再造 p₁⋯pₙ+1 的素因子 | 构造性（自然演绎的祖师爷） | 算术 |
| Goldbach：Fermat 数 F_k=2^{2^k}+1 两两互素 ⟹ 素数无穷 | 组合构造 | 算术 |
| Euler：∑1/p 发散 ⟹ 素数无穷 | 解析 | 分析 |
| Fürstenberg：拓扑空间中"素数倍数集"既开又闭 | 公理化抽象 | 拓扑 |

> **反直觉发现 #1**：四个证明**没有一个是另一个的改写**——
> 它们把素数无穷这个命题"接"到四个不同的数学世界（算术/组合/分析/拓扑）上。
> 天书之美 = **找到最深的接口**。而证明论的问题是：把"证明"本身当作对象后，
> 这些风格各异的证明，能不能装进同一套形式系统？——能，这就是本章的地图。

## 二、数学层：三大证明系统（同一门语言的三种语法）

### 2.1 Hilbert 系统（1920s）：公理 + 少量规则

- 结构：一堆公理模式 + **一条规则**（Modus Ponens：A→B 与 A 推出 B）
- 优点：元定理好证（归纳只在规则上做）；缺点：**人类根本不会用它写证明**
- 历史角色：不完备性定理的原生语言

### 2.2 自然演绎 Natural Deduction（Gentzen 1934/Jaśkowski）：按"人怎么想"设计

- 每个联结词一对规则：**引入**（怎么造出它）与**消去**（怎么用它）
  例如 →I：`[A] … B` 撤销假设得 `A → B`；→E：`A → B` 与 `A` 得 `B`
- 证明=树，节点=判断，分支=子证明；**假设可以开可以撤**（框框 `[A]`）
- 这是所有逻辑教科书和证明检查器的实用语法（本系列实验 00 实现它）

### 2.3 矢列演算 Sequent Calculus（Gentzen 1934）：对称化的机器语法

- 对象改为**矢列** `Γ ⊢ Δ`（左边假设集，右边结论集——经典逻辑允许右边多个）
- 左右规则完美对称（每个联结词的左规则=另一侧的对偶）
- **结构规则**显式化：弱化（加没用假设）、收缩（假设用两次）、交换（假设排序）
  ——把它们的组合限制掉，就得到直觉主义/线性/相关逻辑（03 章）
- 机器友好：所有规则都是"上下文重组"，无假设框

三系统**互相翻译**且保持可证性（多项式互转）；选用是工程/美学问题，不是数学分叉。

### 2.4 中心定理：切割消去（Cut Elimination, Gentzen 1934）

矢列演算里的切割规则：

```
    Γ ⊢ A      A, Δ ⊢ B
    ────────────────────── (cut)
         Γ, Δ ⊢ B
```

——"先用中转命题 A"的合法偷懒。Gentzen 的定理：**一切使用 cut 的证明都能改写成
无 cut 的证明**（子公式性质：证明里只出现结论的子公式）。

> 为什么它是中心定理：切消 ⟹ **一致性**（无 cut 的 ⊢⊥ 证明不可能存在——
> 规则反着读永远缩小）；⟹ 一致性的**构造性**证明（对 PA 需要超穷归纳到 ε₀——
> 03 章）；⟹ 证明的范式定理（每个证明有"最简形态"）；
> ⟹ 逻辑编程的完备性（聚焦演算，04 章）。
> **证明论的一切大路都经过它。**

## 三、两大元定理划出的领地

| 定理 | 内容 | 划出的领地 |
|------|------|-----------|
| **完备性**（Gödel 1929） | 可证 ⟺ 永真 | 证明系统"够用"——语法追平语义 |
| **不完备性**（Gödel 1931） | 含算术的一致递归理论必有不可判定句 | "够用"≠"万能"——证明的地平线 |
| （配套）完备性的极限 | 紧性/Löwenheim–Skolem | 见 [`../讲透集合/02-语言特征.md`](../讲透集合/02-语言特征.md) |

证明论的核心张力：**在完备性给的"够用"和不完备性给的"不给力"之间，
把证明本身研究到最细**——它们的强度（序数分析）、结构（范式/聚焦）、
计算内容（Curry–Howard）、自动化边界（04 章）。

## 四、证明论版图：四大分支

| 分支 | 核心问题 | 代表工具 | 去哪章 |
|------|---------|---------|--------|
| **结构证明论** | 证明系统本身的结构性质（切消/范式/聚焦） | 矢列演算、证明网、deep inference | 02/03 |
| **序数分析** | 理论有多强？一致性证明需要多长的超穷归纳？ | 证明论序数（PA↔ε₀）、Gentzen 式分析 | 03（2024 破冰见 01） |
| **证明论语义 / Curry–Howard** | 证明的计算内容是什么？ | λ-演算、实现性、正规化 | 03/04 |
| **证明搜索与自动化** | 证明能自动找吗？ | resolution、tableaux、CDCL、Lean tactic、LLM | 04（前沿见 01） |

配套活跃带：**逆向数学**（定理的反向公理需求标定——哪个定理需要多强的系统证明），
它是"证明论强度"向具体数学定理的测绘术（01 章）。

## 五、Python 层：证明检查器先行

```bash
python3 -u experiments/00_nd_checker.py
```

实现自然演绎的八条规则（∧∨→⊥ 的引入/消去 + ¬ 的 RAA），

"证明是可检查的树"——这一个实验就解释了整个证明助手产业的第一性原理。

## 六、Lean 层

自然演绎就是 Lean 的 `tactic` 世界底座（`intro` = →I，`exact` = 规则应用，
`apply` = 反向的 →E）。读 [`../讲透Lean4数学/`](../讲透Lean4数学/) 时
把每个 tactic 对应回本章的规则名——证明助手的"语法糖=自然演绎"。

## 七、不足层（诚实清单）

1. **三大系统只覆盖一阶（经典/直觉）逻辑**——模态/时序/线性逻辑各有独立的证明论，版图比本章地图大得多
2. **天书美学在地图之外**："最美证明"没有形式判据（尝试过：证明长度？切消后的形状？
   都是代理指标）。美学是证明论的**动力系统**，不是它的**定理**
3. **切消的代价**：切消变换可能让证明**非初等地爆炸**（超指数级变长）——
   "存在无 cut 证明"≠"找得到/存得下它"（04 章边界）
4. Gentzen 式一致性证明的"构造性"有条件：ε₀ 超穷归纳本身就是 PA 证明不了的强工具
   （03 章把这个循环拆开算账）
