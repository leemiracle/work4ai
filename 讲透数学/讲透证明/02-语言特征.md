# 02 · 语言特征：矢列、判断与"规范化"的双关

> **本章回答五问之三（表达？逻辑？规范化？）。**
> 证明论的语言有三次抽象：**命题→判断→矢列**；它的逻辑性格围绕一条定理
> （切割消去）与一种匹配（谐和性）展开；它的"规范化"一词有两层意思，
> 分别对应证明的**范式**与数学的**形式化**——这个双关不是巧合，是 Curry–Howard。

---

## 一、表达：从命题到矢列——语法的三级火箭

### 1.1 判断先于命题（Martin-Löf 的洞见）

- **命题**：`A ∧ B`——一个可能为真的东西
- **判断**：`A true`、`A ⊢ B`（在假设 A 下 B 真）——**我们对命题的断言行为**
- **矢列**：`Γ ⊢ Δ`——判断的打包：左边全体假设，右边全体候选结论

> **反直觉发现 #1**：日常数学写"∠A=∠B"，证明论强迫你区分
> **命题 `∠A=∠B`**（内容）与 **判断 `∠A=∠B 成立`**（行为）。
> 类型论继承了这个区分：`Prop` 的元素 vs `True p` 的证据——Lean 里
> `p : Prop` 与 `h : p` 是两个世界。把命题当判断混淆 = 把剧本当演出。

### 1.2 规则即语法（proofs-as-syntax）

推理规则不是"关于证明的陈述"，它**就是证明的构造语法**：

```
    Γ, A ⊢ B            （子证明树 + 撤销 A 的书签）
    ───────── (→I)
    Γ ⊢ A → B
```

证明 = 有限树，节点是规则名，叶子是公理/假设。**可证性变成语法性质**
（这棵树是否良构）——这是"证明可以被计算机检查"的全部本体论基础。

### 1.3 表达力的三处边界

| 想表达 | 能否 | 说明 |
|--------|------|------|
| "证明 D 是有效的" | 元语言（非对象语言） | 有效性谓词走 Tarski 路线（[`../讲透集合/02-语言特征.md`](../讲透集合/02-语言特征.md)） |
| 语义永真（不止可证） | ✗ 矢列只认语法树 | 完备性定理负责两边缝合 |
| 规则集"恰好匹配"其联结词的意义 | ✓ 谐和性定理（见下） | 这是证明论特有的表达力问题 |

## 二、逻辑：中心定理与谐和性

### 2.1 切割的可容许性（admissibility）——证明论版"完备性"

切割规则**不在**系统里，但**用它的证明都能改写**——"cut-free 系统证明同样多"。
这叫规则的**可容许性**。切消定理的准确读法：

> **切割是安全的多米诺：你可以永远不用它，但用它不会证明更多。**

由它立即得到：
- **子公式性质**：切消后的证明只用结论的子公式——证明"向下透明"
- **一致性**：`⊢ ⊥` 无切证明不存在 ⟹ 系统一致
- **插值性质**（Craig）：A→B 可证 ⟹ 存在 C 只用公共词表——模块化的逻辑基础

### 2.2 谐和性（harmony）：引入/消去规则的匹配

自然演绎里每个联结词一对规则。**谐和性要求**：消去规则至多恢复引入规则投入的信息
（不许"无中生有"，也不许"入不敷出"）。它有两个精确化：
- **局部约化**（local reduction）：`(→I 的结果) →E 应用` 化简回原子证明
  ——多余的绕路被消除，这就是 β-归约
- **逆引理**（inversion）：消去规则是引入规则的逆——证明论语义
  （proof-theoretic semantics：**意义 = 用法**，维特根斯坦的逻辑学实现）

> 天书展品：∨E 规则（分情况讨论）是"最像人类"的规则——它不引入任何联结词，
> 只是搭桥。谐和性告诉我们哪些桥是可拆的（局部约化），哪些是本质的。

## 三、规范化：一个词的两层意思（双关即对应）

| | 规范化 ①：证明的范式 | 规范化 ②：数学的形式化 |
|---|---|---|
| 对象 | 单个证明 | 整个数学理论 |
| 定理 | 强规范化（β-归约必终止）+ 合流（Church–Rosser：范式唯一） | Hilbert 纲领（部分实现：不完备性修正版） |
| 工程 | 类型系统停机性 / 求值器 | 证明助手 / Mathlib |
| 对应 | Curry–Howard 下：证明规范化 **=** 程序求值 | 同一对应：形式化 **=** 类型化 |

**强规范化**：任何证明项的任何 β-归约序列都终止——证明没有无限绕路。
**合流**：不管先消哪个切割，最终范式相同——证明的最简形态**唯一**。

> **反直觉发现 #2**：范式唯一（好）但**代价可能非初等爆炸**（Meyer–Stocker 1981；
> Orevkov）——切消后证明长度可以是原证明的 tower-of-exponential 级。
> "每个证明都有唯一最简形"与"我们能找到它"是两回事。
> 规范化是理论上的温柔，工程上的暴政。（04 章边界清单重申）

实验 `02_beta_normalization.py` 把这节全部跑给你看：
同一命题两个证明 ⟶ 归约步数不同 ⟶ 范式相同（合流）；
而"想写出不停机的证明项"（自应用 λx.xx）**根本无法通过类型检查**——
一致性=类型安全，同一定理的两个名字。

## 五、Lean 层

Lean 的 `Prop`/证明项就是本章语言的工业化：`fun h => h` 是 →I 的证明项，
`Nat.rec` 是归纳原理的证明项，`rfl`/`simp` 是规范化引擎的入口。
对照表见 [`../讲透Lean4数学/`](../讲透Lean4数学/)。

## 六、不足层（诚实清单）

1. **矢列语法是经典/直觉一阶逻辑的方言**——高阶/模态/归纳定义语言的证明论各有方言，谐和性并非处处成立
2. **谐和性无统一判据**——局部约化/局部膨胀逐系统手工验证，"意义=用法"的完全形式化仍是开放纲领（证明论语义）
3. **规范化的爆炸性**使"最简证明"在实践中不可得——形式化实践里的证明都是"够用就收"
