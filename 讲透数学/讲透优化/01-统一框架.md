# 01 · 优化学统一框架：七要素、两元抽象与消除限制论

> **一句话**：所有优化 = **What + Metric + Model + Constraint + Search + Execution + Feedback**（七要素）；所有迭代算法 = **方向 × 步长**（两元）；所有优化的本质 = **找到限制 + 放松限制**（消除限制论）。本章把全系列（及讲透高性能计算）钉进这三个统一框架。
>
> 本章 2026-09-02 由全景框架材料升级为完整章（原大纲版吸收本体论三问后扩容）。

---

**一个公式走遍八个领域。** 数学优化改决策变量、编译器改程序变换、CPU 改指令调度、HPC 改布局、深度学习改参数、企业改资源分配、控制改输入、人改学习策略——**变量不同、评价不同、机制不同，但结构完全同构**。这个同构不是修辞：把每一领域的问题写成 min f(x)，它们的对偶理论、瓶颈分析、搜索策略可以互相翻译。本章就是这个翻译字典——读完它，你看到任何"优化问题"，第一反应是一张七格表。

---

## 一、七要素统一公式（本系列的总宪法）

$$\text{Optimization} = \underbrace{\text{What}}_{\text{优化什么}} + \underbrace{\text{Metric}}_{\text{如何衡量}} + \underbrace{\text{Model}}_{\text{如何建模}} + \underbrace{\text{Constraint}}_{\text{受何约束}} + \underbrace{\text{Search}}_{\text{如何搜索}} + \underbrace{\text{Execution}}_{\text{如何执行}} + \underbrace{\text{Feedback}}_{\text{如何反馈修正}}$$

### 1.1 领域映射表（八域同构）

| 领域 | x（变量） | f（目标） | 约束 | 搜索法 | 反馈 |
|---|---|---|---|---|---|
| 数学优化 | 决策变量 | 目标函数 | 不等式/等式 | 梯度/对偶/分支 | 步长日程 |
| 算法优化 | 算法/数据结构 | 时间/空间 | 正确性 | 复杂度分析 | benchmark |
| 编译优化 | 程序变换 P→P' | 执行效率 | **语义等价** | pass 序列/自动调优 | 性能计数器 |
| CPU/HPC 优化 | 布局/调度/精度 | FLOPS/带宽利用率 | 物理墙（Amdahl/Roofline） | profiling+重构 | 火焰图回归 |
| 深度学习 | 参数 θ | Loss | 显存/通信/时间预算 | SGD 族 | 验证曲线 |
| 控制系统 | 控制输入 u_t | 稳定性/能耗 | 动力学方程 | MPC/LQR | **闭环观测**（控制=时间中的优化） |
| 企业管理 | 资源分配 | 成本/利润 | 预算/法规/伦理 | 规划/启发式 | 市场 |
| 人类学习 | 学习策略 | 学习效率 | 时间/精力 | 试错/元认知 | 考试/实践 |

**关键洞察**：七要素里最常被漏掉的是 **Model 与 Feedback**——直接从"What"跳到"Search"就是无模型乱调参（工程界最大的浪费）；没有 Feedback 的优化是一次性赌博（所有持续优化系统的死亡）。

### 1.2 五问框架（5W，快速诊断任一优化任务）

1. **Optimize WHAT**？（f 是什么——代理检查，50 章 Goodhart）
2. **Change WHAT**？（x 的自由度清单——变量边界即问题边界）
3. **Limited by WHAT**？（g 与物理墙——四类墙：物理/复杂度/信息/伦理）
4. **Search HOW**？（算法选择=先验选择，NFL 定律）
5. **Know BETTER HOW**？（评价协议——测量科学与误差棒）

## 二、两元抽象：所有迭代算法 = 方向 × 步长

$$x_{k+1} = x_k + \alpha_k d_k$$

| 算法 | 方向 d_k 怎么来 | 步长 α_k 怎么控 |
|---|---|---|
| GD | −∇f（最速下降） | 固定 1/L / 线搜索 |
| Newton | −H⁻¹∇f（用曲率矫正方向） | 1（或置信域 Δ 限制 ‖d‖） |
| 动量/NAG | 历史方向的指数平均（±前瞻） | 固定 + β |
| Adam | 梯度/√二阶矩（**信噪比方向**） | 自适应 |
| 共轭梯度 | 上方向的正交共轭化 | 精确线搜索 |
| 信任域 | 子问题模型的最优解 | **区域半径**动态伸缩（模型好→扩，差→缩） |

→ **方向回答"局部几何知道多少"**（0 阶：只知道值 / 1 阶：知道坡 / 2 阶：知道弯曲）；**步长回答"信模型多少"**（线搜索=实证派 / 信任域=保守派 / 自适应=统计派）。04 章的全谱系是此表的展开。

## 三、优化即搜索：方法的动物园统一观

$$\text{Optimization} = \text{Search over State Space}$$

一切区别只在**搜索策略利用了什么结构**：

- **Gradient/Newton**：利用局部微分结构（连续宇宙）
- **DP**：利用最优子结构（重叠子问题的记忆化）
- **Branch & Bound**：利用上下界剪枝（离散宇宙的"对偶"）
- **GA/群体**：利用种群多样性（隐式并行假设——23 章批判）
- **SA**：利用**允许变差**（Metropolis e^{−Δ/T}：短期变差换长期更优——"优化 ≠ 一直改善"，这条对架构重构/学习/投资同样成立）
- **贝叶斯优化**：利用全局代理模型（昂贵评估的结构先验）

## 四、消除限制论（终极统一：优化 = 找墙 + 拆墙）

$$\text{Optimization} = \text{Find Constraint} + \text{Relax Constraint}$$

| 宇宙 | 限制的形态 | "拆墙"的手段 | 本库锚点 |
|---|---|---|---|
| 数学 | 约束集 X | 对偶/松弛/罚 | 03 章 |
| 性能 | 瓶颈资源 | 重构数据流/并行 | 讲透高性能计算 02-06 |
| 并行 | 串行分数 1−p | 减少串行（而非加核！） | Amdahl：Speedup_max=1/(1−p) |
| HPC | 内存带宽 | 分块/融合/换格式 | Roofline：AI×BW 封顶 |
| 深度学习 | 损失景观 | 动量/二阶/初始化 | 04/06 章 |
| 控制 | 动力学约束 | 前馈+反馈 | MPC 滚动优化 |
| 企业 | 资源 | 借贷/外包/重组 | 经济学对偶 |

→ **先找到真正的墙**（profiling/对偶间隙/瓶颈分析），**再决定拆哪堵**——50 章"下界=结构指示器"的工程版。
