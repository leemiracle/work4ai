# 13 · 动态规划：最优子结构的算法学

> **一句话**：如果"全局最优包含子问题的全局最优"（最优子结构）且子问题会重叠，那么"自顶向下记忆化"把指数级重复计算折叠成多项式——**DP = DAG 上的最短路**，是贝尔曼给"时间中的决策"写的微积分。

**1950 年代，Bellman 在 RAND 公司。** "Dynamic Programming"这个名字据他自传所述是精心设计的烟雾弹：国务卿 Wilson 厌恶"research"一词，Bellman 需要一个既不惹眼又听起来数学化的名字——"dynamic"捕捉时变决策，"programming"当时的含义是"规划/优化表"（linear programming 同源）。他提炼的**最优性原理**成为控制论、经济学（他的 Bellman 方程是宏观动态规划的骨架）、强化学习（价值迭代的母体）、生物信息学（序列比对的核心算法）的共同地基。**DP 不只是一个算法，是"多阶段决策"这个现实结构的数学镜像**——凡有"现在的选择影响未来的选项"处，皆有 Bellman。

## 一、直觉层：重叠的叹息、表格与倒推

- **重叠子问题**：fib(30) 的朴素递归把 fib(10) 重算了百万次——**指数的重复劳动**；记忆化（memoization）=给每次呼出的答案留便签——O(n)
- **最优子结构**：最短路径的子路径必是最短（否则换成更短的子路径整体更短——反证两行）——**全局最优可以由子最优拼装**。反例：最长简单路径**没有**此性质（子路径最长可能堵死后路）——同一张图，最短有 DP、最长没有：**结构的方向性决定算法的命运**
- **填表（tabulation）vs 记忆化（memoization）**：自底向上（按依赖序填表，无递归开销、可空间优化）vs 自顶向下（只算用到的子问题、代码即递归式）——同一数学、两种工程
- **倒推重构**：表格给最优**值**，方案要沿表回溯（argmax 链）——值与方案的分离是 DP 实现的第一课

## 二、数学层

### 2.1 Bellman 最优性原理与方程

> "最优策略的性质：无论初始状态与决策如何，余下的决策对当前状态构成最优策略。"

数学化（对加性目标）：

$$V^*(s) = \max_a\Big[\, r(s,a) + V^*(s')\,\Big]$$

——状态值函数的自洽方程（不动点形式）。**加性可分解**（总收益=各段收益之和）+ **马尔可夫性**（未来只依赖当前状态）是两块地基——目标可分解才有多阶段结构，无后效性才敢"忘掉历史"。**DP = 在状态图上做最短（长）路**：状态=节点、决策=边、V*=到终点的距离——13 章与讲透图 05 的精确同构。

### 2.2 设计 DP 的四步法（手册）

1. **定义状态**（最关键的一步）：状态="足以决定未来的最小信息集"（背包=（剩余容量，剩余物品）；编辑距离=（前缀 i，前缀 j））——状态定义错误=维数爆炸或错误
2. **写转移方程**：V(i,j) 从哪些更小子状态来、代价多少
3. **定边界与计算序**：依赖图的拓扑序（填表）或递归+memo
4. **复杂度=状态数×转移成本**：O(状态空间)——**维数诅咒**的来源：d 维状态各取 n 值 → O(n^d)

### 2.3 经典三柱（每个都改变过一个行业）

**①编辑距离**（Levenshtein）：

$$D(i,j)=\min\big\{D(i\!-\!1,j)+1,\ D(i,j\!-\!1)+1,\ D(i\!-\!1,j\!-\!1)+[x_i\ne y_j]\big\}$$

O(mn)——生物信息学（BLAST 的内核思想）与拼写纠错的地基。

**②0/1 背包**：

$$V(i,c)=\max\big\{V(i\!-\!1,c),\ V(i\!-\!1,c-w_i)+p_i\big\}$$

O(nW)——**伪多项式**（W 是数值不是位数！）：这暴露了 DP 的微妙地位——它"多项式于数值、指数于位数"，所以背包仍是 NP 难（10 章），但 W 小时 DP 完全实用——**NP 难≠不可解，只是不可"在位数多项式内"解**。

**③Viterbi**（HMM 解码）：max-product 版 DP（把 Bellman 的 max 换概率乘积）——语音识别/词性标注/生物序列的工业基石（讲透概率图模型 06-HMM 的算法核心）。

### 2.4 区间 DP、树 DP、状态压缩（进阶形态）

- **区间 DP**：状态=区间 [i,j]（矩阵链乘/最优三角剖分）——O(n³)；转移按区间长度递增填表
- **树 DP**：状态=子树（树的直径/最大权独立集）——后序遍历即拓扑序
- **位掩码 DP**（TSP 的 Held-Karp）：状态=（已访问集合 S，当前城 i），S 用 n 位整数——O(2ⁿ·n²)：**指数但远好于暴力 n!**（n=20 时 4×10⁸ vs 2.4×10¹⁸）——"指数中的可解者"

### 2.5 与强化学习的血亲

Bellman 方程在 RL 的化身：V^π(s)=E[r+γV^π(s')]（策略评估的迭代）、Q-learning 的更新（采样版 Bellman）——**RL = 免模型的 DP**（转移概率未知时用采样逼近 Bellman 不动点）。讲透模型 RL 系列的全部理论，在本章只是"转移方程的不同解法"。

## 四、不足与边界（批判）

1. **维数诅咒**：状态空间 O(n^d)——三维以上每加一维致命；缓解（状态剪枝/近似 DP/拉格朗日松弛）各丢保证
2. **最优子结构的脆弱性**：目标加一点全局约束（"路径长度≤K"外的资源约束、简单路径）即可破坏——**每一题都要重新证明结构**（与贪心不同：贪心只需贪心选择性质证明一次）
3. **伪多项式的欺骗**：O(nW) 看着多项式，W 是输入数字不是输入长度——复杂度理论的精确与工程直觉的偏差常造成"DP 万能"的错觉
4. **免模型的难处**（RL 侧）：采样版 Bellman 的方差、探索、函数逼近下的偏差（ Deadly Triad）——DP 的优雅在现实数据面前碎成一门独立学科
