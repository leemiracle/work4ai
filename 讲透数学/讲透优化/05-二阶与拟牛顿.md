# 05 · 二阶与拟牛顿：曲率的赎金

> **一句话**：牛顿法用 Hessian 一步消掉条件数（κ 从分母里消失），代价是 O(n³) 的赎金；拟牛顿一族用"梯度的历史"赎买曲率的近似——L-BFGS 只记 m 步过去，买到了 90% 的曲率价值。
>
> 实验配套：[`experiments/second_order_lab.py`](./experiments/second_order_lab.py)（GD/牛顿/L-BFGS 三方在病态二次上的收敛率实测）

---

**1970 年，L-BFGS 的前身 BFGS 诞生。** 四位发明者的首字母（Broyden-Fletcher-Goldfarb-Shanno）在同一年各自独立发表——数学史上罕见的"同名同岁"四重奏，说明该方法的思想已经成熟到"谁先碰到谁摘"。它解决的问题是牛顿法的死结：Hessian 的计算（n² 个二阶导）与求逆（O(n³)）在 n>10⁴ 时是天文数字。BFGS 的洞见：**相邻两步的梯度差已经编码了曲率信息**——s=x_{k+1}−x_k 与 y=g_{k+1}−g_k 满足 y≈Hs（割线方程），历史对 (s,y) 的序列足以重建 H 的良好近似。Liu-Nocedal 1989 年的有限内存版（L-BFGS）只存最近 m≈10 对——至今仍是中等规模无约束优化的工业默认（深度学习之前的训练主力、scipy.optimize 的 l-bfgs-b）。

---

## 一、直觉层：地图、罗盘与记忆

- **GD**：只有**坡度罗盘**——在狭长峡谷（κ 大）里沿最陡方向走必然横跳（最陡≠朝谷底）
- **牛顿**：手里有**完整地形图**（Hessian 的全部曲率）——直接解"局部二次模型的最低点"，一步跳到二次函数的最优；但画地图贵（n² 次二阶导）且地图可能画错（H 不定时"最低点"是最高点——需要修正）
- **拟牛顿**：**记忆式测绘**——用走过的路（梯度差）逐步拼出地形图；走的地方多图越准，没走过的地方靠最近 m 段记忆外推
- **信任域 vs 线搜索**：两种"信地图多少"的哲学——线搜索先定方向再找多远（方向错了走再远也白搭）；信任域先定"这一步最多走 Δ"再找模型最优解（模型不可靠时自动缩短）——**信任域对牛顿尤其重要**：局部二次模型只在小的 Δ 内可信

## 二、数学层

### 2.1 牛顿方向的最优性：一步消 κ

对二次模型 f(x+d) ≈ f(x)+gᵀd+½dᵀHd 求最小：∇_d = g+Hd = 0 ⟹

$$d_N = -H^{-1}g$$

二次函数上牛顿**一步到最优**（与 κ 无关！）；一般函数上局部收敛率为**二次收敛**：

$$\|x_{k+1}-x^*\| \;\le\; C\,\|x_k-x^*\|^2$$

（误差的平方——每步有效数字翻倍。对比 GD 的线性收敛 (κ−1)/(κ+1)：κ=1000 时 GD 每步 0.998、牛顿每步平方——**数字翻倍 vs 千分之二**的碾压）。代价：H 求逆 O(n³)+H 计算 O(n²)～O(n³)（自动微分可算 H-vector 积但完整 H 仍 O(n²) 存储）。

### 2.2 阻尼与修正：牛顿的三个救命补丁

1. **阻尼牛顿**（damped）：步长 α 由线搜索控制——远离最优点时牛顿方向可能"过头"
2. **Hessian 修正**（modified Newton）：H⋠0 时加对角 εI 或用 Cholesky 的绝对值谱（|Λ|）——把下山方向从"局部模型最优"降级为"至少下山"
3. **信任域**：解 min m_k(d) s.t. ‖d‖≤Δ_k，按**实际下降/模型预测下降**之比 ρ 调 Δ（ρ 近 1 模型准→扩 Δ；ρ 差→缩）——dogleg 法在牛顿方向与最速方向之间折衷

### 2.3 拟牛顿的公理：割线方程与秩二更新

要求近似阵 B_{k+1} 满足（拟牛顿公理）：

$$B_{k+1}\,s_k = y_k,\qquad s_k=x_{k+1}-x_k,\quad y_k=g_{k+1}-g_k$$

BFGS 更新（对 B 的秩二修正，保持对称正定——这是 BFGS 战胜 DFP 的关键性质）：

$$B_{k+1} = B_k - \frac{B_k s_k s_k^\top B_k}{s_k^\top B_k s_k} + \frac{y_k y_k^\top}{y_k^\top s_k}$$

（DFP 更新的是 H=B⁻¹ 本身；BFGS 更新 B 再隐式取逆——就这一个顺序差别，BFGS 的数值稳健性完胜，史称"DFP 悲剧"。）收敛率：**超线性**（|x_{k+1}−x*|/‖x_k−x*‖→0——介于线性与二次之间，且免 Hessian 计算）。

### 2.4 L-BFGS：O(mn) 的记忆魔法

不存 B（n²），只存最近 m 对 {s_i, y_i}，用**双循环递归**（two-loop recursion）计算方向 d = −H_k g：

```
q ← g
for i = k−1, …, k−m:          # 第一循环：从新到旧，扣除已知方向的分量
    α_i ← ρ_i s_iᵀq;  q ← q − α_i y_i
r ← γ q                        # γ = sᵀy/yᵀy（初始 Hessian 的标量缩放）
for i = k−m, …, k−1:          # 第二循环：从旧到新，加回（代数上恰好还原）
    β ← ρ_i y_iᵀr;  r ← r + (α_i − β) s_i
d ← −r
```

复杂度 O(mn) 每步（m≈5-20）——**用 10 步历史买了超线性收敛**。这是"资源受限下近似昂贵量"的教科书设计（与 KV cache、流式算法同哲学）。

### 2.5 收敛率总表（04 章的续篇）

| 方法 | 每步成本 | 凸/强凸收敛率 | 需要什么信息 |
|---|---|---|---|
| GD | O(n)（梯度） | 线性 (κ−1)/(κ+1) | 一阶 |
| NAG | O(n) | 线性 (√κ−1)/(√κ+1) | 一阶 |
| 牛顿 | O(n³) | **二次**（局部） | Hessian |
| BFGS/L-BFGS | O(n²)/O(mn) | **超线性** | 梯度历史 |
| 共轭梯度 | O(n) | n 步精确（二次） | 一阶+方向记忆 |

→ **收敛率-每步成本-信息量的三角**：牛顿买速度用信息，L-BFGS 用记忆赊账，GD 只用现钞（最便宜也最慢）。

## 四、不足与边界（批判）

1. **深度学习为什么不用 L-BFGS**：随机梯度下 (s,y) 对被噪声污染——割线方程失效；且 n=10⁹ 时 O(mn) 也贵。16 章 SGD 的天下。（但**全批量时代/科学计算**仍首选）
2. **牛顿的非凸危险**：H 不定时 −H⁻¹g 可能上山——修正/信任域是必需品而非可选
3. **曲率的稀疏采样**：L-BFGS 只知道走过的 m 个方向的曲率——新方向靠 γ 标量外推，方向突变（如 restart）时记忆失效
4. **共轭梯度被遗忘**：二次问题上 CG 用一阶信息 n 步精确解、O(n) 每步——理论与实践的最佳性价比常被 L-BFGS 光环掩盖
