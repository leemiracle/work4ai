# 09 · 线性规划：多面体上的顶点之舞

> **一句话**：线性目标+线性约束=可行域是多面体、最优在顶点、对偶是资源定价——LP 是凸优化的始祖、组合优化的母体、对偶理论的教科书，也是"数学规划征服工业"的第一战场。
>
> 实验配套：[`experiments/lp_lab.py`](./experiments/lp_lab.py)（单纯形 vs 内点对照 + 对偶间隙轨迹 + 影子价格灵敏度）

---

**1947 年，Dantzig 在五角大楼。** 空军后勤规划问题（70 个约束、多少变量已不可考）被他写成线性不等式组求最大。他发明的单纯形法沿着多面体的**顶点**跳到最优——此后 LP 成为"数学规划"的同义词：炼油配方（每桶利润的百分比级提升）、航线排班、供应链、饮食配比……Kantorovich（苏联，1939 先行工作）与 Dantzig 分享了运筹学的圣杯（Kantorovich 1975 得诺贝尔经济学奖）。理论高潮在 1979：Khachiyan 的椭球法首次证明 LP 多项式可解；1984 Karmarkar 内点法实用化——**"单纯形指数最坏 vs 内点多项式保证"的算法大战**至今仍是复杂度理论最生动的教材。

---

## 一、直觉层：多面体地质学

- **可行域是多面体**（polyhedron）：线性约束围成的"切割钻石"——有顶点（极点）、棱（边）、面
- **最优在顶点**：线性目标没有"盆地"——等值线是平行超平面，推到最后必然停在顶点（或多面体无界/退化时停在棱上——棱上每点都最优）
- **单纯形法=顶点之舞**：从当前顶点沿**最陡的棱**走到隔壁顶点（目标单调改善）直到没有更陡的棱——贪心但居然（通常）很快
- **内点法=中心公路**：不贴边走，从多面体**内部**沿"中心路径"（到所有面的距离均衡）直奔最优——多项式步数保证
- **对偶=影子价格**：原问题（怎么生产）的每个约束对应对偶问题（资源定价）的一个变量——最优价格体系下"利润全部来自资源"（03 章经济学的完全体）

## 二、数学层

### 2.1 标准形与基本可行解

标准形：min cᵀx s.t. Ax=b, x≥0（任何 LP 都可改写——松弛变量化不等式、±x 分解自由变量）。

**基本可行解（BFS）**：取 A 的 m 个线性无关列（基 B），令其余变量为 0，解 Bx_B=b——**BFS=多面体顶点的代数身份**。顶点数上界 C(n,m)（组合爆炸——但单纯形实际访问的顶点数 ~O(m)～O(3m) 经验值）。

**定理三连**：①若 LP 有有限最优，则某顶点最优 ②BFS 集合=顶点集合 ③单纯形法有限步终止（目标严格改善+顶点有限——退化时用 Bland 规则防循环）。

### 2.2 单纯形法的每步：检验数与主元

当前基 B 下，目标用非基变量表示：

$$z = z_0 + \sum_{j\notin B} \underbrace{(c_j - c_B^\top B^{-1}A_j)}_{\bar{c}_j\ \text{（检验数/reduced cost）}}\, x_j$$

- 检验数 $\bar c_j<0$：让 x_j 入基能改善——**选最负的进基**（Dantzig 规则）
- 比值检验（ratio test）定出基变量（保持 x≥0 的最大步长）——**主元（pivot）**
- 全部 $\bar c_j≥0$：当前顶点最优，且 $\bar c$ 直接给出对偶解 $y=c_B^\top B^{-1}$（**单纯形乘子=影子价格**——每一步都在隐式解对偶）

复杂度：最坏指数步（Klee-Minty 立方体的构造陷阱）；平均/光滑多面体上多项式（Spielman-Teng 光滑分析 2001——"指数最坏+实践优秀"悖论的数学和解）。

### 2.3 内点法：障碍+牛顿=中心路径

对数障碍：min cᵀx − (1/t)Σlog x_j s.t. Ax=b。**中心路径** x*(t)：每个 t>0 有唯一解，且

$$\text{duality gap} \le \frac{n}{t}$$

迭代：t←μt（μ~10）+ 牛顿步追踪新中心（Newton decrement 控制步长）。**多项式复杂度 O(√n·L)**（L=位长）——Karmarkar 的原始形式等价于障碍法（自和谐障碍理论的特例，Nesterov-Nemirovski 的一般化把内点法扩展到整个凸锥规划）。

### 2.4 LP 对偶：完全体的影子价格

$$\min\ c^\top x\ (Ax\ge b,\,x\ge0)\;\;\Longleftrightarrow\;\;\max\ b^\top y\ (A^\top y\le c,\,y\ge0)$$

四条定理（LP 对偶的完全公理）：
1. **弱对偶**：任意可行对 yᵀb ≤ cᵀx（剪枝的基础——分支定界的界就是这么来的）
2. **强对偶**：一方有有限最优 ⟹ 另一方同值（LP 恒成立——一般凸需 Slater）
3. **互补松弛**：x_j>0 ⟹ 对偶第 j 约束顶满；对偶 y_i>0 ⟹ 原始第 i 约束顶满（**稀缺资源有价、闲置免费**）
4. **对偶的对偶=原始**（自反——对偶不是"另一个问题"，是同一问题的另一半）

**经济读法**：工厂 max 利润（原始）⟹ 资源最优定价（对偶）——影子价格=该资源再多一单位能多赚多少（灵敏度的局部导数）。

### 2.5 LP 作为万能模板（组合优化的母体）

| 组合问题 | LP 松弛 | 松弛间隙 |
|---|---|---|
| 最短路 | 差分约束的 LP | **零**（整数多面体——LP 即精确解） |
| 最大流 | LP | **零**（全单模性 TU） |
| 最小生成树 | 割约束 LP | 零（TU） |
| 指派/二部匹配 | 匹配 LP | 零（TU——Birkhoff 定理） |
| 背包 | 分数背包 | ≤1（贪心即最优分数解） |
| TSP | DFJ 割平面族 | >0（NP 难的 LP 代价） |
| Max-Cut | SDP（超线性） | 0.878（GW——超越 LP 需要锥的升级） |

→ **整数多面体（TU 性质）的判定学**是组合优化的暗线：满足 TU 则 LP 直接出整数解——"幸运的组合结构=LP 免费午餐"；不满足则进入 10/12 章的松弛-舍入世界。

## 四、不足与边界（批判）

1. **单纯形最坏指数**（Klee-Minty）：构造性陷阱存在——尽管实践中罕见，复杂度证书上内点胜
2. **数值精度**：退化顶点（多面体棱过近）下单纯形循环/数值漂移；内点法自和谐性质免疫——两种病的病理不同
3. **规模天花板**：变量千万级时 O(n³) 牛顿步吃不消——一阶法/ADMM 系（07 章）接管超大规模 QP/LP
4. **"LP 一切皆可"的滥用**：现实常非线性（风险、固定成本、逻辑）——强制线性化的模型误差常大于算法收益（建模第一课：别用 LP 的锤子拧非线性的螺丝）
