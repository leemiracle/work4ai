# 讲透纤维丛论 · 参数化空间的分类:底×纤维的「扭曲乘积」

> **定位句**:这支负责「把一族空间拧在一起」——纤维丛=底空间上每点挂一个纤维,
  局部是乘积、全局可能扭曲;示性类给扭曲发「身份证」。
> GB/T 11031 三级「纤维丛论」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1935:Whitney 引入球丛,Stiefel–Whitney 示性类出生
- 1946:陈省身(Shiing-Shen Chern)定义**陈类**——复向量丛的示性类,
  Gauss–Bonnet 的丛论化身
- 1950s-:丛论成为微分几何与规范场论的共同语言
  (物理学的「规范场」=数学的「联络 on 丛」,1970s 相认)

## 核心问题

已解决:
- 分类定理:丛的分类空间 BG 的同伦类 ↔ 丛的等价类
- 四大示性类(Stiefel–Whitney/陈类/Pontryagin/Euler)与对偶定理

未解决:
- 高示性类的几何实现问题(哪些多项式真正实现为某丛的示性类)
- 丛的正合序列与 K 理论之间的深层对照(代数 K 理论侧,见代数学家族)

## 最美的一个事实

**陈类是曲率的踪迹**:Gauss–Bonnet–Chern 定理说:陈类的积分 =
曲率形式的积分。「丛的扭曲(拓扑)」与「曲率的总量(几何)」
在积分层面握手——**拓扑不变量能被几何测量**。
物理化身:量子霍尔效应的电导 = 第一陈类的整数(诺贝尔奖级的拓扑)。

## 假设与依赖

- 丛=局部平凡化(每点附近是 U×F)+结构群 G(扭曲方式由 G 的同伦分类)
- 示性类是「扭曲的上同调指纹」:粗(撞值=可能同丛)但可算
