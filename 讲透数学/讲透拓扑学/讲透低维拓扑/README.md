# 讲透低维拓扑 · 3/4 维流形:分类定理的边境与 exotic 王国

> **定位句**:这支负责「三维与四维流形」——拓扑学的「边境省份」:
  3 维有完全分类(几何化),4 维连分类定理都不存在(exotic 王国)。
> GB/T 11031 三级「低维拓扑学」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1904:Poincaré 猜想(单连通闭 3 维流形 ≅ S³?)——百年悬案
- 1970s-80s:Thurston 几何化纲领(3 维流形按 8 种几何切割);
  Freedman 拓扑 4 维 Poincaré(1982,Fields)
- 1982:Donaldson 规范理论进 4 维——「光滑 4 维与拓扑 4 维分家」开演
- 2003:Perelman 用 Ricci 流证几何化+Poincaré——唯一已解决的千禧问题

## 核心问题

已解决:
- Poincaré 猜想与几何化(Perelman 2003)
- 3 维流形算法分类(Haken 算法;Heegaard Floer 世代)
- 纽结的不少不变量(Jones 多项式、Khovanov 同调)

未解决:
- **光滑 4 维 Poincaré**(S⁴ 有无 exotic 结构)——4 维唯一盲区
- IP5(相交性质)——2024-25 热度飙升的突破口
- 纽结的完备可算不变量是否存在

## 最美的一个事实

**4 维是宇宙的特权维数**:n≥5 有 h-协配手术分类,n=3 有几何化,
唯独 n=4:exotic ℝ⁴ 存在、光滑 Poincaré 未决、同胚不可判定——
**你恰好活在其中**(物理时空 3+1)。低维拓扑的美学:最深的谜住在最熟悉的维数。

## 假设与依赖

- 「低维」= 3、4 维:维数低到通用手术失效(没有足够空间转柄)、
  高到直觉失效(四维空间画不出)
- 光滑结构是加码假设:拓扑范畴的分类工具(交形式)与光滑范畴(Floer)口径不同
