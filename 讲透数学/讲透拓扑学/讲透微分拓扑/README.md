# 讲透微分拓扑 · 光滑流形:横截性、Morse 理论与 exotic 球面

> **定位句**:这支负责「拓扑上的微积分」——给空间加光滑结构后,
  用横截性避免退化、用 Morse 临界点数清拓扑、用 exotic 球面揭示光滑结构的独立性。
> GB/T 11031 三级「微分拓扑学」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1936:Whitney 嵌入定理(n 维流形嵌入 ℝ²ⁿ)——「抽象流形都能搬进欧氏空间」
- 1954:Thom 横截性定理——「一般位置」从此可证
- 1956:Milnor 发现 exotic 7-sphere(28 个 S⁷)——Fields 奖 1962
- 1960s:Morse 理论成熟(Smale 用它证 h-协配→高维 Poincaré)

## 核心问题

已解决:
- Whitney 嵌入/浸入定理;Thom 横截性
- Morse 不等式:临界点数 ≥ Betti 数——「地理决定拓扑账本」
- h-协配定理(n≥5 单连通)与高维 Poincaré(Smale,Fields 1966)

未解决:
- 光滑 4 维 Poincaré(exotic S⁴?)——4 维手术失效的代价(低维拓扑支共享)
- 光滑结构的存在性的一般判据(哪些拓扑流形容许/不容许光滑结构:
  4 维有不容许光滑结构的流形!)

## 最美的一个事实

**Morse 理论=登山者的拓扑账本**:在流形上「登山」,每过一个鞍点/峰,
拓扑就按规则增加一个胞腔——**山的海拔剖面重写空间的 CW 分解**。
「临界点数 ≥ Betti 数」(Morse 不等式):地形必然比账本要求的更戏剧化。
工程化身:损失景观的鞍点分析、构型空间的瓶颈(见家族 04 章)。

## 假设与依赖

- 光滑结构是**额外假设**:拓扑流形可以有 0 个、1 个、多个不等价光滑结构
  ——「空间」与「空间上的微积分」是两层本体
- 横截性靠小扰动获得(genericity): Thom 定理=「可以永远假设没有退化相交」
