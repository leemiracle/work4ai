## 〇、直觉先行:拓扑题进代码世界,先问「住在第几层」

拿到一个拓扑问题,第一个动作是**分级**:它是 L1(组合)/L2(线性代数)/
L3(呈现代数)/L4(同伦)的哪一层?层号决定命运:

```
L1 复形数据 ──▶ 纯数据结构问题(图论的表亲)      ✅ 放心写
L2 同调     ──▶ 整数矩阵 Smith 标准形            ✅ 放心算(多项式)
L3 基本群   ──▶ 呈示+字问题(不可判定)          ⚠️ 只能半自动化
L4 同伦群   ──▶ 无通用算法                       ❌ 换问题或换近似
```

## 一、可机械化边界(什么能/不能变成代码)

### ✅ 完全可机械化

| 对象/问题 | 机械化路径 | 复杂度 |
|-----------|-----------|--------|
| 单纯同调 Hₙ | 边界矩阵 → Smith 标准形 | 多项式(整系数时注意:Smith 比秩贵,秩在 GF(2) 上更便宜) |
| Betti 数(域系数) | 边界矩阵的秩差 bₙ = rank ker∂ₙ − rank im∂ₙ₊₁ | 矩阵乘法级 |
| Euler 示性数 | 交替数格子 / 交替和 Betti(两法互验) | 线性 |
| 图的基本群 | 生成树 + 弦(每条弦一个生成元) | 近线性 |
| 覆盖空间(有限层) | 子群 → Schreier 图 | 群大小线性 |
| 持续同调(persistence) | 滤过的复形 → barcode | 排序 + 并查集主导,O(α) 级 |

### ⚠️ 半可机械化(有算法但无完备算法)

| 问题 | 能做什么 | 边界在哪 |
|------|---------|---------|
| 纽结识别 | 算 Jones 多项式等不变量做「同 ≠ 异纽结」排除 | 不变量不完备:不同纽结可撞同一 Jones 值 |
| 字问题(特定群类) | 双曲群/自动结构群有解法 | 一般呈示不可判定(Novikov–Boone) |
| 三维流形识别 | 几何化后按几何分类,有实用算法 | 4 维起无分类定理,无从谈起 |

### ❌ 不可机械化(定理级禁区)

- **同胚判定**(4 维及以上流形):不可判定——别写这个求解器,写不出来
- **πₙ(S²) 类同伦群的「完整计算」**:无通用算法,只有手工艺(谱序列)
- **exotic 结构搜索**:无系统方法,只有个例工艺

**工程启示**(与 [`../讲透计算复杂度/`](../讲透计算复杂度/) 互证):
「不可判定」不是劝退贴,而是**问题重述的信号**——
同胚判不了 ⟹ 改判不变量(算 Hₙ);πₙ 算不出 ⟹ 改用 Hₙ 近似。
**降层(L4→L2)是拓扑工程的通用降维术**。

## 二、代码走廊清单(五条走廊,各配核心数据结构)

### 走廊 1:复形 → 同调(本家族实验主走廊)

```python
# 数据结构:单纯形 = 顶点 frozenset;复形 = 单纯形列表(面闭包封闭)
# 边界矩阵 C_n → C_{n-1}:∂(单纯形) = Σ (±1)·去掉第 i 个顶点的面
# Betti: b_n = dim ker ∂_n − dim im ∂_{n+1}   (GF(2) 上用高斯消元即可)
```
实验现场:[`experiments/00_euler_characteristic.py`](experiments/00_euler_characteristic.py) 第三段。

### 走廊 2:点云 → 持续同调(TDA 的主走廊)

```python
# 半径 ε 从 0 扫到 ∞:每帧建 Vietoris–Rips 复形(距离 ≤2ε 连单纯形)
# 记录每个洞「出生 ε_birth / 死亡 ε_death」→ barcode
# 洞活得久 = 数据的真实形状;短命洞 = 噪声
```
关键工程点:增量式加边(并查集判 H₀;H₁ 用链跟踪 lazy 评价)——
**Ripser 的核心就是「只算必要边界」,把朴素 O(复形全规模) 压到准线性**。
性能视角:朴素实现的瓶颈是复形爆炸(combinatorial blowup),
生产库的全部技巧(清晰度剪枝/隐式复形/共配对对偶)都是冲这个来的。

### 走廊 3:图 → 基本群

```python
# 生成树 T;每条非树边 e 恰贡献 π₁ 一个生成元(环 e∪T-path)
# 呈示:⟨弦集 | 每个面的边界词⟩——平面图给网格呈示
```

### 走廊 4:构型空间 → 运动规划

机器人 n 个关节 = 环面 Tⁿ 挖障碍;**拓扑复杂度 TC(X)**(Farber)
=「连续运动规划算法」的最少页数——**下界来自拓扑**(同伦群/上同调积),
意思是:某些系统的「万能运动规划器」本质不可能连续单页写完。
工程化身:PRM/RRT 采样规划器都在近似一个拓扑上必然多叶的对象。

### 走廊 5:网格/流形的工程拓扑审计

- 三角网格的流形性检查(每条边 ≤2 面;顶点星形连通)——DCC(数字内容创作)与
  GPU 渲染管线的拓扑合法性检查就是点集拓扑的「顶点星形」定义
- 编译器 CFG 的支配树/循环嵌套深度——图拓扑(生成树结构)决定优化合法性

## 三、工程师落点(性能工程视角)

| 落点 | 拓扑供给什么 | 工程要什么 |
|------|-------------|-----------|
| TDA/材料/生物 | 持续同调 barcode | 准线性大规模实现(GF(2)+位并行)、GPU 边排序 |
| 机器人学 | 构型空间 TC 下界 | 「别找不存在的单页规划器」的证明级依据 |
| 图形学/DCC | 流形网格定义、亏格 | 网格修复/细分连通性 invariant |
| GIS/点云 | α-shape/reconstruction | 重建的拓扑保真(χ 与 Betti 校验) |
| 网络/系统 | 图的割点/连通度(点集+图拓扑) | 容错下界的证明结构(见 [`../讲透图/`](../讲透图/) 图论部) |
| 量子计算(方向锚) | anyon 的拓扑不变量分类 | 容错量子编码的数学基座 |

**性能工程惯例**(本宇宙读者专属):拓扑计算的复杂度台阶主要来自
**「组合爆炸(单纯形个数)×整系数(Smith 质因数膨胀)」**——
先降系数域(GF(2)),再剪枝(只算 persistence 必要列),
最后才考虑并行——顺序反了就是在给不可能问题加机器。

## 四、✨ 美之时刻(本章):barcode——「洞的一生」

**陈述**:持续同调给每个洞一条 [ε_birth, ε_death) 的线段(barcode)。
**为什么美**:它把「拓扑不变量」(Betti 数,一个静态整数)升级成
「**不变量的谱**」——噪声短命、结构长寿,一组线段同时回答
「有几个洞」与「洞有多真实」。不变量从名词变成了生命史。
**亲历**:对单位圆采 200 个带噪点,扫 ε;看 H₁ barcode 里
一条长线(圆)与一撮短毛(噪声)——机器视觉里这叫「形状从噪声里结晶」。

## 五、认知升维:这章给了你什么新眼睛

1. **降层之眼**:不可判定/算不动 ⟹ 问「降到 L2 还保留多少信息」——
   这与数值分析里「放弃精确解、逼近解」是同一个思维(见 [`../讲透计算数学/`](../讲透计算数学/),平行建设中)
2. **下界之眼**:拓扑复杂度证明「不可能」——工程里,不可能性证明是最好的省时器
3. **形状之眼**:数据不是点集,是(带噪)空间——barcode 教你把「聚类」
   升级成「形状感知」
