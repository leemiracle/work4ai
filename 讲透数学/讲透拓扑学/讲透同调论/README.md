# 讲透同调论 · 洞的账本:边界算子记出空间的腔

> **定位句**:这支负责「洞的代数账本」——链复形+边界算子把「圈与填充」
  记成线性代数,是拓扑不变量里**唯一完全可机械化**的一支。
> GB/T 11031 三级「同调论」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1895:Poincaré 用 Betti 数记洞——但只是数字,不分「洞的类型」
- 1925:Emmy Noether 指出:正确的对象不是数,是**群**——同调群诞生,
  拓扑学自此接入代数学的主干
- 1945:Eilenberg–Steenrod 公理:同调的「接口规范」,20 世纪最好的 API 设计

## 核心问题

已解决:
- 有限复形同调群的多项式时间计算(Smith 标准形)
- Euler–Poincaré:χ = Σ(−1)^k b_k——组合/几何/代数三张脸是同一个数
- 流形上的 Poincaré 对偶(Hⁿ⁻ᵏ ≅ Hₖ)

未解决:
- 高效计算大复形同调(工程侧):稀疏边界矩阵的秩算法仍是活跃工程问题
- 同调的「逆问题」:哪些代数数据能实现为某空间的同调(部分解决)

## 最美的一个事实

**Euler–Poincaré 公式**:V−E+F = b₀−b₁+b₂−…。
同一个 χ,组合地数格子、几何地积分曲率(Gauss–Bonnet)、代数地数 Betti——
三条互不相干的路走到同一个数。亲历:家族实验
[`../experiments/00_euler_characteristic.py`](../experiments/00_euler_characteristic.py)
三段程序就是三张脸。

## 假设与依赖

- 系数域的选择是档位:GF(2) 最快(丢挠),ℤ 全息(慢),ℚ 折中——
  「工程用 GF(2),数学用 ℤ」
- 同调是同伦的 Abel 化(Hurewicz):换来可算性,付出缠绕细节
