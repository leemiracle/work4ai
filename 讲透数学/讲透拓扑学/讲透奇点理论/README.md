# 讲透奇点理论 · 光滑的失效处:临界点的分类学与突变

> **定位句**:这支负责「光滑地图不光滑的地方」——临界点/折叠/尖点的分类,
  以及参数族里突然跳变的「突变」;它是拓扑学与几何学的边境哨所。
> GB/T 11031 三级「奇点理论」(**双归属**:GB/T 11027 几何学侧的临界点理论
> 与本支互指,全景表消歧)| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1955:Hassler Whitney 证明**一般性定理**:平面到平面的光滑映射,
  一般只出现两种奇点——折叠(fold)与尖点(cusp)
- 1960s:René Thom 建立奇点分类纲领,1972《结构稳定性与形态发生学》
  ——「突变论」(catastrophe theory)轰动一时(含争议,见故事)
- 1968-:Arnold 完成 ADE 分类:简单奇点的宇宙只有一张小表

## 核心问题

已解决:
- 一般奇点的 Whitney 分类(折叠/尖点)
- Arnold 的 ADE 分类(简单奇点 ↔ Dynkin 图——奇点与李代数的神秘对偶)
- Thom 七种初等突变(≤4 参数的完备表)

未解决:
- 高余维奇点模空间的几何(「奇点的动物园」还在扩建)
- 突变论的应用边界(70s 的过度宣传至今仍是方法论教案)

## 最美的一个事实

**Whitney 一般性定理**:把世界光滑地压到纸上,折痕处只会出现
「折叠」与「尖点」两种形状——不是近似,是**除这两种外全是可消除的偶然**。
为什么美:自由度无限的连续世界,在临界处只剩两张面孔;
ADE 分类再进一步:简单奇点全体与李代数的 Dynkin 图一一对应——
**完全不相干的两片数学,在奇点处长得一模一样**。

## 假设与依赖

- 一般性(genericity)假设:忽略「可扰消失」的退化奇点
  (测度零的坏行为),这是「 Thom 跨线」的方法论承诺
- 稳定性:结构稳定映射才是研究对象(扰动不改拓扑类型)

## 教材锚

- Arnold–Gusein-Zade–Varchenko《Singularities of Differentiable Maps》(百科)
