# 讲透维数论 · 「维数」的严格化:不变性与分数维的居留权

> **定位句**:这支负责回答「空间的维数是什么」——
  把直觉(「曲线 1 维、曲面 2 维」)升级为可证的不变量,
  并给分数维(coastline)发放合法居留证。
> GB/T 11031 三级「维数论」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1913:Brouwer 证明**维数不变性**(ℝⁿ ≅ ℝᵐ ⟺ n=m)——
  看似显然、实则极难:此前所有「初等证明」都是错的
- 1922:Menger 与 Urysohn(独立)给出覆盖维数 dim 的公理化定义,
  「维数」从形容词变成函数
- 1975:Mandelbrot 的分形把「维数可以是非整数」推上舞台

## 核心问题

已解决:
- 三种维数在小空间类上重合:覆盖维数 dim / 小归纳维数 ind / 大归纳维数 Ind
- dim ℝⁿ = n;维数是拓扑不变量
- 可数分解定理(dim σ-紧空间 = sup 分量维数)

未解决:
- 一般度量空间上 dim 与 Ind 的分离现象的完整刻画(反例宇宙的地图)
- 分形维数的可计算性刻画(Hausdorff 维数一般不可算,只能估计)

## 最美的一个事实

**维数不变性**:ℝ 与 ℝ² 不同胚——「点一样多、局部一样稠」,却**绝不相同**。
证明的关键是「去掉一点后连通性不同」(家族 02 章反直觉 2 的放大版):
1 维去掉一点断成两段,2 维去掉一点纹丝不动。
**维数不是数出来的,是「破坏性试验」测出来的**。

## 假设与依赖

- 覆盖维数只依赖开集结构(纯拓扑);Hausdorff 维数依赖度量(分形几何的口径)
- 两个「维数」不同义:拓扑维数必为整数,Hausdorff 维数可分数——
  分形的拓扑维数 1、Hausdorff 维数 1.26(coastline)并不矛盾,是两把不同的尺
