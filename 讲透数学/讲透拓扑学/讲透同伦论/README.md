# 讲透同伦论 · 形变的代数:环路的历史记成群

> **定位句**:这支负责「连续形变的细粒度读数」——把空间里的环路/球面按
  「能不能互相形变」分类成群(同伦群),读出洞的缠绕方式。
> GB/T 11031 三级「同伦论」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1895:Poincaré《Analysis Situs》发明基本群 π₁——天体力学相空间的环路
  (「周期轨道能不能连续缩成点」)是第一个原生问题
- 1931:Hopf 纤维化 S³→S² 证明 π₃(S²)=ℤ——「高维有非平凡同伦」震撼弹
- 1935:Hurewicz 定义高阶同伦群 πₙ,同伦论独立成军

## 核心问题

已解决:
- π₁ 的计算(van Kampen 定理:粘合空间的群 = 群的粘合)
- 球面稳定同伦群的框架(Adams 谱序列)

未解决:
- **πₙ(S²) 的完整描述**(1950 至今)——同伦论的「暗物质」
- 稳定同伦群的整体结构(染色猜想群)

## 最美的一个事实

**Hopf 纤维化**:S³(三维球面)布满互不相交的圆圈(纤维),商掉后是 S²。
π₃(S²)=ℤ 说:三维球面到二维球面的映射按「缠绕圈数」分类——
**高维空间里藏着看不见的缠绕**,这是「同胚看不出、同伦数得出」的第一现场。

## 假设与依赖

- 同伦等价比同胚粗:丢失「洞的位置」,保留「洞的维数与缠绕」
- 高阶同伦群必 Abel(πₙ, n≥2),π₁ 可以非 Abel——**Abel 分水岭**(家族 03 章)
