# 讲透点集拓扑 · 一切支的方言基础:开集公理下读空间

> **定位句**:这支负责「拓扑学的语法」——只靠开集公理谈连续、收敛、连通、紧,
> 不借助任何距离、代数或光滑结构。全家族其他支都讲它的方言。
> GB/T 11031 三级「点集拓扑学」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1908-1914:Felix Hausdorff《Grundzüge der Mengenlehre》从 Cantor 集合论
  (开集/闭集/极限点/聚点)提炼出**邻域公理**——点集拓扑作为独立学科诞生
- 原生问题:分析学的定理(收敛、连续、极限交换)到底依赖空间的什么?
  答案:只依赖开集结构——**分析是拓扑学上的客人**

## 核心问题

已解决:
- 度量化定理(Urysohn:第二可数+正则 ⟺ 可度量化)——「什么时候能装回距离」完全刻画
- Tychonoff 定理(紧空间任意积紧,⟺ 选择公理)
- 紧性的序列/网/滤子三套等价语义

未解决/开放:
- 集合论独立性问题群(如 Suslin 假设、可测性公理)——点集拓扑是公理集合论的实验场
  (入口:[`../../讲透集合/`](../../讲透集合/))

## 最美的一个事实

**紧性=无穷兑换有限**:任何开覆盖(可能无穷张)必能挑出有限张盖住全空间。
一句公理,把分析学所有「有限步论证」的合法性(极值存在、一致收敛、极限交换)
一次性买断。Heine–Borel 是它最古老的兑现窗口。

## 假设与依赖

- 只假设开集公理(空/全/任意并/有限交)——不假设距离、可数性、分离性
- 引入分离公理旋钮(T₀→T₄)与可数性公理时,须声明档位(定理的「适用电压」)
