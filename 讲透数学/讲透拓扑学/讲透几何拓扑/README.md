# 讲透几何拓扑 · 刚性王国:纽结、映射类群与双曲结构

> **定位句**:这支负责「几何结构锁死拓扑」——曲面的映射类群、
  3 维流形的双曲结构、纽结的补空间;主角是**刚性**(Mostow:π₁ 定生死)。
> GB/T 11031 三级「几何拓扑学」| 家族:[讲透拓扑学](../README.md)

## 诞生

- 1910s:Dehn 用组合方法研究纽结(Dehn 手术、Dehn 引理——后者错了 50 年才补对,
  Papakyriakopoulos 1957,拓扑学的「长跑补丁」故事)
- 1920s-30s:Nielsen 定理(曲面映射类群 ≅ π₁ 的自同构群)——「映射 = 代数」
- 1968:Mostow 刚性定理——有限体积双曲流形由 π₁ 唯一决定
- 1978:Thurston 把双曲几何推上 3 维主角地位(几何化前传)

## 核心问题

已解决:
- 曲面映射类群的生成系与关系(Humphries 生成元、Gervais 呈现)
- Mostow 刚性 ⟹ 双曲体积是拓扑不变量(3 维的「体积=指纹」)
- 纽结补的驯服性(Gordon–Luecke:纽结由补空间决定)

未解决:
- 映射类群的字问题复杂度精细刻画
- 双曲体积谱(哪些实数实现为双曲 3 维流形体积)的结构
- 4 维几何化(几何化的未竟篇章)

## 最美的一个事实

**Mostow 刚性**:两个有限体积双曲 n 维流形(n≥3)同伦等价 ⟹ 等距。
π₁ 这个纯代数对象,在负曲率的加持下,**完全锁死几何**——
「代数是几何的完整身份证」。对照:exotic 现象(微分拓扑支)是「同一拓扑多套光滑」,
Mostow 是反例的镜像:「一个代数只配一种几何」。刚性与分裂对唱。

## 假设与依赖

- 刚性的代价:负曲率假设不可去(平坦/正曲率有变形家族)
- 双曲结构存在性是几何化定理的果实(依赖 Perelman,见低维拓扑支)
