## 一、怎么产生的:三个原生问题(诞生史)

**📖 故事 1:七桥问题(1736,Königsberg)。** 普鲁士小城哥尼斯堡,普雷格尔河穿城而过,
河心岛与两岸由七座桥相连。市民的周日消遣:能不能**每座桥恰好走一次**地环城一圈?
Euler 证明不可能。关键的洞察不是算,而是**遗忘**:把陆地缩成点、桥缩成线——
长度、面积、形状全部丢掉,只留「连接关系」。一个拓扑不变量(顶点度数的奇偶性)
一票否决了所有走法。**拓扑学的第一个定理,诞生于一次大胆的遗忘。**

**📖 故事 2:位置分析(1895,Poincaré)。** Henri Poincaré 研究天体力学——
三体问题的相空间是 ℝⁿ 里的能量曲面,轨道在上面缠绕。他发现:要理解轨道的长期行为,
需要的不是坐标,而是空间的**粘连方式**。他称这门新学问为 *analysis situs*(位置分析),
发明了基本群与 Betti 数。**拓扑学从这里有了自己的纲领:用代数读空间。**

**📖 故事 3:集合论的救赎(1908-1914)。** Cantor 的集合论爆发悖论危机,
但他的点集概念(开集、闭集、极限点)被 Hausdorff 系统提炼:1914 年《集合论基础》
给出邻域公理——**任何数学对象,只要说得出「哪些子集是开集」,就能谈连续、紧、连通**。
点集拓扑诞生:它不是研究某个具体空间的学问,而是一门**语言的语法**。

一句话:七桥给了**问题**,Poincaré 给了**工具**,Hausdorff 给了**语法**——三者合体即拓扑学。

## 二、核心问题清单(Q1 的骨架)

### 已解决的里程碑

| 年份 | 定理/事件 | 意义 |
|------|----------|------|
| 1736 | Euler 七桥/示性数 | 拓扑不变量的首例 |
| 1895 | Poincaré 基本群 | 「用代数读空间」开山 |
| 1913 | Brouwer 维数不变性 | ℝⁿ≇ℝᵐ(n≠m)——「维数」从此严格 |
| 1925 | Noether 把 Betti 数升级为群 | 同调的代数化(点→群的关键一跃) |
| 1931 | Hopf 纤维化 S³→S² | 高维同伦的第一个奇迹 |
| 1956 | Milnor exotic 7-sphere | 「同胚≠微分同胚」——微分拓扑震撼弹 |
| 1961 | Smale h-协配定理 | 高维 Poincaré 猜想解决 |
| 1976 | 四色定理(机器证明) | 拓扑×计算机的第一次大联姻 |
| 1984 | Jones 多项式 | 纽结不变量来自物理(Fields 奖) |
| 2003 | Perelman 几何化/Poincaré 猜想 | 百年悬案,唯一解决的千禧问题之一 |

### 悬而未决的大问题

| 问题 | 地位 |
|------|------|
| 光滑 4 维 Poincaré 猜想(S⁴ 有无 exotic 微分结构) | 4 维是唯一维数盲区;「拓扑最后的圣杯」之一 |
| IP5(相交性质猜想) | 2024-2025 热度飙升,若成立则光滑 4 维 Poincaré 随之倒下 |
| Borel 猜想(闭 aspherical 流形由 π₁ 决定) | 拓扑刚性的终极表述 |
| Novikov 猜想(高阶示性数血统) | 分析/拓扑/几何的十字路口 |
| π_n(S²) 的完整描述 | 从 1950 年悬到今天;同伦论的「暗物质」 |

## 四、相互喂养图(家族内的依赖经济)

```
点集拓扑 ──给语法──▶ 全家(开集/连续/紧是方言基础)
同调论 ──给账本──▶ 低维拓扑(纠正亏格) / 微分拓扑(Morse 不等式)
同伦论 ──给细粒度──▶ 几何拓扑(映射类群) / 纤维丛论(提升障碍)
微分拓扑 ──给光滑结构──▶ 低维拓扑(exotic 问题) / 奇点理论(临界点)
纤维丛论 ──给分类──→ 物理规范场论(家族外最大买家)
几何拓扑 ──给刚性──▶ 低维拓扑(Mostow) 
维数论 ──给地基审计──▶ 全家(维数不是免费午餐)
格上拓扑 ──给构造性替身──→ 计算拓扑/locale 式数学
```

**一句话经济**:点集卖语法,同调卖账本,同伦卖细读,微分卖光滑,低维卖战场,
纤维丛卖分类,几何拓扑卖刚性,维数论卖审计,格上卖无点替身。

## 五、假设与代价(这个家族站在什么之上)

| 假设/选择 | 买到什么 | 付出什么 |
|----------|---------|---------|
| 同胚等价(而非等距) | 极大的自由,洞/连通成为主角 | 距离、角度、曲率全部失效 |
| 同伦等价(更粗) | 代数不变量可用(π、H_*) | 「洞的维数」保留但「洞的位置」丢失 |
| 分离公理(T₀→T₄ 逐级加码) | 收敛行为逐级可控行为 | 公理越强,容纳的空间越少(病态反例出局) |
| 紧性假设 | 无穷压回有限(有限子覆盖) | 非紧空间要么丢掉要么紧化 |
| 光滑结构(微分拓扑加码) | 微积分工具进场 | 同一拓扑空间可能有多个不等价光滑结构(exotic!) |

## 七、✨ 美之时刻(本章先给一个,全家族五章合计 ≥3)

**Euler 示性数的三张面孔。** 同一个数 χ:
- 组合脸:V − E + F(顶点减棱加面);
- 分析脸:∫K dA / 2π(曲率的积分,Gauss–Bonnet);
- 代数脸:b₀ − b₁ + b₂ − …(Betti 数交错和,Euler–Poincaré)。
组合、几何、代数在三张不相干的脸上写下**同一个数**——这是「不变量」思想的极致表演。
亲历方式:跑 [`experiments/00_euler_characteristic.py`](experiments/00_euler_characteristic.py),
亲手从三个方向算出球面 χ=2、环面 χ=0。
