# 03 · 可构造与结构:一切皆符号操作,结构来自自指

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> 本质一句话:计算机数学是**天然的构造主义王国**——存在性声明必须交出算法才算数;
   而它的结构刚性,来自三个反复出现的骨架:**归约、不变式、不动点**。

---

## 开篇:一场搬家引发的十年冷战

📖 1967 年,Bishop 出版《构造性分析基础》:把整个分析学**不依赖排中律**地重写一遍。
动机之一正是计算气质:「存在 x 使 P(x)」若无构造步骤,机器就无法兑现。
经典数学界当时觉得这是自缚手脚;五十年后风向倒转——Lean/mathlib 里的每一个
`∃ x, P x`,**都要交出一个 x**(依值对携带见证,见 02 章)。
构造主义从哲学立场变成了**工程默认**。本家族就住在这场转变的源头:
在这里,**存在 = 可构造**不是选项,是语言本身。

## 一、可构造性:这里的一切都要「拿得出来」

| 对象 | 构造形态 | 反例/边界 |
|---|---|---|
| 可计算函数 | 图灵机/λ 项(有限符号串) | 停机判定函数:定义清晰,但**构造不出**——可定义 ≠ 可计算 |
| 证明 | 证明项(类型的居民) | 经典逻辑的部分定理(用排中律)在构造系统里**没有对应程序** |
| 复杂度界 | 显式算法+显式分析 | Ω 下界的存在性证明往往非构造(对角化/计数) |
| 不可判定性证明 | **构造性的**:显式造出反例机器 D | 「证明不存在」在这里反而是构造——造一台骗过你的机器 |
| 证明检查器 | 极小可信内核(TCB 数千行) | 内核自身正确性靠人工审计——构造的链条必有第一环人肉 |

**三步法**:「归约」这个本域最核心的构造——
- **直觉图像**:翻译机。想知道问题 A 难不难?造一台翻译机,把 A 的任意输入
  改写成 B 的输入,答案再翻译回来。于是「解 B」的机器秒变「解 A」的机器——
  A 的难度被 B **继承**。
- **严格陈述**:A ≤ₘ B(多一归约):存在可计算 f,∀x: x∈A ⟺ f(x)∈B。
  若 B 可判定,则 A 可判定(逆否:B 难 ⟹ A 难)。
- **最小例子**:停机问题 K ≤ₘ 「程序 e 对输入 0 停机吗」——把 (e,x) 改写成
  程序 e'(忽略输入先跑 e(x))。三行改写,一根难度管道。

**反直觉**:本域的「不可能定理」全是**构造性证明**——要证明没有判定器,
就亲手造一台任何判定器都骗得过的机器。这与其他数学「不存在」靠抽象论证
(如测度零)的习惯正相反:**这里连『没有』都要造出来给你看**。

## 二、结构:三根刚性骨架

### 骨架一:归约结构(难度是一个偏序宇宙)

归约 ≤ 把一切计算问题排成巨大偏序;NP-完全问题是 NP 里的「最大元」集群
(Cook-Levin:SAT 是第一个被证明的)。结构刚性来源:**归约可传递**——
难度像血统,可以隔代继承。于是 610 类复杂度动物园
([`../讲透计算复杂度/`](../讲透计算复杂度/))不是清单,是一张**家谱**。

### 骨架二:不变式结构(对的核心)

**直觉图像**:程序状态在亿维空间里乱窜,不变式是一条焊死的轨道——
不管怎么动,某个量永远满足某性质。到达终点时,轨道直接告诉你结果正确。
**严格**:Hoare 三元组 {P} S {Q} 的证明规则把不变式做成代数;
循环的正确性=找不变式 I:P⟹I,I∧B⟹I,I∧¬B⟹Q(归纳法套上程序)。
**最小例子**:`i := 0; while i < n do i := i+1` 的不变式就是 `0 ≤ i ≤ n`——
平凡,但它是千万行验证的原子。**刚性**:不变式一旦确立,
状态空间的其余自由度全部作废——这是「以小博大」的结构性杠杆。

### 骨架三:不动点结构(自指的合法化)

**直觉图像**:克莱尼递归定理说,程序变换 F 必有不动点——一台「先取 F 的复印件、
再跑复印件」的机器 p,行为与 F(p) 一模一样。
**严格**:对任何全可计算 F,存在 e 使 φ_e = φ_{F(e)}(两程序计算同一函数)。
**最小例子**:quine——打印自己源码的程序:`s = "print(repr(s) 的拼接)"`
模式,凡 quoted-unquoted 对皆可。
**刚性来源**:不动点把「自指」从悖论(罗素)驯化为**定理**——
编译器自举、反射、元编程、Gödel 编码,全是这根骨架的承重墙。

## 三、可构造 × 结构的合流点

| 合流 | 内容 |
|---|---|
| Curry–Howard(02 章)的构造读法 | 证明是构造出来的对象;规范化(求值)是这个对象的机械代谢 |
| 良基归纳 | 递归定义合法 ⟺ 依良基序下降——`termination` 证明是程序界的「存在性检查」 |
| 显式矛盾构造 | 类型检查器对 `False` 的居民:不存在——所以「能构造 False」= 证伪一切(爆炸原理的构造版) |

## 四、与其他分支的联系表

| 分支 | 结构交换 |
|---|---|
| ← 讲透证明 | 切消定理:证明项的规范化**就是**计算——证明论给本域的代谢理论 |
| ← 数理逻辑(母) | 递归论提供骨架一的原始版本(图灵归约层次);模型论给「理论的可判定性」测度 |
| → 讲透计算复杂度 | 归约偏序的资源精细化(多项式归约),610 类的家谱学 |
| → 讲透Lean4数学 | 三根骨架的健身房:每个 sorry 填空都在练不变式,每个 `termination` 都在练良基 |
| ↔ 讲透优化 | 组合优化的下界证明大量消费本域结构(归约出难题,不变式出近似保证) |

## 五、反直觉发现

1. **存在写不出程序的可定义函数**(00 章的老朋友,此处看它的结构面):
   「D=骗过一切判定器的机器」之所以造得出,全靠不动点骨架——
   自指不是 bug,是最强力的生成器。
2. **加速定理的结构根源**:程序空间的稠密性——任何固定优化策略 F,
   都有不动点落在它的盲区。「优化策略没有全胜将军」是**空间结构**定理,
   不是工程抱怨(Blum 1967)。
3. **验证器的「信任内核」不能自举**:由哥德尔第二不完备性,
   一致性证明不能在系统内完成——所以 Lean 的内核虽小,
   相信它仍是**一次哲学决定**,不是数学事实。构造链条的第一环永远在人手里。

## ✨ 美之时刻

**✨ 之一:quine 的三次方**。写一个程序,它构造另一个程序,那个程序打印
第一个程序的源码——自指可以套自指,因为不动点定理不限制嵌套层数。
亲历:写出 10 行内的 Python quine;然后体会:你手写的是
Kleene 递归定理的一个实例化。

**✨ 之二:Cook-Levin 的「平移不变性」**。SAT 的 NP 完全性证明本质是:
**任何**多项式时间计算都能局部地「编译」成布尔公式——像任何电路都能印在 PCB 上。
计算的一般性 ⟹ 布尔约束的一般性。为什么美:**一个定理锁死了整个宇宙的难度结构**
(只要 SAT 多项式可解,一切 NP 问题瞬间投降)。亲历:把 3-SAT 手工编译成
3-着色问题(经典归约),体会「难度管道」的接头手感。

**✨ 之三:良基性把无穷关进笼子**。「递归调用总会停」不是信念,是构造:
每次调用沿良基序下降。ω 上加一层反自反序,无穷递降链就非法——
**用序结构一劳永逸地买断停机性**,这是 Lean 里 `termination_by` 一行的全部魔法。

## 🧠 认知升维

- **构造眼**:听到「存在」,反射性追问「怎么构造?」——
  在本域,交不出构造的存在声明等于没说
- **归约眼**:问题难,先找邻居——它是谁的翻译?它翻译给谁?
  难度地图比单点难度更有用
- **不变式眼**:调试循环 bug 时别盯 trace,问「什么量本该不变而被破坏」——
  这是把 Hoare 逻辑用作思维工具的日常形态
