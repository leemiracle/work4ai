# 讲透算法分析数学 · 算多快:资源的价格学

> 定位句:这支负责的问题是「**有了算法,资源(时间/空间/通信)要花多少**」——
> 以及反过来:**证明没人能更省**(下界)。
> GB/T 13745-2009:110·11085 计算机数学(GB/T 未列三级,**自定主干支**)。
> 家族:[讲透计算机数学](../README.md)

## 诞生

📖 1960s-70s:Knuth《TAOCP》把「分析程序」变成数学学科;
1971 年 Cook-Levin 与 1972 年 Karp 的 21 个 NP 完全问题,让「难」有了
**可传递的严格定义**(归约)。算法分析从计步器升格为价格学+下界学。

## 核心问题

已解决:
- **主定理**(分治递求的闭式解)与**排序下界 Ω(n log n)**(比较模型的不可逾越线)
- **摊还分析**(势能法):数据结构单步贵、整体便宜的严格记账
- Cook-Levin/Karp:NP 完全性——难度可归类传递

未解决:
- **P vs NP**(千禧悬赏)——本支第一圣杯
- 矩阵乘法的真下界(ω=2 还是 2.37…?)
- 动态规划的最优子问题划分是否存在通用判据

## ✨ 这支最美的一个事实

排序的 n log n 下界:任何基于比较的排序,信息论上必须区分 n! 种排列,
每次比较最多砍一半 → 至少 log₂(n!) ≈ n log n 次。
**一个问题自身的组合复杂度,先于一切算法规定了价格的底线**——
聪明可以逼近下界,不能击穿下界。

## 假设与依赖

- 渐近分析(大 O/Θ/Ω):常数与低阶项让位于规模行为
- 最坏情况为主(普适但严苛);平均/摊还是补丁
- 计算模型明确(RAM/比较模型/字 RAM)——换模型换答案
