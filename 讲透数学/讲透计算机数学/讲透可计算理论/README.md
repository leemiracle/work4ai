# 讲透可计算理论 · 什么可算:计算的极限地图

> 定位句:这支负责的问题是「**哪些问题存在原则上的算法**」——计算的能与不能的边界学。
> GB/T 13745-2009:110·11085 计算机数学(GB/T 未列三级,**自定主干支**)。
> 家族:[讲透计算机数学](../README.md)

## 诞生

📖 1936 年,图灵为回答希尔伯特判定问题,发明图灵机并证明**停机问题不可判定**;
同年丘奇(λ 演算)殊途同归。本支比电子计算机更古老——它是先造「计算的定义」,
再造计算机的。

## 核心问题

已解决:
- **停机不可判定**(图灵 1936)——存在定义清晰而无算法的问题
- **三教堂等价**(图灵机/λ 演算/递归函数,1936-37)——「算法」定义无争议
- **Rice 定理**(1951-53)——程序的一切非平凡语义性质均不可判定
- **一阶逻辑 validity 半可判定**(1936)——可枚举证明,不可判定真假

未解决:
- 丘奇-图灵论纲的物理版:量子/类比计算能否算出更多(普遍信「不能,只能更快」)
- 逆数学路线:哪些定理「等价于」多强的可计算性公理

## ✨ 这支最美的一个事实

对角论证的复用:康托 1891 证实数不可数的「列表-翻面」招式,45 年后被图灵原样
搬来证明停机不可判定——同一结构横跨集合论与计算论。美在**必然**,不在巧合。

## 假设与依赖

- 丘奇-图灵论纲(定义而非定理):一切「直观算法」=图灵机可算
- 离散符号操作:连续对象(实数)必须先编码(→ 可计算分析的独立分支)
