## ⚠️ 消歧框:讲透计算机数学(11085)≠ 讲透计算数学(11061)

| | 讲透计算机数学 11085 | 讲透计算数学 11061 |
|---|---|---|
| 问的问题 | **什么可算、怎么保证对** | **算得准不准、算得快不快** |
| 本体 | 可计算性/验证/算法分析的数学 | 数值/符号计算的误差与格式 |
| 招牌结果 | 停机不可判定、P vs NP、Hoare 逻辑 | 收敛阶、条件数、正则化 |
| 关系 | 前者研究计算的**极限与保证**;后者研究计算的**工艺**。前者消费后者,后者落地前者 | |
