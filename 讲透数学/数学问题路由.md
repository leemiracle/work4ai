## 三、组合路由三步算法

1. **提取特征集**:把问题拆成 2-3 个特征关键词(比如"推荐系统缓存命中"→ 排队+统计+缓存离散结构)。
2. **查交叉表**:特征对在 §二 有已命名分支 → 直接进去读 00 章;同时把**主特征**在 §一 落一个家。
3. **无交叉名则**:主特征定家族(§一),副特征去该家族的 **长尾归属表/内节** 找工具——每个家族 README 第三节都有归属表,写明"XX 主题归我这里"。

> 例:问题="GPU 上大矩阵求逆的数值可信度" → 特征={浮点误差, 矩阵计算} → §二 无名 → 主特征=浮点误差 → [讲透计算数学](讲透计算数学)(误差分析支)+副特征 → [讲透数值线代](讲透数值线代)(条件数工具)。
