## §0 全局视角：信息论 = "ML 的微积分"

信息论给了 ML **统一的语言**：
- **熵** = 不确定性 = 损失函数
- **KL** = 分布距离 = 正则化
- **互信息** = 相关性 = 表示学习目标
- **交叉熵** = ML 的标准 loss

> 🔑 **核心 DNA**：**信息论把"学习"形式化为"压缩"**——好的表示 = 压缩后的本质信息。

## §1 十条算法经验

### 算法经验 IT1：交叉熵 = KL = MLE 三等价

> $$\min KL(P\|Q) \equiv \min H(P,Q) \equiv \max \mathbb{E}_{x\sim P}[\log Q(x)]$$
>
> 这是 ML 最深刻的等价之一：**最小化损失 = 最小化 KL = 最大似然**。

可迁移：所有 ML loss 都能从信息论推出（应用 #6 KL 约束、#7 配分函数）。

### 算法经验 IT2：为什么分类用 CE 不用 MSE

> MSE 假设高斯噪声，对**离散分类**梯度会消失（饱和区）。
> CE 直接对应 categorical 分布的最大似然——梯度健康。
>
> 算法本质：**损失函数要与数据分布假设匹配**（应用 A6 温度、N5 饱和→消失）。

### 算法经验 IT3：forward KL vs reverse KL = VAE vs GAN

> - **forward KL**（$KL(P\|Q)$）：mode-covering（VAE，mass-preserving）
> - **reverse KL**（$KL(Q\|P)$）：mode-seeking（GAN，避免生成 P 里没有的）
>
> 算法本质：**KL 不对称决定生成模型的特性**。

可迁移：
- **VAE** 用 forward KL
- **GAN** 用 reverse KL
- **扩散模型** 用 score matching（与 reverse KL 相关）
- **变分推断** 用 reverse KL

### 算法经验 IT4：熵 = 不确定性 = 不确定性奖励

> 熵 $H(P) = -\sum P \log P$ 既是"信息量"，也是"不确定性"。
>
> 在 RL 里，**熵正则鼓励探索**（避免策略过早收敛）。
> 在 LLM 生成里，**temperature × entropy** 控制多样性。

可迁移：所有"探索-利用"场景都能用熵正则（应用 RL1 探索-利用）。

### 算法经验 IT5：互信息 = 表示学习的目标

> 互信息 $I(X;Y) = H(X) - H(X|Y)$ 衡量"Y 提供了多少关于 X 的信息"。
>
> **对比学习（SimCSE, CLIP）的目标就是最大化正例对的互信息**。

可迁移：
- **对比学习**：最大化 anchor-positive 互信息
- **特征选择**：选与目标互信息高的特征
- **解释性**：互信息衡量特征重要性

### 算法经验 IT6：压缩即学习（Colt 2024 图灵奖）

> **模式识别 = 数据压缩**（Kolmogorov 复杂性）。
>
> 现代版本：
> - **LLM 预训练** = 压缩互联网文本
> - **表示学习** = 压缩数据到低维向量
> - **RAG** = 用外部库"压缩"知识
>
> 这是 ML 的"统一理论"（应用 G1 RAG=外部 K/V、M1 表示=中间货币）。

### 算法经验 IT7：通道编码 = 错误纠正 = 鲁棒性

> Shannon 的通道编码定理：**只要码率 < 通道容量，就能可靠传输**。
>
> 在 ML 里：**正则化 = 给模型"加冗余"防过拟合**——与错误纠正同构。

可迁移：
- **dropout** = 通道噪声
- **data augmentation** = 错误纠正码
- **ensemble** = 多次重传

### 算法经验 IT8：Transformer 是信息瓶颈网络

> 信息论视角看 Transformer：
> - **attention** = 信息路由（应用 A2 核回归）
> - **FFN** = 信息存储（应用 A11）
> - **残差** = 信息高速路（应用 N1）
> - **LayerNorm** = 信息归一化

每层都是信息处理操作——**Transformer 是工程化的信息处理流水线**。

### 算法经验 IT9：信息瓶颈（Information Bottleneck）

> Tishby 的信息瓶颈理论：**深度网络在学"压缩输入 X 但保留标签 Y 信息"的表示**。
>
> $$\min I(X; T) - \beta I(T; Y)$$
>
> $T$ 是中间表示。这是**表示学习的数学形式化**（应用 M1、M3）。

### 算法经验 IT10：香农熵决定 LLM 上限

> 语言的香农熵率约 1.5-2 bit/字符。这决定了**LLM 理论上的压缩极限**。
>
> Chinchilla、Scaling Law 都是**逼近这个极限**的工程努力。
