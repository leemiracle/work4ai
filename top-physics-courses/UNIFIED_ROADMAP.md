# 🎯 物理学最优学习路径 · 30 课费曼式 Roadmap（10 校联合精炼版）

> **核心问题**：10 校 × 8 主题 = 79 门课程，全部学完需要 5+ 年。但如果只有 1-2 年，应该**学哪 30 课、按什么顺序、用哪个学校的版本**，才能从零达到物理本科+研究生入门？
>
> **本文档**：从 79 门中精选 30 课，按**物理学的内在逻辑**（危机→解决→新危机）排序，每课标"前置→当前→后续"的衔接关系。
>
> **与 PHYSICS_FEYNMAN_NARRATIVE.md 的关系**：叙事文档讲"故事"，本文档给"地图"——两者配合使用。

## 📖 第一部分：30 课路径（按物理学的"危机→革命"链排序）

> 每课标号 L01-L30，含：**衔接**（前置/后续）+ 最佳学校版本 + 费曼式一句话 + 知识检查

### 阶段 A：经典物理地基（6-8 周，所有路径必学）

---

#### **L01 经典力学** ⭐⭐⭐ 必学
- **费曼一句话**：苹果和月亮服从同一套定律；自然界走"最省力"的路径
- **衔接**：前置 = 微积分 → **本课** = 牛顿/拉格朗日/哈密顿 → 后续 = 电磁学（力学的框架被推广到场）
- **最佳版本**：**MIT 8.09**（Taylor 教材）或 **Cambridge Part IA**（Kibble & Berkshire）
- **替代**：Harvard Phys 15a（Morin 荣誉版，难题多）/ Caltech Ph 1a（Feynman 风格）
- **可跑 demo**：[Berkeley 谐振子](berkeley-physics/physics_demos.py) / [Caltech 开普勒](caltech-physics/physics_demos.py) / [MIT 陀螺](mit-physics/physics_demos.py)
- **知识检查**：能否用拉格朗日方程推导出单摆的运动方程？

---

#### **L02 电磁学** ⭐⭐⭐ 必学
- **费曼一句话**：场是真实的物理实体（不是数学工具）；光就是电磁波
- **衔接**：前置 = 力学 + 矢量微积分 → **本课** = 麦克斯韦方程 → 后续 = 狭义相对论（光速危机催生）
- **最佳版本**：**MIT 8.022**（Purcell 荣誉版，从相对论视角讲电磁学）或 **Berkeley 110A**（Griffiths）
- **替代**：Cambridge Part IB / Oxford Year 2
- **可跑 demo**：[Cambridge RC/LC](cambridge-physics/physics_demos.py) / [Oxford 高斯定律](oxford-physics/physics_demos.py)
- **知识检查**：能否从麦克斯韦方程推出光速 $c = 1/\sqrt{\mu_0\varepsilon_0}$？

---

#### **L03 振动、波与光学** ⭐⭐ 强烈推荐
- **费曼一句话**：从吉他弦到激光，波是自然界最普遍的信息载体
- **衔接**：前置 = 力学 → **本课** = 波动方程 + 干涉/衍射 → 后续 = 量子力学（物质也是波）
- **最佳版本**：**MIT 8.03**（Crawford《Waves》经典）或 **Caltech Ph 2a**（Feynman 讲波）
- **知识检查**：能否解释双缝干涉为什么产生明暗条纹？

---

#### **L04 热力学** ⭐⭐ 强烈推荐
- **费曼一句话**：时间为什么单向？因为"回到有序"的概率太小
- **衔接**：前置 = 力学 → **本课** = 热力学四定律 → 后续 = 统计力学（微观解释）
- **最佳版本**：**Stanford PHYS 45**（Schroeder《热物理》）或 **MIT 8.044**
- **可跑 demo**：[Caltech 卡诺循环](caltech-physics/physics_demos.py)
- **知识检查**：能否解释为什么熵增定律不是"绝对定律"而是统计规律？

---

#### **L05 统计力学** ⭐⭐⭐ 必学
- **费曼一句话**：$S = k_B \ln W$——熵 = 信息的缺失（和信息论、ML loss 同源）
- **衔接**：前置 = 热力学 + 量子 → **本课** = 玻尔兹曼 + 系综理论 → 后续 = 凝聚态（多体统计）
- **最佳版本**：**Berkeley 112**（Kittel & Kroemer）或 **Stanford PHYS 107**
- **替代**：Cambridge Part IB / Princeton PHY 505（研究生版 Pathria）
- **可跑 demo**：[Caltech Ising](caltech-physics/physics_demos.py) / [ETH Ising 精确解](eth-physics/physics_demos.py)
- **知识检查**：能否推导理想气体的麦克斯韦-玻尔兹曼分布？

---

#### **L06 数学方法** ⭐⭐ 强烈推荐
- **费曼一句话**：复变函数 + 偏微分方程 + 特殊函数——物理学的"工具箱"
- **衔接**：前置 = 微积分 + 线性代数 → **本课** = 物理数学工具 → 后续 = 所有高级课
- **最佳版本**：**Princeton PHY 403**（Boas）或 **Stanford PHYS 131**
- **替代**：Cambridge Part IB Mathematics（Riley Hobson Bence）/ Oxford
- **知识检查**：能否用留数定理计算实变积分？

---

### 阶段 B：近代物理革命（8-10 周，所有路径必学）

---

#### **L07 狭义相对论** ⭐⭐⭐ 必学
- **费曼一句话**：光速对所有人一样 → 时空是一个整体 → $E = mc^2$
- **衔接**：前置 = 电磁学（光速危机）→ **本课** = 洛伦兹变换 → 后续 = 广义相对论（加速参考系）
- **最佳版本**：**MIT 8.20**（独立暑假课）或融入 Harvard Phys 16（Morin 相对论章节）
- **知识检查**：能否推导时间膨胀公式 $\Delta t' = \gamma \Delta t$？

---

#### **L08 量子力学入门** ⭐⭐⭐ 必学
- **费曼一句话**：上帝确实在掷骰子；粒子是波，波是粒子
- **衔接**：前置 = 力学 + 波 + 统计 → **本课** = 薛定谔方程 → 后续 = 量子中级（氢原子 + 自旋）
- **最佳版本**：**MIT 8.04**（Adams，Griffiths 教材）或 **Stanford PHYS 130**
- **替代**：Berkeley 137A / Harvard Phys 143a / Oxford Year 2
- **可跑 demo**：[MIT 波包演化 Crank-Nicolson](mit-physics/physics_demos.py) / [Berkeley 势阱](berkeley-physics/physics_demos.py) / [Oxford 轨道](oxford-physics/physics_demos.py)
- **知识检查**：能否从薛定谔方程推出无限深势阱的能级？

---

#### **L09 量子力学中级** ⭐⭐⭐ 必学
- **费曼一句话**：氢原子的美妙在于球对称 → 角动量量子化 → 元素周期表的根源
- **衔接**：前置 = 量子入门 → **本课** = 氢原子 + 自旋 + 微扰 → 后续 = 量子场论（相对论性量子）
- **最佳版本**：**MIT 8.05/8.06**（Sakurai / Griffiths ch 2-11）或 **Princeton PHY 305**
- **知识检查**：能否解释为什么电子自旋是 1/2？

---

#### **L10 广义相对论** ⭐⭐ 理论方向必学
- **费曼一句话**：引力不是力，是时空弯曲；物质告诉时空怎么弯，时空告诉物质怎么动
- **衔接**：前置 = 狭义相对论 + 数学方法 → **本课** = 微分几何 + 爱因斯坦方程 → 后续 = 宇宙学
- **最佳版本**：**MIT 8.962**（Carroll 教材，Carroll 本人在 Stanford）或 **Cambridge Part III**
- **替代**：Princeton PHY 563 / Stanford PHYS 250 / ETH 402-3001-00L
- **可跑 demo**：[Princeton 引力红移](princeton-physics/physics_demos.py) / [ETH 等效原理](eth-physics/physics_demos.py)
- **知识检查**：能否解释 GPS 为什么必须修正广义相对论效应？

---

### 阶段 C：高级专题（10-14 周，按方向选）

---

#### **L11 量子场论 / 标准模型** ⭐⭐⭐ 理论必学
- **费曼一句话**：万物皆场；粒子是场的振动；真空不空（在涨落）
- **衔接**：前置 = 量子中级 + 狭义相对论 → **本课** = QFT → 后续 = 粒子物理 / 弦理论
- **最佳版本**：**MIT 8.323**（Peskin & Schroeder）或 **Princeton PHY 619**
- **知识检查**：能否解释为什么费曼图是计算散射截面的工具？

---

#### **L12 凝聚态物理** ⭐⭐⭐ 必学（应用广）
- **费曼一句话**：More Is Different——$10^{23}$ 个粒子会涌现出全新的物理（超导/磁性/拓扑）
- **衔接**：前置 = 量子 + 统计 → **本课** = 能带 + 超导 + 拓扑 → 后续 = 量子计算 / 材料科学
- **最佳版本**：**Oxford**（Simon《Oxford Solid State Basics》）或 **MIT 8.231**（Kittel）
- **替代**：Cambridge Part II / ETH 402-2601-00L
- **可跑 demo**：[ETH London 方程](eth-physics/physics_demos.py) / [Tokyo BCS](tokyo-physics/physics_demos.py)
- **知识检查**：能否解释为什么金属导电而绝缘体不导电（能带论）？

---

#### **L13 粒子物理** ⭐⭐ 理论必学
- **费曼一句话**：17 种基本粒子 + 4 种力 = 宇宙的全部基本构件
- **衔接**：前置 = QFT → **本课** = 标准模型 → 后续 = 超出标准模型 / 弦理论
- **最佳版本**：**Stanford PHYS 275**（Griffiths《粒子物理》）或 **Berkeley 129**
- **知识检查**：能否解释为什么希格斯玻色子的发现完成了标准模型？

---

#### **L14 宇宙学** ⭐⭐ 推荐
- **费曼一句话**：宇宙 95% 是暗的（暗物质 + 暗能量），我们只理解 5%
- **衔接**：前置 = 广义相对论 → **本课** = 大爆炸 + 暗物质/能量 → 后续 = 量子引力
- **最佳版本**：**MIT 8.286**（Alan Guth 早期宇宙）或 **Stanford PHYS 380**（KIPAC）
- **知识检查**：能否解释哈勃定律和宇宙膨胀？

---

#### **L15 计算物理** ⭐⭐⭐ 现代必备
- **费曼一句话**：物理学 = 理论 + 实验 + **计算**（第三支柱）
- **衔接**：前置 = 所有基础 → **本课** = 数值方法 + MD + MC → 后续 = AI for Science
- **最佳版本**：**Caltech Ph 20-22**（最系统）或 **Berkeley 115**（Giordano 教材）
- **可跑 demo**：本项目全部 10 校 physics_demos.py 都是计算物理产物
- **知识检查**：能否写一个分子动力学（MD）模拟？

## ⚠️ 第三部分：避坑指南

### 🕳️ 陷阱 1：先学完所有数学再学物理
- ❌ 学完 Boas 整本再做物理 = 永远开始不了
- ✅ 边学边用，遇到不会的回头查

### 🕳️ 陷阱 2：只读教材不做题
- ❌ "我读懂了" ≠ "我会做了"
- ✅ 每章做 5-10 道题，特别是 Cambridge Tripos 风格计算题

### 🕳️ 陷阱 3：跳过经典力学直接学量子
- ❌ 没有拉格朗日/哈密顿基础，量子力学的算符形式无法理解
- ✅ 先学 L01（特别是哈密顿），再学 L08

### 🕳️ 陷阱 4：忽视统计力学
- ❌ 统计力学看起来"不够基本"，但它**通向凝聚态 + ML + 信息论**
- ✅ L05 是投资回报率最高的课之一

### 🕳️ 陷阱 5：追最新论文忽视经典
- ❌ 直接读 arXiv 最新量子引力论文 = 看不懂
- ✅ 先把 L01-L14 的经典教材啃完（费曼、Griffiths、Sakurai、Carroll、Peskin）
