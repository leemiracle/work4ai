# Susskind 理论最小系列导读笔记（6 本）

> **为什么有这个目录**：Leonard Susskind（Stanford 理论物理学家，弦论创始人之一）写的"Theoretical Minimum"系列是**最好的科普→教材桥梁**。他给不懂物理但想学的人写了这套书——用最少的数学，讲最深邃的物理原理。
>
> **定位**：科普级到本科入门之间。如果你觉得 Feynman 讲义还是太难，Susskind 是你的前一站。
>
> **来源**：Susskind 在 Stanford 的系列公开课（YouTube 有全部视频），后整理成书。

## 核心特征

1. **最少数学，最核心物理**：Susskind 只教"做物理所需的最少数学"——不多一个符号
2. **从第一性原理**：每本从零开始，不假设你有前置知识
3. **有视频**：Stanford 公开课配套，YouTube 免费看
4. ** Leonard Susskind 的个人风格**：幽默、直接、偶尔激进——和 Feynman 同一气质

## 阅读路径建议

### 路径 A：理论物理全景（12-18 月）
```
01 经典力学（拉氏/哈氏基础）
→ 02 量子力学
→ 03 狭义相对论与经典场论
→ 04 广义相对论
→ 05 统计力学
→ 06 宇宙学
```

### 路径 B：快速核心（6 月）
只读 01（力学）+ 02（量子）+ 05（统计）——这三个是现代物理的核心语言

### 路径 C：搭配费曼/Tong
Susskind 是"热身"——读完后进入 Feynman 或 Tong 的更严谨教材：
```
Susskind 01 经典力学 → Tong 02 Dynamics and Relativity → Feynman 卷 1
Susskind 02 量子 → Feynman 卷 3 → Griffiths 量子
```
