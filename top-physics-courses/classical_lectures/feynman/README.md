# 费曼物理学讲义（FLP）导读笔记（3 卷全集）

> **为什么有这个目录**：Feynman Lectures on Physics（FLP）是 20 世纪最伟大的物理教科书——Richard Feynman 在 Caltech 给一年级本科生上的课，被整理成 3 卷。它不是教你怎么算题，而是教你像物理学家一样思考。**全 3 卷免费在线**：feynmanlectures.caltech.edu。

## 核心特征

1. **直觉先行**：费曼永远先给你一个物理画面，再写公式——这是费曼方法的核心
2. **叙事风格**：每章像一个故事，不是公式手册
3. **覆盖极广**：3 卷覆盖了几乎整个本科物理（力学→电磁→热学→量子→统计→光学）
4. **习题集**：在线版配有 Caltech 习题（由 Robert Leighton 编写），免费
5. **永不过时**：写于 1961-1963 年，但物理直觉至今无出其右

## 阅读路径建议

### 路径 A：跟随项目主线
```
卷 1（力学 L01 + 热力学 L04 + 相对论 L07）
→ 卷 2（电磁 L02）
→ 卷 3（量子 L08）
```
约 6-9 个月（每周 3-5 小时）。

### 路径 B：只读精华章
如果时间有限，只读这些章节（每卷 4-6 章，共约 15 章）：
- **卷 1**：§1 原子假说、§4 能量守恒（Denis 积木）、§15-16 狭义相对论、§39-40 气体动理论
- **卷 2**：§1 电磁直觉、§18 麦克斯韦方程、§20 自由空间电磁波
- **卷 3**：§1 量子行为（双缝）、§3 概率振幅、§6 自旋 1/2

### 路径 C：配合 Tong 讲义（推荐！）
费曼给直觉，Tong 给系统和习题。交叉阅读效果最好：
```
Tong 02 Dynamics and Relativity ↔ Feynman 卷 1
Tong 05 Electromagnetism ↔ Feynman 卷 2
Tong 06 Quantum Mechanics ↔ Feynman 卷 3
```
