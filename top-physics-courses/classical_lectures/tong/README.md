> **为什么有这个目录**：David Tong（Cambridge）的讲义被公认为"当代最好的物理讲义"——免费、全面、清晰、配习题。本目录把 23 本讲义**逐本做成导读笔记**，整合进项目，作为学习的"黄金中段"资源。

> **来源**：davidtong.org/teaching/（2026-08-13 webfetch 核实）

> **用法**：每本笔记告诉你"这本讲义讲什么、怎么读、读完能干什么"。配合讲义原文（免费 PDF）使用。

## 3 条阅读路径

### 路径 A：本科快速（12-18 月，到 Cambridge 本科毕业水平）
```
01 Particle Physics (科普起兴趣)
→ 02 Dynamics and Relativity
→ 03 Vector Calculus
→ 05 Electromagnetism
→ 04 Classical Dynamics
→ 06 Quantum Mechanics
→ 07 Statistical Physics
→ 08 Solid State Physics
```

### 路径 B：理论深钻（24-36 月，到研究生）
路径 A + 
```
→ 12 Topics in QM
→ 13 General Relativity
→ 14 QFT (看视频!)
→ 15 Statistical Field Theory
→ 23 Gauge Theory
→ 18 String Theory
```

