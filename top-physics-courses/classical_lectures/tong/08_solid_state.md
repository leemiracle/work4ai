## §4 核心章节拆解（深化版）

### §4.1 自由电子气（第 1 章）—— 金属导电的两种理论

**核心问题**：金属中的电子怎么运动？为什么导电？

**Drude 模型（1900，经典）**：
- 电子像气体分子，在离子实之间自由飞行，偶尔碰撞（散射）
- 碰撞提供电阻，两次碰撞间的平均时间 = 弛豫时间 $\tau$（mean free time）
- **电导率**（Drude 公式）：
$$\sigma = \frac{ne^2\tau}{m}$$
其中 $n$ = 电子数密度，$e$ = 电子电荷，$m$ = 电子质量
- 直觉：电子像台球，被电场加速，撞到东西就重新开始——平均速度 = 电导

**Drude 的成功与失败**：
- ✅ 正确给出 $\sigma$ 的形式，预测了电子比热（但数值错）
- ❌ 预测电子气对比热的贡献应为 $\frac{3}{2}Nk_B$（经典）——但实测只有它的 ~1%！
- ❌ 无法解释为什么只有 Fermi 面附近的电子参与导电

**Sommerfeld 理论（1928，量子修正）**：
- 电子服从 **Fermi-Dirac 分布**：
$$f(E) = \frac{1}{e^{(E-\mu)/k_BT} + 1}$$
- $T=0$ 时电子填满到 **Fermi 能** $E_F$，以上全空
- **Fermi 能**（自由电子气）：
$$E_F = \frac{\hbar^2}{2m}(3\pi^2 n)^{2/3}$$
对典型金属（$n \sim 10^{29}\,\text{m}^{-3}$），$E_F \sim$ 几个 eV，对应 $T_F = E_F/k_B \sim 10^4$ K！

- **Fermi 速度**：$v_F = \sqrt{2E_F/m} \sim 10^6$ m/s（比经典热运动快得多）
- **态密度**（3D 自由电子）：$g(E) \propto \sqrt{E}$（能量越高，可用态越多）

**Sommerfeld 的关键修正**：
- 只有 $E_F$ 附近 $\sim k_BT$ 范围内的电子能被热激发（其他电子被 Pauli 不相容原理锁住）
- 室温下 $k_BT/E_F \sim 1\%$ → 只有约 1% 的电子参与导电和热容
- **电子比热**（线性）：
$$C_e = \gamma T, \quad \gamma = \frac{\pi^2}{2}\frac{nk_B^2}{E_F}$$
这与声子的 $T^3$ 不同——低温下金属热容 = 电子（$\gamma T$）+ 声子（$\beta T^3$），电子项主导。

**直觉图像**：金属中的电子像一罐紧密排列的球——大部分在 Fermi 面以下"填满了"动不了，只有 Fermi 面最顶层的少数电子能被电场/热场推动。但它们速度极快（$v_F \sim 10^6$ m/s），所以即使只有 1%，金属仍导电良好。

**反直觉点**：金属里电子的平均速度是 $v_F \sim 10^6$ m/s，**与温度几乎无关**（因为 $E_F \sim 10^4$ K 远大于室温）。加热金属不会让电子"跑得更快"——只让 Fermi 面附近的一小撮电子重新分布。这是经典 Drude 模型完全无法理解的。

### §4.2 能带理论（第 2 章）—— 固体物理的灵魂

**核心问题**：周期势中的电子能谱为什么会分裂成"带"和"隙"？

**Bloch 定理（1928）**：周期势 $V(\mathbf{r}) = V(\mathbf{r}+\mathbf{R})$ 中，电子波函数必为：
$$\psi_k(\mathbf{r}) = e^{i\mathbf{k}\cdot\mathbf{r}}\,u_k(\mathbf{r})$$
其中 $u_k(\mathbf{r})$ 具有晶格周期性（$u_k(\mathbf{r}) = u_k(\mathbf{r}+\mathbf{R})$）。

直觉：电子不是驻波，而是"调制在晶格周期上的行波"——它在晶格中传播像波，但感受到周期性的调制。

**近自由电子模型**（弱周期势，微扰论）：
- 自由电子的抛物线 $E = \hbar^2k^2/2m$ 在**布里渊区边界**处被周期势扰动
- 边界处发生 **Bragg 反射**（电子波被晶格反射），打开**能隙**
- 能隙大小正比于周期势的 Fourier 分量 $|V_G|$

**紧束缚模型**（强束缚，从原子轨道出发）：
- 电子主要局域在原子附近，偶尔跃迁到近邻原子
- 一维紧束缚能带：
$$E(k) = E_0 - 2t\cos(ka)$$
其中 $t$ = 跃迁幅度（hopping），$a$ = 晶格常数。带宽 = $4t$。

**能隙的起源**：周期势导致**布里渊区边界处的能级排斥**（level repulsion）。两个简并的自由电子态（$+k$ 和 $-k$ 的 Bragg 反射态）混合后分裂——一个能量升高，一个降低，中间留出能隙。

**导体/绝缘体/半导体的判据**（关键！）：
- **部分填充的带 = 导体**（电子可被电场加速到附近空态）
- **完全填满 + 大能隙（$\gg k_BT$）= 绝缘体**（电子无法跃迁到上一个带，无可移动空态）
- **完全填满 + 小能隙（$\sim k_BT$ 或 $\sim 1$ eV）= 半导体**（热激发可少量跃迁）

**直觉图像**：自由电子的连续能谱在周期势中被"切割"成带——就像楼梯把斜坡切成台阶。每个带是一个"楼层"，楼层之间的空隙就是能隙。

**反直觉点 1**：导体/绝缘体/半导体的区别**完全来自能带结构**——不是原子本身的性质（碳可以是金刚石绝缘体，也可以是石墨导体！），而是晶格结构和电子填充方式。

**反直觉点 2**：完全填满的带**不导电**。虽然有很多电子，但它们的总动量为零，加电场后没有可用的空态跃迁（像满了的停车场，车无法移动）。这是绝缘体不导电的本质原因。

### §4.3 半导体（第 3 章）—— 现代电子学的物理基础

**核心问题**：小能隙材料如何通过温度和掺杂控制导电性？

**典型带隙**（~1 eV 量级）：
- 硅 Si：$E_g = 1.12$ eV（信息时代的基石）
- 砷化镓 GaAs：$E_g = 1.43$ eV（高速器件、激光器）
- 锗 Ge：$E_g = 0.67$ eV（第一个晶体管材料）

**本征载流子浓度**（热激发）：
$$n_i \propto T^{3/2} e^{-E_g/2k_BT}$$
室温下 Si 的 $n_i \sim 10^{10}$ cm⁻³（远小于金属的 $10^{22}$ cm⁻³）。

**有效质量**（$m^*$）：
$$m^* = \frac{\hbar^2}{d^2E/dk^2}$$
- 能带底部：$d^2E/dk^2 > 0$ → $m^* > 0$（电子）
- 能带顶部：$d^2E/dk^2 < 0$ → **$m^* < 0$**！
- 负有效质量在物理上重新解释为**带正电的空穴**（hole）

**掺杂**：
- **n 型**：掺入多电子杂质（如 Si 中掺磷 P，第 V 族）→ 提供额外电子
- **p 型**：掺入少电子杂质（如 Si 中掺硼 B，第 III 族）→ 提供额外空穴

**p-n 结**（半导体的核心器件）：
- p 型和 n 型接触 → 电子从 n 扩散到 p，空穴反向 → 形成**耗尽层**（depletion region）
- 耗尽层内有**内建电场**（built-in potential $V_{bi}$）
- **整流 I-V 特性**：
$$I = I_0\left(e^{eV/k_BT} - 1\right)$$
正向偏置（V > 0）电流指数增长，反向偏置（V < 0）电流几乎为零——这就是二极管的单向导电性。

**直觉图像**：半导体像"可调阀门"——通过掺杂和电场控制载流子，实现开关、放大、整流。整个数字电子学建立在这个原理上。

**反直觉点**：空穴是"缺失的电子"——但它表现得像一个带正电、有正有效质量的准粒子。这不是近似，是精确的物理。空穴的迁移率可以和电子不同（Si 中空穴慢于电子），这是为什么 CMOS 电路要 pMOS 和 nMOS 配对。

### §4.4 声子（第 4 章）—— 晶格振动的量子化

**核心问题**：晶格原子如何振动？振动如何量子化？

**经典图像**：原子间用弹簧（原子间力）连接，集体振动 = 格波（lattice waves）。

**量子化**：格波的能量量子化为**声子**（phonon）——声子是**玻色子**（自旋 0）。

**色散关系 $\omega(k)$**（一维双原子链为例）：
- **声学支**（acoustic）：$\omega \propto k$（低频），对应相邻原子**同向**运动 → 声波
- **光学支**（optical）：$\omega \neq 0$ at $k=0$，对应相邻原子**反向**运动 → 可被红外光激发（IR active）

**Debye 模型**（低温热容）：
$$C_V = 9Nk_B\left(\frac{T}{\Theta_D}\right)^3 \int_0^{\Theta_D/T} \frac{x^4 e^x}{(e^x-1)^2}\,dx$$
其中 $\Theta_D$ = Debye 温度（材料常数，如 Cu 的 $\Theta_D \approx 343$ K）。

**两个极限**：
- **高温**（$T \gg \Theta_D$）：$C_V \to 3Nk_B$（**Dulong-Petit 定律**，经典极限，每个原子 3 个自由度各贡献 $k_B$）
- **低温**（$T \ll \Theta_D$）：$C_V \propto T^3$（**Debye 定律**，量子极限）

**直觉图像**：原子振动像弹簧链——声子是这根链上的波。低频声子 = 声学支（所有原子同向晃），高频声子 = 光学支（相邻原子对撞）。

**反直觉点**：低温下晶格热容 $\propto T^3$，**远小于**经典 Dulong-Petit 值 $3Nk_B$——因为只有长波长（低频）声子被激发，高频声子被 Bose-Einstein 分布"冻结"（$e^{\hbar\omega/k_BT}$ 太大）。这是量子效应在宏观热力学中的直接体现，也是 Einstein 1907 年首次用量子论解释固体比热的成功（虽然他的模型给出 $e^{-\hbar\omega/k_BT}$ 衰减而非 $T^3$，Debye 1912 才修正）。

### §4.5 费米面（第 5 章）—— 金属的"地形图"

**核心概念**：动量空间（$k$-space）中 $E = E_F$ 的等能面。

- **自由电子**：费米面是**球**（$E = \hbar^2k^2/2m = E_F$）
- **真实金属**：费米面形状复杂——铜有"neck"，铁有多重"pocket"

**费米面决定什么**：
- 电导、热导（费米面附近电子的散射）
- 光学性质（金属的颜色、反射率）
- 磁性各向异性（费米面的形状决定磁化方向）

**实验探测：de Haas-van Alphen 效应**：
- 强磁场下，金属磁化率随磁场**振荡**
- 振荡频率正比于费米面的**极值截面积**（Onsager 关系）
- 通过测量振荡，可以**反推费米面拓扑**——这是实验绘制费米面的金标准

**直觉图像**：费米面是金属电子的"地形图"——它的形状决定了电子在各个方向的运动能力，从而决定金属的输运、光学、磁性。

**反直觉点**：费米面只占动量空间的一小部分（$E < E_F$ 的填充区域），但它的**拓扑结构**决定了所有电子输运性质。这就是为什么凝聚态物理学家花大量精力研究费米面几何。

### §4.6 磁场中的电子（第 6 章）—— Landau 能级与量子霍尔

**核心概念**：磁场中的自由电子能量量子化为 **Landau 能级**。

**Landau 能级**：
$$E_n = \hbar\omega_c\left(n + \frac{1}{2}\right), \quad \omega_c = \frac{eB}{m}$$
其中 $\omega_c$ = 回旋频率（cyclotron frequency）。

**能级简并度**：每个 Landau 能级容纳的电子数 $\propto B$（磁场越强，简并度越高）。

**直觉图像**：磁场让电子做圆周运动（回旋运动），量子化后圆周半径只能取离散值 → 分立 Landau 能级。就像把连续的"坡道"变成"台阶"。

**整数量子霍尔效应**（von Klitzing 1980，1985 诺奖）：
- 二维电子气在强磁场中，Hall 电导量子化：
$$\sigma_{xy} = \nu\frac{e^2}{h}, \quad \nu = 1, 2, 3, \ldots$$
- 量子化精度高达 $10^{-9}$——**独立于样品细节**（杂质、形状、大小）！

**拓扑保护**：
- 电流由**边缘态**（edge states）携带
- 边缘态是**拓扑保护的**——杂质无法背散射（没有反向态可散射到）
- 这是**拓扑物相**（topological phases）的第一次实验实现，催生了拓扑绝缘体、拓扑超导体等整个领域

**反直觉点**：Hall 电导量子化到 $10^{-9}$ 精度，**与样品的微观细节无关**——这是拓扑保护的威力。$e^2/h$ 现在用于**定义电阻标准**（von Klitzing 常数 $R_K = h/e^2 \approx 25812.8\,\Omega$）。

→ 详见 [19_quantum_hall.md](19_quantum_hall.md)（分数量子霍尔效应 + 拓扑物相）。

- **怎么读**：重点理解**能带**和**费米面**——这两个概念贯穿全部凝聚态物理
- **陷阱**：
  - 有效质量 $m^* = \hbar^2/(d^2E/dk^2)$ 可以是负的——这导致"空穴"概念，初学易混
  - 不要把声子当声波——声子是量子化的格波，玻色子准粒子
  - Bloch 波矢 $k$ 不是真正的动量——它是"晶格动量"，只能定义到倒格子矢量（相差一个倒格矢的 $k$ 等价）
  - Fermi 能 $E_F$ 是 $T=0$ 的化学势；有限温下化学势 $\mu(T) \neq E_F$（虽然差别很小）
- **关键洞察**：固体物理的核心洞察是**能带**——周期势中电子的能谱自然分裂为带和隙。导体/绝缘体/半导体的全部区别来自能带的填充方式。这个洞察直接催生了晶体管（1947，Bell Labs，Bardeen/Brattain/Shockley 1956 诺奖）、集成电路、整个半导体工业——人类历史上最重要的技术革命之一。

## §10 常见误区（深化新增）

### 🕳️ 误区 1：有效质量总是正的
- ❌ "电子的有效质量就是电子质量 $m_e$，总是正的"
- ✅ 有效质量 $m^* = \hbar^2/(d^2E/dk^2)$ **可以为负**（能带顶部）。负有效质量在物理上重新解释为**带正电的空穴**——这不是近似，是精确的准粒子描述。

### 🕳️ 误区 2：填满的带会导电
- ❌ "带里电子越多，导电越好，所以填满的带导电最强"
- ✅ 填满的带**净电流为零**——所有 $k$ 态都被占据，加电场后没有可跃迁的空态（像满停车场，车动不了）。绝缘体的本质就是最高带完全填满。

### 🕳️ 误区 3：声子就是声波
- ❌ "声子 = 声波，和空气里的声音一样"
- ✅ 声子是**量子化的晶格振动**，是玻色子准粒子。声波只是声学支声子的经典极限；还有光学支声子（相邻原子反向振动，IR 活性），与声波完全不同。

### 🕳️ 误区 4：Bloch 波矢 k 是真正的动量
- ❌ "Bloch 态的 $k$ 就是电子的真实动量 $\hbar k$"
- ✅ $k$ 是**晶格动量**（crystal momentum），定义在倒格子空间，只能确定到**模一个倒格子矢量**（$k$ 和 $k+G$ 等价）。真正的动量不守恒（周期势会传递动量给晶格），守恒的是晶格动量。

### 🕳️ 误区 5：半导体带隙 = 把电子拿出材料所需的能量
- ❌ "带隙就是把电子从材料里拔出来要的能量"
- ✅ 带隙是**价带顶到导带底的跃迁能**（promotion energy），是把电子从价带顶激发到导带底所需的能量（Si: 1.12 eV）。把电子完全拿出材料叫**功函数**（work function，几个 eV），是不同的物理量。

## §11 与其他固体物理教材的对比（深化新增）
