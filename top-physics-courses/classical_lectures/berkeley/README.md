
# Berkeley Physics Course 导读笔记（5 卷全集）

> **为什么有这个目录**：Berkeley Physics Course 是 1960 年代 UC Berkeley 为本科生物理课编写的 5 卷教材，与费曼讲义同时代、同级别。它的风格更传统、更系统，适合配合费曼使用。其中 **Purcell 电磁（卷 2）** 和 **Reif 统计（卷 5）** 是公认的各自领域最佳教材。

## 核心推荐

### ⭐ 必读：卷 2 Purcell 电磁
- **从相对论讲电磁**——磁力 = 运动参考系中的电力。这一视角深刻影响了 Feynman 卷 2、Griffiths、Schwartz 等后世教材
- Morin 2013 修订版更新了符号、加了新习题、保持了 Purcell 的精神

### ⭐ 必读：卷 5 Reif 统计
- **统计力学最完整的本科/研究生级教材**——~800 页，从基本原理出发，推导热力学、统计系综、相变、输运
- 比 Kittel & Kroemer 更完整，比 Pathria 更可读

| 卷 | Berkeley | 费曼 | 建议组合 |

## 阅读路径建议

### 推荐组合（18-24 月）
```
Berkeley 卷 1 力学（系统）
→ Feynman 卷 1（直觉补充）
→ Berkeley 卷 2 Purcell EM（相对论电磁）
→ Berkeley 卷 3 波（Crawford）
→ Feynman 卷 3 量子（不用 Berkeley 卷 4）
→ Berkeley 卷 5 Reif 统计（最后，最难也最深）
```

### 快速路径（只读精华）
- **Purcell 卷 2**（相对论电磁，不可替代）
- **Reif 卷 5** 前 7 章（系综理论核心）
