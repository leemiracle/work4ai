## §1 诚实的前置判断

### 1.1 实验物理的现实

- **门槛高**：仪器（光谱仪/低温/真空/激光）昂贵，一个实验台 $10k-$1M
- **时间长**：一个博士实验可能 4-5 年
- **需要实体**：必须有实验室、安全培训、导师现场指导
- **失败率高**：80% 的实验因各种问题（噪声/污染/仪器故障）失败

### 1.2 你应该走实验吗？

**建议走实验**，如果：
- 你对动手操作有强烈热情
- 你能进入实体实验室（中科院/大学/工业）
- 你享受"调试仪器"胜过"推导公式"

**建议走理论/计算/AI for Physics**（推荐），如果：
- 你擅长数学和编程（你有 work4ai）
- 你希望快速产出（计算 1 月 = 实验 1 年）
- 你想用 AI 能力弯道超车

> **结论**：对你而言，实验是**可选补充**，不是主线。本文档主要给"理论/计算学生也该懂的基础实验素养"。

## §2 所有物理学生都该懂的实验素养（不论方向）

### 2.1 误差分析（必学）

**教材**：
- **Taylor** *An Introduction to Error Analysis*（物理系标配，必读）
- **Bevington & Robinson** *Data Reduction and Error Analysis*（进阶）

**核心概念**：
- 系统误差 vs 随机误差
- 不确定度传播：$\sigma_f^2 = \sum (\partial f/\partial x_i)^2 \sigma_{x_i}^2$
- 最小二乘拟合
- $\chi^2$ 检验

**为什么重要**：即使做计算物理，也要会量化误差（你的 PINN 解和解析解差多少？统计上显著吗？）

### 2.2 数据采集与处理

- **数据格式**：HDF5（科学数据标准）/ CSV / JSON
- **处理库**：NumPy + pandas + xarray（多维数据）
- **可视化**：matplotlib + Plotly（交互）+ ParaView（3D）
- **统计**：scipy.stats + astropy.stats（天文）

### 2.3 可复现性

- 实验数据 + 代码 + 分析脚本都进 git
- 用 Jupyter notebook 记录分析过程
- 论文发表时数据上传 Zenodo/figshare（分配 DOI）

## §3 在线实验资源（不需实体实验室）

### 3.1 PhET 交互式模拟

- **网址**：phet.colorado.edu
- **内容**：物理各领域的交互式 Java/HTML5 模拟（量子/电磁/力学/统计）
- **用法**：建立直觉，不是真实验

### 3.2 MIT 8.13（实验物理方法论）

- **OCW**：ocw.mit.edu/courses/8-13-experimental-physics
- **内容**：误差分析 + 经典实验（光谱/霍尔效应/Millikan 油滴）
- **免费**：讲义+实验手册全公开

### 3.3 在线远程实验

- **Labster**：虚拟实验室（付费）
- **PocketLab**：传感器+app，家用实验
- **NASA/ESA 公开数据**：天文/空间物理（真实数据！）

### 3.4 用真实公开数据做"实验"

| 数据源 | 做什么 |
|--------|--------|
| **COBE/FIRAS**（NASA）| 拟合 CMB 黑体谱 → 宇宙温度 2.725 K |
| **LIGO 公开数据** | 引力波信号检测（Python gwpy 库）|
| **SDSS**（斯隆数字巡天）| 星系分类/红移测量 |
| **Planck 卫星数据** | 宇宙学参数 |
| **Materials Project** | DFT 数据库，材料筛选 |

> **这是"理论学生也能做的实验"**——用真实观测数据，做真实分析。

## §6 计算物理学生的"伪实验"训练（你的最佳路线）

如果走理论/计算，做这些培养"实验直觉"：

1. **跑公开数据**：从 NASA LAMBDA 下载 CMB 数据，用 Python 拟合
2. **数值"实验"**：用 LAMMPS 跑不同温度/压强的 MD，观察相变
3. **DFT"实验"**：用 Quantum ESPRESSO 扫描不同材料的能带
4. **数据驱动"实验"**：用 Materials Project 数据训练材料性质预测模型

> **这些"实验"不需要仪器，但培养相同的"观测 → 假设 → 验证"科学思维。**
