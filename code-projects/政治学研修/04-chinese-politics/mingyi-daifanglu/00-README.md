# 《明夷待访录》专题 · 中国本土的反专制源头

> **04 中国政治 / 政治思想史经典**
> 黄宗羲《明夷待访录》（1662）是中国传统里**最系统的君主专制批判**，比卢梭《民约论》早约一百年。它与[王夫之《读通鉴论》](../du-tongjian-lun/00-README.md)构成**明清之际思想双峰**——黄从政治批判，王从历史哲学。
>

## 0. 为什么读《明夷待访录》？

项目多处提到黄宗羲（[明史学史](../ming-dynasty/04-明史史学史与方法论.md)的"反专制源头"、[读通鉴论](../du-tongjian-lun/02-核心史观.md)的"生民为公一姓为私"对照），但一直没系统读他。本专题补上这块，理由有三：

1. **它是中国本土"反专制"的思想源头**。"天下之大害者，君而已矣"——这句石破天惊的话，出自 1662 年的中国，比欧洲启蒙还早。**它证明"批判君主专制"不是西方专利，中国本土曾长出自己的批判传统**。
2. **它不止于批判，还提出了制度设计**。"学校议政"（公是非于学校）、"置相"（恢复相权制衡）、"天下之法"代替"一家之法"——黄宗羲画了一幅**限制君权的蓝图**，是中国本土最早的"权力制衡"设想。
3. **它深刻影响了近代中国**。梁启超、谭嗣同"将其书节抄，印数万本，秘密散布，于晚清思想之骤变，极有力"；孙中山的"民权"也受其影响。**读懂它，就读懂了中国近代思想的一个源头**。

> 一句话：**《明夷待访录》让你看到——在没有西方输入的情况下，中国思想能走多远、又在哪儿止步。** 这既是骄傲，也是反思。

## 1. 关于本书：21 篇的反专制纲领

- **作者**：黄宗羲（1610–1695），字太冲，号南雷，学者称**梨洲先生**，浙江余姚人。与顾炎武、王夫之并称**明清之际三大思想家**。
- **成书**：始作于顺治十八年（1661），完稿康熙元年（**1662**），黄宗羲 54 岁。因批判君主专制，乾隆年间曾被列为**禁书**。
- **书名**："明夷"出自《周易》卦名"箕子之明夷"——**黎明前的昏暗**；"待访"=等待明君来访。全意：**黎明前的昏暗中，留给未来明君的备忘录**。
- **结构**：全书 **21 篇**，分三类——
  - **政治批判**：《原君》《原臣》《原法》（追问君、臣、法的本源）
  - **制度设计**：《置相》《学校》《取士》《建都》《方镇》
  - **经济社会**：《田制》《兵制》《财计》《胥吏》《阉宦》

> **一个学术分寸**：黄宗羲是**民本思想家**，但**不等于现代民主主义者**。他主张"学校议政"限制君权，但**未主张人民主权、未主张言论自由彻底**（甚至主张禁毁"无裨实用"的书籍）。称他为"中国的卢梭"是**溢美**（见 `04`）。本专题既讲他的光辉，也讲他与现代民主的距离。
