# 《读通鉴论》专题 · 一个思想家的史论巅峰

> **04 中国政治 / 史论经典精读**
> 王夫之《读通鉴论》是中国传统史论的巅峰——一个思想家借《资治通鉴》的史实，写出"理势合一"的历史哲学。它与[毛泽东读《通鉴》](../zizhi-tongjian/00-README.md)专题构成**古今读《通鉴》的双重视角**：王夫之（古人/哲学家）↔ 毛泽东（今人/政治家）。

## 0. 为什么读《读通鉴论》？

项目里已有[毛读《通鉴》专题](../zizhi-tongjian/00-README.md)，讲"今人/政治家如何读《通鉴》"。但《通鉴》还有另一类伟大读者——**古代思想家**，其中最系统、最深刻的就是**王夫之的《读通鉴论》**。两者对照，才见"读《通鉴》"这一文化行为的全貌：

1. **它是传统史论的巅峰**。北京大学张帆教授的评价：王夫之史论"**宏观视野、问题意识、批判能力**"三长俱全，"堪称传统史论中最系统最精彩的杰作"。中国古代以思想家身份系统论史的极少（除司马迁外），王夫之弥补了这一缺憾。
2. **它提出了一套进步的历史哲学**："**理势合一**""事随势迁而法必变""世益降物益备"——在"天不变道亦不变"的传统里，王夫之独树一帜地主张**历史是进化而非倒退**，制度须随势变革。这是中国本土生长出的、接近现代历史观的智慧。
3. **它与毛读通鉴形成"双焦镜头"**：王夫之是**哲学家读史**（求历史之理），毛泽东是**政治家读史**（求治国之用）。两者读同一部《通鉴》，读出的东西截然不同又相互照亮——**对照读，才能既懂历史的"理"，又懂读史的"用"**。

> 一句话：**《读通鉴论》让你看到——一个中国古代思想家，如何在没有现代社会科学工具的情况下，仅凭深思，就逼近了"历史发展规律"的认知。** 这是中国思维的骄傲，也是它局限的标本。

## 1. 关于本书：30 卷的史论巨著

- **作者**：王夫之（1619–1692），字而农，号姜斋，湖南衡阳人，晚年隐居石船山，学者称**船山先生**。与顾炎武、黄宗羲并称**明清之际三大思想家**。
- **成书**：始撰于**69岁（1687）**，逝世前（1691）完成。"贫无书籍纸笔，多假之故人门生"。
- **规模**：**30 卷约 60 万字**，按朝代分卷（秦1/汉4/东汉4/三国1/晋4/宋齐梁陈隋各1/唐8/五代3），卷末附**《叙论》四篇**（王夫之自己的方法论总结）。
- **性质**：不是独立史书，而是**读《通鉴》的笔记与议论**——每节针对《通鉴》某段史实发论。**不参照《通鉴》单读，会"丈二和尚摸不着头脑"**。
