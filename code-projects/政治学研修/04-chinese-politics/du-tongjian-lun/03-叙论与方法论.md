# 03 · 叙论：王夫之的史学方法论

> 本篇精读《读通鉴论·叙论二》——这是王夫之**自己总结的史学方法论**，是中国传统里最精炼的"如何论史"的纲领。它直接通向 [06 历史政治学方法论](../../06-methodology/)。

---

## 一、叙论四篇：王夫之的方法论自述

《读通鉴论》30卷之外，卷末附**《叙论》四篇**，是王夫之对自己"为何论史、如何论史"的总说明。其中**叙论二**最集中地阐述了他的**史学方法论**。

### 叙论二原文（维基文库）
> "天下有大公至正之是非，匹夫匹妇之与知，圣人莫能违也。然而君子之是非，终不与匹夫匹妇争鸣……**故编中于大美大恶、昭然耳目、前有定论者，皆略而不赘。推其所以然之繇，辨其不尽然之实，均于善而醇疵分，均于恶而轻重别，因其时，度其势，察其心，穷其效**，所繇与胡致堂诸子之有以异也。"

---

## 二、王夫之方法论的核心：六字真诀

把上面这段提炼，王夫之的论史方法是**六个动作**：

| 动作 | 含义 | 反对的毛病 |
|------|------|-----------|
| **推其所以然之繇** | 追究"为什么会这样"的根本原因 | 只陈述现象，不究因果 |
| **辨其不尽然之实** | 辨别"传言/定论"中不真实之处 | 盲从旧说、人云亦云 |
| **因其时** | 放回当时的时代情境 | 用后人的标准苛责古人 |
| **度其势** | 衡量当时的历史大势 | 忽视结构性约束 |
| **察其心** | 体察当事人的内心动机 | 只看行为不看意图 |
| **穷其效** | 追究最终的实际效果 | 只论动机不论后果 |

**这六字真诀的精髓**：
1. **不重复常识判断**："王莽曹操是大恶"——这是匹夫匹妇都知道的，史论者不必喋喋重复。**史论的价值，在于说出常人说不出的东西**。
2. **深挖因果**："推所以然"——要找到**别人没看到的原因**。
3. **历史主义**："因其时、度其势"——**把古人放回他自己的时代去理解**，不用今天的道德标准简单裁判。
4. **动机-效果并重**："察其心、穷其效"——既看意图，也看结果（呼应[卷一"天假其私行大公"](02-核心史观.md)）。

---

## 三、王夫之方法论的现代回响

令人惊叹的是，王夫之这六字真诀，竟与现代社会科学的几套方法**暗合**：

| 王夫之 | 现代对应 |
|--------|---------|
| 推其所以然之繇 | **因果机制分析**（causal mechanism） |
| 辨其不尽然之实 | **史料批判 / 事实核查**（source criticism） |
| 因其时、度其势 | **历史制度主义的"时间性""路径依赖"**（见 [06](../../06-methodology/)） |
| 察其心 | **行动者意图理解**（韦伯的 Verstehen） |
| 穷其效 | **结果评估 / 过程追踪**（process tracing） |

**一个判断**：王夫之在17世纪，仅凭深思，就**独立摸索出了一套接近现代历史社会科学的方法直觉**。这不是说他等于现代学者，而是说——**好的历史思维，古今相通**。中国人不必妄自菲薄，我们的思维传统里本就有这些种子。

## 四、王夫之 vs 其他史论家：方法论的高下

王夫之在叙论里特意点出自己与宋代史论家**胡致堂（胡寅）**等人的区别。胡寅作《读史管见》，是典型的"道德史论"——见到古人某事，立刻贴"善/恶"标签。王夫之认为这**太浅**：

- **胡寅一路**：王莽篡汉→恶。曹操挟天子→恶。**全是道德标签，匹夫匹妇都会说**。
- **王夫之一路**：王莽为何能篡？当时制度有何漏洞？他的政策有何效果？**深究因果、因时度势**。

> **这就是史论的层次差**：低层次的史论是"道德法官"（判善恶），高层次的史论是"历史解剖者"（究机理）。王夫之的伟大，在于他把史论从"道德评判"提升到"机制分析"。**这与[明史专题《万历十五年》](../books/黄仁宇-万历十五年.md)的结构史观、[毛读通鉴](../zizhi-tongjian/02-毛泽东对通鉴的总体评论详解.md)的"看制度不看个人"，是同一种方法论自觉**。

---

## 五、给学习者的启示：如何"像王夫之那样论史"

把六字真诀变成可操作的**论史纪律**（这也是 [06 方法论](../../06-methodology/) 要展开的）：

1. **先问"为什么"，再下判断**——遇到一段史事，先追究因果，别急着贴善恶标签。
2. **回到语境**——把古人放回他的时代（因其时、度其势），别用今天的标准苛责。
3. **动机与效果并察**——既看他想干什么（察其心），也看他干成了什么（穷其效）。
4. **不重复常识**——如果你的判断和"大家都知道"的一样，那你没贡献。**史论的价值在"说出新东西"**。
5. **批判地对待旧说**——"辨其不尽然之实"，对正史、定论都要存疑。
