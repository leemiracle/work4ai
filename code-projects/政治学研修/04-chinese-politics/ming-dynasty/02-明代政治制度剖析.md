# 02 · 明代政治制度剖析：八大制度的运行与得失

> 本篇是技术性最强的一篇。我们不再讲"故事"，而是**拆机器**——把明代政治机器的八个核心部件逐一拆开，看它怎么运转、为什么会坏。
>
> 核心方法：对每个制度问三个问题——**①它要解决什么问题？②它实际怎么运作？③它后来出了什么毛病？**

---

## 先看整机：明代权力流程图

在拆部件之前，先看整机怎么运转。明代国家机器的**信息—决策—执行**流程是：

```
        ┌──────────── 奏折（章奏）从全国涌入 ────────────┐
        │                                                 │
        ▼                                                 │
  ┌──────────┐    票拟(拟意见)    ┌──────────┐  批红(朱笔)  │
  │  内 阁   │ ───────────────→ │  皇 帝   │ ──────────→ │
  │ (大学士) │   草拟处理方案     │ (或怠政) │  或由司礼监  │
  └──────────┘                   └──────────┘   代行批红   │
        ▲                              │                   │
        │ 顾问/起草                     ▼                   │
        │                       ┌──────────┐               │
        │   厂卫监视             │ 司礼监   │ ← 宦官集团     │
        │   文武百官             │ (秉笔/掌印)│              │
        │                       └──────────┘               │
        │                              │                   │
        │                              ▼                   │
        │                       ┌──────────┐               │
        └────────────────────── │ 六 部    │ ──→ 地方执行 ──┘
                                │ (吏户礼兵刑工)│
                                │ + 都察院/通政司│
                                └──────────┘
```

**两个关键洞察**：
1. **皇帝是唯一的决策节点**，但他可以"外包"决策——外包给内阁（票拟）或司礼监（批红）。当皇帝怠政（万历），实际决策权就落到**内阁+司礼监**的"配合"上。
2. **厂卫不在流程图主线里**，它是**横向监视系统**——监视所有人（包括内阁和六部），直接向皇帝汇报。这是明代独有的"平行监督网"。

理解了整机，下面拆八个部件。

## 制度一 · 废丞相：两千年制度史的一次地震

### 要解决的问题
朱元璋要**消灭任何能分享皇权的职位**。丞相自秦以来就是"百官之首"，有独立权力基础（汉唐丞相/三省长官可封驳诏书）。朱元璋亲历元末权臣专擅，认定丞相是皇权的最大威胁。

### 怎么做的
洪武十三年（1380），借"胡惟庸案"（指控左丞相胡惟庸通蒙、通日、谋反），诛杀胡惟庸并**废除中书省和丞相制**，六部（吏户礼兵刑工）直接对皇帝负责。同时下诏**后世不许再设丞相**，"臣下有奏请设立丞相者，群臣即时劾奏，将犯人凌迟，全家处死"。

### 得
- 皇权再无制度性的分割者，皇帝独揽决策。
- 消除了"权臣篡位"的制度通道。

### 失（致命）
- **决策负担全压皇帝一人**：全国政务（奏折动辄每日数百件）全要皇帝批。朱元璋是工作狂尚能应付，但**子孙大多做不到**——于是必然出现决策真空。
- 真空被两个非正式机构填补：**内阁**（拟意见）和**司礼监**（代批红）。它们名义上是"秘书"，实际掌握了相权，却**没有丞相的合法性**——所以明代阁臣始终"名不正言不顺"，宦官却因代表皇权而能压过文官。
- **这才是明代宦官专权的制度总根源**：废了丞相，皇帝又管不过来，就只能用最亲近的宦官——宦官专权不是偶发的"坏人坏事"，而是废相制度的**必然产物**。

> **政治学洞察**：废丞相是一场**"消灭中介"的实验**——皇帝想直接统治，结果反而更依赖非正式中介（宦官），且这些中介更难控制。这是"去制度化"反噬的经典案例。

## 制度二 · 内阁与"票拟—批红"：没有名分的相权

### 制度起源
废相后政务堆积，朱元璋挑几个文人当"殿阁大学士"做顾问。永乐帝出征时常让太子（仁宗）监国，**内阁**逐渐成为常设顾问机构（因其在文渊阁办公得名）。仁宣之后，内阁获得**"票拟"**权——对各部院和地方奏折，拟定处理意见草案，呈皇帝定夺。

### 运作机制
- **票拟**：内阁大学士（首辅领衔）在奏折上附拟处理意见。这是"建议权"。
- **批红**：皇帝审阅票拟，用红笔批示同意/修改/驳回，奏折才算正式生效。这是"决定权"。
- **首辅**：内阁首席大学士（嘉靖以后地位凸显），被尊为"相"，但实际上他**只是皇帝的首席秘书**，权力完全来自皇帝的信任程度。

### 变异：当皇帝怠政时
- 万历近三十年不上朝，**批红权实际落入司礼监**（秉笔太监按内阁票拟代为朱批）。于是形成"内阁票拟—司礼监批红"的**双轨决策**。
- 首辅若能与司礼监勾结（如张居正联合冯保），就能"假皇权以行事"，权倾朝野；若不能，则被宦官掣肘。
- 这套机制**没有宪法保障**：首辅的权力随时可被皇帝一句话收回（张居正死后被清算）。这正是[《万历十五年》](../books/黄仁宇-万历十五年.md)讲的"势过盛招祸"。

### 得失
- **得**：在内阁制下，文官精英仍能参与决策，皇帝可借其智力。
- **失**：阁臣无独立合法性，必须依附皇权或宦官，导致**决策高度人格化、不稳定**；首辅与宦官的拉扯，构成明代中后期政治的主要张力。

> **政治学洞察**：内阁制是"废丞相"留下的**制度补丁**，但它从不被承认为正式的决策机关。这种"名实分离"（有名无权、有权无名）是明代政治混乱的根源——**一个拒绝给予中介合法性的系统，反而被中介（宦官）反向支配**。

## 制度三 · 厂卫：平行于法律的特务监视网

### 构成
明代的"厂卫"是**皇帝私设的特务司法系统**，独立于三法司（刑部、都察院、大理寺）之外：

| 机构 | 设立 | 掌管 | 职能 |
|------|------|------|------|
| **锦衣卫** | 洪武十五年（1382，由仪鸾司改制） | 武官（皇帝亲军） | 侍卫、侦缉、诏狱（皇帝直管的监狱）、廷杖 |
| **东厂** | 永乐十八年（1420） | 宦官 | 侦缉百官与民间，权力凌驾锦衣卫 |
| **西厂** | 成化十三年（1477） | 宦官（汪直） | 短设短废，权力更广 |
| **内行厂（内厂）** | 正德初（刘瑾） | 宦官 | 统辖东西厂与锦衣卫，刘瑾倒台即废 |

### 运作逻辑：皇帝的"耳目与爪牙"
厂卫的**本质功能**是绕开正规官僚系统，让皇帝能直接监视和控制所有人：
- **侦缉**：派"番子"（特务）混入民间、百官身边，刺探言行，**无需证据即可抓人**。
- **诏狱**：厂卫有自己的监狱和刑罚（酷刑骇人），不经三法司审判直接关押，被称为"人间地狱"。
- **廷杖**：在朝堂上当众杖打大臣（嘉靖大礼议一次打死十六人）——既是肉体刑罚，更是**人格羞辱**，摧毁士大夫的尊严与独立人格。

### 得失
- **得（对皇帝）**：皇权获得了独立于官僚系统的强制工具，能有效震慑百官。
- **失（对国家）**：
  - **法治破坏**：厂卫司法与正式司法并存且冲突，"法外之法"横行，冤狱遍地。
  - **恐怖政治**：人人自危，敢言者死，**扼杀了官僚系统的诚实反馈**——这正是周雪光"一统体制下信息失真"在明代的最极端形态。
  - **宦官坐大**：东/西/内厂由宦官掌管，给了宦官独立权力基础（掌握暴力机器），宦官之祸的制度根源在此。

> **政治学洞察**：厂卫是"绝对皇权"的**必然配套**——当皇帝要绕开一切中介直接统治，就必须有自己的特务系统。但特务系统一旦拥有暴力，就成了**新的、更难控制的中介**。这是"控制者反被控制"的辩证法。把厂卫和现代极权国家的秘密警察对照，能看到惊人的结构相似。

## 制度四 · 科举与八股：社会流动的通道与思想的笼子

### 明代科举的定型
科举制隋唐已立，但**明代把它推向极致标准化**，并定型为后世（含清朝）的模板：

- **三级考试**：乡试（省，中者为"举人"）→ 会试（京，中者为"贡士"）→ 殿试（皇帝亲考，定进士名次）。
- **八股文**：成化以后定型。文章须按固定结构（破题、承题、起讲、入手、起股、中股、后股、束股，后四股各有两股排比对偶，故称"八股"），**代圣贤立言**，只能依据《四书》《五经》及朱熹注。
- **功名与社会**：秀才→举人→进士是身份阶梯，进士可入仕做官。明代"非进士不入翰林，非翰林不入内阁"——**科举是入仕的唯一正途**。

### 得
- **社会流动**：理论上任何读书人（除"贱籍"）都可应考。明代有不少寒门进士（如张居正、海瑞），社会下层确有上升通道。
- **文化统合**：全国士子读同样的书、写同样的文，形成高度一致的文化精英集团，是"大一统"的人才基础。
- **文官供给**：为庞大的官僚系统提供源源不断的识字人才。

### 失（致命）
- **思想钳制**：八股只能"代圣贤立言"，不许发挥己见，**扼杀创造性思维**。明末顾炎武痛斥"八股之害等于焚书"。这正是黄仁宇讲的"道德化政治"的精神基础——士人只会用儒家话语思考，无力应对技术与经济问题。
- **脱离实际**：考试内容（经义、诗赋）与治国所需（财政、军事、水利、法律）完全脱节。**考上的进士可能连账都不会算**——这是明代"无法数目字管理"的人才学根源。
- **功利化**：读书只为做官，"书中自有黄金屋"，知识沦为敲门砖，士风日下。

> **政治学洞察**：科举是明代最成功也最危险的设计——它**用上升通道换取思想统一**。代价是：整个精英阶层丧失了解决真实问题的能力。当帝国面对全新的财政/军事/技术挑战时，满朝文武只会用"祖制""道德"应对——这正是晚明无解的死结之一。

## 制度五 · 卫所军制：从"寓兵于农"到有名无实

### 设计初衷
洪武元年（1368）确立卫所制：全国设**卫**（约5600人）、**所**（1120人），军户**世袭**。每军户给田耕种，"寓兵于农"，试图让军队**自给自足**——"吾养兵百万，不费百姓一粒米"。

### 崩坏过程
这套制度在明中期就全面败坏：
- **军户逃亡**：军户地位低、负担重（还要屯田自养），大量逃亡。明中期卫所"名存实亡"，在籍军士多为空额。
- **军官侵吞**：卫所军官把屯田当私产，役使军户为佃农，军队沦为军官的私人劳力。
- **战力崩塌**：土木堡之变（1449）暴露卫所军不堪一战。此后明代只能靠**募兵**（戚家军、辽东军）作战——但募兵要花钱，**财政压力剧增**。

### 得失
- **得（短期）**：开国时确以低成本维持了庞大军队。
- **失（长程）**：制度刚性导致"自给军队"破产后，没有替代方案，被迫转向募兵，而**财政制度又跟不上**——这是明代"军事—财政"螺旋崩溃的起点。

> **政治学洞察**：卫所制是"制度锁定"（lock-in）的典型——它把军队绑死在一种生产方式（军屯）上，当外部环境变化（货币化、商业化），军屯瓦解，整个军制随之崩溃，却没有制度更新的机制。**没有退出机制的制度，必然走向衰亡**。

## 制度六 · 一条鞭法：赋役制度的革命性简化

### 问题背景
明代中期赋役制度极其繁杂：田赋（夏税秋粮）+ 徭役（里甲、均徭、杂役），名目繁多，且**按人丁和土地分别征收**，催征成本极高，贪吏中饱，百姓苦不堪言。豪强还大量隐匿土地和丁口，税基流失。

### 改革内容
嘉靖年间庞尚鹏、欧阳铎等已在地方试点。万历九年（1581）张居正借清丈土地之机**全国推行一条鞭法**：
- **合并**：把田赋和各种徭役**合并为一项**。
- **按亩**：负担**主要按土地面积**（而非人丁）分摊。
- **征银**：一切**折算白银缴纳**，不再征实物和劳役。
- **官收官解**：由官府直接征收解运，废除里甲包收。

### 得
- **简化**：赋役从名目繁杂变为"一条"，征收成本大降。
- **公平**：负担转向土地，**减轻无地少地农民**，增加豪强税负（触动既得利益，故阻力巨大）。
- **货币化**：推动白银货币化，促进商品经济，是"数目字管理"的雏形。
- **增税基**：清丈查出大量隐田，国库充盈。

### 失与局限
- **白银依赖**：赋税全征银，使国家经济**绑定在白银流入上**（晚明美洲白银减产，直接引发通货紧缩与财政危机——这是晚明崩溃的隐秘经济动因之一）。
- **张居正死后未能彻底贯彻**，部分地区回潮。
- **未触及根本**：宗藩、军费等支出端问题未解，单靠税收改革无法救明。

> **政治学洞察**：一条鞭法是明代**最具"现代性"的制度创新**——它试图建立可量化、可核算的财政（正是黄仁宇说的"数目字管理"）。它的失败不是因为设计差，而是因为**制度环境（白银波动、官僚惰性、既得利益）不支持**。这说明：**好的制度移植，需要配套的制度生态，否则水土不服**。

## 制度七 · 宗藩制度：皇族的财政黑洞

### 设计
朱元璋封子孙为王（藩王），分布全国，"分封而不锡土，列爵而不临民，食禄而不治事"——吸取汉七国之乱、晋八王之乱教训，**只给爵禄不给实权实土**。初衷是"以藩屏皇室"。

### 失控
问题出在**繁衍速度**：朱元璋子孙经两百余年繁衍，到明末**数以十万计**（一说数十万）。所有宗室按爵位领"宗禄"，全由国家财政供养，且**不许做官、不许经商务农**（怕他们夺权）——成为纯消费者。
- 嘉靖年间，部分省份的**宗禄已占当地财政支出大半**，地方不堪重负。
- 这成了明代财政的**结构性死结**：支出端有一个无法削减的、指数级增长的窟窿，任何税收改革都填不满。

### 政治学洞察
宗藩是"祖制"最荒谬的遗产——**祖宗定下的规矩，把后代锁死**。朱元璋想"以藩屏皇室"，结果藩王成了帝国的吸血鬼。**制度的"刚性"在这里表现为一种自我毁灭：明知不可持续，却因"祖制不可改"而无法纠正**。这是"路径依赖"最悲剧的形态。

## 制度八 · 宦官二十四衙门：皇权的家奴机器

### 制度
宦官机构称"二十四衙门"（**十二监、四司、八局**），覆盖皇室生活的方方面面（饮食、衣物、马匹、兵器……）。核心是：
- **司礼监**：最权势者。设**掌印太监**（掌玉玺）、**秉笔太监**（代皇帝批红）、提督东厂太监。**掌握文书（批红）+ 暴力（东厂）+ 印信**，是宦官权力的中枢。
- **御马监**：掌腾骧四卫（亲军），有兵权。

### 运作逻辑
宦官之所以能专权，**根子在制度**：
- **批红外包**：皇帝（尤其怠政的）把批红交给司礼监秉笔太监，宦官就掌握了"代皇帝决策"的权力。
- **厂卫武力**：东厂由司礼监提督，宦官握有独立暴力。
- **皇帝信任**：宦官是皇帝从小的家奴，比外朝文官"更贴心"，皇帝天然更信任他们，用他们制衡文官。

### 得失
- **得（对皇帝）**：宦官是皇权最驯服的工具，能替皇帝做文官不愿做的事。
- **失**：宦官无文化根基（多为穷苦出身净身入宫）、无制度约束、有暴力机器——一旦掌权极易腐败暴虐（刘瑾、魏忠贤）。而且**宦官专权必然与文官集团对立**，加剧党争，撕裂朝政。

> **政治学洞察**：宦官不是"反常"，而是**废丞相+绝对皇权+皇帝怠政**这套制度的**必然产物**。皇帝需要中介，又不信任外朝文官，就只能用宦官。这是"制度决定行为"的最佳证明——把王振、刘瑾、魏忠贤换成别人，结果一样。**批判宦官个人是肤浅的，批判产生宦官专权的制度才是深刻的。**

---

## 收束：八大制度如何拼成一个"自我锁死"的系统

把这八个制度放在一起看，你会发现它们**相互咬合，形成一个无法自我纠偏的闭环**：

```
        废丞相（无中介） ──→ 皇帝管不过来 ──→ 重用宦官（司礼监批红）
              ↑                                          │
              │                                          ▼
        祖制不可改 ←── 宗藩财政黑洞 ←── 宦官与文官对立（党争）
              │                                          │
              ▼                                          ▼
        科举八股（思想僵化） ──→ 无力改革 ──→ 卫所崩坏/募兵要钱
              │                                          │
              └──────── 厂卫镇压敢言者 ←── 三饷加派 ←─ 财政崩溃
                                                    │
                                                    ▼
                                                 民变亡国
```

**这就是"结构史观"看到的东西**：不是某个皇帝昏庸、某个宦官坏，而是**八大制度彼此咬死，任何改革（如张居正）都只能治标，无法打破闭环**。明代亡于"制度锁死"——这是本专题 [03 篇](03-明代政治学专题.md) 要用政治学理论系统阐述的核心命题。
