# 毛泽东读《资治通鉴》专题 · 一个政治家如何借史为镜

> **04 中国政治 / 读史方法论专题**
> 把毛泽东读《资治通鉴》当作一个**政治学的样本**来研究：一个现代革命家如何把一部 300 万字的封建史学巨著，读成治国理政的"经验库"？他的批注与评论，揭示了"以史为鉴"的真实机制——以及它的边界与危险。

## 0. 为什么把这个专题放进政治学项目？

上一轮我们讨论"当官的为什么爱看明史"，提到了**毛泽东**——他是中国读史文化的最高典范。而《资治通鉴》是他**一生最钟情的书**。研究"毛读通鉴"，对学政治学的人有三重价值：

1. **它是"以史为鉴"最完整的实战案例**。理论家谈"历史经验"，往往是空对空；毛泽东是把历史经验**直接转化为政治实践**（决策、用人、军事、整风）的人。研究他，能看清"读史"究竟如何"明智"。
2. **它是中国传统政治智慧的枢纽**。毛通过《通鉴》接续了从司马光、王夫之到顾炎武的"治道"传统，又用马克思主义重新解释它。这是**传统与现代的一次关键焊接**——理解当代中国政治，绕不开这层底色。
3. **它是一面"有曲率的镜子"**。毛读史有非凡的洞察，也有明显的偏向（实用主义、阶级史观、为现实斗争服务）。**学会批判地看待一个伟大读者的读法**，本身就是最好的政治学训练。

> 一句话：**研究毛泽东怎么读《资治通鉴》，比直接读《资治通鉴》更能训练政治思维——因为前者同时展示了"历史的智慧"和"读史的陷阱"。**

## 1. 一个关键说明：什么是"毛泽东对通鉴的批注"？

严格意义上，"批注"分三层，本专题都涵盖：

| 类型 | 内容 | 主要出处 |
|------|------|---------|
| **书页批语** | 毛直接在《通鉴》书页上天头、行间的圈点批注 | 《毛泽东读文史古籍批语集》（中央文献研究室编，中央文献出版社 1993 年版），"读《资治通鉴》批语"在第 289 页起 |
| **衍生书批语** | 毛读《通鉴纪事本末》《读通鉴论》（王夫之）等衍生书的批语 | 同上批语集（"读《通鉴纪事本末》批语"第295页起、"读《读通鉴论》批语"等） |
| **谈话评论** | 毛在各种场合谈《通鉴》的言论 | 《毛泽东文集》、身边工作人员回忆录（如郭金荣《走进毛泽东的最后岁月》）、陈晋等学者的研究 |

> **诚实交代**：直接写在《通鉴》书页上、且保存下来公开出版的批语**数量并不多**（批语集近300条覆盖39部古籍，分到通鉴本身的不多）。毛泽东对通鉴的"思想批注"，**更多体现在谈话评论和读衍生书的批语里**。因此本专题采用**广义的"批注"概念**——凡毛对《通鉴》及其人物、思想的有据评论，均纳入"详解"，并**逐条标注出处**。这是严谨对待史料的基本要求。

## 3. 贯穿全专题的三条判断

在进入细节前，先给出三条**贯穿性判断**，帮助你带着问题读：

1. **毛读史的根本方法是"批判地继承"**。他反复强调《通鉴》"立场观点是封建统治阶级的"，要"批判地读"。这不是套话——他确实既吸收其中的政治智慧，又用唯物史观改造它。**读他的批注，要同时看到"继承"和"批判"两面。**

2. **毛读史的核心目的是"为现实斗争服务"**。他读《通鉴》不是为学术，而是为**治国、治军、治党**。这使他的批注高度实用化、当下化——好处是与现实紧密结合，**危险是容易"六经注我"，让历史屈从于现实需要**（详见 `04`）。

3. **毛读史的精华在"用人"与"治吏"**。通观他的批注，谈得最多、见解最深的，是**如何识人、用人、驾驭官僚**。这与本项目的[为官为人模块](../../05-statesmanship-ethics/)直接相通——毛的读史心得，本质上是一部"政治家的人才学与组织学"。
