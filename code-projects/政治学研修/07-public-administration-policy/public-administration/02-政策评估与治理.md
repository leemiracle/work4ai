# 02 · 政策评估与治理演变：从官僚到市场到价值

> 政策制定后，如何知道它"有效"？治理模式经历了怎样的演变？本篇讲政策周期、RCT 因果评估，以及新公共管理的得失与反思。

---

## 一、政策周期：一项政策的生命

政策不是"制定→执行"的直线，而是**循环**：
```
议程设置（问题进入视野）
   ↓
政策制定（设计方案）
   ↓
政策执行（落地）
   ↓
政策评估（检验效果）
   ↓
政策延续/调整/终结
   ↓ （反馈）回到议程
```

### 议程设置（最被忽视的关键）
- **金登的"多源流"框架**（John Kingdon）：问题流、政策流、政治流**三流汇合**时，"**政策之窗**"打开，议题才能上议程。
- **谁决定"讨论什么"**，往往比"如何讨论"更重要——这是政治权力的核心。

### 执行的难题
- 政策执行常因[街头官僚](01-官僚制.md)的裁量、资源不足、协调失败而**走样**。
- "**政策意图 vs 执行结果**"的鸿沟，是 PA 的核心研究议题。

## 二、政策评估：RCT 与因果推断

如何科学地知道"一项政策有没有用"？这就进入[06 方法论](../../06-methodology/00-README.md)的定量领域。

### 随机对照试验（RCT）
- **"政策评估的金标准"**：随机分组（实验组 vs 对照组），看政策干预是否真有效果。
- 代表：Esther Duflo 等在发展经济学的"**随机化革命**"（肯尼亚驱虫、印度教育补贴）——用 RCT 检验扶贫政策。

### 准实验方法（RCT 不可行时）
- **双重差分**（DID）：比较政策实施前后的"差异之差异"。
- **断点回归**（RDD）：利用政策门槛（如贫困线）两侧的对比。
- **工具变量**（IV）：找外生变量解决内生性。

### 警示（呼应[06](../../06-methodology/historical-method/05-研究设计指南.md)）
- **统计显著 ≠ 实质重要**：看效应量，不只看 p 值。
- **测量陷阱**："治理质量""民主度"怎么量化？指标本身有意识形态假设。
- **外部效度**：RCT 在肯尼亚有效，在中国未必——**情境很重要**。

## 三、新公共管理（NPM）：把企业逻辑引入政府

20 世纪 80–90 年代，全球掀起"**新公共管理**"（New Public Management, NPM）浪潮。

### 起源与主张
- 代表：奥斯本与盖布勒《**改革政府**》（*Reinventing Government*，1992）——"**政府应掌舵而非划桨**"（steer not row）。
- 主张：把**企业/市场逻辑**引入政府——
  - **绩效评估**（KPI/产出导向）
  - **竞争与外包**（公共服务私营化）
  - **分权/扁平化**
  - **顾客导向**（把公民当"顾客"）

### 英国撒切尔、美国克林顿的实践
- 撒切尔私有化英国国企；克林顿"重塑政府"运动。

### NPM 的成就
- 提高了部分效率，打破了官僚惰性。
- 引入了"结果导向"思维。

### NPM 的批评（2000s 反思）
1. **碎片化**：外包/分权导致政府**失去整体协调**（"谁来负责"模糊）。
2. **"顾客"隐喻的错误**：公民**不是顾客**——公民有政治权利/责任，顾客只是消费者。
3. **绩效主义反噬**：为达标而"**数据造假**""**形式主义**"——这正是[中国"指标崇拜"的问题](../../04-chinese-politics/00-README.md)。
4. **侵蚀公共价值**：只看效率，忽视了公平、公共善。

## 四、从 NPM 到公共价值治理

反思 NPM 后，出现新范式：

### 公共价值治理（Moore）
- 马克·摩尔《**创造公共价值**》（*Creating Public Value*，1995）：政府的目标不是"效率"，而是**创造"公共价值"**（公民真正珍视的东西）。
- 重新把"**价值**"带回治理——超越"市场 vs 官僚"的效率之争。

### 协同/网络治理
- 当代许多问题（气候、疫情、城市治理）**跨部门、跨层级、跨国**，单一政府搞不定。
- 需要**协同治理**（collaborative governance）：政府+企业+NGO+公民**网络化协作**。

### 对中国的启示
- 中国的"**治理现代化**"话语，某种程度上在吸收这些理念（多元参与、整体性治理）。
- 但需警惕：**"协同"在中国常被"行政化"吸收**（政府主导的"协同"），与西方"网络治理"的权力分布不同。

## 五、专题收束：治理的三个维度

把公共行政三篇合起来，治理有三个维度：
1. **能力**（官僚制能否有效执行）——韦伯。
2. **责任**（官僚/政策对谁负责）——铁三角/街头官僚的偏离。
3. **价值**（治理为了什么）——从效率到公共价值。

> **好的治理 = 强能力 + 清晰责任 + 公共价值**。三者失衡，就会出现"**能干但不为民**"（榨取性强国家）或"**为民但无能**"（失败国家）。
