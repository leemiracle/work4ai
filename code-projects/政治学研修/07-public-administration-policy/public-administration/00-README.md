> **07 公共行政与公共政策**

---

## 0. 公共行政研究什么？

公共行政（Public Administration, PA）研究**国家内部如何运作**：
- **官僚制**：政府机构怎么组织、运转？
- **政策过程**：一项政策从提出到落地到评估，经历什么？
- **治理模式**：从传统官僚 → 新公共管理 → 公共价值治理，如何演变？

> 一句话：**公共行政是政治学的"内部解剖学"——把国家机器打开看它的齿轮**。

## 2. 治理模式的演变（一条主线）

公共行政经历了**三代演变**：
```
传统公共行政（官僚制，20世纪初-70s）
   ↓ 怀疑官僚效率
新公共管理（NPM，市场化/企业化，80s-2000s）
   ↓ 反思NPM的碎片化
新公共治理 / 公共价值治理（2000s-）
```
- **传统**：韦伯式科层制，重规则、稳定性。
- **NPM**：把企业逻辑引入政府（绩效、外包、竞争）。
- **当代**：超越"市场 vs 官僚"二分，强调**协同、网络、公共价值**。
