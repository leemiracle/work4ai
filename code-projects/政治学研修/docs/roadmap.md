# 学习路线图 · 从入门到精进

> 本路线图把"政治学通论 / 中国政治 / 为官为人"三份地图整合成**统一的三阶段**。
> 每个阶段说明：学什么 / 为什么 / 产出什么 / 检验标准。
> 假设投入：每周 5-8 小时。可按个人节奏伸缩。

---

## 阶段总览

```
阶段一·奠基（3-4 月）        阶段二·深入（6-12 月）         阶段三·精进（长期）
搭骨架                       填血肉                        长骨骼与神经
─────────                   ─────────                    ─────────
通识教材 ×3                  各领域里程碑专著              方法论硬核训练
思想史脉络 ×2                政治理论原著选读              前沿期刊追踪
IR 入门 ×2                   中国政治经典                  专题深挖
中国制度入门 ×2              为官为人经典                  独立写作输出
为官为人筑基 ×4

产出：四大支柱骨架           产出：能用框架解释现实        产出：能做研究/写文章
检验：能画出概念地图         检验：能写读书笔记            检验：能提出原创问题
```

## 第一阶段 · 奠基：构建宏观框架（3-4 个月）

### 目标
用最通俗的语言，把政治学四大支柱的"骨架"搭起来，同时建立中国政治的基本事实感和为官为人的心性根基。

### 必读（按顺序）

#### 1. 政治学通论（约 6 周）
| 书 | 作用 | 提示 |
|----|------|------|
| 包刚升《政治学通识》 | 中文入门首选，逻辑清晰 | 通读，做章节笔记 |
| 海伍德《政治学》 | 西方经典教材，概念透彻 | 与包刚升对照读，互补 |
| 马工程《政治学概论》 | 国内主流话语体系 | 理解"官方语言"，建立对话基础 |

#### 2. 思想史脉络（约 4 周，与上同步）
| 书 | 作用 |
|----|------|
| 麦克里兰《西方政治思想史》 | 像听故事走完两千年思想史 |
| 萧公权《中国政治思想史》 或 刘泽华同类著作 | 回看中国自身的儒法道脉络 |
| 韦伯《政治作为一种志业》（短文） | 理解"国家=垄断合法暴力"+ 官僚制本质，2 小时可读完 |

#### 3. 国际关系入门（约 3 周）
| 书 | 作用 |
|----|------|
| 明斯特《国际关系精要》 | IR 公认入门佳作，结构清晰 |
| 小约瑟夫·奈《理解全球冲突与合作》 | 理论结合历史，可读性强 |

#### 4. 中国政治入门（约 4 周）
| 书 | 作用 |
|----|------|
| 景跃进、陈明明《当代中国政府与政治》 | 最好的中文教材，静态全貌 |
| 朱光磊《当代中国政府过程》 | 从静态机构→动态权力运行的关键转换 |
| 钱穆《中国历代政治得失》 | 一本小册子打通汉唐宋明清制度 |

#### 5. 为官为人筑基（贯穿全程，每天 30 分钟）
- 《大学》《中庸》：熟读成诵，三纲八目是儒家总纲
- 《论语》：杨伯峻《论语译注》，每天一两章，反躬自问
- 《孟子》：养浩然之气
- 《道德经》：陈鼓应注译，体会"上善若水""知止不殆"

### 阶段一产出
- 一张"政治学概念地图"（手绘或软件画）
- 每本书一份章节摘要（≤500 字）
- 能用自己的话讲清：什么是国家、民主、权威、合法性

### 检验
- 能否向一个外行讲清"政治学四大支柱各自研究什么"？
- 能否说出 5 位西方政治思想家 + 3 位中国政治思想家的核心主张？
- 能否描述当代中国党政体制的基本结构？

## 第二阶段 · 深入：精读里程碑之作（6-12 个月）

### 目标
骨架搭好后，通过精读经典专著"填充血肉"，体会理论如何被用来解释重大问题。开始读政治理论原著。

### A. 比较政治学（约 8 周）
| 书 | 核心论点 | 批判点 |
|----|---------|--------|
| 亨廷顿《变化社会中的政治秩序》 | "现代性带来稳定，现代化引起动荡" | 忽视自由价值；秩序优先于正义？ |
| 阿西莫格鲁/罗宾逊《国家为什么会失败》 | 包容性 vs 汲取性制度决定兴衰 | 历史过度简化；因果方向争议 |
| 巴林顿·摩尔《民主与专制的社会起源》 | "没有土地贵族就没有民主" | 案例选择偏差；阶级还原论 |

### B. 政治理论原著（约 12 周，选 4-6 本精读）
不必一本本死磕。先看**耶鲁公开课《政治哲学导论》**（Steven Smith）作导览，再聚焦：

| 原著 | 核心问题 |
|------|---------|
| 柏拉图《理想国》 | 什么是正义？谁应当统治？ |
| 马基雅维利《君主论》 | 政治与道德的关系？ |
| 霍布斯《利维坦》 | 为什么需要国家？ |
| 洛克《政府论（下篇）》 | 政府的正当性从何而来？ |
| 卢梭《社会契约论》 | 自由与权威如何兼容？ |
| 托克维尔《论美国的民主》 | 民主的利与弊？ |
| 密尔《论自由》 | 自由的边界在哪？ |
| 罗尔斯《正义论》 | 什么是公平的正义？ |

### C. 国际关系经典（约 6 周）
| 书 | 流派 |
|----|------|
| 摩根索《国家间政治》 | 古典现实主义圣经 |
| 华尔兹《国际政治理论》 | 新现实主义开山 |
| 基欧汉《霸权之后》 | 新自由制度主义 |
| 温特《国际政治的社会理论》 | 建构主义核心 |

### D. 中国政治经典（约 8 周）
| 书 | 视角 |
|----|------|
| 李侃如《治理中国：从革命到改革》 | 海外中国研究扛鼎，对照国内教材读 |
| 朱光磊《当代中国政府过程》 | 静态机构→动态权力运行（若阶段一未读，此处必读） |
| 周雪光《中国国家治理的制度逻辑》 | "一统体制与有效治理"基本矛盾 + 基层"变通" |
| 兰小欢《置身事内》 | 经济发展中的政府角色，通俗深刻 |
| 傅高义《邓小平时代》 | 改革开放政治逻辑的全景式巨著 |
| 孔飞力《叫魂：1768 年中国妖术大恐慌》 | 国家权力与基层社会互动的神作；信息扭曲机制 |
| 邓正来《国家与社会》 | "国家—社会"框架引入中国研究 |
| 萧公权《中国政治思想史》 | 思想根源回溯 |

### E. 为官为人经典（贯穿，约 8 周）
| 书 | 重点 |
|----|------|
| 《曾国藩家书/日记》 | 屡败屡战、和光同尘、勤俭谦；"耐烦"二字 |
| 张宏杰《曾国藩传》 | 资质平庸者凭自省成就立德立功立言 |
| 王夫之《读通鉴论》 | 大儒点评千年治乱，培养历史纵深 |
| 《韩非子》选读 | 法术势；理解权力底层逻辑（防人之心非害人之心） |
| 《万历十五年》黄仁宇 | 海瑞/张居正/申时行三种命运——儒/法/和的三维案例 |
| 《沧浪之水》阎真 | 知识分子入体制的蜕变与灵魂挣扎 |
| 《菜根谭》洪应明 | 处世进退格言，案头常置 |
| 《大明王朝1566》 | 高浓度政治智慧与权力博弈沙盘 |
| 德鲁克《卓有成效的管理者》 | 现代管理：时间、贡献、用人所长 |
| 圣吉《第五项修炼》 | 系统思考，避免线性因果浅见 |

### F. 公共行政与公共政策（约 4 周，对应模块 07）
| 书 | 重点 |
|----|------|
| 韦伯《政治作为一种志业》 | 国家垄断合法暴力 + 官僚制本质（短文，若阶段一未读此处必读） |
| 奥斯特罗姆《公共事物的治理之道》 | 多中心治理；公地悲剧的第三条路（诺奖） |
| 金登《议程、备选方案与公共政策》 | 多源流框架；政策如何进入议程 |

### 阶段二产出
- 每本精读书一份**五层穿透笔记**（历史→概念→文本→案例→批判）
- 能用某个理论框架解释一个现实事件（如"用亨廷顿解释某国动荡"）
- 形成"内外视角对照"的习惯

### 检验
- 能否就一个议题（如"为什么某些国家民主化失败"）写出 2000 字逻辑清晰的小论文？
- 能否识别一本书的"价值预设"（它在为谁说话）？

## 第三阶段 · 精进：方法论与前沿（长期）

### 目标
从"学习者"转向"研究者/深度实践者"。掌握证明观点的工具，进入学术前沿，形成独立判断。

### A. 方法论硬核训练（二选一深入，或两者兼顾）

#### 定量方向
1. 基础统计学（任意一本入门教材）
2. 因果推断核心：
   - 安格里斯特/皮施克《基本无害的计量经济学》
   - 《精通计量》
3. 工具：学 R 或 Stata，用真实数据跑回归
4. 进阶：实验设计、DID、RDD、IV

#### 定性方向
1. KKV《社会科学中的研究设计》——建立科学思维
2. 《过程追踪方法》
3. 罗伯特·殷《案例研究：设计与方法》
4. 斯科特《国家的视角》——比较历史分析典范

#### 计算政治学方向（有编程/AI 基础者的发力点）
1. 文本挖掘：Python spaCy / R quanteda
2. 主题模型：LDA / BERTopic（分析政府报告、议会辩论的话语演变）
3. 网络分析：networkx / Gephi（政策网络、国际关系网络）
4. LLM 应用：政治文本自动标注、政策模拟、政治 Agent
5. 数据源：GDELT、中国政府工作报告语料、Comparative Agendas Project

### B. 追踪学术前沿
| 类型 | 期刊/来源 |
|------|----------|
| 顶级英文 | *American Political Science Review*、*American Journal of Political Science*、*World Politics*、*International Organization* |
| 核心中文 | 《政治学研究》《世界经济与政治》《公共管理学报》《社会学研究》《开放时代》 |
| 海外中国研究 | *The China Quarterly*、*Journal of Contemporary China* |
| 智库 | 布鲁金斯学会、卡内基国际和平基金会、中国发展研究基金会、北大国发院 |

### C. 专题深挖（选 1-2 个聚焦）
- **央地关系与官员行为**：周黎安《转型中的地方政府》（晋升锦标赛）
- **政策过程**："碎片化威权主义"模型；环境/教育/科技政策
- **基层治理**：华中学派（贺雪峰等）田野研究；吴毅《小镇喧嚣》；乡村振兴
- **中国与世界**：马凯硕《中国的选择》、米尔斯海默《大幻想》
- **公共行政与政策评估**：韦伯官僚制 + 奥斯特罗姆多中心治理；用因果推断评估政策（RCT/DID）；数字治理专题
- **为官为人专题**：官箴书（《官箴》《牧鉴》）；反腐纪实（《追问》）；《公务员法》《监察法》

### D. 为官为人·践行层（终身）
- **官箴研读**：吕本中《官箴》"清、慎、勤"三字诀；《州县提纲》《作邑自箴》
- **失败案例**：《史记·酷吏列传》《佞幸列传》；反腐警示录
- **法律纪律**：《公务员法》《监察法》《纪律处分条例》——知边界
- **榜样传记**：《周恩来传》；《王阳明大传》（知行合一、事上磨炼）
- **写作复盘**：工作日志 + 定期反思（曾国藩修炼法宝）
- **交游寻师**："友直、友谅、友多闻"

### 阶段三产出
- 一篇符合学术规范的研究综述或小论文
- 一个持续追踪的专题文献库
- 一套自己的判断框架（面对新闻事件能快速定位：这属于哪个议题？哪些理论适用？证据如何？）

## 跨阶段原则（始终遵守）

1. **一主一辅，交替阅读**：一本精读 + 一本完全不同领域泛读，调节思维。
2. **不动笔墨不读书**：书页批注 + 章节心得。
3. **情景代入**：读史到关键决策处，合书自问"如果是我会怎么选"，再看历史人物的抉择与后果。
4. **以写促思**：定期把零散思考写成结构清晰的文章。写作是让思想走向深刻的最可靠路径。
5. **内外对照**：永远把国内话语与海外研究并置，训练识别价值预设的能力。

---

> 政治学的学习不是为了找到一个简单的答案，而是为了培养一种**复杂思考的能力**——在面对纷繁复杂的现实时，既能心怀理解，又保持深刻。
