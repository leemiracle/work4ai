## 二、怎么读？精读 vs 速读

| 类型 | 读法 | 占比 |
|------|------|------|
| 教材/通识（包刚升、海伍德） | **速读**：通读 + 章节摘要，搭框架 | 40% |
| 经典原著/里程碑专著 | **精读**：五层穿透笔记，磨思维 | 60% |

**铁律：精读 20 本 > 泛读 100 本。** 不要把教材当圣经精读——教材是地图，经典才是风景。

## 三、怎么记？五层穿透笔记

精读每本书，用 [`book-note-template.md`](book-note-template.md) 做笔记：
1. 历史脉络（作者在回应什么？）
2. 核心概念（抓住关键术语）
3. 文本精读（论证骨架 + 最精彩/最薄弱）
4. 案例应用（能解释什么？边界在哪？）
5. 批判反思（价值预设 + 谁反对 + 我信几分）

**已有 4 篇示范笔记可对照**：
- [《君主论》](../01-political-theory/books/马基雅维利-君主论.md)（西方哲学读法）
- [《置身事内》](../04-chinese-politics/books/兰小欢-置身事内.md)（中国经验读法）
- [《韩非子》](../05-statesmanship-ethics/books/韩非子-二柄八经.md)（法家扬弃读法）
- [《万历十五年》](../04-chinese-politics/books/黄仁宇-万历十五年.md)（结构史读法）

## 四、怎么用代码？

三套可运行代码（全部 bash 验证跑通），**跑一遍胜过读十页教材**：

```bash
# 因果推断（OLS/DID/RDD/IV，看方法如何恢复真实效应）
python3 06-methodology/code/01-causal-inference.py

# 计算政治学（TF-IDF/LDA/网络分析）
python3 06-methodology/code/02-computational-politics.py

# 政策评估（RCT/异质性/平行趋势/DID）
python3 07-public-administration-policy/code/03-policy-evaluation.py
```

每套代码都设定"真实因果效应"，让你直观看到**方法能否恢复它**——这是理解方法论最快的方式。

## 六、一条建议

**不要试图"读完整个项目"**——那是 4.6 万字 + 代码，会让人望而生畏。

正确做法：
1. 先读本指南 + README，找到入口
2. 选 1-2 本核心书，开始读
3. 读到经典时，用五层笔记法（对照示范）
4. 遇到不懂的概念，查对应模块的深度导读
5. 想动手时，跑代码

**学习是马拉松，不是冲刺。每月精读 1 本 + 做笔记，一年就是 12 本——超过 90% 的人。**

---

> 政治学的学习不是为了找到答案，而是为了**学会提出正确的问题，并对任何简单化解释保持警惕**。本项目是你路上的同伴，不是终点。
