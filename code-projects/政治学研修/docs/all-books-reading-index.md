> 配套 [全栈精读法](all-methods-reading.md)（九层说明）与 [`reading-list.md`](reading-list.md)（完整书单）。

> **怎么用**：想读某本书时，先查它的卡片（核心论点+建议层），按建议挑 2-3 层深化即可。
> L1/L9 所有书必做；L2-L8 按建议挑。

## 第一部分 · 核心必读 22 本（详细全栈卡片）

### 1. 《政治学通识》包刚升 · 01通识 · ⭐
- **核心论点**：政治学研究权力、权威、制度的运作
- **关键概念**：国家、权力、合法性、意识形态、政体
- **全栈重点**：L1（速读搭框架）+ L5（学科地图）
- **一句话**：中文入门首选，1 个月速读搭骨架
- **难度**：★

### 2. 《政治学》海伍德 · 01通识 · ⭐
- **核心论点**：西方政治学概念的系统梳理
- **关键概念**：民主、自由、权威、意识形态谱系
- **全栈重点**：L1（速读）+ L5（与包刚升对照）
- **一句话**：全球最经典教材，与包刚升互补
- **难度**：★

### 3. 《中国历代政治得失》钱穆 · 04中国 · ⭐
- **核心论点**：汉唐宋明清制度的演变逻辑（皇权膨胀、相权衰落）
- **关键概念**：皇权相权、中央集权、科举、兵役
- **全栈重点**：L1（精读）+ L6（与西方政体比较）+ L7（历史惯性对当代的启发）
- **一句话**：薄薄一本打通五朝，历史纵深必备
- **难度**：★★

### 4. 《乡土中国》费孝通 · 04中国 · ⭐
- **核心论点**：中国社会的"差序格局"——以自我为中心的关系网络
- **关键概念**：差序格局、礼俗社会、熟人社会、血缘地缘
- **全栈重点**：L1（精读）+ L6（与西方"团体格局"对比）+ L7（理解当代中国人行为）
- **一句话**：理解中国人"人情面子"的底层逻辑
- **难度**：★

### 5. 《当代中国政府与政治》景跃进 · 04中国 · ⭐
- **核心论点**：中国党政体制的全貌与运作
- **关键概念**：党的领导、人大、政府、政协、央地关系
- **全栈重点**：L1（速读查参考）+ L5（制度框架）
- **一句话**：最好的中文教材，搞清"基本事实"
- **难度**：★★

### 6. 《置身事内》兰小欢 · 04中国 · ⭐（[有笔记](../04-chinese-politics/books/兰小欢-置身事内.md)）
- **核心论点**：中国经济奇迹的密码在"地方政府公司化"（土地财政+城投+晋升锦标赛）
- **关键概念**：分税制、土地财政、城投、晋升锦标赛、产业引导
- **全栈重点**：L1（精读）+ L4（机制能否因果检验？）+ L7（解释当下房地产调整）
- **一句话**：通俗深刻，理解中国政府经济行为的最佳入门
- **难度**：★★

### 7. 《变化社会中的政治秩序》亨廷顿 · 02比较 · ⭐
- **核心论点**："现代性带来稳定，现代化引起动荡"
- **关键概念**：政治制度化、政治参与、政治衰退、政治秩序
- **全栈重点**：L1 + **L4（核心论断能否实证？能，且被部分证实）** + L7（解释阿拉伯之春/转型动荡）+ L8（被批"为威权辩护"）
- **一句话**：比较政治奠基之作，秩序与发展的张力
- **难度**：★★★

### 8. 《君主论》马基雅维利 · 01理论 · ⭐（[基础笔记](../01-political-theory/books/马基雅维利-君主论.md) + [全栈精读](../01-political-theory/books/君主论-全栈精读.md)）
- **核心论点**：政治应基于"实效"而非道德；virtù 对抗 fortuna
- **关键概念**：virtù、fortuna、necessità、verità effettuale、狮与狐
- **全栈重点**：**全部九层（已有完整示范）**
- **一句话**：政治学的"第一书"，教你看清权力的真实逻辑
- **难度**：★★

### 9. 《韩非子》（二柄/八经）· 05为官 · ⭐（[有笔记](../05-statesmanship-ethics/books/韩非子-二柄八经.md)）
- **核心论点**：法术势三位一体；循名责实；二柄（赏罚）
- **关键概念**：法、术、势、二柄、循名责实、潜御、上君尽人之智
- **全栈重点**：L1 + **L6（与《君主论》跨文化对话）** + L7（现代绩效管理=循名责实）+ L8（扬弃：取精华弃糟粕）
- **一句话**：绩效管理祖师爷 + 办公室政治病理学家
- **难度**：★★★

### 10. 《当代中国政府过程》朱光磊 · 04中国 · ⭐
- **核心论点**：从静态机构研究转向动态权力运行过程
- **关键概念**：政府过程、决策机制、央地互动、政策执行
- **全栈重点**：L1 + L5（方法论升级：静态→动态）
- **一句话**：视角转换的关键，看权力"怎么动"
- **难度**：★★

### 11. 《中国国家治理的制度逻辑》周雪光 · 04中国 · ⭐
- **核心论点**："一统体制与有效治理"的基本矛盾
- **关键概念**：一统体制、有效治理、运动式治理、变通、共谋
- **全栈重点**：L1 + **L4（委托代理模型能否检验？）** + L7（解释央地博弈）+ L6（与韦伯官僚制对照）
- **一句话**：最有解释力的中国政治社会学，机制深挖
- **难度**：★★★

### 12. 《国家为什么会失败》阿西莫格鲁 · 02比较 · ⭐
- **核心论点**：包容性制度带来繁荣，汲取性制度导致失败
- **关键概念**：包容性制度、汲取性制度、关键节点、路径依赖
- **全栈重点**：L1 + **L4（制度→繁荣的因果方向争议）** + L8（历史简化/案例偏差的批评）+ L5（与福山/摩尔比较）
- **一句话**：流行框架，宏大但简化，需批判性读
- **难度**：★★

### 13. 《万历十五年》黄仁宇 · 04中国 · ⭐（[有笔记](../04-chinese-politics/books/黄仁宇-万历十五年.md)）
- **核心论点**：1587 年看似平淡，实为帝国衰亡的转折；制度僵化让所有人都失败
- **关键概念**：大历史观、数目字管理、道德化政治、文官集团的阴阳
- **全栈重点**：L1 + **L3（六个人物困境的论证解剖）** + L7（"道德治国"的当代警示）+ L8（决定论/西方中心的批评）
- **一句话**：结构史典范，看制度而非个人道德
- **难度**：★★

### 14. 《叫魂》孔飞力 · 04中国 · ⭐
- **核心论点**：1768 年妖术恐慌揭示专制皇权如何透过官僚体系运作 + 信息扭曲
- **关键概念**：官僚君主制、信息流、权力穿透、社会恐慌
- **全栈重点**：L1 + **L3（微观史如何揭示宏观权力的论证）** + L7（信息扭曲的当代对应：舆情/瞒报）
- **一句话**：一部微观史揭示宏观权力运作的神作
- **难度**：★★★

### 15. 《论自由》密尔 · 01理论 · ⭐
- **核心论点**：自由的边界是"伤害原则"——只有防止伤害他人时才可干涉
- **关键概念**：伤害原则、多数暴政、个性、思想自由
- **全栈重点**：L1 + **L3（伤害原则的论证解剖）** + L7（数字时代的言论自由边界）+ L8（社群主义批评）
- **一句话**：自由主义经典，短小精悍
- **难度**：★★

### 16. 《政治作为一种志业》韦伯 · 01理论/07 · ⭐
- **核心论点**：国家=垄断合法暴力的实体；信念伦理 vs 责任伦理
- **关键概念**：合法暴力垄断、信念伦理、责任伦理、官僚制、魅力型权威
- **全栈重点**：L1（短文，2小时）+ **L3（国家定义的论证）** + L7（责任伦理对当代从政者的意义）
- **一句话**：理解国家本质 + 政治伦理的必读短文
- **难度**：★★

### 17. 《正义论》罗尔斯 · 01理论 · ⭐
- **核心论点**：在"无知之幕"后，理性人会选两个正义原则（自由+差异原则）
- **关键概念**：原初状态、无知之幕、差异原则、反思平衡、公平的正义
- **全栈重点**：L1 + **L3（思想实验的论证解剖）** + **L5（之后所有政治哲学都是对他继承/反驳）** + L8（诺齐克/桑德尔/女性主义的多方批评）
- **一句话**：20 世纪最重要的政治哲学著作，难但必读
- **难度**：★★★★

### 18. 《国际政治理论》华尔兹 · 03IR · ⭐
- **核心论点**：国际系统的结构（无政府+能力分布）决定国家行为
- **关键概念**：结构、无政府状态、能力分布、两极稳定、层次谬误
- **全栈重点**：L1 + **L3（结构论证的极简之美）** + L5（现实主义 vs 自由主义 vs 建构主义）+ L6（与修昔底德/韩非的"势"对照）
- **一句话**：新现实主义开山，理论建构的典范
- **难度**：★★★

### 19. 《曾国藩传》张宏杰 · 05为官 · ⭐
- **核心论点**：资质平庸者凭自省、韧劲、三维平衡成就立德立功立言
- **关键概念**：耐烦、结硬寨打呆仗、功成身退、自省日记
- **全栈重点**：L1 + **L7（三维模型在当代的应用）** + L6（与王阳明"知行合一"对照）
- **一句话**：为官为人三维平衡的终极案例
- **难度**：★

### 20. 《基本无害的计量经济学》安格里斯特 · 06方法 · ⭐
- **核心论点**：因果推断的核心是用自然实验构造可信的反事实
- **关键概念**：反事实、IV、DID、RDD、LATE、依从性
- **全栈重点**：L1 + **L4（全书就是因果检验方法）** + 计算（配[代码](../06-methodology/code/01-causal-inference.py)跑一遍）

### 21. 《美国反对美国》王沪宁 · 02比较 · ⭐
- **核心论点**：以中国学者的眼光观察美国社会的矛盾与张力
- **关键概念**：美国社会的内在张力、个体主义、制度悖论
- **全栈重点**：L1 + **L6（中美对照）** + L7（1988 年观察对今天的预言力）
- **一句话**：中国学者写比较政治的标杆，至今被引用

### 22. 《政治的人生》王沪宁 · 05为官 · ⭐
- **核心论点**：一个青年学者对政治、学术、人生的日常思考
- **关键概念**：学术修炼、经世致用、知识分子的选择

## 使用建议

1. **先读核心 22 本**（第一部分），每本按"全栈重点"挑 2-3 层深化
2. **按兴趣扩展**时查第二部分，看建议层
3. **已有笔记的书**（5 篇）直接读笔记，再决定是否做全栈深化
4. **每读完一本**，做 Layer 9（个人综合）——这是归宿

> 178 本书，每本都有了自己的"全栈精读导航"。**现在，你真正可以开始读"全部的书"了**——不是盲目地读，而是带着方法、带着地图、带着九种眼光去读。
