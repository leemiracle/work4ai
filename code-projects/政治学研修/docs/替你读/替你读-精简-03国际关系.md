# 替你读·速览 · 03 国际关系

> 03 模块已有 16 篇单独笔记 + 核心替你读（华尔兹）。本文件是**速览补充**——每本 2-3 行核心。

| 书 | 替你读核心 |
|----|-----------|
| 摩根索《国家间政治》 | 现实主义圣经——"国家以权力定义的利益行动"；看国际新闻先问"这影响权力分布" |
| 基欧汉《霸权之后》 | 新自由制度主义——"制度能让合作成为可能"；现实主义的解药 |
| 温特《国际政治的社会理论》 | 建构主义——"无政府是国家造就的"；观念建构利益，利益建构行为 |
| 艾利森《注定一战？》 | 修昔底德陷阱——"16 次案例 12 次战争"；不注定但风险极高 |
| 奈《理解全球冲突与合作》 | IR 入门首选——理论+历史融合；"软实力"概念 |
| 明斯特《国际关系精要》 | 结构最清晰的教材——与奈互补（骨架+血肉） |
| 基欧汉/奈《权力与相互依赖》 | 复合相互依赖——"军事不是唯一工具"；全球化的理论预言 |
| 米尔斯海默《大国政治的悲剧》 | 进攻性现实主义——"大国必追求权力最大化"；最冷峻 |
| 马凯硕《中国的选择》 | 亚洲视角——"美国没有战略，中国有"；温和现实主义 |
| 米尔斯海默《大幻想》 | 对"自由主义霸权"的清算——"民族主义比自由主义更强" |
| 基辛格《大外交》 | 400 年外交史——"和平是均势的，不是自然的" |
| 奈《软实力》 | "吸引力也是权力"——文化/价值观/政策合法性 |
| 卡赞斯坦《国家安全的文化》 | 建构主义安全研究——"威胁被身份和文化建构" |
| 秦亚青《国际关系理论》 | 中国学派——"关系本位"替代"理性个体" |
| 王沪宁《国家主权》 | 中国学者论主权——"主权有核心、有弹性" |
