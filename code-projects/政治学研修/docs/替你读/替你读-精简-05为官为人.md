## 四书合讲（大学/中庸/论语/孟子）

**核心论点**：儒家内圣外王的总纲。**《大学》**三纲八目（明明德/亲民/止于至善；格物→致知→诚意→正心→修身→齐家→治国→平天下）是**修炼的路线图**。**《论语》**讲"仁"与"君子"——半部治天下。**《孟子》**养浩然之气——"富贵不能淫，贫贱不能移，威武不能屈"。**《中庸》**讲"中道"——不偏不倚。

**关键概念**：仁；义；礼；智；信；修身齐家治国平天下；中道。

**一句话启发**：**四书是中国人的"精神操作系统"**——你的价值观、处世方式，很多根源在这里。每天读一两章，结合生活经验反躬自问。

## 道德经

**核心论点**："**上善若水**"——最强大的力量是柔的。知止不殆（知道什么时候停）；功成弗居（成功了不独占）；无为而治（不妄为）。

**一句话启发**：**道家提供"进退之智"**——在最刚的儒家和最冷的法家之间，道家提供温度和弹性。"柔弱胜刚强"是最深的管理智慧。

## 近思录（朱熹/吕祖谦）

**核心论点**：宋明理学的入门——理/气/心/性的系统讨论。

**一句话启发**：理学是儒家的哲学化升级——想深入理解"天理/人欲"的辩论，从这本开始。

## 传习录（王阳明）

**核心论点**："**知行合一**"——知而不行只是未知。"**致良知**"——每个人心里都有判断是非的能力。"**在事上磨**"——修炼不离开实践。

**一句话启发**：**阳明心学是"行动哲学"——读了做不到，等于没读**。唯一的修炼是在真实处境中检验所学。

## 曾国藩家书/日记

**核心论点**：终身不辍的自省记录——"耐烦"二字为为官第一要义。

**一句话启发**：**曾国藩的修炼不是"天才"，是"日常"——日记自省+勤勉+耐烦**。

## 读通鉴论（王夫之）

**核心论点**：大儒点评千年治乱——分析制度得失/人物成败的深邃眼光。

**一句话启发**：**"以史为鉴"的最高范本——读它培养历史纵深感和判断力**。

## 资治通鉴（司马光）

**核心论点**：给帝王看的"治国案例集"——1362 年的历史，聚焦"治乱兴衰"。

**一句话启发**：**中国的"政治教科书"——读关键段落（如楚汉/三国/安史之乱），看权力如何运作**。

## 毛泽东选集

**核心论点**：矛盾论/实践论/调查研究方法——理解中国现实政治的钥匙。

**一句话启发**：**"没有调查就没有发言权"——毛的方法论至今有效**。矛盾论教你抓主要矛盾。

## 现代管理学合讲

| 书 | 替你读核心 |
|----|-----------|
| 德鲁克《卓有成效的管理者》 | "管理者的第一职责是管好自己"——时间/贡献/用人所长/要事优先 |
| 圣吉《第五项修炼》 | 系统思考——避免线性因果的浅见；学习型组织 |
| 海菲兹《没有容易的答案》 | 适应性领导力——区分技术性问题（有答案）vs 适应性问题（需改变价值观） |

| 科特《领导变革》 | 八步法——如何推动组织变革（造势的现代版） |
| 罗伯特议事规则 | 开会的方法——程序实现民主与效率 |

**一句话启发**：**这些现代管理学经典，是"法家为术"的现代转化**——阳光的、建设性的管理方法，与韩非的"阴谋潜御"形成对比。
