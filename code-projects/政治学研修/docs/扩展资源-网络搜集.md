## 三、计算政治学最新工具（2025 前沿）

> 以下工具/论文均为 2025 最新，特别适合有 AI/编程背景的你。

### LLM + 政治网络分析（最前沿）

**GPT-4 提取政治网络**（PLOS One 2025-01）
- 论文："A frustratingly easy way of extracting political networks from text"
- 方法：用 GPT-4 一步完成**实体识别 + 关系提取 + 实体链接 + 情感分析**
- 验证：用智利国会 1009 篇新闻，验证 GPT-4 提取的关系与议员投票一致性高度吻合
- **启示**：LLM 让政治网络分析变得"出奇地容易"——这是计算政治学的范式转移

### 开源工具

| 工具 | GitHub | 功能 |
|------|--------|------|
| **GOIES** | [tanu-1403/GOIES](https://github.com/tanu-1403/GOIES) | 地缘政治情报平台：文本→知识图谱→可视化→政策模拟→危机预测。**本地运行**（Ollama），隐私安全 |
| **Political Influence Network MCP** | [apifyforge/...](https://github.com/apifyforge/political-influence-network-mcp) | 美国政治影响力分析：FEC 献金+国会股票交易+法案追踪→PageRank 影响力评分+暗钱追踪 |
| **discourse-networks** | [PyPI](https://pypi.org/project/discourse-networks/) | 从社交媒体构建"话语网络"——不靠关注/转发，靠**共同叙事参与**连接用户。`pip install discourse-networks` |

### 数据集

| 数据集 | 描述 |
|--------|------|
| **POLITISKY24** | 2024 美国大选 Bluesky 立场检测数据集（16044 用户-目标对），含 LLM 标注管线（81% 准确率） |
| **Project 2025 文本数据集** | [judgelord/2025](https://github.com/judgelord/2025)——Project 2025 全文+机构标注，适合文本分析练习 |
