>
> **什么是政治？** 拉斯韦尔（Harold Lasswell）的经典定义：**"政治就是决定谁得到什么、何时得到、如何得到。"**（*Politics: Who Gets What, When, How*）记住这句话，它是一切政治分析的起点。

## 00.5 · 王沪宁著作（中国政治学奠基性著作）

> 王沪宁（1955– ），复旦大学政治学教授，中国政治学重建后的代表学者之一，著作覆盖比较政治、国际关系、西方政治学评介、马克思主义政治学。其"学者→高层政策核心"的轨迹，本身也是中国政治学"经世致用"传统的当代案例。

## 选读顺序建议（零基础）

```
第 1 个月：包刚升《政治学通识》 + 桑德尔《公正》公开课 + 韦伯《政治作为一种志业》(短)
第 2 个月：海伍德《政治学》 + 钱穆《历代政治得失》 + 《论语》每日
第 3 个月：景跃进《当代中国政府与政治》 + 明斯特《国际关系精要》
第 4 个月：朱光磊《当代中国政府过程》 + 麦克里兰《西方政治思想史》
──────────  阶段一完成  ──────────
第 5-8 月：比较政治三巨头（亨廷顿/阿西莫格鲁/摩尔）+ 政治理论原著选 4 本
第 9-12 月：IR 四大经典 + 中国政治经典（李侃如/周雪光/兰小欢/孔飞力《叫魂》）+ 曾国藩传
──────────  阶段二完成  ──────────
长期：方法论 + 公共行政/政策评估 + 前沿期刊 + 专题深挖
```
