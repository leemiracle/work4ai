# 核心概念 Anki 闪卡集

> 把项目的核心概念做成**闪卡**——Front（问题）+ Back（简短答案）。可直接导入 Anki 或手动复习。

## 如何导入 Anki
1. 复制下方表格内容到 Excel/CSV（Front, Back 两列）。
2. Anki → 文件 → 导入 → 选择 CSV → 映射 Front→正面、Back→背面。
3. 每天复习 20 张，约 5 天过一轮。

| 柏拉图《理想国》的正义观？ | 各部分各司其职、互不僭越的和谐秩序（灵魂三分对应城邦三分） |

| 亚里士多德政体六分？ | 人数（一/少/多）× 目的（为公/为私）= 君主/僭主、贵族/寡头、共和/平民 |

| 马基雅维利的 virtù？ | 君主获取/维持权力的**能力**（果敢/狡黠），非道德"美德" |
| 马基雅维利"狮与狐"？ | 君主须兼具狮（力/威慑）和狐（狡/欺骗） |

| 洛克的天赋权利？ | 生命、自由、财产——先于国家、高于国家 |
| 洛克的"信托式契约"？ | 人民信托（非让渡）权利给政府；政府违约可被推翻（革命权） |
| 卢梭的公意 vs 众意？ | 公意=共同公共利益；众意=私人利益相加 |
| 卢梭"主权不可代表"？ | 意志不能被代表；议员一经选出，人民就成奴隶 |
| 密尔的伤害原则？ | 权力干涉个人的唯一正当理由=防止对他人的伤害 |
| 密尔为言论自由的四理由？ | ①被封意见可能为真 ②含部分真理 ③不经挑战则成死教条 ④失去影响力 |
| 罗尔斯的"无知之幕"？ | 选择正义原则时，不知道自己的阶级/天赋/性别/价值观——故无法偏私 |
| 罗尔斯正义两原则？ | ①平等自由 ②公平机会 + 差异原则（最不利者利益最大化） |
| 罗尔斯"差异原则"的核心？ | 天赋/出身是"自然彩票"（道德任意），其红利须惠及最不利者 |
| 诺齐克的"最小国家"？ | 只履行保护+契约执行；不做再分配（税收=强制劳动） |
| 诺齐克"持有正义"三原则？ | 获取正义 + 转让正义 + 矫正正义 |
| 诺齐克的张伯伦论证？ | 自愿交易会破坏任何"模式化"分配——自由颠覆模式 |
| 社群主义批判罗尔斯的核心？ | 罗尔斯的"人"是脱离传统的"无拘束自我"——不真实 |
| 韦伯的国家定义？ | 在特定领土内（成功地）**垄断合法暴力**的共同体 |
| 韦伯三种正当性？ | 传统型 / 卡里斯玛型 / 法理型 |
| 韦伯"信念伦理 vs 责任伦理"？ | 信念=按绝对道德不计后果；责任=对后果负责。政治家须持责任伦理 |
| 阿罗不可能定理？ | 当备选≥3，不存在同时满足U/P/IIA/D的社会福利函数 |
| 阿罗四公理？ | 无限制域(U) + 帕累托(P) + 无关独立性(IIA) + 非独裁(D) |
| 马克思《共产党宣言》核心命题？ | "至今一切社会的历史，都是阶级斗争的历史" |
