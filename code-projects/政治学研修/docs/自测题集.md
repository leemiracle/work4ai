## 答案（先自己想，再看）

1. 各部分各司其职、互不僭越的和谐秩序（灵魂三分对应城邦三分）。
2. 霍布斯=战争（暗）；洛克=相对和平但不便。
3. 公意=共同公共利益；众意=私人利益相加。
4. 天赋/出身是"自然彩票"（道德任意），其红利须惠及最不利者。
5. 强制拿走劳动成果给他人=迫使人为他人劳动=部分奴役。
6. 传统型 / 卡里斯玛型 / 法理型。
7. 当备选≥3，不存在同时满足四个合理公理的非独裁社会福利函数。
8. virtù=获取/维持权力的**能力**（非道德"美德"）。
9. 现代性（已完成）=稳定；现代化（过程中）=动荡。
10. 包容=保护产权/开放机会→繁荣（北美）；榨取=少数攫取→长期衰（拉美）。
11. 搭便车；解决方案=选择性激励。
12. 国家崩溃 + 农民起义 + 国际压力的交汇。
13. 国家包办一切的温柔奴役——公民变成被动"羊群"。
14. 现实主义=自助/冲突；自由主义=制度可促合作；建构主义=含义由国家互动建构。
15. 国家行为的核心=追求权力；这是理性分析的招牌概念。
16. 国际制度降低交易成本/提供信息/监督声誉——即使无霸权也能维持。
17. 无政府本身中性；含义取决于国家观念。三文化：霍布斯/洛克/康德。
18. A自保增强→B不安也增强→恶性循环——双方只想自保却走向冲突。
19. 废相→决策全压皇帝→皇帝管不过来/怠政→决策真空→司礼监代批红→宦官掌文书+厂卫→宦官专权。
20. 废相→内阁+宦官→党争→科举八股无力改革→卫所崩→募兵要钱→三饷→财政崩→民变亡国。
21. 军机处（消宦祸）/ 密折（信息）/ 秘密立储（消储争）/ 文字狱+满汉双轨。
22. "天下为主君为客"=人民是主人、君是公仆——颠覆了忠君。差一步：黄宗羲止于"民本"（精英议政），卢梭走向"民主"（人民主权）。
23. 理势合一=势之所趋即理（顺应趋势=合理）；天假其私=秦始皇私天下的动机，客观上推动了郡县的"大公"。
24. 推其所以然之繇·辨其不尽然之实·因其时·度其势·察其心·穷其效。
25. 茶余偶谈 + 读史十页 + 楷书写日记。
26. 求阙=主动求缺、戒满招损（功成即裁军）。张居正不知退→死后被清算；曾国藩知退→善终保家。
27. 知行合一=真知必能行（不行=未知）；致良知=把本心良知推致到事事上——前者是认识论，后者是工夫论。
28. 找尽可能相似的案例，控制变量，隔离唯一差异。例：张居正 vs 曾国藩（都功高，差异在"知退"）。
29. 政策在基层执行者（警察/教师/办事员）手中被"再生产"——他们有裁量权。这正是"上有政策下有对策"的学理化。
30. AI 的算法/平台/数据构成了不受民主问责的"新主权"——治理它就是把这种权力重新纳入透明/问责/人类控制的框架。
