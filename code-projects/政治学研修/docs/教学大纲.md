# 教学大纲：政治学通论（15 周）

> **把项目体系化为一门可讲授的课程**
> 这份大纲把项目的 13 个专题，组织成一门 **15 周"政治学通论"课程**——可用于自学规划、教学输出、或讲给别人（费曼法）。

---

## 课程目标
学完本课，学生应能：
1. 掌握政治学的**核心概念**（权力、合法性、正义、民主、制度）。
2. 用**三大圆环**（望远镜/显微镜/反光镜）立体地看政治。
3. 对**中西政治传统**都有基本了解，并能批判性比较。
4. 具备**基本的研究方法意识**（一手史料、因果推断、比较历史）。

## 三种授课模式

### 模式 A·完整 15 周课程（一学期）
- 适合：系统学习者、可做大学选修课。
- 每周 1 讲（2 小时）+ 阅读 + 笔记。

### 模式 B·短训（3–5 天工作坊）
- **Day 1**：望远镜（理论+比较+IR）。
- **Day 2**：显微镜（中国政治）。
- **Day 3**：反光镜（为官为人）+ 方法。
- 适合：快速建立框架。

### 模式 C·主题研讨（按兴趣选 3–5 个专题深读）
- 如"中西反专制对照"（黄宗羲+卢梭+洛克）。
- 或"制度锁定"（明史+历史制度主义+明清比较）。
- 适合：有基础者深化。

## 作业与考核建议

1. **每周读书笔记**（用[项目模板](methodology.md)）——五层穿透法。
2. **期中**：选一个理论/人物，写 2000 字精读。
3. **期末**：用[研究设计指南](../06-methodology/historical-method/05-研究设计指南.md)，完成一份**小型研究设计**（或像[mini 论文](mini论文-明清制度锁定可修正性.md)那样的比较研究）。

## 教学原则（呼应项目精神）
1. **五层穿透法**：每个概念"历史脉络→核心概念→经典文本→案例→批判"。
2. **三圆环**：望远镜-显微镜-反光镜，立体看。
3. **批判性**：对任何理论保持警惕（[认识论陷阱](../06-methodology/historical-method/04-以史为鉴的认识论陷阱.md)）。
4. **中西对照**：避免单一视角。
5. **输出倒逼输入**：写笔记、讲给别人。

---

## 一句话

> 这门课的终极目标，不是"记住政治学"，而是**学会"像政治学家一样思考"**——遇事能问"权力如何运作？制度如何框定？历史如何沉积？我该如何自处？"——**这是政治学训练的真正礼物**。
