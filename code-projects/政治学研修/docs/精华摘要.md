# 项目精华摘要 · 62 万字的 1 小时版

> 没时间读 210 个文件？这篇把整个 `political-studies` 项目浓缩成**可在一小时内通读的精华**。

---

## 0. 项目是什么

一个从"综合明史"起步、经 32 次迭代长成的**政治学研修体系**——三圆环（望远镜/显微镜/反光镜）、14 个专题、16+ 本原典精读、5 个可运行代码。

> 核心问题：**人类如何组织起来共同生活？权力如何产生、被正当化、被约束？而我们自己，又该如何在其中自处？**

## 1. 14 个专题的一句话精华

### 望远镜（01/02/03）

| 专题 | 一句话 |
|------|--------|
| **政治思想史长河** | 从柏拉图（哲人王）到马克思（阶级斗争），2500 年政治哲学的核心是三个母题：人是什么/最好政体/法从何来 |
| **社会契约论** | 霍布斯（怕乱→绝对主权）→洛克（怕暴→有限政府）→卢梭（要真自由→人民主权）：现代政治的奠基叙事 |
| **当代政治哲学** | 罗尔斯（差异原则）vs 诺齐克（最小国家）vs 社群主义（共同善）vs 哈贝马斯（协商）：平等/自由/共同体/对话的四方张力 |
| **比较政治** | 民主化（亨廷顿第三波）+ 发展型国家（东亚奇迹）+ 国家能力（福山三件套）|
| **政治经济学** | 市场会失灵、政府也会失灵——制度（诺斯/Acemoglu）决定长期繁荣 |
| **国际关系** | 现实主义（权力博弈）vs 自由主义（制度合作）vs 建构主义（观念塑造）——三副眼镜看世界 |

### 显微镜（04）

| 专题 | 一句话 |
|------|--------|
| **明史政治学** | 明代八大制度形成"自我锁死"的闭环——崇祯再勤政也救不了"制度绝症" |
| **毛泽东读《通鉴》** | 17 遍，最钟情的书——"治国就是治吏""上梁不正下梁歪" |

| **《明夷待访录》（黄宗羲）** | "天下之大害者君而已矣"——中国本土最系统的反专制批判，比卢梭早百年 |

### 反光镜（05）

| 专题 | 一句话 |

| **王阳明（心学）** | "知行合一"——知而不行只是未知；"致良知"——每件事上听本心 |

### 方法与前沿（06/07）

| 专题 | 一句话 |
|------|--------|
| **历史政治学方法论** | 一手史料批判 + 路径依赖 + 比较历史分析 + 认识论自检——让读史变科学 |
| **公共行政** | 韦伯官僚制 + 街头官僚（政策在基层被"再生产"）+ 新公共管理的得失 |
| **AI 治理** | 算法权力 + 监控资本主义 + 数字威权——AI 不是技术问题，是政治问题 |

## 4. 跨模块思想网络（5 条隐线）

1. **霍布斯的两个面孔**：国内绝对主权（01）+ 国际现实主义鼻祖（03）——同一人，两个领域。
2. **中西反专制对话**：黄宗羲（民本，for the people）vs 卢梭（民主，of/by the people）——差一步。
3. **契约论两次生命**：17 世纪古典（霍/洛/卢）→ 20 世纪罗尔斯复兴（无知之幕）。
4. **批判传统跨域**：哈贝马斯（01 协商民主）→ IR 批判理论（03 "理论总是为某人服务"）。
5. **读史双视角**：王夫之（古人/哲学家，求"理"）vs 毛泽东（今人/政治家，求"用"）。

## 6. 一句话总结整部项目

> **政治学不是"记住概念"，而是学会"像政治学家一样思考"——遇事能问"权力如何运作？制度如何框定？历史如何沉积？我该如何自处？" 这四个问题，就是政治学送给每个公民最珍贵的礼物。**
