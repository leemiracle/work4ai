# 项目总览图

> 一张图看清整个 `political-studies` 项目的全貌：**七模块主干 + 历史纵深板块（内容/方法/桥梁）**。

## 一、三大圆环（项目的设计哲学）

```
            ┌─────────────────────────────────┐
            │   为官为人（反光镜）05          │  ← 照见自己
            ├─────────────────────────────────┤
            │   中国政治（显微镜）04          │  ← 看清这片土地
            ├─────────────────────────────────┤
            │   政治学通论（望远镜）          │
            │   01理论 / 02比较 / 03IR        │  ← 看清人类治理一般规律
            │   06方法 / 07公共行政           │
            └─────────────────────────────────┘
```
- **望远镜**（01/02/03/06/07）：抽象"权力—制度—治理"的一般规律。
- **显微镜**（04）：聚焦中国连续文明的特殊经验。
- **反光镜**（05）：照见政治实践者自身如何修心、做事、处世。

## 三、七模块速览

| 模块 | 主题 | 特别专题 |
|------|------|---------|
| **01 政治理论** | 政治哲学（权力/合法性/正义） | ⭐ 思想史长河 + 社会契约论 + 当代政治哲学 |
| **02 比较政治** | 政体/民主/发展型国家 | ⭐ 比较政治核心议题 + 政治经济学 |
| **03 国际关系** | 现实主义/自由主义/建构主义 | ⭐ IR 理论三大流派 |
| **04 中国政治** | 党政体制/央地/治理 | ⭐ 明史 / 毛读通鉴 / 读通鉴论 / 明夷待访录 |
| **05 为官为人** | 儒骨/法术/道底 + 三接口 | ⭐ 曾国藩 / 王阳明 / 法术势三维 |
| **06 方法论** | 定量/定性/形式 + 历史 | ⭐ 历史政治学方法论 + 计算政治学代码库（4 代码已跑通） |
| **07 公共行政** | 政策/官僚/治理效能 | ⭐ 公共行政与政策 + AI 治理 |

## 四、两条推荐学习路径

### 路径 A·按"圆环"由外到内（理论优先）
```
01理论 → 02比较 → 03IR → 06方法 → 07行政 → 04中国 → 05为人
（望远镜 → 显微镜 → 反光镜）
```

### 路径 B·按"历史纵深"由史到己（本项目特色）
```
明史（制度）→ 毛读通鉴/读通鉴论（读史双视角）→ 曾国藩/王阳明（修身两路）
→ 明夷待访录（思想批判）→ 历史政治学方法论（元反思）
→ 张曾对比/导航图（综合）
```

## 五、一句话总览

> 这是一个**以"权力与治理"为核心、以"三圆环"为架构、以"历史纵深板块"为特色**的政治学研修项目——既有通论骨架，又有中国显微镜，更有为官为人的反光镜。**所有理论与经验，最终都要回到"我如何活、如何治理"**。
