# 政治学方法论 · 如何研究政治

> 政治学不只是"读经典 + 谈观点"。它是一门**试图用证据说话的科学**。
> 方法论训练决定你能否从"有看法的人"变成"有根据的人"。

---

## 一、三大研究传统

| 传统 | 核心问题 | 工具 | 代表 |
|------|---------|------|------|
| **定量**（Quantitative） | 多少？多强？显著吗？ | 统计、回归、实验 | APSR/AJPS 大多数论文 |
| **定性**（Qualitative） | 怎么回事？为什么？ | 案例、访谈、过程追踪 | 摩尔、斯科特、比较历史分析 |
| **形式理论**（Formal） | 理性人会如何博弈？ | 博弈论、空间模型 | 唐斯、布坎南 |

三者不是对立，而是互补。一个问题往往需要多种方法 triangulation（三角验证）。

---

## 二、定量方法路径

### 1. 基础
- 描述统计 + 概率论 + 假设检验
- 线性回归（OLS）及其假设
- 工具：R（学界主流）或 Stata（政治学常用）

### 2. 因果推断（核心）
政治学定量研究的灵魂是**因果识别**（causal identification）。相关 ≠ 因果。

**必读**：
- 安格里斯特/皮施克《基本无害的计量经济学》（Mostly Harmless Econometrics）
- 《精通计量》（Mastering 'Metrics）

**核心工具**：
- **随机实验**（RCT）：金标准，但政治学里少见（谁能随机分配政体？）
- **自然实验**：利用"准随机"的事件
- **工具变量**（IV）：找个好工具
- **双重差分**（DID）：政策前后的处理组 vs 对照组
- **断点回归**（RDD）：利用阈值（如选举得票率 50%）

### 3. 数据库（中国政治研究）
- **CFPS** 中国家庭追踪调查——个体政治态度
- **CGSS** 中国综合社会调查——社会态度与行为
- **CHFS** 中国家庭金融调查
- **国家统计局**——宏观数据

## 三、定性方法路径

### 1. 研究设计思维
**必读**：KKV《社会科学中的研究设计》

核心思想：定性研究也要遵循"科学推断的逻辑"——如何从小样本案例推出可推广的结论。

### 2. 案例研究
- 罗伯特·殷《案例研究：设计与方法》
- 单案例：深度理解机制
- 多案例：比较找异同

### 3. 过程追踪（Process Tracing）
定性因果推断的核心武器。在单个案例里，通过追踪"因果链条"上的各个环节，验证或证伪某个因果假设。

- 必读：《过程追踪方法》
- 例子：论证"某项改革为何成功"，逐一检查每个中间环节的因果证据

### 4. 比较历史分析（CHA）
- 摩尔《民主与专制的社会起源》
- 斯科特《国家的视角》
- 特点：大跨度、长时段、深度解释

---

## 四、形式理论（博弈论）路径

用数学模型研究政治行为：

- **空间模型**：唐斯《民主的经济理论》——政党为何趋中？
- **投票悖论**：阿罗不可能定理——完美的民主为何不可能？
- **集体行动**：奥尔森——大集团为何难以合作？
- **委托—代理**：选民—政客、中央—地方的信息不对称

入门：乔尔·沃森《策略：博弈论导论》

## 五、计算政治学（Computational Politics）· 新兴前沿

> 这是政治学方法论里**最新、增长最快**的方向。对有 AI/编程背景的学习者，这是天然的发力点——你可以用别人没有的武器，进入这个领域。

### 1. 什么是计算政治学

利用**大数据、文本挖掘、计算社会科学模型**来分析政治文本、舆论场与政策网络。它不是替代传统方法，而是提供**新数据源 + 新分析工具**：

- 传统政治学：问卷（几百到几千样本）+ 案例
- 计算政治学：海量文本（百万级政府报告/议会辩论/社交媒体）+ 自动化分析

### 2. 核心方法与工具

| 方法 | 用途 | 工具 |
|------|------|------|
| **文本挖掘** | 分析政府报告、议会辩论、法律文本的话语演变 | Python: spaCy / transformers; R: quanteda |
| **主题模型**（LDA/BERTopic） | 从海量文本中发现潜在议题 | Python: gensim / BERTopic |
| **情感与立场分析** | 舆情监测、选民态度 | Python: transformers 情感模型 |
| **网络分析** | 政策网络、议员共决网络、国际关系网络 | Python: networkx; Gephi（可视化） |
| **事件抽取** | 从新闻中结构化提取政治事件（冲突、选举） | Python: spaCy NER + 规则 |
| **机器学习预测** | 选举预测、冲突预警 | Python: scikit-learn / XGBoost |
| **LLM 应用**（新） | 政治文本自动标注、政策模拟、政治 Agent | Python: transformers / LangChain |

### 3. 数据源

- **政府公开数据**：政府工作报告、人大议案、政策文件（中国政府网、各部委）
- **社交媒体 API**：微博、Twitter（舆论场）
- **政治文本语料库**：Comparative Agendas Project、Party Manifesto Project
- **国际数据库**：GDELT（全球事件数据库）、Polity IV / V-Dem

### 4. 与因果推断的关系

计算政治学 ≠ 取消因果推断。最佳实践是**两段式**：

1. **用计算方法发现规律**（文本挖掘/网络分析找到有趣的相关性）
2. **用因果推断验证机制**（DID/RCT 确认是不是真因果）

计算方法擅长"广度"（海量数据找模式），因果推断擅长"深度"（确认因果关系）。两者结合最强。

### 5. 局限与陷阱

1. **数据偏差**：社交媒体用户不代表全民；网络数据有选择性。
2. **可重复性危机**：很多计算研究不公开代码/数据。
3. **测量效度**：LDA 提取的"主题"真的对应政治学概念吗？需要人工校验。
4. **伦理**：舆情监测、选民微定位（Cambridge Analytica 事件）有严重的伦理风险。
5. **LLM 幻觉**：用 LLM 做政治文本分析，要警惕它"编造"——必须有人工核查环节。

### 6. 推荐入门路径（给有编程基础的你）

1. 学 quanteda（R）或 spaCy（Python）做基础文本处理。
2. 用中国政府工作报告语料（可从政府网爬取）做一个**主题演变分析**（如"改革""安全""创新"词频随时间变化）。
3. 进阶：用 transformers 做政治文本分类（如区分改革派/保守派言论）。
4. 高阶：用 GDELT 数据做国际冲突事件网络分析。

## 六、如何选择方法

| 你的问题 | 推荐方法 |
|---------|---------|
| "影响有多大？" | 定量 |
| "机制是什么？" | 定性/过程追踪 |
| "理性人会如何选择？" | 形式理论 |
| "这个现象普遍吗？" | 定量（大样本） |
| "这个案例为什么独特？" | 定性（深度案例） |

**最佳实践**：混合方法。先用定量发现规律，再用定性深挖机制。

---

## 七、对方法论的批判性态度

方法论训练也有陷阱：

1. **方法崇拜**：为了用精巧方法而牺牲问题的重要性。"用 DID 研究一个无关紧要的问题"是学术界的常见病。
2. **统计显著 ≠ 实质重要**：大样本下任何微小差异都"显著"。要看效应量。
3. **定性 ≠ 不科学**：好的定性研究（如过程追踪）同样遵循严格的因果逻辑。
4. **数据不能自己说话**：任何量化都需要理论框架解读。"

> 方法论是工具，不是目的。**最好的研究者是问题驱动的**——先有重要问题，再选合适方法，而不是反过来。
