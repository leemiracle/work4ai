## 0. 这是什么？

`political-studies` 是一个**系统化学习政治学**的长期项目，回答一个贯穿始终的问题：

> **人类如何组织起来共同生活？权力如何产生、如何被正当化、如何被约束？**

这个问题没有标准答案，但有 2500 年的思考积累。本项目把这些积累组织成一条**可走通的路径**——从柏拉图的洞穴到当代中国的治理，从马基雅维利的冷峻到罗尔斯的正义，从亨廷顿的秩序焦虑到温特的观念建构。

项目不追求"背完概念"，而追求**搭建一座"权力与治理"的知识大厦**：每个概念都有承重墙，每个理论都有地基，每个案例都能检验结构。

> **什么是政治？** 拉斯韦尔（Harold Lasswell）的经典定义：*"Politics: Who Gets What, When, How"*——**政治就是决定谁得到什么、何时得到、如何得到。** 记住这句话：政治的核心是**资源与价值的权威性分配**。

## 1. 为什么这样设计：三大学科的同心圆

你面对的三份学习地图（政治学通论 / 中国政治 / 为官为人）不是三门独立的课，而是**三个层次的同心圆**：

```
            ┌─────────────────────────────────┐
            │   为官为人（反光镜）             │  ← 照见自己：心性、戒律、实践
            │   05-statesmanship-ethics        │
            ├─────────────────────────────────┤
            │   中国政治（显微镜）             │  ← 看清这片土地：制度、历史、逻辑
            │   04-chinese-politics            │
            ├─────────────────────────────────┤
            │   政治学通论（望远镜）           │  ← 看清人类治理的一般规律
            │   01-theory / 02-comparative     │
            │   03-IR / 06-methodology         │
            │   07-public-admin-policy         │
            └─────────────────────────────────┘
```

- **政治学通论**给你**望远镜**：抽象出"权力—制度—治理"的一般规律，适用全人类。
- **中国政治**给你**显微镜**：聚焦一个连续文明的特殊经验，看制度的真实运转。
- **为官为人**给你**反光镜**：照见政治实践者自身——儒骨/法术/道底三维心法 + 向上/横向/向下三个接口 + 谨言/灰度/护城河三条铁律。

少了望远镜，你会陷在"中国特殊论"里出不来；少了显微镜，理论变成空中楼阁；少了反光镜，学问与人格割裂，沦为"两脚书橱"。三者缺一不可。

## 2. 学习哲学：五层穿透法

本项目沿用"层层穿透"的学习方法，针对政治学调整为**五层**（政治学没有数学/代码层，但有"经典文本"层）：

| 层 | 做什么 | 产出 |
|----|--------|------|
| ① 历史脉络 | 这件事从何而来？制度/思想的源头与演变 | 一条时间线 |
| ② 核心概念 | 用专业语言重新看世界（权力、合法性、国家、民主） | 概念地图 |
| ③ 经典文本 | 与最聪明的头脑对话，精读里程碑之作 | 读书笔记 |
| ④ 案例应用 | 用理论框架解释具体事件/国家/政策 | 案例分析 |
| ⑤ 批判反思 | 每个理论的局限、争议、反例；识别价值预设 | 批判短文 |

**第五层最重要**。政治学里没有任何理论是"银弹"：

- 亨廷顿的"秩序论"被批评忽视自由价值；
- 阿西莫格鲁的"制度论"被质疑历史过度简化；
- 周雪光的"一统与有效"被指过度结构化、忽视能动性；
- 罗尔斯的"正义论"被社群主义、女性主义多方挑战。

学政治学的成熟标志，是**对任何简单化解释保持警惕**，并能识别每个理论背后的价值预设。

## 4. 如何使用

### 如果你是零基础
1. 先读 [`docs/roadmap.md`](docs/roadmap.md) 的**第一阶段**，用 2-3 本书搭骨架。
2. 推荐：包刚升《政治学通识》+ 海伍德《政治学》对照读，约 1 个月。
3. 同步看哈佛桑德尔《公正》公开课（B 站有中文字幕），引发思辨。

### 如果你已有框架
1. 直接进 [`docs/reading-list.md`](docs/reading-list.md)，按兴趣挑模块。
2. 每个模块的 `00-README.md` 给了该领域的必读 + 学习路径。
3. 重点用**五层穿透法**做读书笔记，存到对应模块的 `books/`。

### 三阶段时间预算（每周 5-8 小时）
| 阶段 | 时长 | 核心任务 |
|------|------|---------|
| 一·奠基 | 3-4 个月 | 通识教材 + 思想史脉络 + IR 入门 + 中国制度入门 |
| 二·深入 | 6-12 个月 | 各领域里程碑专著精读 + 原著选读 |
| 三·精进 | 长期 | 方法论训练 + 前沿期刊追踪 + 专题研究 |

## 5. 关于"在中国学政治学"的三条提醒

1. **平衡内外视角**：国内教材（马工程《政治学概论》）与海外中国研究（李侃如、周雪光、傅高义）对照读，训练识别不同理论前提和价值预设的能力。这是思想成熟的标志。
2. **回归经验与田野**：政治的活力在基层，在地方。费孝通《乡土中国》本身就是"过程—事件"分析方法的绝佳示范；若有机会，参与一次社会调查胜过读十本书。
3. **保持历史感**：白鲁恂（Lucian Pye）说"中国是伪装成国家的文明"。不要孤立看当代制度，向前看百年千年，脉络自现。
