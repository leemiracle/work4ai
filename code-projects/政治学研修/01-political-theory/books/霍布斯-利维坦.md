# 《利维坦》精读笔记

> 01 政治理论 · 绝对主权论的奠基 · ⭐ 必读
> 配合 [社会契约论 01 霍布斯](../social-contract/01-霍布斯.md) 的概览，本篇做全书深化

## 元信息
- **书名**：《利维坦》（*Leviathan*）
- **作者**：托马斯·霍布斯（Thomas Hobbes，1588–1679）
- **出版**：1651 年
- **结构**：四部分（论人 / 论国家 / 论基督教国家 / 论黑暗之国）

## 第一层 · 历史脉络
- 生于西班牙无敌舰队入侵之年（自称"与恐惧是双胞胎"）。
- 经历**英国内战**（1642–1651）——查理一世被处决、社会失序。**对"乱"的恐惧**是他全部思想的火种。
- 流亡法国写成《利维坦》，主张**绝对主权**以止乱。

## 第二层 · 核心概念

### 1. 自然状态 = 战争
- 人**自保、追求权力、能力大致平等** → 竞争/猜疑/荣誉 → **所有人对所有人的战争**。
- 生活"**孤独、贫困、污秽、野蛮、短命**"。

### 2. 自然法与契约
- 理性指出**求和平**；为此，每人**让渡自然权利**给共同主权者。
- 契约是**人民之间**互订，**主权者不在契约内** → 主权绝对、不可反抗。

### 3. 利维坦（Leviatan）
- 那个被授权的"**人造的人**"——"**有死的上帝**"（mortal god）。
- 拥有**绝对、不可分割的主权**：立法、司法、宣战、控制言论……

### 4. 主权的绝对性
- **不可分**（分则内战）、**不可反抗**（主权者不违约）。
- 唯一例外：**主权者不能保护人民生命时**，人民不再有服从义务。

## 第三层 · 全书结构
- **第一部分·论人**：感觉、想象、推理、激情、自然状态——从"人性"演绎。
- **第二部分·论国家**：契约、利维坦、主权者的权利与义务、臣民的自由、政体——**政治学核心**。
- **第三部分·论基督教国家**：把理论与《圣经》调和（神学辩护）。
- **第四部分·论黑暗之国**：批判经院哲学/教权——**知识与权力的争夺**。

## 第四层 · 应用与当代
1. **现实主义 IR 鼻祖**：自然状态移植到国际=[03 现实主义](../../03-international-relations/ir-theories/01-现实主义.md)的国际无政府。
2. **秩序优先论**：呼应[亨廷顿](../../02-comparative-politics/books/亨廷顿-政治秩序.md)"秩序优先于政体"。
3. **博弈论**：自然状态=囚徒困境（见[代码④](../../06-methodology/code/computational-politics/04_game.py)——合作崩溃）。

## 第五层 · 批判
1. **绝对主权过强**：几乎为任何暴政辩护。
2. **人性过暗**：忽视合作/道德的可能（[洛克](../social-contract/02-洛克.md)修正）。
3. **但奠基性不朽**：**第一个系统的现代政治哲学**，"自然状态→契约→主权"成为此后所有政治哲学的起手式。

## 一句话
> 霍布斯从"人对人是狼"推演出"利维坦"——**为了逃离相互屠杀，人需让渡权利给绝对主权**。他悲观、冷峻，却奠基了现代政治哲学的**整套语言**。
