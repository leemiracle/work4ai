# 《论自由》精读笔记

> 01 政治理论 · 自由主义的圣经 · ⭐ 必读
> 配合 [社会契约论 04 密尔](../social-contract/04-批判与当代.md) 与 [当代政治哲学 04 多数暴政](../contemporary-political-philosophy/04-哈贝马斯与当代.md)

## 元信息
- **书名**：《论自由》（*On Liberty*）
- **作者**：约翰·斯图亚特·密尔（John Stuart Mill，1806–1873），与妻子 Harriet Taylor 合著
- **出版**：1859 年
- **核心**：划定**个人自由与社会/国家权力的边界**（严复中译《群己权界》即此意）

## 第一层 · 历史脉络
- **时代**：维多利亚英国——道德保守、舆论一律、国教压制异端。
- **动机**：密尔忧虑**多数人的暴政**（不只法律的，更是舆论的）。
- **背景**：继承[边沁功利主义](../history-of-political-thought/04-十九世纪与收束.md)，但更重视**个性与精神自由**。

## 第二层 · 核心概念

### 1. 伤害原则（Harm Principle）——全书核心
> "**权力能正当地施于文明共同体任何成员的唯一目的，是防止对他人的伤害**——为了他自己（的利益、道德、幸福），不能强制他。"

- 这划定了**个人不可侵犯的自由领地**：只要不伤害他人，国家/社会无权干涉。
- **应用**：思想/言论/信仰/生活方式/结社/贸易——都属个人自由。

### 2. 言论自由的四重论证
密尔为言论自由给出**四个理由**（即便被封的意见是错的）：
1. 被封的意见**可能是真的**——封杀它就是假设我们绝不会错。
2. 即便它是错的，也包含**部分真理**——真理在与谬误碰撞中更清晰。
3. 即便公认意见是全对的，若不**经受挑战**，它会变成"僵死的教条"而非"活的信念"。
4. 教条化的真理会失去**影响力**——人不再理解其意义。

### 3. 个性（Individuality）
- 密尔极力推崇**个性**——"个性是人类福祉的要素之一"。
- 反对**一律（conformity）**：人人像同一模具刻出，是社会衰败的征兆。
- "**让不同的人过不同的生活**"——这是自由的高级理由。

### 4. 多数暴政（Tyranny of the Majority）
- 密尔警告：民主时代最大的危险不是暴君，而是**多数人（通过法律+舆论）压迫少数**。
- 这比政治压迫更隐蔽——**社会舆论的暴政**让人不敢"与众不同"。
- 呼应[托克维尔《论美国的民主》](../../02-comparative-politics/comparative-politics/01-民主化.md)"多数暴政"概念。

## 第三层 · 全书结构
- **第一章·引论**：提出伤害原则。
- **第二章·思想与讨论自由**：言论自由的四重论证（最经典）。
- **第三章·个性**：个性的价值。
- **第四章·社会权力的界限**：进一步划界（如"不得劝人自杀"等）。
- **第五章·应用**：贸易、教育、道德立法、税收等具体问题。

## 第四层 · 应用与当代
1. **言论自由**：密尔的论证至今是**言论自由的最强辩护**（即便 hate speech，密尔倾向容忍）。
2. **AI 与信息操纵**：[AI与民主](../../07-public-administration-policy/ai-governance/02-AI与民主.md)的深度伪造/算法操纵，挑战密尔的"真理越辩越明"假设——当假信息工业化，密尔框架需要更新。
3. **家长主义**：密尔反对"为了你好"的强制（如强制系安全带？密尔会反对，但这有争议）。
4. **取消文化（cancel culture）**：是社会舆论暴政的现代版？密尔的警告在当代回响。

## 第五层 · 批判
1. **伤害原则的模糊**：什么算"伤害他人"？冒算不算？污染算？（密尔的边界比想象模糊）。
2. **过度个人主义**：忽视了人对共同体/传统的归属需求（[社群主义](../contemporary-political-philosophy/03-社群主义.md)批评）。
3. **文化局限**：维多利亚英国的精英视角，对殖民/性别（密尔自己在印度公司任职）有盲点。
4. **但洞见不朽**：**多数暴政、个性的价值、言论自由的根基**，至今是自由社会的基石。

## 一句话
> 密尔用《论自由》划定了一条**文明的底线**：**只要不伤害他人，个人就有权按自己的方式生活**。这条线，是抵御"多数暴政"和"国家家长主义"的最坚固的堤坝。

## 金句
- "人类不是机器，按模型造出、为做精确的工作而设；人类像树木，需要按自身内在力量的方向生长。"
- "既然人类会犯错，被压制的意见可能是真的。"
