# 01 · 政治理论 / 政治哲学

> **规范性追问**：什么是正义？什么是自由？我们为什么需要国家？权力何以正当？

## 模块定位

政治理论是政治学的"良心"。它不问"是什么"，而问"应当如何"——这是**规范性**（normative）的领域。它有两个分支：

- **政治哲学**：追问根本价值（正义、自由、平等、权威）
- **政治思想史**：梳理这些追问的历史演变

整个模块的主线，是**反复的对话与反驳**：柏拉图回应智者派，霍布斯回应内战，洛克回应霍布斯，卢梭回应洛克，罗尔斯回应功利主义……读懂一场对话，胜过背诵十个定义。

## 核心追问

1. **国家何以正当？** ——为什么我们需要服从一个拥有暴力的权威？（社会契约论的核心）
2. **自由与权威如何兼容？** ——"人生而自由，却无往不在枷锁中"（卢梭）
3. **什么是正义？** ——分配应基于什么？需要？功劳？平等？程序？（罗尔斯 vs 诺齐克）
4. **权力与道德的关系？** ——政治是否应当服从道德？还是政治有独立逻辑？（马基雅维利的颠覆）
5. **民主是好东西吗？** ——多数暴政？精英统治？托克维尔的忧虑。

## 批判性提示

1. **识别价值预设**：每位思想家都有"默认的好"。柏拉图默认精英智慧；洛克默认财产权；罗尔斯默认公平。读到任何论断，问：他默认了什么？
2. **西方中心主义陷阱**：主流政治哲学史几乎默认"希腊—欧洲"为主线。要主动补中国（儒法道）和印度、伊斯兰的思想传统，否则视野残缺。
3. **理论与历史脱节**：洛克的理论被用来为殖民辩护；卢梭的"公意"被指责为雅各宾专政的先声。**理论一旦进入历史，后果常超出作者意图**。
4. **"应然"不能推出"实然"**：罗尔斯的正义原则很美，但能否实现是另一个问题。规范理论与比较政治的经验研究要分开。

### ② 当代政治哲学 · 自由主义内部的伟大辩论

罗尔斯《正义论》（1971）复活政治哲学，引爆平等（罗尔斯）↔ 自由（诺齐克）↔ 共同善（社群主义）↔ 协商（哈贝马斯）四方张力。**与①社会契约论构成"古典→当代"完整的西方政治哲学链**（霍布斯→哈贝马斯，三百年核心议题）。

> **四方没有赢家**：平等、自由、共同善、协商无法同时最大化——**真正的政治智慧是在四者间艰难平衡**。本专题对中国"集体/共同善"传统与西方"个人权利"传统的对话也有参照意义。

## 如何开始

1. 先看 B 站耶鲁公开课《政治哲学导论》前 3 讲（Smith 讲柏拉图），感受政治哲学的"问题感"。
