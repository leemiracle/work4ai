# 王阳明心学专题 · 知行合一的成事之路

> **05 为官为人 / 人物专题**
> 王阳明（1472–1529）与曾国藩并列，是中国"立德立功立言"三不朽的又一典范——但他的路径截然相反：曾国藩靠**笨功夫渐修**，王阳明靠**顿悟+事功**。本专题用《传习录》一手原文，拆解"心即理—知行合一—致良知"的心学三大命题，并与曾国藩理学形成"修身两路"的对照。
>

## 0. 为什么把王阳明放进"为官为人"模块？

05 模块（反光镜）已有[曾国藩](../zeng-guofan/00-README.md)代表**理学渐修**一路；王阳明则代表**心学顿悟+知行合一**另一路。两路对照，才见"修身成事"的全貌：

1. **他是"知行合一"的化身**。本模块反复强调"知行合一"是最难的（[05 README](../00-README.md)批判提示#5）。而"知行合一"这个词，正是王阳明提出的。**读他，就是读这四个字的原产地**。
2. **他是"事功+学问"合一的典范**。王阳明不只是哲学家，更是**军事家、政治家**——平定宁王叛乱、剿赣南盗贼，是明代最传奇的文臣统帅。他证明了**思想可以转化为切实的成事能力**。
3. **他与曾国藩构成"修身两路"**：曾国藩"钝拙渐修、有恒改过"，王阳明"龙场顿悟、良知妙用"。**一个靠笨功夫，一个靠悟性+实践**。两条路都能成圣，但气质迥异——对照读，才能找到适合自己的路。

> 一句话：**曾国藩教你怎么"熬"成事，王阳明教你怎么"悟"成事。两者都是中国"内圣外王"的最高样本，缺一不可。**

## 1. 王阳明其人：与曾国藩反差的"天才型"圣人

| 维度 | 曾国藩（理学） | 王阳明（心学） |
|------|--------------|--------------|
| 资质 | 自认"钝拙"，靠苦功 | 少年神童，天资超迈 |
| 修身路径 | 渐修（日课、有恒） | 顿悟（龙场悟道） |
| 核心方法 | 敬、恒、拙 | 悟、良知、知行合一 |
| 事功 | 平太平天国（苦战十余年） | 平宁王叛乱（43天） |
| 学问性格 | 笃实、保守、集大成 | 锋利、革命、开新风 |
| 对后世 | "笨办法"可学 | "妙悟"难学，易流弊 |

**一个判断**：曾国藩是"可学的圣人"（方法可复制），王阳明是"难学的圣人"（悟性难复制，且心学末流易流于狂禅）。**正因为难学，更要读他——至少要知道"成事的另一条路"长什么样，避免把曾国藩的渐修当成唯一正途。**

## 3. 一手材料说明

| 层级 | 来源 | 用途 |

| **一手典籍** | 《传习录》（维基文库卷上/中/下原文）、《王文成公全书》、《阳明先生年谱》（钱德洪） | 阳明亲笔与弟子记录 |

| **学者研究** | 陈来、吴光、束景南、杨国荣等当代阳明学研究 | 体系化解读 |

> **一个学术分寸**：龙场悟道"悟的究竟是什么"，学界有争论（格物致知之旨？心即理？知行合一？致良知？）。本专题采信主流考据：龙场（1508）首悟"格物致知之旨/圣人之道吾性自足"，次年（1509）贵阳揭"知行合一"，五十岁（1521）定"致良知"，晚年（1527）天泉证道说"四句教"——**心学是渐进成熟的，不是一次顿悟完成的**。这个分寸很重要（详见 `01`、`02`）。
