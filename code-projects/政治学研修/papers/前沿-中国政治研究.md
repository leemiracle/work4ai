# 前沿综述：中国政治研究图景

> papers / 前沿文献笔记
> 中国政治研究是当代政治学的**核心议题场**——既是最大案例，也是理论富矿。本文梳理其议题地图与关键学者。

---

## 一、议题地图

中国政治研究围绕**六大议题**：

### 1. 威权韧性（Authoritarian Resilience）
- **Nathan（2003）**：提出中国威权的"**韧性**"——通过制度化（换届、协商、精英选拔）适应变化，避免苏联式崩溃。
- 争论：是真韧劲，还是"**表象稳定下的脆弱**"（Shirk《脆弱的超级大国》）？

### 2. 党国体制
- 党如何嵌入国家机器（[04 党政体制](../04-chinese-politics/00-README.md)）、党管干部、归口管理。
- **景跃进/朱光磊**（中国体制通论）。

### 3. 央地关系 / 晋升锦标赛
- **周黎安**：地方官员围绕 GDP 锦标赛竞争。
- **周雪光**："一统体制与有效治理"基本矛盾、基层"变通"。
- **Landry**：分权化中国。

### 4. 绩效合法性
- 中国的合法性**依赖经济绩效**（而非选举/意识形态）——若增长放缓，合法性危机？
- **Zhao**（赵鼎新）《Performance Legitimacy》。

### 5. 数字治理 / 监控
- 社会信用、智慧城市、天网——**数字威权的中国实验**（[AI治理](../07-public-administration-policy/ai-governance/00-README.md)、[研究论文](../docs/研究论文-技术治理与国家能力.md)）。

### 6. 政治经济学
- 政商关系、国企改革、发展型国家（[02 发展型国家](../02-comparative-politics/comparative-politics/02-发展型国家.md)）。
- **裴敏欣**（*Crony Capitalism*）、**Naughton**（中国经济）。

## 三、中国政治学的"本土化"争论

- 主流政治学以西方概念为核心——中国学者正争论是否要**本土化**：
  - **本土派**：西方概念（民主/公民社会）不适用中国，需发展本土理论（如"关系本位""天下体系""贤能政治"贝淡宁）。
  - **普世派**：政治学应普世，警惕"特色论"为现状辩护。
- **成熟的立场**：**既不照搬西方，也不本质化中国**——用比较视角，既看共性也看特性（呼应[04 批判提示](../04-chinese-politics/00-README.md)）。
