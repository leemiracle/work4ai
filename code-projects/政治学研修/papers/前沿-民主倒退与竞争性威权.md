# 前沿综述：民主倒退与竞争性威权

> papers / 前沿文献笔记
> 21 世纪最值得关注的政治现象：**民主不是"一次性成就"，它在持续倒退**。本文梳理这一前沿领域的关键文献。

---

## 一、现象：第三波之后的"民主倒退"

- 亨廷顿的[第三波民主化](../02-comparative-politics/comparative-politics/01-民主化.md)（1974–）曾让民主达到历史高峰。
- 但 2006 年起（自由之家数据），**全球自由度连年下降**——出现"**民主倒退**"（democratic backsliding）。

## 二、核心文献

### 1. Levitsky & Ziblatt《民主如何死亡》（*How Democracies Die*，2018）
- **核心**：现代民主很少死于"军事政变"，而是**被民选领袖从内部侵蚀**。
- **机制**：渐进地——控制司法、媒体、选举规则、打压反对派。
- **两大警示**：
  - **民主的"护栏"（norms）比制度更重要**——如"相互容忍"（不把对手当敌人）、"制度性克制"（不滥用规则）。这些非正式规范一旦崩塌，制度挡不住独裁。
  - 民主倒退的**典型路径**：民粹领袖 + 极化 + 规范崩塌。

### 2. Levitsky & Way"竞争性威权"（Competitive Authoritarianism，2010）
- 一种**新型政体**：**有选举，但不公平**——在任者用国家资源/媒体/司法打压对手，但保留竞争的外壳。
- 案例：匈牙利（欧尔班）、土耳其（埃尔多安）、委内瑞拉（查韦斯）、俄罗斯（普京）。

### 3. Bermeo"民主倒退的类型学"（2016）
- 区分**古典政变**（军队推翻）、**选举独裁**、**行政扩权**等不同倒退模式——现代倒退更隐蔽、渐进。

## 三、解释：为什么民主会倒退？

| 解释 | 要点 |
|------|------|
| **极化**（polarization） | 社会撕裂→把对手当敌人→接受破坏规则的领袖 |
| **民粹主义** | "我代表真正的人民"→否定反对派的合法性 |
| **经济不平等** | 中产萎缩、贫富悬殊→对民主失望 |
| **社交媒体** | 信息茧房、假新闻→加剧极化 |
| **强人魅力** | 选民愿为"效率/秩序"交换自由 |

## 四、对中国研究的意义
- 中国不是"民主倒退"案例（它本非选举民主），但**这套理论提供对照**：
  - **"竞争性威权"**概念帮助定位某些介于民主威权间的国家。
  - **"规范比制度重要"**的洞见，对理解任何政体的稳定性都有启发。
  - 提醒：**治理效能与民主问责是两回事**（参[福山国家能力](../02-comparative-politics/comparative-politics/03-国家能力与制度.md)）。

## 一句话
> 民主倒退研究提醒：**民主不是"建成即永恒"，而是需要"护栏（规范）+制度+公民警觉"持续维护的脆弱均衡**。这对任何政体（包括非西方的）都是警示——**没有永远的稳定，只有持续的维护**。
