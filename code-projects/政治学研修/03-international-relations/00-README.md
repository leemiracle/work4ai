# 03 · 国际关系

> **无政府状态下的合作与冲突**：国家间为何打仗？国际合作如何可能？全球化带来了什么？

## 模块定位

国际关系（IR）研究的是一个**没有世界政府**的系统——这是它与国内政治的根本区别。在"无政府状态"（anarchy）下，国家如何共存、如何合作、如何冲突？

IR 的魅力在于**三大流派的持续辩论**：现实主义、自由主义、建构主义。它们对同一个现象给出截然不同的解释，而你的任务是理解每派的逻辑、适用条件和盲点。

## 核心追问

1. **战争何以发生？** ——修昔底德陷阱真实存在吗？大国冲突不可避免吗？
2. **合作何以可能？** ——没有世界警察，国家为何遵守条约？（基欧汉的核心问题）
3. **权力是什么？** ——只是军事经济实力？还是观念与身份？（温特的颠覆）
4. **国际制度有用吗？** ——联合国、WTO 是装饰还是约束？
5. **国家是唯一角色吗？** ——跨国公司、NGO、个人在 IR 中扮演什么角色？

## 三大流派速览

| 流派 | 人性假设 | 核心机制 | 代表 |
|------|---------|---------|------|
| **现实主义** | 权力追求，理性自利 | 权力平衡、安全困境 | 摩根索、华尔兹、米尔斯海默 |
| **自由主义** | 理性 + 可进步 | 制度、相互依赖、民主和平 | 基欧汉、奈 |
| **建构主义** | 身份与观念建构利益 | 观念塑造行为体 | 温特 |

**关键分歧**：
- 现实主义 vs 自由主义：制度能否改变国家行为？
- 现实主义 vs 建构主义：利益是给定的还是被观念建构的？
- 三派对"中美关系"的预测完全不同——这是最好的练习场。

## 批判性提示

1. **现实主义不是"真理"**：摩根索/米尔斯海默的预测常有失准（如冷战和平结束）。现实主义的"权力政治"视角强大，但常低估制度、规范和身份的作用。
2. **自由主义不是"天真"**：基欧汉论证制度能降低交易成本、提供信息、改变预期——这有大量经验支持。民主和平论（民主国家不打仗）是最稳健的经验规律之一。
3. **建构主义不是"玄学"**：温特说的"观念建构利益"有具体机制——冷战何以结束？戈尔巴乔夫的观念转变是关键。观念不是虚无，它是行为的塑造者。
4. **"修昔底德陷阱"要慎用**：艾利森的概念流行，但他统计的 16 个案例里，并非都是必然冲突。用历史类比要警惕"决定论"色彩。
5. **西方中心 vs 非西方视角**：主流 IR 理论几乎全由英美学者建构。秦亚青的"关系理论"、阿米塔夫·阿查亚的全球 IR 都是重要补充。
6. **理论与政策的鸿沟**：IR 理论高度抽象，外交决策却充满偶然、个性、危机。理论是地图，不是地形。

## 如何开始

1. 先读奈《理解全球冲突与合作》前 4 章，建立"无政府状态 + 三大流派"的基本图景。
2. 然后挑一个现实案例（如俄乌冲突、中美博弈），分别用现实主义/自由主义/建构主义解释，体会三派的差异。
3. 进阶精读华尔兹《国际政治理论》——它结构极简（不到 200 页核心论证），是理论建构的典范，也是最好的"形式化思维"训练。
