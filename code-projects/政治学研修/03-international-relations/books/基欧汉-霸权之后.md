# 《霸权之后》精读笔记

> 03 国际关系 · 新自由制度主义的奠基 · ⭐ 必读
> 配合 [IR·02 自由主义](../ir-theories/02-自由主义.md) 概览

## 元信息
- **书名**：《霸权之后：世界政治经济中的合作与纷争》（*After Hegemony*）
- **作者**：罗伯特·基欧汉（Robert O. Keohane，1941– ）
- **出版**：1984 年

## 第一层 · 历史脉络
- **70-80 年代背景**：美国霸权相对衰落（越战/石油危机/布雷顿森林体系瓦解）——现实主义"霸权稳定论"预测"霸权衰落=合作瓦解=混乱"。
- **基欧汉之问**：霸权衰落后，国际合作真的瓦解了吗？
- **发现**：没有！国际制度（IMF/GATT/IEA）**仍在维持合作**。
- **理论创新**：即使无霸权，**国际制度**也能促进合作——这就是"**新自由制度主义**"。

## 第二层 · 核心概念

### 1. 国际制度（international regimes）
- 定义：在国际关系特定领域，各国**共同期望的**一套明示或暗示的**原则、规范、规则、程序**。
- 不是"世界政府"，而是**功能性的合作框架**（贸易/金融/环境/安全）。

### 2. 制度促进合作的四大功能
| 功能 | 含义 |
|------|------|
| **降低交易成本** | 提供谈判平台、惯例，避免每次重新博弈 |
| **提供信息** | 减少不确定/欺骗，增加透明 |
| **监督与声誉** | 监督违约，提高"背信"的声誉成本 |
| **议题联动** | 把不同议题挂钩，增加合作回报 |

### 3. 绝对收益 vs 相对收益
- 现实主义重"**相对收益**"（我比你多才算赢）→ 易冲突。
- 基欧汉强调"**绝对收益**"（大家都赚就行）→ 合作的理性基础。

### 4. 对现实主义的修正（不否定）
- 基欧汉**接受**现实主义的三个假设（无政府/国家理性/追求权力）。
- 但**补充**：在无政府下，制度能**降低背叛的诱惑**，使合作从"难"变"可行"。
- 这是"**新-新辩论**"（neo-neo debate）的核心——沃尔兹（新现实主义）vs 基欧汉（新自由制度主义）。

## 第三层 · 文本精读
- **第一章**：问题——霸权衰落后合作能否维持？
- **第二-四章**：国际合作的理论（博弈论/市场失灵/制度功能）。
- **第五-七章**：案例——战后国际经济制度（布雷顿森林/GATT/IMF）的演化。
- **结论**：**制度不消除无政府，但降低其恶果**。

## 第四层 · 应用与当代
1. **国际组织**：WTO/WHO/巴黎气候协定的存在，正是基欧汉论证的实证。
2. **中美竞争**：中美虽竞争，但在气候/贸易/金融上仍需制度框架——基欧汉的理论预言了这种"竞争中的合作"。
3. **制度也在衰退**：近年WTO瘫痪/WHO政治化——基欧汉的框架能解释"制度一旦弱化，合作也随之衰退"。

## 第五层 · 批判
1. **制度能持续吗？** 当大国退出（美国退巴黎/WHO），制度可被架空——基欧汉低估了"大国退出"的破坏力。
2. **制度本身被权力塑造**：建构主义指出，制度不是中性的——强国塑造了制度规则（呼应[批判理论](../ir-theories/04-延伸与当代.md)）。
3. **但奠基性不朽**：**制度促合作的四大功能**——至今是 IR 自由主义的核心工具。

## 一句话
> 基欧汉证明：**即使霸权衰落，国际制度仍能维持合作**——因为它降低交易成本、提供信息、监督声誉。他是**新自由制度主义**的奠基者，是现实主义最重要的对手。
