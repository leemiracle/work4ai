# 《基本无害的计量经济学》精读

> 乔舒亚·安格里斯特 / 约恩-斯特芬·皮施克 (Angrist & Pischke) | 06 方法论 · ⭐ | 精简全栈精读

## 核心论点
**因果推断的核心，是用"自然实验"构造可信的反事实。** 我们永远观察不到同一个人"既接受又没接受处理"的两种状态，但可以通过**随机实验、工具变量、双重差分、断点回归**等"识别策略"，逼近"假如没有处理会怎样"的答案。这就是现代实证社会科学的灵魂。

## 关键概念
- **反事实**（counterfactual）：因果效应 = 实际结果 − "假如没处理"的结果。问题是后者永远观察不到。
- **识别策略**（identification strategy）：用数据逼近反事实的方法——RCT/IV/DID/RDD
- **随机对照试验**（RCT）：金标准——随机分组保证两组可比
- **工具变量**（IV）：找一个只影响"处理"但不直接影响"结果"的工具（如出生季度→受教育年限→收入）
- **双重差分**（DID）：用对照组的前后变化，推断处理组"若无处理"的变化
- **断点回归**（RDD）：阈值上下几乎随机（如得票率 50%），断点跳跃=因果效应
- **LATE**（局部平均处理效应）：IV 估计的是"被工具影响的人"的效应，不是全人群

## 全栈重点

### L1 精读 + 计算（配代码动手学）
本书是**因果推断圣经**，但不是"读完就懂"——**必须动手跑数据**。读法：每读完一个方法，立即跑[配套代码](../code/01-causal-inference.py)里对应的部分。代码用模拟数据设定"真实效应"，让你直观看到"方法能否恢复它"。

### L4 因果检验（全书就是"如何做因果检验"）
本书的独特之处：**它不是讲理论，是教你怎么从数据里"榨出因果"**。

四种方法对应四种"反事实构造"：
| 方法 | 如何构造反事实 | 政治学应用 |
|------|--------------|-----------|
| RCT | 随机分组 | 选举动员实验、政策试点 |
| IV | 用外生工具 | 教育→政治参与（出生季度做工具） |
| DID | 对照组前后变化 | 政策评估（特区/改革） |
| RDD | 阈值上下 | 选举效应（得票率 50% 断点） |

### L7 当代应用（"相关≠因果"的觉醒）
读完本书，你看世界的方式会改变：
- 不再说"X 与 Y 相关，所以 X 导致 Y"——你会问"识别策略是什么？反事实可信吗？"
- 不再轻信"政策有效"的宣称——你会问"有没有对照组？是不是只是趋势？"
- 这就是**因果推断训练给政治学的"免疫系统"**——防止被"看起来有道理但逻辑有漏洞"的结论忽悠

### L8 批判（"识别崇拜"的反思）
本书代表的"因果推断革命"也有批评：
- **"识别崇拜"**（identification fetish）：为了方法精巧而牺牲问题重要性——"用 DID 研究无关紧要的问题"
- **外部效度**：RCT/IV 估计的是特定情境的效应，能推广吗？
- **大问题 vs 好方法**：有些重要问题（如"民主是否促进增长"）无法用精巧识别——怎么办？

**平衡**：方法是工具不是目的。**最好的研究 = 重要问题 + 合适方法**，不是为了方法而方法。

## 一句话
> 因果推断的圣经——它教你的不是"公式"，而是**一种怀疑精神**：面对任何"X 导致 Y"的论断，先问"反事实可信吗？识别策略是什么？"这就是实证科学家的免疫系统。
