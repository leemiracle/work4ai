## 0. 为什么用代码学政治学？

政治学不只是"读文献、写文章"——它的许多核心命题**可以被计算、被模拟、被可视化**：
- 阿罗不可能定理 → 用代码**构造**出悖论；
- 网络权力 → 用图论**算出**谁是把关人；
- 话语极化 → 用文本分析**量化**；
- 合作崩溃 → 用博弈仿真**看见**。

> **代码让政治学从"抽象论证"变成"可操作的实验"**——这正是[计算社会科学](../../../papers/前沿-历史政治学新进展.md)的精神，也是你（数学/AI 背景）的独特优势所在。

## 2. 每个代码的核心发现（bash 实跑输出）

### ① 投票与社会选择
- **Condorcet 悖论**：3 选民 A>B>C / B>C>A / C>A>B → 两两比较出现 **A>B、B>C、C>A 循环**，无 Condorcet 赢家。
- **中位选民定理**：两党从 0.2/0.8 出发，3 步内收敛到 **0.5**（中点）。
- **阿罗直觉**：同一 profile（60 人 A>B>C，40 人 B>C>A），**Plurality 选 A，Borda 选 B**——规则决定赢家。

> **政治学意义**：没有"完美"的投票规则（阿罗不可能定理的直观）；政党会向中位收敛（解释两党制趋同）。

### ② 政治网络分析
- **度中心性**：A/C/E = 0.600（枢纽），F = 0.200（边缘）。
- **聚类系数**：B = 1.000（朋友圈最紧），F/D = 0（松散）。
- **桥边**：`E-F` 是桥——删掉则 F 脱离网络，**E 是把关人（gatekeeper）**。

> **政治学意义**：政治权力 = 网络位置。枢纽（高中心性）有影响力，把关人（桥）控制信息流。这是[计算政治学](../../../docs/个人研究路线.md)方向 B 的入门。

### ③ 文本即数据
- 左翼 top 词：平等/公平/福利；右翼：市场/自由/减税。
- **极化指数 = 1.00**（示例中两阵营无共享词，话语完全隔离）。

> **政治学意义**：可以用文本分析**量化**政党/媒体的话语极化（呼应[民主倒退](../../../papers/前沿-民主倒退与竞争性威权.md)的极化议题）。真实研究用 jieba/LLM 分词。

### ④ 博弈论与演化
- 囚徒困境：T=5 > R=3 > P=1 > S=0 → 背叛是占优策略。
- **演化博弈**：初始合作者 70%，因 T>R（背叛诱惑），**15 代内合作崩溃至 0**。

> **政治学意义**：这是霍布斯"自然状态"（[01 霍布斯](../../../01-political-theory/social-contract/01-霍布斯.md)）和奥尔森"集体行动难题"的形式化——**合作不会自发维持，需制度（利维坦/惩罚/声誉）**。

## 4. 对你（数学/AI 背景）的意义

这 4 个代码是[个人研究路线](../../../docs/个人研究路线.md)的**入门试验场**：
- **方向 A（形式政治理论）**：①投票是社会选择的入门，可扩展到阿罗定理的严格证明、机制设计。
- **方向 B（计算政治学）**：②网络③文本是核心方法，可扩展到真实议员数据/LLM 分析。
- 用你的 PyTorch/数学能力，这些都能做到**研究级深度**。

> **建议**：先跑通这 4 个，理解原理；然后选一个方向（如用真实投票数据复现阿罗，或用 LLM 分析政治文本），做一个 mini 项目——这就是"研究"的起点。

## 5. 扩展练习（给你）

1. **扩展①**：实现更多投票规则（Instant-Runoff、Coombs），构造一个真的"阿罗违反"案例。

4. **扩展④**：实现"以牙还牙"（tit-for-tat）在重复囚徒困境中，看合作如何涌现（Axelrod 经典实验）。
