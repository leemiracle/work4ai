## 一、学科地图：政治学方法论的独特地位

方法论不是政治学的一个"子领域"，而是**所有子领域的免疫系统**。它不研究"政治是什么"，而研究"**我们如何知道政治是什么**"——认识论与方法论的自觉。

没有方法论训练，你会被各种"看起来有道理"的论断淹没。方法论训练让你学会问：
- 这个结论的**证据**是什么？质量如何？
- 有没有**替代解释**？
- **测量**可靠吗？"民主度""治理质量"怎么量化？

## 二、方法论革命史（理解学科的演化）

### 传统阶段（–1950s）：历史与哲学
政治学以历史叙事、法律分析、哲学思辨为主。研究"应当如何"多于"实际如何"。

### 行为主义革命（1950s–60s）
战后美国政治学转向"科学化"——研究**可观察的政治行为**（投票、态度），用统计方法。代表：阿尔蒙德、伊斯顿、达尔。
- 口号："政治学要像物理学一样"
- 价值：引入大样本、可检验命题
- 批评：忽视制度、历史、意义

### 后行为主义（1970s）
对行为主义的反弹——"实证不等于价值中立"。研究者有权也有义务关注**实质的伦理问题**。同时，**新制度主义**复兴（制度不是背景，而是塑造行为的核心）。

### 理性选择革命（1980s）
用**博弈论和经济学方法**研究政治（投票、联盟、立法、官僚）。代表：唐斯、奥尔森、布坎南、谢普斯尔。
- 价值：精致的模型，清晰的预测
- 批评：理性人假设过强；忽视规范与文化

### 因果推断革命（2000s–）
**政治学的方法论灵魂**。核心：相关 ≠ 因果。用自然实验、IV、DID、RCT 识别真正的因果效应。
- 代表：安格里斯特（2021 诺奖）、格林/帕尔谢克《政治学因果推断》
- 影响：APSR、AJPS 的实证论文几乎都用因果推断

### 计算社会科学（2010s–）
大数据 + 机器学习 + 文本挖掘 + 网络分析。新数据源（社交媒体、政府文本）+ 新工具。这是有编程背景者的发力点（详见 [`docs/methodology.md`](../docs/methodology.md) 计算政治学章节）。

## 三、定性与定量的大辩论（KKV 的综合尝试）

这是方法论领域最持久的辩论：

- **定量派**：大样本、统计、可推广、可复制。
- **定性派**：深度、机制、情境、意义。

1994 年 KKV（King, Keachone, Verba）《社会科学中的研究设计》试图综合——主张定性研究也要遵循"科学推断的逻辑"（可控比较、案例选择）。这本书**同时被定量派和定性派批评**，但成为必读。

后续发展：
- **过程追踪**（Process Tracing）：定性研究的"因果推断"武器——在单案例里通过因果链条验证假设（hoop test / smoking gun test）。
- **混合方法**：定量发现规律，定性深挖机制。

**核心洞见**：方法没有高下，只有**是否适合问题**。"影响有多大"用定量；"机制是什么"用定性。

## 四、因果推断的哲学基础：反事实框架

现代因果推断的基石是**反事实框架**（Neyman-Rubin 模型）：

> 因果效应 = （接受处理的个体结果） − （同一个体若未接受处理的结果）

问题：**我们永远观察不到同一个体的两种状态**。因果推断的全部技术，都是在**构造可信的反事实**：

| 方法 | 如何构造反事实 |
|------|--------------|
| RCT（随机实验） | 随机分组保证两组可比 |
| DID（双重差分） | 用对照组的前后变化，推断处理组"若无处理"的变化 |
| RDD（断点回归） | 阈值上下的人几乎可比（如得票率 50%） |
| IV（工具变量） | 用外生工具影响处理，隔离因果 |

**核心忠告**：统计显著 ≠ 实质重要。看效应量，不只看 p 值。

## 五、学习路径（深化版）

### 定量方向
1. 基础统计 + R/Stata
2. 安格里斯特《基本无害》《精通计量》
3. 政治学因果推断专题：格林/帕尔谢克《政治学因果推断》
4. 用 CFPS/CGSS 数据做 mini 研究

### 定性方向
1. KKV《研究设计》
2. 过程追踪方法
3. 案例研究（罗伯特·殷）
4. 田野实践

### 计算政治学方向（有编程基础者强项）
1. Python/R 文本处理
2. 主题模型、网络分析
3. LLM 应用
4. 见 [`docs/methodology.md`](../docs/methodology.md) + 本模块 C 阶段代码

### 跨方法建议
**最好的研究者是问题驱动的**——先有重要问题，再选合适方法。不要为了方法而方法（"为了用 DID 而 DID"是学术病）。
