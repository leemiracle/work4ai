## 0. 为什么 06 模块需要"历史政治学方法论"？

06 模块的方法论三大传统是**定量、定性、形式理论**——这是当代（特别是美国）政治学的主流。但还有第四股日益重要的潮流：**历史政治学 / 历史制度主义**。

它回答定量方法答不了的问题：
- 定量问"**影响有多大**"（大样本、统计）；
- **历史方法问"这个制度/现象是怎么变成这样的"**（长时段、因果机制、路径依赖）。

**中国的政治研究尤其需要历史方法**——因为中国的制度、文化、治理逻辑，都有**深厚的历史沉积**（[04 中国政治](../../04-chinese-politics/00-README.md)讲的"路径依赖"）。不懂历史，就只能看到"现状"，看不懂"为何如此"。

> 一句话：**历史政治学方法论，是研究中国政治（以及任何有漫长历史的国家）的必备工具。本专题把它系统化，并用本项目四个历史专题的真实案例来演示。**

## 2. 历史"要素"的七个维度

当代历史制度主义代表学者**皮尔逊（Paul Pierson）**总结：历史方法中的"历史"，可归纳为**七个时间性要素**：

| 要素 | 含义 | 项目案例 |
|------|------|---------|
| **路径依赖** | 早期选择锁定后续轨迹 | 明代"祖制不可改"锁死改革 |
| **关键节点** | 罕见的开放选择窗口 | 朱元璋废丞相（1380）、龙场悟道（1508） |
| **发生次序** | 事件先后影响结果 | 卫所先崩→募兵→财政崩（明亡链条） |
| **持续时长** | 过程的时间跨度 | 王夫之论郡县"两千年弗能改" |
| **发生时机** | 同一事件在不同时机结果不同 | 张居正改革在万历幼年才能推行 |
| **事件** | 关键转折 | 土木堡之变、攻破天京 |
| **意外后果** | 行动者意图之外的结果 | 秦始皇"私天下"却"行大公"（王夫之论） |

> **这七个要素是历史方法的"工具箱"**。本专题 02 篇会重点展开前两个（路径依赖、关键节点）。

## 3. 历史方法 vs 定量方法：互补而非对立

| 维度 | 定量方法 | 历史方法 |
|------|---------|---------|
| 样本 | 大 N（成千上万） | 小 N（少案例） |
| 目标 | 普遍规律、效应大小 | 因果机制、独特过程 |
| 效度 | 外部效度强（可推广） | 内部效度强（案例内深） |
| 数据 | 统计数据 | 档案、史料、文本 |
| 强项 | 排除随机干扰 | 还原复杂因果、结构 |

**两者不是对立，而是分工**：定量告诉你"平均而言X影响Y"，历史方法告诉你"**在某时某地，X通过什么机制导致了Y**"。**最好的研究，是两者结合**——大样本找相关，历史案例揭机制。

## 4. 一个诚实的警告：历史方法的软肋

历史方法也有被批评的软肋（学界共识）：
1. **"有历史无方法"**：很多自称"历史研究"的，只是**讲故事**，没有严格的因果逻辑。
2. **案例选择偏差**：小N研究容易"挑对自己有利的案例"。
3. **过度依赖二手史料**：不读一手档案，结论不可靠。
4. **"准论证"**：研究者易把**自己的预设**代入历史（[情境比较路径的通病](https://www.rccp.pku.edu.cn)）。

**本专题的态度**：承认这些软肋，并用 [`01一手史料批判`](01-一手史料批判.md) 和 [`04认识论陷阱`](04-以史为鉴的认识论陷阱.md) 来**防范它们**——这才是成熟的历史方法使用者。
