# 05 · 历史政治学研究设计指南：从问题到论文

> 本篇是历史方法论的**落地工具**——把 [`01`–`04`](00-README.md) 的方法，变成**一篇可执行的研究设计（research design）**。学方法是为了用；本篇教你如何用本项目四个历史专题同款的工具，自己设计一篇研究。

---

## 一、为什么需要"研究设计"？

历史方法最易犯的病是"**有历史无方法**"——只是讲故事、发感慨，没有严谨的因果逻辑（[00篇](00-README.md)提过的软肋）。**研究设计就是治这个病的**：它强迫你在动笔前想清楚——**我要回答什么问题？用什么证据？如何排除替代解释？**

好的历史研究，**严谨性不输统计**——关键在于事先把"因果逻辑"设计清楚。

---

## 二、八步研究设计（每步配项目案例）

### 第1步·选问题
- **标准**：①**重要**（关乎真问题，非琐碎）；②**可研究**（有史料可考）；③**有因果悬念**（非纯粹描述）。
- **项目案例**：
  - ✅ 好问题："朱元璋废丞相（1380）如何长期锁定了明清政治的宦官专权？"（重要+可考+因果）
  - ❌ 烂问题："明代有几个皇帝？"（纯描述，无因果）

### 第2步·文献回顾
- 问：前人怎么回答这个问题？我的研究**新在哪儿**？
- 用[史料批判六问](01-一手史料批判.md)分辨一/二/三手文献。

### 第3步·理论框架
- 选一个历史理论的"镜头"：
  - [路径依赖/关键节点](02-历史制度主义.md)？
  - [比较历史/过程追踪](03-比较历史分析.md)？
  - 还是别的（国家能力、合法性、制度锁定…）？
- **项目案例**：研究"明代制度锁死"→用**历史制度主义（路径依赖+正反馈锁定）**框架。

### 第4步·案例选择
- **最相似系统设计（MSSD）**：控制变量，找关键差异。
  - 案例：[张居正 vs 曾国藩](../../docs/张居正与曾国藩对比.md)（都功高，差异在"知退"）。
- **最不同系统设计（MDSD）**：找不同案例的共同点。
  - 案例：[理学 vs 心学](../../05-statesmanship-ethics/wang-yangming/05-批判反思与当代意义.md)（方法相反，都成圣——共同点是"在事上磨"）。
- **警惕**：主动找**反例/半负面案例**，防[案例选择偏差](04-以史为鉴的认识论陷阱.md)。

### 第5步·一手史料
- **铁律**：尽量用一手（档案、当事人亲笔），二手用于理解。
- 用[史料批判六问](01-一手史料批判.md)（第几手？谁写的？有无印证？最早出处？能否知道？有无动机说谎？）。
- **项目案例**：[辨《冰鉴》](../../05-statesmanship-ethics/zeng-guofan/05-冰鉴辨伪与批判反思.md)、[核毛批语页码](../../04-chinese-politics/zizhi-tongjian/01-毛泽东读通鉴的史实与材料.md)。

### 第6步·因果机制（打开黑箱）
- 不要只列"A→B"的链条，要写清**A 通过什么机制导致 B**。
- **项目案例**：废丞相→（决策负担压皇帝）→（皇帝怠政）→（决策真空）→（司礼监代批红）→宦官专权。每步可检验。

### 第7步·过程追踪（检验）
- 对关键步骤做**检验**：
  - **hoop test**（必要条件）：若无A，B还出现吗？
  - **smoking gun**（充分证据）：有无直接证据锁定某因？
- **项目案例**：研究"明亡"，用 hoop 检验"小冰河是否必要因"，用 smoking gun 找"三饷→民变"直接证据链。

### 第8步·防认识论陷阱 + 写作
- 动笔前后，用[读史者自检清单八条](04-以史为鉴的认识论陷阱.md)自检（防六经注我/后见之明/单线类比…）。
- 写作时**严格区分"史实层"与"解释层"**，标注证据强度。

## 三、一个完整示范：研究设计骨架

**研究问题**：朱元璋废丞相（1380）如何长期锁定明清的宦官专权？

| 要素 | 内容 |
|------|------|
| **问题** | 废相→宦官专权的因果机制？ |
| **理论** | 历史制度主义（关键节点+路径依赖+正反馈锁定） |
| **案例** | 明代（关键节点：1380废相）；对照：唐宋（有相权，宦官之祸模式不同） |
| **一手史料** | 《明实录》《明史·职官志》《明会典》；私史《国榷》交叉 |
| **因果机制** | 废相→决策负担压皇帝→皇帝怠政/管不过来→决策真空→司礼监代批红→宦官掌文书+厂卫→宦官专权 |
| **过程追踪** | hoop：若皇帝勤政不怠政（如洪武），宦官能否专权？（检验"怠政"是否必要） |
| **防陷阱** | 防"后见之明"（废相之初未必注定宦官之祸，需恢复当时可能性空间） |

**这就是一篇历史政治学研究设计的骨架**——每一步都对应本专题 [`01`–`04`](00-README.md) 的某个工具。

---

## 四、检查清单：你的研究设计合格吗？

动笔前，用这十条自检：
1. ☐ 问题**重要且可考**吗？（非琐碎描述）
2. ☐ 有明确的**理论镜头**吗？
3. ☐ 案例选择是**MSSD/MDSD** 哪种？控制了什么？
4. ☐ 主动找了**反例**吗？
5. ☐ 主要靠**一手史料**吗？
6. ☐ 因果**机制**写清了吗（非只链条）？
7. ☐ 关键步骤做了**过程追踪检验**吗？
8. ☐ 通过了[读史者自检八条](04-以史为鉴的认识论陷阱.md)吗？
9. ☐ 区分了**史实与解释**？
10. ☐ 标注了**证据强度**（强/中/弱/孤证）？

**全过，你的历史研究才有"科学性"**——这才配叫"研究"，而非"感想"。
