# 06 · 政治学方法论

> **如何研究政治？如何证明一个观点是可靠的？**

## 模块定位

方法论是政治学的"免疫系统"。没有它，你会被各种"看起来有道理"的论断淹没——媒体评论、智库报告、学术论文、朋友圈转发，每个都说得头头是道。

方法论训练让你学会问：
- 这个结论的**证据**是什么？
- 证据的**质量**如何？（相关 vs 因果？样本是否有偏？）
- 有没有**替代解释**？
- 作者的**测量**可靠吗？（"民主度""治理质量"怎么量化？）

详见 [`docs/methodology.md`](../docs/methodology.md) 的横向介绍。本模块是**学习导航 + 实践代码库**。

## 三大传统

| 传统 | 适合的问题 | 工具 |
|------|-----------|------|
| **定量** | "影响有多大？""是否普遍？" | 统计、回归、因果推断、实验 |
| **定性** | "机制是什么？""为何独特？" | 案例、过程追踪、田野 |
| **形式理论** | "理性人会如何博弈？" | 博弈论、空间模型 |

三者互补，不对立。好的研究常混合使用。

## 数据库（动手用）

- **CFPS** 中国家庭追踪调查（北大）——个体政治态度、社会流动
- **CGSS** 中国综合社会调查（人大）——社会态度、信任、参与
- **CHFS** 中国家庭金融调查（西南财经）
- **Polity IV / V-Dem**——全球政体数据
- **国家统计局** data.stats.gov.cn——宏观

## 批判性提示

1. **方法崇拜是病**：学术界有"为了用 DID 而 DID"的现象。**方法服务于问题，不是反过来**。先问"这个问题重要吗"，再问"什么方法合适"。

2. **统计显著 ≠ 实质重要**：大样本下任何微小差异都"显著"。看**效应量**（effect size），不只看 p 值。

3. **测量是隐藏的陷阱**：
   - "民主度"用 Polity IV 量？V-Dem 量？Freedom House 量？结果会不同。
   - "治理质量"用世界银行 WGI？它本身就有意识形态假设。
   - 任何量化都先问：**这个指标真的测了它声称测的东西吗？**

4. **定性 ≠ 不科学**：好的过程追踪有严格的因果检验逻辑（hoop tests / smoking gun tests），其严谨性不输统计。

5. **数据不能自己说话**：
   - 回归结果是"相关"，如何解读为"因果"需要**理论**。
   - 同一份数据，不同理论框架会得出相反结论。理论是先导，方法是工具。

6. **可重复性危机**：政治学也有可重复性问题。读实证研究时，关注它是否公开了数据和代码。

## 如何开始

1. **如果你怕数学**：先读 KKV《社会科学中的研究设计》——它讲逻辑不讲公式，是定性研究者的"科学思维启蒙"。
2. **如果你有数理基础**：直接上安格里斯特《基本无害》——它是因果推断的圣经，写得风趣，案例丰富。
3. **实践**：找一份 CFPS 或 CGSS 数据，问一个具体问题（如"教育是否影响政治信任"），跑一个回归。**动手一次胜过读十本书**。
4. **计划**：本模块将在 v0.3 补充可运行的 R/Python 代码示例，用真实数据演示回归、DID、过程追踪。
