# 02 · 制度经济学：制度如何决定繁荣

> 为什么有的国家富、有的穷？道格拉斯·诺斯和阿西莫格鲁给出了同一个答案的两种版本：**制度是关键**。

---

## 一、诺斯：制度是"游戏规则"

道格拉斯·诺斯（Douglass North，1920–2015，1993 年诺奖）。

### 核心概念
- **制度 = 游戏规则**——人类设计的、约束人际交往的**正式规则**（法律/宪法）+ **非正式约束**（规范/习俗/惯例）。
- 制度**降低交易成本**（让交换更可预期、更安全）。
- **制度是长期增长的关键**——不是技术、不是资本、不是地理，而是**制度**。

### 制度变迁与路径依赖
- 诺斯提出[路径依赖](../../06-methodology/historical-method/02-历史制度主义.md)的经济版——初始制度选择锁定后续发展轨迹。
- 这与[06 历史制度主义](../../06-methodology/historical-method/02-历史制度主义.md)的"锁定"完全一致——**经济史和政治史在这里交汇**。

### 产权保护
- 诺斯认为**产权保护**是增长的制度核心——保护产权→激励投资/创新→增长。
- 反例：产权不保→精英掠夺→无激励→停滞（呼应[Acemoglu"榨取性"](../comparative-politics/03-国家能力与制度.md)）。

---

## 二、Acemoglu：包容性 vs 榨取性

[Acemoglu & Robinson《国家为什么会失败》](../comparative-politics/03-国家能力与制度.md)（已在比较政治讲过，这里从经济学深化）。

### 经济学机制
```
制度类型 → 激励结构 → 行为 → 结果
包容性 → 保护产权/开放机会/创造性破坏 → 投资+创新 → 长期繁荣
榨取性 → 精英垄断/无产权保护/压制创新 → 寻租+掠夺 → 短期增长但长期衰
```

### 关键洞见："创造性破坏"的威胁
- 包容性制度允许**创造性破坏**（熊彼特）——新技术淘汰旧产业。
- 但**榨取性精英害怕创造性破坏**——因为它会动摇其权力基础。所以他们**压制创新**。
- 结果：榨取性制度**短期可增长**（靠资源/模仿），但**长期必然停滞**（无创新）。

### 对中国的判断
- Acemogdu 认为中国是"**增长型榨取**"——短期靠国家动员+出口增长，但**缺乏包容性制度的长期创新激励**。
- 这一判断是否成立，是中国政治经济学的核心争论（呼应[实证论文·中国发展型国家](../../docs/实证论文-中国发展型国家.md)）。

## 三、诺斯 vs Acemoglu：同与异

| | 诺斯 | Acemoglu |
|---|------|---------|
| 核心 | 制度=游戏规则（降低交易成本） | 制度=激励结构（包容/榨取） |
| 方法 | 经济史+路径依赖 | 比较历史+博弈论 |
| 共同点 | **制度是长期繁荣的根本** |

两人合起来：**制度决定激励，激励决定行为，行为决定繁荣**。

## 五、一句话

> 诺斯和 Acemoglu 证明：**制度是长期繁荣的根本**——包容性制度激励创新→繁荣；榨取性制度压制创新→停滞。**技术/资本/地理都重要，但它们被制度框定**。
