# 政治经济学专题 · 权力与财富的交叉

> **02 比较政治 / 政治经济学（PE）**
> 政治经济学追问：**权力如何影响财富分配？经济结构如何塑造政治？** 它是政治学与经济学的交叉地带，是理解"国家与市场"关系的核心工具。

---

## 0. 什么是政治经济学？

如果说[政治理论](../../01-political-theory/)问"权力**应当**如何"，[比较政治](../comparative-politics/)问"不同国家**为何**不同"，那**政治经济学**问的是：
> **"经济利益如何塑造政治行为？政治权力如何决定经济结果？"**

**三大经典传统**：
| 传统 | 核心立场 | 代表 |
|------|---------|------|
| **自由主义** | 市场优先，国家少干预 | 亚当·斯密/李嘉图/弗里德曼 |
| **重商主义/国家主义** | 国家主导，贸易保护 | 汉密尔顿/李斯特/发展型国家 |
| **马克思主义** | 经济结构决定政治，资本主义内在矛盾 | 马克思/沃勒斯坦 |
