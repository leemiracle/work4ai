# 02 · 比较政治学

> **经验性解释**：为什么有些国家民主，有些威权？革命、内战、发展是因何发生？

## 模块定位

比较政治学是政治学的"实验室"。它用**跨国家、跨时间的比较**寻找因果规律——这是**经验性**（empirical）的领域，和政治理论的"规范性"形成对照。

它的核心方法是**受控比较**：通过比较相似但结果不同的案例，隔离出可能的因果因素。摩尔比较三国阶级结构，亨廷顿比较现代化进程，阿西莫格鲁比较制度演化——都是这一思路的典范。

## 核心追问

1. **国家为什么有强弱之分？** ——国家能力从何而来？为什么有的地方是"failed state"？
2. **民主化为何发生？为何倒退？** ——亨廷顿的"三波"与"逆向波"。
3. **现代化带来稳定还是动荡？** ——亨廷顿的悖论。
4. **制度决定发展，还是发展决定制度？** ——阿西莫格鲁 vs 反向因果。
5. **革命与内战的根源？** ——为什么有些冲突走向谈判，有些走向暴力？
6. **威权政体为何能持久？** ——"威权韧性"（authoritarian resilience）辩论。

## 批判性提示

1. **亨廷顿的"秩序优先"争议**：他强调政治稳定先于自由化，被批评为"为威权辩护"。读时要问：稳定是目的还是手段？谁的稳定？
2. **阿西莫格鲁的简化风险**：包容性/汲取性的二分法很漂亮，但历史被剪裁了。批评者指出：他的案例选择支持论点，反例被淡化；因果方向（制度→繁荣 vs 繁荣→制度）也未真正解决。
3. **摩尔阶级还原论**："没有土地贵族就没有民主"——东亚四小龙（韩国、台湾）的经验是否成立？阶级是唯一变量吗？
4. **"民主化"概念本身的西方中心**：民主的定义、测量（Polity IV、Freedom House）都隐含西方自由民主标准。比较时要注意"我们在用什么尺子量"。
5. **案例选择偏差**：比较历史分析常被批评"挑有利案例"。读时要警惕：作者为何选这几个国家？没选的国家会怎样？
6. **文化解释的陷阱**：把一切归于"文化"（儒家、新教伦理）是思维惰性。文化是因还是果？文化与制度如何互构？

## 如何开始

1. 先读亨廷顿《变化社会中的政治秩序》第 1 章（"政治差距"论），体会"问题感"。
2. 注意他 1968 年写的，对照 1960s 第三世界独立浪潮的历史背景。
3. 然后读阿西莫格鲁，带着"亨廷顿会怎么反驳"的视角，构成对话。
4. 把比较政治与中国政治（模块 04）打通：用这些框架看中国经验，看哪里适用、哪里需要修正。
