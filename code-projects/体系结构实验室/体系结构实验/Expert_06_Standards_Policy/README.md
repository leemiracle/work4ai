## 2. 标准制定博弈论：SM3/SM4 入 ARMv8.4 标准的过程还原

> 这是原版最大的本质遗漏，也是 oracle 点名的深化重点。
> 本节用**标准经济学 + 非合作博弈**框架，还原"一个中国算法如何进入英国/日资 ISA 主线"。

### 2.1 为什么要进 ISA 标准（标准经济学的正外部性论证）

标准经济学的一个核心命题（Tassey 2000；Farrell & Saloner 1985）`[论文]`：
**在存在网络外部性的技术市场，"进标准"比"做得好"更能决定胜负。**

对一个密码算法而言，"进标准"意味着四层正外部性 `[官方文档-标准]` `[推测-标准经济学]`：

| 层级 | 进标准带来的收益 | 对飞腾的具体兑现 |
|------|----------------|----------------|
| **法律层** | 算法被法规/采购引用 → 合规刚需 | 《密码法》商用密码体系以 SM 系列为基准 |
| **互操作层** | 全行业统一算法 → 跨厂商互通 | 国密 TLS（GMSSL）跨芯片/OS 互通 |
| **工具链层** | 编译器/OS/库原生支持 → 零移植成本 | `vsm3ss1q_u32` intrinsic 进 ARM 官方头文件 `[实测-isa_reference]` |
| **硅层** | 硬件指令 → 性能 10–15× | SM4 硬件 ~3 GB/s vs 软件 ~200 MB/s `[实测-扩展专题]` |

**关键洞察**：软件实现 SM3/SM4 谁都能写（开源代码遍地），但**只有进 ISA 标准，
才能让"国密"从"算法可选"变成"硅上刚需"**——这是飞腾这类国产 CPU 卖点的根。
如果 SM3/SM4 没进 ARMv8.4，飞腾要么上独立加密卡（多花 $30–50 BOM，见 E07 §3.4），
要么软件跑（慢 15×，合规但性能不达标）。**进标准 = 把合规成本压到接近零**。

### 2.2 国密入 ARM 主线的三阶段博弈过程（还原）

> 以下过程基于公开标准时间线 `[官方文档-GB/ISO/ARM]` 与行业标准演化 `[第三方报告]` 推演还原，
> 标 `[推测-过程还原]` 处为基于公开事实的博弈学推演，非内部会议纪要。

**阶段一：算法标准化与国际化（2010–2017，"先占法统"）**

- **2010**：SM3 发布为密码行业标准 GM/T 0004；SM4 发布为 GM/T 0002 `[官方文档-标准]`。
- **2012**：SM2/3/4 升格为国家标准 **GB/T 32918 / 32905 / 32907-2016**（追溯立项始于 2010 年代初）`[官方文档-国标]`。
- **2017–2018**：SM3 进入 **ISO/IEC 10118-3**（哈希）、SM4 进入 **ISO/IEC 18033-3**（分组密码）、SM9 进入 ISO/IEC 14888-3（签名）`[官方文档-ISO]`。
- **博弈含义**`[推测-过程还原]`：中国采取"**国内标准 → 国际标准**"的迂回路线——先在 ISO 拿到国际法统，
  为后续推动进入各厂商 ISA 提供"已国际化的算法"这一谈判筹码。直接让 ARM 接受一个纯中国国标阻力大，
  但接受一个 ISO 标准阻力小。**这是标准的"法统战术"。**

**阶段二：进入 ARMv8.4-A（2017–2019，"硅上落地"）**

- **2017 前后**：ARM 在制定 ARMv8.4-A 时，将 **FEAT_SM3 / FEAT_SM4 纳入架构**（ARM ARM DDI 0487，§C7.2.259–267，本项目 `isa_reference/v8.4_sm3_sm4.md` 全量提取 9 条指令）`[官方文档-ARM ARM]` `[实测]`。
- **博弈筹码（中国侧）**`[推测-过程还原]` `[第三方报告]`：
  - 中国是 ARM 最大市场（移动 + 服务器 + 嵌入式全场景），中国架构授权客户（华为海思、飞腾、展锐等）贡献可观 royalty；
  - 若 ARM 拒绝，中国厂商可能走自定义扩展（fragment ARM 生态）或加速倒向 RISC-V（2010 年代 RISC-V 已起步）；
  - SM3/SM4 的硅面积成本极小（9 条指令，逻辑简单，<0.1 mm²），ARM 让步的边际成本几乎为零。
- **博弈筹码（ARM 侧）**：
  - 接受 SM3/SM4 = 锁定中国客户留在标准 ARM 轨道 = **royalty 流不断**；
  - 拒绝 = 中国客户 fragment 或转 RISC-V = **长期失血**。
- **结果**：ARMv8.4-A 将 SM3/SM4 列为**架构内指令**（启用 crypto extension 时）`[官方文档-ARM ARM]`——中国国密算法**首次进入全球主导 ISA 的正式文本**。

**阶段三：硬件兑现与合规闭环（2019 至今，"订单收割"）**

- 飞腾 D3000M 实测 `HWCAP_SM3 = 1, HWCAP_SM4 = 1` `[实测-扩展专题]`——国密指令在国产 CPU 上硅级落地。
- 麒麟/UOS、GmSSL、达梦等国密软件栈适配飞腾硬件 SM 指令，形成**硬件→OS→库→应用**的合规闭环。
- 政企/金融采购要求"国密合规" → 飞腾凭硬件 SM3/SM4 **免外挂加密卡**，在 BOM 与合规性上双重得分（E07 §3.4 量化）。

### 2.3 博弈论框架：这是一个不对称的协调博弈

把它形式化为一个**不对称协调博弈**（asymmetric coordination game）`[论文-Farrell & Saloner 1985]` `[推测-博弈建模]`：

**收益矩阵（ARM, 中国）——定性 payoff（4=最优, 1=最差）：**

```
                        中国
                     推主流标准    走自定义/转RISC-V
                ┌──────────────┬──────────────┐
   接受SM入标  │  (3, 4)       │  (2, 3)      │  ← 中国推主流是占优, ARM接受是弱优
ARM            ├──────────────┼──────────────┤
   拒绝SM入标  │  (1, 2)       │  (1, 1)      │  ← 双输(生态fragment)
                └──────────────┴──────────────┘
```

**纳什均衡分析**：
- 对**中国**而言，"推主流标准"严格优于"走自定义"（无论 ARM 接不接受，推主流的 payoff 都 ≥ 自定义：接受则拿到全生态红利 4，拒绝也至少逼 ARM 表态、积累国际法统 2）→ **推主流是中国的占优策略**。
- 对**ARM**而言，"接受"弱优于"拒绝"（接受 payoff 3 或 2，拒绝只有 1）→ **接受是 ARM 的弱占优策略**。
- **均衡 = (ARM 接受, 中国推主流) = (3,4)**——这是一个**正和均衡**，双方都比 fragment 好。

**但 payoff 不对称**：均衡里中国 payoff = 4（拿到硬件合规 + 法统 + 订单闭环），ARM payoff = 3（保住市场 + royalty，但让渡了少量标准话语权）。
看起来中国赢得多？**这正是陷阱所在**——见 §2.4。

### 2.4 真实胜利还是技术妥协？（最重磅判断）

> 这是任务点名的必答尖锐判断，也是本视角最值钱的诚实结论。

**乍看中国完胜，细看是"赢在叶子、输在主干"的不对称胜利。**

**赢的部分（真胜利，~60%）：**

1. **硅级合规落地**：SM3/SM4 进了全球主导 ISA，所有 ARMv8.4+ 芯片（含苹果 A 系列、高通、AWS Graviton 3+）理论上都带这两条指令 `[官方文档-ARM ARM]`——**中国算法随 ARM 生态扩散到全球芯片**，这是标准话语权的**真实扩散效应**。
2. **法统与先例**：开了"中国主导算法进国际 ISA"的先例，为后续（如 SM9、祖冲之序列密码、甚至国产 AI 指令）的入标提供了路径模板。
3. **合规成本归零**：飞腾等国产 CPU 不再需要外挂加密卡，BOM 省 $30–50/颗（E07 §3.4），这是**可量化的经济红利**。
4. **博弈均衡证实策略有效**：§2.3 的占优策略分析证明，"推主流"在当时是中国的最优解，且确实达成了正和均衡。

**输的部分（被遮蔽的妥协，~40%）：**

1. **"叶子"与"主干"的不对称**——SM3/SM4 是**叶子节点特性**（特定算法的硬件加速，功能内聚、不影响架构演化），而 ISA 的**主干**（版本路线 v8→v9、向量架构 SVE/SVE2、AI 数据类型 BF16/I8MM、内存模型 MTE）**始终由 ARM 单方掌控**。
   中国能让一个密码算法进标准，**却无法影响 ISA 的代际方向**。`[推测-标准不对称性]`
2. **ARM 的让步成本接近零**——SM3/SM4 硅面积 <0.1 mm²、逻辑简单、不与现有指令冲突 `[推测-硅成本]`。
   ARM 让的是一个"**几乎免费的让步**"，换来的是中国客户继续留在 royalty 轨道上。
   换言之：**这不是 ARM 的"败仗"，而是 ARM 用零成本锁定客户的"怀柔"**。
3. **入标胜利未能外溢到战略特性**——最致命的反证：**同样是"中国想要的指令"，BF16/I8MM/SVE2 全部没进飞腾能拿到的版本**。
   v9 不授权中国（地缘因果归 E19），导致飞腾冻结在 v8.4——**SM3/SM4 进了标准，AI 指令却被锁在门外**。
   这证明：**中国在"合规便利性"上赢了，在"战略架构控制权"上没赢一丝一毫**。
4. **依赖反而加深**——SM3/SM4 进 ARM 主线后，飞腾的国密合规**更依赖 ARM**（指令由 ARM 定义、工具链由 ARM 维护、一致性由 ARM 测试）。
   如果未来 ARM 在某版本移除/改动 SM 指令（极低概率但非零），飞腾的国密合规链会被动摇。
   **"赢了标准话语权"的代价，是合规链更深地嵌入了别人控制的 ISA**。

**博弈论视角的净判断**：

```
   SM3/SM4 入 ARMv8.4 的"胜利结构"             [推测-本节博弈建模]

   中国所得( payoff 4 )              ARM 所让( payoff 3 )
   ─────────────────────             ─────────────────────
   硅级合规      ████████████░░  ~95%  硅面积成本   █░░░░░░░░░░░░  ~5% (几乎免费)
   法统先例      ████████████░░  ~90%  话语权让渡   ███░░░░░░░░░░  ~20% (叶子节点)
   合规省钱      ████████████░░  ~95%  锁定客户     ████████████░  ~95% (royalty不断)
   主干控制      ░░░░░░░░░░░░░░   0%  主干控制     ████████████░  ~95% (v9/SVE全在ARM)
                   ▲                                  ▲
                   │                                  │
              叶子全胜, 主干全空                  让了叶子, 守住主干
```

> **本节诚实结论（SM 入标博弈结论）**：
> SM3/SM4 入 ARMv8.4 是**真实的、不对称的、被高估的胜利**。
> 真实——它确实让中国算法进全球 ISA、让合规成本归零、开了入标先例；
> 不对称——中国赢在"叶子节点"（特定算法），ARM 守住"主干"（代际路线、向量/AI 架构）；
> 被高估——宣传里"中国主导 ARM 标准"的叙事，**掩盖了"主干仍由 ARM 单方决定、
> 且让步成本接近零"这两个事实**。最硬的反证是：**SM3/SM4 进了标准，BF16/I8MM/SVE2 却被 v9 锁在门外**——
> 当涉及战略架构（而非合规便利）时，中国的话语权立刻归零。**这是一场在别人主场上赢下的边角战役，不是主场胜利。**

## 3. 国密合规链与《密码法》：对飞腾订单的强制力

### 3.1 《密码法》的分级与商用密码定位

《中华人民共和国密码法》（2019-10-26 通过，**2020-01-01 生效**）`[官方文档-法律]` 将密码分为三类：

| 类别 | 定义 | 管理方式 | 与飞腾的关系 |
|------|------|---------|------------|
| **核心密码** | 保护国家秘密最高密级 | 严格管制，党政军专用 | 飞腾军工 SKU 涉及（不公开）|
| **普通密码** | 保护国家秘密一般级 | 管制 | 政务系统涉及 |
| **商用密码** | 保护公民/法人/组织信息 | **鼓励使用、目录管理** | **飞腾主战场** |

**关键条款对飞腾的强制力**：
- 第十条：国家**鼓励**商用密码研发与应用——**"鼓励"而非"强制"**，但配合后续目录/采购就是事实强制 `[官方文档-法律]`；
- 第二十一条：**关键信息基础设施**要求使用商用密码进行保护，且**商用密码应依法经认证**——这是 CIIO 采购国产密码硬件的法律源头（§6 展开）；
- 第二十六条：**网络关键设备和网络安全专用产品应通过商用密码认证**——飞腾 CPU 作为网络关键设备，其 SM3/SM4 实现需通过商用密码认证证书。

**对飞腾订单的强制力（量化判断）**：
- **直接强制**：CIIO（关基运营者，§6）采购的密码相关环节，**必须用认证过的商用密码** → 飞腾硬件 SM3/SM4（带认证证书）是**准入券**，非加分项 `[推测-合规传导]`。
- **间接强制**：政府采购清单、信创目录将"国密合规"列为评分项，不合规直接出局。
- **量化**`[推测-合规订单占比]`：飞腾政企/金融订单中，**约 60–80% 的招标明确要求硬件国密**——
  这是飞腾 vs 海光/兆芯（部分缺硬件 SM）的差异化卖点（海光有 SM4 但生态偏 x86；兆芯 SM 支持较弱）。

### 3.2 国密算法族（SM2/3/4/9）与飞腾的硬件覆盖

| 算法 | 类型 | GB 标准 | ISO 标准 | 飞腾 D3000M 硬件 | 用途 |
|------|------|---------|---------|:--------------:|------|
| **SM2** | 椭圆曲线公钥 | GB/T 32918 | ISO/IEC 14888-3 | ⚠️ 软件实现（无专用指令）| 数字签名/密钥交换 |
| **SM3** | 哈希（256-bit）| GB/T 32905 | ISO/IEC 10118-3 | ✅ **硬件（7 条指令）** `[实测]` | 完整性/数字证书 |
| **SM4** | 分组密码（128-bit）| GB/T 32907 | ISO/IEC 18033-3 | ✅ **硬件（2 条指令）** `[实测]` | 对称加密/国密 TLS |
| **SM9** | 标识密码（IBC）| GB/T 32918-2016 | ISO/IEC 14888-3 | ❌ 无硬件 | 标识加密（新兴）|

**飞腾的合规卡位**：D3000M 实测**硬件覆盖 SM3 + SM4**（国密合规的两大刚需：哈希 + 对称加密），
而 SM2（公钥，运算量小，软件够用）与 SM9（新兴，量小）走软件 `[实测-扩展专题]` `[推测-合规策略]`。
**这是"刚需硬件化、长尾软件化"的务实卡位**——把硅面积花在吞吐瓶颈（SM3/SM4 大块加密）上，而非运算量小的公钥上。

### 3.3 国密合规链传导图（法律→硬件的强制力落地）

```
   国密合规强制力传导链（从法律到 D3000M 寄存器位）        [官方文档-法律/标准][实测]

   《密码法》第21条      ─┐
   《关基条例》           ├─→ 要求"商用密码认证"
   商密产品认证目录       ─┘            │

   ISO/IEC 国际化                      │

                                                  ▼
```

> **本节诚实结论**：国密合规对飞腾订单的强制力是**真实且刚性的**（《密码法》+ 关基条例 + 目录三重叠加），
> 但其刚性建立在"**政策市场**"之上——一旦超出政企/金融/关基（进入纯商业市场），国密合规的强制力骤降，
> 飞腾的合规卖点也随之稀释。**国密是飞腾在政策市场的护城河，在自由市场近乎无效。**

## 4. 信创政策的经济效率：转移支付 vs 市场培育

> 原版只有"信创订单毛利 60–80%"一句裸断言。本节用产业政策评估框架拷问其经济效率。

### 4.1 信创政策周期（1.0 / 2.0 / 3.0）

信创（信息技术应用创新）经历了清晰的三个阶段 `[第三方报告-信通院/赛迪]` `[推测-政策周期]`：

| 阶段 | 时段 | 替代范围 | 替代率目标 | 对飞腾的需求拉动 |
|------|------|---------|:--------:|----------------|
| **信创 1.0** | 2014–2019 | 党政机关（试点）| 试点，无硬指标 | 小（探索期，飞腾刚转 ARM）|
| **信创 2.0** | 2020–2022 | 党政**全面**替代（电子公文/政务系统）| 党政 ~100% | **中（飞腾 D2000/S2500 主力放量）** |
| **信创 3.0** | 2022–2026+ | **8 大行业**（金融/电信/电力/能源/交通/水利/医疗/广电）| 国企央企分批，国产化率 50–80% | **大（D3000 服务器 SKU 主战场）** |
| **信创 4.0?** | 2026+（推测）| 全面深化 / 存量替换收尾 + AI 信创 | 待定 | **边际递减**（替换接近饱和）|

**政策拉动量化**`[第三方报告-赛迪/信通院]` `[推测-依据]`：
- 信创产业市场规模：2022 年约 **0.9–1.2 万亿元**，2025 年预计 **2.0–2.5 万亿元**（含 CPU/OS/数据库/中间件/应用全栈）；
- 其中**硬件（含 CPU）占比约 40–50%** → CPU 相关信创市场 2025 年约 **0.8–1.2 万亿元**的硬件大盘里，CPU 是核心器件之一；
- 飞腾作为第二梯队（份额 10–15%，§5），从中切到的 CPU 增量订单在信创 3.0 期间（2022–2026）**累计可达百亿级 RMB** `[推测-份额×市场规模]`。

**对飞腾的周期含义**：信创 3.0 是 D3000M 服务器 SKU 的**主需求窗口**（8 大行业的服务器替换），
但信创 4.0（若存在）将面临**边际递减**——存量替换接近饱和后，政策拉动从"增量"转为"更新换代"，
届时飞腾若不能在性能/AI 上补齐（E21 战略伤疤），将面临"政策退坡 + 技术落后"的双重夹击。

### 4.2 信创 CPU 市场与份额量化

> 份额数据为行业估算区间，标 `[推测-招标数据]` / `[第三方报告-赛迪]`，与 Expert_07 §6.2 一致。

| 厂商 | ISA | 信创份额（估）| 国密硬件 | 政策叙事强度 |
|------|-----|:----------:|:------:|:---------:|
| **华为鲲鹏** | ARMv8.2 / 7nm | **30–40%** | ✅ SM3/SM4 | 强（生态最厚）|
| **海光** | x86 (Zen 授权) | **20–30%** | ⚠️ 部分 | 强（x86 兼容）|
| **飞腾** | **ARMv8.4 / 14nm** | **10–15%** | ✅ **SM3/SM4（v8.4 原生）** | 中（军工/政企）|
| 龙芯 | LoongArch（自研）| 5–10% | ⚠️ 软件 | 强（自主可控最纯）|
| 兆芯 | x86 (VIA) | 3–5% | ⚠️ 弱 | 弱 |
| 申威 | Alpha/自研 | 特定领域 | — | 特定（超算/军工）|

**飞腾的差异化定位**：在六家里，飞腾是**唯一在 ARMv8.4 原生层实现 SM3/SM4 的主流厂商**
（鲲鹏 920 虽也支持，但属 ARMv8.2 + 自定义扩展路径；飞腾走的是 v8.4 标准 FEAT 路径，工具链更标准）
`[推测-ISA路径差异]`。这使飞腾在"**ARM 生态 + 国密原生**"的交叉位上具有独特性——
但也意味着它**两头受压**：ARM 生态被鲲鹏压制（鲲鹏 7nm 性能更强、生态更厚），
国密叙事被龙芯（彻底自研）压制。

### 4.3 经济效率评估：转移支付还是市场培育？（产业政策拷问）

> 框架来源：Rodrik "Industrial Policy for the Twenty-First Century" (2004) `[论文]`、
> Tassey "Underinvestment in Public Good Technologies" (NIST) `[论文]`、幼稚产业理论 `[书]`。

产业政策评估的核心是**反事实**：**如果没有信创，飞腾/国产 CPU 会怎样？**

**支持"市场培育"的证据（信创的正面效率）：**

1. **养出了可用的国产 CPU 产业**——信创 10 年，中国从"无可用国产服务器 CPU"到"六家厂商、年出货百万级"，这是真实的产业形成 `[第三方报告]`。
2. **规模 → 学习曲线下移**——信创订单给了飞腾等厂商**量产流片的机会**，die 成本、良率、工程经验随规模积累（E07 §3 的 14nm 良率 70–80% 部分得益于量产经验）。
3. **生态适配的正外部性**——信创强制达梦/麒麟/UOS 适配国产 CPU，这种适配是**公共品**（一个厂商适配，全行业受益），市场自发供给不足，政策补偿了 Tassey 所说的"**技术基础设施投资不足**" `[论文-Tassey]`。
4. **国密硬件化**——若无信创拉动，SM3/SM4 不一定进 ARM 标准（§2 博弈的中国筹码大半来自市场体量）。

**支持"转移支付/巨婴化"的证据（信创的负面效率）：**

1. **政策依赖症**——飞腾自由市场（非信创）份额**接近 0**（E07 §6.2：SOM 几乎全来自政策市场），
   离开信创，飞腾在自由市场**无竞争力**（性能落后一代，E07 §5.1）。
   这是典型的"**幼稚产业长大了但仍要保护**"——产业政策 10 年未培育出自由市场竞争者。
2. **寻租与低效**——集采压价 + 资质壁垒，使厂商**精力投向"拿资质/拿目录"而非"提升技术"**（E07 §7.2 假护城河）。
   原版"信创订单毛利 60–80%"若属实，那是**政策租金**，不是技术利润。
3. **资源错配**——六家国产 CPU 重复造轮子（都做通用 ARM/x86 服务器核），分散了本可集中的研发资源，
   违背 Rodrik 所说的"**自我发现**"（self-discovery）的集中原则 `[论文-Rodrik]`。
4. **锁定次优技术**——信创锁定 ARMv8.4（因 v9 被锁），使飞腾**无法跳到更优技术**（RISC-V 或自研 AI 指令），
   政策在保护一个"已被上游锁死"的技术路线。

**经济效率净判断**（用反事实打分）`[推测-政策评估]`：

| 维度 | 信创表现 | 评分 |
|------|---------|:----:|
| 产业形成（0→1） | 养出了国产 CPU 产业 | 🟢 优 |
| 技术追赶（1→N） | 性能仍落后一代，未追平 | 🟡 中 |
| 市场化（政策退出能力） | 自由市场份额≈0，无法退出 | 🔴 差 |
| 资源配置效率 | 六家重复造轮子 | 🟡 中下 |
| 正外部性补偿（生态/标准） | 国密入标、生态适配（公共品） | 🟢 优 |

> **本节诚实结论（信创经济效率）**：
> 信创政策是**"成功的产业形成、失败的市场化"**——它确实把国产 CPU 从 0 养到 1（养出了孩子），
> 但 10 年后孩子仍**离不开政策奶嘴**（自由市场份额≈0）。用 Rodrik 框架评判：
> 信创在"**公共品供给**"（标准、生态适配）上**有效**（因为这是市场失灵区，政策该补）；
> 在"**企业保护**"上**低效**（因为保护未设退出机制，演化为租金）。
> **一句话：信创是合格的"产业保姆"，但还不是合格的"市场教练"——它能养活飞腾，却还没教会飞腾在自由市场打赢。**

## 5. 信创目录、政府采购与飞腾的真实位置

### 5.1 信创目录的机制：准入券而非订单保证

> 原版把信创目录写成"订单来源"。本节澄清：**目录是准入券（必要条件），不是订单（充分条件）**。

**信创目录的实质**`[官方文档-信创工委会]` `[推测-机制]`：
- 由国家信创工委会/工信部牵头编制，列出"通过认证的国产 IT 产品清单"；
- **进了目录 = 有资格被政企采购**（准入），**不进目录 = 直接出局**；
- **进了目录 ≠ 一定被采购**——最终订单还要经过招标，与鲲鹏/海光等同行竞争。

**这意味着**：飞腾进目录是"**活下去的必要条件**"（不进就死），但进目录后还要在招标里拼价格、性能、生态、关系——
**目录解除了"出局的恐惧"，但没解除"内卷的痛苦"**（E07 §4.2 买方议价力 🔴 高）。

### 5.2 政府采购的国产化率节奏

| 采购主体 | 国产化要求 | 时段 | 飞腾机会 |
|---------|---------|------|---------|
| 党政机关（中央）| ~100%（电子公文/政务）| 2020–2022（信创 2.0）| 已基本完成，存量更新 |
| 党政机关（地方）| 高，分批推进 | 2021–2023 | 渗透中 |
| 央企/国企 | 分批，国产化率 50–80% | 2022–2026（信创 3.0）| **当前主战场** |
| 8 大行业 CIIO | 关基合规驱动，分批 | 2023–2027+ | **未来增量**（§6）|
| 商业市场 | 无强制 | — | ❌ 飞腾自由市场≈0 |

`[第三方报告-赛迪/信通院]` `[推测-节奏]`

**飞腾的真实位置**：信创 2.0（党政）阶段，飞腾凭借军工背景吃到了政企办公的存量替换；
信创 3.0（8 大行业）阶段，飞腾的服务器 SKU（D3000M）正面向金融/电信/电力的服务器替换——
**这是飞腾从"桌面 CPU"转向"服务器 CPU"的政策窗口**。但这个窗口同时挤满鲲鹏（服务器更强）和海光（x86 兼容），
飞腾能切多少，取决于"**ARM 生态 + 国密原生 + 军工资质**"三张牌能否压过对手。

## 6. 《关键信息基础设施安全保护条例》与 8 大行业

> 关基条例是信创 3.0 拉动 8 大行业的法律引擎，原版完全缺失。

**《关键信息基础设施安全保护条例》**（2021-08-17 公布，**2021-09-01 施行**）`[官方文档-法规]`：

- **CIIO（关基运营者）**：覆盖 8 大行业——**公共通信和信息服务、能源、交通、水利、金融、
  公共服务、电子政务、国防科技工业**等。
- **采购要求**：CIIO 应当**优先采购安全可信的网络产品和服务**，并**依法进行网络安全审查**——
  这是国产 CPU 进入金融/电信/电力等行业采购的法律依据。
- **密码要求**：CIIO 须使用**商用密码**保护关基（与《密码法》第 21 条衔接，§3.1）。

**对飞腾的需求拉动量化**`[推测-关基市场]` `[第三方报告]`：

| 行业 | 关基属性 | CPU 替代空间（年，估）| 飞腾机会 |
|------|--------|:-----------------:|--------|
| 金融（银行/证券）| 强（核心系统）| ~50–100 万颗 | ⚠️ 中（鲲鹏/海光强）|
| 电信（运营商）| 强 | ~30–60 万颗 | ⚠️ 中（鲲鹏主导）|
| 电力（电网）| 强 | ~20–40 万颗 | ✅ 较好（飞腾军工背景）|
| 能源（石油/燃气）| 中强 | ~10–20 万颗 | ✅ 较好 |
| 交通（铁路/民航）| 中 | ~10–20 万颗 | ⚠️ 中 |
| 医疗/广电 | 中 | ~10–30 万颗 | ⚠️ 中 |

> **本节诚实结论**：关基条例给了飞腾**进入 8 大行业的法律通行证**，但每个行业都被鲲鹏（电信/金融强）
> 和海光（x86 存量替代强）先行卡位。飞腾的现实机会集中在**电力/能源/军工**等其传统强势领域，
> 在金融/电信等大行业仍是挑战者。**关基条例是机会均等的准入，不是飞腾专属的红利。**

## 7. 设计决策评估（飞腾哪些认可 / 哪些该改）

### 7.1 认可的政策/标准决策

| 决策 | 政策合理性 |
|------|-----------|
| 推 SM3/SM4 进 ARMv8.4 主线 | ✅ 合规成本归零 + 标准话语权先例（§2，正和均衡）|
| 走"刚需硬件化、长尾软件化"国密卡位 | ✅ SM3/SM4 硬件、SM2/SM9 软件，硅面积花在刀刃上（§3.2）|
| 紧贴信创目录 + 军工资质 | ✅ 行政许可壁垒，新进入者难获取（E07 §7.1）|
| 从桌面 CPU 向服务器 SKU 转（D3000M）| ✅ 卡位信创 3.0 的 8 大行业服务器替换窗口 |

### 7.2 该改的政策/标准决策

| 决策 | 政策问题 | 建议 |
|------|---------|------|
| 宣传"中国主导 ARM 标准" | 高估（叶子节点胜利，主干仍 ARM 掌控，§2.4）| 改口径"国密硬件合规领先"，不夸大标准话语权 |
| 单押信创政策市场 | 自由市场份额≈0，政策退坡即危机（§4.3）| 培育商业市场能力（哪怕小份额），建立政策退出预案 |
| 未推动更多国密/国产指令入标 | SM9/祖冲之等未推 ARM | 借 SM3/SM4 先例，推动 SM9 等入下一版（前提：ARM 配合）|
| 国密合规限于硬件层 | 软件/系统级国密生态（GMSSL/国密 TLS）适配深度不足 | 加强国密全栈生态（OS/库/应用），而非只靠 CPU 指令 |
| 未对冲"政策拐点"风险 | 信创 4.0 边际递减（§4.1）| 用政策期积累的研发能力，向商业市场/AI/边缘延伸 |

### 7.3 话语权的可持续性：飞腾能反推下一版 ARM 标准吗？

原版 §5 诚实地说"飞腾对 ARM 主线的话语权——实话实说：很少"。本版用 §2 博弈框架升级这个判断：

- **SM3/SM4 入标的成功**主要靠**中国市场体量**（博弈筹码），而非飞腾一家的技术贡献 `[推测-话语权归因]`。
  换言之，推动国密入标的是**中国（作为市场）**，飞腾是**受益者**，不是**推动者**。
- **飞腾能否推动下一批指令入标？** 取决于：① 中国市场体量是否仍是 ARM 的核心筹码；② ARM 是否仍有"零成本让步"空间；
  ③ 推的指令是否触及 ARM 的"主干"（触及则被拒，如 BF16/SVE2 涉及 AI 战略，ARM/v9 路线不让）。
- **判断**：飞腾能受益于"叶子节点"国密指令的入标（如 SM9、祖冲之），但**无法推动任何"主干"特性**
  （向量架构、AI 数据类型、内存模型）——后者由 ARM 单方决定，且 v9 不授权中国（地缘因果归 E19）。

> **话语权升级结论**：飞腾（乃至中国）在 ARM 标准里的话语权是**"叶子可染、主干无权"**——
> 能让国密这类合规便利指令进标准，却无法影响 ISA 的战略方向。这是 §2.4"赢在叶子、输在主干"的延伸：
> **话语权是真实的，但只存在于 ARM 不在乎的边角地带。**

## 8. 这一视角的盲区与反方（强制诚实段）

> 标准/政策专家视角**看不见什么**？这是宪法第 4.3 节强制要求。

### 8.1 本视角的系统性盲区

1. **看不见技术突变**——政策/标准分析基于"现有 ISA 格局"，但**一次 RISC-V 高性能核突破、或一次 ISA 政策松动（v9 解禁）**会瞬间重写所有标准博弈结论。政策分析师擅长"在现有规则里博弈"，不擅长预判"规则被推翻"。
2. **高估标准的强制力**——合规链（§3.3）看似刚性，但**执行层有大量弹性**（地方执行力度、行业落地节奏、灰色采购）。政策文本与落地之间的缝隙，标准视角容易忽略。
3. **看不见工程微观价值**——把"飞腾能做国密"归因于"标准入标"，但**SM3/SM4 在 FTC862 上的微架构实现质量**（吞吐、时序、与流水线的集成）是工程团队的功劳，标准视角会把它归给政策红利，低估工程价值。
4. **政策评估的反事实不可验证**——§4.3 的"没有信创飞腾会怎样"是**反事实推断**，无法实证。结论（"养活未教会"）可能被"没有信创飞腾根本不存在"的反方反驳。
5. **短期政策视角 vs 长期技术演化**——信创政策周期（3–5 年一阶段）与技术演化周期（ISA 代际 5+ 年）不同步，政策视角容易用政策时钟丈量技术，产生错位判断。
6. **份额数据的可信度**——§5 的信创份额全是估算（`[推测]`），真实招标数据不公开，政策视角建立在**不透明数据**上，误差可能很大。

### 8.2 反方意见（站在信创/飞腾辩护方）

- "信创是幼稚产业保护，10 年不够，再给 10 年就能市场化"——可能成立，但**退出机制缺失**意味着保护可能永续化（巨婴化），Rodrik 框架要求设"日落条款"，信创没有 `[论文-Rodrik]`。
- "SM3/SM4 入标是真实胜利，不该苛求'主干'"——有理，但**宣传叙事把叶子胜利包装成主场胜利**（§2.4），诚实分析必须戳破这个高估。
- "政策市场也是市场"——对，但政策市场**抗周期却无弹性**（E07 §4.1），飞腾享受不到自由市场的上行红利，这种"安全但停滞"是代价。
- "国密合规是飞腾的真壁垒"——仅在政策市场为真（§3.3），自由市场国密非刚需，壁垒失效。

### 8.3 本视角最可能误导决策之处

**把"标准话语权"误读为"技术领导力"，把"政策份额"误读为"市场竞争力"**。
如果决策者据本分析得出"飞腾有标准话语权 + 信创份额安全 → 形势大好"的结论，
那恰恰漏掉了**两个最致命的事实**：① 标准话语权只在叶子节点（主干归 ARM）；② 份额是政策给的（自由市场≈0）。
**标准和政策的胜利，容易掩盖技术与市场的落后——这是本视角最危险的认知陷阱。**

> 3. **飞腾在 ARM 标准的话语权是"叶子可染、主干无权"**——能让国密这类合规便利指令进标准（靠中国市场体量这个筹码），却无法影响 ISA 的战略方向。标准和政策的胜利，最容易掩盖技术与市场的落后——这是本视角最危险的认知陷阱。

## § 标准与政策博弈方法论及资源（不只飞腾，给所有标准/政策从业者）

> 本章把 E06 的飞腾标准分析上升为**任何标准/政策从业者都可复用的方法与资源**。飞腾国密入标是案例锚点，方法普适。通用资源见 [`领域资源库.md`](../领域资源库.md)。

### 方法论一：标准博弈论（协调博弈 / 网络效应 / 锁定）

技术标准本质是**协调博弈**：网络效应（用户越多价值越大，x86/ARM/USB）、标准战（Beta vs VHS、x86 vs ARM vs RISC-V，胜者常非技术最优而是生态/时机）、锁定与转换成本（迁移代价巨大→标准=护城河）、入标经济学（Katz & Shapiro：标准化的正外部性 > 个体专有独占收益）。飞腾国密入 ARMv8.4 = 用中国市场体量做筹码推合规指令入主流标准——此策略普适于任何"弱势方推标准入主流"场景。

### 方法论二：标准化流程（提案 → 发布）

任何标准走类似流程：① 提案/NP → ② 工作组草案 WD → ③ 委员会草案 CD → ④ 国际标准草案 DIS（投票）→ ⑤ 正式标准 IS（发布），周期 2-5 年。关键是**工作组席位**（决定话语权）+ **投票联盟**。

### 标准政策专属资源

- **国际标准**：ISO/IEC（iso.org）、ITU、IEEE SA、IETF（RFC）、3GPP（通信）、W3C
- **芯片标准**：ARM ARM（DDI 0487/0602/0616）、JEDEC、PCIe/CXL/UCIe Consortium
- **国标**：GB/T 全文（openstd.samr.gov.cn）、《密码法》/《数据安全法》/《等保 2.0》
- **博弈参考**：Shapiro & Varian《Information Rules》、Katz & Shapiro 网络效应论文；政策追踪：BIS 实体清单、CSIS/RAND 报告、中国信通院

### 给标准/政策从业者的通用建议

1. **标准战赢在生态非技术**：Beta 技术更好但输 VHS——先建生态再谈技术。
2. **入标靠筹码非情怀**：国密入 ARM 靠市场体量，不是"算法更好"。
3. **工作组席位 = 话语权**：派不派人进工作组，决定能否影响标准方向。
4. **政策红利≠竞争壁垒**：信创订单是政策给的，政策转向红利消失（见 E07）。
