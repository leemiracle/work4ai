 飞腾 D3000M 浮点精度与 bit-diff 实测  (Expert_08_Numerics)
 N_SUM=1000000  N_DOT=4096   NEON=1  FP16=1
==============================================================

【实验 A】求和算法的相对误差（理论真值 ≈ 100.9999）
  理论真值(FP64) : 100.9999000000
  朴素 FP32 求和 : 100.754517   相对误差=2.430e-03
  Kahan 补偿求和 : 100.754517   相对误差=2.430e-03
  配对(树状)求和 : 100.999893   相对误差=6.744e-08
  Kahan vs 朴素 ULP 差 : 0
  → 朴素求和的「大数吃小数」：1.0 + 1e-4 时 1e-4 被部分吞掉

【实验 B】点积 bit-diff（同一代码、同一输入，仅 -O 不同）
  维度 N=4096，FP32

  dot_naive (标量串行) = 1040.90429687500000   bits=0x44821CF0
  dot_neon  (NEON 4路) = 1040.90429687500000   bits=0x44821CF0
  标量 vs NEON ULP 差  = 0  (累加顺序不同)

  提示：用不同 -O 各编译一份，比较 dot_naive 的 bits：
    -O0/-O1/-O2 通常 bit-exact；-O3 向量化后 ~1-3 ULP；
    -ffast-math 允许重关联，差异可能 >>10 ULP。

【实验 C】精度档位的范围与精度代价（无 BF16 之痛）
  C1 范围测试：求和 [60000, 6000, 6000, 6000] = 78000 (>65504)
    FP32  : 78000   (精确)
    BF16  : 78336   (范围=FP32，无溢出) [飞腾硬件不支持]
    FP16  : 有限   (60000+6000 超 65504 → +Inf 溢出!) [飞腾硬件支持]
  C2 精度测试：1000000 个 [0.1,1.0] 值累加
    理论真值(FP64)=549882.8
    FP32 累加 : 549883.4   相对误差=1.115e-06
    BF16 模拟 : 256.0   相对误差=9.995e-01  (尾数仅7位，小增量被吞)
    FP16 累加 : 2048.0   相对误差=9.963e-01  (和>2048 后增量<ulp 被吞，静默饱和)

  → 两条铁律：
    1) 范围：BF16=FP32(±3.4e38)，FP16 仅[6e-5,65504]。大动态范围→FP16 必崩。
    2) 精度：均匀小量累加时，FP16(10位尾数)比 BF16(7位)更准——但都远逊 FP32。
    ML 现实：梯度动态范围跨 10+ 数量级，FP16 易溢出/下溢 → 需 loss-scaling；
             BF16 用范围换精度，免 loss-scaling → 训练更稳。D3000M 两样都没有原生 BF16。

【实验 D】FMA 融合乘加（省一次舍入）
  分离 mul+add : 0.0000000000e+00   bits=0x00000000 (两次舍入，2^-46 被丢→0)
  fmaf() 单舍入 : 1.4210854715e-14   bits=0x28800000 (一次舍入，保住 2^-46)
  ULP 差       : 679477248  (一个=0，一个≠0)
  → 数学真值=2^-46≈1.4e-14。fmaf≈真值(非零)，分离=0。
    FMA 更准但改了 bit；-ffast-math 会把 mul+add 自动收缩成 FMA，破坏 bit-exact。
    （飞腾 NEON 的 FMLA 指令即硬件 FMA，与 fmaf 等价单次舍入）

【性能】朴素 vs Kahan 求和耗时（N=1000000，FP32）
  朴素 : 0.23 ms
  Kahan: 0.38 ms  (补偿的代价：~3-4× 慢)

==============================================================
 结论速查：
  · 需要 bit-exact 可复现 → 用 -O2，禁 -ffast-math，禁 -O3 向量化
  · 需要 FMA 精度但可复现 → 显式 #pragma STDC FP_CONTRACT ON/OFF 控制
  · 科学计算(CFD/FEM)     → FP64 + Kahan，绝不 -ffast-math
  · ML 推理(飞腾无BF16)   → FP16 + loss-scaling，或 INT8 + 校准
  · 密码学(SM3/SM4)       → 硬件指令 bit-exact，不受 -O 影响
