超标量处理器：每周期可以同时发射并执行多条指令【4-wide = 每周期最多从指令流中取出 4 条独立指令，并行发射到不同执行单元。】
- RAW (Read-After-Write) 依赖链：add → cmp → b.ne 但为什么还是 1 cycle？
  - 现代 CPU 的循环展开和寄存器重命名
    - 每轮迭代使用不同的物理寄存器，消除 WAW/WAR 依赖！
    - 分支预测器提前知道要跳转，所以 b.ne 不等待 cmp 结果——预测正确就继续，错误才刷新流水线。
- 原始硬件事件（RAW）：
    L1D_CACHE_REFILL (0x03) / L1D_CACHE (0x04)：L1 数据缓存重填与访问
    L2D_CACHE_REFILL (0x17)：L2 数据缓存重填
    BR_MIS_PRED (0x10) / BR_PRED (0x12)：分支误预测与分支预测总次数
    STALL_FRONTEND (0x23) / STALL_BACKEND (0x24)：前端、后端停顿周期
    ASE_SPEC / NEON (0x74)：SIMD/浮点指令执行数
- 缓存共享拓扑：缓存内部的组织方式是 “组相联”（Set‑Associative）。把一个缓存分成很多个 组（Set），每个组里有固定的几个槽位可以存放数据，每个槽位叫一个 路（Way）
  - 每核：L1-I (64KB) + L1-D (64KB)  →  L2 (512KB) 统一 【L1、L2 私有：单线程优化（减少冲突失效）的着力点，尽量让热数据在 64+512KB 内周转】
  - 每簇（4核）：L3 (4MB) 共享【4 核协同工作（如 OpenMP 线程组）时，通信只需经过 L3，延迟低于跨簇访问】
  - 全片（8核）：L4 (8MB) 系统缓存，最后一级缓存【对多程序或多线程吞吐量至关重要】
乱序执行：指令执行顺序与指令流中的顺序不一致，但最终结果与顺序执行一致。
指令流水线：将指令的执行过程划分为多个阶段，每个阶段由不同的执行单元完成，从而提高处理器的性能。
指令缓冲区：用于存储正在执行的指令，包括已发射但未完成的指令。
指令窗口：指令缓冲区中的一部分，用于显示当前正在执行的指令。
指令队列：存储待执行的指令，包括已发射但未完成的指令。
指令流：程序中按顺序排列的指令序列。
