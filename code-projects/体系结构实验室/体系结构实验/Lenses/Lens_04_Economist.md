# Lens_04 — 用经济学家的眼睛看飞腾

> **范式**：**产业组织经济学（Industrial Organization）** + **平台经济学（Platform Economics）** + **半导体经济周期理论**。
> 不写"飞腾卖多少钱"（那是 Expert_07 的地盘），而是回答一个更冷的问题：**为什么 CPU 这个行业天然只容得下两三家？为什么飞腾即使技术不差、也注定是边缘玩家？经济学规律允不允许飞腾"逆袭"？**
>
> 用的不是 SWOT、波特五力这种商学院套话，而是 **Tirole 工业组织理论、Parker/Van Alstyne 平台革命、Spengler 双重边际化、Kaldor 蛛网周期**——把这些 named framework 拍在 D3000M 这颗具体的芯片上。
>
> **为什么从业者看不见**：微架构师的世界观是"只要 IPC 提上去、功耗降下来，就能赢"。但经济学告诉我们，**芯片业成败 70% 由规模经济与网络效应决定，PPA 只占 30%**。FTC862 这颗 4-wide 核做得再漂亮，如果销量不够分摊 7nm 流片的 $300M 固定成本，如果 ARM 生态的网络效应把客户锁死在鲲鹏侧，如果信创这个"市场"的价格信号是失真的——**那么微架构的精进只是在给一个注定小众的产品抛光**。经济学家看的不是这颗核几 wide，而是**这颗核所处的市场结构，结构决定命运**。

## 1. 这个范式的核心逻辑（6 个 named framework）

经济学家用六个框架解释"为什么 CPU 市场长成现在这样"：

### ① 规模经济与自然垄断（Natural Monopoly / Economies of Scale）

芯片设计是教科书级的**高固定成本 + 低边际成本**行业。

| 成本类型 | 金额 | 来源 |
|---------|-----:|------|
| 7nm 设计 + 验证 NRE | ~$300M | `[报告-McKinsey/SIA 2020+]` |
| 3nm 设计 + 验证 NRE | ~$1.0-1.5B | `[报告-SemiAnalysis 2023]` |
| 7nm 掩模版（mask set） | ~$15M | `[报告-IBS]` |
| 3nm 掩模版 | ~$30-50M | `[报告-TSMC 财报披露]` |
| 单 die 边际制造成本 | ~$20-80 | `[推测-依据晶圆成本/良率]` |

平均成本公式：`AC = NRE / Volume + MarginalCost`。当出货量趋大，`AC → MarginalCost`；当出货量小，`AC` 被固定成本主导。**这意味着出货量最大的玩家，单颗成本最低，可以定价压死小厂——这就是"自然垄断"的经济学定义**（Baumol & Willig 1982）。Intel 年出货数亿颗、Apple 年出货数十亿颗（含移动），它们的单颗 R&D 摊销低到飞腾望尘莫及。

### ② 网络效应与双边市场（Network Effects / Two-Sided Markets）

Parker、Van Alstyne、Choudary 的**平台革命**理论：当一个产品的价值随用户增多而增大（直接网络效应），或当一边用户增多吸引另一边（间接/交叉网络效应），市场就会**倾斜向单一赢家**。

- **x86**：直接网络效应 = 二进制兼容。30 年积累的 Windows/Linux 软件，让任何新 ISA 都要付"重新编译/重写"的迁移成本。这是**最强的用户侧锁定**。
- **CUDA**：教科书级双边市场。开发者写 CUDA → 用户买 NVIDIA 卡（因为有库）→ 开发者继续写 CUDA（因为有用户）。鸡生蛋死锁，AMD/Intel 至今打不破 `[书-Parker/Van Alstyne《Platform Revolution》2016]`。
- **ARM**：ISA 兼容性带来的生态锁定。移动端 ARM 已成事实标准，服务器端 ARM 生态（Linux + 编译器 + 应用）正在自我强化。

**网络效应的经济学后果：市场不是"谁做得好谁赢"，而是"谁先到临界质量谁通吃"**。这解释了为什么技术更好的 Itanium 死了、技术更差的 x86 活了——锁定 > 性能。

### ③ 摩尔定律的经济学本质（Economics of Moore's Law）

一个常被误解的点：**摩尔定律不是物理定律，是经济学规律**。

Douglas Brock（2006）《Understanding Moore's Law》的核心论点：摩尔定律是一条**自我实现的经济学预期**——全行业协调在"每 18-24 个月晶体管密度翻倍"的节奏上，因为**只要密度翻倍能带来单晶体管成本下降，巨额投资就划算，于是大家投，于是密度真的翻倍**。Aizcorbe、Flamm、Khurshid（2007）的半导体定价实证证实：几十年来芯片的**每性能单价**持续暴跌，这是摩尔定律的经济学皮肤 `[论文-Aizcorbe, Flamm, Khurshid, "Moore's Law", 2007]`。

**关键转折**：当制程逼近物理极限（5nm/3nm），**密度翻倍不再带来单晶体管成本下降**——TSMC 3nm 单晶体管成本比 5nm 更贵 `[报告-Bersemi/SemiAnalysis 2023]`。摩尔定律的经济学引擎熄火，后果是：

1. **不再有"等下一个节点就便宜了"** → 投资回报率下降 → **行业加速整合**（能玩得起 3nm 的只剩 TSMC/Samsung/Intel 三家，代工集中度飙升）。
2. **成熟节点（14nm/28nm）反而获得"经济续航"** → 因为先进节点不划算，大量需求停留在成熟节点 → 对飞腾这种困在 14nm 的玩家是**意外的喘息窗口**。

### ④ 半导体周期（Silicon Cycle / Cobweb Model）

半导体业有著名的 **3-4 年繁荣-衰退周期**：短缺 → 扩产 → 过剩 → 砍价 → 投资不足 → 再短缺。经济学上这是经典的 **Kaldor 蛛网模型**（Kaldor 1934）——产能建设有 1.5-2 年时滞，供给永远滞后于需求信号，导致周期性震荡。

历史实证：2017-2018 繁荣（存储）→ 2019 衰退 → 2020-2022 史诗繁荣（疫情+缺芯）→ 2023 过剩（存储暴跌 40%+）→ 2024-2026 复苏 `[报告-WSTS/SIA 月度数据]`。

**当前（2026）相位判断**：逻辑芯片处于**复苏上行**，但**严重分化**——AI 算力（HBM、先进逻辑）在过热顶点，成熟节点（14nm/28nm）温和复苏。飞腾困在成熟节点，吃的是温和复苏，**错过了 AI 那条最陡的上行线**。

### ⑤ 赢家通吃 vs 政策庇护（Winner-Take-All vs Protected Market）

规模经济 + 网络效应 = **强赢家通吃倾向**。但芯片业的现实是"赢家通吃**多**"而非绝对通吃：Intel 通吃但 AMD 活着，NVIDIA 通吃但 AMD/Intel 在追。存活的小厂要么有**技术差异化**，要么有**政策庇护**。

**政策庇护型垄断**是经济学上特殊的垄断——它不是因为企业效率高而垄断，而是因为**政府人为限制竞争**（关税、准入、国产化令）。这种垄断的经济学判断：

- **正面（幼稚产业论，Hamilton/List）**：暂时保护 → 学习曲线 → 最终具备全球竞争力。日韩半导体史（1970s-1990s）是成功先例。
- **负面（寻租理论，Krueger/Tullock）**：保护 → 企业靠寻租而非创新获利 → 永久依赖 → 资源错配。**信创的经济学性质，是判断飞腾命运的核心命题**（见 §2.3）。

### ⑥ IP 授权经济学（Licensing Model / Double Marginalization）

ARM 的商业模式是**IP 授权**：设计 ISA/核，授权给下游芯片厂，按颗收版税。经济学上这是**纵向分离**（vertical separation）。

经典问题：**Spengler 双重边际化**（Spengler 1950）——当上游（ARM）和下游（飞腾）各自加价，总价格高于纵向一体化（如 Apple 自研核），**总销量低于社会最优**。Apple 同时持有 ARM 架构授权 + 自研核 + 自有品牌，**纵向一体化吃满整条链**；飞腾付 ARM 版税 + 自己再加价，**结构上就被双重边际化放血** `[论文-Spengler, "Vertical Integration", 1950; Tirole《工业组织理论》1988]`。

但 ARM 授权模式之所以仍成立：**ARM 把固定研发成本摊到全行业所有 licensee 上**，单颗版税远低于自研全套 ISA+核的成本——**前提是你自研的量达不到 ARM 的全行业总量**。飞腾正是这个"前提成立"的典型：它的量太小，自研不如买授权。

## 2. 用经济学看飞腾 D3000M（5 个尖锐判断）

### 2.1 判断一：CPU 市场为什么易垄断，飞腾如何破锁死？

**经济学结论：CPU 市场被两股力量推向寡头——规模经济（成本侧）+ 网络效应（需求侧）。飞腾两道锁都打不开。**

三巨头的统治，各有经济学机理：

| 巨头 | 规模经济来源 | 网络效应来源 | 锁定强度 |
|------|-----------|-----------|:------:|
| **Intel/x86** | 年出货数亿、自有 fab、R&D ~$18B/年 | x86 二进制兼容（30 年软件） | 🔴 极强 |
| **NVIDIA/CUDA** | GPU 出货 + 数据中心寡占 | **CUDA 双边市场**（开发者↔用户死锁） | 🔴 极强 |
| **ARM** | 全行业 licensee 摊销 ISA/核 R&D | 移动端 ARM 生态事实标准 | 🟡 强 |

**飞腾的破局困境**：
- **破不了 x86 锁**：商用市场（与 Intel/AMD 竞争）上，飞腾要付"软件迁移税"——客户从 x86 切到 ARM，所有应用要重编译/适配。经济上这等于一个巨大的**转换成本**（switching cost），没有足够的价格优势客户不会切。飞腾 14nm 的单线程（~2.5-2.8 GHz `[推测]`）落后 Intel 30-40% `[依据-Lens_03 §4.4]`，**价格优势不够补偿性能差与迁移成本** → 商用市场基本进不去。
- **破不了 CUDA 锁**：D3000M **无 BF16/I8MM/SVE** `[实测-扩展专题第 39-41 行]`，原生跑不了现代大模型推理。即便硬件能跑，飞腾也没有对标 CUDA 的软件生态——**AI 市场对飞腾是网络效应锁死的铁门**（E21 战略伤疤的经济学根因）。
- **只能活在 ARM 生态 + 政策夹缝**：飞腾的全部经济空间，是"ARM 生态里被政策保护的那块信创蛋糕"。而这块蛋糕里，**鲲鹏的网络效应还比飞腾强**（鲲鹏生态、开发者更多）。

**一句话**：飞腾不是在"市场竞争"，是在"政策市场里和鲲鹏抢同一块受保护份额"。经济学上这叫**受保护寡头内的次级竞争**，不是自由市场。

### 2.2 判断二：飞腾的"规模"够吗——死亡螺旋

**经济学结论：不够。飞腾正处于"低量→高单颗成本→竞争力弱→量更低"的死亡螺旋边缘，靠政策输血续命。**

用数字算飞腾的 R&D 摊销（这是 §1.① 规模经济的具体应用）：

| 玩家 | 年出货量（估） | 年 R&D（估） | 单颗 R&D 摊销 | 来源 |
|------|:----------:|:--------:|:---------:|------|
| Apple（含移动） | ~2 亿颗（自研核） | ~$30B（全公司） | ~$150/颗 | `[官方-Apple 财报]` |
| Intel | ~3 亿颗（CPU） | ~$18B | ~$60/颗 | `[官方-Intel 财报]` |
| 华为鲲鹏+海思 | 年亿片级 | ~千亿 RMB | ~$100-150/颗 | `[推测-依据Lens_03 §4.3]` |
| **飞腾** | **年百万片级（服务器为主）** | **估 10-20 亿 RMB** | **~$200-400/颗** | `[推测-依据E07+Lens_03]` |

**飞腾的单颗 R&D 摊销是 Intel 的 3-7 倍、Apple 的 1.5-2.5 倍**。这是规模经济的残酷算术——**不是飞腾不努力，是量级差了 1-2 个数量级，经济学规律不放过它**。

死亡螺旋的力学：
```
低出货 → 高单颗成本 → 无法在价格上压过鲲鹏/Intel
   ↑                                    ↓
   ←← 份额流失 ←← 客户嫌贵/性能差 ←←
```
唯一打破螺旋的方式是**把量做上去**。但量被三重锁压住：① 商用进不去（x86 锁）；② AI 进不去（无 BF16/CUDA 锁）；③ 信创内部还要和鲲鹏分（鲲鹏量更大、螺旋转得更顺）。

**经济学判断**：飞腾的量，**撑不起独立迭代下一代先进制程芯片的经济性**。每代流片 $100-300M 固定成本 `[报告]`，飞腾年百万片出货要 3-5 年才能回本——这解释了为什么飞腾代际更新慢、为什么 D3000M 停在 ARMv8.4/14nm。**不是不想上 7nm/v9，是量撑不起那个经济性**（叠加 E19 的地缘锁，双锁）。

### 2.3 判断三：信创市场是不是"市场"？——效率判断

**经济学结论：信创是一个价格信号失真的"扭曲市场"，目前更像转移支付而非有效市场。能否转型为有效市场，决定飞腾生死。**

这是一个尖锐但必须诚实的判断。用三个经济学标准检验信创：

**标准一：价格是否反映真实支付意愿？**
自由市场中，价格 = 边际消费者愿意支付的上限。信创订单是**强制国产化**（政企"必须"用国产 CPU），购买决策不是"飞腾比 Intel 值"而是"必须买国产" `[官方-信创目录]`。**这意味价格信号失真**——飞腾政企服务器售价 $500-1000 `[推测-E07 §2]`，毛利 80%，这个价格不是因为飞腾值这么多，而是因为**政策消除了 Intel 这个价格参照系**。

**标准二：竞争是否驱动效率改进？**
有效市场中，竞争逼迫企业降本增效。信创市场里，飞腾/海光/鲲鹏/龙芯 竞争，但**真正的全球对手（Intel/AMD）被政策挡在门外**。这种"温室竞争"是否会催生全球竞争力？经济学上的**幼稚产业保护论**（List 1841）要求保护是**临时的**且保护期内企业真的爬上学习曲线。**现实证据**：信创推进 10+ 年，至今没有一款国产 CPU 在全球商用市场（非信创）对 Intel/AMD 形成实质竞争 `[报告-IDC/Gartner]`。这暗示保护**尚未**转化为竞争力，更像 Krueger 的**寻租**（rent-seeking）——企业把资源花在进信创目录、拿政策红利，而非拼全球技术 `[论文-Krueger, "The Political Economy of the Rent-Seeking Society", 1974]`。

**标准三：是否资源错配？**
经济学上，如果一笔投入在自由市场不会被做（因为回报不够），是政策推着做的，那就是**社会层面的资源错配**（除非有正外部性，如国防安全）。飞腾的研发、产能，若纯粹按市场回报率算，很多是不划算的——**信创用财政/国企预算补贴了这个不划算**。这究竟是"为自主可控付的合理溢价"还是"打水漂"，**取决于 10 年后飞腾能否在没有政策保护下独立存活**。目前看，去掉政策，飞腾经济上**活不下去**（§2.2 死亡螺旋）。

**诚实结论**：信创**今天是转移支付为主、市场为辅**；它能否进化成"真正的市场"，取决于保护期是否真的磨出了全球竞争力。**经济学上，无限期的保护 = 永久低效**。这是飞腾最该被问的尖锐问题。

### 2.4 判断四：半导体周期定位——2026 扩产含义

**经济学结论：2026 处于 AI 过热 + 成熟节点温和复苏的分化相位。飞腾困在成熟节点，扩产赌的是信创需求曲线，而非全球周期。**

用 Kaldor 蛛网框架定位（§1.④）：

| 周期相位 | 时间 | 特征 | 对飞腾 |
|---------|------|------|--------|
| 史诗繁荣 | 2020-2022 | 全品类缺货、存储暴涨 | 飞腾吃不到（产能受限、非主流） |
| 过剩衰退 | 2023 | 存储暴跌 40%+、逻辑库存高 | 飞腾需求跟随信创，波动小 |
| 分化复苏 | **2024-2026（当前）** | AI/HBM 过热顶点；成熟节点温和 | **飞腾在成熟端，吃温和复苏，错过 AI 暴涨** |
| ？ | 2027+ | AI 是否软着陆？成熟是否持续？ | 见下注 |

**关键判断**：当前（2026）不是全面繁荣顶点，而是**结构性分化**——AI 算力那部分在顶点甚至有过热风险（HBM 产能被抢、CoWoS 排队到 2027+ `[官方-TSMC 法说会]`），而飞腾所在的**通用服务器 CPU（14nm 级、无 AI 加速）**处于**温和复苏、无泡沫**。

**对飞腾扩产决策的经济学含义**：
- 飞腾若扩 14nm 产能，赌的是**信创渗透率继续提升**（政策变量），而非全球半导体周期（市场变量）。这两条曲线**正在脱钩**——全球周期看 AI/消费电子，飞腾周期看财政信创预算。
- 风险：信创渗透率到一定水平（政企核心系统替换完）后，**需求曲线会走平甚至回落**。飞腾若按当前增速线性外推扩产，**可能撞上信创需求见顶的产能过剩**（自己的小周期）。这是 §1.④ 蛛网模型在飞腾身上的微观复现——产能时滞 vs 需求信号失真。

### 2.5 判断五：ARM 授权费经济学——双重边际化放血

**经济学结论：飞腾付给 ARM 的版税，加上飞腾自身加价，构成 Spengler 双重边际化。相比 Apple 的纵向一体化，飞腾结构性地每颗都被"抽税"。**

ARM 架构授权的经济学结构（§1.⑥）：

```
ARM（上游，英国）→ 收版税 → 飞腾（下游，自研 FTC862 核）→ 加价 → 客户
        ↑                          ↑
   上游垄断加价              下游垄断加价
        ↑________________________________↑
            双重边际化 → 总价高于一体化、总销量低于最优
```

**对比 Apple**：Apple 同样持有 ARM 架构授权，但 Apple **纵向一体化**——自研核（A/M 系列）+ 自有品牌 + 自有 OS + 自有生态。Apple 付给 ARM 的版税在其千亿利润里**几乎可忽略**，且 Apple 吃满整条价值链。**飞腾付同样的版税结构，但在百万片级出货上，版税占比显著；且飞腾吃不到 OS/生态那截利润**。

**具体数字（推测）**：ARM 架构授权版税通常为芯片售价的 ~1-2% `[官方-ARM 授权模式公开文档]`。飞腾政企服务器 SKU 售价 $500-1000 `[推测-E07]`，则单颗 ARM 版税 ~$5-20。看似不大，但**叠加在飞腾本就高企的单颗 R&D 摊销（§2.2 的 $200-400）上，版税是"压死骆驼的稻草之一"**。

**双重边际化的深层后果**：飞腾既不能像 Intel 那样"ISA+核+品牌全自有"（零纵向加价），也不能像 Apple 那样"量大道具摊薄一切"。**飞腾卡在中间——既付了 ARM 税，又没 Apple 的量去稀释它**。这是 ARM 授权模式下"中等规模玩家"的结构性劣势，经济学上几乎没有解药，除非量级跃升或纵向整合。

## 3. 对飞腾命运的具体下注（强制，可证伪）

> 本透镜的预测必须可证伪。以下五注，2028-2030 年回看：

1. **下注 1（量级）**：到 2028 年，飞腾年出货量**仍无法达到千万片级**（维持百万片级），单颗 R&D 摊销**仍高于 Intel/Apple 2 倍以上**。即死亡螺旋不会被打破。**预测概率 80%**。依据：商用/AI 双锁不解、信创内部分给鲲鹏的份额难逆。
2. **下注 2（政策依赖）**：到 2030 年，飞腾**仍有 ≥70% 营收来自政策性市场（信创/国防）**，即信创**未能**进化为真正具备全球竞争力的商业市场。**预测概率 70%**。依据：10 年保护期未产出全球级 CPU 的历史惯性。
3. **下注 3（合并/整合）**：若 ARM v8 授权生变或中芯产能受阻，飞腾作为独立经济实体**无法独立存活**，会被并入更大集团（中国电子 CEC 内部整合）。**5 年内触发概率 50%**。依据：规模不经济 + 供应链单点失败（与 Lens_03 下注 4 共振）。
4. **下注 4（成熟节点红利）**：2026-2028，因先进节点经济性恶化（摩尔定律经济学熄火），**成熟节点（14nm/28nm）的相对性价比短暂改善**，飞腾在这段窗口里"过得还行"。但 2028 后先进封装/chiplet 若让先进节点重新划算，窗口关闭。**窗口期预测概率 75%**。
5. **下注 5（AI 缺位的经济学后果）**：因无 BF16/I8MM/SVE，飞腾**无法进入 AI 推理服务器增量市场**，这块最大增量被 GPU 厂商和鲲鹏（若上 v9+AI 扩展）吃走。飞腾 2030 年 AI 相关营收占比 **< 10%**。**预测概率 85%**。依据：网络效应（CUDA/生态）+ ISA 缺失双重锁死。

## 5. 这一视角的盲区与反方（强制诚实段）

> 经济学是"假设理性主体、可建模市场"的分析框架。**芯片业的现实远比模型复杂，敢说看不见什么，才不是软文**。

1. **技术突变不可建模**：经济学假设技术进步是平滑外生的。但**一次架构革命（如存算一体、光子计算、神经形态）可能瞬间重写整个成本曲线与网络效应结构**。Lens_04 的"死亡螺旋"预测，在技术范式跃迁面前可能全部失效。**经济学看不见颠覆**。
2. **政策非理性**：经济学假设政策是追求效率的工具。但信创/国产化背后有**国防安全、主权独立、就业稳定**等非效率目标，这些在经济学模型里是"外生偏好"。**经济学评判信创"低效"，可能是因为它量错了效用的口径**——把安全效用排除在外了。E06 视角比 Lens_04 更懂这个。
3. **地缘冲突不可建模**：Lens_04 把 ARM 版税、TSMC 代工价当"价格"分析，但这些随时可能被**制裁/断供变成"0 或 ∞"**。价格理论在非市场干预（实体清单、出口管制）下失效。**这是 Lens_03/E19 的地盘，Lens_04 假装市场是连续的**。
4. **网络效应的临界点难预测**：经济学知道网络效应会"倾斜向赢家"，但**临界质量到底在哪、何时翻转**，模型给不出精确值。ARM 服务器生态会不会在某个时点突然越过临界、爆炸式增长（把飞腾带上）或突然被 RISC-V 颠覆（把飞腾甩下）？**经济学定性知道会发生，定量给不准**。
5. **飞腾的"内部信息"看不见**：Lens_04 用公开财报/行业数据估算飞腾 R&D、出货量，**但飞腾真实的良率、真实成本结构、真实政府补贴额，可能与分析值差一个数量级**（涉密/不披露）。**经济学分析的精度受限于数据可得性**。
6. **"规模不够"可能是错的**：飞腾背后是中国电子（CEC）国资体系，**可通过集团内部交叉补贴、军工订单合并计算，达到经济学上看不到的"有效规模"**。Lens_04 按独立公司算，可能低估了国家资本主义下的规模整合能力。

**反方一句话**：经济学告诉你飞腾"按市场规律该死"，但**飞腾从来不在纯市场里**——它在政治+市场+地缘的混合场。把混合场当纯市场分析，是 Lens_04 最该被警惕的盲区。**真正的答案，可能要 Lens_04 × E06 × Lens_03 三者乘积才看得清**。

## § 经济学方法论与资源（不只飞腾，给所有用经济学框架的分析师）

> 本章把 Lens_04 的飞腾经济分析上升为**任何产业经济分析都可复用的方法与资源**。飞腾是案例锚点，方法普适。通用资源见 [`领域资源库.md`](../领域资源库.md)。

### 方法论一：规模经济 vs 网络效应（两种垄断逻辑）

- **规模经济**：单位成本随产量下降（半导体晶圆成本固定，量大摊薄）——飞腾出货量 << Intel/TSMC，规模不经济
- **网络效应**：用户越多价值越大（ARM/x86/CUDA 生态）——飞腾生态规模小，锁打不开
- **双层市场（two-sided market）**：平台连接两边（CPU 连接软件+硬件厂商），鸡生蛋问题——飞腾软件侧生态薄

### 方法论二：半导体周期（资本密集行业的宿命）

半导体 3-4 年一周期：繁荣→扩产→过剩→降价→衰退→出清。晶圆厂 100 亿美元级，决策要 5-10 年前瞻。**周期错配**（繁荣扩产在衰退还本）是 Fabless 致命风险。政策庇护（信创）让飞腾部分脱离周期，但脱离市场也脱离市场倒逼。

### 方法论三：政策扭曲与租金经济学

- **政策租金**：信创订单的确定性溢价 = 政策给的租金（非效率赢来）
- **寻租（rent-seeking）**：靠政策而非创新获利，长期削弱竞争力（Krueger 经典论文）
- **庇护成本**：脱离市场压力 = 创新激励弱化（飞腾性能代差的经济学根源）

### 经济学资源

- **市场数据**：**IC Insights**、**SEMI**、**WSTS**（全球半导体出货）、**SIA**（美国半导体协会年报）、中国信通院
- **周期/资本**：**SemiAnalysis**（深度）、Bloomberg/S&P 半导体指数、**Pelumeza 半导体周期模型**
- **经济理论书**：**Shapiro & Varian《Information Rules》**（平台经济学）、Katz & Shapiro（网络效应）、**Krueger 寻租论文**、Tirole《产业组织理论》
- **半导体经济**：Leachman《半导体制造经济学》、Tilton《国际技术扩散》

### 给经济学分析师的通用建议

1. **区分规模 vs 网络垄断**：规模（量大便宜）vs 网络（生态锁定），对策不同。
2. **周期是资本密集行业宿命**：半导体/造船/钢铁都周期，决策要逆周期。
3. **政策租金要折现**：信创庇护是租金非效率，估值给政策风险折扣。
4. **寻租长期腐蚀竞争力**：靠政策活着的，市场能力退化——飞腾性能代差的经济学根源。
