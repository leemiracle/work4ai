### 4.1 `INS (element)` (C7.2.175)

> 💡 **被以下指令作为别名使用**：`MOV (element)`


**语义**：Insert vector element from another vector element. This instruction copies the vector element of the source SIMD&FP register to the specified vector element of the destination SIMD&FP register.


**汇编模板**：
```
INS <Vd>.<Ts>[<index1>], <Vn>.<Ts>[<index2>]
```

 integer src_index = UInt(imm4<3:size>);
