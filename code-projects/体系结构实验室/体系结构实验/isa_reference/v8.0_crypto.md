## 0. 一句话

15 条指令覆盖 AES/SHA1/SHA256/PMULL —— TLS 全栈、磁盘加密、区块链的硬件底座。


---
## 1. 现象：为什么需要它？

**软件 AES 一轮**：~20 条指令（S-box 查表 + ShiftRows + MixColumns）
**硬件 AESE 一轮**：1 条指令（SubBytes + ShiftRows + MixColumns + AddRoundKey 全部）

```
// AES-128 加密（10 轮）核心循环
AESE  v0.16b, v1.16b    // 第 1-9 轮：完整 AES round
AESMC v0.16b, v0.16b    //       (MixColumns 单独)
// 最后一轮特殊：只 AESE 不 AESMC
EOR   v0.16b, v0.16b, v_final_key
```

**实测吞吐（Lab07）**：AES-128-GCM ~5 GB/s（vs 软件 AES-NI 模拟 ~600 MB/s）

**版本**：ARMv8.0-A optional（启用了 +crypto 时）。


**飞腾 D3000M 状态**：

飞腾 D3000M 实测全部支持：HWCAP_AES/SHA1/SHA2/PMULL=1。

- 编译：`-march=armv8-a+crypto` 或 `-mcpu=ftc86x`
- intrinsic 头：`<arm_neon.h>` 中 `vaeseq_u8`、`vsha1cq_u32`、`vsha256hq_u32`、`vpmullq_*` 系列


**杀手级应用**：TLS 1.3 / IPSec / 磁盘加密 (LUKS) / 区块链 (BTC/ETH) / Signal protocol

### 4.2 `PMULL, PMULL2` (C7.2.215)

**语义**：Polynomial Multiply Long. This instruction multiplies corresponding elements in the lower or upper half of the vectors of the two source SIMD&FP registers, places the results in a vector, and writes the vector to the destination SIMD&FP register. The destination vector elements are twice as long as the elements that are multiplied.


**汇编模板**：
```
PMULL{2} <Vd>.<Ta>, <Vn>.<Tb>, <Vm>.<Tb>
```


<details><summary>Decode 伪代码（点击展开）</summary>

```

 integer n = UInt(Rn); 
 integer m = UInt(Rm);

 if size == '11' && !HaveBit128PMULLExt() then UNDEFINED; 
 integer esize = 8 << UInt(size); 
 integer datasize = 64; 
 integer part = UInt(Q); 
 integer elements = datasize DIV esize;
```

## 6. 性能预期（飞腾 D3000M @ 2.5 GHz）

| 算法 | 飞腾 D3000M | 实现 | 备注 |
|------|------------|------|------|
| AES-128-ECB | ~6 GB/s | 8-block parallel | 单核单线程 |
| AES-256-GCM | ~5 GB/s | AESE+PMULL (GHASH) | TLS 主流 |
| SHA-256 (大块) | ~3 GB/s | 2-block parallel SHA256H | 单核 |
| SHA-1 | ~2 GB/s | 2-block parallel SHA1C | 已弱化 |
| GHASH (PMULL) | ~5 GB/s | 128-bit polynomial mult | GCM 模式用 |

**对比**：Intel AES-NI 单核 ~7 GB/s；飞腾 ~5 GB/s，差距在可接受范围。

## 7. 缺陷与陷阱

1. **AESE 不含 AddRoundKey**：要自己 XOR round key（最后一轮特殊）
2. **AESMC 必须跟 AESE**：单独 AESMC 行为 undefined
3. **SHA256H / SHA256H2 必须成对**：前者算 H,后者算 H2，调用顺序固定
4. **PMULL 输出位宽**：8b×8b→16b (8 lane) 或 64b×64b→128b (1 lane)，两种 variant
5. **intrinsics 命名混乱**：`vsha256hq_u32` vs `vsha256h2q_u32`，差一个 '2'
6. **endianness**：AES 大端 vs NEON 小端，intrinsics 已封装但汇编层要注意
7. **side channel**：硬件指令天然抗 timing 攻击（vs 查表 AES）
8. **VAES 没有**：飞腾不支持 VAES（512-bit AES），单核只能 128-bit
