## 0. 一句话

饱和舍入双倍乘加（SQRDMLAH/SH）—— 音频处理、量化神经网络的核心运算。


---
## 1. 现象：为什么需要它？

音频处理常需要 Q15 (int16 fixed-point) 乘加 + 饱和 + 舍入：

```c
// 朴素 C：int16 饱和乘加
int32_t prod = (int32_t)a * (int32_t)b;       // 32-bit
prod = prod * 2 + (1 << 14);                   // doubled + round
if (prod > 32767) prod = 32767;                 // saturate
if (prod < -32768) prod = -32768;
acc = acc + prod;
// 一坨指令：SMULL + QADD + USAT + ADD
```

SQRDMLAH 一条指令：
```asm
SQRDMLAH v0.4s, v1.4s, v2.4s   // 4 路 int32 饱和舍入双倍乘加
```

**元素级公式**：`acc += sat((2*a*b + (1<<14)) >> 15)`

### 4.1 `SQRDMLAH (by element)` (C7.2.293)

**语义**：Signed Saturating Rounding Doubling Multiply Accumulate returning High Half (by element). This instruction multiplies the vector elements of the first source SIMD&FP register with the value of a vector element of the second source SIMD&FP register without saturating the multiply results, doubles the results, and accumulates the most significant half of the final results with the vector elements of the destination SIMD&FP register. The results are rounded.


**汇编模板**：
```
SQRDMLAH <V><d>, <V><n>, <Vm>.<Ts>[<index>]
```

## 7. 缺陷与陷阱

1. **doubled 才舍入**：`2*a*b` 后舍入，不是先舍入再翻倍
2. **舍入模式固定 round-half-up**：不能改 round-to-even
3. **饱和到 int32 范围**：不是 int16，注意上层不能溢出 int32
4. **by element 的 index**：从 4S lane 取一个，最大 index=3
5. **没有 fp 版本**：纯整数运算，做量化需要外部 CVT
