## 0. 一句话

一组 v8.5-v8.7 的小特性集合：分支目标标识/区间舍入/标志位操作/内存标签/等待指令改进等。


---
## 1. 现象：为什么需要它？

**BTI (Branch Target Identification, FEAT_BTI)**：保护间接分支目标，防 JOP 攻击：
```asm
BTI c                    ; 标记有效间接 call 目标
BTI j                    ; 标记有效间接 jump 目标
```

**FlagM/FlagM2 (FEAT_FlagM)**：直接操作 NZCV 标志位：
```asm
RMIF x0, #12, #0xf       ; rotate + insert into flags
SETF8 w0                 ; set flags from int8 sign/magnitude
CFINV                    ; invert C flag
```

**FRINTTS (FEAT_FRINTTS)**：fp32/fp64 → int32/int64 with saturation:
```asm
FRINT32Z v0.4s, v1.4s    ; round to fp32 fitting in int32 (toward zero)
FRINT64X v0.2d, v1.2d    ; round to fp64 fitting in int64 (current mode)
```

**MTE (Memory Tagging Extension)**：每 16-byte granule 加 tag，硬件级 use-after-free 检测：
```asm
STG [x0]                 ; store random tag
IRG x0, x0, x1           ; insert random tag into pointer
```

**WFxT (Wait For Event with Timeout)**：WFE/WFI 加超时：
```asm
WFET w0                  ; wait for event with timeout
WFIT w0                  ; wait for interrupt with timeout
```

## 2. 引入版本 & 飞腾状态

**版本**：v8.5 (BTI/FlagM/FRINTTS/MTE), v8.6 (MTE2), v8.7 (WFxT).


**飞腾 D3000M 状态**：

飞腾 D3000M (FTC862, ARMv8.4) **基本不支持 v8.5+** 特性。
- BTI: 未报 HWCAP_BTI
- MTE: 未报
- FlagM: 未报
- FRINTTS: 未报
- 这些需要 ARMv8.5+ 实现（Cortex-A78/X2 起），飞腾 D3000 是 v8.4 不支持


**杀手级应用**：BTI: 安全加固 / FlagM: JIT 优化 / FRINTTS: WebAssembly / MTE: Android 内存安全 / WFxT: 低功耗等待

## 7. 缺陷与陷阱

1. **飞腾 D3000 不支持**：直接用会 SIGILL
2. **MTE 与 userspace 兼容性**：需要 kernel 5.10+ 和 enabled binary
3. **BTI 需要 PLT/异步栈配合**：单独 BTI 不构成完整防护
4. **WFxT 默认 timeout 不变**：仅提供更好的 poll 模式
