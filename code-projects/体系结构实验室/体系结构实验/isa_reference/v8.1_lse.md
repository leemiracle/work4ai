## 0. 一句话

55 个原子指令助记符，单条指令完成原子 add/cas/swap —— 无锁队列、引用计数、计数器的硬件基石。


---
## 1. 现象：为什么需要它？

**LL/SC 实现 atomic_add（v8.0 baseline）**：
```asm
1: ldxr w0, [x1]       // load-exclusive，标记内存"被监视"
   add  w0, w0, #1
   stxr w2, w0, [x1]   // store-exclusive，成功则 w2=0
   cbnz w2, 1b         // 失败（被其他核改了）→ 重试
```
- 单线程：~5 cycles
- 多核高争用：~50-1000 cycles（live-lock 风险！）

**LSE 单条 LDADD（v8.1+）**：
```asm
ldadd w0, w2, [x1]     // 原子：old=*x1; *x1=old+w0; return old in w2
```
- 单线程：~3 cycles
- 多核高争用：~20-50 cycles（总线保证原子性，无 live-lock）

## 2. 引入版本 & 飞腾状态

**版本**：ARMv8.1-A mandatory。


**飞腾 D3000M 状态**：

飞腾 D3000M 实测支持（HWCAP_ATOMICS=1，Lab01 已测）。

- 编译：`-march=armv8.1-a+lse` 或 `-mcpu=ftc86x`，运行时 GCC 会自动用 LSE 替代 LL/SC
- 也可显式：`__atomic_add_fetch()` / `__sync_add_and_fetch()`
- 内联汇编：直接写 `ldadd` 即可


**杀手级应用**：无锁队列 / 引用计数 (shared_ptr) / std::atomic / futex / spin lock / memory_order_consume

## 6. 性能预期（飞腾 D3000M @ 2.5 GHz）

| 场景 | LL/SC | LSE | LSE 优势 |
|------|-------|-----|---------|
| 单线程 uncontended | ~5 cyc | ~3 cyc | 1.7× |
| 4 核低争用 (1k ops/s/core) | ~10 cyc | ~5 cyc | 2× |
| 8 核高争用 (1M ops/s/core) | ~200 cyc | ~30 cyc | **6.7×** |
| 8 核 extreme 争用 | live-lock | ~100 cyc | **决定性** |

**Lab02 实测**：LSE 比 LL/SC 快 ~30%（单线程）。

**关键 LSE 指令语义**：
- `LDADD` → 原子 add 返回旧值
- `STADD` → 原子 add 不返回（更紧凑）
- `CAS` → 原子 compare-and-swap
- `SWP` → 原子 swap
- `LDCLR/LDSET/LDEOR` → 原子位运算
- `LDSMAX/LDSMIN/LDUMAX/LDUMIN` → 原子 max/min
- 后缀 `A` = acquire (load-acquire 语义)
- 后缀 `L` = release (store-release 语义)
- 后缀 `AL` = acquire+release
- 后缀 `B/H` = byte/halfword (子字原子)

## 7. 缺陷与陷阱

1. **CAS 有 4-byte / 8-byte / 16-byte (CASP) 三种**：CASP 双字比较交换是 v8.1 LSE 引入，注意 alignment
2. **sub-word atomic (LDADDB/LDADDH)**：仅 v8.1 LSE 支持，旧 ARMv8 实现需 LL/SC
3. **memory order 后缀**：`LDADD` (relaxed) / `LDADDA` (acquire) / `LDADDL` (release) / `LDADDAL` (seq_cst)，C++ `memory_order_*` 映射很关键
4. **forward progress guarantee**：LSE 保证有限步内完成（无 live-lock），LL/SC 不保证
5. **intrinsics 选择**：`__atomic_*` (C11) 优于 `__sync_*` (legacy)，前者支持 memory order
6. **CAS false sharing**：CAS 同一 cache line 的不同变量也会触发争用（-padding 解决）
7. **LSE 信号量在 ARMv8.0 fallback**：用 `__GCC_HAVE_LSE` 宏做编译期 dispatch
