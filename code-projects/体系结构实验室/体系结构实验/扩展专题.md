# ARMv8.x 扩展专题（贯穿 Lab01-Lab07）

> 本文件列出飞腾 D3000M (FTC862) **实测支持**的 ARMv8.x 扩展特性，
> 每个特性都对应若干实验。这些扩展把"通用体系结构实验"提升到
> **"针对国产 ARM 平台的深度工程实验"**。

## 1. 飞腾 D3000 实测 ISA 能力矩阵

> **关键指令列**列出该扩展引入的指令助记符（按 ARM ARM DDI 0487G.b 提取，详见 [`isa_reference/`](./isa_reference/) 目录）。

| # | 特性 | 标志位 | 关键指令（助记符） | 状态 | 引入版本 | 在飞腾上的实测应用场景 | 详细参考 |

| 2 | AES | HWCAP_AES | `AESE / AESD / AESMC / AESIMC` (4 条) | ✅ | v8.0 | TLS / 磁盘加密 | [`v8.0_crypto.md`](./isa_reference/v8.0_crypto.md) |
| 3 | SHA1 | HWCAP_SHA1 | `SHA1C / SHA1P / SHA1M / SHA1H / SHA1SU0 / SHA1SU1` (6 条) | ✅ | v8.0 | Git / 旧证书 | [`v8.0_crypto.md`](./isa_reference/v8.0_crypto.md) |
| 4 | SHA256 | HWCAP_SHA2 | `SHA256H / SHA256H2 / SHA256SU0 / SHA256SU1` (4 条) | ✅ | v8.0 | 区块链 / 签名 | [`v8.0_crypto.md`](./isa_reference/v8.0_crypto.md) |

| 6 | CRC32 | HWCAP_CRC32 | `CRC32{B,H,W,X}` / `CRC32C{B,H,W,X}` (2 助记符 8 变体) | ✅ | v8.0 | 网络包校验 / Zlib | [`v8.0_crc32.md`](./isa_reference/v8.0_crc32.md) |
| 7 | **LSE 原子** | HWCAP_ATOMICS | `LDADD / LDCLR / LDSET / LDEOR / SWP / CAS / LDSMAX / LDSMIN / LDUMAX / LDUMIN / STADD / STCLR / STSET / STEOR / STSMAX / STSMIN / STUMAX / STUMIN` + 字节/半字/字/双字 + acquire/release 变体 (**55 个助记符**) | ✅ | **v8.1** | 无锁队列 / 计数器 | [`v8.1_lse.md`](./isa_reference/v8.1_lse.md) |

| 9 | **LOR** (Low-overhead Load/Store) | HWCAP_LOR | `LDLAR / STLLR` × (B/H/X) (6 条) | ✅ | v8.1 | LL/SC 优化变体 | [`v8.1_lor.md`](./isa_reference/v8.1_lor.md) |
| 10 | **LRCPC v1** | HWCAP_LRCPC | `LDAPR / LDAPRB / LDAPRH` (3 条) | ✅ | v8.1 | RCpc 内存序 | [`v8.1_lrcpc.md`](./isa_reference/v8.1_lrcpc.md) |

| 12 | **FP16 NEON** (ASIMDHP) | HWCAP_ASIMDHP | `FADD (vector) / FMLA / FMAXNMV / FCMLT / FMINV / FRECPE / ...` (**68 条**) | ✅ | **v8.2** | fp16 向量 | [`v8.2_fp16.md`](./isa_reference/v8.2_fp16.md) |

| 19 | **FHM** (fp16→fp32 FMLA) | HWCAP_ASIMDFHM | `FMLAL / FMLSL` × (vector / by element) (2 助记符 4 变体) | ❌ | v8.4 | （飞腾不支持） | [`v8.x_unsupported.md`](./isa_reference/v8.x_unsupported.md) |
| 20 | **SHA3** | HWCAP_SHA3 | `BCAX / EOR3 / RAX1 / XAR` (4 条) | ✅ | **v8.4** | Keccak / Web3 | [`v8.4_sha3_sha512.md`](./isa_reference/v8.4_sha3_sha512.md) |
| 21 | **SHA512** | HWCAP_SHA512 | `SHA512H / SHA512H2 / SHA512SU0 / SHA512SU1` (4 条) | ✅ | **v8.4** | Ed25519 / 现代签名 | [`v8.4_sha3_sha512.md`](./isa_reference/v8.4_sha3_sha512.md) |
| 22 | **SM3** (国密) | HWCAP_SM3 | `SM3SS1 / SM3PARTW1 / SM3PARTW2 / SM3TT1A / SM3TT1B / SM3TT2A / SM3TT2B` (7 条) | ✅ | v8.4 | 国密 / 国内合规 | [`v8.4_sm3_sm4.md`](./isa_reference/v8.4_sm3_sm4.md) |
| 23 | **SM4** (国密) | HWCAP_SM4 | `SM4E / SM4EKEY` (2 条) | ✅ | v8.4 | 国密分组密码 | [`v8.4_sm3_sm4.md`](./isa_reference/v8.4_sm3_sm4.md) |
| 24 | **UDOT/SDOT** (Dot Product) | HWCAP_ASIMDDP | `UDOT / SDOT` × (vector / by element) (2 助记符 4 变体) | ✅ | **v8.4** | int8 量化 CNN | [`v8.4_dotprod.md`](./isa_reference/v8.4_dotprod.md) |
| 25 | ❌ SVE / SVE2 | HWCAP_SVE / HWCAP_SVE2 | （可变长向量，飞腾不支持） | ❌ | v8.4+ / v8.6+ | （不可用） | [`v8.x_unsupported.md`](./isa_reference/v8.x_unsupported.md) |
| 26 | ❌ I8MM | HWCAP_I8MM | `SMMLA / UMMLA / USMMLA / USDOT / SUDOT` (6 条) | ❌ | v8.6 | （int8 矩阵乘不可用，需 UDOT 替代）| [`v8.x_unsupported.md`](./isa_reference/v8.x_unsupported.md) |
| 27 | ❌ BF16 | HWCAP_BF16 | `BFCVT / BFCVTN / BFDOT / BFMLALB / BFMLALT / BFMMLA` (6 条) | ❌ | v8.6 | （bfloat16 不可用） | [`v8.x_unsupported.md`](./isa_reference/v8.x_unsupported.md) |

**结论**：飞腾 D3000 是 **ARMv8.4 级别**的全面实现，**唯一缺**：
- SVE/SVE2（可变长向量）
- BF16（BFloat16，数据中心 AI 主流）
- I8MM（int8 矩阵乘 intrinsic，但 UDOT 可手动实现等价）
- ASIMDFHM（fp16→fp32 横向乘累加，可用 FP16 NEON + 额外指令组合替代）

**ARMv8-A 总指令数参考**（按 ARM ARM DDI 0487G.b 全量提取，2021-07 版）：
- A64 base instructions (C6.2)：**354 个小节**
- A64 Advanced SIMD/FP (C7.2)：**391 个小节**
- 合计 **~745 个指令条目**（一个条目常含多个尺寸变体，如 LDADD 实际展开 ~10 条汇编助记符）
- 本项目 [`isa_reference/`](./isa_reference/) 目录对**飞腾实测可用**的 19 项扩展逐个深入剖析

## 3. 编译与运行支持

### 编译选项
```makefile
CFLAGS += -march=armv8.4-a+simd+crypto+lse+rcpc+flagm
# 或针对飞腾：
CFLAGS += -mcpu=ftc86x
```

### 运行时检测
每个实验开头调用 `hwcap_probe()`，检测实际支持：
```c
#include <sys/auxv.h>
unsigned long hwcap = getauxval(AT_HWCAP);
if (hwcap & HWCAP_ASIMDHP) { /* 飞腾支持 fp16 NEON */ }
```

## 5. 一句话索引（每个扩展的"杀手级指令"）

| 扩展 | 杀手指令 | 一句话 |
|------|---------|--------|
| NEON | `FMLA v0.4s, v1.4s, v2.4s` | 4 路乘累加，GEMM 优化基石 |
| AES | `AESE v0.16b, v1.16b` | 一条指令完成一轮 AES SubBytes+ShiftRows+MixColumns |
| SHA256 | `SHA256H q0, q1, v2.4s` | 一条指令算两轮 SHA-256 压缩 |
| PMULL | `PMULL v0.8h, v1.8b, v2.8b` | 8 路 8×8→16 位多项式乘法，GHASH 神器 |
| CRC32 | `__crc32cw(w0, w1)` | 一周期算 CRC32（vs 软件 ~10 周期） |
| LSE | `LDADD w0, w1, [x2]` | 单条原子加，比 LL/SC 快 ~30% |
| RDM | `SQRDMLAH v0.4s, v1.4s, v2.4s` | 饱和有符号乘加（音频 GAIN） |
| LRCPC | `LDAPR w0, [x1]` | 单条 load-acquire（vs LDAR+后续指令更轻） |
| FP16 | `FMLA v0.8h, v1.8h, v2.8h` | 8 路 fp16 乘累加（vs fp32 4 路，2× 宽度） |
| FCMA | `FCMLA v0.4s, v1.4s, v2.4s, #0` | 复数乘累加（4 实指令 → 1 条） |
| UDOT | `UDOT v0.4s, v1.16b, v2.16b` | 4×int8 点积累加到 int32（CNN 量化神器） |
| SM3 | `SM3SS1 v0.4s, v1.4s, v2.4s, v3.4s` | 国密 SM3 一轮压缩核心 |
| SM4 | `SM4E v0.4s, v1.4s` | 国密 SM4 一轮 4 路并行加密 |
| SHA3 | `EOR3 v0.16b, v1.16b, v2.16b, v3.16b` | Keccak-f 三输入异或（vs 2 条 EOR） |
| SHA512 | `SHA512H q0, q1, v2.2d` | SHA-512 压缩核心 |
