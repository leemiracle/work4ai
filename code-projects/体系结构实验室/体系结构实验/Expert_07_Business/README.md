## 1. 看飞腾 D3000M 的 10 个核心商业问题

1. **一颗 D3000M（8 核服务器 SKU）的真实 BOM 是多少？** 原版"$20/ die @7nm"是否站得住？
2. **飞腾给 ARM 交多少授权费与版税？** 这笔钱在 BOM 与毛利里占多大洞？
3. **ARM v9 不授权中国厂商**，把飞腾冻结在 ARMv8.4——这笔市场损失怎么量化？
4. **D3000M 卖给政企的售价区间、毛利率**，对标 Intel Xeon Silver/Gold、AMD EPYC、华为鲲鹏 920、AWS Graviton 谁更贵？
5. **信创 CPU 的 TAM/SAM/SOM** 到底是 $5B 还是 $30B？飞腾现在吃到几 %？
6. **飞腾的护城河**里，哪几条是真壁垒，哪几条是经不起财报拷问的"叙事壁垒"？
7. **缺 BF16 / I8MM / SVE**（战略伤疤）让飞腾失去了多少 AI 推理订单？这是商业失血还是致命？
8. **半导体周期**当前（2026）处于哪个相位？对飞腾扩产与定价是顺风还是逆风？
9. **波特五力**逐项打分，飞腾在产业链里是"能攫取价值"的一方还是"被两头挤压"的一方？
10. **5 年后**飞腾是被鲲鹏蚕食、被 RISC-V 颠覆、被制裁锁死，还是守住信创基本盘？

这 10 个问题的答案，构成本文第 2–8 节。

## 2. IP 授权经济学：飞腾这笔"自研"账，到底付了多少学费

> 这是 oracle 在战略评审中点名的**本质遗漏**：不弄清 ARM 三种授权，
> "飞腾自研 CPU"这句话的商业含义就无从评估。

### 2.1 ARM 的三种授权层级（钱、自由度、政治风险全不同）

ARM 的授权并非铁板一块，而是**三个自由度递减、价格递减**的层级 `[官方文档-ARM年报]` `[报告-Brookwood/Tirias]`：

| 授权层级 | 客户能做什么 | 代表客户 | 典型费用结构 |
|---------|------------|---------|------------|
| **ISA License**（架构授权，最高级）| 自行设计**符合 ARM ISA 的微架构**（可做自己的核）| **苹果、高通、华为海思、飞腾、亚马逊（Graviton）** | 高额 upfront license fee（数千万–上亿 USD 一次性）+ **按出货量抽 royalty（版税，约芯片售价 1–2%）** |
| **Architecture License** | 同上，但更早期/覆盖范围更窄 | （术语常与 ISA License 混用）| 类似，取决于合同 |
| **Core License**（核授权，现成 IP）| 直接买 ARM 设计好的核（Cortex-A78/X4 等），**不能改微架构** | 联发科、瑞芯微、紫光展锐、大量 IoT 厂商 | **按核授权费（per-core）+ royalty**，单核数十万–数百万 USD |

> ⚠️ 注：飞腾对外宣传的"**自研 FTC 核**"（FTC662 / FTC862），其合法性来源正是
> **ISA/Architecture License**——飞腾有权设计自己的核，只要它执行 ARMv8 指令集、通过 ARM 一致性测试。
> 这与**买 Cortex-A72/A76 现成核**（如早期展锐）是本质不同的两条商业路径。

**飞腾在三层里的位置**：飞腾是 **ISA/Architecture License 持有者** `[官方文档-飞腾]` `[推测-飞腾为进入ARM生态]`。
这给了它：
- ✅ **可自研微架构**（FTC862 = 4-wide OoO，[Lab00 实测]）——自由度最高档；
- ❌ **必须遵守 ARM ISA 边界**——指令集扩展要 ARM 批准（SM3/SM4 入 v8.4 就是中国推动的结果，见 Expert_06）；
- ❌ **必须为每颗出货芯片付 royalty**——这是无法回避的持续性现金流出。

### 2.2 授权费与版税在 BOM 里的占比（双重边际化）

ARM 的收费是典型的**双重边际化（double marginalization）**：飞腾的芯片已经含了代工厂的加价、封测厂的加价，ARM 还要在最终售价上再抽一道 royalty。量化如下 `[推测-基于ARM年报royalty模型]`：

| 项 | 估算（USD，单颗 8 核服务器 SKU） | 依据 |
|----|------------------------------:|------|
| ARM upfront license 摊销（假设一次性 $50–100M，按生命周期 5 年、年出货 200 万颗摊）| **$5–10 / 颗** | ARM 大客户 ISA license 行业估算 |
| ARM royalty（按售价 ~1.5%，售价 ~$600）| **~$9 / 颗** | ARM 年报披露 royalty 占营收大头，平均 effective rate 1–2% |
| **ARM 相关现金流出合计** | **~$14–19 / 颗** | |
| 占芯片 BOM（见 §3，~$95）的比例 | **~15–20%** | |
| 占最终售价（~$600）的比例 | **~2.5–3%** | |

**商业含义**：ARM 拿走的是"**纯利润的过路费**"——飞腾无论怎么优化微架构、怎么压代工成本，
这 15–20% BOM 的 ARM 费用是**刚性外流**。对比：
- **龙芯（LoongArch，自研 ISA）**：**零 royalty**，但代价是没有 ARM 生态、软件全靠自己移植 `[官方文档-龙芯年报]`；
- **RISC-V 厂商**：ISA 免费，但高性能核生态薄弱 `[第三方报告]`。

这就是飞腾"自研核"叙事的**第一个商业裂缝**：核是自己设计的，但**ISA 是租来的，按件付费，永不停租**。

### 2.3 ARM v9 不授权中国：被冻结在 v8.4 的市场损失量化

> 这是宪法第 6 节"关键诚实点"第一条，也是飞腾**最重的单一商业风险**。

2021 年起，ARM 推出 v9 架构，但**因英国/美国出口管制，v9 不向中国厂商授权** `[第三方报告-Reuters/SemiAnalysis]` `[推测-多方报道]`。
后果是飞腾、华为海思**双双被冻结在 ARMv8.4**。商业损失分三层量化：

**（1）指令集代际差**——v8.4（2019）到 v9.x（2021+）之间新增的关键能力 `[实测-扩展专题]` `[官方文档-ARM ARM]`：

| 能力 | 引入版本 | D3000M 是否有 | 商业后果 |
|------|---------|:------------:|---------|
| **SVE / SVE2**（可变长向量）| v8.4+ / v9 | ❌ | 向量/科学计算生态掉队（HPC、信号处理） |
| **BF16**（BFloat16）| v8.6 / v9 | ❌ | **Transformer 推理主流 FP 类型缺失**（见 §8） |
| **I8MM**（int8 矩阵乘 SMMLA）| v8.6 / v9 | ❌ | 量化推理效率落后 Graviton 3+ 数倍 |
| **MTE**（内存标签）| v8.5 / v9 | ❌ | 内存安全（buffer overflow 防护）缺失 |
| **PAuth / BTI**（指针签名/分支目标）| v8.3/v8.5 | ⚠️ 部分 | 安全特性不全 |

**（2）生态代际差**——ARM 官方与第三方工具链、编译器、性能库的新特性优先保障 v9 路线，
飞腾停留在 v8.4 意味着**享受不到 ARM 后续 5+ 年的指令集红利**，每多停一年，与 Graviton/Neoverse 的差距就累积一层。

**（3）叙事损失**——"自研 ARM CPU"的叙事里，"停留在上一代 ISA"是**不可回避的减分项**。
对追求"自主可控"的政企客户，"ISA 还是外国公司的、且只给到上一代"这个事实，
削弱了"国产化"叙事的纯度——这恰恰是龙芯 LoongArch（彻底自研 ISA）的叙事攻击点。

**量化（`[推测-依据]`）**：若 v9 解禁且飞腾获得 BF16/I8MM/SVE，按 §8 的 AI 推理订单损失估算，
**每年挽回 5–15 亿元的政企 AI 推理增量订单是可能的**（占飞腾年营收 20–60%）。v9 被锁，这笔钱就持续漏损。

> **本节诚实结论**：飞腾的"自研"是**有限自研**——微架构自己设计（真），
> 但 ISA 租用（真）、按件付 royalty（真）、且 ISA 被冻结在上一代（真）。
> 把这四条都摊在桌上看，"飞腾是国产 ARM CPU"比"飞腾是自主 CPU"在商业上更准确。

## 3. 诚实重估 BOM：否定"$20/die @7nm"

### 3.1 为什么原版假设几乎肯定错

原版写"**Die 制造（7nm 假设）$20**"。问题在于：**飞腾几乎不可能用 7nm**。
原因 `[第三方报告-出口管制]` `[推测-供应链现实]`：
- 美国 2019 年起将飞腾列入**实体清单**，先进制程（≤7nm）EUV 光刻与代工服务被切断；
- 中芯国际 7nm（N+2）产能极有限、良率受限，且同样受设备管制，**优先保障华为昇腾/鲲鹏**；
- 飞腾现实的量产工艺是 **14nm 级（中芯 N+1 / 华虹 14nm 等成熟制程）** `[推测-多源报道]`。

因此原版 "$20/die @7nm" 是建立在**飞腾拿不到的工艺**上的，必须重算。

### 3.2 14nm vs 7nm 的 die 成本量化（成本-良率-性能三角）

用业界通行的 **die 成本模型**（wafer cost ÷ good dies per wafer）`[报告-Tirias/SemiAnalysis die cost]`：

| 维度 | 7nm（原假设）| **14nm（飞腾现实）** | 差异 |
|------|----------:|----------------:|------|
| Wafer 成本（含代工）| ~$9,400 | **~$4,000–5,000** | 14nm wafer 更便宜 |
| die 面积（8 核服务器，推测）| ~80 mm² | **~120–150 mm²**（同晶体管数，14nm 密度低，die 更大）| |
| 可用 die/wafer（扣除边缘）| ~470 | **~240–280** | 14nm die 少 |
| 裸 die 成本 | ~$20 | **~$15–20** | 单看 die 成本反而接近！ |
| **良率**（defect density 影响）| ~85% | **~70–80%** | 14nm 成熟、良率尚可 |
| **good die 成本** | ~$24 | **~$19–28** | |
| **频率/能效代价** | 基准 | **频率 -20~30%、同频功耗 +30~50%** | **性能是 14nm 的真正代价** |

**关键洞察**：**14nm 的 die 成本并不显著高于 7nm**（成熟制程 wafer 便宜、良率好，抵消了 die 大的劣势）；
**真正的代价是性能与能效**——同样微架构在 14nm 上，频率上不去、功耗下不来。
这就是为什么飞腾 D3000M 在 SPEC 上追不上同代 Intel/AMD：**不是微架构不行，是工艺节点拖后腿**。

## 4. 半导体周期 + 波特五力：飞腾被架在了哪个相位

### 4.1 半导体周期（Silicon Cycle）当前相位

半导体行业有显著的 **3–4 年繁荣-萧条周期** `[论文-Aizcorbe/Flamm]` `[报告-McKinsey/BCG半导体]`，
驱动因素是**资本开支-产能-库存的滞后反馈**：

```
                 半导体周期相位图（示意，2021-2027）
   繁荣
    ▲          ●2017-18                    ●2025-26(AI驱动)
    │         /  \                        /
    │        /    \                      /
    │       /      \____            ____/
    │      /           \__________/
    │     /
   ─┼────/──────────────────────────────────────────────► 时间
    │   2019       2021    2023       2025       2027
    │     谷        峰      谷(库存)    复苏/AI   ?
    ▼  萧条
   [第三方报告-WSTS/SIA月度数据] [推测-周期外推]
```

**对飞腾的周期含义（2026）**：
- **顺周期**：AI 驱动的 2025-26 复苏，但**主要拉动 GPU/HBM/先进制程**，飞腾在 14nm 通用 CPU 上**吃不到 AI 红利的主菜**；
- **逆周期**：成熟制程（14nm 级）在下行期产能过剩、价格战；上行期又被先进制程抢走焦点；
- **结构性逆风**：飞腾的"信创基本盘"是**政策驱动而非周期驱动**，相对抗周期，
  但这也意味着飞腾**享受不到自由市场的周期上行弹性**——它被锁在政策市场里。

**定价与扩产含义**：飞腾不应追周期扩产（成熟制程产能充足），而应**在政策窗口期锁定份额**
（信创采购周期是飞腾的真正"时钟"）。

### 4.2 波特五力逐项打分（飞腾 D3000M）

> 框架来源：Porter, "How Competitive Forces Shape Strategy" (HBR 1979) `[论文]` + *Competitive Strategy* (1980) `[书]`。
> 评分：🔴 高压（飞腾吃亏）/ 🟡 中 / 🟢 低（飞腾占优）。

**① 供应商议价力 —— 🔴 高（飞腾被两头卡）**
- **ARM**：ISA 唯一供应方，royalty 刚性（§2）；
- **代工厂（中芯/华虹）**：成熟制程国内可选有限，先进制程被管制；
- **EDA（Synopsys/Cadence）**：受管制影响，工具链存在断供风险（见 Expert_16）；
- **HBM/先进封装**：飞腾服务器 SKU 若上 HBM，依赖长鑫/长电，国产替代尚在早期（Expert_15）。
→ 飞腾在上游几乎没有议价空间，**成本结构由供应商决定**。

**② 买方议价力 —— 🔴 高（政企集采，大客户主导）**
- 飞腾最大客户是**党政机关、央企、军工**，**集中采购、压价能力强** `[第三方报告-信创采购]`；
- 信创目录采购是**招标制**，价格透明、毛利被压；
- 长尾的工控/商业客户议价力低，但份额小。
→ 飞腾**卖方议价力弱**，售价天花板由集采价决定，这是原版"80% 毛利"假设的硬伤（实际远低）。

**③ 替代品威胁 —— 🟡 中高（三条替代路径）**
- **华为鲲鹏（同 ARM）**：生态最直接的替代，份额最大威胁；
- **海光（x86 授权）**：兼容 x86 生态，在已有 Windows/x86 资产的客户处是替代；
- **RISC-V**：长期颠覆者，短期生态弱（见 Lens_02 Christensen 透镜）。
→ 替代品环伺，飞腾的份额靠"政策目录在不在"而非技术壁垒。

**④ 潜在进入者威胁 —— 🟢 低（壁垒高）**
- CPU 设计门槛高（数亿研发 + 数年流片 + 生态适配）；
- ISA 授权受限（ARM v9 不给、x86 不给、RISC-V 高性能核难做）；
- 信创资质、军工资质是**行政许可壁垒**，新进入者难获取。
→ 飞腾在"**既有玩家俱乐部**"里相对安全，这是它为数不多的真护城河（§6）。

**⑤ 业内竞争 —— 🔴 高（国产 CPU 内卷）**
- 飞腾、鲲鹏、海光、龙芯、兆芯、申威**六家国产 CPU**争信创份额 `[第三方报告]`；
- 同质化（都做 ARM/x86 通用服务器 CPU）、价格战；
- 飞腾位列**第二梯队**（落后鲲鹏，与海光相当，见 §5）。
→ 业内竞争是最直接的利润挤压源。

**五力综合结论**：飞腾处于"**供应商强 + 买方强 + 业内卷 + 进入难**"的结构——
**能守住存量（进入壁垒），但攫取超额利润极难（上下游挤压）**。
这解释了为什么飞腾年营收只有 ~25 亿、净利率 ~12%（§7），而不是原版臆想的 80% 毛利。

### 7.1 真护城河（经得起财报与结构检验）

1. **政策合规（信创目录 + 军工资质）**——行政许可壁垒，新进入者数年拿不到资质 `[官方文档-信创目录]`。**这是飞腾最硬的真护城河**，波特五力"进入者威胁 🟢 低"的来源。

### 7.2 假护城河（原版三连击，本版加证据升级）

## 8. 战略伤疤正面对决：无 BF16/I8MM/SVE 的商业失血

> 这是宪法六大诚实点之一，也是 Expert_05（AI 推理）与本视角的交汇点。
> 本节从**商业损失**而非技术角度量化。

### 8.1 缺的是什么（实测锚点）

`[实测-扩展专题]`：D3000M 实测为 **ARMv8.4 全面实现，唯一缺 SVE/SVE2、BF16、I8MM、FHM**。
这三者恰好是 **2023+ Transformer 推理的主流指令集**（见 Expert_05 算子矩阵）。

### 8.2 AI 推理订单损失的量化

**假设场景（`[推测-依据]`）**：2025-27 年，政企/金融大规模"私有化部署"AI 推理（合规要求不出公网），

| 场景 | 算力需求 | D3000M 能否承接 | 替代方案 | 飞腾损失 |
|------|---------|:----:|------|------|
| 7B 模型私有部署（Q4 量化）| ~3-6 tok/s | ⚠️ 勉强（FP16，见 Expert_05）| Graviton 4 / 鲲鹏 / 思元 NPU | 部分流失 |
| 13B+ 模型推理服务 | 高吞吐 | ❌ 无 BF16，效率落后 3–5× | 必上 NPU/GPU | **全流失** |
| int8 量化服务（无 I8MM）| 矩阵乘 | ❌ 只有 UDOT，慢 4× | Graviton 3+ | **全流失** |
| 向量数据库 / embedding | SVE | ❌ 无 SVE | x86 AVX-512 | 流失 |

**量化损失估算（`[推测-依据]`）**：
- 假设政企 AI 推理私有化部署市场，飞腾若"AI 能力齐全"本可按其信创份额（10–15%）承接 ~5–15 亿元/年增量；
- 因无 BF16/I8MM/SVE，**实际只能承接通用控制面 + 小模型边缘场景**，AI 推理主单流失 **~80%**；
- **年损失估算：4–12 亿元**（占飞腾年营收 15–50%）——这是一笔**持续、累积**的商业失血。

### 8.3 商业含义：退守纯通用计算，还是被边缘化？

**两条战略路径的商业权衡**：

- **路径 A（退守通用计算）**：承认 D3000M 是"通用服务器 CPU"，AI 推理交由外挂 NPU（寒武纪思元/燧原/华为昇腾）。
  - 优点：守住通用计算基本盘，AI 算力走异构集成；
  - 缺点：**CPU 在 AI 数据中心被降格为"陪跑/控制面"**，价值占比与话语权下降。
- **路径 B（下一代补齐 AI 指令）**：D4000 必须加 BF16/I8MM/SVE2。
  - 障碍：**v9 不授权** → BF16/I8MM 是 v8.6 特性，飞腾停在 v8.4，**ARM 不一定给**；
  - 若 ARM 拒绝授权 v8.6 的这些扩展，飞腾**技术上无法补齐**（除非走自定义扩展，破坏 ARM 一致性）。

> **本节诚实结论（最重磅判断之一）**：飞腾的 AI 缺口**不仅是技术落后，更是被 ISA 授权政治锁死**——
> 即便飞腾想补 BF16，也可能**拿不到 ARM 的授权**。这意味着飞腾在 AI 时代**结构性退守**，
> 除非转 RISC-V 或自研扩展（代价巨大）。这是"**ISA 租来的**"这句话最残酷的商业兑现。

|------|-----------|
| 选 ARM ISA（而非自研/x86）| ✅ 用最低生态成本拿到可用生态，是中国长城当时的最优解 |
| 拿 ISA/Architecture License（可自研核）| ✅ 比买 Cortex 核自由度高，长期摊薄 royalty |
| 推 SM3/SM4 入 v8.4 | ✅ 国密合规是信创硬需求，差异化卖点 |
| 守信创政企基本盘 | ✅ 波特五力"进入壁垒高"，存量能守住 |

### 9.2 该改的商业决策

| 决策 | 商业问题 | 建议 |
|------|---------|------|
| 宣传"自主 CPU" | 夸大（ISA 租用 + v8.4 冻结）| 改口径为"国产 ARM CPU"，降低预期落差 |
| 80% 毛利假设 | 与集采现实不符 | 按真实毛利（~20–25%）做财务规划 |
| 无 AI 路线 | §8 战略失血 | D4000 必须解决 BF16/I8MM 授权或转 RISC-V |
| 单一 ARM 路线 | v9 被锁风险 | 投 RISC-V 备份路线（对冲 ISA 政治风险）|
| 估值叙事模糊 | 不如海光/龙芯清晰 | 强化"国密一体化 + 军工资质"差异化叙事 |

### 9.3 商业路径简史：飞腾为什么走到今天（回看决策的账）

要看懂飞腾此刻的商业处境，必须回看它**三次 ISA 路线切换**的历史账本——每次切换都有沉没成本与生态债：

- **血统期（国防科大时代）**：飞腾的前身可追溯到国防科技大学的"银河"超算与"飞腾"微处理器 lineage，
  早期走 **SPARC / Alpha** 路线（开源指令集、自主可控性强）。这段历史解释了为什么飞腾**微架构自研能力是真的**——
  它不是买核拼装的厂商，而是有数十年超标量设计底蕴的团队 `[官方文档-飞腾]`。
  但 SPARC/Alpha 生态在 2010 年代全面凋零，软件无人适配，**自主性换不来市场**。

- **转向期（拥抱 ARM ISA）**：约 2015 年前后，飞腾做出关键商业转向——放弃纯自研 ISA，
  改为**获取 ARM 架构授权、自研符合 ARMv8 的核**（即 FTC 系列）。
  这一步的账是：**用"ISA 租金"换"生态可用性"**。彼时 Android/服务器 Linux 的 ARM 生态正在崛起（华为鲲鹏同期入局），
  飞腾判断"**自研 ISA 活不下去、ARM 生态是国产 CPU 唯一可行的大生态**"。事后看，这个判断**在 2015 年是对的**——
  它让飞腾获得了可用生态、进了信创目录、活了下来 `[推测-行业复盘]`。

- **冻结期（v9 锁定）**：但 2021 年 ARM v9 不授权中国，让"用租金换生态"的这笔交易**被单方面改了条款**——
  飞腾付着同样的租金（royalty），却拿不到新一代 ISA（§2.3）。这是飞腾商业路径上**最大的非预期风险兑现**：
  当年押注 ARM 时，没有人预见到 ISA 升级会被地缘政治切断。**租金照交、红利断供**。

**回看的商业教训**：飞腾的三次路径选择，本质是在"**自主可控**"与"**生态可用**"两极之间反复摇摆。
SPARC/Alpha 选了自主、丢了生态（死局）；ARM 选了生态、丢了自主上限（被锁 v8.4）；
龙芯 LoongArch 选了彻底自主、赌长期生态能自建（高风险高叙事）。
**飞腾此刻停在 ARMv8.4，不是某个决策的失误，而是"租金换生态"这条路在地缘风暴下的必然代价。**
这笔历史账，是任何单期财报都看不出来的——这正是本视角（商业经济学家）必须补上的时间维度。

## 10. 这一视角的盲区与反方（强制诚实段）

> 商业经济学家视角**看不见什么**？这是宪法第 4.3 节强制要求，也是原版"假护城河"段的精神延续。

### 10.1 本视角的系统性盲区

1. **看不见技术突变**——商业模型基于线性外推，但**一次 ISA 政策松动（v9 解禁）或 RISC-V 突破**会瞬间重写所有估值。
   商业分析师擅长"在现有结构里算账"，不擅长预判"结构本身被推翻"。
2. **看不见地缘黑天鹅**——制裁升级/台海冲突是**非市场变量**，财务模型无法定价。
   一次成熟制程管制升级，飞腾的 14nm 退路都可能断（§7.3）。
3. **看不见工程师微观决策的价值**——BOM 模型把 die 成本当黑盒，但**一次微架构改进（如重命名容量、cache 调度）**
   带来的 IPC 提升，商业模型无法归因，会低估飞腾工程团队的真实价值。
4. **高估"份额即护城河"**——信创份额是政策给的，不是技术赢的。
   商业分析容易把"当前份额"误读为"持久壁垒"，一旦政策转向，份额蒸发比获取快得多。
5. **低估软件生态的隐性资产**——财务报表里"生态认证"不体现为资产，但切换成本是真实壁垒（§7.1）。
   商业视角倾向于低估这种"表外资产"。

### 10.2 反方意见（站在飞腾辩护方）

- "ARM royalty 只占售价 2.5–3%（§2.2），不算重负"——但这是**永续**现金流，且 v9 冻结的**机会成本**远大于 royalty 本身；
- "飞腾信创份额 10–15% 还能涨"——但涨的空间被鲲鹏/海光挤压（§7.3），不是空地；
- "缺 AI 不致命，飞腾本就是通用 CPU"——但**AI 是未来 5 年最大增量**（§6.3），退守通用等于放弃增长引擎。

### 10.3 本视角最可能误导决策之处

**把"政策红利"误读为"竞争壁垒"**。如果某位 CFO 据本分析得出"飞腾毛利稳定、份额安全"的结论，
那恰恰漏掉了**政策是外生变量**这个最大风险。飞腾的财务安全垫，建立在"**政策不转向 + 制裁不升级**"两个假设上，
而这两个假设都不在 CFO 的可控范围内。**商业分析的边界，止步于地缘与政策的边界。**

## § 半导体商业方法论与资源（不只飞腾，给所有芯片商业/投资人）

> 本章把 E07 的飞腾商业分析上升为**任何半导体商业分析师/投资人都可复用的方法与资源**。飞腾是案例锚点（信创政策市场），方法普适。通用资源见 [`领域资源库.md`](../领域资源库.md)。

### 方法论一：半导体四种商业模式

IDM（Intel/Samsung，设计+制造，资本密集）/ Fabless（NVIDIA/Qualcomm/飞腾，设计，依赖代工）/ Foundry（TSMC，代工，规模效应）/ IP 授权（ARM，授权费+版税，依赖生态规模）。飞腾 = Fabless + 信创政策市场。理解商业模式才能理解其决策（为何不 IDM？为何停留 ARMv8.4？）。

### 方法论二：波特五力 + 半导体周期（3-4 年一周期）

五力：供应商(代工/EDA)、买方(信创/DC)、替代(异构/DSA)、潜在进入者、业内竞争(鲲鹏/海光)。半导体强周期：繁荣→扩产→过剩→降价→衰退→出清→复苏，晶圆厂 100 亿美元级决策要 5-10 年前瞻。

### 方法论三：估值与财务框架

IP 授权估值（ARM 模式：授权费+版税，DCF+生态溢价）/ 芯片公司（PS 5-15×，半导体常用）/ BOM 分解（晶圆 40-50% + 封测 10-15% + IP/EDA 5-10% + 毛利）/ 政策溢价（信创订单的确定性溢价 vs 纯市场风险）。

### 半导体商业专属资源

- **市场数据**：IC Insights、SEMI（设备出货）、TrendForce/Counterpoint（份额）、SemiAnalysis（深度，付费）
- **财报**：各公司 IR 页（ARM/Intel/NVIDIA/TSMC/飞腾母公司中国软件）
- **研究**：McKinsey/BCG 半导体报告、CSIS/RAND（地缘-商业）、中国信通院
- **书**：Tilton《International Diffusion of Technology》、Jackson《Inside Intel》、Brown & Linden《Chips and Change》

### 给芯片商业/投资人的通用建议

1. **先定商业模式再估值**：Fabless/IP/Foundry/IDM 估值逻辑完全不同。
2. **半导体周期是宿命**：繁荣扩产要在衰退还本，别在顶部乐观。
3. **政策红利要折现**：信创订单政治确定性 ≠ 永久，估值给政策风险折扣。
4. **代工产能是瓶颈**：Fabless 命脉在 Foundry 产能分配（飞腾受中芯/华虹制约）。
5. **生态规模 > 单点技术**：ARM 值钱因生态，飞腾商业价值看生态而非单核。
