# 改造蓝图与写作规范（项目宪法 v1.0）

> 本文件是"飞腾 D3000M 体系结构实验项目"视角体系大改造的**最高决策文档**。

## 0. 一条战略忠告（最高原则）

> **项目护城河 = 对一颗具体芯片（FTC862 / D3000M）的密集实测剖析，不是通用半导体综述。**

新增视角的入场券 = **必须通过"D3000M 特异性测试"**：
> 删掉"飞腾/D3000M/FTC862"几个字后，若该文仍读得通 → **判定为通用教科书，失败，重写**。

每个 Expert/Lens 必须有**只有这台芯片才答得出**的具体内容（实测数据、ISA 锚点、架构决策还原、规格诚实剖析）。

**资源分配**：70% 投在「非从业者透镜 + 服务器定位致命断层深度」，30% 才铺价值链广度。**禁止用规模换辨识度。**

## 4. 质量门槛（反 E07，每个 Expert/Lens 强制）

### 4.1 Expert 硬性下限

| 维度 | 下限 | 说明 |
|------|------|------|
| 字数 | ≥ 8000 字（深度型 ≥ 12000） | E07 才约 2000 字 |
| 参考文献 | ≥ 15 条，其中 ≥ 5 条论文/标准/官方文档 | E01 分领域参考目录是模板 |
| 量化对标表 | ≥ 1 张（PPA / benchmark / 市场份额 / BOM 实数） | 禁止裸断言 |
| 图表 | ≥ 3 张（ASCII / PNG / 表格均可，鼓励原创） | E09 Roofline PNG 是范例 |
| 可运行 artifact | 技术类尽量有（代码/脚本/数据集） | 纯战略类须有 artifact（地图/决策矩阵） |
| **D3000M 特异性测试** | ✅ **必过** | 删芯片名后不能读成通用教科书 |

### 4.2 Lens 硬性下限（透镜是锐利短篇，不堆料）

| 维度 | 下限 |
|------|------|
| 字数 | ≥ 4000 字 |
| 框架引用 | 明确使用该范式的** named framework**（如 Christensen 的 disrupting innovation） |
| 飞腾命运判断 | 必须给出**具体预测/下注**（不准=空谈） |
| 对偶 | 指出该透镜与从业者视角的**冲突点** |

### 4.3 三条制度性纪律（强制）

1. **数字来源分级制**：所有数字必须标 `[实测]` / `[官方文档]` / `[第三方报告]` / `[推测-依据]`。E07 错在全是 `[推测]` 却没标依据。
2. **"盲区/弱点"诚实段强制**：每个 Expert 必须有一节"**这一视角的盲区与反方**"——敢说这一视角看不见什么、会误导什么。E07 的"假护城河"段是全篇最值钱的，强制保留这种诚实。**杜绝软文。**
3. **对偶链接强制**：每个 Expert/Lens 必须有"与其他视角对偶"段，指明一致/冲突。

## 6. D3000M 实测锚点速查（所有 Expert 必须引用的真实数据）

> 来自 Lab 实测与 `扩展专题.md`，是"特异性"的地基。

| 维度 | 实测值 | 来源 |
|------|--------|------|
| 微架构 | 4-wide issue、2 ALU/cycle、自研 FTC862 核 | Lab00 |
| L1D | 64KB/4-way @ 1.61ns | Lab03 |
| L2 | 512KB/8-way @ 4.78ns | Lab03 |
| L3 | 8MB shared @ 14ns | Lab03 |
| DRAM | 130ns | Lab03 |
| 重命名拐点 | n=10 saturate | Lab04 |
| ISA 等级 | **ARMv8.4-A 全面实现** | 扩展专题 |
| **缺失（战略伤疤）** | **无 SVE/SVE2、无 BF16、无 I8MM** | 扩展专题第25-27行 |
| LSE 原子 | v8.1，55 助记符 | 扩展专题 |
| FP16 NEON | v8.2，68 条，3.81× 加速 | Lab01 |
| UDOT INT8 | v8.4，16.9× 加速（但无 I8MM 矩阵乘） | Expert_05 |
| FCMLA 复数 | v8.3 | 扩展专题 |
| SM3/SM4 国密 | v8.4（中国推动入标的成果） | 扩展专题 |
| RAS 扩展 | v8.2（ESB/DC CVAP）—— **E23 必接** | 扩展专题第13项 |
| TLB 2M vs 4K | 4.81× | Expert_04 |
| matmul 优化 | 15× | View_03 |

**关键诚实点**：
- ARM v9 不授权中国厂商 → 飞腾**被迫停留 ARMv8.4**（非纯工程决策）
- 无 BF16/I8MM/SVE → D3000M **原生跑不了现代大模型推理**（E21 核心命题）
- 现实工艺节点受出口管制 → E07 的"7nm 假设"几乎肯定错，需诚实重估
