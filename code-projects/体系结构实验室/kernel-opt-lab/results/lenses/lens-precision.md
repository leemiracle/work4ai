## 关键洞察

- **FP16** 在 Normal(0,1)/Uniform[-1,1] 下精度好（mean_rel < 0.1%）
- **FP16** 在 Normal(0,5) / Adversarial(250) 下可能溢出（>65504）→ 必须用 BF16 或 FP32
- **INT8** 在大动态范围（WideRange）下精度严重劣化（INT8 只有 7-bit 分辨率）
- **INT8** 在均匀分布小动态范围下接近 FP16（K=1024 累加误差被 SIMD 平均化）
- **稀疏输入** FP16 误差小（累加项少），INT8 反而误差大（非零值动态范围相对大）

**工程启示**：
- 选数据类型不能只看实测 GFLOPS，必须看输入分布
- 模型推理前需做 sensitivity analysis（逐层测 FP16/INT8 误差）
- 对抗输入检测：能跑过本表说明在极端分布下不崩溃
- LLM 用 BF16 而非 FP16：BF16 范围 = FP32，精度 = FP16 tail
