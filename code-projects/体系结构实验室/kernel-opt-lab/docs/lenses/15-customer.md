## 4. 关键洞察

**本项目作为"PoC 技术底座"的真实价值——比飞腾官方 SDK 更可信。** 飞腾官方白皮书绝不会写"FP16 在 FP16 累加是算法错误""OMP_PROC_BIND 通用建议在本机反而让性能减半""Spec store bypass Vulnerable"。本项目把这些**真相全公开**，这正是第三方独立 POC 底座的核心价值——**可信来自不护短**。

**客户真正关心的 3 件事（与项目的卖点完全错位）：**
1. **我的应用能跑吗？**（兼容性，不是 GEMM）——目前答不了（B5）
2. **多少钱？**（TCO，不是 GFLOPS）——目前没算（B1）
3. **出了问题谁兜底？**（SLA + 二供，不是峰值利用率）——目前没有（B2/B8）

**金融/电信/政务三类客户差异化竞争力：**
- **金融**：合规第一（等保 2.0/信创目录），对**延迟稳定性**敏感——本项目 `lens-latency` 的 p99/p50=1.01× 是可写入合同的金字招牌；但 SSB Vulnerable 是硬伤
- **电信**：性能密度第一，按单机吞吐打分——本项目 **8 核只有 57% 效率是致命短板**（运营商集采看多核扩展性）
- **政务**：合规+成本第一，性能要求低——本项目技术深度对政务**过剩**，ROI 模型 + 信创材料才是政务最需要的
