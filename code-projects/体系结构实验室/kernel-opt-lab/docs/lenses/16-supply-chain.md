# 视角 16：半导体供应链/制造专家（Supply Chain Analyst）

> **审查时间**：2026-06-30
> **审查者**：councillor delegate（gentle-coral-otter），曾任职中芯国际/华大半导体，专长流片 + EDA + IP 授权

---

我已完整审查项目。这是一份纯软件/算法优化项目，但底层硬件（FTC862）、工具链（PhyGCC）、ISA（ARM v8.2）、OS（麒麟）全是受制裁/受地缘影响的供应链节点，而项目对这些风险**零记录**。

## 1. 视角定位

我看的是 FTC862 这颗芯片的"出生证明"和"续命药方"：它在哪家晶圆厂流片、用谁家 EDA 画出来、靠谁的 IP 授权活着、封装/存储谁供货、有没有第二来源。项目把 FTC862 当成性能优化的"既定常量"，但在我眼里它是一串随时可能断裂的供应链契约。

## 2. 八个供应链盲区

1. **流片地缘风险**：FTC862 的 TSMC 7nm 已是"沉没产能"。飞腾 2021 年 12 月被列入美 entity list，TSMC 此后不得再为飞腾接 7nm 新订单。**D3000/FTC862 的产能是"断供前存量 + 历史库存"，无法补货**。
2. **ARM ISA 授权可撤销**：飞腾只能停在 ARMv8.2。2022 年后 ARM 收紧了对被制裁实体的新 ISA 授权，飞腾**无法合法获取 ARMv9**，甚至 ARMv8.4+ 的高阶扩展（BF16/BFDOT/SVE2）授权状态存疑。这直接解释了算法科学家指出的"BF16 全缺席"——**可能不是工程遗漏，是 IP 授权拿不到**。
3. **EDA 工具断供**：下一代芯片无 Synopsys/Cadence 可用。2022 年起这些厂商对 entity list 实体断供 license。飞腾下一代若要流片，**必须依赖华大九天/概伦电子的国产 EDA**，但国产 EDA 在数字综合上与三大厂仍有 2-3 代差距。
4. **PhyGCC 的 GPL 许可证传染风险**：PhyGCC 是飞腾基于 GCC 12.3.2 定制的编译器，**GPL v3 许可证**。任何静态链接 PhyGCC 编译产物的分发，理论上触发 GPL 传染义务。下游若是闭源商业产品（信创政务云、车载），**PhyGCC 链路 = 合规雷区**。
5. **HBM/存储受制**：D3000 双通道 DDR4-3200（实测 25.6 GB/s），**无 HBM**。服务器级 AI 推理需要 HBM2/3（美光/海力士/三星，全部受出口管制），长鑫存储的国产 HBM 尚在研发早期。8 核 tiled 效率 31% 本质是 DRAM 带宽墙——**这不是软件 bug，是硬件配置的不可逆约束**。
6. **封装/Chiplet 路线被完全忽略**：FTC862 是单片 monolithic D3000。下一代服务器 SoC 主流是 Chiplet + UCIe，飞腾作为被制裁实体能否加入 UCIe 联盟、能否合法采购先进封装（CoWoS 归 TSMC）存疑。
7. **二供（second source）零备案**：工具链 PhyGCC（飞腾独供，已停产）+ OS 麒麟 V10 SP1（麒麟软件独供）+ Perfetto（Google）全单点。
8. **飞腾 entity list 身份贯穿所有输出，但项目从不声明**：本项目产出的所有代码、参数表、性能数据，若用于出口或交付境外关联实体，本身可能触发出口管制合规问题。

## 4. 关键洞察

1. **本项目最大的供应链价值是"软件库存"**。FTC862 硬件已停产，但本项目的**调优方法论 + 参数表 + bug 发现过程**是不依赖硬件再生产的"软件资产"。当飞腾下一代芯片需要快速调优时，这套方法论可平移——**算子优化知识是对冲硬件断供的对价**。
2. **国产 EDA 替代窗口决定了下一代飞腾芯片的 PPA 上限**，而本项目参数表在国产 EDA 下需全部重标定。华大九天 2026 年的数字综合能力约相当于 2018-2019 年的 Synopsys。
3. **PhyGCC 的 GPL 风险是被低估的合规地雷，但也是推动工具链自主（LLVM-based）的契机**。本项目若能在编译器 lens 基础上沉淀出"clang 等效路径"，既是性能实验，也是**许可证脱钩的合规预案**——一举两得。
