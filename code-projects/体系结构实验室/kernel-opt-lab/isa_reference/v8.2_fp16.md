## 0. 一句话

68 条 fp16 SIMD/标量指令 —— 比 fp32 SIMD 宽度翻倍（8 lane vs 4），AI 推理的关键格式。


---
## 1. 现象：为什么需要它？

深度学习推理：fp16 vs fp32 几乎无损精度，但**带宽减半 + 寄存器密度翻倍**：

```
NEON 128-bit 寄存器：
  fp32:  4 lane × 32 bit   = 4 个 float 并行
  fp16:  8 lane × 16 bit   = 8 个 float 并行  ← 2× SIMD 宽度
  int8: 16 lane × 8  bit   = 16 个 int   并行 ← 4× SIMD 宽度

→ 飞腾 fp16 GEMM 实测：6.82 GFLOPS（vs fp32 4.55，3.81× 加速）
```

**fp16 数据流（典型 Transformer attention）**：
- KV cache: fp16（减半显存）
- MatMul: fp16（加速 2×）
- Softmax/LayerNorm: 升 fp32（避免溢出）


---
## 2. 引入版本 & 飞腾状态

**版本**：ARMv8.2-A optional（FEAT_FP16 = FEAT_FPHP + FEAT_ASIMDHP）。


**飞腾 D3000M 状态**：

飞腾 D3000M 实测支持（HWCAP_FPHP + HWCAP_ASIMDHP = 1，Lab01 已测）。

- 编译：`-march=armv8.2-a+fp16` 或 `-mcpu=ftc86x`
- intrinsic：`<arm_neon.h>` 中 `vfmaq_f16` / `vld1q_f16` / `vaddq_f16` 等 `*_f16` 系列
- **不支持 FHM** (fp16→fp32 横向乘累加，FEAT_FHM 飞腾没有，但 fp16 NEON 已足够覆盖)


**杀手级应用**：深度学习推理 (LLM/Transformer/CNN) / 计算机图形 / HDR 视频 / 科学计算 mixed-precision

## 6. 性能预期（飞腾 D3000M @ 2.5 GHz）

| 精度 | SIMD 宽度 | 飞腾 D3000M GEMM | vs fp32 |
|------|----------|----------------|---------|
| fp64 | 2 lane | 1.79 GFLOPS | 0.4× |
| fp32 | 4 lane | 4.55 GFLOPS | 1.0× (基线) |
| **fp16** | **8 lane** | **6.82 GFLOPS** | **3.81×** |
| int8 (UDOT) | 4×4 dot | ~30 GOPS | 6.6× (as int ops) |

**注**：fp16 GEMM 3.81× 加速来自 Lab01 fp16_perf.c 实测。理论极限 8/4=2.0×，超额部分来自寄存器密度提升 + load 带宽节省。

## 7. 缺陷与陷阱

1. **fp16 精度**：只有 10-bit mantissa（vs fp32 的 23-bit），累加容易丢精度，需要 Kahan summation 或部分和
2. **Inf/NaN 表示**：与 fp32 不同，intrinsics 已封装但汇编层注意
3. **flush-to-zero (FTZ)**：默认 denormal 关闭（FPCR.FZ16 控制），denormal 输入会被 flush 成 0
4. **FHM 缺失**：飞腾不支持 `FMLAL v0.4s, v1.8h, v2.8h`（fp16 输入累加到 fp32），需用 vfmaq_f16 + vcvt 组合
5. **LLVM/GCC 默认 fp16 ABI**：C 标准的 `_Float16`（GCC 12+）和 `__fp16`（legacy）
6. **类型转换开销**：fp16↔fp32 转换不是零开销（FCVT 1 cycle），大块转换要并行
