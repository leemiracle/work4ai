## 0. 一句话

8 条指令覆盖 SHA3 (Keccak) 和 SHA512 —— Web3 / Ed25519 / 现代密码学哈希。


---
## 1. 现象：为什么需要它？

**SHA3 (Keccak-f[1600])** 核心是 24 轮 θ/ρ/π/χ/ι 变换。软件实现 ~300 cyc/byte，硬件 SHA3 加速指令：

```asm
EOR3  v0.16b, v1.16b, v2.16b, v3.16b   ; 3-input XOR (θ 步骤)
BCAX  v0.16b, v1.16b, v2.16b, v3.16b   ; bit-clear + xor (χ 步骤)
XAR   v0.16b, v1.16b, v2.16b, #41      ; xor + rotate (ρ 步骤)
RAX1  v0.2d, v1.2d, v2.2d              ; rotate xor (θ 步骤)
```

**SHA512** 与 SHA256 类似，但 lane 是 64-bit：
```asm
SHA512H  q0, q1, v2.2d      ; 主压缩
SHA512H2 q0, q1, v2.2d      ; 高半压缩
SHA512SU0 v0.2d, v1.2d      ; schedule 上半
SHA512SU1 v0.2d, v1.2d, v2.2d  ; schedule 下半
```

## 7. 缺陷与陷阱

1. **SHA3 不是 SHA2 演进**：完全不同的算法 (Keccak 海绵结构 vs Merkle-Damgård)，不能复用 SHA256 代码
2. **EOR3/BCAX/XAR/RAX1 是通用指令**：不止 SHA3 用，凡是 3-input bitwise 都能加速
3. **SHA512H/H2 必须配对**：单条指令只算一半 round
4. **小消息劣势**：< 64B 消息，硬件加速被 setup 开销淹没
5. **Ethereum 用 Keccak-256 不是 SHA3-256**：编码细节不同，但底层用同一指令集
