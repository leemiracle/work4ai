## 0. 一句话

FCMLA 一条指令完成 4 路复数乘累加 —— FFT/DSP/5G 波束成形的杀手锏。


---
## 1. 现象：为什么需要它？

**复数乘法朴素实现**：(a+bi)(c+di) = (ac-bd) + (ad+bc)i，需要 4 次实数乘法 + 4 次加法：

```asm
// 朴素：复数乘法 4 路 → ~16 条指令
FMUL v0.4s, v_a_re.4s, v_c_re.4s   ; ac
FMUL v1.4s, v_a_im.4s, v_d_im.4s   ; bd
FMLA v0.4s, v_a_im.4s, v_c_im.4s   ; ac+ad*ci → real part: ac + ad*ci ? actually ac - bd
... 共 ~16 条
```

**FCMLA 单条指令**：
```asm
FCMLA v0.4s, v1.4s, v2.4s, #0    ; 4 lane 复数乘累加, rotate #0
FCMLA v0.4s, v1.4s, v2.4s, #90   ; rotate 90° (用于 imag 部分)
```

→ 16 条 → 2 条（real + imag 部分），8× 加速

**寄存器布局**：lane 0,1 = (a₀.re, a₀.im), lane 2,3 = (a₁.re, a₁.im)

## 6. 性能预期（飞腾 D3000M @ 2.5 GHz）

| 任务 | 朴素 NEON | FCMLA | 加速 |
|------|---------|-------|------|
| 4-lane 复数乘 | ~16 FMLA | 2 FCMLA | **8×** |
| 1024-pt FFT (radix-4) | ~1500 cyc | ~400 cyc | **3.7×** |
| DPD feedback filter | ~100 cyc | ~30 cyc | 3.3× |

**实测（Lab01.7）**：FCMLA 加速比 ~4-8×（取决于具体 kernel）。

## 7. 缺陷与陷阱

1. **rotate 角度只能 0/90/180/270**：`#0/#90/#180/#270`，不能任意角度
2. **寄存器布局严格**：lane 必须是 (re, im, re, im) 交错
3. **rot90 vs rot180/270**：rot90 用于变换 (a+bi)→(-b+ai)，其他用于迭代
4. **HWCAP_FCMA 可能不报**：飞腾/旧 kernel 上的 bug，可用 .inst 0x... 字节码绕过
5. **FCADD 也有用**：复数加法（实际只省 1 条，不如 FCMLA 关键）
