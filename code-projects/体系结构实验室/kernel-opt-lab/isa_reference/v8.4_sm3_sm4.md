## 0. 一句话

9 条指令覆盖国密 SM3 (哈希) + SM4 (分组密码) —— 中国金融/政务合规的硬件基石。


---
## 1. 现象：为什么需要它？

**国密**是中国商用密码标准 (GB/T 32907-2016 SM4, GB/T 32905-2016 SM3)，金融、政务、电信领域强制使用。

**SM3 哈希**（类似 SHA256，256-bit 输出，64 round）：
```asm
SM3SS1    v0.4s, v1.4s, v2.4s, v3.4s   ; SS1 单步
SM3PARTW1 v0.4s, v1.4s, v2.4s          ; W 扩展 part 1
SM3PARTW2 v0.4s, v1.4s, v2.4s          ; W 扩展 part 2
SM3TT1A/B v0.4s, v1.4s, v2.4s[0]       ; T1 with table A/B
SM3TT2A/B v0.4s, v1.4s, v2.4s[0]       ; T2 with table A/B
```

**SM4 分组密码**（128-bit block, 32 round）：
```asm
SM4E     v0.4s, v1.4s                  ; 4 round parallel encrypt
SM4EKEY  v0.4s, v1.4s                  ; round key expansion
```

## 2. 引入版本 & 飞腾状态

**版本**：ARMv8.4-A mandatory（启用了 +sm3/+sm4，是中国主导加入 ARM 标准的国密指令）。


**飞腾 D3000M 状态**：

飞腾 D3000M 实测支持（HWCAP_SM3 + HWCAP_SM4 = 1，**飞腾作为国产 CPU 在国密合规上是天然优势**）。

- 编译：`-march=armv8.4-a+sm3+sm4` 或 `-mcpu=ftc86x`
- intrinsic：`vsm3ss1q_u32` / `vsm4eq_u32` 等


**杀手级应用**：国密 TLS (GMSSL) / 政务电子证书 / 银行卡芯片 / 5G 国密终端 / 区块链联盟链 (FISCO-BCOS)

### 4.3 `SM3SS1` (C7.2.261)

**语义**：SM3SS1 rotates the top 32 bits of the 128-bit vector in the first source SIMD&FP register by 12, and adds that 32-bit value to the two other 32-bit values held in the top 32 bits of each of the 128-bit vectors in the second and third source SIMD&FP registers, rotating this result left by 7 and writing the final result into the top 32 bits of the vector in the destination SIMD&FP register, with the bottom 96 bits of the vector being written to 0.

## 6. 性能预期（飞腾 D3000M @ 2.5 GHz）

| 算法 | 软件 C | 硬件指令 | 加速比 |
|------|------|---------|--------|
| SM3 (大块) | ~500 MB/s | ~2 GB/s | 4× |
| SM4-CBC | ~200 MB/s | ~3 GB/s | 15× |
| SM4-CTR | ~200 MB/s | ~3 GB/s | 15× |

**对比 AES-128-GCM**：硬件 SM4 ~3 GB/s vs 硬件 AES ~5 GB/s — SM4 略慢（SM4 算法本身更复杂），但合规性是 AES 比不了的。

## 7. 缺陷与陷阱

1. **SM4 32 round，SM4E 只算 4 round/lane**：4 lane × 4 round = 16 round，还需再 SM4E 一次
2. **SM4 key schedule 是一次性工作**：SM4EKEY 把 128-bit 用户 key 扩展为 32 个 round key，再喂给 SM4E
3. **SM3 64 round**：SM3SS1 单步 = 1 round，需调用 64 次 + SM3PARTW 4 次（W 扩展）
4. **intrinsics 命名混乱**：`vsm3ss1q_u32` vs `vsm3ss1_u32`（前者 128-bit，后者标量），易混
5. **国密合规要求 FIPS 140-2 等级认证**：硬件指令本身合规，但实现要看证书
6. **不要把 SM4 跟 SMS4 混淆**：SMS4 是早期名，现统一为 SM4
