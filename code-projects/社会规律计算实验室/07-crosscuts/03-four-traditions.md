## 1. 为什么有这个专题

张博伦、周浥莽（2026）在《社会学评论》指出：计算社会科学里的「计算」被笼统使用，导致方法论讨论失焦。他们拆出**四传统**：

```
公理（ABM/形式化）        描述（统计建模）
       \                    /
        \                  /
         \                /
          \              /
           四传统整合
          /              \
         /                \
        /                  \
       /                    \
预测（ML/黑箱）          实验（RCT/DID/RDD）
```

本项目的目标：**不是用一种方法解决所有问题，而是四传统组合应用**。

## 3. 四传统整合的具体实验（前沿）

### 实验 A：公理 + 描述（ABM + 统计）
**目的**：让 ABM 的输出和数据匹配
- Schelling 模型跑出 80% 隔离 → 用真实城市数据（陆铭方法）测密度梯度
- 比较"ABM 预测的 γ" vs "真实数据的 γ"
- 这是 Schelling 模型**第一次有真实校准**

代码骨架：
```python
# 1. 跑 Schelling（公理）
schelling_gamma = run_schelling(threshold=0.3)

# 2. 计算真实数据 γ（描述）
real_gamma_shanghai = compute_density_gradient(shanghai_grid)

# 3. 比较
print(f"Schelling γ={schelling_gamma:.2f} vs 上海真实 γ={real_gamma_shanghai:.2f}")
# → 看 Schelling 模型在多大程度上预测了真实隔离
```

### 实验 B：公理 + 预测（ABM + ML）
**目的**：用 ML 学习 ABM 的"规则"
- Schelling 模型跑 1000 次
- 用 ML 学习"什么阈值下产生什么隔离度"
- 反过来：用 ML 预测"如果一个新城市用某规划，会怎样"

### 实验 C：公理 + 实验（ABM + 因果）
**目的**：ABM 做反事实，实验做验证
- ABM 预测：如果上海放开人口控制，γ 从 0.48 → 1.32
- 实验验证：找一个自然实验（某城市突然放开户籍）

### 实验 D：四传统全整合（终极）
- ABM（公理）生成数据
- ML（预测）找模式
- 因果模型（实验）识别机制
- 统计模型（描述）做理论解释

→ 这就是 Salganik《Bit by Bit》第 6 章描绘的"计算社会科学的未来"。

## 4. 与本项目已读论文的对应

| 论文 | 主导传统 |
|---|---|
| **陆铭《倾斜城市》** | 描述（统计拟合）+ 实验（binscatter + 固定效应） |
| **屈小博《AI 暴露》** | 预测（LLM 构建暴露度）+ 描述（回归分析） |

| **强世功《重读亨廷顿》** | 公理（理论解读）—— 无数据 |
| **张博伦《计算多义性》** | 元方法论的反思（本专题基础） |
| **封凯栋《纳尔逊创新竞争》** | 公理（演化经济学理论） |
| **陈小鼎《世界政治极化》** | 公理（框架建构）—— 政治学少实证 |

**观察**：
- 经济学论文（陆铭、屈小博）= 描述 + 实验为主
- 社会学/政治学理论文章（刘梦岳、强世功、陈小鼎）= 公理为主
- 真正的四传统整合论文在中国 CSSCI 里**还很少**——这是机会！
