## 一、问题

2007 年，Bettencourt 等人在 *Science* 发现：**城市的几乎所有指标都按 N^β 缩放**：
- β ≈ 1.15：工资、专利、GDP（超线性）
- β ≈ 0.85：道路、加油站（次线性）

Geoffrey West 2017《Scale》把这写成畅销书。

**问题**：这套规律在中国成立吗？

中国特殊情况：
- 户籍制度限制人口流动
- 政府主导城市化（"撤县设区"等行政手段）
- 土地财政依赖
- 与西方自发城市化路径不同

→ 中国的 β 应该和 West 的 1.15 不同。

### 已有的中国研究

- 用中国地级市数据复现 West 法则

- 但 β_工资 ≈ 0.95-1.05（比 West 低）—— 因为户籍压制了工资
- β_专利 ≈ 1.25-1.40（高于 West）—— 中国大城市创新超线性更强

## 四、政策含义：陆铭《大国大城》的核心主张

陆铭基于 West 法则 + 中国数据，提出**反主流政策主张**：

### 主流政策（1978-2018）
- "严格控制特大城市规模"
- "大力发展中小城市"
- 户籍限制、土地指标向中小城市倾斜

### 陆铭的反驳
- West 1.15 法则证明：**大城市人均产出更高**
- 控制大城市 = 牺牲效率
- 应该：放开户籍、集中人口到几个超级都市圈（长三角、珠三角、京津冀）
- 中小城市分散发展 = "土地财政依赖" + "鬼城"

### 数据支撑
- 上海人均 GDP ≈ 全国 2.5 倍
- 但上海人口被严格控制在 2500 万（远低于自然均衡）
- 如果放开到 4000 万，全国 GDP 可增加 10%+

### 政治争议
- 陆铭主张被批评为"东部中心主义"
- 但 2019 年后中央政策开始转向——
- "城市群"战略、户籍逐步放开、长三角一体化
- 部分印证陆铭主张

## 五、批判：West 法则的局限

### 1. β 不是常数
- 不同国家/时期 β 不同
- 技术革命（如 AI）会改变 β
- 远程工作（WFH）可能"打破" 1.15 法则

### 2. 城市定义模糊
- 中国"市"包括大量农村（地级市 ≠ 真正城市）
- 美国 metropolitan area 更接近"功能城市"
- 比较时要注意定义

### 3. β > 1 也有坏处
- 犯罪、污染、传染病也按 1.15 增长
- COVID-19 在纽约、武汉爆发最快
- "大城市病"是真实的

### 4. 中国特殊情况
- 户籍压制了 β_工资
- 政府干预扭曲了市场
- 但创新（专利）β 更高——政策红利

### 5. 网络时代
- 远程工作让"地理接近"的价值下降？
- 但 2020-2026 数据显示：**超大城市继续增长**
- 数字经济反而加剧聚集（程序员去硅谷/深圳/北京）

## 六、对比：West vs 中国学者的对话

| 议题 | West 立场 | 中国学者（陆铭等）立场 |
|---|---|---|
| 城市规模 | 1.15 法则普适 | 中国 β ≈ 1.05-1.20 |
| 政策含义 | 自然城市化 | 政府应**主动放开**大城市 |
| 户籍 | 不涉及 | 中国特色限制，应废除 |
| 工资 | 人均工资 ~ N^0.15 | 中国更低（户籍压制） |
| 创新 | 专利 ~ N^1.25 | 中国更高（政策红利） |
| 大城市病 | 同样按 1.15 增长 | 需要治理而非限制 |

→ 这就是真正的"理论 + 实证 + 跨文化对话"研究。
