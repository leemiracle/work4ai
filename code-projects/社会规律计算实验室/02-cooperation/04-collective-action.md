# 04 · Collective Action · 集体行动的悲剧与突破

> **Olson vs Ostrom**：搭便车不可避免 vs 公地可以自治——20 世纪社会科学最伟大的辩论之一。

---

## 1. 历史：三本书定义了一个问题域

### 1965 — Olson《The Logic of Collective Action》
Mancur Olson 用博弈论证明：**理性个体不会自愿贡献公共物品**。
- 公地悲剧（Hardin 1968）：每个牧民都多放一头牛，草地毁了
- 搭便车（free rider）：你不付钱也能享受路灯
- 大集团比小集团更难组织集体行动

Olson 的悲观结论：**集体行动需要"选择性激励"**（给贡献者额外奖励、对搭便车者惩罚）。

### 1968 — Hardin《The Tragedy of the Commons》
Garrett Hardin 在 *Science* 发表短文：用 Olson 的逻辑解释公地悲剧，结论是：
> "自由使用公共物品必然导致灾难。"

主流经济学接受了：要么私有化（产权学派），要么政府管制（国家干预）。

### 1990 — Ostrom《Governing the Commons》
政治学家 Elinor Ostrom 做了一件不被当时主流接受的事：**她去现场**。

她研究了瑞士高山草场、日本渔村、加州地下水、缅因森林——**全是公地，全都没悲剧**。当地社区**没有私有化也没有政府管制**，而是发展出一套**自治制度**，运转了几百年。

**Ostrom 的颠覆性发现**：Olson 和 Hardin 错了。公地悲剧**不是必然**——只要满足 8 个条件，社区可以自治公地。

2009 年，Ostrom 获诺贝尔经济学奖（首位女性得主）。

## 2. 公地悲剧的博弈论基础

### 单次囚徒困境
```
            合作 C    背叛 D
合作 C    (R, R)     (S, T)
背叛 D    (T, S)     (P, P)
```

设 $T > R > P > S$（囚徒困境）。
- 集体最优：(C, C)，每人得 R
- 个体最优：D 是占优策略 → 双方都 D，每人得 P < R
- **个体理性导致集体非理性**

### N 人公共物品博弈
N 个人，每人可以选择"贡献" $c_i \in [0, y]$ 或"不贡献" $c_i = 0$。
- 公共物品总量 $G = \sum c_i$
- 每人收益 = $\frac{G}{N} + (y - c_i)$（公共物品均分 + 私人剩余）

**问题**：你贡献 1 元，自己只拿回 $1/N$ 元（其他 $N-1$ 人拿走）。
- N 大时，每元贡献的私人回报接近 0
- 所以 $c_i = 0$ 是占优策略
- → 所有人不贡献，公共物品消失

**这是 Olson 的数学核心**。

## 3. Ostrom 八原则

Ostrom 通过跨案例比较，提炼出**成功的公地自治必须满足的 8 条原则**：

### 原则 1：清晰界定的边界（Boundaries）
谁能用、谁不能用，必须明确。
- 瑞士 Torbel 村：只有 1491 年前定居的家族有放牧权
- 失败案例：加州地下水 anyone-can-pump → 过度抽取

### 原则 2：规则与本地条件匹配（Congruence）
规则要符合当地生态和社会条件，不能"一刀切"。
- 日本渔村按鱼汛期、鱼种定规则
- 失败案例：殖民政府套用欧洲森林法到热带雨林

### 原则 3：集体选择安排（Collective Choice）
受规则影响的人能参与修改规则。
- 失败案例：政府自上而下命令，地方无发言权

### 原则 4：监督（Monitoring）
监督者对资源使用者负责（不是上级）。
- 阿尔卑斯村庄选本村人当"草场监督员"
- 失败案例：远在首都的官僚监督，根本看不到现场

### 原则 5：渐进式制裁（Graduated Sanctions）
违反者先受轻罚，重犯才重罚。
- 第一次：警告。第二次：小额罚款。第三次：剥夺使用权
- 失败案例：一上来就严刑峻法 → 大家都违规 → 法不责众

### 原则 6：冲突解决机制（Conflict Resolution）
低成本、快速的纠纷解决渠道。
- 村民议事会、长老调解
- 失败案例：所有纠纷都上法庭 → 慢、贵、关系破裂

### 原则 7：最低限度认可（Minimal Recognition of Rights）
外部权威（政府）承认社区自治权。
- 失败案例：政府不承认村规，强制国有化 → 自治崩溃

### 原则 8：嵌套式企业（Nested Enterprises）
大系统由小系统组成，每层都有自己的规则。
- 瑞士草场：村 → 镇 → 州 → 联邦，每层都自治

## 4. Ostrom 八原则的博弈论解读

Ostrom 八原则不是经验总结，而是**改造博弈结构的 8 种机制**：

| 原则 | 改造了博弈的什么 | 数学对应 |
|---|---|---|
| 1 边界 | 谁是"N 人"博弈的玩家 | 缩小 N |
| 2 匹配 | 支付矩阵参数 | 改变 T/R/P/S |
| 3 集体选择 | 重复博弈而非单次 | 让博弈无限重复 |
| 4 监督 | 信息不对称减少 | 监督改变 $P(\text{背叛被发现})$ |
| 5 渐进制裁 | 制裁成本是凸的 | 把 P 改成 P(c) |
| 6 冲突解决 | 协商成本降低 | 让重新谈判成为可能 |
| 7 外部认可 | 自治是稳定均衡 | 排除外部"颠覆者" |
| 8 嵌套 | 多层级博弈 | 元博弈（meta-game）|

**Ostrom 的真正贡献**：把"单次囚徒困境"改造成"无限重复博弈 + 廉价监督 + 渐进制裁"——这时合作变成均衡。

这就是 **Folk Theorem**（民间定理）的应用：在无限重复博弈中，几乎任何合作都可以是均衡，只要大家重视未来。

## 5. 三种治理模式的对比

| 模式 | 主张者 | 适用条件 | 失败模式 |
|---|---|---|---|
| **私有化** | Coase, 产权学派 | 资源可分割、可定价 | 公平问题、市场失灵 |
| **政府管制** | Hardin, Pigou | 大规模、外部性强 | 信息不对称、寻租 |
| **社区自治** | Ostrom | 8 条原则满足 | 不适用超大群体 |

Ostrom 不否认前两种模式，她强调**第三种被忽视**。她的真正贡献是证明：**没有"一刀切"的最优解，要看资源特征、群体规模、生态条件**。

## 6. 现实案例

### 成功案例
- **瑞士 Torbel 高山草场**（自 13 世纪自治至今）
- **日本平野村灌溉系统**（300 年传统）
- **缅因湾龙虾渔业**（渔民自治，资源稳定）
- **西班牙瓦伦西亚水管系统**（千年水法庭）

### 失败案例（违反 8 条原则的）
- **纽芬兰鳕鱼崩溃**（1992）：政府忽视渔民警告，过度捕捞
- **咸海干涸**：苏联中央计划，无视生态
- **亚马逊雨林**：政府鼓励开发，无社区自治
- **全球大气**：N=80 亿，无监督，无制裁 → 气候变化

### 中国案例
- **福建土楼**：宗族自治，几百年的"公共住宅"
- **浙江鲁家村**：早期家庭联产承包 + 集体保留
- **草原承包**：1980 年代后草场承包到户，部分地区因过小规模反而退化（违反"嵌套"原则）

## 7. 现代延伸

### 数字公地
- **开源软件**（Linux, Wikipedia）：贡献者获得声誉（间接互惠）
- **维基百科**：监督 + 渐进制裁 + 集体选择 → Ostrom 原则数字化
- **共享单车**：违反原则 1 和 4 → 满地废车

### 环境治理
- **碳交易**：混合模式（政府设上限 + 市场交易 + 社区参与）
- **流域共治**：上游下游联合治理

### AI 时代的新公地
- **数据隐私**：数据是公地还是私产？
- **AI 训练语料**：谁有权使用？怎么治理？
- **算法公共影响**：算法本身是新的"公地悲剧"来源

## 8. 批判与争议

### 对 Olson 的批评
- 实验经济学显示：人类合作率比理论预测高 40%（Fehr-Gächter 2002）
- 强互惠（strong reciprocity）：人会花成本惩罚搭便车者
- 文化差异：东亚合作率高于北美

### 对 Ostrom 的批评
- **样本偏倚**：她选的全是成功案例（生存者偏差）
- **规模限制**：8 条原则对大群体（N > 1000）不适用
- **可持续性神话**：有些"千年传统"在气候变化下崩溃了

### 元批判
- Ostrom 八原则本质是"理性设计"——但社区制度往往是演化的
- "自治"有时掩盖了**内部权力不平等**（族长/男性垄断决策）
