# 01 · Dual Inheritance Theory · 双传承理论

> **Boyd & Richerson (1985)**《Culture and the Evolutionary Process》：人类演化有两条并行通道——基因和文化。它们互相塑造，有时文化甚至反转基因压力。

---

## 1. 历史：基因演化的"标准答案"不够

### 标准答案（Wilson 1975《Sociobiology》）
人类行为主要由基因决定：
- 利他 = 亲缘选择（Hamilton）
- 配偶选择 = 繙殖适应度优化
- 攻击性 = 雄性竞争

### 反例
- **成人乳糖酶持续**：基因层面，所有哺乳动物成年后停止产乳糖酶。但北欧人、东非牧民成人继续产——这是文化（畜牧业）反向选择基因。
- **疟疾与镰状细胞**：非洲镰状细胞基因频率高 = 农业文化（砍伐雨林 → 蚊子繁殖 → 疟疾增加 → 镰状细胞抗疟疾）
- **颅骨变形 / 纹身**：纯文化，无基因适应意义

### Boyd-Richerson 的回答
**人类演化是双轨的**：基因 + 文化平行演化，互相影响。

---

## 2. 数学：双传承演化方程

### 基因演化
等位基因频率 $p$ 的变化（标准群体遗传学）：
$$
\Delta p = \frac{p(1-p)}{\bar w} \cdot \frac{\partial \bar w}{\partial p}
$$
- $\bar w$ = 平均适应度
- 选择系数 = $\frac{\partial \bar w}{\partial p}$

### 文化演化（Boyd-Richerson）
文化特征频率 $q$ 的变化：
$$
\Delta q = \underbrace{q(1-q) s_c}_{\text{自然选择}} + \underbrace{q(1-q) s_g}_{\text{引导变异}} + \underbrace{\text{bias}}_{\text{文化偏差}} + \underbrace{\text{random}}{\text{随机漂变}}
$$

四种文化演化机制：
1. **自然选择**：某些文化特征让人繁殖更快
2. **引导变异**：个人试错后选择更有效的
3. **文化偏差**：
   - **从众偏差**（conformist）：跟大多数人
   - **榜样偏差**（prestige）：模仿成功者
4. **随机漂变**：小群体里随机波动

### 关键定理
**Boyd-Richerson (1985)**：当环境变化快、个人学习成本高时，**从众偏差**演化出来——这让人牺牲准确性换效率。

→ 这解释了为什么人类有"群体盲从"倾向。

## 3. 文化 vs 基因的相互作用

### 案例 1：成人乳糖酶持续
- 基因层面：LCT 基因调控
- 文化层面：畜牧业（约 1 万年前出现）
- 双传承：文化（畜牧业）→ 选择压力 → 基因（LCT 持续）扩散
- 今天：北欧 95%+，东亚 < 5%（无畜牧业文化）

### 案例 2：疟疾与镰状细胞
- 基因：HbS 抗疟疾但导致镰状细胞贫血
- 文化：约 3000 年前非洲班图人开始砍伐雨林种地 → 静水增加 → 按蚊繁殖 → 疟疾爆发
- 双传承：文化（农业）→ 环境（疟疾）→ 基因（HbS）

### 案例 3：火与烹饪
- 基因：Homo erectus 约 150 万年前肠子缩短
- 文化：用火烹饪（约 200 万年前）
- 双传承：烹饪 → 食物更易消化 → 肠子可以更短 → 大脑可以更大（Wrangham "Catching Fire"）

### 案例 4：一夫一妻制
- 基因：人类本来像黑猩猩（一夫多妻）
- 文化：约 1 万年前农业社会 → 财产传承需要确定父亲 → 一夫一妻
- 双传承：文化（财产制度）→ 性选择压力 → 基因（伴侣绑定激素 Oxytocin 敏感性）

## 4. 文化演化的速度

### 比基因演化快 100-1000 倍
- 基因：一代人 25 年，单一突变扩散需 100+ 代
- 文化：一个 meme 一周传遍世界
- → 文化演化主导近期人类变化

### 但也有"惯性"
- 文化有路径依赖（制度、规范一旦形成难改）
- 文化有"规范心理学"——人会内化规范，反对变革
- 文化有"群体惩罚"——偏离规范者被排斥

### Henrich 的"文化-基因共同演化"
Joe Henrich（Boyd 学生）扩展理论：
- 人类群体的"集体大脑"——知识在群体中累积
- 文化演化先于基因演化：先有狩猎技术（文化）→ 才有相应身体特征（基因）
- 现代人脑容量在过去 2 万年**下降** 10%——因为文化储存知识，脑不需要那么大

## 5. 现代应用

### AI 时代
- LLM 是新的"文化载体"——但只有 70 年训练数据
- LLM 也能演化（fine-tuning）但比人类文化快百万倍
- → LLM 可能与人类文化"共同演化"，影响不可预测

### 公司文化
- 文化偏差：新人会"从众"（不挑战既定规范）
- 榜样偏差：员工模仿成功高管
- → 公司文化有强路径依赖，难以改变

### 全球化
- 文化演化从"地方"变成"全球"
- 全球文化（互联网文化）正在吞噬地方文化
- Henrich 警告：WEIRD（Western Educated Industrial Rich Democratic）心理学样本不能代表人类

## 6. 批判

### 对 Boyd-Richerson
1. **文化"特征"如何定义？**：离散的还是连续的？单位是什么？
2. **"偏差"机制过于模糊**：从众 vs 榜样 vs 引导，难分离
3. **文化演化的"适应度"难以测量**
4. **忽略权力结构**：文化演化是谁推动的？精英？大众？

### 元批评
- 双传承理论仍是"西方演化主义"框架
- 不适用于纯建构主义社会学（Berger-Luckmann）
- 文化是否真的"演化"还是"流变"？这是元问题
