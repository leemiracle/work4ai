## 核心命题回顾

跑完本子领域，你应该能用 5 句话总结：

1. **人类演化是双轨的**（基因 + 文化）
2. **文化演化比基因快 100-1000 倍**
3. **DeGroot 模型：连通网络必然共识**
4. **SIR 模型：信息扩散 = 疾病扩散**
5. **算法是新的"超级文化偏差机制"**

---

## 进阶批判

1. **Boyd-Richerson 的"特征"定义模糊**
2. **DeGroot 假设观点连续可加**——但信念可能是离散的
3. **SIR 假设均匀混合**——真实网络是异质的
4. **文化演化 ≠ 文化进步**：演化无方向，可能"倒退"
5. **WEIRD 偏见**：现有文化演化研究主要来自西方样本
