## 五、抓取可行性评估（与本项目对接）

### ✅ 完全可抓（开放 API）
- **arXiv API**：`export.arxiv.org/api/query?search_query=...`（已验证可用）
- **OpenAlex API**：`api.openalex.org/works?search=...`（2.5 亿篇元数据）
- **Semantic Scholar API**：`api.semanticscholar.org/graph/v1/...`
- **NBER Working Papers**：直接 HTML 抓取
- **RePEc / IDEAS**：HTML 抓取

### 🔶 部分可抓（需注册）
- **SSRN**：注册后可下载，自动化需 cookie
- **JSTOR**：机构订阅才能下全文
- **Connected Papers**：API 受限

### ❌ 不可抓
- **Elsevier/Springer/Taylor&Francis 期刊**：付费墙
- **EBSCO/ProQuest**：付费墙
- **Google Scholar**：强反爬

## 八、抓取示范：arXiv API（已验证可用）

```python
import urllib.request
import xml.etree.ElementTree as ET

def search_arxiv(query, max_results=10):
    """搜索 arXiv 论文"""
    url = f"http://export.arxiv.org/api/query?search_query=all:{query}&max_results={max_results}"
    with urllib.request.urlopen(url) as r:
        data = r.read().decode()
    root = ET.fromstring(data)
    ns = {'atom': 'http://www.w3.org/2005/Atom'}
    papers = []
    for entry in root.findall('atom:entry', ns):
        papers.append({
            'title': entry.find('atom:title', ns).text.strip().replace('\n', ' '),
            'authors': [a.find('atom:name', ns).text for a in entry.findall('atom:author', ns)],
            'summary': entry.find('atom:summary', ns).text.strip()[:300],
            'link': entry.find('atom:id', ns).text,
            'published': entry.find('atom:published', ns).text[:10],
        })
    return papers

# 示例：搜 LLM agent 社会仿真
papers = search_arxiv("generative agents LLM social simulation", max_results=5)
for p in papers:
    print(f"- {p['title']}")
    print(f"  {p['authors'][0]} et al. ({p['published']})")
    print(f"  {p['link']}")
```

→ **可立即跑**，不需要登录。
