# Methodology · 数学如何介入社会科学

> 这是整个项目的方法论核心。如果你只读一篇 docs，读这篇。它解释了我们**为什么**用数学研究社会、用**哪些**数学、以及最重要的——**这套方法的边界在哪里**。

---

## 〇、子领域 vs 方法：研究的两条轴线

任何社会研究项目都可以沿两个轴线组织：

```
                方法轴（工具的内逻辑）
                网络科学 / 博弈论 / 复杂系统 / ABM / 因果推断 / LLM-Agent
                              ↑
                              │
                              │
             ┌────────────────┼────────────────┐
             │                │                │
   relations │ cooperation    │ inequality     │  ← 子领域轴
             │ power-politics │ culture-cog    │   （研究对象的内规律）
             │ markets-cities │ crosscuts      │
             └────────────────┼────────────────┘
                              │
                              ↓
                          现实世界
```

### 为什么本项目以子领域为主轴？

传统教科书按方法分（"博弈论教程"、"网络科学教程"）——学完你会拥有一堆工具，但**不知道要修什么**。

按子领域组织的好处：

1. **社会规律是长在子领域里的**——"革命"、"极化"、"合作"是真实议题，不是工具的附属品。
2. **每个子领域自然涉及多种方法**——研究革命既要博弈论（个体决策）、又要复杂系统（相变）、又要网络（信息级联）。**避免工具单一化盲点**。
3. **跨子领域结合才能产生新洞见**——例如"算法 × 极化"是过去 10 年最重要的社会议题之一，它在两个子领域的接缝处。
4. **故事感与历史感更强**——Schelling 模型是为了解释美国种族隔离（具体问题），不是为了"推广元胞自动机"（抽象方法）。

### 工具箱仍然完整

子领域为主轴，**方法不会丢**——它会作为工具反复出现在多个子领域里：

| 方法 | 出现在哪些子领域 |
|---|---|
| 网络科学 | relations（基础）, crosscuts（犯罪/算法极化） |
| 博弈论 | cooperation（基础）, power-politics（投票）, markets-cities（拍卖） |
| 复杂系统 / 相变 | inequality（涌现）, power-politics（革命）, markets-cities（隔离） |
| ABM | inequality（Sugarscape）, markets-cities（Schelling） |
| 动力系统 | culture-cognition（SIR/观点动力学）, power-politics（革命） |
| 因果推断 | inequality（社会流动）, crosscuts（算法公平） |
| LLM-Agent | crosscuts（Generative Agents） |

## 一、两种认识社会的姿态：还原论 vs 涌现论

社会科学里有延续百年的方法论之争：

### 还原论（Reductionism）
> 把社会现象**还原**到个体决策，理解了个体就理解了整体。

代表：**博弈论、理性选择理论、微观经济学**。

例子：理解"价格战"，只要理解两家公司各自的利润最大化决策，用博弈论推导均衡。

**核心工具**：优化、均衡、纳什、效用函数。

### 涌现论（Emergence）
> 个体规则简单，但群体层面会产生**完全无法从个体预测**的模式。

代表：**复杂系统、Agent-Based Models、统计力学类比**。

例子：美国城市的种族隔离不需要任何人有"种族歧视"——只要每个人都有"我不想成为社区里少于 30% 的少数"这种温和偏好，**整体就会涌现极端隔离**。

**核心工具**：仿真、相变、网络、幂律、自组织。

### 本项目的立场：两条腿走路 + 网络视角

- **博弈论**回答"理性个体会怎么做"
- **复杂系统**回答"很多个体在一起会发生什么"
- **网络科学**是两者的桥梁——既关心个体（节点）也关心整体（拓扑）
- **数据科学/因果推断**是现实校准——告诉你上述模型在真实数据里成立不成立

```
              微观（个体）
                  ↑
                  │
        博弈论    │   理性选择
        ─────────┼─────────
        复杂系统  │   ABM
                  │
              宏观（群体）→ 时间/动态
```

## 二、数学介入社会科学的三条路径

历史上有三种"把社会数学化"的方式：

### 路径 A：公理化（Axiomatic）—— 经济学的选择
从一组关于人类行为的公理出发（理性、自利、偏好一致），逻辑推导定理。
**代表**：亚当·斯密 → 阿罗-德布鲁 → 现代微观经济学。
**胜利**：阿罗不可能定理（1951）——证明没有任何投票规则能同时满足五个合理公理。

### 路径 B：动力学化（Dynamical）—— 物理学的启发
社会变量（人口、观点、流行病、技术）随时间变化，用微分方程描述。
**代表**：Verhulst（Logistic 方程，1838）→ Lotka-Volterra → SIR 模型。
**胜利**：Kermack-McKendrick SIR 模型（1927），今天所有 COVID 建模都是它的后代。

### 路径 C：网络化 / 计算化（Network/Computational）—— 当代主流
社会是嵌入在**关系网络**中的异质个体；不能用方程解析的，就**仿真出来**。
**代表**：Granovetter（1973）→ Schelling（1971）→ 复杂网络（1998-）→ Generative Agents（2023）。
**胜利**：Schelling 隔离模型——几个 if-else 推翻了"隔离 = 歧视"的常识。

**本项目的重点**就是路径 C，因为它最契合"应用数学工程师"——能写代码、能跑仿真、能用数据。

## 三、警示：物理学妒忌（Physics Envy）

数学化社会科学有反复出现的失败模式：

> 看到物理学用 $F = ma$ 描述世界那么成功，社会科学家也想找一个 $S = f(x)$ 来描述社会。结果造出来的"理论"看起来像物理，实际上是数学包装的故事。

### 典型症状
1. **过度拟合参数**：8 个参数拟合 10 个数据点。
2. **不可证伪**：模型在所有情况下都"对"——因为可以随便调参。
3. **无视情境**：把西方现代社会的规律外推到所有时代所有文化。
4. **数学形式 > 解释力**：方程很漂亮，但解释力不如白话。

### 本项目的态度
- **每个数学模型都要回答**："如果它错了，世界会是什么样？" 答不上来就不是科学。
- **优先简单模型**：3 个参数能说清楚的事，不用 10 个。
- **永远用数据校准**：差太多就承认模型不对。
- **历史情境敏感**：19 世纪的"人口规律"在 21 世纪可能完全不成立。

## 四、五个奠基性案例

每个项目成员都该熟悉——它们是"数学化社会科学"的标志性胜利。

### 案例 1：Schelling 隔离模型（1971）→ 子领域 6
**问题**：为什么美国城市种族隔离这么严重？是种族歧视吗？
**数学**：棋盘上每人要求"至少 30% 邻居和我同类，否则搬家"。
**结果**：跑下来隔离度高达 80%。**温和偏好 → 极端隔离**。
**意义**：政策含义颠覆——光消除歧视不够，必须改变**搬家机制**本身。

### 案例 2：Granovetter 弱连带（1973）→ 子领域 1
**问题**：找工作，至亲好友有用还是泛泛之交有用？
**数学**：网络结构 + 信息冗余度。
**结果**：**弱连带更有用**。强连带信息高度重合，弱连带才桥接到新信息。
**意义**：奠定了社会网络分析的基础。

### 案例 3：Watts-Strogatz 小世界（1998）→ 子领域 1
**问题**：为什么"六度分隔"是真的？
**数学**：在规则网络基础上随机重连少量边。
**结果**：少量随机边让"平均距离"暴跌，但聚类系数几乎不变。
**意义**：第一次用数学严格解释了一个被观察了几十年的现象。

### 案例 4：Nowak 合作演化（1992-2006）→ 子领域 2
**问题**：自然选择鼓励自私，为什么生物界有那么多合作？
**数学**：重复囚徒困境 + 演化博弈。
**结果**：合作可以通过 **5 条规则**涌现——亲缘选择、直接互惠、间接互惠、网络互惠、群体选择。
**意义**：把道德问题变成了可仿真的科学问题。

### 案例 5：Park 等 Generative Agents（2023）→ 子领域 7
**问题**：能不能用 LLM 模拟出"像真的"的小型社会？
**数学**：每个 agent 是有记忆、目标、计划能力的 LLM 实例。
**结果**：25 个 AI agent 在沙盒小镇自发举办情人节派对、形成意见领袖。
**意义**：社会科学第一次有了**实验室级别**的"社会实验"工具。

## 五、研究流程：从问题到结论

```
   ┌──────────────────────────────────────────┐
   │  1. 现象观察：什么社会现象让你困惑？        │
   └──────────────────────────────────────────┘
                    ↓
   ┌──────────────────────────────────────────┐
   │  2. 文献定位：前人怎么解释？哪些不满意？    │
   └──────────────────────────────────────────┘
                    ↓
   ┌──────────────────────────────────────────┐
   │  3. 建模：选最小化的数学/计算模型         │
   │     （博弈？网络？ABM？动力系统？）       │
   └──────────────────────────────────────────┘
                    ↓
   ┌──────────────────────────────────────────┐
   │  4. 仿真：用代码跑一遍，看涌现什么        │
   └──────────────────────────────────────────┘
                    ↓
   ┌──────────────────────────────────────────┐
   │  5. 校准：和真实数据对比                  │
   └──────────────────────────────────────────┘
                    ↓
   ┌──────────────────────────────────────────┐
   │  6. 批判：遗漏了什么？什么情况下失效？     │
   │     谁是受益者谁是受害者？                │
   └──────────────────────────────────────────┘
                    ↓
   ┌──────────────────────────────────────────┐
   │  7. 写出来：可复现的报告                  │
   └──────────────────────────────────────────┘
```

**重要**：第 6 步（批判）和第 7 步（写出来）不能跳过。它们是把你从"调参侠"提升到"研究者"的关键。

## 六、关于"客观性"的元方法论

最后警告：**数学化不等于客观化**。

- 你**选择**用什么模型，本身是有立场的决定。
- 你**选择**用什么数据，反映你认为什么重要。
- 你**选择**怎么解释结果，预设了价值观。

**例子**：用 ML 预测"哪里会发生犯罪"。数学上客观，但训练数据来自"过去警察在哪里抓人多"——而警察本来就部署在少数族裔社区多。结果模型"客观地"告诉你"少数族裔社区更可能犯罪"。**数学在这里帮了歧视的忙**。

所以本项目方法论最后一条：

> **数学让你更精确。但精确并不等于公正。研究者必须始终追问：这套数学是谁在用、对谁有利、对谁有害。**

→ 这条原则会贯穿子领域 3（inequality）和子领域 7（crosscuts）的所有讨论。

## 七、四传统定位（基于张博伦、周浥莽 2026）

> ⭐ 本节是本项目方法论的元反思，来自 CSSCI 顶刊精读（见 `papers/css-computing-2026.md`）。

「计算社会科学」中的「计算」**不是一件事**——按对模型-现实关系预设的强弱，可分为四传统：

| 传统 | 模型-现实预设 | 代表方法 | 本项目应用 |
|---|---|---|---|
| **公理**（Axiomatic）| 最弱 | ABM、形式化模型 | `03-inequality/02-sugarscape.py`、`06-markets-cities/01-schelling.py` |
| **描述**（Descriptive）| 最强 | 统计建模、回归 | `01-relations/02-weak-ties.py` 实证、`06-markets-cities/02-scaling-laws.py` 幂律拟合 |
| **预测**（Predictive）| 弱（黑箱）| ML、深度学习 | `07-crosscuts/02-llm-society.md`（LLM agent） |
| **实验**（Experimental）| 中（因果）| RCT、DID、RDD | 模块 5 二期（因果推断） |

### 本项目的态度

**不把 4 传统视为替代关系**（如"ML 革命取代统计"），**视为互补**：
- 公理传统回答"**给定规则下涌现什么**"
- 描述传统回答"**数据生成机制是什么**"
- 预测传统回答"**未来值是什么**"
- 实验传统回答"**干预的因果效应多大**"

不同问题用不同工具——这是本项目横跨 4 传统的根据。

### 实践建议
- 每个 `.py` 文件头加「传统标签」（公理/描述/预测/实验）
- 完成单传统代码后，思考"它能与哪个传统组合"
- 终极目标：ABM（公理）+ ML（预测）+ 实验数据（实验）+ 统计模型（描述）的**四传统整合**

详见交叉专题：[`../07-crosscuts/03-four-traditions.md`](../07-crosscuts/03-four-traditions.md)
