## 二、按子领域补强：中国本土学者 + 研究方向

### 子领域 1 · relations（社会关系与网络）

#### ⭐ 核心反驳：Granovetter 弱连带在中国成立吗？

**边燕杰**（明尼苏达大学 / 西安交通大学）的"强连带命题"——**直接挑战 Granovetter**：
- 中国是"伦理本位/关系本位"社会（梁漱溟、费孝通传统）
- 找工作不靠"不熟的人"，而靠"强连带"——尤其**直接人情关系**
- 实证：1988、1994、1999 三次天津调查反复验证
- → 这是"理论的本土化修正"典范

**NCPSSD 检索关键词**：
- "强连带" OR "弱连带" + 作者 边燕杰
- "社会网络资本" + 中国
- "社会分层" + 网络

**翟学伟**（南京大学）：中国人的"关系"本体论
- 代表作《中国人的关系原理》《人情、面子与权力的再生产》
- 提出"中国关系"≠西方社会资本——前者是伦理义务，后者是工具交换
- 直接对话 Putnam/Bourdieu/林南

**林南**（杜克/香港中文大学）：社会资本本土化
- "社会资源理论"：你认识的人的位置 > 你自己的位置
- 中国情境下的"关系"测量
- 代表作 Social Capital: A Theory of Social Structure and Action

**梁玉成**（中山大学）：移民社会网络
- 中国乡城迁移、社会融入

**陈云松**（南京大学）：量化社会网络
- 把大数据方法引入中国社会学
- NCPSSD 检索："陈云松" + 大数据 / 量化

**刘军**（哈尔滨工程大学）：社会网络分析方法
- 翻译/推广 Wasserman-Faust 等教材
- 《整体网分析讲义》

## 四、为什么必须有中国顶刊配套

本项目原来"太空"的原因：
1. **所有理论都来自西方经典**（Granovetter/Arrow/Piketty/Schelling）
2. **缺少中国情境的实证**——中国网络结构和西方不同
3. **缺少本土理论**——费孝通、翟学伟、边燕杰的中国理论被忽视
4. **缺少近 5 年研究**——只引 1960-2000 论文

补强后的对话结构：

```
       西方经典理论  ←─对话─→  中国本土研究
       (Granovetter)         (边燕杰：强连带)
       (Piketty r > g)       (李实/CHFS：中国不平等)
       (Schelling 隔离)      (中国学区房/户籍)
       (Arrow 民主)          (王绍光：国家能力)
       (Putnam 社会资本)     (翟学伟：关系本位)
       (Bourdieu 文化资本)   (周晓虹：中产阶级)
```

**这才是真正的"研究"**——理论 + 实证 + 跨文化对话。
