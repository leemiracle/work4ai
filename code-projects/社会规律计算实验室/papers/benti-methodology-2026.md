## 1. 一句话总结

> **案例研究的「科学性」质疑来自把它套进统计推断逻辑。出路是回到案例的本体——区分形态学（典型/特征）vs 发生学（事件/机制），构建本体论-方法论-认识论的大循环。**

→ 这是对"案例 vs 定量"百年方法之争的**第三条路**。

---

## 2. 核心贡献

### 2.1 案例研究的「合法性困境」
传统挑战（来自定量派）：
- **代表性问题**：单案例无法满足大数法则
- **普遍性问题**：N=1 不能推断总体

张兆曙的诊断：这些质疑**用错了逻辑**——把案例研究套进统计推断，自然不合规。

### 2.2 「另起炉灶」：从本体论出发
案例研究的合法性不在"代表总体"，而在：
- **形态学**：典型性——案例是某种类型的代表（不是统计代表）
- **发生学**：机制性——案例展示某种因果机制的过程

### 2.3 两种范式的精确区分

| 维度 | 形态学范式 | 发生学范式 |
|---|---|---|
| **逻辑** | 类型化 | 事件化 |
| **核心** | 典型 + 特征分析 | 过程 + 机制分析 |
| **认知方式** | 以小见大 | 从可见故事发现不可见机制 |
| **案例选择** | 典型案例 | 关键事件 |
| **目标** | 类型学知识 | 机制性知识 |
| **代表** | 费孝通《江村经济》 | Tilly《大结构、大过程》 |

## 3. 理论核心

### 3.1 「大循环」：本体-方法-认识
```
案例的本体存在方式（形态 vs 发生）
        ↓
方法论选择（类型化 vs 事件化）
        ↓
认识论产出（类型知识 vs 机制知识）
        ↓
回到本体（验证 + 反思）
```

### 3.2 与中国学界的方法论之争对话
作者回顾了 2010s 中国社会学界两大争论：
- **陈云松 vs 渠敬东**（2016-2017）：方法主义迷信 vs 大数据
- **刘林平 vs 潘绥铭**（2016）：大数据原罪 vs 反批评

张兆曙的回答：**两派都把案例研究放进了错误的逻辑**——
- 定量派用统计逻辑否定案例
- 案例派用"独特性"反驳——但仍受统计逻辑牵制

→ 真正的出路是**重构案例研究的本体论**。

## 5. 批判

1. **形态/发生的边界模糊**：很多案例同时是典型+机制
2. **「大循环」操作化不足**：具体怎么"从本体出发"做研究？
3. **未深挖比较案例**：多案例比较研究属于哪种范式？
4. **与西方文献对话不足**：忽略 Becker、Ragin、Mahoney 等案例研究方法大家
5. **"另起炉灶"的代价**：完全脱离统计逻辑，案例研究的"科学性"如何保障？
