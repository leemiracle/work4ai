## 1. 一句话总结

> **「计算社会科学」中的"计算"不是一件事，而是 4 条独立的演化路径——公理传统（ABM/形式化）、描述传统（统计建模）、预测传统（机器学习）、实验传统（因果识别）。混为一谈导致方法论混乱。**

**这是对本项目最直接相关的一篇论文**——我们整个 social-laws 项目就横跨这 4 个传统。

---

## 2. 核心贡献

### 2.1 揭示「计算」的多义性
作者指出，既有文献把"计算"混为一谈，至少包括 5 种含义：
1. 计算机模拟（ABM）
2. 大数据
3. 监督式机器学习
4. 自然语言处理
5. 深度神经网络

→ 这种笼统理解导致方法论讨论失焦。

### 2.2 提出四传统分类法

按「**对模型与现实关系的预设强弱**」分类：

| 传统 | 模型-现实预设 | 代表方法 | 典型问题 |
|---|---|---|---|
| **公理传统** | 最弱 | ABM、形式化模型、Schelling、Sugarscape | 给定规则下涌现什么？ |
| **描述传统** | 最强 | 统计建模、回归、SEM | 数据生成机制是什么？ |
| **预测传统** | 弱（黑箱）| 机器学习、深度学习 | 预测准确率多高？ |
| **实验传统** | 中（因果）| RCT、DID、RDD | 干预的因果效应多大？ |

### 2.3 整合 vs 替代

作者主张：
- **不要把 4 传统视为替代关系**（机器学习≠统计的革命）
- **要视为互补**：不同传统回答不同问题
- **从方法推广转向方法整合**

## 3. 理论核心

### 3.1 公理传统（Axiomatic）
- **代表**：Schelling 隔离模型、Sugarscape、Epstein generative social science
- **逻辑**：从公理出发，演绎涌现
- **判断标准**：内部一致性 + 启发性
- **预设**：理论与现实关系最弱（不要求模型"真"，只要求"有用"）

→ **本项目 `03-complexity/01-schelling.py` 就是公理传统！**

### 3.2 描述传统（Descriptive）
- **代表**：传统社会学量化（回归、SEM、社会化分析）
- **逻辑**：模型近似数据生成过程
- **判断标准**：模型拟合度 + 解释力
- **预设**：模型应该"接近"真实

→ 本项目模块 3 inequality 的帕累托拟合属于此类。

### 3.3 预测传统（Predictive）
- **代表**：机器学习、深度学习
- **逻辑**：算法从数据学习输入-输出映射
- **判断标准**：out-of-sample 预测准确率
- **预设**：模型是黑箱，不关心是否对应真实

→ 本项目模块 7 LLM×社会 多用此类。

### 3.4 实验传统（Experimental）
- **代表**：RCT、自然实验、DID、RDD
- **逻辑**：通过随机化识别因果
- **判断标准**：内部效度 + 因果识别强度
- **预设**：理论是辅助，因果效应是核心

→ 本项目模块 5 数据驱动部分属于此类。

## 6. 批判与局限

1. **四传统的边界并不清晰**：预测和描述在实际研究中常融合（如可解释 ML）
2. **缺范式之争的实证**：作者呼吁"整合"，但没给整合的具体方法论
3. **西方文献偏少**：主要引中国学界，与西方最新方法对话不足
4. **没讨论 LLM 革命**：2023+ 的 LLM 正在颠覆四传统分类
5. **「公理-描述-预测-实验」的元认识论来源**未深究（库恩范式？拉卡托斯研究纲领？）
