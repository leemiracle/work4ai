## 1. 一句话总结

> **多利益攸关方参与全球粮食治理的有效性，取决于两个核心因素：①权力分配公平；②资源筹措能力。两者兼具 = 最有效；缺其一 = 失败。**

这是 **Ostrom 公地治理八原则在全球尺度（N=多国+多组织）的实证检验**。

---

## 2. 核心贡献

### 2.1 两条衡量标准
- **过程有效**：达成各方均认可且实施的协议
- **结果有效**：粮食安全问题得到切实解决

### 2.2 两大决定因素
| 因素 | 内涵 | 案例 |
|---|---|---|
| **权力分配公平** | 决策权分散、参与平等 | GAFSP（公平）vs NAFSN（北方主导）|
| **资源筹措能力** | 资金、技术、组织能力 | GAFSP（强）vs NAFSN（弱）|

### 2.3 实证对照
| 案例 | 权力分配 | 资源筹措 | 结果 |
|---|---|---|---|
| **GAFSP** | 公平（多国共治）| 强（多边资助）| ✅ 有效 |
| **NAFSN** | 不公（美国主导）| 弱（正规化低）| ❌ 失败 |
| **PABRA**（泛非豆类）| 公平 | 强 | ✅ 极强（650+ 改良品种，3 亿人受益）|
| **棕榈油圆桌** | 不公（大企业主导）| 弱 | ❌ 决议无企业执行 |

## 3. 与本项目 `02-cooperation/04-collective-action.md` 的精确对接

### 3.1 Ostrom 八原则在全球尺度的检验

| Ostrom 八原则 | 在全球粮食治理中 | 张帅的判断 |
|---|---|---|
| 1. 清晰边界 | 谁是"利益攸关方" | ✓ 多利益攸关方定义清楚 |
| 2. 规则匹配本地条件 | 各地区粮食问题差异 | 部分 ✓ |
| 3. 集体选择安排 | **权力分配** | **关键变量** |
| 4. 监督 | 国际组织监督 | 弱 |
| 5. 渐进制裁 | 几乎不存在 | ✗ |
| 6. 冲突解决 | 国际仲裁 | 弱 |
| 7. 最低限度认可 | 国家主权 | 复杂 |
| 8. 嵌套式企业 | 联合国体系 | ✓ |

→ 张帅的核心论点：**Ostrom 八原则在全球尺度（N=多国）下，第 3 条（集体选择/权力分配）+ 资源筹措是关键瓶颈**。

### 3.2 与本项目 `02-cooperation/03-evolutionary-game.py` 的对接

GAFSP vs NAFSN = 重复博弈中的合作均衡 vs 背叛：
- GAFSP：公平权力 → 重复合作（TIT-for-TAT 类似）
- NAFSN：权力不对等 → 强方剥削 → 弱方退出

## 4. 关键案例深描

### GAFSP（成功案例）
- 2010 年 G20 倡议
- 多边信托基金（世界银行托管）
- 治理结构：捐款国 + 受援国 + 多边机构 + 公民社会 + 私营部门
- 资源：累计承诺 20 亿美元
- 成效：50+ 国家，2000+ 项目

### NAFSN（失败案例）
- 2013 年美国主导
- 资源筹措弱（依赖私人部门）
- 权力分配不公（USAID 主导决策）
- 结果：协议未被执行，对象国粮食问题未解决

## 5. 批判

1. **"权力分配"如何测量**：论文用定性案例对比，没量化指标
2. **2×2 矩阵太简化**：现实案例往往是连续光谱
3. **样本偏倚**：只挑了成功和失败两个对照，忽略中间状态
4. **未涉及中国角色**：作为全球粮食治理的重要参与者，中国经验缺失
5. **缺时间维度**：组织有效性会演化，GAFSP 未来是否会失败？
