# 中外对比 #3 · 张博伦周浥莽《计算多义性》vs Lazer et al.《Computational Social Science》

> **议题**：计算社会科学的方法论定位
> **中国论文**：张博伦、周浥莽（2026）《计算社会科学中的"计算"多义性：对四种传统的探析》《社会学评论》第 2 期
> **国际对标**：Lazer, D. et al. (2009). *Computational Social Science.* **Science** 323, 721-723.（被引 8000+，计算 SS 宣言论文）
> **项目对接**：⭐ `docs/methodology.md` + `07-crosscuts/03-four-traditions.md`

---

## 一、议题的共同起点

**核心问题**：大数据 + 计算工具如何改变社会科学？

- Lazer 2009：**宣示性**——"计算 SS 是新学科"
- 张博伦 2026：**反思性**——"计算 SS 内部不是铁板一块"

→ Lazer 是**开拓者视角**，张博伦是**审视者视角**。

---

## 二、核心论点对比

### Lazer et al. (2009) Science manifesto
**主张**：
- 计算社会科学 = **新学科**（不是单纯工具应用）
- 三大支柱：大数据 + 复杂网络 + 计算机仿真
- 例子：移动电话数据、Twitter、Web2.0
- **挑战**：隐私、伦理、跨学科训练

**风格**：
- 乐观、扩张性
- 号召社会科学家拥抱数字时代
- 没有内部分化的讨论

### 张博伦-周浥莽 (2026) 反思
**主张**：
- "计算"在 CSS 里有**四种独立传统**：
  1. **公理传统**（ABM、形式化）—— Schelling/Sugarscape
  2. **描述传统**（统计建模）—— 传统定量社会学
  3. **预测传统**（机器学习）—— 黑箱预测
  4. **实验传统**（因果识别）—— RCT、DID

- 不同传统对**"模型与现实关系"**预设不同
- 不要把 4 种传统混为一谈

**风格**：
- 反思、分化性
- 批评"笼统推广"
- 呼吁"方法整合"

## 三、三点关键差异

### 差异 1：时间与位置
| 维度 | Lazer 2009 | 张博伦 2026 |
|---|---|---|
| 时间 | CSS 诞生初期（17 年前）| CSS 成熟期 |
| 国家 | 美国（哈佛-东北大学团队）| 中国（浙大-人大）|
| 历史 | Web 2.0 刚兴起 | LLM 时代 |
| 立场 | 开拓 | 反思 |

→ **17 年时间差，立场必然不同**——开拓者讲"我们要做什么"，反思者讲"我们做错了什么"。

### 差异 2：CSS 内部结构的认识
- Lazer：CSS 是统一的新学科（"computational" 是核心）
- 张博伦：CSS 内部分化为 4 传统，**计算不是单一概念**

→ 张博伦更准确——CSS 17 年发展证明它确实内部分化了。

### 差异 3：对方法的态度
- Lazer：**推广**——希望更多社会学家用计算方法
- 张博伦：**审慎**——"关注从方法推广转向更严谨审慎的方法整合"

→ 中国学者更保守、更严谨。

## 四、互补与综合

| 维度 | Lazer | 张博伦 |
|---|---|---|
| 贡献 | 定义了 CSS 的疆域 | 揭示了 CSS 的内部分化 |
| 局限 | 没看到内部异质性 | 没看到 LLM 革命（2023+）|

**未来综合**：可能需要加入**第 5 传统**——**生成传统**（generative tradition）：
- LLM 不仅预测，还**生成**新数据
- Generative Agents (Park 2023) 用 LLM 仿真整个社会
- 这是 Lazer 2009 完全没预见的方向
- 张博伦 2026 也未充分讨论（2026 年初 LLM 仿真刚兴起）
