## 0. 这个项目是什么

**一句话**：14 模块 / 169 md / 114 py / ~133 万字 / 1152 arXiv / 50 个研究课题 / 10 条学习路径的 **AI 全景调研 + 研究导航**。

**核心价值**：不是"教你 AI"（有 Karpathy / HuggingFace 课程做这个），而是**帮你从"学了 AI"走到"做出研究"**——50 个课题 + 10 条路径 + 1152 个一手核实的 arXiv 是这个项目的不可替代性。

## 8. 常见问题（FAQ）

**Q: 我数学零基础，能读懂吗？**
A: 能。模块 14 专门为零基础设计（§01 可计算性 → §05 数值分析，从 IEEE 754 讲起）。`learning-paths.md` 的 10 条路径都标了"数学补课清单"，从零开始 3-4 月可达课题入门。

**Q: arXiv 引用可靠吗？**
A: 极可靠。v2.0.3-4 抽查了 19 个 arXiv ID（6 高引用 + 8 新引用 + 5 低引用），全部正确。项目铁律"arXiv ID 绝不能凭记忆"，三轮里触发 2 次（DeepMath 年份错 + 试 AlphaGeometry 给错 ID），都已修正。

**Q: 实验能跑吗？**
A: 100%。v2.0.4 跑了全部 114 个 py，0 崩溃（修复了 4 个历史 bug 后）。54 个快速跑通（≤4s），60 个超时但能跑（真训练）。

**Q: 怎么贡献新内容？**
A: 遵循项目铁律（CHANGELOG 末尾有完整列表）：
1. arXiv ID 必须 webfetch 一手核实
2. 代码必须 bash 实跑验证
3. 三层讲透（直觉→数学→代码→不足）
4. 不重复现有内容（grep 确认空白才补）

**Q: 这个项目和 Karpathy/HuggingFace 课程有什么不同？**
A: Karpathy 教你"从零实现"；HF 教你"怎么用库"。这个项目教你**"从学到做研究"**——50 个课题 + 10 条路径是这个项目的核心差异化。
