# 20 个核心洞察 · 5 分钟读完整个项目

> 从 133 万字 / 173 文件中萃取的 20 个最反直觉、最有价值的发现
> 产出：2026-07-23（v2.1.3）

---

**1.** **Attention sink 是 softmax 的"垃圾注意力倾倒场"**——Transformer 前几层学到把无语义的初始 token 当"垃圾桶"，让 softmax 有地方归一化。去掉它们，长上下文质量崩溃。这不是 bug，是 feature。（模块 11 §07 / 模块 12 §05 §12.2）

**2.** **BF16 缺失不只慢，而是改变训练可行性边界**——BF16 和 FP32 共享 8 位指数（动态范围相同，不需 loss scaling）；FP16 只有 5 位指数（必须 loss scaling，否则梯度下溢）。飞腾 D3000 无 BF16 = 不适合训练大模型，只适合推理。（模块 14 §05 §11.7）

**3.** **Higham 浮点误差上界保守 10-100×**——经典理论说 FP16 累加误差是 O(n)，实验测定是 O(n^0.54)（接近 √n）。量化误差几乎完全随机抵消。**这是 INT8/INT4 在 LLM 中可用的数学基础。**（NA-1 实验）

**4.** **Pinsker 不等式对 spec decoding 完全不可用**——KL > 2 时下界归零，但实际 accept rate 仍有 15-25%。经验关系 α ∝ KL^-0.43。**小 draft 模型仍有效的理论解释。**（IT-3 实验）

**5.** **DotProd ≠ i8mm**——SDOT 一次 4 个 INT8（ARMv8.2-A，飞腾 D3000 有），i8MM 一次 8 个（ARMv8.6-A，D3000 没有）。"INT8 加速 4×"的常识在 D3000 上打折。（模块 14 §05 §11.3）

**6.** **sorry 是 Lean 的合法 tactic**——接受任何命题为真。LLM 可能学到"写不出证明就用 sorry"，产生通过 Lean 验证但实际是假的证明。**所有 LLM × Lean Agent 必须显式禁 sorry。**（模块 13 §13 §六，实验时意外发现）

**7.** **Certigrad4 慢 10× 但仍有价值**——用 Lean 证明 autograd 的正确性。在医疗/金融/科研复现等高 stakes 场景，数学证明的价值远超 10× 算力开销。（模块 12 §01 §10）

**8.** **AlphaProof Nexus 解决了 9 个 Erdős 开放问题**——这是 AI 首次大规模解决"没有标准答案"的研究数学问题。从"竞赛数学"到"研究数学"的范式转移。（模块 03 §3.5）

**9.** **Inkling-Small 在推理上超过 Inkling（975B）**——276B 小模型在 GPQA/HLE 上更强，但 SimpleQA 差 2×。**量化分离了"推理"和"记忆"**：纯推理不需要大模型，事实记忆需要。（docs/frontier-deep-dive/02）

**10.** **Sessa 证明了 attention × SSM 的第三种拓扑**——不是 interleave（Jamba）、不是 replace（Mamba），而是 nest（attention 嵌入 recurrent feedback）。power-law memory tail O(ℓ^-β)，比 Transformer 的 O(1/ℓ) 和 Mamba 的 exponential 都慢。（模块 11 §07 §2.7）

**11.** **Kimi K3 的 MXFP4 QAT 让量化从"事后压缩"变成"训练原生"**——从 SFT 阶段就量化（4 bit），模型在训练中学会补偿量化误差。2.8T 模型只需 1.4 TB 存储而非 5.6 TB。（模块 12 §05 §12.3）

**12.** **Curry-Howard 同构绕过了停机问题**——类型论通过"限制表达力"（只允许强正规化的项）换取"可判定的证明检查"。**Lean 验证不会卡死的数学基础。**（模块 14 §01 §2.6）

**13.** **三大加速杠杆的本质都是"用富余换稀缺"**——推测解码用富余算力换延迟；KV cache 优化用富余算法换显存；量化用富余精度换带宽。**下一代硬件改变"什么是稀缺"时，杠杆的相对价值会变。**（模块 12 §05 §12.5）

**14.** **DeepSeekMath-V2 让 LLM 自己验证自己的证明**——Self-Verifiable Reasoning。IMO 2025 金牌 + Putnam 118/120（超人类最高 90）。**这是 AI 从"生成答案"到"验证答案"的跨越。**（模块 03 §3.5）

**15.** **AlphaFold 3 故意去掉了全局等变性**——"no invariance or equivariance required"。在足够数据下，硬约束的边际收益不如软约束 + 更大模型。**反共识但有效。**（模块 02 §3.3）

**16.** **排队论的重尾方差是延迟杀手**——M/G/1 系统中，服务时间方差 σ² 直接进入等待时间公式 W_q = λ·E[S²]/(2(1-ρ))。少数超长请求拖死整个队列。**这就是 continuous batching + prefill-decode 分离要解决的。**（模块 12 §05 §14.3）

**17.** **Grokking 是训练很久后的"相变"**——模型在 validation loss 稳定很久后突然泛化。可能与权重的 late-phase 结构重组有关。统计力学视角正在解释这个现象。（模块 14 §02 + §04）

**18.** **国密 SM3/SM4 在飞腾 D3000 上几乎零开销**——同一颗 CPU 同时硬件加速国密 + 国际算法。软件层无需切换库。**信创 AI 在国密合规上的隐性优势。**（模块 14 §05 §11.5）

**19.** **Macaron-V1 的 Mixture-of-LoRA 是 continual learning 的工程化**——base 冻结 + 4 个 LoRA 专家（Chat/Agent/Coding/GenUI）。新能力通过 plug-in LoRA 加入，不修改 base。**这与 Certigrad4 的 verified ML 有共鸣——base 不变时更易形式化验证。**（docs/frontier-briefing-2026-07.md）

**20.** **"换维度"是突破边际递减的唯一方式**——十轮"不要停"走了六个阶段（内容→验证→前沿→行动→导航→反思），每个阶段换一个维度。**不停做同样的事只会递减；不停换维度才能持续创造价值。**（docs/ten-lessons.md 教训 #9）
