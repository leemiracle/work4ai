## 核心论点

**经典数学理论（数值分析 / 信息论 / 排队论）在 AI 系统中高度保守或直接失效——但这一结论有条件：在连续分布（LLM 典型情况）下保守 10-100×，在离散分布下可能不保守。AI 系统需要自己的数学理论——不是最坏情况上界，而是利用 AI 的统计特性给出更紧的界。**

> ⚠️ **v2.1.6 修正**：原 Thesis（v2.1.5）说"经典理论无条件保守"。NA-1 第二步实验（4 种输入分布）发现：双峰离散分布（±1）的 α ≈ 0.95（接近最坏情况 O(n)），说明保守性**依赖输入分布的连续性/离散性**。详见 `01-fp16-error-propagation.md` §9。

## 三个 Case Study

### Case 1 · Higham 浮点误差理论（NA-1）

| | 经典理论 | 实际 |
|---|---|---|
| **预测** | FP16 累加误差 O(n) | O(n^0.54) |
| **保守倍数** | — | **10-100×** |
| **失效原因** | Higham 假设最坏情况（所有误差同向累积）| 实际误差符号随机，接近完全抵消（随机游走 O(√n)）|
| **AI 特性** | FP16 量化误差在 LLM 激活值分布下**几乎完全随机**——这和经典数值分析假设的"对抗性输入"完全不同 |

### Case 2 · Pinsker 信息论不等式（IT-3）

| | 经典理论 | 实际 |
|---|---|---|
| **预测** | α ≥ 1 - √(KL/2) | α ∝ KL^-0.43 |
| **保守倍数** | — | **~70×** |
| **失效原因** | Pinsker 对**任意分布对**给上界，但 LLM 的 softmax 分布有特殊结构（少数高概率 token + 大量低概率 token）|
| **AI 特性** | LLM 的 token 分布是**高度集中的**（top-10 token 占 90%+ 概率），Pinsker 的"最坏分布"假设与实际不符 |

### Case 3 · Pollaczek-Khinchine 排队论（PR-5）

| | 经典理论 | 实际 |
|---|---|---|
| **预测** | W_q = λE[S²]/(2(1-ρ)) | σ > 0.05 时偏离 146-233× |
| **失效原因** | M/G/1 假设**稳态**，但 ρ=0.80 + 高方差时系统偶尔"卡住"后无法恢复 |
| **AI 特性** | LLM 服务时间有**极重尾**（少数请求生成长序列，服务时间 10× 于平均），且**利用率接近饱和**（ρ→1 是生产常态）|

## 共同模式

三个 case 的深层原因相同：**AI 系统的统计特性与经典理论的最坏情况假设不匹配**。

| 经典理论的假设 | AI 系统的实际情况 | 后果 |
|---|---|---|
| 输入是对抗性的（最坏情况）| LLM 激活值是**随机的**（近高斯）| Higham 上界保守 100× |
| 分布对是任意的 | LLM 分布是**高度集中的** | Pinsker 保守 70× |
| 系统在稳态运行 | LLM serving 接近**饱和** | Pollaczek-Khinchine 失效 |
| 误差/方差是**有界的** | AI 的误差/方差是**重尾的** | 经典界不适用 |

## "AI 原生数学理论"应该长什么样

### 原则 1 · 用统计特性替代最坏情况

经典理论给**确定性上界**（"对所有输入都成立"）。AI 原生理论应该给**概率界**（"对 99% 的实际输入成立"）——因为 AI 系统的输入分布是已知的（激活值统计可离线采集）。

### 原则 2 · 用高维结构替代标量界

经典信息论在低维（2 个分布的 KL）上紧。AI 系统在**高维**（vocab=100K 的 softmax）上有特殊结构（集中 + 稀疏）。利用高维结构可以给出更紧的界。

### 原则 3 · 用 AI 自身的模型替代外部验证

经典排队论用"外部验证"（统计假设检验）。AI 系统有**内置验证器**（reward model / verifier / Lean kernel）。用 AI 自身的验证能力来替代经典理论的保守界。

## 这个 Thesis 的研究价值

这个 thesis 本身就是一篇论文的核心论点：

> **标题（草案）**：*"Classical Mathematical Bounds Are Highly Conservative for AI Systems: Evidence from Three Case Studies and a Call for AI-Native Theory"*
>
> **摘要**：我们通过三个实验（FP16 累加误差 / 推测解码 accept rate / LLM serving 排队论）发现，经典数学理论的预测在 AI 系统中高度保守（10-100×）或直接失效。根本原因是 AI 系统的统计特性（随机量化误差 / 集中的 token 分布 / 重尾服务时间）与经典理论的最坏情况假设不匹配。我们呼吁发展"AI 原生的数学理论"——利用 AI 的统计特性给出更紧的概率界。
