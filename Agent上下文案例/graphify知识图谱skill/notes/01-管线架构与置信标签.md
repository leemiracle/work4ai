# 01 · 管线架构与置信标签：七段流水线、Schema 与安全模型

> 出处：上游 `ARCHITECTURE.md`（v8 分支）+ README "What it does / What files it handles"。
> 可信度锚点：`tests/test_architecture_doc.py` 导入本文引用的每个符号——**架构文档由 CI 强制不漂移**（文档说谎会让测试红）。

## 1. 定性：skill 编排库，不是服务

graphify = **一个 Claude Code skill（后泛化到 20+ 平台）+ 一个可独立使用的 Python 库**。skill 只是编排者；库是实体。无常驻守护进程、无后台索引——与 codegraph（SQLite 常驻 + watcher）的**根本架构分歧**：graphify 选择"**按需全量/增量构建 + 产物文件**"，codegraph 选择"**常驻索引 + 查询服务**"。

## 2. 七段管线（每段独立模块，纯字典/NetworkX 通信，无共享状态）

```
detect() → extract() → build() → cluster() → analyze 辅助 → report.generate() → export.to_*()
```

| 模块 | 入口 | 输入 → 输出 |
|---|---|---|
| `detect.py` | `detect(root)` | 目录 → 扫描摘要（按类别分组的 files + total_files/total_words/…）|
| `extract.py` | `extract(paths, *, root=None)`、`collect_files(target)` | 路径列表 → `{nodes, edges}` 字典 |
| `build.py` | `build(extractions)`、`build_from_json` | 提取字典 → NetworkX 图 |
| `cluster.py` | `cluster(G)` | 图 → `{community_id: [node_id,…]}`（**不改动图**）|
| `analyze.py` | `god_nodes` / `surprising_connections` / `suggest_questions` / `find_import_cycles` / `graph_diff` | 图 → 各一个列表/字典（**无统一 analyze 入口**）|
| `report.py` | `generate(...)` | 图+分析 → GRAPH_REPORT.md 字符串 |
| `export.py` | `to_json / to_html / to_obsidian / to_svg / to_graphml / to_canvas / to_cypher` | 图 → 各格式（**一格式一函数**）|
| 其他 | `wiki.py`（每社区一篇 md）、`callflow_html.py`（Mermaid 架构图）、`ingest.py`（URL→语料）、`cache.py`（语义缓存）、`security.py`、`validate.py`、`serve.py`（MCP）、`watch.py`（debounce 3s 重建）、`benchmark.py`（语料 vs 子图 token 对比）| |

**设计美德**：每段一个函数、纯数据进出、副作用只落在 `graphify-out/`——这是本项目 [`软件即熵治理.md`](../../../软件即熵治理.md) "模块边界=熵闸门"的干净样本。

**API 陷阱（官方文档明示）**：调用 `extract()` 必须显式传 `root`——省略时 root 推断为"该文件列表的公共父目录"，单文件调用会锚到该文件所在目录，节点 id 带上机器路径。这类"默认值悄悄错"的警示写进架构文档，本身是反欺骗自觉。

## 3. 双 pass 提取：确定性 AST + LLM 语义

| Pass | 处理对象 | 引擎 | 成本 | 隐私 |
|---|---|---|---|---|
| **AST pass** | 36 种 tree-sitter 语法（py/ts/js/go/rs/java/c/cpp/cu/metal/rb/cs/kt/scala/php/swift/lua/zig/ps1/ex/jl/vue/svelte/astro/dart/v/sv/sql/f90/pas/sh/json/…+ Apex 正则 + Terraform/Pascal extra）| tree-sitter，确定性 | **0 LLM credit** | 全本地，纯代码语料可完全离线（`--code-only`）|
| **语义 pass** | docs（md/html/rst/yaml，含 `[[wikilink]]`→references 边）、PDF、Office、Google Workspace、图片、音视频（本地 faster-whisper 转写）、YouTube/arXiv URL | 你的 assistant 模型或 `--backend {gemini,kimi,claude,openai,deepseek,ollama,bedrock,azure,claude-cli}` | 按 token | 出网（除 ollama/whisper）|

边的类型：`calls` / `imports` / `inherits` / `mixes_in` / `uses` / `references` / `depends_on`（包清单）等；`calls` 第二趟（call-graph second pass）产出 **INFERRED** 边。MCP 配置文件（`.mcp.json`/`claude_desktop_config.json`）也被解析成服务器节点——agent 的工具面进图。

## 4. 置信标签：证据分级的 schema 级强制

每个提取器必须返回：

```json
{
  "nodes": [{"id": "…", "label": "…", "source_file": "…", "source_location": "L42"}],
  "edges": [{"source": "id_a", "target": "id_b", "relation": "calls|imports|uses|…",
              "confidence": "EXTRACTED|INFERRED|AMBIGUOUS"}]
}
```

| 标签 | 含义 |
|---|---|
| `EXTRACTED` | 源中显式存在（import 语句、直接调用）|
| `INFERRED` | 合理推导（call-graph 第二趟、上下文共现）|
| `AMBIGUOUS` | 不确定——**在 GRAPH_REPORT.md 里标出待人审** |

`validate.py` 在 `build()` 消费前强制 schema（`validate_extraction` 返回错误清单 / `assert_valid` 抛异常）。

> 与本项目的映射：这正是 [`欺骗动力学-AI纪实验包.md`](../../../欺骗动力学-AI纪实验包.md) D1（验证维度）的工程化——**每个论断携带自己的证据等级**，"读到的"与"猜的"在数据结构上不可混淆。codegraph 的 `provenance:'heuristic'` 只标桥接边；graphify 把三值置信标签做进**每条边**的 schema，更彻底。
>
> 演进注：ghost duplicate 问题（同一符号 AST 带源位置 + 语义不带源位置 → 双节点）在 v0.8.33 起构建时自动合并——置信体系也有成长史。

## 5. 图分析层：Leiden 社区 + god nodes + 意外连接

- **Leiden 社区检测**把图切成子系统，社区标签 **LLM-free**（本地生成；agent 内运行时由 agent 命名）。`--resolution 1.5` 调粒度；`--exclude-hubs 99` 把工具型超级枢纽排出 god-node 榜（防止 `len()` 之类污染"最重要概念"）。
- **god nodes**（度最高的概念）、**surprising connections**（按"意外程度"排名的跨文件/跨模块连接）、**suggest_questions**（图独有能力的问题建议 4–5 个）、**find_import_cycles**（循环依赖）、**graph_diff**（两版图差异——配合 `prs` 做 PR 影响面）。
- `graphify path "FastAPI" "ModelField"` 输出最短路逐跳（uses/references 边点亮）——"两个东西怎么连上的"是图谱独有查询，grep 与向量都做不到。

## 6. 安全模型（SECURITY.md 的执行层）

所有外部输入先过 `security.py`：

| 输入 | 防线 |
|---|---|
| URL | `validate_url()`（仅 http/https）+ `_NoFileRedirectHandler`（**阻断 file:// 重定向**）|
| 抓取内容 | `safe_fetch()`（大小上限 + 超时）|
| 图文件路径 | `validate_graph_path()`（必须解析进 `graphify-out/` 内——防路径穿越）|
| 节点标签 | `sanitize_label()`（去控制字符、256 上限、HTML 转义）|

`ingest()` 收 URL（arXiv/YouTube）的场景使这些防线成为必需——**"agent 工具收外部内容"必配的输入验证四件套**，可与 dsh 案例的网络栅栏对照。

## 7. 测试与贡献约定

一模块一测试文件，纯单测（无网络、无 tmp_path 外副作用）；新增语言提取器的 5 步清单（新模块 + 两处注册表 + 依赖 + fixture）。CI 权威环境 Ubuntu + Python 3.10/3.12；Windows 测试需 Developer Mode + LongPathsEnabled——**Windows 是二等公民的诚实声明**。
