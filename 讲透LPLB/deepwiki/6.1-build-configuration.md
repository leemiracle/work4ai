# Build Configuration

  Relevant source files 
 - [pyproject.toml](https://github.com/deepseek-ai/LPLB/blob/0490f794/pyproject.toml)
 - [setup.py](https://github.com/deepseek-ai/LPLB/blob/0490f794/setup.py)
 
  This document explains the build-time configuration of LPLB through `setup.py` and `pyproject.toml`. These files define how the C++ extension module (`lplb._cpp`) is compiled, how dependencies are managed, what resources are packaged, and how development tools are configured. This covers only the **build-time** compilation of the C++ plugin; for runtime CUDA kernel compilation via NVRTC, see [Runtime Compilation and Caching](https://deepwiki.com/deepseek-ai/LPLB/6.3-runtime-compilation-and-caching). For dependency acquisition (cuSolverDx, NVSHMEM), see [Dependency Management](https://deepwiki.com/deepseek-ai/LPLB/6.2-dependency-management).

### Build Parameters When NVSHMEM Enabled

 
| Parameter | Value | Purpose |
|---|---|---|
| extra_link_args | [deep_ep_path, '-Wl,-rpath,...'] | Link DeepEP shared library with runtime path |
| include_dirs | [f'{nvshmem_dir}/include'] | Access NVSHMEM headers during compilation |
| extra_compile_args | -DUSE_NVSHMEM | Enable NVSHMEM code paths in plugin.cpp |
| extra_compile_args | -DNVSHMEM_DIR="{nvshmem_dir}" | Embed NVSHMEM path for runtime use |
| extra_compile_args | -DDEEP_EP_SO="{deep_ep_path}" | Embed DeepEP shared library path |

 These flags enable conditional compilation in `csrc/plugin.cpp`, where `#ifdef USE_NVSHMEM` blocks enable NVSHMEM-specific functionality.

## Build Process Flow

 
```

```

 **Key Build Steps:**

 
 - **Dependency Acquisition** - Run `bash download-mathdx.sh` to fetch cuSolverDx (see [Dependency Management](https://deepwiki.com/deepseek-ai/LPLB/6.2-dependency-management))
 - **Build Invocation** - `pip install .` parses `pyproject.toml` and executes `setup.py`
 - **Extension Compilation** - `CUDAExtension` compiles `csrc/plugin.cpp` with CUDA libraries
 - **Conditional NVSHMEM** - If `deep_ep_cpp` exists and `NVSHMEM_DIR` is set, NVSHMEM support is enabled
 - **Package Assembly** - Python modules, resources, and compiled extension are packaged together
 
 **Sources:** [setup.py1-51](https://github.com/deepseek-ai/LPLB/blob/0490f794/setup.py#L1-L51) [pyproject.toml1-152](https://github.com/deepseek-ai/LPLB/blob/0490f794/pyproject.toml#L1-L152)
