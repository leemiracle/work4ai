## Purpose and Scope

 This document guides developers through setting up a development environment for contributing to or extending FlashMLA. It covers the required software dependencies, environment configuration, build system setup, and IDE configuration specific to CUDA kernel development.

 For information about building FlashMLA for end-user installation, see [Building from Source](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/Building from Source) For details about external dependencies like CUTLASS, see [External Dependencies](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/External Dependencies)

 
---

 
## System Requirements

 
### Hardware Requirements

 FlashMLA requires one of the following GPU architectures for development and testing:

 
| GPU Architecture | Compute Capability | Example GPUs | CUDA Version |
|---|---|---|---|
| SM90 (Hopper) | sm_90a | H100, H800 | CUDA 12.8+ |
| SM100 (Blackwell) | sm_100f | B200 | CUDA 12.9+ |

 Development can be performed on systems without these GPUs (e.g., for code editing), but compilation and testing require appropriate hardware. Note that SM100 support uses the `sm_100f` target [setup.py43](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/setup.py#L43-L43)

 
### Software Requirements

 The following software dependencies are required:

 
| Component | Version | Notes |
|---|---|---|
| Python | 3.8+ | Development and scripting |
| CUDA Toolkit | 12.8+ (SM90), 12.9+ (SM100) | NVCC compiler and runtime |
| PyTorch | Latest stable | Must be compiled with CUDA support setup.py28 |
| GCC/G++ | 9.0+ | C++20 support required setup.py59 |
| Git | 2.0+ | For submodule management setup.py52 |

 **Sources:** [setup.py28-59](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/setup.py#L28-L59)

### Build Environment Variables

 FlashMLA supports several environment variables that control the build process:

 
| Variable | Values | Default | Purpose |
|---|---|---|---|
| FLASH_MLA_DISABLE_FP16 | 0, 1, TRUE, FALSE | FALSE | Disable FP16 support at compile time setup.py21-22 |
| FLASH_MLA_DISABLE_SM90 | 0, 1, TRUE, FALSE | FALSE | Skip SM90 kernel compilation setup.py37 |
| FLASH_MLA_DISABLE_SM100 | 0, 1, TRUE, FALSE | Auto-detect | Skip SM100 kernel compilation setup.py36 |
| NVCC_THREADS | Integer | 32 | Number of parallel NVCC threads setup.py49 |

 **Note:** SM100 compilation requires NVCC 12.9 or higher. If detected version is lower, `FLASH_MLA_DISABLE_SM100=1` must be set [setup.py38-39](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/setup.py#L38-L39)

## IDE Configuration

 
### Visual Studio Code

 FlashMLA excludes `.vscode` and `.clangd` from version control [.gitignore8-12](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/.gitignore#L8-L12)

 **Recommended `c_cpp_properties.json` include paths:** Based on `setup.py`, the following paths should be included for IntelliSense [setup.py127-132](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/setup.py#L127-L132):

 
 - `csrc`
 - `csrc/sm90`
 - `csrc/cutlass/include`
 - `csrc/cutlass/tools/util/include`
 
 
### Clangd

 A `compile_commands.json` is ignored by git [.gitignore9](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/.gitignore#L9-L9) It is recommended to generate this file (e.g., using `bear` or `compiledb`) to enable high-fidelity navigation in editors using `clangd`.

### Troubleshooting

 
| Issue | Cause | Solution |
|---|---|---|
| *.so not found | Build failed | Check nvcc logs for errors setup.py108-124 |
| sm100 build errors | NVCC < 12.9 | Set FLASH_MLA_DISABLE_SM100=1 setup.py38-39 |
| Submodule errors | CUTLASS missing | git submodule update --init csrc/cutlass setup.py52 |
