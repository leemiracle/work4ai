## Overview of Basic Usage

 LPLB's primary interface is the `Planner` class, which orchestrates both static rebalancing (via EPLB) and dynamic per-batch load optimization. The typical workflow consists of:

 
 - **Define expert topology** - Specify how redundant experts map to original experts using an `r2o` matrix
 - **Instantiate Planner** - Create a planner with topology and expert counts
 - **Process expert indices** - Call `planner.run()` on logical expert indices to get optimally balanced physical indices
 
 The following sections demonstrate this workflow with progressively more realistic examples.

## Runtime Processing Workflow

 When `planner.run()` is called, the system performs three phases to map logical indices to optimally balanced physical indices:

 **Diagram: run() Method Data Flow**

 
```

```

 **Phase Breakdown:**

 
| Phase | Method | CUDA Kernel | Purpose | Output |
|---|---|---|---|---|
| 1 | count_workload() | kernel_count_idx | Count occurrences of each logical expert | Per-expert workload histogram |
| 2 | solve_probs() | kernel_solve | Solve LP to compute load distribution ratios | Weight for routing to original vs replica |

## Common Topology Configurations

 LPLB provides predefined topologies optimized for different hardware configurations. Here's how to select and configure them:

 **Standard Topologies:**

 
```

```

 **Topology Selection Criteria:**

 
| Topology | GPUs | Nodes | Best For | Trade-offs |
|---|---|---|---|---|
| Cube | 8 | 1 | Intra-node balancing | No inter-node flexibility |
| Hypercube | 16 | 2 | 2-node EP parallelism | Higher inter-node communication |
| Torus | Flexible | Multiple | Global load balancing | Complex topology, more communication overhead |

 The `r2o` matrix structure must satisfy:

 
 - Each rank has exactly `num_redundants` redundant experts
 - The i-th redundant expert on any rank must map to the i-th original expert on another rank
 - Redundancy is bidirectional between paired ranks
 
 For custom topology definition, see [Custom Topologies](https://deepwiki.com/deepseek-ai/LPLB/8.3-custom-topologies).
