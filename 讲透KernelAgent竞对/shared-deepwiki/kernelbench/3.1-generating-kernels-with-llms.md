## Purpose and Scope

This page documents the single kernel generation workflow using `generate_and_eval_single_sample.py`, which generates and evaluates one GPU kernel at a time. This is the primary entry point for:

- Quick experimentation with different LLMs, prompts, or backends

- Debugging specific problem failures

- Development when iterating on prompt designs or static checkers

The workflow combines generation, optional static validation, and immediate evaluation in a single execution. For batch generation across multiple problems, see Batch Evaluation [/ScalingIntelligence/KernelBench/3.2-batch-evaluation]. For understanding prompt construction details, see Prompt Construction System [/ScalingIntelligence/KernelBench/4.1-prompt-construction-system].
