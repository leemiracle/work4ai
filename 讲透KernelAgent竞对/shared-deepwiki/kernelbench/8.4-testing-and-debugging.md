### Error Categorization

KernelBench distinguishes three primary error types during evaluation:

| | Error Type | Stage | Detection Point | Common Causes
| Compilation Error | Pre-execution | `load_custom_model()` | Syntax errors, invalid CUDA code, missing includes
| Runtime Error | Initialization/Execution | Model instantiation or forward pass | Memory access violations, shape mismatches, kernel launch failures
| Correctness Error | Output verification | `torch.allclose()` comparison | Numerical precision issues, algorithmic bugs, incorrect optimizations

### Common Compilation Errors

| | Error Pattern | Cause | Debug Strategy
| `SyntaxError` | Invalid Python syntax | Check for malformed function definitions, missing colons, indentation
| `NameError` | Undefined variables/functions | Verify all CUDA kernel names match Python bindings
| `ImportError` | Missing modules | Ensure `torch`, `triton`, or backend-specific imports present
| `nvcc error` | Invalid CUDA code | Check CUDA syntax, shared memory declarations, thread indexing
| Lock file error | Concurrent compilation | Retry; not a true failure

### Timing Statistics

The `get_timing_stats()` function computes aggregate statistics from timing trials:

- mean: Average execution time in milliseconds

- std: Standard deviation indicating performance consistency

- min: Best-case performance (useful for comparing theoretical limits)

- max: Worst-case performance (identifies outliers)

- num_trials: Number of measurements (for confidence assessment)

- hardware: GPU name for cross-device comparison

- device: Torch device identifier for debugging

All values formatted to 3 significant digits for readability.

Sources: src/eval.py892-915 [https://github.com/ScalingIntelligence/KernelBench/blob/2f65279d/src/eval.py#L892-L915]
