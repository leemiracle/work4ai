# 讲透 openai/CLIP（官方对比图文预训练实现）

## 一、定位：官方"推理侧"实现，而非训练框架

仓内**没有任何训练代码**：无 loss、optimizer、数据管道。`CLIP.forward`（clip/model.py:358）只返回图文 logits，论文 Eq.1 的对称交叉熵未随仓发布。官方仓交付：①九权重注册表 `_MODELS`（clip/clip.py:30-40），URL 路径段即 SHA256（clip/clip.py:47）；②双塔 clip/model.py；③BPE 分词器 clip/simple_tokenizer.py；④API `clip.load/tokenize/available_models`（clip/clip.py:27，barrel clip/__init__.py:1）。另有 README 未记载的 torch.hub 入口：hubconf.py:8 把模型名标点转下划线，`globals().update`（hubconf.py:40-42）注入九个 entrypoint。

## 二、架构：三个代码文件各司其职

### model.py——双塔与"权重考古"工厂

- **视觉塔二选一**：`CLIP.__init__` 按 `vision_layers` 类型分流（clip/model.py:262-280）。ModifiedResNet 是论文 Appendix 的魔改：3 层 3x3 卷积 stem（clip/model.py:108）、抗锯齿下采样（先 AvgPool 再 stride=1 卷积，clip/model.py:96-100 docstring）、末端单查询注意力池化 AttentionPool2d（clip/model.py:58-91）。VisionTransformer 为标准 ViT：patch 卷积嵌入（clip/model.py:211）、class embedding（clip/model.py:214）、ln_post 取 class token（clip/model.py:235）。
- **文本塔**：复用同一 Transformer/ResidualAttentionBlock（clip/model.py:171-203），注入上三角 -inf 因果掩码（clip/model.py:328-334）——CLIP 文本编码器是 GPT-2 式单向，最易被忽略。
- **对比前向**：特征 L2 归一化内积，乘 `logit_scale.exp()`（clip/model.py:363-369）；温度初始化 `log(1/0.07)`（clip/model.py:295），exp≈100 且**可学习**。文本特征取 EOT 位置 `text.argmax(-1)`（clip/model.py:354），变长无需 mask。
- **build_model（clip/model.py:399）最优雅**：不读 config，超参全从 state_dict 形状反推——`"visual.proj" in state_dict` 判别塔型（clip/model.py:400）、层数数 `.attn.in_proj_weight` 键（clip/model.py:404）、分辨率反解 grid（clip/model.py:406）。checkpoint 即规格书。
- **fp16**：自定义 LayerNorm 前向上转 fp32 再转回（clip/model.py:157-163）；convert_weights（clip/model.py:375）在 build_model 无条件调用（clip/model.py:434）——GPU 加载即 fp16，CPU 由 `model.float()` 兜底（clip/clip.py:141）。

### clip.py——加载与 JIT 补丁

`load`（clip/clip.py:94）按名下载或当本地路径（clip/clip.py:119-124）；先试 `torch.jit.load`，失败回退 build_model 重建（clip/clip.py:129-139）。JIT 分支三个嵌套闭包 `_node_get/patch_device/patch_float`（clip/clip.py:148-198）是底层手术：把 JIT 烘焙进计算图的设备常量/dtype 用 `torch._C` 图节点重写。预处理 `_transform`（clip/clip.py:79-86）BICUBIC+中心裁剪，归一化用 CLIP 自有统计量（clip/clip.py:85）。

### simple_tokenizer.py——49408 词表小写 BPE

字节-Unicode 映射（clip/simple_tokenizer.py:16）、49152 merges 贪心合并带 cache（clip/simple_tokenizer.py:80）、切词正则优先特殊 token 与缩写（clip/simple_tokenizer.py:78）。词表构成一行可读：`merges[1:49152-256-2+1]`（clip/simple_tokenizer.py:67）=49152 merge+256 字节符号+2 特殊 token。1.36MB 词表 gz 经 MANIFEST.in:1 打包（二进制未入图谱）。`tokenize`（clip/clip.py:205）加 SOT/EOT 包夹（clip/clip.py:228）填充 77 列，超长默认抛错、truncate 强制末位 EOT（clip/clip.py:238-242）。

## 三、训练与推理入口

推理三式：`clip.load` 返回 model+preprocess；`encode_image/encode_text` 取特征（clip/model.py:340/343）；`model(image,text)` 取 logits。notebooks：Interacting_with_CLIP（图文相似度）、Prompt_Engineering（1000 类×80 模板 ensemble）。"训练入口"由数据文档代理：data/yfcc100m.md（1480 万图消融）、data/country211.md、data/rendered-sst2.md，WIT-400M 与训练循环未发布。测试：tests/test_consistency.py:9 对 9 模型参数化比对 JIT/非 JIT softmax（atol=0.01，tests/test_consistency.py:25）；CI 锁 PyTorch 1.7.1-1.10.1（.github/workflows/test.yml:14-15）。

## 五、使用建议

1. **选型**：推理/复现选本仓；微调、更大权重、训练循环去 README.md:196 推荐的 OpenCLIP/HuggingFace（架构性缺口）。
2. **精度**：GPU 加载即 fp16（clip/model.py:434），需 fp32 显式 `model.float()`；混合精度注意 LayerNorm fp32 桥。
3. **版本**：依赖零 pin（setup.py:13-17），仅运行时警告（clip/clip.py:23-24）；tokenize dtype 分支（clip/clip.py:231）与 JIT 补丁在新 torch 上最易碎。
4. **合规**：model-card.md:44-50——任何部署越界、监控/人脸永久禁用、仅英文。
5. **零样本**：先用 data/prompts.md 现成模板（ensemble 稳于单模板）；中文场景考虑多语变体。
