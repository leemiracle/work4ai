# 00 - 分析进阶是什么：4 卷全景

> 本科实分析（Tao）教你极限 / 连续 / 微分 / 积分。**进阶分析**把这 4 个概念推到极限——测度、复平面、无穷维空间、Fourier。

---

## 一、4 卷的核心问题

### 卷 I：Fourier 分析

**核心问题**：怎么把"任意"函数分解成正弦/余弦的和？

**答案**：$f(x) = \sum_{n} \hat{f}(n) e^{inx}$（Fourier 级数）或 $\hat{f}(\xi) = \int f(x) e^{-2\pi i x \xi} dx$（Fourier 变换）。

**反直觉**：不是所有函数都能 Fourier 展开——收敛性是 200 年难题（Dirichlet / Jordan / Lebesgue / Carleson）。

### 卷 II：复分析

**核心问题**：把实分析推广到**复数域**会怎样？

**反直觉**：复可微（全纯）比实可微**强得多**——一次复可微 ⟹ 无穷次可微 ⟹ 解析（有 Taylor 展开）。

**最美定理**：Cauchy 积分公式 $f(z) = \frac{1}{2\pi i} \oint \frac{f(w)}{w - z} dw$。

### 卷 III：实分析（测度论）

**核心问题**：Riemann 积分对 Dirichlet 函数失效，怎么修？

**答案**：Lebesgue 积分——按"函数值"分组而非"区间"分组。可积函数大大扩展。

**反直觉**：存在**处处连续处处不可微**的函数（Weierstrass）；存在**测度非 0 但无处稠密**的集（胖 Cantor）。

### 卷 IV：泛函分析

**核心问题**：函数本身作为"点"构成空间，会怎样？

**答案**：Banach 空间（完备赋范）/ Hilbert 空间（内积）。

**反直觉**：无限维空间里，**有界闭集不一定紧致**（Heine-Borel 失效）。

---

## 二、4 卷的依赖关系

```
I. Fourier ← 需要实分析基础
II. Complex ← 需要实分析 + 卷 I 部分
III. Real (Measure) ← 实分析的严格化（独立于 I/II）
IV. Functional ← 需要卷 III（L^p 空间）
```

**推荐顺序**：III（测度）→ I（Fourier）→ II（复）→ IV（泛函）。
