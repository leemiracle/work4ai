# 00 · 符号主义是什么

> **第一性问题**：1956 年 Dartmouth Conference 后，AI 圈主导了 **30 年** 的范式叫"**符号主义**"——认为智能 = **符号操作**。
>
> 1986 年连接主义复兴，符号主义被边缘化。但 2024 年 AlphaProof（IMO 银牌）+ Lean + Neurosymbolic——**符号主义复活了**。
>
> 本篇问：**符号主义到底是什么？为什么没死？为什么必须和神经融合？**
>

## 一、符号主义的定义

### 1.1 物理符号系统假设（Newell-Simon 1976）

> **核心宣称**：一个物理符号系统（能操作符号的物理系统）**具有产生智能行为的充分和必要条件**。

- **符号**（symbol）：抽象实体（如概念、词、对象）
- **操作**：组合、变换、检索、推理
- **物理实现**：计算机（早期）/ 大脑（哲学）

**Turing Award 1975** 给 Newell-Simon，正是为此。

### 1.2 GOFAI（Good Old-Fashioned AI）

**John Haugeland 1985** 造的词——指 1956-1985 主导的符号 AI：

```
GOFAI 三要素：
    1. 符号表示（symbolic representation）
    2. 显式规则（explicit rules）
    3. 演绎推理（deductive reasoning）
```

### 1.3 与连接主义的对比

| | 符号主义（GOFAI）| 连接主义（神经网络）|
|---|---|---|
| **表示** | 符号（离散）| 权重（连续）|
| **计算** | 规则演绎 | 矩阵乘 |
| **学习** | 人写规则 | 从数据学 |
| **优势** | 可解释、可推理 | 可学习、感知强 |
| **劣势** | 难学、感知弱 | 黑箱、推理弱 |

## 二、符号主义的工具箱

### 2.1 一阶逻辑（First-Order Logic, FOL）

**构件**：
- 常量：$a, b, c$
- 变量：$x, y, z$
- 谓词：$P(x), Q(x, y)$
- 量词：$\forall x, \exists y$
- 连接：$\land, \lor, \to, \neg$

**例子**：
$$\forall x \, \text{人}(x) \to \text{会死}(x)$$
$$\text{人}(\text{苏格拉底})$$
$$\Rightarrow \text{会死}(\text{苏格拉底})$$

**性质**：**可判定性 / 完备性 / 一致性**——数学严格。

### 2.2 框架（Frame）

**Minsky 1974** 提出——结构化的知识表示：

```
框架：餐厅
  is-a: 商业场所
  部分: 厨房, 用餐区, 收银台
  事件: 点菜, 用餐, 结账
```

### 2.3 语义网（Semantic Network）

**节点** = 概念，**边** = 关系（is-a / has-a / part-of）。

**现代版**：**知识图谱**（Wikidata / Google KG）。

### 2.4 描述逻辑（Description Logic）

- 一阶逻辑的**可判定子集**
- 是 OWL（Web Ontology Language）的基础

### 2.5 产生式系统（Production System）

- IF-THEN 规则集合
- **专家系统**的核心
- **代表**：MYCIN（诊断细菌感染，1970s）

## 三、专家系统的兴衰

### 3.1 黄金时代（1975-1985）

```
MYCIN（1972-1980）—— 斯坦福，诊断细菌感染
XCON（1978-1988）—— DEC，配置 VAX 计算机，年省 $40M
DENDRAL（1965）—— 斯坦福，质谱分析
PROSPECTOR（1976）—— SRI，矿藏勘探
```

**专家系统范式**：
```
知识工程师 + 领域专家 → 知识库（几千条规则）
                     + 推理引擎 → 解决具体问题
```

### 3.2 第一次危机

**问题**：
- **知识获取瓶颈**：把专家知识翻译成规则极难
- **维护成本爆炸**：XCON 增长到 1 万+ 规则，维护崩溃
- **脆弱性**：规则外的情况完全失效

**结果**：1987 年 LISP 机器市场崩盘（第二次 AI 寒冬）。

### 3.3 教训

1. **专家知识难形式化**——直觉难翻译成规则
2. **规则系统不 scalable**——数量爆炸
3. **缺学习**——系统不能从数据学

---

## 四、CYC 项目——最大的符号主义冒险

### 4.1 Doug Lenat 1984 启动

**目标**：手工编码所有"常识"——建立一个有 100 万+ 规则的知识库。

**逻辑**：如果 AI 缺常识，那把所有常识编码进去就行。

### 4.2 失败

**30 年 + 数亿美金 + 几百知识工程师** —— **没成功**。

**教训**：
- 常识太庞大——手工编码不可能
- "常识"不是离散规则，是模糊的关联网络
- 没有学习的系统注定失败

> 🎯 **博士级教训**：**CYC 是符号主义的墓志铭**——纯符号路线的死胡同。但**CYC 的理想（机器有常识）在大模型里复活了**。

## 五、符号主义的复活（2024-2026）

### 5.1 知识图谱（KG）

- **Wikidata**：1 亿+ 实体，1.5 亿+ 关系
- **Google KG**：搜索背后的知识库
- **DBpedia / YAGO**：学术版

**符号主义没死**——它在工业界活着。

### 5.2 自动定理证明

**Lean** / **Coq** / **Isabelle**——形式化证明助手。

**2024 突破**：**AlphaProof + AlphaGeometry 2** —— Google DeepMind 用 LLM + Lean 在 IMO 拿银牌。**符号主义 + 神经网络的胜利**。

### 5.3 Neurosymbolic AI

**核心思想**：神经网络的感知 + 符号的推理 = 两全。

**代表方法**：
- **DeepProbLog**：神经网络 + ProbLog（概率逻辑）
- **Logic Tensor Networks**：可微逻辑
- **LLM + Tool Use**：LLM 调用定理证明器/计算器

### 5.4 LLM 的"工具调用"本质

- LLM 生成函数调用 → 程序执行 → 返回结果
- **这就是符号推理**！LLM 的 tool use 是隐式 Neurosymbolic

> 🎯 **博士级洞察**：Neurosymbolic 不是新发明——**LLM + tool use 已经在做**。未来 5-10 年是显式 Neurosymbolic 的爆发。

## 六、为什么符号主义必须和神经融合

### 6.1 各自的局限

| 神经网络 | 符号主义 |
|---|---|
| 感知强 | 感知弱 |
| 学习强 | 学习弱（人写规则）|
| 推理弱 | 推理强 |
| 黑箱 | 可解释 |
| 难验证 | 可形式化验证 |

### 6.2 互补性

- LLM（神经）+ Lean（符号）→ 数学证明（AlphaProof）
- LLM（神经）+ SQL（符号）→ 数据查询
- 视觉模型（神经）+ 知识图谱（符号）→ 视觉推理
- World model（神经）+ 因果图（符号）→ 真因果推理

### 6.3 AlphaProof 的启示

DeepMind 2024 在 IMO 拿银牌：
- **神经部分**：LLM 生成证明思路
- **符号部分**：Lean 验证（formal proof）
- **结合**：神经的直觉 + 符号的严谨

## 八、一句话总结

> 🎯 **四句话**：
> 1. **符号主义 = GOFAI**：智能 = 符号操作（Newell-Simon 1976）——主导 AI 30 年。
> 2. **1987 第二次寒冬**：专家系统维护爆炸 + CYC 失败——纯符号路线死胡同。
