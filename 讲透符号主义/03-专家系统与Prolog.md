# 03 — 专家系统与 Prolog：符号主义的工程化历史

> 「讲透符号主义」第三章。01 讲了一阶逻辑，02 讲了知识表示。本篇讲符号主义的**黄金时代**——专家系统（1970s-1980s）和 Prolog。理解这段历史，才能理解 AI 的"周期轮回"和符号主义的价值。

---

## 1. 灵魂：把专家知识编码成规则

$$
\boxed{\text{专家系统} = \underbrace{\text{知识库}}_{\text{专家经验}} + \underbrace{\text{推理引擎}}_{\text{01章归结}} \to \underbrace{\text{诊断/决策}}_{\text{专家级答案}}}
$$

1970s 的信念：**如果能编码人类专家的推理规则，AI 就能达到专家水平**。

---

## 2. 经典专家系统

### 2.1 MYCIN（1972-1980，Stanford）

**领域**：细菌感染诊断 + 抗生素推荐。

**结构**：
- 知识库：~600 条规则（"如果革兰氏阴性 + 杆菌 → 可能是大肠杆菌"）
- 推理引擎：**反向链**（从目标"是什么菌"倒推需要的证据）
- **置信度**（Certainty Factor）：每条规则带概率（处理不确定性）

**效果**：诊断准确率 **69%**——超过实习医生（55%），但低于专家（80%）。这是 1970s 的 SOTA。

**致命问题**：知识库**手工编写**，扩到其他领域需从零开始。

### 2.2 DENDRAL（1965，Stanford）

**领域**：从质谱数据推断分子结构。

**贡献**：第一个**知识密集型** AI 系统——证明"专家知识 > 通用推理"。

### 2.3 Cyc（1984-至今）

**野心**：手工编码**所有常识**（"水是湿的""人有父母"）。

**结果**：积累了百万级规则，但**从未达到预期**——常识太多了，手工不可扩展。

> 🎯 **Cyc 是符号主义的"墓志铭"**：它证明了"纯手工规则"不能通向 AGI——知识工程瓶颈。

## 3. Prolog：逻辑编程

### 3.1 Prolog = Programming in Logic

```prolog
% 知识库
parent(tom, bob).      % Tom 是 Bob 的家长
parent(bob, ann).
ancestor(X, Y) :- parent(X, Y).                    % 规则1
ancestor(X, Y) :- parent(X, Z), ancestor(Z, Y).    % 规则2

% 查询
?- ancestor(tom, ann).
true.                 % Prolog 自动推理
```

### 3.2 Prolog 的执行：反向链 + 回溯

Prolog 收到查询后：
1. 从目标出发，找匹配的规则
2. 递归证明子目标
3. 失败 → **回溯**，尝试下一条规则

### 3.3 Prolog 的优缺点

| 优点 | 缺点 |
|---|---|
| 声明式（说"什么"不说"怎么"）| 性能慢（回溯搜索）|
| 自动推理（不用手写控制流）| 不适合数值计算 |
| 内置回溯/模式匹配 | 生态小（vs Python）|

## 4. 符号主义的"冬天"（1987-1993）

### 4.1 AI 寒冬

专家系统的问题暴露：
- **知识工程瓶颈**：手工编码不可扩展
- **脆弱性**：超出知识库范围就完全失效（不像 NN 有概率输出）
- **维护成本**：规则越多越矛盾

### 4.2 连接主义复兴

同时，反向传播（1986 Rumelhart）成熟 → 神经网络在感知任务（手写数字/语音）上碾压符号系统 → **AI 范式从符号转向连接**。

---

## 5. 符号主义的现代复兴（LLM + 符号）

### 5.1 LLM 的"软符号"

LLM 用自然语言做"规则"——CoT/ReAct 本质是**隐式符号推理**。但它不可靠（幻觉）。

### 5.2 LLM + 形式化验证

AlphaProof（DeepMind 2024）：LLM 生成数学证明 + **Lean 形式化验证**——神经网络出直觉，符号系统保证正确。

### 5.3 规则引擎的现代应用

- **法律科技**：自动合同审查（规则引擎 + NLP）
- **金融合规**：反洗钱规则
- **医疗**：临床决策支持（CDSS）

---

## 6. 批判性

- **专家系统"赢在专业，输在通用"**——MYCIN 很强但只懂细菌感染
- **知识工程瓶颈至今未解**——即使有 LLM 辅助抽取知识，验证/维护仍贵
- **符号主义的历史价值**：它给了 AI 第一个"工程化"的框架（知识库+推理引擎），这个框架仍在特定领域（法律/金融/医疗）有效

> **诚实结论**：专家系统是符号主义的黄金时代，也是它的"滑铁卢"——证明了手工知识不可扩展。但符号主义没有死——LLM + 形式化验证（AlphaProof）是它的新生。符号保证可靠性，NN 提供感知——融合是未来。
