# 01 · 一阶逻辑与谓词演算

> 承接 [00-符号主义是什么](./00-符号主义是什么.md)。00 讲了 GOFAI 的物理符号系统假设；本章进入符号主义最核心的数学内核——**一阶逻辑（FOL）**，并指出一个容易被掩盖的事实：**LLM 在做的事实在推理，本质就是 FOL 推理的模糊、概率版本**。理解 FOL，才能看清 LLM 推理的"硬"边界。

---

## 直觉层

### 一个具体时刻

> 1965 年，John Robinson 在 JACM 上发表《A Machine-Oriented Logic Based on the Resolution Principle》。在此之前，定理证明器要手写大量启发式；Robinson 给出**一条规则**——归结（resolution）——就能证明一阶逻辑里任何可证的命题。**角色**：Robinson。**冲突**：人类推理千变万化，如何用机器统一捕捉？**时刻**：他意识到只要把所有公式转成合取范式（CNF），一条归结规则就够。这一刻起，符号主义有了数学意义上的"推理引擎"。

### 为什么这是 LLM 时代必读

当你问 GPT-4："苏格拉底是人，所有人会死，苏格拉底会死吗？"——它能答对。但它**没有**在脑内跑 FOL 推理；它在做的是**概率模式匹配**，恰好在训练分布里命中了三段论模板。**FOL 推理保证前提真则结论必真；LLM 推理保证前提真则结论大概率真**。差之毫厘，在长链推理里就是"hallucination 累积"和"形式化正确"的分野。

## 数学层

### FOL 的语法构件

| 类型 | 符号 | 含义 |
|---|---|---|
| 常量 | $a, b, \text{苏格拉底}$ | 具体个体 |
| 变量 | $x, y, z$ | 任意个体 |
| 函数 | $f(x), \text{father}(x)$ | 个体到个体 |
| 谓词 | $P(x), \text{人}(x)$ | 个体到真值 |
| 量词 | $\forall x, \exists x$ | 全称 / 存在 |
| 连接 | $\land, \lor, \to, \neg$ | 与/或/蕴含/非 |

### 经典三段论（MP 推理）

$$\forall x \, (\text{人}(x) \to \text{会死}(x))$$
$$\text{人}(\text{苏格拉底})$$
$$\vdash \; \text{会死}(\text{苏格拉底}) \quad \text{(Modus Ponens)}$$

### 归结原理（Robinson 1965）

从两个子句 $A \lor B$ 与 $\neg B \lor C$，推出 $A \lor C$（消去互补文字）。**反演证明**：要证 $G$，把 $\neg G$ 加入知识库 KB，若能**导出空子句 $\square$**（矛盾），则 $G$ 成立。

$$\text{KB} \cup \{\neg G\} \vdash \square \;\iff\; \text{KB} \models G$$

### 关键定理（完备性与可判定性）

- **Gödel 完备性定理（1929）**：FOL 中"语义真"等价于"语法可证"——$\text{KB} \models G \iff \text{KB} \vdash G$。
- **半可判定性**：FOL 是**半可判定的**——若 $G$ 成立，归结程序会停机给出证明；若不成立，可能永远跑下去。
- **适用边界**：以上都要求 KB **一致**（不矛盾）。若 KB 自身矛盾，FOL 会"爆炸"——任何命题都可证（ex falso quodlibet）。

## 代码层

用 `sympy.logic` 演示命题逻辑归结，用 `z3-solver` 演示一阶可满足性（SMT 思路，第 05 章详讲）：

```python
from z3 import *

# 定义一个一阶理论：所有人会死，苏格拉底是人
Person = Function('Person', BoolSort(), BoolSort())
Mortal = Function('Mortal', BoolSort(), BoolSort())
socrates = Bool('socrates')

s = Solver()
# ∀x. Person(x) -> Mortal(x)   （此处用具体常量简化）
s.add(Implies(Person(socrates), Mortal(socrates)))
s.add(Person(socrates))

# 求 Mortal(socrates) 是否被蕴含
s.push()
s.add(Not(Mortal(socrates)))     # 加入否定
print(s.check())                  # UNSAT → 原命题成立
s.pop()
```

输出 `unsat`——意味着 $\neg \text{Mortal}(\text{苏格拉底})$ 与 KB 矛盾，即 KB 蕴含"苏格拉底会死"。这就是**归结反演的工程化**。

**LLM 等价行为**：直接问 LLM 同样问题，它会给"会死"。但 LLM **没有**给出不可辩驳的证明链——它只是把三段论模式延续下去。把 KB 换成 10 层嵌套规则，LLM 出错率陡升，z3 不变。

## 不足层

- **已证明**：FOL 的完备性（Gödel）、归结的完备性（Robinson）——数学事实。
- **经验但未证**：在真实知识图谱（如 Wikidata 子集）上，一阶推理在 KB 规模 10M 三元组左右就开始性能崩塌（需 materialize / approximate）。
- **未解**：
  1. **开放世界假设下的知识获取瓶颈**：FOL 假设封闭世界时强，但真实世界开放——CYC 的死穴（见 00 章）。
  2. **不确定性建模**：FOL 没有"概率"。要加概率得升级到 Markov Logic Network（MLN）或 Probabilistic Soft Logic——这是神经符号的桥梁之一（[`讲透神经符号`](../讲透神经符号/)）。
  3. **LLM 推理与 FOL 的精确映射**：LLM 内部表示里有多少对应 FOL 的"隐式规则"？目前只是现象层面观察（CoT 提升推理 = 拉长推理链），理论机制未明。

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我最初把"半可判定"和"不可判定"混为一谈。重读 Gödel 后发现：FOL 是半可判定的——真命题可被有限步证明，但不可证命题可能让程序无限运行。一阶 Peano 算术的"真但不可证"命题存在（Gödel 不完备），但那是算术系统的事，不是 FOL 本身不可判定。
- **F3 术语翻译**：
  - "Modus Ponens" → 如果"A 蕴含 B"且"A 真"，那"B 必真"。最常见的推理一步。
  - "归结（resolution）" → 把两个含相反说法的句子撞一起，撞掉相反部分，剩下拼起来。
  - "合取范式 CNF" → 把所有句子统一成"括号里的或，括号之间的与"，方便机器统一处理。
- **F4 回炉**：v1 写成纯数学罗列；v2 加了"LLM 推理 = FOL 模糊版"这条主线，因为否则这章就和数学教材没差别，看不出"为什么 LLM 时代要读 FOL"。
