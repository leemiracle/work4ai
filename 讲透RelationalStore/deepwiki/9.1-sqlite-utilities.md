  The SQLite Utilities component provides a set of helper functions that streamline common SQLite database operations within the OpenHarmony Distributed Relational Database Management System (RDBMS). These utilities handle SQL statement analysis, file operations, path management, database replication support, security features, and debugging tools. For system-level database management, see [RDB Store Core](https://deepwiki.com/openharmony/distributeddatamgr_relational_store/2-rdb-store-core).

## SQL Constants and Definitions

 The `SqliteUtils` class defines several constants and enumerations that are used throughout the RDBMS to categorize and process SQL statements.

 
### SQL Statement Types

 
```
STATEMENT_SELECT    = 1   // SELECT statements
STATEMENT_UPDATE    = 2   // UPDATE statements
STATEMENT_ATTACH    = 3   // ATTACH DATABASE statements
STATEMENT_DETACH    = 4   // DETACH DATABASE statements
STATEMENT_BEGIN     = 5   // BEGIN TRANSACTION statements
STATEMENT_COMMIT    = 6   // COMMIT statements
STATEMENT_ROLLBACK  = 7   // ROLLBACK statements
STATEMENT_PRAGMA    = 8   // PRAGMA statements
STATEMENT_DDL       = 9   // Data Definition Language (CREATE, ALTER, DROP)
STATEMENT_INSERT    = 10  // INSERT statements
STATEMENT_ERROR     = 11  // Error in statement
STATEMENT_OTHER     = 99  // Other statement types
```

 
### Conflict Resolution Clauses

 The utility provides constants for SQLite conflict resolution clauses:

 
```
""              // Default conflict resolution
" OR ROLLBACK"  // Abort the command and roll back the transaction
" OR ABORT"     // Abort the command but don't roll back
" OR FAIL"      // Don't change remaining rows
" OR IGNORE"    // Skip the row causing the conflict
" OR REPLACE"   // Replace the existing row with the new row
```
