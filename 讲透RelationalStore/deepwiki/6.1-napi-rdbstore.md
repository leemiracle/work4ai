  This document provides technical documentation for the NAPI RdbStore module in OpenHarmony's Distributed Relational Database Management System. This module provides JavaScript interface bindings to the native RdbStore implementation, allowing applications to interact with SQLite databases through JavaScript APIs. For information about the native RdbStore implementation, see [RdbStore Core](https://deepwiki.com/openharmony/distributeddatamgr_relational_store/2-rdb-store-core).

 
## Purpose and Scope

 The NAPI RdbStore module serves as a bridge between JavaScript applications and the native RdbStore functionality. It enables developers to:

 
 - Create and open relational databases
 - Execute SQL queries and statements
 - Perform CRUD operations (Create, Read, Update, Delete)
 - Use predicates for complex query conditions
 - Manage database transactions
 - Handle distributed database operations
 
 This module is part of the JavaScript API layer in the Distributed Data Management framework and provides the foundation for relational database access in JavaScript applications.

## Key Components

 
### RdbStoreProxy

 The `RdbStoreProxy` class is the main wrapper for the native RdbStore functionality. It provides JavaScript bindings for database operations and manages the lifecycle of the native RdbStore instance.

 Key methods include:

 
| Method | Description |
|---|---|
| Init | Initializes the RdbStore class and exports its methods |
| NewInstance | Creates a new RdbStore instance with a native RdbStore object |
| Insert | Inserts a record into the database |
| Update | Updates records in the database |
| Delete | Deletes records from the database |
| Query | Queries records using RdbPredicates |
| QuerySql | Executes a SQL query |
| ExecuteSql | Executes a SQL statement |
| BeginTransaction | Begins a transaction |
| Commit | Commits a transaction |
| RollBack | Rolls back a transaction |

### AsyncCall Mechanism

 The `AsyncCall` class provides a mechanism for executing database operations asynchronously. It handles the creation and management of asynchronous work items and ensures that database operations do not block the main JavaScript thread.

 Key methods include:

 
| Method | Description |
|---|---|
| Call | Entry point for executing operations, supports both async and sync modes |
| OnExecute | Executed in a worker thread to perform the database operation |
| OnComplete | Executed in the main thread to process results and notify JavaScript |
| SetBusinessError | Creates JavaScript error objects from native errors |

## Conclusion

 The NAPI RdbStore module provides a robust JavaScript interface to the OpenHarmony relational database functionality. It supports all essential database operations, includes comprehensive error handling, and offers both synchronous and asynchronous execution models. The module maintains backward compatibility through version checking mechanisms and provides a foundation for relational database access in JavaScript applications.
