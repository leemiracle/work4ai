  This document details the SQLite Connection component in the OpenHarmony Distributed Relational Database Management System (RDBMS). The SQLite Connection provides a bridge between the RDB Store implementation and the underlying SQLite database engine, handling database connection management, configuration, statement preparation, and execution.

 For information about the connection pool that manages multiple connections, see [Connection Pool](https://deepwiki.com/openharmony/distributeddatamgr_relational_store/3.1-connection-pool).

 
## Overview

 The `SqliteConnection` class implements the `Connection` interface and manages the lifecycle of SQLite database connections. It provides functionality for opening databases, configuring connections, preparing and executing SQL statements, handling encryption, managing journal modes, and supporting high availability through slave connections.

## Security and Encryption

 The `SqliteConnection` class supports database encryption using the following mechanisms:

 
 - Key retrieval through the `RdbSecurityManager`
 - Setting encryption parameters for the SQLite database
 - Key rotation support with re-keying functionality
 
 
```

```

 The encryption setup process includes:

 
 - Checking if encryption is enabled
 - Retrieving encryption keys (could be from key files or service)
 - Setting the encryption key using `sqlite3_key`
 - Configuring crypto algorithms, HMAC algorithms, and KDF algorithms
 - Setting crypto page size
 - Supporting key rotation with `ReSetKey`

## Connection Methods Reference

 The `SqliteConnection` class provides these primary methods:

 
| Method | Description |
|---|---|
| Create | Static factory method to create a connection |
| InnerOpen | Opens the SQLite database with configuration |
| OpenDatabase | Opens the SQLite database |
| Configure | Configures the database connection |
| CreateStatement | Creates a SqliteStatement for SQL execution |
| ExecuteSql | Executes SQL without returning a result |
| ExecuteForValue | Executes SQL and returns a single value |
| SetEncrypt | Configures encryption for the database |
| SetJournalMode | Sets the journal mode |
| Backup/Restore | Handles high availability operations |

## Configuration Parameters

 The connection behavior is controlled through `RdbStoreConfig` with these key parameters:

 
| Parameter | Description |
|---|---|
| journalMode | SQLite journal mode (WAL, DELETE, etc.) |
| syncMode | Synchronization mode for WAL |
| pageSize | Database page size |
| encryptKey | Encryption key for the database |
| integrityCheck | Level of integrity checking |
| busyTimeout | Timeout for busy handlers |
| haMode | High availability mode |
| storageMode | Memory or disk storage |
