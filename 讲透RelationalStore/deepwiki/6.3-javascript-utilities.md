  This page documents the JavaScript utilities that support the JavaScript API layer for the OpenHarmony Distributed Relational Database Management System. These utilities provide essential functionality for type conversion, configuration handling, property management, and other operations that bridge the gap between JavaScript and native C++ code.

 For information about the NAPI RdbStore implementation, see [NAPI RdbStore](https://deepwiki.com/openharmony/distributeddatamgr_relational_store/6.1-napi-rdbstore). For information about NAPI Result Sets, see [NAPI Result Set](https://deepwiki.com/openharmony/distributeddatamgr_relational_store/6.2-napi-result-set).

 
## Overview

 The JavaScript utilities consist of two main components:

 
 - **Generic JavaScript Utilities** - Common operations for converting between JavaScript and C++ data types, property handling, and class definition
 - **RDB-specific JavaScript Utilities** - Database-specific operations for handling RDB configurations, asset values, and distributed data structures

### Path Resolution

 The utilities provide a `GetRealPath` function that resolves the actual database file path based on the configuration and context parameters.

 The path resolution follows these rules:

 
 - If `rootDir` is provided, it uses that as the base directory
 - Otherwise, it uses the application's database directory
 - It validates path constraints (e.g., no path separators in the database name)
 - If using a data group ID, it resolves the system database directory

## Summary

 The JavaScript utilities form a crucial bridge between the JavaScript API layer and the native C++ implementation of the OpenHarmony Distributed Relational Database Management System. They provide comprehensive functionality for type conversion, configuration processing, context management, property handling, and value object utilities, enabling seamless integration between JavaScript applications and the underlying database system.
