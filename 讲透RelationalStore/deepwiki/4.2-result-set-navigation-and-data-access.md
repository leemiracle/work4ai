## Result Set Overview

 Result sets in the OpenHarmony RDBMS represent the data returned from database queries. They provide methods to navigate through rows and columns, as well as access data in various formats. Results are accessed via a cursor-based model where navigation methods move a position pointer through result rows.

### Result Set Lifecycle and Positioning

 Result sets in OpenHarmony RDBMS follow a cursor-based model with the following key concepts:

 
 - **Initial Position**: When a result set is first created, it points to position -1 (before the first row)
 - **Position Range**: Valid positions are from 0 to row count - 1
 - **Navigation Methods**: Move the cursor to different positions within the result set
 - **Data Access**: Only available once the cursor is positioned on a valid row
 - **Closing**: Resources must be released by calling `close()` when finished

## Navigation Methods

 The result set provides multiple ways to navigate through query results. All navigation methods return boolean values indicating success or failure.

 
### Positional Navigation

 These methods move the cursor to a specific position by row number:

 
| Method | Description |
|---|---|
| GoToRow(position) | Moves to the specified absolute position (0-based) |
| GoTo(offset) | Moves relative to current position by the specified offset |
| GoToFirstRow() | Moves to the first row (position 0) |
| GoToLastRow() | Moves to the last row (rowCount - 1) |

## Data Access Methods

 The result set provides multiple methods for accessing data from the current row.

 
### Type-Specific Access Methods

 These methods retrieve data in specific formats:

 
| Method | Return Type | Description |
|---|---|---|
| GetString(columnIndex) | string | Retrieves text data |
| GetInt(columnIndex) | int | Retrieves integer data |
| GetLong(columnIndex) | int64_t | Retrieves long integer data |
| GetDouble(columnIndex) | double | Retrieves floating-point data |
| GetBlob(columnIndex) | vector<uint8_t> | Retrieves binary data |
| GetAsset(columnIndex) | Asset | Retrieves asset data |
| GetAssets(columnIndex) | Assets | Retrieves multiple assets |
| GetFloat32Array(columnIndex) | vector<float> | Retrieves float vector data |
| GetValue(columnIndex) | ValueObject | Retrieves data as a generic value |

 Each of these methods requires a valid column index, which can be obtained using `GetColumnIndex(columnName)`.
