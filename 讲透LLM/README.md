# 讲透 LLM（大语言模型）

> **LLM 是 2024-2026 AI 的绝对中心**——ChatGPT/Claude/Gemini/DeepSeek 都是 LLM。但"LLM"这个词承载太多：架构（Transformer）、训练（预训练+对齐）、能力（推理/Agent/多模态）、工程（推理优化/部署）。
>
> **本系列是 LLM 方向的整合枢纽**——不是单点深挖（那些已有专题目录），而是把 LLM 的**完整生命周期 + 能力地图 + 工程全栈**串成一条线，让你看清 LLM 的全貌，单点深入时知道去哪。
>
> 🆕 **2026-08-13 新建**：整合 [`讲透Transformer`](../讲透Transformer/)（架构）+ [`讲透NLP`](../讲透NLP/)（任务）+ [`讲透微调`](../讲透微调/)（PEFT）+ [`讲透Agent`](../讲透Agent/)（应用）+ [`讲透RL`](../讲透RL/)（RLHF）+ [`讲透数据`](../讲透数据/) 的 LLM 相关内容。
