## §1 ① Reasoning Scaling：从训练算力到推理算力

### 1.1 范式转移

**传统 scaling**（2020-2024）：更大模型 + 更多数据 → 更强能力
**Reasoning scaling**（2025+）：**相同模型 + 更多推理算力** → 更强能力

DeepSeek-R1 / OpenAI o1 证明：推理预算 10× 时，能力可显著提升。

### 1.2 关键技术

| 技术 | 怎么做 |
|------|-------|
| **Chain-of-Thought** | 多步推理路径 |
| **self-consistency** | 采样多次 + 多数投票 |
| **tree search** | 推理树 + 剪枝（ToT/MCTS）|
| **self-reflection** | 推理 + 自我批判 + 修正 |

### 1.3 边界（诚实，连 [`讲透RL/05`](../讲透RL/05-RLVR的极限.md)）

- **RLVR 是锐化器不是发现器**——放大已有能力，不创造全新能力
- **pass@k 反转**（NeurIPS 2025 Oral）：RLVR 训练后 pass@k 在大 k 反而下降
- **含义**：reasoning 的根本上限可能仍在预训练

## §2 ② Test-Time Compute：新的 scaling 维度

### 2.1 Brown 的战略洞察

> Noam Brown（CS224R）：**inference compute 被严重低估**——今天 $1M 的能力明年可能 $100。安全评估必须 project test-time compute（dedicated state actor 可花 $10M 推理）。

### 2.2 三种 test-time 方法

```
① 采样多 + 投票（self-consistency）    → 简单，成本线性
② 树搜索（MCTS / beam）                → 强，成本指数
③ 自我反思 + 修正（reflection）        → 中等，效果好
```

### 2.3 代表系统

- **o1**（OpenAI）：reasoning model，推理时多步思考
- **R1**（DeepSeek）：RLVR 训出的 reasoning
- **PaCoRe**（8B 超 GPT-5，待核 [`讲透RL/07`](../讲透RL/07-2026最新研究全景.md)）

## §3 ③ World Model 集成：LLM + 世界模拟

### 3.1 为什么 LLM 需要世界模型

纯 LLM 是**文本模式压缩器**，缺乏对物理世界/因果的理解。要走向 AGI / 具身，需要"懂世界"。

### 3.2 三条集成路径

| 路径 | 思路 | 状态 |
|------|------|------|
| **LLM 内置 world model** | 在 latent 空间预测未来 | 研究阶段 |
| **LLM + 外部世界模型**（Genie/Dreamer）| LLM 规划 + 世界模型推演 | 🟢 进行中 |
| **视频生成 = 隐式世界模型** | Sora 路线 | 争议（[`讲透世界模型/03`](../讲透世界模型/03-视频生成是世界模型吗.md)）|

### 3.3 LeCun vs OpenAI 之争（详见 [`讲透世界模型/02`](../讲透世界模型/02-JEPA数学与LeCun路线.md)）

- **LeCun（JEPA）**：预测抽象表征，理论可解释
- **OpenAI（Sora/Scaling）**：预测像素，赌涌现

2026 仍未有定论。

## §4 ④ 效率前沿：更小更快更省

### 4.1 训练效率

| 方向 | 代表 |
|------|------|
| **MoE**（混合专家）| DeepSeek V3 / Mixtral（激活部分参数）|
| **MTP**（多 token 预测）| DeepSeek V3（+15% 效率）|
| **稀疏注意力**| Flash Attention / Ring Attention |

### 4.2 推理效率

| 方向 | 代表 |
|------|------|
| **量化** | INT4（AWQ/GPTQ）/ 2-bit |
| **蒸馏** | 大模型 → 小模型 |
| **投机解码** | 小模型起草 + 大模型校验 |
| **KV Cache 优化** | PagedAttention / 压缩 |

### 4.3 小模型革命

**趋势**：小模型（1-3B）+ 强后训练 → 在特定任务接近大模型。
- **Phi 系列**（Microsoft）：1-3B 用高质量合成数据训出超预期能力
- **端侧 LLM**：手机/PC 本地跑（详见 [`端侧AI压缩技术/`](../端侧AI压缩技术/)）

## §5 ⑤ 架构创新：post-Transformer？

### 5.1 Transformer 的瓶颈

- **$O(n^2)$ attention**：长上下文成本爆炸
- **静态参数**：不能根据任务调整容量
- **无显式记忆**：所有知识压在权重

### 5.2 候选架构

| 架构 | 创新 | 状态 |
|------|------|------|
| **Mamba / SSM** | 状态空间模型，线性复杂度 | 🟢 已用于生产（Jamba）|
| **RWKV** | RNN + 并行训练 | 🟡 社区活跃 |
| **混合（Hybrid）** | attention + SSM | 🟢 2026 主流（Jamba/Zamba）|
| **Diffusion LM** | 扩散做语言 | ❌ 早期 |
| **检索增强** | 外部记忆 | ✅ RAG 已成熟 |

### 5.3 诚实判断（2026）

**Transformer 仍是绝对主流**，post-Transformer 在特定场景（长上下文/端侧）有优势，但尚未根本替代。混合架构（attention + SSM）是 2026 的务实选择。

## §7 一句话总结

> 🎯 **5 句话**：
> 1. **Reasoning scaling** 是 2025-2026 最大范式转移——从"训更多"到"推理时想更多"。
> 2. **Test-time compute** 是新 scaling 维度——同模型 + 更多推理 = 更强能力（但有 RLVR 天花板）。
> 3. **World model 集成**是走向 AGI / 具身的必经路——LeCun vs OpenAI 之争未决。
> 4. **效率前沿**：MoE / 量化 / 投机解码 / 小模型革命，让 LLM 更普惠。
> 5. **Transformer 仍是主流**，混合架构（attention + SSM）是 2026 务实选择，post-Transformer 在长上下文/端侧有空间。
