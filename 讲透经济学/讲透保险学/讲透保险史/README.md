# 讲透保险史 · 每个条款都是一场灾难的结晶

> **定位**：这支负责"保险制度如何长成"——从巴比伦海运贷款到巨灾债券，
> 每一条现代条款背后都有一场被写进合同的灾难。GB/T 79075 三级支
> （保险史，7907510）。史即理论：条款的演化史=风险认知的演化史。

## 诞生

约公元前 1754 年汉谟拉比法典（底部贷款含风险保费——保险思想的
第一块泥板）；1666 伦敦大火（1.3 万户焚毁→火灾保险与建筑分类费率的
起点）；1688 劳合社咖啡馆（承保信息挂墙→可交易市场）；
1762 伦敦公平人寿（生命表定价→精算职业）；1805 广州谏当保安行
（中国现代保险开端）；1949 中国人民保险公司（国家保险体系起点）。

## 核心问题（3-5 条）

- ✅ 已梳理：大风险事件→新险种/新条款的因果链（大火→火险；海难→再保险；
  1906 旧金山地震→地震除外条款的诞生与反复拉锯）
- ✅ 已梳理：保险中心的历史迁移（伦敦→纽约→百慕大/新加坡 IL S 枢纽）
- 🔄 前线：中国保险史的档案化（近代华商保险与民族金融史研究）
- 🔄 前线：巨灾证券化三十年（1992 安德鲁飓风→1997 首只猫债）的制度史书写
- ❌ 待做：口述史抢救（1980s 复业一代从业者的记忆）

## ✨这支最美的一个事实

1906 年旧金山地震后保险公司照赔了约 90% 的火灾损失（当时条款赔火不赔震
——大火一半是地震引起的），多家险企因此破产，但**照赔的那批名字
活成了百年品牌**：保险史反复证明，**这个行业最值钱的资产是"危机时
说到做到"的名声**——因为它卖的本来说的就是承诺。
