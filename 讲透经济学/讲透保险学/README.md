## 一、诞生

保险的三个原生问题，各自长出一类保险：

1. **船会沉**（海运风险分担）——巴比伦汉谟拉比法典（约公元前 1754 年）
   的底部贷款已含风险保费；1688 年伦敦劳合社咖啡馆把"给船担保"
   变成可交易合约——现代保险市场的起点。
2. **人会死得不是时候**（寿命不确定性）——1693 年哈雷（那颗彗星的人）
   编制第一张科学生命表；1762 年伦敦公平人寿首次用生命表+死亡率
   定价——**精算职业的出生证**。
3. **城市会烧**（巨灾）——1666 年伦敦大火（1.3 万户）催生火灾保险
   与再保险的萌芽；巨灾至今仍是"可保性边界"的守门问题。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 风险池为何稳定（大数定律） | ✅ 已解 | 独立个体风险加总→相对波动→0，保险的第一定理 |
| 保费怎么定（保费原理） | ✅ 方法已解 | 期望值/方差/ES 原理族——期望加安全附加 |
| 逆向选择（谁会来投保） | ✅ 理论已解 | Rothschild-Stiglitz 1976：信息不对称下的自选合约 |
| 道德风险（保了就浪） | 🔄 永恒工程 | 免赔额/共保是经济学上最优的不完全保障 |
| 巨灾可保性 | ❌ 前沿 | 相关性击穿大数定律——巨灾债券把风险卖回资本市场 |
| 气候下的重定价 | ❌ 未解 | 历史损失数据失效（分布本身在移动），见 01 章 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 个体风险近似独立 | 大数定律→保费稳定可预算 | 相关性灾难（疫情/巨灾）池子瞬间变小 |
| 历史数据代表未来 | 精算定价的全部表格 | 分布漂移（气候/医疗通胀）下表格过期 |
| 投保前信息可核（核保） | 逆向选择可控 | 隐私与公平的冲突（基因检测/大数据定价） |
| 长期资产匹配长期负债 | 期限溢价收入 | 流动性与再投资风险（利率下行卖年金=慢性失血） |
