# 讲透保险管理 · 逆向银行的经营学

> **定位**：这支负责"保险公司怎么运营"——核保、定价、准备金、偿付能力、
> 再保险、投资六大管理环。保险公司的经营本质=**负债驱动的逆向银行**
> （先收钱后服务，负债比资产长久）。GB/T 79075 三级支（保险管理，7907520）。

## 诞生

1848 伦敦精算师学会成立（精算从"会算生命表"变成职业）；
20 世纪分业经营与偿付能力监管成型（1944 美国 RBC 前身、
2009 Solvency II、2016 中国偿二代）；2010s 科技重塑分销与核保
（代理人 900 万→腰斩，见家族 01 章前线五）。

## 核心问题（3-5 条）

- ✅ 已解：六大管理环的分工（核保管入口、定价管价格、准备金管负债、
  偿付能力管资本、再保险管尾部、投资管收益）
- ✅ 已解：准备金评估方法族（链梯法/BF 法/期望法——家族 04 章走廊 2）
- 🔄 前线：资产负债管理（ALM）在利率大起大落年代的久期缺口军规执行
- 🔄 前线：IFRS 17 新准则（保险合同收入按服务确认——行业报表口径重构）
- ❌ 未解：长期低利率下"利差损"治理（卖出去的高预定利率保单如何消化）

## ✨这支最美的一个事实

保险公司资产负债表上最大的数字在负债端：**准备金=欠未来的钱**——
一家保险公司的"利润"不是收进来的保费，而是"假设兑现后释放出来的
负债"。所以精算报表的假设页比利润表诚实：**改一个死亡率假设，
利润可以凭空多出几十亿**——读懂保险公司的第一步是读它的假设。
