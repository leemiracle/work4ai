# 讲透区域经济学 · 空间上的经济：集聚与差距

> 支：[讲透国民经济学](../README.md) 自定主干支。经济为什么不在
> 国土上均匀铺开——集聚的机制与区域差距的政策。

## 定位句

本支负责**经济活动的空间分布**：集聚机制（向心力 vs 离心力）、
城市体系（中心地/位序-规模）、区域差距的测度与收敛、
区域政策（转移支付/开发区/都市圈）的评估。
消歧：本支是国内空间；国际区域归
[讲透世界经济学/讲透世界区域经济](../../讲透世界经济学/讲透世界区域经济/)。

## 诞生与关键事件

- 1826 冯·杜能《孤立国》：区位地租理论——空间经济学第一定理
- 1933 克里斯塔勒中心地理论：城市等级的六边形几何
- 1950s- 区域经济学建制化（Isard）；增长极理论（Perroux）
- 1991 克鲁格曼新经济地理（NEG）：规模经济+运输成本的
  均衡集聚（2008 诺奖）——"第二自然"地理
- 2000s- 中国区域政策研究热：西部大开发/中部崛起/都市圈一体化

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 城市为什么存在（集聚机制） | ✅ NEG 框架：向心力-离心力均衡 |
| 城市规模分布的齐普夫律 | ✅ 经验极其稳健（位序-规模指数≈1） |
| 区域差距的收敛（σ/β 收敛） | 🔄 条件收敛稳健，政策贡献争议 |
| "人动还是钱动"（迁移 vs 转移支付） | 🔄 政策哲学之争 |
| 集聚的红利与代价（拥堵/房价） | 🔄 前线（大城市边界之争） |

## 这支最美的一个事实（一句）

城市位序-规模律：一国第 k 大城市的人口 ≈ 首位的 1/k——
从美国到中国横跨制度与历史，指数都惊人接近 1——
**空间自组织的指纹**，两百年理论（杜能→NEG）都在解释这一条线。

## 假设与依赖

读本支需微观基础+一点空间想象；假设：运输成本与土地是
第一变量（空间由此进入模型）、国内要素可流动（与国际
贸易支的假设互补）。
