# 讲透消费投资经济学 · 总需求的两大引擎

> 支：[讲透国民经济学](../README.md) 自定主干支。C+I+G+NX 里的 C 与 I——
> 一国短期增长的油门与长期产能的种子。

## 定位句

本支负责**总需求的两大构成**：消费函数（凯恩斯→生命周期→
持久收入→行为修正）与投资函数（加速数、托宾 Q、投资不可逆性），
以及两大引擎的结构转型（消费率/投资率的长期演变与再平衡）。

## 诞生与关键事件

- 1936 凯恩斯消费函数（边际消费倾向+乘数）
- 1946 Kuznets 之谜：长期消费率稳定 vs 短期波动——
  理论真空带
- 1954/1957 莫迪利安尼生命周期+弗里德曼持久收入（1985/1976
  诺奖）：之谜的双解
- 1969 托宾 Q：资本市场视角的投资理论
- 1982 Dixit-Pindyck 投资不可逆性：实物期权方法
- 2008 四万亿与消费刺激政策的中国实践；2020s 扩内需战略

## 这支最美的一个事实（一句）

消费函数之谜的解法极简：把"一生"装进消费决策——
人按持久收入而非当期收入消费，短期的收入波动被"熨平"——
一个时间维度的引入，同时解释了短期波动与长期稳定。

## 假设与依赖

读本支需宏观基础（国民收入恒等式）；假设：信贷市场完备
（生命周期模型的软肋——流动性约束家庭占比高时模型失灵）。
