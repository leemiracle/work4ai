# 讲透国民经济计划学 · 从物资平衡表到五年规划

> 支：[讲透国民经济学](../README.md) 自定主干支。国家如何配置资源——
> 一门经历了"理论平局、实践判决、算法重审"的学科。

## 定位句

本支负责**国家层面的资源配置与规划**：投入产出核算与平衡、
线性规划与影子价格（计划的数学形态）、五年规划的制度与
方法（指令性→指导性→战略引导）、规划-市场边界的理论。

## 诞生与关键事件

- 1920s 苏联物资平衡表（Narkomat 下的核算实践）
- 1936/1941 列昂惕夫《美国经济结构》投入产出表（1973 诺奖）
- 1939 康托罗维奇线性规划+影子价格（1975 诺奖）——
  最优计划的数学=市场的对偶
- 1930s-40s 兰格-米塞斯-哈耶克论战：计划可行性的第一次开庭
- 1953- 中国五年计划；2006"十一五"计划改规划——
  指令性退出、战略引导定型
- 2020s 大数据/AI 重开论战：算力解决计算，未解决信息生成

## 这支最美的一个事实（一句）

康托罗维奇为苏联胶合板厂解出的"影子价格"，与芝加哥交易所的
真实价格在数学上是同一个对象——**计划与市场在最优处相遇**，
分野只在谁能到达那里。

## 假设与依赖

读本支需线性代数基础；假设：部门可加总（表口径）、指标可
问责（治理前提）——两假设本身都是本支研究对象。
