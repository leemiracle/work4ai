## 诞生

三条制度-思想线铸成本家族：

1. **计划线**：1920s 苏联物资平衡表实践 → 列昂惕夫 1936/1941
   投入产出表（美国经济结构）——计划工具成为通用核算框架
   （1973 诺奖）；康托罗维奇线性规划（1975 诺奖）证明计划
   的数学形态与市场对偶（影子价格=价格）；兰格-米塞斯论战
   （1930s）与哈耶克 1945 信息反诘，直到大数据时代重开
2. **规划转型线**：中国五年计划 1953-2025（十一五起"计划"
   改"规划"——从指令性转向战略性、约束性指标并存）
3. **需求与空间线**：凯恩斯乘数（消费/投资两大引擎）→
   中国"四万亿"（2008）的政策实践；冯·杜能 1826→克里斯塔勒
   中心地 1933→克鲁格曼新经济地理 1991（2008 诺奖）——
   空间维度进入主流

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 投入产出表与列昂惕夫逆阵 | ✅ (I−A)⁻¹ 存在与收敛（Perron-Frobenius） | 需求冲击的完全乘数可精确计算 |
| 计划的数学可行性 | ✅ 理论可解（线性规划对偶）、信息不可行 | 兰格论战的现代结案陈词 |
| 消费函数之谜（短期波动 vs 长期稳定） | ✅ 生命周期/持久收入解释（1985 诺奖） | Kuznets 之谜的两大答案 |
| 空间集聚的向心力-离心力机制 | ✅ NEG 框架成型 | "为什么有城市"有了均衡答案 |
| 规划与市场的边界（大数据计划经济之辩） | 🔄 前线重开 | 算力上升 vs 信息-激励不变 |
| 区域差距的收敛（中国区域经济） | 🔄 条件收敛证据 vs 政策争论持续 | 每五年规划的核心张力 |

## 假设与依赖

薄家族如实标注：三条主假设——①国民经济是可记录的整体
（SNA 国民账户成立）；②总量政策可调节需求（乘数机制存在、
且利率不落入零下界陷阱）；③空间与部门结构可被"表"刻画
（投入产出表的部门同质性假设）。
