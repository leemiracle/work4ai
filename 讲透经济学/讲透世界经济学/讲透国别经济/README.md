# 讲透国别经济 · 美日德法英俄六强研究

> 支：[讲透世界经济学](../README.md) GB/T 三级六条（美国经济·日本经济·
> 德国经济·法国经济·英国经济·俄国经济）归组。一国的经济是一台
> 可比较的机器。

## 定位句

本支负责**主要发达与转型大国的经济解剖**：增长模式、宏观治理
框架、产业结构与对外经济关系——以"同一张检查表"逐国体检，
差异即发现。

## 诞生与关键事件

- 战后比较经济体制研究（美苏对比）是本支前身；
  冷战后转向发达经济体比较
- 1980s 日本奇迹研究热→1990s 日本化（低增长低利率老龄化）
  成为全球议题
- 1990s 转型经济学（俄国休克疗法 vs 中国渐进）反哺比较方法
- 2008 危机后美欧模式对照；2010s 安倍经济学/德国模式
  （出口+双元制）各自成为参照系

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 六国的增长模式差异及其来源 | ✅ 描述成熟（消费驱动/出口驱动/资源驱动） |
| 日本化的机制（低利率陷阱） | 🔄 理论与政策争论持续 |
| 德国模式的双元制与出口竞争力 | 🔄 可迁移性争论 |
| 俄国资源型经济的结构与制裁脆弱性 | 🔄 2022 后量化研究爆发 |
| 六国检查表的通用维度 | ✅ 本支方法论：同一指标集逐国体检 |

## 这支最美的一个事实（一句）

同一个"劳动市场改革"检查项，六国跑出六种结果——制度互补性
（complementarity）：单项移植常失效，**制度是配套件不是零件**。

## 假设与依赖

薄支如实标注：以描述性比较+指标表为主，模型化程度低；
假设：跨国指标可比（OECD 口径）、模式可命名（命名有过度
简化风险）。
