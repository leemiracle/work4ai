# 讲透国际经济关系学 · 经济的治理层

> 支：[讲透世界经济学](../README.md) GB/T 三级支。IMF/WTO/BIS 与
>区域协定——没有世界政府的世界如何立规矩。

## 定位句

本支负责**国际经济治理与协调**：全球机构（IMF/WTO/BIS/世行）与
区域协定（EU/USMCA/RCEP/CPTPP）的职能与困境、经济制裁与
发展援助的政治经济、国际政治经济（IPE）的理论接口。

## 诞生与关键事件

- 1944 布雷顿森林会议：IMF+世行双机构设计（凯恩斯 vs 怀特
  方案之争是本支的创世故事）
- 1947 GATT→1995 WTO：贸易规则的法庭化（争端解决机制）
- 1975 G7；1999 G20——危机驱动的协调机制谱系
- 2014- 制裁经济学复兴（金融制裁/出口管制）；2022 后
  "武器化的相互依赖"（Farrell-Newman 2019）成显学
- 2015 巴黎气候协定、2021 全球最低税：议题从贸易货币扩展到
  碳与税

## 这支最美的一个事实（一句）

布雷顿森林是凯恩斯方案（全球货币 Bancor+自动矫正顺差国）与
怀特方案（美元中心）的折中——**今天所有关于储备体系的争论，
都是 1944 年那场折中的续集**。

## 假设与依赖

读本支无需高深技术；方法以制度分析+博弈论+案例为主；
假设：国家是可模型化的理性主体（IPE 的基本简化）。
