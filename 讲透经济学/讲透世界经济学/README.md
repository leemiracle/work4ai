## 诞生

学科骨架由三个制度时刻铸成：

1. **古典金本位（1870-1914）**：第一波全球化的引擎与枷锁——
   价格-铸币流动机制（休谟 1752 的思想）首次全球运转
2. **布雷顿森林（1944）**：大萧条以邻为壑的教训制度化——IMF/
   世界银行/关贸总协定三件套；蒙代尔-弗莱明框架（1960s，
   蒙代尔 1999 诺奖）给开放宏观配上模型
3. **1971 尼克松冲击至今**：浮动汇率时代；特里芬难题（1960）
   预言的储备货币矛盾持续发酵；1997、2008、地缘割裂（2022-）
   三次危机重塑研究议程

## 假设与依赖

薄学科如实标注：本家族三条主假设——①国民经济可作"开放系统"
建模（内部结构压缩成几个总量）；②国际收支会计恒等成立
（CA+KA+FA+EO=0，会计层最硬）；③"世界"是可分析单位
（全球加总逻辑存在）。国别/区域支另加"可比性"假设。
