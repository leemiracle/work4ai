# 讲透国际贸易学 · 谁卖什么给谁、谁获益

> 支：[讲透世界经济学](../README.md) GB/T 三级支。比较优势两百年的
> 理论阶梯与"贸易的政治学"。

## 定位句

本支负责**商品与服务的跨国交换**：贸易为何发生（比较优势→规模
经济→企业异质性）、谁获益谁受损（斯托尔珀-萨缪尔森）、以及
贸易政策的政治经济学（关税/配额/FTA/WTO）。

## 诞生与关键事件

- 1817 李嘉图比较优势：两国两商品的劳动成本差即贸易基础
- 1941 斯托尔珀-萨缪尔森定理：贸易改变国内收入分配——
  保护主义有了经济学根源
- 1962 丁伯根引力方程：GDP×距离解释贸易流大头
- 1979-80 克鲁格曼新贸易理论：规模经济+差异化产品解释
  产业内贸易（2008 诺奖）
- 2003 Melitz 企业异质性：出口企业是少数高生产率企业
- 2018- 贸易战与产业政策回潮：比较优势遇上阵营距离

| 关税的传导（谁付钱） | ✅ 经验主流：进口国消费者与企业承担大头 |

## 这支最美的一个事实（一句）

两百年前李嘉图用"葡萄牙酒换英国布"证明：**即使一国样样都弱，
只要相对成本不同，两国都能从贸易中获益**——专业化不看绝对
强弱，看相对差距。

## 假设与依赖

读本支需微观基础（供需、机会成本）；核心假设：要素在国内可流动、
跨国不可流动（H-O 框架）——GVC 时代部分松动。
