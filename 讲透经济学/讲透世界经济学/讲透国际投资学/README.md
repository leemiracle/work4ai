# 讲透国际投资学 · 资本为何跨国流动

> 支：[讲透世界经济学](../README.md) GB/T 三级支。FDI 与证券投资的
> 动机之别——"控制权"改变一切。

## 定位句

本支负责**跨国资本流动**：外商直接投资（FDI，带控制权）与
国际证券投资（FPI，纯财务）的动机、决定因素与后果；跨国公司
的全球生产组织与避地（避税地）结构。

## 诞生与关键事件

- 1960 海默（Hymer）垄断优势论：FDI 因市场不完全——
  跨国公司理论的起点
- 1976 邓宁 OLI 折衷范式（所有权-区位-内部化）：FDI 三问框架
- 1980s-90s 内部化理论 Vernon 产品周期→价值链切片
- 1990s FDI 大扩张；2008 后金融账户波动成为新兴市场风险源
- 2015 BEPS 行动计划：跨国避税与利润转移的全球规制

## 这支最美的一个事实（一句）

卢卡斯之谜：新古典理论预言资本应涌向穷国（边际回报高），
现实却是穷国资本外流——**"资本追逐的不是高回报，是安全的
高回报"**，一句话逼出制度经济学。
