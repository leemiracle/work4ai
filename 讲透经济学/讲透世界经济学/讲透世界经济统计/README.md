# 讲透世界经济统计 · 世界的仪表盘

> 支：[讲透世界经济学](../README.md) GB/T 三级支。世界经济这台机器
> 的仪表盘——谁造的、怎么校的、哪里会骗人。

## 定位句

本支负责**世界经济数据的测量与治理**：国民账户与国际收支的
全球口径（SNA/BPM6）、PPP 换算（ICP 项目）、贸易与金融统计的
编制、以及数据质量的审计（GDP 修订、影子经济、官方统计的政治）。

## 诞生与关键事件

- 1953 联合国 SNA 第一版→1968→1993→2008（现行）：全球国民
  账户宪法
- 1944- IMF《国际收支手册》BPM 一至六版（BPM6 现行）
- 1968 ICP 项目启动：购买力平价的全球比价工程（最大的
  统计协作之一）
- 1990s- 季度 GDP 全面化；2008 巴黎小组（G20 数据缺口倡议，
  危机教训）
- 2020s 另类数据（卫星夜光/移动/支付）进入宏观测量

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 全球口径的统一与执行 | ✅ SNA/BPM 成熟（执行落差仍在） |
| PPP 换算的稳定性 | 🔄 基期更换挪动全球贫困率与 GDP 排名（中国超美争议的根源） |
| 数据缺口（避税/影子经济/资本流动） | 🔄 常态难题（BIS 伦敦港之谜） |
| 官方统计的政治经济学 | 🔄 前线（阿根廷 GDP 争议等案例研究） |
| 另类数据的信度校准 | 🔄 前线（夜光 vs 官方 GDP 的融合） |

## 这支最美的一个事实（一句）

PPP 一换基期（ICP 2005→2011→2017），全球极端贫困人数可挪动
上亿、中美经济规模对比改写——**世界排名是价格基的函数**，
测量即政治。

## 假设与依赖

薄支如实标注：以口径学+数据治理为主，模型化低；假设：
各国统计机构独立且方法可审计（假设本身常被研究质疑——
这正是本支内容）。
