# 讲透世界区域经济 · 欧北美亚太拉美非洲中亚西亚

> 支：[讲透世界经济学](../README.md) GB/T 三级六条（欧洲经济·北美经济·
> 亚太经济·拉美经济·非洲经济·中亚西亚经济）归组。区域=地理+制度
> 双重单位。

## 定位句

本支负责**世界各区域的经济格局**：区域一体化（EU/USMCA/ASEAN/
AfCFTA）、区域增长模式（东亚奇迹/拉美中等收入陷阱/资源诅咒）与
南北关系——把"世界"切成有结构的大块。

## 诞生与关键事件

- 1957 罗马条约→1993 欧盟：史上最深的区域一体化实验室
  （货币联盟 1999，欧债危机 2010 考试）
- 1960s 拉美结构主义（普雷维什中心-外围）→进口替代半个世纪
  →1980s 失落的十年
- 1960s-90s 东亚奇迹（世界银行 1993 报告定名）：出口导向的
  对照组胜利
- 1994 NAFTA→2020 USMCA；2002 中国入世后亚太供应链成型
- 2021 AfCFTA 启动：非洲大陆自贸区——最新的一体化实验

## 这支最美的一个事实（一句）

资源诅咒不是物理定律而是**条件概率**：博茨瓦纳（钻石+好制度）
与挪威（石油+主权基金）逃出，制度弱者困于"资源的波动"——
变量是制度，不是资源。
