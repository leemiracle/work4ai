# 讲透国际金融学 · 汇率、危机与不可能三角

> 支：[讲透世界经济学](../README.md) GB/T 三级支。开放宏观的货币面：
> 汇率为什么动、危机为什么来、政策为什么只能三选二。

## 定位句

本支负责**跨国货币与金融关系**：汇率决定（平价理论与其失灵）、
国际收支调节、资本流动与危机（货币/银行/债务三联症）、
国际货币体系（金本位→布雷顿森林→浮动与美元本位）。

## 诞生与关键事件

- 1752 休谟价格-铸币流动机制：金本位的自我调节思想
- 1944 布雷顿森林；1960 特里芬难题预言体系内伤（1971 应验）
- 1960-63 蒙代尔-弗莱明：开放宏观标准模型；不可能三角
  （蒙代尔 1999 诺奖）
- 1983 Meese-Rogoff：结构模型汇率预测跑不赢随机游走——
  40 年之谜
- 1997 亚洲金融危机（三元悖论+原罪论）；2010 欧债（货币联盟
  无财政联盟）；2008 后央行互换额度补位"世界央行"

## 这支最美的一个事实（一句）

不可能三角：汇率稳定、资本自由流动、货币政策独立——**三个目标
最多同时要两个**；香港选联汇+资本自由（让渡利率独立），大陆
汇率管理+利率独立（管资本账户），各有各的账。

## 假设与依赖

读本支需宏观基础（利率、总需求）；假设：利率平价与无套利成立
（短期最硬）、平价理论是长期引力而非短期轨道。
