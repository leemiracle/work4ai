# 讲透经济地理学 · 为什么经济活动不肯均匀铺在地图上

> 经济地理学：**距离不是背景板，是主角**——运输成本、地租与集聚力量
> 把工厂、人口与城市压成今天这幅极不均匀的地图，并解释为什么不均匀反而高效。
> GB/T 13745 二级学科 79019（经济地理学）。

## 定位声明（本家族怎么读）

本宇宙多数家族问"什么决定价格、增长、分配"；本家族问"什么决定**位置**"——
为什么芯片厂挤在一起、为什么硅谷是硅谷、为什么"距离已死"的预言三次落空。

## 诞生（四个原生问题）

| 问题 | 年代 | 结局 |
|---|---|---|
| 同样的土地，为什么离城近的种菜、远郊放牧？ | 1826 | 冯·杜能《孤立国》：竞租→同心圈层 |
| 工厂该靠原料地、靠市场、还是居中？ | 1909 | 韦伯《工业区位论》：最小运费区位三角 |
| 为什么小城围绕大城、大城隔空排队？ | 1933 | 克里斯塔勒《中心地原理》：六边形市场区与等级 |
| 报酬递增时代，制造业为何会"突发"扎堆一处？ | 1991 | 克鲁格曼核心-外围模型（JPE，2008 诺奖） |

## 核心问题清单（详 00 章）

已解决里程碑：杜能圈层（1826）· 韦伯区位三角（1909）· 中心地体系（1933）·
阿隆索城市竞租（1964）· Starrett 空间不可能定理（1978）· 核心-外围模型（1991）。
悬而未决：远程办公是否终结集聚红利 · Zipf 位序-规模律的成因 ·
中国"大国大城"与区域均衡之争 · 友岸外包的效率代价。

## 假设与代价

本家族假设：**运输成本可以折算成钱、距离可以折算成成本**。买到一维可解的模型
（距离成了空间问题的唯一语法）；付出维度坍缩（制度、文化、边界被压成运费系数）。
