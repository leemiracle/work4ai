# 04 · 经济地理学转代码：地图问题的三条代码走廊

> **本章回答五问之五（本支：讲透经济地理学）。**
> ①本质一句话：本家族可机械化的核心是三类计算——**网格求解**（竞租/区位）、
> **对数回归**（引力/位序律）、**智能体模拟**（集聚/迁移）；不能机械化的
> 是制度与历史，只能作为参数请回方程。

---

## 一、可机械化边界（为什么是这样）

| 能交给代码 | 不能交给代码 |
|---|---|
| 竞租上包络、圈层重构（凸问题，argmax 即解） | 制度细节（土地财政、户籍）如何变成运费系数 |
| 引力模型回归、位序律拟合（对数线性） | 历史锁定：哪条路径依赖链被触发 |
| 核心-外围分岔扫描（参数→均衡分支图） | 均衡选择：多重均衡中"哪一个"实现 |
| 选址优化（p-median，NP-hard 但可启发式） | 政治可行性的空间分布 |

边界的哲学：模型算"给定规则下的必然"，规则本身（制度）是外生的——
**代码走廊走得再深，也走不进立法过程**。

## 二、走廊①：竞租求解器（本家族实验）

[杜能实验](experiments/thunen_bidrent.py)的核心只三行——竞租曲线族取上包络：

```python
x = np.arange(0, 1300, 0.1)                         # 距离网格
R = np.vstack([N - T*scale*x for _, N, T in USES])  # 竞租曲线族
ring, rent = R.argmax(axis=0), R.max(axis=0)        # 圈层=argmax，地租=上包络
```

值得亲历的扩展：把 `scale` 换成距离的函数（拥堵使近郊运费非线性），
圈层会扭曲变形——高速公路出口就是人为的"低 scale 洞"。

## 三、走廊②：引力模型回归（可跑最小例）

**直觉**：两地流量像万有引力——质量（经济体量）相乘、距离相除。
**陈述**：log F_ij = α + b₁·log Y_i + b₂·log E_j + b₃·log d_ij + ε。

```python
X = np.column_stack([np.ones(n), np.log(Yi), np.log(Ej), np.log(dij)])
beta, *_ = np.linalg.lstsq(X, np.log(F), rcond=None)
# 经验律：b₃ ≈ −1（距离翻倍，流量减半）；跨国回归加"边界哑变量"
```

最小例（三城，自造流量 F_ij = Yi·Ej/dij，验证估计器找回 b₃=−1）：

| 起讫 | Y_i | E_j | d_ij | F_ij |
|---|---|---|---|---|
| A→B | 1000 | 600 | 50 | 12000 |
| A→C | 1000 | 400 | 100 | 4000 |
| B→C | 600 | 400 | 60 | 4000 |

对数化后三行数据完美共线地满足方程——`lstsq` 返回 (0, 1, 1, −1)。
现实数据加噪声与边界哑变量后，b₃ 仍稳定落在 −0.8 至 −1.2；
美加边界的等效距离达数千公里（McCallum 1988）——**边界是最贵的"距离"**。
深入空间计量（Moran's I、SAR/SEM）用 pysal 生态；
回归理论母学科→[讲透数学/讲透统计学习理论](../../讲透数学/讲透统计学习理论/)。

## 四、走廊③：空间大数据——手机信令重建城市体系

匿名手机信令（通话/位置记录）给出亿级个体的日移动；聚合后不需任何先验假设，
就能从流量矩阵里"长出"中心地等级：功能区域=流量社区，中心性=节点强度。
英国、法国等国的重建结果与克里斯塔勒式等级高度吻合——
**1933 年的六边形猜想，被 21 世纪的数据自动画了出来**。同一技术栈服务于：
通勤圈划定、都市区界定（替代陈旧行政区口径）、灾害人流监测。
工程落点：GeoAI 与矢量瓦片在[计算机宇宙](../../讲透计算机科学技术/)；
隐私边界（k-匿名、差分隐私）是这条走廊的限速牌。

## 五、✨美之时刻（⑧之三）：数据自己长出等级

**陈述**：不告诉算法任何"城市等级"定义，只给它一国的匿名移动流，
社区发现算法划分出的区域体系与百年中心地理论预测的等级嵌套惊人一致。
**为什么美**：*意外*——理论在 1933 年从想象力出发，数据在 2020 年代
独立抵达同一形状；两列火车从不同车站开出，在同一隧道贯通。
**怎么亲历**：取公开通勤矩阵跑一轮 community detection（networkx 一行
`greedy_modularity_communities`），把模块度最高的划分画上地图，
与该国城市体系图并排。

## 六、反直觉发现（⑥）

**修路模拟的反弹**：在区位模型里加一条新路，交通量增长常超过通行能力增量
（诱导需求）——运费下降→新区位可达→新流量诞生。这与[讲透环境经济学](../讲透环境经济学/)
的回弹效应（rebound effect）同构：**矫正一个价格，行为会从别处长回来**。
做政策模拟时不给模型装上行为反馈，等于给地图装了不会转的指针。

## 七、数据源与可复现

| 数据 | 用途 | 入口 |
|---|---|---|
| 人口普查（七普/US Census） | 城市体系、位序律 | 公共统计年鉴 |
| 卫星夜间灯光 | 无统计地区的经济活动代理 | NASA/珞珈卫星产品 |
| 匿名手机信令 | 通勤圈、中心地重建 | 合规运营商脱敏产品 |
| 企业注册/招聘大数据 | 产业集聚动态 | 商业数据库 |

可复现三原则：口径先行（市辖区/都市区声明）、随机种子固定、
地图与回归表同发——空间结论离开口径就是孤儿。
