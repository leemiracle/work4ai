# 讲透区位论 · 给定运费与市场，最优位置在哪

> **定位**：这支负责经济地理学的古典骨架——冯·杜能（农业圈层）、韦伯（工业区位）、
> 克里斯塔勒与廖什（中心地与市场网）四大解，把"选址"变成最优化问题。
> 自定主干支（GB/T 79019 无三级明细）。

## 诞生

1826 年冯·杜能经营梅克伦堡庄园四十年，从账本中剥出"位置地租"；
1909 年韦伯《工业区位论》用区位三角与等费线（isodapanes）给出工业版；
1933 年克里斯塔勒用六边形市场区解释德国南部的城镇等级；
1940 年廖什《区域经济学》把静态等级换成利润最大化的需求侧市场网。

## 核心问题（3-5 条）

- ✅ 已解：竞租与农业圈层（杜能 1826）——土地同质也产生完整地租理论
- ✅ 已解：区位三角与总运费最小点（韦伯 1909）——选址变成可计算问题
- ✅ 已解：中心地等级与 k=3/4/7 体系（克里斯塔勒 1933）——市场、交通、行政三原则
- 🔄 前线：多设施推广（p-median 与覆盖问题，NP-hard，交给运筹学与启发式）
- ❌ 未解：制度与文化区位（关税、语言、信任）的统一模型——友岸外包正在倒逼这门课

## ✨这支最美的一个事实

完全相同的平原上，仅因"离市场的远近"就长出环带——**地租不需要土地差异，
位置差异就够了**。李嘉图与杜能各执地租理论的一半：土质与位置。

## 假设与依赖

单一市场、运费与距离成线性、土地同质是古典四解的共同地基；
修路或冷链（改运费 T）瞬间改写圈层边界——假设不是装饰，是政策杠杆。
