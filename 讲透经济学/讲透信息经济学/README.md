# 讲透信息经济学 · 知道得不一样，市场就不是那个市场

> 信息经济学：**信息不对称的经济后果**——当交易一方比另一方知道得多，
> 价格不再是中性的信号灯，而会反过来改变被交易商品的质量构成。
> 四条主线：柠檬市场（Akerlof 1970）· 信号（Spence 1973）· 筛选（Rothschild–Stiglitz 1976）·
> 道德风险与机制设计（Holmström；Hurwicz–Maskin–Myerson）——2001/2007/2016 三届诺奖。

## 定位声明（本家族怎么读）

本家族研究"谁在什么时候知道什么"如何改写一切市场结果。与近邻的划界：
[讲透数学/讲透信息论](../../讲透数学/讲透信息论/)回答"一段信息有多少比特、
传输的极限在哪"——是**度量与传输**的科学；本家族回答"这些信息差异值多少钱、
会把市场变成什么样"——是**经济后果**的科学。比特不等于价值：
一条一比特的"此车是柠檬"足以摧毁整个市场。

## 核心问题清单（详 00 章）

已解决里程碑：逆向选择（1970）· 信号分离均衡（1973）· 筛选合同（1976）·
信息性原则（1979）· 显示原理与最优拍卖（Myerson 1981）· 机制设计诺奖（2007/2016）。
悬而未决：平台声誉系统的长期有效性 · 算法定价默契合谋的法律认定 ·
高维类型空间最优机制的计算复杂性 · 混同均衡不存在性在真实市场的化身。

## 假设与代价

本家族假设：**私有信息不可直接验证，但可被间接诱导**。买到合同与机制的
可执行性（用激励相容替代信任）；付出信息租金（必须给知情者留好处才肯说真话）。
