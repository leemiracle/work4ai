# 讲透信号与筛选 · 好人如何自证、菜单如何分拣

> **定位**：这支负责"信息不对称的正面解法"——知情方用有成本的行动自证
> （信号），或不知情方摆出自选菜单让类型自己站队（筛选）。
> （自定主干支：GB/T 79069 无三级明细）

## 诞生

Spence 1973《Job Market Signaling》：教育哪怕不提高生产率，只要读书的
成本随能力递减，文凭就能分离强弱——"烧钱"承载信息。三年后
Rothschild–Stiglitz 1976 从另一端进场：保险公司摆出两档合同，让高风险
与低风险投保人自选，并证明混同均衡常常不存在（撇脂必然挖走好客户）。
两人与 Akerlof 分享 2001 年诺奖。

## 核心问题（3-5 条）

- ✅ 已解：分离均衡存在性（Spence 1973；单交叉条件 single crossing）
- ✅ 已解：筛选菜单的最优构造（Mussa–Rosen 1978 二级价格歧视的孪生）
- 🔄 前线：平台担保/退换货/验车作为"商业化的信号"——成本差设计的产业实践
- ❌ 未解：信号的社会成本核算——Spence 世界里"浪费的教育"何时过度投资
- ❌ 未解：多维类型下的菜单爆炸——维度灾难使最优菜单不可列

## ✨这支最美的一个事实

无效率的行动可以创造效率：教育不生产任何东西，仅因"聪明人读得便宜"
就让市场完成分拣——社会烧掉时间买回配置。浪费与价值在同一份文凭上并存。

## 假设与依赖

单交叉条件（不同类型的无差异曲线只交叉一次——分离的技术前提）；
信号成本的类型依赖性。依赖[博弈论](../../../讲透数学/讲透博弈论/)的
精炼贝叶斯均衡；菜单构造与[讲透数学/讲透优化](../../../讲透数学/讲透优化/)同型。
