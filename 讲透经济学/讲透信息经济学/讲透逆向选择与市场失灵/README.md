# 讲透逆向选择与市场失灵 · 价格如何赶走好东西

> **定位**：这支负责"签约前的隐藏信息如何让市场萎缩、塌缩甚至消失"——
> 柠檬市场、保险死亡螺旋、信贷配给，同一台发动机的三次点火。
> （自定主干支：GB/T 79069 无三级明细）

## 诞生

1970 年 Akerlof 在 QJE 发表《The Market for "Lemons"》：二手车市场上
买方按平均质量出价，价格越低在场车越酸，直到好车全体退场、市场消失。
论文三次被拒，审稿人断言"若此文为真，经济学早该不存在"——2001 年诺奖。

## 核心问题（3-5 条）

- ✅ 已解：市场整体不存在的数理条件（Akerlof 1970）；逆向选择均衡的构造
- ✅ 已解：信贷配给（Stiglitz–Weiss 1981）——利率本身吓跑好借款人
- 🔄 前线：ACA 罚款归零后市场为何未死——强制/补贴/风险调剂的分工核算（2024 一批论文）
- 🔄 前线：逆向选择解释保险市场集中（"非自然垄断"，FTC 2024）
- ❌ 未解：平台信息聚合后的"残余"逆向选择（跳单、信息泄露定价）

## ✨这支最美的一个事实

消除逆向选择不需要消除信息不对称——只需要让"留下"变得对好类型有利：
一个预算平衡的交叉补贴就能把柠檬专场变回全信息市场
（见家族实验 [`experiments/lemons.py`](../experiments/lemons.py) 幕 C）。

## 假设与依赖

买方理性按条件期望出价；质量不可被第三方验证（若可验证则退化为分级市场）。
依赖微观经济学的供求框架与[博弈论](../../../讲透数学/讲透博弈论/)的均衡概念。
