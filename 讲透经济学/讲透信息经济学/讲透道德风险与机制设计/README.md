# 讲透道德风险与机制设计 · 看不见的努力与写得出的规则

> **定位**：这支负责"签约后的隐藏行动"——偷懒、过度医疗、冒进交易——
> 以及它的总解法：把诚实与努力**编译进规则**（机制设计）。
> （自定主干支：GB/T 79069 无三级明细）

## 诞生

Holmström 1979 信息性原则：薪酬该挂什么指标？答案——任何与努力相关、
又不受噪音污染的可观察量；与努力无关的指标挂了只添风险。机制设计一线
由 Hurwicz 开创（激励相容概念的奠基），Maskin（执行理论）与
Myerson（显示原理、最优拍卖）完成体系，三人获 2007 年诺奖；
Hart–Holmström 以合同理论再获 2016 年诺奖。

## 核心问题（3-5 条）

- ✅ 已解：信息性原则（1979）——指标进合同的充分条件
- ✅ 已解：显示原理与最优拍卖（Myerson 1981）；VCG 让说真话成为占优策略
- 🔄 前线：算法定价代理的默契合谋——独立机制却收敛超竞争价格（法律认定悬而未决）
- 🔄 前线：数据市场的披露悖论——卖方一亮货就失去货（信息商品的最优售卖机制）
- ❌ 未解：高维类型空间最优机制的计算复杂性；动态机制下的承诺问题

## ✨这支最美的一个事实

显示原理：任何规则、任何沟通协议，都等价于一个"直接报类型"的机制——
说谎在其中自动成为劣策略。一段几乎显然的构造，把无限大的规则空间
压缩成可计算的菜单空间，整个学科从此变成工程学。

## 假设与依赖

委托人可承诺并执行合同（法庭可验证性）；参与人理性。机制设计本质是
[博弈论](../../../讲透数学/讲透博弈论/)的规则设计层——"设计规则"而非
"在给定规则下求均衡"；工程落地见[计算机宇宙](../../../讲透计算机科学技术/)
的广告拍卖与平台规则。
