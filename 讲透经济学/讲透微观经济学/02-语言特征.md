# 02 · 语言特征：最优化语言、对偶语言与价格的三重身份

> **本章回答五问之三（本家族：讲透微观经济学；宇宙任务书要求写深）。**
> 微观的母语是**最优化语言**（偏好+约束→选择），它的高阶语法是
> **对偶语言**（同一选择问题有两种问法，两种答案互相翻译），
> 它的核心词"价格"身兼三职：**比率、信号、乘子（影子价格）**。
> 本章还有第二个任务：把微观的模型语言与企业的制度叙述
> （成本加成、KPI、预算）对表——**微观是最接近企业管理话语的经济学，
> 也是翻译损耗最隐蔽的地方**。

---

## 一、表达力：三种语言及其互译

### 1.1 最优化语言：一个句型的万次复用

微观的每个理论构件都是同一个句型填空：

```
max  目标（效用/利润/社会福利）
s.t. 约束（预算/技术/信息/激励）
⟹    一阶条件 = 行为方程
```

**为什么这个句型如此霸道**：一阶条件天然给出"边际相等"——
消费者：MRS=价格比；生产者：MP_L/w=MP_K/r；社会福利：MSB=MSC。
**微观的全部政策建议都是同一句话：让边际收益等于边际成本**。
（数学母港：[讲透数学·讲透优化](../../讲透数学/讲透优化/)
——拉格朗日、KKT、对偶，微观是它们的最大用户。）

### 1.2 对偶语言：两个问题，一个答案

| 原问题 | 对偶问题 | 输出 |
|--------|---------|------|
| 效用最大化：max u(x) s.t. p·x≤m | 支出最小化：min p·x s.t. u(x)≥u | Marshall 需求 x(p,m) ↔ Hicks 需求 h(p,u)，间接效用 v(p,m) ↔ 支出函数 e(p,u) |
| 成本最小化（给定产出） | 产出最大化（给定成本） | 条件要素需求 ↔ 条件产出供给 |
| 生产者利润最大化 | 消费者支出最小化（一般均衡的两侧） | 供给 ↔ 需求 |

**为什么对偶不只是数学杂技**：
- **恒等式 e(p, v(p,m)) = m** 是两种语言互相翻译的字典；
- **Slutsky 方程 = 字典的微分版**（00 章美之时刻的另一种读法）；
- **谢泼德引理/罗伊恒等式**（对偶问题对参数求导直接得需求）让实证
  需求系统（AIDS、CES 族）成为可能——**对偶语言是微观计量的语法基础**。

### 1.3 价格的三重身份：一词三义的精确拆分

| 身份 | 语言位置 | 例 |
|------|---------|---|
| 比率（相对价格） | 交换比率：MRS、边际转换率 | "一小时的闲暇值三杯咖啡" |
| 信号（信息载体） | 哈耶克电报：加总分散信息 | "牛肉涨价=某处牛肉更稀缺了" |
| 乘子（影子价格） | 约束的拉格朗日乘子 λ：放松约束值多少 | 预算放宽一元，效用升 λ；排队一小时的机会成本 |

**为什么要拆**：三职常常冲突。计划经济试图保留"比率"（核算工具）
而砍掉"信号"（市场试错）——兰格-勒纳的模拟市场方案；信息经济学
研究"信号"失真（不对称信息）；环境经济学用"乘子"重新定价
（影子价格法估生态服务）。**任何现实定价制度=三职的某次组合取舍**。

✨ **美之时刻 ①：拉格朗日乘子的经济学读法**
陈述：max u(x) s.t. p·x≤m 的乘子 λ=\*∂v/∂m\*——收入放宽一元的边际效用。
为什么美：**必然+统一**——同一个 λ 在企业问题里是"预算放宽一元的利润"，
在宏观里是"流动性约束的影子价格"（HANK 的核心对象），在工程里是
"缓存放宽 1MB 的吞吐"。对偶变量=约束的价值，这是最优化语言
送给一切学科的标准礼物。
怎么亲历：跑 [讲透数学·讲透优化](../../讲透数学/讲透优化/) 的对偶章节任一例，
读出乘子并解释它"是多少钱"。

## 二、模型语言 vs 制度叙述：微观的翻译现场

微观是离企业话语最近的经济学——也因此翻译最频繁、损耗最隐蔽：

| 企业话语（制度叙述） | 模型语言 | 翻译损耗 |
|---------------------|---------|---------|
| "成本加成定价：成本上浮 20%" | P=MC·(1+markup)，markup=ε/(ε−1) | 模型说加成由需求弹性定；企业说由公平感定——两者在垄断竞争下可以兼容，但"谁决定谁"颠倒 |
| "预算是我们自己定的" | 预算约束=硬约束 | 企业内部预算是**软的**（可追加）——软预算约束（科尔奈）是计划企业的微观宪法，见 [社会主义微观支](讲透社会主义微观经济学/) |
| "KPI 驱动" | 委托-代理：激励合同 | KPI=可_contract化的产出子集；不可测维度被系统性牺牲（古德哈特定律：指标成为目标就不再是好指标） |
| "客户至上" | 消费者剩余最大化 ≠ 利润最大化 | 价格歧视的语言：企业想"占有"剩余而非"创造"它 |

📖 **故事框：古德哈特定律——指标语言的自我拆台**
"当测量变成目标，它就不再是好测量。"（古德哈特 1975，针对货币目标；
Strathern 1997 推广为一般形式。）模型语言版本：代理人对指标的反应
进入行为方程，指标与目标的相关性内生于激励强度——**这是一条
可以证明的定理，不是鸡汤**。微软 Stack Ranking、苏联 GDP 均值化指标，
同一条定律的三次执行。

**翻译的元规则**：从制度叙述译入模型语言时，**每个名词都要找到
它的"约束或偏好"位置**（它是预算的一部分吗？偏好参数？还是均衡
结果？）；找不到位置的词（"文化""信任"）要么造新变量（社会资本），
要么承认在模型之外——**翻译的诚实=标注不可译词**。

## 三、逻辑性质：微观语言的公理文化

### 3.1 三层逻辑结构

1. **公理层**：偏好公理（完备/传递/连续/凸）+ 技术公理（生产集凸性/
   自由处置）——欧氏几何式的开局（Debreu《价值理论》是美学巅峰）
2. **定理层**：表示定理（偏好⟹效用）、存在性（均衡=不动点）、
   福利两定理、StSlutsky——**微观是经济学里定理密度最高的分支**
3. **可检验层**：显示偏好（偏好不可见，选择可见——Samuelson 1938
   把形而上学问题变成数据问题；Afriat 1967 给出可检验条件，03 章）

### 3.2 说不了的（表达力边界）

| 说不了一 | 原因 | 谁能说 |
|---------|------|--------|
| 偏好从哪来 | 偏好是外生输入（广告/文化塑造被挤出） | 行为经济学/社会学（收编中） |
| 均衡如何到达 | tatonnement 是虚构，调整过程非本语言对象 | 演化经济学、实验经济学 |
| 权力 | 除市场势力外无词 | 政治经济学（[本宇宙](../讲透政治经济学/)） |
| 幸福与效用 | 效用=选择的排序，非心理福祉 | 幸福经济学（补丁） |

### 3.3 规范化台阶

| 级 | 内容 | 代表 |
|----|------|------|
| 1 叙述层 | 斯密的道德语言+例子 | 1776 |
| 2 图形层 | 马歇尔剪刀、无差异图 | 1890 |
| 3 公理层 | 偏好公理+存在性+福利定理 | 1939-1959 |
| 4 数据层 | 显示偏好/Afriat/结构估计 | 1938-1967- |
| 5 机制层 | 机制设计与计算市场（表达=算法） | 1960-2020s |

## 四、Python 层：语言的形态决定代码的形态

```python
# 最优化语言 → 求解器调用（scipy.optimize / cvxpy）
# 对偶语言 → 同一问题的第二个求解入口 + 乘子读取（shadow price）
# 价格三职 → 三种代码对象：ratio(数组)、signal(均衡解)、multiplier(λ 字段)
# 制度叙述 → 参数化假名（markup_from_survey=0.2 # "成本加成20%"，注明来源）
```

本家族实验 [supply_demand_surplus.py](experiments/supply_demand_surplus.py)
把"价格=均衡解"（数值求根 vs 解析）与"剩余=积分"（福利语言）做成
断言对——语言的每个断言都能代码化，是微观可检验文化的直接体现。

## 五、不足层

- 对偶语言在企业实务中几乎不存在（企业用成本语言不用对偶语言）——
  学术微观与实务微观是两种方言，教材很少正面处理
- "偏好外生"在数字时代越来越难维持（推荐系统在写偏好）——
  内生偏好理论仍是边陲
- 价格三职的冲突（如管制想要比率之稳定却杀信号之功能）缺乏
  一般理论——制度设计在逐案处理

## 👁 这章给了你什么新眼睛（认知升维）

- **看见乘子**：任何"约束的影子价格"——排队时间、碳配额、GPU 显存——
  都可以问"放松它值多少"；对偶思维是资源配置问题的万能第二问
- **翻译要标注不可译词**：把管理话语/政策话语译成模型时，
  诚实的方法是把没位置的概念显式列出——模型的边界比模型的内容更重要
- **指标即激励**：看到任何 KPI 先想古德哈特——反应函数会移动，
  这是微观版的卢卡斯批判（[宏观 03 章](../讲透宏观经济学/03-可构造与结构.md)）
