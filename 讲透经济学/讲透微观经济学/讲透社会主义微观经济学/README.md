# 讲透社会主义微观经济学 · 激励设计主线

> 这支负责：**"公有制与计划语境下微观激励如何设计"的理论线**——
> 从兰格的模拟市场之问、科尔奈的批判、到激励理论与机制设计时代的
> 国企改革与公有制实现形式。GB/T 79015 三级之一；GB/T 原名"社会主义微观经济学"。
> 现代形态：它越来越多地与西方支共享母港（赫维茨-马斯金的机制设计）。

## 诞生

1936/1938 兰格《社会主义经济理论》——"试错模拟市场"回应米塞斯-哈耶克
"计划不可能"论战（家族 [比较经济学 00 章](../../讲透比较经济学/00-体系结构.md)
的源头战役）→ 1940s-70s 苏东企业行为研究积累 → 1980 科尔奈《短缺经济学》
（软预算约束——社会主义企业的微观宪法）→ 1970s-90s 激励理论起飞
（赫维茨机制设计、莫里斯-霍姆斯特朗委托代理）与中国国企改革实践
（放权让利→承包制→股份制→混改）互喂 → 2000s- 公有制实现形式与
国企治理的持续实验。

## 核心问题

| 问题 | 状态 |
|------|------|
| 计划的信息与激励双重不可能（Hayek 1945/Hurwicz 1960s） | ✅ 定理化（机制设计视角） |
| 软预算约束综合征（科尔奈 1980/1986） | ✅ 概念定型；博弈论化（Dewatripont-Maskin 1995） |
| 公有制+市场经济的激励相容（国企效率） | 🔄 世界最大政策实验室，结论分期 |
| 混合所有制的治理结构设计 | 🔄 前线（与公司治理学共管） |
| 经理人市场的替代机制（政治锦标赛等） | 🔄 实证活跃 |

## ✨ 这支最美的一个事实

**软预算约束**：预期到亏损会被救助的企业，行为方程永久改变——
不害怕破产的"预算"不是约束。Dewatripont-Maskin 1995 把它形式化为
**信贷集中度的函数**：银行越多、再谈判越难，预算越"硬"——
一个原生于社会主义企业的概念，预言了 2008 年"大而不倒"（too big
to fail）：**西方巨头的预算也软了**。概念出口转内销，如今是
分析一切"救助预期"的通用工具。

## 假设与代价

公有产权的激励结构可以再设计（经营权/收益权/转让权的组合空间）——
买到：超越"私有化单变量"的改革工具箱；付出：每一层安排都需要
配套的监督与竞争条件（无市场则监督者无人监督，无竞争则指标失真——
古德哈特定律的计划版，家族 [02 章](../02-语言特征.md) 故事框）。

## 教材锚

科尔奈《短缺经济学》（1980，社会主义微观的解剖正典）、《社会主义体制》；
林毅夫等《中国的奇迹》（比较优势战略的微观叙事）；
张维迎《企业理论与中国企业改革》；Laffont & Martimort《激励理论》
（数学母港正典）。
