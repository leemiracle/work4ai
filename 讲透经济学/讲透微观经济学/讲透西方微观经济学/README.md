# 讲透西方微观经济学 · 价格机制主线

> 这支负责：**"价格如何协调"的标准理论线**——边际革命、四大板块
> （消费者/生产者/市场均衡/失灵规制，家族 [00 章](../00-体系结构.md)）与
> 博弈、信息两次扩容。GB/T 79015 三级之一；GB/T 原名"西方微观经济学"。

## 诞生

1871-1874 边际革命三杰（杰文斯《政治经济学理论》/门格尔《国民经济学
原理》/瓦尔拉斯《纯粹经济学要义》——三人互相不知，同时出手）→
1890 马歇尔定型局部均衡 → 1939/1947 希克斯-萨缪尔森公理化 →
1954 阿罗-德布鲁一般均衡存在性+福利两定理 → 1950 纳什均衡 →
1970 阿克洛夫柠檬市场（信息革命发令枪）。

## ✨ 这支最美的一个事实

**价格用一维向量压缩了全社会的分散知识**（哈耶克 1945）——没有中央
数据库，但任何人想要牛肉的信息都已经在牛肉价格里。阿罗-德布鲁随后
证明这套压缩系统在数学上自洽存在：**自利+价格=协调** 从修辞变成了定理。

## 假设与代价

理性偏好（买到效用函数，付认知失真账）、凸性（买到微分法，付掉
网络规模报酬）、价格接受（买到供需曲线，付掉"谁定价"之问）、
完全信息或贝叶斯结构（买到均衡定义，付掉信息不对称的半个世界——
靠信息经济学分支赎回）。全表见家族 README §三。
