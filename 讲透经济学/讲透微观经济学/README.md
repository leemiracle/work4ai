# 讲透微观经济学 · 选择与市场：价格如何协调千万个体

> **微观经济学 = 个体选择与市场协调的学问**——消费者如何在约束下选、
> 企业如何在技术下产、价格如何把这两头拧成均衡、均衡何时是好的。
> 它的核心赌注是一句话：**不需要任何人看见全局，分散决策经由价格
> 就能达成协调**（哈耶克 1945 的"知识问题"是它的灵魂）。

## 一、诞生

微观有三次诞生时刻：

1. **1870s 边际革命**——杰文斯（英）、门格尔（奥）、瓦尔拉斯（法/瑞士洛桑）
   三人几乎同时独立提出边际效用价值论：价值不在劳动里在边际上。
   古诺（1838）与戈森（1854）是被遗忘的先知。
2. **1890/1947 两次公理化**——马歇尔《经济学原理》定型局部均衡
   （供给-需求剪刀、消费者剩余）；希克斯《价值与资本》(1939) 与
   萨缪尔森《经济分析基础》(1947) 把偏好→效用→需求做成公理系统；
   阿罗-德布鲁 (1954) 证明一般均衡存在性（02/03 章主角）。
3. **1950/1970 两次扩容**——纳什 (1950) 均衡概念把策略互动纳入；
   阿克洛夫 (1970"柠檬市场")、斯宾塞 (1973 信号)、斯蒂格利茨 (1976 筛选)
   把信息不对称纳入——"价格协调"的适用边界被精确测绘。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 看不见的手：自利+价格 ⟶ 帕累托效率 | ✅ 已证（福利两定理，Arrow-Debreu 体系） | 经济学最重要的一条定理——市场协调的可能性被数学证明 |
| 一般均衡的存在与唯一性 | ✅存在/⚠️唯一性弱 | 存在=不动点；唯一性常常失败（多重均衡是常态） |
| 市场失灵的完整分类 | ✅ 框架成熟 | 外部性/公共品/信息不对称/市场势力——第一定理的四类反例 |
| 需求的可检验性 | ✅ 已解 | 显示偏好（Samuelson 1938）+ Afriat (1967)：从数据重构并检验理性 |
| 策略环境下的均衡选择 | 🔄 永恒前线 | 博弈多重均衡的精炼史（[讲透数学·讲透博弈论](../../讲透数学/讲透博弈论/)） |
| 行为偏离何时毁灭模型 | 🔄 前线 | 行为经济学 40 年：哪些反例是尘埃、哪些是地震（01 章） |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 理性偏好（完备+传递） | 效用函数存在（Debreu 表示定理） | 跨时选择/框架效应处系统性失效 |
| 凸性与连续性 | 内点解、微分法可用、二阶福利定理 | 规模报酬递增（网络/平台）被挤到模型边缘 |
| 价格接受（完全竞争） | 供需曲线、福利定理 | 谁定价格？——瓦尔拉斯拍卖师是虚构（03 章） |
| 完全信息（或贝叶斯结构） | 均衡可定义 | 信息不对称是常态；信息经济学是"赎罪分支" |
| 代表性个体（教科书层） | 图好画、课好教 | 分布与加总问题全部隐形（与宏观同病） |
