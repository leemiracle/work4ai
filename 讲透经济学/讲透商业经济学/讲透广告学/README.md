# 讲透广告学 · 注意力的买与卖

> **定位**：这支负责广告这门生意的经济学与传播学双重身份——它买什么
> （注意力/信任）、卖什么（信号/说服）、怎样计价（CPM/CPC/CPA 的
> 定价结构革命）。GB/T 三级"广告学"落位于此。

## 诞生

现代广告业随大众报刊起（19 世纪末版面经纪），1920s 广播、1950s 电视
造就黄金时代；1960s"创意革命"（伯恩巴克）确立创意产业身份。经济学的
两次入题：Nelson 1970/74（搜索品/体验品与广告的信息理论）、
Milgrom-Roberts 1986（烧钱=质量信号）。2010s 程序化广告把版面变成
实时拍卖（RTB），广告学从此同时是传播学、经济学与计算机科学的交叉地。

## 核心问题（3-5 条）

- ✅ 已解：广告的信息与信号二分（体验品广告"越浪费越可信"——家族
  [02 章](../02-语言特征.md)反直觉发现）
- ✅ 已解：程序化拍卖的定价机制（二价拍卖/GSP——搜索广告的引擎，
  与[讲透数学·讲透博弈论](../../../讲透数学/讲透博弈论/)共管）
- 🔄 前线：归因革命（点击归因→增量实验，A/B holdout 成黄金标准）
- 🔄 前线：内容化与直播（广告与内容的边界溶解——信息流原生广告）
- ❌ 未解：广告的宏观效果（总量上广告是抢夺份额还是扩大市场——
  百年争论无共识）

## ✨这支最美的一个事实

电视台黄金时段广告位用**二价/多价位拍卖**卖出、搜索引擎用 GSP、
程序化用 RTB 实时竞价——广告业在不知不觉间完成了人类最大规模的
**市场机制工程**：每天几十亿次、毫秒级的拍卖，定价的是"一个 eyeball
此刻的价值"。经济学家设计机制（Vickrey 传统），工程师浇筑管道，
广告主出钱读数——三方的合作品比大多数央行更市场。

## 假设与依赖

注意力稀缺且可交易（本支第一假设）；广告主的预算在渠道间可自由流动
（归因与比价的技术前提）；受众不厌恶到反制（广告拦截器是需求端的
否决票）。

## 教材锚

- Nelson (1970/1974) 原典（信息与信号理论）
- 《广告狂人》之外的学术标准件：O'Guinn 等《Advertising and Society》
- Varian 系（拍卖与机制设计的广告应用，与博弈论宇宙共管）
