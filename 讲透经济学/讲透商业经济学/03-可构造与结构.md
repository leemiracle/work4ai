# 03 · 可构造与结构：加价、引力、扩散与双边

> **本章回答五问之四（本家族：讲透商业经济学）。**
> 商业经济学有四个高构造度的模型：**双重加价**（纵向结构）、
> **零售引力**（空间结构）、**Bass 扩散**（时间结构）、**双边定价**
> （平台结构）。四个加一个实验，就是本章。

---

## 一、双重加价：纵向链条的税（直觉先行）

直觉：一块钱的加价，经过两家垄断者的手会变成两块——而且比一家垄断
更狠。模型（线性需求 P=100−Q，上游边际成本 20）：

```
一体化：     p=60, Q=40, 利润 1600, 消费者剩余 800, 总福利 2400
双重加价：   w=60（批发）→ p=80（零售）, Q=20
             上游利润 800 + 下游 400 = 1200 < 1600；消费者剩余 200；总福利 1400
两部制费：   w=20（=成本）+ 固定费 1600 → 一体化结果完全恢复
```

**结构三读**：
1. **双重死重损失**：两次加价=两次垄断扭曲叠加，两家总利润反而更低
   （"囚徒的定价"）。
2. **纵向约束的效率理由**：转卖价格维持（RPM）、独家经销、特许费——
   每一种都是消除第二次加价的工具。反垄断从"本身违法"到"合理原则"
   （Leegin 2007）的理论路基。
3. **两部制费=纵向一体化替身**：批发价定成本、利润走固定费——产业组织
   里"价格结构解决激励问题"的第一课（与双边市场、拍卖设计同宗）。
4. **多级链条的推广**：三层垄断=三次加价，扭曲按层数叠乘——特许经营、
   总代分代体系因此天然偏爱"扁平化+两部制"：**渠道层级是可计算的
   税收层级**。

## 二、零售引力模型：空间结构（Reilly 1931 → Huff 1964）

两家购物中心分割中间的城市：**引力与人口成正比、与距离平方成反比**
（牛顿式）。Huff 把它概率化：消费者去店 j 的概率
`P_j = (S_j/T_ij^λ) / Σ_k (S_k/T_ik^λ)`（S=规模，T=路程，λ≈2）。
**结构读法**：选址问题从此可算——新店的客流=引力场叠加的积分。
参数 λ（距离衰减）是行业性格：日常品 λ 大（就近买）、耐用品 λ 小
（愿意跑远路）——**λ 的估计值本身就是一份消费地理学报告**。
今天电商的"搜索排名"是它的赛博版：S=相关性权重、T=翻页成本。

## 三、Bass 扩散：时间结构（1969）

新产品采用人数 `dN/dt = (p + q·N/m)·(m−N)`：p=创新系数（广告拉动的
先锋）、q=模仿系数（口碑带动的大众）、m=市场容量。**结构读法**：
三参数长出 S 曲线——慢起飞、陡峰值、长尾巴；**峰值时点公式
t* = ln(q/p)/(q−p)** 闭式可写。iPhone 与抖音的曲线都是它的后代，
零售商"上新预测"至今仍用。**q>p 是口碑驱动市场、p>q 是广告驱动
市场**——一条公式顺手完成"品牌类型"的诊断分类。

## 四、双边定价：平台结构（Rochet-Tirole 2003）

平台利润 = (p_S − c_S)·N_S + (p_B − c_B)·N_B，两侧需求通过交叉网络
外部性耦合。**结构读法**：价格结构（谁被补贴）由"哪侧更难获取、哪侧
外部性更强"决定，与成本结构无关——**收费站可以倒贴一侧**（游戏平台
补贴玩家、向开发商抽成）。这是"免费"的经济学地基——04 章的
网格扫描会亲眼看着负价格长出来。

## 五、✨美之时刻（⑧要件）：两部制费——用价格结构消灭扭曲

**陈述**：上游收"批发价=边际成本+固定特许费"，双重加价的第二次扭曲
**无中生有地消失**：零售价落回 60、销量回到 40、两家分走 1600。
没有合并、没有监管，只改了一张发票的形状。
**为什么美**：*极简*——机制设计的全部威力浓缩在"两部"二字：变动价
对齐激励（边际），固定费转移剩余（平均）。剃刀-刀片、健身房年卡、
云服务"按量+包月"，全是它的产业后代。**怎么亲历**：本家族实验
[double_marginalization.py](experiments/double_marginalization.py)
第三个断言组——改两个参数，福利曲线弹回一体化水平。

## 六、假设与代价（④要件续）

| 模型 | 关键假设 | 失效现场 |
|------|---------|---------|
| 双重加价 | 上下游均垄断、线性需求 | 竞争零售（第二次加价自动消失）→ RPM 效率理由减弱 |
| Huff 引力 | 出行成本对称、单目的出行 | 目的地聚类（一站式）与多目的出行 |
| Bass 扩散 | 均质人口、单一渠道 | 社交媒体使 p/q 边界模糊、多波产品 |
| 双边定价 | 两侧各归属给定 | 多归属与跳单（side-switching）改写结构选择 |

## 七、反直觉发现（⑥要件汇总）

垄断+垄断比大垄断更糟（但可被一张发票治愈）· 渠道层数=加价层数（扁平化
的数学理由）· 广告烧钱越"浪费"信号越真（02 章）· 补贴一侧是理性定价而非
恶性竞争（本章四）· 成本病的涨价恰是进步的影子（02 章美之时刻）。

## 👁 认知升维（⑨要件）

**结构眼**：商业问题先定位它的坐标——纵向（链条几层）×空间（引力场
形状）×时间（扩散阶段）×平台（几边、谁补贴）。四轴定位后，该用哪个
模型、断言什么、怎么写代码，自动就位。
