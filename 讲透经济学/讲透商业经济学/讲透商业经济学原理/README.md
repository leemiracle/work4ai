# 讲透商业经济学原理 · 交换的功能与交易成本

> **定位**：这支负责商业的"第一性问题"——商人凭什么存在、渠道为什么分层、
> 商品流通靠什么节约。GB/T 三级"商业经济学原理+商品流通经济学"归组于此。

## 诞生

1776 年斯密留下分工-市场之谜；1937 年 Coase《企业的性质》给出钥匙：
**使用市场价格机制本身有成本**（搜索、谈判、履约），中间商出售的就是
降低这些成本的服务。商品流通经济学的中国脉络（纪宝成《贸易经济学》
为代表）把它落地为"流通生产力"叙事：商流/物流/信息流/资金流四流分立。

## 核心问题（3-5 条）

- ✅ 已解：渠道长度由交易成本与组织成本的边际平衡决定（Coase/Williamson）
- ✅ 已解：批发与零售的功能分工（数量桥接 vs 分类桥接——"集中采购、
  分散销售"的对称性）
- ✅ 已解：双重加价与纵向约束的福利分析（家族 [03 章](../03-可构造与结构.md)）
- 🔄 前线：流通成本占 GDP 的分解（"物流贵还是商流贵"的口径之争）
- ❌ 未解：数字平台时代"渠道"概念本身的存续（当渠道变成市场）

## ✨这支最美的一个事实

批发商做的事情在数学上是一个**整形变换**：把少品种大批量（工厂输出）
变成多品种小批量（商店输入）——教科书叫"集中与分散的对称操作"。
一个看似卑微的搬运环节，实际是供应链上唯一的"品种×数量"矩阵变换器。
没有批发，每家小店都要跟每家工厂谈一遍。

## 假设与依赖

交易成本存在且可比较（理论强、测量弱）；信息不完全但可被中介改善
（平台评价系统的前提）。若信息与匹配成本趋零（理想互联网），本支的
一半定理失效——另一半（履约与信任）反而更值钱。
