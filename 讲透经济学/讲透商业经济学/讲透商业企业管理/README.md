# 讲透商业企业管理 · 零售业态与商品经营

> **定位**：这支负责"把店开好"的学问——业态选择、商品组合（品类管理）、
> 供应链与门店运营、自有品牌。GB/T 三级"商业企业管理学+商品学（含商品
> 包装与技术）"归组于此。

## 诞生

零售管理的现代化以三次管理革命为节点：1916 年自助服务（Piggly Wiggly，
把劳动换成顾客时间）；1960-80 年代品类管理+条码（POS 数据让货架成为
可优化对象）；1990 年代供应链协同（宝洁-沃尔玛的连续补货，EDI 时代）。
商品学一脉（商品质量与包装技术）是德日商业教育的传统科目，
中国商业院校至今保留。

## 核心问题（3-5 条）

- ✅ 已解：业态定位=毛利率×周转×履约成本的组合选择（家族 [00 章](../00-体系结构.md)
  四波革命表）
- ✅ 已解：品类管理的经济学（货架是稀缺资源——每米的毛利贡献×周转
  是分配律；长尾 SKU 靠周转率豁免）
- ✅ 已解：自有品牌的纵向逻辑（后向一体化消除双重加价——家族 [03 章](../03-可构造与结构.md)）
- 🔄 前线：全渠道（线上下单门店发货）的库存归属与成本分摊
- ❌ 未解：门店体验的定价（"逛"的产出如何进入损益表）

## ✨这支最美的一个事实

货架每一米的租金、人工与机会成本，最终会逼问每一个 SKU：**你的
"每米毛利×周转"及格吗？** 这一条冷冰冰的乘法淘汰了无数情怀商品，
也解释了为什么便利店SKU≈3000、会员店≈4000、大卖场≈20000 却各有其理
——**业态就是密度的选择**，密度就是那条乘法的解。

## 假设与依赖

POS 数据反映真实需求（缺货与压货都会污染它——需与库存数据联读）；
商品质量可标准化（商品学的技术前提：检验、分级、包装规范）。
