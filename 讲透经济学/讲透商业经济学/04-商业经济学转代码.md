# 04 · 商业经济学转代码：渠道、场、波与边的施工图

> **本章回答五问之五（本家族：讲透商业经济学）。**
> 三件套：**可机械化边界**、**代码走廊**、**工程师落点**。
> 商业经济的四个结构（加价/引力/扩散/双边）都是小而美的模型——
> 代码化的难点从来不是算，而是**估参数**。

---

## 一、可机械化边界（为什么边界画在这里）

| 问题类 | 可机械化程度 | 边界原因 |
|--------|-------------|---------|
| 双重加价/两部制费 | ✅ 完全 | 闭式，微积分几行 |
| Huff 引力客流预测 | ✅ 完全 | 公式直算；λ 标定需数据 |
| Bass 扩散拟合与峰值预测 | ✅ 完全 | 三参数非线性最小二乘 |
| 双边平台定价仿真 | 🟡 半机械 | 均衡解需迭代；参数（外部性强度）难估 |
| 价格弹性/促销响应 | 🟡 计量+ML | 因果识别（同期混杂）是主战场 |
| 业态生命周期预测 | ❌ 尚未 | 结构断点由外生冲击决定，无内生动 |
| 广告预算-销售因果 | ❌ 尚未 | 媒体混杂+长期效应，识别未解 |

**判据一句话**：结构闭式（微积分）→直接算；参数存在（弹性/扩散系数）
→数据喂；结构本身会变（业态/心智）→只有事后解释权。

## 二、代码走廊（五条）

### 走廊①：双重加价与两部制费（本家族实验）

[`../experiments/double_marginalization.py`](experiments/double_marginalization.py)
（同目录链接见 [experiments/](experiments/)）：三组闭式断言。核心模式：

```python
def monopoly(p):                     # 给定零售价的利润链
    Q = a - p;  return Q, (p - c) * Q
# 一体化：max (p-c)(a-p) -> p=(a+c)/2
# 双重：下游面对"成本"w -> p=(a+w)/2；上游预见之 -> w=(a+c)/2
```
工程化要点：把"上游预见下游反应"写成两层嵌套优化（Stackelberg 骨架），
任何纵向链（供应商-平台-商家）复用。

### 走廊②：Huff 引力选址

```python
P = (S/ T**lam) / sum(S_all / T_all**lam, axis=0)   # 消费者网格 -> 门店
revenue = P @ spend                                  # 客流×客单
```
输入：城市网格人口、竞店矩阵；输出：新店选址的增量客流。50 行 numpy，
咨询公司的选址模型内核。

### 走廊③：Bass 扩散拟合

```python
def bass(t, p, q, m):                 # 累计采用 S 形
    return m * (1 - np.exp(-(p+q)*t)) / (1 + q/p*np.exp(-(p+q)*t))
popt, _ = curve_fit(bass, weeks, sales)   # scipy 或手写高斯牛顿
peak = np.log(q/p) / (q-p)                # 峰值时点闭式
```
用于新品铺货计划、直播选品的"起量周"预测。

### 走廊④：双边平台定价仿真

两侧需求 `N_S = A_S − α_S·p_S + β_S·N_B`（交叉外部性耦合），
不动点迭代至均衡，扫描 (p_S, p_B) 网格找利润峰——**补贴边在网格解里
自动浮现**（最优 p_B 可为负）。100 行内完成，是理解"免费"的最短路径。

### 走廊⑤：促销弹性 A/B（工业级入口）

电商实验平台的标准件：分层随机化（用户级/地理级）、CUPED 方差缩减、
长期效应 holdout。经济学模型的弹性在这里从假设变成测量——
**商业计算=结构（闭式）×参数（实验）**。

## 三、工程师落点（这些东西在谁家产线上）

1. **电商定价与促销引擎**：弹性估计（走廊⑤）+ 库存联动（
   [讲透物流经济学](../讲透物流经济学/) 04 章）。
2. **选址与门店网络规划**：Huff 引力+GIS（走廊②），零售扩张部的内核。
3. **新品预测与选品**：Bass 拟合+搜索热度先验（走廊③）。
4. **平台机制设计**：抽成/补贴双参数搜索（走廊④），与
   [讲透数学·讲透博弈论](../../讲透数学/讲透博弈论/) 共管。

## 四、✨美之时刻（⑧要件）：网格里的"免费"——补贴边自动浮现

**陈述**：走廊④的双参数扫描中，把两侧价格从 −20 扫到 +40，利润面的
最高点常常落在**一侧价格为负**的格子上——不是程序错了，是模型告诉你：
**对弹性大的那侧倒贴，换来外部性强的一侧入场，总盘子更大**。
**为什么美**：*必然*——"免费"不是商业魔术，是交叉外部性方程的解；
你在网格上亲眼看到市场自己长出免费。**怎么亲历**：把 β_S 设为 0
（无外部性）重扫——负价格立刻消失。免费的根基是外部性，仅此而已。

## 五、反直觉发现（⑥要件）

代码化边界的教学版：**最难算的不是定价（闭式）而是"这一届消费者的
偏好结构"（会漂移）**。商业模型的小巧恰恰暴露了它的软肋——参数的
半衰期越来越短。对策不是更大的模型，而是**实验基础设施**（走廊⑤）。

## 👁 认知升维（⑨要件）

**闭式×实验眼**：把商业决策拆成"结构定式（数学）+参数测量（实验）"，
前者十年不变、后者天天更新——系统的可维护性来自把两者分层的勇气。
这与性能工程的"算法×profiling"分工完全同构。
