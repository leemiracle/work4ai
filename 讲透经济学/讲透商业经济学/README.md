# 讲透商业经济学 · 交换本身的经济学

> **商业经济学 = 把"交换"作为成本对象来研究的学问**——商人凭什么存在、
> 渠道为什么长这样、零售价格如何形成、广告买到了什么、服务为何越来越贵。
> 它的全部张力在一句话里：**市场是最伟大的资源配置机器，但使用这台机器
> 本身是要付费的——商业就是付费说明书。**

## 一、诞生（三个原生问题）

1. **商人凭什么赚钱（1776/1937）**——斯密之谜：分工受市场范围限制，但把
   东西从生产者搬到消费者手里这件事本身谁在付钱？Coase 1937 用**交易成本**
   作答：商人出售的是"降低交易成本"的服务——商业经济学的理论地基。
2. **零售为什么不断自我革命（1852-）**——百货公司（巴黎 Bon Marché）→
   连锁（A&P）→ 超市（1930）→ 折扣店（ALDI）→ 电商：每一波都是
   "更低毛利率×更高周转"对上一代的降维打击（McNair 1958 零售轮转假说）。
3. **平台为什么给一边免费（2003）**——Rochet & Tirole 把双边市场形式化：
   平台定价的是**结构**（谁补贴谁）而非**水平**——商业组织理论的世纪更新。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 中间商的价值（Coase 1937；Williamson 1975） | ✅ 已解 | 交易成本决定渠道长度——渠道是节约交易的装置 |
| 双重加价（Spengler 1950） | ✅ 已证明 | 上下游都垄断→零售价更高、总利润更低——纵向约束的效率理由 |
| 零售业态更替（McNair 1958 轮转假说） | ✅ 框架成熟 | 新业态低价进入→加服务升级→被下一代低价颠覆 |
| 广告的信息与信号（Nelson 1970/1974；Milgrom-Roberts 1986） | ✅ 已证明 | 烧钱重复投放=质量信号——广告卖的是信任 |
| 服务的成本病（Baumol 1967） | ✅ 已证明 | 生产率滞涨部门相对涨价是必然——不是服务变差 |
| 平台定价结构（Rochet-Tirole 2003） | ✅ 框架成熟 | 补贴边与收费边的选择=鸡蛋问题求解 |
| 直播/即时零售的业态终局 | ❌ 未解 | 信任技术与履约成本的赛跑正在进行 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 交易有成本且可度量 | 渠道结构可解释、可设计 | 组织内"关系成本"隐形 |
| 消费者信息可被触达/影响 | 市场学与广告学成立 | 操纵与信息的边界永在争论 |
| 零售业态=毛利率×周转的组合 | 业态更替可预测 | 体验/信任等软维度难以入表 |
| 平台两侧需求相互强化 | 网络效应可计算 | 赢家通吃的福利后果无共识解 |
