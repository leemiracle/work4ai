# 讲透商业经济史 · 四波零售革命的社会学

> **定位**：这支负责商业的历时维度——从行商坐贾到百货、连锁、超市、
> 电商的四波组织革命，以及商业变迁的社会后果（社区、街市、消费文化）。
> GB/T 三级"商业经济史+商业社会学"归组于此。

## 诞生

商业史作为学科随社会经济史大传统成型（20 世纪初德国历史学派与
哈佛商学院企业史学派，钱德勒《看得见的手》1977 把"流通革命"写进
管理资本主义叙事）。商业社会学一脉：Zelizer 对保险与货币的社会意义
研究、消费社会学（Bourdieu 区隔）提供了"市场嵌入社会"的分析。

## 核心问题（3-5 条）

- ✅ 已解：四波零售革命的编年与机制（家族 [00 章](../00-体系结构.md)
  业态表——每波都是毛利率×周转的重构）
- ✅ 已解：商业组织形态与运输/信息技术的共生（冷链与超市、信用卡与
  连锁、移动互联网与即时零售）
- ✅ 已解：市场嵌入性（Polanyi/Zelizer——价格之外，商业永远背着
  社会关系与道德边界）
- 🔄 前线：电商对城市商业地产与社区商业的重构（空洞化还是再分化）
- ❌ 未解：直播与即时零售是"第五波"还是第四波的延长（业态史的
  当代判例未过）

## ✨这支最美的一个事实

1852 年巴黎 Bon Marché 百货公司推出"明码标价、自由出入、退换保证"
三件套——在讨价还价为主流的时代，这是**把信任制度化为商店政策**：
标价省谈判成本，退换省验货成本，自由进入省身份门槛。现代零售的全部
文明底座（以及今天的"7 天无理由"）都从这三件套里长出来。商业史
的一半，是**信任的技术史**。

## 假设与依赖

技术-组织共生律（交通/信息基建决定业态可行域）；编年数据可比
（口径史与统计史是本支的地基工作，史料批判不可省）。

- Zelizer, *The Social Meaning of Money*（商业社会学的标本方法）
