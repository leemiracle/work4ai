# 讲透服务经济学 · 不可储存的产业

> **定位**：这支负责"服务"作为一类经济物品的特殊性——不可储存、
> 生产消费同时、质量不可验（信任密集）。GB/T 三级"服务经济学"落位于此。

## 诞生

服务经济学的理论地基是两篇经典：Fuchs《服务经济学》(1968) 宣告发达
经济体过半就业在服务业；Baumol (1967) 成本病预言服务业相对价格必然
上涨（家族 [02 章](../02-语言特征.md)美之时刻）。中国脉络：服务业
占比自 2015 年过半后持续上升，"提高服务业生产率"成为政策高频词——
本支的中国现场是数字经济（外卖/网约车/平台服务）。

## 核心问题（3-5 条）

- ✅ 已解：成本病（生产率滞涨部门相对涨价——不是衰退是阴影增长率）
- ✅ 已解：服务的异质性（IHIP：无形/不可分/异质/易逝——与
  [讲透物流经济学](../../../讲透经济学/讲透物流经济学/) 的库存论形成
  镜像：易逝即负库存）
- ✅ 已解：质量的信息结构（体验品+信任品——评价机制与品牌的服务版）
- 🔄 前线：服务业生产率的可测性（数字化让"无形变有形"——交易留痕）
- ❌ 未解：服务自动化的边界（哪些服务环节可标准化而不摧毁信任）

## ✨这支最美的一个事实

酒店今晚空出的房间，明早价值归零；飞机起飞时空着的座位永远无法
补卖——**服务的库存是负数**。这一个性质派生出整门产业经济学：
收益管理（把不确定性切成价格段）、超售（对冲 no-show）、峰荷定价
（容量记高峰的账）。与 [讲透旅游经济学](../../../讲透经济学/讲透旅游经济学/)
共管的这一页，是"易逝性"作为经济学变量的最强现场。

## 假设与依赖

质量可被声誉机制约束（评价/复购的均衡）；需求波动可预测（收益管理的
统计前提）。生产率"滞涨"的判断依赖物量衡量——数字化服务
（一次检索的价值）至今难以入账，成本病在数字部门可能是"假病"。

- Baumol (1967) 宏观寓言原典
