- 命名：家族目录=GB/T 二级名轻规范化（"数量经济学"→讲载数量经济学——注意"讲透+数量"连排，
  目录名保持全词不缩）
- 穷尽声明：79011-79077 全部落子；79099 兜底类不设系列
- **薄家族纪律**：部门经济学多为"领域×经济学基本工具"结构——家族卡按七要件写，
  章可精简至 150 行下限附近，核心问题清单与该领域的真实政策争论挂钩，不注水
- 实验纪律：家族实验=最小可跑经济模型（供需/乘数/OLG/拍卖/风控等经典计算模型或数据小样）
