# 讲透比较经济学 · 把制度当作变量

> **比较经济学 = 把经济制度当作变量而非背景的学问**——产权结构、
> 协调机制、国家-市场关系如何不同，绩效为何因此不同，制度如何变迁。
> 它的终身命题来自 1920 年那场大论战：**计划与市场，各靠什么收集
> 信息、提供激励？** 1989 年后它换了主场：**转型**——制度如何从一种
> 形态迁移到另一种。
>
> GB/T 13745：79017（经济学·二级学科，GB/T 无三级明细——**自定主干两支**：
> 体制比较 / 转型研究）。宇宙：[讲透经济学](../README.md)（2026-09-07 GB13745 扩展波4 建族）。

## 一、诞生

1. **1920-1945 大论战（学科的原罪与荣光）**——米塞斯 1920《社会主义
   共同体中的经济计算》：没有生产资料市场就没有合理定价；
   哈耶克 1945《知识在社会中的运用》：价格是分散知识的电报，
   中央计划在信息上不可能。兰格 1936/1938 反击：试错模拟市场
   （计划者扮拍卖师）——论战定义了学科的坐标轴（信息+激励）。
2. **1950s-1980s 体制比较学的教科书期**——比较经济体制
   （comparative economic systems）建制化：isms 分类学
   （资本主义/社会主义/共产主义）、MPS vs SNA 双核算体系。
   科尔奈《短缺经济学》(1980) 是这期的巅峰：从"主义"转向"机制"
   （软预算约束、数量调节）。
3. **1989- 转型研究爆发**——柏林墙倒下，学科瞬间从"比较"变"施工"：
   华盛顿共识（价格自由化+私有化+稳定化）vs 渐进主义；
   转型衰退的深度出乎所有人意料（苏联-40%+），中国路径的反例地位
   确立——转型经济学（Roland 2000 教科本）成型。
4. **2000s- 合流期**——与新制度经济学（诺斯；Acemoglu-Robinson）
   和资本主义多样性（Hall-Soskice 2001）合流；国家资本主义研究
   随中国体量崛起（01 章）。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 计划的信息不可能（价格=知识电报） | ✅ 定理化（Hurwicz 机制设计给兰格-哈耶克之争做了终审：信息效率有定理） |
| 计划的激励不可能（软预算约束） | ✅ 概念定型+博弈论化（Kornai 1986；Dewatripont-Maskin 1995） |
| 转型速度与顺序（大爆炸 vs 渐进） | ✅ 案例清算：衰退深度的差异已被系统度量，机制归因仍多门 |
| 制度决定长期绩效（东西德/朝韩自然实验） | ✅ 强证据（同民族同文化对照）——2024 诺奖加冕（Acemoglu-Johnson-Robinson） |
| 中国悖论（"错误"顺序的成功） | 🔄 持续争论（国家能力/官员激励/渐进试验论各执一词） |
| 制度趋同还是多样 | 🔄 前线（VoC 框架 vs 趋同论） |
| 制度的内生起源（地理vs制度vs文化） | 🔄 大论战（AJR vs 地理派 Sachs 的识别战） |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 制度可定义可分类 | 比较研究可进行 | 边界案例（混合体制）挤不进类型学 |
| 制度可与其他变量分离（识别假设） | 绩效归因可行 | 地理/文化/历史同源混淆——AJR 之争的根源 |
| 绩效指标跨国可比（GDP/MPS 折算） | 定量比较 | 两套核算体系不可通约的历史遗留（03 章） |
| 制度有"性能"可言（存在可比较的产出维度） | 排名/评估产业 | 价值维度选择即立场（增长vs分配vs自由） |

## 四、教材锚

- 科尔奈《社会主义体制》（1992，解剖学正典）、《短缺经济学》（1980）
- Roland《Transition and Economics》（2000，转型标准教本）
- Hall & Soskice《Varieties of Capitalism》（2001，VoC 正典）
- Acemoglu & Robinson《国家为什么会失败》（2012，制度论大众正典）
- 格鲁奇《比较经济制度》（1985，教科书期的代表）
