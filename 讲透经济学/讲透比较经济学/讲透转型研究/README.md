# 讲透转型研究 · 纵断面：制度迁移的速度、顺序与代价

> 这支负责：**从一种体制到另一种的迁移动态**——大爆炸 vs 渐进、
> 改革顺序与互补性、转型衰退的深度、路径依赖与中国路径。
> **自定主干支**（GB/T 79017 无三级明细，本家族按学科习惯自定）。

## 诞生

1989 柏林墙倒下，比较经济学从"拍横断面"变成"施工"：
1990 波兰休克疗法（Balcerowicz 计划）→ 华盛顿共识成型（价格自由化+
私有化+稳定化）→ 转型衰退深度出乎意料（苏联空间累计 −40% 量级）→
中国双轨制与越南革新的反例地位确立 → 1990s 后期学术清算
（渐进主义抬头：Roland 2000 教科本、Aghion-Blanchard 失业与速度
模型）→ 2000s- 转型 30 年总评估（01 章）。

## ✨ 这支最美的一个事实

**超模互补性一句话同时给出两派论据**：F(x₁x₂)＞F(x₁)+F(x₂) 意味着
"只改一半"收益很低——大爆炸派拿它论证全改；但同一结构也意味着
局部改革的产出可能落在低均衡（俄罗斯的产权改革×软信贷）——
渐进派拿它论证顺序即命运。**一个偏导数符号装下一场三十年论战**，
而定理诚实地拒绝裁决顺序——学科把不可判定性本身讲清楚了。

## 假设与依赖

存在可迁移的"目标体制"（终点假设——中国路径对它的挑战是本支的
生产性张力）；制度互补性可操作化（组合观测稀疏）；转型衰退可比
（MPS→SNA 口径遗留，家族 [03 章](../03-可构造与结构.md) §四）。
