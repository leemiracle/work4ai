# 讲透体制比较 · 横断面：谁的制度跑得快、为什么

> 这支负责：**体制的静态比较**——计划 vs 市场的信息与激励解剖、
> 资本主义多样性（VoC）、国家资本主义、制度与长期绩效的识别。
> **自定主干支**（GB/T 79017 无三级明细，本家族按学科习惯自定）。

## 诞生

1920-1945 米塞斯-哈耶克 vs 兰格的计算/知识论战定义了坐标轴 →
1950s-70s 比较经济体制学教科书期（isms 分类、MPS/SNA 双账本）→
1980 科尔奈《短缺经济学》把比较从"主义"推进到"机制"（软预算约束）→
2001 Hall-Soskice《Varieties of Capitalism》开类型学新局 →
2024 诺奖（Acemoglu-Johnson-Robinson）为"制度决定繁荣"加冕。

## 核心问题

| 问题 | 状态 |
|------|------|
| 计划的信息与激励不可能 | ✅ 定理化（Hurwicz 机制设计；Dewatripont-Maskin 软预算） |
| 制度效应的因果识别（东西德/朝韩/AJR 工具变量） | ✅ 强证据+持续争议（地理派反击） |
| 资本主义多样性（CME/LME）的比较优势预测 | 🔄 中年危机与数字经济扩展 |
| 国家资本主义的类型地位 | 🔄 前线（01 章：从标签到纲领） |
| 制度质量测量指数的因果地位 | 🔄 方法论前线 |

## ✨ 这支最美的一个事实

**软预算约束**（科尔奈）原生于比较社会主义企业，被博弈论化后
（Dewatripont-Maskin 1995：信贷集中度决定预算软硬）成为分析
2008 年"大而不倒"的通用工具——**概念的移植能力是比较经济学
最好的产出证明**。

## 假设与依赖

制度可定义可分类（混合体制挤类型学的缝）；制度可与地理/文化分离
（识别假设，AJR 之争的战场）；绩效指标跨国可比（MPS/SNA 历史
遗留见家族 [03 章](../03-可构造与结构.md) §四）。全表见家族 README §三。

Acemoglu & Robinson《国家为什么会失败》；格鲁奇《比较经济制度》。
