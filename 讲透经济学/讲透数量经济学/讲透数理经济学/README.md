# 讲透数理经济学 · 存在性、唯一性与最优性

> 支：[讲透数量经济学](../README.md) GB/T 三级支。经济学的定理部——
> 把"看不见的手"从信仰变成命题，把"最优增长"从口号变成变分问题。

## 定位句

本支负责**经济关系的公理化**：消费者/生产者理论的约束优化结构、
一般均衡的存在性与福利性质、社会选择的不可能性、最优增长与动态
规划——核心问题永远是"在什么假设下，什么必然成立"。

## 诞生与关键事件

- 1874 瓦尔拉斯方程组（无存在性证明，悬置 80 年）
- 1928 拉姆齐最优储蓄；1936 沃尔德首个存在性证明
- 1951 Arrow 不可能性定理（社会选择）；1954 Arrow-Debreu 一般均衡
  存在性（不动点方法）
- 1957 Scarf 算法：均衡从存在走向可计算
- 1965 Cass-Koopmans 最优增长；1969 Lucas 递归方法——动态规划
  成为宏观的标准语言

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 竞争均衡的存在条件 | ✅ 1954 解决（凸性+连续性+无外部性） |
| 均衡的唯一性与稳定性 | 🔄 部分解决（唯一性条件苛刻；全局稳定未有一般定理） |
| 两个福利定理（均衡↔帕累托最优） | ✅ 证明完成，条件（无外部性/完备市场）恰是其软肋 |
| 均衡的可计算性（Scarf 之后的大规模 GE） | 🔄 CGE/ABM 实用化中，收敛保证有限 |
| 不可能性定理的边界（哪些放宽条件能逃出） | 🔄 社会选择理论常青问题 |

## 这支最美的一个事实（一句）

Arrow 不可能性定理：不存在同时满足无限域、帕累托、无关备选独立
和非独裁的（≥3 个备选的）社会排序——**民主加总在数学上有天花板**，
而天花板的位置可以被精确画出。

## 假设与依赖

读本支需数学分析+线性代数基础（凸集、不动点、动态规划）；
经济学假设：个体理性+市场完备无摩擦——定理的力量与假设的脆弱
互为镜像。
