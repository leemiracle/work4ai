## 诞生

两条诞生线在 1930s 的考尔斯委员会（Cowles Commission）汇合：

1. **公理线**：瓦尔拉斯 1874 写下一般均衡方程组却无法证明解存在；
   沃尔德 1936 给出首个存在性证明；Arrow-Debreu 1954 用不动点定理
   完成标准证明——"看不见的手"从信仰变成定理
2. **数据线**：丁伯根 1939 建第一个宏观计量模型，凯恩斯质疑
   "这是统计还是炼金"；哈维尔莫 1943-44《计量经济学的概率方法》
   把误差变成概率对象（诺奖 1989）——考尔斯委员会产出联立方程
   识别理论（诺奖 2000 赫克曼-麦克法登一脉的前置）
3. **转折线**：卢卡斯批评 1976 指出"用历史数据估的政策模型会在
   政策改变瞬间失效"——识别与结构自此成为学科的第一词

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 一般均衡的存在性 | ✅ 1954 Arrow-Debreu | 竞争均衡的存在条件被精确划界 |
| 联立方程的识别 | ✅ 阶条件/秩条件（考尔斯） | "能估什么"先于"怎么估" |
| OLS 何时可信 | ✅ 高斯-马尔可夫+识别条件 | 现代答案：外生性+识别设计（2021 诺奖 Card/Angrist/Imbens） |
| 均衡的唯一性与稳定性 | 🔄 部分解决 | 存在不等于唯一，太阳黑子与多重均衡仍是前线 |
| 机器学习与因果推断的融合 | 🔄 前线 | 双重机器学习（DML）、异质性处理效应（04 章） |
| 结构模型的外部效度（一个情境估的参数能否外推） | 🔄 悬而未决 | 可信性革命与结构主义的百年拉锯点 |

## 假设与依赖

本家族站在三条假设上：①经济关系可写成（随机）方程——买到可估性，
付出"方程形式本身是假设"；②识别先于估计——买到因果语言，
付出"识别假设不可检验"（只能辩护，不能证明）；③参数跨情境稳定
（卢卡斯批评的靶心）——买到政策分析，付出参数在政策变时漂移的风险。
