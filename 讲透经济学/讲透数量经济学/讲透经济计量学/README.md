# 讲透经济计量学 · 识别、估计、推断

> 支：[讲透数量经济学](../README.md) GB/T 三级支。经济学的称重部——
> 把理论参数从数据里称出来，并诚实报告秤的误差。

## 定位句

本支负责**观测数据的因果与预测方法论**：识别（数据能不能回答）、
估计（参数怎么算）、推断（误差多大）——以及三板斧实验设计
（IV/DID/RD）与机器学习的融合。

## 诞生与关键事件

- 1939 丁伯根首个宏观计量模型；凯恩斯"统计炼金术"之讥
- 1943-44 哈维尔莫《计量经济学的概率方法》：误差成为概率对象
  （1989 诺奖）
- 1950s 考尔斯委员会：联立方程识别理论（2SLS 前身）
- 1976 卢卡斯批评：政策评价的重定向；1980s 结构 vs 简约百年之争
- 1994 Angrist-Imbens LATE；2000s 可信性革命（2021 诺奖
  Card/Angrist/Imbens）；2018 双重机器学习（DML）

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 联立方程的识别条件 | ✅ 阶/秩条件（考尔斯） |

| 工具变量估计的因果解释 | ✅ LATE（1994）：局部平均处理效应 |
| 面板/聚类的标准误（Few Clusters 问题） | 🔄 修正方法活跃 |
| 高维控制+因果参数（DML 之后） | 🔄 前线（异质性效应、稳健推断） |
| 预测与因果的分工 | 🔄 永久问题（预测好≠政策有用） |

## 这支最美的一个事实（一句）

哈维尔莫把"误差项"从理论家的耻辱变成随机变量——这一个概念操作
让经济学同时获得统计学的全部装备与"模型永远错了但有用"的谦逊。

## 假设与依赖

读本支需概率统计基础（抽样分布、假设检验）+ 线性代数；
核心假设链：模型设定→识别（不可检验，只能辩护）→估计（渐近性质
可证明）→推断（区间可计算）——每一环的失败方式都不同。
