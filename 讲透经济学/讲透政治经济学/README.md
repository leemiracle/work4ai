# 讲透政治经济学 · 生产关系之学：谁拥有、谁劳动、剩余去哪

> **政治经济学 = 研究生产关系的经济学**——生产资料归谁所有、劳动如何
> 组织、剩余如何分配、经济制度如何随生产力演化而演化。
> 它问的是主流微观默认外生的那个问题：**产权与制度本身从哪来、向哪去**。
> 两句家训：生产力决定生产关系（历史唯物主义）；
> 剩余劳动是利润、地租、利息的共同源头（剩余价值论）。
>

> 社会主义政治经济学）。宇宙：[讲透经济学](../README.md)（2026-09-07 GB13745 扩展波4 建族）。
> 政治学宇宙亦以此为共同边境（GB/T 810 政治学理论与之接壤）。

一支是批判解剖学，一支是制度发生学。

## 一、诞生

政治经济学是经济学的前身与母体（"economics"去掉"political"是 1890
马歇尔之后的窄化）：

1. **1615-1776 前史**——蒙克莱田 1615 首用"政治经济学"之名；
   重商主义（财富=金银）→ 重农学派（魁奈 1758《经济表》：再生产分析
   的第一张图）→ 斯密《国富论》(1776) 确立"财富的生产与分配"议程。
2. **1867 正典时刻**——马克思《资本论》第一卷：劳动价值论
   （价值实体=社会必要劳动时间）→ 剩余价值论（劳动力这一特殊商品的
   使用价值是创造价值）→ 资本积累与有机构成提高。二卷（1885）再生产
   表式、三卷（1894）生产价格与转形——三卷构成体系。
3. **1917-1954 扩展与建制**——列宁《帝国主义论》(1917)（垄断与
   金融资本）；苏联《政治经济学教科书》(1954) 首次把"社会主义政治
   经济学"建制化（规律+范畴+政策的教科书体）。
4. **1978- 中国线**——社会主义初级阶段理论（1987）→ 社会主义市场
   经济（1992）→ 基本经济制度（公有制为主体、多种所有制共同发展）→
   习近平经济思想与中国特色社会主义政治经济学体系化（2015-）。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 剩余价值的来源（劳动力商品论） | ✅ 体系内已解 | 交换不创造价值；剩余来自生产领域——与"资本生产力论"的根本分岔 |
| 转形问题（价值→生产价格） | 🔄 百年论战 | 逻辑上多解（Bortkiewicz 1907 起），迭代法（Shaikh 1984 等）给出收敛解一族 |
| 利润率趋向下降规律（TRPF） | 🔄 实证活跃 | 有机构成上升 vs 剩余价值率上升的赛跑——43 国 2000-2014 面板新证（01 章） |
| 危机的根源（生产过剩/利润挤压/实现危机） | 🔄 多模型并立 | 结构欠定：同一数据多套危机理论都能讲通（03 章诚实标注） |
| 社会主义与市场经济的兼容性 | 🔄 实践检验中 | 从"计划=社会主义"教条到市场在资源配置中起决定性作用——理论与实践的双重演化 |
| 历史趋势命题（生产关系一定要适合生产力） | 📐 定性规律 | 是方法论纲领不是可计算命题（03 章 §4 边界） |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 劳动价值论（价值实体=社会必要劳动时间） | 剥削与分配问题的统一分析基准；与投入产出表直接可接（03 章） | 供求与稀缺性进入"转形"绕行道；使用价值差异被抽象 |
| 资本总公式 G—W—G'（增殖为资本的本性） | 积累、竞争、危机的动态全在一条公式里 | 金融、国家、家户的自主性需要额外装置 |
| 历史唯物主义（生产力-生产关系-上层建筑） | 制度内生化：产权不是自然事实而是历史形态 | 不可量化为参数；趋势判断依赖史识（03 章边界） |
| 阶级分析（剥削关系的定位） | 分配冲突的第一性问题化 | 非阶级异质性（性别/族群/部门）需扩展装置 |
