# 02 · 语言特征：叙述的科学——范畴推演如何工作

> **本章回答五问之三（本家族：讲透政治经济学；宇宙任务书要求写深：
> 模型语言 vs 制度叙述）。**
> 政治经济学的母语不是数学，是**范畴推演**：商品→货币→资本→
> 剩余价值→积累→危机，一条概念链从最抽象长到具体总体。
> 但它同时拥有一套**准形式的数字装置**（总公式、再生产表式、
> 利润率公式）——本章的任务是把两种表达并排放好：
> 叙述承担什么、装置承担什么、它们与主流模型语言的翻译地图在哪里。

---

## 一、表达力：范畴语言的四件兵器

### 1.1 什么是"范畴"（与"变量"的区别）

主流模型语言的对象是**变量**（有取值、进方程）；政经的对象是
**范畴**——一个概念同时编码实体、关系与历史趋势：

| 范畴 | 不变式编码 | 关系编码 | 历史编码 |
|------|-----------|---------|---------|
| 商品 | 使用价值+价值 | 私人劳动与社会劳动的矛盾 | 商品生产的普遍化=特定历史阶段 |
| 劳动力 | 商品（有价格） | 特殊商品：使用创造大于价值 | 劳动力成为商品=资本主义起点 |
| 有机构成 c:v | 技术结构 | 资本对劳动的替代比 | 上升=利润率下降压力的载体 |
| 软预算约束 | 行为规则 | 国家-企业关系 | 特定体制的微观宪法（借自 [比较经济学](../讲透比较经济学/)） |

**为什么范畴比变量"重"**：一个范畴是一族命题的压缩包（定义+规律+
趋势），叙述语言按范畴的逻辑顺序展开论证——**从抽象上升到具体**
（Marx 1857《导言》自述的方法：先分析最简单范畴（商品），逐步
加入规定，最后到达"许多规定的综合"——资产阶级社会的"具体总体"）。

### 1.2 范畴推演的合法 moves（叙述语言的语法）

| 语句类型 | 例子 | 逻辑地位 |
|---------|------|---------|
| 定义展开 | 商品二因素→劳动二重性 | 概念分析（必然真） |
| 矛盾推进 | 使用价值与价值的矛盾→货币的必然性 | 辩证推理（结构必然性论证） |
| 机制叙述 | 工作日一章：限额斗争史 | 经验归纳（史料） |
| 数字例 | 再生产表式、转形计算 | 算术模型（可检验） |
| 趋势判断 | 利润率趋向下降"规律" | 规律+反作用因素的竞争断言（半经验） |

**关键区分**：同一文本里五种句子交替出现——读《资本论》分不清
哪句是哪类，是把"经文"读成"教科书"或反之的根源。**叙述科学的
纪律=每一步标明句子类型**（本章的元贡献）。

## 二、叙述 vs 装置：政经内部的两种表达

### 2.1 数字装置的谱系（政经可形式化的暗线）

```
魁奈经济表（1758，再生产流的图示）
  → 马克思再生产表式（1885，两部门数字例，含平衡条件）
  → 转形问题（三卷；Bortkiewicz 1907 三部门代数化）
  → 列昂惕夫投入产出（1936，与表式同构的实证化）
  → Sraffa《用商品生产商品》（1960，价格-分配的线性方程体系，
     与劳动价值论和新古典同时开战的"第三条路"）
  → 现代政经的动力学模型（Goodwin 1967 分配-就业振荡器——
     Lotka-Volterra 的阶级版！）
```

**这条暗线的意义**：政治经济学"能算"的部分比刻板印象大得多——
再生产、转形、利润率、分配动态都有可执行模型（03 章全面展开）。
叙述与装置的分工：**范畴负责"是什么与为什么"（定性结构），
装置负责"多少与平衡与否"（定量结构）**。

✨ **美之时刻 ①：Goodwin 振荡器（1967）**
陈述：把工资份额对就业的反应（菲利普斯式）与积累方程联立，
得到捕食者-猎物方程组——就业率与工资份额永续振荡。
为什么美：**统一+意外**——马克思的"产业后备军"机制
（失业压工资、工资压利润、利润压积累、积累造就业）被写成两条
微分方程，与生态学共享同一个数学骨架（[讲透数学·动力系统](
../../讲透数学/讲透分析/讲透动力系统/) 的 Lotka-Volterra 款）。
叙述直觉 ⟶ 动力系统，一步到位。
怎么亲历：手推两方程平衡点，再用任何 ODE 求解器画出相图的
闭合轨道（04 章练习 2）。

### 2.2 叙述承担什么（不可替代的四项）

| 叙述独有 | 为什么数学装不下 |
|---------|----------------|
| 历史性（制度形态的时间与更替） | 状态空间会随制度重构——"变量"本身在变（结构变化无平稳表示） |
| 总体性（经济-政治-意识形态一体） | 跨层次反馈无一致的模型本体 |
| 矛盾（动力的内生来源） | 均衡语言以消解矛盾为目标 |
| 具体总体（现象的丰富性） | 抽象必然丢弃（这是抽象的代价，见 03 章 §4） |

📖 **故事框：两种文本的出版史对照**
1890 马歇尔《经济学原理》与 1894《资本论》三卷（恩格斯整理）同年代
出版——此后经济学分成两种文体：图与方程的教科书体，与范畴推演的
叙述体。二十世纪的赛局：教科书体统治了期刊与院系建制；叙述体
保住了国家与运动的叙事阵地。**文体之争即受众之争**——这不是
学术趣味史，而是两套知识生产制度的历史（见 [讲透经济思想史](../讲透经济思想史/)）。

## 三、模型语言 vs 制度叙述：翻译地图（家族主战场）

主流模型语言与政经范畴的**官方对译表**（有限但有实义）：

| 政经范畴 | 主流最近对应 | 翻译损耗 |
|---------|-------------|---------|
| 剩余价值率 m/v | 劳动份额 1−s_L 的倒数结构 | "剥削"的规范含义在翻译中蒸发 |
| 有机构成 c/v | 资本-劳动比 K/L（资本深化） | 资本加总悖论双方共有（见 [生产力经济学 03 章](../讲透生产力经济学/03-可构造与结构.md)） |
| 简单再生产/扩大再生产 | 稳态/平衡增长路径 | 剩余的分配问题被"代表性主体"抹平 |
| 生产价格 | 完全竞争长期均衡价格 | 价值实体问题被绕开（均衡价格无实体承诺） |
| 转形问题 | 一般均衡的存在性计算 | 两边其实共享"从价值量到价格量"的计算问题 |
| 产业后备军 | 自然失业率的动态 | 制度内容（失业的规训功能）消失 |

**翻译的元规则**（与 [微观 02 章](../讲透微观经济学/02-语言特征.md) 同构）：
1. 每个范畴先问它在对面有没有"座位"——没有座位的（剥削的规范含义、
   历史趋势）必须显式标注"不可译"
2. 有座位的翻译要双向检查：m/v→劳动份额容易，**反过来**把劳动份额
   读出"剥削率"需要生产/非生产劳动的分类学（01 章 §六瓶颈）
3. **不可译清单比译表更有信息量**——它标出了两个范式的真正分界线

## 四、逻辑性质：叙述科学的自检标准

| 性质 | 状态 |
|------|------|
| 一致性 | 范畴体系内部（如三卷间的转形一致性）经过百年打磨；叙述与装置混排处偶有张力 |
| 可检验性 | 装置部分强（数字例、平衡条件、TRPF 序列）；趋势命题弱（见 03 章 §4） |
| 完备性 | 有意不完备——开放范畴（如"垄断"）留给历史填空 |
| 严谨性的来源 | 概念的辩证展开 vs 公理演绎——两种"必然性"，不可互相还原 |

**诚实段**：叙述语言的风险恰好是它的长处的影子——范畴可以吸收
一切反例（规律+反作用的解释弹性过大），这是波普尔一系批评的
要害；装置语言的风险是模型可以精致地错（假设不问历史）。
**两套语言的纪律互补，是本家族的写作立场。**

## 五、规范化：政经语言的台阶

| 级 | 内容 | 代表 |
|----|------|------|
| 1 哲学叙述层 | 异化、拜物教批判 | 1844 手稿、《资本论》商品拜物教章 |
| 2 范畴体系层 | 价值-剩余价值-积累-危机的推演 | 《资本论》三卷；苏联教科书体 |
| 3 数字装置层 | 表式、转形、利润率代数 | 二卷表式、Bortkiewicz、Sraffa |
| 4 动力系统层 | 分配振荡、增长-危机模型 | Goodwin 1967 及其后 |
| 5 实证计量层 | 剩余价值率面板、利润率长波 | 2020s 的实证转向（01 章） |

## 七、不足层

- 叙述语言的"句子类型标注"在本章是倡议，尚无正典化的文本分析方法
  （计算叙事学可能提供工具，暂缺）
- 翻译地图只覆盖概念层；方法层（辩证法 vs 最优化）无对译
- 中文语境的范畴双语（教科书范畴与政策范畴的相互缠绕）研究刚起步

## 👁 这章给了你什么新眼睛（认知升维）

- **读任何理论文本先分句子类型**：定义/推理/归纳/计算/趋势——
  五类句子的可反驳性天差地别，混读是信仰化的起点
- **范畴是压缩包**：遇到大概念先拆它的实体/关系/历史三层编码——
  拆完才知道哪部分能进模型、哪部分是历史叙事
- **译表之外看不可译表**：两个范式真正的分歧在翻译不过去的地方，
  不在译得过去的地方
