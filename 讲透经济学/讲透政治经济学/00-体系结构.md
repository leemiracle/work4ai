# 00 · 体系结构：一条主轴、三大装置、两大部类

> **本章回答五问之一（本家族：讲透政治经济学）。**
> 政治经济学的大厦 = **一条主轴（生产力—生产关系—上层建筑）**
> + **三大理论装置（劳动价值论 / 剩余价值论 / 再生产理论）**
> + **两大板块（资本主义解剖 / 社会主义建构）**。
> 一句话分工：**主轴给历史方向，装置给分析工具，板块给两个对象。**

---

## 一、直觉开篇：问一个微观不问的问题

主流微观从"给定产权与偏好"开始分析。政治经济学问的是**上一步**：
这产权本身是谁定的、为谁定的、会不会变？

- 封建地租、资本主义利润、社会主义利润——同样是"干活的人交出一部分
  产出"，制度形态完全不同
- 每一种形态都曾被认为是"自然的"，又都在历史中改变过——
  **制度是变量，不是背景**

反直觉第一击：**"经济"这个词的窄化本身就是历史事件**——
"政治经济学"（political economy）这个名字在 1890 年后被马歇尔换成了
"经济学"（economics），把"分配与阶级"从学科标题里拿掉。
今天重提政治经济学，不是怀旧，是把被拿掉的问题放回桌上的一个学统
（见 [讲透经济思想史](../讲透经济思想史/)）。

## 二、主轴：生产力—生产关系—上层建筑

**历史唯物主义的硬核**（生产方式理论）：

```
生产力（技术、劳动生产率）
   │ 决定（成为其"社会形式"）
生产关系（所有制、分配、交换关系）—— 经济基础
   │ 决定（并为后者所反作用）
上层建筑（国家、法律、意识形态）
```

**为什么它是主轴而不是教条**：它把"制度为什么是这样"变成可研究的
问题——手工磨坊给封建社会、蒸汽磨给资本主义（马克思《哲学的贫困》
1847 名句的直译）；每个制度的兴衰都能用"生产关系是否还容得下
生产力发展"来定位。它的代价与边界在 03 章 §4 诚实处理
（趋势命题不可计算化）。

📖 **故事框：一句话的方法论自白**
《政治经济学批判》导言（1857）：分析经济形式"既不能用显微镜，
也不能用化学试剂；抽象力是唯一的武器。"——政治经济学自觉选择了
**范畴抽象**作为方法（02 章的主题由此而来），与物理式建模
分道扬镳的宣言就写在这里。

## 三、三大理论装置

### 装置 1：劳动价值论——价值实体

**直觉**：两件商品能按比例交换，必有一个可通约的"第三物"——
马克思答：社会必要劳动时间（在现有社会正常生产条件下，
社会平均劳动熟练程度和强度下制造使用价值所需的时间）。

| 概念 | 内容 | 易混点 |
|------|------|--------|
| 价值 vs 使用价值 | 价值=劳动凝结；使用价值=有用性 | 空气使用价值巨大价值为零（非劳动产品） |
| 社会必要 | 行业平均条件，非个别劳动 | 懒人干一天≠多创造一天价值 |
| 简单/复杂劳动 | 复杂劳动=倍加的简单劳动 | 折算率由社会过程定 |
| 价值 vs 价格 | 价格是价值的货币表现，随供求波动 | 价值论不是"价格应该等于劳动量"的定价处方 |

### 装置 2：剩余价值论——剥削机制

**核心三步**（资本主义支的发动机）：
1. 总公式 G—W—G'：货币—商品—更多货币，增殖是资本的本性
2. 悖论：等价交换怎么增殖？答：找到一种特殊商品**劳动力**——
   它的使用（劳动）本身创造价值，且大于其自身价值（工资=劳动力
   再产成本，劳动创造>工资 ⟹ 剩余价值 m）
3. 相对/绝对剩余价值：延长工作日（绝对）vs 提高生产率缩短必要劳动
   时间（相对）——机器、管理、教育全都嵌在这对范畴里

✨ **美之时刻 ①：剩余价值率——一个比率封装一场分配冲突**
陈述：m' = m/v（剩余价值/可变资本）——工作日被无偿与有偿两段的分割比。
为什么美：**极简**——不援引任何道德，只问"你新创造的价值里
多少归你多少不归你"；同时它把"剥削"从伦理词变成**可测量**：
m'=100% ⟹ 一半天数为自己干。工资谈判、社保、工时立法——
全部政治斗争都是围绕这个比率的战争。
怎么亲历：用国民核算数据粗估 m'（劳动报酬 vs 营业盈余+折旧），
与 [讲透生产力经济学](../讲透生产力经济学/) 的要素份额核算互读。

### 装置 3：再生产理论——总量的解剖与危机

**资本循环三形态**（货币-生产-商品）与**两大部类**：
- Ⅰ 部类：生产资料（c₁+v₁+m₁）
- Ⅱ 部类：消费资料（c₂+v₂+m₂）
- **简单再生产平衡：Ⅰ(v+m) = Ⅱc**（生产资料的供给=两部类对生产资料
  的补偿需求）——总量平衡条件的最早系统（先于投入产出七十年）
- 扩大再生产：积累率进入两部类，平衡条件随之改变（03 章可构造性
  主角、04 章实验主场）
- 危机理论的种子：比例失调/生产过剩/利润率下降——多模型并立
  （02 章 §三：结构欠定的处理）

📖 **故事框：魁奈《经济表》到投入产出**
1758 魁奈用 zigzag 图画农业社会的再生产流——马克思称它是
"政治经济学天才的萌芽"；《资本论》二卷的表式把它发展为两部门
数字例；列昂惕夫（曾研读马克思）1936 建成投入产出分析——
**再生产表式是 I-O 的直系祖先**（本家族 03/04 章的可构造性正源于此，
数学侧见 [讲透数学·线性代数](../../讲透数学/讲透代数学/讲透线性代数/)）。

## 四、两大板块：解剖学与发生学

### 板块 1：资本主义政治经济学（解剖）

《资本论》三卷的路线图 + 二十世纪扩展：
- 一卷（1867）：商品→货币→资本→剩余价值→积累（有机构成提高、
  相对过剩人口）→原始积累
- 二卷（1885）：循环与周转→**再生产表式**
- 三卷（1894）：利润率 p'=m/(c+v)→**转形**（价值→生产价格）→
  利润率趋向下降规律→利息/地租/虚假的社会价值
- 扩展线：列宁帝国主义论（1917）→ 垄断资本学派（Baran-Sweezy 1966：
  剩余吸收问题）→ 调节学派（Aglietta 1976，法国）与积累的社会结构
  （SSA，Gordon 1980，美国）——两条"资本主义阶段化"路线（01/02 章接续）

### 板块 2：社会主义政治经济学（建构）

- 核心范畴：公有制实现形式、按劳分配、初级阶段、基本经济制度、
  有效市场+有为政府、共同富裕
- 从"产品经济观"（苏联教科书：计划规律）到"商品经济观"（1984
  有计划的商品经济）到"市场决定性作用"（2013）——**范畴体系的
  四十年演化**是本支的学术本体
- 与主流的接口：激励理论（家庭联产承包=剩余索取权改革）、机制设计
  （见 [讲透微观经济学·社会主义微观支](../讲透微观经济学/讲透社会主义微观经济学/)）

## 六、假设与代价（家族四张底牌的展开）

见家族 README §三。本章补一句对照：主流微观的"理性人"与政经的
"阶级人"都是**分析杠杆**——前者买个体行为的一致性，后者买分配冲突的
第一性；两者的不可通约主要在价值论层（价值实体 vs 均衡价格），
不在工程层（两家都能算剩余份额、要素弹性——01 章的实证线正在
打通这条隧道）。

## 👁 这章给了你什么新眼睛（认知升维）

- **问制度的历史性**：任何"经济规律"先问它是哪个制度形态下的规律——
  产权、货币、公司、福利都是历史的产物而非自然常数
- **分配是第一性问题**：把"产出如何分"与"产出如何生"看成同样
  基本的问题——剩余索取权的安排决定行为（与 [微观 02 章](../讲透微观经济学/02-语言特征.md)
  的乘子语言对照）
- **表式思维**：用部门间平衡表想问题（谁给谁供货、谁向谁支付）——
  投入产出、资金流量表、供应链分析全是表式的现代后裔
