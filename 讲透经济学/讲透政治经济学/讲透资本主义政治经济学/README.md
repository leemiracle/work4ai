# 讲透资本主义政治经济学 · 《资本论》体系：价值、剩余与危机

> 这支负责：**资本主义生产方式的解剖学**——劳动价值论、剩余价值论、
> 积累与有机构成、转形与利润率、危机理论。GB/T 79011 三级之一；
> GB/T 原名"资本主义政治经济学"。

## 诞生

源头三步：1817 李嘉图《政治经济学及赋税原理》劳动价值论（被继承的
对手）→ 1859《政治经济学批判》与 1867《资本论》一卷（正典时刻）→
1885/1894 二、三卷（恩格斯整理：表式与转形）。二十世纪扩展：
列宁《帝国主义论》(1917)、垄断资本学派（Baran-Sweezy 1966）、
调节学派与 SSA（1976/1980）、Sraffa 体系（1960）与 Goodwin 动力学（1967）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 剩余价值来源（劳动力商品论） | ✅ 体系内已解（G—W—G' 悖论的闭合） |
| 转形问题（价值→生产价格） | 🔄 百年论战（迭代解族：Shaikh 1984 等） |
| 利润率趋向下降（TRPF） | 🔄 实证活跃（p'=e/(k+1) 赛跑；43 国面板，家族 [01 章](../01-近五年创新.md)） |
| 危机机制（生产过剩/利润挤压/实现） | 🔄 多模型并立（结构欠定） |
| 垄断与金融化阶段的剩余吸收 | 🔄 前线（垄断金融资本框架） |

## ✨ 这支最美的一个事实

**利润率趋向下降规律不是悲观的预言，是乐观的悖论**：压低利润率的
恰恰是每个资本追逐超额利润的理性行为（竞相采用机器）——个体理性、
总量自伤。它把"合成谬误"（[宏观 00 章](../../讲透宏观经济学/00-体系结构.md)）
在分配层重新演示了一遍：竞争资本的集合行为惩罚竞争本身。

## 假设与依赖

劳动价值论基准（社会必要劳动时间为价值实体）+ 资本总公式 +
平均利润率形成（部门间竞争）。代价与不可构造边界见家族
[03 章](../03-可构造与结构.md) §四（历史趋势不可计算化的诚实清单）。

经济学》；Morishima《Marx's Economics》（数理化正典）。
