## 二、逐条速写

### 走廊 1：再生产表式——断言驱动的模拟

**直觉**：表式是"带平衡检查的国民账户模拟器"——每期产出、分配、
交换三张账对不上，模型立刻报警。

[experiments/marx_reproduction.py](experiments/marx_reproduction.py)
三件套（03 章构造学的直接落地）：
①简单再生产：马克思原例数字进代码，全部平衡条件断言；
②扩大再生产：比例增长路径 g 逐期零误差断言（矩阵谱性质的数值版）；
③TRPF 赛跑：e 与 k 不同速增长时 p' 方向断言（升/平/降三分支）。
**为什么断言文化在这条走廊特别自然**：表式的"理论内容"就是
平衡等式——**等式即测试用例**，比任何其他经济学传统更贴近
测试驱动开发。

**工程师落点**：任何"部门间流量"系统（供应链、资金流、
投入产出碳排放）都可复用表式骨架：状态=部门存量+流量矩阵，
每期跑守恒断言。

### 走廊 2：价值-价格计算——一行逆矩阵

```python
# 劳动价值（含劳动量）：λ = (I−A)^{-1} l     —— Morishima 定理化
# 生产价格迭代：p_{k+1} = (1+r_k)·p_k·A + w·l ；r_k 由总量恒等式校准
```

**为什么全自动**：线性代数（[讲透数学·线性代数](../../讲透数学/讲透代数学/讲透线性代数/)；
数值求逆见 [讲透数值线代](../../讲透数学/讲透数值线代/)）。
**实践指针**：统计局公开投入产出表（中国 42 部门/153 部门序列、
OECD ICIO/WIOD 跨国库）——把 l 取"劳动者报酬"或"就业人数"行，
即得含劳动量/含工资量两个向量，一百年前的范畴今天一天可算。
**口径警示**：生产/非生产劳动的划分（01 章实证瓶颈）在这一步
具体化为"哪些部门进 l"——分类学选择直接改变 λ。

### 走廊 3：利润率动态——一个公式的面板学

```
p' = m/(c+v) = e/(k+1)，e=剩余价值率，k=有机构成
数值实验（本家族实验 ③）：控制 e、k 增速对比 ⟹ p' 三分支
实证（01 章 43 国）：Δln p' = Δln e − Δln(k+1) 的加法分解
```

**归因的欠定提醒**（03 章 §四）：同一 p' 序列，利润挤压派读出
e 顶点、生产过剩派读出实现瓶颈——计算给出分解，**解释要范畴承诺**。
这条走廊的自动化档位是"计算全自动、归因半自动"。

### 走廊 4：Goodwin 振荡器——叙述传统自己的动力系统

```
分配-就业系统（1967）：
  dω/dt = ω·(−α + γ·λ)          工资份额 ω 随就业率 λ 上升（后备军机制）
  dλ/dt = λ·(ρ − σ·ω)           就业随利润份额（1−ω）驱动的积累上升
⟹ Lotka-Volterra 结构：闭轨振荡，中心平衡点（结构性不稳定但持久振荡）
```

**代码形态**：任何 ODE 积分器（scipy.integrate.solve_ivp）+ 相图；
20 行内可见"失业-工资的周期性拉锯"。**与
[宏观的乘数-加速数实验](../讲透宏观经济学/experiments/multiplier_accelerator.py)
对读**：同一个"内生周期"主题，凯恩斯线用差分方程特征根、
马克思线用微分方程闭轨——两大传统在动力学层握手。

## 四、工程师落点（性能工程视角）

1. **守恒断言是最便宜的数值护栏**：表式的每期平衡检查 O(n²)——
   比事后对账便宜三个量级；供应链/资金流模拟直接抄这个骨架
2. **逆矩阵 vs 迭代**：(I−A)⁻¹ 在稀疏大表上应该用迭代解
   （A 稀疏度高）——[数值线代](../../讲透数学/讲透数值线代/)的
   稠密/稀疏抉择在经济矩阵上的直接应用
3. **分解式先于回归**：Δln p' 的加法分解是不用回归的归因——
   能恒等分解的不要统计拟合（会计优于计量，计量补充因果）
4. **相图思维**：Goodwin/乘数-加速数都教"先画零增长线定方向，
   再数值积分"——二维 ODE 的定性分析是模拟前的一次 O(1) 推演
