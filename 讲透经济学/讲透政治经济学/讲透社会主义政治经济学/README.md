# 讲透社会主义政治经济学 · 公有制与市场：制度的发生学

> 这支负责：**社会主义生产关系的建构与演化理论**——公有制实现形式、
> 按劳分配、初级阶段与基本经济制度、有效市场+有为政府、共同富裕。
> GB/T 79011 三级之一；GB/T 原名"社会主义政治经济学"。

## 诞生

思想前史：马克思对"自由人联合体"的原则性设想（《资本论》一卷
"重建个人所有制"句）与《哥达纲领批判》(1875) 按劳分配论。
建制化：1917 后苏俄战时共产主义→新经济政策（1921，市场的第一次
有限回归）→苏联模式定型→1954《政治经济学教科书》把"社会主义
政治经济学"首次学科化。中国线：1956 所有制改造→1978 改革开放→
1984 有计划的商品经济→1992 社会主义市场经济→1997/2002 基本经济
制度表述→2013 市场在资源配置中起决定性作用→2015- 中国特色社会
主义政治经济学体系化。

## 核心问题

| 问题 | 状态 |
|------|------|
| 计划与市场的关系（手段 vs 制度属性） | ✅ 认识论突破已定型（市场=手段，社会主义=制度），理论表述持续深化 |
| 公有制实现形式的多样性（股份/混改/国资监管） | 🔄 世界最大政策实验室 |
| 按劳分配与要素按贡献分配的并存逻辑 | ✅ 制度化（分配理论仍开放） |
| 政府与市场边界（有为政府与有效市场的接口） | 🔄 前线（产业政策有效性之争跨学科） |
| 共同富裕的机制设计（三次分配协调） | 🔄 指标化与测度进行时 |

## ✨ 这支最美的一个事实

**"社会主义市场经济"这个范畴本身是一场持续四十年的理论实验**——
它在两个百年教条（计划=社会主义、市场=资本主义）之间打开的
概念空间，重构了本学科的全部范畴体系：从"有计划的商品经济"
到"市场决定性作用"，每一步范畴演化对应一次制度变迁。
范畴与实践的双向改写，是这支学科独有的"发生学"样本。

## 假设与依赖

公有制为主体（制度前提而非待证命题）+ 解放和发展生产力的效率标准 +
共同富裕的价值导向。方法论依赖历史唯物主义主轴（家族 [00 章](../00-体系结构.md)）；
实证工具与主流共享（准自然实验、面板评估）。

## 教材锚

逄锦聚等《政治经济学》（现行标准教本）；《毛泽东选集》《邓小平文选》
相关篇目（一手文献）；张宇等《中国特色社会主义政治经济学》；
吴敬琏《当代中国经济改革》（改革史的对照叙事）。
