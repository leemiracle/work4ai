# 03 · 可构造与结构：表式可解、转形可迭代、趋势不可算

> **本章回答五问之四（本家族：讲透政治经济学；宇宙任务书要求写深）。**
> 政治经济学的可构造性有一张清晰的热图：**再生产表式完全可解**
> （平衡条件是线性等式）、**劳动价值=投入产出的逆矩阵**
> （Morishima 定理）、**转形可迭代**（收敛解一族）；而**历史趋势
> 命题不可计算**（它是方法论纲领，不是参数化模型）。热图本身就是
> 本章的论点：**叙述传统内部埋着一条强构造暗线**。

---

## 一、可构造之一：再生产表式——总量平衡的线性代数

### 1.1 数字例（马克思二卷原例，本家族实验主场）

```
第Ⅰ部类（生产资料）：c₁=4000  v₁=1000  m₁=1000  ⟹ 产出 W₁=6000
第Ⅱ部类（消费资料）：c₂=2000  v₂=500   m₂=500   ⟹ 产出 W₂=3000
简单再生产条件：Ⅰ(v+m) = Ⅱc  ⟹  2000 = 2000  ✅
```

**验证清单**（全部可断言，实验 (a) 全跑）：
- 生产资料总供需：W₁ = c₁+c₂（6000=6000）
- 消费资料总供需：W₂ = (v₁+m₁)+(v₂+m₂)（3000=3000）
- 总价值：W₁+W₂ = (c+v+m) 总和

### 1.2 扩大再生产：积累率进入系统

积累率 α_i（各部类剩余价值中转化为资本的比例）+ 分配规则
（新增资本在 c:v 间的分割，按现有机构成）⟹ 动态系统。
**马克思第三卷例子的扩展**：Ⅰ 部类积累 500（400c+100v）时，
Ⅱ 部类必须相应积累（c₂: 2000→2000+100…）才保平衡——
**两部类积累率不是自由参数，被平衡条件互相锁定**。

**比例增长定理（可证明）**：两部类按相同比率 g、不变技术系数
扩张时，一切平衡条件逐期成立——平衡增长路径存在且是表式的
特征解。实验 (b) 数值验证：给定 g，各期平衡误差=0。

✨ **美之时刻 ①：从表式到投入产出**
陈述：n 部门再生产的平衡条件写成矩阵形式：
生产 A x（消耗系数×产出）+ 最终需求 y = x，即 x = Ax+y，
**劳动价值向量 λ = (I−A)⁻¹ l**（l=直接劳动投入）。
为什么美：**统一**——马克思的表式、列昂惕夫的 I-O、Sraffa 的
生产价格体系是同一个数学对象的三次命名（Morishima 1973
《马克思的经济学》把同构关系定理化：价值=劳动含量的逆矩阵解）。
叙述传统的 1885 与实证经济学的 1936 在线性代数里握手。
怎么亲历：实验 (b) 的比例增长=矩阵谱性质（Perron-Frobenius 根）的
经济版；进一步把 A 换成真实投入产出表（统计局公开），
λ 一行代码算出"含劳动量"向量。

## 二、可构造之二：转形问题——百年论战的迭代解

### 2.1 问题（三卷的接缝）

一卷：价值由劳动决定；三卷：均衡价格是**生产价格**
（成本+平均利润率 p'）。投入按价值计还是按价格计？
平均利润加到按价值计的成本上 ⟹ 产出价格总和≠价值总和——
"转形"要在两套记账之间架桥。Bortkiewicz（1907）指出马克思
只转形了产出未转形投入，百年论战由此起。

### 2.2 迭代解（Shaikh 1984 等）

```
迭代：价格系统 p^(k+1) = (1+r^(k))·p^(k)·A + 工资项
      r^(k) 由总利润=总剩余（或两总量之一相等）确定
收敛：不动点=生产价格。数值上对典型数据收敛稳定
```

**可构造性判定**：转形有**收敛解族**（取决于取哪两个总量恒等式：
总价格=总价值、总利润=总剩余——一般不能同时成立）。
**这是"结构欠定但可计算"的范本**：数值方法给出的是解族的一个
代表，理论选择（哪个恒等式优先）是范畴层的决定——
**计算不消灭理论争议，只把争议精确定位在恒等式选择上**。

## 三、可构造之三：利润率动态——TRPF 的数值解剖

利润率 p' = m/(c+v)。对技术变革的响应分解：

| 变化 | 对 p' 的直接效应 | 机制叙述 |
|------|----------------|---------|
| 有机构成 c/v 上升（资本深化） | ↓（分母变大） | 竞争迫使个别资本采用机器→超额剩余→普及后社会平均 c/v 上升 |
| 剩余价值率 m/v 上升（生产率提升） | ↑（分子相对变大） | 相对剩余价值生产：必要劳动时间缩短 |
| 周转加快 | ↑（年利润率） | 流通时间的压缩（物流、金融） |

**TRPF = 两个相反箭头的赛跑**——`p' = e/(k+1)`（e=m/v 剥削率，
k=c/v 机构成）：数值上 e 与 k 的增长率之差决定 p' 的方向。
实验 (c)：给定 e 固定、k 上升 ⟹ p' 下降（定律的"净"形态）；
e 与 k 同速 ⟹ p' 不变（"反作用因素打平"的形态）——
**一个公式把百年论战变成参数赛跑**，43 国面板（01 章）测的就是
这场赛跑的实测速率。

## 四、不可构造的部分（诚实边界）

| 不可构造 | 性质 | 说明 |
|---------|------|------|
| 历史趋势命题（生产关系一定要适合生产力） | 方法论纲领 | 无状态空间可写——制度更替重构变量本身（02 章 §2.2） |
| 危机的唯一机制（多模型并立） | 结构欠定 | 同一序列支持生产过剩/利润挤压/实现危机各说——模型选择依赖范畴承诺 |
| 拜物教/异化等哲学范畴 | 规范性理论 | 无可测对应物（这是特性不是缺陷——它们批评"可测量"本身） |
| "下一社会形态"的预测 | 开放历史 | 有意不做参数化外推 |

**边界的教学价值**：把可算与不可算分开陈列，两边都更值钱——
可算部分证明叙述传统不反数学；不可算部分提醒模型传统
"参数化即承诺"（与 [微观 03 章](../讲透微观经济学/03-可构造与结构.md)
Anything-Goes 相互映照：那边证明加总失去约束，这边证明趋势失去可算性）。

## 五、结构：政经装置的刚性从哪来

| 梁 | 刚性表现 |
|----|---------|
| 会计恒等式（价值构成 c+v+m） | 一切表式的硬约束——不可谈判（与 [宏观 02 章](../讲透宏观经济学/02-语言特征.md) 恒等式/均衡之分同源） |
| 线性生产结构 | 平衡条件=线性方程组 ⟹ I-O/谱定理（Perron-Frobenius）全套可用 |
| 双部类对称性 | 平衡条件 Ⅰ(v+m)=Ⅱc 的形态由两部门对偶决定——扩到 n 部门即互投产出平衡 |
| 分配约束（剩余分割） | 工资-利润的分配曲线（Sraffa wage-profit frontier）——不依赖边际生产力的分配理论：给定技术，w 与 r 此消彼长，**一条曲线而非一个点** |

📖 **故事框：剑桥资本论战的一箭双雕**
Sraffa 学派 1950s-60s 证明：总量"资本"的度量依赖利率（价格随分配
变动），资本-劳动比不是技术常数——新古典总量生产函数的地基
（加总）被打穿；而政经这边同样受击：有机构成 c/v 也是加总量。
**一场论战打伤两家**——结论是：任何加总的分配理论都要声明
计价标准。本家族与 [讲透生产力经济学](../讲透生产力经济学/)
（03 章资本加总节）共管这条裂缝。

## 八、不足层

- 表式实验用马克思原例（两部门、离散、无货币与金融部门）——
  金融化的再生产（Minsky 式）需要新装置，属前沿未定型
- 转形解族的公理化（哪个总量恒等式"应"成立）无共识——本章只
  展示计算如何精确定位分歧
- 表式→投入产出的接口在本家族是"定理化叙事"，完整 I-O 实操
  属 [讲透数量经济学]（待产家族）

## 👁 这章给了你什么新眼睛（认知升维）

- **会计恒等式是最硬的理论**：c+v+m、Ⅰ(v+m)=Ⅱc 这类恒等式
  比任何"规律"都硬——分析任何体系先找它的复式记账
- **计算定位分歧**：转形百年论战的教训——把争议推进到
  "哪条恒等式优先"这个可精确陈述的点，比各说各话进步一个世纪
- **加总即承诺**：c/v、K/L、TFP 全是加总量，都依赖计价标准——
  看到总量先问"用什么价格加总的"
