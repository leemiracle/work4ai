# 讲透冲突经济学 · 开战与止战的经济：行为侧

> **定位**：这支负责"战争什么时候'理性'、威慑怎么起作用、制裁有没有用、
> 内战与恐怖主义的经济账"——把冲突从政治叙事翻译成经济结构。
> 自定主干支（GB/T 79077 无三级明细，本支=行为侧）。

## 诞生

1960 Schelling《冲突的战略》（威慑=博弈结构：一半是冲突一半是
共同利益）；1994-1999 Hirshleifer"冲突的宏观经济学"与 Grossman
掠夺模型（抢夺是生产的替代路线）；1998 Collier-Hoeffler 内战经济
根源实证（贪婪 vs 怨怼之争）；2008 Stiglitz-Bilmes《三万亿美元的
战争》（战争全成本核算范式）。

## 核心问题（3-5 条）

- ✅ 已解：战争的理性主义解释框架（Fearon 1995：完备信息下几乎不必
  开打——战争必源于信息不对称/承诺问题/不可分性，家族 03 章）
- ✅ 方法已解·实证争论：内战根源（掠夺机会 vs 不公正——数据长期偏向
  "贪婪"，但测度本身在吵）
- 🔄 前线：制裁经济学（2022 后的实时实验室：影子经济适应速度超预期，
  家族 01 章前线一）
- 🔄 前线：恐怖组织的经济组织（绑架定价、毒品融资、治理替代）
- ❌ 未解：威慑的精确计量（"没打起来"的反事实永远无法观测——
  本学科的测地学难题）

## ✨这支最美的一个事实

Hirshleifer 的**强权悖论（paradox of power）**：冲突性竞争里，
初始强者有时会输给弱者——因为强者把太多资源投入生产"享受",
弱者把更多投入"抢夺"，投入比例决定冲突均衡的翻转。**实力决定于
总量，胜负决定于比例**——这解释了历史上多个"富而弱"政权
被"穷而狠"对手掀翻的账本。
