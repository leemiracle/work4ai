# 讲透军费经济学 · 备战的经济：投入侧

> **定位**：这支负责"军费多大、怎么花、从哪买、谁去扛"——军费需求、
> 费效分析、国防工业与军贸、兵役制度、裁军红利。
> 自定主干支（GB/T 79077 无三级明细，按"投入侧/行为侧"切分，
> 本支=投入侧）。

## 诞生

1960 Hitch-McKean《核时代国防的经济学》——把边际分析与系统分析带进
五角大楼（PPBS），"国防经济学"作为学科正式出生（书名即学科名）；
冷战军控经济学（Schelling-Halperin 1961）与和平红利研究（1990s）
是两次大扩展。

## 核心问题（3-5 条）

- ✅ 已解：费效分析框架（PPBS→PPBE：把"安全"翻译成可预算的效能单位）
- ✅ 已解：征兵的机会成本核算（义务兵=隐性"征兵税"；志愿兵制改革
  的经济学基础，美 1973 废征兵的学术底座）
- 🔄 前线：无人机时代的交换比重算（家族 01 章前线二——平台费效崩塌）
- 🔄 前线：国防工业动员经济学（炮弹产能爬坡=供给弹性的战时版本）
- ❌ 未解：军民融合的最优边界（保密与扩散的两难——两用管制的全成本）

## ✨这支最美的一个事实

核武器的"超杀能力"（overkill）暴露了军费效用的奇形：**当毁灭对手
的能力已冗余 N 倍，再多弹头的边际军事价值是零**——军备竞赛的终点
不是"打赢"而是"过剩"。军控谈判的产品因此不是裁掉的弹头，
而是**可核查性**（信息）——博弈论里最贵的东西。

## 假设与依赖

站在"国家在预算约束下最大化安全"上（理性国防官的画像）；
依赖公共经济学（国防是纯公共品）、产业组织（国防工业的自然垄断与
独买）与[讲透宏观经济学](../../讲透宏观经济学/)（军费凯恩斯主义与挤出）。
