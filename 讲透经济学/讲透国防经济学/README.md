## 一、诞生

三个原生问题，跨越一百年：

1. **军备竞赛会自动失控吗**（1919）——英国气象学家 Richardson 用两条
   耦合微分方程拟合 1909-1913 欧洲列强军费，发现"你扩我也扩"的
   反应系数足以解释一战前的螺旋——**军备竞赛的数量科学比博弈论早三十年**。
2. **核时代军费怎么算账**（1960）——Hitch-McKean《核时代国防的经济学》
   把经济学边际分析带进五角大楼（PPBS 计划-编程-预算系统）：
   威慑是"花小钱防大灾"的期望值计算。
3. **冲突能否被经济学解释**（1960/1994）——Schelling《冲突的战略》
   把战争建模为讨价还价；Hirshleifer 1994 提出"冲突的生产性替代"
   （抢也是获取资源的路线）——冲突经济学成型。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 军备竞赛稳定性判据（Richardson） | ✅ 已解 | 防务反应系数之积小于抑制系数之积 ⟺ 稳定（家族实验现场） |
| 威慑的最低条件（Schelling） | ✅ 已解 | 可信承诺：让对手相信报复压倒收益 |
| 内战的经济根源（Collier-Hoeffler 1998） | 🔄 实证前线 | 贪婪（掠夺机会）vs 怨怼（不公正）——数据反复偏向"贪婪" |
| 裁军的和平红利多大 | 🔄 永恒争论 | 军费转民用的一次性红利 vs 安全外部性的隐性成本 |
| AI 自主武器的经济稳定 | ❌ 未解 | 机器速度×人类授权=新型不稳定（01 章前线五） |
| 军民融合的最优边界 | ❌ 未解 | 保密（安全）与扩散（效率）的两难 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 国家是理性行为者 | 军备/威慑可建模 | 非国家行为体、意识形态狂热成为模型盲区 |
| 威慑可信（报复可信） | 用"不使用"买到安全 | 意外升级：误判也是模型外事件 |
| 军费数据可比（SIPRI 口径） | 跨国跨年比较 | 定义差异（隐蔽项目/准军事）系统性低估 |
| 冲突是"生产"的一种 | 抢夺可一般均衡化 | 正义的规范性问题被排除在模型外 |
