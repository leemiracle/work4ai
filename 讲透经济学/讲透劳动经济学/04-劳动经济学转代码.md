# 04 · 劳动经济学转代码：政策实验室的三个工位

> **本章回答五问之五（本家族：讲透劳动经济学）。**
> 三件套：**可机械化边界 → 代码走廊 → 工程师落点**。
> 核心判断一句话：劳动经济学的"模型半页纸+证据千行码"
> 结构，决定了转代码的主战场在**估计与模拟**，
> 而不是模型本身。

---

## 一、可机械化边界

| 环节 | 可机械化 | 形态 |
|------|---------|------|
| 供需/政策模拟（含买方垄断） | ✅ | 闭式解+断言（本家族实验，60 行） |
| 明瑟回归/分解 | ✅ | 线性代数（`np.linalg.lstsq` 三行） |
| DID/事件研究/RDD | ✅ | 固定效应面板回归——统计软件成熟件 |
| 匹配模型（DMP）均衡求解 | ✅ | 不动点迭代 |
| 数据清洗与口径对齐 | 🟡 | 脚本可写，但口径决策（什么算就业）是人的 |
| 因果有效性判断（识别策略） | ❌ | 假设不可检验——平行趋势只能"示警"不能"证明" |
| 政策的价值判断（该不该补谁） | ❌ | 福利权重是政治，代码只算技术前沿 |

**判据**：凡输出带**不确定带**的（估计）可机械化；
凡输入带**不可检验假设**的（识别）只能半机械化；
凡输出是**规范判断**的（政策取舍）不可机械化。

## 二、代码走廊

### 走廊①：政策模拟器——把 00 章的争论跑成断言（本家族实验）

```python
# 竞争市场：最低工资 = 价格下限
#   就业 = demand(wmin)，失业 = supply(wmin) - demand(wmin)
# 买方垄断：边际支出线 ME = c + 2dL 与需求线相交定雇佣
#   wmin ∈ (w_m, w_c] → 就业上升（Card-Krueger 机制）
# 断言：同一政策在两种结构下符号相反、窗口可精确计算
```

[experiments/minimum_wage.py](experiments/minimum_wage.py) 的价值不在数字
（数字是编的参数），在**结构**：政策争论被翻译成
可逐步断言的数学对象——"争论-模型-断言"三段式
是本家族给所有政策学科的转代码范式。

### 走廊②：明瑟回归最小实现

教育回报率估计的最小内核：设计矩阵 [1, 教育, 经验, 经验²]、
取对数工资、最小二乘、报告系数与标准误——
40 行 numpy 可从零写完（含稳健标准误）。
扩展位：分位数回归（工资分布）、Oaxaca-Blinder 分解（组差）、
工具变量（出生季度）。**自己写一遍的价值**：
黑箱软件里的"显著"从此祛魅——它只是一个 t 值。

### 走廊③：DID/事件研究管道

面板数据 → 长格式 → 组×期固定效应 + 处理×期交互项 →
事件研究图（政策前系数应平——平行趋势的图形检验）。
工程要点：聚类标准误（组内相关）、双向固定效应的
负权重陷阱（近年计量文献的热点 bug 警告——
好研究者与翻车者的分水岭）。

## 三、工程师落点

| 场景 | 落点 | 备注 |
|------|------|------|
| 政策仿真（政府/智库） | 税收-福利微观模拟（劳动供给弹性代入） | 欧洲各国税务模型的标配件 |
| 人事分析（People Analytics） | 离职预测/薪酬公平审计 | 企业内部劳动市场；注意与劳动法的合规接缝 |
| 平台劳动市场 | 派单/定价/补贴的实验平台 | A/B 实验文化浓厚——本学科现场实验的最大新金矿 |
| 劳动统计口径工程 | 调查数据清理与口径衔接 | 低调但量大；"定义即测量"的工程面 |

**诚实判词**：劳动经济学的工程岗位分散在统计机构、HR 技术、
平台实验团队——没有"劳动经济学工程师"的统一名号；
**迁移性最强的单品是因果推断工具链**（走廊③），
它同时是互联网实验科学与政策评估的硬通货。

## 四、反直觉发现（⑥）

**模拟器最好的用法不是预测，是证伪直觉。**
政策模拟的参数几乎永远不可信（弹性吵 30 年），但
模拟器能在 5 分钟内告诉你"你的政策论证隐含了哪个模型"——
说"最低工资无害"的人几乎总在隐含买方垄断结构，
说"必然失业"的人隐含完全竞争。**模拟器当测谎仪用，
比当水晶球用价值高一个量级**（00 章实验的设计哲学）。

## 五、✨美之时刻（⑧要件）：三行代码的诺贝尔奖

**陈述**：明瑟方程的全部估计机器是 `β = (X'X)⁻¹X'y`——
一个矩阵运算。围绕这三行代数，过去半个世纪生产了
数万篇论文、无数政策（学生贷款/义务教育/培训补贴），
和一门诺奖级的方法论（微观计量）。

**为什么美**：*杠杆*——输入是普通人填的调查表，
输出是国家的教育预算辩护词；杠杆比（代码行数/世界影响）
可能超过任何其他经济学公式。

**怎么亲历**：走廊②亲手跑一次（哪怕合成数据）：
看教育系数从 OLS 到 IV 的移动——那一格移动的距离，
就是"能力偏差"的大小，也是半门劳动经济学。

## 📌 收束与认知升维（⑨要件）

**这章给了你什么新眼睛**：
- **测谎仪眼**：遇到政策模拟先问"它在替我假设什么结构"
  ——模拟器的透明度价值高于预测精度。
- **不确定带眼**：任何点估计（回报率/弹性/效应）先补上
  区间再谈含义——点值是营销，区间才是科学。
