# 讲透人力资本与工资 · 把人当作资本的科学与危险

> **定位**：这支负责教育与能力如何变成工资——人力资本理论、
> 明瑟方程、工资结构与不平等。GB/T 把"教育经济学"归入
> 88031（教育学科），**其经济学主线（教育回报、工资决定）
> 由本支承接**——自定主干支，注明跨科归属。

## 诞生

三条线：Schultz（1960 演讲）把教育支出重新认作投资；
Becker《人力资本》（1964）给出系统理论（培训的一般/特殊之分、
在职培训谁付钱）；Mincer（1958/1974）给出测量工具
（工资方程）。1990s 起 Spence 信号论与人力资本论的
"教育到底生产什么"之争成为本支的常设张力。

## 核心问题（3-5 条）

- ✅ 已解：教育回报的估计框架（明瑟方程+识别策略全家桶）
- ✅ 已解：在职培训的费用分担逻辑（一般培训员工自付——
  以低起薪换取技能，特殊培训双方共担）
- 🔄 前线：信号论 vs 人力资本论的世纪审判（羊皮纸效应/能力偏差）
- 🔄 前线：学历溢价的下行重估（部分市场走平、与 AI 暴露度负相关线索）
- ❌ 未解： preschool/非认知技能的回报估计（测量先于估计的难题）

## ✨这支最美的一个事实

"能力偏差"是明瑟方程的心病：受教育者本来就更聪明/更努力，
OLS 高估教育回报；IV（出生季度/距离/改革）修正后回报
经常**不降反升**——因为受教育被信贷约束压低的人，
边际回报比平均更高。**纠正偏差的武器反过来证明了
教育的价值**——计量经济学的诗意时刻。

## 假设与依赖

教育可度量（年数近似质量——最脆弱处：一年顶级教育与
一年普通教育在"年数"里相同）；工资=边际产品（议价结构
进残差）；依赖[讲透就业经济学](../讲透就业经济学/)的
市场结构、[数学宇宙·数理统计](../../../讲透数学/讲透数理统计/)
的估计机器。
