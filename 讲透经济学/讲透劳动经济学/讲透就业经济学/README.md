# 讲透就业经济学 · 劳动市场的主战场

> **定位**：这支负责 GB/T 79045 明列的第一支（"就业经济学，
> 包括劳动市场经济学"）——劳动供需、失业、工资决定与
> 劳动市场制度的全部主戏。家族层 00 章三层楼的完整展开即在此。
> **GB/T 三级**（非自定）。

## 诞生

供需分析来自新古典（把劳动当要素市场），但本支的现代骨架
是 1970s-2010s 两场革命拼出来的：搜寻-匹配理论
（Phelps/ Mortensen-Pissarides，2010 诺奖）给了失业的微观基础；
Card-Krueger（1994）起的自然实验革命给了政策的实证法庭——
本支从此"一个模型、两个法庭"（理论法庭+证据法庭）。

## 核心问题（3-5 条）

- ✅ 已解：失业与空岗并存的微观基础（匹配摩擦——贝弗里奇曲线）
- ✅ 已解：最低工资效应的结构条件（竞争=负、买方垄断=窗口正）
- 🔄 前线：工资粘性与就业调整的机制分解（效率工资/议价/制度）
- 🔄 前线：青年/大龄/长期失业的异质性治理
- ❌ 未解：自然失业率的可测性——估计值随方法摇摆，政策锚不牢

## ✨这支最美的一个事实

失业率与空岗率的反向曲线（贝弗里奇曲线）一根坐标轴就能
区分周期性与结构性失业：沿曲线滑动=刺激有效，
曲线外移=培训与匹配才有效——**一张散点图顶半套产业政策**。

## 假设与依赖

匹配函数存在且稳定（m(u,v) 的技术假设）；议价解概念
（纳什分割）；制度层（最低工资/解雇成本/社保）作为
参数而非内生对象进入。依赖[讲透微观经济学](../../讲透微观经济学/)
的家庭与厂商理论直接供弹。

## 教材锚

- Borjas《Labor Economics》第 2 部分（劳动供给/需求/均衡）
- Pissarides《Equilibrium Unemployment Theory》（搜寻匹配圣经）
- 家族层 Card & Krueger《Myth and Measurement》
