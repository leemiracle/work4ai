# 讲透劳动经济史 · 工资与工人运动的百年

> **定位**：这支负责 GB/T 79045 明列的"劳动经济史"——
> 劳动制度（工厂制/劳动合同/社保/工会）与劳动力市场
> 变迁的历史。它回答一个问题：**今天的"正常雇佣"
> 是一段很短的历史安排，不是自然状态**。
> **GB/T 三级**（非自定）。

## 诞生

工厂制（18 世纪末-19 世纪）把"劳动"从家庭生产中剥离出来，
雇佣关系成为需要制度定义的新事物——工时立法（英国 1833
工厂法）、童工禁令、工伤赔偿，都是这条线的产物；
1880s-1910s 工会与集体谈判立法、1935 美国瓦格纳法、
1942 贝弗里奇报告与战后福利国家——**现代劳动制度
差不多全部诞生于 1830-1950 这一百二十年**。

## 核心问题（3-5 条）

- ✅ 已解：标准就业关系的谱系（工业化-去家庭化-再商品化三段）
- ✅ 已解：工时长期下降的记录（周工时 60+→40 的百年趋势）
- 🔄 前线：标准就业关系的侵蚀史（非标准用工占比上升的断代）
- 🔄 前线：中国劳动制度史的特殊轨迹（单位制→劳动合同制 1994→
  劳动合同法 2008→平台用工 2020s）
- ❌ 未解：福利国家与全球化的历史张力——压缩再分配还是
  转向保护主义，历史没有给出先例

## ✨这支最美的一个事实

八小时工作制从 1817 Robert Owen 的口号（"8 小时劳动、
8 小时休闲、8 小时休息"）到 1919 年国际劳工组织成立即
通过的第一号公约，走了整整 102 年——**今天被视为天经地义的
"朝九晚五"，是三代人街头运动的成果**；它也可以再次改变
（四天工作制正在重演同样的循环）。

## 假设与依赖

制度变迁可断代（避免辉格史观的线性叙事）；史料依赖
工厂档案/工资簿/工会记录（劳动史的资料革命——
从宏大叙事转向工资格栅级微观史，Engerman-Sokoloff 与
Allen 等的量化劳动史范式）。

## 教材锚

- Vito Laterza / Allen 等量化经济史文献中的劳动章节
- 中文：中国近代劳动史与劳动合同制度变迁文献
