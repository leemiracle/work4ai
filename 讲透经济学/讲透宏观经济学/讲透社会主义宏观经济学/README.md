# 讲透社会主义宏观经济学 · 综合平衡与宏观调控主线

> 这支负责：**"制度叙述+规划工具"的总量管理主线**——从马克思再生产表式与
> 国民经济综合平衡，到社会主义市场经济条件下的宏观调控体系
> （五年规划+财政货币政策+国家储备与产业政策组合）。
> GB/T 79013 三级之一；GB/T 原名"社会主义宏观经济学"。

## 诞生

源头在《资本论》二卷再生产表式（1885，总量平衡的最早系统装置，见
[讲透政治经济学](../../讲透政治经济学/)）→ 1920s 苏联物质平衡表（MPS 核算
体系）与计划经济实践 → 1950s 中国"综合平衡"理论（陈云：财政/信贷/物资/
外汇四大平衡）→ 1978 后双重体制 → 1992 社会主义市场经济确立，
宏观调控概念入典（1993 十四届三中全会）→ 2000s- 的规划+政策组合体系
（五年规划、逆周期/跨周期调节）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 综合平衡在市场经济下还剩什么（四大平衡→预算/债务/外储警戒线） | 🔄 概念转型中 |
| 规划与市场的接口（指导性规划何以"指导"） | 🔄 前线（产业政策有效性之争） |
| 转型期宏观稳定（1994 分税制/1998 与 2008 两轮刺激的得失） | ✅ 案例成熟、解释多门 |
| 社会主义市场经济的宏观理论体系化（学理化任务） | 📝 建设中 |

## ✨ 这支最美的一个事实

马克思两大部类平衡条件 **Ⅰ(v+m)=Ⅱc**（家族
[政治经济学实验](../../讲透政治经济学/experiments/marx_reproduction.py) 可跑）——
用一行等式给出"生产资料部门与消费资料部门必须成比例"的总量约束，
比西方投入产出分析早了七十年，且是其直接源头之一（列昂惕夫自述受
再生产图式启发）。

## 假设与代价

总量可以被行政协调（规划可执行）——买到：集中资源办大事的能力、
危机时的动员速度；付出：信息与激励的双重代价（软预算约束、指标博弈，
见 [讲透比较经济学](../../讲透比较经济学/) 科尔奈条目）。
现代形态是把假设改写为"规划引导+市场配置"的混合命题。

## 教材锚

《资本论》第二卷（再生产诸表式）；逄锦聚等《政治经济学》（宏观调控章）；
刘国光主编相关宏观论著；吴敬琏《当代中国经济改革》（转型宏观叙事）。
