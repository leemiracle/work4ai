# 讲透西方宏观经济学 · 微观基础的总量模型主线

> 这支负责：**增长、波动与政策的"模型语言"主线**——凯恩斯→新古典综合→
> RBC→新凯恩斯 DSGE→HANK 的六层谱系（家族 [00 章](../00-体系结构.md) §3 塔）。
> GB/T 79013 三级之一；GB/T 原名"西方宏观经济学"。

## 诞生

1936 凯恩斯《通论》（大萧条的应答）→ 1937 希克斯 IS-LM（翻译成图）→
1939 丁伯根宏观计量（翻译成方程）→ 1956 索洛（增长板块）→
1976 卢卡斯批判（范式地震，家族 [03 章](../03-可构造与结构.md)）→
1982 RBC / 1990s 新凯恩斯 DSGE（微观基础收官）→ 2018- HANK（分布入模）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 增长源泉分解（索洛 1957 增长核算） | ✅ 方法已解（余值解释权在 [讲透生产力经济学](../../讲透生产力经济学/)） |

| 菲利普斯曲线形态（2021-2023 通胀后的重估） | 🔄 前线（家族 [01 章](../01-近五年创新.md)） |
| 深参数不变性（卢卡斯批判驯服） | ❌ 未解——被约定未被证明 |

## ✨ 这支最美的一个事实

**合成谬误**：每个家庭各自多储蓄都是对的，全社会一起储蓄反而谁也攒不下钱
（收入塌陷）——个体理性加不出总体理性，这一条就足以让宏观独立成科。

## 假设与代价

代表性主体+理性预期+均衡解概念（家族 README 三张底牌全表）；
短期模型另付"名义粘性"假设。买到的：可解析、可估计、可政策实验；
付出的：分布隐形、认知过强、失调被挤出（HANK 与预期之争正在补课）。

Walsh《货币理论与政策》；Gali《Monetary Policy, Inflation, and the Business Cycle》
（新凯恩斯三方程标准卷）。
