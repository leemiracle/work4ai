# 04 · 宏观经济学转代码：从增长求解器到 HANK 计算走廊

> **本章回答五问之五（本家族：讲透宏观经济学）。**
> 宏观资产的代码化分五条走廊：**增长模型求解（不动点迭代）→
> 波动系统模拟（特征根/脉冲响应）→ DSGE 工具链（Dynare）→
> HANK/异质性主体（分布状态）→ 预测与滤波（卡尔曼/nowcasting）**。
> 可机械化边界恰好是 03 章的三档：线性世界全自动、全局非线性半自动、
> 制度与预期形成无门。

## 一、五条走廊总表

| # | 走廊 | 输入→输出 | 代表工具/方法 | 自动化档位 |
|---|------|----------|--------------|-----------|
| 1 | 增长求解 | (s,n,g,δ,α)→稳态/收敛路径 | 不动点迭代 vs 解析（本家族实验主场） | ✅ 全自动 |
| 2 | 波动模拟 | 行为方程组→时间路径与分区 | 线性差分/微分系统特征分析（实验主场） | ✅ 全自动 |

## 二、逐条速写

### 走廊 1：增长模型求解——不动点的最小可跑版

**直觉**：索洛模型 k̇ = s·k^α − (n+g+δ)·k 就是一维不动点问题，
离散化后 k_{t+1} = (s·k_t^α + (1−δ)·k_t)/(1+n) 迭代必收敛（压缩性）。

本家族实验 [experiments/solow_growth.py](experiments/solow_growth.py)
三件套：①数值迭代稳态 vs 解析解（断言误差 <1e-6）；
②黄金律：数值搜索 s_gold 与解析 s\*=α 对照（断言一致）；
③收敛速度 λ 的数值实测 vs 对数线性化公式 λ=(1−α)(n+g+δ)（断言带内）。
**为什么这条走廊全自动**：单调+压缩 ⟹ 全局收敛，无需挑初值——
增长模型是宏观里"物理味"最足的部分（03 章表 ✅✅ 行）。

**工程师落点**：长期规划、养老金测算、气候-增长综合评估模型（IAM）
的内核都是这条走廊（一个 solow.py 加碳与温度方程=IAM 的骨架）。

### 走廊 2：波动系统模拟——把"语言的逻辑性质"写成 assert

萨缪尔森 1939 乘数-加速数是三行行为方程（02 章 §5）联立成二阶差分方程：

```
Y_t = c·Y_{t−1} + v·(Y_{t−1} − Y_{t−2}) + G
特征方程 x² − (c+v)x + v = 0；Jury 判据：稳定 ⟺ v<1 且 c<1
```

实验 [experiments/multiplier_accelerator.py](experiments/multiplier_accelerator.py)
做"判据-行为"互证：四个参数区（单调收敛/振荡收敛/振荡发散/单调发散）
逐一断言特征根分类与模拟行为一致——**Blanchard-Kahn 式判定逻辑
（03 章）的最小可跑版**。
**为什么它重要**：它证明了一件事——**内生周期不需要外生周期**。
复特征根就是振荡器；宏观的"商业周期"可以纯内生产生。
这是从线性控制借来的直觉（[讲透控制理论](../../讲透信息科学与系统科学/讲透控制理论/)）。

### 走廊 3：DSGE 工具链——把 03 章第一档工业化

```
model.mod（声明：变量、参数、方程、冲击）
  → Dynare 线性化 → 求解（BK 条件自动检查）→ 输出 IRF/方差分解/矩
  → 估计：校准（calibration）或贝叶斯（Metropolis 采样）
```

**为什么线性化档全自动**：一阶摄动把系统变成矩阵 pencils，
解=广义特征值问题（QZ 分解）——数值线性代数的成熟地盘
（数学侧见 [讲透数值线代](../../讲透数学/讲透数值线代/)）。
**全局法（值函数迭代/投影）为什么半自动**：要挑基函数、盯收敛、
排查多重解——分析师介入点是"解的可信度"，不是代码。

### 走廊 4：HANK——分布作为状态变量

代表性主体模型状态是几个数；HANK 的状态是**财富分布**（无穷维对象）。

```
主流路线（ReITER / 一步摄动）：
  分布 → 用少量矩/直方图节点近似
  分布的演化 ≈ 静态分布 + 线性响应（对总量冲击）
  ⟹ 把无穷维问题压回有限维，代价是"分布漂移非线性"失真
```

**可机械化现状**：Econ-ARK（Python/HARK 工具包）等已把家庭侧
（生命周期+流动性约束）标准化；分布-总量联立求解仍是研究代码级
（半自动）——这是 2026 年还在快速变动的走廊（01 章）。

### 走廊 5：预测与滤波——宏观的"在线系统"

```
卡尔曼滤波：状态空间 (观测方程+转移方程) → 实时最优估计
nowcasting：混频数据（月度零售+周度申领+日度支付）→ 当季 GDP 估计
```

央行的日常宏观其实是这条走廊：政策会议前跑 nowcast 模型群
（纽约 Fed staff nowcast 是公开样本）。与
[时间序列分析](../../讲透数学/讲透数理统计/讲透时间序列分析/)共享全部数学。

## 三、可机械化边界（03 章三档的代码投影）

| 任务 | 档位 | 边界由谁把守 |
|------|------|-------------|
| 稳态/收敛/特征分区 | 全自动 | 解析定理（压缩映射/特征值） |
| 线性化 DSGE 全流程 | 全自动 | BK 条件可机器判定 |
| 全局非线性解（ZLB/危机） | 半自动 | 多重解与收敛性要人盯 |
| HANK 分布动态 | 半自动（工具化中） | 无穷维近似的误差控制 |
| regime 识别/制度切换 | 基本无门 | 无监督判据（卢卡斯批判的实操面） |
| 预期形成的"正确"模型 | 无门 | 理论开放（01 章 Moll 之问） |

**为什么宏观的边界与 03 章一一对应**：可机械化程度=均衡可构造性档位；
离"线性化均衡"越远，自动化衰减越快——**先看理论档位再选工具**，
拿 Dynare 干全局问题不是工具选择错误，是对问题档位的误判。

## 四、工程师落点（性能工程视角）

1. **不动点迭代是通用武器**：solow.py 的 40 行结构（iterate→check→assert）
   可搬到任何"循环引用"系统：平台均衡、薪酬带宽收敛、缓存一致性——
   先证压缩性再写循环
2. **特征分区先于仿真**：任何二阶线性系统（乘数-加速数/库存-订单/
   拥塞-调度）先算特征根判行为，再跑数值——判据是 O(1)，
   仿真是 O(T)，且判据告诉你参数往哪调能改行为类型
3. **nowcast 思维=流式特征工程**：混频数据对齐、缺失插补、
   实时修订——宏观 nowcasting 的工程问题与在线特征管线同构
4. **模型即代码（model.mod）的文化**：Dynare 把"模型"与"求解器"分离，
   值得一切仿真系统借鉴——模型文件可 diff、可 review、可版本化

## 👁 这章给了你什么新眼睛（认知升维）

- **判据优先于仿真**：能闭式判定的先判定——特征根、BK 条件、
  稳态解析解都是"先算判据再跑数字"的范式，省 90% 无效仿真
- **模型与求解器分离**：把方程写成数据（model 文件），
  求解器变成可替换件——宏观工具链五十年进化的最大工程红利
