# 02 · 语言特征：模型语言与制度叙述的百年对撞

> **本章回答五问之三（本家族：讲透宏观经济学；宇宙任务书指定深写章）。**
> 宏观经济学实际上说着**两种语言**：一种是从微观经济学借来的
> **模型语言**（最优化+均衡，变量、参数、均衡条件）；
> 一种是它政策实践里长出来的**制度叙述**（"央行应当保持信誉"、
> "财政空间有限"、"锚定通胀预期"）。本章解剖两种语言的语法、
> 表达力边界与翻译损耗——**宏观的多数争论，认真听都是翻译事故**。

---

## 一、表达力：两种语言各能说什么

### 1.1 模型语言的语法：三条生成规则

模型语言的一切句子由三条规则生成（02 章的核心表）：

| 生成规则 | 例子 | 买到什么 |
|---------|------|---------|
| R1 约束+目标 ⟹ 行为方程 | 家庭跨期欧拉方程 u'(c_t)=β(1+i_t)E[u'(c_{t+1})] | 行为有微观根据（"为什么这样消费"有答案） |
| R2 市场出清/均衡 ⟹ 联立系统 | 总需求=总供给、利率使货币市场清 | 内生性：价格利率由系统内生决定 |
| R3 参数+冲击 ⟹ 脉冲响应 | 泰勒系数 φ_π=1.5 ⟹ 通胀冲击的响应路径 | 可定量实验（反事实模拟） |

### 1.2 制度叙述的语法：三种句子

制度叙述（政策文件、央行声明、政论）的句子类型：

- **承诺句**："我们将坚决遏制通胀预期"——时态是将来时，主语是机构
- **史鉴句**："1970s 的教训是……"——用历史 episode 当证据
- **身份句**："央行的独立性是通胀锚"——把制度当变量而非参数

**为什么模型语言装不下这些句子**：模型里"央行信誉"最多是个参数
（比如 φ_π 的大小），但"建立信誉的过程"是制度演化——模型语言是
**同步的**（解一个联立系统），制度叙述是**历时的**（讲故事有先后）。
2001 年诺奖得主斯蒂格利茨的抱怨可作注脚：DSGE 的"微观基础"
只是把凯恩斯问题翻译成了另一种方言，制度本身仍然没有变量名。

### 1.3 对照实验：同一件事的两种说法

| 事件 | 模型语言 | 制度叙述 |
|------|---------|---------|
| 加息抑制通胀 | φ_π>1 ⟹ 实际利率上升 ⟹ 产出缺口为负 ⟹ π 回落 | 央行用行动证明反通胀决心，预期被"锚定" |
| 2021 通胀误判 | supply shock 被误设为 transitory，预测分布右偏不足 | "暂时性"措辞透支了央行信誉，工资谈判开始对标物价 |
| 财政刺激 | 乘数 μ=g'(Y)，挤出取决于 IS 斜率与货币反应 | 财政空间、代际公平、"该花的钱要花在刀刃上" |

注意第三行：**两种语言可以结论一致，但理由系统不同**——
模型语言说"乘数大于 1 因为 MPC 高"，制度叙述说"该花"。
理由系统不同意味着**适用边界不同**（模型语言在 regime 突变处失效，
制度叙述在数量级上失效——央行声明从不告诉你加多少个基点）。

## 二、宏观自己的三组母语对偶（模型语言内部）

### 2.1 恒等式 vs 均衡条件——一个等号两种身份

```
Y = C + I + G + NX          （恒等式：会计恒真，不允许被"检验"）
I = S                       （均衡条件：行为假设，可以被数据否定）
```

**为什么必须区分**：把恒等式当均衡条件用（或反过来）是宏观第一类错误。
恒等式来自国民核算（定义），均衡条件来自 R1+R2（理论）。
2020s 的"现代货币理论"争论里大量句子正是混淆了两者的等号。

### 2.2 流量 vs 存量——资产负债表的语言

GDP 是流量（每期产出），资本 K、政府债务 B 是存量（时点值）。
**存量语言（部门资产负债表、资金流量表）是宏观叙述里最接近会计的部分**，
也是 2008 后复兴的"存量一致"（stock-flow consistent, Godley 方法）
传统——它恰好与马克思再生产表式（[讲透政治经济学](../讲透政治经济学/) 03 章）
和 MPS 核算（[社会主义宏观支](讲透社会主义宏观经济学/)）三家同源：
**都在用会计恒等式约束叙述**。

### 2.3 名义 vs 实际——货币中性的时间合同

"货币中性"（货币量只动价不动量）不是一个命题而是**一族带期限的命题**。
模型语言把它写成参数（粘性多久消退），制度叙述写成"长期看货币是面纱"
（古典二分法）。期限合同见 00 章 §6。

## 三、逻辑性质：宏观模型语言的三块基石与三条裂缝

### 3.1 基石

- **一致性**：均衡存在性有定理（Gale-McKenzie-Debreu 一般均衡，
  见 [微观 03 章](../讲透微观经济学/03-可构造与结构.md)）；
  动态版（递归均衡）存在性较脆弱但常规情形够用
- **可判定性**：给定参数，线性化 DSGE 的解与稳定性由
  Blanchard-Kahn 条件一刀切（预期跳变量数=单位圆外特征值数）——
  宏观罕见的"判定式"定理（03 章细讲）
- **可实验性**：脉冲响应/反事实模拟是模型语言的"实验语态"

### 3.2 裂缝

| 裂缝 | 表现 |
|------|------|
| 卢卡斯裂缝 | 参数不是制度常数——政策变，结构式变（03 章专节） |
| 代表性主体裂缝 | "一个消费者"的等号掩盖分布（HANK 修补中，01 章） |
| 预期裂缝 | 理性预期是解的一部分还是假设的一部分说不清（Moll 之问，01 章 §3） |

📖 **故事框：两种语言的结婚证书**
1937 年希克斯用 IS-LM 把《通论》翻译成图——凯恩斯的制度叙述
（"投资由动物精神驱动"）被翻译成一条曲线的斜率。这场翻译让宏观
进了课堂也埋下七十年"凯恩斯到底说了什么"的笔墨官司。
**翻译即理论选择**：IS-LM 丢掉的不确定性叙事，要到 2008 年后
才被"金融摩擦"作为新变量名请回模型。

## 四、规范化：宏观语言的三级台阶

| 级 | 内容 | 代表 |
|----|------|------|
| 1 会计层 | 国民核算恒等式（任何流派的公共财产） | Kuznets 核算体系（1930s-40s，1971 诺奖） |
| 2 行为层 | 恒等式+行为方程+均衡条件（联立方程宏观计量） | Klein（1950s，1980 诺奖）、Tinbergen 1939 |
| 3 微观基础层 | 一切行为方程由 R1 推出（跨期最优化+理性预期） | Lucas-Prescott 1970s；DSGE 标准（2000s） |
| （进行中）第 4 级 | 异质性+有限理性+制度变量 | HANK 与预期之争（01 章） |

**规范化的方向感**：每一级都是把上一级的"叙述残留"改写成"参数"。
但规范化有代价——制度叙述里的承诺、信誉、身份，被压缩成参数后
**丢了时间之箭**；第 4 级运动某种程度上是把时间之箭装回去。

## 五、Python 层：语言的形状决定代码的形状

```python
# 恒等式 → 断言/校验（永远为真，用于一致性检查）
# assert Y == C + I + G + NX
# 均衡条件 → 求根/不动点（求解除法）
# sol = scipy.optimize.root(excess_demand, p0)
# 行为方程 → 可微分结构（欧拉方程残差=0 是求解目标）
# 制度叙述 → 场景参数集与注释（regime 字典：policy_regime = {"phi_pi": 1.5, ...}）
```

本家族实验 [multiplier_accelerator.py](experiments/multiplier_accelerator.py)
是"行为方程+恒等式"最小组：乘数（消费函数）+加速数（投资函数）+
收入恒等式——三句话联立成二阶差分方程，特征根判据与数值行为
互为断言（语言的逻辑性质变成了代码的 assert）。

## 六、不足层

- 制度叙述至今没有形式语法——本章的分类（承诺/史鉴/身份）是描述性的，
  不是生成的；"制度变量化"（institution-as-variable）仍是半成品
- 翻译损耗没有度量：同一政策文本，两位宏观学家译出的参数可以差一倍，
  这条"翻译方差"从未被系统研究
- 中文语境多一层翻译：泰勒规则式的政策语言与"逆周期调节/跨周期调节"
  的规划语言之间的对表工作刚刚开始（[社会主义宏观支](讲透社会主义宏观经济学/)）

## 👁 这章给了你什么新眼睛（认知升维）

- **先认等号再读句子**：看到任何宏观命题，先问它的等号是会计恒等、
  均衡条件还是行为假设——三类等号的可反驳性完全不同
- **翻译即理论**：把制度叙述译成模型（或反向）每一步都在做理论选择，
  丢了什么要写进脚注
- **参数是制度的价格标签**：φ_π、μ 这些希腊字母背后是制度承诺；
  改制度=改参数，改参数≠改制度（这正是下一章卢拉斯批判的主题）
