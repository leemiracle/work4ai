# 讲透宏观经济学 · 总量之学：增长、波动与政策

> **宏观经济学 = 把一个经济体当作一个整体来研究的学问**——总产出如何增长、
> 物价与就业如何波动、货币与财政政策能否且如何托底。
> 它的全部张力在一句话里：**由亿万个体的选择加总出的总量，
> 何以能被少数几个变量（Y、i、π、u）的模型捕捉？**
>
> GB/T 13745：79013（经济学·二级学科，三级明细两支：西方宏观/社会主义宏观）。
> 宇宙：[讲透经济学](../README.md)（2026-09-07 GB13745 扩展波4 建族）。

## 一、诞生

宏观经济学不是自古就有的学科，它是**大萧条的应急产物**：

1. **1936 凯恩斯《就业、利息和货币通论》**——诞生时刻。大萧条里
   "经济会自动回到充分就业"的古典信条失灵，凯恩斯给出有效需求不足的
   解释与政府干预的依据。"宏观/微观"这对词 1933 年由 Frisch 首创
   （Ragnar Frisch 1933 提出 macro/micro/dynamic 术语，1969 首届诺贝尔奖）。
2. **1939/1951 两条建制化线**——丁伯根 1939 建成第一个宏观计量模型
   （联立方程拟合美国经济，宏观从叙述变成可估计系统）；
   萨缪尔森 1948 教科书把凯恩斯与新古典嫁接为"新古典综合"。
3. **两次范式地震**——1970s 卢卡斯批判与理性预期革命（模型参数随政策
   regime 变化，见 03 章）；2008 金融危机把 DSGE 模型推上审判席，
   催生异质性主体（HANK）与不平等入模（01 章）。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 增长的源泉分解（索洛 1957） | ✅ 方法已解 | 增长=要素投入+余值（TFP），增长核算是宏观最有用的发明 |
| 短期波动的政策乘数（凯恩斯 1936；Fisher 1930s） | 🔄 永恒争论 | 财政货币乘数多大、何时有效——每个时代重估一次 |
| 菲利普斯曲线（1958）还有多平 | 🔄 前线 | 2021-2023 全球通胀归来后重新成为主战场 |
| 货币中性与否（长期/短期之分） | 🔄 共识脆弱 | "长期中性短期非中性"是教科书共识也是每个危机的争点 |
| 卢卡斯批判能否被真正驯服 | ❌ 未解 | 深参数不变性从未被证明，只是被约定（03 章 §3） |
| 金融危机与宏观的整合（Minsky 时刻） | ❌ 未解 | 金融摩擦进 DSGE 是补丁，不是解决 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 代表性主体（一个消费者代表全体） | 模型可解析、可估计 | 分布效应全部隐形——2008 后被 HANK 推翻主流化（01 章） |
| 理性预期（Muth 1961/卢卡斯 1970s） | 政策分析与微观基础的门票 | 认知假设过强；Moll 2025 公开质疑（01 章） |
| 均衡作为解概念 | 存在性/可计算性的框架（03 章） | 失调、多重均衡、协调失灵被挤到边缘 |
| 名义粘性（新凯恩斯） | 货币非中性的微观基础 | 粘性的微观证据永远吵不完（菜单成本有多大） |
| 加总：一个"总资本"存量存在 | 总量生产函数可用 | 资本加总悖论（剑桥资本论战，见 [讲透生产力经济学](../讲透生产力经济学/) 03 章） |
