# 讲透价格学原理 · 均衡、弹性与影子价格

> **定位**：这支负责价格学的理论总纲——均衡价格论、弹性理论、广义价格
> （影子价格/要素价格/机会成本）。GB/T 三级"价格学原理+广义价格学"归组于此。

## 诞生

1890 年 Marshall《经济学原理》用剪刀两刃终结"价值由劳动还是效用决定"
的单边争论；弹性概念同步入册。广义价格线：1939 年 Kantorovich 的
影子价格（对偶变量）把"价格"从市场现象扩展为**任何配置问题的对偶量**；
机会成本传统（奥地利学派）与之呼应——价格学原理=市场价+计算价+心理价
三层价格观。

## 核心问题（3-5 条）

- ✅ 已解：均衡价格的存在与比较静态（剪刀框架，家族 [00 章](../00-体系结构.md)）
- ✅ 已解：弹性作为一切干预后果的枢纽参数（转嫁/管制/补贴全部由它定分账）
- ✅ 已解：影子价格=约束松紧度（LP 对偶；与 [讲透数学·讲透优化](../../../讲透数学/讲透优化/)
  共管）
- 🔄 前线：价格的信息维度 vs 分配维度的统一评价框架（机制设计）
- ❌ 未解：资产价格（含泡沫）与商品价格的统一理论（金融侧归
  [讲透金融学] 家族——并行 lane，文字互认）

## ✨这支最美的一个事实

同一个线性规划里，三种资源的对偶变量可能是 3.2、1.1、**0**——
影子价格为零意味着"这个约束根本不卡"。**"值钱"不是物品的属性，
是约束系统的属性**：换一道工艺，同一吨原料的影子价格立刻改写。
市场价与计算价在这一条上完全同构。

## 假设与依赖

供需曲线稳定可估（比较静态的命门）；偏好与技术可入矩阵（影子价格
路线的命门——Hayek 的 tacit knowledge 批评永远悬在头上）。

## 教材锚
