# 讲透价格学 · 价值的货币表达及其治理

> **价格学 = 研究"价格如何形成、又如何被治理"的学问**——市场价格
> （供需剪刀）、政府价格（支持价/限制价）、管制品价格（Ramsey/价格帽）

> 又是分配（谁付钱）——动价格的每只手都在同时动这两样东西。**

## 一、诞生（三个原生问题）

1. **价格由什么决定（1890）**——Marshall 的剪刀：需求与供给像剪刀的两刃，
   问"哪一刃剪的"没有意义。均衡价格论取代单方面的价值论（劳动价值/
   效用价值），价格学有了统一框架。
2. **没有市场时价格是什么（1939/1945）**——Kantorovich 在苏联用线性规划
   解计划配置，发现对偶变量天然是一套"影子价格"——**价格是可以被
   算出来的**；Hayek 1945 反驳：分散知识只有价格能汇聚。社会主义计算
   争论（ Lange-Mises-Hayek）由此成为价格学的理论深水区。
3. **政府该怎么定价（1927/1983）**——Ramsey 逆弹性定价（成本递减行业
   最小扭曲保本）；1983 年 Littlechild 为英国电信设计 RPI−X 价格帽——
   规制经济学两大支柱，全世界的电价水价气价至今活在这两个框架里。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 均衡价格的存在与稳定性（Walras/Marshall） | ✅ 框架成熟 | 价格=出清市场的稀缺性显示器 |
| 税负转嫁定律（弹性小者纳税） | ✅ 已证明 | 法定归宿≠经济归宿——本家族实验可复现 |
| 影子价格=LP 对偶（Kantorovich 1939，1975 诺奖） | ✅ 已证明 | 计划者也能"算出"价格，但算不出知识（Hayek） |
| Ramsey 定价与预算平衡（1927/Boiteux） | ✅ 已证明 | 成本递减行业的次优定价定理 |
| 价格上限/下限的福利损失 | ✅ 框架成熟 | 支持价造过剩、限制价造短缺——干预的几何学 |
| 1984 双轨制并轨的路径 | ✅ 已完成（史实） | 中国价格改革：增量市场化并轨的独例 |
| 数字时代算法定价（个性化/动态）的规则 | ❌ 未解 | 价格歧视的福利边界在算法定价下被重写 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 供需曲线可观察/可估计 | 干预的后果可算 | 真实弹性估计误差大（政策数字的软肋） |
| 弹性外生（不随政策变） | 转嫁分析有闭式 | 长期弹性/行为反应使预测失效（香烟税悖论） |
| 成本可归集（分摊到产品） | 成本加成定价可行 | 联产品/共用成本的分摊任选——"成本"不是物理量 |
| 单一价格（无歧视） | 教科书福利分析成立 | 现实定价几乎全是结构化歧视（版本/人群/时段） |
