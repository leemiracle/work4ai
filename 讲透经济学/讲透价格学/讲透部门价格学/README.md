# 讲透部门价格学 · 农产品、公用事业与要素的价格

> **定位**：这支负责具体部门的价格形成与治理——农产品支持价、公用事业
> 规制价、房地产价格、劳动力与土地等要素价格。GB/T 三级"部门价格学"
> 落位于此。

## 诞生

部门价格学是价格学原理的"落地页"：1930s 美国农业调整法（支持价与
休耕补贴）、1927 Ramsey 定价与二战后各国公用事业国有化（政府定价
成为欧洲常态）、中国 1984 莫干山会议后"调放结合"的部门闯关序
（农产品先行、双轨过渡、1992 并轨）。每一条部门价格史都是
"原理×政治"的乘积。

## 核心问题（3-5 条）

- ✅ 已解：农产品支持价的长周期后果（库存-倾销-依赖回路，家族
  [02 章](../02-语言特征.md)反直觉发现）
- ✅ 已解：公用事业定价三件套（Ramsey/两部制/价格帽 RPI−X——家族
  [03 章](../03-可构造与结构.md)）
- ✅ 已解：房租管制长期降低供给数量与质量（租控百年史的标准结论）
- 🔄 前线：电价市场化（现货负价、容量与辅助服务分账——家族 [01 章](../01-近五年创新.md)）
- ❌ 未解：数据要素定价（非竞争性商品的定价悖论）

## ✨这支最美的一个事实

电力现货市场里**价格可以为负**：风大夜深、需求低谷，风机宁可倒贴
让你用电（停机的成本更高）。"负价格"一举击穿"价格=成本+利润"的
民间公式——价格是**出清的信号**，不是成本的账单。能读懂负电价，
就读懂了价格学的第一课。

## 假设与依赖

各部门价格干预的可执行性（无套利、无规避）；规制者信息充分
（成本可审计——Averch-Johnson 效应提醒：回报率规制会诱导过度资本）。
