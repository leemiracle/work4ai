# 04 · 价格学转代码：从剪刀到对偶的走廊

> **本章回答五问之五（本家族：讲透价格学）。**
> 三件套：**可机械化边界**、**代码走廊**、**工程师落点**。
> 价格学的可算部分出奇地整齐：线性世界全部闭式，非线性世界交给
> 规划求解器——真正的难题在**弹性估计**（数据侧）。

---

## 一、可机械化边界（为什么边界画在这里）

| 问题类 | 可机械化程度 | 边界原因 |
|--------|-------------|---------|
| 供需求解（线性/常数弹性） | ✅ 完全 | 闭式几行 |
| 税负转嫁与福利分解 | ✅ 完全 | 本家族实验；t² 律解析 |
| Ramsey 定价 | ✅ 完全 | 二次规划（scipy 一行） |
| 影子价格 | ✅ 完全 | LP 对偶变量（linprog 现成） |
| 价格指数编制（CPI 小样） | ✅ 完全 | Laspeyres/Paasche/几何平均 |
| 弹性估计 | 🟡 计量 | 识别问题：价格内生（促销择时） |
| 动态/个性化定价 | 🟡 ML+优化 | 需求学习（bandit）+约束（合规） |
| 通胀叙事/公平判断 | ❌ 尚未 | 规范权重，不是计算问题 |

**判据一句话**：价格作为**解**（均衡/对偶）可算；价格作为**行为**
（弹性、反应）必须估计；价格作为**判断**（公平）只能透明化。

## 二、代码走廊（五条）

### 走廊①：供需-税负-支持价（本家族实验）

[`experiments/tax_incidence_price_support.py`](experiments/tax_incidence_price_support.py)：
买卖两向征税等价断言、弹性归宿断言、支持价的政府收购与福利恒等式
（ΔCS+ΔPS+ΔGov=−DWL 逐项对账）。

```python
pd, ps = solve_equilibrium(t)          # p_d − p_s = t 联立供需
share_buyers = es / (es + ed)          # 转嫁份额（弹性式）
```

### 走廊②：Ramsey 定价（QP）

```python
# min Σ (p_i − mc_i)² * k_i  s.t. Σ (p_i − mc_i)·q_i(p) >= F
from scipy.optimize import minimize    # 或解析：加价率 ∝ 1/弹性
```
输出各用户段的"最小扭曲加价表"——把 λ（公共乘子）扫一遍，画出
效率-公平前沿（加价结构随 λ 变化的政治菜单）。

### 走廊③：LP 影子价格（Kantorovich 复原）

```python
from scipy.optimize import linprog
res = linprog(c, A_ub=..., b_ub=...)   # 资源配置 LP
shadow = res.ineqlin.marginals         # 对偶变量=影子价格
```
例：两种产品争三种资源（工时/原料/运力）——对偶输出告诉你哪种资源
"卡脖子"（影子价格>0）、哪种白给（=0）。50 行复原 1939 年的
Kantorovich 场景，直观胜过十页讲解。

### 走廊④：价格指数小样（CPI 的解剖）

```python
laspeyres = Σ(p1·q0)/Σ(p0·q0)         # 基期权重
geomean   = exp(Σ w0·ln(p1/p0))       # 链式几何（现代标准）
```
用自家消费小样编一个"个人 CPI"——理解权重、替代偏差、链式修正
最快的路（01 章 shrinkflation 的度量现场）。

### 走廊⑤：动态定价沙盘（工业级入口）

价格 bandit：需求模型（弹性+噪声）× 学习策略（ Thompson sampling）
× 约束（价格区间、库存、合规）。输出：收敛到的定价 vs 最优定价的
regret 曲线。与 [讲透商业经济学](../讲透商业经济学/) 04 章走廊④
（双边定价）共用仿真底座。

## 三、工程师落点（这些东西在谁家产线上）

1. **公用事业计费系统**：阶梯价/分时价/容量价的计费引擎（走廊②的
   规则化），电网营销部的日常。
2. **电商与出行定价引擎**：弹性学习+动态调价（走廊⑤），合规边界
   （大数据"杀熟"禁区）内做优化。
3. **政策分析模型**：税负归宿模拟器（走廊①）、碳价情景（走廊③）——
   智库与价格主管部门的分析件。
4. **企业定价 SOP**：成本加成→价值定价的迁移工具链（成本管理学支
   的数字化）。

## 四、✨美之时刻（⑧要件）：res.ineqlin.marginals——一行代码读到 1939 年

**陈述**：`linprog` 解完资源分配，打印对偶变量：运力 3.2、工时 0、
原料 1.1——**"0"的含义是：这个约束不卡，再加一万单位产出不变**。
**为什么美**：*意外*——"值不值钱"不是物品的属性，是约束系统的属性；
同一吨原料换个工艺矩阵，影子价格立刻改写。Kantorovich 用它算计划，
今天你用它算云资源调度（spot 价=影子价格的市场化），数学没有换过。
**怎么亲历**：走廊③把资源限量调到无穷大，看影子价格怎样"啪"地归零。

## 五、反直觉发现（⑥要件）

代码化边界的教学版：**转嫁闭式最可靠的部分是"结构性结论"（谁钝谁付、
楔子对称），最不可靠的部分是"数字"（弹性估计）**。政策数字的争议
九成在参数、一成在结构——分清二者，评论的质量立分高下。

## 👁 认知升维（⑨要件）

**解-估-判三分眼**：任何定价问题先归档——是"解"（可算）、"估"
（可测）还是"判"（可透明）？三者对应完全不同的工程栈：求解器/
实验平台/规则引擎。归错档的系统（把"判"当"解"做的算法定价）
迟早上新闻。
