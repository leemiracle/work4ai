# 讲透成本管理学 · 定价的成本基础

> **定位**：这支负责"成本如何被核算、归集与分摊，又如何成为定价的
> 基础"——从制造成本法到作业成本法（ABC）到目标成本法。GB/T 三级
> "成本管理学"落位于此。

## 诞生

成本管理随科学管理运动成型（1920s 标准成本法）；1980s 作业成本法
（Cooper & Kaplan）解决制造费用分摊失真——机器小时占比上升使
"人工分摊"系统性扭曲产品成本；1990s 目标成本法（日本成本企划
传统）反转定价逻辑：**市场价 − 目标利润 = 允许成本**（从成本加成
到价格减成的范式翻转）。

## 核心问题（3-5 条）

- ✅ 已解：共用成本分摊的任意性（任何分摊基准都是选择——"真实成本"
  半是判断）
- ✅ 已解：作业成本法的改进（按因果动因归集——成本准确性↑）
- ✅ 已解：目标成本法的逻辑（价格驱动成本而非成本驱动价格）
- 🔄 前线：云时代的成本分摊（共享算力/平台研发费如何进产品账）
- ❌ 未解：边际成本≈0 商品（软件/数据/内容）的成本概念重建

## ✨这支最美的一个事实

"价格=成本×(1+加成率)"是文明的定价史，但**成本本身是会计选择的
产物**：同一工厂、同一年度，用人工工时分摊与用机器小时分摊，
同一款产品的"成本"可以差出 30%。目标成本法把这层窗户纸捅破——
先看市场允许你花多少，再倒逼设计。**定价的起点从来不在车间，
在市场**（价格学对成本学的百年纠正）。

## 假设与依赖

成本对象可界定、动因可计量（ABC 的前提）；成本数据可审计
（政府定价"准许成本+合理收益"的技术前提——被规制者的成本报表
永远是博弈的战场）。
