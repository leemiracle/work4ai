# 讲透注册会计师审计 · 卖独立意见的行业

> **定位**：这支负责财报审计（社会审计/独立审计）——注册会计师
> 受托对财务报表是否在所有重大方面公允反映发表**独立意见**。
> 本学科的主战场：四大+本土所、上市公司年报审计、IPO 与证券服务。
> GB/T 79039 无三级明细——**自定主干支**。

## 诞生

1854 爱丁堡会计师公会（职业化起点）→ 1929-1934 美证券法确立
法定财报审计（看门人制度化）→ 2001-2002 安然/安达信事件与
萨班斯法案（PCAOB 监管、审计咨询分家）→ 2021 康美案
（中国证券责任司法定价元年）。

## 核心问题（3-5 条）

- ✅ 已解：风险导向审计方法论（了解业务→评估风险→应对）
- ✅ 已解：统计抽样的判定纪律（家族实验 Part A 的 3.0/n 律）
- 🔄 前线：责任与收费的杠杆不对称（亿元赔偿 vs 千分之一费率）
- ❌ 未解：期望差距——公众要保证、职业给合理确信，永难合拢
- ❌ 未解：客户付费结构下的独立性（看门人被看门者雇佣）

## ✨这支最美的一个事实

审计意见书是全球印刷量最大的"负面断言"文本：它从不承诺
"报表是真的"，只承诺"我们没有找到足够的理由怀疑它"——
用双重否定撑起了几十万亿美元市值的信任基础设施。

## 假设与依赖

- 独立性可维持（形式+实质）——本支最脆弱的地基
- 重要性分级（真话分级收费）；抽样代表性（统计地基）
- 依赖[讲透会计学](../../讲透会计学/)的账（对象）、
  [数学宇宙·数理统计](../../../讲透数学/讲透数理统计/)的方法（工具）
