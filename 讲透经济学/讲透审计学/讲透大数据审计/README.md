# 讲透大数据审计 · 全量证据的技术现场

> **定位**：这支负责数字化时代的证据学——全量筛查、联网审计、
> 智能取证、持续监控。它不是"审计+电脑"，而是证据基础的迁移：
> **从"抽出来的样本"迁往"全部的数字"**。
> GB/T 79039 无三级明细——**自定主干支**（数字化侧）。

## 诞生

三步走：电算化审计（1980s-90s，计算机当作被审对象）→
计算机辅助审计（CAATs，2000s，计算机当作工具）→
大数据审计（2015-，全量数据+多维关联+智能分析成为方法论本体）。
中国国家审计的"金审工程"（一期 2002 起）是全球最大规模的
联网审计实践；2020s 大语言模型进入底稿与取证环节。

## 核心问题（3-5 条）

- ✅ 已解：全量筛查工具箱（Benford/重复值/关联网络/断层扫描——家族实验 Part B）
- ✅ 已解：多源数据关联（工商/税务/司法/资金流的图式取证）
- 🔄 前线：持续审计（监管侧已国家化、事务所侧受数据权属制约）
- 🔄 前线：AI 取证的可采性（异常列表能否当审计证据写入底稿）
- ❌ 未解：算法黑箱与职业复核的接口——谁验证了模型

## ✨这支最美的一个事实

Benford 定律让数字自己告状：跨数量级的自然金额首位数字服从
log₁₀(1+1/d) 分布（1 开头 30.1%、9 开头 4.6%）——造假者编造
"看起来普通"的金额时，首位分布被压平，无需任何统计知识的
舞弊者仍会被自己的数字出卖（家族实验实测：自然金额 MAD
0.0055 密合，人为金额 0.0665 直接不密合）。
