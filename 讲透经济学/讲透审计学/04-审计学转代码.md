# 04 · 审计学转代码：从抽样手册到异常引擎

> **本章回答五问之五（本家族：讲透审计学）。**
> 三件套：**可机械化边界 → 代码走廊 → 工程师落点**。
> 核心判断一句话：审计的"统计外壳"全部可代码化
> （抽样/筛查/复核流水线），"判断内核"一行也不能——
> 代码改变证据的产量，不改变签字的位置。

---

## 一、可机械化边界

| 环节 | 可机械化 | 形态 |
|------|---------|------|
| 抽样计划（样本量/上界/判定） | ✅ | 泊松上界闭式解——审计软件的内置件 |
| 全量筛查（Benford/重复/断档/关联网络） | ✅ | 确定性检验，毫秒级（实验 Part B） |
| 函证状态机（发函/回函/差异跟踪） | ✅ | 流程系统 |
| 底稿生成与交叉索引 | ✅ | 模板+LLM 摘要（2023- 起实务落地） |
| 持续审计监控（指标/阈值告警） | ✅ | 事件驱动管道（监管侧已国家化：金税四期） |
| 异常的**核实** | ❌ | 疑点要人取证——样本从交易层移到疑点层（03 章 §4） |
| 意见与签字 | ❌ | 责任不可外包给代码（01 章责任链争论的技术面） |

**判据复述**：世界的统计性质可构造；人的隐藏意图不可构造。
**代码是审计师的显微镜，不是审计师。**

## 二、代码走廊

### 走廊①：属性抽样引擎（本家族实验 Part A）

```python
def upper_bound(n, k, conf=0.95):        # 泊松精确上界（二分求 λ）
    # 零偏差: 上界 = -ln(1-conf)/n = 3.0/n  （n=60 → 4.99%）
    # 一偏差: λ 使 e^{-λ}(1+λ)=0.05 → 上界 7.91%
    ...
# 判定规则三行：上界 < 可容忍率 → 接受；否则扩样或走实质性程序
```

审计软件里的"统计抽样模块"就是这二十行的工业化包装；
[experiments/audit_sampling_benford.py](experiments/audit_sampling_benford.py)
是可跑的最小内核（含平方根律断言：样本翻两番，上界减半）。

### 走廊②：Benford/异常筛查管道

生成首 digit 分布 → 卡方 + Nigrini MAD 分区 → 按可疑度排序输出
短名单。工程要点不是统计（五行），是**数据接入**：
科目余额表/凭证库/银行流水的字段映射与清洗占 90% 工作量
（与[讲透会计学/04-会计学转代码](../讲透会计学/04-会计学转代码.md)
走廊③共用同一套数电票管道——造账侧标准化了，验账侧自动受益）。

### 走廊③：持续审计监控

事件源（ERP 业务事件/数电发票/资金流水）→ 规则与统计基线
（比率/趋势/同环比断层）→ 告警队列。技术上是标准的数据管道
+规则引擎；制度上的分岔在**谁运营**：企业内审（内控预警）与
监管侧（联网核查）已经跑通，事务所侧受限于数据权属仍在试点。

## 三、工程师落点

| 场景 | 落点 | 备注 |
|------|------|------|
| 审计作业软件 | 抽样引擎+底稿自动化+函证平台 | 四大与本土所的自研/采购主战场 |
| 监管科技（RegTech/Suptech） | 全量核查、异常报送、联网审计 | 金税工程式国家级系统；国家审计支的工程侧 |
| 内审数字化 | 持续监控+过程挖掘（process mining） | 从"查结果"转向"查流程" |
| ESG 鉴证工具链 | 排放数据采集→核验→报告 | 证据学面对物理量的重写现场（01 章） |

**职业建议定位**（诚实判词）：审计数字化的工程岗位是
"数据工程+规则引擎"为主、统计为辅、会计准则知识做护城河——
纯算法能力可替代性强，**"懂准则的证据工程师"稀缺**。

## 四、反直觉发现（⑥）

**最容易自动化的不是审计的体力活，是它的脑力外套。**
全量筛查（毫秒）取代的恰恰是老审计师的"分析程序直觉"
（数字感、比率异常感）——直觉本质是低带宽统计检验，
机器带宽无限；但**"对管理层说谎时的不适感"没有数据来源**，
无法自动化。审计师的不可替代部从"算得准"迁移到"闻得出"。

## 五、✨美之时刻（⑧要件）：一条断言两种职业

**陈述**：`assert ub_zero < tolerable < ub_one`——本家族实验里
这行断言压缩了审计判定学的全部日常：同样抽 60 笔，
零偏差可接受、一偏差即拒绝，**结论翻转于一笔**。
而这条断言的左右两边，正是审计师与统计师共用而不知的
同一条泊松公式。

**为什么美**：*统一*——注册会计师的"可容忍偏差率"、
质检员的 AQL、药物审评的缺陷率上限，是同一行代码在三个行业
的复用；抽样判定学是人类少有的真正跨行业通用技术。

**怎么亲历**：在实验 Part A 里把可容忍率从 7% 改为 5%，
看判定如何从"悬崖边"变成"全否"——一行参数，重演
准则制定者每年争论的"多严才算严"。

## 📌 收束与认知升维（⑨要件）

**这章给了你什么新眼睛**：
- **显微镜眼**：评估任何"智能风控/智能审计"系统时只问一句：
  它是显微镜（放大证据产量）还是替身（代替签字）？
  前者真实存在，后者至今是营销话术。
- **数据权属眼**：持续审计的瓶颈从来不是算法而是**谁有权
  连续拿到谁的数据**——制度设计决定技术边界，监管侧先跑通
  正是因为权属最清晰。
