## 一、诞生

1. **1854 爱丁堡会计师公会**——苏格兰破产清算纠纷催生职业团体：
   账目争议需要一个**与双方都无关**的第三方，独立性成为商品。
2. **1929 大萧条→1933/34 证券法**——法定审计诞生：上市公司报表
   必须经独立会计师签证。审计从"雇主私聘的查账人"变成
   **资本市场的公共看门人**（watchdog）。
3. **2001 安然-安达信坍塌→2002 萨班斯法案**——"审计+咨询"利益冲突
   暴露，独立性监管重构（PCAOB 设立）；五大会计师事务所变四大。
4. **2021 康美药业案**——中国证券集体诉讼首案：财务造假 89 亿元级，
   独立董事连带巨额赔偿，"独董不独、花瓶有价"的时代结束；
   审计责任边界之争从此有了中国判例坐标。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 抽样的统计纪律 | ✅ 1930s- | 属性抽样/变量抽样：查多少、发现什么、敢下什么结论（本家族实验） |
| 风险导向审计模型 | ✅ 2000s 成形 | AR=IR×CR×DR：把职业直觉变成可分配的预算问题 |
| 审计能否"证明"报表正确 | ✅ 已解（答案是不能） | 合理保证≠绝对保证——审计意见的语言学（02 章） |
| 期望差距（expectation gap） | ❌ 永久 | 公众要"保证没错"，审计只能给"合理确信无重大错报" |
| 审计独立性与市场结构 | 🔄 前线 | 四大寡头+客户付费：看门人由被看管者发工资的结构性扭曲 |
| 全量数据时代抽样还剩多少 | 🔄 前线 | 数据审计改写证据学基础（01 章） |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 抽样代表总体 | 有限成本覆盖大总体 | 抽样风险永远存在（上界只能压缩不能归零） |
| 重要性水平 | 聚焦重大错报 | "不重要"的错报可以合法漏网——重要性是分级的真话 |
| 独立性（形式+实质） | 意见有公信力 | 独立性本身是被购买的——付费结构天然侵蚀它 |
| 内部控制可信时少查 | 审计成本骤降 | 内控失效的系统化舞弊恰好绕开抽查（安然式） |
