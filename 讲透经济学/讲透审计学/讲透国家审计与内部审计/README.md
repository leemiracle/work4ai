# 讲透国家审计与内部审计 · 权力的两双眼睛

> **定位**：这支负责审计的另外两种委托关系——**国家审计**
> （政府审计：审计机关对公共资金与权力的监督，中国为审计署系统）
> 与**内部审计**（组织内部对风险与治理的自我监督）。
> 与注册会计师审计共用证据学，但**责任结构完全不同**：
> 一个向市场签意见、一个向权力提报告、一个向治理层服务。
> GB/T 79039 无三级明细——**自定主干支**。

## 诞生

- 国家审计古已有之：中国古代上计制度（战国-汉，郡国岁末报账）
  与科举式考功、西方 exchequer（财政部词源即"棋盘式账桌"）；
  现代国家审计 1983 中国审计署成立（宪法 1982 确立审计监督制度）。
- 内部审计 1941 年 IIA 成立（纽约）为职业化标志——
  从"查账的分部"进化为"治理、风险、控制"三线模型的中坚
  （三线模型 2020 改版为"三线+管理/governing body"）。

## 核心问题（3-5 条）

- ✅ 已解：国家审计的制度定位（审计全覆盖+经济责任审计）
- ✅ 已解：内审从合规检查到风险导向的职能进化（ assurance + advise 双轮）
- 🔄 前线：审计结果公告与问责联动（公开透明度的边际效应）
- 🔄 前线：党和国家监督体系中审计与纪检/巡视的协同边界
- ❌ 未解：内部审计的独立性与"组织内部人"身份的永恒紧张

## ✨这支最美的一个事实

"上计"制度让两千年前的地方官每年冬天把户口、垦田、钱谷
收支的数目刻在木券上送到京师核对——**数据报送+中央核验+
问责奖惩**，现代国家审计的全部要素在竹简时代已经配齐；
变的只是载体（木券→联网审计平台），不变的是
"让权力对数字负责"的制度直觉。

## 假设与依赖

- 国家审计假设：公共受托责任存在且可计量（预算/决算/绩效）
- 内审假设：管理层愿意购买对自己的批评（治理成熟度决定其效力）
- 方法层完全依赖家族层证据学（00 章三段机）；工具层走向
  [讲透大数据审计](../讲透大数据审计/)（联网审计/全量数据核查）
