# 04 · 交通运输经济学转代码：网络、四步与瓶颈的走廊

> **本章回答五问之五（本家族：讲透交通运输经济学）。**
> 三件套：**可机械化边界**（哪些问题原则上可算）、**代码走廊**（最小可跑实现）、
> **工程师落点**（这些东西在哪家公司哪条产线里跑）。

---

## 一、可机械化边界（为什么边界画在这里）

| 问题类 | 可机械化程度 | 边界原因 |
|--------|-------------|---------|
| 固定需求网络均衡（UE/SO） | ✅ 完全 | 凸规划+现成算法（Frank-Wolfe/内点） |
| 拥堵定价（最优费率结构） | ✅ 完全 | 对 UE 目标加边际成本费即 SO |
| Vickrey 瓶颈动态费 | ✅ 完全 | 半解析：三角费率表闭式可写 |
| 方式分担（Logit 系） | ✅ 参数化 | 结构假设（IIA）可错，但可算 |
| 四步全链条 | 🟡 半机械 | 各环可算，环间无一致均衡（03 章裂缝） |
| 土地利用-交通反馈 | 🟡 需仿真 | 一致均衡需迭代或 ABM，收敛无保证 |
| 个体级行为异质性 | 🟡 需仿真 | 连续近似崩溃，离散主体（MATSim）接管 |
| 事故/可靠性定价 | ❌ 尚未 | 方差入泛成本无共识结构 |

**边界判据一句话**：凡能写成"势函数+约束"的可算（优化接管），只剩"多主体
策略互动无势"的进仿真（博弈/ABM 接管），依赖"不可观测偏好分布"的留给计量。

## 二、代码走廊（四条，从 30 行到工业级）

### 走廊①：网络均衡与拥堵定价（本家族实验）

[`experiments/congestion_pricing.py`](experiments/congestion_pricing.py)：三个部件——
Pigou 双路闭式解、Braess 悖论流量分配、仿射双路 MSC 通行费。核心模式：

```python
def total_cost(x1):            # x2 = D - x1
    return x1*c1(x1) + (D-x1)*c2(D-x1)   # 社会目标
# UE 由 c1(x1)=c2(x2) 解；SO 由 total_cost 的极值解；差额=外部性=通行费
```

工业级对应：BPR 路阻 + Frank-Wolfe 全网络分配（开源交通分配库如
aequilibrae/TransMobSim 皆此模式）。

### 走廊②：四步模型的最小实现（生成→分布→分担→分配）

```python
T_ij = k * O_i * D_j / c_ij**gamma          # 重力模型（出行分布）
P_car, P_bus = softmax([-GC_car, -GC_bus])   # Logit 方式分担（温度=1）
x = solve_ue(network, T)                     # Beckmann 凸规划（走廊①）
```
裂缝在串联处（03 章表）——教学实现不回环，生产实现必须迭代或转 ABM。

### 走廊③：Vickrey 瓶颈模拟（动态拥堵）

固定容量 μ 的瓶颈，N 人从家出发赶 t* 到岗：数值模拟 FIFO 排队长度，
输出"出发率-排队长度-到达时刻"三线图；叠加三角费率（峰值 μ/小时），断言
**排队面积=费率收入**（时间换货币守恒）。50 行 numpy 可完成。

### 走廊④：ABM 一瞥（MATSim 模式）

每个 agent 一条"活动-出行链"计划，日复一日：执行→打分（泛成本）→变异
（换路/换方式/换时刻）→选择。无势函数、无全局均衡声明，只有**协演化收敛**。
这是走廊②③失效后（异质性、反馈）的接盘侠，代价是算力与"收敛了吗"的判据。

## 三、工程师落点（这些东西在谁家产线上）

1. **网约车动态定价与调度**：Uber/Lyft/滴滴的 surge=短期拥堵定价的镜像
   （价格清市场而非排队）；ETA 预测=路阻函数的机器学习化。
2. **航空收益管理**：座位=易逝容量， Booking limit/竞标价格控制
   （EMSRb 算法）——航空支的产业主页，与[讲透旅游经济学](../讲透旅游经济学/)
   共管。
3. **城市"交通大脑"**：信号配时（排队论）、匝道控制（瓶颈管理）、
   公交实时调度（Mohring 效应的运营版）。
4. **货运网络优化**：空箱调拨（库存论）、班期与多式联运衔接（网络流），
   与[讲透物流经济学](../讲透物流经济学/) 04 章共管。

## 四、✨美之时刻（⑧要件）：三角费率表——时间的铸币厂

**陈述**：Vickrey 瓶颈的最优费率是一张以 t* 为顶点的三角表：早到段每早到
一分钟收费递减至零，晚到段镜像。**跑一遍模拟你会发现：费率曲线在数值上
恰好等于"无收费均衡中的排队等待时间曲线"**。**为什么美**：*意外*——
两件看似无关的东西（排队蒸发、税收产生）形状逐点相同，因为它们是同一个
影子价格序列的两种货币形态。**怎么亲历**：在走廊③里同时画两条曲线
（免费情形的队长×瓶颈容量、收费情形的费率），肉眼比对。

## 五、反直觉发现（⑥要件）

可机械化的边界本身就是反直觉的：**"全城几百万人的自私选路"比"一个路口的
行人心理"更容易算**——因为前者有势函数（凸性），后者没有。复杂度不由
规模决定，由结构决定。

## 👁 认知升维（⑨要件）

**走廊眼**：评估任何决策支持系统时先问三件事——问题有势函数吗（可优化）、
主体有异质性吗（需仿真）、参数可观测吗（需计量）。三问定位系统在
"优化/仿真/计量"三原色里的坐标。你的 GPU 调度器、消息队列、缓存策略
都可以用这双眼睛重看一遍。
