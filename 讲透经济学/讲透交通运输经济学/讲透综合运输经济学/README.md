# 讲透综合运输经济学 · 方式分担的均衡与通道治理

> **定位**：这支负责"五种方式的合奏"——多式联运、运输通道规划、
  方式分担（modal split）的均衡条件、综合交通网的社会评估。
  它是"系统眼"的驻地。

## 诞生

每种运输方式单独研究到上世纪中叶后，"合起来看"的问题浮现：一条煤运通道
该走铁路还是水铁联运？城市间客运该建高铁还是加密航班？中国"综合运输"研究
自 1980 年代成派（北方交大荣朝和《论运输化》为代表），主张运输方式是
"可替代的技术经济选项集合"，国家尺度做通道选择。欧美的对应物是
multimodal transport 与 combinatorial infrastructure 评估（TEN-T 走廊）。

## 核心问题（3-5 条）

- ✅ 已解：方式分担均衡——均衡处各方式泛成本相等（家族 02 章泛成本翻译器）
- ✅ 已解：多式联运的接口经济学（换装成本是方式间贸易的"关税"；
  集装箱把"关税"降到近零）
- 🔄 前线：通道投资的社会评估（高铁 vs 航空 vs 公路的影子价格核算——
  中国"八纵八横"盈利分化之争）
- 🔄 前线：运输结构调整政策（"公转铁""公转水"的费率与规制工具）
- ❌ 未解：MaaS 把方式竞争变成套餐组合后，分担模型的微观基础如何重建

## ✨这支最美的一个事实

方式分担的秘密只有一行字：**均衡落在"各方式泛成本相等"处**——
40 分钟地铁+3 元，对阵 25 分钟开车+15 元停车费，时间价值约 0.8 元/分钟时
市场五五开。政策（修路、降票价、提速）的全部作用，就是移动这条等式的
两边。看懂这行字，就能"读"任何一条交通走廊的客流结构。

## 假设与依赖

泛成本可加总且出行者同质（家族 00 章假设表）；各方式供给相互独立
（忽略运力联动）——联运与替代品的交叉弹性是本支的薄弱环节。
