# 讲透水路运输经济学 · 规模经济的极限

> **定位**：这支负责"水面上的经济学"——船舶规模经济的物理极限、港口与
> 航线的市场结构、班轮联盟的反垄断边界。集装箱是它的工业灵魂。

## 诞生

1956 年 Malcolm McLean 把一辆油轮改装成集装箱船（Ideal X，58 个箱子从纽瓦克
到休斯敦），运输成本开始坍塌。1970-80 年代集装箱船标准化（TEU），全球制造
业布局被重写——Levinson《The Box》(2006) 称之为"改变世界的箱子"。经济学上，
规模经济一路把船推到两万 TEU 量级，直到巴拿马运河、港口水深与班期可靠性
画出物理-经济边界。2021-2022 供应链危机（苏伊士堵塞、洛杉矶港锚地排队）把
港口拥堵经济学推上头条。

## 核心问题（3-5 条）

- ✅ 已解：船舶规模经济的来源（资本/燃料/船员的亚线性增长）与其边界
  （港口装卸率、航道水深、网络班期）
- ✅ 已解：班轮联盟的竞争效应（舱位共享降本 vs 运力协同涨价——反垄断豁免
  之争，美国 2022 海运改革法回应）
- 🔄 前线：运价的极端波动性（2021 集装箱即期价 10 倍暴涨后崩回）——
  易逝容量+寡头供给的经典周期
- 🔄 前线：港口拥堵费与堆场费的设计（拥堵定价从客运复制到货运）
- ❌ 未解：脱碳（IMO 碳强度指标）对航速优化与网络结构的重塑幅度

## ✨这支最美的一个事实

2021 年最荒诞的经济画面：**一个空集装箱的运价一度高过一个满箱货值**——
箱子错位（有船无箱、有箱无船）使"运箱子"本身成为稀缺商品。运输网络的
"容器再平衡"（空箱调拨）是库存论与网络流的合奏，见
[讲透数学·讲透运筹学·讲透库存论](../../../讲透数学/讲透运筹学/讲透库存论/README.md)。

## 假设与依赖

规模经济假设"基础设施跟得上"（港口/航道/集疏运同步扩张）；联盟效率假设
舱位共享不演化为运力卡特尔——两条假设都靠规制维护。
