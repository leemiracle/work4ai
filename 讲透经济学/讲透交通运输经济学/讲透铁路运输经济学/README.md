# 讲透铁路运输经济学 · 自然垄断与定价的百年争论

> **定位**：这支负责"轨道上的经济学"——路网的自然垄断、运价的边际成本定价
> 争论、"网运分离"改革。它是产业组织理论最古老的实验室。

## 诞生

铁路是人类第一个固定成本巨大的网络产业。1844 年英国《铁路管理条例》就开始
管制运价（当时议会以"保护公众免受垄断"之名干预）；Dupuit 同年的桥梁收费论文
（见家族 README）把问题数学化。二十世纪法国围绕国铁与电力展开"边际成本定价
派 vs 预算平衡派"大论战（Boiteux 线），Ramsey 定价与两部制定价都从这场争论里
长出来。当代样本：欧盟"网运分离"（路网垄断+运营竞争）、中国铁路政企分开
（2013 撤铁道部）与高铁定价机制改革。

## 核心问题（3-5 条）

- ✅ 已解：边际成本定价在成本递减行业导致亏损（Dupuit 1844 提出矛盾，Ramsey
  1927 给出"最小无谓损失的保本加价"）
- ✅ 已解：自然垄断的判定（成本函数次可加性，Baumol 1982 可竞争市场理论）
- 🔄 前线：网运分离 vs 一体化的制度比较（欧盟模式与中国模式的绩效之争）
- 🔄 前线：高铁定价——公益线与商业线的交叉补贴与影子价格核算
- ❌ 未解：货运班列化（定点定线）与零散车流的最优组织边界

## ✨这支最美的一个事实

一列已经要开走的火车，多载一名乘客的边际成本几乎为零——**但路网和列车的
固定成本巨大到边际成本定价必然破产**。整部铁路经济学就是这句话的展开：
Ramsey 加价、两部制票价、拥挤定价（高峰列车并非零边际成本）、网运分离。
"边际成本是零，但不能按零卖"——与软件业同病，比软件业早一百年。

## 假设与依赖

成本次可加性（一家经营全网最省）是自然垄断的骨架假设——高铁与货运混跑、
客运专线竞争都会动摇它。高峰时段"边际成本≈0"失效（拥挤与能力扩充成本入场）。

## 教材锚

- Nash（利兹大学 ITS 学派）的铁路经济研究传统（综述与 EU 报告轨）
- 荣朝和《交通运输经济学》（中文语境的网运关系分析）
