# 讲透交通运输经济学 · 位移的定价与路网的治理

> **交通运输经济学 = 研究"位移"这门特殊生意的产业经济学**——
> 它的三个原罪：路网固定成本巨大（自然垄断）、每多运一个人的边际成本趋零（定价难题）、
> 需求随钟点剧烈波动（高峰拥堵）。拥堵、补贴、规制、放松管制，全部由此而来。

## 一、诞生（三个原生问题）

1. **桥该收多少费（1844）**——法国工程师 Dupuit 问：一座桥修好后，过桥的边际成本
   是零，按边际成本定价谁来付修桥钱？他为此发明了**消费者剩余**，运输经济学
   与福利经济学同时诞生。
2. **道路为什么堵死（1920）**——Pigou 在《福利经济学》里画出第一条拥堵道路：
   每个司机只算自己的时间，不算自己加给别人的延误——**外部性**概念的出厂现场。
3. **政府该管航线吗（1978）**——美国《航空公司放松管制法》（Kahn 主持）撤销 CAB，
   票价大跌、枢纽网络成型——产业经济学史上最干净的"规制vs市场"自然实验。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 拥堵的定价（Pigou 1920；Vickrey 1969） | ✅ 理论完备 | 最优通行费=外部延误成本；1998 新加坡/2003 伦敦/2024 纽约先后落地 |
| 用户均衡≠系统最优（Wardrop 1952） | ✅ 已证明 | 自私选路全社会更慢；差值=定价的空间 |
| 均衡的可计算性（Beckmann 1956） | ✅ 已证明 | 均衡=凸优化解，交通规划由此可算 |
| 边际成本定价与成本回收的矛盾（Ramsey 1927/Dupuit） | 🔄 永恒争论 | 路网成本递减行业"定低价亏本、定高价闲置" |
| Mohring 效应与公交补贴（Mohring 1972） | ✅ 已证明 | 班次加密缩短等待——公交有规模经济，补贴有理论依据 |
| 诱导需求到底多大 | ❌ 未解 | 扩路引来的新增出行，长期弹性估计仍吵 |
| 自动驾驶/MaaS 改写成本结构 | ❌ 未解 | 车队资本+空驶定价的均衡尚无定论 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 时间可以货币化（时间价值 VOT 单一） | 一切收益折成钱，项目可比较 | 异质性被平均；谁的时间被摊平谁沉默 |
| 出行者自私且理性（Wardrop 均衡） | 均衡可定义、可计算 | 习惯/信息不完全/错峰柔性被挤出去 |
| 需求可由 OD 矩阵刻画 | 四步模型可跑 | 长期土地利用反馈出圈（见 03 章） |
| 外部性可度量 | 定价可操作 | 度量即政治：拥堵费数字就是选票 |
