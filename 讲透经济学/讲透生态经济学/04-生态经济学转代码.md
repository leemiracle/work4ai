# 04 · 生态经济学转代码：从 ODE 到国民账户管道

> **本章回答五问之一（生态经济学转代码）。**
> 本学科的代码化有三条成熟走廊：**渔业评估**（ODE→配额）、**SEEA/物质流核算管道**
> （记账→审计）、**情景与集成评估**（Kaya→蒙特卡洛）。三件套体例：
> 可机械化边界 → 代码走廊 → 工程师落点。

---

## 一、可机械化边界（为什么这条线画在这里）

| 能算 | 不能算 |
|---|---|
| 生物物理核算：恒等式记账（构造③） | 不可通约价值加总（02 章方言四：多元价值无总账） |
| ODE 与最优控制：MSY、稳态路径、配额方案 | 关系价值：人与自然关系的意义不可参数化 |
| 情景模拟与参数不确定性传播 | 盆地形状的实证识别：数据饥渴，多为事后诸葛亮 |
| 估值计算本身（WTP 均值、置信区间） | "该不该货币化"的元判断 |

**判据**：凡是"守恒律 + 偏好序"能写清的都可机械化；**价值排序本身**不可。
边界外的问题代码不欠你答案——这是本学科对算法乐观主义的免疫力。

## 二、代码走廊 A：渔业管理（最小内核=本家族实验）

本家族 [`experiments/msy_logistic.py`](experiments/msy_logistic.py) 是教育内核；
真实世界的链条是**资源评估→总量设定→执法监测**三级：

| 层 | 干什么 | 典型工具 |
|---|---|---|
| 评估 | 从渔获/声学/CPUE 数据估 r、K、当前存量 | 年龄结构模型（如 NOAA 的 Stock Synthesis） |
| 设定 | TAC=配额：MSY 打安全系数（盆地余量，构造④） | 决策规则模拟（management strategy evaluation） |
| 监测 | VMS 船位、渔获申报、合规率 | 数据管道+异常检测 |

**直觉**：走廊 A 的代码纪律 = 把 03 章构造①②的参数每个都标来源与置信区间——
模型不比参数可信。ITQ 制度（构造②的产权化出口）也在这条走廊上：
配额拍卖与交易平台的撮合逻辑就是机制设计代码。

## 三、代码走廊 B：SEEA/物质流核算管道

**直觉**：给 03 章构造③装上 ETL。数据进（统计年鉴/遥感/监测站）→恒等式记账→
闭合校验→出账本。核心是**复式记账的自动化**：

```
资产账户：期末存量 = 期初 + 增加 − 减少          # 每行可对账
物质流：  投入 = 排放 + 出口 + NAS               # 守恒审计：残差>阈值即报警
GEP 两段式：功能量（吨/立方米/人次）→ 价值量（当量因子×单价）
```

最小实现（纯 Python 字典+断言即可，pandas 供表组织）：

```python
FLOWS = {"国内开采": 100, "进口": 30}
OUTS  = {"排放": 95, "出口": 25, "净存量积累": 10}

def balance_check(flows, outs, tol=1e-9):
    residual = sum(flows.values()) - sum(outs.values())
    assert abs(residual) <= tol, f"物质守恒残差 {residual:+.2f} 吨——账没闭合"
    return residual

balance_check(FLOWS, OUTS)   # 通过=一次 MFA 审计
```

**断言自验应成为核算脚本的默认礼仪**——数据改一行，闭合校验自动重跑。
中国 GEP 试点（01 章）的软件化就在这条走廊：功能量核算模块+空间数据接口
（遥感土地利用×生态系统类型对照表）。

## 四、代码走廊 C：情景与集成评估（IAM 界面）

**最小 IAM 是 Kaya 恒等式**：CO₂ = 人口 × (GDP/人口) × (能源/GDP) × (CO₂/能源)
——四个杠杆各给一条路径，乘出排放情景。往上是碳预算倒推（给定 1.5°C 预算，
反解允许排放路径），与[讲透环境经济学](../讲透环境经济学/)的气候模型走廊
（DICE 类）接轨；参数不确定性用蒙特卡洛传播——工具纪律同走廊 A。

📖 **故事框**：Daly 常说生态宏观模型"参数少到能全部怀疑一遍"——
模型小不是缺点，是审计面小。这与软件工程里"可测试面"是同一个概念。

## 五、工程师落点

- **遥感→核算数据管道**：土地利用分类→生态系统范围账（走廊 B 的输入侧）
- **环境数据工程**：监测站/物联网时序→排放与流量账户
- **双碳核算系统**：Kaya 分解+碳预算仪表盘（企业级碳盘查同构）
- **LCA 工具链**：开源 brightway 等做生命周期物质流——构造③的产品级放大
- 交叉宇宙：仿真基础设施→[讲透计算机科学技术](../../讲透计算机科学技术/)

## 六、✨美之时刻（⑧要件）：同一政策、两种命运（代码亲历）

**陈述**：运行本家族实验断言 A——捕捞强度同为 800（"保守"），初始存量 9000 活到
7236，初始存量 2500 灭绝。相差的不是政策，是**起点在山脊的哪一侧**。

**为什么美**：*几何+不可逆*——1992 年北方鳕鱼禁渔三十年未恢复的原因，
藏在一张相图里；而这张相图你笔记本上 30 行代码就能画。

**怎么亲历**：把 X₀ 从 2700 到 2850 每 10 一扫（改实验一行），
亲眼看盆地边界出现在 2764 附近——政策评估里最贵的知识（"还剩多少余量"）
突然变成了一个可以扫参看到的数。

## 📌 收束与认知升维（⑨要件）

**这章给了你什么新眼睛**：
- **参数来源眼**：生态经济模型的可信度全在参数来源与校准纪律，不在代码长度；
  看到任何"模型显示"，先问 r、K 从哪来、置信区间多宽
- **断言自验礼仪**：核算脚本不带闭合断言，等于账本不带试算平衡表——
  能自动验证的东西就不要靠人眼。
