# 03 · 可构造与结构：四个最小可跑构造

> **本章回答五问之一（可构造与结构）。**
> 生态经济学的"构造"不是公理系统，是**可运行的生物物理-经济耦合结构**。
> 本章给四个最小件：生物侧（捕捞）、经济侧（公地）、会计侧（账本）、系统侧（盆地）。
> 全部可在 30 行 Python 内复现；件①②已落成本家族实验。

---

## 构造① 逻辑斯蒂×捕捞（生物侧最小件）

**直觉**（牧场版）：一块草地，草自长（增速先快后慢），牛来吃。
问：每年割多少草，永远割得下去？

**结构**：dX/dt = rX(1 − X/K) − H。两个参数定生死：内禀增长率 r、承载力 K。
可持续产量的硬顶 MSY = rK/4，位于半容量 X=K/2（00 章美之时刻）。

**最小数值**：r=0.4、K=10⁴ → MSY=1000。本家族实验断言 B：捕捞 1200（超顶 20%）
时，任何初始存量都灭绝——**MSY 是硬顶不是参考值**。

| 买到 | 付出 |
|---|---|
| 可持续产量可算；总量管制（TAC）有参照点 | 单物种、无年龄结构、无环境波动——真实渔业都是三维问题 |

## 构造② 开放进入（经济侧最小件，Gordon 1954）

**直觉**（公地版）：海是公地，船是私产。有利可图→新船进来，直到利润为零。

**结构**：捕捞 H = qEX（努力量 E×存量 X×可捕系数 q）；
进入退出动态 Ė = ν(pqX − c)E（利润驱动）。竞争的终点是**生物经济平衡**
X∞ = c/(pq)：利润恰为零、船不再进出。

**最小数值**：p=2、q=4×10⁻⁴、c=3 → X∞=3750、E∞=625、持续产量 937.5 < MSY=1000
（实验断言 D 实测：X=3750、E=625、利润/收入≈0）。

**反直觉发现（⑥要件）**：**经济过度捕捞先于生物过度捕捞**。租金耗散
（利润=0，社会一无所获）发生时，产量已经低于 MSY，但没有任何船亏本退出——
公地悲剧的第一代价是**经济浪费**，生物崩溃是第二幕。
这就是 ITQ（个体可转让配额）的理论起点：把"开放进入"改成"产权进入"。

## 构造③ 物质流恒等式（会计侧最小件，Ayres–Kneese 1969）

**直觉**：给一国的经济称重。进的吨位=出的吨位+囤的吨位，一次称重全对账。

**结构**（经济体物质流 MFA 核心恒等式）：

```
投入（国内开采 + 进口） = 排放（to 空气/水/填埋） + 出口 + 净存量积累 NAS
```

**最小数值**：3 部门经济：开采 100 + 进口 30 = 排放 95 + 出口 25 + NAS 10。
一行对上，物质守恒（02 章方言一的复式记账版）。

**✨美之时刻（⑧要件）：外部性不是外部的**
**陈述**：Ayres 与 Kneese 1969 年证明：只要把热力学第一定律当真，
一般均衡的废物产出是**必然的、系统性的**——不存在"没有外部性"的产业结构，
只存在"没被记账"的废物。
**为什么美**：*必然*——从物理公理直通产业结构结论，中间不需要任何行为假设；
一篇论文废掉一个世界观（外部性=偶发摩擦）。
**怎么亲历**：手算构造③的恒等式闭合——故意让右边少记 5 吨排放，看 NAS
如何被迫虚增；你会立刻明白为什么 MFA 审计能查出瞒报。

## 构造④ 韧性盆地（系统侧最小件）

**直觉**：把 00 章的双碗图变成势能地形——存量 X 是球的位置，政策 H 是推力。
碗（盆地）之间的山脊就是**不稳定平衡**。

**结构**：常数捕捞 H<rK/4 时，logistic 有两个平衡：大根稳定（碗底）、
小根不稳定（山脊）。初始存量在山脊哪一侧，决定同一政策的两种命运。

**最小数值**：H=800 时稳定平衡 7236、不稳定平衡 2764。实验断言 A 实测：
X₀=9000 → 收敛 7236；X₀=2500 → 灭绝。**政策没变，命运由起点决定**——
盆地分离（basin separation）把"风险"变成几何对象。
1992 北方鳕鱼禁渔至今种群未恢复：崩溃不是"产量下降 30%"那种可逆损失，
是翻过了山脊。
