# 讲透能量与物质流分析 · 给经济称重测温

> **定位**：这支负责物理测度——不问价格，问**吨位与焦耳**：经济吞进吐出多少物质、
  沿什么路径流动、占用多少生物物理预算。**自定主干支**（GB/T 79043 无三级明细）。

## 诞生

Odum 1957 年银泉能流图：第一次把生态系统画成能量货币的收支表，
其兄 E. Odum 的《生态学基础》(1953) 同期把"生态系统"变成分析单位；
H.T. Odum 后来发展出**能路语言**（energy circuit language，一套图形语法）
与能值（emergy）换算。1969 年 Ayres–Kneese 把热力学第一定律塞进经济学
（家族 [03 章](../03-可构造与结构.md)美之时刻）；2001 年起欧盟推行
经济体物质流核算（economy-wide MFA），DMC/RMC 成为官方指标。

## 核心问题（3-5 条）

- ✅ 已解：物质平衡恒等式与 MFA 指标体系——投入=排放+出口+存量积累，
  欧盟统计年鉴年年出版（家族构造③即其最小版）
- ✅ 已解：能值/㶲换算框架——不同质的能量折算成统一"太阳能当量"记账
- 🔄 前线：碳流核算——Kaya 恒等式是 MFA 在气候问题上的特例，双碳政策的
  最小模型（家族 [04 章](../04-生态经济学转代码.md)走廊 C）
- ❌ 未解：NPP 占用的可持续上限——人类已占用陆地潜在净初级生产力约四分之一
  （Vitousek 1986 首估约 40%，Haberl 2007 修正约 24%）；"该占多少"无理论答案

## ✨这支最美的一个事实

Ayres–Kneese 1969：只要把守恒律当真，"外部性"就不是外部的——
经济过程必然产出废物，**没有**无排放的产业结构，只有没被记账的排放。
一篇论文用物理公理废掉了一个经济学世界观。

## 假设与依赖

守恒律优先于价格信号（吨位账独立于市场账）；质量单位可加总——
这是被反复批评的弱点（一吨汞与一吨沙不等价，MFA 需配套物质毒性账户）；
依赖统计与遥感数据质量。
