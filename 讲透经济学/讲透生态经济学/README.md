# 讲透生态经济学 · 经济是生态系统的一个胃

> 生态经济学：**经济是生态圈的开放子系统**——它吸入低熵物质与能量、吐出高熵废物，
> 热力学与承载力不是经济学的外部备注，而是约束本身。
> 与近亲[环境经济学](../讲透环境经济学/)的分界：那家在新古典框架内矫正外部性（效率优先），
> 这家追问框架本身——**规模→分配→效率**（Daly 顺序），只把第一问当第一问的就是本家族。

## 诞生（三个原生问题）

| 原生问题 | 年代 | 结局 |
|---|---|---|
| 地球是牛仔场还是宇宙飞船 | 1966 | Boulding《即将到来的地球宇宙飞船经济学》→ 封闭系统观立族 |
| 生态系统的能量账怎么记 | 1950s-70s | Odum 银泉能流图 → 能量/能值语言与系统图语法 |
| 自然的免费服务值多少钱 | 1997 | Costanza 等（Nature）估值 $33 万亿/年 > 全球 GNP → 二十年方法论大战 |

## 核心问题清单（详 [00 章](00-体系结构.md)）

已解决：最大可持续产量 MSY 与开放进入理论（Schaefer/Gordon 1954）·
物质平衡方法（Ayres–Kneese 1969）· 韧性≠稳定性（Holling 1973）·
生态系统核算入国民账户（UN SEEA EA 2021）。
悬而未决：规模可测吗（行星边界量化之争）· 价值可通约吗（货币 vs 多元价值）·
无增长宏观可能吗（就业/债务/货币全锚定增长）· 韧性能折算成风险溢价吗。

## 假设与代价

本家族假设：**经济是可嵌入生态系统的生物物理开放系统**。
买到：把"太大"变成合法的科学问题、把外部性从例外变常态；
付出：放弃 Arrow–Debreu 式封闭均衡的数学优雅，以及单一价格语言的加总便利。
