# 讲透生态系统服务与自然资本 · 给自然的免费礼物记账

> **定位**：这支负责"给自然的免费礼物记账"——从服务分类到价值评估再到国民账户，
> 让生态系统的产出在决策桌上有一栏。**自定主干支**（GB/T 79043 无三级明细）。

## 诞生

1997 年双响：Daily 主编《Nature's Services》与 Costanza 等 Nature 论文同年出版；
2005 年千年生态系统评估（MA）定下四大服务分类；2010 年 TEEB 报告把它推到
国际政策层；2021 年 UN SEEA EA 采纳，服务流量正式进入国民账户（家族 [01 章](../01-近五年创新.md)主线一）。

## 核心问题（3-5 条）

- ✅ 已解：服务分类学——供给/调节/文化/支持四类（MA 2005），全学科的公共词汇表
- ✅ 已解：估值工具箱成型——CVM/旅行成本/享乐法/选择实验（工具细节在
  [讲透环境经济学](../../讲透环境经济学/)深挖，本支管生态侧的用法与陷阱）
- 🔄 前线：GEP 与 SEEA EA 并行核算落地——中国试点是最大实验室
- ❌ 未解：不可通约性——plural values 派 vs 货币派（家族 01 章 §三是主战场），
  五年内不会有裁判

## ✨这支最美的一个事实

Costanza 等 1997 年估计：全球生态系统服务价值约 **$33 万亿/年**，超过当年
全球 GNP（约 $18 万亿）——"免费"的礼物比全人类产出加起来还值钱。
一个数字让自然从经济学的背景板变成了资产负债表的主角。

## 假设与依赖

服务流量可持续（自然资本存量不衰减）——流量考核若不查存量就是 GEP 的陷阱
（家族 02 章反直觉）；影子价格可解释政策权重但不等于出售（入账≠市场化）。
上游依赖：环境经济学的非市场估值方法、遥感的范围/条件数据。
