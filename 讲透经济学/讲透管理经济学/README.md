# 讲透管理经济学 · 微观经济学的经营驾驶舱

> 管理经济学：**把微观经济学装进经理的决策面板**——定价、产量、进入、激励四个
> 决策位上的经济学工具。GB/T 13745 代码 79033，无三级明细，本家族三支均为自定主干支。
> 本家族夹在 `讲透微观经济学`（纯理论）与 [讲透管理](../../讲透管理/)（管理实践）
> 之间：理论来自前者，问题来自后者，出口通向真实企业的定价表与 KPI。

## 定位声明（本家族怎么读）

本宇宙其他家族回答"经济如何运行"；本家族回答"**一家企业该怎么决策**"。
它不是新理论，而是微观工具的**驾驶舱化**：需求弹性变成加成定价旋钮，
博弈论变成竞争策略仪表，委托代理变成激励设计手册——每件工具都对应一个管理动作。

## 诞生（三个原生问题）

| 问题 | 年代 | 结局 |
|---|---|---|
| 铁路与钢铁巨头该怎么定价？垄断有多坏？ | 1933-1934 | 张伯伦/罗宾逊垄断竞争理论、勒纳指数（1934）——"市场力量"第一次可测量 |
| 企业为什么存在？市场不是什么都能干吗？ | 1937 | 科斯《企业的性质》：交易成本划定组织边界→组织经济学一脉 |
| 寡头相争，谁先眨眼？ | 1944-1950 | 冯·诺依曼-摩根斯坦博弈论、纳什均衡（1950）→1980 年代起成为商学院标准语言 |

## 核心问题清单（详 00 章）

已解决里程碑：勒纳条件（1934）· 纳什均衡（1950）· 霍姆斯特姆信息量原则（1979）·
拍卖设计（2020 诺奖）· 平台双边市场策略（梯若尔，2014 诺奖）。
悬而未决：算法合谋的法律与经济学边界 · 多任务下 KPI 如何不失真 ·
数据驱动的个性化定价停在效率与公平的哪一格（大数据杀熟立法之争）。

## 假设与代价

本家族假设：**企业 = 利润最大化的单一决策者**。买到分析锐度
（一切管理问题化归边际比较与激励设计）；付出现实折扣
（真实企业是政治联盟、有限理性、多目标——把工具当蓝图而非罗盘用会失火）。
