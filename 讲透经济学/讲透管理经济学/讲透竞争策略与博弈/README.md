# 讲透竞争策略与博弈 · 对手在读你的时候你在读对手

> **定位**：这支负责"多人决策位"——寡头定价、进入威慑、承诺装置、
> 合谋的可持续性与算法定价时代的合谋涌现。自定主干支（GB/T 79033 无三级明细）。

## 诞生

1944 年冯·诺依曼-摩根斯坦《博弈论与经济行为》给了策略互动数学形态；
1950 年纳什均衡解决了"谁也不能单方面改善"的定格问题；
1950 年代古诺/伯特兰模型被重新读作博弈均衡。1980 年代商学院把这套语言
装进竞争战略教学（波特框架的博弈化改造），本支定型。
2020 年 Calvano 等发现定价算法自主学习默契合谋，本支进入执法时代。

## 核心问题（3-5 条）

- ✅ 已解：无名氏定理——足够耐心的重复博弈里合作（合谋）可以成为均衡
- ✅ 已解：进入威慑的承诺构造（过剩产能/长期合同=自缚以改信念）
- 🔄 前线：算法合谋的法律要件重构——Sherman §1 要"协议"，学习算法只有同步涨价
- ❌ 未解：算法定价回路的监管接口——管单台算法还是管接线图

## ✨这支最美的一个事实

**自缚手脚可以是优势**：先烧掉自己退路的玩家反而赢——承诺装置的
全部经济学就是"花钱买不可逆"。这反了直觉却处处验证：公开降价承诺、
退出条款、沉没投资，都是把"我会硬"从空话变成结构。

## 假设与依赖

局中人理性且共同知识（均衡是锚不是预测）；对手集合与行动空间可枚举。
算法时代的新依赖：学习算法+共享数据平台替代了"理性"假设——
合谋不再需要意图，只需要回路（家族 01/04 章）。
