# 讲透需求与定价 · 价格标签是怎么写出来的

> **定位**：这支负责"从需求曲线到价格标签"的完整生产线——
> 弹性测量、加成规则、歧视结构、动态定价。自定主干支（GB/T 79033 无三级明细）。

## 诞生

1920 年庇古在《福利经济学》里给价格歧视分了级（一/二/三级）；
1934 年勒纳把最优加成写成一条公式 (P−MC)/P = 1/|ε|；
罗宾逊 1933 年把歧视放进不完全竞争的一般理论。三个动作之后，
"定价"从手艺变成计算。1990 年代收益管理（航空公司舱位动态定价）
把它推到工业规模；2020 年代数据化把它推到每个人一个价。

## 核心问题（3-5 条）

- ✅ 已解：三级歧视的福利账——线性需求+共同 MC 下总产量不变、总剩余下降（家族实验断言 C/D）
- ✅ 已解：二级歧视的自选菜单构造（激励相容让消费者自报类型，见家族 03 章）
- 🔄 前线：弹性实时估计（噪声需求下的在线学习）、行为定价（锚定、左位数效应）
- ❌ 未解：个性化定价的"合理差别"判据——效率与公平的边界留给立法与个案

## ✨这支最美的一个事实

定价公式里没有成本曲线、没有品牌、没有胆量——**只有弹性一个数**。
知道"提价 10% 客户跑几个"的经理，比知道成本表明细的经理离最优价更近。

## 假设与依赖

需求曲线可知且稳定（数据稀疏时弹性是猜的）；歧视结构另需
市场可分割+无套利（学生票查证件=分割；倒卖=套利攻破歧视）。
