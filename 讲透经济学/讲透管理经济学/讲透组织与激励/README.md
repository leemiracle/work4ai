# 讲透组织与激励 · 员工凭什么卖力

> **定位**：这支负责"激励位"——委托代理、KPI 设计、组织边界：
> 当努力看不见、目标会跑偏时，制度怎么写。自定主干支（GB/T 79033 无三级明细）。

## 诞生

1937 年科斯问"企业为什么存在"——市场这么灵，为何还要公司？
答案（交易成本）沉睡了四十年。1970 年代信息经济学起来后复活：
威廉姆森把交易成本做成组织边界理论（2009 诺奖）；
霍姆斯特姆 1979 信息量原则解决"报酬该挂什么信号"；
霍姆斯特姆-米格罗姆 1991 多任务模型解释"测什么偏什么"。
2016 年霍姆斯特姆-哈特获诺奖，本支理论主干封顶。

## 核心问题（3-5 条）

- ✅ 已解：信息量原则——与努力无关的信号进合同只增噪声白付风险溢价
- ✅ 已解：风险-激励权衡——产出噪声越大提成应越低（强激励=转嫁风险=要加钱）
- ✅ 已解：古德哈特定律的机制化——强 KPI 把努力从不可测维度抽走
- 🔄 前线：远程办公后产出可观测性重构、OKR 对 KPI 的再平衡运动
- ❌ 未解：激励挤出内在动机的边界（行为经济学反复验证、模型未统一）

## ✨这支最美的一个事实

**多任务下，最好的激励可能是弱的**：只测得到销量的强提成会把服务、
质量、回款全抽干——故意降低可测任务的激励强度，换不可测维度的自发投入。
"少给钱反而多干活"不是鸡汤，是均衡。

## 假设与依赖

代理人理性且对激励有反应（行为经济学的挤出效应是修正项）；
产出信号可观测、可写入合同（关系契约处理不可写入的部分）。
