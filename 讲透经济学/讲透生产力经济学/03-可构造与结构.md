## 一、可构造之一：增长核算恒等式——零假设可算的机器

### 1.1 构造

给定任意 (ΔlnY, ΔlnK, ΔlnL, s_K, s_L)（数据+份额）：

```
Δln A ≡ Δln Y − s_K·Δln K − s_L·Δln L
```

**完全可构造的含义**：无参数估计、无函数拟合、无优化——纯代数。
任何经济、任何时期、任何数据质量都能"算出"一个 TFP——
**这正是要害：恒等式自动产出数字，数字的意义完全依赖假设层**
（02 章 §五分层纪律的构造学根源）。

### 1.2 假设账单（谁在为"余值=技术进步"背书）

| 假设 | 作用 | 破坏后果 |
|------|------|---------|
| 规模报酬不变 | 份额和为 1，分解完备 | 规模经济混入余值（TFP 虚高） |
| 要素按边际产品付酬（竞争） | 份额=弹性 | 市场势力⟹份额≠弹性，加权系统性偏差 |
| 投入完全核算（含质量） | 分母无漏 | 教育/资本质量漏记⟹余值吸收（余值战争） |
| 加总的资本量有意义 | K 可测 | 剑桥悖论（§四） |

✨ **美之时刻 ①：份额校准——免估计的弹性**
陈述：竞争+规模不变下，Cobb-Douglas 的 α 恰等于国民核算中的
资本份额（美国长期 ~0.33-0.38）——**不用跑回归，弹性从账本上读**。
为什么美：**极简+跨范式**——它让增长核算成为"办公室算术"
（一台计算器+一本统计年鉴）；同时它是检验器：企业层面弹性
估计与份额的背离=市场势力的信号（De Loecker-Eeckhout 2017 用
此测出美国加成率 1980- 后翻倍——宏观过剩利润研究的方法核）。
怎么亲历：本家族实验 (b)——Cobb-Douglas 生产+竞争定价的模拟数据，
断言 OLS 估计的 α 回收了份额参数（校准闭环）。

## 二、可构造之二：效率前沿——DEA 作为规划族

### 2.1 生产可能集与 CCR 模型

n 个决策单元（DMU），各含投入 x_j∈R^m、产出 y_j∈R^s。
构造生产可能集（凸组合+自由处置）：

```
T = {(x,y) | x ≥ Σλ_j x_j, y ≤ Σλ_j y_j, λ ≥ 0}
DMU₀ 的效率 = 求解 LP： min θ  s.t.  θ·x₀ ≥ Xλ,  y₀ ≤ Yλ,  λ≥0
θ<1 ⟹ 存在"虚拟单元"（同行加权组合）用 θ 比例投入即产出不低于你——θ=效率
```

**DEA=Charnes-Cooper-Rhodes 1978**——纯线性规划
（数学母港：[讲透数学·讲透运筹学](../../讲透数学/讲透运筹学/)）。
每个 DMU 一个 LP，n 个 DMU 解 n 次——**完全形式化、完全可算**
（本家族实验 [dea_ccr.py](experiments/dea_ccr.py) 手搓可跑）。

### 2.2 结构性质（前沿派的理论红利）

| 性质 | 内容 |
|------|------|
| 包络结构 | 效率前沿=数据点的分段线性包络——非参数（不设函数形式） |
| 分解定理 | 成本效率=技术效率×配置效率（价格信息可用时） |
| 规模报酬变体 | CCR（不变）→BCC（可变，1984）——规模效率可分离 |
| 参照集敏感性 | 前沿由样本自身构成：加一个"超人"全员效率下降——**结论是相对的** |

📖 **故事框：DEA 的出身与方法论性格**
CCR 1978 出身于运筹学（Charnes-Cooper 是规划理论大家）——
它把"效率"从回归平均（SFA 一系走统计路）改成"到前沿的距离"：
**回归派问"平均比同行差多少"，前沿派问"离最优差多少"**。
两条路线的哲学差=管理学的两个问题（常态评估 vs 改进空间）。
中国经济学界 1980s 引入 DEA 后，它在地方政府/医院/银行效率
研究中成为标准武器——运筹学方法在经济学最成功的移民。

## 三、可构造之三：函数估计——半构造与识别陷阱

生产函数的经济计量（面板回归 Y=Xβ）的三重陷阱：

| 陷阱 | 机制 | 对策 |
|------|------|------|
| 同时性（联立） | 高效企业多投要素——投入与误差项相关 | 工具变量/代理（Olley-Pakes 1996：投资作生产率代理） |
| 选择偏差 | 低效企业退出市场——幸存样本偏乐观 | OP 第二阶段修正 |
| 函数形式 | Cobb-Douglas 强加替代弹性=1 | 半参数/非参数（LP/ACF） |

**半构造的定位**：形式自由（回归总能跑），识别靠结构假设
（OP/LP 序列假设）——与 [微观 03 章](../讲透微观经济学/03-可构造与结构.md)
结构估计同题：**可信性的来源不是回归技术，是经济结构假设**。

## 四、深渊：剑桥资本论战与加总的代价

### 4.1 悖论的陈述

**Robinson 1953-54/剑桥（英）vs MIT 之争**：总量生产函数里的
"K"用什么单位度量？——用货币值就要先有利率（资本品的价格依赖
利润率）；用实物又要先加总异质资本品。**K 的度量依赖它自己
要解释的分配变量（r）——循环**。

### 4.2 技术再转折（reswitching）

剑桥派证明：同一技术可以在 r 低时最优、r 中时劣、r 高时**再**最优——
"低利率⟹资本密集技术"的单调叙事不成立——
**资本需求曲线可以向上倾斜**，新古典的 r=资本的边际产品叙事
失去一般性。

### 4.3 学科的务实和解（与诚实标注）

- **Solow 的回答**：总量函数是"寓言"——好用的近似，不是本体
- **Jorgenson 的路线**：放弃总量 K，用资本服务流（分资产类别
  按租金价格加权）——会计上绕开循环（代价：与"资本存量"的
  直觉叙事脱钩）
- **本家族的标注纪律**：任何使用总量 K 的结论（含本家族实验！）
  都自动背上剑桥警示——**加总即承诺**（与 [政经 03 章](../讲透政治经济学/03-可构造与结构.md)
  剑桥故事框互文：那场论战同时打伤两家，此为一家侧的伤情报告）
