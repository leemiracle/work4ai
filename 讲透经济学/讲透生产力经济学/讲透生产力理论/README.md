# 讲透生产力理论 · 范畴层：要素、质态与历史跃迁

> 这支负责：**生产力的范畴与形态**——要素论（劳动者/劳动资料/劳动对象
> +渗透性要素）、科学技术是第一生产力、生产力质态跃迁与新质生产力。
> **自定主干支**（GB/T 79023 无三级明细，本家族按学科习惯自定）。

## 诞生

配第"劳动是财富之父、土地是财富之母"(1662) 与斯密制针厂(1776，
分工=2400 倍)是学说源头；马克思"生产力-生产关系"对子(1859)给了
元框架；熊彼特创新理论(1912/1942)给了"创造性破坏"的质变机制；
1980 中国生产力经济学研究会成立（学科建制化，缘于"科学技术是
生产力"大讨论）；1988"科学技术是第一生产力"；2023"新质生产力"。

## ✨ 这支最美的一个事实

**制针厂 2400 倍的生产力增益里，"技术发明"的贡献是零**——没有新机器，
全部增益来自分工与组织（斯密 1776）。它一击揭示"技术进步"范畴的
混装性：组织、知识、协调全被装进同一只袋子——六十年余值战争与
新质生产力（组织-技术协同质变）在两个世纪后仍在解这只袋子。

## 假设与依赖

生产力可从生产关系中相对独立地分析（对偶假设——[讲透政治经济学](
../../讲透政治经济学/) 管另一半）；形态跃迁有可辨识的阶段结构
（历史唯物主义的弱化版：分期不预定论）；范畴的指标化存在固有
压缩比（不可全译）。
