# 00 · 体系结构：范畴、测量、形态三块大厦

> **本章回答五问之一（本家族：讲透生产力经济学）。**
> 生产力经济学的大厦 = **范畴层（生产力是什么：要素论与质态论）→
> 测量层（生产率怎么算：增长核算与效率前沿）→ 形态层（生产力
> 如何历史性跃迁：手工—机器—信息—智能）**。
> 一句话分工：**范畴层给定义，测量层给账本，形态层给历史。**

---

## 一、直觉开篇：斯密的制针厂

1776 年斯密的开篇例子：独自制针，一人一天 20 枚；分工成 18 道工序，
十人车间日产 48000 枚——**人均 2400 倍**。
同样的手、同样的铜，产出差三个数量级：差在**分工与组织**。
生产力经济学研究的正是这个差：它从哪来（要素？技术？组织？）、
怎么量（余值？前沿？）、怎么变（形态跃迁）。

反直觉第一击：**制针厂 2400 倍的生产力里，"技术发明"的贡献是零**——
没有一台新机器，全部增益来自重新组织劳动。
"技术进步"这个词把组织、知识、协调、激励混装一袋——
**测量层的全部争论（余值战争）都从这只袋子开始**。

## 二、范畴层：生产力的要素与质态

### 2.1 要素论的进化

| 传统 | 要素清单 | 分配含义 |
|------|---------|---------|
| 古典（配第-斯密-马克思） | 劳动（+自然+资本） | 劳动价值论：剩余归属问题 |
| 新古典三要素 | 劳动、资本、土地 | 边际生产力分配（克拉克 1899） |
| 现代扩展 | +人力资本（Schultz 1961/Becker 1964）、+知识（Romer 1990）、+数据（2020s） | 要素范畴的历史增长 |
| 中文语境 | 劳动者、劳动资料、劳动对象（三要素论）+科学技术渗透性要素 | "科学技术是第一生产力"(1988) |

**范畴增长的规律**：每当某要素的稀缺性开始定价（教育→人力资本、
创意→知识、数据→数据要素），它就从"背景"升格为"要素"——
**要素清单是历史的函数**（与 [政治经济学 02 章](../讲透政治经济学/02-语言特征.md)
"范畴是压缩包"同一方法论）。

### 2.2 质态论：生产力的形态跃迁

手工生产力→机器生产力（工业革命）→信息生产力（ICT）→智能生产力
（AI，进行中）。2023 年"新质生产力"范畴：**创新起主导作用、
摆脱传统增长路径**的生产力质态——范畴层的最新成员
（技术-组织-制度的协同质变，而非单点技术）。

✨ **美之时刻 ①：增长核算恒等式——三行算出一个时代的谜**
陈述（Cobb-Douglas 对数微分）：
```
Δln Y = s_K·Δln K + s_L·Δln L + Δln A
⟹    Δln A（TFP） = Δln Y − s_K·Δln K − s_L·Δln L
```
为什么美：**极简+普适**——不需要估计任何参数（份额 s 直接取核算数据），
三行代数把任何经济、任何时期的增长拆成"多投了多少"与"变聪明了多少"。
1957 年索洛用它算出美国 1909-1949 年人均产出增长的 **87.5% 来自余值**——
"技术进步"从修辞变成第一大项。这个恒等式是全部经济学中
"简单装置承载重大结论"的极致（03 章细拆它的假设账单）。
怎么亲历：跑本家族实验 [growth_accounting.py](experiments/growth_accounting.py)
——中美两组教学数据的 TFP 分解，断言恒等式逐项闭合。

## 三、测量层：两套账本（核算派与前沿派）

| | 增长核算（索洛线） | 效率前沿（DEA/SFA 线） |
|---|------------------|---------------------|
| 问 | 时间上：增长从哪来 | 截面上：离最优差多远 |
| 装置 | 生产函数+份额 | 生产可能集+前沿包络 |
| 单位 | 经济体/行业（总量） | 决策单元 DMU（企业/医院/学校） |
| 数学 | 对数微分恒等式 | 线性规划（DEA 1978）/随机前沿回归（SFA 1977） |
| 盲区 | 落后者距离前沿多远（看不见） | 时间上的技术进步（看不见） |

**两套账本互补**：核算法回答"时间维度"、前沿法回答"截面维度"；
完整的生产率诊断=两账并读（03 章构造学、04 章两条走廊）。

📖 **故事框：余值战争（1956- ）**
Abramovitz 1956：余值是"对我们无知的度量"。
Jorgenson-Griliches 1967 反击：把投入测细（资本的质量调整、
劳动的教育构成、能源中间投入），余值大幅缩水——
"技术进步"其实是"投入测量误差"。战争的现役战场：
无形资本（品牌/数据/组织资本）不入资产负债表 ⟹ AI 时代的
生产率可能被系统性低估（01 章索洛悖论 2.0）。
**方法论教训：测量边界决定理论结论——账本即理论**。

## 四、形态层：生产力的历史跃迁

| 跃迁 | 时间 | 核心装置 | 生产率后果 |
|------|------|---------|-----------|
| 手工→机器 | 1760s- | 蒸汽/工厂制 | 人均增长从 ~0 到 ~1%/年（工业革命拐点） |
| 机器→流水线 | 1913- | 福特制+电力 | 美国制造业 TFP 黄金期（1920s 电化的 J 曲线：1890s 装机→1920s 才爆发） |
| 流水线→信息 | 1970s- | ICT | 索洛悖论（1987）→1995-2004 美国生产率复兴（时滞 ~25 年） |
| 信息→智能 | 2020s- | AI/机器人 | 进行时：悖论 2.0 之问（01 章主战场） |

**跃迁的共同模式（J 曲线）**：通用技术（GPT：蒸汽/电/ICT/AI）需要
**互补性重组**（组织、技能、基础设施）才释放生产率——
先投入（生产率反而降）、后爆发。这是"技术-组织协同质变"论，
也是新质生产力范畴的学理底座。

## 六、家族内循环

```
范畴层（要素/质态）──提供语言──▶ 测量层（核算/前沿）──提供证据──▶ 反哺范畴
      ▲                                                        │
      └────────── 形态层（历史跃迁）解释测量的长波 ◀────────────┘
```
余值战争的每一轮（无形资本/数据要素）都由测量层的挫折触发
范畴层的新范畴——**范畴与测量的螺旋**是本学科的发动机。

## 七、假设与代价（家族四张底牌的展开）

见家族 README §三。本章补总纲：生产力经济学的每个假设都是**测量合同**——
生产函数假设买到核算框架、付掉资本加总悖论；份额=弹性假设买到
免估计的弹性、付掉竞争假设的隐含背书；前沿可比假设买到排名、
付掉参照集任意性。**读任何生产率结论，先读它的测量合同**。

## 👁 这章给了你什么新眼睛（认知升维）

- **先问"增长从哪来"再庆祝增长**：产出增长=要素堆出来的还是效率
  涨出来的——增长核算三行代数是最便宜的经济体检
- **测量边界即理论边界**：什么算资本、什么算投入，直接决定
  "技术进步"的大小——账本即理论不是修辞
- **通用技术的 J 曲线**：看到新技术+生产率没涨，别急着下结论——
  电用了 25 年，重组完成前生产率反而降
