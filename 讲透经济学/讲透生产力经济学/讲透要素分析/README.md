# 讲透要素分析 · 测量层：核算、前沿与指数工艺

> 这支负责：**生产率的测量与分解**——增长核算（索洛余值）、
> 生产函数估计、效率前沿（DEA/SFA）、指数工艺（质量调整的投入核算）。
> **自定主干支**（GB/T 79023 无三级明细，本家族按学科习惯自定）。

## 诞生

1942 丁伯根先行；**1957 索洛**《技术变化与总量生产函数》同时发明
TFP 概念与增长核算法（余值占美国 1909-49 人均增长的 87.5%）；
Abramovitz 1956"无知的度量"与 **1967 Jorgenson-Griliches** 的质量
调整反击开启余值战争；1977 SFA（随机前沿）与 **1978 DEA**
（Charnes-Cooper-Rhodes，运筹学移民）补上截面测量；1990s-
Olley-Pakes/Levinsohn-Petrin 修正企业面板估计；2020s 无形资本
测量接棒（AI 生产率之问，家族 [01 章](../01-近五年创新.md)）。

## ✨ 这支最美的一个事实

**份额校准——不用跑回归，弹性从账本上读**：竞争+规模报酬不变下，
Cobb-Douglas 的资本弹性 α 恰等于国民核算的资本份额（美国长期
~0.35）。一台计算器+一本统计年鉴就能做增长核算；反过来，
企业层面弹性估计与份额的背离成为测市场势力的信号
（De Loecker-Eeckhout 2017：美国加成率 1980- 后翻倍）。

## 假设与依赖

总量生产函数（买到核算框架，付剑桥加总悖论）；份额=弹性
（免估计，付竞争假设背书）；投入完全核算（余值干净，付质量
调整工艺）；DEA 同群体可比（前沿排名，付参照集任意性）。
全表见家族 README §三。
