# 04 · 生产力经济学转代码：增长会计、效率前沿与指数走廊

> **本章回答五问之五（本家族：讲透生产力经济学）。**
> 生产力资产的代码化分四条走廊：**增长会计（恒等式机器，实验主场）→
> 效率前沿（DEA 规划族，实验主场）→ 指数计算（Törnqvist/Divisia）→
> 随机前沿（SFA 统计模型）**。本学科可机械化版图的特色：
> **两条主场走廊全自动且理论完备（03 章 ✅✅ 行）**，
> 但每条走廊的输出都自带假设账单——**代码越自动，标注越要紧**。

---

## 一、四条走廊总表

| # | 走廊 | 输入→输出 | 代表工具/方法 | 自动化档位 |
|---|------|----------|--------------|-----------|
| 1 | 增长会计 | (ΔlnY, ΔlnX, s)→要素/TFP 分解 | 三行代数（实验主场） | ✅ 全自动（零估计） |
| 2 | 效率前沿 DEA | DMU 表→各单元 θ/参照集 | n 次线性规划（实验主场） | ✅ 全自动 |
| 3 | 指数计算 | (价格,数量)→真实增长/平减 | Törnqvist/Divisia 链式 | ✅ 全自动 |
| 4 | 随机前沿 SFA | 面板→效率+噪声 | 极大似然（分布假设） | ⚠️ 半自动（假设密集） |

## 二、逐条速写

### 走廊 1：增长会计——三行代数的工程化

[experiments/growth_accounting.py](experiments/growth_accounting.py)
三件套（03 章 §一构造学的全落地）：
①中美两组教学数据的 TFP 分解+恒等式闭合断言（分解项之和=总增长）；
②份额校准闭环：Cobb-Douglas 模拟数据上 OLS 回收 α=份额（断言）；
③指数稳健性：份额±5pct 时 TFP 贡献的摆动区间（断言带内）——
**输出的敏感度与输出本身一起交付**（假设账单的代码形态）。

**工程师落点**：这套"分解+闭合断言+敏感度带"的三段式是任何
归因分析的模板——把"增长从哪来"的问题工程化成可测试的管道。

### 走廊 2：DEA——把"最优同行"变成规划

[experiments/dea_ccr.py](experiments/dea_ccr.py)（本家族第二实验）：
①5 单元两投入一产出，scipy.linprog 逐个解 CCR，效率断言
（谁=1 谁<1）；②参照集解读（θ<1 的单元由谁加权"陪练"）；
③敏感性断言（加一个支配单元后全员效率单调不升、旧前沿单元
严格下降）——**"相对性可以精确"（03 章）的代码演示**。

```python
# CCR 投入导向（单元 j₀）：
#   min  θ
#   s.t. θ·x_{j0} − Σ_j λ_j·x_j ≥ 0     （投入不超虚拟组合）
#        Σ_j λ_j·y_j ≥ y_{j0}           （产出不低于自己）
#        λ ≥ 0
```

**工业指针**：专业实现（SBM/超效率/Malmquist 指数）见
PyDEA/DEApy 等库；中文文献的政府/医院效率研究多用 DEAP/MaxDEA。

### 走廊 3：指数计算——平减的工艺

```
Divisia：dln Y_real = dln(名义) − Σ s_i·dln p_i（瞬时权数）
Törnqvist：离散近似，权数取两期均值——核算派默认工艺
链式 vs 固定基：链式避免"新商品无价"的老化问题，代价是路径依赖
```

**为什么工艺即结论**：Jorgenson-Griliches 的教训（02 章 §二）在
代码层的对应——**平减因子的选择改变 TFP 的符号都不奇怪**（低
通胀环境）。工程纪律：指数方法与基年显式进配置，不埋在代码里。

### 走廊 4：SFA——统计路的前沿

```
ln y_j = β·ln x_j + v_j − u_j
v~N(0,σv²)（噪声）；u~半正态（技术无效率）——ML 分离两者
与 DEA 的哲学差：前沿派（非参数、确定性）vs 统计派（参数、随机）
```

**半自动的原因**：分布假设（u 的族）与函数形式都是研究者承诺；
面板变体（BC 1992 时变效率）更是假设叠假设——**这条走廊的
可信度=假设序列的可信度**（03 章 §三同题）。

## 三、可机械化边界（03 章清单的投影）

| 任务 | 档位 | 边界由谁把守 |
|------|------|-------------|
| 核算分解/DEA/指数 | 全自动 | 代数与规划（理论完备） |

| 新质生产力的测度 | 建设中 | 指标学（压缩比问题，02 章） |

## 四、工程师落点（性能工程视角）

1. **归因管道三段式**：分解恒等式 → 闭合断言（Σ贡献=总变化）→
   敏感度带（关键参数±ε）——可移植到任何指标归因（成本、延迟、能耗）
2. **n 次小 LP 是天然并行**：DEA 的逐单元规划互相独立——
   并行化零依赖（与 [讲透高性能计算](../../讲透高性能计算/) 的
   embarrassingly parallel 模式同款）
3. **配置外置**：份额、指数公式、基年全部进配置不进代码——
   假设的可见性是工程问题（02 章分层纪律的落地）
4. **参照集即对比组**：DEA 的"虚拟组合"思想=业务里的合成对照
   （synthetic control 的近亲）——用同行加权造反事实
