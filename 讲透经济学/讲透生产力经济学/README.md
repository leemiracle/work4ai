## 一、诞生

这门学科有两条出生线，1980s 汇流：

1. **算术线（西方增长核算）**——1957 索洛《技术变化与总量生产函数》：
   把产出增长减去要素贡献，剩下"余值"归技术——TFP 概念与增长
   核算法同时诞生（丁伯根 1942 有先行）。随后 Abramovitz 1956 名句：
   余值是"对我们无知的度量"；Jorgenson-Griliches 1967 反击：
   余值小是因为投入测得粗（质量调整后的投入核算）——六十年
   "余值战争"由此展开。
2. **范畴线（中国学科建制）**——生产力学说古已有之（配第"劳动是
   财富之父"、斯密制针厂分工）；1980 中国生产力经济学研究会成立，
   "生产力经济学"作为学科建制化（缘于"科学技术是生产力"大讨论）；
   1988 邓小平"科学技术是第一生产力"；2017"高质量发展"、
   2023"新质生产力"——范畴体系的四十年演进。
3. **合流**——索洛余值之争在中国语境=科学技术（第一）生产力的
   定量化；两线的工具箱在"要素贡献分解"上完全互通。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 增长源泉分解（增长核算法） | ✅ 方法已解（恒等式级，见 03 章） | 最有用的宏观发明——任何经济体检的第一步 |
| 余值是什么（技术进步 vs 测度残差） | 🔄 余值战争六十年 | Jorgenson 派证明余值随测量精度缩小——"技术"是测量残余的哲学地位 |
| 效率测量（技术/配置/规模效率） | ✅ 方法成熟（DEA 1978/SFA 1977） | 前沿方法把"落后"分解成"够不着前沿"与"用错比例" |
| 索洛悖论（计算机无处不在，生产率统计除外） | 🔄 2020s AI 版重演 | 1987 索洛名句；GPT 类技术的 J 曲线时滞之争 |
| 资本加总（剑桥资本论战） | 🔄 理论僵局 | 总量"资本"依赖利率计价——加总即承诺 |
| 新质生产力的测度 | 📝 建设中 | 创新驱动的生产力质态如何指标化 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 总量生产函数存在（Y=F(K,L,t)） | 核算框架可用 | 资本加总悖论（剑桥论战）；企业异质性被抹平 |
| 规模报酬不变+竞争（核算恒等式版） | 余值=技术进步的解读 | 规模经济、市场势力混入余值 |
| 边际生产力分配（份额=弹性） | 弹性可由份额校准 | 分配的规范辩护争议（克拉克-威克斯蒂德传统） |
| 前沿可比（DEA 的同群体假设） | 效率排名可算 | 参照集选择即结论（多加一个"超人"全体变矮） |
