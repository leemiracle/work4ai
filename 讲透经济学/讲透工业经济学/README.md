## 一、诞生

1. **1930s 垄断资本主义之辩→1940 市场结构-行为-绩效**——
   Mason-贝恩的哈佛学派立起 SCP 范式：结构决定行为、
   行为决定绩效——**产业组织成为一门有自己范式的科学**。
2. **1970s-80s 芝加哥学派+博弈论反击**——结构是效率的结果
   而非原因（Demsetz）；Tirole《产业组织理论》（1988）用
   博弈论重写全学科——从"集中度回归"到"策略互动建模"。
3. **中国工业化现场**——苏联式部门经济（部委工业经济学）→
   改革开放后的产业结构与产业政策研究→2020s 产业政策
   全球回归（芯片/绿色/反内卷），中国经验成为学科新变量。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 集中度与利润率的关系 | ✅ Cournot 下是恒等式 | Lerner=HHI/ε——集中度与加价不是经验相关是定理（本家族实验） |
| 合并的价格效应 | ✅ 可模拟 | 无协同合并可精确算涨价（合并模拟进执法工具箱） |
| 产业政策有效吗 | 🔄 实证重开 | Juhász-Lane-Rodrik (2024)：从"政府失灵"之争转向"何时如何" |
| 竞争与创新的权衡 | 🔄 前线 | Aghion 竞争与创新倒 U 关系——阿罗悖论的当代答案 |
| "内卷式竞争"的界定与治理 | 🔄 中国现场 | 2024-25 中央财经委"反内卷"——过低价格竞争的机理与政策边界 |
| 企业边界（自产还是外购） | ✅ 已解（框架） | 交易成本经济学（Williamson，2009 诺奖）——资产专用性定边界 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 市场可界定（相关市场） | HHI 可算、政策可操作 | 市场界定本身就是产业博弈的第一战场（需求替代弹性之争） |
| 企业利润最大化 | 行为可建模 | 多目标（规模/安全/政治）的国企与平台行为失真 |
| 结构外生（SCP 原版） | 政策可直接动手拆结构 | 芝加哥批评：结构是效率结果——拆结构可能拆掉效率 |
| 产业政策可纠正市场失灵 | 干预有理论根据 | 寻租/俘获/择败者（picking losers）的政府失灵对价 |
