# 讲透工业部门经济学 · 每个行业都有自己的物理学

> **定位**：这支负责 GB/T 79055 三级"工业部门经济学"——
> 分部门（钢铁/化工/装备/汽车/电子……）的技术经济特征
> 与市场分析。核心方法论：**每个行业先问它的"物理学"
> （成本结构/规模经济/技术节奏），再套产业组织分析**。**GB/T 三级**（非自定）。

## 诞生

苏联式部门经济学的遗产：按部委建制研究"某某工业部门"
（中国 1950s-80s 的部门经济研究传统）；市场化改革后
与美式产业组织合流——部门分析从"计划目录学"变成
"技术特征×市场结构"的交叉分析。典型成功案例：
钢铁（产能周期）、汽车（平台经济+规模）、
半导体（摩尔节奏+学习曲线）、平台（网络效应）。

## 核心问题（3-5 条）

- ✅ 已解：部门技术经济特征的分类学（规模/集中度/周期性）
- ✅ 已解：周期行业的产能分析框架（钢铁/化工/航运的朱格拉周期）
- 🔄 前线：新能源产业链的部门经济学（锂/电池/整车的
  垂直整合 vs 专业分工之辩）
- 🔄 前线：成熟制程 vs 先进制程的产业组织分野
- ❌ 未解：部门划分本身的时变性（智能汽车=汽车+电子+软件——
  部门目录永远追着产业形态跑）

## ✨这支最美的一个事实

钢铁、多晶硅、面板、动力电池——四个不相干的行业走过
**同一条产业弧**：暴利→产能军备赛→价格崩塌→寡头稳态。
技术迥异，剧本相同——因为共同的"物理学"：
高资本强度+长建设周期+同质品=产能周期注定的行业。
**部门经济学的核心信念就是：剧本由物理学写，角色可以换**。

## 假设与依赖

部门可界定（国民经济行业分类是坐标系——02 章）；
技术经济特征相对稳定（技术革命的冲击作为外生事件）；
依赖家族层产业组织件+各行业的技术文献（本支最重的
阅读负担：每个部门都得懂一点工程）。
