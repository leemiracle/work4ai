# 讲透工业企业经营管理学 · 工厂与公司的科学

> **定位**：这支负责 GB/T 79055 三级"工业企业经营管理学"——
> 工业企业的生产组织、管理决策与效率。它站在经济学与
> 管理学的界碑上：**市场在门外定价，企业在门内配置**——
> 这支研究门内的经济学。**GB/T 三级**（非自定）。

## 诞生

1911 泰勒《科学管理原理》（动作研究、标准化——
工厂内部的第一套"经济学"）；1920s 福特流水线+
斯隆事业部制（M 型组织的发明）；1937 科斯之问
（"为什么会有企业？"——市场成本与企业边界的交易成本
答案，1991 诺奖）；1950s 运筹学进管理（库存/排产/
线性规划——与[数学宇宙·运筹学]同期合流）。
中国现场：学苏联的工厂制→1984 松绑扩权→现代企业制度
（1990s）→智能制造与精益转型（2010s-）。

## 核心问题（3-5 条）

- ✅ 已解：企业边界的决定（交易成本：资产专用性高则内化）
- ✅ 已解：生产函数与效率测度（前沿分析 DEA/SFA）
- 🔄 前线：智能制造的组织后果（信息实时化压缩管理层级？）
- 🔄 前线：供应链治理（链主-配套的权力结构与韧性）
- ❌ 未解：管理本身的度量（"好管理"的因果识别——
  Bloom-Van Reenen 管理实践测度的十年攻坚仍在路上）

## ✨这支最美的一个事实

福特流水线把底盘装配从 12.5 小时压到 1.5 小时
（1913-14），价格砍半、工资翻倍（5 美元日薪）——
"高工资+低成本"同框出现，推翻"压榨才有利润"的
直觉：**规模经济的真源是分工与标准化，
而分工的极限由市场规模决定**（斯密定理的工厂版）。

## 假设与依赖

企业是可分析的决策单元（代理问题内生化后仍可建模）；
生产技术可函数化（生产函数假设可微、可替代）；
依赖[讲透会计学](../../讲透会计学/)的成本会计
（管理决策的计量底座）与运筹学（排产库存的工具箱）。

## 教材锚

- Chandler《看得见的手》（美国工商企业管理的传记式经典）
- Coase（1937）与 Williamson 交易成本经济学（企业边界正典）
- 中文：企业管理学系列教本（生产与运作管理分册）
