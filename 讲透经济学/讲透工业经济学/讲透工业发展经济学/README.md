# 讲透工业发展经济学 · 工业化的理论与历史（含工业经济史归组）

> **定位**：这支负责 GB/T 79055 三级"工业发展经济学"——
> 工业化、产业结构升级、新型工业化；GB/T 三级"工业经济史"
> 按史论一体**归组并入本支**（映射见家族 README 〇节）。
> 核心问题：**经济如何从农业国变成工业国，又从
> 工业国变成"去工业化"的服务国**。**GB/T 三级**（非自定）。

## 诞生

两条大谱系：一是结构主义发展经济学（1950s，刘易斯/
钱纳里：工业化=发展的发动机，产业结构随收入升级——
钱纳里标准模式）；二是经济史的经验革命（1950s-80s，
Gerschenkron 后发优势论、Rostow 起飞论及其批判）。
中国现场是最大样本：1949-1978 重工业优先（苏联模式的
最大移植）、1978-2020s 出口导向+渐进升级——
"新型工业化"（2020s 提法）叠加数字化与绿色化双约束。

## 核心问题（3-5 条）

- ✅ 已解：结构转变的标准图景（农业份额↓、工业倒 U、服务业↑）
- ✅ 已解：后发优势机制（技术模仿便宜于原创——格申克龙）
- 🔄 前线：过早去工业化（制造业峰值提前、收入未富——
  发展中大国是否失去"工业化的梯子"）
- 🔄 前线：制造业占比要不要保（中国"制造业比重基本稳定"
  之争 vs 服务业升级自然律）
- ❌ 未解：数字时代的工业化形态（服务化的制造业算不算"工业"）

## ✨这支最美的一个事实

所有完成工业化的经济体，制造业就业份额都走出**倒 U 型**
（升到 20-40% 峰值后回落）——无一例外。工业化不是终点
而是**路过**：工厂就业先是吸收农业剩余劳动的巨泵，
后是被自动化与需求结构变化推下舞台——"制造业立国"
与"去工业化"是同一条曲线的两个半场。

## 假设与依赖

结构转变由恩格尔定律+生产率增速差异驱动（鲍莫尔成本病
的另一面）；后发优势假设技术可得——地缘管制时代该假设
正在被重新检验（芯片禁运=后发优势的制度性中断）。

## 教材锚
