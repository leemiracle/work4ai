# 04 · 工业经济学转代码：反垄断工具箱与产能沙盘

> **本章回答五问之五（本家族：讲透工业经济学）。**
> 三件套：**可机械化边界 → 代码走廊 → 工程师落点**。
> 核心判断一句话：本家族的可构造件精确到能出庭
> （合并模拟写进美欧执法实践）——**经济学里罕见的
> "代码即监管"现场**。

---

## 一、可机械化边界

| 环节 | 可机械化 | 形态 |
|------|---------|------|
| HHI/CR4 计算（含合并前后） | ✅ | 平方和——一行；份额数据是唯一瓶颈 |
| Cournot/Bertrand/Stackelberg 求解 | ✅ | 闭式解或方程组（本家族实验） |
| 合并模拟（含效率抗辩门槛） | ✅ | 代数——参数化扫描可自动化 |
| 需求估计（合并模拟的输入） | 🟡 | BLP 类模型可估计但工程重、识别假设强 |
| 市场界定（SSNIP） | 🟡 | 临界分析可算，替代弹性假设靠判 |
| 产能/学习曲线外推 | ✅ | 幂律拟合（莱特定律）——产业规划实用件 |
| 默契合谋的检测 | ❌ | 算法协调的"指纹"研究尚在早期 |
| 产业政策的事前评估 | ❌ | 反事实不存在——只有事后准实验 |

## 二、代码走廊

### 走廊①：合并模拟器（本家族实验）

```python
# Cournot N 对称：P = (a + N·c)/(N+1)；HHI = 10000/N
# 断言 A: 一阶条件残差 = 0（数值验证解析解）
# 断言 B: L == (HHI/10000)/eps      （Cowling-Waterson 恒等式）
# 断言 C: N:5→4 → P +8.0%、ΔHHI=500 → 触发 2023 指南结构推定
# 断言 D: 效率抗辩门槛 c' —— 5→4 需 -67%；2→1 无解（c'<0）
```

[experiments/cournot_hhi.py](experiments/cournot_hhi.py) 即此走廊的可跑版。
把它改造成不对称厂商（各 cᵢ 不同）就是真实案件工作底稿的
雏形——执法经济学家（grad school 出身）每天在做的事。

### 走廊②：学习曲线/产能外推

累计产量-单位成本双对数回归 → 莱特斜率 → 未来成本路径
外推——光伏/电池行业的产能投资、购电协议定价、
"多久平价"预测的标准件。**工程要点**：累计口径
（全球还是本厂）的选择改变结论——口径即立场
（02 章的眼睛在工程里复现）。

### 走廊③：HHI 数据管道

行业微观数据（营收按厂商）→ 相关市场界定（人工+SSNIP）
→ 份额→HHI → 案件筛查仪表盘。行业数据工程占九成
工作量，与[讲透审计学](../讲透审计学/04-审计学转代码.md)
的数据管道同构——"计算监管（computational antitrust）"
正在成为反垄断机构的新部门。

## 三、工程师落点

| 场景 | 落点 | 备注 |
|------|------|------|
| 反垄断执法/律所经济证据组 | 合并模拟、需求估计、损害计算 | 经济学博士含量最高的代码岗之一 |
| 企业竞争战略 | 定价优化、进入分析 | 与管理经济学家族共享 |
| 产业规划/咨询 | 产能沙盘、学习曲线外推、补贴测算 | 中国产业政策现场的主力工具 |
| 计算监管（新） | 算法合谋检测、平台数据审计 | 与计算机宇宙的交叉新职业 |

**诚实判词**：产业组织的工程化深但窄——真正吃香的
岗位在"反垄断经济学+数据"交叉处；纯建模能力
（会解 Cournot）是学术门票，工程价值在需求估计
（把模型喂饱）——**瓶颈永远在数据与识别，
不在均衡求解**。

## 四、反直觉发现（⑥）

**最成熟的代码件恰恰用在最不成熟的理论处**：
合并模拟被执法广泛采用，但其核心假设（竞争模式、
需求形态）没有共识——代码的精确性**包装**了假设的
不确定性（垃圾进、精确出）。反垄断界对此的自觉是
"多模型敏感度分析"（跑 Cournot+伯特兰+差异化三套，
报区间不报点值）——**代码的可信度来自假设的透明度，
不来自运算的精确度**。

## 五、✨美之时刻（⑧要件）：一行恒等式管五十年市场

**陈述**：`(P−c)/P = HHI/10000 ÷ |ε|`——Cowling-Waterson
（1968）一行代数，把"集中度、竞争强度、市场势力"
三个概念焊死成一个恒等式；此后五十年的反垄断结构
推定、市场势力测量、集中度-利润率文献都在这行的
引力场里。

**为什么美**：*统一*——经济学少有的"指标间恒等式"：
两个可独立观测的量（份额、弹性）决定第三个量（加价），
误差项为零。它像守恒律一样约束着一切关于"集中与
暴利"的叙述：任何说"高集中但低加价"的行业，
要么弹性巨大、要么竞争形态不是 Cournot——
恒等式逼你说清楚是哪种。

**怎么亲历**：取任何行业公开份额数据自算 HHI，
配上弹性假设扫一遍加价区间——你会发现"这个行业
太暴利"或"这个行业竞争惨烈"的争论，
大多数能用这一行代码裁判掉一半。
