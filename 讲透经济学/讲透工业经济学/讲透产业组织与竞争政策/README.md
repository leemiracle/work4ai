# 讲透产业组织与竞争政策 · 市场势力的诉讼科学

> **定位**：这支负责本家族的现代主体——产业组织理论
> （IO）与竞争政策（反垄断/合并审查/规制）。GB/T 79055
> 三级列表无此名（列表偏"部门与管理"，缺市场治理核心）——
> **自定主干支**，补齐学科现代内核（家族 00-04 章的主体
> 内容即此支的理论层）。

## 诞生

1890 谢尔曼法（先有法律后有理论——反垄断的头四十年
"靠常识执法"）→ 1940s 哈佛 SCP（给执法装上科学）→
1970s-80s 芝加哥学派+博弈论革命（Tirole 1988 定型新 IO）
→ 1990s 合并模拟进执法 → 2020s 新布兰代斯运动
（"大即是坏"回潮：平台反垄断时代）。中国线：
2008 反垄断法施行→2021 平台经济反垄断年→
2024 反垄断法修订与新设公平竞争审查制度。

## 核心问题（3-5 条）

- ✅ 已解：寡头定价与合并效应的计算（Cournot/伯特兰机器）
- ✅ 已解：市场界定的操作化（SSNIP——但平台经济正在掏空它）
- 🔄 前线：平台/数字市场的竞争政策（自我优待/扼杀式并购/
  看门人义务——2020s 全球立法潮）
- 🔄 前线：算法合谋与算法定价的反垄断定性
- ❌ 未解：创新损害理论（合并"杀死未来竞争者"如何举证——
  Instagram/WhatsApp 案的世纪难题）

## ✨这支最美的一个事实

Cowling-Waterson 恒等式（L=HHI/ε）让"集中度"与"暴利"
从经验相关升格为 Cournot 结构下的恒等——执法者用
可观测的 HHI 说话，理论家用可解释的 Lerner 说话，
一行代数给两界当翻译（家族实验 Part B 逐步复现）。

## 假设与依赖

执法者独立（规制俘获是永恒阴影）。
依赖[数学宇宙·博弈论](../../../讲透数学/讲透博弈论/)
