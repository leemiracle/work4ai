# 讲透工业经济地理 · 生产放在哪里

> **定位**：这支负责 GB/T 79055 三级"工业经济地理"——
> 工业区位、产业布局与集聚的空间面。工业的位置选择
> 是经济地理学最老的引擎室：**工厂放哪，城市、港口、
> 运网和区域差距就长成什么样**。**GB/T 三级**（非自定）。

## 诞生

1909 韦伯《工业区位论》：工厂选址=运输成本（原料指数）
+劳动力成本（等费线）的最小化——第一个可计算的区位模型。
其后：廖什（1940，市场区/需求圆锥）、艾萨德（1950s，
区域科学建制化）。中国现场："三线建设"（1964-80，
国防逻辑覆写经济逻辑——区位论的宏大反例）→
沿海开放（比较优势回归）→产业转移与"腾笼换鸟"
（2008 后）→新能源汽车时代的空间重组（2020s）。

## 核心问题（3-5 条）

- ✅ 已解：区位选择的基本权衡（运输/劳力/集聚三力）
- ✅ 已解：产业集聚的空间表现（开发区/集群的地理统计）
- 🔄 前线：供应链安全逻辑对效率区位的覆写（近岸/友岸
  ——芯片与电池产业链的空间重构）
- 🔄 前线：中国产业转移的梯度动态（中西部承接的真实与限度）
- ❌ 未解：数字区位（数据与算力的"地理"——工业区位论
  对比特世界失语的领域）

## ✨这支最美的一个事实

韦伯"原料指数"（失重工业靠近原料、纯装配靠近市场）百年
之后仍能解释炼铝贴电厂、装配贴港口——**运输成本的
物理直觉比多数经济学模型长寿**；而它的失效处
（数字产品的零运输成本）恰好标记了新旧经济的分界线。

## 假设与依赖

空间成本可量化（运费/时滞/关税）；区位决策由企业做出
（地方招商引资=政府替企业补贴区位成本——中国特有变量）；
依赖[讲透城市经济学](../../讲透城市经济学/)的集聚理论
（两支互为城乡界面：集聚的产业面/空间面）。

## 教材锚

- 韦伯《工业区位论》（1909，学科出生证明）
- 藤田昌久等《空间经济学》（新经济地理正典，与城市家族共用）
- 中文：中国工业布局与区域经济研究文献群
