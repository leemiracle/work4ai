# 讲透物流管理学 · 物流的工程学

> **定位**：这支负责物流的**组织与运营**——第三方物流（3PL/4PL）的契约、
> 仓与配的作业管理、KPI 体系、精益与敏捷的运营哲学。它是把定律变成
> 每天凌晨分拣线的东西。

## 诞生

物流管理从军事后勤（logistics 词源即军需）转民用：二战后美军后勤方法论
进入企业（1963 年美国实物配送管理协会 NCPDM 成立，1985 更名 CLM 确立
"logistics"术语）；1980 年代 MRP/ERP 把库存管理软件化；1990 年代 3PL 兴起
（企业把物流外包给专业公司）；2000 年代快递电商化（UPS/FedEx/顺丰/菜鸟）
把物流管理变成日均亿件级的实时系统。

## 核心问题（3-5 条）

- ✅ 已解：物流外包的边界（交易成本视角：资产专用性高则自营—— Williamson
  框架的物流应用）
- ✅ 已解：仓储作业的效率结构（单元化/标准化——托盘与集装箱是"管理即标准"
  的两大证明）
- 🔄 前线：KPI 体系的扭曲效应（时效考核 vs 成本考核 vs 客诉率的相互挤兑）
- 🔄 前线：末端组织形态（驿站/快递柜/众包/无人配送）的收敛
- ❌ 未解：物流平台（网络货运）的责任边界与定价治理

## ✨这支最美的一个事实

一个标准托盘（1.2m×1.0m）省下的钱超过许多发明：货物从"散装搬运"变为
"单元搬运"，装卸效率提升一个数量级，全球贸易因此重排——**管理学的最高
形式不是管人，是定标准**。集装箱（托盘的海运放大版）同理，见
[讲透交通运输经济学·讲透水路运输经济学](../../../讲透经济学/讲透交通运输经济学/讲透水路运输经济学/README.md)。

## 假设与依赖

KPI 可刻画绩效（Goodhart 风险：指标一旦成为目标就不再是好指标）；外包
契约可完备（剩余控制权问题）；作业流程可标准化（长尾异常件是管理黑洞）。
