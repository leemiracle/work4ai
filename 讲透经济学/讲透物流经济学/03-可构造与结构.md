# 03 · 可构造与结构：四件闭式神器

> **本章回答五问之四（本家族：讲透物流经济学）。**
> 物流学罕见的幸运：它的四个核心问题都有**闭式解**——EOQ、报童、√n 法则、
> (s,S) 策略。闭式解不是"省事"，是**结构本身**：它告诉你哪些参数重要、
> 重要到几次方、曲率多平。本章逐一拆解。

---

## 一、EOQ：两个成本的对冲（直觉先行）

直觉：订货有固定成本 S（一次下单/换产线的折腾），存货有持有成本 H
（资金+仓储+跌价）。订得勤批量小→S 项贵；订得懒批量大→H 项贵。

```
TC(Q) = D/Q·S + Q/2·H   →   Q* = √(2DS/H)，TC* = √(2DSH)
```

**结构三读**：
1. **对称性**：最优处两项成本恰好相等（各占 TC*/2）——对冲的结构 signature。
2. **平坦性**：TC(Q)=TC*·(Q*/Q+Q/Q*)/2：批量偏 50%，成本只涨 8.3%；
   偏一倍涨 25%。**最优值不敏感，方向才重要**——EOQ 教的是数量级不是小数点。
3. **参数弹性**：D 涨四倍，Q* 只涨两倍（√ 律）——大销量不必同比例囤货。

## 二、报童：一次订货对赌需求

单期商品（报纸、圣诞树、鲜奶、航班座位）：订 Q 份，需求 D 随机。
卖不掉损失 co（成本−残值），不够赚损失 cu（售价−成本）。
边际分析（多订一份的期望）：P(D≥Q)·(−co) + P(D<Q)·cu = 0 →

```
F(Q*) = cu/(cu+co)     —— 最优订量 = 需求分布的一个分位数
```

**结构读法**：最优策略不依赖分布形状，只依赖**临界比在分布上的位置**。
供应链的全部"服务水平"理论（SL*=1−co/(cu+co)）是这一行的变奏。
[讲透交通运输经济学](../讲透交通运输经济学/) 的航空收益管理（EMSR）与
[讲透旅游经济学](../讲透旅游经济学/) 的酒店超售，同为此式的产业后代。

## 三、平方根法则：波动不共振

n 个独立地区仓，各自备安全库存 z·σ·√L；合并为 1 中央仓后需求汇总，
方差相加而非标准差相加：

```
安全库存总量 ∝ √n·σ → σ·√n 的 n 仓  ==  σ 的 1 仓 ... 合并后 = 1/√n
```

**结构读法**：**波动是平方可加的，规模经济就藏在平方根里**——这与
随机游走扩散（σ√t）同源。反方向的代价：响应时间变长、运费变贵
（末端小批量）——√n 给集中以引力，时间给分散以斥力，网络形态=两种力的
平衡点（00 章地图）。

## 四、(s,S) 策略：连续检查下的最优形态

库存连续检查、固定订货成本 S 存在时，Arrow-Harris-Marschak（1951）证明
（凸性/ K-凸性条件）：最优策略形如"**掉到 s 就补到 S**"——一个数对。
**结构读法**：最优策略的形态（而非数值）可以整类地被证明——这是运筹学
给管理学的最好礼物：ERP 里千万级参数的再订货逻辑，结构证明只有几页。

## 五、✨美之时刻（⑧要件）：牛鞭效应——没有人犯错，波动却四倍

**陈述**：零售需求 ±5%，分销商按"看到的订单"预测并批量订货，制造商
看到 ±20%，原料商 ±40%。Lee 1997 拆出四个机制：需求信号处理（各自外推）、
批量化（凑单）、价格博弈（等促销）、配给博弈（缺货时虚报）。
**为什么美**：*必然*——每个环节都在做局部理性最优，宏观波动却指数放大；
这是"合成谬误"在产业里的精确版本，也是 Forrester 系统动力学与信息经济学
的合流点。**怎么亲历**：04 章走廊③的啤酒游戏 100 行模拟——四层供应链、
每个 agent 都用最优预测器，订单方差照样放大；再删掉"批发层"
（缩短链条）重跑，看瀑布变矮——**去中间化*也*是信息结构手术**，
这就是 DTC 直营浪潮的物流学注脚。

## 六、假设与代价（④要件续）

| 神器 | 关键假设 | 失效现场 |
|------|---------|---------|
| EOQ | 需求恒定、无数量折扣 | 快时尚生命周期内需求衰减 |
| 报童 | 单期、需求独立 | 服装跨季补货（多期版→(s,S)/能力规划） |
| √n | 各地需求独立 | 促销同频/天气共振时独立性破产 |
| (s,S) | 提前期确定 | 提前期波动时要加提前期方差项 |
| 牛鞭 | 各层按理性规则预测与下单 | 恐慌抢购/囤货待涨时预期形成方式突变 |

## 七、反直觉发现（⑥要件汇总）

EOQ 的平坦（精确不值钱）· 报童把"积极备货"变成不等式（态度可计算）·
√n 的集中引力（分散的"安全感"是统计幻觉）· 牛鞭（理性人放大波动）。

## 👁 认知升维（⑨要件）

**闭式眼**：见到一个管理口号，先问它背后有没有闭式结构——有，参数在哪、
曲率多平；没有，它就只是口号。闭式解的真正价值不是"算得准"，是
**告诉你什么不值得算准**（EOQ 的 8.3% 宽容）。
