## 一、诞生（三个原生问题）

1. **工厂该囤多少货（1913）**——福特时代的工程师 Harris 在《工厂》杂志发表
   《多少件为一批量》，推出 EOQ 公式：订货成本与持有成本在批量上对冲，
   最优批量=√(2DS/H)。**现代库存理论的第一行代码**。
2. **成本黑洞在哪里（1962）**——德鲁克在《财富》发表《经济领域的黑暗大陆》：
   分销（distribution）成本占美国 GNP 惊人比例却无人度量——物流作为学科的
   动员令。
3. **需求信号为什么放大（1997）**——斯坦福 Lee 等人把 Forrester 1961 年的
   系统动力学观察形式化为**牛鞭效应**：零售端 ±5% 的波动，到上游工厂变成
   ±40% 的订货震荡——信息结构（而非人性）制造了波动。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 批量的最优权衡（Harris 1913 EOQ） | ✅ 闭式已解 | 四参数一根号，成本曲线极平（+50% 批量仅 +8.3% 成本） |
| 单期报童问题（Edgeworth 1888/Arrow 1951） | ✅ 闭式已解 | 订多少=分位数：cu/(cu+co)——全部随机库存论的种子 |
| 安全库存的集中化（平方根法则） | ✅ 已证明 | n 仓并 1 仓，安全库存降为 1/√n——网络设计的引力 |
| 牛鞭效应的四个成因（Lee 1997） | ✅ 已证明 | 批量化/价格博弈/需求预测/配给博弈——信息内生放大 |
| JIT vs JIC（韧性与效率的权衡） | 🔄 剧烈重估 | 2021-22 危机把"零库存"重写为"关键件冗余" |
| 最后一公里成本结构 | 🔄 前线 | 常占配送总成本一半；众包/驿站/自提的组织实验 |
| 网络级韧性设计 | ❌ 未解 | "冗余放哪、放多少"尚无统一优化框架 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 需求可预测（分布已知） | 安全库存可算 | 分布漂移即系统性缺货/积压（预测的阿喀琉斯之踵） |
| 成本可加（运输+库存+设施+缺货） | 总成本目标函数成立 | 交叉弹性与组织成本被外生化 |
| 集中-响应可权衡（√n 对响应时间） | 网络设计成优化题 | 服务水平的异质性被单一 SL 抹平 |
| 提前期确定或可建模 | 订货点可设 | 提前期波动才是缺货主凶（实证共识） |
