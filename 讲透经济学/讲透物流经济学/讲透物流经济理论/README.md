# 讲透物流经济理论 · 物流的物理学

> **定位**：这支负责物流的**权衡结构与网络经济**——EOQ/报童/√n/牛鞭四大结构、
> 集中与分散的力场、韧性与效率的第四轴。它是把"送快递"上升为定律的部分。

## 诞生

1913 年 Harris 的 EOQ（批量对冲）与 1951 年 Arrow-Harris-Marschak 的随机
库存论（不确定性入模）是理论双根；1970-80 年代地理学与 OR 合流产下
设施选址与网络设计理论；1997 年 Lee 的牛鞭效应把信息结构推上主位；
2021-22 供应链危机后，韧性（中断风险）正式成为第四根权衡轴。

## 核心问题（3-5 条）

- ✅ 已解：四大闭式结构（家族 [03 章](../03-可构造与结构.md)）——对冲、
  分位、平方根、数对
- ✅ 已解：风险池化的边界（需求相关性↑，√n 引力↓——共振击穿独立性假设）
- 🔄 前线：韧性-效率前沿的刻画（CVaR 约束下的网络设计）
- 🔄 前线：物流成本占 GDP 比重的宏观分解（"物流成本高"的统计口径之争：
  结构 vs 效率）
- ❌ 未解：多主体供应链的最优信息结构（谁该看到什么——机制设计级问题）

## ✨这支最美的一个事实

把 100 个仓库合并成 1 个，安全库存只剩十分之一（1/√100）——**分散的安全感
是统计幻觉**：波动在平方可加的世界里，集中就是保险。整个电商仓网从
"遍地前置仓"到"区域大仓+选择性前置"的战略摇摆，就是 √n 引力与时效斥力
的反复平衡。

## 假设与依赖

需求分布已知且平稳（预测的阿喀琉斯之踵）；各级需求独立（√n 的命门）；
成本可加（组织成本外生）。三条假设各自对应一个失效现场：预测漂移、
促销共振、跨部门博弈。
