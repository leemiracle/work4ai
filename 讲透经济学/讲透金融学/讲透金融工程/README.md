# 讲透金融工程 · 把支付函数当积木造出来

> **定位**：这支负责"无套利定价的工程面"——衍生品设计、动态复制、
> 波动率曲面、对冲策略。资产定价问"均衡给这个证券多少价"，
> 金融工程问"我用什么组合把这个支付拼出来"。归组覆盖：金融工程、
> 金融衍生工具（无套利侧）。

## 诞生

1973 双响：CBOE 开张（市场）+ Black-Scholes-Merton 公式（理论）；
1979 CRR 二叉树让定价走进计算器；1994 Dupire 局部波动率、
Heston 1993 随机波动率——微笑曲线成为常驻课程。

## 核心问题（3-5 条）

- ✅ 已解：完备市场下欧式/路径依赖衍生品定价与对冲（树的三个化身：
  链/模拟/PDE，家族 04 章走廊 1）
- ✅ 已解：波动率曲面的构造（从期权价格反解 σ(k,T)——Dupire）
- 🔄 前线：不完备市场定价（跳跃/流动性下无唯一价——只剩区间与偏好）
- 🔄 前线：XVA（对手方信用+资金成本的估值调整——定价与风险的再合并）
- ❌ 未解：对冲的极限（再平衡频率有限+跳跃=复制永远有残差）

## ✨这支最美的一个事实

动态复制像变魔术：**股票+债券按 Δ 比例连续再平衡，可以拼出任何你想要的
支付曲线**——但你必须"连续"交易，而真实市场有最小价格档、有闭市、有跳空。
工程的价值就在理论与现实的这条缝里：**衍生品定价师卖的不是公式，
是公式在离散世界里打折扣后仍然成立的那些场合**。
