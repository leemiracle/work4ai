# 00 · 体系结构：金融的三根柱子与三次革命

> **本章回答五问之一（本家族：讲透金融学）。**
> 金融大厦 = **三根功能柱（跨期配置·风险交易·信息处理）** 架在一块制度地基
> （货币与合约的可执行性）上，由**三次革命（1952 组合/1964 均衡/1973 无套利）**
> 建成，顶层住着八支（GB/T 22 个三级支的归组）。
> 一句话分工：**柱子说金融干什么，革命说金融怎么想，八支说金融谁在干。**

---

## 一、直觉开篇：金融到底是什么生意

一个渔民今天多打的鱼想留到冬天吃，一个学生想用未来的收入今天读书——
**金融的全部生意就是搬运两样东西：时间（消费的时点）与风险（世界的分叉）**。

- 渔民冬天想吃鱼：存款/债券（把今天的资源搬到未来）
- 学生今天要钱：贷款（把未来的资源搬到今天）
- 船可能沉：保险/期权（把"沉船"这个结局卖给别人）

反直觉第一击（有效市场悖论，Grossman-Stiglitz 1980）：
**市场越有效，研究它越无价值**。若价格完全反映信息，就没人有理由花钱研究
信息——可没人研究，价格凭什么反映信息？所以均衡只能是"近似有效"：
错误定价的收益刚好补偿研究的成本。**"市场有效"不是一个状态，是一场拔河。**

**三把尺子**（看任何金融产品的第一刀）：
- **现金流**：它未来给你什么（利息/股息/赔付）——定价的原材料
- **折现率**：你用什么利率把它搬回今天——时间与风险的价格
- **状态**：支付在哪些世界状态下发生——衍生品的全部灵魂

## 二、三根功能柱：金融对经济做的事

| 柱 | 功能 | 一句机制 | 对应支 |
|----|------|---------|--------|
| 跨期配置 | 把资源在时间上搬运 | 借贷市场出清利率 | [货币经济学](讲透货币经济学/)·[公司金融](讲透公司金融/) |
| 风险交易 | 把风险卖给最能承受它的人 | 分散化+风险溢价 | [资产定价](讲透资产定价/)·[风险管理](讲透风险管理/)·[保险学](../讲透保险学/) |
| 信息处理 | 把分散信息聚进一个数 | 价格=信息的充分统计量（近似） | [金融市场](讲透金融市场/)·[行为金融](讲透行为金融学/) |

**为什么按功能切而不按产品切**：产品会过时（票据→股票→衍生品→DeFi 代币），
功能三百年不变。功能观的妙处：看任何"金融创新"，先问它搬运的是时间、风险
还是信息——2015 年的 P2P 是借贷（时间），2000 年的 CDS 是保险（风险），
2021 年的预言机是报价机（信息）。**新瓶装的一定是旧酒，问题只是装得是否更便宜。**

## 三、三次革命谱系：金融怎么变成科学

| 革命 | 年代 | 口号 | 核心定理 | 建成物 |
|------|------|------|---------|--------|
| 风险可量化 | 1952 | 分散化是免费午餐 | 均值-方差前沿（Markowitz） | 组合管理业 |
| 均衡可定价 | 1958-1976 | 风险有市场价格 | MM（1958）·CAPM（1964）·APT（1976） | 指数基金（1971-76） |
| 契约可合成 | 1973- | 无套利+动态复制 | BSM 期权定价·FTAP（Harrison-Kreps 1979） | 衍生品产业（万亿级名义本金） |

三次革命的递进关系不是并列而是**抽象升级**：第一次把风险变成数（方差），
第二次把风险的价格变成数（β·λ），第三次把"任何支付"变成数（风险中性期望）。
到第三层，金融定价与本福德无关、与投资者偏好无关——**只剩概率结构与复制成本**，
这正是它可机械化（04 章）的根源。

📖 **故事框：公式与市场的三个月**
1973 年 4 月 26 日 CBOE 开张，只交易 16 只股票的看涨期权；5 月
Black-Scholes 论文发表。此前期权柜台交易的买卖价差可以到 10%，
公式上计算器后价差一年内收窄到原来的零头——**不是市场学会了自己该值多少，
是做市商学会了用公式对冲**。科学与工业互相喂养的加速度纪录。
（反面同一枚硬币：1998 年 LTCM——同一批诺奖得主的复制机器在流动性
蒸发时同时失灵。定价定理没有错，错在假设"总有人接你的对冲单"。）

## 四、八支地图：GB/T 22 个三级支的归组

GB/T 79073 明列三级 22 支（货币银行、金融市场、金融机构、公司理财、投资学、
证券投资、金融工程、金融风险管理、保险经济相关支、金融史等），本家族按问题域
归组为 8 个主干支（逐支 README 头部注明覆盖域）：

| 支 | 归组吸收的三级域（问题域口径） | 一句定位 |
|----|------------------------------|---------|
| [货币经济学](讲透货币经济学/) | 货币理论·银行·中央银行·通胀 | 金融的制度地基 |
| [金融市场](讲透金融市场/) | 金融市场·金融机构·微观结构·国际金融 | 交易发生的地方 |
| [公司金融](讲透公司金融/) | 公司理财·资本结构·治理·并购 | 资金需求方 |
| [资产定价](讲透资产定价/) | 投资学·证券投资·金融理论（均衡侧） | 均衡价格论 |
| [风险管理](讲透风险管理/) | 金融风险管理·信用·流动性 | 风险当作对象 |
| [金融工程](讲透金融工程/) | 金融工程·衍生工具（无套利侧） | 支付当作积木 |
| [金融科技](讲透金融科技/) | 金融科技·互联网金融·数字化 | 中介的代码化 |
| [行为金融学](讲透行为金融学/) | 跨支（行为与心理域，含金融史案例） | 理性的纠错本 |

归组的原则：**按"问题域"而非"机构"**——银行存款与 DeFi 稳定币在同一支
（都是货币），保险与 CDS 分居两家族（一个在[保险学](../讲透保险学/)、
一个在这里，见 00 章 §六的边境说明）。

✨ **美之时刻 ①：Black-Scholes-Merton 公式（1973）**

陈述：在无摩擦、连续交易的完备市场里，执行价 K、到期 T 的欧式看涨期权
今天的价格为 C = S·N(d₁) − K·e^(−rT)·N(d₂)，其中
d₁,₂ = [ln(S/K) + (r ± σ²/2)T] / (σ√T)。整个公式里**没有一个人的风险偏好**。

为什么美：**统一+意外**——"买期权"这种最主观的交易，价格公式里居然只有
五个可观测参数（S, K, r, T, σ）；风险偏好被"动态复制"整个消除：期权 =
 continuously 再平衡 的股票+债券组合。偏好被消掉的那一刻，定价从经济学
变成了概率论。
怎么亲历：跑本家族实验 [option_binomial_pricing.py](experiments/option_binomial_pricing.py)——
离散二叉树一步步加细，价格收敛到这个闭式解，亲眼看见"复制"如何逼出唯一价格。

## 五、一块制度地基：为什么金融学离不开货币经济学

三根柱子都站在同一块地基上：**合约的可执行性**。期货之所以能对冲，是因为
保证金与清算所在；股票之所以有价值，是因为股东权利有法庭背书；DeFi 之所以
震动行业，是因为它第一次尝试把地基本身写进代码。地基由[货币经济学](讲透货币经济学/)
研究——利率是它的地心引力（见 [讲透宏观经济学](../讲透宏观经济学/) 00 章），
通胀是它的地震，中央银行是它的守夜人。**看懂任何一次金融危机，一半在看柱子
（错定价），一半在看地基（谁失信）**。

## 六、与保险学的边境（本宇宙家族分工）

金融与保险都在卖风险，为什么是两个二级学科？——**期限结构与业务方向相反**：

| | 金融（银行/市场） | 保险 |
|---|---|---|
| 期限 | 短借长贷（期限错配是命门） | 先收后赔（负债比资产更长久是常态） |
| 风险来源 | 市场价格（相关、连续变动） | 个体事件（近似独立、跳跃） |
| 数学母科 | 随机分析（布朗运动） | 大数定律（独立同分布） |
| 崩溃模式 | 挤兑（流动性） | 相关性灾难（巨灾/疫情） |

两边的汇流点——巨灾债券、寿险嵌期权、偿付能力监管——是 21 世纪最活跃的
交界（[保险学 01 章](../讲透保险学/01-近五年创新.md)）。

## 七、假设与代价（家族五张底牌的展开）

见家族 README 表。本章总纲：**金融学的每个假设都是"定价权的让渡"**——
无套利假设买到"唯一价格"，付出"套利者必须有钱撑到价格回归"；连续交易买到
闭式公式，付出"跳跃时公式失效"；理性假设买到均衡，付出"泡沫成为无法命名
的东西"。判断一个金融模型，先问它把什么风险藏进了假设。

## 👁 这章给了你什么新眼睛（认知升维）

- **价格是信息的容器，不是价值的标签**：看任何资产价格，第一反应不是"值不值"，
  而是"这个数聚合了什么信息、谁有动机污染它"
- **先问搬运的是什么**：时间、风险还是信息——三柱分类切开一切金融产品的包装
- **无关性定理是地图不是结论**：MM 证明"在完善市场里资本结构无关"，
  恰好告诉你离开完善市场后该去哪找答案（税、破产成本、代理）——
  "证明无关"是标出"有关之处"的探针
- **公式越优美，假设越锋利**：BSM 的五个参数背后藏着四个假设，每个假设的
  破产日期都写在危机史里
