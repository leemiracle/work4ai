# 讲透行为金融学 · 理性假设的纠错本

> **定位**：这支负责"系统性记录投资者什么时候、以什么方式偏离理性"——
> 前景理论、过度自信、处置效应、动量与泡沫。它不是"骂市场 irrational"
> 的合集，而是理性模型的可证伪对照组。归组覆盖：跨三级的问题域归组支
> （行为与心理域+金融史案例），GB/T 未单列，按问题域自定。

## 诞生

1979 Kahneman-Tversky 前景理论（参照点依赖/损失厌恶——心理学进入
定价）；1985 De Bondt-Thaler 均值回归与 Shiller 波动性之谜
（市场波动大于现金流波动能解释的程度）；2000-2001 互联网泡沫
把本支从边缘推向主流（Shiller《非理性繁荣》）。

## 核心问题（3-5 条）

- ✅ 已解：处置效应（卖盈持亏）的稳健存在（全球数据反复复现）
- ✅ 已解：动量与反转（中期动量/长期反转——行为与风险的解释之争仍在）
- 🔄 前线：有限套利理论化（Shleifer-Vishny 1997 框架的当代扩展）
- 🔄 前线：文本与 LLM 情绪度量（新闻/社交媒体→情绪因子）
- ❌ 未解：泡沫的实时识别（每次都说"这次不一样"的人与每次都喊狼来的人
  谁对——只能事后裁决）

## ✨这支最美的一个事实

投资者卖出赚钱股票的速度是卖出亏损股票的 1.5-2 倍——**人们宁可让
错误继续，也不肯把错误坐实**（损失厌恶：亏损的痛≈同额盈利的爽的 2 倍
多）。这一条人性在全球几十个市场用三十年数据反复复现，
比多数"因子"都稳健——**最持久的 alpha 藏在最古老的心理里**。

## 假设与依赖

站在"偏误系统性、可预测"上（随机错误会抵消，系统错误才成学科）；
依赖心理学实验方法与[讲透数理统计](../../../讲透数学/讲透数理统计/)
（异象=统计检验+多重检验纪律）。
