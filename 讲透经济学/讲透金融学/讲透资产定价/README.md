# 讲透资产定价 · 均衡价格论：风险的市场价

> **定位**：这支负责回答金融学的中心问题——**为什么不同资产要求不同的
> 期望收益？**从马科维茨组合选择到 CAPM 到因子模型到 SDF 统一框架，
> 是三次革命中第二次（均衡定价）的完整展开。归组覆盖：投资学、
> 证券投资、金融理论（均衡侧）。

## 诞生

1952 马科维茨（风险=方差）；1964 夏普等 CAPM（β 定价）；
1976 Ross APT（多因子）；1993 Fama-French 三因子；
2013 Fama 与 Shiller 同年诺奖——"市场有效"与"可预测"两答案同时授奖。

## 核心问题（3-5 条）

- ✅ 已解：组合选择的数学（均值-方差前沿=凸优化，完全闭环）
- ✅ 方法已解·实证半解：SDF 框架统一一切定价 p=E[mx]（理论）与因子动物园（实证）
- 🔄 前线：因子动物园治理（数百"因子"经多重检验校正后存活多少——ML 双刃）
- 🔄 前线：机器学习截面定价（Gu-Kelly-Xiu 2020 范式，见家族 01 章）
- ❌ 未解：股权溢价之谜（消费基础模型需要荒谬的风险厌恶才能解释 6% 溢价）

## ✨这支最美的一个事实

CAPM 的结论野心得吓人：**在均衡里，全市场只有一个组合值得持有**
（市场组合），一切资产的定价只需一个数（β）。六十年的因子研究
本质都在问同一句话：**"只靠 β"到底错了多少？**——每发现一个因子，
就是在 CAPM 的世界地图上多标一片未知海域。
