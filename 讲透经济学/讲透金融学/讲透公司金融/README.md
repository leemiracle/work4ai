# 讲透公司金融 · 资金需求方的决策学

> **定位**：这支负责"企业怎么找钱、怎么花钱"——投资决策（NPV）、
> 融资决策（债股比例）、分配决策（股利回购）、治理决策（谁监督经理）。
> 金融市场上每一只证券的供给端都从这里发出。归组覆盖：公司理财、
> 资本结构、公司治理、兼并收购。

## 诞生

1958 莫迪利亚尼-米勒定理把公司金融变成科学（资本结构无关→缺口清单）；
1976 Jensen-Meckling 代理成本理论把"经理是人"纳入模型；
1980s Jensen 接管市场与自由现金流假说、LBO 十年。

## 核心问题（3-5 条）

- ✅ 已解：投资决策准则（NPV 最大化——与其他准则的比较已闭环）
- ✅ 已解：资本结构的三个缺口（税盾/破产成本/代理）及其权衡
- 🔄 前线：ESG 与利益相关者资本主义的会计化（公司到底为谁经营）
- 🔄 前线：PE/VC 的治理实验（期限治理 vs 上市公司的永续治理）
- ❌ 未解：中国式股权融资偏好之谜的完整解释（MM 预言反着走）

## ✨这支最美的一个事实

MM 定理证明"怎么切饼不改变饼的大小"，结果反而催生了整个学科：
**证明无关，正是为了找出有关的**——税、破产、代理，每一个缺口都长出
一个理论流派和一条华尔街业务线。无关性定理是学科史上最肥沃的"零"。

## 假设与依赖

站在"企业是现金流的可分离束"上（法人作为合同束，Coase-Jensen 血统）；
依赖[讲透博弈论](../../../讲透数学/讲透博弈论/)（代理=委托代理博弈）与
会计语言（现金流信息的计量基础）。
