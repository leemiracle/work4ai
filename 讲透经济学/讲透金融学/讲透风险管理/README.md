# 讲透风险管理 · 把风险当作对象来管理

> **定位**：这支负责"风险怎么量、怎么汇报、怎么对冲、怎么被监管"——
> VaR/ES/压力测试/资本充足率。它是最年轻也最制度化的支：
> 理论的每次进步都由灾难推动。归组覆盖：金融风险管理、信用风险、
> 流动性风险。

## 诞生

1993 G30 报告首倡 VaR、1996 巴塞尔市场风险修正案把它写进全球监管；
1998 LTCM（四个 σ 之外的月份连续出现）；2008 危机终结"风险可加总"的天真；
2022-2023 LDI/SVB 让"走廊外挤兑"进入词汇表（家族 01 章前线四）。

## 核心问题（3-5 条）

- ✅ 已解：市场风险度量（VaR 三法+ES，可算可监管）
- ✅ 已解：信用风险的两大模型系（结构式 Merton 1974 / 简约式）
- 🔄 前线：非银中介的监管边界（什么算"事实上的银行"）
- 🔄 前线：网络与传染模型（一家倒下沿什么边传多远）
- ❌ 未解：内生风险——风险度量本身改变行为、行为改变风险（反思性闭环）

## ✨这支最美的一个事实

危机时刻相关性趋向 1：平时分散得漂亮的组合，崩盘时所有资产一起跌——
**分散化在恰好最需要它的时刻失效**。这不是巧合而是结构：流动性紧张时
所有人卖同一批"能卖的"资产，分散化的数学假设（稳定的相关结构）被
自己的持有人打破。

## 假设与依赖

站在"历史分布代表未来"与"风险可加总"上；依赖极值理论（ EVT，尾部
建模的数学本体）与[讲透概率论](../../../讲透数学/讲透概率论/)。
姊妹传统：[讲透保险学](../../讲透保险学/)（同一问题的精算语言，
家族 00 章 §六对照表）。
