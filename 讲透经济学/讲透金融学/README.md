## 一、诞生

金融实践古已有之（美索不达米亚的借贷泥板），但**金融学作为科学是二十世纪的产物**，
由三次革命建成：

1. **1952 马科维茨《组合选择》**——风险第一次被定义为方差、被当作可优化的对象。
   "分散化是唯一的免费午餐"从谚语变成定理。现代金融学元年。
2. **1958-1964 均衡定价线**——莫迪利亚尼-米勒（1958）证明完善市场下资本结构与
   股利政策无关；夏普（1964）等给出 CAPM：风险的价格 = β·市场溢价。
   金融从"描述合约"变成"推导定理"。
3. **1973 无套利定价**——布莱克-斯科尔斯-默顿期权定价公式发表同年，芝加哥期权
   交易所（CBOE）开张。**公式与市场互相喂养**：理论给市场产品，市场给理论每日
   检验。这是科学与工业结合速度的纪录（默顿-斯科尔斯 1997 诺奖；LTCM 1998 崩塌
   则是同一枚硬币的反面）。

2008 年金融危机是第四次塑造事件：它没有推翻三次革命，但暴露了"市场即真理"的
边界——[风险管理](讲透风险管理/)与[行为金融](讲透行为金融学/)两支由此从
边缘走向核心（01 章）。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 风险如何度量与组合（马科维茨 1952） | ✅ 已解 | 均值-方差前沿，分散化的数学 |
| 完善市场下资本结构无关（MM 1958） | ✅ 已解 | "无关性"定理划出"何时有关"的地图 |
| 均衡定价 β（CAPM 1964） | ✅ 数学已解，实证半解 | 教科书支柱，但 β 解释截面收益长期失败（因子动物园） |
| 完备市场下期权定价（BSM 1973） | ✅ 已解 | 无套利+动态复制，衍生品产业的宪法 |
| 汇率/股价可否预测 | 🔄 永恒前线 | 有效市场假说（Fama 1970）：价格多快反映信息 |
| 泡沫能否被识别与刺破 | ❌ 未解 | Shiller 与 Fama 2013 同年诺奖——两种答案同时授奖 |
| 尾部风险定价 | ❌ 未解 | 平时定价准确的市场为何危机时刻集体失效（08 年/2020.3） |
| DeFi 是否新金融范式 | 🔄 前线 | 消除中介的同时把法律保护换成代码（01 章） |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 无套利（不存在免费的午餐） | 定价定理的引擎：无套利 ⟺ 存在等价鞅测度（FTAP） | 危机时套利者破产、价差可以长期存在（Limits of Arbitrage） |
| 投资者理性·同质预期 | 均衡模型可解（CAPM 的解就是市场组合） | 泡沫、动量、处置效应全部成为"异象"无处安放 |
| 市场完备（任何支付可复制） | 每个合约有唯一价格 | 真实市场不完备：流动性蒸发即复制失败（08 年 CDS） |
| 价格连续交易（连续时间） | BSM 优美的偏微分方程 | 跳跃风险被系统性低估（1987、2008、2010 闪电崩盘） |
| 风险可加总（VaR 思路） | 一个数汇报全行风险 | 尾部相关性与内生风险被平均掉——危机前 VaR 都很小 |
