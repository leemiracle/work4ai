# 讲透货币经济学 · 金融的制度地基

> **定位**：这支负责"货币是什么、银行怎么造钱、中央银行怎么管"——
> 一切资产价格的地心引力（利率）与地震源（通胀）都在这里。
> 归组覆盖 GB/T 79073 三级域：货币理论、银行、中央银行、通货膨胀。

## 诞生

1936 凯恩斯把货币经济与实物经济打通（《通论》利率章）；
1963 弗里德曼-施瓦茨《美国货币史》用百年数据证明
"通胀处处且始终是货币现象"；2008 量化宽松与 2020-2023 通胀归来
是本支的两次当代大考。

## 核心问题（3-5 条）

- ✅ 已解：部分准备金银行内生创造货币（贷款造存款，不是存款造贷款）
- ✅ 已解：货币数量论的适用域（长期物价、短期产量——货币中性的期限合同）
- 🔄 前线：货币政策的传导机制（利率→信贷→资产价→实体，每环时滞与泄露）
- 🔄 前线：QE/QT 时代货币数量论还成立吗（2008 后 M 大增而通胀不起，2021 后反转）
- ❌ 未解：央行数字货币（CBDC）下商业银行地位——存款搬家会不会杀死信贷创造

## ✨这支最美的一个事实

一张纸的成本是几分钱，购买力是一百元——**货币的价值是全社会的共同信念，
而央行的工作就是每天证明这个信念是对的**（通胀目标制=公开的自我承诺机制，
时间不一致性理论的制度化解法，见[宏观经济学](../../讲透宏观经济学/)）。

## 假设与依赖

站在"货币需求稳定"上（数量论 MV=PY 的 V 不能乱跳——2020 年它乱跳了）；
依赖银行业的行为方程。代价：货币的定义随金融创新不断失效
（M0/M1/M2 的边界被货基与稳定币侵蚀）。
