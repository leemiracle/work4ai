# 讲透金融科技 · 中介的代码化重写

> **定位**：这支负责"技术如何逐块重写金融中介"——支付（移动/即时）、
> 信贷（大数据风控）、交易（算法/链上）、基础设施（区块链/云/AI）。
> 视角提示：技术是名词，金融功能才是主语（家族 00 章三柱分类）。
> 归组覆盖：金融科技、互联网金融、数字化。

## 诞生

2007 M-Pesa（肯尼亚手机货币——无银行账户者的支付Leapfrog）；
2009 比特币创世块（去中介结算的第一次工程实现）；
2020-2021 DeFi 之夏与 2022 出清（家族 01 章前线一）；
2010s 中国移动支付双寡头格局——本支的最大田野。

## 核心问题（3-5 条）

- ✅ 已解：移动支付的双边市场结构（规模经济+网络效应的教科书案例）
- ✅ 已解：链上结算的工程可行性（AMM/闪电贷在代码层可运行）
- 🔄 前线：稳定币监管（私人货币与主权的边界）
- 🔄 前线：AI 核保/信贷（公平性与歧视的量化——法规与模型的赛跑）
- ❌ 未解：代码即合约的失效责任（智能合约 bug 由谁兜底——法律真空）

## ✨这支最美的一个事实

AMM 用一条曲线 x·y=k 代替了整部做市法律：不需要信任任何对手方，
流动性由公式被动提供——**三百年做市商制度的全部功能被压缩进一行
代数式**。代价同样优美地显形：无常损失，即提供流动性的人被动持有
库存风险。功能可以压缩，风险守恒。
