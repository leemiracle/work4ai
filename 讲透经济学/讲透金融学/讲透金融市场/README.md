# 讲透金融市场 · 交易发生的地方

> **定位**：这支负责"市场本身如何运转"——订单怎么撮合、价格怎么形成、
> 流动性从哪来、机构为什么存在。其他支研究"价是多少"，这支研究
> "这个数是怎么被报出来的"。归组覆盖：金融市场、金融机构、
> 微观结构、国际金融市场。

## 诞生

1602 阿姆斯特丹交易所与荷兰东印度公司第一只可交易股票（现代市场原型）；
1971 NASDAQ 第一个全电子市场；1980s 微观结构理论成型
（Kyle 1985、Glosten-Milgrom 1985：买卖价差=逆向选择的补偿）。

## 核心问题（3-5 条）

- ✅ 已解：买卖价差的分解（订单处理成本+逆向选择+库存风险）
- ✅ 已解：做市商的报价策略（在不利信息与库存约束下的最优化）
- 🔄 前线：高频市场的稳定性（2010 闪电崩盘后"熔断+最小报价停留"的制度修补）
- 🔄 前线：市场分散化（暗池/链上 DEX 与主市场的价格发现竞争）
- ❌ 未解：流动性为什么蒸发、何时蒸发（ crises 的第一因，至今无预警定理）

## ✨这支最美的一个事实

一价定律在毫秒级被执行：同一股票在两个市场的价差一旦超过套利成本，
几毫秒内被抹平——**"市场有效"不是比喻，是机房里真跑着的代码**。
但同一时刻跨境的香蕉价差可以挂几十年：套利的速度=信息可代码化的速度。
