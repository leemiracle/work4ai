# 讲透贫困与不平等 · 贫困线、洛伦兹曲线与"给钱"的证据

> 支：[讲透发展经济学](../README.md) 自定主干支。家庭的尺度——
> 谁是穷人、为什么穷、给钱有没有用、不平等怎么量。

## 定位句

本支负责**微观发展线**：贫困的测度（贫困线/FGT 指标族）、
不平等的测度（洛伦兹/基尼/公理化）、贫困陷阱机制（信贷/营养/
行为带宽）、以及 RCT 证据库（现金转移、教育健康干预、普惠金融）。

## 诞生与关键事件

- 1905 洛伦兹曲线；1912 基尼系数——分配测度的公理化起点
- 1971 Sen 贫困指数；1984 Foster-Greer-Thorbecke FGT 指标族
  （今日世界银行标准）
- 1990s 世界银行"每天 1 美元"线；2022 更新为 2.15 美元（2017 PPP）
- 2011 班纳吉-迪弗洛《贫穷的本质》；2019 诺奖 RCT 三人组
- 2022 Egger 等 *Econometrica*：肯尼亚 653 村现金转移一般均衡
  实验；2024 115 项研究元分析：劳动供给不降

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 无条件现金转移是否养懒人 | ✅ RCT+GE 证据主流：劳动供给基本不降 |
| 贫困陷阱存在吗（单均衡 vs 多均衡） | 🔄 经验识别困难（Banerjee-Duflo 主张切小问题） |
| 极端贫困率的历史下降与 COVID 反复 | ✅ 数据清楚（1990 约 36%→2019 约 8.4%，2020 代初小幅反弹） |
| 不平等指标的价值权重（头寸/深度/严重度） | ✅ 公理化清楚（FGT 参数即伦理选择） |
| PPP 口径对贫困率的摆动 | 🔄 常态问题（换基期可挪动数个百分点） |

## 这支最美的一个事实（一句）

基尼系数的一个积分定义同时满足四条公理（匿名、尺度不变、
人口复制、Pigou-Dalton 转移）——"给富人 1 元转给穷人必降
不平等"这条伦理直觉，被写成了数学性质。

## 假设与依赖

读本支无需高深数学；假设：福利可用收入代理、PPP 换算可信、
RCT 内部效度可外推——三条都是本支的日常自我批评对象。
