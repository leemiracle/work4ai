# 讲透发展经济学 · 为什么有的国家富、有的人穷

> 发展经济学：**一门双尺度学科**——国家为什么贫富悬殊（增长与发展），
> 家庭为什么陷入贫困（贫困与不平等）；两个尺度的问题是同一个
> 问题的两面：总量的分解落到每个家庭头上，就是收入分配。
>

> 宇宙：[讲透经济学](../README.md) · 家族层全量，章幅中距。

## 诞生

1949 年杜鲁门就职演说首次把"欠发达地区"（underdeveloped areas）
变成全球政策议程，学科随之制度化；但思想源头与工具箱分期成熟：

1. **宏观线**：哈罗德-多马 1939/1946（增长=储蓄率）→ 索洛 1956
   增长模型与增长核算（1987 诺奖）→ 内生增长（罗默 1986/1990、
   卢卡斯 1988，2018 诺奖）→ 制度转向（Acemoglu-Johnson-Robinson
   2001 殖民起源，2024 诺奖）
2. **结构主义与政策线**：普雷维什 1950 中心-外围论 → 进口替代
   vs 出口导向的半个世纪试验 → 华盛顿共识及其修正
3. **微观革命**：贫困陷阱理论（Banerjee-Duflo）→ 随机对照实验
   （RCT）方法论（2019 诺奖 Banerjee-Duflo-Kremer）——"把大问题
   切成可实验的小问题"

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 增长的直接来源（要素 vs TFP） | ✅ 增长核算成熟 | 残差（TFP）解释国富国穷的大头 |
| 条件收敛（穷国在控制稳态条件后更快增长） | ✅ 经验稳健 | 绝对发散、条件收敛——政策含义重大 |
| 极端贫困率的历史性下降 | ✅ 数据清楚 | 1990 约 36% → 2019 约 8.4%（$2.15 线，世界银行） |
| 直接发钱是否养懒人 | ✅ RCT 证据主流 | 劳动供给基本不降（01 章 Egger 2022 等） |
| 增长的根本原因（地理/制度/文化孰主） | 🔄 圣杯之争 | 制度派 2024 获诺奖，争论未终 |
| 援助有效性（Sachs vs Easterly） | 🔄 持续争论 | 微观有效、宏观存疑的"评估鸿沟" |
| 中等收入陷阱是否真实存在 | 🔄 争论 | 增长回归的中段减速证据与解释都分歧 |

## 假设与依赖

本学科站在三条假设上：①人均收入是核心福利代理（买到可比性，
付出多维贫困的漏测）②跨国可比（PPP 换算成立）③"发展"是多维的
（HDI/ODI 与收入并列）——三条假设各对应一派测度战争。
