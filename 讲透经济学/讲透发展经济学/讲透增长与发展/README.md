# 讲透增长与发展 · 国家尺度的大问题

> 支：[讲透发展经济学](../README.md) 自定主干支。为什么有的国家富、
> 有的国家穷、穷国能不能追上——经济学的圣杯问题住在这里。

## 定位句

本支负责**宏观发展线**：增长模型谱系（索洛→内生增长→统一增长）、
增长核算与收敛证据、制度/地理/文化的根本原因之争、以及发展
政策半个世纪的大试验（进口替代 vs 出口导向 vs 华盛顿共识）。

## 诞生与关键事件

- 1939/1946 哈罗德-多马：增长=储蓄率÷资本产出比（刀锋平衡）
- 1956 索洛模型：稳态+收敛+残差三概念（1987 诺奖）
- 1957 索洛增长核算：TFP 残差称重术
- 1986/1990 罗默、1988 卢卡斯：内生增长——技术与人力资本内生化
  （2018 诺奖）
- 1992 MRW 人力资本扩展：收敛速度从 6% 修到 3%
- 2001 AJR 殖民起源；2024 诺奖加冕制度学派

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 增长的直接来源分解（要素 vs TFP） | ✅ 核算成熟（解释残差是另一回事） |
| 绝对发散与条件收敛并存 | ✅ 经验稳健 |
| 基本增长模型收敛过快之谜 | ✅ MRW 人力资本修复（6%→3%） |
| 增长的根本原因（制度/地理/文化） | 🔄 圣杯之争（2024 诺奖颁制度派，未终） |
| 中等收入陷阱与规模化衰减 | 🔄 前线 |

## 这支最美的一个事实（一句）

索洛模型算出的收敛速度（6%/年，半衰期 12 年）比现实（约 2%，
半衰期 35 年）快三倍——正是这个"太快了"的缺口，逼出了人力
资本进入增长理论：模型与数据打架的伤口上开出新模型。
