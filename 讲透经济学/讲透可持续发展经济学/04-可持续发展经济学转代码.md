# 04 · 可持续发展经济学转代码：跨期账本的机械化

> **本章回答五问之一（本支：讲透可持续发展经济学）。**
> 本学科的「转代码」=把跨期约束的账本变成可跑的程序：资本路径模拟、贴现计算、
> 脱钩分解——以及看清每一段代码里的参数是怎样替你做伦理决定的。

---

## 一、可机械化边界（先划清楚）

| 问题 | 可机械化 | 不可机械化（参数即立场） |
|---|---|---|
| 给定路径算消费/资本/排放 | ✅ 差分方程、数值积分 | — |
| 给定贴现率算净现值/SCC | ✅ 一行求和 | 贴现率本身：δ、η 无数据可校准 |
| 脱钩的速率测量 | ✅ 滚动回归、LMDI 分解 | 「够不够」的基准（巴黎路径）是规范选择 |
| Hartwick 类规则的合规检查 | ✅ 会计恒等式 | 「自然资本能否替代」是模型假设不是测得值 |

**判据**：凡是「算」的部分都可机械化；凡是「该是多少」的部分（贴现率、替代弹性、
损害函数）——代码只会忠实地把你的立场放大（见 03 章真实储蓄手算的碳价敏感性）。

## 二、代码走廊（三段最小可跑件，numpy 级）

### 走廊①：资本路径模拟器（本家族已落地）

[`experiments/hartwick.py`](experiments/hartwick.py) 是完整样板：状态方程
K ← K + I·dt、外生开采路径、三情景对照、解析解交叉验证（吃老本情景与
解析值逐位一致）。实测输出：Hartwick 全投租金→消费比恒 1.0000；
全花掉→末期 0.6818；抢跑开采→C_0=2.3364 崩到 C_T=1.2271。

### 走廊②：贴现与碳预算计算器（十行量级）

```python
import numpy as np
def npv(losses, rho):                 # losses[t]: 第 t 年损害
    return sum(l / (1+rho)**t for t, l in enumerate(losses))
rho = 0.014                           # Stern;  换 0.03 看结论翻转
years_left = budget_tCO2 / annual_emissions   # 碳预算窗口期
```
把 01 章的「速率 vs 时钟」和 02 章的「参数即立场」压缩成两个表达式。

### 走廊③：脱钩计量（LMDI 简化版）

排放 = GDP × (能源/GDP) × (排放/能源)。三因素逐年分解（对数平均迪氏指数），
可把「GDP 增长贡献了多少排放增势」与「强度下降压回了多少」分开记账——
这是各国气候政策评估报告的标准件，也是 Vogel & Hickel 类研究的引擎室。
骨架（完整版只需把 L 函数换成对数平均）：

```python
def lmdi(gdp, energy, co2, t):
    D_act  = gdp[t]/gdp[t-1]                      # 活动效应：经济增长
    D_int  = (energy[t]/gdp[t])/(energy[t-1]/gdp[t-1])   # 强度效应：节能
    D_mix  = (co2[t]/energy[t])/(co2[t-1]/energy[t-1])   # 结构效应：清洁化
    return D_act * D_int * D_mix                  # 三效应乘法分解=排放指数
```

## 二点五、读 IAM 的参数表检查清单

拿到任何政策模型（DICE、FAIR、双碳路径模型、ESG 评级），按序核对五个开关：
①贴现率 ρ（及 δ、η 拆解）——决定远期损害权重；②替代弹性——决定自然资本
能不能换；③损害函数形态（二次还是肥尾）——决定尾部风险；④TCRE 取值——
决定碳预算大小；⑤学习率/成本下降假设——决定未来技术便宜得多快。
五个开关的取值来源（文献区间还是单一引用）比模型结论更值得写进评审意见。

📖 **故事框**：气候综合评估模型（IAM，如 DICE）全套不过几百行代码，
却决定万亿美元政策——2006 年斯特恩与诺德豪斯的全部分歧，落到代码里只是
一个 `rho = 0.014` 还是 `rho = 0.03` 的赋值行。读 IAM，先读参数表。

## 四、反直觉发现（⑥要件）：确定性机器产出不确定性政策

同一 DICE 框架，不同文献的 SCC 估计从每吨几十到几百美元——模型代码完全公开、
可复现，分歧 100% 来自少数参数（贴现率、损害函数曲率、TCRE）。
**可复现性没有带来收敛**：代码越透明，越暴露分歧的根源在参数背后的立场。
这是「开源科学」的一课：机械化能澄清争论的位置，不能代替争论本身。

## 五、✨美之时刻（⑧要件）：一条 assert 检验一个学派

**陈述**：本家族实验用 `assert 0.98 <= r.min() <= 1.02` 检验弱可持续的核心命题
（Hartwick 保消费），用 D+ 情景的 assert 检验其边界条件（路径有效性）。

**为什么美**：*极简*——学派之争（弱可持续成立吗？何时失效？）被铸成两条断言，
跑一次脚本=一次立场-证据对撞；断言带就是学派的置信区间。

**怎么亲历**：改实验的 β（资源份额）与 g_exp（抢跑强度），看断言带在什么参数下
被击穿——那条边界就是弱可持续论的适用域。
