# 讲透弱可持续与强可持续 · 总资产账还是传家宝账

> **定位**（自定主干支）：这支负责回答「『不透支未来』的账到底怎么记」——
> 自然资本能不能被人造资本替代，是弱/强两派的总分歧点，也是所有可持续指标的
> 隐含世界观开关。

## 诞生

1974 年 Solow 证明：只要资本之间可替代、租金用于再投资，资源耗竭不必拉低消费
（弱可持续的数学奠基）。同年 Georgescu-Roegen 提出熵约束：经济过程不可逆，
低熵资源用一吨少一吨。1977 年 Hartwick 给出弱可持续的可执行规则；
1995 年 Pearce & Atkinson 把真实储蓄做成国别记分牌，弱可持续入世。
强可持续一脉经 Daly（稳态经济）、Costanza（1997 生态系统服务估值）到
Rockström 2009 行星边界，把「不可替代的关键自然资本」推上政策桌。

## 核心问题（3-5 条）

- ✅ 已解：弱可持续的可执行判据（Hartwick 1977：租金全投→消费不降）与国别指标（世界银行真实储蓄 1999-）
- ✅ 已解：等价定理（Withagen–Asheim 1998）：储蓄规则⇔消费不降，成立前提是路径本身有效
- 🔄 前线：哪些自然资本是「关键的」（不可替代且不可逆）——安全气候、传粉网络、生物完整性
- 🔄 前线：替代弹性的实证测量——几乎全部宏观证据来自价格序列，而关键自然资本没有价格
- ❌ 未解：临界点的位置与跨越后的恢复成本（一旦测准，往往已经跨过）

## ✨这支最美的一个事实

弱可持续的全部力量与全部傲慢，浓缩在一个实验里：租金全投人造资本，消费曲线
一百年纹丝不动（比值恒 1.0000）；但同一经济里只要把「哪种资本」的替代弹性
调低一档，同样的规则立刻保不住消费——**可持续与否，取决于你对替代性的信仰，
而信仰无法用产出数据证伪**。跑 [家族实验](../experiments/hartwick.py) 亲历。

## 假设与依赖

Cobb-Douglas 生产函数（替代弹性=1，弱可持续的技术底座）；跨期效用可分；
价格可测度稀缺（关键自然资本：无市场价）。上游依赖
[资源经济学](../../讲透资源经济学/) 的租金理论与 [生态经济学](../../讲透生态经济学/)
的承载力概念。
