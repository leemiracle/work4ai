# 讲透可持续发展经济学 · 不透支未来的经济学

> 可持续发展经济学：**把「不能吃子孙饭」翻译成经济学的语言**——
> 后代的福利如何进入今天的决策函数：资本能否替代、未来如何贴现、增长还能不能要。
> GB/T 13745-2009 二级学科 79052。

## 定位声明（本家族怎么读）

本家族是 [讲透经济学](../README.md) 宇宙的「时间债科目」：其他家族问「配置是否有效」，
本家族问「这种有效能不能一直持续下去」。全部内容围绕三场世纪之争展开——
资本替代性之争、贴现率之争、绿色增长与去增长之争——每场都直接决定真实政策量级。

## 诞生（三个原生问题）

| 问题 | 年代 | 结局 |
|---|---|---|
| 增长的极限在哪（罗马俱乐部《增长的极限》1972） | 1972 | 末日模型→被批「狼来了」，但 2008 年 Turner 复盘：40 年实际轨迹贴近标准情景 |
| 挖完的矿怎么还给后代（Solow 1974 / Hartwick 1977） | 1974-77 | 「租金换资本」规则：只要把资源租金全投人造资本，消费可以永不下降 |
| 发展要不损害后代（布伦特兰委员会《我们共同的未来》） | 1987 | 「可持续发展」定义入宪：从学界术语变成全球政策语言（里约 1992、SDG 2015） |

## 核心问题清单（详 00 章）

已解决里程碑：Solow-Hartwick 可持续条件（1974/1977）· 真实储蓄指标（世界银行 1999-）·
碳预算框架（IPCC AR5 2013）· SDG 指标体系（2015）。
悬而未决：脱钩速率够不够巴黎目标（Vogel & Hickel 2023 说不够）· 关键自然资本的临界点在哪 ·
贴现率的「正确」值（Stern 1.4% vs Nordhaus 3%+，悬而未决 20 年）· 去增长是否必要。

## 假设与代价

本家族核心假设：**后代福利可以进入今天的计算**。买到政策有了跨期一致性标准（双碳、
碳预算、代际基金都有公式可依）；付出每一项政策都要先回答一个伦理问题（贴现率），
而伦理问题没有市场答案。
