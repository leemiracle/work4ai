# 讲透代际公平与贴现 · 一个参数的百年战争

> **定位**（自定主干支）：这支负责「未来如何进入今天的账」——贴现率的每一个
> 千分点，都是一次「后代算老几」的表决；它是本学科杠杆率最高的一件小工具。

## 诞生

1928 年 Ramsey 在一篇最优储蓄论文的脚注里写下一句名言：以正利率贴现后代福利
「在伦理上站不住脚」（ethically indefensible）——战争由此打响。1957 年他的
公式被奉为标准（ρ=δ+ηg）；2006 年斯特恩报告取 ρ≈1.4%，推出「立即花 1% GDP
行动」；Nordhaus 反击：应从市场资本回报率倒推 ρ≈3%+，结论变成「先增长后治理」。
同代数据、同代模型，参数分岔，政策结论差一个量级。

## 核心问题（3-5 条）

- ✅ 已解：Ramsey 公式的分解结构（纯时间偏好 δ / 不平等厌恶 η / 增长 g）——伦理的因式分解
- ✅ 已解：贴现率不确定性下的递减贴现（Weitzman 1998「gamma 贴现」：远期应取各情景最低利率）
- 🔄 前线：ρ 的期限结构（长期低贴现已成官方共识，欧盟委员会 2024 指南下行）
- 🔄 前线：灾难风险如何进 η（肥尾损害×风险厌恶的交互）
- ❌ 未解：没有市场能校准 δ——后代没有席位出价，伦理参数注定无实证解

## ✨这支最美的一个事实

ρ=3% 时，300 年后的万亿美元级灾难贴现到今天只剩约千万分之一——斯特恩与
诺德豪斯两代人的全部论战，落点只是把指数 e^(−ρt) 里的 ρ 从 0.014 改到 0.03。
一台十行代码的换算机，决定全球气候政策的量级——数学史上很少有杠杆率这么高的
一个参数。用 [家族 04 章](../04-可持续发展经济学转代码.md) 走廊②亲手翻转它。

## 假设与依赖

跨期效用可加且时间可分；代际「人格连续」假设（后代偏好与当代同构）；
增长预测 g 的可知性。上游依赖 [环境经济学](../../讲透环境经济学/)·气候经济学支
（贴现的实战主战场）与动态优化数学（[讲透优化](../../../讲透数学/讲透优化/)）。
