# 讲透技术进步经济 · 成本为什么自己往下走

> **归组主干支**（GB/T 79041 三级：技术进步）。
> **定位**：这支负责"技术进步本身的经济规律"——干中学、学习曲线、
> 技术扩散、全要素生产率与技术进步对增长的贡献核算。

## 诞生

Wright 1936 年发现飞机机身累计工时幂律；Arrow 1962 年《干中学的
经济含义》把它理论化（学习是生产的副产品，无需专利即外溢）；
Solow 1957 年用增长核算把"资本劳动解释不了的余值"命名为技术进步——
本支三块基石齐了。中国语境下与"科学技术是第一生产力"（1988）合流。

## 核心问题（3-5 条）

- ✅ 已解：干中学的微观机制（重复→熟练→工艺改进；Arrow 外溢模型）
- ✅ 已解：学习率换算 LR=1−2^(−b) 与跨技术实证（光伏约 20%、电池约 18%/翻倍）
- 🔄 前线：全要素生产率（TFP）测度之争——余值法 vs 代理变量法，"增长的多少算技术"无公认答案
- 🔄 前线：研究外推（research spillovers）的政策设计——研发补贴与社会回报率
- ❌ 未解：学习率的来源分解（规模/工艺/供应链/竞争各占多少）——一个黑箱参数统治了能源预测

## ✨这支最美的一个事实

Arrow 的洞见：学习是生产的**免费副产品**——干得越多学得越多，而学到
的知识自动外溢给全社会。市场因此系统性地低估学习的回报，**这是补贴
新兴产业最硬的理论理由**，也是产业政策争论两百行的起点。

## 假设与依赖

学习率平稳（结构突变即失效——技术路线切换、贸易战都会打断）；
依赖增长核算的总量框架。亲历装置：家族实验
[`learning_curve.py`](../experiments/learning_curve.py)。
