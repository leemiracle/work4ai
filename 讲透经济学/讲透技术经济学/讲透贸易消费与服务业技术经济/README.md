# 讲透贸易消费与服务业技术经济 · 服务的账，跨境的账

> **归组主干支**（GB/T 79041 三级归组：贸易·消费·服务业 三支）。
> **定位**：这支负责"技术进步在贸易、消费与服务业中的经济账"——
> 技术贸易与技术转让定价、消费技术的采纳与家电耐用品评价、
> 服务业（金融/电信/平台）的技术经济分析。

## 诞生

技术贸易支源于国际技术转让定价问题（专利许可费怎么定、成套设备引进
怎么算账——1980s 中国引进潮的核心争议）；消费支源于耐用消费品寿命
周期成本（life cycle cost，家电购置费+电费的总账）；服务业支最年轻，
平台经济（2010s）把服务业生产率之谜变成显学。

## 核心问题（3-5 条）

- ✅ 已解：技术定价的收益分成法（licensing 按被许可方利润分成，25% 法则及其争论）
- ✅ 已解：全寿命周期成本（LCC）语法——购置成本只占耐用品总账的一半
- 🔄 前线：服务业生产率之谜（Baumol 成本病：服务为何不降价）在数字服务上的松动
- 🔄 前线：数字服务的技术经济评价（算力/网络效应/双边市场——传统口径失灵）
- ❌ 未解：技术依赖度的度量——贸易战时代"卡脖子"的账怎么算，无公认口径

## ✨这支最美的一个事实

鲍莫尔成本病：乐队四重奏今天还是四个人演奏同一首曲子，两百年没有
"生产率进步"，所以相对制造业，演出票越来越贵——**生产率不进步的部门
会自动变贵**。它预言了医疗、教育的相对价格膨胀，也界定了服务业技术
经济学的核心战场（用技术给成本病解毒）。

## 假设与依赖

服务产出可度量（数字服务打破了传统口径）；技术可交易且产权清晰
（贸易支的暗假设）。依赖[理论方法支](../讲透技术经济理论与方法/)。
