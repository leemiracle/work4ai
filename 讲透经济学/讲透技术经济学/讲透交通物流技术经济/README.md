# 讲透交通物流技术经济 · 路网上的人生死活账

> **归组主干支**（GB/T 79041 三级归组：交通·物流 两支）。
> **定位**：这支负责"交通设施与物流体系的经济账"——高铁/公路/机场的
> 国民经济评价、时间价值、网络效应；物流成本占 GDP 比重的国家账本。

## 诞生

基础设施评价的传统强区：时间价值（value of time）测算始于 1960s
（旅行时间节约的货币化），中国高铁大建设（2008 后）把"国民经济评价
override 财务评价"变成大规模实践——京沪高铁财务上成立，多数线路
靠路网外部性成立。物流侧，中国"社会物流总费用占 GDP 比率"
（2024 约 14%）成为国家竞争力指标。

## 核心问题（3-5 条）

- ✅ 已解：时间价值的显示偏好与陈述偏好测度（工资法/出行选择模型）
- ✅ 已解：物流成本占 GDP 比率的口径体系（运输/保管/管理三块）
- 🔄 前线：高铁网络效应的定价——单线亏损与网络盈利的悖论如何进入可研框架
- 🔄 前线：多式联运与"公转铁/公转水"政策的比选账
- ❌ 未解：间接效益（集聚、土地增值）计量的双重计算风险——计少了亏待基建、计多了自欺

## ✨这支最美的一个事实

交通评价把"节约的每小时"标价：一小时的通勤时间节约被货币化后，
一条路的 NPV 由千万次一小时的加法构成——**国民经济的账本里，
时间真的就是金钱**，而且是可审计的金钱。

## 假设与依赖

时间节约可货币化且边际值稳定（对高收入/低收入者同价？——分配权重的暗礁）；
依赖[项目评价支](../讲透项目评价与工程工业技术经济/)的四层评价结构。
