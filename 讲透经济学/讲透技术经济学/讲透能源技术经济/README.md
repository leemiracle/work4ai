# 讲透能源技术经济 · 学习曲线的主场

> **归组主干支**（GB/T 79041 三级：能源）。
> **定位**：这支负责"能源技术与电源结构的经济账"——LCOE、学习曲线、
> 平价判定、储能经济性、能源情景推演——本家族近五年最活跃的支。

## 诞生

1970s 石油危机催生能源系统模型（IEA 诞生、Markal 类模型）；2000 年代
IRENA/DOE 把学习曲线接入成本预测；2020 年代光伏学习率（约 20%/翻倍，
OWID）成为全球能源政策的定价基础，2022 美国 IRA 与中国"新三样"把这门
算账术推到国策级。

## 核心问题（3-5 条）

- ✅ 已解：LCOE 统一度电成本比较语法；光伏平价上网判定（2021 前后中国多数地区实现）
- ✅ 已解：学习曲线接入成本预测（DOE 用全期 24% 学习率预测光伏 LCOE 低于风电）
- 🔄 前线：时序价值革命——LCOE 之后，容量价值/系统价值/LCOS 如何重构比选语言
- 🔄 前线：2023-25 组件价格暴力周期（崩 60-70% 后反弹 30-45%）下成本口径与价格口径的分离
- ❌ 未解：绿氢/CCUS/聚变等首台（first-of-a-kind）技术无累计产量可学——成本预测的真空地带

## ✨这支最美的一个事实

光伏组件价格十年降约 90%，机制只是一个参数：累计装机每翻倍，
成本降约 1/5（1−0.8^10≈89.3% 可手算）——**人类史上最便宜能源的定价权，
掌握在一条 1936 年的幂律手里**（亲历：家族实验
[`learning_curve.py`](../experiments/learning_curve.py)）。
