# 讲透技术经济理论与方法 · 算账的语法本身

> **归组主干支**（GB/T 79041 三级：技术经济理论与方法）。
> **定位**：这支负责"算账的语法"——指标体系（NPV/IRR/LCOE）、参数体系
> （影子价格/社会折现率）、评价流程与不确定性分析的方法论根基。

## 诞生

1962-1963 年《1963-1972 年科学技术发展规划》在于光远等推动下立"技术经济"
为专门领域，理论方法即其第一支；1987/1993/2006 三版《建设项目经济评价
方法与参数》把这套语法宪章化。西方对应物是工程经济（复利贴现传统）与
成本效益分析（福利经济学传统）。

## 核心问题（3-5 条）

- ✅ 已解：NPV 可加性与决策一致性（1950s 定理化）；IRR 多重根的完整刻画
- ✅ 已解：影子价格=线性规划对偶解（福利经济学与运筹学的握手）
- 🔄 前线：社会折现率之争——代际伦理如何进入国家参数（环境派 3% vs 财政派 8%）
- 🔄 前线：实物期权方法（real options）对深不确定项目的适配
- ❌ 未解：非市场价值（生态、公平、尊严）的货币化边界——补偿定价的哲学合法性悬而未决

## ✨这支最美的一个事实

影子价格是线性规划对偶问题的解——**"稀缺性"可以被证明为一个数学对象**
：约束松一格，目标函数恰好改善那么多。价格理论与优化理论在这里是同一件事的两面。

## 假设与依赖

后果可货币化、贴现率外生、项目可分离（详见[家族 00 章](../00-体系结构.md)
假设与代价表）。依赖微观经济学的福利经济学根基与概率统计。
