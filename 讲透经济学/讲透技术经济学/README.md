# 讲透技术经济学 · 技术的经济海关（中国原创学科）

> 技术经济学：**给技术算经济账**——一个方案、一个项目、一项政策在经济上
> 值不值、何时值、对谁值。GB/T 13745 二级学科 79041；本家族是八家族中唯一
> 有三级明细的：**14 个三级学科归组为 8 个主干支**（映射见下表）。
> 诞生于 1962-63 年《1963-1972 科技发展规划》（于光远等推动）——中国原创。

## 定位声明（本家族怎么读）

其他家族讲"经济如何运行"；本家族讲"**技术凭什么过关**"：可行性研究、
NPV/IRR/LCOE、影子价格、学习曲线——评价装置的学科。与部门经济 28 家
兄弟（讲透工业经济学/讲透农业经济学/讲透交通运输经济学/讲透物流经济学/
讲透商业经济学 等）的分工：他们管部门运行，本家族管部门的技术与项目值不值。

## 诞生（三个原生问题）

| 问题 | 年代 | 结局 |
|---|---|---|
| 苏联援建 156 项工程怎么比选厂址方案 | 1950s | 技术经济论证进入中国 |
| 要不要立学科专管"技术的经济性" | 1962-63 | 立技术经济专门领域（于光远等） |
| 引进项目频超支，谁来把关 | 1983 | 可行性研究制度化；《方法与参数》1987/1993/2006 三版宪章化 |

## 核心问题清单（详 00 章）

已解决：Wright 学习律 1936 · Arrow 干中学 1962 · NPV/IRR 性质 1950s ·
可研制度化 1983 · 影子价格体系 1987。
悬而未决：TFP 测度之争 · 首台（first-of-a-kind）技术成本预测 ·
社会折现率的政治经济学 · 产能过剩与学习的相互作用。

## 假设与代价

本家族假设：**一切后果可货币化**。买到可比性与可审计性；
付出非市场价值漏计（详 [00 章](00-体系结构.md)④要件表）。
