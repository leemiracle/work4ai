# 04 · 技术经济学转代码：算账的机械化，与它的边界

> **本章回答五问之一（本支：讲透技术经济学）。**
> 本学科的 90% 计算是确定性算术（贴现、求和、比较）——天然可机械化；
> 剩下 10%（影子价格、分配权重）本质是政治与伦理——永远不可。
> 本章画清这条线，并给出三条代码走廊。

---

## 一、可机械化边界（三件套之一）

| 环节 | 可机械化吗 | 为什么是这样 |
|---|---|---|
| 现金流贴现/NPV/IRR | ✅ 完全 | 纯确定性算术，公式封闭 |
| 学习曲线拟合与外推 | ✅ 完全 | 回归+幂律，本家族实验即证 |
| 蒙特卡洛风险分析 | ✅ 完全 | 参数分布→抽样→NPV 分布，机械重复 |
| LCOE/LCOS 计算 | ✅（但口径要人管） | 公式封闭，但"计什么、不计什么"是口径决定 |
| 影子价格标定 | ⚠️ 半 | 局部均衡/线性规划对偶可算，全局扭曲靠判断 |
| 社会折现率、分配权重 | ❌ 不 | 这是伦理与政治参数——代码只能算它的影响，不能替你选它 |
| 可研结论的综合裁定 | ❌ 不 | 问责链的最后一环必须留给人（评审专家签字） |

**边界的形状**：可机械化的全是**从参数到指标**的箭头；不可机械化的是
**参数本身从哪里来**。代码是放大器——放大判断，也放大误判。

## 二、代码走廊（三件套之二）

### 走廊① 学习曲线（本家族实验）

[`experiments/learning_curve.py`](experiments/learning_curve.py)：
合成含噪数据→OLS 恢复学习率 19.91%（真值 20%）→Wright/Moore 模型判别
（R² 0.9999 vs 0.9836）→外推预测误差 1.26%。约 70 行 numpy，无外部依赖。
对应 00/01 章的美之时刻——**为什么最小**：Wright 律只有两个参数，
学习率换算一行对数式。

### 走廊② NPV/蒙特卡洛风险装置（百行内可自建）

```
现金流表（numpy 数组）→ r 网格 → NPV 曲线 → IRR 二分求根
                      ↘ 参数抽分布（rng.normal/lognormal）
                        → 5000 次 NPV → P(NPV<0) 即项目风险
```

**为什么自建而非调库**：财务计算的核心是**口径透明**——黑箱财务库恰恰
破坏可研的"逐格可质询"要求；百行自建代码本身就是审计对象。

### 走廊③ 能源系统与情景模型（生态侧）

产业级走廊：Python 能源系统模型生态（PyPSA/Calliope 类开源模型、
IEA 情景方法），把学习曲线、贴现、容量扩张优化合成为国家尺度推演。
个人可用小规模复刻（单区域电源结构优化=线性规划，接口
[数学宇宙·优化](../../讲透数学/讲透优化/)）。

## 四、⑥反直觉要件：Excel——事实上的生产语言及其错误率

**反直觉发现**：这门学科真正的生产语言不是 Python 而是 Excel，
而财务模型审计研究长期报告**约九成的复杂表格存在错误**（公式引用错、
硬编码常数、口径混层）。产业界近年推动"Excel→代码"迁移，动机不是性能，
是**可审计性**——代码的版本控制与单元测试恰好对应可研的问责链。
为什么如此：1983 年制度化的可研文体先于电子表格普及，两者的联姻
（模板化 Excel 报告）造就了存量惯性；迁移之慢不是技术问题，是
**每张表格背后有一个签字人**。

## 五、断言即文档：实验代码的写作纪律

本家族实验的写作纪律可作为走廊①②的模板：**每个断言对应一个可质询的
命题**（学习率恢复到 19.91%？Wright 判别胜出 0.0163？），打印值+断言
阈值同时呈现——代码即评审材料。这与可研"逐格可弹错"的表格精神同源：
**计算装置的价值不在于跑通，在于错得可定位**。固定随机种子（seed=42）
是可复现性的底线——评审者重跑必须得到同一组数字。

## 六、✨美之时刻（⑧要件）：蒙特卡洛——把"没把握"变成分布

**陈述**：给每个参数配分布而非点估计，机械重复抽样几千次，NPV 从
一个数变成一条分布——P(NPV<0) 从修辞变成概率。

**为什么美**：*必然*——不确定性的诚实表达只能是分布；点估计是对
决策者的谎报。**怎么亲历**：走廊②的 5000 次抽样，二十行代码就能
看到"IRR=8%"背后藏着的破产概率。

## 📌 收束与认知升维（⑨要件）

**这章给了你什么新眼睛**：
- **箭头/参数分视眼**：任何决策支持系统，分清"箭头"（可机械化的推导）
  与"参数"（人定的立场）——自动化永远吃掉前者，后者换个界面还是人。
- **可审计眼**：模型的价值不在算得快，在**错得可定位**——
  黑箱精确比透明粗糙更危险。
