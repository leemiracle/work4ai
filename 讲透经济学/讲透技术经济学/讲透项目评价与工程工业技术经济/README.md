# 讲透项目评价与工程工业技术经济 · 通关文牒的量产车间

> **归组主干支**（GB/T 79041 三级归组：工程·工业·建筑 三支）。
> **定位**：这支负责"一件具体的工程/工厂/楼宇怎么算账"——可行性研究、
> 财务与国民经济评价、方案比选——技术经济学最大的应用腹地。

## 诞生

1983 年国家计委《建设项目可行性研究试行管理办法》确立"先评价后决策"；
1987 年起《方法与参数》三版给出全国统一的表格与参数。工业项目评价
（工厂选址、工艺比选）与建筑工程经济（概预算、全寿命成本）自此制度化。

## 核心问题（3-5 条）

- ✅ 已解：可研文体与四层评价结构（财务→国民经济→社会→风险）——问责链制度化了
- ✅ 已解：互斥方案比选准则（同寿命 NPV 直接比；不同寿命用年金化/最小公倍寿命）
- 🔄 前线：改扩建与设备更新项目的"有无对比"口径——增量分析在实践中最易做错
- 🔄 前线：2024 大规模设备更新政策下"经济寿命 vs 技术寿命"的提前退役判定
- ❌ 未解：系统性项目的分离评价悖论——单条高铁线都亏、网络整体成立，可研框架对此失语

## ✨这支最美的一个事实

"有无对比"（with-and-without analysis）四字浓缩了整个评价哲学：
**项目的价值不是它的产出，而是它相对于"没有它"的反事实世界的差额**——
把因果推断的最小定义装进了工程算账。

## 假设与依赖

项目可分离、参数可外推（家族 00 章④要件表）；依赖[理论方法支](../讲透技术经济理论与方法/)
