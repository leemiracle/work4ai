# 讲透农业技术经济 · 喂饱问题的算账术

> **归组主干支**（GB/T 79041 三级：农业）。
> **定位**：这支负责"农业技术与农业生产的经济账"——品种/机械/灌溉
> 技术的采纳决策、规模经济、要素替代，以及粮食安全的国家账本。

## 诞生

1960s 绿色革命（良种+化肥+灌溉的技术包）提出"技术如何到农民手里"的
经济问题；中国家庭联产承包后，农业技术经济学围绕杂交水稻采纳、
农业机械化、化肥边际报酬展开——最早把"农户理性"当真实主体建模的
中国经济学分支之一。舒尔茨《改造传统农业》（1964）是国际思想源头。

## 核心问题（3-5 条）

- ✅ 已解：技术采纳的诱导创新框架（Hayami-Ruttan：要素稀缺诱导技术方向）
- ✅ 已解：农户生产函数与要素边际报酬测算（杂交水稻采纳研究成为经典范式）
- 🔄 前线：小农户与规模化的账——土地流转与机械化的盈亏平衡规模
- 🔄 前线：智慧农业/无人机植保的采纳经济性（服务外包 vs 自购设备）
- ❌ 未解：农业技术正外部性（粮食安全溢价、生态农法）如何进入项目账本——计不入账的公共价值长期失声

## ✨这支最美的一个事实

诱导创新模型说：土地贵的国家发明机械（美国），劳动贵的经济体发明
生物技术提单产（日本路径）——**技术路线的选择本身就是一张要素价格表
的镜像**。一个模型解释了两大洲的农业史分岔。

## 假设与依赖

农户是理性主体（舒尔茨假说——穷而有效率）；自然风险进入收成分布；
依赖[项目评价支](../讲透项目评价与工程工业技术经济/)的评价语法。
