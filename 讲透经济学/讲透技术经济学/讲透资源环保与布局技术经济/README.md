# 讲透资源环保与布局技术经济 · 绿色的账与地图的账

> **归组主干支**（GB/T 79041 三级归组：资源环保·生产力布局 两支）。
> **定位**：这支负责"资源环境技术的经济评价"（治污成本、循环经济、
> 环保项目效益）与"生产力在国土上怎么摆"（布局论证、区域规划的项目账）。

## 诞生

1970s 环境规制兴起，治理技术的成本有效性（unit abatement cost，单位
减排成本）成为核心指标；中国"三线建设"到西部大开发的布局论证传统，
则让"生产力布局"成为独立三级支。两支在双碳时代合流：减排技术怎么选、
落在哪个区域。

## 核心问题（3-5 条）

- ✅ 已解：边际减排成本曲线（MACC）构造——治污技术的排序语法
- ✅ 已解：布局论证的运输成本/要素禀赋框架（与区位论共享地基）
- 🔄 前线：碳价与减排技术比选（碳市场价×减排量进入 NPV，2021 中国碳市场后制度化）
- 🔄 前线：循环经济（再生资源替代原生资源）的边界账——回收率的经济上限在哪
- ❌ 未解：环境效益（健康、生态）货币化进入项目账本的口径统一——跨部门争论现场

## ✨这支最美的一个事实

边际减排成本曲线把"环保=烧钱"翻转为"环保=**按成本排序的技术清单**"：
每吨减排成本从负（节能顺手减排）到天价（末端捕获）排成一条曲线，
碳市场做的事就是让市场自动从便宜端开始砍——**曲线的形状即政策的形状**。

## 假设与依赖

环境效益可货币化（环境经济学的估值接口）；布局依赖空间成本假设
（运输/集聚）。依赖[理论方法支](../讲透技术经济理论与方法/)的口径体系。
