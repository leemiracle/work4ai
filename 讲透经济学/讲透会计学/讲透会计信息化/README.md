# 讲透会计信息化 · 从算盘到实时账本

> **定位**：这支负责会计与信息技术的接口——电算化、ERP 总账、
> 财务共享、RPA、数电发票与实时会计。会计是**最早被数字化的
> 商业职能**（1954 GE 用 UNIVAC 发工资是业界第一单），
> 因为它的产出天然是结构化数据。
> GB/T 79037 无此三级名——**自定主干支**（数字化侧）。

## 诞生

| 波次 | 时间 | 内容 |
|---|---|---|
| 电算化 | 1979-1990s | 手工账平移进计算机：中国 1979 长春第一汽车厂试点会计电算化 |
| ERP 集成 | 1990s-2000s | 业务财务一体化：记账嵌入业务事件（SAP R/3 时代） |
| 财务共享+RPA | 2010s | 集中工厂化处理+机器人流程自动化 |
| 数电+AI | 2021- | 源数据结构化（数电发票）+大模型进判断辅助（家族 01 章现场） |

## 核心问题（3-5 条）

- ✅ 已解：总账引擎（借贷不变量=数据库约束，家族 03/04 章）
- ✅ 已解：业务财务一体化（业务事件自动生成凭证）
- 🔄 前线：实时会计（技术上可行、准则上无动力——分期是博弈均衡）
- 🔄 前线：多准则并行换算（CAS/IFRS 双轨的自动化）
- ❌ 未解：AI 参与判断的责任链（机器建议、谁签字）

## ✨这支最美的一个事实

会计信息化的真正瓶颈 70 年没变过：不是算法，是**凭证的数据结构**——
1954 年的难题是工资数据怎么进穿孔卡，2026 年的难题是发票数据
怎么标准化（数电发票）。每次瓶颈松动都靠**强制标准**而不是
更聪明的算法：账本的数字化是监管拉动的，不是技术推动的。
