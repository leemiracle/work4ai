# 讲透成本与管理会计学 · 对内说话的账

> **定位**：这支负责"不对外、只对内"的那半会计——给管理者决策用的
> 成本计算、预算控制与业绩评价。准则不管它（没有"应当"），
> 唯一裁判是**有用**：算出来的数能改决策吗？
> GB/T 79037 无此三级名——**自定主干支**（承接"会计学其他学科"）。

## 诞生

三条源流汇合：泰勒科学管理（1911）要标准成本；杜邦公司 1919 年
发明 ROI 分解（杜邦分析法）管庞大的多部门帝国；20 世纪中叶
机会成本概念进入管理决策（相关成本/沉没成本之分）。
1987 年 Johnson-Kaplan《相关性消失》控诉成本会计被财务报告绑架，
随后作业成本法（ABC）、平衡计分卡（1992）把本支推成独立王国。

## 核心问题（3-5 条）

- ✅ 已解：标准成本与差异分析（价差/量差分解——哪里偏离、偏多少）
- ✅ 已解：本量利分析（CVP：保本点=固定成本/单位边际贡献）
- ✅ 已解：相关成本决策框架（沉没成本滚出去、机会成本请进来）
- 🔄 前线：间接费用占比越涨，制造费用分摊的"谎言半径"越大（ABC 与其改良）
- ❌ 未解：业绩指标的可博弈性——任何 KPI 一旦成为目标（古德哈特定律）
  ，就会被优化到失真（预算游戏、渠道压货）

## ✨这支最美的一个事实

沉没成本的会计处理是理性的铁律（已花的钱不影响未来决策），
但人类心理恰好相反（协和飞机效应：因已投入而继续投入）——
**管理会计的半个学科，是在教人对抗自己的记账本能**。

## 假设与依赖

- 成本可归集且可分摊（共同成本的分摊基础是选择不是事实）
- 决策相关即可，无需可审计（放弃外部审计=放弃可靠性换敏捷）
- 依赖家族层记录层（00 章四层结构的第一层）供数；产出喂给
  [工业经济学](../../讲透工业经济学/)的企业经营分析与 [管理经济学] 定价决策

- Kaplan & Norton 平衡计分卡系列（哈佛商业评论 1992 起）
