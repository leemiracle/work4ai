# 讲透会计学 · 商业语言的宪法

> **会计学 = 把企业的经济活动翻译成可加总、可验证、可比较的数的制度**——

## 一、诞生

1. **1494 帕乔利《算术、几何、比与比例概要》**——复式记账第一次成文。
   威尼斯商人已用了两百年，帕乔利只是写下来：每笔业务同时记借贷两方，
   余额永远互相咬合。这不是经济理论，是**记账技术**——但它是历史上
   第一个自带错误检测的商业信息系统。
2. **工业革命逼出成本会计（19 世纪末-1920s）**——多工序工厂需要知道
   每件产品"吃掉"多少间接费用；科学管理运动（泰勒）与成本会计互相喂养。
3. **1929-1933 大萧条与证券法（1933/1934）**——股市崩盘暴露自由编表
   的后果，美国设 SEC、GAAP 开始成文化：会计从商人的私账变成
   **公共品与法律语言**。"公认"二字=准则委员会政治的产物。
4. **1973 国际会计准则委员会（IASC→IASB）**——跨国资本要求可比，
   开启趋同长跑；中国 2006 企业会计准则体系（CAS）与国际财务报告
   准则（IFRS）实质性趋同。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 复式记账的自检结构 | ✅ 1494 已成 | 借贷恒等=分布式账本的守恒律，500 年未改内核 |
| 收入何时确认（五步法） | ✅ 2014 IFRS15/CAS14 | "控制权转移"取代"风险报酬"——全球统一判据 |
| 历史成本 vs 公允价值 | 🔄 永恒争论 | 2008 危机中公允价值被指"顺周期放大器"（见 00 章） |
| 会计信息是否影响资本成本 | 🔄 实证前线 | 决定准则收益的终极证据 |
| 无形资产/数据能否入表 | ❌ 未解 | 数据资源 2024 年入表开了门缝，计量与摊销仍无共识 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 会计主体持续经营 | 折旧/摊销/递延有意义的 | 破产边缘企业账面瞬间失真 |
| 应计制（权责发生制） | 利润匹配业务实质 | 利润≠现金——骗局几乎都在应计项里 |
| 币值稳定 | 可加总、可比较 | 通胀期报表系统性说谎 |
| 谨慎性（不高估资产收益） | 抑制管理层乐观 | 引入不对称=留给操纵的灰色地带 |

## 四、教材锚

- 帕乔利 1494（学科出生证明）；Littleton《1900 年前的会计演变》（会计史标准）
- Kieso/Weygandt《Intermediate Accounting》（中级财务会计全球标准）
- 葛家澍《会计学》（中文权威体系）；财政部《企业会计准则》（CAS 原文——
  本家族的"宪法文本"，教材都只是注释书）
- Horngren《Cost Accounting》（成本/管理会计标准）；Penman《财务报表分析与证券估值》
