# 讲透行业会计学 · 同一台记账机，五套业务循环

> **定位**：这支负责 GB/T 79037 明列的五支三级学科——工业/农业/商业/
> 银行/交通运输会计学的归组。五支共享同一复式记账内核
> （家族层 00 章），差异只在**业务循环**：钱货权如何在行业内流转。

## GB/T 五支归组映射

| GB/T 三级 | 业务循环特征 | 特有科目/难点 |
|---|---|---|
| 工业会计学 | 采购→生产→销售三段循环 | 成本归集与分摊（在产品/约当产量） |
| 农业会计学 | 生物资产生长周期 | 消耗性/生产性生物资产（自然增值入账难题） |
| 商业会计学 | 购→存→销两段循环 | 进销差价、存货计价（零售价法） |
| 银行会计学 | 资金即商品 | 存贷款摊余成本、利息收支的分日计提 |
| 交通运输会计学 | 位移即产品（无形产品） | 营运收入确认（完成里程/航段）、燃油套保 |

## 诞生

工业会计随工厂制（19 世纪成本会计运动）成学；银行会计随票据交换所
（1853 伦敦）制度化；农业与交通运输会计长期依附行业主管部门制度
（中国的行业会计制度 1993 年才并轨到统一企业会计准则——
**统一准则史=行业差异从"制度"退到"业务"的历史**）。

## 核心问题（3-5 条）

- ✅ 已解：统一准则下行业核算的"接口标准化"（一张资产负债表通吃五业）
- ✅ 已解：生物资产（CAS 5）/建造合同（原 CAS15→并入收入准则）等行业专门准则
- 🔄 前线：新业态混业（平台即商业+物流+金融）冲击行业会计的边界
- ❌ 未解：自然增值过程（作物/林木生长）的可靠计量——会计对"时间生物"失明

## ✨这支最美的一个事实

银行业可能是唯一"科目表即产品目录"的行业：吸收存款=进货（负债侧），
发放贷款=出货（资产侧），**银行的商品是记在账上的法律关系本身**——
所以银行会计的科目改革史，就是银行业务创新史的直接抄本。

## 假设与依赖

依赖家族层全部（恒等式/应计制/持续经营）；行业层追加假设：
**业务循环可枚举**——行业会计制度本质是给每类循环预制借贷模板。
混业经营越复杂，模板失配越多（反推：会计准则趋同的深层动力
不是学术审美，是混业企业没法用五套账记账）。
