# 讲透城市土地经济学 · 位置的生产力

> **定位**：这支负责 GB/T 79047 三级"城市土地经济学"——
> 地租理论、土地市场、用途管制与土地制度。土地的特殊性：
> **总量给定的存量资产 × 位置即生产力**——一切土地问题的
> 张力都在"管多少"与"归谁"。**GB/T 三级**（非自定）。

## 诞生

地租理论是经济学的最老问题之一：李嘉图级差地租（1817，
土地肥力/位置差异产生地租）→ 马歇尔稀缺地租（城市土地：
区位而非肥力）→ 杜能-竞租传统把位置地租数学化（家族 00 章）。
中国现场：1988 宪法修正案允许土地使用权出让→土地有偿使用
制度确立→2020《土地管理法》修法允许集体经营性建设用地入市
——土地制度的每次改动都是最大的"参数变化"。

## 核心问题（3-5 条）

- ✅ 已解：级差地租的来源（位置差异资本化）
- ✅ 已解：用途管制的福利代价（供给弹性压低→房价上涨的经典链条）
- 🔄 前线：土地供给弹性与房价关系的跨城市证据（中国 2000s-2020s）
- 🔄 前线：宅基地"三权分置"与集体土地入市的制度实验
- ❌ 未解：最优管制度（容积率的政治经济学——没有效率基准）

## ✨这支最美的一个事实

同一块地在不同用途下"值"不同的钱（商务>住宅>工业>农业），
竞租决定谁用它——但用途管制先于竞租存在：
**分区制（zoning）是在市场出价之前替城市做出的选择**。
美国单户住宅分区的大片土地，等于永久冻结了竞租包络——
"城市长得像什么"一半是均衡，一半是管制化石。

## 假设与依赖

土地总量给定（供给零弹性——土地市场的第一特征）；
位置属性外生（交通/规划改变它）；制度前提（产权结构）
决定收益分配——中国城市土地国有+农村集体所有的双轨
是本支一切中国问题的出发点。
