# 讲透城市经济管理学 · 城市当企业经营

> **定位**：这支负责 GB/T 79047 三级"城市经济管理学（含城市经济理论）"——
> 城市的经济理论、城市规划的经济逻辑、城市财政与城市治理。
> 城市经济理论部分（竞租/集聚）在家族层展开，本支侧重
> **管理与政策侧**：城市这台机器怎么驾驶。**GB/T 三级**（非自定）。

## 诞生

城市经济学与管理学的合流发生在 1960s-70s 代美国市政危机
（财政破产、中心城市衰退）：城市被视为需要资产负债表的
经济体；1990s 新公共管理运动把企业工具（绩效/外包/竞争）
搬进市政。中国路径：土地财政+平台公司+开发区模式构成
独特的"城市经营"实践（1998 房改—2020s），近年转向
"城市更新+运营"的下半场叙事。

## 核心问题（3-5 条）

- ✅ 已解：城市财政的空间逻辑（资本化→税基地理）
- ✅ 已解：开发区/新区模式的经济机理（补贴换集聚的政策工具箱）
- 🔄 前线：从"建设城市"到"运营城市"的转型（存量时代的收入模式）
- 🔄 前线：城市间竞争与协作（抢企业/抢人的边界与协同失灵）
- ❌ 未解：城市破产与重组的制度设计（中国语境的未考科目）

## ✨这支最美的一个事实

"经营城市"这个词 2000 年代初进入中国政策语言时带着争议——
但它的经济学内核无可指摘：公共投资会资本化进地价，
政府回收地价增益（土地出让）再投资——**一个闭环的
城市资产负债表**。争议在于闭环的另一半：土地终会卖完，
而维护是永久的——"建设期财政"到"运营期财政"的断裂
正是当下转型的本质。

## 假设与依赖

城市可近似为一个决策主体（市长/理事会）——代理问题由此进入；
土地增值可回收（制度前提：土地公有/税制设计）；
依赖家族层全部理论件（梯度/集聚/资本化）。
