# 讲透市政经济学 · 每一盏路灯的经济学

> **定位**：这支负责 GB/T 79047 三级"市政经济学"——
> 城市基础设施与公共服务（给排水/交通/环卫/公共安全）
> 的供给、定价与融资。核心问题：**规模经济的收益
> 与分摊成本的公平如何兼得**。**GB/T 三级**（非自定）。

## 诞生

19 世纪城市化把"市政"变成专业：伦敦下水道大工程（1859-1875，
巴扎尔杰特设计，回应大恶臭与霍乱）证明基础设施是
公共卫生的先决条件——市政工程与城市经济学同源。
理论侧：公共品理论（Samuelson 1954）+ 自然垄断定价
（边际成本定价与亏损补偿问题）+ 蒂伯特辖区竞争
（家族 02 章）构成本支三大理论件。

## 核心问题（3-5 条）

- ✅ 已解：自然垄断的定价困境（边际成本定价 vs 补偿成本——次优理论）
- ✅ 已解：基础设施的规模经济证据（成本亚线性 ~0.85，家族 00 章）
- 🔄 前线：公用事业定价改革（阶梯水价/热计量/拥堵收费的政治经济学）
- 🔄 前线：PPP 与基础设施融资的合同设计（风险分配的教训史）
- ❌ 未解：维护缺口的经济学（建设有政绩、维护无掌声——
  全球城市普遍低估维护的贴现行为）

## ✨这支最美的一个事实

基础设施人均成本随城市规模**下降**（亚线性 0.85）：
城市每翻一倍，水管、道路、线路只多 85%——
"城市让基础设施更便宜"是集聚红利中被看见得最少的一块
（人人看见工资溢价，没人看见下水道的规模经济）。

## 假设与依赖

服务有明确的辖区边界（成本分摊的对象）；使用可计量可定价
（水表/电表/计费里程——计量技术决定定价制度）；
依赖公共品理论与规制经济学（家族外邻，连接产业组织）。

## 教材锚

- 市政公用事业定价与规制研究文献（规制经济学应用层）

- 家族层标度律文献（Bettencourt-West 2007 起的实证群）
