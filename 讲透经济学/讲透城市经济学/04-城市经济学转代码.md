# 04 · 城市经济学转代码：从竞租求解器到城市数据科学

> **本章回答五问之五（本家族：讲透城市经济学）。**
> 三件套：**可机械化边界 → 代码走廊 → 工程师落点**。
> 核心判断一句话：城市经济学的转代码有两个世界——
> **模型世界（均衡求解，几十行）与数据世界
> （空间数据处理，占工程量的九成）**；前者是学科内核，
> 后者是行业饭碗。

---

## 一、可机械化边界

| 环节 | 可机械化 | 形态 |
|------|---------|------|
| 竞租包络/边界求解 | ✅ | 闭式解或一维求根（本家族实验，60 行） |
| 密度曲线/人口积分 | ✅ | 数值积分 |
| 资本化回归（Oates 式） | ✅ | 边界断点+双重差分——标准件 |
| 标度律估计 | ✅ | 双对数 OLS（三行核心） |
| 土地利用-交通一体化（LU/T）仿真 | 🟡 | 商业与开源软件成熟，但校准=人工经验 |
| 空间数据处理（地理编码/路网/可达性） | ✅（体力型） | GIS 工程件（geopandas/OSM） |
| 管制政治的预测 | ❌ | 制度博弈不可枚举 |
| 集聚机制的因果分解 | ❌ | 共享/匹配/学习三机制的黑箱尚未开 |
| **房地产价格预测** | ⚠️ 特别注明 | 工程 ML 高度可行，但属于数据行业
  而非学科内核——预测价格≠理解城市 |

## 二、代码走廊

### 走廊①：竞租求解器（本家族实验）

```python
# 三部门指数竞租 R_i(x) = A_i·exp(-b_i·x)，农业保底 R_ag
# 均衡 = np.maximum.reduce([...])   # 上包络
# 边界 = log(A_1/A_2)/(b_1-b_2)      # 相邻曲线交点（闭式）
# 政策臂：b_h 下降（通勤改善）→ assert 边界外移 & 边缘租金上升
```

价值不在数字在结构：**"梯度怎么动、边界怎么动、谁受益"
三个政策问题被压缩成两个断言**——任何交通投资/房产税
讨论都能挂上这台最小模型先跑一遍方向。
[experiments/bid_rent.py](experiments/bid_rent.py) 可直接改参数复用。

### 走廊②：标度律回归

城市样本（人口 P，产出 Y）→ `np.log` → OLS → 斜率 β。
断言 β_产出>1（超线性）、β_基建<1（亚线性）——
把 00 章✨美之时刻变成十行代码；进阶：
按国家/年份分组比较 β 的稳定性（研究课题的入场券）。

### 走廊③：空间数据管道（行业主战场）

数据源（手机信令/POI/路网/房价切片）→ 地理编码 →
可达性计算（路网最短路/公交等时圈）→ 空间连接
（点聚合到网格）→ 计量（断点-DID）。
工具栈：geopandas/networkx/osmnx（开源）+
ArcGIS/TransCAD（行业）。**工程要点**：
坐标系与口径（行政区 vs 网格 vs 通勤区——02 章口径眼），
九成 bug 在这里，不在模型。

## 三、工程师落点

| 场景 | 落点 | 备注 |
|------|------|------|
| 规划院/交通咨询 | 交通模型（四阶段/活动链）、用地仿真 | 中国城镇化下半场的稳定行业 |
| 房地产与土地咨询 | 资本化分析、土地估值（楼面价-房价传导） | 与[家族 00 章]反直觉直接挂钩的红利归属测算 |
| 城市数据服务 | 活力评估、商圈选址（POI+信令） | 零售/商业地产的采购方 |
| 政策评估 | 地铁/学区/限购的效果估计（空间计量） | 因果推断工具链的空间版 |

**诚实判词**：行业里"空间数据工程"岗位远多于"城市经济学
建模"岗位——**GIS 技能是饭碗，均衡思维是天花板**；
两者兼得者（能写 geopandas 也能推 Muth 条件）在
规划与咨询行业是稀缺物种。

## 四、反直觉发现（⑥）

**预测房价最好的模型对"为什么贵"一无所知。**
梯度提升树吃进学区/地铁/楼龄可以相当准地预测单价
——但它不知道梯度来自竞租均衡，也回答不了
"地铁修好后谁受益"（资本化问题）。
**预测（mapping）与机制（mechanism）是两种产出**：
行业大量购买前者，学科只生产后者——
想两边都拿，就得清楚自己每一步在哪个世界。

## 五、✨美之时刻（⑧要件）：max 函数画出城市

**陈述**：单中心城市的全部空间秩序——环带、梯度、边界——
在代码里就是一行 `np.maximum.reduce([R_c(x), R_h(x), R_m(x), R_ag])`。
没有规划者、没有总目标函数、没有协调者；
**竞争的加总=一个逐点取最大值**。

**为什么美**：*极简*——社会秩序的涌现被压缩到一个
初等函数；对比复杂系统里动辄数万行的多主体仿真，
竞租模型用一行代码保留了同样的内核（局部优化→全局秩序）。

**怎么亲历**：在走廊①的数组里把某条竞租曲线的 A 调高一档
（比如商务业数字化后"面对面"价值上升）——重跑，
看环带怎么被压缩、边界怎么内移——你在用手感受
"城市结构对参数的弹性"，这是任何教科书图都给不了的体感。
