## 一、诞生

1. **1826 冯·杜能《孤立国》**——第一个空间模型：城市在中心，
   农业用地按运输成本成环分布——**地租梯度的第一次数学化**
   （比新古典边际革命还早半个世纪）。
2. **1964 Alonso-Muth-Mills 竞租模型**——把杜能逻辑反转到城市内部：
   家庭/厂商在"住房消费 vs 通勤成本"间权衡，均衡地租=
   各类用地者竞租曲线的上包络——单中心城市从此可解。
3. **1977 Dixit-Stiglitz 垄断竞争 + 1991 Krugman 新经济地理**——
   集聚从"外部性的黑箱"变成可解的均衡结果（循环因果：
   工人去有市场的地方、市场在有工人的地方），空间经济学
   重新进入主流，核心-边缘模型成为标准件。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 地价为什么随距离衰减 | ✅ 1826/1964 已解 | 竞租理论：省下的通勤费变成租金（本家族实验） |
| 城市为什么存在（集聚的机制） | ✅ 机制清单已立 | 共享/匹配/学习三机制（Duranton-Puga 2004 标准分类） |
| 城市规模收益的定量规律 | ✅ 2007 实证 | 收益超线性（~1.15）、成本亚线性（~0.85）——Bettencourt-West 标度律 |
| 房产税该不该征、怎么征 | 🔄 政策活争论 | 中国试点（沪渝 2011 起）与立法进程的长期博弈 |
| 住房该市场配置还是政府配置 | 🔄 全球争论 | "住房是商品还是权利"——新加坡/德国/美国三种范式并存 |
| 城市规模该不该控制 | 🔄 中国特色争论 | 大城市控规模 vs 集聚红利派（陆铭《大国大城》之争） |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 单中心（CBD 唯一） | 竞租模型可解析 | 多中心/郊区就业的当代现实被简化 |
| 家庭自由选址（无迁移障碍） | 空间均衡成立（效用均等化） | 户籍/学区/信息摩擦让均衡迟到几十年 |
| 土地用途可管制也即被管制 | 政策变量进入模型 | 管制的福利成本（供给弹性被压低→房价上涨） |
| 集聚收益可永续 | 城市越大越有效率的推论 | 拥堵/房价/污染的影子价格常被低估 |

## 四、教材锚

- O'Sullivan《Urban Economics》（全球标准教本）
- Fujita《Urban Economic Theory: Land Use and City Size》（Alonso-Muth-Mills 数理圣经）
- Brueckner《Lectures on Urban Economics》（研究生短程标准）
- Glaeser《Cities, Agglomeration, and Spatial Equilibrium》（集聚与城市增长）
- DiPasquale & Wheaton《The Economics of Real Estate Markets》（房地产四象限模型）
- 中文语境：陆铭《大国大城》（集聚派政策论述代表作）
