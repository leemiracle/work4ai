# 讲透城市集聚经济学 · 为什么在一起

> **定位**：这支负责城市存在的理论核心——集聚效应
> （agglomeration economies）：共享（投入品/基础设施）、
> 匹配（劳动市场池/供需对接）、学习（知识溢出）三机制。
> GB/T 79047 三级"城市经济管理学（含城市经济理论）"承担
> 政策管理面，**理论核心单列本支**——自定主干支（补 GB/T
> 列表的理论缺口）。

## 诞生

马歇尔（1890）首先点出集聚三源（专业投入品共享、
劳动市场池、知识外溢）；Duranton-Puga（2004）把三源
正式命名为 sharing/matching/learning 并各配现代模型；
Krugman（1991）新经济地理把集聚放进主流一般均衡
（1991-2008 之争的核心-边缘模型，2008 诺奖）；
Bettencourt-West（2007）用全球城市数据测出超线性
标度律（产出~人口^1.15）——集聚红利第一次有了
跨系统的定量形状。

## 核心问题（3-5 条）

- ✅ 已解：集聚的机制分类（共享/匹配/学习——理论完整）
- ✅ 已解：集聚的净收益存在（工资溢价超拥堵成本——城市工资溢价研究）
- 🔄 前线：标度律的微观机制（什么互动网络长出 1.15）
- 🔄 前线：集聚与不平等的共生（高技能者集聚收益更大——
  城市既拉高均值又拉大方差）
- ❌ 未解：最优城市规模（超线性的尽头/拥堵的边际追赶点在哪里）

## ✨这支最美的一个事实

把全球城市画在双对数坐标（人口 vs GDP），它们挤在
斜率约 1.15 的直线附近——**城市每大一倍，人均产出
多约 15%**；而基础设施只多 85%。"大城市机会多"
不是文学修辞，是幂律的斜率。

## 假设与依赖

规模报酬递增在某处存在（否则集聚无理由——这是与
新古典完全竞争的深刻不兼容点）；知识溢出局部化
（距离衰减——面对面仍有带宽）；标度律假设网络
结构跨城市稳定（用它比较城市系统时的隐含前提）。

## 教材锚
