# 讲透城郊经济学 · 城乡边界的实验室

> **定位**：这支负责 GB/T 79047 三级"城郊经济学"——
> 城乡结合部、都市圈与城乡融合带的经济分析。这里是
> **两种土地制度、两种生活方式、两套公共政策相遇的边境**：
> 拆迁、城中村、通勤迁徙、土地增值分配全部发生在这条带上。**GB/T 三级**（非自定）。

## 诞生

郊区化（suburbanization）作为全球现象始于 20 世纪
（汽车+电车道把住宅推出步行城市）；中国版本更具戏剧性：
城乡二元土地制度使"城郊"成为唯一能发生农地转用的地带
——土地增值收益分配（征地补偿制度）成为中国社会
转型期最重要的再分配机制之一；2015-2020 农村土地制度
三项改革试点（征地/集体经营性建设用地入市/宅基地）
全部以城郊为主战场。

## 核心问题（3-5 条）

- ✅ 已解：土地增值分配的机制（征地-出让价差的结构）
- ✅ 已解：郊区化的通勤-地价权衡（竞租模型的家庭侧应用）
- 🔄 前线：城中村改造（2023 起扩围）的融资与安置模式
- 🔄 前线：都市圈同城化（轨道通勤圈）的边界与治理
- ❌ 未解：城乡融合的终局形态（边界消失还是永久二元的中间态）

## ✨这支最美的一个事实

城中村——规划图纸外的自发城市——为上亿流动人口提供了
正式市场永远给不起的"可支付起步房"：区位好、租金低、
社区网络密。**它是对住房政策最尖刻的辩护状：没有补贴、
没有规划，穷人的住房问题在灰色地带自组织解决了大半**——
拆与留之争因此远不只是市容问题。

## 假设与依赖

城乡土地制度双轨（国有/集体）是分析起点而非变量；
通勤成本与地价差驱动人口再分布（竞租理论在制度
边境上的应用）；"半城市化"人口（就业在城市、身份在
农村）是中国城郊带的特征变量。

## 教材锚

- 中国城乡结合部与土地征转制度研究（周其仁、刘守英等的制度叙事）
- 全球郊区化研究（Brueckner 城市扩张理论文献群）
- 家族层竞租件（梯度在边境的延伸）
