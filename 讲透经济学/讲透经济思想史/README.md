# 讲透经济思想史 · 人们如何学会思考"稀缺"

> 经济思想史：**把"人如何思考经济"本身当作研究对象**——思想不是真理竞赛的记分牌，
> 而是被考据的史料：谁在什么问题压力下、用什么概念工具、给出了什么答案，
> 后又被什么新问题推翻。
>
> GB/T 13745：79025（二级学科，三级明细未列——自定主干三支）。
> 宇宙：[讲透经济学](../README.md) · 厚家族（材料丰富，章幅从宽）。

## 诞生

经济思想与经济分析是两回事：思想古已有之（轻重、义利、公正价格），
**把经济当作独立对象来"分析"**却是晚近的事。学科化的三步：

1. **词的诞生**：1615 年蒙克莱田（Montchrétien）造出"政治经济学"一词——
   经济从家政（oikonomia）变成国家事务；
2. **体系的诞生**：1776 年斯密《国富论》——第一次把价格、分工、贸易、
   赋税装进一个"自协调市场"的框架；
3. **学科的诞生**：19 世纪末大学设经济学讲席、专业期刊创立——
   思想史随之成为对这段谱系的考据学。

熊彼特《经济分析史》（1954）定下本学科的标尺：不写"经济思想的花絮"，
写**分析工具的演进史**——每个时代的经济学能解决什么问题、工具从哪来。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 水与钻石悖论（有用者贱、无用者贵） | ✅ 1871-1874 边际革命解决 | 效用按"边际"而非"总量"定价——现代微观的地基 |
| 劳动价值论能否自洽解释价格与利润 | ✅ 逻辑命运已澄清 | 边际主义胜出；但其对剥削/权力的追问转入制度与政治经济学 |
| 一般均衡方程组是否有解 | ✅ 1954 Arrow-Debreu | 数理经济学为"看不见的手"补上了存在性证明（思想上迟到了 80 年） |
| 斯密问题（《国富论》利己 vs《道德情操论》同情） | 🔄 持续争论 | 人性假设是统一还是割裂——关系到经济学边界 |
| 价值转形问题（《资本论》卷一价值→卷三生产价格） | 🔄 百年论战 | Bortkiewicz 1907 以来数学解层出不穷，解释学意义仍争 |
| 2008 危机后宏观主流为何"免于清算" | 🔄 前线 | 思想史的当代现场：范式更替的动力学 |

## 假设与依赖

本学科站在三条假设上：①思想有可追溯的连续谱系（代价：容易把体系强加给古人——
斯密不是"斯密主义者"）；②文本可考据（著作、通信、手稿、讲义）；③"经济学"
的身份可以合法地回溯投影（代价：19 世纪之前无人自称"经济学家"，重商主义者
从未自称重商主义者——标签是后人贴的）。

## 教材锚

  "理论与反理论"对照读法的典范

- 中线：赵靖《中国经济思想史》、胡寄窗《中国经济思想史》
