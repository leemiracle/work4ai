# 讲透西方经济思想史 · 问题接力五纪元

> 支：[讲透经济思想史](../README.md) 自定主干支。斯密到行为经济学——
> 一部"旧答案如何变成新问题"的接力史。

## 定位句

本支负责**西方经济思想的纪元更替**：前学科（经院—重商—重农）→
古典（1776-1870s）→ 边际纪元（1871-1930s）→ 凯恩斯纪元（1936-1970s）→
当代（理性预期与行为转向）——每一纪元由一个卡壳的问题开启。

## 诞生与关键事件

- 1776 斯密《国富论》：市场自协调体系——"经济学"的创世纪
- 1817 李嘉图《原理》：劳动价值论+比较优势——抽象化的代价与威力同时显现
- 1871-74 边际革命（门格尔/杰文斯/瓦尔拉斯三重独立）：水与钻石悖论解决
- 1890 马歇尔《经济学原理》：供需剪刀+弹性术语——教科书形态的诞生
- 1936 凯恩斯《通论》→ 1937 希克斯 IS-LM：理论革命与翻译损耗的标本
- 1976 卢卡斯批评 → 1980s 理性预期革命；1979 卡尼曼-特沃斯基前景理论
  → 1990s- 行为与实验转向（2002、2017 诺奖）

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 水与钻石悖论 | ✅ 1871-74 边际效用论解决 |

| 行为革命是"修补"还是"范式更替" | 🔄 争论 |

## 这支最美的一个事实（一句）

瓦尔拉斯 1874 年写下一般均衡方程组时不知道解是否存在，
80 年后（1954）Arrow-Debreu 用不动点定理补上存在性——
"看不见的手"先被信仰了八十年，才被证明。
