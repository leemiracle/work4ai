# 讲透中国古代经济思想 · 轻重、义利、本末

> 支：[讲透经济思想史](../README.md) 自定主干支。司马迁到严复之间，
> 中国本土传统两千年——被近代中断、又被当代召回的思想库存。

## 定位句

本支负责**中国古代的国家—市场思想**：轻重之术（国家收放以平物价）、
义利之辩（伦理与财富的关系）、本末之序（农与商的位次）、以及历代
财政制度的连环改革（占田→两税→一条鞭→摊丁入亩）。

## 诞生与关键事件

- 春秋战国：管子轻重论（托名管仲）——货币谷物收放的宏观调控雏形；
  儒家义利之辩、法家重农抑商同时成型
- 前 81 年：盐铁会议——桑弘羊（官营平准）vs 贤良文学（放任节用），
  《盐铁论》为国家干预论战的最早完整文本
- 司马迁《史记·货殖列传》："善者因之"——最早的自由放任倾向表述之一
- 780 杨炎两税法 → 1581 张居正一条鞭法 → 1723 摊丁入亩：
  财政货币化的千年连环
- 1901-02：严复译《原富》——本土传统与西方经济学接通，传统转为学科史对象

## 这支最美的一个事实（一句）

"善者因之，其次利道之，其次教诲之，其次整齐之，最下者与之争"——
司马迁在公元前就把干预强度排成了五级谱系，最低一级才是"与民争利"。

## 假设与依赖

读本支需中国通史基础；史学假设：以传世政论文本为主要史料
（奏议、食货志），民间经济观念的材料远少于官方文本——沉默偏差大。
