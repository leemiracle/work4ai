# 讲透马克思主义经济思想史 · 从《资本论》到社会主义市场经济

> 支：[讲透经济思想史](../README.md) 自定主干支。一条思想线的三段论：
> 批判资本主义的理论 → 建设社会主义的实验 → 市场经济的理论再发现。

## 定位句

本支负责**马克思主义经济思想的展开史**：古典政治经济学的最彻底化
（劳动价值论→剩余价值）→ 帝国主义论与计划经济实验（1917-1980s）→
社会主义商品生产论争与中国化（1984 有计划商品经济→1992 社会主义
市场经济）——思想史上唯一一段"从理论直接进入制度运行"的主线。

## 诞生与关键事件

- 1848《共产党宣言》；1867《资本论》第一卷（二、三卷恩格斯整理，
  1885/1894 出版）
- 1907 Bortkiewicz 挑起转形问题：价值→生产价格的数学转形百年论战开端
- 1899 伯恩施坦修正主义→第二国际分裂；1917 列宁《帝国主义论》
- 1920s 苏联物资平衡表实践；1952 斯大林《苏联社会主义经济问题》、
  1954《政治经济学教科书》定本
- 1956- 毛泽东《论十大关系》；1978 十一届三中全会；1984 有计划商品
  经济；1992 十四大确立社会主义市场经济——"计划与市场都是手段"

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 转形问题（价值如何转形为生产价格） | 🔄 数学解多、解释学未终结 |
| 兰格-米塞斯论战（计划能否模拟市场） | ✅ 理论上可解（试错法/影子价格），信息与激励上不可行——大数据时代重开 |
| 苏联教科书体系为何教条化 | ✅ 思想史解释成熟（政治定型→理论定型） |
| 社会主义市场经济的理论地位（通向何方） | 🔄 前线（本身在历史进程之中） |
| 马克思主义与西方主流的危机理论能否互译 | 🔄 争论（利润率下降 vs 有效需求不足） |

## 这支最美的一个事实（一句）

兰格 1936 年用试错法证明计划者可以扮演瓦尔拉斯拍卖人——三十年后
计算复杂性证明这条路走不完，又四十年后大数据让这个问题重新开放：
一个论战横跨三波技术条件。
