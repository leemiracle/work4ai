# 讲透种植业经济学 · 大田里的部门经济

> **定位**：这支负责 GB/T 79059 三级"种植业经济学"——
> 粮、油、糖、菜、果的生产与市场部门分析。
> 它是蛛网模型的故乡：**大田作物的供给滞后最规整
> （一年一季）、需求最刚性（口粮）**——周期现象的
> 标准标本。**GB/T 三级**（非自定）。

## 诞生

种植业是最早被经济学化的农业部门（李嘉图的地租
例证全是谷物）；1930s 美国农业调整法案（AAA）的
价格支持体系以大田作物为对象；中国的粮改史
（统购统销 1953→保护价 1990s→最低收购价 2004→
目标价格/生产者补贴 2014-）是本支的政策主轴。

## 核心问题（3-5 条）

- ✅ 已解：口粮最低收购价的双轨机制（托底收购+
  市场化购销）
- ✅ 已解：目标价格改革（新疆棉花/东北玉米——
  价补分离：价格归市场、补贴归财政）
- 🔄 前线：三大主粮与大豆玉米的种植结构调整
  （镰刀弯地区调减与扩种油料的政策联动）
- 🔄 前线：经济作物的市场周期（棉花/糖料的收储改革遗产）
- ❌ 未解：口粮绝对自给与饲料粮进口的长期均衡结构

## ✨这支最美的一个事实

中国小麦水稻的最低收购价政策是"半蛛网稳定器"的
精巧设计：只在市价跌破时启动（托底不封顶）——
丰收年农民保收入、价格信号仍向下传导（抑制来年
过度扩种）。托底不封顶四个字，是价格支持政策
六十年全球实验里找到的最优折中（代价：托底价
定多高的永恒争论）。

## 假设与依赖

大田作物的蛛网参数（供给滞后=一季、需求刚性）
是家族层模型的标准参数化；政策档期（春耕前公布
最低收购价）是决策时点约束；依赖家族层蛛网与
储备件+世界农业支的贸易变量。
