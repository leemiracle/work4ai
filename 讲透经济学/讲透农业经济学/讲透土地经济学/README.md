# 讲透土地经济学 · 稀缺的第一形态

> **定位**：这支负责 GB/T 79059 三级"土地经济学
> （包括国土经济学、农业资源经济学等）"——农地的
> 地租、产权、流转与利用。土地是经济学的第一个
> 稀缺对象（李嘉图-马尔萨斯时代），农地是它的
> 主要形态。**GB/T 三级**（非自定；与
> [城市土地经济学](../../讲透城市经济学/讲透城市土地经济学/)
> 分置城乡两侧，按 GB/T 分立）。

## 诞生

1817 李嘉图级差地租（土地肥力/位置差→地租）；
1924 Ise 与 1928 Ely《土地经济学》建制化（威斯康星）；
1970s- 产权学派（Demsetz 等）重述土地制度；
中国现场：土改（1950）→集体化→家庭联产承包（1978）→
三权分置（2016-2018 确权登记）→二轮延包试点（2023-）
——全球最密集的土地制度实验场。

## 核心问题（3-5 条）

- ✅ 已解：级差地租与土地价格的地租资本化机制
- ✅ 已解：地权稳定性与农业投资的关系（确权证据积累）
- 🔄 前线：三权分置下经营权的抵押与流转边界
- 🔄 前线：土地细碎化的效率损失与互换并地
- ❌ 未解：集体所有制的长期均衡形态（产权束的终点）

## ✨这支最美的一个事实

中国农地制度的核心发明是**权利束拆分**：所有权（集体）、
承包权（农户、 member 权益）、经营权（流转、可抵押）——
教科书说"所有权残缺必致低效率"，三权分置是反例探索：
用**稳定（承包权不动）+流动（经营权动）**两个束
同时满足保障与效率——土地经济学的中国原创题。

## 假设与依赖

土地总量给定（供给零弹性）；位置与肥力差异是
地租的物质基础；制度（产权结构）是分析变量而非
背景——依赖[讲透农村经济学](../../讲透农村经济学/)
的制度层与[家族 00 章]级差地租件。

## 教材锚

- 周其仁《城乡中国》、刘守英《土地制度与中国发展》
  （中国制度叙事双柱）
- 家庭联产承包与三权分置政策文献群（判例层）
