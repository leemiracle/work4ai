## 一、诞生

1. **18-19 世纪地租与人口之辩**——李嘉图级差地租与
   马尔萨斯人口论：农业是政治经济学的出生地之一
   （魁奈《经济表》干脆以农业为唯一生产部门）。
2. **1900s 建制化**——美国农学院体系（1862 赠地法案）
   孵化农业经济系；1920s-30s 美国农业危机（大萧条中
   农产品价格崩盘）催生价格支持政策与农业政策学。
3. **1960s 两场革命**——舒尔茨《改造传统农业》
   （技术要素论）+ 绿色革命（高产良种+化肥在亚洲的
   实证胜利）；同期 Zeuthner/Ezekiel 的蛛网理论
   （1930s）成为理解农产品价格波动的标准件。
4. **中国现场**——集体化（1950s）→家庭联产承包（1978）→
   市场化改革（1985-2004 取消统购统销）→税费改革与
   补贴体系（2004-）→粮食安全与乡村振兴双主线（2013-）。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 农产品价格为什么周期波动 | ✅ 1930s 蛛网模型 | 供给看上期价格+需求刚性=振荡系统（本家族实验） |
| 传统农业为何低效、如何改造 | ✅ 1964 舒尔茨 | 贫穷但有效；改造=引进新要素（人力资本+技术） |
| 技术进步养活世界了吗 | ✅ 绿色革命实证 | 良种+化肥使粮食增速跑赢人口——马尔萨斯暂时失业 |
| 农业补贴该不该给、怎么给 | 🔄 永恒政策题 | 价格支持（黄箱）扭曲贸易、直接补贴（绿箱）转移收入——WTO 框架下的百年拉锯 |
| 粮食安全 vs 效率 | 🔄 中国活题 | 18 亿亩红线/大豆进口依赖（八成+）/适度进口之争 |
| 谁来种地（老龄化与规模经营） | 🔄 前线 | 小农老龄化+流转集中——东亚小农的转型难题 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 供给对价格的响应有滞后（生物周期） | 蛛网模型成立 | 滞后结构因产品而异（肉猪 18 个月、粮食 1 季）——单一模型打天下易翻车 |
| 需求刚性（食品缺乏弹性） | 谷贱伤农可解 | 政策空间被锁死：丰收反而伤农 |
| 技术进步外生可引进 | 绿色革命逻辑 | 种质依赖与技术主权的地缘风险（01 章） |
| 家庭农场为基础单位 | 与东亚现实匹配 | 规模经济的研究被边缘化——大农场体系的经验装不进来 |
