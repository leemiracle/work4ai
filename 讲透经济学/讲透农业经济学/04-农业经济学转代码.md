# 04 · 农业经济学转代码：从蛛网沙盘到估产管道

> **本章回答五问之五（本家族：讲透农业经济学）。**
> 三件套：**可机械化边界 → 代码走廊 → 工程师落点**。
> 核心判断一句话：本家族最成熟的代码件是**周期沙盘
> 与价格监测**（调控部门的仪表盘），最有未来的代码件
> 是**估产管道**（遥感+气象+单产模型的融合）——
> 一个向后看稳周期，一个向前看算产量。

---

## 一、可机械化边界

| 环节 | 可机械化 | 形态 |
|------|---------|------|
| 蛛网模拟（三区制+预期机制） | ✅ | 差分迭代+谱半径（本家族实验） |
| 储备吞吐规则仿真 | ✅ | 规则引擎 |
| 保险费率/赔付精算 | ✅ | 分布假设+蒙特卡洛 |
| 价格监测与异常预警 | ✅ | 时序基线+阈值（批发市场价格日度数据） |
| 遥感估产 | ✅（工程重） | 植被指数→单产回归（地块级） |
| 生产函数与技术进步分解 | ✅ 可估计 | 面板计量 |
| 农户预期的建模 | ❌ | 调查数据可得，机制不可构造 |
| 极端气候情景 | ❌（只能消费气候模型输出） | 情景分析非预测 |

## 二、代码走廊

### 走廊①：蛛网沙盘（本家族实验）

```python
# 天真预期：P[t+1] = (a_d - a_s - b_s·P[t]) / b_d，特征根 λ=-b_s/b_d
# 断言：收敛区每期振幅×|λ| 精确衰减 / 临界区等幅 / 发散区指数放大
# 适应性预期：2×2 系统谱半径 <1 判收敛（λ_e=0.3 → ρ=0.550）
# 政策臂：调 b_d（需求替代）与 λ_e（预期管理）看区制迁移
```

[experiments/cobweb.py](experiments/cobweb.py) 是可跑版。
沙盘的判词同其他家族：**当测谎仪**——"猪周期被熨平了吗"
的判断隐含了哪组斜率与预期参数，沙盘三分钟逼问。

### 走廊②：价格监测管道

批发市场日度价格 → 季节分解+基线 → 异常指数
→ 预警分级。工程要点：季节性（节前需求峰）与
趋势（成本推动）的分离——多数"暴涨暴跌"新闻
是没做季节调整的原始序列（口径学的时序版）。
能繁母猪存栏监测（月度）是同一管道的产能前哨
（价格是后视镜、存栏是导航仪——01 章的眼睛）。

### 走廊③：估产与保险精算

- **估产**：遥感植被指数（NDVI 时序）+气象数据+
  单产统计模型 → 地块/县级产量分布。数据融合
  是工程主体（遥感幅宽、云污染、地块边界矢量的
  对齐）；与[计算机宇宙·图象处理](../../讲透计算机科学技术/讲透计算机应用/讲透计算机图象处理/)支
  共享技术栈。
- **保险**：历史产量/价格分布 → 保障水平-费率表 →
  赔付情景蒙特卡洛。天气指数保险把"查勘定损"
  换成"指数触发"（降水/温度的站点数据）——
  **道德风险与查勘成本一起消掉**，代价是基差风险
  （指数与实际损失脱节）——精算与制度设计的合流点。

## 三、工程师落点

| 场景 | 落点 | 备注 |
|------|------|------|
| 农业农村部门市场信息系统 | 价格/产能监测预警 | 调控仪表盘的运营方 |
| 农业保险科技 | 承保理赔自动化、指数保险 | "按图承保、按图理赔"（遥感+地块矢量）——中国农险的政策级落地 |
| 期货与产业服务 | 套保策略、基差分析 | 农产品期货的价格发现与风险管理 |
| 大型农企/平台 | 产销预测、供应链计划 | 从"靠经验"到"靠数据"的产业端 |

**诚实判词**：农业数据工程的岗位在政策机构、保险与
期货——特点是**数据脏（口径多）、时效紧（季节窗）、
容错低（粮安问责）**；最有壁垒的技能不是建模，
是**口径考古**（统计口径的历次变更倒背如流）。

## 四、反直觉发现（⑥）

**最古老的模型（蛛网 1938）配上了最新的数据（实时价格+
遥感估产）——中间没有新模型。** 农产品市场预测的
工程升级全部发生在**数据与监测**侧，动力学核心
还是八十年前的差分方程：因为系统的一阶结构
（滞后供给+刚性需求）没变，变的是参数的可观测性
（产能/预期如今可以高频测量）。**模型不老，数据年轻**
——判断技术怎么改变一门学科，先看它改变的是
模型的哪一层。

## 五、✨美之时刻（⑧要件）：精确到 9 位小数的收敛判据

**陈述**：`assert np.allclose(ratios, -b_s/b_d, atol=1e-9)`——
蛛网价格每期偏离与前一期之比**精确等于**特征根
（不是拟合、不是近似）：收敛区 45→22.5→11.25…
每步严格乘 −0.5。一个由农民的播种决策构成的
混沌世界，在差分方程里露出钟表般的齿轮。

**为什么美**：*必然*——社会行为聚合成精确的数学关系，
是这个学科最动人的时刻（与复式记账的恒等式、
Cournot 的 Lerner=HHI/ε 同列为本宇宙三大"精确齿轮"）；
混沌的表象、齿轮的内核——**集体行动的可预测性
远高于个体行动**，这是整个实证社会科学的地基信念。

**怎么亲历**：跑实验 Part A，打印 40 期价格序列的
偏离比——每个比值都严格是 −0.500000000；
然后把 P0 换成任何别的数——齿轮转速不变
（特征根与初值无关）：**你改写不了周期，只能改写振幅**
——这句判词同样适用于政策。
