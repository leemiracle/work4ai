# 讲透农业生产经济学 · 田间的生产函数

> **定位**：这支负责 GB/T 79059 三级"农业生产经济学"——
> 农业生产函数、要素配置、技术进步与技术采纳。
> 农业经济学的"工厂物理"：土地/劳动/资本/投入品
> 如何组合出产量。**GB/T 三级**（非自定）。

## 诞生

1920s-50s 生产函数方法进农业（Cobb-Douglas 的最早
大样本应用之一就是美国农业）；1964 舒尔茨把"低效"
归因于要素停滞而非农民无能；1971 Hayami-Ruttan
诱致性创新（技术路径由要素稀缺性诱导——家族 00 章✨）；
1970s- 速水-拉坦的跨国农业发展数据库成为本支的
标准实证底座。

## 核心问题（3-5 条）

- ✅ 已解：农业生产函数的估计与规模报酬检验
  （家庭农场多为规模报酬不变——小农并不"小"在生产效率）
- ✅ 已解：技术效率测度（DEA/SFA 分解技术效率与配置效率）
- ✅ 已解：诱致性创新的跨国检验（机械 vs 生物技术路线）
- 🔄 前线：社会化服务的规模化（服务规模化替代土地规模化——
  中国第三条道路）
- ❌ 未解：气候肥尾下的生产函数（极端事件的产出弹性）

## ✨这支最美的一个事实

"小农无效率"是农业经济学被推翻次数最多的成见：
从恰亚诺夫到舒尔茨到现代效率测度，结论反复指向
**家庭农场在技术效率上不输大农场**——劣势只在
采购、销售与融资的市场势力。效率问题在田间，
规模问题在市场——这个区分决定了农业政策的
整个设计逻辑。

## 假设与依赖

生产技术可函数化；农户目标近似利润/家庭效用最大化
（依赖[讲透农村经济学/讲透农户与二元经济](../../讲透农村经济学/讲透农户与二元经济/)
的行为件）；数据层依赖农业试验站（农学与经济学的
数据婚姻——本支建制的独特优势）。
