# 讲透农业企业经营管理 · 农场作为企业

> **定位**：这支负责 GB/T 79059 三级"农业企业经营管理"——
> 农场、合作社企业与涉农公司的经营管理：生产计划、
> 契约、供应链与风险管理。家庭农场之外的农业组织世界。**GB/T 三级**（非自定）。

## 诞生

农业的企业化管理随商品化出现：美国家庭农场的
公司化（1970s-，LLC 化的农场）、订单农业的全球扩散
（契约农业——公司+农户）、中国的"龙头企业"模式
（1990s 农业产业化政策催生，"公司+农户/合作社+基地"
诸形态）；2000s 超市革命（全球农产品供应链重构）。

## 核心问题（3-5 条）

- ✅ 已解：契约农业的分配（订单价格的风险转移——
  公司与农户谁承担价格波动）
- ✅ 已解：农业供应链的治理（契约 vs 垂直一体化——
  资产专用性的教科书应用：专用投资高则一体化）
- 🔄 前线：龙头企业与农户的履约机制（违约的
  关系治理 vs 法律治理）
- 🔄 前线：品牌农业的溢价机制（地理标志的信任品问题）
- ❌ 未解：家庭农场与公司农场的长期边界（组织经济学
  在农业的未竟题——与[农户与二元经济]支共答）

## ✨这支最美的一个事实

"公司+农户"是全球农业组织史上最大规模的契约实验
（中国数万个龙头企业带动上亿农户）——教科书说
资产专用性高该一体化，但它恰恰在专用性极高的
养殖与种植环节以契约形式长期存在：**关系、声誉、
专用性投资的三重锁**替代了产权的锁——契约治理的
中国经验正在改写组织经济学的案例库。

## 假设与依赖

企业分析框架适用（依赖[讲透工业经济学/讲透工业企业经营管理学](../../讲透工业经济学/讲透工业企业经营管理学/)

的分层管理是经营主线。
