# 讲透农业合作经济 · 弱者的联合经济学

> **定位**：这支负责 GB/T 79059 三级"合作经济"——
> 合作社与其他合作组织（社区股份合作/信用合作/
> 供销体系）。合作社是组织经济学的珍稀物种：
> **用户所有、用户控制、用户受益**——不是资本的企业，
> 是人的企业。**GB/T 三级**（非自定）。

## 诞生

1844 英国罗奇代尔公平先锋社（28 个纺织工人，
"一人一票、按交易返还"的原始规则——现代合作社原则
的出生证明）；1890s-1930s 全球扩散（丹麦奶业合作社、
日本农协、中国民国乡村建设运动）；1937 国际合作社
联盟原则成文化；1995 曼彻斯特原则（现行版）。
中国线：1950s 合作化（从自愿到强制的教训）→
改革后新型合作社（2007《农民专业合作社法》）→
"空壳社"清理与规范提升（2019-）。

## 核心问题（3-5 条）

- ✅ 已解：合作社的产权逻辑（按惠顾分配而非按资本
  分配——与投资者所有企业的分野）
- ✅ 已解：集体行动的搭便车问题（Olson 1965——
  小集团与选择性激励）
- 🔄 前线：空壳合作社的治理诊断（政策补贴驱动的
  假合作 vs 真合作的条件）
- 🔄 前线：合作社 vs 龙头企业的组织竞争（谁能真正
  让农户分享增值）
- ❌ 未解：合作社的资本形成难题（惠顾返还制天然
  融资难——百年未解的内生缺陷）

## ✨这支最美的一个事实

诺奖级难题"合作社为什么存在"有一个经济学解释链：
农户面对的买方垄断（收购商压价）与卖方垄断（农资
抬价）可以用**后向+前向的联合**内部化——合作社
本质上是农民自建的"双边垄断对冲机"。妙处在于
它用一人一票而非一股一票分配控制权：
**资本在这里是仆人不是主人**——组织光谱上
介于市场与企业之间的第三形态。

## 假设与依赖

成员异质性可控（大户与小农的利益结构——
异质性是空壳化的温床）；集体行动的逻辑适用
（Olson 件）；依赖[讲透农村经济学/讲透农户与二元经济](../../讲透农村经济学/讲透农户与二元经济/)
的行为件与家族层蛛网件（合作社的稳定器职能）。
