# 讲透农业生态经济学 · 田园的外部性账本

> **定位**：这支负责 GB/T 79059 三级"农业生态经济学"——
> 农业与生态系统的经济接口：面源污染、化肥农药的
> 外部性、农业碳排与生态补偿。**GB/T 三级**（非自定；
> GB/T 79043 生态经济学把农业生态经济学"归入 79059"——
> 双向指引：生态经济学的农业面在此，不在 79043）。

## 诞生

1962《寂静的春天》开启农药外部性的公共议程；
1970s-80s 环境经济学工具（庇古税/产权）进入农业；
2010s- 农业面源污染（化肥零增长行动 2015）与
2020s 双碳（稻田甲烷、土壤碳汇）把本支推入政策前排。

## 核心问题（3-5 条）

- ✅ 已解：面源污染的经济学定性（分散排放难监管——
  与点源的工具差异）
- ✅ 已解：生态补偿的机制设计（退耕还林/轮作休耕补贴）
- 🔄 前线：化肥农药减量的增产-减污权衡（测土配方
  的技术经济边界）
- 🔄 前线：农业碳汇的计量与交易（土壤碳库的可测量性）
- ❌ 未解：生物多样性价值的货币化（传粉服务的定价困境）

## ✨这支最美的一个事实

退耕还林（1999 起）是全球最大规模的生态补偿实验：
千万公顷坡耕地退耕、亿级农户参与——用粮食换生态，
工程中期评估发现了经典权衡：生态有效、到期后
复耕压力依赖补贴延续——**生态服务的"租金"必须
永远付下去**，一次买断买不来永久生态。

## 假设与依赖

外部性可界定可计量（农业面源恰好是计量最难的一类：
分散、滞后、随水文漂移）；依赖环境经济学的
工具箱（生态经济学 79043 的对面）。

## 教材锚

- 《寂静的春天》（公共议程起点）
- 中国退耕还林评估文献群+化肥零增长政策评估
- 环境与资源经济学工具书（家族外邻的标准件）
