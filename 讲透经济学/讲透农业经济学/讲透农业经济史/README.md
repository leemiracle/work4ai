# 讲透农业经济史 · 从圈地到绿色革命

> **定位**：这支负责 GB/T 79059 三级"农业经济史"——
> 农业制度与生产变迁的历史：圈地、农奴解放、
> 集体化、绿色革命。农业是经济史的母剧场
> （工业革命前 90% 的人种地——所有人的祖辈都是农民）。**GB/T 三级**（非自定）。

## 诞生

两个传统合流：一是计量经济史（cliometrics，1960s——
Fogel-Engerman 用铁路与奴隶制研究重写美国经济史，
Fogel 1993 诺奖——农业是最早被计量化的历史部门）；
二是制度经济史（圈地运动、俄国农奴制、东亚小农制
的比较研究——诺斯传统）。
中国线：明清江南农业（ involution 内卷化之争——
黄宗智 vs 历史学界）、集体化史（1950s-70s）、
改革史（1978 小岗村到统分结合）。

## 核心问题（3-5 条）

- ✅ 已解：圈地运动的效率-分配再评价（羊吃人叙事的
  计量修正——产权集中与农业革命的关系）
- ✅ 已解：内卷化之争（Involution：单位劳动边际报酬
  递减下的人口压力——明清江南的"没有发展的增长"）
- 🔄 前线：集体化绩效的重估（饥荒经济学——Sen 的
  权利方法与退出权理论）
- 🔄 前线：绿色革命的全球史（技术扩散的政治经济）
- ❌ 未解：欧洲特殊论之争（为什么工业革命在欧洲的
  农业？——Allen vs 广义加州学派）

## ✨这支最美的一个事实

Fogel 用铁路重新计算美国经济增长，顺手发明的方法论
（反事实计量史）后来养活了几代经济史学家——
而他的另一半工作更震撼：测算美国南方奴隶制种植园
的"效率"并不低下（有争议但方法严密）——
**史实判断与道德判断的分离能力**是计量史学的
职业成人礼，也是它永远的政治痛点。

## 假设与依赖

历史数据可信赖度分层（账簿>方志>追述）；反事实
方法合法但需明示假设；依赖[讲透经济史](../../讲透经济史/)
的母学科方法与家族层诱致性创新框架（历史检验的
理论件）。
