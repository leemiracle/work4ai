# 讲透世界农业经济 · 全球食物体系的地图

> **定位**：这支负责 GB/T 79059 三级"世界农业经济"——
> 全球食物体系：农产品贸易格局、粮食安全的地缘、
> 各国农业模式比较。**GB/T 三级**（非自定；
> 贸易的理论件与 79029 世界经济学相接）。

## 诞生

食物的全球体系由三轮全球化织成：1870-1914 第一轮
（蒸汽船+铁路把新大陆粮食灌进欧洲——李嘉图比较
优势的第一幕）；1945 后第二轮（美国农产品出口与
粮食援助的政治经济——"粮食武器"论争）；1995 后
第三轮（WTO 农业协定把补贴装进规则笼子+全球价值链）。
2022 俄乌冲击是第三轮的压力测试。

## 核心问题（3-5 条）

- ✅ 已解：农产品贸易的比较优势格局（土地丰裕国出口
  大田作物——美/巴西/澳；劳动与资本密集国出口
  高值品——荷兰模式）
- ✅ 已解：粮食援助的贸易扭曲效应（实物援助压低
  受援国粮价、打击本地生产）
- 🔄 前线：出口限制的合成风险（一国禁运引发连锁——
  2008 与 2022 两轮的机制比较）
- 🔄 前线：土地 grabbing（海外耕地投资的争端）
- ❌ 未解：全球粮食储备的最优分布（国家理性 vs
  全球理性的永久错位——00 章"储备的政治经济学"）

## ✨这支最美的一个事实

荷兰——国土四万平方公里、光照不足——是全球
第二农产品出口国（按出口额，仅次于美国）：
温室+种业+拍卖市场体系（鲜花拍卖的钟表式定价）
把"人多地少"的劣势翻转为知识与资本密集的优势。
**农业比较优势的来源不止土地，还有知识与组织**——
东亚农业现代化最重要的参照系。

## 假设与依赖

贸易框架适用（比较优势+运输成本）；粮食的商品
属性与安全属性并存（市场逻辑与国家逻辑的双轨——
家族 00 章的"储备矛盾"全球版）；依赖世界经济学
家族的贸易理论件。
