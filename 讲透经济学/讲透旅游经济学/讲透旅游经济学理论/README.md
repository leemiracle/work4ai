# 讲透旅游经济学理论 · 需求、供给与乘数的特殊性

> **定位**：这支负责旅游经济学的理论内核——需求三奇（收入弹性/季节性/
> 体验品）、供给三奇（不可储存/容量固定/不可搬运）、乘数与漏损、
> 旅游导向增长假说。GB/T 三级"旅游经济学理论"落位于此。

## 诞生

1899 年 Bodio 的游客消费统计与 1927 年 Mariotti 的首批专著把旅游
变成经济学对象；战后大众旅游提出了新理论问题（季节性产业的容量与
定价）；2000 年 TSA 让乘数核算有国际标准；2010s 后 Airbnb 与
overtourism 把平台经济学与公共品理论拉进来。

## 核心问题（3-5 条）

- ✅ 已解：旅游需求的收入弹性>1（奢侈品属性——实证稳定）
- ✅ 已解：峰荷定价定理（Steiner 1957——容量账记高峰，家族
  [03 章](../03-可构造与结构.md)）
- ✅ 已解：乘数-漏损框架（TSA 2000——游客支出≠本地收入）
- 🔄 前线：旅游导向增长（TLG）假说的因果检验（国别证据不一致）
- ❌ 未解：目的地声誉动态（网红地的崛起与速朽无定形模型）

## ✨这支最美的一个事实

旅游乘数总被宣传数字夸大：全包式度假村把食材、利润、机票都"漏"
回外地/外国，游客花的 100 元本地可能留下不足一半。**乘数不是宣传语，
是一张漏损表的余额**——这是理论支对地方政策的第一贡献（家族
[02 章](../02-语言特征.md)反直觉发现）。

## 假设与依赖

旅游支出可从总消费中剥离（TSA 口径）；季节模式稳定（收益管理与
规划的共同命门）；承载力外生（过度旅游恰恰反噬吸引物本身）。
