# 讲透旅游事业史 · 从壮游到大众旅游到入境游政策

> **定位**：这支负责旅游的历时维度——欧洲壮游（Grand Tour）、
> 温泉与海滨疗养、铁路与包价旅游、喷气时代的大众旅游、
> 中国入境游政策史。GB/T 三级"旅游事业史"落位于此。

## 诞生

旅游作为"事业"（产业+制度）的史前史：17-19 世纪欧洲贵族的
Grand Tour（教育性的长途游学）→ 1841 年 Thomas Cook 的第一班
包价火车（现代旅行社业起点）→ 1958 年波音 707 把跨洋旅行成本
砍到大众可及 → 1978 年后中国入境游从"外事接待"转"创汇产业"
→ 1999 年黄金周制度启动国内大众旅游 → 2023-2025 免签扩容的
入境游新政。

## 核心问题（3-5 条）

- ✅ 已解：交通技术与旅游形态的共生史（铁路→包价、喷气机→度假村、
  高铁→周末游）
- ✅ 已解：带薪休假制度与大众旅游的关系（需求的时间预算立法）
- 🔄 前线：黄金周制度的经济学评估（集中休假的拥堵成本 vs 分散
  带薪休假的执行难）
- 🔄 前线：免签政策作为旅游供给变量的量化（2023-2025 自然实验）
- ❌ 未解：旅游史上"接待→产业→治理"三阶段的一般规律（样本国太少）

## ✨这支最美的一个事实

1841 年 Thomas Cook 包下一列火车带 570 人往返 22 公里参加禁酒大会，
每人收 1 先令——**第一次把"旅行"打包成标准商品**（交通+餐饮+导览，
固定价格）。一个禁酒运动的副产品，开创了全球旅游业的基本单元：
**包价旅游**。此后一切"跟团"都是这 1 先令的后代。
