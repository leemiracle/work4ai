# 讲透旅游经济学 · 离家消费的产业

> **旅游经济学 = 研究"人为什么花钱离开家、这个产业如何运转"的学问**——
> 需求端三奇（高收入弹性·强季节性·体验品属性），供给端三奇（容量固定·
> 产品不可储存·不可搬运）。它的全部张力在一句话里：
> **全年最贵的那间房和最空的那间房，是同一间。**

## 一、诞生（三个原生问题）

1. **游客的钱怎么算（1899）**——意大利统计局长 Bodio 发表外国游客消费
   研究：旅游第一次成为**可统计的经济活动**；1927 年 Mariotti 写出
   首批旅游经济学专著，把旅游业当作产业对象。
2. **喷气机与带薪假（1958-）**——波音 707 投入运营+各国带薪休假普及，
   旅游从贵族壮游变为大众消费；经济学问题变成**大规模季节性产业**
   的容量与定价。
3. **景区该收多少钱（2000-2024）**——联合国旅游卫星账户（TSA 2000）
   让旅游的 GDP 贡献可比；2024 年威尼斯开出全球首个城市"进城费"，
   overtourism 把公共品定价推上前台。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 旅游需求的收入弹性>1 | ✅ 实证稳定 | 旅游是"奢侈品"——经济下行最先被砍 |
| 乘数与漏损（TSA 框架 2000） | ✅ 框架成熟 | 每元游客支出的本地放大系数；全包式度假村漏损过半 |
| 峰荷定价（Steiner 1957） | ✅ 已证明 | 容量成本应记在高峰用户账上——酒店/航空通用 |
| 收益管理（Littlewood 1972→EMSRb） | ✅ 工业标准 | 不可储存商品的 probabilistic 定价 |
| 旅游导向增长假说（TLG） | 🔄 证据混合 | 旅游业先行的增长战略——国别证据不一致 |
| overtourism 的治理 | 🔄 前线 | 免费景点=公共品被过度消费；威尼斯收费的实验 |
| 平台对目的地经济的净效应 | ❌ 未解 | OTA/Airbnb 的渠道效率 vs 房租外溢 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 旅游支出可从消费中剥离（TSA） | 产业的规模可比 | 口径复杂——"出差算不算"系列争议 |
| 季节模式稳定（收益管理的命根） | 容量与人力可排程 | 极端事件/趋势漂移即全盘失准 |
| 游客对目的地是价格接受者 | 定价分析简单 | 旅游的搜寻与预期反馈（声誉循环） |
| 目的地供给能力外生 | 乘数可算 | 过度旅游反过来侵蚀吸引物本身（承载力） |
