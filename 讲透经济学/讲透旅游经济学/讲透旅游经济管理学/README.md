# 讲透旅游经济管理学 · 目的地治理与收益管理

> **定位**：这支负责旅游的"管理面"——目的地治理（DMO/承载力/预约制）、
> 酒店与景区运营（收益管理/超售）、旅行社与 OTA 的渠道管理。
> GB/T 三级"旅游经济管理学+旅游企业管理学"归组于此。

## 诞生

管理现代化的三个节点：1970-80s 航空收益管理成熟后被酒店全面复制
（Littlewood→EMSRb，家族 [03 章](../03-可构造与结构.md)）；
1990s DMO（目的地管理组织）运动把"营销目的地"升级为"治理目的地"；
2020s 预约制与进城费（威尼斯 2024）把数量工具写进目的地治理的
工具箱。

## 核心问题（3-5 条）

- ✅ 已解：收益管理三件套（保护水平/动态价/超售——家族 [04 章](../04-旅游经济学转代码.md)
  走廊②③）
- ✅ 已解：渠道管理（OTA 直销/分销的价格墙与佣金博弈）
- 🔄 前线：预约制与分时入园的治理设计（数量工具与价格工具的配伍）
- 🔄 前线：景区/博物馆的免费开放 vs 定价（公共品定位之争）
- ❌ 未解：目的地"多主体共治"的最优结构（政府/居民/企业/游客四方利益）

## ✨这支最美的一个事实

收益管理的决策表每天重算：离入住还有 30 天，系统为高价客保护 20 间；
还有 3 天，保护降到 5 间——**同一间房的机会成本长在日历上**。
"越晚订越便宜"与"越晚订越贵"的分岔只有一个变量：余量。
看懂这张表，就看懂了酒店、航空、演唱会、云 spot 价格的
全部定价戏剧（家族 [03 章](../03-可构造与结构.md)美之时刻）。

## 假设与依赖

需求分级且可预测（舱位/房型篱笆有效）；no-show 率稳定（超售的
统计前提）；治理工具可执行（预约需实名与核验的技术底座）。
