## 一、可机械化边界（为什么边界画在这里）

| 问题类 | 可机械化程度 | 边界原因 |
|--------|-------------|---------|
| 峰荷定价（确定性季节） | ✅ 完全 | 闭式+格点双验证（本家族实验） |
| Littlewood/EMSRb 保护水平 | ✅ 完全 | 期望不等式，查表即得 |
| 季节分解（正弦/STL） | ✅ 完全 | 现成算法 |
| 超售优化（no-show 对冲） | ✅ 完全 | 二项分布期望罚款极小化 |
| 需求预测（到店曲线） | 🟡 ML | 预测≠决策；参数漂移需监控 |
| 承载力与流量仿真 | 🟡 仿真 | 排队网络近似可行，体验质量难量化 |
| 目地品牌与网络效应 | ❌ 尚未 | 声誉动态无定形模型 |

**判据一句话**：容量与价格的匹配（结构问题）全部可算；需求本身
（预测问题）交给统计；体验与声誉（心理问题）留给定位与叙事。

## 二、代码走廊（四条）

### 走廊①：峰荷定价（本家族实验）

[`experiments/seasonal_peak_pricing.py`](experiments/seasonal_peak_pricing.py)：
双季市场（Qh=100−p，Ql=60−p，容量成本 r=25），统一价 vs 分季价的
利润/容量/福利三断言，附 12 个月正弦负荷演示。核心模式：

```python
K = max(Qh(p_h), Ql(p_l))                    # 容量=峰值需求
profit = p_h*Qh + p_l*Ql - r*K                # 容量费只记一次
# 分季：p_l=mc（容量费与淡季无关），p_h 吸收容量账 —— Steiner 定理
```

### 走廊②：Littlewood 保护水平（两价）

```python
def accept_low(pL, pH, seats_left, hi_demand_dist):
    pH_exp = pH * (1 - hi_demand_dist.cdf(seats_left - 1))
    return pL >= pH_exp                        # 临界不等式
```
泊松需求下逐日重算保护水平，输出"天数×余座"的决策表——
任何 RMS（收益管理系统）的内核页。

### 走廊③：超售仿真

```python
show = rng.binomial(booked, 1 - no_show_rate) # 到店人数
cost = bump_cost * max(0, show - capacity) + empty_cost * max(0, capacity - show)
# 扫描 booked：期望总成本最低点 > capacity —— 超售是数学不是胆量
```

### 走廊④：季节分解（statsmodels STL 或手写正弦）

```python
X = np.column_stack([np.ones(12), np.sin(2*np.pi*m/12), np.cos(2*np.pi*m/12)])
beta, *_ = np.linalg.lstsq(X, monthly_demand, rcond=None)   # 趋势+振幅+相位
```
三行最小二乘复原"趋势×季节"语言（家族 02 章），振幅即容量浪费率
的预警指标。

## 三、工程师落点（这些东西在谁家产线上）

1. **酒店/航空 RMS**：保护水平+动态价+超售三件套（走廊②③），
   IDEAS/Prospero 类系统的内核。
2. **OTA 定价与调仓**：间夜库存的动态分销（渠道间价格墙），与
   [讲透商业经济学](../讲透商业经济学/) 平台定价共管。
3. **景区预约系统**：分时段预约=数量工具的工程化（01 章配额眼），
   与文旅部门治理需求直接对接。
4. **目的地智慧平台**：客流预测+承载力预警（走廊④输入），DMO 的
   决策屏。

## 四、✨美之时刻（⑧要件）：超售的最优点——冒犯的艺术有公式

**陈述**：座位 100，no-show 率 10%，改签赔偿 800 元。卖 108 张的
期望罚款<空座损失——**最优超售量是二项分布尾巴上的一个加号**。
航空公司每年因此少空转数百万座位，个别乘客则被"非自愿改签"——
同一公式里写着效率与冲突。**为什么美**：*必然*——期望值计算把
"该不该多卖"变成一行可审计的算术；旅游经济学最不体面的惯例
（超售）恰恰是它最严谨的数学。**怎么亲历**：走廊③扫描 booked
从 100 到 115，画出期望总成本 U 型曲线，找你的最优冒犯量。

## 五、反直觉发现（⑥要件）

边界的教学版：**本家族"能算"的部分几乎全部来自继承**（航空的
收益管理、物流的报童、电力系统的峰荷）——旅游经济学的原创贡献
在"目的地维度"（乘数/漏损/承载力治理），而那部分恰好最难算。
**能算的都是引进的，原创的都难算**——学科成熟度的一个有趣切片。

## 👁 认知升维（⑨要件）

**继承眼**：进入一个新领域，先盘点它的"进口技术"与"本土问题"——
进口技术看成熟度（能省多少年弯路），本土问题看未解度（值得
投入哪里）。旅游经济学的这份清单，也适用于你评估任何交叉岗位。
