# 03 · 可构造与结构：季节、峰荷与保护水平

> **本章回答五问之四（本家族：讲透旅游经济学）。**
> 旅游经济学有三个高构造度结构：**季节性分解**（波动可以拆开看）、
> **峰荷定价**（容量账的分摊定理）、**Littlewood 保护水平**
> （不确定需求的容量分配）。三者共同面对同一个敌人：**波动**。

---

## 一、季节性分解：把波浪拆成三种（直觉先行）

直觉：一年的入住率曲线像波浪。分解它：

```
需求(t) = 趋势 T(t) + 季节 S(t) + 噪声 ε(t)
            ↑长期增长    ↑年度波形    ↑不可预测
```

**结构三读**：
1. **季节项是钱**：S(t) 的振幅决定容量投资的浪费率——振幅越大，
   "为峰值建的产能"在谷底闲置越多（家族 00 章三角的定量化）。
2. **趋势项是战略**：T 的斜率回答"这个行业在不在长大"（数字游民
   世代趋势漂移的主战场，01 章方向四）。
3. **噪声项是收益管理的战场**：ε 的分布形状直接进入 Littlewood
   规则的概率项（本章三）。
   工具：确定性正弦拟合（月度数据足够）或 STL（周度/日度）——
   [讲透数学·讲透数理统计](../../讲透数学/讲透数理统计/) 的时间序列
   传统在这里落地。

## 二、峰荷定价：容量账的分摊定理（Steiner 1957）

双季市场（旺/淡各占半年），容量成本 r 只为峰值而建。定理：

```
淡季价 p_l = 运营边际成本（容量费与它无关）
旺季价 p_h = 运营边际成本 + 容量成本（账单全寄高峰）
```

**结构读法**：这不是伦理判断（旺季客"该"多付），是**成本归因的
必然**——容量若不为高峰存在就无需建造。本家族实验的断言组：
统一价 46.25 → 分季价（62.5/30），利润 1778→2306，所需容量
53.75→37.5（**省 30% 的产能投资**），总福利上升——效率与利润同向
的少有场景（因为统一价把容量错配给了淡季需求）。
**代价**：分配上，对时间无弹性的人群（只能在暑假出行的家庭）
承担全部容量账——峰荷定价的公平修辞战由此而来（教职员工假期的
立场问题）。

## 三、Littlewood 保护水平：把容量分给未来

两级票价（折扣票 p_L、全价票 p_H，p_H>p_L），容量 C，折扣票先到。
**收不收这张折扣票？** Littlewood 1972 规则：

```
接受 p_L  ⇔  p_L ≥ p_H · P(未来全价需求 ≥ 剩余座位)
```

**结构读法**：卖折扣票的机会成本是"这张座位未来可能卖全价"——
期望值随剩余座位数与剩余天数变化。**保护水平**（为全价客保留的
座位数）由这条不等式的临界点决定；EMSRb（1987）把它推广到多级票价，
成为航空/酒店系统的工业心脏。它与[讲透物流经济学](../讲透物流经济学/)
的报童问题是同一个数学对象：**容量=订货量，分位=临界比**——
"易逝商品的 probabilistic 定价"一族。

## 四、✨美之时刻（⑧要件）：保护水平的动态——座位的价格长在日历上

**陈述**：离起飞还有 30 天，系统为全价客保护 20 个座；还有 3 天，
保护水平悄悄降到 5——**同一张座位的价格预期随时间衰减**，
Littlewood 不等式每分钟都在重算。**为什么美**：*统一*——航空、
酒店、演唱会、闪购、云 spot 价格，全部是"易逝容量×不确定需求×
剩余时间"的三元函数；理解这一条，就看懂了所有"越接近越贵/越便宜"
现象的分岔条件（看余量还是看时间）。**怎么亲历**：04 章走廊③的
50 行模拟——两个泊松需求流抢一个容量，打印每日保护水平表。

## 五、假设与代价（④要件续）

| 结构 | 关键假设 | 失效现场 |
|------|---------|---------|
| 季节分解 | 波形年复一年稳定 | 签证/汇率/气候突变（01 章方向五） |
| 峰荷定价 | 旺季确定且唯一 | 多峰（五一+暑期+国庆）需多段定价 |
| Littlewood | 需求分级且独立到达 | 折扣客抢全价座（舱位篱笆失效）、no-show 率漂移 |

## 六、反直觉发现（⑥要件汇总）

淡季亏本开门仍是对的（p>AVC 即开门）· 峰荷分价让利润与总福利
同向上升（统一价的隐性浪费被释放）· 保护水平动态意味着"同一座位
不同时间机会成本不同"（价格的日历维度）· 乘数常被高估（漏损语言，
02 章）。

## 👁 认知升维（⑨要件）

**易逝眼**：给库存问三个问题——会过期吗？容量定死吗？需求分层吗？
三个"是"齐了，收益管理的全部逻辑（保护水平+超售+动态价）自动
适用。你的 GPU 批处理时段、广告位、餐厅翻台，都可以用这双眼睛
重新定价。
