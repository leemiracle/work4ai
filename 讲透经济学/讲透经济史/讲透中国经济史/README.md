# 讲透中国经济史 · 从长期领先到现代赶超

> 支：[讲透经济史](../README.md) 自定主干支。一个文明经济体两千年的
> 三段式：领先—坠落—回归，世界史上最完整的"长时段"标本。

## 定位句

本支负责**中国经济的长期表现**：古代高峰（宋代的"经济革命"争议）、
明清高水平均衡与停滞、近代坠落与工业化挫折（1820→1950 人均下降）、
当代赶超（1978- 增长奇迹）——核心问题是"为什么领先、为什么坠落、
为什么回归"。

## 诞生与关键事件

- 梁方仲、吴承明 1950s-80s：明代财政与国内市场研究，中文计量
  经济史奠基
- 1970s-80s 伊懋可（Elvin）"高水平均衡陷阱"论：宋代之后技术
  创新的经济激励枯竭
- 1990s-2000s 加州学派（Pomeranz、李伯重）：1750 年前江南与
  英格兰"平起平坐"，分流源于煤与新大陆
- 2009 Maddison 表：中国人均 GDP 1820:600 → 1950:448（150 年负增长）
- 1978-2010：人均 GDP 年增约 8-9%，人类史上最大规模的快速赶超

## 核心问题（3-5 条）

| 问题 | 状态 |
|------|------|
| 宋代是否发生"经济革命"（铁产量、货币化、市镇） | 🔄 争论（证据强、定性弱） |
| 明清为何高水平均衡而不突破 | 🔄 高工资低工资之争（vs 英国）持续 |
| 近代坠落：战争、条约体系还是内部结构 | 🔄 多因素论争 |
| 1820-1950 人均负增长的分解 | ✅ 量级清晰（战争+制度+人口） |
| 1978 后增长奇迹的动力（要素 vs TFP vs 制度） | 🔄 增长核算持续更新（跨 [讲透发展经济学](../../讲透发展经济学/)） |

## 这支最美的一个事实（一句）

1820 年中国占世界 GDP 约三分之一、人均却只有英国的三分之一——
同一个年份里"最大"与"最穷之一"并存，大分流研究的全部张力
浓缩在一个比例里。

## 假设与依赖

读本支需中国古代史框架；数据假设：官方人口/赋税序列可用但精度
随年代递减；"GDP"概念前推到传统经济需靠折算（粮食、布匹、工时）。
