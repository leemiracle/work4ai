# 讲透经济史 · 增长、危机与制度的长期档案

> 经济史：**用历史数据考据"经济如何随时间运行"**——它不是经济学的
> 例题库，而是经济理论的检验场：工业革命、大萧条、大分流这些
> "只发生一次的大事件"，恰恰是理论必须面对的终极考题。
>
> GB/T 13745：79027（二级学科，三级明细未列——自定主干两支）。
> 宇宙：[讲透经济学](../README.md) · 厚家族（材料丰富，章幅从宽）。

## 诞生

经济史与经济学同龄，但作为**独立学科**成型于 20 世纪：一边是档案学派
（物价史、货币史：韦伯-汉密尔顿 16 世纪西班牙物价序列），一边是
制度-叙事学派（Ashley、Unwin）；决定性时刻是 **1960s 计量史学
（Cliometrics，新经济史学）**——Fogel 用社会储蓄法重估铁路（1964）、
Fogel-Engerman《苦难的时代》重估奴隶制（1974）、North 把制度变量
引入长期增长（1973）——"经济学理论与量化方法"全面接管历史档案，
1993 年 Fogel-North 同获诺奖。中国线：梁方仲、吴承明的明代财政与
市场研究开创中文计量经济史传统。

## 核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 铁路对美国 19 世纪增长是否不可或缺 | ✅ Fogel 1964 | 社会储蓄≈GDP 的 4% 左右——"不可缺"是神话 |
| 大萧条为何如此深久 | ✅ 主要归因成熟 | 货币收缩（Friedman-Schwartz 1963）+金本位传染（Eichengreen 1992） |
| 工业革命为何发生在英国 | 🔄 持续争论 | 高工资+廉价煤（Allen）vs 制度（North/Acemoglu）vs 生态分流（Pomeranz） |
| 马尔萨斯陷阱为何被打破 | 🔄 持续争论 | 1800 年前人均收入几乎不动是常态，突破是例外——为什么是那时那地 |
| 长期不平等的形状 | 🔄 前线 | Piketty 资本收入比 U 型曲线引发全球数据工程 |

## 假设与依赖

本学科站在三条假设上：①过去可量化（物价、人口、产出可重建——
代价：越早的数据建构成分越大，"数据"其实是"估计的模型"）；
②反事实可用但须限定（Fogel 的"无铁路美国"不是科幻，是带误差棒的
计算）③跨国跨期可比（口径换算 PPP/白银/工时，每一步都是研究本身）。

## 教材锚

- Maddison《世界经济千年史》——千年 GDP 表是本学科的"元素周期表"
- Pomeranz《大分流》、Allen《近代英国工业革命揭秘》
- Cameron-Neal《世界经济简史》；Fogel-Engerman《苦难的时代》
- 中线：吴承明《中国的现代化：市场与社会》、李伯重《江南的早期工业化》
