# 讲透世界经济史 · 工业革命、大分流与两波全球化

> 支：[讲透经济史](../README.md) 自定主干支。英国车间到世界工厂——
> 世界经济格局两百年重构的档案。

## 定位句

本支负责**世界范围的长期经济史**：工业革命（1760-1870）、大分流
（1870-1914 第一波全球化与西方崛起）、危机世纪（1914-1973 战争、
大萧条与管制）、全球化第二波（1973-）——以跨国比较为主轴。

## 诞生与关键事件

- 1760s-1830s 英国工业革命：人均增长破千年陷阱
- 1870-1914 第一波全球化：金本位+轮船+电报，全球贸易/GDP 达
  1913 峰值（直到 1990s 才被超越）
- 1929-33 大萧条：产出跌 1/4、通缩 1/4、失业 1/4 的"三个四分之一"
- 1944 布雷顿森林；1950s-60s 黄金时代（西欧日本高速增长）
- 1973 布雷顿森林终结+石油危机：增长放缓、全球化第二波启幕

## 这支最美的一个事实（一句）

1913 年的全球贸易/GDP 比值直到 1990 年代才被重新追平——
全球化的"退潮-回涨"走了整整 80 年，比任何人的职业生涯都长。
