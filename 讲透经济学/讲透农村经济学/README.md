## 一、诞生

1. **1954 刘易斯《劳动无限供给下的经济发展》**——二元经济
   模型开山：传统部门边际生产率近零、现代部门以生存工资
   无限吸纳劳动——**"农村问题"第一次被建模为结构问题**
   （拉尼斯-费景汉 1961、乔根森 1961 补全谱系）。
2. **1964 舒尔茨《改造传统农业》**——反向一击："传统农业
   贫穷但有效"，问题不在农民愚昧而在要素停滞——
   投资新要素（知识/技术）才能起飞。刘易斯 vs 舒尔茨
   构成本学科的第一场范式之争。
3. **中国现场（1978- ）**——家庭联产承包（1978 小岗村）→
   乡镇企业异军突起（1980s）→农民工大潮（1990s-2000s，
   全球最大规模劳动力转移）→脱贫攻坚（2013-2020）→
   乡村振兴（2017-）。**中国是二元经济理论最大的实验室**，
   也是它最大的挑战者（制度双轨的复杂度超出模型）。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 劳动力转移的机制 | ✅ 1954-61 已建模 | 刘易斯-拉尼斯-费：无限供给→拐点→工资上涨（本家族实验） |
| 传统农业为何停滞 | ✅ 1964 已答 | 舒尔茨：有效但要素投入停滞——改造靠新要素供给 |
| 托达罗之问：迁移为什么导致城市失业 | ✅ 1969 已答 | 预期收入差（非实际差）驱动迁移——农村的隐蔽失业换城市公开失业 |
| 刘易斯拐点之争（中国） | 🔄 活争论 | 蔡昉"2004-2010 已过拐点" vs 质疑派——参数之争（实验 §D） |
| 农地制度与效率 | 🔄 前线 | 三权分置/规模经营/地权稳定性投资的实证 |
| 乡村振兴的产业逻辑 | 🔄 政策前线 | 县域经济/新业态能否逆转"要素净流出"的引力 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 部门可二分（传统/现代） | 模型极简有力 | 现实是连续谱（乡镇企业/县域经济在两部门之间） |
| 传统部门有剩余劳动（MPL≈0） | 无限供给段成立 | 舒尔茨反驳：农民会按边际效率配置——剩多少余粮是实证题 |
| 劳动可自由转移 | 转移机制清晰 | 户籍/土地/社保把模型锁在制度里——中国修正项 |
| 城市现代部门充分扩张 | 吸纳没问题 | 托达罗：城市失业证明吸纳本身有摩擦 |
