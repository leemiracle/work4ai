# 讲透农户与二元经济 · 理论核：小农的经济学

> **定位**：这支负责本家族的理论核——农户行为理论
> （恰亚诺夫/舒尔茨/新家庭经济学）与二元经济理论
> 的完整谱系。GB/T 79057 三级列表偏宏观与区域，
> 缺微观行为层——**自定主干支**（补理论核）。

## 诞生

恰亚诺夫（1920s，家庭农场的劳动-消费均衡与"自我剥削"）
vs 舒尔茨（1964，"贫穷而有效"的理性小农）——两大小农
理论隔空对话；贝克尔新家庭经济学（1965，家庭生产函数）
把农户的 生产-消费-生育 统一建模；波普金《理性的小农》
（1979）与斯科特《小农的道义经济》（1976，"安全第一的
生存伦理"）延伸出著名的"理性-道义"之争。

## 核心问题（3-5 条）

- ✅ 已解：农户=生产单位+消费单位的统一模型
  （separability：市场完备时生产与消费决策可分离）
- ✅ 已解：自我剥削机制（无可替代的劳动供给压低隐含工资）
- 🔄 前线：不可分离性的检验——信贷/土地/劳动市场不完备时
  生产决策被自家消费扭曲
- 🔄 前线：风险与保险缺位下的技术采纳迟滞（安全第一的现代版）
- ❌ 未解：小农 vs 雇工农场的选择条件（组织经济学未竟题）

## ✨这支最美的一个事实

"农户模型"教给整个微观经济学一个概念：**可分离性**——
市场完备时生产与消费决策可分开研究（先利润最大化、
再效用最大化）；信贷或劳动市场不完备时两者焊死
（投入选择取决于家里几张嘴）。**市场完备性这一个开关，
决定能不能用"厂商理论"研究农民**——市场失灵思想
最生动的一课。

## 假设与依赖

家庭是可建模的决策单元（内部决策黑箱——家庭内部
性别/代际分配被舍象， feminist economics 的批评口）；
效用函数存在（恰亚诺夫的辛苦-消费权衡是其特殊形式）；
依赖[讲透微观经济学](../../讲透微观经济学/)的
家庭理论与[讲透劳动经济学](../../讲透劳动经济学/)的
劳动供给件。
