# 讲透农村宏观经济学 · 城乡结构的总量账

> **定位**：这支负责 GB/T 79057 三级"农村宏观经济学"——
> 城乡结构变迁的总量分析：劳动力转移、城乡收入分配、
> 农村要素市场的宏观面。家族层 00/03 章的刘易斯机器
> 即本支的核心模型层。**GB/T 三级**（非自定）。

## 诞生

刘易斯（1954）-拉尼斯-费景汉（1961）-乔根森（1961）
建起二元经济的宏观骨架；托达罗（1969）补迁移的
预期机制。中国是其最大实验场：1978-2020s 人类
史上最大规模的劳动力转移（数亿人），2013-2020
脱贫攻坚消除绝对贫困——结构模型在此被反复检验
与修正（户籍摩擦、土地制度成为标配修正项）。

## 核心问题（3-5 条）

- ✅ 已解：转移三阶段与拐点的机制（闭式可解）
- ✅ 已解：城乡收入差距的倒 U 假说及其中国检验
- 🔄 前线：刘易斯拐点之争的人口结构版（剩余劳动的年龄质量折扣）
- 🔄 前线：人口红利消失后增长引擎的切换（劳动数量→人力资本）
- ❌ 未解：城乡收入差距收敛的终局速度（2.5:1 之后的路径）

## ✨这支最美的一个事实

刘易斯模型预言：拐点前资本积累的果实几乎全归资本
（工资钉死）——"增长的分配"不是道德选择而是供给
曲线形状的结果。中国工资性收入占比在 2010 年代
的抬升，恰与"民工荒"同步——**一张劳动供给曲线
的折点，在三十年宏观数据里留下了脚印**。

## 假设与依赖

二元结构（部门可分）；生存工资制度给定；
劳动可转移（摩擦为修正项）——依赖家族层全部；
数据层依赖人口普查与劳动力调查（口径学敏感区）。
