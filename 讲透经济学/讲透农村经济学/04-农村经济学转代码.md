# 04 · 农村经济学转代码：结构变迁的沙盘

> **本章回答五问之五（本家族：讲透农村经济学）。**
> 三件套：**可机械化边界 → 代码走廊 → 工程师落点**。
> 核心判断一句话：本家族的转代码主角是**结构变迁沙盘**
> （二元经济模拟）与**政策评估流水线**（确权/转移/补贴
  的准实验分析）——前者小而深，后者是数据工程。

---

## 一、可机械化边界

| 环节 | 可机械化 | 形态 |
|------|---------|------|
| 刘易斯转移模拟（含拐点闭式解） | ✅ | 60 行（本家族实验） |
| 托达罗迁移均衡 | ✅ | 联立方程求解 |
| 家庭农场配置（恰亚诺夫式） | ✅ | 效用最大化数值解 |
| 县域/村庄数据的口径衔接 | 🟡 | 脚本可写，口径决策靠人（02 章的统计层） |
| 确权/补贴政策的效果估计 | ✅ | DID/断点——准实验工具链（与劳动家族共用走廊③） |
| 城乡 CGE（一般均衡） | 🟡 | 可算，校准即命运 |
| 乡村振兴的"效果"外推 | ❌ | 多目标（五个振兴）无单一度量——政策学领地 |

## 二、代码走廊

### 走廊①：二元经济沙盘（本家族实验）

```python
# 闭式拐点：K* = (w̄·L_max^α/(1-α))^(1/α)   （断言 MPL(K*,L_max)==w̄）
# 迭代：L = min(((1-α)K^α/w̄)^(1/α), L_max)；K ← K + s·利润 - δK
# 断言三连：拐点前工资恒 w̄ / 拐点后工资严格递增 / Ks[t*] 跨过 K* 恰在换挡期
# 政策臂：s↑ → 拐点提前（0.8 vs 0.3：14 期 vs 41 期）
```

沙盘的用法（与[讲透劳动经济学/04](../讲透劳动经济学/04-劳动经济学转代码.md)
的判词一致）：**不当水晶球，当测谎仪**——
"人口红利还有十年"的判断隐含了哪组 (w̄, L_max, s)，
沙盘三分钟逼它报数。

### 走廊②：转移与迁移的核算

普查/抽样微观数据 → 农村-城镇人口矩阵（年龄×教育×
迁移状态）→ 转移存量/流量核算 → 剩余劳动的
年龄质量折扣估计（刘易斯拐点之争的核心数字）。
工程要点：口径衔接（常住/户籍/人户分离三层统计）——
"城镇化率"的一个百分点里有多少是口径制造的，
是这段代码最伤人也最值钱的部分。

### 走廊③：政策评估流水线

确权试点/电商进村示范县/补贴发放清单 → 政策断点或
试点批次 → DID/合成控制 → 效果与异质性。
数据工程占九成（村级面板的匹配清洗），识别策略
是学术含量所在（试点非随机——配额分配规则本身
可作为识别来源）。

## 三、工程师落点

| 场景 | 落点 | 备注 |
|------|------|------|
| 农业农村部门/政策智库 | 监测预警（收入/转移/防返贫监测） | 行政数据的体系化消费方 |
| 县域规划咨询 | 人口与产业预测、村庄布局规划 | 结构沙盘的真实买家 |
| 农业保险与金融科技 | 天气指数保险、信贷风控 | 与[讲透农业经济学](../讲透农业经济学/) 04 章共用 |
| 平台农业（电商/供应链） | 产销匹配、价格监测 | 数字乡村的产业侧 |

**诚实判词**：本家族没有独立成型的"农村经济学工程师"
职业——工程岗位寄生在统计机构、智库、农险与平台上；
**可迁移单品是准实验评估工具链与县域数据工程**，
与劳动家族、城市家族的对应件同构（三家的 04 章
可以互相换工作）。

## 四、反直觉发现（⑥）

**最好的农村数据不在"农村"系统里。**
测算转移劳动力的真实规模，教育部的学籍流（子女随迁）
、人社部的社保参保地、平台的骑手注册地，都更准
农村劳动力转移——**结构变迁的真相分散在各部委
与平台的业务系统里**，学科数据的最大工程不是收集
而是拼接（口径学因此成为本家族 02 章的一等公民）。

## 五、✨美之时刻（⑧要件）：把一场国策争论装进一行断言

**陈述**：`assert Ks[t_turn] >= K_star > Ks[t_turn-1]`——
刘易斯拐点（四十年的发展经济学争论、上千篇论文、
无数政策报告）在代码里坍缩成一条括住闭式解的
不等式断言：换挡恰在跨过 K* 的那一步。

**为什么美**：*统一*——争论的双方（拐点已过/未过）
其实在争同一个 K* 与同一条 K 轨迹的相对位置；
断言把"观点之争"翻译成"参数之争"——这是发展经济学
作为实证科学成熟的那一刻（模型共用、分歧数据化）。

**怎么亲历**：跑实验，把 w̄（生存工资/最低生活成本）
上调 20%——看 K* 怎么变、拐点怎么推迟；
再想想现实中"新农合+低保"的抬升是否正是这个参数的
政策操作——你在用旋钮理解国策。
