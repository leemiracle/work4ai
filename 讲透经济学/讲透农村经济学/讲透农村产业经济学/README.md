# 讲透农村产业经济学 · 离土不离乡的产业史

> **定位**：这支负责 GB/T 79057 三级"农村产业经济学"——
> 乡村的产业组织：从乡镇企业到县域经济、再到电商与
> 新业态。核心问题：**产业能否（以及何种）在农村长出来**——
> 这是"要素回流"的产业面。**GB/T 三级**（非自定）。

## 诞生

1980s 乡镇企业"异军突起"（费孝通"离土不离乡"的概括）——
计划体制外的工业化，一度"三分天下有其一"；
1990s 后改制与分化（苏南模式/温州模式的路径之争）；
2000s 农民工大潮取代就地工业化（"离土又离乡"）；
2010s- 产业回流的新形态：电商村（淘宝村现象）、
县域产业带、乡村文旅——**产业形态换了三轮，
理论问题（农村能不能长工业）没换**。

## 核心问题（3-5 条）

- ✅ 已解：乡镇企业的体制解释（社区政府公司主义——
  行政资源与市场活力的杂交形态）
- ✅ 已解：电商村的空间爆发机制（平台降低进入门槛的
  集聚效应）
- 🔄 前线：县域产业带的升级路径（成本洼地→集群→品牌）
- 🔄 前线：乡村文旅的可持续性（流量型业态的收入天花板）
- ❌ 未解：农村产业的"天花板"由什么决定（集聚经济的
  乡村版本是否存在规模收益）

## ✨这支最美的一个事实

淘宝村从 2009 年的 3 个涨到数千个——同一套平台
基础设施复制出千百个专业村（家具/化妆品/农产品各霸
一村）："一村一品"这个 1980s 日本大分县的政策口号，
被中国电商平台用算法流量**自动化执行**了——
产业政策的目标被基础设施顺手实现。

## 假设与依赖

产业区位由要素成本与集聚力博弈（依赖[讲透城市经济学]
的集聚理论——乡村版本的集聚收益远小，但进入门槛
也低）；平台基础设施外生给定；劳动力兼业供给
（农忙务农、农闲进厂）是乡村产业特有的弹性。

## 教材锚

- 费孝通《乡土中国》《小城镇大问题》（乡镇企业的
  理论化石层）

  ——数据密集的当代记录）
