# 讲透农村区域经济学 · 村庄、县城与国土的格局

> **定位**：这支负责 GB/T 79057 三级"农村区域经济学"——
> 乡村的空间结构：村庄分布、县域格局、城乡体系与
> 国土空间的农村面。核心问题：**人往哪里去、村往哪里
> 去**——空间规划与结构变迁的对表。**GB/T 三级**（非自定）。

## 诞生

两支汇流：德国区位论传统（杜能/克里斯塔勒的中心地
理论——集市与城镇层级的空间几何）与中国实践
（2000s 后的社会主义新农村建设→2010s 的村庄布局规划
→县域城镇化政策（2022《关于推进以县城为重要载体的
城镇化建设的意见》））。施坚雅的基层市场共同体
（家族 02 章✨）是这支最漂亮的理论遗产：**市场层级
=社会层级=空间层级**三位一体。

## 核心问题（3-5 条）

- ✅ 已解：中心地/集镇层级的空间几何（六边形市场区）
- ✅ 已解：村庄规模-服务配置的基本权衡（学校/卫生室的门槛人口）
- 🔄 前线：村庄撤并与保留的边界（什么样的村该"消亡"——
  规划理性与乡土价值的冲突）
- 🔄 前线：县城承载力的真实边界（人口-产业-公共服务
  能否在县城闭环）
- ❌ 未解：中国乡村聚落格局的终局形态（城镇化率天花板
  与村庄数量的均衡）

## ✨这支最美的一个事实

克里斯塔勒 1933 年推导中心地体系：只要服务有门槛人口
（小学/医院/百货的最低客源），市场区就自动叠成
六边形的层级嵌套——**集镇的分布不是历史偶然，
是服务门槛的几何投影**。今天打开任何县地图数一数
初中与高中的选址，六边形的幽灵仍在。

## 假设与依赖

空间均质假设（地形/制度修正后近似成立）；
人口分布可规划引导（中国特有的强规划变量——
"合村并居"的争议正是该假设的政治重量）；
依赖[讲透城市经济学](../../讲透城市经济学/)的
竞租与集聚件（乡村版参数不同、结构同源）。
