# 讲透资源经济学 · 时间维度上的稀缺定价

> 资源经济学：**给"早晚要用完/用不掉"的东西定价**——同样一吨油，
> 今天挖还是十年后挖，差价不是成本，是**利率**。本家族把"时间"装进价格：
> 可耗竭资源的租值路径、可再生资源的收获纪律、产权制度如何决定资源命运。
> GB/T 13745 二级学科 79049（资源经济学，无三级明细——三支均自定主干支）。

## 定位声明（本家族怎么读）

微观经济学（并行建族）讲一个市场、一个时点；
本家族讲**跨时市场**：资源是存量（stock），开采是流量（flow），
今天的每一铲都在给未来定价——定价的锚是利率与承载力，不是当期成本。
真实政策争吵（关键矿产价格暴烈、石油峰值预测分裂、渔业崩溃）全都是本家族的现场。

## 诞生（三个原生问题）

| 问题 | 年代 | 结局 |
|---|---|---|
| 英国煤炭会耗竭吗？工业增长要停吗 | 1865 | Jevons《煤炭问题》：耗竭方向对、机制错——替代与效率让"储量"变成经济学变量 |
| 均衡市场里，耗竭性资源的价格路径长什么样 | 1931 | Hotelling 法则：净价格（租）以利率指数增长——论文沉睡 40 年，石油危机后成全领域地基 |
| 公海渔场为什么必然过度捕捞 | 1954→1968 | Gordon 开放进入模型 + Hardin《公地悲剧》：无产权→租值消散为零 |

## 核心问题清单（详 00 章）

已解决里程碑：Hotelling 路径（1931）· 公地悲剧形式化（Gordon 1954/Hardin 1968）·
MSY=增长曲线顶点（logistic 渔业）· 资源诅咒经验确认（Sachs–Warner 1995）·
公共池资源自主治理可行（Ostrom 1990，2009 诺奖）。
悬而未决：石油/关键矿产需求峰值时点（OPEC 与 IEA 预测分裂）· 关键矿产中游垄断的治理 ·
深海与太空资源产权 · 绿色悖论的政策反制。

## 假设与代价

本家族假设：**资源可以折算成一条跨时价格路径**。买到定价基准（利率、承载力两个锚）；
付出"制度失格即崩溃"（产权或配额错配，鳕鱼产业 500 年历史 5 年终结）。
