# 03 · 可构造与结构：从两期套利到崩溃三分图

> **本章回答五问之四：这门学科的可构造内核是什么——最小模型怎么搭，结构定理说什么。**
> 一句话：全部骨架是**一个约束下的跨期最优化**——
> 两期手算见套利，T 期微分方程见路径，可再生版加一个增长率函数见崩溃。

---

## 一、最小构造：两期模型（手算级）

**构件**（三个符号搭起整个家族）：
存量 S=1，两期需求 p(q)=a−bq（取 a=2, b=1），利率 r=10%，开采成本 0。

**问题**：q₁+q₂=1，max p(q₁)q₁ + p(q₂)q₂/(1+r)。

**一阶条件**（拉格朗日，λ=影子价格）：
2−2q₁ = λ = (2−2q₂)/(1+r) → q₁ = (2−λ)/2, q₂ = (2−λ(1+r))/2。
代入约束解出 λ ≈ 0.524，q₁ ≈ 0.738 > q₂ ≈ 0.262。

**读出来的三件事**：
1. **影子价格 λ>0**：存量的存在本身值钱——这就是"地下银行"的利率单；
2. **前载路径**：q₁>q₂，开采量逐期递减（存量稀释）；
3. **租在涨**：p₁=1.262 < p₂=1.738，且 p₂/p₁−1 = r。两期模型五分钟算完，
   Hotelling 法则的三个面（λ、路径、租增长）全部现形。

## 二、结构定理一：Hotelling 路径的存在与唯一（可耗竭支）

**定理（Hotelling 1931，离散叙述）**：需求 Q(p) 连续递减、存量 S、利率 r、
后备技术价 p_b > 开采成本，则竞争均衡价格路径存在且唯一：
p_t = p₀(1+r)^t，其中 p₀ 由"存量恰在价格触及 p_b 的那一期耗尽"反解。

三个构件缺一不可：
- **存量约束** Σq_t = S（资源不灭不生）→ 给出 λ>0；
- **跨时套利** p_{t+1}/p_t = 1+r（无套利）→ 给出路径形状；
- **横截性条件** p_T = p_b 且剩余=0（终点不剩也不亏）→ 钉死 p₀。

闭式化简（美之时刻，见 §五）：线性需求 q=a−p 时累计开采
= aT − (p_b−p₀)/r，其中 T = ln(p_b/p₀)/ln(1+r)——
**整条产业命运压缩进两个参数**（利率、后备价）。
可跑实现：[`experiments/hotelling.py`](experiments/hotelling.py)（二分法解 p₀≈31，
本家族 04 章走廊①）。

**结构性质**（政策计的账）：
- 利率↑ → p₀↓、T↓、开采前载（高利率对未来打折，挖得急）；
- 后备价 p_b↓（替代技术预期变便宜）→ T↓、早期开采↑——绿色悖论的机制核。

## 三、结构定理二：logistic 三分图（可再生支）

**模型**：存量 X，增长 F(X)=rX(1−X/K)，恒定收获 H。
均衡：F(X*)=H。三次态势由 H 与 F 的顶点 F(K/2)=rK/4 比较：

```
收获 H < rK/4  ：两个均衡——高存量稳定 ✓（好均衡）+ 低存量不稳定 ✗（崩溃门槛）
收获 H = rK/4  ：半稳定（MSY，刀锋）
收获 H > rK/4  ：无均衡 → 存量指数滑向 0 → 崩溃（鳕鱼剧本）
```

**反直觉发现（⑥要件）**：H 略低于 rK/4 时模型"有稳定均衡"，但若存量被随机冲击
压到不稳定均衡以下，收获率不变则**必然崩到零**——可持续的不是产量，是
"产量×存量位置"的组合。配额制度最致命的错配就是只锁产量不测存量。
加拿大鳕鱼 1992：持续收获逼近 rK/4 加上技术进步（声呐/拖网=努力量隐性上升），
把系统推过刀锋。数值复现见近亲 [生态经济学](../讲透生态经济学/)（MSY 实验）
与本家族 [04 章走廊②](04-资源经济学转代码.md)。

## 四、统一视角：资源=一种资本（结构性终章）

三个支在资本理论里是同一个对象的三种参数化：

| 支 | 资本方程 | "折旧" | "自增殖" |
|---|---|---|---|
| 可耗竭 | Ṡ = −q | 只出不进（折旧率 100% 的消耗性资本） | 0 |
| 可再生 | Ẋ = F(X) − H | 被 H 消耗 | F(X)（增长率函数） |
| 产权支 | 制度决定 F 与 H 由谁控制 | 租值消散=制度折旧 | Ostrom 型治理=制度增殖 |

**桥**：Solow 1974 与 Hartwick 1977 把"资源租"接到资本积累——
**把可耗竭资源的租全部转投人造资本，消费可以跨代恒定**（Hartwick 准则）。
这一条桥把本家族与 [可持续发展经济学](../讲透可持续发展经济学/) 焊死：
弱可持续（资本可替代）派与强可持续（自然资本不可替代）派的百年之争，
数学上就是问 F(X) 里的 K 与人造资本的替代弹性是否=1。
可跑实现：可持续发展家族的 Hartwick 实验（近亲互链）。

## 五、✨美之时刻（⑧要件）：两个对称的 rK/4 与一行闭式

**陈述一（可再生）**：logistic 增长 F(X)=rX(1−X/K) 是 X 的二次函数，
配方即见顶点在 X=K/2，顶高 **rK/4**——最大可持续收获不用微积分，
对称轴一条就看穿：**可持续产量的上限=增长曲线自己的顶**。

**陈述二（可耗竭）**：累计开采闭式 aT−(p_b−p₀)/r 中，几何级数 Σp₀(1+r)^t
利用终点条件 (1+r)^T = p_b/p₀ **整体坍缩为 (p_b−p₀)/r**——
一条 40 年开采路径的总账，化简到只有两个外生参数（利率、后备价）做主。

**为什么美**：*意外*——两个支各藏一次"复杂消失术"：二次函数的对称性、
几何级数的首尾相消；*统一*——都在说同一句话：**时间维度可以被两个参数全部打包**。

**怎么亲历**：对 §三 在纸上画 F(X) 抛物线，把 H 画成水平线，移动它看三分图；
对 §二 跑 [hotelling.py](experiments/hotelling.py) 断言 B，看二分法把 p₀ 钉到
闭式的预测值上。
