# 04 · 资源经济学转代码：把时间之尺写进脚本

> **本章回答五问之五：这套思维怎么落成可跑的代码。**
> 一句话：**路径可算，制度不可算**——Hotelling 与 logistic 都是十几行差分/代数方程，
> 难的从来不是数值，而是给方程喂数据的那部分现实。

---

## 一、可机械化边界（先划清楚）

| 环节 | 可机械化 | 为什么 |
|---|---|---|
| 竞争均衡价格路径（给定 r、p_b、S） | ✅ 完全 | 闭式+一元求根（本家族实验） |
| 比较静态（r↑/p_b↓ 的政策情景） | ✅ 完全 | 对参数重跑一遍 |
| 存量动态与崩溃阈值（logistic） | ✅ 完全 | 差分迭代三行 |
| 需求/存量**参数估计** | ⚠️ 半 | 数据噪声大；峰值预期不可直接观测 |
| 卡特尔行为、产权制度演化 | ❌ | 制度与博弈：只能建仿真场景，无唯一解（→[讲透博弈论](../../讲透数学/讲透博弈论/)） |

边界本身就是本家族的教导：**OPEC 与 IEA 的峰值预测分裂，不是算力差距，
是"预期"这个参数无法从数据里直接读出**——模型再精，喂进去的世界观决定输出。

## 二、走廊①：hotelling.py——本家族实验逐断言拆解

（源码 [`experiments/hotelling.py`](experiments/hotelling.py)，对应 [03 章](03-可构造与结构.md) §二）

设定：线性需求 q=100−p，存量 S=600，利率 r=5%，后备价 p_b=50。
闭式总开采 C(p₀)=100T−(p_b−p₀)/r，T=ln(p_b/p₀)/ln(1+r)，二分法解 C(p₀)=600。

| 断言 | 内容 | 数值结果（实测） |
|---|---|---|
| A | 价格路径逐期恰以 1.05 复利，单调无跳 | 比值全为 1.05（容差 1e−12） |
| B | 切换点 p_T=p_b 且存量恰耗尽 | p₀≈30.99，T≈9.8，闭式残差 <1e−6 |
| C | r=10%：p₀ 更低、T 更短、开采前载 | p₀≈21.5，T≈8.8，前半窗口占比 53.8%→54.9% |
| D | p_b 50→40（绿色悖论）：切换提前、固定窗内早期开采加速 | T≈8.8，前 4 期累计 266→288 |

**代码模式三件**（拿走复用）：
1. **实数 T 延拓**——几何级数闭式对非整数 T 直接用，避开整数期跳变；
2. **二分法优于牛顿**——C(p₀) 单调光滑但导数在终点附近怪，二分稳；
3. **两条时间线分开报**——闭式解（精确）与整数期模拟（可解释）并排打印，
   差额=最后一期的部分装载，物理含义自明。

## 三、走廊②：渔业 logistic——七行核心的崩溃模拟

```python
def fish(X, H, r=0.4, K=10_000, years=60):
    path = [X]
    for _ in range(years):
        X = max(0.0, X + r*X*(1 - X/K) - H)   # 一行增长，一行收获
        path.append(X)
    return path
```

三个情景各一行参数：H=800（<rK/4=1000，稳定）；H=1000（刀锋）；
H=1200（崩溃，鳕鱼剧本）。加上努力量模型（H=qEX，成本 cE）即得
MEY/MSY/开放进入三点比较——完整版在近亲 [生态经济学](../讲透生态经济学/)，
本家族支占位 [讲透可再生资源经济](讲透可再生资源经济/) 有推导指针。
工程要点：崩溃情景必须 max(0,·) 截断，否则数值变负后 logistic 项翻转，
会"数值复活"——一个能骗过抽查的 bug。

## 四、走廊③：真实数据——给方程喂世界

| 数据源 | 用途 | 接口 |
|---|---|---|
| Our World in Data（光伏价格/装机序列） | 学习曲线拟合后备价 p_b 的动态（→[技术经济学](../讲透技术经济学/)实验同源） | CSV 直读，无注册 |
| USGS《Mineral Commodity Summaries》（年度） | 储量-价格联动（"储量是经济学变量"的一手证据） | 年鉴 PDF/CSV |
| IEA《Global Critical Minerals Outlook》 | 供需集中度、价格周期 | 年度报告 |
| OPEC WOO vs IEA WEO | 峰值预测分裂的原始文本 | 年度报告 |

最小练习（半天级）：取 OWID 光伏组件价格与累计装机，对数回归
ln(cost)=ln(a)−b·ln(cum)：b≈0.32 → 学习率 1−2^(−b)≈20%/倍增。
这就是"后备技术价格为什么会自己下降"的实证版，
与 [技术经济学](../讲透技术经济学/) 的实验共用同一条数据走廊。

## 五、工程师落点（这门课在哪些工位上挣钱）

- **矿山/油气投资**：折现现金流（DCF）+期权溢价——储量是实物期权，
  价格路径模型给期权定价（Hotelling 路径是分红资产的底稿）；
- **电网与电池储能规划**：关键矿物价格情景×技术学习曲线双蒙特卡洛，
  输出 LCOE 分布（锂价 −80% 与 +800% 都要在情景库里）；
- **碳预算核算**：把剩余碳预算当存量 S、碳价当 p_t——
  Hotelling 框架直接迁移（[环境经济学](../讲透环境经济学/)与
  [可持续发展经济学](../讲透可持续发展经济学/)的实验走廊）；
- **供应链压力测试**：集中度指标（HHI）+ 断供情景 → 库存与替代弹性决策。

## 六、✨美之时刻（⑧要件）：二分法的一声"咔哒"

**陈述**：hotelling.py 里二分循环 60 次后，闭式残差从 |C(p₀)−600|≈600 收敛到 1e−10 以下
——初始价 p₀ 被唯一钉死，整条 10 期价格路径、切换时点、耗尽时刻同时就位。

**为什么美**：*必然*——这不是数值巧合，是结构定理（[03 章](03-可构造与结构.md) §二
"存在且唯一"）在机器上的兑现；数学说解只有一个，算法就一定收敛到它。

**怎么亲历**：把 r 改成 0.07、p_b 改成 60，先手算估 T，再跑脚本对答案——
你会开始用 Hotelling 的眼睛看新闻里的矿价。
