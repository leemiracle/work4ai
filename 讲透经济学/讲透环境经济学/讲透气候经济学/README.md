# 讲透气候经济学 · 把一个世纪装进一个模型

> **定位**：这支负责气候变化的经济工程学——综合评估模型（IAM）、
> 社会成本碳（SCC）、贴现伦理与剩余碳预算；环境经济学的工具箱
> 在这里面对时间尺度最长、不确定性最深的问题（自定主干支，GB/T 79051 无明细）。

## 诞生

Nordhaus 1975-1992 构建 DICE 模型（碳循环+经济+气候+损伤四模块），
2018 年获诺奖"把气候变化纳入长期宏观经济分析"；2006 年 Stern 报告
以低贴现率得出"立即强力减排"，与 Nordhaus"先发展后治理"针锋相对——
贴现率之战成为本支的立身之问；2015 年《巴黎协定》后碳预算
（1.5°C 对应剩余排放量）成为数量工具的最大应用。

## 核心问题（3-5 条）

- ✅ 已解：IAM 四模块框架（排放→气候→损伤→福利）成为政策分析标准机
- ✅ 已解：SCC 概念与 EPA/世界银行官方估值流程（$51→$190 的 2023 重估）
- 🔄 前线：损伤函数计量（温度-增长 vs 温度-水平之争，结果差数倍）
- 🔄 前线：深度不确定性（ tipping points、灾变尾部）下的稳健政策 vs 期望效用最优
- ❌ 未解：贴现伦理——ρ 是伦理选择（Stern）还是市场读数（Nordhaus），
  同一模型两套参数给两个文明级的政策结论

## ✨这支最美的一个事实

$100 的百年后损害：贴现率 1.4% 时现值 $24.7，3% 时 $5.2，5% 时 $0.76——
**一个参数，四个数量级**。全球气候政策的天平，支点是一条指数曲线（家族 03 章✨）。

## 假设与依赖

全球可加总的福利函数；指数贴现可代表跨代权衡（争议中心）；损伤函数可外推
（2°C 之外的数据几乎为零——本支最大的经验窟窿）。

## 教材锚

- Nordhaus《The Climate Casino》（DICE 世界观的可读版）；Hanley 等（应用工具部分）
