# 讲透外部性与政策工具 · 把环境损害塞回价格的三种办法

> **定位**：这支负责外部性理论的政策工程学——庇古税、科斯产权谈判、
> 总量帽与交易三大工具的设计、等价条件与失效边界（自定主干支，GB/T 79051 无明细）。

## 诞生

庇古 1920 年对外部损害开税；科斯 1960 年证明零交易成本下产权谈判可替代税；
Dales 1968 年提出政府只定总量、市场发现价格；Weitzman 1974 年给出
"价格工具 vs 数量工具"的不确定性分岔定理；1990 年美国 SO₂ 酸雨计划首次大规模落地。

## 核心问题（3-5 条）

- ✅ 已解：庇古税=最优边际损害；科斯定理（初始分配不影响效率，当且仅当交易成本为零）
- ✅ 已解：Weitzman 分岔——边际损害曲线陡（存量污染物）偏数量工具，边际成本不确定偏价格工具
- ✅ 已解：美国酸雨计划实证——市场型工具成本约为命令控制预期的一半
- 🔄 前线：碳价下限/价格走廊设计（EU ETS 改革）；混合工具（帽+地板价+天花板价）
- ❌ 未解：政治可行性如何进入工具设计（IRA 补贴路线对"次优理论"的挑战）

## ✨这支最美的一个事实

本家族实验里，税 96、科斯谈判、许可出清价 96 **是同一个数字从三条路自己长出来**——
1920/1960/1968 三代人在不同政治哲学里各自发明，最后在一条边际曲线上握手。

## 假设与依赖

凸性（单峰边际曲线→唯一最优）；MD/MAC 可估；代际工具（碳预算）需配贴现理论
（[家族 03 章](../03-可构造与结构.md)）。
