# 讲透环境经济学 · 给没有价格的东西定价

> 环境经济学：**外部性的价格修复学**——市场遗漏的环境成本，用税、产权、
> 总量帽三种方式塞回价格体系。GB/T 13745 二级学科 79051；
> 理论血统：庇古（1920）→ 科斯（1960）→ Dales（1968）→ Weitzman（1974）→ Nordhaus（2018 诺奖）。

## 定位声明（本家族怎么读）

部门经济学多为"领域×基本工具"；本家族是**部门经济中的理论高地**——
它不研究某个部门，研究**市场失灵本身**，再把修复工具卖回所有部门
（碳市场、水权、渔权、排污许可全是它的作品）。

## 诞生（三个原生问题）

| 问题 | 人物 | 结局 |
|---|---|---|
| 熏烟的工厂该不该赔？ | 庇古《福利经济学》1920 | 庇古税：对边际外部损害征税 |
| 限制污染不也损害企业吗？ | 科斯《社会成本问题》1960 | 产权+谈判可以替代管制（零交易成本下） |
| 政府算不出每条河的价 | Dales 1968 | 只管总量、市场发现价格 → 全球碳市场体系 |

## 核心问题清单（详 00 章）

已解决：庇古税 · 科斯定理 · Weitzman 价格 vs 数量（1974）· 美国 SO₂ 酸雨计划（1990，成本减半）· DICE 框架（2018 诺奖）。
悬而未决：碳税 vs 碳市场 vs 补贴（IRA 路线）· SCC 的 $51→$190 之争 · CBAM 与 WTO 相容性 · 深度不确定下的工具选择。

## 假设与代价

本家族假设**环境损害可货币度量、边际分析有效**。买到政策可比性与市场化修复；
付出：多元价值被压缩、阈值与不可逆被平滑、价格工具对穷人的累退性（黄背心根源）。
