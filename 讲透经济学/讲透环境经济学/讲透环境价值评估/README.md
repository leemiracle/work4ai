# 讲透环境价值评估 · 逼问出没有价格的东西的价

> **定位**：这支负责"非市场估值"（non-market valuation）——
> 空气、风景、物种、健康风险都没有账面价，这支的全部手艺是
> 从人的真实选择或诚实回答里把价值逼问出来（自定主干支，GB/T 79051 无明细）。

## 诞生

Krueger-Knetch 1950s 问道"建坝的游憩价值是多少"，旅行成本法（Hotelling 提议）登场；
Davis 1963 首次条件价值法（CVM）问卷；Thaler-Rosen 1976 从工资-风险楔子读出
生命统计价值（VSL）；1989 年埃克森·瓦尔迪兹溢油案把 CVM 推上法庭，
催生 NOAA 蓝带小组（Arrow-Solow 主持，1993）给出 CVM 可信性规程。

## 核心问题（3-5 条）

- ✅ 已解：显示偏好三法（旅行成本/享乐定价/工资风险）的计量框架
- ✅ 已解：CVM 可信性规程（NOAA 1993：WTP 问法、校准检验、范围检验）
- 🔄 前线：选择实验（choice experiment）取代单点 CVM；生态等效性分析进赔偿法
- 🔄 前线：VSL 的年龄/收入/国别调整（监管影响分析的分配争论）
- ❌ 未解：范围不敏感（WTP 对"救 2000 只鸟 vs 20 万只鸟"几乎不变）——
  偏好建构 vs 偏好揭示，至今无解

## ✨这支最美的一个事实

没人直接回答过"一条命值多少钱"，但劳动力市场千万笔"加薪换风险"的交易
早已投票——回归一次工资单，VSL≈$7-13M 就自己浮出来（家族 02 章✨）。

## 假设与依赖

偏好存在且稳定（行为经济学持续侵蚀此假设：WTP≠WTA 的禀赋效应裂缝）；
统计外推有效（从微小风险外推到政策规模）。
