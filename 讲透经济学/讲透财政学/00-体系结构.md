# 00 · 体系结构：三职能与收支债三表

> **本章回答五问之一（本家族：讲透财政学）。**
> 财政学的大厦是一个**三层三表的城堡**：三职能（配置/分配/稳定，
> Musgrave 1959 定型）为经，收支债三表（税收·支出·公债）为纬。
> 五支就住在城堡的五个房间里。

---

## 一、一张地图：财政在干什么（直觉先行）

想象国家是一台巨大的取予机器：

```
 取（谁出钱）          予（钱去哪）            平（差额怎么办）
 税收（强制·无偿）    公共品（国防/路灯）      盈余 → 还债/储蓄
 收费（对价·有偿）    转移支付（养老金/低保）  赤字 → 发债/印钞
 公债（自愿·有偿）    补贴与税式支出          ─────────────
 公企利润            债务利息                国家资产负债表
```

**取予之间永远隔着两个市场失灵的深渊**：公共品（没人愿意为路灯单付钱）
与再分配（市场不管公平）。财政学的全部理论，就是在这两个深渊上修桥；
公共选择学派则研究桥本身什么时候塌（投票循环/利益集团/预算最大化）。

## 二、三职能与五房间（五支的地盘）

| 职能（Musgrave） | 内容 | 主要房间 |
|-----------------|------|---------|
| 配置 | 纠市场失灵：公共品/外溢/自然垄断 | [理论财政学](讲透理论财政学/) |
| 分配 | 再分配：税的累进+转移支付 | 理论+税务管理学 |
| 稳定 | 反周期：乘数/自动稳定器 | （与[讲透宏观经济学](../讲透宏观经济学/)共管） |
| —— | 思想与历史的纵深 | [财政思想史](讲透财政思想史/)/[财政史](讲透财政史/) |
| —— | 机器的操作手册 | [财政管理学](讲透财政管理学/)/[税务管理学](讲透税务管理学/) |

📖 **故事框**：1896 年瑞典人 Wicksell 提出：公共支出应与税收捆绑、
经**一致同意**批准——否则就是多数对少数的强制。他的论文在图书馆
睡了六十年，被 Buchanan 翻出（1962《同意的计算》），催生公共选择
学派（1986 诺奖）。**财政学最著名的"迟到的论文"**：正确的洞见
比学科建制早了两代人。

## 三、核心问题清单（③要件）

**已解决里程碑**：

| 年 | 里程碑 | 一句意义 |
|----|--------|---------|
| 1776 | 斯密四原则 | 财政从账房术变原则之学 |
| 1896 | Wicksell 一致同意 | 财政决策的政治经济学出厂 |
| 1927 | Ramsey 最优商品税 | 逆弹性法则（价格学同源） |
| 1936/1943 | 凯恩斯/Lerner 职能财政 | 赤字从罪恶变工具 |
| 1945 | Haavelmo 平衡预算乘数=1 | "加税花钱"恰为单位乘数（本家族实验） |
| 1954 | Samuelson 公共品条件 | 最优供给有公式，偏好显示无解 |
| 1959 | Musgrave 三职能 | 学科地图定型 |
| 1962/1971 | 公共选择/Mirrlees 最优所得税 | 政治与信息双维度革命 |
| 1994 | 中国分税制 | 央地财政关系的世纪重塑 |

**悬而未决**：公债的代际负担（r<g 的可持续性）· 数字经济税基
（利润在云上）· 全球最低税的执行博弈 · 地方债化解的路径 ·
财政规则与相机抉择的最优混合。

## 四、假设与代价（④要件）

| 假设 | 买到什么 | 付出什么 |
|------|---------|---------|
| 国家是单一决策者 | 三职能可分立可讨论 | 政治过程黑箱化（公共选择的补刀方向） |
| 偏好可观测（或可代理） | 最优税有闭式 | 避税与规避是"观测"的内生反应（Mirrlees 革命的核心） |
| 乘数结构稳定 | 政策可测算 | Regime 变则参数变（卢卡斯批判） |
| 税收行政可行 | 税制可设计 | 征管能力是硬约束——发展中国家的税制≠教科书税制 |

## 五、✨美之时刻（⑧要件）：Haavelmo 定理——1 的乘数

**陈述**：借债花 1 元（c=0.8）：产出最终 +5；**加税 1 元**再花 1 元：
产出恰好 **+1**（不多不少）。加税的紧缩（−4/5×5）与支出的扩张
（+5）相消，净剩 1。**为什么美**：*必然*——两条乘数的代数和恰为 1，
不依赖参数 c 的取值（c=0.8 只是把 5 与 −4 写具体）；"平衡预算不是
中性的"这一反直觉定理，在恒等式层面锁死。**怎么亲历**：本家族实验
[experiments/fiscal_multiplier.py](experiments/fiscal_multiplier.py)
C 部分——凯恩斯交叉迭代 100 步，看产出差收敛到 1.000000。

## 七、反直觉发现速览（⑥要件，详 02/03 章）

1. **法定纳税人≠实际纳税人**（弹性归宿，税单面纱）。
2. **加税花钱的乘数恰为 1**（Haavelmo）。
3. **最优税率对弹性收"逃逸税"**：τ*=1/(1+ε)（拉弗峰的闭式）。
4. **公共品越重要越没法收费**（偏好显示问题——最需要的价格最难问出）。

## 👁 认知升维（⑨要件）

**取予眼**：评估任何政策先画两张表——谁出钱（归宿）与谁受益
（转移），再把两表的**不同人**连起来看。政策的政治学在两表之间，
政策的经济学在两表之内。
