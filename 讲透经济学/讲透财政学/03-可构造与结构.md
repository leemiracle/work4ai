# 03 · 可构造与结构：乘数、拉弗与公共品条件

> **本章回答五问之四（本家族：讲透财政学）。**
> 财政学有四个高构造度结构：**凯恩斯交叉**（乘数的迭代构造）、
> **Haavelmo 恒等式**（平衡预算乘数=1）、**拉弗峰**（τ*=1/(1+ε)）、
> **Samuelson 公共品条件**（垂直加总）。四者合起来，
> 是"国家取予"的数学骨架。

---

## 一、凯恩斯交叉：乘数的迭代构造（直觉先行）

直觉：政府多花 1 元，拿到的人花掉 0.8 元，下一轮又有人花 0.64 元……
几何级数收敛：ΔY = 1/(1−c)（c=0.8 时 =5）。

```
构造：Y_{t+1} = c·(Y_t − T) + I + G     迭代至收敛
闭式：Y* = (I + G − cT)/(1 − c)
```

**结构三读**：
1. **乘数的分母是"漏出"**：1−c 是每轮漏出的比例——进口、税收、
   储蓄都是漏出，漏出越多乘数越小。
2. **比例税=自动稳定器**：T=tY 使乘数从 1/(1−c) 降到 1/(1−c(1−t))
   ——c=0.8, t=0.25：5→2.5。**税收让经济"变钝"**：外生冲击的
   放大倍数减半（本家族实验 B 断言）。
3. **迭代即构造**：均衡不必解方程，模拟收敛本身就是证明路径
   （凯恩斯交叉是宏观里最"可计算"的模型）。

## 二、Haavelmo 定理：平衡预算乘数=1

ΔG=ΔT（等额加税与支出）联立两条乘数：

```
ΔY = ΔG/(1−c) − c·ΔT/(1−c) = ΔG(1−c)/(1−c) = ΔG
```

**结构读法**：支出乘数（1/(1−c)=5）与税收乘数（−c/(1−c)=−4）之和
**恒为 1**——不依赖 c。直觉解释：加税抽走的是"本来也要部分储蓄的
钱"，挤出小于一比一。这是财政学最著名的恒等式级定理（1945），
也是"平衡预算≠中性"的标准证据。

## 三、拉弗峰：弹性定税率

应税基数对净税率有弹性 ε（劳动供给/避税/迁移）：
`T(τ) = τ·B·(1−τ)^ε`，求峰：

```
τ* = 1/(1+ε)
```

**结构读法**：ε=0（无行为反应）→ τ*=1，税率越高收入单调越多——
**拉弗曲线的峰完全是行为反应造出来的**。ε=0.4（顶层收入的可弹性
经验值，Saez 传统）→ τ*≈71%。高税率区（τ>τ*）减税增收、低税率区
减税减收——**曲线从来不反对所有税收，只反对"越过峰"的那一段**。
（实证战场在 ε 的大小：顶层弹性 vs 中位数弹性相差数倍。）

## 四、Samuelson 公共品条件：垂直加总

私人物品：**水平加总**需求（同一价格下量相加）；公共品：**垂直加总**
（同一数量下支付意愿相加）：

```
Σ_i MRS_i = MRT（边际转换率）
```

**结构读法**：一条路灯对每个人都"整条"生效——各人的边际支付意愿
**叠在同一个数量上**。条件在数学上干净，**执行上无解**：真话没有
价格（偏好显示问题），Wicksell 的一致同意与 Lindahl 定价都是
不完美补丁——这是公共品理论"上有定理、下无机制"的结构性裂缝
（机制设计在缝里生长，[讲透数学·讲透博弈论](../../讲透数学/讲透博弈论/)
共管）。

## 五、✨美之时刻（⑧要件）：τ*=1/(1+ε)——一个根号里没有根号的定理

**陈述**：拉弗峰的位置只由一个行为参数决定：弹性。ε→0 时峰消失
（单调世界），ε=1 时 τ*=50%——**"经济对税率越敏感，最优税率越低"**
一行公式说尽。**为什么美**：*极简*——政治争论里最情绪化的话题
（税率），被压缩成弹性的一元函数；参数之辩（ε 到底多大）替代了
立场之辩。**怎么亲历**：本家族实验 [laffer_curve.py](experiments/laffer_curve.py)——
ε 从 0 扫到 1，看峰从右边界长出来向 50% 移动。

## 六、假设与代价（④要件续）

| 结构 | 关键假设 | 失效现场 |
|------|---------|---------|
| 凯恩斯交叉 | 价格不动、闲置产能 | 充分就业时挤出发（乘数骤降） |
| Haavelmo | 一次性总量税 | 现实税种皆扭曲（所得税同时压劳动） |
| 拉弗 | 弹性外生且恒定 | 避税技术内生化（数字化让 ε 变大） |
| Samuelson 条件 | 偏好已知 | 显示偏好无解——理论停在"应然" |

## 七、反直觉发现（⑥要件汇总）

自动稳定器是"设计出来的迟钝"（税收让经济变钝是好事）·
平衡预算乘数恰为 1（不是 0 也不是 5）· 拉弗峰是弹性的产物
（无行为反应则峰不存在）· 公共品越重要越难收费（垂直加总的
执行悖论）· 税式支出是隐形预算（02 章）。

## 👁 认知升维（⑨要件）

**漏出眼**：见到任何"放大/传染/级联"系统，先找漏出项——乘数的
全部秘密在 1−c；漏出（隔断/熔断/缓冲）决定系统对外生冲击的
敏感度。疫情 R₀、金融传染、缓存雪崩，都是凯恩斯交叉的亲戚。
