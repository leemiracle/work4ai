# 04 · 财政学转代码：从乘数到微观模拟的走廊

> **本章回答五问之五（本家族：讲透财政学）。**
> 三件套：**可机械化边界**、**代码走廊**、**工程师落点**。
> 财政学的计算版图分两层：教学层（乘数/拉弗——闭式小模型）与
> 工业层（微观模拟/税收大数据——真正的建制）。

---

## 一、可机械化边界（为什么边界画在这里）

| 问题类 | 可机械化程度 | 边界原因 |
|--------|-------------|---------|
| 凯恩斯交叉/乘数/稳定器 | ✅ 完全 | 闭式+迭代双验证（本家族实验） |
| 拉弗曲线与弹性敏感性 | ✅ 完全 | 一元函数扫参 |
| Haavelmo/恒等式族 | ✅ 完全 | 代数恒等，数值复核 |
| 公共品博弈（自愿供给） | ✅ 完全 | 仿真即结论（搭便车内生于结构） |
| 税制微观模拟（每个纳税人） | ✅ 建制成熟 | 行政数据+税则引擎（各国财政部在用） |
| 最优税制设计 | 🟡 半机械 | Mirrlees 问题可算，弹性分布需估 |
| 政治过程（投票/游说） | 🟡 博弈仿真 | 均衡存在性与收敛无保证 |
| 央地博弈（化债谈判） | ❌ 尚未 | 多期多主体激励，无定形 |

**判据一句话**：**恒等式与闭式全可算，参数分布靠行政大数据，
政治与激励留给博弈仿真**——财政学的"能算"比例高，因为国家
本身就在产生数据。

## 二、代码走廊（五条）

### 走廊①：凯恩斯交叉三件套（本家族实验）

[`experiments/fiscal_multiplier.py`](experiments/fiscal_multiplier.py)：
乘数 5、稳定器 5→2.5、Haavelmo=1，闭式与 100 步迭代双重断言：

```python
def iterate(G, T, c=c, t=0.0, steps=100):
    Y = 0.0
    for _ in range(steps):
        Y = c*(1-t)*Y + (I + G - c*T0)   # 比例税进系数
    return Y                              # 收敛到闭式
```

### 走廊②：拉弗曲线扫参（本家族实验）

[`experiments/laffer_curve.py`](experiments/laffer_curve.py)：
T(τ)=τ·B·(1−τ)^ε，ε∈{0, 0.4, 1.0} 三线对比，格点峰 vs 闭式
τ*=1/(1+ε) 断言；输出"90% 税率区减税增收"区间演示。

## 三、工程师落点（这些东西在谁家产线上）

1. **税务系统的算法征管**：发票大数据、风险画像（金税四期类系统）——
   AI 征管（IMF 2026 前沿）的工程现场。
2. **财政部的微观模拟部门**：税改方案的分布效应核算（走廊④）。
3. **预算与国库信息化**：指标流+资金流的对账系统（财政管理学支的
   数字孪生）。
4. **智库的政策沙盘**：乘数/可持续算术（走廊①⑤）做情景分析。

## 四、✨美之时刻（⑧要件）：搭便车的机器复现——人心比模型温柔

**陈述**：公共品博弈仿真里，纯理性预测捐助=0；真人实验里首轮平均
捐 40-60%，随后衰减，但**加入惩罚机制后反弹并稳定**。
**为什么美**：*意外*——仿真给出"应该自私"的下界，实验给出"愿意
合作"的现实；制度设计就活在这个带宽里。Samuelson 条件说公共品
无市场解，实验说：**给一点惩罚权，人类自己就是机制**。
**怎么亲历**：走廊③把惩罚成本参数从 0 扫到 0.3，看捐助率曲线
怎样从衰减翻转为稳定——你刚运行了一次"制度的诞生"。

## 五、反直觉发现（⑥要件）

工业层的教学版：财政学"最能算"的部分（微观模拟）依赖"最不能算"
的输入（行政数据的口径与覆盖）；**征管数字化让逃税弹性（ε）变大
的同时也让征管方看得更清**——猫鼠双方的技术军备，是拉弗峰位置
的真正决定者（01 章方向五与本节的合流）。

## 👁 认知升维（⑨要件）

**双层眼**：评估任何政策工具栈，分"教学层"（闭式小模型——给直觉
与方向）与"工业层"（微观模拟/大数据——给数字与分布）。只有教学层
的学科停留在嘴上，只有工业层的学科失去方向感——财政学恰好两层
都齐，所以它是经济学里最"工程化"的学科之一。
