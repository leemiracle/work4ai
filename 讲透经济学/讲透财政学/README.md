## 一、诞生（三个原生问题）

1. **国家该怎么收钱（1776）**——斯密《国富论》第五篇立税收四原则
  （平等/确定/便利/经济），财政学从"君主的账房"变成"原则之学"。
2. **大家想搭便车怎么办（1954）**——Samuelson 公共品条件
   ΣMRS=MRT：好的公共品该提供多少，数学上有答案，但**偏好没人
   愿意真说**（Wicksell 1896 早指出：一致同意才无强制）——财政学
   的激励深水区。
3. **赤字是谁的债（1936/1974）**——凯恩斯说赤字救命；Barro 1974
   复活李嘉图等价说"发债=推迟的税收，理性家庭不动消费"——公债
   负担论的百年悬案，2020 年代大财政（r 与 g 的赛跑）再登头条。

## 二、核心问题（已解决/未解决）

| 问题 | 状态 | 一句意义 |
|------|------|---------|
| 公共品的最优供给条件（Samuelson 1954） | ✅ 已证明 | 需求垂直加总=供给；但偏好显示无解（激励问题） |
| 最优商品税（Ramsey 1927） | ✅ 已证明 | 逆弹性法则——同 [讲透价格学](../讲透价格学/) 03 章结构 |
| 最优所得税（Mirrlees 1971，1996 诺奖） | ✅ 已证明 | 信息约束下的再分配-激励权衡框架 |
| 税负归宿的弹性定律 | ✅ 已证明 | 法定归宿≠经济归宿（[讲透价格学](../讲透价格学/) 实验） |
| 平衡预算乘数=1（Haavelmo 1945） | ✅ 已证明 | 加税花钱的乘数恰为 1——反直觉定理（本家族实验） |
| 拉弗曲线的可行区间 | 🔄 实证争议 | 高税率减税增收只在弹性足够大处成立 |
| 公债的代际负担 | 🔄 永恒争论 | 李嘉图等价 vs 功能财政 vs r<g 新共识 |
| 央地财政分权（1994 分税制之后） | 🔄 中国前线 | 事权与财权匹配、土地财政转型、化债 |

## 三、假设与代价

| 假设 | 买到 | 付出 |
|------|------|------|
| 国家是单一决策者 | 三职能框架（配置/分配/稳定）可写 | 政治过程（利益集团/周期）被抽象掉——公共选择补刀 |
| 偏好与技术可观测 | 最优税理论闭式 | 实际征管靠"可观测的代理"（收入/消费）——避税空间随之而生 |
| 乘数结构稳定 | 财政政策可测算 | 卢卡斯批判：换个 regime 参数就变 |
| 税基与税源同域 | 征管可行 | 数字经济（利润在云上）撕开这条假设 |
