# 讲透税务管理学 · 税制、征管与遵从

> **定位**：这支负责税收的操作科学——税制结构（流转/所得/财产）、
> 征管技术与遵从行为（逃税的猫鼠博弈）、纳税服务与国际税收
> （全球最低税）。GB/T 三级"税务管理学"落位于此。

## 诞生

征管现代化三阶段：手工定额定率（协商征税）→ 以票控税（增值税
发票体系的全球扩散）→ 以数治税（金税四期/算法风险画像——
IMF 2026 称之为"AI 征管"前沿）。理论面：Allingham-Sandmo 1972
把逃税形式化为期望效用下的赌博（稽查率×罚款率的最优威慑），
行为财政学（nudge 式纳税提醒）在 2010s 后大放异彩。

## 核心问题（3-5 条）

- ✅ 已解：逃税的威慑模型（A-S 1972：稽查率与罚款率的替代——
  "低稽查×高罚"与"高稽查×低罚"可同效率，社会成本不同）
- ✅ 已解：增值税的自我执行机制（抵扣链让买方监督卖方开票——
  税制设计的杰作）
- 🔄 前线：数字经济税基（常设机构概念失效→全球最低税 BEPS 2.0
  的 15% 实施博弈）
- 🔄 前线：行为征管（催报短信的措辞实验——社会规范 nudge 的
  大规模 RCT）
- ❌ 未解：小规模经济的征管边界（起征点、核定与豁免的权衡——
  发展中国家的"窄税基"困境）

## ✨这项最美的一个事实

增值税是**让纳税人互相监督的税**：你要抵扣，就必须拿到上游的
发票——买方成了税务稽查的义务编外人员。抵扣链把千万家企业
连成互锁的证据网，链条断口（虚开发票）自动暴露。用税制结构做
治理工程，这是公共经济学里"机制设计"最成功的实战案例。

## 假设与依赖

第三方信息可得（工资/发票/流水——信息报告是遵从的第一变量）；
稽查的边际成本可控（数字画像使其骤降——猫鼠军备的当前回合）。

## 教材锚

- Allingham & Sandmo (1972) 原典（逃税模型）
- Slemrod 的遵从研究传统（"应然税制×征管能力"框架）
- 中国金税工程与国际 BEPS 文件（制度与数据轨）
