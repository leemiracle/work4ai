# 讲透财政史 · 从盐铁专营到分税制

> **定位**：这支负责财政的历时制度——中国赋税史（田赋/盐铁/厘金/
> 关税/统税）、财政国家形成史（西欧战争-税收-代议制链条）、
> 当代中国财政体制变迁（统收统支→分灶吃饭→分税制）。
> GB/T 三级"财政史"落位于此。

## 诞生

财政史的中心命题由 Schumpeter 1918 年定调：**财政是社会的探针**
（"税收国家"论）——一个时代的财政构造暴露其权力构造。西欧线：
战争筹资压力→征税需要议会同意→"无代表不纳税"催生代议制
（Tilly 一脉的财政-军事国家研究）。中国线：盐铁会议（公元前 81 年）
的官营之辩是世界最早的财政政策大辩论；1994 年分税制是二十世纪
最重要的财政制度变革之一。

## 核心问题（3-5 条）

- ✅ 已解：财政国家形成的东西方分岔（包税/专营 vs 议会税权的
  制度后果）
- ✅ 已解：中国赋税结构的长期演变（人头税→土地税→流转税的主体
  税种迁移及其政治逻辑）
- ✅ 已解：1994 分税制的动因与后果（央地收入倒挂的再集中；
  土地财政作为地方财源补位的意外遗产）
- 🔄 前线：统账结合社保的历史账（隐性债务的代际核算）
- ❌ 未解：数字税基的历史意义（"税收国家"之后是什么——平台国家？）

## ✨这支最美的一个事实

公元前 81 年的盐铁会议：桑弘羊为汉武帝的盐铁专营辩护（国库与
边防），贤良文学主张放民间（藏富于民）——**官营 vs 民营、国富 vs
民富的全部论点在两千年前的这场会议上一轮齐全**。世界财政史的
第一场大辩论发生在中国，且至今没有结束（今天的国企利润上缴与
烟草专营仍在同一条延长线上）。
