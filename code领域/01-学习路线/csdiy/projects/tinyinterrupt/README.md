# tinyinterrupt · 中断控制器模拟器

> 中断向量、优先级、屏蔽、上下文保存的完整状态机。参照 **Linux IRQ / Intel 8259A PIC**。

## 概述

tinyinterrupt 模拟硬件中断控制器：多个设备同时发出中断，谁先响应？中断能嵌套吗？中断处理中又来更紧急的中断怎么办？这些问题的答案构成了「信号处理为什么有 async-signal-safe 清单」的底层原理。

## 核心概念

| # | 概念 | 一句话 |
|---|------|--------|
| 1 | **中断向量** | 每个中断源一个编号，CPU 据此跳到对应的处理函数 |
| 2 | **优先级与嵌套** | 高优先级可以抢占低优先级；同级屏蔽 |
| 3 | **中断屏蔽（mask）** | 临界区临时屏蔽中断，避免被打断 |
| 4 | **上下文保存** | 中断时硬件自动压栈 PC + flags，处理完 IRET 弹回 |
| 5 | **EOI（End of Interrupt）** | 处理完必须通知 PIC，否则下一中断永远不来 |
