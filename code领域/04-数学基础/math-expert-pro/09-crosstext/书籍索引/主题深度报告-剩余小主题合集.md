## 🎯 跨子主题协同

### 协同 1：群论 + 表示 + 同调 = 抽象代数三件套
- 群论 → 表示（理解群结构）
- 表示 → 同调（导出函子）
- 同调 → 代数拓扑 / 代数几何

### 协同 2：调和 + 小波 + 数值 = 信号处理三件套
- Fourier → 小波（多尺度）
- 小波 → 数值（FWT 快速算法）
- 数值 → MP3 / JPEG / 5G

### 协同 3：随机过程 + 金融 + 优化 = 量化三件套
- 随机分析 → Black-Scholes
- Black-Scholes → 优化（蒙特卡洛）
- 优化 → 量化策略
