## 🎯 五大核心洞察

### 洞察 1：**4 大丛书的"分工"非常清晰**

| 丛书 | 主题集中度 | 定位 |
|------|----------|------|
| 通俗译丛 31 本 | 数学史/科普 + 几何 + 经典主题 | **品味热身 + 故事化** |
| 华章 74 本 | 应用数学（线代/概率/金融/优化）| **工程落地主力** |
| 现代基础 105 本 | 高级中文专著（同调/算子/PDE）| **研究生阶段中文参考** |
| GTM 265 本 | 全谱研究级（覆盖所有主题）| **研究级黄金标准** |

→ **学习路径自然映射**：通俗译丛（阶段 0-1）→ 华章（阶段 1-2）→ 现代基础 + GTM（阶段 2-3）

### 洞察 2：**视角覆盖有"长尾"——4 个视角几乎全覆盖**

| 视角 | 覆盖书数 | 占比 |
|------|--------|------|
| V4 最小例子 | 200 | 42% |
| V24 跨书追踪 | 193 | 41% |
| V15 工程出口 | 158 | 33% |
| V8 范畴俯瞰 | 155 | 33% |
| V22 费曼讲解 | 150 | 32% |

→ 这 5 个视角是**通用视角**，每本书都该考虑。

**对比：低覆盖（窄域视角）**：
| 视角 | 覆盖 | 适用域 |
|------|------|-------|
| V1 反例驱动 | 4 | 仅微积分 |
| V6 计算实验 | 12 | 数值/算法 |
| V27 日常化身 | 19 | 应用数学 |
| V23 问题驱动 | 18 | 组合/科普 |

→ 这些是**特色视角**，只对特定书高效。

### 洞察 3：**主题分布有"主战场 + 边缘"**

| 主题域 | 本数 | 视角分析难度 |
|-------|------|-----------|
| 代数·线性 | 多 | ⭐⭐ 易（教材标准） |
| 分析·微积分 | 多 | ⭐⭐ 易 |
| 几何·拓扑 | 多 | ⭐⭐⭐⭐ 难（抽象） |
| 数论 | 中 | ⭐⭐⭐⭐⭐ 极难（研究级） |
| 数学物理 | 中 | ⭐⭐⭐ 中（V9 物理直觉首选） |
| 数学史/科普 | 中 | ⭐ 易（故事化） |
| 信息/编码 | 少 | ⭐⭐⭐ 中 |

→ **先从"易 + 高频"切入**：线性代数 + 微积分 + 概率 + 数学史。这些主题视角分析最成熟。

### 洞察 4：**TOC ≥ 20 的 125 本构成"深度分析靶心"**

这 125 本的特点：
- 章节结构清晰（书签目录完整）
- 大多是经典教材（GTM 主体 + 现代基础核心）
- 平均页数高（≈ 500 页/本）

→ **视角分析的第一波目标**：把这 125 本全部跑过 28 视角扫描。

### 洞察 5：**"其他"分类 116 本需要再细化**

这 116 本大多是：
- 跨主题书（如数学物理方法、几何分析）
- 工具书（如数学指南、问题集）
- 综合性专著（如代数拓扑与示性类）

→ **下一步优化**：扩展关键词，把"其他"降到 50 本以下。

## 📐 视角深度分析模板（每本书）

为每本书生成"深度视角分析卡"，模板：

```markdown
# 视角深度分析：《书名》

## 元数据
- 丛书 / 主题 / 页数 / TOC
- 在 475 本中的定位
- 阶段位置（阶段 1/2/3）

## 5 个深度视角（基于该书的 TOC 实际章节）

### V? 视角名
- **本书哪一章最适合用此视角？**
- **启动提问**（针对具体章节）
- **落地动作**（针对本书内容的 Python/Lean 实操）
- **切面产出**（这本书能照出什么独特切面）

## 该书在 475 本生态中的"独家价值"
- 哪些主题/视角只有它覆盖？
- 它和哪些书形成"配套组"？

## 接入 13 目录的路径
- 主轨位置：01-track/...
- 概念切片：04-concepts/...
```

→ **第 1 波 60 本 × 这个模板** = 60 份深度卡（按 2000 字/卡估算 = 12 万字）
