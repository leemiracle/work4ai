## 🔍 4 视角深度分析

### V4 最小非平凡例子 ⭐⭐⭐⭐⭐

**通用提问**：每个图论概念先在 K₃ / K₄ / C₄ / Petersen 图上验证

| 概念 | 最小例 |
|------|------|
| 连通 | K₂ vs 2× K₂ |
| 树 | K₃ 不算 / 3 顶点树 |
| 二部图 | K_{2,2} |
| 平面图 | K₄ / K₅ 非平面 |
| Euler 路 | K₃（每个顶点偶度）|
| Hamilton 圈 | K₃ |
| 染色 | K₄ 4 色 |
| Petersen 图 | 最小非 Hamilton 3-正则 |

### V10 复杂度 ⭐⭐⭐⭐⭐

**通用提问**：每个图论问题属于什么复杂度类？

| 问题 | 复杂度 |
|------|------|
| 连通性 | P（BFS）|
| Euler 圈 | P |
| Hamilton 圈 | NP-complete |
| 图染色（k≥3）| NP-complete |
| 子图同构 | NP-complete |
| 最大流 | P（Dinic）|
| TSP | NP-hard |
| 图同构 | NP（Babai 2015）|
