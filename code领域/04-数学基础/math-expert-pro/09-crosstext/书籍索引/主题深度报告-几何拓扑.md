## 🔍 5 视角深度分析

### V4 最小非平凡例子 ⭐⭐⭐

**通用提问**：每个拓扑概念先在 S¹ / S² / T² / Möbius 带上验证

**29 本的最小例表**：

| 概念 | 最小例 |
|------|------|
| 同胚 | 区间 (0,1) ≅ ℝ |
| 紧致 | [0,1] vs (0,1) |
| 连通 | ℝ vs ℚ ⊂ ℝ |
| 基本群 | S¹ 的 π₁ = ℤ |
| 同调群 | Sⁿ 的 Hₙ = ℤ |
| Euler 示性数 | V−E+F（多面体）|
| 流形 | S¹ / S² / T² 三种基础流形 |
| 纽结 | 三叶结（最小非平凡纽结）|

### V8 范畴论俯瞰 ⭐⭐⭐

**通用提问**：拓扑空间范畴 Top 的函子都是什么？

**29 本的范畴图**：

```
       Top（拓扑空间范畴）
        │
        ├─ π₁ 函子 → Grp（基本群）
        ├─ Hₙ 函子 → Ab（同调群，到 Abel 群）
        ├─ Hⁿ 函子 → Ab（上同调）
        └─ Ω 函子（环路空间）→ Top（自函子）
              │
              └─伴随─► Σ 函子（悬置）
```

**关键书**：
- **GTM082 Bott-Tu** 用微分形式做上同调，是 V8 范畴论的最佳搭档
- **现代基础 078 同调论**用范畴论框架

### V18 不可能性边界 ⭐⭐⭐⭐

**通用提问**：拓扑学有什么"不可能"？

| 不可能性 | 出处 |
|---------|------|
| 维数不变性（Brouwer 1911）| 不能 Rⁿ ≅ Rᵐ (n≠m) |
| 不动点定理（Brouwer 1909）| 闭球到自身的连续映射必有不动点 |
| 毛球定理（Brouwer）| S²ⁿ 上没有处处非零切向量场（但 S¹, S³, S⁷ 有）|
| 6 色/5 色定理（Hadwiger）| 平面图染色最多 4 色 |
| Gauss-Bonnet | 拓扑 = 几何的积分约束 |
