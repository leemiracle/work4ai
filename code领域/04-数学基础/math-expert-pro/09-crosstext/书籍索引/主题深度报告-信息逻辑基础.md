### V11 信息论 ⭐⭐⭐⭐⭐

**通用提问**：每个数学对象的信息含量？

| 对象 | 信息 |
|------|-----|
| 自然数 n | $\log_2 n$ bit |
| 实数 | 不可数无限 bit |
| 程序 | Kolmogorov 复杂度 |
| 密钥 | 256 bit（AES-256）|
| DNA | 3 GB（人类基因组）|

### V12 Curry-Howard ⭐⭐⭐⭐⭐

**通用提问**：命题 = 类型？证明 = 程序？

| 数学 | 程序 |
|------|------|
| 命题 A | 类型 A |
| 蕴含 A → B | 函数类型 A → B |
| 合取 A ∧ B | 积类型 A × B |
| 析取 A ∨ B | 和类型 A + B |
| ∃x.P(x) | Σ 类型（依赖对）|
| ∀x.P(x) | Π 类型（依赖函数）|

→ **现实应用**：Coq / Lean / Agda 形式化证明
