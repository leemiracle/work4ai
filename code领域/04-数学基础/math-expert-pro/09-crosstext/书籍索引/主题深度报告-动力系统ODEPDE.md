## 🔍 5 视角深度分析

### V9 物理直觉 ⭐⭐⭐⭐⭐

**通用提问**：每个方程对应什么物理过程？

| 方程 | 物理过程 | 真实现象 |
|------|---------|---------|
| Navier-Stokes | 流体 | 飞机气动 / 天气 / 海流 |
| Schrödinger | 量子 | 半导体 / 激光 |
| Maxwell（PDE 形式）| 电磁 | 5G / Wi-Fi / 光刻 |
| Heat equation | 扩散 | COVID 传播 / 热传导 |
| Wave equation | 波动 | 地震 / 声音 / 光 |
| KdV | 孤子 | 海浪 / 光纤 |
| Ginzburg-Landau | 超导 | 超导体 / 超流 |
| Reaction-Diffusion | 反应扩散 | COVID / 化学振荡 / 动物纹理 |

### V11 信息论

**通用提问**：PDE 的"信息流"是什么？

| PDE 类 | 信息行为 |
|--------|---------|
| 双曲型（波）| 信息有限速度传播 |
| 抛物型（扩散）| 信息瞬时传播（但有衰减）|
| 椭圆型（稳态）| 信息全局耦合 |
| 色散 | 不同频率不同速度 |
