## 🔍 5 视角深度分析

### V4 最小非平凡例子 ⭐⭐⭐

**通用提问**：每个概率概念先在 n=2（两硬币/两人/两次）上验证

**15 本的最小例表**：

| 概念 | n=2 最小例 |
|------|----------|
| Bayes | 两枚硬币中一枚双头，摸到正面，是双头硬币的概率 |
| 期望 | 掷 1 颗骰子的期望 = 3.5 |
| 方差 | 掷 1 颗骰子的方差 ≈ 2.92 |
| CLT | 2 个独立 uniform 的和 → 三角分布 |
| 大数律 | 掷 100 次硬币累积平均 → 0.5 |

### V14 ML 锚点

**15 本的 ML 锚点**：

| 概念 | ML 化身 |
|------|--------|
| Bayes | 朴素贝叶斯 / 贝叶斯网络 |
| 期望 | 损失函数期望 = 风险 |
| 方差 | 偏差-方差分解 |
| CLT | SGD 收敛性 / 随机梯度噪声 |
| 测度论概率 | PAC-Bayes 界 / KL 散度 |
| 高斯过程 | 贝叶斯优化 |

### V26 失败案例 ⭐⭐⭐

| 案例 | 数学误用 | 真实损失 |
|------|---------|---------|
