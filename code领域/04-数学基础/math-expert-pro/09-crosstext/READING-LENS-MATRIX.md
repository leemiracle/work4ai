# 28 视角阅读矩阵：让 480 本书每一本都成为棱镜

> 触发：用户要求"越多越好越接近现实价值的不同视角来开发……每个视角是一种切入方向，是一种结构化的思维方式，深具启发性和实践性"。
> **不违反收敛纪律**：这不是新增「门类/职业档案」（13 目录已封），而是为 `../math` 480 本书开发**阅读方法论的视角切片**——同一本书可以从 28 种不同思维透镜切入，每种都是可立即用于今晚阅读的结构化方法。

---

## 🎯 设计原则

1. **每个视角 = 一种结构化提问方式**——不是标签，是启动问题的模板
2. **每个视角都双面**：启发（让你看到书的全新切面）+ 实践（有具体阅读动作）
3. **不与 13 目录重复**——视角是「怎么读」的元方法，13 目录是「读出什么」的内容沉淀
4. **可组合**——一本书可同时用 2–3 个视角切（如 Spivak = 反例驱动 + Lean 形式化 + 历史发生学）
5. **可生成**——任何新书都能用 [GENERATOR](READING-LENS-GENERATOR.md) 自动产出 5–8 个适用视角

## 🎬 完整示范：用 5 个视角切一本书

> 示范书：**Spivak《Calculus》第 7 章「三个硬定理」**（IVT / Extreme Value / Cauchy MVT）

| 视角 | 启动提问 | 切出来的"切面" |
|------|---------|---------------|
| **V1 反例驱动** | 删掉"连续"假设，IVT 还成立吗？ | 写出 $f(x)=\text{sign}(x)$ 在 $[-1,1]$ 上的反例，画出"跳过 0"的图像 |
| **V2 公理逆向** | 为什么最小上界公理（LUB）非加不可？ | 在 $\mathbb{Q}$ 上证 IVT 失败的反例：$f(x)=x^2-2$ 在 $[0,2]$ 有根但 $\mathbb{Q}$ 上"跳过" |
| **V3 历史发生学** | Cauchy 1821 为什么"证错"了 IVT？ | 重读 Cauchy 原始论证，看 Bolzano 1817 怎么先证对的 |
| **V5 严格度光谱** | 我现在在 Tao 哪一阶？ | 从"图像上 obviously"（pre-rigorous）→ ε-δ 严格证（rigorous）→ 拓扑连通性刻划（post-rigorous） |
| **V13 Lean 形式化** | Mathlib4 里 IVT 叫什么？ | `Mathlib.Topology.Continuity.IntermediateValue` — 实际跑一遍 |

→ **同一章被切成 5 个面**，深度比单向精读多 5 倍，且每个面都能落到现有目录（06 反例 / 05 历史 / 04 概念 / Lean 验证）。

## 🚀 使用流程

1. **挑书**：从 [BOOKS-INVENTORY](BOOKS-INVENTORY-2026-07-05.md) 选一本
2. **挑 2–3 视角**：按上面「视角 × 丛书」表选高优组合
3. **激活**：每视角用「启动提问」打开书
4. **沉淀**：把视角产出物存到对应 13 目录的合适位置
5. **记录**：在笔记 §11「方法论反思」标注用了哪几个视角，效果如何
