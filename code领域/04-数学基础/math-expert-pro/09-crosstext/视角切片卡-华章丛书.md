## 📘 卡 1：华章 51《概率论基础教程》第 9 版 · Sheldon Ross

### 书籍元数据
- **作者**：Sheldon Ross
- **版次/年**：第 9 版 / Pearson 2012（中译：机械工业出版社）
- **难度**：⭐⭐ 入门偏进阶
- **文风**：教材严谨 + 生活化例子
- **主题**：概率论（直觉入门）
- **阶段位置**：**阶段 1 概率主线**（约 2 月）。前置：Spivak 积分章；后续：现代基础 006 严格化 / Shreve 随机分析
- **路径**：`../math/华章数学丛书/51-概率论基础教程原书第九版.pdf`

### 推荐视角组合（6 个）

#### 视角 1：V4 最小非平凡例子
- **启动提问**：每个公式先算 n=2（两个硬币 / 两次抛 / 两个人），看是否成立
- **落地动作**：边栏写"2 元素最小例"，例如 Bayes 公式：先算"两枚硬币中一枚双头，摸到正面，是双头硬币的概率"
- **切面产出**：每章末有一张"最小例速查表"
- **配套目录**：`04-concepts/概率收敛-多表征.md`

#### 视角 2：V25 真实数据
- **启动提问**：第 4 章离散分布能拟合哪些真实数据？
- **落地动作**：
  - 第 4 章二项分布 → 拟合 COVID-19 家庭感染数据（[Our World in Data](https://ourworldindata.org/)）
  - 第 5 章正态分布 → 拟合 SAT / 高考分数分布
  - 第 8 章 CLT → 用 Python 模拟 1000 次"掷 30 颗骰子和"，画出收敛过程
- **切面产出**：3 个真实数据 Python notebook
- **配套目录**：`11-日常生活与公民数学/02-病人理解诊断概率.md`（Bayes 配套）

#### 视角 3：V22 费曼讲解
- **启动提问**：第 3 章 Bayes 公式能向我妈讲清吗？
- **落地动作**：录 3 段 5 分钟语音，分别讲：① Bayes ② 期望线性性 ③ CLT
- **切面产出**：3 个语音文件（用手机录）
- **配套目录**：`10-personal/01-我的画像与学习偏好.md`

#### 视角 4：V14 ML 锚点
- **启动提问**：第 8 章 CLT 在神经网络训练里是哪一步？
- **落地动作**：写一段 1 页笔记，说明 SGD 收敛性证明为何用 CLT
- **切面产出**：ML 锚点段（"CLT → SGD 收敛 → 梯度噪声分析"）
- **配套目录**：`10-personal/02-AI锚点法-数学落到工程.md`

#### 视角 5：V21 审美游戏
- **启动提问**：期望线性性 $E[X+Y]=E[X]+E[Y]$（**即使 X, Y 相关**也成立）——为什么这么美？
- **落地动作**：找一个利用期望线性性巧解的题（如"赌徒破产期望步数"），写一段 Lockhart 式短文
- **切面产出**：1 篇审美短文
- **配套目录**：`08-projects/01-FTC微积分基本定理的N条证明.md`（"巧证"风格文件）

#### 视角 6：V24 跨书追踪
- **启动提问**：Bayes 在 Ross / 现代基础 006 / 通俗译丛 25 三本书各怎么写？
- **落地动作**：三栏对照表
- **切面产出**：1 张跨书 Bayes 三栏表
- **配套目录**：`09-crosstext/04-概率路径对照-Ross-Shreve-Loeve.md`

### 视角组合的协同
- **V4 × V25** = 最小例（建立直觉） → 真实数据（验证直觉）的完整闭环
- **V22 × V14** = 给妈讲（人话直觉）→ ML 锚点（专业映射）的双向翻译

### 不推荐视角
- **V8 范畴论**：本科阶段概率尚不严格，范畴化是过度抽象
- **V18 不可能性**：概率论本身没有"不可能性边界"，留到测度论阶段

### 接入路径
- 主轨：`01-track/stage-1-本科核心/04-Ross概率/`
- 概念切片：`04-concepts/概率收敛-多表征.md`
- 现实化身：`11-日常生活与公民数学/02-病人理解诊断概率.md`

## 📗 卡 2：华章 52《矩阵分析》第 2 版 · Horn-Johnson ⭐

### 书籍元数据
- **作者**：Roger A. Horn, Charles R. Johnson
- **版次/年**：第 2 版 / Cambridge 2013（中译：机械工业出版社）
- **难度**：⭐⭐⭐⭐ 进阶
- **文风**：教材严谨 + 参考书风格（不是教科书式流畅，是百科式完整）
- **主题**：线性代数（高级/矩阵理论）
- **阶段位置**：**阶段 1 末/阶段 2 初**——Axler LADR 之后的工程补强，永久工具书
- **路径**：`../math/华章数学丛书/52-矩阵分析原书第二版.pdf`

### 推荐视角组合（6 个）

#### 视角 1：V4 最小非平凡例子
- **启动提问**：每个定理先在 2×2 矩阵上验证
- **落地动作**：全书每章配一个 2×2 验证小脚本（Python/numpy）
- **切面产出**：numpy 2×2 验证脚本库
- **配套目录**：`10-personal/03-Python验证库.md`

#### 视角 2：V14 ML 锚点 ⭐
- **启动提问**：每章定理在 ML 里对应什么算法？
- **落地动作**：建一张"矩阵概念 → ML 算法"映射表：
  - 特征值 → PCA / 谱聚类
  - SVD → 推荐系统 / LSI / 图像压缩
  - 正定矩阵 → 高斯过程 / 核方法
  - 数值范围 → 神经网络稳定性分析
  - 范数 → 正则化（L1/L2）
- **切面产出**：一张 30 行的"矩阵→ML"映射表
- **配套目录**：`10-personal/02-AI锚点法-数学落到工程.md`

#### 视角 3：V7 几何对偶
- **启动提问**：每个代数陈述对应的几何图像是什么？
- **落地动作**：
  - 特征值 = 椭圆半轴长度
  - SVD = 旋转 → 缩放 → 旋转 的几何分解
  - 正定矩阵 = 椭球形状
- **切面产出**：3 张几何图 + 3Blue1Brown 视频链接
- **配套目录**：`04-concepts/特征值-多表征.md`

#### 视角 4：V20 比较文学
- **启动提问**：Horn-Johnson vs Axler vs Artin，三者对"特征值"各怎么写？
- **落地动作**：三栏对照表，对比：
  - Horn-Johnson：从特征多项式 + 迹 + 行列式切入
  - Axler：刻意绕开特征多项式，用不变子空间
  - Artin：用群作用框架统一
- **切面产出**：1 张三栏对照表
- **配套目录**：`09-crosstext/01-线性代数三书对照-Axler-Horn-Artin.md`

#### 视角 5：V6 计算实验
- **启动提问**：numpy 的 SVD 数值稳定性如何？大矩阵 vs 小矩阵差异？
- **落地动作**：跑 `numpy.linalg.svd` 在病态矩阵（Hilbert 矩阵）上的误差分析
- **切面产出**：1 个数值稳定性实验 notebook
- **配套目录**：`10-personal/03-Python验证库.md`

#### 视角 6：V15 工程出口
- **启动提问**：每章支撑哪个真实工程系统？
- **落地动作**：建工程映射：
  - 特征值 → Google PageRank
  - SVD → Netflix 推荐大赛 2009
  - 正定矩阵 → 量子力学密度矩阵
  - 数值范围 → 控制论稳定性
- **切面产出**：工程出口清单（4 条）
- **配套目录**：`03-lens-practitioners/03-计算信息视角/`

### 视角组合的协同
- **V4 × V6** = 最小例（手算 2×2）→ 计算实验（numpy 大矩阵），从手到机器
- **V14 × V15** = ML 锚点（学术工程）→ 工程出口（产业工程），理论的双重落地

### 不推荐视角
- **V3 历史发生学**：本书是参考书风格，没有故事线
- **V21 审美游戏**：矩阵分析本身不是"美"的，是"有用"的——审美留给 Axler

### 接入路径
- 主轨：`01-track/stage-1-本科核心/03-LADR线性代数/` （作为 LADR 后续）
- 概念切片：`04-concepts/特征值-多表征.md`
- AI 锚点：`10-personal/02-AI锚点法-数学落到工程.md`

## 📕 卡 3：华章 71《凸优化教程》第 2 版 · Borweind-Borwein

### 书籍元数据
- **作者**：Jonathan M. Borwein, Adrian S. Lewis
- **版次/年**：第 2 版 / Springer 2006（中译：机械工业出版社）
- **难度**：⭐⭐⭐⭐ 进阶
- **文风**：教材严谨（CSOR setText 风格）
- **主题**：凸分析 / 优化理论
- **阶段位置**：**阶段 2–3 ML 理论前修**——学完 Royden 实分析 + Horn-Johnson 之后
- **路径**：`../math/华章数学丛书/71-凸优化教程原书第2版.pdf`

### 推荐视角组合（5 个）

#### 视角 1：V8 范畴论俯瞰
- **启动提问**：Fenchel 对偶 / Lagrange 对偶是哪个伴随对的单位/余单位？
- **落地动作**：画对偶范畴图，标记单位 ε 与余单位 η
- **切面产出**：1 张范畴对偶图
- **配套目录**：`04-concepts/优化.md`

#### 视角 2：V14 ML 锚点 ⭐
- **启动提问**：每章定理在 ML 训练里是哪一步？
- **落地动作**：建映射表：
  - 强凸性 → SGD 收敛速率 $O(1/t)$
  - KKT 条件 → SVM 对偶推导
  - Fenchel 对偶 → 变分推断 ELBO
  - 次梯度 → L1 正则化（非光滑优化）
  - 投影梯度 → 约束优化（如 LogBarrier）
- **切面产出**：5 条 ML 映射
- **配套目录**：`10-personal/02-AI锚点法-数学落到工程.md`

#### 视角 3：V9 物理直觉
- **启动提问**：最小作用量原理 vs 凸优化，是同一种"经济"吗？
- **落地动作**：写一段 1 页类比，从 Lagrange 力学到 KKT 条件
- **切面产出**：1 页物理类比笔记
- **配套目录**：`04-concepts/优化.md`

#### 视角 4：V25 真实数据
- **启动提问**：用凸优化拟合真实数据是什么样？
- **落地动作**：
  - LASSO（L1 正则） → 基因表达数据（高维稀疏）
  - 二次规划 → 投资组合优化（Markowitz）
  - 半定规划 → PhaseSync 相位恢复
- **切面产出**：3 个 cvxpy notebook
- **配套目录**：`11-日常生活与公民数学/`（金融）+ `12-社会系统视角/03-金融系统的整体稳定.md`

#### 视角 5：V6 计算实验
- **启动提问**：cvxpy 内部用的是哪种求解器？复杂度如何？
- **落地动作**：用 cvxpy 跑同一问题，对比 ECOS / SCS / OSQP 三个求解器
- **切面产出**：1 个求解器对比 notebook
- **配套目录**：`10-personal/03-Python验证库.md`

### 视角组合的协同
- **V8 × V14** = 范畴论（结构）→ ML（应用），抽象结构落到具体算法
- **V9 × V25** = 物理直觉（自然经济）→ 真实数据（社会优化），同一种"最小"跨域
