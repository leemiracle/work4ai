---

| 时间 | 事件 |
|------|------|
| 1994 | **LTCM 成立**——团队含 2 名 Nobel 经济学奖（Scholes + Merton）|

## 🎯 数学误用：Black-Scholes 的隐含假设

### LTCM 的核心策略
**收敛套利**：找两个相关债券的价差暂时扩大，做"会收敛"的押注。

**数学基础**：Black-Scholes 模型 + 协方差假设。

### 3 个致命假设

#### 假设 1：正态分布（轻尾）
$$r_t \sim \mathcal{N}(\mu, \sigma^2)$$

**真实**：金融收益**重尾**（Cauchy / Stable distribution）。1998 年 8 月俄罗斯违约是 **8σ** 事件——按正态，宇宙年龄内不会发生，但实际每 10 年一次。

#### 假设 2：连续交易（无跳跃）
$$\frac{dS}{S} = \mu\,dt + \sigma\,dW$$

**真实**：俄罗斯违约是**跳跃过程**（Merton 1976 模型才正确）。

#### 假设 3：高流动性
可随时平仓。

**真实**：1998.8 流动性瞬间消失——价差不收敛反而扩大。

---

## 🧠 认知偏差：Nobel 奖光环 + 杠杆傲慢

### 偏差 1：权威光环
2 位 Nobel 奖得主 → 投资者盲目信任 → 不质疑模型。

### 偏差 2：杠杆傲慢
LTCM 杠杆 25:1（资产 $125B / 资本 $5B）。任何小波动都被放大 25 倍。

### 偏差 3：幸存者偏差
1994-1997 连续高回报 → 误以为模型永远正确。

## 💻 Python 复盘

```python
import numpy as np
import matplotlib.pyplot as plt

# 模拟 LTCM 策略：价差收敛
np.random.seed(42)
n_days = 252 * 4  # 4 年
sigma = 0.005  # 正常波动
# 假设 99% 时间收敛，1% 时间发散
spread = np.zeros(n_days)
for i in range(1, n_days):
    if np.random.rand() < 0.99:
        spread[i] = spread[i-1] * 0.95 + np.random.randn() * sigma  # 收敛
    else:
        spread[i] = spread[i-1] * 1.2 + np.random.randn() * sigma * 10  # 跳跃发散

# 杠杆 25:1
leverage = 25
pnl = np.cumsum(-spread * leverage)

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.plot(pnl)
plt.title('LTCM 模拟 P&L（杠杆 25:1）')
plt.axhline(0, color='gray')
plt.subplot(1, 2, 2)
plt.hist(np.diff(pnl), bins=50)
plt.title('日收益分布（重尾！）')
plt.savefig('LTCM_simulation.png', dpi=100)

# 计算尾部风险
losses = -np.diff(pnl)
print(f"日 VaR(99%): {np.percentile(losses, 99):.2f}")
print(f"日 ES(99%): {losses[losses > np.percentile(losses, 99)].mean():.2f}")
```

## 📚 启示：6 条核心教训

1. **正态假设是危险的**——金融必须用重尾
2. **流动性会消失**——价差交易假设"可平仓"
3. **杠杆放大错误**——25:1 任何模型误差都会致命
4. **Nobel 奖 ≠ 真理**——Scholes/Merton 也犯错
5. **极端事件不是黑天鹅**——而是必然（10 年一遇）
6. **监管必须介入**——美联储救市是必要的
