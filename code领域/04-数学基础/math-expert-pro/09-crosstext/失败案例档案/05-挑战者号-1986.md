|------|------|

## 🎯 数学误用：贝叶斯直觉被忽视

### 核心问题

工程师 **Boisjoly**（Morton Thiokol）发射前夜警告：低温（28°F）会让 O-ring 失效。

**管理层回应**："数据显示 53°F 时 O-ring 也烧蚀过，但没有灾难性失败"。

### 数学层面的错误

**正确做法（Bayes）**：
$$P(\text{失败} \mid T=28°F) = \frac{P(T=28°F \mid \text{失败}) P(\text{失败})}{P(T=28°F)}$$

管理层只看 $P(\text{失败} \mid \text{发生过})$——历史样本中失败比例。

**忽略的关键**：
1. **样本大小**：低温发射次数极少（仅 1 次 < 60°F）
2. **外推风险**：28°F 远超历史最低（53°F）
3. **O-ring 物理机制**：橡胶低温变脆（已知物理）

### Diane Vaughan 的"正常化偏差"理论

> 每次有惊无险，都被解释为"系统正常"——偏差变成规范。

---

## 🧠 认知偏差：4 重误判

### 偏差 1：生产压力
NASA 计划 15 次/年发射，进度压力 → 降低标准。

### 偏差 2：官僚层级
工程师 → 中层 → 高层 → NASA 高管 → 4 道过滤，警告被稀释。

### 偏差 3：成功偏差
24 次成功发射 → "O-ring 烧蚀是正常的"

### 偏差 4：领导决断
高管 Larry Mulloy 否决工程师："证明不会失败，否则就发射"——举证责任倒置。

## 🔍 正确做法（事后改进）

### 1. 完整数据 + 物理模型
```python
import numpy as np
# O-ring 烧蚀 vs 温度（实际数据）
T_actual = np.array([66, 70, 69, 80, 68, 67, 72, 73, 70, 57, 63, 70, 78, 67, 53, 67, 75, 70, 81, 76, 79, 75, 76, 58])  # °F
damage = np.array([0, 4, 0, 0, 0, 4, 0, 0, 0, 4, 2, 0, 0, 0, 11, 0, 0, 0, 0, 0, 0, 0, 0, 6])

# 28°F 时预测
from sklearn.linear_model import LinearRegression
X = T_actual.reshape(-1, 1)
model = LinearRegression().fit(X, damage)
T_28 = np.array([[28]])
predicted_damage = model.predict(T_28)[0]
print(f"预测 28°F 损伤: {predicted_damage:.1f}（最高级 11 = 灾难性）")
# 真实：损伤 16+，远超历史最高
```

### 2. 全数据可视化
**Tufte 1997《Visual Explanations》经典分析**：
- NASA 管理层看的图：只显示"有 O-ring 损伤"的发射
- **应该看的图**：所有发射，包括无损伤的
- 加上 28°F 后，趋势**显然**——温度越低损伤越大

### 3. 贝叶斯决策
- **预防原则**：不确定时保守
- **冗余设计**：双层 O-ring（部分有，但航天飞机只有单层）
- **告警优先**：工程师警告 = 暂停

### 4. 文化改革
NASA 改革"安全文化"——设立独立安全办公室。

## 💻 Python 复盘

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# 完整 O-ring 数据（Dalal-Fowlkes-Hoadley 1989）
T = np.array([66, 70, 69, 80, 68, 67, 72, 73, 70, 57, 63, 70, 78, 67, 53, 67, 75, 70, 81, 76, 79, 75, 76, 58])
damage_index = np.array([0, 4, 0, 0, 0, 4, 0, 0, 0, 4, 2, 0, 0, 0, 11, 0, 0, 0, 0, 0, 0, 0, 0, 6])

# NASA 管理层视角：只看有损伤的数据
mask = damage_index > 0
plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.scatter(T[mask], damage_index[mask], color='red', s=100)
plt.xlabel('温度 °F'); plt.ylabel('损伤指数')
plt.title('管理层视角：只有损伤样本\n（看不清温度趋势）')

# 工程师视角：全部数据
plt.subplot(1, 2, 2)
plt.scatter(T[damage_index==0], damage_index[damage_index==0], color='green', s=80, label='无损伤')
plt.scatter(T[mask], damage_index[mask], color='red', s=100, label='有损伤')
plt.axvline(28, color='black', linestyle='--', label='发射日 28°F')
plt.xlabel('温度 °F'); plt.ylabel('损伤指数')
plt.legend(); plt.title('工程师视角：全部样本\n（趋势明显！）')

# 线性回归
model = LinearRegression()
model.fit(T.reshape(-1,1), damage_index)
T_line = np.linspace(20, 85, 100).reshape(-1,1)
plt.subplot(1, 2, 2)
plt.plot(T_line, model.predict(T_line), 'b-', alpha=0.5)
plt.axhline(11, color='orange', linestyle=':', label='灾难级 (11)')

print(f"28°F 预测损伤: {model.predict([[28]])[0]:.1f}")
plt.savefig('challenger.png', dpi=100)
```

## 📚 启示：6 条核心教训

1. **数据可视化决定决策**——Tufte 经典教训

3. **物理机制 + 统计**——橡胶低温变脆是已知
4. **管理 ≠ 工程**——官僚层过滤警告
5. **预防原则**——不确定时保守
6. **举证责任**——证明安全 vs 证明危险
