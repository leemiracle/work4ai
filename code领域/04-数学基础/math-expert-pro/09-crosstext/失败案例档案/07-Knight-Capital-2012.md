## 🎯 数学误用：状态机错误

### Bug 本质
Knight 在 8 台服务器部署 SMARS。**1 台服务器忘了更新**——保留旧版（2003 年的测试代码 PowerPeg）。

**旧代码**：
- 当股价 > 启动阈值：**疯狂买入**
- 当股价 > 关闭阈值：**疯狂卖出**

45 分钟内：触发 154 只股票，成交 3.97 亿股。

### 数学错误
- **状态机不匹配**：8 台服务器，1 台不同步
- **缺乏一致性检查**：没有"所有服务器代码版本一致"的验证

---

## 🧠 认知偏差：技术傲慢 + 压力测试缺失

### 偏差 1：自动化陷阱
"算法不会错" → 不监控。

### 偏差 2：部署检查缺失
没有"金丝雀发布"（先小规模测试）。

### 偏差 3：紧急停止不熟悉
交易员不熟悉手动 kill 开关。

---

## 🔍 正确做法

### 1. 形式化验证
用 TLA+ / Coq 验证交易算法。

### 2. 形式化部署
所有服务器版本一致性检查。

### 3. 熔断器
任何算法损失 > $1M 自动停止。

### 4. 模拟环境
新代码先在 sandbox 跑 1 周。

## 💻 Python 复盘

```python
# 模拟 Knight Capital bug
import numpy as np

# PowerPeg bug：当股价上涨时疯狂买
np.random.seed(0)
prices = [50.0]
positions = [0]
cash = [0]

for t in range(2700):  # 45 分钟 × 60 秒
    price_change = np.random.randn() * 0.01
    price = prices[-1] * (1 + price_change)
    prices.append(price)
    
    # Bug: PowerPeg 触发
    if 50 < price < 60:  # 触发区间
        # 疯狂买
        buy = 10000
        positions.append(positions[-1] + buy)
        cash.append(cash[-1] - buy * price)
    else:
        positions.append(positions[-1])
        cash.append(cash[-1])

# 损失 = 持仓 × 价格 + 现金
loss = positions[-1] * prices[-1] + cash[-1]
print(f"模拟 45 分钟损失: ${-loss/1e6:.2f}M")
# 真实 $440M
```
