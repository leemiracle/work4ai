# V26 失败案例档案 #8：Fukushima 2011（PDE 极值低估）

> **海啸高度 PDE 误判 → 核灾难**

---

## 📅 时间线

| 时间 | 事件 |
|------|------|
| 1967 | 福岛核电站建成，海堤设计高度 5.7 m |
| 2002 | 重新评估，提升至 6 m |
| 2008 | 东京电力估算最大海啸 15 m（未采纳）|
| **2011.3.11** | **9.0 级地震 + 14 m 海啸** |
| 2011.3.12 | 福岛 1 号堆氢爆 |
| 2011.3.14-15 | 3 号、2 号堆爆炸 |
| 2011-2020 | 30 万人疏散，清理 $200+ 亿 |

**直接损失**：
- 600+ 死亡（疏散相关）
- $200+ 亿清理
- 30 万人失去家园
- 全球核电倒退

---

## 🎯 数学误用：极值理论 PDE 低估

### 错误 1：历史样本外推
1967 设计基于 1960 智利海啸（远端）+ 1896 三陆（远端），**没有本区域大地震数据**。

### 错误 2：极值分布错选
**正确做法**：用 **GEV（广义极值分布）** 估计。

**实际做法**：用最近 100 年海啸数据拟合——**严重低估**尾部。

### 错误 3：地震 PDE 模型未更新
2008 东京电力用新 PDE 模型算出 15 m 海啸——但**管理层未采纳**。

---

## 🧠 认知偏差：监管俘获 + 成本压力

### 偏差 1：成本规避
提升海堤要 $25M——东电不愿。

### 偏差 2：安全神话
"日本核电绝对安全" → 不接受极端事件。

### 偏差 3：监管俘获
日本原子力安全保安院（NISA）与东电密切。

---

## 🔍 正确做法

### 1. 极值统计（EVT）
```python
# 用 GEV 拟合海啸数据
from scipy.stats import genextreme
# 假设历史海啸高度
heights = [2, 3, 4, 1.5, 2.5, 5, 3.5, 6]  # m
# GEV 拟合
c, loc, scale = genextreme.fit(heights)
# 100 年一遇
return_100 = genextreme.ppf(0.99, c, loc, scale)
# 但日本实际数据少，应结合地质证据（古海啸沉积物）
```

### 2. 物理基础 PDE
不只用历史数据，用**地震 PDE 模型**模拟。

### 3. 防御纵深
- 海堤（1 层）
- 防波堤（2 层）
- 海拔（3 层）
- 移动电源（4 层）

### 4. 国际同行评审
独立第三方评估。

## 📚 启示

2. **PDE 不更新就是犯罪**
3. **多层防御**——不要依赖单一屏障
4. **监管独立**
5. **预防原则**
6. **地质证据是数据**——沉积物显示 869 年贞观海啸
