# 视角生成器：为任意一本新书自动产出 5–8 个适用视角

> 触发：拿到 `../math` 下任意一本新书时，用本表的 7 步提问流程，自动生成"这本书的高优视角组合"。
> 输入：书名 + 翻一下前言/目录。输出：5–8 个视角 + 启动提问 + 落地动作。

---

## 🔄 7 步生成流程

### Step 1 · 书的本质判定（决定视角池）

读前言/封底/目录，回答 3 个问题：

| 问题 | 选项 | 判定 |
|------|------|------|
| Q1 这本书的**难度带**？ | ⭐⭐ 入门 / ⭐⭐⭐ 本科 / ⭐⭐⭐⭐ 研究生 / ⭐⭐⭐⭐⭐ 研究 | 决定 V5 严格度光谱是否适用 |
| Q2 这本书的**文风**？ | 故事科普 / 教材严谨 / 研究专著 / 工具书 | 故事→ V3/V21/V22；教材→ V1/V4/V6；研究→ V8/V12/V19 |
| Q3 这本书的**目标读者**？ | 高中生 / 本科生 / 研究生 / 研究者 | 决定 V14 ML 锚点 / V22 费曼讲解的深度 |

### Step 2 · 主题域映射（决定跨学科视角）

| 书的主题 | 优先跨学科视角 |
|---------|--------------|
| 微积分/分析 | V9 物理直觉 · V13 Lean 形式化 · V14 ML 锚点（梯度） |
| 线性代数 | V14 ML 锚点（PCA/SVD）· V7 几何对偶 · V15 工程出口（图形/信号） |
| 抽象代数 | V8 范畴论 · V12 Curry-Howard · V16 对称群（艺术/晶体）|
| 拓扑 | V8 范畴论 · V17 反例库 · V18 不可能性 |
| 概率统计 | V25 真实数据 · V26 失败案例 · V11 信息论 · V15 量化 |
| 几何 | V9 物理直觉 · V16 艺术 · V7 代数对偶 |
| 数论 | V15 工程出口（密码学）· V18 不可判定 · V19 替代范式 |
| 逻辑/基础 | V12 Curry-Howard · V13 Lean · V18 不可能性 · V19 替代范式 |
| 数值/计算 | V6 计算实验 · V10 复杂度 · V14 ML 锚点 |
| 动力系统 | V25 真实数据（疫情/气候）· V28 社会系统 · V9 物理 |

### Step 3 · 历史/批判维度扫描（决定 V3/V17/V18/V19）

- 这本书的概念有没有"著名的反例史"？（如 IVT / 不可测集 / 选择公理） → 启用 V17
- 这本书的理论有没有"著名的极限"？（Gödel / CAP / 不可判定） → 启用 V18
- 这本书的范式有没有"竞争者"？（标准 vs 非标准分析 / 经典 vs 直觉主义） → 启用 V19

### Step 4 · 现实价值扫描（决定 F 族 V25–V28）

- 书里的定理能拟合哪段真实数据？（疫情/股市/天气/交通） → V25
- 这个理论被误用导致过哪些真实灾难？（LTCM / 挑战者号 / 2008） → V26
- 这个概念在厨房/手机/超市/电网里有化身吗？ → V27 / V28

### Step 5 · 学习者画像适配（个人化）

参考 `10-personal/01-我的画像与学习偏好.md`：
- Python 工程级 → V6 计算实验 + V12 Curry-Howard 优先
- PyTorch 入门 → V14 ML 锚点 优先
- 喜可视化历史动机 → V3 + V7 + V9 优先
- 喜工程落地 → V15 + V25 + V26 优先

### Step 6 · 去重 + 收敛到 5–8 个

把上面 5 步得出的视角汇总，按下列规则去重：
- 同族（A/B/C/D/E/F）只取 Top 2
- 保留至少 1 个"启发型"（V3/V16/V21）+ 至少 1 个"实践型"（V6/V13/V22）
- 总数控制在 5–8 个（再多就过载）

### Step 7 · 输出（视角切片卡）

模板：

```markdown
# 视角切片卡：《书名》

## 书籍元数据
- 作者 / 版次 / 出版年
- 难度 / 文风 / 主题
- 阶段位置（阶段 1/2/3）

## 推荐视角组合（N 个）

### 视角 1：V?-????
- 启动提问：……
- 落地动作：……
- 切出来的切面：……

### 视角 2：……

## 视角组合的协同
- V? × V? 形成 …… 升维

## 风险提示
- 不推荐视角 V??：因为 ……
```

## 🎯 与现有 `09-crosstext/` 的关系

`09-crosstext/` 现有 5 份对照文件（线代三书 / 分析路径 / 代数路径 / 概率路径 / GTM 指南），是「**跨书**」对照。

本生成器产出的是「**单书多视角**」切片卡——补全了 `09-crosstext/` 的另一维度。两者正交：

```
                  同一概念            不同概念
              ┌──────────────┬──────────────┐
   单本书  │  04-concepts   │  视角切片卡   │ ← 本生成器
              ├──────────────┼──────────────┤
   多本书  │  09-crosstext  │   待发展      │
              └──────────────┴──────────────┘
```
