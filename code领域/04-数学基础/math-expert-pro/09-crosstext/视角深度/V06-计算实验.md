## ⚠️ 失败边界 + 元批判

### 何时不适用 V06？
- **存在性证明**：可能无法算法化（如 Cantor 对角线）
- **不可判定**：停机问题无法验证
- **超限数学**：实数集合无法在计算机中精确表示

### 元批判
**V06 的危险**：**数值实验 ≠ 严格证明**——浮点数误差可能误导。或者**陷入编程细节**——忘记了数学本身。或者**伪深度**——跑通代码 ≠ 真懂。

## 💻 实战代码

```python
# V06 完整流程：以 Spivak 第 7 章 IVT 为例
import numpy as np
import sympy as sp
import matplotlib.pyplot as plt

# 1. 定理陈述
print("IVT: f 在 [a,b] 连续, f(a)*f(b) < 0 → ∃c, f(c)=0")

# 2. 算法化：二分查找
def bisect_ivt(f, a, b, tol=1e-10):
    if f(a) * f(b) > 0:
        return None  # IVT 失效
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) < 0: b = m
        else: a = m
    return (a + b) / 2

# 3. 数值验证
f = lambda x: x**2 - 2
root = bisect_ivt(f, 0, 2)
print(f"√2 的数值根: {root}")  # 1.41421356...
print(f"验证: {root**2}")  # 2.0000...

# 4. 符号验证（SymPy）
x = sp.Symbol('x')
sym_root = sp.solve(x**2 - 2, x)
print(f"SymPy 符号根: {sym_root}")  # [-√2, √2]

# 5. 可视化
xs = np.linspace(0, 2, 100)
plt.plot(xs, f(xs), label='x² - 2')
plt.axhline(0, color='black', linewidth=0.5)
plt.plot([root], [0], 'ro', label=f'根 ≈ {root:.4f}')
plt.legend(); plt.title('V06 计算实验: IVT 验证'); plt.savefig('V06_IVT.png', dpi=100)
```
