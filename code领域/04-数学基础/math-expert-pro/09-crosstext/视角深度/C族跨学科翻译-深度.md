## V12 Curry-Howard 翻译 · "命题 = 类型，证明 = 程序"

### 本质
**20 世纪最深洞察之一**：数学证明与计算机程序是**同一事物的两面**。V12 让你把数学定理翻译成代码——证明的"计算内容"被显化。

### 大师参考
- **Curry 1934 / Howard 1969**（命题-类型对应）
- **Per Martin-Löf**（直觉类型论）
- **Coquand-Huet**（Calculus of Constructions）
- **Wadler**《Theorems for Free》
- **Asperti**（数学形式化）

### 在 475 本中的深度应用

| 数学 | 程序 | 书 |
|------|-----|----|
| 命题 A | 类型 A | 数理逻辑 |
| $A \to B$ | 函数类型 | 全部 |
| $A \land B$ | 积类型 $A \times B$ | 同调 |
| $A \lor B$ | 和类型 $A + B$ | 离散 |
| $\exists x. P(x)$ | Σ 类型（依赖对）| 同伦类型论 |
| $\forall x. P(x)$ | Π 类型（依赖函数）| 类型论 |
| $\neg A$ | $A \to \bot$ | 直觉主义 |
| 归纳法 | 结构递归 | Lean |

### 深度方法论
1. **命题类型化**：定理 = 类型
2. **证明算法化**：构造该类型的项
3. **extract 程序**：从证明提取程序
4. **反向**：从程序写证明
5. **依赖类型**：用 Σ / Π 表达全称/存在

### 失败边界
- ❌ **经典数学**排中律不直接 Curry-Howard
- ⚠️ 翻译可能"失真"

### 协同
- **V12 + V13**：Curry-Howard + Lean 实操
- **V12 + V8**：类型论 = 范畴论的 internal language

### 实战（Lean 4）
```lean
-- V12: 证明 = 程序
theorem modus_ponens (A B : Prop) (h1 : A → B) (h2 : A) : B := h1 h2
-- h1 是函数，h2 是 A 的项，应用即得 B
```

### 独家切面
**只有 V12 能照出**：证明的"计算内容"——纯数学证明隐藏的可执行部分。

## V13 Lean 形式化 · "机器严格 > 人类严格"

### 本质
**Lean 4 + Mathlib4 是当代数学形式化的黄金标准**。V13 让每个定理在机器里"绝对严格"——比人类证明严格 100 倍。

### 大师参考
- **Leonardo de Moura**（Lean 创始人）
- **Kevin Buzzard**（Imperial College，用 Lean 教本科）
- **Terence Tao**（2023 起用 Lean 形式化）
- **Peter Scholze**（用 Lean 验证凝聚态数学）
- **Mathlib Community**（500+ 贡献者）

### 在 475 本中的深度应用

| 书 | 章节 | Mathlib 路径 |
|----|------|-----------|
| Spivak Calculus | IVT | `Mathlib.Topology.Continuity.IntermediateValue` |
| LADR Axler | 谱定理 | `Mathlib.LinearAlgebra.Eigenspace.*` |
| Halmos GTM018 | 测度 | `Mathlib.MeasureTheory.*` |
| 现代基础 014 | ODE | `Mathlib.ODE.*` |
| 现代基础 029 | 同调 | `Mathlib.CategoryTheory.Abelian.*` |
| GTM052 Hartshorne | 概形 | `Mathlib.AlgebraicGeometry.Scheme` |
| GTM113 | 布朗运动 | `Mathlib.MeasureTheory.Measure.Gaussian` |
| GTM082 Bott-Tu | de Rham | `Mathlib.Geometry.Manifold.*` |

### 深度方法论
1. **找 Mathlib 对应**：用 `gh-grep` 搜
2. **读 API 文档**：mathlib4_docs
3. **形式化定义**：写 `structure` / `class`
4. **形式化证明**：用 `theorem` / `lemma`
5. **代码高尔夫**：压缩证明

### 失败边界
- ⚠️ Mathlib 未覆盖所有数学（如随机分析进展慢）
- ⚠️ 形式化耗时（证明 1 页可能要 1 周）

### 协同
- **V13 + V12**：Lean 是 Curry-Howard 的实操
- **V13 + V8**：Mathlib 大量用范畴论

### 实战（你的项目）
`../math/lean4demo/` 已搭建。每周形式化 1 个定理。

### 独家切面
**只有 V13 能照出**：定理的"机器可验证性"——人类盲点的暴露。
