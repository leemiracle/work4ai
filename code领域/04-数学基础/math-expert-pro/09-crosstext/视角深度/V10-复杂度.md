## 🌌 哲学根基

**每个数学对象问：构造/判定/枚举/计数它属于什么复杂度类？** V10 把数学与计算机科学绑定——可计算性 / 复杂度 / 不可判定。

哲学：**真理的可获得性**——一个数学对象不只是"存在"，而是"多容易构造"。P / NP / PSPACE / EXPTIME / 不可判定 = 可获得性的阶层。

## 📜 发展史关键节点

- **1936 Turing**：停机问题不可判定
- **1965 Edmonds**：P 类定义

## 🔧 完整方法论（10 步）

1. **可判定？** 能否在有限步判定
2. **复杂度类**：P / NP / coNP / PSPACE / EXPTIME
3. **规约**：从已知 NP 难题规约（CIRCUIT-SAT / 3-SAT）
4. **算法**：是否存在多项式算法？
5. **复杂度下界**：证明不存在更快算法
6. **随机化**：BPP / RP / ZPP
7. **量子化**：BQP（Shor / Grover）
8. **交互式证明**：IP = PSPACE（Shamir 1990）
9. **近似**：PTAS / APX / 不可近似（PCP 定理）
10. **元层**：P vs NP（千禧问题）

## ⚠️ 失败边界 + 元批判

### 何时不适用 V10？
- **纯理论数学**（如范畴论）难分复杂度
- **连续数学**（如实分析）复杂度理论不直接适用
- **本科阶段**：本科数学多不涉及复杂度

### 元批判
**V10 的危险**：**伪深度**——贴个 P/NP 标签看似深刻，实则空洞。或者**未证命题当定理**（如 P≠NP 未证）。

```python
# V10 验证 TSP 是 NP-hard
# 给定完全图 + 边权，求最短 Hamilton 圈
import itertools

def tsp_bruteforce(dist):
    """O(n!) 暴力"""
    n = len(dist)
    return min(
        sum(dist[cities[i]][cities[i+1]] for i in range(n-1)) + dist[cities[-1]][cities[0]]
        for cities in itertools.permutations(range(n))
    )

# 5 城市
dist = [
    [0, 2, 9, 10, 7],
    [2, 0, 6, 4, 12],
    [9, 6, 0, 8, 5],
    [10, 4, 8, 0, 3],
    [7, 12, 5, 3, 0]
]
print(f"TSP 最短: {tsp_bruteforce(dist)}")  # O(5!) = 120
print(f"n=20 时 O(20!) ≈ 2.4 × 10^18——爆炸")
```
