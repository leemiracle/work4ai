## 🌌 哲学根基

**代数是几何的语言，几何是代数的图像**。这是 20 世纪数学最深洞察——任何代数陈述都对应几何直观，反之亦然。V07 让你**双栏翻译**：左代数右几何，互相照亮。

哲学：**数学对象的本质是表征不变的**——同一个对象可以从代数/几何两种角度同时看，没有"哪一个更本质"。

## 📜 发展史关键节点

- **1637 Descartes《几何学》**：解析几何诞生，代数 ↔ 几何统一
- **1860s Riemann**：黎曼面，几何 + 复分析

- **2010s Mirror Symmetry**：弦理论中的代几对偶巅峰

## 💻 实战代码

```python
# V07 双栏翻译：SVD 的代几对偶
import numpy as np
import matplotlib.pyplot as plt

A = np.array([[2, 1], [1, 3]])  # 正定矩阵
U, S, Vt = np.linalg.svd(A)

# 代数栏
print(f"代数：A = U Σ V^T")
print(f"U = {U}\nΣ = diag({S})\nV^T = {Vt}")

# 几何栏：画椭圆
theta = np.linspace(0, 2*np.pi, 100)
unit_circle = np.array([np.cos(theta), np.sin(theta)])
ellipse = A @ unit_circle

plt.figure(figsize=(6, 6))
plt.plot(unit_circle[0], unit_circle[1], 'b--', label='单位圆')
plt.plot(ellipse[0], ellipse[1], 'r-', label='A 作用后（椭圆）')
plt.axis('equal'); plt.legend(); plt.title('V07 代几对偶: 正定矩阵 = 椭圆')
plt.savefig('V07_algebra_geometry.png', dpi=100)
# 半轴长度 = 奇异值
```

```python
# V07 黎曼几何：度量张量
# 单位圆上的诱导度量
import sympy as sp
theta = sp.Symbol('theta')
# 在极坐标 (r, theta) 下，欧氏度量 = dr² + r² dθ²
# r=1 时，诱导度量 = dθ²
# 所以单位圆的弧长 = ∫₀^θ dθ = θ
print("单位圆弧长 = θ（度量张量的几何意义）")
```
