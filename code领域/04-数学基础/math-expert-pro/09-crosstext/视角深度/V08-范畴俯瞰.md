## 🌌 哲学根基

**数学不是研究"对象"，而是研究"对象之间的关系"**。范畴论（Eilenberg-Mac Lane 1945）是数学的"元语言"——它不关心"什么是群"，而关心"群与群之间的关系（同态）"。

V08 让你跃迁到**结构层**——每个具体构造（积/和/张量积）都问："它的**泛性质**是什么？它是哪个**伴随**对的单位/余单位？" 这把数学从"具体计算"提升到"普适结构"。

哲学：**数学的本质不在对象，而在关系**。Yoneda 引理："你是什么 = 你做什么"。

## 🔧 完整方法论（10 步）

1. **找范畴**：对象 + 态射是什么？（如 Set / Grp / Top / R-Mod）
2. **找函子**：到其他范畴的"保持结构映射"
3. **找自然变换**：函子之间的"映射的映射"
4. **找泛性质**：这个构造是哪个泛性质的解？
5. **找伴随**：F ⊣ G？单位 η / 余单位 ε 是什么？
6. **Yoneda 引理**：嵌入 $\text{Hom}(-, X)$ 完全决定 X
7. **极限/余极限**：积/直和/反向/正向 = 各种极限
8. **导出函子**：左右导出 Ext/Tor 的"导数"对应
9. **高阶范畴**：n-范畴 / (∞,1)-范畴（现代）
10. **内部语言**：每个范畴有 topos / 类型论作为内部语言

## ⚠️ 失败边界 + 元批判

### 何时不适用 V08？
- **本科阶段慎用**：先 V4 最小例再 V8 范畴
- **应用数学**：工程通常不需要范畴
- **算法分析**：用 V10 复杂度更直接

### 元批判
**V08 的危险**：**过度抽象**（abstract nonsense）——范畴论绰号"general abstract nonsense"，可能脱离具体。或者**炫技性范畴化**——把简单问题复杂化。
