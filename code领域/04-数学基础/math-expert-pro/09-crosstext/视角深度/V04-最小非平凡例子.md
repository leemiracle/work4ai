## 🌌 哲学根基

**真理的骨架在最小非平凡例子中显形**。n=2, dim=2, |G|=2——再小就 trivial，再大就冗余。最小非平凡例子是**直觉与严格的桥梁**：足够具体让你看见结构，足够抽象让你推广。

V04 的哲学：**所有一般真理都是对最小例子的"自然推广"**。理解 n=2，你就理解了 n=k；理解 dim=2，你就理解了 dim=n。数学家的工作是"在最小例子里看见无穷"。

## 🎓 大师方法

### Paul Erdős
方法："**3 个例子原则**"——任何定理发表前，先用 3 个不同例子（trivial / instructive / non-trivial）验证。

### George Pólya（《怎样解题》）
方法："**简化 + 类比 + 推广**"——遇到难题，先解最简单的版本，然后类比回原问题。

### John Conway
方法："**游戏驱动**"——把抽象数学转化为最小游戏（如 Conway 的 surreal numbers，源于围棋类游戏）。

### Terence Tao
方法："**两步法**"：①在 dim=2 / n=2 上手算验证 ②推广到一般情形。

### Tim Gowers（《数学：一个非常简短的导论》）
方法："**定义什么算"理解"**"——理解 = 能给最小例 + 能推广 + 能反例。

## 🔧 完整方法论（10 步）

1. **找最小例**：n=2 / dim=2 / 3 顶点图 / 2 元群
2. **手算验证**：定理在最小例上是否成立？
3. **可视化**：画图（几何 / 网络 / 矩阵）
4. **找临界规模**：n=k 成立但 n=k+1 失败吗？
5. **类比推广**：从 n=2 到 n=k 的"自然"路径
6. **反例对比**：trivial vs instructive vs non-trivial
7. **代数化**：把最小例转化为代数符号
8. **抽象化**：剥离具体数字，留下结构
9. **跨学科应用**：最小例在其他领域长什么样？
10. **教学应用**：用最小例讲比用一般定义讲更有效

## ⚠️ 失败边界 + 元批判

### 何时不适用 V04？
- **概率极限定理**：CLT 的最小例不显化收敛
- **不可数结构**：n=2 vs n=∞ 跳跃太大
- **范畴论**：最小范畴（如 1 对象 1 态射）过于 trivial

### 元批判
**V04 的危险**：**最小例可能误导**——例如 $n=2$ 群都是 Abel，让人误以为所有群都 Abel。或者**陷入 triviality**——永远停在 n=2，不敢推广。

## 💻 实战代码

```python
# V04 验证：在 2x2 矩阵上跑全部线性代数
import numpy as np

A = np.array([[0, 1], [1, 0]])  # 反射矩阵
# 特征值
eigenvalues, eigenvectors = np.linalg.eig(A)
print(f"特征值: {eigenvalues}")  # [1, -1]
print(f"特征向量: \n{eigenvectors}")

# SVD
U, S, Vt = np.linalg.svd(A)
print(f"SVD: U={U}, S={S}, V={Vt}")

# 行列式
print(f"行列式: {np.linalg.det(A)}")  # -1

# 谱分解
print(f"A = U @ diag(eig) @ U^T: {U @ np.diag(eigenvalues) @ U.T}")
```

# V04 验证：在 S^1 上算 de Rham 上同调
# S^1 = [0, 2π] / ~, 1-form = f(x) dx
# 闭形式: df = 0 → f = const
# 恰当形式: f = dg → ∫f dx = 0
