## V25 真实数据 · "用 Python 拟合真实世界"

### 本质
**每个数学定理 → 真实数据拟合**。V25 让数学从"教科书符号"变成"解释世界的工具"。

### 大师参考
- **Tukey**（探索性数据分析 EDA）
- **Tufte**《量化信息的视觉展示》
- **Hadley Wickham**（tidyverse）
- **Nate Silver**《信号与噪声》
- **Claude Shannon**（信息论的真实数据根基）

### 在 475 本中的深度应用

| 书 | 数据源 | Python 实操 |
|----|------|------|
| 现代基础 092 传染病 | COVID Our World in Data | scipy.odeint |
| 华章 51 Ross | 掷骰子 / SAT 分数 | numpy.random |
| 华章 71 凸优化 | Markowitz 1952 | cvxpy |
| GTM113 Karatzas-Shreve | 股价布朗 | yfinance |
| GTM113 | 蒙特卡洛期权 | numpy |
| 现代基础 080 排队论 | 地铁到站 | pandas |
| GTM173 图论 | Twitter 网络 | networkx |
| 华章 19 小波 | 心电图 | pywt |

### 深度方法论（5 步）
1. **找数据**：公开数据集（OWID / Kaggle / FRED）
2. **数学模型**：定理/方程/分布
3. **Python 拟合**：scipy / numpy / sklearn
4. **残差分析**：拟合优度 + 系统偏差
5. **报告**：参数 + 误差 + 图表

### 失败边界
- ⚠️ **不要伪造数据**——所有数据可溯源
- ⚠️ **不要混淆相关与因果**
- ⚠️ 小样本误导

### 协同
- **V25 + V9**：真实数据 + 物理直觉
- **V25 + V14**：真实数据 + ML

### 实战
每周做 1 个真实数据拟合 notebook。

### 独家切面
**只有 V25 能照出**：数学的"实证有效性"——理论 vs 现实。

## V26 失败案例 · "数学误用 → 真实灾难"

### 本质
**抽象数学被误用时，现实崩塌**。V26 让数学**警示**——每个定理都配一个"血泪案例"。

### 大师参考
- **Charles Perrow**《正常事故》
- **Nassim Taleb**《黑天鹅》
- **Diane Vaughan**《挑战者号发射决策》
- **Scott Page**《模型失误》
- **N. N. Taleb**（反脆弱）

### 在 475 本中的深度应用

| 灾难 | 数学误用 | 损失 | 书 |
|------|--------|------|----|
| Sally Clark 1999 | 乘法独立误用 | 母亲冤狱 3 年 | Ross 概率 |
| LTCM 1998 | Black-Scholes 假设 | $46 亿 | GTM113 |
| 2008 次贷 | Li 高斯 Copula | 全球 $22 万亿 | GTM113 |
| Knight Capital 2012 | 算法错误 | $4.4 亿（45 分钟）| 离散 |
| London Whale 2012 | CDS 模型错 | JPM $62 亿 | GTM113 |
| Madoff 2008 | 概率伪造 | $65 亿 | Ross |
| Imperial Ferguson 2020 | SIR 参数 | 英国封城 | 现代基础 092 |
| Vioxx 2004 | 心脏概率低估 | 6 万人死亡 | 概率 |
| Theranos 2018 | 统计学造假 | $9 亿 | 全部 |
| 挑战者号 1986 | 贝叶斯忽略 O-ring | 7 人 | 贝叶斯 |

### 深度方法论
1. **找灾难**：何时何地崩了
2. **数学误用**：具体哪个定理/假设错了
3. **认知偏差**：为什么当时误用
4. **正确做法**：事后改进
5. **学习启示**：当前数学要学到什么程度

### 失败边界
- ⚠️ **不要简化归因**（灾难是多因素）
- ⚠️ **不要事后诸葛亮**（当时认知有限）

### 协同
- **V26 + V18**：失败 + 不可能性
- **V26 + V28**：失败 + 社会系统

### 实战
配 `07-critique/`，10 个失败案例档案。

### 独家切面
**只有 V26 能照出**：数学的"反面教材"——误用的代价。

## V28 社会系统 · "数学支撑城市/电网/金融"

### 本质
**每个理论支撑哪个社会子系统**。V28 让数学**系统化**——从个体到社会的依赖链。

### 大师参考
- **Donella Meadows**《系统思考》
- **Jay Forrester**《城市动力学》
- **Nassim Taleb**《反脆弱》
- **James Gleick**《混沌》
- **社系统分析师**（IPCC / NERC / BIS）

### 在 475 本中的深度应用（参见 30 系统映射）

| 社会系统 | 数学 | 真实规模 | 书 |
|---------|------|--------|----|
| SCOOT 交通 | 排队论 | 350+ 城市 | 现代基础 080 |
| COVID 决策 | SIR 模型 | 全球 | 现代基础 092 |
| Black-Scholes | Itô 引理 | $600T | GTM113 |
| 全球电网 | 动力系统 + 优化 | NERC | 现代基础 080 |
| Amazon 物流 | TSP + 图论 | 全球 | GTM173 |
| 5G 通信 | 信息论 | 全球 | GTM134 |
| 半导体 | 偏微分方程 | 台积电 | 现代基础 019 |
| Netflix | SVD + 协同过滤 | 100M 用户 | 华章 52 |
| 比特币 | 椭圆曲线 | $1T | GTM106 |
| AlphaFold | 黎曼几何 | Nobel 2024 | GTM171 |

### 深度方法论
1. **找系统**：哪个城市/国家/行业
2. **数学模型**：方程 / 算法
3. **真实参数**：R₀ / σ / ρ
4. **失效后果**：数学失效时崩成什么
5. **依赖链**：数学 → 职业 → 决策 → 社会
6. **政策启示**：公民/决策者该懂什么

### 失败边界
- ⚠️ **不要简化系统**（社会是耦合的）
- ⚠️ **不要忽视人**（决策者 + 数学）

### 协同
- **V28 + V15**：社会 + 工程出口
- **V28 + V26**：社会 + 失败案例

### 实战
配 `12-社会系统/`，每个系统写 1 页档案。
