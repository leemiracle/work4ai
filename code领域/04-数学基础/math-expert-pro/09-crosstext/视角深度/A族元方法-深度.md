## V1 反例驱动 · "先读为什么不能更弱"

### 本质
**反向构造的艺术**：每个数学陈述都是"边界条件 + 主体"——视角 V1 强迫你先**拆掉每个假设**，看定理崩成什么，从而反推出"为什么这条假设用血换来的"。

### 大师参考
- **B. Riemann**（解析 + 几何反例思维）
- **K. Weierstrass**（处处不可导连续函数 1872）
- **G. Cantor**（用反例推翻直觉：可数/不可数）
- **Lakatos**《证明与反驳》1976：反例驱动数学进步

### 在 475 本中的深度应用

| 书 | 章节 | V1 启动 | 反例 |
|----|------|--------|------|
| Spivak Calculus | Ch.7 IVT | 删"连续"假设 | $\text{sign}(x)$ 跳过 0 |
| 现代基础 066 | 全本 | 删各 $T_i$ 公理 | 反例族谱 |
| GTM052 Hartshorne | 概形 | 删 Noether 假设 | 病态非 Noether |
| GTM113 Karatzas-Shreve | Itô 积分 | 删"adapted" 假设 | 信息泄漏 |
| 华章 51 Ross 9e | CLT | 删"独立同分布" | 重尾不收敛 |

### 深度方法论（5 步）
1. **陈述原版**：写下定理全文
2. **假设清单**：列出每条假设
3. **逐条删除**：每删一条，找一个反例
4. **反例等级**：trivial / instructive / pathological
5. **反推必要性**：每条假设 = 防哪个反例

### 失败边界
- ❌ 不要对**纯构造性证明**用 V1（没有"假设"可删）
- ❌ 不要对**算法**用 V1（用 V10 复杂度）
- ⚠️ 反例过多会**稀释主旨**——V1 + V17 区别：V1 是"假设反推"，V17 是"反例族"

### 协同
- **V1 + V17**：假设反推 + 反例库 = 完整闭环
- **V1 + V2**：删假设 → 删公理，自然延伸
- **V1 + V5**：每个反例对应 Tao 哪一阶失败

### 实战（Python）
```python
# V1 验证 IVT 删"连续"假设
import numpy as np
def sign(x): return np.where(x > 0, 1, np.where(x < 0, -1, 0))
xs = np.linspace(-1, 1, 100)
print(sign(xs))  # 跳过 0，IVT 失效
```

### 独家切面
**只有 V1 能照出**："这条假设为什么存在"——其他视角看主体，V1 看边界。

## V2 公理逆向 · "每个公理都是墓碑"

### 本质
**公理不是起点，是教训的终点**。V2 视角把每条公理当作**数学家付血代价换来的**——墓碑下埋着"曾经认为不证自明但被反例推翻的命题"。

### 大师参考
- **Hilbert**《几何基础》1899（首次系统公理化）
- **Gödel**（不完备：公理系统本身的边界）
- **Bourbaki**（结构主义公理化）
- **Tarski**（真理定义）

### 在 475 本中的深度应用

| 书 | 公理 | 反例碑文 |
|----|------|--------|
| Spivak Calculus | P1-P13 实数公理 | $\mathbb{Q}$ 上 IVT 失败 |
| LADR Axler | 向量空间 8 公理 | 删"加法交换" → 非 Abel 群 |
| GTM018 Halmos | 测度 σ-可加 | 不可数可加 → 病态 |
| 现代基础 036 公理集合论 | 选择公理 | Banach-Tarski 悖论 |
| GTM005 Mac Lane | 范畴公理 | "全体范畴"不是范畴 |

### 深度方法论
1. **公理清单**：列出系统的所有公理
2. **历史考证**：每条公理何时被加？谁加的？为什么？
3. **反例碑文**：删公理 → 找反例
4. **替代公理**：能否用更弱的公理得到同样结论？
5. **元层反思**：这个公理系统是否 Gödel 不完备？

### 失败边界
- ❌ **本科阶段慎用**：本科书公理已是最优
- ⚠️ 公理逆向耗时——只对**关键公理**用

### 协同
- **V2 + V18**：公理 → 不可能性边界（Gödel）
- **V2 + V19**：公理 → 替代范式（非标准分析）

### 实战（Lean）
```lean
-- V2 验证：删掉 commutativity 公理后的"向量空间"
class NonCommVectorSpace (K : Type*) extends Ring K ...
```

### 独家切面
**只有 V2 能照出**：公理的"历史教训"维度。

## V3 历史发生学 · "作者当年怎么想出来的"

### 本质
**成书顺序 ≠ 思想发生顺序**。V3 视角重走"作者当年的错路"——理解一个概念最快的方式，是看**历史上聪明的头脑怎么想错的**。

### 大师参考
- **Lakatos**《证明与反驳》
- **Hadamaard**《数学领域中的发明心理学》
- **Klein**《古今数学思想》
- **Friedrichs**（数学发生学）

### 在 475 本中的深度应用

| 书 | V3 启动 | 历史路径 |
|----|--------|---------|
| 通俗译丛 14《无穷之旅》| 全本 | 芝诺→Cantor→Gödel |
| 通俗译丛 11《数：科学的语言》| 全本 | 印度 0 → 欧洲 200 年拒绝 |
| 通俗译丛 09《计算出人意料》| 开普勒章 | Mars 900 页计算 |
| Spivak Calculus | 极限章 | Cauchy 1821 误证 IVT |
| GTM060 Arnold | 全本 | Hamilton → Poincaré → Arnold |

### 深度方法论
1. **现代陈述**：写下今天教科书的版本
2. **历史考古**：原始论文是哪年？作者当时在想什么？
3. **错路重建**：第一版是怎么错的？
4. **修正轨迹**：谁修正了？怎么修正的？
5. **历史反事实**：如果 X 没生，会推迟多久？

### 失败边界
- ❌ **研究级专著不适合**（如 Hartshorne，已经"最终态"）
- ⚠️ 历史容易**浪漫化**——必须用一手论文校对

### 协同
- **V3 + V19**：历史 + 替代范式 = 范式演化
- **V3 + V21**：历史 + 审美 = 美的演化

### 实战
读 Cantor 1874 原文 + 重做对角线论证 + 写"假如 Cantor 没生"反事实短文。

### 独家切面
**只有 V3 能照出**：思想的"时间深度"。

## V4 最小非平凡例子 · "n=2 还成立吗"

### 本质
**所有数学陈述，先用 n=2, dim=2, |G|=2 跑一遍**。最小非平凡例子（既不 trivial 也不复杂）是**直觉与严格的桥梁**。

### 大师参考
- **Erdős**（"证明前先举 3 个例子"）
- **Polyá**《怎样解题》
- **Tao**（博客常从最小例开始）
- **Conway**（用小例子驱动）

### 在 475 本中的深度应用

| 书 | V4 启动 | 最小例 |
|----|--------|------|
| 华章 52 Horn-Johnson | 全本 | 2×2 矩阵手算 |
| LADR | 全本 | $\mathbb{R}^2$ 抽象 |
| 现代基础 029 同调 | Ext¹ | $A = \mathbb{Z}/2$ |
| GTM082 Bott-Tu | de Rham | $S^1$ 上同调 |
| 华章 51 Ross | 全本 | 抛 2 硬币 |
| GTM052 Hartshorne | 概形 | $\text{Spec}(\mathbb{Z})$ |

### 深度方法论
1. **找最小例**：n=2 / dim=2 / 3 顶点图
2. **手算验证**：定理在小例上是否成立
3. **找临界规模**：n=2 成立，n=3 失败吗？
4. **可视化**：画图/几何/网络
5. **抽象化的"啊哈"**：小例如何"代表"一般情况

### 失败边界
- ❌ **概率极限定理**（CLT）：小例不显化收敛
- ⚠️ 小例有时**误导**（如 $n=2$ 群都是 Abel）

### 协同
- **V4 + V6**：最小例 + 计算实验
- **V4 + V22**：小例 → 费曼讲解

### 实战
所有数学概念都先在 2 维 / 2 元素上验证。

### 独家切面
**只有 V4 能照出**："定理的骨架"——剥离了一般性的内核。

## V5 严格度光谱 · "Tao 三阶自检"

### 本质
**Tao 三阶**：pre-rigorous（直觉+图像）→ rigorous（ε-δ + 公理化）→ post-rigorous（直觉+严格）。
V5 让你**实时标注当前在哪一阶**，避免"卡死"或"飘忽"。

### 大师参考
- **Terence Tao**《What is good mathematics?》2007
- **Arnold**（永远在 post-rigorous）
- **Bourbaki**（永远在 rigorous）
- **Lockhart**（永远在 pre-rigorous）

### 在 475 本中的深度应用

| 阶段 | 书 | 严格度 |
|------|----|----|
| pre-rigorous | 通俗译丛 14《无穷之旅》| ⭐ |
| pre-rigorous | 3Blue1Brown | ⭐ |
| rigorous | Spivak Calculus | ⭐⭐⭐⭐ |
| rigorous | Rudin PMA（华章 01）| ⭐⭐⭐⭐ |
| rigorous | Halmos GTM018 | ⭐⭐⭐⭐⭐ |
| post-rigorous | Arnold GTM060 | ⭐⭐⭐⭐⭐ |
| post-rigorous | Hartshorne GTM052 | ⭐⭐⭐⭐⭐ |

### 深度方法论
1. **当前阶段自评**：pre / rigorous / post
2. **目标阶段**：本节需要达到哪阶？
3. **跨阶升级**：从 pre → rigorous 需要补什么？
4. **跨阶降级**：rigorous 卡住时，退到 pre 重建直觉
5. **post-rigorous 候选**：哪些概念 3 个月后回访

### 失败边界
- ⚠️ 不要永远停在 rigorous（容易僵化）
- ⚠️ 不要永远飘在 pre-rigorous（缺乏严格）

### 协同
- **V5 + V1**：每个反例在 Tao 哪阶失败？
- **V5 + V22**：post-rigorous = 费曼讲解

### 实战
每章末标注"我现在在哪阶？"

### 独家切面
**只有 V5 能照出**：你的**学习状态**而非书的内容。

## V6 计算实验 · "没用代码跑过不算懂"

### 本质
**数学 + 代码 = 双重验证**。V6 视角强迫每个定理都用 Python / Lean / Wolfram 跑一遍——代码会暴露你**以为懂了但实际不懂**的地方。

### 大师参考
- **Wolfram**《一种新科学》
- **Karpathy**（"代码是最好的老师"）
- **Tao**（用 Lean 形式化）
- **Buzzard**（Imperial College，用 Lean 教数学）

### 在 475 本中的深度应用

| 书 | V6 实操 | 工具 |
|----|--------|-----|
| Spivak Calculus | 极限数值 | SymPy limit |
| 华章 52 Horn-Johnson | SVD | numpy.linalg |
| 华章 71 凸优化 | cvxpy 求解 | cvxpy |
| 现代基础 092 传染病 | SIR odeint | scipy |
| GTM018 Halmos 测度 | Cantor 测度数值 | numpy |
| GTM113 Karatzas-Shreve | 布朗运动模拟 | numpy.random |
| 全部 | Lean 形式化 | Lean 4 + Mathlib |

### 深度方法论
1. **定理陈述**：用数学语言写下
2. **算法化**：能否转化为可计算的过程？
3. **代码实现**：Python / Lean / Wolfram
4. **数值验证**：跑几个例子
5. **失败分析**：哪类输入会让代码崩？

### 失败边界
- ❌ **存在性证明**：可能无法算法化
- ❌ **不可判定**：停机问题无法验证
- ⚠️ 数值实验 ≠ 严格证明

### 协同
- **V6 + V13**：Python 验证 + Lean 形式化
- **V6 + V12**：Curry-Howard 实证

### 实战
每周至少 1 个定理用 Python 验证。

### 独家切面
**只有 V6 能照出**："你以为懂了"的隐藏漏洞。

## A 族整体协同

```
V1 反例 ────► V2 公理
  │              │
  ▼              ▼
V5 严格度 ◄── V6 计算
              │
              ▼
            V4 最小例
              │
              ▼
            V3 历史
```

**A 族核心**：教"怎么读"——是其他 5 族的方法论根基。

### A 族 vs 其他族
- A → B（多重表征）：先 V4 最小例再 V7 对偶
- A → C（跨学科）：先 V6 计算再 V12 Curry-Howard
- A → D（批判）：先 V1 反例再 V17 反例库
- A → E（元认知）：先 V5 严格度再 V22 费曼
- A → F（现实）：先 V6 计算再 V25 真实数据
