## 🎓 大师方法

### Claude Shannon
方法："**熵 = 不确定性**"——一个分布的熵 = 编码该分布的最短平均码长。

### Andrey Kolmogorov
方法："**Kolmogorov 复杂度 = 最短描述长度**"——一个对象的"算法信息含量"。

### Edwin Jaynes
方法："**最大熵原理**"——在约束下，最不偏的分布是熵最大的。

### Naftali Tishby
方法："**信息瓶颈**"——深度学习 = 信息压缩。

### Jorma Rissanen
方法："**MDL（最小描述长度）**"——模型选择准则。

## 💻 实战代码

```python
# V11 Shannon 熵 / KL 散度
import numpy as np

def entropy(p):
    """Shannon 熵"""
    p = np.array(p); p = p[p > 0]
    return -np.sum(p * np.log2(p))

def kl_divergence(p, q):
    """KL 散度（信息损失）"""
    p = np.array(p); q = np.array(q)
    mask = (p > 0) & (q > 0)
    return np.sum(p[mask] * np.log2(p[mask] / q[mask]))

# 三个分布
p_uniform = [0.25, 0.25, 0.25, 0.25]
p_skewed = [0.7, 0.1, 0.1, 0.1]
p_peak = [0.97, 0.01, 0.01, 0.01]

print(f"均匀分布熵: {entropy(p_uniform):.2f} bit (最大)")  # 2.0
print(f"偏斜分布熵: {entropy(p_skewed):.2f} bit")  # 1.36
print(f"峰值分布熵: {entropy(p_peak):.2f} bit (最小)")  # 0.24

print(f"\nKL(p_uniform || p_skewed) = {kl_divergence(p_uniform, p_skewed):.2f} bit")
# 信息损失量化
```
