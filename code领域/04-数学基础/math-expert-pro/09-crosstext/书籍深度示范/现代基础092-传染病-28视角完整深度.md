## V06 计算 · scipy 数值
```python
from scipy.integrate import odeint
import numpy as np

def sir(y, t, beta, gamma, N):
    S, I, R = y
    return [-beta*S*I/N, beta*S*I/N - gamma*I, gamma*I]

t = np.linspace(0, 200, 1000)
sol = odeint(sir, [999, 1, 0], t, args=(0.3, 0.1, 1000))
# R0 = beta/gamma = 3
```
