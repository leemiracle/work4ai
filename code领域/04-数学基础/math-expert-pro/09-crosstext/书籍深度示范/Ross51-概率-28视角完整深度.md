## V01 反例驱动 · "假设墓碑"

**应用章**：Ch.2 公理 + Ch.8 极限定理

**Ross 的反例驱动教学**：
- 删"可加性"公理（Ch.2）→ 概率不再保持"互斥事件相加"——构造 $P(A\cup B) < P(A)+P(B)$ 反例
- 删 CLT "独立同分布"假设（Ch.8）→ 重尾分布（Cauchy）不收敛正态，反而保持重尾
- 删 CLT "方差有限"假设 → St. Petersburg 悖论的无限期望

**反例族**：
- **悖论族**：Monty Hall / 三囚犯 / Bertrand 弦——直觉与正确概率背离
- **重尾族**：Cauchy / Pareto / Lévy——CLT 失效
- **相依族**：相关样本——大数律可能失效

**产出**：写一份《概率反例族谱》存入 `06-counterexamples/`

## V02 公理逆向 · "Kolmogorov 公理的碑文"

**应用章**：Ch.2 概率公理

**Ross 的 Kolmogorov 1933 三公理**：
1. $P(A) \geq 0$
2. $P(\Omega) = 1$
3. 可数可加：$P(\cup A_i) = \sum P(A_i)$（互斥）

**逐条反推**：
- 删公理 1（非负）→ "负概率"（Feynman 1987 曾尝试，用于量子）
- 删公理 2（归一）→ "不归一测度"（用于无穷测度）
- 删公理 3（可数可加）→ **有限可加**（de Finetti 主张）—— 主观概率学派

**学派之争**：
- 频率派（von Mises）：极限频率
- **Kolmogorov 公理化派**（Ross 此书立场）
- Bayes 派（de Finetti / Savage）：主观概率
- 量子概率（von Neumann）：非交换概率

**产出**：写一份《概率公理演化史》存入 `07-critique/`

## V06 计算实验 · "用 numpy 跑遍全书"

**应用章**：全书

**Python 验证**：

```python
import numpy as np
import matplotlib.pyplot as plt

# Ch.1 组合：生日问题
def birthday(n):
    """n 人中至少 2 人同生日的概率"""
    days = 365
    p_no_match = 1
    for i in range(n):
        p_no_match *= (days - i) / days
    return 1 - p_no_match
print(f"23 人: {birthday(23):.2%}")  # 50.7%

# Ch.3 Bayes：双头硬币
P_D = 0.5  # 选双头硬币
P_H_given_D = 1; P_H_given_notD = 0.5
P_D_given_H = P_H_given_D * P_D / (P_H_given_D * P_D + P_H_given_notD * 0.5)
print(f"Bayes: {P_D_given_H:.2%}")  # 66.7%

# Ch.4 二项分布
n, p = 10, 0.5
samples = np.random.binomial(n, p, 10000)
plt.hist(samples, bins=range(n+2), density=True, alpha=0.7)

# Ch.8 CLT：10000 次掷 30 骰子和
sums = np.sum(np.random.randint(1, 7, (10000, 30)), axis=1)
plt.hist(sums, bins=50, density=True)
# 拟合正态
```

## V21 审美游戏 · "概率之美"

**应用章**：Ch.3 Bayes

## V22 费曼讲解 · "向妈讲 Bayes"

**应用章**：Ch.3

**3 分钟讲法**：
"妈，假设有个不靠谱的体温计：测 100 个真发烧的人，能测出 95 个（灵敏度 95%）；测 100 个没发烧的人，会误报 10 个（特异度 90%）。现在全中国 1% 的人真发烧。你测出'发烧'，真正发烧的概率是多少？

直觉：95%（体温计可靠）。正确：~9%。

为什么？1000 人中 10 个真发烧（测出 9.5 个）+ 990 个没发烧误报 99 个 = 108.5 个'发烧'报告，其中只有 9.5 个真的——9%。

这就是 Bayes：先验 1% × 似然 95% / 证据 10.85% = 后验 8.7%。"
