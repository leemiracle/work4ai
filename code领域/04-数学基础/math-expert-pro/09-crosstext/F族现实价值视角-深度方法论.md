### Python 验证模板

```python
# V26 通用模板：复盘一个失败案例的数学误用
def reconstruct_failure(original_model, correct_model, data):
    """
    original_model: 当时被误用的模型
    correct_model: 事后正确的模型
    data: 当时数据
    返回：误差倍数 + 灾难规模
    """
    pred_wrong = original_model(data)
    pred_right = correct_model(data)
    error_ratio = abs(pred_wrong - pred_right) / abs(pred_right)
    return error_ratio, pred_wrong, pred_right

# 示范：LTCM 1998 复盘
# 当时用 Black-Scholes 假设正态分布
# 正确：用 stable distribution（厚尾）
```
