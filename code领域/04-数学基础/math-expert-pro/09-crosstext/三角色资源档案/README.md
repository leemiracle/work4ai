## 🚀 使用流程

### 选书 → 看角色 → 查资源 → 实际学习

1. **选书**：从 [TOTAL-INDEX](../书籍索引/TOTAL-INDEX.md) 选一本
2. **看角色**：在 `三角色资源档案/{丛书}/{书名}.md` 查你的角色定位
3. **查资源**：按你的角色挑 2-3 个网络资源
4. **实际学习**：视频 + 书 + 代码 + 社区

### 例：学 Horn-Johnson 第 5 章 SVD

1. **教材路径**：3Blue1Brown 线性代数 → Horn-Johnson 第 5 章 → numpy.linalg.svd 验证
2. **工程师路径**：numpy.linalg.svd → Netflix 大赛 2009 论文 → 自己实现 SVD 推荐
3. **研究员路径**：Horn-Johnson → Mathlib.LinearAlgebra → MathOverflow 讨论
