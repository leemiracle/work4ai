## 🔧 修复：6 大分类错误 + 修复建议

### 修复 1：GTM113 Karatzas-Shreve 双重归属
- **教材**：阶段 3 量化方向
- **工程师**：量化基金必备
- **研究员**：随机分析方向圣经
→ 三角色共用，**跨角色桥梁书**典型

### 修复 2：华章 51 Ross 的双重身份
- **教材**：阶段 1 概率主线
- **工程师**：金融/AI 入门必备
→ **教材优先**

### 修复 3：通俗译丛 31 本的角色
- 大部分：教材的"品味热身"
- 但 24 Engel / 16 五大理论：研究员的"方法论参考"
→ **大部分教材，少数研究员**

### 修复 4：GTM018 Halmos 测度的角色
- **教材**：阶段 2 严格度进阶
- **研究员**：数学写作的"文风典范"
→ **教材 + 研究员双重**

### 修复 5：现代基础 066 拓扑反例
- **教材**：阶段 2 拓扑配套
- **研究员**：反例库永久工具
→ **跨阶段工具书**

### 修复 6：GTM052 Hartshorne 的角色
- **教材**：❌ 不适合教材（太难）
- **研究员**：✅ 代数几何圣经
→ **研究员专属**

```
  - 选定方向后 → 方向圣经（GTM113 / GTM052 / GTM082 / ...）
```

### 🔧 工程师学习者路径（按需查书）

```
1. 项目需求识别
   - 例：要做 Netflix 推荐 → SVD → 华章 52

2. 数学概念建立
   - 查 Horn-Johnson 相关章节
   - 不必通读

3. Python 实现
   - numpy / scipy / cvxpy
   - 配 V06 计算实验

4. 真实数据验证
   - 配 V25 真实数据

5. 失败案例警示
   - 查失败案例档案（LTCM / 2008 / ...）
```
