## 4. 何时用哪本——决策树

```
你现在在学什么概念？
│
├─ 遇到严格定义卡住（如 ε-δ / 测度）
│   ├─ 先回 🟢 入门读本（Banner / Grinberg / Miller）建直觉
│   └─ 再上 ⭐ 主用书（Spivak / Royden）啃严格
│
├─ 主用书讲法不喜欢 / 看不懂
│   └─ 换本不同风格的对照看（这正是本目录的价值）
│      ├─ 线代卡住 → Axler（抽象）↔ Horn-Johnson（矩阵）↔ Artin（代数视角）
│      ├─ 分析卡住 → Spivak（具体严格）↔ Royden（测度）↔ Rudin（经典精炼）
│      └─ 概率卡住 → Ross（直觉）↔ 现代基础 006（严格）↔ Shreve（随机）
│
├─ 需要查公式 / 定理陈述 / 反例
│   └─ 用 ▪ 工具书（Horn-Johnson / Rudin / 数学天书），不求通读
│
├─ 阶段 2 末选研究方向
│   └─ 看 [05-GTM与现代基础丛书使用指南](05-GTM与现代基础丛书使用指南.md)
│      翻 5 个方向各 1 本 GTM，看哪本翻开最想读
│
└─ 想看"漂亮的证明" / 找回趣味
    └─ Aigner-Ziegler 数学天书 / 柯朗 / 3Blue1Brown
```
