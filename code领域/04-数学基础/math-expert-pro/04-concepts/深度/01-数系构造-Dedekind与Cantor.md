# 数系构造：Dedekind切割与Cantor基本列

> 从自然数到实数的两条严格构造路径。

## 路径一：Dedekind切割（1872）
把有理数 Q 按"切割"分成两部分 (A,B)，A 中所有元素 < B 中所有元素。
每个切割定义一个实数。有理切割→有理数；无理切割（如 {q: q²<2}）→无理数。

**关键定理**：Dedekind完备化 → 每个有界单调序列有极限 → 微积分的基础。

## 路径二：Cantor基本列（1872）
把有理数的基本列（Cauchy序列）的等价类定义为实数。
{qₙ}~{q'ₙ} 当 |qₙ-q'ₙ|→0。

**优势**：自然推广到度量空间的完备化（Banach空间的构造）。

## 从N开始的一切
- N：Peano公理（0, 后继 S, 归纳）
- Z：N×N 的等价类（(a,b)~(c,d)当 a+d=b+c）
- Q：Z×(Z\{0}) 的等价类
- R：Q 的 Dedekind 切割 / 基本列等价类
- C：R×R 配运算 (a,b)(c,d)=(ac-bd,ad+bc)
- H（四元数）：C×C 配非交换乘法

## 为什么需要这么多层？
每层解决上一层的"不完整性"：
- Z 解决 N 不能减
- Q 解决 Z 不能除
- R 解决 Q 有"缝隙"（√2 不在 Q 中）
- C 解决 R 的多项式不一定有根
- H 解决 C 不能表示 3D 旋转（但放弃交换律）

## 超越R的扩展
- p进数 Qp：用 p 进赋值完备化（与 R 截然不同的"距离"）
- 超实数 *R：含无穷小的非标准分析（Robinson 1960）
- Surfectural numbers：Conway 的超现实数（包含所有实数+无穷大+无穷小）
