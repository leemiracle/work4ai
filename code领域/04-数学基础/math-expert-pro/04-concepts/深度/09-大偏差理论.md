# 大偏差理论

> "极端事件有多罕见？"——精确量化小概率事件的数学。

## Cramér 定理
对独立同分布 Xᵢ，P(Sₙ/n ≈ x) ≈ e^{-nI(x)}
其中 I(x) = sup_θ [θx - log E(e^{θX})]（Cramér泛函/速率函数）

→ 偏离均值的概率**指数衰减**，衰减率由 I(x) 决定。

## Sanov 定理
经验分布偏离真实分布的概率：
P(μ̂ₙ ≈ ν) ≈ e^{-n D_KL(ν‖μ)}
→ KL 散度 = 经验分布的速率函数

## 应用
1. **统计假设检验**：p值 ≈ e^{-nI}（大偏差给出精确渐近）
2. **压缩感知**：RIP 以高概率成立 = 大偏差论证
3. **信息论**：信道编码定理 = 大偏差的特例
4. **统计物理**：相变 = 大偏差函数的非解析性
5. **机器学习**：泛化界 = 训练误差偏离真实误差的大偏差

## Gärtner-Ellis 定理（推广）
对非独立序列，用 lg E(e^{θSₙ})/n 的极限 Λ(θ)：
I(x) = sup_θ [θx - Λ(θ)]
→ 适用于 Markov 链、混合过程等
