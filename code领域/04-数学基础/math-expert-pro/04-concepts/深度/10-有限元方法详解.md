# 有限元方法（FEM）：PDE 数值解的王者

> 从桥梁到飞机到心脏模拟——FEM 是工程计算的基石。

## 变分形式
椭圆 PDE -∇·(a∇u) = f 的弱形式：
找 u ∈ V 使 a(u,v) = l(v) ∀v ∈ V
其中 a(u,v) = ∫ a∇u·∇v（双线性型），l(v) = ∫fv（线性泛函）

## Galerkin 离散化
取有限维子空间 Vₕ ⊂ V（分片多项式）：
找 uₕ ∈ Vₕ 使 a(uₕ,vₕ) = l(vₕ) ∀vₕ ∈ Vₕ
→ 变成线性方程组 Kx = F（K=刚度矩阵）

## 误差估计
Céa 引理：‖u-uₕ‖ ≤ (M/α) inf_{vₕ∈Vₕ} ‖u-vₕ‖
→ 误差 = 最优逼近 × 条件数比

## 单元类型
| 维度 | 单元 | 形函数 | 连续性 |
|------|------|--------|--------|
| 1D | 线段 | 线性/二次 | C⁰ |
| 2D | 三角形 | P1/P2 | C⁰ |
| 2D | 四边形 | Q1/Q2 | C⁰ |
| 3D | 四面体 | P1/P2 | C⁰ |
| 混合 | RT/BDM | 混合阶 | C⁰(法向) |

## 自适应有限元（AFEM）
标记 → 细化 → 求解 → 重复
误差估计子：η_K² = h_K² ‖f + Δuₕ‖²_{L²(K)}
→ 自动在需要的地方加密网格

## 高性能FEM
- hp-自适应：同时调网格(h)和阶数(p)
- 区域分解：FETI/BDDC（并行）
- GPU 加速：矩阵组装+求解
