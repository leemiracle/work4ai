# 镜像对称：弦论送给数学的礼物

> 物理学家的"猜想"变成了数学家的定理——Fields级工作。

## 基本思想
Calabi-Yau 三维流形 X 存在"镜像" X̂，使得：
- X 的 symplectic 几何 = X̂ 的 complex 几何
- I₁(X) = I₁(X̂) （在某种意义上交换）

## 数学影响
1. **枚举几何**：计算曲线计数的不变量（Gromov-Witten 不变量）
2. **同调镜像对称**（Kontsevich 1994 Fields）：D^b Coh(X) ≅ Fuk(X̂)
3. **量子上同调**：变形经典上同调环

## SYZ 猜想（Strominger-Yau-Zaslow 1996）
X 和 X̂ 都有特殊拉格朗日 T³ 纤维化 → 镜像是 T-对偶
→ 几何解释了镜像对称
