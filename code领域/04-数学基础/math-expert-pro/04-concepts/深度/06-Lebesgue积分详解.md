# Lebesgue 积分：测度论的胜利

> Riemann 积分的彻底革新——"分割值域而非定义域"。

## Lebesgue vs Riemann
| 维度 | Riemann | Lebesgue |
|------|---------|----------|
| 分割 | x 轴（定义域）| y 轴（值域）|
| 适用 | "好"函数 | 可测函数 |
| 极限交换 | 需一致收敛 | 控制收敛即可 |
| 完备性 | L¹(Riemann)不完备 | L¹(Lebesgue)完备 |

## 三大收敛定理
1. **单调收敛**：fₙ↑f, fₙ≥0 → ∫fₙ→∫f
2. **Fatou 引理**：∫liminf fₙ ≤ liminf ∫fₙ
3. **控制收敛（DCT）**：|fₙ|≤g, fₙ→f a.e. → ∫fₙ→∫f

→ DCT 是概率论和PDE中最常用的工具

## 可测函数
f 可测 ⟺ {f > a} 可测 ∀a
- 连续函数可测
- 可测函数的极限可测
- 可测函数的和/积/复合可测

## Lp 空间
Lᵖ(μ) = {f : ∫|f|ᵖdμ < ∞}，范数 ‖f‖ₚ = (∫|f|ᵖdμ)^{1/p}
- p=2 → Hilbert 空间（量子力学/PDE/信号处理）
- p=1 → 概率密度函数
- p=∞ → 本质有界函数
- Hölder 不等式：‖fg‖₁ ≤ ‖f‖ₚ ‖g‖_q（1/p+1/q=1）
