# Sobolev 空间：现代PDE的语言

> 弱解理论的基础——让 PDE "可解"的关键抽象。

## 定义
W^{k,p}(Ω) = {f ∈ Lᵖ(Ω) : 弱导数 ∂^α f ∈ Lᵖ ∀|α|≤k}
H^k(Ω) = W^{k,2}(Ω)（p=2 的特例，Hilbert 空间）

"弱导数"：不要求逐点可导，只要分部积分成立。
∫ f ∂^α φ = (-1)^|α| ∫ g φ ∀φ ∈ C_c^∞ → g = ∂^α f（弱意义）

## 关键定理

### Sobolev 嵌入定理
W^{k,p} ⊂ L^q 当 1/q = 1/p - k/n（n=维数）
→ 高阶导数 + Lp 控制 → 低阶导数的更强范数

### Poincaré 不等式
‖u - ū‖_{Lᵖ} ≤ C ‖∇u‖_{Lᵖ}（有界域上）
→ 常数的梯度=零被"模掉"→ 控制零空间

### Rellich 紧性
W^{1,2}(Ω) → L²(Ω) 的嵌入是紧的（有界域）
→ 谱是离散的（特征值序列 →∞）

## 应用：椭圆 PDE 弱解
-Δu = f 的弱解：u ∈ H₀¹(Ω) 使 ∫∇u·∇v = ∫fv ∀v
- Lax-Milgram 定理保证存在唯一
- 这就是有限元方法（FEM）的数学基础
