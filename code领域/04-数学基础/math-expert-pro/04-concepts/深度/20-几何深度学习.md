# 几何深度学习：对称性与深度学习的融合

> Bronstein et al. 2021 的统一框架——用对称性分类所有深度学习架构。

## 核心思想
"几何深度学习 = 对称性引导的深度学习"

不同数据有不同的对称群 → 不同的网络架构：
| 对称性 | 群 | 网络架构 |
|--------|-----|---------|
| 置换不变 | Sₙ | Deep Sets / Transformer |
| 平移 | ℤⁿ 或 ℝⁿ | CNN |
| 旋转 | SO(3) | 球面 CNN / 等变 NN |
| 图同构 | Aut(G) | GNN（消息传递）|
| 规范 | Gauge | 几何代数网络 |

## 消息传递 GNN（MPNN）
hᵢ^{l+1} = φ(hᵢ^l, Σ_{j∈N(i)} ψ(hᵢ^l, hⱼ^l, eᵢⱼ))
→ 对节点置换等变

## 等变神经网络
要求 f(g·x) = g·f(x)（对群 g）
- SO(3) 等变：分子设计（旋转不变的能量预测）
- E(3) 等变：蛋白质结构
- 仿射等变：图像识别

## Transformer 的几何视角
注意力 = 软排列（Softmax 加权的排列聚合）
→ Transformer = 在完全图上的 GNN！

## 应用
- AlphaFold2 = 几何深度学习 + 注意力（蛋白质折叠）
- 分子性质预测（等变 GNN）
- 物理仿真（保结构的神经网络）
