# 纽结理论：从Jones到Khovanov

> 纽结 = 打结的绳（首尾相接）——如何判断两个纽结不同？

## Reidemeister 运动
三种局部移动生成所有纽结等价。
→ 纽结不变量 = 在三种运动下不变的量。

## 纽结多项式
| 不变量 | 发现年 | 来源 |
|--------|--------|------|
| Alexander Δ(t) | 1928 | 拓扑 |
| Jones V(t) | 1984（Fields） | von Neumann 代数 |
| HOMFLY-PT P(a,z) | 1985 | 推广 |
| Kauffman F(a,z) | 1987 | 统计物理 |

## Jones 多项式的震撼
V(t) 区分了 Alexander 不能区分的纽结。
且 V(e^{iθ}) 与 Chern-Simons 理论相关（Witten 1989 Fields）。
→ 连接拓扑、量子场论、统计物理！

## Khovanov 同调（2000）
Khovanov 把 Jones 多项式"提升"为同调理论。
→ 更强的不变量（区分镜像/更多纽结）
→ Categorification：多项式 → 同调的范式

## Perelman 与 Poincaré
3 维 Poincaré 猜想：每个单连通闭3流形 ≅ S³。
Perelman 用 Ricci 流证明（2002-2003）——七大千禧唯一已解。
