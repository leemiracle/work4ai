# 高维概率精要

> "高维空间与直觉截然不同"——concentration 是核心现象。

## 浓度现象
高维随机向量"几乎常数"：
P(|f(X)-Ef|>t) ≤ 2exp(-ct²/σ²)

→ 均值附近的指数衰减 → "concentration of measure"

## Johnson-Lindenstrauss 引理
n 个点可嵌入 O(log n / ε²) 维仍保持距离（1±ε）
→ 高维数据的"几乎等距"低维嵌入

## 随机矩阵的谱
- Marchenko-Pastur 定律：样本协方差矩阵的极限谱
- RIP（限制等距性质）：随机矩阵以高概率满足 RIP → 压缩感知

## 高维 CLT
维度 d →∞ 时，随机向量的范数 concentrate 在 √d 附近：
P(||X-μ|| ≈ σ√d) → 1

→ 高维球的体积集中在"赤道"附近（反直觉！）
