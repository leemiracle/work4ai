# 表示论：群如何线性作用

> "每个抽象对称都有线性实现"——Frobenius/Schur/Weyl 的纲领。

## 基本概念
群 G 的表示 = 同态 ρ:G→GL(V)
"用矩阵实现抽象群的对称性"。

不可约表示：没有非平凡不变子空间。
"表示论的原子"——所有表示是不可约的"直和"。

## Schur 引理
ρ 不可约 → 与 ρ 交换的唯一算子是标量。
→ 不可约表示的"刚性"

## 特征标理论
χ(g) = Tr(ρ(g))
- 特征标决定表示（共轭类上的函数）
- 正交关系：⟨χᵢ,χⱼ⟩ = (1/|G|)Σχᵢ(g)χⱼ(g)⁻¹ = δᵢⱼ

## 有限群表示
- 不可约表示数 = 共轭类数
- 所有不可约维数²之和 = |G|
- Burnside p^a q^b 定理的证明用表示论

## 紧李群表示（Peter-Weyl）
紧群 G 的不可约表示的矩阵元 L²(G) 的正交基。
→ L²(S¹) 的 Fourier 级数 = U(1) 表示论
→ L²(SU(2)) = 球谐函数（量子力学角动量）

## Langlands 约领中的表示
自守表示 = GL(n) 在 Adele 商上的表示。
Langlands 猜想：Galois 表示 ↔ 自守表示的"字典"。
