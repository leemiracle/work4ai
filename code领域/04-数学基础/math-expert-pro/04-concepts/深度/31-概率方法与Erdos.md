# Erdős 概率方法：用随机证明确定性

> "概率论中最美的证明技巧"——证明存在性不需要构造。

## 核心思想
要证明"存在 X 具有性质 P"：
1. 构造随机 X
2. 计算 P(X 有 P) > 0
3. → 至少存在一个有 P 的 X

**不需要知道具体是哪个 X！**

## 经典例子

### Ramsey 数下界
R(k,k) > 2^{k/2}
证明：随机 2-着色 Kₙ，P(单色 Kₖ) < 1 当 n < 2^{k/2}
→ 存在一种着色没有单色 Kₖ

### Erdős 不同距离
n 个点至少有 Ω(n/√log n) 个不同距离
证明：随机取点 → 期望不同距离多 → 存在好的配置

### Lovász Local Lemma
即使事件不独立，只要"足够不依赖"，仍可避免所有坏事件。
P(Aᵢ)≤p, 依赖度≤d, ep(d+1)≤1 → P(∩¬Aᵢ)>0
