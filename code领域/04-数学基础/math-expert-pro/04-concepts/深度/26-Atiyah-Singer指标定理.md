# Atiyah-Singer 指标定理

> 20世纪最優美的数学定理之一——连接分析、拓扑、几何。

## 定理陈述
椭圆算子 D 的解析指标 = 拓扑指标
ind(D) = ∫_{T*M} ch(σ(D)) ∧ Td(T*M⊗ℂ)

→ 分析量（D的核-余核维度差）= 几何量（示性类的积分）

## 特例
- **Gauss-Bonnet**：χ(M) = (1/2π)∫K dA（曲率的积分=Euler示性数）
- **Hirzebruch-Riemann-Roch**：χ(L) = ∫ch(L)Td(TX)（代数几何核心）
- **Dirac算子**：spin流形上的Dirac算子指标 → 物理中 anomalies

## 为什么深刻
- 统一了分析（椭圆算子）、拓扑（示性类）、几何（曲率）
- 是 Langlands 纲领的几何版基础
- Witten 用它推导了弦论中的 anomalies
