# 最优传输理论

> "搬运泥土的最优方案"——Monge 1781 → Kantorovich →现代ML。

## Monge 问题（1781）
给定两个分布 μ,ν，找传输映射 T 使 Tₐμ=ν 且 min ∫c(x,T(x))dμ

## Kantorovich 松弛（1942）
允许"分裂"质量：传输计划 π（联合分布）
min ∫∫c(x,y)dπ s.t. π的边际 = μ,ν

Kantorovich 对偶：max ∫φdμ + ∫ψdν s.t. φ(x)+ψ(y)≤c(x,y)

## Wasserstein 距离
Wₚ(μ,ν) = (inf ∫∫d(x,y)^p dπ)^{1/p}

性质：
- Wₚ=0 ⟺ μ=ν
- 满足三角不等式（度量！）
- 比KL散度更强：能比较不重叠的分布

## Brenier 定理（1991）
c(x,y)=½|x-y|² 时，最优 T = ∇φ（凸函数的梯度）
→ 最优传输 = 梯度映射（连接到 Monge-Ampère 方程）

## 应用（2020-2026爆炸式增长）
1. **WGAN**：用 W₁ 代替 JS 散度训练 GAN
2. **Sinkhorn**：熵正则化的快速近似（GPU 友好）
3. **域适应**：用 OT 对齐源域和目标域分布
4. **分布嵌入**：用 OT 把点云嵌入向量空间
5. **经济/运筹**：资源分配/匹配市场

## Schrödinger 桥
OT 的随机版：在 Brown 运动约束下找最优传输
→ 连接扩散模型和最优传输
