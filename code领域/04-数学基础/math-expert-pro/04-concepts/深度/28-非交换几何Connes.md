# 非交换几何（Noncommutative Geometry）

> Connes 的纲领："非交换代数 = 虚拟空间的函数代数"

## 核心思想
Gelfand 对偶：{交换 C*-代数} ≃ {紧 Hausdorff 空间}
→ 非交换 C*-代数 = "非交换空间"

## Connes 的标准模型推导
用谱三元组 (A, H, D) 推导粒子物理标准模型：
- A = 代数（编码规范对称性）
- H = Hilbert 空间（费米子态）
- D = Dirac 算子（编码度量+规范场）

→ 从纯几何原理推出 SU(3)×SU(2)×U(1) 和 Higgs 机制！

## 应用
- 量子Hall效应（非交换Torus）
- 分形几何（谱测度）
- 数论（Riemann ζ 与非交换几何的连接）
