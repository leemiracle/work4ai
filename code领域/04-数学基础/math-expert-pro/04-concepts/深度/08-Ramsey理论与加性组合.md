# Ramsey 理论与加性组合

> "完全无序是不可能的"——Ramsey 理论的核心哲学。

## Ramsey 定理
对任意 r, k, 存在 N 使任何 r-着色的 K_N 都有单色 K_k。
→ "足够大的结构必然包含规律"

R(3,3)=6：任意 6 人中必有 3 人互相认识或互相不认识。

## Szemerédi 正则性引理（1975）
每个足够大的图可以被 ε-正则划分为有界多部分。
→ "每个大图几乎都看起来像随机图"
→ 这是图论最重要的定理之一

## Szemerédi 定理（1975, Fields 级）
正密度的整数集包含任意长等差数列。
四种证明：
1. Szemerédi（组合）
2. Furstenberg（遍历理论）
3. Gowers（Fourier分析 + 高阶傅里叶）
4. Tao（加性组合新方法）

## Green-Tao 定理（2004）
素数集包含任意长等差数列。
→ 用 Szemerédi + "素数伪随机性"证明

## Polynomial Freiman-Ruzsa 猜想（PFR）
小倍积集的"结构"——2023 Green-Tao-Ziegler "声称证明"，Lean形式化完成！
