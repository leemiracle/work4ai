# 模型论初步与非标准分析

> 用模型的方法得到"新"的数学结构。

## 核心概念
**模型** M = (D, I)：一个域 D + 解释 I，使一阶逻辑的公式在 M 中为真。
**理论** T：一组公理。**模型** M ⊨ T：M 满足 T 的所有公理。

## 关键定理
### Löwenheim-Skolem 定理
如果一个一阶理论有无限模型，则对任意基数 κ ≥ |Language|，它有基数为 κ 的模型。
→ 存在可数模型的理论（如 ZFC）也有不可数模型（"Skolem悖论"）

### 紧致性定理
T 的每个有限子集有模型 → T 有模型。
→ 应用：非标准分析、图论中的有限图逼近无限

### 完备性与不完备性
- Gödel 完备性（1929）：FOL 中可证明 ⟺ 在所有模型中为真
- Gödel 不完备性（1931）：PA/ZFC 中存在不可判定命题

## 非标准分析（Robinson 1960）
用超幂构造 *R = R^N/U（U 是 [0,∞) 上的自由超滤）。
*R 包含：
- 标准实数 r ∈ R ⊂ *R
- 无穷小 ε（ε > 0 但 ε < 1/n ∀n ∈ N）
- 无穷大 H（H > n ∀n）

**优势**：Leibniz 的"无穷小"终于严格化。微积分可以用无穷小做（更直觉）。

**例子**：f'(x) = st((f(x+ε)-f(x))/ε)，其中 st = 标准部分（取最接近的标准实数）。
