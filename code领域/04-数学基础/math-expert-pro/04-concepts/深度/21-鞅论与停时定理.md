# 鞅论与停时定理

> "公平赌博"的数学——概率论最优美的分支之一。

## 鞅定义
E[Xₙ₊₁ | Fₙ] = Xₙ（条件期望等于当前值）
→ "公平游戏"：未来的期望 = 现在

上鞅：E[Xₙ₊₁|Fₙ] ≤ Xₙ（不利）
下鞅：E[Xₙ₊₁|Fₙ] ≥ Xₙ（有利）

## Doob 鞅分解
任何下鞅 = 鞅 + 递增可料过程
Xₙ = Mₙ + Aₙ（Aₙ 可料递增）

## 可选停时定理
对有界停时 τ：E[X_τ] = E[X₀]（鞅的）
→ "公平游戏不可能靠停时策略赢"

应用：Wald 等式 E[ΣXᵢ] = E[X]·E[N]

## 不等式
- Doob 极大值：P(max Xₖ ≥ λ) ≤ E[Xₙ⁺]/λ
- Azuma-Hoeffding：P(|Xₙ-X₀|≥t) ≤ 2exp(-t²/(2Σcᵢ²))
  → 浓度不等式的核心

## 应用
- 金融：风险中性测度下的价格 = 鞅
- ML：泛化界用 Azuma-Hoeffding
- 算法：随机化算法的浓度
