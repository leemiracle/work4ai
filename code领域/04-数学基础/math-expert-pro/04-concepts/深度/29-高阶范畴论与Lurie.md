# 高阶范畴论：Lurie 的无穷范畴

> Jacob Lurie 用 ∞-范畴重写了代数几何和代数拓扑。

## 为什么需要 ∞-范畴？
普通范畴：对象 + 态射（1-态射）
2-范畴：对象 + 1-态射 + 2-态射（态射间的态射）
∞-范畴：对象 + 任意高阶态射

→ 在代数拓扑中，拓扑空间的映射空间本身就是拓扑空间（∞-群胚）

## Lurie 的贡献
- Higher Topos Theory (HTT, 2009)：∞-topos 的系统理论
- Higher Algebra (HA, 2017)：∞-范畴上的代数
- Spectral Algebraic Geometry：用"谱"代替"环"的代数几何

## 对数学的影响
- 简化了推导代数几何的基础
- 统一了同伦论与代数几何
- Dugger-Spivak: ∞-范畴可以用"单纯集合"模型化
