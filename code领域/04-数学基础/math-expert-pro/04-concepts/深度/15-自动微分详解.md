# 自动微分：精确梯度的引擎

> 反向传播 = 自动微分在神经网络上的应用。

## 两种模式
**前向模式（FD）**：对每个输入变量，传播导数。
- 一次 pass = 一个方向导数
- 适合输入少输出多

**反向模式（AD/反向传播）**：对每个输出，积累梯度。
- 一次 pass = 全部偏导数（对所有输入）
- 适合输入多输出少（= 深度学习！）

## 计算图
f(x₁,x₂) = sin(x₁) × x₂
分解：
1. z₁ = sin(x₁)
2. z₂ = z₁ × x₂

前向传播：计算 z₁, z₂ 的值
反向传播：计算 ∂f/∂z₂=1 → ∂f/∂z₁=x₂ → ∂f/∂x₁=x₂·cos(x₁), ∂f/∂x₂=z₁

## 复杂度
- 前向：O(n)（n=输入维度）次 pass
- 反向：O(1) 次 pass + O(记忆) 回溯
- 反向传播 = 深度学习的"魔法"——梯度计算成本 ≈ 前向的 2-3 倍

## Jacobian 积累
对于向量值函数 F:ℝⁿ→ℝᵐ：
- 前向 m 次 pass 得到完整 Jacobian
- 反向 n 次 pass 得到完整 Jacobian（或 1 次得到 Jᵀv）

→ 深度学习：n(参数)≈10⁹ >> m(损失)=1 → 反向模式最优

## 隐函数定理 + AD
如果 y 由 F(x,y)=0 隐式定义：
dy/dx = -F_y⁻¹ F_x
→ 可用 AD 自动计算隐式层的梯度（NeurIPS 2020 后大量应用）

## 检查点（Checkpointing）
用时间换空间：不存所有中间值，重算需要的部分。
→ 大模型训练的标准技术
