# Scholze-Clausen Condensed Mathematics

> 2026.05 Quanta 报道——正在重建拓扑学基础。

## 问题
传统拓扑空间有"病态"：不是所有拓扑空间都"好"。
特别是：拓扑空间在函子范畴中不是"稳定"的。

## Condensed Sets
Condensed set = 在"profinites"上的 sheaf。
→ 用"点"的"代数替代"重新定义拓扑。

关键：condensed sets 形成一个 **Grothendieck abelian category**
→ 同调代数的全部工具可用！（传统拓扑空间不行）

## Liquid Vector Spaces
Scholze 的核心突破：定义了 "liquid" 向量空间
→ 解决了 condensed 框架下的泛函分析基础
→ Liquid Tensor Experiment（2021 Lean 形式化验证）

## 为什么重要
1. 统一拓扑与代数（condensed = 代数化拓扑）
2. 解决 p-adic 泛函分析的基础问题
3. 可能改变代数几何/数论的根基
4. Scholze 亲自用 Lean 验证（Fields 得主下场形式化）
