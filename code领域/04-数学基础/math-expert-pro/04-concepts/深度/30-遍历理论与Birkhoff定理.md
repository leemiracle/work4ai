# 遍历理论与 Birkhoff 定理

> "时间平均 = 空间平均"——统计物理的数学基础。

## 基本概念
保测变换 T:(X,μ)→(X,μ)：μ(T⁻¹(A))=μ(A) ∀可测 A

遍历：T 的不变集只有零测和满测集。

## Birkhoff 遍历定理（1931）
对遍历的 T 和 f∈L¹：
(1/n)Σ_{k=0}^{n-1} f(T^k x) → ∫f dμ a.e.

→ **时间平均 = 空间平均**（遍历假设的严格化）

## von Neumann 遍历定理（L²版）
‖(1/n)Σf∘T^k - ∫f‖_{L²} → 0

## 应用
- 统计物理：等概率假设 = 遍历性
- 数论：等分布定理（Weyl）= 遍历定理的推论
- 概率：Markov链的遍历定理 → 平稳分布
- ML：SGD的遍历行为 → 时间平均≈总体平均

## Furstenberg 的遍历方法
用遍历理论证明 Szemerédi 定理（正密度集含等差数列）
→ 纯组合/数论问题用动力学方法解决——革命性！
