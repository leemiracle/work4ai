# 线性规划与内点法

> 从 Dantzig 的单纯形到 Karmarkar 的内点法——优化理论的核心。

## LP 标准形式
min cᵀx s.t. Ax ≤ b, x ≥ 0

可行域 = 多面体 P = {x : Ax≤b, x≥0}
最优解 = P 的顶点（如果存在）

## 单纯形法（Dantzig 1947）
沿多面体的边从一个顶点走到更好的顶点。
- 实际中极快（O(n) 步左右）
- 最坏情况指数级（Klee-Minty 1972 反例）

## 对偶理论
原问题 min cᵀx s.t. Ax≥b
对偶 max bᵀy s.t. Aᵀy≤c
强对偶：两者最优值相等（如果有可行解）
→ 对偶间隙=0

互补松弛：xⱼ(cⱼ-Aⱼᵀy)=0
→ 最优时"原变量和对偶约束不能同时紧"

## 内点法（Karmarkar 1984）
不从顶点走，而是在可行域**内部**走路径。
- 多项式时间 O(n^{3.5} L)
- 实际与单纯形竞争

路径跟踪法：min cᵀx - μΣln(xⱼ)（障碍函数）
μ→0 时最优解→LP 最优

## 整数规划（IP）
LP + x∈Zⁿ → NP 难
方法：分枝定界 / 割平面 / 列生成
松弛：LP 松弛 → 分数解 → 分枝
