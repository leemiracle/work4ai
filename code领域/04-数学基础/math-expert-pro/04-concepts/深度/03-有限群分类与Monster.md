# 有限群分类定理（CFSG）

> 数学史上最长的证明——10000+页，100+年。

## 定理陈述
每个有限单群属于以下之一：
1. **素数阶循环群** Zₚ
2. **交错群** Aₙ (n≥5)
3. **Lie型群**（16族 + 例外）
4. **26个散在群**（sporadic groups）

## 散在单群
26 个不属于任何无限族的有限单群。最大的：
- **Monster群 M**：|M| ≈ 8×10⁵³（维数 196883 的表示）
- **Baby Monster**：第二大
- **Conway群 Co₁**：与 Leech 格有关
- **Mathieu群 M₁₁,M₁₂,M₂₂,M₂₃,M₂₄**：最早的散在群

## Moonshine 猜想（1979→1992 Conway-Norton）
Monster 的特征标 j(q) 的系数 = 模函数 j(τ) 的 Fourier 系数。
→ 连接有限群与模形式——完全意想不到的深层联系！
→ Borcherds 1998 证明 → Fields Medal
