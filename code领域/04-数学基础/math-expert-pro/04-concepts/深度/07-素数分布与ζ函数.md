# 素数分布与 Riemann ζ 函数

> "素数是数学的原子"——它们的分布藏着最深的秘密。

## 素数定理（Hadamard/de la Vallée-Poussin, 1896）
π(x) ~ x/ln(x)（x→∞）
更精确：π(x) = Li(x) + O(x e^{-c√ln x})

ζ(s) = Σ 1/nˢ 的零点位置决定 π(x) 的精度。

## Riemann 猜想（1859, 千禧 $1M）
ζ(s) 的非平凡零点都落在 Re(s)=1/2 上。

**为什么重要**：RH 蕴含 π(x) = Li(x) + O(√x ln x)
（比无条件结果好得多——素数分布的"终极精度"）

## Montgomery-Odlyzko 现象
ζ 的零点间距统计 = GUE 随机矩阵的特征值间距。
→ 素数分布与量子物理有深层联系（至今未完全理解）

## 零点验证（2024）
前 10¹³ 个零点全部在 Re=1/2 线上（Zhou-Platt-Trudgian 2020）。
但数值验证≠证明。
