# 概率收敛
> 随机变量序列"靠近"某个极限的四种方式，强度递减但适用面递增。

## 多重表征并列对照

### 总表：四种收敛

| 收敛类型 | 记号 | 定义 | 直觉一句话 | 代表定理 |
|---|---|---|---|---|
| 几乎必然收敛 a.s. | Xₙ→ᵃˢX | P(lim Xₙ=X)=1 | 除零测集外逐点收敛 | SLLN（强大数定律） |
| 依概率收敛 | Xₙ→ᴾX | ∀ε>0, P(|Xₙ−X|>ε)→0 | 偏差大概率趋于零 | WLLN（弱大数定律） |
| 依分布收敛 | Xₙ→ᵈX | Fₙ(x)→F(x) 在 F 连续点 | 分布形状逼近 | CLT（中心极限定理） |
| Lᵖ 收敛 | Xₙ→ᴸᵖX | E[|Xₙ−X|ᵖ]→0 | p 阶矩距离归零 | L²=均方收敛（RMS） |

### 强度层次图

```
        a.s. ─────┐
                  ├──▶ 依概率 ────▶ 依分布
         Lᵖ ─────┘
```

- a.s. ⟹ 依概率 ⟹ 依分布
- Lᵖ ⟹ 依概率（由 Markov 不等式：P(|Xₙ−X|>ε) ≤ E[|Xₙ−X|ᵖ]/εᵖ）
- **a.s. 与 Lᵖ 互不蕴含**（关键反例考点）

### 分小节：逐个拆解

**1. 几乎必然收敛（a.s.）**
- 定义：P({ω: limₙ Xₙ(ω) = X(ω)}) = 1
- 强度：最强（逐样本路径收敛，只允许一个"坏样本集"概率为 0）
- 典型实例：SLLN——样本均值 X̄ₙ →ᵃˢ μ
- 陷阱：a.s. 不要求"所有 ω"，允许零测集例外

**2. 依概率收敛**
- 定义：∀ε>0, lim P(|Xₙ−X|>ε)=0
- 强度：中等。"坏事件"的概率（非样本本身）趋于 0
- 典型实例：WLLN——X̄ₙ →ᴾ μ
- 与 a.s. 区别：依概率允许"坏样本"在不同 n 跳来跳去，a.s. 要求固定下来

**3. 依分布收敛（弱收敛）**
- 定义：Fₙ(x)→F(x) 在 F 的所有连续点成立
- 强度：最弱。只关心分布函数，不要求随机变量定义在同一概率空间
- 典型实例：CLT——√n(X̄ₙ−μ)/σ →ᵈ N(0,1)
- 注意：Xₙ 与 X 可在不同概率空间；只比"分布形状"

**4. Lᵖ 收敛（矩收敛）**
- 定义：E[|Xₙ−X|ᵖ]→0
- L¹ = 平均收敛；L² = 均方收敛（RMS）
- 典型实例：均方分析（随机过程、信号处理）
- 陷阱：Lᵖ 与 a.s. 互不蕴含（见自测）

## 它们的统一与差异

### 统一：Kolmogorov 测度论框架下的同一族概念

四种收敛都是**测度论语言**下的收敛：

| 收敛 | 测度论翻译 |
|---|---|
| 依概率 | 测度收敛（按测度） |
| a.s. | 几乎处处逐点收敛 |
| 依分布 | 分布函数弱收敛（pushforward 测度弱收敛） |
| Lᵖ | Lᵖ 空间中的范数收敛（Banach 空间） |

→ 高观点：四种收敛 = 函数空间 + 测度论下的不同"拓扑"。

### 差异：强度不可比的角落

- **a.s. ⇏ Lᵖ**：Xₙ = n·1_{[0,1/n]}，在 [0,1] 上 a.s.→0，但 E[Xₙ]=1 不趋于 0。
- **Lᵖ ⇏ a.s.**：经典的"游动鼓包"反例（Xₙ 在不断缩小的区间上取 1，轮流扫描 [0,1]），Lᵖ→0 但每点无限次被命中，不 a.s. 收敛。

## 跨学科这张面孔

| 学科 | 这张面孔叫什么 | 角色 |
|---|---|---|
| ML 统计学习 | 大数定律 | 经验风险 →ᴾ 期望风险，训练越多越准（ERM 理论基础） |
| 统计推断 | 一致性 | 估计量 θ̂ₙ →ᴾ θ（相合估计） |
| 随机过程 | 均方收敛 | L² 理论（Itô 积分构造） |
| 数值方法 | 蒙特卡洛收敛 | √n 速率来自 CLT，强弱来自 SLLN |
| 信号处理 | 均方稳定 | L² 意义下的功率/能量 |

**ML 一句话**：训练集越大，经验风险依概率（甚至 a.s.）逼近期望风险——这就是"为什么大数据能学"的理论基石。
