# 数学基础与数系（Foundation & Number Systems）

> 所有数学的起点——从自然数到p进数的完整数系发展。

---

## 数系演化链

**关键词**：N→Z→Q→R→C→H(四元数)→O(八元数)→p进数→超实数

每次扩展解决一个问题：Z解决减法不封闭；Q解决除法；R填补有理数'缝隙'(完备化)；C解决x²+1=0；H放弃交换律获得3D旋转；p进数改变'距离'定义(素数视角)。

## 集合论

**关键词**：ZFC公理体系/基数/序数/选择公理/连续统假设/大基数

Cantor开创。ZFC 9+1条公理是标准基础。选择公理(AC)→Banach-Tarski悖论。CH在ZFC中不可判定(Gödel+Cohen)。

## 数学逻辑

**关键词**：命题逻辑→一阶逻辑→高阶逻辑→元数学

命题逻辑用真值表；一阶逻辑加∀∃和量词；Gödel不完备定理：任何足够强的形式系统都有不可判定的命题。

## 构造主义vs形式主义

**关键词**：Brouwer/Hilbert/Bishop/Wildberger

直觉主义拒绝排中律；形式主义接受ZFC；构造主义要求算法可提取；有限主义拒绝实无穷。

## 学习路径

**关键词**：What is Mathematics→Spivak→Halmos Naive Set Theory→Enderton Mathematical Logic

先直觉后严格。集合论用Halmos；逻辑用Enderton；构造主义读Bishop。
