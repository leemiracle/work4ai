# 概念横切总览：同一张面孔的多种相貌

> 多视角矩阵的第二条轴——同一个数学概念，在不同教材、不同分支里以不同的"面孔"出场，本目录把它们并列摆在一起，让割裂的分科重新连通。

## 这是架构维度 2

math-expert-pro 的知识体系是一个**多视角矩阵**：

- **维度 1（纵向，`03-textbooks/`）**：按教材逐章推进，是"时间线 / 难度线"。
- **维度 2（横向，本目录 `04-concepts/`）**：按概念横切，是"同一概念的多重表征线"。
- **维度 3（纵深，`05-connections/`）**：概念之间的依赖、类比、统一。

只走维度 1，容易把"极限"理解成 Spivak 第 1 章那一道 ε-δ 题；只走维度 2，又容易脱离难度梯度空谈抽象。两条腿走路，概念才立体。本目录就是第二条腿。

## 为什么要"横切"

传统数学教育按分支割裂：分析课讲 ε-δ 极限，拓扑课讲邻域，逻辑课讲形式系统。结果是同一个"极限"，学生在三门课里见了三次，却没意识到那是**同一张面孔的多次亮相**。

横切的价值在打破这种割裂：

- 看到**等价性**：不同刻刻画的是同一对象，可以互相翻译。
- 看到**适用边界**：哪种刻画在什么场景下好用、什么场景下失效。
- 看到**抽象阶梯**：从直觉到形式化到最一般化，每一步丢掉了什么、换来了什么。

## 多表征的一个核心原则

每种表征都不是"更正确的极限"，而是**同一个极限的不同投影**。判断好坏的唯一标准是：**在当前任务里，哪种表征的认知代价最低**。

- 求 δ 时，ε-δ 最直接。
- 看数值收敛，序列最直观。
- 推广到一般空间，必须上升到邻域 / 网。
- 做物理启发式推导，超实数最顺手。

能在这几种语言之间**主动切换**，而不是被某一种困住，才是"懂了极限"。本目录每个文件都是为训练这种切换能力而设。

## 使用方法

1. **学完一本教材的对应章节后**，回到本目录读那个概念的多表征文件，对照你刚学的这一种刻画，看其他几种。
2. **做辨析自测**：每个文件末尾有 3-5 道辨析题，先自己答，再回头看正文。
3. **横向跳转**：如果一个概念的某表征依赖另一个概念（如"网滤子极限"依赖"有向集"），顺着依赖跳到那个概念文件。
4. **不要一次性通读**：横切文件是"对照参考"，不是"教材正文"，按需查阅比通读更有效。
5. **回填主线**：在 `03-textbooks/` 的笔记里标注"此处对应 `04-concepts/` 的第 N 种表征"，建立双向链接。
6. **优先读已完成的范例**：[极限-多表征.md](极限-多表征.md) 是模板最完整的样本，其他文件参照它的结构。

## 参考与方法论

本目录的设计依据调研报告 §5.2"概念多表征矩阵"：数学概念的深度理解，表现为能在多种等价表征之间自由切换，并清楚每种表征的代价与收益。这也是 math-expert-pro 区别于"单线刷书"模式的核心机制之一。
