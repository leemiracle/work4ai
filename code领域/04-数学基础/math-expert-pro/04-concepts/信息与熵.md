# 信息与熵

> 不确定度可以被精确度量，且这一度量贯穿通信、物理与学习。

## 出现在哪些教材/阶段

| 视角 | 出处 | 阶段 |
|------|------|------|
| Shannon 熵 | Shannon 1948《通信的数学理论》 | 信息论本科 |
| Landauer 原理 | Landauer 1961 IBM Journal | 物理信息论 |
| KL 散度 | Kullback-Leibler 1951 | 统计 / 机器学习 |
| 交叉熵损失 | 深度学习标准实践 | ML 应用 |

## 多重表征并列对照

| 视角 | 数学表象 | 直觉 | 典型场景 |
|------|----------|------|----------|
| Shannon 熵 | H(X) = -Σ p(x) log p(x) | 随机变量的不确定度 | 数据压缩、信道容量 |
| Landauer 原理 | E ≥ kT ln 2 | 擦除 1 bit 必耗散能量 | 计算能耗下界 |
| KL 散度 | D_KL(P‖Q) = Σ p log(p/q) | 用 Q 近似 P 的信息损失 | 变分推断、模型比较 |
| 交叉熵损失 | L = -Σ y log(ŷ) | 真分布与预测分布的差距 | 深度学习分类 |

### Shannon 熵：信息论黄金标准

H(X) = -Σ p(x) log p(x)，单位为 bit（log 以 2 为底）。

直觉：随机变量"惊讶度"的期望。-log p 是"看到稀有事件"的惊讶量，熵是它的平均。

性质：均匀分布熵最大（最不可预测）；确定分布熵为 0。条件熵 H(Y|X) ≤ H(Y)——条件作用不会增加不确定度。

何时用：信源编码极限（Huffman 接近 H(X)）、信道容量 C = max I(X;Y) = max[H(X) - H(X|Y)]。

### Landauer 原理：信息是物理的

擦除 1 bit 信息至少耗散 kT ln 2 的能量，其中 k 是 Boltzmann 常数、T 是绝对温度。

直觉：信息不是抽象的，它绑定到物理载体；不可逆计算有热力学代价。麦克斯韦妖的"账"在这里偿还——记录与擦除信息产生的熵抵消了它"违规"抽取的功。

何时用：可逆计算、物理信息论、计算复杂度的能量下界。从业者透镜中"硬件角色"对它最敏感——摩尔定律撞墙时这一原理变得紧迫。

### KL 散度：不对称的"距离"

D_KL(P‖Q) = Σ p(x) log (p(x)/q(x))，也称相对熵。

直觉：用 Q 当模型来编码来自 P 的数据，比用最优编码平均多花多少 bit。

关键性质：D_KL ≥ 0（Jensen 不等式）；不对称（D_KL(P‖Q) ≠ D_KL(Q‖P)），所以它不是真正的距离。前向 KL（P 为真分布）倾向于"覆盖全部支撑"，反向 KL 倾向于"寻峰"——这解释了变分推断中 mass-covering vs mode-seeking 的差异。

何时用：变分推断 ELBO、贝叶斯模型比较、生成模型（VAE、扩散）。

### 交叉熵损失：ML 的标准损失

L = -Σ y log(ŷ)。

关键等式：交叉熵 = 熵 + KL，即 H(P, Q) = H(P) + D_KL(P‖Q)。

由于真实分布 P 固定（标签），H(P) 是常数，因此**最小化交叉熵 ⟺ 最小化 KL ⟺ 最大化似然**。

softmax + 交叉熵 = 多分类标准配置；数值稳定实现用 log-sum-exp，避免先 softmax 再 log 的下溢。

何时用：几乎所有深度分类网络的输出层。

## 它们的统一与差异

统一：交叉熵 = KL + 熵（熵是关于真分布的常数）。因此最小化交叉熵、最小化 KL、最大化似然三者等价。Shannon 熵是"自信息"-log p 的期望——所有这些量都是"信息量"在不同语境下的加权平均。

差异：
- Shannon 熵度量单分布的不确定度。
- KL 散度度量两分布的差异（不对称）。
- 交叉熵把 KL 写成可直接优化的形式。
- Landauer 把信息从概率拉回物理。

高观点：信息论统一了压缩、通信与学习——三者本质上都是"减小不确定性"。压缩找短编码；通信在噪声中恢复信号；学习从数据中提取规律。三者共享同一个数学骨架：负对数似然。

## 跨学科这张面孔

- **ML 角色**：交叉熵是分类的默认损失；KL 是变分推断的核心；信息论给 ML 提供了"为什么最大似然"的底层理由。
- **硬件角色**：Landauer 原理给出"计算的物理账单"，提示不可逆计算有能耗下界，是后摩尔时代计算的硬约束。
- **密码学角色**：密钥熵是密码强度的度量；熵不够，加密就崩——一次一密的强度恰好来自密钥熵等于消息熵。

## 自测

1. 为什么最小化交叉熵等价于最大似然？写出从 H(P,Q) = H(P) + D_KL(P‖Q) 出发的推导。
2. KL 散度不对称会带来什么后果？前向 KL 与反向 KL 在变分推断中分别倾向什么行为？
3. Landauer 原理是否断言"所有计算都耗能"？精确陈述它的前提（哪类操作才耗散？）。
4. 均匀分布的 Shannon 熵为什么最大？用拉格朗日乘子或 Jensen 不等式给出论证。
5. softmax + 交叉熵的数值稳定实现为什么要用 log-sum-exp，而不是先 softmax 再取 log？
