## 一、数系扩展

### 四元数 ℍ
Hamilton 1843。ℍ = {a+bi+cj+dk}，i²=j²=k²=ijk=-1。**非交换**（ij=k≠ji=-k）。应用：3D旋转（避免万向锁）、机器人姿态控制。
关联：[代码库 21-微分几何](../15-applications/代码库/21-微分几何_曲线与曲面.py) 的 SO(3)

### p 进数 ℚₚ
Hensel 1897。用 p 进赋值完备化 ℚ。性质：|pⁿ|_p = p⁻ⁿ（素数 p 越"大"值越"小"）。应用：数论（Wiles 证明 FLT 用了 p 进 Hodge 理论）、密码学。
关联：[14-frontier/conjecture进展/](../14-frontier/conjecture进展/)

### 超实数 *ℝ
Robinson 1960（非标准分析）。包含无穷小 ε（ε>0 但 ε<1/n ∀n）。让 Leibniz 的"无穷小"严格化。
关联：[16-foundations/基础争议/02-构造主义](../16-foundations/基础争议/02-构造主义与数学实践.md)

## 二、代数进阶

### 环论
环 (R,+,·)：加法是阿贝尔群，乘法结合+分配律。理想 I⊂R 是"加法子群且 rI⊂I"。商环 R/I 把理想"模掉"。
关键定理：Hilbert 零点定理（理想↔代数簇）、Noether 环（理想升链条件）。
关联：[16-foundations/统一视角/02-Galois](../16-foundations/统一视角/02-Galois理论与对偶实例.md)

### 模论
模 M over 环 R：向量空间的推广（系数在环而非域）。表示论 = 群代数上的模论。
关键概念：自由模/挠模/Noether 模/平坦模。
关联：[代码库 22-群论](../15-applications/代码库/22-群论_对称与表示.py)

### 李代数
李代数 𝔤：向量空间 + 李括号 [x,y]（双线性+反称+Jacobi）。李群的"无穷小"版本。
例子：𝔰𝔩(2)（2×2 追迹零矩阵）、𝔰𝔬(3)（3D 旋转）。
应用：粒子物理标准模型 = 李代数 SU(3)×SU(2)×U(1)。
关联：[代码库 22-群论](../15-applications/代码库/22-群论_对称与表示.py) Noether 定理

### 交换代数
交换环的深入理论。Atiyah-MacDonald 是经典教材。核心：局部化/准素分解/Dedekind 域/维数理论。
应用：代数几何的基础语言（概形 = 局部交换环的空间化）。

### 张量与张量积
张量 = 多线性映射的坐标表示。张量积 V⊗W 是"最一般的双线性映射"。
关键：Universal Property、张量秩（矩阵秩的推广）、CP/Tucker 分解。
应用：深度学习（TensorFlow）、广义相对论（度规张量 g_μν）、量子纠缠（密度矩阵）。

## 三、分析进阶

### Lebesgue 测度与积分
Lebesgue 1902。比 Riemann 积分更强大：能积更广的函数类。
核心思想：分割 y 轴（值域）而非 x 轴（定义域）。
关键定理：控制收敛定理 / 单调收敛定理 / Fatou 引理。
应用：概率论的严格基础（随机变量 = 可测函数）。

### Banach 空间
完备赋范向量空间。例子：Lᵖ 空间 / ℓᵖ 序列空间 / C(K) 连续函数空间。
关键定理：Hahn-Banach（泛函延拓）/ 开映射 / 闭图像 / 一致有界原理。
应用：PDE 的函数空间、信号处理（L² 傅里叶）。

### Hilbert 空间
完备内积空间。Banach 的特例（范数由内积诱导）。
关键：正交基 / Riesz 表示 / 投影定理 / 谱定理。
应用：量子力学（态空间）/ 核方法（RKHS）/ 傅里叶分析（L²）。
关联：[15-applications/物理工程/02-量子力学](../15-applications/物理与工程/02-量子力学数学.md)

### 泛函分析
无穷维空间上的分析。核心：算子（线性映射）/ 谱理论 / 弱拓扑。
重要概念：紧算子 / Fredholm 理论 / Schauder 基。
应用：PDE 弱解 / 量子散射理论 / 最优控制。

## 四、几何进阶

### 射影几何
研究射影不变量（交比）。射影空间 ℙⁿ = (ℝⁿ⁺¹\{0})/~。
核心：任何两条直线相交（包括"无穷远"）→ 无平行线。
应用：计算机视觉（射影重建）/ 代数几何基础。

### 黎曼几何
黎曼流形 (M, g)：每点有内积 gₚ。曲率 R = ∇²∇（Riemann 张量）。
关键：Ricci 流 d/dt g = -2Ric（Perelman 用它证 Poincaré）/ 测地线。
应用：广义相对论（Einstein 方程 G_μν = 8πT_μν）。
关联：[代码库 21-微分几何](../15-applications/代码库/21-微分几何_曲线与曲面.py)

### 辛几何
辛流形 (M, ω)：闭非退化 2-形式 ω。Hamilton 力学的几何框架。
核心：Darboux 定理（所有辛流形局部相同）/ Hamilton 流。
应用：经典力学 / 镜像对称 / 量子化。

### 代数几何
多项式方程解空间的几何。Grothendieck 的概形（scheme）理论。
核心：层（sheaf）/ 概形 / 上同调 / 模空间。
应用：Wiles 证明 FLT / 密码学（椭圆曲线）/ Langlands 纲领。

### 计算几何
算法几何。核心问题：凸包 / Voronoi 图 / Delaunay 三角化 / 点定位。
应用：计算机图形学 / 机器人路径规划 / GIS。

### 凸几何
凸集/凸体的研究。核心：Brunn-Minkowski / John 椭球 / 凸体的度量几何。
应用：凸优化 / 纠错码（球填充）/ 数学的渐近几何。

## 五、拓扑进阶

### 代数拓扑
用代数工具（群/环）分类拓扑空间。核心：同调群 Hₙ / 同伦群 πₙ / 上同调。
关键定理：de Rham 定理（微分形式上同调 = 奇异上同调）/ Hodge 定理。
应用：TDA / 纤维丛 / 示性类。

### 微分拓扑
可微流形的研究。核心：横截性 / Morse 理论 / Sard 定理 / 流形浸入/嵌入。
关键：Smale 的 h-配边定理 / Whitney 嵌入定理。

### 低维拓扑
3-流形（Thurston 几何化）/ 4-流形（Donaldson/Seiberg-Witten）/ 纽结（Jones 多项式）。
关键：Perelman 证明 Poincaré（3维）/ Freedman（4维拓扑分类）。

### 纤维丛与示性类
纤维丛 = 推广的乘积空间（局部平凡，全局可能扭曲）。
示性类（Stiefel-Whitney / Chern / Pontryagin）= 丛的拓扑不变量。
应用：规范场论 / Atiyah-Singer 指标定理。

## 六、数论进阶

### 代数数论
代数整数 / 理想 / 类数 / Dedekind 域 / 局部域。
核心：类域论（Abel 扩张的分类）/ Artin 互反律。
应用：Wiles FLT / Langlands 纲领。

### 几何数论
Minkowski 几何数论 = 格点几何。核心：Minkowski 定理（凸体+格点→短向量）。
应用：密码学（格基规约 LLL）/ 数论（类数公式）。

## 七、统计与概率进阶

### 时间序列
ARIMA(p,d,q) / GARCH / 协整 / 单位根检验。
核心：Box-Jenkins 方法 / 谱分析 / 状态空间模型。
应用：经济预测 / 量化交易 / 信号处理。

### 因果推断
Pearl 的 DO 演算 / 反事实（counterfactual）/ DAG（有向无环图）。
核心："相关≠因果"——因果发现/工具变量/回归断点。
应用：流行病学 / 经济学 / A/B 测试 / AI 可解释性。

## 八、优化进阶

### 线性规划
min cᵀx s.t. Ax≤b。单纯形法（Dantzig 1947）/ 内点法（Karmarkar 1984）。
对偶定理：强对偶（LP总有最优对偶）。
应用：物流/生产计划/资源分配。

### 非凸优化
非凸目标/非凸约束。挑战：局部最优 / 鞍点 / 平坦方向。
方法：动量SGD/Adam/模拟退火/遗传算法。
应用：深度学习训练 / 组合优化松弛。

### 在线优化
序贯决策，每步收到新数据。Regret = 累积损失 - 最优事后损失。
方法：Follow the Regularized Leader / 在线梯度下降。
应用：推荐系统 / 广告投放 / 多臂老虎机。

### 鲁棒优化
min max（最坏情况优化）。不确定集合 U → 对 U 内所有情况优化。
方法：SOCP 鲁棒化 / 分布鲁棒优化（DRO）。
应用：供应链 / 电网 / 金融风险。

## 九、信息论进阶

### Kolmogorov 复杂度
K(x) = 最短生成 x 的程序长度。不可计算的但可定义。
核心：K(x) ≈ H(x) + O(1)（与 Shannon 熵的关系）。
应用：AI（通用智能的度量）/ 压缩极限 / 随机性定义。

## 十一、前沿进阶

### 镜像对称
弦理论的数学推论：Calabi-Yau 流形 X 和 X̂ 的"镜像"关系。
数学：Gromov-Witten 不变量 / 量子上同调。
Fields 级工作：Kontsevich / Tao（相关）。

### 非交换几何
Connes 的纲领：用非交换代数替代函数代数来定义"空间"。
核心：谱三元组 (A,H,D) / Connes 距离公式。
应用：标准模型 / 分形几何 / 量子引力。

### 热带几何
"热带化" = 用 max-plus 半环替代普通运算。
核心：热带曲线 = 分段线性曲线 / 热带化 = 退化极限。
应用：代数几何计数 / 优化 / 生态系统建模。

### 最优传输
Monge-Kantorovich：把一个分布"搬运"到另一个的最优方式。
核心：Wasserstein 距离 Wₚ / Brenier 定理 / Schrödinger 桥。
应用：生成模型（WGAN）/ 统计 / 经济学。
