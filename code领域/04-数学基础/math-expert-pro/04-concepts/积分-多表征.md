# 积分

> 积分是"把无穷多无穷小加起来"——它有黎曼的纵向切、Lebesgue 的横向切、Stieltjes 的加权、Itô 的随机四副面孔，背后是同一个"测度求和"思想。

### 1. 黎曼积分 Riemann (1854)

**构造**：在区间 [a,b] 上做分割 P: a=x₀<x₁<…<xₙ=b，每个子区间取样本点 ξᵢ∈[xᵢ₋₁, xᵢ]，求和

$$S(P, f) = \sum_{i=1}^{n} f(\xi_i)\,\Delta x_i$$

当 mesh(P) = max Δxᵢ → 0 时和的极限存在，即为黎曼积分 ∫ₐᵇ f dx。

**Darboux 改写**：用上和 U(f,P)=∑MᵢΔxᵢ 与下和 L(f,P)=∑mᵢΔxᵢ（Mᵢ, mᵢ 为子区间上 f 的上、下确界），可积 ⟺ 上积分=下积分。这把"任取样本点"换成"最坏情况"，更易证明。

**优点**：直观，几何意义就是"曲线下面积"；微积分基本定理（FTC）将积分与反导数绑定，计算极其方便。
**致命缺点**：**Dirichlet 函数**（有理点取 1、无理点取 0）不可积——上和恒=1，下和恒=0。这说明黎曼积分对"振荡太剧烈"的函数束手无策；其函数空间不完备（Cauchy 序列不收敛）。

### 2. Lebesgue 积分 Lebesgue (1902)

**核心思想**：不再纵向切定义域，而是**横向切值域**。

$$\int f\,d\mu = \lim_{n\to\infty} \sum_{k} y_k \cdot \mu(\{x : f(x) \in [y_k, y_{k+1})\})$$

对每个值域小条，问"函数取到这附近值的点集有多宽（测度 μ 多大）"，再以值为权重求和。

**黎曼 vs Lebesgue 的隐喻**：
- 黎曼：按时间顺序一分一分地数硬币（按定义域顺序求和）；
- Lebesgue：先把所有 1 元硬币堆一起、所有 5 元硬币堆一起，分别数有几枚（按值域分类，再用测度计数）。
后者效率更高、更鲁棒。

**优点**：
- **Dirichlet 函数 Lebesgue 可积**：∫ = 1·μ(ℚ∩[0,1]) + 0·μ(ℚᶜ∩[0,1]) = 0；
- **三大收敛定理**：控制收敛定理（DCT）、单调收敛定理（MCT）、Fatou 引理——这些是现代分析的支柱，黎曼积分无法支撑；
- 可积函数空间 L¹ 完备（是 Banach 空间）。
**缺点**：需要先建立测度论（σ-代数、可测集、可测函数），门槛陡峭；对于连续函数，与黎曼积分结果一致，工程上无必要升级。

### 3. Riemann-Stieltjes 积分

$$\int_a^b f\,dg$$

把黎曼积分中的 Δxᵢ 换成 Δgᵢ = g(xᵢ) − g(xᵢ₋₁)。g 称为"积分子"（integrator）。

**几种重要特例**：
- g(x) = x：退化成普通黎曼积分；
- g(x) 为阶梯函数（如 Heaviside）：积分变成**离散加权求和**——∑ f(cₖ)·Δgₖ，其中 Δgₖ 是 g 在跳跃点 cₖ 的跳跃高度；
- g(x) 绝对连续：dg = g'(x)dx，回到 ∫ f·g' dx；
- g(x) = x^α：可定义分数阶积分。

**何时用它**：
- **概率论**：随机变量的期望 E[X] = ∫ x dF(x)，其中 F 是分布函数。无论 X 是离散、连续还是混合型，这一式都成立——Stieltjes 统一了离散期望（求和）与连续期望（积分）。
- **物理学**：质量分布含点质量 + 连续质量时，用 Stieltjes 一次写完。

### 4. Itô 随机积分 Itô (1944)

$$\int_0^t f_s\,dW_s$$

其中 W_s 是 Brown 运动。问题在于 dW_s 不是普通微分——它是"噪声"，方差与 ds 同阶，量级为 √ds。

**两种取法导致两种积分**：
- **Itô 积分**：样本点取**左端点** f(xᵢ₋₁)。结果是**鞅**（martingale）——期望为 0、信息流自然。代价是链式法则多出二阶项（Itô 引理：df = f'dW + ½σ²f''dt）。
- **Stratonovich 积分**：样本点取**中点** (f(xᵢ₋₁)+f(xᵢ))/2。保持经典链式法则，但不再是鞅，物理上更"自然"。

**为什么金融几乎都用 Itô**：无套利定价要求"用当前已知信息决策"，左端点取值正好对应"不偷看未来"，鞅性质是风险中性测度的数学骨架。

## 它们的统一与差异

**统一**：Lebesgue 是**最一般的测度论框架**。其他三者都可看作它的特例或推广：

```
黎曼积分  ─┐
            ├─→ Lebesgue 积分（测度=长度）
Stieltjes ─┘    （测度由 g 诱导）

Itô 随机积分：测度换成 Brown 运动诱导的概率测度，
              但因被积过程与积分子耦合，需独立理论
```

**范畴论视角**：积分是一个**余极限**（colimit）思想——把"局部贡献"（函数值 × 微元）粘合成一个整体。各种积分的差异在于"局部"如何定义、"粘合"如何取极限。

**差异的核心**：
- **黎曼 vs Lebesgue**：纵向 vs 横向；对振荡函数的态度不同；
- **Stieltjes vs Lebesgue**：前者强调"积分子 g 诱导测度"，后者直接抽象测度；
- **Itô vs 黎曼/Stieltjes**：被积函数与积分子 W_t 不独立（适应过程），必须指定取点位置（左端 vs 中点），链式法则随之改变。

## 跨学科这张面孔

| 学科 | 积分的面孔 | 典型应用 |
|------|-----------|----------|
| 量化金融 | Itô 积分 = 随机收益 | 期权定价、鞅方法、风险中性测度 |
| 机器学习 | 积分 = 期望 = 经验风险 | E[L(θ,X)] 用样本均值近似（大数定律） |
| 概率论 | Stieltjes = 期望 | E[X] = ∫ x dF(x)，离散连续统一 |
| 物理学 | 积分 = 累积量 | 功 = ∫ F·dx、概率振幅、路径积分 |
| 信号处理 | 积分 = 滤波 | 卷积、Fourier 变换、L² 空间 |
| 统计物理 | Lebesgue = 相空间平均 | 配分函数、Boltzmann 分布 |

**一个洞察**：机器学习的"经验风险最小化"本质是用样本均值（离散求和）逼近真实期望（Lebesgue 积分）——大数定律保证了这种逼近的合理性。**积分是机器学习理论的地基**，只是大多数时候被"求和"伪装掩盖了。
