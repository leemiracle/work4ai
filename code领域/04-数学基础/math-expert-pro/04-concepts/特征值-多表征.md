# 特征值

> 特征值是「线性变换中方向不变、只缩放」的那个因子；它在不同学科有不同名字——谱、主成分、固有频率、稳定性判据——但数学骨架完全相同。

## 多重表征并列对照

| # | 表征 | 核心定义 | 「特征向量」叫什么 | 「特征值」叫什么 |
|---|---|---|---|---|
| 1 | 矩阵特征值 | det(A−λI)=0，Av=λv | 不变方向的向量 | 缩放因子 λ |
| 2 | 算子谱 σ(T) | Banach 代数里 (T−λI) 不可逆的 λ | 广义特征向量 | 谱点（含连续谱/剩余谱）|
| 3 | 物理简正模 | M ẍ + K x = 0 的解耦 | 简正模（独立振动模式）| 固有频率的平方 ω² |
| 4 | ML-PCA / SVD | 协方差矩阵的最大特征方向 | 主成分（载荷向量）| 该方向的方差 |
| 5 | 控制稳定性 | Jacobian 在平衡点的特征值 | 扰动展开的主轴 | 实部正负 ⟺ 失稳/稳定 |

### 1. 矩阵特征值：最熟悉的代数面孔

给一个 n×n 矩阵 A，找 λ 和非零 v 满足

```
A v = λ v
```

也就是 (A − λI)v = 0，要有非零解就得 det(A − λI) = 0——这就是特征方程。

- **Horn-Johnson 路线**：直接算行列式，靠数值算法（QR 算法）求根；
- **Axler 路线**：不靠行列式，先讲不变子空间与算子，把特征值定义为「存在非零 v 使 Tv = λv 的 λ」。结构更清晰，但证明长一些。

### 2. 算子谱 σ(T)：无穷维的推广

到了无穷维（Hilbert / Banach 空间），矩阵变成有界线性算子 T，「特征值」升级成**谱 σ(T)**：

```
σ(T) = { λ ∈ ℂ : (T − λI) 不可逆 }
```

谱里包含三类点：

- **点谱**：就是经典特征值；
- **连续谱**：(T − λI) 有定义但值域不充满；
- **剩余谱**：(T − λI) 单射但值域不稠密。

后两类在有限维里不存在，是无穷维独有的「幽灵」。量子力学里，束缚态对应点谱，自由态对应连续谱。

### 3. 物理简正模：振动的独立模式（Arnold 视角）

考虑小振动方程 M ẍ + K x = 0（M 质量阵，K 刚度阵）。解耦的关键是广义特征值问题：

```
K v = ω² M v
```

- 特征向量 v = **简正模**：系统可以单独按这个模式振动；
- 特征值 ω² = **固有频率的平方**。

Arnold 在《经典力学的数学方法》里强调：振动、刚体转动、甚至天体力学的小扰动，骨架都是同一个特征值问题。物理直觉让特征值「活」了起来。

### 4. ML-PCA / SVD：数据里找主轴

给一坨高维数据，协方差矩阵 C 的特征值分解给出「数据变化最剧烈的方向」：

- 最大特征值对应的特征向量 = **第一主成分**（方差最大方向）；
- 第二大 = 第二主成分，依此类推。

**PCA** = 协方差矩阵的特征值分解；
**SVD** = 任意矩阵都能写成 UΣVᵀ，奇异值就是特征值的推广。

应用：

- **降维**：保留前 k 个主成分，丢掉噪声；
- **推荐系统**：用户-物品矩阵 SVD 分解出潜在因子；
- **图像压缩**：丢掉小奇异值对应的分量。

（参考 math-expert W1-W3 的 PCA / SVD 实战。）

### 5. 控制稳定性：特征值实部判生死

一个动力学系统 ẋ = f(x) 在平衡点 x* 处线性化，得到 Jacobian J。**Lyapunov 第一方法**说：

- J 的所有特征值实部 < 0 ⟺ 平衡点（局部）渐近稳定；
- 有任一特征值实部 > 0 ⟺ 不稳定。

实际工程里不必真算特征值，用 **Routh-Hurwitz 判据**直接从特征多项式系数判断所有根是否都在左半平面——这是控制工程师每天用的工具。

## 它们的统一与差异

五种表征共享一句话定义：**「方向不变，只缩放」的那个因子**。差别只在「方向」和「缩放」在不同领域叫什么：

| 领域 | 「方向」叫什么 | 「缩放因子」叫什么 |
|---|---|---|
| 线性代数 | 特征向量 | 特征值 |
| 泛函分析 | 广义特征向量 | 谱点 |
| 力学 | 简正模 | 固有频率² |
| ML | 主成分 / 奇异向量 | 方差 / 奇异值 |
| 控制理论 | 扰动主轴 | （实部正负判稳定性）|

**谱定理 (Spectral Theorem)** 是统一的高观点：自伴算子（对称矩阵 / Hermitian 矩阵）可以被自己的特征向量完全对角化——这就是为什么物理量、协方差、刚度阵都能被「解耦」成一堆独立模式的根本原因。五种表征其实是同一句话的五种翻译。

## 跨学科这张面孔

特征值之所以横扫一切，是因为「找不变方向」几乎是所有定量学科的核心动作：

- **ML**：PCA / SVD 是几乎所有降维、推荐、压缩算法的内核；
- **物理**：量子力学里可观察量 = 自伴算子，测量值就是特征值；振动系统的简正模、刚体的主转动惯量轴，全是特征向量；
- **控制 / 工程**：稳定性、共振、滤波器设计都靠特征值的位置；
- **图论 / 网络**：图的 Laplacian 特征值揭示聚类结构（谱聚类）、连通性、PageRank；
- **数值分析**：迭代法的收敛速度由迭代矩阵的谱半径决定。

记住一句话：**「看到线性变换，先问它的特征值在哪」——这是数学家、物理学家、工程师和机器学习工程师共同的本能。**
