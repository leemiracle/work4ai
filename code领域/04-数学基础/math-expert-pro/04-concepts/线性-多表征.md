# 线性

> 「线性」是数学里反复出现的一张面孔：它在不同学科换上不同衣装，但内核始终是「保持加法与数乘结构」。

## 出现在哪些教材/阶段

| 教材 / 资料 | 阶段 | 这一教材如何呈现「线性」 |
|---|---|---|
| Axler《Linear Algebra Done Right》(LADR) ch1 | 阶段1 本科 | 抛弃行列式，用向量空间 + 线性算子的公理路线 |
| Horn-Johnson《Matrix Analysis》 | 阶段1-2 | 矩阵视角：把线性映射写成数组，强调计算与算法 |
| Dummit-Foote《Abstract Algebra》 | 阶段2 研究生 | 把线性代数抽象成环上模 (module over a ring) |
| Mac Lane《Categories for the Working Mathematician》 | 阶段2+ | 范畴论：把所有线性空间看成 R-Mod 范畴里的对象 |
| Girard《Linear Logic》(1987) | 阶段3 前沿 | 线性类型论：把「线性」从几何搬进类型系统 |

## 多重表征并列对照

| # | 表征 | 一句话定义 | 关键操作 | 强项 | 弱项 |
|---|---|---|---|---|---|
| 1 | 几何向量 | 有方向、有大小的箭头 | 平行四边形加法 | 可视化、直觉强 | 高维（>3 维）失效 |
| 2 | 代数线性组合 | 满足 8 条向量空间公理的对象 | 加法 + 数乘（封闭） | 统一 ℝⁿ / 多项式 / 函数 / 矩阵 | 抽象，初学者无图可依 |
| 3 | 范畴论 R-Mod | 环 R 上模的对象 | 态射 = R-线性映射 | 统一线代、交换代数、表示论 | 形式化重，门槛高 |
| 4 | 线性类型 | 资源恰好使用一次的类型 | 线性蕴含 A ⊸ B | 量子 no-cloning、资源安全 | 与日常直觉相悖 |

### 1. 几何向量：箭头与世界

最早接触的「线性」是一根带方向的箭头。两个箭头相加遵循平行四边形法则：把两个箭头尾对尾，对角线就是和。

- **优点**：可视化、有物理直觉（力、速度、位移都是向量）。
- **缺点**：一旦维数超过 3，画面就画不出来；函数、矩阵这些「非空间」对象根本不是箭头。

### 2. 代数线性组合：8 条公理（LADR 路线）

Axler 在 LADR 里干脆丢掉箭头，只留下 8 条向量空间公理（加法交换/结合、零元、负元、数乘分配……）。只要满足这些公理，对象就是「线性」的：

- ℝⁿ 是线性空间；
- 次数 < n 的多项式集合是线性空间；
- 区间 [0,1] 上的连续函数是线性空间；
- m×n 矩阵的集合也是线性空间。

**优点**：一套公理统一了完全不同的对象——这就是 Axler「Done Right」的用意。
**缺点**：抽象，初学者没有图可看；行列式被刻意推迟到最后一章。

### 3. 范畴论 R-Mod：环上模

把视角再拉高一层：固定一个环 R，所有「R-模」配上 R-线性映射构成范畴 **R-Mod**。

- 域 F 上的向量空间 = F-模（线性代数）；
- ℤ-模 = 阿贝尔群（抽象代数）；
- 多项式环上的模 = 表示论里的模。

于是「线性代数 = 域上模论的一个特例」。范畴论用同一套语言（对象、态射、函子、自然变换）统一了线性代数、交换代数与表示论。**阶段 2+ 才接触**，门槛高但统一性极强。

### 4. 线性类型论：资源恰好用一次

Girard 1987 年提出线性逻辑 (Linear Logic)，把「线性」从几何搬进类型系统：一个线性类型的变量在程序里**恰好使用一次**。

- 普通函数 `A → B`：参数可以用任意多次；
- 线性函数 `A ⊸ B`：参数必须用且仅用一次。

为什么有用？因为物理世界里的资源（一个量子比特、一块内存、一次 API 调用）是不能随便复制的。线性类型天然适合：

- **量子计算**：no-cloning 定理——量子态无法复制，正好对应线性类型；
- **资源敏感计算**：编译器用线性类型保证「文件恰好关闭一次」「内存恰好释放一次」。

## 它们的统一与差异

四种表征看似无关，其实共享同一个内核：**保持加法与数乘结构**。

- 表征 1（几何）→ 表征 2（代数公理）：丢掉箭头，只留公理，得到更大的适用范围；
- 表征 2（向量空间）→ 表征 3（R-Mod）：把「域」换成「环」，得到更一般的模论，统一线性代数与抽象代数；
- 表征 2 → 表征 4（线性类型）：把「线性」从「保持结构」翻译成「资源精确使用」，是同一种思想在计算机科学里的回响。

**Axler vs Horn-Johnson 的双视角**本身就是「线性」的两种面孔：

- Axler 关心**结构**（不要行列式，靠算子与不变子空间）；
- Horn-Johnson 关心**计算**（矩阵就是数组，特征值靠数值算法）。

两者并不矛盾——结构告诉你「为什么」，计算告诉你「怎么算」。范畴论则把它们都收纳进 R-Mod 这一个框架。

## 跨学科这张面孔

「线性」之所以反复出现，是因为它足够简单又足够丰富：

- **编译器 / 程序语言**：线性类型 = 资源安全（Rust 的所有权机制、Linear Haskell 都借鉴线性类型思想）；
- **量子计算**：量子态空间是复内积线性空间，量子门是酉线性算子——线性代数就是量子力学的母语；
- **机器学习**：神经网络的每一层就是一个线性映射 + 非线性激活，没有线性代数就没有深度学习；
- **物理**：力、电场、波函数都满足线性叠加，量子力学整个建立在 Hilbert 空间（完备内积线性空间）上。

记住一句话：**「线性」不是某一个学科的概念，而是数学给所有学科提供的同一套基础语法。**

## 自测

1. 用一句话说明 Axler 路线与 Horn-Johnson 路线的核心差别。
2. 为什么说「域上的向量空间是 R-Mod 的特例」？把「域」换成什么就退化成阿贝尔群？
3. 线性类型论里的 `A ⊸ B` 与普通 `A → B` 的区别是什么？举一个量子计算里必须用线性类型的例子。
4. 把 ℝ³、ℝ[x]_{<5}、C[0,1]、M_{2×3}(ℝ) 四个集合列出来，验证它们都满足 8 条向量空间公理中的「零元」与「负元」。
5. 范畴论把线性代数、交换代数、表示论统一在哪一个范畴名下？写出这个范畴的对象与态射各是什么。
