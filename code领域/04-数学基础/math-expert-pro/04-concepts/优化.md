# 优化
> 寻找"最好"的统一主题：变分法、凸优化、最优控制、最小作用量——都是极值原理的实例。

## 出现在哪些教材/阶段

| 教材 / 出处 | 阶段 | 定位 |
|---|---|---|
| 微积分（Euler-Lagrange） | 本科高数/分析 | 变分法入门 |
| 华章 71《凸优化》（Boyd） | 研究生应用数学 | 凸优化理论与算法 |

## 多重表征并列对照

### 总表：四种"优化"面孔

| 视角 | 优化对象 | 核心工具 | 关键定理 | 何时用 |
|---|---|---|---|---|
| 变分法 | 泛函 J[y]=∫L(y,y',x)dx | Euler-Lagrange 方程 | 极值必要条件 | 经典力学、测地线 |
| 凸优化 | 凸函数 f(x) 在凸可行域 | 梯度/牛顿/KKT | 局部=全局 | 工程优化、信号处理 |
| 最优控制 | 动态系统轨迹 | Bellman / Pontryagin | 极大值原理 | 机器人、控制、RL |
| 最小作用量 | 物理作用量 S=∫Ldt | Hamilton 原理 | 自然规律=极值 | 理论物理 |

### 分小节：逐个拆解

**1. 微积分变分（Euler-Lagrange）**
- 问题：在函数空间中求泛函 J[y] = ∫ L(y, y', x) dx 的极值。
- 必要条件（Euler-Lagrange 方程）：
  $$\frac{\partial L}{\partial y} - \frac{d}{dx}\frac{\partial L}{\partial y'} = 0$$
- 典型应用：
  - 经典力学：最小作用量推导出牛顿方程
  - 几何：测地线（最短路径）方程
  - 最速降线问题（brachistochrone）
- 陷阱：Euler-Lagrange 只给必要条件，需二阶变分判断极大/极小。

**2. 凸优化（现代）**
- 前提：目标函数凸 + 可行域凸。
- 核心红利：**局部最优 = 全局最优**（凸性的礼物）。
- 算法：梯度下降、牛顿法、内点法；约束优化的 KKT 条件。
- 优点：理论优美、算法高效、收敛性可证。
- 缺点：现实多为非凸（深度学习的损失曲面）；凸化是常用近似（LASSO、凸松弛）。
- 引用：华章 71《凸优化》。

**3. 最优控制（LQR / Pontryagin）**
- 问题：在动态系统 ẋ=f(x,u) 下，找控制策略 u(t) 使代价 J=∫ℒ(x,u,t)dt 最小。
- LQR（线性二次型调节器）：线性系统 + 二次代价 → 黎卡提（Riccati）方程解析解。
- Pontryagin 极大值原理：变分法 + 不等式约束的推广，给"最优控制"必要条件。
- 与强化学习（RL）连：Bellman 方程 = 离散时间版动态规划最优控制。

**4. 最小作用量原理（物理）**
- Hamilton 原理：物理系统真实轨迹使作用量 S = ∫ L(q, q̇, t) dt 取极值（通常是极小）。
- 自然规律 = 极值原理：牛顿方程、拉格朗日方程、麦克斯韦方程都能由此导出。
- 地位：现代物理的"第一原理"之一，广义相对论、量子力学（路径积分）都沿用。

## 它们的统一与差异

### 统一：变分法是共同祖先

```
        变分法（函数空间上的微积分）
              │
   ┌──────────┼──────────┐
   │          │          │
 凸优化    最优控制   最小作用量
（利用凸   （加动态   （物理版
  结构）    约束）     变分）
```

- 一句话：**四种优化都是"极值原理"在不同语境下的实例。**
- 变分法 = 无穷维空间上的微积分；
- 凸优化 = 利用凸结构简化的变分；
- 最优控制 = 带动态约束的变分；
- 最小作用量 = 物理版变分。

### 差异：四种面孔的边界

- 变分法：处理"函数空间"极值，但只给必要条件，不保证全局最优。
- 凸优化：唯一能保证**全局最优**的——靠凸性换取强保证。
- 最优控制：多了"时间动态"维度，最优解是策略 u(t) 而非静态点。
- 最小作用量：物理自然规律，不是"设计"出来的优化目标——是描述世界的语言。
- 注意：非凸优化（如深度学习）目前没有统一理论，靠启发式（SGD、动量、Adam）。

## 跨学科这张面孔

| 学科 | 这张面孔叫什么 | 角色 |
|---|---|---|
| ML / 深度学习 | 训练（梯度下降、Adam） | 损失函数极小化 = 学习 |
| 控制论 / 机器人 | LQR / MPC | 最优轨迹规划 |
| 理论物理 | 最小作用量原理 | 自然规律的第一性语言 |
| 运筹 / 量化 | 线性规划、投资组合优化（Markowitz） | 资源/风险最优配置 |
| 数值分析 | 数值优化（拟牛顿、共轭梯度） | 大规模科学计算 |
| 经济学 | 一般均衡、效用最大化 | 市场=优化问题的解 |

**ML 一句话**：训练神经网络 = 在高维非凸损失曲面上做梯度下降——没有凸优化的全局保证，但 SGD + 隐式正则在实践中"足够好"。
