# 14-开放记录轴（Polymath Project）

> 严肃数学研究可大规模公开协作——完整记录含 false starts 和 dead ends 的思考过程，这本身是有价值的数学资源。

## 核心视角

✅ Polymath Project 由 Gowers 发起，文档于 *"Is massively collaborative mathematics possible?"*（2009）和 Gowers & Nielsen *"Massively collaborative mathematics"*（Nature 461:879-881, 2009）。

**Polymath1 案例**（✅）：
- 目标：density Hales-Jewett theorem 的新组合证明
- 规模：40+ 人参与，7 周完成
- 发表：pseudonym "D.H.J. Polymath"
- 意义：证明严肃数学研究可以大规模公开协作

✅ **Gowers 的关键洞见**："the open nature of the collaboration was in the end more important than its size"——**开放性比规模更重要**。

✅ **关键机制**：贡献完全公开可追溯，消除"怕被抢先"的恐惧。每个参与者的思考过程——包括 false starts、dead ends、错误尝试——都被完整记录。

⚠️ 核心价值主张：记录**完整的思考过程**（含错误和死胡同）本身就是有价值的数学资源——不只记最终结果。

✅ **与 Lakatos 的呼应**：Polymath 的"开放记录"精神正是 Lakatos 提倡的 "heuristic style"（展示完整思考过程）的大规模实践。两者共同对抗"deductivist style"（只给最终结果，隐藏挣扎）。

## 作为学习透镜怎么用

**记录 false starts 和 dead ends，不只记最终结果**：

| 记录类型 | 内容 |
|---------|------|
| 试图解决的问题 | 原始问题 + 我的初始理解 |
| 尝试的路径 | 我先试了什么？为什么觉得可行？ |
| 失败的尝试 | 哪条路走不通？为什么走不通？ |
| 转折点 | 什么让我改变方向？ |
| 最终解法 | 怎么走通的？（这只是最后一小步）|
| 反思 | 如果重来，我会怎么做？ |

**具体操作**：
1. 笔记中不只记"正确解法"——记录"我先试了什么、为什么失败"
2. 卡点日志（`10-personal/`）：详细记录卡点与突破，含失败路径
3. 在 `00-META/PROGRESS.md` 的透镜使用记录中如实记录效果
4. 允许"失败笔记"——记录走不通的路，标注"此路不通"及原因

⚠️ **为什么 dead ends 有价值**：
- 避免重蹈覆辙（下次遇到类似问题，知道避开什么）
- 理解正确解法"为什么正确"（对比之下，错误路径暴露了正确路径的必要性）
- 培养元认知（"我怎么想的"比"答案是什么"更重要）
- 降低挫败感（失败是数学研究的常态，记录它让失败有意义）

⚠️ **与学术规范的区别**：学术论文只发成功结果，隐藏失败。但学习笔记不是论文——它是你个人的思考档案，失败记录的边际价值极高。

## 适用数学概念举例

- **任何"卡住"的概念**（卡住本身就是 false start 的信号——记录为什么卡住）
- **难题求解过程**（多路径尝试：哪些走通，哪些走不通）
- **证明尝试**（先写"直觉版"，暴露漏洞，再补严格——过程本身值得记录）
- **反例搜索**（尝试构造反例失败——为什么失败？这暴露了什么？）
- **定义理解**（先误解定义 → 发现误解 → 修正——记录误解本身）
- **计算实验**（代码 bug 导致"发现"——哪些是 bug，哪些是真发现？）
- **跨章节联系**（错误联想 → 发现类比不成立 → 理解差异——记录过程）
- **复习时的再发现**（遗忘后重新推导，第二次路径可能不同——对比记录）
