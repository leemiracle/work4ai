# 09-问题驱动轴（Paul Lockhart + George Pólya）

> "The main problem with school mathematics is that there are no problems."——好问题驱动理解，而非公式操练。

## 核心视角

### Lockhart：数学缺少真正的"问题"

✅ Lockhart 在 *A Mathematician's Lament*（2002 短文, 2009 扩展为书）中提出：

> "The main problem with school mathematics is that there are no problems."

⚠️ 核心主张：数学教育的核心病根是**没有真正的数学问题**——只有公式套用和机械操练。真正的数学问题是有趣的、开放的、激发好奇心的。

✅ Lockhart 主张数学是 "art of explanation"——创造性的解释艺术。好问题比标准答案更重要。一个好问题让你**自己想探索**，而非被动接受。

### Pólya：好问题的启发法

✅ Pólya 在 *How to Solve It*（1945）中的四步框架本质上也是"问题驱动"：
1. Understand the problem——真正理解问题问什么
2. Devise a plan——找切入点
3. Carry out the plan——执行
4. Look back——反思，这个问题能引出什么更深层的问题？

✅ Pólya 的启发法（类比、特殊化、一般化、倒推等）是"面对好问题时怎么想"的工具箱。

### Lockhart + Pólya 的共性

⚠️ 两人共享：**好问题是数学理解的引擎**。Lockhart 强调"什么构成好问题"（有趣、开放、有美感），Pólya 强调"遇到好问题时怎么推进"（启发法清单）。

⚠️ 与"做题"的区别：不是做教材后的机械练习，而是**面对真正引发好奇心的数学问题**——有多个入口、多种解法、能引出更深层概念。

## 作为学习透镜怎么用

**每个概念/章节找一个"驱动问题"**：

好问题的标准（⚠️ 调研归纳 Lockhart 精神）：
- 有趣——你自己想知道答案
- 开放——不只有一种解法
- 有深度——解决它需要理解概念本质
- 可延伸——解决后引出更多问题

**具体操作**：
1. 每章开头，先不看教材——自己想"这个领域有哪些有趣的问题？"
2. 做题时选"好问题"优先（多解法、能推广的），跳过纯机械练习
3. 建立"问题驱动支线"——在 `08-projects/` 中追踪大问题的多路径解法
4. 做完后问 Pólya 第四步"Look back"——这能引出什么更深问题？

⚠️ 项目已有的"问题驱动支线"案例（见 ARCHITECTURE.md §3）：
- FTC（微积分基本定理）的 N 条证明
- π 计算史
- 勾股定理多证
- √2 无理 N 证
- 质数无限多证
- CLT（中心极限定理）多证

这些都是 Lockhart/Pólya 精神的落地——一个好问题，多种解法，深入理解。

## 适用数学概念举例

- **微积分基本定理**（为什么微分和积分互逆？N条证明各暴露什么？）
- **$\sqrt{2}$ 无理**（为什么不能表示为分数？N种证明各用什么思路？）
- **质数无限多**（Euclid证明 vs 其他证明，各暴露什么结构？）
- **勾股定理**（几何证 vs 代数证 vs 动态证，哪种最直观？）
- **$\pi$**（为什么周长/直径是常数？计算史如何演进？）
- **中心极限定理**（为什么和的分布趋向正态？多种证明路径）
- **鸽巢原理**（看似显然，但能解决哪些不显然的问题？）
- **四色定理**（为什么四种颜色就够了？这个问题为什么难？）
