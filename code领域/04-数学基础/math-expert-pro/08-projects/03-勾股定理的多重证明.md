# 勾股定理的多重证明

> 一个定理，已知证法超过 400 种——人类历史上被证明次数最多的数学结论。每一种证法，都是把「直角三角形的几何」与不同数学结构挂钩的尝试。

## 结论陈述

**勾股定理（Pythagorean Theorem）**：在欧氏平面中，直角三角形两直角边长度 $a, b$ 与斜边长度 $c$ 满足
$$a^2 + b^2 = c^2.$$

等价地，以三边为边长作正方形，两直角边正方形面积之和等于斜边正方形面积。

下面给出 **5 条** 思路迥异的证法——分别用全等、代数、相似、面积、内积攻下同一个结论。

---

## 路径 1：欧几里得「风车」证法（《几何原本》I.47，约公元前 300 BCE）

**思路**：纯几何。在直角三角形三边外侧各作一个正方形，用全等三角形证明面积关系。

**关键步骤**（简述欧氏原证的核心）：

1. 设 $\triangle ABC$ 直角在 $C$，三边为 $a=BC, b=CA, c=AB$。分别以 $a, b, c$ 为边作正方形 $BCFG, ACDE, ABHI$（在三角形外侧）。
2. 从直角顶点 $C$ 作斜边 $AB$ 的高，延长交大正方形 $ABHI$ 于 $J$，把大正方形分成两个矩形。
3. **关键引理**：以直角边 $a$（即 $BC$）为边的正方形 $BCFG$ 的面积 = 大正方形中靠近 $a$ 一侧的那个矩形的面积。
4. 引理的证明：作辅助线 $AG$ 与 $KC$（$K$ 是高与 $AB$ 的交点），用 SAS 全等证明 $\triangle ABG\cong\triangle KBC$，进而 $\triangle ABG$ 面积 = $\triangle KBC$ 面积（同底等高），得到正方形 $BFGC$ = 矩形 $ABJK$。
5. 对另一条直角边同理：正方形 $ACDE$ = 矩形 $KHIJ$。
6. 两式相加：$a^2 + b^2 = c^2$。$\square$

**美学**：⭐⭐⭐⭐ 经典「风车图」，几何纯净，但步骤繁琐。

**揭示**：欧几里得的「面积剪切」思想——把一块面积搬到另一处——是后来 Hilbert 在《几何基础》中严格化的「面积理论」起点。

## 路径 2：代数拼图（中国「弦图」/ Bhaskara，约 12 世纪）

**思路**：用四个全等直角三角形拼成大正方形，中间剩一个小正方形。

**关键步骤**：取四个全等的、直角边为 $a,b$、斜边为 $c$ 的直角三角形。把它们拼成一个边长 $a+b$ 的大正方形（每个三角形的一条直角边贴在大正方形边上，斜边朝内），中央留下一个边长 $|a-b|$ 的小正方形（更常见的拼法是斜边围成中央边长 $c$ 的小正方形）。

**经典版（赵爽「弦图」）**：四个直角三角形斜边围成中央边长 $c$ 的正方形，外围是边长 $a+b$ 的大正方形。

- 大正方形面积 = $(a+b)^2$；
- 又 = 4 个三角形 + 中央小正方形 = $4\cdot\frac{ab}{2}+c^2 = 2ab+c^2$；
- 展开 $(a+b)^2 = a^2+2ab+b^2$；
- 故 $a^2+2ab+b^2 = 2ab+c^2$，化简 $a^2+b^2=c^2$。$\square$

**美学**：⭐⭐⭐⭐⭐ 一行代数。Bhaskara（12 世纪印度）据说只写了 "Behold!"（看！）一个词作为证明。

**揭示**：把几何问题化为代数恒等式——这是「代数化几何」的最古老范式。

---

## 路径 3：相似三角形（比例证法）

**思路**：从直角顶点向斜边作高，把原三角形分成两个都与原三角形相似的小三角形。

**关键步骤**：设 $\triangle ABC$ 直角在 $C$，从 $C$ 作斜边 $AB$ 的高 $CH$，垂足 $H$ 把斜边分成两段 $AH=p$ 和 $BH=q$（$p+q=c$）。注意：$p$ 是邻接边 $b=CA$ 的那段（$A$ 到 $H$），$q$ 是邻接边 $a=BC$ 的那段（$B$ 到 $H$）。

**关键观察**：$\triangle ACH \sim \triangle ABC$（共角 $\angle A$ 与一直角），相似比给出
$$\frac{AC}{AB} = \frac{AH}{AC} \;\Rightarrow\; b^2 = c\cdot p.$$
同理 $\triangle BCH \sim \triangle ABC$ 得
$$\frac{BC}{AB}=\frac{BH}{BC}\;\Rightarrow\;a^2 = c\cdot q.$$

相加：
$$a^2+b^2 = c\cdot p + c\cdot q = c(p+q) = c\cdot c = c^2. \;\square$$

**美学**：⭐⭐⭐⭐ 简洁、深刻。

**揭示**：勾股定理其实是「**相似 + 比例**」的推论——只要有相似三角形，就有 $a^2=cq$ 这类「线段乘积 = 线段乘积」的关系。**毕达哥拉斯定理本质上是射影几何 + 度量**的结合。

## 路径 4：Garfield 梯形证法（1876）

**思路**：两个全等直角三角形拼成梯形。

**关键步骤**（James A. Garfield，美国第 20 任总统，1876 年发表于 *New England Journal of Education*）：

把两个全等的、直角边 $a,b$、斜边 $c$ 的直角三角形如下图放置——让一条直角边（长度 $b$）重合，且两个三角形关于这条边镜像，构成一个**直角梯形**。梯形上下底分别为 $a$ 和 $b$（实际上是 $a$ 在上、$b$ 在下，或反之），高 $a+b$。

实际上更准确的描述：把两个三角形按一条直角边（$a$）首尾相接，使得它们的斜边构成梯形内部的一条对角线。具体地，让第一个三角形直角边沿 $x$ 轴和 $y$ 轴，顶点 $(0,0), (a,0), (0,b)$；第二个三角形旋转后顶点 $(a,0), (a+b, 0), (a, b)$（沿 $x$ 轴一段长 $b$）。这三点加原点构成梯形。

- **梯形面积**（上底 $b$，下底 $a+b$，高 $a$... 这里采用最经典版本）：

> 标准版本：梯形三顶点 $(0,0),(a+b,0),(a,b)$，加上 $(0,0)$——其实是三角形不是梯形。修正如下：取三个直角三角形拼成直角梯形。梯形的两底分别为 $a$ 与 $b$（平行），高为 $a+b$。

**最干净的写法**：三个顶点 $A=(0,0)$，$B=(a+b, 0)$，$C=(a, b)$。$\triangle ABC$ 可以看作「两个直角三角形 + 一个等腰直角三角形」的组合：
- 从 $C$ 作 $x$ 轴垂线，垂足 $D=(a, 0)$；
- $\triangle ACD$ 是直角三角形（直角边 $a, b$，斜边 $c$）；
- $\triangle BCD$ 是直角三角形（直角边 $b, a$，斜边 $c$）；
- $\triangle ABC$ 不是直角三角形，但 $AB=a+b$，$C$ 到 $AB$ 的高度是 $b$，面积 $\frac{1}{2}(a+b)\cdot b$。

**经典 Garfield 梯形**：把两个全等直角三角形（直角边 $a,b$ 斜边 $c$）和它们之间夹的一个**等腰直角三角形**（直角边 $c$）拼成一个**直角梯形**：
- 梯形面积 = $\frac{1}{2}(a+b)(a+b) = \frac{(a+b)^2}{2}$；
- 又 = 三个三角形面积之和 = $\frac{ab}{2}+\frac{ab}{2}+\frac{c^2}{2}$；
- 等式 $\frac{(a+b)^2}{2} = ab + \frac{c^2}{2}$；
- 两边乘 2：$a^2+2ab+b^2 = 2ab+c^2$；
- 化简 $a^2+b^2=c^2$。$\square$

**美学**：⭐⭐⭐⭐⭐ 政治家贡献的传世证法，简洁优雅。

## 路径 5：向量 / 内积证法（现代代数）

**思路**：勾股定理 = 正交性 + 内积双线性。

**关键步骤**：设两直角边对应向量 $\vec u, \vec v\in\mathbb R^n$，正交意味着内积为零：$\vec u\cdot\vec v=0$。斜边向量是 $\vec u - \vec v$（或 $\vec u+\vec v$，取决于方向约定）。计算其长度的平方：
$$|\vec u-\vec v|^2 = (\vec u-\vec v)\cdot(\vec u-\vec v) = |\vec u|^2 - 2\,\vec u\cdot\vec v + |\vec v|^2 = |\vec u|^2 + |\vec v|^2.$$

最后一步用了正交性 $\vec u\cdot\vec v=0$。$\square$

**美学**：⭐⭐⭐⭐⭐ 一行！这是「升格」的典范——把几何问题化为代数恒等式。

**揭示的本质**：勾股定理的代数灵魂是「**正交性**」。一旦看清这一点，勾股定理立刻推广到任意内积空间：
- $\mathbb R^n$ 中，正交向量长度平方可加；
- 函数空间 $L^2[0,1]$ 中，正交函数（如 $\sin(2\pi nx)$ 与 $\cos(2\pi mx)$）的内积为零，「长度」$\|f\|^2=\int|f|^2$ 满足勾股定理——这是**傅里叶分析的根基**（Parseval 等式）；
- ML 中的核方法（kernel trick）建立在再生核希尔伯特空间 RKHS 的内积上，本质上还是「正交分解」。

## 哪条路径最能揭示本质？为什么

**路径 5（向量内积）最深刻**。

它把勾股定理从「特殊平面图形的性质」升格为「**正交性的代数定义**」：
- 在 $\mathbb R^n$ 中，两个向量正交（内积为零）$\iff$ 它们的长度平方满足勾股定理；
- 在 $L^2$ 函数空间中，正交函数系满足 Parseval 等式——这就是无穷维勾股定理；
- 在 ML 中，PCA、核方法、神经网络正交初始化——全都建立在「正交分解」之上。

**反过来理解**：欧氏平面里的勾股定理**只是**内积空间一般规律的二维特例。Grothendieck「升起之海」的精神在此显现——把孤立定理沉入更广的框架（内积空间），它就变成框架内的平凡事实。

**对学习者**：先做路径 2（弦图，一眼看穿）建立直觉，再读路径 1（欧氏风车）感受古典严格，最后用路径 5（向量内积）完成「升格」——从平面几何跨入线性代数与泛函分析。
