# 问题驱动轴：一个大问题的多条证明路径

> 本目录是「问题驱动轴」（Lockhart / Pólya）——好数学从**好问题**出发，而非从一堆公式出发。真正的理解，来自为同一结论寻找**多种证明**。

## 为什么「多证法」是好数学

Paul Lockhart 在《A Mathematician's Lament》里写下这句刺穿一切的话：

> "The main problem with school mathematics is that there are no problems."

学校数学把数学写成「公式 → 例题 → 习题」的流水线，掩盖了数学的本来面目——**数学是想象力的艺术探险**。真正的数学理解，不是「记住一个证明」，而是「为同一结论找到多种截然不同的证明路径」。每条路径用不同的工具、不同的视角、不同的美感攻下同一个结论，于是这个结论被你**从多个侧面**看清。

William Thurston 在 *On Proof and Progress in Mathematics*（1994）里列出理解数学的**五种模态**：① 人类语言；② 视觉/空间/动觉意象；③ 逻辑与演绎；④ 过程与算法；⑤ 与其他领域的类比。「同一结论的多条证明」恰好把五个模态全部激活。

## 为什么「多证法」有价值

1. **不同证法揭示不同的结构联系**。例如 $\pi$ 既是几何常数（圆周长/直径），又是分析常数（无穷级数），又是概率常数（Buffon 投针）。看 $\pi$ 被几何、分析、概率三种方式攻下，才能看清它如何把三个分支缝合在一起。
2. **培养证明策略嗅觉**。George Pólya《How to Solve It》的启发法——「这像什么已知问题？能特殊化吗？能一般化吗？有类比吗？」——只有在**见过同一结论的多种攻法**之后，才能在面临新问题时灵活调动。单证法训练出来的 strategist 只会一招。
3. **美学享受**。Lockhart 写道，数学是 "the music of reason"。看 Euler 用发散级数攻下 $\pi$，再看他用复指数攻下同一个 $\pi$；看 Euclid 用反证攻下素数无限，再看 Furstenberg 用拓扑攻下同一个结论——这是「为同一旋律听到多种变奏」的美学体验。

Euler 的精神（非原话，是后人概括）：**一个结论被多次独立证明，才真正可信、真正被理解**。Euler 本人就喜欢对同一个结论给出多种证明，他认为这是检验真理的最高标准。

## 本目录的设计

每个项目遵循统一结构：

```
# 结论的 N 条证明路径
## 结论陈述
## 证明路径1（名称）：完整思路 + 关键步骤
## 证明路径2：...
## 证明路径N：...
## 各路径对比表（适用条件 / 深刻度 / 所需工具 / 美学）
## 哪条路径最能揭示本质？为什么
## 推荐深入阅读
```

对比表是**核心**——把同一结论的不同证法并列展示，让你一眼看出哪条简洁、哪条深刻、哪条可推广、哪条只是审美游戏。

## 阅读建议

- **可按兴趣跳读**：每个项目完全独立，无前置依赖。
- 入门建议顺序：03 勾股（最具体）→ 04 $\sqrt{2}$ → 05 质数 → 02 $\pi$ → 01 FTC → 06 CLT（最抽象）。
- 阅读时多停顿，先自己想「我会怎么证」再看路径——Pólya 启发法的真正训练发生在「自己想」那几秒。
- 看完一个项目后，回头问自己 Thurston 五模态问题：我能用语言、视觉、逻辑、算法、类比这五种方式分别解释这个结论吗？
