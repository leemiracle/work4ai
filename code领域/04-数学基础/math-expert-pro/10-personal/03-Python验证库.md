## 0. 核心策略：用工程优势补数学弱项

你是 Python 工程级，数学零基础。**用代码做数学实验**是你最大的杠杆：

> 把每个抽象定理变成"可运行、可可视化、可改参数"的代码，让工程直觉带着数学直觉走。

你的工程能力在这里转化为数学能力：
- 写测试 = 验证定理（断言定理成立）
- 调试 = 找反例（什么时候定理失效？）
- 可视化 = 把抽象公式变成图（matplotlib）
- 蒙特卡洛 = 用采样逼近解析结果

## 2. 可复用的验证模式（写新脚本时的模板）

这 12 个脚本沉淀出几种可复用的"数学实验模式"，写新验证时直接套用：

### 模式 A：numpy 数值验证定理
```python
# 验证"线性映射的核的维数 + 像的维数 = 定义域维数"
A = np.array([[1,2,3],[4,5,6]])
assert np.linalg.matrix_rank(A) + (3 - np.linalg.matrix_rank(A)) == 3
```
适用：代数恒等式、维数定理、行列式性质。

### 模式 B：matplotlib 可视化抽象概念
```python
# 把 ε-δ 定义画成图：给定 ε 带，找 δ 带
fig, ax = plt.subplots()
ax.fill_between(xs, L-eps, L+eps, alpha=0.3)  # ε 带
```
适用：极限、连续、导数（切线动画）、积分（黎曼和矩形）。

### 模式 C：蒙特卡洛逼近解析结果
```python
# 投点估 π：解析结果（π）vs 采样估计（4×命中比）
hits = np.sum(x**2 + y**2 < 1)
pi_est = 4 * hits / N
# 误差 ~ 1/√N（CLT 的直觉）
```
适用：概率、期望、积分、大数定律。

### 模式 D：符号计算（sympy，阶段 2 引入）
```python
import sympy as sp
x = sp.symbols('x')
sp.diff(sp.sin(x)*sp.exp(x), x)   # 符号求导
sp.integrate(1/(1+x**2), x)        # 符号积分 = atan
```
适用：验证求导/积分法则、泰勒展开、极限的符号计算。

### 模式 E：动画/交互（matplotlib FuncAnimation）
适用：梯度下降轨迹、Gram-Schmidt 逐步正交化、扩散过程。

## 3. 方法论：用代码做数学实验的四步

```
① 猜测   ：从直觉猜一个结论（如"黎曼和越多矩形越接近真实面积"）
② 编码   ：把猜测写成可运行的断言/可视化
③ 跑通   ：运行，看是否如预期（绿色）还是反例（红色）
④ 反思   ：为什么成立/不成立？回教材找严格证明
```

> 这四步正好是 [02-lens-mathematicians 计算实验轴]（Wolfram）的落地，也呼应 Tao 的"pre-rigorous→rigorous"：代码帮你停在 pre-rigorous 阶段建直觉，严格证明由教材完成。
