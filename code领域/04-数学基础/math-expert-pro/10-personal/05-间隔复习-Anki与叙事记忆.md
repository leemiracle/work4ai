# 间隔复习：Anki 与叙事记忆

> Matuschak / Nielsen 的 mnemonic medium（记忆媒介）方法，升级你的 Anki 使用。
> 关联 [02-lens-mathematicians/反思层/叙事记忆轴]（Matuschak/Nielsen）。
> 配合 [00-META/PROGRESS.md] 的"间隔复习队列"维度。

---

## 0. 核心问题：为什么普通 Anki 卡对数学不够用

普通 Anki 卡记的是"碎片"：定义、公式。但研究级数学需要的是**理解**——"为什么 X 成立"、"X 和 Y 的区别"、"X 在什么情况下失效"。

Andy Matuschak 和 Michael Nielsen 的洞察（叙事记忆轴）：

> **真正持久的理解，不是靠记碎片，而是把知识嵌入"叙事"——一个有上下文、有动机、有连接的故事。**

所以你的 Anki 要从"记碎片"升级为"记理解"。

---

## 1. Anki 使用四条升级原则

### 原则 ①：不只记公式/定义，记"为什么 X 成立"（理解型卡） | 卡类型 | 例子 | 效果 |
|--------|------|------|
| ❌ 碎片卡 | 正面"特征值定义"，背面"det(A−λI)=0 的根" | 死记，易忘，不会用 |
| ✅ 理解型卡 | 正面"为什么 Axler 不用行列式也能定义特征值？"，背面"特征值是几何不变量 T(v)=λv，det 只是计算手段" | 记住的是理解 |

> 规则：每张卡问自己"如果只看正面，我能讲清为什么吗？"——能，才是好卡。

### 原则 ②：新卡必须绑定上下文故事

孤立的新卡 = 孤儿卡片（见原则③）。新卡要绑：
- **来源**：从哪本教材/哪个笔记/哪次顿悟来的
- **动机**：当年谁为什么需要这个概念
- **连接**：它和已知的什么相连

```
新卡模板：
  正面：问题/提示
  背面：答案 + 【来源：Spivak ch5】+【动机：…】+【连接：与 LADR ch5 对应】
```

### 原则 ③：定期清理孤儿卡片

孤儿卡片 = 没有上下文、长期记不住、也不知道为什么在牌组里的卡。它们会拖垮复习动力。

每月一次清理：
- 连续 3 次答错的卡 → 要么加上下文（原则②），要么删掉
- "我也不知道为什么加这张"的卡 → 删
- 重复/可合并的卡 → 合并

### 原则 ④：从 math-expert-pro 笔记提炼卡片的流程

```
读完一篇八重视角笔记（NOTES_TEMPLATE.md）
  ↓
挑出 3-5 个"如果忘了就等于没学"的理解点
  ↓
每个点做成理解型卡（原则①），绑定上下文（原则②）
  ↓
加进 Anki，纳入日常间隔复习
```

> 关键：**卡的质量 > 卡的数量**。一篇笔记 3-5 张好卡，胜过 20 张碎片卡。

## 2. 理解型卡的三个层次

| 层次 | 问法 | 例子 |
|------|------|------|
| L1 概念卡 | "X 是什么？" | "σ-代数是什么？" → "Ω 的子集族，对补/可数并封闭" |
| L2 关系卡 ⭐ | "X 和 Y 有什么区别/联系？" | "依概率收敛 vs 几乎必然收敛，区别？" |
| L3 洞察卡 ⭐⭐ | "为什么 X 成立？/ X 在何时失效？" | "为什么黎曼积分处理不了 Dirichlet 函数？" → "它处处不连续，黎曼和振荡不收敛" |

> L2 关系卡和 L3 洞察卡是研究级数学的核心——它们训练的是"理解"而非"记忆"。多造这两类卡。

---

## 3. 卡片与多视角架构的连接

每个理解点可以从多个视角出卡，让复习本身变成"多视角回访"：

| 透镜 | 出卡角度 | 例子 |
|------|---------|------|
| 多模态理解轴 | "用代码怎么验证 X？" | "用 numpy 怎么验证谱定理？" |
| 历史脉络轴 | "X 是谁、为什么发明的？" | "Weierstrass 为什么搞 ε-δ？" |
| 对比反例轴 | "X 的反例是什么？" | "处处连续但处处不可导的函数？" |
| AI 锚点法 | "X 在 AI 里怎么用？" | "特征值 → PCA → 降维，链条？" |
| 批判边界轴 | "X 在什么情况下失效？" | "CLT 在重尾分布下失效？" |

---

## 4. 复习节奏建议

| 频率 | 内容 | 时长 |
|------|------|------|
| 每天 | Anki 间隔复习队列（系统调度）| 10-15 min |
| 每周 | 清理本周新增卡的上下文（原则②）| 10 min |
| 每月 | 孤儿卡片清理（原则③）| 20 min |

> ⚠️ **可持续纪律**：Anki 每天别超过 20 分钟。复习是"防遗忘"不是"主学习"——主线永远是精读 + 做题 + 写笔记。

## 5. 从 math-expert-pro 笔记批量提炼卡片（示例）

以 [01-track/.../spivak_01_limits.md]（极限）为例，可提炼的理解型卡：

```
卡1（L3 洞察）：为什么极限定义里是"0 < |x−a| < δ"而不是"|x−a| < δ"？
    → 因为极限不关心 x=a 处的值，只关心趋近过程。

卡2（L2 关系）：∀ε∃δ 和 ∃δ∀ε 的区别？
    → 前者（正确）：对手任意给 ε，我都能找到 δ。后者（错误）：存在万能 δ。

卡3（L3 洞察/AI锚点）：sin(1/x) 为什么没有极限？
    → 在 0 附近无限震荡，找不到固定趋近值。→ 训练 loss 震荡不收敛的数学原型。

卡4（多模态/代码）：用 Python 怎么"自动找 δ"？
    → 给定 ε，二分搜索满足 |f(x)−L|<ε 的最大 δ 区间。
```

> 💡 这 4 张卡覆盖了极限的"理解"而非"记忆"。一个月后复习，你回想起的是顿悟，不是死记。

> 📖 方法论原文：Matuschak/Nielsen "How to do great work" / "Augmenting Long-term Memory"（叙事记忆轴来源）。
