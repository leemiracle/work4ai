# 卡点与突破日志

> 模板文件：记录每个卡点（什么概念/卡在哪/试了什么/怎么突破/耗时）。
> 关联 [02-lens-mathematicians/反思层] 的两条轴：
> - **创造节奏轴**（Poincaré/Hadamard 四阶段）：苦思 → 孵化 → 顿悟 → 验证
> - **开放记录轴**（Polymath）：记录 false starts，卡点也是数据。

---

## 0. 为什么要记卡点

两个反直觉的事实：
1. **卡点不是失败，是数据**。记录"试了什么没用"，比只记"最终怎么懂的"更有价值（开放记录轴）。
2. **顿悟常发生在"放下"之后**。苦思无果 → 暂时搁置（孵化）→ 某个瞬间突然想通（顿悟）。这是 Poincaré/Hadamard 的创造四阶段。

> **使用纪律**（来自 [01-我的画像 §5](01-我的画像与学习偏好.md)）：**卡 3 天跳过**，标记回头补。可持续 > 完美主义。

---

## 1. 创造节奏四阶段（每个卡点的生命周期）

```
① 苦思    →  ② 孵化    →  ③ 顿悟    →  ④ 验证
（主动钻研）  （暂时搁置）  （突然想通）  （严格确认）
``` | 阶段 | 状态 | 你该做什么 |
|------|------|-----------|
| ① 苦思 | 卡住、难受 | 主动试多种方法（换书/换视角/写下来）|
| ② 孵化 | 暂时放下 | 去散步/睡觉/学别的，让潜意识工作 |
| ③ 顿悟 | "啊哈！" | 立刻记下灵感（容易忘）|
| ④ 验证 | 兴奋但谨慎 | 用严格证明/代码验证灵感对不对 |

> 💡 第②步最反直觉：**主动允许自己"暂时不懂"**。强撑苦思往往无效，孵化期才是顿悟的温床。

## 2. 卡点记录模板

每遇到卡点，复制下面的模板记一条（日期/概念/卡点/尝试/突破/耗时/反思）：

```markdown
### YYYY-MM-DD｜概念名

- **什么概念**：（如 ε-δ 极限定义 / 谱定理证明）
- **卡在哪**：（具体描述，如"不知道 δ 怎么从 ε 推出来"）
- **尝试了什么**（false starts，照实记）：
  1. 试法 A → 结果（没用，因为…）
  2. 试法 B → 结果（部分有用，但…）
- **怎么突破的**：
  - 触发：（换书？看 3Blue1Brown？睡一觉？跑代码？）
  - 顿悟：（一句话，"原来 δ 可以取 ε/2 因为…"）
- **严格验证**：（教材第几页 / .py 脚本 / 同伴讨论）
- **耗时**：苦思 X 小时 + 孵化 Y 天 + 顿悟瞬间
- **用了哪个透镜**：（计算实验轴？多模态理解轴？AI 锚点法？）
- **反思**：（下次遇到类似卡点，更快的路径是…）
```

## 3. 卡点示例（2 条示范）

### 2026-XX-XX｜ε-δ 极限（示范）

- **什么概念**：Spivak 的 ε-δ 极限定义
- **卡在哪**：分不清"∀ε ∃δ"和"∃δ ∀ε"的区别
- **尝试了什么**：
  1. 反复读定义 → 没用，越读越糊
  2. 查 Wikipedia → 图示帮助有限
- **怎么突破的**：
  - 触发：写 [01-track/.../spivak_01_limits.py] 跑"程序自动找 δ"
  - 顿悟："∀ε ∃δ" = 嵌套循环，外层是 ε（对手任意给），内层是 δ（我必须找得到）
- **严格验证**：Spivak 第 5 章习题 + 代码断言
- **耗时**：苦思 3h + 孵化 1 天 + 顿悟 5 分钟
- **用了哪个透镜**：计算实验轴（代码）+ 多模态理解轴（程序循环类比）
- **反思**：量词嵌套用编程循环类比最有效，下次先这么建直觉

### 2026-XX-XX｜Axler 为什么不用行列式（示范）

- **什么概念**：LADR 特征值不靠 det(A−λI)
- **卡在哪**：习惯了"det 求特征值"，突然不用 det 很别扭
- **尝试了什么**：
  1. 硬读 LADR → 卡在抽象证明
  2. 翻 Horn-Johnson 对照 → 信息太多
- **怎么突破的**：
  - 触发：放下去散步（孵化），回来查"Axler 不用行列式 争议"
  - 顿悟："det 是计算工具，但特征值的本质是几何不变量（T(v)=λv）"
- **严格验证**：[09-crosstext/01-线代三书对照] Axler vs Horn-Johnson 对比
- **耗时**：苦思 2h + 孵化 2 天 + 顿悟瞬间
- **用了哪个透镜**：对比反例轴（多教材对照）+ 暂时搁置（创造节奏②）

## 5. 月度复盘问题

每月末翻一遍卡点日志，问自己：

1. 这个月卡得最多的是哪个主题？（可能说明根基不牢，需回补）
2. 哪种突破方式最有效？（换书？代码？孵化？）
3. 有没有"卡 3 天"该跳过却硬撑的？（违背可持续原则）
4. false starts 里有没有其实指向了正确方向的？（被错过的灵感）
