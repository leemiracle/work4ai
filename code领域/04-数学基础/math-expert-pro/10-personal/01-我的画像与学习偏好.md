### 1.1 关键洞察：数学零基础，但有工程逻辑思维

你虽然数学零基础，但**工程级编程 = 强逻辑思维**。这意味着：
- ε-δ 证明里的量词嵌套（∀ε ∃δ）= 编程里的嵌套循环 + 条件判断
- 数学归纳法 = 递归 / for 循环
- 反证法 = 断言失败（assert false）
- 公理化系统 = 接口契约 / 类型系统

> **补数学应较顺利**——你不是从零学逻辑，你是把已有的工程逻辑迁移到数学语言。这是你相对纯文科转数学者的最大优势。

## 3. 学习风格：五层递进

这是你固定的吸收节奏（强化三层法，必带缺陷分析与场景补充）：

```
① 直觉  →  ② 公式  →  ③ 代码  →  ④ 不足/缺陷/弥补  →  ⑤ 应用场景
```

| 层 | 做什么 | 工具 |
|----|--------|------|
| ① 直觉 | 先建立"这是什么、为什么需要它"的图像 | 3Blue1Brown + 历史故事 + 类比 |
| ② 公式 | 严格定义 + 定理 + 证明 | Spivak/LADR/Ross 主用书 |
| ③ 代码 | 用 Python 验证/可视化定理 | [03-Python验证库](03-Python验证库.md) |
| ④ 不足 | 这个定义/定理的缺陷、反例、边界 | [06-counterexamples/](../06-counterexamples/) + [07-critique/](../07-critique/) |
| ⑤ 应用 | 它在 AI/工程/物理/金融里怎么用 | [02-AI锚点法](02-AI锚点法-数学落到工程.md) |

> 这五层正好对应 [NOTES_TEMPLATE.md](../NOTES_TEMPLATE.md) 八重视角的核心节：§1 直觉 → §4 证明 → §8 代码 → §5/§6 反例批判 → §7/§9 应用。

## 4. 时间切分：6:5:4

每周 10-20h，强制结构切分（旧路径 §2/§11）：

| 块 | 占比 | 时长（按 15h）| 做什么 |
|----|------|--------------|--------|
| 📖 输入 | 6 | ~6h | 精读教材（主动推导，不是看小说）|
| ✍️ 输出 | 5 | ~5h | 写笔记 + 证明 + 代码验证 |
| 🤝 应用 | 4 | ~4h | 把当周数学落到一个 AI/工程项目 |

> **反"只读不写"**：没有输出的输入 = 没学到。每章必产出（笔记 + 代码 + 练习）。
