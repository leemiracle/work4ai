## 0. 为什么需要 AI 锚点法

你的三约束：🎯 研究级深度 + 🔧 工程落地 + 🎨 趣味性。AI 锚点法是后两者的交汇：

> **每个抽象数学概念，必须找到一个 AI/工程落地。**

它的作用：
1. **防悬空**：学了测度论却不知道它怎么用 → 锚点让它落地
2. **续燃料**：看到"这个数学真的能跑"，趣味性大增
3. **发挥优势**：你是工程师，用代码理解数学比纯符号快

> ⚠️ **纪律**（架构 §7.3）：AI 锚点里的 🟢【事实】可作理解锚点，🟡【类比】仅供直觉搭建，**绝不在严格证明中引用**。

## 2. AI 锚点法的使用流程

学一个新数学概念时，按这个流程找锚点：

```
1. 这个概念的本质是什么？（一句话）
   ↓
2. 它在 AI/工程里有对应物吗？（查上面的映射表）
   ├─ 有 → 标注锚点，写进笔记 §9（AI/工程应用锚点）
   └─ 暂时没找到 → 标记"待锚点"，继续学，阶段 2-3 再回找
3. 能用 Python 验证这个锚点吗？（→ 03-Python验证库）
   └─ 能 → 写 .py 跑通（最佳：直觉→公式→代码三闭环）
```

## 3. 锚点深度分级

不是所有锚点都同等可靠（架构 §7.3 事实vs类比纪律）：

| 级别 | 含义 | 能否在证明中用 |
|------|------|--------------|
| 🟢【事实】| 数学结构在 AI 里的真实对应（如 PCA = 特征值分解）| ✅ 可作理解锚点 |
| 🟡【类比】| 启发式类比，帮助建直觉（如"σ-代数≈信息流"）| ❌ 仅直觉，不可引用证明 |
| 🔴【悬空】| 暂时找不到锚点 | 标记，不强行编 |

> 上面的映射表大多是 🟢 事实级。遇到 🟡 要心里清楚它只是脚手架。
