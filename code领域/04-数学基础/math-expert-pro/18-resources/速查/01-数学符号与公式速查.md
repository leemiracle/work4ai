## 1. 希腊字母表

| 小写 | 大写 | LaTeX | 英文读音 | 中文读音 | 常见数学用途 |
|------|------|-------|----------|----------|-------------|
| α | A | `\alpha` `A` | alpha | 阿尔法 | 角度、显著性水平、系数 |
| β | B | `\beta` `B` | beta | 贝塔 | 角度、系数、Beta 分布 |
| γ | Γ | `\gamma` `\Gamma` | gamma | 伽马 | 欧拉常数 Γ(n)、Gamma 函数、光线 |
| δ | Δ | `\delta` `\Delta` | delta | 德尔塔 | 变分、变化量 Δ、Dirac δ 函数 |
| ε | Ε | `\epsilon` / `\varepsilon` | epsilon | 艾普西龙 | 极小正数、极限定义、误差 |
| ζ | Ζ | `\zeta` | zeta | 泽塔 | Riemann ζ 函数 |
| η | Η | `\eta` `\Eta` | eta | 伊塔 | 效率、粘性系数 |
| θ | Θ | `\theta` `\Theta` | theta | 西塔 | 角度、参数、Big-Θ |
| ι | Ι | `\iota` | iota | 约塔 | 单位矩阵的极小记号、包含映射 |
| κ | Κ | `\kappa` `\Kappa` | kappa | 卡帕 | 曲率、一致性 |
| λ | Λ | `\lambda` `\Lambda` | lambda | 兰姆达 | 特征值、Lambda 演算、波长 |
| μ | Μ | `\mu` `M` | mu | 缪 | 均值、微(μ)、摩擦系数 |
| ν | Ν | `\nu` `N` | nu | 纽 | 自由度、频率 |
| ξ | Ξ | `\xi` `\Xi` | xi | 克西 | 随机变量（概率论） |
| ο | Ο | `o` `O` | omicron | 奥密克戎 | 小 o 记号（与大 O 区分） |
| π | Π | `\pi` `\Pi` | pi | 派 | 圆周率、乘积 Π |
| ρ | Ρ | `\rho` | rho | 柔 | 密度、相关系数、半径（球坐标） |
| σ | Σ | `\sigma` `\Sigma` | sigma | 西格玛 | 标准差、求和 Σ、σ-代数 |
| τ | Τ | `\tau` `T` | tau | 陶 | 扭矩、时间常数、1/(2π) 的倡导 |
| υ | Υ | `\upsilon` `\Upsilon` | upsilon | 宇普西龙 | 与 ν 类似，较少用 |
| φ | Φ | `\phi` / `\varphi` `\Phi` | phi | 斐 | 黄金比例、欧拉 φ 函数、相位 |
| χ | Χ | `\chi` `X` | chi | 卡 | 卡方分布 χ²、特征（群论） |
| ψ | Ψ | `\psi` `\Psi` | psi | 普西 | 波函数、双射映射 |
| ω | Ω | `\omega` `\Omega` | omega | 欧米伽 | 角速度、样本空间 Ω、序数 |

> 💡 `\epsilon` vs `\varepsilon`：前者是卷曲 ε，后者是 φ 形 ε，后者在严格分析中更常用。`\phi` vs `\varphi` 同理。

## 2. 集合论符号

| 符号 | LaTeX | 读法 | 含义 |
|------|-------|------|------|
| ∈ | `\in` | belongs to | 属于 |
| ∉ | `\notin` | not in | 不属于 |
| ⊂ | `\subset` | subset | 真子集 |
| ⊆ | `\subseteq` | subset or equal | 子集 |
| ⊃ | `\supset` | superset | 真超集 |
| ⊇ | `\supseteq` | superset or equal | 超集 |
| ∪ | `\cup` | union | 并集 |
| ∩ | `\cap` | intersection | 交集 |
| ∅ | `\emptyset` | empty set | 空集（也可 `\varnothing`）|
| ∖ | `\setminus` | set difference | 差集 A∖B |
| △ | `\triangle` | symmetric difference | 对称差 |
| × | `\times` | cartesian product | 笛卡尔积 |
| 𝒫 / 2^ | `\mathcal{P}` | power set | 幂集 |
| ∣ | `\mid` | such that | 使得（集合构造符 {x ∣ ...}） |
| ℵ | `\aleph` | aleph | 超限基数（ℵ₀, ℵ₁...） |

> 💡 `\mathbb{...}` 需要宏包 `amssymb`（LaTeX）或直接在 Markdown/MathJax 中可用。

## 7. LaTeX 数学排版常用命令速查

### 7.1 数学环境
```latex
$ ... $          % 行内公式
$$ ... $$        % 独立公式（不编号）
\begin{equation} ... \end{equation}    % 编号公式
\begin{align} ... \end{align}          % 多行对齐
\begin{cases} ... \end{cases}          % 分段函数
\begin{matrix} ... \end{matrix}        % 矩阵（无括号）
\begin{pmatrix} ... \end{pmatrix}      % 矩阵（圆括号）
\begin{bmatrix} ... \end{bmatrix}      % 矩阵（方括号）
\begin{vmatrix} ... \end{vmatrix}      % 行列式
```

### 7.2 常用排版命令
```latex
\frac{a}{b}      % 分数
\sqrt{x}          % 根号
\sqrt[n]{x}       % n 次根号
\overline{x}      % 上划线
\underline{x}     % 下划线
\widehat{x}       % 宽帽子
\widetilde{x}     % 宽波浪
\vec{v}           % 向量箭头
\overrightarrow{AB} % 右箭头
\text{文字}       % 数学环境中的文字
\mathrm{d}        % 直立 d（微分）
\operatorname{Hom} % 自定义运算符
```

### 7.3 空格控制
```latex
\quad    % 1em 空格
\qquad   % 2em 空格
\,       % 小空格 (3/18 em)
\:       % 中空格 (4/18 em)
\;       % 大空格 (5/18 em)
\!       % 负空格 (-3/18 em)
```

### 7.4 常用宏包
```latex
\usepackage{amsmath}    % 数学排版核心
\usepackage{amssymb}     % 数学符号（含 \mathbb, \square 等）
\usepackage{mathtools}   % amsmath 增强
\usepackage{theorem}     % 定理环境
\usepackage{bm}          % 粗体数学符号 \bm{x}
\usepackage{mathrsfs}    % 花体字母 \mathscr{...}
```

### 7.5 定理环境
```latex
\newtheorem{theorem}{Theorem}[section]
\newtheorem{lemma}[theorem]{Lemma}
\newtheorem{corollary}[theorem]{Corollary}
\newtheorem{definition}[theorem]{Definition}

\begin{theorem}[名称]\label{thm:1}
...
\end{theorem}
```
