# LaTeX 数学公式速查

> 用 LaTeX 写数学的完整参考。

---

## 基础语法
```
行内：$E = mc^2$
行间：$$\int_0^\infty e^{-x} dx = 1$$
```

## 希腊字母
```
α \alpha  β \beta  γ \gamma  δ \delta  ε \epsilon
θ \theta  λ \lambda  μ \mu  π \pi  σ \sigma
φ \phi  ψ \psi  ω \omega  Δ \Delta  Σ \Sigma
∂ \partial  ∇ \nabla  ∞ \infty  ∈ \in
```

## 运算符
```
求和 \sum_{i=1}^{n}
积分 \int_{a}^{b}
极限 \lim_{x \to 0}
分数 \frac{a}{b}
根号 \sqrt{x}, \sqrt[n]{x}
幂 x^{n}, 下标 x_{i}
矩阵 \begin{pmatrix} a & b \\ c & d \end{pmatrix}
```

## 常用环境
```
方程：\begin{equation}...\end{equation}
多行：\begin{align}...\end{align}
分段：f(x) = \begin{cases} 1 & x>0 \\ 0 & x \leq 0 \end{cases}
```

## 集合/逻辑
```
∪ \cup  ∩ \cap  ⊂ \subset  ⊆ \subseteq
∀ \forall  ∃ \exists  ¬ \neg  ∧ \wedge  ∨ \vee
→ \to  ↔ \leftrightarrow  ⟹ \implies  ⟺ \iff
```

## 排版技巧
```
粗体向量 \mathbf{x} 或 \vec{x}
黑板粗 \mathbb{R}, \mathbb{N}, \mathbb{Z}
书法体 \mathcal{F}, \mathcal{L}
```
