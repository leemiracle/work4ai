## 2. 与 09-crosstext 的分工

| 维度 | 09-crosstext（教材） | 18-resources（教材之外） |
|------|---------------------|------------------------|
| **核心载体** | 书（PDF / 纸质） | 课程 / 软件 / 网站 / 视频 / 社区 |
| **使用场景** | 系统学习某分支 | 辅助学习、解决问题、追踪前沿 |
| **深度** | 完整知识体系 | 工具性、启发性、连接性 |
| **更新频率** | 低（经典教材不常变） | 高（工具和社区持续迭代） |
| **典型动作** | "我要学实分析，读 Rudin" | "积分算不出来，用 SymPy / 问 MathOverflow" |

> **原则**：教材归 09，其他归 18。通俗数学名著（如《什么是数学》）的**书籍本体**在 09-crosstext，但其**作者讲座/相关纪录片/书评资源**在 18-resources/博客视频。

## 3. 资源可信度分级（Tier System）

每个资源条目标注 Tier，帮助你判断投入时间：

| Tier | 含义 | 标准 | 示例 |
|------|------|------|------|
| **S** | 🏆 数学共同体公认顶级 | 机构背书 + 长期维护 + 覆盖面广 + 质量极高 | MIT OCW、MathOverflow、Annals of Math、Lean 4 |
| **A** | ⭐ 高质量推荐 | 专家推荐或社区公认 + 内容可靠 | 3Blue1Brown、Tao 博客、SageMath、AoPS |
| **B** | ✅ 可用，需甄别 | 有参考价值但有局限或需交叉验证 | 知乎数学话题、部分 YouTube 频道 |
| **C** | ⚠️ 谨慎使用 | 娱乐性强 / 广告多 / 质量不稳定 | 部分公众号、未署名笔记 |

> **使用建议**：学习核心概念优先选 Tier S/A；遇到具体问题 Tier B 也可查；Tier C 仅作灵感参考，**不做唯一来源**。

## 4. 使用建议

### 4.1 按学习阶段

| 阶段 | 最该用的资源 |
|------|-------------|
| **入门**（高中-大一） | 课程（MIT 18.01/18.06）+ 博客视频（3Blue1Brown）+ 速查 |
| **本科核心**（大二-大四） | 课程（MIT 18.100+）+ 工具（SageMath/NumPy）+ 社区（Math SE）+ 竞赛（Putnam） |
| **研究生** | 工具（Lean 4）+ 社区（MathOverflow/arXiv）+ 期刊会议 + 博客（Tao/Gowers） |
| **研究前沿** | arXiv + 期刊会议 + Lean Zulip + nLab + Polymath |

### 4.2 按需求场景

- **"概念不懂想看可视化"** → [博客视频](博客视频/)（3Blue1Brown 是首选）
- **"计算/证明需要工具辅助"** → [工具软件](工具软件/)
- **"想快速查 ∮ 或 ⊨ 怎么读"** → [速查](速查/)
- **"遇到研究级问题"** → [社区](社区/)（MathOverflow）
- **"想知道某领域最新进展"** → [期刊会议](期刊会议/) + arXiv

### 4.3 与项目其他模块联动

- [01-track/](../01-track/)：学习路径中引用本目录资源作为补充
- [04-concepts/](../04-concepts/)：概念拆解时链接到可视化视频
- [06-counterexamples/](../06-counterexamples/)：反例验证可用工具软件
- [08-projects/](../08-projects/)：是竞赛训练的实战场
- [14-frontier/](../14-frontier/)：前沿追踪依赖期刊会议和 arXiv
