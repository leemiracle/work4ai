# 数学社区地图：问对人比找对书更重要

> 数学不是孤独的学科。当你卡住时，社区是最高效的求助渠道。
> 本文按"研究级→学习级→兴趣级"分层，标注每个社区的使用方法和礼仪。

---

## 1. MathOverflow & Math StackExchange —— 🏆 Tier S

### MathOverflow（研究级）
- **定位**：研究级数学问答，面向职业数学家
- **网址**：<https://mathoverflow.net>
- **门槛**：高。问题必须有研究价值，简单题会被移走
- **怎么用**：
  - ✅ 搜索已有问题（大量顶级讨论已存在）
  - ✅ 提问前先自查 arXiv / 教材
  - ✅ 标签精准（如 `nt.number-theory`）
  - ❌ 不要问本科习题级问题（会被 close vote）
- **为什么推荐**：Terence Tao、Peter Scholze 等顶级数学家活跃于此，回答质量极高

### Mathematics Stack Exchange（学习级）
- **定位**：本科到研究生水平的数学问答
- **网址**：<https://math.stackexchange.com>
- **门槛**：中等。适合学习中遇到的问题
- **怎么用**：
  - ✅ 证明卡壳可以问思路（但别只问答案）
  - ✅ 用 LaTeX 格式写清楚（`$...$` 行内，`$$...$$` 独立行）
  - ✅ 展示你已经尝试过的步骤
  - ✅ 精确打标签（`linear-algebra` / `real-analysis` / `proof-writing`）
- **为什么推荐**：回答速度快，社区规模大，覆盖面广

> 📐 **提问黄金法则**（SE 通用）：展示你的努力 → 精确定位困惑点 → 最小化可复现案例 → 感谢回答者。

## 2. arXiv math —— 🏆 Tier S

- **网址**：<https://arxiv.org/archive/math>
- **定位**：数学论文预印本服务器，全球数学研究的"生命线"
- **怎么订阅**：
  - RSS / 邮件订阅特定分类（如 `math.NT`）
  - 每日/每周浏览 new submissions
- **主要分类含义**：

| 分类 | 全称 | 中文 |
|------|------|------|
| `math.AG` | Algebraic Geometry | 代数几何 |
| `math.AT` | Algebraic Topology | 代数拓扑 |
| `math.NT` | Number Theory | 数论 |
| `math.RT` | Representation Theory | 表示论 |
| `math.AP` | Analysis of PDEs | 偏微分方程分析 |
| `math.PR` | Probability | 概率论 |
| `math.ST` | Statistics Theory | 统计理论 |
| `math.CO` | Combinatorics | 组合数学 |
| `math.LO` | Logic | 数理逻辑 |
| `math.DG` | Differential Geometry | 微分几何 |
| `math.FA` | Functional Analysis | 泛函分析 |
| `math.OA` | Operator Algebras | 算子代数 |
| `math.CT` | Category Theory | 范畴论 |
| `math.HO` | History and Overview | 数学史与综述 |

> 💡 全分类列表见 <https://arxiv.org/category_taxonomy>
> 💡 **为什么推荐**：论文在正式发表前数月甚至数年就上 arXiv，是追踪前沿的第一渠道。

## 3. Polymath 项目 —— ⭐ Tier A

- **网址**：<https://polymathprojects.org>
- **定位**：大规模协作数学研究（Timothy Gowers 发起）
- **怎么参与**：在博客评论区讨论、贡献思路、验证证明步骤
- **著名成果**：
  - Polymath1：DHJ 定理的新证明
  - Polymath8：张益唐素数间隔结果的改进（从 7000 万改进到 246）
- **为什么推荐**：亲眼见证数学研究的"开放式厨房"

## 4. nLab —— ⭐ Tier A

- **网址**：<https://ncatlab.org>
- **定位**：范畴论、高阶范畴论、类型论、数学物理的 wiki
- **特点**：
  - 由范畴论社区（John Baez、Urs Schreiber 等）维护
  - 内容学术性强，术语密度极高
  - 是"范畴论界的维基百科"
- **为什么推荐**：学范畴论/同伦类型论时不可或缺的参考
- **⚠️ 注意**：对初学者不友好，建议先看 Bartosz Milewski 的视频入门

---

## 5. Lean Zulip —— 🏆 Tier S

- **网址**：<https://leanprover.zulipchat.com>
- **定位**：Lean 4 + Mathlib 社区的实时交流平台
- **特点**：
  - 形式化数学的核心社区
  - 有 `#new members`（新手区，提问无门槛）
  - 有 `#mathematics`（数学讨论）
  - 有 `#Is there code for X?`（查是否已有定义/定理）
- **为什么推荐**：Lean 4 是 2024-2026 形式化数学最热方向，Zulip 是该领域最活跃社区
- **关联**：[工具软件/01-数学工具全景图.md](../工具软件/01-数学工具全景图.md) §2

## 6. AoPS（Art of Problem Solving）—— 🏆 Tier S

- **网址**：<https://artofproblemsolving.com>
- **定位**：全球最大的数学竞赛社区
- **核心板块**：
  - **AoPS Forum**：按竞赛/主题分类的论坛（AMC/AIME/USAMO/IMO 级别）
  - **AoPS Wiki**：竞赛题库+解法集
  - **Alcumus**：自适应练习系统（免费）
  - **AoPS Books**：竞赛教材（如 Engel《Problem-Solving Strategies》）
- **为什么推荐**：如果你对竞赛数学有兴趣，这里是最专业的社区
- **关联**：[竞赛/01-数学竞赛体系.md](../竞赛/01-数学竞赛体系.md)、[08-projects/](../../08-projects/)

## 8. 中文数学社区

| 社区 | 定位 | 推荐度 |
|------|------|--------|
| **MathOverflow 中文镜像/讨论** | 研究级 | ✅ Tier B |

| **数学中国（mathchina）** | 学习交流 | ⚠️ Tier C |

> 💡 **知乎使用建议**：关注高质量答主（如研究级数学工作者），将话题作为"灵感来源"而非"权威来源"。

## 9. 社区参与礼仪速查

| 做 ✅ | 不做 ❌ |
|-------|---------|
| 先搜索再提问 | 不搜索就重复提问 |
| 写清楚背景和已尝试的步骤 | 只甩一句"怎么做" |
| 用 LaTeX 排版数学公式 | 用图片代替公式 |
| 感谢回答者，标记最佳答案 | 接到答案就消失 |
| 回答你力所能及的问题 | 不顾水平回答超出能力的问题 |
