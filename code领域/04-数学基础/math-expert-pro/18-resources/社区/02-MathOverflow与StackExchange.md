# MathOverflow 与 Stack Exchange 指南

> 数学社区是你最好的"免费导师"。以下怎么有效使用。

---

## 一、核心社区

| 社区 | 定位 | 水平 |
|------|------|------|
| MathOverflow | 研究级数学问答 | 研究生/教授 |
| Math StackExchange | 各水平数学问答 | 本科+ |
| Lean Zulip | Lean/mathlib 社区 | 形式化数学 |
| r/math | Reddit 数学讨论 | 通用 |
| AoPS | 竞赛数学 | 中学/大学 |

## 二、提问的艺术
1. **先搜索**——90% 的问题已有人问过
2. **给背景**——"我在学 X 时遇到 Y 问题"
3. **展示尝试**——"我试了 A 方法但卡在 B"
4. **最小可复现**——给出具体的例子

## 三、MathOverflow 高赞回答（推荐阅读）
- "什么是动机？"系列
- Terry Tao / Tim Gowers / Gil Kalai 的回答
- "直观理解"标签下的回答

## 四、Reddit/YouTube 补充
- r/math（通用讨论）
- r/learnmath（入门问题）
- Numberphile / Mathologer / 3Blue1Brown（视频）
