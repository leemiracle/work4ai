# 预印本、同行评审与发表体系

> 数学论文怎么从"想法"变成"已发表"。

---

## 一、发表流程

```
想法 → 手稿 → arXiv 预印本 → 投稿期刊 → 同行评审(1-3年) → 修改 → 发表
```

## 二、预印本服务器
- **arXiv**（[arxiv.org](https://arxiv.org)）：数学/物理/CS 最重要
- **HAL**：法国
- **BioRxiv**：生物

## 三、期刊分级（数学界）
| 级别 | 代表 | 发表难度 |
|------|------|---------|
| Tier S | Annals / Inventiones / JAMS / Acta | 极难（1-3年审） |
| Tier A | Duke / Compositio / G&T | 非常难 |
| Tier B | 各种专业期刊 | 难 |
| Tier C | 地方性/教育类 | 适中 |

## 四、同行评审的意义
- **不是保证"正确"**——而是"领域专家认为值得发表"
- 可能出错——历史上多次有错误证明通过了评审
- 形式化验证（Lean）正在成为"最终保证"

## 五、引用与影响
- MathSciNet（Mathematical Reviews）= 数学论文索引
- Zentralblatt MATH = 欧洲版索引
- Google Scholar = 通用（但质量参差）

## 六、开放获取（Open Access）
- 趋势：越来越多期刊走向开放获取
- 数学家通常把论文放在 arXiv（免费访问版本）
- arXiv > 期刊版（更及时）
