# YouTube 频道与播客推荐

> 视频和播客是培养数学直觉的最佳方式。

---

## 一、YouTube 频道（按深度排序）

### 入门级（直觉建立）
| 频道 | 内容 | 特色 |
|------|------|------|
| **3Blue1Brown** | 线代/微积分/神经网络 | 最美的数学可视化 |
| **Khan Academy** | 基础到中级 | 系统课程 |
| **Mathologer** | 有趣数学 | 深入浅出 |
| **Numberphile** | 数学科普 | 访谈式 |

### 中级（大学水平）
| 频道 | 内容 |
|------|------|
| **MIT OCW** | 完整大学课程 |
| **Trefor Bazett** | 线代/微积分 |
| **Michael Penn** | 解题/竞赛 |
| **Math The Sorcerer** | 各种数学话题 |

### 高级（研究级）
| 频道 | 内容 |
|------|------|
| **Terry Tao 博客** | 研究前沿 |
| **Gowers's Weblog** | Tim Gowers |
| **Kevin Buzzard** | Lean/形式化 |

## 二、播客
- **The Joy of Why**（Quanta Magazine）：Steven Strogatz 主持
- **My Favorite Theorem**：数学家分享最喜欢的定理
- **Mathematical Objects**：Chalk & Talk

## 三、使用建议
- 每天 10 分钟看一个视频 → 培养直觉
- 每周精读一个视频 → 做笔记
- 遇到不懂的 → 在 Math StackExchange 查/问
- 每月选一个频道系统跟 → 形成知识网络
