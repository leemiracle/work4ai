# 数学竞赛体系与策略

> 竞赛不是必须的，但训练你的"解题直觉"。

---

| IMO | 高中顶级 | 6题/2天 |

## 二、竞赛策略

### Pólya 解题四步
1. **理解问题**：已知什么？求什么？
2. **制定计划**：有没有类似问题？
3. **执行计划**：逐步检查
4. **回顾**：能否改进/推广？

### 常用技巧
- 特殊化（令 n=1,2,3 看模式）
- 一般化（抽象为更通用形式）
- 逆向思维（从目标倒推）
- 对称性利用
- 极端原理（最大/最小元素分析）
- 不变量法
- 生成函数
- 归纳法

## 四、竞赛 ≠ 数学研究
竞赛题 = 有技巧的已知方法组合。
研究 = 提出没有已知方法的新问题。
竞赛训练**技巧**，研究需要**直觉+品味**。
