## 2. 形式化证明（定理证明器 / ITP）—— 🔥 2024-2026 热点

这是数学与计算机科学交汇的最前沿。2024 年 Fields 奖得主 Peter Scholze 的液态张量实验（Liquid Tensor Experiment）就是在 Lean 中验证了他的重要定理。

| 工具 | 类型 | 用途 | 学习曲线 | 推荐度 |
|------|------|------|----------|--------|
| **Lean 4** | 依赖类型论 | 形式化数学、Mathlib 库（全球最大） | 高 | 🏆 Tier S — **2024-2026 最主流**，Mathlib 已覆盖大量本科-研究生数学 |
| **Coq** | 归纳构造演算 | 形式化数学、软件验证 | 高 | ⭐ Tier A — Four Color Theorem、Feit-Thompson 在此证明 |
| **Agda** | 依赖类型论 | 类型论研究、构造性数学 | 高 | ⭐ Tier A — 类型论学者偏爱 |
| **Isabelle/HOL** | 高阶逻辑 | 定理证明、软件验证 | 高 | ⭐ Tier A — 强自动化，Isar 语法接近数学书写 |
| **Metamath** | 替换代换 | 极简公理化验证 | 中高 | ✅ Tier B — 从零开始，极度透明 |

> 🔗 Lean 4 官网: <https://lean-lang.org>
> 🔗 Lean Zulip 社区: <https://leanprover.zulipchat.com>
> 🔗 Mathlib: <https://github.com/leanprover-community/mathlib4>
> 🔗 Coq: <https://coq.inria.fr>
> 🔗 Isabelle: <https://isabelle.in.tum.de>
> 📖 入门书：*Theorem Proving in Lean 4*（免费在线：<https://lean-lang.org/theorem_proving_in_lean4/>）
> 📖 入门书：*Mathematics in Lean*（免费在线：<https://leanprover-community.github.io/mathematics_in_lean/>）

## 7. 自动定理证明（ATP）

区别于上面的 ITP（交互式，需人引导），ATP 是自动搜索证明的工具。

| 工具 | 类型 | 用途 | 推荐度 |
|------|------|------|--------|
| **E prover** | 一阶逻辑 ATP | 自动证明一阶逻辑定理 | ⭐ Tier A — 经典 ATP |
| **Vampire** | 一阶逻辑 ATP | 自动推理竞赛冠军常客 | ⭐ Tier A — 最强一阶 ATP 之一 |
| **Z3** | SMT 求解器 | 可满足性模理论（算术/数组/量词） | 🏆 Tier S — 微软出品，应用最广 |

> 🔗 E prover: <https://eprover.org>
> 🔗 Vampire: <https://vprover.org
> 🔗 Z3: <https://github.com/Z3Prover/z3>
> 💡 ATP 常作为 Lean/Coq/Isabelle 的后端"自动辅助"（tactic 调用）。

## 8. 工具选择决策指南

| 你的需求 | 推荐工具 |
|----------|----------|
| 快速符号积分/化简 | SymPy（会 Python）或 Wolfram Alpha（在线） |
| 全面 CAS 功能 | SageMath（免费）或 Mathematica（收费） |
| 形式化证明一个定理 | **Lean 4**（首选，2024-2026 主流） |
| 高性能数值计算 | Julia 或 NumPy+SciPy |
| 统计分析/贝叶斯 | R + Stan 或 Python + PyMC |
| 教学几何演示 | GeoGebra |
| 制作数学动画 | Manim |
| 群论计算 | GAP |
| 数论计算 | PARI/GP |
| 查询特定数学对象 | LMFDB / OEIS（整数序列 <https://oeis.org>） |
