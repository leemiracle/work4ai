# 系统化课程地图：从入门到研究级的在线课程

> 教材给你深度，课程给你**节奏感和讲解**。以下是按数学分支和水平分级精选的在线课程。
> 所有课程均经过数学共同体筛选，标注 Tier 和推荐理由。

---

## 1. MIT OpenCourseWare（OCW）—— 🏆 Tier S

MIT OCW 是全球最优质的免费数学课程来源，几乎所有 18.xxx 系列课程都有完整视频/讲义/习题/答案。

| 课程号 | 课程名 | 讲师 | 难度 | 推荐理由 |
|--------|--------|------|------|----------|
| **18.01SC** | Single Variable Calculus | Gilbert Strang 等 | 入门 | 经典微积分，有习题答案，自学友好 |
| **18.02SC** | Multivariable Calculus | Denis Auroux | 入门 | 多元微积分最佳视频课之一 |
| **18.03SC** | Differential Equations | Arthur Mattuck | 本科 | ODE 圣经级课程，线性系统讲得好 |
| **18.06SC** | Linear Algebra | Gilbert Strang | 本科 | **强烈推荐**，Strang 的直觉讲解全球公认 No.1 |
| **18.065** | Matrix Methods in DA | Gilbert Strang | 本科 | 数据科学的矩阵方法，18.06 续作 |
| **18.100A/B/C/Q** | Real Analysis | 多位 | 本科 | 四个版本可选，A 最易，Q 最硬 |
| **18.1001** | Real Analysis (A) | virtual | 本科 | 实分析入门，Rudin PMA 的视频伴侣 |
| **18.102** | Intro to Functional Analysis | | 研究生 | 测度→泛函的桥梁 |
| **18.125** | Measure and Integration | | 研究生 | 测度论核心课，关联 Royden |
| **18.155** | Complex Analysis | | 研究生 | 复分析高级课程 |
| **18.901** | Topology | James Munkres | 研究生 | **强烈推荐**，Munkres 本人讲自己的教材 |
| **18.906** | Algebraic Topology | Haynes Miller | 研究生 | 代数拓扑经典，同调论+上同调 |
| **18.701** | Algebra I | | 本科高年级 | 代数，Artin 风格 |
| **18.786** | Topics in Number Theory | | 研究生 | 数论专题 |

## 2. Stanford Math & Stats —— 🏆 Tier S

Stanford 在统计、概率、优化方向全球顶尖。

| 课程 | 方向 | 讲师 | 推荐理由 |
|------|------|------|----------|
| **Stat 116/200** | 概率论 | Persi Diaconis（有时） | 概率论精品，从直觉到严格 |
| **CME 108** | 概率论 for engineers | | 工程视角的概率，应用友好 |
| **Math 61DM** | 离散数学+线代+概率 | | 本科荣誉序列，整合性强 |
| **EE364A** | Convex Optimization I | Stephen Boyd | **强烈推荐**，凸优化全球 No.1 课，Boyd 是该领域奠基人 |
| **EE364B** | Convex Optimization II | Stephen Boyd | 凸优化续作 |
| **Stats 300A** | Theory of Statistics | | 研究生统计理论 |

> 🔗 官网：<https://exploredegrees.stanford.io/schoolofengineering/departmentofmathematics/>
> 🔗 Boyd 凸优化课件：<https://web.stanford.edu/~boyd/cvxbook/>（书+课件全免费）
> 💡 Stanford 部分课在 edX 和 YouTube 有公开版。
