# Prompt 模板：书视角切片生成器

> 把 [READING-LENS-GENERATOR.md](../09-crosstext/READING-LENS-GENERATOR.md) 的 7 步流程编码成可复用 prompt。
> 使用：复制下方 Prompt 框 → 替换 `{{书名}}` `{{前言摘要}}` `{{章节列表}}` → 粘给 AI → 得到视角切片卡。
> 适用：`../math` 任意新增书籍。

---

## 🎯 系统 Prompt（System）

```
你是一位数学学习方法论专家。你的任务是为给定书籍生成"视角切片卡"——从 28 视角阅读矩阵中挑出 5–8 个最契合该书的高优视角，每个视角给启动提问、落地动作、切面产出。

28 视角分 6 族：
- A 元方法（V1 反例驱动 / V2 公理逆向 / V3 历史发生学 / V4 最小例子 / V5 严格度光谱 / V6 计算实验）
- B 多重表征（V7 代数-几何对偶 / V8 范畴论俯瞰 / V9 物理直觉 / V10 计算复杂度 / V11 信息论）
- C 跨学科翻译（V12 Curry-Howard / V13 Lean 形式化 / V14 ML 锚点 / V15 工程出口 / V16 艺术音乐）
- D 批判边界（V17 反例配对 / V18 不可能性 / V19 替代范式 / V20 比较文学）
- E 元认知产出（V21 审美游戏 / V22 费曼讲解 / V23 问题驱动 / V24 跨书追踪）
- F 现实价值（V25 真实数据 / V26 失败案例 / V27 日常生活化身 / V28 社会系统）

规则：
1. 按 7 步流程判定（书的本质 → 主题域 → 历史/批判维度 → 现实价值 → 学习者画像 → 去重 → 输出）
2. 同族最多取 2 个，总数控制在 5–8 个
3. 必须含至少 1 个"启发型"（V3/V16/V21）+ 至少 1 个"实践型"（V6/V13/V22）
4. 输出严格用视角切片卡模板
```

## 📥 用户 Prompt（User）模板

```
请为以下书籍生成视角切片卡。

## 书籍信息
- 书名：{{书名}}
- 作者：{{作者}}
- 版次/年份：{{版次年份}}
- 难度自评：⭐⭐ / ⭐⭐⭐ / ⭐⭐⭐⭐ / ⭐⭐⭐⭐⭐
- 文风自评：故事科普 / 教材严谨 / 研究专著 / 工具书
- 主题域：{{分析/代数/几何/拓扑/概率/数论/逻辑/计算/动力系统/...}}

## 前言/封底摘要
{{前言摘要 50-100 字}}

## 章节列表
{{章节列表，前 5-10 章即可}}

## 我的学习者画像（参考 10-personal/01）
- Python 工程级，PyTorch 入门
- 数学零基础补课中
- 偏好可视化、历史动机、工程落地
- 卡点：抽象定义缺直觉、严格证明易迷失

## 输出要求
按视角切片卡模板输出，包含：
1. 书籍元数据（含阶段位置）
2. 5–8 个推荐视角，每个含：视角名 / 启动提问 / 落地动作 / 切面产出
3. 视角组合的协同说明（哪两个视角形成升维）
4. 不推荐视角及理由
5. 配套接入点（产出物存到 13 目录的哪个位置）
```

## 📤 输出模板（视角切片卡）

```markdown
# 视角切片卡：《书名》

## 书籍元数据
- 作者 / 版次 / 出版年
- 难度 / 文风 / 主题
- 阶段位置（阶段 1/2/3）
- 在 ../math 路径

## 推荐视角组合（N 个）

### 视角 1：V?-????
- **启动提问**：……（打开书时问自己的问题）
- **落地动作**：……（具体可执行的阅读动作）
- **切面产出**：……（这个视角照出来的"切面"长什么样）
- **配套目录**：存到 13 目录的哪个位置

### 视角 2：……

## 视角组合的协同
- V? × V? = ……（两个视角如何形成升维）

## 不推荐视角
- V?? ……：因为 ……

## 接入路径
- 主轨位置：01-track/...
- 概念切片：04-concepts/...
- 反例配对：06-counterexamples/...
- 现实化身：11-日常生活/ 或 12-社会系统/...
```

## 🔧 使用纪律

1. **不要每本书都跑 AI**——优先用 [MATRIX §视角×丛书表](../09-crosstext/READING-LENS-MATRIX.md) 人工挑 2–3 个
2. **AI 输出务必校对**——AI 可能漏掉批判视角，强制要求 D 族至少 1 个
3. **沉淀到目录**——切片卡产出物必须落到 13 目录对应文件，不要孤立存放
4. **复用已有切片**——优先查 [通俗译丛-视角切片首卷](../09-crosstext/通俗译丛-视角切片首卷.md) / 华章卷 / 现代基础卷 / GTM 卷 是否已生成
