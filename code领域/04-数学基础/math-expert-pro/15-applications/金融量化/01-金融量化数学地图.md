## 🎯 5 个核心数学分支

### 1. 概率论 + 随机过程（⭐⭐⭐ 金融的核心语言）
**关键概念**：
- 几何布朗运动（GBM）→ 股价模型（Black-Scholes 假设）
- 马尔可夫链 → 信用评级迁移 / 制度切换
- 鞅（martingale）→ 无套利定价的数学基础
- 布朗运动 / Itô 积分 → 随机微分方程（SDE）

**核心定理**：资产定价基本定理——"无套利 ⟺ 存在等价鞅测度"

**立刻能跑**：[05-蒙特卡洛期权](../代码库/05-蒙特卡洛_期权定价.py)

### 2. 随机微积分 / Itô 演算（⭐⭐⭐）
**关键概念**：
- Itô 引理 → 随机版本的链式法则
- Black-Scholes 方程 → 期权定价 PDE
- Greeks（Delta / Gamma / Vega）→ 风险敏感度
- 测度变换（Girsanov 定理）→ 从真实测度到风险中性测度

**为什么重要**：所有衍生品定价的数学基础。Black-Scholes 公式（1973）让期权市场从手工变为电子化，1997 年诺贝尔经济学奖。

### 3. 蒙特卡洛方法（⭐⭐⭐）
**关键概念**：
- 路径模拟 → 定价路径依赖期权（亚式 / 回望 / 障碍）
- 方差缩减 → 对偶变量 / 控制变量 / 重要抽样
- 拟蒙特卡洛 → 低差异序列（Sobol / Halton）

**立刻能跑**：[05-蒙特卡洛期权](../代码库/05-蒙特卡洛_期权定价.py)

### 4. 统计 / 时间序列（⭐⭐ 量化交易）
**关键概念**：
- ARIMA / GARCH → 波动率建模
- 协整 → 配对交易（统计套利）
- 贝叶斯推断 → 参数估计 / 模型选择
- 极值理论（EVT）→ VaR / 尾部风险

### 5. 凸优化（⭐⭐ 组合管理）
**关键概念**：
- Markowitz 均值-方差 → 投资组合理论（1990 诺贝尔奖）
- 风险平价 / Black-Litterman → 实际组合管理
- 拉格朗日对偶 → 约束优化

## 📊 三个诺贝尔奖级的数学应用

| 理论 | 数学核心 | 诺贝尔奖 | 应用 |
|------|---------|---------|------|
| **Black-Scholes 期权定价** | 随机微积分 / Itô 引理 / PDE | 1997 | 衍生品市场 |
| **Markowitz 组合理论** | 凸优化 / 二次规划 | 1990 | 投资组合 |
| **Engle ARCH/GARCH** | 时间序列 / 条件异方差 | 2003 | 波动率建模 |

> 金融是"数学直接换钱"的领域——一个改进的定价模型或风控算法，可能值数亿美元。

## 🚀 给金融背景的学习建议

### 量化交易方向
1. 概率 + 统计（Ross + 时间序列）
2. 随机过程（Karatzas-Shreve 选读）
3. 机器学习（[AI-ML 指南](../AI-ML/01-AI-ML数学地图.md)）

### 衍生品定价方向
1. 随机微积分（Shreve 两卷本）
2. PDE 数值解（有限差分）
3. 蒙特卡洛（Glasserman）

### 风险管理方向
1. 概率 + 极值理论
2. 优化（Boyd 凸优化）
3. 统计建模
