## 进阶数学 → 金融

| 数学 | 金融应用 |
|------|---------|
| Itô 微积分 | Black-Scholes/Greeks |
| 偏微分方程 | 定价方程 |
| 蒙特卡洛 | 路径依赖期权 |
| 极值理论 | VaR/尾部风险 |
| 凸优化 | 投资组合 |
| 随机矩阵 | 相关矩阵过滤 |
| 压缩感知 | 因子筛选 |
