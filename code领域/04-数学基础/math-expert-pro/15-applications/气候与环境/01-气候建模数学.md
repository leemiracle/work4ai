# 气候与环境数学：从天气预报到气候变化

> 气候科学 = PDE + 数值方法 + 概率 + 数据分析 = 理解地球系统。

---

## 数学概念 → 气候应用

| 数学概念 | 气候角色 | 具体应用 |
|---------|---------|---------|
| **Navier-Stokes** | 大气/海洋流体 | 天气/洋流 |
| **热传导方程** | 能量平衡 | 温度场 |
| **辐射传输** | 太阳辐射 | 能量收支 |
| **有限元(FEM)** | 数值求解 PDE | GCM 网格 |
| **随机过程** | 混沌/不确定性 | 集合预报 |
| **数据同化** | 观测+模型 | 初始条件 |
| **时间序列** | 趋势分析 | 全球变暖 |
| **极值理论** | 极端事件 | 热浪/洪水 |

## 核心数学模型

### 1. 大气环流模型（GCM）
- 控制 PDE：Navier-Stokes + 热力学 + 辐射
- 数值方法：谱方法/有限元（球面网格）
- 网格：0.5°×0.5°，20-50 层
- 时间步：分钟级，积分到百年

### 2. 天气预报 vs 气候预测
- 天气预报：初值问题（精确初始条件）
- 气候预测：边值问题（统计平均）
- 共同数学：混沌动力系统 → [代码库 12-混沌](../代码库/12-动力系统_混沌吸引子.py)

### 3. 碳循环建模
- 碳储量 ODE：dC/dt = 排放 - 吸收
- 反馈循环：温度↑→碳释放↑→温室效应↑
- 数学：[ODE 数值解](../代码库/11-数值分析_微分方程求解.py)

### 4. 极端事件统计
- GEV 分布（广义极值）：P(X>x) ~ 1 - exp(-exp(...))
- Poisson 过程：极端事件频率 → [代码库 17-泊松](../代码库/17-随机过程_泊松与排队论.py)
