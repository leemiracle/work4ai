# 集合预报与不确定性量化

> 天气预报为什么不准？因为大气是混沌系统。

---

## 一、混沌 → 不确定性

大气满足 Navier-Stokes 方程——混沌系统（[代码库 12](../代码库/12-动力系统_混沌吸引子.py)）。
初始条件的微小差异 → 指数放大（蝴蝶效应）。

→ 单一预报必然失败 → 需要**集合预报**。

## 二、集合预报（Ensemble Forecasting）

**方法**：运行 N 个略有不同的模型实例
1. 扰动初始条件（N=20-50 个成员）
2. 积分每个成员
3. 统计输出：均值（预报）+ 标准差（不确定性）

**数学**：
- 初始扰动：奇异向量（SVD）/ breeding vector
- 集合统计：经验正交函数 EOF（= PCA [代码库 01](../代码库/01-PCA特征值_人脸压缩.py)）
- 概率预报：P(降水>10mm) = 15/50 = 30%

## 三、数据同化（Data Assimilation）

**问题**：如何把观测数据融入模型？
**方法**：卡尔曼滤波的变种
- 3D-Var / 4D-Var：变分方法
- EnKF：集合卡尔曼滤波
- 数学：min ||x-x_b||_{B⁻¹} + ||y-H(x)||_{R⁻¹}

## 四、气候 vs 天气
- 天气（<2周）：初值问题 → 混沌限制
- 气候（>月）：边值问题 → 统计平均
- 数学区别：天气=ODE初值；气候=吸引子上的概率分布
