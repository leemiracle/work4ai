# 深度学习理论：为什么深度学习有效？

> 深度学习的实践远超理论——但理论正在追上。

---

## 核心未解问题

### 1. 过参数化悖论
- 参数量 >> 数据量 → 经典泛化理论预测过拟合
- 但实际泛化良好 → 为什么？
- 关键洞察（Belkin 2019）：双下降（double descent）

### 2. 优化景观
- 非凸优化理论：SGD 为何找到好解？
- NTK（Neural Tangent Kernel）：无限宽网络的线性近似
- Lottery Ticket Hypothesis：稀疏"中奖"子网络

### 3. 表示学习几何
- 表示空间的几何结构 → [TDA](../代码库/20-TDA_拓扑数据分析.py) 可以分析
- Mechanistic Interpretability（Anthropic）：理解网络内部
