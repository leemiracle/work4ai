## 🎯 8 个核心数学分支（按对 ML 的重要性排序）

### 1. 线性代数（⭐⭐⭐ 最高优先）
**为什么核心**：ML 的几乎所有计算都是矩阵运算。神经网络的前向传播 = 矩阵乘法 + 非线性。

**关键概念**：
- 向量空间 / 线性映射 → 数据表示
- 特征值 / 特征向量 → PCA / 谱聚类
- SVD → 推荐系统 / 压缩 / 伪逆
- 正交性 / 投影 → 最小二乘 / 回归

**立刻能跑**：[01-PCA](../代码库/01-PCA特征值_人脸压缩.py) + [03-SVD推荐](../代码库/03-SVD_推荐系统.py)

**学习位置**：[01-track/stage-1](../../01-track/stage-1-本科核心/) 的 LADR（Linear Algebra Done Right）

### 2. 微积分 / 优化（⭐⭐⭐）
**为什么核心**：训练 = 沿梯度方向最小化损失。

**关键概念**：
- 导数 / 偏导数 / 梯度 → 反向传播的数学基础
- 链式法则 → 反向传播算法（backprop）
- 凸函数 / 凸优化 → 保证全局最优
- 拉格朗日对偶 → SVM 的理论基础

**立刻能跑**：[06-梯度下降](../代码库/06-梯度下降_线性回归从零实现.py)

**学习位置**：Spivak 微积分 + Boyd 凸优化

### 3. 概率论与统计（⭐⭐⭐）
**为什么核心**：ML = 用数据估计概率模型。不确定性建模的本质。

**关键概念**：
- 条件概率 / 贝叶斯定理 → 朴素贝叶斯 / 贝叶斯推断
- 大数定律 / 中心极限定理 → 蒙特卡洛 / 统计保证
- 分布（高斯/伯努利/多项）→ 生成模型 / 分类
- 极大似然估计 → 几乎所有参数学习

**学习位置**：Ross 概率论基础

### 4. 信息论（⭐⭐）
**为什么核心**：损失函数的数学根基 + 模型压缩的理论。

**关键概念**：
- 熵 H(X) → 不确定性度量
- 交叉熵 → 分类损失函数（几乎标配）
- KL 散度 → 分布距离 / VAE 的损失
- 互信息 I(X;Y) → 特征选择 / 表征学习

### 5. 随机过程（⭐⭐）
**为什么核心**：序列数据 + 采样算法。

**关键概念**：
- 马尔可夫链 → HMM / PageRank / MCMC
- 鞅（martingale）→ RL 的收敛理论
- 布朗运动 / SDE → 扩散模型（Diffusion Models）的数学基础

**立刻能跑**：[02-PageRank](../代码库/02-马尔可夫链_PageRank.py) + [05-蒙特卡洛](../代码库/05-蒙特卡洛_期权定价.py)

### 6. 泛函分析（⭐）
**为什么核心**：核方法 + 无限维优化 + 深度学习的理论分析。

**关键概念**：
- 希尔伯特空间 / RKHS → 核方法的理论家
- 算子 / 谱定理 → PCA 的无限维推广
- Banach 空间 → 优化收敛性分析

### 7. 图论（⭐）
**为什么核心**：图结构数据（社交网络 / 分子 / 知识图谱）。

**关键概念**：
- 谱图理论 → 谱聚类 / GNN 的数学基础
- 随机游走 → 图嵌入（node2vec）
- 图拉普拉斯 → 流形学习

### 8. 抽象代数 / 群论（⭐）
**为什么核心**：等变神经网络（Equivariant NN）/ 对称性约束。

**关键概念**：
- 群表示论 → 球面 CNN / 分子设计
- 对称性 → 物理启发的神经网络

## 📊 数学深度 vs ML 实用的权衡

| 数学深度 | 对 ML 的边际收益 | 建议 |
|---------|----------------|------|
| 本科线性代数 + 微积分 + 概率 | 90% 的 ML 工程够用 | **必学** |
| 凸优化 + 信息论 | 理解训练理论 | 强烈推荐 |
| 泛函分析 + 测度论 | 理解 ML 理论研究 | 选学研究方向时学 |
| 范畴论 / 代数几何 | 极少数 ML 理论前沿 | 按需 |

> 💡 **实用心法**：AI/ML 工程师不需要全学完才动手。**学完线代+微积分+概率，就能理解 80% 的 ML**。其余按需补。
