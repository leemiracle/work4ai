# 量子算法详解：Shor / Grover / VQE / HHL

> 四大量子算法的数学原理与加速。

---

## 一、Shor 算法（因式分解）

**经典**：分解 N=pq 需要 O(exp(√(log N)))
**量子**：O((log N)³) — 多项式时间！

**核心步骤**：
1. 随机选 a < N
2. 量子计算 a^x mod N 的周期 r（用量子傅里叶变换 QFT）
3. 如果 r 偶数 → gcd(a^(r/2)±1, N) 可能给出因子

**数学核心**：QFT = 量子版 FFT
$$QFT|j\rangle = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} e^{2\pi ijk/N} |k\rangle$$

## 二、Grover 算法（搜索）

**经典**：无序搜索需要 O(N)
**量子**：O(√N) — 平方根加速！

**核心**：振幅放大
1. 均匀叠加 |ψ⟩ = (1/√N)Σ|x⟩
2. Oracle 标记目标：O|x⟩ = (-1)^f(x)|x⟩
3. Grover 扩散：D = 2|ψ⟩⟨ψ| - I
4. 重复 O(√N) 次 → 测量得到目标

**应用**：数据库搜索/密码暴力破解/优化

## 三、VQE（变分量子特征值求解器）

**目标**：求分子基态能量 min⟨ψ(θ)|H|ψ(θ)⟩
**方法**：量子+经典混合
1. 量子计算机：计算 ⟨ψ(θ)|H|ψ(θ)⟩
2. 经典优化器：更新 θ → [代码库 06-梯度下降](../代码库/06-梯度下降_线性回归从零实现.py)

**应用**：量子化学/材料科学/药物发现

## 四、HHL（线性方程组求解）

**经典**：O(N³) 或 O(Ns²)（稀疏）
**量子**：O(log N · κ² · 1/ε)（条件数 κ，精度 ε）

**A x = b** → 量子版 |x⟩ = A⁻¹|b⟩

**核心**：量子相位估计（QPE）提取 A 的特征值
