## 核心概念

### 量子比特（Qubit）
|0⟩ = [1, 0]ᵀ, |1⟩ = [0, 1]ᵀ
叠加态 |ψ⟩ = α|0⟩ + β|1⟩, |α|²+|β|²=1

### 量子门
- Hadamard: H = 1/√2 [[1,1],[1,-1]]（创建叠加）
- Pauli-X: [[0,1],[1,0]]（量子 NOT）
- CNOT: 2量子比特纠缠门
- Toffoli: 3量子比特通用门

### 量子算法
| 算法 | 加速 | 数学核心 |
|------|------|---------|
| **Shor** | 因式分解 O(N³)→量子 | 量子傅里叶变换 |
| **Grover** | 搜索 O(N)→O(√N) | 振幅放大 |
| **VQE** | 量子化学 | 变分法 |
| **HHL** | 线性方程组 | 量子相位估计 |
