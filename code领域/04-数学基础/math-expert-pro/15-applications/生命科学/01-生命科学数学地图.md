## 🎯 5 个核心数学分支

### 1. 概率 / 统计（⭐⭐⭐ 生物统计根基）
**关键概念**：
- 假设检验 → 临床试验（p 值 / 置信区间）
- 生存分析 → Kaplan-Meier / Cox 回归（癌症治疗）
- 贝叶斯推断 → 医学诊断（先验→后验）
- 多重检验校正 → 基因组研究（FDR / Bonferroni）

**为什么重要**：循证医学（EBM）的数学基础。每个药物的获批都靠统计。

### 2. 微分方程（⭐⭐⭐ 动力学）
**关键概念**：
- SIR 模型 → 传染病建模（COVID-19 预测）
- Lotka-Volterra → 捕食者-猎物动力学
- Hodgkin-Huxley → 神经元电活动
- 反应-扩散方程 → 模式形成（胚胎发育 / 斑马条纹）

**应用**：疫情预测 / 生态保护 / 神经科学
**深入**：[12-社会系统视角/](../../12-社会系统视角/)（疫情系统）

### 3. 线性代数 + 高维统计（⭐⭐⭐ 基因组学）
**关键概念**：
- PCA / t-SNE / UMAP → 单细胞测序降维
- 矩阵分解 → 基因表达模式发现
- 稀疏回归 → 基因选择（LASSO）
- 高维统计 → p >> n 问题（基因数 >> 样本数）

**立刻能跑**：[01-PCA](../代码库/01-PCA特征值_人脸压缩.py)（同样的方法用在基因数据上）

### 4. 图论 / 网络科学（⭐⭐）
**关键概念**：
- 蛋白质相互作用网络 → 药物靶点发现
- 基因调控网络 → 理解细胞决策
- 神经连接体 → 大脑图谱
- 网络中心性 → 关键基因 / hub 蛋白

### 5. 拓扑数据分析 TDA（⭐ 新兴）
**关键概念**：
- 持续同调（Persistent Homology）→ 数据的"形状"
- 应用：癌症亚型发现 / 蛋白质结构 / 动脉瘤检测

**为什么前沿**：传统统计看"数值"，TDA 看"形状"——生物数据常含拓扑结构。

### AlphaFold（蛋白质折叠）

## 🚀 给生命科学背景的学习建议

### 生物信息学方向
1. 概率统计（Ross + 生物统计）
2. 线性代数 + 高维统计（LADR + PCA）
3. 算法（序列比对 / 隐马尔可夫）
4. 机器学习（[AI-ML 指南](../AI-ML/01-AI-ML数学地图.md)）

### 流行病 / 公共卫生方向
1. 微分方程（SIR 模型）
2. 概率 + 随机过程
3. 网络科学
4. 统计（生存分析 / 因果推断）

### 医学影像方向
1. 线性代数 + 优化
2. 傅里叶分析（[04-FFT](../代码库/04-傅里叶变换_音频频谱.py)）
3. 深度学习
