## 技术栈

- Python 3.8+
- 仅依赖标准数据科学栈（numpy / scipy / matplotlib / sympy / scikit-learn）
- 无框架依赖（TensorFlow / PyTorch 等均不需要）
- 所有数值计算从零实现，便于学习原理

## 学习建议

1. 先运行脚本看结果图
2. 阅读顶部 docstring 理解数学概念
3. 对照 `04-concepts/` 目录学习对应理论
4. 修改参数（如 k 值、学习率、路径数）观察变化
5. 尝试替换数据集扩展到其他应用场景
