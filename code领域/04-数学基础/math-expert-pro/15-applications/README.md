# 15-applications：可运行应用案例库

> 解决痛点：**「不知道怎么应用」**

本模块的答案：**给你看它怎么用 + 让你自己跑一遍**。

## 🎯 用法建议

### 如果你正在学某个概念（如特征值）
1. 在 [04-concepts/特征值-多表征.md](../04-concepts/特征值-多表征.md) 看 5 种刻画
2. **立刻**跑 [代码库/01-PCA特征值_人脸压缩.py](代码库/01-PCA特征值_人脸压缩.py) 看它怎么用

4. 写笔记（[NOTES_TEMPLATE.md](../NOTES_TEMPLATE.md) §8 代码验证）

### 如果你想入门一个应用领域
1. 找该领域的子目录（如 [金融量化/](金融量化/)）
2. 读该领域的"数学需求清单"（哪些数学概念是核心）
3. 对照主轨 [01-track/](../01-track/) 补欠缺的概念
4. 跑相关代码案例

### 如果你是 AI/ML 工程师
1. 重点 [代码库/06-梯度下降](代码库/06-梯度下降_线性回归从零实现.py) + [01-PCA](代码库/01-PCA特征值_人脸压缩.py) + [03-SVD推荐](代码库/03-SVD_推荐系统.py)
