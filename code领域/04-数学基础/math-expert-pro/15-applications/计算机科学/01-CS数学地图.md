## 🎯 6 个核心数学分支

### 1. 数论（⭐⭐⭐ 密码学根基）
**关键概念**：
- 素数 / 算术基本定理 → RSA 的根基
- 模运算 / 欧拉定理 → RSA 加解密
- 椭圆曲线 → 现代密码学（比特币 / TLS）
- 离散对数 → Diffie-Hellman 密钥交换

**为什么重要**：现代互联网安全的数学基础。没有数论，就没有 HTTPS、加密货币、数字签名。

**学习位置**：[01-track](../../01-track/stage-1-本科核心/) 的数论教程 + [数学天书中的证明](../../01-track/stage-1-本科核心/)

### 2. 抽象代数（⭐⭐⭐）
**关键概念**：
- 群 → 对称性 / 密码学（DES/AES 的结构）
- 环 / 域 → 有限域 GF(p) → Reed-Solomon 纠错码
- 伽罗瓦理论 → 为什么 5 次方程没有求根公式（算法理论意义）

**应用**：编码理论（你的二维码 / CD 纠错 / 卫星通信都靠它）

### 3. 图论（⭐⭐⭐）
**关键概念**：
- 最短路（Dijkstra / Bellman-Ford）→ 网络路由 / GPS 导航
- 最大流 / 最小割 → 网络流 / 图像分割
- 谱图理论 → 图聚类 / PageRank / GNN
- 图染色 → 寄存器分配 / 调度

**立刻能跑**：[02-PageRank](../代码库/02-马尔可夫链_PageRank.py)

### 4. 信息论（⭐⭐）
**关键概念**：
- 熵 → 压缩极限（Shannon 定理）
- 信道容量 → 5G / Wi-Fi 的编码理论
- 纠错码 → Reed-Solomon / LDPC / Turbo 码

**应用**：你每次扫码、每次用 4G/5G，都在用信息论

### 5. 逻辑 / 类型论（⭐⭐ 程序验证）
**关键概念**：
- 命题逻辑 / 一阶逻辑 → 程序正确性证明
- Curry-Howard 同构 → 命题=类型，证明=程序
- 依赖类型 → Lean / Coq / Agda

**应用**：形式化验证（飞机软件 / 内核验证 / 密码协议验证）
**深入**：[16-foundations/Curry-Howard/](../../16-foundations/Curry-Howard/) + [Lean 入门](../../14-frontier/AI-for-Math/02-Lean形式化数学入门.md)

### 6. 概率论（⭐⭐ 随机算法）
**关键概念**：
- 随机算法 → 快速排序随机化 / 蒙特卡洛
- 哈希 → 哈希表 / 密码学哈希 / 一致性哈希
- 概率分析 → 负载均衡 / 分布式系统

## 🚀 给 CS 背景的学习建议

### 密码学方向
1. 数论（Hardy-Wright / Ireland-Rosen）
2. 抽象代数（Dummit-Foote 的群/环/域）
3. 椭圆曲线（Silverman AEC 入门）

### 算法方向
1. 离散数学 + 组合（Concrete Mathematics）
2. 图论（Diestel / Bollobas）
3. 复杂度理论（Sipser / Arora-Barak）

### 编译器 / 形式化方向
1. 数理逻辑（Enderton）
2. 类型论（Pierce TaPL）
3. Lean 实战（[14-frontier/AI-for-Math/02-Lean入门](../../14-frontier/AI-for-Math/02-Lean形式化数学入门.md)）
4. 范畴论（Mac Lane / [16-foundations/范畴论/](../../16-foundations/范畴论/)）
