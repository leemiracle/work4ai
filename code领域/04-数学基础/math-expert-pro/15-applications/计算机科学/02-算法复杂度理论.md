# 算法复杂度理论：P vs NP 与不可解问题

> 计算复杂度 = "什么能高效计算"的数学。

---

## 复杂度类
| 类 | 定义 | 典型问题 |
|----|------|---------|
| P | 多项式时间可解 | 排序/最短路 |
| NP | 多项式时间可验证 | SAT/TSP |
| NP-C | NP中最难 | 3-SAT/最大团 |
| PSPACE | 多项式空间 | 博弈策略 |
| EXPTIME | 指数时间 | 某些博弈 |

## 三重障碍（P≠NP 为什么难证明）
1. 相对化（Baker-Gill-Solovay 1975）：oracle 使 P=NP 和 P≠NP 都可能
2. 自然证明（Razborov-Rudich 1994）：现有电路下界技术不够
3. 代数化（Aaronson-Wigderson 2008）：代数化方法也有障碍

## 前沿方向
- Geometric Complexity Theory（Mulmuley）：用代数几何攻 P vs NP
- Unique Games Conjecture（Khot）：如果为真 → 大量硬度结果
- Fine-grained complexity：SETH → SETH 蕴含很多下界
