# 音乐与数学：和声、节奏与结构的数学

> 毕达哥拉斯以来最古老的数学交叉——音乐。

---

## 数学 → 音乐

| 数学概念 | 音乐含义 |
|---------|---------|
| 傅里叶分析 | 音色 = 谐波组成 |
| 群论 Z₁₂ | 十二平均律 = 等分八度 |
| 黄金比例 | 乐句结构 |
| 分形 | 节奏模式自相似 |
| 信息论 | 音乐熵/可预测性 |
| 拓扑 | 和声空间 |

## 关键事实
- 八度 = 频率比 2:1
- 纯五度 = 3:2
- 十二平均律 = 2^(k/12)（对数等分）
- 和谐 = 简单整数比（毕达哥拉斯）
