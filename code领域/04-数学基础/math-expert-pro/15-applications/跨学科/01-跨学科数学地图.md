## 🎵 1. 数学 + 音乐（最古老的交叉）

### 核心数学
- **傅里叶分析** → 音色 = 频谱组成（钢琴 vs 小提琴 = 谐波不同）
- **群论** → 音阶的对称性（十二平均律 = ℤ₁₂ 的对称）
- **调和分析** → 和声学（协和/不协和 = 频率比的简单/复杂）
- **素数** → 节奏模式（复合节拍 / 多律制）

### 关键事实
- **毕达哥拉斯发现**：弦长比 2:1 = 八度，3:2 = 纯五度——**数学和音乐的最早连接**（公元前 6 世纪）
- **十二平均律**：将八度对数等分 12 份，2^(1/12) 为半音——中国明代朱载堉（1584）首次精确计算
- **傅里叶**：任何周期声音 = 正弦波叠加（你听到的每个音色都是傅里叶级数）

**立刻能跑**：[04-FFT](../代码库/04-傅里叶变换_音频频谱.py)——看音乐怎么变成频谱

### 进阶
- SET 理论（Allen Forte）：用 ℤ₁₂ 群分析现代音乐
- David Lewin 的变换理论：用群论分析音乐结构

## 🎨 2. 数学 + 艺术 / 设计

### 核心数学
- **几何 / 射影几何** → 透视（文艺复兴的核心发明）
- **分形几何** → 自然形态（海岸线 / 山脉 / 树木）
- **黄金比例 φ = (1+√5)/2** → 帕台农神庙 / 蒙娜丽莎（争议但流行）
- **对称群** → 装饰图案（伊斯兰几何 / Escher 版画）
- **拓扑** → 现代建筑（扎哈·哈迪德的连续曲面）

### 关键人物
- **M.C. Escher**：用对称群 / 双曲几何创作视错觉版画
- **Jackson Pollock**：滴画被证明具有分形维度
- **Da Vinci**：《维特鲁威人》= 人体比例的数学研究

## 🏛️ 3. 数学 + 社会科学

### 博弈论（⭐⭐⭐）
- 纳什均衡 → 经济学 / 国际关系 / 生物学
- 机制设计 → 拍卖 / 选举 / 市场设计
- 阿罗不可能定理 → **没有完美的投票制度**（社会学的基础限制）

- 社交网络分析 → 信息传播 / 影响力 / 回音壁
- 六度分隔 → 小世界网络
- 网络效应 → 平台经济

### 概率与决策
- 贝叶斯决策 → 理性选择
- 期望效用 → 风险决策（保险 / 投资）
- 行为经济学 → 数学描述非理性行为

## 🤔 4. 数学 + 哲学

### 逻辑与真理
- **哥德尔不完备定理** → 任何足够强的形式系统都有不可判定的命题——**数学本身的局限性**
- **图灵停机问题** → 不可计算性
- **塔斯基不可定义定理** → 真理不可在系统内定义

### 基础论战
- 集合论 vs 类型论 vs 范畴论 → 数学建立在什么之上？
- 直觉主义 vs 经典逻辑 → 排中律是否成立？
- 形式主义 vs 柏拉图主义 → 数学是发明还是发现？

**深入**：[16-foundations/基础争议/](../../16-foundations/基础争议/) + [07-critique/](../../07-critique/)

### 范畴论作为"数学的数学"
- 函子 / 自然变换 → 不同数学分支的统一语言
- 哲学家开始用范畴论讨论本体论 / 认识论

**深入**：[16-foundations/范畴论/](../../16-foundations/范畴论/)
