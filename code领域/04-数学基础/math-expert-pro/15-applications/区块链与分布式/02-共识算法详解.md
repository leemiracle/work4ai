# 共识算法详解：PBFT / Paxos / Raft / Tendermint

> 分布式共识 = 不信任节点间达成一致的数学。

---

## 一、问题定义

n 个节点，f 个可能拜占庭（任意行为），需要就某个值达成一致。

**可用性**：n ≥ 3f+1（BFT）/ n ≥ 2f+1（崩溃容错）

## 二、FLP 不可能定理

**Fischer-Lynch-Paterson (1985)**：在异步网络中，如果有一个节点可能崩溃，则不存在确定性共识算法同时保证安全+活性。

→ 解法：加入随机性/超时/部分同步假设

## 三、核心算法

### Paxos (Lamport 1989)
- 角色：Proposer / Acceptor / Learner
- 两阶段：Prepare → Accept
- 数学：多数派（quorum）交集保证一致性

### Raft (2014)
- Paxos 的简化版（更容易理解）
- 领导者选举 + 日志复制

### PBFT (Castro-Liskov 1999)
- 三阶段：Pre-prepare → Prepare → Commit
- 实用拜占庭容错（n≥3f+1）
- 应用：Hyperledger Fabric

### Tendermint
- PBFT + PoS 混合
- 即时最终性（无分叉）
