# SLAM 与状态估计：机器人定位的数学

> SLAM（同时定位与建图）= 概率 + 优化 + 图论。

---

## 一、SLAM 问题

给定：传感器数据（激光/相机/IMU），控制输入
求：机器人轨迹 + 环境地图

**数学本质**：P(thazit, map | observations, controls)
= 贝叶斯滤波在超高维空间

## 二、核心算法

### 1. 卡尔曼滤波（KF）
- 线性高斯最优估计
- 数学：x̂ = x̂⁻ + K(y - Hx̂⁻)
- K = P⁻Hᵀ(HP⁻Hᵀ+R)⁻¹（卡尔曼增益）

### 2. 扩展卡尔曼（EKF）
- 非线性：线性化（雅可比）
- 应用：大多数实时 SLAM 系统

### 3. 粒子滤波（PF）
- 非高斯/多模态
- 应用：FastSLAM

### 4. 图优化 SLAM（现代方法）
- 建图 = 构建因子图
- 数学：min Σ||rᵢ(x)||²_{Σᵢ}（最小二乘）
- 工具：g2o/GTSAM/Ceres
