# 机器人数学地图：从运动学到自主导航

> 机器人 = 微分几何 + 控制论 + 优化 + 概率 → 自主行动的数学。

---

## 数学概念 → 机器人应用

| 数学概念 | 机器人角色 | 应用 |
|---------|-----------|------|
| **齐次变换矩阵** | 正运动学 | 关节角→末端位置 |
| **雅可比矩阵** | 逆运动学/速度控制 | 速度/力控制 |
| **李群 SE(3)** | 位姿表示 | 6DOF 定位 |
| **Lyapunov 稳定性** | 控制系统设计 | 平衡/跟踪 |
| **卡尔曼滤波** | 状态估计 | SLAM/GPS |
| **图搜索(A\*/RRT)** | 路径规划 | 导航 |
| **贝叶斯滤波** | 感知/定位 | 粒子滤波 |
| **凸优化** | 轨迹优化 | 最优运动 |

## 核心子系统

### 1. 运动学（在哪里？）
- 正运动学：T = ∏T_i(θ_i)（DH 参数法）
- 逆运动学：已知目标位置求关节角（可能有多解/无解）
- 数学：齐次变换矩阵 / 旋量理论

### 2. 动力学（怎么动？）
- 拉格朗日方程：L = T - V → 运动方程
- 牛顿-欧拉：递归力/力矩计算
- 数学：[变分法](../代码库/23-变分法_最优控制.py)

### 3. 感知与定位（我在哪？）
- 卡尔曼滤波：线性高斯最优估计
- 扩展卡尔曼（EKF）：非线性推广
- 粒子滤波：非高斯/多模态
- SLAM：同时定位与建图
- 数学：[贝叶斯推断](../代码库/10-概率_贝叶斯推断.py)

### 4. 路径规划（怎么去？）
- A*：图搜索最优路径 → [代码库 08-图论](../代码库/08-图论_最短路算法.py)
- RRT/RRT*：随机采样规划
- 轨迹优化：min ∫(成本)dt s.t. 动力学约束
- 数学：[控制论](../代码库/35-控制论.py) + [变分法](../代码库/23-变分法_最优控制.py)
