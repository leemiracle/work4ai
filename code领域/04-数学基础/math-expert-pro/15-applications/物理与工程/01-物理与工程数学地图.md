## 🎯 6 个核心数学分支

### 1. 微分方程（⭐⭐⭐ 物理的语言）
**关键概念**：
- 常微分方程（ODE）→ 牛顿第二定律 F=ma
- 偏微分方程（PDE）→ 波动方程 / 扩散方程 / 麦克斯韦
- 边值问题 → 量子力学定态
- 稳定性分析 → 控制论（Lyapunov）

**应用**：从天体轨道到电路到结构力学，微分方程是物理的"母语"

### 2. 傅里叶分析（⭐⭐⭐）
**关键概念**：
- 傅里叶级数 / 变换 → 频域分析
- 量子力学中的动量-位置对偶（Fourier 对）
- 衍射 / 光学 / 信号处理

**立刻能跑**：[04-FFT](../代码库/04-傅里叶变换_音频频谱.py)

### 3. 线性代数 + 泛函分析（⭐⭐⭐ 量子力学根基）
**关键概念**：
- 希尔伯特空间 → 量子态空间
- 厄米算子 / 谱定理 → 可观测量
- 张量积 → 复合系统 / 量子纠缠
- 幺正变换 → 量子门 / 时间演化

**应用**：量子计算 / 量子信息 / 量子化学

### 4. 微分几何（⭐⭐ 相对论）
**关键概念**：
- 流形 / 切空间 → 时空几何
- 度量张量 → 引力 = 时空弯曲
- 联络 / 曲率 → 广义相对论的核心
- 纤维丛 → 规范场论（Yang-Mills）

**经典书**：Arnold《经典力学的数学方法》(GTM60)

### 5. 群论 / 李论（⭐⭐ 对称性）
**关键概念**：
- Noether 定理 → 对称性 = 守恒律（时间平移→能量守恒）
- 李群 / 李代数 → 角动量 / 规范对称性
- 表示论 → 粒子分类（标准模型）

**应用**：粒子物理 / 量子化学（分子对称性）/ 晶体学

### 6. 变分法（⭐⭐ 力学与控制）
**关键概念**：
- 欧拉-拉格朗日方程 → 最小作用量原理
- 哈密顿原理 → 分析力学
- 最优控制（Pontryagin 极大值原理）→ 航天 / 机器人

## 🚀 给物理/工程背景的学习建议

### 经典物理方向
1. 微积分 + ODE/PDE（Spivak + Arnold）
2. 线性代数 + 傅里叶（LADR + Stein-Shakarchi）
3. 分析力学（Arnold GTM60 / Goldstein）

### 量子方向
1. 线性代数 + 泛函分析（LADR → Royden）
2. 群论（Weyl / Sternberg）
3. 量子力学（Sakurai / Griffiths）

### 控制 / 信号方向
1. ODE + 拉普拉斯变换
2. 概率 + 随机过程（Ross）
3. 凸优化（Boyd）+ 控制论
