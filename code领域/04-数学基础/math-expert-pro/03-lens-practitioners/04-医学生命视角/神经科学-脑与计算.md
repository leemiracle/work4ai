# 计算神经科学家（把数学当"脑功能的语言"看）

> 从 Hodgkin-Huxley 膜电位 ODE 到贝叶斯推断，数学是微观（离子通道）与宏观（认知）之间的桥梁。

计算神经科学横跨非线性动力学、信号处理、概率推断和信息论——大脑在每个尺度都在"做数学"。

## 核心数学工具箱
🟢【事实】
- **Hodgkin-Huxley 方程**（非线性 ODE 组）：$C_m dV/dt=-\bar{g}_K n^4(V-V_K)-\bar{g}_{Na}m^3 h(V-V_{Na})-\bar{g}_l(V-V_l)+I$（HH 1952, *J. Physiol.* 117(4):500-544，1963 诺奖）。四元 ODE，非线性 ODE + 分岔经典。
- **神经网络**：McCulloch-Pitts → MLP → 深度学习；反向传播 = **链式法则**（多元微积分的自动微分）。脉冲神经网络（SNN）用积分-发放模型 $\tau\,dV/dt=-V+RI$。
- **脑电 EEG——傅立叶**：频段 δ/θ/α/β/γ = 傅立叶频谱；ERP = 叠加平均；源定位 = 逆问题。
- **贝叶斯脑假说**：先验 + 似然 → 后验；预测编码；**卡尔曼滤波**（线性高斯状态估计）。
- **神经编码**：Gabor 滤波器（V1）、泊松过程脉冲、互信息 $I(X;Y)$。

## 详写：Hodgkin-Huxley 方程——非线性 ODE 的分岔
🟢【事实】（Hodgkin-Huxley 1952, *J. Physiol.* 117(4):500-544；Dayan-Abbott 2001；交叉验证）

HH 方程描述枪乌贼巨轴突的膜电位动力学，是计算神经科学的奠基石：

$$C_m\frac{dV}{dt}=-\bar{g}_K n^4(V-V_K)-\bar{g}_{Na}m^3 h(V-V_{Na})-\bar{g}_l(V-V_l)+I$$

其中 $m, n, h$ 是门控变量（取值 [0,1]），各自满足一阶 ODE $\dot{x}=\alpha_x(V)(1-x)-\beta_x(V)x$。

**动力学结构**：四元非线性 ODE 系统。当输入电流 $I$ 增大越过阈值时，系统经历 **Hopf 分岔**——不动点失稳，涌现极限环 = 周期性动作电位发放（"激发"）。恢复阶段（$h$ 门关闭钠通道）使系统回到静息。

**为什么重要**：HH 证明了"兴奋性"可以完全用非线性 ODE 描述——不需要"生命力"或神秘物质。此后所有神经元模型（FitzHugh-Nagumo、积分-发放）都是 HH 的简化。

## 独特视角：把数学当"脑功能的语言"看
- 🟢 Hodgkin-Huxley = 非线性 ODE + 分岔：门控变量的非线性耦合产生动作电位"全或无"，Hopf 分岔涌现极限环放电
- 🟢 贝叶斯脑 = 卡尔曼滤波：大脑用先验 + 感官证据做最优估计（线性高斯状态估计）
- 🟢 反向传播 = 链式法则：学习 = 多元微积分的自动微分
- 🟢 EEG 频段 = 傅立叶频谱：不同频段对应不同脑状态（δ=深睡，γ=专注）
- 🟢 神经编码 = 信息论：脉冲发放用泊松过程，编码效率用互信息 $I(X;Y)$ 度量
- 🟡 大脑 ≈ "在做积分和贝叶斯推断"——从离子通道 ODE 到感知决策，数学是功能描述语言
- 🟡 动作电位 ≈ "非线性 ODE 的极限环"——与电路振荡（RLC）、化学反应（BZ）同构
