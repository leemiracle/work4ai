# 药代动力学家（把数学当"身体的管道与阀门"看）

> 给身体画管道图——房室 = 器官，速率常数 = 阀门。双指数曲线告诉你药效维持几小时。

每个药物标签背后都是 ODE + 统计。药代动力学（PK）是线性 ODE 特征值 / 指数衰减最直接的医学应用。

## 核心数学工具箱
🟢【事实】
- **房室模型（一阶 ODE 组）**：一房室 $dC/dt=-k_e C$（指数消除）；二房室 = 中央 + 外周耦合线性 ODE → 双指数 $C(t)=Ae^{-\alpha t}+Be^{-\beta t}$。线性 ODE 特征值 = 消除速率常数的直接体现。
- **半衰期** $t_{1/2}=\ln 2/k_e$；**清除率** $CL=\text{剂量}/\text{AUC}$（AUC = 定积分）；**表观分布容积** $V_d=\text{剂量}/C_0$。
- **剂量-响应——Hill 方程**：$E=E_{max}D^n/(EC_{50}^n+D^n)$。S 形，Logistic 函数族。
- **生物等效性（统计）**：$C_{max}$/AUC 比值的 90% CI ∈ [0.80, 1.25]，对数正态假设检验。
- **群体 PK（非线性混合效应模型）**：NONMEM，$\theta_i=\theta_{pop}\cdot e^{\eta_i}+\varepsilon$；EM 算法（FOCE）、贝叶斯分层模型。

## 详写：房室模型 = 线性 ODE 的特征值分解
🟢【事实】（Rowland-Tozer *Clinical Pharmacokinetics*；交叉验证）

**一房室模型**：

$$\frac{dC}{dt}=-k_e C \quad\Rightarrow\quad C(t)=C_0\,e^{-k_e t}$$

半衰期 $t_{1/2}=\ln 2/k_e$——所有指数衰减过程的通用语言。

**二房室模型**：中央室（血液/快分布器官）+ 外周室（慢分布组织），耦合线性 ODE：

$$\frac{d}{dt}\begin{pmatrix}C_1\\C_2\end{pmatrix}=\begin{pmatrix}-(k_{10}+k_{12}) & k_{21}\\ k_{12} & -k_{21}\end{pmatrix}\begin{pmatrix}C_1\\C_2\end{pmatrix}$$

系统矩阵的两个**特征值** $-\alpha, -\beta$（$\alpha > \beta > 0$）给出双指数解：

$$C(t)=Ae^{-\alpha t}+Be^{-\beta t}$$

- $\alpha$ 相（快）：分布到外周室
- $\beta$ 相（慢）：代谢消除

**读法**：多房室 PK 模型就是线性 ODE 系统的特征值分解。特征值 = 消除速率常数，特征向量 = 各房室的浓度分布模式。$CL=\text{剂量}/\text{AUC}$ 中，$\text{AUC}=\int_0^\infty C(t)\,dt$ 是定积分。

## 独特视角：把数学当"身体的管道与阀门"看
- 🟢 多房室 = 线性 ODE 系统：特征值 = 消除速率常数，双指数衰减直接对应两个特征值
- 🟢 AUC（药时曲线下面积）= 定积分：$\text{AUC}=\int_0^\infty C(t)\,dt$，生物利用度的定义量
- 🟢 Hill 方程 = Logistic 函数族：药物剂量-效应的 S 形曲线，$n$（Hill 系数）控制陡度
- 🟢 群体 PK = 分层贝叶斯 / 非线性混合效应模型：个体参数 = 群体参数 + 随机效应
- 🟡 房室模型 ≈ "把身体简化成几个连通水箱"——真实器官是分布参数系统，房室是集总参数近似
- 🟡 半衰期 ≈ "一阶 ODE 的时间常数"——$t_{1/2}=\ln 2/k$ 是所有指数衰减过程的通用语言
