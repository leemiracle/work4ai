# 基因组学家 / 生物信息学家（把数学当"拿计算机找进化的侦探工具"看）

> DP 找同源，HMM 找基因，最大似然重建生命树——生物信息学的数学武器库最像计算机科学。

生物信息学把动态规划、隐马尔可夫模型、极值理论和组合优化全部用于"读懂 DNA 序列"。

## 核心数学工具箱
🟢【事实】
- **序列比对——动态规划**：Needleman-Wunsch 1970（*JMB* 48:443-453）全局比对，Smith-Waterman 1981 局部比对。BLAST = 启发式加速。
- **HMM——基因预测**：状态链（外显子/内含子），Viterbi（最大后验路径）、前向-后向算法；Profile HMM 刻画蛋白质家族。
- **系统发育**：距离矩阵法（UPGMA/NJ）、最大似然（Felsenstein，GTR 替换模型）、Bootstrap。组合优化 + 概率。
- **BLAST 统计**：Karlin-Altschul 极值理论，$E\text{-value}=Kmn\,e^{-\lambda S}$（Gumbel 分布）。
- **编码论**：遗传密码（64→20）冗余 ≈ 纠错码（Hamming 距离）。

## 详写：Needleman-Wunsch = 动态规划在字符串上的经典
🟢【事实】（Needleman-Wunsch 1970, *JMB* 48(3):443-453；Durbin et al. 1998；交叉验证）

**问题**：给定两条 DNA/蛋白质序列 $x=x_1\cdots x_m$ 和 $y=y_1\cdots y_n$，找最优全局比对（最大化匹配得分 - 空位罚分）。

**递推**（NW 1970）：

$$F(i,j)=\max\begin{cases}F(i-1,j-1)+s(x_i,y_j)\\ F(i-1,j)-d\\ F(i,j-1)-d\end{cases}$$

- $s(x_i,y_j)$：替换得分（如匹配 +1，错配 -1）
- $d$：空位罚分
- 初始：$F(0,j)=-jd$, $F(i,0)=-id$
- 回溯：从 $F(m,n)$ 回溯到 $F(0,0)$，得到最优比对

**读法**：最优比对 = 得分矩阵 $F$ 上的最高分路径。这是 DP 的教科书级应用——最优子结构（$F(i,j)$ 只依赖左、上、左上三个邻居）+ 重叠子问题（同一子比对被反复使用）。

**Smith-Waterman 1981**：局部比对变体，递推多一个"重新开始"选项 $\max(0, \ldots)$，找序列中最相似的片段（不是全长比对）。BLAST 是其启发式加速——牺牲精确性换取 $10^3$ 倍速度。

## 独特视角：把数学当"拿计算机找进化的侦探工具"看
- 🟢 Needleman-Wunsch = 动态规划：递推 + 回溯找最优比对，DP 的教科书级应用
- 🟢 Viterbi = HMM 上的最大后验路径：从观测序列（DNA）推断隐藏状态（基因结构）
- 🟢 BLAST E-value = 极值理论：随机序列匹配分数服从 Gumbel 分布
- 🟢 系统发育 = 组合优化 + 概率：树空间是 NP 难的，最大似然在树空间搜索最优拓扑
- 🟡 遗传密码 ≈ 纠错码：64 个密码子编码 20 种氨基酸，冗余提供了错误容忍（Hamming 距离）
- 🟡 HMM 基因预测 ≈ "语音识别搬到 DNA 上"——Viterbi 在两个领域做同一件事
