# 医学影像专家（把数学当"从投影反演真相"看）

> CT 把投影还原切片，MRI 把 k 空间填回图像——核心信念：采样够多角度，傅立叶给你真相。

医学影像是逆问题的集中地：从有限的测量数据重建完整图像，数学工具是积分变换和正则化。

## 核心数学工具箱
🟢【事实】
- **CT 重建——Radon 变换 / 反投影**：$Rf(\theta,s)=\int f$ 沿 θ 方向射线的线积分（Radon 1917）。滤波反投影 FBP，**傅立叶切片定理**。Hounsfield-Cormack 工程化（1979 诺奖）。
- **MRI——k 空间 / 傅立叶 / 拉莫尔进动**：$\omega_0=\gamma B_0$ 进动；梯度场编码空间 → 原始数据 = 图像的 2D 傅立叶变换（k 空间）；重建 = 逆 2D FFT。傅立叶最纯医学应用。
- **PET**：湮灭光子对符合探测 → 放射性分布重建，Radon 类反演。
- **图像分割**：水平集（PDE 曲线演化）、图割（最小割 = 最大流）、区域生长。
- **深度学习诊断**：U-Net、GAN——卷积 + 梯度下降 + 反向传播。
- **逆问题正则化**：Tikhonov、全变差 TV。

## 详写：Radon 变换与傅立叶切片定理（CT 的数学基石）
🟢【事实】（Radon 1917；Kak-Slaney *Principles of Computerized Tomographic Imaging*；交叉验证）

**Radon 变换**：对二维函数 $f(x,y)$（人体截面密度），沿角度 $\theta$ 方向、距原点 $s$ 的射线上积分：

$$Rf(\theta,s)=\int_{-\infty}^{\infty} f(s\cos\theta - t\sin\theta,\; s\sin\theta + t\cos\theta)\,dt$$

CT 每条 X 射线测量的就是沿路径的衰减积分 = Radon 变换的一个样本。

**傅立叶切片定理**（核心）：$f$ 在角度 $\theta$ 的一维投影的傅立叶变换 = $f$ 的二维傅立叶变换 $\hat{f}$ 沿同一角度过原点的径向切片。

**含义**：旋转投影覆盖 360°，等价于在频域中逐条线填满 $\hat{f}$ 的完整二维数据。然后逆 2D 傅立叶即可重建 $f$。滤波反投影（FBP）是这一原理的高效数值实现。

**MRI 的 k 空间**：MRI 直接在频域（k 空间）采集数据——梯度磁场编码空间位置，原始信号 = 图像的 2D 傅立叶变换。重建 = 逆 2D FFT。这是傅立叶对偶性最直接的工程实现。

## 独特视角：把数学当"从投影反演真相"看
- 🟢 Radon 变换 = 沿射线积分：CT 每条 X 射线测量的是沿路径的衰减积分，FBP 把这些积分反演回截面
- 🟢 傅立叶切片定理：一个角度的投影 = 频域中过原点的一条线——旋转覆盖 360° 即填满 2D 频域
- 🟢 MRI k 空间 = 2D 傅立叶：原始数据是图像的傅立叶变换，重建 = 逆 FFT——傅立叶最纯的医学应用
- 🟢 逆问题病态性：少量投影 → 无穷多解 → 需正则化（Tikhonov / TV）选择"最合理"的解
- 🟡 CT ≈ "从影子猜物体形状"——多角度投影 + 傅立叶切片定理 = 数学保证的可重建性
- 🟡 k 空间 ≈ "图像的频率配方表"——中心 = 低频（轮廓），边缘 = 高频（细节）
