## 详写：Curry-Howard 同构（本视角的数学锚点）
🟢【事实】（Wadler 2014 综述 "Propositions as Types"，CACM 2015；交叉验证）

三条核心对应：
1. **命题即类型**（Propositions as Types）
2. **证明即程序**（Proofs as Programs）
3. **证明检查即类型检查**（Proof Checking as Type Checking）

逻辑连接词与类型的精确对应表：

| 逻辑命题 | 类型 |
|---------|------|
| 合取 $A \wedge B$ | 积类型 $\tau \times \sigma$（pair） |
| 蕴含 $A \supset B$ | 函数类型 $\tau \to \sigma$ |
| 析取 $A \vee B$ | 和类型（tagged union） |
| 假 $\bot$ | 空类型 |
| 真 $\top$ | 单位类型 |
| 否定 $\neg A$ | $A \to \bot$（函数到空类型） |

进一步扩展为 **Curry-Howard-Lambek** 三元同构：直觉主义逻辑 $\cong$ 类型化 λ-演算 $\cong$ 笛卡尔闭范畴（CCC）。

含义：学构造性逻辑、学 λ-演算、学 CCC，是同一件事的三个面孔。一个在 logic 里证完了，等于在 type theory 里写完了程序，等于在 category 里构造完了态射。

## 独特视角：把数学当"可执行的符号变换"看
- 🟢 **IR + 等价变换**：编译器优化（常量折叠、死代码消除、循环不变量外提）本质是"保持语义的代数化简"
- 🟢 **依赖类型 + 形式化证明**：在 Coq / Lean 4 / Agda 里写程序 = 构造证明，定理是一等公民类型
- 🟢 学命题逻辑连接词时强制做映射：$\wedge$ 是"积"（pair），$\vee$ 是"和"（tagged union），$\supset$ 是"函数"

## 作为学习透镜怎么用
- 学**逻辑证明**时：证明就是"类型为该命题"的程序。写证明 = 写代码，检查证明 = 编译期类型检查。
- 学**自然演绎 / 构造性证明**时：每条引入规则对应一种类型的构造子，每条消去规则对应一种模式匹配。
- 学**归纳法**时：它就是结构递归——对数据构造子的递归 = 对自然数的归纳。
- 学**停机问题 / 不可判定性**时：它是类型系统能力的边界（即便依赖类型也证不完所有真命题）。

## 适合照哪些数学概念
（来自 14×12 矩阵第 4 列）
- **证明**：证明 = 程序（Curry-Howard），本视角的核心锚点
- **抽象**：类型 = 命题抽象，类型系统是对命题的分层
- **线性**：线性类型 = 资源单用（线性逻辑的工程化身）
- **极限**：程序求值的不动点语义（递归 = 最小不动点）
- **导数**：自动微分 = 一种编译变换
- **特征值**：特征文法【类】（解析文法的"特征"）
