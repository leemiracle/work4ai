## 独特视角：把数学当"对海量数据的代数操作"看
- 🟢 **关系代数**（Codd 1970）：选择 σ、投影 π、连接 ⋈、并 / 差是关系上的代数运算，SQL 是其语法糖。关系代数与关系演算"关系完备"等价（Codd 1972）
- 🟢 **查询优化 = 代数等价变换 + 代价搜索**（Chaudhuri 1998）：$\text{Join}(A, \text{Join}(B,C)) = \text{Join}(\text{Join}(B,C), A)$ 等代数等价生成候选计划，动态规划找最优——"代数化简"工业界最大规模应用
- 🟢 **可串行化理论**：并发事务正确性 = "存在等价串行顺序"，冲突图（有向图）无环性判定
- 🟡 函数依赖 $X \to Y$ ≈ 逻辑蕴含；范式化 ≈ "消除冗余的代数分解"

## 作为学习透镜怎么用
- 学**代数结构**时：关系代数是具体的代数系统，σ/π/⋈ 是运算，满足等式定律——"代数"不是抽象玩具，是 SQL 优化器每天跑万亿次的东西。
- 学**图论（环 / 拓扑序）**时：事务可串行性靠冲突图无环判定，死锁检测也靠图里找环。
- 学**动态规划**时：查询优化器用 DP 在所有 join 顺序里搜最低代价计划。
