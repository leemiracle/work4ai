## 详写：CAP 定理证明（不可能性证明的经典样本）
🟢【事实】（Gilbert-Lynch 2002 形式化证明；交叉验证，与 Gödel、停机问题同类）

**陈述**：异步网络中，不可能同时满足原子一致（Consistency）+ 可用（Availability）+ 分区容忍（Partition tolerance）三者。

**证明骨架（反证法）**：
1. 假设存在算法同时满足三者。
2. 网络分区：把节点分成 G1、G2 两组，两组之间消息全部丢失。
3. 在 G1 写入初值 $v_1$；随后在 G2 读取。
4. 由"可用性"，G2 必须返回；由"分区"，G2 收不到 G1 的写；由"原子一致"，G2 必须返回 $v_1$。
5. 矛盾。故假设不成立。

这类证明的价值：**"证明 X 做不到"和"证明 X 能做到"一样有力量**——它划清了系统能力的边界，让工程师不再徒劳追求不可能的三全。

补充：🟢 拜占庭容错——$f$ 个拜占庭（任意作恶）节点需要 $3f+1$ 个节点达成共识（Lamport-Shostak-Pease 1982）。

## 独特视角：把数学当"在不可靠中构造可靠"看
- 🟢 Lamport happens-before：偏序定义分布式事件的因果，时钟同步 = 把偏序嵌入全序
- 🟡 最终一致性 ≈ 数学分析"收敛但不逐点成立"
- 🟡 quorum（多数派交集）≈ 鸽穴原理：两个多数派必有交集节点

## 作为学习透镜怎么用
- 学**反证法 / 不可能性证明**时：CAP 是最工程化的样本——"证明 X 做不到"和"证明 X 能做到"一样有力量。Gödel、停机问题、CAP 都是这类。
- 学**鸽穴原理**时：quorum 一致性是其工程化身——两个多数派必相交。
- 学**偏序 / 全序**时：Lamport happens-before 把"因果"形式化成偏序，时钟同步 = 偏序扩张成全序。

## 适合照哪些数学概念
（来自 14×12 矩阵第 6 列）
- **不变量**：归纳证共识（Paxos/Raft 正确性的根基）
- **证明**：Paxos / Raft 正确性 = 形式化证明
- **概率**：故障 / 拜占庭占比（系统可靠性建模）
- **极限**：最终一致性 = 异步收敛【类】
- **对称**：节点对称 = 一致易达【类】
- **信息**：复制 = 信息冗余（用冗余换可靠）
