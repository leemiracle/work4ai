# 数据科学家（把数学当"从相关到因果的阶梯"看）

> 相关 ≠ 因果——Pearl do-演算把"如果干预 X，Y 会怎样"变成了可从观测分布计算的数学问题。

数据科学站在统计学、计算机科学和领域知识的交叉点，而它的核心张力始终是：从数据看到的关联，有多少能回答"做了某事会怎样"的因果问题。

🟢【事实】
- **因果推断（核心）**：Pearl do-演算（3 规则）、潜在结果框架（Neyman-Rubin）、反事实

- **特征工程**：对数变换处理重尾、one-hot / 目标编码

## 详写：Pearl do-演算（从观测到干预的数学桥梁）
🟢【事实】（Pearl *Causality* 2000 Cambridge, 2nd 2009；Hernán-Robins *Causal Inference: What If*；交叉验证）

**核心区分——观测 vs 干预**：
- 条件概率 $P(Y \mid X=x)$：观察到 $X=x$ 时 $Y$ 的分布（被动看数据）
- 干预概率 $P(Y \mid do(X=x))$：强制设定 $X=x$ 后 $Y$ 的分布（主动改变世界）

两者的差距正是"混杂偏倚"的根源。do-演算就是一套规则，告诉你什么时候能从观测分布 $P$ 算出干预分布 $P(Y \mid do(X=x))$。

**三条规则**（Pearl 1995 提出，完备性由 Shpitser-Pearl 2006 证明）：
1. **插入/删除观测**：在因果图中，若观测变量与结果被"门"隔开，可删可加
2. **行动/观测交换**：在某些条件下，$do(\cdot)$ 可替换为条件概率
3. **插入/删除行动**：若无因果路径指向该行动变量，该 $do$ 可删除

**后门准则（最实用的特例）**：若存在变量集 $Z$ 满足——(1) $Z$ 阻断所有从 $X$ 到 $Y$ 的后门路径，(2) $Z$ 不是 $X$ 的后代——则：

$$P(Y \mid do(X=x)) = \sum_z P(Y \mid X=x, Z=z)\,P(Z=z)$$

**读法**：只要找到合适的"后门调整集" $Z$，就能用纯观测数据回答干预问题。这就是为什么 A/B 测试（随机化 = 切断所有后门路径）是因果推断的金标准——随机化让 $do$ 等价于条件。

当后门变量不可观测时，do-演算告诉你需要**工具变量**，或者该问题从根本上不可识别。

## 独特视角：把数学当"从相关到因果的阶梯"看
- 🟢 相关是 $P(Y \mid X)$，因果是 $P(Y \mid do(X))$——两者数学上不同，混淆它们是数据科学最大的陷阱
- 🟢 随机化实验 = 切断后门路径的物理操作，使 $do$ 等价于条件概率
- 🟢 贝叶斯框架：先验 + 似然 → 后验，不确定性显式建模，适合小样本因果推断
- 🟡 Count-Min Sketch ≈ "用哈希换内存"：放弃精确计数换取近似但有保证的估计
- 🟡 A/B 测试 ≈ "用随机化换因果"：放弃观察性数据的便利换取可信的因果结论

## 作为学习透镜怎么用

| 学什么数学 | 用数据科学家照一遍 |
|---|---|
| **条件概率** | $P(Y\mid X)$ 是"看到"，$P(Y\mid do(X))$ 是"做了"——区分两者是因果推断全部出发点 |
| **贝叶斯** | 先验 + 似然 → 后验，小样本下因果效应估计的利器 |
| **图论** | 因果图（DAG）= 混杂路径的可视化工具，后门准则靠图上判断 |
| **假设检验** | A/B 测试的 p 值有商业后果——错误结论 = 真金白银损失 |
| **哈希/随机化** | HyperLogLog / Count-Min Sketch = 用数学换内存的工程艺术 |
