# 从业者透镜（维度 3b）：把数学放到 43 个真实职业眼里看

> 这是三维多视角矩阵的**维度 3b**。
> 维度 3a（数学家方法论透镜）给数学的**内在动机**——为什么这么定义、美的追求；
> 维度 3b（从业者透镜）给数学的**外在压力**——为什么需要这个、化学/医生/经济学家/音乐家把它逼成什么样。
> **同一个数学概念，放到不同从业者眼里，每个视角照出不同切面。**

## 🌐 核心命题：数学是基础学科

> 数学不是一门孤立的"基础课"，而是**渗透到几乎所有学科和职业的通用语言**。
> 学数学 = 获得一把能打开 43 扇职业大门的万能钥匙。

例如"特征值"：化学家看是分子轨道能级，流行病学家看是 R₀（决定封城），机械工程师看是固有频率，ML 工程师看是 PCA，量子计算看是可观察量——**一个抽象，13+ 种化身**。

👉 **先读 [全景图-数学如何渗透各学科.md](全景图-数学如何渗透各学科.md)**：55 角色 × 13 核心数学概念的密度热力，以及"特征值/傅立叶/不可能性定理"等概念的多职业化身。

## 🧭 如何使用本目录

### 学一个数学概念时
1. 看 [全景图](全景图-数学如何渗透各学科.md) 找这个概念的"多职业化身"
2. 挑 2-3 个最相关的角色文件深读（如学"特征值"→控制 + ML + 化学）
3. 同一抽象获得 3 个具象锚点

### 找 AI/工程锚点时
学某数学时问"它在哪个真实职业落地？"→ 跳对应角色文件 → 拿到工程化应用。这是 [10-personal/AI锚点法](../10-personal/) 的扩展弹药库。

### 与维度 3a 配合
学概念建议同时跑：**数学家透镜（内在美）+ 1-2 个从业者透镜（外在用）**。两者互补。
