# 电气工程师（把数学当"活在频域"看）⭐

> 电气工程师活在"频域"——不问信号长什么样，问含哪些频率。傅立叶是眼镜，复平面是地图。

从傅立叶变换到奈奎斯特判据，电气工程拥有最成熟的"时域 ↔ 频域"双语体系。

## 核心数学工具箱
🟢【事实】
- **信号处理—傅立叶/拉普拉斯/Z 变换**：$X(f)=\int x(t)e^{-j2\pi ft}\,\mathrm{d}t$。Nyquist 采样 $f_s>2f_{\max}$。正交函数分解。
- **电路—复阻抗（复分析）**：$Z_C=1/(j\omega C)$，$Z_L=j\omega L$。$j=\sqrt{-1}$ 是 90° 相位差算子。戴维南定理 = 线性叠加。
- **麦克斯韦方程（向量微积分）**：四个方程（散度+旋度），散度定理 / Stokes。导出电磁波方程。
- **控制理论**：根轨迹（特征方程根轨迹）、Bode 图（频率响应）、奈奎斯特判据（复分析辐角原理）。
- **信息论**：Shannon $C=B\cdot\log_2(1+\mathrm{SNR})$。

## 详写：傅立叶 + 复分析——频域双子星（本视角的数学锚点）
🟢【事实】（Oppenheim & Willsky *Signals and Systems*；Hayt *Engineering Circuit Analysis*；交叉验证）

**傅立叶变换**把时域信号分解为频率成分：

$$X(f)=\int_{-\infty}^{\infty}x(t)e^{-j2\pi ft}\,\mathrm{d}t$$

| 数学概念 | 电气含义 |
|---------|---------|
| 傅立叶变换 | 信号 → 频谱（滤波、压缩、调制的基础） |
| 复阻抗 $j\omega L$ | 电感/电容的频率响应（$j$ = 90° 相位） |
| 极点位置 | 系统稳定性（左半平面 = 稳定） |
| 奈奎斯特判据 | 复平面辐角原理判稳定性 |

🟢 配对锚点—奈奎斯特判据：用复分析**辐角原理**（环绕原点的圈数 = 极点-零点数差）判断闭环稳定性——纯复分析直接工程化。复阻抗里 $j=\sqrt{-1}$ 不是抽象，而是"相位超前 90°"的算子。

## 独特视角：把数学当"活在频域"看
- 🟢 不看信号波形，看频谱成分（傅立叶是"眼镜"）
- 🟢 复平面是地图：极点在左半平面 = 稳定
- 🟡 "时域 ↔ 频域" ≈ 同一信号两种语言的双语翻译
- 🟡 麦克斯韦方程 ≈ "四个向量微积分等式概括全部电磁现象"
