# 化学工程师（把数学当"放大的尺子"看）

> 化工工程师是"放大"的数学家——烧杯反应变万吨反应釜，尺度分析告诉什么不变什么翻倍。无量纲数是放大实验的尺子。

从反应器 ODE 到传热传质 PDE，化工的核心是"用无量纲数把实验室结果放大到工业规模"。

## 核心数学工具箱
🟢【事实】
- **反应器物料衡算（ODE）**：CSTR $\mathrm{d}C/\mathrm{d}t=(F/V)(C_{\text{in}}-C)-r(C)$，PFR $\mathrm{d}C/\mathrm{d}V=r(C)/F$。Arrhenius 非线性。
- **传热传质（PDE/边界层）**：扩散 $\partial C/\partial t=D\nabla^2 C$，对流扩散，传热 $\partial T/\partial t=\alpha\nabla^2 T$。有限差分/体积。
- **尺度分析 / Buckingham π**：$n$ 变量 − $k$ 量纲 → $n-k$ 无量纲群。$Nu=f(Re,Pr)$。
- **化工流程优化**：多反应器序列（LP/NLP）、换热网络（夹点分析 = LP）、精馏最小能耗。
- **相平衡**：拉乌尔定律、吉布斯相律 $F=C-P+2$、闪蒸 = 非线性方程组。

## 详写：尺度分析与无量纲数（本视角的数学锚点）
🟢【事实】（Bird, Stewart & Lightfoot *Transport Phenomena*（BSL）；Felder, Rousseau & Bullard *Elementary Principles*；Buckingham；交叉验证）

**Buckingham π 定理**：$n$ 个有量纲变量、$k$ 个基本量纲 → $n-k$ 个独立无量纲群。

| 无量纲数 | 含义 |
|---------|------|
| Reynolds $Re=\rho vL/\mu$ | 惯性/黏性（层流 vs 湍流） |
| Nusselt $Nu=hL/k$ | 对流/导热 |
| Prandtl $Pr=\nu/\alpha$ | 动量/热量扩散 |

**含义**：🟢 无量纲数是"放大实验的尺子"——只要 $Re$ 相同，模型与原型行为相似。这是化工从烧杯放大到万吨反应釜的数学根基。

🟢 配对锚点—反应器多稳态：CSTR 的 Arrhenius 非线性 + 移热曲线可产生**多个平衡点**（多稳态/点火-熄火），是 ODE 分岔在化工的直接体现。

## 独特视角：把数学当"放大的尺子"看
- 🟢 无量纲数让小实验预测大装置（$Re$ 相同即相似）
- 🟢 反应器 ODE 可有多稳态（点火/熄火分岔）
- 🟡 "放大" ≈ 保持无量纲数不变，几何/速率可成倍缩放
- 🟡 夹点分析 ≈ "用线性规划找最省能量的换热网络"
