# 横切轴 B：范畴组合性轴（Compositionality）

> 每学"结构 / 运算"，问：**它可组合吗？组合定律是什么？它是不是某个范畴 / 代数结构？**

## 定位
"能不能把小东西拼成大东西、且大东西的行为由小东西决定"——这是数学和工程共有的核心审美。范畴论给所有"可组合结构"统一语言。

## 来源
🟢【事实】
- 范畴论：functor、natural transformation、monad（严格定义）、Kleisli 范畴
- Haskell 类型类（`Functor` / `Monad` / `Monoid`）
- SICP（抽象与组合的工程训练）
- Milewski "Monads Categorically"；Gonzalez "The category design pattern"

## 适用主题
函数与复合、monoid / 半群 / 群、同态、functor / monad、抽象代数、拓扑、抽象本身。

## 落地（具体怎么做）
- 学群 / 代数结构时做三连问：(1) 它满足哪些定律？(2) 这组定律能否当"接口"用？(3) 哪些类型是它的实例？
- 学一个运算时：问"它可结合吗？有单位元吗？"——结合律 = 可任意分组（可并行），单位元 = 空操作默认值。
- 学 functor 时：问"为什么 `map` 在 list / Maybe / Future 上同名同义？"
