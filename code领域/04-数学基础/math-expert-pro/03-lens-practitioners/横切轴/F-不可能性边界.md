# 横切轴 F：不可能性边界轴 ⭐（共用元轴）

> 每学"能力 / 定理"，问：**它的边界在哪？有没有不可能性定理证明它做不到？**

## 定位
这是跨多角色的**共用元轴**，专治"以为万能"的认知偏差。学会"证明 X 做不到"和"证明 X 能做到"同样重要——它划清能力边界，让人不再徒劳追求不可能。

## 来源（一组平行的不可能性结果）
🟢【事实】
- **CAP 定理**（Gilbert-Lynch 2002）：异步网络中原子一致 + 可用 + 分区容忍不可兼得（反证法：G1/G2 分区，先写后读矛盾）
- **Gödel 不完备定理**：足够强的相容形式系统必含不可判定的真命题
- **停机问题**（Turing 1936）：不存在判定任意程序是否停机的通用算法（对角线论证）
- **Landauer 能耗下界**：擦除 1 bit 最少耗 $E \geq k_B T \ln 2$
- **$P \neq NP$ 假设**：密码学、计算复杂度的根基（未证但广泛相信）
- **No-Free-Lunch 定理**（Wolpert）：没有任何学习算法在所有问题上都最优

## 共同的证明武器
🟢 反证法、对角线论证（Cantor / Turing / Gödel 共用）、复杂度归约。

## 适用主题
反证法、对角线论证、计算复杂度（P / NP / NP-hard）、可计算性（停机）、信息论极限（Shannon）、测度论（不可测集 / 选择公理）、优化（凸 vs 非凸）。

## 落地（具体怎么做）
- 学一个"能做到"的定理时，立刻问："它的反面做不到吗？有没有不可能性定理？"
- 学反证法 / 对角线法时，把 CAP、停机、Gödel 当三个平行样本对照读。
- 学"P vs NP"时绑定："公钥密码、优化、AI 的难度根源全在这里"。
