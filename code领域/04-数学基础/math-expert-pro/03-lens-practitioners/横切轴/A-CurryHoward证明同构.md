# 横切轴 A：Curry-Howard 证明同构轴

> 每学"证明 / 逻辑 / 类型"概念，问：**它对应的程序 / 类型长什么样？**

## 定位
把数理逻辑、类型论、编程语言三者打通的一条共用轴。一旦建立这套对应，学逻辑连接词、学证明构造、学类型系统就不再是三件孤立的事，而是同一张图的三种读法。

## 来源
🟢【事实】
- Curry-Howard 同构（Wadler 2014 综述 "Propositions as Types"，CACM 2015）
- 扩展：Curry-Howard-Lambek 三元同构（直觉主义逻辑 ≅ 类型化 λ-演算 ≅ 笛卡尔闭范畴 CCC）
- 工具载体：Lean 4 / Coq / Agda（依赖类型定理证明器）
- 教材：Pierce *TAPL*、*Software Foundations*

## 核心对应表
🟢
- 命题 $A \wedge B$ ↔ 积类型 $\tau \times \sigma$
- 命题 $A \supset B$ ↔ 函数类型 $\tau \to \sigma$
- 命题 $A \vee B$ ↔ 和类型（tagged union）
- 假 $\bot$ ↔ 空类型
- 否定 $\neg A$ ↔ $A \to \bot$

三条口号：**命题即类型、证明即程序、证明检查即类型检查**。

## 适用主题
命题逻辑、谓词逻辑、自然演绎、构造性证明、类型论、简单类型 λ-演算、归纳法（= 程序递归）、停机问题 / 不可判定性。

## 落地（具体怎么做）
- 学命题逻辑连接词时，强制做映射表：$\wedge \to$ pair，$\vee \to$ sum，$\supset \to$ function，$\neg \to$ function-to-empty。
- 学自然演绎时：引入规则 = 类型的构造子，消去规则 = 模式匹配。
- 学归纳法时：把它读成"对数据结构的递归"。
- 学一个定理时：问"它的证明作为程序，输入输出类型是什么？"
