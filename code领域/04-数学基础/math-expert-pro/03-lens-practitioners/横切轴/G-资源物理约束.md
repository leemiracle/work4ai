# 横切轴 G：资源物理约束轴

> 每学"算法 / 信息 / 抽象"，问：**它在资源（时间 / 空间 / 能量 / 信息）上的代价与下界是多少？**

## 定位
任何计算都不是免费的：跑算法要时间、存数据要空间、擦信息要能量、传输要带宽。这条轴把"数学结构"和"物理代价"绑死，防止把抽象当成无成本的符号游戏。

## 来源
🟢【事实】
- Landauer 原理（信息 ↔ 能量）：擦除 1 bit $\geq k_B T \ln 2$ 焦耳
- Shannon 极限：信道容量 $C = B \log_2(1 + S/N)$，不可超越
- 计算复杂度（时间 / 空间）
- Amdahl 定律：并行加速受串行部分限制
- 排队论：延迟下界

## 适用主题
算法复杂度、信息论（熵 = 代价）、数值分析（误差 / 精度）、优化（收敛速率）、Landauer（物理下界）、压缩极限。

## 落地（具体怎么做）
- 学熵时绑定："擦除 1 bit 最低耗 $k_B T \ln 2$"——熵有物理代价。
- 学复杂度时绑定："大 O 是工程可行性红线"——$O(2^n)$ 在 $n=100$ 就跑不动。
- 学算法时：问"它的时间 / 空间下界是什么？有没有更优的可能？"（决策树模型下界、排序的 $\Omega(n \log n)$）
- 学数值方法时：绑定"误差 / 精度"——浮点数不是实数，每步运算都有代价。
