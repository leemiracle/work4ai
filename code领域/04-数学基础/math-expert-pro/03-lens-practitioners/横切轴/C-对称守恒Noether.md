# 横切轴 C：对称守恒 Noether 轴

> 每学"对称 / 不变量"，问：**它对应的守恒律或不变量是什么？能否用变分原理推导？**

## 定位
物理学的"王道"思维：对称性是第一性的，守恒律是对称性的推论。这条轴把群论、变分法、微分方程、守恒律串成一根线。

## 来源
🟢【事实】
- Noether 定理（1915）：每个连续对称性对应一个守恒律
  - 时间平移对称 → 能量守恒
  - 空间平移对称 → 动量守恒
  - 旋转对称 → 角动量守恒
  - 形式化：若 $L$ 在单参数变换族下不变，则 $C = \dfrac{\partial L}{\partial \dot{q}} \cdot \dfrac{\partial q}{\partial s}$ 守恒
- 最小作用量原理 → Euler-Lagrange 方程：$\dfrac{d}{dt}\dfrac{\partial L}{\partial \dot{q}} - \dfrac{\partial L}{\partial q} = 0$
- 量纲分析：Buckingham π 定理

## 适用主题
对称与群论、守恒律、变分法、微分方程、量纲分析、拉格朗日 / 哈密顿力学、摄动理论。

## 落地（具体怎么做）
- 学群论 / 对称时强制问："这个对称性守恒了什么？"（Noether 透镜）
- 学微积分 / 变分时：最速降线、最小作用量都是"求泛函极值"。
- 学量纲分析时：用"尺度对称性"直接推关键无量纲关系（Buckingham π）。
