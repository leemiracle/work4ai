# 横切轴 E：不确定性与决策轴

> 每学"概率 / 随机 / 风险"概念，问：**它如何支撑不确定性下的最优决策？**

## 定位
概率论不只是"算频率"，它的终极目的是"在不确定下做最好的决策"。这条轴把概率、贝叶斯、期望、测度、信息熵全部对齐到"决策"这个靶心。

## 来源
🟢【事实】
- 贝叶斯决策（先验 + 似然 → 后验，选期望损失最小行动）
- PAC-Bayes 泛化界：$R_{out}(Q) \leq R_{in}(Q) + \sqrt{\dfrac{KL(Q\ |P) + \ln(2\sqrt{m}/\delta)}{2m}}$
- Itô 微积分（Itô 引理：$df = \left(\partial_t f + \tfrac{1}{2}\partial_W^2 f\right)dt + \partial_W f\,dW$）
- Jaynes *Probability Theory: The Logic of Science*（概率即逻辑的延伸）
- 极值理论（VaR / CVaR）

## 适用主题
概率公理、条件概率 / 贝叶斯、期望 / 方差、大数定律 / 中心极限定理、随机过程、测度论、信息熵 / KL、统计检验。

## 落地（具体怎么做）
- 学期望时绑定："它是定价 / 决策的基础"——期权价格 = 期望折现，最优决策 = 期望损失最小。
- 学测度时绑定："概率 = 测度为 1 的空间"（Kolmogorov 公理）。
- 学贝叶斯时绑定："先验 + 数据 → 后验 → 决策"，这是一套完整的决策回路。
