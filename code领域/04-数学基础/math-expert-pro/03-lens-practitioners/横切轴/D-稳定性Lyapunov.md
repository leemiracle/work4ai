# 横切轴 D：稳定性 Lyapunov 轴

> 每学"收敛 / 迭代 / 动态系统"，问：**它的 Lyapunov 函数（递减不变量）是什么？它稳定吗？**

## 定位
"找一个一直减的量来证明收敛"——这个思维在数学里无处不在：动力系统稳定性、数值迭代法收敛、优化算法收敛、马氏链平稳分布。Lyapunov 给了它统一的名字。

## 来源
🟢【事实】
- Lyapunov 稳定性：正定 $V(x)$，沿轨迹 $\dot{V} \leq 0$ ⇒ 稳定；$\dot{V} < 0$ ⇒ 渐近稳定；$\dot{V} \leq -\alpha V$ ⇒ 指数稳定。注意是**充分条件**。
- 线性系统特征值判稳：$\dot{x} = Ax$ 渐近稳定 $\iff \text{Re}(\lambda_i) < 0\;\forall i$
- 动态规划 / Bellman 最优性原理
- 卡尔曼滤波（高斯贝叶斯滤波解析解）

## 适用主题
收敛性、迭代法（梯度下降 / 牛顿法）、动力系统、ODE 稳定性、特征值、马氏链平稳分布、强化学习。

## 落地（具体怎么做）
- 学梯度下降、牛顿法、数值迭代法时：用 Lyapunov 函数思维证 / 理解收敛——把"误差"或"到最优点的距离"当 $V$。
- 学特征值时：稳定性 = 特征值实部全负，特征值是"系统会不会爆炸"的判据。
- 学马氏链时：平稳分布 = 长期不变量，收敛到它是另一种"稳定"。
