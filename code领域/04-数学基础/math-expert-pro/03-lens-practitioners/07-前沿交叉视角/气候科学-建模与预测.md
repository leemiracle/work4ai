# 气候科学家（把数学当"行星级 PDE"看）

> 地球是一个旋转球面上的流体——气候科学面对人类最大的 PDE 问题，而混沌不是障碍，是集合预报量化不确定性的理由。

气候建模把 Navier-Stokes、热力学、辐射传输和相变耦合在球面网格上数值求解，关系数十亿人命运。

## 核心数学工具箱
🟢【事实】
- **全球气候模型 GCM**：球面 PDE、谱方法（球谐函数展开）；大气海洋 = 旋转球面 Navier-Stokes + 热力学
- **混沌与集合预报**：Lorenz 1963 蝴蝶效应（正李雅普诺夫指数）；集合预报 = 多初值蒙特卡洛
- **检测归因**：最优指纹法 = 回归 / 信噪比检验，区分自然变率与人为信号
- **碳循环**：ODE 耦合箱式模型
- **海平面**：时间序列（趋势 + 周期 + 噪声）
- **不确定性量化**：IPCC AR6 概率语言（"很可能 66-100%"等校准）

## 详写：GCM 与谱方法（球面上的傅立叶）
🟢【事实】（McGuffie-Henderson-Sellers *Climate Modelling Primer*；IPCC AR6 WG1 方法附录；交叉验证）

**GCM = 什么方程？**：大气和海洋的动力学核心是旋转球面上的 Navier-Stokes（含科里奥利力）+ 热力学能量方程 + 辐射传输 + 水汽相变。这是一个巨大的耦合 PDE 组。

**谱方法**：全球变量在球面上展开为球谐函数 $Y_l^m(\theta,\phi)$ 的级数。球谐函数是球面上的正交基（正如正弦/余弦是直线/圆上的），微分运算在谱空间变为代数运算，精度高于有限差分。

**与混沌的关系**：Lorenz 1963 证明即使三 ODE 的简化大气模型也有正李雅普诺夫指数——初始误差指数增长。这不是模型的缺陷，而是流体动力学的本质。集合预报（多初值蒙特卡洛）正是把"不可精确预测"变成"可量化不确定性"。

**检测归因**：从混沌的自然变率（噪声）中提取人为气候变化信号，本质是信噪比检验——最优指纹法把它形式化为回归问题。

## 独特视角：把数学当"行星级 PDE"看
- 🟢 GCM = Navier-Stokes + 热力学 + 辐射 + 相变在球面网格上数值离散化——人类最大规模的 PDE 求解
- 🟢 谱方法 = 球谐函数展开：全球变量在球面上展开为球谐函数 $Y_l^m(\theta,\phi)$ 的级数
- 🟢 混沌 = 正李雅普诺夫指数：初始误差指数增长 → 长期预报本质不可能（Lorenz）→ 集合预报量化不确定性
- 🟢 检测归因 = 信噪比检验：从混沌的自然变率（噪声）中提取人为气候变化信号
- 🟡 气候 ≈ "不可做实验的混沌系统"——不能重跑地球，只能用模型 + 集合做数值实验
- 🟡 谱方法 ≈ "在球面上做傅立叶分析"——球谐是球面上的正交基，正如正弦/余弦是直线上的

## 作为学习透镜怎么用

| 学什么数学 | 用气候科学家照一遍 |
|---|---|
| **PDE / 数值方法** | 球谐展开 = 全球网格上求流体方程——谱方法在球面上的应用 |
| **ODE / 混沌** | Lorenz 三 ODE 产生混沌——蝴蝶效应 = 正李雅普诺夫指数 |
| **傅立叶（球谐）** | 球谐函数 = 球面上的傅立叶基——全球场展开的正交系 |
| **统计 / 检测归因** | 从噪声提取信号——回归 + 信噪比检验服务气候政策 |
| **时间序列** | 趋势 + 周期 + 噪声分解——海平面、温度记录的标准模型 |
| **蒙特卡洛** | 集合预报 = 多初值蒙特卡洛——量化混沌系统的不确定性 |
