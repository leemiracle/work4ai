# 首席科学家 / 研究科学家（把数学当"研究手艺"看）

> 不是"用某种数学"，而是用数学的**态度**做研究：形式化、定理-证明、构造反例、追问假设能否放宽。

这个视角特殊——它不绑定某块数学知识，而是提供一套**跨概念通用的研究姿态**。任何定理都能用它照一遍。

## 核心数学工具箱
🟢【事实】不是"用某种数学"，而是用数学的态度做研究：
- 形式化定义（把模糊直觉变成精确陈述）
- 定理-证明范式
- 构造反例（找定理的边界）
- 收敛性 / 复杂度分析

## 独特视角：把数学当"研究手艺"看
- 🟢 Tao 研究哲学："先找到正确的模糊直觉 → 再逐步形式化 → 最后追求简洁"
- 🟢 方法论四件套：假设-实验-结论、文献综述、可复现性、同行评审
- 🟡 数学证明 ≈ 可复现实验：证明是"任何人按步骤重跑都得同样结论"的实验报告
- 🟡 "taste（品味）" ≈ 工程的"架构嗅觉"

## 作为学习透镜怎么用
学任何定理时，问四个研究式问题：
1. 🟢 它回答什么"实验问题"？（把它当对一个现象的解释）
2. 🟢 它的"对照组 / 反例"长什么样？（构造让结论失效的情形，理解假设为何必要）
3. 🟢 假设能否放宽？（这就是做研究本身——弱化条件、推广结论）
4. 🟢 我能独立重证吗？（合上书重走一遍证明链，卡住的地方就是真理解缺口）

## 适合照哪些数学概念
（来自 14×12 矩阵第 2 列）
- **证明**：研究核心产出——证明是终极交付物
- **抽象**：概念抽象 = 研究产物（定义一个好概念本身就是贡献）
- **极限**：严格化直觉工具——把"越来越接近"变成 ε-δ
- **不变量**：定理 = 永恒不变量（一旦证明，永远成立）
- **优化**：估计 / 拟合 = 优化（统计研究的引擎）
- **信息**：知识度量（信息论把"知道多少"量化）
- **对称**：简化解题钥匙（对称性是研究中最强大的工具之一）
