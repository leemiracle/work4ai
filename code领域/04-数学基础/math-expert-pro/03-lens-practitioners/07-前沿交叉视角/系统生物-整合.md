# 系统生物学家（把数学当"生命的优化理论"看）

> 进化是最优化器，网络是解。FBA 用线性规划预测细菌最优代谢，基因调控网络的反复出现的模体 = 自然选择优化出的计算模块。

系统生物学整合组学数据、网络分析和动力学建模，用数学回答"生命为什么这样设计"。

## 核心数学工具箱
🟢【事实】
- **生物网络**：图论（基因调控、蛋白互作），度分布、模体 motif
- **鲁棒性/脆弱性**：bow-tie 结构（多输入 → 少核心 → 多输出）
- **代谢流平衡分析 FBA**：线性规划 $\max v_{biomass}$ s.t. $S\cdot v=0$, $v_{min}\leq v\leq v_{max}$
- **组学整合**：矩阵分解（NMF / ICA）、张量
- **生物随机性**：Gillespie 算法（化学主方程）
- **动力学**：ODE 系统、Michaelis-Menten 酶动力学

## 详写：FBA = 线性规划预测细菌代谢
🟢【事实】（Palsson *Systems Biology*；Edwards-Palsson 2000 *PNAS* 97:5528-5533；交叉验证）

**问题**：给定细菌的完整代谢网络（化学反应列表 + 化学计量矩阵 $S$），预测它在新环境中怎么分配代谢流以最大化生长？

**FBA（Flux Balance Analysis）模型**：

$$\max_{\mathbf{v}}\; v_{biomass} \quad \text{s.t.}\quad S\cdot\mathbf{v}=0,\quad v_{min,i}\leq v_i\leq v_{max,i}$$

- $S$：$m\times n$ 化学计量矩阵（$m$ 代谢物 × $n$ 反应），每列是一个反应的化学计量
- $\mathbf{v}$：代谢流向量（每个反应的速率）
- $S\cdot\mathbf{v}=0$：稳态假设——代谢物既不积累也不耗尽
- $v_{biomass}$：生物量反应（消耗前体分子合成新细胞）

**读法**：这是一个标准线性规划。约束 $S\mathbf{v}=0$ 定义可行流锥，目标函数 = 在锥上最大化生物量。进化被建模为"在化学约束下最大化生长"——LP 的解 = 细菌的最优代谢策略。

**网络模体**（Alon）：基因调控网络中反复出现的小图模式（前馈环、自调控）= 自然选择优化出的功能模块，像电路中的逻辑门。

## 独特视角：把数学当"生命的优化理论"看
- 🟢 FBA = 线性规划：代谢网络用化学计量矩阵 $S$ 约束稳态流 $Sv=0$，目标函数 = 最大化生物量——LP 预测细菌最优代谢策略
- 🟢 网络模体 = 自然选择的计算模块：Alon 发现基因调控网络中反复出现的小图模式（前馈环、自调控）= 优化的功能单元
- 🟢 bow-tie 结构 = 鲁棒性设计：大量输入汇聚到少量核心节点再发散——对扰动鲁棒但对核心攻击脆弱
- 🟢 Gillespie 算法 = 精确随机模拟：化学主方程的精确采样，处理分子数少时的随机涨落
- 🟡 进化 ≈ 最优化器：自然选择 = 梯度上升（Fisher 基本定理），网络结构 = 最优解的化石记录
- 🟡 FBA ≈ "细菌在做线性规划"——进化让代谢流分配最优，数学模型发现了这一点
