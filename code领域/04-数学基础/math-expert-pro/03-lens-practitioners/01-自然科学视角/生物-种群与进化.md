# 理论 / 数量生物学家（把数学当"生命的方程"看）

> 理论生物学家相信生命可方程化——一个 Lotka-Volterra 周期就是草原上狼和兔的命运。生物数学常是随机（遗传漂变）+ 博弈（频率依赖）的结合。

从种群振荡到进化博弈，数学让生物学从描述走向预测。

## 核心数学工具箱
🟢【事实】
- **种群动力学—Lotka-Volterra（ODE 组）**：$\dot{x}=\alpha x-\beta xy$，$\dot{y}=\delta xy-\gamma y$。解为闭合轨道（种群周期振荡），Hopf 分岔的经典实例。（Lotka 1925 / Volterra 1926）
- **费希尔自然选择基本定理**：$\dot{\overline{m}}=V_A(m)$（适应度变化率 = 加性遗传方差）。"自然选择 = 梯度上升"。
- **进化博弈论—ESS（Maynard Smith）**：策略 $p$ 是进化稳定策略 ⟺ 对任意 $q\ne p$：$E(p,p)>E(q,p)$，或 $E(p,p)=E(q,p)$ 且 $E(p,q)>E(q,q)$。支付矩阵。
- **遗传学概率**：Hardy-Weinberg 平衡 $p^2+2pq+q^2=1$，孟德尔 $\chi^2$ 检验。
- **分子进化**：Jukes-Cantor（碱基替换马氏链）、Kimura 两参数模型。

## 详写：Lotka-Volterra 与 ESS（本视角的数学锚点）
🟢【事实】（May *Stability and Complexity in Model Ecosystems*；Nowak *Evolutionary Dynamics*；交叉验证）

**Lotka-Volterra 捕食模型**：

$$\dot{x}=\alpha x-\beta xy,\quad \dot{y}=\delta xy-\gamma y$$

| 现象 | 数学含义 |
|------|---------|
| 闭合轨道 | 猎物-捕食者周期振荡（非线性相图） |
| 守恒量 | 存在首次积分（类似能量守恒） |
| Hopf 分岔 | 参数变化使不动点失稳 → 涌现极限环 |

**配对锚点—ESS（进化稳定策略）**：🟢 Maynard Smith 把"稳定"从微分方程搬到了博弈论——一个策略若被小群变异者入侵后仍占优，则进化稳定。这是"平衡点稳定性"在策略空间的对应物。

## 独特视角：把数学当"生命的方程"看
- 🟢 一个 Lotka-Volterra 极限环 = 草原上狼兔种群的周期命运
- 🟢 Fisher 定理：自然选择在数学上等价于适应度的梯度上升
- 🟡 "生命可方程化"——核心信念（仅供直觉，真实生物远比模型复杂）
- 🟡 Hopf 分岔 ≈ "平静突然变成振荡"：不动点失稳涌现周期
