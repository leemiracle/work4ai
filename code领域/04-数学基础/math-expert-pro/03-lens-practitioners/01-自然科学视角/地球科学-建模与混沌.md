# 地球科学家（把数学当"给不可实验的系统做预报"看）⭐

> 地球科学家面对"不可做实验"的混沌系统——用方程给一个无法重来的实验做预报。Navier-Stokes 确定但混沌，长期预报本质上不可能。

大气、海洋、气候、地震：尺度巨大、无法重做实验，唯一工具是数学建模 + 数值模拟。

## 核心数学工具箱
🟢【事实】
- **大气海洋流体力学—Navier-Stokes（PDE）**：$\rho\!\left(\dfrac{\partial\mathbf{u}}{\partial t}+\mathbf{u}\cdot\nabla\mathbf{u}\right)=-\nabla p+\mu\nabla^2\mathbf{u}+\mathbf{f}$。含科里奥利力。千禧年七大难题之一。
- **混沌—Lorenz 方程（三 ODE 组）**：$\dot{x}=\sigma(y-x)$，$\dot{y}=x(\rho-y)-zx$，$\dot{z}=xy-\beta z$（Lorenz 1963, *JAS* 20(2):130–141）。蝴蝶效应、奇怪吸引子原型，分形维数约 2.06。
- **地震波—波动方程（PDE）**：P 波（纵）/S 波（横），Snell 推广，层析成像（反演，类 CT 的 Radon）。
- **气候建模 GCM**：Navier-Stokes + 热力学 + 辐射 + 相变，在球面网格上数值离散化。
- **GIS / 空间统计**：克里金插值（高斯过程回归的地学版）、半变异函数、点过程。
- **尺度分析 / 无量纲化**：Buckingham π（Reynolds 数、Rayleigh 数）。

## 详写：Lorenz 方程——混沌的原型（本视角的数学锚点）
🟢【事实】（Lorenz 1963, *Journal of the Atmospheric Sciences* 20(2):130–141；Strogatz *Nonlinear Dynamics and Chaos*；交叉验证）

Lorenz 从大气对流的 Navier-Stokes 截断得到三个看似简单的 ODE：

$$\dot{x}=\sigma(y-x),\quad \dot{y}=x(\rho-y)-zx,\quad \dot{z}=xy-\beta z$$

| 现象 | 数学含义 |
|------|---------|
| 蝴蝶效应 | 初值敏感性：解指数分离（正 Lyapunov 指数） |
| 奇怪吸引子 | 轨道被吸引到一个分形集合（维数 ≈ 2.06） |
| 不可长期预报 | 确定性方程却不可长期预测 |

**含义**：🟢 这是对"确定性 = 可预测"直觉的根本反驳——方程完全确定，但长期行为本质上不可预报。Lorenz 由此奠定现代混沌理论。

🟢 配对锚点—Navier-Stokes：$\rho(\partial_t\mathbf{u}+\mathbf{u}\cdot\nabla\mathbf{u})=-\nabla p+\mu\nabla^2\mathbf{u}+\mathbf{f}$，描述一切流体（大气、海洋、岩浆），其**光滑性与全局存在性**至今未解（千禧年难题）。

## 独特视角：把数学当"给不可实验的系统做预报"看
- 🟢 用方程给一个无法重来的实验（地球气候）做预报
- 🟢 Navier-Stokes 确定但混沌 → 长期预报本质上不可能（Lorenz）
- 🟡 "蝴蝶效应" ≈ 一只蝴蝶扇翅膀引发飓风（仅供直觉，实际是初值敏感性的形象化）
- 🟡 气候模型 ≈ "把整个地球装进一个 PDE 求解器"
