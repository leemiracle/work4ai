# 音乐理论家（把数学当"听得见的结构"看）

> 音色 = 傅立叶频谱，音阶 = $\mathbb{Z}_{12}$ 群作用，转调 = 群元素——音乐理论揭示"听觉美感有数学结构"。

音乐是最古老的数学应用之一：毕达哥拉斯发现弦长比与和声的关系，傅立叶分解揭示音色本质，群论刻画音阶对称。

## 核心数学工具箱
🟢【事实】
- **音色的傅立叶分析**：音色 = 频谱包络（基频 + 泛音的叠加），傅立叶变换分解
- **音阶的群论**：十二平均律移位 = $\mathbb{Z}_{12}$ 作用，倒影生成二面体群 $D_{12}$
- **调律系统**：对数、连分数（平均律 = 八度 12 等比 $\sqrt[12]{2}$，毕达哥拉斯 3:2 迭代）
- **新黎曼理论**（**Lewin 1987**）：和声进行 = 群元素
- **Tymoczko 几何**（2011, Oxford）：和弦映射到**轨形（orbifold）**，音程 = 测地线
- **对位约束**：声部进行的组合规则（平行五度禁止等）
- 🟡 巴赫与黄金分割：网络说法多为后验模式匹配，**缺乏学术共识**

## 独特视角：把数学当"听得见的结构"看
- 🟢 傅立叶分解：钢琴音色 = 基频 + 泛音的叠加——傅立叶分析有直接的听觉实体
- 🟢 群论：十二音移位 = $\mathbb{Z}_{12}$ 群作用，移位 + 倒影 = 二面体群 $D_{12}$——琴键上的对称是可见的群论
- 🟢 对数：半音 = 频率乘以 $\sqrt[12]{2}$，八度 = 频率乘以 2——音程是对数刻度
- 🟢 Tymoczko 轨形：和弦空间 = 轨形几何，音程运动 = 测地线——音乐有几何结构
- 🟡 "音乐是听得见的数学——音程 = 几何距离，转调 = 群作用"
- 🟡 巴赫黄金比：**缺乏学术共识**，多为后验模式匹配，不可作严格结论
