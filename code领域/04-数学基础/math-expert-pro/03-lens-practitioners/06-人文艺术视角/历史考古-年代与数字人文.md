# 计量历史学家 / 考古学家（把数学当"读时间的函数"看）

> 碳-14 把指数衰减变成历史学时钟：半衰期 5730±40 年恰好覆盖考古关心的时段。Libby 的天才——有机体死亡后碳-14 以已知速率衰减。

历史学和考古学在数字人文时代越来越数学化：碳-14 测年、贝叶斯年代学、文本挖掘（齐普夫定律 / LDA）。

## 核心数学工具箱
🟢【事实】
- **碳-14 测年**：$N(t)=N_0 e^{-\lambda t}$，$\lambda=\ln2/T_{1/2}$。**Cambridge 半衰期 5730±40 年**（1962 第五次放射性碳会议）；Libby 值 5568 年仍作惯例。Libby 1960 诺奖化学
- **树木年代学**：树轮时间序列交叉定年
- **计量历史 Cliometrics**：回归 / 经济计量（Fogel-Engerman *Time on the Cross* 1974，争议；Fogel 1993 诺奖）
- **文本挖掘**：齐普夫定律（词频 $\propto 1/\text{rank}$，幂律）；LDA 主题模型（Blei-Ng-Jordan 2003，狄利克雷分布）
- **考古空间统计**：点过程、GIS
- **贝叶斯年代学**：先验（地层学）+ 似然（碳-14），OxCal 软件（Bronk Ramsey）

## 独特视角：把数学当"读时间的函数"看
- 🟢 碳-14 测年 = 指数衰减的历史时钟：$N(t)=N_0 e^{-\lambda t}$，半衰期 5730 年意味着每过 5730 年碳-14 剩一半——恰好覆盖考古关心的 5 万年时段
- 🟢 贝叶斯年代学：地层学先验 + 碳-14 似然 → 后验年代分布——考古学是贝叶斯推断的自然应用
- 🟢 齐普夫定律：词频 $\propto 1/\text{rank}$——自然语言和城市人口都遵循幂律，历史文本挖掘的数学基础
- 🟢 LDA 主题模型：用狄利克雷分布分解文档——"每篇文档是多个主题的混合"
- 🟡 "考古学是用指数函数读时间"
