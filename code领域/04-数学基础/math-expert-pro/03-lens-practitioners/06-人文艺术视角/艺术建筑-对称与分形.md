# 艺术家 / 建筑师（把数学当"视觉化的对称"看）

> 伊斯兰几何图案是 17 墙纸群的物理实现——500 年前工匠用尺规实现了 Pólya 1924 才证明的分类定理。埃舍尔在 Coxeter 启发下画出双曲几何。

艺术与建筑是数学对称群、射影几何、分形几何最直观的物理实现。

## 核心数学工具箱
🟢【事实】
- **黄金比**：$\varphi=(1+\sqrt5)/2\approx 1.618$，$F_{n+1}/F_n\to\varphi$（帕特农、柯布西耶模度——🟡 部分后验解读有争议）
- **透视**：射影几何、消失点（文艺复兴 = 中心投影，Alberti 1435）
- **对称群**（**Pólya 1924** 证明）：平面重复图案恰有 **17 墙纸群**、7 条带群——伊斯兰几何图案是这些群的物理实现
- **分形**：Mandelbrot 海岸线、波洛克滴画分形维数（Taylor 1999+，🟡 方法论有争议）
- **折纸数学**：Huzita-Hatori 7 公理，三浦折叠 Miura-ori（卫星太阳能板）
- **埃舍尔**：双曲几何（庞加莱圆盘）《圆之极限》

## 独特视角：把数学当"视觉化的对称"看
- 🟢 伊斯兰几何图案是对称群博物馆——500 年前工匠用尺规实现了 17 墙纸群（Pólya 1924 才分类证明）
- 🟢 埃舍尔在数学家 Coxeter 启发下画出双曲几何——《圆之极限》是庞加莱圆盘模型的艺术化
- 🟢 透视 = 射影几何：消失点 = 无穷远点，文艺复兴画家"发明"了射影几何的直觉
- 🟢 折纸数学：三浦折叠 Miura-ori 把一张纸折成可展开的太阳能板——数学指导工程
- 🟡 黄金比在艺术中的应用：部分是后验模式匹配，$\varphi$ 的"神圣性"被夸大
- 🟡 "艺术是视觉化的数学"
