# 形式语言学家（把数学当"自然语言的形式化"看）

> 乔姆斯基层级揭示"语言复杂性与计算复杂性是同一枚硬币"——Type 3 正则 ⟺ 有限自动机，Type 0 递归可枚举 ⟺ 图灵机。

形式语言学把语法变成数学对象，用自动机理论、概率模型、λ-演算刻画自然语言的结构与计算。

## 核心数学工具箱
🟢【事实】
- **乔姆斯基层级**（**Chomsky 1956** / **1959**）：
  - Type 3 正则 ⟺ 有限自动机
  - Type 2 上下文无关 ⟺ 下推自动机
  - Type 1 上下文相关 ⟺ 线性有界自动机
  - Type 0 递归可枚举 ⟺ 图灵机
- **句法的代数结构**：半群 / 幺半群；组合范畴语法 CCG 用 $\lambda$-演算
- **隐马尔可夫模型 HMM**：词性标注，前向-后向算法、Viterbi 解码
- **n-gram 语言模型**：$P(w_n|w_1\ldots w_{n-1})\approx P(w_n|w_{n-n+1}\ldots w_{n-1})$（马氏假设）
- **优选论 OT**：约束排序的优化

## 独特视角：把数学当"自然语言的形式化"看
- 🟢 乔姆斯基层级 = 语言复杂性与计算复杂性的精确对应：每种语法类型恰好对应一类自动机
- 🟢 HMM / Viterbi：NLP 的概率基础——语音识别、机器翻译的数学根基
- 🟢 λ-演算：句法-语义的组合性——"句子的意义 = 各部分的语义通过 λ 组合"
- 🟢 马氏假设：n-gram 模型用"下一个词只依赖前 n-1 个词"简化概率计算
- 🟡 "语言学是自然语言的形式化——语法 = 生成函数"

## 作为学习透镜怎么用

|---|---|
| 形式语言 / 自动机 | 乔姆斯基层级：每层语法 = 对应自动机能处理的语言 |
| 概率 / 马氏链 | HMM / Viterbi：NLP 基础，产出语音识别 / 机器翻译 |

| 信息论 | 交叉熵 = 语言模型的困惑度（perplexity） |
