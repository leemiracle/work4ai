# 定量社会学家（把数学当"关系的计算"看）

> "弱关系的力量"本质是图论命题——桥接边比强关系更能传播信息。社会网络分析把"谁认识谁"变成可计算的图。

定量社会学用图论、随机图模型、矩阵动力学研究社会结构，核心洞察：社会现象可以从微观关系的数学结构中涌现。

## 核心数学工具箱
🟢【事实】
- **社会网络分析**：**图论**——度中心性 / 介数中心性 / 接近中心性、结构洞（**Burt 1992**）
- **小世界网络**：**Watts-Strogatz 1998** *Nature*，高聚类系数 + 短平均路径，重连概率 $p$ 在规则与随机间插值
- **ERGM 指数随机图**：$P(Y=y)\propto\exp\{\theta'\cdot g(y)\}$，MCMC 估计微观结构如何涌现
- **意见动力学**：**DeGroot 1974** $x(t+1)=W\cdot x(t)$（矩阵幂 → 共识，马氏链收敛）
- **有界信任模型**：Hegselmann-Krause 2002，只信任与自己意见相近者
- **同质性分析**（Homophily）

## 独特视角：把数学当"关系的计算"看
- 🟢 图论把"关系"变可计算对象：中心性量化"谁是关键中介"，结构洞量化"谁占据信息桥"
- 🟢 DeGroot 模型：$x(t)=W^t x(0)$，矩阵幂收敛 → 群体意见趋同（马氏链的平稳分布就是共识）
- 🟢 Granovetter 1973"弱关系的力量"本质是图论命题：跨社群的桥接边比社群内强关系更能传播新信息
- 🟢 ERGM：用指数族分布建模"什么样的微观网络结构更可能出现"——统计推断社会结构
- 🟡 "社会网络是有血有肉的图论"

## 代表性资源
- Wasserman-Faust *Social Network Analysis: Methods and Applications*（1994）
- Granovetter 1973 *AJS*（"The Strength of Weak Ties"）
- Watts-Strogatz 1998 *Nature*（"Collective dynamics of small-world networks"）
- Burt *Structural Holes*（1992）
- DeGroot 1974 *JASA*（"Reaching a Consensus"）

## 作为学习透镜怎么用

| 学这个数学概念时 | 社会学家照出的切面 |
|---|---|
| 图论（度 / 介数 / 路径） | 社交网络中心性 = 谁是关键中介 |
| 矩阵幂 / 马氏链 | DeGroot 模型 $W^t$ 收敛 = 群体意见趋同 |
| 随机图模型 | ERGM：微观规则如何涌现社会结构 |
| 概率 / 统计 | 小世界网络统计性质（聚类 vs 路径长度） |
| 特征值 | 图拉普拉斯算子谱 → 社群检测 |
| 指数族分布 | ERGM = 指数族随机图，MCMC 参数估计 |

## 适合照哪些数学概念
（来自调研矩阵第 3 行：线代矩阵幂DeGroot / 概率统计 / 图论网络中心性 / 优化ERGM）
- **图论**：网络中心性、结构洞（核心锚点）
- **矩阵幂 / 马氏链**：DeGroot 意见动力学收敛
- **随机过程**：小世界 / 无标度网络
- **特征值**：谱聚类 / 社群检测
- **概率 / MCMC**：ERGM 参数估计
- **指数族分布**：ERGM 的统计基础
