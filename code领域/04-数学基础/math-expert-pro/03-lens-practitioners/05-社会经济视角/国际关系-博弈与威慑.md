## 详写：Axelrod 锦标赛与 tit-for-tat（合作演化的数学发现）
🟢【事实】（Axelrod 1984 *The Evolution of Cooperation*；Axelrod-Hamilton 1981 *Science* 211:1390）

1979-80 年，政治学家 Robert Axelrod 邀请博弈论专家提交计算机策略，进行**迭代囚徒困境锦标赛**。

**结果颠覆直觉**：最简单的策略——Anatol Rapoport 提交的 **tit-for-tat（以牙还牙）**——两次夺冠。规则仅两条：①第一步合作；②之后模仿对手上一步。

**tit-for-tat 的四大特征**（Axelrod 1984 总结）：
| 特征 | 含义 |
|---|---|
| 善良（nice） | 永不首先背叛 |
| 可激怒（retaliatory） | 被背叛立即报复 |
| 宽容（forgiving） | 对手回到合作后立即原谅 |
| 清晰（clear） | 规则简单，对手能看懂 |

**民间定理**（Folk Theorem）：在无限重复博弈中，只要贴现因子 $\delta$ 足够大，合作均衡可以被"未来报复的威胁"维持——**合作从纯粹自利中涌现**。

**Schelling 焦点**：在多重纳什均衡中，人们不约而同选中的那个——无需沟通的协调。Schelling 举例：两人约定在纽约见面却无法联系，大多数人选"中央车站中午 12 点"。这是博弈论中"唯一性"的社会来源。Schelling 与 Aumann 共获 **2005 诺奖**。

## 独特视角：把数学当"重复博弈与可信威慑的语言"看
- 🟢 博弈论天然实验室：威慑是否可信 = 不可撤销承诺的数学（自缚手脚才能威慑）
- 🟢 Axelrod 颠覆直觉——最简单 tit-for-tat 击败所有复杂策略，"善良但不软弱"
- 🟢 民间定理：合作从自利涌现（$\delta$ 足够大时报复威胁维持合作）
- 🟢 Schelling 焦点：无沟通协调的数学奇迹
- 🟡 "外交是博弈论穿西装——Schelling point 是两将军不打商量却选中同一座桥的数学奇迹"

**数学浓度特点**：国际关系是"博弈论专精"——重复博弈、民间定理、威慑可信性、联盟博弈。浓度集中在博弈论一域，深度可观（Axelrod/Schelling 均为该领域里程碑）。
