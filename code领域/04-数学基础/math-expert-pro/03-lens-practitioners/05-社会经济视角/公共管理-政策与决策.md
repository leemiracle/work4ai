# 政策分析者（把数学当"因果识别与伦理折现的语言"看）

> 折现率的伦理：低贴现率（Stern 1.4%）证成巨额气候投资，高（Nordhaus ~6%）则否——数学参数携伦理判断。DID/RDD/IV 是政策"到底有没有用"的因果三件套。

公共管理/政策分析的核心张力是**"折现率的伦理"** + **"政策因果识别"**。⭐ 四大标志性锚点：**CBA 社会折现率**（伦理判断编码为参数）、**DID/RDD/IV 因果三件套**、**AHP 特征向量权重**（Saaty 1977/1980）、**DEA 数据包络分析**（LP 效率前沿）。

## 核心数学工具箱
🟢【事实】
- **成本效益分析 CBA**：**NPV**、社会折现率争议（低折现率=重未来，气候核心）、**影子价格**、Hicks-Kaldor 准则
- **政策评估因果三件套**：**双重差分 DID**、**断点回归 RDD**（Lee-Lemieux 2010）、**工具变量 IV**（Wright 1928 / Angrist-Krueger）。"自然实验"范式
- **多目标决策/AHP 层次分析法**：**Saaty 1977/1980**——两两比较矩阵→最大特征值特征向量=权重，**一致性比率 CR**
- 🟢 **公共财政**：拉弗曲线、劳动供给弹性、Gini/洛伦兹
- 🟢 **DEA 数据包络分析**：**Charnes-Cooper-Rhodes 1978**（*EJOR* 2:429-444）——线性规划包络前沿，效率=加权产出/投入

## 详写：AHP 特征向量法与折现率伦理
🟢【事实】（Saaty 1977 *J Math Psychol* 15:234 / 1980 *McGraw-Hill*；Stern 2007 *The Stern Review*）

**AHP（层次分析法）**：决策者对 $n$ 个方案两两比较，给出比较矩阵 $A=(a_{ij})$（$a_{ij}$=方案 $i$ 相对 $j$ 的重要度）。权重向量 $w$ 是 $A$ 的**最大特征值对应的特征向量**：
$$Aw=\lambda_{\max}w$$

**一致性比率 CR**：若比较完全一致（$a_{ij}\cdot a_{jk}=a_{ik}$），则 $\lambda_{\max}=n$。CR$=(\lambda_{\max}-n)/(n-1)/\text{RI}$，CR<0.1 视为可接受。AHP 从"模糊主观比较"提取"客观权重"——线性代数的决策应用。

**折现率伦理**：CBA 把未来收益折现为现值 $\text{NPV}=\sum B_t/(1+r)^t$。Stern Review（2007）用低折现率 $\approx$1.4%，主张巨额气候投资；Nordhaus 用 $\approx$6%，则投资规模大减。**同一个数学参数（$r$），不同伦理立场，天壤之别的政策结论**。

**DEA**：线性规划构造效率前沿——$n$ 个决策单元中，效率=加权产出/加权投入的最大值。CCR 模型（Charnes-Cooper-Rhodes 1978）。

## 独特视角：把数学当"因果识别与伦理折现的语言"看
- 🟢 核心张力：**折现率的伦理**——低贴现率证成巨额气候投资，高则否，数学参数携伦理判断
- 🟢 AHP 用特征向量从"模糊主观比较"提"客观权重"
- 🟢 DID/RDD/IV 是政策"到底有没有用"的因果命根
- 🟢 DEA 用线性规划包络前沿度量效率
- 🟡 "政策是带贴现率的道德——折现率就是你对未出生者的关心程度"

**数学浓度特点**：公共管理是"统计因果 + 线性规划 + 特征值"的标准社科浓度——DID/RDD/IV、AHP、DEA。浓度中等，但"折现率伦理"是数学参数携带价值判断的独特视角。
