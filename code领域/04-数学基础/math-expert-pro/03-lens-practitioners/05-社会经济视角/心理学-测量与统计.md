# 心理测量学家（把数学当"看不见的能力的温度计"看）

> 特征值告诉你"这些题测了几个能力维度"，逻辑斯蒂函数把"能力"映射成"答题概率"——心理测量用量化方法回答"心理属性可不可测量"。

心理测量学是心理学中数学最密集的分支，核心问题：像智力、焦虑、能力这样看不见的心理属性，能否被严格量化？它用特征值分解、逻辑斯蒂模型、信号检测论给出肯定回答。

## 核心数学工具箱
🟢【事实】
- **项目反应理论 IRT**：三参数逻辑斯蒂 $P(\theta)=c+\dfrac{1-c}{1+e^{-a(\theta-b)}}$，其中 $a$=区分度、$b$=难度、$c$=猜测参数；Rasch 模型是其特例
- **因子分析 / PCA**：**特征值分解**，从相关矩阵提取潜在能力维度（"这些题背后有几个因子"）
- **结构方程 SEM**：$\Sigma=\Lambda\Phi\Lambda'+\Theta$，最大似然估计潜变量与观测变量的关系
- **实验统计**：ANOVA、混合效应模型、统计功效（Cohen's $d$）、样本量计算
- **心理物理学**：史蒂文斯幂律 $\psi=kS^n$（**Stevens 1946**）；费希纳对数律 $\psi=k\ln(S/S_0)$（**Fechner 1860**）
- **信号检测论 SDT**：$d'=(\mu_{signal}-\mu_{noise})/\sigma$，ROC 曲线量化辨别力

## 独特视角：把数学当"看不见的能力的温度计"看
- 🟢 特征值 = 能力维度：相关矩阵的特征值分解告诉你"这些测试题背后有几个潜在因子"——降维有心理学意义
- 🟢 逻辑斯蒂 = 能力→概率映射：IRT 把不可观测的能力 $\theta$ 映射到可观测的答题概率 $P(\theta)$
- 🟢 费希纳对数律：人类感知量与物理刺激量呈对数关系——"感知是对数刻度"（亮度、音量、重量都适用）
- 🟢 信号检测论 $d'$：把"能否区分信号与噪声"量化为一个数——ROC 曲线下的面积 = 辨别力
- 🟡 "心理测量像给看不见的能力装数学温度计"

## 作为学习透镜怎么用

| 学这个数学概念时 | 心理测量学家照出的切面 |
|---|---|
| 特征值 / 特征向量 | 智力测试背后几个能力因子——降维有心理学意义 |
| 逻辑斯蒂函数 | 能力 $\theta$ → 答题概率 $P(\theta)$ 的 S 形映射 |
| 对数 / 幂函数 | 费希纳"人类感知是对数"——感知量 vs 物理量 |
| 最大似然估计 | SEM 参数估计——从协方差结构反推潜变量 |
| ANOVA / 统计检验 | 实验组差异是否显著，统计功效决定样本量 |
| ROC / 信号检测 | 区分"真有信号"与"噪声"——$d'$ 量化敏感度 |
| 协方差矩阵 | 相关矩阵 = 心理变量间关系的数学表示 |
