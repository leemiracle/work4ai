# 城市规划师（把数学当"网络流与空间均衡的语言"看）

> Wardrop 用户均衡就是纳什均衡——无人能单方面改路缩短时间。NaSch 元胞自动机仅 4 条规则就涌现"鬼影拥堵"。城市规划是博弈+优化+排队+相变的四重交汇。

城市规划/交通工程是"博弈论 + 凸优化 + 排队论 + 复杂系统"的交汇点。⭐ 三大标志性锚点：**Wardrop UE = 纳什均衡**（用户均衡/系统最优的 4/3 价格）、**p-中位选址**（NP-hard 整数规划）、**NaSch 元胞自动机**（4 规则涌现走走停停）。

## 核心数学工具箱
🟢【事实】
- **网络流与交通分配**：**Wardrop 第一原理（用户均衡 UE）**——使用路径等时、未用更长；**第二原理（系统最优 SO）**——总行程时间最小。**Beckmann-McGuire-Winsten 1956** 证明 UE 等价凸规划的 KKT 条件；**Frank-Wolfe 算法**（1956）。非对称成本→**变分不等式**（Smith 1979, Dafermos 1980）。**无政府代价 ≤ 4/3**（Roughgarden-Tardós）
- **空间优化（设施选址）**：**p-中位问题**（min $\sum d$，整数规划 NP-hard）、p-中心、覆盖问题
- **排队论**：M/M/1 推广、**利特尔法则** $L=\lambda W$
- **用地模型**：**Lowry 模型**（**1964** *A Model of Metropolis*, RAND）基础就业→服务业→人口空间迭代
- **微观交通模拟**：**Nagel-Schreckenberg 元胞自动机 NaSch**（**1992** *J Physique I* 2:2221）——四规则涌现"鬼影拥堵"
- **空间相互作用**：**Wilson 最大熵引力模型** $T_{ij}=A_iB_jO_iD_jf(c_{ij})$

## 详写：Wardrop 均衡 = 纳什均衡（交通分配的灵魂）
🟢【事实】（Wardrop 1952 *Proc Inst Civil Eng* Part II 1(3):325-378；Beckmann-McGuire-Winsten 1956；Sheffi 1985）

**Wardrop 第一原理（用户均衡 UE）**：在均衡态，所有被使用的路径行驶时间相等，且不大于任何未被使用路径的行驶时间。

**这恰恰是纳什均衡**：没有司机能通过单方面改路来缩短自己的行驶时间。

**Wardrop 第二原理（系统最优 SO）**：总行驶时间最小——社会最优。

**UE 与 SO 的差距 = 无政府代价**：Roughgarden-Tardós 证明，在仿射成本函数下，UE/SO ≤ 4/3——自私驾驶最多让总时间增加 33%。

**Beckmann 1956 数学化**：UE 等价于一个**凸规划**的 KKT 条件——把"博弈均衡"变成"可求解的优化问题"。Frank-Wolfe 算法（1956）是标准解法。当路段间成本非对称（有交叉拥堵），凸规划失效，需改用**变分不等式**（Smith 1979, Dafermos 1980）。

## 独特视角：把数学当"网络流与空间均衡的语言"看
- 🟢 "博弈+优化+排队+相变"交汇：UE 是纳什均衡，SO 是社会最优，差=自私代价
- 🟢 NaSch 仅 4 条规则涌现无瓶颈的走走停停——**自组织临界**
- 🟢 p-中位选址是经典 NP-hard 整数规划
- 🟢 利特尔法则 $L=\lambda W$ 连接排队长度、到达率、等待时间
- 🟡 "城市是写在土地上的网络流问题，拥堵是它的相变"

**数学浓度特点**：城市规划是"博弈 + 凸优化 + 排队 + 元胞自动机"的**四重交汇**——Wardrop UE/KKT/变分不等式/NaSch。数学浓度中等偏高，且门类丰富。
