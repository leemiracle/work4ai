# 营销学者（把数学当"在噪声中识别因果的语言"看）

> A/B 测试把统计检验变日常工程，CUPED 让方差减半，Netflix Prize 发现口味是低维潜因子——推荐系统是猜心术的线代版。

营销是"统计实验 + 矩阵分解 + 因果推断"的工业实践。⭐ 三大标志性锚点：**A/B 测试 CUPED**（协变量调整减方差）、**矩阵分解推荐**（Netflix Prize 低秩结构）、**MMM 营销组合模型**（VAR 向量自回归）。

## 核心数学工具箱
🟢【事实】
- **消费者聚类/细分**：混合模型（latent class / Gaussian mixture，EM）、k-means、潜变量分群
- **A/B 测试与实验设计**：假设检验、统计功效、多重比较（Bonferroni/BH）、**CUPED**（协变量调整，**Deng-Xu-Kohavi 2013**）、在线因果推断
- **定价策略**：博弈（Bertrand/Cournot 寡头）、**机制设计**（拍卖、捆绑）、动态定价（RL/收益管理）
- **营销组合模型 MMM**：多元回归、**VAR 向量自回归**、广告弹性
- **推荐系统**：协同过滤、**矩阵分解**（**Koren-Bell-Volinsky 2009** *Computer* 42:8:42-49, Netflix Prize）、FM、深度 CTR 模型

## 详写：CUPED 与矩阵分解（营销的两大数学利器）
🟢【事实】（Deng-Xu-Kohavi 2013；Koren-Bell-Volinsky 2009 *Computer* 42:8:42-49）

**CUPED（Controlled-experiment Using Pre-Experiment Data）**：A/B 测试中，用实验前的协变量 $X$ 调整目标指标 $Y$：
$$Y_{\text{CUPED}}=Y-\theta(X-EX),\quad \theta=\frac{\text{Cov}(X,Y)}{\text{Var}(X)}$$

当 $X$ 与 $Y$ 高相关时，方差可降低 **50%+**——等价于把样本量翻倍。这是微软 Kohavi 团队的工业突破，已成为在线实验标配。

**矩阵分解推荐**（Netflix Prize 2006-2009）：用户×物品评分矩阵 $R$ 近似分解为 $R\approx UV^\top$（$U$=用户潜因子，$V$=物品潜因子）。核心发现：**口味是低维潜因子**——百万级评分矩阵有低秩结构。Koren-Bell-Volinsky 2009 总结了获奖方法。

## 独特视角：把数学当"在噪声中识别因果的语言"看
- 🟢 "在噪声中识别因果"的工业实践：A/B 把统计检验变日常工程
- 🟢 CUPED 让方差减半——协变量调整的工业落地
- 🟢 Netflix Prize 发现用户×物品评分矩阵有**低秩结构**——"口味"是低维潜因子
- 🟢 MMM/VAR 把广告效果归因到时间序列因果
- 🟡 "市场是高维噪声，营销数学是降噪器；推荐系统是猜心术的线代版"

**数学浓度特点**：营销是"统计 + 线代 + 因果"的标准社科浓度——A/B 检验、矩阵分解、混合模型。浓度中等，但工业实践深度极高（Netflix Prize、Kohavi CUPED 是工业级标杆）。
