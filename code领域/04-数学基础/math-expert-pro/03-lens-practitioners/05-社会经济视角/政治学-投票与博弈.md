# 政治学家（把数学当"不可能定理的实验场"看）⭐

> 阿罗不可能定理用公理化证明：没有"完美"的投票规则——这是数学定理，不是政治观点。沙普利值用公式定义"公平分配"。

政治学的数学化揭示了一个深层结论：民主制度在数学上有内在限度。⭐ 两大标志性定理——**阿罗不可能定理**和**沙普利值**——把"公平"和"权力"变成了可计算的数学对象。

🟢【事实】
- **阿罗不可能定理**（**Arrow 1951**, *Social Choice and Individual Values*, Wiley/Yale）
- **吉巴德-萨特斯维特定理**（Gibbard 1973 / Satterthwaite 1975）：任何非独裁投票机制都可被策略操纵

- **兰彻斯特方程**：$dA/dt=-\beta B$, $dB/dt=-\alpha A$（兵力损耗 ODE）

## 详写：阿罗不可能定理（民主的数学限度）
🟢【事实】（Arrow 1951；Mueller *Public Choice III*；交叉验证）

**⚠️ 这是数学定理，不是政治观点。**

阿罗证明了：当选项 ≥ 3 个时，**不存在**同时满足以下五条公理的社会福利函数（把个体偏好序聚合为群体偏好序的规则）：

| 公理 | 含义 |
|------|------|
| 1. 无限制定域（Unrestricted Domain） | 允许所有可能的个体偏好序 |
| 2. 帕累托（Pareto Efficiency） | 若所有人都偏好 A > B，则群体也偏好 A > B |
| 3. 无关选项独立性（IIA） | 群体对 A vs B 的排序只取决于个体对 A vs B 的排序，与其他选项无关 |
| 4. 非独裁（Non-dictatorship） | 不存在某个人的偏好完全决定群体偏好 |
| 5. 传递性（Transitivity） | 若群体偏好 A > B 且 B > C，则群体偏好 A > C |

**结论**：五条看似合理的公理**互相矛盾**——任何满足 1-3 和 5 的规则必然产生独裁者。这不是说"民主不好"，而是说"完美投票规则在数学上不可能"。孔多塞悖论（A>B, B>C, C>A 的循环偏好）是其最简单的具体实例。

## 详写：沙普利值（公平分配的数学定义）
🟢【事实】（Shapley 1953；Peyton Young *Equity*；交叉验证）

**沙普利值公式**——合作博弈 $(N,v)$ 中玩家 $i$ 的"公平"份额：
$$\varphi_i=\sum_{S\subseteq N\setminus\{i\}}\frac{|S|!\;(n-|S|-1)!}{n!}\big[v(S\cup\{i\})-v(S)\big]$$

**直觉**：$v(S\cup\{i\})-v(S)$ 是玩家 $i$ 加入联盟 $S$ 时的**边际贡献**。沙普利值对所有可能的加入顺序取平均——"每个玩家按其平均边际贡献获得份额"。

**为什么是"公平"的**：沙普利值是唯一满足效率（全部分配完）、对称性（等价玩家等分）、虚拟玩家（零贡献者得零）、可加性四条公理的分配方案。

**政治学应用**：Shapley-Shubik 权力指数（1954）用沙普利值度量"在投票联盟中，谁的关键否决权最大"——联合国安理会常任理事国的实际权力远大于表面票数。

## 独特视角：把数学当"不可能定理的实验场"看
- 🟢 阿罗定理：公理化方法揭示"民主在数学上有内在限度"——选哪些公理 = 选哪些价值立场
- 🟢 沙普利值：把"公平"定义成可计算的公式——边际贡献的平均
- 🟢 吉巴德-萨特斯维特：任何投票机制都可被策略操纵——"诚实投票"在数学上不成立
- 🟢 兰彻斯特方程：兵力损耗 ODE 把战争建模为微分方程组
- 🟡 "政治是不可能定理的实验场"
