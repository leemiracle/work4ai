# 运筹学家 / 管理科学家（把数学当"最优化的应用工程"看）

> 每个航班排班、每瓶可乐供应链背后都是优化模型——运筹学是最直接的"数学换钱"学科。

运筹学把线性规划、排队论、动态规划全部工程化，是连接"纯数学优化理论"和"日常商业决策"的桥梁视角。

## 核心数学工具箱
🟢【事实】
- **线性规划**：$\max c^Tx$ s.t. $Ax\leq b$，单纯形法（**Dantzig ~1947**）、对偶理论、KKT 条件
- **整数规划**：分支定界、割平面、旅行商问题 TSP
- **排队论**：Erlang 1909/1917 呼损公式；**利特尔法则** $L=\lambda W$（**Little 1961**）
- **库存模型**：EOQ $Q^*=\sqrt{2DK/h}$（Harris 1913）、报童模型（分位数解）
- **决策分析**：决策树、期望效用（von Neumann-Morgenstern 1944）
- **马尔可夫决策过程 MDP**：$\pi^*(s)=\arg\max_a\sum_{s'}P(s'|s,a)[R+\gamma V^*(s')]$
- **网络流**：Ford-Fulkerson，最大流 = 最小割

## 独特视角：把数学当"最优化的应用工程"看
- 🟢 单纯形法：在多面体顶点间移动寻找最优——线性规划 = 几何在约束多面体上的优化
- 🟢 利特尔法则 $L=\lambda W$：一行公式解释"系统中平均人数 = 到达率 × 平均停留时间"——供应链管理的基石
- 🟢 MDP 是强化学习的前身：$\pi^*(s)$ 公式就是 Bellman 最优性方程
- 🟢 对偶理论：影子价格 = 约束的边际价值——"放松这个约束能多赚多少钱"
- 🟢 最大流 = 最小割：图论对偶定理在网络优化中的直接应用
- 🟡 "运筹学是数学的应用工程"
