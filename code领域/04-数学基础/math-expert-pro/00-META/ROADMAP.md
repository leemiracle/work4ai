## 0. 定位

把一位 **Python 工程级、PyTorch 入门、数学零基础补课**的成年人，6-8 年培养成 **「应用数学研究型工程师 / 计算数学研究者」**（典型代表：von Neumann、Hassabis、DeepMind/量化研究员）。

**三约束交集**：🎯 研究级深度 + 🔧 工程落地 + 🎨 趣味性。

---

## 1. 六条强约束（贯穿全程）

| 原则 | 内涵 |
|------|------|
| 🎯 研究级深度 | 不再"会算就行"，要懂证明、能读论文 |
| 🔧 工程落地 | 每个抽象都找 AI/工程出口（**AI 锚点法**，防悬空）|
| 🎨 趣味性优先 | 历史+可视化+难题+故事，防半途而废 |
| 📦 输出倒逼输入 | 每书每章产笔记（**八重视角**）+ 代码 + 练习 |
| 🚫 拒绝完美主义 | 卡 3 天跳过，可持续 > 单次深度 |
| 🔁 每年一里程碑 | 年末研究级自检，决定进/留/退 |

**每周 10-20h 强制切分**：输入 6h : 输出 5h : 应用 4h。

## 4. 阶段 2 验收（研究生基础）

- Royden 核心章独立证明
- 读懂任一 GTM 前 3 章
- 用测度论重述概率
- **读懂一篇 arXiv ML 理论论文**
- **锁定 1-2 个研究方向**

### 阶段 2 四大支柱（待建学习包）
- Royden 实分析（测度论）+ Rudin Real & Complex
- Dummit-Foote 抽象代数 + Atiyah-MacDonald 交换代数
- Munkres 拓扑
- 测度论概率（Billingsley / 现代基础006/012）

## 5. 阶段 3 验收（= 最终验收）

- 读懂该方向前沿 arXiv
- 复现 ≥3 关键论文
- ≥10 篇研究笔记
- **能向研究生讲清一个开放问题**

### 研究方向 5 候选（阶段 2 末选 1-2）
- **A. ML 理论**：泛化/优化景观/PAC-Bayes（→ `03-lens-practitioners/角色/08-机器学习.md`）
- **B. 概率与随机过程**：SDE/鞅/扩散模型理论（GTM113 圣经，→ `角色/11-量化.md`）
- **C. 数值分析与科学计算**：仿真/图形/AlphaFold 类（→ `轴/计算实验.md`）
- **D. 优化理论**：凸非凸/组合优化/在线学习
- **E. 信息论与编码**：Shannon/压缩/密码（→ `角色/09-密码学.md` + `角色/05-硬件.md`）
