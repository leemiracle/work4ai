## 🌐 核心理念：从单视角到三维多视角矩阵

旧架构只有一条轴（时间轴 × 教材分科），笔记是「直觉→形式→代码→陷阱→AI应用」的**单向切片**——切得深但只有数学家一个视角。

**新架构是三维矩阵**，每个数学概念都可被多视角"照亮"：

```
                  维度3：透镜（Through whose eyes）
            ┌────────────────────────────────────┐
            │  🎓 数学家方法论透镜（16轴）         │
            │  🔧 从业者透镜（55角色·7门类+全景图） │
            └────────────────────────────────────┘
                           │
   维度2：概念切片 ◄────────┼────────► 维度1：时间主轴
   （同一概念的多元表征）              （教材进度 stage-1/2/3）
```

- **维度1 时间主轴**（`01-track/`）：保留教材进度流，不破坏学习节奏
- **维度2 概念切片**（`04-concepts/`）：同一概念跨教材跨表征的统一与差异
- **维度3 透镜**（`02-lens-mathematicians/` + `03-lens-practitioners/`）：名家方法论 × **43个真实职业**（化学/医生/经济/音乐…），每个视角照出数学的不同切面

加 5 条专题轴（历史/反例/批判/项目/教材对照）+ 个性化层 + 多维追踪。
