# START_HERE：从这里开始 👋

> 数学专家路径工作区的入口。**新用户 3 步内找到落点**，不再面对 13 扇门。

---

## ⭐ 3 步决策树（你来这做什么？）

**① 我在按教材学数学（主流程，占 80% 时间）**
→ 直接去 [01-track/stage-1-本科核心/](../01-track/stage-1-本科核心/) 精读教材+做题。这是 6-8 年马拉松的主战场，**不要被多视角分散注意力**。

**② 我想彻底搞懂某一个概念（如"极限""特征值"）**
→ 去 [CONCEPT-INDEX](CONCEPT-INDEX.md) 找这个概念的全景导航卡——它把概念散落在 11 个门类的所有讨论串成一张表（多表征/历史/反例/批判/职业化身/接地气/...），挑 2-3 个链接深读即可。

**③ 我想要动机/接地气/趣味（学累了或忘了为什么学）**
→ 读 [11-日常生活与公民数学/](../11-日常生活与公民数学/)（王阿姨贝叶斯/GPS 相对论/4% 法则）或 [12-社会系统视角/](../12-社会系统视角/)（雷曼/长赐号/德州寒潮）或 [05-history/](../05-history/) 的故事——看数学如何真实影响世界。

> 💡 **核心心法**：主轨 01-track 是必走主线，多视角是按需查阅的调味。**不要本末倒置**——多视角已就绪，重心转回实际学数学。
