## 如何使用本索引

**学一个新概念时（标准流程）**：
1. **先查本索引** → 找到对应概念导航卡
2. **读主轨 + 切片**（建立第一印象：教材怎么讲 + 有几张面孔）
3. **按兴趣挑 2-3 个链接深读**——推荐组合：
   - 想理解**为什么这么定义** → 读「历史」+「反例」+「批判」（看概念怎么被逼出来的）
   - 想理解**为什么有用** → 读「从业者化身」+「日常生活/社会系统」（看它在哪落地）
   - 想理解**数学家怎么想** → 读「数学家透镜」（换 1-2 个视角重看）
   - 想看**深度证明** → 读「项目」（同一个结论的多条证明路径）
4. **做自测题** → 检验是否真正理解
5. **记笔记** → 照 [NOTES_TEMPLATE](../NOTES_TEMPLATE.md) 八重视角写

**复习时**：直接扫一张卡的链接清单，看哪个门类忘了，点进去复习。

**选研究方向时**：横向对比几张卡——哪个概念在你感兴趣的职业里化身最多（查 [全景图](../03-lens-practitioners/全景图-数学如何渗透各学科.md) 的密度热力），就是高杠杆方向。

> 💡 **核心提醒**：每张导航卡不是要你一次读完所有链接。它是**地图**——告诉你"这个概念在这座知识城的哪些街区有分店"。你按当下需求，挑 2-3 家进店深读即可。
