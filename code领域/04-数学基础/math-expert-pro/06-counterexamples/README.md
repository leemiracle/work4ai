# 对比反例库：训练批判性思维的弹药

> 本目录是「批判性思维燃料轴」——每个反例都点破一个「以为万能」的认知偏差，逼理论变得更精确。
> 所属维度：维度 3a · 数学家方法论透镜 / 反思层 / **对比反例轴**（Lakatos「证明即反驳」）。

## 为什么单独建一个反例库

Imre Lakatos 在《证明与反驳》（*Proofs and Refutations*）中揭示了一个被教科书掩盖的真相：

> 「数学不是永恒真理的单调累积，而是通过证明尝试和反驳不断改进创造性假说的动态过程——定义不是刻在石头上的。」

按 Lakatos 的框架，数学概念的演化遵循同一条律动：

$$
\text{原始猜想 (primitive conjecture)} \;\xrightarrow{\text{反例 (counterexample)}}\; \text{找出有罪的引理 (guilty lemma)} \;\xrightarrow{\text{并入新条件 (lemma-incorporation)}}\; \text{改进后的定理}
$$

反例不是「刁难」，而是「逼理论更精确」。没有 Weierstrass 怪物，就不会有一致收敛；没有 Vitali 不可测集，就不会有 σ-代数；没有 Dirichlet 函数，就不会有 Lebesgue 积分。

## 三件事必须先讲清楚

1. **反例不是抬杠**：它是理论的「体检报告」——点破一个反例，就修复了一个隐藏假设。
2. **几何直觉在分析里已被永久降级**：从 Weierstrass 1872 那一天起，任何「画图能看出的论证」都不可信，只有 $\varepsilon$-$\delta$ 才算数（详见 `05-history/01-无穷之争` 的方法论遗产）。
3. **「反例嗅觉」比更多证明技巧更重要**：从 Berkeley 到 Russell 到 Weierstrass 怪物，每一次概念跃迁都由反例推动。培养对反例的嗅觉，是研究级数学家的核心能力。

## 阅读建议

- **入门**：从 01 Weierstrass 怪物开始——它是最经典的「直觉被打脸」案例，故事性最强。
- **学测度论时**：02 → 03 → 06 一组读——Cantor 集、Vitali 集、稠密性三个反例一起看，测度论的「为什么这样定义」就通了。
- **学积分时**：04 Dirichlet 函数配合 `05-history/01` 的 Lebesgue 一节——理解黎曼为何不够用。
- **学集合论时**：07 配合 `05-history/06-对角线与不完备`——连续统假设独立性是数理哲学的「核弹级」结论。
- **配横切轴**：本目录与 `03-lens-practitioners/横切轴/F-不可能性边界.md` 紧密呼应——Vitali、Gödel、停机问题、CAP 同属一条「不可能性元轴」。

## 方法论提醒

读完每个反例，问自己三个 Lakatos 式问题：

1. 这个反例破坏了哪个「以为显然成立」的直觉？把它写下来。
2. 理论是如何「打补丁」的？新补上的条件是什么？
3. 我能想象一个更强的反例吗？——这是培养「反例嗅觉」的关键练习。
