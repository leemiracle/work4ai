## 🎯 8 个能力维度

数学能力不是一个数（"我数学好不好"），而是**至少 8 个相对独立的维度**。一个人可能证明强但建模弱，可能可视化强但抽象弱。

| # | 维度 | 核心问题 | 极端表现 |
|---|------|---------|---------|
| 1 | **计算能力** | 能手算/数值计算吗？ | 5=秒算重积分；0=连分数加减错 |
| 2 | **证明能力** | 能写严格证明吗？ | 5=独立 ε-δ；0=只会套公式 |
| 3 | **建模能力** | 能把现实问题转成数学吗？ | 5=PDE 建模+求解；0=只会做应用题 |
| 4 | **抽象能力** | 能感知结构/做范畴思维吗？ | 5=自如用泛性质；0=离开具体数字就不行 |
| 5 | **可视化能力** | 有几何直觉吗？ | 5=脑内 4D 流形；0=图形都画不准 |
| 6 | **应用能力** | 能把数学落到工程/AI 吗？ | 5=端到端落地；0=不知道数学有什么用 |
| 7 | **计算思维** | 能算法化/形式化吗？ | 5=Lean 写证明；0=没接触过形式化 |
| 8 | **历史与品味** | 知道数学为什么这样发展吗？ | 5=懂 Lakatos 演变；0=只看公式不看人 |

## 📋 诊断题（每维度 5 题，0/1 分）

### 维度 1：计算能力
1. 求 $\int_0^1 x^2 e^{-x} dx$（用分部积分）→ 能做 = 1
2. 算 $\det\begin{pmatrix}1&2&3\\2&3&4\\3&4&6\end{pmatrix}$ → 正确 = 1
3. 估算 $\sum_{n=1}^{100} 1/n$ 到 0.1 精度 → 正确 = 1
4. 解 $y' = y, y(0)=1$ 并说出为什么 → 正确 = 1
5. 给定 $f(x)=x^2 \sin(1/x)$，$f'(0)$ 是多少？→ 正确 = 1

**得分 / 5 → 乘 1.0 = 该维度分（0-5）**

### 维度 2：证明能力
1. 写出"$\sqrt{2}$ 是无理数"的证明 → 严格 = 1
2. 用 ε-δ 证明 $\lim_{x\to 2} x^2 = 4$ → 严格 = 1
3. 证明有限群中元素的阶整除群的阶 → 严格 = 1
4. 证明紧致闭区间上的连续函数一致连续 → 严格 = 1
5. 证明 $\mathbb{Q}$ 在 $\mathbb{R}$ 中稠密 → 严格 = 1

### 维度 3：建模能力
1. 把"人口增长有上限"翻成数学模型 → logistic 方程 = 1
2. 把"传染病的扩散"翻成数学 → SIR 模型 = 1
3. 把"网页重要性"翻成数学 → PageRank/特征向量 = 1
4. 把"用户喜好预测"翻成数学 → 矩阵分解/低秩 = 1
5. 把"股票价格随机波动"翻成数学 → 几何布朗运动 = 1

### 维度 4：抽象能力
1. 说清"群"和"环"的区别 → 能 = 1
2. 说清"向量空间"的抽象定义（不依赖具体向量）→ 能 = 1
3. 理解"同态 = 保持结构的映射"→ 能 = 1
4. 理解"泛性质"（如积、自由对象）→ 能 = 1
5. 说清"范畴、函子、自然变换"三层 → 能 = 1

### 维度 5：可视化能力
1. 脑内画 $z = x^2 + y^2$ → 能 = 1
2. 理解高维球体体积在维度升高时趋于 0 → 能 = 1
3. 想象 Möbius 带 + 为什么不可定向 → 能 = 1
4. 看出矩阵特征值 = 椭圆半轴 → 能 = 1
5. 想象 4D 超立方体的投影 → 能 = 1

### 维度 6：应用能力
1. 用过 PCA 降维 → 能 = 1
2. 用过梯度下降训模型 → 能 = 1
3. 写过 PageRank 或推荐系统 → 能 = 1
4. 用过 SVD 做图像压缩 → 能 = 1
5. 用过傅里叶变换分析信号 → 能 = 1

1. 用过 Python/SymPy 做符号计算 → 能 = 1
2. 写过非平凡的递归/分治算法 → 能 = 1
3. 理解 Curry-Howard（证明 = 程序）→ 能 = 1
4. 用过 Lean/Coq 写过证明 → 能 = 1
5. 给过 mathlib/开源项目 PR → 能 = 1

### 维度 8：历史与品味

## 📊 评分与雷达图

**总分 0-40**。把 8 个维度分数填入下表，然后用 Python 画雷达图。

| 维度 | 分数(0-5) | 水平标签 |
|------|----------|---------|
| 1 计算 | __ | <2 入门 / 2-3 本科 / 4 熟练 / 5 专家 |
| 2 证明 | __ | <2 入门 / 2-3 本科 / 4 严格 / 5 研究 |
| 3 建模 | __ | <2 入门 / 2-3 会做 / 4 熟练 / 5 专家 |
| 4 抽象 | __ | <2 入门 / 2-3 本科 / 4 范畴 / 5 研究 |
| 5 可视化 | __ | <2 弱 / 2-3 中 / 4 强 / 5 几何直觉大师 |
| 6 应用 | __ | <2 不会 / 2-3 会调库 / 4 端到端 / 5 落地专家 |
| 7 计算思维 | __ | <2 不会 / 2-3 会编程 / 4 算法强 / 5 形式化 |
| 8 历史品味 | __ | <2 不关心 / 2-3 知道 / 4 有观点 / 5 有品味 |

### 雷达图绘制脚本（保存为 `radar.py` 跑）

```python
import numpy as np
import matplotlib.pyplot as plt

# 填入你的 8 维分数（0-5）
scores = [3, 4, 4, 3, 2, 5, 4, 3]  # 示例：替换成你的
labels = ['计算', '证明', '建模', '抽象', '可视化', '应用', '计算思维', '历史品味']

angles = np.linspace(0, 2*np.pi, len(scores), endpoint=False).tolist()
scores_plot = scores + scores[:1]
angles += angles[:1]

fig, ax = plt.subplots(figsize=(7,7), subplot_kw=dict(polar=True))
ax.plot(angles, scores_plot, 'o-', linewidth=2)
ax.fill(angles, scores_plot, alpha=0.25)
ax.set_thetagrids(np.degrees(angles[:-1]), labels)
ax.set_ylim(0, 5)
ax.set_title('数学能力雷达图', size=15, pad=20)
plt.savefig('能力雷达.png', dpi=100, bbox_inches='tight')
print('已保存 能力雷达.png')
```

## 🎯 雷达图的 3 种典型形状

### 形状 A：应用工程师型（你的起点很可能长这样）
```
应用5 计算3 证明4
计算思维4              建模4
       抽象3   历史品味3
              可视化2(短板)
```
**含义**：工程强、理论中、可视化弱。**方向建议**：走"应用数学研究型工程师"路线，补可视化 + 范畴抽象。

### 形状 B：纯数学研究型
```
证明5 抽象5 历史5
计算2                建模2
       应用1(短板)  可视化3
              计算思维2
```
**含义**：理论极强、应用弱。**方向建议**：走纯数学研究，但要补"AI 防御性"（选 AI 难做的方向）。

### 形状 C：均衡发展型
```
所有维度都在 3-4，无明显短板也无明显长板
```
**含义**：均衡。**方向建议**：找你的兴趣点深扎，从均衡变成 T 型（一深多广）。
