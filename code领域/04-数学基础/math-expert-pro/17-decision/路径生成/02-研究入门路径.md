# 研究入门路径：从学习者到研究者

> 这份指南帮你完成从"学数学"到"做数学"的转变。

---

## 一、学习 vs 研究的根本区别

| 维度 | 学习 | 研究 |
|------|------|------|
| 问题来源 | 教材/老师给 | **你自己找** |
| 答案 | 已知 | **未知** |
| 时间 | 周/月级 | 月/年级 |
| 成功标准 | 做对题/懂证明 | **发现新东西** |
| 方法 | 学习已有知识 | **创造新知识** |

## 二、从学习到研究的 5 步

### Step 1：读论文（阶段 2 中期）
- 从 survey 开始（不要直接读原始论文）
- 用 3-pass 法
- 目标：理解"数学家怎么思考问题"

### Step 2：复现论文（阶段 2 后期）
- 选一篇重要论文
- 自己重新推导每个定理
- 用 [Lean](../../14-frontier/AI-for-Math/02-Lean形式化数学入门.md) 验证关键步骤

### Step 3：找问题（阶段 2 末/阶段 3 初）
- 在你读过的论文中找"未解决的问题"
- 问导师/在 MathOverflow 提问
- 用 [方向决策矩阵](../方向决策/01-方向决策矩阵.md) 筛选

### Step 4：小研究（阶段 3）
- 选一个**小**的具体问题
- 尝试 3 种方法 → 都失败 → 换问题或换方法
- 记录所有尝试（[决策日志](../里程碑/决策日志.md)）

### Step 5：写论文（阶段 3 后期）
- 用 LaTeX 写（[速查](../../18-resources/速查/02-LaTeX数学公式速查.md)）
- 投 arXiv + 期刊
- 请人审阅

## 三、Tao 的建议（来自他的博客）

1. **不要只读"正确"的证明** → 读"错误的尝试"（Polymath 的开放记录）
2. **做"小"问题** → 不要一上来就攻大猜想
3. **写下你的思路** → 包括失败的尝试
4. **找学伴/导师** → 研究是孤独的，但不必独自做
5. **用 Lean** → 形式化帮你发现漏洞

## 四、研究方向匹配

用 [研究方向匹配器](../方向决策/02-研究方向匹配器.md) 确定你的"研究气质"：

| 气质 | 适合的方向 | 特征 |
|------|----------|------|
| 问题解决型 | 组合/数论 | 攻克具体问题 |
| 理论构建型 | 范畴论/基础 | 构建大框架 |
| 计算型 | 数值分析/ML | 设计算法 |
| 应用型 | 控制/优化 | 落地工程 |
| 跨学科型 | 数学物理/TDA | 连接领域 |
