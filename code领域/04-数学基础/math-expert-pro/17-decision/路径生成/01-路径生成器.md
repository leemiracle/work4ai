# 路径生成器（从 A 到 B 要学什么）

> 工具三：回答"从我现在到目标方向，要学什么、按什么顺序"。
> 核心机制：基于**前置依赖图**做拓扑排序，避免"还没学测度就看泛函"这种错序。

## 🛤️ 6 条典型路径

每条路径标注：**起点 → 终点 → 时长 → 关键节点**。

### 路径 1：本科核心重建（阶段 1）
```
起点: 会高中数学 + Python
终点: 能读 Spivak/LADR/Ross 关键定理证明
时长: 1-2 年（~1100h）
节点: 集合逻辑 → Spivak微积分(4月) → LADR线代(2月) → Ross概率(2月) → Rosen离散(2月)
详见: [01-track/stage-1-本科核心/](../../01-track/stage-1-本科核心/)
```

### 路径 2：研究生基础（阶段 2）
```
起点: 完成路径 1
终点: 读懂 GTM 前 3 章 + 一篇 arXiv ML 理论
时长: 2-3 年（~1900h）
节点: Royden实分析 → Dummit抽代 → Munkres拓扑 → Billingsley测度概率 → 锁定研究方向
详见: [01-track/stage-2-研究生基础/](../../01-track/stage-2-研究生基础/)
```

### 路径 3：ML 工程师 → ML 理论研究者
```
起点: 会训模型 + 懂微积分线代概率
终点: 能做 ML 理论研究（泛化/优化景观）
时长: 3-4 年
节点: 补严格证明(Spivak) → 补测度论(Royden选章) → 泛函分析(选章) → 
      高维概率(Vershynin) → 优化理论(Nesterov) → ML理论survey(Mohri/Bartlett)
推荐方向: [14-frontier/热点方向追踪/](../../14-frontier/热点方向追踪/) 的 #1 深度学习理论
```

### 路径 4：纯数学研究（数论/代数方向）
```
起点: 完成路径 1+2
终点: 能读 Annals/Inventiones 数论论文
时长: 4-5 年
节点: Dummit-Foote完整 → Atiyah-MacDonald交换代数 → 代数数论(Neukirch) → 
      类域论 → 自守形式/表示论 → Langlands纲领入门
推荐: G 数论方向（[方向决策矩阵](../方向决策/01-方向决策矩阵.md)）
```

### 路径 5：AI for Math 研究者（形式化 + AI）
```
起点: 会 Python + 懂基本代数
终点: 能给 mathlib 贡献 / 理解 AlphaProof
时长: 2-3 年
节点: 学 Lean 4(Natural Number Game) → 形式化本科数学(mathlib教程) → 
      同伦类型论 HoTT(选读) → 读 AlphaProof Nature论文 → 
      MiniF2F/lean-gym 基准
推荐: [14-frontier/AI-for-Math/](../../14-frontier/AI-for-Math/)
```

### 路径 6：应用数学研究型工程师（你项目的主线）
```
起点: Python 工程级 + PyTorch 入门
终点: 应用数学研究型工程师（Hassabis/DeepMind 量化型）
时长: 6-8 年
节点: 路径1(本科核心) → 路径2(研究生基础) → 路径3 或 选定方向专精(路径3-5之一) → 
      复现论文 + 做小研究
详见: [00-META/ROADMAP.md](../../00-META/ROADMAP.md)
```

## 🎯 自定义路径生成模板

**输入**（填空）：
```
我的起点（自评雷达）: 证__ 抽__ 应__ 计__ 视__ 建模__ 计思__ 史__
我的目标方向: __（从决策矩阵 Top 1）
我的时间预算: __ h/周 × __ 年 = __ h
我的约束: __（如：不读闭源软件、要兼顾工作）
```

**生成步骤**：
1. **定位**：用自评雷达对照目标方向的"需求雷达"，找出 **gap**（差最大的维度）
2. **补 gap**：在 [01-track/](../../01-track/) 里选补 gap 的教材（如证明弱 → Spivak）
3. **铺前置**：按依赖图拓扑排序，确保不跳序（如要学泛函先有实分析）
4. **加应用**：每周留 4h 跑 [15-applications/代码库/](../../15-applications/代码库/) + AI 锚点
5. **设里程碑**：每 3 个月一个可验证产出（如"独立证明 FTC"）

**输出**（示例）：
```
路径: 应用工程师(起点) → 优化理论研究方向(终点)
时长: 4 年（10h/周 × 48 周 × 4 = 1920h）
阶段A (0-6月): Spivak 证明训练（补证明 gap）
阶段B (6-12月): Royden 选章（补测度）+ LADR 完整
阶段C (1-2年): 凸优化(Nesterol) + 高维概率(Vershynin)选章
阶段D (2-3年): 非凸优化survey + 复现 3 篇关键论文
阶段E (3-4年): 选一个小问题做研究笔记
```
