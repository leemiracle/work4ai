# 研究方向匹配器（我适合做研究吗？做哪个？）

> 工具四：阶段 2 末锁定 1-2 个研究方向时用。
> 回答两个问题：① 我适合做数学研究吗？② 如果适合，做哪类研究？

---

## 🔬 第一问：你适合做数学研究吗？

数学研究 ≠ 数学学习。学习是"吸收已知"，研究是"创造未知"。下面 10 个问题帮你判断。

### 研究气质测试（每题 0/1/2 分）

| # | 问题 | 0=从不 / 1=偶尔 / 2=经常 |
|---|------|------------------------|
| 1 | 读到定理时，我会想"能不能换个条件/换个方向" | __ |
| 2 | 我能对着一个开放问题想 3 天以上不烦 | __ |
| 3 | 我享受"卡住"的感觉，卡住 = 即将突破 | __ |
| 4 | 我会主动找书/论文看，不是因为作业 | __ |
| 5 | 我能清晰地把一个数学想法讲给别人听 | __ |
| 6 | 我对"为什么这个定义这样写"比"怎么用"更感兴趣 | __ |
| 7 | 我能接受"努力 6 个月没有可见产出" | __ |
| 8 | 我读过至少 1 篇 arXiv 论文（哪怕没全懂）| __ |
| 9 | 我有自己的"数学品味"（喜欢某类问题胜过其他）| __ |
| 10 | 我能独立做出课本上的"练习题之外的"问题 | __ |

**总分 / 20**：
- **16-20**：✅ 强烈建议走研究向。你有研究者的核心气质（好奇心 + 耐心 + 品味）
- **10-15**：🟡 可以走，但需要培养耐心和品味。建议先做"小研究"（复现论文 + 写综述）试水
- **< 10**：❌ 暂时不建议。先在 [01-track/](../../01-track/) 深耕基础，研究气质可以后天培养

> ⚠️ **重要**：这不是"智商测试"，是"气质测试"。多数人通过培养可以从 < 10 到 15+。研究靠的是**10 年专注**而非天赋。

## 🎯 第二问：做哪类研究？

研究有多种"模式"。根据你的气质和雷达，匹配最合适的。

### 5 种研究模式

| 模式 | 特征 | 适合的人 | 代表 |
|------|------|---------|------|
| **A. 纯理论** | 证明定理、解猜想 | 证明★★★/抽象★★★/耐心★★★ | Tao, Scholze, Maynard |
| **B. 计算实验** | 用计算发现模式、猜定理 | 计算★★★/应用★★★/可视化★★ | Wolfram, OEIS 类工作 |
| **C. 应用驱动** | 工程/科学问题 → 找数学 | 建模★★★/应用★★★ | Hassabis, 量化研究员 |
| **D. 形式化** | 把数学形式化到 Lean/Coq | 计算思维★★★/严格★★★ | Buzzard, mathlib 贡献者 |
| **E. 综述/桥梁** | 整理、跨领域翻译 | 品味★★★/历史★★★/抽象★★ | Bourbaki, Terence Tao 的博客文 |

### 匹配规则

用你的自评雷达 + 研究气质总分，对照下表：

| 你的强项（雷达 ≥4） | 推荐模式 | 推荐方向（见决策矩阵） |
|-------------------|---------|-------------------|
| 证明 + 抽象 | A 纯理论 | G 数论 / I 泛函 / L 范畴 |
| 计算 + 应用 | B 计算实验 | D 数值 / C 概率 |
| 建模 + 应用 | C 应用驱动 | B 优化 / C 概率 / F 密码(应用) |
| 计算思维 + 证明 | D 形式化 | L 范畴 / E 信息 + Lean |
| 历史 + 抽象 | E 综述桥梁 | 跨领域（如 Langlands 物理-数论）|
| 可视化 + 抽象 | A 纯理论（几何向）| H 几何拓扑 / J 数学物理 |

## 📋 5 大研究方向的"做研究需要什么"

每个方向给一个"做研究的最低门槛 + 进阶"清单。

### G. 数论
- **最低门槛**：Dummit-Foote 完整 + 解析数论入门(Montgomery) + 复分析
- **进阶**：代数数论(Neukirch) + 模形式 + 类域论
- **做研究**：选一个小猜想（如某类 L 函数的性质）做数值实验 + 文献综述
- **时间**：从本科到能读论文 ≈ 4-5 年

### B. 优化
- **最低门槛**：凸优化(Boyd) + 线性代数 + 实分析
- **进阶**：非凸优化(Nesterov) + 在线学习 + 随机优化
- **做研究**：复现 3 篇 NeurIPS/ICML 优化论文 + 提改进
- **时间**：从本科到能投稿 ≈ 3 年（应用向比纯数快）

### C. 概率与随机过程
- **最低门槛**：Ross + 测度论概率(Billingsley)
- **进阶**：鞅论 + SDE(Karatzas-Shreve) + 高维概率(Vershynin)
- **做研究**：扩散模型理论 / 随机优化的某个开放问题
- **时间**：3-4 年

### D. 数值与科学计算
- **最低门槛**：线性代数 + 数值分析(Trefethen) + Python/C
- **进阶**：有限元 + 高性能计算(GPU/CUDA)
- **做研究**：某个科学计算问题（如流体仿真）的算法改进
- **时间**：2-3 年（最快出成果的方向）

### L. 范畴论与形式化
- **最低门槛**：本科代数 + 拓扑 + Lean 4 入门
- **进阶**：Mac Lane 范畴论 + HoTT Book + mathlib 深度贡献
- **做研究**：形式化一个未形式化的定理 / 范畴论应用（如数据库建模 Spivak）
- **时间**：3-4 年

## 🧪 "试研究"协议（锁定前的最后一步）

在正式锁定方向前，做一次"试研究"——花 1-2 个月，验证"我真的喜欢做这个吗"。

**协议**：
1. 选一个该方向的**开放小问题**（不是大猜想，是"硕士论文级别"的小问题）
2. 读 5 篇相关 arXiv 论文
3. 尝试独立推进（哪怕只推进一点点）
4. 写一份 2-3 页的"研究笔记"（不是论文，是思考记录）

**判断**：
- 做这 1-2 个月时，你**多数时候是兴奋还是焦虑**？
- 兴奋 > 焦虑 → ✅ 锁定这个方向
- 焦虑 ≥ 兴奋 → 换 Top 2 方向再试

> 这一步比任何测试都准。**研究的真相只能通过做研究来发现**。

## 🚫 常见研究决策错误

1. **"我要解黎曼猜想"** — 太大。研究者从"小问题"开始，积累信誉后才能攻大问题
2. **"AI 能做的我不做"** — 错。学会**用 AI 加速**是当代研究者的必备技能（[14-frontier/AI-for-Math](../../14-frontier/AI-for-Math/)）
3. **"我不够聪明"** — 多数研究者不是天才，是"足够聪明 + 10 年专注"。Tao 是例外不是常态
4. **"研究方向要时髦"** — 时髦方向竞争激烈。冷门方向更容易出成果
5. **"一个人闷头做"** — 现代数学高度协作。找合作者 = 10x 产出
