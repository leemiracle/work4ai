# 里程碑目录

> 这个目录用于记录你通过 [17-decision/](../) 工具做出的重大决策节点。

## 建议文件

- `决策日志.md` — 每次重大方向决策的记录（日期 / 自评雷达 / 决策矩阵结果 / 最终选择 / 理由）
- `年度复盘-YYYY.md` — 每年年末复盘（这一年学了什么 / 雷达怎么变 / 下年调整）

## 与 [00-META/PROGRESS.md](../../00-META/PROGRESS.md) 的分工

- PROGRESS.md：**周/月级**的进度追踪（学了什么、做了什么）
- 里程碑：**季度/年级**的重大决策记录（选了什么方向、为什么）

> 决策记录的价值：6 个月后回头看，你会发现"当时为什么这样选"——这是最宝贵的学习元数据。
