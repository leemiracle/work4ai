# 17-decision：方向决策与自评工具包

> 解决痛点：**「方向太多不知道怎么选」**
> 定位：在"数学有几百个分支、几千个方向"面前，给你一套**可执行的诊断 + 决策 + 路径生成**工具，把"凭感觉选"变成"用框架选"。

---

## 🎯 这个模块解决什么

数学的"选择困难"是结构性的：

```
分析 ─┬─ 实分析 ─┬─ 测度论 ─┬─ 概率论 ─┬─ 随机过程 ─┬─ SDE ── 量化金融
      │          │          │           │            └─ 马尔可夫 ── ML
      │          └─ 调和分析 ── 信号处理
      └─ 泛函分析 ─┬─ 算子代数 ── 量子物理
                  └─ Banach 空间 ── 优化 ── ML 理论
代数 ─┬─ 群论 ── 表示论 ── 物理/化学
      ├─ 数论 ─┬─ 解析数论 ── 密码学
      │       └─ 代数数论 ── Langlands ── Wiles
      └─ 同调代数 ── 代数拓扑 ── TDA(拓扑数据分析)
几何 ─┬─ 微分几何 ── 广义相对论 / 弦论
      ├─ 代数几何 ── 密码学(椭圆曲线) / Wiles
      └─ 拓扑 ── TDA / 量子场论
... (还有组合/逻辑/范畴/数值/离散/...)
```

**一个学习者面对这张图，最常问的 5 个问题**：
1. 我现在什么水平？（自评）
2. 我该学什么分支？（选方向）
3. 这个方向需要哪些前置？（路径）
4. 我适合做研究吗？做哪个方向？（研究向决策）
5. 我学数学是为了什么？（目标校准）

本模块用 **4 个工具** 回答这 5 个问题。

## 🔍 工具一：自评诊断器（能力雷达）

**做什么**：评估你在 8 个数学能力维度上的水平（0-5 分），生成雷达图，定位短板。

**8 维度**：
1. **计算能力**（手算 / 数值计算）
2. **证明能力**（ε-δ / 公理化推理）
3. **建模能力**（现实问题 → 数学）
4. **抽象能力**（结构感知 / 范畴思维）
5. **可视化能力**（几何直觉）
6. **应用能力**（数学 → 工程/AI）
7. **计算思维**（算法 / 形式化）
8. **历史与品味**（知道为什么这样发展）

详见 [自评诊断/01-能力雷达自评.md](自评诊断/01-能力雷达自评.md)（含 40 道诊断题 + 评分标准 + 雷达图绘制脚本）。

---

## 🧭 工具二：方向决策矩阵

**做什么**：用 5 个维度对每个候选方向打分，加权求和，**用框架代替感觉**。

**5 个决策维度**：
1. **兴趣匹配度**（0-10）：你对它的内在好奇心
2. **能力匹配度**（0-10）：你的自评雷达与该方向的需求匹配
3. **AI 防御性**（0-10）：这个方向 5-10 年内是否会被 AI 取代（参见 [14-frontier/AI-for-Math](../14-frontier/AI-for-Math/)）
4. **职业价值**（0-10）：对求职/研究的实际价值
5. **可行性**（0-10）：你当前的水平能否在合理时间内进入

**12 个候选方向**（详见 [方向决策/01-方向决策矩阵.md](方向决策/01-方向决策矩阵.md)）：
- ML 理论 / 优化 / 概率与随机过程 / 数值与科学计算 / 信息论与编码 / 代数与密码 / 数论 / 几何与拓扑 / 泛函分析 / 数学物理 / 离散与组合 / 范畴与基础

## 🗺️ 工具三：路径生成器

**做什么**：输入"我现在的水平 + 我想去的方向"，输出**个性化的学习路径**。

**核心机制**：基于**前置依赖图**（哪个概念是哪个概念的前置）做拓扑排序，生成路径。

详见 [路径生成/01-路径生成器.md](路径生成/01-路径生成器.md)（含 50+ 概念的依赖图 + 6 个典型路径样例 + 生成模板）。

## 📊 一次完整的决策流程（举例）

**场景**：你学完本科核心（Spivak + LADR + Ross），到阶段 2 末要选研究方向。

```
Step 1: 跑自评诊断器
  → 雷达图：证明4 / 抽象3 / 应用5 / 可视化2 / 计算3 / 建模4 / 计算思维4 / 品味3
  → 诊断：可视化弱、抽象待加强，但应用和建模强

Step 2: 用方向决策矩阵打分（12 方向 × 5 维度）
  → Top 3：ML 理论(8.4) / 优化(7.9) / 概率随机过程(7.6)

Step 3: 用 AI 防御性过滤器
  → ML 理论（高价值但 AI 也在做） vs 优化（AI 难以取代开放问题） vs 概率（经典护城河）

Step 4: 用路径生成器看"进入 Top 方向需要什么"
  → 选「优化」：需要凸分析(Royden) + 数值优化(Nocedal) + 非凸理论(近期综述)

Step 5: 用研究方向匹配器确认"我适合做优化研究吗"
  → 测评：你的"耐心 + 抽象 + 工程"组合 → ✅适合应用优化方向

Step 6: 输出 → 锁定「优化理论」为研究方向，生成 2-3 年路径
```

**关键**：每一步都可独立使用，但串起来 = 完整决策。

## 🚫 常见决策陷阱

| 陷阱 | 表现 | 解药 |
|------|------|------|
| **跟风选热门** | "AI 理论最热，我就选它" | 用兴趣 + 能力匹配，不用热度选 |
| **完美主义选不出** | "我想选最优的" | 没有"最优"，只有"足够好 + 你愿意坚持" |
| **过早收窄** | 阶段 1 就锁死方向 | 阶段 1-2 保持开放，阶段 2 末再锁 |
| **忽视 AI 趋势** | 选了 AI 5 年能做的方向 | 过 [AI 防御性](../14-frontier/AI-for-Math/) 过滤器 |
| **只看天赋不看努力** | "我没有 Tao 的天赋" | 多数研究方向不需要天才，需要 10 年专注 |
