# 社会系统整体视角

> **核心命题**：现代社会的运转不是某个英雄的功劳，而是无数数学模型在同时运行、相互协同的结果。任何一个环节的数学失效，整个系统就会崩溃。

---

## 这个门类讲什么

如果说 **11-日常生活与公民数学** 讲的是"数学怎么影响一个人"，这里讲的是"数学怎么支撑一个社会"。

一座城市一天里，交通信号、电网、地铁、供水、急救由各自的数学模型协同。一次疫情里，SIR 模型在流行病学家、经济学家、政策制定者、媒体、医生、统计学家之间流转。一次金融危机里，一家银行的倒下通过网络传染瘫痪全球信用。一次供应链中断里，一艘船卡住一条运河，全世界的工厂停摆。一次寒潮里，电网的供需平衡方程失守，246 人冻死。

这些不是孤立的"意外"，而是**系统结构决定的脆弱性**。每个系统都是一张由数学模型编织的网——网越密越高效，但也越脆弱，因为任何一个节点的失败都可能沿着连接扩散成灾难。

本门类的立场：**理解宏观系统，能帮你理解为什么"个人努力"有时敌不过"系统结构"。** 德州居民再省电也挡不住电网崩溃；普通消费者再精明也挡不住金融危机；一家工厂再高效也挡不住苏伊士运河堵船。系统的脆弱性，需要系统的视角才能看见。

## 系统脆弱性的数学根源

从这五个系统里，可以提炼出五个共同的脆弱性模式。这不是抽象理论，而是用真实灾难换来的教训。

### 1. 网络互联放大冲击

雷曼一个节点倒下 → AIG 倒下 → 货币市场冻结 → 全球信用冻结（网络传染 / 级联失败）。苏伊士运河一条船 → 全球 12% 贸易堵死（割集瓶颈）。**连接让系统高效，也让冲击扩散。** 数学上，这对应网络理论中的"级联失败模型"——一个节点的失效让相邻节点超载，进而引发雪崩。

### 2. 正反馈循环的危险

德州：天然气管道冻结 → 燃气电厂停机 → 电力短缺 → 天然气压缩机断电 → 更多管道冻结（正反馈循环）。金融恐慌：抛售 → 价格跌 → 保证金追加 → 更多抛售（追缴螺旋）。**正反馈让小扰动滚雪球成灾难。** 这与"负反馈"（恒温器、人体体温调节）相反——负反馈让系统稳定，正反馈让系统失控。

### 3. 供需实时平衡的刚性约束

电网的 $\sum P_{gen} = P_{load}$ **每一秒**都必须成立，没有缓冲余量。城市交通每秒数千个信号决策。金融清算每秒数万笔交易结算。**这些系统的"实时性"意味着一旦失衡，没有时间慢慢调整——必须瞬间响应。** 德州就是供需失衡超过储备容量后的被迫"减载"（主动停电）。

### 4. 模型与现实的差距

雷曼 VaR 模型排除商业地产，低估损失 3-4 倍。Ferguson 模型预测"不干预会死 51 万"，但干预后没发生——不是模型错，而是模型预测的是"不干预情景"。**模型永远是对现实的简化，简化的边界就是风险的藏身处。** 塔勒布的"黑天鹅"警告：正态分布假设的 VaR 系统性低估尾部风险。

### 5. 独立子系统的耦合失败

德州 ERCOT 是独立电网，与邻近州互联极少——危机时无法"借电"。天然气系统与电力系统耦合失败：电停了 → 天然气压缩机停 → 气停了 → 电厂停（两个本应独立的系统互相拖垮）。**效率驱动的"独立优化"在危机时变成致命弱点。** 韧性（resilience）需要冗余和互联，而这恰恰是效率的反面。

> **点睛**：系统性风险不是某个人犯错，而是系统结构决定的必然性。你以为你在看一棵树，但你其实在看一片森林。

## 从日常生活到社会系统：两层视角的互补

| 维度 | 11-日常生活与公民数学 | 12-社会系统视角 |
|------|---------------------|-------------------|
| 视角 | 微观（个人决策） | 宏观（社会运转） |
| 主角 | 小李、王阿姨、老周、张奶奶 | 新加坡、英国、雷曼、长赐号、ERCOT |
| 数学怎么出现 | 影响你的钱包/健康/分数 | 支撑城市/金融/供应链/电网的运行 |
| 核心素养 | 概率/指数/复利思维 + 量化质疑 | 系统性思维 + 脆弱性识别 |
| 失败的代价 | 个人失眠/破财/误诊 | 万人死亡/经济危机/全球停摆 |

两层视角缺一不可：只看微观，你会把系统性问题误认为个人努力不够（"穷人是因为不够聪明"）；只看宏观，你会忽视每个数字背后都是活生生的人（"246 人死亡"不是统计，是 246 个家庭）。

## 怎么用这个门类

- **先读本 README** 理解"系统脆弱性五根源"，再按兴趣读单个系统。
- **每个系统文件都包含**：真实事件开场 + 数学模型 + 真实数据与年份 + 真实工具 + 常见误区 + 系统协同素养提炼。
- **🟢 标记是已核实事实**，可作为锚点；❌ 标记是常见误区。
- 建议把五个系统对照着读，你会发现它们的脆弱性模式高度相似——这就是"系统性思维"的入门：**学会在不同领域看见相同的结构。**
