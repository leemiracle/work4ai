## 🤖 0. OpenAI 解决 Erdős 单位距离问题（2026.07）⭐⭐⭐ 最新！

**来源**：[Tao 博客 2026.07.03](https://terrytao.wordpress.com/2026/07/03/a-digestion-of-unit-distance-constructions/) 讨论 OpenAI 的构造

**核心**：OpenAI 团队解决了 Erdős 单位距离问题——构造了 $n$ 个点的集合，产生 $d_1(P) \gg n^{1+c}$ 个单位距离（$c > 0$ 为常数），**超越了 Erdős 1946 年的原构造** $n^{1+c/\log\log n}$。

**为什么震撼**：
- 这是 **AI 做出真正数学发现**的又一里程碑（继 AlphaProof/FunSearch 之后）
- 构造使用了深刻的代数数论（Golod-Shafarevich 塔扩张）
- 目前已知 $0.0358 \leq c \leq 1/3$，最优值仍开放
- Tao 还提到 Mythos AI 用更少的代数数论给出了中间结果 $n^{1+c/\log\log\log n}$

**与项目连接**：AI 改变数学 → [AI-for-Math/01](../AI-for-Math/01-AI正在重写数学研究.md)；组合几何 → [热点方向追踪](2024-2026十大热点方向.md) #2

## 📐 1b. Tao 新论文：Gilbreath 猜想的随机模型（2026.07.11）⭐

**来源**：[Tao 博客 2026.07.11](https://terrytao.wordpress.com/2026/07/11/gilbreaths-conjecture-a-cramer-random-model-and-a-deterministic-analysis/) + [arXiv:2607.08712](https://arxiv.org/abs/2607.08712)

**核心**：Tao + Zachary Chase + Zach Hunter 的新论文——Gilbreath 猜想的 Cramér 随机模型验证 + 确定性"逆定理"。

**Gilbreath 猜想**：从素数序列出发，反复取相邻项的绝对差，每行第一项总是 1：
```
2  3  5  7  11  13
  1  2  2  4   2
    1  0  2   2
      1  2   0
        1   2
           1
```

**论文贡献**：
1. 在 Cramér 随机模型下几乎必然成立（将 Chase 之前的结果从 $f(n) \leq \frac{\log\log n}{10\log\log\log n}$ 推广到 $f(n) = o(n)$）
2. 给出确定性"逆定理"——将猜想归约为两类"坏情景"的排除（长零串 / {0,d} 块）

## 💻 1c. Tao 用 AI Coding Agent 做数学可视化（2026.07.11）⭐

**来源**：[Tao 博客 2026.07.11 - Old and new apps, via modern coding agents](https://terrytao.wordpress.com/2026/07/11/old-and-new-apps-via-modern-coding-agents/)

**核心**：Tao 用 AI coding agent（"vibe coding"）：
1. 几小时内将他 1999 年的 Java applet 迁移到 JavaScript（仅 1 个小 bug）
2. 实现了他 1999 年放弃的狭义相对论时空图可视化
3. 为 Gilbreath 猜想论文创建了配套交互式可视化

**Tao 的评价**："LLM coding agent 能产生各种明显或微妙的 bug，但在移植这二十几个 applet 时，我只找到一个 bug——而且 agent 还发现了我原代码里的两个 bug。对于非核心论证的辅助可视化，这种风险是可接受的。"

**意义**：顶尖数学家公开采用 AI coding 工具辅助研究——AI 已进入数学家的日常工具箱。

## 📊 3. Erdős 随机方法 80 年后获升级（2026.06.26）⭐

## 🃏 4. 洗牌数学新突破（2026.06.17）

**来源**：[Quanta - Seven Perfect Shuffles Randomize a Deck of Cards. But How Many Sloppy Ones?](https://www.quantamagazine.org/seven-perfect-shuffles-randomize-a-deck-of-cards-but-how-many-sloppy-ones-20260617/)

**核心**：
- 经典结果（Bayer-Diaconis 1992）：7 次**完美**洗牌足以随机化一副牌
- 新证明：**粗糙（sloppy）洗牌**需要多少次？
- 新方法绕过了"完美切割"的假设，更贴近现实

**为什么有趣**：连接了概率论、马尔可夫链、群论（洗牌 = 对称群的随机游走）
