## 🔀 与 conjecture进展/ 的区别

这是新用户最常混淆的两点，务必分清：

| 维度 | 本目录（热点方向追踪）| conjecture进展/ |
|------|---------------------|----------------|
| **粒度** | **领域 / 方向**（如"加性组合"）| **具体问题**（如"PFR 猜想""孪生素数"）|
| **视角** | 横向：一片活跃的研究版图 | 纵向：一个问题的解决状态（✅/🟡/🟠/❌）|
| **时间感** | 持续活跃（3-5 年视角）| 里程碑式（哪年谁突破）|
| **回答的问题** | "这个领域在做什么？怎么入门？" | "这个问题被解决了吗？" |

**类比**：本目录是"地图上的热区"（哪里活跃），conjecture进展/ 是"地图上的灯塔"（具体边界点）。

## 🎯 入口建议（按你的背景选 2-3 个深跟）

### 不要全追——选 2-3 个

10 个方向全追 = 信息过载 + 哪个都不深。建议：

1. **选 1 个"主轨方向"**：与你当前学习路径 / 工作最相关的（如学数论 → #2 加性组合）
2. **选 1 个"AI 交叉方向"**：拓展视野、防止闭门造车（如纯数背景 → #9 形式化数学）
3. **选 1 个"防御性方向"**：长期保值（🟢 标的，如 #8 数学物理）

### 按背景推荐

| 你的背景 | 推荐组合 |
|---------|---------|
| CS / AI | #1 深度学习理论 + #10 优化 + #9 形式化 |
| 纯数（数论 / 代数）| #2 加性组合 + #3 RMT + #8 数学物理 |
| 纯数（几何 / 拓扑）| #4 TDA + #7 数值代数几何 + #8 数学物理 |
| 应用 / 工程 | #4 TDA + #6 高维概率 + #10 优化 |
| 跨学科 / 想保值 | #5 范畴论 + #8 数学物理（AI 难解）|
