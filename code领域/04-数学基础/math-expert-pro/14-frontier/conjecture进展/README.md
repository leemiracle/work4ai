## 📐 目录定位

当你问出这些问题时，来这里：

- "黎曼猜想到底被证明了吗？" → 看状态标记，不要被新闻误导
- "七大千禧问题中哪些已经解决了？" → 只有 Poincaré，其余 6 个仍开放
- "abc 猜想到底什么情况？" → Mochizuki 声称 vs Scholze 反对，标 🟠 争议未决
- "我学的东西距离研究前沿有多远？" → 用这张表当灯塔，定位自己的位置

本目录**不是**让你去"攻克"这些问题——它是一张**地图**，帮你理解数学的版图边界在哪。

## 🔖 状态图例

| 标记 | 含义 | 判定标准 |
|------|------|---------|
| ✅ | **已解决** | 发表在 Tier S 顶刊（Annals / Inventiones / JAMS / Acta），或获 Fields/Abel/千禧奖确认 |
| 🟡 | **部分进展** | 有发表在顶刊或权威来源确认的实质性结果，但未完全解决原问题 |
| 🟠 | **声称待验证** | arXiv 预印本或争议中——**不算已解决**，需等待同行评审或主流共识 |
| ❌ | **开放** | 无被广泛接受的实质性逼近（可能有数值验证或相关模型结果） |

## ⚠️ 可信度声明（重要）

**"声称证明" ≠ "已证明"。** 这是最核心的区分：

- 🟠 **声称证明**：arXiv 预印本、作者博客、媒体报道——**默认不可信**，仅作线索
- ✅ **已证明**：Tier S 顶刊发表 + 主流专家（Fields/Abel 级）公开确认

**典型案例——黎曼猜想**：过去 20 年出现 10+ 次"声称证明 RH"（含 de Branges、多篇 arXiv 预印本），**无一通过同行评审**。任何"RH 被证明"的新闻，默认标 🟠，直到 Annals/JAMS 发表或 Tao 等公开背书。

**典型案例——abc 猜想**：Mochizuki 2012 提出 IUT 理论，PRIMS 2021 发表，但 **Scholze-Stix 2018 公开反对**。当前主流共识：abc **仍为猜想**。

> **铁律**：读到"X 问题被解决"时，先回溯到 [14-frontier 的 Tier S 源](../README.md)。回溯不到，就标 🟠。

## 📅 维护节奏

| 时间 | 动作 | 原因 |
|------|------|------|
| **每年 ICM 后（8 月）** | 全表刷新 | Fields Medal 新得主工作、ICM 邀请报告反映最新前沿 |
| **年底（12 月）** | 状态盘点 | 年内发表的重磅论文进入 Tier S |
| **随时（遇重大消息）** | 局部更新 + 标 🟠 | 遇到"声称证明"立即标记，但不急于改 ✅ |

**信息日期**：每条记录标注截至年月。本目录所有事实以 [14-frontier 可信度分级](../README.md) 中的 Tier S/A 源为准。
