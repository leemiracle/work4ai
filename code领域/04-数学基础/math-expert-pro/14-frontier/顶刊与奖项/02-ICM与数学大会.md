# ICM 与国际数学大会

> ICM（International Congress of Mathematicians）= 数学界的奥运会。

---

## 一、ICM 基本信息

| 维度 | 内容 |
|------|------|
| 频率 | 每 4 年 |
| 主办 | IMU（国际数学联盟） |
| 最大亮点 | Fields Medal 颁奖 |
| 规模 | 3000-5000 数学家 |
| 报告 | ~200 个邀请报告（Plenary + Sectional） |

## 二、历届 ICM 与 Fields 得主

| 年 | 地点 | 亮点 |
|----|------|------|
| 2002 | 北京 | Perelman 宣布 Poincaré 证明 |
| 2006 | 马德里 | Perelman 拒领 Fields；Tao 获奖 |
| 2010 | 海得拉巴 | Villani/Ngô |
| 2014 | 首尔 | Mirzakhani（首位女性 Fields）|
| 2018 | 里约 | Scholze（30岁 Fields）|
| 2022 | 线上(圣彼得堡改) | Duminil-Copin/Huh/Maynard/Viazovska |
| **2026** | **Philadelphia** | **下一届 Fields！** |

## 三、ICM 邀请报告——风向标

被邀请做 ICM 报告 = 被"圈内核"认可 → 预判未来 Fields。

建议：
1. 看 2022 ICM 报告人列表 → 预判 2026 Fields 候选
2. 看 2026 ICM 报告人列表 → 预判 2030 Fields 候选
3. ICM 报告视频免费在 YouTube

## 四、2026 ICM（Philadelphia）关注点

- 时间：2026 年 7 月（已过——追回顾间报道）
- 新一届 Fields 得主（4 人）
- ICM 邀请报告 = 未来 4-8 年风向标
- **可信度**：Tier S（ICM 官方）
