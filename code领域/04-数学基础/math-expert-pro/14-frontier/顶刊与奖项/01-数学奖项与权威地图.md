# 数学奖项与权威地图

> **「谁是当下权威？哪些期刊最重要？」**——Fields / Abel / Breakthrough / EMS 四大奖项体系 + 四大顶刊的发表规律，帮你识别"值得追的人和工作"。
>
> 信息日期：2026-07 | 可信度：Tier S（奖项官网 + 期刊官网）

---

## 一、Fields Medal（菲尔兹奖）——数学界最高荣誉

### 规则

| 维度 | 规定 |
|------|------|
| **频率** | 每 4 年，在国际数学家大会（ICM）上颁发 |
| **年龄** | 获奖当年 1 月 1 日未满 **40 岁** |
| **人数** | 每次 **不超过 4 人** |
| **国籍** | 无限制 |
| **奖金** | 加拿大元 15,000（象征性，非重金）|
| **历史** | 1936 首届（Fields 设立），1950 起每 4 年 |

**为什么有年龄限制**：Fields 本意是"激励年轻数学家继续创造"，而非终身成就。这也是 Fields 与 Abel 的核心区别。

### 历届高光（近 30 年）

| 年份 | 得主 | 代表工作 | 备注 |
|------|------|---------|------|
| **1998** | **Maxim Kontsevich** | 镜像对称、Witten 猜想 | Bourgain, Gowers, McMullen 同届 |
| **2002** | Laurent Lafforgue, Vladimir Voevodsky | Langlands（函数域）、motivic 同伦 | Voevodsky 后转向 HoTT，2017 故 |
| **2006** | **Terence Tao**, Grigory Perelman（拒）、Andrei Okounkov, Wendelin Werner | Tao：素数、压缩感知；Perelman：Poincaré | **Perelman 拒领**，历史性事件 |
| **2010** | Ngô Bảo Châu, Cédric Villani, Stanislav Smirnov, Elon Lindenstrauss | Ngô：基本引理；Villani：Boltzmann | |
| **2014** | **Maryam Mirzakhani**（首位女性）、Artur Avila, Manjul Bhargava, Martin Hairer | Mirzakhani：Riemann 面动力系统 | **Mirzakhani 2017 病逝**，年仅 40 |
| **2018** | **Peter Scholze**, Alessio Figalli, Caucher Birkar, Akshay Venkatesh | Scholze：perfectoid spaces | Scholze 30 岁获奖 |
| **2022** | 见下表 | | 虚拟 ICM（原定圣彼得堡，因俄乌冲突改线上）|

### 2022 年四得主（最近一届）

| 得主 | 国籍 / 单位 | 代表工作 | 信息日期 |
|------|------------|---------|---------|
| **Hugo Duminil-Copin** | 瑞士 / IHÉS | 统计力学相变、Ising 模型连续性 | 2022.07 |
| **June Huh** | 美籍韩裔 / Princeton | 组合代数几何、Rota 基猜想（特征多项式 log-concavity）| 2022.07 |
| **James Maynard** | 英国 / Oxford | 素数间隙（独立于 Zhang）、小间隙突破 | 2022.07 |
| **Maryna Viazovska** | 乌克兰 / EPFL | **8 维与 24 维球填充最优解**（模格 E₈, Leech lattice）| 2022.07 |

> Viazovska 是**第二位女性**Fields 得主，也是第 2 位乌克兰裔。她的球填充证明只用模形式，优雅至极。

### 2026 ICM（Philadelphia）预热

- **时间**：2026 年 7 月（International Congress of Mathematicians）
- **地点**：美国费城
- **关注点**：新一届 Fields 得主（届时 40 岁以下的新生代）、ICM 邀请报告（= 未来 4-8 年的风向标）
- **可信度**：Tier S（ICM 官方）
- **预测讨论**：每年都有热议，但 Fields 评委会严格保密，**任何"预测名单"均为 Tier C 猜测，不要当真**

## 二、Abel Prize（阿贝尔奖）——终身成就标杆

### 规则

| 维维 | 规定 |
|------|------|
| **频率** | **每年** |
| **年龄** | 无限制（终身成就）|
| **人数** | 通常 1-2 人 |
| **奖金** | 挪威克朗 750 万（约 $75 万）|
| **历史** | 2003 首届，挪威政府设立 |
| **定位** | "数学界的诺贝尔奖"——弥补 Fields 40 岁年龄限制 |

### 近届得主

| 年份 | 得主 | 代表贡献 | 信息日期 |
|------|------|---------|---------|
| 2025 | **Masaki Kashiwara**（柏原正树）| D-模、晶体基、Riemann-Hilbert 对应 | 2025.03 |
| 2024 | **Michel Talagrand** | 随机过程上确界、concentration 不等式 | 2024.03 |
| 2023 | **Luis Caffarelli** | 非线性 PDE 正则性、自由边界问题 | 2023.03 |
| 2022 | **Dennis Sullivan** | 代数拓扑 / 动力系统的统一 | 2022.03 |
| 2021 | **Lași Lovász** + **Avi Wigderson** | 离散数学 / 理论计算机科学 | 2021.03 |
| 2020 | **Furstenberg** + **Margulis** | 概率方法在数论 / 群论的应用 | 2020.03 |
| 2019 | **Karen Uhlenbeck**（首位女性）| 几何分析、Yang-Mills | 2019.03 |
| 2018 | **Robert Langlands** | Langlands 纲领 | 2018.03 |
| 2017 | **Yves Meyer** | 小波分析 | 2017.03 |
| 2016 | **Sir Andrew Wiles** | Fermat 大定理 | 2016.05 |

**用法**：Abel 得主 = 该领域公认的"活化石级权威"。读他们的综述 = 站在巨人肩上。

## 三、Breakthrough Prize in Mathematics（突破奖）——奖金最高

### 规则

| 维度 | 规定 |
|------|------|
| **频率** | 每年（部分年度空缺）|
| **人数** | 1-5 人 |
| **奖金** | **$3,000,000**（奖金最高）|
| **历史** | 2015 首届（Yuri Milner / Mark Zuckerberg 设立）|
| **定位** | 重奖"重大突破"，偏具体成果而非终身 |

### 历届得主（部分）

| 年份 | 得主 | 获奖 work |
|------|------|----------|
| 2025 | **Sam Payne** + 多位合作者 | 代数几何与组合的桥接 |
| 2024 | 多位 | 代数几何 / 表示论 |
| 2023 | **Daniel Spielman** | 图论、光谱图理论、编码 |
| 2021 | **Takuro Mochizuki**（望月拓郎，非 abc 那位）| D-模、非阿贝尔 Hodge |
| 2020 | **Alex Eskin** | 法测动力系统（与 Mirzakhani 合作）|
| 2019 | **Vincent Lafforgue** | 几何 Langlands（函数域 GL_n）|
| 2018 | **Christopher Hacon** + **James McKernan** | 双有理几何 |
| 2017 | **Jean Bourgain** | 多领域贡献（已故 2018）|
| 2016 | **Ian Agol** | 3-流形拓扑 |
| 2015（首届）| **Simon Donaldson, Maxim Kontsevich, Terence Tao, Richard Taylor, Jacob Lurie** | 五人共享，涵盖几何 / 物理 / 数论 / 范畴 |

**另有 New Horizons in Mathematics Prize**：颁给早期职业数学家（类似"青年 Fields"），关注它可发现"下一代 Fields 候选人"。

## 四、EMS Prize（欧洲数学会奖）

| 维度 | 规定 |
|------|------|
| **频率** | 每 4 年（在欧洲数学大会 ECM）|
| **年龄** | <35 岁 |
| **人数** | ~10 人 |
| **历史** | 1992 首届 |
| **定位** | 欧洲青年数学家风向标——许多人后来获 Fields |

**2024 ECM（西班牙塞维利亚）**得主涵盖代数几何、概率、PDE 等。EMS 得主列表 = "下一届 Fields 候选人池"。

## 五、ICM 邀请报告——4 年一度的"风向标"

- **是什么**：ICM 每 4 年邀请约 200 位数学家做报告（Plenary + Sectional）
- **信号价值**：**被邀请 = 被"圈内核"认可**。许多人几年后获 Fields
- **怎么用**：
  - 看 2022 ICM 报告人列表 → 预判 2026 Fields 候选
  - 看 2026 ICM 报告人列表 → 预判 2030 Fields 候选
- **可信度**：Tier S（ICM 官方）
- **资源**：ICM 官网有全部报告视频 + 论文集

## 六、四大顶刊——"发表在哪里"比"发表了什么"更说明可信度

### 期刊对比

| 期刊 | 出版方 | 创刊 | 发什么 | 投稿周期 | 影响力 |
|------|--------|------|--------|---------|--------|
| **Annals of Mathematics** | Princeton Univ / IAS | 1933 | 全领域顶刊，偏代数几何 / 数论 / 表示论 | 1-3 年（极严）| 公认 #1 |
| **Inventiones Mathematicae** | Springer | 1966 | 全领域，偏几何 / 数论 / 动力系统 | 1-2 年 | #2 |
| **Journal of the AMS (JAMS)** | American Math Society | 1988 | 全领域，偏结构 / 代数 | 1-2 年 | 与 Inventiones 争 #2 |
| **Acta Mathematica** | Mittag-Leffler Institute | 1882 | 全领域，偏分析 / 几何 | 2-3 年（极慢，发表量少）| 历史最悠久之一 |

### 其他高声望期刊（Tier S 边缘）

- **Duke Mathematical Journal**（Duke Univ）
- **Journal für die reine und angewandte Mathematik (Crelle's Journal)**——最古老（1826）
- **Compositio Mathematica**（基金会）
- **Geometry & Topology**（几何拓扑首选）
- **Publications mathématiques de l'IHÉS**——发表量极少，声望极高

### 怎么用期刊信息

1. **判断论文可信度**：发表在 Annals / Inventiones / JAMS / Acta 的 = Tier S，可信
2. **找权威**：翻近 5 年四大刊的作者列表 = 当下最活跃的权威
3. **追踪方向**：四大刊近 2 年高频出现的主题 = 当下最热方向

## 七、怎么追踪（实操）

### 信息源金字塔

```
Tier S（必看）
├── 各奖项官网：Fields（IMU）/ Abel（abelprize.no）/ Breakthrough（breakthroughprize.org）
├── Annals / Inventiones / JAMS / Acta 官网"最新发表"

Tier A（高价值）
├── Quanta Magazine：每次大奖颁发后必有深度报道 + 采访
├── Tao 博客：常评论大奖得主的工作

├── MathOverflow 高赞讨论
└── 机器之心 / 数学文化类公众号（中文，但需回溯 Tier S）
```

## 八、奖项-期刊-人物的三角关系

理解这个三角，就能快速判断"谁是真权威"：

```
        人物（具体研究者）
          ↗          ↘
   获奖（背书）    ←    顶刊发表（背书）
```

- **Fields + Annals** = 最强组合（如 Scholze：Fields 2018 + 多篇 Inventiones/Annals）
- **只有 arXiv 预印本，无顶刊无奖项** = 🟠 需观望，不要轻信"突破"声称
- **Abel + Acta** = 终极权威（如 Langlands）
