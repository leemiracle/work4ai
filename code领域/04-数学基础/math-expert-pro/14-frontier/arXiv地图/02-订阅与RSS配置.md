# arXiv 订阅与 RSS 配置指南

> 每天如何高效过滤 arXiv 的 200+ 篇新论文。

---

## 一、订阅方式

### 方式1：RSS（最快）
每个 arXiv 分类有 RSS feed：
```
https://arxiv.org/rss/math.NT  （数论）
https://arxiv.org/rss/math.AG  （代数几何）
https://arxiv.org/rss/math.CO  （组合）
```
用 RSS 阅读器（Feedly/Inoreader）订阅。

### 方式2：arXiv API
```
https://arxiv.org/a/作者名_1.html  （按作者订阅）
```

### 方式3：Google Scholar Alerts
搜索关键词 → "Create Alert" → 每天邮件推送。

### 方式4：AK @_akhaliq
每天在 Twitter/Bluesky 推送 arXiv 热门论文（AI/ML 向）。

## 二、每日/每周/每月节奏

| 频率 | 动作 | 时长 |
|------|------|------|
| 每天 | 扫标题（RSS）| 10 min |
| 每周 | 精读 1 篇摘要 | 30 min |
| 每月 | 精读 1 篇完整论文 | 2 h |
| 每季度 | 读 1 篇 survey/综述 | 3 h |

## 三、高效阅读论文的 3-pass 法
1. **第一遍**（5 min）：标题/摘要/结论 → 决定是否继续
2. **第二遍**（30 min）：图表/关键定理/方法 → 理解核心贡献
3. **第三遍**（2h+）：逐行推导/验证/找gap → 深度理解

## 四、推荐订阅分类（按你的方向）

### 数论方向
math.NT + math.NT（解析数论/代数数论）

### AI/ML 方向
cs.LG + stat.ML + math.OC + math.PR

### 形式化方向
cs.LO + math.LO + math.CT

### 组合/图论方向
math.CO + cs.DM
