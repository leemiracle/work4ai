## 📖 核心内容

### Ch.2 拓扑空间 + 连续
- **开集公理**（∅/X 开 + 任意并 + 有限交）
- 连续：$f^{-1}(U)$ 开 → $f$ 连续
- 同胚：双射 + 连续 + 逆连续

### Ch.3 连通 + 紧致 ⭐⭐⭐⭐⭐
- **连通**：不能分成两个非空开集
- **紧致**：每个开覆盖有有限子覆盖
- **Heine-Borel**：Rⁿ 中紧致 ⟺ 闭 + 有界

### Ch.4 可数 + 分离公理
- $T_0, T_1, T_2$(Hausdorff), $T_3, T_4$
- **Hausdorff 最重要**：极限唯一

### Ch.5 Tychonoff 定理 ⭐⭐⭐
**紧致空间的任意积紧致**（等价选择公理）

### Ch.7-9 度量空间 + 完备化 + 函数空间
- Baire 纲定理
- 一致收敛
- Ascoli 定理

### Ch.11-13 基本群 + Seifert-van Kampen
- $\pi_1(S^1) = \mathbb{Z}$
- **Brouwer 不动点**（2D 版用 $\pi_1$）

## 🎯 6 视角

### V01 反例 ⭐⭐⭐⭐⭐
- **正则不正规** / **完全正规不正则**（现代基础 066 圣经）
- **非 Hausdorff 空间**（极限不唯一）
- **非紧致的闭有界集**（无穷维）

### V04 最小例
| 概念 | 最小例 |
|------|------|
| 拓扑 | $\{\emptyset, \{a\}, \{a,b\}\}$（Sierpinski）|
| 连通 | 区间 $(0,1)$ |
| 紧致 | $[0,1]$ |
| Hausdorff | Rⁿ |

### V18 不可能性 ⭐⭐⭐⭐⭐
- **Brouwer 不动点**：闭球到自身连续映射必有不动点
- **维数不变性**：Rⁿ ≄ Rᵐ (n≠m)
- **毛球定理**：S² 上无处处非零切向量场

### V26 失败
**非 Hausdorff 空间的极限不唯一**——物理建模陷阱。

"绕圆的圈数"——代数 + 拓扑的完美结合。
