## 📖 Ch.3 章节（精读 15 min）

### 3.A 线性映射定义
$T: V \to W$ 线性 ⟺ $T(av + bw) = aT(v) + bT(w)$

**例**：旋转、缩放、投影、神经网络线性层。

### 3.B 核 + 像 + 秩-零度定理 ⭐⭐⭐
- $\text{null}(T) = \{v : T(v) = 0\}$
- $\text{range}(T) = \{T(v) : v \in V\}$
- **秩-零度定理**：$\dim V = \dim \text{null}(T) + \dim \text{range}(T)$

### 3.C 矩阵表示
- 选定基后，线性映射 ↔ 矩阵
- 不同基 → 不同矩阵，但**映射本身不变**

## 🎯 6 视角应用

### V01 反例 ⭐⭐⭐⭐
**T(v) = v² 不是线性映射**：
- $T(v_1 + v_2) = (v_1+v_2)^2 \neq v_1^2 + v_2^2 = T(v_1) + T(v_2)$
- Python 验证：T([1,2]+[3,4]) = [16, 36] ≠ T([1,2])+T([3,4]) = [10, 20]

### V04 最小例
| 映射 | null | range | dim V |
|------|------|-------|------|
| $T(x)=2x$ | {0} | R¹ | 1=0+1 |
| R³→R² 投影 | z 轴 | R² | 3=1+2 |

### V14 ML 锚点 ⭐⭐⭐⭐⭐
| 概念 | ML |
|------|----|
| 线性映射 | **全连接层** $y=Wx+b$ |
| 矩阵表示 | 权重矩阵 |

## 💡 "啊哈"时刻

### 啊哈 1：秩-零度定理的"守恒"
$\dim V = \dim \text{null}(T) + \dim \text{range}(T)$

**类比**：能量守恒——"信息要么保留在像中，要么丢失在核中"。

### 啊哈 2：神经网络本质 = 交替线性映射 + 非线性激活
$y = \sigma(Wx + b)$
- $Wx$ = 线性映射
- $\sigma$ = 非线性（ReLU/sigmoid）
- 没有 $\sigma$ → 多层等价单层（线性坍塌）

### 啊哈 3：换基 = 同一映射的不同矩阵
旋转 90° 在标准基下 $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$，在 {(1,1),(1,-1)} 基下变成 $\begin{pmatrix}0&1\\-1&0\end{pmatrix}$。

**意义**：**映射是本质，矩阵是表示**——这是 LADR 的核心美学。
