## 📖 Ch.2 章节（精读 15 min）

### 2.A 张成 + 线性无关
- $\text{span}(v_1, \ldots, v_m) = \{a_1 v_1 + \ldots + a_m v_m\}$
- 线性无关：$\sum a_i v_i = 0 \Rightarrow$ 所有 $a_i = 0$

### 2.B 基 + 维数
- **基** = 线性无关 + 张成 V
- **维数** $\dim V$ = 基的元素数（不变量！）

### 维数定理 ⭐⭐⭐
$$\dim(U + W) = \dim U + \dim W - \dim(U \cap W)$$

## 🐍 Python 完整验证

```python
import numpy as np
from numpy.linalg import matrix_rank, det, svd

# 线性无关：det ≠ 0
v1, v2, v3 = np.array([1,0,1]), np.array([0,1,1]), np.array([1,1,0])
A = np.column_stack([v1, v2, v3])
print(f"det = {det(A):.4f}")  # -2 → 无关

# 反例：相关
v1, v2 = np.array([1,2,3]), np.array([2,4,6])
print(f"rank = {matrix_rank(np.column_stack([v1,v2]))}")  # 1 < 2

# PCA = 找最优低维基
data = np.random.multivariate_normal(np.zeros(10), np.eye(10), 1000)
U, S, Vt = svd(data - data.mean(axis=0))
print(f"前 5 奇异值: {S[:5].round(2)}")

# 图像压缩 = 换基 + 截断
img = np.random.randn(32, 32)
U, S, Vt = svd(img)
for k in [5, 10, 20]:
    approx = U[:,:k] @ np.diag(S[:k]) @ Vt[:k]
    error = np.linalg.norm(img - approx) / np.linalg.norm(img)
    print(f"k={k}: error={error:.4f}")
```

## 💡 "啊哈"时刻

### 啊哈 1：基不是唯一的，但维数是
$\mathbb{R}^2$ 有无穷多组基（{(1,0),(0,1)}, {(1,1),(1,-1)}, ...），但**维数总是 2**。

**意义**：维数是**拓扑不变量**——所有基都同意。

### 啊哈 2：维数定理是"集合容斥"的化身
$\dim(U+W) = \dim U + \dim W - \dim(U \cap W)$

**类比**：$|A \cup B| = |A| + |B| - |A \cap B|$（集合容斥）

→ **维数定理 = 子空间的"容斥"**

### 啊哈 3：PCA = 找"信息密集"的基
标准基各向同性，PCA 找的基让前几维承载大部分方差。

→ **这就是降维的本质**——不是"删除维度"，而是"换更好的坐标系"。

### 啊哈 4：JPEG = 换基（DCT）
图像 32×32 像素 = 标准基的 1024 个系数。
JPEG 换到 DCT 基 → 大部分系数接近 0 → 截断 → 压缩。

→ **Ch.2 的"换基"概念 = 所有信号压缩的根基**。
