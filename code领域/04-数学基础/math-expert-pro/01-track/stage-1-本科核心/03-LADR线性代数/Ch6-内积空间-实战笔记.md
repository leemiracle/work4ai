## 📖 Ch.6 章节（精读 15 min）

### 6.A 内积 + 范数
- 内积：$⟨u, v⟩$（线性 / 共轭对称 / 正定）
- 范数：$||v|| = \sqrt{⟨v, v⟩}$
- **Cauchy-Schwarz**：$|⟨u,v⟩| \leq ||u|| \cdot ||v||$
- **三角不等式**：$||u+v|| \leq ||u|| + ||v||$

### 6.B 标准正交基 + Gram-Schmidt
- 标准正交：$⟨e_i, e_j⟩ = \delta_{ij}$
- **Gram-Schmidt**：线性无关向量 → 正交基

### 6.C 正交补 + 正交投影 ⭐⭐⭐
- $U^\perp = \{v : ⟨v, u⟩ = 0\}$
- **正交投影** $P_U(v) \in U$，$v - P_U(v) \in U^\perp$
- **最佳逼近**：$||v - P_U(v)|| \leq ||v - u||$ for all $u \in U$

### 6.D 极小化向量（最小二乘根基）
$V = U \oplus U^\perp$ → $v = P_U(v) + (v - P_U(v))$

## 🐍 Python 关键验证

```python
import numpy as np
from numpy.linalg import norm, qr, lstsq

# Gram-Schmidt 手动
v1, v2, v3 = np.array([1,1,0.]), np.array([1,0,1.]), np.array([0,1,1.])
e1 = v1 / norm(v1)
e2 = (v2 - (v2@e1)*e1); e2 /= norm(e2)
e3 = (v3 - (v3@e1)*e1 - (v3@e2)*e2); e3 /= norm(e3)
print(f"e1={e1.round(4)}, e2={e2.round(4)}, e3={e3.round(4)}")

# 最小二乘 = 正交投影
x = np.array([1,2,3,4,5.]); y = 2*x + 1 + np.random.normal(0,0.5,5)
X = np.column_stack([x, np.ones(5)])
beta = lstsq(X, y, rcond=None)[0]
print(f"最小二乘: y = {beta[0]:.4f}x + {beta[1]:.4f}")
```
