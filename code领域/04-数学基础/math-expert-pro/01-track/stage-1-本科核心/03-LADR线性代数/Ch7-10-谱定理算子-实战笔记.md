# 📖 Ch.7 谱定理（LADR 高潮）⭐⭐⭐⭐⭐

### 7.A 自伴算子（实矩阵 = 对称）
$T = T^*$（实矩阵：$A = A^T$）

**关键性质**：
- 特征值都是实数
- **不同特征值的特征向量正交**

### 7.A 谱定理（实版）⭐⭐⭐
**对称矩阵 → 正交对角化**

$$A = Q \Lambda Q^T$$

其中 $Q$ 正交（$Q^T Q = I$），$\Lambda$ 对角。

**Python 验证**：
```python
A = [[4,2],[2,3]]  # 对称
特征值: [5.56, 1.44]（实数）
特征向量矩阵 Q: Q^T Q = I（正交）
Q Λ Q^T = A ✓
```

### 7.B 正算子（半正定）
$T \geq 0$ ⟺ 自伴 + 特征值非负

### 7.C 等距同构（正交矩阵）
$T^* T = I$（保持长度）

**例**：旋转矩阵 $|det| = 1$（保持体积）

# 📖 Ch.8 复向量空间算子

### 8.A 广义特征向量
$(T - \lambda I)^k v = 0$

**例**：Jordan 块 $[[3,1],[0,3]]$
- $(A - 3I)^2 = 0$ → 所有向量都是广义特征向量

### 8.B Jordan 标准型 ⭐⭐⭐
**复数域上每个矩阵都相似于 Jordan 标准型**（对角 + 上三角 1）

```python
Jordan 块 [[3,1,0],[0,3,1],[0,0,3]] 已是标准型
```

**实矩阵的复特征值成共轭对**。

**例**：旋转 90° 矩阵特征值 = $\pm i$

# 📖 Ch.10 迹 + 行列式 ⭐⭐⭐

### 迹 = 特征值之和
$\text{tr}(A) = \sum \lambda_i$

### 行列式 = 特征值之积
$\det(A) = \prod \lambda_i$

### 几何意义
**行列式 = 体积变化倍数**

```python
A = [[2,0],[0,3]]（拉伸）
det(A) = 6（面积变 6 倍）
```

### Cayley-Hamilton 定理
**A 满足自己的特征方程**

```python
A = [[1,2],[3,4]]
tr(A) = 5, det(A) = -2
特征方程: λ² - 5λ - 2 = 0
验证: A² - 5A - 2I = 0 ✓
```
