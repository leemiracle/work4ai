## 📖 Ch.1 章节（精读 15 min）

### 1.A $\mathbb{R}^n$ 与 $\mathbb{C}^n$
- $\mathbb{R}^n$ = n 维实向量
- 加法（分量加）+ 标量乘法（分量乘）

### 1.B 向量空间定义（10 公理）
1. 加法交换 $v+w = w+v$
2. 加法结合 $(u+v)+w = u+(v+w)$
3. 加法单位 $0+v = v$
4. 加法逆 $v + (-v) = 0$
5. 乘法单位 $1v = v$
6. 乘法结合 $a(bv) = (ab)v$
7. 标量分配 $a(v+w) = av+aw$
8. 加法分配 $(a+b)v = av+bv$

### 1.C 子空间
$W \subseteq V$ 是子空间 ⟺
- $0 \in W$
- 加法封闭
- 标量封闭

### 1.D 子空间的和 + 直和
$U + W = \{u+w\}$；直和 $U \oplus W$ = 唯一表示

## 🐍 Python 完整验证

```python
import numpy as np
from numpy.linalg import svd

# 10 公理验证
v, w, u = np.array([1,2]), np.array([3,4]), np.array([5,6])
zero = np.zeros(2)
print(f"v+w == w+v: {(v+w == w+v).all()}")  # True
print(f"0+v == v: {(zero+v == v).all()}")  # True

# 子空间：过原点直线
xs = np.array([1, 2, -1, 3])
W = np.column_stack([xs, 2*xs])  # (x, 2x)
print(f"W[0]+W[1] = {W[0]+W[1]}（仍在 W）")

# PCA = 找最佳低维子空间
data = np.random.multivariate_normal([0,0], [[2,1],[1,1]], 1000)
X = data - data.mean(axis=0)
U, S, Vt = svd(X, full_matrices=False)
print(f"PC1: {Vt[0]}, 奇异值: {S}")
```

## 💡 "啊哈"时刻

### 啊哈 1：向量空间是"代数结构"，不只是箭头
$\mathbb{R}^n$ 是向量空间，但**函数也是**：$f + g$ 和 $af$ 满足 8 公理。

**意义**：向量空间 = 任何满足公理的代数结构（多项式、函数、矩阵）。

### 啊哈 2：R² 子空间只有 3 类
$\{0\}$ / 过原点直线 / R²。

**意义**：分类**完整**——这是数学的美感。

### 啊哈 3：PCA = 找最佳子空间
数据协方差矩阵的特征向量张成的子空间，保留最大变异。

**意义**：Ch.1 的"子空间"概念在 ML 中化身 PCA——理论→应用的桥梁。
