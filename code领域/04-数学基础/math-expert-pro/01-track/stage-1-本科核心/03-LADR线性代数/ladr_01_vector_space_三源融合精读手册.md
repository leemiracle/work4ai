### 习题分级
- 🟢 **必做**:证 $\mathbb{R}^n$ 的维度是 $n$;维度定理(dim V = dim null T + dim range T);线性映射的矩阵表示
- 🟡 **选做**:多项式向量空间的基;线性映射空间的维度
- 🔴 **挑战**:Axler "Linear Algebra Done Right" 的反传统——**先线性映射后行列式**,理解为何

### 证明骨架:维度定理
```
证 dim V = dim null T + dim range T:
  [思路] null T 是 V 的子空间,取 null 的基 u₁...uₘ,扩充成 V 的基 u₁...uₘ,v₁...vₙ
  [关键] 证 T(v₁)...T(vₙ) 是 range T 的基(线性无关 + 张成)
  [结论] dim V = m+n = dim null + dim range
  → 这是"信息守恒":输入维度 = 被压扁的部分(null)+ 保留下来的部分(range)
```

## §3 飞腾 D3000M 实测锚点 ⭐

### 锚点一:向量空间 ↔ NEON SIMD 寄存器
> **飞腾 NEON 128-bit 寄存器 = 一个硬件"4 维 FP32 向量空间"。**

飞腾 `[实测 Lab01/Lab05]`:V0-V31 共 32 个 128-bit 寄存器,每个可装 4 个 FP32(或 2 个 FP64,或 8 个 INT16)。一次 `fadd` 指令对整个向量并行运算——**这就是"向量空间"的硬件具象**:维度=4(FP32),运算=并行。

| NEON 类型 | 维度(元素数)| 飞腾实测 |
|-----------|-------------|---------|
| `.4s`(4×FP32)| 4 | GEMM 主力 |
| `.2d`(2×FP64)| 2 | 高精度 |
| `.8h`(8×FP16)| 8 | 3.81× 快 |

### 锚点二:线性映射 ↔ GEMM
线性映射 $T:\mathbb{R}^n\to\mathbb{R}^m$ 的矩阵表示 = GEMM。飞腾 `[实测 Lab05]`:NEON FP32 GEMM **9.45 GFLOPS**。`[实测 View_03]`:matmul 优化 **15×**——每一步优化(分块/向量化/重排)都是对"线性映射"计算的工程精炼。

### 锚点三:基/维度 ↔ 编译器向量化
> **编译器判断"这段循环能否向量化"= 判断数据是否构成可被 NEON 并行处理的"基"。**

飞腾 `Expert_11_Compiler`:PhyGCC 的 `-O3` 自动把标量循环提升为 NEON 向量运算——`[实测 View_01]` 可见 `-O0` 到 `-Ofast` 的性能跃升。这是"选择好基=高效计算"的工程体现。

### 一句话
> **Axler 给你向量空间的公理化抽象(8 条公理);飞腾 NEON 寄存器是这套公理的硬件实例(128-bit=4维FP32),GEMM 是线性映射的工程化身。公理是上界,寄存器是下界实现。**
