### V01 反例 ⭐⭐⭐⭐⭐
**Abel-Ruffini 定理**（5 次方程无根式解）：
- 代数基本定理保证根**存在**
- 但 ≥5 次一般多项式**不能用根式表示**
- 这是 V18 不可能性的经典

**Python 验证**：
```python
# x^5 - x - 1 = 0
# 不能用 + - × ÷ ⁿ√ 表示
# 只能数值解（Newton 迭代）
real_root = newton(lambda x: x**5-x-1, 1.0)  # 1.167304
```

## 💡 "啊哈"时刻

### 啊哈 1：复数乘法 = 旋转
$(1+i) \times i = -1+i$（45° + 90° = 135°）

**意义**：复数是 2D 几何的代数语言。

### 啊哈 2：代数基本定理
每个 $n$ 次多项式有 $n$ 个复根——**复数域代数封闭**。

**意义**：这是为什么数学家"发明"复数——为了让所有方程可解。

### 啊哈 3：5 次方程无根式解
根存在但不能用根式表示——**存在性 ≠ 可构造性**。

**意义**：**Galois 理论揭示数学的内在边界**——某些事永远做不到。
