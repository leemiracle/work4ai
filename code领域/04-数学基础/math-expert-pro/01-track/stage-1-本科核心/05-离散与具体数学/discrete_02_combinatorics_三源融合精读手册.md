### 证明骨架:Fibonacci 通项(特征根法)
```
解 F_n = F_{n-1} + F_{n-2}, F_0=0, F_1=1:
  [特征方程] r² = r + 1 → r = (1±√5)/2 = φ, ψ
  [通解] F_n = A·φ^n + B·ψ^n
  [定系数] 用 F_0=0, F_1=1 解 A,B
  [结果] F_n = (φ^n - ψ^n)/√5  (Binet 公式)
  [洞察] 整数序列由无理数 φ 表达——递推→特征根→线代(LADR)的桥梁
```

## §3 飞腾 D3000M 实测锚点 ⭐
> **组合优化 = 性能调优的数学骨架。GEMM 分块 = 组合策略。**

### 锚点一:GEMM tiling ↔ 组合优化
飞腾 `[实测 Lab05 + View_03]`:GEMM 的 5 步优化(朴素→分块→向量化→重排→汇编)= 一个组合搜索问题。"选多大的 tile"= 组合优化。`[实测]` matmul 0→最优 **15× 加速**——每一步都是组合策略的胜利。

### 锚点二:递推 ↔ 流水线 stall
CPU 流水线的停顿是递推的:$T_n = T_{n-1} + \text{stall}_n$。飞腾 `[实测 Lab02]` data_hazards:数据冒险导致的 stall 链就是递推关系。分支预测失误 = 递推断裂(清空重填)。

### 锚点三:生日悖论 ↔ 哈希碰撞
生日悖论 $\sqrt N$ 阈值直接用于哈希表/密码学碰撞分析。飞腾 `View_02_Security`:cache 时序攻击的碰撞概率分析用到生日界。

### 锚点四:生成函数 ↔ 性能建模
`Expert_09_Performance_Model` 的 CPI 栈分解,本质是"性能指标的生成函数"——把各 stall 源的贡献叠加成总 CPI。
