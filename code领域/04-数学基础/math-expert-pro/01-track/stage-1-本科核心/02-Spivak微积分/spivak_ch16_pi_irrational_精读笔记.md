## §2 Niven 证明结构(原书 PP.324-329)

### 证明策略:反证 + 构造积分 + 矛盾
假设 $\pi=a/b$($a,b\in\mathbb{N}$)。构造一个精心设计的多项式 $f$,研究 $I_n=\int_0^\pi f(x)\sin x\,dx$。

### 关键函数(原书 P.324-325)
$$f(x)=\frac{x^n(a-bx)^n}{n!}$$
性质:
1. $f$ 在 $[0,\pi]$ 非负,且 $f(0)=f(\pi)=0$
2. $f$ 及其低阶导数在端点 0,π 都为 0
3. $f^{(k)}(0),f^{(k)}(\pi)$ 对所有 $k$ 都是**整数**(因为 $x^n(a-bx)^n$ 展开后系数含 $b$ 的幂)

### 积分 $I_n$ 的两个性质(原书 P.326-328)
反复分部积分(用 $f$ 在端点为 0):
$$I_n=\int_0^\pi f(x)\sin x\,dx = f^{(2)}(0)+f^{(2)}(2)+\cdots = \text{整数}$$
（因为每次分部积分把 $\sin/\cos$ 互换,端点项都是 $f^{(k)}(0),f^{(k)}(\pi)$ 的整数组合）

但另一方面,当 $n\to\infty$:
$$0 < I_n = \int_0^\pi f(x)\sin x\,dx \le \frac{\pi}{n!}\cdot\text{小量} \to 0$$
（$f(x)\le \pi^n\cdot\text{有界}/n!$,当 $n$ 大时 $I_n$ 任意小)

### 矛盾(原书 P.329)
$I_n$ 既是**正整数**又是**小于 1 的正数**——矛盾!∴ $\pi$ 无理 ∎

## §3 证明的美学与训练
1. **构造性魔法**:$f(x)=x^n(a-bx)^n/n!$ 的选取"无动机"(Spivak 明说 motivation 无法供应),但它同时满足"端点为 0""导数为整数""趋于 0"三个性质——这是数学构造的极致。
2. **分部积分的威力**:把 $\int f\sin$ 反复分部,把"积分"变成"端点导数求和"——这是第 14 章 FTC 工具的高级应用。
3. **"整数 vs (0,1)"矛盾**:经典数论反证法(也见于 $e$ 无理、$e$ 超越的证明)。

## §4 飞腾/Python 锚点
| 概念 | 工程 |
|------|------|
| π 无理 | `math.pi` 只是近似(浮点永远逼近,Expert_08)|
| Niven 积分 $I_n$ | 可数值验证(对大 $n$,$I_n\to0$)|
| 分部积分 | 符号积分的核心算法(SymPy)|

### 代码验证思路
```python
# 验证 I_n 趋于 0(数值版)
import numpy as np
from scipy import integrate
a, b = 22, 7  # π≈22/7 的近似(实际 π 无理,这里模拟)
for n in [1,5,10,20]:
    f = lambda x: x**n*(a-b*x)**n/np.math.factorial(n)
    I,_ = integrate.quad(lambda x: f(x)*np.sin(x), 0, np.pi)
    print(f"n={n}: I_n={I:.3e}")  # 应趋于 0
```
