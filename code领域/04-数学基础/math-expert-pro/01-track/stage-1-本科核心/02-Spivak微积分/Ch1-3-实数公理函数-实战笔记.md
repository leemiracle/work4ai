## 🐍 Python 关键验证

```python
from fractions import Fraction as Q
from sympy import sqrt, Rational

# P1 加法结合
a, b, c = Rational(1,2), Rational(2,3), Rational(3,4)
assert (a+b)+c == a+(b+c)

# P13 完备性：√2 不在 Q
print(sqrt(2))  # 无理数

# 浮点不满足 P1
print(0.1 + 0.2)  # 0.30000000000000004

# Bernoulli 不等式
for n in [2, 5, 10]:
    x = 0.1
    assert (1+x)**n >= 1 + n*x
```
