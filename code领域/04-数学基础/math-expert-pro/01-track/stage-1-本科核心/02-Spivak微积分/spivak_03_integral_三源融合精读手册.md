### 习题分级
- 🟢 **必做**:用黎曼和定义算 $\int_0^1 x^2\,dx$;亲笔证 FTC;$\int e^{-x^2}$ 为何"积不出来"
- 🟡 **选做**:Simpson 误差阶推导;蒙特卡洛估 $\pi$
- 🔴 **挑战**:FTC 的严格证明(用上/下 Darboux 和);$e^{-x^2}$ 无初等原函数的证明(Liouville)

### 证明骨架:微积分基本定理
```
证 若 F'(x)=f(x),则 ∫_a^b f(x)dx = F(b)-F(a):
  [思路] 把 [a,b] 分 n 份,F(b)-F(a) = Σ[F(x_i)-F(x_{i-1})]
  [关键] 对每段用中值定理:F(x_i)-F(x_{i-1}) = f(c_i)·Δx
  [极限] Σ f(c_i)Δx → ∫ f  (c_i 是黎曼和的采样点)
  → 这是"变化率的累积 = 净变化",导数与积分互逆的精髓
```

## §3 飞腾 D3000M 实测锚点 ⭐

### 锚点一:黎曼和 ↔ GEMM 大量累加
> **矩阵乘法 GEMM = 海量的"乘-加"累加,本质是黎曼和的工程化身。**

飞腾 `[实测 Lab05]`:NEON FP32 GEMM 达 **9.45 GFLOPS**(23.6% peak),核心指令 `fmla`(fused multiply-accumulate)就是"乘了立即加"。数学上 $\sum f(x_i)\Delta x$ 的累加,在硬件上有专用流水线。`[实测 View_03]`:matmul 优化 0→最优 **15× 加速**——这就是"黎曼和收敛"的工程对应(分块/向量化让累加更快)。

### 锚点二:数值积分收敛阶 ↔ 算法性能建模
Simpson 误差 $O(1/n^4)$ vs 梯形 $O(1/n^2)$——飞腾 `[实测 Expert_09 Roofline]` 的"算力屋顶"模型正是量化这类"收敛阶→性能"的工具。收敛阶高 = 同样算力下精度更高。

### 锚点三:蒙特卡洛 ↔ 高维积分的硬件现实
$e^{-x^2}$ 一维还能用 Simpson;但贝叶斯推断的高维积分只能蒙特卡洛。飞腾 `[实测 Expert_05]`:INT8 UDOT **16.9× 加速**让大规模采样推理可行——蒙特卡洛的工程价值直接依赖硬件吞吐。

### 锚点四:FTC ↔ 自动微分
FTC 说导数与积分互逆。反向传播(自动微分)是 FTC 的离散/算法化身——链式法则反向求梯度。math-expert W4 的反向传播,严格根基就在这里。

### 一句话
> **Spivak 给你积分的理想定义(黎曼和极限);飞腾告诉你真实硬件上积分=海量乘加(GEMM/fmla)、收敛阶有可测的性能屋顶(Roofline)、高维积分靠蒙特卡洛吃硬件吞吐。**
