## §0 一句话

> **Spivak 把 π 从"圆周率"变成"半圆面积 = 2∫√(1-x²)",把 sin/cos 从"几何比"变成"积分定义的反函数"。三角函数彻底分析化——这是 FTC 红利的最华丽展示。**

## §1 π 与 sin/cos 的积分定义(原书 PP.305-307)

### π 的定义(原书 P.305)
$$\pi = 2\int_0^1 \sqrt{1-x^2}\,dx$$
> π = 单位圆面积 = 2 × 半圆面积。**π 不再是"周长/直径",而是积分值**。

### 扇形面积 A(x)(原书 P.305-306)
对 $-1\le x\le 1$,定义从 $(1,0)$ 到 $(x,\sqrt{1-x^2})$ 的扇形面积:
$$A(x)=\frac{x\sqrt{1-x^2}}{2}+\int_x^1\sqrt{1-t^2}\,dt$$
用 FTC 求导:
$$A'(x)=\frac{1}{2}\left[\sqrt{1-x^2}+x\cdot\frac{-x}{\sqrt{1-x^2}}\right]-\sqrt{1-x^2}=\frac{-1}{2\sqrt{1-x^2}}$$

### cos/sin 的定义(原书 P.306)⭐
对 $0\le x\le\pi$:
- $\cos x$ = 满足 $A(\cos x)=x/2$ 的唯一数(用 **IVT** 保证存在 + 严格单调保证唯一)
- $\sin x=\sqrt{1-(\cos x)^2}$

> 🔑 **关键**:cos 的"存在性"用了**介值定理 IVT**(第7章⟸第8章 LUB)!没有完备性,连 cos 都定义不出。又一次 LUB 的隐秘登场。

## §2 定理 1:导数(原书 P.307)

### 定理
$$\cos'(x)=-\sin x,\quad \sin'(x)=\cos x$$

### 证明(用反函数求导 + FTC)
令 $B=2A$,则 $\cos=B^{-1}$(由定义 $B(\cos x)=x$)。
$B'(x)=2A'(x)=\frac{-1}{\sqrt{1-x^2}}$。由第12章反函数求导:
$$\cos'(x)=(B^{-1})'(x)=\frac{1}{B'(B^{-1}(x))}=\frac{1}{-1/\sqrt{1-\cos^2 x}}=-\sin x\;\checkmark$$
$\sin'(x)$ 类似(对 $\sin=\sqrt{1-\cos^2}$ 用链式法则)。∎

> 🎯 **这是 FTC + 反函数 + IVT 的三重合奏**:积分定义 → FTC 求导 → 反函数求导 → 得 sin/cos 的导数。全部严格,零几何直觉。

## §3 延拓与周期性(原书 PP.307-309)

- $[0,\pi]$ 上定义后,用对称性延拓到 $[0,2\pi]$:$\sin x=-\sin(2\pi-x)$
- 再用周期延拓到全 $\mathbb{R}$:$\sin(x+2\pi)=\sin x$
- 验证 $\sin^2+\cos^2=1$(由定义显然)、导数公式在全 $\mathbb{R}$ 成立(用 Theorem 11-7 处理端点)

## §5 批判:为什么 Spivak 这么定义?
1. **避免几何依赖**:几何直觉易错(第4章 Spivak 警告"证明不靠图")。积分定义纯分析,可严格推导一切。
2. **π 的本体**:π 不再是"测量出来的常数",而是"一个具体积分的值"——可严格证明其性质(第16章证 π 无理)。
3. **与微积分统一**:sin/cos 成了"FTC 的产物",与对数(第18章,=积分)、指数(=对数反函数)同一套语言。
