### 证明骨架:链式法则
```
证 (f(g(x)))' = f'(g(x))·g'(x):
  [关键陷阱] 不能直接写 Δf/Δx = (Δf/Δg)·(Δg/Δx),因 Δg 可能为 0
  [正确] 定义 g(x+h)-g(x) = k(h),用 f'(g(x)) 的 ε-δ 定义处理 k=0 情形
  → Spivak 的处理是这个陷阱的标准教学
```

## §3 飞腾 D3000M 实测锚点 ⭐

### 锚点一:数值微分的 $h$ 陷阱 ↔ 浮点误差
Spivak 说"$h$ 越小越准"。飞腾 `[实测 Expert_08]` 说:**$h < 10^{-8}$ 时浮点舍入误差反超**,最优 $h \approx 10^{-5}$。
- 数学:导数 = 极限($h\to0$)
- 硬件:$h$ 不能真趋近 0(浮点),存在最优 $h$ = 截断误差与舍入误差的平衡点
- 🔍 **思考**:为什么 $h=10^{-15}$ 的数值导数反而差?($f(a+h)-f(a)$ 两个相近数相减 → catastrophic cancellation,`Expert_08`)

### 锚点二:泰勒展开 ↔ CPU 怎么算 $\sin$
> **CPU 只会 $+-\times\div$。它算 $\sin x$ 就是用截断泰勒级数。**

飞腾 NEON `[实测 Lab05]` 有专门的 `fmla`(fused multiply-accumulate)指令加速多项式求值——泰勒展开的每一项都是"乘加",硬件为此专门优化。一条泰勒定理,撑起整个科学计算库(numpy/SciPy/glibc)。

### 锚点三:牛顿法二次收敛 ↔ 迭代算法性能
牛顿法求 √2,5 步达 $10^{-12}$ 精度(误差→误差²)。这与飞腾 `[实测 Lab04]` 寄存器重命名"n≥10 saturate IPC=4.00"的收敛拐点是同类现象——**迭代算法的收敛阶决定工程价值**。

### 一句话
> **Spivak 给你导数的理想定义(极限);飞腾告诉你真实硬件上导数有"最优步长 $h$"、泰勒有专用指令(`fmla`)、收敛有可测拐点。数学是导数的上界理论,工程是导数的有限实现。**
