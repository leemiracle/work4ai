## 📖 核心内容

### Ch.5 极限 ε-δ ⭐⭐⭐
$\forall \epsilon > 0, \exists \delta > 0, 0 < |x-a| < \delta \Rightarrow |f(x) - L| < \epsilon$

**经典极限**：
- $\lim_{x \to 0} \frac{\sin x}{x} = 1$
- $\lim_{x \to \infty} (1+1/x)^x = e$

### Ch.6 连续
$f$ 在 $a$ 连续 ⟺ $\lim_{x \to a} f(x) = f(a)$

### Ch.7 三个硬定理 ⭐⭐⭐⭐⭐
1. **IVT**（介值）：$f$ 连续, $f(a) < 0 < f(b) \Rightarrow \exists c, f(c) = 0$
2. **EVT**（极值）：$f$ 在 $[a,b]$ 连续 $\Rightarrow$ 有最大最小值
3. **一致连续**

**Python 验证**：$x^5 - 5x + 1$ 在 $[-2,0]$ → 根 $-1.541652$ ✓

### Ch.8-10 导数 + 应用
- $f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}$
- 链式法则 / 乘积法则 / 商法则
- 极值 / 凹凸 / 二阶导
