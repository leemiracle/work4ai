## §1 数学归纳法：数学里的「for 循环」

### 1.1 三段式（必须背下来）

```
基础: P(1) 成立
归纳: ∀n,  P(n) ⟹ P(n+1)
结论: ∀n, P(n) 成立
```

**直觉**：多米诺骨牌——推倒第 1 块（基础）+ 每块倒下推倒下一块（归纳）⇒ 全部倒下（结论）。

**程序员视角** ⭐：这就是**递归**！基础 = base case，归纳 = 递推关系。`factorial(n) = n * factorial(n-1)` 背后就是归纳结构。你写过的所有递归，本质都是数学归纳法。

### 1.2 经典例子：前 n 个奇数和 = n²

$$1 + 3 + 5 + \cdots + (2n-1) = n^2$$

**归纳证明**：
- 基础 n=1：左边=1，右边=1²=1 ✓
- 归纳：假设 $\sum_{k=1}^{n}(2k-1) = n^2$。则
  $$\sum_{k=1}^{n+1}(2k-1) = \underbrace{\sum_{k=1}^{n}(2k-1)}_{=n^2} + (2n+1) = n^2 + 2n + 1 = (n+1)^2 \checkmark$$
- 结论：对所有 n 成立。$\blacksquare$

**几何直觉**（`wim_ch1_section1_induction.png`）：每个奇数 = 一个 L 形，L 形一层层套上去正好拼成 n×n 正方形点阵。

### 1.3 归纳法的陷阱（数学成熟度）

- ⚠️ **基础不能漏**：只证归纳步不证基础，可能 P(n) 对所有 n 都不成立（空中楼阁）。
- ⚠️ **归纳步必须严格**：`P(n)⟹P(n+1)` 不能依赖直觉，必须用逻辑推出。
- ⚠️ **强归纳法**：有时 `P(n+1)` 依赖前面所有 `P(1..n)`，要用强归纳（`P(1)∧...∧P(n)⟹P(n+1)`）。

## §2 素数：数论的原子

### 2.1 算术基本定理（最重要定理之一）

> 每个 n>1 **唯一**分解为素数之积（不计顺序）。

$$120 = 2^3 \times 3 \times 5$$

素数 = 自然数的"DNA"。这条唯一性是整个数论的基石。

### 2.2 欧几里得：素数无穷（最古老的优美证明）

**反证法**：假设素数有限，设全部为 $p_1, \ldots, p_k$。
令 $N = p_1 p_2 \cdots p_k + 1$。则 $N$ 除以任何 $p_i$ 都余 1，所以要么 $N$ 自己是新素数，要么 $N$ 有一个不在列表里的素因子。矛盾。$\blacksquare$

> 💡 这个证明 2300 年了，仍是数学美的典范——**不构造一个素数，却证明素数无穷**。

### 2.3 厄拉多塞筛法（`what_is_math_ch1.py` §2）

古希腊算法，复杂度 $O(N \log\log N)$：
```
列 2..N → 2 是素数划掉 2 的倍数 → 下一个 3 划掉 3 的倍数 → ... → √N
```

### 2.4 素数定理（19 世纪最大里程碑之一）

$$\pi(N) \sim \frac{N}{\ln N} \quad (\pi(N) = \leq N \text{ 的素数个数})$$

代码实测：N=1000 时 π=168，N/ln(N)≈145，相对误差 ~14%（N 越大越准）。**这条公式连接了素数（离散）和 ln（连续/分析）**——是解析数论的起点。

## §3 同余与费马小定理

### 3.1 同余（高斯的发明）

$$a \equiv b \pmod{n} \iff n \mid (a-b)$$

**直觉**：时钟算术。17 点 = 5 点（mod 12）。`wim_ch1_section3_congruence.png` 左图画了 mod 12 时钟。

### 3.2 费马小定理

> 若 $p$ 素，$\gcd(a,p)=1$，则 $a^{p-1} \equiv 1 \pmod{p}$。

代码验证（§3）：p=5/7/11/13 时 $a^{p-1} \bmod p$ 恒 = 1。✓

### 3.3 RSA 密码的直觉（工程锚点）

费马小定理是 **RSA 公钥密码**的数学根基：
- 选两个大素数 $p, q$，造"锁" $n = pq$
- 用 $a^{p-1} \equiv 1$ 设计加解密
- **破解 = 分解大 n**——当 n 是 2048 位时，最快的计算机也要几亿年
- 你每天用的 HTTPS、银行转账、加密货币，全建立在这条 350 年前的定理上

> 🎯 这就是"研究级数学 + 工程落地"的典范：纯数论的定理（费马小定理）造出了现代文明的密码基础设施。

## §4 数论奇观：未解之谜

### 4.1 完美数

> $n$ = 其真因子之和。如 $6 = 1+2+3$，$28 = 1+2+4+7+14$。

**欧几里得-欧拉定理**：偶完美数 $\Leftrightarrow 2^{p-1}(2^p-1)$（$2^p-1$ 是梅森素数）。
代码找到的 4 个（6/28/496/8128）全部符合。

**❓ 未解**：是否存在**奇**完美数？——至今零个发现，但也无人证明不存在。

### 4.2 孪生素数

> $(p, p+2)$ 都是素数：$(3,5), (5,7), (11,13), \ldots$

代码：≤10000 有 205 对。

**❓ 未解**：是否无穷多？
- 2013 **张益唐**突破：存在无穷多对素数，间隔 < 7000 万（后被优化到 246）
- 完全证明"间隔=2 无穷"还能拿菲尔兹奖级荣誉

### 4.3 哥德巴赫猜想（练习题）

> 每个 >2 的偶数 = 两素数之和。如 $4=2+2$, $10=3+7$, $100=3+97$。

**❓ 未解**（1742 年提出，至今 280+ 年）。已验证到 $4 \times 10^{18}$，但无人能证。

> 💡 这就是柯朗《什么是数学》的精神——**用小学生懂的定义，引出全世界最聪明的头脑 280 年都证不动的谜题**。数学的乐趣 = 在已知里发现未知。

## §6 数学成熟度训练（阶段 1 的核心）

这一章真正教你的不是数论知识，而是**证明思维**：

1. **归纳法**：从有限（基础+归纳）推出无穷（结论）——数学独有的力量
2. **反证法**（欧几里得素数无穷）：假设反面 → 推矛盾 → 得证
3. **定义的力量**：完美数/孪生素数这么简单的定义，引出深不可测的问题
4. **已知 vs 未知**：很多"显然"的猜想（哥德巴赫）280 年无人会证——**数学的谦虚**

> 🎓 **学完本章你应该感受到**：数学不是"算对答案"，而是"严格论证"。这种思维是阶段 1 要建立的底座，后面 Spivak 会用 ε-δ 把它推到极致。
