## §0 一句话

> **数系扩张的每一步都是"为填补某种不足"：减法不够→负数，除法不够→分数，极限不够→无理，开方不够→复数。到复数，代数封闭，扩张终结。**

## §1 有理数：稠密但「有洞」

**有理数** $= p/q$（$p,q$ 整数，$q \ne 0$）。可化为有限小数或无限循环小数。

**稠密性**：任意两个有理数之间还有一个有理数（取中点 $(a+b)/2$）。
> 直觉：有理数在数轴上"挤得满满的"。

**但有洞**：$\sqrt{2} \approx 1.4142$ 不是有理数——数轴上有理数之间有"缝隙"。
> `what_is_math_ch2.py` §1：分母 ≤50 的有理数在 [1,2] 上看起来"连续"，但 √2 处是洞。

**连分数**：$\sqrt{2} = [1; 2, 2, 2, \ldots]$（无限不循环 → 无理）。代码 §1 右图显示连分数渐近分数误差单调下降但不归零。

## §2 √2 无理——数学史最经典反证法

### 2.1 反证法证明（必背）

**定理**：$\sqrt{2}$ 不是有理数。

**反证**：假设 $\sqrt{2} = p/q$，$p, q$ 互素（既约）。
- 则 $2q^2 = p^2$ → $p^2$ 偶 → $p$ 偶 → 设 $p = 2k$
- 代入：$2q^2 = 4k^2$ → $q^2 = 2k^2$ → $q^2$ 偶 → $q$ 偶
- 但 $p, q$ 都偶与「互素」矛盾！

所以假设错，$\sqrt{2}$ 无理。$\blacksquare$

### 2.2 历史冲击

毕达哥拉斯学派信仰"万物皆整数之比"。$\sqrt{2}$ 无理的发现**动摇了他们的世界观**（传说发现者希帕索斯被扔进海里）。这条证明引发了数学史第一次"基础危机"。

### 2.3 几何含义：不可公度

单位正方形对角线 = $\sqrt{2}$，**无法用任何有理数度量**（`wim_ch2_section2_sqrt2.png`）。
古希腊人因此被迫从"算术"转向"几何"来处理这种"不可公度量"——这是几何学兴起的契机。

### 2.4 程序验证的局限

代码找 $q \le 10000$ 的最佳有理逼近，误差永远不为 0（因为 √2 无理）。
> ⚠️ 注意：**程序"验证"不能代替"证明"**。程序只能验证有限情形，$\sqrt{2}$ 无理需要逻辑证明。这是数学成熟度要点：**计算机做归纳验证，人做演绎证明**。

## §3 实数不可数——Cantor 对角线法（1891）

### 3.1 证明（颠覆直觉）

**定理**：$[0,1]$ 上的实数**不可数**（比自然数"多"）。

**反证**：假设 $[0,1]$ 实数可列：$r_1, r_2, \ldots$，每个写成无限小数：
$$r_n = 0.d_{n1}d_{n2}d_{n3}\cdots$$
构造新数 $s = 0.e_1 e_2 e_3 \cdots$，其中 $e_n \ne d_{nn}$（第 $n$ 位与 $r_n$ 不同）。
则 $s \ne r_1$（第1位不同），$s \ne r_2$（第2位不同），$\ldots$
但 $s \in [0,1]$，应在列表里 → 矛盾！$\blacksquare$

### 3.2 代码演示（`§3`）

8×8 假列表，对角线 `[6,3,1,8,3,2,3,4]`，构造 $s = 0.74294345\ldots$，验证 $s$ 与每个 $r_i$ 第 $i$ 位不同 → 不在列表。

### 3.3 哲学冲击

> **「无限」也有大小之分**。自然数、整数、有理数都是同一级无限（**可数**），实数是**更大的无限**（不可数）。

Cantor 的同代人激烈反对（Kronecker："上帝创造整数，其余都是人造"），但这套理论最终成为现代数学的根基。

## §4 复数——欧拉公式与代数封闭

### 4.1 复数 = 平面上的点

$z = a + bi$（$i^2 = -1$），几何 = 平面点 $(a, b)$。
**乘法 = 旋转 + 缩放**：$z_1 \cdot z_2$ 把 $z_1$ 转 $\arg(z_2)$、乘 $|z_2|$。

### 4.2 欧拉公式（数学最美等式）

$$e^{i\theta} = \cos\theta + i\sin\theta$$
特例 $\theta = \pi$：
$$e^{i\pi} + 1 = 0$$
把数学最重要的 5 个常数（$0, 1, \pi, e, i$）用一个等式串起。

代码 §4 数值验证：`np.exp(1j*np.pi) = -1.000000 + 0.000000i` ✓

### 4.3 代数基本定理

> 任何 $n$ 次多项式在复数域有 $n$ 个根（含重根）。

→ 复数是**代数封闭**的。从自然数到复数的数系扩张到此终结：
$$\mathbb{N} \to \mathbb{Z} \to \mathbb{Q} \to \mathbb{R} \to \mathbb{C}$$
每步扩张都是为"填补某种不足"。

## §6 数学成熟度训练（本章核心）

1. **反证法**（√2 无理）：假设反面 → 推矛盾 → 得证。数学最强大的工具之一。
2. **构造性证明**（对角线）：不只证明"存在"，还**造出来**。Cantor 给出了构造法。
3. **扩张思想**：数学不是"发现真理"，而是"为解决问题而构造新对象"（虚数、无理数都是"构造"出来的）。
4. **无限的层级**：可数 vs 不可数——人类对无限认知的革命。

> 🎓 **学完本章你应该感受到**：数学允许"构造"新对象解决旧问题（i 解决 $x^2+1=0$，无理数填补数轴洞）。这种"扩张"思维是研究级数学的核心。

## §7 与 AI / 工程的联系

| 数学概念 | 工程落地 |
|---------|---------|
| 有理数 | **浮点数 = 有理数近似**（计算机无法精确表示 √2、π）→ 数值误差、稳定性 |
| 复数 | **信号处理（FFT）、量子计算、电路分析、电磁学** |
| Cantor 不可数 | **计算理论**：图灵机只能处理可数，绝大多数实数"不可计算" |
| 欧拉公式 | 控制论（极点）、数字信号（相位）、量子态 |
| 代数封闭 | 数值算法求多项式根（特征值、谱）的保证 |

> 💡 **计算机只能处理可数**——所有浮点数是有理数。所以数值计算永远有误差。这是数值分析（阶段 2-3 候选方向 C）的起点。
