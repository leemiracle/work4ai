## 📖 Ch.3 章节结构（精读 30 min）

### 3.1 条件概率
$$P(B|A) = \frac{P(AB)}{P(A)}$$

**直觉**：知道 $A$ 发生后，$B$ 发生的"重新归一"概率。

### 3.2 乘法公式
$$P(AB) = P(A) \cdot P(B|A)$$

**链式**：$P(A_1 A_2 A_3) = P(A_1) P(A_2|A_1) P(A_3|A_1 A_2)$

### 3.3 全概率公式
若 $\{A_i\}$ 互斥且并 $= S$：
$$P(B) = \sum_i P(B|A_i) P(A_i)$$

### 3.4 Bayes 公式 ⭐⭐⭐
$$P(A_i|B) = \frac{P(B|A_i) P(A_i)}{\sum_j P(B|A_j) P(A_j)}$$

**本质**：把"先验"$P(A_i)$ 更新为"后验"$P(A_i|B)$。

### V25 真实数据 ⭐⭐⭐⭐⭐
**王阿姨乳腺癌**：
```python
P_disease = 0.01  # 真实患病率
P_pos_given_d = 0.90  # 灵敏度
P_pos_given_not_d = 0.09  # 误报率
P_d_given_pos = (P_disease * P_pos_given_d) / (
    P_disease * P_pos_given_d + (1-P_disease) * P_pos_given_not_d)
print(f"P(癌|阳性) = {P_d_given_pos:.4f}")  # 9.17%
```
**直觉**：90%。**真实**：9.17%——**Bayes 反直觉！**

## ⚠️ 真实学习卡点（V22 + V26）

### 卡点：Sally Clark Bayes 我算错了

**第一次尝试**：
```python
P_SIDS1 = 1/8543
P_SIDS2 = 1/1500
P_dSIDS = P_SIDS1 * P_SIDS2  # 7.8e-8
P_murder = 1/10000
P_2m = 0.95
P_dM = P_murder * P_2m  # 9.5e-5
P_murder_given_2death = P_dM / (P_dSIDS + P_dM)
# = 99.92%
```

**结果违反直觉**：P(谋杀|2死) = 99.92%？！

**反思 + 突破**：
1. **错误根源**：`P_murder = 1/10000` 是"**单次**谋杀率"，但 Sally 案是"**双重**谋杀"
2. **错误根源**：`P_2m = 0.95` 隐含"谋杀者必杀 2 人"假设——这没有数据支撑
3. **正确做法**：用**警方实证数据**估计双重谋杀先验
4. **正确结果**：P(双重 SIDS | 2死) = **95.24%**（Ray Hill 2004）

**教训**：
> **Bayes 的难点不在公式，而在"先验"估计**。
> 公式机械套用可能给出"假精确"的错答。

→ 这正是 Sally Clark 案的核心教训——Meadow 用了错误的先验（独立性假设），得到错误的 1/73M。

## 🐍 Python 完整验证

```python
import numpy as np

# 条件概率：P(>3 | 偶数) = 2/3
print(2/3)  # 0.6667

# 全概率：3 工厂次品
P_defect = 0.5*0.01 + 0.3*0.02 + 0.2*0.03  # 0.017
# Bayes：第 1 厂
print((0.5*0.01)/P_defect)  # 0.2941

# 王阿姨乳腺癌
P_d, P_p_d, P_p_n = 0.01, 0.90, 0.09
P_pos = P_d * P_p_d + (1-P_d) * P_p_n
print((P_d*P_p_d)/P_pos)  # 0.0917

# 邮件过滤（朴素 Bayes）
P_spam, P_ham = 40/100, 60/100
P_fs, P_fh = 30/40, 5/60
P_free = P_spam * P_fs + P_ham * P_fh
print((P_spam*P_fs)/P_free)  # 0.8571
```

## 💡 "啊哈"时刻

### 啊哈 1：王阿姨 9.17% vs 90%
**直觉**：体检阳性 = 真病 90%。
**真实**：**9.17%**。

**为什么**：1000 人中只有 10 人真病，但 89 个没病的也被误报——**误报数量远超真病**。

### 啊哈 2：我自己算错了 Sally Clark
**初始计算**：99.92%（违反直觉）
**修正后**：4.76%（与 Ray Hill 一致）

**啊哈**：**我也犯了 Meadow 类似的错误——公式对，先验错。** 这是 Ch.3 最深刻的教训。

### 啊哈 3：Bayes 的本质 = "信念更新"
$$\text{先验} \xrightarrow{\text{证据}} \text{后验}$$

→ 这就是**学习**的本质——根据新证据更新信念。机器学习、科学方法、人类认知都遵循 Bayes。
