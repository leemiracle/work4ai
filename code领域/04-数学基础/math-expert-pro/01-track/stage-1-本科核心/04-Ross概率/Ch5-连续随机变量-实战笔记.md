## 📖 Ch.5 章节（精读 15 min）

### 5.1 PDF vs PMF
- 离散：$P(X = x)$ 有意义
- 连续：$P(X = x) = 0$，用 $P(a < X < b) = \int_a^b f(x)dx$

### 5.2 三大连续分布
| 分布 | PDF | E | Var |
|------|-----|---|----|
| Uniform(a,b) | $\frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| **Exp(λ)** | $\lambda e^{-\lambda x}$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |
| **Normal(μ,σ²)** | $\frac{1}{\sigma\sqrt{2\pi}}e^{-(x-\mu)^2/2\sigma^2}$ | μ | σ² |

### 5.3 关键性质
- **指数无记忆性**：$P(X>s+t|X>s) = P(X>t)$ ⭐
- **正态 68-95-99.7 法则**：
  - $P(|X-\mu|<\sigma) = 68.27\%$
  - $P(|X-\mu|<2\sigma) = 95.45\%$
  - $P(|X-\mu|<3\sigma) = 99.73\%$

### 5.4 分位数
- $z_{0.95} = 1.645$（90% CI 上界）
- $z_{0.975} = 1.96$（95% CI 上界）⭐ 假设检验标准
- $z_{0.995} = 2.576$（99% CI 上界）

## 🐍 Python 完整验证

```python
import numpy as np
from scipy.stats import norm, expon, cauchy

# 68-95-99.7 法则
for k in [1, 2, 3]:
    p = 2*norm.cdf(k) - 1
    print(f"P(|X-μ|<{k}σ) = {p:.4f}")

# 分位数
for q in [0.95, 0.975, 0.995]:
    print(f"z_{q} = {norm.ppf(q):.4f}")

# 高考分数
mu, sigma = 500, 100
print(f"P(≥600) = {1 - norm.cdf(600, mu, sigma):.4f}")

# Cauchy 反例
samples = cauchy.rvs(0, 1, 10000)
print(f"Cauchy 均值（不稳定）: {samples.mean():.4f}, max: {samples.max():.2f}")
```

## 💡 "啊哈"时刻

### 啊哈 1：指数无记忆性
$P(X>s+t|X>s) = P(X>t)$

**直觉**：等了 s 时间没等来 → "应该快来了"。
**真实**：和重新等待一样——**过去不提供信息**。

**应用**：硬件寿命建模（无磨损的电子元件）。

### 啊哈 2：Cauchy 期望不存在
- Normal 10000 次样本均值 = -0.0181（稳定）
- Cauchy 10000 次样本均值 = 0.9332（**不稳定**）

**意义**：**大数律依赖方差有限**——Cauchy 是反例。这是 Ch.8 CLT 的伏笔。

### 啊哈 3：正态分位数 1.96 是统计学的"5%"
- 假设检验 5% 显著性 → z = 1.96
- 95% CI → z = 1.96
- 这个数字在统计学家脑中是常数——比电话号码还熟

**题**：高考 N(500, 100²)，680 分以上多少人？
