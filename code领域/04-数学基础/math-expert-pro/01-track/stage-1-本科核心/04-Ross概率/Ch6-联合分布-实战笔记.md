## 📖 Ch.6 章节（精读 15 min）

### 6.1 联合分布
- 离散：$P(X=x, Y=y) = p(x,y)$
- 连续：$f(x,y)$，$P((X,Y) \in A) = \iint_A f\,dxdy$

### 6.2 边缘 + 独立
- 边缘：$P(X=x) = \sum_y p(x,y)$
- 独立：$p(x,y) = p_X(x) p_Y(y)$

### 6.3-6.4 协方差 + 相关
- $\text{Cov}(X,Y) = E[XY] - E[X]E[Y]$
- $\rho = \text{Cov}(X,Y) / (\sigma_X \sigma_Y)$
- $\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X,Y)$

### 6.5-6.6 多元正态 + 条件分布
二元正态 $N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$：
- 条件 $Y|X=x \sim N(\mu_2 + \rho\frac{\sigma_2}{\sigma_1}(x-\mu_1), \sigma_2^2(1-\rho^2))$
- **向均值回归**：父高 195 cm → 子约 184 cm（ρ<1）

### 6.7 和的分布（卷积）
$f_{X+Y}(z) = \int f_X(x) f_Y(z-x) dx$

## 🐍 Python 关键验证

```python
import numpy as np
from scipy.stats import multivariate_normal, norm

# 不相关 ≠ 独立
np.random.seed(0)
X = np.random.normal(0, 1, 100000)
Y = X**2
print(f"Cov(X, X²) = {np.cov(X,Y)[0,1]:.4f}")  # ≈ 0
# 但 Y 完全由 X 决定

# 多元正态条件分布
samples = np.random.multivariate_normal([0,0], [[1,0.5],[0.5,1]], 100000)
mask = (samples[:,0] > 0.9) & (samples[:,0] < 1.1)
print(f"E[Y|X=1] = {samples[mask,1].mean():.4f}")  # 理论 0.5

# 2008 危机 Copula
def joint_default(p, rho):
    z = norm.ppf(p)
    return multivariate_normal.cdf([z,z], mean=[0,0], cov=[[1,rho],[rho,1]])

print(f"独立: {0.05**2:.6f}")
print(f"危机 ρ=0.95: {joint_default(0.05, 0.95):.6f}")
```

## 💡 "啊哈"时刻

### 啊哈 1：不相关 ≠ 独立
$Y = X^2$ 完全由 $X$ 决定，但 $\text{Cov}(X, X^2) = 0$。

**意义**：**独立是比不相关更强的条件**。ML 中假设"特征独立"很危险——特征可能"非线性相关"。

### 啊哈 2：向均值回归（Galton）
父 195 → 子 184（不是 195）。

**意义**：Galton 在 1886 年发明"回归"一词，源于这个观察。今天机器学习的"回归"一词来自这里！

### 啊哈 3：2008 危机 = Copula ρ→1
平时 ρ=0.3，危机 ρ→0.95。

**意义**：金融灾难的本质是**相关性突增**。Li Copula 模型假设 ρ 稳定——错了。
