### 习题分级
- 🟢 **必做**:证期望线性性(无需独立);Markov 不等式证明;Chebyshev 推论;Jensen 不等式(凸函数 $E[f(X)]\ge f(E[X])$)
- 🟡 **选做**:矩母函数 $M_X(t)=E[e^{tX}]$ 唯一决定分布;Cauchy-Schwarz 概率版
- 🔴 **挑战**:用 Jensen 证 AM-GM;反例 $E[XY]\ne E[X]E[Y]$(依赖时不独立)

### 证明骨架:Chebyshev 不等式
```
证 P(|X-μ|≥kσ) ≤ 1/k²:
  [思路] 用 Markov 不等式作用于 (X-μ)²
  [Markov] 对非负 Y,E[Y]≥a·P(Y≥a)
  [令] Y=(X-μ)²,a=k²σ²: P((X-μ)²≥k²σ²) ≤ E[(X-μ)²]/(k²σ²) = σ²/(k²σ²) = 1/k²
  → Chebyshev 是 Markov 的特例(作用在平方上)
  [意义] "偏离均值 2σ 的概率 ≤ 25%"——只用均值方差就能给尾概率上界
```

## §3 飞腾 D3000M 实测锚点 ⭐

### 锚点一:概率 ↔ 分支预测(本章最精彩锚点)
> **CPU 分支预测器就是在"猜一个概率事件"。猜错代价巨大。**

飞腾 `[实测 Lab02 branch_predict]`:
| 分支模式 | 实测 IPC | 含义 |
|---------|---------|------|
| 单调递增(可预测)| **3.14** | 预测器几乎全对 |
| 随机(50/50)| **0.71** | 预测器瞎猜,频繁清空流水线 |

- 数学:分支结果是个随机变量 $X$(取 0/1),预测器估 $P(X=1)$
- Chebyshev 视角:预测错误率 = "偏离最优策略的尾概率",尾越重(随机)性能越差
- 🔍 **思考**:为什么随机分支 IPC 跌到 0.71(只有单调的 23%)?流水线清空代价 + 预测命中率

### 锚点二:期望 ↔ 性能平均
IPC = "每周期指令数"本质是期望值(指令数/周期的期望)。`[实测 Lab00]` null_loop IPC=4.00 = 满载期望;真实程序 IPC 是各种停顿加权后的期望。

### 锚点三:Jensen 不等式 ↔ 性能非线性
$E[f(X)]\ge f(E[X])$(凸 $f$)。性能优化里"平均延迟"vs"延迟的平均函数"常违反直觉——Jensen 提醒:对非线性指标(如倒数=吞吐),不能用平均算。

### 一句话
> **Ross 给你概率的公理化(Kolmogorov)+ 尾界(Markov/Chebyshev);飞腾分支预测器是"猜概率"的硬件——随机分支 IPC 暴跌 4.4× 是 Chebyshev 尾界的工程肉身。**
