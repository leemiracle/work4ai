# 📖 Ch.7 期望性质

### 7.1 线性性 ⭐⭐⭐⭐⭐
$$E[X+Y] = E[X] + E[Y]$$

**即使 X, Y 相关！** 这是 Ross 全书最美的事实之一。

**Python 验证**：100000 次相关 X,Y → E[X+Y] = E[X]+E[Y] 精确成立。

### 7.2 协方差矩阵 + 特征值
$\Sigma$ 的特征值 = **PCA 主成分**（V14 ML 锚点）

### 7.3 MGF 矩生成函数
$M(t) = E[e^{tX}]$——分布的"DNA"。

**重要 MGF**：
- Normal(0,1)：$M(t) = e^{t^2/2}$
- Poisson(λ)：$M(t) = e^{\lambda(e^t-1)}$
- Binomial(n,p)：$M(t) = (1-p+pe^t)^n$

### 7.4 Jensen 不等式
凸 $f$：$E[f(X)] \geq f(E[X])$

**特例**：$E[X^2] \geq (E[X])^2$（方差非负）

# 📖 Ch.8 极限定理（全书高潮）⭐⭐⭐⭐⭐

### 8.1 Chebyshev 不等式
$$P(|X-\mu| \geq k\sigma) \leq \frac{1}{k^2}$$

**Python 验证**：Binomial(100, 0.5)
- Chebyshev 上界：0.1111
- 实际：0.0036（Chebyshev 是宽松上界）

### 8.2 弱大数律 WLLN ⭐⭐⭐⭐⭐
样本均值 $\bar{X}_n \xrightarrow{P} \mu$（依概率收敛）

**Python 验证**（掷骰子累积均值）：
| n | 累积均值 | 偏差 |
|---|--------|------|
| 10 | 3.9000 | +0.4 |
| 100 | 3.4200 | -0.08 |
| 1000 | 3.5190 | +0.019 |
| 10000 | 3.4939 | -0.006 |
| 100000 | 3.5082 | +0.008 |

→ **缓慢但确定地收敛到 3.5**

### 8.3 强大数律 SLLN
$\bar{X}_n \xrightarrow{a.s.} \mu$（几乎必然收敛）

**比 WLLN 更强**：1000 次实验每次 10000 样本，**全部**最终均值在 [3.4, 3.6]。

### 8.4 中心极限定理 CLT ⭐⭐⭐⭐⭐
$$\frac{\sum X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$$

**Python 验证**（掷 30 骰子和）：
- 标准化后均值 -0.0063 ≈ 0 ✓
- 标准差 1.0012 ≈ 1 ✓
- 正态性检验 p=0.0288

**CLT 收敛速度**（看 skew/kurtosis → 0）：
| n | skew | kurtosis |
|---|------|--------|
| 2 | 0.03 | -0.62 |
| 5 | -0.02 | -0.27 |
| 10 | 0.01 | -0.11 |
| 30 | -0.01 | -0.02 |
| 100 | 0.003 | -0.05 |

→ **n=30 已极接近正态**（统计学的"30 法则"由来）

### 8.5 工程意义：蒙特卡洛积分
```python
∫₀¹ x² dx 真值 = 1/3
蒙特卡洛（10万样本）= 0.333042
误差 = 0.000291
```

### 8.6 CLT 统计应用：95% CI
$$\bar{X} \pm 1.96 \frac{\sigma}{\sqrt{n}}$$

**Python 验证**：n=100, μ=5, σ=2 → 95% CI [4.72, 5.51]，真值在内 ✓

## 💡 "啊哈"时刻（全书最强）

### 啊哈 1：期望线性性（即使相关）⭐⭐⭐⭐⭐
$E[X+Y] = E[X]+E[Y]$ 不需要独立！

**意义**：这是"线性"的回报——破坏性的简化（去掉协方差项）。

### 啊哈 2：CLT 是"民主"的胜利
任何分布（方差有限）→ 标准化和 → 正态。

**意义**：正态不是特殊，是**普遍**——所有随机性叠加的最终归宿。

### 啊哈 3：CLT 假设"方差有限"——Cauchy 是反例
Cauchy 不收敛正态——因为方差无限。

**意义**：**所有"普适定理"都有边界**。CLT 边界 = 方差有限。

### 啊哈 4：SLLN 让蒙特卡洛成为可能
随机采样 → 估计积分 → 误差可控。

**意义**：这是**计算数学的根基**——所有数值积分、贝叶斯推断、强化学习的基石。
