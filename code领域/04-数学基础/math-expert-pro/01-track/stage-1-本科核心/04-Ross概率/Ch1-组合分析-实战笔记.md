## 📖 Ross Ch.1 章节结构（精读 15 min）

### 1.1 引言
**核心问题**：等可能事件概率 = $P(E) = \frac{|E|}{|S|}$——需要会**数**样本空间 $S$ 和事件 $E$ 的元素个数。

### 1.2 计数基本原理（乘法原理）⭐⭐⭐
> 如果实验 1 有 $m$ 个可能结果，实验 2 有 $n$ 个，则**复合实验**有 $m \times n$ 个。

**我的理解**：实验 1 完成 → 实验 2 选择独立时，乘法成立。

**反例**（V01 反例驱动）：如果不独立？实验 2 选项依赖实验 1 结果——乘法失效。

### 1.3 排列 Permutations
$n$ 个不同对象的排列数：$n! = n \times (n-1) \times \cdots \times 1$

**部分排列**：从 $n$ 个中取 $k$ 个有顺序 → $P(n,k) = \frac{n!}{(n-k)!}$

### 1.4 组合 Combinations ⭐⭐⭐
从 $n$ 个中取 $k$ 个**无序**：$\binom{n}{k} = \frac{n!}{k!(n-k)!}$

**关键洞察**：组合 = 排列 ÷ $k!$（消去"顺序"）。

### 1.5 多项式系数
将 $n$ 个对象分成 $n_1, n_2, ..., n_r$ 组：$\binom{n}{n_1, n_2, ..., n_r} = \frac{n!}{n_1! n_2! \cdots n_r!}$

**特例**：$\binom{n}{k} = \binom{n}{k, n-k}$。

### 1.6 方程 $\sum_{i=1}^r x_i = n$ 的非负整数解个数 ⭐⭐
**经典**：$\binom{n+r-1}{r-1}$（球盒模型 stars and bars）

**直觉**：$n$ 个球 + $r-1$ 个隔板 = $n+r-1$ 个位置选 $r-1$ 个放隔板。

### 1.7 组合恒等式
- $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$（Pascal 三角）
- $\sum_{k=0}^{n} \binom{n}{k} = 2^n$（二项式定理）
- Vandermonde 恒等式：$\binom{m+n}{r} = \sum_k \binom{m}{k}\binom{n}{r-k}$

### V25 真实数据 ⭐⭐⭐
**经典真实问题**：生日悖论

```python
import numpy as np
from math import comb

# 精确公式
def birthday_exact(n):
    p = 1
    for i in range(n):
        p *= (365 - i) / 365
    return 1 - p

# 关键节点
for n in [10, 23, 30, 50, 70]:
    print(f"{n} 人: 至少 2 人同生日 = {birthday_exact(n):.2%}")
# 23 人 ≈ 50.7%（最小震撼群）
# 50 人 ≈ 97%
# 70 人 ≈ 99.9%

# 蒙特卡洛验证
np.random.seed(0)
trials = 100000
matches = sum(len(set(np.random.randint(1, 366, 23))) < 23 for _ in range(trials))
print(f"\n蒙特卡洛 23 人（{trials} 次）: {matches/trials:.4f}")
# 期望 ~0.507，验证理论
```

## 🐍 Python 完整验证

```python
from math import comb, perm, factorial
import numpy as np

# === Ch.1 全部公式 Python 化 ===

# 1.2 乘法原理
def multiplication(*choices):
    """复合实验总数"""
    result = 1
    for c in choices: result *= c
    return result

print(f"2 道菜 × 3 主菜 × 4 甜点 = {multiplication(2, 3, 4)} 种套餐")  # 24

# 1.3 排列
print(f"P(5, 3) = {perm(5, 3)}")  # 60
print(f"5! = {factorial(5)}")  # 120

# 1.4 组合
print(f"C(5, 2) = {comb(5, 2)}")  # 10
print(f"C(10, 3) = {comb(10, 3)}")  # 120

# 1.5 多项式系数
def multi(n, *groups):
    """分组成 groups，和=n"""
    from math import factorial as f
    if sum(groups) != n: return None
    result = f(n)
    for g in groups: result //= f(g)
    return result

print(f"将 9 人分成 2/3/4 三组 = {multi(9, 2, 3, 4)}")  # 1260

# 1.6 球盒（非负整数解）
def stars_bars(n, r):
    """x_1 + x_2 + ... + x_r = n 的非负整数解个数"""
    return comb(n + r - 1, r - 1)

print(f"x + y + z = 10 的非负整数解 = {stars_bars(10, 3)}")  # C(12,2)=66

# 1.7 组合恒等式
# Pascal 三角
print("\nPascal 三角前 6 行:")
for n in range(6):
    print([comb(n, k) for k in range(n+1)])

# 验证 sum C(n,k) = 2^n
for n in [5, 10, 20]:
    assert sum(comb(n, k) for k in range(n+1)) == 2**n
print("\n✓ sum C(n,k) = 2^n 验证通过")
```

### 完整解题示范（Ross 1.12 桥牌）

**题目**：52 张牌中发 13 张给一玩家，全部 13 张都是黑桃的概率？

**解**：
- 样本空间 $|S| = \binom{52}{13}$
- 事件 $E$ = 全黑桃 = $\binom{13}{13} = 1$（13 张黑桃全选）
- $P(E) = 1/\binom{52}{13} = \frac{1}{635,013,559,600} \approx 1.57 \times 10^{-12}$

```python
from math import comb
p = 1 / comb(52, 13)
print(f"全黑桃概率 = {p:.2e}")  # 1.57e-12
print(f"C(52,13) = {comb(52,13):,}")  # 635,013,559,600
```

**直觉校准**：6350 亿分之一——人类直觉严重低估。

### 完整解题示范（Ross 1.18 生日推广）

**题目**：n 人中至少 2 人同月生的概率 ≥ 50% 时，n = ?

**解**：
- 12 个月，假设均匀
- $P(\text{都不同月}) = \frac{12 \cdot 11 \cdot 10 \cdots (12-n+1)}{12^n}$
- 求最小 $n$ 使 $1 - P(\text{都不同月}) \geq 0.5$

```python
def same_month(n):
    p_diff = 1
    for i in range(n):
        p_diff *= (12 - i) / 12
    return 1 - p_diff

for n in range(1, 13):
    p = same_month(n)
    if p >= 0.5:
        print(f"n = {n}, P = {p:.2%}")  # n=5, 0.618
        break
# 答案：n=5（5 人中至少 2 人同月生概率 61.8%）
```

**对比生日（365 天）n=23**：12 月份的"碰撞阈值"更小（n=5 vs n=23）——月份越少越易碰撞。
