### 习题分级
- 🟢 **必做**:WLLN 的 Chebyshev 证明;$\bar X_n \xrightarrow{P} \mu$;蒙特卡洛估 $\pi$ 的误差分析($O(1/\sqrt{n})$)

- 🔴 **挑战**:CLT 的特征函数证明(Taylor 展开 $\varphi_X(t)$ + 截断);三种收敛(依概率/依分布/a.s.)的关系链

### 证明骨架:WLLN(Chebyshev 路线)
```
证 样本均值 $\bar X_n = (X_1+...+X_n)/n \xrightarrow{P} \mu$ (独立同分布,均值 μ,方差 σ²):
  [用 Chebyshev] P(|$\bar X_n$ - μ| ≥ ε) ≤ Var($\bar X_n$)/ε²
  [算方差] Var($\bar X_n$) = Var(X₁+...+Xₙ)/n² = nσ²/n² = σ²/n  (独立性)
  [结论] ≤ σ²/(nε²) → 0 当 n→∞  ∴ $\bar X_n \xrightarrow{P} \mu$  □
  [蒙特卡洛的根基] 这就是"采样越多估计越准"的严格保证
```

## §3 飞腾 D3000M 实测锚点 ⭐

### 锚点一:WLLN ↔ benchmark 必须跑多次
> **飞腾实验纪律第 4 条:"跑足够多次取中位数"——这就是 WLLN。**

飞腾 `[实测 Lab00-07]` 每个实验都跑 N 次取统计,因为单次受噪声(DVFS/调度/缓存)影响。WLLN 保证:N 次测量的均值 ⟶ 真值。`iron_law` 误差<2% = WLLN 在工程上的兑现。

### 锚点二:CLT ↔ 性能分布近似正态
> **大量独立噪声叠加 → 正态分布(CLT)。CPU 延迟分布近似正态,故 benchmark 报均值±标准差。**

飞腾 `[实测]`:`bench.h` 的高精度计时+统计,正是基于"延迟近似正态"的 CLT 假设。

### 锚点三:蒙特卡洛 ↔ 高维积分的工程现实
> **WLLN ⟹ 蒙特卡洛收敛。高维积分(贝叶斯推断)只能靠它。**

飞腾 `[实测 Expert_05]`:INT8 UDOT **16.9× 加速**让大规模蒙特卡洛采样(MCMC)可行——每秒采样次数直接决定推理速度。蒙特卡洛的误差 $O(1/\sqrt{n})$ 意味着精度提升 10× 需 100× 样本,完全依赖硬件吞吐。

### 锚点四:CLT ↔ 分支预测的"正态近似"
大量独立分支的累计命中/失误,由 CLT 近似正态——这也是预测器统计建模的基础。

### 一句话
> **Ross 给你极限定理的理想(WLLN/CLT 的严格证明);飞腾告诉你 benchmark 跑多次取中位数=WLLN、延迟近似正态=CLT、蒙特卡洛吃 INT8 吞吐。极限定理是实验统计学的数学根基。**
