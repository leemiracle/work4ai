## §2 选择决策树(基于你的画像)

```
你的偏好(画像:Python 工程 + 飞腾 + AI 求职背景 + 趣味性)?

├─ 想做"最前沿 AI 理论"(生成模型/大模型)?
│   ├─ 偏数学严密? → A ML 理论(PAC-Bayes/landscape)
│   └─ 偏随机建模? → B 概率随机过程(扩散模型 SDE)
│
├─ 想做"飞腾最贴近"的?
│   └─ → C 数值分析(Expert_08 的数学根基,无 BF16 的对策)
│
├─ 想做"ML 的引擎"(训练/优化)?
│   └─ → D 优化理论(凸+非凸 SGD)
│
└─ 想做"通信/密码/压缩"?
    └─ → E 信息论(Shannon/国密 SM)
```

### 我的推荐(基于你的"应用数学研究型工程师"定位)
- **首选 C 数值分析 + D 优化**:工程落地最强,飞腾直接受益,且 ML/AI 都需要(梯度=优化,推理=数值)
- **次选 A ML 理论**:若想兼顾理论深度,与 C+D 形成"理论+工程"双轨

## §4 与 stage-1/2 的衔接(每个方向的数学根基)

| 方向 | stage-1 依赖 | stage-2 依赖 |
|:--:|------------|------------|
| A ML | Spivak(链式) + Ross(概率) + LADR(线代)| Royden(测度/概率)|
| B 概率 | Ross(初等) + Spivak(连续)| Royden(测度) + Munkres(拓扑)|

| E 信息 | Ross(概率) + 柯朗(数论/密码)| Dummit(代数编码)|

> 🎯 **stage-1/2 不是浪费时间**:它们是 stage-3 任何方向的根基。例如 C 数值分析需要 Spivak 全部 30 章 + Royden 全部 20 章。
