# Galois 理论：代数与几何的桥梁

> Galois 理论是"统一视角"(B) 代几对偶的最经典实例——连接域扩张与群论。

---

## 一、Galois 理论的核心

对于域扩张 L/K，Galois 理论建立**反变格同构**：

中间域 E (K⊆E⊆L) ⟷ 子群 H⊆Gal(L/K)

| 中间域 | 子群 |
|--------|------|
| E 越大 | Gal(L/E) 越小 |
| L^H = {x: ∀h∈H, h(x)=x} | Gal(L/E) |
| L/K 是 Galois 扩张 | 格反同构 |

### 五次方程无根式解的证明
1. x⁵-x-1 的 Galois 群 = S₅（5 次对称群）
2. S₅ 不可解（没有正规复合列）
3. 方程可根式解 ⟺ Galois 群可解
4. ∴ x⁵-x-1 不可根式解

→ 一个**代数**问题（方程可解性）翻译成**群论**问题（群可解性），再翻译回来——这是统一视角的完美范例。

## 二、其他经典对偶实例

### Stone 对偶（布尔代数 ⟷ Stone 空间）
- 布尔代数 B ⟷ Stone 空间 S_B（全不连通紧 Hausdorff）
- 逻辑 ↔ 拓扑
- 这是 topos 理论的远祖

### Gelfand 对偶（交换 C*-代数 ⟷ 紧 Hausdorff 空间）
- {交换 C*-代数}^op ≃ {紧 Hausdorff 空间}
- 非交换几何：把"空间"替换为"可能非交换的 C*-代数"

### Pontryagin 对偶（局部紧阿贝尔群 ⟷ 对偶群）
- LCA 群 G → 对偶群 Ĝ → 双对偶 = G
- 傅里叶变换 = Pontryagin 对偶的具体实例

## 三、Langlands 纲领——终极统一？

Langlands 纲领预言：数论（自守表示）与几何（Galois 表示）之间存在深层的"字典"对应。

| 数论侧 | 几何/分析侧 |
|--------|-----------|
| Galois 表示 | 自守形式 |
| 椭圆曲线 | 模形式 |
| L 函数 | 自守 L 函数 |

**Fermat 大定理**（Wiles 1995）= Langlands 纲领的一个特例：证明每个半稳定椭圆曲线"是模的"。

→ 如果统一视角是"翻译字典"，Langlands 纲梯是**最大的字典**。
