# Martin-Löf 依赖类型论（MLTT）

> MLTT 是 Lean/Coq/Agda 的数学基础——用"类型"统一了逻辑、计算和集合论。

---

## 一、从简单类型到依赖类型

**简单类型**（Hindley-Milner）：`f : Int → String`（类型不依赖值）

**依赖类型**（MLTT）：`v : Vec(n, A)`（类型**依赖**值 n——长度为 n 的向量类型）

核心区别：类型可以是"值的函数" → 类型系统足以表达**任意数学命题**。

## 二、MLTT 的四个类型构造器

### 1. Π 类型（依赖函数）= ∀
`Π (x : A) → B(x)` — 对每个 x:A 返回类型 B(x)

```lean
-- ∀ n : ℕ, n + 0 = n 是一个 Π 类型
theorem zero_add : Π (n : ℕ), 0 + n = n := ...
```

非依赖版本 = 普通函数类型 A → B。

### 2. Σ 类型（依赖对）= ∃
`Σ (x : A) × B(x)` — 一个 x:A 配上一个 B(x) 的证明

```lean
-- ∃ n : ℕ, n > 0 是一个 Σ 类型
def exists_pos : Σ (n : ℕ), n > 0 := ⟨1, by norm_num⟩
```

非依赖版本 = 积类型 A × B。

### 3. 等同类型（Id/≡）
`Id(A, x, y)` 或 `x ≡ y : A` — x 和 y 在类型 A 中相等

```lean
-- 2 + 2 ≡ 4 是一个类型
-- 它的"居民"（证明）是 refl（自反性）
```

等同类型是**命题性相等**——比集合论的外延相等更精细。

### 4. 归纳族（Inductive Types）
```lean
inductive Nat where
  | zero : Nat
  | succ : Nat → Nat
```

归纳类型 = 递归定义的数据类型，附带**归纳原理**（证明关于该类型的性质）。

## 三、Curry-Howard 在 MLTT 中的体现

| 逻辑 | MLTT 类型 | 计算 |
|------|-----------|------|
| ∀x:A. P(x) | Π(x:A). P(x) | 依赖函数 |
| ∃x:A. P(x) | Σ(x:A). P(x) | 依赖对 |
| A ∧ B | A × B | 积 |
| A ∨ B | A + B | 和 |
| A ⇒ B | A → B | 函数 |
| ⊥ | ∅ | 空类型 |
| x = y | Id(A,x,y) | 等同类型 |

**每条逻辑规则 = 一条类型规则 = 一条计算规则**——三位一体。

## 四、MLTT vs 集合论

| 维度 | ZFC 集合论 | MLTT 类型论 |
|------|-----------|-------------|
| 基本对象 | 集合 | 类型+项 |
| 相等 | 外延（A=B iff 元素相同）| 命题性(x≡y) + 外延 |
| 存在 | ∃x ∈ A, P(x) | Σ(x:A).P(x)（必须构造）|
| 排中律 | 默认成立 | 不成立（除非加 classic 公理）|
| 计算 | 不可执行 | 可执行（β-归约）|
| 形式化 | 难（集合编码）| 自然（直接写数学）|

## 五、HoTT（同伦类型论）—— MLTT 的几何推广

Voevodsky 2009 提出：把 `x ≡ y` 解释为**路径**（拓扑空间中的同伦）。

- `refl : x ≡ x` = 常值路径
- `p : x ≡ y` + `q : y ≡ z` → `p ∘ q : x ≡ z` = 路径连接
- `p⁻¹ : y ≡ x` = 逆路径
- 高阶等同 `α : p ≡ q` = 路径之间的路径（2-同伦）

HoTT 把类型论、拓扑学、范畴论统一在一起——这是 21 世纪数学基础的前沿。
