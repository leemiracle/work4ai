# 极限、伴随与 Yoneda 引理

> 这三个概念是范畴论的核心——Mac Lane 名言："所有重要概念都是伴随。"

---

## 一、极限与余极限——统一的构造

极限统一了：积、拉回、逆极限、等化子——所有"满足相容性条件的选取"。

### 极限的定义（泛性质）
对象 L 是图 D 的极限，如果有态射 πᵢ:L→D(i) 使得：
1. 所有关系可交换：D(f)∘πⱼ = πᵢ（对图中每条边 f:i→j）
2. **泛性质**：对任何其他满足条件的 X，存在**唯一**态射 u:X→L

| 极限特例 | 条件 | 在 Set 中的实现 |
|---------|------|----------------|
| 积 A×B | 离散图（两点）| {(a,b) : a∈A, b∈B} |
| 拉回 | A→C←B 形图 | {(a,b) : f(a)=g(b)} |
| 等化子 | A ⇉ B（平行态射）| {a : f(a)=g(a)} |
| 逆极限 | 无穷链 ...→A₂→A₁ | ∏Aᵢ 的相容子集 |

余极限 = 极限的对偶（箭头反转）。

### 例子：积 = 一种极限
A×B 的泛性质：给定任何 X 配态射 f:X→A, g:X→B，存在**唯一** u:X→A×B 使 π₁∘u=f, π₂∘u=g。

→ 这就是为什么群直积、拓扑积、向量空间积"是同一回事"——它们都是各自范畴里的极限。

## 二、伴随函子——"最接近的翻译"

L⊣R 当且仅当 Hom_D(L(A), B) ≅ Hom_C(A, R(B))（自然同构）

### 经典伴随对

| 左伴随 L | 右伴随 R | 含义 |
|---------|---------|------|
| 自由群 F:Set→Grp | 遗忘 U:Grp→Set | "给集合配最一般群结构" ↔ "忘掉群结构" |
| 积 -×B | 指数 (-)^B | currying: A×B→C ≅ A→C^B |
| 张量积 -⊗B | Hom(B,-) | 线性代数的张量-Hom 伴随 |
| ∃（存在量词）| ∀（全称量词）| 逻辑中 ∃ ⊣ ∀ |
| 反像 f⁻¹ | 全像 ∃f | 拓扑中开集的反像/全像 |

### 伴随的性质
- 右伴随保持极限（积/拉回/等化子）
- 左伴随保持余极限（余积/推出/余等化子）
- 伴随唯一确定（在同构意义下）

## 三、Yoneda 引理——"关系决定对象"

**陈述**：对任何局部小范畴 C，函子 y:C→[C^op,Set]（Yoneda 嵌入）是**完全忠实**的。

更具体地：Nat(Hom(-,A), F) ≅ F(A)（自然变换集合 ≅ F 在 A 的值）

### 直觉解读
> 一个对象 A 由它与所有其他对象的关系完全决定——不需要知道 A 的"内部构造"。

**比喻**：一个人的身份由他与所有其他人的关系决定（社交网络定义身份），不需要知道他的"内在"。

### 应用
- **证明伴随的存在性**：Yoneda 是验证泛性质的通用工具
- **表示论**：可表示函子 Hom(-,A) 是"最简单"的预层
- **Lean/HoTT**：Yoneda 是形式化数学的关键引理

## 四、 Monad——自函子范畴上的代数

Monad = (T, η, μ) where T:C→C, η:Id⇒T, μ:T²⇒T

每个伴随对 L⊣R 产生一个 Monad T=R∘L。

### 计算中的 Monad
- List Monad：非确定性计算
- Maybe Monad：可能失败的计算
- IO Monad：带副作用的计算（Haskell）
- State Monad：带状态的计算

Monad 的核心：**封装计算上下文**，通过 return(η) 和 bind(μ 的变体) 操作。
