# Curry-Howard 同构：命题即类型，证明即程序

> 这是逻辑、类型论与范畴论之间的**三元等价**——计算机科学和形式化数学的理论根基。
> 与 [统一视角/01-四种统一视角.md](../统一视角/01-四种统一视角.md) 的 (C) 路线互为表里。

---

## 🎯 一句话核心

**每个逻辑命题对应一个类型，每个证明对应一个程序。**

更精确地说：直觉主义命题逻辑、简单类型 λ-演算、笛卡尔闭范畴（CCC）三者**形式等价**。

---

## 📜 历史脉络

| 年代 | 人物 | 贡献 |
|------|------|------|
| 1934 | **Haskell Curry** | 发现组合逻辑与蕴涵逻辑的对应（命题=类型雏形）|
| 1934-1940 | **Alonzo Church** | λ-演算——成为"程序"的数学模型 |
| 1969 | **William Howard** | 手稿（1980 发表）明确写出完整对应：命题↔类型，证明↔程序 |
| 1972 | **Joachim Lambek** | 补全第三元：笛卡尔闭范畴 ↔ λ-演算 ↔ 直觉主义逻辑 |
| 1980s | **Per Martin-Löf** | 依赖类型论（MLTT）——把对应推广到一阶逻辑（Π=∀, Σ=∃）|
| 1990s-2000s | **Coq/Agda/Lean** | 实用的定理证明器，全部基于 Curry-Howard |
| 2010s-2020s | **Mathlib/HoTT** | 大规模形式化数学库，Curry-Howard 的工业化 |

## 🔄 三元对应表（核心）

| 直觉主义逻辑 | 简单类型 λ-演算 | 笛卡尔闭范畴 (CCC) |
|:---:|:---:|:---:|
| 命题 $A$ | 类型 $A$ | 对象 $A$ |
| 证明 of $A$ | 程序 $: A$ | 态射 $1 \to A$ |
| $A \Rightarrow B$（蕴含）| 函数类型 $A \to B$ | 指数对象 $B^A$ |
| $A \wedge B$（合取）| 积类型 $A \times B$ | 积对象 $A \times B$ |
| $A \vee B$（析取）| 和类型 $A + B$ | 余积 $A \amalg B$ |
| $\bot$（假）| 空类型 $\emptyset$ | 初始对象 $0$ |
| $\top$（真）| 单位类型 $1$ | 终端对象 $1$ |
| Modus Ponens（$A, A\Rightarrow B \vdash B$）| 函数应用 $f(a)$ | 态射复合 $1 \to A \to B$ |
| 假设引入 | λ 抽象 $\lambda x. e$ | currying 的 transpose |
| 蕴含消去 | 函数应用 | eval 态射 |

## 📝 具体例子

### 例 1：Modus Ponens = 函数应用 = 态射复合

**逻辑**：有证明 $a : A$ 和证明 $f : A \Rightarrow B$，得 $B$ 的证明。

**类型论**：有值 $a : A$ 和函数 $f : A \to B$，得 $f(a) : B$。

**范畴论**：有态射 $a : 1 \to A$ 和 $f : A \to B$，复合得 $f \circ a : 1 \to B$。

**三者完全等价**——同一个动作，三种语言。

### 例 2：$A \Rightarrow A$（同一律）= 恒等函数 = 恒等态射

**逻辑**：$A$ 蕴含 $A$ 的证明 = 假设 $A$ 成立，结论 $A$ 成立（直接引用假设）。

**类型论**：`id : A → A` 定义为 `λx. x`（恒等函数）。

**范畴论**：`id_A : A → A`（每个对象的恒等态射）。

### 例 3：$(A \wedge B) \Rightarrow A$（投影律）= `fst` 函数

**逻辑**：若 $A$ 且 $B$，则 $A$。

**类型论**：`fst : A × B → A` 定义为 `λp. fst(p)`（取积的第一个分量）。

**范畴论**：积的投影态射 $\pi_1 : A \times B \to A$。

### 例 4：$A \Rightarrow (B \Rightarrow A)$（K 组合子）= currying

**逻辑**：若 $A$，则（若 $B$ 则 $A$）——多余假设不影响结论。

**类型论**：`K : A → (B → A)` 定义为 `λx. λy. x`。

**范畴论**：CCC 的 currying——$A \times B \to A$ 等价于 $A \to A^B$（但不完全——这里是 $A \to (B \to A)$，即 $A \to A^B$ 的特例）。

## 🔗 依赖类型：推广到一阶逻辑

Martin-Löf 依赖类型论把 Curry-Howard 从**命题逻辑**推广到**一阶逻辑**：

| 一阶逻辑 | 依赖类型论 | 含义 |
|:---:|:---:|:---|
| $\forall x:A. P(x)$ | $\Pi(x:A). P(x)$ | 依赖函数类型（对每个 $x$ 返回类型 $P(x)$）|
| $\exists x:A. P(x)$ | $\Sigma(x:A). P(x)$ | 依赖对类型（$x : A$ 加上 $P(x)$ 的证明）|
| 谓词 $P(x)$ | 类型族 $P : A \to \text{Type}$ | 把谓词看成"返回命题的函数" |

**关键**：在依赖类型论里，**类型可以依赖值**——这让类型系统足以表达任意数学命题。

这就是 Lean / Coq / Agda 的全部威力所在：

```lean
-- ∀ n : ℕ, n + 0 = n  （一个 Π 类型）
theorem zero_add (n : ℕ) : 0 + n = n := ...

-- ∃ n : ℕ, n > 0  （一个 Σ 类型）
def exists_pos : Σ n : ℕ, n > 0 := ⟨1, by norm_num⟩
```

详见 [14-frontier/AI-for-Math/02-Lean形式化数学入门.md](../../14-frontier/AI-for-Math/02-Lean形式化数学入门.md)。

## ⚠️ 经典逻辑 vs 直觉主义逻辑

Curry-Howard **只覆盖直觉主义逻辑**——不含排中律（LEM）。

| 规则 | 直觉主义 | 经典 | 在类型论里的困难 |
|------|---------|------|-----------------|
| $A \Rightarrow \neg\neg A$ | ✓ | ✓ | 没问题 |
| $\neg\neg A \Rightarrow A$（反证法）| ✗ | ✓ | 需要" continuation "类型 |
| $A \vee \neg A$（排中律 LEM）| ✗ | ✓ | 没有对应的程序（无法构造性地选择哪边）|

**为什么 LEM 没有对应的程序**：$A \vee \neg A$ 要求你**知道**哪个成立。但构造性地，你可能既没有 $A$ 的证明也没有 $\neg A$ 的证明——LEM 断言"总有一个成立"，但不告诉你怎么找到它。

**补救**：
- **Gödel-Gentzen 翻译**：把经典逻辑嵌入直觉主义逻辑（加双否定）
- **call/cc（continuation）**：编程语言里的"经典控制流"对应经典逻辑
- **Lean 的选择**：Lean 在依赖类型论基础上**额外加了**经典公理（`Classical.choice`），所以可以写经典证明

## 🏗️ 实际应用

### 1. 定理证明器（Lean / Coq / Agda）
所有现代证明助手都基于 Curry-Howard：
- 你写的"证明"实际上是一个**类型化的程序**
- 证明检查 = **类型检查**（编译器自动完成）
- 这就是为什么 Lean 能"100% 保证证明正确"——类型系统不会撒谎

### 2. 函数式编程（Haskell / Scala / OCaml）
- 类型系统 = 轻量级证明系统
- `Maybe a` 类型 = "证明这个值可能不存在"
- `IO a` 类型 = "证明这个计算有副作用"
- Monad = "带结构的计算"（范畴论里的代数）

### 3. 程序验证
- 写一个程序 + 证明它满足规范 = 写一个**依赖类型**的程序
- 类型本身包含正确性保证（如"这个排序函数返回排好序的列表"）

### 4. 形式化数学
- Mathlib 的所有定理 = 类型化的程序
- 每个定理引用 = 函数调用
- 整个数学库 = 一个大型类型化程序库

## 🧩 Curry-Howard-Lambek 三元对应（完整版）

Lambek 1972 补全了第三元：

$$\text{直觉主义命题逻辑} \;\simeq\; \text{简单类型 } \lambda\text{-演算} \;\simeq\; \text{笛卡尔闭范畴 (CCC)}$$

三者**范畴等价**：
- 逻辑的证明规则 ↔ λ-演算的 typing rule ↔ CCC 的泛性质
- 证明变换（cut elimination）↔ β-归约 ↔ 范畴的态射等式

**深入**：[范畴论/01-范畴论作为统一语言.md](../范畴论/01-范畴论作为统一语言.md) 的"伴随"部分——$-\times B \dashv (-)^B$ 就是 currying 的范畴化。
