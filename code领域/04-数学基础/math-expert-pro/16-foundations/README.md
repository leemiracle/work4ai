# 16-foundations：数学基础与统一视角

> 解决痛点：**分支太多，没有统一**。分析、代数、几何、拓扑、逻辑各自为政，学得越多越觉得割裂。本模块不去重复各分支的内容，而是回答两个更底层的问题——数学的"地基"是什么？分支之间能否用同一种语言互相翻译？

## 核心洞察

1. **"基础"不是唯一的**：20 世纪数学曾试图找一个"唯一地基"（ZFC），但 Gödel 不完备、CH 独立性、范畴论的大小问题让这个梦想破灭。当代态度是多元主义。
2. **"统一"靠翻译**：分支间不是靠"合并"，而是靠**函子 / 对偶 / Curry-Howard** 这些精确的翻译机制互相映射。统一是"字典"，不是"合并"。
3. **抽象要分级**：范畴论是"数学的数学"，但它是**给已掌握足够多具体数学的人准备的统一工具**。跳级会迷失。
4. **三种基础互补**：ZFC 给直觉，类型论给验证（Lean），范畴论给统一——三件套并用，不冲突。

## 本模块要回答的两个问题

1. **"基础"之争**：数学最终建立在什么之上？——集合论（ZFC）、类型论（Martin-Löf / HoTT）、范畴论，三种方案各有拥护者，没有公认赢家。
2. **"统一"之桥**：分散的分支之间，有没有精确的翻译机制？——函子映射、代几对偶、Curry-Howard-Lambek 三元对应、Bourbaki 结构主义，四条路线各擅其场。

## 三大基础方案之争（地基选谁）

| 方案 | 起源 | 核心思想 | 主场领域 |
|------|------|---------|---------|
| **集合论 Set Theory (ZFC)** | Cantor 1870s → Zermelo 1908 → Fraenkel | 一切数学对象 = 集合；用 9 条公理（+AC）演绎全部 | 20 世纪数学的"事实基础" |
| **类型论 Type Theory** | Russell 1903 → Martin-Löf 1970s → HoTT 2013 | 每个对象有"类型"；命题 = 类型（Curry-Howard）| Lean / Coq / 形式化数学 |
| **范畴论 Category Theory** | Eilenberg-Mac Lane 1945 → Grothendieck | 对象本身不重要，对象之间的**态射**才重要 | 代数几何、函数式编程、统一语言 |

三者**不是非此即彼**：当代实践者通常"ZFC 直觉 + 类型论验证 + 范畴论统一"三件套并用。详见 [基础争议/01-基础论战与多元主义](./基础争议/01-基础论战与多元主义.md)。

## 四种统一视角（桥梁怎么搭）

| 代号 | 名称 | 一句话 | 代表性定理/对应 |
|------|------|--------|----------------|
| **(A)** | [函子映射 Functor Mapping](./统一视角/01-四种统一视角.md) | 用函子把分支 A 的概念精确翻译到分支 B | Galois 对应、同调函子 |
| **(B)** | [代几对偶 Algebra–Geometry Duality](./统一视角/01-四种统一视角.md) | 代数对象 ↔ 几何空间的对偶字典 | Nullstellensatz、Gelfand 对偶 |

### 本模块不做什么（边界声明）

为了避免与相邻模块重叠，本模块**刻意不涉及**以下内容：
- 具体分支的教材级内容（线性代数、实分析、抽象代数）——那是 `03-textbooks/` 与各专题目录的事。
- 单个概念的多表征（如极限的 ε-δ / 序列 / 邻域）——那是 [04-concepts/](../04-concepts/) 的事。
- 数学作为语言的修辞/文体/方言分析——那是 [13-数学作为语言/](../13-数学作为语言/) 的事。
- 数学的批判性反思（不可证性、Wigner 不合理有效性）——那是 [07-critique/](../07-critique/) 的事。

本模块只做两件事：**往下挖地基**（ZFC / 类型论 / 范畴论选谁）和**往上搭桥**（函子 / 对偶 / Curry-Howard / 结构主义四条统一路线）。

## 给学习者的建议（重要）

### ❌ 不要一上来就学范畴论

范畴论被誉为"数学的数学"，但它**是为已经掌握大量具体数学的人准备的统一工具**，不是入门教材。在没有学好线性代数、抽象代数、点集拓扑、实分析之前直接读 Mac Lane，只会感到空洞——因为你脑子里没有足够多的"具体范畴"让抽象概念落地。

推荐顺序：
1. **先打本科基础**：线性代数（LADR）、抽象代数（群环域）、点集拓扑、实分析。
2. **再用范畴论统一**：当你能在 $\mathbf{Set}, \mathbf{Vect}, \mathbf{Grp}, \mathbf{Top}$ 之间看到共通结构时，再读 Awodey 或 Leinster。
3. **最后接触高阶**：伴随、topos、monad 等概念留到研究生阶段。

### ✅ 推荐的实用组合

- **直觉层**：用 ZFC 集合论作"默认心智模型"（几乎全部本科教材都隐含 ZFC）。
- **实践层**：学一点 Lean 或 Coq，体验类型论的"证明即程序"。
- **统一层**：当某概念在多个分支重复出现时，用范畴论的语言（函子/伴随）把它收束。
- **批判层**：翻 [基础争议/01](./基础争议/01-基础论战与多元主义.md) 和 [07-critique/](../07-critique/)，知道每种基础都有边界。

### 📚 入口教材分级

| 级别 | 集合论 | 类型论 | 范畴论 |
|------|--------|--------|--------|
| 入门 | Halmos《Naive Set Theory》| Pierce《TaPL》前 9 章 | Leinster《Basic Category Theory》（免费）|
| 进阶 | Enderton《Elements of Set Theory》| HoTT Book（开源）1-3 章 | Awodey《Category Theory》|

### 🧭 怎么用这个模块

- **第一次接触"基础"问题** → 先读本 README，再看 [基础争议/01](./基础争议/01-基础论战与多元主义.md) 建立全局观。
- **学集合论课卡住** → 翻 [集合论/01](./集合论/01-集合论作为基础.md)，查 ZFC 公理与三大危机的来龙去脉。

- **想理解"分支怎么互通"** → 翻 [统一视角/01](./统一视角/01-四种统一视角.md) 的四座桥。

## 参考与方法论

本模块对应 math-expert-pro 的"高观点收束"主线：当分散学习到一定密度后，需要一层元视角把分支重新缝合。设计原则是**不替学习者学高深内容，而是给出地图与入口**——所有抽象概念都附"先学什么再看它"的前置依赖。
