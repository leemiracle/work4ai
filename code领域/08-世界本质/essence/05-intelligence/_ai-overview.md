# 人工智能总体框架 · AI Overview

> AI 回答：**如何构建能够感知、学习、推理、规划、决策和行动的智能系统。**  
> AI 不是孤立学科——是整个认识科学体系的**工程实现**。

---

## 核心定位

```
哲学→数学→逻辑→信息科学→系统科学
  →神经科学→心理学→认知科学→语言学
  →计算机科学
  → 人工智能：如何构造机器智能？  ← 所有学科的汇聚点
```

> AI 的终极问题不是"如何训练模型"，是：**如何构建能感知、学习、推理、决策和行动的智能系统。**

---

```
环境 → 感知 → 世界模型 → 学习 → 推理 → 规划 → 决策 → 行动 → 环境反馈 ↺
```

## 知识体系

```
AI
├── 一、基础（数学/概率/优化/信息论）
├── 二、学习（ML/DL/RL/自监督）
├── 三、认知（知识表示/推理/规划/决策）
├── 四、多模态（NLP/CV/Speech/VLM）
├── 五、智能体（Agent/Memory/Tool Use/Multi-Agent）
└── 六、AI工程（数据/训练/推理/部署/安全）
```

## 智能科学三层模型

```
                   智能（Intelligence）
                           │
      ┌──────────┬──────────┬──────────┐
      │          │          │
   生物智能    人类智能    机器智能
      │          │          │
   神经科学    心理学       AI
      │          │          │
      └──── 认知科学（统一理论）─────┘
                 │
              工程实现
```

> 神经科学解释智能的生物基础，心理学研究人的认知，认知科学建立统一理论，AI 是工程实现。
