# 认知科学总体框架 · Cognitive Science Overview

> 认知科学回答：**智能是如何产生的？认知是如何工作的？**  
> 不是单一学科，是跨学科领域——融合心理学/神经科学/语言学/计算机科学/哲学/人类学。

---

## 核心定位

```
心理学研究"人"
神经科学研究"脑"
人工智能研究"机器"
认知科学研究"认知机制本身"
```

> 信息如何变成知识，知识如何变成智能。

## 知识体系

```
认知科学
├── 一、信息输入（感知/注意/多模态整合）
├── 二、知识形成（学习/记忆/概念形成/知识表示）
├── 三、高级认知（推理/决策/问题解决/创造力/意识）
├── 四、实现机制（大脑/神经网络/计算模型/AI模拟）
└── 五、应用（教育/AI/人机交互/医疗/机器人/脑机接口）
```

## 方法论——多方法协同

```
提出问题 → 建立理论 → 行为实验 → 脑成像 → 计算建模 → AI模拟 → 比较验证
```

| 计算建模 | 构建理论模型 |
| AI模拟 | 验证模型能否实现 |
| 跨文化研究 | 认知的文化差异 |

## 在认知科学链条中的位置

```
                 世界
                   │
          哲学：什么是真实？
                   │
        心理学：认知有什么规律？
                   │
     神经科学：规律如何由大脑实现？
                   │
    认知科学：如何统一解释认知机制？  ← 这里
                   │
    人工智能：如何在机器中实现？
                   │
          工程应用
```

**认知科学不是心理学+神经科学+AI的简单相加**——是试图建立统一解释"认知如何产生、如何发展、如何实现"的理论框架。
