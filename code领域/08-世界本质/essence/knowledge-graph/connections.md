### 新增跨学科发现

**发现 1：控制权理论 = 机制设计理论的中国应用**
> 周雪光的"控制权理论"（目标设置权、检查验收权、激励分配权）在数学结构上等价于 Hurwicz/Maskin/Myerson 的机制设计理论——都是研究"委托人如何设计规则，使得自利的代理人在追求自身利益的同时实现委托人的目标"。区别在于：机制设计理论假设信息不对称是给定的，而周雪光揭示了信息不对称本身是制度选择的结果（运动型治理就是为了克服常规渠道的信息失真）。

**发现 2：收-放循环 = 系统控制中的极限环振荡**
> 周飞舟记录的财政体制"收-放循环"（1949-1994年六次大调整），在动力系统理论中对应"极限环"（limit cycle）——系统在两个不稳定状态之间周期性振荡。原因是：集中→信息成本过高→效率下降→放权→失控风险上升→再集中。这与 Schmidt（1997）描述的"德国财政联邦主义的钟摆"和 Oates（1972）的财政联邦主义理论形成对话。

**发现 3：土地财政 = 制度锁定**
> 周飞舟揭示的土地财政机制是一个经典的"路径依赖/锁定效应"案例：分税制（1994）→ 地方财政缺口 → 依赖土地出让金 → 推高地价 → 房地产成为支柱产业 → 更依赖土地财政。这与 Arthur（1989）的"递增报酬与路径依赖"和 David（1985）的 QWERTY 键盘分析共享同一个数学骨架——初始条件的微小差异通过正反馈循环锁定为长期结构。

**发现 4：波普尔与邓小平的隐秘对话**
> 波普尔的"渐进工程"主张（渐进改良、可纠错、反乌托邦）与中国改革的"摸着石头过河"策略，在方法论上高度同构——尽管两者的哲学出发点完全不同（波普尔从认识论出发否定历史预测的可能性；邓小平从实践理性出发拒绝教条主义）。这种"殊途同归"本身就是跨学科连接的范例。

**发现 5：共谋现象 = 信息论中的级联错误**
> 周雪光描述的基层政府共谋现象（联合造假、默契配合应对检查），在信息论框架下可以理解为"信息传递链中的系统性失真"：中央的目标信号经过省→市→县→乡的逐级传递，每一级都有动机修饰信息，导致中央收到的信号严重失真。这与 Shannon（1948）的信道噪声模型、以及 Akerlof（1970）的"柠檬市场"共享同一个结构——信息不对称导致系统退化。

## EPUB扩展的跨学科连接

> 来源：基于 6 本 EPUB 原著提取内容，新增的跨学科概念连接。

### 新增高度数概念（EPUB 扩展）

- **数目字管理** ⭐⭐⭐⭐⭐——连接历史学/经济学/信息论/治理理论
  - 黄仁宇：缺乏数目字管理 = 缺乏法律-产权-金融的基础设施
  - 对照英国 1689 年革命后的司法独立 + 议会政治 + 商业原则
  - 与现代"数字政府""数据治理"的本质区别：前者是制度问题，后者是技术问题

- **想象的共同体 / 虚构故事** ⭐⭐⭐⭐⭐——连接人类学/政治学/经济学/认知科学
  - 赫拉利：国家、公司、法律、金钱都是集体想象
  - 与 Benedict Anderson 的"想象的共同体"（民族主义）理论共振
  - 对照中国治理：党、国家、集体所有制都是"想象秩序"的实例
  - 连接哲学：制度本体论（Searle 的社会实在构造论）

- **计划 vs 市场** ⭐⭐⭐⭐⭐——连接经济学/政治学/控制论/信息论
  - 邓小平：计划和市场都是经济手段（手段中性论）
  - 陈云：计划经济为主、市场调节为辅（鸟笼经济）
  - 哈耶克：知识问题——市场的分散信息处理优于中央计划
  - 控制论视角：计划 = 集中控制回路，市场 = 分布式反馈回路
  - 信息论视角：价格系统是信息压缩-传递机制（Hayek 1945）

- **激励相容** ⭐⭐⭐⭐——连接经济学/政治学/博弈论/机制设计
  - 置身事内：事权划分三大原则之一
  - 机制设计理论（Hurwicz-Maskin-Myerson）：让个人最优 = 社会最优
  - 对照中国"GDP 锦标赛"：地方官员激励与经济增长

- **预算约束软化** ⭐⭐⭐⭐——连接经济学/制度经济学/财政学
  - Kornai 软预算约束理论 → 城投债、地方融资平台
  - 置身事内：预算外收入膨胀 = 约束软化的制度基础
  - 连接委托-代理理论：中央委托 → 地方代理 → 约束失灵

### 跨学科发现

**发现 1：货币乘数 = 生物繁殖的离散映射**
> 银行的部分准备金制度（存 100 贷 90 存 90 贷 81...）在数学上等价于细菌的指数增长（N_t = N_0 × r^t）和模因的传播链条。三者共享同一个骨架：**离散迭代的无穷级数**。区别在于：细菌增长受资源限制，货币乘数受准备金率限制，模因传播受注意力限制。

**发现 2：金融周期 = 控制系统的极限环振荡**
> Minsky 的金融不稳定假说（稳定→投机→崩盘→复苏）在动力系统理论中对应"极限环"——系统在两个状态间周期振荡。这与周飞舟记录的财政"收-放循环"（见政治连接）完全同构。两者都源于：**负反馈的延迟**——当调节者反应太慢，系统已经从一端摆到另一端。

**发现 3：市场效率 = 演化均衡**
> 有效市场假说（EMH）不是物理定律，而是**演化结果**——不有效的策略被淘汰，有效的被复制。但 Grossman-Stiglitz 悖论说，完全有效时信息搜集无利可图→策略被淘汰→市场又不有效。这是**演化博弈的均衡**——效率在"足够多人努力"的水平上振荡。与生态系统的"红皇后效应"（必须不停跑才能留在原地）同构。

**发现 4：金融 = 跨期信任的工程化**
> 所有金融产品本质都是"今天的确定换明天的不确定"的契约——这些契约成立的唯一基础是**信任**。这与 DNA（跨代的信息承诺）、合法性（跨期的权力信任）、合作演化（跨期的互惠信任）共享同一个深层结构：**复杂系统需要跨时间的承诺机制对抗熵增**。详见 [`insights/2026-07/2026-07-16-finance-is-intertemporal-trust.md`](../insights/2026-07/2026-07-16-finance-is-intertemporal-trust.md)。

- **价值的主观/客观之争**：劳动价值论（马克思，客观）vs 边际效用（主观）vs 市场共识（建构）——与 Q2"本质是什么"的哲学根源同构
