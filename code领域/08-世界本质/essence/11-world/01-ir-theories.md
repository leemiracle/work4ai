> 调用思想家：霍布斯（利维坦）、韩非子（法术势）、洛克（政府论）、`game-theorist`（博弈论）

## 一、国家是什么——从部落到主权国家

### 国家的四要素

```
领土 + 人民 + 政府 + 主权 = 国家
```

### 国家如何形成？——韦伯的定义

韦伯说国家 = "在特定领土内**合法垄断暴力**的人类共同体"。

关键不是"有暴力"，是"**合法垄断**"——只有国家可以合法使用暴力（警察/军队），其他人使用暴力是非法的。这个垄断是秩序的基础。

### 费曼问题：为什么需要"垄断暴力"？

**一句话**：因为如果人人都能合法使用暴力，就是霍布斯的"自然状态"——所有人对所有人的战争。

**连接图**：
```
无垄断暴力 → 人人自卫 → 弱肉强食 → 安全无保障 → 霍布斯"自然状态"
  ↓
垄断暴力 → 只有国家可合法用武 → 秩序 → 安全 → 合作可能
  ↓
但：垄断者可能滥用暴力 → 需要限制国家权力（宪政/分权）
```

**反问**：如果国家垄断了暴力但滥用它，比"自然状态"好还是坏？

→ 霍布斯说好（至少有秩序）。洛克说可能更坏（有组织的暴政比无组织的暴力更可怕）。**这就是"安全vs自由"的根本张力——从国内延伸到国际。**

> **调用**：→ `thinkers/western.md` 霍布斯（利维坦）、洛克（政府论）；→ `09-ideologies/ideological-lenses.md`——"安全vs自由"矩阵

## 二、国际关系三大理论——三种看世界的镜片

### 2.1 现实主义：权力至上

**核心**：国际体系是"无政府状态"（没有世界政府）→ 国家必须自助 → 安全是首要目标 → 权力是保障安全的工具。

```
无政府状态 → 无终极裁判 → 国家只能靠自己
  ↓
靠自己 → 需要权力（军事/经济）→ 权力越大越安全
  ↓
但：他国也在积累权力 → 安全困境（Security Dilemma）
  ↓
你增强军力为了防御 → 他国看作威胁 → 也增强军力 → 双方更不安全
```

### 费曼问题：为什么"防御性"军备会让对方更不安全？

**一句话**：因为对方无法区分你的军备是"防御"还是"进攻"——枪不分好坏，只分谁拿着。

**博弈论分析**：

> **调用：`game-theorist`（迁移精度：高）**

```
安全困境 = 囚徒困境的国际版
  - 双方都不扩军 → 都安全（合作解）
  - 但各自扩军是占优策略（不管对方怎样，扩军更安全）
  - 结果：双方都扩军 → 都更不安全（纳什均衡=次优解）
  ↓
= 理性个体选择 → 集体非理性结果
```

**反问**：安全困境能破解吗？

→ 部分可以：军控条约（可信承诺）、透明度（让对方看到你是防御）、多边机制（把双边博弈变成多边）。但**信任是稀缺品**——尤其在大国之间。

> **关联**：→ mental-models.md #6（囚徒困境/纳什均衡）；→ `thinkers/chinese.md` 韩非子——"势"的分析：无政府状态下，势=权力

### 2.2 自由主义：合作可能

**核心**：国家不仅竞争，也可以合作。合作的基础是：贸易相互依赖、国际组织、国际规则、民主制度。

```
贸易 → 相互依赖 → 战争成本升高 → 和平更可能
  ↓
国际组织 → 提供信息/降低交易成本/创造重复博弈 → 合作更可能
  ↓
民主制度 → 民主国家之间不打仗（民主和平论）→ 民主扩大→和平扩大
```

### 费曼问题：贸易真的能促进和平吗？

**一句话**：部分能——贸易提高了战争成本。但贸易也可能制造**不对称依赖**（一方更依赖另一方→被武器化）。

**反事实**：如果中美贸易完全脱钩，战争概率升高还是降低？

→ 自由主义说升高（相互依赖降低→战争成本降低）。现实主义说可能降低（脱钩减少了冲突的经济诱因）。**两种理论给出相反预测——说明贸易与和平的关系不是线性的。**

> **关联**：→ `thinkers/western.md` 洛克（契约论——国际规则是"国家间的契约"）；→ `thinkers/western.md` 康德（永久和平论——共和制+联邦+世界公民权利）

### 2.3 建构主义：观念塑造行为

**核心**：国家行为不只受利益/权力驱动，也受**身份/观念/历史经验**塑造。

```
现实主义：利益 → 行为（利益是客观的）
自由主义：制度 → 行为（制度约束选择）
建构主义：身份 → 利益 → 行为（身份定义什么是"利益"）
```

### 费曼问题：为什么美国把中国的崛起看作"威胁"而把欧盟的崛起不看作威胁？

**一句话**：因为美国和欧盟有**共享的身份认同**（民主/西方/盟友），而美国和中国没有。

```
身份认同 → 定义"谁是朋友谁是敌人" → 定义"什么是威胁"
  ↓
美欧：共享身份 → 不互视为威胁 → 安全困境弱
美中：身份不同 → 互视为潜在威胁 → 安全困境强
  ↓
= 不只是"权力"决定威胁感知，"身份"也决定
```

> **调用**：→ `thinkers/western.md` 曼海姆（知识社会学——"利益"本身就是观念建构）；→ `09-ideologies/_philosophy-of-ideology.md`——国家身份本身就是意识形态建构

## 三、国际政治——权力的全球分配

### 3.1 权力格局的演变

```
多极（1648-1945）→ 两极（1945-1991）→ 单极（1991-2008）→ 多极化（2008-）
```

### 3.2 修昔底德陷阱

```
崛起国（中国）vs 守成国（美国）
  ↓
崛起国实力增长 → 守成国恐惧 → 双方误判可能 → 战争风险
  ↓
历史上16次中12次发生战争（75%）
  ↓
但：历史是模式不是机制（insight #12）——核威慑改变了战争代价
```

### 费曼问题：修昔底德陷阱能避免吗？

**一句话**：能，但需要**双方的战略克制+制度安排**——历史上避免战争的4次都靠制度化沟通（如美苏冷战中的热线/军控条约）。

**7维分析**：
1. 背景：中美力量差距缩小
2. 参与者：中美+盟友+国际组织
3. 利益：中国=发展空间；美国=维持秩序
4. 能力：经济互赖+军事差距缩小+科技竞争
5. 规则：WTO/联合国/国际法——但效力下降
6. 结果：共存/竞争/脱钩——三种情景
7. 理论：现实主义看到安全困境；自由主义看到合作可能；建构主义看到身份冲突

> **关联**：→ `10-china/06-future.md`——三种情景分析；→ `thinkers/social-theorists.md` 托克维尔（大国兴衰）；→ insight #12（维特根斯坦——历史是模式不是机制）

## 四、地缘政治——地理如何影响战略

### 4.1 海权 vs 陆权

```
海权论（马汉）：控制海洋→控制贸易→控制世界
  → 美国：海军+航母+岛链
  ↓
陆权论（麦金德）：控制欧亚大陆心脏地带→控制世界
  → 俄罗斯/中国：陆上交通+一带一路
  ↓
空权/天权：飞机+卫星→三维控制
  → 美国：空军+GPS+太空军
```

### 4.2 关键地缘节点

| 节点 | 为什么重要 | 控制方 | 风险 |
|------|-----------|--------|------|
| 马六甲海峡 | 中国80%石油经此 | 美国（海军）| 封锁→能源危机 |
| 台湾海峡 | 半导体+第一岛链 | 争议 | 冲突→全球芯片断供 |
| 苏伊士运河 | 欧亚海运捷径 | 埃及 | 阻塞→全球物流紊乱 |
| 霍尔木兹海峡 | 全球20%石油经此 | 伊朗 | 封锁→能源危机 |

### 费曼问题：为什么中国修"一带一路"？

**一句话**：因为马六甲海峡是中国的"咽喉"——一旦被封锁，能源断供。一带一路是**陆上替代路线**，降低对海路的依赖。

**连接图**：
```
马六甲困局 → 海路被美国控制 → 能源安全脆弱
  ↓
一带一路 → 陆路替代（中巴经济走廊/中欧班列）→ 降低海路依赖
  ↓
= 地缘战略：从"海权依赖"转向"海陆并重"
```

> **关联**：→ `10-china/01-natural-environment.md`——地理约束的延续；→ `thinkers/chinese.md` 韩非子——"势"的地缘分析

## 五、全球经济政治——经济与权力的交织

### 5.1 贸易武器化

```
贸易不只是经济 → 也是权力工具
  ↓
关税/制裁/出口管制/技术封锁 = "经济战"
  ↓
例子：芯片封锁、SWIFT制裁俄、稀土出口管制
```

### 5.2 供应链作为地缘武器

> **调用：熊彼特·创造性破坏 + 波兰尼·嵌入/脱嵌**

```
全球化供应链 → 效率最优但脆弱
  ↓
地缘竞争 → 供应链"武器化"（断供/制裁）
  ↓
各国策略：从"效率优先"转向"安全优先"
  - 中国：自研芯片/储备稀土/内循环
  - 美国：友岸外包/芯片法案/去风险
  ↓
= 全球化部分逆转 → 从"一个体系"到"两个体系"？
```

### 费曼问题：经济相互依赖促进了和平还是制造了新冲突？

**一句话**：两者都有——相互依赖降低了战争概率（成本高），但创造了新的冲突形式（贸易战/科技战/金融战）。

```
传统战争（军事）→ 成本太高 → 减少
  ↓ 但
新型冲突（经济/科技/信息）→ 成本较低 → 增加
  ↓
= 战争形式在变，不是冲突在减少
```

> **关联**：→ `10-china/05-economy.md`——半脱嵌经济；→ insight #21（深圳乘法模型——供应链是乘数之一）

## 六、国际组织与全球治理

### 6.1 为什么需要国际组织？

```
无政府状态 → 国家间缺乏信任 → 需要中介/规则/信息
  ↓
国际组织 → 提供论坛/规则/信息/监督 → 降低交易成本 → 促进合作
  ↓
但：国际组织没有强制力 → 依赖大国支持 → 大国不配合就无效
```

### 6.2 主要国际组织

| 组织 | 功能 | 局限 |
|------|------|------|
| 联合国 | 安全/人权/发展 | 安理会一票否决→大国不配合则无效 |
| WTO | 贸易规则/争端 | 上诉机构瘫痪→规则执行力下降 |
| IMF/世界银行 | 金融稳定/发展 | 美国主导→代表性不足 |
| AIIB/金砖银行 | 基建/发展 | 新兴→但规模仍小 |

### 费曼问题：国际组织是"全球治理"还是"大国工具"？

**一句话**：两者都是——国际组织既是规则提供者（全球治理），也反映了创建时的权力分配（大国工具）。

**哈贝马斯检验**：

> **调用：哈贝马斯·交往理性（迁移精度：高）**

国际组织在理想情况下应该满足"交往理性"四条件（无强制/对称信息/所有受影响者参与/只认论证）。但现实：
- 安理会五票否决→有强制（大国>小国）
- 信息不对称→强国信息多
- 不是所有受影响者参与（如气候谈判中被排除的最穷国）
- 论证让位于权力

**洞察**：国际组织是"不完美的公共领域"——比没有好，但远未满足交往理性。改进方向=让更多声音参与、让规则更公平。但这需要大国让步——而大国不会自愿让步。

> **关联**：→ insight #27（哈贝马斯——中国有公共领域吗）——国际组织是全球版的"公共领域"

## 八、综合：认识世界的"操作系统"

### 三大理论的分工

```
现实主义：看"硬实力"（军事/经济）→ 安全问题
自由主义：看"软规则"（贸易/组织/制度）→ 合作问题
建构主义：看"软身份"（观念/历史/认同）→ 信任问题
  ↓
三者不是非此即彼——是互补的镜片
不同问题用不同镜片：军事冲突→现实主义；贸易谈判→自由主义；战略互疑→建构主义
```

### 费曼复述（一句话）

> 认识世界就像下棋——棋盘是地理（地缘政治），棋子是国家（权力/能力），规则是国际法/组织（自由主义），但每个棋手还有自己的"性格"（建构主义：身份/历史/观念）。现实主义教你"看棋子的力量"，自由主义教你"看规则如何约束棋手"，建构主义教你"看棋手为什么这样想"。三个镜片一起用，才能看懂这盘棋。
