## 一、地缘政治的核心命题

### 命题 1 · 地理塑造国家行为

```
地理 → 资源 → 经济 → 军事 → 外交
  ↑                              ↓
  └────── 反馈 ←─────────────────┘
```

**关键地理要素**：
- **海陆位置**——海权国（美/英/日）vs 陆权国（俄/德/中）
- **资源禀赋**——能源/粮食/矿产的自给程度
- **战略纵深**——俄罗斯的纵深 vs 以色列的缺乏
- **邻国结构**——友好/敌对/不稳定

### 命题 2 · 欧亚大陆是"大棋盘"

**布热津斯基命题**（A4）：全球霸权的重心在欧亚大陆——谁控制欧亚大陆谁控制世界。

```
欧亚大陆
├── 西端：欧盟（民主桥头堡）
├── 中部：黑海/里海/中亚（"欧亚巴尔干"——资源+碎片化）
├── 东端：中国（"东方巨龙"——潜在挑战者）
├── 南亚：印度（"远东之锚"候选）
└── 地缘轴心：乌克兰/土耳其/伊朗/韩国
```

**地缘轴心**（pivot）：
- **乌克兰**——远离俄罗斯则俄罗斯降为地区国家
- **土耳其**——控制黑海海峡+中亚通道
- **伊朗**——连接波斯湾+里海+中亚
- **韩国**——远东力量平衡的关键

### 命题 3 · 海权 vs 陆权

**Mahan 海权论**（1890）：控制海洋=控制世界——海军+商业船队+海外基地

**Mackinder 心脏地带论**（1904）：控制东欧=控制心脏地带=控制世界岛（欧亚大陆）=控制世界

```
海权（美/英/日） vs 陆权（俄/德/中）
  ↓                    ↓
离岸平衡            大陆霸权
  ↓                    ↓
维持欧亚分裂        统一欧亚大陆
```

**当代应用**：
- 美国"离岸平衡"——防止欧亚出现霸权
- 中国"一带一路"——连接欧亚大陆（陆权复兴？）
- 俄罗斯——心脏地带的衰退者

## 二、中国的地缘战略

### 地理条件

```
中国地理
├── 海陆复合——既有海疆又有大陆
├── 14 个陆上邻国——世界最多
├── 三级阶梯——西高东低
├── 主要河流——自西向东（黄河/长江/珠江）
├── 缺乏天然屏障——北方平原易受入侵
└── 海疆——第一岛链（日韩台菲）+ 第二岛链（关岛）
```

### 地缘挑战

1. **第一岛链封锁**——美日韩台菲形成海上封锁线
2. **马六甲困境**——80% 能源运输经过马六甲海峡——易被封锁
3. **北方威胁减弱**——中俄关系改善——但历史不信任
4. **西部不安**——新疆/西藏的地缘+民族
5. **南方争议**——南海九段线+台海

### "一带一路"的地缘逻辑

```
丝绸之路经济带（陆）——连接中亚/俄罗斯/欧洲
  ↓
打破马六甲困境+拓展陆权
  +
21世纪海上丝绸之路（海）——连接东南亚/南亚/非洲/欧洲
  ↓
突破第一岛链+保障海上通道
```

**评价**：
- **机遇**：拓展战略纵深+保障资源通道+输出产能
- **风险**：投资回报不确定+地缘政治反弹+债务陷阱批评
- **本质**：中国从"陆权"向"海陆复合"的战略转型

## 三、中美博弈的地缘结构

### 修昔底德陷阱

**命题**（Allison）：崛起国与守成国必然冲突——16 个案例中 12 个发生战争。

**中美案例**：
- 崛起国：中国——GDP 接近美国 70%（按 PPP 已超）
- 守成国：美国——维护二战后秩序
- 结构性矛盾：贸易/科技/台海/南海/盟友体系

### 美国对华战略演变

```
接触（1972-2016）——通过贸易促进中国"和平演变"
  ↓
竞争（2017-）——"战略竞争"取代"接触"
  ↓
科技脱钩+盟友围堵+台海强化
```

**关键文件**：
- 2017《国家安全战略》——中国定位为"战略竞争对手"
- 2022《印太战略》——强化盟友体系
- 芯片管制——科技脱钩

### 中国应对

- **"双循环"**——以内循环为主+国际循环为辅
- **科技自立**——"卡脖子"技术攻关
- **军事现代化**——反介入/区域拒止（A2/AD）
- **外交多元**——"全球南方"+BRICS+

## 四、地缘政治的理论工具

### 现实主义（Morgenthau/Waltz/Mearsheimer）

- 国际体系无政府——国家自利+权力最大化
- 安全困境——一国增防→他国感知威胁→军备竞赛
- 均势——国家联合制衡霸权

### 自由主义（Keohane/Nye）

- 相互依赖降低战争概率
- 国际制度降低交易成本
- 民主和平论——民主国家不打仗

### 建构主义（Wendt）

- "无政府是国家造就的"——观念塑造利益
- 认同决定行为——"中国威胁论"vs"中国机遇论"

### essence 立场

**MANIFESTO 第十二条**：三理论作为"镜片"切换——
- 戴现实主义镜片：中美博弈是结构性的——权力转移
- 戴自由主义镜片：经济相互依赖+制度合作可能
- 戴建构主义镜片：观念改变=行为改变——避免"自我实现的预言"
