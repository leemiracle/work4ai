## 分析任何国际事件的7维框架

面对任何国际事件，按以下7个维度分析：

1. **背景**：历史、地理、相关国家基本情况
2. **参与者**：国家/国际组织/企业/其他行为体
3. **利益**：各方追求什么？安全/经济/政治利益
4. **能力**：各方资源和影响力
5. **规则**：涉及哪些国际法/条约/机制
6. **结果**：短期和长期影响
7. **理论视角**：现实主义/自由主义/建构主义分别怎么解释
