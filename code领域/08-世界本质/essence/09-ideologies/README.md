# 09-ideologies · 意识形态与思潮

> 各种"主义"作为**被研究的客体**和**看世界的镜片**。

⚠️ **进入此目录前，必先读 [`_philosophy-of-ideology.md`](./_philosophy-of-ideology.md)**。  
它会防止你的"研究"偷偷变成"站队"。

---

## 这个目录是什么

这里收录各种**意识形态 / 思潮**——社会主义、资本主义、自由主义、保守主义、无政府主义、民族主义、女权主义、环保主义……

它们不是学科（学科按研究对象分，价值中立），而是**价值立场的系统化**（它们回答"社会应该怎样"）。因此这个目录的用法和 `01-08` 不同：见哲学锚点的"范畴区分"一节。

---

## 核心原则

1. **镜片，不是立场**。思潮是用来戴上摘下看世界的，不是用来纹在身上的。
2. **钢铁侠优先**。研究任何思潮，先建构它的最强版本，再批评。稻草人批评不算研究。
3. **必须交叉**。研究一个思潮，必须同时看它的对手怎么回应——否则你只听到了一面之词。
4. **历史化**。思潮不是永恒真理，它是特定历史困境的回应。问"它在当时解决了什么"。
5. **批判化**。问"这套方案的前提是什么？谁受益？前提不成立时会怎样？"

## 思潮清单（按探索优先级排列）

| 思潮 | 状态 | 核心张力 |
|------|------|---------|
| [`socialism/`](./socialism/_overview.md) | 🟡 骨架 | 平等 vs 效率；计划 vs 自发秩序 |
| [`capitalism/`](./capitalism/_overview.md) | 🟡 骨架 | 自由 vs 剥削；创新 vs 不平等 |
| `liberalism/` | ⬜ 待建 | 个人自由 vs 集体善；消极自由 vs 积极自由 |
| `conservatism/` | ⬜ 待建 | 传统 vs 进步；秩序 vs 自由 |
| `anarchism/` | ⬜ 待建 | 自由 vs 秩序如何可能无权威地维持 |
| `nationalism/` | ⬜ 待建 | 归属 vs 普遍主义；建构 vs 本质 |
| `feminism/` | ⬜ 待建 | 性别的本质；公私领域的政治化 |

> 清单会扩展。但记住 MANIFESTO 的心法：**宁深勿广**。一个思潮想透 > 八个思潮浅尝。

## 每个思潮子目录的规范

当你开始探索某个思潮时，在其子目录里建：

1. `_overview.md` —— 一句话定义、核心主张、内部派别、核心争论（已有模板见 socialism/）
2. `_philosophy-of-X.md` —— 这个思潮的本体论/认识论/方法论假设
3. `key-thinkers.md` —— 代表人物与核心文本
4. `internal-debates.md` —— 内部派别争论（防止把思潮当成铁板一块）
5. `critique-from-opponents.md` —— 对手怎么批评它（强制交叉视角）
6. 按需长出的概念笔记
