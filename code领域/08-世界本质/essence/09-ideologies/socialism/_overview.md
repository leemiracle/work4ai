# Socialism · 社会主义

> ⚠️ 这是一份骨架，不是研究结论。下面的每一句都应被你质疑、补充、修正。

---

## 一句话

生产资料应**社会化**（非私人所有），财富分配应更**平等**，因为资本主义的自由是"形式上的自由"而掩盖了实质的不自由。

## 核心主张（钢铁侠版）

1. **劳动创造价值**，资本不创造——资本收益是对劳动的占有（剩余价值理论）
2. **生产资料的私人占有**导致结构性不平等，靠个人努力无法消解
3. **市场自发秩序**会走向垄断和危机（生产社会化 vs 占有私人化的矛盾）
4. **民主应延伸到经济领域**——工厂里的专制和政治上的民主是矛盾的

## 内部派别（它不是铁板一块）

| 派别 | 核心差异 | 代表 |
|------|---------|------|
| 社会民主主义 | 保留市场 + 二次分配 + 福利国家 | 北欧模式、伯恩斯坦 |
| 马克思列宁主义 | 先锋党 + 计划经济 + 无产阶级专政 | 苏联模式 |
| 民主社会主义 | 议会道路 + 生产资料渐进社会化 | 考茨基、科尔宾 |
| 市场社会主义 | 所有权社会化但保留市场配置 | 兰格、罗默 |
| 自由意志马克思主义 | 反国家、反先锋党，保留马克思主义批判 | 乔姆斯基、早期委员会共产主义 |
| 空想/伦理社会主义 | 不诉诸历史必然性，强调道德召唤 | 欧文、费边社 |

> **注意**：这些派别之间的分歧，可能比它们与资本主义的分歧还大。"社会主义"是一个**家族相似**概念，不是一个本质。

## 核心争论

- **计划经济的信息问题**：哈耶克论"知识在社会中的运用"——价格是分散信息的汇聚，计划者无法拥有这些信息。社会主义如何回应？
- **激励问题**：去掉私有利润后，创新和努力的激励从哪来？
- **国家权力悖论**：生产资料社会化需要强大国家，但强大国家会异化为新统治阶级（官僚阶层）。如何驯服？
- **历史预言的失败**：马克思预言革命发生在发达资本主义，实际发生在落后农业国。为什么？

## 它解决了什么真问题（历史语境）

- 19 世纪工人阶级的**极端贫困**（每天 14 小时、童工、无保障）
- 资本的**不受约束的权力**（工厂主就是工厂里的专制君主）
- **周期性经济危机**（大萧条式的崩盘）

## 它的对手怎么说

见（待建）`critique-from-opponents.md`。关键反对：
- 奥地利学派：价格信号不可替代
- 公共选择学派：官僚也是自利的，计划者不会更善良
- 经验证据：20 世纪的实践记录
