# Capitalism · 资本主义

> ⚠️ 这是一份骨架，不是研究结论。下面的每一句都应被你质疑、补充、修正。

---

## 一句话

生产资料**私人所有**，资源配置靠**市场交换**和**价格信号**，行为主体追求**自利**——这套机制自发产生了秩序、创新和繁荣，但也产生了不平等和异化。

## 核心主张（钢铁侠版）

1. **主观价值论**：价值不是劳动创造的，而是个体主观评价的——交换之所以发生，因为双方都觉得自己赚了（正和博弈）
2. **价格是信息**（哈耶克）：价格汇聚了全社会分散的、无法被任何人掌握的知识，是最有效的信号机制
3. **自发秩序**：没有人设计市场，但它自发产生协调；正如没有人设计语言，但它自发产生沟通
4. **利润是创新的奖励**（熊彼特）：企业家打破均衡，创新带来"创造性破坏"，利润是对承担风险的补偿
5. **私产是自由的基础**（洛克/诺齐克）：没有私产就没有自由——你的劳动成果被夺走，你就是奴隶

## 内部派别（它不是铁板一块）

| 派别 | 核心差异 | 代表 |
|------|---------|------|
| 古典自由主义 | 最小国家 + 自由放任 | 斯密、洛克 |
| 奥地利学派 | 主观主义 + 自发秩序 + 反计划 | 门格尔、米塞斯、哈耶克 |
| 芝加哥学派 | 新古典 + 经验实证 + 反垄断 | 弗里德曼、斯蒂格勒 |
| 自由意志主义 | 最小国家甚至无国家 + 绝对财产权 | 罗斯巴德、诺齐克 |
| 秩序自由主义 | 市场需要**秩序框架**（法治+竞争政策） | 欧肯、德国社会市场经济 |
| 凯恩斯主义 | 市场会失灵，需要宏观干预 | 凯恩斯（严格说是资本主义内部改良）|

> **注意**：凯恩斯和哈耶克同属"资本主义阵营"，但分歧巨大——一个要干预，一个要放任。把"资本主义"当成统一立场是稻草人。

## 核心争论

- **不平等问题**：市场产生的不平等是"自由的代价"还是"自由的背叛"？罗尔斯 vs 诺齐克
- **外部性**：污染、气候——市场无法内化的成本怎么处理？
- **垄断趋势**：竞争会自发走向垄断吗？如果是，"自发秩序"自我否定？
- **劳动异化**：马克思的批评——资本主义让人的劳动失去意义，变成工具
- **周期性危机**：繁荣-萧条循环是市场的"自我修正"还是系统缺陷？
- **金融化**：当利润主要来自金融投机而非生产，资本主义在"空心化"？

## 它解决了什么真问题（历史语境）

- **稀缺问题**：市场经济比计划经济更好地解决了大规模资源配置（20 世纪的实验对比）
- **创新激励**：利润驱动产生了人类历史上最快的科技/组织创新
- **协调问题**：数亿人的分散决策通过价格自发协调，无需中央计划

## 它的对手怎么说

见（待建）`critique-from-opponents.md`。关键反对：
- 马克思主义：剥削、异化、危机必然性
- 社会民主主义：不平等不可接受，需要二次分配
- 保守主义：市场腐蚀传统和共同体（这批评来自"右"而非"左"）
- 卡尔·波兰尼：《大转型》——市场不是"自然的"，它是被国家权力**建构**出来的
