## 一、MANIFESTO 第十二条回顾

> **铁律**：研究任何思潮，先建构它的最强版本，再批评。任何结论必须经过至少两副对立镜片的检验。

**七副镜片**：
1. 马克思主义——矛盾分析+唯物史观+意识形态批判
2. 奥地利学派——主观主义+自发秩序
3. 保守主义——反激进+传统作为智慧
4. 自由主义——契约论+权利边界
5. 批判理论——意识形态批判+工具理性批判
6. 女权主义——个人即政治+立场认识论
7. 环保主义——代际正义+增长极限

## 二、51 本书 × 七副镜片

### 马克思主义镜片

**核心问题**：谁受益？掩盖了什么矛盾？

| 书目 | 马克思主义解读 |
|------|-------------|
| E1 毛泽东文集 | 马克思主义中国化——阶级分析+继续革命 |
| E2 邓小平文选 | 社会主义市场经济——半脱嵌的理论基础 |
| D4 政治的逻辑 | 马克思主义政治学原理 |
| B1 周雪光 | 国家作为阶级矛盾不可调和的产物——但周偏组织分析 |
| G1 孙隆基 | "大共同体"作为统治阶级的工具 |
| F5 孙萍 | 平台资本对劳动的剥削——算法异化 |

### 自由主义镜片

**核心问题**：契约能同意吗？权利被侵犯了吗？

| 书目 | 自由主义解读 |
|------|-----------|
| A1 波普尔 | 反极权——保护个人自由 |
| A3 秦晖 | 大共同体压制个人——需要小共同体缓冲 |
| D6 王沪宁《美国反对美国》 | 美国多元主义作为自由范本 |
| F1 陶然 | 土地产权改革——市场化方向 |
| F2 周其仁 | 城乡二元破坏自由选择 |

### 保守主义镜片

**核心问题**：现状解决了什么问题？激进改革的风险？

| 书目 | 保守主义解读 |
|------|-----------|
| I2 钱穆 | 传统政治有内在合理性——"温情与敬意" |
| I1 黄仁宇 | 制度失败的深层原因——不是简单"专制" |
| I3 李瑞环 | 实践智慧优于激进理论 |
| A1 波普尔 | 零星工程优于乌托邦工程 |
| B1 周雪光 | 运动式治理的危险——破坏常规 |

### 批判理论镜片（法兰克福学派）

**核心问题**：工具理性如何吞噬意义？"常识"里的权力？

| 书目 | 批判理论解读 |

| C1-4 习近平谈治国理政 | 官方话语作为意识形态机器 |
| D3 王沪宁《政治的人生》 | 学者从仕——知识分子的体制俘获 |

### 女权主义镜片

## 四、操作建议

### 每周仪式

1. 选一本政治类书目
2. 戴上三副不同镜片各读一遍
3. 记录每副镜片看到什么+看不到什么
4. 问：哪副镜片让我最不舒服？那副可能揭示了我的盲点

### Council 审议

对关键议题（如中国模式/房地产/数字治理），用 `/council` 召集多角色审议——每位角色戴一副镜片。
