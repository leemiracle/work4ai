# 认识中国知识树 · China Knowledge Tree

> 借鉴计算机系统（硬件→操作系统→应用）、复杂系统和费曼学习法。  
> 每一层建立在前一层之上。不是零散学习，而是**从底层到上层**的系统构建。

---

## 10 个模块

| 模块 | 核心问题 | 关键费曼问题 | 时间 |
|------|---------|------------|------|
| 1. 自然环境 | 自然如何影响文明？ | 为什么人口集中在东部？ | 2-3周 |
| 2. 历史 | 今天的中国为什么是这样？ | 为什么统一？为什么分裂？为什么再统一？ | 8-10周 |
| 3. 文化 | 中国人的思维为什么这样？ | 儒/道/法/佛各解决什么问题？ | 3-4周 |
| 4. 政治制度 | 国家如何运行？ | 为什么需要制度？ | 2-3周 |
| 5. 经济 | 钱怎样流动？ | 为什么沿海先发展？ | 3周 |
| 6. 科技 | 科技如何推动经济？ | 芯片/AI/高铁如何改变格局？ | 2-3周 |
| 7. 社会 | 社会如何变迁？ | 为什么老龄化？为什么城市化？ | 2周 |
| 8. 国际关系 | 中国与世界？ | 为什么国际合作重要？ | 2周 |
| 9. 未来 | 未来二十年？ | AI/碳中和/老龄化如何塑造未来？ | 2周 |
| 10. 综合分析 | 任何问题能拆解 | 高铁→物流→经济→人口→战略→国际竞争 | 持续 |

## 6 卷课程结构

| 卷 | 标题 | 内容 |
|----|------|------|
| 第一卷 | 《自然中国》 | 地理、气候、资源、人口——物理基础 |
| 第二卷 | 《历史中国》 | 从史前到现代——文明形成 |
| 第三卷 | 《文化中国》 | 思想、文学、艺术——思维方式 |
| 第四卷 | 《制度中国》 | 政治、法律、行政——国家运行 |
| 第五卷 | 《经济中国》 | 产业、金融、区域、科技——发展逻辑 |
| 第六卷 | 《未来中国》 | AI、人口、能源、国际——未来趋势 |

## 每卷统一结构

1. **提出问题**（为什么会这样？）
2. **历史背景**（如何形成的？）
3. **底层原理**（运行机制是什么？）
4. **案例分析**（真实案例）
5. **费曼复述**（用自己的话讲出来）
6. **知识网络图**（与其他模块连接）
7. **思考题与拓展阅读**

## 每个知识点的费曼四步

1. **一句话解释**：不用术语，用自己的话
2. **画图连接**：与已学内容连接（黄河→农业→人口→城市→国家）
3. **举现实例子**：改革开放→深圳、浦东
4. **提出反问**：如果没有长江，经济重心还会南移吗？

## 与 essence 项目的交叉

| 模块 | 使用的思想家/方法论 |
|------|-------------------|
| 1. 自然环境 | `genealogist`（追问"地理决定论"的来历）+ 第一性原理 |
| 2. 历史 | `dialectician`（统一-分裂-再统一的辩证）+ `historian` |
| 3. 文化 | 已有思想家库：孔子/老子/庄子/荀子/韩非/王阳明/朱熹 |
| 4. 政治制度 | `institution-designer`（荀子）+ `strategist-eastern`（韩非子）+ `power-self-understanding`研究样本 |
| 5. 经济 | 熊彼特（创造性破坏）+ 韦伯（理性化）+ 波兰尼（嵌入/脱嵌） |
| 6. 科技 | 库恩（范式）+ 哥德尔（AI的局限）+ 熊彼特（创新） |
| 7. 社会 | 托克维尔（民主病理）+ 福柯（规训/人口治理） |
| 8. 国际关系 | 马基雅维利+韩非子+博弈论 |
| 9. 未来 | 波普尔（可证伪）+ 庄子（齐物——不执着于预测）|
| 10. 综合分析 | 所有工具的总调用 |
