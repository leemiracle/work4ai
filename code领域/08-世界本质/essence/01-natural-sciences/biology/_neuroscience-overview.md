# 神经科学总体框架 · Neuroscience Overview

> 神经科学回答：**心理活动是如何由神经系统实现的？**  
> 连接生物学、医学、心理学、计算机科学和人工智能。

---

## 核心模型：神经系统=多层级信息处理系统

```
外部世界 → 感觉器官(输入) → 神经信号编码 → 神经网络计算 → 大脑功能整合 → 认知/情绪/决策/行为(输出) → 身体运动 → 环境反馈 ↺
```

> 神经科学研究的是：**神经系统如何把物理世界的信息转换成行为和认知。**

---

## 七层研究层次

| 层次 | 研究什么 | 核心问题 |
|------|---------|---------|
| 分子 | DNA→RNA→蛋白质→离子通道→神经递质 | 神经元为什么能工作？ |
| 细胞 | 神经元（树突→胞体→轴突→突触） | 神经信息如何传递？ |
| 神经回路 | 千百神经元组成的网络 | 功能如何涌现？ |
| 脑区 | 额叶/顶叶/枕叶/颞叶/海马/杏仁核 | 各区负责什么？ |
| 脑网络 | 多系统协作（视觉/听觉/运动/奖赏/注意/语言）| 复杂任务如何完成？ |
| 行为 | 学习/奖励/强化/成瘾/睡眠 | 神经如何驱动行为？ |
| 认知 | 注意/记忆/语言/意识/推理/决策 | 心智如何由大脑实现？ |

```
神经科学
├── 一、基础结构（神经元/胶质细胞/突触/神经递质）
├── 二、多层级组织（分子→细胞→回路→脑区→脑网络）
├── 三、核心功能（感觉/运动/学习/记忆/情绪/决策/意识）
├── 四、研究方法（电生理/脑成像/神经调控/行为实验/计算建模）
└── 五、应用（神经疾病/精神疾病/脑机接口/康复/教育/AI）
```

| 方法 | 时间分辨率 | 空间分辨率 | 用途 |

## 费曼比喻：大脑=超级计算中心

| 子系统 | 神经科学 | 职能 |
|--------|---------|------|
| 计算单元 | 神经元 | 基本逻辑元件 |
| 通信接口 | 突触 | 信息传递+连接强度调整 |
| 软件模块 | 神经回路 | 视觉/语言/运动等特定任务 |
| 分布式系统 | 脑网络 | 多系统协同完成复杂认知 |
| 输出 | 认知和行为 | 系统运行的最终结果 |

## 与哲学→心理学→神经科学→AI的统一关系

```
               哲学
     （什么是意识？什么是知识？）
                  │
                  ▼
              心理学
     （人的心理与行为规律）
                  │
                  ▼
            神经科学
   （这些规律由大脑如何实现？）
                  │
                  ▼
          计算神经科学
 （如何建立可计算的神经模型？）
                  │
                  ▼
            人工智能
 （如何在机器中实现部分智能能力？）
```

**注意**：这是**研究关系**，不是上下级——AI 受神经科学启发但不是大脑的复制；心理学研究行为规律，神经科学研究其生物实现；哲学讨论概念基础。
