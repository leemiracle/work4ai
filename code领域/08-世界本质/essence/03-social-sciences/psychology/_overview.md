# 心理学总体框架 · Psychology Overview

> 心理学不是"读心术"或"心理咨询"——是**以科学方法研究心理、行为及其生物基础**的学科。  
> 从神经元到社会互动，多个层次。  
> 回答：**人是如何接收信息、加工信息、形成决策并表现为行为的？**

---

## 核心模型：人=信息处理系统

```
外部世界 → 感觉 → 知觉 → 注意 → 记忆 → 思维 → 决策 → 行为 → 环境反馈 → 学习 ↺
```

这是认知心理学的主线——也是 `12-epistemology/` 七环节认识系统模型的**人类版**。

---

## 知识体系

```
心理学
├── 一、基础心理过程（感觉/知觉/注意/记忆/学习/思维/语言/情绪）
├── 二、认知心理学（信息加工：输入→处理→存储→提取→应用）
├── 三、发展心理学（胎儿→婴儿→儿童→青少年→成年→老年）
├── 四、个体差异（人格/智力/动机/能力/兴趣/价值观）
├── 五、社会心理学（从众/群体压力/偏见/刻板印象/社会认同/合作/竞争）
├── 六、生理心理学（神经元/突触/脑区/神经递质/激素/遗传）
├── 七、临床心理学（焦虑/抑郁/强迫/创伤/评估/诊断/干预/康复）
├── 八、人格心理学（大五：外向/尽责/开放/宜人/情绪稳定）
├── 九、工业与组织心理学
└── 十、健康心理学
```

## 方法论

```
提出问题 → 假设 → 实验设计 → 数据收集 → 统计分析 → 解释 → 重复验证
```

| 方法 | 适合回答 |
|------|---------|
| 实验法 | X是否导致Y？ |
| 观察法 | 自然环境中如何表现？ |
| 问卷 | 群体态度/人格/满意度 |
| 脑成像 | 哪些脑区参与某心理活动？ |

## 分析模板（7维度）

| 维度 | 核心问题 |
|------|---------|
| 研究对象 | 研究什么心理现象？ |
| 核心问题 | 要解释什么？ |
| 理论模型 | 如何解释？ |
| 研究方法 | 如何验证？ |
| 影响因素 | 哪些变量影响结果？ |
| 应用领域 | 用在哪里？ |
| 局限性 | 哪些情境不适用？ |

## 费曼比喻：人=智能机器人

| 子系统 | 心理学分支 | 职能 |
|--------|-----------|------|
| 传感器 | 感觉/知觉 | 接收外界信息 |
| 内存管理 | 注意/记忆 | 决定保存/忽略什么 |
| 处理器 | 思维/推理 | 分析和判断 |
| 优先级调度 | 情绪/动机 | 影响资源分配和行动方向 |
| 配置文件 | 人格 | 稳定的行为模式 |
| 模型更新 | 学习 | 根据反馈调整规则 |
| 输出 | 行为 | 最终行动+环境反馈 |
