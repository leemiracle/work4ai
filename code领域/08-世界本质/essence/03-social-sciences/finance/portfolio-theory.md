## 引言：一个跨期决策问题的数学化

"不要把鸡蛋放在一个篮子里"——这句谚语古已有之。但**为什么**分散有用？分散到什么程度？有没有一个"最优"的篮子配置？这些问题直到 1952 年才被 Markowitz 用数学严格回答。

投资组合理论的本质是：**把直觉上的"分散化"变成一个可计算的最优化问题**。它的演化史，就是人类试图用越来越精细的数学捕捉"风险与收益关系"的历史——而每一次精细化，都暴露出上一代模型的盲区。

> **essence 立场**：投资组合理论是金融学中**数学最优雅、假设最脆弱、教训最深刻**的领域。它完美示范了一个认识论命题——**模型的精确性不等于模型的真实性**。

## 一、投资组合理论的演进史

```
1952  Markowitz《Portfolio Selection》         均值-方差框架（诞生）
1964  Sharpe / Lintner / Mossin                CAPM（单因子定价）
1976  Ross                                      APT（多因子定价的起点）
1992  Fama-French                              三因子（市场+规模+价值）→ CAPM 实证死亡
1997  Carhart                                  四因子（+动量）
2015  Fama-French                              五因子（+盈利+投资）
2017  Hou-Mo-Xue-Zhang                         q-factor 模型（投资+ROE）
1990s Bridgewater 全天候                         风险平价（Risk Parity）
1992  Black-Litterman                          结合市场均衡与主观观点
2010s Smart Beta ETF 兴起                       因子投资的工业化
2020s 机器学习组合优化                            非线性、高维、稳健优化
```

| 阶段 | 核心突破 | 数学工具 | 实证命运 |
|------|---------|---------|---------|
| Markowitz | 分散化的数学定义 | 凸优化、协方差矩阵 | 工程上有效，对输入极度敏感 |
| CAPM | 风险 = 系统性 + 非系统性 | β 系数、线性回归 | **实证失败**（β 无法解释收益） |
| APT | 多个风险因子 | 线性因子模型 | 框架成立，因子未指明 |
| 三因子 | 规模/价值异象 | 时间序列回归 | 解释了 CAPM 的残余 |
| 五/六因子 | 盈利/投资/动量 | 双重排序组合 | 因子之间存在共线性 |
| Smart Beta | 因子可投资化 | 规则化指数 | **因子拥挤**成为新风险 |
| 风险平价 | 按风险而非资金配置 | 风险预算 | 杠杆依赖、2020 流动性危机暴露缺陷 |

> **演进逻辑**：每一代模型都在修补上一代的漏洞，但修补本身引入新的假设。这是科学的常态——**没有终极模型，只有不断被证伪的近似**。

## 二、Markowitz 均值-方差理论深度

### 2.1 核心问题与数学设定

Markowitz 的天才在于：他把投资决策重新表述为一个**最优化问题**。设 $n$ 种资产，各自收益率为随机变量 $R_i$。

- 期望收益向量：$\boldsymbol{\mu} = E[\mathbf{R}] = (\mu_1, \dots, \mu_n)^T$
- 协方差矩阵：$\boldsymbol{\Sigma} = \text{Cov}(\mathbf{R})$（半正定对称）
- 权重向量：$\mathbf{w} = (w_1, \dots, w_n)^T$，约束 $\mathbf{1}^T\mathbf{w} = 1$

组合的期望收益与方差：

$$\mu_p = \mathbf{w}^T\boldsymbol{\mu}, \qquad \sigma_p^2 = \mathbf{w}^T\boldsymbol{\Sigma}\mathbf{w}$$

### 2.2 数学推导：最小方差组合

**最优化问题**：在给定目标收益 $\mu_{\text{target}}$ 下，最小化组合方差。

$$\min_{\mathbf{w}} \;\mathbf{w}^T\boldsymbol{\Sigma}\mathbf{w} \quad \text{s.t.} \quad \mathbf{w}^T\boldsymbol{\mu} = \mu_{\text{target}}, \;\; \mathbf{1}^T\mathbf{w} = 1$$

构造拉格朗日函数：

$$\mathcal{L} = \mathbf{w}^T\boldsymbol{\Sigma}\mathbf{w} - \lambda(\mathbf{w}^T\boldsymbol{\mu} - \mu_{\text{target}}) - \gamma(\mathbf{1}^T\mathbf{w} - 1)$$

对 $\mathbf{w}$ 求导并令其为零：

$$2\boldsymbol{\Sigma}\mathbf{w} - \lambda\boldsymbol{\mu} - \gamma\mathbf{1} = 0 \quad\Rightarrow\quad \mathbf{w}^* = \frac{1}{2}\boldsymbol{\Sigma}^{-1}(\lambda\boldsymbol{\mu} + \gamma\mathbf{1})$$

这说明**最优权重是期望收益向量和单位向量的线性组合**——这正是两基金分离定理的根源。代入约束条件可解出 $\lambda, \gamma$（略去繁琐代数），最终得到权重关于 $\mu_{\text{target}}$ 的解析表达。

### 2.3 有效前沿（Efficient Frontier）

对所有可行的 $\mu_{\text{target}}$ 求解上述问题，在 $(\sigma_p, \mu_p)$ 平面上得到的曲线就是**有效前沿**。

- **全局最小方差组合（GMV）**：前沿最左端的点，方差最小。
- **有效前沿**：GMV 之上那段"向上"的曲线——同样风险下收益最高。
- **可行集**：前沿内部的所有组合，均被前沿"支配"（dominated）。

> **直觉**：前沿是一条"帕累托最优边界"——你不可能在不增加风险的情况下提高收益，也不可能在不降低收益的情况下减少风险。

### 2.4 两基金分离定理（Two-Fund Separation）

**定理**：有效前沿上的**任何一个**组合，都可以由前沿上的**任意两个**不同组合的线性组合表示。

$$\forall\, p \in \text{前沿},\;\; \exists\, a,b \in \text{前沿},\;\; \alpha\in\mathbb{R}:\quad \mathbf{w}_p = \alpha\mathbf{w}_a + (1-\alpha)\mathbf{w}_b$$

**意义**：投资者不需要在整条前沿上选择——只需选定两个"共同基金"，通过调整它们的资金比例就能到达任何想要的前沿点。这是共同基金行业的**数学基石**。

### 2.5 代码：有效前沿计算与可视化

```python
import numpy as np
from scipy.optimize import minimize

np.random.seed(42)

# 5 只模拟股票（年化）
n = 5
mu = np.array([0.10, 0.12, 0.08, 0.15, 0.09])
vol = np.array([0.18, 0.22, 0.15, 0.28, 0.20])
corr = np.array([
    [1.00, 0.30, 0.20, 0.40, 0.25],
    [0.30, 1.00, 0.15, 0.35, 0.28],
    [0.20, 0.15, 1.00, 0.10, 0.20],
    [0.40, 0.35, 0.10, 1.00, 0.30],
    [0.25, 0.28, 0.20, 0.30, 1.00],
])
cov = np.outer(vol, vol) * corr

def port_var(w):  return w @ cov @ w
def port_ret(w):  return w @ mu

# 给定目标收益，最小化方差
def min_var_for_target(target):
    cons = [{'type':'eq','fun':lambda w: w.sum()-1},
            {'type':'eq','fun':lambda w: port_ret(w)-target}]
    res = minimize(port_var, np.ones(n)/n, method='SLSQP',
                   bounds=[(0,1)]*n, constraints=cons)
    return res

targets = np.linspace(mu.min(), mu.max(), 30)
frontier_std = [np.sqrt(min_var_for_target(t).fun) for t in targets]

# 全局最小方差组合（无收益约束）
gmv = minimize(port_var, np.ones(n)/n, method='SLSQP',
               bounds=[(0,1)]*n, constraints={'type':'eq','fun':lambda w:w.sum()-1})
print(f"GMV 权重: {np.round(gmv.x,4)}")
print(f"GMV 收益: {port_ret(gmv.x):.4f}, 标准差: {np.sqrt(port_var(gmv.x)):.4f}")
```

> **已验证运行**（见文末 §十一）。GMV 把大量权重给了低波动资产（第 3 只 0.46），几乎不持有最高波动资产（第 4 只 0.02）——这印证了"最小方差 = 低波动资产的分散组合"。

### 2.6 Markowitz 理论的致命弱点

| 弱点 | 描述 | 后果 |
|------|------|------|
| **对输入极度敏感** | 期望收益 $\mu$ 的微小估计误差导致权重剧烈变化 | "误差最大化"（Michaud 1989） |
| **协方差不稳定** | $\boldsymbol{\Sigma}$ 用历史估计，但相关性在危机中飙升 | 危机时分散失效 |
| **正态假设** | 方差无法刻画肥尾/偏度 | 低估极端损失 |
| **单期框架** | 忽略动态调整、交易成本、税 | 理论最优 ≠ 实务可行 |

> **essence 诊断**：Markowitz 给出了一个**数学上完美、工程上危险**的框架。实务界大量使用"收缩估计"（shrinkage）、Black-Litterman、稳健优化来修补——但修补越多，离"无假设的真理"越远。

## 三、CAPM 深度审视

> CAPM 的基础已在 [`markets-and-pricing.md`](./markets-and-pricing.md) 介绍。这里深化其推导、β 的含义、与 SML/CML 的关系，以及它为何**实证失败**。

### 3.1 CAPM 的推导

**假设**（极其理想化）：
1. 所有投资者都是**均值-方差优化者**（Markowitz 框架）
2. 所有投资者有**相同的投资期限和预期**（齐次预期）
3. 存在**无风险资产**，可无限借贷
4. 市场**完全可分、无税、无交易成本**
5. 价格是**竞争性**的（每个人都是价格接受者）

**推导**：在齐次预期下，所有投资者面对同一条有效前沿。引入无风险资产 $r_f$ 后，投资者会在**资本市场线（CML）**上选择——即无风险资产与**切点组合**（tangency portfolio）的组合线。

关键一步：所有投资者都持有同一个切点组合 → 该组合必须包含**所有**风险资产 → 这就是**市场组合 $M$**。

由"无套利"（市场均衡时，任何资产的预期超额收益必须与其对市场风险的贡献成正比），得到 **CAPM**：

$$\boxed{\;E[R_i] = r_f + \beta_i\big(E[R_M] - r_f\big)\;}$$

其中 $\beta_i = \dfrac{\text{Cov}(R_i, R_M)}{\text{Var}(R_M)}$ 是资产 $i$ 对市场的敏感度。

### 3.2 β 的估计与解释

β 通过时间序列回归估计（市场模型）：

$$R_{it} - r_{f,t} = \alpha_i + \beta_i(R_{Mt} - r_{f,t}) + \varepsilon_{it}$$

- $\beta = 1$：与市场同涨同跌
- $\beta > 1$：放大市场波动（成长股、科技股常在此列）
- $\beta < 1$：弱于市场（公用事业、必需消费）
- $\beta < 0$：与市场反向（黄金、某些对冲策略）

> **第一性原理拆解**：β 度量的不是"波动大小"，而是**"与市场共动的程度"**。一个高波动但不跟市场走的资产，β 可以很低——因为它的风险是**非系统性**的，可被分散掉。CAPM 的哲学是：**只有不可分散的风险才配得上风险溢价**。

### 3.3 SML vs CML：两条常被混淆的线

| | 资本市场线 CML | 证券市场线 SML |
|---|---------------|---------------|
| 描述对象 | **有效组合**（含无风险资产） | **任意资产/组合** |
| 横轴 | 总风险 $\sigma_p$ | 系统风险 $\beta$ |
| 方程 | $\mu_p = r_f + \dfrac{\mu_M - r_f}{\sigma_M}\sigma_p$ | $E[R_i] = r_f + \beta_i(\mu_M - r_f)$ |
| 用途 | 选组合（配置层） | 定价单个资产（α 检验） |
| 在线上 | 有效组合在线**上** | 均衡资产在线**上**，偏离则定价错误 |

**α 的定义**：资产实际收益减去 CAPM 预测收益的差额。$\alpha > 0$ 表示**战胜了风险调整后的市场**——这是主动管理的圣杯，也是 EMH 说它不存在的东西。

### 3.4 CAPM 的实证失败与原因

**Black, Jensen & Scholes (1972)** 早就发现：低 β 股票收益高于 CAPM 预测，高 β 股票低于预测——**SML 太平**。

**Fama-French (1992) 的致命一击**：单独看 β，几乎**无法**解释股票截面收益。加入规模和价值因子后，β 的解释力消失。

| 失败原因 | 说明 |
|---------|------|
| 假设太强 | 齐次预期、无摩擦市场在现实中不存在 |
| 市场组合不可观测 | 真正的 $M$ 应包含所有资产（含人力资本、房地产）—— Roll 批评 |
| 单因子不够 | 风险是多维的，一个 β 无法捕捉 |
| 行为偏差 | 投资者并非均值-方差理性 |

> **essence 立场**：CAPM 不是"错的"——它是**一个理想化模型**，揭示了"系统性风险应被定价"这一深刻洞见。它的价值在于**思想而非精度**：β 至今仍是描述资产风险特征的一阶近似，只是不该当作定价的终极真理。

## 四、套利定价理论（APT）—— 多因子模型的起点

### 4.1 从 CAPM 到 APT

CAPM 说收益由**一个**因子（市场）决定。Ross (1976) 的 APT 放宽：收益由**多个**因子驱动，但**不指明**是哪些因子。

**APT 假设**：资产收益服从**线性因子模型**：

$$R_i = E[R_i] + \sum_{k=1}^{K} b_{ik} F_k + \varepsilon_i$$

其中 $F_k$ 是第 $k$ 个因子（均值为零），$b_{ik}$ 是因子载荷，$\varepsilon_i$ 是特质风险。

### 4.2 APT 的定价方程

通过**无套利论证**（而非 CAPM 的均衡论证），Ross 推出：

$$E[R_i] = r_f + \sum_{k=1}^{K} b_{ik}\,\lambda_k$$

其中 $\lambda_k$ 是第 $k$ 个因子的**风险溢价**。

**APT vs CAPM**：

| | CAPM | APT |
|---|------|-----|
| 因子数量 | 1（市场） | K（多个，未指明） |
| 推导基础 | 均衡 + 强假设 | 无套利（弱假设） |
| 可检验性 | 单一可检验方程 | 因子需研究者自行发现 |
| 哲学 | "风险有唯一来源" | "风险有多重来源" |

> **关键洞察**：APT 是一个**框架**，不是一个**模型**——它说"收益由因子驱动"，但把"哪些因子"留给了实证研究。正是这个开放性，催生了 Fama-French 因子模型。

## 五、Fama-French 因子模型演进

### 5.1 三因子模型（1993）

Fama-French 发现 CAPM 残差中藏着两个系统性模式：
- **规模效应（SMB, Small Minus Big）**：小市值股票长期跑赢大市值
- **价值效应（HML, High Minus Low）**：高账面市值比（价值股）跑赢低账面市值比（成长股）

**三因子模型**：

$$R_i - r_f = \alpha_i + \beta_i(R_M - r_f) + s_i\,\text{SMB} + h_i\,\text{HML} + \varepsilon_i$$

**经济学解释**：
- **规模溢价**：小公司流动性差、信息少、破产风险高 → 需要补偿
- **价值溢价**：价值股可能是"困境"公司 → 承担困境风险需补偿；或市场过度外推成长股

### 5.2 五因子模型（2015）

Fama-French 加入两个因子（基于股利贴现模型的启示）：
- **盈利因子（RMW, Robust Minus Weak）**：高盈利公司跑赢低盈利
- **投资因子（CMA, Conservative Minus Aggressive）**：低投资增速公司跑越高投资增速

**五因子模型**：

$$R_i - r_f = \alpha_i + \beta_i\text{MktRF} + s_i\text{SMB} + h_i\text{HML} + r_i\text{RMW} + c_i\text{CMA} + \varepsilon_i$$

> **有意思的是**：在五因子模型中，**HML（价值因子）的解释力大幅下降**——因为价值与盈利、投资高度相关。这引发了"价值是否只是盈利/投资的代理"的争论。

### 5.3 六因子模型（+动量，Carhart 1997）

**动量因子（MOM）**：过去 12 个月（剔除最近 1 个月）表现好的股票，未来继续跑赢。这是行为金融最稳健的实证发现之一——**趋势确实存在**，但难以用风险解释（更像是行为偏差导致的持续性错误定价）。

### 5.4 因子的经济学解释与实证证据

| 因子 | 定义 | 经济学解释 | 实证稳健性 |
|------|------|-----------|-----------|
| **MktRF** | 市场超额收益 | 系统性风险溢价 | 全球普遍存在 |
| **SMB** | 小盘−大盘 | 流动性/破产风险补偿 | **近年来减弱**（小盘溢价缩小） |
| **HML** | 价值−成长 | 困境风险补偿 / 行为外推 | 2008 后长期失效，2022 复苏 |
| **RMW** | 高盈利−低盈利 | 高质量公司的风险溢价 | 较稳健 |
| **CMA** | 低投资−高投资 | 资本配置效率 | 较稳健 |
| **MOM** | 赢家−输家 | 行为偏差（反应不足） | 稳健但**崩溃风险大**（2009 动量崩盘） |

### 5.5 实时数据：Kenneth French 数据库（截至 2026 年 5 月）

来自 Kenneth French Data Library（学术界因子数据的权威来源）的**过去 12 个月**累计因子收益（%）：

| 因子 | Rm−Rf | SMB | HML | RMW | CMA |
|------|-------|-----|-----|-----|-----|
| 近12月 | **25.63** | 6.14 | **14.53** | **−27.50** | −2.92 |

> **实证观察**：盈利因子（RMW）在过去 12 个月录得 **−27.50%** 的惊人负收益——这正是**因子时变性**的铁证。一个长期被认为"稳健"的因子，在特定宏观环境下可以严重失效。价值因子（HML）则在同期强劲反弹（+14.53%），呼应 2022 年成长→价值的风格切换。

### 5.6 代码：Fama-French 回归（纯 numpy 实现 OLS）

```python
import numpy as np

np.random.seed(7)
T = 120  # 月数

# 模拟因子收益（月度）
rm  = 0.008 + 0.045*np.random.randn(T)   # 市场
smb = 0.003 + 0.030*np.random.randn(T)   # 规模
hml = 0.004 + 0.035*np.random.randn(T)   # 价值

# 某股票：真实 beta=1.20, s=0.30, v=-0.45
stock = 0.001 + 1.20*rm + 0.30*smb - 0.45*hml + 0.02*np.random.randn(T)

def ols(X, y):
    """OLS 回归 + 标准误 / t 值"""
    n, k = X.shape
    beta, *_ = np.linalg.lstsq(X, y, rcond=None)
    resid = y - X @ beta
    sigma2 = resid @ resid / (n - k)
    se = np.sqrt(sigma2 * np.diag(np.linalg.inv(X.T @ X)))
    return beta, beta/se  # 系数 + t 值

# 三因子回归
X = np.column_stack([np.ones(T), rm, smb, hml])
b, t = ols(X, stock)
for name, bv, tv in zip(['alpha','MktRF','SMB','HML'], b, t):
    print(f"{name:>7} = {bv:+.4f} (t={tv:+.2f})")
```

> **已验证运行**：上述代码精确恢复了真实参数——$\beta_{\text{Mkt}}=1.18(t=32)$，$s=0.33(t=5.4)$，$h=-0.47(t=-10.2)$。加入更多因子后 $R^2$ 从 CAPM 的 0.81 升至三因子的 0.92——**因子模型确实解释了更多收益变异**。

## 六、因子投资与 Smart Beta

### 6.1 什么是"因子"？

**因子（Factor）**：能系统性地解释资产收益差异的**共同驱动力**。可以理解为收益的"主成分"——类似于物理学中把复杂运动分解为基本力的叠加。

学术界公认的"风格因子"（Style Factors）：

| 因子 | 直觉 | 操作化定义 |
|------|------|-----------|
| **价值（Value）** | 便宜的股票被低估 | 低 P/B、低 P/E、高股息率 |
| **规模（Size）** | 小公司有溢价 | 小市值 |
| **动量（Momentum）** | 趋势会延续 | 过去 12 月收益（剔除最近月） |
| **质量（Quality）** | 好公司值得溢价 | 高 ROE、低杠杆、稳定盈利 |
| **低波（Low Volatility）** | 低风险股票反而表现好 | 低历史波动 / 低 β |

> **低波动异象（Low-Volatility Anomaly）**：与 CAPM 预测**相反**——低 β 股票长期收益**高于**高 β 股票。这是对 CAPM 最直接的实证反驳之一。可能原因：杠杆约束、彩票偏好（投资者偏好"暴富"机会）、行为偏差。

### 6.2 Smart Beta ETF：因子的工业化

**Smart Beta**（又称因子投资 / 科学化主动）：介于传统**市值加权指数**（被动）和**主动选股**之间的"第三条路"——用规则化的因子加权替代市值加权。

代表产品（示例性，非投资建议）：
- **价值因子 ETF**：跟踪价值指数
- **质量因子 ETF**：选高 ROE / 低负债公司
- **低波动 ETF**：选历史波动最低的股票
- **多因子 ETF**：综合价值+质量+动量

**Smart Beta 的承诺与陷阱**：

| 承诺 | 陷阱 |
|------|------|
| 系统性捕获因子溢价 | 因子会**长期失效**（如价值 2008-2020） |
| 透明、规则化、低成本 | **因子拥挤**——太多人买同一因子，溢价被套利掉 |
| 优于市值加权 | 市值加权本身在泡沫期会超配高估资产 |

### 6.3 因子时变性：因子会失效

这是因子投资**最深刻的实务问题**：历史有效的因子，未来未必有效。

**价值因子的"失去的十年"**：2008-2020 年，价值因子持续跑输成长因子——FANG（Facebook/Amazon/Netflix/Google）等成长股的崛起让价值投资者备受煎熬。直到 2022 年利率飙升，价值才强劲回归。

**根本原因**：
1. **结构性变化**：经济从重资产转向轻资产/无形资产，账面价值失去意义
2. **行为变化**：当价值溢价广为人知，套利者涌入，溢价消失
3. **宏观周期**：因子对通胀、利率、增长高度敏感

### 6.4 因子拥挤（Factor Crowding）

当大量资金涌入同一因子策略时：
- 因子组合的股票被推高 → 未来收益下降
- 持仓高度重叠 → **踩踏风险**（同时卖出时流动性枯竭）
- 因子间相关性上升 → 分散化失效

> 2020 年 3 月新冠崩盘中，**多个因子同时失效**——动量、价值、质量同步暴跌——这是拥挤交易去杠杆的典型表现。量化对冲基金在那两周经历了历史性回撤。

## 七、风险平价（Risk Parity）—— 桥水的全天候策略

### 7.1 核心思想：按风险而非资金分配

传统组合（如 60/40 股债）看似平衡，**风险上却高度倾斜**——股票贡献了 90% 以上的组合波动。

**风险平价**：让每类资产对组合**总风险的贡献相等**。

定义资产 $i$ 的**边际风险贡献**：

$$\text{MRC}_i = \frac{\partial \sigma_p}{\partial w_i} = \frac{(\boldsymbol{\Sigma}\mathbf{w})_i}{\sigma_p}$$

资产 $i$ 的**风险贡献**：$\text{RC}_i = w_i \cdot \text{MRC}_i$，满足 $\sum_i \text{RC}_i = \sigma_p$。

**风险平价目标**：$\text{RC}_1 = \text{RC}_2 = \dots = \text{RC}_n = \sigma_p/n$。

### 7.2 桥水全天候（All Weather）

Ray Dalio 的桥水基金将全球经济划分为四种"季节"：

| | 增长上升 | 增长下降 |
|---|---------|---------|
| **通胀上升** | 股票、商品、大宗 | 黄金、TIPS、商品 |
| **通胀下降** | 股票、公司债 | 长期国债、长期债券 |

全天候策略在这四个象限中**等风险配置**，目标是在任何宏观环境下都有稳定表现。

### 7.3 代码：风险平价（等风险贡献）

```python
import numpy as np

np.random.seed(11)
n = 4
vols = np.array([0.10, 0.15, 0.20, 0.25])  # 债/股/商品/高风险
corr = np.array([[1,.2,.1,0],[.2,1,.3,.1],[.1,.3,1,.2],[0,.1,.2,1]])
cov = np.outer(vols, vols) * corr

# 等权组合（1/N）的风险贡献
w_eq = np.ones(n)/n
rc_eq = w_eq * (cov @ w_eq)
rc_eq /= rc_eq.sum()
print("等权组合风险贡献:", np.round(rc_eq,4))   # [0.08 0.20 0.32 0.40] 高度不均!

# 风险平价：迭代使风险贡献相等
w = np.ones(n)/n
for _ in range(100000):
    sigma = np.sqrt(w @ cov @ w)
    rc = w * (cov @ w) / sigma
    grad = rc - sigma/n                    # 偏离等贡献的方向
    w = np.maximum(w - 0.5*grad/sigma, 1e-8)
    w /= w.sum()
print("风险平价权重:", np.round(w,4))          # [0.41 0.24 0.18 0.17]
rc_rp = w * (cov @ w); rc_rp /= rc_rp.sum()
print("风险平价风险贡献:", np.round(rc_rp,4))  # [0.25 0.25 0.25 0.25]
```

> **已验证**：风险平价让低波动资产（债券）权重高达 41%，但四类资产风险贡献均为 25%。代价是**需要杠杆**——因为低风险资产权重大，组合整体收益偏低，实务中需加杠杆放大。

### 7.4 风险平价的批评

- **杠杆是双刃剑**：平稳期放大收益，危机期放大损失
- **相关性假设**：模型假设资产相关性稳定，但 2020 年 3 月"所有资产一起跌"
- **债券依赖**：过去 40 年利率下行让风险平价大放异彩——利率反转是其系统性威胁

## 八、Black-Litterman 模型 —— 结合市场均衡与主观观点

### 8.1 解决 Markowitz 的问题

Black-Litterman (1992) 针对 Markowitz"对输入敏感"的缺陷，提出了一个优雅的融合方案：

**核心思想**：不要直接估计 $\mu$（误差大），而是从**市场隐含均衡收益**出发，再用投资者的**主观观点**做贝叶斯更新。

### 8.2 模型步骤

**第一步**：从市值权重 $\mathbf{w}_{\text{mkt}}$ 反推市场隐含的均衡收益：

$$\boldsymbol{\Pi} = \delta\boldsymbol{\Sigma}\mathbf{w}_{\text{mkt}}$$

其中 $\delta = \frac{\mu_M - r_f}{\sigma_M^2}$ 是风险厌恶系数。$\boldsymbol{\Pi}$ 是"如果所有人都是均值-方差理性的，市场均衡暗示的收益"。

**第二步**：表达投资者的观点。观点矩阵 $\mathbf{P}$，观点向量 $\mathbf{q}$，观点置信度 $\boldsymbol{\Omega}$：

$$\mathbf{q} = \mathbf{P}\boldsymbol{\mu} + \boldsymbol{\varepsilon}, \quad \boldsymbol{\varepsilon}\sim N(0,\boldsymbol{\Omega})$$

例如："资产1会比资产2高出2%"→ $\mathbf{P}=[1,-1,0,\dots]$，$\mathbf{q}=[0.02]$。

**第三步**：贝叶斯融合，得到后验期望收益：

$$\hat{\boldsymbol{\mu}}_{\text{BL}} = \left[(\tau\boldsymbol{\Sigma})^{-1} + \mathbf{P}^T\boldsymbol{\Omega}^{-1}\mathbf{P}\right]^{-1}\left[(\tau\boldsymbol{\Sigma})^{-1}\boldsymbol{\Pi} + \mathbf{P}^T\boldsymbol{\Omega}^{-1}\mathbf{q}\right]$$

**第四步**：用 $\hat{\boldsymbol{\mu}}_{\text{BL}}$ 代入 Markowitz 优化，得到**稳健**的最优组合。

### 8.3 Black-Litterman 的哲学价值

> 它解决了一个认识论难题：**"我们应该相信市场，还是相信自己的判断？"** Black-Litterman 的答案是——**两者都用，按各自的置信度加权**。这比"纯被动"（完全相信市场）和"纯主动"（完全相信判断）都更理性。

## 九、行为视角的投资组合 —— 前景理论投资组合

### 9.1 传统理论的理性人假设

Markowitz/CAPM 都假设投资者是**期望效用最大化者**——只关心收益的均值和方差，对盈亏对称。

但 Kahneman-Tversky 的**前景理论**（Prospect Theory，详见 [`behavioral-finance.md`](./behavioral-finance.md)）证明：
- **损失厌恶**：损失的痛苦 ≈ 等额收益快乐的 2 倍
- **参考点依赖**：人评估盈亏是相对某个参考点，而非绝对财富
- **概率扭曲**：小概率事件被高估，大概率事件被低估

### 9.2 行为投资组合理论

Shefrin-Statman (2000) 提出**行为投资组合理论（BPT）**：投资者的组合像一个**金字塔**——

| 层 | 目标 | 资产 |
|----|------|------|
| 底层 | 避免贫困（安全） | 保险、存款、国债 |
| 顶层 | 渴望暴富（彩票） | 期权、小盘股、加密货币 |

> **核心洞察**：人不是持有一个"最优组合"，而是同时持有**多个心理账户**——每个账户对应一个不同的目标（安全感 vs. 发财梦）。这解释了为什么人们**一边买保险一边买彩票**——在传统理性框架下这是矛盾的。

### 9.3 前景理论对组合优化的启示

- **下行风险更重要**：投资者关心 $\sigma^-$（下行半方差）而非 $\sigma$（总方差）→ 半方差优化、CVaR 优化
- **偏度偏好**：投资者喜欢正偏度（彩票式小概率大涨）→ 解释了对 IPO、彩票股的过度需求
- **处置效应**：持有亏损股太久，卖出盈利股太早 → 组合被"锚定"

> **essence 桥接**：行为投资组合理论把 [`behavioral-finance.md`](./behavioral-finance.md) 的认知偏差，**直接嵌入组合构建**。它不是对 Markowitz 的替代，而是对"理性人假设"的解构——提醒我们**优化的对象是人，不是数学函数**。

## 十、另类资产在组合中的角色

### 10.1 为什么要分散到非传统资产？

股票和债券的相关性在正常期为负（分散有效），但在**危机中会飙升趋近于 1**——"所有东西一起跌"。这驱动了向**另类资产**的分散。

### 10.2 另类资产分类与角色

| 类别 | 代表 | 组合角色 | 关键风险 |
|------|------|---------|---------|
| **对冲基金** | 多空、宏观、套利 | 绝对收益、低相关性 | 高费率、流动性差、**回报序列相关**（估值平滑） |
| **私募股权（PE）** | 杠杆收购、风投 | 流动性溢价、超额收益 | J 曲线、存活偏差、**流动性锁定** |
| **房地产** | REITs、直接持有 | 通胀对冲、现金流 | 周期性强、与经济高度关联 |
| **大宗商品** | 黄金、石油、农产品 | 通胀对冲、危机避险 | 无现金流、纯投机定价 |
| **基础设施** | 收费公路、电网 | 稳定现金流、抗通胀 | 政策风险、监管风险 |
| **私人信贷** | 直接贷款、不良债 | 收益增强 | 信用风险、流动性 |

### 10.3 另类资产的"陷阱"

- **估值平滑（Smoothing）**：PE/房地产不每日盯市，**表面波动低是假象**——去平滑后真实波动接近公开市场
- **存活偏差**：能募集到的基金数据是"活下来的"——失败基金被剔除
- **费率侵蚀**："2/20"（2% 管理费 + 20% 业绩提成）长期严重侵蚀收益
- **尾部相关性**：危机时另类资产与股票相关性飙升——分散在最需要时失效

> **essence 立场**：另类资产的价值不在"更高收益"，而在**"不同经济环境下的不同表现"**——它们提供了与股票/债券不同的**风险敞口维度**。但它们的光环（低波动、高收益）很大程度上是**会计幻觉**（平滑估值）和**选择偏差**（存活偏差）的产物。

## 十三、开放问题

1. **因子是"风险补偿"还是"行为偏差"？** —— 这决定了因子是否会持续存在。若是风险补偿，会持续；若是行为偏差，当套利者足够多时会消失。**至今无定论**。
2. **"最优组合"真的存在吗？** —— 它依赖于（未知的）真实收益分布。Hansen-Jagannathan 界告诉我们最优是分布相关的——而我们永远不知道真实分布。**这是 Knight 式不确定性的体现**（见 [`risk-and-uncertainty.md`](./risk-and-uncertainty.md)）。
3. **机器学习能发现新因子吗？** —— $p \gg n$ 问题（因子数远超样本量）导致严重过拟合。Harvey-Liu-Zhu (2016) 警告：已发表的"几百个因子"大多是**数据挖掘的产物**，需用更严格的 t 值阈值（>3 而非 2）。
4. **因子会永远存在吗？** —— 因子拥挤假说认为：一旦因子被广泛认知和投资，其溢价会被套利掉。价值因子 2008-2020 的失效是支持此假说的证据。**因子的"半衰期"是当代金融最前沿的问题之一**。
5. **加密资产如何纳入组合？** —— 高波动、低相关性，理论上是好的分散工具，但其**非平稳性**（历史太短、结构性变化剧烈）让传统组合优化完全失效。
6. **AI 主导交易时，因子还成立吗？** —— 如果所有交易者都用相同因子模型，市场效率提高，因子溢价消失——这是**有效市场假说的自我实现**。

## 十五、essence 方法论反思

### 这门学问的哲学锚点

投资组合理论是金融学里**最像物理学**的分支——它有优美的数学、可证伪的预测、不断被实证修正的模型。但这恰恰是它的危险：**数学的优雅会让人误以为它捕捉了真实**。

> **核心反思**：从 Markowitz 到 Smart Beta，70 年的演化揭示了一个反复出现的模式——**模型越精确，对假设越敏感；假设越理想化，离现实越远**。CAPM 的 β 是个一阶近似，Fama-French 的因子是经验拟合，Black-Litterman 是贝叶斯妥协。**没有终极模型——只有不断被证伪的近似，和从证伪中学到的教训。**

这正是 essence 项目 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 所说的金融学第二假设"风险可以量化"的**最深刻张力**：我们用数学把风险量化了，但量化的可能只是**我们以为的风险**，而非**真实的风险**。真实的风险（黑天鹅、范式转换、结构性断裂）往往在模型之外。
