## 一、金融学是什么

**经典定义**：金融学研究**跨时间的资源配置**——在不确定性下，如何把今天的钱、未来的钱、别人的钱、自己的钱，进行最优的交换、分配和风险管理。

**essence 理解**：金融学 = 关于"**时间 × 风险 × 信任**"的学科。它的三个核心变量是：
1. **时间**：今天的钱 ≠ 未来的钱（时间价值）
2. **风险**：确定的收益 ≠ 不确定的收益（风险溢价）
3. **信任**：承诺 ≠ 履行（信用风险）

> **一句话**：金融的本质是**用今天的信任，兑换明天的不确定**。

**与经济学的区别**：
| | 经济学 | 金融学 |
|---|--------|--------|
| 关注 | 实体（生产/分配/消费） | 符号（价格/契约/权利） |
| 时间 | 相对静态 | 核心维度（时间价值） |
| 不确定性 | 边缘议题 | 核心议题 |
| 方法 | 均衡分析、博弈论 | 随机分析、无套利、定价 |
| 价值 | 解释价值来源 | 不问价值来源，只问价格 |

## 四、金融学的六个核心问题

### 问题 1 · 价格由什么决定？

**三大理论**（详见 [`markets-and-pricing.md`](./markets-and-pricing.md)）：
1. **均衡定价**（新古典）——供需均衡决定价格
2. **信息定价**（EMH）——价格反映所有信息
3. **行为定价**（行为金融）——价格反映人类心理

**essence 立场**：三种理论各自捕捉了部分真相——价格是**均衡 × 信息 × 心理**的三重叠加。不存在单一正确答案。

### 问题 2 · 风险能被量化吗？

**Knight 的关键区分**（详见 [`risk-and-uncertainty.md`](./risk-and-uncertainty.md)）：
- **风险**：已知概率分布——可量化、可对冲、可定价
- **不确定性**：未知概率分布——不可量化、不可对冲、不可定价
- **黑天鹅**：连"事件的可能性"都没想到——彻底的认知盲区

**essence 立场**：金融学的核心原罪是把"不确定性"假装成"风险"来处理。

### 问题 3 · 货币的本质是什么？

**四大立场**（详见 [`money-and-credit.md`](./money-and-credit.md)）：
1. **金属主义**（奥地利学派）——钱必须有内在价值
2. **chartalism/MMT**——法币有价值因为国家接受它纳税
3. **建构主义**（Searle）——钱是集体意向性的产物
4. **算法主义**（比特币）——钱应该去中心化、算法化

**essence 立场**：货币的"本质"不是单一属性，而是**功能的集合**——交换媒介/价值尺度/价值储藏/信用工具——不同货币在不同功能上强弱不同。

### 问题 4 · 市场是有效的吗？

**EMH 三种形式**：
- **弱式**：价格反映所有历史价格信息（技术分析无用）
- **半强式**：价格反映所有公开信息（基本面分析无用）
- **强式**：价格反映所有信息（内幕也无用）

**悖论**（Grossman-Stiglitz）：如果市场完全有效，没人有动力搜集信息，市场就不可能有效。

**essence 立场**：市场"大致"有效但"经常"偏离——偏离的幅度和持续时间由信息搜集成本决定。价值投资者的超额回报就是"搜集信息的报酬"。

### 问题 5 · 金融稳定是可能的吗？

**Minsky 金融不稳定假说**：
```
稳定 → 自信 → 加杠杆 → 投机 → 庞氏融资 → 脆弱 → 触发事件 → 崩盘 → 去杠杆 → 痛苦 → 稳定 → ...
```

**三类融资**（Minsky）：
- **对冲融资**：收入能覆盖本金+利息（安全）
- **投机融资**：收入只能覆盖利息（依赖滚动融资）
- **庞氏融资**：收入连利息都覆盖不了（依赖资产升值）

**essence 立场**：金融不稳定是**内禀属性**——不是"管理不善"，而是资本主义金融系统的结构性特征。监管只能延缓，不能消除。

### 问题 6 · 金融创造价值还是零和赌博？

**四种立场**（见哲学锚点 §四 极限 4）：
- **乐观派**：金融配置资源——创造巨大社会价值
- **怀疑派**（Tobin）：大部分交易是噪音——零和
- **批判派**（Haldane）：金融化是经济病灶——私人回报 > 社会价值
- **Keynes**：当金融变成赌场，实体遭殃

**essence 立场**：金融**既创造价值又制造风险**——关键在于"金融深化"和"金融化"的区别。前者服务实体，后者寄生实体。

## 五、金融学的方法论

| 方法 | 核心 | 代表 | 适用 | 哲学辩护 |
|------|------|------|------|---------|
| **无套利定价** | "没有免费午餐"→ 推导价格 | Black-Scholes | 衍生品 | 公理化方法的金融应用 |
| **随机分析** | 伊藤引理、SDE | Merton | 动态对冲 | 把不确定性数学化 |
| **最优化** | 均值-方差、效用最大化 | Markowitz | 组合配置 | 理性人假设的工具化 |
| **计量实证** | 回归、事件研究 | Fama-French | 因子检验 | 经验主义 |
| **行为实验** | 实验室/田野 | Kahneman | 偏差发现 | 心理学补充 |
| **复杂系统模拟** | Agent-Based Model | Santa Fe Institute | 系统性风险 | 涌现视角 |
| **金融物理** | 统计力学方法 | Mandelbrot | 肥尾建模 | 物理类比 |

**essence 方法论**（MANIFESTO 第七条）：每个金融概念都要**三层讲解**——直觉（比喻）+ 数学（公式）+ 代码（用 Python 跑出结果）。金融特别容易"术语堆砌掩盖无知"，必须用代码验证。

## 九、essence 的金融方法论宪章

### 学习金融的三条原则

1. **数学是工具，不是真理**——每个公式都建立在假设上。先问"假设合理吗"，再算"结果是多少"。
2. **历史是数据，但不是全部**——金融史上最大的灾难（黑天鹅）都不在历史数据里。从历史学**模式**，不要学**参数**。
3. **代码验证直觉**——任何金融直觉，都该用 Python 跑一遍（模拟、回归、可视化）。直觉错了，代码会告诉你。

### 金融与其他学科的"桥"

金融连接 essence 项目的多个高度数概念：
- **时间**（金融时间是贴现的时间）
- **不确定性**（金融把不确定性变成可交易的产品）
- **反馈**（正反馈=泡沫，负反馈=均值回归）
- **涌现**（市场价格是涌现的秩序）
- **信用 = 信任**（金融的底层资产是信任）

> **核心洞察**：金融不是"关于钱"的学科——它是"**关于时间、风险、信任的跨期契约**"的学科。钱只是这些契约的计量单位。
