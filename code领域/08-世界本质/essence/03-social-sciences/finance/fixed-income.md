## 引言：为什么固定收益是金融学的"硬核"

股票投资问的是"**未来涨多少**"——答案充满不确定性。  
债券投资问的是"**承诺的钱能不能拿到**"——答案相对确定，但确定之中藏着**精确的数学结构**。

固定收益（Fixed Income）这个名字有欺骗性：它不是"固定收益"，而是"**固定承诺**"。债券发行人承诺按合同付息还本——这个承诺本身就是一种可定价的契约。固定收益学的全部优雅，来自一个事实：**债券的现金流在合同上是已知的，唯一未知的是"这些现金流在今天值多少"**。

> **一句话**：固定收益学 = 把时间、信用、流动性、通胀四个变量，压缩进一个叫"贴现率"的参数，然后算出现值。

本文遵循 essence 方法论：**每个概念走三层——直觉（比喻）→ 数学（公式与推导）→ 代码（用 Python 跑出数字）**。所有代码均已用 bash 验证。

## 一、固定收益市场概览

固定收益市场是全球资本市场的**绝对主体**。债券市场规模远超股票市场——不是因为债券更"性感"，而是因为债券是机构资金的**主要配置工具**（养老金、保险、银行、央行）。

### 1.1 全球规模（量级感受）

| 市场 | 规模（约） | 说明 |
|------|-----------|------|
| **全球债券存量** | **~$140 万亿** | 远超全球股票市值（~$100 万亿） |
| 美国国债（Treasury） | ~$27 万亿 | 全球"无风险资产"的基准 |
| 美国公司债 | ~$10 万亿 | 投资级为主（IG ~$8万亿，高收益 ~$2万亿） |
| 美国市政债（Muni） | ~$4 万亿 | 免税特性，地方政府发行 |
| 美国机构 MBS | ~$12 万亿 | 房贷证券化——最大的"非国债"板块 |
| 资产支持证券（ABS） | ~$2 万亿 | 车贷/信用卡/学生贷证券化 |
| 中国债券存量 | ~￥170 万亿（~$24万亿） | 全球第二大债券市场 |

> **洞察**：美国国债（~$27万亿）是美国政府的"欠条"。而中国持有的美债曾是全球最大的单一债权。债券不只是投资工具——它是**主权信用、地缘博弈、货币霸权的载体**。

### 1.2 债券的分类维度

```
按发行主体          按到期期限        按利息结构         按市场

├── 公司债 (Corp)    ├── 中期 (1-10年) ├── 浮动利率      └── 二级市场

├── 机构债 (Agency)                      └── 通胀挂钩(TIPS)
├── MBS / ABS
└── 国际/主权债 (Sovereign EM)
```

### 1.3 固定收益的参与者生态

| 参与者 | 动机 | 行为特征 |
|--------|------|---------|
| **中央银行** | 货币政策、外汇储备 | 量级最大，设定短端利率 |
| **商业银行** | 资产负债管理（ALM） | 期限错配——短借长贷 |
| **保险公司/养老金** | 匹配长期负债 | 久期匹配，买入长债 |
| **共同基金/ETF** | 追踪指数或超额收益 | 流动性需求高 |
| **对冲基金** | 套利、相对价值 | 杠杆，方向性交易 |
| **做市商（投行）** | 提供流动性赚取买卖价差 | 库存风险管理 |

> **关键不对称**：固定收益市场的流动性高度集中在**国债**。公司债、MBS 的流动性在危机时**瞬间蒸发**——这就是 2008 年流动性危机的结构性根源。

## 二、债券基础：现金流结构与定价

### 2.1 债券的解剖

一只标准固定利率债券的现金流是**确定性的时间序列**：

```
时间:   t=0      t=1    t=2    ...    t=N-1   t=N
现金流:  -P      +c     +c     ...    +c      +c+F
         (买入)  (票息)                      (票息+本金)
```

- **票息（Coupon, $c$）**：每期支付的利息 = $\text{票面利率} \times \text{面值} / \text{付息频率}$
- **面值/本金（Face/Par, $F$）**：到期偿还的本金（通常 $F=100$）
- **到期（Maturity, $N$）**：最后的付息期数
- **付息频率（$m$）**：美国国债半年付息（$m=2$），中国国债多为年付（$m=1$）

### 2.2 定价公式（第一性原理）

**债券价格 = 所有未来现金流的现值之和**：

$$P = \sum_{t=1}^{N} \frac{CF_t}{(1+y/m)^t} = \sum_{t=1}^{N} \frac{c}{(1+y/m)^t} + \frac{F}{(1+y/m)^N}$$

其中 $y$ 为**到期收益率（YTM, Yield to Maturity）**——那个让现值恰好等于市场价格的单一贴现率。

**票息部分的封闭解**（等比数列求和）：

$$\sum_{t=1}^{N} \frac{c}{(1+y/m)^t} = c \cdot \frac{1 - (1+y/m)^{-N}}{y/m}$$

> **直觉**：YTM 是"**如果你持有到期，且所有票息能按 YTM 再投资，你的年化收益率**"。两个隐藏假设：(1) 不违约；(2) 票息再投资率 = YTM。现实中两者都不成立——这就是债券投资的**再投资风险**和**信用风险**。

### 2.3 价格-收益率关系的三定律

| 关系 | 原因 |
|------|------|
| **YTM ↑ ⟹ P ↓**（反向） | 贴现率越高，现值越低 |
| **价格曲线是凸的**（ convex） | 涨多跌少——凸性是有价值的（§三详解） |
| **票息率 > YTM ⟹ 溢价；票息率 < YTM ⟹ 折价** | 票息率 = YTM 时恰为平价（$P=100$） |

### 2.4 应计利息、净价与全价

债券在两次付息之间交易时，卖方应得**已累积但未支付的利息**——这就是应计利息（Accrued Interest, AI）。

$$AI = c \times \frac{\text{上一次付息到结算日的天数}}{\text{一个付息周期的天数}}$$

- **全价（Dirty Price / Full Price）**：买方实际支付的金额 = 现值（用 $y$ 贴现到结算日）
- **净价（Clean Price）**：全价 − 应计利息 = 市场报价的价格

> **为什么要有净价？** 因为债券价格波动反映的是**利率变化**，不应被"今天恰好是付息周期第几天"这种机械因素污染。净价让价格变动只反映利率风险，剥离应计利息的机械增长。这是金融工程的"信号去噪"。

### 2.5 代码块 1：债券定价与 YTM 反推

```python
import numpy as np
from scipy.optimize import brentq

def bond_price(coupon_rate, face, ytm, periods, freq=2):
    """债券定价: P = Σ c/(1+y/freq)^t + F/(1+y/freq)^N"""
    c = coupon_rate * face / freq
    y = ytm / freq
    pv_coupons = sum(c / (1+y)**t for t in range(1, periods+1))
    pv_face = face / (1+y)**periods
    return pv_coupons + pv_face

def bond_ytm(price, coupon_rate, face, periods, freq=2):
    """用 Brent 法从价格反推 YTM"""
    c = coupon_rate * face / freq
    def f(y):
        yy = y / freq
        return sum(c/(1+yy)**t for t in range(1,periods+1)) + face/(1+yy)**periods - price
    return brentq(f, -0.5, 1.0, xtol=1e-10)

# --- 验证 ---
P_par = bond_price(0.05, 100, 0.05, 10, freq=2)   # 平价债
P_disc = bond_price(0.05, 100, 0.06, 10, freq=2)   # YTM升到6%
ytm_back = bond_ytm(P_disc, 0.05, 100, 10, freq=2)  # 反推
print(f"平价债(YTM=5%): {P_par:.4f}")    # 100.0000
print(f"YTM升到6%: {P_disc:.4f}")         # 95.7349 (折价)
print(f"反推YTM: {ytm_back:.6f}")          # 0.060000
```

> **洞察**：这只 5 年期、5% 票息的债券，YTM 仅上升 100bp（从 5% 到 6%），价格就跌了 **4.27%**（从 100 到 95.73）。这就是利率风险的杀伤力——也是§三要精确度量的对象。

## 三、利率风险度量：久期与凸性

债券价格对利率变动有多敏感？这是固定收益风险管理**最核心的问题**。答案的两个支柱：**久期**（一阶效应）和**凸性**（二阶效应）。

### 3.1 久期：价格对利率的一阶敏感度

#### 直觉层

> 想象你借给别人两笔钱：一笔 100 元明天还，一笔 100 元 30 年后还。如果央行加息——哪笔"亏"得多？显然是 30 年那笔，因为它被"锁住"的时间更长。**久期就是衡量"平均来说，你要等多久才能拿回钱"的指标**——等得越久，对利率越敏感。

#### Macaulay 久期（1938）

Frederick Macaulay 提出以**现金流时间的加权平均**来度量期限：

$$D_{\text{Mac}} = \frac{\sum_{t=1}^{N} t \cdot \frac{CF_t}{(1+y/m)^t}}{P} = \sum_{t=1}^{N} t \cdot w_t, \quad w_t = \frac{PV(CF_t)}{P}$$

- $w_t$ 是第 $t$ 期现金流的现值权重（$\sum w_t = 1$）
- 单位是**时间**（年）

**直觉**：久期 = "你资金的**有效等待时间**"。零息债券的久期恰好等于它的到期日（因为只有一笔现金流）。付息债券的久期严格小于到期日（因为票息提前回流了部分资金）。

#### 修正久期（Modified Duration）

将 Macaulay 久期除以 $(1+y/m)$，得到**价格对收益率的导数**：

$$D_{\text{Mod}} = \frac{D_{\text{Mac}}}{1+y/m} = -\frac{1}{P}\frac{\partial P}{\partial y}$$

**推导**（关键，不只是背公式）：

$$P = \sum_{t} CF_t \cdot (1+y/m)^{-t}$$

$$\frac{\partial P}{\partial y} = \sum_t CF_t \cdot (-t) \cdot \frac{1}{m}(1+y/m)^{-t-1} = -\frac{1}{m}\frac{1}{1+y/m}\sum_t t\cdot\frac{CF_t}{(1+y/m)^t}$$

$$\Rightarrow -\frac{1}{P}\frac{\partial P}{\partial y} = \frac{1}{m}\cdot\frac{1}{1+y/m}\cdot\frac{\sum_t t\cdot PV(CF_t)}{P} = \frac{D_{\text{Mac}}}{m(1+y/m)} = \frac{D_{\text{Mac}}}{1+y/m}$$

（$m$ 期合并为年的约定）。

> **经济含义**：$D_{\text{Mod}} = 4.38$ 意味着"**收益率每上升 1%（100bp），价格大约下跌 4.38%**"。这是固定收益交易员每天用几百遍的"心算"。

### 3.2 凸性：久期的"曲率修正"

#### 为什么需要凸性

久期是**一阶（线性）近似**——它假设价格-收益率关系是直线。但实际关系是**凸的曲线**（价格涨多跌少）。当收益率变动**较大**时，线性近似失真，需要二阶修正。

#### 凸性的定义

$$C = \frac{1}{P}\frac{\partial^2 P}{\partial y^2} = \frac{1}{P}\sum_{t=1}^{N} \frac{t(t+1)}{m^2}\cdot\frac{CF_t}{(1+y/m)^{t+2}}$$

（对 $P$ 求二阶导，再除以 $P$ 归一化。）

#### 凸性为什么"有价值"

价格曲线是**凸向原点**的。这意味着：
- 收益率**下降**时，价格**涨得比久期预测的多**
- 收益率**上升**时，价格**跌得比久期预测的少**

**涨多跌少 = 凸性是"免费的保险"**（在利率波动的两个方向上都有利）。因此高凸性的债券更值钱——市场会为凸性**支付溢价**（价格更高/YTM更低）。

### 3.3 DV01 / Price Value of a Basis Point

**DV01** = 收益率变动 1 个基点（0.01%）时，债券价格的变化金额：

$$\text{DV01} = -\frac{\partial P}{\partial y}\times 0.0001 \approx D_{\text{Mod}}\times P\times 10^{-4}$$

- 这是交易台最常用的风险单位——"我的头寸每 1bp 值多少钱"
- 对于 100 面值的债券，$D_{\text{Mod}}=4.38$，则 DV01 ≈ $4.38\times 100\times 10^{-4} = 0.0438$ 元

### 3.4 久期-凸性近似公式（Taylor 展开）

把价格 $P(y+\Delta y)$ 在 $y$ 处 Taylor 展开：

$$\frac{\Delta P}{P} \approx \underbrace{-D_{\text{Mod}}\cdot\Delta y}_{\text{一阶(久期)}} + \underbrace{\frac{1}{2}C\cdot(\Delta y)^2}_{\text{二阶(凸性)}}$$

这是债券风险管理的**核心公式**。

### 3.5 代码块 2：久期、凸性、近似精度验证

```python
import numpy as np

def duration_convexity(coupon_rate, face, ytm, periods, freq=2):
    c = coupon_rate * face / freq
    y = ytm / freq
    times = np.arange(1, periods + 1)
    cfs = np.full(periods, c); cfs[-1] += face
    pv_cfs = cfs / (1 + y)**times
    P = pv_cfs.sum()
    mac_dur_years = (times * pv_cfs).sum() / P / freq
    mod_dur = mac_dur_years / (1 + y)
    convexity = ((times*(times+1)) * pv_cfs).sum() / (P * (1+y)**2) / freq**2
    return P, mac_dur_years, mod_dur, convexity

# 5年期, 票息5%, YTM5%, 半年付息
P0, mac, mod, conv = duration_convexity(0.05, 100, 0.05, 10, freq=2)
print(f"Macaulay Duration = {mac:.4f} 年")
print(f"Modified Duration = {mod:.4f}")     # 4.3760
print(f"Convexity         = {conv:.4f}")    # 22.6123
print(f"DV01 ≈ {mod*P0*1e-4:.4f} (每100面值, 每1bp)")  # 0.0438
```

**近似精度验证**（同一只债券，不同幅度的收益率变动）：

| Δy (bp) | 实际价格变化 | 仅久期预测 | 久期+凸性 | 久期误差 | 凸性修正后误差 |
|---------|------------|-----------|----------|---------|--------------|
| 1 | -0.0437% | -0.0438% | -0.0437% | 0.00 bps | -0.00 bps |
| 10 | -0.4365% | -0.4376% | -0.4365% | 0.11 bps | -0.00 bps |
| 50 | -2.1600% | -2.1880% | -2.1598% | 2.80 bps | -0.03 bps |
| 100 | -4.2651% | -4.3760% | -4.2630% | 11.09 bps | -0.21 bps |
| 200 | -8.3166% | -8.7521% | -8.2998% | 43.55 bps | -1.68 bps |
| 500 | -19.3043% | -21.8802% | -19.0536% | 257.58 bps | -25.07 bps |

> **核心洞察**：
> 1. **小变动（<10bp）**：仅久期就够精确（误差 <0.1bp）。
> 2. **中等变动（50-100bp）**：凸性贡献明显——100bp 时久期高估跌幅 11bps，凸性修正后仅差 0.2bps。
> 3. **大变动（>200bp）**：连二阶近似也开始失真（500bp 时误差 25bps）——需要更高阶项或全价重算。
> 4. **凸性永远是正贡献**：最后一列总是负号（或零），因为凸性让实际跌幅小于久期预测。这就是"凸性是免费保险"的数学证明。

## 四、利率期限结构：收益率曲线

### 4.1 即期利率、远期利率与互换利率

#### 即期利率（Spot Rate / Zero Rate）

$s_t$ = 从今天到 $t$ 时刻的**年化零息收益率**。即期利率曲线（零息曲线）是所有定价的**地基**。

零息债券直接给出即期利率：$s_t$ 满足 $P_{\text{zero}}(t) = \frac{F}{(1+s_t)^t}$。

#### 远期利率（Forward Rate）

$f(t_1, t_2)$ = 从未来 $t_1$ 到 $t_2$ 的隐含利率。由**无套利**条件推导：

$$(1+s_{t_2})^{t_2} = (1+s_{t_1})^{t_1} \times (1+f(t_1,t_2))^{t_2-t_1}$$

$$\Rightarrow f(t_1,t_2) = \left[\frac{(1+s_{t_2})^{t_2}}{(1+s_{t_1})^{t_1}}\right]^{1/(t_2-t_1)} - 1$$

**验证**（代码跑出）：$s_1=3\%,\; s_2=4\%$，则隐含 1 年后 1 年期远期利率 $f(1,2)=5.01\%$。

> **直觉**：2 年期利率（4%）高于 1 年期（3%），市场隐含**明年利率会升到 ~5%**。远期利率不是"预测"——它是"要使无套利成立，明年的利率**必须**是多少"。

#### 互换利率（Swap Rate）

利率互换（IRS）中固定端支付的利率。互换曲线在现代市场常被用作**基准曲线**（尤其在美元市场，LIBOR/SOFR 互换曲线比国债曲线更常用做贴现曲线）。

### 4.2 收益率曲线的三大理论

为什么收益率曲线有时向上倾斜（长端利率高），有时向下？三大经典理论：

#### 理论 1 · 预期理论（Expectations Hypothesis）

**核心命题**：远期利率 = 市场对未来即期利率的**无偏预期**。

$$f(t_1, t_2) = E[s_{t_2}\;|\;\text{时刻 }t_1]$$

- 曲线向上 ⟹ 市场预期**加息**
- 曲线向下 ⟹ 市场预期**降息**

**致命缺陷**：现实中远期利率**系统性高于**预期未来即期利率——因为**没有风险溢价补偿**。这与下一理论冲突。

#### 理论 2 · 流动性偏好理论（Liquidity Preference）

**核心命题**：投资者偏好短期（流动性高、价格风险低），要他们买长期，必须给**期限溢价（Term Premium）**。

$$f(t_1,t_2) = E[s_{t_2}] + \text{期限溢价} > E[s_{t_2}]$$

- 远期利率 = 预期即期利率 + 正的期限溢价
- 因此曲线**通常向上倾斜**（即使市场不预期加息）

> **essence 注**：这两个理论的分歧，本质是"**市场是风险中立的吗？**"。预期理论假设风险中性，流动性偏好说"不"。后者更符合现实——这也是为什么向上倾斜的曲线是"常态"。

#### 理论 3 · 市场分割 / 习惯栖息地（Market Segmentation / Preferred Habitat）

**核心命题**：长短期市场被**不同参与者分割**，各自供需决定各自利率。

- 短端：银行、货币基金（受央行政策利率主导）
- 长端：保险、养老金（有长期负债，必须买长债）

曲线形状由**各段的供需**独立决定，不必然有跨段的套利拉平。这个理论解释了为什么央行操作（如 QE）能"扭曲"特定段——因为不同段的参与者确实不太替代。

> **综合**：真实曲线是三者的叠加——$y(t) = \underbrace{E[s_t]}_{\text{预期}} + \underbrace{TP_t}_{\text{期限溢价}} + \underbrace{\text{分割效应}}_{\text{供需}}$。

### 4.3 收益率曲线倒挂为什么"预测"衰退

**经验事实**（美国数据，1955 至今）：**每当 10 年期 - 2 年期（或 10年-3月）利差转负（倒挂），经济在 12-18 个月内进入衰退的概率极高**。二战后几乎每次衰退前都出现倒挂（仅 1960s 中期一次例外有争议）。

**为什么？三种解释**：

1. **预期渠道**：市场预期衰退 → 预期央行未来降息 → 长端利率下降 → 曲线倒挂。倒挂不是**导致**衰退，而是**预测**了市场对衰退的预期。
2. **银行利润渠道**：银行"短借长贷"（期限错配盈利）。曲线倒挂意味着长短利差为负——**银行放贷无利可图** → 信贷收缩 → 实体缺血 → 衰退。这里倒挂**因果性地促发**衰退。
3. **期限消失渠道**：倒挂时，长期不补偿期限风险 → 投资者撤离长债 → 长期融资成本上升 → 投资下降。

> **哲学警告**：相关 ≠ 因果。倒挂"预测"衰退的记录惊人，但 **2022-2023 美国曲线深度倒挂超 18 个月，衰退至今未现**（截至 2026 年中观察）。这可能是 (a) 这次不一样（AI 生产率提升、财政赤字支撑）；(b) 滞后还在发酵；(c) 指标失效。保持谦逊。

### 4.4 曲线拟合：Nelson-Siegel 模型

收益率曲线不是几个离散点——实务中需要**连续函数**来给任意到期日的债券定价。Nelson-Siegel（1987）是最广泛使用的参数化模型：

$$y(\tau) = \beta_1 + \beta_2\cdot\frac{1-e^{-\tau/\lambda}}{\tau/\lambda} + \beta_3\left[\frac{1-e^{-\tau/\lambda}}{\tau/\lambda} - e^{-\tau/\lambda}\right]$$

**四个参数的直觉**：

| 参数 | 角色 | 直觉 |
|------|------|------|
| $\beta_1$ | **长期水平**（Level） | $\tau\to\infty$ 时 $y\to\beta_1$（曲线的渐近线） |
| $\beta_2$ | **短端-长端利差**（Slope） | $\tau\to 0$ 时 $y\to\beta_1+\beta_2$（短端 = 水平 + 斜率） |
| $\beta_3$ | **曲率**（Curvature） | 中段的"隆起或凹陷" |
| $\lambda$ | **衰减时间常数** | 控制"短端过渡到长端"发生在哪里 |

> **优雅之处**：仅用 4 个参数就能拟合整条曲线的"水平+斜率+曲率"三个维度。这是**降维的胜利**——把无限维的曲线压成 4 个可估计的数字。

### 4.5 代码块 3：Nelson-Siegel 曲线拟合

```python
import numpy as np
from scipy.optimize import least_squares

def nelson_siegel(tau, beta1, beta2, beta3, lam):
    """向量化 Nelson-Siegel 收益率曲线"""
    tau = np.atleast_1d(tau).astype(float)
    x = tau / lam
    factor2 = np.where(x > 1e-10, (1-np.exp(-x))/x, 1.0)
    factor3 = factor2 - np.exp(-x)
    return beta1 + beta2*factor2 + beta3*factor3

# 模拟市场数据（真实参数 b1=4, b2=-3.5, b3=2, λ=2.5，加噪声）
maturities = np.array([0.25, 0.5, 1, 2, 3, 5, 7, 10, 15, 20, 30])
y_true = nelson_siegel(maturities, 4.0, -3.5, 2.0, 2.5)
rng = np.random.default_rng(7)
y_obs = y_true + rng.normal(0, 0.05, len(maturities))

def resid(p): return nelson_siegel(maturities, *p) - y_obs
res = least_squares(resid, [3,-2,1,2], bounds=([-5,-10,-10,0.1],[10,10,10,30]))
print(f"拟合: b1={res.x[0]:.3f}, b2={res.x[1]:.3f}, b3={res.x[2]:.3f}, λ={res.x[3]:.3f}")
print(f"RMSE = {np.sqrt(np.mean(resid(res.x)**2)):.4f}%")
# 典型输出: b1=3.969, b2=-3.439, b3=2.368, λ=2.829, RMSE=0.027%
```

> **验证结果**：拟合参数 (3.97, -3.44, 2.37, 2.83) 接近真值 (4.0, -3.5, 2.0, 2.5)，RMSE 仅 0.027%——曲线几乎完美复现。短端 y(0.25)≈0.78%，长端 y(30)≈3.87%，是一条典型的**向上倾斜**曲线。

## 五、信用风险与信用利差

国债（美国）被视作"无违约风险"——它的收益率纯粹反映时间价值。但公司债、新兴市场主权债有**违约可能**。信用利差（Credit Spread）就是市场对这种风险索取的额外收益。

### 5.1 信用利差的分解

公司债收益率高于同期限国债收益率的部分，叫**信用利差**：

$$s = y_{\text{corp}} - y_{\text{gov}}$$

这个利差**不全是违约风险**。它可以分解为：

$$s = \underbrace{PD \times LGD}_{\text{预期违约损失}} + \underbrace{RP}_{\text{风险溢价}} + \underbrace{LQ}_{\text{流动性溢价}} + \underbrace{TA}_{\text{税收/其他}}$$

- $PD$ = 违约概率（Probability of Default）
- $LGD$ = 违约损失率（Loss Given Default）= $1 - \text{回收率}$
- $RP$ = 风险溢价（对意外违约的补偿，>0，因为投资者风险厌恶）
- $LQ$ = 流动性溢价（公司债比国债难卖，要补偿）

**代码验证**（信用利差分解）：

```python
PD, LGD, RP, LQ = 0.05, 0.60, 0.02, 0.01  # 5%违约, 40%回收, 2%风险溢价, 1%流动性
EL = PD * LGD          # 预期损失
spread = EL + RP + LQ
print(f"预期损失 PD×LGD = {EL*100:.2f}%")
print(f"总利差 = {spread*100:.2f}%")
print(f"预期损失仅占利差的 {EL/spread*100:.0f}%")  # 50%
```

> **关键洞察**：预期违约损失（3%）只占总利差（6%）的**一半**。另一半是风险溢价和流动性溢价。这意味着——**即使你完全分散了违约风险（买了全部公司债），你仍能赚到利差**，因为你承担了**系统性风险**和**流动性风险**。这就是"信用利差之谜"的部分答案。

### 5.2 信用评级体系

评级机构（S&P / Moody's / Fitch）把发行人的违约风险分档：

| S&P | Moody's | 含义 | 历史平均违约概率（5年） |
|-----|---------|------|----------------------|
| AAA | Aaa | 最高品质 | ~0.1% |
| AA | Aa | 高品质 | ~0.3% |
| A | A | 中上 | ~0.6% |
| BBB | Baa | **投资级下限** | ~1.5% |
| BB | Ba | 投机级（低门槛） | ~5% |
| B | B | 高度投机 | ~15% |
| CCC/CC | Caa | 极度脆弱 | ~40% |
| D | C | **违约** | 100% |

**投资级（IG）vs 高收益（HY）的分界线**在 BBB-/Baa3。这条线是机构投资的"生死线"——很多基金章程规定"只能投 IG"。一只债从 BBB 降到 BB（"坠落天使"），会触发**被迫抛售**（机构必须卖出）→ 价格暴跌 → 恶性循环。

> **利益冲突问题**：评级机构由**发行人付费**（issuer-pays model）。这造成结构性利益冲突——给低评级 = 丢客户。2008 危机中，大量次贷 CDO 被评为 AAA，事后证明灾难性错误。评级是**必要但不可全信**的信号。

### 5.3 结构化模型：Merton 模型（1974）

Robert Merton 把公司股权建模为**公司资产的看涨期权**——这是信用风险建模的里程碑。

**设定**：公司资产价值 $V$ 服从几何布朗运动。公司有一笔面值 $D$、期限 $T$ 的零息债。

- 若到期时 $V_T > D$：股东还债，拿走剩余 $V_T - D$（股权价值 = $\max(V_T - D, 0)$）
- 若到期时 $V_T < D$：违约，股权归零，债权人拿走 $V_T$

$$\Rightarrow E = V\,N(d_1) - D\,e^{-rT}N(d_2) \quad\text{（股权 = 看涨期权）}$$

$$d_1 = \frac{\ln(V/D)+(r+\tfrac{1}{2}\sigma_V^2)T}{\sigma_V\sqrt{T}}, \quad d_2 = d_1 - \sigma_V\sqrt{T}$$

**违约概率** = $P(V_T < D) = N(-d_2)$。

> **深刻洞见**：在 Merton 框架里，**股权是看涨期权，债权是卖出看跌期权**。股东有限责任 = 买了"破产保护"的保险；债权人 = 卖了这个保险。增加杠杆（$D\uparrow$）会增大股权的期权价值（波动率效应），但增大违约概率——这解释了**为什么股东有时欢迎加杠杆**（把价值从债权人转移到自己）。

**代码验证**（Merton 模型）：

```python
from math import log, sqrt, exp, erf
def N(x): return 0.5*(1+erf(x/sqrt(2)))
def merton(V, D, sV, r, T):
    d1=(log(V/D)+(r+0.5*sV**2)*T)/(sV*sqrt(T)); d2=d1-sV*sqrt(T)
    return V*N(d1)-D*exp(-r*T)*N(d2), N(-d2)

E, pd = merton(V=120, D=100, sV=0.25, r=0.05, T=1)
print(f"健康公司(V=120): E={E:.2f}, PD={pd*100:.2f}%")   # 27.41, 21.06%
E, pd = merton(V=90, D=100, sV=0.25, r=0.05, T=1)
print(f"困境公司(V=90):  E={E:.2f}, PD={pd*100:.2f}%")   # 6.87, 63.55%
```

> **直觉校验**：资产 120 > 负债 100，看似健康，但一年内违约概率仍有 21%——因为 25% 的波动率意味着 $V$ 有显著概率跌破 100。资产 90 < 负债 100（已"资不抵债"），违约概率 64%。**Merton 把"资产负债表的健康度"翻译成了精确的概率**。这是 KMV 模型（Moody's KMV）的商业基础。

### 5.4 简约式模型：Jarrow-Turnbull（1995）

Merton 模型的局限：依赖可观测的资产价值 $V$（但 $V$ 本身难以直接观测，需从股价反推），且违约只在到期时发生。**简约式模型**（Reduced-form）绕开资产价值，直接把违约建模为**外生的随机过程**：

- 违约时间 $\tau$ 服从**Cox 过程**（带强度 $\lambda(t)$ 的泊松过程）
- $\lambda$ = **危险率（Hazard Rate）** = 即时违约强度
- 存活到 $t$ 的概率 = $Q(0,t) = e^{-\int_0^t \lambda(s)ds}$

$$P(\text{违约在 }[0,T]) = 1 - e^{-\int_0^T \lambda(s)ds}$$

**信用利差与危险率的关系**（简化，$LGD$ 常数，连续复利）：

$$s \approx \lambda \times LGD$$

> **两派之争**：结构化模型（Merton）从**经济机制**出发（资产跌破负债触发违约），经济学解释力强，但校准难；简约式模型从**统计现象**出发（违约是随机的跳跃），校准灵活（直接从 CDS 利差反推 $\lambda$），但缺乏经济学直觉。实务中信用衍生品定价**几乎全用简约式**（因为可校准到市场 CDS 报价）。

## 六、住房抵押贷款证券（MBS / ABS）

MBS（Mortgage-Backed Securities）和 ABS（Asset-Backed Securities）把**不流动的贷款**打包成**可交易的证券**——这是 1970s 以来的伟大金融创新，也是 2008 危机的核心炸药。

### 6.1 证券化的基本逻辑

```
房贷池(数千笔)  →  SPV(特殊目的实体)  →  分层发行(tranches)  →  卖给投资者
  (资产)            (破产隔离)            (按优先级)            (证券)
```

**核心价值**：把不能交易的贷款变成可交易证券 = **创造流动性 + 分散风险**。这是金融的"炼金术"。

### 6.2 提前还款风险（Prepayment Risk）

美国房贷大多可**无罚金提前还款**。当利率**下降**时，房主会**再融资**（借新低利率贷款还旧高利率房贷）——MBS 投资者被迫提前收回本金，只能以更低利率再投资。

> **负凸性（Negative Convexity）**：普通债券利率下降时价格上涨（正凸性，涨多）。但 MBS 利率下降时，提前还款加速，**价格涨幅被截断**——MBS 有**负凸性**。这使 MBS 比同期限国债更复杂：你卖出的是一个**隐含的看涨期权**（给房主的提前还款权）。

MBS 定价必须用**提前还款模型**（如 PSA 基准、CPR 条件提前还款率），通常结合利率路径模拟（蒙特卡洛/OAS 分析）。

### 6.3 CMO / IO / PO 结构

**CMO（Collateralized Mortgage Obligation）**把 MBS 的现金流**按优先级分层**：

| 层级（Tranche） | 特征 |
|----------------|------|
| **Sequential** | A 先拿所有本金，A 还完 B 拿，依次类推 |
| **PAC（Planned Amortization Class）** | 提供稳定的本金还款计划（只要提前还款在某区间内） |
| **Companion/Support** | 吸收提前还款的波动，保护 PAC |
| **IO（Interest Only）** | 只拿利息，不要本金——利率敏感度极度反常 |
| **PO（Principal Only）** | 只拿本金，不要利息——深度折价 |

> **IO 的反直觉**：利率**下降**时，提前还款加速 → 本金快速还完 → **剩余利息变少** → IO 价格可能**下跌**（与正常债券相反！）。IO 是固定收益世界里最"反直觉"的产品之一。

### 6.4 CDO 与 2008 危机

**CDO（Collateralized Debt Obligation）**把公司债、杠杆贷款、甚至其他 MBS 的现金流重新分层。当 CDO 的底层又是其他 CDO 的层级时，叫 **CDO²**（CDO-squared）——风险放大的平方。

2008 危机的致命链条：

1. 次级房贷（低信用借款人）被大量发放（2002-2006 房地产泡沫）
2. 这些贷款被打包成 MBS，再分层成 CDO
3. 评级机构把 CDO 的**高级层评为 AAA**（基于"违约相关性低"的错误假设）
4. 银行用 CDO 高级层做**回购融资**（短期借款买长期资产，高杠杆）
5. 房价下跌 → 违约飙升 → 违约相关性趋 1 → AAA 层也亏
6. CDO 价值崩盘 → 回购被抽贷 → 银行流动性枯竭 → **系统性危机**

> **根源诊断**：(1) **相关性假设错误**——模型假设不同地区房贷违约独立，危机时全部相关；(2) **评级失灵**——issuer-pays 的利益冲突 + 模型盲区；(3) **杠杆**——结构化产品本身不是问题，**加杠杆持有它们**才是炸药。详见 [`financial-history.md`](./financial-history.md)。

## 七、通胀保护债券（TIPS / 通胀挂钩债）

普通债券的票息和本金是**名义金额**——通胀会侵蚀实际购买力。**通胀挂钩债**（Inflation-Indexed Bonds）的本金随通胀指数调整，提供**实际收益**的确定性。

### 7.1 机制（以美国 TIPS 为例）

- **本金调整**：本金 = 面值 × 调整因子（基于 CPI）。通胀上升 → 调整本金上升 → 票息和本金都增加。
- **通缩保护**：到期时至少偿还原始面值（美国 TIPS 有通缩下限保护）。
- **实际收益率**：TIPS 的 YTM 就是市场的**实际利率预期**。

### 7.2 盈亏平衡通胀率（Breakeven Inflation）

$$\text{Breakeven Inflation} = y_{\text{名义国债}} - y_{\text{TIPS}}$$

这是市场**隐含的通胀预期**。若实际通胀 > 盈亏平衡通胀率，TIPS 跑赢名义国债（反之亦然）。

> **全球同类**：英国 Linkers（自 1981，最早）、法国 OATi、德国 Bunds、中国…通胀挂钩债的历史比美国 TIPS（1997 起）悠久得多。英国 1981 年发行的通胀挂钩金边债，是现代通胀挂钩债的鼻祖。

## 八、固定收益投资策略

### 8.1 久期匹配与免疫策略（Immunization）

**目标**：让资产的利率风险恰好对冲负债的利率风险，使**盈余（资产-负债）对利率变动不敏感**。

**条件**：资产久期 = 负债久期（且资产价值 ≥ 负债现值）。

> **养老金的命脉**：养老金欠退休员工一系列未来付款（负债）。如果资产久期太短（比如全买股票），利率下降时负债现值暴涨，资产跟不上 → 资金缺口扩大。这就是为什么养老金必须配置大量长债——**久期匹配不是收益最大化，是风险最小化**。

**代码验证**（杠铃免疫）：

```python
# 目标: 匹配久期=10年的负债。用2年期+30年期债构建杠铃。
# w*Da + (1-w)*Db = 10  =>  w = (10-Db)/(Da-Db)
# (2年债 Da≈1.90, 30年债 Db≈16.37)
w = (10 - 16.374) / (1.899 - 16.374)  # = 0.440
print(f"杠铃: {w*100:.1f}% 买2年债, {(1-w)*100:.1f}% 买30年债")
print(f"组合久期 = {w*1.899+(1-w)*16.374:.2f}年")  # 10.00 ✓
```

### 8.2 三大经典组合形态

| 策略 | 现金流分布 | 适用场景 |
|------|-----------|---------|
| **子弹（Bullet）** | 集中在单一到期日 | 匹配单笔未来负债 |
| **杠铃（Barbell）** | 两端集中（短+长） | 凸性更高（利于波动） |
| **梯子（Ladder）** | 均匀分布各到期年 | 滚动再投资，平滑利率风险 |

**杠铃 vs 子弹的凸性权衡**：杠铃（短+长组合）比子弹（中间到期）**凸性更高**——因为长债贡献凸性。在**高波动**环境，杠铃优于子弹（凸性增值）；在**低波动**环境，子弹优于杠铃（不付凸性溢价）。

### 8.3 收益率曲线策略

- **骑乘曲线（Riding the Yield Curve / Roll-down）**：向上倾斜曲线下，买入并持有——随时间推移，债券"滚下"更陡的短端，赚取资本利得（只要曲线形态不变）。
- **曲线陡峭化/平坦化交易**：做多一段、做空另一段，赌曲线斜率变化。
- **蝶式交易（Butterfly）**：做多蝶翼（短端+长端）、做空腹部（中端），赌曲率变化。

## 九、中国的债券市场

中国债券市场是全球第二大，但结构与欧美差异巨大——理解中国债市，必须理解**银行主导**和**利率市场化**这两个关键词。

### 9.1 双轨制市场结构

| 市场 | 占比 | 主要品种 | 参与者 |
|------|------|---------|--------|
| **银行间市场** | **~90%** | 国债、政金债、NCD、信用债 | 银行、保险、基金（机构为主） |
| **交易所市场** | ~10% | 国债、公司债、可转债 | 券商、散户、部分机构 |

> **关键特征**：中国债市是**银行间主导**（场外 OTC），而非交易所主导。这反映了中国的金融结构——银行是绝对主体，债市首先服务于银行的资产负债管理。这与美国（交易所/电子化做市更发达）形成对比。

### 9.2 主要品种

- **国债**：财政部发行，无风险基准。关键期限 1/3/5/7/10 年。
- **政策性金融债（政金债）**：国开行、进出口行、农发行发行，**准主权信用**（隐性国家担保），流动性好，常被视为"准国债"。
- **同业存单（NCD）**：银行发行的短期融资工具，是银行负债端的重要工具，也是货币市场基准。
- **地方政府债**：2015 年大规模置换开始，现为最大品种之一。地方债背后是**土地财政**的信用（详见 [`china-financial-system.md`](./china-financial-system.md)）。
- **信用债**：公司债（交易所）、企业债（发改委体系）、中票/短融（银行间交易商协会）——多头监管，品种繁多。
- **城投债**：地方融资平台发行的债务。**不是真正的地方政府债**，但有隐性担保预期——这是中国特有的"灰色信用"地带。

### 9.3 利率市场化进程

中国利率市场化走过 20 年：

1. **1996-2015**：逐步放开贷款和存款利率浮动（2015 年基本完成名义放开）
2. **2019**：改革 LPR（贷款市场报价利率）机制，LPR 取代基准贷款利率成为贷款定价锚
3. **存款利率**：2022 年起建立存款利率市场化调整机制，参考 LPR 和国债收益率

> **未竟之业**：存款利率仍受**市场利率定价自律机制**的软约束（隐性上限），银行息差受保护但也受限。"利率双轨制"（市场化的资产端 vs 半管制的负债端）仍未完全消除。这是理解中国货币政策传导效率的关键。

### 9.4 中美国债收益率曲线的对比

- **美国**：10 年期国债是全球资产定价锚，曲线反映全球对美元安全资产的需求。
- **中国**：10 年期国债收益率更多反映**国内基本面和货币政策**。中国曲线与美国的联动性在增强（资本账户渐进开放），但仍受资本管制隔离。

## 十、跨学科映射

> 固定收益的数学结构，与物理学、工程学、精算学共享**同构的骨架**。

| 固定收益概念 | 对应学科/概念 | 共同骨架 |
|-------------|-------------|---------|
| **贴现/现值** | 物理学：信号衰减、阻尼振荡 | 未来事件对今天的"影响"随距离（时间）指数衰减 |
| **久期** | 力学：质心（center of mass） | 加权平均位置——久期就是现金流的"时间质心" |
| **凸性** | 光学：像差、非线性畸变 | 一阶近似的"曲率修正"——二阶导捕捉弯曲 |
| **久期-凸性近似** | 泰勒展开（普遍数学工具） | 任意光滑函数 = 局部多项式——金融版的"线性化+修正" |
| **收益率曲线** | 热传导方程的解曲线 | 一个参数化曲面描述系统状态随时间的演化 |
| **无套利** | 热力学第二定律（无永动机） | "没有免费午餐"作为公理——禁止自发创造价值 |
| **违约的泊松过程** | 放射性衰变、地震发生 | 稀有事件的记忆-less 随机到达——危险率模型 |
| **Merton 模型（股权=期权）** | 期权定价（Black-Scholes） | 债权和股权是同一资产价值的**不同衍生品** |
| **免疫策略** | 控制论：鲁棒控制、对消扰动 | 让系统输出（盈余）对外部扰动（利率）不敏感 |
| **提前还款的负凸性** | 可赎回债券 / 嵌入期权 | 卖出一个期权 = 接受一个不利的不对称性 |

> **核心洞察**：久期 = "现金流的时间质心"——这个类比不是修辞，是**数学同构**。质心 $\bar{x} = \sum m_i x_i / \sum m_i$，久期 $D = \sum t\cdot PV_t / P$。把"质量"换成"现值"，"位置"换成"时间"，力学的质心公式直接变成金融的久期公式。这就是为什么 fixed income 被称为"金融中最像物理学的分支"。

## 十一、开放问题

> 这些问题没有标准答案——保持张力本身就是好的思考姿态。

1. **收益率曲线倒挂的"预测力"是否在失效？**  
   2022-2023 美国曲线深度倒挂超 18 个月，衰退至今（2026 中）未现。是 AI 生产率革命改变了规律？是财政赤字对冲了货币紧缩？还是滞后仍在发酵？一个工作了 70 年的指标如果失效，意味着**底层结构发生了变化**——这正是最值得警惕的信号。

2. **负利率在理论上可能吗？在实践中可持续吗？**  
   2019-2021 欧元区、日本出现**负收益率国债**——借钱给人还要倒贴。这违背了"时间价值"的基本直觉（今天的钱应比未来值钱）。负利率的存在说明：当**安全资产稀缺**到极致，"储藏价值"本身变成付费服务。这是货币理论的极限情况。

3. **TIPS 的盈亏平衡通胀率，是"预期"还是"预期+风险溢价"？**  
   盈亏平衡通胀 ≠ 纯粹的通胀预期——它还包含通胀风险溢价和流动性折价。分解这两者极难（需要模型假设）。我们永远无法直接观测"市场真正的通胀预期"——它被埋在利差里，需要假设才能挖出。

4. **结构化 vs 简约式信用模型，哪个更"对"？**  
   Merton 模型经济学深刻但校准困难；简约式模型校准灵活但经济空洞。这是"**解释力 vs 可用性**"的经典权衡。更深的问题是：违约真的有"机制"吗（资产跌破负债），还是它是无法预测的外生跳跃？这触及**决定论 vs 随机性**的哲学根本。

5. **中央银行持有巨额国债，扭曲了收益率曲线吗？**  
   QE（量化宽松）让央行成为长债的最大持有者。央行不是利润最大化的投资者——它的需求扭曲了市场价格。那么，**后 QE 时代的收益率曲线，还是"市场预期"吗？还是央行的政策投影？** 这质疑了收益率曲线作为"信息聚合器"的认识论地位。

6. **当 AI 主导固定收益交易，久期还是正确的风险度量吗？**  
   久期假设收益率曲线**平行移动**（所有期限同向同幅变动）。但 AI/因子模型发现曲线变动有**多个独立因子**（水平/斜率/曲率，即 NS 的三个 $\beta$）。久期只捕捉了水平因子——它是"简化"还是"误导"？在多因子风险框架下，单一久期是否过时？

```bash
python3 << 'EOF'
import numpy as np
from scipy.optimize import brentq, least_squares
from math import log, sqrt, exp, erf

def bond_price(cr,f,y,n,m=2):
    c=cr*f/m; yy=y/m
    return sum(c/(1+yy)**t for t in range(1,n+1))+f/(1+yy)**n

def dur_conv(cr,f,y,n,m=2):
    c=cr*f/m; yy=y/m; t=np.arange(1,n+1)
    cf=np.full(n,c); cf[-1]+=f; pv=cf/(1+yy)**t; P=pv.sum()
    mac=(t*pv).sum()/P/m; mod=mac/(1+yy)
    conv=((t*(t+1))*pv).sum()/(P*(1+yy)**2)/m**2
    return P, mac, mod, conv

P,mac,mod,conv = dur_conv(0.05,100,0.05,10,2)
print(f"5年5%债: ModDur={mod:.3f}, Conv={conv:.2f}, DV01≈{mod*P*1e-4:.4f}")
print(f"+100bp久期预测: {-mod*0.01:.2%}, 久期+凸性: {-mod*0.01+0.5*conv*0.01**2:.2%}, 实际: {(bond_price(.05,100,.06,10)-100)/100:.2%}")
EOF
```
