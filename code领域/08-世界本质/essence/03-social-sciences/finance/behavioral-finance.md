## 引言：一个无法回避的事实

如果你在 2000 年 3 月买入纳斯达克指数基金，到 2002 年 10 月你亏了 78%。如果你在 2007 年买入中国石油（A股 IPO 价 16.7 元），到 2008 年你亏了 75%。如果你在 2021 年买入任何"明星基金"，到 2024 年你大概率还在亏损。

这些不是个案。这是**系统性模式**：

- 散户**集体**在泡沫顶部买入（高买）
- 散户**集体**在崩盘底部卖出（低卖）
- 散户**集体**过早卖出盈利股
- 散户**集体**死扛亏损股
- 散户**集体**交易太多、分散太少、追热点太狠

有效市场假说说"价格反映所有信息"——但 2000 年的纳斯达克 5000 点反映了什么信息？2007 年的中石油 48 元反映了什么信息？2021 年的核心资产 80 倍 PE 反映了什么信息？

> **一句话**：行为金融学的核心发现是——**人类大脑不是为金融市场设计的**。我们的大脑进化自大草原，优化目标是"在部落中生存"，不是"在随机游走中最大化夏普比率"。我们系统性犯错，因为我们用旧硬件跑新软件。

## 一、行为金融的诞生——对"理性人"的反叛

### 1.1 新古典金融的理性人假设

新古典金融学的整座大厦，建立在一个假设上：**Homo Economicus（理性经济人）**。这个假设包含三个公理：

| 公理 | 内容 | 数学表达 |
|------|------|---------|
| **期望效用最大化** | 人在风险下选择期望效用最高的选项 | $\max E[u(W)] = \sum p_i \cdot u(w_i)$ |
| **贝叶斯更新** | 人获得新信息后按贝叶斯法则修正信念 | $P(H\mid E) = \frac{P(E\mid H)P(H)}{P(E)}$ |
| **风险厌恶** | 效用函数凹（$u'' < 0$），要求风险溢价才承担风险 | $u(W) = \frac{W^{1-\gamma}}{1-\gamma}$ |

这三个公理合在一起，推导出了 CAPM、Black-Scholes、有效市场假说——全部现代金融学的核心定理。**没有理性人，就没有这一切。**

### 1.2 三大反例——理性公理的裂缝

但实验经济学很快发现，人类**系统性地违反**这三条公理。

#### 反例 1 · 圣彼得堡悖论（Bernoulli, 1713/1738）

> 抛硬币。第一次正面得 2 元，第二次正面得 4 元，第 $n$ 次正面得 $2^n$ 元，直到出现反面为止。你愿意付多少钱玩这个游戏？

**期望值**：$E = \sum_{n=1}^{\infty} \frac{1}{2^n} \cdot 2^n = \sum_{n=1}^{\infty} 1 = \infty$

期望值是无穷大！但**没有人愿意付超过 10-20 元**。这直接违反了"期望值最大化"公理。Bernoulli 的解释是：人不是最大化期望货币值，而是最大化期望**效用**——边际效用递减（$u = \ln W$）。这是期望效用理论的起点，但也埋下了"理性公理需要修正"的第一颗种子。

#### 反例 2 · Allais 悖论（1953）

> **选择 A**：100% 得 100 万。  
> **选择 B**：10% 得 500 万 + 89% 得 100 万 + 1% 得 0。

期望值：$E[A] = 100$ 万，$E[B] = 139$ 万。理性人应选 B。但**大多数人选 A**——确定性效应（certainty effect）。

Allais 证明了：人类在评估概率时，**不是线性的**。100% 的概率被过度加权（"确定"有特殊心理权重），而 99% 和 100% 之间的心理距离远大于 10% 和 11% 之间的距离。这违反了期望效用理论的**独立性公理**（independence axiom）。

#### 反例 3 · Ellsberg 悖论（1961）

> 缸里有 90 个球：30 个红球，剩下 60 个是黑球或黄球（比例未知）。  
> **赌注 A**：抽到红球赢 100 元。  
> **赌注 B**：抽到黑球赢 100 元。

两个赌注的期望值应该一样（概率都是 1/3 vs 未知但对称），但**大多数人选 A**——偏好已知概率，厌恶"模糊"（ambiguity）。

Ellsberg 证明了：人类不仅在乎概率大小，还在乎**概率的确定性程度**。这是"模糊厌恶"（ambiguity aversion）——违反了贝叶斯更新公理（贝叶斯法则不区分"已知概率"和"估计概率"）。

### 1.3 Kahneman-Tversky 的范式转移（1979）

1979 年，Daniel Kahneman 和 Amos Tversky 在 *Econometrica* 发表了**《Prospect Theory: An Analysis of Decision under Risk》**。这篇论文做了一件颠覆性的事：

**他们不再假设人是理性的，而是直接测量人实际上怎么决策。**

他们的方法很简单：给受试者一系列二选一的选择题，记录选择模式，然后反推出一个**描述性的决策模型**——不问"人应该怎么做"，只问"人实际上怎么做"。

结果就是**前景理论（Prospect Theory）**——一个用三个参数就能解释 Allais 悖论、Ellsberg 悖论、损失厌恶、确定性效应的统一框架。

> **范式转移**：从"理性人应该怎么做"（规范性）到"人实际怎么做"（描述性）。这不是修正理性公理——而是**抛弃**它作为描述性基础的地位。理性公理仍然作为"理想基准"存在（就像物理学中的理想气体），但不再是描述人类行为的工具。

Kahneman 因此获得 2002 年诺贝尔经济学奖（Tversky 于 1996 年去世，未能共享）。评委会说："他把心理学研究带入了经济学，特别是关于人在不确定条件下的判断和决策。"

## 二、前景理论深度——三层讲解

### 直觉层

前景理论的核心洞察可以用一句话概括：

> **人对损失的痛苦 ≈ 2.25 倍等量收益的快乐。**

想象你捡到 100 元的快乐值是 +10 分。那么丢失 100 元的痛苦不是 -10 分，而是 **-22.5 分**。

这个不对称导致了所有行为金融的"反常"现象：

| 现象 | 直觉解释 |
|------|---------|
| **不肯止损** | 卖出 = 实现亏损 = 承受 -22.5 分。不卖 = 亏损还只是"浮亏" = 心理上还没发生。所以宁愿赌它涨回来。 |
| **过早止盈** | 卖出 = 实现盈利 = 获得 +10 分。不卖 = 怕利润回吐。所以"落袋为安"。 |
| **买彩票** | 人对极小概率事件过度反应——1% 的概率被"感觉"成 5%。所以愿意花钱买几乎不可能的梦。 |
| **买保险** | 同样的概率扭曲 + 损失厌恶双重作用——1% 的灾难被放大成噩梦。所以愿意付高于期望的保费。 |

### 数学层

前景理论由两个函数组成：**价值函数** $v(x)$ 和**概率权重函数** $\pi(p)$。

#### 价值函数

$$v(x) = \begin{cases} x^\alpha & x \geq 0 \quad \text{（收益区：凹函数 → 风险厌恶）} \\ -\lambda(-x)^\beta & x < 0 \quad \text{（损失区：凸函数 → 风险寻求）} \end{cases}$$

参数标定（Tversky & Kahneman, 1992）：
- $\alpha = \beta = 0.88$：曲率。小于 1 意味着边际价值递减（赚第一个 1 万很爽，赚第 100 个 1 万没那么爽）。
- $\lambda = 2.25$：损失厌恶系数。等量损失的价值是收益的 2.25 倍。

三个数学特征：
1. **定义在损益上，不是绝对财富上**——人关心的是"相对于参考点的变化"，不是绝对水平。（参考点通常是买入价。）
2. **S 形**：收益区凹（风险厌恶），损失区凸（风险寻求）。
3. **损失区更陡**：$|v(-x)| > |v(+x)|$，即损失比收益"更重"。

#### 概率权重函数

$$\pi(p) = \frac{p^\gamma}{(p^\gamma + (1-p)^\gamma)^{1/\gamma}}$$

参数标定：$\gamma = 0.61$（收益），$\delta = 0.69$（损失）。

这个函数的形状是**反转 S 形**：
- 小概率（$p < 0.3$）被**高估**：$\pi(0.01) \approx 0.055$，即 1% 被感觉成 5.5%。
- 大概率（$p > 0.5$）被**低估**：$\pi(0.99) \approx 0.91$，即 99% 被感觉成 91%。
- 拐点在 $p \approx 0.35$ 附近。

#### 前景值的计算

一个前景（prospect）$(p_1, x_1; p_2, x_2; \ldots)$ 的总价值：

$$V = \sum_i \pi(p_i) \cdot v(x_i)$$

人选择 $V$ 更大的选项，而不是 $E[u(W)]$ 更大的选项。

### 代码层

```python
# === 前景理论：价值函数 + 概率权重函数 ===
# 验证：损失厌恶、概率扭曲、确定性效应、反射效应
import numpy as np

# ---- 参数（Tversky-Kahneman 1992 标定）----
ALPHA  = 0.88   # 收益区曲率（凹）
BETA   = 0.88   # 损失区曲率（凸）
LAMBDA = 2.25   # 损失厌恶系数
GAMMA  = 0.61   # 收益概率权重曲率
DELTA  = 0.69   # 损失概率权重曲率

def value_function(x, alpha=ALPHA, beta=BETA, lam=LAMBDA):
    """前景理论价值函数 v(x)。x 为相对参考点的损益。"""
    x = np.asarray(x, dtype=float)
    result = np.empty_like(x)
    pos = x >= 0
    result[pos]  = x[pos] ** alpha              # 收益：凹
    result[~pos] = -lam * (-x[~pos]) ** beta    # 损失：凸 × 惩罚
    return result

def prob_weight(p, gamma=GAMMA):
    """Tversky-Kahneman (1992) 概率权重函数 π(p)。"""
    p = np.asarray(p, dtype=float)
    return p**gamma / (p**gamma + (1-p)**gamma)**(1.0/gamma)

# ---- ① 损失厌恶 ----
print("① 损失厌恶：等量收益 vs 损失的价值不对称")
V, w = value_function, prob_weight
print(f"  {'金额':>6} {'v(+x)':>10} {'v(-x)':>10} {'|损失|/|收益|':>14}")
for amt in [10, 50, 100, 500, 1000]:
    vg, vl = float(V(amt)), float(V(-amt))
    print(f"  {amt:>6} {vg:>+10.2f} {vl:>+10.2f} {abs(vl)/vg:>14.2f}")

# ---- ② 概率权重 ----
print("\n② 概率权重 π(p)：小概率高估，大概率低估")
print(f"  {'p':>6} {'π_收益':>8} {'π_损失':>8} {'偏差':>6}")
for p in [0.001, 0.01, 0.05, 0.10, 0.25, 0.50, 0.75, 0.90, 0.99]:
    wg, wl = float(w(p, GAMMA)), float(w(p, DELTA))
    print(f"  {p:>6.3f} {wg:>8.4f} {wl:>8.4f} {'高估↑' if wg>p else '低估↓':>6}")

# ---- ③ 共比例效应（Allais 简化版）----
print("\n③ 共比例效应 (KT 1979 经典实验)")
# 问题1：确定 3000 vs 80% 概率 4000
V1A = float(w(1.0) * V(3000))          # 确定得3000
V1B = float(w(0.8) * V(4000))          # 80%得4000
print(f"  Q1: 确定3000 vs 80%×4000")
print(f"    EV: 3000 vs 3200 → 理性选B | PT: {V1A:.0f} vs {V1B:.0f} → 选{'A' if V1A>V1B else 'B'}")
print(f"    实验: 80%人选A（确定性效应）")
# 问题2：25% 得 3000 vs 20% 得 4000
V2A = float(w(0.25) * V(3000))
V2B = float(w(0.20) * V(4000))
print(f"  Q2: 25%×3000 vs 20%×4000")
print(f"    EV: 750 vs 800 → 理性选B | PT: {V2A:.0f} vs {V2B:.0f} → 选{'A' if V2A>V2B else 'B'}")
print(f"    实验: 65%人选B（概率缩小后偏好翻转）")

# ---- ④ 反射效应：损失区变风险追求 ----
print("\n④ 反射效应：收益风险厌恶，损失风险寻求")
V3A = float(w(1.0, DELTA) * V(-3000))  # 确定亏3000
V3B = float(w(0.8, DELTA) * V(-4000))  # 80%亏4000
print(f"  损失域: 确定亏3000({V3A:.0f}) vs 80%亏4000({V3B:.0f})")
print(f"    → PT选{'确定亏(不赌)' if V3A>V3B else '赌(可能亏更多)'}")
print(f"    实验: 92%人选赌博 → 这就是不肯止损的数学根源")
```

## 三、认知偏差全谱系——系统化分类

前景理论解释了人在**风险选择**中的偏差。但人类的认知偏差远不止于此。这里按 Kahneman 的"双系统理论"框架（系统 1 = 快速直觉，系统 2 = 慢速推理），把金融相关的认知偏差分为四大类。

### A. 启发式偏差（Heuristic Biases）——判断错误

启发式（heuristic）是大脑的"快捷方式"——用简单的规则代替复杂的计算。大多数时候它们管用（这就是进化的理由），但在金融场景中，它们**系统性失灵**。

| 偏差 | 定义 | 金融实例 |
|------|------|---------|
| **代表性启发**（Representativeness） | 用"像不像"判断"是不是"——过度依赖相似性，忽视基础概率 | 赌徒谬误：连涨 5 天就觉得"该跌了"（赌场记忆效应）。热手效应：基金经理连续 3 年跑赢就认为他有"真本事"（可能只是运气） |
| **可得性启发**（Availability） | 越容易回忆的事件越觉得它常见 | 2008 年危机后所有人觉得"房价必跌"（但长期看房价大多上涨）。最近的新闻影响过大——某公司出了一次负面，就觉得它整体不行 |
| **锚定效应**（Anchoring） | 初始数字（即使是随机的）影响后续判断 | "这只股票从 100 跌到 50，很便宜了"——100 是锚，但 100 和"便宜不便宜"无关。分析师的目标价锚定了你的预期 |

```python
# === 锚定效应模拟 ===
import numpy as np
np.random.seed(7)

TRUE_VALUE = 3200  # 假设真实合理值
n = 200
print("锚定效应：随机锚如何扭曲判断")
print(f"  真实合理值 = {TRUE_VALUE}")
for label, anchor in [("低锚(2500)", 2500), ("高锚(4000)", 4000)]:
    w = np.random.uniform(0.25, 0.45, n)  # 锚的权重
    estimates = anchor * w + TRUE_VALUE * (1 - w) + np.random.normal(0, 150, n)
    print(f"  {label}: 平均预测 {estimates.mean():.0f} (偏差 {estimates.mean()-TRUE_VALUE:+.0f})")
print("  → 高锚系统性高估，低锚系统性低估，即使锚是随机给的")
```

```
  真实合理值 = 3200
  低锚(2500): 平均预测 2952 (偏差 -248)
  高锚(4000): 平均预测 3469 (偏差 +269)
  → 高锚系统性高估，低锚系统性低估，即使锚是随机给的
```

### B. 自我偏差（Self-Related Biases）——自我欺骗

这类偏差的共同特征是：**人系统性地高估自己**。

| 偏差 | 定义 | 金融实例 |
|------|------|---------|
| **过度自信**（Overconfidence） | 高估自己的知识、能力和预测准确性 | "我能跑赢市场"——90% 的司机认为自己的驾驶水平高于平均（Lake Wobegon 效应）。散户平均年换手率 200%+，远超合理的分散策略 |
| **自归因偏差**（Self-Attribution） | 成功归因于能力，失败归因于运气 | 赚钱时："我选股眼光准"。亏钱时："大盘不好/庄家操纵/运气差"。结果：不学习、不复盘、不改进 |
| **确认偏差**（Confirmation） | 只注意/记住支持自己观点的信息，忽略反面证据 | 看多某只股票后，只读看多的研报，屏蔽看空的分析。最终活在信息茧房里 |

```python
# === 过度自信：Barber-Odean (2001) 性别与交易 ===
# 核心洞察：男女选股能力相同，但交易频率不同 → 交易成本差异 → 净收益差异
import numpy as np
np.random.seed(42)
n, market_ret = 10000, 0.08
print("过度自信的代价 (Barber-Odean 2001)")
print("  假设：男女选股能力相同（都跟踪市场 8%），差异仅来自交易频率")
print(f"  {'群体':>12} {'年换手率':>8} {'交易成本':>8} {'年化净收益':>10}")
# 同一组选股收益，确保差异只来自成本
stock_picks = np.random.normal(market_ret, 0.15, n)
for label, turnover in [("女性", 0.50), ("男性", 0.75)]:
    cost = turnover * 0.005 * 2   # 买卖双向各0.5%
    net = stock_picks - cost       # 同样的选股，只差成本
    print(f"  {label:>12} {turnover*100:>7.0f}% {cost*100:>7.2f}% {net.mean()*100:>9.2f}%")
print("  → 交易越多 → 交易成本越高 → 净收益越低")
print("  → Barber-Odean 实证：男性年换手率比女性高 45%，净收益低 1.4pp")
print()

# === 确认偏差：信息消费不对称 ===
print("确认偏差：同样的信息，不同的'现实'")
for stance, gr, br in [("看多者",0.80,0.20), ("看空者",0.20,0.80)]:
    print(f"  {stance}: 50利好/50利空 → 感知 {int(50*gr)}利好/{int(50*br)}利空")
print("  → 信息消费是选择性失明——你看到的是你想看到的")
```

### C. 情绪偏差（Emotional Biases）——感情用事

这类偏差不是认知错误，而是**情绪驱动的行为**——你知道应该止损，但你做不到。

| 偏差 | 定义 | 金融实例 |
|------|------|---------|
| **损失厌恶**（Loss Aversion） | 等量损失的心理痛苦 ≈ 2.25 倍收益的快乐 | 死扛亏损股，不肯割肉——"只要不卖，就没真亏" |
| **禀赋效应**（Endowment Effect） | 拥有的东西估值更高 | 买入后立刻觉得它"值更多"。卖价比买价高 2-3 倍才肯卖（Thaler 实验：咖啡杯拥有者要价是非拥有者出价的 2 倍以上） |
| **处置效应**（Disposition Effect） | 卖盈持亏——过早卖出盈利股，过久持有亏损股 | 这是损失厌恶在交易中的直接表现：盈利时风险厌恶→落袋为安；亏损时风险寻求→赌它回来 |
| **从众/羊群效应**（Herding） | 跟着多数人行动，放弃独立判断 | 泡沫的本质：每个人都知道价格不合理，但每个人也都相信"自己能在崩盘前跑掉"。凯恩斯："世俗智慧教导我们：以常规方式失败胜过以非常规方式成功。" |

**处置效应模拟**（核心代码——见下方完整模拟）：

```python
# === 处置效应模拟 (Disposition Effect) ===
# 预言：亏损股持有时间 >> 盈利股持有时间（前景理论的直接推论）
import numpy as np
np.random.seed(42)

N_TRADERS, MAX_DAYS = 1000, 250
ENTRY, DRIFT, VOL = 100.0, 0.0002, 0.02
SELL_BASE, GAIN_BOOST, LOSS_DRAG = 0.01, 0.08, 0.06

results = []
for _ in range(N_TRADERS):
    price = ENTRY
    for day in range(1, MAX_DAYS + 1):
        price *= np.exp(np.random.normal(DRIFT, VOL))
        pnl_pct = (price - ENTRY) / ENTRY
        # 前景理论驱动：盈利→倾向卖出，亏损→倾向持有
        if pnl_pct > 0:
            sell_p = SELL_BASE + GAIN_BOOST * min(pnl_pct, 0.3)
        else:
            sell_p = max(SELL_BASE - LOSS_DRAG * min(-pnl_pct, 0.3), 0.001)
        if np.random.random() < sell_p:
            results.append((day, price - ENTRY, pnl_pct > 0)); break
    else:
        results.append((MAX_DAYS, price - ENTRY, pnl_pct > 0))

r = np.array([(d, p, int(g)) for d, p, g in results])
days, is_gain = r[:, 0], r[:, 2].astype(bool)
gd, ld = days[is_gain], days[~is_gain]

print(f"处置效应模拟 (N={N_TRADERS}, {MAX_DAYS}天)")
print(f"  盈利卖出 {is_gain.sum()}人 | 亏损卖出 {(~is_gain).sum()}人")
print(f"  盈利股平均持有 {gd.mean():.0f}天 | 亏损股平均持有 {ld.mean():.0f}天")
print(f"  亏损股持有 ≈ 盈利股的 {ld.mean()/gd.mean():.1f} 倍")
z = (ld.mean()-gd.mean()) / np.sqrt(gd.std(ddof=1)**2/len(gd) + ld.std(ddof=1)**2/len(ld))
print(f"  差异检验 z={z:.1f} → {'极显著 p<0.001' if abs(z)>3.3 else '显著'}")
print(f"  → 卖掉会涨的，留下会跌的 → 系统性跑输市场")
```

```
  盈利股平均持有 75天 | 亏损股平均持有 131天
  亏损股持有 ≈ 盈利股的 1.7 倍
  差异检验 z=9.4 → 极显著 p<0.001
```

### D. 框架效应（Framing Effects）——语境操控

这类偏差揭示了一个深刻的事实：**人不是对"客观现实"做反应，而是对"被呈现的现实"做反应**。同样的信息，不同的表达方式，引发完全不同的决策。

| 偏差 | 定义 | 金融实例 |
|------|------|---------|
| **心理账户**（Mental Accounting, Thaler） | 把钱分到不同的"心理账户"区别对待，违反了货币的可替代性（fungibility） | 辛苦赚的工资舍不得花，意外中奖/分红随便花。工资定投基金，奖金全买彩票——同样的钱，来源不同就区别对待 |
| **框架效应**（Framing, Kahneman-Tversky） | 同一个问题，正面表述 vs 负面表述 → 不同选择 | "这个策略 90% 的情况下存活"听起来比"10% 的情况下破产"好得多——但它们是同一件事。"已涨 50%" vs "从最高点跌了 33%" |
| **货币幻觉**（Money Illusion） | 关注名义金额，忽视通胀 | "我的房子 10 年涨了 100%！"（但 CPI 涨了 40%，实际只涨了 43%）。"工资涨了 5%！"（但通胀 6%，实际购买力下降了） |
| **沉没成本谬误**（Sunk Cost） | 因为已经投入了，所以继续投入 | "这只股票我已经亏了 50% 了，现在卖太亏了"——但过去投入的钱是沉没成本，和"未来该不该持有"完全无关 |

> **框架效应的哲学深意**：它挑战了"理性人"的最底层假设——如果决策取决于问题的**表达方式**而非**内容本身**，那么"客观偏好"就不存在。偏好是**被构造的**，不是被发现的。这是对理性选择理论的根本性挑战（参见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 假设 1）。

## 四、市场异象——行为金融的实证弹药

如果偏差只存在于实验室，行为金融不过是心理学游戏。但偏差在**真实市场**中留下了可观测的痕迹——这就是"市场异象"（anomalies）：**无法被有效市场假说解释的系统性价格模式**。

### 4.1 动量效应（Momentum, Jegadeesh-Titman 1993）

**现象**：过去 3-12 个月表现好的股票，未来 3-12 个月继续表现好；表现差的继续差。

> 买入过去 6 个月涨幅前 10% 的股票，卖空后 10%，可获得年化约 **12%** 的超额收益（扣除了市场风险后）。

**行为解释**：
- **保守主义偏差**（underreaction）：人对新信息反应不足——好消息出来后，价格只涨了一半，剩下的要慢慢涨。
- **羊群效应**：赢家吸引更多买家，正反馈推高价格。

**被套利消除了吗？**：部分。动量策略在 2000 年代初回撤巨大（动量崩溃），但仍未完全消失。Fama-French 五因子模型加入了动量因子（UMD）。

### 4.2 反转效应（Reversal, De Bondt-Thaler 1985）

**现象**：过去 3-5 年表现最差的股票，未来 3-5 年反而表现最好（反转）。

> 买入过去 3 年跌幅最大的"输家组合"，卖空涨幅最大的"赢家组合"，可获得年化约 **5%** 的超额收益。

**行为解释**：
- **过度反应**（overreaction）：投资者对坏消息反应过度，把好公司砸得太低。
- **代表性启发**："连续亏钱 = 这公司不行了"——但均值回归是基本的统计规律。

**与动量的关系**：短期动量（6-12 月）+ 长期反转（3-5 年）= **同一个偏差在不同时间尺度的表现**。短期反应不足（动量），长期反应过度（反转）。

### 4.3 规模效应（Size Effect, Banz 1981）

**现象**：小市值公司的长期平均收益率高于大市值公司（风险调整后）。

**行为解释**：小公司关注度低（可得性偏差）、流动性差（需要流动性溢价）、信息不对称严重。但 Barber-Odean 发现散户**偏爱**小公司（彩票偏好——小公司暴涨概率高）。

**是否被消除？**：Fama-French 三因子模型（1993）正式纳入规模因子（SMB）。但 1981 年后被发现后，规模溢价有所收窄。

### 4.4 价值效应（Value Effect, Fama-French 1993）

**现象**：低 P/B（市净率）、低 P/E（市盈率）的价值股，长期跑赢高估值的成长股。

> 买入 P/B 最低 30% 的股票，卖空最高 30%，年化超额收益约 **4-5%**。

**行为解释**：
- **过度外推**（extrapolation bias）：投资者把过去的高增长外推到未来，对成长股估值过高。
- **禀赋效应 / 锚定**：热门股被锚定在高估值，投资者不愿认输。

**争议**：Fama 认为价值溢价是**风险补偿**（价值股在经济衰退时更脆弱）；行为派认为它是**偏差定价**（被过度悲观砸低）。两者至今未分胜负。

### 4.5 日历效应（Calendar Effects）

| 效应 | 现象 | 行为解释 |
|------|------|---------|
| **一月效应**（January Effect） | 小盘股在 1 月（尤其前 5 天）异常强势 | 税损卖出（tax-loss selling）：年底卖出亏损股抵税 → 1 月买回 → 价格反弹 |
| **周一效应**（Monday Effect） | 周一平均收益为负（美股） | 周末累积的坏情绪在周一释放（情绪效应，存争议） |
| **假日效应** | 假日前一天收益偏高 | 节日前乐观情绪，交易清淡 |

**是否被消除？**：大部分日历效应在被广泛报道后已大幅减弱——这是"异象被发现后即消失"的典型案例。

### 异象的本质追问

> 这些异象说明了什么？有效市场派说："数据挖掘（data snooping）——在无数可能的策略中，总有一些在过去'显著'。"行为派说："它们是人类偏差的市场投影——偏差不会消失，只是换了表现形式。"
>
> **essence 立场**：异象的存在证明了市场**不完全有效**，但不意味着市场**完全无效**。异象的存在恰恰是市场效率的**动力**——套利者发现异象、交易异象、消除异象，这个过程本身让市场趋向有效（但不完全达到）。

## 五、有限套利——为什么异象不被消除？

有效市场假说的逻辑很简单：如果价格偏离价值，**理性套利者**会买入低估的、卖出高估的，把价格推回合理水平。偏差定价应该被瞬间消除。

但现实中，异象持续存在——有的持续了几十年。为什么？行为金融的第二根支柱——**有限套利**（Limits to Arbitrage）——回答了这个问题。

### 5.1 Shiller 的洞见：套利有成本和风险

Robert Shiller（1981）在《Do Stock Prices Move Too Much to Be Justified by Subsequent Changes in Dividends?》中证明：**股价的波动性远超基本面（股利）的波动性**。价格不只是在反映信息——它在**过度反应**。

### 5.2 噪音交易者风险（De Long et al, 1990）

> **核心洞见**："市场保持非理性的时间，可能比你保持偿付能力的时间更长。"（凯恩斯）

即使你知道某资产被高估了，你做空它，你也可能亏钱——因为**非理性交易者可以把价格推得更高**。在价格回归理性之前，你可能已经被迫平仓（追加保证金）。

经典案例：
- **1998 年 LTCM**：LTCM 做空高估的俄罗斯国债利差——方向是对的，利差最终确实回归了。但俄罗斯违约前，利差先扩大了 10 倍，LTCM 在回归之前就爆仓了。
- **2000 年互联网泡沫**：很多对冲基金在 1998-1999 年做空互联网股——方向是对的，但泡沫又涨了 200%，很多做空者在泡沫破裂前就已经破产。

### 5.3 卖空限制

做空比做多难得多：
- **融券成本**：借股票要付费用，热门股的融券费可达年化 20%+。
- **逼空风险**（short squeeze）：当太多人做空同一只股票，价格反弹时会触发被迫买入（平仓），形成正反馈螺旋（GameStop 2021）。
- **法律限制**：很多市场（如中国 A 股）对做空有严格限制。

这意味着：即使价格明显高估，也**没有足够的做空力量**来修正它。

### 5.4 资金约束与委托代理问题

套利者管理的是**别人的钱**。当价格暂时偏离（账面亏损）时：
- 投资者（LP）可能赎回资金 → 套利者被迫平仓 → 价格进一步偏离。
- 基金经理的考核周期短（季度/年度）→ 不敢做长期正确的逆向交易。

> **Shleifer-Vishny（1997）的关键洞见**：套利的有效性取决于套利者的**资金结构**，而不仅仅是他们的**判断力**。即使是最聪明的套利者，如果资金是短期的、有赎回条款的，他也无法修正长期的价格偏离。

### 5.5 LTCM 教训——模型精确性的致命幻觉

长期资本管理公司（LTCM, 1994-1998）的故事是有限套利的终极教材：
- 团队：2 位诺贝尔奖得主（Merton, Scholes）+ 华尔街顶级交易员
- 策略：收敛套利——找到微小定价偏差，用高杠杆放大收益
- 杠杆：峰值约 **25:1 到 100:1**
- 结果：1998 年俄罗斯违约 → 利差扩大 → 追加保证金 → 被迫平仓 → 亏损 **46 亿美元** → 美联储组织救助

> **LTCM 的哲学教训**：模型说"利差应该收敛"——方向是对的。但模型没告诉你"在收敛之前，利差会扩大到什么程度"以及"你的资金能不能撑到收敛的那一天"。**方向正确 + 资金断裂 = 灾难**。这就是有限套利的残酷现实。

## 六、行为金融的应用

### 6.1 投资者如何利用——反人性操作

行为金融不仅是诊断学，更是**处方学**。知道人类会犯什么错，就能设计对策：

| 偏差 | 对策 |
|------|------|
| 损失厌恶 / 处置效应 | **预设规则**：买入时同时设止损和止盈规则，用程序执行，不用情绪 |
| 过度自信 / 交易过多 | **被动投资**：买指数基金，减少主动交易。或者设"交易冷却期"：想买/卖时先等 48 小时 |
| 确认偏差 | **刻意寻找反面证据**：看多时主动读看空的逻辑，问"如果我错了，可能错在哪？" |
| 锚定效应 | **忘掉成本价**：问自己"如果我现在没有持仓，我会按当前价格买入吗？"如果答案是否，就该卖 |
| 羊群效应 | **逆向思考**：当所有人都说"这次不一样"时，大概率就是一样的（泡沫信号） |
| 心理账户 | **统一视角**：把所有资产放在一起看总资产配置，不要被"这笔是工资/那笔是奖金"干扰 |

**投资检查清单**（inspired by Charlie Munger）：
```
□ 这笔交易是基于分析还是情绪？
□ 我是否在追热点？（羊群效应检查）
□ 我是否因为亏损了才不卖？（处置效应检查）
□ 我是否只看了支持自己的信息？（确认偏差检查）
□ 如果我判断错了，最大亏损是多少？我能承受吗？
□ 这个判断依赖于什么假设？假设合理吗？
```

### 6.2 政策设计——助推（Nudge）

Richard Thaler 和 Cass Sunstein 在《Nudge》（2008）中提出了**选择架构**（choice architecture）的概念：

> 人不是完全理性的，但我们可以**设计环境**，让"默认选项"指向更好的方向——既不限制自由，又能改善决策。

经典案例：
- **默认参保**（default enrollment）：把养老金 401(k) 的默认选项设为"自动加入"，员工可以退出但需要主动操作。这一改变让参保率从 40% 跳到 90%+——因为人懒惰（现状偏差 status quo bias），默认选项的力量巨大。
- **自动递增**（auto-escalation）：每年自动增加缴费比例 1%，员工不主动取消就持续递增。
- **目标日期基金**（target-date fund）：默认投资一个随年龄自动调仓的组合，消除"选什么基金"的决策负担。

> **助推的哲学**：它不试图让人变理性（不可能），而是承认人的非理性，然后**利用非理性的规律来帮助人**。这是行为金融从"描述"到"干预"的关键一步。

### 6.3 公司治理——CEO 过度自信

行为金融也解释了**公司层面的非理性**：

- **过度自信的 CEO 并购更多**：Malmendier-Tate（2008）发现，过度自信的 CEO（用"持有期权到期"来衡量）发起并购的概率高 65%，但并购回报更低。
- **控股股东的过度投资**：CEO 对自己的项目过度乐观 → 投资 NPV 为负的项目 → 摧毁股东价值。
- **市场择时的失败**：CEO 在股价高时增发（自以为抓住了窗口），但往往卖在了顶部附近。

> 这连接到 essence 项目的 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 极限 4：金融是创造价值还是零和赌博？当 CEO 的过度自信驱动了毁损价值的并购，金融就变成了零和甚至负和游戏。

## 七、行为金融的局限与批评

行为金融不是万能药。它有深刻的内在局限，这些局限本身就是哲学反思的入口。

### 批评 1 · "心理学故事太多——能解释一切，但预测不足"

> **Fama 的批评**：行为金融能解释**任何**现象——涨了是过度自信，跌了是恐慌抛售，横盘是反应不足。一个能解释一切的理论等于什么都没解释。

这个批评的力量在于：科学理论的价值在于**可证伪性**（Popper）。如果行为金融只是"事后讲故事"，它就不是科学预测工具。行为金融需要做出**事前可检验的预测**——比如"高换手率的散户会跑输市场"（已被 Odean 证实）。

### 批评 2 · "异象被发现后即消失"

> 有效市场派的终极反驳：如果动量效应是真的，为什么动量策略的回报在下降？如果规模效应是真的，为什么小盘股溢价在收窄？

答案是双面的：
- **部分异象确实在消失**——这正是市场有效化的证据。
- **但偏差本身不消失**——它只是换了表现形式。90 年代的"概念股"、2000 年的互联网、2021 年的 SPAC 和 NFT，本质都是同一种"彩票偏好 + 羊群效应"，只是标的变了。

### 批评 3 · 模型碎片化——没有统一框架

CAPM 是一个优雅的统一框架——一个公式解释所有资产的期望收益。行为金融没有这样的统一框架：它有几十个偏差，每个偏差有自己的参数，它们之间如何叠加、何时主导、如何交互——没有统一理论。

> 这很像心理学相对于物理学的关系：物理学有少数基本定律，心理学有大量现象级规律。行为金融更接近"博物学"（natural history）而非"物理学"。

### essence 立场

> **行为金融是"补充"不是"替代"。** 市场既不完全理性（EMH 错了），也不完全非理性（行为金融也不能全盘接管）。
>
> 更准确的说法是：市场**大致有效但经常偏离**——偏离的方向和幅度由人类认知偏差决定，偏离的持续性由有限套利决定。有效市场是**吸引子**（attractor），行为偏差是**扰动**（perturbation），两者共同决定了价格的动态。
>
> 这和 essence 项目在 [`markets-and-pricing.md`](./markets-and-pricing.md) 的立场一致：价格 = $(p_{\text{均衡}}, p_{\text{信息}}, p_{\text{心理}})$ 的三维坐标。行为金融研究的是第三维——它不可或缺，但也不能替代前两维。

## 八、跨学科映射

行为金融的偏差，在 essence 项目的其他学科里有精确的同构：

| 金融偏差 | 心理学 | 进化生物学 | 神经科学 | 认知科学 / AI |
|---------|--------|-----------|---------|-------------|
| **启发式偏差** | 系统 1 快速判断 | 大草原优化：快速决策 > 精确决策 | 杏仁核快速通路 | 启发式搜索 / 贪心算法 |
| **损失厌恶** | 负面偏差（negativity bias） | 生存优先：错过猎物 < 被猎物吃掉 | 前额叶-杏仁核不对称 | 非对称损失函数（focal loss） |
| **过度自信** | 达克效应（Dunning-Kruger） | 冒险 = 繁殖机会（雄性孔雀尾） | 多巴胺奖赏系统 | 过拟合 / 模型幻觉 |
| **羊群效应** | 从众心理（Asch 实验） | 群体生存：落单 = 死亡 | 镜像神经元 / 社会脑 | 集体学习 / 涌现智能 |
| **锚定效应** | 初始效应（primacy effect） | 参照依赖的感知 | 启动效应（priming） | 预训练偏差（先验主导） |
| **处置效应** | 自我辩护 / 认知失调 | 沉没成本 → 承诺升级 | 脑岛（痛苦感知） | 回报 shaping 的次优策略 |
| **概率扭曲** | 对数概率感知 | 小样本外推 | 多巴胺对意外奖励的非线性反应 | softmax 温度参数 |
| **框架效应** | 语境依赖的语义加工 | 场景识别驱动行为 | 语义网络激活扩散 | 注意力机制 / 上下文窗口 |

> **最深的同构：损失厌恶 = 进化的不对称赌注。** 在大草原上，错过一顿饭（收益损失）的代价是饿一天；被狮子吃掉（生存损失）的代价是死。进化必然让大脑对"损失"（危险）比对"收益"（机会）更敏感——2.25 倍的损失厌恶系数，是百万年自然选择的结果。金融市场的"非理性"，其实是**旧环境下的"理性"在新环境中的失配**（mismatch）。我们用石器时代的大脑，在电子化的赌场里做决策。

## 九、开放问题

- [ ] **偏差能被"训练掉"吗？** Kahneman 本人很悲观——他认为系统 1 的偏差无法通过"知道偏差"来消除。认知偏差像视觉错觉：你知道缪勒-莱尔错觉（两条等长线段看起来不等），但你看它们还是不一样长。那么"投资纪律化"（规则化、自动化）是唯一的出路吗？
- [ ] **当 AI 主导交易时，偏差会消失吗？** 如果所有交易都由无情绪的算法完成，市场会更有效吗？还是算法继承了人类的偏差（因为算法是人类训练的）？参见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 极限 5。
- [ ] **文化差异如何影响偏差？** 损失厌恶系数 $\lambda = 2.25$ 是在美国大学生中测的。在东亚（集体主义文化）、在散户主导的市场（中国 A 股）、在不同年龄群体中，参数会一样吗？初步研究表明 $\lambda$ 在 1.8-2.5 之间波动，但羊群效应在东亚市场显著更强。
- [ ] **偏差是"缺陷"还是"特征"？** 从进化看，这些偏差让我们的祖先活了下来。在金融市场中它们是致命的——但在其他领域（社交、创业、创新）它们可能仍然有用。过度自信让创业者去冒险（大部分失败，少数改变世界）——这是社会的"彩票"。没有过度自信，就没有硅谷。
- [ ] **"理性"到底意味着什么？** 如果一个人按前景理论做决策（最大化前景值 $V$），在他的参考点框架内，他是"理性"的。那"理性"的定义到底是什么？是遵循冯·诺依曼-摩根斯坦公理？还是进化适应？还是个人效用最大化？这个问题没有唯一答案——它是 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 假设 1 的核心（参见 [`00-philosophy/`](../../00-philosophy/)）。
- [ ] **助推（nudge）是操纵还是帮助？** 如果政府用"默认参保"来提高养老金参与率，这是善意的助推还是家长式管控（paternalism）？自由意志主义者批评助推侵犯了人的自主选择权。这是政治哲学问题（参见 [`03-social-sciences/politics/`](../politics/)）。

### 本质追问（留给读者）

> 你现在持有一只亏损 40% 的股票。你知道（因为你刚读了这份文档）你有 1.7 倍的倾向持有亏损股、有损失厌恶（$\lambda = 2.25$）、有确认偏差（你一直在看多它的研报）。
>
> **但是——你知道这些，能让你卖出吗？**
>
> Kahneman 的悲观预测是：不能。知识不等于行动。你能做的，不是"战胜偏差"，而是**设计一个让偏差无法伤害你的系统**——比如：买入时就设好止损线，交给程序执行。
>
> 想清楚：你要做"知道自己有偏差但能控制的人"，还是"设计系统让自己不需要控制的人"？把你的回答写进 [`insights/`](../../insights/)。
