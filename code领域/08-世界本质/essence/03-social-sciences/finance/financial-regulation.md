## 引言：监管的悖论

金融监管面临一个根本性悖论：

> **监管者用昨天的危机设计今天的规则，来防范明天的风险——但明天的危机永远不会和昨天一样。**

这不仅仅是技术问题，而是**认识论问题**（参见 [`risk-and-uncertainty.md`](./risk-and-uncertainty.md) §一 Knight 区分）。监管建立在"风险可量化"的假设上，但真正的系统性危机（2008 次贷、2020 疫情冲击）属于 Knight 意义上的"不确定性"——不可量化的未知。监管框架的每一次重大修订，都是对上次"不可量化事件"的**事后追认**。

```
金融监管的认识论循环：
  危机爆发（不确定性显现）
    → 立法者恐慌 → 设计新规则
      → 规则把"不确定性"编码为"风险参数"
        → 银行适应规则 → 新的套利空间出现
          → 系统在新的规则下积累新风险
            → 下一次不同形式的危机爆发
              → ……
```

> **一句话**：金融监管的历史，是一部**永远在打上一场战争**的历史。但好的监管不是预测未来——而是确保系统在**未知的冲击下不至于崩溃**。

## 一、为什么需要监管——市场失灵与系统性风险

### 1.1 市场失灵的三重根源

金融市场的自由运作会产生系统性的效率损失，这不是"偶然失灵"，而是**结构性失灵**——源于金融活动的三个内在特征：

#### 失灵一：外部性（Externality）——银行的倒闭伤害所有人

```
普通企业破产：
  企业 A 破产 → 员工失业 → 供应商损失 → 产业链局部震荡
  （影响范围有限，市场可自行调整）

银行破产：
  银行 X 倒闭 → 存款人损失 → 其他银行挤兑（恐慌传染）
    → 信贷收缩 → 实体企业断贷 → 失业 → 经济衰退
    → 全社会承担成本（包括与银行 X 毫无关系的人）
```

**负外部性的放大机制**：银行是**高杠杆、高互联**的——一家银行的负债就是另一家银行的资产。这种网络结构使得个别风险可以瞬间**传染**为系统性风险。外部性的存在意味着：银行自身的"最优决策"（如过度杠杆）对它有利，但对整个系统有害——**私人成本 < 社会成本**。

> **监管回应**：资本充足率要求——强制银行用**自有资本**吸收损失，而不是把损失外部化给存款人和纳税人。

#### 失灵二：信息不对称（Asymmetric Information）——存款人不知道银行在干什么

金融交易的核心矛盾——**一方比另一方知道得多**：

| 类型 | 不对称方向 | 后果 | 典型案例 |
|------|-----------|------|---------|
| **逆向选择**（交易前） | 高风险者更积极寻求交易 | 劣币驱逐良币 | 次贷危机前：最差的房贷被积极发放，因为能转手卖掉 |
| **道德风险**（交易后） | 交易后行为改变 | 存款保险下银行更冒险 | "大而不能倒"→ 银行知道会被救 → 更敢赌 |
| **委托代理** | 管理层 vs 股东 vs 存款人 | 利益不一致 | 短期奖金驱动长期风险（交易员"赢了归我，输了归公司"） |

> **Akerlof 的"柠檬市场"**：信息不对称严重到一定程度，市场会彻底崩溃——因为没人敢交易。2008 年次贷危机的转折点正是 **ABX 指数暴跌后，CDO 市场彻底冻结**——没有人知道对方的 CDO 到底值多少钱，于是没有人愿意交易。

> **监管回应**：信息披露要求 + 存款保险 + 监管审查（限制银行能做什么）。

#### 失灵三：垄断与市场力量——"大而不能倒"

```
大银行的垄断力量：
  ├── 规模经济 → 大银行成本更低 → 挤压小银行
  ├── 网络效应 → 结算/支付系统自然垄断
  ├── "大而不能倒"（TBTF）→ 隐性补贴 → 融资成本更低
  │     ↓ 隐性补贴 = 市场认为政府会救 → 愿意以更低利率借钱给大银行
  │     ↓ IMF 估计：G-SIB 的隐性补贴每年约 700-2500 亿美元
  └── 政治游说 → 影响监管立法（监管俘获）
       ↓ "大到不能监管"——监管者缺乏足够人力和专业知识去审查复杂大行
```

> **监管回应**：反垄断审查 + 系统重要性机构（SIFI）附加资本 + 生前遗嘱（处置计划）。

### 1.2 系统性风险——金融监管的终极目标

**系统性风险**（Systemic Risk）≠ 普通风险。它的三个特征：

1. **传染性**（Contagion）：风险从一个机构/市场传播到整个系统
2. **顺周期性**（Procyclicality）：监管和经济周期同向放大——繁荣时放松、衰退时收紧
3. **内生性**（Endogeneity）：风险是系统自身运行产生的，不是外部冲击

```
系统性风险的传播路径（2008 案例）：
  房价下跌（触发）
    → 次贷违约率上升
      → MBS/CDO 价值暴跌（市场风险）
        → 持有 CDO 的银行资本受损
          → 银行收缩信贷（信用风险）
            → 企业断贷 → 破产潮（实体经济）
              → 更多人失业 → 更多人断供房贷
                → 房价进一步下跌
                  → 恶性循环（正反馈）
```

> **Minsky 的洞察**（见 [`_overview.md`](./_overview.md) §问题 5）：系统性风险不是"意外"——它是金融系统稳定运行时**内生积累**的。稳定孕育不稳定。监管的任务不是消除风险（不可能），而是**防止内生的风险积累到不可逆的程度**。

## 二、监管演进史——从自由银行到巴塞尔

### 2.1 监管的历史周期

金融监管呈现明显的**钟摆运动**——危机后收紧，繁荣后放松：

```
1780-1860  自由银行时代（美国）
  ↓ 各州自由发牌，银行频繁倒闭（"野猫银行"）
1860-1913  国家银行时代
  ↓ 国民银行法（1863）→ 统一货币，但仍有频繁恐慌
1913       联邦储备法 → 美联储成立
  ↓ 最后贷款人，减少银行恐慌
1929-1933  大萧条
  ↓ 9000+ 家银行倒闭 → 全面监管时代
1933       Glass-Steagall 法案
  ↓ 分业经营（商业银行 vs 投资银行）+ 存款保险（FDIC）
1933-1970s 严格监管的"安静年代"
  ↓ Q 条例（利率管制）+ 分业经营 + 资本管制
1970s-1980s 放松管制开始
  ↓ 汇率浮动 + 利率市场化 + 金融创新
1980s-1990s 大幅放松
  ↓ Riegle-Neal（跨州银行）+ Gramm-Leach-Bliley（废除 Glass-Steagall）
1999-2007  最自由的时期
  ↓ 影子银行膨胀 + CDO/CDS 爆发 + 次贷繁荣
2008       全球金融危机
  ↓ 全面再监管
2008-2019  巴塞尔 III + Dodd-Frank + 银行联盟
  ↓ 资本充足率大幅提高 + 杠杆率引入 + 流动性要求
2018-至今  部分回撤 + 新挑战
  ↓ 美国放松中小银行监管 + 金融科技 + 加密资产
```

### 2.2 Glass-Steagall 法案（1933）——分业经营的逻辑

大萧条的教训是：**商业银行用存款人的钱去炒股票**。当股市崩盘时，存款人的钱一起蒸发。

```
Glass-Steagall 的核心分离：
  商业银行（吸收存款、发放贷款）
    ✗ 不能：承销证券、自营交易、与投行联营
  
  投资银行（承销证券、自营交易）
    ✗ 不能：吸收零售存款

  保险（承保风险）
    ✗ 不能：与银行/投行混业
```

**效果**：1933-1999 年，美国银行业几乎没有发生过系统性危机。分业经营切断了"存款人的钱"和"资本市场风险"之间的直接通道。

**废除**（1999 Gramm-Leach-Bliley 法案）：金融业游说认为分业经营让美国银行在国际竞争中处于劣势（欧洲银行是全能银行）。废除后，花旗-旅行者合并成为"金融超市"的典范——而 2008 年，花旗恰恰是次贷损失最惨重的银行之一。

> **essence 洞察**：Glass-Steagall 的废除是否直接导致了 2008 危机？学术界有争议。但**分业经营的逻辑——隔离风险传染通道——至今有效**。Volcker Rule（§五）可以看作 Glass-Steagall 的精神复活。

### 2.3 1980 年代放松管制的意识形态

```
放松管制的思想基础：
  里根-撒切尔革命 → "政府不是解决方案，政府本身就是问题"
    ↓ 市场效率信仰 → "市场能自我监管"
      ↓ 金融创新论 → "衍生品分散风险，让系统更安全"
        ↓ Alan Greenspan 的信仰：
          "市场参与者的自利会自动约束过度风险"
            ↓ 结果：影子银行从 ~$2万亿（1990）膨胀到 ~$20万亿（2007）
```

> **Greenspan 的忏悔**（2008 国会听证）："我发现的缺陷在于，那些依赖自利来保护股东权益的机构模型……是错误的。"——一个意识形态的崩塌。

### 2.4 2008 之后再监管

```
2008 危机暴露的监管失败：
  ① 资本不足：银行杠杆高达 30-40 倍，一点点损失就资不抵债
  ② 流动性幻觉：银行依赖短期批发融资（回购），一旦市场冻结就瞬间断血
  ③ 表外实体：SIV/ conduit 把风险移到表外，逃避资本要求
  ④ 互联性不透明：没人知道谁欠谁多少 CDS
  ⑤ 顺周期性：繁荣时资本"充足"，危机时突然"不足"
  ⑥ 大而不能倒：雷曼破产后恐慌救市，道德风险极大
    ↓
全球改革（G20 主导，BIS/FSB 执行）：
  巴塞尔 III（资本+杠杆+流动性+顺周期）
  + Dodd-Frank（美国：有序清算+Volcker Rule）
  + 银行联盟（欧洲：单一处置机制 SRM）
  + SIFI 框架（附加资本+生前遗嘱）
  + 衍生品改革（集中清算+交易报告）
```

## 三、巴塞尔协议深度——资本监管的全球语言

> **权威来源**：[BIS Basel III 框架页](https://www.bis.org/bcbs/basel3.htm)  
> **关键文件**：`bcbs189`（Basel III 框架）+ `d424`（最终改革）+ `d457`（市场风险）

### 3.1 巴塞尔协议是什么

巴塞尔协议是**巴塞尔银行监管委员会**（BCBS）制定的**国际银行监管标准**。它不是"法律"——BCBS 没有强制执行权。但成员国承诺在**本国法律**中实施，形成事实上的全球标准。

```
巴塞尔体系的逻辑：
  BCBS（制定标准）—— 位于 BIS（国际清算银行）
    ↓ 成员国（G20 主要经济体）
      ↓ 本国监管机构翻译为法律
        ↓ 银行执行
          ↓ BCBS 监测实施进度（RCAP 评估）
```

> **为什么需要国际标准？** 竞争公平性。如果 A 国要求银行持有 12% 资本，B 国只要求 4%，那么 B 国银行成本更低，在国际竞争中占优——这迫使 A 国也降低要求（**监管底线竞争**，race to the bottom）。统一标准阻止了这种竞争。

### 3.2 Basel I（1988）——资本充足率的诞生

**核心创新**：第一次提出了**统一的最低资本充足率**要求。

```
Basel I 公式：
  资本充足率 = 银行资本 / 风险加权资产（RWA） ≥ 8%

  其中：
  RWA = Σ (资产类别 × 风险权重)
  
  风险权重（简化版）：
    现金/国债          0%（无风险）
    银行间债权        20%
    住房抵押贷款      50%
    普通企业贷款     100%
```

**资本定义**：
- **一级资本**（Tier 1）：核心资本——股本 + 留存收益（≥4%）
- **二级资本**（Tier 2）：补充资本——次级债、准备金

**问题**：
1. **风险权重太粗糙**——所有企业贷款都是 100%，不管 AAA 还是 CCC
2. **只覆盖信用风险**——市场风险、操作风险未纳入
3. **鼓励监管套利**——银行把高风险资产"包装"成低权重资产

### 3.3 Basel II（2004）——精细化的代价

**三大支柱框架**（沿用至今）：

```
支柱一：最低资本要求（Pillar 1）
  信用风险 + 市场风险 + 操作风险
  
  信用风险的三种方法：
  ① 标准法（Standardized）——监管给定权重（基于外部评级）
  ② 基础 IRB（Foundation IRB）——银行自估 PD，其他参数监管给
  ③ 高级 IRB（Advanced IRB）——银行自估 PD/LGD/EAD/M
  
  关键参数：
    PD（Probability of Default）——违约概率
    LGD（Loss Given Default）——违约损失率
    EAD（Exposure at Default）——违约风险敞口
    M（Maturity）——有效期限

支柱二：监管审查（Pillar 2）
  监管者评估银行的资本是否充足，可要求高于最低标准

支柱三：市场纪律（Pillar 3）
  强制信息披露——让市场参与者监督银行
```

**IRB 的逻辑——让银行用自己的模型算风险**：

> 监管者认为，银行比监管者更了解自己的资产风险，所以应该让银行用自己的模型来计算 RWA——前提是模型经过监管审批。这就是 **内部评级法（IRB）** 的核心。

```
Basel II 信用风险资本（IRB 法）核心公式（简化）：

  资本要求 K = LGD × [N((1-R)^(-0.5) × G(PD) + (R/(1-R))^0.5 × G(0.999)) - PD]
               × (1 + (M - 2.5) × b(PD))   ← 期限调整
  
  其中：
    N(·)  = 标准正态累积分布函数
    G(·)  = N 的逆函数（分位数函数）
    R     = 资产相关性（取决于 PD 和资产类别）
    0.999 = 99.9% 置信水平（"千年一遇"的损失）

  直觉：算出在 99.9% 的最坏情况下，这笔贷款会损失多少 → 这就是需要的资本
```

**致命缺陷**：IRB 让银行**自己决定**风险权重。银行有强烈动机**低估风险**来降低资本要求（少持资本 = 更高 ROE）。2008 证明，银行模型严重低估了相关性——当所有房价同时下跌时，"独立"的贷款**集体违约**。

> **essence 认识论批判**（呼应 [`risk-and-uncertainty.md`](./risk-and-uncertainty.md)）：Basel II 的 IRB 法把"系统性不确定性"（房价全国普跌的可能性）降格为"可量化的风险参数"（PD）。这正是 Knight 所警告的原罪。

### 3.4 Basel III（2010）——危机后的全面修补

Basel III 是对 2008 危机的系统性回应，**四大支柱**：

```
Basel III 的四大改革：

① 更高的资本
   ├── 一级核心资本（CET1）≥ 4.5%（从 2% 提高到 4.5%）
   ├── 一级资本 ≥ 6%
   ├── 总资本 ≥ 8%（不变）
   ├── 资本留存缓冲（Conservation Buffer）2.5%
   │     → CET1 实际需 ≥ 7%（4.5% + 2.5%）
   └── 逆周期缓冲（CCyB）0-2.5%（宏观审慎，见 §六）
   → 合计 CET1 最低要求可达 7% + 2.5%（CCyB）+ SIFI 附加

② 杠杆率（Leverage Ratio）
   杠杆率 = 一级资本 / 总敞口（不含风险加权）≥ 3%
   → 填补 RWA 被 game 的漏洞：不管你怎么算 RWA，总杠杆不能超过 33 倍

③ 流动性要求（全新）
   ├── LCR（流动性覆盖率）≥ 100%
   │     = 优质流动性资产 / 30天净现金流出 ≥ 100%
   │     → 确保30天内能扛住流动性冲击
   └── NSFR（净稳定资金率）≥ 100%
         = 可用稳定资金 / 所需稳定资金 ≥ 100%
         → 确保长期资金结构稳定（不用短期钱做长期贷）

④ 顺周期性修补
   ├── 拨备的前瞻性（预期损失 EL 模型）
   ├── CCyB 逆周期缓冲
   └── 降低 IRB 的顺周期性（压力测试参数）
```

**关键创新：杠杆率（Leverage Ratio）**——Basel III 引入了一个**与风险权重无关**的底线：

> RWA 是可操纵的（银行可以通过 IRB 低估风险来降低 RWA）。杠杆率不管这些——**一级资本除以总敞口**，简单粗暴。它是 RWA 的"安全网"——即便银行完美 game 了 RWA，总杠杆仍然被限制在 33 倍以内。

### 3.5 Basel IV / "最终改革"（2017）——收口 IRB

> **来源**：[BIS d424 "Finalising post-crisis reforms"](https://www.bis.org/bcbs/publ/d424.htm)（2017 年 12 月）

2017 年的"最终化"（俗称 Basel IV，但 BCBS 官方仍称 Basel III 最终化）主要解决一个遗留问题：**IRB 的 output floor（输出底线）**。

```
Basel IV（2017 最终改革）的核心：

① 标准法改进
   ├── 信用风险标准法更精细（细分风险权重档次）
   └── 操作风险标准法改为"业务指标法"（基于收入）

② IRB 的"输出底线"（Output Floor）
   IRB 算出的 RWA ≥ 标准法 RWA × 72.5%
   
   意思：不管你的模型怎么算，RWA 不能低于标准法的 72.5%
   → 防止银行通过 IRB 过度压低 RWA
   → 大幅收窄了 IRB 降低资本的空间

③ 取消高级 IRB 用于某些高风险资产
   ├── 大型企业敞口：不再用 A-IRB（必须退回标准法或 F-IRB）
   └── 股权敞口：不再用 IRB

④ 过渡期
   2023 年开始实施，2028 年完全到位（后因疫情推迟）
```

> **essence 评价**：Basel IV 的输出底线是"认输"——监管者承认 IRB 被操纵得太厉害，不得不设定硬底线。这是**对"让银行自估风险"这条路线的根本修正**。但它也引发了新问题：72.5% 这个数字从何而来？它是政治妥协，不是科学推导。

### 3.6 RWA 与资本充足率计算器

```python
#!/usr/bin/env python3
"""
巴塞尔协议 RWA（风险加权资产）与资本充足率计算器
演示标准法下不同资产组合的资本要求
"""

# ============ Basel 标准法信用风险权重（简化版）============
CREDIT_RISK_WEIGHTS = {
    "现金_央行存款":       0.00,
    "主权_AAA":            0.00,
    "主权_A":              0.20,
    "主权_BBB":            0.50,
    "主权_BBB以下":        1.00,
    "银行间_AAA":          0.20,
    "银行间_BBB":          0.50,
    "银行间_BB":           1.00,
    "住房抵押_LTV<50%":    0.30,
    "住房抵押_LTV50-80%":  0.35,
    "住房抵押_LTV>80%":    0.45,
    "企业_AAA":            0.20,
    "企业_A":              0.50,   # Basel IV 细化后
    "企业_BBB":            1.00,
    "企业_BB":             1.50,   # Basel IV 新增：高风险权重 >100%
    "企业_B以下":          1.50,
    "零售_合格":           0.75,
    "零售_其他":           1.00,
    "股权":                2.50,   # Basel IV 标准法股权权重
    "不良资产_逾期90天+":  1.50,   # 不良资产惩罚权重
}

def compute_rwa(assets):
    """计算风险加权资产（RWA）"""
    rwa = 0
    breakdown = []
    for name, amount, asset_type in assets:
        weight = CREDIT_RISK_WEIGHTS.get(asset_type, 1.00)
        weighted = amount * weight
        rwa += weighted
        breakdown.append({
            "资产": name, "类型": asset_type,
            "金额": amount, "权重": weight, "加权额": weighted
        })
    return rwa, breakdown

def capital_adequacy(rwa, cet1, tier1, total_capital):
    """计算各类资本充足率 + Basel III 合规检查"""
    results = {}
    
    # 核心一级资本充足率
    cet1_ratio = cet1 / rwa
    results["CET1比率"] = cet1_ratio
    results["CET1≥4.5%"] = "✅" if cet1_ratio >= 0.045 else "❌"
    results["CET1≥7%(含留存缓冲)"] = "✅" if cet1_ratio >= 0.07 else "❌"
    
    # 一级资本充足率
    tier1_ratio = tier1 / rwa
    results["一级资本比率"] = tier1_ratio
    results["一级≥6%"] = "✅" if tier1_ratio >= 0.06 else "❌"
    
    # 总资本充足率
    total_ratio = total_capital / rwa
    results["总资本比率"] = total_ratio
    results["总资本≥8%"] = "✅" if total_ratio >= 0.08 else "❌"
    
    # 缺口计算
    required_cet1 = rwa * 0.07  # 4.5% + 2.5% 留存缓冲
    shortfall = max(0, required_cet1 - cet1)
    results["CET1缺口"] = shortfall
    
    return results

def leverage_ratio(tier1_capital, total_exposure):
    """杠杆率 = 一级资本 / 总敞口（不分险）"""
    return tier1_capital / total_exposure

# ============ 示例：两家银行对比 ============
print("=" * 70)
print("Basel RWA 与资本充足率计算器")
print("=" * 70)

# 银行 A：保守型（多国债、少高风险企业贷）
bank_a_assets = [
    ("现金及央行存款",  5000, "现金_央行存款"),
    ("国债",            3000, "主权_AAA"),
    ("银行间拆放",      1000, "银行间_AAA"),
    ("住房抵押贷款",    2000, "住房抵押_LTV50-80%"),
    ("AAA企业贷款",     1500, "企业_AAA"),
    ("BBB企业贷款",     1000, "企业_BBB"),
    ("零售贷款",         500, "零售_合格"),
]
# 银行 B：激进型（多高风险企业贷、股权投资）
bank_b_assets = [
    ("现金及央行存款",  2000, "现金_央行存款"),
    ("主权债",          1000, "主权_BBB"),
    ("银行间拆放",      1000, "银行间_BB"),
    ("住房抵押贷款",    1500, "住房抵押_LTV>80%"),
    ("AAA企业贷款",      500, "企业_AAA"),
    ("BBB企业贷款",     3000, "企业_BBB"),
    ("BB企业贷款",      2000, "企业_BB"),   # 高风险！
    ("股权投资",         500, "股权"),       # 极高权重
    ("不良资产",         500, "不良资产_逾期90天+"),
]

for name, assets in [("银行A（保守型）", bank_a_assets), ("银行B（激进型）", bank_b_assets)]:
    total = sum(a[1] for a in assets)
    rwa, breakdown = compute_rwa(assets)
    
    print(f"\n{'─' * 50}")
    print(f"  {name}")
    print(f"  总资产: {total:>12,.0f}  |  RWA: {rwa:>12,.0f}  |  RWA密度: {rwa/total:.1%}")
    print(f"{'─' * 50}")
    
    # 假设 CET1 = RWA 的 10%（两家银行资本相同绝对值场景）
    # 更真实：设 CET1 = 总资产的 8%
    cet1 = total * 0.08
    tier1 = cet1 + total * 0.01  # +1% 附加一级资本
    total_cap = tier1 + total * 0.02  # +2% 二级资本
    
    results = capital_adequacy(rwa, cet1, tier1, total_cap)
    lev = leverage_ratio(tier1, total)  # 总敞口≈总资产（简化）
    
    print(f"  CET1:      {cet1:>12,.0f}  比率: {results['CET1比率']:.2%}  {results['CET1≥7%(含留存缓冲)']}")
    print(f"  一级资本:  {tier1:>12,.0f}  比率: {results['一级资本比率']:.2%}  {results['一级≥6%']}")
    print(f"  总资本:    {total_cap:>12,.0f}  比率: {results['总资本比率']:.2%}  {results['总资本≥8%']}")
    print(f"  杠杆率:    {lev:.2%}  {'✅' if lev >= 0.03 else '❌'} (需≥3%)")
    print(f"  CET1缺口:  {results['CET1缺口']:>12,.0f}")

print("\n" + "=" * 70)
print("洞察：相同资本水平下，激进型银行RWA密度更高，资本充足率更低")
print("杠杆率是安全网——即使RWA被操纵，总杠杆仍受限")
print("=" * 70)
```

### 3.7 RWA 操纵的博弈——"RWA optimization"

```
银行如何 game RWA（降低资本要求的技巧）：

技巧 1：资产选择偏好
  同样放贷 100 万：
    AAA 企业贷 → RWA = 20万 → 需资本 = 20万 × 8% = 1.6万
    BB 企业贷  → RWA = 150万 → 需资本 = 150万 × 8% = 12万（Basel IV）
  → 银行偏好"低权重"资产 → 但这些资产收益率也低 → ROE 压力

技巧 2：IRB 模型操纵
  调低 PD 估计 → RWA 降低 → 资本要求降低
  "我们的模型显示这套次贷的违约概率只有 0.3%"（2007 年的银行）
  → 模型假设（独立性、正态性）一改，结果天差地别

技巧 3：表外转移
  把资产塞进 SIV / conduit → 不进 RWA → 不需资本
  2008：这些表外实体崩溃后风险回流表内 → 灾难

技巧 4：风险权重的监管套利
  把 BB 企业贷通过"信用增级"包装成 AAA
  买 CDS 保护 → 算作 AAA 权重（20%）
  但保护方（AIG）本身可能违约 → 系统性风险集中
```

> **essence 洞察**：RWA 操纵揭示了一个深层悖论——**监管越复杂，套利空间越大**。简单粗暴的杠杆率反而更难被 game。这是为什么 Basel III 强调杠杆率作为补充。

## 四、系统重要性机构（SIFI）——"大而不能倒"的治理

### 4.1 为什么"大而不能倒"是个问题

```
大而不能倒（Too Big To Fail, TBTF）的逻辑：

  大银行 X 即将破产
    ↓ 如果让它破产：
      → 存款人恐慌 → 挤兑其他银行
      → 支付系统瘫痪 → 经济停摆
      → 系统性崩溃
    ↓ 政府/央行不得不救（bailout）
      → 用纳税人的钱救私人银行
        → 道德风险（Moral Hazard）：
          银行知道"大"了就会被救
            → 利润私有化，风险社会化
              → 银行有动机变得更大、更冒险
                → 下次危机更大 → 更不能倒
                  → 恶性循环
```

**隐性补贴的量化**：市场知道大银行会被救，所以愿意以**更低的利率**借钱给大银行。这个利差就是**隐性补贴**——相当于纳税人在补贴大银行。

```
隐性补贴估算（IMF / FSB 数据）：
  G-SIB 的融资成本优势：约 10-80 个基点（取决于时期）
  换算为年度补贴：
    资产 2 万亿的大行 × 0.5% 利差 = 每年 100 亿美元补贴
  → 这扭曲了竞争：大银行可以凭"隐形政府担保"打败小银行
```

### 4.2 SIFI 的分类框架

> **来源**：[FSB G-SIFI 框架](https://www.fsb.org/work-of-the-fsb/market-and-institutional-resilience/global-systemically-important-financial-institutions-g-sifis/)

```
SIFI 分层：
  G-SIB（全球系统重要性银行）—— BCBS 评估
    ├── 评估指标：规模 × 交叉度 × 复杂度 × 国际活跃度 × 可替代性
    ├── 分 5 档，附加资本 1% → 3.5%
    └── 2023 年名单：约 30 家（摩根大通在最顶层）
  
  G-SII（全球系统重要性保险人）—— IAIS 评估
    └── 如 AIG、Allianz、MetLife
  
  D-SIB（国内系统重要性银行）—— 各国自行评估
    └── 如中国的工农中建交
  
  非银 SIFI：
    ├── 系统重要性支付机构（如 Visa, Mastercard）
    ├── 大型对冲基金 / 资管公司
    └── CCP（中央对手方）——"金融市场的基础设施"
```

**G-SIB 分档与附加资本**：

| 分档 | 附加 CET1 要求 | 代表机构（示例） |
|------|---------------|-----------------|
| 第 5 档 | +3.5% | （目前空缺——没有银行达到） |
| 第 4 档 | +2.5% | 摩根大通（唯一） |
| 第 3 档 | +2.0% | 美银、花旗、汇丰、工行 |
| 第 2 档 | +1.5% | 高盛、摩根士丹利、中行、建行 |
| 第 1 档 | +1.0% | 约 15-20 家 |

### 4.3 生前遗嘱（Living Will / Resolution Plan）

**核心思想**：像人写遗嘱一样，大银行必须在**生前**写好自己破产时的处置方案。

```
生前遗嘱的两个部分：

① 战略性分析（Strategic Analysis）
  ├── 银行的核心业务线（Critical Functions）是什么
  ├── 哪些业务对金融系统至关重要（不能中断）
  └── 破产时哪些可以卖掉、哪些需要维持

② 描述性信息（Descriptive Information）
  ├── 详细的公司结构（实体图谱）
  ├── 跨实体敞口（谁欠谁多少）
  ├── 关键的合同/衍生品/融资安排
  └── 处置的可行路径（破产 vs 重组 vs 拆分）
```

**可处置性评估**（Resolvability Assessment）：监管者会问——**如果这家银行明天倒闭，我们能有序处置它吗？** 如果答案是"不能"，银行必须重组（简化结构、增加可剥离性）。

> **Dodd-Frank 第 165 条**：美国要求资产 >500 亿美元的银行每年提交生前遗嘱。2014 年，Fed/FDIC 联合否决了 11 家大银行的遗嘱——认为它们的处置计划"不可信"。这迫使银行简化结构。

### 4.4 TLAC（总损失吸收能力）

```
TLAC（Total Loss-Absorbing Capacity）：

  G-SIB 必须持有足够多的"可吸收损失的债务工具"
    → 破产时，这些债务可以被"减记"（bail-in）
    → 股东和债权人承担损失，而不是纳税人

  TLAC ≥ max(RWA × 18%, 风险敞口 × 6.75%)
    → 从 2019 年开始逐步实施，2025 年完全到位

  bail-in vs bailout：
    bailout：政府出钱救（纳税人承担）—— 2008 的做法
    bail-in：债权人承担损失（减记/转股）—— 新框架的做法
```

> **essence 评价**：TLAC 是对"大而不能倒"最实质性的回应——它改变了**谁来承担损失**。从"纳税人"转向"债权人"。但这也有风险：如果债权人发现自己可能被 bail-in，他们可能**挤兑**——把"债券挤兑"变成新的传染渠道（2023 年硅谷银行危机的预演）。

## 五、2008 后改革——Dodd-Frank、Volcker、银行联盟

### 5.1 Dodd-Frank 法案（2010）——美国的全面再监管

> 848 页法案，16 个标题（titles），涉及金融监管的几乎所有方面。

```
Dodd-Frank 的核心改革：

① 金融稳定监督委员会（FSOC）
  → 识别系统性风险，跨机构协调
  → 有权指定"系统重要性非银金融机构"（纳入 Fed 监管）

② 有序清算机制（Orderly Liquidation Authority, OLA / Title II）
  → FDIC 有权接管濒临破产的系统性金融机构
  → 目标：避免"雷曼式的混乱破产"
  → 费用由金融行业事后分摊（不花纳税人钱）

③ Volcker Rule（Section 619）
  → 禁止银行用存款进行自营交易（proprietary trading）
  → 禁止银行持有/发起对冲基金和私募股权基金
  → "Glass-Steagall 的精神复活"

④ 消费者金融保护局（CFPB）
  → 保护消费者免受金融欺诈（房贷、信用卡、发薪日贷款）
  → 从各监管机构剥离消费者保护职能，统一管理

⑤ 衍生品改革（Title VII）
  → 场外衍生品（OTC）必须通过 CCP 集中清算
  → 必须向数据仓库报告交易
  → 提高透明度和标准化

⑥ 沃尔克规则、风险留存、信用评级改革……
```

**Volcker Rule 的争议**：

```
Volcker Rule 的核心禁令：
  银行（有存款保险保护的）不能：
    ✗ 自营交易（用自己的钱炒股票/债券）
    ✗ 发起对冲基金/私募
    ✗ 持有超过基金资产 3% 的有限合伙权益

  争议：
    "自营交易"和"做市"（market making）的边界模糊
      → 做市需要持有库存 → 像自营 → 难以区分
      → 银行抱怨合规成本极高（合规团队数百人）
      → 2018-2020 年被大幅放松（豁免中小银行、放宽做市认定）
```

> **Paul Volcker 本人的话**："银行唯一有价值的创新是 ATM。"——对金融创新论的彻底怀疑。

### 5.2 欧洲银行联盟（Banking Union）

```
欧洲银行联盟的三大支柱：

① 单一监管机制（SSM, Single Supervisory Mechanism）
  → ECB 直接监管欧元区大银行（资产 >300亿 或 占本国GDP >20%）
  → 2014 年开始运作

② 单一处置机制（SRM, Single Resolution Mechanism）
  → 设立单一处置委员会（SRB）
  → 管理单一处置基金（SRF）—— 目标规模 550 亿欧元
  → 统一的破产处置规则（BRRD 指令）

③ 欧洲存款保险（EDIS）
  → 计划中的第三支柱（至今未完全实现）
  → 目标：打破"银行-主权死循环"（sovereign-bank doom loop）
     = 银行持有大量本国国债 → 本国主权信用恶化 → 银行受损 → 需要政府救 → 主权信用更差
```

**银行-主权死循环——欧洲的特殊问题**：

```
2010-2012 欧债危机暴露的恶性循环：

  希腊主权信用恶化
    → 持有希腊国债的希腊银行资本受损
      → 银行需要政府救助
        → 政府发更多债 → 被银行买走（因为外资不买了）
          → 银行更依赖本国主权 → 主权更依赖本国银行
            → 主权和银行"绑死在一起"
```

> **essence 洞察**：银行联盟是"不完整的联邦主义"——有统一监管和处置，但**没有统一的财政后盾**。这暴露了欧盟的根本矛盾：**货币统一了，但财政没统一**。下次系统性危机时，SRF 的 550 亿欧元够不够？大概率不够。

### 5.3 FSB 的"更安全、更简单、更公平"

> **来源**：[FSB 后危机改革总结](https://www.fsb.org/work-of-the-fsb/market-and-institutional-resilience/post-2008-financial-crisis-reforms/)

FSB 用三个词总结全球改革：

```
Safer（更安全）：
  银行资本大幅提高——G-SIB 的 CET1 从 2007 的 ~3% 升到 2023 的 ~13%
  + 杠杆率 + 流动性 + TLAC = 更厚的"减震器"

Simpler（更简单）：
  衍生品集中清算 → 透明化
  + 表外实体回归表内
  + 结构简化（生前遗嘱要求）

Fairer（更公平）：
  bail-in 替代 bailout → 债权人/股东承担损失，不是纳税人
  + "大而不能倒"隐性补贴被压缩
```

但 FSB 也承认改革的**未竟之业**：

## 六、宏观审慎 vs 微观审慎——两个维度

### 6.1 两者的区别

```
                微观审慎（Microprudential）    宏观审慎（Macroprudential）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
目标              单个机构不倒闭                 整个系统不崩溃
视角              自下而上（机构 → 系统）        自上而下（系统 → 机构）
风险观            风险是外生的（给定的）          风险是内生的（系统产生的）
关注              资本/流动性/治理                顺周期性/传染/关联性
时间              截面分析（某时刻）              跨周期分析（繁荣-衰退周期）
典型工具          资本充足率、LPR、NSFR          CCyB、LTV 限制、部门资本附加
类比              不让每一棵树生病              防止整个森林起火
```

> **关键区别——风险的来源**：微观审慎假设风险是"外生"的（给定条件下，银行面临固定风险）。宏观审慎认识到风险是**内生**的——**所有银行同时去杠杆**本身就是系统性风险的来源。个体理性 ≠ 集体理性（囚徒困境的金融版）。

### 6.2 顺周期性（Procyclicality）——宏观审慎的头号敌人

```
顺周期性的恶性循环：

经济繁荣期：
  资产价格上涨 → 抵押品价值上升 → 银行放贷更多
    → 资产价格更高 → 抵押品更值钱 → 更多放贷
      → 杠杆飙升 → 系统脆弱（但模型显示"一切正常"）

经济衰退期：
  资产价格下跌 → 抵押品缩水 → 银行要求追加抵押
    → 借款人被迫抛售资产 → 价格更低 → 更多追加要求
      → 火灾降价（fire sale）→ 银行资本受损 → 收缩信贷
        → 实体经济受损 → 更多违约 → 恶性循环
```

**监管本身也会顺周期**：

```
Basel II/III 的顺周期性：
  衰退期 → 违约率上升 → PD 上升 → RWA 上升 → 资本要求上升
    → 银行被迫收缩（在正是需要放贷的时候！）
  
繁荣期 → 违约率低 → PD 低 → RWA 低 → 资本要求低
  → 银行可以更多放贷（在正是应该收手的时候！）
    → 恰恰反了！
```

### 6.3 逆周期资本缓冲（CCyB）

**机制**：在经济繁荣时要求银行积累额外资本，在衰退时释放——**逆周期操作**。

```
CCyB（Countercyclical Capital Buffer）：
  
  范围：0% - 2.5%（各国自行设定）
  
  繁荣期：央行提高 CCyB（如到 2%）
    → 银行多持资本 → 限制放贷冲动 → 给泡沫降温
  
  衰退期：央行降低 CCyB（如到 0%）
    → 释放的资本可以用来吸收损失 + 继续放贷
    → 避免资本要求"在错误的时间收紧"

  决策信号：
    信用/GDP 缺口（credit-to-GDP gap）
    = 当前信用/GDP 比例 - 长期趋势
    缺口 > 10 个百分点 → 预警，考虑提高 CCyB
```

### 6.4 顺周期性模拟 + 逆周期缓冲效果

```python
#!/usr/bin/env python3
"""
模拟金融系统的顺周期性，以及 CCyB（逆周期资本缓冲）的效果
简化模型：信贷周期 → 资产价格 → 银行行为 → 反馈循环
"""
import math

class ProcyclicalityModel:
    """简化的顺周期性模型"""
    
    def __init__(self, ccyb_on=False, ccyb_threshold=0.15):
        self.ccyb_on = ccyb_on
        self.ccyb_threshold = ccyb_threshold  # 信用/GDP缺口阈值
        
    def simulate(self, years=20, shock_year=12, shock_size=0.15):
        """
        模拟信贷-资产价格反馈循环
        shock_year: 外生冲击发生的年份
        shock_size: 冲击导致资产价格下跌幅度
        """
        results = []
        
        # 初始状态
        asset_price = 100.0
        credit_gdp = 1.0        # 信用/GDP 比例
        credit_gdp_trend = 1.0   # 长期趋势
        bank_capital_ratio = 0.12  # 银行资本充足率
        
        for t in range(years):
            # 1. 信用/GDP 缺口
            gap = credit_gdp - credit_gdp_trend
            
            # 2. CCyB 决策
            if self.ccyb_on:
                if gap > self.ccyb_threshold:
                    ccyb = min(0.025, (gap - self.ccyb_threshold) * 0.5)
                elif gap < 0:
                    ccyb = 0.0  # 衰退时释放
                else:
                    ccyb = max(0, (gap / self.ccyb_threshold) * 0.01)
            else:
                ccyb = 0.0
            
            required_capital = 0.08 + 0.025 + ccyb  # 基础+留存+CCyB
            
            # 3. 银行放贷行为（取决于资本充足度）
            capital_buffer = bank_capital_ratio - required_capital
            if capital_buffer > 0.02:
                # 资本充裕 → 扩张信贷
                credit_growth = 0.08 + 0.5 * capital_buffer
            elif capital_buffer > 0:
                # 资本紧张 → 放缓
                credit_growth = 0.02 + 2.0 * capital_buffer
            else:
                # 资本不足 → 收缩（fire sale）
                credit_growth = -0.05 + 2.0 * capital_buffer  # 负增长
            
            # 4. 外生冲击
            if t == shock_year:
                asset_price *= (1 - shock_size)
                bank_capital_ratio -= shock_size * 0.3  # 损失侵蚀资本
            
            # 5. 信贷扩张推高资产价格（正反馈）
            # 信贷增长 → 资产价格上涨 → 抵押品升值 → 更多信贷
            price_feedback = credit_growth * 0.8
            asset_price *= (1 + price_feedback * 0.1)
            
            # 6. 信用/GDP 更新
            credit_gdp *= (1 + credit_growth - 0.03)  # 减去名义GDP增长
            credit_gdp_trend = 0.9 * credit_gdp_trend + 0.1 * credit_gdp  # 趋势更新
            
            # 7. 资本充足率动态
            # 资产价格变化影响银行资产质量
            if price_feedback < 0:
                # 资产价格下跌 → 不良上升 → 资本受损
                bank_capital_ratio += price_feedback * 0.2
            bank_capital_ratio = max(0.02, min(0.20, bank_capital_ratio))
            
            results.append({
                "年份": t,
                "资产价格": round(asset_price, 1),
                "信用/GDP": round(credit_gdp, 3),
                "信用缺口": round(gap, 3),
                "资本比率": round(bank_capital_ratio * 100, 2),
                "CCyB": round(ccyb * 100, 2),
                "信贷增长": round(credit_growth * 100, 2),
            })
        
        return results

def run_comparison():
    print("=" * 80)
    print("顺周期性模拟：有无 CCyB（逆周期资本缓冲）的对比")
    print("=" * 80)
    print("场景：12 年繁荣积累后，第 12 年遭遇 15% 资产价格冲击\n")
    
    # 无 CCyB
    model_no = ProcyclicalityModel(ccyb_on=False)
    results_no = model_no.simulate()
    
    # 有 CCyB
    model_yes = ProcyclicalityModel(ccyb_on=True)
    results_yes = model_yes.simulate()
    
    # 打印关键年份对比
    key_years = [0, 3, 6, 9, 11, 12, 13, 14, 16, 19]
    header = f"{'年':>3} | {'─── 无CCyB ───':^40} | {'─── 有CCyB ───':^40}"
    sub = f"{'':>3} | {'资产价':>7} {'信用/GDP':>8} {'资本%':>6} {'信贷增%':>7} | {'资产价':>7} {'信用/GDP':>8} {'资本%':>6} {'CCyB%':>6}"
    print(header)
    print(sub)
    print("-" * 90)
    
    for y in key_years:
        n = results_no[y]
        y_ = results_yes[y]
        print(f"{y:>3} | {n['资产价格']:>7.0f} {n['信用/GDP']:>8.3f} {n['资本比率']:>6.2f} {n['信贷增长']:>7.2f} | "
              f"{y_['资产价格']:>7.0f} {y_['信用/GDP']:>8.3f} {y_['资本比率']:>6.2f} {y_['CCyB']:>6.2f}")
    
    # 分析
    print("\n" + "=" * 80)
    print("分析：")
    
    # 危机前信贷积累
    peak_credit_no = max(r["信用/GDP"] for r in results_no[:12])
    peak_credit_yes = max(r["信用/GDP"] for r in results_yes[:12])
    print(f"  危机前信用/GDP峰值：无CCyB={peak_credit_no:.3f} vs 有CCyB={peak_credit_yes:.3f}")
    print(f"  → CCyB 压制了 {(1-peak_credit_yes/peak_credit_no)*100:.1f}% 的过度信贷积累")
    
    # 危机后信贷收缩
    post_crash_no = results_no[13]["信贷增长"]
    post_crash_yes = results_yes[13]["信贷增长"]
    print(f"  冲击后第1年信贷增长：无CCyB={post_crash_no:.2f}% vs 有CCyB={post_crash_yes:.2f}%")
    
    # 资本比率
    cap_crash_no = results_no[13]["资本比率"]
    cap_crash_yes = results_yes[13]["资本比率"]
    print(f"  冲击后资本比率：无CCyB={cap_crash_no:.2f}% vs 有CCyB={cap_crash_yes:.2f}%")
    
    print("\n核心洞察：")
    print("  ① CCyB 在繁荣期压制信贷泡沫 → 减少脆弱性积累")
    print("  ② CCyB 在衰退期释放 → 银行有空间继续放贷 → 避免信贷断崖")
    print("  ③ 顺周期性是内生的——个体的'理性'行为（追涨杀跌）在集体层面是灾难性的")
    print("=" * 80)

run_comparison()
```

## 七、影子银行监管——风险在监管之外积累

### 7.1 什么是影子银行

```
影子银行（Shadow Banking）/ 非银金融中介（NBFI）：
  
  广义定义：所有在传统银行体系之外进行信用中介的活动
  
  包括：
    ├── 货币市场基金（MMF）
    ├── 回购协议（Repo）市场
    ├── 对冲基金
    ├── 私募股权 / 私募信贷
    ├── 结构性投资工具（SIV）
    ├── 信托产品 / 理财产品（中国）
    ├── 证券化产品（MBS/CDO）
    └── DeFi（去中心化金融）

  共同特征：从事"银行的业务"（期限转换+信用转换+流动性转换）
            但不受银行监管（无资本要求、无存款保险、无央行流动性支持）
```

**为什么影子银行危险**——它做了**银行的三个核心转换**但没有银行的保障：

```
银行的三个转换（也是脆弱性来源）：
  ① 期限转换：短期存款 → 长期贷款（存款人随时可取，贷款不能随时收回）
  ② 信用转换：存款人承担低风险，银行承担信用筛选
  ③ 流动性转换：非流动资产（贷款）→ 流动负债（存款）

  → 这三个转换使得银行天然脆弱（挤兑风险）
  → 但银行有：存款保险 + 最后贷款人 + 资本要求

影子银行做了同样的转换：
  ① MMF：短期投资（随时赎回）→ 投资于较长期资产
  ② Repo：短期回购融资 → 持有较长期证券
  ③ SIV：短期商业票据 → 长期结构性产品

  但没有：保险 + 最后贷款人 + 资本要求
  → 一旦信心动摇，"影子挤兑"瞬间发生（2008 年 9 月的回购市场冻结）
```

> **FSB 数据**：全球 NBFI 规模从 2008 年的 ~$100 万亿增长到 2023 年的 ~$220 万亿，占全球金融资产的约 50%——已经超过传统银行。

### 7.2 货币市场基金（MMF）改革

```
2008 + 2020 的"MMF 挤兑"：

  2008 年 9 月：
    Reserve Primary Fund（MMF）"跌破面值"（broke the buck）
      → 因持有雷曼商业票据而亏损
        → 投资者恐慌赎回
          → 美国政府被迫给所有 MMF 担保（临时保障计划）
  
  2020 年 3 月（新冠冲击）：
    同样的剧情重演
      → MMF 大规模赎回 → 美联储再次出手（MMF 流动性工具）

  根本问题：
    MMF 承诺"1 元面值不变"（NAV = $1.00）
      → 但底层资产价值是波动的
      → 一旦亏损，"1元不变"的承诺无法维持
      → 投资者争先恐后赎回（先赎回的拿1元，后赎回的亏损）
        → 经典的挤兑动态
```

**2014 SEC 改革 + 2023 进一步改革**：

```
MMF 改革措施：
  ① 区分机构 prime MMF 和政府 MMF
     → prime MMF（投资商业票据）必须浮动 NAV（不再承诺 $1）
     → 政府 MMF（投资国债）可保持固定 NAV
  
  ② 流动性费用和赎回门（Gates）
     → 周度流动性低于 30% → 可征收流动性费用（2%）或暂停赎回
  
  ③ 2023 新规（应对 2020 教训）：
     → 取消"门槛触发"的费用机制（反而加剧挤兑——投资者抢在门槛前赎回）
     → 改为"渐进式"流动性费用
```

### 7.3 回购市场的透明化

```
回购（Repo）市场——影子银行的核心管道：

  回购 = 以证券为抵押的短期借款
    A 把国债给 B → 获得 100 现金 → 约定明天以 100.01 买回国债
    → 利率 0.01%（隔夜）
  
  杠杆叠加（hypothecation + rehypothecation）：
    同一份国债被反复抵押 → 创造出多倍的"货币"
    → 2008 年：当抵押品（MBS）价值存疑时，整个回购市场冻结
    → 银行/对冲基金瞬间失去资金来源

  改革：
    ① 中央清算（CCP）→ 降低对手方风险
    ② 交易报告 → 提高透明度
    ③ 最小保证金/折扣率 → 防止过度杠杆
    但：回购市场仍然大部分是双边的，透明度不足
```

### 7.4 证券化的风险留存

```
证券化的问题——"发起-分销"（Originate-Distribute）模式：
  
  银行发放贷款 → 打包成 MBS → 卖给投资者
    → 银行不再持有贷款 → 不关心贷款质量
      → "只要能卖出去，质量无所谓"
        → 次贷泛滥

  改革——风险留存（Risk Retention）：
    Dodd-Frank 第 941 条 / 欧盟 CRD IV：
      发起人必须保留至少 5% 的信用风险
        → "skin in the game"——自己的钱在里面，才会关心质量
```

## 八、金融科技监管——监管如何追赶创新

### 8.1 监管面临的根本困境

```
技术 vs 监管的速度差：

  技术（金融科技）：
    区块链 → DeFi → NFT → Web3 → AI 金融
    周期：6-12 个月出新概念
  
  监管：
    立法 → 谘询 → 起草 → 公众评论 → 表决 → 实施 → 过渡期
    周期：3-7 年
  
  → 监管永远滞后于创新
  → 创新者利用滞后期进行"先上车后补票"
```

### 8.2 监管沙盒（Regulatory Sandbox）

```
监管沙盒的逻辑：
  
  传统：要么合规（成本高）→ 要么不合规（违法）
    → 创新者要么不敢试，要么偷偷干
  
  沙盒：
    在限定条件下，允许创新者在"受控环境"中测试
      ├── 时间限制（6-12 个月）
      ├── 客户数量限制（如 < 10 万）
      ├── 资金额度限制
      ├── 消费者保护要求
      └── 监管者实时监控

  发源地：英国 FCA（2015 年首创）
  全球扩散：新加坡 MAS、香港 HKMA、中国（数字货币沙盒）
  
  成功案例：开放银行 API 的原型测试
  失败/争议：加密货币借贷平台借沙盒"洗白"后再暴雷
```

```
PSD2（欧盟支付服务指令第二版，2018 生效）：

  挑战：
    - 安全：API 暴露了账户接口 → 攻击面扩大
    - 数据隐私：第三方拿到数据后怎么用？
    - 责任分配：出了问题谁负责？银行？第三方？客户？
```

## 九、监管悖论——监管自身的失败模式

### 9.1 监管套利（Regulatory Arbitrage）

```
监管套利的逻辑：
  
  规则 A 对银行监管严格
    → 银行把业务转移到"规则 B"（监管宽松）
      → 监管者跟进，收紧规则 B
        → 银行转移到"规则 C"（更新领域）
          → 监管者再跟进……
            → 永无止境的猫鼠游戏

  历史模式：
  1980s：银行受 Q 条例利率管制 → 货币市场基金绕过
  1990s：银行受 Basel I 资本管制 → 证券化（SIV）绕过
  2000s：银行受 Basel II → CDO/CDS 在表外膨胀
  2010s：银行受 Basel III → 影子银行/NBFI 膨胀
  2020s：受监管的银行 → DeFi/加密资产试图完全逃避监管

  本质：风险不是消失了——它只是移动到了监管看不到的地方
```

> **essence 洞察**：监管套利揭示了一个**流体力学原理**——金融资本像水一样，会找到所有缝隙。堵住一条缝，水会找到另一条。有效的监管不是"堵"——而是**降低套利的激励**（统一标准、减少监管碎片化）。

### 9.2 监管俘获（Regulatory Capture）

```
监管俘获的机制（Stigler / 公共选择学派）：

  ① 旋转门（Revolving Door）
     监管者离任后到被监管机构工作
       → 监管者在任时不愿得罪未来的雇主
  
  ② 信息不对称
     监管者不如银行懂业务（银行有更多专家和数据）
       → 监管依赖银行"自觉"报告
  
  ③ 资源不对等
     大银行的合规/游说预算 > 监管机构的全部预算
       → 银行可以雇最好的律师/经济学家来 game 规则
  
  ④ 政治影响
     大银行是重要雇主/纳税人 → 政治家不愿过度监管

  表现：
    - 规则被"软化"（loophole）
    - 执法不力（极少处罚高管个人）
    - 处罚可被"成本化"（罚款只是经营成本的一部分）
```

**2008 的监管俘获案例**：

```
SEC 对投资银行的"合并受监管实体"（CSE）项目：
  2004 年允许投行提高杠杆上限（从 12:1 到 40:1）
    → 五大投行（贝尔斯登、雷曼、美林、摩根、高盛）杠杆飙升
      → 2008 年全部出事或被迫转型
  
  事后调查：SEC 的 CSE 部门只有 1 名工作人员负责监督所有五家投行
    → "监管"形同虚设
```

### 9.3 合规成本转嫁

```
监管的成本悖论：

  更严格的监管 → 更高的合规成本
    → 大银行养得起庞大的合规团队（数千人）
    → 小银行养不起 → 被挤出市场
      → 行业集中度上升 → 更多"大而不能倒"
        → 监管的初衷（降低系统性风险）反而被加剧

  数据：
    2008 后美国社区银行数量减少 ~30%
    Dodd-Frank 的合规成本被认为是原因之一
    → 2018 年 Economic Growth Act 放松了对中小银行的监管
      （资产 <2500 亿的银行豁免部分要求）
```

### 9.4 模型 Gaming——Goodhart 定律

> **Goodhart 定律**："当一个指标成为政策目标时，它就不再是好的指标。"

```
Basel 资本充足率的 Goodhart 效应：

  目标：资本充足率 ≥ 8%
    → 银行的目标变成"让 RWA 尽量低"
      → RWA 不再反映真实风险——它反映"银行操纵后的风险"
        → 资本充足率失去意义

  实证：
    欧洲银行的"RWA 密度"（RWA/总资产）差异巨大：
      有的银行 RWA 密度 30%，有的 70%
      → 同样规模、同样业务的银行，RWA 差 2 倍
      → 说明 RWA 被严重操纵

  这就是为什么 Basel III 引入杠杆率（不分险）——
    它是"Goodhart 免疫"的指标（无法通过操纵模型来降低）
```

```python
#!/usr/bin/env python3
"""
Goodhart 定律演示：当 RWA 成为目标，银行如何操纵它
模拟不同 IRB 模型假设下 RWA 的巨大差异
"""
import numpy as np

np.random.seed(42)

def basel_irb_capital(pd, lgd=0.45, m=2.5, asset_class="wholesale"):
    """
    Basel IRB 信用风险资本要求（简化版核心公式）
    返回：单位敞口的资本要求比例
    """
    from scipy.stats import norm
    
    # 资产相关性 R（取决于 PD 和资产类别）
    if asset_class == "wholesale":
        R = 0.12 * (1 - np.exp(-50 * pd)) / (1 - np.exp(-50)) + 0.24 * \
            (1 - (1 - np.exp(-50 * pd)) / (1 - np.exp(-50)))
    elif asset_class == "retail":
        R = 0.03 * (1 - np.exp(-35 * pd)) / (1 - np.exp(-35)) + 0.16 * \
            (1 - (1 - np.exp(-35 * pd)) / (1 - np.exp(-35)))
    else:
        R = 0.15
    
    # 期限调整 b
    b = (0.11852 - 0.05478 * np.log(pd)) ** 2
    b = max(0, b)
    
    # 核心公式：99.9% 置信水平下的非预期损失
    z = norm.ppf(0.999)  # ~3.09
    w = norm.ppf(pd)
    
    K = lgd * (norm.cdf((1 - R)**(-0.5) * w + (R / (1 - R))**0.5 * z) - pd)
    K *= (1 + (m - 2.5) * b)
    
    # 资本要求 = K × 8%（简化为一级资本）
    rwa_weight = K / 0.08  # 转换为 RWA 权重
    
    return max(0, rwa_weight), K

print("=" * 75)
print("Goodhart 定律演示：IRB 模型参数操纵导致 RWA 巨大差异")
print("=" * 75)

# 场景：一笔 10 亿元的 BBB 企业贷款组合
exposure = 10_000  # 百万元

# 不同银行的 PD 假设（"同一资产"，不同模型）
scenarios = [
    ("银行A：保守估计", 0.020, 0.45, "真实BBB违约率~2%"),
    ("银行B：乐观估计", 0.008, 0.40, "认为比市场更安全"),
    ("银行C：激进估计", 0.003, 0.35, "模型大幅低估风险"),
    ("标准法权重",      None,  None, "Basel 标准法 BBB=100%"),
]

print(f"\n{'场景':^24} | {'PD':>6} {'LGD':>5} | {'RWA权重':>8} {'资本要求':>10} | {'说明'}")
print("-" * 80)

for name, pd, lgd, note in scenarios:
    if pd is not None:
        weight, K = basel_irb_capital(pd, lgd)
        capital = K * exposure
        print(f"{name:^24} | {pd:>6.1%} {lgd:>5.0%} | {weight:>8.1%} {capital:>8,.0f}百万 | {note}")
    else:
        weight = 1.00  # 标准法 BBB = 100%
        capital = weight * exposure * 0.08
        print(f"{name:^24} | {'—':>6} {'—':>5} | {weight:>8.1%} {capital:>8,.0f}百万 | {note}")

print(f"\n{'─' * 80}")
print("对比：同样 10 亿 BBB 敞口，IRB 模型差异：")

# 计算
w_a, _ = basel_irb_capital(0.020, 0.45)
w_b, _ = basel_irb_capital(0.008, 0.40)
w_c, _ = basel_irb_capital(0.003, 0.35)

print(f"  银行A（保守）：RWA 权重 = {w_a:.1%}，资本 = {w_a*0.08*exposure:,.0f}百万")
print(f"  银行C（激进）：RWA 权重 = {w_c:.1%}，资本 = {w_c*0.08*exposure:,.0f}百万")
print(f"  差异：银行C的资本要求仅为银行A的 {w_c/w_a*100:.0f}%")
print(f"  → 同样的资产，资本要求差 {w_a/w_c:.1f} 倍！")
print()
print("这就是 Basel IV（2017）引入 output floor 的原因：")
print("  IRB RWA ≥ 标准法 RWA × 72.5%")
print(f"  即 IRB 权重 ≥ 72.5% × 100% = 72.5%")
print(f"  银行C当前权重 {w_c:.1%} → 被强制提升到 72.5%")
print()
print("本质洞察（Goodhart 定律）：")
print("  当 RWA 成为监管目标 → 银行优化 RWA → RWA 失去信息含量")
print("  唯一的解药：引入不可操纵的约束（杠杆率 + output floor）")
print("=" * 75)
```

## 十、中国金融监管——一行一局一会

### 10.1 监管体制演变

> 详见 [`china-financial-system.md`](./china-financial-system.md) §一（顶层控制）。

```
中国金融监管体制演变：

1992-2003：分业监管形成期
  证监会（1992）→ 证券业
  保监会（1998）→ 保险业
  银监会（2003）→ 从央行分出银行业监管
  → "一行三会"（央行 + 银监/证监/保监）

2003-2017：分业监管运行期
  问题：分业监管 vs 混业经营
    → 影子银行/资管产品跨行业 → 监管真空 + 监管套利
    → "谁都在管，谁都不管"

2017-2022：国务院金融稳定发展委员会
  2017 年全国金融工作会议 → 设立金稳委
    → 统筹协调"一行两会"
  2018 年：银监会 + 保监会合并 → 银保监会
    → "一委一行两会"

2023 至今：金融监管体制改革
  → 组建国家金融监督管理总局（金监总局/NFRA）
    → 在银保监会基础上，纳入央行的行为监管 + 证监会的投资者保护
  → 证监会保留（专管证券业）
  → 央行专注于货币政策和宏观审慎
    → "一行一局一会"：
      央行（货币政策+宏观审慎）
      + 金监总局（微观审慎+行为监管，除证券外）
      + 证监会（证券业监管）
```

### 10.2 资管新规（2018）——中国版的"影子银行整顿"

```
资管新规（"关于规范金融机构资产管理业务的指导意见"，2018-04）：

  背景：
    中国影子银行（银行理财+信托+券商资管+基金子公司）规模达 ~100 万亿
      → 刚性兑付（"预期收益率"承诺）扭曲风险定价
      → 资金池运作（"庞氏"——用新发行的钱兑付旧产品的"收益"）
      → 多层嵌套（银行→信托→资管→底层资产，风险不透明）
      → 非标资产（房地产/城投的"暗渠"）

  核心改革（"破刚兑、去通道、限非标"）：
  ① 打破刚性兑付
     → 理财产品净值化（不再承诺"预期收益率"）
     → 投资者自负盈亏
  
  ② 消除多层嵌套
     → 只允许一层嵌套（如"银行理财→公募基金"）
     → 禁止"银行→信托→资管→..."的多层套娃
  
  ③ 限制非标投资
     → 非标资产比例受限
     → 期限匹配要求（不能用短期资金投长期非标）
  
  ④ 统一杠杆限制
     → 公募/私募/理财的杠杆统一上限

  影响：
    - 影子银行规模大幅收缩（~100万亿 → ~70万亿）
    - 银行理财从"刚兑存款替代品"变成"真正的投资产品"
    - 2022 年"破净潮"（理财产品净值跌破1）→ 投资者教育
    - 房地产/城投的"影子融资渠道"被切断 → 部分引发流动性压力
```

> **essence 关联**（[房地产系统危机洞察](../../insights/2026-07/2026-07-12-real-estate-system-crisis.md)）：资管新规切断城投的影子融资渠道，是 2021-2023 年房地产流动性危机的制度性诱因之一。监管的"去杠杆"与市场的"去杠杆"叠加，加速了危机。

### 10.3 房地产金融宏观审慎

```
中国的房地产金融宏观审慎框架：

① 房贷 LTV 限制
   首套房：最低首付 20-30%
   二套房：最低首付 40-70%（城市差异化）
   → 远比西方严格的 LTV 要求

② 房贷集中度管理（2021）
   银行房地产贷款占比上限：
     大型银行：房地产贷款 ≤ 40%（其中个人房贷 ≤ 32.5%）
     中型银行：≤ 27.5%（个人房贷 ≤ 20%）
     → 超标的银行必须压降 → 结构性收缩房贷

③ "三道红线"（2020，针对开发商）
   ① 剔除预收款后资产负债率 > 70%
   ② 净负债率 > 100%
   ③ 现金短债比 < 1 倍
   → 三条全踩 = 红档 → 不能新增有息负债
   → 这直接导致了恒大/融创等高杠杆房企的流动性危机

④ 房贷利率下限调整
   2024 年大幅下调存量房贷利率 → 缓解居民偿债压力
```

> **essence 评价**：中国的房地产宏观审慎工具比西方更直接、更强力。但"三道红线"的教训是——**过猛的去杠杆本身会引发危机**。宏观审慎工具需要**渐进**和**逆周期**——而不是"运动式"的一刀切。

### 11.1 跨学科映射

| 金融监管现象 | 对应学科概念 | 映射逻辑 |

| **监管套利** | 热力学 / 流体力学 | 资本像水，找到所有缝隙（监管真空）流动 |
| **Goodhart 定律** | 控制论 / 系统理论 | 测量干扰系统——当测量成为目标，测量失真 |
| **监管俘获** | 政治学 / 公共选择 | 监管者被被监管者"俘获"——委托代理问题 |
| **生前遗嘱** | 概率论 / 极值理论 | 为"低概率高影响"事件做准备（呼应 [`risk-and-uncertainty.md`](./risk-and-uncertainty.md)） |
| **Knight 不确定性** | 认识论（`00-philosophy/epistemology.md`） | 监管建立在"可量化"假设上，但系统性风险是 Knight 不确定性 |
| **Minsky 不稳定** | 动力系统 / 分岔理论 | 稳定→不稳定是内禀动力学，不是外生冲击 |
| **监管沙盒** | 进化论 / 试错学习 | 在受控环境变异→选择→保留——降低创新的风险 |
| **中国运动式监管** | 周雪光"运动式治理"（`../politics/china-governance.md`） | "三道红线"= 非常规纠偏，打破常规监管节奏 |

### 11.2 监管的哲学反思

```
金融监管的三个哲学立场：

立场一：建构主义（Constructivist）
  → 监管可以设计出"完美的规则"来防范危机
  → Basel 的精细化路线代表
  → 信念：足够的资本+流动性+透明度 = 安全
  → 问题：复杂性本身成为漏洞（规则越复杂，套利空间越大）

立场二：演化主义（Evolutionary）
  → 监管是"试错学习"——每次危机后修正
  → 沙盒模式代表
  → 信念：无法预知未来，但可以从错误中学习
  → 问题：学习成本太高（每次"学习"都是一次危机）

立场三：谦逊主义（Humility / Knight-Taleb）
  → 系统性风险不可量化（Knight 不确定性）
  → 真正的保护不是精确的风险模型，而是"让自己不在乎它发生"
  → Taleb 的反脆弱：让系统从冲击中受益
  → 实践：高资本缓冲 + 简单结构 + 允许小银行倒闭
  → 问题：可能与效率冲突（"浪费"在冗余上）
```

> **essence 立场**：三种立场各有道理。有效的监管是**建构（规则）+ 演化（学习）+ 谦逊（冗余）**的三重叠加。没有任何单一方法足以应对 Knight 不确定性。监管的终极目标不是"防止危机"（不可能）——而是**确保危机可控、可恢复、不摧毁文明的信任基础**。

### 11.3 开放问题

- [ ] **巴塞尔框架能防范下一次危机吗？**——还是只是让危机以"未被预见的形式"重现？（Basel 防了信用风险，但 NBFI 在监管外膨胀）
- [ ] **IRB 模型应该完全废除吗？**——output floor 是"修正"还是"遮羞布"？让银行自估风险这条路，从根本上可行吗？
- [ ] **"大而不能倒"真的被解决了吗？**——TLAC + bail-in 改变了激励，但 2023 年硅谷银行危机中，Fed 仍然动用了系统性风险豁免来保护未投保存款
- [ ] **宏观审慎工具够用吗？**——CCyB 在 2020 年被广泛降到 0%，但释放效果有限——银行仍然在恐慌中收缩信贷
- [ ] **NBFI（非银中介）如何监管？**——对冲基金/私募信贷/MMF 占了金融资产的一半，但监管远不及银行——下一个系统性风险在这里？
- [ ] **加密资产 / DeFi 的系统性风险**——当 DeFi 规模足够大，它的崩溃会传染传统金融吗？MiCA 豁免 DeFi 是漏洞还是务实？
- [ ] **AI 的系统性风险**——当所有银行用类似的 AI 模型，它们会"集体犯错"吗？算法同质化是新版的"模型同质化"（2008 的 VaR 模型同质化）？
- [ ] **气候风险如何纳入资本要求？**——TCFD/ISSB 要求披露，但"棕色资产"的资本附加至今未实现——银行体系为化石能源融资的风险如何定价？
- [ ] **中国金融监管能否实现"功能监管"？**——从"机构监管"（按牌照分）转向"功能监管"（按业务性质分），是解决监管真空的根本路径，但涉及权力重新分配
- [ ] **全球监管碎片化 vs 统一**——MiCA vs 美国 vs 中国的加密监管碎片化，是否会催生新的"监管套利天堂"？

## 十二、监管简明编年史

```
1863     美国国民银行法 → 统一货币 + 国民银行体系
1913     联邦储备法 → 美联储成立
1933     Glass-Steagall → 分业经营 + FDIC 存款保险
1944     布雷顿森林体系 → 固定汇率 + IMF/世界银行
1971     尼克松冲击 → 布雷顿森林崩溃 → 浮动汇率
1980     DIDC 法案 → Q 条例废除（利率市场化开始）
1988     Basel I → 第一个全球资本充足率标准（CET1 ≥ 8%）
1994     Riegle-Neal → 允许银行跨州经营
1999     Gramm-Leach-Bliley → 废除 Glass-Steagall（全能银行合法化）
2004     Basel II → IRB 法 + 三大支柱
2007-08  全球金融危机 → 雷曼破产 → 全面再监管
2010     Basel III → 资本+杠杆+流动性+顺周期
2010     Dodd-Frank → Volcker Rule + OLA + CFPB + FSOC
2012     BRRD → 欧洲处置指令 → bail-in 框架
2013     FSB TLAC → G-SIB 总损失吸收能力
2014     银行联盟 SSM → ECB 直接监管欧元区大银行
2015     英国 FCA 监管沙盒 → 全球首创
2017     Basel IV（"最终改革"）→ output floor 72.5%
2018     中国资管新规 → 破刚兑、去通道、限非标
2020     新冠冲击 → CCyB 释放 + 各国紧急流动性工具
2021     中国"三道红线"全面执行 → 房企流动性危机
2023     硅谷银行/签名银行/瑞士信贷危机 → 监管反思
2023     中国金融监管改革 → "一行一局一会"
2024     MiCA 生效 → 全球最全面加密资产监管
2024     Basel III 最终改革正式实施（推迟后）
2026     FSB 发布 AI 负责任采用咨询报告
```

---

> **一句话总结**：金融监管是金融系统的**免疫系统**——它不能消灭所有病原体（危机），但能确保系统不至于被一次感染摧毁。好的监管像好的免疫系统：**足够敏感以识别威胁，足够强大以应对冲击，但又不过度反应以至于伤害自身**（自身免疫病 = 过度监管扼杀创新）。监管的终极智慧，是在**安全与效率、规则与弹性、防范与容忍**之间，找到那个不断移动的平衡点。
