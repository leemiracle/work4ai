## 一、中央银行是什么——三大职能与多重目标

### 1.1 三副面孔

> 不要把央行想象成一家"特殊的银行"。它是**三种截然不同职能**的合一，这三副面孔各有来历、各有逻辑、经常打架。

| 面孔 | 职能 | 起源 | 核心动作 | 典型时刻 |
|------|------|------|---------|---------|
| 🛡️ **货币守护者** | 货币政策 | 20 世纪通胀治理 | 调利率 / 调货币量 | 沃尔克抗通胀（1979-82） |
| 🚒 **金融救火队长** | 最后贷款人 | Bagehot 1873 | 危机时向市场注流动性 | 2008 救助、2020 疫情 |
| 📐 **系统架构师** | 宏观审慎 / 监管 | 2008 后巴塞尔 III | 设资本充足率 / LTV 限贷 | 中国"三道红线" |

**essence 理解**：央行不是"一个职能"，而是**三套逻辑的捆绑**。货币政策是"总量调控"，最后贷款人是"个体急救"，宏观审慎是"结构防震"。三者目标可能冲突——比如抗通胀要加息（紧），而救金融要放水（松）。**央行的艺术，就是在三副面孔之间动态平衡。**

#### 职能一 · 货币政策（Monetary Policy）

**直觉**：经济像一辆车，通胀是油门踩太重（过热），衰退是油门不够（熄火）。央行踩"利率"这个踏板——加息=刹车，降息=油门。

**数学骨架**：最简化的货币政策反应函数（泰勒规则的雏形）：

$$i_t = r^* + \pi_t + \phi_\pi(\pi_t - \pi^*) + \phi_y \, y_t$$

其中 $i_t$ 名义政策利率，$r^*$ 自然实际利率，$\pi_t$ 通胀率，$\pi^*$ 目标通胀，$y_t$ 产出缺口。**核心思想：央行按规则对偏离做出反应**（详见 §五）。

#### 职能二 · 最后贷款人（Lender of Last Resort, LOLR）

**Bagehot 三原则**（1873《伦巴第街》，至今仍是危机 playbook）：
1. **自由放贷**（lend freely）——只要有合格抵押品，要多少给多少
2. **惩罚性利率**（at a penalty rate）——比正常高，防止道德风险
3. **只救 solvent 的**（to solvent firms）——资能抵债只是缺流动性的才救，资不抵债的让它死

> **深层**：LOLR 揭示了央行相对于商业银行的**根本特权**——它能创造**无限的基础货币**。一家商业银行挤兑会倒闭，但央行永远不会"挤兑破产"，因为法币就是它的负债。**央行的本质能力是"流动性的终极来源"**。这一点是 §六 QE 和 §七"最后交易商"的逻辑根基。

#### 职能三 · 监管与宏观审慎（Regulation & Macroprudential）

2008 之前，央行主要管货币政策；2008 之后，"宏观审慎"（macroprudential）成为第二支柱。差别在于：

| 维度 | 微观审慎（传统监管） | 宏观审慎（2008 后） |
|------|---------------------|---------------------|
| 对象 | 单个机构的安全 | **整个系统**的安全 |
| 视角 | 个体不倒 | 个体都"安全"但**集体**可能崩（顺周期性） |
| 工具 | 资本充足率、拨备 | 逆周期资本缓冲、LTV/DTI 限贷、系统重要性附加 |

### 1.2 多重目标——永恒的权衡

> 不同央行的"法定目标"不同，但内核是同一组变量的权衡。

```
                 通胀稳定  ◄──────── 权衡 ────────►  充分就业
                     ▲                                 ▲
                     │                                 │
                  （短期，菲利普斯曲线）──  可能冲突  ──┘
                     │                                 │
                 金融稳定  ◄──────── 权衡 ────────►  汇率稳定
                     ▲                                 ▲
                  （加息抗泡沫，但会伤经济；               │
                   降息救经济，但会催泡沫）            （三元悖论）
```

**四目标的内在张力**：

| 目标 | 工具倾向 | 与谁冲突 |
|------|---------|---------|
| 通胀（price stability） | 加息 / 收货币 | 与"就业"短期冲突；与"金融稳定"可能冲突（加息刺破泡沫） |
| 就业（full employment） | 降息 / 放货币 | 与"通胀"短期冲突 |
| 金融稳定（financial stability） | 宏观审慎 / LOLR | 低利率催生杠杆，埋下危机 |
| 汇率 / 外部平衡 | 外汇干预 / 资本管制 | 触发**三元悖论**（见 [`international-finance.md`](./international-finance.md)） |

**essence 立场**：央行目标不是"既要又要"的菜单——它是**一组不可同时满足的约束**。所谓"好央行"，不是消灭权衡，而是**让权衡的成本透明、可解释、可问责**。

**dual mandate vs single mandate**：美联储（Fed）法定"双重使命"（通胀+就业）；欧央行（ECB）是"单一使命"（首要价格稳定）；PBOC 是"多重目标"（币值稳定+促进经济增长+就业+国际收支）。**制度选择反映政治哲学**——美国信"通胀就业可以兼得"，欧洲信"稳定优先（受魏玛恶性通胀创伤）"，中国信"发展是硬道理"。

## 二、货币政策工具箱——传统 / 非常规 / 结构性

> 央行的工具箱像一座三层宝塔。底层是**传统工具**（利率+准备金），中间是 2008 后的**非常规工具**（QE/前瞻指引/负利率），顶层是针对特定市场失血的**结构性工具**（TLTRO/PSL/swap lines）。**当利率触底（ZLB），央行不得不爬向更高层。**

### 2.1 传统工具——"三大件"

#### A. 公开市场操作（Open Market Operations, OMO）

```
机制图：
央行 ──(买卖国债)──► 一级交易商(Primary Dealers)
                         │
            买入国债(注入流动性): 银行准备金 ↑ → 联邦基金利率 ↓
            卖出国债(回笼流动性): 银行准备金 ↓ → 联邦基金利率 ↑
```

**直觉**：央行在公开市场买卖国债，调节银行体系的"准备金"存量。准备金多了，银行间隔夜拆借利率（美国叫联邦基金利率）下降；少了则上升。**这是央行设定政策利率的主要旋钮。**

**2008 后的变化**：因为 QE 把准备金灌成"过剩"（ample reserves），OMO 的"量"不再能精确控"价"。美联储改用**利率走廊**（IORB 上限 + ON RRP 下限）直接定价——详见 §六。

#### B. 贴现窗口（Discount Window）

```
机制图：
商业银行 ──(缺流动性)──► 央行贴现窗口
                              │
                  以合格抵押品借入，利率 = 贴现率（通常 > 政策利率 = 惩罚性）
```

**Bagehot 原则的工具化**：贴现窗口就是 LOLR 的常规通道。**污名效应（stigma）**是最大问题——去贴现窗口借钱会被市场解读为"你出问题了"，所以平时银行不愿用。2023 年硅谷银行（SVB）倒闭部分原因正是：宁可死也不愿去贴现窗口"丢脸"。美联储 2023 新设**银行定期融资计划（BTFP）**就是为了消除污名。

#### C. 存款准备金率（Reserve Requirement Ratio, RRR）

```
机制图：
存款 D = 准备金 R / 准备率 rr    （货币乘数 m = 1/rr 的来源）

降 rr → 乘数 m ↑ → 同样的基础货币创造更多存款 M ↑ → 信用扩张
升 rr → 乘数 m ↓ → 信用收缩
```

**直觉**：准备金率是央行控制"货币乘数"的杠杆。降准=放大银行放贷能力；升准=收紧。

**货币乘数理论**（详见 [`banking.md`](./banking.md)）：

$$M = m \cdot B = \frac{1 + c}{rr + c + e} \cdot B$$

其中 $c$ 现金存款比、$e$ 超额准备金率、$B$ 基础货币。

> **重要陷阱**：货币乘数**不是机械的**。2008 后美国准备金泛滥，但银行囤积超额准备金（$e$ 飙升），乘数暴跌——央行放水了，但"水"没流到实体经济。这就是"**推绳子**"（pushing on a string）现象（详见 §十）。**准备金率在中国仍是核心工具**（§八 PBOC）。

#### 代码：货币乘数模拟——为什么"放水"未必"溢出"

```python
# cb_money_multiplier.py —— 货币乘数与"推绳子"现象模拟
import numpy as np

def money_multiplier(rr, c=0.05, e=0.0, leak=0.0):
    """M1 乘数 m = (1+c)/(rr+c+e+leak)；leak=坏账/惜贷永久漏损"""
    return (1 + c) / (rr + c + e + leak)

def deposit_chain(base, rr, c=0.05, e=0.0, leak=0.0):
    """迭代模拟银行体系存款创造（含现金漏损c/超额囤积e/坏账leak）"""
    d, dep, cash, n = base, 0.0, 0.0, 0
    while d > 1e-6 and n < 1000:
        dep += d
        cash += d * c
        d = d * (1 - rr - c - e - leak)   # 可贷出部分回流为下轮存款
        n += 1
    return dep, cash, n

B0 = 1000.0  # 基础货币（央行注入）
scenarios = [
    ("正常 (rr=10%)",        0.10, 0.0,  0.0),
    ("降准 (rr=5%)",         0.05, 0.0,  0.0),
    ("2008后 (囤超额85%)",   0.10, 0.85, 0.0),
    ("惜贷 (坏账漏损30%)",   0.10, 0.0,  0.30),
]
print(f"基础货币 B = {B0:.0f}，对比不同场景\n")
print(f"{'场景':<22}{'乘数m':>8}{'理论M1':>9}{'模拟M1':>9}{'轮次':>6}")
print("-"*54)
for name, rr, e, leak in scenarios:
    m = money_multiplier(rr, e=e, leak=leak)
    dep, cash, n = deposit_chain(B0, rr, e=e, leak=leak)
    print(f"{name:<22}{m:>8.2f}{m*B0:>9.0f}{dep+cash:>9.0f}{n:>6}")
print("\n洞察:")
print("  • 降准 → 乘数↑ → 同样基础货币创造更多 M1")
print("  • 2008后：银行囤85%超额准备金 → 乘数从7.0暴跌到1.05")
print("    = 央行放天量基础货币却几乎不溢出为流通货币（'推绳子'）")
print("  • 惜贷：坏账永久吃掉信用 → 乘数从7.0降到2.33，扩张链提前终止")
```

实测输出（`python3 cb_money_multiplier.py`）：

```

场景                         乘数m     理论M1     模拟M1    轮次
------------------------------------------------------

降准 (rr=5%)               10.50    10500    10500   197

  • 降准 → 乘数↑ → 同样基础货币创造更多 M1
  • 2008后：银行囤85%超额准备金 → 乘数从7.0暴跌到1.05
    = 央行放天量基础货币却几乎不溢出为流通货币（'推绳子'）
  • 惜贷：坏账永久吃掉信用 → 乘数从7.0降到2.33，扩张链提前终止
```

### 2.2 非常规工具——ZLB 时代的发明

> 当政策利率降到零（甚至负），传统降息空间耗尽，央行被迫发明新工具。这是 2008-2020 的"工具箱大爆炸"。

#### A. 量化宽松（Quantitative Easing, QE）

```
机制图（QE = 央行扩表买长期资产）：
央行资产负债表                  商业银行资产负债表
┌──────────────┐              ┌──────────────┐
│ 国债(长期) ↑  │  ──买入──►   │ 准备金 ↑      │
│ MBS ↑        │              │ 国债 ↓        │
│ 总资产 ↑↑     │              │              │
└──────────────┘              └──────────────┘
        │
        └──► 长期利率 ↓（期限溢价被压低）→ 投资/购房 ↑
```

**直觉**：传统 OMO 买卖**短期**国债，影响**短期**利率。QE 买**长期**国债和 MBS，直接压低**长期**利率——因为按揭、企业债都挂钩长期利率，这比降短端更直接刺激实体。

> **关键区分**：QE 不是"印钞发钱"——它把**长期资产换成短期准备金**，改变的是**期限结构**而非货币总量。准备金本身被锁在央行账户里，是否变成流通货币取决于银行是否放贷（回到乘数问题）。

#### B. 量化紧缩（Quantitative Tightening, QT）

QE 的反向操作——央行**到期不续投 / 主动卖出国债**，缩表。2017-2019 美联储首次 QT，2019 年回购市场动荡而暂停；2022 年再次启动 QT。

#### C. 前瞻指引（Forward Guidance, FG）

```
机制：央行"承诺"未来政策路径 → 影响市场对未来利率的预期 → 长期利率今天就开始动

类型：
  • 时间条件型（date-contingent）："至少维持低利率到 20XX 年"
  • 状态条件型（state-contingent）："在失业率降到 X% / 通胀到 Y% 之前不加息"
  • 门槛条件型（threshold）：明确数值门槛
```

**直觉**：长期利率 = 未来短期利率预期 + 期限溢价。央行管不了"期限溢价"，但能管"预期"。**FG 是用"嘴巴"调利率**——光靠说话就能影响市场。Woodford 的"预期管理"理论是其学术基础：**货币政策的效果 90% 来自预期，而非当期动作**。

#### D. 负利率（Negative Interest Rate Policy, NIRP）

ECB（2014）、日银（2016）、瑞士/丹麦/瑞典曾实施。对银行存放在央行的**超额准备金收取费用**（如 -0.5%），逼银行放贷而非囤钱。

**争议**：负利率伤银行利润（净息差收窄）、伤储户（存款可能搬家）、伤货币（贬值压力）、还可能催现金囤积（纸币的零利率是负利率的"地板"）。

#### E. 收益率曲线控制（Yield Curve Control, YCC）

日银 2016 首创——**直接把 10 年期国债收益率钉在 0% 附近**。机制：无限量按目标价买入，任何偏离都被央行"碾压"。

```
传统 QE: 控"量"——买多少资产
YCC:     控"价"——把收益率钉死，需要买多少就买多少
```

**教训**：YCC 压低了政府融资成本，但 2022-2023 全球通胀下，日银被迫"死扛"0.25% 上限，造成日元暴跌、汇率干预、最终 2023 年 12 月松绑上限。**YCC 退出极难**——一旦市场怀疑央行守不住，债券抛售潮就来了。

### 2.3 结构性工具——定向"输血"

> 当总量宽松的钱淤积在金融体系、流不到特定领域（中小企业/绿色/地产），央行发明**定向工具**。

| 工具 | 央行 | 目标 | 机制 |
|------|------|------|------|
| **TLTRO**（定向长期再融资操作） | ECB | 逼银行放贷给实体 | 给银行超低息长期资金，条件是增加对企业和家庭贷款 |
| **PSL**（抵押补充贷款） | PBOC | 棚改/基建/政策性项目 | 国开行拿 PSL 资金做棚改货币化安置 |
| **流动性互换额度（Swap Lines）** | Fed ↔ 各国央行 | 海外美元荒 | Fed 给盟友央行美元，后者贷给本国银行（详见 §七） |
| **MLF/SLF** | PBOC | 中期/超短期流动性 | 中期借贷便利（MLF）是 LPR 的锚 |

**essence 立场**：结构性工具暴露了总量货币政策的局限——**央行能造钱，但不能决定钱去哪**。定向工具是央行对"传导失灵"的妥协，但也让央行越来越像"政策性银行"，**模糊了货币与财政的边界**（§九 MMT 挑战）。

## 三、传导机制——货币政策如何"传"到实体经济

> 调一个利率数字，凭什么能改变千万企业的投资决策？中间经过**五条渠道**。渠道是否通畅，决定了政策有效还是"推绳子"。

### 3.1 五大传导渠道

```
                        央行调整政策利率 i
                              │
        ┌─────────┬───────────┼───────────┬──────────┐
        ▼         ▼           ▼           ▼          ▼
   ①利率渠道  ②信贷渠道   ③资产价格    ④汇率渠道   ⑤预期渠道
   短端→长端  银行放贷    股市/房价↑   本币变动    通胀预期
   →投资消费  →企业借款   →财富效应    →净出口     →工资定价
        │         │           │           │          │
        └─────────┴─────┬─────┴───────────┴──────────┘
                        ▼
                   总需求 AD → 产出 Y → 通胀 π
```

| 渠道 | 机制 | 关键环节 | 可能断裂处 |
|------|------|---------|-----------|
| ① 利率渠道 | 降息→企业融资成本↓→投资↑ | 利率从短端传到长端（期限结构） | ZLB 时短端降不动；银行不降贷款利率 |
| ② 信贷渠道 | 降息→银行可贷资金↑→放贷↑ | 银行愿意放贷（风险偏好） | 银行囤准备金（2008 后）；坏账周期惜贷 |
| ③ 资产价格渠道 | 降息→股价/房价↑→财富效应/托宾Q→消费投资↑ | 资产价格上涨传导到支出 | 财富集中富人（边际消费倾向低）；泡沫风险 |
| ④ 汇率渠道 | 降息→本币贬值→出口竞争力↑ | 资本流动通畅 | 资本管制（中国）；全球同步降息抵消 |
| ⑤ 预期渠道 | 沟通→通胀预期锚定→工资/定价行为 | 公众信任央行 | 信任崩塌（如新兴市场危机） |

**信贷渠道的两个子机制**（Bernanke-Gertler）：
- **银行借贷渠道**（bank lending channel）：降息→银行准备金↑→可贷资金↑→贷款供给↑
- **资产负债表渠道**（balance sheet channel）：降息→借款人净资产↑→逆向选择/道德风险↓→银行愿意贷

### 3.2 传导的"时滞"——政策的慢性病

> 货币政策不是"即时生效"的。公认时滞：
> - **内部时滞**（认识+决策）：约 3-6 个月
> - **外部时滞**（政策传导到通胀）：约 **12-18 个月**
>
> 这意味着**今天的通胀，往往是 1 年前的政策的结果**。央行永远在"打已经移动的靶"。

### 3.4 传导失灵——渠道为什么会断？

| 断点 | 现象 | 案例 |
|------|------|------|
| 利率渠道断（ZLB） | 短端降不动，长端受预期拖累 | 日本 1990s-"失去的二十年" |
| 信贷渠道断（惜贷） | 钱堆在央行，银行不放贷 | 2008 后美国超额准备金暴涨 |
| 资产价格渠道失效 | 财富进富人腰包，不转化为消费 | 2009-2019 美股长牛 vs 工资停滞 |
| 预期渠道崩塌 | 央行说话没人信 | 新兴市场危机（央行承诺保汇率，市场不信） |

> 这就是 §十"推绳子"的微观基础——**不是央行没用力，而是传导链条在某个环节断了**。

## 四、通胀理论——货币、菲利普斯与预期

> 央行管通胀，但"通胀从哪来"本身是宏观经济学最深的争论。三个理论谱系并存。

### 4.1 货币数量论（Quantity Theory）——货币主义

**费雪方程式**（Fisher, 1911）：

$$MV = PQ$$

- $M$ 货币量，$V$ 货币流通速度，$P$ 物价水平，$Q$ 实际产出（= $Y$）

**核心推论**（长期）：若 $V$ 稳定（由支付习惯/技术决定）、$Q$ 趋于自然产出（长期充分就业），则 **$M$ 决定 $P$——通胀是货币现象**（Friedman 名言）。

**弗里德曼的 k% 规则**：货币量按固定速率 $k\%$ 增长（如 3-5%），别试图微调。

**理论困境**（也是央行实践的困境）：
1. **$V$ 不稳定**——美国 2008 后 $V$ 暴跌（货币流通变慢），$M$ 大涨但 $P$ 没涨。"货币数量论失效了"。
2. **短期 $Q$ 可偏离自然率**——衰退时 $M$ 增长主要推高 $Q$，不是 $P$。
3. **货币口径模糊**——M0/M1/M2 哪个是"真"货币？2008 后 M2 暴涨但通胀温和。

> **essence 立场**：货币数量论在**长期/高通胀**环境下成立（魏玛、津巴布韦——确实印钞→通胀），但在**短期/低通胀/流动性陷阱**下失效。**MV=PQ 是会计恒等式，不是因果机制**——因果方向（M→P 还是 P→M）才是争论焦点。

### 4.2 菲利普斯曲线（Phillips Curve）——通胀与失业的权衡

**原始菲利普斯曲线**（Phillips, 1958）：失业率↓ → 工资增速↑（经验规律）。

**预期增强的菲利普斯曲线**（Friedman-Phelps, 1968）：

$$\pi_t = \pi_t^e - \beta(u_t - u^*) + \varepsilon_t$$

- $\pi_t$ 通胀，$\pi_t^e$ 通胀预期，$u_t$ 失业率，$u^*$ 自然失业率，$(u_t-u^*)$ 失业缺口，$\varepsilon_t$ 供给冲击

**关键洞见**：
- **短期**：$\pi^e$ 给定时，失业↓ → 通胀↑（有权衡，央行可"买"就业）
- **长期**：$\pi^e = \pi$（预期调整到位），权衡**消失**——长期菲利普斯曲线垂直于 $u^*$。任何试图把失业压到 $u^*$ 以下的努力，只换来加速通胀（**stagflation**，1970s 滞胀的根源）

**"菲利普斯曲线之死"**（2008 后）：美国失业率降到历史低位（2019 <4%），通胀却没起来——**曲线"变平"了**。可能原因：通胀预期被央行锚定（预期渠道生效）/全球化压低工资/工会力量衰退。

### 4.3 通胀预期——自我实现的预言

> 现代（2000 后）央行共识：**通胀主要由预期驱动**。央行真正管的不是今天的物价，而是**公众对未来物价的预期**。

**为什么预期如此关键**：
- 工资谈判：工人预期 5% 通胀 → 要求 5% 加薪 → 企业涨价 5% → 预期成真
- 定价决策、长期合同、利率定价，全挂钩通胀预期
- **央行的工作 = 锚定预期**——这是"通胀目标制"（IT）的根本逻辑（§五）

**衡量预期**：
- 调查类：密歇根大学消费者调查、纽约联储 SCE、央行企业调查
- 市场类：**通胀互换（inflation swap）/ 通胀挂钩债券利差（TIPS breakeven）**——市场交易出来的预期

### 4.4 代码：估计菲利普斯曲线

**目标**：用模拟数据估计 $\pi_t = \alpha + \gamma \pi_{t-1} + (1-\gamma)\pi^e - \beta(u_t-u^*) + \varepsilon$ 的简化版，用纯 numpy 做 OLS。

```python
# cb_phillips_ols.py —— 估计菲利普斯曲线（纯 numpy OLS）
import numpy as np
np.random.seed(7)

# ---- 生成模拟宏观数据（"真实"模型参数已知）----
T = 200                      # 季度数
NAIRU = 5.0                  # 自然失业率
PI_STAR = 2.0                # 通胀目标（锚定预期）
u = 5.0 + 0.5*np.random.randn(T)                 # 失业率围绕 NAIRU
u[-40:] += 1.0                                  # 后期衰退
supply = 0.3*np.random.randn(T)                  # 供给冲击
# 真实 DGP: pi_t = 0.4*pi_{t-1} + 0.6*2.0 - 0.5*(u_t-5) + supply
pi = np.zeros(T)
for t in range(1, T):
    pi[t] = 0.4*pi[t-1] + 0.6*PI_STAR - 0.5*(u[t]-NAIRU) + supply[t]

# ---- OLS 估计: pi_t = a + b1*pi_{t-1} + b2*(u_t - 5) + e ----
y = pi[1:]
X = np.column_stack([np.ones(T-1), pi[:-1], u[1:]-NAIRU])
beta_hat, *_ = np.linalg.lstsq(X, y, rcond=None)
resid = y - X @ beta_hat
sigma = resid.std(ddof=3)
# 标准误
XtX_inv = np.linalg.inv(X.T @ X)
se = np.sqrt(np.diag(XtX_inv) * sigma**2)

names = ["const (=γ·π*)", "π_{t-1} (惯性γ)", "失业缺口 (斜率β)"]
print("菲利普斯曲线 OLS 估计")
print("="*48)
print(f"{'变量':<20} {'估计':>8} {'标准误':>9} {'t值':>7}")
print("-"*48)
true = [0.6*PI_STAR, 0.4, -0.5]
for nm, b, s, tr in zip(names, beta_hat, se, true):
    print(f"{nm:<20} {b:>8.3f} {s:>9.3f} {b/s:>7.2f}  (真值 {tr:+.2f})")
R2 = 1 - resid.var()/y.var()
print("-"*48)
print(f"R² = {R2:.3f}")

# ---- 失业缺口 vs 通胀 散点回归斜率（原始菲利普斯）----
slope_gap = beta_hat[2]
print(f"\n失业缺口系数 β = {slope_gap:.3f}")
print(f"含义: 失业率每高于自然率 1pct, 通胀低 {abs(slope_gap):.2f} pct")
print("(若 |β| 很小 → 菲利普斯曲线'扁平化'，权衡变弱)")
```

实测输出（`python3 cb_phillips_ols.py`）：

```

================================================

------------------------------------------------
const (=γ·π*)           1.165     0.078   14.93  (真值 +1.20)
π_{t-1} (惯性γ)           0.410     0.040   10.18  (真值 +0.40)
失业缺口 (斜率β)             -0.507     0.035  -14.33  (真值 -0.50)
```

> **洞察**：估计精准还原了"真实"参数。注意一个实务要点——**如果用真实数据，β 往往估出来很小且不显著**（这就是"菲利普斯曲线扁平化"）。当 β≈0，意味着**用失业率"买"通胀的权衡消失了**——央行无论怎么压失业率，都难以推升通胀。这恰恰是 2010s 发达国家的困境。

## 五、框架之争——央行该按什么"规则"操作？

> "央行该不该有规则？"是宏观经济学百年论战。一端是"相机抉择"（discretion，看情况灵活操作），另一端是"严格规则"（按公式机械执行）。中间是各种"灵活规则"。

### 5.1 框架谱系

| 框架 | 核心主张 | 代表 | 优点 | 缺点 |
|------|---------|------|------|------|
| **通胀目标制 IT** | 明确通胀目标（如 2%），其余服从 | RBNZ 1989 首创，全球主流 | 简单、可信、锚定预期 | 忽视就业/金融稳定 |
| **灵活通胀目标制 FIT** | IT + 兼顾就业/产出 | Fed/BOE/BOJ 现行 | 平衡 dual mandate | 目标多元，问责难 |
| **平均通胀目标制 AIT** | 通胀低过则"补回来"，平均=2% | Fed 2020 引入 | 弥补 ZLB 下空间不足 | 预期难沟通；2021-23 失灵 |
| **货币主义 k% 规则** | 货币量固定增速增长 | Friedman | 机械、防乱来 | M 难控、V 不稳 |
| **NGDP 目标** | 盯名义 GDP 增速 | Market monetarists (Sumner) | 兼顾量价、不需估自然率 | 数据滞后、沟通难 |
| **泰勒规则** | 利率按公式对通胀/缺口反应 | Taylor 1993 | 透明、可预测 | 参数难定、r* 难估 |
| **价格水平目标 PLT** | 盯物价"水平"而非增速 | 学术主张 | 长期价格确定性强 | 短期需通缩，政治不可行 |

### 5.2 规则 vs 相机——时间不一致性

**Kydland-Prescott（1977）**：**时间不一致性**（time inconsistency）。央行今天承诺"我绝不通胀"，但明天发现"稍微胀一点能降失业"——于是违背承诺。公众预见到这点，**承诺不可信，通胀预期就锚不住**。

**解法**：
- **规则约束**（commitment）：用制度绑住央行手脚（通胀目标制、独立央行）
- **声誉机制**：央行若失信，未来说话没人信（代价）

> 这就是为什么全球央行从 1990s 起纷纷"独立化 + 通胀目标制"——不是因为它最优，而是因为它**最可信**。**可信性 > 最优性**，是央行政治经济学的第一定律。

### 5.3 通胀目标制（IT）的兴起与危机

**IT 三要素**：（1）明确的数值目标（通常 2%）；（2）透明的决策框架（通胀报告、新闻发布会）；（3）问责机制（若偏离目标需解释）。

**为什么是 2%**？1989 年新西兰首创，随后被借鉴。2% 不是理论推导——它是经验"甜区"：足够低以稳定预期，又留一点缓冲避免通缩（ZLB）。**但 2021-23 大通胀后，2% 是否仍合理被重新审视**——有人主张调高到 3%（Blanchard/Summers），给央行更多政策空间。

**AIT 的兴起与尴尬**（Fed 2020）：Powell 宣布"灵活平均通胀目标"——若过去低于 2%，未来可允许超 2% 以"平均"。本意是弥补 ZLB。但 2021 通胀飙升，Fed 坚持"暂时性"叙事迟迟不加息，等反应过来通胀已失控。**AIT 成了"为高通胀找借口"的工具**——框架信誉受损。

### 5.4 泰勒规则——最著名的"操作公式"

$$i_t = r^* + \pi_t + 0.5(\pi_t - \pi^*) + 0.5 \, y_t$$

**解读**：政策利率 = 自然利率 + 通胀 + 对通胀缺口反应 0.5 + 对产出缺口反应 0.5。

**关键性质**——**泰勒原理**：通胀缺口系数（这里隐含 1.5）必须 > 1。即通胀涨 1%，利率要涨 > 1%——否则实际利率下降，反而刺激，通胀螺旋。**违反泰勒原理 = 央行失职**。

### 5.5 代码：泰勒规则拟合

**目标**：用模拟数据估计政策利率对通胀缺口和产出缺口的反应系数，检验是否满足"泰勒原理"（通胀反应>1）。

```python
# cb_taylor_fit.py —— 泰勒规则拟合（纯 numpy OLS）
import numpy as np
np.random.seed(11)

T = 160                       # 季度数（40 年）
R_STAR, PI_STAR = 1.0, 2.0    # 自然实际利率 / 通胀目标
shocks = np.random.randn(T)
y_gap = np.zeros(T); pi = np.full(T, PI_STAR)
for t in range(1, T):
    y_gap[t] = 0.7*y_gap[t-1] + 0.4*shocks[t]
    pi[t]    = 0.6*pi[t-1] + 0.4*PI_STAR + 0.3*y_gap[t] + 0.3*np.random.randn(T)[t]
# 真实泰勒规则: i = 1.0 + pi + 0.5*(pi-2) + 0.5*y + noise
i_true = R_STAR + pi + 0.5*(pi-PI_STAR) + 0.5*y_gap + 0.3*np.random.randn(T)

# ---- 估计: i_t = a + b_pi * pi_t + b_y * y_t ----
X = np.column_stack([np.ones(T), pi, y_gap])
beta, *_ = np.linalg.lstsq(X, i_true, rcond=None)
resid = i_true - X @ beta
se = np.sqrt(np.diag(np.linalg.inv(X.T@X)) * resid.var(ddof=3))
a, b_pi, b_y = beta
print("泰勒规则拟合")
print("="*54)
print(f"  截距 a     = {a:6.3f} (se {se[0]:.3f})  理论 = r* - 0.5·π* = {R_STAR-0.5*PI_STAR:.2f}")
print(f"  通胀系数 b = {b_pi:6.3f} (se {se[1]:.3f})  理论 = 1.5")
print(f"  产出系数 c = {b_y:6.3f} (se {se[2]:.3f})  理论 = 0.5")
print("="*54)
taylor_principle = "✓ 满足 (b_π>1, 实际利率随通胀上升)" if b_pi>1.0 else "✗ 违反!"
print(f"\n泰勒原理检验: b_π = {b_pi:.3f}  {taylor_principle}")
print(f"隐含 r* = a + (b_π-1)·π* = {a + (b_pi-1)*PI_STAR:.3f} (理论 {R_STAR})")
```

实测输出（`python3 cb_taylor_fit.py`）：

```
泰勒规则拟合
======================================================
  截距 a     =  0.083 (se 0.118)  理论 = r* - 0.5·π* = 0.00
  通胀系数 b =  1.456 (se 0.056)  理论 = 1.5
  产出系数 c =  0.508 (se 0.062)  理论 = 0.5
======================================================

泰勒原理检验: b_π = 1.456  ✓ 满足 (b_π>1, 实际利率随通胀上升)
隐含 r* = a + (b_π-1)·π* = 0.996 (理论 1.0)
```

> **洞察**：估计几乎完美还原参数。**泰勒规则的价值不在精确预测，而在提供一个"基准"——市场会问"央行利率偏离泰勒规则多少？"**。2002-2005 美联储利率显著低于泰勒规则建议值，Taylor 本人事后论证这正是房地产泡沫的根因（尽管有争议）。**规则不是用来执行的，是用来问责的。**

## 六、QE 深度——机制、争议与退出

> QE 是 2008 后最重要的央行发明。它既是"救市神器"，也是"争议之源"。本节深挖。

### 6.1 QE 的两条传导渠道

#### 渠道一 · 资产组合平衡（Portfolio Balance）

```
央行买长期国债/MBS
   → 这些资产从市场"消失"（央行持有）
   → 投资者被迫调整组合：卖出国债 → 买风险更高资产（公司债/股票）
   → 风险资产价格↑ → 收益率↓ → 企业融资成本↓ → 投资↑
   = "挤出效应"沿风险曲线传导
```

**理论根基**：Modigliani-Sutch 的"期限偏好"（preferred habitat）——不同投资者偏好不同期限的资产，市场不是完全替代的。所以**改变供给能改变收益率**。这与"无套利/有效市场"理论相悖——QE 的有效性本身就反驳了"市场完全有效"。

#### 渠道二 · 信号（Signaling）

```
央行宣布 QE/持续购买
   → 市场解读："央行决心长期维持宽松"
   → 未来短期利率预期 ↓
   → 长期利率（= 预期 + 期限溢价）↓
```

**理论根基**：QE 本身就是"超强力度的前瞻指引"——用真金白银投票，比嘴说更可信。

### 6.2 QE 的效果有多大？

实证共识（Gagnon et al. 2011; Krishnamurthy-Vissing-Jorgensen 2011）：美联储首轮 QE（2008-09，1.75 万亿美元）压低 10 年期国债收益率约 **50-100bp**。后续轮次效果递减（边际效用递减 + 市场已 price-in）。

### 6.3 QE 的四大争议

| 争议 | 论点 | 论据 |
|------|------|------|
| **贫富分化** | QE 推高资产价格，富人受益，穷人无资产 | 美联储研究：2009-2019 股市回暖，最富 10% 拿走大部分；房价上涨挤压租房者 |
| **资产泡沫** | 低利率催生风险追逐、僵尸企业、估值虚高 | SPAC 狂热、加密货币泡沫、 meme stocks（2020-21） |
| **僵尸企业** | 低成本续命本该倒闭的企业，拖累生产率 | BIS 研究：僵尸企业占比与低利率正相关 |
| **财政主导** | 央行变相为财政赤字融资，独立性丧失 | 2020 美联储买大量国债，被批"债务货币化" |

> **essence 立场**：QE 不是"中立工具"——它有**分配后果**。它救了金融系统，但把成本（未来通胀/贫富差距/债务积累）转嫁给了**没有金融资产的人**。这是 §九"央行政治化"的现实注脚。

### 6.4 退出之难——Taper Tantrum

```
2013.5  Bernanke 暗示缩减 QE →
  → 新兴市场暴跌（"缩减恐慌" taper tantrum）
  → 印度/巴西/南非货币崩盘
  → 美国国债收益率飙升
2013.9  推迟 taper → 市场反弹
2014.1  正式 taper，市场已适应 → 平稳
```

**教训**：**退出比进入难十倍**。QE 把市场养成了"央行依赖症"（addiction）——一旦暗示撤走"奶嘴"，市场就崩。这创造了**"央行看跌期权"（Fed put）**——市场相信央行会在下跌时出手相救，于是更敢冒险（道德风险）。

## 七、2008 与 2020——央行的"范式革命"

> 两次危机彻底重塑了央行实践。**2008 救金融体系，2020 救整个经济。央行从"最后贷款人"升级为"最后交易商"（dealer of last resort）。**

### 7.1 2008——金融海啸中的央行

**时间线与工具创新**：
```
2008.3   Bear Stearns 被救（JPM 收购 + Fed 担保 300 亿）
2008.9   Lehman 倒闭（Fed/财政部拒绝救助 → 全球恐慌）
         AIG 救助（Fed 850 亿贷款）
         互惠市场冻结 → Fed 设 AMC 工具
2008.10  全球协调降息（Fed/ECB/BOE/BOE/RBA/.../Riksbank 同步降 50bp）
         QE1 启动（GSE 债务 + MBS 购买）
2008.12  联邦基金利率降至 0-0.25% ZLB
2009.3   QE1 扩容至 1.75 万亿（长期国债 + MBS）
```

**央行角色的突破**：
- **Bagehot 原则被突破**：救助了资不抵债的机构（AIG、后来的欧洲银行），不只救 solvent 的
- **最后贷款人 → 最后交易商**：Perry Mehrling 概念——央行直接成为各类市场的做市商（不只借钱给银行，直接进 MBS/CP/货币市场买入资产），维持市场"流动性的流动性"

### 7.2 全球流动性互换额度（Swap Lines）

```
2008 美元短缺（海外银行需美元结算，但美元市场冻结）
   → Fed 与 14 国央行设立 swap lines
   → Fed 借出美元，换回对方货币
   → 各国央行把美元贷给本国银行
   = Fed 充当"全球美元最后贷款人"
```

**意义**：swap lines 是美元霸权的极致体现——**美联储事实上成为全球央行**。2020 疫情再次启动 swap lines（且新增 FIMA 工具允许外国央行直接典押美债换美元）。**美元的全球地位 = Fed 的全球权力**（见 [`international-finance.md`](./international-finance.md) §美元霸权）。

**政治含义**：2020 后，Fed 把 swap lines 从"应急"变成"常备"（standing），被批"美元永久性国际化"。去美元化的反制（金砖国家本币结算）部分源于此。

### 7.3 2020——疫情冲击的"无限量"反应

```
2020.3   疫情恐慌，美股四次熔断
         Fed 紧急降息至 0-0.25%
         启动"无限量 QE"（unlimited QE）——市场要多少买多少
         设 13(3) 紧急工具：SMCCF（公司债 ETF！）、PMCCF、MSLP...
         = 央行直接买公司债 ETF = 突破"只买国债"传统
2020.3   重启 swap lines，缓解全球美元荒
2020     Fed 资产负债表从 4.2 万亿飙升至 7.2 万亿（年底）
```

**2020 的革命性**：
- **速度更快**：2008 用了数月，2020 数周完成
- **范围更广**：直接进公司债市场、市政债、中小企业贷款——央行变成"全能买家"
- **财政部 + 央行协同**：CARES Act 财政注资 Fed 工具的股权部分——**财政与货币彻底合流**（MMT 的"事实版"）

### 7.4 后遗症——2021-2023 大通胀

```
2020-21  超宽松（0 利率 + 巨额 QE + 财政刺激）
         + 供给侧冲击（疫情供应链/俄乌战争/能源）
2021     通胀飙升至 7%+（美国），欧元区跟进
2021.11  Powell 放弃"暂时性"叙事
2022.3   Fed 启动加息周期（数十年来最快）
2022.6   开始 QT
2022-23  累计加息 525bp（0.25% → 5.5%）
2023.3   SVB/SVB/Signature 银行倒闭（加息副作用：债券浮亏）
2023     通胀回落至 3%，但"最后一英里"艰难
```

> **essence 立场**：2020 证明了两件事——**（1）央行反应能力极强**，能在几周内释放数万亿美元；**（2）央行无法精确控制后果**——救市释放的流动性 + 供给侧冲击 = 大通胀。**央行的工具是霰弹枪，不是手术刀。**

## 八、PBOC 的独特路径

> 中国人民银行是世界上**最独特**的主要央行之一——它既用现代工具（利率走廊/MLF），又保留计划经济遗产（存准率/窗口指导/信贷额度）。**PBOC 是"数量型 + 价格型"双轨转型的活化石。**

### 8.1 PBOC 的工具箱

```
PBOC 工具谱系
├── 数量型（传统，主导）
│   ├── 存款准备金率 RRR（核心，调节货币乘数）
│   ├── 再贷款/再贴现（定向）
│   ├── 外汇占款（2001-2014 主导，现萎缩）
│   └── 信贷额度/窗口指导（行政性）
├── 价格型（转型中，2015 后强化）
│   ├── OMO 逆回购利率（短期，7 天）
│   ├── MLF 利率（中期，LPR 的锚）
│   ├── SLF（常备借贷便利，利率走廊上限）
│   ├── LPR（贷款市场报价利率，2019 改革后贷款定价基准）
│   └── 存贷款基准利率（渐淡化，仍存）
└── 结构性（定向输血）
    ├── PSL（抵押补充贷款 → 国开行棚改）
    ├── 定向降准（普惠金融/绿色）
    └── 碳减排支持工具（2021）
```

### 8.2 数量型 vs 价格型——转型的核心张力

**为什么 PBOC 用"数量型"多**：
1. **传导不畅**——利率管制时期，调利率传不到市场（存贷款基准管制）
2. **汇率绑定**——固定汇率下，利率政策受三元悖论约束（见 [`international-finance.md`](./international-finance.md)）
3. **信贷导向**——数量型工具便于"定向输血"（产业政策）

**转型困境**：
- 利率市场化 2015 完成（存款上限放开），但**银行仍习惯盯基准利率**
- **LPR 改革（2019）**：贷款定价从"央行基准"切换到"MLF + 加点"的 LPR，意图打通"MLF→LPR→贷款利率"传导链
- **现实**：银行放贷利率仍受"信贷需求 + 风险偏好"主导，LPR 改革传导有限

### 8.3 关键事件——811 汇改

```
2015.8.11  PBOC 改革人民币中间价定价
   之前：中间价由央行"管理"（偏离市场）
   之后：中间价 = 前日收盘价 + 一篮子货币稳定
   → 单日贬值近 2%（多年最大）
   → 引发资本外流恐慌（2015-2016 外储从 4 万亿跌至 3 万亿）
   → 加强资本管制 + 动用外储干预
   → 2017 后汇率趋稳，加入 SDR
```

**教训**：811 汇改的初衷是"市场化"，但触发"贬值预期→资本外流→更贬值"的恶性循环。**汇率市场化在没有资本管制后盾时，会引发失序**。最终用"资本管制 + 中间价逆周期因子"重新锚定。这是**三元悖论的活教材**——中国选择"货币政策独立 + 固定汇率"，代价是资本管制（见 [`international-finance.md`](./international-finance.md) §三元悖论）。

### 8.4 PBOC vs Fed——制度对比

| 维度 | Fed（美国） | PBOC（中国） |
|------|------------|-------------|
| **独立性** | 高（决策不须经总统） | 低（国务院组成部门，重大决策报中央） |
| **目标** | 双重使命（通胀+就业） | 多重（币值稳定+增长+就业+国际收支） |
| **主导工具** | 价格型（利率） | 数量型（RRR）+ 价格型转型 |
| **资产负债表主资产** | 国债 + MBS | 外汇占款（历史）+ 对银行债权（MLF/PSL） |
| **汇率** | 浮动 | 有管理浮动 + 资本管制 |
| **政治问责** | 向国会报告 | 向国务院/党中央报告 |
| **财政关系** | 法律禁止直接买国债 | 可买特别国债（如 2007 汇金） |

> **essence 立场**：PBOC 的"非独立性"不是缺陷——它是**中国体制的 deliberate design**（见 [`china-financial-system.md`](./china-financial-system.md) §顶层控制）。在中国，"货币政策服从于国家战略"是 explicit 的。**独立性与否不是技术问题，是政治哲学问题**——你信"专家独立决策"还是"民主集中制"？这个问题没有客观答案（§九）。

## 九、独立性与政治——央行的民主悖论

> 央行是最强大的非民选机构。**它管每个人的钱袋子，却不对选民直接负责**。这个张力是现代民主的深层裂缝。

### 9.1 央行独立性的"幻觉"

**官方叙事**：独立央行 = 不受短期政治干扰（政客爱印钞讨好选民）= 更好的通胀治理。1980-1990s 全球央行独立化浪潮（RBNZ、Bank of England 1998、ECB 1998、BOJ 改革）的依据。

**现实裂缝**：
1. **目标由政治决定**——独立的是"工具"，不是"目标"。通胀目标 2% 由政府定，央行只是"执行独立"。
2. **QE 后独立性侵蚀**——央行扩表买国债，事实上参与财政。决策越来越像政治决策。
3. **危机时政治必然介入**——2008/2020 央行与财政部深度协同，"独立性"暂时悬置。
4. **分配后果是政治的**——QE 的贫富分化效应是政治问题，但央行不民主问责。

### 9.2 财政主导（Fiscal Dominance）

```
货币主导（monetary dominance）：
  央行独立 → 不为财政赤字买单 → 财政必须自律 → 通胀可控

财政主导（fiscal dominance）：
  债务过高 → 央行被迫保持低利率 + 买国债（压低融资成本）
           → 通胀是被默许的（通胀稀释债务）
           → 央行名义独立，实质是财政的工具
```

**2020 后的担忧**：发达国家债务/GDP 创历史新高（美国 120%+，日本 250%+）。维持债务可持续性需要低利率——这**绑架了货币政策**。央行想抗通胀加息，但加息会引爆债务危机。这就是 **"财政主导"回归**——与 1940s 二战后的情境惊人相似（当时靠"金融抑制"低利率 + 通胀稀释了战债）。

### 9.3 MMT 的挑战

**现代货币理论（MMT）核心主张**：
- 主权货币国家（借自己货币）**不会技术性违约**
- 财政可先花钱，央行配合；通胀才是约束，不是"钱够不够"
- 央行应**从属于财政**（本质反对央行独立）

**对央行范式的冲击**：
- 若 MMT 对，央行独立性是"多余的紧箍咒"
- 2020 的实践（财政+货币协同）被 MMT 支持者视为"我们早就说了"

**批评**：
- MMT 忽视通胀的**政治经济学**——通胀来了，民主国家很难迅速加税回收货币
- MMT 在新兴市场（非主权货币/依赖外债）几乎不适用
- MMT 容易被政客"选择性使用"——只采纳"可以多花钱"，不采纳"通胀来了要加税"

> **essence 立场**：MMT 不全是错——它点破了"主权货币 + 浮动汇率"国家的**会计真相**。但"可以"不等于"应该"。**约束货币的不是会计，是通胀的政治后果**。央行的价值，恰恰在于它**是不受欢迎决策的执行者**（加息抗通胀总是得罪人）——这正是独立性存在的伦理理由。

## 十、央行的极限——ZLB、推绳子与 CBDC

> 央行不是全能的。它有几个硬极限。

### 10.1 零利率下限（Zero Lower Bound, ZLB）

**问题**：名义利率难大幅低于零（现金的零利率是地板——负太狠大家囤现金）。ZLB 时，央行**降息工具失效**。

**应对**：
- 非常规工具（QE/FG/负利率）——但效果递减
- 提高通胀目标（如 4%）——给未来留更多降息空间（Krugman 主张）
- AIT——制造"补偿性"预期

### 10.2 流动性陷阱与"推绳子"

```
正常：央行拉绳子（收紧）—— 一拉就灵
陷阱：央行推绳子（宽松）—— 用力推，绳子软塌塌不动
```

**机制**：利率到零 + 预期通缩 → 居民/企业囤钱不消费/投资 → 货币政策失效。**日本 1990s-至今的写照**。

**解法争议**：
- **货币财政协同**（Krugman/Bernanke）：央行承诺通胀，财政直接发钱
- **直升机撒钱**（Friedman 思想实验）：央行直接把钱打到居民账户（= 货币 + 财政合一）
- **"通胀目标可信承诺"**：央行承诺"不惜一切代价制造通胀"，改变预期

### 10.3 央行数字货币（CBDC）——重塑基础设施

> 2020 后，全球央行争相研究 CBDC。这不是"加密货币"——它是**法币的数字形态**，央行直接面向公众发行。

**CBDC 的潜力**：
| 维度 | 影响 |
|------|------|
| 支付效率 | 实时跨境支付、降低中介成本 |
| 货币政策 | 可编程货币——精准定向（如带过期日的消费券）/ 突破 ZLB（负利率可直接施加于数字法币） |
| 金融包容 | 无银行账户者也能用央行货币 |
| 主权防御 | 抵御稳定币/外币 CBDC（如数字美元）的货币替代 |

**争议与风险**：
- **去中介化**——居民把钱从商业银行搬到央行（挤兑风险），商业银行失去存款基础
- **隐私 vs 可追踪**——央行能看到每一笔交易（监控风险）
- **分级设计**——BIS 提"两层架构"（央行→银行→公众），缓解去中介化

**案例**：
- **数字人民币（e-CNY）**——全球最领先的零售 CBDC 试点，已覆盖数亿钱包。但实际日均交易仍小，主要在补贴/政务场景
- **数字欧元**——ECB 调研中，2026 后可能发行
- **Fed**——谨慎，担心 CBDC 改变银行体系结构

> **essence 立场**：CBDC 不是技术问题，是**货币主权的重新定义**。它可能让央行第一次**直接面对每个公民**——这是货币史上从未有过的权力结构。**风险（监控/集权）与机遇（效率/包容）同样巨大**。

## 十二、essence 总结——央行的三重悖论

> 学习央行后，提炼三个无法消解的内在悖论。它们不是"待解决的问题"，而是**央行作为制度设计的结构性张力**。

**悖论一 · 独立 vs 问责**
- 央行需要独立才能做不受欢迎的决策（加息抗通胀）
- 但独立意味着不民主问责，分配后果无人负责
- 解不了——只能在两极间动态摇摆

**悖论二 · 规则 vs 灵活**
- 规则保证可信（时间一致性）
- 但世界在变，规则总会过时（2020 疫情、2008 危机都需打破常规）
- 解不了——"灵活规则"是妥协，不是解决

**悖论三 · 稳定 vs 道德风险**
- 央行出手救市，避免灾难
- 但救助本身制造"下次更敢冒险"的预期（Fed put）
- Minsky 的洞察：**稳定孕育不稳定**（见 [`money-and-credit.md`](./money-and-credit.md) §金融不稳定）

> **一句话**：央行不是"经济的 thermostat"——调好温度就万事大吉。它是**一个永远在悖论中走钢丝的制度**。理解央行，就是理解**现代社会如何在不完美中管理不完美**。
