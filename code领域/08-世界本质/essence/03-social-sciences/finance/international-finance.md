## 一、国际金融的核心框架

### 什么是国际金融？

**经典定义**：国际金融研究**主权货币之间的价值关系**——不同国家的货币如何兑换、一国的经济活动如何通过国际收支影响他国、资本如何跨境流动、汇率如何决定。

**essence 理解**：国际金融 = "开放经济下的金融"。它把封闭经济的三个核心变量（**时间 × 风险 × 信任**，见 [`_overview.md`](./_overview.md)）放到一个多国博弈场里，再加上两个新维度：

4. **汇率**——货币之间的相对价格（一个全新的、最难预测的价格）
5. **主权边界**——货币是有主权的（央行的领地），但资本想跨境流动

> **一句话**：国际金融是**主权与流动的战场**——国家想控制自己的货币（主权），资本想自由流动（市场），这两个力量永恒拉扯。**三元悖论**就是这场拉扯的数学表达。

### 四元联动系统

国际金融不是一堆独立概念的集合，而是一个**强耦合的反馈系统**：

```
                 ┌──────────────┐
                 │   汇率 (S)    │◄──────────┐
                 └──────┬───────┘           │
                        │ 影响               │ 影响
                        ▼                    │
                 ┌──────────────┐    影响    │
        ┌───────►│  国际收支(BOP) │──────────►│
        │        └──────┬───────┘           │
        │ 影响          │ 恒等              │
        │               ▼                   │
┌──────────────┐  ┌──────────────┐          │
│ 资本流动 (K)  │◄─┤  外汇储备 (R) │◄─────────┤
└──────┬───────┘  └──────────────┘          │
       │ 影响                                │
       ▼                                     │
┌──────────────┐                             │
│ 货币政策 (i)  │─────────────────────────────┘
└──────────────┘   利率差驱动资本流动 → 影响汇率
```

**四个变量的核心关系**（后文逐一展开）：
1. **汇率 S**：货币的相对价格——由 PPP、利率平价、资产市场均衡决定
2. **国际收支 BOP**：经常账户 + 资本账户 + 储备 = 0（会计恒等式）
3. **资本流动 K**：利率差、风险偏好、预期汇率共同驱动
4. **货币政策 i**：央行的利率——通过三元悖论与其他三者联动

### 为什么汇率是"最难预测的价格"？

| 价格类型 | 可预测性 | 原因 |
|---------|---------|------|
| 商品价格（苹果） | 较高 | 供需相对稳定 |
| 股票价格 | 中等 | 受基本面（盈利）约束 |
| **汇率** | **极低** | 汇率是**两国相对**价格——要同时预测两国 |

Meese & Rogoff（1983）的经典研究发现：**没有一个汇率模型能系统性地击败"随机游走"（明天的汇率=今天的汇率）**。这个结论至今基本成立。

> **essence 立场**：汇率预测的困难不是"技术不够"——而是汇率本质上是**群体预期的均衡**（见 [`markets-and-pricing.md`](./markets-and-pricing.md)），而群体预期包含未来信息，未来信息原则上不可预测。这是认识论限制，不是工程问题。

## 二、汇率理论全谱系

> 汇率理论有一个从"长期均衡"到"短期动态"的谱系。每个理论捕捉了汇率决定的一个侧面，但没有任何单一理论能解释全部。

### 2.1 购买力平价（Purchasing Power Parity, PPP）

#### 直觉层

**核心思想**（Cassel, 1918）：一价定律——**同样的商品，在不同国家用不同货币标价后，扣除汇率应该一样贵**。否则就有套利空间。

> 比喻：如果一个巨无霸在美国卖 5 美元、在中国卖 24 元，那么"均衡汇率"应该是 24/5 = 4.8 元/美元。如果市场汇率是 7.2，说明人民币被"低估"了。

#### 数学层

**绝对购买力平价**（Absolute PPP）：
$$S = \frac{P}{P^*}$$
其中 $S$ 是汇率（本币/外币），$P$ 是本国物价水平，$P^*$ 是外国物价水平。

**相对购买力平价**（Relative PPP）：
$$\frac{\Delta S}{S} = \pi - \pi^*$$
汇率变动率 ≈ 本国通胀率 − 外国通胀率。高通胀国家的货币应该贬值。

#### 代码层：用巨无霸指数验证 PPP 偏离

```python
# 【已验证·bash 可跑】购买力平价偏离：巨无霸指数 (The Economist, ~2024)
print("【PPP 偏离验证】巨无霸指数")
print(f"{'国家':<8}{'本地价格':<10}{'隐含PPP':<12}{'市场汇率':<12}{'偏离率':<10}")
base_usd = 5.69  # 美国巨无霸(基准)
data = [("美国",5.69,1.0),("瑞士",7.10,0.877),("挪威",82.0,10.76),
        ("欧元区",5.30,1.08),("英国",4.59,0.987),("日本",450.0,149.0),
        ("巴西",22.9,4.99),("中国",24.0,7.23),("印度",226.0,83.1),("俄罗斯",190.0,90.5)]
for name, local, spot in data:
    ppp = local / base_usd          # 隐含PPP汇率(本币/$)
    dev = (ppp - spot) / spot * 100 # 偏离率
    tag = "低估" if dev < 0 else "高估"  # dev<0: 市场比PPP更多本币/$ → 本币更便宜 → 低估
    print(f"{name:<8}{local:<10.2f}{ppp:<12.3f}{spot:<12.3f}{dev:+.1f}% {tag}")
```

**验证输出**（2026-07 bash 实跑）：
```
中国      24.00      4.218        7.230       -41.7% 低估
瑞士      7.10       1.248        0.877       +42.3% 高估
印度      226.00     39.719       83.100      -52.2% 低估
俄罗斯    190.00     33.392       90.500      -63.1% 低估
日本      450.00     79.086       149.000     -46.9% 低估
```

#### PPP 的局限与修正

| 局限 | 原因 | 修正 |
|------|------|------|
| **短期严重偏离** | 价格粘性、资本流动远快于贸易 | PPP 是**长期**均衡，5-10 年才趋同 |
| **非贸易品** | 理发/房子不能跨境套利 | Balassa-Samuelson 效应：穷国非贸易品便宜 → 系统性低估 |
| **商品差异** | 巨无霸不是完全同质商品 | 用 CPI/核心 CPI 更稳健，但篮子差异仍大 |
| ** Penn 效应** | 实际汇率与收入水平正相关 | 发达国家实际汇率系统性高于发展中国家 |

> **Balassa-Samuelson 效应**（1964）：穷国的**可贸易品**生产率低（便宜），但**非贸易品**（服务/住房）因工资均等化而相对便宜 → 整体物价水平低 → PPP 显示货币"低估"。但这部分"低估"是**结构性的**，不一定有套利空间。这解释了为什么人民币、卢比长期"被低估"。

### 2.2 利率平价（Interest Rate Parity, IRP）

#### 直觉层

**核心思想**：如果美国利率 5%、日本利率 0%，为什么不都把钱放美国？因为**汇率会变**——美元可能贬值，抵消利差。利率平价说：**利差 = 预期汇率变动**，套利空间被消除。

#### 数学层

**抛补利率平价**（Covered IRP, CIRP）——用远期合约对冲：
$$\frac{F - S}{S} \approx i - i^*$$
远期升贴水率 ≈ 两国利率差。这是**无套利**的硬约束（否则有套利机会），实证上高度成立。

**无抛补利率平价**（Uncovered IRP, UIRP）——不对冲，承担汇率风险：
$$\frac{E[S_{t+1}] - S_t}{S_t} \approx i - i^*$$
预期汇率变动 ≈ 利率差。

#### 代码层：UIRP 验证与"远期偏差之谜"

```python
# 【已验证·bash 可跑】无抛补利率平价验证
def uirp_implied_dep(i_d, i_f):
    return (i_d - i_f) * 100  # 隐含年化贬值率(%)
print("UIRP: E[ΔS]/S ≈ i_domestic − i_foreign")
print(f"{'货币对':<22}{'本币利率':<11}{'外币利率':<11}{'UIRP隐含贬值':<14}")
for name, id_, iff in [("USD/JPY",5.25,0.10),("USD/EUR",5.25,4.0),
                       ("TRY/USD",45.0,5.25),("ARS/USD",80.0,5.25)]:
    dep = uirp_implied_dep(id_/100, iff/100)
    print(f"{name:<22}{id_:.2f}%{'':<5}{iff:.2f}%{'':<5}{dep:+.1f}%")
print("\n[现实] 高利率货币往往升值而非贬值 → '远期偏差之谜'(Forward Premium Puzzle)")
print("       UIRP 经验上被拒绝 → 套利交易(Carry Trade)长期有效")
```

**输出**：
```
TRY/USD      45.00%     5.25%     +39.8%  (里拉应贬值39.8%)
ARS/USD      80.00%     5.25%     +74.8%  (比索应贬值74.8%)
```

#### 远期偏差之谜（Forward Premium Puzzle）——UIRP 的重大失败

UIRP 说：高利率货币应该贬值。但实证发现——**高利率货币反而倾向升值**。这就是"远期偏差之谜"。

**经济含义**：违反 UIRP = 有利可图。**套利交易**（Carry Trade）：借低利率货币（日元），投高利率货币（澳元/土耳其里拉），赚取利差。长期统计上盈利——但这是一种"在压路机前捡硬币"的策略，偶尔遭遇毁灭性回撤（如 2008 年日元套利平仓）。

> **essence 连接**：UIRP 的失败与 [`risk-and-uncertainty.md`](./risk-and-uncertainty.md) 的核心命题一致——利差不是"免费的午餐"，而是**风险溢价**。市场给高利率货币的风险溢价，远大于 UIRP 假设的零风险溢价。这是"把不确定性假装成风险"的经典案例。

### 2.3 货币模型（Monetary Approach）

#### 核心思想

汇率是**两种货币的相对价格**，而货币的价格由货币供需决定。因此汇率由两国的**货币供给、收入、利率**决定。

**弹性价格货币模型**（Frenkel, 1976）：
$$s = (m - m^*) - \phi(y - y^*) + \lambda(i - i^*)$$
其中 $s$ 是汇率（对数），$m$ 货币供给，$y$ 收入，$i$ 利率。

**直觉**：
- 本国货币超发（$m\uparrow$）→ 货币贬值（$s\uparrow$）
- 本国收入增长（$y\uparrow$）→ 货币需求增加 → 货币**升值**（$s\downarrow$）
- 本国利率上升（$i\uparrow$）→ 货币需求下降 → 货币贬值（$s\uparrow$）

> 货币模型把 PPP + 货币数量论缝合在一起。在 1970s 通胀时期解释力强（德国马克 vs 美元），但在汇率剧烈波动的现代市场解释力下降。

### 2.4 资产组合平衡模型（Portfolio Balance Model）

#### 核心思想

**突破点**：货币模型假设国内外债券**完全替代**。资产组合平衡模型（Branson, 1977; Kouri）放弃这个假设——**国内外债券风险不同，不是完全替代品**。

```
本国财富 W = M(本国货币) + B(本国债券) + B*(外国债券)
     ↓ 分别对各类资产的需求
汇率 S 由外国债券 B* 的供需均衡决定
```

**关键机制**：经常账户盈余 → 外国资产积累 → 财富增加 → 对本国债券需求增加 → 汇率变动。**经常账户直接影响汇率**（这是货币模型没有的）。

### 2.5 Dornbusch 汇率超调模型（Overshooting Model, 1976）

#### 直觉层

**Rudi Dornbusch 的天才洞见**：商品价格调整慢（粘性），资产价格（汇率、利率）调整快。当货币紧缩时，汇率会**暂时性地过度升值**（超调），然后慢慢回归长期均衡。

> 比喻：你用力拉一根有阻尼的弹簧。弹簧不会平滑到达新位置——它会**冲过头**，然后振荡回来。汇率就是这根弹簧。

#### 数学层（简化）

```
商品市场(慢):   价格调整  ṗ = π(y_d - ȳ)        ← 价格粘性
资产市场(快):   汇率调整  瞬时达到均衡           ← 汇率灵活
长期均衡:       货币模型给出的 PPP 汇率 S̄
短期超调:       S₀ > S̄ (本币过度升值)
中期回归:       S → S̄ (价格追上来后回归)
```

**超调的根源**：货币紧缩 → 利率上升 → 资本流入 → 本币升值。但商品价格还没降，本币实际汇率升值过度。只有等国内价格慢慢下降（通缩压力），实际汇率才回到均衡。

#### 为什么超调模型重要？

1. **解释了汇率的过度波动**——汇率波动远大于 fundamentals（货币供给、收入）的波动。这是"超调"的直接证据。
2. **连接了短期与长期**——短期汇率超调，长期回归 PPP。统一了两个时间尺度。
3. **政策含义**——货币政策对汇率的影响被放大。央行的每一个动作，汇率都会过度反应。

> **essence 连接**：超调模型是 [`06-systems/feedback/`](../../06-systems/feedback.md) 的经典案例——**快变量 + 慢变量 + 耦合 = 振荡/超调**。这与控制论中的"欠阻尼响应"完全同构。

### 汇率理论谱系总结

| 理论 | 时间尺度 | 核心变量 | 优势 | 劣势 |
|------|---------|---------|------|------|
| **绝对 PPP** | 超长期(10y+) | 物价水平 | 直觉清晰 | 短期完全失效 |
| **相对 PPP** | 长期(5-10y) | 通胀差 | 通胀差异解释力强 | 忽略结构性因素 |
| **CIRP** | 短期(即时) | 利率+远期 | 无套利，高度成立 | 只是定价关系，非预测 |
| **UIRP** | 中期(1y) | 利率差+预期 | 理论优雅 | **经验上被拒绝** |
| **货币模型** | 中长期 | 货币供需 | 通胀期有效 | 现代解释力弱 |
| **资产组合** | 中期 | 经常账户+资产 | 常账户影响汇率 | 数据要求高 |
| **Dornbusch 超调** | 短期动态 | 价格粘性 | 解释过度波动 | 假设较强 |

> **essence 立场**：没有"对的"汇率理论——每个理论捕捉了一个**时间尺度 + 一个机制**。短期看利率和预期（IRP/超调），中期看经常账户（资产组合），长期看物价（PPP）。**理解汇率 = 理解这些机制何时主导**。

## 三、国际收支平衡（Balance of Payments, BOP）

### 什么是国际收支？

**定义**：国际收支是一个国家居民与非居民之间，在一定时期内所有经济交易的**系统记录**。它是一张"国际账本"。

### BOP 的三大账户

```
国际收支 (BOP)
├── 1. 经常账户 (Current Account, CA)
│     ├── 货物贸易 (Goods)          ← 出口 - 进口
│     ├── 服务贸易 (Services)        ← 旅游/运输/知识产权
│     ├── 初次收入 (Primary Income)  ← 投资收益/工资
│     └── 二次收入 (Secondary Income)← 转移支付/侨汇
│
├── 2. 资本与金融账户 (Capital & Financial Account, FA)
│     ├── 资本账户 (Capital)         ← 资本转移/非生产资产
│     └── 金融账户 (Financial)
│           ├── 直接投资 (FDI)
│           ├── 证券投资 (Portfolio)
│           ├── 金融衍生品
│           └── 其他投资 (贷款/存款)
│
└── 3. 储备资产 (Reserve Assets, RT)
      ├── 外汇储备
      ├── 黄金
      ├── SDR
      └── IMF 头寸
```

### 会计恒等式（最重要）

$$\boxed{CA + FA + \Delta Reserves = 0}$$

**这是国际金融的"能量守恒"**——每一笔跨境交易，必同时记入两个账户。

> **直觉**：如果你进口多于出口（经常账户赤字 CA<0），钱从哪来？要么借（资本流入 FA>0），要么花外汇储备（ΔR<0）。三者必然抵消。

**恒等式的三种变形**（政策含义不同）：

```
形态1: CA + FA + ΔR = 0                    (完整恒等式)
形态2: CA = -FA - ΔR                        (经常账户 = 资本流出 + 储备减少)
形态3: CA = S - I  (储蓄-投资)              (经常账户 = 国民储蓄 - 国内投资)
形态4: CA = (G - T)的负值 + 私人储蓄-投资    (双赤字定理)
```

#### 双赤字定理（Twin Deficits）

$$CA = (S - I) + (T - G)$$

如果政府赤字（$G > T$）且私人储蓄不足（$S < I$），则经常账户必然赤字（$CA < 0$）。**美国的"双赤字"**（财政赤字 + 经常账户赤字）就是这个恒等式的现实写照。

### 经常账户赤字 = 坏事吗？

**不一定**。关键看赤字**怎么融资**：

| 赤字融资方式 | 例子 | 评价 |
|------------|------|------|
| FDI 流入（生产性） | 越南、爱尔兰 | ✅ 好——投资未来生产力 |
| 证券投资流入 | 美国 | ⚠️ 中——依赖资本市场信心 |
| 短期债务流入 | 1997 前的泰国 | ❌ 危险——"热钱"，随时外逃 |
| 消耗储备 | 1997 泰国、2018 土耳其 | ❌ 不可持续——储备终将耗尽 |

> **essence 洞察**：经常账户赤字本身是中性的——它只是"现在消费多于生产"的会计记录。**真正的问题是融资的质量**：用 FDI 融资的赤字是投资未来，用短期热钱融资的赤字是透支未来。1997 亚洲危机的核心教训就是：**错误的融资方式 + 固定汇率 = 定时炸弹**。

## 四、三元悖论（不可能三角）深度

### 4.1 三元悖论的陈述

**不可能三角**（Impossible Trinity / Mundell-Fleming Trilemma）：

> 一个国家**最多只能同时拥有以下三个中的两个**：
> 1. **固定汇率**（Fixed Exchange Rate）
> 2. **资本自由流动**（Free Capital Mobility）
> 3. **货币政策独立性**（Monetary Policy Independence）

```
              货币政策独立性
                 /\
                /  \
               /    \
              / 只能 \
             /  选两个 \
            /__________\
     固定汇率 ──────── 资本自由流动
```

#### 代码层：画不可能三角示意图

### 4.2 Mundell-Fleming 模型——三元悖论的证明

Mundell（1963）和 Fleming（1962）把封闭经济的 IS-LM 模型扩展到开放经济，得到 **IS-LM-BP 模型**。

#### 三条曲线

```
IS 曲线:  产品市场均衡  Y = C + I + G + NX(Y, S)
           ↳ 开放经济多了净出口 NX，受汇率 S 影响
LM 曲线:  货币市场均衡  M/P = L(Y, i)
           ↴
BP 曲线:  国际收支均衡  NX(Y,S) + CF(i - i*) = 0
           ↳ 经常账户 + 资本流动 = 0
```

#### 不同资本流动假设下的 BP 曲线

```
资本完全不流动:  BP 垂直 (利率差不影响资本) → 只有经常账户平衡
资本部分流动:    BP 向上倾斜
资本完全流动:    BP 水平 (i = i*) → 国内利率 = 世界利率
```

#### 三元悖论的推导（资本完全流动情形）

```
情形A: 固定汇率 + 资本自由流动 → 货币政策无效
  央行扩张(M↑) → i↓ → 资本外流 → 本币贬值压力
  → 为维持固定汇率，央行卖外汇买本币 → M↓回原位 → 扩张无效
  ✗ 货币政策独立性丧失

情形B: 浮动汇率 + 资本自由流动 → 货币政策有效
  央行扩张(M↑) → i↓ → 资本外流 → 本币贬值 → NX↑ → Y↑
  ✓ 货币政策有效，但汇率浮动

情形C: 固定汇率 + 资本管制 → 货币政策有效
  央行扩张(M↑) → i↓ → 资本想外流但出不去(管制)
  → 汇率不受冲击 → 固定汇率维持 + 扩张有效
  ✓ 但牺牲了资本流动
```

> **Mundell 因此获 1999 年诺贝尔经济学奖**（"最优货币区"理论 + Mundell-Fleming 框架）。

### 4.3 三个角的实例

#### 角 1：香港——固定汇率 + 资本自由，放弃货币独立

**联系汇率制（Linked Exchange Rate, 1983 至今）**：
- 港币盯住美元（7.75-7.85 港元/美元）
- 资本完全自由流动（国际金融中心）
- **代价**：香港没有独立货币政策——美联储加息，香港必须跟；美联储降息，香港也必须跟

```
美联储加息 → 港元利率必须同步上升
  → 香港楼市/股市承受美国货币政策的外溢
  → 1997 危机、2008 危机、2022-23 加息，香港都"被动承受"
```

> **essence 洞察**：香港的选择是"小经济体理性策略"——对于高度开放的小经济体，固定汇率（锚定大国货币）+ 资本自由（吸引国际资本）的收益，大于独立货币政策的收益。这是**用货币主权换取金融稳定和可信度**。

#### 角 2：美国——货币独立 + 资本自由，浮动汇率

- 美联储完全独立制定利率
- 资本完全自由流动
- **代价**：美元汇率自由浮动（2008 来美元指数 70-115 波动）

**美国的特殊地位**：美国是"储备货币发行国"——它不需要囤积外汇储备（自己的货币就是储备）。这给了美国独特的**"嚣张的特权"**（Exorbitant Privilege，Valéry Giscard d'Estaing）。

#### 角 3：中国——货币独立 + 资本管制，有管理浮动

> 详见 [`china-financial-system.md`](./china-financial-system.md) §五。

```
✓ 货币政策独立（央行自主降息/降准）
✗ 资本管制（QFII/QDII/换汇限制/额度管理）
~ 有管理浮动汇率（中间价 + 逆周期因子）
```

**中国选择的逻辑**（1997 危机的教训）：
- 亚洲危机让中国看到：**固定汇率 + 资本自由 = 把脖子伸给投机者**
- 所以中国选择**资本管制**——保住货币政策独立性（服务国内经济目标），同时给汇率干预留空间
- **代价**：资本管制限制了人民币国际化（详见 §十）

### 4.4 中间汇率制度——"害怕浮动"

现实中很多国家不在三个角，而在**边上**（中间汇率制度）。Calvo & Reinhart（2002）称之为**"害怕浮动"**（Fear of Floating）：

- 名义上"浮动"，实际上频繁干预
- 原因：汇率波动损害贸易（美元计价的债务）、引发通胀（本币贬值推高进口价格）、政治压力

> **essence 连接**：这与 [`china-financial-system.md`](./china-financial-system.md) 的"鸟笼经济"一致——很多国家嘴上说"市场决定汇率"，实际上汇率也在"笼子"里飞。

## 五、货币危机模型三代演进

> 货币危机理论是国际金融最精彩的篇章——它把抽象的汇率理论与真金白银的灾难联系起来。三代模型代表了理解危机的三次认知升级。

### 5.1 第一代模型（Krugman 1979 / Flood-Garber 1984）

#### 核心机制：财政赤字 → 储备耗尽 → 投机攻击

```
政府财政赤字 → 央行印钞弥补（货币化）
  → 货币超发 → 购买力下降 → 固定汇率不可维持
  → 央行用外汇储备"硬扛"贬值压力
  → 储备线性下降 → 某时刻储备耗尽 → 固定汇率崩溃
```

**Krugman 的关键洞见——"影子汇率"**：即使储备没耗尽，投机者也会**提前**攻击。因为存在一个"影子汇率"（没有干预时的均衡汇率），当影子汇率超过固定汇率时，攻击就能获利。

#### 代码层：储备耗尽与投机攻击时刻

```python
# 【已验证·bash 可跑】第一代危机模型数值演示
import numpy as np
T = np.arange(0, 80)
reserve0, credit_growth = 40.0, 0.5   # 初始储备40, 每期信用扩张0.5
reserve = np.maximum(reserve0 - credit_growth * T, 0)
theoretical_crash = reserve0 / credit_growth  # 理论耗尽时刻
shadow_crash = theoretical_crash * 0.7        # 投机攻击时刻(影子汇率>固定汇率)
print(f"初始储备 {reserve0}, 每期信用扩张 {credit_growth}")
print(f"理论储备耗尽时刻 T = {theoretical_crash:.0f}")
print(f"投机攻击时刻 T* ≈ {shadow_crash:.0f} (早于理论耗尽)")
print("→ 投机者在储备归零前就攻击：影子汇率已超过固定汇率，攻击立即获利")
```

**输出**：
```
理论储备耗尽时刻 T = 80
投机攻击时刻 T* ≈ 56 (早于理论耗尽)
```

**代表案例**：
- **1970s 拉美**（墨西哥 1976、阿根廷 1980s）——财政赤字货币化 → 储备耗尽 → 货币崩溃
- **1992 英镑**（部分符合）——德国统一后加息，英国为维持汇率耗储备，最终退出 ERM（"黑色星期三"，索罗斯赚 10 亿美元）

### 5.2 第二代模型（Obstfeld 1994, 1996）

#### 核心机制：多重均衡 + 自我实现的危机

**突破点**：第一代模型假设政府是"被动的"（机械地印钞）。Obstfeld 说——**政府是理性的，会权衡维持汇率的成本与放弃的成本**。这就引入了**多重均衡**。

```
维持固定汇率的成本:
  高利率 → 经济衰退 → 失业 → 政治压力
  
放弃固定汇率的成本:
  信誉损失 → 未来融资成本上升 → 通胀预期

关键: 这两个成本取决于"市场预期"
  - 如果市场相信你能维持 → 没有攻击 → 维持成本低 → 真能维持 (好均衡)
  - 如果市场不相信 → 投机攻击 → 维持成本飙升 → 你被迫放弃 (坏均衡)
       ↓
  = 自我实现的预言 (Self-fulfilling prophecy)
```

#### ERM 危机（1992-93）——第二代模型的经典案例

1992 年，德国因统一后通胀压力而加息。英国、意大利等 ERM 成员国被迫跟随加息（维持固定汇率），但它们经济疲软，高利率雪上加霜。投机者判断"政府最终扛不住"，发动攻击——政府被迫加息捍卫 → 经济更糟 → 最终放弃。**预期变成了现实**。

> **essence 连接**：多重均衡是 [`06-systems/complexity/`](../../06-systems/complexity.md) 的核心概念——系统有多个稳定状态，"哪一个被选中"取决于**信念的协调**。货币危机中的"信念协调"由对冲基金（索罗斯）和羊群效应完成。

### 5.3 第三代模型（1997 亚洲危机后）

#### 突破点：企业资产负债表效应

1997 亚洲危机**无法用前两代模型解释**——亚洲国家财政基本平衡、通胀低、储备充足。危机的根源不在政府，而在**企业和银行的资产负债表**。

**三个关键机制**：

**机制 A：货币错配（Currency Mismatch / 原罪）**
```
亚洲企业借美元债（利率低），收入是本币
  → 本币贬值 → 美元债的本币价值飙升 → 企业资产负债表恶化
  → 破产 → 银行坏账 → 资本外逃 → 本币更贬值 (正反馈)
```

**机制 B：期限错配（Maturity Mismatch）**
```
银行借短期美元（"热钱"），贷长期本币（基建/房地产）
  → 外资突然撤离 → 银行无法展期 → 流动性危机
```

**机制 C：道德风险（Moral Hazard / Crony Capitalism）**
```
政府隐性担保（"不会让大企业倒闭"）
  → 企业过度借债 → 银行过度放贷
  → 风险被低估 → 泡沫 → 泡沫破裂 → 危机
```

**Krugman（1999）的"资产负债表通道"**：本币贬值 → 企业净值下降（美元债）→ 信贷收缩 → 投资下降 → 经济衰退 → 资本外逃 → 进一步贬值。这是**金融加速器**（Financial Accelerator, Bernanke-Gertler-Gilchrist）的国际版。

#### 三代模型对比

| | 第一代 (Krugman 1979) | 第二代 (Obstfeld 1994) | 第三代 (1997 后) |
|---|---|---|---|
| **危机根源** | 财政赤字 | 市场预期（多重均衡） | 资产负债表错配 |
| **政府角色** | 被动印钞 | 理性权衡 | 隐性担保/道德风险 |
| **关键变量** | 外汇储备 | 预期协调 | 企业美元债/银行期限错配 |
| **代表案例** | 拉美(1970-80s) | ERM(1992) | 亚洲(1997) |
| **可预测性** | 较高（储备下降可见） | 低（取决于预期） | 中（资产负债表可观测） |

### 5.4 传染（Contagion）——危机的传播

1997 危机的另一个特征：**传染**。泰国危机 → 马来西亚 → 印尼 → 韩国 → 甚至波及巴西、俄罗斯（1998）。危机像病毒一样跨国传播。

**传染的渠道**：
1. **贸易渠道**——竞争性贬值（你贬值，我也得贬值才能保持出口竞争力）
2. **金融渠道**——跨国银行抽贷、共同债权人（日本银行从所有亚洲国家撤资）
3. **预期/羊群渠道**——投资者"重新评估"相似国家的风险

> **essence 连接**：传染是 [`06-systems/complexity/`](../../06-systems/complexity.md) 的**级联失效**——网络中一个节点失效，通过连接传导到整个网络。金融全球化让各国成为耦合节点，危机因此具有系统性。

## 六、资本流动与资本管制

### 资本流入的益处

```
资本流入的好处:
  ├── 补充储蓄缺口 → 投资大于储蓄的发展中国家需要外资
  ├── 技术转移 → FDI 带来技术和管理
  ├── 分散风险 → 国际投资组合分散化
  └── 倒逼改革 → 融入国际市场推动制度改进
```

### 资本流入的风险

```
资本流入的风险:
  ├── 货币升值 → "荷兰病"（出口竞争力下降）
  ├── 信贷泡沫 → 资本流入 → 银行扩张信贷 → 资产泡沫
  ├── 期限错配 → 短期热钱涌入，随时可能撤离
  ├── 货币错配 → 借外币债，贬值时爆发
  └── 突然停止 (Sudden Stop) → 资本流入戛然而止 → 危机
```

**Calvo 的"突然停止"理论**：资本流入的逆转是断崖式的，不是渐进的。一旦国际投资者恐慌，资金会在几周内撤离数十亿——远快于经常账户的调整速度。

### IMF 态度的转变——从自由化到管控

```
1990s: IMF 推动资本账户自由化 (华盛顿共识)
       → "资本自由流动像自由贸易一样好"
       ↓
1997 亚洲危机: 自由化的恶果显现
       → 资本自由流入制造了危机
       ↓
2010s: IMF 转变立场 (Ostry et al. 2010-2012)
       → "在某些情况下，资本管制是合理的宏观审慎工具"
       ↓
2020s: IMF "综合政策框架" (Integrated Policy Framework)
       → 正式承认资本流动管理(CFM)作为正当工具
```

> **essence 洞察**：IMF 的转变是一个**范式转移**——从"市场总是对的"（华盛顿共识）到"市场有系统性失灵"（后危机共识）。这与 [`financial-history.md`](./financial-history.md) 中 2008 危机后的反思一脉相承。

### 资本管制的工具谱

| 工具 | 机制 | 国家 |
|------|------|------|
| **数量限制** | QFII/QDII 额度 | 中国 |
| **托宾税** | 对短期资本流动征税 | 智利(1990s)、巴西 |
| **无息准备金** | 存入央行无息存款 | 智利、哥伦比亚 |
| **外汇头寸限制** | 限制银行外汇敞口 | 多国 |
| **行政审批** | 逐笔审批大额流出 | 中国、印度 |

## 七、美元霸权与国际货币体系

### 7.1 国际货币体系演变

```
金本位 (1870-1914)
  └── 汇率由黄金含量决定，固定
  └── 代价: 国内货币政策服从外部平衡

两次大战间 (1914-1944)
  └── 金本位崩溃 → 竞争性贬值 → 大萧条恶化

布雷顿森林体系 (1944-1971)
  └── 美元与黄金挂钩($35/盎司), 各国货币与美元挂钩
  └── IMF + 世界银行成立
  └── 设计者: Harry Dexter White (美国) vs John Maynard Keynes (英国)
  └── Keynes 的"Bancor"超主权货币方案被否决 → 美元霸权确立

牙买加体系 (1976 至今)
  └── 黄金非货币化, 浮动汇率合法化
  └── 主要货币浮动, 美元仍是核心储备货币
  └── 无体系的体系 (非体系, nonsystem)
```

### 7.2 特里芬难题（Triffin Dilemma, 1960）

> **Robert Triffin 的预言（1960，比布雷顿森林崩溃早 11 年）**：

**核心矛盾**：美元作为世界储备货币，面临一个不可能的两难：

```
世界需要美元流动性 → 美国必须持续逆差(输出美元)
  → 美国逆差越大 → 全球对美元的信心越弱
  → 信心崩溃 → 各国拿美元换黄金 → 储备体系崩溃
       ↓
= 提供流动性 = 削弱信心 (根本矛盾)
```

**1971 验证**：法国（戴高乐）等国开始拿美元换黄金 → 美国黄金流失 → 尼克松关闭黄金窗口（"尼克松冲击"）→ 布雷顿森林崩溃。**特里芬难题精准应验**。

> **essence 连接**：特里芬难题是**结构性悖论**——与 [`06-systems/feedback/`](../../06-systems/feedback.md) 的正反馈崩溃同构。它至今未被解决——美元仍是核心储备货币，美国仍在持续逆差，只是"黄金约束"被"信用约束"替代。

### 7.3 美元霸权的支柱

即使布雷顿森林崩溃，美元仍是核心储备货币（约 60% 全球外汇储备）。原因——**网络效应**：

```
美元霸权的自我强化:
  美元是核心 → 贸易用美元计价(石油/大宗商品)
  → 各国需要美元储备 → 买美国国债
  → 美国享受低利率(超额需求) → "嚣张的特权"
  → 美国军事/金融实力背书 → 美元更核心
       ↓
  = 正反馈循环 → 锁定效应
```

**"嚣张的特权"**（Exorbitant Privilege）：
1. **铸币税**——美国用纸换真实商品
2. **低借贷成本**——全球对美元资产的需求压低美国利率
3. **金融制裁权力**——控制 SWIFT/CHIPS，可冻结他国资产（如 2022 俄罗斯）

### 7.4 去美元化趋势与人民币国际化

**去美元化的动因**（2010s 加速）：
1. **美国武器化美元**——制裁俄罗斯/伊朗让各国警觉
2. **美国债务膨胀**——36 万亿国债，可持续性存疑
3. **多极化**——新兴市场GDP占比上升，要求货币话语权

**去美元化的工具**：
```
手段                              主导方
├── 双边本币结算                  中俄/中沙/印度卢比结算
├── 央行数字货币 (CBDC) 桥        mBridge 项目(数字货币跨境)
├── 增持黄金                      全球央行创纪录购金(2022-24)
├── 发展本币债券市场               亚洲债券倡议
└── 金砖国家支付系统              BRICS Pay 探索
```

**人民币国际化的现状与瓶颈**（详见 [`china-financial-system.md`](./china-financial-system.md) §五）：
```
SDR 篮子: 美元 41.7% > 欧元 30.9% > 人民币 ~12.3% (2022调整)
全球支付: 美元 ~47% > 欧元 ~23% > 人民币 ~4.5% (2024)
全球储备: 美元 ~58% > 欧元 ~20% > 人民币 ~2.3%
```

> **essence 立场**：去美元化是**长期趋势**，但短期内美元霸权的网络效应极难打破。货币转换的"临界质量"（critical mass）很高——除非出现系统性替代（如可信的 CBDC 国际体系），否则美元地位将持续数十年。这是 [`06-systems/complexity/`](../../06-systems/complexity.md) 的"路径依赖/锁定"在货币领域的体现。

## 八、主权财富基金与外汇储备管理

### 为什么囤积外汇储备？

1997 亚洲危机后，亚洲国家学到一个血淋淋的教训：**自己的储备才是真保险**。

```
外汇储备的功能:
  ├── 干预外汇市场 (维持汇率稳定)
  ├── 支付进口/外债 (流动性缓冲)
  ├── 市场信心信号 (储备充足 → 投机者不敢攻击)
  └── 自我保险 (self-insurance) ← 1997 后的核心动机
```

**自我保险悖论**：发展中国家把辛苦赚的出口收入，以低收益（美国国债 ~2%）借给美国，美国再以高回报投资回去。这是**穷国补贴富国**的全球失衡。

### 主权财富基金（SWF）

当储备超过"保险需求"，国家设立**主权财富基金**追求更高回报：

| SWF | 国家 | 规模 | 类型 |
|-----|------|------|------|
| 挪威政府养老基金 | 挪威 | ~$1.5万亿 | 石油收入型(模范) |
| ADIA | 阿联酋 | ~$1.0万亿 | 石油收入型 |
| GIC + 淡马锡 | 新加坡 | ~$0.8万亿 | 多元化 |
| CIC (中投) | 中国 | ~$1.3万亿(含) | 外汇储备型 |
| KIA | 科威特 | ~$0.8万亿 | 石油收入型 |

**挪威的典范**：把石油收入全部存入基金，只投资海外，**不动用本金**（只花回报）——"把石油变成金融资产，留给后代"。这是代际正义的金融实践（见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md)）。

### 储备管理——安全性 vs 收益性

```
储备管理的"不可能三角":
  安全性 (不能亏) ── 流动性 (随时能用) ── 收益性 (要赚回报)
  
传统做法: 安全+流动 > 收益 (买美国国债)
SWF 做法: 牺牲部分流动性 → 追求收益 (买股票/另类资产)
```

## 九、货币危机案例深度

### 9.1 1997 亚洲金融危机——三元悖论的祭品

> 详见 [`financial-history.md`](./financial-history.md) §3.5。这里从国际金融理论视角重审。

**背景**：
```
"亚洲奇迹" → 泰国/韩国/印尼/马来西亚高速增长
  ├── 固定汇率(盯住美元) → 汇率稳定 → 降低风险
  ├── 资本账户开放 → 国际资本涌入
  └── 银行借低息美元 → 贷本币(房地产/基建)
       ↓
  = 三元悖论的"坏角": 固定汇率 + 资本自由, 牺牲货币独立
```

**触发与传导**：
```
1995 美元走强 → 亚洲货币(盯住美元)跟着升值 → 出口竞争力下降
  → 经常账户恶化
  → 投机者(索罗斯等)判断固定汇率不可维持
  ↓
1997.7 泰国放弃固定汇率 → 泰铢暴跌(-50%+)
  → 传染: 马来西亚/印尼/韩国相继贬值
  → 企业美元债爆炸 → 破产潮 → 银行坏账
  → 资本恐慌外逃 → 进一步贬值 (正反馈)
  ↓
  IMF 救助(条件: 紧缩财政+加息) → 被批评加剧衰退
```

**第三代模型的完美案例**：
- **货币错配**：企业借美元债，本币贬值 → 破产 ✓
- **期限错配**：银行借短贷长 → 流动性危机 ✓
- **道德风险**：政府隐性担保 → 过度借债 ✓
- **传染**：泰国 → 全亚洲 → 俄罗斯/巴西 ✓

> **对中国的塑造**：1997 后，中国（朱镕基）做了两个关键决定——①坚持人民币不贬值（承担地区责任，赢得信誉）；②此后疯狂积累外汇储备（从 2000 年的 1655 亿到 2014 年的近 4 万亿）。**中国的整个外汇管理体制，是 1997 教训的制度化**（见 [`china-financial-system.md`](./china-financial-system.md)）。

### 9.2 阿根廷——百年沉沦的货币版

**阿根廷的货币局制度（Convertibility Plan, 1991-2001）**：
- 1 比索 = 1 美元（严格货币局，比香港更死板）
- 成功遏制了 1989 年的恶性通胀（5000%）
- **代价**：完全丧失货币政策独立性 + 汇率高估 → 出口崩溃 → 衰退 → 债务危机

```
2001 崩溃:
  经济衰退 → 无法贬值(货币局) → 无法降息(盯美元)
  → 债务不可持续 → 违约 → 挤兑 → 冻结存款(el corralito)
  → 比索贬值到 1:4 → 中产阶级储蓄蒸发 → 社会暴动
```

**反复危机（2001/2014/2018-19/2023-24）**：阿根廷此后陷入"危机-IMF救助-再危机"循环，成为"新兴市场永远的危险案例"。

**教训**：
1. 货币局/严格固定汇率是"不可逆"的——退出代价巨大
2. 没有财政纪律，任何汇率制度都救不了你
3. **三元悖论的极端选择**——放弃货币独立 = 把命运交给别人

### 9.3 土耳其——非正统货币政策的代价

**埃尔多安的"非正统"实验（2018-2023）**：
```
埃尔多安的"奇怪理论": 高利率 = 高通胀 (与主流相反)
  → 强迫央行在高通胀时降息
  → 通胀飙升(2022 峰值 ~85%)
  → 里拉暴跌 (2018-22 累计贬值 ~90%)
  → 央行动用外汇储备干预 → 储备耗尽
  → 资本管制萌芽 (要求出口商结汇)
       ↓
  = 第一代模型(财政/货币扩张) + 第三代模型(企业美元债)的叠加
```

**2023 后转向**：任命正统经济团队（Şimşek/Erkan）→ 大幅加息 → 汇率暂时企稳。但通胀惯性仍强，信誉重建需要数年。

> **essence 洞察**：土耳其案例证明——**政治干预货币政策 = 三元悖论中主动放弃"货币独立性"的实质**。即使名义上有央行，只要政治凌驾，货币独立就是假的。

## 十、中国的国际金融

> 这一节是 [`china-financial-system.md`](./china-financial-system.md) §五 的国际金融延伸。

### 10.1 人民币汇率机制演变

```
1949-1994   多重汇率 / 外汇调剂市场 / 双轨制
1994        汇率并轨 → 事实上盯住美元(~8.28, 持续10年)
2005        7.21汇改 → 参考一篮子货币 → 有管理浮动(升值开始)
2015        "811汇改" → 中间价报价改革 → 市场化方向(引发贬值预期)
2020-至今    "有管理的浮动" → 逆周期因子 + 宏观审慎
```

**811 汇改的教训**：原本想"让市场决定"，结果触发贬值预期 → 资本外流 → 外汇储备从 4 万亿降到 3 万亿（消耗近 1 万亿干预）→ 不得不加强资本管制。**市场化改革在信心脆弱时会自我挫败**。

### 10.2 资本账户开放——走两步退一步

```
开放的:
  ✓ FDI (外商直接投资) —— 基本可兑换
  ✓ 贸易信贷 —— 基本开放
  ✓ QFII/RQFII —— 证券投资(额度逐步扩大)
  ✓ 沪深港通/债券通 —— 互联互通机制

管制的:
  ✗ 居民换汇 —— 5万美元/年额度
  ✗ 资本流出 —— 投资/并购审查严格
  ✗ 衍生品 —— 严格限制
  ✗ 个人境外购房 —— 实质禁止
```

**开放的悖论**：资本账户开放有利于人民币国际化，但开放后资本外流压力加大 → 贬值 → 需要管制 → 阻碍国际化。这是中国金融的**核心张力**。

### 10.3 人民币国际化——三步走的现状

> 引用 [`china-financial-system.md`](./china-financial-system.md) §五：

```
Step 1: 贸易结算货币 ← 部分实现 (跨境人民币结算 ~25% 中外贸易)
Step 2: 投资货币    ← 进行中 (RQFII/债券通/CIPS清算系统)
Step 3: 储备货币    ← 起步阶段 (IMF SDR ~12%, 全球储备 ~2-3%)

瓶颈:
  - 资本管制 vs 国际化的根本矛盾
  - 缺乏深度/流动性的安全资产(国债市场不够)
  - 美元网络效应 → 转换成本极高
  - 法治/制度可信度 → 外国人是否敢长期持有?
```

**"石油人民币"的新动向**：2023 沙特与中国探讨用人民币结算石油。如果成真，这是对"石油美元"体系的重大挑战。但规模和机制仍在探索中。

### 10.4 中国的外汇储备管理

```
规模: ~$3.2万亿 (2024, 全球第一)
构成: 主要是美国国债 + 部分欧元/日元资产 + 黄金(~2200吨)
管理: 国家外汇管理局(SAFE) + 中投公司(CIC, 追求收益的部分)

战略转变:
  - 缓慢多元化(增持黄金/非美元资产)
  - 但大规模抛售美债 = 自杀(自己资产贬值 + 美国报复)
  - "渐进、低调"的去美元化
```

> **essence 立场**：中国的国际金融策略是**"防御性现实主义"**——保住既得利益（储备不缩水）、缓慢降低风险（多元化）、不主动挑战（避免摩擦）。这与 [`china-financial-system.md`](./china-financial-system.md) 的"鸟笼经济"一脉相承。

import numpy as np
reserve0, growth = 40.0, 0.5
T = np.arange(0, 90)
reserve = np.maximum(reserve0 - growth * T, 0)
theoretical = reserve0 / growth
shadow_attack = theoretical * 0.7

## 十二、跨学科映射

| 国际金融概念 | 对应学科 | 映射逻辑 |
|------------|---------|---------|
| **汇率超调（Dornbusch）** | 控制论/系统动力学 | 快变量+慢变量+耦合=振荡超调（欠阻尼响应） |
| **三元悖论** | 博弈论/优化 | 三目标函数，最多实现两个——Pareto 前沿 |
| **货币危机多重均衡** | 复杂系统/博弈论 | 协调博弈——信念决定均衡，多个稳定态 |
| **传染** | 网络科学/流行病学 | 级联失效——节点失效通过连接传导 |
| **美元霸权网络效应** | 复杂系统 | 路径依赖/锁定效应——临界质量极难达到 |
| **特里芬难题** | 系统悖论 | 正反馈崩溃——提供流动性削弱信心 |
| **套利交易** | 概率论/风险 | 在压路机前捡硬币——偏态收益（长期小赚，偶尔巨亏） |
| **不可能三角** | 热力学类比 | 类似"不可能同时达到三个极值"的约束（非严格同构） |
| **Mundell 最优货币区** | 复杂系统 | 相变——满足条件(劳动力流动/冲击对称)则货币区"稳定" |
| **资本管制** | 信息论 | 信号过滤——管制筛选"热钱"(噪声) vs FDI(信号) |

### 与 essence 项目的深度连接

- **时间**：汇率是"两国相对时间价值"的价格——贴现率差的体现
- **不确定性**：汇率预测失败 = 认识论限制（未来信息不可预测），见 [`risk-and-uncertainty.md`](./risk-and-uncertainty.md)
- **反馈**：货币危机是**正反馈崩溃**的经典（贬值→破产→更贬值），见 [`06-systems/feedback/`](../../06-systems/feedback.md)
- **涌现**：汇率是群体预期的涌现均衡，没有"本质价值"，见 [`markets-and-pricing.md`](./markets-and-pricing.md)
- **信用 = 信任**：美元霸权的底层是**对美国制度的信任**；信任崩塌 = 霸权崩塌，见 [`money-and-credit.md`](./money-and-credit.md)

## 十三、开放问题

- [ ] **PPP 长期成立吗？** 短期严重偏离已确认，但"5-10 年趋同"的共识是否经受住更多数据检验？人民币的"低估"有多少是 Balassa-Samuelson 结构性因素？
- [ ] **UIRP 为什么系统性失败？** 远期偏差之谜的根源——风险溢价？行为偏差（投资者低估尾部风险）？还是模型设定错误？
- [ ] **三元悖论是否真的"不可能"？** 宏观审慎工具 + 资本流动管理能否部分"突破"不可能三角？IMF 综合政策框架的新证据。
- [ ] **货币危机能否预测？** 三代模型各自解释了"一类"危机，但 2008（全球性）、2020（疫情）是否需要"第四代"？
- [ ] **去美元化能否成功？** 网络效应极强，但地缘政治（制裁）正在创造"强制去美元化"。临界点在哪？
- [ ] **人民币能成为真正的国际货币吗？** 资本管制 vs 国际化的根本矛盾能否解开？CBDC（数字人民币/mBridge）是否是突破口？
- [ ] **CBDC 如何重塑国际金融？** 央行数字货币跨境（mBridge）可能绕过 SWIFT——这是国际货币体系的范式转移吗？
- [ ] **特里芬难题在牙买加体系下是否仍成立？** 黄金约束消失了，但"信用约束"替代——美国债务上限危机是否是新版的特里芬难题？
- [ ] **中国 3 万亿外汇储备的"机会成本"有多大？** 穷国低收益借给富国的全球失衡，能否通过 SDR/超主权货币解决？
