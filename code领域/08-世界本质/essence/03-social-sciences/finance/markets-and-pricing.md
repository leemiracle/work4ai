## 引言：一个问题，三种回答

价格是什么？一个数字。但这个数字从哪里来？

- 新古典经济学家说：**供需曲线相交的那个点**。
- 有效市场论者说：**所有信息汇聚后的共识**。
- 行为金融学家说：**一群有偏见的人互相博弈的结果**。

这三派不是同一场辩论的甲方乙方——它们在问**不同的问题**：

| 流派 | 真正回答的问题 | 数学骨架 | 哲学立场 |
|------|--------------|---------|---------|
| 均衡定价 | "价格停在哪里？" | 供需相等 → $Q_d(p^*)=Q_s(p^*)$ | 价值是关系属性 |
| 信息定价 | "价格知道多少？" | $p_t = E_t[\text{未来现金流}\mid\mathcal{F}_t]$ | 价格是认知装置 |
| 行为定价 | "是谁在定价？" | 非理性偏差驱动偏差定价 | 价格是群体心理的投影 |

> **essence 立场**：价格不是一个数——它是**一个坐标 $(p_{\text{均衡}}, p_{\text{信息}}, p_{\text{心理}})$**。三者通常接近，偶尔分裂，分裂处就是套利与危机的源头。

## 一、价格理论的三大流派

### 流派 A · 均衡定价（新古典）

**核心思想**：价格是供给 $Q_s(p)$ 和需求 $Q_d(p)$ 的均衡解。均衡 = **没有力量推动改变**的状态。

$$Q_d(p^*) = Q_s(p^*) \quad\Longleftrightarrow\quad \text{一阶导为零}$$

这是**力学均衡的经济学移植**——物体静止当且仅当合力为零。Walras 把牛顿搬进了经济学。

**优点**：直观、可计算、可画出供需图。  
**致命缺陷**：它假设供需是**外生给定**的——但真实市场中，供给和需求本身就是价格、预期、信贷的函数。**循环依赖**。

### 流派 B · 信息定价（Hayek → EMH）

**核心思想**：价格不是供需"机械相交"的结果，而是**分布式信息处理的输出**。每个交易者只懂一小片世界，但他们下单，价格就"聚合"了所有人的信息。

> Hayek（1945，《知识在社会中的运用》）：价格体系是"一种记录变化的通讯机制"——比任何中央计划者都更高效地聚合分散知识。

Fama（1970）把它形式化为**有效市场假说（EMH）**：

$$p_t = E_t[p_{t+1}^*] \;\Rightarrow\; \text{价格是未来"真实价值"的最优预测（给定信息集）}$$

**优点**：解释了为什么价格**难以预测**——可预测的部分已经被套利掉了。  
**致命缺陷**：Grossman-Stiglitz 悖论（见 §三）——如果价格已完美反映信息，没人会花成本搜集信息，价格就不可能完美反映信息。

### 流派 C · 行为定价（Kahneman-Tversky → Shiller）

**核心思想**：定价的是**人**，而人系统性地偏离理性。价格反映的不是"信息"，而是"**被认知偏差扭曲后的信息**"。

关键偏差（详见 [`behavioral-finance.md`](./behavioral-finance.md)）：
- **损失厌恶**：亏 100 元的痛苦 > 赚 100 元的快乐（前景理论，价值函数在损失侧更陡）。
- **锚定**：价格被历史高点/整数关口锚住。
- **羊群效应**：买入决策传染，制造动量和泡沫。

Shiller（1981）用方差不等式证明：**股价波动远超基本面（股息）能解释的范围**——市场"过度波动"是行为偏差的直接证据。

**优点**：解释了均衡派和信息派解释不了的"异象"。  
**致命缺陷**：**有限套利**——即使价格错了，纠正它可能需要数年，而套利者可能等不到那一天（"市场保持非理性的时间比你保持偿付能力的时间长"——凯恩斯/一句）。

## 二、资产定价的核心模型

> **方法论**：每个模型走三层——**直觉（为什么需要它）→ 数学（核心公式与假设）→ 代码（用 Python 跑出数字）**。不跑代码的金融直觉，是"幻觉式理解"。

### 模型 1 · 现值与贴现（Present Value）

**直觉层 · 为什么今天的钱更值钱**

> 给你两个选择：今天拿 100 元，或一年后拿 100 元。你一定选今天。  
> 为什么？因为今天的 100 元可以存银行变 105 元，或投资变 110 元，或立刻消费获得效用。**钱有时间的机会成本**——这就是"时间价值"。

一切资产定价的起点：**一个资产的价值 = 它未来所有现金流的现值之和**。

**数学层**

离散贴现：

$$PV = \sum_{n=1}^{N} \frac{CF_n}{(1+r)^n}$$

连续贴现（当现金流连续发生时）：

$$PV = \int_0^T CF(t)\,e^{-rt}\,dt$$

- $r$ = 贴现率（包含无风险利率 + 风险溢价 + 机会成本）
- **贴现率的哲学含义**：它回答"未来相对于现在，对我有多重要？" —— 这本质是个伦理学问题（见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 极限 4：代际正义）。

**代码层**

```python
import math

def pv_discrete(cf, r, n):
    """单笔现金流 n 期后的现值"""
    return cf / ((1 + r) ** n)

def pv_continuous(cf, r, t):
    """连续贴现下的现值"""
    return cf * math.exp(-r * t)

def perpetuity(c, r):
    """永续年金：每年付 c，永远付下去"""
    return c / r  # 推导：sum_{n=1}^∞ c/(1+r)^n = c/r

# --- 跑出结果 ---
print("PV(1000, 5%, 10年)         =", round(pv_discrete(1000, 0.05, 10), 2))
print("PV(连续贴现 1000, 5%, 10年) =", round(pv_continuous(1000, 0.05, 10), 2))
print("永续年金(年付100, r=5%)    =", round(perpetuity(100, 0.05), 2))
```

预期输出：
```
PV(1000, 5%, 10年)         = 613.91
PV(连续贴现 1000, 5%, 10年) = 606.53
永续年金(年付100, r=5%)    = 2000.0
```

> **洞察**：同一笔 1000 元，贴现率从 5% 升到 10%，现值从 614 跌到 386——**贴现率才是定价的真正杠杆**。这也是为什么央行加息，所有资产（股、债、房）的估值都会杀跌。

### 模型 2 · CAPM（资本资产定价模型）

**直觉层 · 风险有两种，只有一种有补偿**

> 站在雨里，你能做两件事：带伞（消除非系统性风险——淋雨），或接受会淋湿（系统性风险——天气不好）。市场只为"天气不好"付钱，不为"忘带伞"付钱——因为你可以带伞。

Sharpe（1964）的核心洞见：**风险分解为两部分**——

- **系统性风险（市场风险）**：整个市场都跌，无法分散——**有补偿**。
- **非系统性风险（公司特有风险）**：可以靠分散投资消除——**无补偿**。

只有系统性风险（用 β 衡量）应该获得风险溢价。

**数学层**

$$E(R_i) = R_f + \beta_i\bigl(E(R_m) - R_f\bigr)$$

- $R_f$ = 无风险利率
- $E(R_m) - R_f$ = 市场风险溢价
- $\beta_i = \dfrac{\text{Cov}(R_i, R_m)}{\text{Var}(R_m)}$ = 资产 i 对市场风险的暴露

**推导主线**：Markowitz 均值-方差 → 引入无风险资产 → 所有理性投资者持有"无风险 + 市场组合"的组合 → 市场均衡时，**任何资产必须落在一条直线（证券市场线 SML）上**，否则被套利。这条直线的斜率就是市场风险溢价。

**代码层 · 计算股票的 β**

```python
import numpy as np

rng = np.random.default_rng(42)
n = 252  # 一年的交易日
market_returns = rng.normal(0.0004, 0.01, n)  # 模拟市场日收益

# 股票收益 = α + β*市场 + 公司特有噪声（真实 β=1.3）
true_beta = 1.3
stock_returns = 0.0002 + true_beta * market_returns + rng.normal(0, 0.015, n)

# β = Cov(Ri, Rm) / Var(Rm)
cov = np.cov(stock_returns, market_returns, ddof=1)[0, 1]
var = np.var(market_returns, ddof=1)
beta = cov / var

# CAPM 预期收益
Rf, Rm = 0.03, 0.10  # 年化：无风险 3%，市场 10%
ER = Rf + beta * (Rm - Rf)

print(f"真实 β = {true_beta}, 估计 β = {beta:.4f}")
print(f"CAPM E(R) = {Rf} + {beta:.3f}*({Rm}-{Rf}) = {ER:.4f}  (年化)")
```

预期输出：
```
真实 β = 1.3, 估计 β = 1.2942
CAPM E(R) = 0.03 + 1.294*(0.1-0.03) = 0.1206  (年化)
```

> **洞察**：β=1.3 的股票比市场更波动，理应要求 12% 的回报。如果市场只给它 9%——它被高估了（落在 SML 下方）；如果给它 15%——它被低估了。**CAPM 把"风险定价"变成了一条可计算的直线**。

**CAPM 的局限**：实证中单因子解释力不足——这就是 Fama-French 要加因子（见下）。

### 模型 3 · Black-Scholes-Merton 期权定价

**直觉层 · 期权就是保险**

> 你买房后会买火灾保险——付一笔保费，万一着火就获赔。  
> 期权同理：**看跌期权是"股价下跌的保险"**，**看涨期权是"锁定买入价格的入场券"**。期权定价 = 给这份保险标价。

Black-Scholes-Merton（1973）的革命性洞见：**你不需要预测股价涨跌**——只要你假设股价服从几何布朗运动，就可以用"构造一个无风险对冲组合"来反推出期权的唯一合理价格。**涨跌方向不重要，波动率才重要**。

**数学层**

看涨期权价格：

$$C = S\,N(d_1) - K e^{-rT} N(d_2)$$

$$d_1 = \frac{\ln(S/K) + (r + \tfrac{1}{2}\sigma^2)T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T}$$

- $S$ = 当前股价，$K$ = 行权价，$T$ = 到期时间，$r$ = 无风险利率，$\sigma$ = 波动率
- $N(\cdot)$ = 标准正态分布的累积分布函数

**无套利推导思路**（关键，不只是背公式）：
1. 假设股价 $dS = \mu S\,dt + \sigma S\,dW$（几何布朗运动）
2. 构造组合 $\Pi = V - \frac{\partial V}{\partial S}S$（卖空 $\Delta$ 份股票对冲）
3. 选 $\Delta$ 消除随机项 → 组合变为无风险
4. 无套利 → 组合收益必须等于 $r\Pi\,dt$
5. 得到 **Black-Scholes PDE**：$\frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0$
6. 代入边界条件（到期时 $C=\max(S-K,0)$）解出公式。

> **哲学意义**：这里**漂移率 $\mu$（涨跌方向）消失了**——只留下波动率 $\sigma$。这是金融学最美的反直觉结论之一：**保险的价格不取决于你会不会出事，而取决于出事的"波动幅度"**。

**代码层**

```python
import math

def norm_cdf(x):
    """标准正态累积分布函数（用 erf 实现，无需 scipy）"""
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))

def bsm_call(S, K, T, r, sigma):
    """Black-Scholes-Merton 看涨期权价格"""
    d1 = (math.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * math.sqrt(T))
    d2 = d1 - sigma * math.sqrt(T)
    return S * norm_cdf(d1) - K * math.exp(-r * T) * norm_cdf(d2)

# S=100 股价, K=100 行权价, T=1年, r=5%, σ=20%
price = bsm_call(S=100, K=100, T=1.0, r=0.05, sigma=0.20)
print(f"BSM 看涨期权价格 = {price:.4f}")
```

预期输出：
```
BSM 看涨期权价格 = 10.4506
```

> **验证**：平值期权（$S=K$）、1 年、20% 波动的看涨期权约值 10.45 元——约占标的价格的 10.5%，符合经验直觉（保险费通常是个位数到十几个百分点）。

### 模型 4 · Fama-French 三因子

**为什么需要它**：CAPM 只用"市场"一个因子，但实证发现——**小盘股**平均跑赢大盘股（**规模效应**，SMB），**低估值的股票**（高账面市值比）跑赢高估值股票（**价值效应**，HML）。CAPM 解释不了，于是加因子。

$$E(R_i) - R_f = \beta_i^{M}(R_m-R_f) + \beta_i^{S}\,\text{SMB} + \beta_i^{V}\,\text{HML}$$

- **SMB**（Small Minus Big）：小盘组合收益 − 大盘组合收益
- **HML**（High Minus Low）：高账面市值比 − 低账面市值比

> **本质追问**：SMB 和 HML 是**风险的代理**（风险未被定价，Fama-French 的辩护），还是**行为的产物**（小盘被忽视、价值股被低估，行为派的辩护）？**同一个事实，两种解释，至今没有共识**——这是信息定价 vs 行为定价之争的缩影。后来 Carhart（1997）加入动量因子 → 四因子；Fama-French（2015）加入盈利和投资 → 五因子。

## 三、有效市场假说（EMH）的深度审视

EMH 是金融学认识论的"宪章"。它不是预测模型——它是一句关于**我们能知道什么**的哲学判断。

### 三种形式

| 形式 | 价格反映的信息 | 推论 | 谁还能赚钱 |
|------|--------------|------|-----------|
| **弱式** | 所有历史价格 | 技术分析无效 | 基本面分析者可赚 |
| **半强式** | 所有公开信息 | 基本面分析也无效 | 只有内幕可赚 |
| **强式** | 所有信息（含内幕） | 没人能赚 | 没人能长期超额 |

### Grossman-Stiglitz 悖论（1980）—— EMH 的自我矛盾

> **如果价格已完美反映信息，搜集信息的成本无法被收益弥补，那没人会去搜集信息。但如果没人搜集信息，价格又怎么可能反映信息？**

这是 EMH 的**哥德尔式自指悖论**。解决它需要一个折中：市场**接近**有效但**不完全**有效——搜集信息能赚一点，但只够补偿信息成本。正是这个"小缺口"养活了整个主动管理行业。

### 市场异象（EMH 难以解释的系统性偏离）

| 异象 | 现象 | 信息派解释 | 行为派解释 |
|------|------|-----------|-----------|
| **动量** | 过去 6-12 月涨的，未来 3-6 月还涨 | 风险因子 | 保守主义偏差 + 羊群 |
| **反转** | 长期（3-5 年）涨太多会回落 | 均值回归 | 过度反应 |
| **日历效应** | 一月/周一收益异常 | 税务/报告周期 | 情绪/注意力的周期 |
| **规模效应** | 小盘股超额收益 | 风险溢价 | 被忽视的股票 |
| **公告后漂移** | 财报超预期后股价继续涨几周 | 信息扩散慢 | 锚定 + 反应不足 |

> **essence 立场**：**市场"大致"有效但"经常"偏离**——偏离的幅度和持续时间由**信息搜集成本**和**套利约束**共同决定。价值投资者的超额回报，本质上就是"承担信息搜集劳动 + 承受均值回归等待时间"的报酬。市场不是全知，也不是全瞎——它是一个**有摩擦的信息处理器**。

## 四、价格 vs 价值

### 格雷厄姆的"市场先生"

> 想象你有个合伙人叫"市场先生"，他每天来敲门报一个价，要把你的股份买走或卖给你。他有时抑郁（报低价），有时狂躁（报天价）。**你没有义务和他交易**——你只需在他报傻价时利用他。

这是格雷厄姆（1949，《聪明的投资者》）的比喻，巴菲特一生的智慧基石。它暗含一个**关键区分**：

- **价格（Price）**：市场先生的报价——**可观测、波动、常不理性**。
- **价值（Value）**：资产"本身值多少"——**估算、稳定、基于基本面**。

### 价值投资的核心逻辑

当 **价格 < 内在价值** 时买入，等待价格回归价值。

但这里藏着一个**深不可测的陷阱**：

### 为什么"价格偏离价值"难以测量——自我指涉问题

> "内在价值"怎么算？答：**未来现金流的现值之和**。  
> 未来现金流怎么预测？答：基于**假设**。  
> 假设怎么定？答：基于**对未来的判断**。  
> 判断用什么校准？答：用**市场价格**作为参照。

**循环出现了**：我们用价格校准对价值的判断，然后又用价值判断去批评价格错了。这就好比：**你用尺子测量尺子本身有多直**。

这就是为什么价值投资**既是科学又是艺术**——DCF（现金流贴现）模型给出一个数，但**贴现率、增长率、终值的假设每一项都涉及主观判断**。两个分析师用同一份财报，能算出相差 50% 的内在价值。

> **哲学层**：价值不是隐藏在价格后面的"客观真理"——它是**一个需要主观模型才能定义的建构**。价格的"错误"永远相对于某个模型而言，而模型本身又无法被市场外部验证。这是 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 对象 4（价值）的"最深哲学黑洞"的具体展开。

## 五、跨学科映射

> 市场不是孤立的——它的运行机制与物理学、生物学、控制论、AI 共享**同构的骨架**。看到这些映射，就看到了市场的"深层语法"。

| 市场概念 | 对应物 | 共同骨架 |
|---------|--------|---------|
| **市场均衡**（供需相等） | 力学均衡（合力为零）、纳什均衡（无人有动力单方面偏离） | **一阶导为零**：系统停在"没有力量推动改变"的状态 |
| **价格机制**（涨跌调节供需） | 恒温器（温差驱动热流）、RL 的 reward signal | **负反馈闭环**：偏差驱动修正 |
| **泡沫/崩盘**（正反馈失控） | 谐振、雪崩、癫痫发作 | **正反馈 + 系统越过临界点** |
| **市场选择**（亏钱者被淘汰） | 自然选择（不利变异被淘汰） | **变异（新策略）+ 选择（盈亏）+ 遗传（成功策略被模仿）**——市场是演化系统 |
| **信息聚合**（无数交易者 → 一个价格） | 神经网络聚合特征（无数神经元 → 一个输出） | **分布式处理的涌现**：整体知道的信息 > 任何个体 |
| **波动率** | 温度（布朗运动的强度） | **微观随机性的宏观统计量** |
| **无套利** | 热力学第二定律（无永动机） | **"没有免费午餐"作为公理**，禁止自发的收益创造 |
| **流动性枯竭** | 相变（液态 → 固态的突变） | **连续行为的集体相变**：个体行为不变但集体性质剧变 |

> **核心洞察**：市场是一个**演化式的、分布式信息处理的、自组织的反馈系统**。它和生命体、大脑、生态系统共享同一套"复杂系统语法"。这就是为什么金融物理学（econophysics）能从统计力学借用工具——不是因为市场"是"物理系统，而是因为它们**共享同构的数学结构**。

## 六、局限与反例

主流定价模型很优雅，但每个都建立在**可能致命的假设**上。

### 局限 1 · 肥尾——正态分布假设失效

BSM 和 Markowitz 都假设**对数收益服从正态分布**。但 Mandelbrot（1963）早就指出：**金融收益是肥尾的**——极端事件（如 1987 黑色星期一单日跌 22%、2008、2020）的发生频率，比正态分布预测的高几个数量级。

```python
# 正态分布下，-4σ 事件的概率：
import math
print("正态分布 -4σ 概率 ≈", round(0.5*(1-math.erf(4/math.sqrt(2))), 6), "(约 3 万分之一)")
# 真实市场：-4σ 事件几乎每年都有
```

> **后果**：基于正态假设的风险模型（VaR、Markowitz 方差）**系统性低估尾部风险**。2008 危机的根本原因之一，就是银行用正态分布假设给毒资产定价。

### 局限 2 · 系统性风险——相关性在危机时趋近 1

分散投资（Markowitz 的核心建议）依赖一个假设：**资产间的相关性稳定**。但在危机中，**所有资产的相关性突然趋近 1**——它们一起跌，分散失效。

> **谚语**：危机里，所有相关性归 1。唯一上涨的是相关性本身。这就是为什么"分散化"在正常时是免费的午餐，在危机时是最贵的错觉。

### 局限 3 · 模型同质化——所有人用同一公式制造系统性风险

当所有交易者用同一个 BSM 公式对冲（Delta 对冲），他们的行为会**同质化**——市场下跌时一起卖出，上涨时一起买入。模型从"描述工具"变成"制造现实的引擎"。

> **LTCM 案例教训**（1998）：一群诺贝尔奖得主（Merton、Scholes 本人在场）用精密模型套利，杠杆 25 倍。俄罗斯违约引发流动性危机，模型假设全部失效（相关性趋 1、肥尾爆发、市场无法出清），基金几周内崩盘，需要美联储组织救援。  
> **Mandelbrot 的判词**："建立在正态分布上的金融工程，就像在沙滩上建大坝。"

> **essence 命名**：这是**"工具的反噬"**——当一个模型被足够多人使用，它就改变了它所描述的现实（自我实现/自我毁灭），模型的前提不再外生。和波普尔的"自我预测悖论"、以及 AI 中的"古德哈特定律"同构。

### 局限 4 · 波动率微笑——BSM 经验失效的直接证据

BSM 假设 $\sigma$ 是常数。但实测中，**不同行权价的期权隐含不同的波动率**——画出来是一条"微笑"曲线。这说明市场**不真的相信**几何布朗运动——市场用 BSM，但用一种 BSM 无法自洽的方式（每个行权价套不同的 σ）。这是经验对理论的"软抵抗"。

## 七、开放问题

> 这些问题没有标准答案——保持张力本身就是好的思考姿态。

1. **价格有"客观价值"吗？**  
   如果价值只能用模型定义，而模型又需要主观假设——那"价格偏离价值"这句话还有客观意义吗？价值是发现的，还是发明的？（链 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 对象 4）

2. **算法定价时代，市场还是"涌现智慧"吗？**  
   当 70% 的交易由算法完成，市场聚合的还是"人的信息"，还是"算法的信息"？算法之间互相学习，会不会制造**算法泡沫**（2010 闪电崩盘的预演）？市场的"集体智慧"是否需要一个"人类心智"作为底层？

3. **效率 vs 稳定——市场越有效，是否越脆弱？**  
   有效市场 = 价格瞬间反映所有信息 = 对冲击无缓冲。一个"完全有效"的市场，是不是一个**一有风吹草动就崩盘**的市场？Minsky 的洞见：**稳定孕育不稳定**——效率本身可能是系统性风险的源头。

4. **价值投资的超额收益，是"信息劳动的报酬"还是"承担风险的补偿"？**  
   这决定了一个问题：如果你能赚，是因为你聪明（信息派），还是因为你敢承担别人不敢承担的风险（行为派/风险派）？同一个利润，两种截然不同的自我理解。

5. **去中心化金融（DeFi）的定价，还是"市场"定价吗？**  
   AMM（自动做市商）用 $x \cdot y = k$ 的固定公式定价，不依赖订单簿——这是一种**算法强制的均衡**。它还是 Hayek 意义上的"分布式信息处理"吗？还是退化为"一条公式假装是市场"？
