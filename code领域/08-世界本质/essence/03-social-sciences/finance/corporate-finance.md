## 文件头：essence 立场

**经典定义**（CFA / Damodaran）：公司金融研究企业如何**筹集资金（融资）、配置资金（投资）、分配回报（分红）**，以最大化企业价值。

**essence 理解**：公司金融 = **关于"代理人与代理人之间、股东与债券人之间、今天与未来之间"的契约设计**。它的三个核心张力是：

1. **时间张力**：投资现在花钱、未来才回收（资本预算）
2. **风险张力**：债务放大收益也放大风险（资本结构）
3. **信任张力**：管理者未必为股东利益最大化（代理问题）

> **核心洞察**：公司金融的全部理论，都是围绕一个虚构的基准——**"完美市场下企业价值最大化"**——不断放松假设、引入摩擦，来逼近现实。

**与资产定价的区别**：
| | 资产定价 | 公司金融 |
|---|--------|--------|
| 视角 | 外部投资者 | 内部决策者（CFO/董事会） |
| 对象 | 金融资产本身 | 创造价值的企业实体 |
| 核心问题 | 这个资产该值多少钱？ | 这笔钱该怎么花/怎么筹？ |
| 工具 | 无套利、CAPM、BSM | NPV、WACC、DCF |
| 价值来源 | 市场均衡/风险定价 | 实体投资回报 |

## 一、公司金融的核心问题：三大决策

Damodaran 的框架：企业的全部财务决策可归为三类，它们最终都指向**企业价值最大化**。

```
                        企业价值最大化 (Maximize Firm Value)
                                   │
        ┌──────────────────┬───────┴────────┬──────────────────┐
        ▼                  ▼                ▼                  ▼
   ① 投资决策          ② 融资决策        ③ 分红决策        (④ 营运资本)
   Capital Budgeting   Capital Structure  Dividend Policy   Working Capital
   "钱花到哪"          "钱从哪来"         "赚了怎么分"      "日常周转"
        │                  │                │
   NPV > 0 ?          债务 vs 股权?      留存 vs 派发?
   投资回报 > 资本成本?  最优资本结构?      发多少? 信号?
```

### 决策一 · 投资决策（资本预算）

企业面对一堆备选项目（建工厂、研发、并购），必须决定**哪些做、哪些不做**。标准只有一个：**项目的净现值（NPV）是否为正**——即回报是否超过资本成本。

### 决策二 · 融资决策（资本结构）

决定了"做"之后，**钱从哪来**？用自有资金？发债？发股？不同融资方式改变了企业的风险结构，进而影响企业价值。这是 MM 定理之后半个世纪的争论核心。

### 决策三 · 分红决策（股利政策）

赚了钱之后，**多少留存、多少派发**？这看似简单，却牵涉到信号传递、税收、代理成本和投资者偏好。

### 三大决策的统一：ROIC 与 WACC

> **价值创造的第一性原理**：只要 **投入资本回报率（ROIC）> 加权平均资本成本（WACC）**，企业就在创造价值。ROIC < WACC，企业就在毁灭价值。其余都是细节。

$$\text{企业价值} = \text{投入资本} + \sum_{t=1}^{\infty} \frac{\text{投入资本}_t \times (\text{ROIC}_t - \text{WACC}_t)}{(1+\text{WACC})^t}$$

这是 Damodaran 的核心等式：**超额回报（ROIC − WACC）才是价值的真正来源**。

## 二、资本预算（投资决策）

### 2.1 四大评价方法对比

| 方法 | 公式 | 决策准则 | 优点 | 缺点 | 本质 |
|------|------|---------|------|------|------|
| **NPV**（净现值） | $\text{NPV}=\sum_{t=0}^{n}\frac{CF_t}{(1+r)^t}$ | NPV > 0 则接受 | 理论最优、考虑时间价值、与价值最大化一致 | 依赖折现率假设 | 绝对价值创造 |
| **IRR**（内部收益率） | 使 NPV=0 的 $r$：$\sum\frac{CF_t}{(1+\text{IRR})^t}=0$ | IRR > r 则接受 | 直观（百分比）、易沟通 | 多重解、互斥项目误判、再投资假设 | 相对回报率 |
| **回收期** | 累计现金流回本所需年数 | < 目标年限则接受 | 简单、度量流动性 | 忽略回本后现金流、忽略时间价值 | 流动性指标 |
| **盈利指数 PI** | $\text{PI}=\frac{\sum_{t\ge1}CF_t/(1+r)^t}{|CF_0|}$ | PI > 1 则接受 | 适合资本受限下的排序 | 与 NPV 在互斥项目可能冲突 | 单位投资回报 |

### 2.2 NPV 为何是"王"

NPV 的理论基础是**价值可加性 + 机会成本**：
- 今天 1 元的现值就是 1 元（无套利基准）
- 未来的 1 元今天的价值 = $1/(1+r)^t$（放弃的等价无风险回报）
- NPV > 0 意味着项目创造了比"市场同等风险回报"更多的价值

IRR 的致命缺陷——**再投资假设错误**：IRR 隐含假设中间现金流以 IRR 再投资。若 IRR=30%，但市场再投资率只有 8%，IRR 会高估真实回报。修正版是 **MIRR**（修正内部收益率），用真实再投资率。

### 2.3 互斥项目的选择困境

当两个项目只能选一个时：
- **规模差异大** → NPV 优先（PI 会偏向小项目）
- **时间分布差异大** → NPV 优先（IRR 会偏向早回收的项目）
- **冲突法则**：**NPV 永远是终极裁判**。IRR 只在独立项目评估中有用。

交叉率（Fisher Intersection）：使两个项目 NPV 相等的折现率，是判断冲突区间的关键。

### 2.4 实物期权（Real Options）

传统 NPV 假设决策是"现在投或不投"的二元选择。但现实中投资往往带有**灵活性**——可以延迟、扩张、放弃、转换。这些灵活性有价，传统 NPV 会**低估**战略性项目的价值。

**实物期权的类型**：
| 类型 | 对应金融期权 | 例子 |
|------|------------|------|
| 延迟期权 | 看涨期权 | 持有土地，等涨价再开发 |
| 扩张期权 | 看涨期权 | 先建小厂，市场好则扩建 |
| 放弃期权 | 看跌期权 | 项目可随时清算残值 |
| 转换期权 | 双向期权 | 灵活切换生产线的工厂 |

**期权调整 NPV（战略 NPV）**：
$$\text{ENPV} = \text{NPV}_{\text{传统}} + \text{期权价值}$$

直觉：僵化的"现在决定"会低估有未来灵活性的战略投资。这是为什么科技巨头愿意为"看起来 NPV 为负"的早期研发砸钱——他们在购买延迟期权。

### 2.5 代码：NPV / IRR / 回收期 / 盈利指数计算器

```python
def calc_npv(cashflows, r):
    """现金流列表, cashflows[0] 为 t=0 的初始投资(负值)"""
    return sum(cf / (1 + r) ** t for t, cf in enumerate(cashflows))

def calc_irr(cashflows, lo=-0.99, hi=10.0, tol=1e-7):
    """二分法求 IRR (使 NPV=0 的折现率)"""
    f = lambda r: calc_npv(cashflows, r)
    a, b = lo, hi
    if f(a) * f(b) > 0:
        return float('nan')   # 无解或多解
    for _ in range(200):
        mid = (a + b) / 2
        if abs(f(mid)) < tol:
            return mid
        if f(a) * f(mid) < 0:
            b = mid
        else:
            a = mid
    return (a + b) / 2

def payback_period(cashflows):
    """静态回收期"""
    C0 = -cashflows[0]
    cum = 0.0
    for i in range(1, len(cashflows)):
        prev = cum
        cum += cashflows[i]
        if cum >= C0:
            return (i - 1) + (C0 - prev) / cashflows[i]  # 插值
    return float('inf')

def profitability_index(cashflows, r):
    pv_fut = sum(cf/(1+r)**t for t, cf in enumerate(cashflows) if t >= 1)
    return pv_fut / (-cashflows[0])

# === 对比两个互斥项目: 真实 NPV-IRR 冲突 ===
projA = [-1000, 0, 200, 400, 1500]    # 耐心项目: 后期现金流大
projB = [-1000, 1000, 300, 100, 50]   # 急躁项目: 早回收
r = 0.10
for name, cf in [("A耐心", projA), ("B急躁", projB)]:
    print(f"项目{name}: NPV={calc_npv(cf,r):>8.2f}  IRR={calc_irr(cf)*100:>6.2f}%  "
          f"回收期={payback_period(cf):.2f}年  PI={profitability_index(cf,r):.4f}")
# 预期: A 的 NPV 更高(但 IRR 更低), B 的 IRR 更高(但 NPV 更低) → 真 NPV-IRR 冲突! NPV 是最终裁判
```

**运行结果**（已验证）：
```
项目A耐心: NPV=  490.34  IRR= 23.09%  回收期=3.27年  PI=1.4903
项目B急躁: NPV=  266.31  IRR= 30.96%  回收期=1.00年  PI=1.2663
```

**洞察**：项目 A 的 NPV 更高（490 > 266）但 IRR 更低（23% < 31%）——这是教科书级的 **NPV-IRR 冲突**。A 把回报压在后期（耐心项目），B 把回报挤在第一年（急躁项目）。若按 IRR 决策会选错 B。**IRR 的"早回收偏好"缺陷在此暴露无遗——永远相信 NPV**。

## 三、资本结构理论深度演进

> 这是公司金融最深邃、最具争议的领域。半个世纪的理论史，就是不断在"完美市场"基准上加摩擦的历史。

### 演进时间线

```
1958  Modigliani-Miller 无税定理      "资本结构无关" —— 震惊学界的基准
1963  Modigliani-Miller 有税定理      "债务有利(税盾)" —— 矫枉过正: 100% 债务?
1977  Miller 均衡模型                 个人税抵消公司税 —— 重新回归
1976  权衡理论(Trade-off)             税盾 vs 破产成本 → 最优债务比存在
1984  优序融资理论(Myers-Majluf)      信息不对称 → 内源>债务>股权
1976  代理理论(Jensen-Meckling)       代理成本 → 债务既是问题也是解药
1985  信号理论(Ross)                  资本结构传递内部信息
```

### 3.1 Modigliani-Miller 定理（1958 / 1963）

**地位**：公司金融的"相对论"——一个反直觉的基准命题，后续所有理论都是对它的修正。

#### MM 无税定理（1958）—— 命题 I & II

**命题 I（无公司税）**：在完美市场下，**企业价值与资本结构无关**。

$$V_L = V_U$$

其中 $V_L$ 是有杠杆企业价值，$V_U$ 是无杠杆企业价值。

**直觉**：馅饼的价值不取决于你怎么切。企业的现金流（馅饼）由资产决定，融资方式（切法）只是重新分配这块饼，不改变饼的大小。

**无套利证明**（核心思想）：
假设 $V_L > V_U$。投资者可以"自制杠杆"——卖空杠杆公司股票 $\alpha$，借入 $\alpha \cdot D$，买入无杠杆公司股票 $\alpha \cdot V_U$。这个组合的收益与杠杆公司完全相同，但成本更低（$\alpha V_U < \alpha V_L$）。套利压力使 $V_L \to V_U$。反之同理。

**命题 II（无税）**：杠杆企业股权成本随债务比上升：

$$r_E = r_0 + (r_0 - r_D) \times \frac{D}{E}$$

其中 $r_0$ 是无杠杆企业股权成本（= 全部资产成本），$r_D$ 是债务成本。

**直觉**：债务越多的企业，股东承担的"残值波动"越大（因为债务优先受偿），所以股东要求更高回报。**便宜的债务带来的好处，恰好被更贵的股权抵消**——这正是价值不变的微观机制。

#### MM 有税定理（1963）

引入公司所得税后，**利息可税前扣除**（税盾 Tax Shield）：

**命题 I（有税）**：

$$V_L = V_U + T_c \times D$$

$T_c \times D$ 就是**税盾的现值**——因为利息抵税带来的永久性节税。

**推论（荒诞的）**：按此公式，企业应该 100% 用债务融资！这显然不符合现实。

**为什么现实中没有 100% 债务**？因为 MM 1963 忽略了：①破产成本 ②代理成本 ③个人税 ④信息不对称。这些摩擦就是后续理论的切入点。

#### Miller 均衡模型（1977）

Miller 指出：还要考虑**个人所得税**。债务利息按普通收入征税（税率 $T_d$），股权收益部分按资本利得税（税率 $T_e < T_d$）。最终税盾价值被个人税部分抵消：

$$V_L = V_U + \left[1 - \frac{(1-T_c)(1-T_e)}{(1-T_d)}\right] \times D$$

当 $(1-T_c)(1-T_e) = (1-T_d)$ 时，税盾完全消失，回归 MM 无税结论。Miller 模型解释了为何现实中债务比远低于"100%"。

### 3.2 权衡理论（Trade-off Theory）

**核心思想**：企业权衡**债务的税盾收益**与**财务困境成本（破产成本）**，存在一个最优债务比。

$$V_L = V_U + \underbrace{T_c \cdot D}_{\text{税盾现值}} - \underbrace{PV(\text{财务困境成本})}_{\text{破产成本现值}}$$

**最优债务比的解析**（线性税盾 + 二次破产成本）：
设破产成本 $= b \cdot D^2$（随债务非线性上升），则：

$$V_L(D) = V_U + T_c D - b D^2$$

对 $D$ 求导令其为零：$T_c - 2bD = 0 \Rightarrow$

$$\boxed{D^* = \frac{T_c}{2b}}$$

**直觉**：
- 债务少时，税盾收益 > 破产成本 → 加杠杆增加价值
- 债务多时，破产成本 > 税盾收益 → 减杠杆增加价值
- 两者相等处即最优债务比

**各行业最优债务比的差异**：
| 行业特征 | 最优债务比 | 例子 |
|---------|-----------|------|
| 资产有形、现金流稳定 | 高 | 公用事业、房地产 |
| 资产无形、现金流波动 | 低 | 科技、生物制药 |
| 成熟、低增长 | 高 | 传统制造业 |
| 高成长、机会多 | 低 | 初创企业 |

### 3.3 优序融资理论（Pecking Order Theory, Myers-Majluf 1984）

**核心思想**：由于**信息不对称**（管理者比投资者更了解企业真实价值），企业融资遵循一个"啄食顺序"：

```
内源融资 (留存收益)  >  债务融资  >  股权融资
    最优先                次之          最后选择
```

**为什么股权排最后**？当管理者认为股价被**高估**时才发新股（逆向选择）。所以市场把"发新股"解读为"股价太高"的信号，导致发行时股价下跌。为避免这个"柠檬问题"（Akerlof），企业宁愿先用内源资金，再用债务，最后才被迫发股。

**推论**：
- 盈利企业负债率**低**（不需要外部融资）——这与权衡理论预测相反！
- 亏损企业反而负债率**高**（被迫借债）
- 没有明确的"目标债务比"——债务是融资缺口的被动结果

**权衡 vs 优序的关键分歧**：权衡理论认为有"目标资本结构"，优序理论认为没有——债务只是内源资金不足时的补充。

### 3.4 代理理论（Jensen-Meckling 1976）

**核心思想**：管理者（代理人）与股东（委托人）利益不一致，产生**代理成本**。资本结构是约束代理问题的工具。

**两类代理冲突**：

| 冲突 | 表现 | 资本结构的角色 |
|------|------|--------------|
| **股东 vs 管理者** | 管理者偷懒/过度投资/建帝国 | 债务产生"自由现金流约束"(Jensen)——强制分红 |
| **股东 vs 债权人** | 股东冒风险转移财富(资产替代) | 债务契约、保护性条款 |

**Jensen 的自由现金流假说**：成熟企业产生大量自由现金流，管理者倾向于挥霍（帝国建造、过度并购）。**增加债务**可以强制把现金"吐出来"还债，约束管理者。这是 1980 年代杠杆收购（LBO）浪潮的理论基础。

$$\text{总代理成本} = \underbrace{\text{股权代理成本}}_{\text{管理者懈怠}} + \underbrace{\text{债务代理成本}}_{\text{资产替代/破产}}$$

最优资本结构最小化总代理成本。

### 3.5 代码：资本结构三大理论模拟

```python
# === 权衡理论: 找最优债务比 ===
Vu, Tc, b = 1000.0, 0.25, 0.001   # 破产成本系数 b
def tradeoff_V(D):
    """V = 无杠杆价值 + 税盾 - 破产成本"""
    return Vu + Tc*D - b*D**2
D_star = Tc / (2*b)   # 解析最优解
print(f"权衡理论: 最优债务 D* = {D_star:.0f}, 企业价值 = {tradeoff_V(D_star):.2f}")
print(f"        (无负债价值 {Vu}, 因杠杆增值 {tradeoff_V(D_star)-Vu:.2f})")

# === MM 定理对比 ===
D = 400.0
print(f"\nMM无税: V_L = V_U = {Vu}")
print(f"MM有税: V_L = V_U + Tc·D = {Vu + Tc*D:.2f}  (税盾 {Tc*D:.2f})")
print(f"权衡:   V_L = MM有税 - 破产成本 = {Vu + Tc*D - b*D**2:.2f}")

# === 优序融资: 盈利企业为何低负债 ===
def pecking_order(fcf, inv_needed):
    """内源优先, 不足才借债, 最后发股"""
    internal = fcf
    if internal >= inv_needed:
        return {"内源": inv_needed, "债务": 0, "股权": 0}
    shortfall = inv_needed - internal
    debt = min(shortfall, 0.6 * inv_needed)   # 债务容量上限60%
    equity = shortfall - debt
    return {"内源": internal, "债务": debt, "股权": equity}
print("\n优序融资模拟:")
print(f"  盈利企业(FCF=800, 投资=500): {pecking_order(800,500)}")
print(f"  成长企业(FCF=200, 投资=800): {pecking_order(200,800)}")
```

**运行结果**（已验证）：
```
权衡理论: 最优债务 D* = 125, 企业价值 = 1015.62
        (无负债价值 1000.0, 因杠杆增值 15.62)
MM无税: V_L = V_U = 1000.0
MM有税: V_L = V_U + Tc·D = 1100.0  (税盾 100.00)
权衡:   V_L = MM有税 - 破产成本 = 940.0

优序融资模拟:
  盈利企业(FCF=800, 投资=500): {'内源': 500, '债务': 0, '股权': 0}
  成长企业(FCF=200, 投资=800): {'内源': 200, '债务': 480, '股权': 120}
```

**洞察**：同样 400 的债务，MM 有税模型说价值增加 100，但权衡理论（考虑破产成本 $bD^2=160$）反而说价值减少 60。**理论的假设决定了结论——这正是公司金融的哲学教训**。

## 四、WACC（加权平均资本成本）

### 4.1 公式

$$\text{WACC} = \frac{E}{V} \cdot r_E + \frac{D}{V} \cdot r_D \cdot (1 - T_c)$$

- $E, D$：股权、债务的**市场价值**
- $V = E + D$：企业总价值
- $r_E$：股权成本（用 CAPM 估计）
- $r_D$：债务税前成本（用现有债务到期收益率 YTM）
- $T_c$：边际公司税率
- $(1-T_c)$：税盾效应——利息可抵税，实际债务成本降低

**直觉**：WACC 是企业资金的"综合机会成本"——每一块钱资金按其来源权重计算成本。它是**企业创造价值的门槛回报率（hurdle rate）**。

### 4.2 各组件的估计

| 组件 | 估计方法 | 关键陷阱 |
|------|---------|---------|
| **$r_E$ 股权成本** | CAPM: $r_E = r_f + \beta(r_m - r_f)$ | β 用历史数据估计，不稳定；风险溢价 $(r_m-r_f)$ 争议大 |
| **$r_D$ 债务成本** | 现有债务 YTM 或信用评级对应利率 | 不是票面利率！是市场要求的收益率 |
| **$T_c$ 税率** | 边际税率（非平均税率） | 考虑递延税项、亏损结转 |
| **权重** | 用**市场价值**，非账面价值 | 账面价值严重低估股权、误判资本结构 |

### 4.3 CAPM 估计股权成本

$$r_E = r_f + \beta \cdot (E[R_M] - r_f)$$

- $r_f$：无风险利率（通常用 10 年期国债）
- $\beta$：股票相对市场的系统性风险
- $E[R_M] - r_f$：市场风险溢价（美国长期约 4-6%）

### 4.4 WACC 的循环性陷阱

WACC 依赖**市场价值权重** $E/V, D/V$，但企业价值本身又要用 WACC 折现！这是**循环依赖**。Damodaran 的解决方法：用**目标资本结构**（行业平均或管理层目标），而非当前市值。

### 4.5 代码：WACC 计算器

```python
def calc_wacc(E, D, Re, Rd, Tc):
    """E,D 为市场价值; Re 股权成本; Rd 税前债务成本; Tc 税率"""
    V = E + D
    wacc = E/V * Re + D/V * Rd * (1 - Tc)
    return wacc

def capm_re(rf, beta, market_premium):
    return rf + beta * market_premium

# 例: 某公司市场价值 股权600 债务400, β=1.2, rf=3%, 风险溢价5%, Rd=7%, Tc=25%
Re = capm_re(0.03, 1.2, 0.05)
wacc = calc_wacc(600, 400, Re, 0.07, 0.25)
print(f"CAPM 股权成本 Re = {Re*100:.2f}%")
print(f"WACC = {wacc*100:.4f}%")
# 验证: 加杠杆降低 WACC (税盾), 但股权成本上升
for lev in [(0,1000),(200,800),(400,600),(600,400),(800,200)]:
    D, E = lev
    if E==0: continue
    w = calc_wacc(E, D, Re, 0.07, 0.25)
    print(f"  D/V={D/(D+E)*100:5.1f}%  WACC={w*100:.4f}%")
```

**运行结果**（已验证）：
```
CAPM 股权成本 Re = 9.00%
WACC = 7.5000%
  D/V=  0.0%  WACC=9.0000%
  D/V= 20.0%  WACC=8.2500%
  D/V= 40.0%  WACC=7.5000%
  D/V= 60.0%  WACC=6.7500%
  D/V= 80.0%  WACC=6.0000%
```

**洞察**：在 WACC 公式里，债务比例越高，WACC 越低（税盾效应）。但这**只在低杠杆时成立**——现实中高杠杆会推高 $r_D$ 和破产成本。这就是为什么不能简单"借越多越好"。

## 五、公司估值方法全谱系

> Damodaran 是估值领域的权威。估值的三大方法：**内在估值（DCF）**、**相对估值**、**实物期权/资产基础**。

### 5.1 估值方法地图

```
公司估值
├── 内在估值 (Intrinsic / DCF)
│   ├── FCFF 模型 (企业自由现金流 → WACC 折现 → 企业价值 - 净债务 = 股权价值)
│   ├── FCFE 模型 (股权自由现金流 → Re 折现 → 直接得股权价值)
│   └── 调整现值 APV (= 无杠杆价值 + 税盾现值)
├── 相对估值 (Relative / Multiples)
│   ├── 盈利倍数: P/E, PEG, EV/EBITDA, EV/EBIT
│   ├── 账面倍数: P/B
│   └── 收入倍数: P/S, EV/Sales
├── 资产基础法 (Asset-Based)
│   └── 重置成本 / 清算价值
└── 实物期权法 (Real Options)
    └── 期权调整 NPV
```

### 5.2 DCF 折现现金流法

**核心思想**：资产的价值 = 它未来能产生的全部现金流的现值总和。

$$V = \sum_{t=1}^{N} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^N}$$

- 显性期现金流 $CF_1 \dots CF_N$
- 终值 $TV$：显性期之后所有现金流的折现（用 Gordon 增长模型）
- 折现率 $r$：与现金流风险匹配（FCFF 用 WACC，FCFE 用 $r_E$）

#### FCFF vs FCFE

| | FCFF（企业自由现金流） | FCFE（股权自由现金流） |
|---|----------------------|---------------------|
| 定义 | 归属于**所有**资本提供者的现金流 | 归属于**股东**的现金流 |
| 公式 | $EBIT(1-T_c) + D\&A - \Delta WC - CapEx$ | FCFF - 利息 $\times(1-T_c)$ + 净新增借款 |
| 折现率 | WACC | $r_E$（股权成本） |
| 得到 | **企业价值** | **股权价值**（直接） |
| 转换 | 企业价值 - 净债务 = 股权价值 | — |

#### 终值计算（Gordon 增长模型）

$$TV_N = \frac{CF_{N+1}}{r - g} = \frac{CF_N \times (1+g)}{r - g}$$

$g$ 是永续增长率，通常取 2-3%（不超长期 GDP 增长率）。**$g$ 必须 < $r$**，否则终值发散。

> **敏感性警示**：终值通常占企业价值的 70-80%！这意味着 DCF 的价值主要由"显性期之后的永续假设"决定。这是 DCF 最大的脆弱性——**长期增长率的小幅变动会导致估值剧变**。

#### 三阶段增长模型

成熟企业的现金流增长往往经历：**高增长 → 过渡 → 稳态**。
1. 阶段一（1-5 年）：高增长 $g_1$（如 15%）
2. 阶段二（6-10 年）：线性递减到稳态
3. 阶段三（11+ 年）：永续低增长 $g_\infty$（如 3%）

### 5.3 相对估值法

**核心思想**：不直接算价值，而是参考"相似公司"的交易倍数。

| 倍数 | 公式 | 适用 | 陷阱 |
|------|------|------|------|
| **P/E** | 股价 / 每股收益 | 盈利稳定的成熟企业 | E 为负/波动时失效；会计政策影响 |
| **PEG** | P/E / 增长率% | 成长股（平衡估值与增长） | 增长率预期不可靠 |
| **EV/EBITDA** | 企业价值 / EBITDA | 跨资本结构、跨国比较 | 忽略资本支出差异 |
| **P/B** | 股价 / 每股净资产 | 银行、保险、重资产 | 无形资产被低估 |
| **P/S** | 股价 / 每股收入 | 亏损的互联网/SaaS | 忽略利润率差异 |

**EV/EBITDA 的优越性**：它用**企业价值**（股权+债务-现金）而非股权价值，且 EBITDA 剔除资本结构（利息）、税收、折旧影响，是**最可比**的倍数。

**相对估值的致命缺陷**：如果整个行业被高估（如 2000 年互联网泡沫），相对估值会给你一个"相对合理的高估值"。**它只回答"比别人贵不贵"，不回答"本身值不值"**。

### 5.4 资产基础法

$$\text{企业价值} = \sum \text{资产重置成本} - \sum \text{负债}$$

适用于：资产密集型（房地产、矿业）、清算场景、控股公司。对轻资产/高增长企业严重低估（因为忽略了无形资产和成长期权）。

### 5.5 代码：完整 DCF 估值模型

```python
def dcf_valuation(fcf_list, wacc, g_terminal):
    """
    fcf_list: 显性期各年 FCFF
    wacc: 加权平均资本成本
    g_terminal: 永续增长率
    返回: (企业价值, 显性期PV, 终值PV, 名义终值)
    """
    n = len(fcf_list)
    # 1. 显性期现金流折现
    pv_explicit = sum(fcf_list[i]/(1+wacc)**(i+1) for i in range(n))
    # 2. 终值 (Gordon 模型)
    terminal_value = fcf_list[-1]*(1+g_terminal)/(wacc-g_terminal)
    pv_terminal = terminal_value/(1+wacc)**n
    # 3. 企业价值
    firm_value = pv_explicit + pv_terminal
    return firm_value, pv_explicit, pv_terminal, terminal_value

def equity_value(firm_value, debt, cash):
    """股权价值 = 企业价值 - 净债务"""
    return firm_value - debt + cash

# === 案例: 某成长企业 5 年 DCF ===
fcf = [100, 110, 121, 133.1, 146.41]   # 年增10%
wacc, g = 0.093, 0.03                    # WACC=9.3%, 永续增长3%
fv, pv_e, pv_t, tv = dcf_valuation(fcf, wacc, g)
eq = equity_value(fv, debt=300, cash=50)
print(f"显性期现金流PV = {pv_e:>9.2f}")
print(f"终值(名义)    = {tv:>9.2f}")
print(f"终值PV        = {pv_t:>9.2f}")
print(f"企业价值      = {fv:>9.2f}")
print(f"终值占比      = {pv_t/fv*100:>8.1f}%")
print(f"股权价值(净债=250) = {eq:.2f}")

# === 敏感性分析: g 和 WACC 如何影响估值 ===
print("\n企业价值敏感性矩阵 (WACC行 × g列):")
print(f"{'WACC/g':>8}", end="")
for g_t in [0.02, 0.025, 0.03, 0.035, 0.04]:
    print(f"  {g_t*100:>7.1f}%", end="")
print()
for w_t in [0.08, 0.09, 0.093, 0.10, 0.11]:
    print(f"{w_t*100:>7.1f}%", end="")
    for g_t in [0.02, 0.025, 0.03, 0.035, 0.04]:
        v = dcf_valuation(fcf, w_t, g_t)[0]
        print(f"  {v:>8.0f}", end="")
    print()
```

**运行结果**（已验证）：
```
显性期现金流PV =   463.35
终值(名义)    =  2393.69
终值PV        =  1534.50
企业价值      =  1997.85
终值占比      =     76.8%
股权价值(净债=250) = 1747.85

企业价值敏感性矩阵 (WACC行 × g列):
  WACC/g      2.0%      2.5%      3.0%      3.5%      4.0%
    8.0%      2174      2337      2533      2772      3071
    9.0%      1854      1968      2101      2258      2446
    9.3%      1775      1878      1998      2138      2305
   10.0%      1614      1697      1792      1902      2030
   11.0%      1427      1490      1561      1641      1733
```

**洞察**：WACC 从 8% 升到 11%（g=2%），企业价值从 2174 跌到 1427——**跌去三分之一**。永续增长率从 2% 升到 4%（WACC=9.3%），价值从 1775 涨到 2305——**涨 30%**。**DCF 估值对假设极度敏感——这就是为什么不同分析师对同一公司估值差异巨大**。诚实的人会承认：DCF 更多是"展示逻辑"而非"发现真相"。

## 六、股利政策

### 6.1 MM 股利无关论（1961）

**命题**：在完美市场下，**股利政策不影响企业价值**。价值由投资决策（资产产生的现金流）决定，与"怎么分"无关。

**逻辑**：如果企业少分红多留存，股价上涨（留存收益投资增值）；如果多分红少留存，股东拿到现金。两种方式下股东总财富相同。

### 6.2 现实中的三大摩擦

完美市场不存在，所以股利政策**可能**重要：

| 理论 | 核心机制 | 预测 |
|------|---------|------|
| **税收差异** | 资本利得税 < 股息税 | 应少分红（回购替代） |
| **信号理论** | 分红是"管理者对未来的信心信号" | 增加分红 → 股价涨 |
| **客户效应** | 不同投资者偏好不同分红（退休者要现金，年轻人要增长） | 企业匹配投资者偏好 |
| **代理成本** | 分红减少管理者可挥霍的自由现金流 | 多分红约束管理者 |

### 6.3 股票回购 vs 现金股利

在美国，**股票回购**已超越现金股利成为主要的回报方式（因税收优势 + 灵活性 + EPS 提升）。但回购的"EPS 提升幻觉"（减少股数抬高每股收益）不应被误认为价值创造——它只是资本结构调整。

## 七、并购（M&A）

### 7.1 并购的价值来源

$$V_{AB} > V_A + V_B \quad ?$$

并购的合理性在于**协同效应（Synergy）**——合并后价值大于部分之和。协同效应来源：

| 类型 | 机制 | 可信度 |
|------|------|--------|
| **经营协同** | 规模经济、范围经济、纵向整合 | 较高 |
| **财务协同** | 税盾、多元化降低破产成本、资金成本 | 中等 |
| **管理协同** | 收购低效企业，替换管理层 | 高（但难执行） |
| **市场力量** | 减少竞争、定价权 | 反垄断风险 |

### 7.2 支付方式

| 支付方式 | 对收购方 | 对目标方股东 |
|---------|---------|------------|
| **现金** | 承担全部风险；无股权稀释 | 立即纳税；确定性高 |
| **换股** | 分担风险；可能稀释 | 递延纳税；保留上涨空间 |
| **混合** | 介于两者之间 | 介于两者之间 |

**经验法则**：收购方认为自身股价**高估**时倾向换股；认为**低估**时倾向现金。

### 7.3 杠杆收购（LBO）

**核心机制**：用大量债务收购目标公司，靠目标自身现金流偿还债务。LBO 的价值来源：
1. **税盾**：高债务产生大额利息抵税
2. **治理**：债务约束管理层（Jensen 自由现金流假说）
3. **运营改善**：PE 收购方介入提升效率

$$V_{LBO} = V_{\text{无杠杆}} + PV(\text{税盾}) + PV(\text{运营改善}) - PV(\text{破产成本})$$

**LBO 的脆弱性**：高度依赖低利率环境。利率上升时，再融资成本飙升，大量 LBO 陷入困境（如 2007-2008 的杠杆泡沫）。

### 7.4 并购的残酷真相

实证研究（Andrade et al., Bruner）一致发现：
- **目标方股东**：平均获得 20-30% 溢价（明确受益）
- **收购方股东**：收益**接近零甚至为负**（经常过度支付）
- **协同效应的"赢家诅咒"**：收购方为赢得竞标过度支付，协同收益被溢价吞噬

> **洞察**：并购活动多由**管理者代理动机**（帝国建造、过度自信）驱动，而非股东价值。这是代理理论在并购领域的直接体现。

## 八、营运资本管理

### 8.1 现金转换周期（Cash Conversion Cycle, CCC）

$$\text{CCC} = \text{DIO} + \text{DSO} - \text{DPO}$$

- **DIO**（存货周转天数）：存货占用资金的时间
- **DSO**（应收账款周转天数）：收回销售款的时间
- **DPO**（应付账款周转天数）：拖延付款给供应商的时间

**直觉**：CCC 是企业"从付钱买原料，到收回卖货款项"的净时间。**CCC 越短，资金效率越高**。负 CCC（如亚马逊、戴尔）意味着用供应商的钱为自己融资——极致的营运效率。

### 8.2 三大管理策略

| 项目 | 目标 | 方法 | 风险 |
|------|------|------|------|
| **存货** | 降低 DIO | JIT、需求预测 | 缺货损失 |
| **应收** | 降低 DSO | 信用政策、保理 | 失去客户 |
| **应付** | 提高 DPO | 拖延付款、谈判 | 供应商关系恶化 |

### 8.3 营运资本的战略意义

营运资本不只是会计问题，而是**商业模式的反映**：
- 沃尔玛/亚马逊的负 CCC = 供应链霸权
- 传统制造业的正 CCC = 资金被存货和应收占用
- CCC 的变化是**企业流动性危机的早期信号**

## 九、公司治理

### 9.1 代理问题的核心

Berle-Means（1932）的经典命题：现代公司的特征是**所有权与控制权分离**。股东（所有者）与管理者（控制者）利益分化，产生代理成本。

Jensen-Meckling（1976）的形式化：
$$\text{代理成本} = \underbrace{\text{管理者在职消费等偏离支出}}_{\text{剩余损失}} + \underbrace{\text{监督成本}}_{\text{审计/董事会}} + \underbrace{\text{担保成本}}_{\text{管理者自我约束}}$$

### 9.2 治理机制

| 机制 | 内部 / 外部 | 机制 | 局限 |
|------|-----------|------|------|
| **董事会** | 内部 | 代表股东监督管理层 | 独立性不足；CEO 影响提名 |
| **高管薪酬** | 内部 | 股权激励对齐利益 | 可能鼓励短期主义/操纵 |
| **机构投资者** | 内部 | 大股东积极主义 | "用脚投票"多于发声 |
| **收购威胁** | 外部 | 控制权市场约束 | 反收购条款削弱 |
| **法律/监管** | 外部 | 信义义务、信息披露 | 执行成本高、滞后 |
| **媒体/声誉** | 外部 | 舆论监督 | 威慑力有限 |

### 9.3 高管薪酬的两难

股权激励（期权/限制性股票）理论上对齐了管理者与股东利益，但也产生了：
- **短期主义**：管理者操纵短期业绩以行权
- **风险偏好扭曲**：期权鼓励过度冒险（期权只对上涨有利）
- **寻租**：管理者影响薪酬委员会设定有利于自己的条款

### 9.4 ESG 与利益相关者理论

传统公司金融假设企业**只为股东**最大化。利益相关者理论（Freeman）和 ESG 运动质疑这个前提：企业应对**所有利益相关者**（员工、客户、供应商、社区、环境）负责。

**本质争论**：
- **股东至上派**（Friedman）：企业唯一社会责任是增加利润；股东自己决定如何做慈善
- **利益相关者派**：长期看，忽视 ESG 会增加风险、损害价值；ESG 是新型风险管理

> **essence 立场**：ESG 的"是否创造价值"本身是个实证问题，被政治立场污染。真正的核心是：**"企业为谁存在"是一个规范问题，不是实证问题**——它取决于你怎么定义"价值"和"正义"。

## 十、中国的公司金融特殊性

### 10.1 国企 vs 民企的融资鸿沟

中国金融体系的根本特征：**银行主导 + 隐性担保 + 所有制歧视**。

| 维度 | 国有企业 | 民营企业 |
|------|---------|---------|
| 融资成本 | 低（隐性担保） | 高（信用溢价） |
| 融资渠道 | 银行贷款、债券、易获 IPO | 贷款难、发债难、IPO 排队 |
| 债务约束 | 软预算约束（政府兜底） | 硬预算约束 |
| 破产风险 | 极低（"大而不能倒"） | 高 |
| 投资效率 | 低（代理问题严重） | 高 |

**机制**：国企享有**隐性政府担保**，降低了违约风险感知，从而获得更便宜的债务。但这造成**资源错配**——低效的国企占用大量信贷，高效的民企融资困难。这是中国经济"宏观高杠杆 + 微观低效率"的结构性根源。

### 10.2 A 股 IPO 与再融资

- **核准制 → 注册制**（2019 科创板试点，2023 全面注册制）：从"证监会审盈利"转向"信息披露为中心"
- **IPO 定价**：长期 23 倍市盈率"窗口指导"，市场化定价逐步放开
- **再融资**：定增（定向增发）是主要方式，有锁定期和发行对象限制
- **退市**：长期"只进不出"，退市率极低；注册制配套退市常态化

### 10.3 债券融资的双轨制

中国债券市场的特殊性：**银行间市场（央行/交易商协会）** vs **交易所市场（证监会）** 的分割。

| 品种 | 监管 | 主体 |
|------|------|------|
| 国债、地方债 | 财政部 | 政府 |
| 金融债 | 央行/银保监 | 银行 |
| 企业债 | 发改委（现划转） | 国企为主 |
| 公司债 | 证监会 | 上市公司 |
| 中票/短融 | 交易商协会 | 较大企业 |

**城投债的灰色地带**：地方政府融资平台（城投）发行的债券，名义上是企业债（政府不担保），实际依赖政府信用。这是"土地财政"的金融延伸，也是地方债务风险的核心载体（详见 [`china-financial-system.md`](./china-financial-system.md)）。

### 10.4 中国公司金融的独特研究问题

1. **软预算约束下的资本结构**：国企负债率是否反映"真实"最优？
2. **政治关联与融资**：政治关联如何影响民企融资成本？
3. **僵尸企业**：低效企业为何能持续获得信贷？（答案是隐性担保）
4. **"国进民退"的金融机制**：信贷分配如何影响所有制结构变化？
5. **房地产企业的三高模式**（高负债/高杠杆/高周转）：恒大等危机的公司金融解读

## 十一、代码汇总 + 跨学科映射 + 开放问题

### 11.1 核心公式速查表

| 概念 | 公式 | 关键变量 |
|------|------|---------|
| NPV | $\sum CF_t/(1+r)^t$ | 折现率 $r$ |
| IRR | 使 NPV=0 的 $r$ | 现金流序列 |
| WACC | $E/V \cdot r_E + D/V \cdot r_D(1-T_c)$ | 市值权重 |
| MM有税 | $V_L=V_U+T_c D$ | 税率、债务 |
| 权衡最优 | $D^*=T_c/2b$ | 破产成本系数 |
| Gordon终值 | $TV=CF(1+g)/(r-g)$ | 永续增长率 |
| CAPM | $r_E=r_f+\beta(r_m-r_f)$ | β、风险溢价 |
| 现金转换周期 | DIO+DSO-DPO | 周转天数 |
| PEG | P/E ÷ 增长率% | 增长预期 |

### 11.2 综合估值器代码（FCFF + FCFE + 相对估值对比）

```python
# ============ 综合公司估值器 ============
def fcff_to_equity(ebit, tax_rate, da, delta_wc, capex, debt, cash,
                   growth_list, wacc, g_terminal):
    """FCFF 法: 得企业价值再推股权价值"""
    fcfs = []
    base = ebit*(1-tax_rate) + da - delta_wc - capex
    for g in growth_list:
        base = base*(1+g)
        fcfs.append(base)
    n = len(fcfs)
    pv_exp = sum(fcfs[i]/(1+wacc)**(i+1) for i in range(n))
    tv = fcfs[-1]*(1+g_terminal)/(wacc-g_terminal)
    pv_tv = tv/(1+wacc)**n
    firm_val = pv_exp + pv_tv
    equity_val = firm_val - debt + cash
    return {"企业价值": round(firm_val,2), "股权价值": round(equity_val,2),
            "终值占比%": round(pv_tv/firm_val*100,1)}

def relative_valuation(net_income, book_value, revenue, ebitda,
                       pe_comp=15, pb_comp=2.5, ps_comp=3.0, evebitda_comp=8):
    """相对估值法: 用可比公司倍数"""
    return {
        "P/E估值":   round(net_income*pe_comp, 2),
        "P/B估值":   round(book_value*pb_comp, 2),
        "P/S估值":   round(revenue*ps_comp, 2),
        "EV/EBITDA": round(ebitda*evebitda_comp, 2),
    }

# === 案例: 某虚构公司 ===
dcf = fcff_to_equity(ebit=150, tax_rate=0.25, da=40, delta_wc=10, capex=60,
                     debt=300, cash=50,
                     growth_list=[0.12,0.10,0.08,0.06,0.04],
                     wacc=0.093, g_terminal=0.03)
print("=== DCF (FCFF) ===")
for k,v in dcf.items(): print(f"  {k}: {v}")

rel = relative_valuation(net_income=80, book_value=500, revenue=500, ebitda=120)
print("\n=== 相对估值 ===")
for k,v in rel.items(): print(f"  {k}: {v}")
print("\n洞察: 不同方法给出差异巨大的估值 → 估值是区间, 不是点估计")
```

**运行结果**（已验证）：
```
=== DCF (FCFF) ===
  企业价值: 1681.09
  股权价值: 1431.09
  终值占比%: 75.4

=== 相对估值 ===
  P/E估值: 1200.0
  P/B估值: 1250.0
  P/S估值: 1500.0
  EV/EBITDA: 960.0

洞察: 不同方法给出差异巨大的估值 → 估值是区间, 不是点估计
```

### 11.4 开放问题（哲学深度）

1. **"企业价值最大化"是否为唯一合法目标？**  
   这是规范前提，不可证明。利益相关者理论、ESG、员工共治（德国模式）都挑战它。**"企业为谁存在"是个政治哲学问题**。

2. **NPV 准则是否低估了战略价值？**  
   实物期权理论指出传统 NPV 忽视灵活性。但更深层：**不可量化的战略价值（品牌、能力、生态）如何纳入估值？** 量化本身是一种认识论选择。

3. **资本结构的"最优"是发现还是建构？**  
   权衡理论认为最优债务比客观存在；优序理论认为没有目标。**这是实在论 vs 建构论的金融体现**。

4. **DCF 的循环依赖揭示了什么？**  
   WACC 依赖市值，市值依赖 WACC 折现——这是**自指**。哥德尔式的困境：估值系统无法完全自洽地证明自身。

5. **协同效应是真实的还是幻觉？**  
   实证显示收购方股东常受损。**"1+1>2"是否只是管理者过度自信的认知偏差的合理化？**

6. **中国国企的"软预算约束"如何重新定义资本结构理论？**  
   西方资本结构理论假设硬预算约束。当破产不可信时，"最优债务比"的概念是否还有意义？**这要求发展中国家的公司金融本土化理论**。

## 尾声：公司金融的认识论谦逊

公司金融的全部精致理论，建立在三个脆弱的支柱上：
1. **理性人假设**——管理者真的最大化企业价值吗？
2. **可预测的未来**——DCF 假设我们能预测 5-10 年的现金流，这在动荡世界里近乎妄想
3. **市场有效**——相对估值假设市场价格是合理基准，但若市场本身错误呢？

> **essence 终极洞察**：公司金融的数学越是精致，越要警惕它制造的"精确幻觉"。**NPV 不是一个数字，而是一个逻辑论证**——它告诉你"在以下假设成立时，这个项目值得做"。当假设崩塌时，整个估值体系随之崩塌。真正的智慧是知道：**哪些假设是稳健的，哪些是脆弱的**。

这就是为什么巴菲特说："**宁要模糊的正确，不要精确的错误**。"
