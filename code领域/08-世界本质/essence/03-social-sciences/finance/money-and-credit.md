## 一、货币的四大功能

> 亚里士多德最早指出货币的三功能，现代金融学补上第四个。**货币不是单一属性，而是一组功能的集合**——这个判断直接决定了 §二 的本体论立场。

| 功能 | 一句话 | 解决的问题 | 失效后果 |
|------|--------|-----------|---------|
| **交换媒介** | 大家都接受它换东西 | 需求双重巧合（barter 困境） | 交易瘫痪，退回物物交换 |
| **价值尺度** | 用它给万物标价 | 缺乏统一计量单位 | 每两种商品一个比价，N 种商品要记 N² 个 |
| **价值储藏** | 把今天的购买力存到明天 | 跨时间转移财富 | 只能囤积实物，流动性枯竭 |
| **信用工具** | 用它清算跨期债务 | 债务的计量与结算 | 信用系统无法运转（没有统一计价） |

### 1.1 交换媒介——消除"需求双重巧合"

**直觉**：物物交换下，你想用苹果换鞋，必须找到一个"恰好有鞋且恰好想要苹果"的人。这种"双重巧合"概率极低，是交易成本的灾难。货币充当"万能中转站"——你只需卖出（别人想要你的东西就行），再买入（别人有你想买的就行），两次单向匹配取代一次双向巧合。

**数学**：设商品种类数为 $k$，每个人随机拥有一种、想要一种。"双向巧合"概率约 $\frac{1}{k^2}$；"单向匹配"（货币媒介只需一次卖出）概率约 $\frac{1}{k}$。当 $k$ 增大，物物交换成功率按 $1/k^2$ 坍缩，货币交换按 $1/k$ 下降——差距随商品丰富度急剧放大。

**代码层**：模拟 100 人的经济体，对比两种模式的交易成功率。

```python
# money_sim1_barter.py —— 物物交换 vs 货币交换
import random
random.seed(42)

N_PEOPLE, N_GOODS, N_TRIALS = 100, 10, 5

def run_once(n_people, n_goods, use_money):
    have = [random.randint(0, n_goods - 1) for _ in range(n_people)]
    want = [random.randint(0, n_goods - 1) for _ in range(n_people)]
    traded = 0
    for i in range(n_people):
        if have[i] == want[i]:
            continue
        matched = False
        for j in range(n_people):
            if i == j:
                continue
            if use_money:                      # 货币：单向匹配（卖得出去即可）
                if want[j] == have[i]:
                    matched = True; break
            else:                              # 物物：双向巧合
                if want[j] == have[i] and have[j] == want[i]:
                    matched = True; break
        if matched:
            traded += 1
    return traded / n_people

for use_money, label in [(False, "物物交换"), (True, "货币交换")]:
    rates = [run_once(N_PEOPLE, N_GOODS, use_money) for _ in range(N_TRIALS)]
    avg = sum(rates) / len(rates)
    print(f"{label:>8}: 成功率 {avg*100:5.1f}%")
```

实测输出（`python3 money_sim1_barter.py`）：

```
    物物交换: 成功率  53.6%
    货币交换: 成功率  90.2%
```

> **洞察**：商品种类（`N_GOODS`）越多，物物交换成功率越快坍缩。把 `N_GOODS` 改成 50，物物交换成功率几乎归零——这就是现代复杂经济**必须**有货币的硬道理。货币的本质功能之一，是**降低交易成本**。

### 1.2 价值尺度——统一的计量单位

**直觉**：如果没有货币，1000 种商品两两比价，要记 $\binom{1000}{2} \approx 50$ 万个价格。有了货币，只需 1000 个价格（每种商品对一个货币标价）。**货币是经济世界的"度量衡"**。

**数学**：从 $O(N^2)$ 个比价压缩到 $O(N)$ 个标价。这是信息复杂度的数量级降低。

### 1.3 价值储藏——跨时间搬运购买力

**直觉**：苹果放一周会烂，但货币（尤其金属/法币）可以存放。**货币是时间的冷冻库**——把今天的劳动成果冻结，留到未来解冻使用。

**边界**：价值储藏功能**会失效**——恶性通胀（津巴布韦、魏玛德国）下，货币今天和明天的购买力天差地别。此时人们逃回实物（黄金/外币/物资）。这说明价值储藏**不是货币的天然属性，而是低通胀环境的产物**。

### 1.4 信用工具——债务的清算单位

**直觉**：我借你 100 元，承诺明年还。没有货币，"还"什么？一筐苹果？两双鞋？债务需要一个**统一的计量单位**才能被精确表达和清算。货币就是那个单位。

**深层**：这个功能把"货币"和"信用"死死绑定——货币既是价值的载体，又是债务的度量。**法币本质上就是中央银行的负债**（详见 §三）。

## 二、货币的本质——四大哲学立场

> 这是最深的层次。**"货币是什么"是一个哲学问题**（本体论），没有经验裁判。下面列四大立场，每派的论据与困境。

| 立场 | 核心主张 | 论据 | 困境 |
|------|---------|------|------|
| **金属主义**（奥地利学派） | 钱必须有内在价值（黄金） | 历史上信用货币多次崩溃归零；通胀是法币的顽疾 | 现代法币已脱离金本位 50+ 年运转良好；黄金的"内在价值"本身也是信念 |
| **Chartalism / MMT** | 法币有价值因为**国家接受它纳税** | 税收创造了对法币的刚性需求；国家是货币的垄断发行者 | 在美元霸权（全球需求）下，"税收驱动"被弱化；MMT 被指责为赤字辩护 |
| **建构主义**（Searle） | 钱是**集体意向性**的产物 | 和婚姻、国家、产权同构——存在因为大家相信它存在 | "集体信念从哪来"被推后一步；无法解释信念如何崩塌（挤兑） |
| **算法主义**（比特币） | 钱应**去中心化、算法化** | 消除信任对国家的依赖；总量算法锁定（抗通胀） | 波动太大无法做交换媒介；"算法信任"仍依赖矿工/代码/社区共识 |

### essence 立场

> 货币的"本质"不是单一属性，而是**功能的集合**。详见 [`insights/2026-07/2026-07-12-four-pillars-of-money.md`](../../insights/2026-07/2026-07-12-four-pillars-of-money.md) 的"四面镜"分析：
> - **本体论**：集体意向性的产物（Searle）
> - **认识论**：社会知识——可靠性依赖社会承诺
> - **价值论**：制度设计本质是正义选择（罗尔斯无知之幕）
> - **逻辑学**：常见推理有隐藏前提（"印钱=致富"是范畴错误）

> **核心判断**：不同货币在不同功能上强弱不同。黄金擅长价值储藏，不擅长交换媒介；法币擅长交换媒介和信用清算，价值储藏依赖通胀控制；比特币擅长抗通胀（算法锁定），但波动摧毁了交换媒介功能。**没有"完美货币"——只有功能组合的权衡。**

## 三、货币创造——银行如何"无中生有"

> 这是金融学最反直觉的事实之一：**商业银行通过贷款创造存款**——钱不是央行"印"出来再借出去的，而是银行"贷"出来变成存款的。

### 3.1 部分准备金制度

**直觉**：银行收到 100 元存款，不需要把 100 元全锁在金库里——只需留一部分（准备金率 $r$，如 10%），其余贷出去。贷款变成别人的存款，那个银行又留 10% 再贷……如此循环，100 元基础货币被"放大"成多倍存款。

### 3.2 货币乘数模型（教科书版，但误导）

**数学**：货币乘数 $m = \frac{1}{r}$，总货币量 $M = m \times B$（$B$ = 基础货币）。

$$M = \frac{B}{r} = B \sum_{n=0}^{\infty}(1-r)^n = \frac{B}{r}$$

**代码层**：模拟准备金率 10%、初始 100 元，追踪 10 轮借贷。

```python
# money_sim2_multiplier.py —— 货币乘数过程
RESERVE_RATIO = 0.10
INITIAL, ROUNDS = 100.0, 10

total_money, deposit = 0.0, INITIAL
print(f"{'轮次':>4} {'新增存款':>10} {'新增贷款':>10} {'累计M':>10}")
for r in range(1, ROUNDS + 1):
    reserve = deposit * RESERVE_RATIO
    loan = deposit - reserve
    total_money += deposit
    print(f"{r:>4} {deposit:>10.2f} {loan:>10.2f} {total_money:>10.2f}")
    deposit = loan
print(f"\n10 轮后 M = {total_money:.2f}  理论极限 B/r = {INITIAL/RESERVE_RATIO:.2f}")
```

实测输出：

```
轮次     新增存款     新增贷款        累计M
   1     100.00       90.00      100.00
   2      90.00       81.00      190.00
   3      81.00       72.90      271.00
   ...
  10      38.74       34.87      651.32

10 轮后 M = 651.32  理论极限 B/r = 1000.00
```

### 3.3 现代视角：内生货币（Endogenous Money）

> **关键纠正**：上面的乘数模型把因果搞反了。

**教科书逻辑**（外生货币）：央行给基础货币 $B$ → 乘数放大 → 产生 $M$。央行控制 $B$ 就控制 $M$。

**现实逻辑**（内生货币，后凯恩斯学派 / MMT）：银行**先**根据客户贷款需求放贷 → 放贷创造存款（凭空记一笔账）→ **再**去市场上找准备金（向央行借或同业拆借）→ 央行为了维持利率**被动**供给准备金。

> **一句话**：**贷款创造存款，不是存款决定贷款。** 央行控制的是利率（资金价格），不是货币量（资金数量）——因为不供给准备金，银行清算就会崩溃，利率会失控飙升。

### 3.4 央行的角色

| 工具 | 机制 | 现状 |
|------|------|------|
| **基础货币（B）** | 买卖国债调整银行体系准备金 | QE 后规模膨胀，但传导失效（见 §八） |
| **政策利率** | 调控银行向央行借钱的成本 → 传导到市场利率 | 主要工具（如美联储联邦基金利率） |
| **准备金率（r）** | 直接限制银行的放贷倍数 | 中国常用；发达国家已降至 0%（靠利率+资本约束） |
| **前瞻指引** | 用言语影响预期 | "信任"本身就是货币政策工具 |

## 四、信用——跨时间的信任

> 一句话：**信用是用今天的信任，兑换明天的不确定。**

### 4.1 信用的本质

- **定义**：信用 = 承诺未来支付。
- **本体论**：信用是**关于未来的跨时间承诺**——它的存在完全依赖"未来会存在"和"承诺会被履行"两个假设（见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) §一 对象 2）。
- **本质**：信用 = 对未来的**押注**。每一笔贷款、每一张债券、每一次赊账，都是在赌"未来比现在更好"（借款人有能力偿还）。

### 4.2 信用周期

```
扩张（乐观） → 过度（投机） → 收缩（恐慌） → 紧缩（萧条） → 复苏 → ...
   信用易得      信贷标准放松    挤兑/违约      去杠杆         信心重建
```

这是 Minsky 金融不稳定假说的核心节奏（见 [`_overview.md`](./_overview.md) 问题 5）：

> **稳定孕育不稳定。** 好时光让人加杠杆，加杠杆制造脆弱，脆弱导致崩盘。信用周期是资本主义金融系统的**内禀属性**。

### 4.3 Minsky 的融资三分类

| 类型 | 收入覆盖 | 安全度 | 典型 |
|------|---------|--------|------|
| **对冲融资** | 收入 > 本金 + 利息 | 安全 | 稳健企业贷款 |
| **投机融资** | 收入只够付利息，需滚动续借 | 脆弱 | 短贷长投、房地产开发 |
| **庞氏融资** | 收入连利息都不够，依赖资产升值 | 危险 | 炒房加杠杆、次贷 CDO |

> **Minsky 时刻**：当经济从"对冲为主"滑向"庞氏为主"，任何风吹草动都会引爆——庞氏融资者被迫抛售资产，资产价格下跌，更多融资者变成庞氏……**正反馈崩塌**。

### 4.4 挤兑的本质

> **挤兑**：不可兑换的承诺被同时要求兑换。

银行的秘密是**期限错配**——用短期存款（储户随时可取）放长期贷款（几年才还）。正常情况下储户不会同时取钱，所以"部分准备金"够用。但当信心动摇，所有人都想"先取为敬"——而银行的钱大部分贷出去了，**物理上无法同时兑现所有承诺**。

**信用瞬间蒸发**：挤兑揭示了一个真相——信用不是"存"在那里的东西，而是**流动的信任**。信任一停，信用归零。这和 Searle 的"集体意向性"完全一致：信念崩塌，制度性事实蒸发。

## 五、利率——时间的价格

> 利率是金融学的核心价格。它不只是"借钱的成本"——它是**时间本身的价格**。

### 5.1 利率的三层含义

| 层 | 名称 | 含义 |
|----|------|------|
| 1 | **时间偏好** | 人们偏好现在甚于未来——补偿等待 |
| 2 | **风险溢价** | 补偿违约/损失的不确定性 |
| 3 | **通胀补偿** | 补偿购买力的侵蚀 |

$$\text{名义利率 } i = \underbrace{r^*}_{\text{实际利率}} + \underbrace{\pi}_{\text{通胀}} + \underbrace{\rho}_{\text{风险溢价}}$$

### 5.2 Fisher 方程：名义 vs 实际利率

$$r \approx i - \pi$$

（精确形式：$(1+i) = (1+r)(1+\pi)$）

- 名义利率 $i$ 是你"看到"的数字（银行挂牌）。
- 实际利率 $r$ 是你"真正得到"的购买力增长。
- 通胀 $\pi$ 是**隐形的税**——它把债权人的购买力悄悄转移给债务人。

> **洞察**：高通胀 + 高名义利率 = 实际利率可能为零甚至为负。储户在亏钱却浑然不觉。这是"通胀是隐形税"的数学根源。

### 5.3 利率期限结构（收益率曲线）

收益率曲线描述**同类债券不同期限**的利率关系。三种典型形态：

| 形态 | 形状 | 含义 |
|------|------|------|
| **正常** | 向上倾斜 | 长期 > 短期，市场预期增长 |
| **倒挂** | 向下倾斜（前段） | **短期 > 长期 → 衰退预警** |
| **陡峭** | 大幅向上 | 复苏初期/极度宽松 |

**代码层**：模拟三种收益率曲线。

```python
# money_sim3_yield.py —— 收益率曲线的三种形态
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

maturities = ["3M", "6M", "1Y", "2Y", "5Y", "10Y", "30Y"]
x = list(range(len(maturities)))
normal   = [4.0, 4.1, 4.3, 4.5, 4.8, 5.0, 5.3]   # 正常
inverted = [5.2, 5.1, 4.9, 4.7, 4.4, 4.2, 4.5]   # 倒挂
steep    = [1.0, 1.2, 1.6, 2.2, 3.2, 4.0, 4.8]   # 陡峭

fig, ax = plt.subplots(figsize=(8.5, 5))
ax.plot(x, normal,   "o-", lw=2.2, label="Normal",  color="#2ecc71")
ax.plot(x, inverted, "s-", lw=2.2, label="Inverted", color="#e74c3c")
ax.plot(x, steep,    "^-", lw=2.2, label="Steep",    color="#3498db")
ax.set_xticks(x); ax.set_xticklabels(maturities)
ax.set_xlabel("Maturity"); ax.set_ylabel("Yield (%)")
ax.set_title("Yield Curve: Three Shapes"); ax.legend(); ax.grid(alpha=0.3)
plt.tight_layout(); plt.savefig("/tmp/yield_curve.png", dpi=110)
```

```
3M      4.0    5.2    1.0
...
10Y     5.0    4.2    4.0
10Y-3M 利差: 正常 +1.3%  倒挂 -0.7%  陡峭 +3.8%
```

### 5.4 倒挂为什么预示衰退？

两大理论解释：

- **预期理论**：长期利率 = 未来短期利率的（加权）平均。倒挂说明市场**预期未来央行会降息**——而央行降息通常发生在衰退时。倒挂是市场在对衰退"提前投票"。
- **分割市场理论**：长期资金市场（养老基金、保险）和短期资金市场（货币基金）参与者不同。当短期利率被推高（央行紧缩）而长期需求旺盛（避险），曲线倒挂。这反映**资金紧张**——本身就是衰退前兆。

> **经验事实**：美国历史上过去 7 次衰退前，10 年期-3 个月利差全部倒挂。**没有一次假阳性，但有 2 次提前量偏差超过 18 个月。** 它是极可靠的领先指标，但不是精确计时器。

## 六、货币史——从贝壳到比特币

> 货币史是"信任对象"不断抽象化的历史——从看得见摸得着的实物，到一张纸，到一个数字，到一段代码。

| 阶段 | 形态 | 信任基础 | 关键转变 |
|------|------|---------|---------|
| **物物交换** | — | 双向需求巧合 | 效率瓶颈 |
| **商品货币** | 贝壳、牛、盐、烟草 | 商品自身的使用价值 | 找到普遍接受的"中转物" |
| **金属货币** | 金、银、铜 | 金属的稀缺性+耐久性 | 标准化（铸币）、防伪 |
| **信用货币** | 纸币（金本位/银本位下） | 可兑换贵金属的承诺 | 从"称重"到"计数"；携带便利 |
| **法币** | 纸币（脱离贵金属） | **国家信用 + 集体信念** | 1971 布雷顿森林瓦解，美元脱金 |
| **数字货币** | 电子记账 / 央行数字货币 | 银行系统 + 央行背书 | 货币变成数据库里的数字 |
| **加密货币** | 比特币 / 稳定币 | **算法 + 去中心化共识** | 信任对象从"机构"转向"代码" |

**哲学意义**：每个阶段，"价值的物理载体"越来越薄，"集体信念"的成分越来越重。从金属（有内在价值）到法币（纯信念）到加密货币（纯算法共识）——**货币的演化就是信任的不断抽象化**。

### 中国货币史的亮点

| 时点 | 事件 | 意义 |
|------|------|------|
| **北宋（约 1023）** | **交子**——世界最早的纸币 | 从金属到信用的飞跃，比欧洲早 600 年 |
| **明清** | 银本位（白银流入） | 中国被卷入全球白银贸易网络 |
| **1935** | 法币改革 | 脱离银本位，进入法币时代 |
| **1948** | 人民币发行 | 新中国统一货币 |
| **2020s** | 数字人民币（DCEP）试点 | 主权数字货币的先发探索 |

> **历史教训**：交子最终因滥发而恶性通胀、信用破产——纸币的价值完全依赖发行纪律。这个教训 1000 年后仍在重演（津巴布韦、委内瑞拉）。**货币的脆弱性是结构性的，不是技术问题。**

## 七、跨学科映射

> 详见 [`knowledge-graph/connections.md`](../../knowledge-graph/connections.md)。货币与信用在多个学科有"同构对象"。

| 概念 | 金融学形态 | 同构对象（其他学科） | 同构的本质 |
|------|-----------|-------------------|-----------|
| **货币** | 集体信念支撑的交换媒介 | 国家（Searle 集体意向性）、婚姻（制度性事实） | 存在依赖集体承认，物理实体无关紧要 |
| **信用扩张收缩** | 周期性繁荣-崩溃 | 控制系统的振荡、生态种群繁荣-崩溃 | 正反馈→过冲→崩溃→负反馈回归 |
| **货币创造（乘数）** | 1 元基础货币放大为多倍存款 | 生物繁殖（一对繁衍成种群）、模因（信息复制） | 自我复制的指数增长 |
| **利率（时间价格）** | 未来收益的贴现率 | 贴现因子、物理时间常数（指数衰减 $e^{-rt}$） | "未来"按指数被折算到"现在" |
| **挤兑** | 信心崩溃→承诺不可兑换 | 银行挤兑 = 纳什均衡的协调失败 | 每个人"理性地"取钱→集体毁灭 |
| **通胀** | 货币贬值（信号噪声增大） | 信息熵增、测量仪器精度退化 | 计量单位本身在被侵蚀 |

> **深层连接**：货币作为"集体意向性构造"和 [`06-systems/complexity/`](../../06-systems/complexity/) 的"涌现秩序"同构——没有任何个体设计了它的价值，但价值产生了。信用周期的正反馈崩塌，和 [`06-systems/feedback/`](../../06-systems/feedback/) 完全一致。

## 八、局限与反例

> 金融学的每个模型都有失效场景。这里列出三个最关键的"模型 vs 现实"的断裂。

### 反例 1：货币乘数模型在 QE 后失效

**模型预测**：2008 后美联储 QE 注入约 4.5 万亿基础货币，乘数 10 倍 → 应产生 45 万亿货币 → 恶性通胀。

**现实**：通胀长期低于 2% 目标。为什么？因为**银行不贷**——危机后监管收紧（巴塞尔 III）、需求疲软、银行囤积超额准备金。乘数 $m$ 不是常数，而是**内生的、依赖信贷需求的**。

> **教训**：内生货币理论是对的——央行能给基础货币，但**不能强迫银行放贷、不能强迫实体经济借钱**。水能牵到河边，不能按着马头喝水。

### 反例 2：MMT "税收驱动货币"在美元霸权下的争议

**模型**：法币有价值因为国家要求用它纳税 → 主权国家不会破产（能印钱还债）。

**争议**：
- 美元的全球需求（石油美元、储备货币）远超"美国纳税需求"——美元价值部分来自**全球霸权**，不只来自国内税收。
- 拉美/土耳其的"印钱还外币债"直接崩溃——因为它们的货币**没有外部需求**。MMT 只对**主权货币 + 浮动汇率 + 不欠外债**的国家成立。
- "不会破产" ≠ "没有代价"——代价是通胀和汇率贬值，把成本转嫁给全民。

### 反例 3：加密货币无法做交换媒介

**理想**：比特币 = 去中心化、抗通胀、算法信任的完美货币。

**现实困境**：
- **波动太大**：年化波动率 60-80%（黄金 15%，法币 5-10%）——无法做计价单位和交换媒介（一杯咖啡今天 0.0001 BTC，明天 0.0002 BTC）。
- **吞吐瓶颈**：比特币 ~7 TPS，Visa ~24000 TPS——无法承载日常交易。
- **"去中心化"是程度问题**：矿工集中化、稳定币抵押物（USDT 的美元储备）仍是中心化依赖。
- **稳定币**（USDT/USDC）反而证明：要稳定就得挂钩法币——**绕了一圈回到了中心化信用**。

> **洞察**：加密货币目前更接近"数字黄金"（投机性价值储藏），而非"货币"（四大功能全套）。它挑战了法币的垄断，但尚未替代。

## 九、开放问题

- [ ] **数字人民币（DCEP）会改变货币创造机制吗？** 如果存款从商业银行搬到央行数字钱包，部分准备金制度如何演变？
- [ ] **负利率是合理的吗？** 欧洲日本曾实行负利率——"存钱要付钱"在哲学上意味着什么？（时间偏好可以为负？）
- [ ] **现代货币理论（MMT）能指导大国财政吗？** 它的边界条件（主权货币/浮动汇率/无外债）中国满足多少？
- [ ] **信用能否完全去中心化？** DeFi 试图用智能合约替代银行，但代码漏洞（闪电贷攻击）是否比银行监管更脆弱？
- [ ] **当 AI 主导信贷决策**，"信用评估"变成黑箱——算法歧视如何审计？信用的"社会知识"本质是否被破坏？
