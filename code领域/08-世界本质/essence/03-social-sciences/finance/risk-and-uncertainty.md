## 引言：金融学的核心维度

如果说金融学只有一句话要说，那就是：**"未来的钱不等于今天的钱"**。这句话之所以成立，不是因为时间的流逝，而是因为**未来是不确定的**。不确定性是金融学的时间之所以有价格的根因——人们要求风险溢价，是因为他们厌恶不确定。

但"不确定性"这个词太笼统。本章的核心任务，是把这个笼统的概念**拆开**：它至少有三层——

1. **风险**（Risk）：已知概率分布的不确定（可量化、可定价、可对冲）
2. **不确定性**（Uncertainty）：未知概率分布的不确定（不可量化、只能应对）
3. **黑天鹅**（Black Swan）：连"可能性"都未进入认知的不确定（彻底的认知盲区）

金融学的所有公式、所有危机、所有争论，本质上都在围绕这三层的边界打架。

> **一句话**：金融不是"管理风险"的学科——它是"**在不可量化的不确定中假装已经量化了风险**"的学科。这个假装，既创造了它的力量，也埋下了它所有灾难的种子。

## 一、Knight 的根本区分：风险 vs 不确定性

Frank Knight 在 1921 年的《Risk, Uncertainty and Profit》中做出了一个被后世反复引用、却总是被实践遗忘的区分：

### 风险（Risk）——可量化的不确定

- **定义**：结果不确定，但**所有可能结果及其概率分布已知**。
- **来源**：可重复的随机机制——掷骰子、轮盘赌、抛硬币、已校准的损失频率表。
- **可处理性**：可以计算期望值、方差、分位数；可以保险、对冲、定价。
- **本质**：风险是**认识论构造**——它"存在"于我们的模型里，不在物理世界里。世界上只有"发生"或"不发生"的事件；"概率 1/6"是我们加的标签。

### 不确定性（Uncertainty）——不可量化的不确定

- **定义**：结果不确定，**且概率分布未知甚至不可定义**。
- **来源**：独特、不可重复的事件——战争、革命、颠覆性技术、制度崩溃、范式转移。
- **不可处理性**：无法用频率逼近（因为事件不可重复），无法用历史校准（因为结构本身在变）。
- **Keynes 的呼应**（1937）："我们对未来的知识是**模糊的、不确定的**……关于一笔投资在若干年后的收益，我们没有科学基础可以计算其概率。"

### 黑天鹅（Black Swan）——Taleb 的第三层

Nassim Taleb 把 Knight 的"不确定性"又切了一刀：有些不确定性是"我们已知未知的"（知道有风险但算不准），但真正的黑天鹅是"**未知未知**"——

- **不可预测**：没有任何模型、任何人预见到了它。
- **影响巨大**：一旦发生，改变整个系统的格局。
- **事后合理化**：发生后，所有人都能编出一个"其实早有征兆"的故事。

> 黑天鹅的可怕不在于它概率低——而在于**在它发生之前，它甚至不在概率表里**。2008 次贷危机里的"CDO 集体违约"、2020 新冠的全球停摆，都不是"低概率事件被实现了"，而是"事件的类别本身没有被想象过"。

### 三者对比

| 维度 | 风险 Risk | 不确定性 Uncertainty | 黑天鹅 Black Swan |
|------|-----------|---------------------|------------------|
| 概率分布 | **已知** | 未知 | 连分布的"存在"都没被想到 |
| 可量化 | ✅ 完全可量化 | ❌ 只能应对，不能量化 | ❌❌ 事后才能命名 |
| 典型例子 | 轮盘赌、保险精算 | 战争、技术革命 | 2008 次贷、9/11、新冠 |
| 正确应对 | 对冲、分散、定价 | 留足缓冲、保持灵活 | **让自己不在乎它发生** |
| 金融学的处理 | 全套数学工具 | **假装成风险来处理**（原罪） | 用更肥的尾分布假装已建模 |

### 金融学的原罪

> 金融学的核心原罪是：**把不确定性假装成风险来处理。**

精算师对车祸死亡率用风险模型是合理的——因为有大量同质、可重复的样本。但用同样的方法去给 CDO 违约相关性定价，就是把 Knight 不确定性**降格**为风险——这正是 2008 的认识论根源。模型越精美，这个假装就越危险，因为它制造了**虚假的精确感**（参见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 极限 2）。

## 二、风险的度量

如果接受了"风险可量化"这个（有缺陷但有用）的框架，下一步就是：**用什么数字度量风险？** 不同的度量给出完全不同的"风险图景"。这里用三层讲解（直觉→数学→代码）逐一拆解。

### 2.1 方差 / 标准差（Markowitz）

- **直觉**：波动 = 风险。价格上蹿下跳的资产"风险大"。
- **数学**：σ² = E[(R − μ)²]，σ = √σ²。这是 Markowitz（1952）均值-方差框架的基石，也是整个现代投资组合理论的起点。
- **批判**：方差是**对称的**——大涨和大跌一样被算作"风险"。一个理性投资者真的厌恶"上涨的波动"吗？这是哲学锚点里"均方差自杀"思想实验的核心（见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 思想实验 3）。此外，方差依赖正态假设，对肥尾无能为力。

### 2.2 VaR（风险价值，Value at Risk）

- **直觉**：在 95%（或 99%）的置信下，**明天最多亏多少**。
- **数学**：VaR_α = −F⁻¹(1 − α)，其中 F 是损失分布函数，α 是置信水平。注意 VaR 本身是个分位数——它告诉你"损失不超过这个值"的概率是 α。
- **批判**：VaR 只回答"门在哪里"，不回答"门外的悬崖有多深"。它对尾部完全不敏感——99% VaR 之后亏 1% 还是亏 100%，VaR 看起来一样。Taleb 痛斥 VaR 是"把崩溃伪装成可控的数字"。

### 2.3 期望尾损失 ES / CVaR

- **直觉**：**如果倒霉落在了最坏的 5% 里，平均亏多少**？
- **数学**：ES_α = E[L | L ≥ VaR_α]，即超过 VaR 那部分的**条件期望**。它修复了 VaR"不管门外悬崖"的缺陷，是现代《巴塞尔协议 III》推荐替代 VaR 的度量。

### 2.4 最大回撤（Max Drawdown）

- **直觉**：从历史最高点到随后的最低点，**跌了多少**。
- **本质**：这才是投资者**真正肉痛**的数字。方差是抽象的，回撤是账户里实打实的缩水。一笔年化 10%、但中途回撤 60% 的投资，和一笔年化 8%、回撤 15% 的投资，体验天差地别。

### 2.5 下行风险 / Sortino 比率

- **直觉**：只把**下跌**算作风险，上涨不算。
- **数学**：Sortino = (R − r_f) / σ_down，其中 σ_down 只对低于目标收益的偏差开方。
- **意义**：这是对方差"对称性"缺陷的实用修正——它和 Markowitz 假设的理性人更一致。

### 代码层：一次性算出全部风险指标

```python
# === 风险度量全家桶 ===
# 一次性计算：方差、VaR、ES/CVaR、最大回撤、Sortino 比率
import numpy as np

np.random.seed(42)
# 模拟 252 个交易日的日收益率（近似标普 500：日均 0.04%，日波动 1%）
returns = np.random.normal(0.0004, 0.01, 252)

# --- 1. 方差 / 标准差 ---
variance = np.var(returns, ddof=1)
sigma = np.std(returns, ddof=1)

# --- 2. VaR（历史模拟法，95%）---
losses = -returns                       # 损失 = 负收益
var_95 = np.percentile(losses, 95)      # 95% 分位的损失
# 数学验证：VaR_α = -F⁻¹(1-α)，即收益分布的 5% 分位取负
var_95_check = -np.percentile(returns, 5)

# --- 3. ES / CVaR（超过 VaR 那部分的平均损失）---
es_95 = losses[losses >= var_95].mean()

# --- 4. 最大回撤 ---
cum_value = np.cumprod(1 + returns)     # 累计净值
running_max = np.maximum.accumulate(cum_value)
drawdown = (cum_value - running_max) / running_max
max_dd = drawdown.min()

# --- 5. Sortino 比率（只惩罚下行）---
target = 0.0
downside = returns[returns < target] - target
downside_dev = np.sqrt(np.mean(downside ** 2))
sortino = (returns.mean() - target) / downside_dev * np.sqrt(252)  # 年化

print("=== 同一组收益率的五种'风险'图景 ===")
print(f"标准差 σ (日)        : {sigma:.4f}  (= {sigma*100:.2f}%)")
print(f"VaR 95% (历史模拟)   : {var_95:.4f}  (= {var_95*100:.2f}%)")
print(f"  (check: -5% 分位)  : {var_95_check:.4f}")
print(f"ES / CVaR 95%        : {es_95:.4f}  (= {es_95*100:.2f}%)")
print(f"最大回撤             : {max_dd:.4f}  (= {max_dd*100:.2f}%)")
print(f"Sortino 比率 (年化)  : {sortino:.2f}")
print()
print("洞察：VaR 说'最多亏 ~1.5%'，但 ES 说'真倒霉会平均亏 ~1.8%'，")
print("      而最大回撤说'整个旅程中你会经历 ~14% 的缩水'——")
print("      同样的数据，不同的度量讲完全不同的故事。")
```

**验证结果**（在 essence 项目下用 bash 跑通，seed=42）：

```

标准差 σ (日)        : 0.0097  (= 0.97%)
VaR 95% (历史模拟)   : 0.0145  (= 1.45%)
  (check: -5% 分位)  : 0.0145
ES / CVaR 95%        : 0.0181  (= 1.81%)
```

> **洞察**：注意 ES（1.81%）总是 **大于** VaR（1.45%）——因为它衡量的是"越过门之后的平均深渊"。这就是为什么巴塞尔 III 用 ES 取代 VaR。

## 三、正态分布的陷阱——肥尾问题

风险度量的数学，几乎都假设收益率**服从正态分布**。这是金融学最致命的简化。

### 正态分布假设说了什么

- 3σ 事件概率 ≈ 0.27%，约**每年发生 1 次**（252 交易日 × 0.27% ≈ 0.68 次）。
- 4σ 事件概率 ≈ 0.006%，约**每 40 年 1 次**。
- 5σ 事件概率 ≈ 0.00006%，约**每 6800 年 1 次**。

### 现实说了什么

- 标普 500 有**数十个**超过 4σ 的单日波动——按正态分布本不该有。
- 1987 年黑色星期一：单日 **−22.6σ**。按正态分布，从宇宙大爆炸至今（138 亿年）都不会发生一次。
- 2008、2020、2022 都有远超正态预期的极端日。

**结论**：要么市场不服从正态分布，要么"σ"这个度量本身就崩溃了。Mandelbrot 选后者。

### Mandelbrot 的批判：狂野随机性

Benoît Mandelbrot（1963）在分析棉花价格后提出：金融收益服从**稳定帕累托分布**，其特征是——

- **方差可能无限**：σ² 发散。如果方差真的无限，整个 Markowitz 均值-方差框架、CAPM、Black-Scholes 全部失去数学地基。
- **极端事件是常态而非异常**：在"狂野随机性"（wild randomness）下，一个事件可以主导整个历史（"单一大局"效应）。
- **市场不是"温和的随机"（布朗运动），而是"狂野的随机"**——它更像地震（长期平静 + 突发巨震），而不是掷骰子。

金融学界的选择是：**假装方差有限**，因为承认方差无限就没法做生意了。这是一种刻意的认识论妥协。

### 代码层：正态 vs 学生 t 的极端事件频率对比

```python
# === 肥尾对比：正态分布 vs 学生 t 分布 ===
# 同样的"中等波动"，但极端事件频率天差地别
import numpy as np
import math

np.random.seed(7)
N = 10_000_000  # 一千万次抽样，看清极端事件的真实频率

# 正态分布：均值 0，标准差 1
normal = np.random.normal(0, 1, N)

# 学生 t 分布：自由度 df=3（典型的金融市场肥尾拟合）
# 同样缩放到标准差≈1，但尾巴厚得多
t_raw = np.random.standard_t(3, N)
t_scaled = t_raw / np.std(t_raw)

def prob_beyond(x, data):
    """超过 |x| 个标准差的事件频率"""
    return np.mean(np.abs(data) > x)

def normal_theory(s):
    """正态分布下 |X|>sσ 的双侧理论概率（用 erfc，数值稳定不溢出）"""
    return math.erfc(s / math.sqrt(2))

print("=== 事件发生频率对比（一千万次抽样）===")
print(f"{'σ 倍数':<10} {'正态(理论)':<14} {'学生t(df=3)':<14} {'倍数差':<14}")
print("-" * 52)
for s in [3, 4, 5, 6, 8, 10]:
    th = normal_theory(s)            # 理论值（稳定，不为零）
    pt = prob_beyond(s, t_scaled)    # 学生 t 的实测频率
    ratio = pt / th
    ratio_str = f"{ratio:.2e}x" if ratio >= 1e5 else f"{ratio:,.1f}x"
    print(f"{s:>3}σ       {th:<14.6%} {pt:<14.6%} {ratio_str:<14}")

print()
# 一个震撼的对比：-10σ 事件
print("=== -10σ 事件：两种分布告诉你的完全是两个世界 ===")
p_normal_10 = normal_theory(10) / 2   # 单侧（负方向）概率
print(f"正态分布下 -10σ 概率 : {p_normal_10:.2e}")
print(f"  → 意味着：每 {1/p_normal_10:.0e} 次抽样发生 1 次")
print(f"  → 按每天交易，需要 {1/p_normal_10/252:.0e} 年才见一次（宇宙年龄的 {1/p_normal_10/252/1.38e10:.0e} 倍）")
print()
# 学生 t(df=3)：用实际抽样估计
count_t10 = np.sum(t_scaled < -10)
freq_t10 = count_t10 / N
print(f"学生 t(df=3) 下 -10σ : 在 {N:,} 次抽样中实际发生 {count_t10} 次")
print(f"  → 估算频率 ≈ {freq_t10:.2e}（比正态高 {freq_t10/p_normal_10:.0e} 倍）")
print()
print("洞察：同一个'−10σ'，在正态分布里是'宇宙级不可能'，")
print("      在肥尾分布里只是'罕见但真实'。")
print("      你用哪个分布给风险定价，决定了你是安全还是 LTCM。")
```

## 四、塔勒布的三部曲——黑天鹅 / 随机漫步 / 反脆弱

Nassim Taleb 的思想是对上面所有问题的哲学总结。他的三部曲层层递进：

### 4.1 黑天鹅（The Black Swan, 2007）

**三个特征**：罕见（超出常规预期范围）、冲击巨大（改变历史轨迹）、事后可解释（"其实早有征兆"）。

> 核心命题：**历史不是缓慢爬行的，而是被少数几个黑天鹅事件塑造的。** 但人类的心智有"叙事谬误"——总想把随机事件编成必然的故事。这让我们对下一个黑天鹅毫无防备。

### 4.2 随机漫步的愚人（Fooled by Randomness, 2001）

**核心命题**：我们系统性地**高估技能、低估运气**。

- 一个交易员连续 5 年跑赢市场，是天才还是运气？Taleb 的算术：如果有 10000 个纯靠运气的交易员，每年一半赢一半输，5 年后必然有约 312 个"全胜冠军"——他们会被写成传奇，但本质是幸存者偏差。
- **启示**：在评价任何"成功"时，永远先问——**这个群体里有多少人？幸存者有几个？** 不看基数谈成绩，就是被随机性愚弄。

### 4.3 反脆弱（Antifragile, 2012）

这是最深刻的一层。Taleb 区分了三类系统：

| 类型 | 面对冲击的反应 | 例子 |
|------|---------------|------|
| **脆弱**（Fragile） | 受损、破裂 | 玻璃杯、高杠杆银行 |
| **坚韧**（Robust） | 不变、抵抗 | 石头、凤凰（重生为原样） |
| **反脆弱**（Antifragile） | **变得更强** | 肌肉、免疫系统、神话的九头蛇 |

> **核心洞察**：最优策略不是"预测并避免黑天鹅"（不可能），而是**让自己从黑天鹅中受益**。反脆弱系统的特征是**凸性**——损失有下界（有限），收益无上界。

### 杠铃策略（Barbell Strategy）

反脆弱在投资中的具体化：

- **一端 85-90% 极度安全**（国债、现金）——保证下界，确保任何冲击都不能让你出局。
- **另一端 10-15% 极度冒险**（期权、风投、不对称赌注）——捕捉上界，让黑天鹅成为收益而非损失。
- **避开中间**：中庸的"中等风险"资产既没有安全的下界保护，又没有冒险的上界机会——它是**脆弱**的。

### essence 立场

> **不要试图预测黑天鹅，而要让自己不在乎黑天鹅。**

这与第六节的凯利公式、第五节的前景理论形成闭环：风险管理的高阶形态不是"算准概率"，而是"设计一个让概率算不算都无所谓的位置"。

## 五、风险偏好与决策

度量了风险，还要决定**如何在风险下选择**。这是决策理论的领域。

### 5.1 期望效用理论（von Neumann-Morgenstern, 1944）

- **核心**：人不是最大化期望金钱 E[X]，而是最大化期望效用 E[U(X)]。
- **数学**：E[U] = Σᵢ pᵢ · u(xᵢ)，其中 u(·) 是效用函数。
- **风险厌恶的数学定义**：u''(x) < 0（**凹效用函数**）——边际效用递减。赚第二个 100 万的快乐 < 赚第一个 100 万的快乐。
- **地位**：这是理性决策的"标准模型"，整个金融学的基石。但它的公理假设（独立性公理等）已被实验反复证伪。

### 5.2 圣彼得堡悖论（1713）——期望值为什么不够

> 抛硬币，第 n 次才出现正面就付 2ⁿ 元。期望收益 = Σ 2ⁿ · (1/2)ⁿ = **∞**。但没人愿意付 100 元玩。

这个悖论催生了效用理论：人类用 **u(x) = log(x)**（对数效用）或更一般的凹函数评估赌局，于是无穷期望被压成了有限值。伯努利的解法就是期望效用的雏形。

### 5.3 前景理论（Kahneman-Tversky, 1979）——理性的真正颠覆

Kahneman 和 Tversky 用实验发现人类决策**系统性偏离**期望效用，并提出前景理论：

1. **价值函数**以**参照点**（而非绝对财富）为原点——人感受的是"赚了/亏了"，不是"现在有多少"。
2. **损失厌恶**：损失段的斜率约为收益段的 **2.25 倍**——亏 100 元的痛苦 ≈ 赚 225 元的快乐。
3. **概率权重非线性**：小概率被高估（买彩票），中大概率被低估（买保险的另一方面）。

**价值函数的数学形式**：

```
v(x) = x^α           若 x ≥ 0  （收益）
v(x) = −λ · (−x)^β   若 x < 0  （损失）
```

其中 α = β ≈ 0.88（凹性），λ ≈ 2.25（损失厌恶系数）。

### 代码层：前景理论价值函数

```python
# === 前景理论价值函数：可视化损失厌恶 ===
# Kahneman-Tversky (1979) 的参数标定
import numpy as np
import matplotlib
matplotlib.use('Agg')  # 无显示环境也能保存
import matplotlib.pyplot as plt

alpha = 0.88   # 收益段曲率（凹）
beta = 0.88    # 损失段曲率
lam = 2.25     # 损失厌恶系数

x = np.linspace(-100, 100, 400)
v = np.where(x >= 0, x**alpha, -lam * (-x)**beta)

# 对比：传统理性效用（对称、无损失厌恶）
u_symmetric = np.where(x >= 0, x**alpha, -(-x)**beta)

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, v, 'r-', lw=2.5, label=f'前景理论 v(x)  (λ={lam})')
ax.plot(x, u_symmetric, 'b--', lw=1.5, label='对称效用 (无损失厌恶, λ=1)')
ax.axhline(0, color='gray', lw=0.5)
ax.axvline(0, color='gray', lw=0.5)
ax.set_xlabel('收益 / 损失 x（相对参照点）', fontsize=12)
ax.set_ylabel('主观价值 v(x)', fontsize=12)
ax.set_title(f'前景理论价值函数 · 损失厌恶 λ = {lam}\n'
             f'亏 100 的痛苦 ({lam*100**beta:.0f}) ≈ 赚 {lam*100:.0f} 的快乐', fontsize=13)
ax.legend(fontsize=11)
ax.annotate('损失段\n（更陡）', xy=(-50, -lam*50**beta), fontsize=11, color='darkred',
            xytext=(-80, 30), arrowprops=dict(arrowstyle='->', color='darkred'))
ax.annotate('收益段\n（平缓）', xy=(50, 50**alpha), fontsize=11, color='darkgreen',
            xytext=(20, -40), arrowprops=dict(arrowstyle='->', color='darkgreen'))
plt.tight_layout()
plt.savefig('/tmp/opencode/prospect_theory.png', dpi=100)
print("图表已保存: /tmp/opencode/prospect_theory.png")

# 数值验证损失厌恶
print(f"\n=== 损失厌恶的数值验证 ===")
for amt in [10, 50, 100]:
    gain = amt**alpha
    loss = lam * amt**beta
    print(f"±{amt:>4}: 收益价值 v(+{amt}) = {gain:>7.2f} | "
          f"损失价值 v(-{amt}) = {loss:>7.2f} | "
          f"损失/收益 = {loss/gain:.2f}x")
print("\n洞察：无论金额大小，损失的痛苦恒为收益快乐的 2.25 倍。")
print("      这就是为什么人们会'止损难'——卖掉浮亏等于把痛苦坐实。")
```

**验证结果**（α=β=0.88, λ=2.25，Kahneman-Tversky 标定）：

```
图表已保存: /tmp/opencode/prospect_theory.png

=== 损失厌恶的数值验证 ===
±  10: 收益价值 v(+10) = 7.59  | 损失价值 v(-10) = 17.07 | 损失/收益 = 2.25x
±  50: 收益价值 v(+50) = 31.27 | 损失价值 v(-50) = 70.35 | 损失/收益 = 2.25x
± 100: 收益价值 v(+100) = 57.54| 损失价值 v(-100) = 129.47| 损失/收益 = 2.25x
```

> 这个 2.25 倍不仅是实验室数字——它解释了金融中"处置效应"（卖赢持亏）、"股权溢价之谜"（股票回报远高于无风险利率所需的补偿）等核心异象。人不是不理性，而是用一套**不同的**理性在决策。

## 六、凯利公式——最优下注

在有利赌局中，**应该下注多少**？这是赌博、投资、乃至生物学"最优增长"的核心问题。

### 直觉层

假设一个赌局：60% 概率翻倍你的下注，40% 概率归零。期望值是正的——那你该全押吗？

**不。** 全押意味着有 40% 概率**直接破产出局**，再也没机会翻本。即使期望值高，一次清零就终结了游戏。**最优下注要让长期财富增长率最大化，而非单次期望值最大化。**

### 数学层

Kelly 公式（1956）：

```
f* = (b·p − q) / b
```

- `p` = 胜率，`q = 1 − p` = 败率
- `b` = 赔率（赢时净赚 b 倍下注）
- `f*` = 最优下注比例（占当前总财富）

证明思想：最大化对数财富的期望 E[log(W)]。对数是凹函数，它天然惩罚"清零"（log(0) = −∞）。这把第五节的"凹效用"和"避免出局"统一起来。

### 凯利 vs 期望值

- **期望值最大化**：会建议在有正期望时"尽量多押"——但它忽略破产风险。
- **凯利最大化**：考虑了**几何增长**（复利）和**破产约束**——它告诉你"押多少才不会死在半路"。
- **半凯利（half-Kelly）**：实践中常用一半的 f*，牺牲一点增长率换取大幅降低的波动和回撤——这是反脆弱精神的应用。

### 代码层：凯利 vs 全押 vs 半凯利的财富曲线

```python
# === 凯利公式模拟：1000 轮下注，对比三种策略 ===
import numpy as np

# 赌局：60% 概率赢（赔率 1:1，赢翻倍下注），40% 输（失去下注）
p_win = 0.60
b = 1.0                       # 赔率 1:1
q = 1 - p_win
f_kelly = (b * p_win - q) / b # 凯利公式
print(f"凯利最优比例 f* = ({b}·{p_win} − {q}) / {b} = {f_kelly:.4f}")
print(f"  → 每轮下注总财富的 {f_kelly*100:.1f}%\n")

np.random.seed(2024)
N_ROUNDS = 1000
N_PATHS = 100                  # 模拟 100 条平行世界

strategies = {
    '全押 (f=1.0)': 1.0,
    '凯利 (f*=0.2)': f_kelly,
    '半凯利 (f=0.1)': f_kelly / 2,
}

# 记录每条路径的最终财富
for name, f in strategies.items():
    final_wealths = []
    for path in range(N_PATHS):
        wealth = 100.0
        outcomes = np.random.random(N_ROUNDS) < p_win
        for win in outcomes:
            bet = wealth * f
            wealth += bet * b if win else -bet
            if wealth <= 1e-10:   # 破产
                wealth = 0
                break
        final_wealths.append(wealth)
    finals = np.array(final_wealths)
    median = np.median(finals)
    p10 = np.percentile(finals, 10)        # 倒霉的 10%（不是均值——乘法过程下均值被彩票赢家扭曲）
    n_bankrupt = np.sum(finals <= 1e-10)
    print(f"{name:<20}: 中位数 {median:>16,.0f} | 10%分位 {p10:>14,.0f} | 破产 {n_bankrupt:>3}/{N_PATHS}")

print("\n=== 一条典型路径的前 10 轮（凯利策略）===")
np.random.seed(1)
wealth = 100.0
for i in range(10):
    win = np.random.random() < p_win
    bet = wealth * f_kelly
    wealth = wealth + bet if win else wealth - bet
    print(f"  第{i+1:>2}轮 {'赢' if win else '输'}: 下注 {bet:>7.2f} → 总财富 {wealth:>8.2f}")

print(f"\n洞察：")
print(f"  - 全押必死：有 40% 概率每轮清零，1000 轮后几乎必破产。")
print(f"  - 凯利长期增长率最大，财富呈指数爆炸（复利威力）。")
print(f"  - 半凯利牺牲部分增长率，换回更小的回撤——更反脆弱。")
print(f"  - 注意：乘法过程下不要看算术均值（被极端赢家拉爆），")
print(f"    中位数和 10% 分位才是真实体验。")
```

**验证结果**（seed=2024，1000 轮 × 100 条平行世界，初始财富 100）：

```
凯利最优比例 f* = (1.0·0.6 − 0.4) / 1.0 = 0.2000
  → 每轮下注总财富的 20.0%

全押 (f=1.0)         : 中位数              0 | 10%分位              0 | 破产 100/100
凯利 (f*=0.2)        : 中位数 187,506,446,107 | 10%分位     53,255,864 | 破产   0/100
半凯利 (f=0.1)       : 中位数     378,767,198 | 10%分位      7,529,420 | 破产   0/100
```

> **全押 100/100 全部破产**——这是本章第二组该记住的数字。期望值为正的赌局，下注方式错了照样归零。凯利公式的本质不是"赚多少"，而是"**如何在有利局面中活到复利起作用**"。凯利中位数高达约 1870 亿（1000 轮复利的有边赌局确实爆炸性增长），半凯利虽"只有"约 3.8 亿，但 10% 分位（倒霉情况）仍高达 750 万——它用更小的波动换来了几乎不会触底的稳健性。这和 Q15 的核心问题（长期主义 vs 当下生存）直接相通。

## 七、系统性风险 vs 个别风险

### 分散化的逻辑

Sharpe 的 CAPM 把风险劈成两半：

- **非系统性风险**（idiosyncratic）：公司特定——CEO 出轨、工厂火灾、单品失败。**可分散**——持有足够多不相关的股票，这类风险互相抵消。
- **系统性风险**（systematic）：市场整体——经济衰退、利率冲击、流动性枯竭。**不可分散**——所有资产同时受冲击。

> 市场只奖励你承担**不可分散**的系统性风险。可分散的风险没有溢价——因为理性的投资者都会把它分散掉。这就是为什么"分散化是金融里唯一的免费午餐"（Markowitz）。

### 分散化的失效——相关性在崩盘时趋近 1

分散化依赖一个假设：资产间相关性低。但危机的特征恰恰是——**所有相关性在崩盘时都趋近 1**。

- 平时：股票和债券负相关（分散有效）、不同行业股票低相关。
- 危机时：流动性枯竭，所有资产被同时抛售（投资者要现金，卖什么不看），相关性 → 1，分散化**瞬间失效**。
- 2008：原本"安全"的分散组合和大盘一起跌，因为 CDO 的违约相关性在崩盘时从 0.3 跳到 0.9。

### 系统性风险的度量

| 度量 | 含义 | 局限 |
|------|------|------|
| **β**（CAPM） | 个股相对市场的敏感度 | 只捕捉线性、平稳期关系 |
| **CoVaR**（Adrian-Brunnermeier） | 某机构陷困时**整个系统**的 VaR | 仍是分位数，尾部盲 |
| **SRISK**（Acharya-Engle） | 机构在危机中**缺多少资本** | 依赖模型假设 |

> **本质洞察**：系统性风险的根源是**网络结构**——谁欠谁多少、连锁反应如何传导。这是复杂系统科学的领地（见 [`06-systems/complexity/`](../../06-systems/complexity/)）。单个机构看起来安全，但它是网络的关键节点——它倒下会拖垮一片。这是 2008 雷曼问题的核心：问题不在雷曼本身的 VaR，而在它是衍生品网络的枢纽。

## 八、跨学科映射

风险与不确定性的概念，在 essence 项目的其他学科里有精确的同构：

| 金融概念 | 物理 / 信息论 | 生物学 | 系统科学 | 认识论 / 哲学 |
|---------|--------------|--------|---------|-------------|
| **风险**（可量化） | 测量误差、热涨落 | 孟德尔分离比 | 可参数化的噪声 | 频率学派概率 |
| **不确定性**（不可量化） | 复杂系统相变 | 演化的突变、遗传漂变 | 不可预测的涌现 | 贝叶斯主观概率 |
| **黑天鹅** | 地震、相变临界点 | 物种大灭绝（K-T） | 临界雪崩 | 库恩范式转移 |
| **肥尾** | 自组织临界（沙堆） | 物种丰度分布 | 幂律（无标度网络） | 归纳问题（休谟） |
| **反脆弱** | —— | 免疫系统、肌肉超量恢复 | 强化学习（exploration） | 黑格尔辩证（正反合） |
| **凯利公式** | 最大熵原理 | 自然选择（费舍尔方程） | 几何增长 vs 算术增长 | 贝叶斯更新（对数似然） |
| **系统性风险** | —— | 生态崩溃（关键种灭绝） | 级联失效 | —— |
| **杠铃策略** | —— | r/K 选择策略（r 繁殖 + K 存活） | 冗余设计 | 极端斯坦 vs 平均斯坦 |

> 最深的同构：**凯利公式 = 自然选择**。生物进化中，最大化对数适应度（= 几何平均增长率）的基因型胜出——这和凯利最大化 E[log W] 是**同一个数学**。生命本身就是一个执行凯利策略的赌徒：它不会全押（否则一次灭绝），而是用"过度繁殖 + 选择"在不破坏种群的前提下探索可能性空间。这是反脆弱的生物学根基。

## 九、局限与开放问题

### 内在局限

1. **风险 vs 不确定性的边界本身不确定**——一个事件到底属于 Knight 风险还是 Knight 不确定性，没有客观裁判（见 [`_philosophy-of-finance.md`](./_philosophy-of-finance.md) 极限 2）。
2. **所有度量都依赖历史**——但黑天鹅的定义就是"历史里没有的"。用历史 VaR 预测下次危机，是用后视镜开车。
3. **肥尾分布的参数也难估计**——学生 t 的自由度 df 极难从数据精确拟合，因为它本身就由最极端的少数样本决定（而这些样本太少）。

### 开放问题

- [ ] **概率是客观的还是主观的？**（Q14）频率学派 vs 贝叶斯学派之争，在金融里有实打实的后果。
- [ ] **黑天鹅真的不可预测吗？** 还是说"不可预测"只是我们认识论无能的借口？复杂系统的临界信号（early warning signals）能否预警相变？
- [ ] **反脆弱能被工程化吗？** 还是说它只能事后识别、无法事前设计？
- [ ] **当市场主要由 AI 交易时，肥尾会变胖还是变瘦？** 算法的同质化制造尾部（2008/LTCM），还是算法的异质化吸收尾部？
