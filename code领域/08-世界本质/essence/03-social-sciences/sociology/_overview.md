# 社会学总体框架 · Sociology Overview

> 社会学回答：**为什么很多人的行为放在一起，会形成个人无法决定的社会规律？**  
> 心理学研究"一个人"，社会学研究"很多人在一起形成的新规律"。

---

## 核心模型

```
个体 → 互动 → 群体 → 组织 → 制度 → 社会 → 文明
  ↑                                              │
  └──────── 社会反过来塑造个体 ←─────────────────┘
```

> 社会学研究的是：**个体如何形成社会，社会又如何反过来影响个体。**

---

## 六层研究对象

| 层次 | 研究什么 | 核心问题 |
|------|---------|---------|
| 个体 | 社会环境中的个人 | 为什么不同社会的人行为不同？ |
| 互动 | 人与人之间的交换 | 合作/竞争/冲突/信任如何产生？ |
| 群体 | 互动形成的集体 | 群体规范如何塑造个体？ |
| 组织 | 有规则的群体 | 权力/分工/激励如何运作？ |
| 制度 | 稳定的规则系统 | 陌生人为什么能信任？ |
| 社会 | 制度的总和 | 经济/政治/文化如何共同运行？ |

## 知识体系

```
社会学
├── 一、社会基础（个体/互动/群体/社会化）
├── 二、社会结构（阶层/网络/组织/制度）
├── 三、社会运行（文化/权力/市场/社会控制）
├── 四、社会变迁（工业化/城市化/全球化/数字化/AI）
└── 五、应用（教育/城市治理/公共政策/企业组织/社会创新）
```

## 方法论

```
提出问题 → 假设 → 收集数据 → 分析规律 → 建立理论 → 政策建议
```

| 方法 | 用途 |
|------|------|
| 问卷调查 | 群体态度/价值观 |
| 深度访谈 | 个体经验/社会意义 |
| 参与式观察 | 长期观察群体 |
| 社会网络分析 | 关系结构 |
| 比较研究 | 跨国家/跨时期 |
| 大数据分析 | 社交媒体/人口/流动 |

## 费曼比喻：社会=分布式网络系统

| 子系统 | 社会学 | 职能 |

| 节点 | 个体 | 有目标和资源 |
| 信息交换 | 互动 | 协作/竞争 |
| 局部网络 | 群体 | 家庭/团队/社区 |
| 子系统 | 组织 | 有规则的功能单元 |
| 通信协议 | 制度 | 保障系统稳定 |

| 系统升级 | 社会变迁 | 技术/人口驱动调整 |

## 在认知科学链条中的位置

```
哲学 → 心理学 → 神经科学 → 认知科学 → 语言学 → 数学 → 逻辑学
  → 社会学：共享的认知如何形成文化、制度和社会  ← 这里
  → 政治学/经济学/法学：不同社会系统如何运行
```

> 社会学把"认识"从个人层面扩展到群体和社会层面。
