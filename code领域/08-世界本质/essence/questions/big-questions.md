# 大问题清单 · Big Questions

> "在一个信息极其丰富的世界里，**提问的能力**比回答的能力更稀缺、更有价值。"  
> — 一个 AI 也同意的话

这份清单是整个项目的**引擎**。每一条都是用户（你）愿意花数月甚至数年反复追问的问题。

**规则**：
- 不要急着回答。先让问题在你脑子里发酵。
- 每个问题后面会慢慢长出笔记、代码、洞察、跨学科映射。
- 一个问题被"想通了"不是终点——而是产生新问题的起点。
- 用 [`/question`](../../.config/opencode/command/question.md) 命令对任意问题做苏格拉底式深挖。

## 🔥 第一性原理层（最根本的"是什么"）

### Q1. 现实的本质是什么？
- 物理世界是**离散**的还是**连续**的？（量子力学 vs 经典）
- 数学是**被发现**的还是**被发明**的？（柏拉图主义 vs 形式主义）
- 信息是**物理的**吗？（Landauer 原理：擦除 1 bit 信息需要消耗 $kT\ln 2$ 的能量）
- **观察者**在现实中扮演什么角色？（量子力学测量问题、人择原理）

**关联**：`01-natural-sciences/physics/`、`02-formal-sciences/information-theory/`、`04-humanities/philosophy/metaphysics.md`

### Q2. "本质"本身是什么？
- 当我们说"X 的本质是 Y"时，我们在说什么？

- 本质 = **最小充分条件**（去掉它就不成立的最少要素）？
- 本质 = **生成器**（从它能生成所有表象）？
- 不同学科对"本质"的定义一致吗？

**关联**：`04-humanities/philosophy/`、`00-meta/first-principles.md`

## 🚀 如何使用这份清单

### 每周仪式

1. **周一**：从清单里选 1 个问题，作为本周的"背景问题"——不刻意想，但允许它在不经意间冒出来。
2. **周中**：把和这个问题相关的任何想法、对话、阅读，记进 `insights/`。
3. **周末**：写一段总结——这周我对这个问题有没有进展？哪怕是"我又发现了自己哪里不懂"也算。
4. **更新清单**：把本周**新生**的问题加进清单。

### 选问题的心法

- **选让你兴奋的**，不选"应该"懂的。
- **选你能在洗澡时反复想的**，不选需要查 10 本书才能开始的。
- **选你能跟朋友争论的**，不选纯学术的。
- **宁深勿广**：1 个问题想透 > 10 个问题浅尝。

### 一个问题的"想通了"标准

- 能用大白话讲给外行听，对方点头。
- 能在 `concept-3layer` 模板下写完整三层。
- 能找到至少 3 个跨学科的对应物。
- 能在笔记里**主动指出它的局限和反例**。
- **它产生了至少 2 个新的、更深的问题**。
