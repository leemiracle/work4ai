# 认识学科学地图 · Science of Knowing

> 不是一门单独的学科，是跨学科领域——研究"人如何认识世界"的所有学科体系。  
> 建立在 essence 项目的全部基础之上：哲学（00-philosophy）提供工具，思想家库提供视角，10-china/11-world 提供"被认识的对象"。

---

## 核心问题

> **人如何从现实世界获得可靠知识？**

认识 ≠ 学知识。认识 = 感知→建模→推理→验证→修正的闭环。

```
现实世界
     │
感知（Perception）
     │
理解（Understanding）
     │
推理（Reasoning）
     │
判断（Judgement）
     │
行动（Action）
     │
反馈（Feedback）
     │
修正认识（Learning）← 回到感知（闭环）
```

## 学科协同：认识的闭环

```
现实世界
    │
感知 ← 心理学、神经科学
    │
表征 ← 语言学、信息科学
    │
建模 ← 数学、系统科学
    │
推理 ← 逻辑学、人工智能
    │
判断 ← 哲学、认知科学
    │
行动 ← 社会学、教育学
    │
反馈 ← 实验、实践
    │
修正 ← 科学方法
    ↺（回到感知）
```

|------|------|------|

| 硬件部 | 神经科学 | 研究大脑如何运作 |
| 流程设计 | 认知科学 | 设计整个认知流程 |

| 法务部 | 逻辑学 | 确保推理正确 |
| AI部 | 人工智能 | 让机器也具备认知能力 |
| 组织行为 | 社会学 | 社会环境如何影响认知 |
| 国际部 | 人类学 | 比较不同文化的认知方式 |

### 认识学回答 essence 的大问题

| 大问题 | 认识学的回答 |
|--------|------------|
| Q1 现实的本质 | 感知+建模+验证→逼近现实（但物自体不可知？康德） |
| Q2 "本质"是什么 | 本质=不变量=模型中不变的量（数学定义） |
| Q3 什么是智能 | 感知→建模→推理→行动→反馈的闭环能力 |
| Q4 学习的本质 | 反馈→修正模型→再感知的循环（正循环！） |
| Q5 意识的本质 | 认识的"主观面"——目前认识学无法完全解释 |
| Q21 我如何知道自己错了 | 可证伪性（波普尔）+ 反馈机制 + 元认知 |
| Q22 语言如何塑造思维 | 语言=认知的编码系统→编码塑造能想到什么 |
