# 语言学总体框架 · Linguistics Overview

> 语言学回答：**语言是什么？它如何产生、组织、理解、传播，并支撑人类认知与社会交流？**  
> 研究的不是某一种具体语言（汉语/英语），而是**语言这一系统**。

---

## 核心模型：语言=信息系统

```
思想 → 概念形成 → 语言编码 → 声音/文字/手语 → 信息传递 → 语言解码 → 概念重建 → 理解
```

> 语言学研究的是：**思想如何变成语言，语言如何再次变成思想。**

---

## 六大核心模块

```
思想
 ↓
```

## 在认知科学链条中的位置

```
      哲学：什么是真实/知识？
           ↓
    心理学：认知有什么规律？
           ↓
  神经科学：大脑如何实现？
           ↓
 认知科学：认知如何统一工作？
           ↓
  语言学：认知如何编码为可共享的信息？  ← 这里
           ↓
   社会交流：人与人共享知识
           ↓
  教育/文化/科学发展
```

> 语言学连接了**思维**（认知科学）、**大脑**（神经科学）、**社会**（社会语言学）和**机器**（NLP）。
