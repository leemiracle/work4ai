# 人类学总体框架 · Anthropology Overview

> 人类学回答：**人为什么会成为今天的人？不同社会为什么形成不同的文化、制度和生活方式？**  
> 研究的不是某个国家或时代，是**整个人类**——从远古到现代，从部落到互联网。

---

## 核心特点：整体性（Holism）

```
                  人（Human）
                       │
      ┌────────┼────────┐
      │        │        │
   生物进化   文化形成   社会组织
      │        │        │
      └────────┼────────┘
               ▼
         人类文明的发展
```

> 社会学关注现代社会运行，人类学关注人类整体及其文化、演化和多样性。

## 核心方法：田野调查

```
提出问题 → 进入田野 → 参与观察 → 访谈 → 整理资料 → 建立解释
```

| 方法 | 特点 |
|------|------|
| 参与式观察 | 长期融入当地生活 |
| 深度访谈 | 理解价值观和经验 |
| 民族志 | 对群体的整体描述 |
| 比较研究 | 跨文化比较 |
| 考古分析 | 重建历史社会 |
