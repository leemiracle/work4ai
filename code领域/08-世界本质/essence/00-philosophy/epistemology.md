# 认识论 · Epistemology

> **"我们如何知道？什么是知识？什么使我们有权相信？"**  
> — 哲学的第二大支柱（仅次于本体论）

---

## 直觉层

**认识论 = 关于知识本身的研究**。

它问的不是"你知道什么"（那是各学科内容），而是更根本的：**"知道"这件事本身是什么？它如何可能？它的边界在哪？**

### 为什么这个问题无法回避

你说"地球绕太阳转"——你**怎么知道**的？
- 你没亲眼看过（即便看过，眼睛可靠吗？）
- 你相信科学家——但科学家之间曾经争论过（地心说 vs 日心说）
- 你相信证据——但什么样的证据算"足够"？
- 你相信推理——但归纳法为何合法？（休谟问题）
- 最终你相信你的**认知能力**——但它从哪来？可靠吗？会不会被系统性欺骗（缸中之脑）？

每一步追问都把"知识"的地基翻出来。

---

## 核心问题清单

### Q1. 什么是"知识"？（Knowledge）

**传统定义（柏拉图）**：知识 = 证成的真信念 (Justified True Belief, JTB)

$$K = JTB$$

- 你相信 P（信念）
- P 是真的（真）
- 你有理由相信 P（证成）

**Gettier 问题 (1963)**：JTB 不充分！
- 案例：你看了一眼表，显示 3:00。你相信"现在 3:00"。但其实表停了，只是恰好现在真的是 3:00。
- 你的信念**真**，也**有证成**（看了表），但这**不算知识**——你只是碰巧对了。

50 多年来哲学家尝试各种修补：
- **因果论**：事实必须因果地导致信念
- **可靠性论**：信念必须由可靠的过程产生
- **美德认识论**：信念必须来自认知美德
- **无知论**：放弃定义，转而刻画"知识"的家族相似性

### Q2. 知识的来源

| 来源 | 可靠性辩论 | 代表 |
|------|-----------|------|
| **感知** | 错觉、梦、缸中之脑 | 洛克、休谟 |
| **理性** | 理性能发现必然真理？ | 笛卡尔、莱布尼茨 |
| **记忆** | 记忆可靠吗？ Elizabeth Loftus | |
| **证词** | 我们大部分知识来自他人——何时可信？ | C.A.J. Coady |
| **直觉** | 哲学直觉是证据吗？ | 实验哲学挑战 |

### Q3. 归纳问题（休谟问题，最经典）

**问题**：观察到 1000 只天鹅是白色，凭什么推断第 1001 只也是白色？

- 你说"因为自然规律是统一的"——但你怎么知道自然规律是统一的？
- 你说"过去一直如此"——但用"过去"推理"未来"本身就是归纳，循环了！
- 休谟的解法：归纳是**习惯**，不是逻辑必然。理性无法证成归纳。

**现代回应**：
- **概率归纳**（贝叶斯）：归纳是合理的概率更新——但仍依赖先验
- **最佳解释推理**（IBE）：归纳本质是"找最能解释现象的假设"
- **自然化认识论**（Quine）：不要追问"归纳为何合法"，而要研究"人类实际如何归纳"

### Q4. 真理理论

| 理论 | 主张 | 困境 |
|------|------|------|
| **符合论** | 真理 = 与事实符合 | 什么是"事实"？符合关系如何定义？ |
| **融贯论** | 真理 = 与信念系统融贯 | 一致的小说也可融贯但全假 |
| **实用论** | 真理 = 在实践中管用 | "管用"标准模糊；可能有用而假 |
| **冗余论** | "P 是真的" = "P" | 没解释真理的概念角色 |
| **最小论** | 真理是同义反复 | 同上 |

### Q5. 我们能"知道"外部世界吗？

**怀疑论的几个层次**：
1. **错觉怀疑**：感官会欺骗（远处的弯曲棍子）
2. **梦境怀疑**：你怎么知道现在不是在做梦？（庄子/笛卡尔）
3. **恶魔怀疑**：全能恶魔可能系统性欺骗你（笛卡尔）
4. **缸中之脑**：你可能是被实验室电极刺激的脑（Putnam）
5. **模拟假说**：我们可能生活在计算机模拟中（Bostrom）

**回应策略**：
- **笛卡尔**：我思故我在——至少"我在怀疑"这件事不可怀疑
- **摩尔**：常识辩护——"这里有一只手"比任何哲学论证都更确定
- **先验论证**（Strawson, Davidson）：怀疑本身预设了不可怀疑的东西
- **实用主义**：怀疑论"理论上"可能，但实践上无法生活，所以无意义
- **语义学反驳**（Putnam）：缸中之脑说"我是缸中之脑"是自指悖论——它说的"脑"不是真正的脑

### Q6. 科学知识特别吗？

**Logical Positivism**（维也纳学派，1920s）：科学命题有意义，形而上学命题无意义
- 困境：这个标准本身是形而上学的

**Popper**：科学 = 可证伪的，不是可证实的
- 困境：可证伪性也是模糊的（任意理论都能用 ad hoc 假设躲避反例）

**Kuhn**：科学不是线性进步，而是**范式转移**
- 困境：相对主义嫌疑（"范式之间不可通约"）

**Lakatos**：科学研究纲领（硬核 + 保护带）
**Feyerabend**：科学方法论是"anything goes"——反对方法

## 数学层

### 贝叶斯认识论（现代认识论的数学化）

**核心**：把"信念强度"概率化，"学习" = 贝叶斯更新。

**先验** $P(H)$：你对假设 $H$ 的初始信心  
**似然** $P(E|H)$：若 $H$ 真，观察到 $E$ 的概率  
**后验** $P(H|E)$：观察到 $E$ 后对 $H$ 的信心

$$P(H|E) = \frac{P(E|H) \cdot P(H)}{P(E)}$$

**贝叶斯主义主张**：理性认识就是按贝叶斯规则更新信念。

**对它的批评**：
- **先验主观性**：先验从哪来？不同先验可能给出不同后验
- **计算不可行**：人类心智不可能真做贝叶斯计算
- **老证据问题**：$E$ 早于 $H$ 已知时，$P(E|H) = P(E) = 1$，后验不变——但老证据应支持 $H$（如水星近日点支持广义相对论）

**贝叶斯主义回应**：规范 ≠ 描述。理性应该如何，不等于人类实际如何。

## 代码层：贝叶斯认识论演示

```python
import numpy as np

def bayes_update(prior, likelihood_e_h, likelihood_e_not_h):
    """贝叶斯更新：给定先验 P(H) 和似然，返回后验 P(H|E)"""
    p_e = likelihood_e_h * prior + likelihood_e_not_h * (1 - prior)
    posterior = (likelihood_e_h * prior) / p_e
    return posterior

print("=== 案例：医学诊断中的贝叶斯 ===")
print("病: 罕见病, 发病率 1/1000")
prior = 1/1000
print(f"先验 P(病) = {prior:.4f}")
print("检测: 灵敏度 99% (真阳性率), 假阳性率 5%")
likelihood_e_h = 0.99   # P(+|病)
likelihood_e_not_h = 0.05  # P(+|无病)
posterior = bayes_update(prior, likelihood_e_h, likelihood_e_not_h)
print(f"检测阳性后 P(病|+) = {posterior:.4f}")
print(f"（直觉以为是 99%，实际只有 ~2%！这就是基本率忽视）")
print()
print("洞察：'证据'的强度取决于先验。这解释了为什么'科学共识'比")
print("      '单一惊人结果'更可信——前者有大量累积的先验支撑。")
```

实际跑一下，预期输出：阳性后 P(病|+) ≈ 0.0194——直觉以为是 99%，实际只有 ~2%！这就是**基本率忽视**，是认识论 + 概率论的经典交叉。

## 跨学科映射

| 学科 | 认识论问题 | 主流立场 |
|------|-----------|---------|
| **物理学** | 实在论 vs 工具主义（理论实体真实存在吗？） | 工作实在论（多数物理学家） |
| **数学** | 数学真理是发现还是发明？ | 柏拉图主义 vs 形式主义 |
| **CS / AI** | 模型学到的"知识"是真知识吗？ | 表征主义 vs 工具主义 |
| **生物学** | 演化是"真"的还是"最有用的解释"？ | 几乎一致接受实在论 |
| **历史学** | 历史真相可知吗？客观性可能吗？ | 解释学、相对主义争论 |
| **经济学** | 经济理论指称真实还是构造？ | 实在论 vs 社会构造论 |

## 局限与反例

- **怀疑论可以走太远**：缸中之脑逻辑可能，但实用上无意义——任何行动都预设外部世界
- **贝叶斯主义的先验问题**：合理先验如何确定？这是认识论持续争论
- **可证伪性不是清晰的二分**：Popper 的标准在很多边界情况下模糊
