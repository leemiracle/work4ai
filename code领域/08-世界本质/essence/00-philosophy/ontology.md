# 本体论 · Ontology

> **"什么存在？"** — 这是最古老、最深、最无法回避的问题。

---

## 直觉层

**本体论 = 关于"什么真实存在"的研究。**

它问的不是"我看到什么"（那是心理学），也不是"我能证明什么"（那是认识论），而是更根本的：**在所有可能为真的陈述背后，必须假设什么存在？**

### 为什么这个问题无法回避

你随手说一句"地球绕太阳转"——背后假设：
- 地球存在（物质对象存在吗？还是只是感觉束？）
- 太阳存在（同上）
- "绕...转"是真实关系（关系存在吗？还是只是我们的描述？）
- 时间存在（过去/现在/未来都真实吗？还是只有现在？）
- 你存在（你是一个连续的自我吗？还是时刻被创造的新的存在？）

每句话都踩在本体论的隐性假设上。本体论把这些假设翻出来。

## 核心问题清单

### Q1. 实在的层次

| 立场 | 主张 | 例子 |
|------|------|------|
| **朴素实在论** | 我看到的就是真的 | 桌子是实在的 |
| **科学实在论** | 科学描述的（电子、夸克）真实存在 | 电子真的存在 |
| **工具主义** | 理论只是预测工具，不指称真实 | "电子"只是计算装置 |
| **现象主义** | 只存在感知，物质是感知的恒定集合 | 桌子 = 视触觉束 |
| **唯心主义** | 只存在心或精神 | 贝克莱：存在就是被感知 |
| **唯物主义** | 只存在物质及其产物 | 意识是大脑的产物 |
| **中性一元论** | 存在某种既非心也非物的"中性素材" | 罗素、James |

### Q2. 抽象对象存在吗？（柏拉图主义 vs 唯名论）

- **柏拉图主义**：数字、集合、命题、性质等抽象对象**真实存在**，且是非时空的存在
  - 论据：数学必然真，且不依赖人类心智
  - 困境：非时空的存在物如何影响物理世界？（Benacerraf 问题）
- **唯名论**：只有个别事物存在，"共相"只是名字
  - 论据：奥卡姆剃刀——不要无必要地增加实体
  - 困境：为什么数学如此有效？（维格纳之问）
- **概念主义**：抽象对象存在，但作为心智构造
  - 困境：数学真理的客观性？

**这个问题直接关系到 `01-natural-sciences/mathematics/` 的根基**。

### Q3. 时间存在吗？

- **现在论 (Presentism)**：只有现在真实存在。过去已不存在，未来还未存在。（常识）
- **永恒论 (Eternalism)**：过去、现在、未来都同等真实。"现在"只是观察者的视角。（相对论支持）
- **增长块宇宙论 (Growing Block)**：过去和现在存在，未来不断加入。

**相对论压力**：如果"同时性是相对的"，那么"现在"没有客观意义——支持永恒论。

### Q4. 因果是真实的吗？

- 休谟：我们只观察到**恒常联结**，从未观察到"因果力"本身
- 康德：因果是心智加诸现象的范畴
- 当代：因果是物理过程的**传递**（Salmon/Dowe 的物理过程理论）

### Q5. 同一性问题

- 忒修斯之船：所有木板都被替换了，船还是原来的船吗？
- 你的所有细胞每 7 年更新一次，你还是 7 年前的你吗？
- 意识上传后那个数字副本，是你吗？

## 数学层

本体论本身没有"公式"，但有**形式化工具**：

### 1. 形式本体论（Formal Ontology）

用形式逻辑刻画"什么存在"。基本工具：**量词**。

$$\exists x \, P(x) \quad \text{（存在 } x \text{ 使得 } P(x) \text{）}$$

$$\forall x \, P(x) \quad \text{（对所有 } x, P(x) \text{）}$$

但"存在"是什么意思？

- **Quine**："存在就是成为约束变量的值" (To be is to be the value of a bound variable)
- 含义：你说"电子存在"，本体论承诺 = 你最佳的科学理论必须量化在电子上

### 2. 模态本体论（Modal Metaphysics）

用**可能世界**语义讨论"必然"和"可能"：

- $\Box P$：在所有可能世界中 $P$ 都真
- $\Diamond P$：在至少一个可能世界中 $P$ 真

可能世界本身**存在**吗？
- **具体论 (Concrete)**：可能世界和现实世界一样具体（Lewis）
- **抽象论 (Abstract)**：可能世界是抽象表征
- **取消论**：可能世界只是说话方式

### 3. 部分整体论（Mereology）

形式化"部分-整体"关系：
- $x \sqsubseteq y$：$x$ 是 $y$ 的一部分
- 公理：部分关系的偏序性、传递性等

应用：忒修斯之船的形式化、拓扑学本体论。

## 代码层（用形式验证感受本体论问题）

本体论的"代码"主要是**形式化验证**——用逻辑系统检查哪些本体论立场自洽。

下面用 Python 模拟一个简化版的可能世界语义：

```python
from itertools import product

# 三个可能世界：w0 (现实), w1, w2
worlds = ['w0', 'w1', 'w2']

# 在每个世界里，命题 P 的真值
P_truth = {'w0': True, 'w1': True, 'w2': False}

# 可达关系：从 w0 能"看到"哪些世界？
accessible = {
    'w0': ['w0', 'w1', 'w2'],   # w0 看到所有（全知视角）
    'w1': ['w1', 'w0'],          # w1 只看到自己与现实
    'w2': ['w2'],                # w2 只看到自己
}

def necessarily(P, world, accessible, truth):
    """□P: 在 world 可达的所有世界里 P 都真"""
    return all(truth[w] for w in accessible[world])

def possibly(P, world, accessible, truth):
    """◇P: 在 world 可达的至少一个世界里 P 真"""
    return any(truth[w] for w in accessible[world])

print("命题 P 在各世界的真值：", P_truth)
print()
for w in worlds:
    print(f"在 {w}:")
    print(f"  □P (P必然真)?  {necessarily(P_truth, w, accessible, P_truth)}")
    print(f"  ◇P (P可能真)?  {possibly(P_truth, w, accessible, P_truth)}")
print()
print("洞察：'必然'和'可能'依赖可达关系——这是 Kripke 语义的核心。")
print("      不同的本体论立场 = 不同的可达关系假设。")
```

## 跨学科映射

| 学科 | 本体论问题 | 该学科的主流假设 |
|------|-----------|----------------|
| **物理学** | 电子、场、时空"真实存在"吗？ | 科学实在论（多数物理学家） |
| **数学** | 数学对象（数、集合）存在吗？ | 工作中是柏拉图主义者，元反思时分裂 |
| **CS** | 程序、数据、算法是什么本体？ | 抽象结构 vs 物理实现（多重可实现性） |
| **生物学** | 物种真实存在吗？是人工分类还是自然类别？ | 争论中（物种概念问题） |
| **经济学** | "价值"、"效用"存在吗？ | 主观主义：存在于偏好中 |
| **心理学** | "自我"、"人格"存在吗？ | 佛教心理学：否；认知科学：捆绑论 |
| **AI** | 模型的"知识"、"理解"存在吗？ | 争论中（中文房间） |

## 局限与反例

- **本体论可能没有"答案"**：问"数存在吗"，哲学家吵了 2500 年没有共识。这不是失败——这是在揭示问题的真正结构。
- **奥卡姆剃刀不是真理标准**：简单 ≠ 真。它只是启发式。
- **科学不直接回答本体论问题**：物理学告诉你"电子的行为"，但"电子是否真实存在"是哲学问题。工具主义和实在论都和实验数据兼容。
