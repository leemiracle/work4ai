# 00-philosophy · 哲学之根

> "哲学没有特权地位——但它是**所有学科不可消除的边界面**。  
> 当你追问得足够深，就会撞到它。"

---

## 为什么哲学单独成层，而不是 04-humanities 下的一个学科？

**经过检验的说法**（详见根目录 `README.md`）：

> 所有学科在三个维度上与哲学绑定：
> 1. **历史维度**：所有现代学科都从哲学母体分化（物理=原"自然哲学"，CS 源于 Hilbert 问题，经济学源于道德哲学）
> 2. **基础维度**：每个学科的根基假设学科内部无法证明，只能假设（这些假设就是哲学问题）
> 3. **前沿维度**：每个学科深入到底/触及极限，必然回到哲学（量子解释、哥德尔、中文房间）

所以哲学**不是平级学科**，而是**贯穿所有学科的根**。把它放在 04-humanities 下是对结构的误读——那等于把"地基"放在"四楼"。

但要注意避免的反命题：
- 哲学不"高于"科学——它是边界，不是顶层
- 哲学不"垄断智慧"——它经常给多套互不相容的答案，没有裁决机制
- 哲学不"终结讨论"——它经常让问题更清晰，但很少让问题消失

## 哲学的真正职能

哲学做的是别的学科**做不了的事**：

### 1. 给出**范畴** (categories)
- 什么是"存在"？什么是"变化"？什么是"原因"？什么是"同一性"？
- 这些概念每个学科都默认使用，但没有任何学科能定义它们——定义它们需要更基本的概念，无限递归。
- 哲学提供最底层的范畴网。

### 2. 暴露**假设** (assumptions)
- 每个学科都有"理所当然"的东西。哲学的活就是把这些"理所当然"翻出来拷问。
- "物理定律是普适的"——你怎么知道的？不能再用物理证明，否则循环。
- "人是理性的"——什么叫理性？为何这是公理而不是经验概括？

### 3. 处理**极限问题** (limit questions)
- 当方法失效时，还能问什么？
- "宇宙大爆炸之前是什么？"——物理在这里失效，但问题不消失。
- "数学为什么能描述自然？"（维格纳之问）——数学和物理都无法回答。

### 4. 提供**元方法** (meta-method)
- 什么是"解释"？什么是"好的理论"？什么是"真理"？
- 这些问题决定所有学科的方法论。

## 如何使用本目录

### 入门顺序（强烈建议按此顺序）

1. **先读 `meta-philosophy/`**：哲学本身是什么？为什么它有特殊性？
2. **再读 `epistemology/`**：你如何知道你正在读的任何东西是真的？
3. **然后 `ontology/`**：你正在读的"东西"到底存不存在？
4. **再 `logic/`**：你的推理是否有效？
5. **然后 `metaphysics/`**：最深的那些问题
6. **最后 `ethics/` 和 `aesthetics/`**：进入价值领域

### 每个学科目录里都有 `_philosophy-of-X.md`

比如：
- `01-natural-sciences/physics/_philosophy-of-physics.md`
- `02-formal-sciences/computer-science/_philosophy-of-computation.md`
- `05-intelligence/_philosophy-of-mind.md`
- `07-worldly-power/money/_philosophy-of-money.md`

这些是**学科的哲学锚点**——回答"这门学科的基础假设是什么？它的极限问题是什么？"

**学习任何学科，先读它的 `_philosophy-of-X.md`**——它会让你看到这门学科站在什么地基上。

## 一个反向警示：哲学的两个陷阱

### 陷阱 1：把哲学当"终点"

> "科学回答不了 → 所以这是哲学问题 → 所以交给哲学家"
> ❌ 错。哲学不是"科学失败时的垃圾场"。

哲学是**边界面**。碰到边界时正确的态度是：
- 承认这是边界（不要假装科学能回答它不能回答的）
- 同时**保持对扩展边界的开放**（也许下个世纪某个新方法把它变成可解的）
- 微积分曾经是"哲学问题"（芝诺悖论）；概率论曾经是"哲学问题"（决定论下的偶然性）；信息论曾经是"哲学问题"（什么是信息）

### 陷阱 2：把哲学当"权威"

> "哲学家说 X，所以 X 是对的"
> ❌ 错。哲学家之间永远在争吵。

哲学**没有裁决机制**——这是它和科学的最大区别。当物理学家争论时，最终用实验裁决；当哲学家争论时，最终只能用更细致的概念分析、思想实验、直觉泵（Dennett）。

所以读哲学要**读多派**——只读柏拉图会被柏拉图塑造，只读维特根斯坦会被维特根斯坦塑造。**对抗单一哲学偏见的最好方法是读互相批评的哲学家**。

## 三个起点问题（本周可以开始）

1. **本体论起点**：数字"3"存在吗？如果存在，它在哪？如果不存在，为什么数学如此有效？
2. **认识论起点**：归纳法为什么合法？（休谟问题：观察到 1000 只天鹅是白色，凭什么推断第 1001 只也是白色？）
3. **形而上学起点**：你现在"选择"读这个文档——这个选择是被前因决定的（决定论）？还是真正自由的（自由意志）？还是幻觉？

任何一个都能让你想几个月。

## 给自己一段话

哲学不让你"知道更多"——它让你**对所知道的更不确定**。

但这种不确定不是虚无主义，而是**清醒**。一个清醒地知道自己根基何在、知道自己边界何在的头脑，比一个盲目自信的头脑强 100 倍。

苏格拉底之问的终极形态："**我知道我一无所知**"——这不是谦虚，这是哲学能给出的最诚实的状态报告。
