## 审计规则

1. **每 10 次 council 审议后**审计一次调用记录
2. **连续 10 场未被调用的思想家** → 降级候选（移出常驻，降为按需外聘）
3. **调用率 < 25%** → 禁止扩展思想家库，先用已有的
4. **调用率 > 50%** → 可以考虑扩展
5. 审计时问：**"这个人的操作，我用过吗？如果没用过，是因为不可替代性不够，还是因为我没碰到合适的问题？"**

## 与正循环的关系

```
学（收录思想家）→ 用（调用操作）→ 输出（insight）→ 反馈（审计调用率）→ 深学（淘汰未用的，深挖常用的）
     ↑                                                                        |
     └────────────────────────────────────────────────────────────────────────┘
```

**没有"用"和"反馈"，循环不转。这个日志就是"用"和"反馈"的记录器。**
