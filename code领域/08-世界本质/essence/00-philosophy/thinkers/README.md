# 思想家库 · Thinkers Index

> 本目录收录 council 审议中涉及的代表性思想家，按"西方/中国/其他"三个区域组织。  
> 每位思想家记录：核心贡献、关键概念、**可提取的思维操作**（供 council 调用）、核心著作、与 essence 项目的连接、局限与批评。

---

## 使用方式

1. **council 审议前**：主持者根据议题查阅本目录，找到提供相关思维操作的思想家
2. **学习中**：研究某概念时，查它出自谁、在什么历史情境中产生——用 `genealogist` 视角
3. **不要当神像**：每位思想家都附"局限与批评"——他们是思维工具的提供者，不是真理的代言人

## 与 council skill 的关系

council 的"哲学操作型角色"从本库提取思维操作，以**操作名**（非人名）作为角色代号。本库是操作的角色库的"思想来源档案"。

## 三个提醒

1. **操作名不人名**：council 角色用操作名（"先验追问者"非"康德"），本库是思想来源档案，不是角色定义
2. **每位都有局限**：不要把任何思想家当神像——"局限与批评"栏和"核心贡献"一样重要
3. **待扩展**：本库聚焦 council 审议中提到的人，非哲学史全集。按需通过 `domain-expert-on-call` 扩展
