## 阅读路径建议

### 🎯 路径 A：理解金融本质（非技术派，5 本）
1. F1《金融与好的社会》——金融的价值
2. F13《随机漫步的傻瓜》——运气的角色
3. F6《漫步华尔街》——市场效率
4. F2《债》——货币的真相
5. F11《黑天鹅》——风险的边界

### 🎯 路径 B：理解中国市场（投资派，4 本）
1. F23《置身事内》✅——财政金融入门
2. F24《分析与思考》——体系全貌
3. F25《以利为利》✅——财政深入
4. F26《渐行渐远的红利》——宏观视角

### 🎯 路径 C：金融理论（专业派，5 本）
1. F3《风险、不确定性与利润》——哲学根基
2. F14《市场的（错误）行为》——数学批判
3. F15《稳定不稳定的经济》——系统视角
4. F20 Hull——定价工具
5. F21 Cochrane——统一框架

### 🎯 路径 D：危机与风险（谨慎派，4 本）
1. F16《疯狂、惊恐和崩溃》——历史模式
2. F19《这次不一样》——800 年教训
3. F11《黑天鹅》——极端事件
4. F15《稳定不稳定的经济》——内在脆弱
