## 第一章 设计目标

### 说明

**宪法序言**（1982年宪法，2018年修正）规定国家的根本任务：

> "沿着中国特色社会主义道路，集中力量进行社会主义现代化建设。中国各族人民将继续在中国共产党领导下，在马克思列宁主义、毛泽东思想、邓小平理论、'三个代表'重要思想、科学发展观、习近平新时代中国特色社会主义思想指引下……把我国建设成为富强民主文明和谐美丽的社会主义现代化强国，实现中华民族伟大复兴。"

**五个具体目标**（来自宪法+党章+法律）：

| 目标 | 法律依据 | 具体内容 |
|------|---------|---------|
| 维护公共秩序 | 宪法第28条/刑法/治安管理处罚法 | 镇压叛国/危害国家安全/打击犯罪 |
| 提供公共服务 | 宪法第19-22条 | 义务教育/医疗卫生/文化事业/科学技术 |
| 保障国家安全 | 宪法第29条/国家安全法(2015) | 国防/反间谍/反恐/网络安全 |
| 促进发展 | 宪法序言/五年规划 | 经济建设/产业升级/科技创新 |
| 保护权利 | 宪法第33-50条（公民基本权利） | 平等权/选举权/言论自由/人身自由/财产权/受教育权 |

## 第二章 操作系统

### 说明

**六大制度**（宪法规定）：

| 制度 | 宪法依据 | 核心内容 |
|------|---------|---------|
| 国体 | 宪法第1条 | "中华人民共和国是工人阶级领导的、以工农联盟为基础的人民民主专政的社会主义国家" |
| 政体 | 宪法第2条 | "中华人民共和国的一切权力属于人民。人民行使国家权力的机关是全国人民代表大会和地方各级人民代表大会" |
| 政党制度 | 宪法序言 | "中国共产党领导的多党合作和政治协商制度将长期存在和发展" |

| 经济制度 | 宪法第6-18条 | "公有制为主体、多种所有制经济共同发展" |
| 基层自治 | 宪法第111条 | "城市和农村按居民居住地区设立的居民委员会或者村民委员会是基层群众性自治组织" |

## 第四章 权限系统

### 说明：权力配置

**立法权限**（立法法规定）：

| 层级 | 主体 | 权限范围 |
|------|------|---------|
| 制宪修宪 | 全国人大 | 修改宪法（需2/3以上多数） |
| 基本法律 | 全国人大 | 刑事/民事/国家机构/其他基本法律 |
| 一般法律 | 全国人大常委会 | 除基本法律外的其他法律 |
| 行政法规 | 国务院 | 为执行法律需要制定的行政法规 |
| 地方性法规 | 省级/设区的市人大 | 地方性事务 |
| 部门规章 | 国务院各部委 | 本部门权限内事项 |
| 地方政府规章 | 省/市政府 | 本行政区域具体管理事项 |

**法律效力层级**（立法法第87-92条）：
```
宪法 > 法律 > 行政法规 > 地方性法规 > 规章
```

**监察权限**（监察法2018年）：
- 监察对象：所有行使公权力的公职人员
- 监察措施：谈话/讯问/询问/查询/冻结/调取/查封/扣押/搜查/勘验检查/鉴定/留置
- 留置期限：一般3个月，最长可延长至6个月

## 第六章 行政系统

### 说明：行政行为体系

**行政许可法**（2004年施行）：
| 许可类型 | 例子 |
|---------|------|
| 普通许可 | 食品经营许可证/建筑施工许可证 |
| 特许 | 矿产资源开采/无线电频率使用 |
| 认可 | 律师执业证/医师资格证 |
| 核准 | 消防验收/电梯安装核准 |
| 登记 | 企业登记/婚姻登记 |

**行政处罚法**（2021年修订）：
```
处罚种类
├── 警告/通报批评
├── 罚款/没收违法所得
├── 暂扣许可证件/降低资质等级
├── 限制开展生产经营活动/责令停产停业
├── 行政拘留（5-20日）
└── 法律行政法规规定的其他处罚
```

**行政复议**（复议法2024年修订）：
- 范围：对行政机关的具体行政行为不服
- 期限：知道行政行为之日起60日内
- 结果：维持/撤销/变更/确认违法/责令履行

**行政诉讼**（诉讼法2017年修正）：
- 原告：公民/法人/其他组织
- 被告：行政机关
- 期限：知道行政行为之日起6个月内
- 判决类型：驳回/撤销/履行/变更/确认违法

| 文种 | 用途 | 方向 |
|------|------|------|
| 决议 | 讨论通过的重大决策事项 | 下行 |
| 决定 | 重要事项作出决策和部署 | 下行 |
| 命令(令) | 发布行政法规/宣布施行重大强制性措施 | 下行 |
| 公报 | 公布重要决定或重大事项 | 公开 |
| 公告 | 向国内外宣布重要事项 | 公开 |
| 通告 | 在一定范围内公布应当遵守事项 | 公开 |
| 意见 | 对重要问题提出见解和处理办法 | 不定 |
| 通知 | 发布/传达/批转/转发文件 | 下行 |
| 通报 | 表彰先进/批评错误/传达重要精神 | 下行 |
| 报告 | 汇报工作/反映情况/回复询问 | 上行 |
| 请示 | 向上级请求指示/批准 | 上行 |
| 批复 | 答复下级请示事项 | 下行 |
| 议案 | 提请审议事项 | 上行 |
| 函 | 不相隶属机关间商洽工作/询问/答复 | 平行 |
| 纪要 | 记载会议主要情况和议定事项 | 内部 |

**公文格式**（GB/T 9704-2012）：

公文格式

## 第八章 财政系统

### 说明：财政收支体系

**财政收入结构**（2024年约21万亿）：

| 收入类型 | 占比 | 具体税种 |
|---------|------|---------|
| 税收收入 | ~85% | 增值税(32%)/企业所得税(24%)/个人所得税(7%)/消费税(8%) |
| 非税收入 | ~10% | 行政事业性收费/罚没收入/国有资源有偿使用 |
| 政府性基金 | ~5% | 土地出让金/彩票公益金/铁路建设基金 |

**主要税种说明**：

| 税种 | 纳税人 | 税率 | 征税对象 |
|------|--------|------|---------|
| 增值税 | 销售货物/提供服务/进口的单位和个人 | 13%/9%/6%/0% | 增值额 |
| 企业所得税 | 企业/其他组织 | 25%（高新15%/小微20%） | 应纳税所得额 |
| 个人所得税 | 居民/非居民个人 | 3%-45%超额累进 | 综合所得/经营所得/其他 |
| 消费税 | 生产/委托加工/进口应税消费品 | 比例税率/定额税率 | 特定消费品（烟/酒/油/车等）|

**预算制度**（预算法2015年）：
```
预算体系
├── 一般公共预算（税收为主，用于一般公共服务）
├── 政府性基金预算（土地出让金为主，用于特定项目）
├── 国有资本经营预算（国企利润，用于国企发展）
└── 社会保险基金预算（社保缴费，用于社保支出）
```

**中央与地方财政关系**：
- 收入划分：中央税/地方税/中央地方共享税
- 支出划分：中央事权/地方事权/共同事权
- 转移支付：一般性转移支付+专项转移支付

## 第十二章 更新系统

### 说明：国家如何适应变化

**法律更新**（立法法）：
- 全国人大每年3月开会→审议新法律
- 常委会每2个月开会→日常立法
- 法律修改/废止：根据社会变化调整

**政策更新**：
| 机制 | 频率 | 产出 |
|------|------|------|
| 五年规划 | 每5年 | 国民经济和社会发展规划 |
| 中央经济工作会议 | 每年12月 | 次年经济政策方向 |
| 中央全会 | 不定期 | 重大改革决定 |
| 全国两会 | 每年3月 | 政府工作报告/预算/法律 |

**"十四五"规划（2021-2025）核心目标**：
| 指标 | 目标 |
|------|------|
| GDP增长 | 年均5-6% |
| 研发投入占GDP | >2.8% |
| 常住人口城镇化率 | 65% |
| 单位GDP能耗降低 | 13.5% |
| 基本养老保险参保率 | 95% |

**2035年远景目标**：
- 基本实现社会主义现代化
- 经济总量和人均收入翻一番
- 关键核心技术实现重大突破
- 建成法治国家/法治政府/法治社会
