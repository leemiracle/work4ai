### 框架1：历史唯物主义（49篇核心文献）

**核心问题**：历史如何发展？什么决定了社会的变化？

**核心概念链**：
```
生产力 → 决定 → 生产关系 → 构成 → 经济基础 → 决定 → 上层建筑（法律/政治/意识形态）
  ↑                                                                    ↓
  └──────── 技术进步驱动 ←────────── 反作用 ←─────────────────────────┘
```

**论证结构**：
1. 人的根本需求是物质生产
2. 生产需要工具（生产力）和关系（生产关系）
3. 生产力发展→旧生产关系不适应→矛盾→革命→新生产关系
4. 经济基础决定上层建筑（但上层建筑有反作用）

**代表文献**：
- 马克思《政治经济学批判序言》(1859)——最简洁的表述
- 恩格斯《反杜林论》(1878)——系统化
- 毛泽东《矛盾论》(1937)——中国化（主要矛盾/次要矛盾）

**与essence关联**：→ `10-china/05-economy.md`（A6半脱嵌=生产关系的特定形态）+ insight #20（统一-分裂=生产力和生产关系的矛盾）

### 框架2：阶级分析（1725篇涉及——最大框架）

**核心问题**：社会分为哪些群体？群体间的关系如何？

**核心概念链**：
```
生产力发展 → 剩余产品出现 → 私有制 → 阶级分化 → 剥削（剩余价值）→ 阶级斗争 → 革命
  ↓                                                                    ↓
资产阶级（占有生产资料）                    无产阶级（出卖劳动力）← 阶级意识觉醒
```

**论证结构**：
1. 阶级=在生产关系中的位置
2. 资产阶级占有生产资料→剥削无产阶级的剩余价值
3. 阶级斗争是历史的动力
4. 无产阶级的使命：消灭阶级（包括自己）

**代表文献**：
- 马克思《共产党宣言》(1848)——"至今一切社会的历史都是阶级斗争的历史"
- 马克思《资本论》(1867)——剩余价值的系统论证
- 毛泽东《中国社会各阶级的分析》(1925)——中国的阶级分析

**与essence关联**：→ insight #2（谱系分析——"权力=强制"是谁的定义）+ insight #35（社会分层——调用率=分层）+ `09-ideologies/ideological-lenses.md`

### 框架3：革命理论（1651篇涉及）

**核心问题**：如何从资本主义过渡到社会主义？

**6条路线的分歧**：

| 路线 | 代表 | 路径 | 核心文献 |
|------|------|------|---------|
| 列宁 | 先锋党+暴力革命 | 《怎么办》/《国家与革命》 |
| 伯恩斯坦 | 议会+渐进改良 | 《什么是社会主义》 |
| 卢森堡 | 群众自发+总罢工 | 《社会改良还是革命》 |
| 葛兰西 | 文化霸权+阵地战 | 《狱中札记》 |
| 毛泽东 | 农村包围城市+人民战争 | 《新民主主义论》/《论持久战》 |
| 托洛茨基 | 不断革命 | 《被背叛的革命》 |

**核心概念链**：
```
革命条件：生产力vs生产关系矛盾激化 + 革命意识觉醒 + 革命组织
  ↓
革命路径：6条路线（见上表）
  ↓
革命结果：夺取政权 → 建立专政 → 改造社会
  ↓
但：斯大林主义？热月化？官僚化？
```

**与essence关联**：→ insight #20（统一-分裂=6条路线的分叉）+ `10-china/02-history.md`（中国革命=农村路线）+ insight #10（库恩——革命=范式转移）

### 框架4：帝国主义论（431篇涉及）

**核心问题**：资本主义发展到什么阶段？为什么有世界大战？

**核心概念链**：
```
自由竞争 → 生产集中 → 垄断 → 资本输出（vs商品输出）→ 殖民瓜分 → 帝国主义
  ↓                                                          ↓
金融资本（银行+工业融合）                      民族解放运动（反帝国主义）
```

**代表文献**：
- 列宁《帝国主义是资本主义的最高阶段》(1916)
- 曼德尔《晚期资本主义》

**与essence关联**：→ `11-world/01-ir-theories.md`（现实主义——帝国主义=权力扩张）+ insight #42（芯片封锁=新帝国主义？）

### 框架5：文化霸权（25篇核心文献）

**核心问题**：为什么被统治者"同意"被统治？

**核心概念链**：
```
权力 = 暴力(force) + 同意(consent)
  ↓                              ↓
军队/警察/法院              文化霸权(hegemony)
  ↓                              ↓
镇压性国家机器              意识形态国家机器（学校/媒体/教会/党）
  ↓                              ↓
直接强制                    塑造"常识"→被统治者"自愿"接受
  ↓
阵地战：逐个攻克文化阵地（vs运动战：直接夺取政权）
```

**代表文献**：
- 葛兰西《狱中札记》——文化霸权/阵地战/有机知识分子
- 阿尔都塞《意识形态和意识形态国家机器》(1970)——ISA理论

**与essence关联**：→ `analysis/gramsci-hegemony-analysis.md` + insight #6（福柯——权力-知识）+ insight #22（外儒内法=古代版霸权）+ insight #36（文化建构）

### 框架6：实践认识论（205篇涉及）

**核心问题**：人如何认识世界？认识和实践的关系？

**核心概念链**：
```
实践（生产/阶级斗争/科学实验）
  ↓
感性认识（感觉/印象/外部联系）
  ↓ [飞跃]
理性认识（概念/判断/推理/内部联系）
  ↓ [回到实践]
实践检验 → 发现错误 → 修正 → 再实践
  ↓
循环上升："实践、认识、再实践、再认识"
```

**代表文献**：
- 马克思《关于费尔巴哈的提纲》(1845)——第十一条"改变世界"
- 毛泽东《实践论》(1937)——系统化
- 毛泽东《矛盾论》(1937)——主要矛盾/次要矛盾

**与essence关联**：→ `analysis/practice-theory-analysis.md` + MANIFESTO第十三条（正循环=实践论）+ insight #8（知行合一）+ insight #39（缺"回到实践"）

### 框架7：物化理论（257篇涉及）

**核心问题**：资本主义如何把"人与人的关系"变成"物与物的关系"？

**核心概念链**：
```
人与人的关系 → 商品交换 → 关系被"物化"（表现为物的属性）
  ↓                          ↓
劳动→商品                   社会关系→市场关系
  ↓                          ↓
剩余价值→利润                人的本质→交换价值
  ↓                          ↓
异化（Alienation）：人与自己/他人/劳动产品/类本质异化
```

**代表文献**：
- 马克思《1844年经济学哲学手稿》——异化劳动
- 马克思《资本论》——商品拜物教
- 卢卡奇《历史与阶级意识》(1923)——物化（Reification）

**与essence关联**：→ insight #28（四大支柱分析金钱——金钱=物化的社会关系）+ insight #48（DeepSeek——工程突破≠科学突破=技术拜物教？）

### 框架9：社会主义建设（530篇涉及）

**核心问题**：夺取政权后如何建设社会主义？

```

### 框架10：民主理论（976篇涉及）

**核心问题**：什么是民主？无产阶级民主vs资产阶级民主？

**核心争论**：
```
伯恩斯坦：社会主义=民主→议会道路
  vs
列宁：资产阶级民主=虚伪→无产阶级专政
  vs
卢森堡：无产阶级也需要民主→反对列宁的集中制

## 二、概念逻辑关系网络

不只是共现——是**逻辑关系**（A推出B/A反对B/A深化B）：

```
                    生产力
                      ↓ 决定
                    生产关系 ←→ 阶级（在生产关系中的位置）
                      ↓ 构成                  ↓ 分析
                    经济基础              资产阶级 vs 无产阶级
                      ↓ 决定                  ↓ 关系
                    上层建筑              剩余价值→剥削
                      ↓ 包括                      ↓ 导致
              法律/政治/意识形态          阶级斗争
                      ↓                          ↓ 导致
                意识形态                革命
                      ↓                          ↓ 路径
              文化霸权(葛兰西)       6条路线(列宁/伯恩斯坦/...)
              ↑ 深化                    ↓ 结果
        福柯(权力-知识)            专政→社会主义→共产主义
              ↑ 补充                      ↓ 异化风险
        阿尔都塞(ISA)              官僚化(斯大林主义)
                                          ↓ 批判
                                    托洛茨基(不断革命)
                                    毛泽东(文化大革命?)
```

### 概念的"逻辑链"（非共现，是推演关系）

| 链 | 逻辑 |
|----|------|
| 生产力→生产关系→经济基础→上层建筑 | 历史唯物主义的"决定链" |
| 剩余价值→剥削→阶级斗争→革命 | 阶级分析的"动力链" |
| 实践→感性认识→理性认识→回到实践 | 实践认识论的"循环链" |
| 商品交换→物化→异化→解放 | 物化理论的"批判链" |
| 暴力+同意→文化霸权→阵地战→有机知识分子 | 葛兰西的"文化链" |
| 自由竞争→垄断→资本输出→殖民→帝国主义 | 列宁的"帝国主义链" |
