## 一句话

**资本不是钱——资本是"能生出更多钱的钱"。钱变成资本的那一刻，它就从"交换工具"变成了"自我增殖的种子"。**

---

## 资本 vs 钱 vs 财富——三个常被混淆的概念

| | 钱（Money） | 资本（Capital） | 财富（Wealth） |
|---|---|---|---|
| **本质** | 交换媒介、欠条 | 能增值的价值 | 已有的存量价值 |
| **状态** | 静态（在手里的） | 动态（在循环中的） | 静态（拥有的） |
| **目的** | 流通 | 增殖（M→M'） | 享用/储藏 |
| **例子** | 钱包里的现金 | 投入生产的机器、生息的债券 | 你住的房子 |
| **关键** | 流动性 | 收益率 | 数量 |

**马克思的洞见**：资本的公式是 **M → C → M'**（货币→商品→更多货币）。当 M' > M，资本就实现了增殖。这个差额（剩余价值）的来源——是劳动？是创新？是风险承担？——是全部政治经济学的争论起点。

---

## 资本的七种形态

资本不只是"钱"——凡是能**产生未来收益**的东西都是资本：

| 形态 | 例子 | 如何增殖 |
|------|------|---------|
| **金融资本** | 现金、股票、债券 | 利息、股息、资本利得 |
| **生产资本** | 机器、工厂、设备 | 生产商品赚取利润 |
| **人力资本** | 技能、知识、健康 | 更高的工资、更长的寿命 |
| **社会资本** | 人脉、信任、声誉 | 更好的机会、更低的交易成本 |
| **智力资本** | 专利、品牌、版权 | 垄断租金、授权费 |
| **自然资本** | 土地、矿产、生态 | 地租、资源出售、生态服务 |
| **符号资本**（布迪厄） | 学历、头衔、荣誉 | 社会地位→资源获取 |

> **洞察**：当你只把"资本"理解为"钱"，你就低估了自己拥有的资源——你的健康、知识、人脉、声誉都是资本。**穷人不是没有资本，而是他们的资本无法变现。**

## 资本的三个核心问题

### 问题 1 · 资本从哪来？（积累）
- **马克思**：原始积累 = 暴力掠夺（殖民、圈地运动）
- **熊彼特**：创新创造新资本（创造性破坏）
- **皮凯蒂**：资本回报 r > 经济增长 g → 资本自我集中 → 贫富分化

### 问题 2 · 资本到哪去？（配置）
- **市场**：价格机制引导资本流向高回报处
- **国家**：产业政策、财政补贴引导资本
- **金融**：银行/股市/VC 是资本的分配器

### 问题 3 · 资本增殖的尽头？（集中）
- **皮凯蒂《21 世纪资本论》**：r > g 意味着资本拥有者的收入增长快于劳动者 → 财富不断集中 → 需要全球财富税
- **反驳**：创新会打破集中（每个时代的新贵）；消费会侵蚀资本（富不过三代）

## 资本的哲学——三层

### 直觉层
资本像**种子**——你吃掉它（消费），它就没了；你种下去（投资），它能长出更多。但种子种下去有风险：可能不发芽、可能被虫吃。**资本增殖的本质 = 承担风险换取增长。**

### 数学层
资本的增殖遵循**复利**：
$$A = P(1+r)^n$$
- P = 本金，r = 收益率，n = 时间
- 复利是世界第八大奇迹——但它的前提是**时间足够长 + 不中断**。一次 -50% 的回撤，需要 +100% 才能回本。

```python
# 复利的力量 vs 直觉的失败
def compound(p, r, n):
    return p * (1+r)**n

# 100 元，年化 10%，30 年
print(f"100元年化10%×30年 = {compound(100, 0.10, 30):.0f}元")  # 1745
print(f"100元年化20%×30年 = {compound(100, 0.20, 30):.0f}元")  # 23738
print(f"收益率翻倍，结果翻 {23738/1745:.0f} 倍")  # 14 倍！

# 但中断一次的代价
capital = 100
for i in range(30):
    capital *= 1.10
    if i == 14:  # 第15年亏50%
        capital *= 0.5
print(f"中间亏50%后继续 = {capital:.0f}元")  # 远低于 1745
```

## 资本与权力

资本不只是经济力量——它是**权力**：

| 机制 | 说明 |
|------|------|
| **资本控制生产** | 谁拥有资本，谁决定生产什么、雇谁、怎么分 |
| **资本控制媒体** | 媒体需要广告 → 资本决定话语权 |
| **资本控制政治** | 游说、政治献金、旋转门 |
| **资本控制未来** | VC 决定哪些技术被投资、哪些被忽略 |

> **马克思**：资本不是物，而是一套**社会关系**。机器不是资本——机器在特定社会关系下（雇佣劳动 + 私有产权）才变成资本。

---

## 反直觉的真相

1. **资本越多 ≠ 经济越好**——当资本回报率持续低于增长率，资本会"过剩"（日本失去的三十年）。
2. **金融化是病灶**——当金融资本脱离实体资本太远（衍生品>实体 10 倍），系统脆弱（2008）。
3. **"圈钱"不是"创造价值"**——回购股票推高股价，对股东有利，对社会无益（股市成为财富转移工具）。
4. **穷人最大的贫困是"没有资本"**——他们只能出卖劳动（时间），而时间是有限的。资本能 24 小时增殖，劳动不能。
