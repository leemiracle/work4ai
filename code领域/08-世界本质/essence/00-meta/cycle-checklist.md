# 正循环检查清单 · Cycle Checklist

> 每次想"添加新内容"（新思想家/新群组/新目录）前，**先过这个清单**。  
> 通不过 = 你的"添加"是收藏，不是学习。

---

## 添加前必答（4 题）

### 1. 已有内容用了几次？
- 查 [`thinkers/usage-log.md`](../00-philosophy/thinkers/usage-log.md)
- 上一次"调用"某位思想家是什么时候？

### 2. 上次输出是什么时候？
- 查 [`insights/`](../insights/) 最新一篇
- 如果超过 2 周没有 insight → **先产出，再添加**

### 3. 新内容会进入"用"的环节吗？
- 你能说出"我会用这个操作分析什么具体问题"吗？
- 如果说不出来 → 它只会进入收藏，不会进入循环

### 4. 如果不加，正循环会断吗？
- 正循环 = 学→用→输出→反馈→深学
- "添加新内容"只在"学"的入口。如果"用→输出→反馈"已经断了——加更多入口没用

---

## 判定

| 结果 | 动作 |
|------|------|
| 4 题都答得出 + "会进入使用" | ✅ 可以加 |
| 答不出 + "只收藏" | ❌ 不加。**先用已有的跑一条循环** |
| 调用率 < 25% | ❌ 禁止扩展。先消化到 > 25% |

---

## 为什么需要这个清单？

项目的核心目的是**正循环**（认识世界→改造世界→改造自己→更深的认识）。

正循环的动力来自**输出**，不是输入。只输入不输出 = 囤积。只收藏不用 = 博物馆。

**这个清单是刹车——防止"添加冲动"把项目从"工具箱"变成"收藏柜"。**
