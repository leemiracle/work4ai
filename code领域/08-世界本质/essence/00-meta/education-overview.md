# 教育学总体框架 · Education Overview

> 教育学回答：**如何有目的、有组织地促进人的发展，使知识、能力、价值观和文化得以传承与创新？**  
> 如果认知科学研究"学习如何发生"，教育学研究"如何设计条件让学习更有效发生"。

---

## 核心模型

```
社会需求 → 教育目标 → 课程 → 教学 → 学习 → 评价 → 能力发展 → 反馈改进 ↺
```

> 教育学研究的不是"教书"——是**学习者×教师×知识×环境×社会**之间的系统关系。

---

## 方法论

```
发现教育问题 → 教学设计 → 实施教学 → 收集学习数据 → 分析效果 → 持续改进
```

| 方法 | 用途 |
|------|------|
| 教育实验 | 比较不同教学方法效果 |
| 问卷调查 | 学习态度/动机 |
| 课堂观察 | 教学互动 |
| 学习分析 | 学习行为数据 |
| 行动研究 | 教师在实践中改进 |

## 在认知科学链条中的位置

```
哲学 → 心理学 → 神经科学 → 认知科学 → 语言学 → 数学 → 逻辑学 → 社会学 → 人类学
  → 教育学：如何高效传递、建构和应用知识  ← 这里
  → 文明发展：知识如何代际传承与创新
```

> 教育学位于"认识"与"实践"之间——连接认知科学和社会发展。
