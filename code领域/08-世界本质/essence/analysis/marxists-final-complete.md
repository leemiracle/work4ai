## 核心发现（跨16轮）

### 1. 马克思主义不是一条线——是6条线+3个独立传统

```
6条路线：政治(列宁)/民主(伯恩斯坦)/文化(葛兰西)/理论(阿尔都塞)/哲学(卢卡奇)/存在(萨特)
3个独立传统：无政府主义/委员会共产主义/拉美革命
```

### 2. 中国托派文献量 > 主流

```
中国托派：~850篇（陈独秀228+郑超麟199+王凡西124...）
中国革命主流：~700篇
= 文库保存了被消除的声音
```

### 3. 早期列宁是"工人律师"不是"革命理论家"

```
1895-1899年列宁在体制内用法律保护工人
和伯恩斯坦的改良路径高度相似
分裂发生在1902年后——不是从一开始就有
```

### 4. 概念频率——"阶级"3682次最高

```
Top5：阶级3682/革命2664/社会主义1377/国家1323/劳动1056
政治概念占45%——马克思主义偏"行动"不偏"思考"
```
