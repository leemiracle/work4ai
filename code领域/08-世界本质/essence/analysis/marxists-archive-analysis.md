> 分析对象：marxists.org/chinese 中文马克思主义文库（120+位作者/数千篇文献）  
> 使用工具：6条公理+哲学14分支+认识学DIKW+系统科学+已有insight

## 一、文库的知识地图——7大传统

```
马克思主义文库
│
├── 1. 经典马克思主义（马恩列毛）
│   ├── 理论：哲学/政治经济学/科学社会主义
│   └── 实践：革命策略/国家建设
│
├── 2. 中国革命（毛周刘+托派13人）
│   ├── 主流：毛的农村包围城市/新民主主义
│   └── 异端：托派的不断革命论/对斯大林主义的批判
│
├── 3. 无政府主义（蒲鲁东/巴枯宁/克鲁泡特金/巴金/格雷伯）
│   └── 反国家/反权威/自愿合作

├── 4. 第二国际（考茨基/伯恩斯坦/倍倍尔）

└── 7. 当代左翼（曼德尔/霍布斯鲍姆/斯威齐/布雷弗曼）
```

## 二、用6条公理分析——文库如何反映中国的底层结构

> **调用**：`10-china/11-first-principles-analysis.md`

| 公理 | 文库中的反映 |
|------|------------|
| A3大一统 | 文库的中国部分（毛+托派）= 大一统传统内的"正统vs异端"之争 |
| A4实用理性 | 毛的《实践论》= 实用理性在马克思主义中的极致表达（"实践是检验真理的唯一标准"）|
| A5党国一体 | 列宁《国家与革命》+毛《论人民民主专政》= A5的理论基础 |
| A6半脱嵌 | 马克思《资本论》= 半脱嵌经济的批判工具（资本vs劳动）|

### 核心洞察

> 文库的中国部分反映了A3（大一统）的内在张力：**正统（毛）vs异端（托派）**——13位中国托派被收录，说明大一统内部始终有"反对派"的声音。这些声音在主流叙事中被消除，但在文库中被保存。**文库的价值不只是保存"正统"——更是保存"被消除的声音"。**

### 缺失的维度

| 缺失 | 原因 |
|------|------|
| 宗教哲学 | 马克思主义是无神论的——不讨论宗教的正当性 |
| 数学哲学 | 马克思主义传统不关注数学基础问题 |
| 信息哲学 | 文库偏经典——缺现代信息哲学 |

## 四、用系统科学分析——文库作为一个"知识系统"

> **调用**：`06-systems/_overview.md`（九步法）

| 步 | 分析 |
|----|------|
| 边界 | 文库的边界="马克思主义及相关左翼传统"——但无政府主义也被收录，说明边界是"左翼"不是"马克思主义"|
| 组成 | 120+位作者——从经典作家到当代学者，跨160年（1840s-2020s）|
| 结构 | 按作者组织（个人中心）+ 按组织（四个国际）+ 按主题（左翼文化/工人小说）|
| 关系 | 作者间有"师承/争论/分裂"关系——马恩→列宁→毛（正统线）；马恩→卢森堡/托洛茨基（异端线）；马恩→伯恩斯坦（修正线）；马恩→葛兰西/卢卡奇（西马线）|
| 流动 | 思想从经典→分叉→发展→争论→新分叉——树状分叉但有关联 |
| 反馈 | 文库本身是"保存"不是"反馈"——它记录争论但不参与新争论 |
| 控制 | 文库由志愿者维护——去中心化的知识保存 |
| 演化 | 从2006年开始持续更新——不断添加新文献 |
| 目标 | 文库的目标="保存左翼思想遗产"——不是宣传，是存档 |

### 核心洞察

> 文库的结构是**树状分叉**——从马恩出发，分出列宁/伯恩斯坦/卢森堡三条线，每条线再分叉。这反映了马克思主义的**内在分裂性**——它不是一个统一的理论，是一个**不断分叉的争论传统**。

## 五、用已有insight深化

### insight #2（尼采谱系分析）——追溯"马克思主义"的来历

```
马克思的思想从哪来？
  → 黑格尔（辩证法）+ 费尔巴哈（唯物主义）+ 英国政治经济学（斯密/李嘉图）
  → 马克思的"创新"：辩证唯物主义+历史唯物主义+剩余价值理论
  ↓
马克思主义分叉：
  → 列宁（先锋党/帝国主义论）→ 毛泽东（农村包围城市）→ 中国特色社会主义
  → 伯恩斯坦（修正主义/议会道路）→ 社会民主主义（北欧模式）
  → 卢森堡（自发革命）→ 委员会共产主义
  → 葛兰西（文化霸权）→ 西方马克思主义→ 后殖民/文化研究
  → 托洛茨基（不断革命）→ 第四国际→ 当代托派
  ↓
= "马克思主义"不是一个东西——是一棵不断分叉的树
```

### insight #20（统一-分裂辩证）——马克思主义内部的"统一vs分裂"

```
马克思主义的"统一"：都自称"马克思主义"
马克思主义的"分裂"：列宁vs伯恩斯坦vs卢森堡vs托洛茨基vs斯大林vs毛
  ↓
= A3（大一统）的国际版——都叫"马克思主义"但内部从未统一
= 文库保存了所有分叉——这比只保存"正统"更有价值
```

### insight #36（文化建构）——马克思主义是"普遍真理"还是"文化建构"？

```
马克思主义声称是"科学"（普遍真理）
但：
  - 产生于19世纪西欧（特定时间/地点）
  - 反映工业革命早期的劳资矛盾（特定阶段）
  - 列宁版产生于一战俄国（特定情境）
  - 毛泽东版产生于农业中国（特定情境）
  ↓
= 每个版本都是"马克思主义×特定情境"的建构
= insight #36的框架：MANIFESTO是西方建构→马克思主义也是特定历史情境的建构
= 但"是建构"≠"无效"——它有解释力，但不是"普遍真理"
```

### insight #28（四大支柱分析金钱）——马克思的金钱观

```
马克思的金钱观：
  本体论：金钱=物化的社会关系（商品拜物教）
  认识论：金钱的"价值"=社会必要劳动时间（劳动价值论）
  价值论：金钱应归劳动者（剩余价值应归还）
  逻辑学：资本的运动公式 M-C-M'（货币→商品→更多货币）
  ↓
= 马克思从4个哲学支柱都分析了金钱——比insight #28更系统
= 但劳动价值论被主观价值论挑战（insight #28已指出）
```

## 六、核心洞察

> 马克思主义文库不是一个"统一的体系"——是一棵**不断分叉的争论树**。从马恩出发，分出5条主要线（列宁/伯恩斯坦/卢森堡/托洛茨基/西马），每条线再分叉。文库保存了所有分叉——包括被主流消除的声音（13位中国托派）。
>
> **文库的最大价值**不是"保存正确的东西"——是**保存争论本身**。争论的每一方都有洞见和盲区。只看一方=偏信；看全部=兼听。
>
> **与essence项目的关联**：项目的`09-ideologies/socialism/`已有社会主义的骨架分析——文库是它的**原始文献库**。项目的`thinkers/western.md`已有马克思——文库提供了马克思的**完整著作**。项目可以持续从文库中调用文献来深化分析。

### 费曼复述（一句话）

> 马克思主义文库像一棵从1840年代长到今天的树——根是马恩，主干分出5条枝（列宁/修正/卢森堡/托派/西马），每条枝再分叉。有些枝被"修剪"了（托派在中国被消除），但文库把它们保存了。**看这棵树不只是看"马克思主义是什么"——是看"一个思想如何在不同土壤中长出不同的形态"。**
