## 一、公共基础知识是什么？

公共基础知识（简称"公基"）是中国公务员考试/事业单位考试的核心科目，涵盖：

```
公共基础知识
├── 政治常识（马克思主义/中国特色社会主义/党史/时政）
├── 法律常识（宪法/民法/刑法/行政法/经济法）
├── 经济常识（微观/宏观经济/经济制度/财政金融）
├── 管理常识（公共管理/行政管理/组织行为）
├── 公文写作（党政机关公文处理条例/格式/写作）
├── 科技常识（科技史/前沿科技/科学方法）
├── 人文常识（历史/文学/哲学/文化）
└── 国情社情（中国地理/人口/资源/环境）
```

---

## 二、用6条公理分析——公基如何反映中国的底层结构

> **调用**：`10-china/11-first-principles-analysis.md`（6条公理）

| 公理 | 公基中的对应 | 分析 |
|------|------------|------|
| A1地理 | 国情社情（中国地理/人口/资源） | 公基教的是"中国是什么"——地理是基础 |
| A2规模 | 14亿人需要大量公务员→公考竞争激烈 | 公基是"筛选14亿人中谁有资格治理"的工具 |
| A3大一统 | 政治常识（统一意识形态/党史/时政） | 公基的"政治"部分=大一统的思想统一机制 |
| A4实用理性 | 公基是"考试工具"——不求深刻，求"够用" | 实用理性在公基中的极致体现：记住就行，不追问为什么 |
| A5党国一体 | 法律+管理+公文=服务于党国体制的知识 | 公基培养的是"党国体制的执行者"需要的知识 |
| A6半脱嵌 | 经济常识反映"半脱嵌"——市场+调控并存 | 公基的"经济"部分=国家资本主义的意识形态基础 |

### 核心洞察

> 公共基础知识不是"中立的知识"——是**A5（党国一体）筛选执行者的考试内容**。它教的不是"什么是对的"，是"**在这个体制中你需要知道什么**"。政治常识=意识形态忠诚度检验；法律常识=体制规则认知；公文写作=体制语言能力；管理常识=体制运作知识。

## 三、用哲学14分支分析——公基涵盖哪些哲学维度

> **调用**：`00-philosophy/_overview.md`（14分支）

| 哲学分支 | 公基中的对应 | 深度 |
|---------|------------|------|
| 政治哲学 | 政治常识（马克思主义/中国特色社会主义）| ⚠️ 教条化——不讨论"应该怎样"，只背"是什么" |
| 法哲学 | 法律常识（宪法/行政法）| ⚠️ 工具化——法律作为"规则"而非"正义" |
| 经济哲学 | 经济常识（微观/宏观/制度）| ⚠️ 浅层——不讨论"经济正义" |
| 历史哲学 | 人文常识（历史）| ⚠️ 选择性——官方叙事框架内的历史 |
| 技术哲学 | 科技常识 | ⚠️ 表层——不追问"技术改变认识吗" |
| 教育哲学 | （考试制度本身）| ❌ 不反思——公基不问"考试公平吗" |
| 伦理学 | （隐含但未教）| ❌ 缺失——公基不教"什么是善" |
| 认识论 | （隐含但未教）| ❌ 缺失——公基不问"这些知识可靠吗" |

### 核心洞察

> 公基涵盖哲学14分支中的5个（政治/法律/经济/历史/技术），但都是**浅层+教条化**的——不追问"为什么"，只要求"记住"。**公基缺三个最重要的维度：伦理学（什么是善）、认识论（知识可靠吗）、教育哲学（考试公平吗）**——这三个维度恰好是反思性的，而公基不需要反思，需要服从。

## 四、用认识学DIKW分析——公基是哪一层？

> **调用**：`12-epistemology/02-unified-framework.md`（DIKW模型）

```
Data（数据）→ Information（信息）→ Knowledge（知识）→ Wisdom（智慧）
```

| 层次 | 公基中的对应 | 特征 |
|------|------------|------|
| 数据 | 具体法条/历史年代/地理数据 | 可记忆可检索 |
| 信息 | "宪法第X条规定Y" | 有上下文的数据 |
| 知识 | "行政法的基本原则是..." | 有结构的信息 |
| 智慧 | "这个情境中应该怎么做？" | ❌ **公基不教这个** |

### 布劳威尔检验

> **调用**：insight #1（构造性检验）

```
公基的知识能"构造"吗？
  - "宪法第三条规定..." → 能背诵（数据层）✅
  - "行政法的基本原则包括..." → 能列举（信息层）✅
  - "在这个具体行政纠纷中，应该适用哪条法律？" → ❌ 公基不教这个
  ↓
= 公基的知识停留在"信息层"——能记住但不会用
= 布劳威尔的构造性检验：公基的知识"存在"但不可"构造"（不能应用到新情境）
```

### 核心洞察

> 公基是**信息层**的知识——记住法条/年代/定义，但不教"如何用"。真正的"知识"（能迁移到新情境）和"智慧"（能判断怎么做）公基不覆盖。**公基考的是记忆不是理解，是信息不是知识。**

## 五、用系统科学分析——公基作为一个"系统"

> **调用**：`06-systems/_overview.md`（九步法）

| 步 | 分析 |
|----|------|
| 边界 | 公基的边界="公务员需要知道的最少知识"——但这个边界谁定？ |
| 组成 | 8大模块——但模块间缺乏深度关联（政治/法律/经济/管理各背各的）|
| 结构 | 扁平结构——8个并列模块，没有层次依赖 |
| 关系 | 模块间关系弱——"政治"和"法律"的深层关联不教 |
| 流动 | 信息从教材→考生→试卷→遗忘（单向流动，不回流）|
| 反馈 | 反馈=考试分数——但只反馈"记住了"不反馈"会用了" |
| 控制 | 控制=考试大纲+命题人——决定了"什么算知识" |
| 演化 | 演化=时政更新——但核心框架不变（马克思主义框架锁定）|
| 目标 | 目标=筛选公务员——不是"培养有智慧的人" |

### 核心洞察

> 公基作为一个"系统"，目标是**筛选**不是**培养**——它不关心你"是否真懂"，只关心你"是否能通过考试"。这导致公基的知识在考完后大多被遗忘——因为它没有进入"知识→智慧"的转化链。

## 六、用已有insight深化分析

### insight #36（文化建构）——公基是"普遍知识"还是"文化建构"？

```
公基的"政治常识"=马克思主义+中国特色社会主义
  → 这是"普遍真理"还是"特定文化/制度的建构"？
  → insight #36的框架：MANIFESTO的"默认怀疑"是西方建构
  → 公基的"政治常识"也是建构——它是A5（党国一体）的意识形态基础
  → 但公基不教"这是建构"——它教"这是真理"
  → = 公基的认识论立场：教条主义（不反思自身）
```

### insight #37（教育设计）——公基的评价有效吗？

```
公基的评价=选择题/判断题/简答题
  → 评价的是"记忆"不是"能力"
  → insight #37：有过程评价无结果评价
  → 公基更极端：连"过程"都不评价——只评价"最终记住的"
  → = 评价不闭环：记住≠理解≠会用≠能做好公务员
```

### insight #43（双减）——公考培训会像K12一样被整治吗？

```
K12培训→双减→禁止
公考培训→？？
  ↓
相似性：
  - 都是"考试驱动"的知识灌输
  - 都制造焦虑（考不上=没前途）
  - 都是"记住不理解"
  ↓
差异：
  - K12影响未成年人→社会关注度高
  - 公考影响成年人→社会关注度低
  - 公考培训=体制选拔的"辅导"→体制可能不禁止（它服务于选拔）
  ↓
= 公考培训不太可能被"双减"——因为它是体制的辅助，不是体制的对立面
```

## 七、综合洞察

### 公基的"知识画像"

```
公基 = 信息层知识 × 党国体制筛选工具 × 教条化哲学 × 记忆导向评价
  ↓
= 它不是"教育"——是"筛选"
= 它不培养"智慧"——只检验"信息"
= 它不追问"为什么"——只要求"记住"
```

### 公基的深层功能

> 公共基础知识表面上是"知识考试"，深层是**A5（党国一体）的三个功能**：
> 1. **忠诚度检验**——政治常识=你是否认同体制
> 2. **规则认知**——法律/公文=你是否懂体制的规则
> 3. **服从性测试**——公基的"背而不问"=你是否愿意接受不质疑
>
> **公基考的不是"你知道多少"——是"你是否适合这个体制"。**

### 费曼复述（一句话）

> 公共基础知识像一本"体制说明书"——它告诉你体制的规则（法律）、体制的语言（公文）、体制的理念（政治）、体制的运作（管理）。你不需要"理解"它——只需要"记住"它。**因为体制不需要你"理解"——需要你"执行"。公基考的不是"你懂不懂"——是"你服不服从"。**
