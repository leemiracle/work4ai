## 分析模板

每篇分析报告统一使用以下结构：

1. **问题**——分析什么真实问题
2. **工具**——调用了哪些essence工具（框架/思想家/insight）
3. **分析**——多维度交叉分析
4. **核心洞察**——一句话总结
5. **费曼复述**——大白话重述
6. **待验证**——开放问题
7. **工具调用清单**——实际使用了哪些工具
