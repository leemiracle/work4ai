## 第一章 设计目标（Why）

### 说明层：国家为什么存在？

国家的四个根本目标：

```
国家
├── 维护公共秩序（防止暴力/保护安全）
├── 提供公共服务（教育/医疗/基建/社保）
├── 保障国家安全（国防/外交/反恐）
├── 促进经济社会发展（产业政策/市场规制）
└── 保护公民合法权益（法律/权利/救济）
```

**宪法表述**（说明）：宪法序言规定国家的根本任务是"沿着中国特色社会主义道路，集中力量进行社会主义现代化建设"。

### 马克思主义文献关联

- 毛泽东《论人民民主专政》：区分"人民"和"敌人"→"公共"的范围由谁界定？

## 第三章 核心配置（Core Architecture）

### 说明层：国家机构体系

```
中华人民共和国
├── 宪法（根本大法）
├── 国家机构
│   ├── 全国人民代表大会（最高国家权力机关）
│   │   └── 常务委员会（闭会期间行使职权）
│   ├── 国家主席（国家元首）
│   ├── 国务院（最高行政机关）
│   │   └── 各部委/直属机构
│   ├── 国家监察委员会（最高监察机关）
│   ├── 人民法院（审判机关）
│   │   └── 最高法→高法→中法→基层法院
│   ├── 人民检察院（法律监督机关）
│   │   └── 最高检→省级→市级→基层
│   ├── 中央军事委员会（武装力量领导）
│   └── 国家安全委员会（综合安全协调）
└── 地方国家机关（省/市/县/乡镇四级）
```

**各机构职权**（说明）：
- 人大：立法权/监督权/人事任免/重大事项决定
- 国务院：行政权/行政法规制定/预算执行/经济管理
- 法院：审判权（刑事/民事/行政）
- 检察院：公诉/法律监督/公益诉讼
- 监察委：反腐败/政务监督

## 第四章 权限系统（Authority）

### 说明层：权力如何分配

```
立法权 → 全国人大及其常委会
行政权 → 国务院（中央）+ 地方政府
审判权 → 人民法院
检察权 → 人民检察院
监察权 → 国家监察委员会
军事权 → 中央军事委员会
```

**权限划分原则**（说明）：
- 职权法定：权力来源于法律授权
- 权责统一：有权必有责
- 监督制约：监察权+检察权+人大监督
- 下级服从上级：行政系统内的层级关系

## 第五章 规则系统（Rules）

### 说明层：法律体系

```
法律体系
├── 宪法（最高效力）
├── 法律（全国人大制定）
│   ├── 基本法律（刑法/民法/行政法等）
│   └── 其他法律
├── 行政法规（国务院制定）
├── 地方性法规（省级人大制定）
├── 自治条例/单行条例（民族自治地方）
└── 规章（部门规章+地方政府规章）
```

**法律效力层级**（说明）：宪法>法律>行政法规>地方性法规>规章。上位法优于下位法。

**公基法律模块的核心内容**（说明）：
- 宪法：国家制度/公民权利/国家机构
- 民法：物权/合同/侵权/婚姻/继承
- 刑法：犯罪构成/刑罚/具体罪名
- 行政法：行政行为/行政许可/行政处罚/行政复议/行政诉讼
- 经济法：公司法/合同法/竞争法/税法

## 第六章 行政系统（Administration）

### 说明层：政府如何工作

```
行政流程
├── 决策（调查→方案→审议→决定）
├── 执行（部署→实施→协调）
├── 监督（检查→评估→问责）
└── 反馈（报告→修正→改进）
```

**具体行政行为**（说明）：
- 行政许可：审批/核准/登记
- 行政处罚：警告/罚款/没收/吊销/拘留
- 行政强制：查封/扣押/冻结/强制拆除
- 行政复议：对行政行为不服的救济
- 行政诉讼：民告官

**公文流转**（说明）：
```
下级请示 → 上级批示 → 下级执行 → 上级报告 → 归档
  ↑                                              │
  └──────── 反馈 ←───────────────────────────────┘
```

## 第七章 公文系统（Communication）

### 说明层：国家如何沟通

```
公文种类（15种）
├── 上行文：请示/报告/意见
├── 下行文：决定/命令/批复/通报/通知
├── 平行文：函/议案
└── 公开文：公告/通告/公报
```

**公文格式**（说明）：
- 标题（发文机关+事由+文种）
- 主送机关
- 正文（缘由+事项+要求）
- 发文机关+日期+印章

**为什么格式统一**（说明）：
- 降低沟通成本（标准化=效率）
- 确保严肃性（形式=权威）
- 便于归档检索（标准化=可检索）

## 综合分析

### 用计算机操作系统比喻总结

```
国家 = 操作系统（State OS）
├── 内核 = 宪法+国家制度
├── API = 法律体系
├── 进程 = 政府机关
├── 线程 = 各部门
├── 消息 = 公文系统
├── 资源管理 = 财政系统
├── 用户 = 公民
├── 管理员 = 公务员
├── 日志 = 档案系统
├── 安全 = 监察系统
├── 更新 = 法律修改+政策调整
└── 环境 = 社会+国际
```

### 用哲学四支柱分层

| 支柱 | 说明层（公基做什么） | 评价层（可以追问什么） |
|------|-------------------|---------------------|
| 本体论 | 国家"是"什么——制度/机构/职权 | 国家的本质是什么？人民主权？党主权？ |
| 认识论 | 如何"知道"国家规定——法律/法规/文件 | 这些规定可靠吗？可证伪吗？ |
| 价值论 | 国家"追求"什么——秩序/发展/安全 | 这些价值排序合理吗？谁的排序？ |
| 逻辑学 | 国家"如何"运行——程序/流程/公文 | 程序正义vs实质正义？ |

### 用6条公理映射

| 公理 | 公基中的体现 |
|------|------------|
| A1地理 | 国情社情（地理/人口/资源） |
| A2规模 | 14亿人的公共服务+740万公务员 |
| A3大一统 | 全国统一的法律/政策/公文格式 |
| A4实用理性 | 公基偏"怎么做"不问"为什么" |
| A5党国一体 | 党的领导贯穿所有制度 |
| A6半脱嵌 | 社会主义市场经济=要素控制+产品市场 |

### 马克思主义文献的整合

| 马克思主义框架 | 对公基的关联 |
|-------------|------------|
| 历史唯物主义 | 公基的"经济制度"=经济基础；"政治制度"=上层建筑 |
| 阶级分析 | 公基的"人民民主专政"=阶级分析的制度化 |
| 革命理论 | 公基的"历史"模块=革命合法性的叙事 |
| 文化霸权 | 公基本身=文化霸权的工具（培养认同体制的公务员） |
| 实践认识论 | 公基的"行政"模块=实践→认识→实践 |
| 民族理论 | 公基的"民族"模块=斯大林民族定义的应用 |
| 社会主义建设 | 公基的"经济"模块=半脱_embed经济的制度化 |

### 核心结论

> 公基是一本**"国家运行说明书"**——它系统地说明了国家如何运行：制度是什么、法律怎么规定、行政如何运作、公文怎么写、财政怎么管。这是一个偏实践与制度运行的知识体系，主要回答"是什么"和"如何做"。
>
> **说明和评价必须分开**——公基本身是"说明性"的；"为什么这样设计""是否合理""有无替代"属于政治哲学/法哲学的研究对象。
>
> **essence项目的工具可以从"评价层"审视公基**——6条公理/哲学14分支/48条insight/3570篇马克思主义文献——但这些评价不应混入说明。
>
> **马克思主义文库的价值**：提供了从"评价层"审视公基的工具——历史唯物主义看经济基础、阶级分析看权力分配、文化霸权看意识形态运作、实践认识论看行政循环。
