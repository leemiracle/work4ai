# 住房制度

## 说明层

**住房体系**：

| 类型 | 占比 | 说明 |
|------|------|------|
| 商品房 | ~70% | 市场定价/自由交易 |
| 保障房 | ~10% | 廉租房/公租房/经适房/共有产权房 |
| 自建房/其他 | ~20% | 农村自建房/小产权房 |

**关键数据**：
- 城镇人均住房面积：~42㎡（超过多数发达国家）
- 房价收入比：一线城市30-50倍（国际警戒线6倍）
- 房产占家庭资产：~70%
- 房地产增加值占GDP：~7%
- 土地出让金占地方财政：~30%

## 马克思主义分析

| 框架 | 分析 |
|------|------|
| 地租理论 | 马克思：地租=土地所有者凭垄断占有的收入→中国：土地国有→地租归政府(土地出让金) |
| 物化 | 住房从"居住"→"投资品"→卢卡奇：居住关系物化为房价 |
| 虚拟资本 | 房地产金融化→虚拟资本膨胀→脱离实体经济 |

## insight深化

| insight | 分析 |
|---------|------|
| #47(房地产危机) | 20年正反馈(涨)→反者道之动→必然反转→正在发生 |
| #28(金钱=物化) | 住房=物化的极致——居住需求→投资品→"住"还是"炒"？|
| #52(共同富裕) | 房价收入比50倍→年轻人买不起房→"共同富裕"的障碍 |
| #21(波兰尼) | 土地=虚构商品→"房住不炒"=社会的自我保护运动 |

## 核心矛盾

```
土地财政的循环：
  政府卖地→收入→基建→城市升值→地价更高→卖更多钱
  ↓ 但
  房价太高→年轻人买不起→生育率下降→消费萎缩→经济放缓
  ↓ 且
  地卖不动了→财政危机(insight #47)
  ↓
= "反者道之动"——土地财政的正反馈到极点→必然反转
```

### 核心洞察

> 住房制度的**核心矛盾**：**"居住"和"投资"的双重属性**——住房既是消费品（住）又是投资品（涨）。**"房住不炒"试图把投资属性剥离——但如果房价不涨→没人买→经济下行。**
>
> **解法**：租购并举（租房也能有尊严）+ 保障房（底线）+ 房产税（抑制投机）+ 限制杠杆（去金融化）。但每一步都遇到既得利益。
>
> **费曼**：住房像一个"既是面包又是黄金"的东西——你要吃它（住）但你也想囤它（涨）。**问题是：当大家都囤的时候→面包变贵→吃不起→饿肚子。** "房住不炒"=告诉人"吃面包别囤黄金"——但谁信呢？

# 交通基建

## 说明层

**交通基建成就**：

| 领域 | 规模 | 全球地位 |
|------|------|---------|
| 高铁 | ~4.5万公里 | 全球第一（占2/3） |
| 高速公路 | ~18万公里 | 全球第一 |
| 5G基站 | ~340万个 | 全球第一（占60%） |
| 北斗导航 | 全球覆盖 | 全球第三大导航系统 |
| 港口 | 7个全球Top10 | 集装箱吞吐量全球第一 |
| 机场 | ~250个民用 | 持续扩建 |

## 6条公理分析

| 公理 | 分析 |
|------|------|
| A1地理 | 三级阶梯→基建打破地理阻隔→"天堑变通途" |
| A2规模 | 14亿人→全球最大的基建市场→规模经济 |
| A3大一统 | 全国统一网络→"八纵八横"高铁/全国5G覆盖 |
| A5党国一体 | 国家主导基建→集中力量→效率高但债务重 |
| A6半脱_embed | 基建=国家投资+市场运营→半脱_embed的基础设施版 |

## 马克思主义分析

| 框架 | 分析 |
|------|------|
| 生产力 | 基建=生产力的基础条件→"要致富先修路"→基建投资=生产力投资 |
| 不平衡发展 | 基建不平衡→东部密/西部疏→托洛茨基：基建差距=发展差距 |
| 剩余价值 | 基建降低交易成本→提高劳动生产率→更多剩余价值→但分配给谁？|

## 核心问题

```
问题1：债务
  基建投资→地方债务→城投平台→隐性债务~50万亿→还不起→财政风险
  
问题2：效率递减
  第一条高铁=巨大的经济回报→第100条=边际回报递减→"无效投资"
  
问题3：维护成本
  建设期=投资→运营期=维护→维护成本随老化增加→长期负担
  
问题4：技术依赖
  高铁核心技术→部分国产化但轴承/芯片仍依赖进口→insight #42(芯片封锁)
```

### 核心洞察

> 交通基建的**核心矛盾**：**"建设"和"运营"的不同逻辑**——建设期靠国家投资（集中力量）→运营期需要市场化（效率）→但很多基建无法盈利（高铁亏本/5G回报慢）→需要财政补贴→加重债务。
>
> **费曼**：基建像修路——修路的时候大家都高兴（就业/方便/政绩）——但修完之后路要养护/要还修路的钱——如果路上跑的车不够多（使用率低）→收的过路费不够养路→路越用越烂→要么加税要么不管。**中国现在到了"路修完了该还钱"的时候——但有些路跑的车不够多。**
