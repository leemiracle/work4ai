# 2026-07-13 · 跨书概念地图——从701万字全文中发现的模式

## 触发
对19本政治类书籍（701.5万字）做全文提取+44个概念的跨书量化追踪

## 洞察

### 发现1：概念分布的幂律性
44个概念在19本书中的分布呈极强幂律：
- 前5个概念（权力/制度/改革/开放/维稳）覆盖14本书——**通用概念**
- 后20个概念只出现在1-3本书中——**专有概念**
- 中间概念（合法性/运动式治理/行政发包等）覆盖4-7本——**核心理论概念**

**启示**：通用概念构成政治话语的"基础词汇"；专有概念标记学者的"理论贡献"；核心理论概念是**学术对话的真正战场**。

### 发现2："三周"概念互补
- 周雪光的核心概念（一统体制/有效治理/运动式治理/共谋/逆向软预算约束）集中在自己的书中
- 周黎安的核心概念（行政发包/晋升锦标赛）也集中
- 但两人在"绩效合法性""官僚制"上有交集——这是**理论对话点**

### 发现3：官方话语与学术话语的分离
- "社会主义"在习近平谈治国理政中出现1017次——但在周雪光/周黎安书中几乎为0
- "运动式治理"在周雪光书中145次——但在习近平书中为0（用"反腐败斗争"等替代）
- **官方话语和学术话语用的是不同的概念框架**——尽管描述同一现实

### 发现4：被忽视的概念
以下概念在19本书中几乎不出现：
- "半脱嵌"（0次）——essence项目独创，需要推广
- "大共同体/小共同体"（0次）——秦晖的概念在扫描版中（未OCR）
- "关系丛"（0次）——项飙的概念在扫描版中
- "数目字管理"（12次）——黄仁宇的概念使用不足

**启示**：essence项目有独特贡献（如"半脱嵌"），应该更积极地推广。

## 推论
- 概念的**出现频率**反映其在学术/政治话语中的**中心性**
- 跨书追踪可以揭示**学术对话的结构**——谁在和谁对话
- essence项目应该主动参与这些学术对话——把自己的概念（如"半脱嵌"）插入对话
