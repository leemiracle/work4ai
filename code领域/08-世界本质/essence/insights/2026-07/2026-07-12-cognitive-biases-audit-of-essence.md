# 2026-07-12 · 用心理学八大概念检验essence项目的认知偏误

## 触发

项目已经建了很多结构（40位思想家、28条insight、10-china六卷、12-epistemology四文件）。但认知偏误告诉我们：**建得越多越可能掉进偏误陷阱**。用心理学八大核心概念审计项目本身。

## 调用

- 思想家：`cognitive-psychologist`（council角色）+ 卡尼曼（系统1/系统2）+ `thinkers/chinese.md` 王阳明（知行检验）
- 迁移精度：**高**（认知偏误在任何决策审计直接可用）
- 来源：mental-models.md #21-23 + `03-social-sciences/psychology/_overview.md`

## 洞察

essence 项目在"建设"过程中至少暴露了五种认知偏误：沉没成本、确认偏误、收藏癖（收集机制）、达克效应（半懂就自信）、知行 gap。识别偏误本身不消除偏误——但它是修正的第一步。

## 推论

### 八大概念逐项审计

**1. 损失厌恶（Loss Aversion）**

```
项目表现：不愿意删任何已建的内容——即使调用率低
  ↓
心理机制：失去已有的东西比没得到新的更痛
  ↓
检验：如果今天从零开始，你会建同样的结构吗？
  → 如果不会→你是在保护"已有"而非追求"有用"
```

**2. 确认偏误（Confirmation Bias）**

```
项目表现：每次council审议都"决定加"——从未审议"该不该删"
  ↓
心理机制：寻找支持自己立场的信息，忽视反对证据
  ↓
检验：你有没有做过一次"审议是否应该删掉某些内容"的council？
  → 如果没有→审议框架有确认偏误（只有批准没有淘汰）
```

**3. 锚定效应（Anchoring）**

```
项目表现：第一个数字"40位思想家"锚住了后续判断——
  "调用率25%"的阈值、"<25%禁止扩展"的规则，都以40为分母
  ↓
心理机制：第一个数字统治整场判断
  ↓
检验：如果初始只有10位思想家，你的"健康调用率"标准会不同吗？
  → 可能会→25%这个阈值不是"客观的"，是被40锚定的
```

**4. 达克效应（Dunning-Kruger）**

```
项目表现：写了28条insight就觉得自己"理解"了这些思想家
  ↓
心理机制：半懂时最自信，真懂了反而谦逊
  ↓
检验：你能向一个完全不懂哲学的人讲清"哥德尔不完备性"吗？
  → 如果讲不清→你可能处于"达克曲线"的左侧（半懂高自信）
```

**5. 可得性偏差（Availability Heuristic）**

```
项目表现：最近添加的思想家（形式哲学家群组）被频繁调用——
  因为"刚学"=可得性高=容易想起来=容易被调用
  ↓
心理机制：容易想起来的=以为重要的
  ↓
检验：你调用的思想家，有多少是因为"最近添加"而非"真正最合适"？
  → 可能高估了新添加的，低估了已有但"不新鲜"的
```

**6. 沉没成本（Sunk Cost）**

```
项目表现：投入了大量时间建结构→不愿质疑结构是否合理
  ↓
心理机制：投入多了就不愿改变方向
  ↓
检验：如果今天才第一次看到这个项目，你会觉得它"有用"还是"庞大"？
  → 如果"庞大但不确定有用"→沉没成本在驱动继续投入
```

**7. 群体极化（Group Polarization）**

```
项目表现：council审议中多角色"碰撞"——但可能不是碰撞而是共鸣：
  所有角色都在同一个"哲学框架"内思考→结论被框架极化
  ↓
心理机制：同质群体讨论→观点更极端而非更平衡
  ↓
检验：council的角色库有40位思想家——但它们都来自"哲学传统"。
  一个商人/农民/工程师/儿童会怎么看这些结论？
  → 如果他们的视角完全不同→你的council有"哲学群体极化"
```

**8. 知行 Gap（Knowing-Doing Gap）**

```
项目表现：28条insight——但行为改变了吗？
  ↓
心理机制：知道≠做到——知识获取和行为改变是两个系统
  ↓
检验（王阳明）：哪条insight让你之后想问题不一样了？
  → 如果答不出→28条都是"收藏品"不是"知识"（insight #8）
```

### 偏误之间的关联

```
确认偏误 → 只加不删（框架偏误）
  → 沉没成本 → 不愿质疑已有结构
    → 达克效应 → 半懂就觉得自己"理解了"
      → 知行gap → 知道但不做
        → 损失厌恶 → 不愿删任何东西
          → 确认偏误（循环）
```

**洞察**：这些偏误不是独立的——它们形成了一个**自我强化的循环**。确认偏误让你只加不删→沉没成本让你不愿质疑→达克效应让你觉得"够了"→知行gap让知识不转化为行为→损失厌恶让你不删→回到确认偏误。

### 修正方向

| 偏误 | 修正 |
|------|------|
| 确认偏误 | 做一次"审议该不该删"的council |
| 沉没成本 | 问"如果今天从零开始，我会建同样的东西吗" |
| 达克效应 | 对每条insight做费曼检验——能向12岁孩子讲清吗？ |
| 可得性偏差 | 调用时问"我是因为'最近学的'还是'最合适的'而选这个人" |
| 知行gap | 对每条insight问"它改变了我的行为吗"——没改的标注"待消化" |
| 群体极化 | 引入非哲学视角——商人/工程师/儿童的视角 |
| 损失厌恶 | 定期做"删除审计"——哪些可以安全删掉？ |

## 待验证

- 这个审计本身有没有偏误？——元认知悖论：用偏误概念审计偏误，审计者自己也有偏误
- "识别偏误"能减少偏误吗？——卡尼曼说：知道偏误≠避免偏误（系统1太强）。但识别是第一步
- 王阳明的"知行合一"和认知心理学的"知行gap"——是一个问题的两种表述吗？
