# 中国金融体系

## 说明层

**金融体系结构**：

| 层次 | 机构 | 功能 |
|------|------|------|
| 央行 | 人民银行 | 货币政策/利率/汇率/金融稳定 |
| 银行业 | 6大国有行+股份行+城商行+农商行 | 存贷/支付/信用 |
| 证券业 | 券商/交易所（上交所/深交所/北交所）| 融资/投资/定价 |
| 保险业 | 寿险/财险/再保险 | 风险保障 |
| 信托/基金 | 信托公司/公募/私募 | 财富管理 |
| 监管 | 金融监管总局（2023年成立）+证监会 | 审慎监管/行为监管 |

**关键数据**：
- M2（广义货币）：~300万亿元
- 银行总资产：~400万亿元
- 股市总市值：~80万亿元
- 债券市场：~160万亿元

## 马克思主义分析

| 框架 | 分析 |
|------|------|
| 金融资本 | 列宁：金融资本=银行资本+工业资本的融合→中国：国有银行+国企=国家金融资本 |
| 虚拟资本 | 马克思：虚拟资本=脱离实体经济的金融资产→中国：房地产金融化=虚拟资本膨胀 |
| 信用制度 | 马克思：信用=生产过剩的杠杆→中国：信贷扩张=经济增长的杠杆但也是风险 |

## 6条公理分析

| 公理 | 分析 |
|------|------|
| A5党国一体 | 央行=国务院组成部门（不是独立央行）→货币政策服从政治目标 |
| A6半脱_embed | 金融=半脱_embed的极端——资金（要素）受政治控制/金融产品市场化 |

## 核心问题

```
问题1：房地产金融化
  土地财政→房地产泡沫→银行贷款集中在房地产→如果房价跌→银行坏账→金融风险
  = insight #47（房地产危机）的金融面

问题2：地方债务
  地方政府借债→城投平台→隐性债务~50万亿→还不起→财政危机→金融风险

问题3：金融开放
  资本账户管制→防止资本外逃→但也阻止了外资进入→半脱_embed的金融版

问题4：数字货币(DCEP)
  央行数字货币→替代现金→可追踪→金融监控→A5党国一体在金融中的延伸
```

### 核心洞察

> 中国金融体系的**核心特征**：**金融为实体经济服务**（不是金融主导经济）——这是A5+A6的金融体现。国有银行=半脱_embed的金融工具——资金分配服从国家战略而非市场效率。
>
> **优势**：危机应对能力强（2008/2020年逆周期调节）+ 防止资本外逃 + 定向支持战略产业
>
> **风险**：资金配置效率低（国企拿低息贷款/民企融资难）+ 房地产金融化 + 地方债务
>
> **马克思主义的评价**：列宁的"金融资本"理论需要更新——中国的金融资本不是"银行+工业资本"的私人融合，是"国家银行+国企"的国家融合。**国家金融资本主义=一种新的金融形态——不是私人垄断而是国家垄断。**

### 费曼

> 中国金融像一个"国家开的银行"——贷款给谁/利率多少/汇率怎么定——都是国家说了算。好处是：危机时国家可以命令银行"继续贷款"（2008年4万亿）。坏处是：银行可能贷给不该贷的人（国企/房地产）——因为政治命令>风险评估。**"国家银行"的好处和坏处都来自同一个地方：政治说了算。**

# 中国医疗卫生体系

## 说明层

**医疗体系结构**：

| 层次 | 机构 | 数据 |
|------|------|------|
| 公共卫生 | 疾控中心+卫健委 | 预防/监测/应急 |
| 医院 | 三甲(~3000家)/二级/一级/社区 | 三甲集中在大城市 |
| 基层 | 社区卫生中心/乡镇卫生院 | 覆盖率~95%但质量参差 |
| 医保 | 城镇职工医保+城乡居民医保 | 覆盖~13.3亿人(95%) |
| 药品 | 药企+药品监管局+集采 | 药品集采降价50%+ |

**医疗数据**：
- 卫生总费用：~9万亿元（占GDP ~7%）
- 人均卫生支出：~6400元
- 每千人医生数：~3人（美国~2.6/日本~2.4）
- 每千人床位数：~6.5张

## 系统科学分析

```
医疗系统
├── 边界：14亿人口
├── 组成：医院/基层/医保/药企/公卫
├── 流动：患者→医院→诊断→治疗→医保报销→康复
├── 反馈：
│   正反馈（恶化）：老龄化→需求↑→费用↑→医保压力↑→服务质量↓
│   负反馈（改善）：集采→药价↓→费用↓→医保可持续→服务改善
├── 控制：卫健委/医保局/药监局
├── 演化：医改2009→分级诊疗→集采→DRG付费→AI辅助诊断
└── 目标：全民健康覆盖+可负担+可持续
```

## insight深化

| insight | 分析 |
|---------|------|
| #44(AI×老龄化) | 老龄化→医疗需求暴增→AI辅助诊断→提高效率→但AI诊断准确吗？(insight #4康德) |
| #52(共同富裕) | 城镇职工医保vs居民医保——待遇差距→医疗领域的"共同富裕" |
| #29(偏误) | 医生诊断偏误——锚定（第一个诊断统治后续）+可得性（最近案例影响判断）|
| #39(系统) | 反馈：老龄化→需求↑→医生不够→AI替代→但AI不缴医保费→资源循环断裂？ |

## 反演

```
1.医保基金穿底→老龄化→支出暴增→基金耗尽→老年人看不起病
2.医疗资源不均→三甲集中大城市→基层空转→"看病难"→挤兑三甲
3.医患矛盾→信任缺失→暴力伤医→医生流失→医疗质量下降
4.药价虚高→药品流通链条太长→中间环节加价→患者负担重（集采在缓解）
5.AI误诊→AI辅助诊断→但训练数据有偏→误诊→责任归谁？
```

### 核心洞察

> 医疗体系的**核心矛盾**：需求无限（人想活更久）vs 资源有限（医生/钱/药）→ **必须分配**——但分配标准是什么？
>
> - 按需分配？→需求无限→资源耗尽
> - 按市场分配？→穷人看不起病
> - 按计划分配？→效率低/等待长
>
> **中国的选择**："保基本+多层次"——基本医保覆盖95%+商业保险补充+大病保险。但"基本"的标准是什么？——城镇职工和居民差距大。
>
> **马克思主义的评价**：医疗=劳动力再生产的条件——马克思说"劳动力的价值包括维持工人健康所需的医疗费用"。如果医疗市场化→劳动力再生产成本上升→剩余价值被医疗挤占→工人实际收入下降。**医疗不能完全市场化——它不是"商品"是"权利"。**（波兰尼：医疗是"虚构商品"——insight #21）

### 费曼

> 医疗像一个"生命保险公司"——14亿人缴费→生病的人用钱。问题是：**人越来越多老（需求↑）→缴费的人越来越少（收入↓）→钱不够分。** AI来了——AI能帮看病（提效）但AI不缴医保（不贡献）。**解法和养老一样：要么让AI也"缴费"（数据税补充医保），要么接受"医疗配给"（不是所有人都能得到最好的治疗）。**
