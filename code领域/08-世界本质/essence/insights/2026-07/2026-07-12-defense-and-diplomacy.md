# 国防现代化

## 说明层

**国防体系**：

| 军种 | 兵力 | 装备 |
|------|------|------|
| 陆军 | ~100万 | 坦克/火炮/直升机 |
| 海军 | ~30万 | 航母(3艘)/驱逐舰/潜艇 |
| 空军 | ~40万 | 歼-20/轰-6/运-20 |
| 火箭军 | ~10万 | 东风系列/巨浪系列 |
| 战略支援部队 | ~15万 | 网络/太空/电子战 |

**国防预算**：~1.67万亿元（2024年，占GDP~1.3%，全球第二）

**现代化目标**：2027年建军百年→2035年基本实现国防现代化→2050年世界一流军队

## IR理论分析

> **调用**：`11-world/01-ir-theories.md`

| 理论 | 分析 |
|------|------|
| 现实主义 | 军力=权力=安全→中国军力增长=安全困境→邻国/美国焦虑→军备竞赛 |
| 自由主义 | 经济相互依赖降低战争概率→但军事现代化可能打破平衡 |
| 建构主义 | "世界一流军队"=身份认同→大国必须有与地位匹配的军力 |

## 6条公理分析

| 公理 | 分析 |
|------|------|
| A3大一统 | "党指挥枪"=军队绝对服从党→大一统的军事保障 |
| A5党国一体 | 军委主席=党的主席=国家主席→军权/党权/政权统一 |
| A1地理 | 海军发展=从陆权转向海权→突破第一岛链 |

## 马克思主义分析

| 框架 | 分析 |
|------|------|
| 帝国主义论 | 列宁：帝国主义=军国主义→中国军力增长=新帝国主义？还是防御性？|
| 矛盾分析 | 国防投入vs民生投入→"大炮vs黄油"的经典矛盾 |
| 托洛茨基 | "不断革命"的国际版→军事力量支持外交扩张？|

## 反演

```
1.军备竞赛→中国扩军→邻国扩军→美国加强存在→螺旋升级→冲突风险
2.军工复合体→军费增长→利益集团→推动对抗→和平发展受阻
3.技术代差→如果技术跟不上→装备落后→"数量代替质量"→效费比低
4.台海误判→军事威慑→误判→冲突→美国介入→灾难
5.经济负担→军费增长→挤压民生/教育/科研→长期不可持续
```

### 核心洞察

> 国防现代化的**核心矛盾**：**"防御"和"扩张"的边界模糊**——中国说"防御性国防政策"——但航母/远洋海军/海外基地=进攻性能力。**邻国看到的是扩张，中国看到的是防御——视角不同=安全困境。**
>
> **费曼**：国防像买保险——保费（军费）越高保障越大——但保费太高→吃饭钱不够（民生）。而且邻居看你买保险→他也买→保费越来越贵→最后谁都付不起→但谁也不敢停。**这就是安全困境——所有人都在花更多钱但安全感没增加。**

# 中国外交战略

## 说明层

**外交框架**（新时代中国特色大国外交）：

| 层面 | 内容 |
|------|------|
| 大国关系 | 中美（竞争+合作）/中俄（全面战略协作）/中欧（务实合作）|
| 周边外交 | "亲诚惠容"→RCEP/上合/东盟 |
| 发展中国家 | "一带一路"/南南合作/中非/中拉 |
| 多边外交 | 联合国/G20/金砖/APEC/上合 |
| 全球治理 | "人类命运共同体"/全球发展倡议/全球安全倡议/全球文明倡议 |

## IR三理论分析

| 理论 | 对中国外交的解释 |
|------|----------------|
| 现实主义 | 中国崛起→挑战美国霸权→修昔底德陷阱→大国竞争 |
| 自由主义 | 经济相互依赖+多边机制→降低冲突→合作可能 |
| 建构主义 | "人类命运共同体"=新身份叙事→试图重塑国际规范 |

## 马克思主义分析

| 框架 | 分析 |
|------|------|
| 帝国主义 | 中国外交=反帝国主义（支持发展中国家）还是新帝国主义（资源获取/债务陷阱）？|
| 不平衡发展 | 全球不平衡→中国试图"南南合作"缩小差距→但中国自身也在制造新不平衡 |
| 霸权 | "人类命运共同体"=中国试图建立新的"文化霸权"？→与美国"自由民主"霸权竞争 |

## 反演

```
1.中美脱钩→竞争加剧→技术/贸易/军事全面对抗→新冷战
2.周边反弹→"国强必霸"→邻国恐惧→联合制华→"包围圈"
3.一带一路反噬→债务陷阱指控→国际形象受损→"新殖民主义"标签
4.价值观冲突→"人类命运共同体"vs"自由民主"→意识形态对立
5.内政外溢→国内政策（新疆/香港/人权）→国际批评→外交被动
```

### 核心洞察

> 中国外交的**核心矛盾**：**"和平崛起"的承诺vs 崛起引发的恐惧**——中国说"不称霸"——但实力增长本身就让别人害怕。**这不是中国的"错"——是国际体系的结构性矛盾**（修昔底德陷阱）。
>
> **马克思主义的评价**：中国外交=试图在帝国主义体系内走"非帝国主义"道路——但体系会把你推向帝国主义（实力增长→利益扩展→军事保护→霸权）。**能否"跳出"这个循环——取决于中国的自我克制+制度创新+他国的接受度。**
>
> **费曼**：外交像下棋——你的棋子越来越多（实力增长）→对手越来越紧张（安全困境）→你说"我只是想赢棋不是想吃你的棋子"——但对手不信。**问题不是你说什么——是你的棋子在那里。**
