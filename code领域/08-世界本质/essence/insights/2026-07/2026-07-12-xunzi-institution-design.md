# 2026-07-12 · 如果人性如此，需要什么制度？荀子检验项目的制度假设

## 触发

MANIFESTO 第十三条建了"正循环"和"刹车机制"。但这些机制假设了什么人性？如果人性是荀子说的"性恶"（趋利），正循环的刹车（"调用率<25%就停"）会被遵守吗？还是会被绕过？

## 调用

- 思想家：荀子（性恶→制度设计 / 化性起伪）
- 迁移精度：**高**（"如果人性如此，需什么制度"在任何制度设计直接可用）
- 来源：[`thinkers/chinese.md`](../../00-philosophy/thinkers/chinese.md) 第 5 位，council `institution-designer`

## 洞察

essence 的"正循环检查清单"假设人会**自觉遵守**——但荀子说人性趋利，人会绕过规则。检查清单需要**不可绕过的执行机制**，不能只靠自觉。

## 推论

### 荀子检验

**假设的人性**：MANIFESTO 的检查清单（"调用率<25%就停扩展"）假设用户会**自觉遵守**。这是孟子式的性善假设——"人认识到规则合理就会遵守"。

**荀子的反驳**：人性趋利。即使认识到规则合理，在**冲动来的时候**（"想加更多"的冲动），人会：
- 找例外（"这次特殊"）
- 重新定义标准（"25%太严格了，30%也行"）
- 直接忽略（"我知道但就是想加"）

**荀子的方案**：化性起伪——不靠自觉，靠**制度**。规则要设计成**不可绕过**的，或绕过成本很高。

### 对essence检查清单的改造

| 当前设计（性善假设）| 荀子改造（性恶假设）|
|---|---|
| "调用率<25%禁止扩展"（靠自觉）| git pre-commit hook：调用率<25%时提交新思想家→自动拒绝 |
| "2周无insight禁止添加"（靠自觉）| 检查insights/最后修改时间，超2周→禁止git add新目录 |
| "说不出'会用来分析什么'就不加"（靠自觉）| 强制要求：新思想家必须附带一条调用计划（具体问题+预期操作）|
| 周反思模板（靠自觉填）| 不填反思→禁止下一次git commit（用hook强制）|

**关键转变**：从"我应该"到"我不得不"——制度把自律变成他律。

### 荀子vs孟子的张力

essence 项目的内在矛盾：
- MANIFESTO 的方法论假设性善——"人认识到就会做"（费曼、苏格拉底都假设理性自觉）
- 但项目的实际行为模式（扩展冲动、收藏癖、知行 gap）证明了性恶——认识到但不做

**荀子的洞察**：不是人不理性，是**理性在冲动面前不够强**。所以需要制度——不是让人"想对"，是让人**即使想错也做不了**。

### 与王阳明的张力

王阳明说"知行合一"——知道但不做=没真知道。荀子说"知道但不做是正常的——因为人性趋利"。

两个立场：
- 王阳明：问题在"知"——你没真知道，所以不做
- 荀子：问题在"行"——你真知道了也不做，因为人性如此

**实践差异**：王阳明的方案是"深化认知"（让知识更真切），荀子的方案是"建制度"（让不做不可能）。essence 项目需要**两者并行**——深化认知（知行合一）+ 制度保障（化性起伪）。

## 待验证

- 荀子的"性恶"是否过于悲观？有些人在没有制度约束时也守规则——为什么？是后天教化（化性起伪成功）还是天性？
- git hook 强制机制是否可行？技术上可以，但会不会变成"形式主义"——填了模板但模板是应付的？
- "制度让他律"和"自律"哪个更可持续？长期靠制度可能削弱自律能力（依赖外部约束）
