# 2026-07-12 · essence项目的社会结构审计——调用率=社会分层

## 触发

社会学说"个体形成社会，社会塑造个体"。essence项目也有"社会结构"——40位思想家=人口、调用率=分层、MANIFESTO=制度、方法论=文化。用社会学审视项目自身的"社会"——谁被"边缘化"了？

## 调用

- 思想家：福柯（权力-知识——谁的知识被算作"真理"）+ 曼海姆（知识社会学——研究者的位置）+ 托克维尔（多数暴政——多数淹没少数）
- 迁移精度：**高**（"社会分层如何影响知识生产"在项目审计直接可用）
- 来源：`03-social-sciences/sociology/_overview.md`

## 洞察

essence项目的思想家库有一套"社会分层"：被高频调用的=精英（康德/尼采/福柯/韦伯），从未被调用的=边缘群体（孔子/柏拉图/苏格拉底/弗雷格/希尔伯特/Ubuntu/冯友兰/朱熹…）。这个分层不是"谁更重要"——是"项目的关注偏向什么"。被边缘化的不是弱者，是**被项目的问题选择所忽视的视角**。

## 推论

### 分层分析

**"精英"层（被调用≥3次）**：
- 尼采（谱系分析）——3次
- 福柯（权力-知识）——3次
- 韦伯（理性化）——3次
- 荀子（制度设计）——3次
- 王阳明（知行检验）——3次

特征：**批判性/反思性/制度分析**的思想家被高频调用——项目的关注偏向"批判与反思"。

**"中产"层（被调用1-2次）**：
- 康德/罗尔斯/布劳威尔/哥德尔/库恩/维特根斯坦/笛卡尔/老子/庄子/熊彼特/波普尔/波兰尼/龙树/阿伦特/托克维尔/伯林/哈贝马斯/亚里士多德/黑格尔

特征：**多元化的视角**——覆盖哲学/形式/社会/中国。

**"边缘"层（从未被调用——21位）**：
- 苏格拉底/柏拉图/马基雅维利/斯宾诺莎/霍布斯/洛克/休谟/卢梭/叔本华/密尔/胡塞尔/伽达默尔/德里达/赛义德/罗蒂/巴特勒/曼海姆/孔子/朱熹/冯友兰/希尔伯特/罗素/弗雷格/布劳威尔（部分）

特征：**被忽视的视角**——

### 被边缘化的是谁？

| 被忽视的群体 | 可能原因 | 被忽视的代价 |
|------------|---------|------------|
| **古典哲学家**（苏格拉底/柏拉图/亚里士多德已调用但深度不够）| 项目偏"批判"不偏"建构" | 缺少"什么是好"的建设性视角 |
| **早期现代**（霍布斯/洛克/休谟/卢梭）| 项目偏20世纪思想家 | 缺少社会契约/经验论/自然状态的根基 |
| **非西方**（Ubuntu/冯友兰/朱熹）| 项目偏西方分析传统 | 缺少关系性本体论/中国哲学的系统视角 |
| **形式哲学家未调用**（弗雷格/希尔伯特/罗素已调用但少）| 布劳威尔/哥德尔更"好用" | 缺少逻辑主义/形式主义的完整图景 |
| **当代批判理论**（巴特勒/德里达/赛义德/罗蒂）| 项目偏"经典"不偏"当代" | 缺少性别/解构/后殖民/反讽的视角 |

### 福柯的诊断

福柯说：知识-权力——谁的知识被算作"真理"。

essence项目的"真理"由谁定义？由**调用频率**定义——被调用的思想家=被承认为"有用的"，未被调用的=被边缘化。

但这不是"客观的不可替代性"——是**项目的问题选择塑造了"谁有用"**。如果项目从"批判与反思"转向"建构与实践"，被边缘化的苏格拉底（建构性追问）、洛克（权利建构）、冯友兰（境界建构）可能变得"有用"。

### 曼海姆的补充

曼海姆说：研究者的位置塑造了研究。

essence项目的"位置"是什么？——一个**偏批判/偏反思/偏西方/偏20世纪**的位置。这个位置不是中立的——它决定了什么问题被问、什么思想家被调、什么insight被产出。

### 托克维尔的警告

"多数暴政"——在essence项目中，"批判性视角"（尼采/福柯/韦伯）是"多数"——它们的高频调用压制了"建构性视角"（洛克/密尔/冯友兰）的声音。不是有意的压制——是**可得性偏差**（insight #29）：最近学的/容易想起的被频繁调用，形成"多数"。

### 修正方向

| 问题 | 修正 |
|------|------|
| 古典建构性视角被忽视 | 有意调用苏格拉底/柏拉图/洛克分析"什么是好" |
| 非西方视角边缘化 | 有意调用Ubuntu/冯友兰/朱熹分析"关系性/境界" |
| 当代批判理论缺失 | 有意调用巴特勒/赛义德分析"性别/后殖民" |
| 问题选择偏向批判 | 加入"建构性"问题——不只是"X有什么问题"，还有"X应该怎样" |

## 待验证

- "调用率=分层"的类比有多强？——思想家不是人，没有"被压迫"的体验。但知识生产的"边缘化"是真实的——被忽视的视角=被沉默的视角
- "有意调用"会不会变成"形式主义"（调了但不用心）？——可能。但不调用=永远沉默。先调再用，用不好再淘汰
- 项目的"偏批判"是问题还是特色？——如果目标是"认识世界"，批判+建构都需要。如果只有批判→只见问题不见方案
