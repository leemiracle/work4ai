# 2026-07-12 · council审议有没有犯逻辑谬误？非形式逻辑审计

## 触发

essence项目做了多轮council审议（立场/王沪宁/人性文化/扩展思想家/数学哲学等）。council的多角色碰撞是"有效推理"还是"看似深刻的谬误"？用非形式逻辑的谬误清单审计council本身。

## 调用

- 思想家：`thinkers/western.md` 维特根斯坦（#11——语言治疗）+ `thinkers/formal-philosophers.md`（形式推理标准）+ `cognitive-psychologist`（偏误与谬误的交叉）
- 迁移精度：**高**（谬误清单在任何论证审计直接可用）
- 来源：`02-formal-sciences/logic/_overview.md`

## 洞察

council审议整体上**有效但有几处系统性谬误风险**：稻草人（devil角色容易歪曲对方）、诉诸权威（"康德这么说"替代论证）、虚假二分（"要么有立场要么没有"）、循环论证（"正循环有效因为它循环"）。识别这些谬误不否定council的价值——但能提升其质量。

## 推论

### 逐谬误审计

**1. 稻草人谬误（Straw Man）**

council的设计：devil"系统性反对主流观点"。但devil的prompt要求"无论其他角色说什么，你必须找到反对的理由"——这**系统性鼓励稻草人**：devil可能歪曲对方观点来更容易反驳。

```
其他角色说："X在条件C下有效"
devil可能歪曲为："X无条件有效"→更容易反驳
  ↓
= 稻草人：歪曲对方观点再反驳
```

**修正**：devil的prompt应加"你必须先**准确复述**对方观点，然后反驳——歪曲后反驳不算"。

**2. 诉诸权威（Appeal to Authority）**

council的角色名虽然用"操作名"（如`transcendental-examiner`而非"康德"），但在insight和10-china中，大量使用"康德说""韦伯说"作为论证支撑。

```
"康德的先验追问暴露了AI的三个未证假设" 
  → 这是论证还是权威背书？
  → 如果康德错了呢？"康德说"不替代"为什么对"
```

**修正**：每次引用思想家时问——"这个论证不依赖思想家名字也成立吗？"如果不成立→诉诸权威。

**3. 虚假二分（False Dichotomy）**

第一场council"所有事情都带立场吗"——结论是"有些带有些不带"。但审议过程中多次出现"要么有立场要么没有"的虚假二分。庄子角色最终破了它（insight #17），但其他角色一度困在二分里。

```
虚假二分："要么立场要么无立场"
实际：立场/无立场的二元本身是人为切割（庄子/龙树）
  ↓
= council有时需要东方角色来破除二分，否则会困在西方二元里
```

**4. 滑坡谬误（Slippery Slope）**

10-china/06-future.md 中"AI→大规模失业→社会不稳定→体系崩溃"的推理链——每一步都是可能的但非必然的。如果没有因果证据连接每一步，就是滑坡。

```
AI替代劳动力 → 失业？ → 不一定（可能创造新就业）
失业 → 社会不稳定？ → 不一定（如果有UBI/再培训）
不稳定 → 体系崩溃？ → 不一定（制度可能适应）
  ↓
= 每一步都是"可能"不是"必然"——滑坡
```

**修正**：每一步推理问"这一步的因果机制是什么？概率多大？"

**5. 循环论证（Circular Argument）**

MANIFESTO第十三条"正循环有效"——但"正循环"的定义就包含了"有效"（循环=学→用→反馈→修正→更好的学）。如果定义中已包含结论，就是循环。

```
"正循环导致更好的认识"
  → 为什么？
  → "因为循环中反馈修正了错误"
  → 为什么反馈能修正？
  → "因为正循环"（循环）
```

**修正**：需要外部证据——"正循环"的使用者比不使用者认识更好吗？这需要经验数据，不能只靠定义。

**6. 诉诸动机（Ad Hominem circumstantial）**

question skill质问用户"你想相信它吗"——这质疑动机而非论证。虽然在元认知层有价值（识别偏误），但如果用来否定论证内容，就是诉诸动机。

```
"你想添加更多所以你的论证有偏"
  → 这不否定"添加更多是对的"——只说明动机可疑
  → 动机可疑≠论证错误
```

**修正**：区分"你的动机是什么"（元认知）和"你的论证对不对"（逻辑）。前者有价值但不能替代后者。

**7. 生态谬误（Ecological Fallacy）**

council用"哲学家群体的视角"分析问题——但"哲学家群体"的共识不适用于每个具体情境。

```
"所有哲学家都认为X"
  → 不意味着"在你的具体情境中X成立"
  → 哲学家的共识是抽象的，你的情境是具体的
```

### 谬误之间的关联

```
诉诸权威 → 用思想家名字替代论证
  → 稻草人 → devil歪曲对方更易反驳
    → 虚假二分 → 困在二元中看不到第三选择
      → 循环论证 → 定义中包含结论
        → 诉诸权威（循环）
```

### council的总体评价

| 维度 | 评价 | 理由 |
|------|------|------|
| 多视角碰撞 | ✅ 有效 | 不同角色提供不同视角 |
| 谬误风险 | ⚠️ 有系统性风险 | 稻草人/诉诸权威/虚假二分 |
| 自我修正 | ✅ 有潜力 | 遍历性检查+devil角色可以互相纠偏 |
| 外部校准 | ❌ 不足 | 封闭在哲学框架内，缺外部验证（insight #31）|

**核心洞察**：council的价值不在"无谬误"——在于"谬误被多角色暴露的概率比单人思考高"。但如果不审计谬误，council可能**系统性地产生某些类型的谬误**（特别是稻草人和诉诸权威）。

## 待验证

- 稻草人风险能否通过prompt设计消除？——devil的prompt加"先复述再反驳"可能有效
- 诉诸权威和"调用思想家"的边界在哪？——引用思想家的**操作**（如"先验追问"）是工具使用，引用思想家的**名字**作为论证支撑是诉诸权威
- 循环论证——"正循环"真的循环吗？——如果"反馈修正错误"有独立的经验证据（如学习科学数据），就不是循环而是经验命题
