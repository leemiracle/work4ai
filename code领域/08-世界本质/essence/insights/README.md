# Insights · 洞察沉淀场

> "灵感易逝，文字永存。"  
> 这里存放**碎片化、高价值、带日期**的洞察。不是完整笔记，而是**一闪念**的捕捉。

---

## 什么样的东西写到这里？

**不是**：
- ❌ 完整的概念讲解（那应该在学科目录或 `08-cross-cutting/`）
- ❌ 系统的读书笔记（那应该在 `reading-list/` 或对应学科）
- ❌ 流水账（那应该在私人日记里）

**是**：
- ✅ **一闪念的洞察**：突然想通的某个连接
- ✅ **跨学科的桥**：突然发现 X 和 Y 是同一个东西
- ✅ **反直觉的发现**：原以为 A，其实 B
- ✅ **被推翻的旧观点**：我曾经坚信 X，现在觉得是错的，理由是...
- ✅ **未成形的直觉**：我隐约觉得 X，但还说清，先记下来

## 单篇模板

```markdown
# YYYY-MM-DD · [一句话主题]

## 触发
（什么场景/对话/阅读让我想到这个）

## 调用
（用了哪位思想家的什么思维操作？链接到 thinkers/）
- 思想家：[人名]（[操作]）
- 迁移精度：高/中（如果是中，标注"类比非证明"）

## 洞察
（一句话核心）

## 推论
（如果这是对的，意味着什么）

## 待验证
（我还不确定的地方，需要进一步研究/查证）

## 关联
（链接到其他笔记/概念/大问题）
```

> **"调用"字段是正循环的关键**——它让思想家库从"收藏"变成"工具"。
> 每条 insight 必须记录调用了谁/什么操作。没有调用的 insight 不算数。

## 为什么必须强制沉淀？

1. **对抗遗忘**：灵感 24 小时内不记录就消失
2. **输出倒逼输入**：写不出来说明没真懂
3. **跨时间连接**：半年后回看，会发现当时以为是独立的事其实是同一现象
4. **训练观察力**：写多了你会越来越敏锐地"看见"洞察

## 回顾仪式

每月最后一天，读本月所有 insights：
- 哪几个洞察已经被纳入正式笔记？
- 哪几个被后来的思考推翻？
- 哪几个还是孤立的（没有产生新连接）？

把"高复利洞察"标星，扩展成正式笔记。
