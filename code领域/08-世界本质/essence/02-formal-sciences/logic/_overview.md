# 逻辑学总体框架 · Logic Overview

> 逻辑学回答：**如何保证推理是正确的？**  
> 不研究"人实际上怎样思考"（那是心理学），研究**什么样的推理是有效的**。

---

## 核心定位

```
语言负责表达
数学负责形式化
逻辑负责保证推理有效  ← 这里
计算机负责自动执行推理
```

> 逻辑不决定前提是否真实，决定在前提给定的情况下结论能否被正确推出。

## 关键区分

| 概念 | 定义 | 例子 |
|------|------|------|
| **有效性** | 推理形式正确（前提真→结论必真） | 所有人会死→苏格拉底是人→苏格拉底会死 |
| **可靠性** | 有效+前提实际为真 | 上例+前提确实为真=可靠 |
| **完备性** | 所有真命题都能被证明 | 一阶逻辑完备（哥德尔1929）|
| **不完备性** | 足够强的系统有不可证的真命题 | 算术不完备（哥德尔1931）|
| **可判定性** | 存在算法判断命题真假 | 命题逻辑可判定；谓词逻辑不可判定 |

> ⚠️ 完备性和不完备性是**不同层面**的定理，不应混为一谈。

## 非形式逻辑——谬误清单

| 谬误 | 定义 | essence中的风险 |
|------|------|----------------|
| 诉诸权威 | "X是专家所以X说的对" | "康德这么说所以对"——authority效应 |
| 稻草人 | 歪曲对方观点再反驳 | council中devil可能歪曲其他角色 |
| 滑坡 | "A→B→C→灾难"无因果依据 | "AI→失业→动乱→崩溃"的过度推断 |
| 人身攻击 | 反对人而非观点 | "你没用过所以你不懂" |
| 虚假二分 | 只有两种选择 | "要么立场要么无立场"（第一场council已破）|
| 诉诸动机 | "你有利益所以你说的不可信" | "你收集癖所以你想加" |
| 循环论证 | 结论出现在前提中 | "正循环有效因为它循环" |
| 生态谬误 | 从群体推断个体 | "哲学家都这样想" |
