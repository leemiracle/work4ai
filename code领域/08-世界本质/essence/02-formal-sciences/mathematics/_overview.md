# 数学总体框架 · Mathematics Overview

> 数学回答：**模式、结构、关系、变化和不确定性的形式化描述。**  
> 不是"计算"，是**抽象→定义→公理→推理→证明→理论**。

---

## 核心定位

```
哲学研究认识的基础
心理学研究认识的规律
神经科学研究认识的实现
认知科学研究认识的机制
语言学研究认识的表达
数学研究认识的形式化结构  ← 这里
```

> 数学不研究世界上的具体事物，研究**一切可以被抽象、表示、推理和建模的模式与结构**。
