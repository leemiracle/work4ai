# 信息科学总体框架 · Information Science Overview

> 信息科学回答：**信息是什么？信息如何产生、表示、存储、传输、处理、检索、利用，并最终形成知识和智能？**  
> 处于"世界→信息→知识→智能→决策→行动"链条的中心。

---

## 核心模型：信息生命周期

```
世界 → 数据 → 信息 → 知识 → 智能 → 决策 → 行动 → 新数据（反馈）↺
```

> DIKW：Data → Information → Knowledge → Wisdom

## 关键概念

| 概念 | 定义 | 项目关联 |
|------|------|---------|
| **信息量**（香农熵） | 不确定性的减少 | insight减少了多少不确定性？ |
| **信号 vs 噪声** | 有用信息 vs 干扰 | insight是信号还是噪声？ |
| **编码** | 信息→可传输的表示 | 概念→markdown文本=编码 |
| **信道** | 信息传输的媒介 | council对话/文本=信道 |
| **带宽** | 信道容量 | 每次council的角色数=带宽 |
| **冗余** | 重复信息 | 重复的insight=冗余 |
| **信息不对称** | 一方有另一方没有的信息 | 思想家调用不均=信息不对称 |

> ⚠️ 香农信息论衡量信息**量**，不衡量信息**意义**——"废话"和"洞察"可以有相同的信息量。

## 在认知科学链条中的位置

```
哲学 → 数学 → 逻辑学
  → 信息科学：如何表示/组织/传输/利用信息  ← 这里
  → 心理学 → 神经科学 → 认知科学
  → 教育学 → 社会学 → 人类学
  → AI：如何让机器完成信息处理与认知任务
```

> 信息科学关注"信息"，认知科学关注"认知"，AI 关注"智能实现"——三者密切相关但研究对象不同。
