### 1. Transformer架构的扩展

### 2. 生成模型的发展
- GAN (2014) → VAE/GAN → 扩散模型 (2020) → Stable Diffusion (2021)
- 生成质量和稳定性不断提升

### 3. 大模型训练的优化
- 预训练 → 微调 → PEFT (LoRA/QLoRA)
- 量化、剪枝、蒸馏
- 计算效率不断提升

### 4. 推理能力的提升
- Few-shot → Zero-shot → CoT → Tree-of-Thought
- 提示工程 → 提示优化 → 自动提示
- 思维链、反思、搜索

### 5. 多模态融合
- 视觉-语言 → 音频-语言 → 视频-语言
- 跨模态检索和生成
- 统一的多模态大模型
