## ✨ 核心功能详解

### 1. 📦 项目基础设施

**组件**:
- `config.json`: 系统配置文件
- `data_manager.py`: 数据库ORM（支持13张表）
- `utils.py`: 工具类库（8个工具类）
- `import_data.py`: 数据导入工具

**数据库表结构**:
```
- papers                    # 论文表
- learning_paths            # 学习路径
- path_papers               # 路径-论文关联
- applications              # 应用项目
- path_applications         # 路径-应用关联
- user_progress             # 学习进度
- practice_projects         # 实践项目
- quizzes                   # 测验题
- quiz_results              # 测验结果
- code_implementation       # 代码实现
- knowledge_graph           # 知识图谱
- milestones                # 里程碑
- ai_qa                     # AI问答记录
```

- 问题检索（基于关键词）
- 相关片段提取
- 多源信息聚合
- 置信度评分

**使用示例**:
