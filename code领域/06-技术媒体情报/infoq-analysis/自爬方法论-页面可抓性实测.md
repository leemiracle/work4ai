# 自爬方法论笔记：infoq.cn 页面可抓性实测

> 2026-07-15 ｜ 用 webfetch（执行 JS 渲染）逐页实测，验证哪些页面能静态抽取内容、哪些是纯 CSR 空壳。

## 关键结论

1. **infoq.cn 是"部分 SSR + 大量纯 CSR"混合架构**：首页、文章页、AI 快讯这 3 类高 SEO 价值/高内容密度的页面有 SSR（可被搜索引擎和静态工具抓取）；写作社区、minibook、hotlist、各类专区/活动页都是纯 CSR（空 `<div id="app">`）。
2. **这与维度1技术架构判断一致**：Vue CLI + Webpack 纯 CSR 是底座，但对 SEO 关键页面（首页/文章/快讯）做了 SSR/预渲染补救，其余页面不补救（反正对 SEO 不重要）。
3. **写作社区的 API 反爬**：xie.infoq.cn 的数据 API（/public/v1/article/getList 等）对非浏览器请求统一返回 **HTTP 451**，导致互动数据（阅读量/评论/点赞）无法静态获取。增补3 通过搜索引擎抽样+第三方 SEO 平台间接验证。
4. **方法论启示**：分析 infoq.cn 必须采用"直爬（仅文章/首页/快讯）+ 搜索引擎 site: 抽样 + 第三方平台（爱站/站长/SimilarWeb）+ delegate 深度调研"的混合策略，单一手段无法覆盖。
