# 关键事实核对与勘误（Fact-Check）

> 本项目贯穿"勘误优先"原则。以下为核实过程中纠正的常见错误/冲突信息。

## 勘误1：前端技术栈 Nuxt SSR → 实为 Vue CLI + Webpack 纯 CSR（高置信）

- **错误来源**：首页静态资源 URL 路径含 `/static/web/nuxt/www.infoq.cn/`，字面极易误判为 Nuxt SSR。
- **真相**：delegate 通过 urlscan.io 抓取**服务器原始返回的 HTML**，body 仅为空壳 `<div id="app"></div>`，无 `__NUXT__`/`__NEXT_DATA__` 全局变量；JS 产物为 `manifest + chunk-vendors + app` 三段式（**Vue CLI 默认 splitChunks 标志性输出**，Vite/Nuxt 均不产生此命名）。**实际为 Vue CLI + Webpack 纯 CSR**，`/nuxt/` 路径名系历史遗留/误导。
- **旁证**：同公司极客时间指南站 zhinan.geekbang.com 才真正用 Nuxt SSR（urlscan 捕获 `nuxt.zhinan...`）——同团队对不同产品差异化渲染（SEO 页用 Nuxt，交互门户用 Vue CLI CSR）。

## 勘误2：极客邦"成立年"2008 vs 2014 的真相——两个不同主体

公开资料对"极客邦科技成立年"存在三派说法（2008 / 2014 / 自称2007），实为**混淆了两个不同公司主体**。工商核实（企查猫/企知道）：

| 主体 | 全称 | 成立日期 | 角色 |
|------|------|----------|------|
| **控股公司** | 极客邦控股（北京）有限公司 | **2008-04-18** | 法人霍泰稳，注册资本 395.18 万，地址望京北路9号2幢7层A701（**即 InfoQ 网站页脚 Copyright 主体**） |
| **运营子公司** | 北京极客邦科技有限公司 | **2014-09-18** | 实际运营主体，由控股公司投资，霍太稳 100% 自然人股东 |

- 极客邦官网自称"创立于 2007 年"——**指品牌起点（InfoQ 中国上线），非公司注册年**。
- 百度百科"2014 创立极客邦科技" → 指**运营子公司**北京极客邦科技有限公司。
- 中华工商网"2008 创立极客邦科技收购 InfoQ 业务" → 说法不精确，**把控股公司成立(2008)与实际 MBO 收购(2015-2016)混为一谈**。
- **结论**：copyright 主体 = 极客邦**控股**公司（2008），运营主体 = 极客邦**科技**公司（2014）。两个日期都正确，指向不同实体。

## 勘误3：霍泰稳 vs 霍太稳（人名写法）

同一人两种写法并存：工商登记用 **"霍太稳"**（企查猫法人字段），但其 InfoQ 文章署名与多数媒体报道用 **"霍泰稳"**。二者为同一人（Kevin Huo）。本项目正文统一用"霍泰稳"，引用工商信息时保留"霍太稳"。

## 勘误4：收购 InfoQ 大中华区业务的年份——2015 MBO + 2016 签约

- **2015**：霍泰稳向 Floyd Marinescu 付款，完成 **MBO（管理层收购）**，成立极客邦科技独立运营（霍泰稳自述）。
- **2016**：极客邦科技**正式签署合约**，实现对 InfoQ 大中华区业务的整体收购（36氪 2016-10 报道）。
- 两个年份都对：2015 是交易实质（MBO），2016 是法律签约落地。百度百科采 2016。
