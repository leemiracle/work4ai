## 🧠 核心转向：认知提升体系（v1.13+，项目灵魂）

> 用户核心目标 = **提升认知**（看世界的维度），最终能**理解与改造制度/治理**。
> 论文(R-1/R-2/R-6)和技术(Katz/Vickrey/QV)只是验证认知的沙盘。

```
┌─────────────────────────────────────────────┐
│ L3 治理 (32): 规则如何运作 + 权力 + 改造     │
│   4范式(等级/市场/网络/算法) · QV · DAO       │
├─────────────────────────────────────────────┤
│ L2 制度 (31): 规则本质 + 机制设计             │
│   激励相容 · Vickrey · 显示原理 · Arrow 边界  │
├─────────────────────────────────────────────┤
│ L1 思维模型 (30): 15 可迁移模型 + 4 元认知     │
│   杠杆·权衡·复利·激励·网络·因果·涌现…        │
└─────────────────────────────────────────────┘
```

**认知主线**：思维模型(L1) → 制度(L2) → 治理(L3) → 改造(L4)。
**认知成熟度阶梯**：L0 事件 → L1 模式 → L2 结构 → L3 权力/心智 → **L4 改造（数学地基 35-41 完成，已兑现）**。
**数学专家目标** = 认知(L3 看世界) + 数学(精确表达/证明) = **L4 改造能力**。机制设计（博弈论+契约+拍卖+社会选择+动态+贝叶斯+总论）是从直觉理解升级到证明/设计制度的完整工具箱。
