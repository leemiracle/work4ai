# Python 综合学习项目

计算机在职研究生综合能力提升项目

## 项目结构

```
.
├── algorithms/      # 算法与数据结构练习
├── data_analysis/   # 数据分析与可视化
├── ai_ml/          # AI与机器学习实践
├── web/            # Web应用开发
├── system/         # 系统工具与脚本
├── backend/        # 后端API开发
├── tests/          # 单元测试
├── docs/           # 项目文档
└── requirements.txt # 依赖包
```

## 学习目标

- 算法与数据结构
- 数据分析与可视化
- AI/机器学习
- Web应用开发
- 系统编程
- 分布式系统
- 软件工程实践

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行测试

```bash
pytest tests/
```
