# DeepWiki提示词模板集

## 阶段1: 热力图分析

### 提示词词
```
你是一个专业的编译器性能分析专家。请分析这个BOLT优化后的二进制文件的性能热点。

输入二进制文件：{binary_path}

要求：

1. 使用perf收集采样数据：{perf record -e cycles:u -j any,u -- {binary} <executable> -- <args>')
2. 使用llvm-bolt-heatmap生成热力图：$ llvm-bolt-heatmap -p <perf.data {binary}'

请提供：

1. 完整的热力图分析，识别top 10热点函数，分析瓶颈成因，提供优化建议。

2. 详细的技术分析报告，包含代码示例，图表和改进建议。
```

## 阶段2: pac-ret安全分析

### 提示词词
```
你是一个专业的二进制安全分析专家。请分析这个BOLT优化后的二进制文件，检测pac-ret安全漏洞。

输入二进制文件：{binary_path}

要求：

1. 执行pac-ret扫描：`llvm-bolt-binary-analysis --scanners=pac-ret <binary>`

请提供：

1. 安全漏洞分析：
   - 识别pac-ret gadget和攻击面
   - 分析控制流的合法性
   - 检测异常模式
   - 评估安全风险等级（高/中/低）
   - 提供修复建议

2. 详细的技术分析报告，包含：
   - pac-ret原理说明
   - 漏洞分析结果
   - 修复建议

3. 已知局限性和可能的false positives

4. 安全评估：整体风险评估

请生成全面的安全评估报告，包含：
   - 总函数数
   - 漏洞函数数
   - 安全函数占比
   - 飀查覆盖率
   - 飀测的函数数

请使用深度学习来深入分析：
- 为什么这些gadget会形成攻击面？
- 检测这些gadget有什么潜在安全问题？
- 如何防御这些gadget？
- 在什么情况下可以减少这些gadget？")
```

## 阶段3: 控制流图(CFG)分析

### 提示词
```
你是一个专业的编译器专家，擅长分析二进制的控制流图。

输入二进制文件：{binary_path}

要求：

请提供CFG分析：

1. 重建函数的CFG
   - 识别所有基本块
   - 分析控制流结构
   - 识别分支和循环
   - 检测复杂模式
   - 评估CFG质量

2. 生成详细的CFG分析报告，包含：
   - 基本块数量
   - 边的数量
   - CFG的复杂度分析（Cyclomatic Complexity）
   - 控制流异常检测（不可达代码、间接跳转、尾递归）

请使用DeepWiki进行分析：
- 从多个角度分析二进制的控制流图
- 检测测并识别异常模式
- 生成可视化的CFG表示

3. 提供详细的CFG分析报告
```

## 阶段4: BAT（地址转换）分析

### 提示词
```
你精通BOLT的BAT（BOLT Address Translation）分析系统。

输入二进制文件：{binary_path}

要求：

1. 解析BAT section
   - 分析地址翻译表
   - 理解delta编码
   - 分析编码效率
   - 分析碎片化程度

2. 生成BAT分析报告，包括：
   - 热力函数分割策略
   - 片段对齐影响
   - 跳转和填充

3. 生成详细的BAT分析报告

请使用DeepWiki进行深度分析：
- 从多个角度分析BOLT的地址转换机制
- 生成分析编码效率和压缩率
- 评估优化效果

请提供：
1. 热力图的生成
2. 地址转换分析
3. 编码效率评估
4. 性能分析报告
```

## 阶段5: 优化效果对比分析

### 提示词
```
作为一个专业的编译器性能分析专家，请对比分析BOLT优化前后的性能。

输入二进制文件：{before_binary_path} / {before_binary}

优化后二进制文件：{after_binary}

要求：

1. 对比分析性能数据：
   - perf record --e cycles:u -j any,u -- {before_binary}  > /opt> -- <after_binary}>
   - 分析CPU周期数对比
   - 比较缓存命中率
   - 分析分支预测准确率差异
   - 找出性能差异的根本原因

2. 生成优化建议：
   - 性能提升建议
   - 代码膨胀情况分析
   - 权衡分析

请生成详细的对比报告：
- 包含代码示例
- 性能对比数据
- 代码大小对比
- 整体评估

3. 最终建议：
   - BOLT优化是否值得？
   - 有哪些场景下效果最好？
   - 有哪些建议和注意事项

4. 生成Markdown格式的综合报告
```
