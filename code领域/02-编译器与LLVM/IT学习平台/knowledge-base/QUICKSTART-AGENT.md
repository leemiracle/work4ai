# 快速开始指南

> AI智能体系统 - 从执行者转型为判断者的AI增强解决方案

---

## 🚀 三步启动（5分钟）

### 第1步：配置API密钥（2分钟）

```bash
# 设置GLM API密钥
export GLM_API_KEY="your-api-key-here"

# 验证配置
echo $GLM_API_KEY | cut -c1-8
```

---

### 第2步：启动AI Agent系统（2分钟）

```bash
cd knowledge-base
./ai_agent/start_agent.sh
```

### 第3步：开始AI增强能力提升（1分钟）

在菜单中选择 "1. 能力提升"，然后：
- 输入今天要提升的能力（如：问题定义）
- AI Agent会自动开始训练和评估

**总计**：约5分钟即可开始系统化的AI增强能力提升！

## 📊 AI Agent系统架构

### 智能体角色（6个）

| 角色 | 职责 | 使用模型 |
|------|------|---------|
| **训练器** | 负责每日认知训练和能力提升 | glm-4-flash（快速） |
| **分析器** | 负责深度分析和洞察生成 | glm-4-plus（深度） |
| **研究者** | 负责信息搜索和资料收集 | search-pro（搜索） |
| **规划器** | 负责任务分解和执行计划 | glm-4-plus（规划） |
| **执行器** | 负责具体任务执行 | glm-4-flash（快速） |
| **协调器** | 负责多智能体协调和调度 | 多模型组合 |

### 协作机制

```
用户需求
    ↓
协调器
    ↓
任务分解 → 分配智能体
    ↓
执行 → 验证 → 结果聚合
```
