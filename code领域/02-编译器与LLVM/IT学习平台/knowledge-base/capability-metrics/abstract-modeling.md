# 抽象建模能力指标

## 评估维度

### 维度1: 问题抽象深度 (30%)
- 能识别问题的本质而非现象
- 能从多个角度拆解问题
- 能提炼出核心矛盾

**打分标准:**
1-3分: 只能看到表面现象
4-6分: 能识别部分本质原因
7-8分: 能识别核心矛盾
9-10分: 能建立多层抽象模型

### 维度2: 模型结构化程度 (30%)
- 能用图表/公式清晰表达
- 模型有清晰的输入/输出/边界
- 模型能被他人理解和使用

**打分标准:**
1-3分: 模型模糊，难以复现
4-6分: 模型有一定结构但不够清晰
7-8分: 模型清晰可复现
9-10分: 模型优雅且可扩展

### 维度3: 模型验证能力 (20%)
- 能设计验证实验
- 能根据结果修正模型
- 能识别模型的适用范围

**打分标准:**
1-3分: 从不验证模型
4-6分: 偶尔验证但缺乏系统性
7-8分: 能系统验证并修正
9-10分: 能主动发现模型盲区

### 维度4: 跨域迁移能力 (20%)
- 能将一个领域的模型迁移到另一个领域
- 能识别不同问题的共通结构
- 能组合多个模型解决复杂问题

**打分标准:**
1-3分: 无法跨域迁移
4-6分: 偶尔能迁移但质量不稳定
7-8分: 能稳定跨域迁移
9-10分: 能创新性组合模型

## 提升路径

### Level 1-3: 基础阶段
- 练习: 每天用"5个为什么"拆解一个现象
- 练习: 画出3个日常问题的因果图
- 工具: 鱼骨图、5Why、第一性原理

### Level 4-6: 进阶阶段
- 练习: 每周建立一个抽象模型
- 练习: 复现经典模型并验证
- 工具: 系统动力学、因果推断、博弈论

### Level 7-8: 高级阶段
- 练习: 建立跨领域通用模型
- 练习: 设计模型验证框架
- 工具: 复杂网络、机器学习建模、元模型

### Level 9-10: 专家阶段
- 练习: 建立原创模型
- 练习: 带领团队建模
- 输出: 模型库、论文、教程

## 练习方法

### 方法1: 现象拆解练习
选一个社会/技术现象，用5Why不断深入：
1. 为什么会发生？
2. 为什么是现在？
3. 为什么是这种形式？
4. 深层原因是什么？
5. 最底层的矛盾是什么？

### 方法2: 模型构建练习
从零开始建立模型：
1. 定义问题边界
2. 识别核心变量
3. 建立变量关系
4. 验证模型预测
5. 迭代优化

### 方法3: 跨域迁移练习
选一个熟悉领域的模型，迁移到新领域：
1. 提取模型本质结构
2. 映射到新领域
3. 修正假设
4. 验证有效性
