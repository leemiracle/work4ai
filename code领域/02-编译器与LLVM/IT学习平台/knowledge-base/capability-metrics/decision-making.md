# 不确定性决策能力指标

## 评估维度

### 维度1: 风险认知 (25%)
- 能识别已知未知和未知未知
- 能量化不确定性程度
- 能区分可计算风险和不可计算风险

**打分标准:**
1-3分: 忽视风险或过度焦虑
4-6分: 能识别部分风险
7-8分: 能系统分析风险
9-10分: 能利用不确定性

### 维度2: 信息整合 (25%)
- 能从有限信息中提取关键
- 能判断信息质量
- 能平衡直觉和数据

**打分标准:**
1-3分: 要么全信数据要么全靠直觉
4-6分: 能初步整合信息
7-8分: 能系统整合多源信息
9-10分: 能发现信息中的盲区

### 维度3: 责任承担 (25%)
- 能为决策结果负责
- 能承认错误并快速修正
- 能在压力下坚持判断

**打分标准:**
1-3分: 推卸责任或犹豫不决
4-6分: 能承担部分责任
7-8分: 能为决策负责
9-10分: 能从错误中创造价值

### 维度4: 动态调整 (25%)
- 能监控环境变化
- 能快速调整策略
- 能保持核心方向

**打分标准:**
1-3分: 一旦决定就固执或轻易改变
4-6分: 能偶尔调整
7-8分: 能动态平衡
9-10分: 能引导变化

## 提升路径

### Level 1-3: 基础阶段
- 练习: 每天做一个微小决策并记录结果
- 练习: 列出每个决策的3种可能结果
- 工具: 决策矩阵、SWOT分析

### Level 4-6: 进阶阶段
- 练习: 重要决策前的情景分析
- 练习: 事后回顾决策过程
- 工具: 决策树、贝叶斯更新

### Level 7-8: 高级阶段
- 练习: 设计反脆弱策略
- 练习: 在组织中建立决策框架
- 工具: 期权思维、凯利公式

### Level 9-10: 专家阶段
- 练习: 识别系统性机会
- 练习: 引领团队穿越不确定性
- 输出: 决策方法论、案例库

## 练习方法

### 方法1: 事前验尸练习
重要决策前：
1. 假设决策失败
2. 倒推失败原因
3. 提前设计对策
4. 重新评估决策

### 方法2: 信息分级练习
面对复杂问题：
1. 列出所有已知信息
2. 标注信息可信度 (高/中/低)
3. 列出未知关键信息
4. 判断信息是否足够决策
5. 决策并说明理由

### 方法3: 意外收益分析练习
事后复盘：
1. 记录决策时的推理
2. 记录实际结果
3. 分析成功是运气还是能力
4. 提炼可复制的决策框架

## 决策类型

### 重复决策 (可优化)
- 特征: 频率高，模式相似
- 策略: 建立流程，优化参数
- 例子: 日常任务、代码评审

### 一次性决策 (需权衡)
- 特征: 频率低，影响大
- 策略: 深度分析，快速决策
- 例子: 职业选择、技术栈

### 演化决策 (需迭代)
- 特征: 目标模糊，环境变化
- 策略: 小步快跑，持续调整
- 例子: 产品方向、创业

## 决策框架

### 当信息充分
1. 列出所有选项
2. 量化每个指标
3. 加权评估
4. 选择最优

### 当信息有限
1. 列出关键假设
2. 识别最坏情况
3. 设计止损点
4. 快速试错

### 当信息冲突
1. 分离事实和观点
2. 检查来源可信度
3. 寻找第三方验证
4. 预留调整空间
