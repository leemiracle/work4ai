## 能力自检

### 执行者特征 (避免)
- [ ] 总是等别人分配任务
- [ ] 只问"怎么做"不问"为什么"
- [ ] 只关注如何实现，不问是否值得
- [ ] 不会质疑问题的前提
- [ ] 害怕做决策和承担责任

### 判断者特征 (目标)
- [ ] 能主动定义问题
- [ ] 能在信息不完整时做决策
- [ ] 能为决策结果负责
- [ ] 能整合多方资源
- [ ] 能影响他人

---

## 备注

重要提醒:
1. 关键不在每天做得多完美，而在持续思考
2. 判断力是练出来的，不是天赋
3. AI是工具，不是竞争者
4. 小决策积累成大判断力
5. 失败判断的价值在于学习
