## AI增强特性

### GLM模型集成

#### 模型映射

| 场景 | 推荐模型 | 原因 |
|------|---------|------|
| 快速练习 | glm-4-flash | 200并发，响应快 |
| 深度分析 | glm-4-plus | 20并发，推理强 |
| 平衡场景 | glm-4-air | 100并发，平衡好 |
| 代码相关 | codegeex-4 | 50并发，专用 |
| 知识检索 | embedding-3 | 100并发，向量 |
| 文献搜索 | search-pro | 5并发，搜索强 |
| 可视化 | glm-image | 1并发，图像 |

#### AI工作流

1. **每日认知训练**（10-15分钟）
   - glm-4-flash: 快速响应
   - 五层训练：拆解、推演、量化、系统、复盘

2. **能力评估**（每月）
   - glm-4-plus: 深度分析
   - 24个能力评估

3. **问题定义辅助**
   - glm-4-plus: 多角度分析
   - 5问题框架、假设质疑

4. **判断力训练**
   - glm-4-plus: 提供框架
   - 决策矩阵、事前验尸

5. **知识检索**
   - embedding-3: 向量检索
   - glm-4-plus: 语义理解
