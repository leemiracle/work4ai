## AI Agent系统详解

### 智能体架构

```
用户
  ↓
协调器
  ↓
┌────────┬────────┬────────┬────────┬────────┬────────┐
│Trainer│Analyzer│Researcher│Planner│Executor│
└────────┴────────┴────────┴────────┴────────┴────────┘
```

### 智能体功能

#### 1. 训练器 (Trainer)
- 每日认知训练
- 个性化训练计划
- 训练进度追踪
- 训练报告生成

#### 2. 分析器 (Analyzer)
- 深度分析输入
- 模式和趋势识别
- 洞察和建议生成
- 隐含假设识别

#### 3. 研究者 (Researcher)
- 信息收集和搜索
- 文献和案例检索
- 知识图谱构建
- 资源推荐

#### 4. 规划器 (Planner)
- 任务分解和规划
- 执行计划生成
- 资源分配
- 里程碑设置

#### 5. 执行器 (Executor)
- 具体任务执行
- 工具调用和集成
- 结果验证
- 错误处理和重试

### 协调器 (Coordinator)
- 智能体调度
- 任务路由
- 结果聚合
- 异步执行
- 错误恢复

## 工作流

### 工作流1：能力提升

**输入**："提升问题定义能力"

**执行流程**：
1. 分析器 → 分析当前水平
2. 规划器 → 创建30天计划
3. 训练器 → 每日训练
4. 执行器 → 验证进展
5. 分析器 → 总结进步

**AI使用**：
- 分析器: glm-4-plus 深度分析
- 规划器: glm-4-plus 任务规划
- 训练器: glm-4-flash 快速训练
- 执行器: glm-4-plus 执行验证

---

### 工作流2：问题解决

**输入**："系统性能下降"

**执行流程**：
1. 分析器 → 问题根因分析
2. 研究者 → 相关资料搜索
3. 规划器 → 解决方案规划
4. 执行器 → 实施解决方案
5. 训练器 → 能力提升

**AI使用**：
- 分析器: glm-4-plus 深度分析
- 研究者: search-pro 文献搜索
- 规划器: glm-4-plus 方案规划
- 执行器: glm-4-plus 方案执行

## 使用指南

### 快速开始（3步）

**第1步：配置API**
```bash
export GLM_API_KEY="your-api-key-here"
```

**第2步：启动系统**
```bash
cd knowledge-base
./ai_agent/start_agent.sh
```

**第3步：交互使用**
```bash
cd ai-agent
python3 main.py --interactive
# 选择 "1. 能力提升"
```

### 交互模式选项

```
1. 能力提升 - 多智能体协作提升能力
2. 问题解决 - 分析问题并生成解决方案
3. 单智能体 - 与单个智能体交互
4. 查看状态 - 查看系统状态
5. 退出
```
