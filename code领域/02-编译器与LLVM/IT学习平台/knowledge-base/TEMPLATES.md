# 模板使用指南

## 什么时候用哪个模板？

### 📅 日常使用

```
每天:
├── 选择能力 → start.sh
├── 做练习 → practices/template.md
└── 记录 → 每日检查清单 (CHECKLIST.md)
```

### 📊 定期复盘

```
每月:
├── 更新能力得分 → metrics/*.md
├── 月度复盘 → reviews/monthly/template.md
└── 调整下月计划
```

```
每季度:
├── 季度复盘 → reviews/quarterly/template.md
├── 评估转型进度 → ROADMAP.md
└── 调整长期目标
```

### 🚀 项目实战

```
开始项目:
├── 定义问题 → projects/template.md
├── 设计流程 → resource-integration.md
└── 追踪进度 → projects/template.md
```

```
学习新知识:
├── 学习 → learning-log/template.md
├── 理解 → cognitive-methods.md (费曼法)
└── 练习 → method-template.md
```
