---

## 项目总览

这是一个**AI增强的个人能力长期改进系统**，结合了：

1. **24个核心能力指标** - 系统化的能力评估体系
2. **57+个思维模型** - 认知工具和思维框架
3. **30天认知训练计划** - 可执行的日常训练
4. **60+个GLM AI模型** - 全方位AI辅助
5. **完整方法论库** - 100+个工具和方法

**核心目标**：在AI时代，通过系统化训练和AI辅助，从"执行者"转型为"判断者"

---

## 核心理念

### AI时代能力三原则

1. **AI压缩"执行价值"，放大"方向价值"**
   - 会做事的人变多，会决定做什么的人变稀缺
   - 判断力成为区分判断者和执行者的核心

2. **AI是工具，不是竞争者**
   - AI能生成"框架内问题"，不能"质疑框架"
   - AI能提供选项，但人类需要承担决策责任

3. **能力指数级分化**
   - Top 10%: 判断者与整合者 → 价值指数级增长
   - Middle 60%: AI协同执行者 → 价值稳定或缓慢增长
   - Bottom 30%: 被替代者 → 价值快速消失

## 核心能力（24个）

### 判断力层（最核心）⭐⭐⭐

1. **问题定义与选择** - 质疑框架、定义价值、选择真正值得解决的问题
2. **判断与取舍** - 复杂条件下的判断、长期vs短期权衡、风险承受

### 整合力层

3. **资源整合** - 整合人+AI工具+专家，设计工作流
4. **影响力与沟通** - 建立信任、协调利益、推动落地
5. **战略与策略** - 长期预见、目标定位、资源配置、风险管理

### 思维力层

6. **想象力** - 在现有信息基础上构造"尚不存在但可能存在"的结构能力
7. **抽象建模** - 把复杂现实变成结构化模型
8. **不确定性决策** - 在信息不完整时做决策并承担责任

### 认知层

9. **第一性原理** - 拆解到基本事实，从基本事实重新构建
10. **批判性思维** - 质疑假设、分析逻辑、评估证据
11. **元认知** - 元认知监控、元认知控制、元认知评估
12. **逆向思维** - 目标倒推、反果为因、逆向假设、路径验证
13. **结构化思维** - 要素识别、关系建立、清晰表达、结构优化
14. **系统性思维** - 整体性认知、关系性理解、动态性洞察

### 基础层

15. **快速迁移** - 抽象能力 × 结构识别能力 × 多领域暴露
16. **技术底层理解** - 深入理解系统瓶颈、性能边界、架构权衡

### 支持层

17. **复杂系统设计** - 全局架构设计、多维度权衡、系统性风险识别
18. **情商** - 自我觉察、自我管理、社交觉察、关系管理
19. **执行力** - 目标拆解、行动启动、持续推进、结果交付
20. **领导力** - 愿景能力、团队建设、沟通影响、决策担当
21. **学习能力** - 信息输入、知识整合、技能内化、迁移应用
22. **韧性** - 压力认知、情绪调节、问题解决、恢复反弹
23. **适应性** - 环境感知、学习调整、灵活应变、恢复反弹

## GLM模型能力

### 核心模型

| 模型类型 | 模型名称 | 并发权益 | 主要应用 | 使用场景 |
|---------|----------|---------|---------|---------|
| **通用模型** | glm-4-plus | 20 | 复杂推理 | 深度分析、决策辅助 |
| **通用模型** | glm-4-air | 100 | 平衡 | 日常咨询、知识检索 |
| **通用模型** | glm-4-flash | 200 | 快速 | 高频交互、快速练习 |
| **代码模型** | codegeex-4 | 50 | 代码 | 代码审查、技术实现 |
| **向量模型** | embedding-3 | 100 | 检索 | 知识检索、相似度分析 |
| **搜索模型** | search-pro | 5 | 搜索 | 文献检索、案例搜索 |
| **图像模型** | glm-image | 1 | 可视化 | 架构图、思维导图 |
| **实时音视频** | glm-realtime | 5 | 模拟 | 模拟对话、角色扮演 |

### 模型选择指南

```
日常练习（快速）
    ↓
glm-4-flash (200并发)

深度分析（复杂）
    ↓
glm-4-plus (20并发)

平衡场景（稳定）
    ↓
glm-4-air (100并发)

代码相关
    ↓
codegeex-4 (50并发)

知识检索
    ↓
embedding-3 + glm-4-plus
```

## AI工作流示例

### 示例1：AI辅助问题定义

```python
# 发送给 glm-4-plus
"""
对以下问题进行问题定义分析：

问题描述：我们的软件项目又延期了，需要加快进度。

请分析：

## 5问题框架
1. 问题是什么？
2. 为什么是问题？
3. 为谁而存在？
4. 为什么现在解决？
5. 不解决会怎样？

## 假设质疑
- 问题的前提是什么？
- 这个前提是真的吗？
- 有没有隐含的假设？

## 重新定义
原问题：我们的软件项目又延期了，需要加快进度。

新问题：[请提出重新定义的问题]

新问题更好的原因：[请说明]
"""
```

### 示例2：AI辅助判断力训练

```python
# 发送给 glm-4-plus
"""
提供决策分析框架：

决策背景：团队在技术选型上争论不休，无法达成共识。
可选方案：React vs Vue vs Angular

请提供：
1. 决策矩阵框架
2. 评估标准建议
3. 每个标准的权重建议

注意：不要直接给出答案，而是提供分析框架。
"""
```

### 示例3：AI辅助每日训练

```python
# 发送给 glm-4-flash
"""
分析以下观点：
"微服务比单体架构好"

回答：
1. 核心定义是什么？
2. 前提假设是什么？
3. 边界在哪里？
4. 有反例吗？
"""
```

## 核心原则

1. **写下来才能升级**
   - 不写下来 = 没有真正理解
   - 不写下来 = 无法追踪进步

2. **AI辅助，人类决策**
   - AI提供框架，自己做决策
   - AI分析选项，自己选择
   - AI提供视角，自己判断

3. **练习才能内化**
   - 知道不等于会
   - 练习才能变成能力
   - AI辅助加速练习

4. **应用才能验证**
   - 理论需要实践验证
   - 实战中发现问题
   - AI辅助实战应用

5. **复盘才能提升**
   - 不复盘 = 重复犯错
   - 复盘 = 持续进化
   - AI辅助深度复盘
