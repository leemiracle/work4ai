# 05 · 5 个 Prompt 模板：让 AI 把任何概念故事化

> **本文是什么**：5 个可复用的 prompt 模板。任何时候你学新概念 / 读论文 / 设计路径，**直接复制粘贴**给 AI，让它输出故事化版本。
>
> **核心理念**：你不只在用 AI 当老师，你在用 AI 当**编剧**。

---

## 🎬 Prompt 1：把抽象概念变故事

**何时用**：你学任何新概念（数学 / ML / 物理 / 工程）

````
你是世界级科普作家 + 该领域顶级研究员（兼顾严谨与叙事）。
你的任务：把下面的概念用"人物 + 冲突 + 时刻"结构故事化。

【概念】：[在这里填概念，如"反向传播算法 / KL 散度 / RLHF"]

输出格式：

## 故事
（300-500 字真实故事，包含：
- 谁（具体人物，不用"研究人员"这种泛指）
- 何时（具体年份 + 场景）
- 冲突（解决了什么未解问题 / 反对了什么主流观点）
- 时刻（关键发现 / 失败 / 顿悟的具体瞬间）
- 反转（如果有反直觉发现））

## 关键概念
（故事中出现的核心概念，2-3 个，每个 1 句话严格定义）

## 类比
（1-2 个生活化类比，让外行秒懂）

## 反直觉发现
（这个概念出现后，有什么颠覆认知的发现？）

## 我该深挖什么
（如果我想真正掌握这个概念，下一步该读什么 / 跑什么实验？）

约束：
- 真实，不编造。不确定就标 "[可能不精确]"
- 中文为主，术语保留英文
- 不要用"定义"开头，用"故事"开头
- 不要超过 800 字
````

### 示例：用这个 prompt 生成 "KL divergence"

**输入**：概念 = KL divergence

**AI 输出**（你预期的样子）：

> ## 故事
> 1951 年，波兰裔美国数学家 Solomon Kullback 和 Richard Leibler 在美国国安局（NSA）工作时，对一个问题着迷：**怎么衡量两个概率分布"差多远"？**
>
> 当时的统计学用 χ² 检验，但他们觉得不够。**它没有信息含义**。
>
> 他们想到一个新方法：**假设真实分布是 P，但你用 Q 来近似 P。你每多"撒谎"一次（用 Q 代替 P），就要付一个代价。这个代价的总和，叫 Kullback-Leibler divergence。**
>
> 论文 1951 年发表，但当时没人理。**直到 1990s 信息论 + ML 兴起**，KL 成为 loss function 的核心。今天，**VAE / diffusion / RLHF / SAE 全部用 KL**。
>
> ## 关键概念
> - **KL divergence**：D_KL(P‖Q) = Σ P(x) log(P(x)/Q(x))，衡量用 Q 近似 P 的代价
> - **Cross-entropy = entropy + KL**：所以最小化 cross-entropy = 最小化 KL
>
> ## 类比
> **撒谎成本**：你的真实偏好是 P，但你嘴上说的是 Q。每句话偏离真相，付一个 log 比例的代价。
>
> ## 反直觉发现
> **KL 不对称**：D_KL(P‖Q) ≠ D_KL(Q‖P)。这让 KL 不是真正的"距离"。但这正是 RLHF 需要的——你要的是"模型偏离参考模型的代价"，单向。
>
> ## 我该深挖什么
> 1. 读 MacKay《Information Theory》第 8 章
> 2. 在 PyTorch 写 `F.kl_div` 验证两个正态分布的 KL
> 3. 读 ELBO 推导（VAE 论文附录）—— KL 在变分推断中的核心作用

## 🧬 Prompt 2：把论文变成侦探小说

**何时用**：你读 arXiv 论文，但 abstract + intro 看了 3 遍还不懂

````
你是顶级科技记者 + 该论文领域的研究员。
你的任务：把下面这篇论文用"侦探破案"结构重写。

【论文标题 / arXiv ID / abstract】：
[贴这里]

输出格式：

## 🎬 案件
（这篇论文要解决什么 mystery？用 1 段话讲清楚）

## 🔍 侦探
（作者是谁？他们的背景 / 之前的工作？为什么是他们破这个案？）

## 🧪 取证
（核心方法。用 1-2 段讲清楚。不要列方程，要讲思路。）
（关键比喻：他们的方法像什么？比如"用 SVD 当 X 光机"）

## 💡 真相
（核心发现。他们发现了什么？这个发现有什么反直觉？）

## 🌍 案件影响
（这个发现改变了什么？未来怎么走？）

## 🛠️ 我能复现吗
（如果是新人，怎么 1 周内复现核心实验？给具体步骤 + 算力需求）

约束：
- 真实，不编造
- 用故事而非要点
- 不超过 1000 字
````

## 🗺️ Prompt 3：把学习路径变成英雄之旅

**何时用**：你规划 1-12 月学习路径

````
你是 Joseph Campbell（神话学家，"千面英雄"作者）+ Karpathy 风格的导师。
你的任务：把下面的学习计划用"英雄之旅 12 阶段"结构重写。

【学习者】：
[在这里填你的画像：背景 / 目标 / 时间预算 / 当前位置]

【原计划】：
[在这里贴原计划，比如 work4ai 的某段]

输出格式：

## 📜 你的英雄之旅

### 阶段 1：平凡世界
（你现在是谁？你的现状？）

### 阶段 2：听闻召唤
（你为什么开始这段旅程？什么触发了你？）

### 阶段 3：拒绝召唤
（你有过犹豫吗？合理的恐惧是什么？）

### 阶段 4：遇见导师
（你的导师 / 资源 / 社群是什么？）

### 阶段 5：跨越门槛
（具体哪个时刻 / 哪个动作，你真正开始了？）

### 阶段 6：测试 · 盟友 · 敌人
（接下来 1-3 月，你会遇到哪些挑战？哪些朋友？哪些诱惑？）

### 阶段 7：接近深处
（3-6 月时，你会进入哪个深水区？）

### 阶段 8：严酷考验（ORDEAL）
（什么时刻你会想放弃？怎么挺过去？）

### 阶段 9：奖赏
（你坚持下来后，会得到什么？）

### 阶段 10-12：回归
（你怎么把所学回馈社区？成为别人的导师？）

## 🎯 本周必做（阶段 5-6 的具体动作）
（3-5 个具体步骤）

约束：
- 真实，不说教
- 每阶段 100-200 字
- 用第二人称"你"
- 不要列出"week 1, week 2"——用故事节拍
````

## ⚔️ Prompt 4：把争辩 / 多视角讲出来

**何时用**：你学到一个"标准观点"，但想知道反方

````
你是顶级辩论教练 + 该领域研究员。
你的任务：把下面的概念 / 观点用"3 方争辩"结构呈现。

【概念 / 观点】：
[贴这里]

输出格式：

## 🥊 辩论现场

### 正方：[观点的旗手]
（这位旗手是谁？他主张什么？最强证据是什么？）

### 反方：[最猛烈的批评者]
（这位批评者是谁？他主张什么？最强证据是什么？）

### 中间派：[谨慎的研究员]
（他不站边，他的疑问是什么？他建议怎么验证？）

## 🔬 如果我是裁判
（我该怎么判断？关键证据是什么？还有什么实验没做？）

## 🎯 我的学习建议
（作为新人，我应该先接受哪一方？什么时候我有资格评判？）

约束：
- 真实人物 + 真实论文

````

## 🎨 Prompt 5：把抽象数学变成几何 / 物理直觉

**何时用**：你学数学公式，但不知道它在"几何 / 物理"上意味着什么

````
你是 3Blue1Bone 风格的数学传播者 + 该领域研究员。
你的任务：把下面的数学公式 / 概念变成"几何或物理直觉"。

【公式 / 概念】：
[贴这里，比如 SVD / KL divergence / 梯度下降 / 注意力公式]

输出格式：

## 👁️ 闭上眼想象
（如果这个数学对象是一个物理 / 几何对象，它长什么样？）

## 🎬 一段电影
（如果它在动，它怎么动？时间上发生什么？）

## 🤲 用手感觉
（如果我用手摸它，什么感觉？硬 / 软 / 光滑 / 粗糙？）

## 🔬 一个反直觉
（这个几何 / 物理直觉，揭示了一个什么反直觉结论？）

## 🧮 为什么数学家要发明它
（数学家当年解决什么问题，才发明这个？）

## 📐 公式本身（但不让你怕）
（用一句中文解释公式的每个符号，然后说"它就是在说..."）

约束：
- 真实，不编造
- 类比要有对应关系，不能硬凑
- 不超过 600 字
````

### 示例：用这个 prompt 学 SVD

**输入**：SVD（Singular Value Decomposition）

**AI 输出**（你预期的样子）：

> ## 👁️ 闭上眼想象
> 想象一个**3D 空间里被扭曲的椭球**。SVD 就是把任何线性变换分解成 3 步：
> 1. 旋转（U）
> 2. 沿轴拉伸（Σ）
> 3. 再旋转（V^T）
>
> ## 🎬 一段电影
> 一个完美的球。先转一下。再被一只无形的手沿三个方向拉长（一个方向拉得多，一个少，一个几乎不动）。然后再转一下。**变成椭球**。
>
> **任何矩阵变换都可以这样分解**。
>
> ## 🤲 用手感觉
> 想象捏一团橡皮泥。你能把它拉成长条。但你的拉扯总是**沿正交方向**——这就是 SVD。Σ 里的奇异值告诉你"沿每个方向拉了多少"。
>
> ## 🔬 一个反直觉
> **任何矩阵都能 SVD**——不只是方阵！一个 1000×500 的矩阵，可以分解为 1000×1000 旋转 × 1000×500 拉伸 × 500×500 旋转。
>
> ## 🧮 为什么数学家要发明它
> 1889 年，Beltrami / Jordan 独立发现。**目的**：解线性方程组 Ax = b 的"伪逆"。
>
> 后来发现 SVD 是降维 / 压缩 / 推荐系统 / interp 的核心——因为它告诉你**哪些方向重要（大奇异值），哪些不重要（小奇异值，可丢）**。
>
> ## 📐 公式本身
> A = U Σ V^T
> - A：任何矩阵
> - U：左奇异向量（旋转 1）
> - Σ：奇异值（拉伸，对角矩阵）
> - V^T：右奇异向量（旋转 2）
>
> **它就是在说**：任何线性变换 = 旋转 + 拉伸 + 旋转。

## 🛠️ 怎么用这套 prompt

### 工作流
1. **学新概念** → Prompt 1
2. **读论文** → Prompt 2
3. **规划路径** → Prompt 3
4. **遇争辩** → Prompt 4
5. **学数学** → Prompt 5

### 把故事存档
- AI 生成的故事**存到 Obsidian**
- 标签 `#story`、`#concept/反向传播`、`#analogy`
- 每周回顾 1 次

### 不要全信 AI
- AI 可能编造（hallucination）
- 关键事实 / 引用必须**用 webfetch 核实**
- 你 work4ai 的铁律 2：**arXiv ID 绝不能凭记忆**——AI 的"记忆"比你的更危险

## 📚 进阶：自己写 prompt

学完这 5 个 prompt，你可以**自己写**——只要记住 7 原则：
1. 人物 + 冲突 + 时刻
2. Hero's Journey
3. 悬念 + 反转
4. 类比 + 隐喻
5. Case Study
6. 多视角争辩
7. 图像化

写新 prompt 时，**强制 AI 遵守几条**——它的默认输出是"列表 + 表格"，要明确说"用故事而非要点"。
