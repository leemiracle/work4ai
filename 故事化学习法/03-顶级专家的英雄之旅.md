# 03 · 顶级专家的英雄之旅

> **本文是什么**：4 个 AI 顶级专家的成长路径，按 **Joseph Campbell 的 Hero's Journey** 12 阶段结构讲。
>
> **目的**：让你看清——**顶级专家不是天生的，是经过英雄之旅锻出来的**。你正处在他们的某一阶段。

---

## 🧭 Hero's Journey 12 阶段（速查）

```
1. 平凡世界 → 2. 听闻召唤 → 3. 拒绝召唤 → 4. 遇见导师
→ 5. 跨越门槛 → 6. 测试盟友敌人 → 7. 接近深处
→ 8. 严酷考验（ORDEAL）→ 9. 奖赏 → 10. 回归之路
→ 11. 复活 → 12. 带灵药归来
```

---

## 🥇 Andrej Karpathy：从默默无闻到 Tesla / OpenAI / Eureka Labs

### 阶段 1-2：平凡世界 → 听闻召唤
- 出生在捷克，13 岁随父母移居加拿大
- 多伦多大学本科，**遇到 Hinton**——但他**没立刻选择 AI**
- 起初学物理 / 计算

### 阶段 3：拒绝召唤
- 本科毕业，**去做网页开发**（"赚快钱"）
- 但内心不安

### 阶段 4：遇见导师
- 2009 年回多伦多大学，**Hinton 接受了他**
- 开始接触深度学习——那时 NN 还是边缘方向

### 阶段 5：跨越门槛
- 申请 Stanford 博士，**被拒**
- 转申去了 **Fei-Fei Li** 那里（Stanford Vision Lab）
- 2011 年，加入 ImageNet 团队——就是后来 AlexNet 那批人

### 阶段 6：测试 · 盟友 · 敌人
- 2012 年 **AlexNet 火了**——他在前线
- 2015 年博士毕业，**写了一系列神级 blog**："Hacker's guide to Neural Networks"、"Yes you should understand backprop"
- **CS231N** 课程——成为 Stanford 历史上最受欢迎的 AI 课

### 阶段 7：接近深处
- 2015-2017，加入 **OpenAI**（创始研究员之一）
- 当时 OpenAI 才几个人，研究方向未定

### 阶段 8：严酷考验（ORDEAL）
- 2017 年，他离开 OpenAI，加入 **Tesla**——所有人觉得他疯了
- Musk 给他一个任务：**做自动驾驶**
- 他从一个人，**招到 50 人团队**，从零搭系统
- 头 18 个月，**没出任何东西**——Musk 天天问"什么时候 demo"

### 阶段 9：奖赏
- 2019 Tesla Autonomy Day，他做的 demo 全球直播
- Tesla 视觉自动驾驶 = **业界最先进**

### 阶段 10-11：回归 + 复活
- 2022 年离开 Tesla，回到 OpenAI
- 内部 burnout
- 2024 年离开 OpenAI，**重新评估方向**

### 阶段 12：带灵药归来
- 2024 年创立 **Eureka Labs**——AI + 教育
- 2024 年发布 **nanoGPT**（GitHub 史上最快涨星 repo）
- 2024-2026 一系列视频（"Let's build GPT"、"Intro to LLMs"）——**单视频 1000 万观看**

### Karpathy 模式总结
| 主题 | 启示 |
|---|---|
| **导师** | Hinton + Fei-Fei Li（双重 lineage）|
| **方向深选** | 早期深耕 CV → Tesla 深耕自动驾驶 → 当前深耕 LLM 教育 |
| **持续产出** | 博士期间 blog + 视频，从未停 |
| **冒险** | 加入 OpenAI（2015）和 Tesla（2017）都是高风险，回报巨大 |
| **复活** | 离开 Tesla 不是失败，是重生 |

## 🥈 Sergey Levine：RL 的传教士

### 阶段 1-4：Stanford PhD
- Stanford 本科 + PhD，导师 **Vladlen Koltun**（不是 RL 出身）
- 2013 年起，迷上 **深度 RL**

### 阶段 5：跨越门槛——DAGGER
- 2011 年，他作为一作发表 **DAGGER**（Dataset Aggregation）——RL 的安全学习算法
- **博士前 4 年没人理**

### 阶段 6-7：导师转折
- 真正的导师是 **Pieter Abbeel**（Berkeley）——和 Levine 合作一系列论文
- **TRPO**（2015）→ **PPO**（2017）→ 整个 trust region 系列

### 阶段 8：严酷考验
- 博士最后一年（2014），论文连中 4 篇 NeurIPS——但他差点放弃 PhD
- 深度 RL 训练极其不稳定，**他每天 debug 12 小时**

### 阶段 9：奖赏
- 2017 年 PhD 毕业，**Berkeley 直接聘他做助理教授**
- 2018 年起，**CS 285 Deep RL** 成为全球最受欢迎 RL 课
- 后来加入 OpenAI / 创立 **Physical Intelligence**（2024）

### Levine 模式总结
| 主题 | 启示 |
|---|---|
| **深耕一个方向** | 10 年只做 RL |
| **顶级课程** | CS 285 让他成为 RL 传教士 |
| **导师传递** | Abbeel 教他，他教整个 Berkeley RL 圈 |
| **创业** | 不止学术，**Physical Intelligence** 把 RL 用于机器人 |

## 🥉 Neel Nanda：interp 神童的逆袭

### 阶段 1-2：平凡世界 → 听闻召唤
- 英国 Imperial College 本科，**数学 + CS**
- 大二读 **Anthropic "Mathematical Framework for Transformer Circuits"**——震惊
- "我也想做这个"

### 阶段 3：拒绝召唤
- 本科毕业，**找了份工业工作**（不是 interp）
- 但工作几个月后，辞职——"我必须做 interp"

### 阶段 4：遇见导师
- 没有正式导师。**他的导师是 Anthropic 的 blog**
- 加入 **EleutherAI Discord** 潜水

### 阶段 5：跨越门槛
- 2022 年，他独立做了一个项目：**用 interp 方法研究 Modular Addition 模型**
- 写成 blog "Progress measures for grokking via mechanistic interpretability"——**直接被 ICLR 2023 接收**

### 阶段 6-8：深耕 + 严酷考验
- 2022-2023，他写 **TransformerLens**——interp 标准工具
- 期间多次 burnout，因为没人付钱，他自费研究
- **MATS** 接受他做 mentor

### 阶段 9：奖赏
- 2024 年加入 **Google DeepMind** interp 团队
- MATS Neel Nanda stream 成为 **顶级 interp 入口**

### Nanda 模式总结
| 主题 | 启示 |
|---|---|
| **没有导师也能起步** | 但**必须**从 EleutherAI / LessWrong 社群开始 |
| **早期开源** | TransformerLens 让他成为生态核心 |
| **快速发表** | 1 个 toy 项目 + 写好 = ICLR |
| **垂直深耕** | 5 年只做 mech interp |

## 🏅 Terence Tao：天才的另一面

### 阶段 1-2：神童的世界
- 1975 年生澳洲，**13 岁 IMO 金牌**（史上最年轻）
- 17 岁 Flinders University 毕业
- 20 岁 Princeton PhD（导师 Elias Stein）

### 阶段 3：拒绝召唤
- **拒绝纯天才路径**
- 选择广度：调和分析 → PDE → 组合 → 数论

### 阶段 4-7：跨领域
- UCLA 教授
- **2006 年 Fields Medal**（compressed sensing + Green-Tao 定理）

### 阶段 8：严酷考验
- 2020 年代，他开始关注 **AI for math**
- "我没用 AI 工具很多年，但 2023 年 GPT-4 改变了我"

### 阶段 9-12：归来
- 2024 年起，**Tao Analysis I Lean companion**（用 Lean 形式化他自己的教材）
- 2025 年成为 AlphaProof / 形式化数学 的**布道者**
- **他不是 AI 专家**，但他用 AI 改变数学

### Tao 模式总结
| 主题 | 启示 |
|---|---|
| **跨学科** | 不只做一个领域 |
| **写作** | blog 是公共思考工具 |
| **乐于拥抱新工具** | 50 岁还在学 Lean / 用 LLM |
| **持续输出** | 30 年每日 blog |
