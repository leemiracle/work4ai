# 01 · 方法论：故事化的认知科学

> **核心论点**：故事化不是"哄外行"，是**人脑的天然格式**。所有"难懂"的概念，本质都是没有好故事。

---

## 🧠 为什么故事化符合人脑规律（认知科学背书）

### 1. 故事是人脑的"原生数据结构"

- **Schank & Abelson (1977) "Scripts, Plans, Goals and Understanding"**：人脑用"故事脚本"（scripts）组织记忆，不是用语义网络。
- **Tversky & Kahneman**：情绪标记的事件记忆 10 倍于中性事件。
- **Ebbinghaus 遗忘曲线**：孤立信息 1 天忘 70%；嵌入故事的信息 1 周还在。
- **Case-Based Reasoning（Schank）**：法学院 / 医学院 100 年都用 case 法——因为人脑记不住规则，记得住案例。

### 2. 神经科学证据

- **fMRI 研究**：听故事时，大脑皮层 + 边缘系统 + 运动皮层**全亮**（同步激活）。听列表时只有语言区亮。
- **"神经耦合"（Hasson et al. 2008）**：讲故事的人和听故事的人大脑活动**同步**——这就是为什么你跟 Karpathy 的 talk 产生共振。
- **Default Mode Network**：默认模式网络在叙事理解中活跃——这是大脑的"故事处理中心"。

### 3. 进化心理学

- **Dunbar (1996) "Gossip"**：人类语言进化是为讲八卦（关于谁对谁做了什么）。
- **自传记忆**：你的记忆是按"叙事片段"存的，不是按"事实表"。
- **神话学（Campbell 1949 "千面英雄"）**：全球神话共享同一"英雄之旅"结构——因为这是大脑最熟悉的叙事。

## 📖 7 大原则详解

### 原则 1：概念 = 人物 + 冲突 + 时刻

**人脑不记抽象定义，记具体场景**。

❌ 教科书式：
> "Adam optimizer combines momentum and adaptive learning rates from RMSProp."

✅ 故事化：
> 2014 年 12 月某个深夜，Diederik Kingma 在 Amsterdam 的办公室，看着 ICLR 投稿 deadline 倒计时。他手里有两种当时流行但各管一摊的方法：momentum 让训练更稳，RMSProp 让每个参数有自适应学习率。**"如果我把两者缝合呢？"** 他写了一晚，5 页论文投出去——**Adam**，今天被引用 25 万次，几乎所有深度学习训练都用它。

**为什么有效**：
- 人物（Kingma）→ 人脑有 hook
- 冲突（deadline 压力）→ 情绪标记
- 时刻（深夜 + 缝合）→ 具体场景
- 反转（缝合两种方法）→ surprise

**实操**：你下次学任何新概念，**问 3 个问题**：
1. 是**谁**发明的？
2. 他当时在**什么场景**？
3. 他解决了什么**未解问题**？

### 原则 2：路径 = Hero's Journey（英雄之旅）

Joseph Campbell（坎贝尔）1949 年发现，**全球神话共享同一结构**——Hero's Journey。**这也是顶级专家的成长路径**。

**为什么有效**：你的大脑**已经知道**这个结构（你看过无数电影 / 小说）。

### 原则 3：悬念 + 反转

人脑对**未完成模式**有强烈记忆（Zeigarnik 效应）。

❌ 教科书式：
> "反向传播通过链式法则计算梯度。"

✅ 故事化：
> **1986 年，David Rumelhart、Geoffrey Hinton、Ronald Williams 重新发现了反向传播算法。** 论文一发表，AI 圈炸了——所有人都觉得"神经网络要起飞了"。
>
> **然后 20 年里，神经网络几乎死了两次**。
>
> 第一次死：1990s SVM 和 random forest 把神经网络按在地上摩擦，因为它训不动。
> 第二次死：2000s 大家觉得"神经网络是死胡同"，Hinton 在 Toronto 几乎招不到学生。
>
> **问题是：反传是对的，为什么神经网络死了 20 年？** （答案 2006 年揭晓，Hinton 用 Deep Belief Network 复活了整个领域——这就是深度学习的开始。）

**为什么有效**：
- 悬念（为什么死了 20 年？）→ 人脑自动追踪
- 反转（2006 复活）→ surprise
- 整个深度学习的历史 → 一个故事搞定

### 原则 4：类比 + 隐喻（人脑最爱的模式）

人脑通过**已知映射到未知**学习。

| 概念 | 类比 |
|---|---|
| Attention | 图书馆员同时翻所有书，给每本打相关度分数 |
| SGD | 雪山滑雪者蒙眼下山，靠脚下坡度判断方向 |
| Momentum | 同一个滑雪者带惯性，不会卡在小坑里 |
| Batch Norm | 把每层输入"标准化"成相同分布，像流水线把零件规格化 |
| CNN 卷积 | 用放大镜逐格扫过图片，找局部特征 |
| RNN | 一个有短期记忆的工人，逐字读句子 |
| Transformer | 抛弃记忆工人，让所有词互相"对视"，自动判断谁重要 |
| 过拟合 | 学生背题不学原理，遇到新题就懵 |
| Dropout | 训练时随机让一半神经元睡觉，强迫其他人多学 |
| GAN | 造假币者 vs 警察互相博弈，水平一起提高 |
| RL | 训狗：做对给奖励，做错不理会 |
| KL divergence | 用一个分布"近似"另一个的代价——撒谎的成本 |
| Embedding | 把每个词放到一个高维地图，相似词靠在一起 |
| Diffusion | 雕塑家从一块石头凿出雕像（反向）vs 时间把雕像风化成石头（正向） |
| VAE | 模糊画家：不画精确细节，画一个"风格范围" |

**实操**：你学任何新概念，**问 1 个问题**：**这像什么我已经知道的东西？**

### 原则 5：Case Study > 概念讲解

法学院 / 医学院 100 年都用 case 法——**人脑记得住案例，记不住规则**。

❌ 教科书式：
> "RAG = Retrieval-Augmented Generation。检索文档 + 生成回答。"

✅ Case Study：
> **2023 年 5 月，一位律师用 ChatGPT 查案例，AI 给了几个看似真实但完全不存在的 citation。律师把假案例交上去，被法官公开制裁，全美头条。**
>
> 这就是幻觉问题。**怎么解决？**
>
> 方案 A：微调。问题：每次新案例出来都要重训，成本爆炸。
> 方案 B：写更长 prompt 让 AI "仔细想"。问题：还是幻觉。
> 方案 C：**让 AI 先去查真实案例库（检索），再用检索结果生成答案（生成）**。这就是 RAG。
>
> RAG 不是"先检索后生成"——它是**"用检索把 AI 锚定在真实世界"**。

**实操**：学新概念前，**先找一个真实案例**（事故 / 突破 / 应用），用它引出概念。

### 原则 6：多视角争辩

人脑对**冲突**比对**共识**敏感 5 倍。

❌ 单一视角：
> "Chomsky 的 universal grammar 理论认为..."

✅ 争辩：
> **Chomsky 说**：LLM 不可能真正懂语言，它只是在统计学幻觉。
> **Hinton 说**：Chomsky 错了 50 年。LLM 学到的内部表征证明它在学习语法结构。
> **真相在哪？** 让我们看证据：
> - [证据 A]：LLM 学到 induction heads（真实电路）
> - [证据 B]：LLM 在 OOD 测试上崩盘
> - [证据 C]：interp 发现 LLM 学到的 representation 与人脑类似
>
> **你的判断？**

**实操**：学任何"标准答案"时，找**反方观点**。这强制你思考。

### 原则 7：图像化（千年神话的核心）

古希腊记忆术 "Method of Loci"（记忆宫殿）：**把信息编码在空间图像里**，效率 10 倍。

- **时间线** > 列表
- **流程图** > 段落
- **手绘图** > 精美 PPT
- **思维导图** > 树状目录

**工具推荐**：
- **Excalidraw**（手绘风）
- **Mermaid**（流程图）
- **tldraw**（无限画布）
- **手画 + 扫描**（Karpathy 风格）

## 📐 5 种故事结构模板

### 模板 1：英雄之旅（Hero's Journey）
**用途**：讲个人成长 / 学习路径 / 创业故事
**结构**：见上述 12 阶段
**例**：Karpathy 的成长（详见 [`03-顶级专家的英雄之旅`](03-顶级专家的英雄之旅.md)）

### 模板 2：侦探小说（Detective）
**用途**：讲机理 / interp / debug
**结构**：
1. 案件（现象出现）→ "大模型说出有害内容"
2. 侦探（研究者登场）→ 你
3. 嫌疑人（多个可能解释）→ 各个 attention head / 训练数据 / 对齐失败
4. 工具（侦探的放大镜）→ TransformerLens / SAE
5. 线索（关键发现）→ induction heads / refusal direction
6. 真相（顿悟）→ circuits 组合
**例**：Mech Interp 历史（详见 [`04-Mech-Interp侦探故事`](04-Mech-Interp侦探故事.md)）

### 模板 3：悲剧 / 失败（Tragedy）
**用途**：讲被淘汰的方法 / 历史教训
**结构**：
1. 英雄崛起（方法流行）→ 专家系统 1980s 兴起
2. 致命缺陷（隐藏问题）→ 无法泛化到新领域
3. 崩塌（溃败时刻）→ 1990s AI 寒冬
4. 教训（反思）→ 不要重蹈覆辙
**例**：AI 两次寒冬 / 神经网络被遗忘 20 年

### 模板 4：喜剧 / 反转（Comedy）
**用途**：讲意外发现 / 反直觉结论
**结构**：
1. 大家都以为 X → "增加模型大小一定要增加精度"
2. 一个无名之辈试 Y → "Chinchilla: 不，要增加数据"
3. Y 居然赢了 → 70B 模型 + 4 倍数据 > 280B 模型
4. 整个领域反转 → scaling laws 重写
**例**：Chinchilla scaling law / Mixture of Experts 重新流行

### 模板 5：史诗 / 编年（Epic）
**用途**：讲一个领域的全景
**结构**：按时间线串联人物 / 事件 / 突破
**例**：AI 七十年史诗（详见 [`02-AI七十年史诗`](02-AI七十年史诗-主线故事.md)）

## 🛠️ 实操：把任何概念故事化的 5 步法

学新概念时，走这 5 步：

### 第 1 步：找"谁"和"为什么"
- 谁发明 / 发现 / 推广的？
- 他当时在解决什么问题？

### 第 2 步：找"冲突"
- 这概念出来前，世界是怎样的？
- 大家觉得什么不可能？

### 第 3 步：找"反转"或"surprise"
- 这概念出来后，有什么反直觉发现？

### 第 4 步：找"类比"
- 这像什么我已经知道的东西？

### 第 5 步：找"case"
- 有没有一个真实案例可以印证？

### 示例：把"梯度下降"故事化

1. **谁**：Cauchy 1847 年首次提出
2. **冲突**：1940s 求解大型优化问题没有通用方法
3. **反转**：这么简单的算法，60 年后才在神经网络爆发（GPU 让它可行）
4. **类比**：蒙眼滑雪者靠脚下坡度下山
5. **case**：Karpathy 训练 nanoGPT 时，调 lr 从 1e-3 到 1e-4 让 loss 稳定下降
