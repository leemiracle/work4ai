## 🔑 核心方法论速查

### Prompt 解析（ROIF-CSE）
```
R - Role（角色）
O - Objective（目标）
I - Instructions（指令）
F - Format（格式）
C - Context（上下文）
S - Shot（例子）
E - Edge cases（边界）
```

### Prompt 评价（6 维度）
```
1. 准确性（Accuracy）
2. 稳健性（Robustness）
3. 可迁移性（Portability）
4. 效率（Efficiency）
5. 可控性（Controllability）
6. 安全性（Safety）
```

### 跨模型兼容（4 策略）
```
A. 模型特化 prompt（最优效果，高维护）
B. 通用 + 兼容层（生产推荐）
C. DSPy 自动优化（未来主流）
D. 推理模型 + 少 prompt（新趋势）
```

## ⚠️ 三个最重要反直觉

### 1. "感觉好"不算评价
没指标 + 没黄金集 + 没统计检验 = 没评价。

### 2. 同一 prompt 跨模型表现真不同
Claude 喜欢 XML，GPT 喜欢 Markdown。**直接复制 prompt 跨模型 = 不专业**。

### 3. DSPy GEPA 优化的 nano 模型能超过未优化的 GPT-5
2025 论文已证。**prompt 优化的 ROI 比换大模型高**。
