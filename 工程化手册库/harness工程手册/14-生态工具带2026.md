## 带一 · 安全审计（→ L 组件：Lifecycle Hooks / 策略执行）

| 工具 | 是什么 | 关键数字 | 核实 |
|---|---|---|---|
| **Agent Audit** | LLM agent 应用安全分析：数据流+凭证检测+配置解析+权限风险，SARIF 进 CI/CD，pip 可装 | 22 样本 42 漏洞检出 40（6 误报），亚秒扫描 | ✅ arXiv:2603.22853 |
| **AEGIS** | 预执行防火墙：SDK 拦截 tool_use → Gateway 三段管线（字符串提取→风险扫描→策略验证）→ allow/block/pending；Ed25519+SHA-256 防篡改审计链；高危挂起人审 | 48 攻击全拦截、误报 1.2%（500 良性）、中位延迟 8.3ms、14 框架（Py/JS/Go）| ✅ arXiv:2603.12621（Yuan/Su/Zhao——与 Agent Audit 同团队，Zhao 交集）|
| **OpenClaw PRISM** | 零 Fork 运行时防御层：进程内插件 + 4 sidecar，**10 hooks×5 阶段**（ingress/pre-exec/post-exec/outbound/maintenance），会话级风险累积（TTL 衰减）+ 双层扫描（启发式→LLM）| live 基准（80 例，qwen3:8b）：Full PRISM 拦截率 **0.955**、误报 13.9%；Tier-1 微秒级、LLM 扫描秒级 | ✅ arXiv:2603.11853（Frank Li, UNSW）。⚠️ **纠错**：网传"逃逸率近零/<5ms 开销"不准确——95.5% 拦截≠零逃逸，开销分层。**宿主实证**：[openclaw 案例笔记 04](../../讲透Agent/Agent框架案例/openclaw/notes/04-安全平面.md)（42 挂点中 PRISM 消费哪 10 个）|
| **AgentSys** | OS 进程内存隔离启发的**层级记忆管理**：主 agent 派生 worker，原始工具输出永不进主记忆，仅 schema 校验值过隔离边界（确定性 JSON）| AgentDojo ASR 0.78%、ASB 4.25%、多步任务 0% ASR；纯上下文隔离单独就 2.19% ASR | ✅ arXiv:2602.07398（Wen/Li/Xiao/Zhang）|
| **AgentSpec** | 运行时约束 DSL：触发事件+谓词+执行三段规则；执行方式 stop/user_inspection/invoke_action/llm_self_examine；LangChain 集成 | 代码 agent 拦截 >90%、具身 10 类危险动作清零、AV 100% 合规，毫秒级开销；o1 自动生成规则 precision 95.56% | ✅ arXiv:2503.18666，**ICSE 2026 正式论文**（DOI 10.1145/3744916.3764546）|

**接口**：10 章体检清单"安全项"的自动化版；deepseek-kernel-harness 的 authorize 拦截同族。
**选型**：静态扫描选 Agent Audit；运行时拦截选 AEGIS（框架无关）/ AgentSpec（DSL 声明式）；防间接注入选 AgentSys（架构级）；网关生态选 PRISM。

## 带三 · 调试与根因（→ V 组件：故障定位）

| 工具 | 机制 | 关键数字 | 核实 |
|---|---|---|---|
| **AgentTrace** | 执行日志重建因果图 + 反向追溯 + 位置/结构特征排序，调试零 LLM 调用 | 550 场景 Hit@1 94.9%，0.12s vs 8.3s（69×）；位置特征 w_p=0.70 主导 | ✅ arXiv:2603.14688（ICLR'26 AIWILD）|
| **AgentDebug** | AgentErrorTaxonomy（5 模块×17 错误类型）+ 反事实定位 critical error + 定向反馈重放 | 全对准确率 +24%，任务成功相对 +26% | ✅ arXiv:2509.25370（UIUC）|
| **AgentRx** | 轨迹归一化 IR → 从工具 schema/域政策/轨迹**合成约束**（全局+动态）→ 步进校验日志 → LLM judge 定位 | **115 失败轨迹基准**（τ-bench/Flash/Magentic-One）；定位 +23.6%、归因 +22.9%；10 类失败 taxonomy | ✅ arXiv:2602.02475（Microsoft，microsoft/AgentRx）|
| **TraceCoder** | 插桩/分析/修复三 agent（observe-analyze-repair 人格化）+ HLLM 历史教训学习 + 回滚门禁 | Pass@1 相对 +34.43%（ClassEval 82 vs 61，Gemini-2.5-Flash）；迭代修复单独贡献 65.61% 相对增益 | ✅ **ICSE 2026 正式论文**（DOI 10.1145/3744916.3773187，arXiv:2602.06875）|

**接口**：AgentTrace（多 agent 因果图）与 AgentDebug（单 agent 分类轴）与 AgentRx（约束合成）是三种互补机理；17 类型 taxonomy + AgentRx 10 类 taxonomy 可合并抄进 10 章体检单当故障分类轴。TraceCoder 的 HLLM="从失败轨迹蒸馏教训防止重犯"，与 11 章进化闭环同构。

## 带四 · 元进化家族（→ 11 章的 2026 全家福）

| 系统 | 机制 | 关键数字 | 核实 |
|---|---|---|---|

| **HyperAgents** | DGM-Hyperagents：task agent+meta agent 合一为**可编辑程序**，元认知自修改（改进"改进机制"本身），四域（coding/论文评审/机器人奖励设计/奥数评分）超越 DGM；元级改进跨域迁移累积 | 评审域提升显著（网传 0→0.710，摘要级未复核该具体数字，采用前查正文）| ✅ arXiv:2603.19461（Meta，facebookresearch/HyperAgents，Jeff Clune/Jenny Zhang 等）|

**家族共性铁律**（五系统一致）：**回归门禁 + 最小编辑 + 轨迹证据**——缺一即过拟合基准。HyperAgents 进一步展示：连"生成改进的机制"本身也可进化（元认知层），但 11 章的忠告升级为：**递归一次够，元层无限套娃无门禁必崩**。

## 附 · 01 章证据链补强（初版 + 补核实轮）

1. **hashline**（✅）：Grok Code Fast 1 仅换编辑工具格式 6.7%→68.3%（模型零改动）；GPT-4 Turbo 26→59%、Grok 4 Fast −61% token、MiniMax 2.1×。
2. **Stripe Minions**（✅ 官方博客 Part1 2026-02-09 / Part2 2026-02-19 + InfoQ 交叉）：**每周 1,300+ PR 合并、人类评审但零人工代码**（从 1,000 涨上）；全无人值守 one-shot；devbox 10s 启动、与生产/外网隔离；Goose fork + Toolshed MCP ~500 内部工具；lint<5s + CI≤2 轮自动修复。
3. **SandboxEscapeBench**（✅ 但数字纠错）：UK AISI（arXiv:2603.02277，Inspect AI CTF，18 公开场景）。网传"逃逸率 15-35%"**不准确**——实为分层：misconfig/暴露控制面级（难度 1-2）大模型轻松逃逸；难度 3（runc CVE 等）GPT-5/Opus 4.5 = 40%；难度 4-5 = 0%；总体 Opus 0.49 vs Haiku 0.18 vs GPT-OSS-120B 0.16。**教训：沙箱正确配置是底线，配置错=形同虚设。**
4. **Mem0**（✅ arXiv:2504.19413）：LOCOMO 上 p95 延迟 −91%、token 成本 −90%+（vs full-context）；+26% LLM-as-Judge over OpenAI Memory；full-context 略准（73% vs 67%）但 17s vs 1.44s——**记忆层是"够准+10×便宜"的工程权衡**，非精度冠军。

## 选型决策树（一屏版）

```
要防注入/越权/凭证泄漏      → 带一（静态扫描 Agent Audit；运行时 AEGIS/AgentSpec；注入 AgentSys）
要回答"为什么失败"          → 带三（多 agent 因果 → AgentTrace；分类轴 → AgentDebug；约束合成 → AgentRx）
要进化 harness 本身         → 带四（有评测集 → Self-Harness 式闭环；要榜单可比 → Harbor）
轨迹太长没人看得完          → 带二（存储侧 → Laminar 20×；认知侧 → AHE 蒸馏证据语料）
要系统学 / 团队推广         → 带五（walkinglabs 课程 + Harness Books + awesome 目录）
```
