# 10 · 体检清单与反模式：12 条铁律

> **核心论点**：harness 的坑是系统性的——每条铁律背后都是一种被反复验证的失败模式（NFL 提炼：每个选择都有代价）。
> **本文是什么**：五子系统体检单（速查）+ 12 条反模式铁律。

---

## 🩺 30 秒体检单（按症状挂号）

```
症状                          → 章节处方
─────────────────────────────────────────────
agent 提前宣布完成             → 06 验证（DoD 三件套缺失）
长任务中途失忆/重复劳动        → 05 状态（账本粒度不够）+ 07 WRAP UP
上下文经常爆                  → 04 参数表（cap/预算/压缩没配）
跑飞/删库/越权                → 02 Scope + 03 L 组件（权限门）
会话死了接不上                → 07 生命周期（交接工件缺失）
同任务时好时坏                → 10 反模式 #12（无回归集）
多模型切换后变差              → 09 方言（thinking/缓存断链）
改 prompt 没效果              → 01 反直觉 #2（投资错层：该修 T/S 不是 prompt）
```

## ⚠️ 12 条铁律（每条 = 反模式 → 铁律 → 出处）

### 1. 幻觉式完成
❌ 相模型说"我做完了" → ✅ `exit code 0` 才算数；没有 verify_cmd 的任务不许叫 done（06 章）

### 2. 裸奔上下文
❌ 文件整个读进窗口 → ✅ 2000 行/50KB cap + offset/limit + grep-first（04 章）

### 3. 单层防御
❌ 只查 byte 不查 token（或反之）→ ✅ 双层门：stat 预检 + 读后 token 计数（minified 文件专杀单层）

### 4. 无声截断
❌ 超限直接砍尾部 → ✅ 落盘 + 2KB 预览 + "报错即导航"（错误信息里教模型下一步怎么办）

### 5. 摘要即真相
❌ 压缩摘要当作历史本身 → ✅ 摘要/工件双轨：细节在外存，可回查原文（压缩必有损）

### 6. 剪辑思维链
❌ 手工重组历史 reasoning_content → ✅ 原样整条透传，缺失/改写=Preserved Thinking 失效（09 章铁律）

### 7. 运动员兼裁判
❌ 同一模型生成+质检 → ✅ maker-checker 分离（Goodhart 温床：指标被 gaming）

### 8. 测试对 agent 可写
❌ agent 能改测试让灯变绿 → ✅ 测试/评测脚本只读隔离 + 盲测集不进上下文

### 9. 整文件重写日志
❌ write 全量重写已存在的日志 → ✅ 锚定尾部追加（多会话并发互覆的真实事故）

### 10. 账本与世界脱钩
❌ 只信 progress.md → ✅ 对账三源：账本 vs git vs 测试，矛盾时以世界为准（07 章恢复清单）

### 11. Router 盲降级
❌ 难判样本也发给小模型 → ✅ 风险不对称时默认升级；模型池变更重评估 router（08 章三铁律）

### 12. 抄完不回归
❌ 趋同参数直接上生产 → ✅ 趋同≠最优：抄默认值 + 用自己的任务失败史建回归集（AHE 的增益也只在它训练的分布上成立）

## 🎭 底层逻辑：没有免费午餐（NFL 十大 trade-off 的浓缩版）

| 你想要的 | 你同时买进的 | 关键缓解 |
|---|---|---|
| harness 10× 可靠性 | 维护税 + 模型饱和后收益衰减 | 先跑对照实验确认瓶颈真因 |
| Router 省钱 | 路由错误的静默质量损失 | 难判默认升级 + 漂移监控 |
| 压缩续命 | 摘要有损 + 关键约束可能被压掉 | 压缩前 flush + 任务契约钉住 |
| 子代理隔离省 token | 丢父语境→答非所问 | 交接契约三元组（07 章）|
| 自动进化 harness | 对进化基准过拟合 | 冻结迁移验证（AHE 模式）|

**完整矩阵**见 [harness三综述合并解析](../../harness三综述合并解析.md) §3.2——手册这 12 条是它的工程投影。
