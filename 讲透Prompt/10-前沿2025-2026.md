# 10 - ★ 前沿 2025-2026：敏感性科学、单 prompt 天花板、reasoning 接口化

> 讲透Prompt 第 10 章（重点章）| 素材全部来自 2025-08 ~ 2026-08 检索（来源与日期逐条标注）；与本章实验互证：E8/E9/E10/E11

## 要点速览

1. prompt 词汇敏感性有了 **scaling law**：132k 变体实测，稳定性随模型规模爬升（ACL 2026 Findings）
2. 敏感性被**分解成四个可工程化的因素**：SFT / 规模 / dense 注意力 / few-shot 格式锚定（arXiv 2608.18539，2026-08）
3. 单个 prompt 存在**硬天花板**：45+ 变体的 Pareto 前沿，合并取均值而非最大（arXiv 2604.18897，2026-04）
4. **选项顺序能差 14pp**：CQO vs QOC，因果注意力的位置效应（ACL 2026）
5. reasoning 模型的"努力程度"正在**接口化**：concise / early-answer 指令 vs gpt-oss effort 档位（arXiv 2608.03401，2026-08）

## 一、敏感性从玄学变成科学

**ACL 2026 Findings（2026.findings-acl.2084）**：132k 条 prompt 词汇变体的大规模实测。两个稳定支柱：**领域术语 + 行动指令**（改写同义但保术语和动词，性能稳定）；波动带集中在礼貌语、填充词。**稳定性随模型规模呈 scaling law 式爬升**——越强的模型对措辞越钝感。

**arXiv 2608.18539（2026-08）**：把"prompt 敏感"这个黑箱拆成四个可操作因素——SFT 后训练、参数规模、dense（非稀疏）注意力、few-shot 示例的格式锚定，每个因素独立降敏。工程含义：**你的 prompt 脆弱，可能是模型选型问题而不是措辞问题**。

*与我们实验的互证*：E9 里 glm-4.7/glm-5 对 zero-cot 的反应模式高度一致（IF 齐降）而 glm-4-flash 每格都抖——规模降敏在我们 4 配置矩阵上方向一致（低功效复证）。E3 的 few-direct 陷阱在两个模型上同号（格式锚定效应），对应 2608.18539 的第四因素。

## 二、单 prompt 天花板：SAIR 竞赛的教训

**arXiv 2604.18897（2026-04）**：45+ 个 prompt 变体在 SAIR 竞赛任务上的系统对比。三个结论直击工程实践：

1. **单 prompt 有硬天花板**：变体间的差距远小于"prompt 家族"之间的差距——措辞微调是在天花板下面捡钢镚；
2. **没有万能变体**：不同任务上最优变体不同（Pareto 前沿摊开）；
3. **多 prompt 合并的收益是均值水平，不是最大值水平**——别指望 ensemble 挖出隐藏 alpha。

*互证*：E6 里 CoT 3 采样（≈小 ensemble）解出率 40% 而非最强路径的 100%；E10 的 8 条优化指令里只有 3 条能打——**prompt 空间的收益分布是重尾的，抽样撞大头，合并只保底**。

## 三、位置效应：Lost in the Prompt Order

**ACL 2026**：同一组 few-shot 选项，**CQO（情境-问题-选项）与 QOC（问题-选项-情境）相差 14pp**，机制追溯到因果注意力的信息可达性——问题前置时选项 Attend 不到完整情境。工程速效药：**重要信息要么贴着问题、要么贴着输出位置**，别埋中段。

*互证*：讲透Context E1 的首尾偏好（U 型）与本章互为表里——输入侧的记忆曲线 × 注意力的可达性约束，同一枚硬币。E8 的"防御放 system prompt 不如放输出前"猜想（07 章练习）是这个方向的攻防版。

## 四、reasoning 接口化：从 prompt 咒语到 API 档位

**arXiv 2608.03401（2026-08）**：评估 reasoning 模型的接口层——`concise` / `early-answer` 等**输出风格指令**与 gpt-oss 的 `effort` 档位（low/medium/high）的交互。结论：effort 档位的效果**不被输出风格指令破坏**，两者近似正交。

这标志着行业转向：**"思考多深"正在从 prompt 内变量（咒语长短）变成 API 参数（档位）**。当思考深度接口化，prompt 工程的剩余地盘收窄到：任务语义、格式合同、上下文管理。我们 E9 的"thinking 开关切换最优策略"就是这场转向的本地实证——**08 章决策树的最后一层会越来越薄，最终收进配置文件**。
