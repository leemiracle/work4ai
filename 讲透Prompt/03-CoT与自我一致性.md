# 03 - CoT 与自我一致性

> 讲透Prompt 第 03 章 | 实验：E3（`experiments/e3_cot.py`，results/e3_cot.json/png）+ E4（`experiments/e4_sc.py`，results/e4_sc.json/png）| 素材：`_source/techniques/cot.zh.mdx`、`_source/techniques/zeroshot-cot.zh.mdx`、`_source/techniques/self-consistency.zh.mdx`；论文：Wei et al. 2201.11903、Kojima et al. 2205.11916、Wang et al. 2203.11171（据指南）

## 一、直觉：CoT 是把心算摊到草稿纸上

模型每生成一个 token 只做固定深度的计算（几十层 transformer 前向）。"37 乘 24" 这种需要多步进位的题，一步生成器算不动——但如果你让它**先把 37×24 写成竖式、再逐位算**，每一步都变成了单 token 能负担的浅计算。**CoT 不是让模型"想得更深"，是把深计算摊薄到 token 流上**：草稿纸不增加脑力，增加的是串行步数。

零样本 CoT（Kojima）的惊人之处在于：一句"请一步一步思考"就能触发模型调用它预训练里见过亿万次的"草稿纸模式"。

## 二、数学：SC 多数投票的二项式账本

Self-Consistency 采 $n$ 条独立推理路径，取答案众数。设单条路径答对概率为 $p$，多数投票答对概率：

$$P(\text{majority correct}) = \sum_{k > n/2} \binom{n}{k} p^k (1-p)^{n-k}$$

$p > 0.5$ 时这个值随 $n$ 单调上升（噪声互相抵消）；**$p < 0.5$ 时随 $n$ 单调下降**（错误互相加强）。大数定律只保证收敛到"多数真理"，不保证真理在多数里。这个公式是 E4 反例的全部理论——我们只需要找到一道"错误路径占多数"的题。

**E3：四条件 × 双模型矩阵（准确率）**

| 条件 | Qwen2.5-0.5B（6题lite） | glm-4-flash（10题） |
|------|------------------------|---------------------|
| zero-direct | 0% | 40% |
| zero-cot | 17% | **100%**（+60pp） |
| few-direct | 0% | **10%**（-30pp ⚠️） |
| few-cot | **50%** | 90% |

四条结论：

1. **zero-cot 是单点最大杠杆**：一句咒语 +60pp（glm）——但**救不动太小模型**（Qwen 只有 17%：草稿纸给得起，0.5B 的"笔力"写不对每一步）。
2. **few-direct 是普适陷阱**（双模型齐崩，glm 40%→10%）：只有答案的示例教会"抄一个像答案的数字"——02 章"格式学习器"论断在推理域的铁证。
3. **few-cot 救弱模型**（Qwen 17%→50%）：带推理链的示例给了它可模仿的骨架；**对强模型是微负资产**（glm 100%→90%）：示例占预算还偶发格式纠缠。
4. 矩阵里没有一个格子对所有模型最优——**prompt 策略是模型的函数**（08 章展开）。

**E4：SC 的反例时刻**

6 道难题 × greedy 基线 + T=0.8 采 9 条投票：

| 指标 | 值 |
|------|-----|
| greedy（T=0.1 单次） | **100%** |
| SC n=1 / 3 / 5 | 100% / 100% / 100% |
| SC n=9 | **83%** ⚠️ |

凶手是一道相遇问题：9 条采样里 **5 条犯同一个错**（答 3.0，正确 3.6），5:4 把 greedy 本来算对的答案投票投死。对照第二节公式：这道题的"单路径正确率" $p \approx 4/9 < 0.5$，投票进入恶化区。

**结论：SC 是噪声滤波器，不是真理发生器。** 它滤的是不相关噪声（三加五减各错各的），滤不掉系统性偏差（对题意的集体误读）。论文里 SC +15pp 的场景，全是"错误五花八门"的题；错误高度相关的题（单位换算、题意歧义、常识盲区），采样越多越自信地错。

## 四、何时用 CoT / SC（决策表）

| 场景 | 用什么 | 证据 |
|------|--------|------|
| 弱模型 + 推理题 | few-cot | E3 Qwen 17%→50% |
| 强非思考模型 + 推理题 | zero-cot | E3 glm +60pp |
| 强模型 + 简单任务 | 直答（别加咒语） | E9：咒语伤指令遵循 |
| 错误五花八门的难题 | SC n=5-9 | Wang et al.；E4 n=5 前 |
| 错误同源的题 | SC **危险** | E4：5:4 反杀 |
| thinking 模型 | **删掉手写 step-by-step** | Google Cloud 建议 + E9（08 章） |

## 五、不足与批判

- CoT 的忠实性问题：模型写出的推理链不一定是它"真实"的计算路径（模型可以结论先行、推理补写）。我们的判分只看最终答案，不看推理诚实性。
- E3 本地臂是 lite 版（6 题 + 64 token 截断），对 Qwen 的 CoT 有低估风险（截断即算错）——已存 json 标注。
- E4 的 n=9 在 6 题上只有 1 题翻车，功效极低；但方向（系统性偏差破坏 SC）与公式、与文献一致，作为"机制演示"而非"效应量估计"。
- CoT 长度 = 延迟 = 成本：+60pp 的代价是每题多 300-500 token。批量场景先算账。
