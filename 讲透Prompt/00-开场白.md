# 00 - 开场白：Prompt 是一门实验科学

> 讲透Prompt 第 00 章 | 全单元实验索引：`experiments/`（E1-E11 + E-mini，11 个实验 12 组结果）| 源站：`_source/`（44 页，zh 35 + en 9）

## 一、为什么"技巧清单"学不会 prompt

市面教程的问题不是讲错，而是**把 prompt 讲成菜谱**："加一句'让我们一步步思考'就能提升 20%"——在哪个模型上？什么任务？提升的是准确率还是格式破坏率？菜谱不回答这些，因为菜谱不做实验。

本单元的立场：**prompt 工程是一门实验科学**。每个技巧都是一个假设，每个假设都要在"模型 × 任务"网格上跑出数字。我们自己的数字经常和论文不一致——这些不一致才是最值钱的部分（见 03/06/08 章）。

## 二、单元的三个增量

1. **实验化**：指南里每类技巧（zero-shot → CoT → PAL → ToT → ReAct → 对抗）都用本地 Qwen2.5-0.5B + 智谱 GLM API 真跑。不是复述论文数字，是跑自己的。两个代表性数字：few-shot 直答在算术题上把 glm-4-flash 从 40% 打到 **10%**（03 章）；四种 prompt 级注入防御的拦截率**全部只有 1/4**（07 章）。
2. **模型适配**：同一个 prompt 在不同模型上表现截然不同——这是 2025-2026 最重要的实践知识。"请一步一步思考"这一句咒语，在 glm-4-flash 上把推理从 0/3 拉到 3/3，同时把 glm-4.7 的指令遵循从 3/3 打到 1/3（08 章核心表）。**没有一个 prompt 技巧在所有模型上同号**。
3. **自动优化 + 数学落地**：OPRO/DSPy 让模型自己写 prompt（09 章），最后一切落到数学域：GSM8K 策略矩阵、Persona 实验、Lean/Prover 实战模板（11 章）。

## 三、证据标准与实验环境

- **每个知识点配一个可跑实验**：`experiments/` 下 py + `results/` 下 json/png，绝不停留在"指南说"。
- 环境：本地 Qwen2.5-0.5B-Instruct（CPU, thread=1 铁律）+ 智谱 API（glm-4-flash / glm-4.7 / glm-5 含 thinking 开关）。密钥走 auth.json，脚本独立可跑。
- **arXiv ID 全部核实过**（25 篇直接核实，6 篇次要引用标注"据指南"）。记忆里的 arXiv ID 错误率 30-50%，本单元零凭记忆引用。
- 诚实声明贯穿全篇：n 小的地方标 n（多数实验 3-10 题），方向与文献一致处注明"低功效复证"。

## 四、本单元最重要的五个数字

| 数字 | 实验 | 颠覆的直觉 |
|------|------|-----------|
| few-direct **10%** < zero-direct 40% | E3 | "给示例总没错"——只有答案的示例教抄格式不教计算 |
| SC n=9 **83%** < greedy 100% | E4 | "投票总会更好"——系统性偏差下多数票放大错误 |
| PAL **40% = CoT 40%** | E5 | "写代码必赢心算"——PAL 把错误从算术层挤到建模层 |
| ToT **0%** vs CoT 40% | E6 | "搜索框架更聪明"——弱提议器+弱评估器下搜索是负资产 |
| 防御拦截率**全 1/4** | E8 | "写好 system prompt 就安全"——prompt 防御是安全剧场 |
