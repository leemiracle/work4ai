# 12 - 不足与展望：批判收尾

> 讲透Prompt 第 12 章 | 汇总：11 个实验（E1-E11 + E-mini）| 宪法第五幕：把不足说透，单元才算讲透

## 一、本单元十条定律（每条都有实验编号撑腰）

1. **采样参数买多样性，不买能力**（E1）——T 从 0 到 1.5，会的不变会，不会的不变不会。
2. **few-shot 是格式学习器**（E2/E3）——强模型打乱标签都 100%；只有答案的示例教抄数字不教计算（few-direct 40%→10%）。
3. **CoT 咒语是 (模型, 任务) 的函数**（E3/E9/E11）——flash +60pp / +87.5pp，0.5B 救不动，强模型反受伤。
4. **SC 滤噪不滤系统偏差**（E4，E4-R 校准）——5:4 的同源错误能把 greedy 的对票投死；但 E4-R 复查显示偏差由题面歧义强度诱发、边界窄——**先消歧，后投票**（top-share>0.8 且错 = 危险区）。
5. **PAL 让错误搬家，不让错误消失**（E5）——从算术层搬到语义翻译层；沙箱三课（白名单 `__import__`、别剥 import、必设 alarm）是入场费。
6. **搜索框架不注入能力**（E6）——提议器/评估器弱时 ToT 是负资产（0% vs CoT 40%）；有验证器就让代码暴力。
7. **工具补的是外部性缺口**（E7）——日期/精确计算 ReAct 必赢；简单任务上协议开销必输。
8. **链式拆约束，也放大交接面**（E-mini）——规范化难点分段击破（+13pp），null 语义与生僻翻译是新失败点。
9. **prompt 防御是安全剧场**（E8）——四种防御全 1/4；真防线：不拥有秘密 > 不接触脏数据 > 模型对齐 > 输出过滤。
10. **自动优化是 headroom 的搬运工**（E10）——天花板效应 + 解析器也是 harness + 优化的是你的验证集。

## 二、说透本单元自己的不足

1. **n 小，功效低**：多数实验 3-10 题。所有数字都是**方向的指示牌**，不是效应量的估计器。交叉实验（E3/E9/E11 三网格同号）部分补偿，但不改变统计事实。
2. **模型谱系窄**：智谱一家 + Qwen 本地。跨厂商矩阵是天然续作（GPT/Claude/Gemini 的 thinking 模型行为差异是 2026 开放问题）。
3. **judge 靠规则**：关键词/正则判分在开放生成上有盲区（"半劫持"、推理忠实性都没测）。LLM-as-judge 的引入会带来新的循环论证风险——需要人评校准子集。
4. **无成本-收益全账**：每章报了准确率，没统一报 token 成本/延迟。SC n=9 是 9 倍价钱买 -17pp（E4），这种账应该出现在每个表格里。
5. **单发 prompt 中心**：真实系统是 prompt + 上下文 + 工具 + 循环的复合体（`讲透Loop`/`讲透Harness` 的地盘）。本单元的"最优 prompt"结论只在单发场景内有效。
6. **经典题记忆污染**：E6 的 24 点、E11 的 GSM8K 风格题都可能在预训练语料里。我们用了"自造+验算"缓解，但无法根除——**2026 年做评测，出题本身是 prompt 工程的一部分**。

## 三、2026 视角的展望

1. **思考深度接口化**（E9/10 章）：effort 档位吃掉"思考多深"的 prompt 地盘，剩余地盘=任务语义+格式合同+上下文管理。
2. **prompt 优化器进 CI/CD**：E10 的 OPRO 循环套上版本管理和回归测试，就是 prompt 的"单元测试时代"。DSPy 类编译器会吃掉手写链。
3. **攻防军备升级**：E8 显示 prompt 层防御已死，下一层是**架构层隔离**（不可信内容独立调用）与**输出侧合同**（schema 校验+回退）——这与 agent 安全（讲透Agent 08 章）合流。
4. **形式化是终局预览**（11 章）：Lean 域里 prompt 极简+验证器极严，就是所有任务的方向——**验证越便宜，prompt 越不重要，架构越重要**。

## 四、与姊妹单元的接口（读者路线图）

- 想深 **迭代与磨损** → `讲透Loop`（SC/ToT 的多次采样在那儿长成循环）
- 想深 **上下文管理** → `讲透Context`（本单元的输入侧伏笔全部在那儿展开）
- 想深 **工程化 harness** → `讲透Harness`（E10 的解析器教训在那儿系统化）
- 想深 **Agent 与工具** → `讲透Agent`（E7 的三轮循环长成完整 agent）
- 想深 **数学与形式化** → `top-math-courses/MATH_LOOP_ENGINE.md` + `实战案例-Prover数学Agent/`
