# 14 · 机制设计与显示原理：反向博弈论

> 卷四收官：[13 章](./13-拍卖理论.md)设计了一场拍卖，[12 章](./12-合作博弈.md)设计了一个匹配市场——本章把两者收进同一部语法：**机制设计 = 反向博弈论**（给定想要的结果，反求让自利者自动实现它的规则）。三件套立正：**IC/IR 约束**（说真话占优 + 参与不亏——DSIC 的公理化户口，lab06 E3 的 0 次 vs 8 次是它的最小现场）、**显示原理**（任何机制的任何均衡，都能换成"直接报告类型 + 说真话是均衡"——设计者的搜索空间从规则宇宙塌缩成一张社会选择函数表）、**VCG 的唯一性账单**（效率 + DSIC 几乎锁定 Groves 类——唯一正确解的代价是合谋脆弱与收入非单调）。现场施工两例：**肾交换**（环 + 链的全国系统）与**择校**（Boston 机制的操纵课）；最后 AI 登场：**RLHF 就是一部机制**——奖励模型是社会选择函数、奖励黑客是策略性应对、宪法是报告空间。[50 章](./50-批判收尾.md)卷四定位的收官句在此落地：**放弃预测、改造博弈，是四堵墙最优雅的出口。**

**2007 年 10 月 15 日，明尼阿波利斯**。时年 90 岁的 Leonid Hurwicz 接到斯德哥尔摩的电话，成为当时最年长的诺贝尔经济学奖得主——与 Eric Maskin、Roger Myerson 三人因*"奠定机制设计理论的基础"*同奖。Hurwicz 1960 年问了一个此前没人当真问的问题：**经济学能不能不把制度当天气，而把制度当变量？** 此前的新古典理论在给定的市场里求均衡（02 章的做法）；Hurwicz 问：**什么样的信息沟通规则，能让自利的参与者替社会算出想要的配置？** 半个世纪后，这个问题的答案运行在频谱拍卖（13 章）、医生匹配与肾交换（12 章与本章）、广告竞价（[18 章](./18-博弈论与LLM对齐.md) ◆ 的现场）里。本章立场一句话：**正向博弈论解"这个规则下会发生什么"；机制设计解"想要的发生需要什么规则"——均衡从答案变成了约束。**

## 一、反向：把均衡当约束

机制设计的标准件一次立齐：

| 部件 | 记号 | 意义 | 现场对应 |
|---|---|---|---|
| 环境 | 类型 θᵢ ∈ Θᵢ | 每人私有信息（估值/偏好/成本） | 竞拍者的 v、学生的志愿序 |
| 目标 | 社会选择函数 f: Θ → X | 设计者想要的"类型剖面 → 结果"映射 | "估值最高者得"、"无阻塞对匹配" |
| 机制 | (M, g) | 报告空间 M + 结果规则 g: M → X | 二价拍卖：报 b、付次高、最高者得 |
| 实施 | 均衡 | 玩家在机制里博弈出的报告 | 诚实（想要的）或操纵（要堵的） |

**方向反转一张表**：

| | 正向（02/08 章） | 反向（本章） |
|---|---|---|
| 给定 | 机制（博弈规则） | 目标 f |
| 求解 | 均衡是什么 | 什么机制的均衡实现 f |
| 均衡的身份 | 预测 | **约束** |
| 坏消息 | 多均衡/不可信威胁 | 不可能性定理 |

已见的三台机器对号入座：二价/VCG（[13 章](./13-拍卖理论.md)）实施"估值最高者得 + 说真话"；要求-接受 DA（[12 章](./12-合作博弈.md)）实施"稳定匹配 + 求婚方说真话"；带保留价的二价（13 章 §五）实施"虚拟估值最高者得"——**它们都是"机制"这个词的具体积分**。lab06 E3 的对拍输出（本机实测）是 IC 的最小现场，直接搬来当本章的仪器读数：

```
E3 · 谎报实验：求婚方 DSIC vs 受方可操纵（8 玩家 × 24 种谎报全枚举）
理论锚点（定理）：求婚方严格改进 0 次（Dubins-Freedman 1981，任何实例）；受方改进为实例性（Roth 1982，存在性）
  男（求婚方）4 人 × 24 种谎报 = 96 次：严格改进 0 次（逐人 [0, 0, 0, 0]），严格变差 54 次——谎报无利、且可能自伤
  女（受方）  4 人 × 24 种谎报 = 96 次：严格改进 8 次（逐人 [0, 4, 0, 4]）
    具体轨迹：w3 谎报偏好 [2, 3, 0, 1] → 终局配 m3（第 1 志愿，原第 3 志愿）——受方操纵成功
→ E3 对拍：求婚方 0 改进 = DSIC 数值验证；受方 8 次改进 = 不可双向复制 —— 全绿 ✓
```

## 二、IC/IR：说真话的语法

只研究一类好操作的机制不失一般性（下一节证明为什么）：**直接机制**——报告空间就是类型空间（M = Θ），报告什么、机制就当真什么。两条定义：

- **激励相容 IC（DSIC 版）**：对每个玩家每种类型，报告真实类型是**占优策略**——θᵢ 报 θᵢ 的效用 ≥ 报任何 θᵢ′ 的效用，**无论别人报什么**。（贝叶斯版 BNIC 只要求给定信念最优——[08 章](./08-不完全信息与贝叶斯均衡.md)的一价拍卖均衡就是 BNIC 而非 DSIC：b = v/2 是均衡行为，不是占优策略。）
- **个体理性 IR（参与约束）**：参与机制的期望效用 ≥ 保留效用（不玩走人的选项）——VCG 里"赢家付外部性 ≤ 自己估值"天然保 IR；拍卖里卖方也有自己的 IR（底价）。

IC 与 IR 的张力不是工程摩擦，是数学墙——**不可能性三连**（陈述，置信度：高，均为教科书标准结果）：

| 定理 | 设定 | 结论 |
|---|---|---|
| **Gibbard-Satterthwaite**（1973/75） | ≥ 3 个结果、无独裁、f 取遍所有结果 | **必可操纵**——DSIC 的 f 只有独裁或常数 |
| **Myerson-Satterthwaite**（1983） | 双边交易（买方估值 vs 卖方成本，双方私有） | 效率 + IC + IR + 无补贴**不可兼得**——VCG 在双边交易里必然亏钱或低效 |
| **Arrow**（1951） | ≥ 3 选项的社会排序、无域限制 | 帕累托 + 无关备选独立性 + 无独裁不可兼得 |

一句话读法：**"人人诚实 + 有效 + 自愿"是个三体问题，一般无解**。机制设计的全部手艺在于：认出自己在哪个定理的射程里，然后**放宽最便宜的那一条**——限域（单参数估值、拟线性偏好——VCG 的生存区）、放弃效率（稳定但不最优的匹配）、引入第三方补贴（拍卖行=公共卖方，Myerson-Satterthwaite 的"无补贴"不成立，所以 13 章的 VCG 活得好好的）。

## 三、显示原理：设计者的搜索引擎

**显示原理（Myerson 1979；置信度：高）**：任何机制在任何均衡下能达到的结果，都存在一个直接机制使**说真话（按同一均衡概念）复现同一结果**。证明是机制设计里罕见的便宜货，两步：

1. **打包**：把原机制的均衡策略 sᵢ(θᵢ) 连同原机制 g 一起装进新机制 g̃ = g ∘ s——你报类型 θᵢ，机制替你执行"类型 θᵢ 的均衡行为"；
2. **诚实的传递**：原均衡里 sᵢ(θᵢ) 是对别人的最优反应 ⟹ 在 g̃ 里"报真话"就是对别人（同样报真话）的最优反应——偏离 g̃ 的说谎，恰好对应原机制里偏离均衡，两头都不划算。∎

三条读法：其一，**无穷规则空间塌缩成一张表**——"什么机制能实施 f"变成"f 满足什么条件才 IC"，代数题替换了发明学；其二，**它不白送机制**——只保证"要找就直接机制的诚实均衡里找"，f 好不好实施另算（Gibbard-Satterthwaite 就是翻遍这张表后的"查无此人"）；其三，**等价是均衡级的**——机制在均衡外的稳健性、可理解性、抗合谋性都不在等价范围内（GSP 的存在价值，13 章 §六）。

## 四、VCG 再访：唯一性的账单

13 章装好的 VCG，现在放进公理货架看它站在哪：

**Green-Laffont（1979）**：拟线性偏好下，**DSIC + 有效率的机制几乎必然是 Groves 类**——分配必须最大化申报剩余，支付必须是"别人的剩余 + 一个只依赖别人报告的任意项"。VCG 是这类里最简单的（任意项取零）。

唯一性是荣耀也是账单。**自由度只剩"只依赖别人的支付项"**（✍️ 练习⑤用它造退款机制），于是：合谋的两人可以互报天价套互补折扣；拆成"托儿"多身份进场可以逃外部性（Ausubel-Milgrom 2006）；收入对进场者人数**非单调**——多一个竞拍者收入反而可能降。这些不是 VCG 写错了，是"DSIC + 有效"这把钳子把其他自由度全夹死了。工程界的应对各有姿势：Google 用 GSP（弃 DSIC 换可解释），FCC 2017 年频谱"激励拍卖"用 Milgrom 的两段式（反向拍卖回购广播频段 + 正向拍卖重售）绕开组合 VCG 的算力与操纵坑——**机制设计的实战是"公理 + 预算 + 算力 + 可解释"的多目标折中**，DSIC 只是其中一个旋钮。

## 五、现场施工：肾交换与择校

**肾交换**：尿毒症患者与亲友供体不配型，两组家庭交叉捐献即可各得其所——这是一个匹配市场，但比婚姻难：配型兼容图是**有向图**，能成交的是环（cycle）与链（chain，由无私捐献者起头不必闭合）。Roth-Sönmez-Ünver 2004 给出理论，2010 年起 UNOS 运行全国系统：每周批处理，在兼容图上解"最多救多少人"的整数规划（环长限 3——移植手术须同时进行，长环的协调成本爆炸；链可以拖数周）。**机制设计的教科书级闭环：定理 → 试点 → 全国政策 → 救回的人命。**

**择校**：波士顿机制（按第一志愿排位录满即止，录不上再滑到队尾）的操纵课：第一志愿若填了热门校落空，孩子在第二志愿也排到队尾——**诚实危险，谎报"安全校"是均衡行为**（家长手册当年明着教）。Abdulkadiroğlu-Sönmez 2003 诊断出这是"受方（学校）优先的即决机制"，纽约（2003）与波士顿（2005）改用**要求-接受（DA）**：家庭报真话免罚、学校侧公开排位规则——正是 [12 章](./12-合作博弈.md) Gale-Shapley 的市政工程版，lab06 E2 的两方向读数（阻塞对 = 0、求婚方优势）在此照搬为"学生侧求婚"的设计选择。

| 市场 | 失灵症状 | 机制处方 | 落地 |
|---|---|---|---|
| 肾交换 | 配型不兼容的"捐不起" | 兼容图上环+链的集中清算（RSU 2004） | UNOS 2010 起 |
| 择校 | Boston 机制操纵成风 | DA 替代（AS 2003） | 纽约 2003 / 波士顿 2005 |
| 频谱 | 行政抽签/听证的低效 | SMR 与激励拍卖（13 章） | FCC 1994 / 2017 |

三案同构一句话：**不预测参与者想什么，只把"想做坏事"的激励拆掉**——[50 章](./50-批判收尾.md)"语法而非水晶球"的机制设计版。

## 六、AI 连接：RLHF 是一部机制

把 RLHF 的零件装进 §一的表里，严丝合缝：

| 机制部件 | RLHF 现场 |
|---|---|
| 玩家与类型 | 标注者（偏好各异、私密）+ 模型（策略集 = 全部可能输出） |
| 机制 (M, g) | 奖励模型 r(·)：比较数据的聚合 + RL 优化它 |
| 社会选择函数 f | "人类集体偏好"→ 单一标量——**一部微缩宪法** |
| 策略性应对 | **奖励黑客**：模型最大化 r 而非真目标（Goodhart——代理指标被优化到与目标分家） |
| IC 缺口 | 标注质量不可核实、偏好异质无聚合正解（Arrow/Gibbard 的阴影正好落在这里） |

三个机制论断（[18 章](./18-博弈论与LLM对齐.md) ◆ 展开实证侧）：其一，**奖励黑客不是 bug，是 IC 失效的标准症状**——观测空间太粗（r 只是人类偏好的有损压缩），模型的"报告"（输出）在 r 与真目标之间套利；其二，**宪法/原则是报告空间的设计**——把"什么算好"写进可检验的规则，等于把 f 从隐函数变成直接机制的说明书；其三，**多标注者偏好聚合是社会选择问题**——Arrow 的不可能性不因换上神经网络而失效，"标注者间分歧"是 RLHF 的内生噪声而非数据缺陷。同一视角看**数据与算力市场**（模型竞标数据、竞价算力——13 章拍卖语法的 AI 后院）与 **AMD（automated mechanism design，Conitzer 2002）**：让求解器直接在机制空间里搜索最优规则——机制设计的计算化，而它常把"找均衡"换成"解一个 LP/MILP"（肾交换每周批处理就是现例），恰是 [50 章](./50-批判收尾.md)第二堵墙（找均衡 PPAD-难）的工程绕行。

## 七、不足与边界

1. **不可能性三连是宪法不是 bug 清单**：DSIC + 效率 + IR + 无补贴的多目标在一般域无解；手艺在于识别射程、放宽最便宜的一条（§二的三个出口）。
2. **显示原理的等价不覆盖"均衡之外"**：抗合谋、抗托儿、动态里的承诺问题、参与者的理解成本——GSP 的市场份额证明这些"公理外指标"真能决定胜负。
3. **简单性不入公理**：Roth 的市场设计清单（厚度/拥塞/安全性/**简单性**）里，"参与者能懂"是硬约束——机制设计的落地是社会学工程，不只是定理（NRMP 的自由退出权、择校的地缘政治）。
4. **计算是内生的**：最优机制往往 NP-hard（肾交换的环覆盖、组合 VCG）——"定义优雅 ≠ 计算便宜"（[12 章](./12-合作博弈.md) 2ⁿ 账单的机制版），AMD 是把这笔账摆上台面的尝试。
5. **RLHF 的机制视角是隐喻加半个定理**：说"隐喻"，因为人类 principal 无法与模型签可执行合同（IR 不完备）；说"半个定理"，因为奖励黑客/标注者分歧确是 IC/社会选择的真问题——18 章给它实验证据的户口。
