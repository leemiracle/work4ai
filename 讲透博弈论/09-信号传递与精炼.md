# 09 · 信号传递与精炼：成本即语言

> 卷二收口：BNE 赢回了"不知道对手是谁"的数学，却签下了新账单——**均衡太多了**。本章立起 Spence 教育信号模型（能力私有、教育无生产力、成本按类型分层——**单交叉**）：分离均衡与混同均衡**整族并存**，连"教育毫无用处"都是均衡；把 08 章 PBE 审计升级成**精炼标准一览**，重点讲直觉标准（Cho-Kreps：偏离要"够格"才配得到好信念），当场筛到唯一存活；然后问出"不花钱的话能传多少信息"——Crawford-Sobel 廉价磋商（利益够一致才有真话）；最后把镜头转向 AI：**LLM 的每句话都是廉价磋商**，对齐工程做的事，翻译过来就是"让话变得可信"——18 章伏笔在此埋下。

---

**1973 年，斯坦福**。Spence 把博士论文的核心写成 QJE 的 *Job Market Signaling*：模型里教育**对生产力毫无贡献**，雇主却愿意为文凭付高价，求职者也甘愿为文凭付出真金白银的成本——因为**成本本身在说话**：拿同样的文凭，高能力者花的代价小。这篇论文让他与 Akerlof（柠檬市场）、Stiglitz（筛选）共享 2001 年诺贝尔奖，颁奖词正是"不对称信息"。本章立场一句话：**信号的价值不在内容在成本——没有成本差异的语言，要么是噪声，要么是说给利益一致者听的真话。**

---

## 一、Spence 模型：教育不增值，却值钱

玩家与信号（教学数字全部声明在案）：求职者类型 θ ∈ {H, L}，先验各 1/2，生产力 y_H = 2、y_L = 1（**只有自己知道**）；他可选教育水平 e ≥ 0，取得 e 的成本 c_H(e) = e²/4、c_L(e) = e²/2——**教育不改变生产力，纯粹烧钱**。时序：求职者（知类型）选 e → 企业观察 e（观察不到 θ）→ 竞争性企业按信念出工资 **w(e) = E[y | e]**（两企业竞价 = 期望生产力归工人，零利润）。

**单交叉（single crossing）**是全套戏法的支点：c_L(e) = 2·c_H(e) 处处成立——**同一份教育，低能力的代价永远双倍**（边际成本 e/2 > e/4 也处处双倍）。信号之所以能传递信息，不靠内容的真假，靠的是**获取成本按类型分层**：这正是 07 章承诺装置表里"烧钱信号"一行的正式化——不可逆成本 + 按类型分层 + 只有强者烧得起。承诺与信号是一枚硬币：**承诺用成本改变对手的最优反应，信号用成本暴露自己的类型。**

## 二、分离均衡：一道门槛让低能力自暴

分离策略：H 选 e\*、L 选 0；企业的信念随之定型——见 e\* 信 H（w = 2），见 0 信 L（w = 1）。两个类型各自愿意照办的条件（BNE 审计逐类型过）：

| 类型 | 偏离选项 | 约束 | 解出 |
|---|---|---|---|
| H（守 e\*） | 装文盲得 w=1 | 2 − e\*²/4 ≥ 1 | e\* ≤ **2** |
| L（守 0） | 伪装 H 得 w=2 | 1 ≥ 2 − e\*²/2 | e\* ≥ **√2 ≈ 1.414** |

**任何门槛 e\* ∈ [√2, 2] 都是分离 BNE**——不是点，是整段区间。读法：门槛必须高到 L 爬不动（≥ √2），又不能高到 H 自己也放弃（≤ 2）——信号区间正是**两种成本曲线之间的空隙**，单交叉保证空隙非空。注意区间内哪个 e\* 都行：BNE 概念对"门槛定多高"完全失语。

## 三、混同均衡并存：教育无用也可以是均衡

反过来让两类选同一水平 e_p：企业分不出类型，工资按先验 **w = (2+1)/2 = 1.5**。逐类型审计"不往上爬"：H 守 e_p 得 1.5 − e_p²/4 ≥ 1 ⟺ e_p ≤ √2；L 得 1.5 − e_p²/2 ≥ 1 ⟺ e_p ≤ 1（绑腿在 L）→ **任何 e_p ∈ [0, 1] 都是混同 BNE**。收益曲线的并存一目了然：

| 均衡族 | 谁选什么教育 | 工资 | 存在条件 |
|---|---|---|---|
| 分离（连续统） | H → e\*，L → 0，e\* ∈ [√2, 2] | w(e\*)=2, w(0)=1 | 单交叉空隙非空 ✓ |
| 混同（连续统） | 两类同选 e_p，e_p ∈ [0, 1] | 双双 1.5 | L 爬离 e_p 不划算 ✓ |
| 混同的极端 | e_p = 0（**人人零教育**） | 双双 1.5 | "教育纯属无用"自我实现 |

三个世界并存，预言截然不同——而 **e_p = 0 的世界里教育市场根本不该存在**。这堆多余的均衡正是 08 章 §六那道缝的全身像：PBE 能用"信念钉死"筛掉树上玩假的威胁，却筛不动"人人都选低教育"（那不在偏离审计里，在信念的宽松里）。筛它的剪刀叫**精炼**。

## 四、精炼标准一览与直觉标准：偏离要"够格"

| 标准 | 一句话 | 出场 |
|---|---|---|
| SPE | 每个子博弈上都是 NE | 07 章 |
| PBE | 每个信息集：信念 Bayes 自洽 + 序贯最优 | 08 章 §六 |
| **直觉标准**（Cho-Kreps 1987） | 偏离到路径外消息的**类型**，若在该消息上**任何信念下都不可能得利**（被支配），均衡信念必须给它零概率 | 本节主角 |
| 序贯均衡 / divinity / 稳定性 | 更细的信念纪律与更强的筛选 | 50 章补丁表收总账 |

**直觉标准一段话**（Cho-Kreps 1987，啤酒-蛋饼：强者早餐喝啤酒、弱者吃蛋饼，混同均衡里弱者硬喝啤酒装强者——被"谁有胆量点错早餐"的反问当场问死）。移植到我们的数例，三连筛全程可手推：

1. **杀 e_p = 0 混同**：考虑偏离到 e′ ∈ [1, √2)。L 在此消息上被支配（任何信念下工资 ≤ 2，而 2 − e′²/2 ≤ 1.5 = 混同工资 ⟺ e′ ≥ 1）→ 信念必须全押 H → 工资 2 → H 一算（如 e′ = 1.2：2 − 1.44/4 = 1.64 > 1.5），**H 真的走了** → 均衡崩。
2. **杀一切混同**（e_p ∈ [0, 1]）：同样的账换个区间——e′ ∈ [√(1+e_p²), √(2+e_p²))，L 被支配、H 得利（H 在区间中点 1.57 > 1.44 当 e_p = 0.5），三例验证过，区间恒非空 → **全部混同出局**。
3. **修剪分离**（e\* > √2）：偏离到 e′ ∈ (√2, e\*)，L 被支配（2 − e′²/2 ≤ 1）、H 得利（e′ < e\* 省成本同工资）→ H 降门槛走人 → 只剩**最低成本分离 e\* = √2**。

筛完全场只剩一个：**门槛恰在 L 支配线上的最低成本分离均衡**。诚实标注两笔：其一，直觉标准杀不死 e\* = √2 本身（偏离向下则两类都可能得利、信念不受限，悲观信念下无人走——✍️ 练习④手推）；其二，精炼是补丁史不是终审判决——直觉标准之后还有 divinity、稳定性，50 章的军备竞赛清单会替这份名单续页。社会层面的账单另记一笔：唯一存活均衡里每位 H 烧掉 c_H(√2) = 0.5 的真实资源，**生产力一分未涨**——信号有信息价值，几乎从无生产价值。

## 五、廉价磋商：不要钱的话能传多少信息

把"成本"旋钮拧到零：发言者观察到状态 θ ~ U[0,1]，随后**免费、不约束任何人地**发一条消息；接收者据消息选动作 a。发言者效用 −(a − (θ + b))²（理想点带偏置 b > 0），接收者 −(a − θ)²（Crawford-Sobel 1982）。**空谈均衡永远存在**：说了等于没说（接收者无视消息选 a = 1/2），发言者也懒得绕弯——这就是 07 章那句"廉价磋商式口头承诺三者全无"的坏消息全貌：**不要钱的话构不成承诺**。但 Crawford-Sobel 的另一半是好消息：**利益足够一致时，免费的话真能传信息**。两段分划的完整推导：

- 分划 [0, θ₁), [θ₁, 1]：接收者按区间均值行动 a₁ = θ₁/2、a₂ = (θ₁+1)/2；
- 边界类型 θ₁ 必须无差异：θ₁ + b − θ₁/2 = (θ₁+1)/2 − θ₁ − b → **θ₁ = 1/2 − 2b**；
- θ₁ 落在 (0,1) 内 ⟺ **b < 1/4**。偏置超过 1/4，连"半准话"都保不住——全塌成空谈。

一般结论（uniform-quadratic 经典结果，此处陈述；高置信）：最多能说成 N 段 ⟺ N(N−1) ≤ 1/(2b)——**利益越一致（b 小），语言越碎、信息越细；利益分歧越大，语言越快退化成噪声**。可信性的来源就此分野：承诺靠**改变收益**（07 章），廉价磋商靠**收益本来就够一致**（本节）——信号则居中，用真实成本**替不一致者伪装**。三个概念一张图。

## 六、AI 连接：LLM 的每句话都是廉价磋商

把 Crawford-Sobel 的发言者换成语言模型：token 免费、不构成承诺、事后无法追责——**LLM 通信天然落在廉价磋商的域里**。翻译三条：

- **多智能体协作/辩论**：agent 互相说服 = 发言者与接收者的 b 未必小——辩论收敛存疑（说服偏置、谄媚）正是"b 偏大、话塌成空谈"的工程化身（[18 章](./18-博弈论与LLM对齐.md) ◆ GTBench 与辩论专题接手）。
- **对齐 = 让话可信**，信号模型给出两条正交路数：改**策略本身**（诚实训练/RLHF——把说谎从均衡策略里挤出去）与改**消息成本**（验证器、工具调用、可检验声明——廉价磋商升级成昂贵信号，07 章承诺装置的工程版）。
- **评估即信号**：被污染的 benchmark（测试题漏进训练集）是**无成本假信号**——"会说"冒充"会做"；held-out 集与防污染协议是给信号重新加上成本。**信号的价值在成本，不在音量。**

诚实标注：以上是**结构性类比**，不是已证定理——LLM 是否按均衡行事、b 多大，是实证问题（18 章诚实框收口）。

## 七、不足与边界

1. **教育在现实中当然有人力资本效应**：纯信号模型是教学剪裁；实证世界是信号与资本混合定价（方向上，文凭的"羊皮纸效应"为信号成分提供了证据；置信度：中高）。
2. **直觉标准依赖"类型深知自己收益 + 反事实推理被认真执行"**：实验室受试者并不总按精炼行事——50 章第一堵墙的老账。
3. **CS 的碎话上限是 uniform-quadratic 特例**：偏好曲率、状态分布一换，分划形状全变，只有"b 大则语言退化"的方向稳健。
4. **精炼没有终点**：直觉标准只是补丁序列的一站（序贯均衡、divinity、稳定性……），每一站都有新的反例——50 章补丁表收总账。
5. **AI 类比的三条腿（改类型/改成本/评估防污染）是设计词汇，不是收敛证明**：多智能体辩论何时收敛，18 章 ◆ 给文献快照而非定论。
