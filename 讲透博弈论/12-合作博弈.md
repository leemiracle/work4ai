# 12 · 合作博弈：分配的语法

> 卷三收口：前十一章的博弈论都在回答"给定规则，自利者怎么互动"——本章换掉问题本身。当玩家可以**签约结盟**（把策略互动收进谈判桌），剩下的问题只有一个：**蛋糕怎么分**。本章立起合作博弈的三件套：**特征函数 v(S)**（每个联盟自己能挣多少）、**Shapley 值**（四公理唯一确定的公平分配公式——三人投票 φ=(1/3,1/3,1/3) 与机场跑道 100/180/220 两份完整手算）、**核**（无阻塞联盟的稳定分配集——投票博弈的核当众变空）；然后用 Gale-Shapley 稳定匹配把"分蛋糕"升级成"改制度"（NRMP/择校/肾交换——[14 章](./14-机制设计与显示原理.md)在此露头）；最后把 Shapley 值交给机器学习：**SHAP 就是它的 ML 化身**。

---

**2012 年，斯德哥尔摩**。诺贝尔经济学奖授予 Alvin Roth 与 Lloyd Shapley，颁奖词：*"稳定匹配理论与市场设计实践"*。奖状背后压着两篇一页纸级别的文章：1953 年 Shapley 的 *A Value for n-Person Games*——一个四公理体系，唯一确定"公平分配"的公式；1962 年 Gale 与 Shapley 的 *College Admissions and the Stability of Marriage*——一个大学生都能执行的要求-接受算法，半个世纪后运行在美国医生就业市场与纽约数十万学生的择校系统里。本章立场一句话：**非合作博弈预测自利者会怎么玩，合作博弈回答自利者凭什么接受分配——前者是策略的语法，后者是分配的语法。**

---

## 一、换单元：从个体策略到联盟收益

[00 章"建模四事故"](./00-开场.md)的第四条——玩家单位错——在本章兑付解药。**特征函数型合作博弈**只需一个数据结构：**v: 2^N → ℝ**，给每个联盟 S ⊆ N 标一个数字"这个联盟自己能挣多少"（v(∅) = 0；通常设**超可加**：不相交的联盟合则两利，v(S∪T) ≥ v(S) + v(T)——激励全在结盟）。策略、信息、时序被一次性收进这张表里：谈判桌上的讨价还价，浓缩为"哪个分配各方都肯签字"。

| | 非合作博弈（01-11 章） | 合作博弈（本章） |
|---|---|---|
| 分析单元 | 个体与策略 | 联盟与分配 |
| 核心问题 | 均衡会发生什么？ | 哪些分配能被接受？ |
| 解概念 | NE / SPE / ESS | Shapley 值 / 核 / 稳定匹配 |
| 时间与信息 | 主角 | 收进 v(S)（签约一次性完成） |

一条假设先声明：**可转移效用（TU）**——联盟收益是钱，可在成员间线性过户（本章全部结果在此口径下；不可转移效用 NTU 的推广不展开，[14 章](./14-机制设计与显示原理.md)的 VCG 同属 TU 世界）。

## 二、Shapley 值：四公理唯一锁定的分配公式

n 人挣下 v(N)，怎么分才公平？Shapley 的做法不是直接给答案，而是先把"公平"拆成四条谁也无法拒绝的公理：

| 公理 | 内容 | 一句话 |
|---|---|---|
| **有效** | Σᵢ φᵢ(v) = v(N) | 蛋糕分完，一块不剩 |
| **对称** | 贡献相同的两人分得相同 | 名字不参与分配 |
| **哑元** | 对任何联盟都不改变收益的玩家得 0 | 不添砖者不拿瓦 |
| **可加** | 两个博弈并账，分配 = 各自分账之和 | 会计不串账 |

**Shapley 定理（1953，陈述）**：满足四公理的分配**存在且唯一**——它就是**Shapley 值**（置信度：高，教科书标准结果）：

$$\varphi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(n-|S|-1)!}{n!}\,\big[v(S \cup \{i\}) - v(S)\big]$$

公式的**到达次序读法**最好记：n 个人随机排队入伙（n! 种次序等可能），i 拿到自己到场时刻给桌上添的边际贡献，然后取平均。权重 |S|!(n−|S|−1)!/n! 恰是"i 到达时在场的恰为 S"的概率——S 的成员先到（|S|! 种排法），其余 n−|S|−1 人后到（(n−|S|−1)! 种排法）。**Shapley 值 = 你在一切入伙次序下的平均边际贡献**：不看你多重要，看你到场时添了多少。

## 三、手算两例：投票的权力与跑道的洋葱

**例一：三人投票博弈**（51% 规则：任意两人可强通，一人不成事）。v(S) = 1 若 |S| ≥ 2，否则 0。对玩家 1 列全表（玩家 2、3 由对称公理免算）：

| i 到场时在场 S | 权重 |S|!(3−|S|−1)!/3! | 边际 v(S∪{1})−v(S) | 贡献 |
|---|---|---|---|
| ∅ | 2/6 = 1/3 | v({1}) − 0 = 0 | 0 |
| {2} | 1/6 | v({1,2}) − v({2}) = 1 | 1/6 |
| {3} | 1/6 | v({1,3}) − v({3}) = 1 | 1/6 |
| {2,3} | 1/3 | v(N) − v(N) = 0 | 0 |

**φ = (1/3, 1/3, 1/3)**：三票平权的博弈里每人恰得 1/3 权力。这个例子平凡，但它演示了完整的机器；一旦换成加权投票（如 [51; 40, 35, 25]），权力立刻偏离票数——Shapley 值是**权力指数**（Shapley-Shubik 1954）的数学母体，选票换算成权力的唯一公理化通道。

**例二：机场跑道成本分摊**（Littlechild 1974 的经典）。三家航司，机型所需跑道长度的建设成本分别为 100、180、220；共建一条跑道，规格由最贵机型决定：c(S) = max{成员成本}。对玩家 3（成本 220）列全表：

| i 到场时在场 S | 权重 | 边际 c(S∪{3}) − c(S) | 贡献 |
|---|---|---|---|
| ∅ | 1/3 | 220 − 0 = 220 | 220/3 |
| {1} | 1/6 | 220 − 100 = 120 | 20 |
| {2} | 1/6 | 220 − 180 = 40 | 20/3 |
| {1,2} | 1/3 | 220 − 180 = 40 | 40/3 |

φ₃ = 220/3 + 20 + 20/3 + 40/3 = **340/3 ≈ 113.3**。同法：φ₁ = 100/3 ≈ **33.3**（只有独自到场那次有边际 100，其余每个联盟里跑道规格都由别人抬着）；φ₂ = 180/3 + (180−100)/6 = **220/3 ≈ 73.3**。**效率校验：33.3 + 73.3 + 113.3 = 220 ✓**（分毫不差地摊完全部造价）。

跑道是个洋葱，Shapley 值按"层"切它：0→100 的基座三家平摊（各 33.3），100→180 的升级由 2、3 号平摊（各 40），180→220 的封顶 3 号独付（40）——合计恰是上面的三个数。**用得多的人付升级差价，但基座人人有份**：这是"平均边际贡献"在成本分摊里的形状。手算对拍（numpy 枚举 2ⁿ 子集 + Gale-Shapley 稳定性检查 + 谎报 DSIC 实验）由 [`experiments/lab06_matching_shapley.py`](./experiments/lab06_matching_shapley.py) 承接——E1 公式/手算/随机次序三路一致（φ=(1/3,1/3,1/3) 与 33.3/73.3/113.3 全对）、E2 两方向阻塞对双双 = 0、E3 求婚方谎报 96 次 0 改进 vs 受方 8 次改进；本章的分配问题用不上 lab05 的仪器——E1 锦标赛测的是"谁在重复中存活"（[10 章](./10-重复博弈与无名定理.md)），而"蛋糕该怎么分"不是锦标赛能测的：合作博弈把策略互动收进谈判桌，剩下的只有账目。

## 四、核：无阻塞联盟的分配集

Shapley 值回答"公平"，另一派回答"**稳定**"：一个分配若存在联盟 S，其成员分到的合计 **劣于** S 自己单干（Σ_{i∈S} xᵢ < v(S)），S 就会拆台——这叫**阻塞**。**核（core，Gillies 1953）**：效率（Σxᵢ = v(N)）且无任何阻塞联盟的分配集。它是"没有任何小圈子有拆台动机"的极端稳定性。

**三人投票博弈的核 = 空**，两行证明：任取分配 x，三对之和 (x₁+x₂)+(x₁+x₃)+(x₂+x₃) = 2，故最小的一对 ≤ 2/3 < 1 = v(该对)——这对联盟当场阻塞。∎ 任何分配都被某个二人组否决，**没有稳定点**。核与 Shapley 值的分道扬镳一张表：

| | Shapley 值 | 核 |
|---|---|---|
| 存在性 | 任何特征函数博弈都存在 | **可能为空**（投票博弈） |
| 唯一性 | 唯一 | 通常是一整块区域 |
| 哲学 | 公平平均（边际贡献） | 无阻稳定（没人能拆台） |
| 三人投票 | φ = (1/3,1/3,1/3) ✓ | ∅ |

机场博弈站在核这一侧：成本函数 c(S) = max 是**凹（次模）**的，凹博弈的核非空、且 Shapley 值恰落在核内（核非空的刻画是 Bondareva-Shapley 的平衡性条件，1963/1967；置信度：高）——✍️ 练习②让你亲手验证这一行。

## 五、Gale-Shapley 稳定匹配：分蛋糕的语法变成改制度

1962 年那篇文章处理的是无法过户的"蛋糕"——婚姻：n 男 n 女，每人一份对异性的严格偏好序，目标是**完美匹配**且**无阻塞对**（不存在 m、w：m 更爱 w 胜过现任，且 w 更爱 m 胜过现任）。**要求-接受算法（deferred acceptance）**四步：

1. 每个未婚男向他偏好单上尚未拒绝过的最高位女子求婚；
2. 每位女子**暂存**（defer）当前最中意的求婚者，拒绝其余（含已暂配者——暂存不是承诺）；
3. 被拒者降级再求；直到无人未婚。
4. 终局：暂配全部转正。

三件事打包陈述（Gale-Shapley 1962；置信度：高）：算法**必停**（每人至多向每人求婚一次，总步数 ≤ n²）；停在**稳定匹配**（一被拒绝就永久出局的结构里，阻塞对无处藏身）；且求婚方得到**自己一切稳定匹配中的最优对象**——所以求婚方说真话占优（**求婚方 DSIC**，Dubins-Freedman 1981），受方则**可以**靠谎报偏好操纵结果（Roth 1982；✍️ 练习③给你一个两男两女的完整操纵现场）。稳定性的主意一以贯之：**不预测谁配谁，只保证没有阻塞对**——预测的不可得，换取了机制的可执行（[50 章](./50-批判收尾.md)语法表的最好注脚）。

把"婚姻"换回市场，就是 2012 年另一半奖牌——**市场设计**：

| 市场 | 不稳定的症状 | 设计动作 |
|---|---|---|
| **NRMP 医生匹配**（Roth 1984 诊断） | 提前抢聘、毁约成风——市场自己长出来的规则恰不稳定 | 1998 年按 DA 原理改制 |
| **择校**（Abdulkadiroğlu-Sönmez 2003） | 波士顿机制可操纵：第一志愿填不满就全盘皆输 | 纽约/波士顿改用 DA |
| **肾交换**（Roth-Sönmez-Ünver 2004） | 活体供肾不匹配的"捐不起" | 配对交换 + 链式交换，全美系统运行 |

机制设计（[14 章](./14-机制设计与显示原理.md)）把这些案例收进通用语法：**设计规则，让好结果自动成为均衡**——稳定匹配是它的第一座纪念碑，RLHF 是它碰到 AI 的地方。

## 六、AI 连接：SHAP 是 Shapley 值的 ML 化身

把博弈的玩家换成**特征**，联盟的收益换成**模型输出**：v(S) = 固定特征子集 S、对其余特征取期望时模型的预测。四公理逐条过审：有效（归因分完预测值）、哑元（无用特征归因 0）、可加——**Lundberg-Lee 2017 的 SHAP** 就是这套机器在可解释 ML 的落地：φᵢ = 特征 i 对这次预测的贡献，且 Σφᵢ = f(x) − E[f(x)]（预测相对基线的差额**精确分完**，这是树模型 importances 那类启发式给不出的账目）。TreeSHAP（Lundberg et al. 2020，Nature Machine Intelligence）把树模型的精确计算压到多项式，SHAP 因此上产线。同一台机器还管着多智能体的**信用分配**：团队奖励是 v(N)，子团队表现是 v(S)，个体功劳 = Shapley 值——"这次成功谁的功劳"与"这条跑道谁该摊多少"是同一道题（✍️ 练习④给线性模型算精确 SHAP）。诚实标注一笔：特征相关时，"固定 S、平均其余"的反事实不是因果——SHAP 解释的是模型的账，不是世界的账。

## 七、不足与边界

1. **TU 假设是真刀**：钱能过户才有 Shapley 值与核的标准理论；匹配市场恰是 TU 失效的地方——所以它需要 Gale-Shapley 的另一套语法，两章半一章。
2. **2ⁿ 的账单**：Shapley 值对 n 个玩家要扫 2ⁿ 个联盟（n = 30 已是十亿量级）——精确计算在一般博弈里不可行（计数类 #P 难，置信度：中高），实务走采样近似或结构化捷径（TreeSHAP）；这与 [50 章](./50-批判收尾.md)第二堵墙同族：**定义优雅 ≠ 计算便宜**。
3. **两套公平可以互不相干**：投票博弈 Shapley 值完在、核空；核里的分配可以千千万万、没有一个是 Shapley 公平——"公平"与"稳定"是两个公理体系，不是一枚硬币。
4. **核空不等于无解**：它只说"无阻稳定"这把尺子量不出点；权力指数、最小核等替代解概念各有拥趸——解概念的选择本身是建模判断，[50 章](./50-批判收尾.md)的谦逊在此同样生效。
5. **稳定匹配不是万能药**：受方可操纵（练习③）、市场设计的自由度受现实约束（Roth 反复强调"市场的厚度、拥塞、安全性与简单性"缺一不可）；[14 章](./14-机制设计与显示原理.md)的显示原理告诉你什么规则能独善其身，代价是——只有一个方向的说真话。
