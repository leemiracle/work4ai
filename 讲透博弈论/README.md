# 讲透博弈论：策略的科学与工程（五卷 · 20 篇）

> **博弈论的终极定义**（本系列宪法第一句）：在**利益交织（结构）、信息不对称（信息）、理性层次（认知）和重复互动（时间）**的约束下，研究策略性决策如何达成、如何演化的学问。最凝练的一个词：**策略互动（Strategic Interaction）**——纳什均衡的相互最优、机制设计的激励相容、演化的稳定策略、AI 自博弈的收敛，全是它的方言。
>
> **五卷结构**：卷一（静态与均衡：均衡概念的诞生）→ 卷二（动态与信息：序贯、承诺与信号）→ 卷三（重复、演化与合作：时间与物种改写一切）→ 卷四（机制设计：反向博弈论）→ 卷五（学习与 AI：当博弈遇上机器）。**边界**：在线学习的遗憾分析（OGD/FTRL/Hedge）全谱在 [`讲透优化 25`](../讲透优化/25-在线优化.md)，本系列 15 章造 no-regret 之桥；LP 对偶全谱在 [`讲透优化 09`](../讲透优化/09-线性规划.md)，本系列 04 章造 minimax 之桥。
