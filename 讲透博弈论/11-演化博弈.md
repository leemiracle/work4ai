# 11 · 演化博弈：策略的物种化

> 卷三第二章：换掉博弈论的引擎——**理性退场，选择进场**。策略不再被玩家计算，而是像物种一样被复制与淘汰；收益不再是效用，而是**适应度**。[00 章](./00-开场.md)理性五档表拧到最后一档（零理性，只有选择压力），[02 章](./02-纯策略纳什均衡.md)"NE 的进化读法"从一行字长成一套方程。本章立起演化博弈的三大件：**复制动态** ẋᵢ = xᵢ(fᵢ − f̄)（鹰鸽 x\* = v/c = 0.5 的完整手推——02 章的预告在此兑付）、**ESS 两条件**（入侵者严格劣势 / 持平则同伴对抗占优——NE 的精炼，[50 章](./50-批判收尾.md)补丁表的一站）、**RPS 无 ESS**（特征值 ±i√3/3 纯虚 → 闭轨——行为转圈、平均站稳，直通 [15 章](./15-博弈学习经典.md) ◆ 与 [17 章](./17-自博弈与多智能体RL.md) ◆）；外加有限种群的 Moran 过程与 AI 连接：**数据生态 = 策略生态**。

---

**1973 年，《自然》**。Maynard Smith 与 Price 发表 *The Logic of Animal Conflict*：两只动物为领地相争，既不会算期望效用，也不会子博弈完美——问"理性人怎么选"是问错了题，该问的是**哪种打法在被大批复制之后还能顶住新打法的入侵**。他们给这种稳健起名**演化稳定策略（ESS）**，并在 1982 年的专著里给它配上了一台发动机——**复制动态**（Taylor-Jonker 1978 把它写成方程）。经济学这边，同一台发动机改个名字就是学习理论：均衡不再是谁算出来的，而是被淘汰剩下的。本章立场一句话：**均衡的最不依赖理性的读法——没有人算均衡，种群比例自己停在那里。**

## 一、换引擎：理性退场，选择进场

[00 章](./00-开场.md) §三的理性五档表在此拧到底：| 无限级+公共知识 → NE（02-09 章）| 有限 k 级 → level-k | 有限 λ → QRE | **零理性 → ESS/复制动态（本章）** | 只谈学习 → no-regret（15 章）|。引擎替换的三个动作：

| | 传统读法（02-10 章） | 演化读法（本章） |
|---|---|---|
| 策略 | 玩家的选择 | 物种/表型（自带复制） |
| 收益 | vNM 效用 | 适应度（期望后代数） |
| "均衡" | 相互最优反应 | 频率的不动点（跑偏者被淘汰） |
| 理性 | 逐级假设 | **完全不需要** |

[03 章](./03-混合策略.md)给过混合策略的四种解释（随机/种群/信念/频率）——本章把"**种群**"那一行写成微分方程：xᵢ 是策略 i 的频率，随机配对的个体按矩阵收益繁衍。主角沿用 [00 章鹰鸽记号](./00-开场.md)（v=2, c=4，一分不改）：鹰打斗独占或两败，鸽退让分食或避战——没人算过均衡，但鸽群和鹰群的比例会自己停住。

## 二、复制动态：适应度差就是斜率

设策略 i 当下频率 xᵢ、期望适应度 fᵢ(x)（对手按种群比例随机抽）。三条最小假设——无性繁殖（后代继承策略）、随机配对（对手分布 = 当前频率）、复制率正比于适应度——一行推出**复制动态**（replicator equation）：

$$\dot{x}_i = x_i\big(f_i(x) - \bar{f}(x)\big), \qquad \bar{f} = \sum_j x_j f_j$$

推导只有一步：下一代频率 = 本代频率 × 相对繁殖率，xᵢ'(t+Δ) ∝ xᵢ(1 + Δ·fᵢ)，取极限即得。三个性质白送：**频率守恒**（Σẋᵢ = f̄ − f̄ = 0）；**平均是水位线**（fᵢ > f̄ 才涨——低于平均的策略被稀释，种群整体适应度单调爬升，Fisher 基本定理的离散影子）；**对称混合均衡 = 静止点**（fᵢ = f̄ ⟺ 无差异原理，[03 章](./03-混合策略.md)的选择动机被复制动机平替）。02 章"NE 三层含义"表的第三行——**进化：均衡是选择压力的驻点**——从此有方程可查。

## 三、鹰鸽手推：x\* = v/c = 0.5 的稳态

鹰鸽收益（00 章原样）：鹰对鹰 (v−c)/2 = −1、鹰对鸽 v = 2、鸽对鹰 0、鸽对鸽 v/2 = 1。设鹰频率 x，两种策略的适应度：

$$f_H = x\cdot\tfrac{v-c}{2} + (1-x)v = 2 - 3x, \qquad f_D = (1-x)\cdot\tfrac{v}{2} = 1 - x$$

鹰太多 → 鹰见面全是大打出手（f_H 随 x 下坠），鹰稀少 → 鹰专割软柿（f_H 高）——**负反馈自带**。令 f_H = f_D：2 − 3x = 1 − x → **x\* = 1/2 = v/c**（一般式：x(v−c)/2 + (1−x)v = (1−x)v/2 解出 x\* = v/c，需要 c > v 才有内点）。代入复制动态的恒等式 ẋ = x(f_H − f̄) = x(1−x)(f_H − f_D)：

$$\dot{x} = x(1-x)(1-2x), \qquad g'(x) = 1 - 6x + 6x^2$$

三个不动点逐个判稳（1D 流：g' > 0 推离、g' < 0 吸回）：g'(0) = 1 > 0 全鸽不稳（鹰一来就割）、g'(1) = 1 > 0 全鹰不稳（鸽一来就省下打斗成本）、**g'(1/2) = −1/2 < 0 渐近稳定**。从 0.1、0.5、0.9 出发的三条轨线全部停进 0.5——lab05 E3 实测（dt=0.05 欧拉）：

```
理论锚点（11 章 §三手推）：ẋ = x(1−x)(1−2x)，x* = v/c = 2/4 = 0.5（渐近稳定，g'(1/2)=−0.5）
  x₀ = 0.1 → 终值 0.499998（vs x*=v/c=0.5，|偏差| = 0.000002）✓
  x₀ = 0.5 → 终值 0.500000（vs x*=v/c=0.5，|偏差| = 0.000000）✓
  x₀ = 0.9 → 终值 0.500002（vs x*=v/c=0.5，|偏差| = 0.000002）✓
→ E3a 对拍：三轨收敛 x*=0.5（容差 0.01）—— 全绿 ✓
```

[00 章](./00-开场.md)"没有人算均衡，种群比例自己收敛到 x\*=0.5"与 [02 章](./02-纯策略纳什均衡.md)"11 章它将一跃成为主角"两句预告在此同时兑付。顺带看穿这个数的身份：02/03 章把它算成**对称混合 NE**，这里它换了个出生证明——**同一件事，一个是选择的不动点，一个是复制的不动点**。

## 四、ESS：入侵者视角的两条件

渐近稳定回答"扰动后回不回来"，没回答"变异体持续渗入扛不扛得住"。**演化稳定策略（ESS）**把问题换成入侵者视角：s\* 是 ESS ⟺ 对一切变异 s ≠ s\*：

| 条件 | 内容 | 一句话 |
|---|---|---|
| ① | u(s\*, s\*) > u(s, s\*) | 入侵者在 s\* 群里**严格**更差 |
| ② | u(s\*, s\*) = u(s, s\*) **且** u(s\*, s) > u(s, s) | 打平时，**同伴对抗入侵者**占优——变异体在自家堆里也混不出头 |

鹰鸽全查一遍（这是本章最重要的手推）：纯鹰非 ESS——u(H,H) = −1 < u(D,H) = 0，鸽是鹰群里的搭便车者；纯鸽非 ESS——u(D,D) = 1 < u(H,D) = 2，鸽群是鹰的粮仓。**混合 x\* = 0.5 是 ESS**：x\* 是 NE，两类适应度持平——u(H, x\*) = ½·u(H,H) + ½·u(H,D) = ½(−1) + ½(2) = 0.5 = u(x\*, x\*)，条件①的严格不等式不存在，落进条件②——u(x\*, H) = ½·u(H,H) + ½·u(D,H) = ½(−1) + ½(0) = −0.5 > u(H,H) = −1 ✓，u(x\*, D) = ½·u(H,D) + ½·u(D,D) = ½(2) + ½(1) = 1.5 > u(D,D) = 1 ✓。**条件②正是鹰鸽需要的**：单看相遇收益谁也压不倒谁，但变异体混进 x\* 种群后，遇到的大多还是原策略——同伴的"群众基础"替原策略守门。

与 NE 的关系一条链：**ESS ⊂ 对称 NE**（条件①②合起来恰是"无人敢偏离 + 连持平偏离也吃亏"）；反过来 NE 不必 ESS（下一节 RPS 当场反例）；严格 NE ⇒ ESS；ESS ⇒ 复制动态渐近稳定（Hofbauer-Schuster-Sigmund；置信度：高），反向不成立。[50 章](./50-批判收尾.md)补丁表的一站在此入列：ESS 修复"漂移与变异入侵"，代价是"只讲稳定、不讲规范"——它是个生物学的稳健概念，不承诺任何福利含义（全鹰在 c < v 时也是 ESS，见 ✍️ 练习①）。

## 五、RPS：没有 ESS 的世界——闭轨与时间平均

石头-剪刀-布（行收益矩阵，序 R,P,S）：

$$A = \begin{pmatrix} 0 & -1 & 1 \\ 1 & 0 & -1 \\ -1 & 1 & 0 \end{pmatrix}$$

A 反对称 → xᵀAx ≡ 0 → 种群平均适应度恒 0（有人赢必有人输，零和——[04 章](./04-零和与minimax.md)的价值观）。中心 p = (1/3,1/3,1/3) 处：Ap = 0（每行和为 0）→ 不动点；雅可比 J = ∂ẋᵢ/∂xⱼ = diag(Ax) + diag(x)A 在 p 处化为 **J(p) = A/3**，而 A 的特征多项式 λ³ + 3λ = 0 给 λ ∈ {0, ±i√3} → **J(p) 的谱 = {0, ±i√3/3} = {0, ±0.5774i}**——纯虚，线性化是中心不是焦点。这一手还有个守恒量作证：d/dt·ln(x₁x₂x₃) = Σᵢ(Ax)ᵢ = 0（A 的**列**和也为 0）→ H = x₁x₂x₃ 沿轨线严格守恒——**轨线锁死在 H 的水平集上，绕中心转圈，永不到达**。无 ESS 三连验尸：纯策略彼此相克（u(P,R) = 1 > u(R,R) = 0）；混合 p 上任何变异都拿 0（Ap = 0），条件①永不够严格；条件②也死——u(p, e_R) = 0 = u(e_R, e_R)。**精炼的剪刀在这里找不到落点**（[09 章](./09-信号传递与精炼.md)的教训换了个舞台）。lab05 E3 实测（数值雅可比 + 欧拉相图）：

```
理论锚点（11 章 §五手推）：内点 (1/3,1/3,1/3) 处雅可比特征值理论 = 0, ±i√3/3 ≈ ±0.5774i（纯虚 → 中心 → 闭轨 → 无 ESS）
  数值特征值 0.0000+0.0000j（vs 理论 +0.0000，|Re|=0.00000、|Im|=0.00000） ✓
  数值特征值 0.0000-0.5774j（vs 理论 -0.0000-0.5774j，|Re|=0.00000、|Im|=0.57735） ✓
  数值特征值 0.0000+0.5774j（vs 理论 +0.0000+0.5774j，|Re|=0.00000、|Im|=0.57735） ✓
  轨线1 终值 (0.172, 0.513, 0.315)——远离中心（行为频率不收敛）；时间平均 (0.334, 0.344, 0.323) vs 1/3（|偏差| 0.011，容差 0.02）
→ E3b 对拍：特征值纯虚 ±0.5774i ✓；E3c 时间平均 → 中心（'行为不收敛、平均趋向均衡'，50 章第三堵墙）—— 全绿 ✓
  诚实标注：零和 RPS 的理论图像是闭轨族（中心），欧拉离散化会让轨线缓慢内外漂移（数值伪影，非理论）——
  步长已压细并加单纯形护栏；'孤立极限环'要 a≠1 的广义 RPS（Hofbauer-Sigmund），此处演示的是中心型。
```

读数两行：**行为频率不收敛**（终值 (0.172, 0.513, 0.315) 在单纯形边缘打转——石头多了被布针对，改出剪刀，又被石头针对……），**时间平均收敛**（(0.334, 0.344, 0.323) → 1/3）——[50 章](./50-批判收尾.md)第三堵墙"手在转圈、平均站稳"的几何图像在此兑现，而它正是 [15 章](./15-博弈学习经典.md) ◆"no-regret ⇒ 经验分布收敛到 CCE（平均意义）"的先声；[17 章](./17-自博弈与多智能体RL.md) ◆ 的非传递性泥潭（self-play 绕圈、向新手投降）是同一张图在 AI 训练里的重演。

## 六、有限种群：漂变与 Moran 过程

无限种群是理想化——真实种群 N 有限，**漂变（drift）**上场：纯粹随机的出生死亡就能让频率乱走，中性条件下（人人适应度相同）策略 i 从 i 个个体**固定的概率恰 = i/N**（对称性；Kimura 中性理论的地基）。选择与漂变的赛跑用 **Moran 过程**演：每步按适应度比例选一个"生者"复制、均匀选一个"死者"让位——有限版的复制动态。

lab05 E2 让 TFT 入侵 ALLD 的种群（N=10，BD 模式，30 seeds/档），先手推单挑与种群两本账（turns=200）：

```
单挑手推 vs Match 实测：TFT 0.9950 分/轮（手推 199/200=0.995）、ALLD 1.0200（手推 204/200=1.02）——单挑 TFT 输
适应度交叉阈值（手推）：x* 满足 0.995+2.005x = 1+0.02x → x = 0.00252（0.25%）——i=1/10=10% 已过线 → 选择顺风
 i/10 | 实测固定概率 |   ±2se | 中性基线 i/N | 判读
1/ 10 |      0.233 |    0.154 |        0.1 | ✓（2se 不显著——30 seeds 精度如实标注）
2/ 10 |      0.467 |    0.182 |        0.2 | ✓（2se 显著）
4/ 10 |      0.867 |    0.124 |        0.4 | ✓（2se 显著）
6/ 10 |      1.000 |    0.000 |        0.6 | ✓（2se 显著）
8/ 10 |      1.000 |    0.000 |        0.8 | ✓（2se 显著）
→ E2 对拍：各档实测固定概率压中性基线 i/N（单挑输≠群体输，合作红利随比例放大）—— 方向 全对 ✓；2se 显著 4/5 档
```

读法：单挑里 TFT 是输家（0.995 < 1.02，ALLD 每轮多贪 0.025），但**种群是频率混合体**——TFT 遇同类拿 R=3/轮，适应度 f_TFT(x) = 0.995 + 2.005x 对 f_ALLD(x) = 1 + 0.02x，只要初始比例越过 0.25% 的门槛，选择就顺风：实测固定概率全线压过中性基线 i/N（i=1 档 2se 不显著是 30 seeds 的精度账，方向与理论一致；✍️ 练习④）。**单挑输 ≠ 群体输**——这是 10 章"锦标赛测人口结构"的种群遗传学版本，也是合作的演化经济学最难的一课：TFT 的优势从来不是打败 ALLD，而是**在 TFT 之间互相成就**。

## 七、AI 连接：数据生态 = 策略生态

把"种群"换成训练数据与模型行为，复制动态无处不在：

- **内容生态就是策略生态**：生产者的策略（原创/洗稿/标题党/AI 糊弄）按推荐算法给出的"适应度"（流量）复制——平台不是中立舞台，是**适应度函数的设计者**；改算法 = 改 ẋ 的符号结构。
- **RLHF 的策略漂移**：奖励模型是适应度函数，策略在它的表面上复制攀升——**reward hacking 是高适应度的垃圾策略入侵**（条件①的镜像：它压过诚实策略不是因为它更好，是因为奖励模型量错了）；14/18 章 ◆ 接手。
- **模型崩溃**（Shumailov et al. 2024, Nature）：用生成数据递归训练，分布的尾部逐代灭绝——低频策略被漂变吃掉的自然史，复制动态最贵的一次当代实测（置信度：高）。
- **LLM agent 的进化管线**（EvoAgent 等 2024-2025 一批工作；置信度：中）：生成—筛选—繁殖接上语言模型，self-play 的演化版——[17 章](./17-自博弈与多智能体RL.md) ◆ 的 PSRO 策略人口正是它的理论骨架。

诚实标注：以上是**结构性类比**，不是已证定理——LLM 生态的"复制"经由人类模仿与训练管线发生，速率与保真度都是实证问题（[18 章](./18-博弈论与LLM对齐.md) ◆ 的诚实框收口）。

## 八、不足与边界

1. **确定性复制动态 = 无限种群近似**：N 小、变异稀时漂变主导（Moran 才是正主）；且无变异时一切频率组合皆吸收态——ESS 的"抗入侵"是局部概念，长期看有限种群没有永远的赢家。
2. **ESS 与动态的互洽有单行道**：ESS ⇒ 渐近稳定，但渐稳 ⇏ ESS（3×3 反例见 Hofbauer-Sigmund）——静态标准与动态标准是两把尺子。
3. **RPS 的闭轨是零和的特产**：守恒量 H = x₁x₂x₃ 依赖 A 反对称；一般和博弈的复制动态可以收敛、循环、**发散**（Bailey-Piliouras 2018——[50 章](./50-批判收尾.md)第三堵墙的第三盆冷水）。
4. **适应度 ≠ 效用**：收益尺度是繁殖率，没有 vNM 公理也没有可转移效用——跨博弈、跨物种的比较在本框架内无意义。
5. **AI 类比的证据等级**：模型崩溃有 Nature 级实证，"RLHF 策略漂移 = 复制动态"目前是隐喻——方程要成立，得先回答"谁在复制谁、以什么速率"。
