# 01 · 理性基石与占优：不需要猜对手的推理

> 占优是博弈论里唯一**不需要猜对手**的推理：无论别人怎么选，我都有更好的选项。本章把"理性"两次奠基——先给收益找到 vNM 期望效用的地基，再给解概念装上 IESDS 重复剔除的引擎；然后用 0-100 猜数游戏把这套引擎推到"公共知识"的塔顶，也在塔顶看到裂缝：**真实人群只有 1~2 层深**。章尾在猜拳面前交出占优的失效证明——那里需要全新的概念（02 章的纳什均衡）。

---

**1995 年，Rosemarie Nagel 把一个游戏带进了课堂**：100 人各报一个 [0,100] 的数，最接近"所有人平均数 × 0.7"的人获胜。若人人无限理性，唯一的稳态是**全员报 0**——本章将用重复剔除严格证明它。但 Nagel 的实测胜出数落在 25~35 之间，对应的不是无限理性，而是"比人群平均深 1~2 层"的玩家。这一个游戏同时装下了本章的全部主题：**收益怎么定义**（期望效用）、**不猜对手能推多远**（占优与 IESDS）、**"我知道你知道"能叠多高**（公共知识与共同知识）、以及**塔楼与人间的落差**（理性层级——它将贯穿全系列，直到 [50 章批判收尾](./50-批判收尾.md)的第一堵墙）。

---

## 一、收益从哪里来：偏好公理与 vNM 期望效用

[00 章五要素](./00-开场.md)把**收益 uᵢ**列为博弈的解剖刀之一，但一直没问：收益是什么？凭什么"赚 5"可以被写成数字、还能乘概率？这一节就是收益要素的奠基工程。

优化（[讲透优化 01](../讲透优化/01-统一框架.md)）处理**没有对手的决策**：目标函数 f(x) 是自然律。博弈的第一步跨越是**对手站在你的目标函数里**：u₁(s₁, s₂)——我的满足是**你的**选择的函数。而在给"满足"编数字之前，先得给"偏好"立规矩。

### 1.1 偏好公理（对"抽奖"的偏好规则）

玩家面对的往往不是确定结果而是**抽奖**（lottery：以概率 p 得结果 A、1−p 得结果 B）。vNM 理论对"玩家在抽奖之间的偏好关系 ≻"提出四条公理：

| 公理 | 内容 | 一句话体检 |
|---|---|---|
| **完备性** | 任意两个抽奖都可比较：p ≻ q、q ≻ p 或无差异，三者必居其一 | 没有比不出的选项 |
| **传递性** | p ≻ q 且 q ≻ r ⇒ p ≻ r | 偏好不成环（钱泵定理：成环者会被套空钱包） |
| **连续性** | 若 p ≻ q ≻ r，则存在 θ∈(0,1) 使"θ 的 p 混 (1−θ) 的 r"与 q 无差异 | 没有"无论多小概率都压倒一切"的词典式偏好 |
| **独立性** | p ≻ q ⇒ 对任何 r、任何 θ：θ·p+(1−θ)·r ≻ θ·q+(1−θ)·r | 混入同一杯"第三选项"不翻转偏好——**四条中最强、也最常被现实违反的一条** |

前三条让偏好"像个排序"，第四条**独立性**才是期望效用形式的发动机（它禁止"对概率本身感到恐惧或贪婪"）。Allais 悖论（确定拿 100 万 vs 10% 拿 500 万……多数人翻转选择）正是对独立性的实验否决——这条裂缝在 50 章 QRE 与行为博弈的语境里重新计价。

### 1.2 vNM 期望效用定理（陈述）

**定理（von Neumann-Morgenstern 1944）**：偏好 ≻ 满足上述公理，**当且仅当**存在一个效用函数 u（定义在确定结果上），使得

$$p \succ q \iff \sum_k p_k\, u(a_k) > \sum_k q_k\, u(a_k)$$

即：**对抽奖的偏好 = 对期望效用的偏好**。且 u 在**正仿射变换**下唯一（u ↦ αu+β，α>0，偏好序不变）。

仿射唯一性不是技术脚注，它是全系列的用法说明：**收益加常数、乘正常数不改变任何博弈论结论**——所以 00 章的 T5 R3 P1 S0 与 T50 R30 P10 S0 是同一个博弈；也所以跨玩家比较收益（"A 的 3 比 B 的 5 重要"）在 vNM 框架内**没有意义**，那是 12 章合作博弈（Shapley）要另起炉灶的公平语言。

### 1.3 效用 ≠ 钱（边界的第一次亮相）

| 现象 | 与"收益=钱"的偏差 | 本系列落点 |
|---|---|---|
| 风险态度 | 确定拿 900 vs 50% 拿 2000：凹效用选前者 | 13 章拍卖的风险厌恶修正 |
| 公平偏好 | 最后通牒拒绝正出价：损己不利人 | 06 章 Fehr-Schmidt 不公平厌恶 |
| 概率加权 | Allais 翻转、彩票+保险并存 | 50 章 QRE（理性装旋钮） |

建模四事故（[00 章](./00-开场.md)）第三条"收益拍脑袋"的解药就在这里：先把偏好转成 vNM 效用，再谈均衡。**效用是量好偏好之后的记账单位，不是钱的别名。**

## 二、占优：不需要猜对手的推理

有了收益，解概念登场。博弈论的解概念按"需要猜对手多少"排成一条阶梯，占优站在**不猜**的那一端。

| 概念 | 定义（s、s′ 为我的两个策略，t 遍历对手全部策略组合） | 直觉 |
|---|---|---|
| **严格占优** | uᵢ(s, t) > uᵢ(s′, t) 对**所有** t 成立 | 无论对手怎么办，s 都严格更好 |
| **弱占优** | uᵢ(s, t) ≥ uᵢ(s′, t) 对所有 t，且对**某个** t 严格 | s 永远不差、偶尔更好 |
| **占优均衡** | 每个玩家的策略都严格占优自己的其余策略 | 解概念阶梯的顶点：零猜测、零争议 |

### 2.1 囚徒困境：占优逻辑的绞肉机（三原型 #1）

用 [00 章统一记号](./00-开场.md) T=5 > R=3 > P=1 > S=0（2R > T+S）逐项核对背叛 D 对合作 C 的占优：

| 对手的选择 | 我合作 C 得 | 我背叛 D 得 | 背叛占优？ |
|---|---|---|---|
| 对手合作 C | R = 3 | T = 5 | ✓ 严格 |
| 对手背叛 D | S = 0 | P = 1 | ✓ 严格 |

背叛**严格占优**合作——不需要猜对手、不需要理性层级、不需要公共知识，一步推出唯一占优均衡 (D,D)。占优均衡是博弈论里**唯一"零假设论证"的解**：它的预测坚实到 50 章批判四墙时仍然被保留为"排除法的硬预测"（(C,C) 不会发生）。但 (1,1) < (3,3)：**个体理性碾碎集体理性**——这句判决的赎金在 10 章：δ（未来折扣）够大时，同一个矩阵里能长出合作。

### 2.2 严格占优剔除：安全定理

单个玩家可能没有占优策略，但可以**分轮清理**：删掉某玩家的严格被占优策略，在缩小的博弈里再找、再删。这条路完全安全：

**命题（安全剔除）**：严格被占优（哪怕被**混合**策略占优）的策略，在任何纳什均衡中都以概率 0 被使用。因此：
1. 重复剔除严格占优策略（**IESDS**，Iterated Elimination of Strictly Dominated Strategies）**绝不删除任何均衡**；
2. 若 IESDS 收敛到唯一策略组合，它就是**唯一**的纳什均衡；
3. 有限博弈的 IESDS 必在有限步终止，且**残余集合与剔除顺序无关**（严格情形的干净定理——弱占优没有这个福气，见下一小节）。

第 1 条的证明主脉一句话：若 σᵢ* 以正概率使用严格被占优的 s′，改用其占优者是对对手策略组合的严格改进——与均衡定义"无人想单方偏离"矛盾。完整的均衡定义在 02 章，但**结论不依赖循环论证**：该命题在给定任何合理解概念时都成立。

**混合占优同样安全，也最容易漏检**。占优者不必是某个纯策略，可以是一个**混合**：行玩家的 T = (1, 1) 没有被 M = (3, 0) 单独占优（第二列 0 < 1），也没被 B = (0, 3) 单独占优（第一列 0 < 1），却被"半 M 半 B"占优——0.5·M + 0.5·B = (1.5, 1.5) > (1, 1) 处处严格。安全剔除定理对此一视同仁：被（纯或混合）策略严格占优者在任何均衡中概率为零。**手算 IESDS 时只查纯策略占优，是这类题最常见的失分点。**

### 2.3 弱占优剔除的陷阱：会删掉真均衡

把"严格"放宽成"弱"，安全垫就没了。看这个 2×2（行玩家 U/D，列玩家 L/R，单元 = 行收益, 列收益）：

| | L | R |
|---|---|---|
| **U** | (0, 1) | (1, 1) |
| **D** | (1, 2) | (0, 0) |

- 列玩家视角：L 对 U 无差异（1=1）、对 D 严格更好（2>0）→ **L 弱占优 R**。剔除 R。
- 残局只剩 L：行玩家选 D（1>0）。剔除 U。收敛到 (D, L)。
- **陷阱**：回看原博弈，(U, R) 也是纳什均衡——行玩家在 R 下选 U 最优（1>0），列玩家在 U 下 L 与 R 无差异（1=1），谁都不想单方偏离。**弱占优剔除把一个货真价实的均衡删掉了。**

对比实验（`experiments/lab01_dominance.py` 的 E3 实测打印）：

```
同一博弈 · 严格占优剔除 IESDS：
  残余组合：[('行0', '列0'), ('行0', '列1'), ('行1', '列0'), ('行1', '列1')]，收益 [(0,1), (1,1), (1,2), (0,0)]
  → 严格 IESDS 一步未剔（R 不被严格占优：对 U 无差异）→ 两个 NE (U,R)/(D,L) 全部保留 ✓

同一博弈 · 弱占优剔除 IESWDS：
  第1步：列玩家 列1 被 列0 弱占优 → 剔除 列1
  第2步：行玩家 行0 被 行1 弱占优 → 剔除 行0
  → ⚠ 陷阱兑现：弱占优剔除序列 R→U 收敛到 (D,L)，但 (U,R) 本是原博弈的真 NE（E2 已验证）
```

三条纪律由此而来：**严格占优剔除是推理（结论可信），弱占优剔除是整理（参考点删除）**；弱占优剔除的结果**依赖剔除顺序**；凡用弱占优做论证（06 章信号传递的精炼、08 章的均衡筛选），必须声明"可能有均衡被剔除"。

## 三、IESDS 与猜数游戏：把 0-100 剔到 0

### 3.1 重复剔除 = "我知道你知道"的层层展开

IESDS 的每一轮剔除，消耗的不是一个理性，而是**一层相互知识**：

- 第 1 轮（我是理性的）：我不会选严格被占优的策略；
- 第 2 轮（我知道你是理性的）：我可以在"你不会选被占优策略"的前提下再清理；
- 第 3 轮（我知道你知道我是理性的）……

有限博弈里这趟电梯在有限步内到达底层（共同知识塔的有限层），残余集合就是 IESDS 的预测。**预测强弱取决于残余大小**：残余唯一 → 点预测；残余多格 → 集合预测（"什么不会发生"依然坚实——50 章的立场从这里发芽）。

### 3.2 猜数 ×0.7：一条剔到 0 的无限塔

0-100 猜数（[00 章定义](./00-开场.md)：目标 = 平均数 × 0.7，最近者胜）是 IESDS 的完美展台：

| 轮次 | 论证 | 剔除 |
|---|---|---|
| 1 | 平均数 ≤ 100，目标 ≤ 70；报 x>70 时 70 永远严格更近 | (70, 100] 全部出局 |
| 2 | 人人知道平均 ≤ 70 ⇒ 目标 ≤ 49 | (49, 70] 出局 |
| 3 | 目标 ≤ 34.3 | (34.3, 49] 出局 |
| … | 上界 ×0.7 连乘 | 49 → 34.3 → 24.01 → 16.81 → … |
| ∞ | 几何收敛 | **唯一存活：0** |

`lab01` 的 E3 另有一个 3×3 演示矩阵（行 U/M/D × 列 L/C/R），四步严格剔除（U→D→C→R）收敛到唯一格 (M, L) = (3, 1)，nashpy 复核全博弈**唯一** NE 恰是 (M, L)——"严格剔除绝不删均衡"与"残余唯一即唯一均衡"在同一块矩阵上双双兑现。

两个诚实的注脚：**连续版**的剔除永远差最后一口气（0.7¹³ ≈ 0.0097，第 13 轮后上界已小于 1，"0"作为唯一存活点是无限轮的极限——这正是"无限塔"的字面含义）；**整数版**则在有限步（约 13 轮）正式终止于 0。

### 3.3 lab01 实测：塔楼与人间的落差

`experiments/lab01_dominance.py` 的 E1 用 100 个 k-level 代理（level-0 均匀乱报；level-k = 0.7 × level-(k−1) 的均值；层级分布截断于 k=6，多数人压在 level-1~2——Nagel/Camerer 的实测形态）模拟了这个游戏（种子 42）：

```
k 链（level-k 的报告）: 50 → 35 → 24.5 → 17.15 → 12.005 → 8.4035 → 5.88245 → … → 0（唯一均衡）
IESDS 上界链: 100 → 70.00 → 49.00 → 34.30 → 24.01 → 16.81 → … → 0（×0.7^13 后已 <1）
模拟：全员平均报告 = 32.82，获胜目标 = 0.7×平均 = 22.97
胜者：level-2 代理，报告 23.69
理论对照：公共知识理性 → 唯一均衡 0（无人报告）；Nagel 1995 实测胜出数落在 level-1~2（≈25~35）
诚实标注：本模拟是 k-level 模型，胜者 level-2 是模型性质；它与实测叙事一致——均衡 0 不是赢家
```

**均衡是 0 ≠ 赢家报 0**。按均衡玩游戏的人颗粒无收——人群的理性深度实测只有 1~2 层，k-level 思维的正确用法是**校准层级差**（比对手深一层就赢，深三层输给"愚蠢但稳定"的 level-0，[00 章](./00-开场.md)理性五档旋钮表）。这条裂缝将在 50 章扩展成对均衡概念的第一堵墙。

## 四、蓝眼睛岛：公共知识 ≠ 共同知识

IESDS 的高塔消耗的是什么？蓝眼睛岛谜题给出最干净的一次透视。

**谜题**：岛上有 5 个村民，人人都有蓝眼睛。规矩残酷而明确：**谁推断出自己的眼睛颜色，谁当夜必须离岛**。没有镜子、没有湖水、彼此诚实但绝口不谈眼色——于是人人都能看见 4 双蓝眼睛，却对自己一无所知。一天，一位外来游客当众说了一句看似废话的话："**岛上至少有一人是蓝眼睛。**"结果：第 5 夜，5 个蓝眼睛同时离岛。

**悖论**："至少有一人是蓝眼"人尽皆知——游客说了句废话？**不**。公告之前，"岛上有蓝眼"是**公共知识**（mutual knowledge：人人皆知），但**不是共同知识**（common knowledge）：A 不确定 B 是否知道（若 A 假设自己是唯一的非蓝眼……不对，若 A 恰好推想"可能我是岛上唯一的红眼，那么其余 4 人在彼此眼中……"递归 5 层后悬空）。公告把**认知层级的塔尖**焊死了：从此"人人知道人人知道……（5 层）有蓝眼"成立，归纳引擎点火：

| 夜数 | 若岛上只有 k 个蓝眼 | 蓝眼者的推理 |
|---|---|---|
| 1 | k=1：他看见 0 个蓝眼 | "公告说的蓝眼是我" → 当夜离岛 |
| 2 | k=2：各自看见 1 个 | "若我不是蓝眼，那 1 个第 1 夜就会走" → 没走 ⇒ 我是 → 第 2 夜双双离岛 |
| … | … | … |
| 5 | k=5：各自看见 4 个 | "前 4 夜无人离岛 ⇒ 蓝眼 ≥ 5 ⇒ 包含我" → 第 5 夜全体离岛 |

**本系列术语公约**（沿用 [README](./README.md) 锚点；文献中译名常有出入，以本表为准）：

| 术语 | 英文 | 层级 | 猜数 IESDS 里的角色 |
|---|---|---|---|
| **公共知识** | mutual knowledge | 人人皆知（1 层） | 第 1 轮剔除够用 |
| **共同知识** | common knowledge | 人人知道人人知道……到无穷（Aumann 1976 正式化） | 每多剔一轮，塔就多一层；"唯一存活 0"需要整座塔 |

公告没传递任何**事实**，传递的是**关于知识的知识**——这正是"公共知识 ≠ 共同知识"的全部含义，也是 IESDS 与蓝眼睛岛共用同一座塔的原因。现实里塔只有 1~2 层：50 章将对这座塔做正式清算。

### 4.1 本章概念的自带说明书（不足与边界清单）

| 概念 | 何时失效 | 后果 | 去处 |
|---|---|---|---|
| vNM 期望效用 | 独立性被违反（Allais 型选择） | 期望效用只是偏好的近似 | 50 章 QRE |
| 严格占优/IESDS | 无占优可剔（猜拳、性别战争、鹰鸽） | 推理引擎熄火，零预测力 | 02 章 NE 接棒 |
| 弱占优剔除 | 可删真均衡、结果随剔除顺序变 | 只可作参考点删除，不可作预言 | §2.3 陷阱实验 |
| 公共知识塔 | 人群理性深度实测 1~2 层 | "均衡 0"与胜者相距一个层级差 | 50 章第一堵墙 |

## 五、占优的失效边界：为什么需要均衡概念

把本章的解概念按"猜测需求"排成阶梯，立刻看到占优的疆界：

| 博弈 | IESDS 残余 | 本章能解吗 |
|---|---|---|
| 囚徒困境（T5 R3 P1 S0） | 唯一格 (D,D) | ✓ 占优均衡（免检通道） |
| 3.3 式猜数（连续/整数版） | 唯一点 0 | ✓ IESDS 极限 |
| 性别战争 | 4 格全保留 | ✗ 残余太肥 → 02 章 |
| 鹰鸽（v=2, c=4） | 4 格全保留 | ✗ → 02 章 |
| **猜拳 RPS** | **9 格全保留** | ✗✗ **一步都剔不动** |

猜拳值得多看一眼：石头、布、剪刀**三者互不占优**——不纯占优，连被某个**混合**策略占优都没有。证明是构造性的：对手出 (石 0, 布 0.2, 剪 0.8) 时，石头是唯一最优反应（+0.6）；同理每个纯策略都能在某个对手混合下"独自登顶"，而能登顶的策略不可能被占优。三策略互相救场，IESDS 原地踏步。

可猜拳**显然有解**：人人三分之一的随机——任何可预测的模式都会被对手剥削。占优推理对此哑口无言，因为它只知道"不猜对手"，而猜拳的解恰恰**建立在对手的读你与你的反读之上**。一句话分界：

> **占优是"不需要猜对手"的推理；均衡是"恰好猜对对手"的不动点。** 占优可解的博弈不需要均衡概念——均衡概念恰恰诞生在占优失效的地方（02 章）。

## 六、nashpy 工具箱：三行上手

[00 章工具地图](./00-开场.md)的第一件仪器，从本章开始进入每个 lab。两个人标准式博弈的完整求解：

```python
import numpy as np
import nashpy as nash

A = np.array([[0.65, 0.95], [0.95, 0.55]])   # 行玩家收益（罚点球：行=射门方向，列=扑救方向）
B = 1 - A                                     # 列玩家收益（常和博弈：得分率的另一面是扑救成功率）
g = nash.Game(A, B)                           # 建博弈：A 行玩家、B 列玩家
for s, t in g.support_enumeration():          # 支撑枚举：yield 每个均衡 (行玩家混合, 列玩家混合)
    print(s, t)                               # → [4/7, 3/7] [4/7, 3/7]（手算见 03 章，误差 1e-16）
```

三条使用纪律：`support_enumeration()` 返回**生成器**，逐个 yield (a, b) 两个概率向量；它只枚举**等支撑**的均衡，简并博弈里支撑不等的均衡会被漏报——lab01 的 E2 对每个博弈都显式打印这一诚实标注（陷阱博弈还有一个均衡连续统 (U, σ)——列玩家 L 概率 ≤ 1/2 时成立，nashpy 如实只报出两个纯均衡并附带简并警告）；nashpy 管辖**2 人标准式**，扩展式（06-09 章）交给 pygambit，重复/演化（10/11 章）交给 axelrod，深度算法（16/17 章）交给 WSL 里的 OpenSpiel。分工哲学依旧：**库给答案，手写给理解**——lab01 的 E2 对三原型 + 4 个附加 2×2 + 猜拳逐项"手算 vs nashpy"对拍，8/8 一致 ✓。
