# 08 · 不完全信息与贝叶斯均衡：Harsanyi 的救赎

> 卷二下半场：把 06 章"信息集是单点"的最后假设拆掉——**你根本不知道对手是谁**。本章先看这个缺口有多深（不完全信息下连博弈都写不出来，NE 的定义无从谈起），再看 Harsanyi 1967-68 的一步妙手：**引入"自然"这个虚拟玩家先抽类型**，把"不知道你是谁"转换成"自然抽了什么我没看见"——信息集当场裂开成多点（06 章伏笔在此兑付）。由此立起类型/信念/策略与**贝叶斯纳什均衡**（BNE：每个类型对信念最优），并用它完成本系列第一份完整的不完全信息代数解——**一级价格密封拍卖 n=2 的均衡 b(v) = v/2**（一般 n 陈述 b(v) = (n−1)/n·v）；二价拍卖的占优策略 b = v 与"四种拍卖同一收入"的一瞥，两条路直通 [13 章](./13-拍卖理论.md)。

---

**1967 年，伯克利**。Harsanyi 在《Management Science》上连发三篇（14 卷 3/5/7 期），标题直白得像求救：*"Games with Incomplete Information Played by 'Bayesian' Players"*。求救是有理由的——此前二十多年，博弈论对"我不知道你的收益"这件事**连建模都做不到**：纳什均衡的定义要先写定所有人的收益函数，而现实中你拍卖举牌前根本不知道对手的钱包。Harsanyi 的修法一步到位，1994 年他与 Nash、Selten 同台领奖（07 章已见过 Selten 那一半）。本章立场一句话：**不完全信息不是博弈的噪声，是博弈的主体；Harsanyi 的转换让我们终于能在"无知"上做严谨的数学。**

---

## 一、困境：不知道对手是谁，连博弈都写不出来

00 章"建模五要素"里最哑的一格——**信息**——在此补课。**不完全信息（incomplete information）**：玩家**不确定博弈本身的结构**，典型是不确定对手的收益函数（他多在乎钱？成本是高是低？）。对比 06 章的**不完美信息（imperfect information）**：结构人尽皆知，只是看不见对方"这一手"出了什么（多点信息集）。前者病得更深：

- **NE 无法定义**：NE 是"相互最优反应"，而最优反应依赖对手收益——收益未知，"最优"无从算起；
- **推断塌进无底洞**："他以为我以为他以为……"每一层都要引用对方的收益函数，而它正是未知的那个量。01 章蓝眼睛岛的公共知识链条在这里根本没有第一块砖。

07 章的进入威慑立刻复发：在位者喊"你敢进就打"——如果他其实成本高、打不起价格战呢？进入者面对的不是一个博弈，是"强/弱在位者"两场博弈各一份，而他不知道自己在哪一份里。

## 二、Harsanyi 转换：让"自然"先抽类型

Harsanyi 的手筋：**加一个无收益的虚拟玩家"自然"（Nature），博弈开始前由它按先验概率抽取每个人的"类型"**；类型决定收益函数；抽完只发给本人——于是"不知道你是谁"变成了"不完美信息"：结构（类型空间与先验）成为**公共知识**，未知的只是自然抽的具体实现。病重者的无底洞被浇成了地基。四个名词一次立正：

| 名词 | 定义 | 现场对应（§六例子） |
|---|---|---|
| **类型** θᵢ ∈ Θᵢ | 决定收益的全部私有信息 | 在位者 ∈ {强, 弱} |
| **先验** p(θ) | 类型分布，公共知识 | p(强) = 1/3 |
| **信念** | 到达某信息集时对"自然抽了什么"的概率判断 | 进入者：强 1/3、弱 2/3 |
| **策略** | **类型 → 动作**的完整映射（每个类型一份计划） | 在位者：(强 → 打, 弱 → 容) |

06 章的伏笔在此兑付：**信息集裂开成多点**。自然抽完类型后轮到进入者，他站在两个可能节点之一（自然走强分支后、走弱分支后），却无法分辨——两个节点装进**同一个信息集**，这一回信息集里装的不再是装饰，而是全部的"不知道"（§六用 pygambit 实建）。术语对齐：转换后博弈的结构（类型空间与先验）是公共知识，人人只是没看见骰子——06 章的"不完美信息"正式接管；完美信息恰是它的极限情形（信息集处处单点）。

## 三、贝叶斯纳什均衡：每个类型都是最优

**BNE 定义**：一个"类型 → 动作"策略组合，使得**每个玩家的每一种类型**，在给定先验信念与对手策略下，都最大化该类型的期望收益。与已立的两个均衡概念对齐：NE 审计"人"（02 章），SPE 审计"子博弈"（07 章），BNE 审计"**类型**"——偏离审计的最小单位从玩家细化到"这种类型的这个动作"。混合策略不需要新理论：随机性可以被吸收进"自然抽类型"（03 章 Harsanyi 1973 纯化定理在 06 章 §二已埋过同一根线）。

一句前瞻钉在这里：BNE 是"类型维度的 NE"，它还**不问信念从哪来、到不了的信息集上信念可以乱放**。把"到达的信息集上信念被 Bayes 钉死 + 每个信息集上序贯理性"补上，就是下一节当场上演的 **PBE 审计**；但 PBE 之后仍有缝（路径外的信念依旧自由），更细的剪刀——直觉标准——是 [09 章](./09-信号传递与精炼.md)的主角（§六的例子会让这条缝当众裂开）。

## 四、一级价格密封拍卖：BNE 的第一份完整代数解

**设定**（每个数字声明在案）：n 人竞一件单品，估值 vᵢ ~ U[0,1] 独立同分布、**私有价值**（只知道自己 vᵢ，别人的分布公共知识）、**风险中性**；同时密封出价，价高者得其估值、付自己的出价，输者付 0。对称 BNE 怎么猜？对称 + 估值越大越输得起 → 猜**线性递增** b(v) = αv。n = 2 四步推导（手推，lab04 E1 同锚）：

1. **赢率**：我的类型 v 出价 b，赢 ⟺ 对手类型 v₂ < b/α（他出 αv₂ < b）→ 赢率 = b/α（均匀分布的CDF）；
2. **期望利润**：π(b) = (v − b)·(b/α)——赢才付 b，支付与赢率之间的权衡明码标价；
3. **一阶条件**：dπ/db = (v − 2b)/α = 0 → **b\*(v) = v/2**（π 对 b 凹，二阶 −2/α < 0 ✓）；
4. **自洽**：最优反应必须等于猜的形式 v/2 = αv → **α = 1/2**。注意第 3 步根本没用到 α——"赢率正比于出价"就锁死了 b = v/2；α 只在最后被自洽性钉死。

**一般 n（陈述）**：类型 v 按 z 出价的赢率 = z^(n−1)，一阶条件给 ODE $v\,b'(v) = (n-1)\,(v - b(v))$，代入线性猜 b = αv 即解得 **b\*(v) = (n−1)/n · v**。直觉：对手越多，赢率对出价的弹性越大（多出一点价，赢率沿 z^(n−1) 抬得越快），竞争把出价推得越贴近自己的真实估值（(n−1)/n → 1）；卖方收入 E[R] = (n−1)/n · E[v_max] = (n−1)/n · n/(n+1) = **(n−1)/(n+1)**。拍卖作为机制设计的深水区——收益等价定理、最优保留价、共同价值——全部留给 [13 章](./13-拍卖理论.md)，本章只立 BNE 这块踏板。

蒙特卡洛对拍（[`experiments/lab04_bayes_auction.py`](./experiments/lab04_bayes_auction.py) E1，10⁵ 场，本机实测）：

```
理论锚点（手推，08 章 §四）：E[v_max] = n/(n+1) = 2/3 → E[赢者支付] = E[v_max/2] = 1/3；E[赢者利润] = E[v_max − v_max/2] = 1/3
  蒙特卡洛 E[赢者支付] = 0.3332（vs 1/3 = 0.3333，|偏差| = 0.0002）
  蒙特卡洛 E[赢者利润] = 0.3332（vs 1/3 = 0.3333，|偏差| = 0.0002）
  诚实标注：FPSB 里支付=自己的出价、利润=价值−支付；b(v)=v/2 时利润 = v_max − v_max/2 = v_max/2 = 支付——逐场恒等，两个 1/3 同源
→ E1 对拍：支付/利润双双 ≈ 1/3（容差 0.01）—— 全绿 ✓
```

顺带把价值结构说破：以上全部推导假设**私有价值**。若物件本身值多少钱是客观的（油田、钱包），你赢的那件事本身就是坏消息——**共同价值**与赢家诅咒在 lab04 E3 实测（naive 出价者平均亏 1/6 起），正式戏码 13 章。

## 五、二价拍卖：占优策略与"殊途同归"一瞥

**二价密封（Vickrey 1961）**：还是价高者得，但只付**第二高价**。占优策略一段话推完：出价 b > v——若对手落在 (v, b) 里你会以高于估值的价格中标，白亏；出价 b < v——若对手落在 (b, v) 里你错中以低于估值中标的机会，白丢；只有 b = v 在每个区间都无懈可击，且**与对手是谁、是否理性无关**（占优，比 BNE 还强的保证）。诚实出价不需要勇气，只需要规则——这是卷四 DSIC（说真话机制）的原型。

现在对照第四节的战利品：一价（付自己出价 b = v/2）与二价（付次高），付费规则南辕北辙，n = 2 时**期望收入却同为 1/3**：

```
E2 · 收益等价：英式/荷兰式/一价/二价 同一分布四路蒙特卡洛（10⁵ 场，本机实测）
理论值来源（手推，n=2，v~U[0,1]）：E[v_max] = 2/3 = n/(n+1)；E[次高] = 1/3 = (n−1)/(n+1)
  一价/荷兰式收入 = E[b(v_max)] = E[v_max/2] = 1/3；二价/英式收入 = E[次高] = 1/3 —— 一般 n 四路同式 E[R] = (n−1)/(n+1)
  英式（=二价实现）    平均收入 = 0.3336（vs 1/3，|偏差| = 0.0003）✓
  荷兰式（=一价实现）   平均收入 = 0.3332（vs 1/3，|偏差| = 0.0002）✓
  一价密封           平均收入 = 0.3332（vs 1/3，|偏差| = 0.0002）✓
  二价密封           平均收入 = 0.3336（vs 1/3，|偏差| = 0.0003）✓
→ E2 对拍：四路收入并排全部 ≈ (n−1)/(n+1) = 1/3（容差 0.01）—— 收益等价成立 ✓
```

英式拍卖里竞拍者互相亮牌到次高为止、荷兰式里人人捂着价——四种规则一个收入，这不是巧合是定理（收益等价，13 章）。从本章到 13 章有两条路：**设计者之路**（收入只依赖配置规则 → 最优保留价）与**机制之路**（二价拍卖的诚实占优 → VCG → 显示原理）；两条路都从今天这块踏板起跳。

## 六、pygambit 工具箱：类型进树，信息集裂开成多点

沿用 06 章 §六范式（EFG 文本 + `read_efg`，`Game.new_tree()` 只读、EFG 词法器不认 `#` 行内注释），新增一行语法：**`c` 行 = chance 节点**（自然抽类型，概率直接内联 `{ "Strong" 1/3 "Weak" 2/3 }`）。教学例子是 07 章进入威慑的不完全信息版（收益声明在案：进入者 in→被打 −1 / 被容 +1 / out 0；强在位者 打 1 > 容 0，弱在位者 容 1 > 打 −1；out 时在位者独享 2）：

```
EFG 2 R "bayes entry (incumbent type hidden)" { "Entrant" "Incumbent" }
c "c1" 1 "nature" { "Strong" 1/3 "Weak" 2/3 } 0
p "nS" 1 1 "entrant@both-branches" { "in" "out" } 0
p "nS2" 2 1 "incumbentStrong" { "fight" "accommodate" } 0
t "t1" 1 "in,Strong fights" { -1 1 }
t "t2" 2 "in,Strong accommodates" { 1 0 }
t "t3" 3 "out@Strong" { 0 2 }
p "nW" 1 1 "entrant@both-branches" { "in" "out" } 0
p "nW2" 2 2 "incumbentWeak" { "fight" "accommodate" } 0
t "t4" 4 "in,Weak fights" { -1 -1 }
t "t5" 5 "in,Weak accommodates" { 1 1 }
t "t6" 6 "out@Weak" { 0 2 }
```

逐行对照 06 章：唯一的差别是首行 `c`（自然抽类型）与进入者两个 `p` 行共用**同一个信息集号 1**（标签也相同）——他在树的两个不同节点上做同一个决定，且分不清自己站在哪支，这正是"信息集裂开成多点"的写法。实跑（lab04 E4，pygambit 16.7.0，本机实测）：

```
EFG 已建（chance 节点 c1 先抽类型 1/3:2/3；进入者信息集 1 裂开成 2 个节点——06 章伏笔在此兑付）
手推：BNE 有 3 个——(in, 强=打/弱=容) 进入者期望 (1/3)(−1)+(2/3)(1)=1/3；另 2 个 (out, ·, 弱=打)：out 之后在位者怎么选
  收益都是 2（弱无差异），靠'弱者也会打'的不可信威胁吓住进入者（强分支的喊法自由组合 → 恰 2 个）
  enumpure eq0: 进入者期望收益 0.0000，在位者 2.0000
  enumpure eq1: 进入者期望收益 0.3333，在位者 1.0000
  enumpure eq2: 进入者期望收益 0.0000，在位者 2.0000
PBE 审计：进入者信息集恒被到达 → 信念=先验（Bayes 钉死）→ in 的期望 1/3 > out 的 0 → 威胁版出局
→ 唯一 PBE = (in, 强打/弱容)，进入者期望收益 1/3 —— 与手推一致 ✓
```

三行读数：其一，求解器给 3 个纯均衡（BNE 口径）——07 章"求解器给 NE 清单，审计靠自己"的老话在类型维度原样复发；其二，那 2 个威胁版**在树上的缝**是：进入者的信息集永远会被走到（自然无路可绕），信念必须等于先验，in 的期望收益 1/3 > 0——"信念钉死 + 逐点序贯理性"的审计（PBE）把它们筛掉，这是 07 章 SPE 审计在不完全信息世界的对应物；其三，当先验挪到门槛 p(强) = 1/2 上（✍️ 练习③），in 与 out 期望打平，威胁版重新过审——**精炼的剪刀靠的是"利益差异"，不是形式**。

## 七、不足与边界

1. **BNE 的四条假设腿**：风险中性、估值 U[0,1]、私有价值、对称均衡——抽掉任何一条 b(v) 都变（风险厌恶让一价出价**更高**：输比赢亏更痛；共同价值下均衡形状整体改写）——[13 章](./13-拍卖理论.md)逐条松绑。
2. **对称解只是解之一**：非对称 BNE（如"某方惯常压价更少"）在本设定下也存在；本章只推了对称那支（先立最简锚点，00 章记号公约）。
3. **BNE 是静态的**：它不知道"信念该随观测更新"——观测→更新→再决策的时序版是 PBE/序贯均衡，09 章连同精炼标准一起上。
4. **蒙特卡洛只验证了 n = 2 特例与手推锚点**：一般 n 的 E[R] = (n−1)/(n+1) 是陈述不是实测；lab04 E2 的"收益等价"也只是 4 个可手推特例的对拍，定理本身 [13 章](./13-拍卖理论.md)。
5. **pygambit 的 c 行只解决"建树"**：chance 概率写错不报错、均衡照样错——06 章那句"库不校验形式语义，锚点必须手推对拍"对类型同样生效。
