# 07 · 子博弈完美与承诺：可信的威胁

> NE 在树上有个裂缝：**永远轮不到执行的威胁也能撑起一个均衡**——反正到不了，喊多狠都免费。本章立起审计官：**子博弈完美**（Selten 1965：策略限制在每个子博弈上都是 NE），当场审出"价格战威胁"是空话；然后把审计结果变成武器——**Stackelberg 先动优势**（两份完整代数解：先手 800 / 后手 400 / 同时 711，先手用产量承诺改变对手的最优反应）；最后收拢成一个动词——**承诺**（烧钱、合同、破釜沉舟：改变博弈的人赢），它正是卷四机制设计的原始形态。

---

**1965 年，德国**。Selten 在一篇关于寡头需求的论文里塞进了一个此后被引用万次的概念：子博弈完美。动机不是美学，是打假——经济与政治的世界里满是"你敢进来我就打价格战""你敢选核我我就跟进"，而其中大多数，**在真要执行的那一刻就不符合执行者自己的利益**。NE 对这类空话照单全收（它只审计实际走到的路径），Selten 的修法朴素到近乎较真：**把每一个可能开始的分支都当成一整场博弈重新审计**。二十九年后，他因此与 Nash、Harsanyi 同届分享 1994 年诺贝尔经济学奖。本章的主线一句话：**可信性 = 自我利益与宣称的一致性；承诺 = 主动砍掉自己的选项，让宣称变成均衡行为。**

---

## 一、子博弈与 SPE：把"每个分支都当真"正式化

**子博弈**：树上任一节点连同它后面的全部枝与终端，且**不切割任何信息集**（06 章的信息集在此显出第一重威力：单点信息集处处可切，完美信息博弈处处是子博弈；多点信息集的切割限制到 08/09 章才真正咬人）。**子博弈完美均衡（SPE）**：一个策略组合，它的**限制**在**每一个**子博弈上——包括整棵树永远走不到的那些——都构成 NE。

形式化审计官之后，两句要害：

- **完美信息博弈里，SPE ⟺ 逆向归纳路径**（有限情形）：06 章的算法因此升级为定理——蜈蚣的"节点 1 即 take"是 SPE 的代称。证明方向 ⇒ 每个子博弈里的限制恰好是归纳留下的最优枝；⇐ 对子博弈个数归纳构造。✍️ 练习③把两方向补全。
- **一次性偏离原则**（一句带过，16 章 CFR 的理论地基）：SPE 检验可以压缩成"任何玩家在任何信息集上，单点偏离无利可图"——审计工作量从指数降到线性。

NE ⊃ SPE 的差，就是"不可信威胁"的住址。下一节抓个现行。

## 二、不可信威胁：进入威慑博弈

市场只有一张桌：**进入者**选进/不进；进了，**在位者**选打价格战/容纳。教学数字（声明在案）：容纳双寡头各得 1；价格战两败俱伤各得 −1；不进则在位者独享垄断 2：

| 结果 | 进入者 | 在位者 |
|---|---|---|
| 进入 → 容纳 | 1 | 1 |
| 进入 → 打 | −1 | −1 |
| 不进（垄断） | 0 | 2 |

**NE 有两个**：(进, 容纳) ✓（进 1 > 0；容纳 1 > −1）；(不进, 打) ✓ 也过 NE 审查——进入者被"敢进就打"吓住（进 → −1 < 0），在位者的"打"悬在永远到不了的信息集上，喊得再狠都无罪。**SPE 只剩一个**：子博弈审计显示，真到那一节点，在位者打（−1）不如容纳（1）——**威胁在它自己的利益面前碎掉**；于是进入者知道纸老虎不会咬人，进入，容纳。这就是 Selten 的打假现场：**NE ⊇ { (不进, 打), (进, 容纳) }，SPE = { (进, 容纳) }**。

pygambit 实跑（EFG 文本建树 + `enumpure_solve`，本机实测）：

```
EFG 2 R "entry deterrence" { "Entrant" "Incumbent" }
p "n1" 1 1 "entrant" { "enter" "out" } 0
p "n2" 2 1 "incumbent" { "fight" "accommodate" } 0
t "t1" 1 "fight" { -1 -1 }
t "t2" 2 "accommodate" { 1 1 }
t "t3" 3 "out" { 0 2 }
```
```
enumpure_solve：纯均衡个数 = 2        # 行动顺序决定标号：'1'=enter/fight，'2'=out/accommodate
  eq0: P1='2'（不进）  P2='1'（打）      收益 (0, 2)   ← 不可信威胁撑起的 NE
  eq1: P1='1'（进）    P2='2'（容纳）    收益 (1, 1)   ← 唯一的 SPE
```

一条工程级诚实标注：**求解器返回的是 NE 清单，不是 SPE 清单**——它不替你过滤可信性（对比 06 章蜈蚣：那里唯一 NE 恰好过审，纯属良民）。"这算可信威胁吗"是审计问题，不是求解问题（50 章语法表的那一行在此兑现）。现实对照：价格战威胁在反垄断案卷里随处可见，真执行的少——**审计它的方法就是本章这一页**。

## 三、Stackelberg 先动优势：两份完整代数解

同一张市场，两种时序——00 章"建模四事故"第一条（忘记时序）的正面教材。设定：需求 P = 100 − Q，双方边际成本 c = 20，产量博弈。

**同一博弈、同时出招（Cournot 1838）**。厂商 i 的最优反应：给定 q_j，最大化 q_i(80 − q_i − q_j) → **q_i = (80 − q_j)/2**。对称不动点：q = (80 − q)/2 → **q\* = 80/3 ≈ 26.7 各**；Q = 160/3 ≈ 53.3，P = 140/3 ≈ 46.7，**各得 π = (80/3)² = 6400/9 ≈ 711.1**。

**先后出招（Stackelberg 1934）**。领导者先定量，且**知道追随者会看菜下饭**——把追随者的最优反应 q₂(q₁) = (80 − q₁)/2 代进自己的利润：

$$\pi_1 = q_1\Big(100 - q_1 - \tfrac{80 - q_1}{2} - 20\Big) = q_1\Big(40 - \tfrac{q_1}{2}\Big) \;\xrightarrow{\ \text{一阶条件}\ }\; q_1^* = 40$$

追随者到场吃剩的：q₂\* = (80 − 40)/2 = **20**。Q = 60，P = 40；**π_先 = 40×20 = 800，π_后 = 20×20 = 400**。一般公式顺手带走（a − c = 80，b = 1）：q_先 = (a−c)/2b、q_后 = (a−c)/4b、π_先 = (a−c)²/8b、π_后 = (a−c)²/16b。

| | 产量（各自） | 总产量 | 价格 | 利润（各自） |
|---|---|---|---|---|
| Cournot（同时） | 26.7 | 53.3 | 46.7 | **711.1** |
| Stackelberg 先手 | **40** | 60 | 40 | **800**（= 711.1 × 9/8） |
| Stackelberg 后手 | 20 | | | **400**（= 711.1 × 1/2） |

三行读数：**先动优势**（800 > 711 > 400）来自先手把"我的量已定"变成对手最优反应的输入——产量是战略替代品，先手用承诺把对手的最优反应曲线往自己这边拽；后手 400 惨于 Cournot——信息（看着对手再动）弥补不了行动权的丧失；而消费者欢迎这场内卷（60 > 53.3 的产量、40 < 46.7 的价格）。对比 04 章 LP 对偶的世界：零和里"先说破"无利可图（minimax 对称），**先动优势是"正和 + 承诺"的特产**。边界照例先立：替代品（产量）先行有利，互补/价格竞争里先行可能反而吃亏（低价先手被跟价吃掉利润），别背结论，带着时序建模。

## 四、承诺装置：改变博弈，而不是改变均衡

§二审计的判决其实是一份武器说明书：**威胁可信与否，取决于子博弈的收益；而收益可以被"博弈开始前"的行动改写**。在位者在进入者动之前先建产能（成本 0.6，教学数字）：容纳时产能闲置（1 − 0.6 = 0.4），打价格战时派上用场（−1 + 成本优势 = 1.2）：

| 结果 | 进入者 | 在位者（已建产能） |
|---|---|---|
| 进入 → 打 | −1 | **1.2** |
| 进入 → 容纳 | 1 | 0.4 |
| 不进 | 0 | 2 − 0.6 = 1.4 |

重审子博弈：1.2 > 0.4，"打"**由空话变成均衡行为** → 进入者：进 → −1 < 0，不进 → 在位者独享 1.4 > 容纳路径的 1。**花 0.6 买断一个子博弈的收益结构，把威胁焊成可信，净赚 0.4**（产能威慑的正典化：Spence 1977、Dixit 1980）。装置家族一览：

| 装置 | 机制 | 现场 |
|---|---|---|
| **过剩产能/军备** | 让"打"变便宜，威胁自动可信 | §四的数例 |
| **烧钱信号** | 不可逆成本按类型分层，只有强者烧得起 → 09 章 Spence 单交叉 | 教育/广告/质保 |
| **公开合同/保证金** | 违约自罚，把"背叛"从理性选项里删掉 | 押金、对赌、违约金条款 |
| **破釜沉舟** | 自断退路，让"我不会退"成为共同知识 | Cortés 1519 沉船；创始人的 all-in 与公开 deadline |

承诺的锋利处在 06 章已露过刀尖：最后通牒里 responder 若能承诺"见钱必收"，提议人立刻只给他残渣——**承诺的价值属于承诺者，但值多少，取决于他站在树的哪个节点**。烧船烧掉的选项在博弈论里从来不是损失，是买路钱。

## 五、机制设计回响：Stackelberg 是机制设计的原始形态

把 §三~四的领导者姿态抽象一层：**领导者选择规则（产量、产能、价格表），追随者在规则内最优反应**——这是一个双层优化：外层选规则、内层是跟随者的均衡（逆向归纳从"选动作"升级为"选规则"）。卷四的机制设计（[13 章](./13-拍卖理论.md)：把"卖东西给自利者"变成拍卖规则；[14 章](./14-机制设计与显示原理.md)：显示原理证明规则可以只谈真话）就是把这一姿态制度化为学科。AI 的语境里它已经上岗：**对齐 = principal（人类）与 agent（模型）的 Stackelberg 博弈**——constitution/奖励模型是承诺装置，"模型会不会 reward hacking"是追随者的最优反应审计（[18 章](./18-博弈论与LLM对齐.md) ◆ 待写，Stackelberg alignment 专题）。07 章的一页纸，是卷四的出生证明。

## 六、不足与边界

1. **SPE 是精炼，不是预言**：蜈蚣的 SPE 在实验室当堂翻车（06 章 §四）——精炼修好了"威胁的可信性"，修不了"理性的公共知识"本身；50 章第一堵墙收总账。
2. **SPE 不唯一的世界**：一次性博弈里它常唯一，重复博弈里无名定理（10 章）会把均衡集炸开——精炼的补丁史没完（直觉标准 → ESS → QRE，50 章补丁表）。
3. **承诺三前提**：可观察（对手看得见）、不可逆（烧了就是烧了）、先于对手行动——"廉价磋商"式的口头承诺三者全无，它在 09 章（Crawford-Sobel）有专属的坏消息。
4. **数例的敏感性与先动优势的可逆性**：Stackelberg 结论依赖线性需求/常数成本/替代品时序；承诺装置本身有成本（产能 0.6 在威胁没人试探时是纯浪费）——威慑是买保险，不是印钞。
