# 15 · 博弈学习经典：均衡作为学习不动点

> 卷五开卷：前十四章的均衡要么被"求解"（02-09 章）、要么被"执行"（13/14 章机制设计直接假设激励会兑现）——本章补上被跳过的一问：**均衡从哪里来？** 谁也没在真算纳什均衡（[50 章](./50-批判收尾.md)第二堵墙：算不动），可均衡行为却处处可见——答案候选是**学习**。本章立三件套：**fictitious play**（对历史平均的最优反应——零和/势博弈收敛定理，RPS 上信念永久循环：[11 章](./11-演化博弈.md)复制动态闭轨在学习世界的同构复演）、**no-regret 框架**（外部遗憾作通用货币，Hedge 与遗憾匹配 O(√T)——与 [`讲透优化 25 在线优化`](../讲透优化/25-在线优化.md)**同一数学两种方言**）、**主定理：平均遗憾 → 0 ⇒ 经验分布收敛到 CCE**（证明主脉一段；NE ⊂ CE ⊂ CCE 层级落定，[50 章](./50-批判收尾.md)解概念阶梯的"计算友好逃生通道"在此兑现）。NE 的第四种读法就此登场：**均衡是学习过程的不动点**。

---

**1951 年，圣莫尼卡，兰德公司**。George W. Brown 发表了可能是博弈论史上最简单的算法：*"fictitious play"*——每个玩家假装对手永远重复历史平均，对它出最优反应。同年，Julia Robinson（二十年后因希尔伯特第十问题名震数学界）证明了它的第一个收敛定理：**零和博弈上 FP 的平均策略收敛到 minimax 解**。一个"傻瓜都能执行"的规则，居然自己长出均衡——均衡不必被计算，可以被**演化出来**。半个世纪后 Hart-Mas-Colell 2000 把这条线推到顶：**遗憾匹配——同样简单的自适应程序——的一般和博弈极限必是相关均衡**。本章立场一句话：**均衡概念回答"稳不稳"，学习理论回答"到不到"——把两者接起来的货币叫遗憾。**

## 一、换问题：谁在学，学什么

[00 章](./00-开场.md)理性五档表到此走完最后两档的交接：02 章的"无限理性人"在 11 章降级为"种群选择"，本章再换一种发动机——**显式学习规则**。三个问题立正：

| 问题 | 选项 | 本章取舍 |
|---|---|---|
| 谁在学 | 理性推演 / 种群复制 / 算法更新 | 算法更新（但与种群动力学同构——§五） |
| 学什么 | 信念（对手是谁）/ 策略（我出什么）/ 遗憾（我错在哪） | 三者都要，遗憾最通用 |
| 收敛到哪 | NE / CE / CCE | 分博弈类——**收敛性地图**（§五）是本章的地图 |

由此 NE 得到它的第四种读法：02 章的三层含义（规范/实证/进化）之后再添一层——**学习过程的不动点**：若学习规则的轨迹停在 x\*，则 x\* 必是均衡；[50 章](./50-批判收尾.md)第三堵墙的全部内容，就是"轨迹不停"时怎么办（答案在 §四：看平均）。

## 二、fictitious play：对历史平均的最优反应

**FP 规则**（Brown 1951）：每轮把对手的历史动作频率当作他的（混合）策略，出最优反应。PD 上它一秒锁死——D 对列玩家的**任何**混合都是最优反应（5y_C + 1y_D > 3y_C ⟺ 2y_C + y_D > 0 恒成立，01 章严格占优的频率版），RPS 上它永不落地——信念绕 (1/3,1/3,1/3) 转圈（石头多了改出布、布多了改出剪刀……）。lab07 E1（8000 轮，本机实测）把两景并排：

```
E1 · fictitious play：PD 行为锁死 (D,D) vs RPS 信念循环（8000 轮）
理论锚点（手推）：D 对任何对手混合都是 BR → FP 行为自第 3 轮起锁死 (D,D)
  PD 后 7000 轮：行玩家 D 频率 1.0000、列玩家 D 频率 1.0000（vs 1，|最大偏差| 0.0000）✓
  RPS：行为不收敛（信念绕 (1/3,1/3,1/3) 循环——图 a）；时间平均动作频率 = (0.3354, 0.3256, 0.3390) vs 1/3（|最大偏差| 0.0077，容差 0.02）✓
→ E1 对拍：PD 锁死 ✓ / RPS 循环但平均 → 1/3 —— 全绿 ✓
```

读数两行：**行为可以循环而平均依然站稳**（RPS 时间平均 → 1/3，恰是 minimax——Robinson 定理的现场）；**FP 若收敛则极限是 NE**（各自的平均是对手平均的最优反应，极限处相互最优反应成立）。收敛定理的覆盖面一张表（置信度：高，均为经典结果）：零和（Robinson 1951）、势博弈（Monderer-Shapley 1996）、2×2 博弈（Miyasawa 1961）——**一般和博弈不保证**，Shapley 1964 的反例就是一个改造版 RPS，信念沿异于闭轨的螺旋永不返家。[11 章](./11-演化博弈.md)的复制动态与 FP 是两条不同的向量场，却在同一类博弈上发作同一种病——非传递性（[17 章](./17-自博弈与多智能体RL.md) ◆ 的病根预告）。

## 三、no-regret：遗憾是通用货币

FP 的病根是它只看"对手平均"、对最近的盘面失忆。换货币——**外部遗憾**：

$$R_i(T) = \max_{a^*}\sum_{t=1}^{T} u_i(a^*, s_{t,-i}) - \sum_{t=1}^{T} u_i(a_{i,t},\, s_{t,-i})$$

"事后最能打的固定动作比我实际打出的多赚多少"。三个理由让它成为通用货币：其一，**它不要求对手模型**——界对任意对手序列成立（对手是不是理性、学不学，都无所谓）；其二，**它可分解**——每轮的假想增益直接累加，算法好写；其三，**它刚好够换均衡**（§四）。

两台经典机器（都是 [`讲透优化 25`](../讲透优化/25-在线优化.md) 的方言）：

- **Hedge/指数权重**（Littlestone-Warmuth 1988 谱系；Freund-Schapire 1997 的 Hedge、1999 接入博弈并在线重证明 minimax）：权重 w(a) ∝ exp(η·累计收益)，按权重抽动作；η = √(ln n/T) 时 R(T) ≤ 2√(T·ln n)——**FTRL 框架里取熵正则的那一支**（讲透优化 25 的"正则动物园"：ℓ₂→OGD、熵→Hedge；那边最小化损失、这边最大化收益，代数同构）。
- **遗憾匹配 RM**（Hart-Mas-Colell 2000）：σ(a) ∝ max(0, R(a))（全零时均匀）——**没有学习率**，纯比例响应，比 Hedge 更"博弈论"；保证同样 O(√T)。

lab07 E2（RPS 自博弈 10⁵ 轮，本机实测）：

```
E2 · 遗憾匹配自博弈 RPS：平均遗憾 ~ T^(−1/2)（log-log 斜率 −1/2）
理论锚点：RM 总遗憾 O(√T) → 平均遗憾 ~ c·T^(−1/2)（log-log 斜率 −1/2；√T 界是最坏情形，实测常更快）
  T=   100：平均遗憾 = 0.14000
  T=  1000：平均遗憾 = 0.05500
  T= 10000：平均遗憾 = 0.02100
  T=100000：平均遗憾 = 0.00412
  log-log 斜率（T=10³→10⁵ 最小二乘）= -0.534（vs 理论 −1/2，容差 [−0.75,−0.30]）✓；T=10⁵ 平均遗憾 = 0.0041 < 0.02 ✓
→ E2 对拍：平均遗憾按 T^(−1/2) 衰减 —— 全绿 ✓
```

注意 E1 与 E2 的分工：E1 的 RPS 信念在**转圈**（行为不收敛），E2 的遗憾在**单调消融**（平均遗憾 → 0）——同一张单纯形、两本账，正是本章的标题句：均衡从"点"搬家到"平均"。

## 四、主定理：平均遗憾 → 0 ⇒ 经验分布 → CCE

**CCE（粗相关均衡）**：联合分布 z 使"私下收到抽签建议后自愿服从"占优——比 [05 章](./05-均衡选择与相关均衡.md)的 CE 更宽：CE 要求拿到建议后**每个具体建议**都无偏离动机，CCE 只要求**先于建议**（知道分布、不知这次抽到什么）时无偏离动机——"无条件想换固定动作"不赚。层级链 NE ⊂ CE ⊂ CCE（[50 章](./50-批判收尾.md)阶梯表已预告）。

**主定理**（Foster-Vohra 1997 谱系；Hart-Mas-Colell 2000 的 RM 版；置信度：高）：若每个玩家的平均外部遗憾 → 0，则联合经验分布 z_T（前 T 轮动作对的频率）收敛到该博弈的 CCE 集。证明主脉四行（以两人为例）：

1. 平均遗憾 → 0 ⟺ 对每个固定替换 a′：(1/T)Σ_t [u(a′, b_t) − u(a_t, b_t)] → 0；
2. 左边恰是 **z_T 下的期望差**：Σ_b z_T(a′, b)·u(a′, b) − Σ_{a,b} z_T(a, b)·u(a, b) → 0；
3. 即 z_T 对 CCE 定义不等式组**逐条渐近满足**；
4. CCE 集闭（有限博弈中是紧多面体），z_T 的任何极限点都逐条满足 ⟹ 全在 CCE 内。∎

一句话读法：**遗憾消融把"事后不可指责"兑换成"平均联合分布落在自愿意服从的集里"**——不需要行为收敛（E1 的环照转不误），不需要对手理性（对任意序列成立）。这是博弈论里罕见的"白给"定理：两个各自 no-regret 的傻瓜对打，平均意义自动进均衡。也请看清它给的是什么：**CCE，不是 NE**——从 CCE 到 NE 需要零和（两人零和的 CCE 的边际近似 minimax——Robinson 定理的 no-regret 版）或额外结构；一般和博弈里 CCE 允许相关（05 章红绿灯式的协调），这正是它的力量也是它的松度。

## 五、收敛性地图

| 博弈类 | FP 收敛？ | no-regret 行为收敛？ | 平均收敛到 | 本章现场 |
|---|---|---|---|---|
| 零和 | ✓（Robinson 1951） | ✗（可循环） | minimax / CCE | RPS（E1/E2） |
| 势博弈 | ✓（Monderer-Shapley 1996） | 平均 ✓（行为可振荡） | 纯 NE 附近 | PD（E1，势=占优） |
| 2×2 | ✓（Miyasawa 1961） | — | NE/CE | — |
| 一般和 | **✗（Shapley 1964）** | **✗** | 仅 CCE | Bailey-Piliouras 2018 |

第三行往下是[50 章](./50-批判收尾.md)第三堵墙的正片：**"行为 vs 平均"分家**的三个现场——RPS 复制动态闭轨（[11 章](./11-演化博弈.md)）、FP 信念环（本章 E1）、乘法权重极限点不是 NE（Bailey-Piliouras 2018：一般博弈中 Hedge/复制动态一族的极限点普遍远离 NE）——同一张图三次重演，病根都是**非传递性**（A 克 B、B 克 C、C 克 A 的环上没有梯度可下）。药方两贴：认命用 CCE（计算友好、LP 可解——50 章第二堵墙的逃生通道），或**换掉单一策略、养策略人口**（PSRO——[17 章](./17-自博弈与多智能体RL.md) ◆ 的主角，思想上正是 [11 章](./11-演化博弈.md)"种群"的算法回归）。AI 一句提前挂账：自博弈训练的"平均策略"正是本章的平均哲学——[16 章](./16-CFR与扑克AI.md)的 CFR 平均策略、[17 章](./17-自博弈与多智能体RL.md) ◆ 的人口，全是 §四主定理的工程化身。

## 六、不足与边界

1. **CCE ≠ NE**：主定理白给的是最宽的均衡——从 CCE 往上每走一层（CE、NE）都要加结构（零和、两人、独立性）；把 CCE 当"解决了均衡"是本分支最常见的营销话术。
2. **行为不收敛是常态而非事故**：遗憾照消、环照样转——部署学习算法时能承诺的是"平均不可剥削"，不是"下一手在哪里"。
3. **遗憾类型学**：外部遗憾只管"换固定动作"；**内部/交换遗憾**（"在出 R 的场合换成 P"）控制到 CE 才够（Blum-Mansour 2007 的转换；Hart-Mas-Colell 的内部遗憾版收敛到 CE）——契约里写哪种遗憾，拿到哪种均衡。
4. **√T 是最坏情形**：具体博弈常更快（E2 的 0.004@10⁵ 远低于界），但存在实例逼近平推——机制上不能指望运气。
5. **非平稳对手**：对手同时学习时，"任意序列下 no-regret"依然成立（这是货币的强项），但两台学习机互踩出的**联合动力学**可以长期漂移（17 章的非平稳性难题）——遗憾保护你，不保护环境。
