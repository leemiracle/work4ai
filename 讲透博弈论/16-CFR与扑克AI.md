# 16 · CFR 与扑克 AI：不完美信息的征服

> 卷五第二章：[15 章](./15-博弈学习经典.md)的学习机器全住在策略式矩阵里——本章把它们装进**树**，记账单位从"动作"细化到**信息集**（[06 章](./06-扩展式与逆向归纳.md)的老朋友在此从建模概念变成数据结构）。果蝇是 **Kuhn 扑克**（三张牌、两个筹码、一轮下注——1950 年就被手工解透的最小扑克）；心脏是**反事实遗憾**（CFR：到达概率加权的"假想增益"——15 章遗憾匹配的扩展式推广）；对拍锚点是**博弈值 −1/18**（P1 先动的信息劣势的价格，本机全树枚举 + 手推双验证）与**诈唬比 1:3**（底池赔率的代数——Kuhn 均衡族一行锁定）。收尾是工程史：**CFR+ → Libratus（2017 无人限德州单挑胜人类顶尖）→ Pluribus（2019 六人桌，约 20 万美元云算力）**——[50 章](./50-批判收尾.md)"PPAD 难算就不硬算"的工程绕行在此打到冠军级；lab08（WSL）用 OpenSpiel 官方求解器与本系列手写 CFR 三方对拍。

**2017 年 1 月 30 日，匹兹堡，Rivers 赌场**。"Brains vs. Artificial Intelligence"赛终场：卡内基梅隆 Tuomas Sandholm 与 Noam Brown 的 **Libratus** 经过 12 万手单挑，击败四位顶尖职业无限注德州扑克选手，合计领先 **176.6 万美元**筹码。这不是深蓝式的暴力搜索：两人单挑德州的博弈树规模在 10¹⁶⁰ 量级（比棋类深几十个数量级），且是**不完美信息**——对手的底牌你看不见，诈唬（bluff）因此成为策略的一部分。Libratus 的地基正是本章主角 **CFR（counterfactual regret minimization）**：一个 2007 年的"在树上做遗憾匹配"的算法，配上一系列加速（CFR+）与实时求解的工程组装。本章立场一句话：**CFR 把 15 章"平均策略进均衡"的哲学装进信息集——扑克 AI 不是算出了均衡，是长出了均衡。**

## 一、Kuhn 扑克：最小扑克的完整规则

**Kuhn 扑克**（Kuhn 1950）：三张牌 J < Q < K，各一张；两人各 ante 1 筹码；每人发一张；P1 先动：

```
P1: check(K) ── P2: check(K) ── 摊牌（底池 2：胜者 ±1）
        │            └─ P2: bet(B) ── P1: fold(F) → P2 +1
        │                                └─ P1: call(C) ── 摊牌（底池 4：±2）
        └─ P1: bet(B) ── P2: fold(F) → P1 +1
                        └─ P2: call(C) ── 摊牌（底池 4：±2）
```

历史串（lab07 的编码）：`K/B` 起头、`F/C` 收尾——`KK`（双 check 小摊牌）、`BF`/`KBF`（弃牌）、`BC`/`KBC`（大摊牌）共 6 种终局。**信息集 12 个**：P1 有 6 个（三种牌 × 首动 check/bet + `KB` 后 fold/call），P2 有 6 个（三种牌 × `B` 后 fold/call + `K` 后 check/bet）——每个信息集一个混合策略，这就是"解"的形状（行为策略；完美回忆下 Kuhn 定理保证行为策略不失一般性，[06 章](./06-扩展式与逆向归纳.md)的一句伏笔在此兑付）。

为什么偏用扑克当果蝇：**不完美信息**（对手底牌 = 08 章的私有类型，但这里类型影响的是**终局收益**而非偏好）、**诈唬的必然性**（均衡里必须以正概率拿烂牌下注——否则对手的跟注/弃牌被你自己的下注范围出卖）、**状态空间爆炸**（真实扑克 10¹³⁺ 信息集——50 章第二堵墙的扑克版）。价值预告：**博弈值 = −1/18 ≈ −0.0556**（P1 视角）——先动是劣势：P2 后动**多看一手信息**，这个"看一手"值 1/18 个筹码。

## 二、反事实遗憾：把 15 章的货币装进树

[15 章](./15-博弈学习经典.md)的遗憾按动作记账，树上有两个新问题：决策点千千万（按信息集记），且**你到不到这个信息集取决于你自己的策略**——"假想我在 I 选了 a"该怎么加权？答案是 CFR 的命名词根——**反事实（counterfactual）**：把"我自己的到达概率"折掉，只留对手与自然的：

$$v(I, a) = \sum_{z \,\text{过} I} \pi_{-i}^{\sigma}(z)\, u_i(z \mid I \to a)$$

（π_{-i} = 对手与自然到达该路径的概率之积；自己那份 πᵢ 不乘——这正是"假如我到了这里"的反事实语义。）**反事实遗憾**按信息集累计：R(I, a) ← R(I, a) + π_{-i}·[v(I,a) − v(I)]；策略照 15 章遗憾匹配：σ(I,·) ∝ max(0, R(I,·))；**平均策略按自身到达概率 πᵢ 加权累计**（到达越频繁的信息集权重越大）。伪代码与 lab07 的 `_cfr` 一一对照：

```
cfr(历史 h, 发牌, reach=(π1, π2)):
    若 h 终端: 返回收益
    σ(I) ← 正遗憾归一化（全零则均匀）
    对每个动作 a: v[a] ← cfr(h+a, reach 换成 σ(a)·π_自己)
    R(I, a) += π_对手 · (v[a] − Σ σ(a')v[a'])      # 反事实遗憾
    S(I)    += π_自己 · σ                            # 平均策略累计
    返回 Σ σ(a)·v[a]
每轮遍历全部 6 种发牌（chance 枚举，无抽样方差）
```

**CFR 主定理**（Zinkevich et al. 2007；置信度：高）：所有信息集的遗憾都是 O(√T)，故**平均策略对任意对手的可剥削度 → 0**——两人博弈里平均策略剖面 → Nash。注意它承诺的对象：又是**平均**（15 章 §五的哲学原样上山——行为可以振荡，平均在收敛）。

lab07 E3（本机实测；chance 全枚举、无随机性）：

```

理论锚点（16 章 §四手推）：Kuhn 扑克博弈值（P1 期望收益）= −1/18 ≈ −0.0556
  迭代    100：平均策略博弈值 = -0.0547（入容差 ±0.01）
  迭代   1000：平均策略博弈值 = -0.0552（入容差 ±0.01）
  迭代  50000：平均策略博弈值 = -0.0556（入容差 ±0.01）
  迭代 200000：平均策略博弈值 = -0.0556（入容差 ±0.01）
→ E3 对拍：2×10⁵ 次后博弈值 -0.0556 vs −0.0556（|偏差| 0.0000 < 0.01）—— 全绿 ✓
  P1 六信息集平均策略（均衡族的一支；16 章手推对照）：
    P1:J:      check=0.779  bet=0.221      ← J 诈唬率 α
    P1:J:KB    fold=1.000  call=0.000      ← 面对 check-bet 弃
    P1:K:      check=0.338  bet=0.662      ← ≈ 3α（0.221×3 = 0.663）
    P1:K:KB    fold=0.000  call=1.000      ← 坚决跟
    P1:Q:      check=1.000  bet=0.000      ← Q 从不下注
    P1:Q:KB    fold=0.444  call=0.556      ← ≈ 1/3 + α（0.333+0.221 = 0.554）
```

三处族关系当场验尸（下一节手推的理论值 vs 机器实测）：`b_K = 3α`（0.663 ↔ 0.662）、`c_Q = 1/3 + α`（0.554 ↔ 0.556）、价值 −1/18（族不变量）。可玩版 [`cli/kuhn_poker.py`](./cli/kuhn_poker.py)（`--demo` 自赌 500 手 ≈ −0.056 ± 抽样；交互模式 bot 每手**当场揭示**它抽签用的真实混合概率）在 5×10⁴ 次迭代处落到族的另一端点 α = 1/3（P2 侧：J 诈唬 0.333、K 必下注 1.000、Q 跟注 0.338）——同一算法、不同迭代数，落在族内不同点，价值纹丝不动。

## 四、Kuhn 均衡手推：诈唬比 1:3 与价值 −1/18

均衡长什么样可以从"哪些牌根本没有选择"开始。四条**支配律**（各一两行可证）：面对 bet 的 J 永远弃（只能赢诈唬，赔率不允许）；面对 bet 的 K 永远跟；P1 的 Q 永远 check（下注 = 白送：J 弃牌赚 1、K 必跟亏 2——§五练习①算这笔账）；P2 的 Q 在 check 后永远 check。剩下四个自由度：P1 的 J/K 下注率（b_J, b_K）、双方 Q 的跟注率（c_Q¹, c_Q²）、P2 的 J/K 偷鸡率（β_J, β_K）。

**第一把钳子：底池赔率。** P2 拿 Q 面对 P1 的 bet：弃 = −1；跟 = 2·P(J|bet) − 2·P(K|bet)。无差异 ⟺ P(J|bet) = 1/4——**下注范围里诈唬:价值 = 1:3**（pot odds 的代数：跟 1 赢 3。P1 的 Q 不下注 ⟹ 范围只有 J 和 K）。P2 的 Q 要混合，P1 就必须 b_K = 3·b_J。对称地，P1 拿 Q 面对 check-bet 的无差异 ⟹ P2 的偷鸡范围 β_K = 3·β_J。**诈唬不是为了赢摊牌，是让你的下注范围"可信到恰好"——对手的中间牌站不稳也放不下。**

**第二把钳子：诈唬者自己的无差异**（这里有个著名的坑——**check 本身带信息**）。P1 的 J 在"下注诈唬 vs check"间无差异：下注的期望 = −c_Q²（P2 的 Q 跟注率越高诈唬越亏）⟹ **c_Q² = 1/3**。P2 的 J 在"偷鸡 vs check"间无差异时，P1 会 check 的牌里 Q 与 K 的**条件概率**不再是 1:1（P1 拿 K 有 3α 的概率已下注、拿 Q 永远 check）——带着这个条件概率算到底，得 **c_Q¹ = 1/3 + α**（α = P1 的 J 诈唬率：P1 下注越凶，剩下 check 范围里 K 越稀、Q 越密，P1 自己的 Q 面对偷鸡就越敢跟）。同理 P1 的 K 无差异 ⟹ β_J = 1/3；而 P2 的 K 在 check 后下注**严格占优**（β_K = 1——P1 的 Q 跟着 c_Q¹ > 0 的概率白送）。汇总成表（**均衡族**：P1 一侧单参数 α ∈ [0, 1/3]，P2 一侧唯一；Kuhn 1950）：

| 信息集 | 均衡策略 | lab07/CLI 实测 |
|---|---|---|
| P1·J 首动 | bet α，check 1−α | α = 0.221 |
| P1·K 首动 | bet 3α，check 1−3α | 0.662 ≈ 3×0.221 ✓ |
| P1·Q 首动 | check | 1.000 ✓ |
| P1·Q 面对 check-bet | call 1/3 + α | 0.556 ≈ 0.554 ✓ |
| P1·J 面对 check-bet / P1·K | fold / call | 1.000 / 1.000 ✓ |
| P2·J 面对 bet / P2·K | fold / call | 1.000 / 1.000 ✓ |
| P2·Q 面对 bet | call 1/3 | 0.338 ✓ |
| P2·J / P2·K 在 check 后 | bet 1/3 / bet 1 | 0.333 / 1.000 ✓ |
| P2·Q 在 check 后 | check | 1.000 ✓ |

**价值六手牌枚举**（每手 1/6；把上表策略代进去逐手算期望，α 是唯一参数）：

| 发牌 (P1, P2) | 期望收益 | 发牌 | 期望收益 |
|---|---|---|---|
| (J, Q) | α − 1 | (Q, J) | α + 2/3 |
| (J, K) | −α − 1 | (Q, K) | −4/3 − α |
| (K, J) | 4/3 − α | (K, Q) | 1 + α |

六项相加：常数项合计 **−1/3**，α 项**恰好互相抵消**（+1−1+1−1−1+1 = 0）——

$$v_1 = \frac{1}{6}\cdot\Big(-\frac{1}{3}\Big) = -\frac{1}{18} \approx -0.0556$$

α 怎么选都不影响价值（均衡族的公共价值，零和博弈的通性——[04 章](./04-零和与minimax.md)的价值观）；机器侧 lab07 E3 全树枚举 −0.0556 双验证 ✓。1/18 从哪来：按 P1 的牌分三组——**J 两手合计约 −2**（最小牌的硬亏损）、**K 两手合计 +7/3**（拿最大牌却赚不满 2×2：偶尔被诈唬弃牌、下注时 J 直接吓走）、**Q 两手净 −2/3**——中间牌被 P2 的位置优势（后看一手行动）持续放血，先动的"信息税"合计 −1/3，摊到六手恰是 −1/18。

## 五、CFR+ 与扑克 AI 的工程史

vanilla CFR 的收敛是 O(1/√T)，Kuhn 上秒级到位，真实扑克远远不够。三级跳：

- **CFR+**（Tammelin 2014）：三处手术——**交替更新**（P1 更新时 P2 策略冻结，反向亦然）、**遗憾即时正化**（R ← max(0, R)，消极遗憾清零）、**线性加权平均**（近期策略权重高）。Heads-up 限注德州（约 10¹⁴ 决策点，Cepheus 2015 到"本质解决"）上把可剥削度压到肉眼难分——2014 年起"解扑克"的默认引擎。
- **Libratus**（Sandholm-Brown 2017，无限制单挑）：三件套——**蓝图**（粗抽象 + CFR+ 离线解）、**实时子博弈求解**（对手下注后在该子树内现场重解，绕开抽象误差）、**夜间自加强**（把白天暴露的漏洞补进蓝图）。注意它**从不计算整棵树的均衡**（10¹⁶⁰ 规模，50 章第二堵墙）——它算的是"每个到达的局部够不够均衡"，[50 章](./50-批判收尾.md) §2.3 工程回声的冠军版。
- **Pluribus**（Brown-Sandholm 2019，六人桌）：多人不完美信息的第一次攻克——六人桌**非零和**，CFR 的理论保证不再直接成立，工程上靠"自博弈 + 蓝图不动 + 实时搜索"照样赢了职业阵容，且全部训练算力约 **15 万美元云费用**（对比 AlphaGo 的量级——搜索深度换深度的胜利）。DeepStack 2017（价值网络持续求解，另一条路线）一句带过。

工具箱对拍预告：**lab08**（WSL）用 OpenSpiel 官方 `CFRSolver`/`CFRPlusSolver` 跑 Kuhn，与理论 −1/18、lab07 手写值**三方对拍**——同一锚点、三个独立实现，是本系列"诚实校准"的收官一环。

## 六、不足与边界

1. **完美回忆是硬假设**：CFR 的信息集结构要求玩家记得自己看过的牌（Kuhn 定理也在此前提下）；真实对局中的"忘了"会击穿行为策略等价性——多智能体系统里这条假设比看上去脆。
2. **收敛的是平均**：行为策略可以永久振荡（15 章 §五的树版）；工程上"部署哪个策略"是个真问题（Pluribus 部署蓝图+实时搜索的混合，不是裸平均）。
3. **抽象误差**：真实扑克必须先做卡片聚类/动作桶化——抽象间隙是 Libratus 时代最大的误差源（实时子博弈求解正是为了在到达处抹掉它）。
4. **多人/非零和的定理缺口**：两人零和有"可剥削度 → 0 ⟹ Nash"的闭环；多人博弈里 CFR 收敛到何物理论上并不干净——Pluribus 是工程胜利，不是定理（[50 章](./50-批判收尾.md)第四堵墙在多人博弈上更宽）。
5. **均衡打法不剥削对手**：Nash 策略保证不被剥削，但也放弃了对非均衡对手的利润——对手建模/剥削（CFR + 开发者的 best-response 混合）是竞技 AI 的实务分支，也是 [17 章](./17-自博弈与多智能体RL.md) ◆ 人口方法（PSRO）的入口。
