# ⚠️ 第 4 幕 · 不足：CV 的失败模式

## 1. Adversarial Patch
一张「人类看不出异常」的图，能让 CNN/ViT 严重误分类。**视觉模型的鲁棒性远低于直觉**。
**根因**：模型依赖像素统计，不是真「理解」。
**缓解**：对抗训练、certified robustness、检测异常输入。

## 2. 长尾（Long Tail）
常见类（猫狗车）识别准，罕见类（特定零件/医学影像）崩。
**根因**：训练数据分布偏斜。
**缓解**：长尾 loss reweighting、few-shot、合成数据。

## 3. OOD（Out-of-Distribution）
没见过的场景（新光照/新角度/新域）识别崩。
**缓解**：domain randomization、大规模多样化训练、异常检测。

## 4. 可解释性差
模型「看见」了什么？无法精确指出。saliency map 常误导。
**缓解**：attention 可视化（ViT 的 attention 相对可解释）、concept bottleneck、prototype networks。

## 5. SAM 的语义局限
SAM 能分割「物体」，但不懂「这是什么」或「为什么重要」。**分割≠理解**。
**例**：SAM 把 X 光片里的肿瘤分成「一个物体」，但不知道它是肿瘤。

## 6. Diffusion 的 Compositionality
文生图在「A 和 B」时经常漏一个、错放位置、属性串扰（蓝色立方体和红色球→蓝色球）。
**根因**：注意力分配不均。
**缓解**：布局引导（ControlNet）、结构化 prompt、多步生成。

## 7. 多模态幻觉
VLM「看到」不存在的东西（说图里有某物其实没有）。
**根因**：语言先验压过视觉证据（「常见搭配」让模型脑补）。
**缓解**：视觉 grounding、置信度、对比多视角。

## 8. 分辨率折中
高分辨率细节多但 token 爆炸；低分辨率省 token 但丢细节。
**缓解**：Qwen2-VL 的动态分辨率、分层 attention。

## 9. 3D 的病态性
从 2D 重建 3D 仍是病态问题。NeRF/Gaussian Splatting 强但需多视角。
**缓解**：先验（单目深度估计）、大规模 3D 数据。

## 10. 视频 = 图 × 时间的复杂度
视频理解远落后于图像。时序因果、长视频一致性都是难题。
**缓解**：高效视频 backbone、分层时序建模。

---

## 🎬 收束

> CV 的本质难题——**从 2D 反推 3D 是病态问题**——没被解决，只是用更强的先验+更多数据把它压到「够用」。adversarial patch、长尾、OOD 提醒我们：**当前 CV 是高级模式匹配，不是真正「理解」视觉**。真正的视觉理解可能需要世界模型（知道杯子会碎）+ 具身（能动着看）。
