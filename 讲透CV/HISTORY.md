# 讲透CV · 思想史

> **一句话定位**：所有其他讲透CV的文件讲"卷积/注意力/扩散**怎么实现**"；本篇问"机器视觉**为什么长成今天这样**"——为什么卷积归纳偏置在 2012 才爆发、为什么 ViT 敢于杀死卷积、为什么生成模型迟到 2022、当前的"现状"有多少是历史偶然。
>
> **博士级标准**：不是"年份+模型+Top-5 错误率"的维基百科（那是浅薄年代史），是**思想史**（history of ideas）——问"为什么某个先验在某个时代被选中、被淘汰、又复兴"。

---

## 0. 方法论

本篇严格遵循 [`讲透AI历史/00-为什么学AI历史`](../讲透AI历史/00-为什么学AI历史.md) 的思想史方法论，并配合 [`讲透AI历史/advanced/01-范式转移的库恩分析`](../讲透AI历史/advanced/01-范式转移的库恩分析.md) 的库恩框架。

### 0.1 三条贯穿原则

1. **思想史 > 年代史**——不只问"AlexNet 何时发布"，问"为什么卷积归纳偏置要等到 2012 才爆发"。答案藏在算力（GPU）、数据（ImageNet）、评测（ILSVRC）三者同时成熟的窗口里。
2. **路径依赖敏感**——当前的"必然"可能是偶然。如果 Krizhevsky 当年没买 GTX 580，深度学习可能再晚 3-5 年。
3. **失败与成功同等重要**——被淘汰的 SIFT/HOG/DPM/手工特征工程不是"落后"，它们在当时是最优解；今天的端到端学习也可能被取代。

### 0.2 CV 的核心矛盾（统一线索）

> **视觉的本质是逆图形学（inverse graphics）**——从 2D 像素反推 3D 世界，这是病态问题（ill-posed）。CV 的全部历史，就是**用不同的"先验"（prior）约束这个病态反演**。

这条线索贯穿全篇。每次范式更迭，本质是**换了一种先验**：

| 范式 | 先验 | 谁规定的先验 | 死板度 |
|---|---|---|---|
| 经典特征（SIFT/HOG） | 人工设计的不变性 | 人类直觉 | 最死板 |
| CNN | 局部性+平移不变+层次 | 硬编码进架构（但参数学习） | 死板 |
| ViT | 通用 attention | 模型从数据自学 | 中 |
| CLIP | 视觉-语言对齐 | 对比目标 + 海量配对 | 中 |
| Diffusion | 通用生成先验（去噪） | 训练目标本身 | 最灵活 |
| SAM/基础模型 | "什么是一个物体" | 11 亿掩码 + 提示 | 灵活 |

🎯 **方向**：**先验越来越通用，对数据的依赖越来越大**。这就是为什么 CV 越来越像 NLP——架构趋同于 Transformer，差别退化为数据和目标。这条"先验熵减"主线和 [`讲透CV/01`](./01-直觉-视觉三次范式更迭.md) 完全一致，本篇补上**时间-因果维度**。

### 0.3 CV 史的库恩范式转移（5 次革命）

套用库恩框架（常规科学→异常累积→危机→范式转移），CV 经历至少 **5 次大范式转移**（另加前史 3 个阶段）：

| # | 时代 | 旧范式 | 新范式 | 触发 |
|---|---|---|---|---|
| 前史 | 1960s-1980s | — | **神经科学启发 + 计算视觉** | Hubel-Wiesel / Marr / Fukushima |
| 前史 | 1990s-2011 | 感知机受挫 | **经典特征工程** | SIFT / Viola-Jones / HOG |
| **1** | 2012 | 经典特征+浅层 | **CNN + ImageNet** | AlexNet |
| **2** | 2020 | CNN 统治 | **ViT / 自监督** | ViT / MAE / DINOv2 |
| **3** | 2021 | 纯视觉 | **视觉-语言对齐** | CLIP |
| **4** | 2022- | GAN 生成 | **扩散模型** | DDPM / Stable Diffusion |
| **5** | 2023- | 任务专用模型 | **视觉基础模型** | SAM / DINOv2 / Sora |

后文逐一展开。**先从前史讲起**——因为 CNN 不是 2012 凭空出现的。

## 1. 神经科学启发（Hubel-Wiesel 1959）

### 1.1 猫的视觉皮层

1959 年，David Hubel 和 Torsten Wiesel 在约翰·霍普金斯大学（后转哈佛），把微电极插进**猫的初级视觉皮层（V1）**，给猫看各种图案，记录神经元放电。他们发现了两类细胞：

- **简单细胞（simple cells）**：对**特定朝向**的亮暗边缘有选择性放电（一个朝向敏感，换 90 度就沉默）。
- **复杂细胞（complex cells）**：同样朝向选择，但**位置不敏感**——边缘在感受野内移动，细胞持续放电。

这个发现颠覆了对视觉的理解：**视觉皮层不是"逐像素记录"，而是"逐特征层次抽象"**——简单细胞抽边缘，复杂细胞抽平移不变特征，更深层抽更复杂形状。

两人因此获 **1981 年诺贝尔生理学或医学奖**（与 Roger Sperry 共享）。

### 1.2 为什么这是 CV 的"创世记"

🎯 **博士级洞察**：Hubel-Wiesel 给了 CV 第一个、也是最深的归纳偏置——**层次特征抽象 + 局部感受野 + 平移不变性**。这三条后来被硬编码进卷积网络。

但有个反讽：

> **生物视觉的"卷积"1959 年就被发现，但工程实现花了 21 年（Fukushima 1980），再花 9 年才有可训练版本（LeCun 1989），再花 23 年才爆发（AlexNet 2012）= 53 年的复兴。**

这和 [`讲透AI历史`](../讲透AI历史/README.md) 的反常识 1（"神经网络 69 年才复兴"）同构——**想法 vs 时机**：好想法早早就有，但等算力、数据、训练技巧同时到位才能爆发。

### 1.3 早期视觉计算：Roberts 1963 / Guzman 1968

几乎同一时期，CV 的另一条线——**符号-几何路线**——在 MIT 起步：

- **Lawrence Roberts (1963)**：《Machine Perception of Three-Dimensional Solids》博士论文。把图像转成线画（edge detection），再用线画重建多面体的 3D 结构。这是"**视觉 = 逆图形学**"思想的最早工程化——从 2D 反推 3D。
- **Adolfo Guzman (1968)**：《Decomposition of a Visual Scene into Three-Dimensional Bodies》。用顶点类型（L 型、T 型、Y 型、箭头型 junction）的几何约束，把线画分割成多个 3D 物体。这是"**积木世界（blocks world）**"范式的代表。

这两条线和 Hubel-Wiesel 的神经科学看似无关，但它们共享一个信念：**视觉是可以被计算分解的**。Roberts/Guzman 走符号-几何路线，Hubel-Wiesel 走神经-层次路线——这两条路在 1980 年的 Fukushima 和 1982 年的 Marr 那里交汇。

## 2. Marr 计算视觉（1979-1980）

### 2.1 Marr 的三层理论

David Marr（1945-1980）是 CV 史上最深刻的思想家之一。他在 MIT 工作时提出：**理解任何信息处理系统，必须分三个层次**：

| 层次 | 问的问题 | 视觉的对应 |
|---|---|---|
| **计算理论**（computational） | 要算什么？为什么算？ | 从图像恢复 3D 场景（逆图形学） |
| **表示与算法**（representational/algorithmic） | 怎么表示？用什么算法？ | primal sketch → 2.5D sketch → 3D model |
| **硬件实现**（implementational） | 物理上怎么实现？ | 神经元 / 数字电路 |

Marr 还提出了视觉处理的**三阶段**：
1. **初始素描（primal sketch）**：从像素抽边缘、角点、线段、blob（≈ Hubel-Wiesel 的简单细胞输出）。
2. **2.5D 素描（2.5D sketch）**：以观察者为中心，恢复深度、表面朝向、遮挡关系（即"半 3D"——还没到完整物体）。
3. **3D 模型（3D model）**：以物体为中心，恢复物体的完整 3D 结构和语义。

### 2.2 Marr 的悲剧与遗产

**1980 年 11 月，Marr 因白血病去世，年仅 35 岁。** 他的著作《Vision》由其学生 Tomaso Poggio 整理，1982 年出版。

这是 CV 思想史的重大损失：

> 🎯 **反事实推演**：如果 Marr 活到 60 岁（2005 年），计算视觉的"符号-几何重建"路线可能延续更久，CV 的理论根基会更扎实。现实中，他的"分层重建"思想被 2010s 的端到端学习**直接绕过**——CNN 不显式建 primal sketch，而是隐式学特征。

但 Marr 的遗产没死：
- **"逆图形学"**这个核心命题，在 **NeRF（2020）/ 可微渲染 / Gaussian Splatting（2023）** 里复活——它们就是在做"从图像恢复 3D"，正是 Marr 的计算理论层。
- **"视觉是病态问题，需要先验"**这个判断，是本篇全部叙事的基石。

### 2.3 Marr 与 Marr 之后的分裂

Marr 之后，CV 分成两派：
- **重建派**（reconstructionist）：坚持显式建 primal sketch / 2.5D / 3D。代表：Hildreth、Poggio。1980s 主流。
- **特征/识别派**（feature/recognition）：放弃完整重建，直接从图像抽特征做识别。1990s 主流，演化为 SIFT/HOG 时代。

**重建派在 1990s 衰落**——因为"显式重建 3D"太难、太慢、太脆。但它的核心命题（逆图形学）从未消失，只是换了一种实现方式。

## 3. 经典特征时代（SIFT / Viola-Jones / HOG，1990s-2011）

### 3.1 为什么特征工程统治了 20 年

1990s 到 2011，CV 的范式是**"手工特征 + 浅层分类器"**：

```
图像 → [手工特征提取] → 特征向量 → [SVM / 随机森林 / AdaBoost] → 类别
        SIFT/HOG/Haar       128维/...     浅层判别器
```

为什么是这个范式？因为：
1. **神经网络在 1969 被 Minsky-Papert "杀死"**（[`讲透AI历史/03`](../讲透AI历史/README.md)），1986 反向传播虽复活但**算力不够**跑深网。
2. **SVM（Vapnik 1995）/ Boosting** 是当时最先进的学习器——理论优雅、效果好、样本高效。
3. **手工特征把"视觉先验"工程化**——人类把对视觉的直觉编码成 SIFT 的尺度不变、HOG 的梯度方向直方图。

### 3.2 三大里程碑特征

**① Lowe SIFT（1999 ICCV / 2004 IJCV）**——《Distinctive Image Features from Scale-Invariant Keypoints》

SIFT（Scale-Invariant Feature Transform）检测**尺度不变的关键点**，并对每个点输出 128 维描述子。它对旋转、缩放、光照变化鲁棒。**应用**：图像拼接（全景照片）、物体识别、SLAM（同时定位与建图）。

SIFT 是当时"特征工程"的巅峰——把不变性的数学手工雕到极致。

**② Viola-Jones（2001 IJCV）**——《Rapid Object Detection using a Boosted Cascade of Simple Features》

Viola-Jones 解决了**实时人脸检测**：
- 用 **Haar 特征**（黑白矩形模板的差）算超快（用积分图 O(1)）。
- 用 **AdaBoost 级联**（cascade）——先快速排除大量非脸区域，只在"可能含脸"区域细看。
- **第一次让 CV 跑到 15-20 FPS**，装进数码相机。这是 CV 走向工业的标志性时刻。

**③ Dalal-Triggs HOG（2005 CVPR）**——《Histograms of Oriented Gradients for Human Detection》

HOG（方向梯度直方图）：把图像切成小 cell，每个 cell 统计梯度方向直方图，拼成描述子。**行人检测**的 SOTA。和 SIFT 思路一致——把梯度/边缘先验手工编码。

### 3.3 经典特征时代的极限（=CNN 的"异常累积"）

到 2010 左右，经典特征范式开始**累积异常**（库恩的 crisis 前兆）：
- **特征是"瓶颈"**——SIFT/HOG 再精心设计，遇到复杂场景（1000 类物体）就力不从心。ImageNet 2011 的 top-5 错误率卡在 25%+，多年难推进。
- **"特征工程 vs 端到端"之争**——越来越多的人怀疑：为什么不让机器自己学特征？
- **DPM（Deformable Part Models, Felzenszwalb 2008-2010）**是经典特征的最后辉煌——用可变形部件模型做检测，2010 ILSVRC 冠军。但它已经是"手工特征+精巧建模"的复杂度极限。

🎯 **博士级洞察**：经典特征不是"落后"——在算力受限的年代，把人类视觉直觉编码进 SIFT 是当时最优解。它的失败不是"想法错了"，而是**遇到了 ImageNet 这种规模的任务，手工先验的表达力不够**。这为第一次范式转移（CNN）铺好了"危机"的土壤。

## 4. 第一次范式转移：CNN + ImageNet（2012）

### 4.1 神经科学 → 工程实现：Fukushima 与 LeCun

在讲 AlexNet 之前，必须补两块被简化叙事跳过的关键拼图：

**① Fukushima Neocognitron（1980）**

福岛邦彦（Kunihiko Fukushima）受 Hubel-Wiesel 的简单/复杂细胞启发，设计了 **Neocognitron**——一个层次化的网络：S 层（简单细胞，抽特征）和 C 层（复杂细胞，做平移不变池化）交替堆叠。

> 🎯 **Neocognitron 是 CNN 的生物学原型**——卷积（S 层）+ 池化（C 层）的结构第一次被写出来。但它**没有反向传播**（训练靠无监督聚类），所以能力有限，被历史低估。

**② LeCun LeNet（1989-1998）**

Yann LeCun 在 1989 年把反向传播和卷积结合，造出第一个**可训练的 CNN**，用于识别手写数字（读支票上的金额）。LeNet-5（1998）被美国银行系统部署，**每天处理数百万张支票**——这是深度学习最早的工业成功之一。

但 LeNet 只能在"小数据小任务"（10 个数字）上工作。**为什么不放大？**——算力不够、没有大数据集、没有 ImageNet 这种评测。于是 CNN 再次沉睡。

### 4.2 ImageNet：被嘲笑的"笨办法"

**李飞飞（Li Fei-Fei）**，2007 年在普林斯顿/斯坦福，做了一个当时看起来"笨"的决定：**众包标注 1400 万张图片，覆盖 22000 类，分 1000 类做比赛（ILSVRC）**。

> 🎯 **反常识**：ImageNet 诞生时**被同行嘲笑**——"谁需要 1400 万张标注图？""大数据是缺乏理论的笨办法"。李飞飞申请经费屡屡被拒。但她的信念是：**"数据才是关键，不是算法"**——这个判断后来被证明是 CV 史上最具前瞻性的洞察之一。

ImageNet 的真正价值不只是"大"，而是它**同时提供了"大数据"和"标准评测"**——后者（ILSVRC 年度比赛）让不同方法有了可比的擂台。**没有标准评测，就没有范式转移**（库恩：范式需要共识的"解谜"标准）。

### 4.3 AlexNet 2012：引爆时刻

**Alex Krizhevsky + Ilya Sutskever + Geoffrey Hinton**（多伦多大学），用 **两个 GTX 580 GPU** 训练了一个 8 层 CNN（AlexNet），在 ImageNet ILSVRC 2012 上把 top-5 错误率从 26.2%（第二名，经典特征）砍到 **15.3%**——**近 11 个百分点的断层式领先**。

AlexNet 的关键创新（每一个都是"异常→范式转移"的催化剂）：
1. **GPU 训练**——让深网第一次跑得动。GTX 580 是偶然选择（便宜、可用）。
2. **ReLU 激活**——取代 sigmoid，解决深网梯度消失。
3. **Dropout**——正则化，防过拟合。
4. **数据增强**——裁剪、翻转，扩充有效数据。

**为什么是 2012 而不是 2002？**——答案正是思想史要问的：2002 年没有 GPU（CUDA 2007 才出）、没有 ImageNet（2009 才发布）、没有 ReLU 在深网的普及。**三个条件在 2012 同时成熟**，AlexNet 只是点燃了火种。

### 4.4 黄金十年（2012-2020）：CNN 统治

AlexNet 之后，CNN 进入"常规科学"（库恩 normal science）阶段——无数人在 CNN 框架内解谜：

| 年份 | 模型 | 突破 | Top-5 错误率 |
|---|---|---|---|
| 2012 | AlexNet | 引爆 | 15.3% |
| 2014 | VGG（Simonyan-Zisserman）| 简洁的 3×3 卷积堆叠，16/19 层 | 7.3% |
| 2014 | GoogLeNet/Inception（Szegedy）| 22 层，Inception 多尺度模块 | 6.7% |
| 2015 | **ResNet（He et al.）** | **152 层，残差连接** | **3.57%（超越人类~5%）** |
| 2019 | EfficientNet | 复合缩放 | ~2% |

**ResNet（2015）是黄金十年的皇冠**——何恺明等人的残差连接（`y = F(x) + x`）解决了"网络越深越难训练"的退化问题，让网络可以堆到 152 层甚至 1000 层，ImageNet 错误率首次跌破人类。ResNet 是**史上被引用最多的论文之一**（10 万+引用）。

> 🎯 **ResNet 的反常识**：残差连接本质是"给恒等映射开捷径"——看起来 trivial。但它解决了一个深刻的退化问题（不是梯度消失，是优化landscape的退化）。**最简单的想法，最大的影响**——这是 CV 史反复出现的模式（attention、CLIP 对比损失亦然）。

### 4.5 第一次转移的库恩诊断

- **旧范式的异常**：SIFT/HOG 在 1000 类任务上表达力见顶。
- **新范式**：端到端 CNN 学习，放弃手工特征。
- **不可通约性**：经典特征派问"如何设计更好的不变性"，CNN 派问"如何让网络自己学特征"——**换问题了**。
- **老一辈的反应**：经典特征派许多人没有转向，逐渐边缘化。

## 5. 检测分割的繁荣（2014-2020）

CNN 统治期，CV 在"识别"之外开枝散叶——**检测、分割、生成**三大方向爆发。

### 5.1 目标检测：R-CNN 系列 vs YOLO

**① R-CNN 系列（Girshick 2014-）**——"两阶段"检测：
- **R-CNN（2014）**：先用 Selective Search 提候选框（~2000 个），每个框过 CNN，再 SVM 分类。慢但准。
- **Fast R-CNN（2015）**：整图过一次 CNN，再在特征图上裁框——快 100 倍。
- **Faster R-CNN（Ren 2015）**：用 RPN（区域提议网络）替代 Selective Search，端到端。**检测进入实时**。
- **Mask R-CNN（He 2017）**：在 Faster R-CNN 上加分割分支，**同时做检测+实例分割**。

**② YOLO（Redmon 2016）**——"单阶段"检测：《You Only Look Once》。把检测当成回归，一次前向出所有框。**极快（45-150 FPS）**，牺牲一些精度换实时。YOLO 系列（v2-v11）统治了工业检测。

> 检测史是"**精度 vs 速度**"矛盾（[`毛泽东哲学视角`](../讲透AI历史/README.md)：抓主要矛盾）的教科书——R-CNN 系抓精度，YOLO 抓速度，两者后来融合（RetinaNet/Focal Loss，Lin 2017）。

### 5.2 分割：U-Net / DeepLab

- **U-Net（Ronneberger 2015）**：编码器-解码器 + 跳连接，医学图像分割标配。
- **DeepLab（Chen 2014-2018）**：空洞卷积（dilated convolution）扩大感受野，语义分割 SOTA。

### 5.3 生成的预演：GAN 与风格迁移

**① GAN（Goodfellow 2014）**——生成对抗网络：生成器 vs 判别器博弈。**第一次让神经网络生成逼真图像**。但 GAN 训练不稳定、多样性差——这些"异常"后来被 Diffusion 利用，引发第四次转移。

**② Neural Style Transfer（Gatys 2015）**——《A Neural Algorithm of Artistic Style》：用预训练 VGG 的特征，分离"内容"和"风格"，把照片变成梵高风。**第一个引爆大众的 AI 艺术应用**。

这俩是"生成"的预演，但都还没成气候——GAN 的局限要到 2022 年才被 Diffusion 彻底解决。

## 6. 第二次范式转移：ViT 2020

### 6.1 CNN 的"异常累积"

到 2019-2020，CNN 范式开始累积自己的异常：
- **感受野有限**——CNN 看不远，长距离依赖弱（虽然空洞卷积/注意力辅助缓解）。
- **预训练-微调增益见顶**——ImageNet 预训练迁移到下游的提升越来越小。
- **卷积归纳偏置是"天花板"还是"脚镣"？**——越来越多的人问：数据足够多时，硬编码的卷积是不是反而限制？

### 6.2 ViT：把图像当句子

**Dosovitskiy et al. 2020（ViT）**——《An Image is Worth 16×16 Words》做了一个激进决定：

> **把图像切成 16×16 的 patch，每个 patch 当一个 token，塞进标准 Transformer。完全放弃卷积。**

结果：**在 JFT-300M 这种超大数据上，ViT 超过 CNN**；在小数据上不如 CNN（缺归纳偏置）。

🎯 **这是 CV 的"规模胜过手工设计"时刻**，和 GPT-3 在 NLP 的时刻同构。它颠覆了"卷积归纳偏置是视觉必需"的共识——**数据足够多时，模型可以自己学到这些偏置**。

### 6.3 自监督革命：MAE / DINOv2

ViT 之后，CV 之问转向："能不能不靠标注？"

- **MAE（He et al. 2022）**——Masked Autoencoder：挡住图像 75%，让模型重建。**视觉版 BERT**。何恺明从 ResNet（监督巅峰）转向 MAE（自监督），是这个时代的标志性转身。
- **DINOv2（Oquab et al. 2023，Meta）**——自监督 ViT，质量高到可直接当通用特征提取器，无需微调。

🎯 **自监督的哲学转向**：从"人标什么，机器学什么"到"机器从数据结构自己学"。这呼应 LeCun 一直主张的"预测式自监督才是通向 AGI 的路"。

### 6.4 ConvNeXt 反例：卷积没死

**反常识**：2022 年的 **ConvNeXt（Liu et al.）**证明——**纯卷积网络加上现代训练技巧（大数据、强增强、现代优化器）能追平 ViT**。

这说明：**2012-2020 CNN 的统治，部分归功于卷积归纳偏置；但 ViT 的胜出，更多归功于"Transformer 生态+现代训练配方"，而非"注意力本质优于卷积"。** 归纳偏置没有死，是被"数据+训练技巧"淹没后又被重新发现价值。这是避免"胜利者叙事"的典型例子。

## 7. 第三次范式转移：视觉-语言模型（CLIP 2021）

### 7.1 纯视觉的天花板

纯视觉模型（CNN/ViT）有个根本问题：**它学到的是"像素模式"，不是"语义"**。一只猫的 ViT 特征向量，和"猫"这个词的语义没有直接联系。这导致：
- **零样本能力差**——训练时没见过的类别，识别不了。
- **迁移需要微调**——换任务要重训。
- **不能推理**——只能说"这是猫"，不能说"猫在追球"。

### 7.2 CLIP：用语言锚定视觉

**Radford et al. 2021（OpenAI CLIP）**——用 **4 亿图文对**做对比学习：

```
训练: 「一只金黄色的狗」文本 ↔ 狗图  → 拉近嵌入
       「一只金黄色的狗」文本 ↔ 猫图  → 推远
```

结果：**零样本分类**——CLIP 见过"猫"这个词和猫的图，能零样本认出新场景的猫。这是"一个模型做所有任务"的早期范本，也是后来所有 VLM（GPT-4V/Claude vision/Qwen-VL）的视觉编码器基础。

🎯 **CLIP 的反常识**：它的核心创新不是架构（双塔+对比损失很简单），而是**数据（4 亿对）+ 目标（对齐）**。又一个"简单想法+海量数据"的胜利——印证"数据 > 算法"。

### 7.3 VLM 的爆发

CLIP 之后，**视觉-语言模型（VLM）**爆发：
- **LLaVA（2023）**：视觉编码器→投影层→LLM，让 LLM"看图说话"。开源 VLM 范式。
- **GPT-4V / Claude vision / Qwen2-VL**：把 VLM 产品化，进入主流。
- **SigLIP 2（Google 2025）**：改进 CLIP 的对比学习（用 sigmoid 而非 softmax），更强的对齐 backbone。

第三次转移的核心信念：**视觉理解需要语言**。纯视觉的"猫"概念不如"这是一只金黄色的猫在追球"丰富——语言给了视觉以推理能力。这从根本上改变了 CV 的目标——从"识别"到"理解+推理"。

## 8. 第四次范式转移：扩散模型（2022-）

### 8.1 GAN 的极限

GAN（2014）统治了图像生成 8 年，但累积了三个异常：
1. **训练不稳定**——模式崩溃（mode collapse）频发。
2. **多样性差**——生成的图像分布窄。
3. **难可控**——精细控制生成内容需要额外技巧。

### 8.2 Diffusion：老数学 + 新算力

**DDPM（Ho et al. 2020 NeurIPS）**和 **Latent Diffusion（Rombach et al. 2022，Stable Diffusion）**让生成质量飞跃。核心机制：训练一个网络预测"加了多少噪声"，然后反向去噪生成图像。

> 🎯 **反常识**：扩散模型的理论基础——**score matching 和朗之万动力学——1980-90 年代就有**。Yang Song 等人 2019-2020 把它和 DDPM 在数学上统一。**扩散不是 2022 发明的，是"老数学 + 新算力 + 新实现"的爆发。** 又一个"想法等时机"的案例。

### 8.3 为什么 Diffusion 打败 GAN

- **训练稳定**——不像 GAN 的对抗博弈，扩散是简单的去噪回归。
- **多样性好**——覆盖完整数据分布。
- **可控性强**——ControlNet（2023）/ LoRA / 提示词让生成精细可控。

**Stable Diffusion（2022）开源权重**，引爆了大众 AI 绘画。DALL·E（2021，OpenAI）、Midjourney、SD 共同构成了"文生图"时代。

### 8.4 视频生成：Sora 与"世界模型"之争

**Sora（OpenAI 2024）**用 Diffusion Transformer（DiT）生成长视频。它引发了 CV 史上最热的争论之一：**视频生成模型是不是"世界模型"？**

- **是派**：模型能生成物理合理的视频（重力、碰撞、光影），说明它"理解"了物理。
- **不是派**（LeCun 为代表）：生成逼真 ≠ 理解因果。模型只是学了像素相关性，没有真正的因果/物理引擎。LeCun 主张 **JEPA（Joint Embedding Predictive Architecture）**——在抽象表征空间预测，而非像素空间重建。

🎯 **这场争论本身就是 CV 思想史活生生的范式之争**——和 1980s "重建派 vs 特征派"同构。它决定了下一代 CV 的方向。

## 9. 第五次范式转移：视觉基础模型（SAM / DINOv2 / Sora，2023-）

### 9.1 从"任务专用"到"通用基础模型"

2023 起，CV 进入"基础模型"时代——**一个预训练模型，零样本做几乎所有视觉任务**。

### 9.2 SAM：分割万物

**Kirillov et al. 2023（Meta SAM）**——Segment Anything。给它任何图 + 一个提示（点/框/文本），它分割出对应物体。**分割任务的"GPT 时刻"。**

SAM 的核心不是算法突破，而是**数据**：
- **SA-1B 数据集**：**11 亿个掩码**，大部分由 SAM 自己用"学生-教师"自动标注（数据引擎）。
- **可提示（promptable）分割**——统一了所有分割任务的接口。

> 🎯 **SAM 的反常识**：它的成功靠**数据（SA-1B）而非算法**。架构是成熟的 ViT，创新在"数据引擎+提示范式"。又一次印证"数据 > 算法"。SAM 2（2024）扩展到视频。

### 9.3 统一视觉模型：Florence-2 / DINOv2

- **Florence-2（Microsoft 2024）**：一个模型做所有视觉任务（检测/分割/字幕/OCR），用统一的 seq2seq 接口。
- **DINOv2（Meta 2023）/ DINOv3（2025-）**：自监督视觉 backbone，无需微调即可用于各种下游。

### 9.4 3D 与空间智能

**Gaussian Splatting（2023）/ NeRF（2020）**——从 2D 图像重建 3D 场景。这其实是**Marr 的"逆图形学"在可微渲染时代的复活**——Marr 的计算理论层命题，50 年后有了工程实现。

### 9.5 第五次转移的特征

| 特征 | 含义 |
|---|---|
| 通用化 | 一个模型做所有任务（vs 任务专用） |
| 零样本 | 不需微调即用 |
| 多模态融合 | 视觉+语言+动作（VLA） |
| 数据驱动 | SA-1B / 4 亿对——数据是核心资产 |
| 工业化 | SAM 2 / Sora 走向产品 |

## 10. 思想史反思（5 个反常识）

### 反常识 1：卷积归纳偏置的"53 年复兴"——而且没死

- **1959** Hubel-Wiesel 在生物视觉发现卷积式层次结构。
- **1980** Fukushima Neocognitron 工程实现。
- **1989** LeCun 第一个可训练 CNN。
- **2012** AlexNet 爆发。
- **2020** ViT 宣判"卷积已死"。
- **2022** ConvNeXt 证明"卷积没死，只是需要现代训练配方"。

**教训**：好的归纳偏置不会消失，它会被"数据淹没"然后"重新被发现价值"。警惕"X 已死"的宣判。

### 反常识 2：ImageNet 诞生时被嘲笑为"笨办法"

李飞飞申请经费被拒，同行质疑"谁需要 1400 万张标注图"。但**"数据是关键"**这个判断被证明是 CV 史最具前瞻性的洞察之一。**教训**：被嘲笑的"笨办法"可能是真突破——警惕"理论优雅"的陷阱。

### 反常识 3：ResNet 残差 = 看起来 trivial 的恒等捷径

残差连接 `y = F(x) + x` 本质是"给恒等映射开捷径"——看起来 trivial，却解决了深网退化，催生 152 层网络。**最简单的想法，最大的影响。** 何恺明后来从监督学习巅峰（ResNet）转向自监督（MAE）——**反直觉地"放弃标签"**。

### 反常识 4：扩散模型的数学 1980s 就有

Score matching、朗之万动力学是 1980-90 年代的经典。Diffusion 的爆发是"老数学 + 新算力 + 新实现"，不是 2022 的全新发明。**教训**：很多"突破"是旧思想等时机——和 [`讲透AI历史/00`](../讲透AI历史/00-为什么学AI历史.md) 的"backprop 1970 就有，1986 才火"同构。

### 反常识 5：SAM 靠数据而非算法

SAM 的架构是成熟 ViT，创新在 SA-1B（11 亿自动标注掩码）+ 提示范式。**"数据 > 算法"**在 CV 反复应验。**教训**：评估一个"突破"时，先看它靠的是新算法还是新数据——90% 的"SOTA"是旧算法+更多数据。

> 🎯 **博士级训练**：每个反常识都对接一条**判断力**——避免"胜利者叙事"、警惕"X 已死"、识别"营销 vs 真突破"、区分"数据红利 vs 算法红利"。

## 11. 关键人物谱系

### 11.1 Yann LeCun——卷积的坚持者与质疑者

- **轨迹**：Bell Labs → NYU → Meta FAIR（首席 AI 科学家）。
- **贡献**：LeNet（1989，第一个可训练 CNN）、联合发明 LeNet-5（1998）、推动卷积工业化。
- **转向**：从监督 CNN 转向**自监督学习（JEPA）**，坚信"预测式自监督是通向 AGI 的路"。
- **立场**：**公开质疑扩散模型/自回归做世界模型**——认为生成像素≠理解因果。这使他在 2024-2026 的"世界模型"之争中站在反对 Sora 的一方。
- **思想史位置**：连接主义三巨头之一（Hinton/LeCun/Bengio，2018 图灵奖）。他代表了"**归纳偏置不能丢，但要从硬编码转向数据自学**"的中间路线。

### 11.2 李飞飞（Li Fei-Fei）——数据驱动信仰的奠基人

- **轨迹**：普林斯顿 → 斯坦福 → Google Cloud AI/ML 首席科学家 → 独立创业（World Labs，空间智能）。
- **贡献**：ImageNet（2009）——CV 史最重要的数据资产和评测。
- **信念**：**"数据是关键，不是算法"**——这个判断在她做 ImageNet 时被嘲笑，后来被证明是 CV 最具前瞻性的洞察。
- **思想史位置**：她代表了 CV 从"算法中心"到"数据-评测中心"的范式转向。没有 ImageNet，AlexNet 不会被看见。

### 11.3 何恺明（He Kaiming）——从监督巅峰到自监督

- **轨迹**：MSRA（微软亚洲研究院）→ Facebook AI Research（FAIR）→ MIT（2024 加入）。
- **贡献**：**ResNet（2015，史上最高引论文之一）** → Mask R-CNN（2017）→ **MAE（2022，自监督）**。
- **转身**：从监督学习的巅峰（ResNet/Mask R-CNN）转向自监督（MAE）——这是整个 CV 从"监督"到"自监督"转向的个人缩影。
- **思想史位置**：他代表了"**把监督做到极致后，发现天花板，转向自监督**"的路径。ResNet 解决了"怎么训深网"，MAE 解决了"怎么不靠标签学"。

### 11.4 其他关键人物

- **Krizhevsky / Sutskever**（AlexNet 作者）：前者去 Google（后离开），后者成为 **OpenAI 联合创始人/首席科学家**（GPT 系列核心，2024 离开创立 SSI）。
- **Girshick**（R-CNN）：Berkeley → Facebook，检测系列奠基。
- **Redmon**（YOLO）：后**主动退出学术界**（对 AI 伦理的担忧）——罕见的人物选择。
- **Goodfellow**（GAN）：Google → Apple，GAN 之父。
- **Dosovitskiy**（ViT）：Google Brain → Meta。
- **Kirillov**（SAM）：Meta，分割基础模型。

> 🎯 **谱系观察**：CV 2012 后的中心从**学术转向工业实验室**（Google Brain / Meta FAIR / OpenAI / MSRA）。这和 [`讲透AI历史/advanced`](../讲透AI历史/README.md) "资金/机构对 AI 的影响"一致——大模型时代，算力和数据让工业实验室主导了 CV 前沿。

## 12. 失败方向（被淘汰的教训）

### 12.1 手工特征工程（SIFT/HOG/SURF）

**当时为何合理**：算力受限，把人类视觉直觉编码进 SIFT 是最优解。
**为何失败**：在 1000 类任务上表达力不够，被端到端 CNN 超越。
**教训**：手工先验有天花板——遇到规模化任务就会被端到端学习取代。但**SIFT 在 SLAM/全景拼接至今在用**——失败方向不会完全死。

### 12.2 字典学习 / Sparse Coding（Olshausen-Field 1996）

**当时为何合理**：理论优雅——稀疏编码模拟视觉皮层的稀疏表示，数学优美。
**为何失败**：被深度学习的端到端学习淹没——学到的"字典"不如 CNN 特征通用。
**教训**：理论优雅 ≠ 工程有效。CV 是工程驱动的领域。

### 12.3 Marr 的符号-几何重建路线

**当时为何合理**：Marr 的"primal sketch → 2.5D → 3D"是计算视觉的优雅理论。
**为何（暂时）失败**：被 2010s 端到端学习**直接绕过**——CNN 不显式建 2.5D sketch。
**复活**：**NeRF/Gaussian Splatting 在做"逆图形学"**——Marr 的计算理论层命题在可微渲染时代复活。**失败方向可能只是"早生了 40 年"。**

### 12.4 DPM（Deformable Part Models）

**当时为何合理**：2010 ILSVRC 检测冠军，手工特征+可变形部件建模的巅峰。
**为何失败**：R-CNN 一举超越——CNN 端到端学习碾压手工建模。
**教训**：复杂的手工建模在端到端学习面前不堪一击。

### 12.5 GAN（在图像生成上）

**当时为何合理**：GAN（2014）第一次让神经网络生成逼真图像，统治生成 8 年。
**为何（在图像生成上）失败**：训练不稳定、多样性差——被 Diffusion 在质量上取代。
**仍存活**：GAN 在**实时/风格化/超分**仍有价值（推理快）。**失败是局部的，不是全盘的。**

### 12.6 浅层模型（SVM/随机森林）在视觉

**为何失败**：表达力不如深网。
**教训**：被 CNN 全面替代。但在**小数据/可解释**场景仍有用——失败方向不等于无用。

> 🎯 **博士级总结**：失败方向的共同模式——**手工设计遇到规模化任务就被端到端学习取代；理论优雅遇到工程有效性就败下阵；但失败方向往往"局部存活"或"几十年后复活"。** 这正是 [`讲透AI历史/00`](../讲透AI历史/00-为什么学AI历史.md) "失败与成功同等重要"的方法论。

## 13. 路径依赖与偶然性

思想史的核心训练是问"**如果 X 没发生，会怎样**"——这揭示"必然 vs 偶然"的边界。

### 13.1 如果 Krizhevsky 没用 GPU？

AlexNet 的关键是用了两块 GTX 580。**如果当年 GPU 不可用或 CUDA 不成熟（CUDA 2007 才发布），深度学习可能再晚 3-5 年。** CNN 的想法 1989 就有了，但"何时爆发"取决于硬件这个偶然因素。

### 13.2 如果李飞飞没坚持做 ImageNet？

没有标准大数据集 + 标准评测（ILSVRC），CNN 可能继续在"小数据小任务"沉睡。**一个研究者被嘲笑的坚持，改变了整个领域。** 这提醒：**范式转移常由"看似笨"的基础设施工作触发**，不是算法论文。

### 13.3 如果 Marr 没有英年早逝？

计算视觉的"符号-几何重建"路线可能延续更久，CV 的理论根基会更扎实。现实中它被端到端学习绕过——但 NeRF 的复活说明 Marr 的命题没错，只是"早生了"。**人物的生命长度本身塑造了思想史。**

### 13.4 如果 Hinton 圈子没去工业界？

AlexNet 作者（Krizhevsky/Sutskever）和 Hinton 去 Google，深度学习的研究中心从学术转向工业。**如果他们留在多伦多大学，算力/数据优势不会这么快建立**——工业实验室的主导地位部分源于这次人才流动。

### 13.5 ConvNeXt 反例：卷积的"再发现"

2022 ConvNeXt 证明纯卷积+现代训练能追平 ViT。**这说明 ViT 的胜出有"Transformer 生态红利"的偶然成分**——如果当时社区全力优化 CNN 而非 Transformer，CV 可能长成另一个样子。**"现状"里有多少是路径依赖，值得警惕。**

> 🎯 **博士级核心**：CV 当前的样子，是**算力（GPU）、数据（ImageNet）、人物（Hinton 圈子/李飞飞/何恺明）、评测（ILSVRC）**多个偶然交汇的结果。把现状当必然，就会对未来误判。

## 16. 费曼回炉

### F1 · 一句话讲清

> CV 的 67 年（1959-2026），是**"先验"从死板到灵活**的历史——从 Hubel-Wiesel 发现的卷积式生物先验，到 SIFT 手工先验，到 CNN 硬编码先验，到 ViT 让数据自学先验，到 Diffusion 最通用的生成先验。**每次范式更迭，本质是换了一种约束病态逆图形学问题的先验；先验越通用，核心越简单，对数据依赖越大。**

### F2 · 卡壳点（已迭代）

- **长期误区**：把"CV 进步"当成"模型越来越准"的线性进步。重读思想史后意识到——**进步是"换问题"而非"换答案"**：CNN 不是"更会抽特征"，而是把问题从"如何设计不变性"换成"如何让网络自己学"；ViT 不是"更好的 CNN"，而是把问题从"如何编码归纳偏置"换成"如何让数据淹没归纳偏置"。
- **另一个误区**：把 AlexNet 当成"突然的突破"。重读后发现它是**53 年积累的引爆**——Hubel-Wiesel(1959)→Fukushima(1980)→LeCun(1989)→AlexNet(2012)，算力/数据/评测三者在 2012 才同时成熟。
- **第三个误区**：以为"被淘汰的方向=错误方向"。重读失败方向后发现——Marr 的重建路线在 NeRF 复活、SIFT 在 SLAM 仍用、GAN 在实时生成仍活——**失败往往是"早生了"或"局部失效"，不是全盘错误**。

### F3 · 术语翻译（讲给非专业人）

- **逆图形学（inverse graphics）** → 相机拍照是把 3D 世界压成 2D 像素（正向图形学）；CV 是反过来从 2D 像素猜回 3D 世界（逆向）。问题是同一个 2D 图对应无限种 3D 场景——所以是"病态"的，必须加"先验"来缩小可能。
- **先验（prior）** → 在看到证据前，你对答案的预设。CNN 的先验是"一个像素只和邻居相关、猫在哪都是猫"；Diffusion 的先验是"任何图像都能从噪声一步步去噪出来"。先验越死板（如 CNN），样本越省但灵活性差；越灵活（如 Diffusion），越通用但需要海量数据。
- **归纳偏置（inductive bias）** → 模型架构里"硬编码"的对世界的假设。卷积的归纳偏置是"局部性+平移不变"。ViT 的激进之处是"几乎不硬编码任何视觉假设，全靠数据学"。
- **范式转移（paradigm shift）** → 一群研究者共同换了一套"该问什么、怎么答"的游戏规则。从 CNN 到 ViT 不是"更好的 CNN"，是换了"要不要硬编码归纳偏置"这个根本信念。

### F4 · 回炉 diff

- **v1（年代史思维）**：罗列"1959 Hubel-Wiesel → 2012 AlexNet → 2020 ViT → 2022 Diffusion → 2023 SAM"，重心在"何时发生"。
- **v2（思想史）**：每个节点问"**为什么此时**"——卷积为什么 2012 才爆发（算力+数据+评测三者同年成熟）；ViT 为什么敢杀死卷积（数据足够多时归纳偏置可自学）；扩散为什么 2022 才火（老数学+新算力）。**diff 是从"时间线"升级为"因果链 + 路径依赖分析"。**
- **v3（补失败与偶然）**：加上"被淘汰方向"和"如果 X 没发生"的反事实推演——避免胜利者叙事。这是从"赢家故事"到"完整历史观"的升级。
