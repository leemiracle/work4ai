# 🚀 第 5 幕 · 应用：2024-2026 CV 前沿

## 前沿地图

| 系统 | 突破 | 意义 |
|---|---|---|
| **SAM 2** (Meta 2024) | 视频分割万物，零样本 | 分割的工业化 |
| **SigLIP 2** (Google 2025) | 改进 CLIP 对比学习 | 更强视觉-语言 backbone |
| **Florence-2** (Microsoft 2024) | 统一视觉基础模型 | 一个模型做所有视觉任务 |
| **Qwen2-VL** (Alibaba 2024-2025) | 任意分辨率处理 | 解决 VLM 分辨率折中 |
| **GPT-4V / Claude vision** | 视觉推理 | VLM 进入主流 |
| **Sora 2 / Veo 3** (2025) | 视频+音频生成 | 文生视频工业化 |
| **Gaussian Splatting / NeRF** | 3D 重建 | 从 2D 重建 3D |
| **DINOv3** (2025-) | 自监督视觉 backbone | 降低标注依赖 |

## CV 正在和其他宇宙合流

纯 CV（识别/分割）**已基本解决**。前沿在交叉：

- **CV + 世界模型**：视频生成模型是不是视觉世界模型？（见 `讲透世界模型/`）
- **CV + 多模态**：VLM 让视觉会推理（见 `讲透多模态/`）
- **CV + 具身**：机器人视觉（VLA）
- **CV + 3D**：NeRF/Gaussian Splatting → 空间智能

## 应用场景选型

| 场景 | 推荐方案 |
|---|---|
| 图像分类/检索 | CLIP/SigLIP 2 + 向量库 |
| 目标检测 | YOLO 系列（实时）/ Florence-2（统一）|
| 分割 | SAM 2（零样本）/ DeepLab（精度）|
| 文生图 | Stable Diffusion 3 / DALL-E 3 / Midjourney |
| 视频生成 | Sora 2 / Veo 3 / Runway |
| 视觉问答 | GPT-4V / Claude vision / Qwen2-VL |
| 3D 重建 | Gaussian Splatting（快）/ NeRF（精度）|
| 机器人视觉 | VLA（Vision-Language-Action）|

## 五条经验法则

1. **基础任务（分类/检测/分割）用预训练 backbone + 轻量微调**。
2. **生成任务用 diffusion + ControlNet 引导**。
3. **视觉推理用 VLM，别自己搭**。
4. **3D 任务用 Gaussian Splatting（比 NeRF 快）**。
5. **adversarial robustness 是生产硬要求**（关键系统加对抗训练）。

## 🎬 五幕收束

> CV 三次范式更迭（CNN→ViT→Diffusion/VLM）= 先验从死板到灵活。**先验越通用 = 核心熵减越彻底 = 边缘越能发散**。纯 CV 已基本解决，前沿在与世界模型/多模态/具身合流。
>
> CV 的本质难题（2D 反推 3D 病态问题）没消失——**当前 CV 是高级模式匹配，不是真正「理解」视觉**。真正的视觉理解可能需要世界模型（因果）+ 具身（能动）+ 抽象（JEPA）。
