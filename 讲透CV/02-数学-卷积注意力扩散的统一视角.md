# 📐 第 2 幕 · 数学：卷积、注意力、扩散的统一视角

三种范式（CNN/ViT/Diffusion）的数学骨架，以及它们如何统一。

## 1. 卷积：参数共享的局部线性

2D 卷积核 $K \in \mathbb{R}^{k \times k}$ 在图像 $X$ 上滑动：

$$(K * X)_{ij} = \sum_{u,v} K_{uv} \cdot X_{i+u, j+v}$$

**三个归纳偏置硬编码**：
- **局部性**：$k$ 有限，只看邻域
- **平移不变**：同一 $K$ 在所有位置共享
- **层次**：多层堆叠，感受野递增

**参数量**：$k^2 \cdot C_{\text{in}} \cdot C_{\text{out}}$，与图像大小无关。这是 CNN 高效的根。

## 2. Attention：动态权重的全局聚合

ViT 把图像切成 patch，每个 patch 投影成 token $\mathbf{x}_i \in \mathbb{R}^d$。self-attention：

$$\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

$Q = XW_Q, K = XW_K, V = XW_V$。

**vs 卷积**：
- 卷积：权重固定，只看局部
- attention：权重**动态**（取决于 query），看**全局**

**复杂度**：$O(n^2 d)$，$n$ 是 token 数。这就是为什么 ViT 处理大图比 CNN 慢——但数据足够时效果更好。

**关键洞察**：**卷积是 attention 的特例**。当 attention 权重矩阵是稀疏带状（只关注邻域），等价于卷积。CNN 把「局部」硬编码，ViT 让模型自己学。

## 3. ViT 的 patch embedding

图像 $X \in \mathbb{R}^{H \times W \times C}$ 切成 $N = HW/P^2$ 个 patch，每个 $P \times P \times C$。展平线性投影：

$$\mathbf{x}_i = \text{flatten}(X_{p_i}) \cdot E + \mathbf{e}_i^{\text{pos}}$$

$E$ 是投影矩阵，$\mathbf{e}_i^{\text{pos}}$ 是位置编码（attention 本身无位置概念）。

**这就是「图像变 token 序列」**——之后和 NLP 的 Transformer 完全一样。

## 4. CLIP / InfoNCE：对比对齐

CLIP 训练：图像编码器 $f_v$，文本编码器 $f_t$，batch 内 $N$ 对 $(I_i, T_i)$。

**InfoNCE loss**：

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^N \log \frac{\exp(\text{sim}(f_v(I_i), f_t(T_i))/\tau)}{\sum_{j=1}^N \exp(\text{sim}(f_v(I_i), f_t(T_j))/\tau)}$$

**直觉**：分子是正对（图 $I_i$ 配它真实描述 $T_i$）的相似度，分母是它和 batch 内所有描述的相似度和。**最大化正对、最小化负对**。

**为什么有效**：把「图和文是同义」这个语义关系，编码成 embedding 空间的几何接近。学完后，零样本检索/分类都能做。

## 5. DDPM：去噪生成

**前向加噪**（固定）：
$$q(x_t \mid x_0) = \mathcal{N}(x_t; \sqrt{\bar\alpha_t} x_0, (1-\bar\alpha_t) I)$$

$\bar\alpha_t = \prod_{s \leq t} \alpha_s$，$t$ 从 0（纯数据）到 $T$（纯噪声）。

**反向去噪**（学习）：
$$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t))$$

**简化 loss**（Ho 2020）：
$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

$\epsilon$ 是前向加的噪声，$\epsilon_\theta$ 是学到的去噪网络。**让网络预测噪声，再减掉**。

**生成的魔法**：从 $x_T \sim \mathcal{N}(0, I)$ 出发，反复 $\epsilon_\theta$ 去噪，得到 $x_0$——一张全新图像。

## 6. 三者统一：都是表征学习

| 范式 | 学什么 | 先验 |
|---|---|---|
| CNN | 卷积特征 | 局部+平移 |
| ViT | attention 权重 | 通用（数据学）|
| CLIP | 跨模态对齐 | 文图同义 |
| Diffusion | 去噪方向 | 数据分布的梯度 |

**统一视角**：它们都在学一个**表征函数** $f_\theta$，让 $f_\theta(x)$ 在某任务上有用。区别在**用什么 loss 驱动**（分类 / 对比 / 重建）。

**CV 的方向**：先验从「架构硬编码」（CNN）→「数据学」（ViT）→「跨模态对齐」（CLIP）→「分布建模」（Diffusion）。**越来越通用，越来越像统一的基础模型**。

> CV 三范式 = 卷积（局部线性）+ attention（动态全局）+ diffusion（去噪分布）+ CLIP（对比对齐）。统一视角：**都是在学表征，差别在 loss 和先验**。先验越通用 = 核心熵减越彻底 = 边缘越能发散。
