## 一、为什么要交叉学习

艺术与 AI 的交汇点 = **本系列最活跃的前沿**。AI 艺术（Stable Diffusion / 风格迁移 / 多模态）是当下最具创造力的领域之一。

- **艺术课**：补美学/史论/创作直觉（艺术为什么"好"）
- **讲透 X 系列**：补生成模型的数学/工程（AI 怎么"生成"）

## 三、双向学习建议

### 3.1 艺术 → ML 的「补工程」路径

| 艺术概念 | 补这篇 work4ai |
|---|---|
| **Stable Diffusion 怎么工作** | [`讲透生成模型`](../讲透生成模型/)（DDPM/Score）|
| **CLIP 怎么对齐文图** | [`讲透多模态`](../讲透多模态/) |
| **风格迁移的 Gram 矩阵** | [`讲透基础模型`](../讲透基础模型/)（CNN 特征）|
| **神经辐射场 NeRF** | [`讲透CV`](../讲透CV/) |
| **生成视频（Sora）** | [`讲透世界模型`](../讲透世界模型/) |
| **艺术中的分形/比例** | [`top-math`](../top-math-courses/)（分析/几何）|

### 3.2 ML → 艺术的「补美学」路径

| ML 主题 | 艺术验证/延伸 |
|---|---|
| **讲透生成模型 Diffusion** | 复现简化 Stable Diffusion → 生成图像 |
| **讲透多模态 CLIP** | 用 CLIP 做文本引导生成 |
| **讲透CV** | 神经风格迁移实战（Gatys 2015）|
| **讲透基础模型 CNN** | 理解"特征层级"=艺术感知层级 |
| **讲透世界模型** | 视频生成 = 世界模拟（Sora 路线）|

## 六、典型学习路径示例

### 路径 A：从 0 到 AI 艺术创作者

```
第 1 阶段（美学地基，3 个月）
  ├─ 央美《中国美术史》(中国大学MOOC) + 李泽厚《美的历程》
  ├─ 贡布里希《艺术的故事》（通读）
  └─ art_demos.py 实跑（黄金比例/色彩/透视）→ 理解"美的数学"

第 2 阶段（现当代 + 中西对话，3 个月）
  ├─ 现代主义（塞尚→杜尚→抽象→观念）
  ├─ 中国写意（谢赫六法/书法/留白）
  └─ 东风西渐与西风东渐（林风眠/赵无极/吴冠中）

第 3 阶段（AI 艺术，3+ 个月）
  ├─ 讲透生成模型（Diffusion 数学）
  ├─ 讲透多模态（CLIP 文图对齐）
  ├─ 本地 Stable Diffusion 实战（不依赖外网）
  └─ 风格迁移复现（art_demos.py 概念 → 真实 CNN）
```
