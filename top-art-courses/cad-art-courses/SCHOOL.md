# 中央戏剧学院 CAD · 中国戏剧教育最高学府（艺术校 #6 · 主题⑥戏剧舞蹈）

> **定位**：中国**唯一一所教育部直属**戏剧高等学府（与 BFA 对称：北电管电影、中戏管戏剧），1949 年正式命名（前身可追溯至 1938 年延安鲁迅艺术学院戏剧系及国立戏剧专科学校）。代表中国**话剧表演、导演、戏剧文学、舞台美术**的最高水准，是**主题⑥（戏剧与舞蹈）**的唯一主力入口校。
> **核实状态**：⚠️ 院系结构为稳定公开常识（教育部直属 + 六大系为公众知识）；具体课程编号/开课状态待 `zhongxi.cn` 教务处 + 中国大学MOOC 二次核实。

## 五、中西对话视角（中国戏剧的独立传统与对话）

中戏的独特价值在于**中国话剧与西方戏剧的对话 + 京剧国粹传承**：

- **话剧（西方引入）vs 京剧（中国本土）**：中戏同时设话剧系与京剧系——这象征了 20 世纪中国戏剧的核心张力：**接受西方话剧体系（斯坦尼/布莱希特/荒诞派）的同时，守护中国戏曲传统（京剧/昆曲/地方戏）**
- **斯坦尼斯拉夫斯基体系的中国化**：中戏表演系以斯坦尼体系（体验派）为核心训练方法——这是西方戏剧理论在中国的**最深层植入**。但同时，中国戏曲的"程式化表演"（虚拟/象征/写意）与斯坦尼"体验真实"形成根本对话：**写意 vs 写实在表演中的映射**（呼应 README 东西方第五张力）
- **欧阳予倩的双线**：话剧先驱 + 京剧旦角 = 一个人身上浓缩了中西戏剧的对话可能
- **布莱希特与中国戏曲**：布莱希特 1935 年在莫斯科看梅兰芳演出 → 提出"间离效果"（Verfremdungseffekt），**中国戏曲启发了西方现代戏剧理论**——这是中西戏剧对话中最著名的案例之一 ⭐
- **林兆华的"中国导演学派"**：融合传统戏曲的节奏/空间感与现代话剧叙事 → 试图建立**不依赖西方模式的独立导演语言**

**学习路径**：中戏戏剧理论（斯坦尼体系基础）→ 《茶馆》（中国话剧经典）→ 布莱希特 × 梅兰芳（中西对话）→ 京剧（中国戏曲传统）→ 实验戏剧。
