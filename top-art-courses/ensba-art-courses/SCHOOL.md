# 巴黎国立高等美术学院 ENSBA · 学院派源头与徐悲鸿留法母校（艺术校 #10 · 国际补充）

> **定位**：巴黎国立高等美术学院（École Nationale Supérieure des Beaux-Arts，简称 Beaux-Arts / ENSBA），1648 年由法国宰相**科尔贝**（Jean-Baptiste Colbert）与首席宫廷画家**勒布伦**（Charles Le Brun）创立（前身为 Académie Royale de Peinture et de Sculpture，皇家绘画与雕塑学院）。**西方学院派（Académisme）的源头**——博纳（Bonnat）体系/安格尔/大卫构建了"素描为地基、古典为标杆"的训练传统，统治欧洲 19 世纪美术教育。**徐悲鸿 1919-1927 留法母校**——中国现代美术教育（央美体系）的直接源头。
> **核实状态**：✅ 历史地位（1648 创立 / 学院派源头 / 徐悲鸿留法）为稳定公开常识；⚠️ 现代课程设置待 `beauxartsparis.fr` 官网核实。

---

## 一、历史与学科（历史地位 ✅ · 现代课程 ⚠️）

### 历史身份（核心价值）

| 时段 | 事件 | 意义 |
|---|---|---|
| **1648** | Colbert + Le Brun 创立 Académie Royale de Peinture et de Sculpture | **法国学院派源头**；将艺术教育制度化为国家工程 ⭐ |
| 17-18c | **大卫（David）/ 安格尔（Ingres）**时代 | 新古典主义 = 学院派最高标准；素描/历史画为最高等级 |
| 19c | **博纳（Léon Bonnat）**体系 | "素描为地基"的训练方法 → 经徐悲鸿传入中国 ⭐⭐ |
| 1863 | 理论家/批评体系成熟 | 学院 vs 落选沙龙（马奈/印象派反叛）—— **张力①②③的历史战场** |
| **1919-1927** | **徐悲鸿留法** | 在 ENSBA 学习写实主义/素描体系 → 归国创立中央美术学院 ⭐⭐⭐ |

> ⭐⭐⭐ **徐悲鸿留法 = 中国现代美术教育最关键的"文化输入"**：徐悲鸿 1919 年赴法入 ENSBA（师从达仰 Pascal Dagnan-Bouveret），1927 年归国，将法国学院派"素描地基 + 写实标准"系统引入中国 → 1946 年任国立北平艺专校长 → 1950 年创立中央美术学院。**央美的"徐悲鸿体系"根在 ENSBA**。

### 现代学科设置（⚠️ 待核实）

| 方向 | 说明 | 对应主题 |
|---|---|---|
| **Art（艺术）** | 绘画/雕塑/装置/多媒体/影像 | 主题②③⑧ ⭐ |
| **Théorie de l'art（艺术理论）** | 艺术史/美学/批评 | 主题① ⭐ |
| **Design / Graphisme（设计/平面）** | 平面设计/视觉传达 | 主题④ |
| **Photographie（摄影）** | 当代摄影 | 主题⑦ |
| **Sérigraphie/Gravure（丝网/版画）** | 传统版画工作室 | 主题②③ |

> ⚠️ 现代 ENSBA 已彻底转型为**当代艺术学院**（不再教古典学院派技法），与 19 世纪博纳体系时期截然不同。但其**历史身份**（学院派源头）和**徐悲鸿连接**使其在本系列中具有独特地位。

## 二、招牌人物（学院派大师 + 中国连接）

| 人物 | 生卒年 | 领域 | 意义 |
|---|---|---|---|
| **勒布伦**（Charles Le Brun）| 1619-1690 | 绘画/理论 | **学院联合创立者**；路易十四首席画家；凡尔赛宫装饰 |
| **雅克-路易·大卫**（Jacques-Louis David）| 1748-1825 | 新古典主义绘画 | **学院派巨匠**；《荷拉斯兄弟之誓》《马拉之死》；拿破仑首席画家 ⭐ |
| **安格尔**（Jean-Auguste-Dominique Ingres）| 1780-1867 | 新古典主义绘画 | **学院派最高代表**；素描为"艺术的诚实"——"素描是艺术的骨骼" ⭐ |
| **博纳**（Léon Bonnat）| 1833-1922 | 绘画/教育 | **博纳体系**：素描地基 + 明暗造型 → **徐悲鸿的间接师承** ⭐⭐ |
| **布格罗**（William-Adolphe Bouguereau）| 1825-1905 | 学院派绘画 | 19c 学院沙龙标杆；超写实人体/神话——后被印象派/现代主义"颠覆" |
| **达仰**（Pascal Dagnan-Bouveret）| 1852-1929 | 自然主义/肖像 | **徐悲鸿在法直接导师** ⭐⭐⭐ |
| **徐悲鸿**（留法 1919-1927）| 1895-1953 | 写实主义/美术教育 | **ENSBA → 央美的关键桥梁**；中国现代美术教育奠基人 ⭐⭐⭐ |

> ⭐ **大卫（David）+ 安格尔（Ingres）**是理解**张力①（模仿 vs 表现）的西方极点**：新古典主义 = 极致模仿（理性/秩序/古代典范）。当印象派（莫奈）/现实主义（库尔贝）反叛学院时，**张力①的历史战场就在 ENSBA 门口**（落选沙龙 1863）。

> ⭐⭐⭐ **徐悲鸿 × ENSBA × 央美**：本系列的**中国旗舰校（央美 #1）与国际校（ENSBA #10）存在直接血脉连接**。理解央美"素描地基 + 写实标准" → 必须回溯 ENSBA 博纳体系。这是本系列**中西艺术教育血脉**的关键节点。

## 五、如何从中国大陆访问 + 与中国艺术的对话

### 访问策略
1. **数字馆藏（核心）**：
   - **卢浮宫**（`louvre.fr`）：大卫《荷拉斯兄弟之誓》《拿破仑加冕》、安格尔《土耳其浴女》——学院派核心馆藏。.fr 域名在中国大陆**通常可访问**（速度可能慢）
   - **奥赛博物馆**（`musee-orsay.fr`）：学院派 vs 印象派的历史战场（布格罗 vs 莫奈/马奈）
   - **Wikimedia Commons**：大卫/安格尔/布格罗高清公共域图像
2. **纪录片/讲解**：B站搜"新古典主义""大卫""安格尔""学院派""印象派落选沙龙"——中英文纪录片/讲解极其丰富
3. **徐悲鸿连接**：
   - **中国美术馆**（徐悲鸿国画/油画常设/特展）
   - **《徐悲鸿传》**（中文传记丰富：廖静文《徐悲鸿一生》/徐伯阳编）
   - B站搜"徐悲鸿""徐悲鸿素描"——作品高清 + 纪录片
4. **学院派理论**：安格尔论素描（"素描是艺术的骨骼"）→ 中文美术教育书系（央美/国美基础训练，间接传承博纳体系）

### 与中国艺术的对话（徐悲鸿 × ENSBA × 央美 = 本系列核心血脉）

- **徐悲鸿的文化输入路线**：ENSBA 博纳体系（素描地基 + 写实标准）→ 徐悲鸿 1927 归国 → 国立北平艺专 → 1950 中央美术学院 → **央美"徐悲鸿体系"成为中国 20 世纪美术教育主流**。**ENSBA 是央美的"祖宗"之一** ⭐⭐⭐
- **"素描为地基"的中法传承**：安格尔"素描是艺术的骨骼" → 博纳体系 → 徐悲鸿"素描是一切造型艺术的基础" → 央美造型基础训练。**一条从巴黎到北京的素描传承链**
- **学院派 vs 印象派 = 中国美术教育的"路线之争"映射**：
  - ENSBA 学院派（理性/秩序/古代典范）vs 印象派（光/色/感觉/反叛）= **西方内部的张力①**
  - 央美徐悲鸿体系（写实/素描/社会功能）vs 国美林风眠体系（中西融合/表现/形式探索）= **中国内部的张力①映射**
  - **两个国家内部的"路线之争"惊人地平行**：都是"理性写实" vs "感性表现"的张力 ⭐
- **安格尔 vs 徐悲鸿的"中西融合"**：安格尔坚守新古典主义（西方学院正统）；徐悲鸿用西方写实技法改造中国画（跨文化嫁接）——**徐悲鸿走得更远：他不是在西方体系内做选择，而是把西方体系嫁接到中国土壤**
