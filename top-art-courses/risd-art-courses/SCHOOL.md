# 罗德岛设计学院 RISD · 美国设计教育 #1（艺术校 #8 · 国际补充）

> **定位**：罗德岛设计学院（Rhode Island School of Design），1877 年创立于美国罗德岛州普罗维登斯。美国**公认排名最高**的设计学院（常与 Parsons、Pratt、ArtCenter 并列但 design 排名常年 #1）。与布朗大学（Brown University）比邻，两校可互选课程。强项：插画（Illustration）、工业设计、平面设计、玻璃艺术、珠宝设计。校友广泛分布在 Pixar/Google/IDEO 等创意科技企业。
> **核实状态**：✅ 历史地位（1877 创立 / 美国设计 #1 / 插画强项）为稳定公开常识；⚠️ 当前课程编号/开放课程清单待 `risd.edu` 官网 + OpenCourseBook 核实。

## 五、如何从中国大陆访问 RISD 资源 + 跨文化对话

### 访问策略
1. **官网**：`risd.edu`（.edu 域名在中国大陆**通常可访问**，但速度可能不稳）。OpenCourseBook（`cis.risd.edu`）可查课程大纲
2. **作品集/毕业展**：RISD 官网有学生作品展示 → B站搜"RISD 作品集""罗德岛设计学院毕业展"有大量展示/分析
3. **讲座/采访**：YouTube/Vimeo → **转 B站搬运**
4. **核心可替代学习**：
   - RISD **插画方法论** → B站"插画教程"系列（人体结构/色彩/构图/角色设计）
   - RISD **Foundation Year 理念** → B站"设计基础""立体构成""色彩构成"
   - RISD **工业设计作品集** → B站"工业设计作品集"（申请 RISD 级别的训练）
5. **Shepard Fairey 与视觉传达**：Fairey 的 Obama "HOPE" 海报 = 当代平面设计如何介入政治（呼应 README 张力③自律 vs 他律——设计的社会介入）

### 中西对话视角
- **RISD 插画 vs 中国连环画/绘本传统**：RISD 的插画重"叙事 + 视觉风格"（Chris Van Allsburg 绘本传统）；中国传统有连环画/年画/绣像——**两者都是"图绘叙事"，但风格语言完全不同**（西方重光影体积，中国重线条笔墨）
- **美国工坊传统（Studio Culture）vs 中国师徒制**：RISD 强调"Studio"（工坊/工作室）实践文化——动手做（making）是核心。中国的师徒制（非遗传承）也强调动手——**东西方在"做"（craft）这一点上有共鸣**
- **RISD × Pixar 与中国动画**：Pixar 视觉风格背后的 RISD 插画/动画校友 → 对比中国"动画学派"（上海美影厂水墨动画）——**两种动画美学的平行与对话**
