# Exercises · 讲透 AI 系统逆向工程

> 每章末尾的练习题汇总 + 一套"毕业练习"。所有练习都基于**公开 APK / 自造靶子 / 开源工具**，不涉及任何商业系统。
>
> 答题建议：先把题目思考 30 分钟（写在 markdown 里），再开始动手。遇到卡壳看对应章节，不要硬刚。

---

## 一、入门级（每章 1 题，共 10 题）

### 00 章 · 开场与心态

**Q1**：找一份你**合法持有**的 APK（自己写的应用 / F-Droid 上下载的开源应用），用 `unzip -l` 看看里面的 assets/ 目录有什么。**数一数有多少个 .so / .db / 模型文件**。这是逆向的第一步：观察。

**预期产出**：一份 50 字内的观察笔记。

### 01 章 · 准备层

**Q2**：找一个开源 Android 应用（如 VLC / NewPipe），用 `apktool d` 解包。看 `AndroidManifest.xml`，找出它用了哪些权限、入口 Activity 是什么。

**预期产出**：一份 markdown 表格（权限 + 入口）。

### 02 章 · DEX 反编译

**Q3**：写一个简单 Java 类（含 `List<NoteSlot>` 泛型字段 + `@androidx/annotation/Keep` 注解），用 `javac` + `d8` 编译成 dex。用 androguard 反编译，验证：
- 字段名是否明文？
- Signature annotation 是否包含真实泛型？
- @Keep annotation 是否存在？

**预期产出**：3 个 YES/NO 答案 + androguard 输出片段。

### 03 章 · 二进制格式逆向 ★

**Q4**：用 `flatbuffers` Python 库写一个 5 字段 schema（field_a: int, field_b: string, field_c: [float], field_d: bool, field_e: long），build 出 buffer。**不要看 schema**，用 vtable walker（参考 [experiments/03_flatbuffer_walker.py](experiments/03_flatbuffer_walker.py)）反推。你能恢复几个字段？

**预期产出**：反推结果 + 与原 schema 的对照表。

### 04 章 · 动态插桩

**Q5**：写一个简单 Android app（含一个 native 方法 `int add(int a, int b)`），在 Waydroid 或真机上跑通第一个 Frida hook，dump 出 `add(1, 2)` 的调用现场。

**预期产出**：frida hook 脚本 + hook 输出。

### 05 章 · 数据反推

**Q6**：写一个自造的 SQLite db（5 张表，每张 10-100 行），用本章节的脚本 dump 出 schema + 样本。再复制 db 改几行，用 diff_tables 比对差异。

**预期产出**：db 文件 + diff 输出。

### 06 章 · 模型恢复 ★

**Q7**：用 `torchvision.models.mobilenet_v3_small()` 创建一个模型，save 成 state_dict。然后**只读 state_dict 文件**（不看代码），用 `torch.load` 加载到新建的 model，跑一张猫的图片。能否正确分类？

**预期产出**：state_dict 文件 + 推理输出（top-5 类别 + 概率）。

### 07 章 · 同构对比

**Q8**：找一份你常厂商的开发者平台公开 SDK 文档（华为 HMS / 小米 MIUI SDK / 任意厂商），翻 1 小时，列出：
- 哪些 API 文档对逆向有用？
- 哪些信息你已经能从 APK 反编译拿到？
- 哪些是文档独有的（蓝海信息）？

**预期产出**：3 列对照表。

### 08 章 · LLM 辅助

**Q9**：用 `objdump -d` dump 你自己写的一个简单函数（如快速排序），把汇编喂给 GPT-4 / Claude / GLM（任选），让它反推回 C 代码。和原代码对比，准确率多少？

**预期产出**：原 C 代码 + LLM 反推的 C 代码 + 差异分析。

### 09 章 · 反逆向手段

**Q10**：如果你是厂商，要保护一个端侧 AI 模型，你会优先在 L1-L7 哪一层投入？为什么？（参考 [09 章](09-反逆向手段与对策.md) 的 7 层模型）

**预期产出**：一篇 300 字的"假如我是厂商"短文。

## 二、进阶级（跨章节综合题）

### Q11 · 端到端反推一个小型 TFLite 模型

找一个开源的 MobileNetV3 TFLite 模型（HuggingFace 上有）：
1. **观察**：用 `xxd | head` 看头部，用 `strings` dump 所有字符串（找 layer name）
2. **反推**：用 `flatc --json` 解析 schema
3. **同构对比**：找到 torchvision 的 MobileNetV3 PyTorch 实现
4. **装载**：把 TFLite 权重装载到 PyTorch
5. **验证**：用同一张图片跑两个模型，diff 输出

**预期产出**：完整 5 步报告 + 还原度（应该 99%+）。

### Q12 · 反推一个 jieba 中文分词器

用 `marisa_trie` 库 + jieba 开源词典：
1. 加载 jieba 主词典（35 万词）
2. 写一个简单分词函数（最长匹配 + 词长分布统计）
3. 测试 100 个中文句子的分词准确率
4. 找 5 个分词错误，分析原因

**预期产出**：分词器 Python 代码 + 100 句测试报告 + 5 个错误分析。

### Q13 · 模拟反逆向对抗

写两个版本的同一个 Java 类：
- **版本 A**：标准实现，Signature 注解正确
- **版本 B**：Signature 注解被故意混淆（指向无关字符串）

各编译成 dex，用 androguard 解析，对比输出。然后写一个 Frida 脚本，通过运行时反射恢复真实泛型。

**预期产出**：两份 dex + androguard 输出对比 + Frida 反射脚本。

## 三、毕业级（独立项目）

### Q14 · 完整逆向一个合法持有的闭源 AI 应用

找一个你**合法持有**的闭源 AI 应用（手机上的助手 / 输入法 / 相册 app 等），按本教程的**五步法**走一遍：
1. 观察（30 分钟）
2. 假设（1 小时）
3. 反推（半天-1 天）
4. 实测（半天）
5. 验证（对拍，1 小时）

写一份 500 字的"我的第一次逆向"——记录：
- 你攻下了什么（哪些信息可以确认）
- 你卡在了什么（哪些黑盒未还原）
- 你有什么意外发现（惊喜 / 失望）
- 你认为这个 AI 系统的工程亮点是什么

**预期产出**：一份完整的逆向报告（可以发布博客，但严格脱敏）。

### Q15 · 设计一个反逆向方案

反过来，**假如你是厂商**，要发布一个端侧 AI 应用。设计一个分层反逆向方案：
- L1-L7 每层你用什么手段？
- 成本 vs 防御强度如何权衡？
- 你能保证逆向者投入多少时间才能 95% 还原？

**预期产出**：一份"反逆向设计文档"（不超过 1000 字）。

## 四、思考题（不要求动手）

### T1 · 法律边界

如果一个人 A 逆向了商业 AI 系统，把方法论写成博客发布（不复述具体细节），另一个人 B 照着博客对同一系统逆向并发布完整内部细节。A 和 B 谁违法？为什么？

### T2 · 道德边界

逆向一个端侧 AI 输入法，发现它在偷偷上传用户输入到云端。你应该：
- 通知厂商？
- 发布漏洞？
- 通知监管？
- 沉默？

每种选择的法律 / 道德后果是什么？

### T3 · 技术演进

LLM4Decompile 在 2024 是 50%，2025 是 64.9%。如果 2027 达到 90%，会对逆向工程生态产生什么影响？
- 反编译工程师会失业吗？
- 厂商的反逆向手段会怎么演进？
- 安全审计的成本会下降还是上升？

### T4 · 商业模式

如果未来法律规定所有 AI 系统必须开源，对厂商、用户、研究者的影响是什么？这种法律的正面 / 负面效应？

## 五、参考答案要点

> 不给完整答案，只给方向提示。完整答案自己想出来才有用。

- **Q1 提示**：观察清单应该包含 .so / .db / 模型 / 词典 / 配置五类。
- **Q4 提示**：5 字段都能反推——关键是看 offset 落在 ASCII / vector 区域的候选。
- **Q7 提示**：torch.load 加载 state_dict + model.load_state_dict() + model.eval()。
- **Q11 提示**：用 `flatc --json --schema model.tflite` 拿到 JSON，再写个 mapping 脚本。
- **Q14 提示**：永远从 Step 1 观察开始，不要急着反编译。95% 的信息在 strings + unzip -l 里。
