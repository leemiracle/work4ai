  The compilation pipeline defines the pattern rules and build recipes used to transform source files into executables. This system is implemented in [build/rules.mk](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk) and orchestrates C/C++ compilation, static library creation, asset embedding, and dual-architecture linking to produce Actually Portable Executables (APE). It also manages the patch system for external submodules like `llama.cpp`, `whisper.cpp`, and `stable-diffusion.cpp`.

 
---

 
## Purpose and Scope

 The compilation pipeline provides:

 
 - **Pattern rules** for compiling `.c`, `.cc`, and `.cpp` files into object files [build/rules.mk16-31](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L16-L31)
 - **Dual-architecture compilation** that produces both x86_64 and aarch64 builds simultaneously [build/rules.mk68-71](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L68-L71)
 - **Extension-preserving rules** to handle filename collisions (e.g., `ggml/src/ggml.c` and `ggml/src/ggml.cpp` in `llama.cpp`) [build/rules.mk36-54](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L36-L54)
 - **Submodule Patch Management** to adapt upstream code for llamafile's build system and Cosmopolitan Libc [Makefile89-128](https://github.com/mozilla-ai/llamafile/blob/43551265/Makefile#L89-L128)
 - **Asset embedding** via `zipobj` for resources like web UIs or model weights [build/rules.mk104-108](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L104-L108)
 
 All compilation occurs under the `o/$(MODE)/` output directory [build/config.mk64](https://github.com/mozilla-ai/llamafile/blob/43551265/build/config.mk#L64-L64) where `MODE` defaults to the build mode (e.g., `opt`, `dbg`) [build/config.mk47-52](https://github.com/mozilla-ai/llamafile/blob/43551265/build/config.mk#L47-L52)

 The `setup` process performs the following for each submodule (e.g., `llama.cpp`):

 
 - **Initialization**: Clones the submodule and nested dependencies [Makefile107-112](https://github.com/mozilla-ai/llamafile/blob/43551265/Makefile#L107-L112)
 - **Modification**: Applies `.patch` files using the `apply-patches.sh` script [Makefile114](https://github.com/mozilla-ai/llamafile/blob/43551265/Makefile#L114-L114)
 - **Injection**: Copies llamafile-specific files from `llamafile-files/` (such as `BUILD.mk`) into the submodule directory [llama.cpp.patches/llamafile-files/BUILD.mk1-5](https://github.com/mozilla-ai/llamafile/blob/43551265/llama.cpp.patches/llamafile-files/BUILD.mk#L1-L5)

## Compilation Variables

 The pipeline uses predefined variables that combine toolchain paths with flags:

 
| Variable | Definition | Purpose |
|---|---|---|
| COMPILE.c | $(CC) $(CCFLAGS) $(CFLAGS) $(CPPFLAGS_) $(CPPFLAGS) $(TARGET_ARCH) -c | C compilation build/rules.mk9 |
| COMPILE.cc | $(CXX) $(CCFLAGS) $(CXXFLAGS) $(CPPFLAGS_) $(CPPFLAGS) $(TARGET_ARCH) -c | C++ compilation build/rules.mk10 |
| LINK.o | $(CXX) $(CCFLAGS) $(LDFLAGS) | Linking command build/rules.mk8 |

 The `TARGET_ARCH` variable defaults to `-Xx86_64-mtune=znver4` [build/config.mk33](https://github.com/mozilla-ai/llamafile/blob/43551265/build/config.mk#L33-L33) which is passed to the Cosmopolitan toolchain to enable architecture-specific optimizations. The toolchain itself is defined by `COSMOCC` and `TOOLCHAIN` variables [build/config.mk19-20](https://github.com/mozilla-ai/llamafile/blob/43551265/build/config.mk#L19-L20)

 **Sources:** [build/rules.mk8-10](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L8-L10) [build/config.mk19-34](https://github.com/mozilla-ai/llamafile/blob/43551265/build/config.mk#L19-L34)

### Static Library Creation

```

```

 [build/rules.mk68-71](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L68-L71)

 This rule:

 
 - Creates a hidden `.aarch64/` subdirectory for ARM objects [build/rules.mk69](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L69-L69)
 - Archives x86_64 object files into the root library [build/rules.mk70](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L70-L70)
 - Archives aarch64 object files (found in parallel `.aarch64/` directories) into the corresponding ARM library [build/rules.mk71](https://github.com/mozilla-ai/llamafile/blob/43551265/build/rules.mk#L71-L71)

## Summary of Key Rules

 
| Rule Pattern | Command | Output |
|---|---|---|
| o/$(MODE)/%.o | COMPILE.c/cc | Object file build/rules.mk16-31 |
| o/$(MODE)/%.c.o | COMPILE.c | Extension-preserving C object build/rules.mk40-42 |
| o/$(MODE)/%.a | $(AR) | Multi-arch static library build/rules.mk68-71 |
| o/$(MODE)/%.zip.o | $(ZIPOBJ) | Embedded asset object build/rules.mk104-107 |
| o/$(MODE)/% | LINK.o | APE Executable build/rules.mk77-78 |
| o/$(MODE)/%.c | build/gperf | Generated C code build/rules.mk60-62 |
