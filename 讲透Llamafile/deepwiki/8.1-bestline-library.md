# Bestline Library

  Relevant source files 
 - [llamafile/bestline.c](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c)
 - [llamafile/bestline.h](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.h)
 
  The Bestline library provides an interactive line editor for command-line interfaces with GNU readline-style keyboard shortcuts, full UTF-8 support, ANSI terminal control, and a kill ring. It is a fork of `linenoise` that fixes bugs and adds missing features while maintaining a small binary footprint (~30KB). Llamafile uses Bestline for its interactive CLI prompt when running in interactive mode. [llamafile/bestline.c1-15](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L1-L15)

 
## Overview

 Bestline is a permissively-licensed terminal line editor that implements nearly all GNU readline editing shortcuts while supporting unlimited line lengths, UTF-8 editing, CTRL-R history search, terminal resizing, and parentheses-aware navigation. The library operates by placing the terminal in raw mode, reading and parsing ANSI escape sequences, and redrawing the edited line as the user types. [llamafile/bestline.c10-50](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L10-L50)

 **Key Features:**

 The library is organized into several functional layers. The public API provides entry points like `bestline()` and `bestlineWithHistory()`, which internally call the core editing loop `bestlineEdit()`. The editing loop manages a `bestlineState` structure containing the current buffer, cursor position, and display state. Input processing parses ANSI escape sequences through `bestlineReadCharacter()` and dispatches keystrokes via `bestlineEditFeed()`. Character handling functions decode UTF-8, calculate display widths for CJK characters and emoji, and encode output. ## Core Data Structures

 
### bestlineState

 The `bestlineState` structure tracks all state during line editing. [llamafile/bestline.c212-230](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L212-L230)

 
| Field | Description |
|---|---|
| buf, len, buflen | The edited line buffer, current byte length, and allocated capacity. |
| pos | Current cursor position (byte offset into buf). |
| prompt | The string displayed at the start of the line. |
| hindex | Current position in history (-1 for new line, ≥0 for history entries). |
| mark | Saved cursor position for region operations (set with CTRL-SPACE). |
| yi, yj | Boundaries of the last yank operation for yank-pop (ALT-Y). |
| ws | Terminal window size (rows and columns). |
| full | struct abuf used for building the terminal refresh sequence. |

### bestlineRing (Kill Ring)

 The kill ring implements Emacs-style cut/copy/paste with rotation. It stores up to 8 killed text regions in a circular buffer. [llamafile/bestline.c204-207](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L204-L207)


 Operations like CTRL-K (kill line forward), CTRL-U (kill line backward), ALT-D (kill word forward), and CTRL-W (kill word backward) push text onto the ring. CTRL-Y yanks the most recent entry, and ALT-Y rotates through older entries. [llamafile/bestline.c79-85](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L79-L85)

### Raw Mode Configuration

 The configuration disables features like automatic echo and line buffering. [llamafile/bestline.c2605-2673](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L2605-L2673)

 
| Flag | Effect |
|---|---|
| ~ECHO | Disable automatic echo (we draw ourselves) |
| ~ICANON | Disable line buffering (read char-by-char) |
| ~ISIG | Disable SIGINT/SIGQUIT signals (we handle CTRL-C) |
| ~IXON | Disable CTRL-S/CTRL-Q flow control (use them as keys) |
| ~ICRNL | Don't translate CR to NL |
| IUTF8 | Enable UTF-8 mode on supported terminals |
| VMIN=1, VTIME=0 | Read blocks with 1-char minimum |

 Sources: [llamafile/bestline.c2605-2673](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L2605-L2673)

## UTF-8 and Unicode Support

 
### Character Width Calculation

 The `bestlineCharacterWidth()` function implements the Unicode monospace width algorithm. It is essential for correct cursor positioning. [llamafile/bestline.c284-531](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L284-L531)

 
 - **0**: Control characters and combining marks.
 - **1**: Most characters (ASCII, Latin, etc.).
 - **2**: CJK ideographs, emoji, and fullwidth forms.
 
 Sources: [llamafile/bestline.c284-531](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/bestline.c#L284-L531)

 
### Word Boundary and Case Conversion

 `bestlineIsSeparator()` uses binary search over Unicode glyph tables to determine word boundaries for navigation (ALT-F/B).
