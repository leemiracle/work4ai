  This page provides technical instructions for getting started with llamafile, covering building from source, downloading pre-built executables, and utilizing the execution modes introduced in v0.10.0.

 
## Overview

 llamafile collapses the complexity of LLMs into a single-file executable (an "Actually Portable Executable") that runs on six operating systems (Linux, macOS, Windows, FreeBSD, OpenBSD, and NetBSD) and two CPU architectures (x86-64 and ARM64) [docs/index.md13-22](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/index.md?plain=1#L13-L22) It achieves this by combining [llama.cpp](https://github.com/mozilla-ai/llamafile/blob/43551265/llama.cpp) with [Cosmopolitan Libc](https://github.com/mozilla-ai/llamafile/blob/43551265/Cosmopolitan Libc) [docs/index.md18-22](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/index.md?plain=1#L18-L22)

### 2. Execution Modes (v0.10.0+)

 Starting with version 0.10.0, llamafile supports four primary execution modes defined by the `ProgramMode` enumeration [docs/cli_arguments.md100-101](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/cli_arguments.md?plain=1#L100-L101):

 
| Mode | Flag | Description |
|---|---|---|
| Combined | (Default) | Starts a server at localhost:8080 AND a terminal chat simultaneously docs/running_llamafile.md126-132 |
| CHAT | --chat | Launches a terminal-based interactive REPL with /commands like /upload docs/running_llamafile.md65-71 |
| SERVER | --server | Starts an HTTP server with a Web UI and OpenAI-compatible API docs/running_llamafile.md73-86 |
| CLI | --cli | Runs a single task (e.g., -p "prompt", --image "path") and exits docs/running_llamafile.md21-30 |

### GPU Support and Backend Selection

 llamafile detects GPU hardware at runtime. If a compatible SDK is found, it compiles or loads an optimized module [docs/support.md39-55](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/support.md?plain=1#L39-L55)

 
 - **Apple Metal:** Offload is enabled by default on ARM64 macOS. Compiles a small module using Xcode Command Line Tools on the first run, stored in `$TMPDIR/.llamafile` or `$HOME/.llamafile` [docs/support.md59-83](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/support.md?plain=1#L59-L83)
 - **NVIDIA CUDA:** Detected via `nvcc` on the `PATH`. Pass `-ngl 999` to enable maximum offloading [docs/support.md60-108](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/support.md?plain=1#L60-L108)
 - **AMD ROCm:** Detected via `hipcc` on the `PATH`. Requires the HIP SDK [docs/support.md61-111](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/support.md?plain=1#L61-L111)
 - **Vulkan:** Select with `--gpu vulkan`. Covers hardware where CUDA/ROCm backends are unavailable [docs/support.md62](https://github.com/mozilla-ai/llamafile/blob/43551265/docs/support.md?plain=1#L62-L62)
