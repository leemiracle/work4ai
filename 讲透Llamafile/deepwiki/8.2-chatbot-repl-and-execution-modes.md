  The llamafile chatbot REPL (Read-Eval-Print Loop) provides an interactive terminal interface for engaging with Large Language Models. Introduced in v0.10.0, the system supports multiple execution modes that determine whether the REPL interacts directly with a local model or acts as a client to a remote or embedded HTTP server.

 
## Program Execution Modes

 llamafile operates in several primary modes, governed by command-line flags or the environment in which the executable is launched. While the high-level logic is orchestrated in `main`, specific main functions handle different entry points.

 
| Mode | Flag | Entry Point | Description |
|---|---|---|---|
| SERVER | --server | llamafile_sandbox_server | Starts the HTTP server and web UI. This is the default when no arguments are provided. |
| CHAT | --chat | lf::chatbot::main | Launches the interactive chatbot REPL in the terminal. |
| CLI | --cli | lf::chatbot::cli_main | Executes a single prompt and prints the completion to stdout before exiting. |
| API/Combined | (internal) | lf::chatbot::api_main | Acts as a client to a local or remote server URL. |

## ChatBackend Abstraction

 The REPL is decoupled from the inference engine via the `ChatBackend` abstract class [llamafile/chatbot_backend.h20-50](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_backend.h#L20-L50) This allows the same REPL logic to function regardless of whether the model is running in-process or behind an API.

 
### DirectBackend

 Used in `--chat` mode. It interacts directly with the `llama_context` and `llama_model` loaded into the process memory [llamafile/chatbot_main.cpp187-194](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_main.cpp#L187-L194) It handles manual KV cache management, tokenization, and local sampling via `common_sampler` [llamafile/chatbot_main.cpp53-57](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_main.cpp#L53-L57) It is created via the `create_direct_backend()` factory [llamafile/chatbot.h90](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot.h#L90-L90)

 
### ApiBackend

 Used when the REPL acts as a client to a llamafile server (e.g., in "combined" mode). It translates user input into OpenAI-compatible JSON requests and sends them to the `/v1/chat/completions` endpoint using `httplib::Client` [llamafile/chatbot_api.cpp104-133](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_api.cpp#L104-L133) It supports SSE streaming and extracts usage statistics from the final chunk [llamafile/chatbot_api.cpp168-177](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_api.cpp#L168-L177)

## Interactive Features and Commands

 The REPL uses the `bestline` library to provide a rich terminal experience, including tab completion, persistent history, and syntax highlighting [llamafile/chatbot_repl.cpp173-176](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_repl.cpp#L173-L176)

 
### Command System

 Users can issue IRC-style commands starting with `/`. These are intercepted by `handle_command()` before being sent to the model.

 
| Command | Function | Description |
|---|---|---|
| /clear | on_clear() | Restarts the conversation and resets the KV cache llamafile/chatbot_help.cpp98-104 |
| /undo | on_undo() | Erases the last exchange from history and rewinds the KV cache llamafile/chatbot_hist.cpp181-193 |
| /forget | on_forget() | Erases the oldest message (after the system prompt) to free context llamafile/chatbot_hist.cpp195-215 |
| /upload | on_upload() | Ingests a file (text or image) into the conversation context llamafile/chatbot_help.cpp130-139 |
| /manual | on_manual() | Toggles manual role selection (User/Assistant/System) llamafile/chatbot_hist.cpp224-236 |

## History and Context Management

 llamafile manages a history stack that allows for "backtracking" conversations. This is implemented through several global vectors in the `lf::chatbot` namespace.

 
 - `g_messages`: A vector of `common_chat_msg` objects representing the high-level chat history [llamafile/chatbot_hist.cpp35](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_hist.cpp#L35-L35)
 - `g_history`: A vector of raw `llama_token` IDs currently residing in the KV cache [llamafile/chatbot_hist.cpp38](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_hist.cpp#L38-L38)
 - `g_undo`: A stack of token offsets used to restore the `g_history` and KV cache state [llamafile/chatbot_hist.cpp37](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_hist.cpp#L37-L37)
 
 
### The Reasoning Filter and Styling

 For models that output internal "reasoning" or "thinking" tokens (like DeepSeek-R1), llamafile implements filters to handle the display of these segments. In the REPL, reasoning content is styled with "faint" ANSI codes. The `maintain_faint_styling` function ensures that if markdown highlighting resets attributes, the faint styling is immediately reapplied [llamafile/chatbot_repl.cpp47-62](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_repl.cpp#L47-L62)

 The `apply_chat_template_with_thinking` helper ensures that templates supporting the `enable_thinking` parameter are correctly invoked for `DirectBackend` operations, honoring the `g_params->enable_reasoning` flag [llamafile/chatbot_repl.cpp67-90](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_repl.cpp#L67-L90)

### Multimodal and CLI Logic

 In `CLI` mode, the system bypasses the REPL loop and performs a single inference pass. It uses `cli_apply_chat_template_full` to prepare the prompt, including support for DeepSeek-style reasoning extraction via the `COMMON_REASONING_FORMAT_DEEPSEEK` parser [llamafile/chatbot_cli.cpp67-96](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_cli.cpp#L67-L96)

 In `ApiBackend`, images detected in text via `data:image/` URIs are converted into OpenAI-compatible `image_url` content parts before being sent to the server [llamafile/chatbot_api.cpp58-102](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_api.cpp#L58-L102)
