# Syntax Highlighting

  Relevant source files 
 - [llama.cpp.patches/llamafile-files/BUILD.mk](https://github.com/mozilla-ai/llamafile/blob/43551265/llama.cpp.patches/llamafile-files/BUILD.mk)
 - [llamafile/BUILD.mk](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/BUILD.mk)
 
  The syntax highlighting subsystem in llamafile provides real-time ANSI colorization for code blocks and terminal output within the Text User Interface (TUI). It supports over 40 programming languages and specialized formats, utilizing a combination of hand-written lexers, `gperf`-generated keyword dictionaries, and a dispatch interface that facilitates integration with the chatbot REPL.

 The subsystem is primarily contained within the `llamafile/highlight/` directory, which houses the individual language highlighters and utility classes for managing terminal escape sequences.

 
### Architecture and Data Flow

 The highlighting system operates as a stream processor. Text is fed into a `ColorBleeder` which manages the transition between different highlighting states (e.g., transitioning from Markdown text into a C++ code block). The `ColorBleeder` delegates the actual tokenization to specific `Highlight` subclasses.

### Core Components

 
#### 1. The Highlight Interface

 All language-specific highlighters inherit from the `Highlight` abstract base class defined in `highlight.h`. This interface requires the implementation of a `feed` method, which processes a single character and returns the appropriate ANSI color code.

 Key functions in the interface:

 
 - `feed(char)`: Processes one byte of input and returns an ANSI escape sequence if the color should change.
 - `flush()`: Returns the escape sequence required to reset the terminal state.
 
 
#### 2. ColorBleeder

 The `ColorBleeder` class (defined in `llamafile/highlight/color_bleeder.cpp`) acts as a stateful wrapper. It ensures that ANSI codes are only emitted when a logical color change occurs, preventing redundant escape sequences in the terminal output. It also handles the "bleeding" of styles across line boundaries and resets.

 
#### 3. Language Highlighters

 Each supported language has a dedicated implementation (e.g., `highlight_cpp.cpp`, `highlight_python.cpp`). These implementations typically use a state machine to track whether the lexer is inside a string, a comment, a keyword, or a preprocessor directive.

 
| Language | Implementation File | Key Mechanism |
|---|---|---|
| C++ | highlight_cpp.cpp | gperf keywords, state machine for templates/macros |
| Python | highlight_python.cpp | Triple-quote string detection, indentation awareness |
| Markdown | highlight_markdown.cpp | Code fence detection (```) and recursive dispatch |
| Shell | highlight_shell.cpp | Variable expansion and command substitution tracking |
| Assembly | highlight_asm.cpp | Mnemonic and register highlighting |

### Integration with Chatbot REPL

 In `chatbot_repl.cpp`, the system prompt and model responses are passed through the highlighting subsystem before being printed to `stdout`.

 
 - **Base Models:** Use `HighlightTxt` for simple styling [llamafile/chatbot_repl.cpp175-176](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_repl.cpp#L175-L176)
 - **Instruct/Chat Models:** Use `HighlightMarkdown` to render formatted responses and colorized code blocks [llamafile/chatbot_repl.cpp175-176](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/chatbot_repl.cpp#L175-L176)

### Compilation and Build System

 The highlighting sources are compiled into the main `llamafile` library. The `LLAMAFILE_HIGHLIGHT_SRCS` variable in the build system tracks the 40+ individual implementation files.

 **Key Build Variables:**

 
 - `LLAMAFILE_HIGHLIGHT_SRCS`: Lists all `highlight_*.cpp` files, including `highlight_ada.cpp`, `highlight_rust.cpp`, `highlight_zig.cpp`, etc. [llamafile/BUILD.mk83-129](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/BUILD.mk#L83-L129)
 - `LLAMAFILE_SRCS_CPP`: Includes the highlight sources in the final binary by referencing `$(LLAMAFILE_HIGHLIGHT_SRCS)` [llamafile/BUILD.mk167](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/BUILD.mk#L167-L167)
