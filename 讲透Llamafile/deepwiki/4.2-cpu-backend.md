## Purpose and Scope

 The CPU Backend implements optimized matrix multiplication kernels for running LLM inference on CPU without GPU acceleration. It provides runtime detection of SIMD capabilities and dynamically dispatches to the best available implementation for the host architecture. This backend is critical for the "Actually Portable" nature of llamafile, ensuring high performance across a wide range of hardware from Raspberry Pi 5 to Zen 4 servers.

 This page covers CPU-based compute operations and the dispatch logic. For details on specific implementations, see:

 
 - [CPU GEMM Optimization](https://deepwiki.com/mozilla-ai/llamafile/4.2.1-cpu-gemm-optimization) — Detailed documentation of tinyBLAS CPU kernels, tiling, and Kahan summation.
 - [Quantized Matrix Multiplication](https://deepwiki.com/mozilla-ai/llamafile/4.2.2-quantized-matrix-multiplication) — IQK quantized matmul kernels for Q4_K, Q8_0, and MoE routing.

### Supported CPU Feature Sets

 The dispatcher selects from the following implementations based on detected features:

 
| Architecture | Required Features | Implementation | Target CPUs |
|---|---|---|---|
| x86_64 | AVX | llamafile_sgemm_amd_avx | Sandy Bridge (2011+) |
| x86_64 | AVX + FMA | llamafile_sgemm_amd_fma | Piledriver (2011+) |
| x86_64 | AVX2 + FMA + F16C | llamafile_sgemm_amd_avx2 | Haswell (2013+) |
| x86_64 | AVX2 + AVXVNNI | llamafile_sgemm_amd_avxvnni | Alder Lake (2021+) |
| x86_64 | AVX512F | llamafile_sgemm_amd_avx512f | Skylake-X (2015+) |
| x86_64 | AVX512F + VNNI + BF16 | llamafile_sgemm_amd_zen4 | Zen 4 (2023+) |
| aarch64 | NEON (baseline) | llamafile_sgemm_arm80 | ARMv8.0-A |
| aarch64 | DOTPROD + FP16 | llamafile_sgemm_arm82 | ARMv8.2-A (RPi5, M1) |

### Flash-Attention Helpers

 Llamafile includes optimized replacements for hot `ggml-cpu` inner loops, specifically for Flash-Attention (issue #975). These helpers, such as `llamafile_fa_vec_dot_f16`, are dispatched to AVX-512F implementations when available to avoid the performance penalties of baseline AVX2 code compiled by `cosmocc` for generic targets [llamafile/sgemm.cpp70-72](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/sgemm.cpp#L70-L72)

## Public API Entry Points

 
### llamafile_sgemm()

 Main entry point for optimized matrix multiplication. It delegates to the `funcs.sgemm` pointer initialized during startup [llamafile/sgemm.cpp148-154](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/sgemm.cpp#L148-L154)

 
### llamafile_mixmul()

 Handles Mixture of Experts operations. It selects between standard `tinyBLAS` implementations and the `iqk` variant for quantized experts [llamafile/sgemm.cpp159-162](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/sgemm.cpp#L159-L162)

 
### llamafile_fa_vec_dot_f16()

 Optimized Flash-Attention helper. Returns `false` if no optimized kernel is available for the current architecture, signaling the caller to use the generic fallback [llamafile/sgemm.h89-94](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/sgemm.h#L89-L94)
