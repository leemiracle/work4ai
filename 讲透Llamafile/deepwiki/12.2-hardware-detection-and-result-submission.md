  The llamafile project includes sophisticated mechanisms for identifying host hardware capabilities and optionally sharing performance benchmarks with the community. This system encompasses runtime detection of CPU and GPU architectures, power consumption sampling, and a submission pipeline to the [localscore.ai](https://www.localscore.ai) public database.

 
## Hardware Detection Architecture

 Hardware detection is performed at runtime to ensure that the "Actually Portable Executable" (APE) format can select the optimal compute kernels for the specific machine it is executing on. This process involves identifying the CPU instruction set, the presence of discrete GPUs (NVIDIA, AMD, or Apple Silicon), and available system memory.

 
### CPU Feature Discovery

 For x86_64 systems, llamafile uses the `cpuid` instruction to identify the manufacturer and supported SIMD extensions [localscore/system.cpp21-56](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/system.cpp#L21-L56) It specifically extracts the CPU brand string by querying leaves `0x80000002` through `0x80000004` [localscore/system.cpp66-72](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/system.cpp#L66-L72) On macOS, it utilizes `sysctlbyname` to extract the processor brand string (`machdep.cpu.brand_string`) and the count of performance vs. efficiency cores using `hw.perflevel0.logicalcpu` and `hw.perflevel1.logicalcpu` [localscore/system.cpp98-124](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/system.cpp#L98-L124) On Linux systems where `cpuid` might not be the primary source (like ARM), it parses `/proc/cpuinfo` for "model name" [localscore/system.cpp74-97](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/system.cpp#L74-L97)

 
### GPU Backend Selection

 The GPU detection logic is controlled via `FLAG_gpu` (defaulting to `LLAMAFILE_GPU_AUTO`) [localscore/localscore.cpp130-132](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L130-L132) The system attempts to identify available accelerators and can be manually overridden via the CLI [localscore/cmd.cpp103-114](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/cmd.cpp#L103-L114) Specific vendor probing is handled by `nvml.cpp` for NVIDIA, `rsmi.cpp` for AMD, and `apple.cpp` for Apple Silicon (Metal).

## LocalScore Result Submission

 The LocalScore utility (`localscore.cpp`) benchmarks the hardware and provides an optional path to submit these results to the `localscore.ai` public database.

 
### Submission Workflow

 
 - **Warmup**: Before benchmarking, `warmup_run` processes a random token sequence to stabilize clock speeds, fill KV caches, and synchronize the context [localscore/localscore.cpp134-174](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L134-L174)
 - **Execution**: The benchmark runs for a specified number of repetitions (`--reps`), which can be set to standard (1), extended (4), or long (16) modes [localscore/cmd.cpp136-144](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/cmd.cpp#L136-L144)
 - **User Consent**: By default, the system prompts the user via `getUserConfirmation()` before sending data unless `params.send_results` is explicitly set to `SEND_YES` [localscore/localscore.cpp120-128](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L120-L128) [localscore/localscore.cpp178-182](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L178-L182)
 - **Payload Generation**: System metadata and performance metrics are serialized into a JSON object using the `jt::Json` library [localscore/localscore.cpp53](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L53-L53) [localscore/localscore.cpp189-210](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L189-L210)
 - **HTTP POST**: The payload is sent to `https://www.localscore.ai/api/results` via the `POST()` function defined in `http.h` [localscore/localscore.cpp55](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L55-L55) [localscore/localscore.cpp204-206](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L204-L206) The system implements a retry loop with exponential backoff (up to 3 attempts) [localscore/localscore.cpp195-201](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/localscore.cpp#L195-L201)

## Power Sampling

 The system includes a `PowerSampler` class defined in `powersampler.cpp` to monitor energy consumption during inference. This is integrated into the benchmark loop to provide efficiency metrics (tokens per joule) when hardware sensors are accessible.

 
## Command Line Configuration

 Hardware detection and submission behavior are tuned via flags parsed by `parse_cmd_params` [localscore/cmd.cpp70-176](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/cmd.cpp#L70-L176)

 
| Flag | Effect | Code Pointer |
|---|---|---|
| -c, --cpu | Disables GPU detection; sets FLAG_gpu to LLAMAFILE_GPU_DISABLE. | localscore/cmd.cpp100-102 |
| -g, --gpu | Manually selects backend (auto, amd, apple, nvidia, disabled). | localscore/cmd.cpp103-114 |
| --list-gpus | Probes hardware and lists available accelerators. | localscore/cmd.cpp95-99 |
| -y, --send-results | Sets send_results mode to SEND_YES (auto-submit). | localscore/cmd.cpp132-133 |
| -n, --no-send-results | Sets send_results mode to SEND_NO (skip submission). | localscore/cmd.cpp134-135 |
| --reps | Manually sets the number of benchmark repetitions. | localscore/cmd.cpp140-144 |
| --output | Sets format to csv, json, or md (markdown). | localscore/cmd.cpp115-127 |

 
### Utility Functions

 The `localscore/utils.h` header provides helper functions for data processing during detection and submission:

 
 - `utils::exec()`: Executes shell commands using `popen` and captures output [localscore/utils.h81-92](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/utils.h#L81-L92)
 - `utils::avg()` and `utils::stdev()`: Calculate arithmetic mean and standard deviation for benchmark repetitions [localscore/utils.h61-79](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/utils.h#L61-L79)
 - `utils::round_to_decimal()`: Rounds double values to specified precision for formatting [localscore/utils.h184-187](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/utils.h#L184-L187)
 - `utils::sanitize_string()`: Ensures hardware strings contain only printable ASCII [localscore/utils.h168-175](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/utils.h#L168-L175)
 - `utils::get_time_ns()`: Provides high-resolution timestamps using `std::chrono` [localscore/utils.h22-25](https://github.com/mozilla-ai/llamafile/blob/43551265/localscore/utils.h#L22-L25)
