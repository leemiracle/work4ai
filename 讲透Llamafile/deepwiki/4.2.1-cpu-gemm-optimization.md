## Purpose and Scope

 This page documents the optimized CPU matrix multiplication kernels used by llamafile for inference. These kernels implement efficient computation of `C = Aᵀ * B` (transposed matrix-matrix multiplication) through architecture-specific SIMD optimizations and register tiling strategies.

 The implementation is called "tinyBLAS" and focuses on small-to-medium matrices that fit in CPU cache without requiring explicit blocking or memory allocation [llamafile/tinyblas_cpu_sgemm.inc32-35](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu_sgemm.inc#L32-L35) The kernels achieve performance through:

 
 - Runtime dispatch to microarchitecture-specific implementations [llamafile/sgemm.cpp47-138](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/sgemm.cpp#L47-L138)
 - SIMD vectorization (AVX, AVX2, AVX-512, NEON) [llamafile/tinyblas_cpu.h130-188](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu.h#L130-L188)
 - Register tiling to maximize data reuse [llamafile/tinyblas_cpu.h432-530](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu.h#L432-L530)
 - Logarithmic accumulation using the ruler function to minimize roundoff errors [llamafile/tinyblas_cpu.h547-569](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu.h#L547-L569)
 - Support for floating-point (F32, F16, BF16) and quantized (Q8_0, IQK) data types [llamafile/tinyblas_cpu_sgemm.inc49-218](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu_sgemm.inc#L49-L218)

## Mixture of Experts (MoE) Optimization

 The `MixMul` class in [llamafile/tinyblas_cpu_mixmul.inc77-155](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu_mixmul.inc#L77-L155) implements optimized tensor multiplication for MoE models like Mixtral.

 
### MoE Data Flow

 MoE requires routing tokens to different expert weights based on a routing plan [llamafile/tinyblas_cpu_mixmul.inc39-50](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu_mixmul.inc#L39-L50)

 
| Entity | Shape | Role |
|---|---|---|
| weights | [cols, rows, experts] | Expert weight matrices llamafile/tinyblas_cpu_mixmul.inc34 |
| thought | [cols, tasks, tokens] | Input hidden states llamafile/tinyblas_cpu_mixmul.inc35 |
| plan | [thinkers, tokens] | Routing indices llamafile/tinyblas_cpu_mixmul.inc37 |
| result | [rows, thinkers, tokens] | Output tensor llamafile/tinyblas_cpu_mixmul.inc36 |

 The implementation manages shared memory for quantized thoughts and row pointers via `allocate_shared_memory()` [llamafile/tinyblas_cpu_mixmul.inc97-107](https://github.com/mozilla-ai/llamafile/blob/43551265/llamafile/tinyblas_cpu_mixmul.inc#L97-L107)
