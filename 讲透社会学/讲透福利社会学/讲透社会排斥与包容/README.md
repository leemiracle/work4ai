# 讲透社会排斥与包容 · 闸门——谁被机器保住,谁被甩出名单

> **定位句**:这支负责分层机器的**闸门车间**——排斥的多维度(收入/就业/居住/关系/服务的出局,不止收入低)、
> 底层阶级争论(结构论 vs 行为论的标签战)、激活政策与社会投资转向(把权利改写成"权利+义务"、把补偿改写成准备)。
> 它管的是**边界**:福利机器的名单外沿在哪里,以及掉线的人如何被重新接线——退坡几何(家族实验律三)证明:
> 闸门的位置首先是算术,其次才是道德。
> GB/T 13745 84067 福利社会学(无三级明细)· **自定支三**。家族:[讲透福利社会学](../README.md)

## 诞生

- **谁/何时**:社会排斥概念起于法国线(Lenoir 1974 起,通说),1990s 被欧盟采纳为政策框架;底层阶级之争由 Wilson
  《真正的穷人》(1987,结构论)与其批评者(行为论侧)对垒;激活政策 1990s 起于荷兰与北欧("权利+义务"),社会投资
  转向以 Esping-Andersen 等(2002)与 Morel 等的汇编(2012,方向锚)立碑。
- **因什么问题**:①贫困线之外还有哪些出局方式(维度之问)②"底层阶级"是结构甩出还是文化堕落的标签战
  (归因之问)③把受益人推回劳动力市场,是解放还是义务化(激活之问)。

## 核心问题

**已解决(通说)**:排斥的多维框架(收入/就业/居住/关系/服务)成为诊断底座;激活与社会投资成为 OECD 主流政策语法;METR 成为就业激励标准读数。

**未解决/深水区**:激活的制裁边界(义务化的正当性);社会投资话语的折现偏差(偏爱儿童、老年照护成盲区);交叉性
维度(性别×族裔×移民身份)的入框;排斥的主观维度(关系/参与)测量弱;基本收入与激活的义务观正面相撞(01 章主线 B)。

## ✨ 这支最美的一个事实

**多劳一个月,倒贴 120 元**:两条家计调查退坡(社会救助退出点 2400/住房补贴退出点 3600)与税线叠加,净收入曲线上
出现分段常数的 METR 阶梯——基准退坡率 0.35 时陷阱宽 2400、最高 0.85(挣 10 元净得 1.5 元);上调到 0.50 后陷阱
加宽到 3600、最高 1.15 越 100% 悬崖:不工作净得 3000>全职最低工资净得 2880,上沿恰好压在中位工资处。为什么美:
**"福利依赖"这个道德词,在坐标纸上是一段可计算的几何**——宽度、深度、位置全是退坡率×退出点×税线的乘积,
改一个参数悬崖就搬家;被骂"懒"的人踩着的是制度的图纸(家族实验律三即本支仪表)。

## 假设与依赖

- 买入"排斥是多维的":维度清单即理论(切五维还是三维,诊断结果不同);METR 的重量取决于劳动供给弹性(几何说"不划算",行为才说"做不做")
- 激活的正当性是规范问题不可仿真:卡片里只存义务/服务/制裁配比,判断留给审议
- 排斥的**测量工艺**(多维剥夺指数的估计)接统计宇宙;就业政策侧归劳动科学 84074(同宇宙,均文字提及)——本支管排斥的社会学与激活的福利语法
