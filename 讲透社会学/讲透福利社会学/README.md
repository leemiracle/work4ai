# 讲透福利社会学 · 福利国家不是恩泽,是分层机器——体制、多元与边界

> **本质一句话**:福利社会学=把「福利」从慈善的施舍改写成公民的
> **社会权利**、再把福利国家当作**分层机器**来解剖的学科——它不问
> "穷人该不该帮"(那是道德哲学),而问**一个社会把生存风险的保障
> 组织成什么制度**(谁出钱、保什么、怎么领、退坡几何如何),这台
> 机器如何决定**谁的生存可以不依赖市场(去商品化)、谁被保进哪一层
> (分层化)、谁根本不在名单上(排斥)**;一句话:
> **福利不是雨露恩泽,是一台有图纸的分层机器——图纸叫体制,
> 体制的三把刻刀叫去商品化、分层化与家庭化。**

## 一、家族定位(它在社会学宇宙里的位置)

社会学宇宙的多数家族研究"社会如何运转",本家族研究**一台特定的
机器**:一个社会如何把生病、年老、失业、抚养这些生存风险的保障
**组织成制度**——以及这台机器如何反过来重塑分层秩序。它的编年是
一张政策与理论的接力单:1795 年斯宾汉兰津贴把工资补到面包价
(波兰尼意义上的"保护社会的双向运动"原型的经典案例),1942 年
贝弗里奇报告把战胜"贫困、疾病、无知、肮脏与懒散"五大巨人的计划
写成一台国家机器,1950 年马歇尔把福利讲成**公民身份**的第三阶段
(公民权利→政治权利→社会权利),1974 年蒂特穆什分出**剩余型与
制度型**,1990 年艾斯平-安德森用**去商品化与分层化**把福利国家
切成三个世界,福利多元主义(Pinker/罗斯)再把国家-市场-家庭-
社会的**四部门组合**摆上台面,新社会风险与社会投资转向
(2000s)把议题从"保护"改写成"准备"。图纸(体制)→供应链
(多元)→边界(排斥)的编年是 00 章的主线;五问(体系/前沿/
语言/构造/转码)的回答见家族层五章。

> (福利被组织成什么类型:怎么去商品化、怎么分层),多元支管
> **供应链**(保障从哪里来:国家/市场/家庭/社会的组合与挤出),
> 排斥支管**边界**(谁被机器保住、谁被甩出:排斥的维度与激活的
> 回应)。三视图合起来正是"制图-供料-闸门"的三车间:图纸定了
> 分层的形状,供料定了分层的来源,闸门定了分层的外沿。
