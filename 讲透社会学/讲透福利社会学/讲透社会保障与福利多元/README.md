# 讲透社会保障与福利多元 · 供料——保障从国家、市场、家庭、社会哪里来

> **定位句**:这支负责分层机器的**供料车间**——四部门组合(国家-市场-家庭-社会)、正式与非正式福利的分账、
> Pinker 福利多元主义(社会部门作为独立供料者)。它管的是保障的**供应链**:总保障是四部门的总账,公共每扩张一步,
> 其他三户是关阀门(挤出)还是开阀门(互补),由替代弹性 σ 说了算——"挤出不是福利的定律,是弹性的问题"
> (家族实验律二即本支仪表)。
> GB/T 13745 84067 福利社会学(无三级明细)· **自定支二**。家族:[讲透福利社会学](../README.md)

## 诞生

- **谁/何时**:罗斯在 1980s 指出国家、市场、家庭共同生产福利(通说);**Pinker 的福利多元主义**进一步把"社会"(共同体
  与志愿部门)立为独立供料者,主张社会政策为社会留出运行空间(2023 年 PMC 福利多元主义综述文为这条线正名,
  检索校准 2026-09-07);正式/非正式福利的分账与挤出之争成为车间常设议题。
- **因什么问题**:①总保障怎么在四部门间分账(总账之问)②公共扩张挤掉还是激活私人供料(弹性之问)
  ③亲属照护这类非正式供料要不要入账(口径之问)。

## 核心问题

**已解决(通说)**:四部门组合成为标准分析框架;挤出与互补作为**条件性问题**(取决于 σ)而非定律被接受;
正式/非正式福利的区分成为照护研究的底座。

**未解决/深水区**:σ 的实证识别(需外生变动,模拟不能冒充估计);"社会部门"的边界与测量(最模糊的供料者);
非正式照护入账的口径(入账即改变待遇政治);疫情扩张与回摆的四部门总账复盘(01 章主线 A/D)。

## ✨ 这支最美的一个事实

**一条直线裁决四十年的争论**:挤出 vs 互补吵了几十年,把分账写下来,判据只剩 dG/dP=1−σ×(公共份额)——
σ=0.5 时临界份额 200%,公共扩张全程加总保障(互补:公共做的是没人做的事);σ=1.6 时份额过 62.5% 即转负
(挤出:公共做的是本来有人做的事);实测 σ=0.5/0.8 全程递增至 175/160,σ=1.25/1.6 峰值 140@80/131.2@62.5 后回落。
为什么美:**它把意识形态争论翻译成参数争论**——且不同部门可以同卡异号(公共养老挤商业保险、公共托育补家庭
空白);想主张挤出,报 σ;想主张互补,报份额(家族实验律二即本支仪表)。

## 假设与依赖

- 买入"四部门可分账":每部门的产出有共同量纲;分账口径即理论——非正式照护入不入账,总保障水平差一截(02 章供料版)
- 常数 σ 是买入的简化:现实弹性是结构函数(随部门/收入段/时期而变);σ≥2 时 S(P) 触零,模型要设防
- 社会保险的**制度本体**(险种/费率/精算/经办)归社会保险学 8407440(劳动科学侧,待建,文字提及)——
  本支管供料组合的社会学,不管齿轮设计
