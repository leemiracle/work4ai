# 讲透福利国家与体制类型 · 图纸——福利被组织成什么类型

> **定位句**:这支负责分层机器的**制图车间**——贝弗里奇-俾斯麦两大供料传统(普遍供款还是就业关联)、三个世界(社会民主/保守/自由)、
> 两把刻刀(去商品化与分层化,外加女性主义补的第三把:去家庭化)。它管的是福利的**类型学内容**:同样叫福利国家,
> 分层的形状可以完全不同——扁平的、地位维持的、二元的。家族实验律一(去商品化指数)是本支的仪表。
> GB/T 13745 84067 福利社会学(无三级明细)· **自定支一**。家族:[讲透福利社会学](../README.md)

## 诞生

- **谁/何时**:贝弗里奇报告(1942)与俾斯麦社会保险(1880s)立下两大**供料传统**;马歇尔《公民身份与社会阶级》(1950)把福利升格为
  社会权利;蒂特穆什《社会政策》(1974)分出剩余型/制度型;艾斯平-安德森《福利资本主义的三个世界》(1990)用**去商品化×分层化**
  切出三体制;刘易斯男性养家者模型(1992)与福利国家女性主义补上**去家庭化**刻刀。
- **因什么问题**:①同样花 GDP 的两成,为何分层形状完全不同(形状之问)②离开市场能否维生怎么度量(去商品化之问)
  ③类型学装不下南欧与东亚时怎么办(边界之问)。

## 核心问题

**已解决(通说)**:去商品化的操作化(覆盖×替代×持续的跨项目合成);三体制坐标成为比较 welfare 研究的通用语言;剩余/制度
二分成为身份分析的底座。

**未解决/深水区**:第四/第五体制之争(南欧/东亚/拉美落格);qualifiers(资格条款)未入指数;移民与居留权边界对"国民=权利人"
预设的冲击;去家庭化的度量口径(照护公共化覆盖率?权利个体化程度?)。

## ✨ 这支最美的一个事实

**山与树:单项目会骗人,合成不会**。去商品化指数 = 失业/医疗/养老三个项目各按「覆盖率×替代率×持续时间」合成再加总——教学版
实验里,总分把三体制干净分层(社会民主 1.994>保守 1.369>自由 0.436,18 国无一越层:0.622<1.054<1.579<1.887),
**而每个单项目上都存在相邻体制对的国家分布重叠**(自由体制也有养老强项,社会民主体制也有失业弱项)。为什么美:它一击同时证明
两件事——**类型学有真信号**(总分分层),且**单指标必翻车**(分布重叠);"体制是多维组合"从口号变成可断言的区间算术
(家族实验律一即本支仪表)。

## 假设与依赖

- 买入"档位在项目间排序一致":三项目同高同低才是"体制";档位错乱(南欧式:养老医疗高、失业低)即落格
- 等权合成是理论决定不是数据决定;qualifiers 未入指数(资格越严,名义覆盖越虚)
- 类型学的**方法本体**(怎么造类型/怎么选案例)归 [../../讲透比较社会学/README.md](../../讲透比较社会学/README.md)
  (互链,其制度与模式比较支已声明分工);本支管体制的**内容与后果**
- 福利国家的**政治经济生成侧**(权力资源/市场-政治结构)归 [../../讲透经济社会学/README.md](../../讲透经济社会学/README.md)(互链)
