# 03 · 可构造与结构:哪些方法的的东西能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:社会学方法的对象沿一条**可构造谱系**排开——
> 设计端**严格可构造**(三张结构卡:研究设计卡/抽样方案卡/访谈
> 提纲卡,字段化、可审查、可存档),判断端**不可构造**(编码的
> 意义判断、理论饱和的停采时机、田野关系的建立);而全谱系共享
> 两条结构引擎:**随机化引擎**(概率抽样的代数与预算)与
> **迭代编码引擎**(定性严格性的程序来源)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
研究设计卡 ── 抽样方案卡 ── 访谈提纲卡 ── 编码手册 ── 测量不变性流程 ── 理论饱和 ── 田野关系
  │                                                                                      │
严格可构造(字段化文件)                                                    不可构造(只有判断,没有装配线)
  └── 写得出、审得动、存得下                                                  └── 只能靠训练与反身性纪律
```

为什么会有这条谱系?**可构造的前提是"有限字段+确定语义"**(离散
数学家族的同一条判据在此复用):抽样方案卡的语义是"总体/框/概率/
量",每个字段的合法取值可枚举;而"田野关系"的语义是研究者与
被研究者的相互转化,描述它的人本身就在构造它。本章先盘家底,
再造三张卡(任务指定的开工文件),最后看两条引擎。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **研究设计卡** | 字段化文件:问题/单元/时间/比较/识别/威胁清单(§二) | 低(一页纸) | 卡片漂亮≠识别成立——设计管计划,世界未必配合 |
| **抽样方案卡** | 字段化文件:总体/框/方法/量/权数/误差预算(§二) | 低 | 抽样框与总体的差必须**逐条登记**,沉默漏掉的人不进数据 |
| **访谈提纲卡** | 字段化文件:主题块/核心问题/探针/敏感位(§二) | 低 | 骨架不是脚本——照读杀死资料 |
| **编码手册** | 码表:码名/定义/入选判据/反例/示例引文 | 中 | 每次修订留版本号,否则互主观性失效 |
| **样本量与功效预算** | 效应量→SE→deff→n 的闭式链条 | 低(家族实验幕一二) | 预算只管抽样误差;覆盖/无应答另记账 |
| **α 与信度计算器** | Σvar_i/var_T 的闭式(实验幕三) | 低 | 只管内部一致性一种信度(02 章 §二) |
| **测量不变性流程** | 多组构念方程的层级检验(形态→载荷→截距) | 中-高 | 技术面住统计宇宙(91040);本家族管设计与解释 |
| **理论饱和** | "新资料不再产生新码"的停采判据 | **不可构造** | 判断性:同一批资料,两个研究者可以停在不同处 |
| **田野关系/编码的意义判断** | 只有训练与反身性备忘 | **不可构造** | 压缩成参数即失真;它是定性证据的**生产条件**而非数据 |

**反直觉发现(本章铁律)**:**程序可构造 ≠ 判断可外包**。扎根理论
的**持续比较**是严格程序(可教可审),但**何时饱和**是判断;
抽样的**权数**是代数(可算可验),但**抽样框漏了谁**是调查者对
社会的知识。**谱系左端管开工文件,右端管手艺修养;用左端的文件
冒充右端的手艺(把编码手册当成编码本身),是方法合规的形式主义。**

## 二、三张结构卡(每项研究的开工文件——本章招牌)

### 卡 1:研究设计卡(把一次研究压成一页可审查的图纸)

```yaml
卡名: 研究设计卡
字段:
  研究问题:      一句话;并附变量语言改写(X 如何影响 Y / Y 意味着什么)
  分析单元:      个体 / 组织 / 事件 / 文本 / 关系
  时间结构:      横断 / 追踪面板 / 回溯 / 序列
  比较结构:      实验(随机分配) / 准实验(断点·前后·匹配) / 观察(比较组)
  识别策略:      随机化 / 断点 / 工具变量 / 控制变量 + 设计威胁分析 / 深描(定性版)
  测量计划:      每个构念一行:观念定义 → 操作化定义 → 层次 → 信效度预案
  抽样计划:      → 引用「抽样方案卡」(字段互链,不许口头带过)
  效度威胁清单:  内部:选择/历史/成熟/流失/测验反应…;外部:总体/情境/时间
  伦理:          知情同意 / 匿名化 / 敏感数据处置 / 痕迹数据的二次使用边界
  预注册:        分析计划是否事先锁定(锁定的字段清单)
构造规则:
  - 一卡一问(两个问题拆两张卡)
  - 每个构念必有操作化列——观念定义不许直接连数据
  - 每条因果主张必附威胁清单(坎贝尔-斯坦利传统的字段化)
暗礁: 卡是计划的合同;执行中的偏离必须记「设计备忘」——事后改卡冒充
      事前设计,是 p-hacking 的设计版
```

### 卡 2:抽样方案卡(代表性的合同,误差的预算表)

```yaml
卡名: 抽样方案卡
字段:
  目标总体:      结论写给谁看(边界逐条写清:年龄/地域/时段/平台)
  抽样框:        从哪份名单/规则抽;覆盖缺口清单(谁在总体却不在框里)
  抽样方法:      概率(简单/分层/整群/PPS/多阶段)
                 | 非概率(方便/目的/配额/滚雪球——须声明放弃可算误差)
  入样概率:      p_i 已知且非零?(概率抽样的两条军规,尼曼 1934)
  样本量预算:    效应量 → 功效计算得 n₀ → ×deff(整群修正)
                 → ÷(1−预估无应答率)得接触量
  权数:          设计权数(1/p_i)·无应答调整·总体校准(人口控制变量)
  误差预算:      抽样误差(可算,报告为误差幅度)‖覆盖误差·无应答误差·
                 测量误差(不可由 n 救赎,逐条给对策)
构造规则:
  - 总体与框之间的差必须逐条登记(沉默的覆盖误差是头号事故源)
  - deff 与无应答进样本量预算,不进事后解释
暗礁: 框外之人不出声:无电话者/流动人口/平台外人群——1936 年《文学文摘》
      之败的机制(00 章 §六)在现代数据库里原样复发
```

### 卡 3:访谈提纲卡(半结构纪律——可比较性的骨架)

```yaml
卡名: 访谈提纲卡
字段:
  主题块:        3-6 块,漏斗排序(宽话题 → 核心议题 → 敏感议题后置)
  核心问题:      每块 1-3 个;开放措辞(先「怎么/什么」,慎用「为什么」启动)
  追问探针:      「能举个例子吗」「后来呢」「当时您怎么想的」
  入口问题:      无威胁暖场(建立可谈性)
  敏感问题位置:  靠后;须预先写拒答免责话术
  转写与编码计划: 逐字转写 → 开放编码 →(扎根时)持续比较 → 编码手册引用
  反身性备忘:    访谈者身份(年龄/性别/机构)可能引发的应答倾斜
构造规则:
  - 同一研究所有访谈共用同一骨架(可比性的来源)
  - 措辞中立不带前提(「您还打孩子吗」是教科书级反例)
暗礁: 提纲是骨架不是脚本——照读杀死叙事;反身性不登记=假装不存在
```

**三张卡的共同几何**:卡 1 定**问什么**,卡 2 定**证据从谁那里来**,
卡 3 定**意义从哪条路径进入记录**——三卡互链(设计卡引用抽样卡、
访谈卡挂编码计划),构成 04 章数据管道的 schema 源头。

## 三、结构引擎 1:随机化引擎(概率抽样的代数与预算)

**直觉图像**:把一枚硬币逻辑装进社会——每个总体成员的入样概率
已知且非零,于是样本统计量的**期望无偏、方差可算**(尼曼 1934)。

- **数学化身**:SE=σ/√n(实验幕一);复杂设计的修正 deff=1+(m−1)ρ
  (实验幕二);权数=1/p_i 的设计还原。三条闭式构成**样本量的
  预算语言**——钱花在 √n 上,整群偷走 (m−1)ρ 倍信息。
- **刚性从哪来**:不变性是随机化的代数事实;但"总体是什么、
  框有没有漏人"是**世界知识不是数学**——引擎的刚性止步于框的边界
  (覆盖误差住在合同之外)。
- 与[../../讲透数学/讲透数学建模/README.md](../../讲透数学/讲透数学建模/README.md)的接口:随机化引擎是
  "建模"在测量侧的对偶——建模压缩世界为方程,抽样选取世界为样本,
  两者共享"假设-代价"的合同语法。

## 四、结构引擎 2:迭代编码引擎(定性严格性的程序来源)

**直觉图像**:定性端的严格性不来自数,来自**程序的可审计性**——
持续比较(数据与数据、数据与码、码与码)、理论抽样(按理论需要
选下一个案例)、备忘录写作(想法与数据分离)。

- **程序化身**:开放编码 → 聚焦编码 → 编码手册(码名/定义/判据/
  反例)→ 双人编码一致性(κ)→ 理论饱和判据。除最后一步外全部
  **可构造**:手册可存档、κ 可计算、修订可留痕。
- **刚性从哪来**:互主观性——第二个受过训练的研究者按同一手册能
  (大致)重做你的编码。这是定性端的"复现"形态:**复现的是程序
  与判断的可追踪性,不是数值**。
- **与引擎 1 的对偶**:随机化引擎用代数担保"样本代表总体",
  编码引擎用程序担保"解释可被审查"。三角验证(00 章 §四)就是
  两台引擎的并网运行。

## 五、判定流程(把一个方法主张钉到谱系上)

```
该主张的载体能写成字段化文件吗?
  ├─ 能,且语义是计数/概率/程序 ─▶ 设计卡端:直接构造+转码(04 章)
  ├─ 能,但字段值是聚合的结果(权数/deff)─▶ 预算端:可算可监控,无直接旋钮
  └─ 不能,依赖意义判断 ─────────▶ 手艺端:程序化训练+反身性备忘,禁止硬造参数
```

(端点错配是方法合规的形式主义高发区:给田野关系上问卷,
给深描上聚类分析,两头失真。)

## 六、谱系×引擎×四支总表

| 家族支 | 谱系位置 | 主引擎 | 可构造等级 |
|--------|---------|--------|-----------|
| [研究设计与测量](讲透研究设计与测量/) | 卡 1 端 | 效度威胁清单(设计语法) | 高(设计卡/操作化列全字段化) |
| [社会调查方法](讲透社会调查方法/) | 卡 2 端 | 随机化引擎 | 高(预算闭式全可算;覆盖误差靠登记) |
| [定性方法](讲透定性方法/) | 卡 3 端 | 迭代编码引擎 | 中(程序可构造;饱和与意义不可) |
| [计算社会科学](讲透计算社会科学/) | 中段(痕迹端) | 两台引擎的移植+复现纪律 | 中高(管道可构造;代表性声明不可) |

**读表法**:一支的"科学硬度"不取决于定量定性,取决于它站在谱系
哪一段、用哪条引擎、以及它**把不可构造的部分诚实标注出来**的能力。

## ✨ 美之时刻(彩蛋第 5 枚:编码手册——互主观性装置)

✨ **美之时刻 5:编码手册——让第二个研究者能重来的装置**(意外)
编码手册把"我读懂了这段田野资料"翻译成**可移交的判断标准**:每个
码配定义、入选判据、反例与示例引文,修订留版本号。为什么美:它
不消灭判断,它让判断**可被另一个人检验与继承**——这是定性研究
对"科学要可复核"给出的诚实体面答案:复核的对象是程序与标准,
不是灵感。亲历:给你的读书笔记里任一标签写一张五字段码卡
(码名/定义/判据/反例/示例),体会"可移交的判断"与"私人感想"
的差距。

## ✍️ 练习

1. ✋ 给你关心的一个问题填一张研究设计卡,重点写满"效度威胁清单"
   六条——写不出的地方就是设计还没想清的地方
2. ✋ 设计一个"居委会整群抽样 m=15、ρ=0.06"的方案卡,用闭式算
   deff 与等效样本量,再叠 40% 无应答算接触量
3. 🐍 用实验脚本把上题的 deff 调参验证(m、ρ 各扫两档),
   对比"预算语言"与"模拟语言"两本账
4. ✋ 给"反学校文化"(或任一定性构念)写编码手册的三个码,
   每码配一个反例——反例比定义更能暴露码的边界

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:开工文件之眼**——评估任何研究,先要三张卡:
设计卡(问什么/怎么识别)、抽样卡(证据从谁那里来/误差怎么预算)、
访谈卡(意义怎么进入记录)。给不出卡的研究不是不严谨,是**无法被
审查**;而卡上"不可构造"字段的处理方式(诚实标注 vs 形式主义遮盖),
正是方法功力的分水岭。
