# 讲透社会调查方法 · 代表性军规——证据从谁那里来

> **定位句**:家族的 **GB/T 原生主支(8401710 社会调查方法)**——概率
> 抽样、问卷设计、**标准化访问**(访谈的调查形态)、调查执行(无应答
> 与覆盖误差);总调查误差是它的总账本。**分承声明**:开放式深访归
> [讲透定性方法](../讲透定性方法/README.md)——同词「访谈」两种工艺。
> 家族:[讲透社会学方法](../README.md)

## 诞生

- **谁/何时**:尼曼 1934(概率抽样理论奠基);拉扎斯菲尔德《人民的选择》
  1944(面板+标准化访问+两级传播);利克特 1946 建密歇根调查研究中心;
  Kish《Survey Sampling》1965(抽样圣经);Groves 等(总调查误差框架)。
- **因什么问题**:①几千人凭什么代表几亿人(代表性之问)②没人答、
  不在名单上怎么办(误差之问)③问法与访员怎么改变答案(反应性之问)。

## 核心问题

- **已解决(通说)**:概率抽样的代数(期望无偏+方差可算);复杂设计修正
  (权数与 deff,实验幕二);问卷与访员工艺(措辞中立/题序效应/访员培训)。
- **未解决/深水区**:无应答的非随机化(应答率长期走低——01 章主线E);
  概率-非概率混合设计的边界(方向锚,时效声明)。

## ✨ 这支最美的一个事实

**样本量不敌样本偏差**:1936 年《文学文摘》回收 240 万份问卷,预测
兰登大胜;盖洛普用数万人的科学抽样押中罗斯福——240 万输给数万,输在
**谁被问到**而不是**问了多少人**。军规算术版:SE=σ/√n 与 deff=1+(m−1)ρ
(实验幕一二)——n 只住在抽样误差一栏,事故几乎都在另外三栏。

## 假设与依赖

- 概率抽样合同:假设抽样框覆盖总体、入样概率已知且非零;代价:框外者沉默出局+成本高周期长
- 自我报告合同:假设应答者能且愿准确自报;代价:社会期许/回忆偏差
  (02 章 §三同源)
