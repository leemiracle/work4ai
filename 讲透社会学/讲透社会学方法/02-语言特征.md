# 02 · 语言特征:一门学科怎么用"证据"说话

> **本章回答五问之三:这个分支的语言——表达力、逻辑性质、规范化程度——长什么样?**
> 三栏 X 光:**术语**(它造什么样的词)/**测量语言**(它怎么把世界
> 变成数)/**话语迁移**(它的词如何进入日常论证)。每栏先答**为什么是这样**。
>
> **本章一句话**:社会学方法的语言是一台**翻译机器**——把日常概念
> 翻成指标(操作化),把人翻成数据(测量),再把方法词租借给日常
> 论证(信效度、显著性、样本代表性);它的全部力量与全部麻烦,
> 都来自**每一次翻译都是一次有损压缩,而租借出去的词都忘了自己
> 带着合同**。

## 开篇:为什么方法的词人人会用、人人误用

新手有两个相反的体验:一是"这不就是问问题记答案吗",二是"为什么
方法节的争论这么细"。两个体验同源:这门学科的词汇(样本/信度/显著)
早已渗入日常语言与媒体素养,但它的**规范用法**全部依赖一条不显眼的
前提链(构念→指标→数据→推断)。本章三栏 X 光把这条链拆开:
第一栏看它**造词**,第二栏看它**计数**,第三栏看它的词
**离开学科后发生了什么**。

## 一、第一栏:术语(它造什么样的词——构念词的户口本)

**先答为什么**:社会学研究的对象大多是**看不见的构念**(阶层认同、
相对剥夺、社会资本),方法学必须先造一套词来管理"从构念到数据"
的每一步。术语表就是一条生产线的工序单:

| 术语 | 一句话定义 | 生活在哪支 |
|------|-----------|-----------|
| 概念/构念 | 理论层面的抽象观念(concept)/为研究而明确界定的构念(construct) | 测量支 |
| 观念定义 vs 操作化定义 | 用概念界定概念 vs 用可观察程序界定概念 | 测量支 |
| 指标/变量 | 构念的可观察记号 / 取值可变的测量特征 | 测量支 |
| 信度 | 测量的一致性/可重复性(打靶的弹着点密不密) | 测量支 |
| 效度 | 测量是否测到了要测的构念(瞄准的是不是靶心) | 测量支 |
| 抽样框 | 从中抽取样本的名单/规则(总体的代理) | 抽样支 |
| 入样概率 | 每个总体成员被抽中的概率 p_i(概率抽样的命门) | 抽样支 |
| 设计效应 deff | 因复杂设计(整群/分层)而对方差的膨胀倍数 | 抽样支 |
| 无应答偏差 | 拒答者与应答者系统不同带来的扭曲 | 抽样支 |
| 覆盖误差 | 抽样框漏掉的那部分总体带来的偏差 | 抽样支 |
| 理论抽样 | 定性研究中按理论需要选下一个案例/受访者 | 定性支 |
| 编码/饱和 | 把资料归入概念类别 / 新资料不再产生新类别的停采判据 | 定性支 |
| 深描 | 格尔茨术语:把行为放回意义脉络的厚实描写 | 定性支 |
| 数字痕迹 | 平台行为留下的记录数据(read 代替 ask) | 计算支 |
| 无反应性测量 | 测量过程不扰动被测者(痕迹测量的卖点与陷阱) | 计算支 |

**构念词的生存法则**:一个好构念要过三关——**可操作化**(写得出现察
程序)、**有理论位置**(挂在某个因果/意义故事里)、**有区别度**
(与相邻构念分得开)。"相对剥夺"过三关活下来并统治了士气研究;
"组织气氛"类构念常死在第三关(与满意度混作一团)。

**反直觉发现(本章铁律之一)**:**操作化定义不是定义,是合同**。
"阶层认同=问卷第 7 题的自评等级"不等于阶层认同本身——它是一个
带适用范围、带误差、可被更换的具体方案。把操作化定义当真理,
等于把菜单当菜吃;两个研究用了不同的操作化,它们的"同一构念"
严格说**不可直接比较**(测量不变性问题的日常入口)。

## 二、第二栏:测量语言(世界怎么被变成数)

**先答为什么**:社会现象大多没有天然的数——测量语言的全部设计,
就是在"没有尺子的地方"造尺子。四件套构成这门方言的语法:

| 语法件 | 内容 | 为什么重要 |
|--------|------|-----------|
| **测量层次**(Stevens 传统) | 定类(类别)/定序(等级)/定距(等距)/定比(有真零) | 层次决定合法运算:定序变量的均值在数学上是方言,在社会学报告里是通行证 |
| **信度族** | 重测信度(跨时间)/复本信度(跨版本)/内部一致性(α,跨题目)/评分者信度(κ,跨编码人) | 四种"一致"不可互换——α 高不代表跨时间稳定 |
| **效度族** | 内容效度(题项覆盖构念域)/准则效度(与外部基准相关)/构念效度(理论网络吻合);表面效度不是效度 | 效度是整体判决,信度是必要非充分条件 |
| **潜变量语言** | 拉扎斯菲尔德潜结构(1950)→因子分析→项目反应理论(IRT) | "构念=藏在回答背后的潜在维度"——测量模型的共同祖先 |

**判读口诀**:看到任何量表得分,连问四声——**测的什么层次?哪路
信度?效度拿什么撑的?跨群体可比吗(测量不变性)?**四问过后,
"均值 3.2 对 3.5"的江湖争执当场现形:差异可能来自构念、来自题项、
也可能来自应答风格(某群体系统性往中间打分)。

## 三、第三栏:话语迁移(方法词如何进入日常论证)

**先答为什么**:方法是社会学的"对外贸易部门"——它的词被日常论证、
媒体与职场大量租借。租借过程中**合同被撕掉**,词的规范含义磨损成
修辞武器。四笔最大的租借:

| 迁移词 | 日常用法 | 原装合同(被撕掉的部分) |
|--------|---------|------------------------|
| **"你这话怎么操作化?"** | 日常质疑:你说得太虚 | 操作化是**方案不是贬义**:一个构念可以有多套合法操作化,互相不可比 |
| **"这个指标信度/效度如何?"** | 公共讨论:数据靠谱吗 | 信度≠效度(可以精确地错);α 只是内部一致性一种;高信度不担保测对了东西 |
| **"显著"(p<0.05)** | 媒体/职场:效果很明显 | 显著≠重要:大样本里芝麻差异也显著;p 值是"数据与零假设的兼容度",不是"假设为真的概率"(美国统计学会 2016 声明按通说转述;p-hacking 是合同被执行坏的著名案例) |
| **"样本有代表性吗?问了多少人?"** | 媒体素养的标准动作 | n 大小只管抽样误差;覆盖误差/无应答/测量误差与 n 无关——1936 年《文学文摘》240 万样本之败(00 章)就是这堂课的原始事故 |

**迁移的双向后果**:好的一面,方法词成了公共理性的**质检词汇**
(知道问"怎么抽的"已经是素养);坏的一面,磨损的词造成**伪严格性**
——"我们的数据很显著"在合同被撕掉后,只是一句穿制服的"我觉得"。
**本家族的立场**:把合同重新贴回词上,是 02 章存在的理由。

**一个次生现象——"定性/定量"成为日常分类词**:它原本指证据类型
(00 章 §四:多少 vs 是什么),迁移后变成阵营标签("我是定性的人")。
语言先于理论完成了范式战争的固化——这是话语迁移反噬学科自身的
罕见标本。

## 四、规范化:术语对译与国际接轨(读国际文献的最低装备)

| 英文 | 通行中译 | 易错点 |
|------|---------|--------|
| operationalization | 操作化 | 是"给构念写观察程序",不是"落实执行"的日常义 |
| reliability / validity | 信度/效度 | 日系旧译"信赖性/妥当性"仍在流通;两者独立不可换 |
| construct validity | 构念效度 | 与"结构效度"并存;与内容效度分立 |
| Cronbach's alpha | 克龙巴赫 α 系数 | 只管内部一致性;别拿它当一切信度 |
| sampling frame | 抽样框 | 框≠总体:覆盖误差住在两者的差里 |
| nonresponse bias | 无应答偏差 | 与"无应答率"不同:率高≠偏差大,关键是拒答者**怎么不同** |
| design effect | 设计效应 | deff=1+(m−1)ρ 是整群版的教科书式(实验幕二) |
| purposive/theoretical sampling | 目的性/理论抽样 | 定性研究的选样逻辑,不是"随便选" |
| saturation (theoretical) | (理论)饱和 | 扎根理论停采判据;与市场饱和无关 |
| thick description | 深描 | 格尔茨术语;不是"写得多" |
| digital traces | 数字痕迹 | 亦译数字足迹;read 数据与 ask 数据的分野 |
| computational social science | 计算社会科学(CSS) | 与"社会计算"混用需声明口径 |
| triangulation | 三角验证 | 亦译三角测量/多方印证;收敛非必然(00 章 §四) |
| margin of error | 误差幅度 | 指抽样误差的 95% 区间半宽;不含覆盖/无应答误差 |

## 五、一门学科,三种口音并存(语言的社会学)

同一现象——"为什么年轻人不愿生育"——三种口音给出三张不同处方:

| 口音 | 诊断问句 | 处方形态 |
|------|---------|---------|
| 调查口音(抽样+量表) | 多少人打算不生?哪些变量预测?各占多少? | 量表+回归:态度与约束的分布图 |
| 田野口音(访谈+民族志) | 不生育对当事人意味着什么?在什么脉络里成立? | 深描:意义的传记与关系结构 |
| 计算口音(痕迹+网络) | 搜索、社媒、平台上"不生"如何被谈论与扩散? | 痕迹数据+文本/网络:话语与传播的动力图 |

**三种口音互相供弹药**(计算口音发现议题聚集,田野口音解释意义,
调查口音测分布)——但同一个论证里混用三种口音而不声明切换,
是方法写作的大忌:每换一次口音,证据的合法动作集就换一套。

## ✨ 美之时刻(彩蛋第 4 枚:操作化——让千年争吵变成可检验分歧)

✨ **美之时刻 4:操作化定义——"把概念变成指标的合同"**(极简)
"偏见"吵了两千年没有裁判,因为它没有观察程序。操作化定义把
"偏见"改写成"在这五道题上的得分"——争吵立刻变成两件可办的
事:**改程序**(更好的五道题)或**比结果**(谁的程序预测了什么)。
为什么美:**它不裁决谁对,它把"对错之争"翻译成"方案之争"**——
文明处理不可证伪之争的标准手法,被方法学做成了工艺。代价同样
明白:方案赢不等于构念被征服(合同第一页就写着)。亲历:
给你最常挂在嘴边的一个社会词(如"内卷""躺平")写两套不同的
操作化方案,体会"同一构念、两把尺子"(✍️练习 1)。

## ✍️ 练习

1. ✋ 给"内卷"或"躺平"写两套操作化方案(行为指标/态度指标),
   并各写一条"它会测歪"的理由——操作化合同的最小亲历版
2. ✋ 找一篇媒体报道,用 §三的迁移词表逐行审:哪些方法词被租借、
   合同里哪几条被撕掉(尤其"显著"与"问了多少人")
3. ✋ 把"信度高效度低=精确地错"用一个生活例子讲给非专业者
   (提示:一把每天少 2 公斤但示数稳定的体重秤)
4. ✋ 用 §五的三种口音分别诊断你关心的一个现象,写出三张问句表,
   并标注哪两问需要三角验证(00 章 §四)
