## 一、家族定位(它在社会学宇宙里的位置)

社会学的一切主张都泡在证据的汤里:涂尔干的自杀率是官方统计表,
布迪厄的文化资本是问卷题项,《学做工》是一年半的田野笔记——
**换一个方法,同一个理论问题会给出不同形状的答案**。本家族是
840 宇宙的「工艺层」:社会学史管这门学科想过了什么,社会学理论管
它信什么,数理社会学管它怎么形式化,**本家族管它的证据是怎么
被生产、质检与限制的**。五问(体系/前沿/语言/构造/转码)的
回答见家族层五章。
