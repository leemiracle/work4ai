## 诞生

- **谁/何时**:马林诺夫斯基特罗布里恩田野(1922,参与观察规范);
  托马斯-兹纳涅茨基《身处欧美的波兰农民》(1918-20,生活史);帕克的
  芝加哥城市实验室;怀特《街角社会》(1943);默顿-肯德尔聚焦访谈
  (1946,焦点小组前身);格尔茨"深描"(1973);格拉泽-斯特劳斯
  《扎根理论的发现》(1967);Yin《案例研究》(1984,设计化)。
- **因什么问题**:①意义与过程怎么进入记录(意义之问)②没有数字的
  evidence 凭什么可检验(严格性之问)③案例凭什么超出自身(概括之问)。

## 核心问题

- **已解决(通说)**:定性严格性的程序来源(持续比较+编码手册+备忘录,
  互主观可审计);理论抽样与饱和;案例的分析性概括(指向理论命题)。
- **未解决/深水区**:扎根理论三分支(经典/程序化/建构化)对"客观
  发现"的哲学分歧;单案例概括合法性(说服力与边界条件如何分开报告)。

## ✨ 这支最美的一个事实

**持续比较法**:理论与数据必须**逐条互相比较着生长**——资料与码比、
码与码比、数据与成形的理论比,直到饱和。它把"质性洞察"从灵感叙事
改造成**可追踪的生成过程**:第二个研究者按同一编码手册可以(大致)
重走你的路(家族[03 章](../03-可构造与结构.md))。

## 假设与依赖

- 访谈合同:假设话语呈现真实经验与意义;代价:访谈者效应、回顾合理化、"说的"≠"做的"
- 在场合同:假设参与观察获得内部视角;代价:观察者效应、伦理红线、个案概括力有限
