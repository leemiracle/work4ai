## 诞生

- **谁/何时**:网络线——莫雷诺(1934);格兰诺维特弱关系(1973);
  哈佛块模型(1976);Wasserman-Faust《社会网络分析》(1994)。计算
  线——Salganik-Dodds-Watts 音乐实验室(2006);Lazer 等 14 人
  《Science》CSS 宣言(2009);LDA 主题模型(2003,通说)进入社会学;
  Abbott 序列分析复兴;Salganik《Bit by Bit》(2018)。
- **因什么问题**:①不经问就被记录,证据边界在哪(痕迹之问)②平台
  人群≠总体,代表性怎么声明(军规之问)③大规模与理论驱动怎么共存。

## 核心问题

- **已解决(通说)**:CSS 身份定义(三方合格证);痕迹类型学(read/
  ask/observe/experiment,Salganik);网络指标工具箱。
- **未解决/深水区**:痕迹的代表性(平台人群/使用强度/算法中介三重
  偏差,文学文摘之败的当代复发位);理论驱动 vs 数据漫游;伦理合流。

## ✨ 这支最美的一个事实

**音乐实验室——平行文化世界**:Salganik-Dodds-Watts 让数万名用户在
多个只在初始下载数上不同的"平行世界"里听同一批歌并下载——同一批
歌在不同世界冲上完全不同的排行榜:**成功=质量×累积优势**,初始小
扰动被放大为结局的大分歧——在线实验+痕迹组合拳的封神之作。
