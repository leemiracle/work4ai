## 诞生

- **谁/何时**:测量线——瑟斯顿等距量表(1927-29);利克特总加量表
  (1932);古特曼累积量表(1944);克龙巴赫 α(1951,统一内部一致性);
  坎贝尔-菲斯克多特质-多方法矩阵(1959)。设计线——所罗门四组设计
  (1949);坎贝尔-斯坦利《实验与准实验研究设计》(1963,效度威胁清单)。
- **因什么问题**:①构念(偏见/剥夺/认同)怎么变成可观察的指标
  (测量之问)②设计凭什么支持因果或意义的结论(设计之问)
  ③同一构念的两套测量凭什么比较(不变性之问)。

## 核心问题

- **已解决(通说)**:操作化流程成学科默认工序;信度效度分立(信度是
  必要非充分,四路信度不可互换);效度威胁可清单化。
- **未解决/深水区**:测量不变性(量表翻译/跨群后还是不是同一构念);
  构念效度的循环性(效标本身也是测量,网络整体可断、单点不可证)。

## ✨ 这支最美的一个事实

**信度-效度打靶图**:四张靶纸讲清一对概念——弹着点散(低信度)再瞄
也白搭;弹着点密但偏离靶心=高信度低效度:**精确地错**。量表报告只晒
α 不谈效度,就是只给你看弹着点、藏起靶纸(实验幕三算"密度"的账)。
