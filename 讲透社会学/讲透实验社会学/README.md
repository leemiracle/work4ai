# 讲透实验社会学 · 受控的干预——把社会过程放进可断言的实验台

> **本质一句话**:实验社会学=把「干预」引入社会研究的学科——它不满足于
> 观察社会的相关,而要在实验室与田野里**制造一个受控的差异**(随机分配的
> 处理组与控制组),让社会过程在聚光灯下交出因果;
> 一句话:**观察问「世界是什么样」,实验问「拨一下这里,世界会怎么变」——
> 而这门学科的全部尊严,在于连同拨动的代价(伦理边界与精度账单)一起摆在桌面上。**

## 一、家族定位(它在社会学宇宙里的位置)

社会学的一切因果主张都面临同一道墙:社会不能重播。涂尔干有自杀率表,
却没有「再来一遍没有工业化的法国」。实验社会学是 840 宇宙里唯一以
**制造差异**为业的家族:社会学史管这门学科想过了什么,社会学理论管它
信什么,社会学方法管证据的工艺总论,**本家族管「干预」这一件最锋利也
最昂贵的证据工艺**——随机分配之下,组间差异只有一个来源。五问
(体系/前沿/语言/构造/转码)的回答见家族层五章。

## 二、家族树(无三级明细 → 3 自定主干支)

```
讲透实验社会学/             GB/T 84021(无三级明细,自定主干支)
├── 讲透实验室实验/         自定支——机制层:合作与公平博弈(公共品/最后通牒/
│                          信任博弈);被试招募与激励相容
├── 讲透田野实验/           自定支——现场层:列表实验/审计实验/自然实验;
│                          现场与外部效度
└── 讲透实验伦理与效度/      自定支——合法性层:田野实验伦理争论/知情同意边界/
                           preregistration 与复制危机
```

> 三支的共同血统:**同一条「干预→观测→识别」链条的三段分工**——
> 实验室支管把机制搬进可控环境(内部效度优先,真钱激励),田野支管把
> 干预带进真实现场(外部效度优先,不惊扰),伦理与效度支管这条证据链的
> **合法性边界**(知情同意、效度威胁清单、预注册纪律)——没有第三支,
> 前两支的产品不被承认。
