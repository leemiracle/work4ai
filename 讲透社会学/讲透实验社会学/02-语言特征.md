# 02 · 语言特征:一门学科怎么用「干预」说话

> **本章回答五问之三:这个分支的语言——表达力、逻辑性质、规范化程度——长什么样?**
> 三栏 X 光:**术语**(它造什么样的词)/**量与单位**(它怎么把社会过程
> 变成可比的数)/**证据规范**(它凭什么信一个结论)。
> 每栏先答**为什么是这样**。
>
> **本章一句话**:实验社会学的语言是一台**对照机器**——处理(treatment)
> 对控制(control),随机(randomization)对混杂(confound),效应量
> (effect size)对显著性;它的全部力量来自「**跟谁比**」这个问句,
> 它的全部麻烦来自「比出来的数,单位是什么」。

---

## 开篇:为什么实验论文读起来像法庭笔录

新手读实验论文有两个相反的困惑:一是「这不就是 A/B 测试吗」,
二是「为什么『我们处理了三组人』这种话要写三页」。两个困惑同源:
这门学科的词汇表极小(处理/对照/随机/效应),但每个词背后都拴着
一个**效度威胁**——省略它,句子立刻从证据降格为轶事。本章用三栏
X 光看清这门方言:第一栏看它造的词,第二栏看它认的数,第三栏看
这些词怎么漏进了日常语言。

## 一、第一栏·术语:构念的户口本(能说什么,不能说什么)

**先答为什么**:实验的每个主张都必须挂在「差异从哪来」的追问上,
所以术语系统天然围绕**差异的来源与纯度**组织。

| 构念 | 一句话定义 | 典型操作化 | 血统 | 常见误用 |
|------|-----------|-----------|------|---------|
| 处理(treatment) | 研究者施加的差异本身 | 一条信息/一种制度/一个激励 | 实验-计量传统 | 与「刺激」「政策」混同——处理必须是可分配的 |
| 控制组(control) | 不受处理的对称组 | 随机分配后的对照组/安慰剂 | 同上 | 「历史对照组」冒充随机对照 |
| 随机分配 | 用机会机制分派处理 | 抽签/区组随机 | 费歇尔-农业试验传统 | 与「随机抽样」混同(前者管组间可比,后者管总体代表) |
| 混杂/混淆变量 | 同时影响分配与结果的变量 | 随机化使其对称化 | 因果推断 | 「控制了变量」≠「随机了」 |
| 操纵检查(manipulation check) | 确认处理真被被试接收 | 处理后测量认知/感知 | 社会心理学工艺 | 当成结果变量重复使用(污染) |
| 激励相容 | 报酬结构与说真话一致 | 真钱+决策挂钩(支配性/突显性/单调性) | 史密斯 1982 | 「给了钱」≠激励相容——挂钩方式才算数 |
| 社会困境 | 个体占优策略致集体次优 | 公共品自愿供给(MPCR<1) | 实验经济学 | 与「囚徒困境」混同(后者是二人离散版) |
| 条件合作 | 贡献随他人(预期)贡献调整 | 上期组均值回归贡献 | 费尔-菲施巴赫系 | 与「互惠」混同(后者含惩罚维度) |
| 公平规范(不平等厌恶) | 拒绝不利分配的偏好 | 最后通牒拒绝率 | 居特等 1982;费尔-施密特 1999 | 把拒绝当「非理性」——恰是规范执行 |
| 列表设计 | 以条目计数隐蔽敏感项 | 4 vs 4+1 条目组间均值差 | 项目计数技术 | 当成「匿名问卷」——它买的是不可识别性 |
| 内部/外部效度 | 因果纯度/可外推性 | 效度威胁清单逐项排查 | 坎贝尔系 | 「效度高」不注明哪一种 |

**构念的生存法则**:一个好实验构念要过三关——**可分配**(能随机给
一半人)、**可检查**(操纵检查能验它真到了)、**可重复**(协议标准
到别家能复跑)。「处理」靠三关活下来成为全学科的通货;「氛围」「感觉」
类构念常死在第一关(不可分配)。

**反直觉发现(本章铁律之一)**:实验语言里**「什么都没做」是一个
处理**(霍桑教训,00 章美之时刻 1)——控制组不是空白,是「另一种
被观察的方式」;安慰剂组、纯空白组、等待组,各有各的效应。读实验
先问:控制组到底经历了什么?

## 二、第二栏·量与单位:这门学科认哪些数

**先答为什么**:实验的结论要跨实验室、跨田野、跨论文比较,就必须
有**共同的量纲**;这门学科的量纲系统是围绕「支付可比」建的。

| 量 | 单位/取值 | 为什么用它 | 换算陷阱 |
|----|----------|-----------|---------|
| 支付(payoff) | 代币→按公布汇率兑真钱 | 激励相容的载体 | 汇率与展示框架改变行为(框架效应) |
| 贡献率 | 占禀赋的比例(0-1) | 跨禀赋可比 | 分母是禀赋不是组池 |
| offer 份额 x | 蛋糕的份额(0-1) | 与金额无关的公平度量 | 0.05 的「小额」在大蛋糕下不小 |
| 拒绝率/接受率 | 概率 | 规范强度的度量 | 与「惩罚成本」要一起读 |
| MPCR | m/n(每元组池的人均回报) | 社会困境的结构件 | MPCR<1 是困境存在条件,不是「亏损」 |
| 效应量 d/g | 对照组标准差为单位 | 跨研究可比的「有多大」 | 分母用哪个 SD(合并/对照)必须注明;d=0.2/0.5/0.8 只是口头惯例 |
| 统计功效 1−β | 概率 | 检出真效应的把握 | 事后「观察功效」是无意义的循环量 |
| 均值差与 SE | 原单位 | 推断的地基 | 百分点(差)与百分比(比)混报是公共报道第一大错 |

**判读口诀**:看到一个实验数字,三问定身份——**分母是什么**(禀赋?
蛋糕?哪个组的 SD?)、**汇率是什么**(代币怎么变真钱)、**跟谁比**
(哪个控制组)。三问答不清的数字,单位就是悬空的。

## 三、第三栏·话语迁移:实验词怎么进入日常论证

**先答为什么**:实验是当代社会**最普及的科学形象**——A/B 测试、
对照实验、安慰剂效应已从论文进入产品经理、医生与政策顾问的日常
语言。迁移带来普及,也带来系统性失真。

| 迁移词 | 日常用法 | 科学原义 | 迁移失真 |
|--------|---------|---------|---------|
| 「对照组」 | 「拿XX当对照组」 | 随机分配的对称组 | 任意挑一个「没做的」当对照——历史对照冒充随机 |
| 「这只是相关不是因果」 | 挡箭牌 | 随机分配下组间差可归因处理 | 被滥用为「一切观察证据无用」(自然实验:as-if 随机也算识别) |
| 「安慰剂效应」 | 「心理作用」 | 控制组本身的有效应 | 与霍桑效应混淆(被观察≠期待) |
| 「处理效应」 | 「XX 有效」 | 该处理在该总体该条件的平均因果差 | 平均效应抹平异质性(对谁有效?) |
| 「操纵检查」 | 少见 | 验证处理被接收 | —— |
| 「A/B 测试」 | 试两个版本 | 随机分流+预注册指标+功效计算 | 无功效无预注册的「AB」只是同时看两个数 |
| 「社会实验」 | 贬义「拿社会做实验」 | 受控干预的合规研究 | 与不负责任的政策试错混为一谈——恰是伦理支要分家的 |

**话语迁移的三条规律**:(1)词先走,条件留下——「对照」进了日常,
「随机」没进;(2)数字先走,单位留下——「效应显著」进了日常,
「效应量多大」没进;(3)动词先走,代价留下——「测试一下」进了日常,
「谁承担风险」没进。三条规律共同解释了为什么日常论证里的「实验」
总是比科学原义更强(声称)又更弱(程序)。

**一门学科,三种口音**——同一句「给员工涨薪提高了绩效」:

| 口音 | 诊断句式 | 处方句式 |
|------|---------|---------|
| 实验师 | 「随机涨薪组 vs 控制组,d=0.3,预注册」 | 「先小规模随机试点再推广」 |
| 计量师 | 「识别策略是什么?断点在哪?」 | 「找 as-if 随机的制度变异」 |
| 民族志师 | 「涨薪在车间里意味着什么(认可/怀疑)」 | 「先理解意义系统再谈效应」 |

三种口音都对一部分;同一个论证里混用而不注明(拿民族志的机制叙述
配实验的效应数字)是写作大忌——先定口音,再开数字。

## 四、规范化:术语对译与国际接轨

| 英文 | 通行中译 | 易错点 |
|-----|---------|--------|
| treatment / control group | 处理组/控制组(对照组) | control 此处非「控制变量」 |
| random assignment vs random sampling | 随机分配 vs 随机抽样 | 两个「随机」管两件事,必须分家 |
| manipulation check | 操纵检查 | 别译「操纵控制」;它检验处理到达 |
| incentive compatibility | 激励相容 | 与「物质激励」不同——结构才算数 |
| MPCR (marginal per-capita return) | 边际人均回报 | MPCR<1 定义社会困境 |
| effect size (Cohen's d) | 效应量 | d 的口头惯例(0.2/0.5/0.8)非判定标准 |
| statistical power | 统计功效 | 「功效不足」是设计缺陷,不是结果 |
| list experiment / item count | 列表实验/条目计数 | 不是「匿名调查」——机制完全不同 |
| audit / correspondence experiment | 审计实验/通讯(配对简历)实验 | 「审计」指派真人,「通讯」寄材料 |
| natural experiment | 自然实验 | 「自然」指 as-if 随机,不是「自然发生就行」 |
| debriefing | (事后)澄清/告知 | 伦理程序术语,不是「汇报」 |
| preregistration / Registered Report | 预注册/注册报告 | 后者是期刊级别的双盲审 |
| Hawthorne effect | 霍桑效应 | 与安慰剂效应、需求特征分家 |
| social desirability bias | 社会期许偏差 | 列表实验对付的正是它 |

## ✨ 美之时刻(彩蛋第 4 枚:效应量的翻译之美)

✨ **美之时刻 4:效应量——把「有没有用」翻译成「差多少个标准差」**(极简)
显著性回答「这个差异像不像碰巧」,效应量回答「这个差异有多大」——
d 把任意量纲的处理效应(涨薪/信息/制度)统一翻译成「对照组波动
的倍数」,跨研究、跨领域忽然可以同台比大小。为什么美:**一场延续
百年的「哪个干预更管用」的争论,被压缩成一个可比的实数轴**;
元分析的全部魔法都建立在这个翻译上。亲历:把两个你熟悉的干预结论
换算成 d 并排,大小立判——但先问分母(哪个 SD)。

## ✍️ 练习

1. ✋ 给「内卷」「氛围」这类日常词做可分配性检查:它能随机分给一半
   人吗?不能的话,实验构念的最近邻是什么?
2. ✋ 找一篇实验论文,把它的数字全部过「三问」(分母/汇率/跟谁比),
   标出悬空的单位
3. ✋ 收集三条日常论证里误用「对照组/安慰剂/只是相关」的话,分别
   写出科学原义下的纠错版
4. ✋ 用三种口音(实验师/计量师/民族志师)各写一句对同一政策的评估,
   并标注各自的失灵场景

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:对照与单位之眼**——听到任何「有效果」,先补
两个问句:跟谁比(对照组是什么)、差多少(效应量、单位是什么)?
再检查说话人的词是从科学迁来的还是被迁移磨损过的。两问一查,
产品发布会与社会学论文当场分流。
