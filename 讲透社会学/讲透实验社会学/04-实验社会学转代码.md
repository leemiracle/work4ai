# 04 · 实验社会学转代码:把干预机器搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:实验社会学的设计端(03 章谱系左端)几乎可以无损
> 转码,意义端几乎不可转码;三条代码走廊——**博弈实验台**、
> **田野测量功效账**、**预注册检查单**——把「干预→观测→识别」
> 变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是「能不能转」,是「转到哪一层」

数学家族转代码要解决「离散化」,实验社会学转代码要解决「**协议化**」:
把一段干预语言(信息改变行为/激励改变贡献)先翻成结构(支付函数/
分配清单/方差公式),再翻成代码。翻译的损耗全部发生在第一步——
所以本章先划清哪些对象第一步就走得通(绿色区),哪些走不通(红色区),
再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 实验社会学概念 | 代码化身 | 备注 |
|------------|---------|------|
| 随机分配机制 | 种子化分配清单+区组函数 | 可复现是第一公民;分配时点在招募后 |
| 公共品博弈 | 支付函数+MPCR 参数+重复轮循环 | 家族实验律一全程纯标准库 |
| 最后通牒 | 拒绝概率分段+U(x) 网格搜索+MC | 律二:最优 offer 的参数扫描 |
| 列表实验 | 组间 Bernoulli/Binomial 采样+p̂ 方差闭式 | 律三:方差保单与样本量报价 |
| 条件合作动力学 | 上期组均值×系数的迭代映射 | 衰减率与搭便车比例的扫描台 |
| 置换检验 | 重洗组标签×k 次的经验零分布 | 03 章美之时刻 5;免分布假设 |
| 功效/样本量预算 | 闭式公式或 MC 模拟 | 设计卡「功效预算」格的引擎 |
| 预注册纪律 | 检查单+时间戳的执行脚本 | 走廊 3 |

**转不动/转不动的边界(红色区)**:

1. **意义系统**:「信任氛围」「组织文化」没有支付函数——硬造参数
   只会把自己假设的东西测回来(03 章 §一铁律)。工程对策:退到
   量表与叙述,不当仿真变量用。
2. **现场的社会语境**:田野里的历史、名声与制度史压不进实验室
   协议——转码能模拟「机制的骨架」,不能模拟「语境的重量」
   (00 章 §五争论 1 的硬边界)。
3. **伦理判断**:代码能算风险-精度的量化权衡(律三的保单),
   算不了「该不该豁免知情同意」——规范问题留在审查程序,不进实验台。
4. **外推**:实验估的是「这次这个总体」;外推靠结构模型与理论,
   不靠更多算力(00 章 §五争论 2)。

**边界的一句话**:绿色区=协议端(分配+支付+推断),恰好覆盖
「干预→观测→识别」的前两步;第三步(解释与外推)是理论与建制问题,
正主在社会学理论(84014,文字提及)与混合建制(01 章主线 C)。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:博弈实验走廊(支付结构全机械化——本家族招牌)

```
社会困境/公平博弈理论 ──参数化──▶ 支付函数(MPCR·拒绝率分段·条件合作系数)
      │
      ├──一次性分析──▶ 占优策略检验·帕累托比较·最优 offer 网格
      └──重复模拟──▶ 条件合作×0.9+搭便车比例 ──▶ 逐轮衰减·末轮崩落
```

- **理论→模型**:公共品:payoff=(E−c)+MPCR·Σc,MPCR=m/n;最后通牒:
  U(x)=(1−x)(1−P拒(x))。两个函数加一组参数,就是全部社会困境的
  最小实验室。
- **算法层**:解析断言(均衡值)+蒙特卡洛(经验收敛)+参数扫描
  (搭便车比例/拒绝率分段怎么动,结论怎么动)。
- **本家族实现**:[`experiments/games_and_field.py`](experiments/games_and_field.py)
  律一/律二——断言 20 vs 32(损失 37.5%)、14.79→1.48 逐轮衰减末轮
  最低、x*=0.25(U=0.6375,贪心仅 14.9%)。
- **真实系统**:行为经济学的在线实验平台(招募-随机-真钱兑付-数据
  落盘的整条流水线);政策预演(激励结构改参数不改口号)。
- **性能工程要点**:被试循环天然可并行(按组分流 seed=base+组号,
  保证可复现);支付函数与统计断言解耦成纯函数,便于缓存与差分;
  重复博弈是 O(组×轮) 的迭代映射,扫参数先扫单参数再扫网格。

### 走廊 2:田野测量走廊(方差保单与样本量报价)

```
敏感态度测量理论 ──参数化──▶ 列表设计:v_c=4×0.25,v_t=v_c+p(1−p)
      │
      ├──闭式账单──▶ SE(列表)/SE(直接)=√((v_c+v_t)/p(1−p)) ──▶ 倍率与样本报价
      └──MC 互证──▶ p̂ 分布的偏差/方差经验值 ──▶ 无偏性+代价双断言
```

- **理论→模型**:估计量 p̂=μ处理−μ控制;方差分解「中性噪声 2.00
  vs 敏感信号 0.21」——保单的条款就这两行。
- **算法层**:2000 次重抽样给经验 SE;断言无偏(±0.01)与倍率
  落 [2.9,3.6]。
- **本家族实现**:同实验律三——理论 3.244,MC 3.209,同显著性
  样本 ×10.5。
- **真实系统**:调查机构的敏感题设计预算表(隐私换精度的报价单);
  多臂敏感测量的功效分配。
- **性能工程要点**:Binomial(4,0.5) 用四次伯努利显式生成,便于
  审计;方差公式闭式优先、MC 兜底——**凡有闭式,不用模拟;
  凡用模拟,先对闭式校准**(本走廊的方法论纪律)。

### 走廊 3:预注册与复制走廊(可信度生产线的代码化)

```
预注册卡(03 章 schema)──机械化──▶ 可执行检查单+时间戳
      │
      ├──置换检验──▶ 重洗组标签×k ──▶ 零分布与 p 值(免分布假设)
      └──功效模拟──▶ 「安慰剂世界」(零效应下 p<α 的频率≈α)
```

- **理论→模型**:分析者自由度→事前合同;检验水平→重洗机制本身。
- **算法层**:零效应世界模拟 K 次,统计 p<α 的频率——一个设计
  「诚实」当且仅当这个频率≈α;真实效应世界模拟,统计检出率=功效。
- **本家族实现**:律三的单次实现+03 章 ✍️练习 3 的十行置换检验
  即其最小版;完整版留作本章练习 2。
- **真实系统**:注册报告的审稿流水线;多站点复制的协议对齐工具
  (同一脚本,不同站点种子)。
- **性能工程要点**:置换检验 K 次重算组间差——把统计量写成
  O(n) 增量函数(和/平方和),K×n 不存样本;功效模拟是批处理
  作业,按 (d,n) 网格分片并行。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:A/B 测试平台——实验设计卡的工程化

- 产品实验=实验社会学的日常形态:分流(随机分配)、对照版本
  (控制组经历什么,霍桑条款)、指标(主结果预注册)、功效预算
  (样本量/时长)。**没有功效预算与预注册指标的「AB」只是同时看
  两个数**(02 章话语迁移表)。
- 工程纪律:peeking 禁令对应序贯检验(多次看数据会把 α 吃掉);
  溢出(用户互传)对应组间独立性假设的破坏——社会实体的实验
  独有,零件的实验没有。

### 落点 2:操纵检查→漏斗质检——「处理到达」的监控

- 实验的「处理未到达即无效」在工程里是漏斗质检:曝光≠看到,
  看到≠理解。操纵检查的三件套(时点/标准/通过率)直接翻译为
  曝光埋点、停留时长、注意力题;通过率写进数据质量门禁。

### 落点 3:样本量报价单——方差保单的产品版

- 任何「要不要加样本」的会议,先跑走廊 2 的账单:当前 SE、
  目标 SE、所需 n(精度按 1/√n 收敛,翻倍样本只买 30% 精度);
  敏感指标(隐私/代理指标)先算设计效应再报价。列表实验的
  ×10.5 是这条纪律最响的例证。

### 落点 4:离线-在线指标对应——实验室与田野的工程版

- 实验室(内部模拟/小流量)结论外推到田野(全量),正是 00 章
  内部效度-外部效度之争的工程形态:内部通过≠全量成立,流量
  分层、时段效应、生态位(早期用户≠全量用户)都是「学生被试」
  问题的变体。对策:小流量→大流量的**梯度布防**+多站点复制
  (00 章 §五的解法直接复用)。
