# 讲透实验伦理与效度 · 证据链的合法性——知情同意、效度威胁与预注册

> **定位句**:这支负责"合法性层"——实验证据要被承认必须过的三道关:伦理(知情同意边界/欺骗的必要与补偿)、效度(内部-外部效度的威胁清单)、可信度(preregistration 与复制危机后的程序重建);纪律只有一条:**没有这道工序,前两支的产品不被承认**。
> GB/T 13745 84021 实验社会学 · **自定主干支**(GB/T 未列三级明细,家族自定)。
> 家族:[讲透实验社会学](../README.md)

## 诞生

- **谁/何时**:纽伦堡法典 1947 与贝尔蒙报告 1979(尊重人/有利/公正三原则,IRB 建制);米尔格拉姆 1963 与津巴多 1971(欺骗与压力的争论原型);坎贝尔 1957 立内部/外部效度之轴,库克-坎贝尔 1979 与沙迪什等 2002 扩成四种效度与威胁清单;复制危机总账:2015 大规模心理学复制研究(通说量级:约四成复制率)与 2016 实验经济学复制研究(经典效应复制率显著更高);此后 preregistration/Registered Report 走向常规(01 章主线 B)。
- **因什么问题**:①知情同意与处理有效结构性冲突,边界在哪(同意之问)②组间差异什么时候真的算处理造成(效度之问)③「显著」的结果为什么经常复制不出来,程序怎么修(可信之问)。

## 核心问题

**已解决(通说)**:效度框架——内部/外部/统计结论/构念四效度+威胁清单成为设计语法(家族三张结构卡的底层);伦理程序——风险极小化审查、事后澄清、不可识别化汇总成为田野默认;病理诊断——分析者自由度(forking paths)+发表偏倚+功效不足=复制危机三因模型(通说)。

**未解决/深水区**:豁免边界——大规模平台实验与审计实验的同意豁免条件仍在逐案规则化(01 章主线 A);效应异质性与外推——平均效应藏住"对谁有效",复制失败与站点异质性难分离;欺骗的累积外部性——污染被试池与"被试猜测"的长期成本。

## ✨ 这支最美的一个事实

**预注册是把「自由度」锁进抽屉,不是把科学家锁进抽屉**:同一份数据、多种切法、只报显著的那种——复制危机的病理不在造假,在合法的选择。预注册卡(假设/主检验/排除规则事前封存)把分析路径从**事后结果选择器**变成**事前合同**——科学共同体用程序修复自己,而不是用道德口号修复自己(03 章预注册卡的原产地)。

## 假设与依赖

- 伦理审查可程序化:风险分级与豁免判据可写成分层规则——买到边界的可预期性,付出逐案裁量空间的压缩
- 效度威胁可枚举:清单主义假设威胁可预先命名;程序可信假设:预注册计划能覆盖数据的真实复杂性(探索性分析的合法空间须同卡声明)
- 与[../../../讲透数学/讲透数学建模/README.md](../../../讲透数学/讲透数学建模/README.md)互链(功效与检验水平的骨架);红线:涉伦理议题只作程序性陈述,不作评价
