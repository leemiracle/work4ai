# 讲透实验室实验 · 合作与公平博弈——机制的可控放大

> **定位句**:这支负责"机制层"——把社会过程搬进可控环境放大观察:合作怎么产生又怎么被稀释(公共品)、公平规范怎么执行(最后通牒/信任博弈)、以及支撑这一切的工艺标准(被试招募与激励相容);纪律是**内部效度优先**:宁可世界暂时缺席,不让机制混入杂质。
> GB/T 13745 84021 实验社会学 · **自定主干支**(GB/T 未列三级明细,家族自定)。
> 家族:[讲透实验社会学](../README.md)

## 诞生

- **谁/何时**:张伯伦 1948(课堂市场实验首例);史密斯 1956 起双向拍卖系列、1982 激励相容三条件(支配性/突显性/单调性);居特等 1982(最后通牒:低 offer 被拒);艾萨克-沃克 1980s(公共品:首捐高-逐轮衰减-末轮崩落);伯格等 1995(信任博弈);费尔-施密特 1999(不平等厌恶);菲施巴赫-加赫特 2010 前后(条件合作系统测量,通说)。
- **因什么问题**:①社会困境里人合作多少、为何衰减(合作之问)②拒绝正 offer 的"损己"行为说明什么(公平之问)③怎么保证被试说的就是做的(激励之问)。

## 核心问题

**已解决(通说)**:公共品首捐约禀赋一半、逐轮衰减、末轮崩落——条件合作被搭便车者稀释(家族实验律一的 14.79→1.48);低 offer 被系统性拒绝,提议者让利接近最优期望收益点(律二:x*=0.25,U=0.6375);激励相容=真钱+挂钩方式三条件("给了钱"≠"挂钩对了")。

**未解决/深水区**:跨社会幅度与制度相关性(WEIRD 批评后的全球参数表仍在积累);学生被试池的代表性与污染(重复被试/经验效应);社会语境的实验室压缩——名声、历史与制度进不了协议怎么办。

## ✨ 这支最美的一个事实

**公平是期望收益最大化的解**:把响应者的经验拒绝率(0.9/0.5/0.15/0.05 阶梯)当真实约束,提议者的 U(x)=(1−x)(1−P拒(x)) 在 x*=0.25 取最大——贪心 offer 0.05 的期望收益只有它的 14.9%。**规范不是贴在理性上的道德装饰;当违规会被惩罚,遵守规范本身就是最优化**(家族实验律二的原产地)。

## 假设与依赖

- 激励相容假设:真钱挂钩揭示真偏好(史密斯三条件)——买到决策真实性,付出社会语境的压薄
- 被试=代理决策者:学生/众包样本代表目标人群是假设不是结论
- 博弈零假设(均衡预测)来自数理社会学(84024,同宇宙,文字提及);随机化骨架与[../../../讲透数学/讲透数学建模/README.md](../../../讲透数学/讲透数学建模/README.md)互链
