# 实验社会学思维技能卡(讲透实验社会学 · GB/T 84021)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **设计类**:实验设计、随机对照、处理组/控制组、随机分配 vs 随机抽样、
  区组随机、功效计算、样本量
- **博弈类**:公共品博弈、搭便车、MPCR、社会困境、最后通牒、信任博弈、
  条件合作、公平规范、不平等厌恶
- **田野类**:田野实验、列表实验/条目计数、审计实验/通讯实验、
  自然实验、as-if 随机、社会期许偏差
- **效度类**:内部效度、外部效度、霍桑效应、安慰剂组、操纵检查、
  WEIRD 样本、溢出与污染
- **制度类**:知情同意、IRB/伦理审查、事后澄清、欺骗协议、
  preregistration/预注册、Registered Report、复制危机、效应量

## ② 核心思维模式(这个分支怎么想问题)

1. **对照优先**:看到「X 之后变好了」先问——跟谁比?控制组经历了
   什么(它真的「什么都不做」吗)?没有对照的差异是轶事不是证据
2. **随机之辨**:随机分配(组间可比)≠ 随机抽样(总体代表)——
   两个「随机」管两件事,混用是公共讨论第一大错
3. **协议不是心态**:可分配的只有协议(信息/激励/制度),心态是
   协议的输出——给「信任氛围」上随机化是把自己假设的测回来
4. **代价之眼**:每个设计买一样付一样——列表实验买隐私付 3.24 倍
   SE;实验室买机制赔代表性;没有免费的处理
5. **梯度布防**:内部效度与外部效度不可兼得——实验室证机制、田野
   证在场、多站点证边界,不站队,布防
6. **程序可信**:范式百年未变,可信度门槛五年一升——先查预注册与
   伦理三件套,再看效应量

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 公共品支付函数(MPCR 结构) | 把「个体理性 vs 集体最优」做成可计算两难;合作衰减的模拟 |
| 最后通牒 U(x)=(1−x)(1−P拒(x)) | 把规范执行变成提议者的最优化;公平的收益基础 |
| 列表实验方差保单 | 敏感话题测量的精度报价:SE 倍率=√((v_c+v_t)/p(1−p)) |
| 效应量 d 与功效公式 | 「有多大」与「要多少样本」的跨研究通货 |
| 置换检验(重洗组标签) | 免分布假设的组间检验;小样本与审计数据 |
| 三张结构卡(设计/操纵/预注册) | 开工前的合同书;缺格即设计未完成 |
| 激励相容三条件(支配/突显/单调) | 检查「给钱」是否等于「挂钩」 |
| 效度威胁清单(Campbell 系) | 逐项排查因果纯度的漏点 |
| as-if 随机判据(自然实验) | 制度变异(抽签/断点)的识别合法性 |

## ④ 常见误区与禁忌

- **把「有对照」当「随机对照」**:历史对照组、自愿对照组都混着
  选择——随机化才是混杂的对称化机器
- **「不显著=无效应」**:功效不足时只能宣布「未检出」,不能宣布
  「不存在」;先看样本量再看 p 值
- **效应量当判决**:d=0.2/0.5/0.8 只是口头惯例;分母用哪个 SD、
  效应是否异质,必须先问
- **操纵检查当结果用**:检查本身是被试经历,混进结果变量就是污染
- **给心态上随机化**:处理必须是协议;「提高信任的培训」要先翻译
  成可分配的信息/激励/制度
- **列表实验当匿名问卷**:它买的是不可识别性,付的是 3.24 倍方差
  与 ×10.5 样本——保单条款要先读
- **peeking**:多次看数据再决定停不停,α 被吃掉——序贯设计或
  预注册停时,二选一
- **仿真替代识别**:模拟造「安慰剂世界」检验设计,不能替代
  随机化/as-if 随机本身
