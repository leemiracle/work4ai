# 讲透田野实验 · 列表/审计/自然实验——现场的外部效度

> **定位句**:这支负责"现场层"——把干预带进真实现场:敏感态度的隐蔽测量(列表实验)、歧视与差别对待的现场度量(审计/通讯实验)、制度变异的免费实验室(自然实验);纪律是**外部效度优先**:宁可控制漏一些,不让世界缺席。
> GB/T 13745 84021 实验社会学 · **自定主干支**(GB/T 未列三级明细,家族自定)。
> 家族:[讲透实验社会学](../README.md)

## 诞生

- **谁/何时**:列表实验(条目计数技术;统计学源头 1970s 末,政治学 1990s 中期起系统应用——库克林斯基等);通讯审计经典 2004(贝特朗-穆莱纳森:简历署名不同的 callbacks 差);自然实验经典安格里斯特 1990(越战抽签的自然随机);李斯特 2001 前后(体育卡市场田野实验,实验室-田野对照);莱维特-李斯特 2007(实验室外推的制度检验);杰伯-格林《田野实验》2012(革命的教科书)。
- **因什么问题**:①敏感态度直接问就撒谎,怎么测(社会期许之问)②真实机构的差别对待怎么现场捕捉(歧视之问)③不能随机的地方,制度变异能不能当随机用(as-if 随机之问)。

## 核心问题

**已解决(通说)**:列表估计量无偏——p̂=μ处理−μ控制,被试永不被直接问(家族实验律三);审计/通讯设计可度量现场差别对待,配对设计规范成形;自然实验合法性判据=抽签/断点/行政规则的 as-if 随机+机制可辩护。

**未解决/深水区**:3.24 倍 SE 的压缩(双列表/修正估计仍在推);溢出与一般均衡——局部田野效应外推到全量会变号(工程版见家族 04 章落点4);审计实验对第三方(被审计机构)的伦理定位(伦理支主场)。

## ✨ 这支最美的一个事实

**方差保单**:列表实验用"多一条、不告诉你哪条"买来诚实的回答——保费可闭式算出:四条中性条目方差 2.00 淹没敏感信号 0.21,SE=直接提问的 √(2.21/0.21)≈3.24 倍,同显著性样本 ×10.5(家族实验律三:MC 2000 次无偏,偏差 −0.0010,经验倍率 3.21)。**伦理代价拿到硬形式,权衡才可能理性**。

## 假设与依赖

- 随机化/as-if 随机假设:组间差异只剩处理(列表实验还要求两组对中性条目同分布——设计对称性)
- 无设计效应假设:敏感条目不改变对中性条目的回答(不满足则方差公式失真)
- 现场可控性弱于实验室:污染/溢出/依从损失都要预注册处理规则;识别骨架与[../../../讲透数学/讲透数学建模/README.md](../../../讲透数学/讲透数学建模/README.md)互链
