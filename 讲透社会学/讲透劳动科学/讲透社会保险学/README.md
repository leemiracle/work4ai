# 讲透社会保险学 · 风险的定价车间——用确定的缴费买不确定的兜底

> **定位句**:这支是家族的**主轴定价车间**——社会保险是俾斯麦发明的风险池
> (1883-89,通说):小额缴费汇成池子,支付少数人的大额损失,给"会磨损的
> 商品劳动力"上官方保修;两条血脉(俾斯麦的收入关联 vs 贝弗里奇 1942 的
> 普遍统一),五张保单(养老/医疗/失业/工伤/生育),一门手艺(**费率与
> 替代率的定价语法**),一个当代考题(缴费绑定标准合同,就业却在灵活化
> ——**便携化**是适配性大修)。GB/T 13745 840 社会学 · 84074 劳动科学 ·
> **GB/T 原生支 8407440**。家族:[讲透劳动科学](../README.md)

## 诞生

- **谁/何时**:俾斯麦三部保险法(1883/1884/1889,通说)立风险池;贝弗里奇
  报告(1942)立普遍主义;McCall(1970)/MP(1994)反哺失业保险设计;2010s-
  平台灵活就业冲出覆盖缺口,便携化成为制度前沿(检索校准 2026-09-07)。
- **因什么问题**:①工资中断风险为何不能靠私人市场(逆向选择)②池子怎么
  定价才既养得起又不毁激励③缴费怎么跟着人走(便携)。

## 核心问题

**已解决(通说)**:强制参保破解逆向选择;风险池的大数定律底盘;缴费-
给付的精算恒等式;经验费率的激励修复(实验律三:投资 0→2.47 级,事故率
降 41%)。**未解决**:现收现付的代际平衡(费率-替代率-退休年龄三角);
便携化接口;失业保险最优刻度(实验律二);指数化选择。

## ✨ 这支最美的一个事实

**现收现付制是一张没有写出来的代际合同**。今天的缴费人并不是把钱存给
明天的自己——缴费直接支付今天退休者的养老金;他们将来领钱时,依赖的是
那时还有人在缴费。**这份合同的标的物不是钱,是下一代的就业与缴费能力**
——老龄化必然表现为财务问题;"基金穿不穿底"之争,争的是执行条款。
