## 诞生

- **谁/何时**:芒斯特伯格《心理学与工业效率》(1913)开应用之端;霍桑
  实验(1924-32)与梅奥《工业文明的人类问题》(1933)立"社会人"命题;
  Maslach 倦怠三维(1980s,通说)建制;当代:算法监督下的数字倦怠成为
  新战场(01 章主线 A 体验侧,检索校准 2026-09-07)。
- **因什么问题**:①报酬之外什么在驱动工作行为②谁适合哪个岗位,怎么测
  ③长期高压工作如何把人耗干④生涯转折期的认同怎么重构。

## 核心问题

**已解决(通说)**:激励的多因素结构(保健因素消不满/激励因素生满意);
倦怠的三维结构与测量。**未解决**:倦怠量表跨文化与跨职业等价;
算法管理下"被评分"的心理后果。

## ✨ 这支最美的一个事实

**灯调暗,产出也涨——被关注本身就是激励**。霍桑工厂本来要测照明与产出
的剂量关系,结果怎么调灯都涨:真正起作用的变量不是灯,是"有人在意你"。
这一发把泰勒的经济人假设打出一道裂缝:工资与工时之外,**意义与被看见**
进入激励的语法表。
