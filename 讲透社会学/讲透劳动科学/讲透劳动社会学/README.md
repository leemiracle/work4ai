## 诞生

- **谁/何时**:马克思《资本论》"工作日"章(1867)供阶级力量之问;
  Braverman《劳动与垄断资本》(1974)开山立派;Doeringer-Piore《内部
  劳动力市场》(1971)与格兰诺维特《找工作》(1974)供分割与网络两翼;
  2010s 起平台算法管理成为主战场(01 章主线 A,检索校准 2026-09-07)。
- **因什么问题**:①工作的组织由谁做主、代价归谁②同样的努力为何在不同
  市场段卖不同的价③技术变迁把技能搬向哪里④劳动者如何活出策略与意义。

## 核心问题

**已解决(通说)**:控制权上移是泰勒制-福特制-算法管理的共同逻辑;
内部劳动力市场的行政定价。**未解决**:去技能化论战(双录);算法控制的
边界;平台劳动者身份认定(法域拉锯);不稳定就业下的意义重构。

## ✨ 这支最美的一个事实

**你被去技能化的不是机器,是分工**。Braverman 的读法:把工作拆成"概念"
(计划/知识)与"执行"(照做),概念收进管理层,执行留给车间;技能随
知识上移,劳动者变成可替换的执行端。**控制人的最稳办法不是造更强的机器,
是把"想"从 ta 的工作里拿走**——抗争史就是把"想"抢回来的历史。
