# 04 · 劳动科学转代码:把劳动的形式面搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:劳动科学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**Beveridge 分离走廊**、
> **McCall 双面账走廊**、**经验费率激励走廊**——把"两种失业在
> UV 平面上可分离""失业保险是一笔显式换购""保费定价即安全激励"
> 变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",劳动科学转代码要先过**口径关**
(02 章"构念的制度户口"):把一项劳动主张("失业与空位并存是搜索
稳态")先翻成模型(匹配函数+分离率+流量稳态),再翻成代码。
翻译的损耗发生在两处——**总量理想型**的简化(制度细节压进 A)与
**意义面**的丢弃(控制/自主进不了状态方程);所以本章先划清哪些
对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条走通
了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 劳动科学概念 | 代码化身 | 备注 |
|---------|---------|------|
| 匹配函数稳态 | U←U+s(1−U)−A√(UV) 迭代+解析根对表 | 实验律一;稳态方程二次闭式解 |
| Beveridge 分离 | 双曲线对照+双高点检验+Spearman 断言 | 曲线凸,线性 r 与秩 ρ 分开报 |
| 保留工资 | 离散报价网格上的不动点迭代(后缀和+bisect) | 实验律二;O(K) 每步 |
| 平均失业期/接受工资 | 几何分布均值+截尾均值(理论)vs 蒙特卡洛(仿真) | 两值对表即自校验 |
| 风险池定价 | 费率=α·池均+(1−α)·自身;索赔伯努利仿真 | 实验律三;基金结余做偿付断言 |
| 安全投资响应 | 近视优化:min{期望保费+δ残余+级成本} | 决策确定化,噪声留在费率结算 |
| 事故金字塔 | 分层计数+比例断言 | 报告文化参数化(报告率→塔基可见度) |
| 三张结构卡 | 定长字段记录(dict/dataclass) | 卡 1/2/3 的数据化;主位栏强制非空 |

**转不动(红色区)**:

1. **劳动的意义与认同**:没有状态方程——"工作好还是坏"由劳动者
   与制度互相定义,测量改变被测者;工程对策:退到岗位结构卡的
   主位栏(03 章),不当仿真变量。
2. **车间政治与控制权的争夺**:Braverman 之问是意义争夺,不是参数;
   代码能算"评分机制改变了离职率",算不了"控制感被侵蚀"——
   后者只能进卡片的主位备注。
3. **口径本身的合法性**:调查失业率 vs 登记失业率哪个"对"是制度
   选择;代码只接给定口径,不裁口径(02 章口径之争)。
4. **α 与 b 的最优取值**:旋钮的数学可算(实验律二/三给边际账),
   最优值带规范权重(共济值多少),代码不豁免政治判断。

**边界的一句话**:绿色区=动力学类+定价类+计数类,覆盖"摩擦与
池化的直觉校准";红色区提醒:**转码是劳动主张的使用说明书,
不是劳动的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:Beveridge 分离走廊(匹配引擎的扫描台)

```
匹配命题 ──参数化──▶ M=A·√(U·V)+分离率 s ──扫描──▶ 稳态(U*,V;A)
      │
      └──断言──▶ 沿曲线移动(V 变)/曲线外移(A 变)/双高点存在
```

- **理论→模型**:劳动力归一;每期流入 s(1−U)、流出 A√(UV)
  (不超过失业存量);稳态 U²−(2+A²V/s²)U+1=0 取小根。
- **算法层**:迭代到 |ΔU|<1e-13;解析根闭式对表(误差<1e-9);
  相关性用双指标(线性 r=−0.922,秩 ρ=−1.0——**曲线凸,只报
  线性 r 会低估单调性**)。
- **本家族实现**:[`experiments/matching_search_insurance.py`](experiments/matching_search_insurance.py)
  律一——V 从 0.010 到 0.050,U* 从 12.30% 降到 3.01%(ρ=−1.0);
  A 从 0.50 降到 0.36:同一 V=0.035 上 U 从 4.20%→7.54%,复原需
  空位+93%,双高点 (6.05%,0.045) 存在。
- **真实系统**:招聘漏斗的**匹配效率监控**(落点 1);裁员潮与
  空位潮并存的诊断(是需求还是错配);再培训政策的压力测试
  (A 恢复多少才能压回目标失业率——93% 那个数的用途)。
- **性能工程要点**:稳态迭代是收缩映射,固定步数内必收敛,不需要
  事件队列;**参数扫描的每格独立可并行**(seed=base+格号);
  断言解析解与仿真解逐点对表,是把"模型写对了"从信仰变成测试。

### 走廊 2:McCall 双面账走廊(搜索的固定点与蒙特卡洛)

```
搜索命题 ──参数化──▶ 对数正态报价+保留工资 w*(b) ──对照──▶ {低金臂, 高金臂}
      │
      └──记账──▶ 成本面(失业期/基金支出)+收益面(接受工资)──▶ 换购率
```

- **理论→模型**:w* 由动态规划不动点给出:
  w*=[(1−β)b+βS(w*)]/(1−βF(w*));失业期=1/(1−F(w*));
  接受工资=S(w*)/(1−F(w*))。
- **算法层**:报价网格 K=4001(等权,正态逆变换),后缀和+bisect
  把每步固定点迭代压到 O(log K);蒙特卡洛每臂 2 万段失业期,
  与理论值对表(±8%/±3% 以内)。
- **本家族实现**:同实验律二——b 从 0.4 到 1.0:w* 1.700→1.947,
  失业期 5.28→7.55 个月(+2.27),接受工资 +11.2%,每段失业基金
  多付 5.44 个月失业金;换购率:每多搜 1 个月≈+4.9% 接受工资。
- **真实系统**:失业保险替代率的**政策沙盘**(落点 2);离职缓冲
  期的求职预算设计("再看看"的机会成本算术);招聘方的等待博弈
  (候选人的保留工资随市场热度移动)。
- **性能工程要点**:不动点迭代与蒙特卡洛**解耦**(先解 w*,再仿
  真)——重跑政策参数只动前者,秒级;理论值先算后仿,两值对表
  即回归测试;**截尾均值对报价分布形状敏感**,换分布须重验收敛。

### 走廊 3:经验费率激励走廊(池化引擎的制度对照)

```
池化命题 ──参数化──▶ 费率=α·池均+(1−α)·自身 ──对照──▶ {统一费率臂, 经验费率臂}
      │
      └──断言──▶ 投资(组别)/事故率/交叉补贴/基金结余 四联表
```

- **理论→模型**:60 家企业风险异质(高/低组),安全投资每级事故率
  ×0.75、级成本线性;近视优化 min{期望保费+δ残余+级成本};
  索赔按敞口伯努利实发,费率按近 3 期滚动结算。
- **算法层**:决策确定化(企业知自身工艺,噪声只进费率结算)——
  **断言的锐度来自解耦**:投资是制度确定性的,账目是随机的;
  每期 O(企业×敞口),24 期毫秒级。
- **本家族实现**:同实验律三——统一:投资 0.00/0.00(高风险每期
  白拿 135 补贴);经验(α=0.3):2.47/0.00,事故率 5.02%→2.97%,
  交叉补贴 ±149→±18,基金结余均<3%。
- **真实系统**:保险/保障产品的**定价结构评审**(落点 3);外包
  与自营的安全责任设计(谁担风险,谁就投资安全);评分体系的
  激励审计(把"评分"当费率读:它内化了谁的风险)。
- **性能工程要点**:制度对照要**共享企业生成种子**(840740)——
  差异来自规则不来自抽样;α 扫描外循环可并行;**基金结余是制度
  仿真的不变量断言**(定价再巧,养不起池子都是废案)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:招聘漏斗=匹配函数,监控它的 A 而不是只看人数

招聘漏斗(曝光→申请→面试→offer→入职)就是离散化的匹配过程:
候选人池是 U,开放岗位是 V,漏斗各环的转化率合成一个 A。多数
团队只盯"招到几个人";匹配引擎的读法是**三量联读**:岗位空置
时长(V 侧)、人才池深度(U 侧)、漏斗转化(A 侧)——空岗久+
候选人多并存,说明 A 病了(要求错配/流程迟滞),加人手(推 V)
是沿曲线白跑,93% 那个数的日常版。

### 落点 2:离职与空缺的"双面账"——裁员的搜索账单

裁员决策常只记省下的固定成本;搜索账的另一面:被裁者的再就业
摩擦(行业 U)、重建团队的匹配成本(岗位 V 与新人的磨合期)。
McCall 的算术给一页沙盘:市场热度(报价分布)×再就业支持(b 的
企业侧变体,如缓冲金/内推)决定平均空窗期与"回流质量"——
**缓冲金买的不只是善意,是匹配质量**(实验律二收益面的管理版)。

### 落点 3:定价即激励——把你身边的"大锅饭"费率改成经验制

一切内部资源定价(云成本分摊/测试机时/事故赔偿池)都有统一费率
的搭便车问题:用量与风险不挂钩,节约无收益。经验费率的改造清单:
定**可观测的自身风险信号**(近 N 期的实际用量/故障率)、定**共济
权重 α**(别拆成纯自付,高风险者被逐出就失去池子意义)、保留
**基金平衡断言**(总收费≈总成本)。改完先跑对照仿真(走廊 3 的
内网版)再上线。

### 落点 4:未遂报告系统——把塔基变成数据

生产系统的事后复盘常只记"重伤"(重大故障);把**未遂事件**
(差点点火/差点删库/差点超卖)设为免责报告项并计数,事故金字塔
的塔基才可见——安全管理体系卡的"报告文化"栏就是它的宪法条款。
配套纪律:未遂数据只用于改系统不用于罚人(报告率是生命线),
指标按**每百万工时**(或每千次发布)归一,跨期比较先对口径。
