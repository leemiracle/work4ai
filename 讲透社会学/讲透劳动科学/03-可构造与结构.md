# 03 · 可构造与结构:哪些劳动对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:劳动科学的对象沿一条**可构造谱系**排开——
> 匹配函数端**严格可构造**(UV 动力学算得动、解析解对得上、断言
> 得了),费率公式端**严格可构造**(风险池的定价几何可仿真可断言),
> 岗位结构端**半可构造**(卡片带判断),劳动的意义端**几乎不可
> 构造**(认同/车间政治/工作意义只有田野);全谱系共享两具结构
> 引擎:**匹配引擎**(M=A·√(U·V) 的出清几何——两种失业在 UV 平面
> 上分离)与**池化引擎**(风险池的定价几何——共济与激励的 α
> 之辨);而"一项劳动研究"可以压进三张**结构卡**(岗位结构卡/
> 社保方案卡/安全管理体系卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
UV 动力学 ── 费率公式 ── 保留工资 ── 岗位结构卡 ── 社保方案卡 ── 安全体系卡 ── 工作意义/车间政治
   │                                                                                  │
严格可构造(可断言)                                                     几乎不可构造(只有田野与判断)
  └── 稳态有解析解、仿真贴理论、能过 assert                          └── 只能在访谈与在场中操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:匹配
函数的语义是"每期 M 对匹配发生",输入输出明确;而"工作意义"的
语义是劳动者与制度的**互相定义的长期关系**——被测者会因测量改变
行为(02 章的口径之眼),仪器无法装配仪器。本章先盘家底,再看两具
结构引擎,最后把劳动研究压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **UV 稳态动力学** | U←U+s(1−U)−A√(UV) 迭代;解析根 U²−(2+A²V/s²)U+1=0 | 低(实验律一全程可跑) | 匹配函数是总量黑箱;制度细节全压进 A,A 的估计口径敏感(00 章) |
| **Beveridge 分离** | 两条曲线(不同 A)的对照+双高点检验 | 低 | 现实数据的 A 变动与 V 变动常常同时发生,识别要靠时间结构 |
| **保留工资** | McCall 固定点迭代(离散报价网格) | 低 | 报价分布的形状假设强;接受概率不可直接观测 |
| **风险池定价** | 费率=α·池均+(1−α)·自身;索赔伯努利仿真 | 低 | "自身风险可观测"是理想化;真实经验费率按历史索赔滚动(实验律三注记) |
| **事故金字塔** | 未遂/轻伤/重伤的分层计数 | 中 | 比例因行业而异(1:29:300 是经验非定律,通说);报告文化决定塔基可见度 |
| **岗位结构卡** | 三栏 schema(§四) | 低 | 岗位评估的"点数法"带判断;主位意义必须显式登记 |
| **社保方案卡** | 三栏 schema(§四) | 低 | 精算假设(利率/工资增长/长寿)是政治选择,不是技术参数 |
| **安全管理体系卡** | 三栏 schema(§四) | 低 | 卡片管体系不管现场——现场的隐患辨识永远填不满 |
| **工作满意度/倦怠量表** | 心理测量构造 | 中 | 构念效度争议;跨文化等价(心理学正主 190 未建,声明) |
| **工作意义/车间政治/劳动认同** | 田野与访谈 | **不可构造** | 压缩即失真;测量改变被测者 |

**反直觉发现(本章铁律)**:**本学科的可构造性与"是否涉及数字"
无关,与"规则面/意义面"的分工有关**。最老的制度(风险池,1883)
反而最可构造——因为保险的**规则面**(费率/给付/资格)天然有限
可描述;最新的现象(算法管理)再数字,只要涉及控制与自主的**意义
争夺**,照样不可构造。**规则可构造,意义不可构造;结构可断言,
关系只能田野**——拿意义硬造指标(用"接单量"测自主性)是两头
都不是。

## 二、结构引擎 1:匹配引擎(搜索摩擦的出清几何)

**直觉图像**:失业的湖与空位的山之间没有桥,相遇靠随机搜索——
匹配函数就是这座桥的通过率。

- **数学化身**(实验律一):劳动力归一,分离率 s 外生,每期匹配
  M=A·√(U·V);稳态 s(1−U)=A√(UV) 有解析根。A=0.50 时,V 从
  0.010 到 0.050,U* 从 12.30% 单调降到 3.01%(Spearman ρ=−1.0)。
- **三条刚性**:
  1. **负相关刚性**:同一条曲线内 U 与 V 必然反向——需求冲击的
     几何是"沿曲线移动",不是"随机漂移"。
  2. **外移刚性**:A 下降使每个 V 上的 U 都变高(A=0.50→0.36:
     同一 V=0.035 上 U 从 4.20% 升到 7.54%)——结构性冲击是
     "曲线本身移动",且存在 U、V 双高的稳态(6.05%,0.045)。
  3. **复原代价刚性**:A 下降后要把 U 压回原位,空位须多投 93%——
     修摩擦比补需求贵一个数量级,结构性失业的顽固性有算术本体。
- **理论地位**:这是"摩擦性失业"概念的机制化身——U 与 V 并存
  不是失灵,是搜索的稳态;匹配效率 A 成为政策对象(培训/信息/
  住房/资格互认全都写进 A)。
- **刚性从哪来**:总量匹配函数的凹性与流量稳态是刚的;软的地方
  在**微观基础**(谁和谁匹配的细节被黑箱化)——用总量断言宏观
  分离(周期 vs 结构)可靠,用总量断言个体命运不行。

## 三、结构引擎 2:池化引擎(风险池的定价几何)

**直觉图像**:千家万户的小额缴费汇成池子,支付少数人的大额损失
——池子能转动靠大数定律,池子怎么分账靠费率结构。

- **数学化身**(实验律三):企业事故率 p 异质,费率=α·池均+
  (1−α)·自身;安全投资每级 p×0.75、成本线性。统一费率(α=1)
  下投资边际收益只剩 δ=10% 残余→投资 0.00 级;经验费率(α=0.3)
  →高风险 2.47 级、低风险 0.00 级,池子事故率降 41%。
- **三条刚性**:
  1. **共济刚性**:α>0 保证池子不挑人——高风险者买得到保障
     (市场会拒保的风险,池子接),这是保险的社会理由。
  2. **激励刚性**:(1−α)>0 保证风险回到价格——自身风险有 70%
     内化进费率,安全投资才有边际买主;α 是共济与激励的旋钮,
     不是道德选择。
  3. **偿付中性刚性**:两制度的基金结余都在总赔付 3% 以内——
     定价结构改变的**不是偿付能力,而是行为**(事故率降 41%);
     保费怎么定价,安全就怎么被投资。
- **理论地位**:这是俾斯麦风险池(00 章)的机制化身——社会保险
  的"社会"两字写在那个 α 里;失业保险的双面账(实验律二)是
  同一引擎在给付侧的变体(替代率 b 同样是"保险-激励"旋钮)。
- **刚性从哪来**:期望定价与大数定律是刚的;软的地方在**可观测性
  假设**(实验律三把自身风险当作可知,真实制度用历史索赔滚动
  近似,机制同构)。

- **两具引擎的合读**:匹配引擎管**相遇的几何**(劳动力市场为什么
  不出清——摩擦),池化引擎管**分账的几何**(风险与保障怎么在
  池子里定价——共济);前者是劳动科学的"市场过程组"底盘,后者
  是"社会保护组"底盘——波兰尼双向运动的两翼各拿到一个可断言的
  算术身:市场那翼的病(摩擦)在 UV 平面上读得出,保护那翼的
  旋钮(α/b)在定价公式上调得动。

## 四、结构卡 schema:把一项劳动研究压进三张卡

**先答为什么**:劳动研究的难点在"整体性"——一项研究牵涉岗位、
保障、安全三层,散落文献难以携带。结构卡是**有限字段的压缩格式**:
字段固定、填空即复用、可比可查(这是"可构造"在研究层的对应物:
卡片本身严格可构造)。

### 卡 1:岗位结构卡(把一个岗位钉成可审的表)

```
【岗位结构卡】
岗位:________(名称/行业/用工形态:标准雇佣/派遣/平台接单)
任务束:核心任务 3-5 条;自动化暴露度(任务级,高/中/低):____
控制结构:谁派活(人/系统/算法);定价方式(谈判/规章/计件/动态);考核指标=______
自主性边界:可拒单吗/可议价吗/申诉通道=______;评分或监督机制=______
报酬结构:固定/计件/小费/奖金的构成;工时口径(合同/实际)=______
可检验推论(一条):________(如:考核指标从时长改为质量,拒单率的变化方向)
主位备注:________(在职者自己怎么描述这份工作的"好坏")
```

样例(已填,外卖骑手骨架,通说口径):岗位=平台接单;任务束=取餐/
配送/客服应答,导航与路线由算法派定(暴露度:路线优化高,情绪
劳动中);控制=算法派单+动态定价+评分,无协商通道;自主=可短时
下线,高峰拒单受派单权重惩罚;报酬=计件+冲单奖励,实际工时>
在线时长;推论=透明化算法定价规则,留存率与接单稳定性上升;
主位="系统让跑就跑"的时间纪律自述(01 章主线 A 的田野侧)。

### 卡 2:社保方案卡(把一个保障方案钉成可审的表)

```
【社保方案卡】
险种:________(养老/医疗/失业/工伤/生育;俾斯麦-贝弗里奇坐标:______)
覆盖接口:谁参保(标准雇佣/灵活/全民);缴费主体(雇主/个人/平台/财政)分担=______
费率结构:统一 or 经验(α=____);缴费基数与封顶线=______
给付结构:替代率(毛/净,基准:最后工资/生涯平均)=______;等待期/给付期=______
精算假设:利率/工资增长/待遇指数化=______(政治选择,须声明)
便携性:记录随人跨什么流转(地区/平台/制度)=______
可检验推论(一条):________(如:α 从 1 降到 0.3,高风险行业事故率变化)
```

样例(已填,工伤保险经验费率骨架):险种=工伤(俾斯麦侧,雇主单方
缴费);覆盖=标准雇佣+平台试点;费率=经验(α≈0.3,行业基准+企业
浮动);给付=无过错法定+医疗康复+伤残津贴;推论=实验律三——
统一转经验后高风险组投资 0.00→2.47 级,池子事故率降 41%;
主位=企业主视费率浮动为"罚单"还是"价签"的叙事差(02 章
"经验费率"误用栏)。

### 卡 3:安全管理体系卡(把一套安全体系钉成可审的表)

```
【安全管理体系卡】
体系:________(ISO 45001 类/行业规程;认证状态=______)
致因模型:单一/链式/系统(瑞士奶酪式);事故金字塔统计(未遂/轻伤/重伤)=______
危害辨识清单:物理/化学/生物/人因/心理(含算法时间压力)=______
层级控制:消除/替代/工程/管理/个体防护的部署顺序=______
报告文化:未遂报告免责吗;指标(每百万工时伤害率)与口径年份=______
联动:与工伤保险费率挂钩吗(经验费率接口)=______
可检验推论(一条):________(如:未遂报告免责后,塔基计数与次年重伤率的相关)
```

样例(已填,配送平台安全骨架,方向锚):体系=类体系(平台自查+
外部审计);致因=系统式(时间压力×路线设计×天气,瑞士奶酪式
对齐);危害=交通暴露+算法时间压力(心理-人因);控制=工程
(路线库)/管理(时段限速)/个体(头盔与保险)三级混布;报告=
事故回溯计入骑手画像(免责未建制——塔基不可见的口径根源);
联动=职业伤害试点与派单参数的接口(01 章主线 C)。

**判定流程**(把一个劳动科学主张钉到谱系上):

```
该主张的核心对象能写成动力学、定价式或分层计数吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(卡片/量表,填空带判断)─▶ 中段:卡片化+口径声明,禁止硬算
  └─ 不能(意义/认同/政治)────▶ 右端:田野+主位记录,禁止压成参数
```

## 五、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 劳动管理学 8407420 | 中段:岗位结构与工时制度可卡片化;协商过程不可 | 两具引擎的**管理层**(把规则写进岗位) | 中(规则面可审,过程靠田野) |
| 劳动统计学 8407425 | 中段偏左:口径是有限描述;测量误差可量化 | 匹配引擎的**读数器**(U/V/f 的口径) | 中-高(口径可构造,口径之争不可) |
| 劳动社会学 8407430 | 右端为主:控制/自主/意义靠田野;分割结构可图 | 匹配引擎的**社会侧**(谁被摩擦卡住) | 低-中(结构可图,过程靠田野) |
| 劳动心理学 8407435 | 中段:量表构造严格;意义的深层不可 | 两具引擎的**体验账**(激励与倦怠) | 中(量表可测,等价性存争) |
| 社会保险学 8407440 | 左端:定价/精算/替代率全可算 | 池化引擎(α 与 b 的旋钮) | 高(本家族最可构造的支) |
| 职业安全卫生 8407445 | 中段偏左:金字塔计数与体系审核可构造 | 池化引擎的**前线**(费率的激励落点) | 中-高(体系可审,现场靠辨识) |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——保险
走计算,统计走口径工程,社会学走田野与结构图;**没有哪支全家可
构造,也没有哪支全家不可构造**;这正是劳动科学比它的名声("政策
辩论")更能算的地方,也比它的野心("一切皆可精算")更谦逊的地方。

## ✨ 美之时刻(彩蛋第 6 枚:两具引擎的合龙)

✨ **美之时刻 6:摩擦与池子——劳动科学的左右手**(极简)
匹配引擎说:劳动力市场不出清不是失灵,是搜索的稳态——病在摩擦,
药在 UV 平面上读得出(沿曲线=周期,移曲线=结构);池化引擎说:
保险的社会性就写在一个 α 里——α=1 全共济(高风险搭便车),α=0
全市场(高风险被拒保),最优在中间,且两端的基金都养得起池子。
为什么美:**"市场过程"与"社会保护"这对百年冤家,各自拿到了一个
可断言的算术化身**——一个管相遇的几何,一个管分账的几何;波兰尼
的双向运动在实验室里不再是修辞,而是两条可以调参数的曲线/一个
可以调的旋钮。亲历:挑一个你身边的劳动争议(裁员/骑手/内卷),
判断它的主战场在哪具引擎上——修摩擦还是调旋钮(✍️练习 1)。
