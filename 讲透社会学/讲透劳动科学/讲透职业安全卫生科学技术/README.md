## 诞生

- **谁/何时**:工业化的事故代价催生安全立法(19 世纪矿山与工厂,通说);
  海因里希《工业事故预防》(1931)立事故金字塔(1:29:300 未遂,经验比例
  有争议,通说双录);瑞士奶酪模型(Reason,1990,通说)把致因改写为
  "防御层对齐";当代:算法时间压力成为新型危害源(01 章,检索校准 2026-09-07)。
- **因什么问题**:①事故为什么发生,归因给谁②危害怎么辨识、按什么顺序
  控制③安全管理怎么从运动式变成体系化④预防的钱从哪来(费率联动)。

## 核心问题

**已解决(通说)**:层级控制优先序(消除>替代>工程>管理>个体防护);未遂
报告免责的纪律;经验费率的激励修复(实验律三:投资 0→2.47 级,事故率
降 41%)。**未解决**:金字塔比例的行业异质性;心理-人因危害的认定。

## ✨ 这支最美的一个事实

**1:29:300——重伤不是倒霉,是塔尖**。海因里希整理数万起工伤发现:每起
重大伤害背后,约有 29 起轻伤和 300 起未遂(通说双录,方向稳定)。安全
战略因此翻面:**追责塔尖永远来不及,填平塔基(让未遂被报告、被统计、
被改造)才会让塔尖自己消失**——最反直觉的动作是"报告未遂不罚反奖"。
