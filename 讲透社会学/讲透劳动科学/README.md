# 讲透劳动科学 · 会喊疼的商品——工作如何被组织、定价与保障

> **本质一句话**:劳动科学=研究「工作如何被组织、定价与保障」的学科群——
> 劳动力是波兰尼意义上的**虚构商品**(人不是为出卖劳动力而生产,却被
> 按商品组织进市场),本家族的全部张力由此而来:它一半研究**劳动力市场

> **劳动力不是商品,又不得不按商品组织——劳动科学就是这门
> "按商品组织人、再修补商品化"的制度学。**

## 一、家族定位(它在社会学宇宙里的位置)

社会学宇宙的多数家族研究"社会如何运转",本家族研究一台特定的机器:
**社会如何把"工作"组织起来、给劳动力定价、再为劳动力的损耗兜底**。
它的编年是一部双线接力:一条线从工厂立法(1833 英国工厂法,通说)、
泰勒制(1911)、霍桑实验(1924-1932)、劳动过程理论(1974)一路到
平台算法管理——问"工作如何被组织与控制";另一条线从俾斯麦社会保险
立法(1883-1889,通说)、贝弗里奇报告(1942)一路到社保便携化——问
"商品化的劳动力如何被再保护"。GB/T 的 6 条三级原生支恰好落成两组:
**劳动力市场过程组**(劳动管理学/劳动统计学/劳动社会学/劳动心理学)
与**社会保障与安全组**(社会保险学/职业安全卫生科学技术)——
本家族 README 与 00-04 章全部按这两组速写展开。
