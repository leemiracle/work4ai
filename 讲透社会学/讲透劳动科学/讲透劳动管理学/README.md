## 诞生

- **谁/何时**:工厂立法(1833 英国工厂法起,通说)与八小时工作制运动
  (1886 芝加哥工潮与五一由来,通说)供"工时=政治参数"原型;泰勒(1911)
  供定额测定;20 世纪劳动法与集体协商建制供关系调整程序;当代:混合办公
  与算法派单把工时边界重新开庭(01 章主线 D 方向锚,检索校准 2026-09-07)。
- **因什么问题**:①岗位与工作量怎么科学测定②工时与加班的边界怎么划
  ③工资怎么结构化才既有激励又合规④冲突不靠辞职与罢工,靠什么程序消化。

## 核心问题

**已解决(通说)**:工作分析与定额测定的技术体系;工时制度的法律框架;
集体协商的三方程序。**未解决/深水区**:算法派单下的工时认定(在线时长
≠合同工时);"隐形加班"的边界;平台用工的协商主体缺位。

## ✨ 这支最美的一个事实

**八小时工作制不是效率算出来的,是斗争定出来的——然后被写进劳动标准
成为管理参数**。1886 年的工人不可能用生产率模型说服工厂主:他们要的是
"八小时工作,八小时休息,八小时归自己"。胜利之后,这个数字进入劳动法,
变成排班表上的常量——下一代管理者把它当成工程参数来"优化",忘了它曾是
战场上的停火线。**今天每一个"弹性工时"方案,都是在重新谈判那条停火线**。
