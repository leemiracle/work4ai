# 讲透人口地理学 · 人口有地图——分布、迁移流与人地关系

> **定位句**:这支负责**分布与移动**——人口在地表怎么分布(密度与聚落体系)、怎么移动(迁移流与法则)、人地关系怎么互相改写;空间的统计制图技术归 91045 与地理学宇宙,本支管人口过程的地理形状。口号:**人口有地图**。GB/T 13745 84071 人口学 · **GB/T 支**(8407135)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:拉文斯坦《迁移法则》(1885,距离/阶段/流-反流的第一组规律,基于英国普查的引力直觉);李(1966)推-拉理论(迁出地/迁入地/中间障碍/个人因素四件套);泽林斯基(1971)流动转型假说(迁移也有「转变」:前近代的有限流动→农村向城市→城市间→环流);胡焕庸(1935)立中国人口分布线(瑷珲-腾冲线);当代:迁移流矩阵、收缩城市地理、环流(circulation)研究。
- **因什么问题**:①人为什么这样分布(分布之问)②迁移遵循什么规律(流动之问)③移动会随现代化走完自己的「转变」吗(转型之问)。

## 核心问题

**已解决(通说)**:拉文斯坦法则的主体(短距优先/阶梯式/流-反流共生)在当代数据中反复成立;胡焕庸线的惊人稳定性(1935 年的线,其后近百年人口分布基本未破线,通说);城镇化与迁移的阶段性确认。

**未解决/深水区**:远程办公与环流对「常住」概念的瓦解(测量口径追不上行为);气候迁移的地理重构(01 章;生态学支接口);收缩城市的地理定型(哪些城市缩了回得来)。

## ✨ 这支最美的一个事实

**胡焕庸线**。1935 年胡焕庸用一份县级人口统计画出瑷珲-腾冲直线:线的东南侧约 36% 的国土承载约 96% 的人口(通说)。为什么美:**其后近百年,战争、饥荒、工业化、大规模迁移与城镇化全部发生过,这条线基本没动**——东侧仍以约四成的土地承载九成以上人口(历次普查通说)。地理约束(降水/地形/耕地)通过两千年农业史把分布焊死,而一切「人口再平衡」的政策雄心都在这条线前止步。一条 1935 年的手绘线,是「存量周期」(幕二)在国土尺度上的最长实拍。
