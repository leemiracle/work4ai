# 讲透人口社会学 · 生育决策的社会结构——社会想动生育,必经那几扇窄门

> **定位句**:这支负责**生育与迁移的社会结构**——家庭制度/性别分工/代际契约如何决定生不生、生几个、何时生;老年人口学、妇女人口学、发展人口学(GB/T 注文明文)是本支内部分目,不另立目录。口号:**生育率是社会的函数**。GB/T 13745 84071 人口学 · **GB/T 支**(8407120,**主轴**;GB/T 注:含老年人口学、妇女人口学、发展人口学)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:杜蒙特晚婚阶梯(1890 一线,社会毛细现象);戴维斯与布莱克(1956)立**中介变量**框架(社会力量必须经结婚/避孕/哺乳/不育等近端变量作用于生育);邦加茨(1978)工程化(近端决定因素模型);伊斯特林(1976 相对收入假说)与贝克尔(1960 家庭经济学,数量-质量替代)立经济侧双雄;费孝通《生育制度》(1947)立中文侧底座(生育是制度安排不是生物行为);埃尔德一系生命历程范式(1974 一线)把生育放进时间表;老年人口学随老龄化建制化,妇女人口学随性别研究兴起。
- **因什么问题**:①为什么同等收入的社会生育率天差地别(结构之问)②社会怎么「够得着」生育(中介之问)③理想与行为的差距由什么构成(推迟之问)。

## 核心问题

**已解决(通说)**:中介变量的分解框架成为生育分析的标准语法(02 章 §一);生育决策的多主体性(夫妻/代际/性别)确立;老年人口学的支撑比体系、妇女人口学的性别口径体系建制化。

**未解决/深水区**:理想子女数是否内生于成长环境(低生育陷阱之争的实证核心,01 章主线 B);推迟折损的制度构成(住房/就业/托育各占多少);迁移人口的生育率向谁收敛(融合研究的经典题)。

## ✨ 这支最美的一个事实

**窄门定理**。戴维斯-布莱克 1956 年发现:从国王的税令到广告牌的劝服,任何社会力量想改变生育,都**必须**穿过同一组窄门——初婚年龄、避孕可获得性、产后哺乳、宫内死亡、绝育……门总共十几扇,门后才是孩子。为什么美:**它把「文化影响生育」这句空话改写成可检查的通路图**——文化从哪扇门进去、政策堵住哪扇门、哪扇门年久失修,一张图上看清。后来一切生育政策分析(从计划生育到生育支持)都在这张图上作业:幕三的「推迟折损」不过是「初婚与避孕两扇门被社会推迟关上」的数学影子。
