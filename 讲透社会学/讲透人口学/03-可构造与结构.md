# 03 · 可构造与结构:哪些人口对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:人口学的对象沿一条**可构造谱系**排开——矩阵端
> **严格可构造**(Leslie 迭代可以跑出收敛与动量、转变路径可以跑出
> 间隙、反馈回路可以跑出双稳态,全部过 assert),规范解释端**几乎
> 不可构造**(「理想子女数为什么下移」「什么算适度人口」只能在调查
> 与理论里操练);全谱系共享三条结构引擎:**间隙引擎**(死亡与生育
> 回应现代化的时间差)、**矩阵引擎**(年龄结构把过去存成现在的
> 增长)、**反馈引擎**(规范在代际复制自己);而任何一个人口情形
> 都可以被压进三张**结构卡**(人口金字塔卡/转变阶段卡/预测假设卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
Leslie 迭代 ── 转变路径 ── 动量核算 ── 金字塔读图 ── 预测假设卡 ── 转变阶段卡 ── 政策传导审计 ── 理想子女数的解释 ── 「什么算适度人口」
  │                                                                                                │
严格可构造(可断言)                                                                     几乎不可构造(只有思想操作化)
  └── 枚举得出、迭代得动、能过 assert                                                                   └── 只能在调查、田野与理论里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:Leslie
矩阵的语义是"生育率首行+存活率次对角",转变路径的语义是"两个率的
时间表",反馈回路的语义是"记忆窗口与棘轮权重"——输入输出明确;而
「这一代人的理想子女数为什么是 1.8」的语义进入意义世界与制度安排,
**调查口径本身就是研究对象**(02 章 §二:期望还是接受,口径一换结论
就翻)。本章先盘家底,再看三条结构引擎,最后把人口诊断-预测-决策
工序压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **Leslie/稳定人口模拟** | 17 组年龄别率→矩阵迭代;幂迭代取 λ | 低(幕二全程可跑) | 率谱设定即结论:真实率逐年在变,λ 是渐近概念 |
| **动量核算** | 更替切换+继续迭代 | 低(幕二第三段) | 「骤然到位」是理想化;迁移被关在门外 |
| **转变路径模拟** | 死亡/生育两条时间表+r 的解剖 | 低(幕一) | sigmoid 的形状是教学设定;滞后 τ 是外生输入,它为何是 60 年不是 20 年恰是未解问题(00 §四) |
| **反馈回路(陷阱)模拟** | 记忆窗口+单向棘轮+理想下限 | 低(幕三) | **机制演示而非证据**:γ 无直接测量,初值-归宿的映射依赖设定 |
| **金字塔读图** | 年龄结构向量的可视化规则 | 低 | 读图技能不可完全规则化(两个引擎的分解靠人) |
| **预测假设卡** | 生育/寿命/迁移三栏假设的字段表 | 中(§五 schema) | 假设的**选择**是理论,机器只管执行 |
| **转变阶段卡** | 时序+证据+反例的固定字段表 | 中 | 阶段判定有事后描述风险,须双人校 |
| **政策传导审计** | 流量-存量对照+时差表 | 中 | 反事实(无政策对照)构造依赖评估设计(91045 互链) |
| **理想子女数的规范解释** | 意义世界的调查与理论重建 | **不可构造** | 口径不稳(期望/接受);自报≠行为 |
| **「什么算适度人口」的裁定** | 目标函数的规范哲学 | **不可构造** | 适度取决于你要什么(福利/实力/生态),裁定不能由机器代投 |

**反直觉发现(本章铁律)**:**本家族最硬的机器围着最老的问题转**。
Leslie 矩阵(1945)与转变理论(1945)是全学科最老的装备,却是可构造
谱系的最左端;最新的争论(陷阱/峰值)反而要靠最老的机器搭台。**左端
管推演,右端管判断**;用右端对象硬造左端指标(给「生育意愿」打分后
跑回归)是本学科量化研究的头号失真来源。正确的接法是**左端造右端
概念的最小机器**(幕二之于动量,幕一之于间隙,幕三之于陷阱),机器
不替代概念,只给概念一个可审计的极端案例。

## 二、结构引擎 1:间隙引擎(时间差的机械学)

**直觉图像**:现代化像两支速度不同的部队过桥——死亡率先过(卫生/
防疫/营养的技术门槛低、见效快),生育率后过(规范与家庭经济的改写
慢)——**增长率的峰值就是两支部队之间的空档**。这是人口爆炸的机械学。

- **诊断化身(幕一)**:死亡率 sigmoid 40‰→10‰(中心年 40),生育率
  滞后 τ=60 年才 40‰→11‰。三条刚性:
  1. **峰值的位置解剖**:r 峰值 2.43% 出现在第 69 年,该年死亡率已完成
     降幅的 92%、生育率仅 11%——峰值严格落在间隙里。
  2. **高度的封顶**:峰值 < b0−d1=3.0%——间隙再宽,爆炸的高度由
     死亡率的降幅单方封顶。
  3. **体积=高度×宽度**:τ 从 45 拉到 75,峰值 2.07%→2.66%(几乎不动),
     终规模 4.32→10.18(翻倍以上)——爆炸的空间几乎全部由时间差提供。
- **刚性从哪来**:两条时间表与 r=b−d 的算术是确定的,骨架是刚的;
  软的地方在**时间表的宪法**(τ 为什么那么长——子女价值的改写为何
  慢于卫生技术的扩散)恰是 00 §四的未解问题,机器只演示不解释。
- **方法上游**:率的测量与曲线拟合技术归[91045](../../讲透统计学/讲透人口统计学/README.md);
  本家族的增量是**问时间差的社会安排**——谁先谁后、为什么。

## 三、结构引擎 2:矩阵引擎(存量周期的机械学)

**直觉图像**:人口是一台**遗忘初值的机器**——不管从什么结构出发,
固定的率谱把它拧到同一个稳定结构、同一个增长率;而政策改的是率
(流量),结构(存量)按自己的周期走完。这是动量与「政策时差」的
机械学。

- **诊断化身(幕二)**:17×17 Leslie 矩阵(高生育档 NRR=2.245)。
  三条刚性:
  1. **遗忘初值**:两个随机初始向量各迭代 160 步,相邻步结构距离
     2.99e-1→1.8e-14 单调降,终结构互相距离 1.9e-14——常数率把一切
     历史拧成同一个特征向量(Perron-Frobenius 的正矩阵谱半径统治)。
  2. **λ 与 NRR 的汇率**:λ=1.1384(每 5 年)=NRR^(1/T)(T≈28 年,
     相对差 1.5%)——隔代的账与每年的账由世代长度换算;两种世代口径
     差 3.2 年,如实标注(一阶近似)。
  3. **动量的方向性**:切换到更替(NRR=1)后,年轻结构 +52%、年老
     结构 −19%——同一个政策,两种存量,两个方向。
- **刚性从哪来**:矩阵迭代与谱运算是确定性代数,骨架是刚的;软的
  地方在**率的宪法**(单性人口/封闭系统/率长期不变——移民与率变
  恰是当代主变量)与**更替切换的理想化**(政策从不瞬时)。
- **方法上游**:Leslie 的技术实现(生命表×矩阵的工程细节)归
  [91045](../../讲透统计学/讲透人口统计学/README.md)(其 00_leslie.py
  为三组简化演示);本家族做**理论教学版**——收敛的单调性、λ-NRR
  换算、正负动量对照,重心在稳定人口理论的读懂,已成文分工。

## 四、结构引擎 3:反馈引擎(规范复制的机械学)

**直觉图像**:若生育规范内生于成长环境,低生育就**自己生产下一代的
低生育**——均衡不止一个,历史在边界两侧分岔。这是低生育陷阱的机械学。

- **诊断化身(幕三)**:理想子女数=更替基准+γ×(成长期记忆−更替)×
  单向棘轮权重;TFR=理想数−推迟折损;理想下限一孩硬底。三条刚性:
  1. **单稳态(γ=0)**:推迟冲击(25 年 TFR 压到 1.45)结束,TFR 精确
     回 2.10——无反馈的世界里记忆不参与动力学。
  2. **双稳态(γ=1.35)**:初值 1.70/1.90/2.30 收敛回更替,1.60/1.50/
     1.35 自锁于 1.15——一条不稳定边界(1.6-1.7 之间)把历史分成
     两种命运。
  3. **冲击的重新定性**:同样的推迟冲击,γ=0.5 时是「可恢复的借支」,
     γ=1.35 时是「越界的推手」——**冲击本身不决定结局,边界位置与
     反馈强度的合取才决定**。
- **刚性从哪来**:确定性迭代给出干净的分岔,骨架是刚的;软的地方
  在**反馈的宪法**(单向棘轮的设定、γ 的取值、记忆窗口的宽度)——
  每一处都无直接测量,这正是「机制演示而非经验证据」的诚实边界
  (01 章主线 B:实证检验至今未决)。
- **理论地位**:它是「人口是自变量还是因变量」之争(00 §二之争 1)
  的极端化身:γ>阈值时,人口过程把自己的输入(规范)也生产了——
  箭头成环。

## 五、结构卡 schema:把一个人口情形压进三张卡

**先答为什么**:人口诊断-预测-决策的难点在"整体性"——结构、阶段、
假设散落在报告各节。结构卡是**有限字段的压缩格式**:字段固定、填空
即可复用、可比可查可补(卡片本身严格可构造,这是「可构造」在设计层
的对应物)。

### 卡 1:人口金字塔卡(这个人口的结构是什么)

```
【人口金字塔卡】
人口与年份:________(注明口径:常住/户籍;数据源:普查/推算)
结构读数(0-14/15-64/65+ 三段占比;中位年龄;金字塔形状:扩张/收缩/老化):
________
两个引擎分解(长寿推动的老化 vs 生育下降推动的老化,各给一条证据):
________
队列标记(最大的三个队列及其规模:如 1960s/1980s/2010s 出生队列):
________
动量初判(按年龄结构:正/负动量;扩大的育龄队列还能推多久增长):
________
结构风险(抚养比口径与读数;婚育人口的性别比失衡位置):
________
一句话鉴定(这个结构最要紧的一件事):
________
```

样例(已填,教学版·虚构地区「甲」):结构=0-14 占 13%、65+ 占 21%、
中位 46 岁,老化型;分解=寿命引擎为主(65+ 存活率十年改善),生育
引擎叠加(0-14 连续三档收缩);队列=最大队列 1960s 出生(普查峰值),
次大 1980s 回声,2010s 二次回声缩水;动量=**负**(育龄队列在收缩,
即使 TFR 回到更替,出生数仍将下行数年);风险=老年抚养比按 65 线
读数偏高,按余命线(动态老化)读数温和——口径即结论(02 章 §一);
鉴定=典型的「队列回声耗尽+负动量」结构,幕二年老结构的现场版。

### 卡 2:转变阶段卡(这个过程走到哪了)

```
【转变阶段卡】
人口与时段:________
死亡端(CDR 的轨迹与现值;拐点年代;主导死因的流行病学转变证据):
________
生育端(CBR/TFR 的轨迹与现值;拐点年代;滞后 τ 的粗估=生育拐点−死亡拐点):
________
间隙账(r 的峰值、出现年代、窗口宽度;当前 r 及其构成):
________
阶段判定(高位平衡/间隙/低位平衡/二次转型中的哪个;判定证据两条):
________
反例与疑难(不符合经典顺序的现象:如生育先于死亡下降的局部、停滞的
生育下降;何时出现为何):
________
一句话鉴定(这个转变最独特的一件事):
________
```

样例(已填,教学版):死亡端=CDR 拐点在 1950s(防疫与卫生体系先建),
现值 7‰;生育端=TFR 拐点在 1970s,τ≈20 年(短于经典的 60 年——政策
加速了生育端),现值 1.0;间隙账=r 峰值 2.8% 出现在 1960s,窗口约
25 年(窄而陡——τ 短,爆炸高度高、体积相对小,幕一 τ 敏感性的现场
版);阶段=低位平衡已过,处于二次转型深水(推迟折损显著);反例=
生育下降的两段变速(1970s 政策段陡/1990s 后惯性段缓);鉴定=「压缩
的转变」——几十年走完别人两百年的间隙,代价是结构转换的全部应力
也压缩在几十年里。

### 卡 3:预测假设卡(这个预测信什么)

```
【预测假设卡】
预测主体与版本(机构/模型/版本号/发布年——修订序列的一员):
________
区间纪律(中位数+区间;80%/95%;情景名与概率的区分):
________
生育假设(TFR 路径的分歧点:回升/持平/继续降;由年龄结构还是率驱动):
________
寿命假设(e0 改善速度;健康寿命的口径):
________
迁移假设(净迁移路径;这是最大的自由参数):
________
时差分层(近端由已出生队列支配的年份 vs 远端由生育假设支配的年份):
________
机器敏感性(峰值/总量对哪个假设最敏感;与哪家机构的分歧最大及原因):
________
一句话鉴定(这个预测最脆弱的一环):
________
```

样例(已填,教学版):主体=WPP 某版全球层(版本纪律:引数字必带版);
区间=中位数+95% 区间,情景与概率分列;生育=撒哈拉以南非洲下降速度
为第一分歧点,东亚回升假设为第二;寿命=e0 改善年均约 1-2 岁每十年
(量级,通说),健康寿命另列口径;迁移=国家级净迁移为最大自由参数
(统计基础设施最弱的一环恰是它);时差=2045 年前主要由已出生队列
与存活率决定(幕二动量的统治区),之后生育假设接管;敏感性=峰值
时点对东亚与非洲两端同时敏感;鉴定=最脆弱一环=迁移,重要性最高、
测量最弱(01 章主线 C 的剪刀差)。

**判定流程**(把一个研究主张钉到谱系上):

```
该主张的核心是率与结构的推演,还是规范与目标的判断
(间隙/动量/分岔/区间)?
  ├─ 是 ────────────────▶ 左端:建模+模拟+断言(04 章走廊 1/2/3)
  ├─ 半,是情形与假设的结构化 ─▶ 中段:卡片化+双人校,禁止硬算「意愿分」
  └─ 否,是意义与「什么算适度」─▶ 右端:调查+田野+规范分析,禁止压成参数
```

## ✨ 美之时刻(彩蛋第 6 枚:假设宇宙)

✨ **美之时刻 6:把政策拧到 NRR=1,再看三十年——假设宇宙的对照**
**(极简)**
本家族车间最锋利的工具是**假设宇宙**:幕二把两档人口(年轻/年老)
同时「拧」到更替水平——现实中永远不会发生的事(政策从不瞬时、迁移
从不关门)——然后让存量自己走:一个再涨 52%,一个再跌 19%。为什么
美:**它把「政策的上限」做成了可复现实验**——鼓励或限制政策的全部
短期空间,就装在这两条曲线之间;任何「三年扭转」的政治承诺,都可以
拿来跟这台机器对表。反方也拿到同样的武器:把迁移假设打开、把率变动
打开,看动量还剩多少——理想化的每一条缝,都是留给现实的接口。亲历:
给你领域的一个「存量-流量」现象(用户池/师资/基建容量)写一份假设
宇宙说明书:拧哪个阀、看哪条曲线、断言什么(✍️练习 1)。
