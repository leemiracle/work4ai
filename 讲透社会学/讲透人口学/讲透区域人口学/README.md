# 讲透区域人口学 · 区域是人口过程的容器,也是它的产物

> **定位句**:这支负责**区域尺度的人口过程**——区域人口再生产、人口移动与城镇化的耦合、区域间的人口分化(增长区/收缩区);全国数字是它的汇总,不是它的研究对象。口号:**区域是容器也是产物**。GB/T 13745 84071 人口学 · **GB/T 支**(8407145)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:区域科学的兴起(艾萨德 1950s 一线)给区域人口分析以底盘;诺瑟姆(1975)立**城镇化 S 曲线**(起步-加速-饱和三段,逻辑斯蒂);中国 1980-90 年代区域人口研究建制化(迁移潮与区域规划的双重驱动);当代:收缩城市研究(德国/东欧经验先行,通说)、区域人口负增长分化成为主战场。
- **因什么问题**:①区域的人口过程与全国有什么不同(尺度之问)②人口在区域间怎么分化(分化之问)③城镇化走完 S 曲线之后区域怎样(后城镇化之问)。

## 核心问题

**已解决(通说)**:城镇化 S 曲线的三段论确立(城镇化率随时间走逻辑斯蒂,自动减速);区域人口迁移的净流结构(向都市圈集聚+边缘收缩)在多国数据中反复出现;七普级数据使区域比较的口径统一成为可能。

**未解决/深水区**:收缩的定型化——哪些区域是暂时收缩、哪些进入结构性的螺旋(服务撤出→人口流出→更撤出,幕三自锁的区域版);都市圈极化与均衡发展的政策取舍无共识;跨区域口径(常住/户籍/人户分离)的测量损耗。

## ✨ 这支最美的一个事实

**S 曲线的自动减速**。城镇化率随时间走一条拉平的 S(诺瑟姆 1975):起步段慢(农村基数大)、加速段陡(农村剩余劳动力倾泻)、饱和段自动减速——**不是政策踩了刹车,是曲线自己的形状**。为什么美:它给一切「城镇化率还能涨多久」的政策焦虑一个数学答案(逻辑斯蒂的饱和),也给「增长区-收缩区」的分化一个时间表(S 曲线后段,区域间的再分配取代总量的增长)。区域人口学的第一课:先看这个区域在 S 的哪一段,再谈它的数字。

## 假设与依赖

- 买入「区域是有效分析单位」:边界与口径稳定;行政边界与功能边界(都市圈)错位是常态损耗
- 城镇化率的口径(城镇定义)跨期跨国有跳变——口径即读数(02 章)
- 区域经济模型本体归经济学宇宙(文字提及);流矩阵技术归地理学支互提
