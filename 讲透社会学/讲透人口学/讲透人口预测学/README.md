# 讲透人口预测学 · 预测的诚实在于分解——已经出生的人与还没发生的生育

> **定位句**:这支负责**预测**——把今天的年龄结构推到明天:队列要素法(未来=已出生的人+还没发生的生育+还没发生的迁移)、动量核算、概率走廊;它管预测的**假设与语法**(哪个分位、哪版机器),概率建模的技术本体归 91045。口号:**预测的第一课不是外推,是分解**。GB/T 13745 84071 人口学 · **GB/T 支**(8407155,**主轴**)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:马尔萨斯的外推(几何级数)是最早也最坏的教材;惠尔普顿一系把预测做成**队列要素法**(1930-40 年代:未来人口=已知队列的存活+假设的新生);洛特卡-莱斯利的稳定人口(1907/1945)给预测以收敛理论(λ 与动量);凯菲茨(1971)动量核算回答「到更替之后还涨多久」;Lee 与 Carter(1992)把死亡率做成因子模型;联合国 WPP 自 2015 版全面概率化(贝叶斯分层,技术本体归 91045),2024 版延续并下修(检索校准 2026-09-07)。
- **因什么问题**:①未来人口能不能算(可算性之问)②误差从哪来(分层之问)③怎么把不确定性交给决策(区间之问)。

## 核心问题

**已解决(通说)**:队列要素法成为全球标准机器;误差的时差分层确立——近端由已出生队列支配(20 年内的预测其实是「会计」),远端由生育假设支配(50 年外其实是「赌注」);动量把「政策时差」变成可计算的量(幕二:+52%/−19%)。

**未解决/深水区**:超长期生育率路径无理论(东亚会不会回升、撒哈拉以南非洲降多快——恰是 WPP 与 IHME 分歧的两端,01 章主线 A);迁移是最大自由参数且测量最弱;修订序列的回验文化刚起步(区间覆盖率自身的统计)。

## ✨ 这支最美的一个事实

**时差分层**。看一条 2070 年的人口预测曲线,先问一个粗鲁的问题:这条线**凭什么**?答案分两段:2045 年以前,几乎全由「已经出生的人」走完的队列周期决定——误差极小,这半段是**会计**;2045 年以后,每一点都押在「还没发生的生育」的假设上——这半段是**赌注」。为什么美:**它把「预测准不准」这个糊涂问题拆成「哪半段在数钱、哪半段在下注」**——引任何人口预测,先找到它从会计变赌注的那一年(时差分层线),线前可以苛刻,线后只能宽容;而一切「人口预测又错了」的新闻,十有八九是把赌注段当会计段骂。

## 假设与依赖

- 买入「率的结构可外推」:存活与生育的年龄轮廓相对稳定;危机(战争/疫情/大迁移)是它的系统性盲区
- 概率化的哲学前提:不确定性本身可模型化(先验+数据的贝叶斯更新),技术本体归[91045](../../../讲透统计学/讲透人口统计学/README.md)
- 情景(SSP 类)与概率(区间)不可混用;点值只是分布的摘要——呈现纪律见家族 01 章 §方法节
