# 讲透人口生态学 · 承载力的每次计算都是一次政治——人口-资源-环境三角

> **定位句**:这支负责**人口-环境接口**——承载力概念、IPAT 类恒等式、增长极限论与它的批评、人口峰值的环境含义;它管「多少人对这片土地意味着什么」的争论本体。口号:**承载力的每次计算都是一次政治**。GB/T 13745 84071 人口学 · **GB/T 支**(8407140)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:承载力从牧场生态学(载畜量)移入人口语境;福格特《生存之路》(1948 一线)与埃利希《人口炸弹》(1968)立警世线;埃利希与霍尔德里(1971)立 **IPAT 恒等式**(环境影响=人口×富裕×技术);梅多斯等《增长的极限》(1972,罗马俱乐部,系统动力学模型)把人口-资源-污染装进反馈回路;博塞鲁普(1965)立反方(人口压力推集约化);90 年代起环境减压(environmental Kuznets 一线)与气候-人口研究接棒。
- **因什么问题**:①人口是不是环境危机的第一因(归因之问)②承载力能不能客观计算(测量之问)③人口峰值对环境意味着什么(换挡之问)。

## 核心问题

**已解决(通说)**:IPAT 的分解成为标准语法(争议从「要不要」移到「哪个字母重要」);承载力不是静态数字(技术与制度改写基数)成为共识;增长的极限论的历史预测失败本身成为方法论教材(指数外推的代价)。

**未解决/深水区**:人口峰值与减排路径的合流账(人口下降自动减多少排放、代价与时机,01 章);气候迁移的规模与权利(地理学支共担);「环境移民」的概念政治(定义即立场)。

## ✨ 这支最美的一个事实

**IPAT:三个乘数的五十年吵架**。1971 年,埃利希与霍尔德里把环境冲击写成一行乘法:**I=P×A×T**(人口×人均消费×技术)。为什么美:**此后五十年的环境政治,几乎每一场都能翻译成「哪个字母该负责、哪个字母该动」**——南方阵营强调 A(富国消费),北方阵营强调 P(穷国人口),技术乐观派押 T(去耦);一行恒等式把全部分歧摆上桌面,却因为乘法结构**无法由数据仲裁谁的责任大**(乘数无先后)。它跟 02 章 §二的启示同构:指标不是对世界的测量,是对世界应该怎样的投票。
