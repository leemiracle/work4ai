# 讲透人口理论 · 过程的本体论——人口是被安排的,安排者也是人口

> **定位句**:这支负责**过程本体**——人口规律是什么形状(自然规律还是历史规律)、人口与社会经济谁决定谁(人口决定论 vs 被决定论)、多少人口算合适(适度人口);它不问「生了多少」(那是 91045 的测量),只问「人口这个变量在因果链的哪个位置」。口号:**没有自然的人口**。GB/T 13745 84071 人口学 · **GB/T 支**(8407110,**主轴**)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:配第(约 1662)立下人口-资源对偶(劳动之父/土地之母);马尔萨斯《人口原理》(1798)立人口决定论原型(级数压顶);马克思恩格斯一系立反题——「两种生产」(物质资料生产与人类自身生产互相适应,抽象的人口规律不存在);坎南(1888 一线)立适度人口;20 世纪转变理论把「规律」历史化(阶段代替铁律);当代把箭头掰成环(规范自锁)。
- **因什么问题**:①人口增长是不是有自身铁律(规律之问)②人口是自变量还是因变量(位置之问)③一个社会该有多少人(适度之问)。

## 核心问题

**已解决(通说)**:人口决定论的单一箭头被历史否证(博塞鲁普倒转+技术变迁);「抽象人口规律」与「历史地起作用的人口规律」的区分成为中文教材底盘;适度人口从「客观存在」改写为「目标函数的函数」。

**未解决/深水区**:人口-发展的净效应长期账(马尔萨斯 vs 博塞鲁普的老战场);低生育时代「规律」的再表述——过程-结构-反馈三件套如何拼成理论(家族幕三只演示机制);「多少算合适」的价值排序无共识。

## ✨ 这支最美的一个事实

**适度人口的空椅子**。「一个国家最好有多少人?」——坎南以来的回答拆开看只有三步:放一把椅子(目标函数:福利/实力/生态/就业),给椅子写约束(资源/技术/结构),解最优。椅子一换,答案全换。为什么美:它把「最优人口」从事实问题改写成**座位问题**——争论了两百年的「中国最适合多少人」从来不是测出来的,是每个人自带椅子来开会。此后看到任何「理想人口规模」的数字,先问椅子是谁搬来的。
