# 讲透人口学说史 · 每个时代的人口理论,是那个时代的人口问题

> **定位句**:这支负责**思想编年**——从配第的对偶、马尔萨斯的级数、新马尔萨斯主义的避孕,到转变论、矩阵、第二次转型与陷阱假说的概念史;它管「谁在何时为什么这样想」。口号:**人口思想史是人口问题的编年史**。GB/T 13745 84071 人口学 · **GB/T 支**(8407125)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:配第(约 1662)人口-资源对偶;马尔萨斯(1798/1803)级数与两版抑制;普莱斯一系新马尔萨斯主义(19 世纪,主张避孕而非禁欲——马尔萨斯本人反对的正是它);马克思的人口批判(抽象人口规律不存在);朗德里(1909/1934)人口革命;汤普森(1929)/诺特斯坦(1945)转变论;坎南-索维适度人口;1945 年双生(转变叙事+莱斯利矩阵);1986/1998/2006 三连(二次转型/进度效应/陷阱);中文线:马尔萨斯论战(汪士铎一系对照)/马寅初《新人口论》(1957)及其后的学术曲折。
- **因什么问题**:①概念从哪来、针对谁(源流之问)②旧理论在新问题前的改写史(换挡之问)。

## 核心问题

**已解决(通说)**:马尔萨斯-马克思-转变论-当代的谱系骨架清晰;每次范式转换的问题背景(工业化焦虑→控制增长→应对萎缩)有案可查。

**未解决/深水区**:中文人口思想史的近代段落(汪士铎/薛福成一系与马尔萨斯的同时性比较)研究仍薄;「从爆炸叙事到萎缩叙事」的概念史刚刚发生,史料未沉淀。

## ✨ 这支最美的一个事实

**马尔萨斯反对马尔萨斯主义**。新马尔萨斯主义(主张用避孕控制生育)打着马尔萨斯的旗号,而马尔萨斯本人在世时明确反对避孕——他开出的药方只有道德抑制(晚婚节欲)。为什么美:**思想史上最响亮的招牌,恰恰是本主拒绝的货**;一个词的旅行史(02 章 §三)在两百年前就上演了第一幕。读学说史的第一纪律:看本主写了什么,别看招牌挂了什么。
