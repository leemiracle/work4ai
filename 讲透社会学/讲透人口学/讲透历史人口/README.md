# 讲透历史人口 · 从死人名册读出活人的婚育节奏

> **定位句**:这支负责**史料层**——教区登记、家庭重组法、逆向存活、倒推估计,把没有普查的时代变成可分析的人口过程(婚龄/生育间隔/婴孩死亡/迁移)。口号:**人口学的时间深度靠史料,不靠回忆**。GB/T 13745 84071 人口学 · **GB/T 支**(8407130)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:昂利(1956 一线,日内瓦-凡尔赛教区研究)立**家庭重组法**——把洗礼/婚礼/葬礼的登记逐条拼回家户,重建婚龄、生育间隔、家庭结构;里格利与斯科菲尔德(1981)《英格兰人口史 1541-1871》用教区汇总+倒推给出四百年总量序列;剑桥人口与社会结构史组(1964 建制,通说)建制化;逆向存活技术(用后来的年龄结构反推历史出生)补无登记区;中文侧:家谱、族谱、方志与《中国人口史》多卷本(葛剑雄主编一系,通说)构成中文史料底盘。
- **因什么问题**:①普查以前的人口过程能不能测(可测性之问)②欧洲的婚姻模式(晚婚与独身)是不是「欧洲例外」的引擎(比较之问)。

## 核心问题

**已解决(通说)**:家庭重组法的工序标准化;西北欧的晚婚-独身模式(Hajnal 线,1965)确证为历史上独特的人口调节机制;历史生育与死亡的季节性、间隔性成为可比量。

**未解决/深水区**:无登记社会(口传社会/早近代东亚民间)的测量仍靠间接技术,误差大;中国历史人口的官方序列与家谱序列的拼接仍有系统分歧(通说);历史数据与当代预测的互证方法学刚起步。

## ✨ 这支最美的一个事实

**家庭重组法**。一本教区登记簿,记的只有三件事:洗礼、婚礼、葬礼——死人的名册。方法只有一步:把同名者逐条拼回家户。为什么美:**从最死板的行政残骸里读出最鲜活的生命节奏**——她 24 岁结婚,头胎间隔 14 个月,此后每 26 个月一胎,九个孩子活了四个,她 41 岁去世。全部人口学指标(婚龄/间隔/生育力/婴孩死亡/寡居)都在名册的缝隙里,只等有人去拼。这门学科最像法医的地方:证据全在,只欠重组。
