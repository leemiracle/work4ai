# 讲透人口学 · 把「人口增长」变成问题——生育、死亡与迁移的过程解剖学

> **本质一句话**:人口学=**人口过程的科学**——它把一个社会最坚硬的
> 「自然事实」(人要生、要死、要移动)变成可解释、可预测、可治理的对象:
> 出生与死亡如何被社会安排(转变的间隙),年龄结构如何把过去的人口行为
> 存成今天的增长(动量与稳定人口),生育规范如何在代际复制自己(低生育
> 陷阱);从马尔萨斯「几何级数压过算术级数」的警报,到 Leslie 矩阵把
> 人口变成一行特征值,再到全球人口峰值辩论——每拆一台「人口自然增长」
> 的直觉机器,买回一层「过程×结构×反馈」的解释;一句话:**没有自然的
> 人口,只有被社会安排的生育、死亡与迁移**。

## 一、家族定位(它在社会学宇宙里的位置)

1690 年代,格雷姆特用伦敦死亡表把死亡变成数(技术面归 91045);1798 年,
马尔萨斯把「人口按几何级数增长」变成对工业革命的警报,人口思想史开场;
1945 年前后两件事定盘:诺特斯坦把死亡-生育的先后下降写成**人口转变
理论**,莱斯利把年龄结构写成**矩阵**——一个管叙事,一个管机器。此后
半个世纪,学科的重心从「人口会不会爆炸」走到「人口会不会消失」:
第二次人口转型把生育率跌破更替解释为价值变迁,低生育陷阱把它解释为
自我强化的规范,联合国 WPP 逐版下修把全球峰值辩论推上前台。它在 840
宇宙里是**人口过程的司令部**:社会学理论供家庭与规范的理论底盘,
历史社会学供长时段的方法,统计宇宙供技术面,本家族管**把「生多少、
活多久、迁哪里」从命运变成社会科学**。五问(体系/前沿/语言/构造/转码)
的回答见家族层五章。

- **零门槛**:会算增长率与比例即可入门;只想看「人口排行榜」的去看
  新闻,本家族管的是**人口过程如何被社会安排、又如何反过来安排社会**
