# 04 · 人口学转代码:把人口过程搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:人口学的谱系左端(03 章)几乎可以无损转码——
> 转变是两条时间表的差分,人口是一台矩阵迭代,自锁是一个带记忆的
> 分岔;三条代码走廊——**转变解剖**(间隙的峰值/宽度/体积)、
> **稳定人口**(λ/NRR/动量)、**反馈回路**(双稳态与边界)——把
> 「爆炸是少死出来的」「增长欠昨天的生育率」「低生育会自锁」变成
> 可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",人口学转代码几乎**生来就是离散的**
(人是整数、事件按年计数、年龄分组组)——真正的翻译工作只有一步:
把人口学语言("死亡先于生育下降")翻成**时间表与率谱的参数化**。
损耗全部发生在参数的**选择**上(τ 为什么是 60 年、γ 为什么是 1.35)
——所以本章先划清哪些对象第一步就走得通(绿色区),哪些走不通
(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 人口学概念 | 代码化身 | 备注 |
|---------|---------|------|
| 转变的间隙 | 双 sigmoid 时间表+r(t) 差分+峰值/窗口解剖 | 实验幕一;τ 扫描可全量 assert |
| 稳定人口理论 | Leslie 矩阵迭代+幂迭代取 λ/特征向量 | 实验幕二;收敛与遗忘初值可精确断言 |
| 人口动量 | 更替切换(率谱缩放 NRR→1)+继续迭代 | 幕二第三段;正/负动量对照 |
| 低生育陷阱机制 | 记忆窗口+单向棘轮+理想下限的迭代 | 幕三;分岔扫描(初值网格)可自动化 |
| 指标族换算 | 粗率/标化率/TFR/NRR/λ/动量的规则化计算 | 02 章语法表的执行器 |
| 三张结构卡 | 定长字段记录+完整性断言 | 03 章 schema 的数据化 |
| 修订序列审计 | 多版本预测的 diff 与假设归因 | 01 章主线 A 的工具化 |

**转不动(红色区)**:

1. **理想子女数的规范解释**:「为什么是 1.8」是意义世界的重建;
   把自报意愿编码后跑回归,是把口径问题伪装成参数问题(02 章 §二)。
2. **「什么算适度人口」的裁定**:适度取决于目标函数(福利/实力/
   生态)——机器能对每个目标解最优,不能替人选目标。
3. **转变阶段的事后判定**:阶段的证据权衡(反例算不算数)须双人校;
   自动规则化会重演「阶段论」最被诟病的事后性。
4. **迁移的政治可行性**:替代迁移的算术可算,政治的裂缝不可算
   (01 章主线 C 的第二层)。
5. **政策的价值排序**:鼓励生育的预算该不该高于教育——代码算传导
   与后果,算不了应当。

**边界的一句话**:绿色区=时间表类+矩阵类+反馈类+卡片类,覆盖
"人口过程的机械学";红色区提醒:**转码是人口学的使用说明书,不是
替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:转变解剖走廊(间隙的峰值/宽度/体积)

```
率时间表 ──参数化──▶ 死亡/生育双 sigmoid(中心年差 τ) ──迭代──▶ r(t), P(t)
      │                                                        │
      └──扫描──▶ τ 网格(生育回应的早晚)──▶ 峰值/窗口/体积的敏感性断言 ◀──┘
```

- **理论→模型**:r=b(t)−d(t);死亡先降(卫生现代化),生育滞后 τ
  年降(规范改写慢)——爆炸=间隙的体积。
- **算法层**:每期 O(1);τ 扫描 O(k·T);断言用**峰值位置解剖**
  (峰值年 d 降幅>70% 且 b 降幅<30%)、**高度封顶**(峰值<b0−d1+ε)
  与**体积单调**(τ 大→终规模大,峰值几乎不动)。
- **本家族实现**:[`experiments/demographic_transition_momentum.py`](experiments/demographic_transition_momentum.py)
  幕一——峰值 2.43%(第 69 年,d 已降 92%/b 未降 11%);τ 45→75:
  峰值 2.07%→2.66%,终规模 4.32→10.18。
- **真实系统**:一切「两支速度不同的队伍过桥」的系统——技术采纳的
  供需差(算力供给先降成本、应用生态滞后)、组织变革的能力差(授权
  先到、问责后到)、疫后修复的部门差。诊断模板:**先找两支队伍,
  再量间隙**。
- **性能工程要点**:sigmoid 的中心年与宽度是**强耦合参数**(宽度大
  时峰值对中心差不敏感),做 τ 敏感性扫描必须固定宽度;断言只锚
  **聚合量**(峰值/窗口/终规模),不锚逐年路径——路径断言会被数值
  噪声随机击穿。

### 走廊 2:稳定人口走廊(λ、NRR 与动量的矩阵机)

```
率谱(年龄别生育/存活) ──构造──▶ Leslie 矩阵 L ──迭代──▶ 结构收敛 + λ
      │                                                        │
      └──对照──▶ 更替切换(NRR 缩放到 1)──▶ 动量 = 终规模/切换时规模 ◀─┘
```

- **理论→模型**:n(t+1)=L·n(t);常数率→稳定结构与内在增长率 λ
  (Lotka/Leslie);动量=更替后存量的周期(Keyfitz)。
- **算法层**:稀疏矩阵(17×17 只有 33 个非零元)——用嵌套列表直乘
  即可,O(组数²/步);幂迭代取 λ,收敛判据用**相邻两步结构距离**
  (2.99e-1→1.8e-14 单调降);动量迭代到结构距离平稳即止(慢尾如实
  标注:两臂终结构距离 2.4e-5,次主特征值 |λ2| 接近 1 的线性收敛)。
- **本家族实现**:同实验幕二——λ=1.1384/5 年(+2.63%/年);λ vs
  NRR^(1/T) 相对差 1.5%,两种世代口径差 3.2 年(一阶近似的诚实标注);
  动量 年轻 +52% vs 年老 −19%。
- **真实系统**:一切**存量-流量**系统的总账——用户池(新客=出生、
  流失=死亡、召回=迁移)、员工结构(招聘/离职/晋升=存活链)、教师
  与学位体系、基建容量。Leslie 化三问:状态变量按什么分组(年龄=
  司龄/届次)?组的宽度(细分组精确但参数多)?存活链上有没有漏画
  的迁移项(召回/回流)?
- **性能工程要点**:①**稀疏性必须利用**——只有首行+次对角非零,
  全矩阵乘是纯浪费;组数翻倍精度增益有限(5 岁组的教学精度已够
  λ-NRR 对照);②**断言单调性要避开暂态**(从第 6 步起断言,前几步
  的结构距离可能非单调);③动量的收敛判据用**结构**不用总量——总量
  的相对变化 1e-9 太贵,结构的慢尾是已知形态,如实标注比硬等便宜。

### 走廊 3:反馈回路走廊(双稳态与边界检测)

```
规范动力学 ──参数化──▶ 理想数=锚+γ×(记忆−锚)×棘轮权重;TFR=理想数−折损
      │                                                │
      └──扫描──▶ 初值网格 × γ 网格 ──▶ 稳态归类(更替/陷阱)──▶ 边界定位 ◀──┘
```

- **理论→模型**:记忆=成长期窗口的 TFR 均值(延迟系统);单向棘轮=
  低记忆才启反馈;理想下限=一孩硬底——γ 足够大时两个吸引子并存。
- **算法层**:确定性迭代,每步 O(窗口宽);稳态归类用终值阈值
  (>2.05 或 <1.25);边界定位用**初值二分**(1.6 落陷阱/1.7 回更替,
  边界夹在其间);延迟系统的收敛要等记忆窗口整体换血(窗口宽+1 代
  人),迭代长度按 3×窗口起步。
- **本家族实现**:同实验幕三——γ=0 冲击后精确回 2.10;γ=1.35:初值
  {2.3,1.9,1.7}→更替,{1.6,1.5,1.35}→1.15;同一冲击在 γ=0.5 可恢复、
  在 γ=1.35 越界自锁。
- **真实系统**:一切**规范自锁**的现象——小众产品的用户社群(小池子
  的内容由小池子的用户生产,新用户看到的是冷清)、代码库的技术栈
  (旧栈生态由旧栈需求喂养)、城市的收缩循环(服务撤出→人口流出→
  更撤出)。诊断模板:**找到记忆窗口(新人看到的世界由谁构成)、
  量棘轮强度(小池子会不会自我合理化)、判边界(掉到多低就回不来)**。
- **性能工程要点**:延迟系统的**稳态判定要防早停**——终值在窗口
  换血前会假平稳(记忆还没更新完);γ 扫描与初值扫描是**独立的两维**,
  别用一维扫描冒充分岔图;断言边界位置用区间(夹逼),不用点估计。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:用户池的 Leslie 化——增长是留存与新客的矩阵机

- 把用户池写成 Leslie:状态=司龄组,存活=留存率,出生=新客注入,
  迁移=召回/回流(常被漏画的一项)。立刻得到的两个免费洞见:
  ①**内在增长率**由率谱决定,与当前结构无关(结构只是暂态)——
  「这个月增长快」可能只是拉新脉冲的动量,不是留存改善;②**动量**
  ——即使新客率立刻降到「更替」(与流失打平),用户池仍会惯性变化
  数个周期。增长分析的第一课:先分离率与结构,再谈趋势。

### 落点 2:结构动量审计——别把存量周期记成立功/过错

- 任何「指标连续 N 季度上涨/下跌」的归因会议,先跑一遍动量审计:
  把流量(新增/流失)拧到持平,存量还会走多久?若趋势的大部分由
  存量周期解释,当期运营的功过都要按残差记账——幕二 +52%/−19% 的
  业务版。这一条对用户增长、教师结构、内容供给池全部适用。

### 落点 3:规范自锁检测——小池子会不会自我复制

- 社区/产品生态的「冷启动失败」常是幕三的形态:新用户看到的内容由
  老用户生产,池子越小内容越稀、内容越稀池子越缩。检测三步:定义
  记忆窗口(新用户首月看到的世界)、估棘轮强度(内容密度对留存率的
  弹性)、做边界实验(把内容密度人工垫高到阈值之上,看能否翻越自锁
  边界)。「增长团队该在边界之上还是边界之下发力」,是这个模型给出
  的战术问题。

### 落点 4:区间纪律进 roadmap——预测给区间,决策给分位

- 把 01/02 章的预测纪律工程化:任何 12 个月以上的规划数字(用户量/
  营收/人力),输出必须是**中位数+区间+敏感性排序**(哪个假设最脆),
  且近端(由存量决定)与远端(由假设决定)分段标注——WPP 概率走廊的
  产品版。评审卡三道:区间带了吗?分位选了吗(保守/基准/乐观各对
  什么决策)?最脆假设点名了吗?

## ✍️ 练习

1. 🐍 给走廊 2 加迁移项:在 Leslie 次对角外给某年龄组加常数净迁入,
   预测并验证:λ、稳定结构、动量各怎么变?「移民补的是数量还是结构」
   的参数答案是什么(01 章主线 C 的机器版)?
2. 🐍 在走廊 3 把记忆窗口从 t−27…t−17 改成 t−37…t−27(隔一代才
   记),预测并验证:边界位置与自锁速度各怎么变?「记忆越深越难自锁
   还是越易自锁」?
3. ✋ 按落点 1 给你的用户池/业务池写 Leslie 化三问的答案:分组变量/
   组宽/漏画的迁移项;注明哪个率你最测不准
4. ✋ 按落点 2 审计你团队最近一次「连续增长/下跌」的归因:多少是动量、
   多少是残差?把审计表写成半页 runbook(含数据、切换定义、结论)

衰退归罪/低生育会自锁),先问它的**对照切换**造了没有:没有更替
