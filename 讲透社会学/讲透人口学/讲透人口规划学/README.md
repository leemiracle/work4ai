# 讲透人口规划学 · 规划人口的悖论——越成功,越要为后果再规划一次

> **定位句**:这支负责**规划**——把人口预测接进学校/劳动力/住房/养老的供需滚动匹配,目标人口的概念与情景规划;它管「知道人口要变,安排怎么跟着变」。口号:**规划是预测的制度化**。GB/T 13745 84071 人口学 · **GB/T 支**(8407160)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:计划经济时代的人口-经济平衡表(劳动力/消费基金的规划核算)是中文侧的直接源头;1970-80 年代教育规划与劳动力规划的方法输入(供需滚动匹配);「目标人口」概念随计划生育的规划实践进入中文话语;当代:萎缩期规划(收缩城市与过剩基建的处置)、区间决策的制度化(预测概率走廊的治理传导,01 章)成为主战场。
- **因什么问题**:①人口不确定时怎么规划硬资产(不确定性之问)②规划的时滞与人口的时滞怎么对表(双时滞之问)③萎缩期规划与增长期规划是不是同一门学科(换挡之问)。

## 核心问题

**已解决(通说)**:供需滚动匹配的工序(预测→分年龄段需求→设施供给→再滚动)标准化;「按队列规划」的确立(学龄人口=已出生队列的会计,预测误差极小——时差分层的直接应用)。

**未解决/深水区**:过剩资产的处置伦理(为峰值建的校舍与道路,峰值过后归谁);区间决策的制度化(按 80% 分位还是 95% 分位建医院——分位选择是政治);萎缩期的规划范式(增长期规划的全部直觉在萎缩期反转)仍在成型。

## ✨ 这支最美的一个事实

**规划的悖论**。人口规划越成功,越要为它的成功再规划一次:学校按出生峰值扩建,十年后峰值队列毕业,校舍过剩;道路按扩张期通勤建,收缩期养护反成财政包袱。为什么美:**它暴露了规划的时间结构**——规划对象(人口)自带几十年周期(幕二的存量周期),规划工具(预算与基建)自带另几十年周期,两个周期的错拍就是过剩与短缺的全部来源。规划学的一半是预测,另一半是**给自己上一次规划善后**。
