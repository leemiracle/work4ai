# 讲透计划生育学 · 从家庭计划到生育支持——一门掉过头来的学科

> **定位句**:这支负责**计划生育的学术史与各国方案比较**——从新马尔萨斯主义的避孕主张、家庭计划运动的服务系统,到各国方案的设计与转型,再到当代生育支持的服务侧;按通说学术史口径平实记录政策演变,**不评论现行政策**(治理纪律)。口号:**同一门学科,两个方向**。GB/T 13745 84071 人口学 · **GB/T 支**(8407170)· 家族:[讲透人口学](../README.md)

## 诞生

- **谁/何时**:普莱斯一系新马尔萨斯主义(19 世纪,避孕作为「预防抑制」的技术替代);桑格一线的节育诊所运动(1910-20s)与国际计划生育联合会成立(1952,通说);印度首个国家级家庭计划方案(1951,通说)开启「限制时代」的国家实验;中国:1970 年代「晚稀少」、1980 年代一孩化、2010 年代「单独-全面两孩」、2021 年三孩与生育支持(按官方文献与学术史通说平实记录);1994 年开罗人发大会把范式从人口指标转向**生殖健康与权利**(通说节点);此后「计划生育学」的内涵逐步扩为「生殖健康与生育调节」。
- **因什么问题**:①生育能不能被有计划地调节(可行性之问)②计划由谁做——国家/家庭/个人(主体之问)③调节的方向翻转时学科怎么自处(转向之问)。

## 核心问题

**已解决(通说)**:避孕技术的可得性与生育率下降的强相关(近端决定因素框架的实证核心,02 章);服务系统设计(供给网络/随访/知情选择)的工序成熟;开罗范式(权利本位)成为国际文件的规范语言。

**未解决/深水区**:历史限制政策与自发生育转变的贡献分解(识别难题,通说存争议);支持时代的服务系统怎么建(托育/辅助生殖的可及性——生育医学的接口);「家庭计划」概念的当代重述(家庭自主的生育间隔与数量选择)。

## ✨ 这支最美的一个事实

**掉头的学科**。19 世纪普莱斯为工人阶级争避孕权,20 世纪国家把它变成人口指标的工具,1994 年开罗把它还回权利的语言,21 世纪同一套服务网络开始反向运转(从节制到支持)。为什么美:**这门学科把「工具无所谓方向、方向属于范式」演绎了两百年**——诊所还是诊所,随访还是随访,变的是「为谁计划」四个字;读它的历史像看一条河改道:河床没动,水头掉了头。理解这个掉头,比评价任何一段政策都更接近这门学科的本体。
