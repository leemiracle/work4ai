# 03 · 可构造与结构:哪些田野对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:社会人类学的对象沿一条**可构造谱系**排开——
> 亲属图端**严格可构造**(记法写得下、外婚半径算得动、联盟网络
> 断言得了),交换圈端**严格可构造**(周转期线性、基尼可断言),
> 田野关系端**几乎不可构造**(只有反身的工艺,没有装配学);
> 全谱系共享两条结构引擎:**循环引擎**(环式交换把平等从极限
> 性质变成结构性质)与**联盟引擎**(禁忌半径把通婚边撑成网络);
> 而"田野研究本身"可以压进三张**结构卡**(亲属图卡/田野笔记
> 结构卡/交换圈卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
交换圈 ── 外婚联盟图 ── 亲属术语表 ── 继嗣分支图 ── 亲属图卡 ── 交换圈卡 ── 田野笔记卡 ── 参与观察/田野关系
   │                                                                                  │
严格可构造(可断言)                                                     几乎不可构造(只有思想操作化)
  └── 记法写得下、网络算得动、能过 assert                              └── 只能在居住与反身中操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:
交换圈的语义是"物沿固定方向的传递序列",输入输出明确;而
"参与观察"的语义是观察者与被观察者**互相改造的长期关系**——
观察者本人就是仪器,且仪器在测量过程中被被测物重写
(马林诺夫斯基日记问题,00 章美之时刻 3),仪器无法装配仪器。
本章先盘家底,再看两条结构引擎,最后把田野研究压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **交换圈→周转期与基尼** | 环+双流对开+锁步节拍;基尼=持有份额的基尼 | 低(实验律一全程可跑) | 锁步是制度理想型;现实库拉的名人长持会造成相位漂移(实测口径见实验注记) |
| **外婚图→联盟网络** | 禁区半径 r+许可圈择偶;分量/直径/平均最短路 | 低(实验律二) | 择偶规则是示数化的(均匀);真实偏好(近距优先/聘礼)会改形状不改机制 |
| **亲属术语表** | 称谓×亲属类型的矩阵;六型分类 | 低 | 类型是客位格;同型不同义(02 章) |
| **亲属图记法** | 标准记号(□/○/=/─/│)+代际分层 | 低 | 记法本身是客位投影;当地画法可能不同 |
| **继嗣分支图** | 谱系树+裂变线(福忒斯式) | 中 | 法人资格(地盘/仪典)比血缘更决定分支效力 |
| **亲属图卡** | 三栏 schema(§四) | 低 | 主位范畴必须显式登记 |
| **交换圈卡** | 三栏 schema(§四) | 低 | 义务的强制性程度要定级 |
| **田野笔记卡** | 三栏 schema(§四) | 低 | 卡片管记录不管关系——关系的部分永远填不满 |
| **互惠三型判定** | 社会距离×返还时距×等效性 | 中 | 三型是连续谱的两端锚(02 章) |
| **参与观察/田野关系** | 长期居住+语言+反身性 | **不可构造** | 观察者被被测物重写;压缩即失真 |

**反直觉发现(本章铁律)**:**本学科的可构造性与"出身年代"
大体无关,与"形式面/意义面"的分工有关**。最老的母题(亲属,
1877)反而最可构造——因为亲属的**规则面**(禁区/记法/术语表)
天然有限可描述;最新的方法(数字田野)再新,只要涉及关系与
在场,照样不可构造。**规则可构造,意义不可构造;结构可断言,
关系只能反身**——拿关系硬造指标(用"共处时长"测田野质量)
是两头都不是。

## 二、结构引擎 1:循环引擎(环式交换的制度化平等)

**直觉图像**:物在环上走,人在原地等——流动被写死成一张
时刻表。

- **数学化身**(实验律一):N 群体的锁步双流环(臂环逆时针/
  贝项顺时针),每跳=持有期 h+传递延迟;绕圈时间=N×(h+延迟),
  严格线性(N=6/12/18/24→18/36/54/72 期),双向同速;长期持有
  份额的基尼=0.0000,开放市场·随机 0.0065,开放市场·累积优势
  0.4850。
- **三条刚性**:
  1. **线性刚性**:绕圈时间只由环大小与节拍决定——名望的
     回归周期(你的名声多久转回你手里)是制度的钟,不是人气
     的浮标。
  2. **零点刚性**:环式基尼恒为 0——不是"趋于平等",是
     "就是平等";每一步该谁持有由环写死,运气无处插手。
  3. **断裂刚性**:市场只要有一丝累积优势(流向偏好已富者),
     份额就锁死不平等(0.4850,与环差 74 倍)——平等与集中
     之间没有温和的中间态,只有制度与非制度之分。
- **理论地位**:这是莫斯"礼物在环上永不停止"的算术化身——
  三重义务(给/受/报)在环上被**空间化**:你的报就是下一家的
  给。夸富宴是循环引擎的极限档(用销毁把"给"推到顶点)。
- **刚性从哪来**:锁步与环是**制度理想型**——刚的地方在结构
  (环+方向+义务),软的地方在**现实相位**(名人长持、季节性
  停摆);理想型的作用是给出"纯环"的基准,现实库拉是它的
  扰动版(02 章换算陷阱栏)。

## 三、结构引擎 2:联盟引擎(禁忌半径的代数学)

**直觉图像**:禁区像吹气球——禁掉近处,通婚边被推到远处,
联盟网络被撑开。

- **数学化身**(实验律二):M=24 群体排环,禁婚半径 r(禁与
  环距 ≤r 者通婚),每群发起 3 桩婚姻(许可圈内随机);平均
  通婚环距 6.29→11.33 随 r 单调上升,网络直径 3.1→6.0、平均
  最短路 1.93→3.61 拉长;r=11 时崩解为 12 个孤对。
- **三条刚性**:
  1. **撑开刚性**:禁忌半径每推一格,通婚跨越的社会距离单调
     上升——禁令不是减法,是联盟的**发生器**(列维-斯特劳斯:
     乱伦禁忌=外婚制的正面)。
  2. **拉长刚性**:联盟圈越大,姻亲链越长(直径/最短路随 r
     扩大)——网络规模的代价被结构性地摊给每个成员。
  3. **断裂刚性**:许可圈收缩到只剩对跖群体时,网络崩解成
     孤对——**撑过头就要断**;外婚制的可行域是一个有限区间,
     不是越严格越好。
- **理论地位**:这是联盟理论的最小机器——"交换妇女"的宏观
  后果(联盟网络)被压缩成一个参数(禁区半径);继嗣群分支与
  对立(福忒斯-埃文思-普里查德)是它在不同继嗣规则下的变体
  (第一支的纵深)。
- **刚性从哪来**:图的连通性数学是刚的;软的地方在**择偶规则**
  (均匀是示数化;真实的近距优先/聘礼制会改具体数字,不改
  "撑开-拉长-断裂"三段式)。

- **两具引擎的合读**:循环引擎管**物的流动**(声望如何在环上
  回归),联盟引擎管**人的流动**(婚姻如何把群体焊成网络)——
  莫斯与列维-斯特劳斯师徒的两大母题各拿到一个可断言的算术
  身;礼物圈靠**义务**维持,联盟网靠**禁忌**生成——一个是
  正向的"必须给",一个是负向的"不许娶",合起来正是交换的
  阴阳两面。

## 四、结构卡 schema:把一项田野研究压进三张卡

**先答为什么**:田野研究的难点在"整体性"——一个田野就是
一整个世界,散落文献难以携带。结构卡是**有限字段的压缩格式**:
字段固定、填空即复用、可比可查(这是"可构造"在研究层的
对应物:卡片本身严格可构造)。

### 卡 1:亲属图卡(把一个亲属系统钉成可审的表)

```
【亲属图卡】
研究对象:________(哪个群体的亲属制度)
术语类型:□爱斯基摩 □夏威夷 □易洛魁 □苏丹 □克劳 □奥马哈(客位格)
关键区分:________(当地最在意的切分:如交表/平表、母系/父系)
继嗣规则:□单系(父/母) □双系 □其他__;继嗣群的法人性标记:______
婚姻规则:禁区=________ 许可侧=________(规定型/选择型)
可检验推论(一条):________(如:禁区每扩一格,通婚圈外推一圈)
主位备注:________(当地自己的范畴与我们的格最大的出入)
```

样例(已填,努尔人骨架,通说):术语=克劳型偏移;关键区分=父系
继嗣线上的辈分;继嗣=父系,法人性=地盘与牛仪典;婚姻=父系
外婚+聘牛;推论=裂变对立在谱系深度上是"对称的"(离共同祖先
越远越易对立);主位=牛在亲属语言里的中心地位。

### 卡 2:交换圈卡(把一个交换制度钉成可审的表)

```
【交换圈卡】
对象:________(哪个交换制度:库拉式环/夸富宴式竞赛/平台打投)
流通物:________(物类/方向/是否可让渡);圈拓扑:□环 □竞赛 □网
三重义务定级:给(强/中/弱)__ 受(拒绝的代价)__ 报(时限/等效性)__
节拍:名义周期=________ 实际持有(名人长持?)=________
结构诊断:环式 or 累积?(基尼/流向规则);断裂点:________
可检验推论(一条):________
```

样例(已填,平台打投骨架):流通物=虚拟礼物,单向粉丝→主播+
排行榜回流;三重义务=给(强,氛围强制)受(中,不接即塌房)
报(强,点名回谢);节拍=名义周期一场直播,实际持有=榜首效应
长持;结构诊断=排行榜是**累积市场**不是环(00 章实验律一的
右列);断裂点=不回谢的主播;推论=引入"流转型"荣誉(限持有
期的勋章)会把基尼从累积档压向环式档。

### 卡 3:田野笔记结构卡(把一次田野的记录钉成可审的表)

```
【田野笔记结构卡】
田野:________(地点/时段);周期覆盖:□完整年度周期 □部分(缺哪段)
语言:工作语言等级=________(寒暄/事务/争吵)
报道人:人数=__ 谱位分布=________(头人/边缘/跨派别)
双轨记录:主位轨(他们的范畴与说法)=____ 客位轨(我的格)=____
反身栏:观察者位置(权力差/扰动/盲区)=________
缺失声明:没看到什么、为什么没看到=________
```

样例(已填,线上场景骨架):田野=某游戏公会群,时段=两个完整
赛季;周期覆盖=完整(两次版本迭代);语言=事务级(术语流利,
语音缺席);报道人=7 人(会长/团长/边缘成员/退会者);双轨=
主位轨"带新人"的义务话术/客位轨声誉分数模型;反身栏=笔者是
资深玩家,与会长有旧谊(扰动:边缘人对我戒备);缺失=线下
生活(成员的地区分布仅自报)。

**判定流程**(把一个人类学主张钉到谱系上):

```
该主张的核心对象能写成记法、网络或圈吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(卡片/谱系,填空带判断)─▶ 中段:卡片化+主位客位双轨,禁止硬算
  └─ 不能(关系/在场/意义)────▶ 右端:田野笔记卡+反身栏,禁止压成参数
```

## 五、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 亲属制度与继嗣 | 左-中段:外婚图/术语表/分支图可算;称谓的意义面在右端 | 联盟引擎(禁区半径撑开网络) | 中-高(规则面可断言,意义面不可) |
| 礼物与交换 | 左端为主:交换圈/周转/基尼全可算;义务的强制性定级靠田野 | 循环引擎(环式平等+市场集中) | 高(本家族最可构造的支) |
| 田野民族志与数字人类学 | 右端为主(关系与在场不可构造);方法规程可清单化 | 两具引擎的**使用说明书**(什么对象交给什么构造) | 低(卡片管记录,关系靠反身) |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——
交换圈走计算,亲属走半计算(图+判断),田野永远走居住与反身。
**没有哪支全家可构造,也没有哪支全家不可构造**;这正是社会
人类学比它的名声("只会讲故事")更能算的地方,也比它的野心
("一切皆可计算")更谦逊的地方。

## ✨ 美之时刻(彩蛋第 6 枚:两具引擎图的合龙)

✨ **美之时刻 6:义务与禁忌——交换的两台发动机**(极简)
循环引擎说:物被"必须给"的义务锁在环上,平等是结构的副产品
(基尼 0.0000);联盟引擎说:人被"不许娶"的禁忌推出家门,
网络是禁令的副产品(通婚环距 6.29→11.33,撑过头崩成孤对)。
为什么美:**莫斯与列维-斯特劳斯这对舅甥(学术谱系,通说)的
两大母题,各自拿到了一个可断言的算术化身**——一个正向给,
一个负向禁;一个管物流,一个管婚姻流;"社会的粘合剂"与
"社会的语法"原来是同一台交换机的两个按钮。亲历:挑一个你
身边的声望循环(游戏勋章/公司荣誉/学术引用),问它是环式
(限时流转)还是累积(终身沉淀)——两台发动机听声可辨
(✍️练习 1)。
