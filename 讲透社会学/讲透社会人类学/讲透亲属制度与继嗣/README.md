# 讲透亲属制度与继嗣 · 社会的语法——血缘分节成联盟的规则系统

> **定位句**:这支负责三大母题的**语法车间**——亲属术语不是血缘距离的记录,是
> **社会分组的地图**(摩尔根);继嗣群不是亲戚名单,是有地盘与仪典的**法人
> 团体**(福忒斯);婚姻规则不是道德禁令,是**联盟的发生器**(列维-斯特劳斯:
> 乱伦禁忌=外婚制的正面)。
> GB/T 13745 840 社会学 · 84057 社会人类学 · **自定支 1/3**。家族:[讲透社会人类学](../README.md)

## 诞生

- **谁/何时**:摩尔根《古代社会》(1877,塞讷卡田野)开山;列维-斯特劳斯
《亲属关系的基本结构》(1949)立顶层(基本结构=规定型通婚/复杂结构=只定
禁区);福忒斯-埃文思-普里查德《努尔人》《塔伦西人》(1940s)立继嗣群
学派;当代:通婚圈测绘的计算转向(家族 01 章主线 C,检索校准 2026-09-07)。
- **因什么问题**:①称呼为什么与血缘距离错位(术语之问)②没有国家的社会
靠什么组织政治(法人之问)③禁最近的婚姻为何是社会性的起点(联盟之问)。

## 核心问题

**已解决(通说)**:术语切分社会分组(六型分类为客位标准格);继嗣群的
法人性;外婚制的联盟效应(禁区撑开通婚网络)。
**未解决/深水区**:复杂结构内部的多样性(联盟理论的软肋);称谓的意义面
(同型不同义);计算转向只接客位侧的口径边界(家族 02 章)。

## ✨ 这支最美的一个事实

**努尔人的裂变政治——离共同祖先越远,对立越深**:努尔人没有首领与法院,
秩序却稳定。父系继嗣群像套盒层层分支,最小支为一头牛打得不可开交,大支
只在更大的冲突里对立——**对立的规模与谱系距离同步放大**。没有中央的政治
靠"敌人的敌人就是盟友"自我平衡:每个群体同时在几层对立中占位,系统整体
反而稳定——**谱系就是政治的宪法,祖先的名字就是条款**。
