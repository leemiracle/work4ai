# 讲透社会人类学 · 他者的镜子——社会形式如何在田野里显影

> **本质一句话**:社会人类学=用「他者的眼睛」反观自身社会的学科——
> 它不问"我们的制度为什么先进",而问**同样的功能(联姻/交换/信仰)
> 在别的社会长成什么形状**;它不靠问卷靠**田野**(长期参与观察,
> 马林诺夫斯基标准:住进村里、学会语言、跟完一个年度周期);它的
> 三大经典母题——**亲属、礼物、仪式**——都指向同一件事:**社会用
> 可传承的形式把流动的人际关系焊成结构**;一句话:**把自家社会眼里
> 的"自然",还原成人类可能性清单上的一项。**
>

## 一、家族定位(它在社会学宇宙里的位置)

社会学宇宙的多数家族研究"现代社会的某一域"(分层/组织/市场),
本家族研究**"社会形式本身"**——它在小型与非现代社会里看得最清楚:
亲属术语如何把血缘分节成联盟(摩尔根-列维-斯特劳斯),礼物如何
把人捆进义务之环(莫斯),长期田野如何让"自然"显影为"文化"
(马林诺夫斯基-格尔茨)。它给全宇宙供两件看家工具:**比较**
(用他者打断自家的理所当然)与**深描**(分层写清行为背后的
意义结构);从摇椅到田野(1870s-1920s)、从功能到结构到解释到
反思(1920s-1980s)、从单点到多点到线上(1990s-),编年见 00 章。

> 三支的共同血统:**三大母题都是"社会形式如何约束流动的人"**——
> 亲属约束婚姻流(谁可以嫁谁),交换约束物流(物必须走多远),
> 田野约束知识流(观察者被自己的位置约束);前两支是学科的对象面,
> 第三支是学科把手术刀对准自己的一支——认识论的车间。
