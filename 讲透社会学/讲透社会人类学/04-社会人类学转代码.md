# 04 · 社会人类学转代码:把田野的形式面搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:社会人类学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**库拉环走廊**、**外婚联盟
> 走廊**、**深描=重要性抽样走廊**——把"环式交换把平等制度化"
> "禁忌撑开联盟圈,撑过头就断""把观察力花在信息最多的地方再
> 还原"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",社会人类学转代码要先过**出身关**
(02 章"构念的田野户口"):把一段田野主张("礼物在环上永不
停止")先翻成模型(环+双流对开+锁步节拍+基尼),再翻成代码。
翻译的损耗发生在两处——**制度理想型**的简化和**主位意义面**的
丢弃;所以本章先划清哪些对象第一步就走得通(绿色区),哪些走
不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 人类学概念 | 代码化身 | 备注 |
|---------|---------|------|
| 交换圈→周转期 | 环+双流对开+计时器;标记物回归检测 | 实验律一;线性律解析可断言 |
| 持有份额基尼 | 累计持有/总量;O(n²) 两两差 | 环式/市场两制度对照的核心量 |
| 市场累积优势 | 流向概率 ∝ (β+累计接收数)(波利亚 urn) | "开放市场"的最小模型 |
| 外婚禁区→联盟网络 | 许可圈择偶+边集;BFS 全源最短路 | 实验律二;分量/直径/ASP 全可断言 |
| 亲属术语矩阵 | 称谓×亲属类型表;六型分类器 | 客位格的机械判定 |
| 亲属图记法 | 标准记号的规范字符串/边表 | 记法校验与代际分层 |
| 稀有事件估计(深描) | 移位指数 proposal+似然权重还原 | 实验律三;方差比可断言 |
| 三张结构卡 | 定长字段记录(dict/dataclass) | 卡 1/2/3 的数据化;主位栏强制非空 |

**转不动(红色区)**:

1. **田野关系与在场**:没有状态方程——信任、报道人网络、观察者
   被重写的过程不可参数化,压缩即失真。工程对策:退到田野笔记
   结构卡+反身栏(03 章右端),不当仿真变量。
2. **主位意义**:代码能算"禁区半径多远",算不了"当地觉得什么
   算近亲"——主位范畴必须由人在卡片里声明,不许藏在代码里
   冒充自然(与 02 章"出身之眼"同源)。
3. **义务的强度**:三重义务的"强/中/弱"定级靠田野;代码只能
   执行定级后的参数。
4. **proposal 的端到端选择**:实验律三里 λ=τ 是**知情选择**
   (贴住尾部衰减尺度);面对真实田野,proposal 形状要从领域
   知识来——代码不豁免"了解分布"的责任。

**边界的一句话**:绿色区=环类+网类+估计器类,覆盖"交换与联盟
直觉的校准";红色区提醒:**转码是田野主张的使用说明书,不是
田野的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:库拉环走廊(循环引擎的全机械化)

```
莫斯命题 ──参数化──▶ 锁步双流环(h+延迟,均布相位) ──测量──▶ 周转期/基尼
      │
      └──对照实验──▶ {环式, 随机市场, 累积市场} ──▶ 平等的制度化断言
```

- **理论→模型**:N 群体、臂环逆时针/贝项顺时针、每跳 h+延迟;
  三种流向规则(环邻/均匀任意/按优势加权)共享同一节拍。
- **算法层**:计时器数组同步递减,O(K)每期;标记物回归检测
  绕圈;基尼 O(N²)(N 小,无所谓)。
- **本家族实现**:[`experiments/kinship_gift_field.py`](experiments/kinship_gift_field.py)
  律一——断言绕圈=N×(h+延迟) 线性(N=6/12/18/24→18/36/54/72);
  基尼 环 0.0000 < 随机 0.0065 ≪ 累积 0.4850(差 74 倍)。
- **真实系统**:荣誉/积分系统的**环式 vs 累积**设计(见落点 1);
  声望回归周期的容量规划(名望多久转回头上,是制度钟,可排期);
  虚拟物品经济的结构诊断(排行榜=累积市场,限期勋章=环)。
- **性能工程要点**:锁步环是 O(1) 摊还的时钟,不需要事件队列;
  市场臂的加权抽取用线性扫描(O(N) 每次,K 大时改前缀和+二分);
  **制度对照实验要共享随机数流外的独立种子**,保证差异来自规则
  不来自噪声。

### 走廊 2:外婚联盟走廊(联盟引擎的扫描台)

```
列维-斯特劳斯命题 ──参数化──▶ 禁区半径 r + 许可圈择偶 ──扫描──▶ 网络形状(r)
      │
      └──断言──▶ 撑开(距离单调↑)/拉长(直径·ASP↑)/断裂(分量爆炸)
```

- **理论→模型**:M=24 群体排环;禁婚半径 r 禁掉环距 ≤r 的对象;
  每群发起 3 桩婚姻,均匀落在许可圈;并集成无向联盟网络。
- **算法层**:许可圈构造 O(M²);BFS 全源最短路 O(M·E);每个
  r 重复 8 张网络平均掉择偶噪声(单张网络的均值噪声 ~0.37,
  会淹没 0.5 的步进——**平均不是装饰,是断言成立的前提**)。
- **本家族实现**:同实验律二——平均通婚环距 6.29→11.33 单调
  上升(1.8 倍);直径 3.1→6.0、ASP 1.93→3.61;r=11 崩解为
  12 个孤对。
- **真实系统**:跨团队协作规则的**禁忌半径设计**(见落点 2);
  联盟/伙伴网络的健康度监控(直径拉长=协调成本上升的早期信号);
  平台撮合的禁区参数(地域/利益冲突回避)对网络连通性的压力
  测试。
- **性能工程要点**:扫描是 r 的外循环,每格独立可并行
  (seed=base+格号保证可复现);**随机性必须被平均掉再断言**
  (对随机系统直接断言单次实现,是仿真实验的头号翻车点);
  连通性判断在 r 接近断裂点时最敏感,加密采样。

### 走廊 3:深描=重要性抽样走廊(观察预算的最优配置)

```
马林诺夫斯基命题 ──参数化──▶ 尾概率估计 E[1{X>τ}] ──对照──▶ {均匀臂, IS 臂}
      │
      └──还原纪律──▶ 似然权重 w=f/g ──▶ 无偏+方差坍缩断言;窄窗=偏差警示
```

- **理论→模型**:目标 p=P(X>τ)=1%(稀有但关键的田野事件);
  均匀臂=随机抽查日常;IS 臂=把观察押在尾部情境(移位指数
  proposal,λ=τ),按 w=f/g 还原。
- **算法层**:两臂各 n=1000 次×400 组重复,以**组间方差**估计
  估计量方差;闭式理论值对表(E_g[w²] 的解析式在代码注释里)。
- **本家族实现**:同实验律三——均匀臂相对误差 ±31.6%,深描臂
  ±0.7%,方差比 2177(理论 2121);窄窗警示臂 0.0076(系统性
  低估 24%)。
- **真实系统**:用户研究/风控巡查的**观察预算配置**(见落点 3);
  灰度发布中稀有故障率的估计(把监控密度押在风险窗口,再按
  窗口占比还原);审计抽样(异常凭证的尾部概率)。
- **性能工程要点**:IS 的全部红利来自 **proposal 对尾部的贴合度**,
  λ=τ 贴住高斯尾衰减尺度,权重几乎恒定(w_max/p≈1.14)——
  方差坍缩三个数量级不是魔法,是匹配;**权重方差是 IS 的健康
  指标**(权重发散=proposal 说谎),工程上以有效样本量
  n_eff=(Σw)²/Σw² 监控;窄窗臂不是稻草人——忘了还原权重的
  "深描"是系统性偏差,不是高方差。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:荣誉系统的环式设计——用制度对抗累积

排行榜类荣誉(积分/徽章/等级)是**累积市场**:流向偏好已富者
(强者恒拿),基尼锁死(实验律一的 0.4850 档)。环式替代:**限期
流转的荣誉**(限时称号/轮换徽章/年度重置)把"持有"变成接力
——名望的回归周期=N×节拍,平等由结构保证。设计清单:荣誉的
**可让渡性**(能否转赠)、**持有期限**(节拍)、**回归路径**
(转给谁由什么写死)——三格都填上,就是一张交换圈卡(03 章卡 2)。

### 落点 2:协作网络的禁忌半径——撑开,但别撑断

跨团队组队规则里的回避条款(本组禁婚=同组禁评/竞业回避/利益
冲突回避)是联盟引擎的开关:回避半径每扩一格,协作边跨的部门
距离单调上升(多样性↑),但网络直径与协调链也拉长,回避过宽
时分网络崩成孤岛(分量数爆炸)。工程动作:把回避规则参数化,
在**多样性收益**与**连通性风险**之间扫描(走廊 2 的内网版),
监控"孤对"的出现作为过断的早期报警。

### 落点 3:观察预算的重要性抽样——押在尾部,权重还原

有限的调研/巡查/审计预算别均匀撒:识别你的"尾部情境"(事故
高发的深夜班/流失用户的最后七天/大促的峰值小时),把观察密度
按贴近尾部的分布配置,记录每个观察的**典型性权重**(这个情境
在总体中占多少),出报告时按权重还原总体口径。两条纪律:权重
要存档(忘了还原=把戏剧性当典型性,实验律三警示臂的 24% 低估);
权重方差要监控(权重发散=你押错了地方)。

### 落点 4:给"在场"定价——方法效度的容量规划

线上社区的运营与研究都要回答"待多久算数":按马氏标准的本质
(覆盖一个完整社会循环),先定义你的场景的**年度周期**(一个
赛季/一次版本迭代/一轮寒暑假),再据此排观察窗口——覆盖完整
周期的短观察,优于错过关键节气的长观察(02 章铁律的工程版)。
