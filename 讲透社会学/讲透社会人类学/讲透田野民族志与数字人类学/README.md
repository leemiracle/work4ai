## 核心问题

**已解决(通说)**:参与观察的标准动作(住/语言/周期/报道人网络);反身
性入方法;多点与线上作为合法田野。**未解决/深水区**:深描的可比性;
线上在场效度(赛季≠年度周期的争议);数字知情同意;"哪都没待够"。

## ✨ 这支最美的一个事实

**把马氏宪法带进虚拟世界**:Boellstorff 研究《第二人生》不访谈玩家、不
分析日志,而是**化作头像住进去两年**,在虚拟世界里参加婚礼、买地、建
社区,按马林诺夫斯基的原始标准做完整民族志。发现:虚拟世界不是现实的
影子,是**自成一体的社会**。**田野的本质不是地理,是"完整社会循环的
在场"**——线上田野不是降级版,是同一部宪法的新领土。
