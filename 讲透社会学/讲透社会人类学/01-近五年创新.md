# 01 · 近五年创新:2021-2026 社会人类学在动什么

> **本章回答五问之二:近五年(2021-2026)这个分支在动什么。**
> **不是教材共识,是活的。**
> 检索校准 2026-09-07(Semantic Scholar + Web 双轨;素材由主会话集中检索,见章末来源节)。
>
> **本章一句话**:社会人类学近五年把田野搬进了它自己研究出来的
> 世界体系里——**线上田野**成为方法建制(数字人类学从边缘变常规),
> **基础设施与物质性**成为新的"亲属与礼物"(物如何组织社会被
> 重新问了一遍),**多点民族志**在世界体系纲领三十年后与供应链/
> 平台/气候议题合流;而三大古典母题(亲属/礼物/田野传统)是三条
> 主线共同的上游(方向锚)。

## 开篇:一门"最慢"学科的最近五年

本家族的方法宪法是"住满一个年度周期"(1922),经典对象的平均
研究尺度是"一个村子"。2021-2026 的图景却是:**对象先于方法
流动化了**——平台、供应链、数据中心、气候、移民路线,没有一个
肯老实待在一个村界里;学科的反应不是放弃田野,而是把田野的定义
扩容。三条主线记录了这次扩容;按通说综述口径记录,无被引数不虚构
(检索校准 2026-09-07)。

## 一、主线 A:数字/线上田野方法的建制化(数字人类学)(检索校准 2026-09-07)

- **线上田野从"新潮"变"常规"**
  经过米勒-斯莱特(2000)、Boellstorff《第二人生》(2008)、
  Horst-Miller《数字人类学》(2012)二十年的铺垫,近五年数字/
  线上田野已从方法论特例变成**常规装备**:即时通讯群组、游戏
  世界、社交平台、直播与短视频场景都可作为主田野;方法论文献
  讨论的不再是"能不能在线上做田野",而是**在场如何界定、年度
  周期如何折算、知情同意如何在滚动的群组里落地**(检索校准
  2026-09-07:该线已形成方法综述与教材化的建制态势)。
  **为什么重要**:这是马林诺夫斯基标准(00 章)问世百年来的
  第一次系统扩容——"住进村里"变成"住进场景",学科把自己
  最硬的宪法条款重写了。

  **对本家族的含义**(家族内部推演):田野支(84057 第三支)
  的"线上田野"节由方向锚升为正章;实验律三的读法直接对接——
  线上田野的"在场"是**采样分布的选择**(你在哪个场景泡着),
  还原权重(这个场景多典型)成为效度的核心问题;忘了还原,
  平台的戏剧性就会被当成社会的典型性(00 章发现 3 的警示臂)。

- **算法与平台作为新的"仪式装置"**(检索校准 2026-09-07)
  推荐流、审核规则、排行榜被当作**值得民族志化**的社会形式:
  平台如何像仪式一样组织时间与声望(什么算"在场的成功")、
  算法变更如何像节气一样重排社区生活。该线与科学技术侧的平台
  研究共享对象,人类学的差异化在手艺:**把平台的可供性当作
  当地人来学**(检索校准 2026-09-07)。

  **对本家族的含义**:交换支(84057 第二支)的库拉分析拿到
  新工地——虚拟物品的声望循环(游戏装备/数字藏品/粉丝打投)
  是"物循环保声望"的当代变体;00 章实验律一的环式/市场对照
  可直接用作其结构诊断(环式设计 vs 排行榜累积)。

- **方法伦理的数字化重做**(方向锚,检索校准 2026-09-07)
  知情同意、匿名化、回馈义务在线上场景全部要重新发明(群聊里
  谁是"报道人"?截图算不算田野材料?);伦理审查与田野伦理的
  讨论近五年显著增多(检索校准 2026-09-07)——写文化一代的
  "权威之问"(00 章 §一)在数字工地重新开庭。

## 二、主线 B:基础设施与物质文化转向(检索校准 2026-09-07)

- **基础设施成为田野对象**
  数据中心、物流网络、电网、水系、维修工与运维者在近五年成为
  民族志的主角(检索校准 2026-09-07):承接 Star 的基础设施
  民族志纲领("基础设施对使用者透明,对研究者必须是研究对象",
  通说)与物质文化研究的长线,该线问的是:**现代社会的"自然"
  藏在哪些沉默的系统里**——这正是本学科的老问题(把自然还原
  成文化)换到最大号的工地。
  **为什么重要**:基础设施是"背景性"的极致——把背景做成前台,
  是深描方法在当代最漂亮的实战;也为 00 章 §二"整体观 vs
  个体主义"之争提供了新战场(系统与人的关系不再是"结构与
  行动者",而是互相构成)。

  **对本家族的含义**:与考古学的边界在此处贴得最近(方向锚,
  检索校准 2026-09-07):器物与物质序列的**本体**归考古学
  (GB/T 780 未建宇宙,纯文字边界声明),本家族取其**社会关系**
  侧——物如何组织人,而非物如何断代;两家的接口是"物质性"
  这一节(声明见家族 README §〇)。

- **物质性的复权:物的社会生命线**
  "物的方法论地位"近五年被系统重审(检索校准 2026-09-07):
  礼物研究的经典命题(物的流动即人的关系)被推进到标准件、
  数据、废弃物与二手商品——物在流通中累积传记、标记关系、
  制造义务。莫斯的总体现呈在这个意义上被"做了一遍当代版"
  (方向锚,检索校准 2026-09-07)。

## 三、主线 C:多点民族志的当代化与亲属研究的计算转向(检索校准 2026-09-07)

- **多点民族志与世界体系纲领三十年**
  马库斯 1995 年的纲领(跟着人/物/故事/隐喻/冲突走)近五年与
  供应链、平台经济、气候治理、移民路线等议题合流(检索校准
  2026-09-07):一条供应链、一次平台改版、一场气候会议都是
  天然的多点对象。方法论文献的活跃点在**多点的纪律**——怎么
  避免"哪都没待够"(00 章 §二的方法论之争表的当代版)。
  **对本家族的含义**:田野支的"多点"节从纲领升为操作手册;
  与历史学的走廊(档案作为田野)在追踪长链条时叠加使用。

- **亲属研究的数字/计算转向**(方向锚,检索校准 2026-09-07)
  大规模谱系数据、亲属网络的计算分析让亲属制度研究出现形式化
  复兴(方向锚):继嗣网络的度量、通婚圈的测绘与经典问题
  (外婚/联盟/分支)重新接上;联盟理论的最小机器(00 章实验
  律二)正是这条线的教学化身。注意边界:亲属的**意义面**
  (称谓背后的自我理解)仍是民族志的地盘,计算只接客位侧
  (02 章"民族志量"栏的口径之争)。

- **三重义务的当代回声**(方向锚,检索校准 2026-09-07)
  平台打赏、众筹回礼、开源社区的互惠规范,近五年被当作
  "给·受·报"的当代田野(方向锚):互惠的三重义务在数字
  场景的变体(时间差/公开性/算法中介)是交换支的活跃问题。

## 四、主线 D:方向锚——三处接口与时效声明(方向锚)

- **三大古典母题的上游地位**(方向锚,检索校准 2026-09-07):
  亲属制度/礼物(莫斯)/田野民族志传统是三条主线的公共上游——
  线上田野是"田野传统"的扩容,基础设施是"物质性"的深化,
  多点是"比较"的运动化;近五年的文献几乎都以"回到经典再
  离开"的姿势写作(方向锚)。
- **考古学边界声明**(检索校准 2026-09-07):物质文化的本体
  研究归考古学(GB/T 780 未建宇宙);本家族只在"物如何组织

## 五、三条线合成的图景

```
   线上田野方法(主线A)            基础设施与物质性(主线B)
   在场/周期/伦理的重写            背景→前台,物→主角
        │ 方法的扩容                    │ 对象的扩容
        ▼                              ▼
   ┌──────────── 田野的扩容:一个村子 ──▶ 一个世界体系 ────────────┐
   │   平台/群组/游戏里的参与观察      数据中心/供应链/维修工的民族志 │
   └───────────────────────────┬──────────────────────────┘
                               │ 上游纲领:三大古典母题(主线D,方向锚)
                               ▼
              多点民族志当代化+亲属计算转向(主线C)
              跟着人/物/故事走;客位侧接计算,主位侧守民族志
```

**一句话**:三条主线共享同一个结构——**田野的扩容**:方法从
村里搬到场景(主线 A),对象从风俗搬到系统(主线 B),尺度从
单点搬到链条(主线 C);而"住进去、学语言、跟周期"的马氏
纪律未变——**宪法不换,领土换代**。

## 七、给读文献的人:三个判读要点

1. 看到"线上/数字民族志"类研究(主线 A):先问**在场的操作
   定义**——泡了多久?哪个场景?场景的典型性怎么还原?没有
   还原权重的线上田野,就是把平台戏剧性当社会典型性(00 章
   发现 3 的警示臂)。
2. 看到"基础设施/物质性"类研究(主线 B):分清**本体与关系**——
   断代与器物序列归考古学(780,声明),"物如何组织人"归本
   家族;混写的研究两头都站不稳。
3. 看到"多点/跟物走"类研究(主线 C):查**多点的纪律**——
   每个点待了多久?点与点之间靠什么连接(同一个物?同一群人?
   同一个故事?)?"哪都没待够"的批评是否被正面回应。

## ✨ 美之时刻(彩蛋第 4 枚:宪法百年重写)

✨ **美之时刻 4:年度周期在服务器上怎么算**(意外)马林诺夫斯基
的宪法说:跟完一个年度周期才算开张(园圃开垦→收获→库拉远航);
线上田野的年度周期是什么——一次版本的完整迭代?一轮热搜的
四季?一个赛季?近五年方法文献把这些当真问题讨论。为什么美:
**百年前为村里立的法,正在给服务器量刑**——学科最古老的标准
遇上最新的对象,两边都被照得更清楚:周期的本质不是十二个月,
是"社会形式的完整循环"。亲历:给你常泡的一个线上场景写出
它的"年度周期"(什么事件标记它的春耕与秋收)(✍️练习 1)。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:在场之眼**——看到任何数字/多点/基础设施
研究,先问它的**田野在哪、在场的操作定义是什么、典型性怎么
还原**;再问**对象与方法的尺度是否匹配**(一个村子的方法配
一条供应链,还是配一个赛季)。宪法百年未变,胜负全在领土的
划法里。
