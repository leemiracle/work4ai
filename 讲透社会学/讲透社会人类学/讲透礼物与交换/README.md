# 讲透礼物与交换 · 社会的粘合剂——人如何被捆进义务之环

> **定位句**:这支负责三大母题的**粘合剂车间**——礼物不是自愿的,是
> **给、受、报**三重义务的总和(莫斯);库拉不是以物易物,是臂环与贝项
> **双流对开、永不停止**的声望环(马林诺夫斯基);夸富宴不是炫富,是
> **以销毁与散尽定名望**的义务竞赛(鲍阿斯材料);萨林斯互惠三型接上社会距离的标尺。
> GB/T 13745 840 社会学 · 84057 社会人类学 · **自定支 2/3**。家族:[讲透社会人类学](../README.md)

## 诞生

- **谁/何时**:莫斯《礼物》(1925)开山——总体呈献/三重义务/hau(毛利通说
转述);马林诺夫斯基《西太平洋上的航海者》(1922)供库拉实录;鲍阿斯供
夸扣特尔夸富宴材料;萨林斯《石器时代经济学》(1972)立互惠三型;当代:
平台打赏/虚拟物品的数字变体(家族 01 章,检索校准 2026-09-07)。
- **因什么问题**:①没有警察与法院的社会,交换为什么不赖账(约束之问)②
敢拒绝吗、不回礼会怎样(义务之问)③声望为什么随物走不随钱走(名望之问)。

## 核心问题

**已解决(通说)**:三重义务的普遍结构;交换=总体社会事实(宗教/法律/
经济/道德同场);互惠类型与社会距离负相关。**未解决/深水区**:hau 的
跨案例移植(依赖转述链);数字平台上互惠与市场的边界重画;声望经济的
度量口径(家族 02 章)。

## ✨ 这支最美的一个事实

**夸富宴:权力靠销毁来证明**。夸扣特尔首领的最高动作不是囤积,而是把毯子
与独木舟**当众烧掉、扔进海里**——散尽与销毁不是浪费,是把财富转成名望的
炼金术:收不完的礼还不清的债,才是压在对手头上的权力;最富的人是把一切
都给出去的人。**市场说占有即权力,夸富宴说:权力在于让别人欠你——
销毁是让所有人欠你的极限形式**。

## 假设与依赖

- 买入"义务先于自愿":三重义务是结构而非选择;"自由交易"是历史特例
