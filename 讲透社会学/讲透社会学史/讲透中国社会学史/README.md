# 讲透中国社会学史 · 引入、中断、重建——一门学科的生死档案

> **定位句**:这支负责**中国线**——社会学在中国的建制史全程:晚清民初学科引入(译名竞争→首设系科→学会与期刊)→**1952 取消与 1979 重建**(27 年建制断口,全球学科史上绝无仅有)→社会学中国化(吴文藻纲领、费孝通/雷洁琼等的实践)→当代建制化。家族两支中的"建制史极限案例"支。
> GB/T 13745 84011 三级原生支 **8401110 中国社会学史**。家族:[讲透社会学史](../README.md)

## 诞生

- **谁/何时**:引入期——章太炎译岸本能武太《社会学》(1902,"社会学"译名由此通行,通说)与严复译斯宾塞《群学肄言》(1903,"群学"译名竞争落败);1913 沪江大学设中国第一个社会学系(通说);1930 中国社会学社成立;孙本文的教材体系。中国化期——吴文藻 1930s 提出"社会学中国化",主张社区研究;费孝通《江村经济》(1939)、《乡土中国》(1948)。断口与重建——1952 院系调整,社会学建制被取消;1979 重建("赶快补课"同年,中国社会学研究会成立,费孝通任会长,通说);1980"南开班"培训重建一代;1984《社会学概论》试讲本;此后院系·学会·期刊·学位体系全面复建。
- **因什么问题**:①一门外来学科如何在本土落地生根(引入之问)②学科存废如何被社会决定(断口之问)③重建是复原还是再发明(重建之问)。

## 核心问题

**已解决(通说)**:译名史("群学"败于"社会学"——概念入关的实录);建制断口的通说编年(1952/1979/1980);中国化纲领谱系(吴文藻倡导→费孝通社区研究实践)。

**未解决/深水区**:断层史整理(1952-1979 的人才转行、文献散佚、口述抢救);早期院系档案(教会大学/民国大学)的系统发掘;"中国化"的谱系重估(方法论纲领、学术自主宣言,还是分期标签)。

## ✨ 这支最美的一个事实

**1952-1979:建制史上最硬的"自然实验"**。一门学科被建制性移除 27 年,又在 1979 年被宣布"需要赶快补课"——学科的存在与否,不由学科内部的理论优劣决定,而由社会对"它是否被需要"的判定决定;这正是"学科是社会的对象"的极端证明。重建一代(费孝通/雷洁琼等)接续的不是自动延续的传统,而是需要重新发明的传统——重建≠复原。

## 假设与依赖

- 通说编年依赖:首系年份(1913,教会大学口径)等按学术文献通说,争议随注
- 断层史料稀缺:断口期的档案与记忆抢救先于评价——史料优先纪律
- 红线:涉现当代中国学科建制与政策的史实,一律按文献通说转述为建制史事实,不作规范性评价

## 教材锚

- 费孝通《乡土中国》(1948)、《江村经济》(1939)、《师承·补课·治学》(重建期自述)
- 阎明《中国社会学史:一门学科与一个时代》(2004,学科史专书,通说)
- 《社会学概论》试讲本(1984,重建初期标志性教材)
