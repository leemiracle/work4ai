# 讲透外国社会学史 · 造词、立教、制度化、重写——正典线的全过程

> **定位句**:这支负责**外国线**——社会学的正典编年全程:孔德 1838 造词→斯宾塞/马克思→涂尔干《自杀论》1897 与韦伯、齐美尔(欧洲立教)→芝加哥学派与帕森斯(美国建制与综合)→默顿/米尔斯→布迪厄/吉登斯/哈贝马斯/卢曼(理论爆炸)→后殖民与全球转向(正典重写)。内部分三段:古典(1838-1920s)/美国世纪(1915-1960s)/当代(1970s-今)。
> GB/T 13745 84011 三级原生支 **8401120 外国社会学史**。家族:[讲透社会学史](../README.md)

## 诞生

- **谁/何时**:孔德造词 sociologie(1838,通说;刊行 1839 两说并存)与实证纲领;斯宾塞社会有机体论;马克思《资本论》(1867,社会学身份系后人追认)。欧洲立教——涂尔干《社会学方法的规则》(1895,社会事实)《自杀论》(1897,首个定量社会研究)与《社会学年鉴》(1898);韦伯《新教伦理》(1904-05,理解社会学)《经济与社会》(1922,身后);齐美尔形式社会学。美国建制——芝加哥第一个社会学系(1892)与人文生态学;帕森斯《社会行动的结构》(1937)《社会系统》(1951);默顿中层理论与马太效应(1968);米尔斯《社会学的想象力》(1959)。当代——布迪厄场域论/吉登斯结构化/哈贝马斯交往行为/卢曼自创生;赛义德《东方学》(1978)之后,后殖民与全球转向重写正典。
- **因什么问题**:①一门学科如何从口号变成建制(学科化之问)②经典名单如何被固化与重写(正典之问)③方法论之争为何百年不分胜负(双路线之问)。

## 核心问题

**已解决(通说)**:编年正典(造词→立教→建制→理论爆炸,家族 00 章全图);两大方法论路线的定位(实证·涂尔干系 vs 理解·韦伯系)各自的传承与工具;正典化机制(马太效应·默顿 1968→累积优势·普赖斯 1976→可跑模型·家族实验)。

**未解决/深水区**:正典凭什么——学术价值沉淀还是引用网络固化(机制证据无法裁决价值);全球转向重写正典的边界(多中心环流史与学科认同的张力);帕森斯式"综合"的再发明系数(翻译-误读史的系统考据)。

## ✨ 这支最美的一个事实

**帕森斯的翻译工程:一个人发明了"古典"**。1937 年,帕森斯把韦伯/涂尔干/帕累托译介进英语世界并综合成自己的行动理论——此后半个世纪英语世界"读韦伯必经帕森斯",今天所说的"古典六大家"很大程度是这次翻译+综合操作的产品。它示范了"综合"与"再发明"的距离只有一步:学科史的每一次综合都是一次创造性误读,而误读本身成为后续历史的起点。

## 假设与依赖

- 正典名单的欧美中心:全球转向批判的靶子(家族 01 章主线 B)——用正典讲正典史,必须同时拆正典
- 断代依赖:古典/美国世纪/当代三分是教学施工,不是历史必然(断代即论断)
- 译本依赖:多数读者经英译/转述接触原典——语境引擎(反现在主义)是必需的纪律而非装饰
