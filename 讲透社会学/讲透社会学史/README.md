## 一、家族定位(它是什么,不是什么)

- **是**:**学科的建制史**为主轴——一门"对象是自己"的学科史:系科/学会/
  期刊如何建成、中断、重建(中国线),经典如何被引用网络与教科书
  固化成**正典**(外国线);编年(1838 孔德造词→当代全球转向)是它
  的骨架,建制化与正典化是它的追问。
- **不是**:名人轶事集,不是"过时理论回收站",也不是社会思想史
  (思想内容谱系归 8401420,见 §〇两"史"分工)——它的招牌问题是:
  **这门学科凭什么这样记住自己:谁建制了它,谁写进了它,谁被忘记?**
- **工具性格**:给整个 840 宇宙提供"历史地基"——理论家族讲每个 -ism 时,
  本家族回答这个 -ism 是在哪场论战里、被谁的引用网络放大的。
