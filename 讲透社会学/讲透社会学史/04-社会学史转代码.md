# 04 · 社会学史转代码:把学科记忆搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:社会学史的编年轴端(03 章谱系左端)几乎可以无损
> 转码,语境端几乎不可转码;四条代码走廊——**编年轴入库**、
> **学派谱系遍历**、**概念旅行状态机**、**正典形成模拟**——把
> "学科怎么记住自己"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",社会学史转代码要解决"**档案化**":
把一段学科史叙述(教科书为什么讲这六个人)先翻成数据结构(事件卡/
谱系图/概念状态/引用网络),再翻成代码。翻译的损耗全部发生在
第一步——所以本章先划清哪些对象第一步就走得通(绿色区),哪些
走不通(红色区),再给四条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 学科史概念 | 代码化身 | 备注 |
|------------|---------|------|
| 编年轴 | 事件卡 schema + 排序/分组查询 | 03 章卡 1 的机器形态;断代分组字段=可切换的视角 |
| 学派谱系 | 邻接表(节点+带类型的边)+ 图遍历 | 论战边/师承边/翻译边分色;找"论战核"=找图的对偶结构 |
| 概念旅行 | 概念×时点×语义状态机 | 03 章卡 3 的机器形态;每站一个语义快照 |
| 正典形成 | 普赖斯优先连接网络模拟 | 家族实验本体:Π(k)∝k+c,三律可断言 |
| 正典审计 | 名单分布统计(国籍/语言/性别) | 01 章主线 B 的测量引擎 |
| 教材覆盖率 | 大纲数据→经典排序/配对矩阵 | 量化"谁在每本教材里" |
| 断代实验 | era 字段重分组的视图切换 | "断代即论断"的可交互版 |

**转不动/转不动的边界(红色区)**:

1. **语境解释**:文本在论战语言中的本义没有状态方程——硬造"语境
   参数"只会得到自己假设回去的结论。工程对策:语境引擎做成
   **可检查的纪律**(反现在主义的车检),不做仿真变量。
2. **影响认定**:"X 影响了 Y"是解释学问题(读过≠受影响);
   引文共现可以造"影响嫌疑名单",定罪要人读档案。
3. **正典评价**:模型解释份额,不解释伟大;用模拟裁决"谁该进
   正典"是把机制证据当价值判决用(00 章发现 1 的红线)。
4. **断代的合法性**:代码能瞬间重画断代线(视图切换),画哪条线
   的**理由**永远在代码外面。

**边界的一句话**:绿色区=可档案化的记忆组织(年表/谱系/概念/
引用),恰好覆盖"学科怎么记住";红色区=理解与评价,恰好是
"记住的东西什么意思"。**转码让记忆可审计,不让意义可计算。**

## 二、代码走廊清单(四条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:编年轴走廊(事件库全机械化)

```
事件卡 schema ──装载──▶ 事件库 ──查询──▶ 时间线/断代视图/ contested 计数
      │
      └──视图切换:era 字段重分组 ──▶ "断代即论断"的交互实验
```

- **理论→模型**:03 章卡 1 的 9 字段 schema;争议两说并存为多卡
  (1838 造词卡与 1839 刊行卡同时在场,`contested` 标志计数)。
- **算法层**:按 year 排序是平凡的;有价值的是**分组透视**——按
  era/school_tag/place 切片,数"每断代的事件密度";把 era 改三个
  版本重切,看同一批事件讲出几部不同的学科史。
- **真实系统**:学术史数据库、数字人文时间线项目、教材附录的
  机器可读版。
- **性能工程要点**:事件库是典型的小数据重查询——索引按
  (year, kind) 建,冷热分离没必要;真正的工程量在**录入的源纪律**
  (每卡必须有 source 字段,两说必须双卡)。

### 走廊 2:学派谱系走廊(带类型边的图遍历)

```
人物/机构/期刊 ──建节点──▶ 图 ──边分型──▶ {师承, 论战, 翻译, 流亡, 编纂}
      │
      └──遍历──▶ 师承链(B 是 A 的几世传人)/ 论战核(最大论战团)/ 断代画像
```

- **理论→模型**:03 章卡 2;论战边是招牌——学科史的骨架查一跳
  "谁跟谁吵"就有。
- **算法层**:师承链=有向路径查询;**论战核**=仅保留论战边后的
  连通分量(涂尔干-韦伯对、帕森斯-米尔斯对应各自成核);翻译边
  的重数(韦伯→英语世界有几次翻译浪)可数。
- **真实系统**:学术谱系项目(如数学谱系计划式的师生库)、思想史
  知识图谱。
- **性能工程要点**:边类型必须一等公民(别混在备注里);图的写入
  是人工密集型——审核流(每条边配 source)比遍历算法重要一百倍。

### 走廊 3:概念旅行走廊(语义状态机)

```
概念 ──时点序列──▶ {t1:出生义@文本A, t2:改宗义@文本B, t3:海关@媒体C, ...}
      │
      └──状态机查询──▶ 任一时点的"通行义"/ 漂移轨迹 / 回流检测
```

- **理论→模型**:03 章卡 3;每个时点存一次语义快照+原文样例,
  转移即"改宗事件"。
- **算法层**:漂移轨迹=(快照序列的语义距离)——语义距离的度量
  是软肋(词向量可用但带bias),最稳的机器形态是**人工编码+
  时间线可视化**;回流检测=日常语料频率的突变点。
- **真实系统**:概念史数据库(科塞雷克传统的数字化)、术语史
  词典的动态版。
- **性能工程要点**:编码靠人,机器管一致性与可追溯——每个语义
  快照必须挂原文坐标(文本/页码),否则状态机退化成语义学感想。

### 走廊 4:正典形成走廊(普赖斯优先连接——本家族招牌)

```
累积优势理论(普赖斯 1976) ──参数化──▶ Π(k) ∝ k + c 的引用网络生长
      │
      ├──对照──▶ 优先 vs 均匀:最早 10% 份额 0.756 vs 0.333(律一:两层固化)
      ├──拨 c ──▶ 0/1/2/8:最新 20% 份额 0→0.0044→0.0086→0.0134,
      │           零被引 396→220→177→110(律二:可见度的制度参数)
      └──年龄──▶ 同一种子 n/2→n:基尼 0.884→0.896(律三:内生不平等)
```

- **理论→模型**:文献逐篇加入,每篇 m 条引用;两个旋钮——连接规则
  (优先/均匀)与偏好附加 c;两个读数——份额与集中度。
- **算法层**:加权抽样 O(t)/条 → 全网 O(m·n²);n=400 秒级;
  快照在生长中拍(不是事后切片——本家族实验开发时的真实教训:
  事后切片会把 t=n 的头部误报成 t=n/2 的状态)。
- **真实系统**:引文数据库的机制审计、新领域(新期刊/新会议)的
  可见度设计、教材大纲的正典固化监测。
- **性能工程要点**:这是最便宜的社会学实验台——两个标量参数、
  一条加权抽样;关键是**把制度语言钉到参数**(检索系统=给 c 垫底,
  教学大纲=每年代一批新引用,经典重印=m 的老文献获得新边)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:知识图谱 schema——学术史数据管道

- 任何"领域史"项目(某技术的思想来源/某团队的学术谱系)的核心
  不是数据大而是**结构对**:节点(人·文本·机构)+带类型的边
  (师承/论战/翻译/编纂)。schema 先过 03 章三张卡的字段纪律;
  source 字段不可空,争议双卡并存——没有这两条,图谱是传话器。

### 落点 2:正典监控面板——别只看总数

- 给任何"领域必读清单"配两个指标层:**份额层**(被引/被收录
  分布的 top10% 与基尼)+**结构层**(清单的国籍/语言/年代分布)。
  只有第一层的面板会把"资历优势+累积优势"误报为"经典不可替代"
  (律一的教训);只有第二层的面板会把审计当裁决(01 章 §七判读 2)。

### 落点 3:新领域的可见度设计——c 的工程化

- 建新社区/新期刊/新标签系统时,你正在设 c:默认排序按累计热度
  (c→0)还是按时间衰减+新人加权(c 大)?律二给出设计语义:
  c=0 的世界不是中性,是封死——新文献零份额(第一引用问题);
  但 c 过大→均匀世界,资历信号也丢。先定"多想让后来者被看见",
  再定排序参数。

### 落点 4:引文数据的偏差纪律

- 引文数据库有国籍(语言/期刊/年份覆盖的系统性偏向):用单一库
  做"全球"审计,测到的一部分是数据库自己的出身(01 章 §七判读 3)。
  工程对策:多库交叉+覆盖率声明+分语言分层;任何"高被引"结论
  附数据源画像,像代码标注依赖版本一样自然。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:参数之眼**——看到任何"经典排行榜/必读清单/
热榜",先问三个参数:连接规则是什么(优先还是均匀)?c 是多少
(后来者的垫底可见度)?网络几岁了(集中度到了哪一段)?再看到
任何"领域史"数据库,先问它的边分型了吗、source 字段在吗、
争议双卡了吗。转码让这些追问从修辞变成可跑的断言。
