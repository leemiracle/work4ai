# 04 · 社会地理学转代码:把空间透镜搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程
> 视角贯穿)。
>
> **本章一句话**:社会地理学的设计端(03 章三张卡)几乎可以无损
> 转码,刀口端(单元/W/λ 的"正确"选择)与意义端(场所感)几乎
> 不可转码;三条代码走廊——**格局走廊**(I+置换检验的隔离签名)、
> **暴露走廊**(距离衰减的剂量扫描)、**层级走廊**(Gibrat→齐普夫
> 的涌现模拟)——把"开工文件"变成可跑、可断言、可做参数扫描的
> 实验,最实用的出口是一份**选址与暴露审计**。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",社会地理学转代码要解决"**刀口的
参数化**":把一段空间语言("这个城市很隔离/这个选址方便")先翻
成参数与统计量(单元/W/I/λ/剂量),再翻成代码。翻译的损耗全部
发生在第一步——所以本章先划清哪些对象第一步就走得通(绿色区),
哪些走不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 空间概念 | 代码化身 | 备注 |
|----------|---------|------|
| 空间自相关 | Moran's I 闭式+1000 次置换检验 | 实验幕一;隔离的签名仪 |
| 邻域权重矩阵 W | 邻接/阈值/衰减三种生成器 | W 可枚举可存档(03 章卡 2) |
| 距离衰减暴露 | w(d)=1/(1+d/λ) 剂量+λ 扫描 | 实验幕二;选址审计的核心 |
| 邻里效应剂量-距离 | 收益(λ) 曲线+半效应尺度 λ* | 幕二断言;邻里干预的辐射圈设计 |
| 城市层级 | 位序-规模回归(log-log 斜率)+拟合优度 | 幕三断言;斜率≈−1 的体检表 |
| Gibrat 机制 | 比例增长迭代生成器(等规模起步) | 幕三;层级涌现的 30 行复现 |
| 可达性 | A_i=Σ机会×w(d_ij);阶梯/衰减双算法 | 走廊 4(轻);"15 分钟"验收仪 |
| 职住与通勤 | OD 矩阵+阻抗函数的 ETL | schema 见走廊 3 的姊妹件 |
| 痕迹地理管道 | 位置数据 schema+去标识+快照包 | 落点 4;伦理红线硬编码 |

**转不动/转不动的边界(红色区)**:

1. **单元的"正确"刀口**:MAUP 没有唯一解——代码能跑多刀口
   并报,不能替你选真刀口;把"网格扫描里最显著的那格"当结论,
   是刀口 hacking 的自动化版。
2. **场所感与地方意义**:可达性指数测不到"这是我的街区";
   硬造"场所感评分"只会把意义压扁成问卷分。工程对策:意义层
   用深描接口(人工研究进报告),代码只管功能层。
3. **选择效应的彻底识别**:工具变量与随机搬迁是研究设计,不是
   算法;代码只能做敏感性扫描(Oaxaca 式分解的空间版),不能
   生成外生性。
4. **衰减函数族的选择**:双曲/指数/阶梯互不包容,选择靠理论与
   经验——代码只能让"换函数族,结论翻不翻"变得廉价(敏感性
   扫描自动化)。

**边界的一句话**:绿色区=03 章三张卡的字段与预算,恰好覆盖
"开工文件"的可计算部分;刀口的可审计性(多刀口并报/λ 扫描/
函数族对比)可以**记录**进代码,不能**产生**于代码。

## 二、代码走廊清单(三条主走廊+一条轻走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:格局走廊(隔离签名仪——本家族招牌)

```
托布勒第一定律 ──参数化──▶ W(邻接/阈值/衰减)──▶ I=(n/S₀)·Σw·zᵢzⱼ/Σzᵢ²
      │
      ├──置换检验 ─▶ 打乱 1000 次→零分布→p 值 ──▶ 签名判定
      └──拨 W ────▶ 刀口敏感性(同一格局,I 随 W 动)──▶ MAUP 审计
```

- **理论→模型**:两个参数轴——单元粒度与 W 的定义;两分类
  (各 50%)下 I 的两副面孔(同配生成 vs 随机散布)是教学最小例。
- **算法层**:闭式 I+随机置换零分布(家族实验幕一的 assert 就是
  验收标准:I>0.6、p<0.01、随机臂 |I|<0.05)。置换检验对两分类
  用打乱标签(超几何等价),对连续值用打乱残差,均为 O(reps×n)。
- **本家族实现**:[`experiments/space_and_city.py`](experiments/space_and_city.py)
  幕一。
- **真实系统**:城市隔离的年度监测仪表(多样性指数+I 并报)、
  平台内容/舆论的地理聚集审计、选址前后的邻里构成变化追踪。
- **性能工程要点**:W 是稀疏的(每单元邻居数≈常数),用邻接表
  不用满矩阵——满矩阵在 10⁴ 单元就爆内存,稀疏版可到 10⁶;
  置换检验按 seed=base+rep 号分流,保证可复现;I 的分子只与
  (wᵢⱼ, zᵢzⱼ) 对有关,增量更新可把多刀口扫描摊薄。

### 走廊 2:暴露走廊(剂量-距离扫描器)

```
Hägerstrand 约束 + 距离衰减 ──参数化──▶ w(d)=1/(1+d/λ)
      │
      ├──拨 λ ──▶ 剂量/收益曲线+半效应尺度 λ* ──▶ 邻里辐射圈设计
      └──换函数族 ─▶ 双曲 vs 指数 vs 阶梯的敏感性 ──▶ 审计报告
```

- **理论→模型**:个体结果=基线+β×加权邻里均值+噪声;λ 是唯一
  扫描轴(实验幕二),半效应尺度 λ* 是曲线特征数。
- **算法层**:O(个体×邻居) 的加权求和;断言:收益随 λ 单调升、
  边际递减、λ* 落在扫描区间内。
- **本家族实现**:同实验幕二。
- **真实系统**:公共服务设施选址的暴露审计(新设施对各社区的
  剂量增量)、"15 分钟城市"的验收仪表(阶梯与衰减双算法并报,
  03 章卡 3)、邻里干预项目的辐射圈预算(半径是设计参数)。
- **性能工程要点**:剂量求和可用空间索引(网格桶/k-d 树)把
  O(n²) 配对降到 O(n·k);λ 扫描共享距离计算(先算 d_ij 再套
  不同 λ),别在循环里重算距离——这是空间代码最常见的十倍浪费。

### 走廊 3:层级走廊(Gibrat→齐普夫模拟器)

```
Gibrat 比例增长 ──参数化──▶ S_{t+1}=S_t×(1+g_t), g_t~对数正态(与 S 无关)
      │
      ├──等规模起步+500 期 ──▶ rank-size 的 log-log 回归 ──▶ 斜率≈−1
      └──方差→0 对照 ─────▶ 全部城市同规模(层级的死亡开关)
```

- **理论→模型**:100 城、等规模、500 期;增长率与规模独立是
  Gibrat 的全部内容(反射壁用 max(S, ε) 近似,通说处理)。
- **算法层**:O(城数×期数) 迭代+O(n log n) 排序+两行回归
  (log 规模对 log 位序);断言:斜率∈[−1.15,−0.85] 且对照臂
  规模离散度≈0。
- **本家族实现**:同实验幕三。
- **真实系统**:城市/平台城市群/商圈层级的健康监测(偏离 −1
  的斜率才是待解释对象)、模拟规划政策的长期层级后果(机制沙盘)、
  教学演示(统计必然 vs 设计产物)。
- **性能工程要点**:比例增长迭代注意浮点下溢(取 log 空间计算
  更稳:log S 累加 g);回归用闭式最小二乘,不必引库。

### 走廊 4(轻):可达性计算器(15 分钟验收仪)

```
卡 3 字段直通 ──▶ A_i = Σ_j 机会_j × w(d_ij)
      ├──阶梯式 w=1[t≤15min] ──▶ 口径口径的政策达标率
      └──衰减式 w=1/(1+t/λ)  ──▶ 审计口径的连续得分——两者并报
```

- 教学用 40 行标准库可实现(距离表+两行汇总);不另设实验
  (留作 ✍️练习 3),但它在真实规划 pipeline 里是**双口径验收**
  的标配(03 章卡 3 的构造规则)。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:隔离/聚集的年度仪表——别只报比例

- 任何带地理维度的产品与政策评估(内容分布/门店覆盖/用户构成),
  汇报"各区比例"之外加一列 I 与置换 p 值:比例是多样性,格局
  是隔离——**两个都混合的城市可以处处纯粹**(00 章 §六发现 1)。
  仪表常年跑,刀口两套(两种 W),结论只认刀口间稳健的。

### 落点 2:选址与暴露审计——把"方便"写成合同

- 新设施/新功能上线前跑走廊 2:对各人群分层算剂量增量,报
  半效应半径与最不受益人群。**"平均可达性提高 X%"而弱势人群
  全垫底的方案,均值是帮凶**(03 章卡 3 暗礁)——分层报告是
  设计要求不是排版偏好。

### 落点 3:层级健康监测——盯斜率,别盯冠军

- 平台生态(城市群的机构分布/商圈的店型分布/创作者生态)监测
  位序-规模斜率而非只看头部:斜率长期稳定=比例增长在起作用
  (背景);斜率突变=机制被扰动(平台规则/政策/技术冲击)——
  **该解释的是突变的时点,不是层级的存在**(实验幕三)。

### 落点 4:痕迹地理的复现与伦理——空间数据是最敏感的

- 位置数据的采集包:快照存档、API 版本、聚合阈值(k-匿名式
  最小单元)、再识别风险评估记录。**轨迹的再识别能力随长度
  指数上升**(01 章主线 B)——伦理红线在 schema 层硬编码
  (最小聚合单元、禁入字段),不靠分析时的自觉。

选址很方便/层级在演化),先问三个数:I 与 p 值(格局)、λ 与剂量
(半径)、斜率与突点(层级);看到任何位置数据,先查它的聚合
阈值与快照(伦理)。转码让这些追问从修辞变成可跑的断言。
