# 讲透城市空间结构 · 格局的解剖学——人怎么排布成地方

> **定位句**:这支负责"格局层"——**同心环/扇形/多核心**(城市横截面的三大经典模型)、**通勤与职住**(日常流动把结构织成网络)、**空间错配**(就业地与居住地的制度性脱节)、**城市层级**(齐普夫位序-规模与 Gibrat 机制);它管"格局怎么长出来",与邻里支互为因果的两面(格局塑造人,人造格局)。
> GB/T 13745 84034 社会地理学 · **自定补充支**(无三级明细)· 家族:[讲透社会地理学](../README.md)

## 诞生

- **谁/何时**:Park-Burgess 同心环(1925,《城市》);Hoyt 扇形论(1939,租金梯度的方向性);Harris-Ullman 多核心论(1945,通说);Kain 空间错配假说(1968,就业郊迁×居住隔离);Hägerstrand 时间地理学(1970,通勤作为约束几何);Zipf 位序-规模律(1949);Gabaix 1999(QJE,齐普夫的 Gibrat 机制证明)。
- **因什么问题**:①城市内部为什么分化成圈层与扇面,而不是均匀浆糊(结构之问)②日常流动把分散的人织成什么网络(流动之问)③城市体系为什么稳定地分层、大城小城各安其位(层级之问)。

## 核心问题

- **已解决(通说)**:三大模型作为待检验假说的教科书地位;错配假说的多城验证(就业可达与就业结果的关联);Gibrat→Zipf 的数学机制(反射壁比例增长→稳态幂律)。
- **未解决/深水区**:三大模型在同一城市数据上怎么判优劣(至今没有公认裁判);远程工作对职住与层级的再平衡(活的争论,01 章主线E);圈层叙事与多核现实在中国城市的张力(方向锚)。

## ✨ 这支最美的一个事实

**Gibrat→Zipf——层级是统计必然**:100 个同规模城市、500 期"增长率与规模无关"的对数正态比例增长,自己长出 log-log 线性、斜率≈−1 的位序-规模分布(家族实验幕三实测 −1.029);而等速无差异的对照臂全部城市几乎同规模。**城市层级不需要设计师**——正确的提问不是"大城市为什么大",而是"哪里偏离了 −1 直线、比例增长在那里被什么破坏"。

## 假设与依赖

- 经典模型合同:假设城市横截面可用单一主导结构概括;代价:现实城市常多结构叠加,模型是假说不是定律(家族[02 章](../02-语言特征.md)"圈层"词条的合同)
- 错配三把刀合同:假设就业地/居住地/阻抗三者同时定义才成立;代价:只报通勤时长是把三维问题压成一维
- Zipf 合同:假设比例增长+反射壁成立;代价:截断的城市清单(行政市≠功能区)会扭斜率——单元之刀(家族[03 章](../03-可构造与结构.md))
- 经济区位与集聚的骨架按 79019/84034 双归属归经济学宇宙侧重(家族 README §〇声明);涌现机制与复杂系统宇宙互链
