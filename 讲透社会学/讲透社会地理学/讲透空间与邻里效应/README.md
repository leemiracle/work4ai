# 讲透空间与邻里效应 · 暴露的科学——地方怎么改变人,人怎么错认地方

> **定位句**:这支负责"机制层"——**邻里效应**(住址对个体结果的净影响)、**空间同配**(谁与谁比邻的生成)、**隔离的空间签名**(Moran's I 把"很隔离"变成统计量)、**选择效应之辨**(人是被地方塑造,还是自选了地方);它是全家族因果问题最重、识别战争最激烈的一支(00 章 §四第二争的主战场)。
> GB/T 13745 84034 社会地理学 · **自定补充支**(无三级明细)· 家族:[讲透社会地理学](../README.md)

## 诞生

- **谁/何时**:涂尔干自杀率的空间差异(1897,证据原型);芝加哥学派聚居区研究(1920s-30s);Shaw-McKay 少年犯罪同心分布(1942,邻里效应的经验起点);Wilson《真正的弱势者》(1987)《当工作消失时》(1996,机制复兴);Sampson 集体效能(2012,纵向操作化);Schelling 隔离模型(1971,微偏好→宏隔离);搬家人群试验(2011-,随机化入场)。
- **因什么问题**:①"好街区的人更好"是地方塑人还是人选地方(识别之问)②隔离怎样从无害偏好中生成(涌现之问)③邻里影响走什么通道、有多大的半径与时间窗(机制之问)。

## 核心问题

- **已解决(通说)**:隔离可检验(Moran's I+置换检验);集体效能作为可测构念;选择效应的随机化拆解在原则上成立(试验设计)。
- **未解决/深水区**:效应量的收敛(试验图景:儿童期强、成人端经济指标弱,方向锚);剂量-距离函数的形状(λ 多大、多久起效、哪个通道主导);试验的外推边界(Volunteers 与搬迁扰动)。

## ✨ 这支最美的一个事实

**同配的涌现——没有恶意的隔离**:Schelling 表明,即使每个人都容忍异类邻居(只要同类不少于三分之一),微弱的同类偏好加上搬迁,足以让城市走向完全隔离;而 Moran's I 给这个涌现物发签名(家族实验幕一:同配生成 I=0.903,随机散布 −0.016)。**宏观的隔离不需要微观的恶意**——它需要的只是偏好+流动性+空间。

## 假设与依赖

- 观察研究合同:假设住址外生;代价:选择效应全面污染——识别策略不明不可当因果读
- 试验合同:假设随机化分掉选择、搬迁≈暴露改变;代价:搬迁本身的扰动、Volunteers 效应、长期随访成本
- 邻域操作化合同:假设邻域定义(行政/感知/功能)抓住有效暴露;代价:三源不重合,效应对刀口敏感(家族[03 章](../03-可构造与结构.md)卡 2)
- 测量与抽样军规链[../../讲透社会学方法/README.md](../../讲透社会学方法/README.md)(同宇宙已收口家族,互链);涌现的数理本体住复杂系统宇宙
