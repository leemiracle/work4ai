## 开篇:老学科的两条换血管

社会地理学的经典问题清单五十年没变(隔离怎么测、邻里怎么起作用、
城市为什么分层),但近五年它的**证据来源**与**数据来源**同时在
换血:一边是因果推断的实验化——搬家人群试验从单一美国的准实验
长成跨国证据线;一边是数据的痕迹化——手机信令、社媒地理标签、
地图 API 让"人在哪里"不经询问就被记录。换血带来新答案,也带来
新账单(伦理与代表性)。五条主线记录这场双换血。

## 一、主线 A:邻里效应的实验证据线——搬家试验的收敛

- **搬家人群试验的证据积累**(方向锚,检索校准 2026-09-07):
  以租房券随机搬迁为核心设计的系列研究(Movers 类试验,Ludwig
  et al. 一线)在近五年进入**结果复核与机制拆解期**——跨试验的
  图景是:童年期搬迁到低贫困街区的长期教育与收入收益方向一致,
  成人端的经济指标收益有限而心理健康指标出现信号(方向锚,细节
  以原始文献为准)。
- **剂量-距离的机制研究**(方向锚,检索校准 2026-09-07):试验
  之后的追问从"有没有效应"转向"效应的函数形状"——暴露强度、
  持续时长、作用半径与敏感时间窗成为新的参数化议程;这恰好是
  家族实验幕二的领域(收益随 λ 上升但边际递减,存在半效应尺度)。
- **为什么重要**:观察时代的邻里研究被选择效应污染(00 章 §四
  第二争);试验线是这门学科第一次拿到**不依赖"住址外生"假设**
  的证据。效应量比倡导者希望的小、比怀疑者声称的明确——这个
  "中间判决"本身就是近五年最重要的科学产出(检索校准
  2026-09-07)。

  **对本家族的含义**:邻里支的宪法以试验证据为界碑——教学上
  先讲 Wilson 式机制故事、再讲试验判决,让学生体会"机制漂亮
  ≠效应量大"的证据纪律。

## 二、主线 B:数字痕迹地理与数据伦理的同步账单

- **数字痕迹作为空间数据主矿脉**(方向锚,检索校准 2026-09-07):
  手机信令、社媒地理标签、轨迹类数据在近五年成为活动空间、
  隔离动态、通勤圈研究的主流来源——痕迹数据"不问而知"的测量
  特性(读到的行为而非报告的态度)与空间研究天然亲和。
- **地理数据伦理成为一级议题**(方向锚,检索校准 2026-09-07):
  位置数据的**再识别风险**(稀疏轨迹几乎唯一确定个人)、平台
  代表性偏差、疫情期位置数据公共健康与监控的双重用途,是这波
  矿脉开发的三大债务;伦理框架与知情同意边界的讨论在方法文献
  里持续升温(检索校准 2026-09-07)。
- **代表性军规的空间版**(方向锚):平台人群≠总体在空间上加了
  一层——城市核心过采样、老年与农村人群欠表示;"数字痕迹的
  抽样框问题"与[../讲透社会学方法/README.md](../讲透社会学方法/README.md)
  的覆盖误差军规同构。

  **对本家族的含义**:数字地理支以"矿脉+账单"双栏教学——每个
  痕迹数据的用法旁边必须写它的再识别风险与代表性缺口,这是
  00 章 §五合同表的数字版。

## 三、主线 C:CSS 空间思维进入社会研究——演绎的回归

- **Akbaritabar et al. 2024(EPJ Data Science)**:计算社会科学中
  的**空间思维与演绎理论驱动**(检索校准 2026-09-07)——主张
  CSS 研究应显式引入社会过程的**空间与关系结构**,并以演绎的
  理论驱动对抗"先有数据再找问题"的归纳漂移。**为什么重要**:
  这是给社会地理学在新方法共同体里发的**合格证条款**——空间
  结构不是控制变量,是社会过程的本体;对本家族,它意味着
  "空间思维"从地理学的家传手艺变成全社会科学的必修件
  (检索校准 2026-09-07)。
- **空间社会学与邻里效应的议程交汇**(方向锚,检索校准
  2026-09-07):社会学阵营的空间转向与地理学阵营的社会理论化
  在近五年互相对接——"空间性"作为社会分层、文化与政治过程的
  构成维度(而非背景)进入主流社会学期刊的议程(方向锚,细节
  以原文为准)。

  **对本家族的含义**:家族的宪法身份由此定调——本家族是社会学
  宇宙(840)的空间透镜,不是地理学的边警;空间思维进 CSS 的
  通道(EPJ Data Science 2024)是本家族与计算社会科学家族共享的
  前沿接口(该家族住[../讲透社会学方法/README.md](../讲透社会学方法/README.md)
  体系内,文字提及)。

## 四、主线 D:经济社会地理的归入声明落地(双归属的执行)

- **79019/84034 双归属的当代执行**(方向锚,检索校准 2026-09-07):
  经济地理/人口地理地带在 GB/T 中跨表双归属(宇宙 README §二);
  近五年经验研究的实际分工印证了这条声明的必要性——经济区位、
  产业集聚、空间经济学的论文流主要在经济学/区域科学共同体
  (79019 侧重),而聚居隔离、邻里与迁移的社会后果、活动空间的
  社会分层在社会科学地理共同体(84034 侧重)(方向锚,检索校准
  2026-09-07)。
- **对本家族的含义**:教材锚与检索都以声明划界——本家族引用
  经济地理文献时,收其"社会过程的空间性"侧面,区位论的经济
  骨架注明归属经济学宇宙(README §〇)。

## 五、主线 E:城市层级的再检验与远程工作冲击(方向锚)

- **齐普夫律的持续复核**(方向锚,检索校准 2026-09-07):位序-
  规模分布的跨国再检验与 Gibrat 机制的微观验证(增长率方差与
  城市规模脱钩吗)持续产出;家族实验幕三就是这个机制的 30 行
  复现(100 城 500 期对数正态比例增长→斜率≈−1)。
- **远程工作与"距离之死"的重开庭**(方向锚,检索校准
  2026-09-07):2020s 的远程工作潮让 1997 年的论靶(凯恩克罗斯)
  重新开庭——核心城市的净效应、职住半径的重构、超级明星城市
  的再集中与分散并存,是活的争论(方向锚;证据仍在积累,
  判决未下)。
- **时效声明**:本主线为方向性综述,细节以原始文献为准。

## 六、五条线合成的图景

```

          │ 因果升级                        │ 数据换血
          ▼                                ▼
   ┌────────── 社会地理学:老问题的新法庭 ──────────┐
   │   ▲ 合格证条款(主线C:CSS 空间思维,EPJ 2024) │
   │   归入边界执行(主线D:79019/84034 双归属)      │
   └──────────────────┬──────────────────────────┘
                      │ 层级与距离的再检验
                      ▼

```

**一句话**:近五年的增量不是"又多了几篇空间论文",而是**老问题
的法庭换了一遍**——隔离与邻里在实验证据上重判,城市层级在
Gibrat 机制上复核,距离之死在远程工作冲击下重审;而所有新证据
共享一张账单:痕迹数据的伦理与代表性。

## 八、给读文献的人:三个判读要点

1. 看到邻里效应论文:先查它的**识别策略**——是观察数据(选择
   效应未除,00 章 §四)、自然实验还是随机搬迁?证据等级决定
   效应量能信几成。
2. 看到数字痕迹的空间研究:先查**伦理与代表性两栏**——再识别
   风险怎么处理的?平台人群与总体的差在哪(主线 B)?两栏空白
   的痕迹研究按 00 章 §五合同表审。
3. 看到城市层级的新解释:先问**比例增长成立吗**(Gibrat 检验)——
   层级本身是统计必然的背景(实验幕三),需要解释的是**偏离**
   −1 斜率的部分,不是层级的存在。

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:证据等级之眼**——看到任何空间主张(隔离
在加剧/邻里起作用/城市要萎缩),先问它站在哪级证据上:观察
相关、自然实验、随机试验,还是机制定理?五条主线说明这门学科
的全部当代活力,就是**把经典问题从低等级证据搬到高等级证据**
的搬运工程。

城市"这些词如何从地图走进政策文件。
