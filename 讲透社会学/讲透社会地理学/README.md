## 一、家族定位(它在社会学宇宙里的位置)

社会学的一切命题几乎都藏着一个未言明的前提:人与人**在空间中**
相遇或错过。阶级隔离住在住址里,婚姻市场住在通勤圈里,贫困的
代际传递住在街区里——但古典社会学把空间当成背景板,只在脚注里
出现。本家族把背景板请回舞台中央:它是 840 宇宙的**空间透镜**,
 sociology 史管这门学科想过了什么,社会学方法管证据怎么来,
**本家族管"地方"作为自变量的全部科学**——隔离怎么测、邻里怎么
起作用、城市格局怎么涌现、数字时代距离死了没有。五问(体系/
前沿/语言/构造/转码)的回答见家族层五章。
