# 03 · 可构造与结构:哪些空间的东西能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:社会地理学的对象沿一条**可构造谱系**排开——
> 设计端**严格可构造**(三张结构卡:空间设计卡/邻域操作化卡/
> 可达性度量卡,字段化、可审查、可存档),判断端**不可构造**
> (单元的最终刀口、场所感的意义、置换检验之外的解释);而全
> 谱系共享两条结构引擎:**格局引擎**(网格/W/I 的空间统计流水线)
> 与**衰减引擎**(距离-半径-暴露的函数族)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手
> 构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
空间设计卡 ── 邻域操作化卡 ── 可达性度量卡 ── W矩阵 ── Moran's I ── 场所感研究 ── 单元的"正确"刀口
  │                                                                              │
严格可构造(字段化文件)                                                  不可构造(只有判断,没有装配线)
  └── 写得出、审得动、存得下                                                  └── 只能靠训练与敏感性纪律
```

为什么会有这条谱系?**可构造的前提是"有限字段+确定语义"**(离散
数学家族的同一条判据在此复用):可达性度量卡的语义是"机会清单/
衰减函数/半径",每个字段的合法取值可枚举;而"这个研究该按什么
单元切"的最终判断依赖对当地社会的知识,描述它的方案本身就在
改变它。本章先盘家底,再造三张卡(任务指定的开工文件),最后
看两条引擎。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **空间设计卡** | 字段化文件:问题/单元/格局假设/识别/MAUP 审计(§二) | 低(一页纸) | 卡上格局假设≠城市真相——模型是待检验假说(02 章 §三) |
| **邻域操作化卡** | 字段化文件:邻域界定/W/暴露权重/时间窗(§二) | 低 | 邻域定义三源(行政/感知/功能)不重合——选错源,效应全偏 |
| **可达性度量卡** | 字段化文件:机会清单/衰减函数/半径/人群分层(§二) | 低 | 半径 λ 是拍的;清单是选的——同一卡片换两行,结论翻转 |
| **权重矩阵 W** | 程序化生成:邻接规则/距离阈值/衰减函数 | 低 | W 的选择改变 I 与空间计量的一切下游(02 章 §二) |
| **Moran's I + 置换检验** | 闭式+随机化零分布(实验幕一) | 低 | 检验是义务,解释是判断——I 显著≠机制成立 |
| **距离衰减暴露模型** | w(d)=1/(1+d/λ) 函数族+剂量扫描(实验幕二) | 低 | 函数形式(双曲/指数/幂)互不包容,敏感性必做 |
| **Gibrat/齐普夫模拟器** | 比例增长的迭代生成(实验幕三) | 低 | 模拟证明的是机制充分性,不是历史真实性 |
| **通勤/职住矩阵** | OD 表+阻抗函数的 ETL | 中 | "通勤"口径(常态/偶尔/意愿)不同研究不同义 |
| **痕迹地理管道** | 位置数据 schema+去识别+快照包 | 中-高 | 再识别风险随轨迹长度指数上升(01 章主线 B) |
| **场所感/地方意义** | 人本地理的深描与访谈 | **不可构造** | 压缩成参数即失真;它是意义的**生产条件**而非数据 |
| **单元的"正确"刀口** | 只有敏感性分析+领域知识 | **不可构造** | MAUP 没有唯一解;能做的是多刀口并报,不是选出真刀口 |

**反直觉发现(本章铁律)**:**程序可构造 ≠ 刀口可外包**。I 值的
计算是严格程序(可教可审),但**单元怎么切、W 怎么定**是研究者
对当地社会的判断;暴露模型可跑,**λ 取多少**是理论与经验的权衡。
**谱系左端管开工文件,右端管手艺修养;用左端的文件冒充右端的
手艺(把 sensitivity analysis 的展示当成中性),是空间合规的形式
主义。**

## 二、三张结构卡(每项空间研究的开工文件——本章招牌)

### 卡 1:空间设计卡(把一次空间研究压成一页可审查的图纸)

```yaml
卡名: 空间设计卡
字段:
  研究问题:      一句话;并附空间语言改写(格局问题 X 如何分布 / 暴露问题 X 如何到达人)
  空间单元:      行政区 / 街道 / 网格(尺度) / 自然聚居点 / 个体位置
  时间结构:      横断格局 / 追踪 / 事件前后 / 序列(活动路径)
  格局假设:      同心环 / 扇形 / 多核心 / 层级(齐普夫) / 无结构(零假设)
  识别策略:      观察+MAUP 审计 / 自然实验(边界断点) / 随机搬迁(试验) / 机制模拟
  邻接与权重:    → 引用「邻域操作化卡」(字段互链,不许口头带过)
  MAUP 审计:     至少两套刀口(两种单元或两种 W)并报——结论须在刀口间稳健
  生态谬误防线:  区级结论是否被推到个体?个体数据在哪一层入场
  伦理:          位置数据的去标识 / 再识别风险评估 / 痕迹二次使用边界
构造规则:
  - 一卡一问(格局与暴露两问拆两张卡——证据类型不同)
  - 每个格局主张必附零假设与检验(I 的置换检验是底线)
  - MAUP 审计进设计不进脚注——单刀口研究按未审计处理
暗礁: 卡是计划的合同;执行中换单元不记「设计备忘」,是 p-hacking
      的空间版(刀口 hacking)
```

### 卡 2:邻域操作化卡(把"邻里"从直觉变成合同)

```yaml
卡名: 邻域操作化卡
字段:
  邻域界定源:    行政边界 / 感知边界(居民认定) / 功能边界(活动重叠)
  邻域几何:      固定半径圆 / 行政多边形 / k 近邻 / 网格邻域
  权重矩阵 W:    Queen/Rook 邻接 / 距离阈值 / 衰减函数 w(d)
  暴露定义:      暴露对象(贫困率/绿地/口碑环境)+ 汇总方式(均值/加权均值)
  衰减与半径:    w(d)=1/(1+d/λ) 的 λ;或阶梯式(圈内/圈外)
  时间窗:        暴露累计期 / 敏感期假设(儿童期?)+ 测量时点
  选择效应声明:  住址外生吗?识别策略引用「空间设计卡」的对应字段
构造规则:
  - 邻域三源(行政/感知/功能)必须声明用了哪源、为何——三源不重合时
    效应对定义敏感
  - 半径 λ 附理论理由与敏感性扫描计划(λ 扫一遍,效应稳不稳)
  - 时间窗与敏感期假设成对出现——"暴露多久"与"何时暴露"一起报
暗礁: 搬到边界上的人:加权均值会给"隔壁街区"计半权,阶梯式计零权
      ——两种处理对同一户人家给出不同暴露,这就是剂量-距离的
      刀口(实验幕二)
```

### 卡 3:可达性度量卡(把"方便不方便"变成可审计的账)

```yaml
卡名: 可达性度量卡
字段:
  机会清单:      哪些设施算"可及"(医疗/教育/就业/绿地/商业)——逐项列名
  需求人群:      为谁度量(全人群 / 老年 / 无车 / 夜班)——分层列名
  阻抗函数:      出行时间(分) / 距离(km) / 费用;交通方式(步行/公交/驾车)
  衰减函数:      w(d)=1/(1+d/λ) / 指数 / 阶梯(15 分钟内=1,外=0)
  半径 λ:        每类机会各自的半径(菜场与三甲医院不同 λ)+ 理由
  汇总量:        可达性 A_i = Σ_j 机会_j × w(d_ij);分母用人口或家户
  对照设计:      现状 vs 规划情景(新地铁/新设施)的差分——可达性审计
构造规则:
  - 机会清单与人群分层成对声明——"15 分钟城市"对无车老人的 15 分钟
    与对驾车者的 15 分钟是两个量
  - 阶梯式与衰减式各算一遍并报差(口号用阶梯,审计用衰减)
  - 规划情景必须过对照:可达性的增量归因于哪个设施
暗礁: 平均可达性掩盖分布:全市均值高而弱势人群全垫底时,均值是
      帮凶——分层报告是伦理要求不是排版偏好
```

**三张卡的共同几何**:卡 1 定**问什么与怎么审**,卡 2 定**邻里
怎么变成合同**,卡 3 定**方便怎么变成账**——三卡互链(设计卡
引用邻域卡、可达性卡挂人群分层),构成 04 竂数据管道的 schema
源头。

## 三、结构引擎 1:格局引擎(空间统计的流水线)

**直觉图像**:把一张地图变成一个可以拒绝的零假设——单元化、
上 W、算 I、做置换。

- **数学化身**:I=(n/S₀)·(Σᵢⱼwᵢⱼ(xᵢ−x̄)(xⱼ−x̄))/Σᵢ(xᵢ−x̄)²
  (实验幕一的实现体);置换检验把格值随机重排 1000 次,构造零
  分布,p 值=真实 I 在零分布中的位置。
- **刚性从哪来**:置换检验的随机化是代数级严格的(不依赖正态
  假设);但**单元与 W 在流水线最上游**——引擎的刚性止步于刀口
  (02 章 §一铁律)。多刀口并报是引擎自带的止血带。
- 与[../../讲透复杂系统/README.md](../../讲透复杂系统/README.md)的接口:格局引擎
  是"涌现的测量面"——Schelling 式隔离模拟在那边,量它的 I 在
  这边;涌现物(格局)与测量物(统计量)由此闭环。

## 四、结构引擎 2:衰减引擎(距离-半径-暴露的函数族)

**直觉图像**:把"近"从介词变成函数——一切影响(机会、邻里、
设施、信息)按 w(d) 折扣,半径 λ 定折扣的快慢。

- **函数化身**:双曲 w(d)=1/(1+d/λ)(实验幕二)/指数 e^(−d/λ)/
  阶梯 1[d≤λ]。剂量=Σ暴露×w;收益随 λ 的曲线必然饱和(远处
  的项权重→0),**半效应尺度**(收益到最大一半的 λ)是曲线的
  特征数。
- **刚性从哪来**:函数族一旦选定,一切下游(剂量、半效应、政策
  辐射圈)可复算;**函数族之间的选择没有定理**——双曲与指数在
  中段可以差出可观剂量,敏感性分析是纪律不是装饰。
- **与引擎 1 的对偶**:格局引擎量"谁挨着谁"(结构),衰减引擎量
  "挨着意味着多少"(剂量);隔离研究=格局引擎签名+衰减引擎定
  剂量,两台引擎并网(00 章 §四两场争在两台引擎上各占一台)。

## 五、判定流程(把一个空间主张钉到谱系上)

```
该主张的载体能写成字段化文件吗?
  ├─ 能,且语义是格局/剂量/流程 ─▶ 卡片端:直接构造+转码(04 章)
  ├─ 能,但字段值依赖刀口选择(单元/W/λ)─▶ 审计端:可算可监控,
  │        必须多刀口并报,无"中性"默认
  └─ 不能,依赖意义判断(场所/地方认同)─▶ 手艺端:深描+访谈,
           禁止硬造参数
```

(端点错配是空间合规的形式主义高发区:给场所感上可达性指数,
给可达性审计写散文,两头失真。)

## 六、谱系×引擎×三支总表

| 家族支 | 谱系位置 | 主引擎 | 可构造等级 |
|--------|---------|--------|-----------|
| [空间与邻里效应](讲透空间与邻里效应/) | 卡 2 端 | 两台并网(签名+剂量) | 高(邻域卡全字段化;选择效应的识别靠卡 1) |
| [城市空间结构](讲透城市空间结构/) | 卡 1 端 | 格局引擎(结构+层级) | 高(OD 表/位序回归全可算;格局解释是判断) |
| [数字时代的地理](讲透数字时代的地理/) | 中段(痕迹端) | 衰减引擎的痕迹版(活动空间) | 中高(管道可构造;场所感与代表性声明不可) |

**读表法**:一支的"科学硬度"不取决于它画不画地图,取决于它
站在谱系哪一段、用哪条引擎、以及它**把刀口敏感性诚实展示出来**
的能力。

## ✨ 美之时刻(彩蛋第 5 枚:λ 扫描——把"邻里"的边界变成一条曲线)

✨ **美之时刻 5:半效应尺度——"邻里多大"原来是个可回答的问题**
(意外)"邻里的边界在哪"吵了几十年(行政?感知?步行十分钟?),
答案看起来只能是立场。衰减引擎把它改写成:固定一切,只扫 λ——
收益随 λ 单调上升但边际递减,曲线的**半效应尺度**给出"感受半径"
的操作定义:λ 之内贡献过半,λ 之外锦上添花。为什么美:**它把
一个本体论争吵(邻里的本质)翻译成一个参数估计(λ*)**——学科
处理定义之争的标准手法(操作化)在空间上的最优雅落地。代价同样
明白:λ* 依赖衰减函数族与人群,它不是邻里的本质,是邻里的
**测量**(合同第一页写着)。亲历:实验幕二的扫描表,看收益曲线
在哪里过半(✍️练习 3)。

2. ✋ 为"好学区影响孩子"填一张邻域操作化卡:邻域三源选哪源?

3. 🐍 用实验幕二的扫描表回答:你所在城市的"15 分钟生活圈"如果

4. ✋ 找一份城市规划文本里的可达性指标,用卡 3 逐字段审:机会
