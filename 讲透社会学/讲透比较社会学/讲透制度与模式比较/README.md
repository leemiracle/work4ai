## 核心问题

**已解决(通说)**:去商品化的操作化(养老/失业/疾病三分项把「福利国家」从道德词变成
坐标);理想类型纪律(类型是标尺,个案对照量偏差,成员资格模糊是常态);LME/CME 的制度
互补性(零件互相支撑,故不能单件移植)。

**未解决/深水区**:第四体制之争(地中海/东亚家庭主义该进类型表还是当偏差);类型的动态性(模式被欧洲化与全球化持续重构);粒度之争(扩容换分辨力)。

## ✨ 这支最美的一个事实

**去商品化指数——把「离开市场还能活多久、多好」压成一个数**:养老、失业、疾病三个分项,
各自回答「一个完全不工作的人,靠制度能维持什么样的生活」。为什么美:它让「福利国家」从
价值观争吵(仁慈 vs 懒人陷阱)变成一张可辩论的地图——而且答案出乎直觉:美国、加拿大、
瑞典不是「多与少」一根轴上的三点,而是三个**世界**(加拿大与瑞典在去商品化轴上分家)——**一个好指标让道德争论变成经验问题**,类型学的尊严就在这一跃。
