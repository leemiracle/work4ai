# 03 · 可构造与结构:哪些比较对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:比较社会学的对象沿一条**可构造谱系**排开——
> QCA 真值表端**严格可构造**(组态枚举得出、一致性覆盖度算得动、
> 最小化解断言得了),语境解释端**几乎不可构造**(案例的意义只能
> 在深读与田野里操练);全谱系共享两条结构引擎:**比较作为控制**
> (求同/求异=手工造实验)与**集合论骨架**(组态/包含/最小化);
> 而比较设计本身可以被压进三张**结构卡**(案例选择卡/等价性检验卡/
> QCA 真值表卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
QCA 真值表 ── 一致性/覆盖度 ── 案例选择卡 ── 等价性检验卡 ── 去商品化指数 ── 回译程序 ── 理想类型比较 ── 语境解释
  │                                                                                            │
严格可构造(可断言)                                                            几乎不可构造(只有思想操作化)
  └── 枚举得出、算得动、能过 assert                                                  └── 只能在深读与田野里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:真值表
的语义是"每案例在每条件集合的隶属",输入输出明确;而"语境解释"的
语义是进入案例的历史与意义——**解释者本人就是测量仪器**,仪器无法
装配仪器(与社会学理论家族的"理解"同构,彼处右端)。本章先盘家底,
再看两条结构引擎,最后把整套比较工序压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **QCA 真值表→最小解** | 案例校准为隶属→按 2^k 组态聚合→一致性筛选→布尔最小化 | 低(家族实验幕三全程可跑) | 校准锚点带质性判断;k>15 组态空间爆炸 |
| **一致性/覆盖度** | 子集包含的计数:consistency=\|A∩Y\|/\|A\|,coverage=\|A∩Y\|/\|Y\| | 低 | 语义是集合不是概率;覆盖度按并集扣重叠 |
| **必要性/充分性检验** | 单条件与组合的包含关系扫描 | 低 | 必要性≠重要性(幕三:A=0.6 仍非必要) |
| **辛普森分解/标准化** | 分层率+共同权重加权 | 低 | 分层维度选谁仍靠理论 |
| **案例选择卡** | 问题/结果/案例池/策略/配平清单/偏差风险的固定字段表 | 低(§四 schema) | 「相似/不同」的裁定带主观性,须双人独立定再对表 |
| **等价性检验卡** | 构念/回译记录/不变性层级/DIF 结果/响应性修订的字段表 | 中 | 估计技术面归统计宇宙(素材纪律);本卡管设计与判定 |
| **去商品化指数** | 三分项(养老/失业/疾病)的规则化打分 | 中 | 规则化后仍有大量边界裁量(替代率口径) |
| **回译程序** | 翻译→回译→比对→困难词处置的工序清单 | 中 | 程序可列,**不可译点的处置**是语言-文化判断 |
| **理想类型比较** | 造纯型→量个案偏差 | 中 | 标尺是人为磨尖的,比较结论只对标尺负责 |
| **语境解释/过程追踪** | 案例内的时序与意义重建 | **不可构造** | 路径的"恰是如此"不可压缩成参数;压缩即失真 |

**反直觉发现(本章铁律)**:**比较研究的名气与其对象的可构造性
常常倒挂**。最出名的成果(摩尔三路径、韦伯之问)全在谱系右端,
最能跑的对象(真值表、标准化)名气最小。**右端管洞察,左端管
检验**;用右端对象硬造左端指标(给"路径"打分、给"语境"编码后
跑回归)是本学科量化研究的头号失真来源——两头都不是。

## 二、结构引擎 1:比较作为控制(密尔引擎)

**直觉图像**:实验用随机分组造控制,比较社会学用**选组**造控制
——这是全部设计工序的共同骨架。

- **求异化身(MSSD)**:两案例在配平清单上逐项相等,唯余一个差异
  与结局差异对上——**手工的差分**。数学骨架:设结局 Y=f(X, B),
  配平即固定 B₁=B₂,则 ΔY=f(X₁,B)−f(X₂,B) 只由 ΔX 负责。
- **求同化身(MDSD)**:多案例各不相同而结局相同,公共原因必在
  交集里——**手工的消去**。骨架:候选原因集合的交运算。
- **标准化化身(辛普森的解药)**:给两群体套同一结构权重,消除
  分布差——**手工的加权控制**(实验幕一的直接标准化:50/50 权重
  下 A 国 54.4% vs B 国 61.7%,翻回分层方向)。
- **刚性从哪来**:包含与消去是逻辑运算,骨架是刚的;软的地方在
  **配平清单谁定**——「相似」是理论裁定的(这正是案例选择卡要双人
  校的原因)。Galton 问题在此入账:即便配平了清单,案例间扩散与
  共同渊源仍能伪造相似——独立性没有逻辑运算能担保。

## 三、结构引擎 2:集合论骨架(拉金引擎)

**直觉图像**:把"哪些条件组合导致结局"从概率语言(平均而言、
净效应)改写成集合语言(子集、包含、并集)——QCA 的全部机器。

- **数学化身**:案例对条件集合 A,B,C 的隶属(校准后为 0-1 或
  连续隶属度);组态是布尔积 A·B;通路由并集连接(Y = A·B + C);
  一致性=\|组态∩Y\|/\|组态\|(充分方向),必要性=\|条件∩Y\|/\|Y\|
  (必要方向);最小化=布尔吸收律(实验幕三的最小性检查)。
- **三条刚性**(家族实验幕三即其数值化身):
  1. **一致性是包含,不是相关**:解一致性=1.0 意味着组态是 Y=1
     案例的精确子集描述——没有期望值,没有显著性。
  2. **覆盖度按并集,重叠必须扣减**:两通路原始覆盖 30+25=55,
     解覆盖 50——重叠的 5 例被各数一次;当方差份额加总是第一大坑。
  3. **必要性是子集关系**:A 的必要性一致性 0.6<1,因为 20 例 Y=1
     的案例根本不含 A——「重要」与「必要」在集合论里是两回事。
- **理论地位**:这是「小n、多变量」困境(00 章之争 1)的形式解法:
  组态语言不需要自由度——它问的是包含关系,不是参数估计。
- **刚性从哪来**:布尔运算是刚的;软的地方在**校准**——把变量转
  成集合隶属的三个锚点(完全隶属/交叉/完全不隶属)是质性判断,
  04 章转码时这恰好是红色区:机器只负责锚点给定后的诚实计算。

## 四、结构卡 schema:把一套比较设计压进三张卡

**先答为什么**:比较设计的难点在"整体性"——选样、尺子、类型
散落在论文各节,难以携带与审计。结构卡是**有限字段的压缩格式**:
字段固定、填空即可复用、可比可查可补(这是"可构造"在设计层的
对应物:卡片本身严格可构造)。

### 卡 1:案例选择卡(把选样设计钉进可审计的字段)

```
【案例选择卡】
研究问题:________
结果变量(Y,及其测量口径):________
候选案例池(国家/地区/时期;可及数据注明):________
选择策略:MSSD / MDSD / 典型案例 / 异常案例 / 关键案例 / 负案例(勾选)
配平清单(已控制的相似点或已利用的差异点,≤5 条):________
已知偏差风险:选择偏差(只选成功?)/ Galton(案例间扩散?)/ 生态(单位错配?)
余项声明(未观察的对照放在哪、怎么处置):________
一句话鉴定(这个选样设计能让什么结论站住):________
```

样例(已填,摩尔式):问题=现代政体的三条路;Y=政体结局(民主/
法西斯/共产主义);案例池=英法美/德日/俄中(+负案例候选);策略=
MDSD(求结局通约)+路内 MSSD(配平阶级结构);配平=都以农业社会
的阶级关系为轴;偏差=通说批评「样本偏西方大国、负案例不足」;
鉴定=能站住"路径多样性",站不住"穷尽所有路"。

### 卡 2:等价性检验卡(把尺子的资格审钉进字段)

```
【等价性检验卡】
构念(及源问卷语言):________
回译记录(困难词清单+处置):________
不变性检验:构造型 / 度量型 / 标量型(结果+证据强度):________
DIF 扫描(哪题对哪群体偏移多大):________
文化响应性修订(认知访谈发现的语义偏移):________
结论:可比较 / 部分可比较(限定哪些题哪些群体)/ 不可比较:________
```

样例(已填,幕二的教学版):构念=某态度量表(源语言英语);回译=
第 5 题两处困难词;不变性=标量型**未过**(第 5 题载荷同但截距差
0.3);DIF=第 5 题对群体二 +0.3;响应性=该题的例证情境本地化后
截距差缩小;结论=部分可比较(校准第 5 题后总分可比)。
(估计与检验的技术细节归
[../../讲透统计学/讲透社会统计学/README.md](../../讲透统计学/讲透社会统计学/README.md);
本卡管设计与判定。)

### 卡 3:QCA 真值表卡(把组态分析钉进字段)

```
【QCA 真值表卡】
结局集 Y(校准三锚:完全隶属/交叉/完全不隶属):________
条件集(k 个,各自三锚):________
真值表(2^k 行;行=组态,列=案例数/一致性):________
矛盾行处置(删除/重校准/增条件):________
一致性阈值(通说 ≥0.8/0.75,注明取值):________
必要性检查(单条件与关键组合的必要性一致性):________
解(复杂解/简约解/中间解;所用反事实声明):________
覆盖度(各通路原始覆盖/唯一覆盖/解覆盖;重叠=原始和−解覆盖):________
```

样例(已填,实验幕三):Y=结局发生;三锚略;真值表 8 行 6 行有案例;
无矛盾行;阈值 0.8;必要性:A=0.6/B=0.6/C=0.5 皆非必要;解=Y=A·B+C
(一致性 1.0);覆盖度:AB 通路 30、C 通路 25、解覆盖 50、重叠 5
——**重叠扣减行必填,防"方差份额"误读**。

**判定流程**(把一个比较主张钉到谱系上):

```
该主张的核心是比较单位的意义与路径吗?
  ├─ 否,是条件组合与结局的集合关系 ─▶ 左端:校准+真值表+最小化+断言(04 章走廊 3)
  ├─ 半,是选样与尺子的设计 ──────▶ 中段:卡片化+双人校,禁止硬算"选样质量分"
  └─ 是,语境即数据 ─────────────▶ 右端:深比较+过程追踪,禁止压成 0/1
```

## 五、谱系×引擎×三支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| [比较设计逻辑](讲透比较设计逻辑/README.md) | 中段(选择卡)——配平是清单,裁定是判断 | 密尔引擎(控制) | 中(卡片+清单,双人校) |
| [跨国调查与等价性](讲透跨国调查与等价性/README.md) | 左-中段(DIF/标准化可算;响应性修订靠判断) | 双引擎并用 | 中-高(幕二全程可跑) |
| [制度与模式比较](讲透制度与模式比较/README.md) | 中段(指数规则化)-右段(类型适用边界) | 密尔引擎(类型即标尺) | 中(指数可算,成员资格靠裁定) |
| 组态分析(横贯三支的算法层) | 左端(真值表/一致性/覆盖度) | 拉金引擎(集合) | 高(幕三全程可跑) |

**读表法**:一个对象的"可构造纯度"决定它的转码方式(04 章)——
真值表与标准化走计算,选择卡与等价性卡走字段校验,语境与路径永远
走深读。**没有哪支全家可构造,也没有哪支全家不可构造**;判据永远
是判定流程那一问:**核心是集合、清单,还是意义?**

## ✨ 美之时刻(彩蛋第 6 枚:三张卡)

✨ **美之时刻 6:三张卡——把一套比较设计装进上衣口袋**(极简)
选择卡审资格(选了谁、配平了什么、偏差在哪),等价性卡审尺子
(翻译过了几道、不变性到哪层、哪题带方言),真值表卡审解(组态
怎么枚举、覆盖怎么扣重叠)。为什么美:**它把"会比较"变成"填得
出卡"——审计从同行的不对称印象,移到任何人可复查的字段**;三卡
互相引用(选择卡的案例池喂真值表卡,等价性卡的结论限定选择卡的
结果变量),一套比较设计的强度与磨损一目了然。亲历:挑一篇你读过
的跨国研究填三张卡(✍️练习 1),填不出的格子就是它的透明度地图。
