## 一、家族定位(它在社会学宇宙里的位置)

社会学的一切因果主张都面对同一个尴尬:**社会不许做实验**——你不能
把法国随机分成两半。比较社会学的回答是:**拿世界当实验室,用设计
造控制**:找一对相似的社会让差异变量现形(MSSD),找一对迥异的社会
让共同原因钉死(MDSD),把各国压进同一个真值表(QCA),或把量表
回译到语义对齐再比均值(等价性工程)。它在 840 宇宙里是**方法学
自律层**:社会学理论管解释机器,各议题家族管领域,本家族管**这些
主张跨出本国之后还能不能站住**。五问(体系/前沿/语言/构造/转码)
的回答见家族层五章。

- **零门槛**:不要求社会学前置;只想看"各国对比"趣闻的去新闻,
  本家族管的是比较的**设计纪律**
- 路线 A(问题派):为什么甲国做得到乙国做不到?→00 章;跨国数字
  能直接比吗?→[跨国调查与等价性支](讲透跨国调查与等价性/README.md)
- 路线 B(方法派):00→01(前沿地图)→02(比较的语言怎么造出来)
- 路线 C(研究派):00→03(三张结构卡)→04(转码走廊)
- 工程师快轨:直接跑 [`experiments/comparison_pitfalls.py`](experiments/comparison_pitfalls.py),再回读 04 章

```
讲透比较社会学/            GB/T 84031(无三级明细 → 自定 3 支)
├── 讲透比较设计逻辑/       自定支(设计层)——密尔求同求异法/MSSD-MDSD/案例选择与偏差
├── 讲透跨国调查与等价性/   自定支(测量层)——测量等价/翻译回译/文化响应性
└── 讲透制度与模式比较/     自定支(模式层)——欧洲社会模式/福利体制对照/市场协调多样性
```

> 三支的共同血统:同一句口号「**社会不能实验,只能比较**」的三层
> 落地——设计层管**选谁比**(比较的单位与配平),测量层管**怎么比
> 才公平**(尺子本身要等价),模式层管**比出了什么**(类型学与坐标
> 系)。三层缺一即塌:选样偏了是比较右倾,尺子歪了是假差异,类型
> 乱了是平均数的暴政。
