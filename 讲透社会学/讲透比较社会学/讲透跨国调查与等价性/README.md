## 诞生

- **谁/何时**:高尔顿 1889 提出跨文化比较的独立性质疑(Galton 问题的测量远祖);布里斯林
  1970/1976 系统化**回译**;世界价值调查/欧洲价值观研究 1981 起建立多国问卷协作;欧洲社会
  调查(ESS)2001 起以源头问卷+翻译审计立标;约雷斯库 1971 的多组**不变性**框架经 2000s-2010s
  扩成层级惯例;近十年对齐法入场,等价性检验升格为**发表门槛**。
- **因什么问题**:①翻译过的问题还是同一个问题吗(同义之问)②量出的差是人的差还是尺的差
  (DIF 之问)③强行等价会不会抹掉真实的文化差异(响应性之问)。

## 核心问题

**已解决(通说)**:回译工序(翻译→回译→比对,困难词逐条处置);不变性层级检验与 DIF 的
题目级检测(家族实验幕二的最小版);等价性作为准入门槛——不变性不过,均值比较不发布。

**未解决/深水区**:部分等价的处置——严格逐题检验 vs 近似/对齐法之争(偏移假设谁审计);
等价性悖论——把每点组间差都校平,可能把真实文化差异当噪声抹掉;「等价」与「响应」的先后。

## ✨ 这支最美的一个事实

**回译——一句话走一个来回,才敢自称「同义」**:原文译成目标语,再由不知原文的人译回去,
两相比较——每处对不上都精确暴露文化的不可译点(那个在两边语言里没有对等物的概念)。所以
等价性程序同时是**测量工具和发现工具**:问卷里最难回译的那道题,往往就是文化差异本身——**程序的副产品比产品更值钱**,方法论史上少见的漂亮结构。
