# 比较社会学思维技能卡(讲透比较社会学 · GB/T 84031)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **设计类**:比较方法、求同法、求异法、最大相似系统设计 MSSD、
  最大不同系统设计 MDSD、案例选择、负案例、选择偏差、配平
- **测量类**:跨国调查、测量等价性、测量不变性、翻译回译、
  题目功能差异 DIF、文化响应性、部分等价、对齐法
- **陷阱类**:辛普森悖论、生态谬误、Galton 问题、聚合偏误、
  幸存者偏差、国家一行数据
- **组态类**:QCA、真值表、组态、校准、一致性 consistency、
  覆盖度 coverage、必要条件、充分条件、布尔最小化、组态因果
- **模式类**:理想类型、福利体制、去商品化、三个世界、
  资本主义多样性、LME/CME、欧洲社会模式、北欧模式、类型学
- **历史类**:比较历史社会学、路径依赖、关键节点、摩尔三路径
  (议题纵深归历史社会学 84041,文字提及)

## ② 核心思维模式(这个分支怎么想问题)

1. **比较不是并列,是设计**:看到"甲国 vs 乙国"先问选样设计——
   MSSD(配平找差异)还是 MDSD(反差钉共性)?配平清单谁裁定的?
2. **先验尺子,再比人**:跨国数字并排出现时,先问等价性——量表
   过没过回译与不变性检验?哪题可能带方言(DIF)?
3. **先问加出来的是什么**:聚合指标先分层——结构分布可以吃掉
   部门内的全部真实差距,聚合方向与分层方向可以完全相反(辛普森)
4. **覆盖度不能加总**:集合论里解覆盖按并集算,重叠必须扣减;
   把各通路覆盖度当方差份额加总会超过账面
5. **必要≠重要,充分≠大概率**:必要性是子集关系(Y=1 的案例是否
   全含于条件);回归里没有对应物,别用系数大小冒充
6. **类型是标尺,不是菜单**:理想类型量偏差合法,把类型当可整套
   移植的处方是误用——移植零件前先问配套制度在不在
7. **案例会互相"抄袭"**:相似可能来自扩散或共同渊源(Galton 问题),
   不全是各自长出的功能原因——独立性没有逻辑运算能担保

## ③ 工具箱(定理/方法 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 求同法/求异法骨架 | 设计最小比较:剔异存同 / 配平找残差 |
| MSSD/MDSD 系统设计 | 选案例对:相似系统锁差异变量 / 迥异系统钉共同点 |
| 案例选择卡(03 章 §四) | 审计选样:池子/策略/配平/偏差风险/负案例 |
| 直接标准化 | 消结构分布差:给两群体套共同权重,治聚合翻案 |
| 分层分解审计 | 任何跨地区报表:聚合方向 vs 分层方向的一致性检查 |
| 回译程序 | 跨语言量表:翻译→回译→困难词清单逐条处置 |
| 等价性检验卡 | 审计尺子:不变性层级+DIF 扫描+响应性修订 |
| QCA 真值表卡 | 组态分析:校准三锚/一致性阈值/最小解/覆盖度扣重叠 |
| 去商品化视角 | 福利比较:问"离开市场还能活多久多好",不比支出 |
| LME/CME 类型学 | 制度比较:协调方式的二分坐标(标尺用法) |

## ④ 常见误区与禁忌

- **把跨国排名当比较**:排名预设了同一把尺与同一条跑道——先过
  等价性门,再谈名次
- **把聚合数字当结论**:不分层的跨国比较=拿幻觉当发现;幕一的
  82%>39% 与分层方向完全相反
- **把均值差当群体差异**:潜特质同分布也能"测出"稳定差异——差异
  可能全在题目(DIF),不在人
- **把覆盖度当解释力百分比**:集合论的覆盖按并集扣重叠,不是
  方差份额,不能跨通路加总
- **把"相似"当客观**:MSSD 的配平清单是理论裁定,不披露配平依据
  的比较不可审计
- **把类型当分类柜**:理想类型不必装下每个案例;成员资格模糊是
  类型学的常态而非丑闻
- **把模式当菜单**:「北欧模式」是坐标系不是处方单;移植制度零件
  而不问配套,是模式话语的第一误用
- **把案例当独立样本**:国家互相学习、同源、贸易依存——Galton
  问题随全球化只增不减
