# 讲透比较设计逻辑 · 选谁比——手工造实验室的工艺

> **定位句**:这支负责**设计层**——比较研究的选样语法:密尔**求同法/求异法**的逻辑骨架,
> **MSSD/MDSD** 两种系统设计,**案例选择与偏差**(选择偏差/Galton 问题/负案例)的审计。
> 口号:比较不是并列,是设计。GB/T 13745 84031 比较社会学 · **自定支(设计层)** ·
> 家族:[讲透比较社会学](../README.md)

## 诞生

- **谁/何时**:密尔《逻辑体系》1843(求同/求异法);涂尔干 1895《准则》宣告比较法=实验替身,
  《自杀论》1897 首战;Przeworski-Teune 1970 命名 MSSD/MDSD;利普哈特 1971(比较方法=案例数
  不够时的控制技术);格迪斯 1990s-2003 揭示选择偏差;Seawright-Gerring 2008 案例选择类型学。
- **因什么问题**:①不能实验的社会怎么造控制(控制之问)②案例这么少凭什么概括(自由度之问)
  ③选出的案例天然偏向结论怎么办(偏差之问)。

## 核心问题

**已解决(通说)**:求同/求异的逻辑骨架(剔异存同/配平找残差);MSSD/MDSD 的适用分工
(相似系统锁差异变量,迥异系统钉共同点);直接标准化作为聚合翻案的解药(实验幕一)。

**未解决/深水区**:负案例的选择——格迪斯批评之后「不成功的那一半」仍无标准选法;小 n 的
概括权(分析性概括 vs 总体概括);配平裁定的主体间性(双人独立定再对表尚未成为行规)。

## ✨ 这支最美的一个事实

**MSSD 的「找相似」其实是手工造实验室**:找一对在一切相关背景上相似、唯独待解释变量不同
的案例——等于把控制变量逐项手工配平,让那一个差异在净化的环境里现形。MDSD 反其道:找一对
处处不同而结局相同的系统,候选原因被迫钉死在极少的共同点上,结论天然跨情境稳健。**两把刀
都把「不可实验」改造成「可推理」**——比较设计就是社会学的湿实验室,烧杯换成了案例。
