# 讲透公关策略与传播 · 关系的流量——议题与危机怎么进出账

> **定位句**:这支负责关系账本的**交易车间**——议题管理(在议题成为危机前监测与介入)、危机传播
> (归因-策略匹配的 SCCT 手艺)、整合营销传播接口(IMC:营销管交换,公关管关系)。存量的每一次
> 大额进出都在这里发生:一次危机是账本上的一笔 −C,辟谣时间窗是这笔账能否少扣的胜负手。
> GB/T 13745 84054 公共关系学(无三级明细)· **自定支二**。家族:[讲透公共关系学](../README.md)

## 诞生

- **谁/何时**:蔡斯提出**议题管理**(1976-1977,通说)——议题有生命周期,组织要在成为危机前进场;
  伯努伊**形象修复理论**(1995)把事后策略整理成策略族(否认/规避/减轻/修正/道歉);库姆斯 **SCCT**
  (2007 成书)把维纳归因论接进危机:受害型/事故型/预防型三格各配策略;舒尔茨等 IMC(1993 起,通说)
  把公关收进整合营销传播的接口带。
- **因什么问题**:①同样的危机同样的回应,为何效果相反(匹配之问)②回应的时间底线在哪(时间之问)
  ③议题能不能在成为危机前管住(前置之问)。

## 核心问题

**已解决(通说)**:归因-策略匹配框架成立(策略无对错,只有站没站对格);议题生命周期成为监测的
通用坐标;形象修复策略族可查表。

**未解决/深水区**:真实危机无反事实(策略-结局因果难识别,情境实验外推要声明);归因未定期的
首响决策是经验带(快-准权衡);慢燃烧与持续型危机不套周期模型;ESG 漂绿把"期望差距"推成新变量。

## ✨ 这支最美的一个事实

**道歉不是美德,是匹配**:SCCT 把百年"道歉学"翻成一张查表——**策略不分级,只有匹配合不配**。
受害型危机(组织也是受害者)用否认与切割,道歉反而坐实责任;预防型危机(确有过失)硬否认必遭
二次扣账,重建策略(道歉+补偿+制度变更)是唯一格内走法。为什么美:**它把道德语气的争论(该不该
道歉)换成归因语气的计算(站在哪格)**——同一次鞠躬,格内是止损,格外是加杠杆;而时间窗(家族
实验律二:d 越过谣言增速峰值 t* 后纠正骤降)给所有查表加了截止日期:**匹配的策略来晚了,也只是注脚**。
