## 诞生

- **谁/何时**:肯特-泰勒**对话式传播五原则**(1998)在万维网早期立下数字对话的规范底稿;2000 年代
  社交媒体把"双向"变成技术默认(任何公众都能@官方);2010 年代平台化与算法分发改写议题通道;
  2020 年代大模型把监测与内容管线自动化,深度伪造把"组织被造假"立为危机新条目(01 章主线 A/B)。
- **因什么问题**:①技术上的双向为什么不等于组织上的双向(伪对称之问)②监测自动化压缩了响应
  时间的哪一段(管线之问)③算法通道下议题还管得住吗(通道之问)。

## 核心问题

**已解决(通说)**:对话原则成为行业话术标准;舆情监测栈建制化(抽取/聚类/预警);平台危机的时间常数压缩(热搜周期)成为共识口径。

**未解决/深水区**:算法分发下议程权力的组织侧版本正在重写(机制本体归 860,接口带归本支);"说谎者
红利"下的信任基线移动与预认证渠道基建;监测替代对话的病态化(舆情天气化,02 章);公众碎片化与
涌现联盟冲击利益相关者地图。

## ✨ 这支最美的一个事实

**双向对称的"技术免费"陷阱**:格鲁尼格 1984 年立"双向对称"时,它是需要组织费力搭建的规范理想——
建反馈渠道、做研究、允许被改变。社交媒体让技术上的双向**免费**了:任何公众随时能@官方账号。
但技术双向≠组织双向:**回复评论的是客服字段,改变自己的才是对称字段**——对话在技术上普及的同一
时刻,伪对称(礼貌地单向)也工业化了。判别只一列:组织因反馈改变过自己吗?
