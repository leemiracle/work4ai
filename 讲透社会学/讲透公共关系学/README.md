# 讲透公共关系学 · 组织与公众之间——信任如何在时间里记账

> **本质一句话**:公共关系学=把「公众」从组织的环境噪声改写成组织的
> **对话方**的学科——它不问"怎么把讯息卖出去"(那是广告),而问组织
> 与公众之间的**信任如何在时间里记账**(一次危机烧掉九个履约期的
> 进账,攒回来要二十一个无事故期);不问"怎么控制舆论",而问**议题
> 如何被监测、危机如何被沟通、声誉如何成为资产**;一句话:
> **公关的对象不是讯息,是关系——关系的货币是信任,信任的账本是时间。**
>

## 一、家族定位(它在社会学宇宙里的位置)

社会学宇宙的多数家族研究"社会如何运转",本家族研究**一个特定界面**:
组织(企业/政府/机构)与它的公众(雇员/消费者/社区/媒体/监管者)之间
的关系如何建立、维持、受损与修复。它是社会学里离**管理职能**最近的
分支:1906 年艾维·李的《原则宣言》给出职业理想("公众必须被告知"),
1923 年伯内斯《舆论的结晶》完成学科化,1984 年格鲁尼格四模型把百年
实践整理成类型学,1992 年卓越研究把"双向对称"立为规范理想,数字
时代又把整个行业搬到平台上重新开工。四模型→卓越研究→关系范式→
数字公关的编年是 00 章的主线;五问(体系/前沿/语言/构造/转码)
的回答见家族层五章。
