# 讲透组织-公众关系 · 关系的存量——信任与声誉记在账上

> **定位句**:这支负责关系账本的**资产车间**——利益相关者是谁(地图)、信任与声誉如何测量与折损(存量)、
> 关系如何成为可经营的**关系资产**。它是关系范式(2000)在家族里的正座位:公关的产出不是讯息送达,
> 而是组织-公众关系的**状态**——状态的货币是信任,账本是时间。
> GB/T 13745 84054 公共关系学(无三级明细)· **自定支一**。家族:[讲透公共关系学](../README.md)

## 诞生

- **谁/何时**:弗里曼《战略管理:利益相关者方法》(1984,管理学侧借来);福姆布朗《声誉》(1996)立**声誉资本**;
  洪-格鲁尼格关系测量纲要(1999)给出**关系五指标**(信任/控制互惠/承诺/满意);莱丁汉-布鲁宁
  《作为关系管理的公共关系》(2000)宣布范式转移——对象从讯息换成关系。
- **因什么问题**:①"关系好"怎么从比喻变成可测的量(测量之问)②声誉凭什么算资本、怎么折现(资本之问)
  ③公众名单是给定的还是涌现的(边界之问)。

## 核心问题

**已解决(通说)**:关系可操作化(五指标成为标准工具箱);声誉进入估值与排名体系(评级机构口径);
利益相关者分格(权力×利益)成为管理常识。

**未解决/深水区**:自报指标与行为指标(复购/溢价)经常不同向,账户口径未统一;评级的"清单即理论"
问题(换表换名次);平台时代公众从名单变成涌现联盟(01 章主线 B);ESG 三栏重新分账后的口径之争。

## ✨ 这支最美的一个事实

**信任的贴现账本——两行算术装下一句老话**:T←δT+x,历史按 δ 打折,当期记 x(履约 +a,危机 −C)。
危机瞬间抹掉 a+C(扣罚之外还丢了当期进账),恢复靠无事故期把缺口 δ^k 磨平——a=1、C=8 时,
δ=0.90/0.95/0.98 分别要 **21/43/109 期**(与解析解 ln(1+C/a)/ln(1/δ) 逐一相等),且**记忆越长恢复越慢**。
"毁信易建信难"从格言变成坐标:不对称比 21:1,还随公众记忆拉长恶化(家族实验律一即本支仪表)。
