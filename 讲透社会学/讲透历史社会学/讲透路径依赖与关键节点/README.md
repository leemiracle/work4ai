## 诞生

- **谁/何时**:大卫〈Clio 与 QWERTY 的经济学〉(1985,劣势幅度有 Liebowitz-Margolis 争议,通说标注);
  阿瑟〈竞争技术与历史事件导致的锁定〉(1989)收益递增;诺思《制度、制度变迁与经济绩效》(1990)
  制度路径依赖;科利尔夫妇《塑造政治竞技场》(1991)关键节点-遗产框架;皮尔森〈收益递增与
  政治研究〉(2000)《时间中的政治》(2004);马奥尼(2000)机制二分:自强化序列 vs 反应序列;
  鲍姆加特纳-琼斯(1993)断续均衡入政治;佩奇(2006)批评与澄清。
- **因什么问题**:①为什么次优的安排能长期存续(锁定之问)②历史事件怎么定框后续路径(节点之问)③变迁为什么长期停滞又短期爆发(均衡之问)。

## 核心问题

**已解决(通说)**:路径依赖的两种机制学——自强化(收益递增)与反应序列(链式触发),
证据形态不同不可混用;关键节点框架(窗口-选择-闭合-遗产四段,遗产要给中介链,存在≠起因);
断续均衡的经验指纹(长稳态+快速变迁,实验幕三的丛集指数是最小版)。

**未解决/深水区**:可证伪化——什么证据能推翻「这是路径依赖」(佩奇之问);锁定的度量
(δ* 没有标准尺,实验幕二是一条路,历史数据稀薄);关键节点的事前识别(事后追认偏差)。

## ✨ 这支最美的一个事实

**Polya 罐(实验幕一)**:初始 1 红 1 蓝,按当前比例强化——事前,终局份额的极限分布是均匀的
(命运对两色完全公平);事后,每一个具体的罐都长出极端的份额。**宏观的可预测与单个的
不可预测在同一个小罐里并存**——「路径依赖」四个字的全部数学。而干预实验补上最狠的一刀:
把 10 抽从末段搬到首段,终局>0.9 的概率从 0.10 跳到 0.68(6.7 倍)——路径依赖的本体
在**搬得动过去**,不在**猜得中结局**。

## 假设与依赖

- 买入「早期事件改变后期概率」:账单是一切皆路径的过度适用(可证伪性弱,佩奇批评)
- 收益递增的强度 α 需要经验测量(归方法侧);份额型与计数型强化的锁定尺度不同,换底盘要重验
- 断续均衡的阈值与纪元界定有任意性:丛集的指纹指向纪元结构,不是漂移本身(幕三如实标注)
