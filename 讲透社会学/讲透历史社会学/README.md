## 一、家族定位

- **三支分工**:同一门「社会如何被时间塑造」之问的三种打开方式——
  **经典议题支**问**什么**(革命/国家形成/资本主义起源/福利国家起源:
  摩尔-斯考切波-蒂利线的大问题谱系),**方法支**问**怎么知道**
  (过程追踪/比较历史/档案方法/机制与叙事:历史取证的规程),
  **机制支**问**用什么概念引擎**(路径依赖/关键节点/收益递增/
  断续均衡:时间起作用的机制学)。
- **一条主线贯穿**:**时序不中性**——同样的因,不同的时刻与次序,
  长出不同的果;早期偶然被强化滚成既得格局(实验幕一/幕二),大事件
  丛集在压力纪元的临界段(幕三)。
- **零门槛**:不要求史学或社会学前置;想看理论直觉去社会学理论家族
  (已链),想看史料工艺去历史学宇宙(已链),本家族是它们共同的
  **时间问题化现场**。
- 路线 A(问题派):为什么相似的社会长出不同的政治?→00 §一+支1;
  为什么坏制度能活几百年?→00 §七+支3;历史证据怎么变成因果断言?
  →03 章+支2
- 路线 B(体系派):00→01(前沿)→02(语言)→03(可构造)→04(转码)
- 路线 C(研究派):00→01(文献地图)→各支教材锚
- 工程师快轨:直接跑 [`experiments/path_and_moment.py`](experiments/path_and_moment.py),再回读 04 章

> 三支是一个问题的三个面:议题支供**战场**(哪些大问题值得问),
> 方法支供**取证规程**(历史证据怎么变成断言),机制支供**概念引擎**
> (时间怎么起作用)——没有议题的方法是空转,没有方法的议题是叙事,
> 没有机制的前两者只是编年。
