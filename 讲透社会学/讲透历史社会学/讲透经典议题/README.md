# 讲透经典议题 · 大问题的比较历史解剖——革命、国家、资本主义、福利国家

> **定位句**:这支管**议题纵深**:革命/国家形成/资本主义起源/福利国家起源——摩尔-斯考切波-蒂利线
> 把「现代世界怎么来的」做成可比较的历史分支树;同一批大问题,历史学给编年与考订,
> 本支给**结构解释的谱系**。
> **自定支**(GB/T 84041 无三级明细,家族自定三分)。家族:[讲透历史社会学](../README.md)

## 诞生

- **谁/何时**:马克思《雾月十八》(1852)立"既得条件"之问;韦伯《新教伦理》(1904-05)示范单线深钻;
  摩尔《专制与民主的社会起源》(1966)三条路线(资产阶级革命→民主/保守现代化→法西斯/农民革命→共产主义);
  斯考切波《国家与社会革命》(1979)国家崩溃论;蒂利《强制、资本与欧洲国家》(1990)战争-国家;
  艾斯平-安德森(1990)福利国家三体制(起源之争的集大成)。
- **因什么问题**:①相似社会为何长出不同政治(分岔之问)②成败由结构还是主角(意图之问)③市场与国家从哪来(起源之问)。

## 核心问题

**已解决(通说)**:三条路线——农业商品化与阶级联盟解释民主/法西斯/共产分岔(摩尔);
革命成功=国际压力下旧政权崩溃×农民村社结构、国家自主性入场(斯考切波);战争制造国家、
资本-强制组合决定国家形态(蒂利);福利国家起源三论并立(工业化/阶级权力/国家论)。

**未解决/深水区**:结构解释的微观基础(抗争政治线在补);分支树装不下的小案例与民主
起源再检验;案例选择的自由度(方法侧归支2 与比较社会学)。

## ✨ 这支最美的一个事实

**革命不是制造出来的,是到来的(斯考切波 1979)**:法国 1789、俄国 1917、中国 1911-49——
三场革命的成功都不归功于革命党的意图与组织,而归于旧政权在国际军事竞争中的自我瓦解
与农民村社的自组织容量。**把「谁的功劳」改写成「什么结构断了」**——伟人史观被结构史观
重讲一遍只用了一本书;此后任何"英明领袖造就革命"的叙事都要先过结构条件这一关。

## 假设与依赖

- 买入结构优先:阶级联盟/国家能力/国际压力是主变量(账单:意义与行动者降维,00 §五)
- 案例少而重:2-5 个深案例买纵深付自由度——取证规程归支2,设计语法归比较社会学;大问题以世纪为尺度,不适用于季度叙事(尺度之眼,01 章)
