# 讲透历史转向与方法 · 知道的方式——过程追踪、比较历史、档案、机制与叙事

> **定位句**:这支管**知道的方式**:过程追踪/比较历史/档案方法/机制与叙事——历史社会学的证据学;
> 同一堆档案,史学的考订工艺归历史学宇宙,本支管「从历史证据到因果断言」的**推断规程**。
> **自定支**(GB/T 84041 无三级明细,家族自定三分)。家族:[讲透历史社会学](../README.md)

## 诞生

- **谁/何时**:韦伯的理想类型与客观可能性(反事实的节制);斯考切波主编《历史社会学中的
  视野与方法》(1984)方法论自觉;科利尔线把过程追踪系统化为四测验(箍/冒烟枪/稻草/决定性,
  范艾弗拉-贝内特系);马奥尼-鲁斯克迈耶手册(2003)定型 CHA;阿伯特序列分析(2001);
  Sewell 事件性时间性(2005);档案批判(殖民档案与沉默,通说)。
- **因什么问题**:①案例少(N=2-5)时因果怎么推断(小样本之问)②历史证据的间接性怎么管理(取证之问)③叙事算分析还是修辞(机制与叙事之问)。

## 核心问题

**已解决(通说)**:案例内因果推断的四测验(证据-假设关系按似然比方向分类,取证有语法);
跨案例比较与案例内追踪的正典分工(比较找模式,追踪找机制);档案的外证内证标准流程;沉默作为证据的编码。

**未解决/深水区**:循环论证险境(用理论挑档案又用档案证理论);数字档案的检索偏差——
三层筛子(产生/保存/数字化)叠加(01 章主线 B);贝叶斯过程追踪的先验纪律(似然比从哪来)。

## ✨ 这支最美的一个事实

**四测验**:同一证据在不同问法下分量完全不同——**箍测验**(hoop test)过了只能说明假设
还活着(必要不充分),**冒烟枪**(smoking gun)找到只能确证不能证伪,**稻草**(straw in
the wind)两向皆弱,**决定性测验**双向都硬。证据的"强度"不是证据自身的属性,是
**证据×假设×备择**三方的属性——这条语法把"这条史料很有力"从争吵变成可以逐环记账的
推断账本(家族 03 章过程追踪卡的全部字段由它撑起)。

## 假设与依赖

- 买入"机制链可从历史残迹重建"(账单:选择性存留——幸存的证据偏袒胜者与官僚)
- 档案一手性≠代表性:产生与保存两道筛子在先(档案证据链卡的沉默字段)
- 叙事两面:既是意义载体又是分析对象——机制与叙事的分工要显式声明
