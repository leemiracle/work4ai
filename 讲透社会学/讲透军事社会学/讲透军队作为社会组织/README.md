# 讲透军队作为社会组织 · 科层的外壳,伙伴的内核

> **定位句**:内部视角——军队作为一种社会组织的运行:**科层与伙伴双重性**(韦伯式科层外壳+主参照组初级群体内核)、**士气与凝聚力**(个体态度与群体纽带的分层)、**Stouffer 相对剥夺**(晋升满意度悖论)。**自定支声明**:GB/T 84047 未列三级明细,本支为家族自定支之一。家族:[../README.md](../README.md)(宇宙:[../../README.md](../../README.md))

## 诞生

- **谁/何时**:韦伯科层制理想类型(1900s)给外壳以语法;Stouffer《美国士兵》(1949)给内核以实证(主参照组/相对剥夺);Janowitz《职业军人》(1960)补职业分层;Moskos I/O 模型(1977)把「军队怎么动员成员」压成一根谱系轴。
- **因什么问题**:①规模化组织靠规则还是纽带让成员坚持 ②满意度为什么与处境倒挂(参照系之问)③军队为什么常是出身不利者的上升通道(规则化机会之问)。

## 核心问题

**已解决(通说)**:态度由参照组校准(晋升悖论);初级群体是组织忠诚的主要载体;军官职业化画像;I/O 谱系的定位测量。
**未解决**:凝聚力的测量与因果(自报 vs 网络结构;凝聚→绩效还是绩效→凝聚);士气与凝聚力的概念分界;规则化晋升的公平上限(规则含历史与政治成分——模型是机制玩具,不是制度背书)。

## ✨ 这支最美的一个事实

**晋升满意度悖论**:晋升最快的航空兵满意度最低,晋升最慢的宪兵反而最高——绝对处境与态度完全倒挂,机关藏在**参照组**里:身边人人快,期望被拉高,落空感最强。**不满=期望−所得,而期望是社会结构给的**(数值机制见[家族实验](../experiments/org_and_reintegration.py)幕一)。

## 假设与依赖

- 机构假设(军队是规则化、相对透明的科层职业组织)——买到「上升通道」的解释力;付出:规则≠公平的自动担保
- 士气/凝聚力的心理机制正主归社会心理学(GB/T 19020,未建,纯文字声明);科层与寡头理论本体在 [../../讲透社会学理论/README.md](../../讲透社会学理论/README.md)(互链)
