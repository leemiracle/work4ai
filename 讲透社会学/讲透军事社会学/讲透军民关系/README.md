# 讲透军民关系 · 军队与社会的界面——统制、志愿役与相互看见

> **定位句**:界面视角——**文官统制的通说框架**(客观/主观统制两案并立,平实转述不作栽判)、**志愿役社会基础**(1973 年 AVF 后「谁服役」成为劳动力市场与公平问题)、**军人群体的社会认知**(军民差距三分:态度/构成/接触;信任的供给线:接触 vs 媒体框架)。**自定支声明**:GB/T 84047 未列三级明细,本支为家族自定支之一。家族:[../README.md](../README.md)(宇宙:[../../README.md](../../README.md))

## 诞生

- **谁/何时**:Huntington《军人与国家》(1957)与 Janowitz(1960)立下文官统制两案;Allport《偏见的本质》(1954)给出接触假说;1973 年美国转向全志愿役(AVF),界面研究获得天然实验;Feaver & Kohn 编《士兵与平民》(2001)使「军民差距」成为标准议题。
- **因什么问题**:①武力如何被置于社会控制之下(统制之问)②谁来服役、谁与军队发生接触(志愿役的社会基础之问)③社会怎么认识军人(信任的供给之问)。

## 核心问题

**已解决(通说)**:统制两案作为分析框架并立;军民差距三分法(态度/构成/接触);接触对群际态度的正效应(接触假说的组织版)。
**未解决**:接触与信任的互为因果(可识别性差,纵向数据稀缺);差距的来源分解——多少来自接触消失,多少来自框架差;志愿役代表性的规范争论(各国方案不同,本支不评价现行制度)。

## ✨ 这支最美的一个事实

**AVF 转型:一次制度切换把「谁服役」变成市场问题**:志愿役把兵源从公民义务改成劳动力市场——机会结构、家庭传承、地区分布从此可被当作变量研究;而服役人口占比下降意味着**大多数社会成员终生无直接接触**,军民信任的供给从握手换成屏幕(数值机制见[家族实验](../experiments/org_and_reintegration.py)幕二:c 塌陷时分化 0.239 取决于框架差)。

## 假设与依赖

- 接触假说假设(群际直接接触普遍改善态度)——买到界面干预的全部合法性;付出:接触的准入条件(平等地位/共同目标)常不满足
- 统制框架为政治社会学通说(两案并录不栽判);群际心理机制本体归社会心理学(GB/T 19020,未建,纯文字声明);制度比较按通说学术框架转述,不涉任何现行制度细节

## 教材锚

- Huntington《军人与国家》(1957);Janowitz《职业军人》(1960);Allport《偏见的本质》(1954);Feaver & Kohn《士兵与平民》(2001);Moskos 等《后现代军队》(2000);家族 00 章为总绪论
