# 04 · 军事社会学转代码:把组织、信任与再融入搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:军事社会学的可构造端(03 章谱系左半——三张结构卡
> 与两条动力学)几乎可以无损转码;**价值层永远不可转码**——军事化
> 批判、制度优劣、政策取舍,机器只能携带与呈现,不能产生;三条代码
> 走廊——**晋升规则模拟 / 接触-信任动力学 / 再融入关键期评估**——
> 把组织社会学最硬的结构变成可跑、可断言、可扫描的实验。
> 本家族独有红线:**一切转码只做参数化玩具,不建任何真实军队的
> 人事、编制或政策数据**(写作红线的技术版)。

---

## 开篇:不是「能不能转」,是「转到哪一层」

数学家族转代码要解决「离散化」,军事社会学转代码要解决
「**代理与规范的剥离**」:把制度语言(士气/凝聚力/军民鱼水)先翻成
单负载的模型(参照组结构/转移概率/信任锚点),再翻成代码——
损耗全部发生在代理环节(自报态度代理组织后果、轨迹数据代理融入
质量)。本章先划清哪些代理走得通(绿色区),哪些走不通(红色区),
再给三条走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 军事社会学概念 | 代码化身 | 备注 |
|---------|---------|------|
| 组织诊断卡 | schema+登记器:四栏字段化,公共可核栏与自报栏分表存 | 03 章卡 1 的直接编码 |
| 再融入轨迹卡 | 状态序列数组+判定器:5 年稳定率=计数 | 03 章卡 2;登记系统稍加改造即是 |
| 军民关系测量卡 | 三源分栏数据结构(网络条目/锚定量表/内容编码) | 03 章卡 3;防三差距混报的工程护栏 |
| 机会分配规则 | 两臂对照仿真:配额锁死+评分规则参数化 | 本家族实验幕一;规则=评分函数,出身权重是显式参数 |
| 接触-信任动力学 | 双供给更新方程+均值场解析 | 实验幕二;MC 与解析双证 |
| 再融入动力学 | 时变转移矩阵递归+MC 队列互证 | 实验幕三;行随机性自检(assert) |
| 关键期评估 | 干预窗扫描:边际贡献=干预组−基线,按窗起点排表 | 政策时间窗的审计工具 |

**转不动(红色区)**:

1. **军事化的判定**:多层价值权衡,只有公开论证——「军事化指数」
   若被硬造,测到的只是可编码的话语表面(03 章批判端)。
2. **制度优劣的裁决**:志愿役/征召孰优,涉及价值排序与国情参数,
   机器可呈现比较维度,不能替社会选择(写作红线:不评论现行制度)。
3. **凝聚力的产生机制**:量表分数可存,纽带如何形成是经验对象;
   「团建算法」是古德哈特定律的团体操版。
4. **真实军队数据**:独有红线——转码一律用参数化玩具数据;
   真实人事、编制与政策数据不入库、不建模、不训练。

**边界的一句话**:绿色区=三张卡+两条动力学+一个扫描器;红色区=
价值层+机制层+真实数据。**红线:凡涉及「该不该、好不好」,机器
只携带不产生。**

## 二、代码走廊清单(三条走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:晋升规则模拟走廊(机会分配的对照实验)

```
机会分配规则 ──参数化──▶ 两臂仿真:同一批人,配额锁死相等
      └─评分函数扫描──▶ 出身 R² / 期望差 / 方差 ─▶ 制度设计审计
```

- **理论→模型**:03 章机会分配引擎——军队臂=绩效+资历透明队列
  (出身权重 0),民间臂=网络化(出身间接起效+累积优势);
  **机会总量锁死相等**是设计的关键:把「更多机会」与「换种分法」
  的混淆一劳永逸地拆开。
- **本家族实现**:实验幕一——底层军-民差 +1.455 级、方差 8.35<9.23、
  出身 R² 0.0013 vs 0.1290、高层反向 −2.213;断言写**方向与结构**
  (均值序、方差序、R² 阈值),不写点值,多 seed 可复现。
- **性能工程要点**:出身权重必须**显式入参**(0 是一种选择,不是
  默认);累积优势项单独开关——两项是审计的靶心。真实系统侧:
  任何组织(企业/院系)的晋升公平性审计同构适用。

### 走廊 2:接触-信任动力学走廊(信任的供给线工程)

```
接触假说 ──参数化──▶ 更新:x ← x + cα(A−x) + (1−c)β(f_g−x)
      └─c 扫描+框架差分解──▶ 信任均衡与差距 ─▶ 军民沟通项目设计
```

- **理论→模型**:03 章接触-框架引擎——均值场均衡
  eq=(cαA+(1−c)βf)/(cα+(1−c)β) 是可手算的仪表盘;MC 仿真贴住
  均衡(偏差<0.002)保证模型自洽。
- **本家族实现**:实验幕二——c=0.50 双高(0.728/0.657),c=0.02
  分化 0.239,同框架不分化(0.000)但停在 0.467;**框架差只在低接触
  区起作用**是给沟通项目的结构性判词:接触还在时别浪费钱修框架,
  接触没了时框架就是全部。
- **性能工程要点**:两群体的框架锚必须**分开编码**(异质性是结论
  的前提);接触率的测量单位要锚定(年均直接互动,不是「认识」)。

### 走廊 3:再融入关键期走廊(政策时间窗的审计)

```
轨迹卡 ──动力学化──▶ p_ij(t)=p_ij(1)·exp(−(t−1)/τ)·干预乘子
      └─干预窗扫描──▶ 边际贡献表 ─▶ 过渡支持项目的排期决策
```

- **理论→模型**:03 章关键期引擎——衰减(技能贴现/网络冷却)+
  吸收态复利,两个机制都偏向早干预;解析递归(分布层)与 MC 队列
  双证(实验幕三偏差 0.0011)。
- **本家族实现**:同为两年干预,头两年 5 年稳定率 0.4020 vs
  第 3-4 年 0.3435(+5.9pp),边际贡献 0.1164>0.0579,晚干预仍优于
  基线 0.2856——**「晚干预没用」是误读,「杠杆更小」才是读数**。
- **性能工程要点**:τ 与干预乘子是**待估参数**不是常数——换一个
  人群重估一次,报告必须附敏感性;选择偏差(谁早转移)是模型外的
  沙,结论降级读。真实系统侧:再就业项目/转岗支持的排期审计同构。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:组织晋升与机会审计(走廊 1 的民用兑现)

- 你的公司/院系的晋升制度=评分函数:把**出身类变量**(毕业院校/
  引荐人/轮岗起点)与**规则类变量**(绩效/资历)分列,跑两臂对照
  ——出身 R² 就是公平性的一号指标;累积优势项(晋升带来的网络
  扩张)单独计量。
- 警惕**透明化的表演**:规则文本透明≠判罚一致——审计时抽同分案
  例双人盲判(03 章卡 1 的判定器用法)。

### 落点 2:员工融入与转岗支持系统(走廊 3 的民用同构)

- 新员工融入、转岗适应、回归职场(育儿假后)共享再融入轨迹卡的
  结构:四状态×月份×支持窗;衰减马尔可夫告诉你**支持资源的排期
  比总量更重要**——同样预算,前置两个月胜过后置半年。
- 数据埋点按状态转移登记(入职培训→带教→独立→稳定),别只记
  「入职/离职」两点——两点之间的轨迹才是系统的可干预面。

### 落点 3:内外部群体的信任运营(走廊 2 的民用同构)

- 平台与用户、总部与一线、公司与社区——任何「内群体/外群体」
  界面上的信任都由两条供给线喂养:**接触率**与**框架锚**;先测
  c,再决定投接触(共建/轮岗/开放日)还是投框架(叙事/沟通)——
  接触还在时修框架是浪费,接触没了时只剩框架。
- 均值场公式是预算速算器:两策的投入比应参照 cα 与 (1−c)β 的
  相对大小,而不是拍脑袋五五开。
