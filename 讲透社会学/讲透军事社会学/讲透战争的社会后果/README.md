# 讲透战争的社会后果 · 输出侧——退伍、家庭与军事化

> **定位句**:下游视角——服役与战争向社会输出什么:**退伍再融入**(从「成败二分」到「轨迹」:四状态流动与关键期)、**军属家庭**(贪婪制度的双重索取;部署周期的家庭压力曲线)、**社会军事化的概念与批评**(军事逻辑向民用领域扩散——描述词先于贬义词,按批判传统平实转述)。**自定支声明**:GB/T 84047 未列三级明细,本支为家族自定支之一。家族:[../README.md](../README.md)(宇宙:[../../README.md](../../README.md))

## 诞生

- **谁/何时**:1944 年《退伍军人权利法案》(GI Bill)让数以百万计退伍军人进入大学(通说史实)——后果研究的制度原型;Coser「贪婪制度」(1974)被 Mady Segal 一线移入军人家庭研究;Elder 生命历程研究把二战服役确立为出身不利者的**转折点**;Enloe《Maneuvers》(2000)立起军事化批判线。
- **因什么问题**:①服役对社会流动意味着什么(转折点之问)②军队与家庭怎么分时间与忠诚(贪婪制度之问)③「再融入」何时最难(关键期之问)④军事逻辑渗入社会的边界在哪(军事化之问)。

## 核心问题

**已解决(通说)**:GI Bill 的教育外溢史实;服役作为生命历程转折点(对出身不利者的压缩效应);部署周期压力曲线的通说模型;再融入从二分变量升维为轨迹(状态转移)。
**未解决**:关键期效应的识别(早成功者自选——选择偏差是常沙);军事化概念的边界与测量(批判端的构造学缺席);退伍身份的社会认知(雇佣方信号解读,方向锚)。

## ✨ 这支最美的一个事实

**转折点:服役压缩出身差距**:生命历程研究(Elder 线)发现,对出身不利的男性,二战服役成为日后成就的**转折点**——标准化训练、credential 与纪律部分替代了家庭背景的作用(机制化表达见[家族实验](../experiments/org_and_reintegration.py)幕一:规则化机会使出身 R²≈0;幕三:政策杠杆支点在退役头两年)。

## 假设与依赖

- 轨迹假设(再融入是可分状态的转移过程)——买到关键期与干预窗的全部推理;付出:状态判定要经训练,选择偏差随卡外
- 军事化研究按批判传统通说转述(概念先是描述词);家庭与福利纵深归福利社会学 84067(同波兄弟,文字提及);战史素材取自 83015 军事史(830 宇宙,纯文字提及)
