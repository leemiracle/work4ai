# 02 · 语言特征:一门学科怎么用「问题」说话

> **本章回答五问之三:这个分支的语言——表达力、逻辑性质、规范化
> 程度——长什么样?** 三栏 X 光:**术语**(它造什么样的词)/**
> 应用量**(它把问题写成什么可算的东西:发生率/暴露率/干预剂量)
> /**话语迁移**(「社会问题」「弱势群体」「社区营造」这些词如何
> 进入政策话语并变形)。每栏先答**为什么是这样**。
>
> **本章一句话**:应用社会学的语言是一台**翻译机**——把「个人的
> 烦恼」翻译成「可算的分布」,再把运算结果翻译回「政策的句子」;
> 它的全部力量来自这次升维(烦恼有了分母,抱怨有了基准),它的
> 全部麻烦来自**翻回来的路上每个词都在偷偷变脸**——把「社会问题」
> 翻成「负面清单」(丢了建构面),把「弱势群体」翻成「救助对象」
> (丢了结构成因),把「社区营造」翻成「搞活动」(丢了权力面)。

## 开篇:为什么这门学科读起来一半像社会学,一半像政府文件

新手有两个相反的困惑:一是「发生率、暴露率、瞄准率,这不就是统计
报表」,二是「同一份项目书,前半页引涂尔干后半页写 KPI,中间没有
过渡」。两个困惑同源:这门学科的词**活在两界**——一界是学术史
(有谱系有论战),一界是政策与行政语言(有指标有预算)。本章三栏
X 光:先查术语的双户口本(第一栏),再看问题被写成什么可算的量
(第二栏),最后查翻回政策时的高发变脸点(第三栏)。

## 一、第一栏:术语——构念的户口本

**先答为什么**:应用社会学的术语不是描述词,是**升维器**——每个
词把一摞个人烦恼压成一个有分母的分布。不懂升维,词就是空的。本
家族十二个高频词:

| 构念 | 一句话定义 | 思想操作化 | 血统 | 常见误用 |
|------|-----------|-----------|------|---------|
| 社会问题 | 被社会认定需要集体干预的社会状况 | 双焦:客观条件(分布)+社会定义(宣称) | Merton-Nisbet 1961 | 当「坏事清单」用(丢建构面:同一种伤害,喊起来才算问题) |
| 病人角色 | 生病=与社会的角色谈判:豁免义务换求医康复 | 四要素核对(免责/求医/康复/豁免) | Parsons 1951 | 当「病人心态」用(它是制度不是心态) |
| 初级/次级越轨 | 初次越轨 vs 被反应改造后的持续越轨 | 找「反应事件」分界(Lemert) | Lemert 1951;Becker 1963 | 把次级越轨当「惯犯品性」(丢了反应的因果位) |
| 标签/污名 | 社会反应打上的贬值印记 | 问「谁贴的、贴在哪个身份上、折扣几何」 | Becker 1963;Goffman 1963 | 当个人感受用(标签是关系与制度的事) |
| 职业声望 | 职业在社会评价序列中的位置 | 声望量表(NORC 传统);跨社会比较 | Treiman 1977 | 与「收入」混同(声望是独立维度,教师高收入中) |
| 代际流动 | 子代位置对父代位置的依赖强度 | 流动表:边际(结构)×关联(继承)分开读 | Sorokin 1927;Goodman 1979 | 用「比例」答「流动」(实验幕一:边际是盲的) |
| 社区 | 地域/关系双重边界上的共同体 | 问边界(谁在内)、问效能(谁站出来) | Tönnies 1887;Sampson 1997 | 当「小区」用(丢了关系与效能面) |
| 集体效能 | 社区实现公共目标的凝聚力(信任+干预意愿) | 三问量表:认识/干预/站出来 | Sampson 1997 | 当「氛围好」用(它有预测力,压过贫困率) |
| 弱势群体 | 在结构位置上承受系统性不利的人群 | 问不利来自哪个结构(市场/制度/关系) | 政策-学术合成词 | 当固定名单用(丢了结构成因与交叉性) |
| 干预(处理) | 有意施加的改变及其可归因效应 | 剂量×单位×对照(因果三件套) | 评估研究传统 | 当「开展活动」用(无对照的干预是叙事不是处理) |
| 社会诊断 | 对个案处境的社会性判断 | 环境-资源-关系的系统记录 | Richmond 1917 | 当心理评估用(社会诊断看处境不看内心) |
| 失范/紧张 | 目标与制度化手段的断裂 | 五种适应类型核对(顺应/创新/仪式/退隐/反叛) | Durkheim 1897;Merton 1938 | 当「没规矩」用(失范是结构断裂的派生状态) |

**构念的生存法则**:一个好术语要过三关——**分布关**(说得清分母
与基准)、**机制关**(哪条链在传动)、**对照关**(和「没有这个
机制的世界」怎么区分)。「标签」三关全过(幕三给了可算版);
「弱势群体」常在第一关就松(名单化);「社会问题」的第二关
(建构机制)至今是深水区(00 §二之争)。

## 二、第二栏:应用量——这门学科的语法是「分母×暴露×剂量」

**先答为什么**:应用社会学的一切定量努力都在回答同一个问题——
**把「问题有多严重、为什么、怎么办」写成什么,才能算?**答案收敛
为三类量:**分布量**(发生率/患病率/流动率)、**暴露量**(谁在
什么里泡了多久)、**剂量量**(干预给了多少、溢出多远)。核心
应用量表:

| 量 | 读法 | 在哪台机器上 | 语法角色 |
|----|------|------------|---------|
| 发生率 incidence | 新发病例/人·时 | 医学支/问题支 | 问题的流速(分母是风险集) |
| 患病率 prevalence | 现存病例/总人口 | 医学支 | 问题的存量(受治疗与病程影响,≠严重度) |
| 暴露率/暴露量 | 处于某环境的比例/强度×时长 | 医学/环境/城市支 | 一切「环境作为自变量」的底账 |
| 干预剂量 dose | 施加的单位量×保真度 | 评估/社工 | 「做了」与「做足」的分界(低剂量试点≠无效) |
| 继承率/流动率 | 流动表对角/非对角占比 | 分层支(实验幕一) | 开放度的两张脸(边际看不见) |
| 结构/循环流动 | 边际变动驱动的/关联变动驱动的流动 | 分层支 | 「职位变多」与「规则变松」分开记账 |
| 直接效应 τ / 溢出 θ | 受治者自身所得/邻居沾光所得 | 评估(实验幕二) | 尺子的两条刻度(单位对层才读得出) |
| 再犯率/累犯 | 释放/被捕后再犯的比例与速度 | 犯罪支(实验幕三) | 反应回流的温度计(条件窗口必须声明) |
| 瞄准率/漏保率/错保率 | 应保尽保中的命中/遗漏/误中 | 保障支 | 再分配机器的质检指标 |
| 集体效能分 | 三问量表的社区均值 | 社区支 | 压过贫困率的预测变量 |
| 声望分/SEI | 职业的评价序/社会经济指数 | 职业支 | 一切职业比较的公用坐标 |

**应用量的四条语法纪律**(这门学科不同于报表汇编的地方):

1. **分母声明**:任何率先钉死风险集——再犯率的分母是「释放者」
   还是「被捕者」?患病率的分母含不含已愈者?分母一换,数字就换
   一个世界;不写分母的率是修辞。
2. **时序纪律**:暴露必须在结果之前(回忆偏差与反向因果是应用
   数据的头号陷阱);横截面数据答不了「为什么」,只能答「什么样」。
3. **层级对齐**:量的层级要与断言的层级同层——社区干预拿个体当
   尺(幕二)、用群体均值下个体断言(区群谬误)都是拿错尺的变体。
4. **对照纪律**:剂量必须有对照才成其为处理——「试点成效」四字
   要拆开问:与谁比?比的单位是什么?没有对照的剂量是活动量,
   不是效应量。

## 三、第三栏:话语迁移——四个词如何在政策话语中变形

**先答为什么**:这门学科的词有一半活在政策与行政语言里——社会
问题、弱势群体、社区营造、代际流动——但每迁移一次,结构内容就
蒸发一点。迁移不是坏事(学科的影响力正在于此),**危险的是带着
指标口音的变脸**。高发迁移表:

| 学科词 | 政策/行政话语中的化身 | 蒸发掉的结构内容 | 变脸警报 |
|--------|--------------------|----------------|---------|
| **社会问题** | 「负面清单」「整治对象」「痛点」 | 双焦里的建构面:问题要被宣称才成为问题(议程竞争/道德恐慌);条件论只剩「客观指标」一焦 | 清单化把「什么算问题」的决定权悄悄交给制表人;同一伤害,不进清单就不存在——宣称活动的分析整个消失 |
| **弱势群体** | 「救助对象」「补贴名单」「重点人群」 | 结构成因:弱势来自市场/制度/关系的系统性位置,不是人群的固有属性;交叉性(多重位置的叠加)被名单压平 | 名单化把动态结构冻成静态身份:「妇女+老人+农村+残疾」四张名单发四份补贴,交叉位置的人反而漏网;「为什么弱势」的政策追问(改结构)让位于「谁在名单」的操作追问(补个人) |
| **社区营造** | 「搞活动」「社区微更新」「网格化」 | 权力面与效能面:营造的原义是居民自组织能力的培育(决策权在社区),不是行政供给的活动量 | 用「活动场次」考核社区营造,恰是反营造:办的越多,自组织越依赖、越萎缩;集体效能(谁站出来)在活动报表上一格都看不到 |
| **代际流动** | 「寒门难出贵子」「阶层固化」「拼爹」 | 边际与关联的分解:「固化」混说了职位结构变动(边际)与继承规则变严(关联);实验幕一:同边际可藏不同开放度 | 把「比例」当「流动」读的政策会把药开错:扩招(动边际)治不了继承(关联);骂「拼爹」骂的是关联,数据里常是边际在动 |
| 发生率/患病率 | 「XX 率上升」 | 分母与流速/存量的区分 | 流速升存量稳(治疗延长生命)被读成「问题恶化」;分母换了口径的纵向比较是数字游戏 |
| 循证/有效 | 「科学证明有效」 | 对照与剂量的设计(幕二的尺子) | 无对照的「成效汇报」借「循证」之名;平台 A/B 实验的有效外推到别处,抽屉里没有代表性审计 |

**一句话用法**:写政策论述引用学科词时,先做**往返检验**——把
行政句翻回应用量(它的分母/暴露/剂量/对照各是什么),再翻出去;
翻不回来的那句,删掉。这是 03 章结构卡在写作层的最小应用。

## 四、规范化:术语对译与国际接轨

学科词从英语学术史来,对译表是读国际文献的最低装备:

| 原文 | 通行中译 | 易错点 |
|-----|---------|--------|
| applied sociology | 应用社会学 | ≠「实用主义社会学」;指问题域为分析单位的分支 |
| social problem | 社会问题 | 双焦:objective condition + subjective definition |
| sick role | 病人角色 | 制度安排,非患者心理 |
| primary/secondary deviance | 初级/次级越轨 | 分界是反应事件,不是次数 |
| labeling / stigma | 标签/污名 | Becker 的标签是过程;Goffman 的污名是属性折扣 |
| occupational prestige | 职业声望 | 与收入、教育并立的独立维度 |
| social mobility | 社会流动 | 结构流动(structural)与循环流动(circulation)分开 |
| status attainment | 地位获得 | Blau-Duncan 路径图的专名 |
| collective efficacy | 集体效能 | ≠社区凝聚力口号;有量表有预测力 |
| vulnerable groups | 弱势群体 | 政策合成词;学术侧配 marginalization(边缘化) |
| community building/ machizukuri | 社区营造 | 日式汉字词的中文借用;原义是自组织培育 |
| intervention / treatment | 干预/处理 | 有对照才算处理(evaluation 语境) |
| anomie / strain | 失范/紧张 | Durkheim 的规范真空 vs Merton 的手段-目标断裂 |
| fundamental causes | 根本原因 | Link-Phelan 专名:灵活资源再造就梯度 |
| targeting / universalism | 瞄准制/普惠制 | 保障支的对立轴(再分配悖论的舞台) |
| evidence-based practice | 循证实践 | 好心不算数,对照才算数 |

## 五、一门学科,三种口音并存(语言的社会学)

同一现象——「某个社区少年犯罪高发」——三种口音给出三种处方:

| 口音 | 诊断 | 处方倾向 |
|------|------|---------|
| 分布口音(流行病学式) | 率高在哪、暴露什么、梯度多陡 | 挪分布(Rose):改暴露环境,别逐个治 |
| 机制口音(过程式) | 解组/标签/紧张,哪条链在传动 | 断链:集体效能、反应去标签、机会结构 |
| 建构口音(宣称式) | 谁在定义问题、议程怎么赢 | 修程序:参与的门槛、叙事的竞争 |

**三种口音都对一部分**;但同一份论证里混用口音而不声明,等于把
三层的假设账单开给同一段论述——先定主导口音,再借译(00 §二
「条件论 vs 建构论」之争在语言层的对应物)。

## ✨ 美之时刻(彩蛋第 5 枚:再分配悖论的往返之美)

✨ **美之时刻 5:「给穷人的越多,穷人得到的越少」押回瞄准率**
(极简)
Korpi-Palme 的再分配悖论:把转移支付瞄准低收入者的国家,再分配
后的贫困与不平等反而常常更糟——因为瞄准制拆掉了中产阶级与福利
的利害同盟,盘子(政治上可持续的转移总额)缩水;普惠制留住同盟,
盘子大,穷人从大盘子里的绝对所得反而更多。把口号押回应用量:
瞄准率↑→漏保率↓(质检指标改善)与盘子↓(政治指标恶化)同时
发生——**质检指标与政治指标可以反向走**。为什么美:**它示范了
应用量语法的最高纪律:同一个干预,在不同层(项目层/体制层)有
两本账,只报一本的是汇报,两本都报的才是研究**。亲历:给你身边
的一项「精准识别」政策找它的第二本账(✍️练习 1)。

## ✍️ 练习

1. ✋ 给一项「精准识别/应保尽保」政策找第二本账:瞄准率改善的
   同时,盘子(覆盖面/政治支持)怎么走了?——美之时刻 5 的亲历版
2. ✋ 用 §三 迁移表体检一份政府工作报告:数它用了几个学科词
   (社会问题/弱势群体/社区营造/循证),每个蒸发了什么
3. ✋ 给「阶层固化」写分解:你所在社会的流动表里,边际在动还是
   关联在动?各举一条证据——幕一的「两张面孔」在公共议题上的
   应用
4. ✋ 把三种口音各写一句「这个社区犯罪为什么高」,标注每句隐含
   的假设与账单;再检查本地政策用的是哪种口音

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:分母之眼**——听到任何借自应用社会学的大词
(社会问题/弱势群体/社区营造/代际流动/循证有效),先做往返检验:
它的分母是什么(谁的率)、暴露在什么里(多久的什么)、剂量多少
(与谁比)、层级对齐没有(干预单位=测量单位?)。写自己的论述时,
先声明主导口音(分布/机制/建构),再借译。

下一章 [`03-可构造与结构.md`](03-可构造与结构.md)——这门学科哪些
对象严格可构造(流动表与对数线性可以,「社会问题」的建构很难),
以及一段应用研究怎么被压进三张结构卡(应用诊断卡/干预设计卡/
评估卡)。
