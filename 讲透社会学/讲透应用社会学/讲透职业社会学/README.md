# 讲透职业社会学 · 干什么活,意味着什么——声望、专业与职业结构

> **定位句**:这支管**职业的结构与意义**:职业是分层社会的主轴——谁干什么活、干什么活在社会天平上值多少(声望)、什么活能自己立规矩(专业主义)、这堆活的构成怎么随时代换血(职业结构变迁)。家庭支管你从哪来,本支管你靠什么活。
> **GB/T 支**(8402711 职业社会学)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:邓肯 SEI 社会经济指数(1961,职业→教育+收入的回归映射);Treiman《职业声望的比较研究》(1977,60+ 社会的标准化比较);Carr-Saunders《专业》(1933,专业化通说起点);Freidson《职业主权》(1970,医学的专业支配);Larson《专业主义的兴起》(1977,专业=市场封闭的项目);Lauderdale? no——略;中国职业声望与阶层研究(通说)。
- **因什么问题**:①阶级太粗,职业是分层的实际零件(图式要落到职业表)②为什么有的职业自带尊敬(声望从哪来)③为什么有的职业能自己定规矩(专业为何权力)。

## 核心问题

**已解决(通说)**:职业声望跨社会高度一致(Treiman:结构位置论——分工中的权力与知识位置普遍,故评价普遍);专业化的要件(系统的理论知识+职业共同体+社会承认与服务取向);职业性别隔离的刻度化(相异指数 D)。分层支的阶级图式(EGP/Wright)最终都要落成职业编码——本支是分层的**零件厂**。

**未解决/深水区**:平台零工算不算职业(分类学正在重写——「职业」的边界随雇佣形态松动);声望的长期漂移(稳定还是随技术声誉波动);专业主义的政治(Larson:专业是靠执照与教育垄断完成的**市场封闭项目**,公共形象与私人利益的张力);声望测量的跨社会等价性。

## ✨ 这支最美的一个事实

**各国职业声望的排序惊人一致(Treiman 1977)**。把大学教授、法官、医生、工程师、教师、店主、农夫、门房、清洁工排进声望量表,横跨制度、意识形态与发展水平,排序高度趋同。为什么:声望不是文化的偏好,是社会分工结构的**回声**——凡是复杂分工的社会,权力与知识的位置相似,位置的评价便相似。此后一切跨国分层比较都靠这张公用坐标尺(换制度不换尺);个人的「职业尊严」焦虑,一半是在跟一张看不见的全球量表对表。亲历:给你的职业在你朋友圈里做个声望排序,再与 Treiman 总表对表(✍️)。

## 假设与依赖
