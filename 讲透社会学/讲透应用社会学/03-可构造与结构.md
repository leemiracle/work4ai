# 03 · 可构造与结构:哪些应用对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:应用社会学的对象沿一条**可构造谱系**排开——
> 机制骨架端**严格可构造**(流动表的边际-关联分解/干预的溢出
> 动力学/标签的反馈回路:写得出、跑得动、断言得了,实验三律全程
> 可跑),设计的中间段**半可构造**(随机化方案与评估量可结构化,
> 但依从、溢出形状与代表性含量化判断),解释的经验实在端
> **几乎不可构造**("这个问题因为社会建构才成为问题"——只有
> 取证通道,没有装配学);全谱系共享三条结构引擎:**流动引擎**
> (边际与关联是两个自由度)、**溢出引擎**(干预单位与测量单位
> 必须同层)、**反馈引擎**(反应进入被反应者的后续行为);而一段
> 应用研究可以被压进三张**结构卡**(应用诊断卡/干预设计卡/评估卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
流动表(IPF/对数线性) ── 溢出设计仿真 ── 标签回路仿真 ── 评估量管线 ── 问题界定的社会判断 ── "为何成为问题"的断言
  │                                                                │
严格可构造(可断言)                                            几乎不可构造(只有取证通道)
  └── 写得出、跑得动、能过 assert                              └── 断言=机制+证据+对照的合取,装配学缺席
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:
流动表的语义是"边际=结构,关联=继承,二者独立可调"(Goodman
1979),输入输出明确,跑一万次都是它;而"青少年网游沉迷成为社会
问题是因为建构"的语义要先问**取证**——谁在宣称、议程怎么竞争、
伤害的测量怎么算——构造学在那里让位给证据学。本章先盘家底,再看
三条结构引擎,最后把一段应用研究压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **流动表(边际×关联)** | 边际向量+继承乘子 φ+IPF 钉边际→5×5 概率表 | 低(幕一全程可跑) | 模型世界不是任何真实社会;观测表混入年龄/时期构成 |
| **溢出设计仿真** | 网络拓扑+θ+两种随机化→估计量分布 | 低(幕二) | 环网络是特例;真实溢出有饱和与衰减,形状是设计难题 |
| **标签反馈回路** | q₀/p/λ/就业乘子+轮次→再犯率与自锁 | 低(幕三) | 观察数据里 λ 与混杂分不开;模型只证机制可能,不证其在场 |
| **抽样与 G² 检验** | 多项抽样+对数似然比→独立性/拟合检验 | 低(幕一③) | 检验拒绝的是模型不是世界;选择校正(幕三底色)是活教材 |
| **评估量管线** | 对照结构+分母声明+剂量登记→效应量表 | 中 | 依从偏差/霍桑效应/外推有效性;准实验设计含手工裁量 |
| **声望/阶级图式编码** | 职业分类→图式编码方案 | 中 | 分类即理论(平台零工算什么职业);跨社会等价性未合龙 |
| **宣称活动的测量** | 议程时点/媒体框数/组织进入的编码 | 中高 | 编码方案即立场;「客观伤害」与「宣称」的账难合记 |
| **"为何成为问题"的断言** | 没有装配学,只有证据链的合取记账 | **不可构造** | "因建构而成问题"=机制+证据+对照的合取,断言永远只有部分可构造 |

**反直觉发现(本章铁律)**:**最能跑的对象离政策最远,离政策最近
的断言恰好跑不了**。流动表跑得飞快,断言只是"在此机制**下**边际
相同的两社会开放度可差 0.39"(幕一);而"把低保瞄准率提到 95%
会改善贫困"这个真断言,落在谱系右端——它要的是依从数据+溢出
审计+对照的排除,模型只是三分之一。用左端的流畅冒充右端的断言,
是应用研究被批评"跑模型交差"的总根源——正确的姿势是**合取
记账**:机制骨架(可构造)+设计证据(半可构造)+备择排除
(取证),三条都齐才升格为政策命题。

## 二、结构引擎 1:流动引擎(边际与关联是两个自由度)

**直觉图像**:一个分层社会有两张脸——结构(各阶级比例)与开放
(出身对获得的钳制);两张脸可以独立变化,流动表是它们共同的
容器。

- **数学化身**:P(子=j|父=i)=marg_j·关联修正;对角乘子 φ 加
  IPF 钉边际——边际动结构,φ 动开放;独立世界继承率=Σmᵢ²。
- **三条刚性**(幕一的数值化身):
  1. **两脸独立**:φ 从 1 扫到 8,继承率 0.242→0.692 单调爬,
     边际偏差全程 <1e-9。
  2. **边际是盲的**:抽样 2500 对,对角差 0.388=30 倍标准误,
     样本列边际最大差 0.016 在噪声内。
  3. **检验的分野**:同边际下,G² 一个 17.8(不拒独立)一个
     1790(爆表)——检验量的是关联,不是结构。
- **刚性从哪来**:参数语义有限确定、断言能过 assert——谱系左端
  的全部刚性。软的地方在**经验根据**(真实社会的 φ 多大、怎么随
  制度变),引擎解决推演,不解决测量。

## 三、结构引擎 2:溢出引擎(干预单位与测量单位必须同层)

**直觉图像**:干预的效应有两份——直接效应(给到本人)与溢出
(沾到邻居);个体随机化把两份在组间平均掉,只量到第一份。

- **数学化身**:Y_i=τ·T_i+θτ·(受治邻居数)+ε;总效应=τ(1+2θ)
  (环网络);个体随机化期望=τ,低估量=2θτ。
- **三个标准断言**(幕二实拍):
  1. **无溢出无原罪**:θ=0 时个体随机化 0.999、社区随机化
     1.010,两把尺同一读数。
  2. **低估单调**:低估量 0.001/0.307/0.617/1.037 随 θ 单调增,
     与 2θτ 吻合;θ=0.5 时个体估计只捕获总效应 48%。
  3. **同层即复原**:社区随机化全程命中总效应(偏差<0.06)
     ——尺子对层,读数复原。
- **刚性从哪来**:设计-估计量的映射语义确定,断言锚在期望与
  单调性上。软的地方:真实网络非环、溢出有饱和;**溢出的形状是
  设计参数**,不是常数(01 章判读要点 3 的练习正是此处)。

## 四、结构引擎 3:反馈引擎(反应进入被反应者的后续行为)

**直觉图像**:社会反应不是外生的天罚,是内生的投资——惩罚在它
想消灭的行为里入了股(标签→就业↓→再犯倾向↑→再被捕)。

- **数学化身**:q←min(q_cap, q·λ)(每次被捕);就业←就业×0.6;
  两环境仅 λ 不同,同 q₀ 同 p。
- **三个标准断言**(幕三实拍):
  1. **自锁**:高标签(λ=3.2)vs 低标签(1.3):被捕过者末十轮
     再越轨率 0.893 vs 0.453;被捕≥3 次者 1.00。
  2. **回流**:累计越轨人均 11.2 vs 2.1(×5.3)——惩罚的重量以
     再犯回流。
  3. **对照无差**:λ=1 时两环境差 0.0077(噪声内);底色组两环境
     同值(0.137/0.143≈选择校正理论 0.142)——差异全由反馈制造。
- **刚性从哪来**:反馈系统的语义有限确定,断言锚在条件对比上
  (有反馈 vs 无反馈)。软的地方:λ 在观察数据中与混杂不可分
  ——**模型证明机制可能,不证明其在场**;在场性要靠准实验
  (01 章主线 A 的封禁回流是候选)。

## 五、结构卡 schema:把一段应用研究压进三张卡

**先答为什么**:应用研究的难点在"三段分离"——诊断、干预、评估
散落在立项书、总结报告与审计报告里,互相不见面。结构卡是**有限
字段的压缩格式**:字段固定、填空即可复用、可比可查可补(这是
"可构造"在研究层的对应物:卡片本身严格可构造,实验三律就是三张
卡的数值实例)。

### 卡 1:应用诊断卡(问题怎么分布、机制在哪)

```
【应用诊断卡】
问题与口径:________(什么问题/怎么操作化/分母是谁)
分布量:发生率 __ 患病率 __ 梯度(按什么分层)__ __
暴露量:暴露定义 ____ 暴露率 __ 强度×时长 ____
机制候选(最多三条):①____ ②____ ③____
  各自的断言层级:个体/邻里/组织/体制 ____
口音声明:主导口音=分布/机制/建构 ____
对照面:和谁比(时间/地区/人群)____ 备择解释 ____
数据与代表性:来源 ____ 抽样框排除谁 ____
升维检查:个人烦恼→公共问题的桥是什么 ____
```

样例(已填,方向级):问题=某市青年失业。口径=16-24 岁非在校未
就业/分母=同龄常住人口;分布量=发生率 8%、按父职分层的梯度明显;
暴露量=毕业院校层次×居住地的产业结构;机制候选:①技能错配
(个体层)②邻里网络的信息隔离(邻里层)③行业周期(体制层);
口音=分布为主、机制为辅;对照面=与五年前比(含周期警告)、与
相邻市比;数据=登记数据+抽样调查,抽样框排除灵活就业者
(**代表性暗礁**);升维检查:个人烦恼(找不到工作)→公共问题
(毕业生供给与产业结构的错位)的桥=规模与梯度。**判读**:这张卡
的作用是把「青年失业很严重」拆成可断言的三层,防止政策在个体层
(培训)治疗体制层的病。

### 卡 2:干预设计卡(改变什么、怎么算改变)

```
【干预设计卡】
干预与理论靶点:________(做什么/打在哪条机制上)
干预单位:个体/家庭/社区/组织 ____ 测量单位:____
  同层吗:____ 不同层的理由与代价 ____
剂量:单位量 ____ 保真度怎么保 ____
直接效应与溢出:τ 怎么量 ____ θ 的先验与形状(局部/全局,线性/饱和)____
随机化:个体/簇/阶梯 ____ 分层变量 ____
  若不能随机化:准实验设计+断点/匹配 ____
依从与污染:不依从怎么登记 ____ 对照组的沾染 ____
伦理与红线:受益/风险/退出权 ____ 敏感结论的处理 ____
预注册的假设:主结果 ____ 次结果 ____ 最小重要差 ____
```

样例(已填,方向级;幕二的世界):干预=社区健康促进(社区宣教+
环境改造);理论靶点=健康行为的邻里扩散;单位=社区(测量单位
同层=社区);剂量=每社区 12 场活动+3 处环境改造,保真度=督导
抽查;溢出=θ 先验 0.2-0.4(人际网络,局部);随机化=社区簇
随机化,按基线健康水平分层;依从=出席率登记,对照社区的自然
暴露监测;预注册主结果=社区健康指标均值差。**判读**:若立项书
写的是「在各社区内随机选半数居民参加」(个体随机化),此卡立即
报警——尺子错层,评估注定量不到总效应(幕二:低估 2θτ)。

### 卡 3:评估卡(效果怎么量、量错了会怎样)

```
【评估卡】
评估对象与阶段:________(哪项干预/过程·结果·成本效果的哪一段)
对照结构:对照组是谁 ____ 怎么构造的 ____
效应量:主指标 ____ 分母 ____ 时点 ____
  尺子对层检查:干预单位=测量单位 ____
溢出审计:处理组对对照的沾染怎么测 ____ 低估量级估计 ____
第二本账:项目层指标之外,盘子/政治/生态层怎么走 ____
外推有效性:别处能复制吗——剂量的边界条件 ____
失败的价值:无效结果登记在哪 ____
结论的措辞边界:能说什么/不能说什么(因果 vs 相关)____
```

样例(已填,方向级):评估=低保瞄准改革两年评估。阶段=结果评估;
对照=未改革县(匹配构造);效应量=漏保率变化,分母=应保人口;
尺子对层=改革在县层、测量在户层——**需户层聚类标准误**;溢出
审计=改革县的邻里示范效应;第二本账=瞄准率↑的同时覆盖盘子与
行政成本(02 章再分配悖数的项目版);外推=高流动县的边界条件;
失败登记=无(暗礁:只报成功的评估生态)。**判读**:这张卡把
「成效 95%」拆成三问——与谁比、什么层、第二本账呢;三问答全,
「成效」二字才有含义。

**判定流程**(把一个主张钉到谱系上):

```
该主张的核心对象能写成流动表、溢出设计或反馈回路吗?
  ├─ 能,且语义有限确定 ──────▶ 左端:直接实现+转码(04 章走廊)+对照
  ├─ 能一半(设计可结构化,含量化判断)─▶ 中段:卡片化(卡 2/3)+设计显式
  └─ 不能(问题界定/建构的经验实在)─▶ 右端:合取记账,禁止"模型即证明"
```

## 六、谱系×引擎×组总表(把全家族钉在一张图上)

| 组(支) | 谱系位置 | 主引擎 | 可构造等级 |
|--------|---------|--------|-----------|
| 分层支(8402764) | 左端(流动表)到右端(图式之争) | 流动引擎 | 分裂:表可跑,图式靠编码 |
| 城乡与社区组(城市/农村/环境/社区) | 中段为主(环境暴露与社区效能的测量) | 溢出引擎(邻里即溢出面) | 中:卡片化+设计显式 |
| 越轨与问题组(犯罪/越轨/问题/妇女/种族) | 左端(标签回路)到右端(建构断言) | 反馈引擎 | 分裂:回路可跑,建构靠取证 |
| 劳动与职业组(职业/工业) | 中段(声望编码/车间观测) | 流动引擎(职业即格子) | 中:编码方案显式 |
| 保障与福祉组(医学/保障/社工) | 中段(评估管线)到右端(循证的边界) | 溢出引擎+反馈引擎 | 分裂:效应量可算,「何为好生活」不可算 |

**读表法**:一个组的"可构造纯度"决定它的转码方式(04 章)——
机制骨架走计算,设计走管线,建构断言永远走合取记账。**没有哪个
组全家可构造,也没有哪个组全家不可构造**。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——把一个政策装进上衣口袋**(极简)
诊断卡验靶(分布、暴露、机制层级),干预设计卡验尺(单位对层、
剂量、溢出),评估卡验收(对照、第二本账、外推边界)。为什么
美:**它把"读懂应用研究"变成"填得出卡"**——可复核性从同行
善意移进字段纪律;一张填得出的「第二本账:空」,比十页「成效
显著」的总结更诚实。亲历:给你身边的一项政策填三张卡(✍️练习
1),填不出的格子就是它的裸泳清单。
