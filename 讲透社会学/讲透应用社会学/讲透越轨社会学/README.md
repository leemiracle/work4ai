# 讲透越轨社会学 · 规则与越界——失范、标签与次级越轨

> **定位句**:这支管**规则与越界的通论**:越轨的正常性(没有越轨的社会不存在)、失范的类型学(手段-目标断裂的五种适应)、标签与污名的过程(越轨是社会反应的产物)、初级越轨到次级越轨的反馈。犯罪支管刑法圈内的分布,本支管一切规则的越界与反应。
> **GB/T 支**(8402751 越轨社会学)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:涂尔干《社会学方法的规则》(1895,越轨的正常性)与《自杀论》(1897,失范:规范真空下的比率波动);默顿〈社会结构与失范〉(1938,五种适应:顺应/创新/仪式/退隐/反叛);莱默特《社会病理学》(1951,初级/次级越轨之分);贝克尔《局外人》(1963,标签:越轨的被制造);戈夫曼《污名》(1963,受损身份的管理:掩饰/蒙混/坦白);科恩《民间魔鬼与道德恐慌》(1972,越轨放大螺旋——与社会问题支共享);Gusfield《饮酒问题与所有权文化》1963?——(符号十字军,通说);数字越轨(Chen 2025 综述,检索校准 2026-09-07)。
- **因什么问题**:①为什么越轨是正常的(功能之问)②为什么「人人想成功」的社会越轨多(结构之问)③为什么小小的越界会滚成身份(过程之问)。

## 核心问题

**已解决(通说)**:越轨的正常性(犯罪存在于一切社会;边界靠越界的显影才可见——改革者也常是越轨者);失范类型学(创新=接受目标拒绝手段——财产犯罪的社会学正名;退隐=都拒绝——漂泊者/瘾者;反叛=换一套目标与手段);标签的因果位(初级越轨人人有份,次级越轨是**反应的产物**:被抓→身份贬值→常规通道关闭→越轨生涯);污名的身份管理学(受污名的信息控制是全职劳动)。

**未解决/深水区**:标签的净效应识别(反应的放大 vs 威慑的抑制,观察数据混杂——[实验幕三](../experiments/mobility_spillover_label.py)给出可算分解:λ>1 自锁、λ=1 无差,但真实 λ 未必>1);数字平台的规则执行(封禁=新标签;平台既是规则执行者又是放大器,01 章主线 A,检索校准 2026-09-07);越轨的「健康剂量」(多少越轨是边界仪式所需,多少是社会成本)。

## ✨ 这支最美的一个事实

**犯罪是正常的(涂尔干 1895)**。惊世骇俗的第一句:设想一个人人都是圣徒的社会——那里对最小瑕疵的不容忍会让瑕疵本身成为「犯罪」,于是犯罪照常存在。为什么:①越界行为是边界的显影液——社会靠对越轨的集体反应确认规则在哪②越轨的正常性不等于可取性,涂尔干的私货藏在第二层:犯罪率的**异常波动**(飙升或归零)才是病征——飙升=失范(规范真空),归零=极权(僵死)。**一个概念(失范)装下了两类灾难:规则的崩溃与规则的完美**。亲历:找一条你所在群体「人人轻微违反、无人当真」的规则,想象它突然零容忍执行——群体会更好还是更僵(✍️)。

## 假设与代价

- 买入越轨正常论:它解释存在性不解释分布(为什么此地多彼地少要另请失范类型学与解组论)
- 买入失范类型学:类型是理想型,真实行为常跨型;「美国中心」(目标=金钱成功的假定)是历史账单
- 买入标签理论:放大机制的条件(λ>1)在经验上不总成立;轻罪的重罚可能只有威慑没有标签(净效应未定)
