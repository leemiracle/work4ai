# 讲透犯罪社会学 · 犯罪率钉在地方——解组、交往与紧张

> **定位句**:这支管**犯罪的社会分布与解释**:为什么犯罪在空间上钉住某些邻里(社会解组)、在人际上怎么传(不同交往)、在结构上从哪来(紧张理论)、在生命历程上怎么走(年龄-犯罪曲线)。**红线:本支只写犯罪的社会学解释与通说政策评估,不写任何作案/侦查技术细节。**
> **GB/T 支**(8402747 犯罪社会学)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:凯特勒与葛雷的道德统计(19 世纪初,犯罪率的规律性——社会事实先于个体);肖-麦凯《少年犯罪区的社会因素》(1942,芝加哥过渡带六十年犯罪率的邻里持久性);萨瑟兰「不同交往」(1939,犯罪行为在亲密群体中习得:技术与动机一并习得——通说口径,不展开技术);默顿〈社会结构与失范〉(1938,紧张:目标与制度化手段的断裂);赫希《少年犯罪的原因》(1969,社会控制:依恋/承诺/卷入/信念四社会键);赫希-戈特弗雷德森〈年龄与犯罪〉(1983,年龄-犯罪曲线);威尔逊-凯林〈破窗〉(1982,通说+争议:秩序混乱与犯罪的因果——Sampson-Raudenbush 的系统再评估)。
- **因什么问题**:①为什么犯罪的分布像地理(空间之问)②为什么犯罪像传染(习得之问)③为什么人人要成功而有人用非法手段(结构之问)④为什么犯罪率随年龄单边下降(生命史之问)。

## 核心问题

**已解决(通说)**:社会解组三因素(贫穷/流动人口/异质性→监管与网络稀薄→犯罪率高;率的**邻里持久性**——人换几茬率不动,是地方的属性);年龄-犯罪曲线的稳健性( prevalence 与 incidence 在青少年后期见峰后单调下降,跨时代跨社会高度一致;「不变论」与争议按通说标注);集体效能作为解组的当代中介([社区研究支](../讲透社区研究/README.md)接口);不同交往与社会控制的互补(学坏要有老师,不学坏要有牵挂)。

**未解决/深水区**:犯罪率下降之谜(1990s 美欧暴力大下降的多因竞争解释——通说综述);威慑与标签的净效应分解(惩罚的直接抑制 vs 反应的回流放大——[实验幕三](../experiments/mobility_spillover_label.py):λ 与 p 是两个参数,政策含义相反);数字侵害的新分布(网络越轨,Chen 2025 分类学,检索校准 2026-09-07);监狱人群的健康与再融入(通说评估)。

## ✨ 这支最美的一个事实

**犯罪率钉在邻里,人来人往,率不动(肖-麦凯 1942;Sampson 2012 全量续证)**。芝加哥的少年犯罪率地图几十年稳定钉在过渡带——移民换了一茬又一茬,种族与文化都换过,率不动。为什么:它把「犯罪是坏人干的事」翻成「犯罪率高是**地方**的属性」——解组的邻里(贫困+流动+异质)缺乏监管孩子的非正式网络,谁搬进去都一样难;此后的邻里政策(集体效能/社区建设)全部押注在这张地图上。**个人风险的社会学第一课:先看 ZIP code,再看 rap sheet**(邮编比前科更说明问题)。亲历:查你城市犯罪率最高的三个街区,五十年前它们是什么(✍️)。

## 假设与代价

- 买入解组论的邻里本位:选择效应(高危者迁入)与蔓延(问题扩散出邻)要另立账户;部分研究把持久性归因于持久贫困而非解组(通说争论)
- 买入年龄-犯罪曲线的不变性:跨社会一致性高,但水平的时段与社会差异巨大(「形状不变、高低可变」)
- 买入破窗的因果:再评估支持「秩序混乱与犯罪共变」,单向因果与警务政策的外推证据混合(通说)
- 红线纪律:一切材料止于社会学解释与政策评估,不涉技术与细节
