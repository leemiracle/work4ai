# 讲透工业社会学 · 车间里的社会——工作如何被组织,工人如何被整合

> **定位句**:这支管**车间与劳动的社会组织**:工作怎么被组织起来(技术与结构)、工人怎么被整合进生产(非正式组织与规范)、劳资之间隔着什么(工业民主与劳动过程)。职业支问「干什么活」,本支问「活怎么干、和谁一起干、谁说了算」。
> **GB/T 支**(8402714 工业社会学;GB/T 注:劳动社会学见 8407430——归入声明,劳动关系本体归劳动科学,文字提及)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:霍桑实验(1924-1932,西部电气公司;梅奥《工业文明的人的问题》1933;Roethlisberger-Dickson《管理与工人》1939)——人际关系学派的起点;Woodward《工业组织:理论与实践》(1965,技术-结构权变);富裕工人研究(Goldthorpe 等,1968-69,英格兰卢顿);Braverman《劳动与垄断资本》(1974,劳动过程论;其雇佣与劳动关系面与 8407430 交叉,本支取车间组织面);工业民主研究(通说,德国共同决定制的比较线)。
- **因什么问题**:①科学管理把人当机器,产出为何反而不稳(霍桑之问)②同样规模的企业为何结构迥异(Woodward 之问)③富裕起来之后,工人为何仍不认同工厂(卢顿之问)。

## 核心问题

**已解决(通说)**:非正式组织的生产性(班组的产出规范自己定上限——「限制班产」;群体规范压过经济激励);技术-结构权变(单件/大批量/流程生产对应不同的组织结构形态);富裕工人的工具性取向(高工资买到出勤,买不到忠诚——私人化的工具性卷入)。

**未解决/深水区**:算法调度下的车间(派单-评分把计划科搬进代码——「数字泰勒」之争;与[../../../讲透管理学/讲透管理理论/](../../../讲透管理学/讲透管理理论/README.md)01 章共用素材,检索校准 2026-09-07);工业社区的生命周期(厂兴城兴、厂衰城衰的社会继承);技能的贬值与再估值。

## ✨ 这支最美的一个事实

**照明降到月光级,产出照升(霍桑;通说口径+方法论再评估双面标注)**。照明实验本想量「光多亮干活最快」,结果照明一路降到近乎月光,女工的产出还在涨——起作用的不是灯,是**被选中、被注意、被倾听**本身。这一下把经济人模型撞出了裂缝,「人际关系」从此进入管理与社会学的词典。账单也要写明:后来的原始数据再评估对照明效应的强度提出质疑(通说的再评估线),「霍桑效应」更多是方法论警世故事(观察改变被观察者)而非稳定定律——**一个以「被观察会变」传世的发现,自己也活在被再观察的变动里**。亲历:检查你团队最近一次「试点成功」:是方案好,还是被试点这件事本身好(✍️)。

## 假设与依赖

- 买入霍桑的「注意效应」:剂量与持久性未知,且与产量规范(非正式组织)的解释有重叠——两机制常被混报
- 买入 Woodward 的技术决定论(弱版):技术在解释结构方差中占比被后续研究缩窄
- 上游依赖[组织社会学家族](../../讲透组织社会学/README.md)的科层解剖(车间是科层的最小现场);劳动关系的制度面按 GB/T 注归 8407430(文字提及)
