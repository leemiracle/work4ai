# 讲透社会问题研究 · 问题如何成为问题——条件、宣称与恐慌

> **定位句**:这支管**「问题」本身的社会学**:同一伤害为什么此地成为问题彼地不是(宣称活动)、问题有怎样的职业生涯(自然史)、媒体与道德企业怎么把焦虑加工成「民间魔鬼」(道德恐慌)。别的支问「这个问题的成因」,本支问「它凭什么算问题」。
> **GB/T 支**(8402761 社会问题研究)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:富勒-迈尔斯〈社会问题的自然史〉(1941,双焦:客观条件+社会定义);默顿-尼斯贝特编《当代社会问题》(1961,清单化建制——问题域成为可教学纲领);布鲁默〈社会问题的社会定义〉(1971,集体定义的五阶段自然史);斯佩克特-库苏斯《宣称社会问题》(1977,激进转向:问题=群体对伤害的宣称活动 claims-making);科恩《民间魔鬼与道德恐慌》(1972,mods 与 rockers 的两个海边周末如何被加工成文明危机);格斯菲尔德《符号十字军》(1963,禁酒运动作为地位政治——中产新教徒的文化攻势,通说);贝斯特(当代综合,通说)。
- **因什么问题**:①失业率与「失业问题」之间隔着什么(定义之问)②为什么危害大的可以不成问题、危害小的可以成问题(宣称之问)③恐慌的螺旋怎么转(放大之问)。

## 核心问题

**已解决(通说)**:双焦框架(条件给分布,定义给显著性——同一伤害两本账);道德恐慌的过程模型(夸大/预测/符号化/敏感化→民间魔鬼被制造→反应升级→魔鬼照剧本表演——越轨放大螺旋,与[越轨支](../讲透越轨社会学/README.md)共享机制);问题自然史的分期(觉察→宣称竞争→制度化→官僚化/消退)。

**未解决/深水区**:问题的议程竞争(一个问题挤掉另一个的零和与窗口);数字时代的恐慌节奏(平台加速:发酵以小时计——方向锚,检索校准 2026-09-07);条件论与建构论的合账(「伤害多大」与「喊得多响」的联合建模无标准方案);恐慌的善用(有些「恐慌」是真的预警——区分误报与预警的标准缺失)。

## ✨ 这支最美的一个事实

**民间魔鬼的制造(科恩 1972)**。1960 年代英国两个海边小镇的周末,mods 与 rockers 两派青年斗殴——财产损失轻微,媒体把它加工成「文明崩溃的预演」:夸张(头条的末日语言)、预测(「下个周末将更糟」)、符号化(摩托服与 hairstyles 成为魔鬼制服)、敏感化(警察与法庭加码)。结果:青年照着魔鬼剧本表演(身份被社会化进了标签), spiral 自我实现——**反应制造了它所恐惧的东西**。为什么:它给「社会问题」装上了反馈回路([实验幕三](../experiments/mobility_spillover_label.py)的同构:反应烈度 λ 是自变量);此后评估任何「整治」都要问:你在消灭问题,还是在制造魔鬼。亲历:复盘一次你亲历的舆论风暴,找出夸张/预测/符号化/敏感化四环(✍️)。

## 假设与代价

- 买入双焦:两本账常被各取一端(纯条件论的报表与纯建构论的叙事都只报一半)
