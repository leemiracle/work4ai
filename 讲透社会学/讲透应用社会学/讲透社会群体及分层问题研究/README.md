# 讲透社会群体及分层问题研究 · 谁得到什么,凭什么,传给谁——分层与流动

> **定位句**:这支是家族主轴之一,管**分层与流动的正主**:不平等怎么被安排(功能论与冲突论之争)、位置怎么定义(阶级图式与资本三态)、地位怎么获得(地位获得的路径图)、位置怎么代际传递(流动表的两张面孔)。一切应用问题(教育/职业/健康/居住)的分布面,最后都在这张桌子上对账。
> **GB/T 支·主轴**(8402764 社会群体及分层问题研究)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:马克思(阶级=对生产资料的关系);韦伯(阶级/地位/政党三重分层:市场机会、声望生活方式、权力);索罗金《社会流动》(1927,流动作为升降的循环——分层研究的第一部专著);戴维斯-摩尔〈分层的一些原则〉(1945,功能论:位置有差→报酬有差→激励才能配置)与图明〈对戴维斯-摩尔范式的批判〉(1953,谁定义「重要」?继承早已破坏激励逻辑);布劳-邓肯《美国职业结构》(1967,地位获得的路径分析——父亲教育→本人教育→初职→现职);古德曼对数线性流动表模型(1979,边际与关联的分解);戈德索普《现代社会中的阶级流动》(1980,EGP 图式与流动比较);赖特《阶级结构》(1985,剥削的多维);布迪厄《区分》(1984,资本三态:经济/文化/社会;品味作为阶级指纹);威斯康星模型(重要他人的中介,通说);CSS 时代的流动重测(01 章,检索校准 2026-09-07)。
- **因什么问题**:①不平等为什么存在、该不该存在(功能之争)②阶级怎么量(图式之争)③一个人的位置多少是挣的、多少是继承的(获得之问)④社会开放还是封闭(流动之问)。

## 核心问题

**已解决(通说)**:功能论与冲突论的僵局(功能论解释分层的普遍性,冲突论解释分层的具体形态与继承;图明的三连问——重要性由谁定义/报酬与重要性的相关从何保证/继承如何破坏激励——至今是试金石);地位获得的基本模型(教育的中介效应远大于父职直接效应——学校是主传送带);流动表的边际-关联分解(结构流动 vs 循环流动:职位结构变动造成的移动与继承规则松动造成的移动必须分开记账——古德曼);阶级图式两大家的分工(EGP 雇佣关系论 vs 赖特剥削论,信度与效度各有战场)。

**未解决/深水区**:数字时代的流动重测(平台零工的阶级位置:无产者的生产资料是自己的手机?——分类学在重写,01 章);机会公平的测量(流量(流动率)与存量(差距)可以反向——「高流动+高不平等」与「低流动+低不平等」都稳定存在,哪个更公平是规范问题);交叉性分层(单轴图式的极限——与[妇女支](../讲透妇女问题研究/README.md)、[种族支](../讲透种族问题研究/README.md)合账);教育是「伟大平等器」还是「大分流」(与[教育社会学](../../../讲透教育学/讲透教育社会学/README.md)接口,GB/T 归 88024 声明);财富 vs 收入的分层(继承的存量面)。

## ✨ 这支最美的一个事实

**品味是阶级的指纹(布迪厄《区分》1984)**。不必问收入——问你喜欢什么音乐、读什么报纸、客厅挂不挂画、怎么看「吃饭就是为了吃饱」:答案排出的序列与阶级结构惊人同构。为什么:布迪厄把继承翻出了新花样——**经济资本换成文化资本,继承就穿上了「才华」与「教养」的外衣**:学校声称奖励天赋,实际上部分在兑现童年投资的利息;品味(惯习)是最诚实的阶级证件,因为持有者自己都以为那是「我的个性」。三层资本(经济/文化/社会)加转换率,成了此后一切「文化再生产」研究的总机。亲历:列出你三项最理直气壮的品味,追溯每一项的获得成本(谁付的)(✍️)。

## 假设与代价

- 买入功能论的激励逻辑:图明三问未解;「报酬与重要性」的相关在数据上时有时无
- 买入地位获得的路径模型:路径是加性的、职业可序的——女性与少数群体的路径曾被「控制掉」而非解释;对数线性修正前,跨国流动比较混结构
- 买入资本三态:转换率难以直接测量;惯习的概念弹性大(什么都能装)
- 买入流动表分解:模型世界的 φ 与真实制度的对应(教育?财产?文化?)要另一层研究
