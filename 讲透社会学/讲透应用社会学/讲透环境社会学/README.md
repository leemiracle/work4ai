# 讲透环境社会学 · 社会长在生态系统里——关切、风险与适应

> **定位句**:这支管**社会与生态系统的界面**:环境关切的态度结构(NEP 传统)、风险与危害的社会分配(环境正义)、能源与气候的适应战场。城市支与农村支管人怎么聚居,本支管聚居的物质底座及其反噬。
> **GB/T 支**(8402734 环境社会学)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:Catton-Dunlap〈环境社会学:一种新范式〉(1978,向「人类例外主义范式」宣战——学科的出生证);Dunlap-Liertman NEP 量表(1978/2000,新生态范式的操作化);英格尔哈特后物质主义价值观(1977,环境关切代际转移的解释与争议);贝克《风险社会》(1986,现代化的自反性——风险的生产与分配);卡司帕森等「风险的社会放大」框架(1988,通说);环境正义研究(1980s-90s 起,有毒设施选址与少数族群社区的叠加——通说);气候适应研究(当代方向锚,检索校准 2026-09-07)。
- **因什么问题**:①主流社会学忘了人类活在生态系统里(范式之问)②关心环境的人是谁、为什么(关切分布之问)③风险谁背、适应资源谁有(正义之问)。

## 核心问题

**已解决(通说)**:NEP 作为范式与量表的双重身份(态度测量的标准装备;效度争论持续但工具沿用);环境关切的社会分布(教育/年龄梯度;后物质主义解释与「关注溢出」的竞争性解读);环境正义的基本事实(危害设施与弱势社区的空间叠加);风险的社会放大(同样的事故,不同传媒与信任结构下社会后果不同)。

**未解决/深水区**:气候适应的分层(谁搬迁谁留守——适应能力本身是阶层资源,01 章主线 C,检索校准 2026-09-07);态度-行为缺口(关心不等于行动,自报环保的测量虚高);能源转型的程序正义(拒绝的预测因素从「离我多近」转向「过程谁说了算」);气候迁移的社会接收(与城市支、人口学接口)。

## ✨ 这支最美的一个事实

**一门学科诞生于一篇「挑刺的便条」(Catton-Dunlap 1978)**。当时的社会学把人类当作例外(文化与社会组织压倒生物与自然,「人类例外主义范式」),两位学者写文说:不,人类社会是生态系统中的种群,承载力与生态限制是所有社会过程的底座。为什么:它示范了**学科可以靠一次「把背景请回前台」的动作立国**——环境社会学不是研究「环境的学问」,是研究「长在生态系统里的社会」的学问;此后气候变化把这条纲领从边缘推向全体社会学科的公共地皮。亲历:数你最近一周读到三条「社会新闻」,几条背后站着物质底座(水/能源/土地)(✍️)。

## 假设与代价

- 买入 NEP 的范式-量表双重身份:量表的维度结构与跨社会等价性是长期账单
- 买入风险社会论:自反性的概念弹性大(几乎什么都能装),证伪压力由实证线扛
- 买入环境正义的空间叠加事实:因果方向(设施选在弱势处 vs 弱势迁向设施周边)要个案审计
- 上游依赖[02 章](../02-语言特征.md)的暴露率语法(环境=暴露的登记)
