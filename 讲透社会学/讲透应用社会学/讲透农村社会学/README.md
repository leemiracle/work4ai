# 讲透农村社会学 · 乡土社会的语法——差序、集市与乡城流动

> **定位句**:这支是家族主轴之一,管**乡土社会的结构与变迁**:关系的基本语法(差序格局)、乡村的社会单位(村落与集市)、小农的经济逻辑(道德经济与理性之争)、乡城流动与乡村振兴的应用战场。城市支管城市性,本支管乡土性——两支是同一连续体的两端。
> **GB/T 支·主轴**(8402731 农村社会学)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:美国建制:罗斯福乡村生活委员会(1908,应用起点);Galpin〈乡村社区的社会解剖〉(1915,以交易圈划社区);Sorokin-Zimmermann《农村社会学原理》(1929)。中国脉络:费孝通《江村经济》(1939,开弦弓——「人类学田野的中国转型标本」)、《乡土中国》(1948,差序格局/礼治秩序/长老统治/文字下乡);施坚雅〈中国农村的市场与社会结构〉(1964-65,基层市场社区论);恰亚诺夫《农民经济组织》(1925,劳动-消费均衡);Scott《农民的道义经济》(1976)对 Popkin《理性的农民》(1979)——道义 vs 理性之争;黄宗智「过密化/内卷化」(1985/1990,华北与长江的小农经济);农民工研究(1990s-2000s,通说);乡村振兴研究(当代通说)。
- **因什么问题**:①乡村社会的基本单位与规则是什么(语法之问)②小农是道义的还是理性的(逻辑之问)③工业化与流动把乡土变成什么(变迁之问)④乡村怎么振兴、政策怎么评估(应用之问)。

## 核心问题

**已解决(通说)**:差序格局(中国社会的关系不是团体格局的成员制,是以己为中心的水波纹——公私相对、伸缩自如);集市作为社会单位(基层市场社区而非自然村才是通婚、祭祀与交往的实际圈子——施坚韦);小农逻辑的双面(家计的生存伦理与市场的精明并存,道义-理性之争的和解:情境决定哪面朝上);乡城流动的家庭策略(候鸟式流动与家庭再生产的分离——留守问题的结构根源)。

**未解决/深水区**:乡村振兴的评估(外源项目 vs 内生发展——尺子问题同[实验幕二](../experiments/mobility_spillover_label.py):整村干预拿户当尺的风险);留守的后果测量(与人口学接口);土地制度的社会学面(流转与身份);数字下乡(电商村/直播返乡——通说方向,检索校准 2026-09-07)。

## ✨ 这支最美的一个事实

**差序格局:中国人的关系是水波纹,不是团体格(费孝通 1948)**。西洋社会像一捆扎清楚的柴(团体:内外分明,成员制),乡土社会是把石头丢进水面的波纹(差序:以己为中心,一圈圈推出去,愈推愈远愈薄)——「私」的问题因此是相对的:为了家可以牺牲村,为了村可以牺牲县,随波纹的中心移动。为什么:一个意象装下了中国社会的公私观、人情运作与制度松紧(为什么规则在不同圈层有不同弹性),也给后续一切「关系研究」定了坐标系(强关系/弱关系的争论在波纹上接着画)。亲历:把你微信通讯录按波纹分三圈,检查你最近求助的三件事各动用了哪一圈(✍️)。

## 假设与代价

- 买入差序格局的理想型读法:城市中国与数字关系网已把波纹拉扁(「圈」的重组),古典意象是坐标不是现状照片
- 买入施坚雅的市场本位:庙会与祭祀圈的证据在部分地区与市场圈不重合(单位的多元竞争未终结)
- 买入道义-经济的双面:两说各自有据,和解框架的预测力有限
- 上游依赖[00 章 §一](../00-体系结构.md)的应用传统(乡村生活委员会=应用社会学的早期建制);流动的宏观面归人口学(文字提及)
