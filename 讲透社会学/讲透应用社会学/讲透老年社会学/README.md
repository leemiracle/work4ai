# 讲透老年社会学 · 老化作为社会过程——地位、分层与脱离之争

> **定位句**:这支管**老化之为社会事实**:老年地位怎么随社会形态变(现代化论)、年龄怎么像阶级一样分层(年龄分层框架)、老化该用哪种理论讲(脱离/活动/连续性)、老年的生产性与照护的战场。青年支管过渡,本支管退出与重新安排。
> **GB/T 支**(8402744 老年社会学)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:卡明-亨利《正在变老》(1961,脱离理论 disengagement);哈维格斯特活动理论(1960s 对照面);阿奇利连续性理论(1970s,通说);考吉尔-霍姆斯〈老年地位与现代化〉(1972,四因素:健康技术/经济技术/城市化/教育→老年地位降);赖利〈年龄分层社会学〉(1972,年龄作为结构:队列流过位置);巴特勒 ageism 概念(1969,通说);生产性老化与第三年龄(拉斯利特 1989,通说);积极老龄化政策框架(WHO 2002,通说)。
- **因什么问题**:①变老只是生物事件吗(社会化之问)②为什么现代社会老人「地位下降」(现代化之问)③「老」了该退出还是继续(理论之争)④老化怎么测量、照护怎么组织(应用之问)。

## 核心问题

**已解决(通说)**:年龄分层框架(社会=两股流:队列流过结构位置;「老年」是位置不是属性——福利、身份与预期都挂在位置上);脱离之争的结局(「老了自然退出」不是普遍规律而是选择、健康与结构的复合;理论存档,教训留名);老年歧视(ageism)的概念化(与种族/性别歧视并列的第三轴)。

**未解决/深水区**:老龄化的数字不平等(数字排斥作为新的退出压力——01 章主线 B 交叉带,检索校准 2026-09-07);照护的社会组织(家庭化 vs 专业化 vs 市场化的分工——与[福利社会学家族](../../讲透福利社会学/README.md)接口);生产性老化的测量(志愿/隔代抚养/再就业怎么折算);年龄、时期、队列的识别(APC 难题——方法家族的常驻案)。

## ✨ 这支最美的一个事实

**「老了就退出」曾被当作普遍规律,后来被骂成「为抛弃辩护」(脱离理论之争)**。卡明-亨利 1961 年提出:老化时个体与社会互相疏离(脱离)是功能必须的——社会要平稳换血,个体要从容谢幕,这是普遍的、必然的。 Townsend 等立即反击:那是把美国中产的健康老人样本当成了人性;对多数老人,脱离是**被迫的挤出**,不是优雅的谢幕。为什么美:它是一堂完整的**理论政治课**——同一组现象,功能论的笔写出「必然与和谐」,冲突论的笔写出「排斥与剥夺」;今天的「退休年龄之争」「老年优待清单」仍在两支笔之间摇摆。亲历:把「延迟退休」政策各用两支笔写一句,看它替谁说话(✍️)。

## 假设与代价

- 买入现代化四因素论:历史双向(部分前现代社会的老人地位也不高),四因素的普适性被缩窄
- 买入年龄分层:位置与人的双流框架好画难量(APC 识别是永久账单)
- 买入生产性老化:折算成「贡献」的框架有再商品化老人的风险(反对面的批评已入通说)
- 上游依赖家庭支(反馈模式的赡养面)与人口学(老龄化的过程量,文字提及)
