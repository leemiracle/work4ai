# 讲透妇女问题研究 · 性别作为分层制度——角色、劳动与权力

> **定位句**:这支管**性别的社会组织**:性别角色怎么造成(社会化)、劳动怎么分性别的账(双重负担与玻璃天花板)、性别与阶级种族怎么交叠(交叉性)。**叙述纪律:通说学术口径,平实叙述。**
> **GB/T 支**(8402754 妇女问题研究)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:前史:沃斯通克拉夫特《为女权一辩》(1792,通说定位为思想前史);第二波:弗里丹《女性的奥秘》(1963,「无名的烦恼」);奥克利《性别的社会学》(1974,sex 与 gender 的区分和社会化四过程);哈特曼〈资本主义与父权制〉(1976 通说线,双系统论);赫希柴尔德《第二轮班》(1989);玻璃天花板(1986 年《华尔街日报》商业评论造词→学术化,通说);克伦肖〈种族、性别与反歧视法的去中心化〉(1989,交叉性 intersectionality——从法律批评到社会学核心概念);性别革命框架(Goldscheider 等,通说)。
- **因什么问题**:①女性的「问题」是生理命运还是社会组织(建构之问)②劳动与权力的性别账怎么算(分层之问)③单轴分析漏掉了谁(交叉之问)。

## 核心问题

**已解决(通说)**:性别角色的社会化读法(性别是社会造的分工与期待,不是生理的直译;奥克利四过程:操纵/渠道/口头标签/活动暴露);双重负担的实证(职业女性的总劳动时间=市场班+家务班,时间日记证据);交叉性的方法论含义(单轴(只看性别或只看种族)的加总不能复原交叠位置的处境——政策名单的漏网者多在交叠处)。

**未解决/深水区**:性别革命的节奏(教育反超与收入滞后的剪刀差——谁的后退谁的进步,通说争论);照护的性别组织(谁照顾、怎么计价——与[家庭支](../讲透家庭社会学/README.md)、[福利社会学家族](../../讲透福利社会学/README.md)接口);平台经济的性别重组(零工的灵活是把双刃——方向锚,检索校准 2026-09-07);性别态度与行为的代际传递。

## ✨ 这支最美的一个事实

**女性下班后再上一班(第二轮班;赫希柴尔德 1989)**。十年田野、多家双职工家庭的分钟级时间账:妻子在外工作一天后,回家再上「第二轮班」——家务与照护;丈夫的「帮忙」被感谢,妻子的「本分」不被看见。折算下来,职业女性每年比丈夫多干约一个月的家务——**一个「永不放假的班**」。为什么:它把「家庭内部谁幸福」的争论变成可以计时记账的分布;此后一切「男女平等了吗」的讨论都要过这本时间账——态度账(都赞成平等)与时间账(没平)的落差,正是性别作为制度的藏身处。亲历:给你家记一周时间账,算出你的「第二轮班」当量(✍️)。

## 假设与代价

- 买入性别二分的角色框架:跨性别与非二元经验的边缘化是框架的历史账单(通说批评已入教科书)
- 买入双重系统论(资本主义×父权制):系统的边界与交互项至今多头;单一系统解释卷土重来过
- 买入交叉性:方法论上要求放弃「可加性」,大样本与多轴的张力是持续账单
- 叙述纪律:通说学术口径,平实叙述,不做立场宣示
