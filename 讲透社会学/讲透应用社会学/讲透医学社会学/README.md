# 讲透医学社会学 · 生病是生物事件,疾病是社会分布——角色、流行与梯度

> **定位句**:这支管**健康与疾病的社会组织**:生病如何被制度管理(病人角色与医患关系)、疾病如何按社会排布(社会流行病学)、健康差距为何换一茬危险因子仍顽固(根本原因)。一句:病在人身,分布在社会。
> **GB/T 支**(8402717 医学社会学;GB/T 注:教育社会学见 88024、商业社会学见 7906335——见注归入声明,本支不收编)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:帕森斯《社会系统》(1951)病人角色章——学科出生证;Freidson《医学的职业主权》(1970);Zola 〈作为 Institutional 化的医学〉(1972,医学化命题);Black Report(1980,英国健康不平等的地标报告);Rose〈患病的个体与患病的人群〉(1985,预防悖论);Link-Phelan〈社会条件作为健康不平等的根本原因〉(1995);Cockerham 健康生活方式理论(通说)。
- **因什么问题**:①生病不只是生物状态,社会怎么把失能管理起来(角色之问)②为什么同一个病在阶层间分布不均且久治不平(分布之问)③为什么消灭了一个危险因子,梯度照旧(根本原因之问)。

## 核心问题

**已解决(通说)**:病人角色四要素(免责/求医义务/康复义务/豁免)——慢性病与长期照护把「暂时性」拉裂,框架被修正仍被沿用;社会流行病学的单位革命(Rose:病例的大头出自「正常」的大多数——分布医学);根本原因机制(阶层以**灵活资源**:知识/金钱/权力/有益关系,持续再造梯度,危险因子只是它的临时载体)。

**未解决/深水区**:数字健康的角色再谈判(生病的定义从诊室搬到 App 界面——01 章主线 B,检索校准 2026-09-07);工作组织作为上游暴露(轮班/不稳定就业/算法调度);多重发病的社会梯度;照护的社会组织(谁在照顾,账记给谁——与家庭支、福利家族接口)。

## ✨ 这支最美的一个事实

**把所有人的血压降两格,救的人比治好高风险的少数更多(Rose 预防悖论)**。直觉盯高危个体;Rose 的算术说:病例的大多数出自风险仅「轻度偏高」的庞大人群,所以分布整体挪一小格,胜过在分布右尾大动干戈。为什么:它把医学的单位从病人搬到**分布**——而分布的挪动是社会工程(食品配方/工作压力/居住条件),于是「病人的医生」之外长出「分布的医生」,医学社会学拿到自己的正题。与根本原因论合成一对:挪分布要动结构,而结构(阶层)恰好掌握着挪分布的资源。亲历:给你身边一项「高危人群筛查」按 Rose 算术算对照方案(✍️)。

## 假设与依赖

- 买入病人角色的制度读法:求医行为的文化差异与自病自理(自我医疗)是账单
- 买入 Rose 的分布优先:个体预防与人群预防的政策预算之争并未因此终结(高危策略在某些病种仍优)
- 买入根本原因:四资源的测量各自带噪;「危险因子换一茬梯度不变」在吸烟等个案上有反例(通说综述口径)
