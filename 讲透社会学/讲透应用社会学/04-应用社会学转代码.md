# 04 · 应用社会学转代码:把流动、溢出与标签搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角
> 贯穿)。
>
> **本章一句话**:应用社会学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**流动**(流动表的边际-关联
> 分解与独立性检验)、**溢出**(个体 vs 社区随机化的设计仿真)、
> **标签**(反应反馈回路的推演)——把「同边际可藏不同开放度」
> 「拿错尺量错布」「刑罚以再犯回流」变成可跑、可扫、可断言的
> 实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",应用社会学转代码要解决"**量与
设计的登记**":把一段应用直觉("寒门难出贵子""好心项目量不出
效果""越抓越犯")先翻成应用量(边际与关联、直接效应与溢出、
反应烈度与回流,02 章/03 章卡片),再翻成代码。翻译的合法性损耗
全部发生在第一步——所以本章先划清哪些对象第一步就走得通(绿色
区),哪些走不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 研究对象 | 代码化身 | 备注 |
|---------|---------|------|
| 流动表分解 | 边际向量+继承乘子 φ+IPF 迭代 → 概率表 | 家族实验幕一全程纯标准库 |
| 开放度扫描 | φ 网格×对角率 → 单调曲线族 | 幕一②;φ 的经验估计是社会侧的活 |
| 流动表抽样与检验 | 多项抽样+G² 对数似然比 | 幕一③;df=(r−1)(c−1) |
| 溢出设计仿真 | 网络拓扑+θ+两种随机化 → 估计量 | 幕二;网络构造固定种子 |
| 尺子对层审计 | 个体/簇两种估计量的偏差对照表 | 幕二;干预设计的仪表盘 |
| 标签反馈回路 | q₀/p/λ/就业乘子的轮次仿真 | 幕三;机制可能性的证明机 |
| 反应烈度对照 | λ 网格×再犯率 → 自锁阈值曲线 | 幕三变体(01 章练习 4 的家) |
| 结构卡 schema | 定长字段记录+完整性断言 | 03 章三张卡;元数据工程 |
| 评估量管线 | 对照结构+分母声明+聚类标准误(方向级) | 评估研究的常规件 |

**转不动(红色区)**:

1. **问题界定的社会判断**:什么算「社会问题」、什么进清单——
   划分即立场,代码只执行不发明(00 §二之争没有算法解)。
2. **弱势群体名单的划定**:名单化冻结动态结构,而「谁弱势」的
   判断随情境变——卡片化可,自动化不可。
3. **职业分类与阶级图式**:平台零工算不算一个职业?编码方案是
   理论决定;转码前必须人工冻结分类学。
4. **干预的伦理审查**:受益/风险/退出权的权衡是价值判断;代码
   可以列清单,不能替人签子。
5. **「何为好生活」的应然之问**:评估卡能量出效应,量不出值得
   ——福祉指标的选取是社会选择,不是技术选择。

**边界的一句话**:绿色区=机制骨架+设计仿真+登记结构,覆盖
"应用直觉的推演与检验";红色区提醒:**代码是政策沙盘的守门员,
不是政策本身**——它能告诉你尺子拿错了(幕二),不能告诉你该
量什么(红色区第 5 条)。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:流动走廊(流动表的边际-关联分解)

```
"寒门难出贵子" ──登记──▶ 5×5 流动表:边际(结构)×关联(继承 φ)
      │
      ├──分解──▶ IPF 钉边际×φ 扫描 → 开放度曲线族
      └──检验──▶ 抽样仿真+G² → 关联是否为零
```

- **理论→模型**:对数线性思想——边际与关联是流动表的两个独立
  自由度;独立世界继承率=Σmᵢ²(解析锚)。
- **算法层**:IPF 每轮行/列各归一一次,双精度下 2000 轮钉到
  1e-9 以下(实测 0.00e+00);抽样用累积表+手写二分(纯
  random);G² 单遍累加 O(格数);**注意二分查累积表的区间
  不变量**——写反一格,对角大格的质量会系统性旁流(本家族实验
  开发期的实战教训,见幕一断言前的修正史)。
- **本家族实现**:[`experiments/mobility_spillover_label.py`](experiments/mobility_spillover_label.py)
  幕一——断言边际钉死、继承率随 φ 单调、样本层对角差 30 倍标准
  误而边际差在噪声内、G² 分野。
- **真实系统**:教育扩招政策的「两张面孔」审计(动的是边际还是
  关联)、招聘公平性的流动表监测、跨国流动比较的模型选择
  (独立性 vs 继承参数)。
- **性能工程要点**:IPF 是 O(轮数×格数) 的稠密小矩阵运算,
  千轮以下瞬时;**别为省轮数改阻尼**——超松弛会破坏边际的
  逐格收敛保证;G² 的零格守卫(0·log0=0)是老 bug 高发区。

### 走廊 2:溢出走廊(干预设计的尺子对层审计)

```
"好心项目量不出效果" ──登记──▶ Y = τ·T + θτ·(受治邻居数) + ε
      │
      ├──对照──▶ 个体随机化 vs 社区随机化 → 估计量偏差表
      └──设计──▶ 溢出先验(θ,形状) → 随机化单位的选择
```

- **理论→模型**:SUTVA 失效的最小机器——处理外溢于邻居;个体
  随机化的期望=τ(直接效应),总效应=τ(1+2θ)(环网络)。
- **算法层**:设计仿真按「设计×θ 档」分桶,逐格 seed=base+格号;
  估计量是分组均值差,O(人数);总效应基准有解析式,MC 只验
  方差。
- **本家族实现**:同实验幕二——断言 θ=0 双尺同读、低估量=2θτ
  单调增、社区随机化全程命中。
- **真实系统**:社区干预(健康促进/治安/教育)的立项前设计审计
  ——先估溢出先验,再选随机化单位;平台 A/B 实验的网络污染
  校正(同构问题的工程版);政策试点的「整县推进 vs 户级试点」
  选择依据。
- **性能工程要点**:设计仿真的热点在逐人 Bernoulli 与高斯噪声
  ——按社区分桶再逐人推进,缓存邻居索引(环网络的模运算免
  重复);**报告必须声明网络拓扑**——环是特例,同一 θ 在无标度
  网络上的低估量不是 2θτ(溢出形状敏感,03 章 §三的暗礁)。

### 走廊 3:标签走廊(反应反馈回路的推演)

```
"越抓越犯" ──登记──▶ 被捕→标签:就业×0.6、q×λ;两环境仅 λ 异
      │
      ├──推演──▶ λ 网格×再犯率 → 自锁阈值与回流倍数
      └──对照──▶ λ=1 的无反馈对照 → 差异归因于反馈本身
```

- **理论→模型**:Lemert 初级/次级越轨的计算读法——社会反应的
  烈度 λ 是自变量,再犯率是因变量;就业是可见的中介变量。
- **算法层**:人群仿真 O(N×T),逐人逐轮两次 Bernoulli(越轨/
  被捕);聚合量(条件再犯率、底色率)用组内均值;**条件组的
  选择效应要算解析对照**(幕三底色:条件在「从未被捕」截掉末窗
  越轨,理论值 1−[(1−q₀)/(1−q₀p)]^L)。
- **本家族实现**:同实验幕三——断言自锁差 0.44、对照无差
  0.0077、底色同值、累计越轨 ×5.3。
- **真实系统**:惩戒政策的回流审计(封禁/开除/曝光的再犯与
  回流测算——通说政策评估口径,不涉规避细节); stigma 的
  信用修复设计(标签的衰减项怎么加);平台封禁的替代设计
  对比(限时 vs 永久 vs 修复性)。
- **性能工程要点**:人群仿真天然并行,逐人 seed=base+人号可
  分片;**q 有上限(capping)时断言要锚在条件组而非总体**
  ——总体均值会被未标签人群稀释;中介变量(就业)与结果变量
  (再犯)要分开登记,别压成一个「综合分」丢掉机制读数。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:立项前的尺子审计——先问干预单位,再谈效果

任何要评估的项目,先过幕二的两问:干预落在什么单位上(个体/
户/社区/平台)?测量打算在什么单位上做?两问不同层,评估设计
就要换随机化单位或显式登记溢出——**否则项目做完连「有没有效」
都答不了,这是最贵的返工**。A/B 实验同理:用户的社交网络会
污染分组,「拿错尺」在工程语境的化身就是组间沾染。

### 落点 2:公平性报表的两张面孔——边际与关联分开报

招聘/晋升/录取的公平性报表,只报「各组占比」(边际)是盲的:
同占比下,继承与通道(关联)可以完全不同。用流动走廊的思路给
报表加第二张表:入口→出口的转移矩阵+对角继承率,时间轴上分
开看「结构变了」还是「规则变了」——幕一是它的最小实现。

### 落点 3:惩戒设计的回流测算——给惩罚加一页账

封号/开除/黑名单类机制,上线前跑一页回流账:被惩戒者的后续
行为(再犯/离开/修复)在什么条件下放大(幕三的 λ)?有没有
修复通道(标签衰减项)?**惩罚在它想消灭的行为里入了股**——
这句话在工程语境的读法是:惩戒的净效应=直接抑制−回流放大,
第二项不测,第一项的汇报就是虚的。

### 落点 4:评估结论的措辞边界——第二本账与外推

任何「实验证明有效」的落地汇报,强制附三行:对照是谁(尺子)、
盘子/生态层的第二本账(02 章再分配悖论的工程版)、外推的剂量
边界(在别处要复制,剂量与保真度能不能跟上)。缺任何一行,
「有效」二字降级为「在彼处彼时有效」。
