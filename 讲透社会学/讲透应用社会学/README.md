# 讲透应用社会学 · 问题的社会学——从城市到标签,十八个战场的诊断、干预与评估

> **本质一句话**:应用社会学=社会学里**拿问题域当分析单位**的一族——
> 城市为何长成圈层、农村为何差序、家庭为何反馈、分层为何继承、越轨
> 为何被反应放大;它把理论与方法的全部装备拉到具体战场上,换回
> 三样东西:**诊断**(问题怎么分布、机制在哪)、**干预**(什么改变
> 有效)、**评估**(效果怎么量、量错了会怎样);一句话:**理论
> 社会学问「社会是什么」,应用社会学问「这个社会问题拿社会学怎么办」
> ——每收一个判断,付一张「测量与因果」的账单**。

## 一、家族定位

- **为什么是它最大家族**:GB/T 给应用社会学开了 **18 条实体三级明细**
  (本宇宙之最)——职业/工业/医学/城市/农村/环境/家庭/青年/老年/
  犯罪/越轨/妇女/种族/社会问题/分层/社区/保障/社会工作,几乎把
  「社会学能下场的每个战场」各立一支。它不是一门窄学科,是**社会学
  的野战军编制表**。
- **一条主线贯穿**:同一个动作在 18 个战场重复——**把「个人烦恼」
  升维成「公共问题」**(米尔斯的立意):你的失业不是你的失败,是
  职业结构的变动;你的孤独不是你的性格,是城市性的代价;你的再犯
  不是你的品质,是标签的反馈回路(实验幕三)。诊断→干预→评估,
  是这门野战军的军械分解。
- **零门槛**:不要求社会学前置;想看理论谱系去
  [社会学理论家族](../讲透社会学理论/README.md),想看方法军规去
  [社会学方法家族](../讲透社会学方法/README.md),本家族是「拿着
  装备下场」的正主现场。
- 路线 A(问题派):为什么寒门难出贵子?→分层支+实验幕一;为什么
  好心项目量不出效果?→00 §二+实验幕二;越抓越犯?→越轨支+实验幕三
- 路线 B(体系派):00→01(前沿)→02(语言)→03(可构造)→04(转码)
- 路线 C(研究派):00→01(文献地图)→各支教材锚
- 工程师快轨:直接跑 [`experiments/mobility_spillover_label.py`](experiments/mobility_spillover_label.py),
  再回读 04 章
