# 讲透社会保障研究 · 保障作为项目——瞄准、覆盖与再分配悖论

> **定位句**:这支管**保障作为应用项目**:钱怎么瞄(瞄准 vs 普惠)、保得全不全(漏保与错保)、给了之后怎样(依赖与退出)、项目怎么评(评估的军规)。福利体制的图纸(三体制/去商品化)归
> [福利社会学家族](../../讲透福利社会学/README.md)(互链),本支管机器的工地与验收;社会保险的制度本体(险种/费率/精算)按 GB/T 归 8407440(劳动科学,待建,文字提及)。
> **GB/T 支**(8402771 社会保障研究)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:俾斯麦社会保险(1880s,通说);贝弗里奇报告(1942,计划面归福利家族);蒂特穆思三分(残补/工业成就/制度再分配——图纸面);应用线:科尔皮-帕尔姆〈再分配悖论〉(1998,瞄准型国家再分配更少——普惠靠中产同盟保住盘子);瞄准评估文献(Moene-Wallertin 线,通说);美国福利改革(1996,AFDC→TANF)的评估研究(依赖争论两面,通说);墨西哥 Progresa/Oportunidades 条件现金转移(CCT,1997 起)的大规模随机化评估——评估研究的标杆;中国低保(1999 城市/2007 农村)研究(通说)。
- **因什么问题**:①资源有限,给谁(瞄准之问)②给了会不会养懒(依赖之问)③「应保尽保」怎么验收(评估之问)④瞄准与政治谁喂谁(再分配悖论之问)。

## 核心问题

**已解决(通说)**:再分配悖论(把转移支付瞄准穷人的国家,再分配总量反而常更小——瞄准拆散中产阶级同盟,盘子缩水;普惠留住同盟,穷人的绝对所得反多;两本账的项目层/体制层必须分开记);瞄准三率的审计(漏保/错保/覆盖率——02 章分母纪律的主场);CCT 的评估范式(随机化做进国家决策:样本村做对照,续期凭证据——评估研究从「事后算账」变成「设计内置」)。

**未解决/深水区**:福利依赖的净效应(保障的退出效应 vs 选择效应,因果分离难;证据混合,通说两面并陈);数字身份与瞄准(数据化提高了命中,也制造了新排斥——没被数据看见的人);非正规经济的覆盖(缴费型保障对灵活就业的失灵);给付的「第二本账」外推(瞄准改革对行政成本与污名化的副作用)。

## ✨ 这支最美的一个事实

**把随机对照做进国家预算(Progresa 的评估设计,1997)**。墨西哥的 CCT 反贫困项目在立项时就把评估写进设计:样本社区随机分批进入(后批即对照),续期与扩编以效果数据为凭。为什么:它示范了应用社会学的最高工艺——**评估不是项目的售后,是项目的图纸一部分**;坎贝尔〈把改革当作实验〉(1969)的纲领第一次以国家规模兑现(此后的他国 CCT 多沿用此范式,通说)。对照[实验幕二](../experiments/mobility_spillover_label.py)的教训更妙:Progresa 以**社区**为随机化单位,恰好躲开了溢出的错尺——好心加对尺,才是可交付的善。亲历:给你身边的项目加一问:它的对照组在设计里,还是在总结里(✍️)。

## 假设与代价

- 买入再分配悖论:样本以福利国家为主;后发型与转型国家的盘子逻辑待验(通说标注)
- 买入 CCT 评估范式:外部有效性(对照期结束后的长期效应)与溢出(控制村的沾染)是持续账单
- 买入依赖争论:退出效应的识别依赖外生变动(改革时点),解释权分散
- 上游依赖[02 章](../02-语言特征.md)的再分配悖论双指标(瞄准率×盘子)
