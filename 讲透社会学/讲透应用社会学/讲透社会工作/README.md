# 讲透社会工作 · 助人的专业化——从善意到证据

> **定位句**:这支管**助人的专业**:个案-小组-社区三大方法、专业判断的框架化(社会诊断)、循证的证据革命、专业与制度的张力。保障支管项目的图纸与验收,本支管帮助怎么递到人手里;照护作为**体制安排**(谁照顾、谁付账)归
> [福利社会学家族](../../讲透福利社会学/README.md)(互链,其消歧表已声明「交付现场归社会工作侧」)。
> **GB/T 支**(8402774 社会工作)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:慈善组织会社 COS(1869,伦敦——「科学慈善」对滥施的纠正)与睦邻运动(汤因比馆 1884/赫尔馆 1889,亚当斯——定居于贫民中);里士满《社会诊断》(1917,把医学的诊断搬给救助:可记录、可复核、可传授)与《什么是社会个案工作》(1922);诊断派 vs 功能派(1930-40s,汉密尔顿一系对功能派——通说);三大方法的成型(个案工作→小组工作 1930s→社区组织);格林伍德〈专业的属性〉(1957,专业五特征);循证实践(1990s 起,从医学 EBM 移植,Gambrill 等的批判性梳理,通说);优势视角(Saleebey,1990s:从缺陷清单转向资源与抗逆);购买服务与专业化张力(当代通说)。
- **因什么问题**:①好心为什么会帮错(科学慈善之问)②助人的知识是什么、从哪来(诊断与循证之问)③案主的难题是内心的还是处境的(人在情境中之问)④专业能既服务案主又服务制度吗(双委托之问)。

## 核心问题

**已解决(通说)**:社会诊断的框架化(「人在情境中」:问题=人×环境×互动,评估要三处下笔——里士满的遗产);三大方法的分工(个案改处境中的个人、小组用同伴动力、社区改环境本身);循证的三层结构(最佳研究证据+实务智慧+案主价值——缺一层都不成其为循证);专业的双委托显式化(受雇于机构/国家,承诺于案主——张力的诚实登记先于解决)。

**未解决/深水区**:循证的边界(什么算证据——RCT 至上对关系性、过程性帮助的适用性争论;实务知识的地位);专业化与行政化的张力(购买服务下,指标考核与专业判断的让位);数字社工(远程个案:关系技术的再定义——方向锚,检索校准 2026-09-07);优势视角的操作化(「资源取向」怎样不变成回避结构不平等)。

## ✨ 这支最美的一个事实

**把「诊断」搬给救助(里士满《社会诊断》,1917)**。十九世纪的慈善凭善心与施舍,常帮错人、帮错法;里士满说:救助前先做**社会诊断**——像医生问病史那样,系统地记录案主的家庭、经济、健康、关系史,判断从何下手、凭什么好。为什么:这是一次「助人的工程化」——善意第一次有了可复核的判断程序,社会个案工作由此立业,**今天的循证之争仍是它的续集**(诊断要证据,证据要设计,设计要对照——[实验幕二](../experiments/mobility_spillover_label.py)的尺子在社工手里的版本)。一百年间从「同情的技术化」走到「技术的同情化」(优势视角),两半都不可少。亲历:给你帮过的一次忙写「社会诊断」:问题在本人、环境还是互动(✍️)。

## 假设与代价

- 买入社会诊断的医学类比:个案化的框架容易漏结构层的病因(贫困不是个案的病——本家族分层支的常识要反向输入社工)
- 买入循证三层:证据的等级制争论未决;「无证据的善意」与「无菌的关系」之间,专业的位置在移动
- 买入优势视角:操作化的松散是概念账单(什么不算「优势」几乎无边界)
- 上游依赖保障支(项目的图纸)与评估卡(验收的军规)
