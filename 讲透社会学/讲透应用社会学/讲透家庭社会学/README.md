# 讲透家庭社会学 · 家的结构与契约——婚姻、代际与第二轮班

> **定位句**:这支是家族主轴之一,管**家的社会组织**:婚姻与亲属的制度、代际之间的赡养与抚育契约(反馈模式)、家内劳动与权力的性别组织(第二轮班)、家庭变迁的全球与本土节奏。城市支管空间容器,本支管时间中的最小制度。
> **GB/T 支·主轴**(8402737 家庭社会学)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:古德《世界革命与家庭模式》(1963,工业化→扩大家庭解体→向核心家庭收敛的现代化叙事及其后续批判);帕森斯的家户功能论(工具/表意分工,1950s);费孝通《生育制度》(1947)与〈家庭结构变动中的老年赡养问题〉(1983,反馈模式);赫希柴尔德《第二轮班》(1989,职业女性的双重负担);本特森代际团结模型(2001,六维度:结构/情感/一致/功能/规范/接触);第二次人口转变(Lesthaeghe-van de Kaa 1986,通说——婚育的去制度化);瑟伯恩《性与世界的权力体系》(2004,通说);家庭政策评估(育儿假/照护政策的因果研究,当代通说)。
- **因什么问题**:①家是自然单位还是历史制度(制度之问)②代际之间凭什么互助(契约之问)③家里谁的劳动算数(性别之问)④家庭在怎么变、政策能不能接住(变迁之问)。

## 核心问题

**已解决(通说)**:反馈模式(中国赡养的代际均衡:抚育与赡养双向流动的「反哺」,对照西方向下单向的「接力」——两种代际契约各配一套制度);第二轮班的实证(女性的总劳动时间=市场班+家务班;「下班后再上一班」);代际团结的多维测量(六维度允许「同住而不亲密、亲密而不同住」的分层描述);家庭现代化的修正(收敛论被多元路径取代——历史与文化的家庭遗产持续塑形)。

**未解决/深水区**:低生育的家庭机制(成本-风险-意义的三层解释,与人口学接口);隔代抚养(家庭养老与儿童照护的双重挤压);家庭政策的因果评估(育儿假的溢出面——[实验幕二](../experiments/mobility_spillover_label.py)的家门:政策给的是家庭,尺子常拿个人);数字家庭的边界(远程亲职/留守儿童的视频母职)。

## ✨ 这支最美的一个事实

**赡养是「反馈」,不是「接力」(费孝通 1983)**。西方代际契约像接力赛:上一代把资源向下传,子女再向下传,赡养交给社会制度;中国传统像反馈电路:乙代抚育甲代(父母养子女),甲代赡养乙代(子女报父母)——「养儿防老」是一个双向均衡,不是单向恩情。为什么:一个电路意象同时解释了中国的抚育强度(养得深是为了将来收得回)、赡养伦理(「报」的义务感)与现代化冲击下的失衡(当子女无法「返回」——流动与少子把反馈电路剪断,养老问题随之井喷);家庭政策的全部争论(家庭养老 vs 社会养老)都是这条电路怎么接的问题。亲历:画你家的反馈电路:上一代给了什么、这一代在返什么、电路哪里变细了(✍️)。

## 假设与代价

- 买入反馈/接力的两型读法:现实家庭常是混合电路(城市核心家庭+ rural 扩展网络),两型是理想型不是普查分类
- 买入第二轮班的计量:时间日记的回忆偏差与「照顾质量」的不可见劳动是测量账单
- 买入代际团结六维:维度间权重是理论决定;跨文化等价性持续检验中
- 上游依赖[02 章](../02-语言特征.md)分母纪律(家庭的边界:谁算「一户」决定一切户级率)
