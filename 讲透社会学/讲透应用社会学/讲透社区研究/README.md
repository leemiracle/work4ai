# 讲透社区研究 · 共同体的结构与权力——从乡到网

> **定位句**:这支管**共同体作为分析单位与行动单位**:社区是什么(双重边界)、社区权力在谁手里(精英论 vs 多元论之争)、社区为什么有效(集体效能)、社区怎么营造(自组织 vs 行政供给)。城市支管城市的整体,本支管城市的细胞。
> **GB/T 支**(8402767 社区研究)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:滕尼斯《共同体与社会》(1887,Gemeinschaft/Gesellschaft——血缘/地缘/精神共同体对组织社会);佐尔鲍《黄金海岸与贫民窟》(1929,城市的社区解剖);社区权力之争:亨特(1953,亚特兰大声望法→精英论)对达尔《谁统治?》(1961,纽黑文议题法→多元论),与波尔斯比的方法论反批评(通说);沃伦〈社区的解体〉(1978,垂直整合吞并本地社区);普特南《独自打保龄》(2000,社会资本的衰减论——通说+争议);桑普森等〈集体效能〉(1997,芝加哥多层证据);社区营造(日本造町运动 1960s 起→台湾社区营造 1990s,通说);数字社区(方向锚)。
- **因什么问题**:①「社区」在现代社会还剩下什么(存亡之问)②社区的事谁说了算(权力之问)③同样的穷社区为何治安两样(效能之问)④营造能造出来吗(行动之问)。

## 核心问题

**已解决(通说)**:社区权力的方法论对峙(声望法数出精英统治,议题法数出多元统治——分歧不在城市在方法:问「谁有威望」找到精英,问「谁在议题上赢」找到多元;潜在议题(不进入议程的事)是两派共同的盲区);集体效能(社会凝聚力+共同干预的意愿,对暴力的预测力压过贫困——穷而有效的社区比富而离散的更安全);社会资本的测量(信任/互惠网络/参与)。

**未解决/深水区**:社区的解体与重组(垂直整合与数字重组同时进行——本地社区没死,换了形态);营造的因果评估(活动场次≠自组织能力,02 章变脸警报的正主——评估的尺子问题同[实验幕二](../experiments/mobility_spillover_label.py):社区干预拿个体当尺);邻里的尺度(什么算「一个」社区——边界划定无算法解);数字社区与地理社区的重叠效应。

## ✨ 这支最美的一个事实

**同 method 异城:你问什么,就看见什么(亨特 vs 达尔)**。亨特问亚特兰大的商界领袖「谁最有影响」,数出一张金字塔(精英论);达尔盯住纽黑文的实际议题(教育/政党提名/公共工程),数出几摊分立的参与者(多元论)。两座美国城市,两种政体——但真正的分歧在**尺子**:声望量的是潜在权力,议题量的是行动权力;议题法天然看不见「没进入议程的事」(谁决定不讨论什么)。为什么:这是社会科学史上最干净的一次**方法论自反**——两位研究者用不同的工具「发现」了不同的城市,学科由此学会:先审尺,再信图。亲历:给你所在社区画两张权力图(声望法/议题法),看哪张图上你自己在哪(✍️)。

## 假设与代价

- 买入滕尼斯两型:理想型的历史账单(共同体被浪漫化的风险;社会学界的标准自我提醒)
- 买入集体效能:与贫困的相关要多层模型分离;「效能」的测量依赖视频情境法的主观编码
- 买入社会资本框架:概念的四义并存(信任/网络/规范/参与),换义不换词的文献污染
- 上游依赖城市支(社区是城市的细胞)与方法家族(多层模型的军规)
