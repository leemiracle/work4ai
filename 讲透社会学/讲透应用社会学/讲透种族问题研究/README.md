# 讲透种族问题研究 · 族群边界的社会组织——距离、同化与边界

> **定位句**:这支管**族群与种族的社会关系**:群体间的社会距离怎么量(量表传统)、同化与多元的路怎么走(同化论与多元论)、当代的不平等如何在不谈种族的话语里再生产(色盲种族主义)。**叙述纪律:通说学术口径,平实叙述。**
> **GB/T 支**(8402757 种族问题研究)。家族:[讲透应用社会学](../README.md)

## 诞生

- **谁/何时**:帕克〈种族关系的循环〉(1926,接触→竞争→适应→同化;循环论后被批评带决定论色彩,通说标注);博加杜斯〈社会距离的测量〉(1925,七级量表:通婚至亲/同街邻居/同业同事/同国公民/仅作访客/排除出境);米达尔《美国的困境》(1944,「美国信条」与种族实践的制度性矛盾);戈登《同化在美国》(1964,同化七维度:文化/结构/婚姻/认同/态度/行为/公民);布鲁默〈群体位置偏见〉(1958,偏见=群体位置感,不是个体心理的加总); segmented assimilation 分层同化(Portes-Zhou 1993,通说);博尼拉-席尔瓦《没有种族主义者的种族主义》(2003,色盲种族主义四框架)。
- **因什么问题**:①群体之间的「远近」能不能量(测量之问)②移民及其后代是否、如何融入主流(同化之问)③为什么法律平等之后差距仍在(再生产之问)。

## 核心问题

**已解决(通说)**:社会距离的刻度化(1925 年的纸笔量表沿用至今,跨国可比——距离是结构不是情绪);同化的多维分解(文化同化≠结构同化:可以学语言、进不了圈子);偏见的社会学定位(布鲁默:偏见来自群体位置感——优势群体的边界防卫,个体态度只是表层)。

**未解决/深水区**:色盲话语下的测量(「不谈种族」的种族主义怎么量——框架分析的编码是难点);第二代移民的分层路径(哪条路通向上流动、哪条通向下融入,条件未合龙);族群边界的过程研究(Wimmer 线的边界开启/关闭,通说);族群与阶级的交互(哪一轴何时主导)。

## ✨ 这支最美的一个事实

**偏见可以量成七级刻度(博加杜斯社会距离量表,1925)**。不给态度打分,只问七个具体行为:你愿意让某群体的人——与你通婚(1)/住同一条街(2)/做同事(3)/做本国公民(4)/仅作为游客来访(5)/被排除出境(6)……级数即距离。为什么:它把「偏见」这个道德词翻成了**行为梯度**——不问「你歧视吗」(没人承认),问「你愿意走多近」(行为不会说谎);一百年了,这张纸还在各国问卷里服役,是社会学的经久工具之一。**测量尺度的设计比口号的声量更能改变讨论**。亲历:把七个等级换成你自己面对某个外群体的真实底线,量出你的社会距离(✍️)。

## 假设与代价

- 买入帕克循环:线性与决定论被批评(历史有倒退、有停滞、有边界重画);当代用作问题清单而非定律
- 买入同化多维论:主流本身是多数中心与分层的主流(分层同化的修正);「同化」的价值中立性有争论
- 买入色盲种族主义框架:话语分析的编码主观性是方法账单;跨语境(非美国)适用性待验
- 叙述纪律:通说学术口径,平实叙述,不做立场宣示
