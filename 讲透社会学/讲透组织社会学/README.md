# 讲透组织社会学 · 组织的形态、合法性与生态——现代社会为何装进一张张图表

> **本质一句话**:组织社会学=把「组织」本身当作社会结构来解剖的学科——
> 现代人的生老病死、衣食住行大多发生在组织里、组织间、被组织管着;
> 这门学问问三件事:组织**为何长这样**(科层制理想型与形态谱系)、
> **为何这么难改又为何彼此越长越像**(结构惰性、种群生态、合法性同构)、
> **组织之间如何相连又如何换代**(网络组织与平台);
> 每收一张组织图景买入**形态-合法性-生态三重解释**,付出**组织内部
> 黑箱与种群数据的稀薄**两张账单;一句话:**个人面对的「社会」,
> 一半以上是一张组织图表——组织不变革人,组织筛选人**。

## 一、家族定位

- **三支分工**:同一门「组织为什么是这个样子」之问的三种打开方式——
  **形态支**问**由什么构成**(科层制理想型的解剖学/寡头铁律/结构惰性:
  组织的骨骼与惯性),**制度支**问**被什么力塑造**(合法性/同构三机制/
  组织场域:环境如何把组织捏成同一个形状),**网络支**问**如何连接与
  换代**(网络组织/组织间关系/平台与后科层:组织的边界与形态变迁)。
- **一条主线贯穿**:**组织不是一件东西,是三副眼镜的叠影**——效率机器
  (西蒙-赛尔特线:有限理性下的满意化)、合法性剧场(迈耶-罗恩线:形式
  结构作为神话与仪式)、种群里被选择的物种(Hannan-Freeman 线:变迁靠
  生死不靠改宗);三镜同戴,才有完整的组织图。
- **零门槛**:不要求管理学或社会学前置;想看韦伯支配理论去社会学理论
  家族(已链),想看交易成本与治理形态去管理理论家族(已链),本家族
  是「组织的社会学解释」的正主现场。
- 路线 A(问题派):为什么大公司都长得像?→00 §一+支2;为什么坏组织
  能活那么久?→00 §七+支1;扁平化真的去科层了吗?→02 章+支3
- 路线 B(体系派):00→01(前沿)→02(语言)→03(可构造)→04(转码)
- 路线 C(研究派):00→01(文献地图)→各支教材锚
- 工程师快轨:直接跑 [`experiments/ecology_institution_filter.py`](experiments/ecology_institution_filter.py),再回读 04 章

```
讲透组织社会学/               GB/T 84061(无三级明细→自定 3 支)
├── 讲透科层制与组织形态/     自定支——骨骼与惯性:韦伯理想型/寡头铁律/
│                             Merton 病理/结构惰性与种群生态
├── 讲透新制度主义/           自定支——环境之力:理性神话/合法性/
│                             同构三机制/组织场域/松散耦合
└── 讲透组织与网络/           自定支——连接与换代:网络组织/组织间关系/
                              平台与算法科层/后科层形态
```

> 三支是一个问题的三个面:形态支供**解剖**(组织由什么构成、为何难改),
> 制度支供**压力源**(组织被什么力捏成这个形状),网络支供**连接与
> 变迁**(组织之间如何相连、形态如何换代)——没有形态的制度是空场,
> 没有制度的形态是标本,没有连接的前两者只是一张静态图。
