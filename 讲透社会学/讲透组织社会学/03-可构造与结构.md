# 03 · 可构造与结构:哪些组织对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:组织社会学的对象沿一条**可构造谱系**排开——
> 机制骨架端**严格可构造**(种群的两力死亡率/三机制的采纳动力学/
> 层间的保真串:写得出、跑得动、断言得了,实验三律全程可跑),
> 观测的中段**半可构造**(组织普查与事件史编码/场域边界划定/采纳
> 与使用的两层测量:可结构化但含量化判断),解释的经验实在端
> **几乎不可构造**("这个组织因为合法性而活下来了"——只有取证,
> 没有装配);全谱系共享三条结构引擎:**生态引擎**(密度同时喂
> 合法化与竞争)、**同构引擎**(三种力把采纳率抬到一)、**保真
> 引擎**(层间复合衰减);而一段组织研究可以被压进三张**结构卡**
> (组织形态卡/场域地图卡/同构压力诊断卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
密度依赖曲线 ── 同构扩散动力学 ── 保真串 p^L ── 事件史编码 ── 场域边界 ── 合法性测量 ── 形态成因断言
  │                                                                    │
严格可构造(可断言)                                              几乎不可构造(只有取证通道)
  └── 写得出、跑得动、能过 assert                              └── 断言=机制+证据+对照的合取,装配学缺席
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:
密度依赖的语义是"μ(N)=μ0+竞争(N/K)−合法化(a·N/(N+N½))",输入
输出明确,跑一万次都是它;而"这家组织因合法性而存活"的语义要先问
**取证**——合法性怎么测、对照怎么设、竞争解释怎么排——构造学
在那里让位给证据学。本章先盘家底,再看三条结构引擎,最后把一段
组织研究压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **密度依赖死亡率** | 参数(μ0/a/N½/C/K)+固定种子→hazard 曲线 | 低(幕一全程可跑) | 模型世界不是任何真实行业;观测死亡率混入年龄/规模构成 |
| **同构采纳动力学** | 权力树/频率依赖/专业圈网络+固定种子→采纳轨迹 | 低(幕二) | 机制的"纯净版"现实中三力叠加;轨迹指纹只在可分离时可靠 |
| **保真串** | AR(1) 衰减信道 p+层数 L+渠道 m→corr 与判读率 | 低(幕三) | 对称高斯噪声是特例;真实科层还有系统性偏误(编码偏差) |
| **组织普查/事件史** | 编码方案(组织定义/生死判据/来源等级)→结构化表 | 中 | 定义漂移(并购算死吗);来源等级要显式 |
| **场域边界** | 成员提名+共认制度清单+位置分析 | 中 | 循环险境(用同构认场域,又用场域解释同构) |
| **采纳 vs 使用的两层测量** | 采纳登记+使用层证据(行为/产出) | 中高 | 脱耦让采纳率虚高;使用层的测量本身含判断 |
| **合法性测量** | 代用指标(认证/评级/媒体语调/资格) | 高 | 解释项自身难测是支2的软肋(00 §四) |
| **形态成因断言** | 没有装配学,只有证据链的合取记账 | **不可构造** | "因合法性而活"=机制+证据+对照的合取,断言永远只有三分之三是可构造的 |

**反直觉发现(本章铁律)**:**最能跑的对象断言最弱,最想下的断言
恰好跑不了**。密度依赖跑得飞快,断言只是"在此机制**下**死亡率呈
U 形"(幕一);而"共享单车行业 2019 年死亡潮是竞争段的红海效应"
这个真断言,落在谱系右端——它要的是行业事件史+年龄构成的校正+
替代解释(资本退潮/监管)的排除,模型只是三分之一。用左端的流畅
冒充右端的断言,是组织社会学被批评"套模型"的总根源——正确的姿势
是**合取记账**:机制骨架(可构造)+事件史证据(半可构造)+对照
(备择解释的排除),三条都齐才升格为经验命题。

## 二、结构引擎 1:生态引擎(密度同时喂两力)

**直觉图像**:组织形态的生死不是一个老板的决策,是一条被种群密度
扳动的曲线——密度低时它是营养(正名),密度高时它是毒药(红海)。

- **数学化身**:μ(N)=μ0 + C·N/K − 合法化增益 a·N/(N+N½),
  进入率 λ(N) 也吃密度合法化;谷底 N*=√(a·N½·K/C)−N½。
- **三条刚性**(幕一的数值化身):
  1. **两力可分解**:只留合法化,实测死亡率 0.102→0.027 单调降;
     只留竞争,0.116→0.230 单调升——U 形是两条单调的叠加。
  2. **谷底随 K 走**:K=100→实测 13(理论 12.5),K=200→23(理论
     22.6);承载力翻倍,红海后移。
  3. **轨迹侧写成带**:300 条种群史按密度带暴露加权 0.097→0.085→
     0.094——先正名后红海,形态的一生被 U 形切成两半。
- **刚性从哪来**:两力参数明确、断言能过 assert——这是谱系左端的
  全部刚性。软的地方在**机制的经验根据**(真实行业里 a 与 C 多大、
  K 怎么测),引擎解决推演,不解决测量。

## 三、结构引擎 2:同构引擎(三种力把采纳率抬到一)

**直觉图像**:场域变整齐不是一种力,是三种力;它们殊途同归(终局
都饱和),但开锁的痕迹(轨迹形状与残留结构)不同。

- **数学化身**:强制=沿权力树的波前推进(每期 0.85 下行);模仿=
  频率依赖采纳率 γ·s(恰是 logistic 方程 ds/dt=γ·s(1−s) 的离散版);
  规范=专业圈网络上的逐边传播(圈间独木桥为瓶颈)。
- **三个标准断言**(幕二实拍):
  1. **终局同构,过程异构**:终采率 98.3%/100%/100%,t50 却是
     2/14/32——看结果分不出,看轨迹立刻分家。
  2. **形状是指纹**:强制前 3 跳占 81%(阶梯),模仿最大增量落在
     份额 59%(S 形中段最陡),规范一圈一圈地漫(t90=51)。
  3. **残渣是力的签名**:强制留抵抗尾巴(1.7%——权力边管不到的
     独立组织),模仿几乎无死角(0%)。
- **刚性从哪来**:三机制的模拟版可分可跑,指纹法(轨迹+残留)是
  **机制识别的可断言化**。软的地方同引擎 1:现实三力叠加,指纹
  只在主导力可分离时可靠。

## 四、结构引擎 3:保真引擎(层间复合衰减)

**直觉图像**:科层的每一层都在给信号抽税;税是复合的(p^L),
退税是平方根的(1/√m)。

- **数学化身**:AR(1) 衰减信道 y=p·x+√(1−p²)·ε;corr(顶层,
  L 层)=p^L;每层 m 渠道平均后噪声方差(1−p^{2L})/m。
- **三个标准断言**(幕三实拍):
  1. **复合律**:实测 corr=0.901/0.529/0.279/0.080(L=1/6/12/24)
     =理论 p^L;**L 翻倍,保真平方级**(corr(6)²=0.280≈corr(12))。
  2. **判读滑向抛硬币**:读对方向 0.981→0.614(L=12)→0.532
     (L=24)。
  3. **退税汇率递减**:SD 比 0.501/0.334≈1/√m;判读 0.618→0.812
     (m=9),但第 1→4 条渠道买回 0.108、第 5→9 条只 0.086。
- **刚性从哪来**:信道模型语义有限确定,断言锚在分布性质上;软的
  地方:真实科层的噪声不对称(系统性编码偏误),且「层」的定义
  (汇报级 vs 审批级)是理论决定。

## 五、结构卡 schema:把一段组织研究压进三张卡

**先答为什么**:组织研究的难点在"整体性"——形态、场域、压力、
证据散落正文,难以携带与复核。结构卡是**有限字段的压缩格式**:
字段固定、填空即可复用、可比可查可补(这是"可构造"在研究层的
对应物:卡片本身严格可构造,实验三律就是三张卡的数值实例)。

### 卡 1:组织形态卡(一台组织机器的解剖档案)

```
【组织形态卡】
对象与自称:________(组织名/它自称是什么形态)
理想型六维打分(0-2 各维:0=无,1=部分,2=满格):
  管辖权固定(规则分工):__ 命令链(层级服从):__
  成文规则与档案:__ 专业训练准入:__
  全职薪俸与生涯:__ 官员与手段分离:__
第七维(分层结构):职级数 __ 带宽 __ 晋升率 __
权威类型:法理/传统/魅力/算法(代码化的命令链):____
协调机制:命令/价格/关系/算法 各占比估计:________
惰性来源:可靠性资产?可说明性义务?专用资产?____
松紧耦合图:哪些部门与正式结构脱耦(仪式层 vs 运作层):____
场域位置:________ 变迁弹性:核心惰性 __ 外围可调 __
```

样例(已填,方向级):对象=平台骑手团队。六维:管辖权 2(算法
分单,边界明确)、命令链 1(派单+申诉链,但无中层裁量)、规则
档案 2(服务条款+行为日志全程留痕)、专业训练 0(**无准入训练,
这是与传统科层的关键分叉**)、全职薪俸 0(计件、无薪俸)、手段
分离 0(反向:骑手自备工具)。第七维:无职级但有**算法分层**
(分数等级)。权威类型:算法;协调:命令(代码)+价格(计件)
混合;惰性来源:数据与规则资产;脱耦:申诉通道(仪式层)vs 实际
派单(运作层)。**判型读法**:科层的骨架(管辖/规则/档案满格)
+市场的皮(计件、手段自理)+生涯的缺位——「后科层形态」的活体
标本,理想型尺子恰好量出它新在哪几维。

### 卡 2:场域地图卡(一圈组织的制度地形)

```
【场域地图卡】
场域对象与边界判据:________(按共认制度划界,不按产品)
成员清单(四类):供方 ____ 买方 ____ 监管/规制者 ____
  专业圈(协会/学校/标准体)____
支配逻辑:国家/市场/专业/平台规则,谁主谁辅:________
同构压力源登记:
  强制:谁手上有依赖与规制(权力树能到哪):________
  模仿:不确定性下大家盯谁(排行榜/头部):________
  规范:专业圈在哪,圈间桥有几座:________
守门人与认证结构:________
场域成熟度:成员互认度/信息流密度/地位稳定性:________
变迁的种子(反向字段):边缘行动者/跨场域地带/多重逻辑嵌带:____
```

样例(已填,方向级):场域=同城即时配送。边界判据:受同一批
平台规则+交通/劳动规制+消费者评价制度共认的行动者(不含堂食
餐饮供给)。成员:供方=骑手与站点;买方=消费者;规制者=交通、
劳动部门+**平台规则本身(private regulation)**;专业圈=**近乎
空白**(无成熟职业共同体——按幕二语言:规范压力的「圈」还没
织起来)。支配逻辑:平台规则为主、市场为辅。强制=平台派单与
准入规则;模仿=排行榜与头部骑手策略;规范=待建的骑手职业
共同体。变迁种子:跨场域地带(外卖骑手→同城货运/跑腿的技能
迁移带)。**读法**:这张卡直接预告了幕二规范支线的现实形态
——规范压力弱不是「没人管」,是专业圈尚未织网。

### 卡 3:同构压力诊断卡(一项实践会不会、以什么形状扩散)

```
【同构压力诊断卡】
对象组织与待诊实践:________
强制面:依赖关系/规制条款/预算条件:____ 力的覆盖面(权力树
  能到哪,谁在树外):________
模仿面:不确定性来源 ____ 被盯的榜样 ____ 频率依赖强度粗估:____
规范面:专业圈网络位置 ____ 学校与协会的教科书化进度 ____
  圈间桥:________
预期轨迹形状:阶梯/S 形中段陡/圈层慢漫(幕二指纹对照):____
预期残留:抵抗尾巴在哪(权力管不到的组织):________
脱耦风险:采纳后使用层的证据计划(采纳≠使用):________
反向字段:谁有动机与位置松动压力(边缘/跨场域/多逻辑):____
```

样例(已填,方向级;素材条与管理理论家族 01 章互认):待诊=
ESG 报告框架在某行业的扩散。强制面=交易所与监管的披露要求
(覆盖上市公司=权力树的主干);模仿面=头部同行的披露格式
(不确定下的标杆);规范面=会计师协会与评级机构的模板化
(教科书化进行中)。预期轨迹=**先强制后模仿再规范的接力**
(上市公司批量合规的阶梯→非上市公司跟随的 S 形→审计职业化
收尾的慢漫);预期残留=不受披露监管管辖的小微企业尾巴;
脱耦风险=披露≠绩效(使用层证据要看资本支出与供应链实况);
反向字段=多重逻辑地带的企业(国企的使命逻辑×市场逻辑)可能
长出混合格式。**读法**:诊断卡把「大家都会上的」从预言变成
有形状、有残渣、有脱耦审计计划的断言。

**判定流程**(把一个主张钉到谱系上):

```
该主张的核心对象能写成两力死亡率、采纳动力学或保真串吗?
  ├─ 能,且语义有限确定 ──────▶ 左端:直接实现+转码(04 章走廊)+对照
  ├─ 能一半(事件可表,含量化判断)─▶ 中段:卡片化(卡 2/3)+编码方案显式
  └─ 不能(成因/合法性的经验实在)─▶ 右端:合取记账,禁止"模型即证明"
```

## 六、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 科层制与组织形态支 | 左端(保真串)到右端(形态成因)横跨 | 保真引擎+生态引擎 | 分裂:骨架可跑,成因靠合取记账 |
| 新制度主义支 | 左端(采纳动力学)到右端(合法性测量) | 同构引擎 | 分裂:轨迹可跑,合法性难测 |
| 组织与网络支 | 中段为主(网络与平台的形态判型) | 三引擎取形态面 | 中:卡片化判型,形态新词多于硬测 |

**读表法**:一个支的"可构造纯度"决定它的转码方式(04 章)——
机制骨架走计算,事件史走管线,成因断言永远走合取记账。
**没有哪个支全家可构造,也没有哪个支全家不可构造**。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——把一个组织装进上衣口袋**(极简)
形态卡验骨(六维+第七维分层,新形态新在哪几维一眼可读),场域
地图卡验场(四类成员、支配逻辑、三把钥匙的源头),同构诊断卡验
势(一项实践会不会上、以什么形状上、上完留下什么残渣)。为什么
美:**它把"读懂组织研究"变成"填得出卡"**——可复核性从同行善意
移进字段纪律;一张填得出的「圈间桥:近乎没有」,比三页「该行业
制度化程度较低」的散文更诚实。亲历:给你熟悉的组织填三张卡
(✍️练习 1),填不出的格子就是你的裸泳清单。
