# 讲透新制度主义 · 环境之力——合法性、同构三机制、组织场域、松散耦合

> **定位句**:这支管**环境之力**:迈耶-罗恩的理性神话与合法性、DiMaggio-Powell 的同构三机制与组织场域、松散耦合与脱耦——回答组织学最漂亮的问题:**组织长成同一个样子,不(只)是因为高效,是因为像才安全**。形态支管骨骼,本支管把骨骼捏成这个形状的力。
> **自定支**(GB/T 84061 无三级明细,家族自定三分)。家族:[讲透组织社会学](../README.md)

## 诞生

- **谁/何时**:先声 Selznick《领导行政》(1957)——制度化=组织被注入超越技术要求的价值;Weick(1976)松散耦合;Meyer-Rowan〈制度化的组织:作为神话与仪式的正式结构〉(1977)理性化的神话+合法性+脱耦;DiMaggio-Powell〈铁笼再访〉(1983)同构三机制(强制/模仿/规范)+组织场域;DiMaggio(1988)制度企业家;Powell-DiMaggio(编,1991)建制;Scott《制度与组织》(1995/2008)三支柱综合(规制/规范/文化-认知);Lawrence-Suddaby 制度工作(2006);Thornton-Ocasio-Lounsbury《制度逻辑》(2012)。
- **因什么问题**:①为什么低效的结构照样扩散(效率解释的失灵之问)②大家为什么越长越像(同构之问)③采纳了为什么不用(脱耦之问)。

## 核心问题

**已解决(通说)**:合法性与理性神话作为结构存活的第二资格(第一资格是效率);同构三机制分类(强制=依赖与规制/模仿=不确定性下的标杆/规范=专业化网络);组织场域作为分析单位(按共认制度划界,非按产品);脱耦作为生存策略;三支柱综合。

**未解决/深水区**:合法性的测量(解释项自身难测——认证/评级/媒体语调各带偏);同构的净效应(与绩效关系理论上不定,实证混合,通说综述口径);场域边界的循环险境(用同构认场域又用场域解释同构);同构如何被打破(制度工作/逻辑冲突/边缘行动者——家族 01 章主线 D)。

## ✨ 这支最美的一个事实

**按规章表演,按惯例办事(Meyer-Rowan 1977)**。组织采纳被环境信念认作理性的结构——不因高效,因**像理性的样子才能换到资源与信任**(理性化的神话);采纳之后立刻**脱耦**:正式结构供展示,实际运作躲进缓冲区。为什么美:它一刀切开「结构」的两层皮——此后看到任何组织的正式章程,第一反应不是「他们怎么运作」,而是「他们想让谁相信什么」;「说一套做一套」从道德批评变成结构分析。家族实验幕二的残留结构是它的数值侧:没采纳的那部分,往往是权力与专业圈都够不着的地带。
