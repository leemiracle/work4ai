# 讲透科层制与组织形态 · 骨骼与惯性——理想型、寡头铁律、惰性与种群

> **定位句**:这支管**骨骼与惯性**:韦伯理想型给解剖图,Michels 寡头铁律与 Merton 病理学给病灶,Hannan-Freeman 的结构惰性与种群生态给寿命表——组织由什么构成、为何难改、如何生死。管理理论家族管「哪种形态更高效」,本支管「形态为何是这样、为何这样也能活」。
> **自定支**(GB/T 84061 无三级明细,家族自定三分)。家族:[讲透组织社会学](../README.md)

## 诞生

- **谁/何时**:Michels《政党论》(1911)寡头铁律;韦伯《经济与社会》(1922)理想型六特征与铁笼判词;Merton〈科层结构与人格〉(1940)目标置换;Selznick《TVA 与草根》(1943)吸纳;Gouldner(1954)假科层;Blau(1955)非正式关系;Stinchcombe(1965)新生儿负债;Hannan-Freeman(1977/1984)种群生态与结构惰性;Hannan-Carroll《组织种群动力学》(1992)密度依赖。
- **因什么问题**:①组织的骨架是什么、怎么量(解剖之问)②好组织为何生病(病理之问)③组织为何难改、形态如何更新(惰性与生死之问)。

## 核心问题

**已解决(通说)**:理想型六维(管辖权/命令链/规则档案/专业训练/薪俸生涯/手段分离)作为可比坐标;寡头化机制链(规模→专门化领导→自我再生产);目标置换/训练出的无能/吸纳/假科层四大病灶;惰性的功能论理由(可靠性/可说明性换资源);密度依赖 U 形死亡率(家族实验幕一:谷底实测 13/23 vs 理论 12.5/22.6,随承载力右移)。

**未解决/深水区**:惰性的微观基础(幕三信息税是候选);观测死亡率的构成异质性(年龄/规模混杂);铁律的反向制度(轮任/基层授权)何时有效;算法接管科层职能后理想型要不要加维(01 章主线 A)。

## ✨ 这支最美的一个事实

**惰性是入场券,不是病(Hannan-Freeman 1984)**。直觉把「大公司改不动」归咎于傲慢;功能论反转:组织靠**可靠性**(可预期的产出)与**可说明性**(说得清责任与程序)向环境换资源,而这两样恰恰要求结构稳定——**组织的难改,正是它被信任的理由**。于是变迁的单位从组织搬走:形态更新靠种群的新生与死亡,不靠老组织改宗。此后一切「转型」叙事都要先过一问:你转的是核心特征(高惰性,大概率转死)还是外围特征(可调)。
