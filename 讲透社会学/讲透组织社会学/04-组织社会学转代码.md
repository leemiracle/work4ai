# 04 · 组织社会学转代码:把形态、场域与层级搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角
> 贯穿)。
>
> **本章一句话**:组织社会学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**生态**(密度依赖的死亡率扫描
> 与进入时机定位)、**同构**(三机制采纳动力学的指纹对照)、
> **信息**(科层串的保真核算与渠道设计)——把「先正名后红海」
> 「整齐的形状与残渣」「层是信息税」变成可跑、可扫、可断言的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",组织社会学转代码要解决"**结构的
登记**":把一段组织直觉("这行挤死了""大家都在抄""传话传丢了")
先翻成组织量(密度与两力、采纳份额与轨迹、保真度与渠道,02 章/
03 章卡片),再翻成代码。翻译的合法性损耗全部发生在第一步——所以
本章先划清哪些对象第一步就走得通(绿色区),哪些走不通(红色区),
再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 研究对象 | 代码化身 | 备注 |
|---------|---------|------|
| 密度依赖死亡率 | 两力 hazard 曲线的网格扫描(密度钉住,死亡即补员) | 家族实验幕一全程纯标准库 |
| 进入时机定位 | N* = √(a·N½·K/C)−N½ + MC 验证谷底 | 幕一;K 的估计是经验侧的活 |
| 同构采纳动力学 | 权力树/频率依赖/网络扩散三种推进器 | 幕二;网络构造需固定种子 |
| 扩散轨迹指纹 | t50/t90、最大单期增量、前 3 跳占比、残留多样性 | 幕二;机制识别的仪表盘 |
| 科层保真串 | AR(1) 信道链 + 并行渠道平均的蒙特卡洛 | 幕三 |
| 信息税核算 | p^L 表 + 1/√m 退税表 + 判读率曲面 | 幕三;组织设计审计的底表 |
| 结构卡 schema | 定长字段记录+完整性断言 | 03 章三张卡;元数据工程 |
| 事件史管线 | 生死编码→风险表(方向级) | 种群研究的常规件 |

**转不动(红色区)**:

1. **合法性的测量**:代用指标(认证/评级/媒体语调)的选择是社会
   判断,代码只执行不发明(00 §四的软肋没有工程捷径)。
2. **场域边界的划定**:用共认制度划界要领域知识与数据双裁;循环
   险境(用同构认场域)没有算法解。
3. **形态的判型**:理想型六维打分的「部分分」(1 分)是人工裁量
   ——卡片化可,自动化不可。
4. **编码方案的社会判断**:什么算一次「死亡」(并购?转型?)——
   划分即理论,代码只执行不发明。
5. **规范之问**:组织该不该更平等、科层该不该拆——代码定价
   (信息税多少),不裁应然。

**边界的一句话**:绿色区=机制骨架+轨迹度量+登记结构,覆盖
"组织直觉的推演与检验";红色区提醒:**代码是组织的沙盘,
不是组织的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:生态走廊(密度依赖与进入时机)

```
"这行挤死了" ──登记──▶ μ(N)=μ0+竞争(N/K)−合法化(a·N/(N+N½))
      │
      ├──扫描──▶ 密度网格×K 档 → U 形曲线族与谷底位置
      └──定位──▶ 当前密度 N(t) 落在 U 的哪一段 → 进入/扩张时机
```

- **理论→模型**:两力分解(合法化 logistic 饱和、竞争 ∝N/K),
  进入率也吃密度合法化(λ=F0·(N/(N+8))·exp(−N/K))。
- **算法层**:密度钉住的 hazard 扫描用 `random.binomialvariate`
  批量抽样(每格数千期);谷底先 argmin 再 7 点抛物线拟合
  (曲线不对称,拟合顶点比 argmin 稳);种群轨迹用 Knuth 泊松采
  进入。O(网格×期数)。
- **本家族实现**:[`experiments/ecology_institution_filter.py`](experiments/ecology_institution_filter.py)
  幕一——断言两力单调、合成 U 形、谷底随 K 右移、轨迹带先降后升。
- **真实系统**:进入新市场/新赛道的时机审计(密度在谷底左侧还是
  右侧)、行业生死周期的监控面板、政策评估(承载力 K 变动如何
  移动谷底)。
- **性能工程要点**:hazard 扫描的格点天然并行,逐格 seed=base+格号;
  抛物线拟合是 O(1) 的减法除法;**别把「密度钉住」改成「自由演化」**
  "优化"——前者测的是 hazard 曲线(可比),后者测的是轨迹
  (混入了动力学),两者回答的问题不同。

### 走廊 2:同构走廊(采纳动力学的指纹对照)

```
"大家都在抄" ──登记──▶ 三种推进器(权力树下行/频率依赖/网络扩散)
      │
      ├──对照──▶ 同一场域×三机制的轨迹并排 → 形状指纹
      └──识别──▶ 观测轨迹匹配哪把钥匙 + 残留结构核对
```

- **理论→模型**:强制=权力树波前(0.85/期下行,树外组织 0.012
  渗透);模仿=采纳率 γ·s(logistic 的离散版);规范=专业圈网络
  (环+弦+圈间独木桥)逐边 0.14 传播。
- **算法层**:轨迹指纹四件套——t50/t90、最大单期增量及其发生
  份额、前 3 跳占比、残留多样性;网络构造固定种子保证可复现。
  O(组织数×期数)。
- **本家族实现**:同实验幕二——断言终采率均近饱和而 t50 2<14<32、
  强制阶梯(前 3 跳 81%)vs 模仿 S 形(峰值份额 59%)vs 规范慢漫,
  残留 0%<1.7%。
- **真实系统**:一项内部实践(K8s/OKR/AI 工具)的扩散监控与机制
  识别——看形状就知道该用哪味药(强制的补覆盖率,模仿的造标杆,
  规范的织圈子);行业标准的渗透阶段判断。
- **性能工程要点**:采纳判断是逐组织逐期的 Bernoulli,热点在
  `random()` 调用——按组织分桶再逐期推进可改批处理;**指纹指标
  对聚合粒度敏感**(逐期 vs 逐周),报告时必须声明时间粒度,否则
  「阶梯」可以是聚合造出来的假象。

### 走廊 3:信息走廊(科层串的保真核算与渠道设计)

```
"传话传丢了" ──登记──▶ AR(1) 信道链(每层保真 p)+ 渠道结构 m
      │
      ├──核算──▶ p^L 保真表 + 判读率曲面 + 1/√m 退税表
      └──设计──▶ 层数×渠道数的成本-保真权衡 → 组织结构审计
```

- **理论→模型**:y=p·x+√(1−p²)·ε 逐层传输;corr(顶,L)=p^L;
  每层 m 渠道平均,噪声方差(1−p^{2L})/m。
- **算法层**:MC 估计相关与判读率用和统计量单遍(Σsy/Σy/Σy²),
  免存轨迹;erf 做理论对照。O(运行数×层数×渠道数)。
- **本家族实现**:同实验幕三——断言复合律、L 翻倍平方级、判读
  0.981→0.532、退税汇率递减(1→4 条买 0.108,5→9 条 0.086)。
- **真实系统**:汇报线与审批链的信息税审计(加一层前先算边际
  保真损失)、多渠道冗余设计(数据看板+越级评审+轮岗交叉的退税
  结构)、算法科层 vs 人类科层的噪声性质对比(对称磨损 vs 编码
  偏误,01 章练习 4)。
- **性能工程要点**:信道链的 MC 天然并行;相关估计在 ρ 接近 0 时
  相对误差爆炸——**断言要锚在绝对偏差上**(幕三的 tolerance 写法),
  不要用相对误差;系统性偏误(均值非零的噪声)是独立的新参数,
  别把它塞进同一个 p 里"简化"。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:组织设计的信息税核算——先算税,再画图

任何加层/减层的组织调整,强制附一页**信息税核算**:当前层数 L、
每层保真 p 的量级(指令被复述的保真度,可抽样测)、渠道结构 m。
幕三的教训:税是复合的(p^L),减一层的杠杆远大于加一条渠道
(层从 8 到 5,保真 0.43→0.59;渠道从 1 到 9 才把判读从 0.62 拉到
0.81)——**扁平化的真实收益要用这两个数说话,不用口号**。

### 落点 2:实践扩散的机制识别——看形状,别只看渗透率

推动一项内部实践(K8s/OKR/AI 工具)时,别只盯渗透率,记**轨迹**:
整批跳(阶梯)=强制在起作用,补权力树覆盖不到的死角是关键;S 形
中段陡=模仿,造标杆最划算;慢而圈层化=规范,去织圈子(培训/
社区/认证)而不是发通知。幕二的残留教训:**模仿几乎无死角,
强制的尾巴在权力管不到的地方**——自组织团队、外包、外部协作者
是采纳计划最常漏掉的人。

### 落点 3:进入时机的种群定位——先问在 U 的哪一段

进入新市场/新赛道前,先估种群密度 N 与承载力 K,问自己在 U 形的
哪一段:谷底左侧(密度升、死亡率降=正名时代,早进者吃合法性
红利)、谷底右侧(红海,进入价码=与在位者拼运营)。幕一的提醒:
**K 会变**(技术/政策扩容),红海会后移——「挤死了」的判断要
带 K 的预测,否则会错过扩容后的新谷底。

### 落点 4:同构压力的合规审计——采纳了不等于用了

组织为合法性采纳的结构(流程/认证/报告),要做**使用层审计**
(脱耦检验):ESG 报告的采纳率与资本支出的一致性、ISO 流程的
采纳与工单实际路径——采纳率是仪式指标,使用率才是结构指标
(02 章纪律 3 的工程版;素材条与管理理论家族互认)。
