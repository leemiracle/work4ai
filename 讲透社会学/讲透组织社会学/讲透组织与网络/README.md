# 讲透组织与网络 · 连接与换代——网络组织、组织间关系、平台与算法科层

> **定位句**:这支管**连接与换代**:Powell 的网络形态(既非市场亦非科层)、组织间关系的组织社会学面、平台与算法科层——命令与价格之外的第三种协调,以及科层被代码重写的现场。交易与治理的判定归经济社会学(互链),本支管组织**形态面**:边界怎么松动、形态怎么换代。
> **自定支**(GB/T 84061 无三级明细,家族自定三分)。家族:[讲透组织社会学](../README.md)

## 诞生

- **谁/何时**:Weick《组织社会心理学》(1969)组织作为过程(organizing);Powell〈既非市场亦非科层〉(1990)网络是第三种组织形态(互惠/关系/声誉治理);March〈探索与利用〉(1991)一切形态的普适张力;1990s 空心公司/无边界组织把边界问题推上前台;平台时代:算法管理(派单/评分/监控/奖惩的代码化,综述框架按通说,方向锚,检索校准 2026-09-07)把命令链写进代码;远程/混合工作(Org Science 专刊线)重新谈判科层的时空基础(家族 01 章主线 A×B)。
- **因什么问题**:①命令与价格之外还有什么协调(第三形态之问)②组织边界为何松动、如何划定(边界之问)③平台是不是第四种形态,还是科层换了引擎(换代之问)。

## 核心问题

**已解决(通说)**:网络作为第三种治理形态的判据(互惠/关系/声誉 vs 价格 vs 命令);探索-利用张力作为形态设计的普适约束;平台的组织学解剖(算法接管中层职能:派单=指令、评分=档案、条款=规则);理想型尺子量平台的方法(六维打分暴露新在哪几维——家族 03 章形态卡样例)。

**未解决/深水区**:算法科层是第四形态还是科层变体(引擎/形态之辨,家族 01 章判读要点 1);算法科层的噪声不对称(编码偏误是系统性单调复制,不是对称磨损——01 章练习 4 的实验方向);远程化的可见性数据化与协调去科层化的分离;网络形态的封闭性与排他(治理面归经济社会学,形态后果归本支)。

## ✨ 这支最美的一个事实

**既非市场,亦非科层(Powell 1990)**。教科书说协调只有两种:价格(市场)与命令(科层)。Powell 看着意大利产业区与硅谷说:还有第三种——**网络**:靠互惠、声誉与长期关系协调,快于市场的关系、柔于科层的命令。为什么美:**它把「组织 vs 市场」的百年二分撬开一条缝**,此后无边界、联盟、平台生态全部从这条缝里长出来;平台时代的续写更妙:派单算法把命令(科层)与计件(市场)焊在同一块屏幕上——第三形态没等来,先等来了**杂交体**,理想型尺子(家族 03 章六维打分)恰好在量它新在哪几维。
