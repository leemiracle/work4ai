# 讲透社会思想史 · 思想的内在理路——从孔德造词到当代综合

> **定位句**:这支负责**思想谱系本体**:概念与论战如何被继承、反转、缝合——古典三源(孔德→涂尔干/韦伯/齐美尔)
> →美国世纪(帕森斯-默顿-戈夫曼-交换与冲突诸论)→欧陆批判与当代综合(法兰克福-布迪厄-吉登斯-哈贝马斯-卢曼)。

## 诞生

- **谁/何时**:1838 孔德《实证哲学教程》造词;1893-1904 古典三源立轴(涂尔干《社会分工论》/韦伯《新教伦理》/
  齐美尔《货币哲学》);1937-1964 美国世纪(欧洲学者移民+大学扩张,通说机制);1968-1984 综合转向(法兰克福
  学院化、布迪厄-吉登斯-哈贝马斯-卢曼四源合流)。
- **因什么问题**:①思想如何被继承与反转(理路之问)②论战阵地如何转移(阵地之问:
  欧洲→美国→再欧陆)③经典为何常新(重读之问)。

## 核心问题

**已解决(通说)**:
- 古典三源的谱系定位:三条河各自浇灌了哪些板块
- 美国化的思想史机制:移民学者把欧陆问题改写成美国议程
- 当代综合四源头的血统表(布迪厄←涂尔干+韦伯;吉登斯←解释学+结构主义;哈贝马斯←批判+语言学转向;卢曼←系统论)

**未解决/深水区**:
- 正典的边界:简·亚当斯、杜波依斯等被边缘化者的正典化重估(进行中)
- 思想史与建制史的执行分界(本支与 84011 的日常划界)
- 重读的合法性:何时是"新读法",何时是"托古改制"

## ✨ 这支最美的一个事实

**《新教伦理》的意外后果**:加尔文教的救赎焦虑逼出尘世禁欲,禁欲伦理不经意塑造了资本主义精神;而资本主义一旦立稳,
不再需要宗教根基,把禁欲者的后代关进"铁笼"。**一个观念成为历史杠杆,而杠杆的支点是当事人完全无意的一步**——
作者意图≠历史后果,思想史最著名的示范,也是默顿"潜功能"的百年前置胎动。
