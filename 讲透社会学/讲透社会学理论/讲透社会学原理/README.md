# 讲透社会学原理 · 四大板块并陈——三轴坐标系里的理论对垒

> **定位句**:家族的**理论主战场**——四大理论板块(结构功能/冲突批判/符号互动与交换/当代综合)
> **并陈对垒**,三大轴线(结构-能动/秩序-冲突/微观-宏观)贯穿全境,方法论之争(实证 vs 理解)是地基。

> 家族:[讲透社会学理论](../README.md)

## 诞生

- **谁/何时**:涂尔干-韦伯立轴(1895《社会学方法的准则》vs 1904《新教伦理》);
  帕森斯综合与默顿造反(1937/1949);板块成形(1956-1964:科塞/达伦多夫/戈夫曼/霍曼斯-布劳);
  综合转向(1972-1984:布迪厄/吉登斯/哈贝马斯/卢曼)。
- **因什么问题**:①同一现象为何有四套合法解释(多元之问)②各板块的假设账单怎么记(成本之问)
  ③理论与经验研究怎么接(中层之问)。

## 核心问题

**已解决(通说)**:
- 三轴坐标系可定位一切理论机器;板块间是位置关系,不是对错关系
- 显/潜功能与后果-动机分账;对偶词=这门学科的证伪语法
- 中层理论作为理论与经验的接口纪律(默顿路线)

**未解决/深水区**:
- 结构与能动之争是否真被综合板块解决(循环性批评,家族 00 章 §四)
- 微观-宏观之桥是否合拢(布劳之桥/互动仪式链/阈值模型各有进展)
- 大理论 vs 中层理论(新功能主义复活大理论的资格之争)

## ✨ 这支最美的一个事实

**涂尔干-韦伯分野**:同一门学科的两块奠基石互相否定——社会事实**外在且强制**,
行动却**挂着主观意义**;学科靠这个张力前进了一百年:每台新机器都是对分野一极的
再平衡(帕森斯偏结构,互动论偏能动,布迪厄与吉登斯各自宣称拆掉了轴)。
**互相否定的地基比互相一致的地基更结实**——每个后来者都被迫先回答对方。

- 每个板块带账单:结构功能买"秩序+共识"付冲突盲区,冲突论反之(总表=家族 [00 章 §五](../00-体系结构.md))
