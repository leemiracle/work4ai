# 04 · 社会学理论转代码:把解释机器搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:社会学理论的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**阈值级联**、**相变扫描**、
> **理论定位卡**——把"分布形状压倒均值""临界质量""理论机器的
> 账单"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",社会学理论转代码要解决"**形式化**":
把一段理论语言("群体事件说爆就爆")先翻成模型(阈值分布+级联
迭代),再翻成代码。翻译的损耗全部发生在第一步——所以本章先划清
哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条
走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 理论概念 | 代码化身 | 备注 |
|---------|---------|------|
| 阈值分布→集体结局 | 阈值列表+迭代 x_{t+1}=max(#{τᵢ≤x_t}/n, x_t) 至不动点 | 家族实验全程纯标准库 |
| 临界质量(critical mass) | 相变扫描:稳态对种子的阶梯函数,边界=团簇阈值 | 实验幕三的最小版 |
| 微观-宏观聚合 | 同均值不同形状的对照实验(命运谱蒙特卡洛) | 实验幕一/幕四 |
| 反馈极性 | 正/负反馈的离散模拟(预言类机制的最小差分方程) | 留作 ✍️练习 3 |
| 理论坐标系卡 | 定长字段的记录(dict/dataclass)+一致性校验 | 走廊 3 |
| 概念对偶表/机制卡 | 表结构+完整性断言(影子/反机制字段非空) | 走廊 3 |
| 场域位置×资本分布 | 位置表 schema(行=位置,列=资本形态) | 中段对象的可构造代理 |

**转不动(红色区)**:

1. **惯习与理解(Verstehen)**:没有状态方程——硬造"惯习参数"只会
   得到自己假设回去的结论。工程对策:退到阅读与田野(03 章右端),
   不当仿真变量。
2. **规范判断**:代码能算"哪种形状会级联",算不了"该不该引爆"
   ——应然问题留在公共讨论与哲学侧
   ([../../讲透哲学/README.md](../../讲透哲学/README.md)),不进实验台。
3. **阈值的经验反推**:仿真可以指定分布,但**从行为数据反推阈值**
   是测量与识别问题(方法侧正主,文字提及)——模拟不能冒充测量。
4. **理论本身的生产**:结构卡能校验理论记录的**完整性**,不能
   生成理论——环节链的每一步须由人指认为真实社会过程。

**边界的一句话**:绿色区=级联类+卡片类,覆盖"形式直觉的校准";
红色区提醒:**转码是理论的使用说明书,不是理论的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:阈值级联走廊(集体结局的全机械化)

```
Granovetter 阈值模型 ──参数化──▶ {τᵢ}+种子 x₀ ──迭代──▶ 轨迹+不动点
      │
      └──对照实验──▶ 同均值不同形状/不同均值不同链 ──▶ 命运差异断言
```

- **理论→模型**:n 人各持阈值 τᵢ;种子 x₀(外生已加入者,不退出);
  x_{t+1}=max(#{τᵢ≤x_t}/n, x_t)。
- **算法层**:直接迭代(实验实现);不动点条件 F(x*)≤x*。
- **本家族实现**:[`experiments/threshold_cascade.py`](experiments/threshold_cascade.py)
  幕一/幕二——断言同均值三命运 40%/10%/20%,低均值形状反到 100%。
- **真实系统**:采用曲线(新产品/新规范的扩散)、舆情引爆、
  集体行动动员、银行挤兑压力测试。
- **性能工程要点**:每步 #{τᵢ≤x_t} 的朴素实现 O(n)·步数;先排序
  再用二分/bisect 推进指针,整条级联 O(n log n);再大用直方图分桶
  O(bins)。**级联序列单调不减**——指针只前进,这是免费的结构红利。

### 走廊 2:相变扫描走廊(临界质量从格言变成曲线)

```
"临界质量"格言 ──参数化──▶ 稳态(种子 x₀) 阶梯函数 ──扫描──▶ 相变边界图
      │
      └──双扫──▶ 分布×种子网格 ──▶ 哪些形状对干预敏感/钝感
```

- **理论→模型**:把种子当**干预变量**扫描,把分布当**人群参数**
  编辑;稳态对种子的阶梯函数暴露相变边界(实验幕三:边界恰在
  团簇阈值 0.20)。
- **算法层**:种子网格 × 分布列表的双重循环;每格一次级联。
- **本家族实现**:同实验幕三/幕四(命运谱=分布维度的蒙特卡洛扫描)。
- **真实系统**:动员/推广的**种子规模决策**(多花多少资源跨过
  相变线?哪类人群形状对种子规模敏感,哪类再多种子也孤悬?);
  风控侧的反向使用(哪些结构不该给第一脚)。
- **性能工程要点**:双扫天然可并行(每格独立;按格分流
  seed=base+格号保证可复现);断言只锚阶梯边界与量级,不锚浮点尾数。

### 走廊 3:理论定位卡走廊(理论资产的数据纪律)

```
结构卡 schema(03 章 §四)──数据化──▶ 定长字段记录 ──校验──▶ 完整性断言
      │
      └──聚合──▶ 机器清单(坐标卡集合)──▶ 盟友/对手图谱一致性检查
```

- **理论→模型**:三张卡各成一类记录(坐标系卡/对偶表行/机制卡);
  字段即 03 章 schema。
- **算法层**:完整性断言(机制卡的反机制字段非空;对偶表的影子
  字段非空——02 章"影子语法"的机器执法);交叉断言(坐标系卡
  挂的机制卡必须存在;同轴相邻的"盟友"坐标差应有界)。
- **本家族实现**:schema 在 03 章 §四,填空即用(不另设脚本,
  留作 ✍️练习 1)。
- **真实系统**:研究组的理论工具库(读文献=填卡;组会=对卡;
  写作=挂卡)、综述的机器可读附录。
- **性能工程要点**:这是**元数据工程**——价值不在计算量,在纪律:
  卡片强制对偶与反机制字段,等于把 02 章的证伪语法编译成校验器。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:引爆/采用监控面板——盯衔接,别盯均值

- 给任何"热度/采用/传播"仪表盘配两个指标层:**平均倾向层**(好评率/
  平均意愿——管理层爱看)加**形状层**(意愿分布的团簇结构与团间
  衔接)。家族实验幕一/幕二是这个面板的最小验收用例:**均值不变,
  命运可以反转**(B vs E);只看第一层的面板会在 E 型世界漏报爆点、
  在 B 型世界误报安全。

### 落点 2:种子规模的先算后投

- 动员类资源(营销首发/社区冷启动/政策试点)投放前跑一次幕三式
  相变扫描:估人群阈值团簇→扫种子→读阶梯。**如果人群形状在
  孤悬区,种子加码是填无底洞;在相变边界附近,加 12 个百分点
  换 5 倍结局**——资源该投向"跨线",不是"撒匀"。

### 落点 3:反馈极性的事前判定

- 任何"预期管理"类设计(公告/指标公开/排名)先填机制卡定极性:
  它走自我实现(正)还是自拆台(反机制)方向?极性定错,干预
  方向相反(03 章引擎 2)。把极性判定写进设计评审的 checklist,
  而不是出事后再拟合。

### 落点 4:理论资产的数据纪律

- 团队的知识库若存理论/框架笔记,按三卡 schema 结构化:字段强制
  (影子/反机制/盲区非空),聚合可查(哪台机器是我们的默认机器?
  账单付了吗?)——**默认机器的盲区=团队系统性盲区**,一年审计
  一次。

## ✍️ 练习

1. 🐍 给走廊 3 实现最小校验器:三张卡各一个 dict schema,断言
   影子/反机制/盲区字段非空;给你最常用的两个框架填卡并过校验
2. 🐍 在实验里把幕三扩展成双扫:分布(改 0.60 团为 0.50/0.55)+
   种子(0.05-0.30 步长 0.05)的网格,画出阶梯边界随团簇阈值
   移动的轨迹
3. ✋ 把自我实现预言写成两行差分方程(信念→行动→世界→信念),
   在纸上推三轮;再写它的反机制版对照——机制卡的算法化预习
4. ✋ 用落点 1 体检一个你维护的业务面板:它盯的是均值还是形状?
   补一个"团簇衔接"指标(如相邻意愿档的人群间隔),并写出它
   的报警语义
