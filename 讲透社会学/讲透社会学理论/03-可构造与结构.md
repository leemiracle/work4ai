# 03 · 可构造与结构:哪些理论对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:社会学理论的对象沿一条**可构造谱系**排开——
> 阈值分布端**严格可构造**(分布写得下、级联算得动、不动点断言得
> 了),惯习与理解端**几乎不可构造**(只有思想操作化,没有装配学);
> 全谱系共享两条结构引擎:**分布形状决定不动点**(级联引擎)与
> **反馈环决定动力学**(预言/安全阀引擎);而"理论机器"本身可以
> 被压进三张**结构卡**(坐标系卡/概念对偶表/机制卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
阈值分布 ── 理论坐标系卡 ── 概念对偶表 ── 机制卡 ── AGIL清单 ── 理想类型 ── 惯习 ── 理解(Verstehen)
  │                                                                              │
严格可构造(可断言)                                              几乎不可构造(只有思想操作化)
  └── 写得出、采得出、算得动、能过 assert                              └── 只能在阅读与田野里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:阈值
分布的语义是"每人的门槛数",输入输出明确;而"理解"的语义是进入
行动者的意义世界——**描述者本人就是测量仪器**,仪器无法装配仪器。
本章先盘家底,再看两条结构引擎,最后把整台理论机器压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **阈值分布→集体结局** | 阈值列表 {τᵢ}+种子 x₀;迭代 x_{t+1}=max(#{τᵢ≤x_t}/n, x_t) 至不动点 | 低(家族实验全程可跑) | 阈值的经验测量(问卷自报有社会期许偏误;正式模型侧归数理社会学,文字提及) |
| **理论坐标系卡** | 三轴坐标+假设+盲区+盟友/对手的固定字段表 | 低(§四 schema) | 坐标定级带主观性;须双人独立定再对表 |
| **概念对偶表** | 对偶/影子/失效条件三字段 | 低 | "影子"找不全=概念还没工作(02 章铁律) |
| **机制卡** | 输入→环节链→反馈极性→反机制→可检验推论 | 中 | 环节链的每一步都应是可指认的社会过程,不能塞黑箱动词 |
| **AGIL 功能清单** | 对一个制度/组织做四功能记账 | 中 | 半构造:格子里装什么高度依赖分析者;**潜功能的发现无法程序化** |
| **理想类型比较** | 造纯型→量个案偏差 | 中 | 标尺是人为磨尖的,比较结论只对标尺负责 |
| **惯习** | 只有思想操作化(实践的同构性) | 高 | **构造学缺席**——可测量(代理量表)≠可构造≠可注入 |
| **理解(Verstehen)** | 阅读与田野的移情重建 | **不可构造** | 意义不可压缩成参数;压缩即失真(韦伯的方法论本意) |

**反直觉发现(本章铁律)**:**构念的名气与可构造性成反比是常态**。
最有名的词(惯习/理解/生活世界)全在谱系右端,最能跑的对象(阈值
分布)名气最小。**右端管洞察,左端管检验**;用右端对象硬造左端指标
(拿五题量表造"惯习指数"再 causal 建模)是本学科量化研究的头号
失真来源——两头都不是。

## 二、结构引擎 1:分布形状决定不动点(级联引擎)

**直觉图像**:宏观结局不是微观倾向的加总,而是微观倾向**衔接结构**
的函数——每一团人踩出的参与率,决定下一团人的门槛是否被够到。

- **数学化身**:n 人阈值 {τᵢ},种子 x₀,
  x_{t+1} = max(#{i:τᵢ≤x_t}/n, x_t),单调不减有上界,必收敛到
  不动点 x*(满足 F(x*) ≤ x*)。稳态由分布与种子**完全决定**。
- **三条刚性**(家族实验的三律即其数值化身):
  1. **均值不守恒**:同均值(0.40)的三种形状 → 稳态 40%/10%/20%
     (幕一);均值更低(0.28)的形状 → 稳态 100%(幕二)。宏观
     结局对均值几乎不敏感,对**团簇间的衔接**极其敏感。
  2. **相变而非斜坡**:种子从 0.10 提到 0.22,分布 B 的稳态从 10%
     跳到 50%;跳跃边界恰在团簇阈值 0.20(幕三)——临界种子规模
     是门槛不是斜率。
  3. **刀锋级联**:完全级联要求每团恰好踩进前团脚印(E 的第二跳
     靠 0.40 恰等于 40/100;幕四蒙特卡洛显示它是稀有形状)。
- **理论地位**:这是"微观-宏观之桥"(00 章 §四未决问题)在形式
  侧最干净的一段:聚合规则明白写着(max 与计数),没有任何隐藏
  变量——正因如此,它是理论直觉的**校准器**:任何"群体会怎样"的
  定性预言,先问它的隐含阈值分布长什么样、衔接是否成立。
- **刚性从哪来**:级联的数学是刚的(不动点唯一);软的地方在
  **阈值从哪测**——实验里我们直接指定分布,现实里要靠调查与行为
  数据反推(方法侧问题,归社会学方法家族,文字提及)。

## 三、结构引擎 2:反馈环决定动力学(预言/安全阀引擎)

**直觉图像**:社会定义会反身地改写它所描述的世界——这是社会学
对象与物理对象的本质差别(吉登斯"双重解释学"的机制层)。

- **正反馈化身:自我实现预言(默顿)**。输入:一个关于未来的公开
  定义;环节:定义改变行动者的情境计算→行动按定义重组→世界向
  定义收敛→定义更可信。银行挤兑是最小完整例:谣言→提款→
  流动性危机→谣言"应验"。
- **负反馈化身:安全阀(科塞)**。冲突能量经制度化的细通道释放,
  张力回落,结构维稳——输出反作用于输入,削减偏差。
- **对偶化身:自拆台预言(self-defeating prophecy,默顿同文)**:
  公开的坏预测引发预防行动,使预测落空——正反馈的影子机制,
  也是"预言类"机制卡的必备字段。
- **刚性从哪来**:反馈极性(正/负)一旦定错,政策方向南辕北辙——
  把安全阀读成正反馈(压制释放通道),系统压力走向结构撕裂而非
  回落。**极性判定是理论判断,不是数据拟合**:同一根曲线,两台
  机器读出两种极性——这正是理论不可被统计替代的地方。

## 四、结构卡 schema:把一台机器压进三张卡

**先答为什么**:理论机器的难点在"整体性"——读散落文献难以携带。
结构卡是**有限字段的压缩格式**:字段固定、填空即可复用、可比可查
可补(这是"可构造"在理论层的对应物:卡片本身严格可构造)。

### 卡 1:理论坐标系卡(把一台机器钉进 00 章的三轴)

```
【理论坐标系卡】
理论名:________
三轴坐标:结构(0-10):___ / 秩序-冲突(0-10):___ / 微观-宏观(0-10):___
买入假设(≤3 条):________
付出盲区(≤3 条):________
招牌机制(挂机制卡):________
可构造代理(谱系位置):________
盟友/对手(同轴相邻/对角机器):________
一句话鉴定(它救了哪个解释危机):________
```

样例(已填,布迪厄综合论):结构 6(结构入身)/冲突 6/桥 7;
买入:惯习使结构入身、实践合逻辑而无须逻辑、资本可转换;
盲区:循环论证风险、能动性弱化、时间性(变迁)偏弱;
机制卡:惯习-场域同构;可构造代理:场域位置×资本分布表;
盟友:吉登斯(同为综合);对手:理性选择论(把惯习换成计算);
一句话:救"结构与能动二选一"的危机。

### 卡 2:概念对偶表(把 02 章的户口本做成可填表)

```
【概念对偶表】(每个核心概念一行)
概念 | 影子(对偶的另一半) | 失效条件(哪里它不再工作) | 血统 | 误用高发区
---- | ---- | ---- | ---- | ----
```

样例行:潜功能 | 显功能 | 当行动者预知并接纳后果(潜→显) | 默顿 | 阴谋论化;
惯习 | 场域(外/内) | 场域剧变期(惯习滞后失配,恰是变革时刻) | 布迪厄 | 问卷化。

### 卡 3:机制卡(把一个社会过程写成带反馈的链条)

```
【机制卡】
机制名:________
输入:________
环节链(每格须可指认为社会过程):____ → ____ → ____ → ____
反馈极性:正 / 负 / 混合(何时翻转:________)
反机制(影子):________
可检验推论(一条):________
已知实例(经典案例):________
```

样例(已填,自我实现预言):输入=公开的未来定义;环节链=定义改变
情境计算→行动重组→世界收敛于定义→定义增信;反馈=正;
反机制=自拆台预言;可检验推论=预言成真率应随"情境的预期依赖度"
上升而上升(银行挤兑型情境>天气型情境);实例=挤兑/考试焦虑/
师长期望(皮格马利翁效应,教育侧见
[../../讲透教育学/讲透教育社会学/README.md](../../讲透教育学/讲透教育社会学/README.md))。

**判定流程**(把一个理论主张钉到谱系上):

```
该主张的核心对象能写成分布、清单或链条吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(清单/标尺,填空带判断)─▶ 中段:卡片化+双人校,禁止硬算
  └─ 不能(意义/规范/理解)─────▶ 右端:思想操作化+田野,禁止压成参数
```

## 五、谱系×引擎×板块总表(把全家族钉在一张图上)

| 板块(原理支内部分节) | 谱系位置 | 主引擎 | 可构造等级 |
|--------|---------|--------|-----------|
| 结构功能主义 | 中段(AGIL 清单/理想类型) | 反馈环(负反馈维稳为主) | 中(卡片+清单,填空带判断) |
| 冲突与批判理论 | 中段偏右(权威结构可清单化,批判规范在右端) | 反馈环(正反馈:对立的组织化) | 中(权威关系可映射;规范判断不可构造) |
| 符号互动与交换论 | 左端(交换命题可算)到右端(理解不可构造)横跨 | 级联(微观聚合)+交换结算 | 分裂:命题集可算,意义不可 |
| 当代理论综合 | 右端为主,场域位置表为中段 | 双引擎并用(级联+反馈) | 低-中(位置表可构造,惯习不可) |

**读表法**:一个板块的"可构造纯度"决定它的转码方式(04 章)——
交换论与阈值类对象走计算,功能清单与位置表走卡片,理解与惯习
永远走阅读。**没有哪个板块全家可构造,也没有哪个板块全家不可
构造**;[思想史支](讲透社会思想史/README.md)纵切全部板块,
其自身对象(思想谱系)整体住在谱系右端(只有思想操作化)。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——把一百年理论史装进上衣口袋**(极简)
坐标系卡定位(哪台机器、什么账单),对偶表验货(影子在哪、哪里
失效),机制卡开机(输入什么、反馈哪极、反机制是谁)。为什么美:
**它把"读懂理论"变成"填得出卡"——可检验性从实验室移进阅读**;
三张卡互相引用(坐标卡挂机制卡,机制卡用对偶表验极性),一台
机器的强度与磨损一目了然。亲历:挑一台你信的机器填三张卡
(✍️练习 1),填不出的格子就是你的盲区地图。
