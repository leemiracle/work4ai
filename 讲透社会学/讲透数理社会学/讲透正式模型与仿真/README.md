# 讲透正式模型与仿真 · 涌现的机器——规则跑起来,格局自己长

> **定位句**:这支管**动力学**:Schelling 隔离/阈值级联/元胞自动机/基于主体建模 ABM——
> 给定微观规则与更新纪律,让宏观格局在机器里**自己长出来**;涌现=终态与规则字面义的差值。
> **自定支**(GB/T 84024 无三级明细,家族自定三分)。家族:[讲透数理社会学](../README.md)

## 诞生

- **谁/何时**:Schelling〈动态隔离模型〉(1971,《数学社会学杂志》创刊同年,硬币-棋盘演示);
  Granovetter〈阈值模型〉(1978);元胞自动机传统(冯·诺依曼-乌拉姆系)入社会学;
  Epstein-Axtell 糖域(1996)示范 ABM;Epstein「没长出来就没解释它」(2006)立生成主义纲领。
- **因什么问题**:①宏观格局能否由温和微观规则涌现(涌现之问)②仿真算不算解释
  (生成主义之问,00 章 §二)③参数没有经验根据的模型算什么(校准之问)。

## 核心问题

**已解决(通说)**:
- 温和偏好滚成接近完全的隔离;t=0.3 终态 0.7612>初始 0.4944(实验幕一)
- 偏好-隔离映射严重次线性:偏好+0.4 只买到隔离+0.2309,代价迁移×8.2(幕一如实标注)
- 阈值级联:命运由分布形状而非均值决定(理论侧由社会学理论家族展开,文字提及)

**未解决/深水区**:
- ABM 的可证伪性:同一格局多套参数可生成,生成充分性是门槛不是判决
- 规则的经验根据:现实中的人真的按这条规则走吗(测量归方法家族)
- 简化模型的政策边界:模型论证"可能",不论证"现实如此"

## ✨ 这支最美的一个事实

**谢林的硬币**:1971 年前后,一台复现城市隔离的社会机器,全部家当是一副棋盘、
黑白两种硬币、一条规则——"同类邻居不足三成就搬"。**社会结构在这里从名词变成动词**:
不需要制度、阴谋或态度测量,温和的局部规则自会滚出宏观的铁格局;模型的美学
在"最少假设买最深涌现"。

## 假设与依赖

- 买入"局部规则+同质主体+固定纪律":账单是规则的经验根据薄、均衡≠历史(00 章 §五)
- 更新纪律(同步/异步/轮内重查)是语义不是实现细节,换纪律要重新验收(实验幕一的纪律字段)
- 参数三档自报(指定/校准/裸泳):裸泳结论不进决策链(04 章落点 4)
