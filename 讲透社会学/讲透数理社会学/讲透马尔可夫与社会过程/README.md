# 讲透马尔可夫与社会过程 · 过程的语言——社会往哪里去

> **定位句**:这支管**时间**:状态转移/流动表 Blau-Duncan/吸收态与稳态——把"流动""固化""继承"
> 写成转移矩阵,问过程的目的地(平稳分布)与不可逆点(吸收态)。
> **自定支**(GB/T 84024 无三级明细,家族自定三分)。家族:[讲透数理社会学](../README.md)

## 诞生

- **谁/何时**:马尔可夫链(1906)入社会科学;Blau-Duncan《美国职业结构》(1967)把代际流动
  写成**流动表**并对角线-非对角分解;Coleman 用链模型解集体趋同;社会流动矩阵学派
  (Duncan 路径分析同源)。PNAS 2011 的 Markov 链网络隔离模型是结构×动力学×时间
  三支同框的经典前站(01 章主线 B)。
- **因什么问题**:①流动与固化能否定量化(固化=吸收态的存在,不是形容词)②长期趋势
  能否从单期转移推出(平稳分布之问)③无记忆假设贵不贵(马尔可夫性之账)。

## 核心问题

**已解决(通说)**:
- 流动表的分解核算:对角线=继承,非对角=交换;"开放"与"继承"可以同表并读
- 平稳分布与吸收态的可解性:π=πP;吸收态一旦可达,质量终将聚齐
- 单期外推的失效:中间态的增长常是稳态的延迟到达(04 章落点 3)

**未解决/深水区**:
- 无记忆性的现实性:社会过程带记忆(声誉/履历/路径依赖),链模型切掉的是什么要逐案核算
- 状态划分的理论地位:阶层怎么分档是理论决定,划分变结论变(02 章红色区)
- 非平稳世界:转移率本身随时代漂移,稳态解的适用期限

## ✨ 这支最美的一个事实

**Blau-Duncan 流动表**:一张行=父亲职业、列=儿子职业的计数表,把"美国梦"变成
可核算的矩阵——对角线是继承的重量,对角线之外是交换的宽度;"社会有多开放"不再是
修辞之争,而是同一张表上两种读法的差。**一门关于命运的宏大叙事,被压进一张
可以除法的表格**。

## 假设与依赖

- 买入无记忆性:下一状态只看当前——账单是路径依赖被切掉、稳态≠历史(00 章 §五)
- 状态划分是构造判断:分档即理论,先声明划分再谈矩阵(03 章规格卡)
- 平稳分布对转移率敏感:尾档小概率要平滑再迭代,断言只锚结构不锚尾数(04 章走廊 3)
