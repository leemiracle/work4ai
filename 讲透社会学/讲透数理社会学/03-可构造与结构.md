# 03 · 可构造与结构:哪些社会对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:数理社会学的对象沿一条**可构造谱系**排开——
> 生成器端**严格可构造**(WS/BA 图、转移矩阵、Schelling 规则:
> 写得出、跑得动、断言得了),机制的经验实在端**几乎不可构造**
> (现实里的人真的按这条规则走吗?只有测量,没有装配);全谱系
> 共享两条结构引擎:**局部规则×聚合算子**(涌现引擎)与**生成-
> 对照**(零模型引擎);而"模型"本身可以被压进三张**结构卡**
> (模型规格卡/参数扫描卡/稳健性卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
WS/BA 生成器 ── 转移矩阵 ── Schelling 规则 ── 中心性/结构洞 ── 流动表 ── 阈值分布 ── 机制的经验实在
  │                                                                              │
严格可构造(可断言)                                                几乎不可构造(只有测量通道)
  └── 写得出、跑得动、能过 assert                              └── 参数要从行为数据反推,构造学缺席
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:BA
生成器的语义是"新点按度数比例连 m 条边",输入输出明确,跑一万次
都是它;而"现实中的连接偏好"的语义要先问**测量**(你从哪个数据、
用什么识别策略、凭什么排除适应度与老化的竞争解释)——构造学在
那里让位给方法学。本章先盘家底,再看两条结构引擎,最后把整台
模型压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **WS/BA 生成器** | 参数(n,k,p / n,m)+固定种子→图 | 低(家族实验幕二/三全程可跑) | 图是模型世界,不是任何真实网络;参数的语义外推要有零模型陪审 |
| **转移矩阵 P** | 状态×状态的概率表;π=πP 解平稳分布 | 低 | 状态划分本身是理论决定(阶层怎么分档,马尔可夫支的头号构造判断) |
| **Schelling/CA 规则** | 规则表+网格+更新纪律→终态 | 低 | 更新纪律(同步/异步/序)是语义的一部分,换纪律要重新验收 |
| **ABM** | 主体参数+交互协议→轨迹 | 中 | 参数自由度大;同一终态常有多套参数能生成(非唯一性问题) |
| **中心性/结构洞** | 图+度量公式→数值 | 中(图要从数据来) | 度量选择即理论选择(三种中心性=三把不同的刀,02 章) |
| **流动表** | 出身×到达的计数矩阵+分解 | 中 | 表格可构造,但"对角线=继承"的语义要模型兜底 |
| **阈值分布** | 指定着仿真完全可构造;**测量**是另一回事 | 高(测量侧) | 问卷自报有社会期许偏误;行为反推是识别问题(方法侧正主) |
| **机制的经验实在** | 没有装配学,只有证据链 | **不可构造** | "现实按此机制运行"的断言永远=模型+测量+对照的合取,模型只是三分之一 |

**反直觉发现(本章铁律)**:**模型的可构造性与断言的强度成反比是
常态**。最能跑的对象(生成器)断言最弱("在此机制**下**会如此"),
最想下的强断言("现实**就是**如此")恰好落在谱系右端。用左端的
流畅冒充右端的断言,是数理社会学被批评"玩具"的总根源——正确的
姿势是**合取记账**:模型断言+测量证据+零模型对照,三条都齐才升格
为经验命题。

## 二、结构引擎 1:局部规则×聚合算子(涌现引擎)

**直觉图像**:宏观格局不是微观动机的加总,而是微观规则**跑起来**
的产物——涌现=终态度量与规则字面义之间的差值。

- **数学化身**:状态空间 S+规则 F:S→S,迭代 x_{t+1}=F(x_t);
  聚合算子 M(x)(隔离度/路径长度/参与率)是读数仪表。断言锚在
  M(x_∞) 与 M(x_0) 的差上。
- **三条刚性**(家族实验三幕即其数值化身):
  1. **放大**:t=0.3 的规则字面义(三成同类即可)→终态隔离度
     0.7612,是需求的 2.5 倍(幕一)。涌现的方向是放大。
  2. **次线性**:偏好 +0.4 只买到隔离 +0.2309,代价迁移×8.2
     (幕一)——涌现对参数的弹性不是常数,温和段最陡。
  3. **杠杆**:聚合度量对结构的微小改动极度敏感——1% 的边重连
     买走 82% 的距离(幕二);同样边数换生成机制,最大度 12→102
     (幕三)。
- **刚性从哪来**:规则明确、算子明确,断言就能过 assert——这是
  谱系左端的全部刚性。软的地方在**规则的经验根据**(§一右端),
  引擎本身不解决合法性,只解决推演。

## 三、结构引擎 2:生成-对照(零模型引擎)

**直觉图像**:"这个格局很特别"是形状断言,不是机制断言;要变成
机制断言,必须问:**换成没有这个机制的世界,格局还在吗?**

- **数学化身**:零模型=保留指定约束(边数/度序列)的随机化世界;
  断言=真实(或机制)世界与零模型的度量差。
- **三个标准对照**(实验实拍):
  1. **BA vs ER**(幕三):同 3997 条边,ER 最大度 12,BA 102
     ——差值就是"优先连接"这个名字的全部内容。
  2. **WS vs 规则环格**(幕二):p=0 的环格是零模型,L(0)=50.45;
     1% 重连后 L=8.96——差值就是"捷径"的全部内容。
  3. **终态 vs 初态**(幕一):随机混合格局是零模型,终态隔离度
     0.7612 对初始 0.4944 的差,就是"迁移规则"的全部内容。
- **刚性从哪来**:零模型把"机制产物"从形容词变成差值——但零模型
  本身也是假设(均匀随机是强假设;度序列保持的配置模型与 ER 给出
  不同裁判)。**对照的选择要随断言走**:谈枢纽用 ER,谈聚类相关
  用配置模型(进阶,文字提及)。

## 四、结构卡 schema:把一台模型压进三张卡

**先答为什么**:模型的难点在"整体性"——参数、纪律、断言散落
正文,难以携带与复核。结构卡是**有限字段的压缩格式**:字段固定、
填空即可复用、可比可查可补(这是"可构造"在模型层的对应物:卡片
本身严格可构造,家族实验就是三张卡的实例)。

### 卡 1:模型规格卡(一台模型的身份证+说明书)

```
【模型规格卡】
模型名:________  底盘:空间网格 / 网络 / 在线平台(01 章主线A的换底盘字段)
状态空间:主体=?  状态=?  自由度(可迁/可连)=?
局部规则:若________ 则 ________(一行写完;写不完=规则未定稿)
更新纪律:同步 / 异步随机序 / 异步固定序;轮内重查:是/否
聚合算子:报告哪个度量(M=________;别报均值就完事)
终止条件:全满足 / 步数上限 / 度量停动
断言(可锚数值):________
参数的经验根据:指定 / 校准 / 裸泳(三档自报)
```

样例(已填,Schelling 空间版,即实验幕一):底盘=20×20 空间网格;
状态空间=400 格,两类各 120 人+160 空位,自由度=空位;局部规则=
相邻同类占比<t 则迁往随机空位;更新纪律=异步随机序+轮内重查;
聚合算子=平均同类邻居占比(隔离度);终止=全员满足或 300 轮;
断言=t=0.3 终态 0.7612>0.7;参数根据=指定(仿真侧)。

### 卡 2:参数扫描卡(一个结论的地形图)

```
【参数扫描卡】
扫描维度:________(如 p∈[1e-4,1] 对数 9 档 / t∈{0.3,0.7})
固定量:________(n、k、m、规则、纪律全冻结)
种子纪律:seed=base+格号(逐格可复现;换种子结论抖动多大要报)
读数表:维度值→度量值(全表列出,不挑档展示)
断言锚:只锚结构(单调性/交叉带存在性/量级),不锚浮点尾数
地形结论:________(哪个参数段结论成立,边界在哪)
```

样例(已填,WS 扫描,即实验幕二):扫描=p 对数 9 档;固定=n=1000、
k=10;种子=SEED_BASE+100+idx;读数=L/L0 与 C/C0 双列;断言锚=
存在 p∈[0.01,0.1] 使 L 比<0.5 且 C 比>0.5(交叉带存在性);
地形=交叉带在 0.01-0.1,p≥0.5 后 C 崩塌(小世界消失)。

### 卡 3:稳健性卡(一个结论的抗打击档案)

```
【稳健性卡】
结论:________
扰动维度逐项记录:
  换种子:结论变化?幅度?
  换实现纪律(同步/异步/重查):结论保持?
  换规模(n/SIDE):结论的量级漂移?
  换底盘(空间→网络):结论是否重验过?(01 章判读要点1)
如实标注栏:与预期/文献不符的实测,原样记录(不得裁剪)
```

样例(已填,幕一的 t=0.7 对照):结论=隔离不是偏好的镜像;扰动=
边长 8/10/12/16/20/30 与三种更新纪律下 t=0.7 均收敛至 ≈0.99(建模
期专项核查);如实标注=任务预期的"高阈值震荡不收敛/隔离反降"在
本参数域(30/30/40 随机迁入)不出现,结论以实测为准,断言改锚
次线性(偏好+0.4→隔离+0.23)——**稳健性卡的如实标注栏就是本家族
"实验数值与文献通说不符处以实测为准"纪律的落点**。

**判定流程**(把一个主张钉到谱系上):

```
该主张的核心对象能写成生成器、矩阵或规则表吗?
  ├─ 能,且语义有限确定 ──────▶ 左端:直接实现+转码(04 章走廊)+零模型对照
  ├─ 能一半(度量可算,数据依赖)─▶ 中段:卡片化+测量侧供货(方法家族)
  └─ 不能(机制的经验实在)─────▶ 右端:证据链合取记账,禁止"仿真即证明"
```

## 五、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 网络分析支 | 左端(生成器/度量)到中段(结构洞要数据) | 零模型引擎为主 | 高(度量全部可算;语义解释带理论判断) |
| 正式模型与仿真支 | 左端(规则表)到右端(规则的经验根据)横跨 | 涌现引擎为主 | 分裂:推演可构造,合法性靠测量 |
| 马尔可夫支 | 左端(矩阵/平稳分布)到中段(流动表) | 两引擎并用(链的极限+零模型对照) | 高(解可断言;状态划分是构造判断) |

**读表法**:一个支的"可构造纯度"决定它的转码方式(04 章)——
生成器与链走计算,度量与流动表走数据接口,机制合法性永远走合取
记账。**没有哪个支全家可构造,也没有哪个支全家不可构造**。

## ✨ 美之时刻(彩蛋第 6 枚:结构卡)

✨ **美之时刻 6:三张卡——把一台模型装进上衣口袋**(极简)
规格卡验身(状态空间、规则、纪律,缺一格模型就没定稿),扫描卡
画地形(结论在哪个参数段活着),稳健卡过堂(换种子换纪律换底盘,
结论还活着吗,不符处如实标注)。为什么美:**它把"读懂模型"变成
"填得出卡"——可复核性从同行善意移进字段纪律**;实验幕一那个
如实标注栏,就是三张卡里最诚实的一格。亲历:给你信的一个模型结论
填三张卡(✍️练习 1),填不出的格子就是你的裸泳清单。
