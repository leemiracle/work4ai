# 讲透社会网络分析 · 网络的语言——格局藏在连线里

> **定位句**:这支管**结构**:度分布/中心性/小世界/结构洞——把「谁连着谁」当成第一性事实,
> 问同样的连线数为什么长出不同的格局(有没有枢纽、有没有桥、圈子抱多紧)。
> **自定支**(GB/T 84024 无三级明细,家族自定三分)。家族:[讲透数理社会学](../README.md)

## 诞生

- **谁/何时**:莫雷诺社会计量图(1934)给关系画几何;Harary-French 图论与 Freeman 中心性
  (1977/1979)造度量;White 块模型(1976)与 Burt《结构洞》(1992)造位置理论;
  Watts-Strogatz(1998)与 Barabási-Albert(1999)带来小世界与优先连接的生成机制。
- **因什么问题**:①格局能否不问内容先从连线解出(结构之问)②哪些位置有结构性红利
  (位置之问)③同样的边数为何格局悬殊(机制之问——家族实验幕二/幕三)。

## 核心问题

**已解决(通说)**:
- 小世界现象的生成机制:少量捷径买走大部分距离而圈子几乎不破(实验幕二:L/L0=0.178、C/C0=0.973)
- 优先连接生成幂律枢纽;同边数 ER 无枢纽(实验幕三:最大度 102 vs 12)
- 结构洞的中介逻辑:横跨互不往来圈子者坐拥信息差价

**未解决/深水区**:
- 网络数据的因果识别(关系内生/边界问题/样本相依三重围攻)
- 结构洞的当代再检验(平台数据第二波,01 章主线 D)

## ✨ 这支最美的一个事实

**弱关系的力量(Granovetter 1973)**:找工作最管用的不是至亲密友,而是**不常见面的熟人**——
亲密圈里信息互相重复,弱关系才是圈子之间的桥:一条低维护成本的边,承载着圈外的全部世界。
**信息的价值不在关系的强度,而在它通向哪里**——把"人脉"从道德词(多走动)改写成
几何词(你的边指向哪些没有互连的圈子)。
