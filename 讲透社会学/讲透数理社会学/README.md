## 一、家族定位

- **三支分工**:同一门「微观规则如何长成宏观格局」之问的三种语言——
  **网络支**问**结构**(谁连着谁:度分布/中心性/小世界/结构洞),
  **仿真支**问**动力学**(规则怎么跑:Schelling 隔离/阈值级联/元胞
  自动机/基于主体建模),**马尔可夫支**问**时间**(过程往哪去:状态
  转移/流动表/吸收态与稳态)。
- **一条主线贯穿**:微观规则 × 聚合算子 → 宏观格局,聚合**不可还原为
  均值**——温和偏好滚成完全隔离(实验幕一),1% 捷径买走 82% 的距离
  (幕二),同样的连线数因生长机制长出枢纽(幕三)。
- **零门槛**:不要求社会学前置;想看理论直觉去社会学理论家族(文字
  提及),想看数据工艺去方法家族,本家族是它们共同的**形式底座**。
- 路线 A(问题派):为什么没有种族主义的城市也会隔离?→00 §七+实验
  幕一;为什么「朋友的朋友」这么近?→幕二+网络支
- 路线 B(体系派):00→01(前沿)→02(语言)→03(可构造)→04(转码)
- 路线 C(研究派):00→01(文献地图)→各支教材锚
- 工程师快轨:直接跑 [`experiments/networks_and_emergence.py`](experiments/networks_and_emergence.py),再回读 04 章

> 动力学、时间在模型里从来是一件事。
