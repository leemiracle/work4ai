# 04 · 数理社会学转代码:把形式引擎搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:数理社会学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**涌现**(规则跑出格局)、
> **结构对照**(零模型差值)、**过程**(矩阵的极限)——把"温和
> 偏好滚成隔离""捷径的杠杆""枢纽是机制产物"变成可跑、可扫、
> 可断言的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",数理社会学转代码要解决"**登记**":
把一段社会直觉("没偏见的城市也会隔离")先翻成模型(状态空间+
规则+聚合算子,03 章规格卡),再翻成代码。翻译的合法性损耗全部
发生在第一步——所以本章先划清哪些对象第一步就走得通(绿色区),
哪些走不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 模型对象 | 代码化身 | 备注 |
|---------|---------|------|
| WS/BA 生成器 | 参数+种子→邻接表 | 家族实验幕二/三全程纯标准库 |
| 图度量(度/L/C/中心性) | BFS 与集合运算 | L 用采样源降本;C 是邻居对查边 |
| Schelling/CA/ABM | 规则表+网格+更新循环 | 幕一;更新纪律写成显式参数 |
| 转移矩阵→平稳分布/吸收概率 | 幂迭代或线性解 | 马尔可夫支的标准件 |
| 参数扫描 | 双重循环+逐格种子(seed=base+格号) | 幕二;可并行,逐格可复现 |
| 幂律尾检验 | 累积分布 log-log 回归+R² | 幕三;拟合段要设计数下限闸 |
| 零模型 | 同约束随机化(ER/置换) | 幕三的 ER;一切机制断言的对照组 |
| 结构卡 schema | 定长字段记录+完整性断言 | 03 章 §四;元数据工程 |

**转不动(红色区)**:

1. **参数的经验校准**:阈值、转移率、容忍度从行为数据反推是测量
   与识别问题(方法侧正主,[../讲透社会学方法/README.md](../讲透社会学方法/README.md))
   ——仿真可以指定参数,不能冒充测得参数。
2. **模型选择**:"哪个机制更真"没有算法裁决——生成充分性是门槛
   不是判决(00 章 §二);同格局多机制可生成时,只能靠附加证据
   合取记账。
3. **状态划分的社会判断**:阶层怎么分档、什么算"同类"——划分
   本身是理论决定,代码只执行不发明。
4. **规范之问**:"隔离该不该干预""枢纽该不该拆"——代码算差值,
   算不出应然(归公共讨论与哲学侧,文字提及)。

**边界的一句话**:绿色区=生成器类+度量类+扫描类,覆盖"形式直觉
的推演与对照";红色区提醒:**代码是模型的使用说明书,不是社会
本身的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:涌现走廊(规则跑出格局)

```
Schelling 规则 ──登记──▶ 网格+规则表+更新纪律 ──迭代──▶ 终态+隔离度
      │
      └──对照──▶ t=0.3 vs t=0.7(偏好-隔离的次线性)/ 初态 vs 终态(放大)
```

- **理论→模型**:规格卡字段直译(03 章卡 1):状态空间=格位与类型,
  规则=同类占比<t 迁往随机空位,纪律=异步随机序+轮内重查。
- **算法层**:每轮扫全员定不满意者(每人数 8 邻),随机序迁移;
  终止=全员满足或步数上限。O(轮数×格数)。
- **本家族实现**:[`experiments/networks_and_emergence.py`](experiments/networks_and_emergence.py)
  幕一——断言 0.7612>0.7 与次线性(+0.4 偏好→+0.2309 隔离)。
- **真实系统**:社区混居政策的压力测试(改容忍度参数不如改迁移
  摩擦)、平台取关动力学的沙盘、组织分群的早期预警。
- **性能工程要点**:邻居查询用预生成偏移表(省掉每次边界判断);
  空位表用数组+pop(randrange) 维护 O(1) 迁移;大规模上 numpy 化
  卷积查不满意者;**纪律即语义**——同步与异步不能互相"优化"替代。

### 走廊 2:结构对照走廊(零模型差值)

```
"格局很特别" ──参数化──▶ 度量(真实/机制世界) vs 度量(零模型) ──▶ 差值=机制的名字
      │
      └──双扫──▶ WS: p 扫描看 L/C 交叉带;BA vs ER: 同边数比最大度
```

- **理论→模型**:对照设计随断言走——谈捷径用规则格作零(幕二),
  谈枢纽用同边数 ER 作零(幕三)。
- **算法层**:L 用多源 BFS(采样每 4 个节点一个源,准确度足够锚
  结构断言);C 是邻居对查边;BA 偏好连接用**端点池**(stubs 列表,
  度数出现次数=连接权重)O(1) 抽样;ER 用拒绝采样造无重边图。
- **本家族实现**:同实验幕二/幕三——断言交叉带存在与 R²>0.98、
  最大度 102 vs 12。
- **真实系统**:枢纽监控(节点的度是否超出零模型 3σ)、推荐冷启动
  (该不该人为加捷径边)、"头部效应"归因审计。
- **性能工程要点**:多源 BFS 是 O(源数×(V+E)),全源在大图上乘
  V——**采样源+断言锚结构不锚尾数**是标配;端点池抽偏好连接严格
  O(1),别用"每次遍历算累积度"的 O(V) 教科书写法;扫描天然可并行,
  seed=base+格号保证逐格复现。

### 走廊 3:过程走廊(矩阵的极限)

```
"流动/固化" ──登记──▶ 转移矩阵 P ──迭代/求解──▶ 平稳分布 π 与吸收概率
      │
      └──对照──▶ 流动表分解(对角线=继承;非对角=交换) vs 完全流动零模型
```

- **理论→模型**:状态=职业/阶层分档(划分是理论判断,红色区借道),
  P_ij=一代人从 i 档到 j 档的比例;马尔可夫性是买入的假设(账单:
  路径依赖被切掉,00 章 §五)。
- **算法层**:π=πP 幂迭代(稀疏矩阵上 O(非零元×迭代数));吸收
  态分析=把矩阵化为规范形再解线性方程组。
- **本家族实现**:schema 与走法在马尔可夫支(待产),家族实验
  未覆盖——留作 ✍️练习 2 的最小实现。
- **真实系统**:组织晋升管道的稳态推演(招人结构不变,N 年后各层
  常住构成)、教育分层政策的长期核算、"固化"指控的定量化
  (吸收态有几个、可达性如何)。
- **性能工程要点**:转移矩阵通常极稀疏——邻接表+向量化幂迭代;
  收敛判据用 L1 漂移;**平稳分布对 P 的条件数敏感**,小概率格档
  要平滑(加伪计数)再迭代,否则尾档 π 抖动毁断言。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:枢纽与级联监控面板——对着零模型报警

给任何关系型业务(交易/通信/关注/调用)配一层**零模型参照**:
节点度、介数超出同规模随机图多少个 σ 才报警——绝对阈值会把
正常枢纽当事故,把机制产物当离群点(幕三的教训:102 vs 12,
量的差别是机制的差别)。

### 落点 2:跨圈层的捷径投资——先算交叉带

任何"打通两个群体"的设计(跨部门协作/跨市场拓展/社交破冰),
先问幕二的地形:已有连接的 L/C 在哪一档?要买断多少条捷径才能
把距离砍半而不拆圈子——**1% 的边能买 82% 的距离**,预算该按
边际距离算,不该按边数算。

### 落点 3:迁移/流失的稳态推演——别用单期外推

用户或人员的流入流出不要拿单期净额线性外推:登记成转移矩阵,
幂迭代到平稳分布再看终态——中间态的"增长"常常只是稳态的延迟
到达,而吸收态(流失池)的存在会彻底改写叙事。

### 落点 4:仿真参数的合取记账——给裸泳上锁

团队里任何"模型说会如此"的结论入库时,按规格卡强制填报**参数的
经验根据**三档(指定/校准/裸泳)——裸泳参数的结论默认只作探索,
不得进决策链;这是 03 章红色区在工程流程里的最小执法。

## ✍️ 练习

1. 🐍 给走廊 3 写最小实现:构造 3×3 转移矩阵(含一个吸收态),
   幂迭代求平稳分布,断言质量全部流向吸收态;再改一个格档的转移率
   看稳态怎么挪
2. 🐍 在实验幕三里把 ER 换成度序列保持的配置模型零模型(简化:
   按度序列重连现有边至收敛),最大度对照还成立吗?——零模型选择
   的敏感度练习(03 章引擎 2)
3. ✋ 用落点 1 体检你维护的一个业务指标:它有零模型参照吗?
   写出"绝对阈值"与"零模型 σ"两种报警语义的差别
4. ✋ 把落点 2 应用到一个你熟悉的割裂(两个团队/两个产品线):
   估 L 与 C,算出"砍半距离"需要几条捷径、落在哪些节点上最划算

## 📌 收束 + 🧭 认知升维

它引爆了/它固化了),先问三件事:它的零模型是什么(差值才有
意义)、结论住在哪个参数段(扫描地形)、参数的证据档位是哪级
(指定/校准/裸泳)。转码让这三问从修辞变成可跑的断言。
