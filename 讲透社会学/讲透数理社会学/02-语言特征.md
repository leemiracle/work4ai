# 02 · 语言特征:一门学科怎么用"模型"说话

> **本章回答五问之三:这个分支的语言——表达力、逻辑性质、规范化程度——长什么样?**
> 三栏 X 光:**术语**(它造什么样的词)/**模型记号**(它的数学
> 语法为什么长这样)/**话语迁移**(状态·连通度·稳态这些词如何
> 渗进公共论述)。每栏先答**为什么是这样**。
>
> **本章一句话**:数理社会学的语言是一台**翻译机**——把社会直觉
> 压进"状态空间+局部规则+聚合算子"三件记号,再把运算结果翻回
> 日常语言;它的全部力量来自"直觉一旦被记号接手就走得很远",
> 它的全部麻烦来自**翻回来的路上谁都在偷换概念**。

## 开篇:为什么这门学科读起来一半像数学,一半像新闻

新手有两个相反的困惑:一是"度、阈值、稳态,这不就是常识换了套
符号",二是"同一篇论文,前半页是定理后半页是政策建议,中间没有
过渡"。两个困惑同源:这门学科的词**两头都有户口**——一头在数学
(有定义有运算),一头在日常(有直觉有情绪)。本章三栏 X 光:先查
术语的双户口本(第一栏),再看模型记号的语法为什么必须是三件套
(第二栏),最后查翻回日常时的高发偷换点(第三栏)。

## 一、第一栏:术语——构念的户口本

**先答为什么**:数理社会学的术语不是描述词,是**压缩包**——每个
词背后压着一台模型的一个零件(一个状态空间、一条规则或一个算子)。
不懂模型,词就是空的。本家族十二个高频词:

| 构念 | 一句话定义 | 思想操作化 | 血统 | 常见误用 |
|------|-----------|-----------|------|---------|
| 度(degree) | 一个节点连了几条边 | 直接数;分布=社会连接的贫富榜 | 图论/网络科学 | 把度高等同于"人缘好"(方向与内容丢失) |
| 中心性 | 节点在图中的要害程度(度/接近/介于三种刀) | 度=连得多;接近=离谁都近;介于=谁都绕不开它 | Freeman 1977/1979 | 三种刀混用;报告"中心性"不报哪一种 |
| 结构洞 | 两个互不往来圈子之间的空档 | 横跨洞者=信息中介;生意=中介红利 | White 1970s;Burt 1992 | 把"认识两拨人"直接当"吃差价" |
| 弱关系 | 低频/低情感投入的连边 | 跨圈信息的载体;找工作的关键通道 | Granovetter 1973 | 误读为"熟人没用"(强关系另有功能) |
| 小世界 | 短平均路径×高聚类的并存 | L 与 C 两个比值一量便知 | Watts-Strogatz 1998 | 当"世界真小"的谈资,不问捷径在哪 |
| 聚类系数 | 你朋友之间互为朋友的比例 | 邻居对中互连占比 | 网络科学 | 与"凝聚力"混同(圈内互连≠组织力) |
| 阈值 | "多少人已做,我才做"的门槛 | 阈值分布的团簇与衔接决定命运 | Granovetter 1978 | 与态度强度混同(是结构位置,不是心理量) |
| 涌现 | 微观规则跑出的宏观格局,规则里没有它 | 指定规则→观察终态,差值即涌现 | 复杂系统/ABM | 当神秘主义"整体大于部分"的咒语 |
| 吸收态 | 进入即无法离开的状态 | 转移矩阵幂次后质量全聚于此 | 马尔可夫链 | 把"锁定"当阴谋(结构效应≠合谋) |
| 平稳分布 | 长期运行后各状态的常住人口占比 | π=πP 的解;与初始态无关(若唯一) | 马尔可夫链 | "稳态"误读为"静止社会"(流动仍在,结构不变) |
| 同配性 | 连边偏向同类节点的程度 | 度同配/属性同配分开报 | 网络科学 | 与"聚类"混同(选谁连≠朋友互连) |
| 零模型 | 保留某约束的随机化反事实 | 同边数随机图/度序列保持的置换 | 网络科学 | 忘了零模型本身也是强假设 |

**构念的生存法则**:一个好术语要过三关——**数学定义关**(算得出)、
**社会语义关**(在关系上意味着什么)、**对照关**(与哪个零模型比)。
"度"三关全过成为地基;"结构洞"过了前两关,第三关正在过(平台
数据的第二波检验,01 章主线 D);"涌现"常在第一关就出局(被当
修辞用)。

## 二、第二栏:模型记号——这门学科的语法是三件套

**先答为什么**:数理社会学的一切记号都在回答同一个问题——**把
"群体会怎样"写成什么,才能算?**答案收敛为三件套:**状态空间**
(谁、能处哪些态)、**局部规则**(每步谁对谁做什么)、**聚合算子**
(微观怎么加总成宏观度量)。三件齐了,模型就能跑;缺一件,剩下的
只是比喻。核心记号表:

| 记号 | 读法 | 在哪台机器上 | 语法角色 |
|------|------|------------|---------|
| A_ij | i 与 j 有无边 | 网络支全部 | 状态空间:结构一张表 |
| k_i=Σ_j A_ij | i 的度 | 网络支 | 一阶聚合:数邻居 |
| L、C | 平均路径长度/聚类系数 | 小世界 | 二阶聚合:全局 vs 局部 |
| P(K≥k)∝k^−(γ−1) | 累积度分布幂律 | 优先连接 | 尾部的形状语言 |
| x_{t+1}=F(x_t) | 参与率的自映射 | 阈值/级联 | 规则+算子合体:迭代即论证 |
| 更新规则表(若…则搬/连/转) | 元胞自动机/ABM 的法律条文 | 仿真支 | 局部规则的载体 |
| P_ij | 一步从 i 态到 j 态的概率 | 马尔可夫支 | 过程的语法:矩阵即社会 |
| π=πP | 平稳分布方程 | 马尔可夫支 | 极限:过程的目的地 |
| seed | 随机种子 | 全部实验 | 可复现性的锚:种子换结果抖,断言只锚结构 |

**记号的三条语法纪律**(这门学科不同于纯数学的地方):

1. **记号自带测量义务**:P_ij 写得出,转移率测不出,模型就只是
   排练(00 章 §四第一瓶颈)——记号是骨架,参数是肉,肉要从
   数据来(方法侧正主)。
2. **更新顺序是语义不是实现细节**:同步更新(全体一起动)与异步
   更新(一个一个动)在自旋模型类里可以给出不同终态——实验幕一
   的实现选了"随机序+轮内重查",换纪律要重新验收(03 章稳健性卡
   的字段之一)。
3. **聚合算子要声明**:同一个微观局面,"均值"与"分布形状"两种
   加总给出相反的宏观判断(阈值级联的全部教训,理论侧详见社会学
   理论家族,文字提及)——写模型先写清楚你报告哪个算子。

## 三、第三栏:话语迁移——状态、连通度、稳态如何进入社会论述

**先答为什么**:这门学科的词有一半活在公共语言里——六度人脉、
引爆点、信息茧房、路径依赖——但每迁移一次,数学内容就蒸发一点。
迁移不是坏事(学科的影响力正在于此),**危险的是带着数学口音的
偷换**。高发迁移表:

| 模型词 | 公共论述中的化身 | 蒸发掉的数学 | 偷换警报 |
|--------|----------------|-------------|---------|
| 平均路径长度(连通度) | "六度人脉""朋友的朋友" | 捷径的分布与完成率(米尔格拉姆信件完成率其实很低,通说) | "人人都只隔六个人"→短路径存在≠你能找到它 |
| 聚类系数 | "圈子""抱团" | C 是比例不是边界;同配才是"物以类聚"的正式版 | 把一切同质交往都指控为"茧房"(茧房=同配+封闭,两个条件) |
| 相变/临界质量 | "引爆点"(格拉德威尔) | 阶梯函数的边界宽度与形状依赖 | "多推一把就爆"→不问人群阈值分布形状的引爆预言都会落空 |
| 吸收态/锁定 | "内卷""阶层固化" | 吸收=概率意义不可逆,锁定=强但可逆 | 把"难"说成"不可能";把结构效应说成合谋 |
| 平稳分布(稳态) | "均衡""大局已定" | 稳态是流的平衡,不是静滞;且未必唯一 | "稳态"被当成"现状合理"的证词(自然主义谬误) |
| 枢纽/优先连接 | "大 V""头部效应""马太效应" | 幂律尾的生成机制(生长+偏好连接) | "人家本来就是大人物"→把机制产物读成个体德性(实验幕三的反面教材) |
| 级联 | "系统性风险""传染" | 级联条件依赖网络拓扑与阈值分布 | 把一切相关波动都叫传染 |
| 偏好连接 | "富者愈富" | 偏好的对象是度,不是财富本身 | 遇到幂律就套 BA,忘了适应度/老化等竞争机制(通说过载批评) |

**一句话用法**:写公共论述引用模型词时,先做**往返检验**——把
日常句翻回记号(写出它的状态空间与假设),再翻出去;翻不回来的
那句,删掉。这是 03 章模型规格卡在写作层的最小应用。

## 四、规范化:术语对译与国际接轨

模型词从英语(网络科学/物理)与德法古典(社会理论侧)来,对译表
是读国际文献的最低装备:

| 原文 | 通行中译 | 易错点 |
|-----|---------|--------|
| preferential attachment | 优先连接(偏好附着) | 是连边的机制,不是"偏好"心理 |
| structural holes | 结构洞 | 洞在圈子之间,不在个人身上(个人是桥) |
| small-world network | 小世界网络 | 指短路径×高聚类并存,不是"世界真小" |
| clustering coefficient | 聚类系数 | 勿译"集群系数";与 community(社区)分家 |
| degree assortativity | 度同配性 | 高度连高度;与属性同配分开报 |
| threshold model | 阈值模型 | 阈值是结构触发点,非态度量表分 |
| cellular automaton | 元胞自动机 | "自动机"指规则更新,非智能体 |
| agent-based model (ABM) | 基于主体的建模 | 勿译"代理模型";agent=行动主体 |
| absorbing state | 吸收态 | 吸收=不可逆返回概率为零,非"困难" |
| stationary distribution | 平稳分布 | 与"稳态"(qualitative)混用时注明数学义 |
| Markov property | 马尔可夫性(无记忆性) | 是假设不是事实;社会过程常带记忆 |
| mobility table | (社会)流动表 | 行=出身,列=到达;对角线=继承 |
| generative sufficiency | 生成充分性 | 是解释的门槛条件,非充分条件 |
| null model | 零模型 | 不是"没模型",是约束化反事实 |
| vacancy chain | 空缺链 | 机会沿结构空洞流动,非"职位空缺列表" |

## 五、一门学科,三种口音并存(语言的社会学)

同一现象——"某行业头部三家公司吃掉八成市场"——三种口音给出
三种处方:

| 口音 | 诊断 | 处方倾向 |
|------|------|---------|
| 网络支 | 市场即图:头部=枢纽,连线按度偏好滚大 | 查连边机制(渠道锁定/平台排名),动结构不动人 |
| 仿真支 | 头部是规则跑出来的:偏好连接+网络效应的涌现 | 改规则参数(改推荐/准入),重跑看终态 |
| 马尔可夫支 | 市场份额是转移矩阵的平稳分布:流动在,结构不变 | 算转移率与吸收态,找"可逆"与"锁定"的分界 |

**三种口音都对一部分**;但同一份论证里混用口音而不声明,等于把
三种数学的假设账单开给同一段论述——先定主导口音,再借译(00 章
§五的账单纪律在语言层的对应物)。

## ✨ 美之时刻(彩蛋第 5 枚:记号的往返之美)

✨ **美之时刻 5:往返检验——把口号押解回记号**(极简)
"阶层固化"押回马尔可夫支:写出转移矩阵,查吸收态有几个、从哪些
状态可达、返回概率是多少——口号立刻分成"结构锁定"(吸收态真实
存在)与"流动变慢"(转移率下降)两种完全不同的主张,政策含义
相反。为什么美:**记号是口号的测谎仪**——凡翻不回记号的大词,
都在贩卖它没有的精确性。亲历:把"信息茧房"押回网络支(同配+
封闭两个条件),看你常用的那句控告站不站得住(✍️练习 1)。

## ✍️ 练习

1. ✋ 把"信息茧房"做往返检验:它的状态空间是什么?需要哪几个
   条件(同配?封闭?级联?)才在模型里成立?——美之时刻 5 的亲历版
2. ✋ 用 §三 迁移表体检一篇财经评论:数它用了几个模型词,每个的
   数学内容蒸发了多少
3. ✋ 给"破圈"写出记号:它动的是哪件套(状态空间/规则/算子)?
   用幕二的语言说清"一条捷径值多少"
4. ✋ 把三种口音各写一句"城市隔如何缓解",标注每句隐含的模型
   假设与账单

## 📌 收束 + 🧭 认知升维

本章给你的**新眼睛:往返之眼**——听到任何借自模型的大词(引爆/
固化/传染/头部),先做往返检验:它的记号原形是什么、假设账单
是什么、翻到公共语境蒸发了什么;写自己的论述时,先声明主导口音
(网络/仿真/马尔可夫),再借译。
