# 讲透发展与发展干预 · 发展被做成什么——项目、参与与评估的实践学

> **定位句**:这支负责**实践层**——发展知识落到地面的全套工序:**发展项目与评估**(理论变迁/传导链/RCT 革命与其反思)、**参与式发展**(钱伯斯的「把最后放在首位」)、**社区发展**(社区作为干预单元的政治)。口号:干预的理论,首先是关于社会怎么变迁的理论。GB/T 13745 84064 发展社会学 · **自定支(实践层)** · 家族:[讲透发展社会学](../README.md)

## 诞生

- **谁/何时**:社区发展运动的机构化(联合国系统 1950s 推广,通说);钱伯斯《农村发展:把最后放在首位》(1983)与参与式农村评估(PRA)立参与式传统;弗格森《反政治机器》(1990)在莱索特揭示项目的权力效应;森《以自由看待发展》(1999)重定干预的目的;J-PAL(2003)把随机对照实验做进发展干预,班纳吉/迪弗洛/克雷默 2019 年获诺贝尔经济学奖(RCT 的方法本体归[经济学宇宙](../../../讲透经济学/README.md),互链)。
- **因什么问题**:①项目为什么常常「成功施工、失败变迁」(传导之问)②「参与」何时是权力何时是签到(参与之问)③RCT 的效应结论能走多远(外推与尺度之问)。

## 核心问题

**已解决(通说)**:结果链与传导链的标准化(投入→活动→产出→结果→影响);RCT 的内部效度建制;参与式方法工具箱(参与式评估/社区主导);「反政治」效应的可研究对象化——家族实验幕三为尺度问题造了教学机:等额预算下实物进口臂价格 6→4.4、生产者剩余蒸发 64%、总福利 −6.4(送粮最多的手臂唯一为负),现金/本购臂 +42.5/+47.5 且本购推价代价如实标注。

**未解决/深水区**:外部效度与异质性(平均效应掩盖「对谁有效」);赋权的可测量化(不被指标化为出席率);试点→推广的尺度悬崖(一般均衡回归);伦理与「管道工」心态的边界。

## ✨ 这支最美的一个事实

**反政治机器:发展项目的主要产品可以是权力**。弗格森在莱索托发现:项目报告里的莱索托是一张白纸——没有历史、没有政治、没有殖民边界,只有待改善的地貌与待培训的农民;项目「失败」了,国家官僚的触角却借项目延伸成功了。为什么美:它把「发展为什么失败」从执行问题升级为**话语问题**——失败可能是另一种成功记账;此后读任何项目书,先找它没写的部分。幕三给这个直觉配了算术版:项目书同样不写均衡——价格把干预的成本转给了没上桌的人。
