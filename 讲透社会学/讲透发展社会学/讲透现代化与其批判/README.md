# 讲透现代化与其批判 · 发展被想象成什么——阶梯、网络与批判的谱系学

> **定位句**:这支负责**理论层**——追赶理论的全部家谱:**现代化理论**(罗斯托的阶段论/帕森斯的模式变量)、**依附理论**(普雷维什的中心-边缘/弗兰克的欠发达的发展)、**世界体系论**(沃勒斯坦的五百年结构与半边缘)。口号:阶梯是谁画的?GB/T 13745 84064 发展社会学 · **自定支(理论层)** · 家族:[讲透发展社会学](../README.md)

## 诞生

- **谁/何时**:罗斯托《经济增长的阶段》(1960,副题「非共产党宣言」)画五级台阶;帕森斯模式变量(1951)供「传统/现代」的编码底盘;普雷维什《拉美的经济发展及其主要问题》(1949,贸易条件恶化)立中心-边缘;弗兰克《资本主义与拉丁美洲的欠发达》(1967,都会-卫星链);桑托斯〈依附的结构〉(1970);沃勒斯坦《现代世界体系》(1974,中心/半边缘/边缘);后发展批判(弗格森《反政治机器》1990/埃斯科瓦尔《遭遇发展》1995)把理论史变成话语史。
- **因什么问题**:①为什么有的社会「先走了一步」(阶段之问)②中心的发达与边缘的欠发达是不是同一个过程的两面(结构之问)③「发展」这个词本身是谁造的、替谁造的(话语之问)。

## 核心问题

**已解决(通说)**:单线论的理论解剖(终点预设/传统残余范畴/欧美外推);中心-边缘的贸易结构表达(部门与流量);世界体系的分析单位升级(国家→体系)与位置流动性(半边缘);后发展对话语的谱系化——家族实验幕二为「位置不是努力的函数,是接入史的函数」造了最小机器(增长×度 ρ=0.851/0.889,跨宇宙换序 ρ=0.013)。

**未解决/深水区**:依附论的可检验化(结构常被说得过死,弹性批评);单线论的当代回潮(增长回归与阶段话语的政策复活)该怎么接;后发展批判的虚无主义边界(拆掉阶梯之后造什么)。

## ✨ 这支最美的一个事实

**「欠发达的发展」:一个短语改写因果箭头**。教科书把欠发达当初始状态:「他们还没走完我们走过的路」;弗兰克 1967 年把状语改成动词——**欠发达是被生产出来的,且与发达同步生产**:中心的每一分积累同时是卫星带的一次剩余流失。为什么美:它不否认差距,只翻转箭头,从「他们缺什么」变成「他们被安排在哪个位置」;幕二是它的数值化身:同一批国家换接入顺序,枢纽与边缘大洗牌——位置分化无需任何「劣根性」参数。
