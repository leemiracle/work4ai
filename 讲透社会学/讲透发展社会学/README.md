## 一、家族定位(它在社会学宇宙里的位置)

1950 年代,「欠发达」成为一个全球治理对象:罗斯托给所有国家画了同一
架五级台阶,帕森斯的结构功能主义给「传统—现代」配了整套对照变量。
发展社会学就诞生在这台大机器的**裂缝**里:普雷维什与桑托斯问「中心
的发达与边缘的欠发达是不是同一个过程的两面」,沃勒斯坦把答案铺成
五百年世界体系,后发展学派连「发展」这个词本身也送上了手术台
(富格逊的反政治机器/萨克斯的发展词典),而评估革命(RCT 化)又把
战场拉回地面:干预到底有没有用。它在 840 宇宙里是**追赶过程的社会
结构司令部**:历史社会学供路径依赖的直觉,比较社会学供跨国设计的
工具,经济学宇宙供对表的另一半图纸,本家族管**把「发展」这个最坚固
的「自然过程」重新问题化**。五问(体系/前沿/语言/构造/转码)的
回答见家族层五章。

- **零门槛**:不要求经济学或社会学前置;只想看「富国穷国排行榜」的
  去看新闻,本家族管的是**追赶如何被结构、干预与话语共同制造**
- 路线 A(问题派):为什么「穷国增长更快」的回归证据换不来世界差距

## 二、家族树(GB/T 无三级明细 → 自定 3 支)

```
讲透发展社会学/              GB/T 84064(无三级明细 → 自定 3 支)
├── 讲透现代化与其批判/       自定支(理论层)——现代化理论/依附理论/世界体系论
├── 讲透发展与发展干预/       自定支(实践层)——发展项目与评估/参与式发展/社区发展
└── 讲透全球南方与不平等/     自定支(结构层)——全球不平等结构/南北差距/另类发展
```

> 三支的共同血统:同一句纲领「**发展是结构位置与政治工程的产物**」的
> 三层落地——理论层管**发展被想象成什么**(单线阶梯还是中心-边缘,
> 话语与理论的批判史),实践层管**发展被做成什么**(项目如何设计、
> 谁参与、怎么评估),结构层管**发展落在谁身上**(全球不平等的分布
> 与另类出路)。三层缺一即塌:只有理论没有实践,批判悬空;只有实践
> 没有结构,评估不知道自己嵌在什么里;只有结构没有理论,地图没有
> 图例。
