# 04 · 发展社会学转代码:把追赶解剖搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:发展社会学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**收敛诊断**(β/σ 双账本)、
> **结构位置**(接入史网络生长)、**干预均衡**(局部市场价格炸弹)
> ——把「穷国在追赶」「先来者成枢纽」「送粮砸市场」变成可跑、可断言、
> 可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",发展社会学转代码要解决两步翻译:
先把社会学语言("位置决定机会")翻成模型(网络上的优先连接与
机会流动),再把模型翻成代码。损耗全部发生在第一步——所以本章先
划清哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给
三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 社会学概念 | 代码化身 | 备注 |
|---------|---------|------|
| 收敛之争(β vs σ) | 增长面板+回归/方差分解双账本 | 实验幕一;两臂对照可全量 assert |
| 结构位置(中心-边缘) | 优先连接网络生长+机会沿边流动 | 实验幕二;对照宇宙=换接入顺序重跑 |
| 干预的市场后果 | 线性供需均衡+位移注入扫描 | 实验幕三;纯算术,可精确断言 |
| 分布指标族 | 排序+分位份额/基尼/σ 序列 | O(n log n)/期;口径轮换的敏感度测试 |
| 三张结构卡 | 定长字段记录+完整性断言 | 03 章 schema 的数据化 |
| 干预日志的传导链审计 | 投入→产出→结果的字段 diff | 拿得到链路日志才成立(红色区的门) |

**转不动(红色区)**:

1. **「什么算发展」的裁定**:能力、Buen Vivir、增长——规范哲学的
   分歧没有状态方程;代码能算代理变量的任何合成,不能替人投票
   (02 章 §二:HDI 换公式的伦理,机器只执行不发明)。
2. **参与式赋权的判定**:谁被赋了权是权力关系的重建;把出席率当
   赋权率,是 02 章 §三「参与→出席」磨损的自动化版。
3. **发展叙事的取舍**:主导叙事与反对叙事的并录须双人校;自动
   文本分类会筛掉弱信号叙事——反政治机器的算法版。
4. **「恰是如此」**:为什么恰是这个社区长出了这套合作社章程;
   硬造「内生性指数」只会得到自己假设回去的结论。
5. **应然之问**:援助该给谁、全球分配怎样才算公正——代码算传导
   与后果,算不了公正。

**边界的一句话**:绿色区=分布类+网络类+均衡类+卡片类,覆盖
"追赶解剖的机械学";红色区提醒:**转码是发展社会学的使用说明书,
不是替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:收敛诊断走廊(增长回归的双账本)

```
国家面板 ──参数化──▶ 稳态设定(承继系数+漂移)+回归机制 ──模拟──▶ β 序列与 σ 序列
      │                                                              │
      └──对照──▶ 纯 Gibrat 世界(增长率与水平无关)──▶ 双账本背离断言 ◀──┘
```

- **理论→模型**:增长=g+λ(θ−y)+噪声;θ=承继×初始+漂移。回归账本
  (growth on level)显示追赶,方差账本(截面 σ)显示分布——两本账
  必须同时记。
- **算法层**:每期 O(n);n=100×60 期秒级;断言用**双账本背离**
  (β 显著为负 AND σ 扩大)与 Gibrat 臂的**单调扩张**(checkpoints
  逐档比较)。
- **本家族实现**:[`experiments/divergence_structure_aid.py`](experiments/divergence_structure_aid.py)
  幕一——Gibrat 臂 σ 0.494→0.875 逐档单调、β 不显著(t=−0.25);
  收敛臂 β=−0.526(t=−3.94)与 σ 0.495→0.695 同时成立。
- **真实系统**:经济与运营看板的**双账本纪律**——任何「平均值在
  追赶」的报表(客户均值提升/人均收入增长)必须配一页分布账本
  (组间差距是缩是扩);增长分析师读跨国报告时的第一道防骗。
- **性能工程要点**:σ 的单调断言要用**粗粒度 checkpoint**(10 期
  一档)——细粒度的样本方差噪声会让逐期断言随机翻车;漂移要
  ≫噪声(稳态漂移 0.7 vs 每期噪声 0.02),断言才硬,否则降级为
  容差断言并如实标注。

### 走廊 2:结构位置走廊(接入史的最小机器)

```
国家+禀赋 ──参数化──▶ 优先连接(权重∝(度+1)(1+δ×禀赋)) ──生长──▶ 终态网络+度分布
      │                                                              │
      └──对照──▶ 同禀赋换接入顺序的宇宙重跑 ──▶ 位置洗牌断言 ◀────────┘
```

- **理论→模型**:位置=接入史×优先连接;增长机会沿边流动(每轮抽
  边,两端受益)——中心度直接换算累积增长。
- **算法层**:生长 O(n·m·n)(加权抽样);机会轮 O(rounds×picks);
  n=100 秒级;断言用**三重相关**(增长×度显著正、接入序×度显著负、
  跨宇宙弱)与**集中度**(前 10 度份额)。
- **本家族实现**:同实验幕二——ρ(增长×度)=0.851/0.889;ρ(接入序
  ×度)=−0.674/−0.626;跨宇宙 ρ=0.013、最大摆动 75 位、枢纽坠落
  5/10;前 10 国 36% 总度。
- **真实系统**:平台生态与联盟网络的**先发优势审计**——生态位/
  应用市场/开发者社区的头部固化,多少来自优先连接的接入史、多少
  来自真实质量差异?跑双宇宙:保留质量分、重排入场序,头部重合度
  就是「历史占比」的估计。渠道与供应链的风控同理:枢纽依赖度
  (前 10 节点度份额)是断链压力测试的第一参数。
- **性能工程要点**:对照宇宙必须**共享禀赋向量**(同一 fitness 数组
  传入两个宇宙),否则「位置洗牌」混入「禀赋差异」——与幕一匿名
  对照共享策略分布同一纪律;Spearman 用平均秩处理并列,断言只锚
  聚合相关不锚单节点轨迹。

### 走廊 3:干预均衡走廊(善意注入的价格账)

```
局部市场 ──参数化──▶ 线性需求+本地供给 ──注入──▶ 三臂位移(现金/实物/本购)
      │                                                        │
      └──扫描──▶ 弹性与替代率参数网格 ──▶ 福利排序稳健性断言 ◀──────┘
```

- **理论→模型**:干预=需求/供给的位移;均衡价格把成本转给曲线
  另一侧;福利账=ΔCS+ΔPS+受益人所得−预算。
- **算法层**:闭式解,零迭代;断言用**排序稳健性**(B 的福利垫底、
  价格跌幅最大在宽参数网格内不翻转)。
- **本家族实现**:同实验幕三——等额预算 60:B 价格 6→4.4、生产者
  剩余蒸发 64%、总福利 −6.4;A/C +42.5/+47.5;C 推价代价标注。
- **真实系统**:补贴与补贴券投放的**市场影响模拟**——发券(需求
  位移)、发实物(供给位移)、定向采购(本地需求位移)三臂在同一
  张供需图上先跑一遍再上线;帮扶采购「以购代捐」的价格外溢、
  平台大战「烧钱补贴」对供给侧的伤害,都是这台机器的产业版。
- **性能工程要点**:线性模型的价值在**排序稳健性扫描**(弹性和
  替代率网格上结论不翻转)而不在点估计精度——单点数字是教学,
  网格上的不变序才是工程;替代率(实物发放挤掉多少自购)是最
  敏感的参数,必须做敏感性标注。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:指标看板的「双账本」纪律——均值页必须配分布页

- 任何运营/经营看板都在跑小型收敛叙事:「均值在涨」被读成「大家
  在变好」。走廊 1 的纪律直接搬来:均值旁边放 σ(组间差距)与
  分位份额(top10 占比)两列;发现「均值追赶+分布发散」的组合,
  报告里必须点名——这正是 Galton 佯谬的看板版。

### 落点 2:生态头部的「接入史」归因——别把历史当质量

- 平台推荐、开发者生态、合作伙伴体系里,头部固化常被解释为质量。
  走廊 2 给出审计流程:保留质量分、重排入场顺序跑对照宇宙,头部
  重合率低=位置由历史主导。预算该补给「质量够但入场晚」的节点,
  而不是继续奖励纯先发优势。

### 落点 3:补贴投放的「价格账」预演——先跑三臂再上真钱

- 发券、发实物、定向采购三种补贴在同一张供需图上的福利排序可以先
  算后投(走廊 3)。特别检查:补贴品是否压垮了本地供给方(实物臂
  的 64% 蒸发)、采购是否推价伤到未覆盖用户(本购臂的 +0.5)。
  把「善意预算的均衡外溢」写进投放评审的必答题。

### 落点 4:试点推广的「尺度」关卡——A/B 成功≠全国成功

- 实验室里赢的 feature 全国铺开就翻车,机制与幕三同构:试点规模
  小到不动价格,推广后一般均衡效应(竞价/挤占/饱和)登场。上量前
  跑一遍尺度问诊:这个干预动了哪条曲线?谁在均衡里买单?

## ✍️ 练习

1. 🐍 给走廊 1 加第三臂「俱乐部收敛」:稳态只取两个值(μ±0.5),
   预测并验证:σ 终态、β 信号、与连续稳态臂的差别各是什么?
2. 🐍 在走廊 2 里把每轮抽边数 G_PICKS 从 30 调到 300(机会更密),
   增长×度的相关会怎么变?接入序×度呢?写出「机会密度改变什么、
   不改变什么」
3. ✋ 把落点 3 写成一页 runbook:补贴三臂的供需参数怎么定、福利账
   怎么算、上线评审卡哪三道;注明哪一步永远留给人(受益人界定的
   政治裁定)
4. ✋ 用落点 4 审计你产品最近一次「试点成功→全量」的推广:它动了
   哪条曲线?谁付了幕三式的隐性价格?

位置稳固/干预有效),先问它的**对照世界**造了没有:没有 Gibrat
