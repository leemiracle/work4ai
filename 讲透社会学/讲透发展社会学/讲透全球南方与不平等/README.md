# 讲透全球南方与不平等 · 发展落在谁身上——分布的账本与另类的出路

> **定位句**:这支负责**结构层**——追赶的最终账本:**全球不平等结构**(国家间+国家内的双账本)、**南北差距**(从第三世界到全球南方的换词史)、**另类发展**(内生发展/Buen Vivir/对发展的另类)。口号:不平等是结构位置的总账。GB/T 13745 84064 发展社会学 · **自定支(结构层)** · 家族:[讲透发展社会学](../README.md)

## 诞生

- **谁/何时**:阿明《世界规模上的积累》(1970)与埃曼纽尔《不平等交换》(1972)立全球分配的结构账;勃兰特委员会《南北问题》报告(1980)把「南方」钉进词表;《人类发展报告》(1990 起,ul Haq 与森)与《世界发展报告》(1978 起)成为分布的年度宪法;《世界不平等报告》(2018/2022,方向锚,检索校准 2026-09-07,见家族 01 章主线 A)把账本做细到个人;COP27 设立损失与损害基金(2022,通说)把结构账推进大气层;Buen Vivir 入宪(厄瓜多尔 2008,通说)开启「对发展的另类」。
- **因什么问题**:①全球差距在缩还是在扩——口径怎么定(账本之问)②「南方」是地理还是政治(命名之问)③发展之外有没有出路(另类之问)。

## 核心问题

**已解决(通说)**:全球不平等的双账本分解(国家间+国家内,此消彼长是头号新闻,具体数值随报告版本不引);贫困线与 PPP 口径的政治学(家族 02 章 §二三重陷阱);换词史(第三世界 1952→发展中国家→南方 1980→全球南方)的谱系;另类发展的宪法化样本——家族实验幕一为「账本之争」造了最小机:β=−0.526 显著为负(回归上「在收敛」)与 σ 扩大 40% 同时成立——口径即结论的双账本纪律。

**未解决/深水区**:气候作为全球公共品对国家中心框架的冲击(损失与损害的治理);全球南方的内部不平等(南方的南);Buen Vivir 等另类是范式候选还是宪法修辞;数据名册化(税务微观)与隐私的边界。

## ✨ 这支最美的一个事实

**换词七十年:每次换名都是主体位置的一次谈判**。「第三世界」(索维 1952,自命名)→「发展中国家」(过程分类的礼貌化)→「南方」(勃兰特线的地理隐喻)→「全球南方」(多极世界的政治-历史主体)——被描述者争取命名权,描述者让渡一个又造一个;「全球南方」不指南半球(澳大利亚地理在南而不在话语的南):**它是位置的命名,不是坐标的命名**。为什么美:范畴的兴替史把「分类中立性」的神话拆穿——一个从来不换名的范畴,多半从来没人谈判过。
