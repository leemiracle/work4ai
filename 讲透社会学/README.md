## 三、特征速查

- 孔德到布迪厄的思想编年 → 社会学史
- 结构功能/冲突/互动/交换诸论 → 社会学理论
- 抽样/访谈/民族志/问卷 → 社会学方法
- 田野实验/实验室社会实验 → 实验社会学
- 社会网络模型/正式模型 → 数理社会学
- 家庭/城市/农村/越轨等应用域 → 应用社会学
- 跨社会结构比较 → 比较社会学
- 空间与社会/社区 → 社会地理学
- 文化工业/知识社会学 → 文化社会学
- 历史事件的社会学解释 → 历史社会学
- 市场嵌入/经济行动的社会性 → 经济社会学
- 军队与战争的社会面 → 军事社会学
- 组织形象/公众沟通 → 公共关系学
- 亲属制度/礼物/田野民族志 → 社会人类学
- 科层制/组织与制度 → 组织社会学
- 现代化/发展中国家 → 发展社会学
- 社会保障/福利国家 → 福利社会学
- 生育/迁移/老龄化 → 人口学
- 劳动关系/就业/社保 → 劳动科学
