# 03 · 可构造与结构:哪些市场对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:经济社会学的对象沿一条**可构造谱系**排开——
> 信任传播模拟端**严格可构造**(嵌入治理与信息冗余可以跑出数字、
> 过 assert,r>g 的分化动力学可以逐期断言单调性),关系工作解释端
> **几乎不可构造**(货币的标记与「恰是如此」只能在深读与田野里
> 操练);全谱系共享两条结构引擎:**网络嵌入引擎**(信息与制裁沿
> 边传播)与**复利结构引擎**(收益率结构长出分布);而市场本身
> 可以被压进三张**结构卡**(市场界定卡/治理结构卡/平台机制卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
信任传播模拟 ── 信息冗余审计 ── r>g 财富动力学 ── 嵌入度指标 ── 市场界定卡 ── 治理结构卡 ── 平台机制卡 ── 货币标记 ── 关系工作 ── 控制观的诞生
  │                                                                                                │
严格可构造(可断言)                                                                 几乎不可构造(只有思想操作化)
  └── 枚举得出、算得动、能过 assert                                                                  └── 只能在深读与田野里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:交易
博弈的语义是"合作/背叛/拉黑",输入输出明确;而"这笔钱为什么进了
奶罐"的语义是进入行动者的意义世界——**解释者本人就是测量仪器**,
仪器无法装配仪器(与 84014 社会学理论家族的「理解」同构,彼处
右端;其构念底盘见[../讲透社会学理论/README.md](../讲透社会学理论/README.md),
互链)。本章先盘家底,再看两条结构引擎,最后把整套市场解剖工序
压成三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **嵌入交易治理模拟** | 交易者(互惠/机会主义)+网络(封闭/桥接)+声誉沿边传播 | 低(家族实验幕一全程可跑) | 参数化已砍掉意义与历史;合作率≠信任本身 |
| **信息冗余审计** | 强弱边网络+单次播报;统计首达占比/冗余率 | 低(幕二) | 「强弱」用拓扑代用,强度本身未测 |
| **r>g 财富动力学** | 双账户复利模型;逐期份额与基尼 | 低(幕三;单调性可断言) | 两账户是极简;行为的再分配与储蓄差异全冻结 |
| **嵌入度指标** | 重复交易率/关系专用投资/网络约束的规则化计算 | 中 | 指标是快照;「嵌入」与「锁定」分不开(幕一的 0.0% 探索率) |
| **市场界定卡** | 参与者角色/状态秩序/控制观/国家在场的固定字段表 | 中(§四 schema) | 边界是政治裁定,卡片只能记录裁定结果 |
| **治理结构卡** | 交易属性→治理形态→嵌入修正的字段表 | 中 | 形态间的杂糅(平台既像市场又像科层)须人工判 |
| **平台机制卡** | 双边/匹配参数/声誉系统/抽成/仲裁的字段表 | 中 | 参数日志拿得到才填得实;拿不到就退化成宣传页摘抄 |
| **货币标记分析** | 钱的流向与分格的规则化编码 | 中 | 格子的命名是解释性判断,须双人校 |
| **关系工作/控制观解释** | 意义与秩序的案例内重建 | **不可构造** | 「恰是如此」不可压缩成参数;压缩即失真 |

**反直觉发现(本章铁律)**:**本家族的名气与其对象的可构造性
常常倒挂**。最出名的论断(双向运动、控制观、货币标记)全在谱系
右端,最能跑的对象(治理模拟、冗余审计、分化动力学)名气最小。
**右端管洞察,左端管检验**;用右端对象硬造左端指标(给「嵌入文化」
打分、给「关系工作」编码后跑回归)是本学科量化研究的头号失真
来源——两头都不是。正确的接法是**左端造右端概念的最小机器**
(幕一之于嵌入性纲领,幕三之于 r>g),机器不替代概念,只给概念
一个可审计的极端案例。

## 二、结构引擎 1:网络嵌入引擎(信息与制裁沿边走)

**直觉图像**:市场的多数「自动」——违约会遭报、承诺会被记得、
消息会传开——全靠一张看不见的网;把网拿走(匿名化),机器立即
降级。这是嵌入性纲领的机械学。

- **治理化身(幕一)**:互惠者+机会主义者+欺诈信息沿边传播。
  三条刚性:
  1. **匿名市场无执行**:合作率被钉在互惠者占比(85.0%),欺诈
     2316 次无人管——「下次报复你」不可执行。
  2. **嵌入即执法**:同样的骗子在封闭/桥接网络里末段交易参与率
     塌到 0.0%/0.2%——拉黑沿边扩散,背叛的价格被网络抬到无处可骗。
  3. **信任的两种价钱**:封闭与桥接合作率相当(100.0% vs 99.9%),
     新配对率 0.0% vs 7.7%——闭包与洞这对「社会资本」的内部矛盾,
     在这里是一组可跑的参数置换。
- **信息化身(幕二)**:强弱边分工。刚性:弱边以 14.2% 的边数拿下
  22.8% 的首达(1.60 倍超额);强边冗余 78.8% vs 弱边 61.1%;
  拆除弱边覆盖率 99%→18%——**信息结构洞是拓扑事实,不是态度事实**。
- **刚性从哪来**:图上的传播与配对是组合运算,骨架是刚的;软的
  地方在**参数化的刀口**——「信任」被砍成合作率,「人情」被砍成
  重复偏好,砍掉的正是右端领地。03 章的纪律:机器的输出永远
  声明为「嵌入性纲领的最小机器」,不是「信任的测量」。
- **方法上游**:这套机器的形式工具(度/聚类/路径/小世界)归
  [数理社会学家族](../讲透数理社会学/README.md)(互链);本家族
  的增量是**给经济过程装上它**(交易的制裁结构、机会的信息结构)。

## 三、结构引擎 2:复利结构引擎(收益率长出分布)

**直觉图像**:把「不平等」从行为词(贪婪/努力)改写成结构词
(两列不同速度的列车)——分布是收益率结构的**沉淀**。

- **数学化身(幕三)**:资本账户(对数正态,中位数 100)按 r=5%
  复利;劳动账户(人人等额 100)按 g=2% 增长。三条刚性:
  1. **单调性**:r>g 时前 10% 份额与基尼**逐期单调上升**
     (0.223→0.305;0.248→0.413)——不是趋势拟合,是逐步断言。
  2. **对照的平坦**:r=g=2% 时两指标纹丝不动(Δ≈0.0001)——分化的
     开关只有 r−g,与任何行为参数无关。
  3. **无行为性**:没有一个「贪婪」参数:不偷不抢不囤积,分化照样
     长出来——把道德叙事请出结构问题的第一课。
- **理论地位**:这是皮凯蒂 r>g 的最小计算模型(其经济学本体归
  [经济学宇宙](../../讲透经济学/README.md),互链);社会学接手的是
  另一半:**为什么资本期初集中、r 为什么能持续高于 g**——遗产制度、
  金融市场准入、elite 网络,答案在制度而不在偏好。分层的制造机制
  归本家族,分配的后果归 84047 福利社会学(文字提及)。
- **刚性从哪来**:复利是确定性动力学的骨架;软的地方在**账户的
  边界**(什么算资本、劳动积累为什么人人等额)——那是模型的宪法
  修正案,不在机器里,在假设里。

## 四、结构卡 schema:把一个市场压进三张卡

**先答为什么**:市场解剖的难点在"整体性"——参与者、规则、意义
散落在论文各节。结构卡是**有限字段的压缩格式**:字段固定、填空
即可复用、可比可查可补(卡片本身严格可构造,这是「可构造」在
设计层的对应物)。

### 卡 1:市场界定卡(这个市场是谁的秩序)

```
【市场界定卡】
市场名称与边界(产品/地理/时段):________
参与者角色(谁在互相盯:厂商/买家/中介/国家):________
状态秩序(谁在上,凭什么排:声誉/规模/资质):________
控制观(此地「什么叫竞争、什么叫成功」的共享定义):________
国家在场(牌照/定价规则/退出机制哪只手在动):________
关键配套市场(劳动力/资本/数据从哪来):________
一句话鉴定(这个市场靠什么秩序不散架):________
```

样例(已填,教学版):市场=某市网约车出行;角色=平台/司机/乘客/
监管;状态=评分与接单等级;控制观=「效率+安全」的双标话语;国家=
牌照与抽成上限之争;配套=司机劳动力市场(虚构商品的当代版);
鉴定=靠算法治理+平台制定的声誉秩序撑住,散架风险在监管重定义。

### 卡 2:治理结构卡(交易凭什么不被坑)

```
【治理结构卡】
交易的关键属性(资产专用性/频率/不确定性各打高中低):________
治理形态(市场/混合/科层/关系网络/平台,可多选并注明主次):________
嵌入修正(关系史与声誉机制在哪一段起作用):________
执行机制(违约由谁发现、由谁惩罚、传播多快):________
失效模式(什么条件下这套治理失灵):________
```

样例(已填,幕一的教学版):属性=高专用(关系专用投资)+高频;
形态=关系网络(封闭街区)为主;嵌入修正=重复交易偏好+黑名单沿边
传播;执行=受害者及其邻居拉黑(传播 1 跳);失效=网络开放后探索
踩雷(桥接的 98 次欺诈)或过闭后锁死(0.0% 新配对)。

### 卡 3:平台机制卡(算法在替谁定规则)

```
【平台机制卡】
双边(多边)用户与交叉网络效应:________
匹配机制的关键参数(排名逻辑/权重/个性化程度):________
声誉系统(评分怎么记、能不能申诉、对谁可见):________
定价与抽成(谁定、怎么变、明不透明):________
治理争议点(封禁/降权/数据归属的最大争端):________
监管接口(哪些参数已被监管,哪些还在黑箱):________
```

样例(已填,教学版):双边=司机×乘客+广告主第三边;匹配=接单
距离×评分加权;声誉=双向评分,申诉工单制;抽成=动态,不对外
透明;争议=封禁无仲裁;监管接口=抽成上限已议,排名权重仍黑箱。
(平台涌现与匹配动力学本体归[复杂系统宇宙](../../讲透复杂系统/README.md),
互链;本卡管其社会结构含义。)

**判定流程**(把一个研究主张钉到谱系上):

```
该主张的核心是网络与分布的机制吗(信任传播/信息冗余/复利分化)?
  ├─ 是 ────────────────▶ 左端:建模+模拟+断言(04 章走廊 1/2/3)
  ├─ 半,是市场与治理的设计 ─▶ 中段:卡片化+双人校,禁止硬算「秩序分」
  └─ 否,是意义与「恰是如此」─▶ 右端:深读+田野,禁止压成参数
```

## 五、谱系×引擎×三支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| [嵌入与市场社会性](讲透嵌入与市场社会性/README.md) | 左-中段(传播模拟/嵌入度指标可算;信任的意义靠深读) | 网络嵌入引擎 | 中-高(幕一二全程可跑) |
| [组织与市场治理](讲透组织与市场治理/README.md) | 中段(三张结构卡;控制观的诞生靠案例) | 嵌入引擎+治理比较 | 中(卡片+清单,双人校) |
| [货币金融社会学](讲透货币金融社会学/README.md) | 左-右段贯通(r>g 机器可断言;标记与关系工作靠深读) | 复利结构引擎+意义分析 | 两极分布(幕三可跑,奶罐不可) |
| 横贯:平台机制分析 | 中段(机制卡;参数日志可得时可半量化) | 双引擎并用 | 中(拿得到日志就高,拿不到就低) |

**读表法**:一个对象的"可构造纯度"决定它的转码方式(04 章)——
传播与复利走计算,结构卡走字段校验,意义与「恰是」永远走深读。
**没有哪支全家可构造,也没有哪支全家不可构造**;判据永远是判定
流程那一问:**核心是机制、清单,还是意义?**

## ✨ 美之时刻(彩蛋第 6 枚:最小机器)

✨ **美之时刻 6:给大概念造最小机器——纲领的可审计重生**(极简)
「嵌入性」「弱关系」「r>g」都是四十岁以上的大概念,大概念的通病是
**谁都能引用,谁都验不了**。本家族的车间传统是给它们各造一台
**最小机器**:60 个交易者三张网(嵌入性纲领)、16 个圈子 40 条弱边
(弱关系)、两本账户两条利率(r>g)。机器不证明概念为真——它把
概念压到一组**可跑、可断言、可推翻的极端条件**,让「若概念成立,
则在此条件下必有此现象」变成 exit 0 的检查。为什么美:**它给
思想史的宏大叙事装上了回归测试**;纲领过生日最好的礼物,不是
纪念文集,是一台谁都能跑的机器。亲历:挑一个你领域的五十年大概念,
写出它的最小机器说明书( Actors/规则/网络/断言各一段,✍️练习 1)。
