# 讲透嵌入与市场社会性 · 交易发生在什么关系里——信任的网络机器

> **定位句**:这支负责**关系层**——嵌入性纲领的微观机器:**经济行动的社会性**(社会化不足/过度社会化两个靶子)、**嵌入**如何执行治理(重复交易/声誉传播)、**社会资本与信任**(闭包买安全、桥接买机会的一对矛盾)。口号:信任不是美德,是网络里可执行的制裁结构。GB/T 13745 84044 经济社会学 · **自定支(关系层)** · 家族:[讲透经济社会学](../README.md)

## 诞生

- **谁/何时**:波兰尼 1944 造出「嵌入」(宏观历史版);格兰诺维特 1973《弱关系的力量》(信息从圈外来)、1985《经济行动与社会结构》(一箭双雕:射穿「社会化不足」的原子算计者与「过度社会化」的自动服从者,嵌入性成为可研究的中层纲领);伯特 1992《结构洞》(非冗余联系的位置优势);科尔曼 1988 闭包版社会资本;乌齐 1997 嵌入与组织绩效(方向锚,检索校准 2026-09-07,见家族 01 章主线 C)。
- **因什么问题**:①匿名市场里「下次报复你」为何是空话(执行之问)②为什么关键消息常来自泛泛之交(信息之问)③社会资本既讲闭包又讲洞,到底要哪个(两种价钱之问)。

## 核心问题

**已解决(通说)**:嵌入的治理机制——欺诈信息沿边传播=拉黑扩散(家族实验幕一:匿名合作率 85.0% vs 嵌入 100.0%/99.9%,欺诈者末段参与率 27.5%→0.0%);弱关系承载非冗余信息(幕二:弱边 14.2% 的边数拿下 22.8% 的首达,拆弱边覆盖率塌到 18%);闭包与洞的分工(封闭 0.0% vs 桥接 7.7% 的新配对率)。

**未解决/深水区**:嵌入性的可操作化(网络约束/重复交易率与「嵌入感」的缝隙);过度嵌入的代价(锁死/合谋/信息冗余——幕一封闭世界的 0.0% 探索率是其极简形态);线上平台的关系重建(评分系统是不是关系的替身)。

## ✨ 这支最美的一个事实

**一箭双雕**:1985 年那篇檄文用一个词同时射穿两个稻草人——新古典的「社会化不足」(信任从真空中算出来)与旧社会学的「过度社会化」(规范内化到自动服从)。**行动者既算计又受束,而算计与约束都长在具体的关系网络里**。为什么美:一个好概念让两门学科同时照见自己的盲区;幕一是它的数值化身——同一群人,换一张网,合作率差 15 个百分点:**「理性」不是解释的起点,是被治理结构造出来的状态**。

## 假设与依赖

- 买入「关系可观察、可承载制裁」:网络数据是本支的硬通货;关系不可见处(暗网交易/一次性博弈),嵌入解释自动退场
- 过度嵌入被浪漫化的风险:信任的另一面是锁死(新配对率 0.0%)与合谋——本支出题也出代价;网络的形式工具上游归[数理社会学家族](../../讲透数理社会学/README.md)(互链)
