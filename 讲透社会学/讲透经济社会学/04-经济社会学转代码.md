# 04 · 经济社会学转代码:把市场解剖搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:经济社会学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**嵌入治理**、**信息冗余审计**、
> **r>g 财富动力学**——把「背叛没人管才理性」「圈子里的消息是旧闻」
> 「分化不需要贪婪」变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",经济社会学转代码要解决两步翻译:
先把社会学语言("这行信任靠关系执行")翻成模型(网络上的配对与
传播),再把模型翻成代码。损耗全部发生在第一步——所以本章先划清
哪些对象第一步就走得通(绿色区),哪些走不通(红色区),再给三条
走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 社会学概念 | 代码化身 | 备注 |
|---------|---------|------|
| 嵌入的治理(声誉制裁) | 网络配对博弈+黑名单沿边传播 | 实验幕一;封闭/桥接/匿名三世界参数化 |
| 弱关系的非冗余 | 强弱边分层网络+首达/冗余统计 | 实验幕二;对照世界=拆弱边重跑 |
| r>g 分化动力学 | 双账户复利+逐期份额/基尼断言 | 实验幕三;单调性可全量 assert |
| 财富分布指标 | 排序+洛伦兹/基尼/前 10% 份额 | O(n log n)/期;n=5000×100 期秒级 |
| 三张结构卡 | 定长字段记录+完整性断言 | 03 章 schema 的数据化 |
| 平台参数日志的治理审计 | 排名/抽成/评分字段的版本 diff | 拿得到日志才成立(红色区的门) |

**转不动(红色区)**:

1. **信任的语义**:机器里只有合作率,没有「信」——幕一断言的是
   制裁结构的执行,不是信任本身的意义(声明为最小机器,不是测量)。
2. **货币标记的裁定**:哪个格子叫「救命钱」是解释性判断;代码能
   统计钱的流向,**不能命名格子**。
3. **市场边界与控制观**:边界是政治裁定、控制观是共享认知的诞生
   史——卡片能记录结果,不能生成裁定。
4. **「恰是如此」**:为什么恰是这笔钱进了这个罐子,没有状态方程;
   硬造「关系工作指数」只会得到自己假设回去的结论(03 章右端)。
5. **应然之问**:「平台该怎么管」「r>g 该不该修」的规范判断不进
   实验台——代码算传播与复利,算不了好坏。

**边界的一句话**:绿色区=传播类+复利类+卡片类,覆盖"市场解剖的
机械学";红色区提醒:**转码是经济社会的使用说明书,不是替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:嵌入治理走廊(背叛的价格表)

```
交易者+策略 ──参数化──▶ 网络(匿名/封闭/桥接)+黑名单沿边传播 ──模拟──▶ 合作率/新配对率
      │                                                                        │
      └──对照──▶ 匿名市场(无声誉记忆)──▶ 治理价差断言 ◀──────────────────┘
```

- **理论→模型**:合作率=f(制裁的可达性);匿名=制裁不可达,
  嵌入=拉黑沿边扩散 1 跳;成功合作沉淀为关系边(网络生长)。
- **算法层**:每轮 O(边数) 配对;300 轮×3 世界秒级;断言合作率
  价差(>5pp)与探索率价差(桥接>4×封闭)。
- **本家族实现**:[`experiments/embedded_markets.py`](experiments/embedded_markets.py)
  幕一——匿名 85.0% vs 封闭 100.0%/桥接 99.9%;新配对率 0.0% vs 7.7%;
  欺诈者末段参与率 27.5% → 0.0%/0.2%。
- **真实系统**:反欺诈的**图特征工程**(被骗者的邻居=风险传播的
  种子集,幕一黑名单传播的工程版);平台信誉与封禁规则的设计评估
  (封禁的「传播半径」设多大,直接改写合作率曲线)。
- **性能工程要点**:价值不在算力在**对照设计**——匿名对照世界必须
  与嵌入世界共享策略分布(同 15% 机会主义者),否则「治理价差」
  混入「人群价差」;A/B 两世界用 base_seed+世界号的分流法保证可复现。

### 走廊 2:信息冗余审计走廊(消息的户口本)

```
网络(强圈+弱桥) ──参数化──▶ 单次播报 SI 扩散 ──统计──▶ 首达边型占比/冗余率
      │                                                  │
      └──对照──▶ 拆除弱边的世界重跑 ──▶ 覆盖率坍塌断言 ◀────┘
```

- **理论→模型**:首达占比=各类边「落在未知情者上」的频率;冗余率
  =1−首达率(按边型分账);弱边价值=拓扑事实,与态度无关。
- **算法层**:每 episode O(边数×轮数);60 次广播聚合;断言
  首达超额(>1.4×边占比)、冗余差(>15pp)、覆盖坍塌(>4×)。
- **本家族实现**:同实验幕二——弱边 14.2% 的边数拿下 22.8% 的首达;
  冗余 61.1% vs 78.8%;拆弱边覆盖率 99%→18%。
- **真实系统**:增长/营销的**渠道冗余审计**(同一素材经多少渠道
  重复触达同一用户——强关系式冗余的运营版;幕二的接收账本直接
  可用);组织内信息扩散设计(全员公告 vs 圈层转达的覆盖-冗余权衡)。
- **性能工程要点**:强弱边的**拓扑代用**(圈边=强,跨圈=弱)要在
  输出里声明——真实研究应换成实测交往频度,机器对代用变量不负责;
  聚合统计用固定种子多点采样(60 episodes),断言只锚聚合量不锚
  单次轨迹。

### 走廊 3:r>g 财富动力学走廊(分化的单调性证明器)

```
家户双账户 ──参数化──▶ 资本×(1+r±噪声) & 劳动×(1+g) ──迭代──▶ 逐期份额/基尼序列
      │                                                        │
      └──对照──▶ r=g 世界重跑 ──▶ 平稳性断言 ◀────────────────────┘
```

- **理论→模型**:分布形状=两列列车的相对速度;份额与基尼在 r>g
  下单调上升(混合分布向资本分布收敛),r=g 下形状不变。
- **算法层**:每期 O(n log n)(排序主导);n=5000、100 期含两世界
  秒级;断言用**全量单调**(all(a<b for 相邻期)),比端点比较强
  一个数量级——这是本走廊的招牌断言。
- **本家族实现**:同实验幕三——0.223→0.305/0.248→0.413 逐期单调;
  对照 Δ≈0.0001。
- **真实系统**:资产配置的**长期不平等压力测试**(客群财富分布×
  收益结构→N 年后的集中度,幕三换初始分布即得);代际财富的情景
  模拟(遗产规则=账户间的转移算子,红色区的政策判断不进机器)。
- **性能工程要点**:噪声要小(σ=0.008)且 n 要大(5000)——单调性
  断言的稳健性靠「漂移≫扰动」:边界换手贡献 ~1e-7/期,漂移
  ~2e-3/期,差四个数量级,断言才硬;否则把单调断言降级为容差
  断言并如实标注。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:风控的「关系侧」特征——谁和谁连着

- 传统风控特征是节点属性(收入/逾期史);幕一的教训是**制裁与
  风险都沿边走**:欺诈者的受害邻域是天然的风险种子集,担保链/
  转账网/设备关联图上的传播半径,就是「下次还能不能骗」的价格表。
  把黑名单传播做成图上的 label spreading,是幕一的产业版。

### 落点 2:触达去重与渠道预算——消息的接收账本

- 营销与增长团队天然面临幕二的账:多渠道推送的**边际新触达**递减
  (强关系式冗余),跨圈层渠道(弱边)单位预算的新增触达更高。
  把每个渠道的触达记成「首达/重复」账本,按首达占比分配预算——
  幕二的接收账本直接搬到报表层。

### 落点 3:客群财富分布的压力测试——别只看均值

- 任何按复利设计的商业模型(会员等级/积分/返现/理财产品),都在
  跑一台小型 r>g 机器:高存量用户滚得快,分布逐期右偏。上线前跑
  幕三的 100 期版本,看 top10 份额与基尼的轨迹——**分化的设计
  意图(激励头部)与其社会后果(锁死长尾)是同一台机器的两面**。

### 落点 4:平台治理参数的「宪法审查」习惯

- 排名权重、抽成、封禁半径,是平台市场的成文宪法。学 03 章卡 3
  的字段把它们**版本化管理**:每次调参跑一遍幕一式的对照世界
  (卖家合作率/新卖家进入率/欺诈参与率三指标),把「治理直觉」
  变成「治理回归测试」。

## 📌 收束 + 🧭 认知升维

消息靠弱边/分化靠结构),先问它的**对照世界**造了没有:没有匿名
对照的合作率、没有拆边对照的首达占比、没有 r=g 对照的单调上升,
都只是故事。转码的全部纪律就在这一眼里:**机器的价值不在算出
数字,在于让「没有它也行」变成一句可以被 exit 1 推翻的话**。
