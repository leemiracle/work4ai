## 一、家族定位(它在社会学宇宙里的位置)

经济学从「经济人」出发解释市场,社会学一直被指责只能在一旁说「还有
文化哦」。经济社会学的回答是**反守为攻**:不是在经济学模型上撒社会学
调料,而是指出**市场本身就是一台社会机器**——交易发生在关系里(空口
无凭的契约靠声誉网络执行),市场被治理结构撑起(谁定价、谁进出、谁
仲裁),货币被意义分格(同一笔钱在奶罐里和在股票账户里不是同一种钱)。
它在 840 宇宙里是**经济领域的社会结构司令部**:社会学理论供构念,
数理社会学供网络工具,各议题家族供战场,本家族管**把「经济」这个
最坚固的「自然事实」重新问题化**。五问(体系/前沿/语言/构造/转码)
的回答见家族层五章。

- **零门槛**:不要求经济学或社会学前置;只想看「经济学笑话」的去脱口
  秀,本家族管的是**市场如何可能**的构造学

## 二、家族树(GB/T 无三级明细 → 自定 3 支)

```
讲透经济社会学/            GB/T 84044(无三级明细 → 自定 3 支)
├── 讲透嵌入与市场社会性/   自定支(关系层)——嵌入性/经济行动的社会性/社会资本与信任
├── 讲透组织与市场治理/     自定支(结构层)——组织间关系/治理结构/平台市场的匹配与算法治理
└── 讲透货币金融社会学/     自定支(意义层)——货币的社会意义/金融化/消费与债务
```

> 三支的共同血统:同一句纲领「**经济行动嵌入社会关系**」的三层落地——
> 关系层管**交易发生在什么关系里**(微观:信任与信息的网络机器),
> 结构层管**市场靠什么结构撑起来**(中观:组织与平台的秩序),
> 意义层管**钱对人意味着什么**(文化:货币与金融的意义机器)。
> 三层缺一即塌:只有关系没有结构,解释不了市场的宏观秩序;只有结构
> 没有意义,解释不了同一枚货币为何被分成奶罐钱与救命钱;只有意义
> 没有关系,信任就成了口号。
