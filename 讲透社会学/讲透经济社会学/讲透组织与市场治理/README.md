# 讲透组织与市场治理 · 市场靠什么结构撑起来——治理的秩序学

> **定位句**:这支负责**结构层**——市场与组织的接缝:**组织间关系**(竞争与合作怎么共处)、**治理结构**(市场/科层/网络/平台凭什么执行交易)、**平台市场的匹配与算法治理**(排名/评分/抽成=成文的市场宪法)。口号:市场的第一个产品是市场本身的秩序。GB/T 13745 84044 经济社会学 · **自定支(结构层)** · 家族:[讲透经济社会学](../README.md)

## 诞生

- **谁/何时**:威廉姆森 1975《市场与科层》立交易成本判据(资产专用性决定治理形态)——1985 年嵌入性纲领攻击的正是它;怀特 1981〈市场从哪里来〉把市场网络化(厂商互相盯梢,角色结构自我再生产);弗利格斯坦 1996〈市场作为政治〉(控制观+国家在场);平台时代:Rochet-Tirole 2003 双边市场(经济学本体,与[../../../讲透经济学/](../../../讲透经济学/README.md)互链),2010s 算法治理与零工研究把治理写成代码(方向锚,检索校准 2026-09-07,见家族 01 章主线 A)。
- **因什么问题**:①同样的交易为何长出不同治理形态(形态之问)②市场秩序从哪里来(秩序之问)③平台的算法算不算治理(代码之问)。

## 核心问题

**已解决(通说)**:治理形态的可枚举比较(市场/混合/科层/网络/平台,家族 03 章治理结构卡);市场网络观(观察参照系从价格转向同伴);控制观作为市场稳定器;平台=双边市场+算法治理+数据反馈的复合体(03 章平台机制卡)。

**未解决/深水区**:形态间的杂糅与漂移(平台既像市场又像科层还像联盟);算法参数的「宪法审查」缺位(排名权重/封禁半径多由平台单方裁量);国家这个隐形签约方如何在平台时代重新签约(监管接口之争)。

## ✨ 这支最美的一个事实

**怀特命题:市场是厂商互相盯梢的产物**。教科书说市场由供求曲线交点定义;怀特说市场先是**一张网**:每个厂商盯着同类对手的动向给自己定位(role structure),价格与产量是这场相互观察沉淀下来的读数——**市场秩序不是竞争的结果,是竞争的前提**:先有「我们是谁、跟谁比」的共识,才有可言的竞争。为什么美:它把「市场」从经济学的前提变成了社会学的**成就**;平台时代这句判词有了代码版:排名算法就是那张相互盯梢的网的机器化身。
