# 04 · 文化社会学转代码:把意义车间搬进机器

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(性能工程视角贯穿)。
>
> **本章一句话**:文化社会学的谱系左端(03 章)几乎可以无损转码,
> 右端几乎不可转码;三条代码走廊——**区隔度计算**、**传染对照**、
> **巴斯扫描**——把"品味是位置的投影""规范需要圈子""峰值在渗透
> 近半之前"变成可跑、可断言、可做参数扫描的实验。

---

## 开篇:不是"能不能转",是"转到哪一层"

数学家族转代码要解决"离散化",文化社会学转代码要先过**清单关**
(02 章"清单即理论"):把一段文化主张("品味分人群")先翻成模型
(品类清单+分组+方差分解),再翻成代码。翻译的损耗发生在两处
——清单的口径与解读的层级;所以本章先划清哪些对象第一步就走得通
(绿色区),哪些走不通(红色区),再给三条走通了的走廊。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 文化概念 | 代码化身 | 备注 |
|---------|---------|------|
| 品味分布→区隔度 | 品类向量+分组;SS_between/SS_within 方差分解 | 实验律一全程纯标准库 |
| 品味空间可视化 | 二维散点(大众-小众×俗-雅)+组均值 | 律一的读图版 |
| 简单/复杂传染 | 环格重连(保度)+邻接表同步更新 | 实验律二;Centola 对照的最小实现 |
| 聚类系数 | 邻居对互连比例的平均 | 圈子密度的度量(律二的结构变量) |
| 巴斯扩散与拐点 | dF=dt(1−F)(p+qF);argmax 搜索 | 实验律三;F* 解析锚可断言 |
| p×q 参数扫描 | 双循环网格+拐点图 | 走廊 3;发布规划的仪表 |
| 生产场位置表 | 行=位置,列=资本/行动的表结构+完整性断言 | 卡 2 的数据化 |
| 品味测量卡 | 定长字段记录(dict/dataclass) | 卡 1 的数据化;清单口径字段强制非空 |

**转不动(红色区)**:

1. **深描与意义解读**:没有状态方程——"意义层级"不可参数化,
   压缩即失真。工程对策:退到意义解读卡+双人复核(03 章右端),
   不当仿真变量。
2. **规范判断**:代码能算"规范能不能传开",算不了"该不该传开"
   ——应然问题留在公共讨论与哲学侧,不进实验台。
3. **清单的中立性**:代码能执行任何清单,但清单本身是理论
   (02 章)——**自动化不豁免方法论责任**:清单字段必须在卡片里
   显式存档,不许藏在代码里冒充自然。
4. **p、q 的端到端标定**:仿真可以指定参数,但**从真实早期数据
   反推 p、q** 是计量识别问题(需早期采纳曲线拟合+稳健性检验)
   ——模拟不能冒充估计。

**边界的一句话**:绿色区=分布类+网络类+曲线类,覆盖"结构与传播
直觉的校准";红色区提醒:**转码是文化主张的使用说明书,不是解读
的替身**。

## 二、代码走廊清单(三条主走廊,每条=理论→模型→算法→真实系统)

### 走廊 1:区隔度走廊(位置转写的全机械化)

```
《区分》命题 ──参数化──▶ 组心{μ_g}+组内同方差 ──方差分解──▶ 区隔度 R(d)
      │
      └──对照实验──▶ 极化 d 扫描 ──▶ 单调性+平方标度断言
```

- **理论→模型**:G 组品味云,组心距离由资本极化参数 d 控制,
  组内发散度 σ 固定;R = MS_between/MS_within。
- **算法层**:单遍累积(组内和/组均值/总均值),O(n);不必存
  原始矩阵——**统计量是流式的**。
- **本家族实现**:[`experiments/culture_dynamics.py`](experiments/culture_dynamics.py)
  律一——断言 d=0 时 R≈1,d↑ → R 单调↑且近 d² 标度
  (实测 0.22→71→…→1589)。
- **真实系统**:用户画像的品味/消费品类面板(区隔度做结构性 KPI:
  人群按位置分组的品类分离是否在加深);推荐系统干预的公平性
  审计(算法是否在放大组间区隔)。
- **性能工程要点**:全部计算是**可并行的分组聚合**(map-reduce
  一次扫过);注意**数值精度**:SS_between 用组均值差的平方乘
  组大小,避免对大坐标做暴力差平方(方差平移不变,先中心化);
  断言只锚单调性与量级,不锚浮点尾数。

### 走廊 2:传染对照走廊(规范传播的对照实验台)

```
"规范要多次见证" ──参数化──▶ 阈值规则(需 3 个感染邻居)+两型网络
      │
      └──2×2 对照──▶ {简单,复杂}×{聚类,随机} ──▶ 结构敏感度断言
```

- **理论→模型**:两网同源于环格(度 8,重连保度):低重连 p=0.1
  (聚类保留)vs 全重连 p=1.0(聚类抹平);种子同一批(连续块)。
- **算法层**:邻接表+同步批量更新(每轮扫未感染节点数邻居感染数);
  吸收态判定=无新增。E=400 条边,每轮 O(E),轮数 O(n)。
- **本家族实现**:同实验律二——简单 100% vs 100%;复杂 100%
  vs 6%(聚类 0.495 vs 0.066)。
- **真实系统**:社区冷启动与规范类功能的种子设计(反霸凌规范/
  引用文化/协作习惯——按"圈子冗余"布种,不按流量撒匀);
  谣言 vs 辟谣的不对称(辟谣是复杂传染:多次见证才修正信念——
  这解释了辟谣总是慢半拍的结构原因)。
- **性能工程要点**:感染集用 set,邻接用压缩邻接表;**同步 vs
  异步更新会改变结果**(同步保守、可复现,实验用同步);大规模
  扫描时每格独立可并行,seed=base+格号保证可复现。

### 走廊 3:巴斯扫描走廊(发布日历的解析仪表)

```
"增长何时见顶" ──参数化──▶ dF=dt(1−F)(p+qF) ──扫描──▶ 拐点图 t*(p,q)
      │
      └──解析锚──▶ F*=1/2−p/(2q) ──▶ 仿真对表断言
```

- **理论→模型**:创新系数 p(外生推动)+模仿系数 q(内生传播);
  累积渗透 F 的 S 曲线;峰值增长位置 F* 解析可得。
- **算法层**:欧拉步进(dt=0.1 已够);峰值=argmax(增量);
  **解析锚做断言**(仿真 F_peak 与 F* 差不超过一步)。
- **本家族实现**:同实验律三——p=0.03、q=0.5 时 F*=0.47,
  实测峰值 F=0.472;p 扫描 0.02→0.20 峰值时间 6.3→1.3 单调前移;
  q=0 无 S 曲线。
- **真实系统**:内容产品/消费品的**发布与容量规划**(峰值服务器
  与库存压在 F* 之前就位)、营销投放的 p/q 标定(早期曲线拟合
  →预测峰值窗口)、增长复盘(实际拐点 vs 理论拐点的偏离=结构
  变化信号)。
- **性能工程要点**:曲线迭代 O(steps),扫描是 p×q 网格的外循环;
  **步长与断言容差联动**(tol=dt·g(F*),步长减半容差减半);
  大 dt 换速度会在拐点附近丢精度——容量规划场景宁小勿大。

## 三、工程师落点(把本家族用到你的日常)

### 落点 1:品味的结构面板——盯区隔,别盯均值

给内容平台的用户画像仪表盘加一栏**区隔度 KPI**:按位置分组
(城市线级/年龄带/会员级)的品类消费向量,监控组间/组内方差比
的时序。均值层(人均消费品类数)告诉你市场在变大,**区隔层**
告诉你人群在分开——算法策展是否在加深品味的地位分区(01 章
主线 B 的"茧房"之问),这个指标比"内容多样性"的总量口径诚实。

### 落点 2:规范类上线的"圈子冷启动",不是流量冷启动

要推的行为若是规范类(社区公约/协作习惯/安全实践),按走廊 2
设计种子:在**高聚类的既有社群**里成团布种(让每个目标用户在
圈子里有≥3 个见证人),而不是全站匀撒曝光——匀撒曝光对复杂
传染近乎无效(实验:随机网络 6%);反过来,谣言类信息你**不需要**
为它建圈子,它自己会走。

### 落点 3:发布的峰值预判——F* 之前做完所有准备

新品/新内容上线前,用早期数据标定 p、q(前 10-20% 渗透的曲线
拟合),推 F*=1/2−p/(2q):**库存、服务器、客服排班全部压在
预测峰值窗口之前**;营销加码(推高 p)会把峰值**前移**且压低
——砸钱买来的不是更高的山,是更早的山。

### 落点 4:辟谣与规范推广的预期管理

辟谣信息在结构上是复杂传染(需要多次见证才修正),其扩散天然
慢于谣言(简单传染)——给管理层的预期应该是"结构性慢半拍",
对策是提高**见证冗余**(多信源×多圈子重复触达),而不是单点
加大音量。
