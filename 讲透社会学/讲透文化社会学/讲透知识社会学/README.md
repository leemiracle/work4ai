# 讲透知识社会学 · 思想的社会存在——知识如何被位置生成与正当化

> **定位句**:这支负责意义链条的**上游车间**——意义的前提:范畴与世界观怎么被社会
> 位置生成(曼海姆的**思想的社会存在**)、常识怎么被分配与正当化(舍茨-伯格-卢克曼)、
> "客观知识"的社会情境边界在哪。与科学社会学以"思想的社会存在"为共用接口
> (专案正主归 6303510,见归入声明)。
> GB/T 13745 84037 文化社会学 · **三级原生支 8403720 知识社会学**。家族:[讲透文化社会学](../README.md)

## 诞生

- **谁/何时**:涂尔干-莫斯《原始分类》(1903,分类范畴的社会起源)预热;曼海姆《意识形态与乌托邦》(1929)开山——**总体的意识形态概念**:不只对手的观念有立场,一切思想都被社会存在穿透;舍茨把知识的社会分配现象学化(1930s-40s);伯格-卢克曼《现实的社会构建》(1966)合流:日常现实感本身是社会的产品;科学/医学/法律等富含知识的职业研究分蘖出去。
- **因什么问题**:①思想有没有"无立场"的位置(发生之问)②常识为什么感觉像自然(自然化之问)③这套理论自身的位置(反身之问——评价悖论)。

## 核心问题

**已解决(通说)**:思想的社会情境化纲领成立(范畴/问题域/证据标准随位置系统
变化);现实感的社会建构框架成为常备工具(外化-客观化-内化三时刻);
"意识形态"从骂词变成方法(总体的意识形态概念)。

**未解决/深水区**:反身性悬崖——知识社会学自身出自哪个位置(相对主义之争);
"真理"的社会学地位(社会条件≠真理判定);数字时代的知识生产与常识变迁
(算法分类系统成为新的范畴供给者)。

## ✨ 这支最美的一个事实

**评价悖论——把手术刀对准自己**:"你只是你所处位置的传声筒"这句批判,
本身出自一个位置。曼海姆不回避:他把**反思性**做成方法——正因为一切思想有
社会发生,追溯发生学本身就是知识工作的一部分;并把"无充分依附的知识分子"
(社会位置漂移者)指认为最有可能综观诸视角的阶层。**最深的洞见与最险的悬崖
是同一条**:承认思想有位置,同时坚持位置可被综观——知识社会学在这条刃上
走了一百年。
