# 03 · 可构造与结构:哪些文化对象能"造出来"

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:文化社会学的对象沿一条**可构造谱系**排开——
> 品味分布端**严格可构造**(清单写得下、区隔度算得动、方差分解
> 断言得了),深描端**几乎不可构造**(只有分层解读的工艺,没有
> 装配学);全谱系共享两条结构引擎:**位置转写引擎**(组间/组内
> 方差比随极化单调上升)与**扩散引擎**(简单/复杂传染的分型与
> 巴斯拐点);而"文化研究本身"可以压进三张**结构卡**(品味测量卡/
> 文化生产场卡/意义解读卡)。
>
> 三步法贯穿:**为什么可构造/不可构造 → 它是什么构造 → 亲手构造一次**。

---

## 开篇:一条谱系,两个极端

想象把本家族的所有对象按"能不能直接造出来"排一条线:

```
品味分布 ── 传染网络 ── 巴斯曲线 ── 生产场位置表 ── 品味测量卡 ── 亚文化风格追踪 ── 正典化档案 ── 深描/解读
  │                                                                                  │
严格可构造(可断言)                                                    几乎不可构造(只有思想操作化)
  └── 清单写得下、方差算得动、能过 assert                                    └── 只能在阅读与田野里操练
```

为什么会有这条谱系?**可构造的前提是"有限描述+确定语义"**:品味
清单的语义是"喜欢哪些品类",输入输出明确;而"深描"的语义是分层
重建行动者自己的意义层级——**解读者本人就是测量仪器,仪器无法
装配仪器**。本章先盘家底,再看两条结构引擎,最后把文化研究压成
三张结构卡。

## 一、可构造性家底盘点

| 对象 | 构造方式 | 成本 | 暗礁 |
|------|---------|------|------|
| **品味分布→区隔度** | 品类清单+分组;组间/组内方差分解;区隔度=MS_b/MS_w | 低(实验律一全程可跑) | 清单即理论(02 章);组定义先于计算 |
| **传染网络→终染率** | 环格重连(保度)+阈值规则;同步迭代至吸收态 | 低(实验律二) | 阈值 3 是"多次见证"的示数;现实采纳规则更模糊 |
| **巴斯曲线→拐点** | dF=dt(1−F)(p+qF);F*=1/2−p/(2q) 解析锚 | 低(实验律三) | p、q 的经验标定需早期数据(04 章落点 2) |
| **文化生产场位置表** | 行=位置(自主极↔他律极),列=资本形态+通行动作 | 中 | 布迪厄式的位置判定带阐释;须声明判据 |
| **品味测量卡** | 三栏 schema(§四) | 低 | 清单口径必须显式(02 章铁律) |
| **正典化档案** | 正典清单时间序列+准入事件表 | 中 | 档案幸存偏差(被遗忘的落选者无声) |
| **亚文化风格追踪** | 风格符号来源表+收编事件时序 | 中 | "收编"的判定有后见之明风险 |
| **解码立场** | 访谈+文本证据的三分编码 | 高 | 编码者间信度要双人对表 |
| **深描/意义解读** | 分层的意义重建 | **不可构造** | 意义层级不可参数化;压缩即失真(格尔茨的方法论本意) |

**反直觉发现(本章铁律)**:**本学科的名气与可构造性大体成反比**。
最有名的词(意义之网/深描/收编)在谱系右端,最能跑的对象(品味
分布/传染网络)名气最小——**右端管洞察,左端管检验**;拿右端对象
硬造左端指标(三题量表测"意义感")是文化量化研究的头号失真来源
——两头都不是。

## 二、结构引擎 1:位置转写引擎(区隔的代数学)

**直觉图像**:品味空间不是个人癖好的噪声海,是群体位置的投影板
——把人按社会位置分组,组间结构就从噪声里显影。

- **数学化身**:G 个组各在自己中心 μ_g 周围撒同方差高斯云
  (σ 相同);区隔度 R = MS_between/MS_within。
  E[R] ≈ 1 + c·d²(资本极化 d 的平方级)——**组内发散度不变时,
  区隔度完全由组心距离决定**(实验律一:d=0→0.22≈1;0.5→71;
  2.5→1589,单调且近平方标度)。
- **三条刚性**:
  1. **零点刚性**:d=0 时 R≈1——投影板本身不产生区隔,区隔的
     全部来源是位置分化(这把"品味天生分高低"的常识关掉了)。
  2. **单调刚性**:R 随 d 单调上升——不依赖分布形状的细节,
     只要组心分开,区隔必然显影(《区分》跨国复现的稳健性
     由此而来,通说)。
  3. **平方标度**:R 近似 ∝ d²——极化的放大是平方级的:位置
     拉开一倍,品味云的分离度翻四倍。
- **理论地位**:这是"文化反映结构"命题最干净的算术化身——
  没有隐藏变量,聚合规则(方差分解)明白写着。它是区隔论的
  **校准器**:任何"品味与阶级无关"的断言,先算区隔度再说。
- **刚性从哪来**:方差分解的数学是刚的;软的地方在**清单与分组**
  ——品类清单谁定、按什么分组,决定你测到哪种区隔(02 章
  "清单即理论";方法工艺归社会学方法家族,文字提及)。

## 三、结构引擎 2:扩散引擎(传染的分型与巴斯拐点)

**直觉图像**:文化事项的传播不是一个过程,是**两型**——
一次接触即染的简单传染(谣言/梗/消息)与需要多次见证的复杂传染
(规范/习俗/高风险采纳);总量层面的对应物是巴斯扩散
(创新 p+模仿 q 的耦合)。

- **网络化身(实验律二)**:同度 8、同种子的两网,聚类 0.495 vs
  0.066——简单传染两网都 100%(结构无感);复杂传染 100% vs 6%
  (结构决定生死)。**刚性**:复杂传染的波前需要**冗余见证**
  (宽桥——波前节点有 4 个本地感染邻居,丢 1 个照走);随机网络
  把见证稀释成单点接触,冻死在种子。**软的地方**:阈值 3 是
  "多次见证"的示数化,现实的采纳规则是概率与异质的(正式模型
  正主归数理社会学,文字提及)。
- **总量化身(实验律三)**:dF=(1−F)(p+qF),峰值增长钉在
  F*=1/2−p/(2q)——**刚性是解析的**:拐点位置只由 p/q 定,
  仿真只是对表;p 增大→峰值前移且落在更低渗透率;q=0→无 S 曲线
  (S 形是模仿的产物,不是传播的通性)。**软的地方**:p、q 要
  从早期采纳数据标定(03 章§一的暗礁;04 章落点 2)。
- **两具化身的合读**:网络化身管**给谁看/看几遍**(圈子与冗余),
  总量化身管**总量何时见顶**(渗透率与拐点)——推广规范先问
  前者,预测爆款先问后者;混用两具就是用流量思路做规范推广
  (00 章发现 2/3 的日常版)。

## 四、结构卡 schema:把一项文化研究压进三张卡

**先答为什么**:文化研究的难点在"整体性"——散落文献难以携带。
结构卡是**有限字段的压缩格式**:字段固定、填空即复用、可比可查
(这是"可构造"在研究层的对应物:卡片本身严格可构造)。

### 卡 1:品味测量卡(把一次品味研究钉成可审的表)

```
【品味测量卡】
研究问题:________(品味携带了哪种位置信息?)
清单口径:品类表来源=________ 粒度=________(粗/中/细)
分组变量:________(按什么分组——分组定义即区隔的定义)
测量仪器:□问卷自报 □行为痕迹 □文本指标(01 章主线 A)
核心量:区隔度 R=____ 杂食指数=____ 清单膝盖印(漏了什么)=______
替代解释(至少一条):________
失效条件(什么情况下区隔消失):________
```

样例(已填,杂食性研究骨架):清单=音乐流派表(粗粒度);分组=
教育与职业地位;仪器=问卷+流媒体痕迹双轨;核心量=杂食指数随
地位上升、区隔度仍显著;替代=可得性差异(低地位者接触渠道少,
非品味差);失效=品类渠道均等化后区隔度回落。

### 卡 2:文化生产场卡(把一个文化场钉成位置表)

```
【文化生产场卡】
场名:________(哪个生产场:音乐/文学/短视频……)
生产视角六要素:法律__ 技术__ 产业结构__ 组织__ 市场__ 职业__
(+第七要素:算法策展□)
位置轴:自主极(为同行而生产)↔ 他律极(为市场/权力而生产)
入场费与幻觉:________(哪些资本是入场券,哪些位置在贬值)
正典机制:谁在编清单________(奖项/榜单/推荐系统)
可检验推论(一条):________
```

样例(已填,独立音乐场景):技术=录音民主化+流媒体;算法策展=playlist
守门;自主极=厂牌信誉与乐评,他律极=流量分成;入场费=设备与
混音技能(在贬值)+场景人脉(在升值);推论=算法改版后作品时长
与结构向"前 30 秒钩子"收敛(生产视角的标准可检验命题)。

### 卡 3:意义解读卡(把一次解读钉成可复核的分层)

```
【意义解读卡】
对象:________(哪片实践/文本/仪式)
表层行为:________(外显的动作序列)
意义层级:第1层(当事人自称)=____ 第2层(情境语法)=____
          第3层(地位/权力坐标)=____
解码立场(若涉受众):□主导 □协商 □对抗;证据=____
收编检查(若涉亚文化):商业化通道__ 道德化通道__
反解读(最可能的另一种读法):________
复核方式:双人独立读→对表差异处
```

样例(已填,巴厘斗鸡):表层=赌博斗鸡;第1层=娱乐与赌注;第2层=
村社等级在重注中的对位法;第3层=地位戏剧——共同体向自己展演
等级;反解读=纯经济赌博(格尔茨用"深层游戏"概念回应:重注
结构与等级系统同构,机会成本不合理);复核=对表村里的
联盟-敌对网络。

**判定流程**(把一个文化主张钉到谱系上):

```
该主张的核心对象能写成清单、网络或曲线吗?
  ├─ 能,且语义有限确定 ─────▶ 左端:直接形式化+转码(04 章走廊)
  ├─ 能一半(位置表/档案,填空带判断)─▶ 中段:卡片化+双人校,禁止硬算
  └─ 不能(意义层级/解读)────▶ 右端:意义解读卡+田野,禁止压成参数
```

## 五、谱系×引擎×支总表(把全家族钉在一张图上)

| 支 | 谱系位置 | 主引擎 | 可构造等级 |
|----|---------|--------|-----------|
| 艺术社会学(8403710) | 中段为主:生产场位置表/正典档案;观众侧横跨到右端 | 扩散引擎(正典化的守门过程)+转写(趣味与位置) | 中(表格+卡片,填空带判断) |
| 知识社会学(8403720) | 右端为主(思想的社会发生靠解读);范畴清单在中段 | 转写引擎(思想的位置坐标) | 低-中(分类系统可清单化,意义不可) |
| 道德社会学(8403730) | 左-中段:容忍度条目可量,神圣性靠仪式解读 | 扩散引擎(复杂传染=规范传播)+转写(道德清单的位置) | 分裂:条目可算,神圣不可 |

**读表法**:一支的"可构造纯度"决定它的转码方式(04 章)——品味
与扩散走计算,生产场走卡片,深描永远走阅读。**没有哪支全家可
构造,也没有哪支全家不可构造**;这正是文化社会学比它的名声
("只会解读")更能算的地方,也比它的野心("全都能算")更谦逊
的地方。

## ✨ 美之时刻(彩蛋第 6 枚:两张引擎图的合龙)

✨ **美之时刻 6:投影板与传染病——文化的两幅可算侧脸**(极简)
位置转写引擎说:把人按位置分组,品味云自动分开(区隔度∝d²);
扩散引擎说:把事项按见证需求分型,规范只在圈子里走(聚类 0.495
vs 0.066 → 100% vs 6%)。为什么美:**"结构"与"传播"这两个最
玄的文化词,各自拿到了一个可断言的算术化身**——一个管静态的
分布(谁爱什么),一个管动态的扩散(什么能传);两幅侧脸合起来,
正是文化社会学的可算半身像。亲历:挑一个你身边的文化热点,分别
问两具引擎的问题——它在区隔什么?它走哪型传染(✍️练习 1)?
