# 讲透文化社会学 · 意义之网——文化如何被生产、分发与解读

> **本质一句话**:文化社会学=把「文化」从社会的装饰品改写成社会的
> **操作系统**的学科——它不问"人们有什么品味",而问品味如何成为社会
> 位置的**转写**(区隔);不问"一部作品好不好",而问艺术如何在集体
> 协作中被**生产**、被正典化;不问"道德是对是错",而问道德如何在
> 共同体中被**密度化**与再生产;一句话:**文化不是社会的反映,是
> 社会运转的深层语法——而意义在生产、分发、解读三个环节上都是社会过程。**
>

## 一、家族定位(它在社会学宇宙里的位置)

社会学宇宙的多数家族研究"人们做什么"(分层/组织/人口),本家族研究
"人们**以为自己在做什么**、这**意味着什么**、这些意义从哪来"——
涂尔干留下的集体表象、韦伯留下的意义箭头,在二十世纪后半汇成独立的
研究领域:文化不再是社会的"上层建筑装饰",而是分层的教学语言(区隔)、
生产的场域产物(艺术界)、共同体的道德密度(涂尔干)。文化转向
(伯明翰→布迪厄→格尔茨→工具箱→数字生产)的编年是 00 章的主线;
五问(体系/前沿/语言/构造/转码)的回答见家族层五章。
