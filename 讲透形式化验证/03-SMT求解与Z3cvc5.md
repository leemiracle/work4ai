## 一、从 SAT 到 SMT：给布尔骨架填上理论血肉

**SAT**：给定 CNF 公式（变量×子句），问是否存在真假赋值使所有子句满足。Cook–Levin（1971）：NP-完全。**证书视角**（全系列反复用）：SAT 的证书是**满足赋值**——检查它只需把每个子句代入，多项式时间；UNSAT 的证书是**反驳证明**（把子句一步步归结出空子句的证明链）。sat 有短证书未必易找、unsat 连"证书一定短"都不能保证——这就是 NP 与 coNP 的一格之隔（[50 章](./50-复杂度动物园与选型.md)把两种证书摆上动物园货架）。

**SMT** 把命题变量换成**理论原子**：`x+3 ≤ y`、`f(a) = b`、`arr[i] ≠ 0`——公式还是布尔骨架（∧∨¬），原子却活在背景理论 T 里。问的变成 **T-可满足性**：有没有一个 T-模型满足整条公式。常见理论一张表：

| 理论 | 缩写 | 管什么 | 判定器 |
|---|---|---|---|
| 未解释函数 | EUF | `f(a)=f(b) ⟸ a=b`（同余） | 同余闭包，O(n log n) |
| 线性实算术 | LRA | `< + ×常数` | 单纯形 |
| 线性整算术 | LIA | 同上但取整 | Omega/分支限界 |
| 位向量 | BV | 机器整数运算 | 位爆破→SAT |
| 数组 | ARR | select/store | 数组公理化 |

关键一句话：**SMT = SAT 求解器（骨架）× 理论求解器（血肉）**——骨架搜索是 NP 硬的那部分，理论求解器多数是多项式。同一个断言的两种编码，一眼看穿这层关系：

```
SMT 原文：  (x+3 ≤ y) ∨ ¬(f(a) = x)              ← 原子是理论命题
布尔骨架：  p ∨ ¬q    （p := x+3≤y，q := f(a)=x）  ← SAT 引擎看到的世界
```

SAT 引擎只在骨架上搜索（比如先猜 p=T），"p=T 在 LRA×EUF 里究竟成不成立"由理论求解器裁决，裁决结果再以引理形式回流骨架（§三的协议）。[04 章](./04-有界模型检查CBMC.md)的程序展开、[06 章](./06-Dafny验证语言.md)的验证义务，最终都落到这种公式上。复杂度格籍：无量词 SMT sat ∈ NP（证书 = 骨架赋值 + 理论一致性检查），unsat ∈ coNP（证书 = 理论引理反驳链）。带量词就出格（见 §七）。

## 二、CDCL 手推：冲突子句学习

公式 `F = (x1∨x2) ∧ (¬x1∨x2) ∧ (¬x2∨x3) ∧ (¬x2∨¬x3)`（lab03 E1）。初始 0 级传播：四个子句每个都有两个自由文字，没有单位子句，无事发生。算法是 DPLL（1962）的现代版 **CDCL**：决策→传播→冲突→**学习**→回跳。lab03 的完整轨迹（输出逐行贴回）：

```
  决策  x1 = T
  传播  x2 = T（由子句 (¬x1∨x2)：其余文字已全假）
  传播  x3 = T（由子句 (¬x2∨x3)：其余文字已全假）
  冲突！子句 (¬x2∨¬x3) 所有文字为假
  回跳  撤销决策 x1，学习单位子句 (¬x1)；assign 全清回 0 级（重启式回跳）
  传播  x1 = F（由子句 (¬x1)：其余文字已全假）
  传播  x2 = T（由子句 (x1∨x2)：其余文字已全假）
  传播  x3 = T（由子句 (¬x2∨x3)：其余文字已全假）
  冲突！子句 (¬x2∨¬x3) 所有文字为假
结果：UNSAT，学习子句 = [[-1]]
```

**手推走查**（每行可复算）：

1. **决策 x1=T**（顺序决策：取最小编号自由变量）。0 级上没有可传播的，只能猜。
2. **传播 x2=T**：子句 (¬x1∨x2) 里 ¬x1 已假，x2 成了唯一"救命文字"——单位子句规则强制 x2=T。
3. **传播 x3=T**：同理，(¬x2∨x3) 强制 x3=T。此刻 (¬x2∨x3) 要求 x3=T 而 (¬x2∨¬x3) 要求 x3=F——一个变量被两条子句拉向两边。
4. **冲突**：(¬x2∨¬x3) 所有文字为假（¬x2 假、¬x3 假）。冲突的责任链倒着捋：x3=T 是 x2=T 推的，x2=T 是 x1=T 推的——**根在决策 x1=T**。
5. **学习 (¬x1)**：把责任链压缩成一条新子句加进子句库（"决策取反"）。这就是"学习"——搜索失败的教训变成永久约束，以后任何分支都不再重蹈。
6. **重启式回跳（教学简化）**：撤销决策 x1、**assign 整体清空**回到 0 级，从 clauses+learned 从头传播——学习子句 (¬x1) 以 **0 级断言**身份进场，永远钉住 x1=F。
7. **0 级重放**：x1=F → (x1∨x2) 强制 x2=T → (¬x2∨x3) 强制 x3=T → (¬x2∨¬x3) 再次全假。这次是**没有任何决策可撤的 0 级冲突**——UNSAT，全程恰学一条子句 `[[-1]]`。

把传播链画成**蕴含图**（箭头 = "由…推出"），冲突的责任一目了然：

```
x1 = T（决策，唯一的根）
  ├─ (¬x1∨x2)：¬x1 假 ──────→ x2 = T
  │                             └─ (¬x2∨x3)：¬x2 假 ──→ x3 = T
  └─ 冲突：(¬x2∨¬x3) 的两个文字 ¬x2、¬x3 全假——撞假它的 x2=T、x3=T 都是 x1 的后代
```

所有箭头追根到底都是 x1=T——真实求解器的 1UIP 分析就在这张图上做归结切分；本 lab 的"决策取反"是它的退化情形（图只有一个根）。**学习为什么值得**：子句库每多一条学习子句，搜索空间就被永久削掉一块，同类死路永不重蹈——CDCL = DPLL + 记忆，工业实例百万变量可解的底气全在这（对比 1962 年的纯 DPLL：无记忆，指数回溯，几千变量就啃不动）。

对照 E2：`G = (x1∨x2) ∧ (¬x1∨x3)` 同一套机制给出 `SAT，模型 = {x1=T, x2=T, x3=T}`，逐子句代入验证通过——这个可独立检查的赋值就是 NP 证书。z3/cvc5 对拍：`z3 对 F check → unsat`、`cvc5 对 F check → unsat`，与手写 mini-CDCL 三方一致。

**与真实 1UIP 的差异（如实交代）**——教学版砍了四刀：

- **学习子句**：工业 CDCL（GRASP 1996 提出、Chaff 2001 定型）沿**蕴含图**做归结，学 **1UIP 子句**——一般含多个文字，回跳后由"断言文字"接棒；本 lab 的"决策取反"只在冲突**完全由最后一个决策+0 级事实**引发时才是可靠推理（F 恰好如此：全程唯一决策就是 x1）。一般情形学出的 [¬d] 过强，可能把 SAT 误判 UNSAT——F/G 是挑过的用例，工程版无此病。
- **回跳层级**：1UIP 回跳到子句的**次高层**，保留下层已推导的赋值；教学版全清重启，0 级重来——省掉层级簿记，代价是重复推导（最坏情形指数放大）。
- **决策启发式**：真实求解器用 VSIDS 活动度（冲突中常出现的变量优先）；lab 用最小编号顺序。
- **工程件全无**：watched literals（两点监视让传播摊销成 O(1)）、子句删除（LBD 度量）一概没有。mini 是真的 mini。

## 三、DPLL(T)：布尔引擎与理论求解器的分工协议

§二 的 CDCL 只会摆布布尔变量。DPLL(T)（Nieuwenhuis–Oliveras–Tinelli，JACM 2006）是分工协议：**布尔抽象**把每个理论原子当作一个命题变量喂给 CDCL；CDCL 给出骨架赋值后，**理论求解器**检查这组原子在 T 里是否一致。三种交互：

1. **抽象冲突**：骨架说 `x>2 ∧ x<1` 全真，LRA 说矛盾 → 产生理论引理 `(¬(x>2) ∨ ¬(x<1))` 加回子句库，CDCL 像对待普通冲突一样学习回跳。
2. **T-传播**：骨架已定 `x≥y`、`y≥z` 为真，LRA 蕴含 `x≥z`——直接当单位传播推出来，省一次决策、少一次冲突。
3. **E-传播**：EUF 已定 `a=b`，同余闭包立即推出 `f(a)=f(b)`——不用等骨架去猜。

理论求解器怎么挂上来，有两条路：**积极（eager）**——把公式全套等价翻译成 SAT/EUF 一次性求解（位向量理论位爆破后走这条最划算）；**懒（lazy）**——按需产生引理、一次只回流一小块（Z3/cvc5 主路线，理论求解器贵时更省）。一个抽象冲突的完整回合：骨架把 `p=(x>2)`、`q=(x<1)` 都定成 T → LRA 报矛盾 → 引理 `(¬p ∨ ¬q)` 入库 → CDCL 把它当普通冲突学习回跳 → 之后任何分支自动绕开这片坏区域。**理论引理在 DPLL(T) 里的角色，恰如学习子句在 CDCL 里的角色**——把昂贵的教训变成便宜的约束。

**Nelson-Oppen 组合**（1979）：两个理论 LRA×EUF 怎么合作？三步：

- **净化（purification）**：把公式按理论切成两份。lab03 E3 的例子 `φ ≡ f(a)>1 ∧ a<2 ∧ f(a)+a<3`：EUF 份只有 `u = f(a)`（函数表无任何约束），LRA 份是 `1<u ∧ a<2 ∧ u+a<3`——**接口变量** `u := f(a)` 冻结了 EUF 项，交给 LRA 当普通实数。只被一个理论引用的变量叫**纯变量**，横跨两边的（u、a）叫**脏变量**——协商只发生在脏变量上。
- **协商（arrangement）**：两个理论求解器对共享变量的等值/不等值关系互换提议，直到双方都满意（存在公共模型）。条件不白给：理论须 **stably infinite** 且**签字不相交**。
- **合取模型**：EUF 说"无约束"，LRA 解出 `u=2, a=0`（z3 给的模型 `[a = 0, f = [else -> 2]]`：f 处处取 2，f(a)=2>1 ✓，a=0<2 ✓，2+0=2<3 ✓）→ 组合 **sat**。lab03 E3 的 `LRA×EUF 组合：f(a)>1 ∧ a<2 ∧ f(a)+a<3 → sat` 就是这条链的输出。

各理论求解器是多项式的，但布尔骨架搜索在顶上主导一切——组合不改变 NP/coNP 格籍（[50 章](./50-复杂度动物园与选型.md)收编时用的是这一条，不是单纯形的多项式）。

## 四、Z3 与 cvc5：架构与生态

**Z3**（de Moura & Bjørner，MSR 起家，TACAS 2008；2015 开源 MIT 许可，现 AWS 维护）——事实标准。架构三层：

```
输入 → 简化器/重写器（rewriter：先做便宜的等价改写，删冗余）
     → 核心（CDCL SAT 引擎——就是 §二 那台，加了全部工程件）
     → 理论插件（算术 / EUF / 数组 / 位向量 / 数据类型 …按需挂载）
```

组合层 Z3 不做经典 Nelson-Oppen 协商，走**基于模型的组合**（model-based combination）：直接猜一个接口等值安排、让理论各自修模型——工程上更快，代价是回退逻辑复杂。

**cvc5**（Stanford/Iowa 系谱：SVC→CVC→CVC3→CVC4→cvc5）——杀手锏是**证明输出**：unsat 时能产出可独立检查的证明证书（这是 lean-smt 能在 Lean 里重建证明的前提，见 §五）。**SMT-COMP**（2005 年起年度竞赛，随 SMT-LIB 生态）是两家的擂台，按 logic 分赛道；格局大致 Z3/cvc5 双雄 + Bitwuzla（位向量赛道黑马）等专项选手。

**SMT-LIB 语法五分钟**——求解器的公共语言，命令式脚本：`declare-fun`（声明）、`assert`（加约束）、`check-sat`（判定）、`get-model`（要模型）。logic 名字按配方缩写：`QF`=无量词，`U`=EUF，`LIA/LRA/NIA`=线性整/线性实/非线性整算术。§二 的 F 写出来：

```lisp
(set-logic QF_UF)
(declare-fun x1 () Bool)
(declare-fun x2 () Bool)
(declare-fun x3 () Bool)
(assert (or x1 x2))
(assert (or (not x1) x2))
(assert (or (not x2) x3))
(assert (or (not x2) (not x3)))
(check-sat)        ; unsat —— 与 lab03 E1/E3 对拍
```

§三 的组合例子则是（lab03 E3 的 SMT-LIB 版，`check-sat` 得 `sat`）：

```lisp
(set-logic QF_UFLRA)
(declare-fun a () Real)
(declare-fun f (Real) Real)
(assert (> (f a) 1.0))
(assert (< a 2.0))
(assert (< (+ (f a) a) 3.0))
(check-sat)        ; sat
```

两个文件贴进任一求解器（Z3 试验页 / cvc5 playground / 本地 CLI），就能与 lab03 对拍。

## 五、SMT 的下游：符号执行与 Lean 的外部求解器

**符号执行**（KLEE/angr）：沿程序路径把执行符号化，收集**路径条件 PC**（该路径上所有分支条件的合取）。验证断言 A：判 `PC ∧ ¬A`——**unsat** 则该路径上断言必真；**sat** 则模型给出触发违反的具体输入。注意方向：SMT 的模型不是答案，是**反例**（[04 章](./04-有界模型检查CBMC.md)的"反例=模型"整个建立在这上面；lab03 E2 的 {T,T,T} 就是一个能直接读走的证书）。一个最小回合：

```c
if (x > 0 && x < 10) assert(x + 5 < 10);
```

then 路径上 PC = `(x>0) ∧ (x<10)`，判 `PC ∧ ¬(x+5<10)`，展开即 `(x>0) ∧ (x<10) ∧ (x+5 ≥ 10)`——LRA 一口报 **sat**，模型（如 x=7）就是现成反例输入：7<10 成立，但 7+5=12 ≥ 10，断言确实被踩爆。把断言换成 `x+1 > 0`，公式变 unsat——该路径安全。每条路径一个 SMT 查询，这就是符号执行"跑一遍、覆盖所有输入"的机制。

**Lean4 的外部求解器**（造桥回 [卷零 00](./00-为什么形式化+Lean4SOTA.md)）：两条路线，同一个信条——**结果可以外包，证明不能外包**：

- **原生证明生产**：Saturn（Gadgil）把 DPLL 写在 Lean 里，输出解或归结证明树——"SAT 求解器即证明器"；Duper（Clune–Qian–Bentkamp–Avigad，ITP 2024）是 superposition 微积分的 Lean 终端 tactic。
- **外部调用 + 证明重建**：lean-smt（CAV 2025）把 Lean 目标译成 SMT-LIB 喂 **cvc5**，再把 cvc5 的证明输出**重建**为 Lean 内核可检查的项；Lean-blaster 走同类路线调 Z3。cvc5 的证明输出（§四）在这里成了刚需。
- 另有 Lean 自带的 `grind`——SMT **风格**（同余闭包+E-匹配思想）但内核内实现、不调外部，与 `omega`/`simp` 同族（[00 章](./00-为什么形式化+Lean4SOTA.md)讲过 `omega` 解不掉的边界）。

## 七、不足与边界

1. **量词爆炸**：带量词的 SMT 一般不可判定；E-matching/MBQI 实例化策略**不完备**——答 unsat 可信，答 sat 可能是猜的（求解器会老实标 unknown，但工程里常被当 sat 用）。
2. **非线性半可判定**：NRA 可判定（柱形代数分解 CAD）但最坏双指数；NIA 直接不可判定——上量就换编码（线性松弛）或换工具。
3. **组合的代价**：Nelson-Oppen 要求 stably infinite + 签字不相交；脏变量一多协商就贵。Z3 的基于模型组合是工程绕行，不是免费的午餐。
4. **证书不对称**：sat 模型立等可取；unsat 证明要看求解器脸色——cvc5 把证明当一等公民，Z3 的证明输出长期非重点（§五 的证明重建因此首选 cvc5）。
5. **昂贵的理论**：浮点理论位爆炸代价极高；字符串约束是另一个世界（Z3str 系）。
6. **卷一的接缝**：SMT 只判"一条断言/一条路径"的公式——循环要靠不变式（[05 章](./05-抽象解释与CPAchecker.md)）、程序整体要靠验证感知语言（[06 章](./06-Dafny验证语言.md)）把义务**分解**成本章吃得下的一口口小菜。
