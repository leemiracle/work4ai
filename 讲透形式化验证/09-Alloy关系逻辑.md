# 09 · Alloy：关系逻辑的小世界

> 卷二收官：[08 章](./08-TLA+与TLC.md) 用值元组写状态，本章把"一切皆**关系**"推到极致——Alloy（MIT，Jackson 一系）的世界里没有函数只有关系，结构的约束（"每个条目至多一个父目录"、"无环"）用四个关系算子写成一行，然后**交给 SAT**：在给定论域规模（scope）下穷举一切实例，要么给反例、要么宣告"这个规模内无恙"。三件套：**关系四算子**（点乘 `.`、方盒 `[]`、波浪 `~`、转置——结构约束的乐高）；**fact/断言/检查/scope 四构件**（lab09 在地址簿上实测：NoShared 首破 scope=2、NoCycle 首破 **scope=1（自环——计划手推漏掉的第一反例）**、禁自环后二环在 scope=2、三名字链汇址恰 scope=3）；**Kodkod→SAT 的归约**（关系约束编译成布尔公式喂给 [03 章](./03-SMT求解与Z3cvc5.md) 的 CDCL——"小反例哲学"的引擎舱）。【有界=NP；无界不可判定】

---

## 一、一切皆关系：四个算子的乐高

Alloy 的本体论：**签名**（sig，如 `Name`、`Addr`）是论域的集合；**字段**（field）是签名间的**二元关系**（`alias: Name → Name`）；没有全局状态、没有可变性——只有"结构长什么样"的约束。四个算子统治一切：

| 算子 | 名字 | 读法 |
|---|---|---|
| `.` | 点乘（join） | `alias.addr`：先 alias 后 addr 的复合——"别名指向的地址" |
| `~` | 转置 | `~alias`：反着走 |
| `*` / `^` | 自反/传递闭包 | `^alias`：沿 alias 走任意步 |
| `& ∪ −` | 集合运算 | 关系就是集合，全套可用 |

例：地址簿的核心一行——`no iden & ^alias`（**alias 传递闭包不碰自身=无环**）。结构性质的"一行一个"是 Alloy 的招牌：图的可达性、单射性、无环性全是关系式的组合——没有归纳法、没有不动点，就这么多。

## 二、四构件：fact / 断言 / 检查 / scope

| 构件 | 语法 | 角色 |
|---|---|---|
| **fact** | `fact { 每个名字至多一条出路 }` | 良构约束——**建模者断言的世界规则**（检查只在满足 fact 的实例里找反例） |
| **断言** | `assert NoShared { … }` | 声称——**待反驳的定理** |
| **检查** | `check NoShared for 3` | 在 scope=3 内穷举——SAT 找反例或宣告无恙 |
| **scope** | `for 3`（或 `for 3 but 2 Addr`） | 论域上界——**有界语义的旋钮** |

关键的哲学选择：**Alloy 的语义天然有界**——`check` 只在"每个签名 ≤ scope 个原子"的实例里穷举。反例是**证据**（找到即确凿），"无反例"只是"此规模内无恙"——与定理证明（无界全称）的分工由此划定（§五）。

## 三、有界语义手推：地址簿的三个断言（先跑后写）

地址簿模型（lab09 用 z3 的 Int+哨兵直译 Kodkod 语义）：`alias_to, direct_to: Name → 原子∪{∅}`，良构 fact = 每个 n 至多一条出路（alias 或 direct 二选一）；`resolve(n) = direct(n) 若有，否则 direct(alias(n))`。三个断言在 scope=1..4 下的首破时刻（实测）：

```
E1 · 三个断言 × scope=1..4：首个反例的 scope（'scope 是旋钮'）
  NoShared 不同的名字解析到不同地址  scope=1:UNSAT  scope=2:反例!  …
  NoCycle   alias 链无环（裸模型）    scope=1:反例!  …
  NoCycle′  alias 无环（fact:禁自环） scope=1:UNSAT  scope=2:反例!  …
  TwoChains 链汇址（三名字互异）      scope=1:UNSAT  scope=2:UNSAT  scope=3:反例!  …

E2 · 反例实例：
  【NoShared】scope=2：n0: direct→a1；n1: alias→n0     —— n1 经别名也解析到 a1，撞址
  【NoCycle】  scope=1：n0: alias→n0                    —— 一节点自环！计划手推漏掉的第一反例
  【TwoChains】scope=3：n0→n1→a0；n1→a0；n2→a0         —— 一个中转站 + 两个直连共享者
```

四条读法。**其一**：NoShared 的反例最小到只需 2 名 1 址——别名机制天生会把两条路指到同一处，"这大概是 bug 而非特性"的证据当场呈堂。**其二**：NoCycle 裸模型在 scope=1 就破——**自环 n0→n0 是环**（计划稿手推"二环@scope=2"漏了它）；给模型加 fact `no n: Name | n ∈ n.alias`（禁自环）后，首破才推迟到 scope=2 的二环——**约束每收紧一分，反例推迟一格**：fact 纪律与 scope 旋钮的双人舞。**其三**：TwoChains 要"中转站与两个共享者互异"的三个名字，scope=2 摆不下——**反例的最小规模本身就是结构信息**（需要什么角色才能摆出这个 bug）。**其四**：断言取反 = SAT 查询（∃ 证人），反例 = 模型——**Alloy 检查器输出的"实例"就是 z3 的 model**（lab09 里两者是同一行代码的两种打印）。

## 四、Kodkod：关系约束 → SAT → 回连 03 章

Alloy 的引擎 Kodkod 做的事：把"关系 + 量词 + 闭包"的约束**编译成布尔公式**——论域 k 个原子 ⟹ 关系变成 k×k 布尔矩阵；点乘/闭包变成矩阵运算的组合；一阶量词变成布尔连接词展开。编译产物交给 SAT 求解器（Minisat/glucose 谱系）——正是 [03 章](./03-SMT求解与Z3cvc5.md) 手推的 CDCL 引擎在吃另一份饲料。**复杂度注记**：固定 scope 下整个检查是**一次 SAT 查询 = NP**（scope 是指数的藏身处：k 个原子的关系有 2^{k²} 种取法——scope 调大，SAT 实例指数涨，这就是"scope 旋钮"的代价面）。无界版本的"结构满足断言吗"则是不可判定的（一阶逻辑有效性）——Alloy 用有界语义绕开了它（§五的立场）。

## 五、轻量级 FM 的定位：比测试强、比定理证明弱

Alloy 自称（也确实占住）的位置——**轻量级形式方法**：

- **vs 测试**：测试跑你要想的实例，Alloy 穷举你没想到的实例（在 scope 内）——"自动化的事故想象力"；
- **vs 定理证明**（[06 章](./06-Dafny验证语言.md) Dafny/卷零 Lean4）：证明给无界全称，但人要给不变式/引理；Alloy 零证明义务，但结论只到 scope 为止；
- **vs 模型检查**（[07](./07-LTL与Spin.md)/[08 章](./08-TLA+与TLC.md)）：Spin/TLC 查**行为**（时序性质），Alloy 查**结构**（快照式约束）——查"数据结构不变量"（文件系统、路由表、权限模型）是它的主场。

选型口诀：**结构的 bug 用 Alloy 一网打尽小规模、行为的 bug 用 Spin/TLC 追路径、要无界保证上 Dafny/Lean**（[50 章](./50-复杂度动物园与选型.md)决策树的一根主枝）。

## 六、仪器

- **Python 保底**（本 lab）：`python experiments/lab09_alloy_relation.py`——四断言 × scope 1..4 的首破扫描 + 反例实例打印（z3 model 当 counterexample）。
- **原生可选**：Alloy（jar，需 JDK；alloytools.org）——把地址簿写成 `book.als`，`Check NoShared for 2` 的 GUI 反例可视化与本 lab 的文本实例对拍。装不通不阻塞。
- 对照：同一断言在 Alloy 里是 `check`、在 z3 里是"取反 + sat"——两边输出的是同一种东西（小反例）。

## 七、不足与边界

1. **有界 ≠ 全称**："scope=5 无反例"不证明无反例——bug 需要 6 个角色才复现的故事在 Alloy 用户里是都市传说级的真实；scope 的"够用"判断靠经验与增量（先小后大地爬）。
2. **scope 是指数旋钮**：关系空间 2^{k²}，scope 稍大 SAT 就爆——Kodkod 的对称破除（同构实例只探一个）是救命稻草，也只是一根。
3. **结构强、行为弱**：时序（"终将"）不是 Alloy 的母语（要靠事件/迹的编码绕）——行为性质请走 [07](./07-LTL与Spin.md)/[08 章](./08-TLA+与TLC.md)。
4. **无归纳**：闭包算子 `^` 有，归纳证明没有——"对任意长度成立"的论证只能交给定理证明器。
5. **整数算术是二等公民**：Alloy 的 int 是有范围撮合的（scope 化的整数）——重数值的模型（计数器、预算）别指望它，那是 SMT（[03 章](./03-SMT求解与Z3cvc5.md)）的主场。
