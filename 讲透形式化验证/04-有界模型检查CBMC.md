# 04 · 有界模型检查：CBMC/ESBMC

> 卷一第二站：03 章造好了 SMT 引擎，本章给它第一个整装客户。程序安全（"任何输入下断言永不踩爆"）**不可判定**——能跑循环的程序就是图灵机。第一条工程出路是**有界模型检查（BMC，Biere–Cimatti–Clarke–Zhu，TACAS 1999）**：程序 k 步展开→SSA→断言取反→SMT——**SAT 的模型就是反例，UNSAT 只保 k 步**。手推 lab04 的 3 行循环 `for i in 0..2: a[i]=i` 三轮 SSA 演化（σ0→σ3，反例模型 0/1/2）；走进工具室看 **CBMC**（goto-IR、指针/数组/位域编码、`--unwind` 与 unwinding assertion）与 **ESBMC**（SMT 多后端、并发上下文界、浮点）的分野，再看 BMC 的自我超越 **k-induction**（从"查 k 步"到"证全貌"）。仪器：[`experiments/lab04_bmc_cbmc.py`](./experiments/lab04_bmc_cbmc.py)（z3 复现编码）+ cbmc.exe（Windows 官方包，可选）。【NP】

## 一、为什么"有界"：不可判定问题的第一出路

**程序安全性不可判定**：一个带循环和未定输入的程序能模拟任意图灵机，"断言 A 是否对一切输入成立"可编码停机问题——不存在对一切实例都给正确答案的算法，[50 章](./50-复杂度动物园与选型.md)把它放进动物园"界外"格。工程不认命，三条出路（卷一的骨架）：

1. **截断**（本章 BMC）：只看前 k 步——判定化，把无穷轨迹砍成有限公式；
2. **过近似**（[05 章](./05-抽象解释与CPAchecker.md) 抽象解释）：把无穷状态压进有穷抽象域，代价是假报警；
3. **人给不变式**（[06 章](./06-Dafny验证语言.md) Dafny）：循环的性质由不变式断言，验证义务分解成一串小公式。

**为什么 1999 年要"无 BDD"**：当年的符号模型检查用 BDD 表示状态集（[12 章](./12-BDD与CUDD.md)），对位级变量多、分支密的程序变量序敏感、动辄节点爆炸。Biere 等的洞察：不表示状态集，只问"k 步内存在一条违反轨迹吗"——这一问一翻就是 SAT 公式，而 SAT 求解器（CDCL，[03 章](./03-SMT求解与Z3cvc5.md) §二）恰好对这种又长又扁的合取式胃口极好。BMC 名字里的 bounded，就是那笔交易的签名。

BMC 的公式一行动笔：**I(s0) ∧ T(s0,s1) ∧ … ∧ T(s_{k−1},s_k) ∧ ¬P(s_k)**——初始条件 ∧ k 份转移关系 ∧ 最后一步断言取反。变量是程序变量的 k+1 个"版本"（SSA，§二），公式有限、无循环结构。无量词（若程序运算线性）时 sat ∈ **NP**：证书是一条**反例轨迹**（每个变量版本的具体值），检查 = 拿输入跑一遍程序（03 章 §五 的证书观照搬过来）；UNSAT 的证书 = 求解器的反驳链（交给 03 章那台 CDCL/DPLL(T)——学习子句砍分支，理论求解器裁决算术原子）。

与符号执行的差别只在**粒度**：符号执行一条路径一次查询（PC ∧ ¬A，03 章 §五），路径数随分支指数涨；BMC 把所有 ≤k 步的路径合进**一个**公式——分支成为布尔选择子，路径枚举变成求解器内部的 case-split，公式大小只是 O(k·|程序|)：

```
路径枚举（符号执行）:  路径1∧¬P?  路径2∧¬P?  …   分支数指数个查询
BMC（一次编码）:      I ∧ T^k ∧ ¬P               一个查询吃下全部分支
```

代价则明码标价：**SAT → 找到 ≤k 步的反例（找 bug 完备）；UNSAT → 只知 k 步内安全**（证全不完备）。完备需要 k ≥ 可达直径（到达每个可达状态所需最少步数的最大值）——此时 UNSAT 即全貌，但直径实践中通常不知道，这正是 §四 k-induction 要救的场。

## 二、展开编码手推：k 步 SSA 与"反例=模型"

lab04 的程序与断言：

```c
int a[3];
for (int i = 0; i < 3; i++) a[i] = i;      // 恰好 3 轮
assert(a[0] + a[1] + a[2] == 3);
```

k=3 展开：循环三次，每轮写一个下标——**展开后 i 已被代入常量 0/1/2**，下标全常量、每槽恰好写一次，SSA 版本号"每槽一个"。三轮演化表（⊥ = 未写）：

| 状态 | 触发语句 | i | a[0] | a[1] | a[2] |
|---|---|---|---|---|---|
| σ0 | 初始 | 0 | ⊥ | ⊥ | ⊥ |
| σ1 | i=0: a[0]=0 | 1 | **0** | ⊥ | ⊥ |
| σ2 | i=1: a[1]=1 | 2 | 0 | **1** | ⊥ |
| σ3 | i=2: a[2]=2（循环退出） | 3 | 0 | 1 | **2** |

断言在 σ3 检查：a[0]+a[1]+a[2] = 0+1+2 = **3**。SSA 方程（lab04 的编码逐行对应；变量名 `aj_r` 读作"第 r 轮写入的 a[j] 版本"，此后不再写 ⇒ a0_σ3 = a0_1 = 0）：

```python
a0_1 = 0          # σ1: 第 1 轮写入 a[0]
a1_2 = 1          # σ2
a2_3 = 2          # σ3
断言取反:  ¬(a0_1 + a1_2 + a2_3 == 期望值)
```

**断言取反 = 找模型 = 反例**（本行的纲领）：BMC 问"存在一条 ≤k 步的执行走到断言处且断言不成立吗"。判 ==3：`¬(0+1+2==3)` 与三个方程矛盾 → **UNSAT** → 不存在这样的执行 → 断言（3 步内）成立。判 ==7：`¬(0+1+2==7)` 可满足 → **SAT**，z3 吐出的模型就是现成反例。lab04 实跑输出（原样贴回）：

```
反例模型: [a0_1 = 0, a1_2 = 1, a2_3 = 2]
lab04 自检通过: ==3 成立 / ==7 违反 ✓
```

模型三个值 0/1/2 与演化表 σ3 行逐位一致——代入 0+1+2=3≠7，断言确实被踩爆。这个模型不是"答案"，是**能直接读走的证书**（03 章 §五 的承诺在程序级兑现）。

三个一般化注脚：其一，本例无分支，路径条件平凡；有分支时每个 if 成为一个布尔选择子，所有 ≤k 步路径共用一个公式（§一）。其二，**每槽被写多次**时版本号沿轮数增长，控制流汇合处用 φ 函数择路：

```
a[0]=1;  if (g) a[0]=2;
→  a0_1 == 1；  a0_2 == 2；  ¬g → a0_2 == a0_1     ← φ：g 真走新值、假走旧值
```

**下标非常量**（`a[j]=i` 而 j 未定）时不能提前定槽位，得换数组理论 select/store（§三）——本例是"最好展开"的循环，工程程序大多没这么乖。其三，断言只读已写槽位，未写槽根本不进公式；若读了未初始化变量，CBMC 会把"未定义行为"本身当一条性质报给你。

## 三、CBMC 的工程：goto-IR、指针/数组/位域、--unwind

**CBMC**（Clarke–Kroening–Lerda，"A Tool for Checking ANSI-C Programs"，TACAS 2004；CMU 起家，2016 年起由 Oxford 衍生公司 Diffblue 工业维护）把 §二 的手工流程做成流水线：

```
C 源码 → goto-cc 编译成 goto-IR（三地址式、控制流显式的 goto-program）
       → 循环展开（--unwind k 截断 + unwinding assertion）
       → 符号执行：沿 goto-IR 走一遍，生成 SSA 方程（§二 手工做的事）
       → 后端求解：位爆破 → SAT（MiniSat2/Kissat/CaDiCaL，亦可换 Z3 等 SMT）
```

编码层的三件硬活：

- **指针**：编成 (对象 id, 偏移) 二元组——解引用变成"对象合法 ∧ 偏移在界内"的断言，越界/悬垂/空解引用顺手全查（内存安全断言与用户断言同一套机制）；
- **数组**：select/store 递增式编码（`a[i]=v` 变 `a' = store(a, i, v)`，读 `select(a, i)`），§二 的"每槽一个变量"是其常量下标特例；
- **位域/机器整数**：一律位向量——环绕溢出是**精确语义**（不是抽象），还能开溢出检查让 `INT_MAX+1` 直接报警。

**`--unwind k` 与循环上界告警**：截断让"第 k+1 轮的 bug"隐形，CBMC 的解法是 **unwinding assertion**——在截断点断言"循环条件已假"（k 轮内必退出）；新版默认生成（`--no-unwinding-assertions` 关闭）。它 FAIL 就明说 bound 不够：此时其余全 PASS 也只对"截断程序"负责。读 CBMC 结果的规矩：**先看 unwinding assertion，再看用户断言**。loop3.c（断言故意写 ==7）：`cbmc loop3.c --unwind 3`——循环恰 3 轮，unwinding assertion PASS，用户断言 **VERIFICATION FAILED**，反例逐步列出三轮赋值、sum=3≠7；把 7 改回 3 → VERIFICATION SUCCESSFUL。对照实验：`cbmc loop3.c --unwind 2`——截到 2 轮循环没走完，unwinding assertion **FAIL**（bound 不够的告警现场），此时截断程序里 a[2] 根本未写，用户断言的结论只对残缺程序负责。

## 四、k-induction：从"查 k 步"到"证全貌"

BMC 的 UNSAT 止步 k 步。想证全貌：**k-induction**（SAT 时序归纳，Sheeran–Singh–Rönnquist 2000；ESBMC 把它带进软件验证），两问：

1. **基始（base）**：`I(s0) ∧ T^k ∧ (∨_{i≤k} ¬P(s_i))` → UNSAT——开头 k 步无违反（就是 k 步 BMC）；
2. **归纳步（step）**：`P(s0) ∧ … ∧ P(s_{k−1}) ∧ T(s_{k−1},s_k) ∧ ¬P(s_k)` → UNSAT——任取**连续 k 个满足 P 的状态**（不管可达不可达），走一步仍满足。

两问 UNSAT ⇒ P 对**一切可达**状态成立：基始封住"开头就错"，归纳步封住"任何地方的第一次出错"（它前 k 步都得满足 P，矛盾）。k=1 退化为经典归纳——P 自己当不变式；k>1 给性质"k 步的上下文"，有些性质天然要几轮才 inductive。完整版是三问（ESBMC 的实现）：在两问之间插一个**前进条件（forward condition）**——"所有长度 k 的可达路径都满足 P"；若 k ≥ 直径（§一），它覆盖一切可达状态。判定规则：**基始 ∧（前进 ∨ 归纳步）UNSAT ⇒ 证全**。

**何时不收敛**：最典型是单调计数器——

```c
int c = 0;
while (c < N) c++;        // 前 k 个状态 c=0..k−1 全合法
if (c == N) error();      // "无 error"对任何 k 都不 inductive
```

任取 k：前 k 个状态 c=0..k−1 满足 P、转移合法，但第 k+1 个状态 c=k 合法与否 P 说了不算——任何固定 k 都能被"再走一步"顶翻。病根是缺**加强不变式**（如"c 单调且 ≤N"）；解法两条：自动发现（ESBMC 的区间分析给归纳步加约束）、人写（[06 章](./06-Dafny验证语言.md) Dafny 的日常）。链条就此打通：**BMC 找 bug（k 内完备）→ k-induction 证全貌（对 inductive 性质完备）→ 都不行，05 章 CEGAR 自动合成不变式**。

## 五、ESBMC 分野：并发上下文界、SMT 多后端、浮点

**ESBMC**（Enhanced SMT-Based Model Checker；Cordeiro–Fischer–Marques-Silva，ASE 2009/TSE 2012；UFAM/曼彻斯特系）从 CBMC 的 ANSI-C 前端分叉，换掉心脏。分野一张表：

| 维度 | CBMC | ESBMC |
|---|---|---|
| 求解路线 | SAT 优先：位爆破→MiniSat2/Kissat/CaDiCaL（SMT 可选） | SMT 优先：Z3/Boolector/Yices/MathSAT/cvc5 多后端一键切换 |
| 并发 | 线程交错整体编码进公式 | **上下文界**：`--context-bound` 截断线程切换次数（round-robin/witness 等策略） |
| 浮点 | 位向量位爆破（IEEE 位级精确） | 原生 SMT 浮点理论（NaN/舍入语义入公式） |
| 循环 | 展开为主 | **k-induction 一等公民**：基始/前进条件/归纳步三问 + 区间不变式 |
| 生态 | Diffblue 工业维护，C/C++ | SV-COMP 常客，衍生 ESBMC-GPU（CUDA 核函数）等 |

为什么分野要紧：位爆破对**位级推理**（移位/异或/环绕）常常更快、模型更小；SMT 对**算术密集**（线性不等式、浮点）常常更省——同一程序两种编码各有赛场，ESBMC 的多后端让你逐性质换刀。对拍一眼：同一个 loop3.c（==7 版），两家都应吐出"三轮赋值 0/1/2、sum=3≠7"的同款反例；把断言改回 ==3，CBMC 走展开，ESBMC 可走 k-induction——循环有界（3 轮必退），基始一问就封全貌，"证全"不再止步 k 步。并发上下文界则是"有界"交易的第三次出现：线程交错无限，截到 C 次切换——找 bug 完备、证全不完备，与 §一 同一笔账。

## 七、不足与边界

1. **天文展开数**：公式大小 O(k·|程序|)。d 层嵌套、每层 n 轮的循环要 k=n^d 步展开；"跑 1000 轮才炸"的 bug 意味着千倍程序大小的公式——而 SAT 本身 NP 完全。完备阈值（可达直径）实践未知，UNSAT 只能读作"k 步内干净"。
2. **非线性与动态下标的编码膨胀**：非常量下标 → 数组理论（或每元素卫式方程，n 下标 × k 步）；乘除/模 → 位爆破子句爆炸（64 位乘法动辄数十万子句）或落入 SMT 非线性（03 章 §七 的不可判定/半可判定地带）。
3. **位精确的代价**：环绕、移位、位域全靠位向量——SAT 变量数 ≈ Σ 位宽 × SSA 版本数，C 代码的每一寸机器语义都要在公式里付房租。
4. **并发上下文界仍是"有界"**：C 次切换之外无保证——§一 那笔交易的并发版。
5. **k-induction 不收敛**：需要加强不变式；自动区间分析覆盖有限，兜底是人写（06 章）或 CEGAR 插值自动合成（05 章）。
6. **卷一的接缝**：BMC/k-induction 都把"程序级问题"化成 03 章的公式——义务分解的另一路是 06 章；不可判定本体归 [50 章](./50-复杂度动物园与选型.md) 动物园"界外"格，本章的 NP 格是它够得着的这一侧。
