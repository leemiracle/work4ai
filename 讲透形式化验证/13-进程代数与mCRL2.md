## 一、并发的话语：CCS 三算子与互模拟

**CCS**（Milner 1980，"通信系统演算"）把并发写成代数式，三个算子起步：

| 算子 | 写法 | 读法 |
|---|---|---|
| 前缀 | `a.P` | 先做动作 a，再 behaving 成 P（**强绑定**——括号有语义！） |
| 选择 | `P + Q` | 提供 P 的第一个动作或 Q 的第一个动作 |
| 并行 | `P | Q` | 双方动作任意交错；互补动作（a 与 ā）可同步成内部 τ |

互模拟（bisimulation）回答"两个进程对外是否无法区分"——不是语法相同，是**行为合同相同**。判定是场**博弈**：攻击者任选一方走一步，防守者必须在另一方用**同一个动作**跟上，且跟上后俩人余下的处境仍然互模拟；谁能把对方逼到"接不住"谁赢。lab13 E2 的三个判例：

```
P = a.(b.0 + c.0)：先做 a，再做 b/c 的选择——a 之后处于【同时提供 b、c】的状态
Q = a.b.0 + a.c.0：先选路线（都以 a 开头）——a 之后要么只会 b、要么只会 c
  P 与 Q 互模拟：False  —— Milner 经典反例：攻击者把 P 引到'双选态'后出 b（或 c），
     防守者跟到 Q 的单支态就再也接不住另一动作——前缀的括号改变一切
  对照真例：a.0 + a.0 ≡ a.0（选择幂等）：True｜a.0 + b.0 ≡ b.0 + a.0（交换）：True
```

一句话读法：**`a.(b+c)` 是"a 之后开菜单"，`a.b+a.c` 是"点菜在 a 之前就完成了"**——菜单态是攻击者的武器。互模拟是"对外行为等价"里最粗的合同（比迹等价细：菜单态在迹里看不见），也是 [11 章](./11-Storm与高性能概率检查.md)概率双模拟压缩的表亲——"最小化再验证"的合法性全靠它。

## 二、从 CCS 到 μ-演算：时序逻辑的公共超集

给进程写性质需要时序语言。两个家族在此汇合：**LTL** 走路径（[07 章](./07-LTL与Spin.md)）、**CTL** 走分支树——而 **μ-演算**把两者都装下：LTL 与 CTL 都可译成它（且互不可表达的余量仍留给它自己）。它的全部机密是**带不动点算子的模态逻辑**：

$$\varphi ::= p \mid \neg\varphi \mid \varphi\vee\psi \mid \langle a\rangle\varphi \mid [a]\varphi \mid \mu X.\varphi(X) \mid \nu X.\varphi(X)$$

- ⟨a⟩φ：存在一个 a 后继满足 φ（菱形=可能）；[a]φ：**所有** a 后继满足 φ（方盒=必然）；
- **μX.φ(X)**：φ 作为 X 的函数（单调）的**最小不动点**——"有限次 unfold 就成立"的性质，**必然性/可达性**的家；
- **νX.φ(X)**：**最大不动点**——"可以永远自持"的性质，**安全性/不变性**的家。

直觉两行背下来受用：**μ 从小往大灌**（从 ∅ 起一轮轮扩大，问"从种子出发灌得到谁"）；**ν 从大往小削**（从全集起一轮轮削减，问"谁配得上留在最大自洽集里"）。交替嵌套（μ 里套 ν）表达"无穷次仍有穷"（如"无穷多次可响应"），表达力在这一步反超 LTL/CTL。

## 三、不动点迭代手推（与 10 章价值迭代同宗）

μ-演算模型检查 = 在状态集上解不动点方程：函数单调 + 有限格 ⟹ 迭代必停（Tarski）。lab13 E1（LTS：s0 -a→ s1 -a→ s2 -b→ s3，s2 ⊨ p、s3 ⊨ q）：

```
μX.(p ∨ <a>X) 迭代（从 ∅ 放大）：['s2'] → ['s1', 's2'] → ['s0', 's1', 's2'] → 停
  = {s0,s1,s2}：s2 是 p 种子，<a> 把 s1、s0 沿 a 倒着灌进——'沿 a 可达 p'
νY.(q ∧ [a]Y) 迭代（从全集收窄）：['s0','s1','s2','s3'] → ['s3'] → 停
  = {s3}：s0/s1 无 q 首轮出局；s2 有 p 无 q 出局；s3 无 a 后继（[a]Y 空真）幸存
对照：μX.(q ∨ <a>X) = {s3}（无人经 a 指向 s3，一轮即停）
     νY.(p ∨ <a>Y) = {s0,s1,s2}（s3 无 p 又无 a 出边，首轮被削）
```

四条读数各是一课：μ 的三轮灌浆（可达性=最小不动点的原型）；ν 的收窄（安全不变式=最大不动点）；换成 q 种子 μ 一轮即停（灌浆的半径由转移结构决定）；ν 削掉死端（无出边且无 p 的状态不配留在"永远"里）。**跨卷呼应**：这与 [10 章](./10-PRISM概率模型检测.md) MDP 价值迭代（p = max Σ Pp，线性算子的不动点）是同一思想的两种格——那里在实数向量上迭代、这里在集合上迭代；[11 章](./11-Storm与高性能概率检查.md)的停机判据陷阱也在这里回声：迭代到"集合不再变"才是真不动点，没有"相邻差小"的模糊地带（幂格没有数值误差——集合世界的干净之处）。

## 四、NP∩coNP：动物园的活展品

μ-演算模型检查的复杂度账本（标准文献结论；置信度：高）：**对公式交替深度 alternation depth d，时间 O(|TS|·|φ|^{d+1})；一般情形模型检查在 NP∩coNP 里**（Emerson-Jutla-Lei 一系；多数文献陈述为 O(n·m^{⌈d/2⌉+1}) 级）。为什么恰好这格：**对偶性**——¬μX.φ(X) = νX.¬φ(¬X)，"满足"与"不满足"对称，故 NP 证书（接受树）与 coNP 证书（反驳树）**同时存在**；它**进没进 P 是 1996 年至今的悬案**（奇偶博弈等价：μ-演算模型检查 ⟺ 奇偶博弈求胜者，而"奇偶博弈是否多项式可解"是复杂度动物园的名门悬案——2017 年 quasi-polynomial 算法突破后仍未关门）。三重身份记住它：**LTL∪CTL 的公共超集**（表达力王座）、**NP∩coNP 的住户**（悬案展品）、**奇偶博弈的化身**（与博弈论系列"均衡可解性"一脉相承的难解性）。

## 五、mCRL2 工具链：代数式的工程出口

mCRL2（Groote 一系，Eindhoven）把 CCS→μCRL→mCRL2 一路工程化：**建模**（mCRL2 语言：数据+进程代数，`allow/comm/block` 算子收拢同步）；**线性化**（mcrl22lps：任意式子编译成**线性进程规范 LPS**——一组参数化转移方程，分析的标准形）；**检查**（lps2lts 生成 LTS、或直接在 LPS 上查 μ-演算公式 `lps2pbes`→`pbessolve`——不动点方程组求解器，本章 §三的迭代法工业化版）。与近亲的分工：**FDR/CSP**（Oxford，精化检查/refinement 一系——用"实现 ⊑ 规约"的序关系而非等价）；**CADP**（另族工具链）；**TLA+**（[08 章](./08-TLA+与TLC.md)：数学规约路线，无代数外壳）。

## 七、不足与边界

1. **代数的门槛是真的**：`a.(b+c) ≢ a.b+a.c` 这种"括号即语义"的纪律，工程师要适应期——TLA+/Alloy 的"数学直写"路线正因此抢走了易用性（[08](./08-TLA+与TLC.md)/[09 章](./09-Alloy关系逻辑.md)的立场差）。
2. **状态爆炸没有豁免权**：代数式再优雅，展开成 LTS 还是指数；互模拟最小化（[11 章](./11-Storm与高性能概率检查.md)压缩的表亲）与符号技术（[12 章](./12-BDD与CUDD.md)）是仅有的两副解药。
3. **μ-演算的 P 之谜悬而未决**：实践里 alternation depth 小（≤2 居多），多项式算法（O(m^{d+1})）已经够用——悬案是理论荣誉问题，不是工程阻塞。
4. **同步通信的表达力有边界**：CCS 式握手要动作名互补配对；数据传递/异步队列要走 π-演算或 mCRL2 的数据化扩展——代数家族内还有方言要学。
5. **互模拟最小化的代价**：最小化本身 PSPACE-难（对标签转移系统），"先压缩再验证"不一定总赢——与 [12 章](./12-BDD与CUDD.md)变量序一样是启发式战场。
