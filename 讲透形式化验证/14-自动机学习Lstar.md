# 14 · 自动机学习 L*：从黑盒重建模型

> 卷四收官：验证需要一个模型——可要是系统是黑盒（legacy 协议栈、第三方芯片、只有 API 的服务），模型从哪来？本章的答案是**问出来**：Angluin **L\***（1987）证明了"最少充分教师"（MAT）模型下，DFA 可以用**多项式次查询**精确学出——这是本系列唯一一章"没有模型也要验证"的正面进攻。三件套：**观察表三件套 S/E/T**（行=候选状态、列=实验、格=成员查询结果；**闭合**=无新行、**一致**=同行必同转移——两个不变量驱动整张表走向规范）；**手推 (a\|b)\*ab**（lab14 的三步演化全记录：反例前缀入行 → 一致修复加列 → 收敛恰为最小 3 态自动机）；**查询复杂度**（成员 O(n²m) 级 + 等价 **O(n)** 次——多项式的来源与工程里"等价查询只能近似"的现实落差）。仪器是 [`experiments/lab14_lstar_angluin.py`](./experiments/lab14_lstar_angluin.py)（完整 L\* + automata-lib 对拍）+ pyformlang 交叉。【多项式查询复杂度】

## 一、MAT 模型：教师是奢侈品，但比"全知"便宜

学习者只有两种提问权：

- **成员查询 MQ(w)**："串 w 在目标语言里吗？"——便宜（黑盒跑一次）；
- **等价查询 EQ(H)**："我的假设 H 对吗？"——不对则教师**必须给出反例**（区分 H 与目标的串）。

关键是后者的强度：现实里没有完美教师——只能用测试集/W 方法（§四）近似。L\* 的历史地位正在于此：**在最强教师假设下把"可学性"钉死为多项式**，此后二十年的工业衍生（LearnLib 一系）全是在"把强教师降级成弱教师"上做工程。与验证的关系一句话：**学习是逆向的模型检查**——检查问"模型满足性质吗"，学习问"满足这些答案的模型是什么"。

## 二、观察表：S/E/T 与两个不变量

观察表是一张渐渐长肉的等价类账本：

| | E（列=实验后缀） |
|---|---|
| **S**（行=已承认的状态代表） | T[s·e] = MQ(s·e) |
| S·Σ（行=待考的后继） | 同上（fill 自动补齐） |

两个不变量是算法的心跳：

- **闭合（closed）**：每个 S·Σ 行都等于某个 S 行——"后继没有新状态"；违反则把新行提升进 S（**发现新状态**）；
- **一致（consistent）**：同行的两个 s，对每个动作 c 后继行也必须同——"同一状态转移良定义"；违反则把区分后缀加进 E（**拆开混装的状态**）。

两者都满足时，**行 ⟷ 状态**：假设 DFA 的状态就是相异行，转移 = 行加动作后落到哪行——一致条件恰好保证这不取决于行的代表元。**最小性是定理**（Myhill-Nerode：行即右等价类）——L\* 吐出的自动机天然最小，不是碰巧。

## 三、手推 (a|b)\*ab：三步收敛（与 lab14 输出逐行对照）

目标：三态最小 DFA（接受恰以 ab 结尾的串）。lab14 的完整演化：

```
[0] S=[''] E=[''] ← 初始
[1] S=['', 'a', 'ab'] E=[''] ← 反例 'ab' 前缀入行
[2] S=['', 'a', 'ab'] E=['', 'b'] ← 一致修复（加入列 'b'：''~'a' 行同而后继异）

轮数 2，等价查询 2 次，成员查询 11 次
最终假设 3 态，与目标无区分词 —— 等价 ✓
minify(目标)=3 态 = 假设 3 态 ✓；抽查 8 词双方接受一致 ✓
```

逐步读（14 章的核心手推）：

1. **第 1 张表** S={ε}, E={ε}：行(ε)=(F)。ext 行 a、b 都是 (F)——闭合 ✓ 一致 ✓。假设 = **1 态全拒自动机**（"什么都不是"的零假设）。等价查询给反例 **ab**（目标接受、假设拒绝）。
2. **反例处置**（经典策略）：ab 的全部前缀 ε/a/ab 进 S——"反例经过的每个中间状态都可能是新状态"。
3. **第 2 张表** E 仍 = {ε}：行(ε)=(F)、行(a)=(F)、行(ab)=(T)——三行两相异，闭合。但**一致被打破**：ε 与 a 同行 (F)，而它们的后继行 row(ε·b)=row(b)=(F) ≠ row(a·b)=row(ab)=(T)——"同一状态 b 转移后命运分叉"，矛盾！把区分后缀 **b** 加入 E。
4. **第 3 张表** E={ε,b}：行变成二元组——ε:(F,F)、a:(F,T)、ab:(T,F) **三行全异**，ext 的行全部可归位：闭合 ✓ 一致 ✓。假设 = 3 态 DFA：ε 态（非终）、a 态（"刚见过 a"、非终）、ab 态（终）。等价查询：**无区分词**——学习完成，恰 2 次 EQ、11 次 MQ。

值得盯一眼的是"肉长在哪"：**反例负责横向开行（新状态线索）、一致修复负责纵向开列（状态分离）**——L\* 的全部戏剧就是这两股力的交替。

## 四、查询复杂度：多项式从哪来，现实差在哪

Angluin 1987 的账本（n=目标状态数，m=最长反例长度，|Σ|=字母表）：成员查询 **O(n²m·|Σ|)** 级、等价查询 **≤ n 次**（每次反例至少让一张新行进 S，而行数 ≤ n）——总代价多项式，这是"主动学习"可性的奠基结果。**现实落差**：等价查询是完美教师——黑盒只能近似：

- **W 方法**（Chow 1978）：用已学的 W 集合（区分后缀族）构造**完备测试套件**——若目标 ≤ n′ 态且套件全过，则假设正确；查错上界随 n′−n 指数增长（状态数差距的罚金）；
- **随机等价查询**：随机采样词对比——实用但无完备保证（LearnLib 的默认工作流）。

一个诚实的工程句式：**L\* 给了"可学"的定理，测试给了"大概学对了"的置信**——两者之间的缝隙正是统计与形式方法的接壤地。

## 五、LearnLib/AutomataLib 与 Python 生态

Java 侧的工业标准 **LearnLib**（Dortmund 一系）把 L\* 做成算法/Oracle/过滤器的积木架：教师被抽象成 **MembershipOracle/EquivalenceOracle** 接口（黑盒=SUL 系统under学习），算法可换（L\*、KV、TTT——后两者查询数更优），**AutomataLib** 提供自动机数据结构与等价/最小化。Python 侧：**automata-lib**（本 lab 对拍对象：DFA/NFA/PDA/TM 的纯 Python 实现）、**pyformlang**（文法/自动机/图查询一体化——正则路径查询直接 `regex ⊗ graph`，与 [13 章](./13-进程代数与mCRL2.md) LTS 查询同型）。两边的分工直觉：Java 管工程规模，Python 管教学与胶水。

## 六、应用：协议逆向与合规测试

- **协议逆向**：对 TLS/SIP/QUIC 的实现当黑盒跑 L\*——学出的状态机与 RFC 对照，差异即实现缺陷或指纹（ fingerprinting）；
- **legacy 系统**：三十年的固件没有文档没有模型——测试口插上 L\*，学个行为模型再上模型检查（[07 章](./07-LTL与Spin.md) 的管线倒着接）；
- **回归验证**：每次发版学一遍自动机、diff 状态数——"行为变化"被机械地暴露。

本章收卷四的题眼：**BDD/进程代数/自动机学习是同一间引擎室的三台机床**——表示（[12](./12-BDD与CUDD.md)）、语义（[13](./13-进程代数与mCRL2.md)）、获取（本章）。

## 七、不足与边界

1. **完美教师不存在**：现实等价查询只能近似（W 方法指数罚金/随机采样无保证）——L\* 的多项式是理想模型下的多项式。
2. **噪声黑盒会撕碎一致性**：MQ 答错一次，一致修复就永远修不平——抗噪学习（Angluin 的 noisy 模型一系）复杂度显著变差。
3. **学的是 DFA**：非确定/概率/带数据字母表的黑盒需要 NFA 学习、注册自动机（RNN 近年也在补位）——模型类选错，学出来的自动机要么爆炸要么欠拟合。
4. **状态数是大前提**：现实协议状态数上万时，观察表 S·Σ 的规模直接压垮查询预算——抽象（把无穷数据域折叠成谓词）先于学习。
5. **黑盒的"黑"有底线**：系统必须可复位、可观测输入输出——不可复位的在线系统没法做成员查询。
