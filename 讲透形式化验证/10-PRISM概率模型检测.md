# 10 · PRISM：概率模型检测

> 卷三开卷：卷一卷二的检查都问"**会不会发生**"，本章开始问"**以多大概率发生**"——会掷骰子的系统（随机协议、失效恢复、缓存淘汰）需要定量的答案，而定量恰好落在复杂度地图**最舒服的一格：P**。三件套立正：**四类概率模型**（DTMC/CTMC/MDP/PTA——"确定性马尔可夫链→连续时间→带选择→带时钟"四步走）、**PCTL**（LTL 的概率化表亲：`P≤p[F φ]` 把"永远/最终"变成可比较的数）、**检查 = 解方程**（DTMC 的 P(F φ) 是**线性方程组**——0.6 的完整手推；MDP 是对动作取 max 的**价值迭代**——与 [13 章](./13-进程代数与mCRL2.md) μ-演算同为不动点思想）。仪器是 [`experiments/lab10_prism_pctl.py`](./experiments/lab10_prism_pctl.py)（numpy 手推对拍）+ PRISM 原生工具（可选）。【P】

## 一、会掷骰子的系统：四类模型

前三卷的系统是"恶魔式的"——环境任意选择、算法任意交错。真实系统还有第三种角色：**骰子**（丢包率 0.01、节点失效率 10⁻⁶/小时、随机退避）。四类模型一张表就位（每类是前一类的加法）：

| 模型 | 加了什么 | 转移 | 现场例子 |
|---|---|---|---|
| **DTMC**（离散马尔可夫链） | 概率转移 | 每步一个**概率分布** | 随机化退避协议的离散步 |
| **CTMC**（连续时间） | 指数时钟 | **转移率** λ（停留时间 Exp(λ)） | 队列/失效/修复（速率方程 = ODE） |
| **MDP**（马尔可夫决策过程） | **非确定性选择** | 先选动作、再按分布掷骰 | "重传或放弃"的策略自由 |
| **PTA**（时间自动机×概率） | 实数时钟 | 带区间的随机时延 | 时限协议（deadline 概率） |

关键区别在第三行：DTMC 只能回答"这个**随机**系统以多大概率满足 φ"；MDP 才能回答"**无论怎么选**（最坏调度）都至少以 p 概率满足 φ"——非确定性是验证里"对抗环境"的化身（[08 章](./08-TLA+与TLC.md)的"任意交错"在此获得了 max-min 语义）。本章手推用最小模型：一个 DTMC、一个只有两个动作的 MDP。

## 二、PCTL：把"最终"变成数字

PCTL（概率计算树逻辑）= CTL 的概率化。三件套语法：

- 状态公式：`p`（原子）、`¬φ`、`φ∧ψ`、`P⋈p[ψ]`（路径公式 ψ 以概率满足 ⋈ p，⋈ ∈ {≤,<,≥,>}）
- 路径公式：`F φ`（最终）、`G φ`（总是）、`φ U ψ`（直到）——[07 章](./07-LTL与Spin.md)的时序算子原班人马
- 奖励算子：`R≤r[F φ]`（到达 φ 的期望开销）——把"能耗/步数/花费"也变成可查的量

读法一句话：**LTL 问"有没有一条坏路径"，PCTL 问"坏路径的测度有多大"**——从二值到连续，恰好对应从 NP/PSPACE 到 P 的复杂度降落。`P≤0.01 [F crash]` 就是工程语言："崩溃概率不超过百分之一"，且是**精确算出的**，不是测试估的。

## 三、DTMC 检查 = 解线性方程组（手推）

设 p(s) = 从 s 出发**最终**到达 target 的概率。首步分解（全概率公式）：

$$p(s) = \sum_{t} P(s \to t)\, p(t), \qquad p(\text{target}) = 1,\; p(\text{死态}) = 0$$

lab10 的三态例子（10 行模型、1 个未知数）：

```
s0 --0.5--> s0（自环）  --0.3--> s1=target  --0.2--> s2=死态

p0 = 0.5·p0 + 0.3·p1 + 0.2·p2
   = 0.5·p0 + 0.3·(1) + 0.2·(0)
   ⇒ 0.5·p0 = 0.3  ⇒  p0 = 0.6
```

矩阵形式：把吸收态挪到右边，得 **(I − Q)·p = r**（Q = 瞬态间转移、r = 一步进 target 的概率）——线性方程组，`np.linalg.solve` 一步出解：

```
E1 · DTMC：P(F target) = 解线性方程组
手推（10 章 §三）：p0 = 0.5·p0 + 0.3  ⇒  0.5·p0 = 0.3  ⇒  p0 = 0.6
  np.linalg.solve((I−Q), r) → p0 = 0.6000000000（vs 手推 0.6，|偏差| 0.0e+00）
→ E1 自检通过：方程组解与手推逐位一致——模型检查是【算】出来的，不是采样采出来的
```

**为什么是解方程而不是迭代/采样**：有限 DTMC 的可达概率是这组方程的**唯一**解（吸收马尔可夫链的基本矩阵定理）；解 n 元线性方程组是 O(n³)——这就是 PCTL 落在 **P** 格的原因（对比 [03 章](./03-SMT求解与Z3cvc5.md) 的 NP、[07 章](./07-LTL与Spin.md) 的 PSPACE）。期望类性质（R 算子）是同一组方程换个右端。

## 四、MDP = 最大化对手：价值迭代（手推）

MDP 里每个状态先选动作再掷骰——"以多大概率"取决于**谁选动作**。验证的默认立场是悲观（[08 章](./08-TLA+与TLC.md)的"任意交错"传统）：**最大概率** = 存在好调度；**最小概率** = 最坏调度下也保证。于是方程变不动点：

$$p(s) = \max_{a} \sum_{t} P_a(s \to t)\, p(t)$$

lab10 的两动作例子（B 是废动作：0.9 自环 + 0.1 进死态，永远碰不到 target；A 即 §三的分布）：

```
E2 · MDP：max 概率 = 价值迭代（调度器 = 策略）
手推（10 章 §四）：动作 B 把概率漏进死态 ⇒ 任何混合都不优于恒选 A ⇒ max p0 = 0.6
  第 1 轮：p = (0.300000, 1, 0)
  第 2 轮：p = (0.450000, 1, 0)
  第 3 轮：p = (0.525000, 1, 0)
  第 4 轮：p = (0.562500, 1, 0)
  第 5 轮：p = (0.581250, 1, 0)
  收敛：p0 = 0.6000000000（vs 手推 0.6，|偏差| 5.5e-13）
```

迭代轨迹值得盯一眼：p₀ 每轮把与 0.6 的距离**精确减半**（0.3→0.15→0.075→…）——因为不动点方程恰是 p = 0.5p + 0.3 的压缩映射。两种等价算法：**价值迭代**（上面的不动点迭代）与**线性规划**（p 是满足约束组的最小解）——迭代是 LP 的对偶化身，小模型迭代快、大模型 LP 稳。调度器（scheduler）= 每状态选动作的函数 = 博弈论里的**策略**——MDP 检查本质是在解一个对自然（骰子）的单人博弈。

## 五、PRISM：语言与工具

PRISM（Birmingham，2001–）是概率模型检查的入门标准：**GUI + 模型语言 + 性质语言**三件套。lab10 例子的 PRISM 模型（`.pm`）逐行对照：

```
dtmc                                  // 或 mdp / ctmc
module M
  s : [0..2] init 0;                  // 状态变量
  [] s=0 -> 0.5 : (s'=0) + 0.3 : (s'=1) + 0.2 : (s'=2);
  [] s=1 -> true;                     // target（自吸收）
  [] s=2 -> true;                     // 死态
endmodule
label "target" = s=1;
// 性质：P=? [ F "target" ]  → 0.6；P>=0.6 [ F "target" ] → true
```

模型语言三要点：`module + 命令 [] 守卫 -> 概率: 更新`；多 module 并行组合（乘积语义，同步标签 `:act`）；奖励模块 `rewards ... endrewards` 标注开销。工具侧三件事：**实验（experiments）**——扫参数画出"失效率 vs 崩溃概率"曲线，是 PRISM 杀手锏；**显式 vs 符号**引擎（符号 = MTBDD，[12 章](./12-BDD与CUDD.md) 的主场，状态数从 10⁷ 起反转）；**置信模型检测**（参数区间→统计区间，模型不确定时的诚实答案）。

## 六、仪器

- **Python 保底**（本 lab）：`python experiments/lab10_prism_pctl.py`——线性方程组与价值迭代两路对拍 0.6，PCTL 边界语义现场（`P>=0.6` 真 / `P>0.6` 假）。
- **原生可选**：PRISM Windows 安装包（`prismmodelchecker.org`，自带 JDK 依赖说明）；把上面的 `.pm` 存盘后 `prism model.pm -prop 'P>=0.6 [F "target"]'` 应输出 true——与本 lab 的 0.6 对拍。装不通不阻塞，lab 已完整覆盖语义。
- 论域提醒：**模型参数从哪来**（失效率是测的还是拍的）是概率验证的第一现场问题——统计模型检查（SMC，对仿真轨迹做假设检验）是 PRISM 的另一半答案。

## 七、不足与边界

1. **参数即信仰**：P=0.6 精确，但输入的 0.3/0.2/0.5 若来自估计，输出就继承误差——置信模型检测与参数综合（"p 取什么值才能保证 ≤0.01"）是补丁，不是消除。
2. **状态数上量即换工具**：显式引擎 10⁶-10⁷ 封顶；更大上符号引擎（[12 章](./12-BDD与CUDD.md)）或专用高性能工具（[11 章](./11-Storm与高性能概率检查.md) Storm）——"P 格"只保证多项式，不保证常数小。
3. **无界概率≠有界概率**：F（最终）的方程组解的是无穷视界；"k 步内"的有界版本是矩阵幂，两者数值可差很远（骗过不少工程师）。
4. **非确定性的语义选择**：max 还是 min、公平性要不要假设——同一 MDP 不同立场答案不同，建模者必须显式表态。
5. **CTMC 的时变性质**（ CSL 的 S/F 稳态算子）是另一组方程（生成元的特征向量），本章未展开。

---

**锚点行**：DTMC 可达概率 = 线性方程组 (I−Q)p = r 的唯一解（手推 0.6 ✓ lab10 E1）；MDP = 对动作取 max 的不动点（价值迭代几何收敛，每轮减半 ✓ E2）；PCTL `P⋈p[F/G/U]` 把时序性质变成可比较的数；复杂度：**模型尺寸线性方程组 = P**（PCTL/CSL 模型检查对模型是多项式、对嵌套概率算子仍 P）——复杂度地图上最舒服的一格。【P】
