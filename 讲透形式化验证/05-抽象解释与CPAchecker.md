# 05 · 抽象解释与 CPAchecker：安全的近似

> 卷一第三站：04 章把无穷轨迹砍到 k 步（截断），本章换第二条出路——**过近似**（抽象解释，Cousot–Cousot，POPL 1977）：把无穷状态空间压进有穷抽象域，只在域上跑分析——域有穷，不动点就可判定地达到。合同写明代价：**可靠（漏报为零）但不完备（可能假报警）**。手推 lab05 的 4 行循环 `while (x<8) { x=x+3; y=y+x; }` 区间域三轮演化（[0,0]→[0,3]→[0,6]→第 3 轮加宽 [0,+∞]），亲眼看出口 y==18 证不出——假阳性现场；再看 **CEGAR**（反例→可满足性查询→Craig 插值→谓词精化）一轮闭环把 y 精确到 18、断言可证；走进工具室看 **CPAchecker** 的 CPA 可配置积木（域×迁移×合并×停止）与 SV-COMP 赛场格局。仪器：[`experiments/lab05_cegar_interval.py`](./experiments/lab05_cegar_interval.py)（手写区间域解释器，纯标准库）+ CPAchecker（zip+JDK，可选）。【不可判定→可靠近似】

## 一、Galois 连接一句话：可靠但可能报假警

**程序安全不可判定**（04 章 §一）的三条工程出路：截断（04 章 BMC）／过近似（本章）／人给不变式（[06 章](./06-Dafny验证语言.md) Dafny）。抽象解释选第二条：不碰无穷的具体状态空间，造一个**有穷抽象域** A，一对单调映射架桥——

- **α（抽象化）**：具体状态 → 抽象格子（"此刻 x=3" → "x∈[0,3]"）；
- **γ（具体化）**：抽象格子 → 它罩住的全部具体状态（"x∈[0,3]" → {0,1,2,3}）。

**Galois 连接一句话**：∀c∈C, a∈A：α(c) ⊑ a ⟺ c ⊑ γ(a)——"落进格子"与"被格子罩住"互为充要，α 问落点、γ 问罩面，二者咬合不越界。可靠性则住在交换图里（具体一步永远被抽象一步罩住）：

```
        F（具体一步：x = x+3）
   c ──────────────────► F(c)
   │                      │
 α │                      │ α        转移包含：α∘F ⊑ F#∘α
   ▼                      ▼          ——先具体走再抽象，必落在"先抽象再走"的格子里
   a ──────────────────► F#(a)
        F#（抽象一步：[0,3] + 3 = [3,6]）
```

于是**抽象域里证得的安全，具体程序必真**：真 bug 不可能漏（**漏报为零**）——这是抽象解释的立身之本。**不完备**则是格子的宿命：格子罩住的集合比真值集大（过近似），"断言在格子里可能不成立"≠"具体真不成立"——**假报警（假阳性）**，§二 就是现场。工业成名作：**Astrée**（Cousot 系，2003-2005 对空客电传飞控 ~13 万行 C 证明无运行时错误且零假警——域按飞控的数值形状定制，窄门里的奇迹）。

## 二、区间域手推：三轮演化、加宽与假阳性

lab05 的程序与断言（C 风格，lab 里用 Python 复刻）：

```c
int x = 0, y = 0;
while (x < 8) { x = x + 3; y = y + x; }
assert(y == 18);          // 具体成立：y 逐轮 3, 9, 18
```

具体执行一眼看穿：x 走 {0,3,6,9}，y 逐轮 3, 9, 18，出口 (x,y)=(9,18)——断言成立。区间域则每变量一个区间 [lo,hi]（lab 里上界 None 表示 +∞），两条算术规则就够：**区间加** [a,b]+[c,d]=[a+c,b+d]（任一端 +∞ 则上界 +∞）；**汇合 join**=[min,max]（循环头把"上一轮的我"与"这一轮的我"并起来——这正是对转移函数求不动点的 Kleene 迭代）。逐轮演化表（lab05 `interval_exec` 的 trail 原样）：

| 轮次 | x' = x+3 | y' = y+x' | join 后 x | join 后 y |
|---|---|---|---|---|
| 入口 | — | — | [0,0] | [0,0] |
| 1 | [3,3] | [0,0]+[3,3]=[3,3] | **[0,3]** | [0,3] |
| 2 | [3,6] | [0,3]+[3,6]=[3,9] | **[0,6]** | [0,9] |
| 3 | [3,9] | [0,9]+[3,9]=[3,18] | [0,9]→**加宽 [0,+∞]** | [0,18]→**加宽 [0,+∞]** |
| 4 | [3,+∞] | [3,+∞] | [0,+∞]（不变） | [0,+∞]（不变）＝**不动点** |

逐行算术（与表同源，第 3 轮的加宽判定看仔细）：

```
第1轮  x'=[0,0]+3=[3,3]   y'=[0,0]+[3,3]=[3,3]   join → x=[0,3], y=[0,3]
第2轮  x'=[0,3]+3=[3,6]   y'=[0,3]+[3,6]=[3,9]   join → x=[0,6], y=[0,9]
第3轮  x'=[0,6]+3=[3,9]   y'=[0,9]+[3,9]=[3,18]  join → x=[0,9], y=[0,18]
       上界仍在涨（9>6、18>9）→ 加宽：x=[0,+∞], y=[0,+∞]
第4轮  x'=[3,+∞]  y'=[3,+∞]  join → [0,+∞] 不再变 → 不动点，分析停
```

读表三件事。其一，**下界为何是 0 不是 3**：join 对下界取 min——入口的 0 与体算出的 3 并起来仍是 [0,3]（具体的 0 也站在循环头上；可靠，但不精确）。其二，**为何第 3 轮加宽**：朴素迭代的上界序列 3,6,9,12,…每轮 +3、永不封顶，对本章程序**根本到不了不动点**；即便友好的情形也要一步一阶地爬——步长 1、界 10 的计数器要 10 轮爬升 + 1 轮确认 = **11 轮**才收敛。**加宽**（widening，Cousot–Cousot 1977/1992）：发现上界仍在涨就直接冲 +∞——lab05 只爬 2 轮，第 3 轮冲顶、第 4 轮收敛。**11 轮的老实收敛，不如 2 轮后的当头加宽**，代价是精度。其三，**收窄**（narrowing）救不了本例：收窄是事后补救，用转移关系把"加宽过头的有限端点"压回来，但对 +∞ 无从下手；即便再给 x 套循环卫过滤（[0,+∞]∩(−∞,8)=[0,8]），y 的上界仍是 +∞——**y 与 x 的耦合（y=3+6+9）在区间域里根本没被表示**，这才是假阳性的根（§三 的插值恰好补这一刀）。

```
不加宽:  x 上界 3, 6, 9, 12, 15, … 每轮 +3 永远追不完 → 无不动点，分析不终止
加  宽:  第 3 轮直接 [0,+∞]，第 4 轮确认不变 → 4 轮收敛，代价 = 出口粗到证不出 y==18
```

出口断言 `y==18` 的验尸报告：区间域只交得出 **y∈[0,+∞]**——真值 18 确实被罩住（可靠），但 [0,+∞] 里的 0、100、10⁹ 也"可能"（过近似）→ 分析既不能确认断言、也拿不出违反反例，只能报**"可能违反"——假阳性**。lab05 实跑输出（原样贴回，§三 继续用）：

```
具体: 出口 (x,y)=(9,18)，y 逐轮 3,9,18
  区间第1轮: x∈[0,3], y∈[0,3]
  区间第2轮: x∈[0,6], y∈[0,9]
  区间第3轮: x∈[0,+∞], y∈[0,+∞]  ← 第3轮起加宽
  区间第4轮: x∈[0,+∞], y∈[0,+∞]
区间域: x∈[0,+∞], y∈[0,+∞] → 证不出 y==18（假阳性）
CEGAR 精化: x 轮换 [0, 3, 6, 9], y 精确 = 18 → y==18 可证 ✓
lab05 自检通过
```

## 三、CEGAR 闭环：反例→可满足性查询→Craig 插值→谓词精化

区间域报了假警，下一步不是拍脑袋换更富的域，而是**让报警自己指导精化**——CEGAR（Counterexample-Guided Abstraction Refinement，Clarke–Grumberg–Jha–Lu–Veith，CAV 2000；工业前传是微软 SLAM→Static Driver Verifier，Ball–Rajamani 2000）。闭环四步，拿 lab05 走完整一轮：

1. **抽象分析出报警**：区间域（§二）沿区间走到断言处，y∈[0,+∞] 不排除 y≠18 → 报"可能违反"，并交出一条**伪反例**（抽象域里的违规轨迹）。
2. **反例检查（可满足性查询）**：把伪反例的约束（初始 ∧ 转移 ∧ ¬断言）喂给 SMT（[03 章](./03-SMT求解与Z3cvc5.md) 的引擎）：存在具体执行使出口 y≠18 吗？本程序无输入、路径唯一，出口恒 y=18 → **UNSAT → 反例是假的（spurious）**——假报警实锤，该精化了。
3. **Craig 插值提炼谓词**：对 UNSAT 的公式对 (A,B)，插值（Craig 1957；McMillan CAV 2003 引入模型检查）给出 I：A⊨I、I∧B 不可满足、I 只谈 A/B 公共变量——**隔开"到得了的前缀"与"到不了的出口"的最短谓词**。本例 I 就是 **x mod 3 == 0**：x 只取 3 的倍数（lab05 用具体轨迹 {0,3,6,9} 提炼——插值器的机器版做同一件事）：

   ```
   A（可行前缀）  : x0=0 ∧ y0=0 ∧ x1=x0+3 ∧ y1=y0+x1 ∧ … ∧ x3=9 ∧ y3=18  （入口→断言）
   B（不可行续段）: 同一轨迹到达出口断言处 ∧ y ≠ 18
   A ∧ B 对具体语义 UNSAT（路径唯一，y 只能是 18）
   → 插值 I : x mod 3 == 0     （A ⊨ I：轨迹上 x 全是 3 的倍数；I ∧ B 不可满足）
   ```

4. **谓词精化再分析**：把 I 加进抽象域（谓词域：可行状态集 = 谓词的布尔组合），重跑不动点：x 在 {x≡0 (mod 3)} 里精确轮换 {0,3,6,9}——可行格子有穷，加宽不再冲 +∞；y 逐轮精确 3, 9, 18 → 出口 **y=18** → 断言可证，分析返回 **SAFE**。

§二 输出的最后两行正是第 4 步的现场：`x 轮换 [0,3,6,9]`、`y 精确 = 18`——区间域的假阳性被一轮 CEGAR 治愈。整个闭环的骨架（两个出口：SAFE 或真反例；一个循环：精化）：

```
while True:
    结果 = 不动点分析(抽象域)                # §二 的区间域跑完
    if 断言处无"可能违反": return SAFE        # 域里证全
    trace = 挑一条违规轨迹                    # 伪反例
    if SMT(初始 ∧ 转移 ∧ ¬断言, 沿 trace) == SAT:
        return 反例(trace)                   # 真 bug，带具体值
    I = Craig插值(前缀 A, 续段 B)            # 从 UNSAT 证明里提炼
    抽象域 += 谓词 I                         # 精化，回到循环头
```

三点注脚：谓词抽象（Graf–Saïdi 1997）是第 4 步的载体——每步转移就是一次 SMT 可满足性查询；**lazy abstraction**（BLAST，Henzinger 等 2002）让程序不同位置持有不同精度的谓词集，插值（McMillan 2003）负责自动提炼；CEGAR 与 04 章 BMC 共用"反例驱动"骨架——BMC 的反例是 k 步内的**真**反例（SAT 即违规），CEGAR 的反例是抽象域里的**伪**反例（先验真、再精化）。

## 四、CPAchecker：CPA 积木与 SV-COMP 赛场

**CPAchecker**（Beyer–Keremoglu，"CPAchecker: A Tool for Configurable Software Verification"，TACAS 2011；LMU München 的 sosy-lab）把"一个验证器"拆成一盒积木：**CPA（Configurable Program Analysis，可配置程序分析）= ⟨D（抽象域）, transfer（迁移关系）, merge（合并算子）, stop（停止算子）⟩ + precision（精度，接 §三 的精化钩子）**。四个零件对号入座 lab05：

| CPA 零件 | lab05 手写对应 | 换件效果 |
|---|---|---|
| D 抽象域 | 区间 (lo,hi)；精化后谓词 x∈{0,3,6,9} | 换谓词域即 §三 第 4 步 |
| transfer 迁移 | iv_add 顺序复合（x'=x+3; y'=y+x'） | 加循环卫过滤即 §二 的收窄讨论 |
| merge 合并 | iv_join；第 3 轮起换加宽版 | 停用加宽 = 朴素迭代永不收敛 |
| stop 停止 | (jx,jy)==(x,y)（trail 不再变） | 不动点即分析终点 |

分析的执行痕迹不是序列而是一棵**抽象可达图 ARG**（Abstract Reachability Graph）：从入口抽象状态出发，transfer 展开后继、merge 汇合兄弟、stop 在已见过的格子上剪枝——lab05 的 trail 是它退化的单链版（循环只有一个头）。merge 的两档正好暴露"积木"本义：`merge=sep`（兄弟不并、路径各自走——精确但状态多）与 `merge=join`（并成一个格——粗但收敛）；CPAchecker 的 `--valueAnalysis` 默认 join（区间天然宜并，§二 即此档），`--predicateAnalysis` 默认 sep（谓词合取易失精度，宁可多状态，§三 即此档）——lab05 的两段恰好各演示一种。配置文件 = 选积木连线：`--kInduction`（04 章 路线）……同一引擎，换件即换分析——这是它**一个工具打全部类别**的机制底座。

**SV-COMP 赛场格局**（International Competition on Software Verification，2012 年起 TACAS 附赛，[sv-comp.sosy-lab.org](https://sv-comp.sosy-lab.org/)）：CPAchecker 是常青树——多次年度总分第一/类别冠军，4.0 起默认按程序特征选策略，多数情形并行组合 k-induction、IMC、谓词分析、值分析的 portfolio 扫全类别；赛场生态里 CBMC/ESBMC（04 章）、Ultimate Automizer、SeaHorn、Symbiotic 各占生态位。赛场最有制度价值的发明是 **witness（证人）**：验证器须输出机读的违反/正确性证人（YAML/GraphML），交独立 witness 验证器复核才计分——把"验证剧场"（00 章）关进制度的笼子；CPAchecker 自带 `cpa-witness2test`，把违反证人编译成可执行复现的测试。

## 五、域的菜单：精度×开销的价目表

| 域 | 一句话 | 对本章程序 |
|---|---|---|
| 区间 | 每变量独立 [lo,hi]——增量 O(1)，快而糙 | 假阳性：y∈[0,+∞]（§二） |
| 谓词 | 可行集 = 谓词的布尔组合（x mod 3==0…）——精度高，每步付 SMT/插值 | y=18 可证（§三） |
| 符号区间 | 端点是符号表达式（x∈[0,3k]）——线性关系保留一截，区间与谓词的折中 | x 与 y 的耦合可留一半 |
| 堆形状 | 指针指向图（shape graph）——别名/可达性，链表树的内存安全专用 | 本章无堆，用不上 |

选域的元规则：**精度换开销**——从区间到符号区间到谓词，每升一档多付一个"求解器调用量级"；且**域要跟 bug 的形状匹配**——内存安全找堆形状、数值溢出找区间、控制流性质找谓词。实战还常拼盘（组合域）：区间管数值、谓词管控制流、堆形状管内存，各守一段——CPAchecker 把多个 CPA 组合成复合分析是常规操作；而谓词的布尔组合天然可上 BDD（[12 章](./12-BDD与CUDD.md) 的 ite/apply 正是布尔组合的引擎）——谓词域符号表示的另一条路线。

## 七、不足与边界

1. **加宽的精度损失近乎不可逆**：冲 +∞ 一步到位，收窄只压得回有限端点、对 +∞ 无从下手；实践中靠延迟加宽、限定加宽位置缓解，本章 y 的病根（变量关系丢失）只能靠更富的域（§五 菜单右移）。
2. **插值器差异**：插值不唯一——同一 UNSAT 对，MathSAT/SMTInterpol/Z3 各给不同的 I，路径插值与树插值又不一致，精化质量看运气；谓词一多，每步转移的 SMT 查询成为新瓶颈。
3. **CEGAR 不保证终止**：精化-再分析可能无限循环（域永远差一刀）；实现上靠精化轮数/谓词数上限截断，截断外的回答只能是 UNKNOWN——SAFE/反例之外的第三个出口。
4. **可靠≠证全**：抽象解释的 SAFE 只对"抽象域 + 规格"负责；规格外的行为（并发交错、环境假设）不在合同里——Astrée 的零假警是单线程顺序 C + 定制域的窄门奇迹。
5. **不可判定永远在门外**：三条出路各付各的税——BMC 付 k、抽象解释付假阳性、Dafny 付人年；本体归 [50 章](./50-复杂度动物园与选型.md) 动物园"界外"格，本章的格是"域有穷则不动点多项式可达，以假阳性为价"——不可判定问题的第二格。

**锚点行**：抽象解释（Cousot–Cousot 1977）= Galois 连接（α/γ）下的可靠过近似——手推 `while (x<8) { x+=3; y+=x; }` 区间三轮 [0,0]→[0,3]→[0,6]→第 3 轮加宽 [0,+∞]（第 4 轮不动点），出口 y==18 证不出 = 假阳性 ✓lab05；CEGAR（Clarke–Grumberg–Jha–Lu–Veith 2000）闭环：伪反例→SAT 查询 UNSAT→Craig 插值（Craig 1957/McMillan 2003）提炼 x mod 3==0→谓词精化 x∈{0,3,6,9}、y=18 可证 → SAFE；CPAchecker（Beyer–Keremoglu 2011）= CPA 积木（域×迁移×合并×停止 + precision）可配置 + SV-COMP 常青树与 witness 证人制度；复杂度：**域有穷则不动点多项式可达（可靠、漏报为零），代价是假阳性与 CEGAR 精化循环不保证终止——不可判定问题的第二格**。【不可判定→可靠近似】
