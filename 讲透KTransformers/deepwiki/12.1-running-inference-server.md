  This page provides complete examples for starting and configuring inference servers with KTransformers. It covers three main deployment methods: SGLang integration for production serving, balance_serve backend for multi-concurrency, and local_chat for quick testing.

 For fine-tuning workflows, see [LLaMA-Factory Integration](https://deepwiki.com/kvcache-ai/ktransformers/5.2-llama-factory-integration). For direct Python API usage without a server, see [Python API Usage](https://deepwiki.com/kvcache-ai/ktransformers/12.3-python-api-usage). For client-side API integration, see [OpenAI API Integration](https://deepwiki.com/kvcache-ai/ktransformers/12.4-openai-api-integration).

## Balance Serve Backend

 The `balance_serve` backend (introduced in v0.2.4) provides multi-concurrency support with continuous batching and chunked prefill [doc/en/balance-serve.md5-7](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L5-L7)

### Parameter Details

 
| Parameter | Description | Source |
|---|---|---|
| --max_new_tokens | Maximum number of tokens generated per request. | doc/en/balance-serve.md129 |
| --cache_lens | Total length of kvcache allocated by the scheduler. | doc/en/balance-serve.md130 |
| --max_batch_size | Max requests (prefill + decode) processed in a single run. | doc/en/balance-serve.md131 |
| --chunk_size | Maximum number of tokens processed in a single run. | doc/en/balance-serve.md132 |
| --backend_type | Set to balance_serve for multi-concurrency. | doc/en/balance-serve.md134 |
| --force_think | Force responding with reasoning tags for DeepSeek-R1. | doc/en/balance-serve.md137 |
