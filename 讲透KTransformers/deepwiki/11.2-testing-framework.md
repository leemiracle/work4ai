  The KTransformers testing framework provides a structured system for validating the correctness and performance of CPU-optimized inference kernels. The framework supports multiple hardware backends (CPU, CUDA, AMD), automated CI/CD integration, and systematic benchmarking of AMX/AVX operations.

 For information about the C++ extension development process, see [C++ Extension Development](https://deepwiki.com/kvcache-ai/ktransformers/11.1-c++-extension-development). For CI/CD pipeline details, see [CI/CD Pipeline](https://deepwiki.com/kvcache-ai/ktransformers/11.3-cicd-pipeline).

## Test Types and Structure

 
### Benchmark Tests

 Benchmark tests measure performance metrics (bandwidth and FLOPS) of AMX/AVX kernel implementations.

 
```

```

 **Benchmark Test Structure**

 Each benchmark test follows this pattern:

 
 - **Configuration** ([kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py37-55](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py#L37-L55)):

 
 - Test parameters (expert_num, hidden_size, intermediate_size, qlen)
 - Worker configuration (subpool_count, NUMA mapping, thread count)
 - **CPUInfer Initialization** ([kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py152-158](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py#L152-L158)):

 
 - Create `kt_kernel_ext.WorkerPoolConfig` with NUMA-aware settings
 - Initialize `kt_kernel_ext.CPUInfer` thread pool
 - **MOE Layer Setup** ([kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py163-198](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py#L163-L198)):

 
 - Create random weight tensors (gate_proj, up_proj, down_proj)
 - Configure `kt_kernel_ext.moe.MOEConfig` with quantization settings
 - Initialize specific MOE variant (e.g., `kt_kernel_ext.moe.AMXInt4_1KGroup_MOE`)
 - Load weights via `load_weights_task()`
 - **Warm-up Phase** ([kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py219-233](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py#L219-L233)):

 
 - Execute 1000 iterations to stabilize CPU caches and branch predictors
 - **Measurement Phase** ([kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py235-251](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py#L235-L251)):

 
 - Execute 2000 timed iterations using `time.perf_counter()`
 - **Metrics Calculation** ([kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py254-269](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py#L254-L269)):

 
 - Bandwidth: `(hidden_size * intermediate_size * 3 * num_experts_per_tok * cache_factor * bytes_per_elem * iterations) / time / 1e9` GB/s
 - FLOPS: `(hidden_size * intermediate_size * qlen * 3 * num_experts_per_tok * 2 * iterations) / time / 1e12` TFLOPS
 - **Results Recording** ([kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py278-305](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_bench_int4_1k.py#L278-L305)):

 
 - Append JSONL entry with metrics, test parameters, git commit, system info
 
 **Quantization Variants**

 
| Variant | Bytes/Element | Class Name | Accuracy Threshold |
|---|---|---|---|
| INT8 | 1.0 | kt_kernel_ext.moe.AMXInt8_MOE | < 0.05 |
| INT4 | 0.5 | kt_kernel_ext.moe.AMXInt4_MOE | < 0.35 |
| INT4_1 | 0.5 | kt_kernel_ext.moe.AMXInt4_1_MOE | < 0.35 |
| INT4_1K | 0.5 | kt_kernel_ext.moe.AMXInt4_1KGroup_MOE | < 0.35 |

 **MLP Reference** ([kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py47-53](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py#L47-L53)):

 **MoE Reference** ([kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py56-88](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py#L56-L88)): The `moe_torch()` function implements:

 
 - Token-to-expert assignment via scatter operation.
 - Expert workload calculation (`tokens_per_expert`).
 - Token sorting by expert ID.
 - Per-expert MLP computation.
 - Output reordering and weighted aggregation.
 
 **Accuracy Validation Flow**

 
 - **Generate Random Test Data** ([kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py147-155](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py#L147-L155)):

 
 - Expert IDs: Random permutations per token.
 - Weights: Random float32 values.
 - Input: Random bfloat16 tensors scaled by 1/100.
 - **Execute Optimized Kernel** ([kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py157-169](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py#L157-L169)):

 
 - Submit `forward_task()` to `kt_kernel_ext.CPUInfer`.
 - Synchronize to wait for completion.
 - **Execute Reference Implementation** ([kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py172](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py#L172-L172)):

 
 - Call `moe_torch()` with same inputs.
 - **Calculate Relative Difference** ([kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py175](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py#L175-L175)):

 
 - `diff = torch.mean(torch.abs(output - t_output)) / torch.mean(torch.abs(t_output))`
 - **Assert Threshold** ([kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py179](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/test/per_commit/test_moe_amx_accuracy_int8.py#L179-L179)):

 
 - INT8: `diff < 0.05` (5% relative error).
 - INT4/INT4_1/INT4_1K: `diff < 0.35` (35% relative error).
