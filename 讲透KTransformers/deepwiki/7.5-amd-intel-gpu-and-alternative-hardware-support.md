  KTransformers extends its CPU-GPU heterogeneous inference capabilities beyond NVIDIA hardware to include AMD ROCm GPUs, Intel XPU/Arc GPUs, AMD EPYC CPU-specific accelerations, and experimental support for Huawei Ascend NPUs. This support is achieved through specialized kernel backends, optimized BLAS libraries, and hardware-specific modeling wrappers.

 
## Intel GPU Support (XPU/Arc)

 KTransformers provides beta support for Intel GPUs, including Intel Arc (A770, B580) and Data Center Max Series GPUs, leveraging the `XPU` backend via PyTorch and IPEX-LLM [doc/en/xpu.md1-6](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L1-L6)

 
### Software Requirements

 
 - **Driver**: Intel Level Zero GPU driver (verified version: `1.3.29735.27-914~22.04`) [doc/en/xpu.md105-113](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L105-L113)
 - **Libraries**: `ipex-llm[xpu_2.6]` and `torch==2.7+xpu` [doc/en/xpu.md50-52](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L50-L52)
 - **Environment**: Requires `SYCL_CACHE_PERSISTENT=1` and `ONEAPI_DEVICE_SELECTOR=level_zero:0` for optimal runtime performance [doc/en/xpu.md74-75](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L74-L75)
 
 
### Configuration and Optimization

 For constrained VRAM scenarios (e.g., 16GB GPUs), KTransformers uses specialized optimization rules:

 
 - **Optimization Rule**: `ktransformers/optimize/optimize_rules/xpu/DeepSeek-V3-Chat.yaml` [doc/en/xpu.md81](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L81-L81)
 - **Hardware Tuning**: Performance is maximized by setting the CPU to `performance` mode and locking GPU frequency using `xpu-smi` [doc/en/xpu.md93-100](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L93-L100)
 - **BIOS**: **Resizable BAR** must be enabled to avoid bus errors and ensure optimal data transfer [doc/en/xpu.md23-24](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L23-L24)

## AMD ROCm GPU Support

 KTransformers provides beta support for AMD GPUs using the ROCm (Radeon Open Compute) platform, allowing hardware like the Radeon 7900 XTX to participate in expert offloading [doc/en/ROCm.md1-6](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/ROCm.md?plain=1#L1-L6)

 
### Implementation Details

 The ROCm implementation utilizes `torch` with ROCm backends.

 
 - **Marlin Kernels**: Currently, Marlin kernels are not supported on ROCm due to their NVIDIA-specific PTX/CUDA architecture [doc/en/ROCm.md94-95](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/ROCm.md?plain=1#L94-L95)
 - **VRAM Optimization**: Specific rules for 24GB AMD GPUs are provided in `ktransformers/optimize/optimize_rules/rocm/DeepSeek-V3-Chat.yaml` [doc/en/ROCm.md62-69](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/ROCm.md?plain=1#L62-L69)
 - **Linear Operators**: `KLinearTorch` is preferred over `KLinearMarlin` for stability on the ROCm path [doc/en/ROCm.md73-82](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/ROCm.md?plain=1#L73-L82)
 
 **Sources:** [doc/en/ROCm.md1-97](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/ROCm.md?plain=1#L1-L97)

## AMD CPU Optimization: BLIS and AOCL

 For AMD EPYC processors, KTransformers integrates the **AMD Optimizing CPU Libraries (AOCL)** and **BLIS** to accelerate the prefill phase.

 
### LPGEMM Acceleration

 The primary optimization for AMD CPUs is **LPGEMM** (Low Precision GEMM) via AOCL-BLAS [doc/en/kt-kernel/amd_blis.md8-9](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/amd_blis.md?plain=1#L8-L9) This targets `MOE_INT8` methods (`--kt-method MOE_INT8`) to significantly improve prefill throughput on EPYC hardware [doc/en/kt-kernel/amd_blis.md3-8](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/amd_blis.md?plain=1#L3-L8)

 
### Build and Usage

 
 - **Environment Variable**: `export CPUINFER_ENABLE_BLIS=ON` must be set before installation [doc/en/kt-kernel/amd_blis.md5](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/amd_blis.md?plain=1#L5-L5)
 - **Tested Hardware**: AMD EPYC 9355 (32-Core) with PCIe 5.0 support, which provides high-bandwidth access for expert offloading [doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md37-38](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md?plain=1#L37-L38) [doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md168-169](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md?plain=1#L168-L169)
 
 **Sources:** [doc/en/kt-kernel/amd_blis.md1-20](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/amd_blis.md?plain=1#L1-L20) [doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md34-40](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md?plain=1#L34-L40)

## Ascend NPU Experimental Support

 KTransformers supports Huawei Ascend NPUs (specifically **Atlas 300I A2**) on Kunpeng-based servers for full-scale DeepSeek-V3/R1 deployment [doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md10-14](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md?plain=1#L10-L14)

 
### Core Features

 
 - **Graph Sinking**: Enabled via `TASK_QUEUE_ENABLE=0` and `--use_cuda_graph`, this allows the NPU to execute a sequence of operations with minimal CPU intervention [doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md113-117](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md?plain=1#L113-L117) [doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md165-167](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md?plain=1#L165-L167)
 - **Mixed Precision**: Supports a hybrid of Q4 and W8A8 weights, merged using `merge_safetensor_gguf.py` [doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md105-108](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md?plain=1#L105-L108)
 - **ARM Optimization**: For Kunpeng CPUs, the `llamafile` backend is adjusted by modifying `iqk_mul_mat_arm82.cpp` to optimize ARM-specific matrix multiplication [doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md130-134](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/zh/DeepseekR1_V3_tutorial_zh_for_Ascend_NPU.md?plain=1#L130-L134)
 
 
### Specialized NPU Operators

 The framework utilizes custom operators that interface directly with `torch_npu`:

 
 - **RMSNorm**: `KDeepseekV3RMSNormW8A8` and `KQwen3MoeRMSNormW8A8` use `torch_npu.npu_rms_norm` [archive/ktransformers/operators/ascend/ascend_layernorm.py32-49](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/archive/ktransformers/operators/ascend/ascend_layernorm.py#L32-L49) [archive/ktransformers/operators/ascend/ascend_layernorm.py61-87](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/archive/ktransformers/operators/ascend/ascend_layernorm.py#L61-L87)
 - **Linear/MLP**: `KDeepseekV3MLPW8A8A2V1` uses `torch_npu.npu_dynamic_quant` and `torch_npu.npu_quant_matmul` for quantized inference on NPU [archive/ktransformers/operators/ascend/ascend_mlp.py26-40](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/archive/ktransformers/operators/ascend/ascend_mlp.py#L26-L40)

## Hardware Comparison and Performance

 KTransformers' heterogeneous approach allows different hardware combinations to achieve competitive performance by balancing the MoE expert load.

 
| Hardware | Model | Precision | Prefill (t/s) | Decode (t/s) |
|---|---|---|---|---|
| 2x RTX 5090 + EPYC 9355 | MiniMax-M2.1 | FP8 | 1847 (8K) | 35.5 |
| 2x RTX 4090 + Xeon 8488C | Kimi-K2-Thinking | RAWINT4 | 294 (8K) | - |
| Atlas 300I A2 + Kunpeng 920 | DeepSeek-V3 | W8A8/Q4 | 169.5 (2K) | 16.12 |
| Intel Arc A770 + i9-13900K | DeepSeek-R1 | GGUF/XPU | - | - |

 *Note: Performance on Intel XPU is currently in beta with focus on local chat functionality; serving is not yet supported [doc/en/xpu.md87-88](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/xpu.md?plain=1#L87-L88)*
