## Purpose and Scope

 This document describes the MoE (Mixture of Experts) operator system in `kt-kernel`, which provides CPU-optimized MoE inference with multiple quantization backends. The system implements a factory pattern for backend selection, abstract base classes for shared functionality, and specialized implementations for different quantization methods including AMX INT4/INT8, RAWINT4, FP8, BF16, and GGUF.

 For Python API usage examples, see [Python API Reference](https://deepwiki.com/kvcache-ai/ktransformers/4.4-python-api-reference). For integration with SGLang serving, see [SGLang Integration](https://deepwiki.com/kvcache-ai/ktransformers/4.3-sglang-integration). For CPU acceleration details, see [Intel AMX Optimization](https://deepwiki.com/kvcache-ai/ktransformers/7.1-intel-amx-optimization) and [AMX Kernel Implementation](https://deepwiki.com/kvcache-ai/ktransformers/7.2-amx-kernel-implementation).

 
## Architecture Overview

 The MoE operator system uses a three-layer architecture: a Python factory interface (`KTMoEWrapper`), Python backend implementations inheriting from `BaseMoEWrapper`, and C++ kernel implementations connected via `pybind11` in `ext_bindings.cpp`.

## Backend Implementations

 
### AMXMoEWrapper

 Implements AMX-accelerated INT4/INT8 quantization. It relies on the `SafeTensorLoader` to handle weights that are typically sharded by NUMA node for optimal CPU performance.

 **Weight Loading**: It supports loading from pre-quantized Safetensors or online quantization from high-precision tensors.

 
 - `load_weights()`: Loads `.safetensors` using `SafeTensorLoader` [kt-kernel/python/utils/amx.py255-300](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L255-L300)
 - `load_weights_from_tensors()`: Performs online quantization and stores results in the C++ backend [kt-kernel/python/utils/amx.py213-253](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L213-L253)
 
 Sources: [kt-kernel/python/utils/amx.py139-320](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L139-L320)

 
### LlamafileMoEWrapper

 Integrates the llamafile backend to support GGUF formats. It enforces specific alignment requirements for Tensor Parallelism (TP).

 **TP Alignment**: Llamafile requires that the intermediate size be divisible by `QK_K` (256) to ensure blocks are not split across threads/NUMA nodes.
