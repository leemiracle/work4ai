## Overview

 The AMX kernel implementation provides high-performance matrix multiplication for MoE layers using Intel Advanced Matrix Extensions (AMX). The system dispatches to optimized GEMM implementations based on input shape, quantization format, and hardware capabilities.

 **Core Components:**

 
 - **GEMM Kernels**: Template-based kernels using `_tile_dpb*` intrinsics for BF16, INT8, INT4, and FP8 quantization.
 - **Dispatch Logic**: Runtime selection between `mat_mul` (batch) and `vec_mul` (single-row) variants based on `qlen`.
 - **Buffer Management**: Memory layout transformations for optimal tile register access patterns.
 - **Quantization Support**: K2 (INT4), AWQ (INT4+zero-point), FP8 (block-wise), and Native BF16 variants.
 - **MoE Operators**: `AMX_K2_MOE_TP`, `AMX_AWQ_MOE_TP`, `AMX_FP8_MOE_TP`, and `AMX_BF16_MOE_TP`.

### Layout Transformations

 Buffers use a blocked physical layout to match AMX tile access patterns. For example, `BufferABF16Impl` uses a 5D layout: `a[k_blocks][m_blocks][k_steps][M_STEP][K_STEP]` [kt-kernel/operators/amx/la/amx_raw_buffers.hpp39-48](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/la/amx_raw_buffers.hpp#L39-L48)

 Weights in `BufferBBF16Impl` are transposed into a VNNI-compatible layout: `b[n_blocks][k_blocks][n_steps][k_steps][N_STEP][K_STEP]` with internal 16x16 transposes using `transpose_16x16_32bit` [kt-kernel/operators/amx/la/amx_raw_buffers.hpp102-114](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/la/amx_raw_buffers.hpp#L102-L114)

## Specific Operator Variants

 
### K2 INT4 MoE (`AMX_K2_MOE_TP`)

 Implemented for Kimi-K2, using `GemmKernel224Int4SmallKGroup`. It supports symmetric INT4 quantization with group-wise scales.

 
 - **Weight Loading**: Loads packed INT4 from `config_.gate_proj` and scales from `config_.gate_scale` using `from_raw_mat` [kt-kernel/operators/amx/k2-moe.hpp133-166](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/k2-moe.hpp#L133-L166)
 - **GEMM**: Dispatches to `amx::mat_mul_kgroup` or `amx::vec_mul_kgroup` based on `qlen` threshold [kt-kernel/operators/amx/k2-moe.hpp86-112](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/k2-moe.hpp#L86-L112)
 
 
### BF16 MoE (`AMX_BF16_MOE_TP`)

 Native BF16 inference without quantization, using `GemmKernel224BF16`.

 
 - **Buffer**: Uses `BufferABF16Impl` and `BufferBBF16Impl` which handle native `ggml_bf16_t` [kt-kernel/operators/amx/bf16-moe.hpp66-84](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/bf16-moe.hpp#L66-L84)
 - **Kernel**: Uses `_tile_dpbf16ps` for accumulation into FP32 tiles [kt-kernel/operators/amx/la/amx_raw_kernels.hpp113-120](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/la/amx_raw_kernels.hpp#L113-L120)

## Performance Tuning

 
### Dynamic Scheduling

 The MoE operators use a `WorkerPool` to parallelize expert computations. Work is distributed as "work-stealing jobs" across available CPU cores, often partitioned by NUMA node [kt-kernel/operators/amx/k2-moe.hpp135-151](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/k2-moe.hpp#L135-L151) [kt-kernel/operators/amx/moe_base.hpp147](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/moe_base.hpp#L147-L147)

 
### Cache-Friendly Design

 Kernels are designed with multi-level blocking (M, N, K) to maximize cache hits. For instance, `GemmKernel224Int8` uses `N_BLOCK=64` and `K_BLOCK=3584` to fit working sets within CPU caches [kt-kernel/operators/amx/la/amx_kernels.hpp823-824](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/la/amx_kernels.hpp#L823-L824)

 
### Tile-Aware Layout

 The `BufferB` implementations ensure that weights are pre-packed and transposed into the exact layout expected by AMX tile registers. For BF16, this involves a VNNI layout transformation [kt-kernel/operators/amx/la/amx_raw_buffers.hpp102-114](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/la/amx_raw_buffers.hpp#L102-L114)
