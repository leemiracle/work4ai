  Kimi-K2.5 is a large Mixture-of-Experts (MoE) model from Moonshot AI that supports CPU-GPU heterogeneous inference through the KTransformers framework. The model features native RAWINT4 quantized weights for both CPU and GPU execution and supports LoRA fine-tuning via the `kt-sft` backend.

 
---

 
## Overview

 **Key Features:**

 
 - **Native RAWINT4 Support:** Optimized for both CPU and GPU without additional quantization steps [doc/en/Kimi-K2.5.md61-64](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/Kimi-K2.5.md?plain=1#L61-L64)
 - **Heterogeneous Inference:** Efficiently offloads MoE experts to CPU while keeping attention and hot experts on GPU [doc/en/Kimi-K2.5.md3](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/Kimi-K2.5.md?plain=1#L3-L3)
 - **SGLang Integration:** Uses a custom fork (`sglang-kt`) for high-throughput production serving [doc/en/Kimi-K2.5.md35-43](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/Kimi-K2.5.md?plain=1#L35-L43)
 - **LoRA SFT:** Supports Supervised Fine-Tuning using LlamaFactory with KTransformers as the backend [doc/en/SFT_Installation_Guide_KimiK2.5.md1-3](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/SFT_Installation_Guide_KimiK2.5.md?plain=1#L1-L3)

## Hardware Requirements

 
### Inference Configuration

 
| Component | Minimum Specification |
|---|---|
| GPU | 2× RTX 4090 (48GB total VRAM) doc/en/Kimi-K2.5.md16 |
| CPU | x86 with AVX512F support (e.g., Intel Sapphire Rapids) doc/en/Kimi-K2.5.md17 |
| RAM | At least 600GB system memory doc/en/Kimi-K2.5.md18 |
| Storage | ~600GB for native RAWINT4 weights doc/en/Kimi-K2.5.md19 |

 
### Fine-Tuning Configuration (LoRA SFT)

 
| Component | Minimum Specification |
|---|---|
| GPU | 4× RTX 4090 (96GB total VRAM) doc/en/SFT_Installation_Guide_KimiK2.5.md27 |
| CPU | x86 with AMX support doc/en/SFT_Installation_Guide_KimiK2.5.md28 |
| RAM | At least 2TB system memory (swap allowed) doc/en/SFT_Installation_Guide_KimiK2.5.md29-30 |
| Storage | ~1.2TB (BF16 weights + checkpoints) |
