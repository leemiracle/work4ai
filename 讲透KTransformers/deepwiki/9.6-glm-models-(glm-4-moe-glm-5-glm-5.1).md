  This guide covers the deployment and optimization of the GLM (General Language Model) family within the KTransformers framework. KTransformers provides specialized support for GLM-4-MoE (including GLM-4.5-Air and SmallThinker) and the latest GLM-5/5.1 series using CPU-GPU heterogeneous inference. Key features include AMX-optimized INT8 kernels for GLM-4.5, native FP8/BF16 support for GLM-5, and advanced "Thinking Mode" configurations for GLM-5.1.

 
## Supported Models and Precision

 KTransformers supports multiple variants of the GLM family with optimized backends for different hardware capabilities.

 
| Model | Parameters | Supported Precisions | Key Features |
|---|---|---|---|
| SmallThinker-21B | 21B (MoE) | BF16 | High-speed reasoning on consumer GPUs doc/en/SmallThinker_and_Glm4moe.md8 |
| GLM-4.5-Air | 110B (MoE) | BF16, AMX INT8 | 128 experts, AMX acceleration doc/en/SmallThinker_and_Glm4moe.md9-10 |
| GLM-5 | Large MoE | BF16, FP8 | Dynamic expert update, uniform placement doc/en/kt-kernel/GLM-5-Tutorial.md3 |
| GLM-5.1 | Large MoE | BF16, FP8 | Thinking Mode, MTP (Multi-Token Prediction) doc/en/kt-kernel/GLM-5.1-Tutorial.md5 |

## Thinking Mode (GLM-5.1)

 GLM-5.1 introduces a native "Thinking Mode" which is enabled by default in KTransformers. It supports two primary reasoning behaviors configured via `chat_template_kwargs` in the API request [doc/en/kt-kernel/GLM-5.1-Tutorial.md181-187](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/GLM-5.1-Tutorial.md?plain=1#L181-L187)

 
 - **Interleaved Thinking:** Standard reasoning interleaved with output.
 - **Interleaved + Preserved Thinking:** Recommended for code agents and complex multi-turn workflows [doc/en/kt-kernel/GLM-5.1-Tutorial.md186-187](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/GLM-5.1-Tutorial.md?plain=1#L186-L187)

## Technical Implementation Details

 
### Weight Loading and Mapping

 The GLM models use a specific expert mapping strategy. In GLM-5/5.1, the `--kt-expert-placement-strategy uniform` ensures experts are distributed evenly across available hardware to prevent NUMA bottlenecks [doc/en/kt-kernel/GLM-5-Tutorial.md88](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/GLM-5-Tutorial.md?plain=1#L88-L88) GLM-5.1 also includes support for MTP (Multi-Token Prediction) weights [doc/en/kt-kernel/GLM-5.1-Tutorial.md59](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/GLM-5.1-Tutorial.md?plain=1#L59-L59)

| Parameter | Description | Recommended Value |
|---|---|---|
| --kt-cpuinfer | Number of CPU threads for MoE computation | Physical Cores - 8 doc/en/Kimi-K2-Thinking.md38 |
