  KTransformers provides experimental support for Meta LLaMA 4 models, specifically the Scout and Maverick architectures. This support leverages the `balance_serve` backend introduced in v0.2.4 to handle multi-concurrency and heterogeneous expert placement for these large-scale Mixture-of-Experts (MoE) models [doc/en/llama4.md1-5](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L1-L5)

 
## Overview and Scope

 LLaMA 4 support is currently handled in a dedicated development branch (`support-llama4`) to manage dependencies on newer versions of the `transformers` library (>= 4.51.0) and to maintain stability for existing models on the main branch [doc/en/llama4.md5-9](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L5-L9) The implementation focuses on the `balance_serve` backend, which provides high-performance asynchronous concurrent scheduling in C++, continuous batching, and chunked prefill [doc/en/balance-serve.md5-7](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L5-L7)

 
### Supported Models

 
| Model | Architecture | Experts | RAM Requirement | VRAM Requirement |
|---|---|---|---|---|
| LLaMA 4 Scout | MoE | 16 Experts | ~65 GB | ~10 GB |
| LLaMA 4 Maverick | MoE | 128 Experts | ~270 GB | ~12 GB |

 *Sources: [doc/en/llama4.md28-30](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L28-L30)*

## Implementation Details

 
### Custom Configuration

 LLaMA 4 models require specific `config.json` modifications to be compatible with the KTransformers injection system. Users must replace the standard `config.json` in their `--model_path` with specialized versions provided in the `support-llama4` branch:

 
 - **Scout**: `doc/en/scout_config.json` [doc/en/llama4.md78](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L78-L78)
 - **Maverick**: `doc/en/maverick_config.json` [doc/en/llama4.md79](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L79-L79)
 
 
### Injection Rules

 The experimental support relies on YAML-based optimization rules to replace standard LLaMA layers with KTransformers' optimized kernels. For LLaMA 4, the primary rule file is `Llama4-serve.yaml` [doc/en/llama4.md95](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L95-L95)

## Execution and Deployment

 To deploy LLaMA 4, the `balance_serve` backend must be explicitly selected. This backend supports `max_batch_size` for concurrent processing and `cache_lens` for global KV cache management [doc/en/balance-serve.md127-134](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L127-L134)

 
### Deployment Commands

 The following parameters are essential for LLaMA 4 experimental inference:

 
| Parameter | Description | Recommended Value |
|---|---|---|
| --backend_type | Selection of the multi-concurrency engine | balance_serve |
| --optimize_config_path | Path to LLaMA 4 specific injection rules | ktransformers/optimize/optimize_rules/Llama4-serve.yaml |
| --cache_lens | Total KV cache tokens allocated (shared across requests) | 32768 |
| --chunk_size | Max tokens processed in a single engine run | 256 |
| --max_batch_size | Maximum concurrent requests in one engine run | 4 |

 *Sources: [doc/en/llama4.md91-101](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L91-L101) [doc/en/balance-serve.md127-134](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L127-L134)*

 
### Limitations

 
 - **Backend Restriction**: Only the `balance_serve` backend is supported for LLaMA 4; the legacy `ktransformers` single-concurrency engine is not compatible [doc/en/llama4.md124](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L124-L124)
 - **Dependency**: Requires `transformers==4.51.0` or newer, which may conflict with environments tuned for older models [doc/en/llama4.md125](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L125-L125)
 - **Modality**: Only text-based MoE models are supported; multimodal LLaMA 4 variants are currently excluded [doc/en/llama4.md126](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/llama4.md?plain=1#L126-L126)
