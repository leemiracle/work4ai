## Purpose and Scope

 This page provides technical documentation for deploying the Qwen model family using KTransformers. It covers high-performance inference for **Qwen3MoE** using Intel AMX optimizations, the linear-attention based **Qwen3-Next-80B-A3B**, the massive **Qwen3.5-MoE-400B**, and the code-specialized **Qwen3-Coder-Next**. These models leverage CPU-GPU heterogeneous computing via the `kt-kernel` and `sglang-kt` integration to offload MoE experts to system RAM while maintaining high prefill speeds through native precision (BF16/FP8) or AMX-optimized kernels.

## Qwen3MoE Models

 
### Overview

 Qwen3MoE models are optimized for different hardware tiers, utilizing AMX instruction sets for significant prefill acceleration on compatible Intel CPUs.

 
| Model Configuration | Parameters | Activated Parameters | Target Hardware |

### AMX Kernel Implementation

 The AMX backend provides a specialized memory layout and compute kernel for Intel Sapphire Rapids and newer CPUs.

 
 - **Tiling-Aware Layout:** Expert weights are rearranged into 16×64 tile sub-matrices during load time to match AMX register dimensions.
 - **Symmetric Quantization:** Supports INT8 per-column group quantization.
 - **Dynamic Scheduling:** Uses fine-grained task splitting and work stealing to balance expert computation across CPU threads.
 
 **Performance:** Reaches 347 tokens/s prefill on Xeon 4th Gen, roughly 4× faster than standard PyTorch AMX kernels.

 **Sources:** [doc/en/AMX.md12-19](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L12-L19) [doc/en/AMX.md75-127](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L75-L127)

## Qwen3-Next-80B-A3B

 
### Overview

 Qwen3-Next-80B-A3B-Thinking and Instruct models utilize linear attention mechanisms. KTransformers supports these models via the `balance_serve` backend.

 
### Deployment Requirements

 
 - **Memory:** Approximately 320 GB System RAM.
 - **VRAM:** Approximately 6 GB GPU memory.
 - **Optimization:** CUDA Graph is currently disabled for this architecture due to linear attention constraints [doc/en/Qwen3-Next.md69-71](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/Qwen3-Next.md?plain=1#L69-L71)

## Qwen3.5-MoE-400B

 
### Deployment via SGLang + KT-Kernel

 Qwen3.5 (400B) is deployed using the `sglang-kt` integration for efficient heterogeneous inference.

 
### Hardware Requirements

 
 - **GPU:** 4x NVIDIA RTX 4090 (96GB total VRAM).
 - **CPU:** x86 with AVX512F support (e.g., Intel Sapphire Rapids).
 - **RAM:** At least 800GB system memory.
 - **Storage:** ~800GB for model weights (BF16).
 
 
### Serving Configuration

 The model is served in BF16 precision, offloading experts to CPU while keeping minimal experts on GPU to manage VRAM pressure.

## Qwen3-Coder-Next (80B-A3B)

 
### Overview

 A code-generation Mixture-of-Experts model. It supports both **FP8** and **BF16** native precision via `kt-kernel` [doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md3-4](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md?plain=1#L3-L4)

 
### Key Features

 
 - **Dynamic Expert Update:** Enabled via `--kt-enable-dynamic-expert-update` to swap experts between CPU and GPU based on routing statistics [doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md106-131](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md?plain=1#L106-L131)

## Troubleshooting

 
### OOM (Out of Memory)

 Layerwise prefill requires additional VRAM. If OOM occurs:

 
 - Reduce `--kt-num-gpu-experts` [doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md143](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md?plain=1#L143-L143)
 - Decrease `--chunked-prefill-size` [doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md147](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md?plain=1#L147-L147)
 - Adjust `--mem-fraction-static` to leave more room for KV cache [doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md95](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md?plain=1#L95-L95)
 
 
### Performance Tuning

 
 - **`--kt-cpuinfer`**: Recommended to be set to the number of physical cores or high-performance threads (e.g., 60 or 96) [doc/en/Qwen3.5.md84](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/Qwen3.5.md?plain=1#L84-L84) [doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md88](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md?plain=1#L88-L88)
 - **`--kt-threadpool-count`**: Should match the number of NUMA nodes on the system (typically 2 for dual-socket Xeon/EPYC) [doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md142](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/Qwen3-Coder-Next-Tutorial.md?plain=1#L142-L142)
