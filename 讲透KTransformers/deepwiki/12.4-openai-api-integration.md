  This document describes how to use KTransformers' OpenAI-compatible API endpoint for chat completions and streaming responses. Once a KTransformers server is running (via `balance_serve` backend or SGLang integration), you can interact with it using any OpenAI-compatible client library or HTTP requests.

 For information about starting the inference server itself, see [Running Inference Server](https://deepwiki.com/kvcache-ai/ktransformers/12.1-running-inference-server). For details on the underlying serving architecture, see [balance_serve Multi-Concurrency](https://deepwiki.com/kvcache-ai/ktransformers/6.1-balance_serve-multi-concurrency).

## API Overview

 KTransformers exposes an HTTP API compatible with the OpenAI Chat Completions API at `/v1/chat/completions`. This allows seamless integration with existing tools, SDKs, and workflows that support OpenAI's API format.

 **Key Features:**

 
 - Full OpenAI Chat Completions API compatibility.
 - Streaming and non-streaming responses.
 - Support for temperature, top_p, and other sampling parameters.
 - Multi-turn conversation support.
 - Special features for thinking models (DeepSeek-R1, Kimi-K2-Thinking).
 
 **Supported Backends:**

 
 - `balance_serve` (multi-concurrency, v0.2.4+): Implements a three-layer architecture (Server, Scheduler, Inference Engine) [doc/en/balance-serve.md21-25](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L21-L25)
 - SGLang with KTransformers integration: Provides production serving with optimized MLA kernels [doc/en/DeepseekR1_V3_tutorial_zh.md118-121](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/DeepseekR1_V3_tutorial_zh.md?plain=1#L118-L121)
 - Legacy `ktransformers` backend: Original single-concurrency engine [doc/en/balance-serve.md134](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L134-L134)

## Special Features for Thinking Models

 
### Force Think Mode (DeepSeek-R1)

 DeepSeek-R1 models use a reasoning process that can sometimes be skipped in standard inference. KTransformers provides the `--force_think` flag to ensure the model outputs its internal reasoning process [doc/en/balance-serve.md137](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L137-L137)

 
### Hybrid Precision Architecture

 When serving DeepSeek-V3 or R1, the server can use a hybrid quantization architecture to balance performance and memory [doc/en/fp8_kernel.md6-9](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/fp8_kernel.md?plain=1#L6-L9):

 
 - **Attention/Shared-Experts**: Use FP8 precision for computational accuracy.
 - **MoE Experts**: Retain GGML/GGUF quantization on CPU to save VRAM.
 
 This configuration allows running 671B models on desktop hardware with as little as 14GB-19GB VRAM [doc/en/fp8_kernel.md15](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/fp8_kernel.md?plain=1#L15-L15) [doc/zh/DeepseekR1_V3_tutorial_zh.md41](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/zh/DeepseekR1_V3_tutorial_zh.md?plain=1#L41-L41)

### Concurrency and Throughput

## Summary

 The OpenAI API integration in KTransformers provides:

 
 - **Drop-in Compatibility**: Works with standard OpenAI client libraries [doc/en/balance-serve.md87](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L87-L87)
 - **Multi-Concurrency**: High-performance asynchronous concurrent scheduling in C++ via `balance_serve` [doc/en/balance-serve.md7](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L7-L7)
 - **Heterogeneous Optimization**: Strategic offloading of MoE experts to CPU while keeping intensive MLA operators on GPU via `sglang-kt` integration [doc/en/Kimi-K2.5.md3](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/Kimi-K2.5.md?plain=1#L3-L3)
 - **Flexible Precision**: Support for RAWINT4, AMXINT4, FP8, and BF16 methods [doc/en/Kimi-K2.5.md84](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/Kimi-K2.5.md?plain=1#L84-L84) [doc/en/kt-kernel/deepseek-v3-sglang-tutorial.md112](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/deepseek-v3-sglang-tutorial.md?plain=1#L112-L112)
