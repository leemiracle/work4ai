  This page documents the weight loading pipeline that transfers quantized MoE expert weights from disk (or in-memory tensors) into the C++ inference backends. The pipeline handles format detection, weight loading, `MOEConfig` population, and task submission to the `CPUInfer` worker pool.

 For information about quantization schemes and their trade-offs, see [Quantization Overview](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/Quantization Overview) For converting weights offline, see [CPU Weight Conversion](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/CPU Weight Conversion) For supported weight formats and loader classes, see [Supported Weight Formats](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/Supported Weight Formats)

 
## Overview

 The weight loading pipeline consists of five main stages:

 
 - **Format Detection**: Identify weight format (SafeTensors/GGUF) and quantization scheme [kt-kernel/python/utils/amx.py169-178](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L169-L178)
 - **Weight Loading**: Read weights from disk using format-specific loaders [kt-kernel/python/utils/loader.py1-7](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/loader.py#L1-L7)
 - **MOEConfig Population**: Configure C++ backend with weight pointers and metadata [kt-kernel/python/utils/moe_kernel.py147-168](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/moe_kernel.py#L147-L168)
 - **Task Submission**: Submit `load_weights_task` to `CPUInfer` queue [kt-kernel/python/utils/amx.py305-306](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L305-L306)
 - **Optional GPU Reconstruction**: Reconstruct weights for GPU with different TP counts [kt-kernel/python/utils/amx.py522-555](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L522-L555)
 
 The pipeline supports two primary paths:

 
 - **Online Quantization**: Quantize BF16/FP16 tensors during loading (`load_weights_from_tensors`) [kt-kernel/python/utils/moe_kernel.py125-180](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/moe_kernel.py#L125-L180)
 - **Pre-Quantized**: Load pre-quantized weights directly from disk (`load_weights`) [kt-kernel/python/utils/amx.py176-316](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L176-L316)

## MOEConfig Structure

 The `MOEConfig` struct (exposed via `kt_kernel_ext.moe`) is the central data structure that bridges Python and C++. It contains all metadata and pointers needed for MoE inference [kt-kernel/ext_bindings.cpp502-563](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/ext_bindings.cpp#L502-L563)

 
| Category | Fields | Purpose |
|---|---|---|

| GPU Offloading | gpu_experts_mask, physical_to_logical_map | Expert distribution between CPU/GPU kt-kernel/ext_bindings.cpp511-515 |
| Weight Pointers | gate_projs, up_projs, down_projs, *_scales | 2D pointer arrays: [numa_id][expert_id] kt-kernel/ext_bindings.cpp525-545 |
| Mode Control | save, load, path | Online quantization vs pre-quantized loading kt-kernel/ext_bindings.cpp518-523 |

## Format-Specific Loaders

 
### SafeTensorLoader (AMX/General MoE)

 Loads NUMA-sharded expert weights from `.safetensors` files [kt-kernel/python/utils/loader.py102-114](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/loader.py#L102-L114) It maps expert IDs and NUMA IDs to specific tensor keys [kt-kernel/python/utils/loader.py187-200](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/loader.py#L187-L200)

 
 - **Key Mapping**: `blk.{layer_idx}.ffn_{up|gate|down}_exps.{expert_id}.numa.{numa_id}.weight` [kt-kernel/python/utils/loader.py187-195](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/loader.py#L187-L195)
 - **Singleton Pattern**: Often used as a singleton per model to avoid redundant file handle overhead [kt-kernel/python/utils/amx.py179-181](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/utils/amx.py#L179-L181)
