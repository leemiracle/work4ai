## Purpose and Scope

 This page provides a complete deployment guide for DeepSeek-R1 and DeepSeek-V3 models (671B parameters) and the newer DeepSeek-V3.2 using KTransformers. It covers weight preparation, server launch configurations for both the `ktransformers` and `balance_serve` backends, and integration with SGLang for AMX-accelerated INT4 inference.

 
## Model Architecture Overview

 DeepSeek-R1 and DeepSeek-V3 are 671B parameter Mixture-of-Experts (MoE) models featuring:

 
 - **236B total parameters**, 21B activated per token. [doc/en/DeepseekR1_V3_tutorial.md52](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/DeepseekR1_V3_tutorial.md?plain=1#L52-L52)
 - **160 experts per layer** with top-8 routing. [doc/en/DeepseekR1_V3_tutorial.md137-140](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/DeepseekR1_V3_tutorial.md?plain=1#L137-L140)
 - **Multi-head Latent Attention (MLA)** with compressed KV cache. [doc/en/DeepseekR1_V3_tutorial.md97](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/DeepseekR1_V3_tutorial.md?plain=1#L97-L97)
 - **60 transformer layers** including shared and routed experts. [doc/en/DeepseekR1_V3_tutorial.md52-58](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/DeepseekR1_V3_tutorial.md?plain=1#L52-L58)
 
 **Key Components:**

 
| Component | Placement | Quantization |
|---|---|---|
| MLA Attention | GPU | FP8/BF16 |
| Shared Experts | GPU | FP8/BF16 |
| Routed Experts | CPU | INT4/INT8/GGUF |
| Embeddings | CPU | GGUF |

## Troubleshooting

 
### R1 No Thinking

 If DeepSeek-R1 does not output reasoning tags, ensure the `--force_think` flag is used. [doc/en/balance-serve.md124](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L124-L124)

 
### NUMA Performance

 For dual-socket systems, use `USE_NUMA=1` during installation and run with `numactl -N 1 -m 1` (for single socket usage) or appropriate affinity to avoid cross-socket latency. [doc/en/DeepseekR1_V3_tutorial.md151-152](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/DeepseekR1_V3_tutorial.md?plain=1#L151-L152)

 
### CUDA OOM

 If running on a single 24GB GPU, ensure `--cache_lens` is not set too high (e.g., 32768) and that `optimize_config_path` correctly offloads enough experts to CPU. [doc/en/balance-serve.md120-125](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L120-L125)
