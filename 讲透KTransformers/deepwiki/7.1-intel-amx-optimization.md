## Purpose and Scope

 This document describes Intel Advanced Matrix Extensions (AMX) optimization in KTransformers, including the instruction set capabilities, implementation architecture, and integration with the CPU inference kernels. AMX provides hardware-accelerated matrix operations for Intel 4th generation Xeon Scalable processors (Sapphire Rapids) and newer CPUs. KTransformers v0.3+ introduced high-performance AMX operators for BF16, Int8, FP8, and Int4 (AWQ/KGroup) formats to eliminate CPU bottlenecks during MoE inference [doc/en/AMX.md1-2](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L1-L2)

 
---

 
## AMX Instruction Set Overview

 Intel AMX introduces specialized hardware for matrix computations through tile registers and dedicated matrix multiply-accumulate instructions. Each CPU core contains 8 tile registers (`tmm0-tmm7`) capable of holding 2D sub-matrices up to 16 rows × 64 bytes, plus a 64-byte configuration register (`TILECFG`) [doc/en/AMX.md34-38](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L34-L38)

 
### Instruction Categories

 
| Category | Instructions | Purpose |
|---|---|---|
| Configuration | LDTILECFG, STTILECFG, TILERELEASE, TILEZERO | Configure and reset tile registers doc/en/AMX.md44 |
| Data Movement | TILELOADD, TILELOADDT1, TILESTORED | Transfer between memory and tiles doc/en/AMX.md45 |
| INT8 Compute | TDPBSSD, TDPBUSD, TDPBUUD, TDPBSUD | INT8 matrix multiply-accumulate doc/en/AMX.md46 |
| BF16 Compute | TDPBF16PS | BF16 matrix multiply-accumulate doc/en/AMX.md47 |

 A single `TDPBSSD` instruction performs 16×64 INT8 matrix multiplication (32,768 operations) in 16 CPU cycles, achieving **2048 operations per cycle per core** — 8× the throughput of AVX-512 [doc/en/AMX.md65](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L65-L65)

## Implementation Architecture

 
### Memory Layout: Tile-Aware Preprocessing

 To exploit AMX, KTransformers introduces **AMX Tiling-aware memory preprocessing**. Expert weight matrices are pre-rearranged into sub-matrices matching AMX Tile register dimensions (e.g., 16x64 for Int8/Int4). This eliminates dynamic transposition overhead during inference [doc/en/AMX.md78-82](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L78-L82)

 **Key Layout Features:**

 
 - **Alignment**: Sub-matrix start addresses are strictly aligned to 64 bytes to avoid cache line splits [doc/en/AMX.md82](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L82-L82)
 - **Symmetric Group-wise Quantization**: For Int8/Int4, each column forms a group sharing a scale factor stored separately to maintain alignment for tile data [doc/en/AMX.md84-85](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L84-L85)
 - **AWQ Int4**: Implemented with group-wise scales and zero-points (KGroup Int4 with zeros) [kt-kernel/operators/amx/awq-moe.hpp11-12](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/awq-moe.hpp#L11-L12)
 - **FP8 Block-wise**: Supports 128x128 block-wise scales for DeepSeek V3.2 native inference [kt-kernel/operators/amx/fp8-moe.hpp8-9](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/fp8-moe.hpp#L8-L9)

## Performance Characteristics

 
### Benchmark Results (Xeon 4th Gen)

 Thanks to AMX optimizations, KTransformers achieves significant prefill performance gains:

 
 - **Workstation (Xeon 4 + RTX 4090)**: Up to **347 tokens/s** prefill performance for Qwen3MoE [doc/en/AMX.md19](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L19-L19)
 - **Efficiency**: AMX can provide up to **4 TOPS** of compute power per core, 8 times the performance of AVX-512 [doc/en/AMX.md65](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L65-L65)
 
 
### Precision Support

 
 - **BF16**: Native inference without quantization [doc/en/AMX.md2](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L2-L2)
 - **Int8**: Symmetric Group-wise Quantization [doc/en/AMX.md84](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/AMX.md?plain=1#L84-L84)
 - **Int4 (AWQ)**: KGroup Int4 with zeros and group-wise scales [kt-kernel/operators/amx/awq-moe.hpp11-12](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/operators/amx/awq-moe.hpp#L11-L12)
