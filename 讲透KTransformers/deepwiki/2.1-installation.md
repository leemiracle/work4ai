### CPU Variant Hierarchy

 `kt-kernel` includes 6 optimized variants that are **automatically selected at runtime** based on your CPU [kt-kernel/README.md110-121](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/README.md?plain=1#L110-L121):

 
| Variant | CPU Support | Performance | Auto-Selected When |
|---|---|---|---|
| AMX | Intel Sapphire Rapids+ (2023+) | ⚡⚡⚡ Best | AMX instructions detected |
| AVX512+BF16 | Ice Lake server, Zen 4+ (2021+) | ⚡⚡⚡ Excellent | AVX512 + BF16 detected |
| AVX512+VBMI | Ice Lake client (2019+) | ⚡⚡ Great | AVX512 + VBMI detected |
| AVX512+VNNI | Cascade Lake+ (2019+) | ⚡⚡ Great | AVX512 + VNNI detected |
| AVX512 Base | Skylake-X+ (2017+) | ⚡⚡ Good | AVX512 base detected |
| AVX2 | Haswell+ (2013+), AMD Zen+ | ⚡ Good | Fallback for maximum compatibility |

 **Sources:** [kt-kernel/README.md110-121](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/README.md?plain=1#L110-L121) [kt-kernel/README_zh.md86-98](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/README_zh.md?plain=1#L86-L98)

 
### CUDA Support

 The PyPI wheel includes GPU acceleration for NVIDIA GPUs (SM 80, 86, 89, 90) with a static CUDA runtime, meaning no CUDA toolkit installation is required [kt-kernel/README.md62-64](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/README.md?plain=1#L62-L64)

### 3. Build Configuration (kt-kernel)

 Compilation is controlled via environment variables passed to `setup.py` [kt-kernel/setup.py14-41](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/setup.py#L14-L41):

 
| Variable | Default | Purpose |
|---|---|---|
| CPUINFER_CPU_INSTRUCT | NATIVE | Instruction set (NATIVE, FANCY, AVX512, AVX2) |
| CPUINFER_ENABLE_AMX | OFF | Explicitly enable Intel AMX (ON/OFF) |
| CPUINFER_ENABLE_BLIS | OFF | Enable AMD BLIS for prefill/decode kt-kernel/README.md33 |
| CPUINFER_USE_CUDA | 0 | Enable CUDA support (1/0) |
| CPUINFER_PARALLEL | auto | Number of parallel build jobs |

## Implementation Details: Build System

 The `kt-kernel` build system bridges Python and C++ using `pybind11` and `CMake`.

 Title: Build System Data Flow

 
```

```

 
### Key Build Components:

 
 - **`setup.py`**: Handles environment variable parsing (e.g., `CPUINFER_USE_CUDA`) and drives the CMake process [kt-kernel/setup.py64-110](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/setup.py#L64-L110)
 - **`CMakeLists.txt`**: Configures compiler flags (`-O3`, `-ffast-math`) and manages `OpenMP` and `HWLOC` [kt-kernel/CMakeLists.txt123-134](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/CMakeLists.txt#L123-L134)
 - **`DetectCPU.cmake`**: Performs low-level feature detection to set variables like `KTRANSFORMERS_CPU_USE_AMX` [kt-kernel/CMakeLists.txt33-36](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/CMakeLists.txt#L33-L36)
 - **`autosetup.sh`**: A script for building multiple wheels across different Python and Torch versions, verifying the CUDA runtime stack and wheel contents [kt-kernel/autosetup.sh5-118](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/autosetup.sh#L5-L118)
