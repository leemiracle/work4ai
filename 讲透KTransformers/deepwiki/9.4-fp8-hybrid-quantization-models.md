  This document covers the deployment of DeepSeek-V3 and DeepSeek-R1 models using FP8 hybrid quantization. This architecture optimizes computational accuracy and memory efficiency by combining FP8-quantized attention and shared-expert layers on GPU with GGUF-quantized experts on CPU. It also details native FP8 and RAWINT4 support via the SGLang integration.

 
## Purpose and Architecture

 
### Hybrid Quantization Strategy

 FP8 hybrid quantization implements a split-precision architecture where different model components use different quantization formats based on their computational characteristics:

 
 - **FP8 Components (GPU)**: Attention layers and shared-expert modules use 8-bit floating-point quantization for higher accuracy [doc/en/fp8_kernel.md7-8](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/fp8_kernel.md?plain=1#L7-L8)
 - **GGUF Components (CPU)**: MoE expert layers retain GGML quantization (residing in CPU memory) for extreme parameter density and memory efficiency [doc/en/fp8_kernel.md8-9](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/fp8_kernel.md?plain=1#L8-L9)
 
 This approach reduces GPU VRAM requirements to approximately 19GB for DeepSeek-V3/R1 while maintaining inference quality through higher-precision attention computations [doc/en/fp8_kernel.md14-15](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/fp8_kernel.md?plain=1#L14-L15)

## Performance Characteristics

 
### JIT Compilation and Precision

 
 - **First-Run Latency**: JIT compilation of FP8 GPU kernels causes a longer initial execution; subsequent runs are optimized [doc/en/fp8_kernel.md69-70](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/fp8_kernel.md?plain=1#L69-L70)

## Troubleshooting

 
 - **CUDA OOM**: Layerwise prefill for native precision models requires extra VRAM (e.g., ~3.6GB for MiniMax-M2.1). If OOM occurs, reduce `--kt-num-gpu-experts` or `--chunked-prefill-size` [doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md187-194](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md?plain=1#L187-L194)
 - **R1 "Thinking" Missing**: Use `--force_think` to ensure reasoning tags are output when using the `balance_serve` backend [doc/en/balance-serve.md124-137](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/balance-serve.md?plain=1#L124-L137)
 - **Path Specification**: Merged weights are stored as `.safetensors`, but the directory path must be passed to the `--gguf_path` argument [doc/en/fp8_kernel.md75-76](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/fp8_kernel.md?plain=1#L75-L76)
