  This page documents the `kt-cli` command-line interface, which provides a unified entry point for KTransformers operations including inference, quantization, benchmarking, and configuration management. The CLI is designed to simplify common workflows by offering both interactive and direct modes of operation.

 
---

 
## Overview

 The `kt-cli` tool consolidates multiple KTransformers functionalities into a single command-line interface. The CLI standardizes the user experience and adds interactive guidance for users unfamiliar with the numerous configuration options.

 **Key Features:**

 
 - **Interactive Mode**: Run commands without arguments to get step-by-step guided prompts [doc/en/kt-kernel/kt-cli.md9](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/kt-cli.md?plain=1#L9-L9) This includes first-run setup and model discovery [kt-kernel/python/cli/main.py77-101](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/main.py#L77-L101)
 - **Direct Mode**: Full argument support for scripting and automation, wrapping SGLang server launches [kt-kernel/python/cli/commands/run.py34-84](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/run.py#L34-L84) Arguments are compatible with previous SGLang + KTransformers workflows [doc/en/kt-kernel/kt-cli.md11](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/kt-kernel/kt-cli.md?plain=1#L11-L11)
 - **Unified Interface**: Single entry point for chat, quantization, benchmarking, and configuration [kt-kernel/python/cli/main.py48-54](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/main.py#L48-L54)
 - **I18n Support**: Full support for English and Chinese localized help texts and prompts [kt-kernel/python/cli/main.py28-44](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/main.py#L28-L44) Language can be set via system locale or `KT_LANG` environment variable [kt-kernel/python/cli/i18n.py4-6](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/i18n.py#L4-L6)

## Core Commands Reference

 
### `kt run`

 Starts the model inference server using SGLang integrated with `kt-kernel` [kt-kernel/python/cli/commands/run.py1-5](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/run.py#L1-L5) It acts as a wrapper for `sglang.launch_server` [kt-kernel/python/cli/commands/run.py119](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/run.py#L119-L119)

 **Key Options:**

 
| Option | Description |
|---|---|
| --model | Model name (e.g., deepseek-v3, m2) or local path kt-kernel/python/cli/commands/run.py38 |
| --gpu-experts | Number of experts per layer to place on GPU kt-kernel/python/cli/commands/run.py41 |
| --cpu-threads | Number of CPU inference threads kt-kernel/python/cli/commands/run.py42 |
| --numa-nodes | Explicit NUMA node IDs for threadpools kt-kernel/python/cli/commands/run.py43-50 |
| --kt-method | Quantization method (e.g., AMXINT4, RAWINT4, FP8) kt-kernel/python/cli/commands/run.py56 |
| --tp | Tensor parallel size for multi-GPU setups kt-kernel/python/cli/commands/run.py52 |

 Sources: [kt-kernel/python/cli/commands/run.py34-110](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/run.py#L34-L110)

 
### `kt doctor`

 Diagnoses environment issues and provides optimization recommendations [kt-kernel/python/cli/commands/doctor.py1-5](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/doctor.py#L1-L5)

 **Diagnostics Performed:**

 
 - **CPU ISA Detection**: Checks for `AMX-INT8`, `AVX512`, and `AVX2` support [kt-kernel/python/cli/commands/doctor.py163-199](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/doctor.py#L163-L199)
 - **kt-kernel Verification**: Checks for installed `.so` variants (e.g., `_kt_kernel_ext_amx.so`) and identifies the active CPU variant [kt-kernel/python/cli/commands/doctor.py34-92](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/doctor.py#L34-L92)
 - **NUMA Topology**: Reports CPU core distribution across NUMA nodes [kt-kernel/python/cli/commands/doctor.py201-214](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/doctor.py#L201-L214)
 - **GPU & CUDA**: Validates NVIDIA driver and CUDA toolkit versions [kt-kernel/python/cli/commands/doctor.py118-150](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/doctor.py#L118-L150)
 - **Memory & Disk**: Checks available RAM and disk space [kt-kernel/python/cli/commands/doctor.py216-235](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/doctor.py#L216-L235)
 
 Sources: [kt-kernel/python/cli/commands/doctor.py95-235](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/commands/doctor.py#L95-L235)

 
### `kt model`

 Manages the local model registry and storage paths. It supports fuzzy matching for built-in models [kt-kernel/python/cli/utils/model_registry.py1-6](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/utils/model_registry.py#L1-L6)

 - **DeepSeek-V3-0324**: Defaults to `AMXINT4` with `triton` attention backend [kt-kernel/python/cli/utils/model_registry.py35-48](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/utils/model_registry.py#L35-L48)

## Configuration Management

 The CLI manages persistent settings in `~/.ktransformers/config.yaml` [kt-kernel/python/cli/main.py85-101](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/main.py#L85-L101)

 **First-Run Setup Wizard:** When `kt` is run for the first time, it triggers `_show_first_run_setup`, which:

 
 - Prompts for language selection (English/Chinese) [kt-kernel/python/cli/main.py128-140](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/main.py#L128-L140)
 - Performs global model discovery to find existing weights on the system (scanning non-system paths) [kt-kernel/python/cli/main.py172-193](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/main.py#L172-L193)
 - Initializes the user model registry in `registry.yaml` [kt-kernel/python/cli/main.py98-101](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/main.py#L98-L101) [kt-kernel/python/cli/utils/model_registry.py173](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/kt-kernel/python/cli/utils/model_registry.py#L173-L173)
