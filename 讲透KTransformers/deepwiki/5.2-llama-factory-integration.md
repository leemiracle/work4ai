## Purpose and Scope

 This page documents the technical integration between KTransformers and LLaMA-Factory, explaining how `kt-sft` serves as a pluggable backend for fine-tuning ultra-large MoE models. The integration enables LoRA fine-tuning of models like DeepSeek-V3 (671B parameters) on consumer GPUs (e.g., 2–4 RTX 4090s) by combining LLaMA-Factory's training orchestration with KTransformers' heterogeneous CPU-GPU execution.

 The integration is delivered via the `ktransformers[sft]` package entry, which includes `kt-kernel`, `transformers-kt`, and `accelerate-kt` [doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md57-69](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md?plain=1#L57-L69)

## Integration Architecture

 LLaMA-Factory acts as the orchestration layer for data processing and training loops. KTransformers acts as a high-performance operator backend that takes over Attention and MoE layers under the same training configurations [doc/en/SFT/KTransformers-Fine-Tuning_User-Guide.md24-26](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/SFT/KTransformers-Fine-Tuning_User-Guide.md?plain=1#L24-L26)

## Training Configuration and Workflow

 The integration uses LLaMA-Factory's standard CLI but requires specific environment setups and YAML parameters.

 
### Configuration Parameters

 
| Parameter | Location | Description |
|---|---|---|
| use_kt | Train YAML | Enables the KTransformers backend for the training session doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md145 |
| kt_config | Train YAML | Path to the optimization rule (e.g., expert placement and backend selection) doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md145 |
| config_file | Accelerate Launch | Path to specialized accelerate configs like fsdp2_kt_int8.yaml doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md107-110 |

 
### Execution Workflow

 
 - **Environment Initialization**: Install `ktransformers[sft]` which provides the patched `accelerate-kt` and `transformers-kt` [doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md63-69](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md?plain=1#L63-L69)
 - **Model Loading**: Use `KTrainer` to load the model. It uses the `kt_optimize_rule` to place Attention on GPU and MoE on CPU [doc/en/SFT/KTransformers-Fine-Tuning_Developer-Technical-Notes.md87-88](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/SFT/KTransformers-Fine-Tuning_Developer-Technical-Notes.md?plain=1#L87-L88)
 - **Training**: Launch via `accelerate launch` with the KT-specific config file [doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md107-110](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md?plain=1#L107-L110)
 - **Adapter Management**: The resulting LoRA adapter is saved normally and can be loaded for inference using the `kt-kernel` backend [doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md149-153](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/doc/en/SFT/KTransformers-Fine-Tuning_Quick-Start.md?plain=1#L149-L153)
