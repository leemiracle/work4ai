## Overview

 KTransformers provides official Docker images that bundle both inference and fine-tuning capabilities in a single container. The images include:

 
 - **Dual conda environments**: `serve` (SGLang + kt-kernel) and `fine-tune` (LLaMA-Factory + ktransformers) [docker/Dockerfile209-210](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/docker/Dockerfile#L209-L210)
 - **Multi-CPU variant support**: AMX, AVX512, and AVX2 backends compiled into a single image with runtime detection [docker/Dockerfile7-8](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/docker/Dockerfile#L7-L8) [docker/README-packaging.md10](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/docker/README-packaging.md?plain=1#L10-L10)
 - **Production dependencies**: CUDA toolkit, NCCL, FlashInfer, DeepEP, and all required system libraries [docker/Dockerfile1-141](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/docker/Dockerfile#L1-L141)
 - **Version tracking**: Automated extraction of SGLang, KTransformers, and LLaMA-Factory versions into a `versions.env` file [docker/Dockerfile378-404](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/docker/Dockerfile#L378-L404) [docker/docker-utils.sh112-130](https://github.com/kvcache-ai/ktransformers/blob/02be2bf5/docker/docker-utils.sh#L112-L130)

 **Dual Environment Design**

 The image contains two independent Python 3.12 environments:

 
| Environment | Purpose | Key Packages | Location |
|---|---|---|---|
| serve | Production inference | sglang, sgl-kernel, flashinfer, deepep, kt-kernel | /opt/miniconda3/envs/serve |

### Build Script Parameters

 Both `build-docker-tar.sh` and `push-to-dockerhub.sh` support these key arguments:

 
| Option | Default | Description |
|---|---|---|
| --cuda-version | 12.8.1 | Target CUDA version docker/build-docker-tar.sh39 |
| --ubuntu-mirror | 0 | Use Tsinghua mirror (1) or default (0) docker/build-docker-tar.sh40 |
| --cpu-variant | x86-intel-multi | CPU architecture label docker/build-docker-tar.sh43 |
| --functionality | sft | Mode: sft (training + inference) or infer docker/build-docker-tar.sh44 |
| --http-proxy | - | Proxy for build-time network access docker/build-docker-tar.sh41 |
