# 讲透优化理论（Optimization Theory）

> **博士级地基**——所有 ML 训练的数学根基。Adam / SGD / Momentum 的收敛性证明、KKT 条件、凸优化、非凸景观、鞍点、critical point 分析。
>
> 一句话定位：[`讲透优化器`](../讲透优化器/) 给"Adam 怎么用"，本系列问"**为什么 Adam 会收敛、收敛到什么**"。
>
> **博士级标准**：实分析 + 凸分析 + 线性代数。
>
> 配套：[`讲透优化器`](../讲透优化器/)（应用）+ [`讲透反向传播`](../讲透反向传播/)（梯度来源）+ [`讲透统计学习理论`](../讲透统计学习理论/)（优化-泛化联系）

---

## 为什么单独开

- **理论根基**：训练 ML = 优化——不懂优化理论 = 不懂训练
- **被工程化掩盖**：很多人会调 Adam，没人能证明它收敛
- **博士必修**：任何 ML 博士资格考都考收敛性证明
