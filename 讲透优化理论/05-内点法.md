# 05 - 内点法：凸优化的高效解法（配 Boyd Ch 11）

> 内点法（interior point method）是凸优化的**工业级解法**——多项式时间收敛。cvxpy / scipy.optimize 都用它。

---

## 一、直觉

### 1.1 障碍法（barrier method）

原问题 $\min f(x)$ s.t. $h_i(x) \leq 0$。

**想法**：把不等式变成"惩罚"：

$$\min_t \quad t \cdot f(x) - \sum_i \log(-h_i(x))$$

第二项是**对数障碍**——当 $x$ 接近边界 $h_i(x) = 0$ 时，$-\log(-h_i) \to +\infty$（爆炸惩罚）。

$t \to \infty$ 时，最优解 $x^*(t) \to$ 原问题最优解。

### 1.2 中心路径（central path）

随 $t$ 增大，$x^*(t)$ 描绘一条**中心路径**，始终在可行域内部（不到边界）——所以叫"内点"法。

---

## 二、数学层

### 2.1 对数障碍函数

$\phi(x) = -\sum_i \log(-h_i(x))$（要求 $h_i(x) < 0$ 严格可行）

### 2.2 中心路径

$x^*(t) = \arg\min_x \, t f(x) + \phi(x)$

**性质**：$x^*(t)$ 满足 KKT 的"松弛版"，$t \to \infty$ 时收敛到真最优。

### 2.3 算法

```
1. 选 t = 1, 严格可行 x
2. 用 Newton 法解 min t·f + φ
3. t := μ·t（μ > 1，如 10）
4. 重复直到 t·f 收敛
```

**收敛**：$O(\sqrt{m} \log(1/\epsilon))$ 次 Newton 迭代（$m$ = 约束数）。

### 2.4 原始-对偶内点法

更高效的变体：同时更新原始 $x$ 和对偶 $(\lambda, \nu)$。KKT 的牛顿步。

## 四、应用

- cvxpy 默认用 ECOS / SCS（内点法变体）
- LP / QP / SOCP / SDP 求解器都用内点法
- ML：LASSO、SVM、matrix completion 的求解

---

## 五、不足

- 需要**严格可行点**作为起点（Slater 条件）
- 二阶方法（要 Hessian）—— 大规模问题慢
- 非凸问题不保证全局
