  The utilities system provides supporting functions and classes that complement the core RL components of skrl. These utilities cover essential functionality including random number generator seeding, Isaac Gym integration tools, data post-processing capabilities, and robotics control algorithms. Furthermore, it includes the **Resources** sub-module, which provides noises, schedulers, preprocessors, and optimizers across PyTorch, JAX, and Warp backends.

## Resources

 Resources are components designed to improve agent performance through data normalization, exploration noise, and adaptive optimization.

 
### Preprocessors: RunningStandardScaler

 The `RunningStandardScaler` standardizes input data (typically observations) by removing the mean and scaling by the standard deviation. It uses a parallel algorithm for computing variance to handle batch updates efficiently [skrl/resources/preprocessors/torch/running_standard_scaler.py50-58](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/resources/preprocessors/torch/running_standard_scaler.py#L50-L58)

 
| Feature | Description |
|---|---|
| Standardization | $\text{clip}((x - \bar{x}_t) / (\sqrt{\sigma^2} + \epsilon), -c, c)$ skrl/resources/preprocessors/jax/running_standard_scaler.py53-57 |
| Inverse | Scales data back to original representation skrl/resources/preprocessors/torch/running_standard_scaler.py88-93 |
| Backends | Supported in PyTorch, JAX, and Warp docs/source/api/resources.rst47-54 |

 
### Noises

 Exploration noises are primarily used for off-policy algorithms like DDPG and TD3.

 
 - **GaussianNoise**: Samples from a normal distribution [skrl/resources/noises/jax/gaussian.py20-31](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/resources/noises/jax/gaussian.py#L20-L31)
 - **OrnsteinUhlenbeckNoise**: Implements a mean-reverting process, useful for temporally correlated exploration [skrl/resources/noises/jax/ornstein_uhlenbeck.py20-43](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/resources/noises/jax/ornstein_uhlenbeck.py#L20-L43)
 
 
### Schedulers: KLAdaptiveLR

 The `KLAdaptiveLR` adjusts the learning rate according to the KL divergence between old and new policies. It is specifically designed for algorithms like PPO and A2C [skrl/resources/schedulers/torch/kl_adaptive.py26-30](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/resources/schedulers/torch/kl_adaptive.py#L26-L30)

 
 - If $KL > threshold \times factor$, the learning rate is decreased [skrl/resources/schedulers/torch/kl_adaptive.py82-83](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/resources/schedulers/torch/kl_adaptive.py#L82-L83)
 - If $KL < threshold / factor$, the learning rate is increased [skrl/resources/schedulers/torch/kl_adaptive.py84-85](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/resources/schedulers/torch/kl_adaptive.py#L84-L85)
 
 
### Optimizers (JAX)

 While PyTorch uses standard `torch.optim` classes, skrl provides a custom `Adam` wrapper for JAX to integrate with the library's `Model` state management. It wraps `optax` transformations and supports custom scaling (learning rate) during optimization steps [skrl/resources/optimizers/jax/adam.py34-60](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/resources/optimizers/jax/adam.py#L34-L60)

## Random Number Generator Seeding

 The core seeding functionality ensures reproducible experiments across different ML frameworks and distributed training scenarios.

 
### set_seed Function

 The `set_seed()` function provides centralized random number generator seeding with support for both PyTorch and JAX backends. It handles distributed training by incrementing the seed based on process rank and supports deterministic operations through PyTorch's deterministic algorithms.

## Isaac Gym and Control Utilities

 
### Isaac Gym Integration

 The library provides tools to bridge skrl with NVIDIA Isaac Gym:

 
 - **WebViewer**: A Flask-based server for remote visualization of simulation frames [skrl/utils/isaacgym_utils.py28-386](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/utils/isaacgym_utils.py#L28-L386)
 - **Debug Printing**: Functions to inspect DOF properties, actor components, and simulation metadata [skrl/utils/isaacgym_utils.py440-569](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/utils/isaacgym_utils.py#L440-L569)
 
 
### Control

 Robotics-specific control utilities include:

 
 - **Inverse Kinematics (ik)**: Damped least squares implementation for mapping end-effector targets to joint space [skrl/utils/control.py1-25](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/utils/control.py#L1-L25)
 - **Operational Space Control (osc)**: Computes joint torques for operational space tasks [skrl/utils/control.py27-56](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/utils/control.py#L27-L56)
