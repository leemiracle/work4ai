  This document covers the JAX backend implementation of reinforcement learning agents in the skrl library. JAX agents provide high-performance implementations of various RL algorithms with JIT compilation, XLA acceleration, and distributed training support.

 For information about PyTorch-based agent implementations, see [PyTorch Agents](https://deepwiki.com/Toni-SM/skrl/2.1-pytorch-agents). For details about the model system used by these agents, see [Model Base Classes](https://deepwiki.com/Toni-SM/skrl/3.1-model-base-classes).

 
## Architecture Overview

 JAX agents form one of the three main backend implementations in skrl (PyTorch, JAX, Warp). They inherit from a common base class and implement the same interface while leveraging JAX's functional programming paradigm and XLA compilation for performance optimization.

## Base Agent Interface

 - `act()`: Returns actions for the given environment states [skrl/agents/jax/base.py314-332](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/jax/base.py#L314-L332).

## Functional Update Pipeline

 Unlike PyTorch's imperative style, skrl's JAX agents use a functional pipeline for updates. The state of the models (parameters) is stored in a `StateDict` and passed to JIT-compiled helper functions.

 
### Gradient Computation

 Agents use `jax.value_and_grad` to compute losses and gradients simultaneously. For example, in PPO, the `_update_policy` function returns both the gradient and auxiliary metrics like KL divergence: [skrl/agents/jax/ppo/ppo.py88-92](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/jax/ppo/ppo.py#L88-L92).

 
### Parameter Synchronization

 In distributed settings (`config.jax.is_distributed`), agents broadcast initial parameters from the rank 0 process to all other processes: [skrl/agents/jax/ppo/ppo.py164-169](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/jax/ppo/ppo.py#L164-L169). During updates, gradients are reduced across devices before being applied by the optimizer.

 
## Available Algorithms

 The JAX backend implements the following algorithms:

 
| Algorithm | Type | Implementation Features |
|---|---|---|
| PPO | Policy Gradient | GAE computation skrl/agents/jax/ppo/ppo.py25-52, clipped surrogate objective skrl/agents/jax/ppo/ppo.py78-79. |
| RPO | Policy Gradient | Robust Policy Optimization with perturbations skrl/agents/jax/rpo/rpo.py130. |
| A2C | Actor-Critic | Advantage Actor-Critic with entropy regularization skrl/agents/jax/a2c/a2c.py103. |
| DDPG | Actor-Critic | Deterministic policy updates skrl/agents/jax/ddpg/ddpg.py71 and exploration noise skrl/agents/jax/ddpg/ddpg.py25. |
| TD3 | Actor-Critic | Twin critics skrl/agents/jax/td3/td3.py133-134 and smooth regularization noise skrl/agents/jax/td3/td3.py33-41. |
| SAC | Actor-Critic | Automatic entropy adjustment skrl/agents/jax/sac/sac.py159-181 and twin Q-networks. |
| DQN | Value-Based | Deep Q-Learning with target network synchronization. |
| DDQN | Value-Based | Double DQN for reduced overestimation. |
| CEM | Evolutionary | Cross-Entropy Method for derivative-free optimization. |

## Warp-Backend Agents

## Distributed Training Optimization

 JAX agents are optimized for multi-device execution using the `skrl.config.jax` settings.

 
 - **Parameter Broadcasting:** At initialization, `model.broadcast_parameters()` ensures all workers start with identical weights [skrl/agents/jax/ppo/ppo.py167](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/jax/ppo/ppo.py#L167-L167).
 - **Gradient Reduction:** During the update step, gradients are averaged across all participating devices before the optimizer step is taken.
 - **Device Management:** Agents respect the `device` parameter, mapping it to a `jax.Device` for memory allocation [skrl/agents/jax/base.py114](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/jax/base.py#L114-L114).
