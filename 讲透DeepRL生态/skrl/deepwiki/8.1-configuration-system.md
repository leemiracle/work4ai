  The Configuration System provides centralized management of machine learning framework settings, device allocation, and distributed training parameters for PyTorch, JAX, and Warp backends in skrl. This system handles framework-specific configurations, automatic device detection, and distributed training setup through environment variables.

 For information about utility functions and general system configuration, see [Utilities](https://deepwiki.com/Toni-SM/skrl/8.3-utilities). For details about the Runner system that uses these configurations, see [Runner System](https://deepwiki.com/Toni-SM/skrl/8.2-runner-system).

## PyTorch Configuration

 The PyTorch configuration handles device management and distributed training setup using standard PyTorch distributed environment variables.

 
### Device Management

 The `PyTorch` class provides automatic device detection and parsing functionality through the `parse_device` method [skrl/__init__.py74-105](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/__init__.py#L74-L105) The default device is determined by CUDA availability and distributed training context.

 
| Property | Type | Default | Description |
|---|---|---|---|
| device | torch.device | cuda:0 or cpu | Default device, uses cuda:LOCAL_RANK in distributed mode skrl/__init__.py108-115 |
| parse_device() | Method | - | Parses device specifications with validation skrl/__init__.py74-105 |

 
### Distributed Training

 Distributed training configuration is automatically initialized based on environment variables [skrl/__init__.py56-71](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/__init__.py#L56-L71):

 
| Property | Environment Variable | Default | Description |
|---|---|---|---|
| local_rank | LOCAL_RANK | 0 | Rank within local worker group skrl/__init__.py131-138 |
| rank | RANK | 0 | Global rank across all workers skrl/__init__.py141-148 |
| world_size | WORLD_SIZE | 1 | Total number of workers skrl/__init__.py151-158 |
| is_distributed | - | False | Computed as world_size > 1 skrl/__init__.py161-168 |

 When `world_size > 1`, the system automatically initializes `torch.distributed` with the NCCL backend [skrl/__init__.py64-71](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/__init__.py#L64-L71)

## JAX Configuration

 The JAX configuration provides PRNG key management and custom distributed training setup.

 
### PRNG Key Management

 The JAX backend manages pseudo-random number generation through a global key [skrl/__init__.py173](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/__init__.py#L173-L173) The key is initialized as a 32-bit unsigned integer array `[0, 0]` [skrl/__init__.py173](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/__init__.py#L173-L173)

 
### Distributed Training

 JAX distributed training uses custom environment variables since JAX requires explicit process management [skrl/__init__.py177-182](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/__init__.py#L177-L182):

 
| Property | Environment Variable | Default | Description |
|---|---|---|---|
| local_rank | JAX_LOCAL_RANK | 0 | Local rank within node docs/source/api/config/frameworks.rst99-107 |
| rank | JAX_RANK | 0 | Global process rank docs/source/api/config/frameworks.rst109-117 |
| world_size | JAX_WORLD_SIZE | 1 | Total number of processes docs/source/api/config/frameworks.rst119-127 |
| coordinator_address | JAX_COORDINATOR_ADDR:JAX_COORDINATOR_PORT | 127.0.0.1:1234 | Coordinator service address docs/source/api/config/frameworks.rst129-137 |

## Experiment Configuration

 The library uses the `ExperimentCfg` dataclass to manage logging and checkpointing settings for agents.

 
| Parameter | Type | Default | Description |
|---|---|---|---|
| directory | str | "" | Root path for run data skrl/agents/torch/base.py27-28 |
| experiment_name | str | "" | Unique run identifier skrl/agents/torch/base.py30-34 |
| write_interval | int \| "auto" | "auto" | TensorBoard logging frequency skrl/agents/torch/base.py36-41 |
| checkpoint_interval | int \| "auto" | "auto" | Checkpoint saving frequency skrl/agents/torch/base.py43-48 |
| wandb | bool | False | Enable Weights & Biases logging skrl/agents/torch/base.py57-58 |

 
### Logging and Visualization

 
 - **TensorBoard**: Managed via `skrl.utils.tensorboard.SummaryWriter` [skrl/agents/torch/base.py20](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/torch/base.py#L20-L20)
 - **Weights & Biases**: Integrated via `wandb_kwargs` in `ExperimentCfg` [skrl/agents/torch/base.py60-64](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/torch/base.py#L60-L64)
 - **Interval Handling**: If set to `"auto"`, `write_interval` defaults to 100 samples and `checkpoint_interval` to 10 samples throughout training [skrl/agents/torch/base.py36-48](https://github.com/Toni-SM/skrl/blob/3cdc7f3b/skrl/agents/torch/base.py#L36-L48)
