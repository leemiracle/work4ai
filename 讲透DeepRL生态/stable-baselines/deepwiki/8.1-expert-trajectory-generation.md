## Purpose and Scope

 Expert Trajectory Generation provides functionality for creating and managing expert demonstration datasets used in imitation learning, specifically with GAIL (Generative Adversarial Imitation Learning). This system allows you to record trajectories from trained RL agents or custom expert policies and store them in a standardized format for later use in behavior cloning and adversarial imitation learning.

 For information about using these expert trajectories with GAIL training, see [Advanced Extensions](https://deepwiki.com/hill-a/stable-baselines/3.3-advanced-extensions). For general environment management and vectorization concepts, see [Environment Management](https://deepwiki.com/hill-a/stable-baselines/5-environment-management).

 
## System Overview

 The expert trajectory generation system consists of three main components: trajectory recording, dataset management, and data loading. The system can work with both traditional vector observations and image-based observations, handling the complexities of data storage and preprocessing automatically.

## Data Format and Storage

 
### NPZ Archive Structure

 Expert trajectories are stored as compressed NumPy archives with the following structure:

 
| Key | Shape | Description |
|---|---|---|
| actions | (N,) + action_shape | Actions taken by the expert |
| obs | (N,) + obs_shape or (N,) | Observations or image file paths |
| rewards | (N,) | Rewards received |
| episode_returns | (n_episodes,) | Total returns for each episode |
| episode_starts | (N,) | Boolean array marking episode boundaries |

 Where `N` is the total number of timesteps across all episodes.

### Image Handling

 For image-based observations, the system:

 
 - Detects image observations automatically based on shape and dtype
 - Saves images as JPG or PNG files to reduce storage requirements
 - Stores file paths in the observations array instead of raw pixel data
 - Handles color space conversions (RGB to BGR for OpenCV)

### Memory Management

 The `DataLoader` class provides sophisticated memory management:

 
 - **Sequential Mode**: Lower memory usage for CI/testing environments
 - **Multiprocessing**: Parallel image loading for better performance
 - **Queue Management**: Controlled batch preprocessing to prevent memory overflow
 - **Pickling Support**: Safe serialization excluding non-pickleable processes

### Integration with Training Algorithms

 Expert datasets integrate seamlessly with multiple training approaches:

 
 - **GAIL Training**: Direct use with adversarial imitation learning
 - **Behavior Cloning**: Pretraining with `model.pretrain(dataset)`
 - **Custom Training**: Access to raw batch data for custom algorithms
