  On-policy algorithms learn directly from the current policy's experience without using replay buffers from past policies. This document covers the implementation and architecture of on-policy reinforcement learning algorithms in stable-baselines, including their common patterns, individual characteristics, and code organization.

 For off-policy algorithms that learn from replay buffers, see [Off-Policy Algorithms](https://deepwiki.com/hill-a/stable-baselines/3.2-off-policy-algorithms). For advanced extensions like imitation learning, see [Advanced Extensions](https://deepwiki.com/hill-a/stable-baselines/3.3-advanced-extensions).

## Core Algorithms

 
### PPO2 (Proximal Policy Optimization)

 PPO2 is the primary GPU-optimized implementation using vectorized environments and clipped policy gradients.

 **Key Features:**

 
 - Vectorized environment support via `n_envs` parameter
 - Clipped policy gradient with `cliprange` parameter
 - Generalized Advantage Estimation (GAE) with `lam` parameter
 - Value function clipping via `cliprange_vf`
 
 **Core Implementation:**

 
 - Main class: `PPO2` [stable_baselines/ppo2/ppo2.py16](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/ppo2/ppo2.py#L16-L16)
 - Training method: `_train_step()` [stable_baselines/ppo2/ppo2.py244](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/ppo2/ppo2.py#L244-L244)
 - Environment runner: `Runner` [stable_baselines/ppo2/ppo2.py442](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/ppo2/ppo2.py#L442-L442)

### A2C (Advantage Actor-Critic)

 A2C implements synchronous advantage actor-critic with multiple parallel environments.

 **Key Features:**

 
 - Synchronous updates across all environments
 - Simple advantage estimation: `rewards - values`
 - RMSProp optimizer with learning rate scheduling
 - Configurable number of steps per update via `n_steps`
 
 **Core Implementation:**

 
 - Main class: `A2C` [stable_baselines/a2c/a2c.py33](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/a2c/a2c.py#L33-L33)

### TRPO (Trust Region Policy Optimization)

 TRPO uses trust region constraints to ensure stable policy updates through conjugate gradient optimization.

 **Key Features:**

 
 - KL divergence constraint via `max_kl` parameter
 - Conjugate gradient for policy updates
 - Fisher vector products for second-order optimization
 - MPI-based distributed training
 
 **Core Implementation:**

 
 - Main class: `TRPO` [stable_baselines/trpo_mpi/trpo_mpi.py23](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/trpo_mpi/trpo_mpi.py#L23-L23)
 - Conjugate gradient: `conjugate_gradient()` [stable_baselines/common/cg.py](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/common/cg.py)
 - MPI utilities: `MpiAdam` [stable_baselines/common/mpi_adam.py](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/common/mpi_adam.py)
 
 Sources: [stable_baselines/trpo_mpi/trpo_mpi.py277-505](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/trpo_mpi/trpo_mpi.py#L277-L505) [stable_baselines/trpo_mpi/trpo_mpi.py384-416](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/trpo_mpi/trpo_mpi.py#L384-L416)

 
### ACER (Actor-Critic with Experience Replay)

 ACER extends actor-critic methods with off-policy experience replay while maintaining on-policy characteristics.

 **Key Features:**

 
 - Experience replay buffer via `buffer_size` parameter
 - Importance sampling for off-policy corrections
 - Q-retrace for value function updates
 - Trust region optimization option
 
 **Core Implementation:**

 
 - Main class: `ACER` [stable_baselines/acer/acer_simple.py140](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/acer/acer_simple.py#L140-L140)
 - Q-retrace function: `q_retrace()` [stable_baselines/acer/acer_simple.py50](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/acer/acer_simple.py#L50-L50)
 - Experience buffer: `Buffer` [stable_baselines/acer/buffer.py](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/acer/buffer.py)

## Algorithm Comparison

 
| Algorithm | Vectorization | MPI Support | Key Innovation | Default Parameters |
|---|---|---|---|---|
| PPO2 | ✓ | ❌ | Clipped policy gradients | cliprange=0.2, n_steps=128 |
| PPO1 | ❌ | ✓ | MPI-based clipping | clip_param=0.2, timesteps_per_actorbatch=256 |
| A2C | ✓ | ❌ | Synchronous A3C | n_steps=5, lr_schedule='constant' |
| TRPO | ❌ | ✓ | Trust region constraints | max_kl=0.01, cg_iters=10 |
| ACER | ✓ | ❌ | Experience replay | replay_ratio=4, buffer_size=5000 |
| ACKTR | ✓ | ❌ | Kronecker-factored trust region | Natural gradients |
