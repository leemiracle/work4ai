## Prerequisites and System Requirements

 Stable-baselines requires Python 3.5 or higher with development headers, plus several system-level dependencies. The library supports TensorFlow versions 1.8.0 to 1.15.0 and does not work with TensorFlow 2.0+.

 
### Required System Dependencies

 The core system packages required across all platforms include:

 
 - **Python 3.5+** with development headers
 - **CMake** for building native extensions
 - **OpenMPI** for distributed algorithms (optional but recommended)
 - **zlib** for compression support

## Troubleshooting

 
### Common Installation Issues

 
| Issue | Symptoms | Solution |
|---|---|---|
| TensorFlow Version | ImportError or version conflicts | Install TensorFlow 1.8.0-1.15.0 manually |
| MPI Dependencies | TRPO/PPO1 import failures | Install with [mpi] extra or install mpi4py |
| Windows DLL Issues | Atari environment errors | Install Visual C++ redistributables |
| Docker GPU Access | CUDA not available in container | Install nvidia-docker and use GPU image |
| Permission Errors | Docker mount failures | Check file permissions and Docker daemon access |

 
### Dependency Conflicts

 The setup configuration handles common dependency conflicts through filtering:

 
 - TensorFlow deprecation warnings are suppressed
 - Gym parameter loading warnings are filtered
 - Python hash randomization is disabled for deterministic testing
 
 Sources: [setup.cfg5-19](https://github.com/hill-a/stable-baselines/blob/45beb246/setup.cfg#L5-L19) [docs/guide/install.rst77-80](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/guide/install.rst#L77-L80)
