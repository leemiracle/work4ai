## Test Environments for Evaluation

 Stable-baselines includes specialized test environments designed for algorithm validation and benchmarking.

 
### Identity Environments

 The identity environment family provides controllable test cases where the optimal policy is known, making them ideal for algorithm validation:

 
```

```

 
#### IdentityEnv Class Hierarchy

 
 - **`IdentityEnv`**: Base class with discrete action/observation spaces
 - **`IdentityEnvBox`**: Continuous action spaces with epsilon tolerance for reward calculation
 - **`IdentityEnvMultiDiscrete`**: Multi-dimensional discrete action spaces
 - **`IdentityEnvMultiBinary`**: Binary action spaces
 
 Each environment implements a simple reward function where the agent receives reward 1 for matching the current state with its action, and 0 otherwise.

## Environment Validation

 The `env_checker` module provides comprehensive validation to ensure environments are compatible with stable-baselines algorithms.

 
### Validation Pipeline

 
```

```

 
### Key Validation Checks

 
#### Space Validation

 
 - Verifies `action_space` and `observation_space` inherit from `gym.spaces.Space`
 - Checks for unsupported space types (Dict, Tuple) with appropriate warnings
 - Validates image input specifications (dtype, bounds, dimensions)
 
 
#### Method Validation

 
 - Confirms `reset()` returns valid observations matching the observation space
 - Validates `step()` returns 4-tuple: `(observation, reward, done, info)`
 - Ensures reward is numeric, done is boolean, info is dictionary
 
 
#### Compatibility Warnings

 
 - Warns about non-standard action space bounds (recommends [-1, 1] normalization)
 - Identifies potential issues with image observations
 - Detects unsupported observation space types

### Standard Experiment Pattern

 
 - **Training Phase**:

 
 - Configure environment and algorithm parameters
 - Implement performance callbacks for monitoring
 - Save trained models with descriptive names
 - **Evaluation Phase**:

 
 - Load saved models
 - Run evaluation episodes with optional rendering
 - Collect performance statistics
 - **Analysis Phase**:

 
 - Use results plotter for visualization
 - Compare performance across different configurations
 - Generate performance reports

### Testing Integration

 The test suite validates algorithm performance on standard environments, ensuring consistent behavior across different configurations and preventing regression:

 
 - **Algorithm Tests**: Verify training and evaluation functionality
 - **Environment Tests**: Validate custom environments using the checking framework
