  Environment wrappers in stable-baselines provide a standardized way to modify the behavior of vectorized environments without changing the underlying environment implementation. These wrappers apply transformations to observations, rewards, and other environment interactions in a composable manner.

 For information about vectorized environments themselves, see [Vectorized Environments](https://deepwiki.com/hill-a/stable-baselines/5.1-vectorized-environments). For custom environment creation, see [Custom Environments](https://deepwiki.com/hill-a/stable-baselines/5.2-custom-environments).

 Environment wrappers in stable-baselines are built around the `VecEnvWrapper` base class, which provides a decorator pattern for vectorized environments. Wrappers can be chained together to apply multiple transformations sequentially.

## VecNormalize

 `VecNormalize` normalizes observations and rewards using running statistics. It maintains separate `RunningMeanStd` objects for observations and returns (discounted rewards).

 
### Key Features

 
| Feature | Description | Configuration |
|---|---|---|
| Observation Normalization | Normalizes observations to zero mean, unit variance | norm_obs=True |
| Reward Normalization | Normalizes rewards using discounted returns | norm_reward=True |
| Clipping | Clips normalized values to prevent extreme outliers | clip_obs=10.0, clip_reward=10.0 |
| Training Mode | Controls whether statistics are updated | training=True/False |
| Persistence | Save/load normalization statistics | save(), load() methods |

## VecFrameStack

 `VecFrameStack` stacks consecutive frames along the last axis of observations. This is commonly used for environments where temporal information is important, such as Atari games.

 
### Implementation Details

 
 - Maintains a `stackedobs` buffer of shape `(num_envs, ..., n_stack * frame_size)`
 - Uses `np.roll` to shift frames and add new observations
 - Handles episode termination by zeroing stacked frames
 - Preserves `terminal_observation` in info dictionaries

## Integration with Algorithms

 Environment wrappers are commonly used with off-policy algorithms that support `VecNormalize`. Algorithms provide a `get_vec_normalize_env()` method to access the wrapper.

 
| Algorithm | VecNormalize Support | Usage Pattern |
|---|---|---|
| DDPG | ✓ | model.get_vec_normalize_env() |
| DQN | ✓ | model.get_vec_normalize_env() |
| SAC | ✓ | model.get_vec_normalize_env() |
| TD3 | ✓ | model.get_vec_normalize_env() |

## Custom Wrapper Creation

 Custom wrappers should inherit from `VecEnvWrapper` and implement the required methods:

 
 - `step_wait()`: Process step results
 - `reset()`: Process reset results
 - `close()`: Clean up resources (optional)
 
 The wrapper pattern allows for modular composition of environment transformations while maintaining the vectorized environment interface.
