## Output Format Writers

 The logging system implements four primary output formats through specialized writer classes that implement the `KVWriter` interface for key-value data and `SeqWriter` interface for sequential data.

 
### Format Types and Implementation

 
| Format | Writer Class | Output File | Use Case |
|---|---|---|---|
| Human-readable | HumanOutputFormat | log.txt | Console output and readable logs |
| JSON | JSONOutputFormat | progress.json | Structured data for analysis |
| CSV | CSVOutputFormat | progress.csv | Spreadsheet-compatible format |
| TensorBoard | TensorBoardOutputFormat | events.* | Real-time monitoring and visualization |

 
### HumanOutputFormat

 The `HumanOutputFormat` creates formatted tables for human-readable output, truncating long values and aligning columns for easy reading.

## Logger Configuration

 The logging system is configured through the `configure()` function, which accepts directory paths and format specifications. Configuration can be controlled through environment variables or direct parameters.

 
### Configuration Parameters

 
| Parameter | Environment Variable | Default | Description |
|---|---|---|---|
| folder | OPENAI_LOGDIR | Temp directory | Log output directory |
| format_strs | OPENAI_LOG_FORMAT | ['stdout', 'log', 'csv'] | Output formats |
| MPI format | OPENAI_LOG_FORMAT_MPI | ['log'] | MPI worker formats |

 The `make_output_format()` function creates appropriate writer instances based on format strings:

 
 - `'stdout'`: Console output using `HumanOutputFormat`
 - `'log'`: File output using `HumanOutputFormat`
 - `'json'`: JSON output using `JSONOutputFormat`
 - `'csv'`: CSV output using `CSVOutputFormat`
 - `'tensorboard'`: TensorBoard output using `TensorBoardOutputFormat`

### Value Averaging Logic

 The `logkv_mean()` function implements incremental averaging to handle multiple calls with the same key:

 
```
new_value = (old_value * count + new_value) / (count + 1)
```

 This allows algorithms to call `logkv_mean()` multiple times per iteration and get the correct average when `dumpkvs()` is called.

## MPI and Distributed Logging

 The logging system handles MPI-based distributed training by creating separate log files for different ranks. Worker processes (rank > 0) use different default formats and add rank suffixes to log files.

 
### MPI Configuration Logic

 
 - Rank 0 (master): Uses full logging format (`stdout,log,csv`)
 - Worker ranks: Use minimal logging (`log` only) with rank suffix
 
 The `mpi_rank_or_zero()` function from `stable_baselines.common.misc_util` determines the current process rank for proper log file naming.
