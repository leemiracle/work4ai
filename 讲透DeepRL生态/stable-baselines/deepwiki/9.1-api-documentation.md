### Method Signatures

 
#### `learn(total_timesteps, callback=None, log_interval=100, tb_log_name="run", reset_num_timesteps=True)`

 Primary training method for all algorithms.

 
 - **total_timesteps**: Total number of samples to train on
 - **callback**: Optional callback function called during training
 - **log_interval**: Number of timesteps between logging
 - **tb_log_name**: Name for tensorboard logging
 - **reset_num_timesteps**: Whether to reset timestep counter
 
 
#### `predict(observation, state=None, mask=None, deterministic=False)`

 Generate actions from trained policy.

 
 - **observation**: Current environment observation
 - **state**: Hidden state for recurrent policies
 - **mask**: Action mask for invalid actions
 - **deterministic**: Whether to use deterministic or stochastic policy
 - **Returns**: `(actions, states)` tuple
 
 
#### `save(save_path)` / `load(load_path, env=None, custom_objects=None, **kwargs)`

 Model persistence methods.

### Architecture Specification

 The `net_arch` parameter controls neural network architecture:

 
 - **Shared layers**: `[128, 128]` - two shared layers of 128 units each
 - **Separate networks**: `[128, dict(vf=[256, 256], pi=[64, 64])]` - shared layer then separate value/policy networks
 - **LSTM integration**: `[64, 'lstm', dict(vf=[32], pi=[32])]` - includes LSTM layer

## Callback System API

 The callback system provides hooks into the training process for monitoring, logging, and custom training logic.

 
### Callback Variables by Algorithm

 Each algorithm exposes different variables through the callback system during training. The following shows common patterns:

 
#### Universal Variables (Available in all algorithms)

 
 - `self` - Algorithm instance
 - `total_timesteps` - Total training timesteps
 - `callback` - Callback instance
 - `log_interval` - Logging frequency
 - `tb_log_name` - TensorBoard log name
 - `writer` - TensorBoard writer
 
 
#### Training Loop Variables

 
 - `obs` - Current observations
 - `actions` - Selected actions
 - `rewards` - Environment rewards
 - `dones` - Episode termination flags
 - `infos` - Environment info dictionaries
 
 
#### Algorithm-Specific Variables

 
 - **On-policy** (PPO2, A2C): `mb_obs`, `mb_rewards`, `mb_actions`, `mb_values`, `mb_dones`
 - **Off-policy** (DQN, SAC): `obses_t`, `obses_tp1`, `batch_idxes`, `td_errors`
 - **Actor-Critic** (DDPG): `actor_loss`, `critic_loss`, `q_value`
 
 **Sources:** [docs/modules/ppo2.rst92-131](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/ppo2.rst#L92-L131) [docs/modules/dqn.rst175-226](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/dqn.rst#L175-L226) [docs/modules/sac.rst160-209](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/sac.rst#L160-L209) [docs/modules/ddpg.rst165-228](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/ddpg.rst#L165-L228)

 
## Algorithm-Specific API Details

 
### DQN-Specific Features

 
 - **Replay Buffer**: Automatic experience replay with configurable buffer size
 - **Double Q-Learning**: Enabled by default, controlled by constructor parameter
 - **Dueling Networks**: Enabled by default for supported policies
 - **Prioritized Experience Replay**: Available through constructor parameters
 
 **Key Parameters:**

 
 - `learning_rate`: Learning rate for optimizer
 - `buffer_size`: Size of replay buffer
 - `learning_starts`: Steps before training begins
 - `train_freq`: Frequency of training updates
 - `target_network_update_freq`: Target network update frequency
 
 **Sources:** [docs/modules/dqn.rst28-40](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/dqn.rst#L28-L40) [docs/modules/dqn.rst112-118](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/dqn.rst#L112-L118)

 
### DDPG-Specific Features

 
 - **Action Noise**: Supports `OrnsteinUhlenbeckActionNoise` and `NormalActionNoise`
 - **Parameter Noise**: Optional `AdaptiveParamNoiseSpec` for exploration
 - **MPI Support**: Multi-process training via OpenMPI
 
 **Key Parameters:**

 
 - `action_noise`: Noise object for exploration
 - `param_noise`: Parameter noise specification
 - `nb_train_steps`: Training steps per rollout
 - `nb_rollout_steps`: Environment steps per rollout
 
 **Sources:** [docs/modules/ddpg.rst60-89](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/ddpg.rst#L60-L89) [docs/modules/ddpg.rst122-136](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/ddpg.rst#L122-L136)

 
### SAC-Specific Features

 
 - **Entropy Regularization**: Automatic entropy coefficient tuning
 - **Double Q-Learning**: Built-in double critic networks
 - **Replay Buffer**: Off-policy learning with experience replay
 
 **Key Parameters:**

 
 - `learning_rate`: Learning rate for all networks
 - `buffer_size`: Replay buffer capacity
 - `tau`: Soft update coefficient for target networks
 - `ent_coef`: Entropy coefficient (can be 'auto' for automatic tuning)
 
 **Sources:** [docs/modules/sac.rst32-48](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/sac.rst#L32-L48) [docs/modules/sac.rst96-102](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/sac.rst#L96-L102)

 
### PPO2-Specific Features

 
 - **Vectorized Environments**: Native support for parallel environment execution
 - **Clipped Surrogate Objective**: PPO clipping mechanism
 - **Value Function Clipping**: Optional value function clipping
 - **Advantage Normalization**: Built-in advantage normalization
 
 **Key Parameters:**

 
 - `n_steps`: Steps per environment per update
 - `n_epochs`: Optimization epochs per update
 - `cliprange`: PPO clipping parameter
 - `cliprange_vf`: Value function clipping parameter
 
 **Sources:** [docs/modules/ppo2.rst14-23](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/ppo2.rst#L14-L23) [docs/modules/ppo2.rst85-91](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/modules/ppo2.rst#L85-L91)
