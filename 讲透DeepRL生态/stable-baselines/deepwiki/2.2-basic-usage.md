## Essential Classes and Methods

 
### BaseRLModel Interface

 All stable-baselines algorithms inherit from `BaseRLModel` and provide a consistent interface:

 
| Method | Purpose |
|---|---|
| learn(total_timesteps) | Train the model for specified timesteps |
| predict(observation) | Get action from trained model |
| save(path) | Save model to disk |
| load(path) | Load model from disk |
| get_env() | Get the training environment |
| set_env(env) | Change the environment |

 **Sources:** [stable_baselines/common/base_class.py](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/common/base_class.py)

 
### Policy Types

 
| Policy Class | Use Case | Input Types |
|---|---|---|
| MlpPolicy | Simple vector observations | Box, Discrete spaces |
| CnnPolicy | Image-based observations | Box (image) spaces |
| LstmPolicy | Sequential/recurrent policies | Any space with memory |

 **Sources:** [stable_baselines/common/policies.py](https://github.com/hill-a/stable-baselines/blob/45beb246/stable_baselines/common/policies.py) [docs/guide/custom_policy.rst6-7](https://github.com/hill-a/stable-baselines/blob/45beb246/docs/guide/custom_policy.rst#L6-L7)
