## Overview

 The training process in stable-baselines follows a standardized pattern implemented across all algorithms through the `BaseRLModel` abstract class. Each algorithm inherits from either `ActorCriticRLModel` for on-policy methods or `OffPolicyRLModel` for off-policy methods, both of which extend `BaseRLModel`. The training process coordinates environment interaction, data collection, neural network updates, and progress monitoring.

## Algorithm-Specific Training Details

 
### Multi-Environment Processing

 All algorithms support vectorized environments for parallel data collection:

 
| Component | Purpose | Implementation |
|---|---|---|
| n_envs | Number of parallel environments | Set during initialization |
| n_batch | Total batch size (n_envs × n_steps) | Computed property |
| Episode buffers | Track per-environment statistics | deque collections |

 
### Target Network Updates

 Off-policy algorithms use target networks with different update strategies:

 
 - **DDPG**: Soft updates every step with τ = 0.001
 - **TD3**: Delayed policy updates with target smoothing
 - **SAC**: Soft value function target updates
 - **DQN**: Hard target network updates every N steps
