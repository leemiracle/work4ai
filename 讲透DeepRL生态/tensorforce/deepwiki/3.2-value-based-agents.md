  This page documents the value-based reinforcement learning agents implemented in the Tensorforce framework. Value-based methods estimate the expected return for states or state-action pairs and derive a policy from these value estimates. For policy gradient methods, see [Policy Gradient Agents](https://deepwiki.com/tensorforce/tensorforce/3.1-policy-gradient-agents), and for hybrid approaches, see [Actor-Critic Agents](https://deepwiki.com/tensorforce/tensorforce/3.3-actor-critic-agents).

 
## Overview of Value-Based Methods

 Value-based methods in reinforcement learning focus on estimating the value function, which represents the expected cumulative reward from a given state or state-action pair. In Tensorforce, these methods primarily work with discrete action spaces and use deep neural networks to approximate the action-value function (Q-function).

### Common Components

 Value-based agents share several key components:

 
 - **Experience Replay Memory**: All value-based agents use a replay memory to store and sample experiences, which helps break correlations between consecutive samples and stabilizes learning.
 - **Target Network**: A separate target network is used for more stable value estimation. The target network is periodically updated from the main network.
 - **Q-Network**: The neural network that approximates the action-value function, mapping states to values for each possible action.
 - **Exploration Strategy**: Typically epsilon-greedy exploration, where random actions are taken with some probability to balance exploration and exploitation.

## Deep Q-Network (DQN)

## Double DQN

 The Double DQN algorithm addresses the overestimation bias in standard DQN by decoupling the selection of actions from their evaluation. It uses the online network to select actions and the target network to evaluate them.

## Advanced Configuration Options

 Value-based agents support a wide range of configuration options to fine-tune their behavior:

 
| Parameter | Description | Default |
|---|---|---|
| update_frequency | How often to update the network | 0.25 * batch_size |
| start_updating | Number of timesteps before first update | None |
| huber_loss | Huber loss threshold for more robust optimization | None |
| horizon | n-step return horizon | 1 |
| predict_terminal_values | Whether to predict the value of terminal states | False |
| target_update_weight | How much to update the target network | 1.0 |
| target_sync_frequency | How often to sync the target network | 1 |
| state_preprocessing | State preprocessing configuration | 'linear_normalization' |
| l2_regularization | L2 regularization weight | 0.0 |
| variable_noise | Standard deviation of noise added to variables | 0.0 |

## Summary

 Value-based agents in Tensorforce provide implementations of key deep reinforcement learning algorithms for discrete action spaces. They share common components such as experience replay memory and target networks, but differ in how they approach value estimation:

 
 - **DQN**: Basic deep Q-learning with experience replay and target networks
 - **Double DQN**: Reduces overestimation bias through decoupled action selection and evaluation
 - **Dueling DQN**: Improves value estimation with separate state value and action advantage computations
 
 All three agent types are implemented as specialized configurations of the general `TensorforceAgent` class, demonstrating the modular design of the Tensorforce framework.
