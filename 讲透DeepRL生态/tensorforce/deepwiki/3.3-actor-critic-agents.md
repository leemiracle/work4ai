  This page documents the Actor-Critic family of reinforcement learning agents implemented in Tensorforce. These agents combine policy-based and value-based approaches, featuring both an "actor" that determines actions and a "critic" that evaluates states or state-action pairs. For value-based agents like DQN, see [Value-Based Agents](https://deepwiki.com/tensorforce/tensorforce/3.2-value-based-agents), and for pure policy gradient methods, see [Policy Gradient Agents](https://deepwiki.com/tensorforce/tensorforce/3.1-policy-gradient-agents).

 
## Overview of Actor-Critic Methods

 Actor-Critic methods are a fundamental family of reinforcement learning algorithms that combine:

 
 - An **Actor** network that learns a policy to select actions
 - A **Critic** network that evaluates states or state-action pairs
 
 This architecture allows for more stable learning compared to pure policy gradient methods while maintaining the ability to work with both discrete and continuous action spaces.

### Standard Actor-Critic (AC)

 The basic Actor-Critic implementation uses:

 
 - A stochastic policy network (actor) to select actions
 - A critic network to estimate state values (V-function)
 - Policy gradient objective for optimization
 - Early horizon value prediction
 
 
### Advantage Actor-Critic (A2C)

 The A2C variant extends the basic Actor-Critic by:

 
 - Using advantage estimation for more stable updates
 - Computing how much better an action is compared to the average action
 - Otherwise using the same policy and critic architecture as standard AC
 
 
### Deterministic Policy Gradient (DPG/DDPG)

 The DPG agent (also known as DDPG - Deep Deterministic Policy Gradient):

 
 - Uses a deterministic policy that outputs actions directly
 - Uses a critic to estimate action-values (Q-function)
 - Only works with continuous action spaces
 - Uses late horizon value prediction
 - Uses a replay memory buffer like DQN

|---|---|---|---|
| Policy Type | Stochastic | Stochastic | Deterministic |
| Value Function | State-Value (V) | State-Value (V) | Action-Value (Q) |

| Memory Type | Recent | Recent | Replay |
| Objective | policy_gradient | policy_gradient | deterministic_policy_gradient |
| Required Parameters | states, actions, batch_size | states, actions, batch_size | states, actions, memory, batch_size |

### Agent Memory Requirements

 Actor-Critic agents differ in their memory requirements:

 
 - AC and A2C use a `recent` memory type, which only needs to store the most recent experiences
 - DPG uses a `replay` memory type, which must be large enough to store many experiences for sampling
 
 DPG, like DQN, requires a memory parameter because it uses experience replay, while AC and A2C update based on recent experiences and don't need a large buffer.
