  The Runner system is a core component of the Tensorforce framework that orchestrates the interaction between reinforcement learning agents and environments. It provides a high-level interface for executing training and evaluation experiments, collecting statistics, and monitoring progress. For information about creating agents, see [Agent Architecture](https://deepwiki.com/tensorforce/tensorforce/2.1-agent-architecture), and for details on environments, see [Environment Interface](https://deepwiki.com/tensorforce/tensorforce/2.2-environment-interface).

 
## Core Components and Functionality

 The Runner class serves as the execution manager for reinforcement learning experiments. It coordinates the agent's decision-making process with the environment's state transitions, handling both the training loop and evaluation scenarios.

## Statistics and Progress Tracking

 The Runner collects and reports various statistics during execution:

 
| Statistic | Description |
|---|---|
| Episode returns | Cumulative rewards per episode |
| Episode timesteps | Number of timesteps per episode |
| Episode seconds | Wall time duration per episode |
| Agent seconds | Time spent in agent computation |
| Environment seconds | Time spent in environment (remote modes) |

 The Runner integrates with tqdm to display a progress bar with real-time statistics:

 
```
Episodes: 42/100 [=====>........................] - ETA: 2:14 - return=127.55, stddev=43.21, ts/ep=312, sec/ep=0.25, ms/ts=0.8, agent=63.4%
```

## Summary

 The Runner system is a versatile component of Tensorforce that simplifies the execution of reinforcement learning experiments. It handles the interaction loop between agents and environments, supports various parallel execution modes for efficiency, and provides features for monitoring training progress and evaluating agent performance.
