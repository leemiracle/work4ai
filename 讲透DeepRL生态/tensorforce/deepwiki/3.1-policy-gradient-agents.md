  This page covers the policy gradient family of reinforcement learning algorithms implemented in Tensorforce. Policy gradient methods directly optimize a parameterized policy by computing gradients of the expected return with respect to policy parameters. Unlike [Value-Based Agents](https://deepwiki.com/tensorforce/tensorforce/3.2-value-based-agents) which learn a value function and derive a policy implicitly, policy gradient methods can learn stochastic policies and are naturally suited for continuous action spaces.

 
## Overview of Policy Gradient Agents in Tensorforce

 Tensorforce implements several policy gradient algorithms, each with different characteristics and optimization approaches:

 
 - **VPG (Vanilla Policy Gradient)** - The classic policy gradient method, also known as REINFORCE
 - **PPO (Proximal Policy Optimization)** - Uses a clipped surrogate objective for stable learning
 - **TRPO (Trust Region Policy Optimization)** - Uses natural gradient to optimize within a trust region
 - **DPG (Deterministic Policy Gradient)** - Learns deterministic policies for continuous action spaces

## Algorithm Details

 
### Vanilla Policy Gradient (VPG)

 VPG/REINFORCE is the most basic policy gradient algorithm. It uses the simplest form of the policy gradient:

 
```
∇J(θ) = E[∇log π(a|s) * G]
```

 where G is the return (discounted sum of rewards).

 Key implementation features:

 
 - Episode-based batch updates
 - Optional baseline (state-value function) to reduce variance
 - Simple policy gradient objective without importance sampling

## Comparison of Policy Gradient Agents

 
| Agent | Key Features | Best For | Limitations |
|---|---|---|---|
| VPG | Simple implementation, episode-based | Simple problems, educational purposes | Sample inefficient, high variance |
| PPO | Clipped surrogate objective, multiple updates | General RL problems, stable learning | Hyperparameter sensitivity |
| TRPO | Natural gradient, trust region, line search | Problems requiring careful updates | Computationally expensive |
| DPG | Deterministic policies, experience replay | Continuous control tasks | Only for continuous action spaces |
