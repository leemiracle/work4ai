## Purpose and Scope

 This document describes the nest and tensor utilities in TF-Agents, which provide essential functionality for manipulating nested data structures and tensors throughout the reinforcement learning workflow. These utilities are fundamental building blocks that support the handling of complex data structures flowing between environments, agents, networks, and policies. The utilities primarily handle tasks such as structure validation, batching/unbatching, and tensor shape manipulation that are necessary when working with reinforcement learning data.

 Sources: [tf_agents/utils/nest_utils.py16-17](https://github.com/tensorflow/agents/blob/2a236d30/tf_agents/utils/nest_utils.py#L16-L17)

 
## Nested Structures in TF-Agents

 In TensorFlow and TF-Agents, "nests" refer to hierarchically structured data composed of Python dictionaries, lists, tuples, and their combinations, with tensors or numpy arrays as leaf nodes. These nested structures are central to TF-Agents as they represent complex data like observations, actions, and other agent-related information.

 The nest utilities in TF-Agents build upon TensorFlow's `tf.nest` module, extending it with additional functionality specific to reinforcement learning needs.

 
```

```

 The nest utilities provide functions for traversing, validating, transforming, and manipulating these nested structures which are essential when:

 
 - Comparing structure compatibility between data and specifications
 - Adding or removing batch dimensions for processing in networks
 - Flattening structures for vectorized operations
 - Restructuring data to match expected formats

## Core Nest Utilities

 
### Structure Validation

 Structure validation utilities ensure that nested data structures conform to expected formats, which is crucial for reliable data flow in TF-Agents.

 
```

```

 Key validation functions include:

 
 - `assert_same_structure`: An enhanced version of TensorFlow's assertion function that provides clearer error messages when structures don't match
 - `prune_extra_keys`: Removes keys from a wider structure that don't appear in a narrower one, useful for preprocessing before comparisons
 - `assert_tensors_matching_dtypes_and_shapes`: Verifies both structure and tensor properties match
 - `assert_matching_dtypes_and_inner_shapes`: Checks that tensors match their corresponding specs

## Tensor Batching and Manipulation

 
### Batching Operations

 Batching is a fundamental operation in deep learning for processing multiple examples simultaneously. The nest utilities provide functions to add or remove batch dimensions across all tensors in nested structures.

 Key batching functions:

 
 - `batch_nested_tensors`: Adds a batch dimension to tensors that don't already have one
 - `unbatch_nested_tensors`: Removes the batch dimension from tensors
 - `is_batched_nested_tensors`: Determines whether tensors already have batch dimensions

## Integration with TF-Agents Components

 The nest and tensor utilities serve as essential infrastructure throughout TF-Agents, facilitating data flow between components.

 
```

```

 Key integration points:

 
 - **Networks**: In `Network.__call__`, nest utilities validate input and state tensors against their specs and ensure proper tensor shapes.
 - **Policies**: When selecting actions, policies use nest utilities to batch observations and unbatch the resulting actions.
 - **Drivers**: When collecting experience, drivers use nest utilities to transform data between environments and agents.
 - **Replay Buffers**: For storing and sampling experience, replay buffers rely on utilities to manipulate batch dimensions.

## Special Features

 
### Tensor Normalization

 The tensor normalization utilities provide mechanisms to standardize tensor values, which is crucial for stable learning in reinforcement learning:

 
 - `EMATensorNormalizer`: Uses exponential moving average to track and normalize tensor statistics
 - `StreamingTensorNormalizer`: Tracks the full history of tensor values for normalization
 
 
```

```

 These normalizers help manage numerical stability when dealing with observations and rewards of varying scales.
