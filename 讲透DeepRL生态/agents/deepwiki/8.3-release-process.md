## Purpose and Scope

 This document describes the process for creating and publishing releases of the TF-Agents library. It covers both stable and nightly release workflows, including version management, building packages, testing, and publishing to PyPI. For information about building and installing TF-Agents, see [Build and Installation](https://deepwiki.com/tensorflow/agents/8.1-build-and-installation).

 
## Release Types

 TF-Agents supports two types of releases:

 
 - **Stable Releases**: Versioned releases (e.g., v0.19.0) that are tested against specific versions of TensorFlow and other dependencies.
 - **Nightly Releases**: Development builds published as `tf-agents-nightly` that work with nightly builds of dependencies.

 TF-Agents releases are aligned with specific versions of TensorFlow and Reverb, as shown in the table below:

### 1. Preparing for a Release

 To prepare for a new release:

 
 - Update version numbers in `tf_agents/version.py`: 
 - For a new release, modify `_MAJOR_VERSION`, `_MINOR_VERSION`, or `_PATCH_VERSION` as needed
 - For a stable release, set `_REL_SUFFIX = ''`
 - For a release candidate, set `_REL_SUFFIX = 'rcN'` (where N is the candidate number)
 
 Sources: [tf_agents/version.py18-29](https://github.com/tensorflow/agents/blob/2a236d30/tf_agents/version.py#L18-L29)

### 4. Publishing the Release

 For stable releases:

 
 - Upload the wheel to PyPI
 - Create a GitHub tag matching the version (e.g., `v0.19.0`)
 - Update the releases table in `README.md` and `docs/overview.md`
 
 For nightly releases:

 
 - Typically handled through automated CI/CD processes
 - Uses `__dev_version__` with a date stamp

## Handling Different Python Versions

 TF-Agents supports multiple Python versions, as specified in the setup.py classifiers:

 
 - Python 3.8
 - Python 3.9
 - Python 3.10
 - Python 3.11
 
 Important version compatibility notes:

 
 - 0.18.0 dropped Python 3.8 support
 - 0.16.0 was the first version to support Python 3.11
 - 0.15.0 was the last release compatible with Python 3.7
 - 0.9.0 was the last release compatible with Python 3.6
 - 0.3.0 was the last release compatible with Python 2.x
