  This page provides a detailed technical documentation of actor-critic agents implemented in TF-Agents. Actor-critic methods combine value-based and policy-based reinforcement learning approaches, making them suitable for environments with continuous action spaces. This page covers the Soft Actor-Critic (SAC), Deep Deterministic Policy Gradient (DDPG), and Twin Delayed DDPG (TD3) implementations. For policy gradient methods like REINFORCE or PPO, see [Policy-Gradient Agents](https://deepwiki.com/tensorflow/agents/3.2-policy-gradient-agents).

 
## Actor-Critic Architecture Overview

 Actor-critic agents consist of two main components:

 
 - An **actor** (policy) that determines which actions to take
 - A **critic** that evaluates the quality of state-action pairs

 The actor's responsibility is to select actions based on the current observation, while the critic's role is to evaluate how good these actions are by estimating Q-values or state values. The actor is trained to maximize these estimated values, and the critic is trained to better estimate returns.

## Soft Actor-Critic (SAC)

 Soft Actor-Critic is an off-policy actor-critic algorithm that maximizes both the expected return and entropy (encouraging exploration).

 
### Key Features

 
 - **Stochastic Policy**: Outputs a distribution over actions, not deterministic actions
 - **Entropy Regularization**: Encourages exploration with an entropy bonus in the objective
 - **Automatic Temperature Tuning**: Adjusts the entropy weight automatically
 - **Double Critics**: Uses two critic networks to mitigate overestimation bias

### Implementation Details

 The SAC agent in TF-Agents includes:

 
 - `SacAgent` class that manages the actor and critic networks
 - `actor_network` for generating an action distribution
 - `critic_network_1` and `critic_network_2` for evaluating state-action pairs
 - Target networks for both critics
 - Three optimizers: actor, critic, and alpha
 - Three loss functions: 
 - `critic_loss`: TD error using minimum of target critic values
 - `actor_loss`: Encourages maximizing Q-values and entropy
 - `alpha_loss`: Adjusts entropy weight automatically
 
 Train method workflow:

 
 - Compute critic loss using target networks and minimum of two Q-values
 - Update critic networks
 - Compute actor loss to maximize Q-values and entropy
 - Update actor network
 - Compute alpha loss to adjust the entropy weight
 - Update alpha parameter
 - Soft update target networks

## Deep Deterministic Policy Gradient (DDPG)

 DDPG is an off-policy actor-critic algorithm that combines ideas from DQN and deterministic policy gradients, designed for continuous action spaces.

 
### Key Features

 
 - **Deterministic Policy**: Directly outputs actions instead of a distribution
 - **Experience Replay**: Uses a replay buffer to store and sample transitions
 - **Target Networks**: Maintains separate target networks for stability
 - **Exploration Noise**: Adds Ornstein-Uhlenbeck noise for exploration

## Twin Delayed DDPG (TD3)

 TD3 extends DDPG with three key improvements to address function approximation error:

 
 - **Clipped Double Q-learning**: Uses two critic networks and takes the minimum
 - **Delayed Policy Updates**: Updates the policy less frequently than the critics
 - **Target Policy Smoothing**: Adds noise to actions for target value calculation

## Performance Considerations

 When choosing between these actor-critic algorithms:

 
 - **SAC**: Best for most continuous control tasks, especially those requiring exploration
 - **DDPG**: Simpler implementation, but can be unstable during training
 - **TD3**: More stable than DDPG, but may be more complex to tune
 
 All algorithms are designed for continuous action spaces, with SAC supporting stochastic policies while DDPG and TD3 use deterministic policies.

 
## Conclusion

 Actor-critic agents in TF-Agents combine policy-based and value-based learning approaches, making them suitable for complex control tasks with continuous action spaces. SAC, DDPG, and TD3 each offer different trade-offs in terms of stability, sample efficiency, and performance. Their implementations in TF-Agents follow a consistent design pattern, making it straightforward to switch between algorithms when experimenting.
