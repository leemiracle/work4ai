## Purpose and Scope

 This document describes two bandit agent implementations in TF-Agents that balance exploration and exploitation: Neural Epsilon Greedy Agent and Dropout Thompson Sampling Agent. Both extend the Greedy Reward Prediction Agent and use neural networks for reward prediction but employ different exploration strategies. For information about the base greedy agent, see [Greedy Reward Prediction](https://deepwiki.com/tensorflow/agents/4.1-greedy-reward-prediction).

 
## Overview

 Neural Epsilon Greedy and Dropout Thompson Sampling agents address the exploration-exploitation dilemma in bandit problems by incorporating uncertainty in different ways:

 
 - **Neural Epsilon Greedy Agent**: Chooses the greedy action with probability `1-ε` and a random action with probability `ε`.
 - **Dropout Thompson Sampling Agent**: Uses neural network dropout to approximate Thompson sampling, providing a Bayesian approach to exploration.

## Dropout Thompson Sampling Agent

 The Dropout Thompson Sampling Agent approximates Bayesian Thompson sampling using dropout in neural networks.

 
### Key Features

 
 - Uses dropout as a Bayesian approximation for uncertainty estimation
 - Can use dropout in all layers or just the top layer
 - Supports heteroscedastic networks for variance prediction
 - Configurable dropout rate and network architecture

## Comparison of Exploration Strategies

 
| Feature | Neural Epsilon Greedy | Dropout Thompson Sampling |
|---|---|---|
| Exploration Method | Explicit random actions | Implicit through network uncertainty |
| Uncertainty Model | None | Bayesian approximation with dropout |
| Configuration Complexity | Simple (epsilon parameter) | More complex (dropout rate, network layers) |
| Computational Cost | Lower | Higher (due to dropout operations) |
| Adaptation to Data | Fixed exploration rate | Exploration adapts to prediction uncertainty |
| Heteroscedastic Option | No | Yes (can model reward variance) |

## Conclusion

 Neural Epsilon Greedy and Dropout Thompson Sampling agents provide different approaches to the exploration-exploitation tradeoff in bandit problems:

 
 - **Neural Epsilon Greedy** offers a simple, configurable approach with explicit random exploration
 - **Dropout Thompson Sampling** provides a more sophisticated Bayesian approximation that adapts exploration based on uncertainty
 
 Both build on the base `GreedyRewardPredictionAgent` to leverage neural networks for reward prediction while adding their own exploration strategies.
