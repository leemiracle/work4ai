## Overview

 TF-Agents provides multiple installation methods to accommodate different user needs. You can install:

 
 - Pre-built stable releases from PyPI
 - Nightly builds with the latest features
 - Custom builds from source with specific dependencies
 
 TF-Agents supports Python 3.8+ (with Python 3.11 requiring pygame 2.1.3+) and is primarily designed to work on Linux systems when using Reverb, which is a common use case.

## Dependencies and Compatibility

 TF-Agents depends on several packages with specific version requirements. The core dependencies are managed in the `setup.py` file.

 
### Core Dependencies

 
| Package | Version Requirement | Notes |
|---|---|---|
| absl-py | >= 2.0.0 | Command line flags and logging |
| cloudpickle | >= 3.0.0 | Object serialization |
| gin-config | >= 0.5.0 | Configuration framework |
| gym | >= 0.17.0, <= 0.23.1 | OpenAI Gym environments |
| gymnasium | >= 0.29.0 | Modern Gym replacement |
| numpy | >= 1.26.2 | Numerical computation |
| pillow | >= 10.1.0 | Image processing |
| protobuf | >= 3.11.3, <= 4.23.4 | Protocol buffers |
| typing-extensions | == 4.5.0 | Type hints |
| pygame | == 2.5.2 | Used by gym environments |
| tf-keras | varies by release | Keras implementation |

## Troubleshooting

 
### Common Installation Issues

 
 - **Incompatible dependencies**: If you see dependency conflicts, try installing dependencies manually before installing TF-Agents:

 
```

```
 - **Platform limitations**: Reverb integration only works on Linux. If you need Reverb on other platforms, consider using Docker or WSL on Windows.
 - **Python version compatibility**: Ensure you're using a supported Python version:

 
 - Python 3.11+ support starts from TF-Agents 0.16.0
 - Python 3.7 support ends with TF-Agents 0.15.0
 - Python 3.6 support ends with TF-Agents 0.9.0
 - **Old numpy versions**: If using numpy < 1.19, use TF-Agents 0.15.0 or earlier.
 - **Missing pygame dependencies**: If using Gym environments with rendering, you may need to install system packages:
