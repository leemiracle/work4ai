  This page documents the `GreedyRewardPredictionAgent`, a neural network-based bandit agent in TF-Agents that predicts rewards for actions and selects them greedily. It serves as a foundation for other bandit agents that use reward prediction, such as `NeuralEpsilonGreedyAgent` and `DropoutThompsonSamplingAgent`.

 For information about other bandit algorithms like Neural LinUCB, see [Neural LinUCB](https://deepwiki.com/tensorflow/agents/4.2-neural-linucb).

 
## Architecture Overview

 The `GreedyRewardPredictionAgent` is a specialized reinforcement learning agent designed for bandit problems. It uses a neural network to predict the reward for each action given an observation, then selects the action with the highest predicted reward.

## Training Process

 The `GreedyRewardPredictionAgent` is trained using experience data, which consists of observations, actions, and rewards. The training process involves:

 
 - **Experience Processing**: The experience is processed using `process_experience_for_neural_agents()` to extract observations, actions, and rewards.
 - **Loss Computation**: The agent computes the loss between predicted and actual rewards.
 - **Parameter Updates**: The optimizer updates the reward network parameters to minimize the loss.

### Loss Computation

 The loss is computed in the `per_example_reward_loss` method, which:

 
 - Gets reward predictions from the network for the given observations
 - Indexes the predictions using the actions that were taken
 - Computes the error between the predicted and actual rewards
 - Applies optional Laplacian smoothing regularization
 - Returns the per-example loss
 
 For heteroscedastic networks (which predict both mean and variance), the loss also includes uncertainty terms.

## Key Features

 
### Reward Network

 The core of the agent is the reward network, which predicts rewards for actions given observations. This network can be any TensorFlow network that outputs predictions for all possible actions.

### Action Constraints

 The agent supports action constraints through the `observation_and_action_constraint_splitter` parameter, which:

 
 - Takes an observation as input
 - Returns a tuple of (observation, action_mask)
 - The action_mask indicates which actions are valid in the current state
 
 This is useful for problems where some actions may be unavailable in certain states.

### Per-Arm Features

 The agent supports contextual bandits with per-arm features, where each action has its own set of features. When `accepts_per_arm_features` is `True`:

 
 - The observation is expected to contain per-arm feature data
 - The training process handles these features appropriately
 - The agent maintains a separate count of samples (instead of per-action counts)

### Laplacian Smoothing

 For problems where actions have a graph structure (e.g., when actions are related to each other), the agent supports Laplacian smoothing. This regularization technique encourages the reward estimates for related actions to be similar.

 The Laplacian smoothing adds a regularization term to the loss:

 
```
Loss_new := Loss + lambda * r^T * L * r
```

 where:

 
 - `r` is the vector of predicted rewards
 - `L` is the Laplacian matrix of the action graph
 - `lambda` is the Laplacian smoothing weight

### Training Data Tracking

 The agent can optionally track the number of samples seen for each action using the `num_samples_list` parameter, which:

 
 - Is a list of TensorFlow variables, one per action (or a single variable for per-arm features)
 - Gets updated during training to count the number of times each action was taken
 - Can be useful for debugging and analyzing the agent's exploration behavior

## Related Agents

 
### NeuralEpsilonGreedyAgent

 The `NeuralEpsilonGreedyAgent` extends `GreedyRewardPredictionAgent` by adding epsilon-greedy exploration:

 
 - With probability `1 - epsilon`, selects the greedy action
 - With probability `epsilon`, selects a random action
 - Uses the same reward prediction network and training process

### DropoutThompsonSamplingAgent

 The `DropoutThompsonSamplingAgent` implements Thompson sampling using dropout neural networks:

 
 - Uses the reward prediction network with dropout layers
 - Dropout introduces stochasticity that approximates posterior sampling
 - The dropout rate controls the exploration-exploitation trade-off
 - Can be configured to apply dropout to all layers or only the top layer
 - Supports heteroscedastic networks for better uncertainty estimation

## Implementation Details

 
### Agent Initialization

 When initialized, the agent:

 
 - Creates variables for the reward network
 - Sets up the policy with the reward network
 - Configures tracking for training data if requested
 - Validates the Laplacian matrix if provided
 
 Sources:

 
 - [tf_agents/bandits/agents/greedy_reward_prediction_agent.py147-228](https://github.com/tensorflow/agents/blob/2a236d30/tf_agents/bandits/agents/greedy_reward_prediction_agent.py#L147-L228)
 
 
### Training Data Processing

 For standard observations, the agent extracts observations, actions, and rewards directly. For per-arm features, it:

 
 - Extracts the chosen arm features from policy info
 - Places these features in the per-arm observation field
 - Sets the action to zero (since there's effectively one action per sample)
 - Updates the num_actions feature if present
 
 This approach allows the agent to train effectively on contextual bandit problems with per-arm features.
