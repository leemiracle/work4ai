  This page documents the Python environment wrappers available in TF-Agents. Environment wrappers allow you to modify the behavior of reinforcement learning environments without changing their core implementation. They follow a composition pattern where each wrapper adds specific functionality while maintaining the original environment API. For information about Gym integration, see [Gym Integration](https://deepwiki.com/tensorflow/agents/5.2-gym-integration).

 
## Overview

 Environment wrappers in TF-Agents inherit from the base class `PyEnvironmentBaseWrapper` and enable various modifications to environment behavior such as:

 
 - Limiting episode length
 - Modifying observations or actions
 - Collecting statistics
 - Implementing performance profiling
 - Discretizing continuous action spaces

## Implementation Details

 All wrappers follow a consistent pattern:

 
 - They inherit from `PyEnvironmentBaseWrapper`
 - They override the necessary methods to modify behavior (typically `_step` and/or `_reset`)
 - They may override `observation_spec()` or `action_spec()` if they change the observation or action space
 
 Many wrappers are decorated with `@gin.configurable` to allow easy configuration through Gin dependency injection.

 The `handle_auto_reset` parameter in the wrapper constructors controls whether the wrapper should automatically reset the environment when a terminal state is reached and a new action is provided.

 Sources: [tf_agents/environments/wrappers.py](https://github.com/tensorflow/agents/blob/2a236d30/tf_agents/environments/wrappers.py)
