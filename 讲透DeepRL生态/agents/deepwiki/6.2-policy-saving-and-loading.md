## Purpose and Scope

 This document explains how to save and load TF-Agents policies for deployment or continued training. TF-Agents provides tools to convert policies from their TensorFlow representation to SavedModel format and back to usable Python policies. This document covers the `PolicySaver` class, which handles saving TF policies, and the various mechanisms for loading and using saved policies, specifically through the `SavedModelPyTFEagerPolicy` class.

 For information about different policy types available in TF-Agents, see [Policy Types](https://deepwiki.com/tensorflow/agents/6.1-policy-types).

## The PolicySaver Class

 The `PolicySaver` class is the primary tool for saving TF policies to a format that can be easily loaded and deployed. It converts a TensorFlow policy to a SavedModel format, which can be loaded in various environments without needing the full TF-Agents library.

### Saved Policy Structure

 When a policy is saved, it includes:

 
 - **Signatures** - TensorFlow concrete functions for key operations:

 
 - `action` - Get actions from observations
 - `distribution` - Get distributions over actions
 - `get_initial_state` - Initialize policy state
 - `get_train_step` - Get the current training step
 - `get_metadata` - Get saved metadata
 - **Specs file** - `policy_specs.pbtxt` with serialized specs for:

 
 - Time step spec
 - Action spec
 - Policy state spec
 - Info spec
 - **Variables** - All model variables and weights

## Troubleshooting

 
### Missing Specs

 If you encounter errors loading a policy without specs, make sure to:

 
 - Enable `load_specs_from_pbtxt=True`, or
 - Explicitly provide the required specs when creating `SavedModelPyTFEagerPolicy`
 
 
### Distribution Function Errors

 Some policies may not have serializable distribution functions. The system will log a warning when saving such policies, and attempting to call `distribution()` on the loaded model will raise an appropriate error.
