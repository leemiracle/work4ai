  This page documents how TF-Agents integrates with OpenAI Gym environments, allowing you to use popular Gym environments in your reinforcement learning experiments. The integration is primarily handled through the `GymWrapper` class, which adapts Gym environments to implement the TF-Agents `PyEnvironment` interface.

 For information about general environment wrappers, see [Python Environment Wrappers](https://deepwiki.com/tensorflow/agents/5.1-python-environment-wrappers).

 
## Overview

 The Gym integration system provides a seamless way to use the extensive collection of OpenAI Gym environments within the TF-Agents framework. The core components of this integration are:

 
 - `GymWrapper`: Wraps Gym environments to make them compatible with TF-Agents
 - `spec_from_gym_space`: Converts Gym spaces to TF-Agents specs
 - Optional environment wrappers to customize behavior

## GymWrapper

 The `GymWrapper` class is the primary interface for Gym integration. It adapts a Gym environment to work with TF-Agents by:

 
 - Converting Gym spaces to TF-Agents specs
 - Translating between Gym's step/reset API and TF-Agents' TimeStep objects
 - Managing environment states and automatic resets

### Key Methods

 
 - `reset()`: Resets the environment and returns a `TimeStep` with step_type=FIRST
 - `step(action)`: Takes an action and returns a `TimeStep` with the result
 - `observation_spec()`: Returns the observation specification
 - `action_spec()`: Returns the action specification
 - `get_info()`: Returns the info dictionary from the most recent step

### Supported Gym Spaces

 
| Gym Space | TF-Agents Spec | Notes |
|---|---|---|
| Discrete(n) | BoundedArraySpec(shape=(), min=0, max=n-1) | Represents discrete actions/observations |
| MultiDiscrete([n1, n2, ...]) | BoundedArraySpec(shape=(k,), min=0, max=[n1-1, n2-1, ...]) | Multiple discrete dimensions |
| MultiBinary(n) | BoundedArraySpec(shape=(n,), min=0, max=1) | Binary values (0 or 1) |
| Box(low, high, shape) | BoundedArraySpec(shape=shape, min=low, max=high) | Continuous values within bounds |
| Tuple((space1, space2, ...)) | (spec1, spec2, ...) | Tuple of specs |
| Dict({'key1': space1, ...}) | OrderedDict({'key1': spec1, ...}) | Dictionary of specs |

## Common Environment Wrappers for Gym Environments

 While the `GymWrapper` provides basic integration, you often need additional wrappers to customize behavior:

 
| Wrapper | Purpose | Example |
|---|---|---|
| TimeLimit | Ends episodes after specified steps | wrappers.TimeLimit(env, duration=100) |
| ActionRepeat | Repeats actions multiple times | wrappers.ActionRepeat(env, times=4) |
| FlattenObservationsWrapper | Flattens nested observations | wrappers.FlattenObservationsWrapper(env) |
| ActionDiscretizeWrapper | Discretizes continuous actions | wrappers.ActionDiscretizeWrapper(env, limits=10) |
| ActionClipWrapper | Clips actions to valid ranges | wrappers.ActionClipWrapper(env) |
| HistoryWrapper | Adds observation/action history | wrappers.HistoryWrapper(env, history_length=4) |
