  The Specs System in TF-Agents provides a fundamental framework for describing the shape, data type, and constraints of tensors used throughout the reinforcement learning pipeline. It allows different components to communicate expectations about data formats, validate inputs and outputs, and generate appropriate initial values or samples.

 This page covers the core specification classes and utility functions that make up the Specs System. For information about how these specs are used by other components, see [Environments](https://deepwiki.com/tensorflow/agents/2.2-environments), [Policies](https://deepwiki.com/tensorflow/agents/2.3-policies), and [Networks](https://deepwiki.com/tensorflow/agents/2.4-networks).

## Spec Types

 
### TensorSpec and BoundedTensorSpec

 `TensorSpec` is the basic specification for TensorFlow tensors, describing shape, dtype, and an optional name. `BoundedTensorSpec` extends this with minimum and maximum values, which is especially useful for action spaces in reinforcement learning.

 
```

```

 TF-Agents directly uses TensorFlow's built-in `tf.TensorSpec` and `BoundedTensorSpec` classes.

 Sources: [tf_agents/specs/tensor_spec.py41-42](https://github.com/tensorflow/agents/blob/2a236d30/tf_agents/specs/tensor_spec.py#L41-L42)

 
### ArraySpec and BoundedArraySpec

 `ArraySpec` and `BoundedArraySpec` serve the same purpose as their tensor counterparts but for NumPy arrays instead of TensorFlow tensors. These are typically used in environments that operate with NumPy rather than TensorFlow.

 Sources: [tf_agents/specs/tensor_spec.py29](https://github.com/tensorflow/agents/blob/2a236d30/tf_agents/specs/tensor_spec.py#L29-L29)

 
### DistributionSpec

 `DistributionSpec` describes a TensorFlow Probability distribution. This is commonly used when dealing with stochastic policies that output probability distributions over actions rather than deterministic actions.

## Conclusion

 The Specs System is a fundamental building block in TF-Agents that enables different components to communicate their requirements and validate their inputs and outputs. By providing a standardized way to describe tensors, it simplifies the implementation of reinforcement learning algorithms and helps prevent errors due to shape or type mismatches.

 Understanding the Specs System is essential for working with TF-Agents, whether you're implementing custom environments, policies, or networks.
