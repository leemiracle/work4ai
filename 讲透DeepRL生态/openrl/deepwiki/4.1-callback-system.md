  The OpenRL Callback System provides a mechanism for monitoring, customizing, and controlling the reinforcement learning training process. Callbacks allow users to hook into various stages of the training lifecycle to perform actions such as logging metrics, saving model checkpoints, evaluating agent performance, and implementing early stopping conditions.

## Core Callback Classes

 
### BaseCallback

 `BaseCallback` is the foundation of the callback system, providing the interface that all callbacks must implement:

 
 - **Initialization**: `init_callback(agent)` is called when the callback is first initialized with a reference to the agent.
 - **Training Events**: 
 - `on_training_start(locals_, globals_)`: Called when training begins
 - `on_rollout_start()`: Called before collecting a batch of experiences
 - `on_step()`: Called after each environment step
 - `on_rollout_end()`: Called after a batch of experiences is collected
 - `on_training_end()`: Called when training ends
 
 The most important method to implement is `_on_step()`, which should return `True` to continue training or `False` to stop.

 Sources: [openrl/utils/callbacks/callbacks.py14-132](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/openrl/utils/callbacks/callbacks.py#L14-L132)

 
### EventCallback

 `EventCallback` is a callback that triggers another callback when a specific event occurs. It is the base class for callbacks like `EvalCallback` and `EveryNTimesteps`.

 Sources: [openrl/utils/callbacks/callbacks.py133-174](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/openrl/utils/callbacks/callbacks.py#L133-L174)

 
### CallbackList

 `CallbackList` allows multiple callbacks to be used together. It includes a `stop_logic` parameter to control how to determine whether training should stop:

 
 - `"OR"`: Stop if any callback returns `False`
 - `"AND"`: Stop only if all callbacks return `False`
 
 Sources: [openrl/utils/callbacks/callbacks.py176-258](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/openrl/utils/callbacks/callbacks.py#L176-L258)

 
### ConvertCallback

 `ConvertCallback` converts a simple function into a callback object, allowing for functional callbacks.

### Early Stopping Callbacks

 OpenRL provides several callbacks for implementing early stopping conditions:

 
 - **StopTrainingOnRewardThreshold**: Stops training when a specified reward threshold is reached
 - **StopTrainingOnMaxEpisodes**: Stops training after a maximum number of episodes
 - **StopTrainingOnNoModelImprovement**: Stops training if there's no improvement in model performance after a specified number of evaluations
 
 Sources: [openrl/utils/callbacks/stop_callback.py23-153](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/openrl/utils/callbacks/stop_callback.py#L23-L153)

 
### EveryNTimesteps

 Triggers a specified callback every N timesteps, useful for operations that don't need to happen on every step.

## Summary

 The OpenRL Callback System provides a flexible framework for monitoring and customizing the training process. With a variety of built-in callbacks and the ability to create custom ones, users can implement complex training routines and monitoring setups that fit their specific needs.

 Key aspects of the system include:

 
 - A consistent interface for all callbacks through the `BaseCallback` class
 - Built-in callbacks for common tasks like evaluation, checkpointing, and early stopping
 - Support for combining multiple callbacks using `CallbackList`
 - Integration with YAML-based configuration through the `CallbackFactory`
 - Ability to extend the system with custom callbacks
 
 For more information about specific training infrastructure components, see [Replay Buffers](https://deepwiki.com/OpenRL-Lab/openrl/4.2-replay-buffers) and [Drivers](https://deepwiki.com/OpenRL-Lab/openrl/4.3-drivers).
