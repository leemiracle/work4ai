## Base Wrapper Types

 OpenRL provides several base wrapper types that you can extend for your custom environments:

 
| Wrapper Type | Description | Key Method to Override |
|---|---|---|
| BaseWrapper | Basic wrapper for any environment | step(action) |
| BaseObservationWrapper | Modifies observations | observation(observation) |
| BaseRewardWrapper | Modifies rewards | reward(reward) |
| BaseMultiPlayerWrapper | Handles multi-agent settings | get_opponent_action(...) |

## Vectorized Environment Integration

 Custom environments are used with OpenRL's vectorized environment system to enable parallel execution:

 
```

```

 Sources: [openrl/envs/vec_env/sync_venv.py35-355](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/openrl/envs/vec_env/sync_venv.py#L35-L355)

 The vectorized environment system:

 
 - Creates multiple copies of your environment for parallel execution
 - Handles synchronization between environments
 - Batches observations, actions, and rewards
 - Applies common wrappers to all environments
 
 When your custom environment is integrated with this system, it gets these benefits automatically.

 
## Best Practices

 When creating custom environments for OpenRL:

 
 - **Follow the relevant interface** (Gymnasium or PettingZoo) completely
 - **Consider vectorization compatibility** by ensuring your environment can be reset and stepped consistently
 - **Use wrappers for common modifications** rather than building them into your environment
 - **Handle randomness properly** by using the provided seed in reset
 - **Document spaces clearly** to ensure compatibility with neural networks
 
 
## Conclusion

 Creating custom environments in OpenRL allows you to define new reinforcement learning tasks while leveraging the framework's powerful training infrastructure. Whether you're implementing an environment from scratch or wrapping an existing one, OpenRL provides the tools to integrate it smoothly into the training pipeline.

 For environments with special requirements, consider extending the appropriate base wrapper classes to modify observations, rewards, or multi-agent behavior.
