  Value Decomposition Network (VDN) is a multi-agent reinforcement learning algorithm implemented in OpenRL for cooperative tasks where multiple agents need to work together. VDN decomposes a team reward signal into individual agent Q-values by assuming the joint action-value function can be represented as a sum of individual agent value functions.

 This page documents the VDN implementation in OpenRL, covering the algorithm architecture, component interaction, and usage in multi-agent environments.

 
## Core Concept

 The fundamental idea behind VDN is to facilitate multi-agent learning by decomposing a shared team reward into individual agent contributions. This allows each agent to learn its own Q-function while still working toward the team objective.

## Key Components

 
### 1. VDN Algorithm

 The `VDNAlgorithm` class implements the core training logic for VDN. It inherits from `BaseAlgorithm` and provides methods for updating the networks, preparing loss functions, and training.

 Key methods:

 
 - `vdn_update`: Updates networks based on sampled experiences
 - `prepare_loss`: Calculates Q-value losses
 - `train`: Processes data from the replay buffer
 
 The algorithm uses Mean Squared Error (MSE) loss to update Q-values toward target values:

### 2. VDN Network

 The `VDNNetwork` class defines the neural network architecture used by VDN. It processes observations to output Q-values for each agent.

 Key features:

 
 - MLP, CNN, or mixed observation processing
 - Optional recurrent layers (GRU/LSTM)
 - Q-value output for each action
 - Value decomposition via summation

## Implementation Details

 
### Q-value Calculation

 VDN calculates individual agent Q-values and then combines them by summation:

 
 - Each agent produces Q-values for its actions based on its observations
 - The Q-values are reshaped to identify individual agent values
 - The VDNBase module sums these values across the agent dimension
 - This sum represents the joint action-value function

### Loss Calculation

 The training process uses the following steps to calculate loss:

 
 - Calculate current Q-values for selected actions
 - Calculate maximum Q-values for the next state
 - Compute target Q-values: rewards + gamma × max next Q-values
 - Calculate MSE loss between current and target Q-values
 - Backpropagate and update the networks
