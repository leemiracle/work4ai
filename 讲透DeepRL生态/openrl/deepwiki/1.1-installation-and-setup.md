## System Requirements

 Before installing OpenRL, ensure your system meets the following requirements:

 
 - **Python**: Version 3.8 or newer
 - **Operating Systems**: Compatible with Windows, macOS, and Linux
 - **Optional**: NVIDIA GPU with CUDA support for accelerated training

## Troubleshooting

 
### Common Issues

 
 - **Python Version Errors**

 
 - Error: `OpenRL requires Python 3.8 or newer`
 - Solution: Upgrade your Python installation or create a new environment with a supported version
 - **Missing Dependencies**

 
 - Error: `No module named 'xxx'`
 - Solution: Install the missing package with `pip install xxx` or the relevant extension package
 - **CUDA/GPU Issues**

 
 - Error: `CUDA error: no kernel image is available for execution on the device`
 - Solution: Ensure your PyTorch version is compatible with your CUDA installation
 - **Self-Play API Connection Issues**

 
 - Error: `Failed to set sample strategy`
 - Solution: Check if the port is available and not blocked by a firewall
