## Purpose and Scope

 This document describes the opponent pool management system in OpenRL, which handles the creation, storage, selection, and tracking of opponents during self-play training. It is a key component of the [Self-Play System](https://deepwiki.com/OpenRL-Lab/openrl/5-self-play-system) that enables agents to train against evolving opponents. For information about the overall self-play API and implementation, see [Self-Play API](https://deepwiki.com/OpenRL-Lab/openrl/5.2-self-play-api).

 
## Overview

 The opponent pool management system maintains a collection of opponent models that agents can train against. These opponents can be rule-based, previously trained models, or even external agents. The system tracks performance using the TrueSkill rating system, which allows for intelligent selection of appropriate opponents based on their relative strength.

## Battle Results and Rating System

 After each battle, the results are reported back to the API server, which updates the TrueSkill ratings of the participants.

 
### Battle Results

 Battles can end in one of three states:

 
 - WIN: The agent defeated the opponent
 - LOSE: The agent was defeated by the opponent
 - DRAW: The battle ended in a tie
 
 These results are tracked in the `BattleHistory` of each opponent, which keeps count of wins, losses, draws, and total games.

## Summary

 The opponent pool management system in OpenRL provides a flexible and powerful framework for managing opponents in self-play training. It handles opponent creation, storage, selection, and rating, allowing for sophisticated self-play training scenarios. The system's modular design, with customizable sample strategies and rating mechanisms, enables users to tailor the self-play process to their specific needs.
