## Purpose and Scope

 This document covers the implementation and usage of the CartPole environment in OpenRL, a classic control problem commonly used to benchmark reinforcement learning algorithms. We'll walk through how to train and evaluate an agent on this environment using the Proximal Policy Optimization (PPO) algorithm, which is one of the core algorithms provided by OpenRL.

 
## What is CartPole?

 CartPole is a classic control problem where the agent must learn to balance a pole attached to a cart by applying appropriate horizontal forces to the cart. It represents one of the simplest environments for testing reinforcement learning algorithms while still providing enough complexity to demonstrate learning capabilities.

 
### Environment Properties

 **CartPole Environment Details:**

 
| Property | Description |
|---|---|
| Observation Space | 4 continuous values (cart position, cart velocity, pole angle, pole velocity) |
| Action Space | 2 discrete actions (push left or push right) |
| Reward Structure | +1 for each timestep the pole remains upright |
| Episode Termination | Pole angle > 15°, cart position > 2.4 units, or episode length = 500 |
| Success Criteria | Average reward of 475+ over 100 consecutive episodes |

### Key Configuration Parameters

 OpenRL provides many configuration parameters that can be customized for training the CartPole agent. Here are some important ones:

 
| Parameter | Description | Default Value |
|---|---|---|
| env_num | Number of parallel environments | Specified by user (9 in example) |
| total_time_steps | Total training steps | Specified by user (20000 in example) |
| hidden_size | Dimension of hidden layers | 64 |
| lr | Learning rate | 5e-4 |
| gamma | Discount factor | 0.99 |
| gae_lambda | GAE lambda parameter | 0.95 |
| clip_param | PPO clip parameter | 0.2 |
| ppo_epoch | Number of PPO update epochs | 10 |
| use_gae | Use Generalized Advantage Estimation | True |
| entropy_coef | Entropy coefficient for exploration | 0.01 |
| value_loss_coef | Value loss coefficient | 0.5 |
