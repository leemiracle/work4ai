## Detailed Project Descriptions

 
### MQE: Multi-agent Quadruped Environment

 MQE (Multi-agent Quadruped Environment) is a platform for developing and evaluating multi-agent reinforcement learning (MARL) algorithms in realistic and dynamic scenarios involving quadruped robots.

 
```

```

 **Key Features:**

 
 - Realistic physics simulation of quadruped robots
 - Multi-agent scenarios and interactions
 - Benchmark for MARL algorithm development
 
 **Paper:** MQE: Unleashing the Power of Interaction with Multi-agent Quadruped Environment (arXiv, 2024)
 **Authors:** Ziyan Xiong, Bo Chen, Shiyu Huang, Wei-Wei Tu, Zhaofeng He, Yang Gao
 **Links:** [GitHub](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/GitHub) [Project Page](https://ziyanx02.github.io/multiagent-quadruped-environment/)

 Sources: [Project.md6-13](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/Project.md?plain=1#L6-L13)

 
### LLMArena: Multi-Agent LLM Evaluation

 LLMArena is a framework for evaluating Large Language Models (LLMs) in multi-agent dynamic environments. It provides an extensible platform to assess various capabilities of LLMs in interactive scenarios.

 
```

```

 **Key Features:**

 
 - Dynamic multi-agent environments for LLM testing
 - Extensible framework for capability assessment
 - Realistic interaction scenarios
 
 **Paper:** LLMArena: Assessing Capabilities of Large Language Models in Dynamic Multi-Agent Environments (arXiv, 2024)
 **Authors:** Junzhe Chen, Xuming Hu, Shuodi Liu, Shiyu Huang, Wei-Wei Tu, Zhaofeng He, Lijie Wen
 **Links:** [GitHub](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/GitHub)

 Sources: [Project.md15-21](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/Project.md?plain=1#L15-L21)

 
### TiZero: Football Game AI

 TiZero is a reinforcement learning agent designed for the Google Research Football full game. It utilizes distributed self-play training to master multi-agent football environments.

 
```

```

 **Key Features:**

 
 - Advanced football AI agent using RL
 - Distributed self-play training
 - Multi-agent coordination
 
 **Paper:** TiZero: Mastering Multi-Agent Football with Curriculum Learning and Self-Play (AAMAS, 2023)
 **Authors:** Fanqi Lin, Shiyu Huang, Tim Pearce, Wenze Chen, Wei-Wei Tu
 **Links:** [GitHub](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/GitHub)

 Sources: [Project.md23-29](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/Project.md?plain=1#L23-L29)

 
### DGPO: Diversity-Guided Policy Optimization

 DGPO is an on-policy framework for discovering multiple diverse strategies for the same reinforcement learning task, rather than focusing on a single optimal solution.

 
```

```

 **Key Features:**

 
 - Multiple strategy discovery
 - Diversity-guided optimization
 - On-policy framework
 
 **Paper:** DGPO: Discovering Multiple Strategies with Diversity-Guided Policy Optimization (AAAI, 2024)
 **Authors:** Wenze Chen, Shiyu Huang, Yuan Chiang, Tim Pearce, Wei-Wei Tu, Ting Chen, Jun Zhu
 **Links:** [GitHub](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/GitHub)

 Sources: [Project.md32-40](https://github.com/OpenRL-Lab/openrl/blob/4c92aa44/Project.md?plain=1#L32-L40)

 - Include the following information: 
 - Project name and brief description
