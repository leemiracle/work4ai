  The Self-Play API provides a mechanism for managing and selecting opponents during training in competitive or adversarial environments. It enables agents to learn by competing against previous versions of themselves or other agents, following various opponent selection strategies. This page documents the API endpoints, client implementation, and integration with the OpenRL training process.

 For information about opponent pool management specifically, see [Opponent Pool Management](https://deepwiki.com/OpenRL-Lab/openrl/5.1-opponent-pool-management).

## API Server

 The Self-Play API server handles opponent storage, selection, and battle result tracking. It uses Ray Serve for deployment and FastAPI for the REST interface.

 
### Endpoints

 The server provides the following endpoints:

 
| Endpoint | Method | Purpose | Parameters |
|---|---|---|---|
| /set_sample_strategy | POST | Configure opponent selection strategy | sample_strategy (string) |
| /add_opponent | POST | Add an opponent to the pool | opponent_id (string), opponent_info (dict) |
| /get_opponent | GET | Get an opponent based on strategy | None |
| /add_battle_result | POST | Record battle outcome & update ratings | battle_info (dict) |

## API Client

 The `SelfPlayClient` class provides methods to interact with the Self-Play API server. It handles HTTP requests to the server endpoints and processes responses.

 
### Client Methods

 
| Method | Purpose | Parameters |
|---|---|---|
| add_opponent | Register a new opponent | opponent_id (string), opponent_info (dict) |
| get_opponent | Retrieve opponents based on strategy | opponent_players (list) |
| set_sample_strategy | Configure selection strategy | sample_strategy (string) |
| add_battle_result | Report battle outcomes | battle_info (dict) |

 - Opponent metadata (type and other info)
 - Battle history (wins, losses, draws)

## Sample Strategies

 The Self-Play API supports different opponent selection strategies through a strategy pattern:

 
| Strategy | Description |
|---|---|
| RandomOpponent | Randomly selects an opponent from the pool |
| LastOpponent | Selects the most recently added opponent |

 Custom strategies can be implemented by extending the `BaseSampleStrategy` class and implementing the `sample_opponent` method.
