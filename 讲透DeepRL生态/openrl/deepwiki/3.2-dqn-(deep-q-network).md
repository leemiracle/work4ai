## Purpose and Scope

 This page documents the Deep Q-Network (DQN) implementation in OpenRL. It covers the architecture, components, and interactions of the DQN algorithm, as well as how to use it for training agents. DQN is an off-policy reinforcement learning algorithm that uses a neural network to approximate the optimal action-value function (Q-function).

 
## Overview

 DQN in OpenRL follows the standard implementation with several key improvements from the original algorithm, including:

 
 - Target network for stability
 - Experience replay for sample efficiency
 - Configurable network architectures (MLP, CNN, RNN)
 - Epsilon-greedy exploration with annealing
 
 The implementation is modular and allows for customization of various components.

 `DQNModule` serves as a bridge between the algorithm and the neural networks. It manages both the primary Q-network and the target Q-network.

 `QNetwork` is the neural network that approximates the Q-function. It estimates the expected future rewards for taking actions in different states.

 Architecture features:

 
 - Support for various input types (vector, image, mixed)
 - Optional recurrent layers (RNN, GRU, LSTM)
 - Customizable hidden layer sizes

## DQN Algorithm Details

 The DQN implementation follows these key steps:

 
 - **Experience Collection**:

 
 - Select actions using epsilon-greedy policy
 - Interact with environment to collect (state, action, reward, next_state) tuples
 - Store experiences in replay buffer
 - **Training**:

 
 - Sample mini-batches from replay buffer
 - Compute Q-values for current states: Q(s, a)
 - Compute target Q-values: r + γ * max Q'(s', a')
 - Calculate loss: MSE(Q(s, a), target)
 - Update Q-network parameters
 - Periodically update target network

## Epsilon-Greedy Exploration

 The DQN implementation uses an epsilon-greedy policy for exploration, with annealing of the exploration rate over time:

 
```

```

 The epsilon value is calculated based on the current step:

 
```
epsilon = epsilon_finish + (epsilon_start - epsilon_finish) / epsilon_anneal_time * current_step
```

 This gradually transitions from exploration (random actions) to exploitation (greedy actions).

## Configuration Options

 DQN in OpenRL offers numerous configuration options to customize the algorithm:

 
| Parameter | Description | Default |
|---|---|---|
| epsilon_start | Initial exploration rate | 1.0 |
| epsilon_finish | Final exploration rate | 0.05 |
| epsilon_anneal_time | Steps to anneal epsilon | 100000 |
| buffer_size | Replay buffer capacity | 10000 |
| gamma | Discount factor | 0.99 |
| train_interval | Target network update frequency | 100 |
| hidden_size | Hidden layer size | 64 |
| lr | Learning rate | 0.001 |
| recurrent_N | Number of recurrent layers | 1 |
| use_recurrent_policy | Use recurrent network | False |

 These parameters can be adjusted to optimize performance for different environments.
