For information on how to use these classes within the GridWorld environment, see [GridWorld API](https://deepwiki.com/geek-ai/MAgent/9.1-gridworld-api). For examples of creating custom environments, see [Creating Custom Environments](https://deepwiki.com/geek-ai/MAgent/8.1-creating-custom-environments).

 
## Overview

 MAgent's configuration system consists of five primary classes that work together to define multi-agent environments:

 
 - **Config**: The main configuration container
 - **CircleRange / SectorRange**: Define spatial ranges for agent view and attack
 - **AgentSymbol**: Symbolic references to agents in reward rules
 - **EventNode**: AST-like nodes for event expressions
 - **Event**: Singleton for constructing event expressions
 
 These classes are defined in [python/magent/gridworld.py571-801](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/gridworld.py#L571-L801) and work together to create a declarative, research-friendly API for environment configuration.

## EventNode Class

 `EventNode` represents nodes in an Abstract Syntax Tree (AST) for event expressions. Nodes can be leaf nodes (primitive events) or internal nodes (boolean operations).

 
### Operation Codes

 
| Code | Constant | Description |
|---|---|---|
| 0 | OP_AND | Logical AND of two events |
| 1 | OP_OR | Logical OR of two events |
| 2 | OP_NOT | Logical NOT of an event |
| 3 | OP_KILL | Agent kills another agent |
| 4 | OP_AT | Agent is at specific coordinates |
| 5 | OP_IN | Agent is within a rectangular region |
| 6 | OP_COLLIDE | Agent collides with another agent |
| 7 | OP_ATTACK | Agent attacks another agent |
| 8 | OP_DIE | Agent dies |
| 9 | OP_IN_A_LINE | Agents form a line |
| 10 | OP_ALIGN | Agents are aligned |

### Serialization Steps

 The serialization process in `_serialize_event_exp()` performs the following steps:

 
 - **Collect AgentSymbols**: Traverse all reward rules and assign unique integer IDs to each distinct `AgentSymbol`. IDs are stored in `symbol2int` dictionary.
 - **Collect EventNodes**: Traverse the event expression tree and assign unique integer IDs to each distinct `EventNode`. IDs are stored in `event2int` dictionary.
 - **Send Symbol Definitions**: For each AgentSymbol, call `gridworld_define_agent_symbol()` with the assigned ID, group handle, and index.
 - **Send Node Definitions**: For each EventNode, flatten its `inputs` list by replacing AgentSymbols and EventNodes with their integer IDs, then call `gridworld_define_event_node()`.
 - **Send Reward Rules**: For each reward rule, convert the `on` EventNode and `receiver` AgentSymbols to their integer IDs, then call `gridworld_add_reward_rule()`.
