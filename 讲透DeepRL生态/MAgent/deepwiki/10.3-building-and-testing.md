  This document covers the build system for compiling MAgent's C++ engine, running tests to verify installation, performance benchmarking tools, and debugging techniques. For information about the overall codebase structure, see [Codebase Structure](https://deepwiki.com/geek-ai/MAgent/10.1-codebase-structure). For details on the C++ engine implementation, see [C++ Engine Internals](https://deepwiki.com/geek-ai/MAgent/10.2-c++-engine-internals).

 
## Overview

 MAgent requires building native C++ components before the Python API can be used. The build system uses **CMake** to generate platform-specific build files and compile the shared library (`libmagent.so` on Linux, `libmagent.dylib` on macOS). After building, several test scripts verify functionality and measure performance at various scales (from thousands to millions of agents).

### Build Script Components

 The `build.sh` script provides a simple interface for compilation:

 
| Command | Action | Description |
|---|---|---|
| ./build.sh | Build | Compiles C++ engine using all available cores |
| ./build.sh -c | Clean Build | Removes build/, *.log, save_model/ directories before rebuilding |

 **Platform Detection**:

 
 - **Linux**: Uses `nproc` to determine core count for parallel compilation [build.sh12-14](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L12-L14)
 - **macOS**: Uses `sysctl -n hw.ncpu` for core count [build.sh15-18](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L15-L18)
 
 The build process:

 
 - Creates `build/` directory if it doesn't exist [build.sh8](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L8-L8)
 - Changes to `build/` directory [build.sh9](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L9-L9)
 - Runs `cmake ..` to generate makefiles [build.sh10](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L10-L10)
 - Executes `make -j <cores>` for parallel compilation [build.sh14-17](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L14-L17)
 
 **Sources**: [build.sh1-19](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L1-L19)

### Common Build Issues

 
| Issue | Symptom | Solution |
|---|---|---|
| Missing CMake | cmake: command not found | Install CMake: pip install cmake or system package |
| Library not found | OSError: cannot open shared object file | Run ./build.sh from repository root |
| Import error | ImportError: No module named magent | Install Python package: pip install -e . |
| Permission denied | Build directory creation fails | Ensure write permissions or use sudo |
| Platform detection fails | Build script exits silently | Check $OSTYPE environment variable |

 
### Performance Troubleshooting

 **Thread Configuration**:

 
 - Default: `OMP_NUM_THREADS` set to half CPU cores [python/magent/c_lib.py](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/c_lib.py) (referenced in architecture diagrams)
 - Override: `export OMP_NUM_THREADS=<N>` before running scripts [scripts/test/test_fps.py34-36](https://github.com/geek-ai/MAgent/blob/2144dbd4/scripts/test/test_fps.py#L34-L36)
 
 **GPU Memory Issues**:

 
 - Reduce `infer_batch_size` parameter [scripts/test/test_1m.py85-86](https://github.com/geek-ai/MAgent/blob/2144dbd4/scripts/test/test_1m.py#L85-L86)
 - Lower `memory_size` in model configuration [examples/train_against.py195-203](https://github.com/geek-ai/MAgent/blob/2144dbd4/examples/train_against.py#L195-L203)
