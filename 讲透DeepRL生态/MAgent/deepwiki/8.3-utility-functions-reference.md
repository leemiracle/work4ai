## Purpose and Scope

 This document provides comprehensive reference documentation for utility functions and helper classes in the `magent.utility` module. These functions support various aspects of MAgent training and deployment, including experience replay management, hyperparameter scheduling, observation sampling, logging, and model management.

 The utilities covered here are low-level helpers used throughout the training pipeline. For information about higher-level training abstractions, see [Training Workflow](https://deepwiki.com/geek-ai/MAgent/4.1-training-workflow) and [ProcessingModel and Parallelism](https://deepwiki.com/geek-ai/MAgent/4.2-processingmodel-and-parallelism). For detailed information about how experience buffers integrate into the overall training loop, see [Experience Buffers and Sampling](https://deepwiki.com/geek-ai/MAgent/4.6-experience-buffers-and-sampling).

## Decay Schedulers

 MAgent provides three decay schedulers for hyperparameter annealing (e.g., learning rate, exploration epsilon). All schedulers share a common interface pattern.

 
### Exponential Decay

 
```

```

 Implements exponential decay curve: $\text{value} = \max(\text{final_value}, \text{decay}^{\text{now_step}^{\text{rate}}})$

 where $\text{decay} = e^{\frac{\ln(\text{final_value})}{\text{total_step}^{\text{rate}}}}$

 **Parameters:**

 
| Parameter | Type | Description |
|---|---|---|
| now_step | int | Current training step |
| total_step | int | Total training steps (controls decay speed) |
| final_value | float | Minimum value to decay to |
| rate | float | Controls decay curve shape (typically 1.0) |

 **Returns:** Current decayed value (float)

 **Sources:** [python/magent/utility.py79-82](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/utility.py#L79-L82)

 
---

 
### Linear Decay

 
```

```

 Implements linear decay: $\text{value} = \max(\text{final_value}, 1 - \text{decay} \times \text{now_step})$

 where $\text{decay} = \frac{1 - \text{final_value}}{\text{total_step}}$

 **Parameters:**

 
| Parameter | Type | Description |
|---|---|---|
| now_step | int | Current training step |
| total_step | int | Total training steps |
| final_value | float | Minimum value to decay to |

 **Returns:** Current decayed value (float)

 **Sources:** [python/magent/utility.py85-88](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/utility.py#L85-L88)

| anchor_value | list[float] | Values at corresponding anchor points |

 **Algorithm:**

 
 - Find the anchor interval containing `now_step`
 - If beyond last anchor, return last anchor value
 - Otherwise, linearly interpolate between surrounding anchors

### FontProvider

 `FontProvider` loads and provides access to pixel font data for rendering text in visualizations.

 **Data Structure:**

 
```

```

 **Constructor:**

 
```

```

 Loads font data from file, expands bit-compressed format to 8x8 pixel matrices.

 **Attributes:**

 
| Attribute | Type | Description |
|---|---|---|
| data | list[list[list[int]]] | 3D array: [char_index][row][col] |
| width | int | Character width (8) |
| height | int | Character height (8) |

 **Method:**

 
```

```

 Returns 8x8 pixel matrix for character `i` (int index or character string).

 **Bit Expansion Algorithm:**

 
 - For each character's 8 integers [python/magent/utility.py288](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/utility.py#L288-L288)
 - For each of 8 bits in integer [python/magent/utility.py290-291](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/utility.py#L290-L291)
 - Test bit with `char[i] & (1 << j)` [python/magent/utility.py292](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/utility.py#L292-L292)
 - Set corresponding pixel to 1 if bit set [python/magent/utility.py293-294](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/utility.py#L293-L294)
