 **Scope**: This document covers the GridWorld environment class, configuration system (Config, AgentType), and reward definition helpers (EventNode, AgentSymbol, Range classes). For information about training models that interact with GridWorld, see [ProcessingModel API](https://deepwiki.com/geek-ai/MAgent/9.2-processingmodel-api). ## Observation and Action

 
### get_observation(handle)

 
```

```

 Retrieves observations for all agents in a group.

 **Parameters**: `handle` (int) - Group handle

 **Returns**: Tuple of two numpy arrays:

 
| Return Value | Shape | dtype | Description |
|---|---|---|---|
| views | (n, view_height, view_width, n_channels) | float32 | Spatial observations |
| features | (n, feature_size) | float32 | Non-spatial features |

 **Spatial View Channels**:

 The spatial view consists of multiple channels:

 
| Channel Type | Description |
|---|---|
| Wall | Binary indicator (0/1) showing wall positions |
| Group N | Binary indicator for agents of each group |
| HP | Normalized health points (0-1) for visible agents |
| Minimap | Compressed global view (if minimap_mode=True) |

 **Non-spatial Features**:

 
| Feature | Description |
|---|---|
| ID embedding | Binary encoding of agent's unique ID |
| Last action | One-hot encoding of previous action |
| Last reward | Normalized reward from previous step |
| Relative position | Normalized (x, y) position in map |

 **Sources**: [python/magent/gridworld.py221-248](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/gridworld.py#L221-L248) [doc/get_started.md20-36](https://github.com/geek-ai/MAgent/blob/2144dbd4/doc/get_started.md?plain=1#L20-L36)

## Configuration Serialization

 GridWorld internally serializes Python configuration objects to C++ data structures. This process is transparent to users but important for understanding the system.

 
### Event Expression Serialization Flow

 
```

```

 The serialization process (implemented in `_serialize_event_exp()`) performs the following steps:

 
 - **Symbol Collection**: Traverses all reward rules and collects unique `AgentSymbol` instances, assigning each an integer ID
 - **Event Collection**: Recursively traverses event expression trees (`EventNode` objects) and assigns integer IDs
 - **Flattening**: Converts the AST-like structure into flat integer arrays
 - **Transmission**: Sends arrays to C++ engine via ctypes
 - **Reconstruction**: C++ engine rebuilds the reward evaluation logic
 
 **Sources**: [python/magent/gridworld.py493-565](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/gridworld.py#L493-L565)

## Memory Management

 GridWorld maintains internal observation buffers for performance optimization. These buffers are automatically resized as needed when agent counts change.

 **Buffer Initialization**: [python/magent/gridworld.py215-219](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/gridworld.py#L215-L219)

 **Buffer Retrieval**: [python/magent/gridworld.py203-213](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/gridworld.py#L203-L213)

 The buffers persist across steps to avoid repeated allocations, significantly improving performance in large-scale simulations.
