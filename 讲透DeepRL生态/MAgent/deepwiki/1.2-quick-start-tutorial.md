### Training Output Interpretation

 During training, you'll see periodic status updates:

 
```
===== sample =====
eps 0.20 number [256, 256]
step   0,  nums: [256, 256] reward: [0.0, 0.0],  total_reward: [0.0, 0.0]
step  50,  nums: [243, 238] reward: [12.4, 8.7],  total_reward: [234.5, 198.3]
steps: 550,  total time: 8.45,  step average 0.015
===== train =====
train_time 5.23
round 0  loss: [0.45, 0.52]  num: [187, 192]  reward: [1245.3, 1087.6]  value: [3.42, 3.18]
```

 **Metrics Explanation**:

 
| Metric | Description |
|---|---|
| eps | Epsilon value for ε-greedy exploration |
| nums | Number of alive agents in each group |
| reward | Step reward for each group |
| total_reward | Cumulative reward for the episode |
| loss | Training loss for each model |
| value | Estimated value function for each model |

## Key Configuration Concepts

 Before diving deeper into MAgent, it's helpful to understand how environments are configured. This quick reference covers the essentials.

 
### Agent Type Configuration

 Agent types define the physical and behavioral properties of agents:


 Sources: [doc/get_started.md10-18](https://github.com/geek-ai/MAgent/blob/2144dbd4/doc/get_started.md?plain=1#L10-L18)

 
### Observation Structure

 Observations consist of spatial views and non-spatial features:

 **Spatial Channels** (example: 13×13×7):

 
 - Wall channel (binary)
 - Group 1 agents (binary)
 - Group 2 agents (binary)
 - HP channel (normalized 0-1)
 - Minimap (global view, downsampled)
 - Additional custom channels
 
 **Non-spatial Features**:

 
 - Agent ID embedding (binary representation)
 - Last action taken
 - Last reward received
 - Normalized position (x, y)
 
 Sources: [doc/get_started.md20-37](https://github.com/geek-ai/MAgent/blob/2144dbd4/doc/get_started.md?plain=1#L20-L37)

 
### Action Space Structure

 Actions are discrete integers mapping to:

 **Movement Actions**:

 
 - Move to adjacent cells (typically 12 directions)
 - Stay in place
 
 **Turn Actions**:

 
 - Rotate view direction
 
 **Attack Actions**:

 
 - Attack targets within attack_range (typically 8 positions)
 
 **Total Actions**: move_actions + turn_actions + attack_actions (e.g., 13 + 8 + 2 = 23)

## Common Troubleshooting

 
### Training Issues

 
| Problem | Solution |
|---|---|
| Out of memory errors | Reduce infer_batch_size in model configuration |
| Training too slow | Ensure OMP_NUM_THREADS is set; check GPU availability |
| Models not learning | Verify reward configuration; check epsilon decay schedule |
| Agents stuck/not moving | Check view_range and action space configuration |

 
### Visualization Issues

 
| Problem | Solution |
|---|---|
| PyGame window blank | macOS users should use web rendering instead |
| No render files generated | Ensure env.set_render_dir() is called and --render flag is used |
| Web viewer won't connect | Check that render server is running in build/render directory |
