## System Requirements

 MAgent supports **Linux** and **macOS** operating systems. The platform requires both C++ compilation tools for the simulation engine and Python (2.7 or 3.x) for the API layer.

 **Minimum Requirements:**

 
 - CMake 2.8 or higher
 - C++11 compatible compiler (GCC 4.8+, Clang 3.4+, or LLVM)
 - Python 2.7 or Python 3.x
 - 4GB RAM (for small-scale simulations)
 - Multi-core CPU (recommended for parallelization)
 
 **Optional Components:**

 
 - CUDA-compatible GPU (for neural network training)
 - PyGame (for interactive visualization)

 - **C++ Simulation Engine**: Compiled into a shared library (`libmagent.so` or `libmagent.dylib`)

## Build System Details

 
### CMake Configuration

 
```

```

 The build script uses platform detection to optimize compilation:

 
 - **Linux**: `make -j $(nproc)` - uses all available cores
 - **macOS**: `make -j $(sysctl -n hw.ncpu)` - uses all available cores
 
 Sources: [build.sh8-18](https://github.com/geek-ai/MAgent/blob/2144dbd4/build.sh#L8-L18)

 
### Build Directory Structure

 After successful compilation, the following directory structure is created:

 
```
MAgent/
├── build/
│   ├── libmagent.so (or libmagent.dylib on macOS)
│   ├── render/
│   │   ├── render (executable)
│   │   └── assets/
│   └── CMakeFiles/ (build artifacts)
├── python/

│       ├── gridworld.py
```
