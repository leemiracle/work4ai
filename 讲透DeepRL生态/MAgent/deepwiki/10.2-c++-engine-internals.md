## Core Architecture

 The C++ engine consists of two primary classes that work together to implement the simulation:

 
| Class | File | Primary Responsibility |
|---|---|---|
| GridWorld | src/gridworld/GridWorld.cc | Simulation orchestration, agent lifecycle, reward calculation, step execution |
| Map | src/gridworld/Map.cc | Spatial management, collision detection, view extraction, coordinate transformations |

 **Design Pattern**: The engine uses a **separation of concerns** pattern where `GridWorld` manages high-level simulation logic and delegates spatial operations to `Map`.

### Parallel Observation Extraction

 The observation generation is parallelized using OpenMP [src/gridworld/GridWorld.cc363-397](https://github.com/geek-ai/MAgent/blob/2144dbd4/src/gridworld/GridWorld.cc#L363-L397):

 
```
#pragma omp parallel for
for each agent:
    map.extract_view(agent, view_buffer, ...)
    agent.get_embedding(feature_buffer, ...)
    fill last_action, last_reward, coordinates
```

 The `map.extract_view()` call [src/gridworld/Map.cc129-207](https://github.com/geek-ai/MAgent/blob/2144dbd4/src/gridworld/Map.cc#L129-L207) performs the actual spatial query to fill the view tensor.

## Performance Considerations

 
### Cache Optimization

 
 - **Channel IDs extracted**: Separating `channel_ids` from `MapSlot` improves cache locality during view extraction [src/gridworld/Map.h73](https://github.com/geek-ai/MAgent/blob/2144dbd4/src/gridworld/Map.h#L73-L73)
 - **Contiguous arrays**: Using `MapSlot[]` instead of nested structures minimizes cache misses
 - **Row-major ordering**: Memory layout matches typical access patterns
 
 
### Thread Safety

 
 - **Read-only parallel operations**: Observation extraction and starvation checks are read-only on shared data
 - **Spatial partitioning**: Move/turn operations in separate regions can execute without synchronization
 - **Critical sections**: Only map-modifying operations (attack, collision) require locks
 
 
### Algorithmic Efficiency

 
 - **O(1) position queries**: Direct array indexing via `pos2int()`
 - **Compact agent arrays**: `clear_dead()` maintains dense agent vectors for efficient iteration
 - **Random shuffle optimization**: Fisher-Yates shuffle for attack fairness [src/gridworld/GridWorld.cc465-468](https://github.com/geek-ai/MAgent/blob/2144dbd4/src/gridworld/GridWorld.cc#L465-L468)
