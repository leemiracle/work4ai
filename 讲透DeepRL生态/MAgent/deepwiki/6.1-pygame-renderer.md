  The **PyGameRenderer** provides real-time local visualization of MAgent simulations using PyGame. It displays agents, walls, attack events, and simulation statistics in an interactive window with support for zooming, panning, and animation. This renderer is designed for local development, debugging, and creating interactive demos where users can observe or control agents.

 For browser-based remote visualization, see [Web-Based Rendering](https://deepwiki.com/geek-ai/MAgent/6.2-web-based-rendering). For server implementations that provide data to renderers, see [Server Implementations](https://deepwiki.com/geek-ai/MAgent/6.4-server-implementations). For complete interactive demo examples, see [Interactive Demos](https://deepwiki.com/geek-ai/MAgent/6.3-interactive-demos).

## Configuration Parameters

 The `start()` method accepts numerous configuration parameters that control visual appearance, performance, and interaction behavior.

 
### Parameter Categories

 
| Category | Parameters | Purpose |
|---|---|---|
| Display | resolution, full_screen | Window size and display mode |
| Animation | animation_total, animation_stop, fps_soft_bound | Animation smoothness and frame rate |
| Colors | background_rgb, attack_line_rgb, attack_dot_rgb, text_rgb | Visual styling |
| Grid | grid_size, grid_min_size, grid_max_size, grid_rgba | Grid cell dimensions and visibility |
| Zoom/Pan | zoom_rate, move_rate | Camera movement speed |
| Text | text_size, banner_size, bigscreen_size, text_spacing | Font sizes and spacing |
| Attack Visual | attack_dot_size | Size of attack event indicators |

 
### Key Parameters Explained

 **Animation Parameters** [python/magent/renderer/pygame_renderer.py20-21](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/renderer/pygame_renderer.py#L20-L21):

 
 - `animation_total=2`: Number of frames to interpolate between simulation steps
 - `animation_stop=0`: Number of frames to pause after interpolation completes
 - Together these create smooth movement between discrete simulation states

 - `grid_min_size=2`: Minimum zoom level (pixels per cell)
 - `grid_max_size=100`: Maximum zoom level (pixels per cell)
 - Controls how much of the map is visible and level of detail
 
 **Performance Parameters** [python/magent/renderer/pygame_renderer.py23](https://github.com/geek-ai/MAgent/blob/2144dbd4/python/magent/renderer/pygame_renderer.py#L23-L23):

## Comparison to Web Renderer

 
| Feature | PyGameRenderer | Web Renderer |
|---|---|---|
| Deployment | Local Python process | Browser-based |
| Latency | Very low (direct queries) | Higher (WebSocket messages) |
| Interactivity | Immediate (keyboard/mouse) | Limited by network |
| Use Case | Development, debugging, demos | Remote viewing, recording |
| Setup | PyGame installation required | Any modern browser |
| Performance | Limited by single process | Can offload to browser |

 For remote or distributed scenarios, see [Web-Based Rendering](https://deepwiki.com/geek-ai/MAgent/6.2-web-based-rendering).
