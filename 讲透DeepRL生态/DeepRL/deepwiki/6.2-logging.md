## Introduction

 The logging system in the DeepRL framework provides a structured way to track, store, and visualize experimental metrics during reinforcement learning training. It combines traditional file-based logging with TensorBoard integration for advanced visualization and analysis. This page documents the logging architecture, API, and common usage patterns. For information about plotting and visualizing the logged data, see [Plotting and Visualization](https://deepwiki.com/ShangtongZhang/DeepRL/6.3-plotting-and-visualization).

 Sources: [deep_rl/utils/logger.py1-74](https://github.com/ShangtongZhang/DeepRL/blob/c0968b5c/deep_rl/utils/logger.py#L1-L74)

## Logger Initialization

 The `get_logger` function creates a new Logger instance with the following parameters:

 
```

```

 
 - **tag**: Identifier for the experiment, used in file naming
 - **log_level**: Controls which messages get logged (higher numbers filter more messages)
 
 The function configures:

 
 - A console logger (from Python's logging module)
 - A file handler writing to `./log/{tag}-{timestamp}.txt`
 - A TensorBoard writer targeting `./tf_log/logger-{tag}-{timestamp}`
 
 Sources: [deep_rl/utils/logger.py17-25](https://github.com/ShangtongZhang/DeepRL/blob/c0968b5c/deep_rl/utils/logger.py#L17-L25)

 
## Logging API

 The Logger class provides several methods for logging different types of information:

 
### Text Logging Methods

 These methods are directly inherited from Python's standard logging module:

 
| Method | Purpose | Example |
|---|---|---|
| info() | Log informational messages | logger.info("Episode completed") |
| debug() | Log detailed debugging information | logger.debug("Action selected: 2") |
| warning() | Log warning messages | logger.warning("Buffer almost full") |

 
### Metric Logging Methods

 These methods log numerical data to TensorBoard:

 
| Method | Purpose | Parameters |
|---|---|---|
| add_scalar() | Log a single scalar value | tag, value, step (optional), log_level (optional) |
| add_histogram() | Log a distribution of values | tag, values, step (optional), log_level (optional) |
