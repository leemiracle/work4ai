## Purpose and Scope

 Model Templates in DI-engine provide pre-defined neural network architectures for different reinforcement learning algorithms. These templates encapsulate common architectures with standardized interfaces, making it easy to implement various RL algorithms while maintaining consistency in model structure. This page documents the available model templates, their architecture, and how they interact with other components of the system.

 For information about specific model components like encoders and heads, see [Model Components](https://deepwiki.com/opendilab/DI-engine/5.1-model-components). For details on how model functionality can be extended, see [Model Wrappers](https://deepwiki.com/opendilab/DI-engine/5.3-model-wrappers).

 
## Overview

 Model Templates serve as the backbone of the model system in DI-engine, offering ready-to-use neural network architectures for various reinforcement learning algorithms. Each template is designed based on the specific requirements of an algorithm while following a consistent pattern that includes an encoder for feature extraction and a head for output generation.

## Value-Based Model Templates

 
### DQN and Variants

 The Deep Q-Network (DQN) template and its variants form the foundation of value-based reinforcement learning in DI-engine. These templates provide implementations of various DQN-based algorithms with different characteristics.

 
#### DQN

 The basic DQN template combines an encoder (either FC or Conv based on observation shape) with a head (either Discrete or Dueling).

#### Distributional DQN Variants

 Several templates implement distributional reinforcement learning approaches:

 
 - **C51DQN**: Categorical DQN with fixed, discrete supports
 - **QRDQN**: Quantile Regression DQN
 - **IQN**: Implicit Quantile Networks
 - **FQF**: Fully parameterized Quantile Function
 - **RainbowDQN**: Combines multiple DQN improvements

## Creating Custom Model Templates

 To create a custom model template in DI-engine, you should:

 
 - Define a new class inheriting from `nn.Module`
 - Register it with `MODEL_REGISTRY.register('your_model_name')`
 - Follow the encoder + head pattern for consistency
 - Implement a `forward` method that returns a dictionary with at least a 'logit' key

## Summary

 Model templates in DI-engine provide standardized neural network architectures for various reinforcement learning algorithms. They follow consistent patterns with encoders and heads, are registered through a central registry, and can be easily extended for custom needs. The templates range from value-based methods like DQN and its variants to multi-agent approaches like QMix, COMA, and CollaQ.

 This structured approach to model design enables consistent implementation across different algorithms while maintaining the flexibility needed for algorithm-specific requirements.
