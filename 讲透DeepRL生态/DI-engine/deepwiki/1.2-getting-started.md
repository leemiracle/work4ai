  This page provides a quick start guide for new users of DI-engine, a generalized decision intelligence framework for PyTorch. We'll cover basic concepts, show how to create your first reinforcement learning program, and explain common workflows to get you up and running quickly. For detailed installation instructions, see [Installation and Setup](https://deepwiki.com/opendilab/DI-engine/1.1-installation-and-setup).

 
## Basic Concepts in DI-engine

 DI-engine is built around several key components that work together to enable reinforcement learning training:

 
```

```

 Sources: [README.md51-63](https://github.com/opendilab/DI-engine/blob/c290a673/README.md?plain=1#L51-L63)

 
 - **Environment**: Interfaces with the outside world where your agent acts
 - **Policy**: Implements reinforcement learning algorithms (DQN, PPO, SAC, etc.)
 - **Model**: Defines neural network architectures using PyTorch
 - **Pipeline**: Orchestrates the training process (collecting data, learning, evaluation)

## Supported Algorithms and Environments

 DI-engine supports a wide variety of reinforcement learning algorithms:

 
| Category | Algorithms |
|---|---|
| Basic RL | DQN, C51, QRDQN, IQN, Rainbow |
| Policy Gradient | PPO, A2C, IMPALA |
| Actor-Critic | SAC, TD3, DDPG |
| Multi-agent | QMIX, WQMIX, MAPPO, MADDPG |
| Offline RL | CQL, BCQ, TD3BC, Decision Transformer |
| Imitation Learning | GAIL, SQIL, DQfD |
| Model-based RL | MBPO, Dreamer |

 And many environments:

 
| Category | Environments |
|---|---|
| Classic Control | CartPole, Pendulum, Acrobot |
| Box2D | LunarLander, BipedalWalker |
| MuJoCo | HalfCheetah, Hopper, Walker2d |
| Atari | Pong, Breakout, SpaceInvaders |
| SMAC | StarCraft Multi-Agent Challenge |
| PettingZoo | Cooperative & competitive multi-agent |
| Custom | GoBigger, MetaDrive, Overcooked |
