  Actor-Critic methods represent a fundamental family of reinforcement learning algorithms that combine policy-based and value-based approaches. This document explains the actor-critic implementations in DI-engine, focusing primarily on the Soft Actor-Critic (SAC) algorithm, its variants, and model architecture.

 For information on other policy types, see [Policy Gradient Methods](https://deepwiki.com/opendilab/DI-engine/4.1-policy-gradient-methods) and [Value-Based Methods](https://deepwiki.com/opendilab/DI-engine/4.2-value-based-methods).

 
## Introduction to Actor-Critic Methods

 Actor-Critic methods integrate two key components:

 
 - **Actor**: A policy network that determines which actions to take in each state
 - **Critic**: A value network that evaluates the actor's policy by estimating state or state-action values
 
 This hybrid approach combines the advantages of both policy-based and value-based methods:

 
 - Direct policy optimization without requiring a max operation over action values
 - Reduced variance in policy gradient estimates compared to pure policy gradient methods
 - Effective performance in both continuous and discrete action spaces

## Soft Actor-Critic (SAC)

 Soft Actor-Critic is an off-policy actor-critic algorithm that incorporates entropy maximization to improve exploration and robustness. SAC is particularly effective for continuous control tasks, but DI-engine also implements a discrete version.

 
### Key Features of SAC

 
 - **Maximum Entropy Reinforcement Learning**: Balances exploitation and exploration by including an entropy term in the objective
 - **Automatic Temperature Tuning**: Dynamically adjusts the temperature parameter to maintain a target entropy
 - **Twin Critics**: Uses two Q-networks to mitigate overestimation bias (similar to TD3)
 - **Off-Policy Learning**: Uses a replay buffer for sample efficiency

### Core Model Classes

 The model implementation provides several action space options:

 
 - **Regression**: Used for deterministic policies (e.g., DDPG, TD3)
 - **Reparameterization**: Used for stochastic policies with continuous actions (SAC)
 - **Discrete**: Used for discrete action spaces (DiscreteSAC)
 
 The model architecture can use either separate encoders for actor and critic or a shared encoder, which is particularly useful for image-based observations.

 
## SAC Implementation Details

 DI-engine implements two main variants of SAC:

 
 - **SACPolicy**: For continuous action spaces
 - **DiscreteSACPolicy**: For discrete action spaces
 
 
### Continuous SAC

 The continuous SAC implementation uses a Gaussian policy with state-dependent mean and standard deviation, leveraging the reparameterization trick for gradient computation. The critic estimates Q-values for state-action pairs.

 Key components in the learning process include:

 
 - Computing target Q-values using minimum of twin critics
 - Adding entropy regularization to target values
 - Updating critic networks using TD learning
 - Updating the actor network using the reparameterized policy gradient
 - Automatic adjustment of the entropy coefficient (alpha)
 
 
### Discrete SAC

 The discrete SAC implementation adapts the SAC algorithm to discrete action spaces. It maintains the entropy regularization concept but applies it to a categorical distribution over discrete actions.

## Conservative Q-Learning (CQL)

 Conservative Q-Learning (CQL) extends SAC for offline reinforcement learning by adding a conservative term to the Q-function update. This prevents the overestimation of Q-values for unseen state-action pairs, which is a common issue in offline RL.

 DI-engine implements CQL by building on the SAC implementation, with additional loss terms to penalize Q-values for out-of-distribution actions.

## Implementation Classes

 The key policy classes for actor-critic methods in DI-engine are:

 
| Class | Description | Action Space |
|---|---|---|
| SACPolicy | Soft Actor-Critic for continuous action spaces | Continuous |
| DiscreteSACPolicy | Soft Actor-Critic adapted for discrete action spaces | Discrete |
| CQLPolicy | Conservative Q-Learning (extends SAC for offline RL) | Continuous |
| DiscreteCQLPolicy | Discrete version of Conservative Q-Learning | Discrete |

 The model templates that support these policies:

 
| Class | Description | Action Space |
|---|---|---|
| ContinuousQAC | Actor-critic model template for continuous action spaces | Continuous |
| DiscreteQAC | Actor-critic model template for discrete action spaces | Discrete |
| QACDIST | Distributional actor-critic model (for use with distributional critics) | Continuous/Discrete |

## Summary

 Actor-critic methods in DI-engine, particularly SAC, provide a powerful framework for reinforcement learning in both continuous and discrete domains. The implementation features entropy regularization for exploration, automatic temperature adjustment, and twin critics for stable learning. SAC is implemented as an off-policy algorithm that can efficiently learn from a replay buffer.

 The extension to CQL enables offline reinforcement learning by adding conservative regularization to prevent overestimation of Q-values for unseen state-action pairs.

 DI-engine's modular architecture allows for easy configuration and experimentation with different actor-critic variants across a wide range of environments.
