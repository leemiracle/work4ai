## Purpose and Scope

 This document details Docker integration in DI-engine, explaining available container images, build processes, and how to use containerized environments for reinforcement learning tasks. Docker containers ensure reproducible environments and simplify dependency management across different reinforcement learning environments. For information about the CI/CD pipeline that builds these Docker images, see [CI/CD Pipeline](https://deepwiki.com/opendilab/DI-engine/7.2-cicd-pipeline).

## Docker Image Contents

 
### Base Image

 The base image (`opendilab/ding:nightly`) includes:

 
 - PyTorch 1.12.1 with CUDA 11.3 and cuDNN 8
 - Essential system dependencies for rendering and visualization
 - Rust environment for certain performance-critical components
 - DI-engine installation with fast and test dependencies
 
 
```
FROM pytorch/pytorch:1.12.1-cuda11.3-cudnn8-runtime as base
```

 Source: [docker/Dockerfile.base1-29](https://github.com/opendilab/DI-engine/blob/c290a673/docker/Dockerfile.base#L1-L29)

 
### Environment-Specific Images

 Environment-specific images extend the base image with additional dependencies and configurations for specific reinforcement learning environments.

 
#### Atari Image

 The Atari image includes:

 
 - AutoROM for managing Atari ROM files
 - Common environment dependencies for Atari games
 
 
```
FROM opendilab/ding:nightly as atari
```

 Source: [docker/Dockerfile.env1-8](https://github.com/opendilab/DI-engine/blob/c290a673/docker/Dockerfile.env#L1-L8)

 
#### MuJoCo Image

 The MuJoCo image includes:

 
 - MuJoCo 2.1.0 physics engine
 - OpenGL and rendering libraries
 - Gym and Gymnasium MuJoCo support
 
 
```
FROM opendilab/ding:nightly as mujoco
```

 Source: [docker/Dockerfile.env10-42](https://github.com/opendilab/DI-engine/blob/c290a673/docker/Dockerfile.env#L10-L42)

 
#### DeepMind Control Suite (DMC2Gym) Image

 The DMC2Gym image includes:

 
 - Dependencies for DeepMind Control Suite environments
 - DMC2Gym wrapper for using DMC with Gym interface
 
 
```
FROM opendilab/ding:nightly as dmc2gym
```

### Build Triggers

 The Docker image build process is triggered by:

 
 - Pushes to the `main` branch
 - Pushes to branches containing `*deploy*` or `*docker*` in their names
 - Specific environment images are built only when the commit message contains special flags (e.g., "metaworld docker", "smac docker")

## Conclusion

 Docker integration in DI-engine provides a consistent, reproducible environment for reinforcement learning research and development. The available Docker images cover a wide range of environments and use cases, from simple Atari games to complex physics simulations. Using these Docker images simplifies dependency management and enables researchers to focus on algorithm development rather than environment setup.
