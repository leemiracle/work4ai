## System Requirements

 Before installing DI-engine, ensure your system meets these requirements:

 
 - Python 3.7 or higher (specified in [setup.py51](https://github.com/opendilab/DI-engine/blob/c290a673/setup.py#L51-L51))
 - CUDA support (optional but recommended for deep learning)
 - Operating system: Linux (recommended), macOS, or Windows

### Package Conflicts

```

```

 
### CUDA Issues

 
 - Ensure compatible CUDA drivers are installed
 - Verify PyTorch was installed with CUDA support
 - Try setting: `export CUDA_VISIBLE_DEVICES=0,1,2,3` (use your GPU indices)
 
 
### Environment-Specific Issues

 
 - **Atari**: Ensure ROMs are correctly installed with AutoROM
 - **MuJoCo**: Verify environment variables are properly set
 - **DeepMind Control Suite**: Check for necessary system libraries (OpenGL, etc.)
