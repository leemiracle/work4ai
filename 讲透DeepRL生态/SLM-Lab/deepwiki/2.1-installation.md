## Overview

 SLM Lab requires:

 
 - **Python 3.12** (managed by `uv`)
 - **System packages** for rendering (SDL2, OpenGL), physics simulation (MuJoCo via SWIG), and build tooling
 - **`uv`** as the package manager and virtualenv tool
 
 The repository provides automated setup scripts in `bin/` for the three supported platforms, a Docker image, and a `pyproject.toml` that `uv` uses to resolve and install all Python dependencies.

## Method 2: Manual Platform Setup

 
### macOS

 Uses Homebrew for system packages and `uv` for Python dependency management.

 **System packages installed** [bin/setup_macOS16-19](https://github.com/kengz/SLM-Lab/blob/d3128a8a/bin/setup_macOS#L16-L19):

 
| Package | Purpose |
|---|---|
| cmake | Build tool required by some Python extension packages |
| sdl2 | Rendering backend for classic control environments |
| swig | Interface compiler needed by Box2D bindings |

 After system packages, `uv` is installed and `uv sync` resolves and installs all Python dependencies.

 
---

 
### Ubuntu (and Debian-based Linux)

 **System packages installed** [bin/setup_ubuntu9-13](https://github.com/kengz/SLM-Lab/blob/d3128a8a/bin/setup_ubuntu#L9-L13):

 
| Package | Purpose |
|---|---|
| build-essential | GCC, make, and headers for compiling C extensions |
| cmake | Build system for native extension packages |
| swig | Required for Box2D Python bindings |
| python3-dev | Python C headers for extension compilation |
| libsdl2-dev | SDL2 development headers for rendering |
| libgl1-mesa-glx | OpenGL runtime for rendering |
| libglib2.0-0 | GLib runtime dependency |
| libsm6, libxext6, libxrender-dev | X11 display libraries for headless rendering |
| libgomp1 | OpenMP runtime for parallel computation |
| xvfb | Virtual framebuffer for headless rendering on servers |

 
> **Note on `xvfb`:** On headless servers (no display), prefix commands with `xvfb-run -a` to enable rendering. See the warning in [slm_lab/lib/viz.py131](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/viz.py#L131-L131)

## Dependency Management with `uv`

 All Python dependencies are declared in `pyproject.toml` and pinned in `uv.lock`. The `uv` tool manages both the virtualenv and the Python interpreter.

 **Key commands:**

 
| Command | Effect |
|---|---|
| uv sync | Install all default dependency groups (ML, training) |
| uv sync --frozen | Install exactly as pinned in uv.lock (used in Docker) |
| uv sync --no-default-groups | Install only core/orchestration deps, skip ML packages |
| uv tool install --editable . | Install slm-lab CLI tool into PATH |
| uv run slm-lab run | Run via uv without installing into PATH |
