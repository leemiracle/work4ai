## Overview

 `SoftActorCritic` is defined in [slm_lab/agent/algorithm/sac.py15-383](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L15-L383) and extends `ActorCritic`. It implements the maximum-entropy RL objective, which augments the standard reward with an entropy bonus controlled by a temperature parameter `alpha`. Two variants are supported:

 
 - **Discrete SAC**: Uses the exact-expectation method from Christodoulou (2019). The Q-network maps state → Q-values for all actions simultaneously.
 - **Continuous SAC**: Uses the reparameterization trick from Haarnoja et al. (2018). The Q-network maps `[state, action]` → scalar Q-value.
 
 Both variants support automatic entropy temperature tuning via a learnable `log_alpha` parameter.

### Input/Output Dimensions

 The Q-network input and output shapes differ between action types:

 
| Mode | Q-network input (q_in_dim) | Q-network output (q_out_dim) |
|---|---|---|
| Discrete | state_dim | action_dim (one Q-value per action) |
| Continuous | state_dim + action_dim | 1 (scalar Q-value) |

 The actor network (`self.net`) always takes `state_dim` as input and outputs the parameters for the action distribution.

### `init_nets`

 [slm_lab/agent/algorithm/sac.py59-124](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L59-L124)

 Instantiates all five networks plus `log_alpha`. Key behaviors:

 
 - `self.shared = False` — SAC never shares actor/critic weights.
 - All networks use the same `NetClass` (from `net_spec["type"]`), the same `optim_spec`, and the same `lr_scheduler_spec`.
 - Target networks are initialized as exact copies via `net_util.copy`.
 - `log_alpha` is a scalar `torch.zeros(1, requires_grad=True)` initialized to 0, so `alpha` starts at 1.0.
 - `net_names = ["net", "q1_net", "target_q1_net", "q2_net", "target_q2_net"]` — these are the names used for model save/load.

## Action Selection

 
### `act`

 [slm_lab/agent/algorithm/sac.py126-135](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L126-L135)

 
 - Before `training_start_step` frames: calls `policy_util.random` to collect experience with pure random actions.
 - After `training_start_step`: calls `self.action_policy` (usually `policy_util.default`, which samples from the actor's distribution).
 - For continuous actions, the raw action is squashed with `torch.tanh` into `[-1, 1]`. The environment's `RescaleAction` wrapper then scales to actual bounds.
 
 
### `calc_log_prob_action`

 [slm_lab/agent/algorithm/sac.py137-153](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L137-L153)

 Computes `(log_probs, actions)` from an `action_pd` object.

 
 - **Discrete**: Calls `action_pd.sample()` and `action_pd.log_prob()`.
 - **Continuous** (with reparameterization when `reparam=True`): Calls `action_pd.rsample()`, applies `tanh` squashing, and corrects the log probability:
 
 
```
squash_correction = 2*(log(2) - x - softplus(-2x))   # numerically stable form
log_prob = sum(raw_log_prob, dim=-1) - sum(squash_correction, dim=-1)
```

 This correction accounts for the change of variables introduced by `tanh`.

 Sources: [slm_lab/agent/algorithm/sac.py137-153](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L137-L153)

## Loss Computations

 
### Q-value Computation

 **`calc_q_discrete`** [slm_lab/agent/algorithm/sac.py155-158](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L155-L158)

 Runs `q_net(states)` to get Q-values for all actions, then gathers the values at the taken action indices.

 **`calc_q_cont`** [slm_lab/agent/algorithm/sac.py160-164](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L160-L164)

 Concatenates `[states, actions]` along the last dimension, then runs `q_net` on the result.

 Both are dispatched through `calc_q` [slm_lab/agent/algorithm/sac.py166-169](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L166-L169)

 
### Soft Value Function `V(s')`

 `calc_v_next` [slm_lab/agent/algorithm/sac.py171-191](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L171-L191) computes the target value for next states using the target Q-networks:

 
| Mode | Formula |
|---|---|
| Discrete | V(s') = Σ_a π(a\|s') * [avg(Q1_target, Q2_target) - α * log π(a\|s')] |
| Continuous | V(s') = min(Q1_target, Q2_target) - α * log π(a'\|s'), where a' ~ π |

 
> **Note on discrete averaging vs. min**: The discrete case uses `avg(Q1, Q2)` (SD-SAC variant) instead of `min(Q1, Q2)` to reduce underestimation bias, which is more common in discrete settings.

 
### Q-targets (Bellman Backup)

 `calc_q_targets` [slm_lab/agent/algorithm/sac.py193-201](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L193-L201) computes targets under `torch.no_grad()`:

 
```
q_target = reward + gamma * (1 - terminated) * V(s')
```

 Uses `terminated` (not `done`) so that Q-values properly propagate through time-limit truncations. See [8.1](https://deepwiki.com/kengz/SLM-Lab/8.1-math-utilities) for details on the `terminateds` vs `dones` distinction.

 
### Policy Loss

 **Discrete** (`calc_policy_loss_discrete`) [slm_lab/agent/algorithm/sac.py203-224](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L203-L224):

 
```
J_π = E_s[ Σ_a π(a|s) * (α * log π(a|s) - avg(Q1, Q2)(s,a)) ]
```

 With optional SD-SAC entropy penalty when `entropy_penalty_coef > 0`:

 
```
J_π += β * 0.5 * (H_ema - H_current)²
```

 **Continuous** (`calc_policy_loss_cont`) [slm_lab/agent/algorithm/sac.py226-235](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L226-L235):

 
```
J_π = E_s[ α * log π(a|s) - min(Q1, Q2)(s, a) ]   where a ~ π (reparameterized)
```

 The `log_probs` computed here are cached in `self._cached_log_probs` to avoid resampling for the alpha loss.

 
### Entropy Temperature Loss (Alpha)

 **Discrete** (`calc_alpha_loss_discrete`) [slm_lab/agent/algorithm/sac.py246-253](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L246-L253):

 
```
J_α = -α * (H_target - H_current)
```

 When `H_current > H_target`, the loss is negative, which decreases `alpha` (less exploration pressure).

 **Continuous** (`calc_alpha_loss_cont`) [slm_lab/agent/algorithm/sac.py255-262](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L255-L262):

 
```
J_α = -mean( α * (log π(a|s) + H_target) )
```

 Reuses cached `log_probs` from the policy loss step.

 Sources: [slm_lab/agent/algorithm/sac.py203-271](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L203-L271)

### `train_alpha`

 [slm_lab/agent/algorithm/sac.py280-287](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L280-L287)

 After backprop, `log_alpha` is clamped to `[-5.0, 2.0]`, keeping `alpha` in `[~0.007, ~7.4]`. This prevents runaway growth in environments where episodes end only by time limit (no terminal states).

 
### `update_nets`

 [slm_lab/agent/algorithm/sac.py366-378](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L366-L378)

 Calls `net_util.update_target_net` for both `(q1_net, target_q1_net)` and `(q2_net, target_q2_net)`. The update type (polyak or hard) is controlled by `net_spec["update_type"]` and `net_spec["polyak_coef"]`. Target network updates only happen when the policy is updated (inside the `policy_delay` branch).

## Spec Configuration

### Algorithm Spec Fields

 
| Field | Type | Default | Description |
|---|---|---|---|
| name | string | — | Must be "SoftActorCritic" |
| action_pdtype | string | "default" | Distribution class name. Use "Categorical" or "GumbelSoftmax" for discrete; "Normal" for continuous. |
| action_policy | string | "default" | Policy function name in policy_util. |
| gamma | float | — | Discount factor (required). |
| training_frequency | int | — | Environment steps between training calls (required). |
| training_iter | int | num_envs | Gradient update steps per training call. |
| training_start_step | int | max(1000, batch_size) | Frames before training starts. |
| policy_delay | int | 1 | Actor updated every N critic updates. |
| entropy_penalty_coef | float | 0.0 | SD-SAC entropy variance penalty weight. |
| target_entropy | "auto" or float | "auto" | Target entropy H_target. |

| Field | Notes |
|---|---|

## `update`

 [slm_lab/agent/algorithm/sac.py380-382](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sac.py#L380-L382)

 SAC's `update` method simply returns `self.agent.explore_var`. There is no epsilon or tau decay because exploration is handled internally through the entropy mechanism and `log_alpha`. The `explore_var` value is tracked by the agent for logging purposes but has no effect on SAC's action selection after `training_start_step`.
