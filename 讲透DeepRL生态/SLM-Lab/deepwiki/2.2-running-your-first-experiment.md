## CLI Command Reference

 The `slm-lab` CLI is built with Typer. The entry point is referenced in the codebase as `run_lab.py`.

 
| Command | Arguments | Description |
|---|---|---|
| slm-lab run | [spec_file] [spec_name] [lab_mode] | Run a local experiment |
| slm-lab run --render | — | Run demo with environment rendering |
| slm-lab run-remote | [spec_file] [spec_name] [lab_mode] | Submit experiment to cloud via dstack |
| slm-lab pull | spec_name | Download results from HuggingFace |
| slm-lab list | — | List available remote experiments |
| slm-lab plot | -f folder1,folder2 | Regenerate plots from saved data |
| slm-lab --help | — | Show all available commands |
| slm-lab run --help | — | Show flags for run |

 
### Lab Mode

 The third positional argument to `slm-lab run` sets the `lab_mode` environment variable, which is read throughout the codebase via `lab_mode()` from `slm_lab/lib/env_var.py`. It controls spec overrides and what execution unit is created:

 
| lab_mode | Spec Overrides | Execution Unit |
|---|---|---|
| train | None | Trial |
| dev | max_session=1, max_trial=2 | Trial |
| enjoy | max_session=1, loads best saved model | Inference only |
| search | None | Experiment (Ray Tune hyperparameter search) |

 Overrides are applied by `spec_util.override_spec` [slm_lab/spec/spec_util.py235-244](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/spec_util.py#L235-L244) In `enjoy` mode, `spec_util.get_best_session` [slm_lab/spec/spec_util.py253-275](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/spec_util.py#L253-L275) selects the session checkpoint with the highest `total_reward_ma`.

## The Demo Spec

 The demo spec [slm_lab/spec/demo.json1-65](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/demo.json#L1-L65) defines a single named configuration, `ppo_cartpole`, with the following key fields:

 
| Spec Field | Value | Effect |
|---|---|---|
| env.name | CartPole-v1 | Gymnasium environment to instantiate |
| env.max_frame | 10000 | Frames per session before termination |
| meta.max_session | 2 | Sessions run per trial (run in parallel) |
| meta.max_trial | 1 | Number of trials |
| meta.log_frequency | 500 | Frames between checkpoint/log events |
| meta.eval_frequency | 128 | Frames between evaluation checkpoints |
| agent.algorithm.name | PPO | Algorithm class name |
| agent.memory.name | OnPolicyBatchReplay | Memory class name |
| agent.net.type | MLPNet | Network architecture class |
| agent.net.hid_layers | [64, 64] | Hidden layer sizes for MLPNet |
| agent.algorithm.gamma | 0.99 | Discount factor |
| agent.algorithm.time_horizon | 128 | PPO rollout length |

 The spec is loaded and validated by `spec_util.get` [slm_lab/spec/spec_util.py160-198](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/spec_util.py#L160-L198) which injects runtime fields into `spec['meta']`: `experiment_ts`, `git_sha`, `prepath`, `info_prepath`, `graph_prepath`, `log_prepath`, `model_prepath`, and index counters.

### The RL Loop

 Inside `Session.run_rl` [slm_lab/experiment/control.py105-129](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L105-L129) each timestep executes:

 
 - `agent.act(state)` — calls `algorithm.act` to select an action
 - `env.step(action)` — advances the environment one step
 - `agent.update(state, action, reward, next_state, done, ...)` — stores experience in memory, calls `algorithm.train()`
 - `Session.try_ckpt(agent, env)` — on every `log_frequency` frames: logs metrics, saves the model, and saves the best model if `total_reward_ma` improved

### File Naming Convention

 Paths are built from a `prepath` that encodes the experiment name, timestamp, trial index, and session index. The pattern is:

 
```
data/{spec_name}_{experiment_ts}/{folder}/{spec_name}_t{trial_idx}_s{session_idx}_{suffix}
```

 The `prepath` is computed by `util.get_prepath` [slm_lab/lib/util.py195-209](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/util.py#L195-L209) and subfolders are inserted by `util.insert_folder` [slm_lab/lib/util.py234-239](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/util.py#L234-L239) The resulting paths are stored in `spec['meta']` as `prepath`, `graph_prepath`, `info_prepath`, `log_prepath`, and `model_prepath` by `spec_util.tick` [slm_lab/spec/spec_util.py319-329](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/spec_util.py#L319-L329)

## Reading Training Output

 During a run, the terminal prints a summary at each `log_frequency` interval, formatted by `MetricsTracker.log_summary` [slm_lab/agent/__init__.py327-347](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/__init__.py#L327-L347) The key columns are:

 
| Column | Description |
|---|---|
| total_reward | Mean episodic return over the most recent episodes |
| total_reward_ma | Moving average of total_reward over the last 100 checkpoints |
| loss | Most recent training loss |
| fps | Training frames per second |
| frame | Cumulative environment frames |
| opt_step | Cumulative optimizer steps |
| lr | Current learning rate |

 The moving-average window is `PLOT_MA_WINDOW = 100` [slm_lab/lib/viz.py15](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/viz.py#L15-L15)

 After training completes, `info/*_t0_trial_metrics_scalar.json` contains the final aggregated metrics:

 
| Metric | Description |
|---|---|
| total_reward_ma | Mean of session total_reward_ma values |
| strength | Mean return above the random baseline |
| max_strength | Peak strength over the run |
| final_strength | Strength at the final checkpoint |
| sample_efficiency | Strength per frame consumed |
| training_efficiency | Strength per optimizer step |
| stability | Smoothness of the learning curve |
| consistency | Agreement across sessions (trial-level only) |

 These are computed by `calc_session_metrics` and `calc_trial_metrics` in [slm_lab/experiment/analysis.py119-243](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/analysis.py#L119-L243) For the formulas behind each metric, see [Metrics and Analysis](https://deepwiki.com/kengz/SLM-Lab/4.2-metrics-and-analysis).
