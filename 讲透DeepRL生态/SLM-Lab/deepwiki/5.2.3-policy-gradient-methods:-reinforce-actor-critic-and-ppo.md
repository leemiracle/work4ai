## Purpose and Scope

 This page documents the policy gradient algorithm implementations in SLM Lab: `Reinforce`, `ActorCritic`, `PPO`, and the Self-Imitation Learning extensions `SIL` and `PPOSIL`. It covers advantage estimation methods (plain returns, N-step, GAE), the `ReturnNormalizer`, shared vs. separate actor-critic networks, and how the training loop for policy gradient methods differs structurally from value-based methods.

 For the abstract `Algorithm` base class interface and action selection utilities, see [Algorithm Base Class and Action Selection](https://deepwiki.com/kengz/SLM-Lab/5.2.1-algorithm-base-class-and-action-selection). For value-based methods (SARSA, DQN), see [Value-Based Methods](https://deepwiki.com/kengz/SLM-Lab/5.2.2-value-based-methods:-sarsa-and-dqn). For math utility functions referenced here (`calc_returns`, `calc_gaes`, etc.), see [Math Utilities](https://deepwiki.com/kengz/SLM-Lab/8.1-math-utilities).

## REINFORCE

 `Reinforce` in [slm_lab/agent/algorithm/reinforce.py](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/reinforce.py) is the simplest policy gradient method. It collects full episodes (or batches), computes discounted returns, and updates the policy network directly.

 
### Algorithm Parameters

 Configured via `algorithm_spec` in the spec file:

 
| Parameter | Type | Description |
|---|---|---|
| action_pdtype | str | Probability distribution type ("default", "GumbelSoftmax", etc.) |
| action_policy | str | Policy function name from policy_util ("default", "epsilon_greedy", etc.) |
| center_return | bool | Subtract mean from returns before using as advantages |
| gamma | float | Discount factor |
| entropy_coef_spec | dict or null | Decay spec for entropy regularization coefficient |
| policy_loss_coef | float | Scalar multiplier for policy loss |
| training_frequency | int | Number of episodes or steps between training calls |

 
### Key Methods

 **`init_nets`** [slm_lab/agent/algorithm/reinforce.py76-94](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/reinforce.py#L76-L94)

 Creates a single network `self.net` of the type specified in `net_spec['type']`, along with its optimizer `self.optim` and lr scheduler `self.lr_scheduler`. For continuous action spaces, the network is expected to return two outputs (mean and std); for discrete spaces, it returns logits.

 **`calc_pdparam`** [slm_lab/agent/algorithm/reinforce.py97-101](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/reinforce.py#L97-L101)

 Performs a forward pass through `self.net` and returns raw parameters for the action distribution. Subclasses override this to handle shared actor-critic outputs.

 **`calc_ret_advs`** [slm_lab/agent/algorithm/reinforce.py123-132](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/reinforce.py#L123-L132)

 Calls `math_util.calc_returns` to compute discounted cumulative returns. If `center_return=True`, subtracts the mean. Returns are used directly as advantages (no value baseline).

 **`calc_policy_loss`** [slm_lab/agent/algorithm/reinforce.py134-151](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/reinforce.py#L134-L151)

 
```
policy_loss = -policy_loss_coef * mean(log_prob(a|s) * adv)
             + (−entropy_coef * entropy)  [if entropy_coef_spec is set]
```

 Advantages are standardized (zero mean, unit variance) via `math_util.standardize` when the batch has more than one element. The `reduce_multi_action` helper from `policy_util` handles multi-dimensional action spaces (e.g., `BipedalWalker`).

 **`train`** [slm_lab/agent/algorithm/reinforce.py154-171](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/reinforce.py#L154-L171)

 Called each time `self.to_train == 1`. Samples a batch, computes `pdparams` and `advs`, computes the policy loss, and calls `self.net.train_step`.

## ActorCritic

 `ActorCritic` in [slm_lab/agent/algorithm/actor_critic.py](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py) extends `Reinforce` by adding a value (critic) network. The critic's value predictions are used to compute advantages, reducing variance in the policy gradient estimate.

 
### Advantage Estimation Modes

 The algorithm selects one of three advantage estimation methods based on the spec, set during `init_algorithm_params`:

 [slm_lab/agent/algorithm/actor_critic.py161-168](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L161-L168)

 
| lam | num_step_returns | Method assigned to calc_advs_v_targets | Algorithm variant |
|---|---|---|---|
| not null | any | calc_gae_advs_v_targets | A2C (GAE) |
| null | not null | calc_nstep_advs_v_targets | A2C (N-step) |
| null | null | calc_ret_advs_v_targets | AC (plain TD) |

```

```

 Sources: [slm_lab/agent/algorithm/actor_critic.py161-168](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L161-L168) [slm_lab/lib/math_util.py62-120](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/math_util.py#L62-L120)

 
#### `calc_ret_advs_v_targets` [slm_lab/agent/algorithm/actor_critic.py265-277](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L265-L277)

 Computes plain discounted returns via `math_util.calc_returns`. `advs = rets - v_preds`. `v_targets = rets`.

 
#### `calc_nstep_advs_v_targets` [slm_lab/agent/algorithm/actor_critic.py279-299](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L279-L299)

 Bootstraps from the value of the last next-state using `math_util.calc_nstep_returns`. `advs = nstep_rets - v_preds`. `v_targets = nstep_rets`. Note: `training_frequency` is automatically set to `num_step_returns`.

 
#### `calc_gae_advs_v_targets` [slm_lab/agent/algorithm/actor_critic.py301-323](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L301-L323)

 Computes GAE via `math_util.calc_gaes`. The value prediction of the final next-state is appended: `v_preds_all = cat(v_preds, next_v_pred)`. `advs = GAE`. `v_targets = advs + v_preds`.

 The GAE formula (from Schulman et al. 2016):

 
```
δ_t = r_t + γ·V(s_{t+1})·(1−terminated_t) − V(s_t)
GAE_t = δ_t + (γλ)·(1−terminated_t)·GAE_{t+1}
```

 
> **Important:** All return/advantage calculations use `terminateds` (true episode end), not `dones`. When an episode is truncated by a time limit, future values are bootstrapped rather than zeroed. See [Math Utilities](https://deepwiki.com/kengz/SLM-Lab/8.1-math-utilities) for details.

 
### Shared vs. Separate Networks

 `init_nets` requires `"shared": true/false` in `net_spec`. [slm_lab/agent/algorithm/actor_critic.py186-222](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L186-L222)

 Sources: [slm_lab/agent/algorithm/actor_critic.py186-222](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L186-L222)

 
| Config | Networks | Optimizers | Loss |
|---|---|---|---|
| shared=true | self.net only | self.optim | policy_loss + val_loss (single backward) |
| shared=false | self.net (actor) + self.critic_net | self.optim + self.critic_optim | separate backward passes |

 **`calc_pdparam`** [slm_lab/agent/algorithm/actor_critic.py224-239](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L224-L239)

 When `shared=True`, the network returns a list. The last element is `v_pred` (cached as `self.v_pred`); the rest is the actor `pdparam`. When `shared=False`, the parent class forward pass returns `pdparam` only.

 **`calc_v`** [slm_lab/agent/algorithm/actor_critic.py241-254](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L241-L254)

 When `shared=True` and `use_cache=True`, returns `self.v_pred` set during the last `calc_pdparam` call. When `shared=False`, runs a forward pass through `self.critic_net`.

 
### Value Loss and ReturnNormalizer

 **`calc_val_loss`** [slm_lab/agent/algorithm/actor_critic.py329-359](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L329-L359)

 
```
val_loss = val_loss_coef * loss_fn(v_preds, v_targets)
```

 If `normalize_v_targets=True` in the spec, a `ReturnNormalizer` instance is used to scale targets and predictions to a stable range before computing the loss.

 **`ReturnNormalizer`** [slm_lab/agent/algorithm/actor_critic.py14-58](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L14-L58)

 Maintains running mean and variance of value targets using Welford's algorithm. Used to prevent gradient explosion in environments with large return scales (e.g., `InvertedPendulum`, `Humanoid`).

 
| Method | Description |
|---|---|
| update(values) | Update running mean/variance from new batch of targets |
| normalize(values) | Divide by running std; clamp to [-clip, clip] |
| denormalize(values) | Multiply by running std to recover original scale |

 A minimum std of `1.0` is enforced to prevent explosion during warm-up. [slm_lab/agent/algorithm/actor_critic.py47-53](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/actor_critic.py#L47-L53)

## PPO

 `PPO` in [slm_lab/agent/algorithm/ppo.py](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py) extends `ActorCritic` with three key additions:

 
 - **Clipped surrogate objective** — prevents large policy updates
 - **Minibatch epochs** — reuses collected data for multiple gradient steps
 - **`old_net`** — a frozen copy of the policy used to compute probability ratios
 
 PPO always uses GAE for advantage estimation. [slm_lab/agent/algorithm/ppo.py124](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py#L124-L124)

 
### Algorithm Parameters

 Configured via `algorithm_spec`:

 
| Parameter | Type | Description |
|---|---|---|
| gamma | float | Discount factor |
| lam | float | GAE lambda (bias-variance trade-off) |
| clip_eps_spec | dict | Decay spec for clipping epsilon ε |
| entropy_coef_spec | dict or null | Decay spec for entropy bonus coefficient |
| val_loss_coef | float | Critic loss multiplier |
| minibatch_size | int | Size of each minibatch within a training epoch |
| time_horizon | int | Steps collected before training (training_frequency) |
| training_epoch | int | Number of passes over collected data |
| normalize_v_targets | bool | Use ReturnNormalizer for critic targets |
| clip_vloss | bool | Enable CleanRL-style value loss clipping |

 
> Both `minibatch_size` and `time_horizon` are auto-corrected to be multiples of `num_envs`. [slm_lab/agent/algorithm/ppo.py97-106](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py#L97-L106)

 
### `init_nets` — `old_net`

 [slm_lab/agent/algorithm/ppo.py131-136](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py#L131-L136)

 After calling the parent `ActorCritic.init_nets`, PPO creates `self.old_net` as a deep copy of `self.net`. `old_net` is updated at the start of each training iteration and kept frozen during minibatch updates.

 
### Clipped Surrogate Objective

 **`calc_policy_loss`** [slm_lab/agent/algorithm/ppo.py138-190](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py#L138-L190)

 The full PPO objective:

 
```
L = L^CLIP + entropy_penalty
```

 Where:

 
```
ratio_t = π(a_t|s_t) / π_old(a_t|s_t)  = exp(log_prob - old_log_prob)

L^CLIP = -mean( min(ratio * A, clip(ratio, 1-ε, 1+ε) * A) )

entropy_penalty = -entropy_coef * H[π](s)
```

 The log ratio is clamped to `[-20, 20]` before exponentiation to avoid numerical overflow. [slm_lab/agent/algorithm/ppo.py174](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py#L174-L174)

 Advantages are standardized per minibatch (zero mean, unit std). [slm_lab/agent/algorithm/ppo.py163-164](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py#L163-L164)

 
### Value Loss Clipping

 **`calc_val_loss`** [slm_lab/agent/algorithm/ppo.py192-218](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/ppo.py#L192-L218)

 When `clip_vloss=True`, the value loss is computed as:

 
```
v_clipped = old_v_preds + clip(v_preds - old_v_preds, -ε, +ε)
val_loss = 0.5 * val_loss_coef * mean(max(
    (v_preds - v_targets)²,
    (v_clipped - v_targets)²
))
```

 When `clip_vloss=False`, falls back to `ActorCritic.calc_val_loss`.

 A critical implementation note: `v_preds`, `advs`, `v_targets`, and `old_v_preds` are all computed **once** (under `torch.no_grad()`) before the epoch loop and stored in `batch`. During minibatch epochs, only `pdparams` and current `v_preds` are recomputed.

## Self-Imitation Learning (SIL)

 `SIL` in [slm_lab/agent/algorithm/sil.py13-174](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sil.py#L13-L174) extends `ActorCritic` by adding an off-policy experience replay update after each on-policy training step.

 `PPOSIL` [slm_lab/agent/algorithm/sil.py177-220](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sil.py#L177-L220) uses multiple inheritance (`SIL, PPO`) to combine SIL's replay mechanism with PPO's clipped surrogate objective.

 
### Additional Components

 
| Component | Description |
|---|---|
| self.replay_memory | Separate Replay memory (configurable via memory_spec['sil_replay_name']) |
| sil_policy_loss_coef | Scales the SIL policy loss |
| sil_val_loss_coef | Scales the SIL value loss |
| training_batch_iter | Gradient steps per sampled replay batch |
| training_iter | Number of replay batches per SIL update |

 
### SIL Loss

 **`calc_sil_policy_val_loss`** [slm_lab/agent/algorithm/sil.py132-152](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/sil.py#L132-L152)

 Computed on a randomly-sampled batch from the replay buffer:

 
```
clipped_adv = max(R_t - V(s_t), 0)

sil_policy_loss = -sil_policy_loss_coef * mean(log_prob(a|s) * clipped_adv.detach())
sil_val_loss    =  sil_val_loss_coef    * mean(clipped_adv² / 2)
```

 Only experiences where the return exceeds the current value estimate contribute to the loss. This biases the policy toward imitating past high-return trajectories.

 
### SIL `sample`

 The on-policy `sample` is extended to also populate `self.replay_memory` from the on-policy batch. Vectorized batches are flattened before insertion using `reshape(-1, ...)` on each key.

## Training Loop Comparison

 The structural difference between these algorithms and value-based methods (DQN, SARSA):

 
| Aspect | REINFORCE / ActorCritic | PPO | DQN / SARSA |
|---|---|---|---|
| Memory type | OnPolicyReplay or OnPolicyBatchReplay | OnPolicyBatchReplay only | Replay (off-policy) |
| Data reuse | One pass per collected batch | training_epoch passes | training_iter × training_batch_iter |
| Advantage estimate | Returns or GAE | GAE always | None (Q-targets) |
| Loss function | Policy gradient (log_prob × adv) | Clipped surrogate + value | TD error (MSE) |
| Policy ratio clipping | No | Yes (clip_eps) | N/A |
| to_train trigger | training_frequency steps | time_horizon steps | training_frequency steps |
