## Purpose and Scope

 This page describes the three-level execution hierarchy that orchestrates all training runs in SLM Lab: `Experiment`, `Trial`, and `Session`. It covers how each level is instantiated from a spec, the mechanics of the RL training loop inside a `Session`, how checkpointing is triggered and what it does, and how `Trial` manages multiple sessions in parallel including the distributed (Hogwild/A3C) case.

 For how the spec file itself is structured and validated, see [7](https://deepwiki.com/kengz/SLM-Lab/7-configuration-and-spec-files). For the metrics computed during and after training, see [4.2](https://deepwiki.com/kengz/SLM-Lab/4.2-metrics-and-analysis). For the hyperparameter search that drives `Experiment`, see [4.3](https://deepwiki.com/kengz/SLM-Lab/4.3-hyperparameter-search).

 All control flow code lives in [slm_lab/experiment/control.py](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py)

## Three-Level Hierarchy

 The three classes form a strict containment hierarchy. Each level runs its children, collects results, then produces analysis output before returning.

 **Hierarchy and responsibilities:**

 
| Level | Class | Runs | Key Output |
|---|---|---|---|
| Top | Experiment | one or more Trials via Ray Tune search | experiment_df.csv, experiment plots |
| Middle | Trial | max_session Sessions | trial_metrics.json, trial plots |
| Bottom | Session | one RL training loop | session_df_train.csv, session_df_eval.csv, session plots |

## Spec Index Management: `spec_util.tick`

 Before any level is instantiated, `spec_util.tick(spec, unit)` must be called to advance the index for that level. It mutates the `meta` block of the spec dict in-place.

 **What `tick` does per unit:**

 
| Unit ticked | experiment index | trial index | session index | Side effects |
|---|---|---|---|---|
| "experiment" | += 1 | reset to -1 | reset to -1 | new experiment_ts, new output dirs |
| "trial" | unchanged (auto-init if -1) | += 1 | reset to -1 | new output dirs |
| "session" | unchanged | unchanged | += 1 | new output dirs |

 After ticking, `meta_spec["prepath"]` is set (e.g. `data/ppo_cartpole_2025_01_01_120000/ppo_cartpole_t0_s1`), and subdirectories for `graph/`, `info/`, `log/`, and `model/` are created on disk. These prepaths are later used by all save/load operations.

## Session

 `Session` is the atomic unit of execution. It owns a single `Agent` and `Env`, runs the full RL loop, and produces one set of session metrics.

 
### Initialization

 [slm_lab/experiment/control.py43-63](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L43-L63)

 
```
Session.__init__(spec, global_nets=None)
```

 
 - Reads `spec["meta"]["session"]` to set `self.index`.
 - Calls `util.set_random_seed(spec)` and `util.set_cuda_id(spec)` for reproducibility.
 - Calls `make_agent_env(spec, global_nets)` which: 
 - Creates `Env` via `make_env(spec)`
 - Creates `MetricsTracker(env, spec)`
 - Creates `Agent(spec, mt=mt, global_nets=global_nets)`
 - If `meta.rigorous_eval` is set, creates a separate `self.eval_env`; otherwise `self.eval_env = self.env`.
 
 The `global_nets` parameter is only non-`None` in distributed training (A3C/Hogwild); see the [Trial distributed session section](https://github.com/kengz/SLM-Lab/blob/d3128a8a/Trial distributed session section) below.

 - `mt.update(...)` — updates the `MetricsTracker` with timestep data.

 In eval lab mode (`lab_mode == "eval"`), steps 2 and 3 are skipped.

### Checkpointing: `to_ckpt` and `try_ckpt`

 [slm_lab/experiment/control.py65-103](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L65-L103)

 `to_ckpt(env, mode)` returns `True` when:

 
 - `frame % frequency < num_envs` (i.e., `util.frame_mod` is true), **or**
 - `frame == env.max_frame` (final frame)
 
 where `frequency` is `env.log_frequency` for `mode="log"` and `env.eval_frequency` for `mode="eval"`.

 `try_ckpt(agent, env)` is called every timestep and performs the following conditionally:

 **Log checkpoint** (triggered by `to_ckpt(env, "log")`):

 
| Step | Code call | Effect |
|---|---|---|
| 1 | mt.ckpt(self.env, "train") | Appends a row to mt.train_df |
| 2 | mt.log_summary("train") | Logs metrics to console/file |
| 3 | mt.calc_log_metrics(spec, "train") | Computes session metrics for Ray Tune reporting |
| 4 | search.report(mt) | Reports metrics to Ray Tune if in search context |
| 5 | agent.save() | Saves latest model checkpoint |
| 6 | agent.save(ckpt="best") | Saves best model if total_reward_ma improved |
| 7 | analysis.analyze_session(spec, mt.train_df, "train") | Computes and plots session metrics |
| 8 | analysis.analyze_trial(spec) (session 0 only) | Recomputes trial metrics mid-run |

 **Eval checkpoint** (triggered when `meta.rigorous_eval` and `to_ckpt(env, "eval")`):

 
| Step | Code call | Effect |
|---|---|---|
| 1 | analysis.gen_avg_return(agent, eval_env) | Runs deterministic evaluation episodes |
| 2 | mt.ckpt(eval_env, "eval") | Appends a row to mt.eval_df |
| 3 | mt.log_summary("eval") | Logs eval metrics |

 Sources: [slm_lab/experiment/control.py65-103](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L65-L103)

 
### Session Completion: `run`

 [slm_lab/experiment/control.py139-144](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L139-L144)

 After `run_rl()` finishes:

 
 - `analysis.analyze_session(spec, agent.mt.eval_df, "eval")` is called, saving the eval session DataFrame and computing final session metrics.
 - `agent.mt.log_metrics(metrics["scalar"], "eval")` logs the scalar metrics.
 - `self.close()` saves the agent and closes the environments.
 - The `metrics` dict is returned to the caller (`Trial`).

## Trial

 `Trial` manages repeated sessions of the same spec to estimate performance variability. It owns the session-level parallelism logic.

 
### Initialization

 [slm_lab/experiment/control.py154-158](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L154-L158)

 
```
Trial.__init__(spec)
```

 
 - Sets `self.index = spec["meta"]["trial"]`.
 - Saves the spec to disk via `spec_util.save(spec, unit="trial")`.
 
 
### Running Sessions

 [slm_lab/experiment/control.py174-182](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L174-L182)

 `run_sessions()` branches on `max_session`:

 
 - If `max_session == 1`: ticks the spec to session 0, instantiates `Session(spec)`, calls `.run()` directly in the current process.
 - If `max_session > 1`: calls `parallelize_sessions()`.
 
 `parallelize_sessions(global_nets=None)` [slm_lab/experiment/control.py160-172](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L160-L172):

 
 - Creates a `mp.Manager().dict()` as a shared results store.
 - Loops from `0` to `max_session`, ticking `spec_util.tick(spec, "session")` each iteration.
 - Spawns one `mp.Process` per session, each targeting `mp_run_session(spec, global_nets, mp_dict)`.
 - Joins all workers and returns `session_metrics_list` ordered by session index.
 
 The `mp_run_session` wrapper [slm_lab/experiment/control.py29-33](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L29-L33) creates a `Session`, calls `.run()`, and stores the result in the shared dict keyed by `session.index`.

 
### Distributed Sessions

 [slm_lab/experiment/control.py184-194](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L184-L194)

 When `spec["meta"]["distributed"]` is not `False`, `Trial.run()` calls `run_distributed_sessions()` instead of `run_sessions()`.

 **Global net initialization** (`init_global_nets`):

 
 - A temporary `Session(deepcopy(self.spec))` is created without ticking — this gives it the pre-session-0 spec.
 - `session.env.close()` is called for safety.
 - `net_util.init_global_nets(session.agent.algorithm)` extracts and shares the algorithm's network weights across processes.
 - These `global_nets` are passed into every session via `mp_run_session`.
 
 Inside `Agent.__init__` [slm_lab/agent/__init__.py71](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/__init__.py#L71-L71) the algorithm receives `global_nets` and uses them for Hogwild-style asynchronous gradient updates (see [5.4.2](https://deepwiki.com/kengz/SLM-Lab/5.4.2-network-utilities) for `GlobalAdam` details).

### Trial Completion

 After all sessions complete, `Trial.run()` [slm_lab/experiment/control.py199-208](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L199-L208) calls `analysis.analyze_trial(trial_spec, session_metrics_list)`, which aggregates session-level metrics into trial metrics (strength, efficiency, stability, consistency) and generates trial-level plots. The scalar metrics dict is returned to the caller.

## Experiment

 `Experiment` is the top-level orchestrator. It does not manage sessions directly; instead it delegates to Ray Tune search which spawns `Trial`s.

 
### Initialization

 [slm_lab/experiment/control.py218-223](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L218-L223)

 
```
Experiment.__init__(spec, keep_trials=3)
```

 
 - Saves the spec to disk via `spec_util.save(spec, unit="experiment")`.
 - `keep_trials` controls how many top trial models to retain on disk after search.
 
 
### Execution

 [slm_lab/experiment/control.py228-235](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L228-L235)

 `Experiment.run()` performs three steps:

 
 - **`search.run_ray_search(self.spec)`** — runs Ray Tune, which spawns trials using the search space defined in `spec["search"]`. Each trial in the search calls `build_run_trial(spec)` which internally ticks the spec and runs a `Trial`. Returns a `trial_data_dict` mapping trial index to metrics + config.
 - **`analysis.analyze_experiment(self.spec, trial_data_dict)`** — aggregates all trial metrics into `experiment_df`, saves it, and generates experiment-level plots.
 - **`search.cleanup_trial_models(self.spec, experiment_df, keep_top_n=self.keep_trials)`** — deletes model checkpoints from all but the top-N trials by strength to reduce disk usage. Disabled when `keep_trials == -1`.

## Output File Naming Convention

 File paths are constructed by `util.get_prepath` and `spec_util.tick`. The prepath pattern is:

 
```
data/{spec_name}_{experiment_ts}/{folder}/{spec_name}_t{trial}_s{session}_{suffix}
```

 
| File | When saved | Saved by |
|---|---|---|
| *_spec.json | At Trial.__init__ and Experiment.__init__ | spec_util.save() |
| model/*_t{t}_s{s}.pt | At each log checkpoint and session end | agent.save() |
| model/*_t{t}_s{s}_best.pt | When total_reward_ma improves | agent.save(ckpt="best") |
| info/*_t{t}_s{s}_session_df_train.csv | At each log checkpoint | analysis.analyze_session() |
| info/*_t{t}_s{s}_session_df_eval.csv | At session end | analysis.analyze_session() |
| info/*_t{t}_s{s}_session_metrics_train.json | At each log checkpoint | analysis.analyze_session() → calc_session_metrics() |
| info/*_t{t}_s{s}_session_metrics_eval.json | At session end | analysis.analyze_session() |
| info/*_t{t}_trial_metrics.json | At trial end | analysis.analyze_trial() → calc_trial_metrics() |
| info/*_experiment_df.csv | At experiment end | analysis.analyze_experiment() |
| graph/* | Alongside each analysis call | viz.plot_session/trial/experiment() |

## Key Configuration Fields

 These `meta` spec fields directly control Session and Trial behavior:

 
| Field | Controls |
|---|---|
| max_session | Number of repeated sessions per trial |
| max_trial | Number of trials in a search experiment |
| log_frequency | Frame interval for training log checkpoints |
| eval_frequency | Frame interval for rigorous eval checkpoints |
| rigorous_eval | If true, runs gen_avg_return against a separate eval_env |
| distributed | If False, runs normal sessions; otherwise runs Hogwild distributed sessions |
| resume | If true, restores train_df from disk at session init |
