## The `Algorithm` Abstract Base Class

 Defined in [slm_lab/agent/algorithm/base.py12-136](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/base.py#L12-L136) the `Algorithm` ABC establishes the interface every algorithm must implement. The `@lab_api` decorator marks public interface methods; `@abstractmethod` marks those that must be overridden by subclasses.

### Constructor

 `Algorithm.__init__` [slm_lab/agent/algorithm/base.py15-25](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/agent/algorithm/base.py#L15-L25) stores a reference to the owning `agent`, extracts `algorithm_spec`, `memory_spec`, and `net_spec` from `agent.agent_spec`, then immediately calls `init_algorithm_params()` and `init_nets(global_nets)`.

 
### Abstract Methods

 
| Method | Signature | Purpose |
|---|---|---|
| init_algorithm_params | (self) | Load hyperparameters from algorithm_spec, create schedulers |
| init_nets | (self, global_nets=None) | Instantiate neural networks and optimizers |
| sample | (self) | Sample a batch from agent.memory, convert to tensors |
| train | (self) | Run one training iteration if self.to_train == 1 |
| update | (self) | Decay exploration variables after training |

 
### Concrete Methods

 
| Method | Notes |
|---|---|
| end_init_nets | Asserts all names in self.net_names end with "net"; calls self.load() on resume/enjoy mode |
| to_action | Converts a torch.Tensor action to a numpy array with the correct shape for single or vectorized envs |
| save | Delegates to net_util.save_algorithm(self, ckpt) |
| load | Delegates to net_util.load_algorithm(self); resets scheduler start values |

 The `slm_lab/agent/algorithm/policy_util.py` module provides utilities that are used by every algorithm for action sampling and exploration variable scheduling. It is not an algorithm itself, but algorithms import from it directly.

## How Algorithms Connect to the Rest of the Agent

 **Algorithm Wiring at Runtime**

 
```

```

 
 - The `Agent` creates its algorithm by passing itself to the `Algorithm` subclass constructor, identified by `algorithm_spec['name']`.
 - The algorithm holds a back-reference (`self.agent`) and reads `agent.state_dim`, `agent.action_dim`, `agent.is_discrete`, and `agent.memory`.
 - `self.to_train` is the flag that gates training: the `Agent.update()` method sets it to `1` when the training trigger condition is met (see [Agent and MetricsTracker](https://deepwiki.com/kengz/SLM-Lab/5.1-agent-and-metricstracker)), and `train()` resets it to `0` after completing a training step.
 - All network model names are stored in `self.net_names` so that `save()` and `load()` can iterate them generically.
