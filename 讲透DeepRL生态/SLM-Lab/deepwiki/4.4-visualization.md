  This page documents `slm_lab/lib/viz.py`, the module responsible for generating all plots in SLM Lab. It covers the four main plot functions (`plot_session`, `plot_trial`, `plot_experiment`, `plot_multi_trial`), the `save_image` utility, what each plot displays, when each is generated during an experiment, and how to invoke plotting manually.

 For the metrics that feed into these plots (strength, efficiency, stability, consistency), see [Metrics and Analysis](https://deepwiki.com/kengz/SLM-Lab/4.2-metrics-and-analysis). For the experiment lifecycle that triggers plotting, see [Control Flow: Experiment, Trial, and Session](https://deepwiki.com/kengz/SLM-Lab/4.1-control-flow:-experiment-trial-and-session).

## Module Overview

 `slm_lab/lib/viz.py` uses [Plotly](https://plotly.com/python/) to render all graphs and writes them as PNG files via `save_image`. The module is imported by `slm_lab/experiment/analysis.py`, which calls plot functions after computing metrics at each level of the hierarchy.

 Key module-level constant:

 
| Constant | Value | Purpose |
|---|---|---|
| PLOT_MA_WINDOW | 100 | Rolling window size for moving-average plots. Also used in MetricsTracker.ckpt() to compute total_reward_ma. |

 When running in a Jupyter notebook, `init_notebook_mode` is called and plots are rendered inline via `iplot`. On a standard terminal run, plots are only written to disk.

## plot_session

 **Function:** `plot_session(session_spec, session_metrics, session_df, df_mode='eval', ma=False)`

 [slm_lab/lib/viz.py136-181](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/viz.py#L136-L181)

 Generates per-session line charts. Called twice per checkpoint: once without moving average and once with `ma=True`.

 
### What it plots

 
| Series | X Axis | Condition |
|---|---|---|
| mean_returns | frames | Always |
| strengths | frames | Only if log_extra() |
| sample_efficiencies | frames | Only if log_extra() |
| training_efficiencies | opt_steps | Only if log_extra() |
| stabilities | frames | Only if log_extra() |
| loss | frame | Always, if column exists in session_df |
| explore_var | frame | Always, if column exists in session_df |
| entropy | frame | Always, if column exists in session_df |

 When `ma=True`, all metric series are passed through `calc_sr_ma()` (a `PLOT_MA_WINDOW`-period rolling mean) before plotting. The training-derived columns (`loss`, `explore_var`, `entropy`) are only plotted when `ma=False`.

 
### Output file naming

 
```
{graph_prepath}_session_graph_{df_mode}_{name}_vs_{time}.png
```

 Example:

 
```
data/ppo_cartpole_2024_01_01_120000/graph/ppo_cartpole_t0_s0_session_graph_train_mean_returns_vs_frames.png
```

 
### When called

 
 - **During training** (`try_ckpt`): every `log_frequency` frames, with `df_mode='train'` [slm_lab/experiment/control.py93-94](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L93-L94)
 - **At session end** (`Session.run`): once with `df_mode='eval'` [slm_lab/experiment/control.py141](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L141-L141)

## plot_trial

 **Function:** `plot_trial(trial_spec, trial_metrics, ma=False)`

 [slm_lab/lib/viz.py184-226](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/viz.py#L184-L226)

 Generates per-trial charts that aggregate results across all sessions of the trial. Each series is displayed as a mean ± std envelope using `plot_mean_sr`, except `consistencies` which is a single series plotted with `plot_sr`.

 
### What it plots

 
| Series | X Axis | Plot Type | Condition |
|---|---|---|---|
| mean_returns | frames | Mean ± std envelope | Always |
| strengths | frames | Mean ± std envelope | Only if log_extra() |
| sample_efficiencies | frames | Mean ± std envelope | Only if log_extra() |
| training_efficiencies | opt_steps | Mean ± std envelope | Only if log_extra() |
| stabilities | frames | Mean ± std envelope | Only if log_extra() |
| consistencies | frames | Single line | Only if log_extra() |

 `mean_returns` and `mean_returns_ma` graphs are also saved directly to the `prepath` directory (not just `graph_prepath`) for convenient top-level access.

 
### Output file naming

 
```
{graph_prepath}_trial_graph_{name}_vs_{time}.png
{prepath}_trial_graph_mean_returns_vs_{time}.png   # duplicate for easy access
```

 
### When called

 
 - **During training** (`try_ckpt`): every `log_frequency` frames for `session_index == 0`, loading session metrics from disk [slm_lab/experiment/control.py95-96](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/control.py#L95-L96)

## plot_experiment and plot_experiment_trials

 
### plot_experiment

 **Function:** `plot_experiment(experiment_spec, experiment_df, metrics_cols)`

 [slm_lab/lib/viz.py229-277](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/viz.py#L229-L277)

 Generates a grid of scatter plots: each row is a metric, each column is a hyperparameter. Each point represents one trial. Markers are colored by `strength` using the `YlGnBu` colorscale.

 
 - Y axes: all columns from `METRICS_COLS` except `frame`; filtered further when `log_extra()` is disabled.
 - X axes: all columns from `experiment_df` that are not in `METRICS_COLS` (i.e., hyperparameter columns).
 
 The figure width and height scale with the number of trials and metrics:

 
```
width  = 100 + 300 * len(x_cols)
height = 200 + 300 * len(y_cols)
```

 Output is saved to both `graph_prepath` and `prepath`:

 
```
{graph_prepath}_experiment_graph.png
{prepath}_experiment_graph.png
```

## plot_multi_trial

 **Function:** `plot_multi_trial(trial_metrics_path_list, legend_list, title, graph_prepath, ma=False, name_time_pairs=None, frame_scales=None, palette=None, showlegend=True)`

 [slm_lab/lib/viz.py323-370](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/viz.py#L323-L370)

 This is the lowest-level multi-trial overlay function and can also be called directly for custom comparison plots. It:

 
 - Reads each trial's `_trial_metrics.json` file using `util.read(path)['local']`.
 - Calls `restore_metric_types()` to convert any JSON-deserialized lists back to `pd.Series`.
 - Optionally rescales frame axes using `frame_scales` (useful for comparing async-trained runs).
 - Produces one figure per `(name, time)` pair in `name_time_pairs`, delegating to `plot_multi_local_metrics`.
 
 `plot_multi_local_metrics` calls `plot_mean_sr` for each trial, giving each a distinct color from a shared palette and merging the traces into a single figure.

 
### Output file naming

 
```
{graph_prepath}_multi_trial_graph_{name}_vs_{time}.png
{prepath}_multi_trial_graph_mean_returns_vs_{time}.png  # for important graphs
```

## save_image

 **Function:** `save_image(figure, filepath)`

 [slm_lab/lib/viz.py124-131](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/lib/viz.py#L124-L131)

 Writes a Plotly `Figure` to disk as a PNG at 2× scale using `pio.write_image`. All plot functions route their output through `save_image`.

 Behavior:

 
 - **In test mode** (`PY_ENV == 'test'`): returns immediately without writing anything.
 - **On headless servers**: `pio.write_image` may fail without a display. The error is caught and a warning is logged recommending `xvfb-run -a` as a prefix.
 - The `filepath` is resolved to an absolute path via `util.smart_path` before writing.

## Output Directory Layout

 All graphs are written to the `graph/` subdirectory inside the experiment data folder. The `graph_prepath` is set in `spec_util.tick()` by calling `util.insert_folder(prepath, 'graph')`.

 
```
data/{spec_name}_{experiment_ts}/
├── graph/
│   ├── {spec_name}_t0_s0_session_graph_train_mean_returns_vs_frames.png
│   ├── {spec_name}_t0_s0_session_graph_train_mean_returns_ma_vs_frames.png
│   ├── {spec_name}_t0_s0_session_graph_train_loss_vs_frame.png
│   ├── {spec_name}_t0_trial_graph_mean_returns_vs_frames.png
│   ├── {spec_name}_t0_trial_graph_mean_returns_ma_vs_frames.png
│   ├── {spec_name}_experiment_graph.png
│   └── {spec_name}_multi_trial_graph_mean_returns_vs_frames.png
├── {spec_name}_t0_trial_graph_mean_returns_vs_frames.png   # duplicate
└── {spec_name}_experiment_graph.png                        # duplicate
```

 The duplicates at `prepath` (without `graph/`) are explicitly saved for the most important plots (`mean_returns` and `experiment_graph`) to provide easy top-level access without navigating into subdirectories.

## The log_extra Flag

 Several plot series are conditional on the `log_extra()` environment variable. When disabled (the default in most runs), only `mean_returns` graphs are generated to reduce I/O overhead. When enabled, all derived metrics (strengths, efficiencies, stabilities, consistencies) are also plotted.

 
| log_extra() | Session plots | Trial plots | Experiment plots |
|---|---|---|---|
| False | mean_returns only | mean_returns only | total_reward_ma only |
| True | all 5 metrics + training vars | all 6 metrics | all non-frame metrics |

 This flag also controls emission of the extra metrics in `analyze_session` and the experiment scatter plot's Y-axis set.

## Retro Analysis

 Plots can be regenerated after a run completes using `slm_lab/experiment/retro_analysis.py`. The `retro_analyze(predir)` function:

 
 - Calls `retro_analyze_sessions(predir)` — re-reads saved `session_df` CSVs and calls `analysis.analyze_session()` for each.
 - Calls `retro_analyze_trials(predir)` — re-reads saved session metrics JSONs and calls `analysis.analyze_trial()` for each.
 - Calls `retro_analyze_experiment(predir)` — re-reads `_trial_data_dict.json` and calls `analysis.analyze_experiment()`.
 
 All three eventually invoke the same `viz.plot_*` functions, so the output is identical to what would have been generated during the live run.
