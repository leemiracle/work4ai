  This page documents the random baseline system in SLM Lab: how baselines are generated, stored, retrieved on demand, and how they feed into the strength metric used throughout the analysis pipeline. For details on how metrics like strength, efficiency, stability, and consistency are computed and used in experiment reporting, see [Metrics and Analysis](https://deepwiki.com/kengz/SLM-Lab/4.2-metrics-and-analysis).

 
---

 
## Purpose

 A **random baseline** is the expected total reward achieved by a uniformly random policy in a given environment. It is used as the zero-point for the **strength** metric: an agent's performance is only considered meaningful insofar as it exceeds what a random agent would achieve.

 Without a baseline, raw total rewards are not comparable across environments with different reward scales. The random baseline normalizes for this.

### `gen_random_return(env_name, seed)`

 [slm_lab/spec/random_baseline.py61-76](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/random_baseline.py#L61-L76)

 Runs a **single episode** of the named Gymnasium environment using a uniformly random policy. The episode is seeded with `seed` for reproducibility. Returns the total accumulated reward for that episode.

 
 - Creates a fresh environment via `gym.make(env_name)` (no rendering).
 - Calls `env.action_space.sample()` at every step.
 - Terminates on `terminated or truncated`.
 - Closes the environment before returning.
 
 This function is designed to be called in parallel; each parallel worker receives a different seed.

 
---

 
### `gen_random_baseline(env_name, num_eval=100)`

 [slm_lab/spec/random_baseline.py79-84](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/random_baseline.py#L79-L84)

 Generates a baseline by averaging `num_eval` independent random episodes. Uses `util.parallelize` to distribute the `gen_random_return` calls across CPU workers, passing `(env_name, seed)` tuples for seeds `0` through `num_eval - 1`.

 Returns a dict: `{'mean': float, 'std': float}`.

 
---

 
### `get_random_baseline(env_name)`

 [slm_lab/spec/random_baseline.py87-103](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/random_baseline.py#L87-L103)

 The primary retrieval interface used by the analysis pipeline. Behavior:

 
 - Reads the current contents of `_random_baseline.json`.
 - If `env_name` is already present, returns the cached `{'mean': float, 'std': float}` dict.
 - If not present, calls `gen_random_baseline(env_name, NUM_EVAL)` to generate it live.
 - Writes the updated dict back to `_random_baseline.json` immediately.
 - Returns `None` if the environment fails to initialize (exception caught, logged as a warning).
 
 This means new environments are handled transparently during training without any manual pre-generation step. The file is updated after each new entry so partial runs are preserved.

 
---

 
### `enum_envs()`

 [slm_lab/spec/random_baseline.py24-58](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/random_baseline.py#L24-L58)

 Used by `main()` for bulk generation. Enumerates all registered Gymnasium environments, applying two filters:

 
 - **Skip list**: Environments known to fail (`tabular/Blackjack-v0`, `GymV21Environment-v0`, etc.) are excluded.
 - **ALE deduplication**: For Atari environments backed by `ale_py`, only the `ALE/`-prefixed variant is kept; legacy non-prefixed variants are skipped.
 - **Version deduplication**: Among environments sharing the same base name (e.g., `HalfCheetah-v4`, `HalfCheetah-v5`), only the latest version is kept.
 
 Returns a sorted list of environment IDs.

 
---

 
### `main()` — Bulk Generation

 [slm_lab/spec/random_baseline.py106-120](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/spec/random_baseline.py#L106-L120)

 Runs `get_random_baseline` for every environment returned by `enum_envs()`. Invoked directly:

 
```
python slm_lab/spec/random_baseline.py
```

 This is the standard way to pre-populate `_random_baseline.json` for a new installation or after a Gymnasium update. It logs progress as `Generating random baseline for {env_name}: {idx+1}/{len(envs)}`.

### The Strength Metric

 Defined in `calc_strength` [slm_lab/experiment/analysis.py56-66](https://github.com/kengz/SLM-Lab/blob/d3128a8a/slm_lab/experiment/analysis.py#L56-L66):

 
```
local_strs = mean_returns - mean_rand_returns
str_ = local_strs.mean()
```

 
 - **`mean_returns`**: A pandas Series of checkpoint total rewards recorded during training.
 - **`mean_rand_returns`**: The scalar `mean` from the random baseline dict.
 - **`local_strs`**: Per-checkpoint strength (element-wise subtraction).
 - **`str_`**: Overall session strength (mean of `local_strs`).
 
 A strength of `0` means the agent performs at the level of a random policy. Positive strength means the agent outperforms random; negative means it underperforms.

 The `strength` metric then propagates into trial-level and experiment-level metrics via `calc_trial_metrics` and `calc_experiment_df`, where it is used for ranking trials (the experiment DataFrame is sorted by `strength` in descending order).

 
---

 
## Fallback Behavior

 If `get_random_baseline` returns `None` (environment instantiation failed), `calc_session_metrics` falls back to `mean_rand_returns = 0.0`. This means `strength` equals the raw mean return, which is interpretable but no longer environment-normalized. A warning is logged.

 This fallback ensures training and analysis proceed even for exotic or custom environments not yet in `_random_baseline.json`.

 
---

 
## Adding a New Environment

 No manual action is required. When an experiment runs on an environment not in `_random_baseline.json`:

 
 - `calc_session_metrics` calls `get_random_baseline(env_name)`.
 - `get_random_baseline` generates the baseline live via 100 parallel random episodes.
 - The result is written back to `_random_baseline.json`.
 - Subsequent runs for the same environment use the cached value.
 
 To pre-populate baselines for a batch of environments before running experiments, use the bulk generation script:

 
```
python slm_lab/spec/random_baseline.py
```
