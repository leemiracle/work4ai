  This document details the ML-Agents sensor system, which provides the mechanism for agents to collect observations from their environment. Sensors are the primary interface between Unity GameObjects and the ML-Agents training pipeline, converting environmental data into structured observations that can be processed by machine learning algorithms.

 
## Core Sensor Architecture

 The ML-Agents sensor system is built around a flexible interface-based architecture that allows for different types of observations while maintaining a consistent API for the training pipeline.

 
### ISensor Interface and Observation Specifications

 The `ISensor` interface defines the contract for all sensors. Each sensor must implement methods for writing observations, providing metadata about the observation space, and handling sensor lifecycle events.

## Sensor Types

 
### VectorSensor

 The `VectorSensor` handles numerical observations. It stores observations as a `List<float>` and provides methods like `AddObservation()` for various Unity types (Vector3, Quaternion, etc.) [com.unity.ml-agents/Runtime/Sensors/VectorSensor.cs137-194](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Sensors/VectorSensor.cs#L137-L194) It handles padding or truncation if the number of observations added does not match the expected `observationSize` [com.unity.ml-agents/Runtime/Sensors/VectorSensor.cs41-66](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Sensors/VectorSensor.cs#L41-L66)

### CameraSensor

 The `CameraSensor` captures visual observations from a Unity `Camera`. ### BufferSensor

 The `BufferSensor` allows observing a variable number of entities. It maintains an internal `m_ObservationBuffer` and allows appending observations until `m_MaxNumObs` is reached [com.unity.ml-agents/Runtime/Sensors/BufferSensor.cs47-65](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Sensors/BufferSensor.cs#L47-L65) This is particularly useful for environments with a dynamic number of objects.
