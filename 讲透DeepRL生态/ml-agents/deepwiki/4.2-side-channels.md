  Side channels provide a mechanism for sending and receiving data between Unity and Python that exists outside of the standard machine learning loop (observations, actions, and rewards) [com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs7-10](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs#L7-L10) This system is essential for exchanging complex data structures, environment configurations, or statistics that are not directly related to a specific agent's RL policy [docs/Custom-SideChannels.md3-7](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Custom-SideChannels.md?plain=1#L3-L7)

 
## System Architecture

 The Side Channel system relies on mirrored implementations in both Unity (C#) and Python. Every side channel is identified by a unique `Guid` (C#) or `UUID` (Python), which must match on both sides to establish a communication link [com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs25-30](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs#L25-L30) [ml-agents-envs/mlagents_envs/side_channel/side_channel.py20-21](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents-envs/mlagents_envs/side_channel/side_channel.py#L20-L21)

 
### Communication Flow

 Data is exchanged via byte arrays. Messages are queued and then processed during the simulation step [com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs21-23](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs#L21-L23)

 **Unity to Python Flow:**

 
 - Unity side creates an `OutgoingMessage` [com.unity.ml-agents/Runtime/SideChannels/OutgoingMessage.cs11-12](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/OutgoingMessage.cs#L11-L12)
 - Data is written to the message (e.g., `WriteFloat32`, `WriteString`) [com.unity.ml-agents/Runtime/SideChannels/OutgoingMessage.cs56-65](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/OutgoingMessage.cs#L56-L65)
 - The message is queued via `QueueMessageToSend(msg)` [com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs64-67](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs#L64-L67)
 - The Python side receives the message in `on_message_received(msg)` [ml-agents-envs/mlagents_envs/side_channel/side_channel.py32-38](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents-envs/mlagents_envs/side_channel/side_channel.py#L32-L38)
 
 **Python to Unity Flow:**

 
 - Python side creates an `OutgoingMessage` [ml-agents-envs/mlagents_envs/side_channel/outgoing_message.py1-5](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents-envs/mlagents_envs/side_channel/outgoing_message.py#L1-L5)
 - The message is queued via `queue_message_to_send(msg)` [ml-agents-envs/mlagents_envs/side_channel/side_channel.py24-29](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents-envs/mlagents_envs/side_channel/side_channel.py#L24-L29)
 - Unity side receives the message in `OnMessageReceived(IncomingMessage msg)` [com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs58](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs#L58-L58)

## Custom Side Channels

 Users can implement their own side channels to handle specialized data.

 
### Implementation Requirements

 
 - **Unique ID:** Both C# and Python classes must share the same UUID [docs/Custom-SideChannels.md23-26](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Custom-SideChannels.md?plain=1#L23-L26)
 - **Message Handling:** 
 - Implement `OnMessageReceived` (Unity) and `on_message_received` (Python) to deserialize incoming data [docs/Custom-SideChannels.md19-21](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Custom-SideChannels.md?plain=1#L19-L21) [docs/Custom-SideChannels.md40-42](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Custom-SideChannels.md?plain=1#L40-L42)
 - Data must be read in the exact order it was written to the `OutgoingMessage` [docs/Custom-SideChannels.md20-21](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Custom-SideChannels.md?plain=1#L20-L21)
 - **Registration:** 
 - Unity: Call `SideChannelManager.RegisterSideChannel(myChannel)` [com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs14-15](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/SideChannels/SideChannel.cs#L14-L15)
 - Python: Pass the channel instance into the `UnityEnvironment` constructor [docs/Custom-SideChannels.md60-63](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Custom-SideChannels.md?plain=1#L60-L63)
