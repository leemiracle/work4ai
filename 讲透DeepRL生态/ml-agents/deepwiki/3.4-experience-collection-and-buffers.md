  This document covers the ML-Agents experience collection and buffer management system, which is responsible for gathering agent experiences from the Unity environment and organizing them into efficient data structures for training algorithms. The system handles the transformation of raw environment observations, actions, and rewards into structured trajectories that can be consumed by reinforcement learning trainers.

 
## Core Data Structures

 The experience collection system is built around several key data structures that represent different levels of agent experience data.

 
### AgentBuffer and AgentBufferField

 The `AgentBuffer` class serves as the primary container for storing agent experiences during training. It implements a dictionary-like interface where keys represent different types of data (observations, actions, rewards, etc.) and values are `AgentBufferField` objects containing the actual data sequences.

## Buffer Management and Operations

 The buffer system provides operations for managing training data across different algorithm requirements.

 
### Buffer Key System

 ML-Agents uses a hierarchical key system to organize data. `AgentBufferKey` is a Union of `BufferKey` (Enum), `ObservationKeyPrefix` tuples, and `RewardSignalKeyPrefix` tuples [ml-agents/mlagents/trainers/buffer.py70-72](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents/mlagents/trainers/buffer.py#L70-L72)

 **Key Mapping Utility:**

 
 - `ObsUtil.get_name_at(index)`: Generates a key for current observations [ml-agents/mlagents/trainers/trajectory.py48-52](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents/mlagents/trainers/trajectory.py#L48-L52)
 - `ObsUtil.get_name_at_next(index)`: Generates a key for next observations [ml-agents/mlagents/trainers/trajectory.py55-59](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents/mlagents/trainers/trajectory.py#L55-L59)
 - `RewardSignalUtil`: Provides static methods to generate keys for specific reward signals (e.g., `rewards_key`, `value_estimates_key`) [ml-agents/mlagents/trainers/buffer.py75-95](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents/mlagents/trainers/buffer.py#L75-L95)

### Batch Processing and Sampling

 The `AgentBuffer` class provides methods to extract data for neural network training:

 
 - **`make_mini_batch(start, end)`**: Extracts a slice of data across all fields in the buffer [ml-agents/mlagents/trainers/buffer.py397-417](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents/mlagents/trainers/buffer.py#L397-L417)
 - **`sample_mini_batch(batch_size, sequence_length)`**: Randomly samples indices and retrieves sequences of a specific length, essential for training recurrent models [ml-agents/mlagents/trainers/buffer.py419-443](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents/mlagents/trainers/buffer.py#L419-L443)
