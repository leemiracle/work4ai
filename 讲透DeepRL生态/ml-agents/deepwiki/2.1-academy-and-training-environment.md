  This document covers the Academy singleton pattern, environment orchestration, and episode management within the Unity ML-Agents Toolkit. The Academy serves as the central coordinator for training environments, managing the lifecycle of agents, communication with Python trainers, and the synchronization of environment steps.

 
## Academy Singleton Pattern

 The `Academy` class implements a thread-safe lazy singleton pattern using `Lazy<Academy>` [com.unity.ml-agents/Runtime/Academy.cs117-132](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L117-L132) It serves as the central orchestrator for all ML-Agents functionality within a Unity environment. The Academy instance is typically initialized the first time it is accessed, often by the first `Agent` initialized in a scene [com.unity.ml-agents/Runtime/Academy.cs52-54](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L52-L54)

 
### Academy Initialization and Versioning

 At initialization, the Academy attempts to connect to a Python training process through an `ICommunicator` [com.unity.ml-agents/Runtime/Academy.cs56-57](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L56-L57) It maintains several critical version strings to ensure compatibility:

 
 - `k_ApiVersion`: The communication protocol version (currently "1.5.0") [com.unity.ml-agents/Runtime/Academy.cs104](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L104-L104)
 - `k_PackageVersion`: The Unity package version (currently "4.0.3") [com.unity.ml-agents/Runtime/Academy.cs110](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L110-L110)

## Environment Orchestration

 The Academy orchestrates environment execution through the `EnvironmentStep()` function [com.unity.ml-agents/Runtime/Academy.cs577](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L577-L577) This method ensures all agents operate in lockstep, which is essential for deterministic training.

 
### Step Execution Sequence

 The step sequence is triggered either automatically by `AcademyFixedUpdateStepper.FixedUpdate()` [com.unity.ml-agents/Runtime/AcademyFixedUpdateStepper.cs33-45](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/AcademyFixedUpdateStepper.cs#L33-L45) or manually.

 
| Sequence Order | Event/Method | Code Responsibility |
|---|---|---|
| 1 | AgentPreStep | Triggered for components like DecisionRequester to call RequestDecision() com.unity.ml-agents/Runtime/DecisionRequester.cs97-113 |
| 2 | AgentIncrementStep | Increments internal step counters for all active agents. |
| 3 | DecideAction | Agents determine their next action via Heuristic, Inference, or External Policy. |
| 4 | AgentSendState | Agents collect observations from ISensor implementations com.unity.ml-agents/Runtime/Academy.cs605 |
| 5 | AgentAct | Agents apply actions through IActuator implementations. |
| 6 | Communicator.Exchange() | Sends observations to Python and receives new actions com.unity.ml-agents/Runtime/Academy.cs614 |

## Episode Management

 The Academy manages the global episode lifecycle. An episode count is incremented each time the environment is reset [com.unity.ml-agents/Runtime/Academy.cs148-150](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L148-L150)

 
 - **Step Counting**: The Academy tracks `m_StepCount` (steps in current episode) and `m_TotalStepCount` (total simulation steps) [com.unity.ml-agents/Runtime/Academy.cs152-160](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L152-L160)
 - **Forced Resets**: The `ForcedFullReset()` method [com.unity.ml-agents/Runtime/Academy.cs520](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L520-L520) triggers the `AgentForceReset` event, causing all agents to reset their state and call `OnEpisodeBegin()`.
 - **Python-Driven Resets**: When the Python trainer sends a `RESET` command, the `RpcCommunicator` triggers the `ResetCommandReceived` event, which the Academy handles to re-initialize the environment [com.unity.ml-agents/Runtime/Communicator/RpcCommunicator.cs28](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Communicator/RpcCommunicator.cs#L28-L28)

## Communication and Compatibility

 The Academy acts as the Unity-side handshake manager for the gRPC connection established by `RpcCommunicator`.

 
### Compatibility Checks

 During initialization, the Academy verifies that the Python `API_VERSION` matches the Unity `k_ApiVersion`.

 
 - Major versions must match exactly [com.unity.ml-agents/Runtime/Communicator/RpcCommunicator.cs87-90](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Communicator/RpcCommunicator.cs#L87-L90)
 - If the major version is 0 (beta), the minor version must also match [com.unity.ml-agents/Runtime/Communicator/RpcCommunicator.cs80-86](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Communicator/RpcCommunicator.cs#L80-L86)
 - Python-side checks are performed in `UnityEnvironment._check_communication_compatibility` [ml-agents-envs/mlagents_envs/environment.py91-117](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents-envs/mlagents_envs/environment.py#L91-L117)
 
 
### Capabilities Negotiation

 The Academy stores `TrainerCapabilities` received from the Python trainer [com.unity.ml-agents/Runtime/Academy.cs215](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L215-L215) These capabilities define if the trainer supports features like:

 
 - `MultiAgentGroups`: Support for `groupId` rewards [com.unity.ml-agents/Runtime/Communicator/GrpcExtensions.cs75](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Communicator/GrpcExtensions.cs#L75-L75)
 - `HybridActions`: Support for both continuous and discrete actions [com.unity.ml-agents/Runtime/Communicator/GrpcExtensions.cs175](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Communicator/GrpcExtensions.cs#L175-L175)

## Automatic Stepping System

 The Academy provides an automatic stepping mechanism through the `AcademyFixedUpdateStepper` component.

 
 - **FixedUpdate Hook**: The stepper calls `Academy.Instance.EnvironmentStep()` inside Unity's `FixedUpdate` phase [com.unity.ml-agents/Runtime/Academy.cs31-46](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L31-L46)
 - **Ownership Check**: To prevent leaks during "Fast Enter Play Mode" or multiple scene loads, the stepper verifies it is the "owner" via `IsStepperOwner(this)` before stepping [com.unity.ml-agents/Runtime/Academy.cs37](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L37-L37)
 - **Toggleable**: Automatic stepping can be disabled via `Academy.Instance.AutomaticSteppingEnabled = false` if the developer wishes to manually call `EnvironmentStep()` [com.unity.ml-agents/Runtime/Academy.cs301-316](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Academy.cs#L301-L316)
