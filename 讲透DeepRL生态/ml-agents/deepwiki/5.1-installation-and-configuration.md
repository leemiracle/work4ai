## Environment Configuration

 
### Binary Executable Management

 The toolkit includes utilities for handling compiled Unity environments across different platforms.

 
| Platform | Executable Extension | Path Resolution Logic |
|---|---|---|
| Linux | .x86_64 | Appends extension to binary name |
| macOS | .app | Treats as a directory/bundle |
| Windows | .exe | Appends extension to binary name |

 Sources: [ml-agents-envs/mlagents_envs/registry/binary_utils.py82-89](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/ml-agents-envs/mlagents_envs/registry/binary_utils.py#L82-L89)

 
### Cloud Training Configuration

 While primarily developed for local use, the toolkit supports cloud instances.

 
 - **AWS**: Uses EC2 p2.xlarge instances with X Server enabled for visual observations [docs/Training-on-Amazon-Web-Service.md11-15](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Training-on-Amazon-Web-Service.md?plain=1#L11-L15)
 - **Azure**: Supports "Headless Mode" builds for Linux. When running headless, the `--no-graphics` flag must be appended to the `mlagents-learn` command [docs/Training-on-Microsoft-Azure.md46-62](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Training-on-Microsoft-Azure.md?plain=1#L46-L62)
 
 
## Migration and Upgrading

 When moving between versions, specific API changes must be addressed:

 
 - **Python**: Minimum version is now 3.10.12 [docs/Migrating.md8-9](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Migrating.md?plain=1#L8-L9)
 - **Unity**: Official support is for Unity 6000.0 [docs/Migrating.md22](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Migrating.md?plain=1#L22-L22)
 - **API Replacements**: 
 - `Agent.Heuristic(float[] actionsOut)` → `Agent.Heuristic(in ActionBuffers actionsOut)` [docs/Migrating.md40](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Migrating.md?plain=1#L40-L40)
 - `SensorComponent.CreateSensor()` → `CreateSensors()` (returns array) [docs/Migrating.md121](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/docs/Migrating.md?plain=1#L121-L121)
