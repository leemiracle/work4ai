  This page explains the core components for creating intelligent agents in the ML-Agents toolkit: the `Agent` class and the `BehaviorParameters` component. These components work together to enable agents to observe their environment, make decisions, and take actions.

 
## Agent Class Overview

 The `Agent` class is the foundational component for creating autonomous entities. It provides the lifecycle hooks for initialization, observation collection, and action execution.

 
### Agent Class Structure

 The `Agent` class implements several key interfaces to facilitate communication between the Unity simulation and the policy (whether remote Python, local inference, or heuristic).

## Behavior Parameters Component

 The `BehaviorParameters` component defines how an agent makes decisions. It configures the observation/action space and determines which policy type is active.

 
### Configuration and Data Flow

 The `BehaviorParameters` component acts as a factory that generates the appropriate `IPolicy` implementation at runtime based on the `BehaviorType` and environment state.

### Behavior Types

 The `BehaviorType` enum defines three primary modes:

 
 - **`Default`**: Attempts to use a remote process (Python) for training. If unavailable, it falls back to local inference (ONNX model). If no model is provided, it falls back to the heuristic [com.unity.ml-agents/Runtime/Policies/BehaviorParameters.cs16-21](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Policies/BehaviorParameters.cs#L16-L21)
 - **`HeuristicOnly`**: Always uses the `Heuristic()` method implemented in the Agent class [com.unity.ml-agents/Runtime/Policies/BehaviorParameters.cs23-26](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Policies/BehaviorParameters.cs#L23-L26)
 - **`InferenceOnly`**: Always uses the assigned neural network model for decision-making [com.unity.ml-agents/Runtime/Policies/BehaviorParameters.cs28-32](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/Policies/BehaviorParameters.cs#L28-L32)
 
 
## Decision-Making Modes

 Decisions can be triggered either automatically or manually.

 
### DecisionRequester

 The `DecisionRequester` component is a utility that automatically calls `Agent.RequestDecision()` at a fixed step interval.

 
 - **`DecisionPeriod`**: The frequency (in Academy steps) at which a decision is requested [com.unity.ml-agents/Runtime/DecisionRequester.cs20-22](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/DecisionRequester.cs#L20-L22)
 - **`TakeActionsBetweenDecisions`**: If true, the agent repeats the last action during steps where no new decision is requested [com.unity.ml-agents/Runtime/DecisionRequester.cs28-30](https://github.com/Unity-Technologies/ml-agents/blob/d52b0062/com.unity.ml-agents/Runtime/DecisionRequester.cs#L28-L30)
 
 
### Model Overriding

 During inference or validation, the `ModelOverrider` utility allows developers to swap the `.onnx` model at runtime via command-line arguments. This is often used in automated testing or evaluation pipelines.
