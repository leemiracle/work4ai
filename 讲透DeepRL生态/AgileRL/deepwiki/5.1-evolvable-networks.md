  This document covers the base evolvable network classes and architectural evolution capabilities in AgileRL. It focuses on the foundational `EvolvableModule` and `EvolvableNetwork` classes that enable neural networks to evolve their architecture during training through mutation operations.

 For specific network implementations, see [Q-Networks and Value Functions](https://deepwiki.com/AgileRL/AgileRL/5.2-q-networks-and-value-functions), [Actor Networks](https://deepwiki.com/AgileRL/AgileRL/5.3-actor-networks), and [Custom Networks and MakeEvolvable](https://deepwiki.com/AgileRL/AgileRL/5.4-custom-networks-and-makeevolvable). For the broader evolutionary optimization system, see [Evolutionary Hyperparameter Optimization](https://deepwiki.com/AgileRL/AgileRL/4-evolutionary-hyperparameter-optimization).

 
## Architecture Overview

 AgileRL's evolvable networks follow a hierarchical structure where all networks inherit from `EvolvableModule`, which provides the core mutation capabilities. The `EvolvableNetwork` class extends this to provide a standardized architecture for RL networks with automatic encoder building and head network management.

## EvolvableModule Base Class

 The `EvolvableModule` class provides the foundation for all evolvable components in AgileRL. It extends `nn.Module` with mutation capabilities and automatic network recreation.

 
### Key Features

 
| Feature | Description | Implementation |
|---|---|---|
| Mutation Decorators | Methods decorated with @mutation() become evolvable | agilerl/modules/base.py49-72 |
| Automatic Recreation | Networks are rebuilt after mutations | agilerl/modules/base.py75-136 |
| Parameter Preservation | Weights are preserved when possible during evolution | agilerl/modules/base.py423-453 |
| Mutation Context | Tracks nested mutations to avoid redundant recreation | agilerl/modules/base.py75-165 |

### Built-in Mutation Methods

 Different evolvable modules provide specific mutation methods:

 
| Module | Layer Mutations | Node Mutations |
|---|---|---|
| EvolvableMLP | add_layer(), remove_layer() | add_node(), remove_node() |
| EvolvableCNN | add_layer(), remove_layer() | add_channel(), remove_channel(), change_kernel() |
| EvolvableNetwork | (inherited from components) | add_latent_node(), remove_latent_node() |
