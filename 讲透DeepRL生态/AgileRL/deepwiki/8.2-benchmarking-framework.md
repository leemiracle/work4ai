## Purpose and Scope

 The benchmarking framework provides comprehensive testing and evaluation scripts for all reinforcement learning paradigms supported by AgileRL. These scripts validate algorithm implementations, test evolutionary hyperparameter optimization effectiveness, and enable performance comparisons across different RL approaches. The framework covers single-agent, multi-agent, offline, and contextual bandit scenarios, with support for both standard and distributed training configurations.

 For information about the underlying training systems, see [Training Framework](https://deepwiki.com/AgileRL/AgileRL/3-training-framework). For configuration management details, see [Configuration System](https://deepwiki.com/AgileRL/AgileRL/8.1-configuration-system).

## Off-Policy Benchmarking

 The off-policy benchmarking system supports algorithms like DQN, DDPG, and TD3, with specialized configurations for different algorithm requirements.

 
### Standard Off-Policy Testing

 The `benchmarking_off_policy.py` script provides comprehensive testing for off-policy algorithms with experience replay.

 **Key Components:**

 
 - **Memory Management**: Uses `ReplayBuffer` for experience storage [benchmarking/benchmarking_off_policy.py40](https://github.com/AgileRL/AgileRL/blob/03307c7b/benchmarking/benchmarking_off_policy.py#L40-L40)
 - **Algorithm Support**: Configurable for DQN, DDPG, TD3 with appropriate hyperparameter configs [benchmarking/benchmarking_off_policy.py74-112](https://github.com/AgileRL/AgileRL/blob/03307c7b/benchmarking/benchmarking_off_policy.py#L74-L112)
 - **Network Flexibility**: Supports both custom networks via `DummyEvolvable` and config-based networks [benchmarking/benchmarking_off_policy.py61-72](https://github.com/AgileRL/AgileRL/blob/03307c7b/benchmarking/benchmarking_off_policy.py#L61-L72)
 
 **Hyperparameter Configuration:**

 
| Algorithm | Learning Rates | Special Parameters |
|---|---|---|
| DQN | Single lr | Epsilon decay params |
| DDPG/TD3 | lr_actor, lr_critic | Actor-critic specific |

 
### Rainbow DQN Benchmarking

 The `benchmarking_rainbow.py` script provides specialized testing for the Rainbow DQN algorithm with its advanced features.

 **Advanced Features Tested:**

 
 - **Prioritized Experience Replay**: `PrioritizedReplayBuffer` with alpha parameter [benchmarking/benchmarking_rainbow.py44-49](https://github.com/AgileRL/AgileRL/blob/03307c7b/benchmarking/benchmarking_rainbow.py#L44-L49)
 - **Multi-Step Learning**: `MultiStepReplayBuffer` for n-step returns [benchmarking/benchmarking_rainbow.py50-67](https://github.com/AgileRL/AgileRL/blob/03307c7b/benchmarking/benchmarking_rainbow.py#L50-L67)
 - **Distributional RL**: `RainbowQNetwork` with value distribution support [benchmarking/benchmarking_rainbow.py93-99](https://github.com/AgileRL/AgileRL/blob/03307c7b/benchmarking/benchmarking_rainbow.py#L93-L99)
 
 *Sources: benchmarking/benchmarking_off_policy.py, benchmarking/benchmarking_rainbow.py*

 
## On-Policy Benchmarking

 The on-policy benchmarking system focuses on algorithms like PPO that don't use experience replay.

 **Distinctive Features:**

 
 - **No Replay Buffer**: Direct trajectory-based learning [benchmarking/benchmarking_on_policy.py110-126](https://github.com/AgileRL/AgileRL/blob/03307c7b/benchmarking/benchmarking_on_policy.py#L110-L126)
