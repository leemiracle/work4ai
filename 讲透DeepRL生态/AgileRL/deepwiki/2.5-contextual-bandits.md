# Contextual Bandits

  This page documents AgileRL's contextual bandit algorithms, which solve multi-armed bandit problems with contextual information. Contextual bandits are a simplified form of reinforcement learning where actions are selected based on context (observations) but there are no sequential state transitions - each decision is independent.

 AgileRL provides two neural contextual bandit algorithms: `NeuralUCB` and `NeuralTS`, which use neural networks to estimate reward functions and handle uncertainty estimation for effective exploration-exploitation trade-offs.

 For full sequential reinforcement learning algorithms, see [Off-Policy Algorithms](https://deepwiki.com/AgileRL/AgileRL/2.1-off-policy-algorithms) and [On-Policy Algorithms](https://deepwiki.com/AgileRL/AgileRL/2.2-on-policy-algorithms).

 
## Overview

 Contextual bandits sit between supervised learning and full reinforcement learning. Unlike standard multi-armed bandits that have no context, contextual bandits receive observations (context) that inform action selection. Unlike full RL, there are no sequential states or long-term rewards to consider.

## Algorithm Implementations

 
### NeuralUCB

 The `NeuralUCB` class implements Neural Upper Confidence Bound, which uses deterministic upper confidence bounds for action selection with neural network function approximation.

 
```

```

 **Key Methods:**

 
 - `get_action()` - Computes UCB values and selects action with highest upper confidence bound
 - `learn()` - Updates network parameters using MSE loss with L2 regularization
 - `init_params()` - Initializes covariance matrix and reference parameters

### NeuralTS

 The `NeuralTS` class implements Neural Thompson Sampling, which uses stochastic sampling from posterior distributions for action selection.

 
```

```

 **Key Difference from NeuralUCB:**

 
 - Uses `torch.normal(mean=μ, std=γ√(g^T Σ⁻¹ g))` for stochastic action value sampling
 - Action selection is based on samples from posterior rather than deterministic upper bounds

## Uncertainty Estimation and Learning

 Both algorithms implement sophisticated uncertainty estimation through covariance matrix tracking and Sherman-Morrison-Woodbury updates.

 
### Covariance Matrix Management

 
```

```

 **Key Mathematical Components:**

 
| Component | Purpose | Implementation |
|---|---|---|
| sigma_inv | Inverse covariance matrix | lamb * torch.eye(numel) |
| g | Gradient matrix | Per-action gradients normalized by √(layer_width) |
| Sherman-Morrison | Efficient rank-1 update | sigma_inv - (sigma_inv @ v @ v.T @ sigma_inv) / (1 + v.T @ sigma_inv @ v) |
| theta_0 | Reference parameters | Initial network parameters for regularization |

## Configuration and Usage

 
### Algorithm Parameters

 
| Parameter | NeuralUCB Default | NeuralTS Default | Description |
|---|---|---|---|
| gamma | 1.0 | 1.0 | Exploration scaling factor |
| lamb | 1.0 | 1.0 | Regularization parameter λ |
| reg | 0.000625 | 0.000625 | L2 regularization coefficient |
| batch_size | 64 | 64 | Training batch size |
| lr | 1e-3 | 3e-3 | Learning rate |
| learn_step | 2 | 2 | Learning frequency |
