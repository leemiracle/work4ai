  This document covers AgileRL's multi-agent training orchestration system, which coordinates the training of multiple reinforcement learning agents within shared environments. The system handles agent coordination, experience sharing, environment interaction patterns, and specialized multi-agent training components.

 For information about specific multi-agent algorithms, see [Multi-Agent Algorithms](https://deepwiki.com/AgileRL/AgileRL/2.3-multi-agent-algorithms). For general training concepts, see [Training Framework](https://deepwiki.com/AgileRL/AgileRL/3-training-framework).

 
## Purpose and Scope

 Multi-agent training in AgileRL orchestrates the simultaneous training of multiple agents in cooperative, competitive, or mixed environments. The system provides specialized training loops, memory management, environment vectorization, and coordination mechanisms that differ from single-agent training paradigms.

 The multi-agent training framework supports:

 
 - Centralized training with decentralized execution patterns
 - Shared experience replay across agent populations
 - Vectorized multi-agent environment integration
 - Agent masking and selective action execution
 - Curriculum learning for multi-agent scenarios
