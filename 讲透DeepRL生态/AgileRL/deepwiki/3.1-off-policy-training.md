  This page covers AgileRL's off-policy training framework, which enables agents to learn from experiences collected by different policies through experience replay. The system supports algorithms like DQN, DDPG, TD3, and Rainbow DQN with evolutionary hyperparameter optimization.

 For on-policy training methods that don't use experience replay, see [On-Policy Training](https://deepwiki.com/AgileRL/AgileRL/3.2-on-policy-training). For offline training from static datasets, see [Offline Training](https://deepwiki.com/AgileRL/AgileRL/3.3-offline-training).

## Algorithm Support

 The off-policy training framework supports multiple algorithm families, each with specific implementation details:

 
| Algorithm | Exploration | Experience Replay | Special Features |
|---|---|---|---|
| DQN | Epsilon-greedy | Standard/Prioritized | Double Q-learning, action masking |
| RainbowDQN | Noisy networks | Multi-step, Prioritized | Distributional, dueling architecture |
| DDPG | Action noise | Standard | Continuous actions, actor-critic |
| TD3 | Action noise | Standard | Delayed policy updates, target smoothing |
