  AgileRL provides distributed training capabilities using HuggingFace Accelerate to scale reinforcement learning across multiple GPUs or nodes. All core training functions (`train_off_policy`, `train_on_policy`, `train_offline`, `train_bandits`) support distributed execution through an optional `accelerator` parameter.

 The distributed training system maintains AgileRL's evolutionary hyperparameter optimization while distributing computation across devices, requiring minimal code changes to transition from single-device to multi-device training.

## Setting Up Distributed Training

 To use distributed training in AgileRL, you need to:

 
 - Create an accelerate configuration file
 - Initialize the Accelerator object in your training script
 - Modify your training loop to work with the Accelerator
 
 
### Configuration File

 Accelerate requires a configuration file that specifies how to distribute the training. AgileRL provides an example configuration at `configs/accelerate/accelerate.yaml`.

## Conclusion

 AgileRL's distributed training capability allows for efficient utilization of multiple GPUs or machines, significantly accelerating the training process. By integrating with Hugging Face's Accelerate library, AgileRL provides a straightforward approach to distributed training that maintains the evolutionary HPO benefits while scaling to multiple compute devices.

 The design allows for minimal code changes when transitioning from single-device to multi-device training, with most of the distributed logic abstracted away by the Accelerator object and the adapted training functions.
