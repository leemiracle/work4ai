  This document covers the multi-agent reinforcement learning algorithms available in AgileRL, their architecture, and their integration with the evolutionary hyperparameter optimization system. These algorithms enable training multiple agents in shared environments for both cooperative and competitive scenarios.

 For single-agent RL algorithms, see [Off-Policy Algorithms](https://deepwiki.com/AgileRL/AgileRL/2.1-off-policy-algorithms), [On-Policy Algorithms](https://deepwiki.com/AgileRL/AgileRL/2.2-on-policy-algorithms), and [Offline Algorithms](https://deepwiki.com/AgileRL/AgileRL/2.4-offline-algorithms). For multi-agent training orchestration, see [Multi-Agent Training](https://deepwiki.com/AgileRL/AgileRL/3.4-multi-agent-training).

 
## Overview

 AgileRL provides three multi-agent algorithms that extend single-agent methods to multi-agent settings:

 
| Algorithm | Base Method | Action Spaces | Key Features |
|---|---|---|---|
| MADDPG | DDPG | Continuous, Discrete (via Gumbel-Softmax) | Centralized critic, decentralized actors |
| MATD3 | TD3 | Continuous, Discrete (via Gumbel-Softmax) | Twin critics, delayed policy updates |
| IPPO | PPO | Continuous, Discrete, MultiDiscrete, MultiBinary | Independent learning, homogeneous agent support |

## MADDPG (Multi-Agent Deep Deterministic Policy Gradient)

 MADDPG extends DDPG to multi-agent environments using a centralized critic and decentralized actors architecture. Each agent has its own actor network but critics observe the global state and all agents' actions.

### Key Features

 **Centralized Critic Architecture**: Critics use concatenated observations and actions from all agents to estimate Q-values, enabling better coordination.

 **Gumbel-Softmax for Discrete Actions**: Enables gradient-based learning in discrete action spaces through continuous relaxation.

 **Action Noise**: Supports both Ornstein-Uhlenbeck and Gaussian noise for exploration in continuous action spaces.

## IPPO (Independent Proximal Policy Optimization)

 IPPO extends PPO to multi-agent settings using independent learning, where each agent estimates its local value function. It's particularly effective for environments with many homogeneous agents.

## Evolutionary Hyperparameter Optimization

 Multi-agent algorithms integrate with AgileRL's evolutionary HPO system through:

 
 - **Population-based training**: Multiple agent instances with different hyperparameters
 - **Tournament selection**: Best-performing agents survive to next generation
 - **Mutation operators**: Architecture, parameter, and RL hyperparameter mutations
 - **Shared experience**: Population members share replay buffer for efficient exploration
 
 The evolutionary system operates at the population level while individual agents learn from shared experiences.
