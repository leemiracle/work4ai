  The Reward System in KSIM provides a flexible framework for defining and calculating rewards used in reinforcement learning tasks. Rewards are the core feedback mechanism that guides the learning process, telling the agent how well it's performing and shaping its behavior. This page documents the reward system architecture, available reward classes, and how to use them in reinforcement learning tasks.

 For information about observations (state representations), see [Observation System](https://deepwiki.com/kscalelabs/ksim/2.4-observation-system). For information about termination conditions, see [Termination System](https://deepwiki.com/kscalelabs/ksim/2.6-termination-system).

## 3. Base Classes

 
### 3.1 Reward

 The `Reward` abstract base class defines the interface for all reward functions. It serves as the foundation for the reward system.

 Key components:

 
 - **scale**: A float that determines the weight of this reward in the overall reward function
 - **scale_by_curriculum**: A boolean indicating whether the reward scale should be adjusted by the curriculum level
 - **get_reward()**: Method that takes a trajectory and returns rewards for each timestep
 - **get_markers()**: Method to provide visualization markers (optional)
 - **get_name()**: Method to get the reward name

### 3.2 StatefulReward

 `StatefulReward` extends `Reward` for cases where the reward calculation requires state information from previous timesteps.

 Key additions:

 
 - **initial_carry()**: Initializes the reward state
 - **get_reward_stateful()**: Takes a trajectory and previous state, returns reward and updated state

## 4. Helper Functions

 The reward system includes several utility functions to help with common reward computations:

 
### 4.1 Monotonic Functions

 `norm_to_reward` converts norm values to rewards using different monotonic functions:

 
 - **exp**: Exponential decay - `exp(-value/temp)`
 - **inv**: Inverse function - `1.0 / (value/temp + 1.0)`
 - **sigmoid**: Sigmoid function - `1.0 / (1.0 + exp(-value/temp))`
 
 These functions help shape raw distance/error values into appropriate rewards with adjustable temperature parameters.

 Sources: [ksim/rewards.py60-80](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/rewards.py#L60-L80)

 
## 5. Reward Types

 KSIM provides a variety of built-in reward functions to address common reinforcement learning needs.

 
### 5.1 Movement Rewards

 These rewards encourage or penalize specific movement patterns:

 
| Reward Class | Purpose | Parameters |
|---|---|---|
| LinearVelocityReward | Rewards velocity in specific dimensions | index, clip_min, clip_max, norm |
| LinearVelocityPenalty | Penalizes velocity in specific dimensions | (Same as LinearVelocityReward) |
| NaiveForwardReward | Simple reward for moving forward in X direction | clip_min, clip_max, in_robot_frame |
| AngularVelocityReward | Rewards angular velocity | index, clip_min, clip_max, norm |
| AngularVelocityPenalty | Penalizes angular velocity | (Same as AngularVelocityReward) |

 Sources: [ksim/rewards.py190-270](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/rewards.py#L190-L270)

 
### 5.2 Position and Orientation Rewards

 These rewards focus on the agent's position and orientation in space:

 
| Reward Class | Purpose | Parameters |
|---|---|---|
| BaseHeightReward | Rewards maintaining a target height | height_target, norm, temp, monotonic_fn |
| BaseHeightRangeReward | Rewards keeping height within range | z_lower, z_upper, dropoff |
| UprightReward | Rewards staying upright | - |
| NaiveForwardOrientationReward | Rewards orientation in X direction | clip_min, clip_max, in_robot_frame |
| FlatBodyReward | Rewards keeping body parallel to ground | body_indices, plane, norm |

## 7. Reward Naming and Scaling Conventions

 The reward system follows specific naming and scaling conventions:

 
 - Reward classes should end with either "Reward" or "Penalty" to indicate their purpose
 - Rewards should have positive scale values
 - Penalties should have negative scale values
