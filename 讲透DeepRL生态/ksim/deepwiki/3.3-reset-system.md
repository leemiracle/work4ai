# Reset System

  Relevant source files 
 - [ksim/resets.py](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py)
 
  The Reset System in KSIM provides mechanisms to initialize or reinitialize the physics state of simulated environments. It's a crucial component of the reinforcement learning framework as it defines how environments are set up at the beginning of episodes or after termination conditions are met. This system works closely with the Physics Engine (discussed in [Physics Engine and Data Structures](https://deepwiki.com/kscalelabs/ksim/3.1-physics-engine-and-data-structures)) to establish initial conditions for robot joints, positions, velocities, and orientations.

 
## Overview

 The Reset System consists of an abstract `Reset` base class and multiple concrete implementations that handle different aspects of environment state initialization. These resets can work independently or be combined to fully configure an environment's initial state.

### Reset Interface

 The `Reset` class defines a simple but powerful interface:

 
 - `__call__(data, curriculum_level, rng)`: The main method that performs the reset operation. It takes the current physics data, a curriculum level (for progressive difficulty), and a random number generator key, and returns the updated physics data.
 - `get_name()`: Returns the class name in snake_case format, used for logging and identification.
 - `reset_name`: A cached property that stores the result of `get_name()`.
 
 Sources: [ksim/resets.py39-52](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L39-L52)

 
## Reset Types

 KSIM provides several specialized reset implementations for different aspects of environment initialization:

 
### Position Resets

 
#### HFieldXYPositionReset

 Resets the robot's XY position within a bounded region, with height determined from a heightfield. This is useful for terrains with varying heights.

 **Key parameters:**

 
 - `bounds`: Outer bounds of the heightfield (x_bound, y_bound, z_top, z_bottom)
 - `padded_bounds`: Effective bounds with padding (lower_x, upper_x, lower_y, upper_y)
 - `x_range`, `y_range`: Range for random position offsets
 - `hfield_data`: The heightfield data
 - `robot_base_height`: Additional Z offset for the robot base
 
 Sources: [ksim/resets.py56-100](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L56-L100)

 
#### PlaneXYPositionReset

 Resets the robot's XY position and sets Z to a fixed plane height. This is used for flat terrains.

 **Key parameters:**

 
 - `bounds`: Bounds of the plane (x_bound, y_bound, z_pos)
 - `padded_bounds`: Effective bounds with padding (lower_x, upper_x, lower_y, upper_y)
 - `x_range`, `y_range`: Range for random position offsets
 - `robot_base_height`: Additional Z offset for the robot base
 
 Sources: [ksim/resets.py104-130](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L104-L130)

 
### Joint Resets

 
#### RandomJointPositionReset

 Resets the joint positions of the robot to random values within a specified scale. It can also use specified "zero" positions.

 **Key parameters:**

 
 - `scale`: Scale of random perturbations
 - `zeros`: Optional tuple of zero position values for each joint
 
 Sources: [ksim/resets.py134-167](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L134-L167)

 
#### RandomJointVelocityReset

 Resets the joint velocities of the robot to random values.

 **Key parameters:**

 
 - `scale`: Scale of random velocity perturbations
 
 Sources: [ksim/resets.py171-181](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L171-L181)

 
### Base Movement Resets

 
#### RandomBaseVelocityXYReset

 Resets the base velocity (X and Y components) of the robot to random values.

 **Key parameters:**

 
 - `scale`: Scale of random velocity perturbations
 
 Sources: [ksim/resets.py185-199](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L185-L199)

 
#### RandomHeadingReset

 Resets the heading (orientation) of the robot to a random value by setting the quaternion in the qpos.

 Sources: [ksim/resets.py301-310](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L301-L310)

 
### Reference Motion Resets

 
#### InitialMotionStateReset

 Resets the state to one from a motion bank, useful for starting from reference motions.

 **Key parameters:**

 
 - `reference_motion`: Reference motion data
 - `freejoint`: Whether to update the free joint (root) position and orientation
 
 Sources: [ksim/resets.py276-297](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L276-L297)

## Integration with Physics Simulation

 The Reset System integrates directly with the Physics Engine by modifying the `PhysicsData` object. When a reset is called:

 
 - It receives the current physics data (`mujoco.MjData` or `mjx.Data`)
 - Modifies specific fields (qpos, qvel, etc.) based on its configuration
 - Returns the updated physics data
 
 For field updates, resets use utility functions like `update_data_field` and `slice_update` that handle both MuJoCo and MJX data types correctly.

## Usage in RL Tasks

 In a typical RL task, resets are configured and provided to the `PhysicsEngine` during task initialization. The engine uses these resets when initializing or reinitializing the environment.

 A typical pattern:

 
 - Create and configure appropriate reset instances based on the task requirements
 - Return them from the `get_resets()` method in the task class
 - The physics engine applies these resets during initialization and after episode terminations
 
 
## Curriculum Integration

 All reset methods accept a `curriculum_level` parameter (a scalar value typically between 0 and 1) that can be used to progressively increase the difficulty or variability of the environment. This enables curriculum learning, where tasks start simple and gradually become more challenging as training progresses.

 For example, `RandomJointPositionReset` scales its random perturbations by the curriculum level, allowing for progressively larger joint position variations as training advances.

 Sources: [ksim/resets.py140-141](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/resets.py#L140-L141)

 
## Conclusion

 The Reset System provides a flexible and extensible framework for initializing environment states in reinforcement learning tasks. By combining different reset mechanisms, complex initial state distributions can be created, enabling efficient learning and robustness to varied conditions.

 The system's integration with curriculum learning further enhances training by allowing for progressive difficulty increases, which is particularly valuable for complex robotics tasks.
