  This page documents the setup process, dependencies, and development workflow for the KSIM framework. It covers installation requirements, project structure, development tools, and common workflows to help users and developers get started with KSIM.

 
## Overview

 KSIM is a modular framework for training reinforcement learning policies in robotic simulation. This document focuses on how to set up the project and manage its dependencies. For information about the core RL framework, see [Core RL Framework](https://deepwiki.com/kscalelabs/ksim/2-core-rl-framework), and for physics simulation details, see [Physics Simulation](https://deepwiki.com/kscalelabs/ksim/3-physics-simulation).

 
## Installation Requirements

 KSIM requires Python 3.11 or later. The framework is designed to work best with a GPU for training, though it can run on CPU for testing and development.

## Development Environment

 KSIM uses several development tools to ensure code quality:

 
 - **mypy**: Static type checking
 - **pytest**: Unit and integration testing
 - **ruff**: Code linting and formatting
 
 These tools are configured in the `pyproject.toml` file with project-specific settings:

 
| Tool | Configuration Details |
|---|---|
| pytest | Test paths: tests/Additional options: -rx -rf -x -q --full-trace |
| mypy | Strict type checking with disallow_untyped_defs=trueIgnores missing imports for third-party libraries |
| ruff | Line length: 120Target Python version: 3.10Quote style: doubleEnforces various linting rules (ANN, B, D, E, F, G, I, N, PGH, PLC, PLE, PLR, PLW, W) |

## Command-Line Tools

 KSIM exposes command-line tools through entry points defined in `setup.py`:

 
 - **ksim-generate-reference**: Generates reference motion data from BVH files
 - **ksim-visualize-reference**: Visualizes generated reference motions
 
 These tools can be used after installation without needing to execute Python scripts directly.
