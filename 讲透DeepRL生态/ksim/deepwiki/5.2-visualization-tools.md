### Marker Types

 KSIM provides factory methods to create common types of markers:

 
| Method | Description | Parameters |
|---|---|---|
| Marker.arrow() | Creates an arrow marker | magnitude, pos, direction, rgba, etc. |
| Marker.sphere() | Creates a sphere marker | pos, radius, rgba, etc. |

 Both factory methods support tracking parameters such as `target_name` and `target_type` to attach the marker to an object in the simulation.

### Tracking and Positioning

 Markers can be configured to track objects in the simulation by specifying:

 
 - `target_name`: The name of the body or geom to track
 - `target_type`: Type of the target ("body", "geom", or "root")
 - Tracking flags (`track_x`, `track_y`, `track_z`, `track_rotation`)
 
 The tracking behavior is implemented in the `get_pos_and_rot` method, which calculates the marker's position and orientation based on the tracked object.

## Rotation Utilities

 The visualization module includes utilities for working with rotations:

 
 - `rotation_matrix_from_direction`: Creates a rotation matrix that aligns a reference vector with a specified direction.
 - `quat_from_direction`: Converts a direction vector to a quaternion orientation.
 
 These functions are particularly useful for orienting geometric primitives like arrows along specific directions.
