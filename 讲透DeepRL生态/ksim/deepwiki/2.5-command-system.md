## Purpose and Overview

 The Command System in KSIM is a core component of the reinforcement learning framework that provides dynamic goals and directives to agents during training. Commands serve as instructions that guide agent behavior by specifying targets such as positions to reach, orientations to maintain, or discrete control inputs to follow. This system enables the creation of varied training scenarios and helps define success criteria for the learning process.

 Unlike the [Reward System](https://deepwiki.com/kscalelabs/ksim/2.3-reward-system) which evaluates performance, and the [Observation System](https://deepwiki.com/kscalelabs/ksim/2.4-observation-system) which provides environmental information, the Command System focuses specifically on providing directives that tell the agent "what to do" rather than "how well it's doing" or "what it can perceive."

## Curriculum Learning with Commands

 Commands support curriculum learning through the `curriculum_level` parameter in both the `initial_command` and `__call__` methods. This allows commands to adjust their complexity based on the agent's learning progress.

 For example, the `PositionCommand` includes a `curriculum_scale` parameter that controls how the target positions scale with the curriculum level:

 
```

```

 This allows the command to start with a smaller range of positions when the curriculum level is low, and gradually increase the range as the agent improves.

## Best Practices

 
 - **Match commands with appropriate rewards**: Ensure that each command has a corresponding reward that incentivizes the desired behavior.
 - **Use visualization markers**: Leverage the `get_markers()` method to visualize commands during debugging.
 - **Consider curriculum learning**: Use the `curriculum_level` parameter to gradually increase command complexity.
 - **Combine multiple commands**: For complex tasks, consider using multiple commands together (e.g., joystick control with position tracking).
 - **Name consistency**: Ensure that reward functions reference command names correctly using the `command_name` property.
