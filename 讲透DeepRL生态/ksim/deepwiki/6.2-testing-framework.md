## Purpose and Scope

 This document describes the testing framework used in the KSIM project. It covers the pytest configuration, test fixtures, model loading utilities, and test execution patterns. The testing framework is designed to ensure the reliability and correctness of the physics simulation and reinforcement learning components across different physics engines.

 For information about continuous integration workflows, see [CI/CD Workflows](https://deepwiki.com/kscalelabs/ksim/6.3-cicd-workflows).

 The KSIM testing framework uses pytest as its foundation, with custom fixtures and configurations to support testing of physics-based simulations. Tests are designed to run with both MuJoCo and MJX physics engines to ensure compatibility and consistent behavior across backends.

## Humanoid Model for Testing

 The testing framework uses a humanoid model defined in MJCF (MuJoCo XML) format. This model provides a consistent and realistic test subject for physics simulations.

 
| Component | Description |
|---|---|
| Body Structure | Torso, head, arms, legs with realistic joints |
| Actuators | 21 motors controlling various joints |
| Sensors | IMU, position, velocity, and orientation sensors |
| Contact Pairs | Defined for foot-floor interactions |
| Keyframes | Predefined poses (boxer, relaxed, tpose) |

 Sources: [tests/assets/humanoid.mjcf](https://github.com/kscalelabs/ksim/blob/9d26400d/tests/assets/humanoid.mjcf)

 The humanoid model includes:

 
 - A complete skeletal structure with appropriate joint limits
 - Realistic mass and inertia properties
 - Sensors for collecting state information
 - Predefined poses for initialization
 
 This model serves as a consistent test subject across the test suite, allowing for reproducible physics-based evaluations.

 
## Best Practices for Writing Tests

 When writing tests for KSIM, consider the following best practices:

 
 - Use the `humanoid_model` fixture to test with both MuJoCo and MJX backends
 - Mark slow tests with `@pytest.mark.slow` so they run after faster tests
 - Set explicit random seeds when testing stochastic components
 - Initialize models using standard keyframe poses for consistency
 
 
## Conclusion

 The KSIM testing framework provides a solid foundation for verifying the correctness of physics simulations and reinforcement learning algorithms. By supporting both MuJoCo and MJX backends, the framework ensures that KSIM components work consistently across different physics engines. The use of standard models and reproducible test conditions helps maintain the reliability of the codebase as it evolves.
