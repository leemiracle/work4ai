  The MuJoCo Viewers module provides visualization capabilities for MuJoCo physics simulations within the KSIM framework. These viewers allow users to visualize robot motions, observe physics interactions, and debug reinforcement learning tasks. For additional visualization tools beyond the MuJoCo viewers, see [Visualization Tools](https://deepwiki.com/kscalelabs/ksim/5.2-visualization-tools).

 
## Overview

 The KSIM framework implements two types of MuJoCo viewers:

 
 - `DefaultMujocoViewer` - An offscreen renderer that produces image frames without displaying a window
 - `GlfwMujocoViewer` - An interactive window-based viewer with real-time camera controls and perturbation capabilities
 
 These viewers provide a crucial interface between the simulation environment and human operators, enabling visual inspection and debugging of physics-based reinforcement learning tasks.

## Viewer Types and Capabilities

 
### DefaultMujocoViewer

 The `DefaultMujocoViewer` provides offscreen rendering capability using MuJoCo's OpenGL context. It is designed for:

 
 - Generating image frames without displaying them
 - Capturing simulation states for logging or post-processing
 - Creating videos of simulations
 - Headless environments without display capabilities
 
 Key features include:

 
 - Configurable rendering resolution
 - Camera selection and positioning
 - Scene visualization with customizable options
 - No support for interactive rendering (window-based visualization)
 
 
```

```

 Sources: [ksim/viewer.py22-132](https://github.com/kscalelabs/ksim/blob/9d26400d/ksim/viewer.py#L22-L132)

 
### GlfwMujocoViewer

 The `GlfwMujocoViewer` provides a full-featured interactive visualization environment using GLFW (OpenGL Framework). It supports:

 
 - Real-time visualization in a window
 - Interactive camera control with mouse and keyboard
 - Applying perturbations to the simulation
 - Both window-based and offscreen rendering modes
 
 Key interactive features include:

 
 - Camera rotation with left mouse button
 - Camera panning with right mouse button
 - Zoom with mouse wheel
 - Object selection and force application with Ctrl+click
 - Simulation termination with Escape key

 Both viewer classes share several key methods and properties:

 
| Method/Property | Description |
|---|---|
| model | MuJoCo physics model |
| data | MuJoCo simulation data |
| scn | MjvScene object for 3D visualization |
| cam | MjvCamera object for camera control |
| vopt | MjvOption object for visualization options |
| set_camera(id) | Set the active camera by ID or name |
| read_pixels() | Capture the current frame as a numpy array |
| render() | Render the current frame (implementation differs) |
| close() | Clean up resources and close the viewer |

### Motion Visualization

 The `AMPTask` class includes a `run_motion_viewer` method that provides an interface for viewing motions on a robot model:

 
```

```

 This method:

 
 - Creates a viewer based on configuration
 - Loads real motion data using `get_real_motions()`
 - Converts motion data to joint positions using `motion_to_qpos()`
 - Sequentially applies these positions to the robot model
 - Renders each frame, optionally saving to create a video

## Interactive Simulation Control

 The `GlfwMujocoViewer` supports applying perturbations to the simulation:

 
```

```

 This allows users to interactively manipulate the simulation by:

 
 - Holding Ctrl and clicking on a body to select it
 - Dragging with left mouse button to rotate the selected body
 - Dragging with right mouse button to translate the selected body
 
 These perturbations are applied to the MuJoCo simulation through external forces and torques.

## Conclusion

 The MuJoCo Viewers module provides essential visualization capabilities for the KSIM framework, enabling users to observe and interact with physics-based simulations. The `DefaultMujocoViewer` supports headless rendering for video generation, while the `GlfwMujocoViewer` provides a full-featured interactive experience for real-time visualization and manipulation of the simulation environment.
