  This document provides a detailed overview of the AMP-based Walking Tasks in the KSIM framework. Adversarial Motion Priors (AMP) is a technique that enables reinforcement learning agents to generate more realistic and natural motions by leveraging reference motion data. This page focuses specifically on how AMP is implemented and used for walking tasks in the KSIM framework, building upon the basic walking tasks covered in [Humanoid Walking Tasks](https://deepwiki.com/kscalelabs/ksim/4.1-humanoid-walking-tasks) and [RNN-based Walking Tasks](https://deepwiki.com/kscalelabs/ksim/4.2-rnn-based-walking-tasks).

 
## 1. Introduction to Adversarial Motion Priors

 Adversarial Motion Priors is a technique that improves the realism of agent motions by using a discriminator network to distinguish between real motion captures and policy-generated motions. The policy is then trained to both achieve the task goal (walking) and produce motions that are indistinguishable from real motion captures.

## 6. Implementation Example: HumanoidWalkingAMPTask

 The `HumanoidWalkingAMPTask` provides a complete example of an AMP-based walking task:

 
### 6.1 Configuration Parameters

 
| Parameter | Description | Default Value |
|---|---|---|
| num_mixtures | Number of Gaussian mixtures in policy | 5 |
| hidden_size | Hidden size for neural networks | 512 |
| depth | Network depth | 2 |
| discriminator_hidden_size | Discriminator hidden size | 512 |
| num_frames | Number of frames for discriminator | 10 |
| learning_rate | Policy learning rate | 1e-3 |
| discriminator_learning_rate | Discriminator learning rate | 1e-3 |
| reference_motion_path | Path to reference motion file | "humanoid_amp_walk_ref.npz" |
| bvh_path | Path to BVH motion capture file | "walk_normal_dh.bvh" |

 Sources: [examples/walking_amp.py268-383](https://github.com/kscalelabs/ksim/blob/9d26400d/examples/walking_amp.py#L268-L383)

 
### 6.2 Reward Structure

 The task uses a combination of rewards:

 
 - **AMPReward**: Rewards for generating realistic motions (scale: 1.0)
 - **StayAliveReward**: Reward for remaining upright and active (scale: 1.0)
 - **XYAngularVelocityPenalty**: Penalty for excessive angular velocity (scale: -0.01)
 - **NaiveForwardReward**: Reward for walking forward (scale: 1.0)
 
 Sources: [examples/walking_amp.py502-508](https://github.com/kscalelabs/ksim/blob/9d26400d/examples/walking_amp.py#L502-L508)

 
### 6.3 Termination Conditions

 The task terminates under the following conditions:

 
 - **BadZTermination**: Height outside allowed range (0.9 to 1.6)
 - **NotUprightTermination**: Tilt beyond 30 degrees
 - **HighVelocityTermination**: Excessive velocity
 - **FarFromOriginTermination**: Distance from origin > 10.0
 
 Sources: [examples/walking_amp.py510-516](https://github.com/kscalelabs/ksim/blob/9d26400d/examples/walking_amp.py#L510-L516)

 
## 7. Usage and Running an AMP Task

 To launch an AMP-based walking task, use the following command:

 
```
python -m examples.walking_amp
```

 For visualization:

 
```
python -m examples.walking_amp run_mode=view
```

 To view the reference motion:

 
```
python -m examples.walking_amp run_mode=view_motion
```
