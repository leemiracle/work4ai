## Purpose and Scope

 The Dataset Utilities in KSIM provide tools for storing, retrieving, and manipulating training data, with a particular focus on trajectory data for reinforcement learning and reference motion data for motion imitation tasks. These utilities allow users to efficiently save agent experiences and load reference motion data from external sources such as BVH motion capture files.

 This page covers the two primary dataset utility systems:

 
 - Trajectory Dataset - for storing and retrieving agent trajectory data
 - Reference Motion Data - for handling motion capture reference data
 
 For information about visualization tools that can be used with these datasets, see [Visualization Tools](https://deepwiki.com/kscalelabs/ksim/5.2-visualization-tools).

 
## Trajectory Dataset System

 The Trajectory Dataset system provides a mechanism to efficiently store and load large collections of agent trajectories. It uses memory-mapped files for efficient disk access and supports random sampling of trajectories for training.

### Data Storage Format

 The Trajectory Dataset system uses a flat memory-mapped file format with an accompanying metadata file:

 
 - **Main data file** (.npy): Contains flattened arrays of all trajectory components
 - **Metadata file** (.meta.json): Contains information about shapes, names, and structure
 
 This structure allows for efficient storage and rapid random access to large datasets.

#### `MotionReferenceData`

 A frozen dataclass that stores reference motion data:

 
 - Joint positions (`qpos`) and velocities (`qvel`)
 - Cartesian poses for specific body parts
 - Time-based or step-based data retrieval
 - Storage and loading from npz files

 The dataset utilities are primarily used in two contexts within the KSIM framework:

 
```

```

 
 - **Trajectory collection for policy learning**:

 
 - PPO tasks can store trajectories for offline learning
 - Trajectories can be analyzed or used for imitation learning
 - **Reference motion for AMP tasks**:

 
 - Reference motion data provides demonstration data for AMP
 - Used to train discriminators in adversarial training
