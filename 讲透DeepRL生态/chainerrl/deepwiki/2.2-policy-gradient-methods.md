## Purpose and Scope

 This document covers the policy gradient algorithms implemented in ChainerRL, which optimize policies directly through gradient ascent on expected rewards. Policy gradient methods learn a parameterized policy that maps observations to action probabilities, rather than learning value functions like in value-based methods.

 For value-based methods like DQN, see [DQN and Value-Based Methods](https://deepwiki.com/chainer/chainerrl/2.1-dqn-and-value-based-methods). For algorithms that combine policy gradients with value estimation, see [Actor-Critic Methods](https://deepwiki.com/chainer/chainerrl/2.3-actor-critic-methods).

 The policy gradient algorithms covered here include:

 
 - **PPO (Proximal Policy Optimization)** - clips policy updates to prevent large changes
 - **TRPO (Trust Region Policy Optimization)** - constrains policy updates using KL divergence
 - **REINFORCE** - basic policy gradient using Monte Carlo returns
 
 
## Algorithm Overview

 
| Algorithm | File | Key Features | Policy Update Method |
|---|---|---|---|
| PPO | chainerrl/agents/ppo.py | Clipped surrogate objective, GAE | Minibatch SGD with clipping |
| TRPO | chainerrl/agents/trpo.py | KL divergence constraint, natural gradients | Conjugate gradient + line search |
| REINFORCE | chainerrl/agents/reinforce.py | Monte Carlo returns, episodic | Direct policy gradient |

### Implementation Details

 TRPO requires separate policy and value function models and uses advanced optimization techniques:

 
 - **Separate Models**: [chainerrl/agents/trpo.py187-199](https://github.com/chainer/chainerrl/blob/7eed3756/chainerrl/agents/trpo.py#L187-L199) - Policy and value function are separate
 - **Fisher Information**: [chainerrl/agents/trpo.py529-531](https://github.com/chainer/chainerrl/blob/7eed3756/chainerrl/agents/trpo.py#L529-L531) - Hessian-vector product for natural gradients
 - **Line Search**: [chainerrl/agents/trpo.py555-650](https://github.com/chainer/chainerrl/blob/7eed3756/chainerrl/agents/trpo.py#L555-L650) - Backtracking to satisfy KL constraint
 - **Second-order Requirements**: [chainerrl/agents/trpo.py100-102](https://github.com/chainer/chainerrl/blob/7eed3756/chainerrl/agents/trpo.py#L100-L102) - Requires functions supporting double backprop
