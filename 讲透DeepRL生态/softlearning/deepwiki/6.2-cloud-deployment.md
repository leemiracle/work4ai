  This document covers deploying softlearning experiments to cloud platforms using Docker containers and Ray autoscaler. The framework supports automated cluster provisioning and experiment execution on both Google Cloud Platform (GCE) and Amazon Web Services (EC2).

 For local development setup using Docker, see [Docker Development Environment](https://deepwiki.com/rail-berkeley/softlearning/6.1-docker-development-environment). For distributed training concepts and Ray integration, see [Distributed Training with Ray](https://deepwiki.com/rail-berkeley/softlearning/5.3-distributed-training-with-ray).

 
## Overview

 The cloud deployment system enables running softlearning experiments on auto-scaling cloud clusters through three main components:

 
 - **Docker Containerization**: Pre-built containers with all dependencies for CPU and GPU workloads
 - **Ray Autoscaler**: Automated cluster provisioning and management
 - **CLI Integration**: Command-line tools for launching experiments with cloud-specific configurations

## Configuration Management

 Cloud deployments require customization of autoscaler configurations for specific projects and environments.

 
### Required Configuration Updates

 Both `ray-autoscaler-gce.yaml` and `ray-autoscaler-ec2.yaml` contain placeholder values that must be updated:

 
| Configuration Field | GCE Location | EC2 Location | Required Value |
|---|---|---|---|
| Project ID | provider.project_id | N/A | GCP project identifier |
| Source Image | head_node.disks[0].initializeParams.sourceImage | head_node.ImageId | Custom image with softlearning |
| File Mounts | file_mounts paths | file_mounts paths | Local project paths |

 
### Environment-Specific Customization

 The autoscaler configurations support environment-specific customization:

 
 - **Resource Scaling**: Adjust `min_workers`, `max_workers`, and `target_utilization_fraction`
 - **Instance Types**: Modify `machineType` (GCE) or `InstanceType` (EC2) based on workload requirements
 - **Storage Configuration**: Customize disk sizes and types for specific use cases
 - **Network Configuration**: Configure VPC, subnets, and security groups (auto-configured by default)
