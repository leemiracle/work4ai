  This document covers the deep reinforcement learning algorithms implemented in the softlearning framework. The algorithms module provides abstract base classes and concrete implementations for model-free RL algorithms, including Soft Actor-Critic (SAC) and Soft Q-learning (SQL). These algorithms integrate with the broader softlearning ecosystem through standardized interfaces for policies, value functions, and environment interaction.

 For information about policies that work with these algorithms, see [Policies](https://deepwiki.com/rail-berkeley/softlearning/4.2-policies). For environment integration, see [Environments](https://deepwiki.com/rail-berkeley/softlearning/4.3-environments). For replay pool management, see [Replay Pools](https://deepwiki.com/rail-berkeley/softlearning/4.5-replay-pools).

## SAC Algorithm

 Soft Actor-Critic (SAC) is an off-policy algorithm that learns a stochastic policy in an off-policy way. It combines policy gradient methods with Q-learning and includes automatic entropy temperature tuning.

 
### SAC Architecture

 
```

```

 
### SAC Update Mechanism

 The SAC algorithm performs three main updates per training step:

 
 - **Critic Update**: Updates Q-functions using temporal difference learning
 - **Actor Update**: Updates policy using the reparameterization trick
 - **Alpha Update**: Automatically tunes entropy coefficient


## SQL Algorithm

 Soft Q-learning (SQL) learns a stochastic policy by maintaining a soft Q-function and using Stein Variational Gradient Descent (SVGD) for policy updates.

 
### SQL Architecture

 
```

```

 
### SVGD Policy Update

 SQL uses SVGD to update the policy, which requires:

 
 - **Particle Generation**: Sample multiple action particles from the policy
 - **Kernel Computation**: Compute kernel values and gradients between particles
 - **Gradient Computation**: Calculate gradients of the Q-function w.r.t. actions
 - **SVGD Update**: Combine kernel and gradient information for policy update
 
 
### Key SQL Parameters

 
| Parameter | Default | Purpose |
|---|---|---|
| policy_lr | 3e-4 | Policy network learning rate |
| Q_lr | 3e-4 | Q-function learning rate |
| value_n_particles | 16 | Particles for value estimation |
| kernel_n_particles | 16 | Particles for SVGD |
| kernel_update_ratio | 0.5 | Ratio of particles to update |
| discount | 0.99 | Discount factor |
| tau | 5e-3 | Target network update rate |
