# Distributions

  Relevant source files 
 - [softlearning/distributions/__init__.py](https://github.com/rail-berkeley/softlearning/blob/13cf187c/softlearning/distributions/__init__.py)
 
  This document covers the probability distribution system in softlearning, which provides the mathematical foundation for stochastic policies and probabilistic components within the reinforcement learning framework. Distributions are primarily used by policies to sample actions and compute log probabilities for policy gradient algorithms.

 For information about how distributions integrate with policy implementations, see [Policies](https://deepwiki.com/rail-berkeley/softlearning/4.2-policies). For details on how algorithms use distribution properties for learning updates, see [Algorithms](https://deepwiki.com/rail-berkeley/softlearning/4.1-algorithms).

 
## Purpose and Scope

 The distributions module provides probability distribution implementations that serve as building blocks for the stochastic components of the RL system. These distributions enable:

 
 - **Action Sampling**: Policies use distributions to sample actions from learned probability distributions
 - **Log Probability Computation**: Algorithms require log probabilities for policy gradient calculations and entropy regularization
 - **Reparameterization**: Support for differentiable sampling through reparameterization tricks
 - **Statistical Properties**: Access to distribution moments, entropy, and other statistical measures needed by RL algorithms

## Distribution Types and Usage

 The framework primarily utilizes distributions for continuous control tasks, with Gaussian distributions being the most common choice for policy action sampling.

 
### Gaussian Distributions

 Gaussian (normal) distributions are the primary distribution type used in softlearning's policy implementations, particularly for continuous action spaces.


 **Gaussian Distribution Usage Pattern**

 
| Property | Usage | Algorithm Context |
|---|---|---|
| sample() | Action sampling during rollouts | Data collection |
| rsample() | Differentiable sampling | Policy gradient computation |
| log_prob() | Policy evaluation | SAC, SQL policy updates |
| entropy() | Regularization term | Maximum entropy RL |
| mean | Deterministic actions | Evaluation mode |

## Implementation Patterns

 
### Reparameterization Trick

 The distributions support the reparameterization trick, which is essential for policy gradient algorithms to maintain differentiability through stochastic sampling.

 
| Method | Purpose | Gradient Flow |
|---|---|---|
| sample() | Non-differentiable sampling | Blocked |
| rsample() | Reparameterized sampling | Preserved |
| log_prob() | Probability density | Direct |

 Distributions provide entropy calculations that are used for maximum entropy reinforcement learning approaches like SAC.

 The distributions module integrates with several other core components of the softlearning framework:
