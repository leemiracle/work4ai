## Purpose and Scope

 The policy system in softlearning provides the core decision-making components for reinforcement learning agents. Policies map observations to actions and compute action probabilities, serving as the learnable component that algorithms optimize during training. This document covers the policy architecture, main implementations, and how policies integrate with other framework components.

 For information about how policies are used within RL algorithms, see [Algorithms](https://deepwiki.com/rail-berkeley/softlearning/4.1-algorithms). For details on policy evaluation and simulation, see [Policy Simulation and Evaluation](https://deepwiki.com/rail-berkeley/softlearning/5.2-policy-simulation-and-evaluation).

## Core Policy Classes

 
### GaussianPolicy

 The `GaussianPolicy` class is the foundation for parametric policies that output actions from Gaussian distributions. It uses a neural network to predict the mean (shift) and standard deviation (scale) of a multivariate Gaussian distribution over actions.

 
#### Key Components

 
| Component | Description | Implementation |
|---|---|---|
| shift_and_scale_model | Neural network outputting distribution parameters | softlearning/policies/gaussian_policy.py24-26 |
| base_distribution | Underlying multivariate normal distribution | softlearning/policies/gaussian_policy.py28-30 |
| raw_action_distribution | Distribution with conditional shift/scale bijectors | softlearning/policies/gaussian_policy.py32-35 |
| action_distribution | Final distribution after post-processing | softlearning/policies/gaussian_policy.py39-40 |

 
#### Core Methods

 **Action Generation**

 
 - `actions(observations)`: Samples actions from the policy distribution [softlearning/policies/gaussian_policy.py42-61](https://github.com/rail-berkeley/softlearning/blob/13cf187c/softlearning/policies/gaussian_policy.py#L42-L61)
 - `actions_and_log_probs(observations)`: Jointly computes actions and their log probabilities to avoid numerical issues [softlearning/policies/gaussian_policy.py100-135](https://github.com/rail-berkeley/softlearning/blob/13cf187c/softlearning/policies/gaussian_policy.py#L100-L135)
 
 **Probability Computation**

 
 - `log_probs(observations, actions)`: Computes log probabilities of given actions [softlearning/policies/gaussian_policy.py63-80](https://github.com/rail-berkeley/softlearning/blob/13cf187c/softlearning/policies/gaussian_policy.py#L63-L80)
 - `probs(observations, actions)`: Computes probabilities of given actions [softlearning/policies/gaussian_policy.py82-98](https://github.com/rail-berkeley/softlearning/blob/13cf187c/softlearning/policies/gaussian_policy.py#L82-L98)

### FeedforwardGaussianPolicy

 `FeedforwardGaussianPolicy` extends `GaussianPolicy` with a specific neural network architecture using fully connected layers.

 
#### Configuration Parameters

 
| Parameter | Purpose | Default |
|---|---|---|
| hidden_layer_sizes | List of hidden layer dimensions | Required |
| activation | Activation function for hidden layers | 'relu' |
| output_activation | Activation function for output layer | 'linear' |

 
#### Network Architecture

 The `_shift_and_scale_diag_net` method creates a feedforward network that:

## Integration with Framework Components

 
### Algorithm Integration

 Policies integrate with RL algorithms through standardized interfaces:

 
 - Algorithms call `actions_and_log_probs()` for actor-critic updates
 - Policy gradients are computed through the action distribution's log probabilities
 - Target policies may be created as copies with fixed weights
 
 
### Sampler Integration

 Samplers use policies for environment interaction:

 
 - Call `actions(observations)` to get actions for environment steps
 - May switch between training and evaluation modes using the context manager
 - Support both local and remote policy execution
 
 
### Environment Compatibility

 Policies work with different observation and action spaces through:

 
 - Flexible input preprocessing for various observation formats
 - Action post-processing for environment-specific action bounds
 - Support for multi-dimensional and structured action spaces
