  The sampling and data collection system manages the core interaction loop between reinforcement learning agents and their environments. This system collects experience data that is used to train RL algorithms by executing policies in environments and storing the resulting transitions in replay pools.

 This document covers the sampler implementations, data collection workflow, and integration with other system components. For information about the environments being sampled from, see [Environments](https://deepwiki.com/rail-berkeley/softlearning/4.3-environments). For details about the replay pools where collected data is stored, see [Replay Pools](https://deepwiki.com/rail-berkeley/softlearning/4.5-replay-pools).

## Utility Functions

 
### Rollout Function

 The `rollout()` function provides a standalone interface for executing complete episodes:

 
#### Function Signature

 
 - `environment`: Environment to interact with
 - `policy`: Policy to execute
 - `path_length`: Maximum episode length
 - `replay_pool_class`: Class for temporary storage (default: `SimpleReplayPool`)
 - `sampler_class`: Sampler class to use (default: `SimpleSampler`)
 - `render_kwargs`: Optional rendering parameters
 - `break_on_terminal`: Whether to stop on episode termination
 
 
#### Rendering Support

 
| Render Mode | Default Parameters |
|---|---|
| 'rgb_array' | width=100, height=100, mode='rgb_array' |
| 'human' | width=500, height=500, mode='human' |
| None | No rendering |

### Initialization and Lifecycle

 Samplers follow a standard lifecycle managed by the experiment framework:

 
 - **Construction**: Sampler created with `max_path_length` parameter
 - **Initialization**: `initialize(environment, policy, pool)` called to set dependencies
 - **Sampling**: Repeated calls to `sample()` collect data
 - **Diagnostics**: `get_diagnostics()` provides statistics
 - **Termination**: `terminate()` cleans up resources

### Statistical Tracking

 Samplers maintain comprehensive statistics about the data collection process:

 
| Statistic | Description | Update Trigger |
|---|---|---|
| _path_length | Current episode length | Each step |
| _path_return | Current episode return | Each step |
| _last_path_return | Previous episode return | Episode end |
| _max_path_return | Maximum observed return | Episode end |
| _n_episodes | Total episodes collected | Episode end |
| _total_samples | Total transitions collected | Each step |
