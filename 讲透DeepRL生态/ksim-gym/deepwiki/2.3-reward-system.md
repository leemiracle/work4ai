# Reward System

  The Reward System in K-Sim Gym provides the reinforcement learning signal that shapes the humanoid robot's behavior during training. It consists of carefully balanced positive rewards and negative penalties that guide the policy towards learning stable, energy-efficient walking gaits. This page explains the components of the reward function, how they interact, and their implementation details.

 For information about the Actor-Critic model that uses these rewards, see [Actor-Critic Architecture](https://deepwiki.com/kscalelabs/ksim-gym/2.2-actor-critic-architecture). For details on the curriculum learning approach that affects reward scaling, see [Curriculum Learning](https://deepwiki.com/kscalelabs/ksim-gym/2.5-curriculum-learning).

 The reward function in K-Sim Gym is structured as a weighted sum of multiple reward components, each targeting a specific aspect of the desired behavior.

### Standard Rewards

 These rewards encourage essential behaviors for successful walking:

 
 - **Forward Progress** (`NaiveForwardReward`): Rewards the robot for moving forward along the x-axis. This is the primary goal of training and carries the highest weight (3.0).
 - **Forward Orientation** (`NaiveForwardOrientationReward`): Rewards the robot for maintaining its body oriented in the forward direction.
 - **Stay Alive** (`StayAliveReward`): Provides a constant positive reward for each timestep the robot remains in a non-terminal state.
 - **Upright Orientation** (`UprightReward`): Rewards the robot for maintaining an upright posture, preventing falling.
 
 Sources: [train.py458-461](https://github.com/kscalelabs/ksim-gym/blob/3e92db5c/train.py#L458-L461)

 
### Movement Penalties

 These penalties discourage undesired movements that could lead to instability:

 
 - **Angular Velocity Penalty** (`AngularVelocityPenalty`): Penalizes excessive angular velocity around the x and y axes, discouraging rapid rotations.
 - **Linear Velocity Penalty** (`LinearVelocityPenalty`): Penalizes excessive vertical movement (z-axis), encouraging the robot to maintain a consistent height.
 
 Sources: [train.py463-464](https://github.com/kscalelabs/ksim-gym/blob/3e92db5c/train.py#L463-L464)

 
### Normalization Penalties

 These penalties promote smooth, stable, and energy-efficient movements:

 
 - **Avoid Limits Penalty** (`AvoidLimitsPenalty`): Discourages the robot from operating near joint limits.
 - **Joint Acceleration Penalty** (`JointAccelerationPenalty`): Penalizes high joint accelerations.
 - **Joint Jerk Penalty** (`JointJerkPenalty`): Penalizes rapid changes in joint acceleration.
 - **Link Acceleration Penalty** (`LinkAccelerationPenalty`): Penalizes high link accelerations.
 - **Link Jerk Penalty** (`LinkJerkPenalty`): Penalizes rapid changes in link acceleration.
 - **Action Acceleration Penalty** (`ActionAccelerationPenalty`): Penalizes rapid changes in actions.
 
 Sources: [train.py466-472](https://github.com/kscalelabs/ksim-gym/blob/3e92db5c/train.py#L466-L472)

 
### Custom Posture Penalties

 These penalties discourage specific undesired postures:

 
 - **Bent Arm Penalty** (`BentArmPenalty`): Penalizes deviations from a specified arm posture, encouraging the robot to maintain a bent arm position.
 - **Straight Leg Penalty** (`StraightLegPenalty`): Penalizes excessive hip roll and yaw, encouraging the robot to keep its legs relatively straight.
 
 Sources: [train.py473-474](https://github.com/kscalelabs/ksim-gym/blob/3e92db5c/train.py#L473-L474)

### Target Joint Positions

 The penalties use reference values defined in the `ZEROS` constant:

 
```
ZEROS: list[tuple[str, float]] = [
    ("dof_right_shoulder_pitch_03", 0.0),
    ("dof_right_shoulder_roll_03", math.radians(-10.0)),
    ...
    ("dof_left_ankle_02", math.radians(-30.0)),

```

 These values define the "zero" or default position for each joint that the custom penalties try to maintain.

## Curriculum-Based Scaling

 Several penalties include the parameter `scale_by_curriculum=True`, which means their effect is modulated by the curriculum level. As the robot improves its performance and advances through curriculum levels, these penalties become more influential.

 The affected penalties include:

 
 - Joint Acceleration Penalty
 - Joint Jerk Penalty
 - Link Acceleration Penalty
 - Link Jerk Penalty
 - Action Acceleration Penalty
 
 This approach allows the robot to focus on basic locomotion at early stages and gradually refine its movement quality as training progresses.

## Relationship with Termination Conditions

 The reward system works in conjunction with termination conditions to shape learning. There are two primary termination conditions:

 
 - **Bad Z Termination** (`BadZTermination`): Terminates the episode when the robot's height is outside the acceptable range of 0.6 to 1.2 meters.
 - **Far From Origin Termination** (`FarFromOriginTermination`): Terminates the episode when the robot is more than 10 meters from the origin.
 
 The `StayAliveReward` component provides a positive reward for avoiding these termination conditions, creating an incentive to maintain stability.

## Typical Reward Values and Performance Metrics

 During training, the agent learns to maximize the combined reward. Typical reward values observed in successful training sessions show:

 
| Reward Component | Typical Value Range | Relative Contribution |
|---|---|---|
| Forward Progress | 0.0 to 3.75 | High |
| Forward Orientation | 0.0 to 1.0 | Medium |
| Stay Alive | 1.0 | Medium |
| Upright Orientation | 0.0 to 0.5 | Medium |
| Movement Penalties | -0.5 to 0.0 | Low-Medium |
| Normalization Penalties | -0.2 to 0.0 | Low |
| Posture Penalties | -0.5 to 0.0 | Low-Medium |
| Total Reward | 0.0 to 5.0 | - |

 A robot that can walk successfully in a straight line with a stable gait typically achieves a consistent reward above 3.0.
