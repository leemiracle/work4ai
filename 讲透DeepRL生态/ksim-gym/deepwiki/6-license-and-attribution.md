## Submitting to the Leaderboard

 When submitting models to the K-Scale Labs leaderboard, you maintain ownership of your models and implementations, but grant K-Scale Labs permission to run, evaluate, and showcase your models.

 The submission process described in the README requires:

 
 - Training your model
 - Converting it to a K-Infer model
 - Committing the model and video to your repository
 - Making your repository public
 - Submitting a link to your repository through Discord

## Third-Party Dependencies

 K-Sim Gym relies on several third-party libraries, such as JAX, MuJoCo, and TensorBoard, each with their own licenses. When using K-Sim Gym, you are also bound by the license terms of these dependencies.

 Key dependencies include:

 
| Dependency | Purpose | License Type |
|---|---|---|
| JAX | Machine learning framework | Apache 2.0 |
| MuJoCo | Physics simulator | Apache 2.0 |
| TensorBoard | Visualization tool | Apache 2.0 |

 While the K-Sim Gym code itself is MIT licensed, be aware that when you use the full system, you must comply with all the licenses of the included dependencies.
