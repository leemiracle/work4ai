  The Observation System is a critical component of K-Sim Gym that provides sensory information from the simulated environment to the reinforcement learning agent. It collects data about the robot's state, including joint positions, velocities, IMU readings, and other proprioceptive feedback, enabling the agent to perceive its environment and make informed decisions.

 K-Sim Gym's `HumanoidWalkingTask` implements the following observation components:

 
| Observation Component | Description | Configuration |
|---|---|---|
| TimestepObservation | Current simulation timestep | - |
| JointPositionObservation | Current joint positions | 2° noise |
| JointVelocityObservation | Current joint velocities | 10° noise |
| ActuatorForceObservation | Forces applied by actuators | - |
| CenterOfMassInertiaObservation | Robot's center of mass inertia | - |
| CenterOfMassVelocityObservation | Velocity of center of mass | - |
| BasePositionObservation | Position of the base link | - |
| BaseOrientationObservation | Orientation of the base link | - |
| BaseLinearVelocityObservation | Linear velocity of the base link | - |
| BaseAngularVelocityObservation | Angular velocity of the base link | - |
| BaseLinearAccelerationObservation | Linear acceleration of the base | - |
| BaseAngularAccelerationObservation | Angular acceleration of the base | - |
| ActuatorAccelerationObservation | Actuator acceleration | - |
| ProjectedGravityObservation | Gravity vector in robot's frame | 1° noise, 0-0.1s lag |
| SensorObservation(imu_acc) | IMU accelerometer readings | 1.0 noise |
| SensorObservation(imu_gyro) | IMU gyroscope readings | 10° noise |

## Summary

 The Observation System in K-Sim Gym provides the sensory foundation for reinforcement learning with a humanoid robot. It collects data from various "sensors" in the simulation environment, preprocesses this data, and feeds it to the actor and critic networks. The actor uses a focused subset of observations for action selection, while the critic uses a comprehensive set for value estimation.

 The system's design mirrors real-world robotic sensors, including joint encoders, IMU sensors, and proprioceptive feedback, helping to ensure that learned policies can transfer effectively to real robots. By configuring the observation system appropriately, users can experiment with different sensory inputs and find the optimal configuration for their specific task.

 For information about how these observations influence the agent's learning through rewards, see the [Reward System](https://deepwiki.com/kscalelabs/ksim-gym/2.3-reward-system) page.
