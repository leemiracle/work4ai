## Converting Checkpoints to K-Infer Models

 The conversion process extracts the policy from a trained checkpoint, converts it to ONNX format, and packages it as a K-Infer model that can be deployed on robots.

 
### How the Conversion Works

 The conversion process involves these key steps:

 
 - Loading the trained policy from a checkpoint
 - Extracting the model's initial state function (`init_fn`)
 - Extracting the model's step function (`step_fn`)
 - Converting both functions to ONNX format
 - Packaging them with joint information into a K-Infer model

## Common Use Cases and Examples

 Here are some common use cases for model conversion and deployment:

 
| Use Case | Command | Description |
|---|---|---|
| Basic Conversion | python -m convert humanoid_walking_task/run_1/checkpoints/ckpt.bin models/model.kinfer | Convert your latest checkpoint to a K-Infer model |
| Simulation Testing | kinfer-sim models/model.kinfer kbot --start-height 1.2 | Test your model in the simulator |
| Record Demo Video | kinfer-sim models/model.kinfer kbot --save-video demo.mp4 | Create a video of your model's performance |
| Alternative Visualization | python -m train run_mode=view load_from_ckpt_path=humanoid_walking_task/run_1/checkpoints/ckpt.bin | Visualize your model using the training environment viewer |

## Troubleshooting

 Here are some common issues that may arise during the conversion and deployment process:

 
| Issue | Possible Solution |
|---|---|
| FileNotFoundError | Ensure the checkpoint path is correct and the file exists |
| Model performs poorly in the simulator | Try a different checkpoint from your training run |
| Simulator crashes | Ensure your K-Infer installation is up to date |
| Unstable robot behavior | Consider additional training with adjustments to your reward function |

 If you encounter issues not covered here, consult the [K-Sim documentation](https://docs.kscale.dev/docs/ksim#/) or reach out to the community on Discord.

## Summary

 Converting and deploying models in K-Sim Gym involves:

 
 - Training a policy to learn locomotion behavior
 - Converting the trained checkpoint to a K-Infer model
 - Testing the model in the K-Infer simulator
 - Optionally deploying to a real robot via the leaderboard submission process
 
 This workflow enables efficient development and testing of robot control policies in simulation before real-world deployment.
