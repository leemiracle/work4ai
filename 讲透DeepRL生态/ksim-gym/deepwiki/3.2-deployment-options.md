| Feature | Description |
|---|---|

| Repeatability | Run identical tests multiple times for comparison |
| Accessibility | No physical hardware required |
| Video Generation | Create videos for documentation or submission |
| Debugging | Observe full system state not available in hardware |

### Leaderboard Submission Process

 K-Sim Gym offers a unique feature: submitting your models to be tested on real robot hardware by the K-Scale team.

 Submission workflow:

 
 - Convert your checkpoint to K-Infer format
 - Test the model in the K-Infer simulator
 - Record a demonstration video
 - Commit both model and video to your repository
 - Submit your repository link on the K-Scale Discord
 - The K-Scale team will test your model on real hardware
 
 For detailed submission instructions, see [Submitting to the Leaderboard](https://deepwiki.com/kscalelabs/ksim-gym/4.4-submitting-to-the-leaderboard).

## Simulation vs. Real-World Deployment

 Understanding the differences between simulation and reality helps prepare for successful deployment:

 
| Aspect | K-Infer Simulator | Real Robot |
|---|---|---|
| Physics | Idealized MuJoCo physics | Real-world dynamics with friction and compliance |
| Sensors | Perfect sensor readings | Noise, delays, calibration issues |
| Actuators | Immediate, consistent response | Motor limitations, backlash, temperature effects |
| Robustness | Limited unexpected scenarios | Many unpredictable environmental factors |
| Debugging | Full state observation | Limited telemetry |
| Failure cost | Restart simulation | Potential hardware damage |
| Iteration speed | Fast | Slower (setup time, safety considerations) |

 
### Deployment Recommendations

 
 - **Start with simulation**: Thoroughly test in the K-Infer simulator first
 - **Evaluate robustness**: Test with different starting conditions and perturbations
 - **Record baseline performance**: Create videos of expected behavior for comparison
 - **Monitor execution**: When deploying to hardware, closely monitor all telemetry
 - **Iterate**: Use real-world observations to refine your policy if needed

## Troubleshooting

 Common deployment issues:

 
 - **Conversion errors**: Ensure checkpoint format is compatible
 - **Simulator crashes**: Verify kinfer-sim installation and compatibility
 - **Poor real-world performance**: Consider retraining with more robust rewards or curriculum
 
 For additional assistance, consult the [K-Sim documentation](https://docs.kscale.dev/docs/ksim#/) or reach out on Discord.
