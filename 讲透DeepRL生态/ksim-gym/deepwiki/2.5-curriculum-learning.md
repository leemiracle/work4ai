## Purpose and Scope

 This page documents the curriculum learning system in K-Sim Gym, which dynamically adjusts training difficulty based on agent performance. Curriculum learning is a technique that structures reinforcement learning training to progressively increase task complexity as the agent improves, similar to how human education progresses from simple to complex concepts. For information about the rewards that work with curriculum learning, see [Reward System](https://deepwiki.com/kscalelabs/ksim-gym/2.3-reward-system).

 Sources: [train.py73-85](https://github.com/kscalelabs/ksim-gym/blob/3e92db5c/train.py#L73-L85)

 
## Curriculum Learning Overview

 Curriculum learning in K-Sim Gym performs the following functions:

 
 - **Progressive Difficulty**: Adapts training difficulty based on agent performance
 - **Performance Monitoring**: Tracks metrics to determine when to adjust difficulty
 - **Reward Scaling**: Modifies penalty magnitudes based on current curriculum level
 - **Training Stabilization**: Prevents premature exposure to challenging scenarios

## Implementation in K-Sim Gym

 The curriculum learning system is implemented through the `DistanceFromOriginCurriculum` class from the ksim framework. This curriculum tracks how far the agent can travel from its starting position as a measure of performance.

 
### Curriculum Configuration

 The HumanoidWalkingTaskConfig class defines several parameters for configuring the curriculum:

 
| Parameter | Default | Description |
|---|---|---|
| num_curriculum_levels | 100 | Total number of difficulty levels |
| increase_threshold | 5.0 | Performance threshold to increase difficulty |
| decrease_threshold | 1.0 | Performance threshold to decrease difficulty |
| min_level_steps | 1 | Minimum steps before changing curriculum level |

## Reward Scaling with Curriculum

 Several penalties in the reward system are scaled based on the current curriculum level using the `scale_by_curriculum=True` parameter:

 
| Penalty | Scaling | Purpose |
|---|---|---|
| JointAccelerationPenalty | scale_by_curriculum=True | Penalizes rapid joint movements |
| JointJerkPenalty | scale_by_curriculum=True | Penalizes abrupt changes in joint acceleration |
| LinkAccelerationPenalty | scale_by_curriculum=True | Penalizes rapid link movements |
| LinkJerkPenalty | scale_by_curriculum=True | Penalizes abrupt changes in link acceleration |
| ActionAccelerationPenalty | scale_by_curriculum=True | Penalizes rapid changes in actions |

 This scaling typically reduces penalties at lower curriculum levels, allowing the agent more freedom to explore. As the curriculum level increases, penalties become more stringent, encouraging more refined movements.

## Practical Considerations

 When working with the curriculum learning system, consider the following:

 
 - **Thresholds**: The `increase_threshold` and `decrease_threshold` values determine how quickly the curriculum adapts. Wider gaps between thresholds create more stable levels.
 - **Level Count**: The `num_curriculum_levels` parameter (default 100) determines the granularity of difficulty progression. More levels allow for more gradual progression.
 - **Min Steps**: The `min_level_steps` parameter prevents rapid oscillation between levels due to momentary performance fluctuations.
 - **Reward Balance**: Curriculum-scaled penalties (`scale_by_curriculum=True`) should be balanced with non-scaled rewards to ensure effective learning at all difficulty levels.
