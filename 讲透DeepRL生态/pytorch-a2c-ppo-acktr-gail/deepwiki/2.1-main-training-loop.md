## Training Loop Parameters

 The main training loop is configured through several key parameters:

 
| Parameter | Description |
|---|---|
| num_env_steps | Total number of environment steps to train for |
| num_processes | Number of parallel environments |
| num_steps | Number of steps to collect per update |
| gamma | Discount factor for returns |
| use_gae | Whether to use Generalized Advantage Estimation |
| gae_lambda | Lambda parameter for GAE |
| log_interval | How often to log training progress |
| save_interval | How often to save the model |
| eval_interval | How often to evaluate the policy |

## Key Implementation Details

 
 - **Vectorized Environments**: The training loop uses vectorized environments to collect experience in parallel, improving training efficiency.
 - **Recurrent Policies**: The code supports recurrent policies by tracking and passing recurrent hidden states.
 - **Masks and Bad Masks**: Masks track episode termination for proper value bootstrapping, while bad masks identify invalid transitions to exclude from learning.
 - **Learning Rate Decay**: A linear learning rate decay schedule can be applied to improve training stability.
 - **Evaluation**: A separate evaluation process can be used to monitor policy performance during training.
