## Purpose and Scope

 This document explains how action distributions are represented, initialized, and utilized within the PyTorch A2C/PPO/ACKTR/GAIL framework. Action distributions are a critical component of any policy-based reinforcement learning system as they define how the agent selects actions in an environment - whether deterministically or stochastically. For information about the neural network architectures that feed into these distributions, see [Network Architectures](https://deepwiki.com/ikostrikov/pytorch-a2c-ppo-acktr-gail/4.1-network-architectures).

 
## Overview of Action Distributions

 In reinforcement learning, policy networks typically output parameters of probability distributions rather than direct actions. This approach enables:

 
 - Exploration through stochastic action selection
 - Calculation of action probabilities for policy gradients
 - Entropy calculation for encouraging exploration
 - Deterministic action selection during evaluation
 
 The codebase provides a standardized interface for different types of probability distributions tailored to various action spaces.

## Fixed Distribution Classes

 These classes extend PyTorch's standard distributions to provide a consistent interface across all distribution types. This standardization simplifies the implementation of the reinforcement learning algorithms.

 
### FixedCategorical

 Used for discrete action spaces (e.g., Atari games), this class extends `torch.distributions.Categorical`:

 
 - `sample()`: Returns sampled actions with an added dimension
 - `log_probs(actions)`: Calculates log probabilities, handling dimension reshaping
 - `mode()`: Returns the most likely action (argmax of probabilities)
 
 Sources: [a2c_ppo_acktr/distributions.py18-32](https://github.com/ikostrikov/pytorch-a2c-ppo-acktr-gail/blob/41332b78/a2c_ppo_acktr/distributions.py#L18-L32)

 
### FixedNormal

 Used for continuous action spaces (e.g., MuJoCo environments), this class extends `torch.distributions.Normal`:

 
 - `log_probs(actions)`: Sums log probabilities across action dimensions
 - `entropy()`: Sums entropy across action dimensions
 - `mode()`: Returns the mean as the most likely action
 
 Sources: [a2c_ppo_acktr/distributions.py36-44](https://github.com/ikostrikov/pytorch-a2c-ppo-acktr-gail/blob/41332b78/a2c_ppo_acktr/distributions.py#L36-L44)

 
### FixedBernoulli

 Used for binary action spaces, this class extends `torch.distributions.Bernoulli`:

 
 - `log_probs(actions)`: Calculates log probabilities, handling dimension reshaping
 - `entropy()`: Sums entropy across action dimensions
 - `mode()`: Returns 1 if probability > 0.5, else 0

## Distribution Network Modules

 These neural network modules transform policy network outputs into parameters for different probability distributions:

 
### Categorical Distribution Module

 For discrete action spaces, this module:

 
 - Takes `num_inputs` features and outputs logits for `num_outputs` actions
 - Uses orthogonal initialization with a small gain (0.01)
 - Produces a `FixedCategorical` distribution from the logits

### DiagGaussian Distribution Module

 For continuous action spaces, this module:

 
 - Outputs both the mean and log standard deviation for a multivariate normal distribution
 - Uses orthogonal initialization for the mean network
 - Initializes log standard deviation to zero
 - Produces a `FixedNormal` distribution with diagonal covariance

## Key Features of Distributions

 All distribution types provide a standardized interface with these key methods:

 
 - **Sampling**: Generate actions randomly according to the distribution
 - **Log Probabilities**: Calculate log probabilities of actions for policy gradient calculations
 - **Entropy**: Calculate entropy for exploration regularization
 - **Mode**: Deterministic action selection (used during evaluation)
 
 This standardization enables the reinforcement learning algorithms to work with any action space without modifying their core logic.
