## Overview

 A2C and ACKTR share the same fundamental actor-critic structure but differ in their optimization methods. Both are implemented in a single class in this codebase. A2C uses RMSProp as its optimizer, while ACKTR leverages the more advanced Kronecker-Factored Approximate Curvature (K-FAC) optimizer to approximate natural gradient updates.

## Update Method

 The core algorithm logic is in the `update()` method, which:

 
 - Takes collected experiences from rollouts
 - Evaluates actions to get values, log probabilities, and entropy
 - Computes advantages (returns - values)
 - Calculates value loss and action (policy) loss
 - For ACKTR, computes Fisher information matrix approximation
 - Performs gradient descent using the chosen optimizer

## Standard A2C Update Flow

 In standard A2C mode (`acktr=False`):

 
 - Compute values and action log probabilities from policy network
 - Calculate advantages as difference between returns and values
 - Compute value loss as mean squared error
 - Compute action loss as negative product of advantages and log probabilities
 - Add entropy bonus to encourage exploration
 - Backpropagate combined loss
 - Apply gradient clipping
 - Update network with RMSProp

## ACKTR-Specific Components

 When using ACKTR mode (`acktr=True`), the algorithm adds steps to approximate the Fisher information matrix:

 
 - Before the main backward pass, compute Fisher loss: 
 - Policy gradient Fisher loss (`pg_fisher_loss`) from action log probabilities
 - Value function Fisher loss (`vf_fisher_loss`) using sampled noise
 - Perform a backward pass with `acc_stats=True` to accumulate Fisher information
 - Skip gradient clipping as KFAC handles optimization differently
 
 The Fisher information accumulation happens every `Ts` steps (controlled by the KFAC optimizer).

## Loss Calculation

 Both algorithms use the same core loss functions:

 
 - **Value Loss**: Mean squared error between state values and returns

 
```
value_loss = advantages.pow(2).mean()
```
 - **Action Loss**: Negative product of advantages and log probabilities

 
```
action_loss = -(advantages.detach() * action_log_probs).mean()
```
 - **Combined Loss**: Weighted sum of value loss and action loss with entropy bonus

 
```
combined_loss = value_loss_coef * value_loss + action_loss - entropy_coef * dist_entropy
```

## Comparison with PPO

 Unlike PPO (see PPO), which uses clipped surrogate objectives and multiple epochs of minibatch updates, A2C and ACKTR:

 
 - Perform a single pass through the collected data
 - Don't use trust region clipping of probabilities
 - Optimize directly with the calculated advantages
 
 ACKTR achieves trust region optimization through the KFAC optimizer rather than probability clipping.
