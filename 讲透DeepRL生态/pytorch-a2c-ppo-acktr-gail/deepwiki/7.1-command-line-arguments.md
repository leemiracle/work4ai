# Command Line Arguments

  Relevant source files 
 - [a2c_ppo_acktr/arguments.py](https://github.com/ikostrikov/pytorch-a2c-ppo-acktr-gail/blob/41332b78/a2c_ppo_acktr/arguments.py)
 
  This document details all command line arguments available in the PyTorch A2C/PPO/ACKTR/GAIL implementation. These arguments configure the training process, algorithm selection, and experiment parameters. For information about running parallel experiments, see [Parallel Execution](https://deepwiki.com/ikostrikov/pytorch-a2c-ppo-acktr-gail/7.2-parallel-execution).

 
## Overview

 The command line arguments are processed in the `get_args()` function, which sets up default values and performs validation. Arguments control everything from algorithm selection to training hyperparameters and hardware utilization.

## Algorithm Selection and Configuration

 These arguments control which reinforcement learning algorithm is used and its basic configuration.

 
| Argument | Type | Default | Description |
|---|---|---|---|
| --algo | string | 'a2c' | Algorithm to use: a2c, ppo, or acktr |
| --recurrent-policy | flag | False | Use a recurrent policy (not available for ACKTR) |

## GAIL Parameters

 These arguments enable and configure Generative Adversarial Imitation Learning.

 
| Argument | Type | Default | Description |
|---|---|---|---|
| --gail | flag | False | Enable imitation learning with GAIL |
| --gail-experts-dir | string | './gail_experts' | Directory with expert demonstrations |
| --gail-batch-size | int | 128 | GAIL batch size |
| --gail-epoch | int | 5 | Number of GAIL epochs |

## Optimization Parameters

 These arguments control the optimization process across all algorithms.

 
| Argument | Type | Default | Description |
|---|---|---|---|
| --lr | float | 7e-4 | Learning rate |
| --eps | float | 1e-5 | RMSprop optimizer epsilon |
| --alpha | float | 0.99 | RMSprop optimizer alpha |
| --gamma | float | 0.99 | Discount factor for rewards |
| --use-gae | flag | False | Use Generalized Advantage Estimation |
| --gae-lambda | float | 0.95 | GAE lambda parameter |
| --entropy-coef | float | 0.01 | Entropy term coefficient |
| --value-loss-coef | float | 0.5 | Value loss coefficient |
| --max-grad-norm | float | 0.5 | Maximum norm of gradients |
| --use-linear-lr-decay | flag | False | Use linear learning rate decay |

## PPO-specific Parameters

 These arguments only affect the PPO algorithm.

 
| Argument | Type | Default | Description |
|---|---|---|---|
| --ppo-epoch | int | 4 | Number of PPO epochs |
| --num-mini-batch | int | 32 | Number of batches for PPO |
| --clip-param | float | 0.2 | PPO clip parameter |

## Training Control Parameters

 These arguments control the overall training process.

 
| Argument | Type | Default | Description |
|---|---|---|---|
| --num-processes | int | 16 | Number of parallel training processes |
| --num-steps | int | 5 | Number of forward steps in A2C |
| --num-env-steps | int | 10e6 | Total number of environment steps to train |
| --log-interval | int | 10 | Log interval (in updates) |
| --save-interval | int | 100 | Save interval (in updates) |
| --eval-interval | int | None | Evaluation interval (in updates) |
| --seed | int | 1 | Random seed |
