## Overview

 After training an agent with one of the reinforcement learning algorithms, you'll typically want to:

 
 - Visualize how the agent performs in its environment
 - Systematically evaluate the agent's performance
 
 The codebase provides two main tools for these purposes:

 
 - `enjoy.py` - For visualizing trained agent behavior in the environment
 - `evaluation.py` - For systematically evaluating agent performance
 
 
## Agent Visualization with enjoy.py

 The `enjoy.py` script loads a previously trained model and runs it in the specified environment with rendering enabled. This allows you to visually observe how the trained agent performs.

 
### Command Line Arguments

 `enjoy.py` accepts the following arguments:

 
| Argument | Default | Description |
|---|---|---|
| --seed | 1 | Random seed |
| --env-name | PongNoFrameskip-v4 | Environment to run the agent in |
| --load-dir | ./trained_models/ | Directory to load the agent model from |
| --non-det | False | Whether to use a non-deterministic policy |
| --log-interval | 10 | Log interval |

## Systematic Evaluation with evaluation.py

 While visual inspection is useful, systematic evaluation provides quantitative metrics about agent performance. The `evaluate()` function in `evaluation.py` runs the agent for multiple episodes and reports average rewards.

 
### Evaluation Process

 
```

```

 Sources: [evaluation.py1-49](https://github.com/ikostrikov/pytorch-a2c-ppo-acktr-gail/blob/41332b78/evaluation.py#L1-L49)

 The evaluation process:

 
 - Creates environments specifically for evaluation
 - Sets up observation normalization using the same statistics as during training
 - Runs the agent through multiple episodes (default is 10)
 - Collects episode rewards and calculates statistics
 - Returns and prints the mean reward

## Best Practices

 When evaluating trained agents, consider the following best practices:

 
 - **Use the same environment configuration** as during training (including wrappers and preprocessing)
 - **Use the same observation normalization statistics** that were used during training
 - **Use deterministic action selection** for evaluation (this is the default in both scripts)
 - **Run multiple evaluation episodes** to get reliable performance metrics
 
 
## Common Issues and Solutions

 
| Issue | Solution |
|---|---|
| Environment renders incorrectly | Check that the environment supports rendering and any required libraries (like PyBullet) are installed |
| Agent performs poorly | Verify you're loading the correct model and using the same environment configuration as during training |
| Observation normalization issues | Ensure you're loading and using the observation statistics (obs_rms) saved with the model |
| "Model not found" errors | Check the path to the model file and ensure the model was properly saved during training |
