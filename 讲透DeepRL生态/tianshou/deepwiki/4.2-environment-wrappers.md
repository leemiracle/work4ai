  Environment wrappers in Tianshou provide a way to modify the behavior of environments without changing their underlying implementation. These wrappers enable important functionality such as observation normalization, action space conversion, and other transformations that can be applied to environments in a modular way.

 For information about vectorized environments that execute multiple environments in parallel, see [Vectorized Environments](https://deepwiki.com/thu-ml/tianshou/4.1-vectorized-environments).

 
## Overview of Environment Wrappers

 Environment wrappers serve as an extension of the decorator pattern in software design, allowing for dynamically adding or modifying behaviors of environment objects. In Tianshou, wrappers are particularly useful for:

 
 - Normalizing observations to stabilize learning
 - Converting between different action space types
 - Modifying environment behaviors for compatibility with specific algorithms

## Vector Environment Wrappers

 Tianshou provides specialized wrappers for vector environments, which are the parallel environment execution engines in the framework.

 
### Base Vector Environment Wrapper

 The `VectorEnvWrapper` class serves as the foundation for all vector environment wrappers. It encapsulates a `BaseVectorEnv` instance and delegates all environment operations to it, providing a clean interface for adding new functionality.

 
```

```

 Unlike traditional inheritance, `VectorEnvWrapper` uses composition to wrap the base environment, forwarding all method calls to the wrapped environment.

### Observation Normalization

 The `VectorEnvNormObs` wrapper normalizes observations from the environment using running mean and standard deviation statistics. This is crucial for stabilizing learning, especially when observations have different scales.

 
```

```

 The normalization process follows these steps:

 
 - Receive raw observations from the environment
 - Update the running statistics (mean and variance)
 - Normalize the observations using these statistics
 - Pass normalized observations to the agent
 
 This wrapper is especially useful for environments where observation values have vastly different scales or ranges.

## Gymnasium Action Space Wrappers

 Tianshou provides several wrappers specifically designed to convert between different types of action spaces. These are particularly useful when using algorithms that require specific action space types.

 
### Continuous to Discrete Conversion

 The `ContinuousToDiscrete` wrapper converts a continuous action space (represented by a `Box` space in Gymnasium) to a multi-discrete action space. This allows algorithms designed for discrete action spaces to be used with environments that naturally have continuous action spaces.

 
```

```

 This discretizes each dimension of the continuous action space according to the specified number of bins.

 
### Multi-Discrete to Discrete Conversion

 The `MultiDiscreteToDiscrete` wrapper converts a multi-discrete action space to a single discrete action space. This is useful for algorithms that can only handle a singular discrete action output.

 
```

```

 The wrapper creates a one-to-one mapping between the product space of the multi-discrete actions and a single discrete action space.

 
### Truncated Episodes Handling

 The `TruncatedAsTerminated` wrapper treats truncated episodes (those that end due to a time limit rather than a natural termination condition) as terminated. This simplifies the logic for algorithms that don't distinguish between the two types of episode endings.

