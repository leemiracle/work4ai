## Purpose and Scope

 This document details the Mujoco examples provided in the Tianshou reinforcement learning library. These examples demonstrate how to train reinforcement learning agents on continuous control tasks using MuJoCo (Multi-Joint dynamics with Contact) environments with Tianshou's high-level API. MuJoCo environments feature realistic physics simulations and are widely used for benchmarking reinforcement learning algorithms on continuous control problems.

 
## Overview of Mujoco Examples

 The Mujoco examples implement various state-of-the-art reinforcement learning algorithms using Tianshou's high-level API, focusing on continuous control tasks like the Ant, Humanoid, and Walker environments.

## Algorithm Configuration Parameters

 The table below summarizes the key configuration parameters for each algorithm example:

 
| Algorithm | Key Parameters | Description |
|---|---|---|
| PPO | eps_clip, gae_lambda, vf_coef, ent_coef | Controls policy clipping, advantage estimation, value function weight, and entropy bonus |
| SAC | alpha, tau, auto_alpha | Temperature parameter, soft update coefficient, and auto-temperature tuning flag |
| A2C | gae_lambda, vf_coef, ent_coef | GAE parameter, value function weight, and entropy bonus |
| TRPO | max_kl, backtrack_coeff, max_backtracks | KL divergence constraint, line search coefficient, and max line search steps |
| NPG | actor_step_size, optim_critic_iters | Step size for actor updates and number of critic optimization iterations |
| DDPG | tau, exploration_noise | Soft update coefficient and exploration noise magnitude |
| TD3 | update_actor_freq, policy_noise, noise_clip | Frequency of delayed policy updates, noise added to target actions, and noise clipping value |
| REINFORCE | reward_normalization, action_bound_method | Whether to normalize rewards and method for bounding actions |
| REDQ | ensemble_size, subset_size, target_mode | Number of critics in ensemble, number of critics used for target calculation, and target calculation method |

## Algorithm Selection Guide

 When choosing which algorithm to use for a Mujoco task, consider the following guidance:

 
| Algorithm Type | Characteristics | Recommended For |
|---|---|---|
| On-Policy (PPO, A2C, TRPO) | Sample efficient in terms of environment interactions, stable learning | Tasks where stability is important, limited environment interactions |
| Off-Policy (SAC, TD3, DDPG) | More data efficient, can reuse past experiences | Tasks requiring high sample efficiency, complex continuous control problems |
| Advanced Methods (REDQ) | Ensemble approaches for reduced overestimation bias | Tasks where standard off-policy methods struggle with bias issues |

 For most Mujoco tasks, SAC and TD3 typically provide the best performance, while PPO offers good stability with reasonable sample efficiency.
