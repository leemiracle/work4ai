## Compatibility and Version Management

 Tianshou is currently developed for Python 3.11+. Version constraints in the `pyproject.toml` file ensure compatibility with dependencies.

 Notable version constraints include:

 
 - Python: `^3.11`
 - PyTorch: `^2.0.0, !=2.0.1, !=2.1.0` (excludes specific problematic versions)
 - Gymnasium: `^0.28.0`
 - Pandas: `>=2.0.0`
 
 The Poetry lock file (`poetry.lock`) ensures reproducible builds by pinning exact versions of all dependencies and their transitive dependencies.
