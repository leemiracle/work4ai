  This page documents the actor-critic network architectures in Tianshou. Actor-critic methods are a fundamental class of reinforcement learning algorithms that maintain separate networks for policy (actor) and value function estimation (critic). This document covers the implementation details of these networks in Tianshou, focusing on their architecture, interfaces, and how they're used across different action spaces and algorithms.

 For information about specific algorithm implementations using these networks, see [Actor-Critic Algorithms](https://deepwiki.com/thu-ml/tianshou/3.4-actor-critic-algorithms).

 
## 1. Overview of Actor-Critic Architecture

 Actor-critic methods combine policy-based and value-based approaches by maintaining two network components:

 
 - **Actor**: Determines the agent's policy by outputting actions or action probabilities
 - **Critic**: Evaluates the actor's policy by estimating state values or state-action values

## 8. Best Practices for Customization

 When customizing actor-critic networks in Tianshou:

 
 - Start with the appropriate base classes (`Actor`, `ActorProb`, `Critic`) based on your action space
 - Define your preprocessing network (usually a feature extractor)
 - Combine them with the `ActorCritic` wrapper if using both components
 - Pass the networks to the appropriate policy class
 
 For advanced customization, you can implement your own networks following the same interfaces.
