## Purpose and Scope

 This document details the neural network architectures specifically designed for distributional reinforcement learning algorithms in Tianshou. Distributional RL extends traditional value-based methods by modeling the entire distribution of returns rather than just the expected value. This page covers the network implementations that support algorithms like C51, QR-DQN, IQN, and FQF. For information about standard actor-critic networks, see [Actor-Critic Networks](https://deepwiki.com/thu-ml/tianshou/7.2-actor-critic-networks).

 
## Overview of Distributional RL

 Distributional reinforcement learning represents the value function as a distribution over possible returns rather than a single expected value. This provides several advantages:

 
 - Better uncertainty estimation
 - Improved exploration
 - More stable learning dynamics
 - Enhanced performance in environments with multimodal reward distributions

 Tianshou implements network structures for the following distributional RL algorithms:

|---|---|---|
| C51 | Categorical distribution with 51 fixed atoms | Net with num_atoms=51 |
| QR-DQN | Quantile Regression DQN with fixed quantiles | Net with appropriate num_atoms |
| IQN | Implicit Quantile Networks with sampled quantiles | ImplicitQuantileNetwork |
| FQF | Fully parameterized Quantile Function with learned quantile fractions | FullQuantileFunction |

 The foundation for distributional RL networks in Tianshou is the `Net` class, which supports distributional outputs through the `num_atoms` parameter:


 When `num_atoms > 1`, the network output is reshaped to `[batch_size, action_dim, num_atoms]`, representing a distribution over possible returns for each action.

 The `Net` class also supports dueling architecture, which is particularly beneficial for distributional RL, as it separates state value and action advantage estimations.

## Distributional Network Components

 
### Categorical Distribution (C51)

 C51 uses a fixed set of support values (atoms) to represent the return distribution. In Tianshou, this is implemented using the standard `Net` class with:

 
 - `num_atoms=51` (typically)
 - `softmax=True` to output a probability distribution
 - Optional dueling architecture
 
 The network outputs a categorical distribution with predefined, equally-spaced support values.

 Sources: [tianshou/utils/net/common.py186-289](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/utils/net/common.py#L186-L289)

## Implementing Custom Distributional Networks

 To implement a custom distributional RL network:

 
 - For categorical or fixed-quantile approaches:

 
 - Extend the `Net` class
 - Set `num_atoms` to the desired number of distribution points
 - Optionally configure dueling architecture with `dueling_param`
 - For flexible quantile-based approaches:

 
 - Consider extending `ImplicitQuantileNetwork` or `FullQuantileFunction`
 - Customize the embedding method or quantile selection as needed
 
 The key is to ensure your network outputs a representation of the full return distribution rather than just a single expected value.

## Summary

 Distributional RL networks in Tianshou extend traditional value networks to model the full distribution of returns rather than just the expected value. This is achieved through:

 
 - The `Net` class with `num_atoms > 1` for categorical and fixed-quantile methods
 - Specialized network components like `ImplicitQuantileNetwork` and `FullQuantileFunction` for more advanced approaches
 - Support for auxiliary components like `CosineEmbeddingNetwork` and `NoisyLinear`
 
 These networks form the foundation for distributional RL algorithms like C51, QR-DQN, IQN, and FQF, enabling more robust and informative value estimation.
