  This document provides comprehensive instructions for installing Tianshou and managing its dependencies. Tianshou is a reinforcement learning library built on PyTorch that provides a modular framework for implementing and experimenting with RL algorithms.

 
## System Requirements

 
 - Python >= 3.11
 - Compatible operating systems: Linux, macOS, Windows (with some platform-specific limitations for certain extras)

## Environment and Algorithm Support

 The following table shows which environment types are supported with specific optional dependencies:

 
| Environment Type | Required Extra | Key Dependencies | Notes |
|---|---|---|---|
| Atari | atari | ale-py, autorom | Requires ROM license acceptance |
| Box2D | box2d | box2d-py, pygame | Used for environments like LunarLander |
| Classic Control | classic_control | pygame | For environments like CartPole |
| MuJoCo | mujoco | mujoco, imageio | Modern MuJoCo support |
| MuJoCo (legacy) | mujoco-py | mujoco-py, cython | Legacy support, macOS issues |
| PyBullet | pybullet | pybullet | Alternative physics simulator |
| Robotics | robotics | gymnasium-robotics | Robotics environments |
| ViZDoom | vizdoom | vizdoom | First-person shooter environments |
