## Deep Q-Network (DQN)

 The DQN algorithm is the foundation of most value-based methods in Tianshou. It approximates the Q-value function using a neural network and uses experience replay and target networks for stable learning.

 
### Key Components of DQN Implementation

 
 - **Model**: A neural network that maps state to action values
 - **Target Network**: A copy of the main network that is updated less frequently for stability
 - **Experience Replay**: Stores and samples transitions for learning
 - **Epsilon-Greedy Exploration**: Balances exploration and exploitation

### Key Methods in DQN

 The DQN implementation in Tianshou contains several important methods:

 
 - **forward**: Computes Q-values for given observations and selects actions
 - **compute_q_value**: Computes Q-values with optional action masking
 - **_target_q**: Calculates target Q-values for TD learning
 - **process_fn**: Processes batches from the replay buffer to compute returns
 - **learn**: Updates the policy based on sampled batches
 
 The `learn` method implements the core DQN update:

 
 - Synchronize target network if needed
 - Compute current Q-values for the batch
 - Compute TD error between targets and current predictions
 - Update the network weights via backpropagation

## Summary

 Tianshou provides a comprehensive implementation of value-based algorithms, from the classic DQN to advanced distributional methods like C51, QRDQN, IQN, FQF, and Rainbow. All of these algorithms share a common structure, inheriting from the `BasePolicy` class and implementing specific methods for estimating value functions and learning from experience.

 These algorithms integrate with Tianshou's collector and trainer systems, making it easy to train and evaluate agents in various environments. The modular design allows for easy experimentation and extension of existing algorithms.
