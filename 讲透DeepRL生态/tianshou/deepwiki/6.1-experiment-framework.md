  This page documents the Experiment Framework, which is part of Tianshou's high-level API. The framework provides a structured way to configure, create, and run reinforcement learning experiments with minimal boilerplate code. It abstracts away many implementation details while providing a clean interface for customization.

 For information about specific experiment builders for different algorithms, see [Builder Pattern](https://deepwiki.com/thu-ml/tianshou/6.2-builder-pattern). For details about agent and environment factory components, see [Agent and Environment Factories](https://deepwiki.com/thu-ml/tianshou/6.3-agent-and-environment-factories).

 
## Overview

 The Experiment Framework serves as a bridge between the user's experimental setup and Tianshou's core reinforcement learning components. It provides a clean, serializable representation of experiments that can be saved, restored, and shared.

## Key Components

 
### ExperimentConfig

 The `ExperimentConfig` class is a dataclass that contains configuration parameters common to all experiments, regardless of the specific reinforcement learning algorithm used.

 
```

```

 Key configuration options include:

 
 - Random seed for reproducibility
 - Device (CPU/GPU) for computation
 - Training and watching flags
 - Persistence and logging settings
 
 Sources: [tianshou/highlevel/experiment.py119-147](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/highlevel/experiment.py#L119-L147)

 
### Experiment

 The `Experiment` class represents a complete reinforcement learning experiment. It contains all configuration and factory objects needed to create a running experiment.

 
```

```

 The `Experiment` class provides two main entry points:

 
 - `create_experiment_world()`: Creates a `World` object containing all components needed for the experiment
 - `run()`: Runs the experiment and returns the results
 
 The `Experiment` can also be serialized and deserialized using the `save()` and `from_directory()` methods.

 Sources: [tianshou/highlevel/experiment.py165-471](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/highlevel/experiment.py#L165-L471)

 
### World

 When an experiment is run, it creates a `World` object, which serves as a container for all the essential components of the experiment:

 
```

```

 The `World` contains references to:

 
 - The environment(s)

 - Train and test collectors
 - Logger
 - Trainer

## Integration with SamplingConfig

 The `SamplingConfig` class defines parameters related to sampling, epochs, parallelization, buffers, collectors, and batching. It works together with `ExperimentConfig` to fully specify an experiment.

 
```

```

 Key aspects of `SamplingConfig`:

 
 - It specifies training parameters like number of epochs and steps per epoch
 - It controls buffer sizes and collection behavior
 - It defines environment-related parameters like number of training and test environments

## Advanced Features

 
### Experiment Persistence


 - Experiments can be saved to disk using `save()`
 - Experiments can be restored using `from_directory()`

 - Observation normalization statistics can be saved and restored for environments that support it

## Summary

 The Experiment Framework provides a high-level interface for setting up, running, and analyzing reinforcement learning experiments in Tianshou. Key benefits include:

 
 - **Simplified Setup**: Abstracts away boilerplate code for experiment creation
 - **Customizability**: Allows for detailed customization while providing sensible defaults
 - **Reproducibility**: Supports saving and restoring experiments
 - **Statistical Rigor**: Facilitates running multiple experiments with different seeds
 - **Integration**: Seamlessly integrates with Tianshou's core components
 
 This framework is particularly useful for researchers and practitioners who want to focus on experimentation and analysis rather than low-level implementation details.
