## Reinforcement Learning Fundamentals

 Reinforcement Learning (RL) is a paradigm where an agent learns to make decisions by interacting with an environment. The agent takes actions, causing the environment to change state and provide feedback in the form of rewards.

 
| Term | Description |
|---|---|
| State (S) | Current situation of the environment |
| Action (A) | Decision made by the agent |
| Reward (R) | Immediate feedback from the environment |
| Policy (π) | Strategy that the agent follows to determine actions |
| Value Function (V) | Expected cumulative reward from a state |
| Q-Function (Q) | Expected cumulative reward from a state-action pair |
| Trajectory | Sequence of states, actions, and rewards over time |

 The goal in RL is to find a policy that maximizes the expected cumulative reward over time.

## Policy Framework

 The Policy Framework is the core of Tianshou, defining how agents make decisions and learn from experience.

 
### BasePolicy

 All policies in Tianshou inherit from the `BasePolicy` class, which defines four key methods:

 
 - **forward**: Computes actions based on observations
 - **learn**: Updates the policy using a batch of experience data
 - **process_fn**: Preprocesses data from the replay buffer
 - **update**: The main training interface that combines the above methods

## Data Handling System

 The Data Handling System manages the collection, storage, and processing of experiences.

 
### Batch

 The `Batch` class is a flexible container for heterogeneous data like observations, actions, and rewards. It provides a unified interface across Tianshou.

 Essential Batch fields:

 
| Field | Description |
|---|---|
| obs | Observations from the environment |
| act | Actions taken by the agent |
| rew | Rewards received from the environment |
| done | Whether the episode has terminated |
| info | Additional information from the environment |
| policy | Policy-specific data (e.g., log probabilities) |

 Sources: [README.md69](https://github.com/thu-ml/tianshou/blob/90846f6b/README.md?plain=1#L69-L69)

 
### ReplayBuffer

 The `ReplayBuffer` stores and samples experience tuples for training. Tianshou provides several variants:

 
 - **VectorReplayBuffer**: For storing experiences from vectorized environments
 - **PrioritizedReplayBuffer**: Prioritizes experiences based on TD error
 - **HERReplayBuffer**: Implements Hindsight Experience Replay

## Performance Features

 Tianshou is designed for high performance:

 
 - Vectorized environment support (synchronous or asynchronous)
 - Integration with EnvPool for super-fast vectorized environments
 - Support for RNN-style training in partially observable environments
 - Support for customized training processes
 - Multi-GPU training capabilities
 - Optimized n-step returns and prioritized experience replay
