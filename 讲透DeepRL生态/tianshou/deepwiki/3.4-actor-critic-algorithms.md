  This document provides a detailed explanation of actor-critic algorithms in the Tianshou reinforcement learning framework. Actor-critic methods combine value-based and policy-based approaches by maintaining both an actor (policy) network that selects actions and a critic network that evaluates those actions. Tianshou implements several actor-critic variants including DDPG, TD3, SAC, A2C, and PPO.

 For policy gradient algorithms that don't use a critic, see [Policy Gradient Algorithms](https://deepwiki.com/thu-ml/tianshou/3.3-policy-gradient-algorithms). For value-based methods, see [Value-Based Algorithms](https://deepwiki.com/thu-ml/tianshou/3.2-value-based-algorithms).

 
## Actor-Critic Architecture

 Actor-critic algorithms in Tianshou follow a common pattern while differing in specific implementation details. The actor chooses actions based on the current policy, while the critic evaluates state-action pairs to provide feedback for policy improvement.

## Implementation Details

 
### DDPG (Deep Deterministic Policy Gradient)

 DDPG is designed for continuous action spaces and uses deterministic policies with experience replay and target networks for stability.

 
```

```

 Key properties:

 
 - Uses a deterministic actor that directly outputs actions
 - Employs a Q-function critic to evaluate state-action pairs
 - Target networks are slowly updated versions of the main networks
 - Supports exploration noise through the `exploration_noise` parameter
 - TD error drives both critic and actor learning
 
 Sources: [tianshou/policy/modelfree/ddpg.py34-58](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/ddpg.py#L34-L58) [tianshou/policy/modelfree/ddpg.py182-198](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/ddpg.py#L182-L198) [tianshou/policy/modelfree/ddpg.py199-224](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/ddpg.py#L199-L224)

 
### TD3 (Twin Delayed DDPG)

 TD3 addresses DDPG's overestimation bias by using twin critics and delayed policy updates.

 
```

```

 Key improvements over DDPG:

 
 - Twin critics to reduce overestimation bias
 - Delayed policy updates (controlled by `update_actor_freq`)
 - Target policy smoothing by adding clipped noise to target actions
 - Uses the minimum Q-value from both critics for learning
 
 Sources: [tianshou/policy/modelfree/td3.py28-61](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/td3.py#L28-L61) [tianshou/policy/modelfree/td3.py128-141](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/td3.py#L128-L141) [tianshou/policy/modelfree/td3.py143-163](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/td3.py#L143-L163)

 
### SAC (Soft Actor-Critic)

 SAC uses stochastic policies with entropy regularization for improved exploration and robustness.

 
```

```

 Key features:

 
 - Stochastic policy that outputs a Gaussian distribution
 - Actions are sampled and squashed using tanh
 - Twin critics like TD3
 - Entropy regularization through the temperature parameter (`alpha`)
 - Optional automatic temperature adjustment
 - Log probability correction for squashed Gaussian actions
 
 Sources: [tianshou/policy/modelfree/sac.py54-93](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/sac.py#L54-L93) [tianshou/policy/modelfree/sac.py186-209](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/sac.py#L186-L209) [tianshou/policy/modelfree/sac.py226-262](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/sac.py#L226-L262)

 
### A2C (Advantage Actor-Critic)

 A2C uses the advantage function to reduce variance in policy gradient updates for both discrete and continuous action spaces.

 
```

```

 Key components:

 
 - Policy network outputs action probabilities or distribution parameters
 - Value network estimates state values
 - Generalized Advantage Estimation (GAE) for variance reduction
 - Optional value function normalization
 - Entropy regularization to encourage exploration
 
 Sources: [tianshou/policy/modelfree/a2c.py33-62](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/a2c.py#L33-L62) [tianshou/policy/modelfree/a2c.py108-156](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/a2c.py#L108-L156) [tianshou/policy/modelfree/a2c.py160-206](https://github.com/thu-ml/tianshou/blob/90846f6b/tianshou/policy/modelfree/a2c.py#L160-L206)

 
### PPO (Proximal Policy Optimization)

 PPO is an on-policy algorithm that constrains policy updates to prevent destructively large changes.

 
```

```

 Key features:

 
 - Clipped surrogate objective that limits policy changes
 - Optional value function clipping
 - Multiple epochs of optimization on each batch of data
 - Support for dual clipping to improve performance in some environments
 - Advantage normalization per mini-batch option

## Algorithm Comparison

 Each actor-critic algorithm in Tianshou has specific strengths and use cases:

 
| Algorithm | Action Space | Key Features | Best For | Implementation |
|---|---|---|---|---|
| DDPG | Continuous | Deterministic policy, target networks | Basic continuous control tasks | ddpg.py |
| TD3 | Continuous | Twin critics, delayed updates, target smoothing | Complex continuous control tasks, better stability than DDPG | td3.py |
| SAC | Continuous | Stochastic policy, entropy maximization | Exploration-heavy problems, robust learning | sac.py |
| A2C | Discrete/Continuous | Advantage estimation, entropy regularization | Fast, simple baseline algorithm | a2c.py |
| PPO | Discrete/Continuous | Clipped objective, on-policy learning | General-purpose, stable learning across many domains | ppo.py |

## Learning Process

 All actor-critic algorithms implement the `learn()` method which handles network updates. Here's a generalized flow of the learning process:

 
```

```

 Common patterns across implementations:

 
 - Off-policy methods (DDPG, TD3, SAC) use target networks that are updated via soft updates
 - On-policy methods (A2C, PPO) often perform multiple update steps on the same batch of data
 - Each algorithm returns a TrainingStats object with algorithm-specific metrics
 - Actor-critic methods typically update the critic first, then the actor

## Usage Recommendations

 When choosing an actor-critic algorithm in Tianshou:

 
 - **For continuous control tasks**:

 
 - **SAC** is often the strongest performer with good sample efficiency and exploration
 - **TD3** provides good stability and performance, especially in deterministic environments
 - **DDPG** is simpler but may be less stable
 - **For discrete or mixed action spaces**:

 
 - **PPO** offers good stability and performance across many problems
 - **A2C** can be faster for simple problems but may be less stable
 - **Implementation considerations**:

 
 - Off-policy methods (DDPG, TD3, SAC) can reuse experience and are often more sample-efficient
 - On-policy methods (A2C, PPO) typically require more samples but can be more stable
 - SAC has automatic entropy adjustment capabilities for balancing exploration and exploitation
