## Introduction

 The Contrib Module in Catalyst is a collection of community-contributed extensions that augment the core functionality of the framework. It serves as a repository for experimental components, specialized implementations, and utilities that may be useful for specific machine learning tasks but are not part of the main API. These components follow a "code-as-a-documentation" format, meaning that their implementation serves as their primary documentation.

 The module is designed to be a proving ground for new features which may eventually be incorporated into the main Catalyst framework. Contributions that demonstrate strong utility and stability may be promoted to the core framework in future releases.

 For information about contributing to Catalyst, including how to add to the Contrib module, see [Contributing Guidelines](https://deepwiki.com/catalyst-team/catalyst/10.2-contributing-guidelines).

## Data Components

 The Contrib module provides several data-related components that extend Catalyst's data handling capabilities.

 
### InBatch Samplers

 InBatch samplers are specialized samplers used for tasks like metric learning, where specific relationships between samples in a batch are required.

 
| Sampler | Description |
|---|---|
| InBatchTripletsSampler | Creates triplets of samples within a batch for triplet loss |
| AllTripletsSampler | Generates all possible triplets from a batch |
| HardTripletsSampler | Selects hard triplets based on distances |
| HardClusterSampler | Creates clusters of samples with similar properties |

 
### Other Samplers

 
| Sampler | Description |
|---|---|
| BalanceBatchSampler | Creates balanced batches across classes |
| DynamicBalanceClassSampler | Dynamically adjusts sampling probabilities to balance classes |

 
### Transforms

 
| Transform | Description |
|---|---|
| Compose | Chains multiple transforms together |
| ImageToTensor | Converts images to tensors |
| NormalizeImage | Normalizes image tensors |
