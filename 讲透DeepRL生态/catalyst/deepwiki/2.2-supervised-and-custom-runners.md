## SupervisedRunner

 The `SupervisedRunner` is a specialized implementation designed for supervised learning tasks. It simplifies the common supervised training workflow by providing automatic handling of input/output data and integrating the necessary criterion, optimizer, and backward callbacks.

### Key Features of SupervisedRunner

 
 - **Flexible input/output handling**: Supports various input and output formats (single values, lists, dictionaries)
 - **Automatic batch processing**: Intelligently processes batch data based on its format
 - **Default callbacks**: Automatically adds criterion, backward, and optimizer callbacks if not provided
 - **Simplified prediction**: Built-in methods for model inference

## Advanced Runner Customization

 
### Handling Different Input/Output Formats

 SupervisedRunner provides several methods for handling different input and output formats:

 
 - `_process_input_str`: For models expecting a single input tensor
 - `_process_input_list`: For models expecting multiple input tensors
 - `_process_input_none`: For models expecting a dictionary of inputs
 - `_process_output_str`: For models returning a single output tensor
 - `_process_output_list`: For models returning multiple output tensors
 - `_process_output_none`: For models returning a dictionary of outputs
 
 This flexibility allows SupervisedRunner to work with a wide variety of model interfaces.

## Best Practices for Custom Runners

 
 - **Inherit from the right base class**: Use Runner for general cases, SupervisedRunner for supervised learning
 - **Override only what you need**: Maintain compatibility with the Catalyst ecosystem by minimizing changes
 - **Leverage the callback system**: Use callbacks for side effects rather than modifying the runner
 - **Maintain the event flow**: Ensure proper calling of event methods (on_batch_start, on_batch_end, etc.)
 - **Consider distributed training**: Make your runner compatible with distributed training setups
 - **Provide clear predictions**: Implement predict_batch for easy model inference

## Summary

 Supervised and custom runners form the backbone of experiment execution in Catalyst. The SupervisedRunner provides a convenient abstraction for standard supervised learning tasks, while custom runners enable specialized training paradigms like self-supervised learning.

 By understanding the runner hierarchy and customization points, you can adapt Catalyst to a wide variety of deep learning tasks while maintaining compatibility with the framework's utilities for logging, checkpointing, and hardware acceleration.
