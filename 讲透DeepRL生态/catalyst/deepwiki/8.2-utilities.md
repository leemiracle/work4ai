These utilities serve as building blocks for the framework's higher-level components and can be used independently in custom code. This page documents the primary utility modules and functions available in Catalyst.

## Distributed Training Utilities

 Catalyst provides utilities to simplify distributed training with PyTorch. These are imported from `catalyst.utils.distributed` and include:

 
| Function | Description |
|---|---|
| get_backend() | Gets the distributed backend being used |
| get_world_size() | Gets the total number of processes in the distributed job |
| get_rank() | Gets the rank of the current process |
| get_nn_from_ddp_module(model) | Retrieves the underlying model from a DistributedDataParallel-wrapped module |
| sum_reduce(tensor) | Reduces tensors by summing across distributed processes |
| mean_reduce(tensor) | Reduces tensors by averaging across distributed processes |
| all_gather(tensor) | Gathers tensors from all processes into a list |
| ddp_reduce(tensor) | Reduces tensors according to specified reduction type |

 Sources: [catalyst/utils/__init__.py6-15](https://github.com/catalyst-team/catalyst/blob/e99f9065/catalyst/utils/__init__.py#L6-L15)

## Conclusion

 Catalyst's utility functions provide a solid foundation for building deep learning workflows. They handle many common tasks that arise in ML development, from configuration management to device handling, checkpoint operations, and training optimizations. By leveraging these utilities, developers can focus on model architecture and training logic rather than boilerplate code.
