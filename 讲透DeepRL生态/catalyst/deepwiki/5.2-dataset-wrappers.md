  This page documents the dataset wrapper classes provided by Catalyst, which extend PyTorch's Dataset interface to provide additional functionality for specific use cases. These wrappers facilitate tasks like distributed training and self-supervised learning by transforming data or adapting existing datasets.

 For information about samplers that handle class imbalance, see [Samplers for Imbalanced Data](https://deepwiki.com/catalyst-team/catalyst/5.1-samplers-for-imbalanced-data).

 
## Overview of Dataset Wrappers

 The Catalyst framework provides two primary dataset wrapper classes:

 
 - **DatasetFromSampler** - Creates a dataset from a PyTorch sampler
 - **SelfSupervisedDatasetWrapper** - Creates multiple augmented views of the same data for contrastive learning
 
 These wrappers are designed to work within Catalyst's data handling pipeline, which connects to the Runner system for training deep learning models.

## SelfSupervisedDatasetWrapper

 
### Purpose and Functionality

 The `SelfSupervisedDatasetWrapper` transforms an existing dataset to create multiple augmented views of the same data sample. This is essential for self-supervised learning methods like SimCLR, BYOL, and Barlow Twins that rely on contrastive learning between different views of the same input.

 
### Implementation Details

 The wrapper works by:

 
 - Taking an original dataset and transformation functions
 - For each data item, applying different transformations to create multiple views
 - Optionally preserving the original sample with a separate transformation
 - Returning all views (and optionally the target) for each item

### Configuration Options

 The `SelfSupervisedDatasetWrapper` offers several configuration options:

 
| Parameter | Type | Description |
|---|---|---|
| dataset | Dataset | The original dataset to wrap |
| transforms | Callable | Transforms applied to both left and right views |
| transform_left | Callable | Transform only for the left view |
| transform_right | Callable | Transform only for the right view |
| transform_original | Callable | Transform for preserving the original sample |
| is_target | bool | Whether the dataset returns (sample, target) or just sample |

 You must specify either `transforms` or both `transform_left` and `transform_right`.

## Integration with Catalyst Self-Supervised Learning

 The dataset wrappers are key components in Catalyst's self-supervised learning implementations. The framework includes examples for several popular self-supervised methods:

 
 - **SimCLR** - Uses contrastive learning between differently augmented views
 - **BYOL** - Uses a teacher-student approach with momentum updates
 - **Barlow Twins** - Uses redundancy reduction through decorrelation
 - **Supervised Contrastive** - Uses label information to guide contrastive learning

### Example: SimCLR Implementation

 In the SimCLR example, the `SelfSupervisedDatasetWrapper` is used to:

 
 - Create two augmented views of each input
 - Pass both views through the encoder to get embeddings
 - Apply a projection head to get projections
 - Compute the contrastive loss (NTXentLoss) between the projections
 - Train a linear classifier on the learned embeddings
 
 The self-supervised runner handles the specific logic for:

 
 - Processing both augmented views
 - Managing the model forward pass
 - Computing the contrastive loss
 - Evaluating the learned representations

## Summary

 Dataset wrappers in Catalyst provide essential functionality for:

 
 - **Distributed Training** - `DatasetFromSampler` enables the use of custom samplers in distributed settings
 - **Self-Supervised Learning** - `SelfSupervisedDatasetWrapper` creates multiple views of data for contrastive learning
 - **Custom Data Processing** - The framework is extensible for creating domain-specific dataset wrappers
 
 These wrappers integrate seamlessly with PyTorch's data handling infrastructure and Catalyst's training pipelines, enabling complex deep learning workflows while maintaining a clean, modular API.
