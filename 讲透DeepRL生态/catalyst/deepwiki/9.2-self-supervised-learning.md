  This page documents self-supervised learning (SSL) capabilities in the Catalyst framework. Self-supervised learning is a technique where models learn from unlabeled data by creating surrogate tasks using the inherent structure of the data itself. This approach is particularly useful when labeled data is scarce or expensive to obtain.

 For information about supervised learning approaches, see [Supervised Learning](https://deepwiki.com/catalyst-team/catalyst/9.1-supervised-learning). For reinforcement learning, see [Reinforcement Learning](https://deepwiki.com/catalyst-team/catalyst/9.3-reinforcement-learning).

 
## Overview of Self-Supervised Learning in Catalyst

 Catalyst provides implementations of several state-of-the-art self-supervised learning algorithms, focusing on contrastive learning approaches. These algorithms learn representations by comparing different views (augmentations) of the same data point.

## Supported Algorithms

 Catalyst currently supports the following self-supervised learning algorithms:

 
| Algorithm | Description | Loss Function | Key Features |
|---|---|---|---|
| SimCLR | Simple Framework for Contrastive Learning of Visual Representations | NTXentLoss | Uses temperature-scaled cross-entropy loss |
| Barlow Twins | Learning representations by maximizing invariance while reducing redundancy | BarlowTwinsLoss | Uses off-diagonal regularization for decorrelation |
| BYOL | Bootstrap Your Own Latent | NTXentLoss + Target Network | Doesn't require negative pairs |
| Supervised Contrastive | Extension of contrastive learning that incorporates label information | SupervisedContrastiveLoss | Uses class labels to create positive pairs |

### Training Process

 The self-supervised learning training process typically consists of the following steps:

 
 - **Data Preparation**: Create augmented views of the same images.
 - **Feature Extraction**: Pass different views through the encoder to obtain embeddings.
 - **Projection**: Transform embeddings with a projection head to a lower-dimensional space.
 - **Loss Calculation**: Compute contrastive loss between projections from different views.
 - **Evaluation**: Assess representation quality by training a simple classifier on frozen features.
 
 
### Callback Configuration

 Catalyst's callback system is extensively used in self-supervised learning to modularize the training process:

 
 - **CriterionCallback**: Computes the contrastive loss between projections.
 - **BackwardCallback**: Performs the backward pass.
 - **OptimizerCallback**: Updates model parameters.
 - **SklearnModelCallback**: Trains a linear classifier on the embeddings for evaluation.
 - **AccuracyCallback**: Calculates accuracy metrics for the linear classification.

## Performance Results

 Performance is evaluated by training a logistic regression classifier on the learned representations:

 
| Algorithm | CIFAR-10 (top-1) | CIFAR-100 (top-1) | STL10 (top-1) |
|---|---|---|---|
| Barlow Twins | 25.68±2.82 | 5.24±1.18 | 27.77±3.27 |
| BYOL | 33.85±2.71 | 11.88±1.83 | 31.22±2.98 |
| SimCLR | 32.92±3.30 | 10.49±1.77 | 34.37±2.71 |
| Supervised Contrastive | 77.78±2.53 | 37.56±2.93 | 63.17±2.78 |

 Notes:

 
 - Supervised Contrastive consistently outperforms other methods as it uses label information.
 - Among purely self-supervised methods, BYOL and SimCLR tend to perform better than Barlow Twins.
 - Performance varies across datasets, with STL10 showing relatively stronger results for SimCLR.
