  This page documents the specialized samplers provided by Catalyst for handling imbalanced datasets. Class imbalance is a common challenge in machine learning where some classes have significantly more samples than others, potentially causing models to be biased toward majority classes. Catalyst offers several samplers that address this issue through different rebalancing strategies.

 For information about dataset wrappers and other data processing components, see [Dataset Wrappers](https://deepwiki.com/catalyst-team/catalyst/5.2-dataset-wrappers).

 
## Overview of Available Samplers

 Catalyst provides five sampler implementations for handling imbalanced data and related training scenarios:

 
| Sampler | Purpose | Strategy |
|---|---|---|
| BalanceClassSampler | Basic class balancing | Upsampling or downsampling to a fixed count per class |
| BatchBalanceClassSampler | Class balancing within batches | Fixed number of samples per class in each batch |
| DynamicBalanceClassSampler | Gradual class balancing | Exponential scheduling from original to uniform distribution |
| MiniEpochSampler | Training on dataset subsets | Creates mini-epochs of specified length |
| DistributedSamplerWrapper | Distributed training | Wraps any sampler for distributed training |

## Sampler Implementations

 
### BalanceClassSampler

 `BalanceClassSampler` addresses class imbalance through static rebalancing, creating a stratified sample by either downsampling or upsampling:

 
 - **Downsampling**: Reduces all classes to have the same number of samples as the minority class
 - **Upsampling**: Increases all classes to have the same number of samples as the majority class or to a specified count
 
 
#### Implementation Details

 The class accepts a list of labels and a mode parameter, then adjusts sampling accordingly:

 
```

```

 Key implementation points:

 
 - Maps class labels to their indices in the dataset
 - For downsampling, uses the size of the smallest class for all classes
 - For upsampling, uses the size of the largest class (or specified count) for all classes
 - When upsampling, uses sampling with replacement for minority classes
 
 Sources: [catalyst/data/sampler.py17-113](https://github.com/catalyst-team/catalyst/blob/e99f9065/catalyst/data/sampler.py#L17-L113)

 
### BatchBalanceClassSampler

 `BatchBalanceClassSampler` ensures each batch contains a fixed number of classes with a fixed number of samples per class. This is particularly useful for metric learning tasks where you need to have multiple samples of the same class within each batch.

 
#### Implementation Details

 The sampler takes:

 
 - A list of class labels
 - `num_classes`: Number of classes to include in each batch
 - `num_samples`: Number of samples per class in each batch
 - `num_batches`: Number of batches per epoch (optional)
 
 
```

```

 Important characteristics:

 
 - The resulting batch size is `num_classes * num_samples`
 - Each batch contains exactly `num_classes` different classes
 - Each class in a batch is represented by exactly `num_samples` instances
 - Classes with fewer than `num_samples` instances will have samples duplicated (replacement sampling)
 - Each class must have at least 2 samples in the dataset (for forming pairs)
 
 Sources: [catalyst/data/sampler.py116-256](https://github.com/catalyst-team/catalyst/blob/e99f9065/catalyst/data/sampler.py#L116-L256)

 
### DynamicBalanceClassSampler

 `DynamicBalanceClassSampler` implements a gradual approach to class balancing. It starts with the original class distribution and progressively transitions to a uniform distribution using an exponential scheduler.

 
#### Implementation Details

 The sampler uses:

 
 - A list of class labels
 - `exp_lambda`: Exponent figure for the schedule (0 < exp_lambda < 1)
 - `start_epoch`: Starting epoch number (useful for multi-stage training)
 - `max_d`: Optional limit on the ratio between most and least frequent classes
 
 
```

```

 Key features:

 
 - Distribution smoothly changes from original to balanced with each epoch
 - Early epochs: Distribution close to original dataset
 - Middle epochs: Partially balanced distribution
 - Later epochs: Nearly uniform distribution
 - The parameter `exp_lambda` controls how quickly balancing occurs
 
 Sources: [catalyst/data/sampler.py258-397](https://github.com/catalyst-team/catalyst/blob/e99f9065/catalyst/data/sampler.py#L258-L397)

 
### MiniEpochSampler

 `MiniEpochSampler` creates smaller subsets of the dataset called "mini-epochs" with a specified length. While not specifically designed for class imbalance, it's useful for large datasets where you want more frequent validation.

 
#### Implementation Details

 This sampler takes:

 
 - `data_len`: Size of the dataset
 - `mini_epoch_len`: Number of samples in each mini-epoch
 - `drop_last`: Whether to drop the last mini-epoch if incomplete
 - `shuffle`: When to shuffle indices ("per_mini_epoch", "per_epoch", or None)
 
 
```

```

 Benefits:

 
 - Allows for more frequent validation without waiting for full epochs
 - Particularly useful for extremely large datasets
 - Can be combined with other balancing strategies
 - Supports different shuffling strategies
 
 Sources: [catalyst/data/sampler.py400-496](https://github.com/catalyst-team/catalyst/blob/e99f9065/catalyst/data/sampler.py#L400-L496)

 
### DistributedSamplerWrapper

 `DistributedSamplerWrapper` allows any custom sampler to be used in distributed training. It wraps around another sampler and ensures proper distribution of samples across multiple processes.

 
#### Implementation Details

 The wrapper takes:

 
 - `sampler`: The base sampler to wrap
 - `num_replicas`: Number of processes in distributed training (optional)
 - `rank`: Rank of the current process (optional)
 - `shuffle`: Whether to shuffle the indices (optional)
 
 
```

```

 Key aspects:

 
 - Uses the `DatasetFromSampler` utility to create a dataset from the base sampler's indices
 - Applies PyTorch's standard `DistributedSampler` to this synthetic dataset
 - Returns the appropriate subset of indices for the current process
 - Preserves the base sampler's logic while enabling distributed training

## Selecting the Right Sampler

 
| Sampler | Best Used When | Advantages | Limitations |
|---|---|---|---|
| BalanceClassSampler | You need a simple solution to class imbalance | - Simple implementation- Ensures balanced class distribution- Works well for standard classification | - Can reduce dataset size with downsampling- May cause overfitting with upsampling |
| BatchBalanceClassSampler | You're performing metric learning or need intra-class pairs | - Creates structured batches for contrastive learning- Guarantees multiple samples per class in each batch- Ideal for triplet and pair-based losses | - Fixed batch size (num_classes * num_samples)- Requires classes to have at least 2 samples- May not use all data in an epoch |
| DynamicBalanceClassSampler | You want to preserve original distribution initially | - Smooth transition from original to balanced- Adaptively changes distribution over epochs- Prevents abrupt distribution changes | - More complex configuration- Requires choosing appropriate exp_lambda- Batch sizes may change between epochs |
| MiniEpochSampler | You have a very large dataset | - Enables more frequent evaluation- Useful for extremely large datasets- Can be combined with other sampling strategies | - Not specifically designed for class imbalance- Introduces mini-epochs concept that affects training |
| DistributedSamplerWrapper | You need custom samplers in distributed training | - Enables distributed training with any sampler- Maintains sampling strategy across processes- Integrates with PyTorch's distributed training | - Adds complexity to training setup- Requires proper distributed configuration |
