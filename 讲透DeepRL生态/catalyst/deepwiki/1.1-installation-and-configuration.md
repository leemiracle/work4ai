## Core Dependencies

 Catalyst requires the following core dependencies:

 
| Dependency | Purpose | Minimum Version |
|---|---|---|
| PyTorch | Deep learning framework | 1.4.0 |
| NumPy | Numerical computing | 1.18 |
| hydra-slayer | Registry system | 0.4.0 |
| tqdm | Progress bars | 4.33.0 |
| accelerate | Hardware backend abstraction | 0.5.1 |
| TensorboardX | Experiment logging | 2.1.0 |

 Catalyst officially supports Python 3.7 to 3.10.

 - User configuration file (`~/.catalyst` on Linux/Mac, `~/.catalyst` in user's home directory on Windows)

### Environment Variables

 You can configure Catalyst with environment variables:

 
| Variable | Description | Default |
|---|---|---|
| CATALYST_USE_LZ4 | Enable LZ4 compression | 0 |
| CATALYST_USE_PYARROW | Enable PyArrow for data handling | 0 |
| CATALYST_USE_LIBJPEG_TURBO | Use libjpeg-turbo for image processing | 0 |
| CATALYST_LOG_BATCH_METRICS | Log metrics for every batch | 0 |
| CATALYST_LOG_EPOCH_METRICS | Log metrics for every epoch | 1 |
| CATALYST_COMPUTE_PER_CLASS_METRICS | Compute per-class metrics | 0 |

 Sources: [catalyst/settings.py323-340](https://github.com/catalyst-team/catalyst/blob/e99f9065/catalyst/settings.py#L323-L340)
