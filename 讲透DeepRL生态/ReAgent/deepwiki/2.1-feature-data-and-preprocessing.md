## Feature Data Representation

 ReAgent uses well-defined data structures to represent features across the entire system. The central class for this purpose is `FeatureData`, which can store various types of features.

 
### FeatureData Class

 The `FeatureData` class is the primary container for feature data used throughout ReAgent. It supports multiple feature types:

 
```

```

 Sources: [reagent/core/types.py313-388](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/core/types.py#L313-L388)

 The `FeatureData` class contains:

 
 - **Dense Features** (`float_features`): A 2D tensor with shape (batch_size, feature_dim)
 - **Sparse Features**: Represented in two formats: 
 - KeyedJaggedTensor format: `id_list_features` and `id_score_list_features`
 - Dictionary format: `id_list_features_raw` and `id_score_list_features_raw`
 - **Sequence Features** (`stacked_float_features`): 3D tensor with shape (stack_size, batch_size, feature_dim)
 - **Document Features** (`candidate_docs`): For ranking algorithms
 - **Time Features** (`time_since_first`): For capturing temporal aspects
 
 
### Feature Types

 ReAgent supports various feature types to accommodate different use cases:

 
| Feature Type | Description | Storage Format |
|---|---|---|
| Dense Features | Continuous numerical features | 2D tensor (batch_size, feature_dim) |
| ID List Features | Categorical features without weights | KeyedJaggedTensor or (offsets, values) tuple |
| ID Score List Features | Categorical features with weights | KeyedJaggedTensor or (offsets, values, weights) tuple |
| Sequence Features | Time-series or sequential data | 3D tensor (sequence_length, batch_size, feature_dim) |
| Document Features | Features for ranking/recommendation | DocList structure |

### Key Transformation Types

 ReAgent provides various transformation types for different feature processing needs:

 
| Transformation | Purpose |
|---|---|
| ValuePresence | Combines value and presence tensors |
| DenseNormalization | Normalizes dense features using normalization parameters |
| IDListFeatures | Processes ID list features into KeyedJaggedTensor format |
| IDScoreListFeatures | Processes ID score list features into KeyedJaggedTensor format |
| OneHotActions | Converts action indices to one-hot encoded vectors |
| ColumnVector | Ensures features are column vectors |
| FixedLengthSequences | Processes fixed-length sequence features |
| SlateView | Reshapes flattened sequences for slate-based models |

## Summary

 ReAgent provides a flexible and powerful feature processing system that supports various types of features and models. Key components include:

 
 - **Feature Data Structures**: Well-defined data structures like `FeatureData` and `ValuePresence`
 - **Feature Types**: Support for dense, sparse (ID list, ID score list), sequence, and specialized features
 - **Preprocessing Transformations**: Composable transformations for feature normalization, encoding, and preprocessing
 - **Embedding Support**: Integration with TorchRec for efficient handling of sparse features
 - **Model Integration**: Specialized feature processing for different model architectures
 
 This feature processing system enables ReAgent to handle a wide range of reinforcement learning tasks and domain-specific applications.
