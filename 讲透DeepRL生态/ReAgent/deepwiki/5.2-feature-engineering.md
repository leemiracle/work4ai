  This document describes the feature engineering subsystem in ReAgent, which is responsible for transforming raw input data into a format suitable for training and serving reinforcement learning models. Feature engineering in ReAgent includes feature type identification, normalization, transformation, and handling of various feature types including dense, sparse, and sequence features.

 For information about the broader data preprocessing pipeline, see [Timeline Processing](https://deepwiki.com/facebookresearch/ReAgent/5.1-timeline-processing).

 
## Overview

 Feature engineering is a critical component in the ReAgent pipeline that bridges raw data and model inputs. It ensures that features are correctly formatted, normalized, and transformed to optimize model performance.

### Feature Type Definitions

 ReAgent classifies features into the following main categories:

 
 - **Dense Features (float_features)**: Continuous numerical features represented as tensors with shape `(batch_size, feature_dim)`.
 - **ID List Features**: Sparse features represented as a list of IDs (e.g., item IDs viewed by a user).
 - **ID Score List Features**: Sparse features with associated scores (e.g., item IDs and corresponding interaction scores).
 - **Sequence Features**: Time-ordered sequences of features, which can be either fixed-length or variable-length.
 - **Candidate Features**: Features used in slate recommendation scenarios, representing candidate items.
 
 Sources: [reagent/core/types.py111-232](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/core/types.py#L111-L232)

### Configuration Parameters

 Normalization parameters include:

 
 - **max_unique_enum_values**: Maximum number of unique values for categorical features
 - **quantile_size**: Size of quantiles for quantile normalization
 - **quantile_k2_threshold**: Threshold for quantile normalization
 - **skip_box_cox**: Whether to skip Box-Cox transformation
 - **skip_quantiles**: Whether to skip quantile normalization
 - **feature_overrides**: Manual overrides for specific features

## Feature Transformation

 ReAgent provides a rich set of transformation primitives to manipulate feature data for different model architectures and training regimes.

 
### Key Transformation Types

 
 - **Compose**: Chain multiple transformations together
 - **ValuePresence**: Handle feature presence information
 - **Lambda**: Apply custom transformations
 - **OneHotActions**: One-hot encode discrete actions
 - **StackDenseFixedSizeArray**: Stack fixed-size arrays
 - **FixedLengthSequences/VarLengthSequences**: Handle sequence data

## Summary

 Feature engineering in ReAgent is a comprehensive system that handles various types of features and provides flexible transformations for preparing data for reinforcement learning models. The system supports dense features, sparse features, sequence features, and provides robust normalization and transformation capabilities.

 Understanding this feature engineering pipeline is essential for effectively using ReAgent, as it forms the bridge between raw data and model inputs, directly impacting model performance and training efficiency.
