## Purpose and Scope

 Agents and policies in ReAgent provide a standardized way to:

 
 - Convert environment observations into actions through policies
 - Record transitions for training
 - Execute trained models in environments
 - Evaluate model performance in simulation environments

## Agent Architecture

 The `Agent` class in ReAgent is responsible for orchestrating the interactions between policies and environments. It processes observations from the environment, uses a policy to select actions, and manages the recording of transitions.

 
### Core Components

 An agent consists of:

 
 - **Policy**: Determines actions based on observations
 - **Observation Preprocessor**: Transforms raw environment observations into a format suitable for the policy
 - **Action Extractor**: Converts policy outputs to environment-compatible actions
 - **Post-transition Callback**: Optional function called after each step
 - **Post-episode Callback**: Optional function called after each episode

### Policy Types

 ReAgent provides several built-in policy types:

 
| Policy Type | Description | Use Case |
|---|---|---|
| DiscreteRandomPolicy | Selects random actions from a discrete action space | Initial exploration, baseline comparison |
| MultiDiscreteRandomPolicy | Handles multiple discrete action spaces | Multi-dimensional discrete control |
| ContinuousRandomPolicy | Samples from a uniform distribution | Continuous control exploration |
| DiscreteDQNPredictorPolicy | Uses a Q-network for scoring with configurable sampling | Trained discrete action policies |
| ActorPredictorPolicy | Uses an actor network for direct action output | Trained continuous action policies |

### Discrete Action Samplers

 ReAgent provides three primary samplers for discrete action spaces:

 
 - **SoftmaxActionSampler**: Uses softmax to sample actions based on their relative scores
 - **GreedyActionSampler**: Always selects the highest scoring action
 - **EpsilonGreedyActionSampler**: Selects random actions with probability ε, otherwise greedy
 
 Each returns an `ActorOutput` containing both the action and its log probability.

## Summary

 The agent and policy framework in ReAgent provides a flexible system for interacting with environments using reinforcement learning models:

 
 - **Agents** orchestrate interactions between policies and environments
 - **Policies** compose scorers and samplers to determine actions
 - **Scorers** convert observations to action scores using models
 - **Samplers** implement exploration strategies to select actions
 
 This modular design enables:

 
 - Easy switching between different exploration strategies
 - Integration with both training and serving models
 - Clean separation of model logic from interaction logic
 - Support for diverse environment types and action spaces
