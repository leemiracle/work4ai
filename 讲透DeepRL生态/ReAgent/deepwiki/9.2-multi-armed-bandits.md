## Introduction

 Multi-Armed Bandits are a class of reinforcement learning algorithms that address the exploration-exploitation dilemma. The name comes from slot machines (one-armed bandits) - imagine facing multiple slot machines with different unknown reward probabilities, and needing to decide which to play to maximize your total reward.

 ReAgent implements:

 
 - **Standard Multi-Armed Bandits**: Where rewards depend only on the chosen arm
 - **Contextual Bandits**: Where rewards depend on both the chosen arm and the current context (features)
 
 These algorithms can be used for applications including personalization, recommendation systems, online advertising, and dynamic content optimization.

### UCB Algorithms

 Upper Confidence Bound (UCB) algorithms balance exploration and exploitation by selecting arms based on an optimistic estimate of their potential reward.

 
#### UCB1

 The classic UCB algorithm computes scores as:

 
```
UCB_i = AVG([rewards_i]) + SQRT(2*LN(T)/N_i)
```

 Where:

 
 - `AVG([rewards_i])` is the average reward for arm i
 - `T` is the total number of observations across all arms
 - `N_i` is the number of times arm i has been observed
 
 Implementation:

 
```
def get_scores(self) -> Tensor:
    avg_rewards = self.get_avg_reward_values()
    log_t_over_ni = (
        math.log(self.total_n_obs_all_arms + 1) / self.total_n_obs_per_arm
    )
    return avg_rewards + self.alpha * torch.sqrt(2 * log_t_over_ni)
```

 
#### MetricUCB

 An improvement over UCB1 with a more precise confidence radius:

 
```
UCB_i = AVG([rewards_i]) + SQRT(AVG([rewards_i]) * LN(T+1)/N_i) + LN(T+1)/N_i
```

 
#### UCBTuned

 A variant that estimates per-arm reward variance:

 
```
UCB_i = AVG([rewards_i]) + SQRT(LN(T)/N_i * min(V_i, 0.25))
```

 Where `V_i` is a conservative variance estimate for arm i.

## Summary

 ReAgent provides a comprehensive suite of multi-armed bandit algorithms:

 
 - **Standard MABs**:

 
 - UCB algorithms (UCB1, MetricUCB, UCBTuned)
 - Thompson Sampling (BernoulliBetaThompson, NormalGammaThompson)
 - Simulation and evaluation tools
 - **Contextual Bandits**:

 
 - LinearRegressionUCB (LinUCB)
 - DeepRepresentLinearRegressionUCB (Deep + LinUCB)
 - CBFullyConnectedNetwork (point predictions)
 - Training framework with offline evaluation
 
 These implementations enable efficient exploration-exploitation trade-offs in a variety of reinforcement learning scenarios, from simple action selection to complex contextual decision-making.
