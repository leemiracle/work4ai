## High-Level System Overview

 ReAgent is designed as a modular reinforcement learning platform that separates concerns between data handling, model definition, training, and serving. The platform supports various RL algorithms and provides standardized workflows for training, evaluation, and deployment.

## Core Data Structures

 At the heart of ReAgent are standardized data structures that represent reinforcement learning concepts uniformly across different algorithms and use cases.

 
### TensorDataClass and Feature Representation

 The `TensorDataClass` serves as the base class for most data structures in ReAgent, providing tensor operations that propagate through nested structures.

 
```

```

 FeatureData is the fundamental representation for state and action features, supporting:

 
 - Dense features via `float_features`
 - Sparse features via `id_list_features` and `id_score_list_features`
 - Sequential features via `stacked_float_features`
 - Ranking candidates via `candidate_docs`
 
 Algorithm-specific inputs inherit from BaseInput, adding specialized fields required by different RL approaches.

## Model Managers

 Model Managers are the orchestration layer responsible for coordinating the entire training and serving lifecycle.


 Model Managers implement a consistent interface that:

 
 - Creates appropriate trainers for specific algorithms
 - Provides data module implementations for data handling
 - Builds serving modules for deployment
 - Sets up evaluation and reporting
 
 This standardized interface allows for uniform training workflows across different algorithms.

## Training System

 ReAgent's training system is built on PyTorch Lightning for scalable, standardized training loops.

 
```

```

 - Identifies feature types and normalization parameters
 - Preprocesses raw data into standardized formats
 - Constructs appropriate trainer modules based on algorithm
 - Executes training and evaluation loops
 - Converts trained models into TorchScript for deployment

## Summary

 ReAgent's architecture provides a comprehensive platform for RL research and production:

 
 - **Modular Design**: Separates concerns between data processing, modeling, training, and serving
 - **Standardized Interfaces**: Common interfaces for different algorithm families
 - **Rich Data Processing**: Handles diverse feature types and formats
 - **Production-Ready**: TorchScript export and deployment mechanisms
 - **Algorithm Diversity**: Supports a wide range of RL algorithms from DQN to recommendations
 
 This architecture enables both research flexibility and production stability, allowing for easy experimentation while maintaining a path to deployment.
