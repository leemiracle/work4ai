  This page documents the combinatorial optimization algorithms available in ReAgent. These optimizers are designed to solve discrete search problems where the goal is to find the optimal combination of choices from a finite set of options. This is particularly useful for hyperparameter optimization, neural architecture search, and other discrete optimization problems in reinforcement learning.

 For information about Multi-Armed Bandits, see [Multi-Armed Bandits](https://deepwiki.com/facebookresearch/ReAgent/9.2-multi-armed-bandits).

 
## Overview

 The combinatorial optimizers in ReAgent provide algorithms for efficiently searching through discrete parameter spaces. They are implemented in the `reagent/lite` module and follow a common interface that allows for easy experimentation with different optimization strategies.

### Key Methods

 
| Method | Description |
|---|---|
| optimize_step() | Main method for optimization that encapsulates sampling and updating parameters |
| sample_internal() | Samples promising solutions to query during training |
| update_params() | Updates optimizer parameters using rewards from sampled solutions |
| sample() | Samples solutions based on the learned optimizer (used after training) |
| best_solutions() | Returns the top best solutions discovered during training |

## Comparison of Optimizers

 Different optimizers are suited for different scenarios:

 
| Optimizer | Best For | Pros | Cons |
|---|---|---|---|
| RandomSearch | Simple problems, baselines | Simple, parallelizable | Inefficient for large search spaces |
| NeverGrad | Complex spaces with structure | Leverages specialized algorithms | Requires parameter tuning |
| GumbelSoftmax | Differentiable objectives | Can exploit gradient information | Requires differentiable objective |
| PolicyGradient | Black-box optimization | Good sample efficiency | Sensitive to learning rates |
| QLearning | Sequential decisions | Handles dependencies between choices | Higher computational complexity |
