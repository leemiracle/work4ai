  This page documents the Deep Q-Network (DQN) implementation and its variants in ReAgent. DQN is a value-based reinforcement learning algorithm that uses neural networks to approximate Q-values (action-value functions). This page covers the core DQN implementation as well as several advanced variants including Double DQN, Dueling DQN, Quantile Regression DQN (QR-DQN), Categorical DQN (C51), and Critic Regularized Regression (CRR).

 For actor-critic methods like SAC and TD3, see [Actor-Critic Methods](https://deepwiki.com/facebookresearch/ReAgent/3.2-actor-critic-methods).

## Core DQN Implementation

 
### DQN Base Class

 `DQNTrainerBaseLightning` serves as the foundation for all DQN variants. It inherits from `RLTrainerMixin` and `ReAgentLightningModule`, leveraging PyTorch Lightning for training workflow management. The base class provides:

 
 - Methods for Q-value calculation
 - Reward normalization and boosting
 - Counterfactual Policy Evaluation (CPE) integration
 - Validation logic

### Standard DQN Trainer

 The `DQNTrainer` class implements the standard DQN algorithm with the following features:

 
 - Uses a neural network (Q-network) to predict Q-values for state-action pairs
 - Maintains a target network for stable training
 - Supports double Q-learning to reduce overestimation bias
 - Provides batch-constrained Q-learning support for offline RL
 
 Key parameters:

 
 - `double_q_learning`: Whether to use double Q-learning (default: True)
 - `bcq`: Configuration for batch-constrained Q-learning (optional)
 - `minibatch_size`: Number of samples per minibatch
 - `minibatches_per_step`: Number of minibatch updates per step
 
 Sources: [reagent/training/dqn_trainer.py28-381](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/training/dqn_trainer.py#L28-L381)

## DQN Variants

 
### Double DQN

 Double DQN addresses the overestimation bias in standard Q-learning by decoupling action selection and evaluation. It uses the online network to select actions and the target network to evaluate them.

 
```

```

 Sources: [reagent/training/dqn_trainer_base.py66-78](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/training/dqn_trainer_base.py#L66-L78) [reagent/training/dqn_trainer.py68](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/training/dqn_trainer.py#L68-L68)

 
### Dueling DQN

 Dueling DQN separates the estimation of state values and action advantages, allowing for better policy evaluation when actions don't affect the environment in some states.

 
```

```

 The architecture contains:

 
 - A shared feature network
 - A value stream that estimates the state value function V(s)
 - An advantage stream that estimates the advantages for each action A(s,a)
 - The final Q-values are computed as: Q(s,a) = V(s) + (A(s,a) - mean(A(s,:)))
 
 Sources: [reagent/models/dueling_q_network.py21-348](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/models/dueling_q_network.py#L21-L348)

 
### Quantile Regression DQN (QR-DQN)

 QR-DQN is a distributional RL approach that models the distribution of returns through quantile regression. Instead of learning expected Q-values, it learns to predict a set of quantiles of the return distribution.

 
```

```

 Key components:

 
 - Divides the cumulative probability space into `num_atoms` equal parts
 - Each quantile represents a specific percentile of the return distribution
 - Uses the Huber loss for quantile regression
 - Maintains the double Q-learning feature from standard DQN
 
 Sources: [reagent/training/qrdqn_trainer.py22-228](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/training/qrdqn_trainer.py#L22-L228)

 
### Categorical DQN (C51)

 C51 models the return distribution as a categorical distribution with a fixed number of support atoms. The algorithm updates the entire distribution rather than just the expected value.

 Key features:

 
 - Uses `num_atoms` (typically 51) to represent the discretized return distribution
 - Defines a minimum and maximum return value (`qmin` and `qmax`)
 - Applies the distributional Bellman operator with categorical projection


### Critic Regularized Regression (CRR)

 CRR is an offline RL algorithm that uses a critic to regularize policy updates, keeping the policy close to the behavior policy while still improving performance.

 
```

```

 Key parameters:

 
 - `beta`: Coefficient for KL-divergence policy constraint (higher values keep policy closer to behavior policy)
 - `entropy_coeff`: Coefficient for entropy regularization
 - `clip_limit`: Threshold for importance sampling
 - `max_weight`: Maximum possible action weight in the actor loss
 
 CRR integrates both actor and critic training in a unified framework.

## Evaluation and Metrics

 DQN models in ReAgent are evaluated using Counterfactual Policy Evaluation (CPE), which estimates performance metrics for a policy using data collected from a different policy.

 The `EvaluationDataPage` class computes various metrics:

 
 - Model propensities (action probabilities)
 - Model rewards (predicted rewards)
 - Logged values and logged metrics
 - Q-values for all possible actions
 
 This data is used to calculate:

 
 - Direct Method estimates
 - Inverse Propensity Scoring estimates
 - Doubly-Robust estimates
 - Sequential Doubly-Robust estimates
 
 Sources: [reagent/evaluation/evaluation_data_page.py30-649](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/evaluation/evaluation_data_page.py#L30-L649)

## Summary Table of DQN Variants

 
| Algorithm | Key Feature | Class | Best For |
|---|---|---|---|
| DQN | Base Q-learning with neural networks | DQNTrainer | General discrete action spaces |
| Double DQN | Reduces overestimation bias | Enabled in DQNTrainer | More accurate value estimation |
| Dueling DQN | Separates state value and action advantage | DuelingQNetwork | Problems where some actions don't affect certain states |
| QR-DQN | Models return distribution with quantile regression | QRDQNTrainer | Better handling of risk and uncertainty |
| C51 | Models return distribution with categorical distribution | C51Trainer | Better performance on complex tasks |
| CRR | Constrains policy updates with a critic | DiscreteCRRTrainer | Offline RL from fixed datasets |
