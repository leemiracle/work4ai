## Purpose and Scope

 This document describes the integration of OpenAI Gym environments with the ReAgent reinforcement learning framework. OpenAI Gym provides standardized environments for developing and comparing reinforcement learning algorithms, and ReAgent's Gym integration enables seamless training, evaluation, and deployment of RL algorithms across these environments.

 For information about agents and policy implementations used with Gym environments, see [Agents and Policies](https://deepwiki.com/facebookresearch/ReAgent/6.1-agents-and-policies).

## Training Modes

 ReAgent supports two main training modes with Gym environments:

 
### Replay Buffer-Based Training

 In this mode, transitions from environment interactions are stored in a replay buffer and then used for training. This approach is commonly used for off-policy algorithms like DQN, SAC, and TD3.

 
```

```

 Sources: [reagent/gym/tests/test_gym.py183-272](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/gym/tests/test_gym.py#L183-L272) [reagent/gym/tests/test_gym_offline.py91-152](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/gym/tests/test_gym_offline.py#L91-L152)

 
### Episode-Based Training

 In this mode, the agent collects complete episodes, and training is performed on the entire trajectory. This approach is commonly used for on-policy algorithms like PPO and REINFORCE.

## Environment Wrappers

 Environment wrappers provide a standardized interface between Gym environments and ReAgent components, handling necessary conversions and normalizations.

 
### Key Components

 
 - **EnvWrapper**: Base wrapper for Gym environments
 - **Gym**: A specific implementation for standard Gym environments
 - **StateEmbedEnvironment**: A specialized wrapper that embeds raw observations using a world model

## Data Preprocessing

 ReAgent provides preprocessors that convert Gym observation and action data into the appropriate format for different trainer types.

 
```

```

 Each preprocessor converts raw Gym data into the specific input format required by different trainer types:

 
| Preprocessor | Output Type | Use Case |
|---|---|---|
| DiscreteDqnInputMaker | DiscreteDqnInput | Discrete action DQN variants |
| PolicyNetworkInputMaker | PolicyNetworkInput | Actor-critic methods (SAC, TD3) |
| SlateQInputMaker | SlateQInput | Slate recommendation |
| MemoryNetworkInputMaker | MemoryNetworkInput | Recurrent models like MDNRNN |
| ParametricDqnInputMaker | ParametricDqnInput | Parametric DQN |
| PolicyGradientInputMaker | PolicyGradientInput | Policy gradient methods (PPO, REINFORCE) |

## Supported Algorithms and Environments

 ReAgent's Gym integration supports a wide range of reinforcement learning algorithms and environments:

 
### Algorithms

 
 - DQN and variants (Discrete DQN, Parametric DQN, C51, QR-DQN, CRR)
 - Actor-critic methods (SAC, TD3)
 - Policy gradient methods (PPO, REINFORCE)
 - Slate recommendation (SlateQ)
 - World models (MDNRNN, CEM)
 
 
### Environments

 
 - Classic control (Cartpole, Pendulum)
 - Grid worlds
 - Recommendation simulators (RecSim)
 - Any standard Gym-compliant environment

## World Model Integration

 ReAgent's Gym integration includes support for world models, which can learn to predict environment dynamics and can be used for planning or representation learning.

 
```

```

 The world model integration enables:

 
 - Training a world model (like MDNRNN) to predict environment dynamics
 - Using the world model to create state embeddings
 - Training an RL agent using these embedded states
 - Evaluating feature importance and sensitivity
