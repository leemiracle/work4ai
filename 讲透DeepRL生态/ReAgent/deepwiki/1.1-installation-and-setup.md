  This document provides instructions for installing and configuring ReAgent, an open-source platform for training and evaluating reinforcement learning policies. The guide covers installation of all main components, including the Python API, Spark preprocessing tools, and optional components. For information about actually using ReAgent after installation, see [ReAgent Overview](https://deepwiki.com/facebookresearch/ReAgent/1-reagent-overview).

### Hardware Requirements

 
 - **CPU-only usage**: Any modern CPU with at least 8GB RAM
 - **GPU acceleration**: NVIDIA GPU with CUDA support compatible with PyTorch

## Troubleshooting

 
### Common Issues

 Here are some common issues and their solutions:

 
 - **Protobuf version conflicts**: If you encounter errors related to descriptors not being created directly, you might have a protobuf version conflict. This is why `grpcio-tools` is pinned to a specific version range in the package configuration.
 - **PyTorch CUDA version mismatch**: Ensure the installed PyTorch version matches your CUDA version. You can check your CUDA version with `nvidia-smi`.
 - **Spark-related errors**: When running Spark locally, you might encounter errors related to the Spark warehouse. You can clear the Spark warehouse by running:

 
```

```
 - **Python version issues**: ReAgent requires Python 3.8+. If you have multiple Python versions, ensure you're using the correct one.
 - **TorchRec installation issues**: TorchRec can sometimes be problematic to install. Try using the nightly build with the `--pre` flag if you encounter issues.
