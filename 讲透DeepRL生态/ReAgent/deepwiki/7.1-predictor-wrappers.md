## Purpose

 Predictor Wrappers in ReAgent provide a standardized interface for deploying trained reinforcement learning models to production environments. They encapsulate the preprocessing, model inference, and postprocessing steps into a single deployable unit that can be optimized using TorchScript for efficient serving. Predictor Wrappers bridge the gap between ReAgent's training infrastructure and model serving environments.

 For information about training models, see [Training System](https://deepwiki.com/facebookresearch/ReAgent/4-training-system) and for general model deployment, see [Model Serving](https://deepwiki.com/facebookresearch/ReAgent/7-model-serving).

## Overview

 
```

```

 Predictor Wrappers are TorchScript-compatible modules that bundle:

 
 - A trained model
 - Necessary preprocessors to transform raw input features
 - Optional postprocessors to format model outputs
 - Logic to convert between serving data structures and model-compatible formats
 
 All predictor wrappers follow a pattern where a model is first combined with preprocessors in a "*WithPreprocessor" class (e.g., `DiscreteDqnWithPreprocessor`), which is then wrapped in a TorchScript-compatible predictor wrapper (e.g., `DiscreteDqnPredictorWrapper`).

## Core Concepts

 
### ServingFeatureData

 The `ServingFeatureData` structure is the standard input format for predictor wrappers, consisting of:

 
 - Float features with presence indicators
 - ID list features
 - ID score list features
 
 This format allows for handling both dense and sparse features in a unified way.

### Wrapper Architecture

 
```

```

 Each Predictor Wrapper follows this pattern:

 
 - A base model that implements the core ML logic
 - A preprocessor that transforms raw features into model inputs
 - A "*WithPreprocessor" class that combines the model and preprocessor
 - A final Predictor Wrapper that provides the TorchScript-compatible interface

## Predictor Wrapper Types

 ReAgent provides specialized predictor wrappers for different model architectures:

 
| Wrapper Type | Description | Primary Use Case |
|---|---|---|
| DiscreteDqnPredictorWrapper | Wrapper for discrete action DQN models | Q-value prediction for discrete action spaces |
| ParametricDqnPredictorWrapper | Wrapper for parametric action DQN models | Q-value prediction for continuous/parametric action spaces |
| ActorPredictorWrapper | Wrapper for actor models | Policy networks, especially for continuous action spaces |
| RankingActorPredictorWrapper | Wrapper for ranking actor models | Ranking candidates from a set of options |
| Seq2SlatePredictorWrapper | Wrapper for sequence-to-slate models | Generating ordered slates (e.g., recommendations) |
| BinaryDifferenceScorerPredictorWrapper | Wrapper for binary difference scorers | Binary classification with probability output |

## Summary

 Predictor Wrappers are a key component in ReAgent's serving infrastructure, providing a standardized way to deploy trained models. They handle the complexity of preprocessing inputs and formatting outputs, making it easier to move models from training to production. By supporting TorchScript optimization, they also enable efficient model deployment in various serving environments.

 The design follows a consistent pattern across different model types, with specialized wrappers for different reinforcement learning algorithms while maintaining a common interface.
