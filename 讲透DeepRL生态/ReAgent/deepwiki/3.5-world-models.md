  World Models in ReAgent are components that learn to predict future outcomes based on current states and action sequences. They enable planning and evaluation without direct environment interaction, allowing for more efficient reinforcement learning. This document focuses on the Seq2Reward implementation, which is the primary world model approach in ReAgent.

 For information about other model types in ReAgent, see [Models and Algorithms](https://deepwiki.com/facebookresearch/ReAgent/3-models-and-algorithms) or [Ranking and Recommendation](https://deepwiki.com/facebookresearch/ReAgent/3.4-ranking-and-recommendation).

 
## 1. Overview of World Models

 World models serve several critical functions in reinforcement learning:

 
 - **Planning**: They simulate future trajectories to evaluate potential action sequences
 - **Sample Efficiency**: They reduce the need for real environment interactions
 - **Policy Improvement**: They enable value estimation for better action selection
 
 In ReAgent, the primary world model implementation is Seq2Reward, which predicts the accumulated reward for sequences of states and actions.

## 2. Seq2Reward Model Architecture

 Seq2Reward is a sequence-to-scalar model that maps sequences of states and actions to accumulated rewards. This enables the model to predict the expected return for any given action sequence from a particular state.

 
```

```

 Sources: [reagent/training/world_model/seq2reward_trainer.py21-28](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/training/world_model/seq2reward_trainer.py#L21-L28) [reagent/models/seq2reward_model.py](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/models/seq2reward_model.py)

 The Seq2Reward model includes two main components:

 
 - **Seq2RewardNetwork**: Predicts accumulated rewards for state-action sequences
 - **Step Prediction Network**: A fully connected network that predicts how many steps remain in the sequence
 
 The step prediction component enhances planning by allowing the model to work with variable-length sequences.

## 5. Model Compression for Efficiency

 While Seq2Reward models are powerful for planning, they can be computationally expensive. The `CompressModelTrainer` provides a way to distill knowledge from a Seq2Reward model into a simpler network for faster inference.

 
```

```

 Sources: [reagent/training/world_model/compress_model_trainer.py23-124](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/training/world_model/compress_model_trainer.py#L23-L124)

 The compression process works as follows:

 
 - The `CompressModelTrainer` takes a trained Seq2Reward model and a simpler network (typically fully connected)
 - For each state, it computes target Q-values using the full planning process with Seq2Reward
 - It trains the compressed model to output the same Q-values directly, without planning:

 
 The compressed model provides similar decision-making capabilities with much faster inference time, making it suitable for real-time applications.

 
## 6. Integration with ReAgent Framework

 World models integrate with the broader ReAgent framework to provide end-to-end reinforcement learning solutions.

 
```

```

 Sources: [reagent/test/world_model/test_seq2reward.py334-473](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/test/world_model/test_seq2reward.py#L334-L473) [reagent/prediction/predictor_wrapper.py](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/prediction/predictor_wrapper.py) [reagent/net_builder/value/seq2reward_rnn.py](https://github.com/facebookresearch/ReAgent/blob/9e707c09/reagent/net_builder/value/seq2reward_rnn.py)

 Key integration points include:

 
 - **Model Building**: The `Seq2RewardNetBuilder` provides a standardized way to construct Seq2Reward models
 - **Serving**: Two predictor wrappers facilitate model serving: 
 - `Seq2RewardWithPreprocessor`: Uses full sequence planning
 - `Seq2RewardPlanShortSeqWithPreprocessor`: Uses variable-length sequence planning
 - **Evaluation**: Models can be evaluated offline using standard ReAgent evaluation metrics
 - **Testing**: The `TestSeq2Reward` class provides testing utilities, including a string game environment for validation

## Summary

 World Models in ReAgent, particularly the Seq2Reward implementation, provide a powerful approach for planning and policy improvement. By learning to predict accumulated rewards for action sequences, they enable agents to evaluate potential actions without additional environment interaction. The combination of sequence modeling, planning algorithms, and model compression techniques makes world models a flexible and efficient component in the ReAgent reinforcement learning framework.
