  This page documents the ranking and recommendation algorithms and training methodologies in ReAgent. These components focus on optimizing ordered lists (slates) of items, which is common in recommendation systems, search results, and feed ranking applications. For related world model approaches used in recommendation, see [World Models](https://deepwiki.com/facebookresearch/ReAgent/3.5-world-models).

## 2. Seq2Slate Architecture

 Seq2Slate is a sequence-to-sequence transformer architecture that takes a set of candidate items and a context state, and produces an ordered slate of selected items.

 
```

```

 The Seq2Slate architecture supports multiple operational modes:

 
 - `RANK_MODE`: Produces a ranked slate of items
 - `PER_SEQ_LOG_PROB_MODE`: Computes log probability of a sequence
 - `ENCODER_SCORE_MODE`: Scores individual items without ranking
 - `PER_SYMBOL_LOG_PROB_DIST_MODE`: Generates log probability distributions for each position

## 3. Training Methodologies

 ReAgent provides several training approaches for ranking models:

 
### 3.1 Standard Reinforcement Learning Training

 The base `Seq2SlateTrainer` implements REINFORCE-based training with importance sampling to learn from logged data.

 
```

```

 The trainer:

 
 - Computes model propensities (probabilities) for selecting slates
 - Applies importance sampling to correct for off-policy learning
 - Updates parameters using policy gradient methods

### 3.2 Simulation-Based Training

 `Seq2SlateSimulationTrainer` extends the base trainer by using a reward model to simulate rewards for newly generated slates, enabling exploration of the slate space without collecting new data.

## 4. Reward Modeling

 Reward modeling is critical for reinforcement learning and simulation-based training in ranking systems.

 
### 4.1 Reward Network Architecture

 ReAgent provides two main reward network architectures:

 
 - **GRU-based Reward Network** (`Seq2SlateGRURewardNet`):

 
 - Uses recurrent GRU layers to process slate sequences
 - Computes attention weights over sequence elements
 - Concatenates hidden state and context vector for reward prediction
 - **Transformer-based Reward Network** (`Seq2SlateTransformerRewardNet`):

 
 - Uses transformer architecture for both encoding and decoding
 - Processes entire slates with self-attention mechanisms
 - Uses final decoder state to predict reward

## 5. Evaluation

 Evaluation of ranking and recommendation models uses both offline and online metrics.

 
### 5.1 Offline Evaluation Metrics

 
```

```

 The evaluation framework includes:

 
 - **Counterfactual Policy Evaluation (CPE)**:

 
 - Direct Method (DM): Uses the reward model to estimate rewards
 - Inverse Propensity Scoring (IPS): Weighs observed rewards by propensity ratios
 - Doubly Robust (DR): Combines DM and IPS for lower variance estimates
 - Switch Estimator: Adaptively selects between different estimators
 - **Ranking-specific metrics**:

 
 - DCG/NDCG: Measure ranking quality with position discounting
 - Mean Average Precision: Evaluates precision at different recall levels
 - AUC: Area under ROC curve for binary relevance
