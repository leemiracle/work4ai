  This document explains the implementation of Contextual Bandit algorithms in ReAgent, focusing on the models, trainers, and utilities that support this approach to sequential decision-making under uncertainty. Contextual Bandits represent an important class of reinforcement learning methods that balance exploration and exploitation based on observed contexts, making them valuable for recommendation systems, online advertising, and similar applications.

 
## Overview

 Contextual Bandits in ReAgent offer a framework for learning policies that make optimal decisions when provided with contextual information. Unlike full Reinforcement Learning (covered in [DQN and Variants](https://deepwiki.com/facebookresearch/ReAgent/3.1-dqn-and-variants) and [Actor-Critic Methods](https://deepwiki.com/facebookresearch/ReAgent/3.2-actor-critic-methods)), contextual bandits don't model full state transitions or delayed rewards, focusing instead on immediate reward maximization given context.

## Model Architecture

 
### Base UCB Model

 All contextual bandit models in ReAgent inherit from the `UCBBaseModel` abstract base class, which defines a common interface for UCB-style (Upper Confidence Bound) bandit algorithms:

 
```

```

 Key outputs from all UCB models include:

 
 - `pred_label`: The predicted reward value
 - `pred_sigma`: The uncertainty estimate
 - `ucb`: The upper confidence bound value, calculated as `pred_label + ucb_alpha * pred_sigma`

### LinearRegressionUCB

 The `LinearRegressionUCB` class implements the LinUCB algorithm, which uses ridge regression to estimate rewards and associated uncertainty:

 
```

```

 The model maintains several key state matrices:

 
 - `avg_A`: The weighted average of X^T*X across all data
 - `avg_b`: The weighted average of label*X across all data
 - `inv_avg_A`: The inverse of the (regularized) A matrix
 - `_coefs`: The regression coefficients (θ)
 
 To avoid redundant computation of matrix inversions, the model computes coefficients only when necessary and keeps track of whether they're up to date with the current data.

### DisjointLinearRegressionUCB

 The `DisjointLinearRegressionUCB` class implements a variant of LinUCB where each arm has its own separate model parameters:

 
```

```

 Unlike the standard LinearRegressionUCB which shares parameters across arms, this model maintains:

 
 - Separate A matrices for each arm: `A` of shape (num_arms, input_dim, input_dim)
 - Separate b vectors for each arm: `b` of shape (num_arms, input_dim)
 - Separate coefficient vectors: `coefs` of shape (num_arms, input_dim)
 
 This allows for more specialized models per arm but requires more data to learn effectively.

## Mathematical Foundations

 
### Upper Confidence Bound (UCB)

 The UCB principle balances exploration and exploitation by choosing actions with the highest upper confidence bound:

 UCB = μ + α × σ

 Where:

 
 - μ is the expected reward
 - σ is the uncertainty estimate
 - α is a parameter controlling the exploration-exploitation trade-off
 
 
### LinUCB Algorithm

 In LinUCB, the reward model is linear: r = x^T θ + ε

 For each context x, the algorithm maintains:

 
 - A = X^T X + λI (regularized gram matrix)
 - b = X^T r (response vector)
 - θ = A^(-1) b (regression coefficients)
 
 The prediction and uncertainty are:

 
 - μ(x) = x^T θ (expected reward)
 - σ(x) = √(x^T A^(-1) x) (standard deviation)
 - UCB(x) = μ(x) + α × σ(x)
 
 ReAgent's implementation optimizes this computation through:

 
 - Incremental updates to A and b
 - Computing A^(-1) only when necessary
 - Handling numerical stability through `matrix_inv_fallback_pinv`
 - Supporting per-observation weights and gamma discounting

## Conclusion

 The Contextual Bandits implementation in ReAgent provides a comprehensive framework for developing, training, and evaluating bandit algorithms with various levels of complexity. From basic linear models to sophisticated deep representation approaches, the system supports both research exploration and production deployment with features like distributed training and robust evaluation.

 When choosing among the different model variants:

 
 - **LinearRegressionUCB**: Best for simple problems with clear linear relationships, limited feature dimensions, or when interpretability is important.
 - **DeepRepresentLinearRegressionUCB**: Suitable for complex problems with high-dimensional inputs where feature representation learning is valuable, while still maintaining uncertainty estimates.
 - **DisjointLinearRegressionUCB**: Appropriate when arms have fundamentally different reward structures, though requires more data per arm to learn effectively.
 
 All these models can be adapted to non-stationary environments through the gamma discount parameter, making them suitable for real-world applications where conditions change over time.
