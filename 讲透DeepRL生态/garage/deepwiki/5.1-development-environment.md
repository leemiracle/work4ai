  This page provides comprehensive guidance on setting up a development environment for contributing to the garage reinforcement learning framework. It covers local installation, Docker-based development, development tools, and workflow recommendations. For information about installing garage for normal usage (not development), see [Installation](https://deepwiki.com/rlworkgroup/garage/1.1-installation).

 
## Overview

 Garage supports development on Linux and macOS platforms, with multiple setup options depending on your needs. This page covers:

 
 - Local development environment setup
 - Docker-based development
 - Development tools configuration
 - Code quality and testing
 
 
## System Requirements

 
### Supported Platforms

 Garage development is officially supported on:

 
 - **Linux**: Ubuntu 16.04, 18.04, and 20.04 are fully tested
 - **macOS**: 10.12 through 10.15.2 are known to work
 
 
### Hardware Requirements

 
 - **CPU**: Any modern multi-core CPU
 - **RAM**: 8GB+ recommended
 - **GPU**: Optional, NVIDIA GPU with driver version 450.36.06+ for CUDA 11.0 support
 - **Disk**: At least 5GB free space

## Development Best Practices

 
### Code Style

 Garage follows a strict code style guided by:

 
 - PEP 8 for general Python style
 - Google style for docstrings
 - Custom rules for imports and other garage-specific conventions
 
 Here are some key style points:

 
 - Use single quotes for strings
 - Sort imports alphabetically
 - Use absolute imports within packages
 - Prefer f-strings for string interpolation
 
 Sources: [CONTRIBUTING.md36-177](https://github.com/rlworkgroup/garage/blob/2d594803/CONTRIBUTING.md?plain=1#L36-L177) [.pylintrc](https://github.com/rlworkgroup/garage/blob/2d594803/.pylintrc) [setup.cfg1-83](https://github.com/rlworkgroup/garage/blob/2d594803/setup.cfg#L1-L83)

 
### Commit Message Format

 Commit messages should follow these guidelines:

 
 - Informative subject line of 50 characters or less
 - Newline between subject and body
 - Body wrapped to 72 characters if present
 
 The pre-commit hooks enforce this format automatically.

 Sources: [CONTRIBUTING.md268-275](https://github.com/rlworkgroup/garage/blob/2d594803/CONTRIBUTING.md?plain=1#L268-L275) [scripts/check_commit_message](https://github.com/rlworkgroup/garage/blob/2d594803/scripts/check_commit_message)

 
### Git Workflow

 Garage uses a linear commit history with rebase-only merging:

 
 - Create feature branches from master
 - Rebase your branch before submitting PRs
 - Don't use merge commits
 - Keep your master branch up-to-date with upstream

## Common Issues and Troubleshooting

 
### MuJoCo Problems

 If you encounter issues with MuJoCo:

 
 - Verify your key is correctly placed at `~/.mujoco/mjkey.txt`
 - Ensure environment variables are set correctly
 - Try reinstalling mujoco-py
 
 
### Docker Issues

 For Docker-related problems:

 
 - Ensure Docker version 19.03+ is installed
 - For GPU images, verify NVIDIA driver compatibility
 - Check Docker BuildKit is enabled (`DOCKER_BUILDKIT=1`)
 
 Sources: [docker/Dockerfile104-108](https://github.com/rlworkgroup/garage/blob/2d594803/docker/Dockerfile#L104-L108) [Makefile132-133](https://github.com/rlworkgroup/garage/blob/2d594803/Makefile#L132-L133)

 
### Pre-commit Hook Issues

 If pre-commit hooks are failing:

 
 - Update pre-commit with `pre-commit autoupdate`
 - Make sure you're using Python 3.6+
 - Run `pre-commit run --all-files` to test all hooks
 
 Sources: [.pre-commit-config.yaml1-88](https://github.com/rlworkgroup/garage/blob/2d594803/.pre-commit-config.yaml#L1-L88)
