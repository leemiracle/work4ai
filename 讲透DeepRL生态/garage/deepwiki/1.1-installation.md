### Available Docker Images

 Two types of garage images are available on Docker Hub:

 
 - **`rlworkgroup/garage`**: Base image without environment visualization
 - **`rlworkgroup/garage-nvidia`**: Image with GPU support (CUDA 11.0 and cuDNN 8.0) and visualization capabilities
 
 
### Prerequisites

 
 - Docker CE version 19.03 or higher
 - For NVIDIA image: 
 - NVIDIA driver (version 450.36.06 or higher for CUDA 11.0)
 - nvidia-container-runtime

## Troubleshooting

 
### MuJoCo Issues

 
 - Ensure your MuJoCo key is placed in `~/.mujoco/mjkey.txt`
 - Check environment variables: `LD_LIBRARY_PATH` should include `~/.mujoco/mujoco200/bin`
 - For visualization issues, set `MUJOCO_GL=glfw`
 
 
### Docker Issues

 
 - For permission issues with mounted volumes, ensure proper permissions: 
```

```
 - If visualization doesn't work with NVIDIA image, run `xhost +local:docker` before starting the container
 
 
### Python Package Conflicts

 
 - Use a clean environment manager (conda, pipenv, virtualenv)
 - If upgrading from an older garage version, uninstall the old version first
