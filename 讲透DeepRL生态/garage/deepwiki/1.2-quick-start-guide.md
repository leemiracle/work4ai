  This guide provides a practical introduction to using the Garage reinforcement learning framework. It covers the basics of setting up experiments, training policies with different algorithms, and evaluating trained models. If you're looking for installation instructions, see [Installation](https://deepwiki.com/rlworkgroup/garage/1.1-installation).

 
## Key Concepts in Garage

 Garage is organized around several core components that work together:

 
```

```

 
 - **Environment**: Where your agent interacts (gym environments, robotics simulators, etc.)
 - **Policy**: The agent's decision-making strategy that maps observations to actions
 - **Algorithm**: Implementation of RL methods (PPO, TRPO, SAC, etc.)
 - **Trainer**: Manages the training process, data collection, and logging
 - **Experiment**: Handles experiment configuration, logging, and snapshots
