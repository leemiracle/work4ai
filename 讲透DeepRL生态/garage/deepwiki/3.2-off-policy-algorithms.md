  This document details the off-policy reinforcement learning algorithms implemented in the Garage framework. Off-policy algorithms can learn from data collected using a different policy than the one being optimized, enabling reuse of past experiences. This contrasts with on-policy algorithms (covered in [On-Policy Algorithms](https://deepwiki.com/rlworkgroup/garage/3.1-on-policy-algorithms)), which require fresh samples from the current policy for each update.

 
## Overview of Off-Policy Learning

 Off-policy algorithms in Garage share several core components:

 
 - **Replay Buffer**: Stores transitions (state, action, reward, next state) from past experiences
 - **Exploration Policy**: Strategy to encourage exploration of the environment
 - **Target Networks**: Separate networks providing stable learning targets
 - **Value Function Approximators**: Networks that estimate action values (Q-functions)

## Core Algorithms

 
### DQN (Deep Q-Network)

 DQN is a value-based method that approximates the Q-function with a neural network. It's used for environments with discrete action spaces.

 **Key Features:**

 
 - Experience replay to break correlations in the data
 - Target network for stable learning targets
 - Optional double Q-learning to reduce overestimation bias

### DDPG (Deep Deterministic Policy Gradient)

 DDPG is an actor-critic algorithm for continuous action spaces that learns a deterministic policy.

 **Key Features:**

 
 - Deterministic policy (actor) that selects actions
 - Q-function (critic) that evaluates state-action pairs
 - Target networks for both actor and critic
 - Exploration through added noise (typically Ornstein-Uhlenbeck)

### TD3 (Twin Delayed Deep Deterministic Policy Gradient)

 TD3 improves upon DDPG with three key modifications to address function approximation errors.

 **Key Features:**

 
 - Twin Q-networks to reduce overestimation bias
 - Delayed policy updates to reduce variance
 - Target policy smoothing by adding noise to target actions
 - Same actor-critic architecture as DDPG

### SAC (Soft Actor-Critic)

 SAC is an entropy-regularized algorithm that optimizes a stochastic policy to maximize both expected return and entropy.

 **Key Features:**

 
 - Stochastic policy with entropy regularization
 - Automatic temperature tuning to balance exploration and exploitation
 - Twin Q-networks to mitigate overestimation bias
 - Off-policy learning from replay buffer experiences

### Policy Optimization

 Each algorithm has its unique optimization objective:

 **DQN**: Minimize the squared TD error

 
```
loss = (Q(s,a) - (r + γ * max_a' Q_target(s',a')))²
```

 **DDPG/TD3**: Maximize expected Q-values for the policy

 
```
policy_loss = -mean(Q(s, π(s)))
```

 **SAC**: Maximize expected Q-values and entropy

 
```
policy_loss = -mean(Q(s, a) - α * log_prob(a|s))  where a ~ π(·|s)
```

## Algorithm Comparison

 
| Algorithm | Action Space | Policy Type | Key Innovations |
|---|---|---|---|
| DQN | Discrete | Implicit/Argmax | Experience replay, target networks, double Q-learning |
| DDPG | Continuous | Deterministic | Actor-critic architecture, target policy networks |
| TD3 | Continuous | Deterministic | Twin Q-networks, delayed policy updates, target smoothing |
| SAC | Continuous | Stochastic (Gaussian) | Entropy maximization, automatic temperature tuning |
