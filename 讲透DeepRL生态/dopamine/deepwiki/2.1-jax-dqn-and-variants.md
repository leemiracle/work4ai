  This document covers the JAX implementation of the Deep Q-Network (DQN) algorithm and its distributional variants in the Dopamine reinforcement learning framework. It focuses on the architecture, components, and relationships between the base DQN agent and its extensions (Rainbow, Quantile Regression DQN, and Implicit Quantile Networks). For information about the Full Rainbow agent with all DQN enhancements, see [Full Rainbow Agent](https://deepwiki.com/google/dopamine/2.2-full-rainbow-agent).

### Key Functions

 
 - **Initialization**: The agent is initialized with network architecture, optimization parameters, and exploration settings.
 - **Action Selection**: Uses an epsilon-greedy strategy to balance exploration and exploitation.
 - **Training Process**: Samples transitions from the replay buffer, computes TD targets, and updates the network weights.
 - **Target Network Update**: Periodically syncs the target network with the online network to stabilize training.

## Key Parameters and Configuration

 Common configuration parameters for all DQN variants:

 
| Parameter | Description | Default |
|---|---|---|
| num_actions | Number of actions the agent can take | Environment-dependent |
| gamma | Discount factor | 0.99 |
| update_horizon | Number of steps for n-step returns | 1 |
| min_replay_history | Minimum transitions before training | 20,000 |
| update_period | Steps between network updates | 4 |
| target_update_period | Steps between target network updates | 8,000 |
| epsilon_train | Final epsilon value for training | 0.01 |
| epsilon_eval | Epsilon value for evaluation | 0.001 |
| epsilon_decay_period | Steps to decay epsilon | 250,000 |

JaxDQNAgent.min_replay_history = 20,000
JaxDQNAgent.update_period = 4

JaxDQNAgent.epsilon_train = 0.01
JaxDQNAgent.epsilon_eval = 0.001
