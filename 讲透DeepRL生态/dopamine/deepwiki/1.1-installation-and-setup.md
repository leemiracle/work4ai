  This document provides detailed instructions for installing the Dopamine reinforcement learning framework and setting up the necessary environment to run experiments. Dopamine is designed to be customized, so understanding the installation options is important for getting started properly.

 For information about the framework architecture and core components, see [Framework Architecture](https://deepwiki.com/google/dopamine/1.2-framework-architecture).

 
## Overview

 Dopamine provides three primary installation methods:

 
 - **Docker containers** - Easiest method with pre-configured environments
 - **Source installation** - Recommended for most users who plan to modify the code
 - **Pip installation** - Simpler but less flexible for customization
 
 Before installation, you'll need to set up the reinforcement learning environments you intend to use.

## Prerequisites

 
### System Requirements

 Dopamine requires:

 
 - Python 3.5 or higher (but less than 4.0)
 - Sufficient disk space for dependencies (~2GB)
 - A virtual environment is strongly recommended
 
 
### Atari Environment Setup

 If you plan to use Atari environments:

 
 - These environments are provided by the [ale_py](https://github.com/google/dopamine/blob/bec5f4e1/ale_py) package which will be installed automatically
 - You may need manual steps to install OpenAI's `baselines` package for certain functionality
 
 
### MuJoCo Environment Setup

 For MuJoCo environments:

 
 - Install MuJoCo and obtain a license from the [MuJoCo website](https://github.com/google/dopamine/blob/bec5f4e1/MuJoCo website)
 - Install the mujoco-py package: `pip install mujoco-py`

## Supported Environments

 Dopamine supports several reinforcement learning environments:

 
| Environment Type | Supported Environments | Required Packages |
|---|---|---|
| Atari | 60+ Atari 2600 games (see list below) | ale_py, opencv-python |
| MuJoCo | Ant, HalfCheetah, Hopper, Humanoid, Walker2d | mujoco-py |
| Gym | Various classic control problems | gym |
| Gymnasium | Modern version of Gym environments | gymnasium |

 A full list of supported Atari games can be found in the codebase.

## Common Issues and Troubleshooting

 
### Package Conflicts

 If you encounter dependency conflicts:

 
 - Use a clean virtual environment
 - Install the packages in the order specified in requirements.txt
 - Pay attention to the version constraints in setup.py
 
 
### Environment Issues

 For Atari environment problems:

 
 - Ensure ROMs are properly installed
 - Check that ale_py is configured correctly
 
 For MuJoCo issues:

 
 - Verify your MuJoCo license is valid and properly installed
 - Check that mujoco-py is built against the correct version of MuJoCo
 
 Sources: [README.md57-68](https://github.com/google/dopamine/blob/bec5f4e1/README.md?plain=1#L57-L68) [setup.py30-49](https://github.com/google/dopamine/blob/bec5f4e1/setup.py#L30-L49)
