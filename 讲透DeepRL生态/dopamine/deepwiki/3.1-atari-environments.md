  This page documents the Atari environment integration in Dopamine. Atari 2600 games have become a standard benchmark in reinforcement learning research, and Dopamine provides specialized utilities for preprocessing and interfacing with these environments. This document explains how Atari environments are created, configured, and preprocessed to make them suitable for reinforcement learning agents.

 For information about other environments supported by Dopamine, see [Other Environments](https://deepwiki.com/google/dopamine/3.2-other-environments).

 
## Overview

 Dopamine's Atari integration follows the guidelines proposed by Machado et al. (2017), "Revisiting the Arcade Learning Environment: Evaluation Protocols and Open Problems for General Agents." This includes standard preprocessing operations that have become conventional in reinforcement learning research with Atari games.

### Key Parameters

 
 - `game_name`: The name of the Atari 2600 game (e.g., "Pong", "Breakout").
 - `sticky_actions`: Whether to use sticky actions (actions persisting with 0.25 probability), which introduces mild stochasticity.
 - `use_legacy_gym`: Whether to use the legacy Gym API instead of the newer Gymnasium API.
 - `use_ppo_preprocessing`: Whether to use PPO-specific preprocessing instead of DQN-style preprocessing.
 - `continuous_action_threshold`: If set, uses the continuous version of ALE (Arcade Learning Environment) with the specified threshold.

## Atari Preprocessing

 Dopamine implements standard preprocessing operations for Atari frames through the `AtariPreprocessing` class. This preprocessing pipeline is critical for making raw Atari frames suitable for deep learning models.

 
```

```

 Sources: [dopamine/discrete_domains/atari_lib.py458-667](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/discrete_domains/atari_lib.py#L458-L667)

 
### Preprocessing Steps

 
 - **Frame Skipping**: The agent only sees and acts on every nth frame (default: 4), accumulating rewards in between.
 - **Grayscale Conversion**: RGB frames are converted to grayscale to reduce dimensionality.
 - **Max-Pooling**: Takes the maximum pixel values over the last two frames to capture moving objects (like flickering sprites).
 - **Resizing**: Downsamples the image to 84x84 pixels, the standard input size for DQN-style networks.
 - **Terminal Signal on Life Loss (Optional)**: Provides a terminal signal when the agent loses a life, encouraging the agent to learn to avoid life loss.
 
 Sources: [dopamine/discrete_domains/atari_lib.py458-667](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/discrete_domains/atari_lib.py#L458-L667)

 
### Implementation

 The `AtariPreprocessing` class implements the above preprocessing steps and provides an interface that matches the Gym environment API:

 
```
reset(): Resets the environment and returns the initial observation.
step(action): Applies the action, returns observation, reward, is_terminal, info.
render(mode): Renders the current screen before preprocessing.
```

 The implementation bypasses the Gym observation system and directly fetches grayscale images from the ALE (Arcade Learning Environment) for improved efficiency.

## Network Architectures for Atari

 Dopamine provides several network architectures specifically designed for Atari domains. These networks expect inputs in the format produced by the `AtariPreprocessing` class.

 
```

```

 Sources: [dopamine/discrete_domains/atari_lib.py179-455](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/discrete_domains/atari_lib.py#L179-L455)

 
### Nature DQN Network

 The `NatureDQNNetwork` implements the convolutional neural network architecture from the Nature DQN paper (Mnih et al., 2015). It consists of:

 
 - 3 convolutional layers: 
 - 32 filters of size 8x8 with stride 4
 - 64 filters of size 4x4 with stride 2
 - 64 filters of size 3x3 with stride 1
 - A fully connected layer with 512 units
 - An output layer with one unit per action
 
 Sources: [dopamine/discrete_domains/atari_lib.py179-249](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/discrete_domains/atari_lib.py#L179-L249)

 
### Rainbow Network

 The `RainbowNetwork` extends the DQN architecture to output a distribution over Q-values as used in the Rainbow agent. It shares the same convolutional architecture as the Nature DQN Network but outputs:

 
 - Q-values (expected returns)
 - Logits (unnormalized probabilities)
 - Probabilities for value distribution
 
 Sources: [dopamine/discrete_domains/atari_lib.py252-340](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/discrete_domains/atari_lib.py#L252-L340)

 
### Implicit Quantile Network

 The `ImplicitQuantileNetwork` implements the network architecture for IQN (Implicit Quantile Networks) agents. It includes:

 
 - The same convolutional layers as DQN
 - An additional embedding network for quantiles
 - Element-wise multiplication between state and quantile embeddings
 
 Sources: [dopamine/discrete_domains/atari_lib.py343-455](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/discrete_domains/atari_lib.py#L343-L455)

 
## Game Over Handling

 Dopamine provides the `GameOverWrapper` class to properly handle game over signals. This wrapper:

 
 - Distinguishes between true game over events and terminations due to time limits
 - Sets `game_over` to `True` only for genuine game overs, not for truncations due to time limits
 
 This distinction is important because agents should learn differently from true terminal states versus artificial terminations.

## Integration with Gin Configuration

 Atari environments in Dopamine are highly configurable through Gin, allowing for easy experiment configuration without code changes.

 Example Gin configuration for Atari:

 
```
# Configure the environment
create_atari_environment.game_name = 'Pong'
create_atari_environment.sticky_actions = True

# Configure the preprocessing
AtariPreprocessing.terminal_on_life_loss = True
AtariPreprocessing.frame_skip = 4
AtariPreprocessing.screen_size = 84
```

## Constants and Network Types

 Dopamine defines several constants and network type namedtuples for Atari environments:

 
### Constants

 
 - `NATURE_DQN_OBSERVATION_SHAPE = (84, 84)`: Size of downscaled Atari frame
 - `NATURE_DQN_DTYPE = tf.uint8`: Datatype for observations
 - `NATURE_DQN_STACK_SIZE = 4`: Number of frames in the state stack
 
 
### Network Types

 
 - `DQNNetworkType`: Contains Q-values
 - `RainbowNetworkType`: Contains Q-values, logits, and probabilities
 - `ImplicitQuantileNetworkType`: Contains quantile values and quantiles
 
 These constants and network types help ensure consistency across different components of the framework.

## Conclusion

 Dopamine's Atari environment integration provides a standardized, efficient way to use Atari games as reinforcement learning environments. The preprocessing pipeline follows best practices established in the research community, and the environment API is designed to integrate seamlessly with Dopamine's agent implementations.

 For users looking to use Atari environments with Dopamine, the primary entry point is the `create_atari_environment` function, which can be configured either directly or through Gin configuration.
