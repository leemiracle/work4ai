## Purpose and Scope

 This document provides information about the original TensorFlow-based agent implementations in the Dopamine framework. While Dopamine has transitioned to primarily using JAX-based agents for improved performance and flexibility, the TensorFlow implementations remain available for backward compatibility and legacy support. For information about the newer JAX-based implementations, see [JAX DQN and Variants](https://deepwiki.com/google/dopamine/2.1-jax-dqn-and-variants).

 
## Overview of TensorFlow Agents

 Dopamine's original reinforcement learning agents were implemented using TensorFlow 1.x. These implementations served as the foundation for the framework before the transition to JAX. The legacy TensorFlow agent implementations include:

 
 - DQN (Deep Q-Network)
 - Rainbow
 - Implicit Quantile Network (IQN)
 
 These implementations share common architectural elements but differ in their specific algorithmic approaches to reinforcement learning.

## TensorFlow Agent Implementations

 
### DQN Agent

 The DQN (Deep Q-Network) agent is the foundational agent in Dopamine. It implements the algorithm described in the seminal paper by Mnih et al. (2015), which combines Q-Learning with deep neural networks.

 Key features:

 
 - Experience replay buffer
 - Target network for stable learning
 - Nature CNN architecture for Atari games
 - Epsilon-greedy exploration policy
 
 
### Rainbow Agent

 The Rainbow agent combines several improvements to the DQN algorithm as described by Hessel et al. (2018):

 Key features:

 
 - Distributional RL (C51)
 - Dueling network architecture
 - Prioritized experience replay
 - Multi-step learning
 - Noisy networks for exploration
 
 
### Implicit Quantile Agent

 The Implicit Quantile Network (IQN) agent implements the algorithm described by Dabney et al. (2018), which extends distributional RL through implicit quantile networks.

 Key features:

 
 - Distributional RL beyond fixed categorical distributions
 - Implicit representation of the return distribution
 - Sample-based representation of quantile functions

### Special Considerations for TensorFlow Agents

 When using legacy TensorFlow agents, be aware of the following:

 
 - **Session Management**: TensorFlow agents require a TensorFlow session, which is managed by the agent itself.
 - **Checkpointing Compatibility**: Checkpoints created with TensorFlow agents are not compatible with JAX agents and vice versa.
 - **Terminal Signal Limitations**: As noted in the code comment, TensorFlow agents do not handle the terminal signal in the same way as JAX agents:

## Conclusion

 Legacy TensorFlow agents remain an important part of the Dopamine framework for backward compatibility and historical reference. While new projects are encouraged to use the JAX-based implementations for better performance and active development, understanding the TensorFlow agents provides valuable context for the evolution of the framework and enables maintenance of existing projects built on these implementations.
