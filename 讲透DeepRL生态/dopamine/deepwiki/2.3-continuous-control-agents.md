## Purpose and Scope

 This document describes the continuous control agent implementations in Dopamine, specifically focusing on agents designed to handle environments with continuous action spaces rather than discrete actions. These agents utilize specialized network architectures and algorithms tailored for continuous control tasks. For information about discrete action agents like DQN and its variants, see [JAX DQN and Variants](https://deepwiki.com/google/dopamine/2.1-jax-dqn-and-variants).

 
## Overview of Continuous Control in Dopamine

 Continuous control in reinforcement learning deals with problems where the action space is continuous (real-valued) rather than discrete. Examples include robotic control, where joint torques are continuous values, or vehicle control with continuous steering and acceleration.

## Soft Actor-Critic (SAC) Agent

 
### Overview

 The SAC agent implements the Soft Actor-Critic algorithm, based on "Soft Actor-Critic Algorithms and Applications" by Tuomas Haarnoja et al. This is an off-policy actor-critic algorithm that incorporates entropy maximization to encourage exploration.

 
```

```

 Sources:

 
 - [dopamine/jax/agents/sac/sac_agent.py286-446](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/jax/agents/sac/sac_agent.py#L286-L446)
 
 
### Implementation Details

 The SAC agent in Dopamine uses:

 
 - **Dual Critics**: Two Q-networks to reduce overestimation bias
 - **Automatic Temperature Tuning**: Optimizes the entropy regularization coefficient (alpha)
 - **Target Networks**: Uses "soft" target updates by default
 - **JAX Implementation**: Leverages JAX for efficient computation and optimization
 
 The core learning happens in the `train` function [dopamine/jax/agents/sac/sac_agent.py71-258](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/jax/agents/sac/sac_agent.py#L71-L258) which updates:

 
 - The critic networks to minimize TD error
 - The actor network to maximize expected return and entropy
 - The temperature parameter (alpha) to achieve a target entropy
 
 
### Configuration

 SAC agent can be configured using Gin, with key parameters including:

 
```
SACAgent.reward_scale_factor = 0.1

```

### Actor Networks

 The actor network in continuous control generates a probability distribution over the action space:

 
 - `ActorNetwork`: Outputs a mean action, a sampled action, and the log probability of the sampled action
 - `PPOActorNetwork`: Specialized actor for PPO that also computes action entropy
 
 Both networks use fully-connected layers with configurable activation functions and transform the output distribution to match the specified action limits.

### Critic Networks

 The critic networks estimate the value of state-action pairs:

 
 - `CriticNetwork`: A standard critic that outputs a single Q-value
 - `PPOCriticNetwork`: A specialized critic for PPO
 
 For SAC, two instances of the critic network are used to reduce overestimation bias, a common problem in Q-learning methods.

### Combined Actor-Critic Networks

 Dopamine provides combined networks that integrate both actor and critic components:

 
 - `ActorCriticNetwork`: Combined network for SAC with methods to access the actor and dual critics
 - `PPOActorCriticNetwork`: Combined network for PPO
 
 These combined networks facilitate parameter sharing and simplify the agent implementation.

### Training and Evaluation

 Dopamine provides two runners for continuous control:

 
 - `ContinuousRunner`: Alternates between training and evaluation phases
 - `ContinuousTrainRunner`: Focuses solely on training, no evaluation
 
 The training process involves:

 
 - Collecting experience from the environment
 - Storing transitions in the replay buffer
 - Sampling batches for training
 - Updating the actor and critic networks
 - Periodically updating target networks
 - Logging metrics and checkpointing

## Handling Action Limits

 Continuous control agents must respect the action limits of the environment. The SAC agent transforms the action distribution to ensure actions fall within the specified limits:

 
 - The environment's action limits are provided to the agent during initialization
 - The actor network uses these limits to transform its output distribution
 - This transformation is done using a tanh squashing function followed by scaling and shifting

## Training Process Walkthrough

 The training process for SAC involves several steps:

 
 - **Sample from Replay Buffer**: Get a batch of transitions
 - **Calculate Critic Loss**: Compute the TD error for both critic networks 
```
q_value_1, q_value_2 = critic(state, action)
target = reward + gamma * (min(target_q_1, target_q_2) - alpha * log_prob)
critic_loss = MSE(q_value_1, target) + MSE(q_value_2, target)
```
 - **Calculate Policy Loss**: Compute the loss for the actor 
```
policy_loss = E[alpha * log_prob - Q(s, a)]
```
 - **Calculate Alpha Loss**: Update the temperature parameter 
```
alpha_loss = log_alpha * (entropy - target_entropy)
```
 - **Update Networks**: Apply gradients to all networks
 - **Update Target Networks**: Soft update the target critic networks
 
 This process repeats continuously throughout training, with periodic evaluation if using `ContinuousRunner`.
