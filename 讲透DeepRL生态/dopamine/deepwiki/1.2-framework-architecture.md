## Core Architecture Principles

 Dopamine is designed as a research framework for reinforcement learning with four key design principles:

 
 - **Easy experimentation**: Simple interfaces for running benchmark experiments
 - **Flexible development**: Modular design allowing for modification of components
 - **Compact and reliable**: Focused implementations of battle-tested algorithms
 - **Reproducible**: Structured to facilitate reproducible research
 
 The framework primarily uses JAX for implementing agents, with legacy TensorFlow implementations maintained for backward compatibility.

## Core Components

 
### 1. Agents

 Agents are the central component of the framework, implementing reinforcement learning algorithms. All agents share a common interface but have different implementations based on the algorithm they use.

 Key agent characteristics:

 
 - JAX-based implementations are preferred (e.g., `JaxDQNAgent`, `JaxRainbowAgent`)
 - Legacy TensorFlow implementations are maintained (e.g., `DQNAgent`)
 - Agents handle algorithm-specific logic like network updates and action selection

### 2. Environments

 Environments provide the interface between agents and simulated worlds (like Atari games or MuJoCo physics simulations). Dopamine includes wrappers and preprocessing for different environment types.

 Key environment features:

 
 - Support for Atari games (primary focus)
 - Support for Gym, MuJoCo, and other environments
 - Standardized preprocessing and observation handling

### 3. Experiment Runners

 Runners orchestrate the training process, coordinating agents and environments. They handle:

 
 - Training and evaluation loops
 - Checkpointing
 - Logging metrics
 - Configuration management

## Configuration System

 Dopamine uses Gin-config for dependency injection and parameter configuration, enabling flexible experiment setup without code changes.

 Key configuration features:

 
 - Configuration files define hyperparameters for agents and runners
 - Supports command-line parameter overrides
 - Facilitates reproducibility through configuration versioning

## JAX Implementation Focus

 The framework has shifted to JAX for agent implementations due to:

 
 - **Performance**: JAX's just-in-time compilation improves training speed
 - **Functional design**: Pure functions help with reproducibility
 - **Auto-differentiation**: Simplifies gradient-based optimization
 
 Legacy TensorFlow implementations are maintained for backward compatibility but new development occurs primarily in JAX.

## Extension Points

 Dopamine is designed to be extensible at several key points:

 
 - **Custom agents**: Create new agent classes by extending base agent classes
 - **Custom environments**: Wrap new environments to work with Dopamine
 - **Custom networks**: Implement new neural network architectures
 - **Custom metrics**: Add additional logging and visualization
 
 These extension points allow researchers to experiment with new algorithms while leveraging the framework's infrastructure.

## Framework Evolution

 Dopamine has evolved from its original TensorFlow-based implementation to a primarily JAX-based framework. This shift reflects the research community's move toward functional programming patterns in reinforcement learning research.

 The framework maintains backward compatibility while focusing new development on JAX-based implementations.
