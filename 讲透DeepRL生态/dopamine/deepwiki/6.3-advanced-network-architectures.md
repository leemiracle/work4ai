  This page documents specialized neural network architectures implemented in Dopamine for reinforcement learning research. These architectures go beyond standard neural networks to provide improved parameter efficiency, scalability, and performance. This document focuses on two key advanced architectures: Mixture of Experts (MoE) and Weight Recycling.

 For information about specific agent implementations using these architectures, see [Agent Implementations](https://deepwiki.com/google/dopamine/2-agent-implementations), and for information about data-efficient architectures specifically designed for the Atari 100k benchmark, see [Atari 100k](https://deepwiki.com/google/dopamine/6.1-atari-100k).

 
## Mixture of Experts (MoE)

 Mixture of Experts (MoE) is a neural network architecture that routes input to specialized sub-networks (experts) and combines their outputs. MoEs enable scaling the parameter count of neural networks without increasing the computational cost proportionally, as only a subset of experts is active for each input.

### MoE Auxiliary Losses

 MoE networks include auxiliary losses to ensure balanced expert utilization:

 
 - **Entropy Loss**: Maximizes entropy of expert assignment for load balancing
 - **Importance Loss**: Minimizes variance in expert utilization
 - **Load Loss**: Ensures balanced expert workload distribution

 Weight Recycling, also known as ReDo, is a technique to reinitialize parts of the network corresponding to "dead" neurons during training. This improves training efficiency by reactivating parts of the network that are no longer contributing to learning.

### Scheduled Recycling

 `NeuronRecyclerScheduled` implements more sophisticated recycling strategies:

 
| Strategy | Description |
|---|---|
| redo | Standard ReDo approach based on activation magnitude |
| random | Randomly select neurons to recycle |
| redo_inverted | Recycle neurons with highest activations |
| cbp | Continual Backprop-style recycling |

 The recycling rate is often scheduled to decrease over time, allowing for more stability later in training.

 Sources:

 
 - [dopamine/labs/redo/weight_recyclers.py700-746](https://github.com/google/dopamine/blob/bec5f4e1/dopamine/labs/redo/weight_recyclers.py#L700-L746)
 
 
### Integration with Training Loop

 Weight recycling is integrated into the training loop through these key steps:

 
 - Collect intermediate activations during forward pass
 - Periodically check if recycling should occur based on step count
 - Compute neuron scores and identify dead neurons
 - Create masks for incoming and outgoing weights of dead neurons
 - Reinitialize weights according to the selected strategy
 - Reset optimizer state for recycled weights
 - Continue training with the recycled network

## Conclusion

 Dopamine's advanced network architectures provide researchers with powerful tools to explore parameter-efficient and scalable reinforcement learning. Mixture of Experts enables selective activation of network components, while Weight Recycling helps revitalize dead parts of the network during training. These architectures can be integrated with various RL algorithms like DQN, Rainbow, and more specialized variants.

 For practical usage examples, refer to the various agent implementations provided in the Dopamine framework.
