## Software Requirements

 ELF OpenGo has specific software requirements that have been tested and verified.

 
### Core System Requirements

 
| Component | Minimum Requirement | Notes |
|---|---|---|
| Operating System | Ubuntu 18.04 | Only tested environment |
| Python | 3.7 | Required for neural network components |
| GCC | 7.3 (minimum 7.1) | C++17 support required |
| CUDA | 10.0 | For GPU acceleration |
| CUDNN | 7.3 | Deep learning primitives |
| NCCL | 2.1.2 | Multi-GPU communication |

### Third-Party Libraries

 ELF OpenGo relies on several third-party libraries that are included as submodules in the repository:

 
| Library | Purpose |
|---|---|
| googletest | Testing framework |
| json | JSON parsing |
| pybind11 | Python/C++ interoperability |
| spdlog | Logging |
| concurrentqueue | Thread-safe queue implementation |
| TBB | Thread Building Blocks for parallelism |
| ZeroMQ | Messaging library for distributed communication |

## Compatibility Notes

 The ELF OpenGo developers note that:

 
> At the moment, this is the only supported environment. Other environments may also work, but we unfortunately do not have the manpower to investigate compatibility issues.

 When using different configurations than those specified, you may encounter compatibility problems. The code is described as "early research code" and may not work reliably or at all on unsupported systems.
