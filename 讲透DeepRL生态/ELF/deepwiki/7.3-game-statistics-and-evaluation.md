## Purpose and Scope

 This document outlines the game statistics collection and evaluation mechanisms in the ELF OpenGo platform. It covers how the system gathers performance metrics during gameplay, evaluates AI models, and uses this data to improve training. The focus is on the technical implementation of statistics gathering, storage, and analysis rather than the theoretical aspects of model evaluation.

 For information about the training system itself, see [Training System](https://deepwiki.com/pytorch/ELF/5-training-system) and for details on self-play, see [Self-Play](https://deepwiki.com/pytorch/ELF/5.1-self-play).

 
## Overview of Game Statistics System

 The ELF OpenGo platform collects various statistics during gameplay to evaluate the performance of AI models. These statistics include move rankings, win rates, predicted values, and complete game records. This data is essential for assessing model strength, tracking training progress, and identifying areas for improvement.

### Types of Statistics Collected

 
 - **Move Rankings**: The system tracks the ranking of selected moves among all possible moves. This helps evaluate how well the AI is selecting optimal moves.
 - **Win Rate Statistics**: Win rates are collected to assess the overall performance of models. These statistics include the number of games played, win percentages, and other relevant metrics.
 - **Game Records**: Complete game records are stored in SGF (Smart Game Format) for detailed post-game analysis.
 - **Predicted Values**: The system records the AI's predicted win probability for comparison with actual game outcomes.

### Model Evaluation

 The collected statistics are used to evaluate model performance and determine whether to update the model. The key metrics include:

 
 - **Win Rate**: The percentage of games won by the model, which indicates its overall strength.
 - **Move Ranking**: The quality of moves selected by the model.
 - **Predicted Value Accuracy**: The correlation between predicted win probabilities and actual game outcomes.
 
 These metrics help determine the effectiveness of model improvements during training.

 The game statistics and evaluation system in ELF OpenGo plays a crucial role in model training and improvement. The integration of these statistics with the training pipeline enables continuous improvement of the AI models.
