## Purpose

 Feature extraction in the ELF OpenGo system transforms the raw Go board state into a structured format suitable for neural network processing. This component bridges the game logic representation and the machine learning components, enabling the neural network to learn meaningful patterns from board states.

 For information about the underlying board representation itself, see [Board Representation](https://deepwiki.com/pytorch/ELF/3.1-board-representation).

## Board Transformations

 The `BoardFeature` class supports symmetry transformations through the D4 group (dihedral group of order 8). These transformations serve two key purposes:

 
 - **Data Augmentation**: Generating multiple training examples from a single board state
 - **Invariance**: Ensuring the neural network learns patterns independently of orientation

## Integration with Training System

 The `BoardFeature` class is integrated into the training system through the `GoStateExtOffline` class, which contains a `BoardFeature` member (`_bf`). This integration is crucial for preparing board states for neural network training.

 
```

```

 During training, the `BoardFeature` component:

 
 - Applies symmetry transformations for data augmentation
 - Extracts features from the transformed board
 - Converts features into tensors for neural network input
