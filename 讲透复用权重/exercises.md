# 练习题汇总 · 讲透复用权重

> 输出倒逼输入。建议每章学完立刻做对应题目。

---

## 第 0 章 · 为什么复用权重
1. **[概念]** 一句话解释"为什么预训练+微调比从零训练省数据"。
2. **[动手]** 把 `00` 的目标点从 12 改成 200，从零和复用的差距变大还是变小？
3. **[洞察]** 源任务换螺旋线（不兼容），复用还会赢吗？这对应什么现象？
4. **[思考]** "成本集中在预训练、收益摊到无数下游"，和哪些传统行业类似？

## 第 1 章 · 迁移学习全景
1. **[概念]** 为什么特征提取只训 130 参数就赢从零训 8642？
2. **[动手]** 目标数据从 20 改成 500，三模式差距怎么变？
3. **[洞察]** 目标改成旋转 60° 的 circles，特征提取还会 100% 吗？（负迁移）
4. **[进阶]** "先特征提取再解冻微调"为什么比直接微调稳？

## 第 2 章 · 预训练范式
1. **[概念]** 为什么自监督能用"无标签"数据训练？
2. **[动手]** 预训练噪声从 0.15 改成 0.5，DAE 还能学好特征吗？
3. **[洞察]** BERT 的 MLM 和本实验的 DAE 本质上是不是一回事？
4. **[进阶]** CLIP 训练数据图文配对有错，会学到什么坏特征？

## 第 3 章 · 权重共享
1. **[概念]** CNN 卷积核滑动共享，编码了什么先验？
2. **[动手]** 共享深度从 6 改成 12，共享版参数变吗？
3. **[洞察]** ALBERT 共享层后参数大减，为什么效果没大跌？
4. **[进阶]** 为什么 GPT-4 不共享层，ALBERT 共享？

## 第 4 章 · 参数高效微调 PEFT/LoRA ★
1. **[概念]** LoRA 为什么初始化 B=0？
2. **[动手]** 秩 r 从 2 改成 1，还能 100% 吗？改成 8 呢？
3. **[洞察]** LoRA 推理可合并，Adapter 不能——为什么？
4. **[进阶]** QLoRA 为什么能让单卡微调 70B？

## 第 5 章 · 知识蒸馏
1. **[概念]** 为什么软标签比硬标签信息多？
2. **[动手]** 学生从 16 宽改成 4 宽，蒸馏 vs 直接差距变大吗？
3. **[洞察]** 蒸馏温度 T=1 vs T→∞ 会怎样？
4. **[进阶]** 蒸馏和直接截断教师前几层（拷权重）有什么区别？

## 第 6 章 · 持续学习
1. **[概念]** 为什么 SGD 学新任务会忘旧任务？
2. **[动手]** 回放样本数从 32 改成 128，A 和 B 准确率怎么变？
3. **[洞察]** EWC 用 Fisher 信息衡量权重重要性，什么权重大概率重要？
4. **[进阶]** 让 GPT 持续学新知识不忘旧能力，为什么特别难？

## 第 7 章 · 选型与批判
1. **[应用]** 500 张医学 X 光片做肿瘤分类，怎么走决策树？
2. **[应用]** 把 70B 模型部署到手机，用什么？
3. **[批判]** 所有人微调同一个 Foundation Model，有什么系统性风险？
4. **[思考]** 预训练成本降到人人可负担，"复用权重"范式会被颠覆吗？

## 进阶篇

## 第 8 章 · LoRA 深水区
1. **[概念]** DoRA 比 LoRA 多学了什么？为什么这让它在难任务上更强？
2. **[动手]** 把 `08` 的 DoRA magnitude 初始化改成 0，重跑——退化成什么？
3. **[洞察]** QLoRA 基座 4bit，LoRA 参数却保持 FP16。为什么不把 LoRA 也量化？
4. **[进阶]** LoRA+ 给 A/B 不同学习率，为什么 B 该用更高学习率？

## 第 9 章 · RAG vs 微调
1. **[概念]** 为什么 RAG 对"新增知识"零成本，微调却要重训？
2. **[应用]** 客服机器人，知识库（产品手册）每月更新。RAG 还是微调？
3. **[应用]** 让模型用"莎士比亚风格"写作。RAG 还是微调？
4. **[进阶]** RAG 检索不到正确片段时模型会怎样？怎么缓解？

## 第 10 章 · 预训练 Scaling Laws
1. **[概念]** 为什么 Chinchilla 说 GPT-3"参数浪费"？用 D/N 解释。
2. **[动手]** 把"大模型少数据"改成 256宽+50数据，MSE 变多差？
3. **[洞察]** 玩具 α≈1.1，真实大模型 α≈0.05~0.1。为什么玩具大得多？
4. **[进阶]** 10T 参数模型要 200T token，但高质量文本就 ~10T。"数据墙"怎么破？
