# 讲透仿真系统理论与技术 · "替身怎么跑"（GB/T 41315 三级：仿真系统理论与技术）

> **这支负责的问题**：把模型变成**能跑、能接、能联**的仿真系统。
> 一支钉住：**实时性（帧时间预算）、半实物（HIL，真硬件入回路）、
> 互操作（DIS/HLA/TENA，把各家仿真器连成一个）——这是最"工程"的一支。**

## 诞生

1929 林克（Link）造出林克训练器（因"飞行员在坠机前必须先学会犯错"），
二战训练约五十万飞行员〔知识〕；1965 Stewart 平台奠定六自由度运动
底座；1960s 导弹研制把真实控制器接进数学回路——半实物仿真（HIL）
成为航天与军工的标配（中国线：钱学森时代的导弹半实物仿真，北航
文传源 1980 年代主持中国首台歼击机飞行模拟机〔知识〕）。
1990s 分布式仿真标准化三步：DIS（IEEE 1278）→ HLA（DMSO 1995
基线，IEEE 1516-2000）→ TENA；并行仿真两路线由 Chandy-Misra
（保守，1979）与 Jefferson Time Warp（乐观，1985）定型。

## 核心问题

| 问题 | 状态 |
|------|------|
| 实时性：帧时间预算内解完模型+IO | ✅ 工程成熟；精度-帧时最优分配无一般解 |
| 半实物/人在回路的接口保真 | 🟡 工程经验丰富，形式化判据缺 |
| 分布仿真的互操作与时间管理（HLA） | ✅ 标准化完成；语义级互操作仍在演进 |
| 并行离散事件同步（保守 vs 乐观回滚） | ✅ 理论已解；大规模回滚成本仍是工程难题 |
| 仿真器认证（飞行模拟机分级等） | ✅ 行业规范成熟（认证=治理不是算法） |

## 这支最美的一个事实

**Time Warp 让"时间"变成可回滚的资源**：每个节点乐观猛跑，
因果违例发生时回滚重放——虚拟时间不必与墙上时间同向，
因果律交给回滚机制执行。

## 假设与依赖

实时约束（超帧即作废：算得完≠算得准）；因果一致性（分布仿真的
时间管理全部为此）；硬件在环时接口延迟与真实执行器的等效性假设。
