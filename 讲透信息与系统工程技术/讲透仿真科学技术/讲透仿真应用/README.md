# 讲透仿真应用 · "替身换什么"（GB/T 41315 三级：仿真应用）

> **这支负责的问题**：替身拿去换什么、换得值不值。一支钉住：
> **应用是仿真家族的预算来源与考场——军事、制造、交通、航天、医疗
> 各自成套，这一代的总入口是数字孪生=实时同步的仿真。**

## 诞生

二战林克训练器（约五十万飞行员〔知识〕）与曼哈顿后的核库存仿真
开创"训练/分析"两大应用母型；Apollo 时代宇航员在模拟器里演练
一切——阿波罗 13 号遇险后，任务控制连夜在仿真器里验证救援程序
再上传〔知识〕；1990s 军仿体系化（JTLS 级战役仿真、分布交互
战场）；2002-2010s Grieves 概念原型经 NASA 用语与 Gartner 2017
热榜普及"数字孪生"〔知识〕；2020s Sim2Real 成为自动驾驶/机器人
的产业刚需（市场锚 2025 约 $4.2B→2033 $18.7B，见家族 01 章，
方向锚带时效声明）。

## 核心问题

| 问题 | 状态 |
|------|------|
| Sim2Real 鸿沟（仿真 99 分的策略真世界不及格） | ❌ 未解：域随机化只是统计缓冲 |
| 孪生的投入产出（多贵的孪生配多贵的决策） | 🟡 逐案工程，无一般判据 |
| 训练仿真的等效性（模拟器课时能折多少真机课时） | ✅ 行业认证体系成熟（飞行模拟机分级） |
| 作战仿真的构设效度（红方怎么演才像红方） | 🟡 永久半解：对手建模是社会科学问题 |
| 孪生与真身的同步节拍（多快算"实时同步"） | 🟡 随应用分级，标准在收敛（ISO 23247 系） |

## 这支最美的一个事实

**阿波罗 13 号的救援方案是在仿真器里连夜"预演未来"后才敢上传的**——
三百多万公里外的真身不可触碰，替身替人类把错误先犯完。

## 假设与依赖

应用问题的相似判据（替身只需对所问问题够真）；封闭世界假设在
应用侧的代价最显眼（没建模的=结构性缺席）；认证与授信依赖
行业治理（飞行模拟机分级、军仿构设审查）。
