# 讲透仿真建模理论与技术 · "替身怎么写"（GB/T 41315 三级：仿真建模理论与技术）

> **这支负责的问题**：替身（模型）的语法与工艺。一支钉住：
> **模型即程序——建模语言的世界观（事件/进程/连续/混合/多主体）
> 决定你能表达什么，DEVS 普通话保证大家的模型能互相听懂。**

## 诞生

1950s Tocher 在英国联合钢铁公司用事件表推演产线（因"排队太复杂
解析不动"），催生三大语言：GPSS（Gordon/IBM, 1961）、SIMSCRIPT
（RAND, Markowitz 主理, 1962-63）、SIMULA（Dahl & Nygaard,
1966/67——为仿真发明 class/继承，面向对象由此诞生）。
1976 年 Zeigler《Theory of Modeling and Simulation》给全行业
立形式语法 DEVS；1990s 多范式建模（块图/状态机/Agent 混编）
随工具链成熟。

## 核心问题

| 问题 | 状态 |
|------|------|
| 离散事件模型的形式规范 | ✅ 已解（DEVS 七元组+封闭性，1976） |
| 连续/离散/混合的统一建模（多范式） | 🟡 工程成熟（Simulink/Modelica），理论统一未完成 |
| 多分辨率建模（同一对象不同颗粒度共存） | ❌ 未解：一致性维护是军仿界的经典难题 |
| 模型重用与互操作 | 🟡 FMU/HLA 走标准路线，语义漂移仍在 |
| 代理模型/元模型（仿真太贵再造"仿真的仿真"） | 🟡 与机器学习合流中，外推无保证 |

## 这支最美的一个事实

**任何耦合 DEVS 网络严格等价于一台原子 DEVS**（封闭性定理，1976）——
组合一万层，语法不变，分层建模因此可以递归实现。

## 假设与依赖

模型-实验-框架三分离（同模型跑不同实验）；连续侧的严格性全部
外包给数值方法（借 [讲透数学/讲透计算数学](../../../讲透数学/讲透计算数学/)）；
离散侧自带 DEVS 代数。

## 教材锚

- Cellier《Continuous System Modeling》；Banks 等《Discrete-Event
  System Simulation》
