# 讲透仿真科学技术基础学科 · "凭什么替"的数学（GB/T 41315 三级：仿真科学技术基础学科）

> **这支负责的问题**：替身凭什么能替代真身？一支钉住：**相似理论给"替"
> 判据，随机数给"签"，可信度理论给"信"——仿真的地基全在这三块数学里。**

## 诞生

四条根各自独立长成：量纲分析（Buckingham π 定理，1914）回答"缩比模型
的试验结果怎么换算到原型"；相似三定理在 20 世纪初由苏联学派
（基尔皮切夫等）集大成〔知识〕；蒙特卡洛数学随乌拉姆/冯诺依曼 1946
年方法与 1955 年 RAND 百万随机数表面世；系统辨识与可信度理论
（VV&A 的理论侧）随 1990 年代工程规范化成型。因的问题只有一个：
**不回答"凭什么替"，替身就只是动画。**

## 核心问题

| 问题 | 状态 |
|------|------|
| 随机数的质量与检验（1955 RAND 表→1998 MT19937→TestU01 大炮测试） | ✅ 工程可用；伪随机的理论边界仍开放 |
| 方差缩减的系统化（对偶/控制变量/重要性抽样/序贯法） | ✅ 已解，是性能工程杠杆 |
| 相似判据的完备性（多无量纲数同时匹配常物理上不可能） | ❌ 部分相似是常态，完备相似不可构造 |
| 可信度的量化（置信度→确认的度量理论） | 🟡 半解：V 有机器可查部分，A 无算法 |
| 真随机源（量子随机数）能否终结伪随机之争 | ❌ 进行中 |

## 这支最美的一个事实

**风洞里 1:10 的模型能替真机，靠的不是像，是雷诺数相等**——
π 定理说物理规律只认无量纲数，缩掉九成尺寸，判据照样成立。

## 假设与依赖

相似性假设（对所问问题相似）+概率公理（不确定性可分布封装）；
数学地基借概率论/数理统计/量纲分析，输出分析借统计推断。
