# 仿真科学技术思维技能（GB/T 41315 · 讲透仿真科学技术家族的抽象层）

## ① 何时用此分支（问题特征触发词）

1. 真系统**太贵/太慢/太危险/太唯一**，需要拿替身试错
   （坠机前学飞行、核试验替代、产线改造前排演）
2. "蒙特卡洛/随机模拟/抽样估计/方差缩减"——期望算不出就抽签
3. "排队/产线/物流/事件驱动"——离散事件仿真的地盘
4. "数字孪生/实时同步的仿真"——替身从一次性变成在线伴飞
5. "这个模型可信吗/验证/确认/VV&A"——学科身份问题来了
6. "半实物仿真/HIL/人在回路/实时仿真"——替身要接真硬件
7. "Sim2Real/仿真训练的策略到真世界掉分"——鸿沟问题
8. "保真度"之争——替身不是越像越好，是对所问问题够真

## ② 核心思维模式

- **替身眼**：昂贵/危险/唯一的决策场景先问"能不能造个可操纵的
  替身，在数字世界里便宜地犯错"
- **三元谓词眼**：保真度=模型×问题×容差，不是一维刻度——
  问新问题前先问旧相似判据还罩不罩得住
- **承诺分层眼**：算得准（统计/数值背书）/跑得出（现象级）/
  算得完（硬实时）/实验级（代理外推）——证据折扣四档不同
- **V-V-A 三分眼**：校验（解对方程没）可机器查、验证（选对方程没）
  是带条件的归纳、确认（此用途敢用没）永远是人类授信
- **方差优先眼**：蒙特卡洛的性能问题第一反应是砍方差
  （对偶/控制变量/重要性抽样），其次才是加机器

## ③ 工具箱（何时用什么）

| 工具 | 何时用 |
|------|--------|
| 蒙特卡洛估计+CLT 置信区间 | 高维期望/概率/积分；自带 ± |
| 方差缩减（对偶/控制变量/分层/重要性抽样） | 抽样太贵时先于加算力 |
| 事件表离散事件仿真（heapq/SimPy） | 排队/物流/产线/通信 |
| DEVS 七元组 (X,Y,S,δext,δint,λ,ta) | 要严格模型语义/多范式统一/组件化建模 |
| Little 定律 L=λW | 任何排队系统的免费自查不变量 |
| 连续系统积分（solve_ivp/定步长） | 物理演化；刚性方程走 BDF |
| 量纲分析/Buckingham π | 缩比物理试验的相似判据换算 |
| HLA/DIS/FMU 互操作标准 | 把多家仿真器连成一个系统 |
| 代理模型（GPR/Kriging/响应面） | 单次仿真太贵、要在线查询 |
| 域随机化+真传仿真 | Sim2Real 鸿沟的统计缓冲（不是消除） |

## ④ 常见误区与禁忌

- **把仿真当动画看**：单次运行=单次观测，不做重复/方差分析
  就下结论是入门级错误
- **保真度单维化**：说"高保真模型"而不说对什么问题、什么容差
  ——保真度是三元谓词，不是形容词
- **替身上问界外问题**：相似判据没覆盖的问题，答案静默失效
  （风洞模型对马赫数相似、对雷诺数失真）
- **把 A 当算法**：宣称"自动可信度评分/自动确认"的产品，
  卖的是证据页，许可证永远由人签发
- **宣称消除 Sim2Real 鸿沟**：封闭世界的缺席不可枚举，
  只有统计缓冲，没有零鸿沟
- **实时仿真看均值**：尾延迟才是真约束，99.9 分位超帧=作废
- **输入分布错了还引用输出区间**：方差区间只覆盖抽样噪声，
  不覆盖模型假设错误

## ⑤ 与相邻分支的判别表 + 组合接口

| 症状像… | 但去 | 判别 |
|---------|------|------|
| 数值积分/ODE 精度与稳定性 | 讲透数学/讲透计算数学 | 只要"算得准"→数值方法；要"替真系统做实验"→本家族 |
| 随机变量的数学本体 | 讲透数学/讲透概率论 | 概率论造地基，仿真用随机数盖楼 |
| 反馈控制/伺服/制导 | ../讲透控制科学与技术（同波在建） | 让真系统听话→控制；让假系统像真系统→仿真（HIL 处合流） |
| 多主体涌现/复杂系统 | 讲透信息科学与系统科学/讲透系统学 | 系统学问"涌现了什么"，本家族给模拟层工程纪律（VV&A/输出分析） |
| 大规模并行与算力 | 讲透高性能计算 · 讲透GPU与系统级 | 仿真负载=HPC/GPU 主战场，本家族出负载特征，那两家出并行方法 |
| 统计推断 | 讲透数学/讲透数理统计 | 输出分析=统计推断的直接应用，判别在"数据是替身产的" |

仿真×机器学习→可微仿真/神经仿真器/Sim2Real 训练；
仿真×控制→HIL 与数字孪生闭环；仿真×大模型→LLM 智能体社会仿真。
