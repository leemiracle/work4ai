# 信息安全技术思维技能（GB/T 41320 · 讲透信息安全技术家族的抽象层）

## ① 何时用此分支（问题特征触发词）

1. 「X 安全吗」/「怎么防住」——一切以**存在对手**为前提的问题
2. 加密、密钥、签名、证书、哈希、随机数怎么选/怎么用对
3. 协议/握手/认证流设计——消息几条、谁先说话、怎么防中间人
4. 漏洞、注入、内存安全、供应链（依赖被投毒怎么办）
5. 量子计算/Shor 算法/后量子迁移/RSA 退役时间表
6. 隐写、水印、内容溯源（藏得住 + 藏得无法证明）
7. 渗透测试、CVE/CVSS、等保/CC 测评——给安全发可复核的证
8. 威胁建模/零信任/纵深防御——架构级安全决策
9. 侧信道（时间/缓存/功耗泄漏）——实现层的安全

## ② 核心思维模式

- **敌手眼**：先问「对手是谁、预算多少、要什么、能等多久」——
  没有敌手模型的安全讨论是空谈（对手模型含未来到达的量子机）
- **差值眼**：安全=防御−对手能力，且随时间自动衰减——
  一切密钥/算法/证书都该有保质期
- **三柱眼**：机密性/完整性/可用性/可证明互相不可还原——
  听到「安全」先拆柱，逐柱配手段
- **归约眼**：新方案第一个问题「安全性外包给了哪个假设」——
  假设链每环都要有独立研究史
- **组合眼**：失守几乎都在组合处（重用/拼接/上下文）——
  「各自安全」的组件保持结构性怀疑
- **爆炸半径眼**：单点失守会烧多大？最小权限/前向保密/纵深防御
  全是同一问题的不同解

## ③ 工具箱（何时用什么）

| 工具 | 何时用 |
|------|--------|
| AEAD（AES-GCM/ChaCha20-Poly1305） | 要加密——认证加密一体，永不裸加密 |
| HMAC/签名（Ed25519/ML-DSA） | 要防篡改/防抵赖 |
| secrets + hmac.compare_digest | 随机数生成与标签比较（恒定时间） |
| 重合指数+卡方 | 古典多表密码自动破译（家族实验） |
| 威胁建模（STRIDE/攻击树） | 设计期枚举威胁——结构化地想，非机械地算 |
| ProVerif/Tamarin | 协议逻辑洞的形式化搜索 |
| Fuzzer（AFL++/libFuzzer）+ sanitizer | 实现层漏洞的有界搜索 |
| 依赖扫描/SBOM/sigstore | 供应链制品完整性 |
| CVSS 向量计算 | 风险**沟通**（不是风险测量） |
| toy LWE 数十行 | 后量子原语的直觉（误差预算三角） |

## ④ 常见误区与禁忌

- **「绝对安全」词汇病**：安全只能相对（敌手/游戏/假设/优势四元组）——
  脱离四元组的断言是修辞
- **自研密码**：安全性外包给标准是纪律不是怯懦——你的秘密只有 key
- **加密当认证用**：密文可篡改（比特翻转）——加密≠认证，
  2000s 的事故学费已缴过
- **一次性材料用两次**：OTP/nonce/IV 重用是结构性灾难
  （两次使用泄漏明文异或——实验第 2 部分亲测）
- **优化进安全代码**：分支/查表/提前退出=侧信道——
  安全代码的性能目标是恒定不是最快
- **「没被攻破=安全」**：智能对手下「未发现攻击」不能归纳为
  「不存在攻击」——结论一律挂证据折扣（定理/验证/实验三档）
- **把 CVSS 分当物理量**：分数与真实可利用性弱相关——
  它是沟通汇率不是测量仪器
