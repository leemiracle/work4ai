# 讲透密码学 · 让保密变成数学（GB/T 4132010 · 家族正主）

> **这支负责的问题**：没有预先共享秘密的双方，如何在公开信道上
> 安全通信？一句钉住：**密码学=把保密义务压缩到 n 比特密钥上的数学
> ——算法全部公开，秘密只剩一把钥匙。**
> GB/T 4132010，由军事学 8304050 迁码而来——**密码学的国标正主在本支**
> （[讲透军事学](../../../讲透军事学/README.md) 军事情报学侧注
> 「密码学 见 4132010」即指向此，波3 就低链）。

## 诞生

凯撒移位（约前 50 年）→ Kerckhoffs 六原则（1883：算法可泄，只保密钥）
→ **香农《保密系统的通信理论》**（1949）：密码学变数学——完美保密
与 Shannon 界 |K|≥|M| → **Diffie-Hellman**（1976）与 **RSA**（1978）：
公钥革命，密钥分发死结被数论解开 → DES 1977/AES 2001（公开竞赛标准）
→ 后量子 FIPS 203/204/205（2024-08-13 终版）。因的问题：
外交与军事情报的保密需求（两千年），与 1970s 网络化通信的密钥分发危机。

## 核心问题

| 问题 | 状态 |
|------|------|
| 无条件保密何时可能 | ✅ 已解（Shannon 1949：OTP 且密钥≥明文） |
| 公钥密码是否存在 | ✅ 已解（DH 1976 论证/RSA 1978 构造） |
| 新方案安全性如何挂靠老难题 | ✅ 方法成熟（归约证明，2000s 成教科书通用语） |
| 量子对手下的公钥 | ✅ 算法标准化（2024）；❌ 全球迁移进行中（家族 01 章） |
| 单向函数是否存在 | ❌ 未解（整个学科的根假设，P≠NP 未证） |

## 这支最美的一个事实

一次一密完美保密，但 Shannon 定死了代价：**密钥不得短于明文**——
无条件安全与规模化通信在 1949 年就被证明不可兼得；
现代密码学全部家当，都建立在「退一步，只赌对手算力不够」之上。
