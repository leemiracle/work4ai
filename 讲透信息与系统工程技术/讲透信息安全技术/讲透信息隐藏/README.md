# 讲透信息隐藏 · 藏得住，还要藏得无法证明（GB/T 4132035）

> **这支负责的问题**：如何让「通信正在发生」这件事本身成为秘密？
> 一句钉住：**密码学保护消息内容，信息隐藏保护消息的存在性
> ——最高境界不是解不开，而是无法证明有东西可解。**

## 诞生

隐写术（steganography，希腊语「掩盖的书写」；希罗多德记蜡板与
剃头奴隶头皮的故事——学科的两千年前传）→ **Simmons 囚犯问题**
（1983）：Alice/Bob 通信被狱警 Wendy 全程监听——她读得懂却
**证明不了**确有隐藏消息——信息隐藏由此变成信息论问题（冷战
核查条约的隐蔽信道是真实动因）→ 数字水印（Cox 等 1997 扩频水印）
→ 隐写分析军备竞赛（2000s 统计检测成熟）→ **AI 时代复兴**
（2023-2024：密码学不可检测水印理论突破+生成内容溯源工程部署）。

## 核心问题

| 问题 | 状态 |
|------|------|
| 隐藏的存在性安全如何定义 | ✅ 已解（Cachin 1998：ε-安全=检测优势的信息论界） |
| 隐写分析的统计检测 | ✅/🟡 检测器与嵌入器军备竞赛，无终态 |
| 抗破坏的鲁棒水印 | 🟡 版权场景可用；对齐攻击/再生成攻击仍开放 |
| 生成内容（AI 输出）的可证明水印 | ✅ 理论突破（2023 不可检测水印）；🟡 部署与对抗进行中 |
| 数字版权管理（DRM）的最终有效性 | ❌ 模拟孔：内容终须呈现给人，重录即绕过 |

## 这支最美的一个事实

Simmons 1983 把谍报手艺变成信息论：狱警读遍全部通信却给不出
「藏了消息」的证据——**「安全」的对象从内容上升到了存在性**；
四十年后 AI 生成内容的水印，让「不可证明性」第一次成为
大规模部署的工程指标。
