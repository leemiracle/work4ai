# 讲透网络安全 · 共享的基础设施是共享的攻击面（GB/T 4132025）

> **这支负责的问题**：当全世界共用一套协议地基（TCP/IP/DNS/BGP），
> 攻击者与防御者站在同一块地上怎么办？一句钉住：**网络安全=
> 在没有设计安全的地基上，事后补建治安——因为 1970s 的互联网
> 把「互信的科研机构」当成了对手模型。**

## 诞生

ARPANET 时代假设「参与者皆可信」→ **Morris 蠕虫**（1988-11-02，
互联网第一次大规模感染，CERT/CC 因它诞生）→ 防火墙与包过滤
（1980s 末-90s）→ 入侵检测 → **Kaminsky DNS 缓存投毒**（2008）
与 BGP 路由劫持的长期暴露 → DDoS 即服务时代 →
**零信任架构**（NIST SP 800-207，2020：「网络位置≠信任」）。
因的问题：网络规模超出信任模型的适用范围。

## 核心问题

| 问题 | 状态 |
|------|------|
| 边界防御范式 | ✅ 成熟又失守——「城堡模式」被云与移动办公淘汰 |
| DDoS 缓解 | 🟡 anycast/清洗中心缓解；❌ 放大攻击与僵尸网络根除无解 |
| 路由与命名基础设施的信任 | 🟡 RPKI/DNSSEC 部署爬坡数十年，未全覆盖 |
| 零信任架构 | ✅ 框架成型（2020）；🟡 迁移是十年级工程 |
| 匿名与可追踪的平衡 | ❌ 价值冲突型问题，无技术终解 |

## 这支最美的一个事实

1988 年 11 月 2 日，一个研究生写的实验蠕虫因重传染率参数设错，
在数小时内瘫痪当时互联网的约十分之一主机——**互联网第一次
集体意识到「网络是共享的攻击面」**；事故催生的 CERT/CC
协调中心，是全人类安全响应体系的第一块砖。
