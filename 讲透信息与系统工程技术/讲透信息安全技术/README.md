# 讲透信息安全技术 · 让信息在敌意环境里存活（GB/T 41320）

> **信息安全 = 让信息在敌意环境里存活**：机密性（Confidentiality，不该看的人看不到）、
> 完整性（Integrity，没人能悄悄改）、可用性（Availability，该用时用得上）三根柱子
> ——外加第四件事：**证明你值得信任的工程**（测评、审计、形式化证据）。
> 它是极少数以「存在智能对手」为公理的工程学科：别的工程与自然搏斗
> （自然不针对你），本家族与「会读你的论文、会花十年预算、会在你的
> 供应链里睡三年」的对手搏斗。**安全性不是系统的属性，是你的系统
> 与对手能力之间的差值——这个差值会随时间自动变小。**
>
> GB/T 13745：41320（二级学科，信息与系统工程技术 413 之下）。
> 宇宙：[讲透信息与系统工程技术](../README.md)。
