# 00 · 体系结构：三大发源与一条「对手升级」暗线

> **本章回答五问之一（家族层）：整个体系结构长什么样。**
> 信息安全技术不是从公理推出来的学科，而是**三场不同战场的危机
> 各自长出的枝干**——外交与军事情报的密码战场（密码学）、
> 分布式系统的握手战场（安全协议）、计算机系统本身的保护战场
> （系统与工程）——在「存在敌手」这个公理下汇成一棵树。
> 另有一条贯穿 2500 年的暗线：**对手模型的一路升级**。

---

## 一、这门学科怎么来的（②怎么产生的）

### 1.1 发源一：密码术变密码学——从手艺到数学（前 50 年-1978）

- **凯撒移位**（约公元前 50 年，高卢战报）：字母循环移位。此后近 1900 年，
  密码是**替换与重排的手艺**——多表替换（重复密钥多表密码，1553 年 Bellaso
  提出，后世误挂在维吉尼亚名下）曾被称为「不可破译之密码」
  （le chiffre indéchiffrable），直到 Kasiski 1863 年用**重合分析**拆穿
- **Kerckhoffs 六原则**（1883，《军事密码学》）：其中第二条成为整个学科
  的地基——**系统落到敌人手里也不应有损安全**：安全性只许依赖密钥的保密，
  不许依赖算法的保密
- **香农《保密系统的通信理论》**（Communication Theory of Secrecy Systems，
  1945 写成、1949 解密发表）：密码学从此是数学。两个结果影响至今：
  ①**完美保密**（perfect secrecy）存在——一次一密（OTP），密钥真随机、
  只用一次、不短于明文；②**Shannon 界**——完美保密必须 |K|≥|M|
  （密钥空间不小于明文空间）：**无条件安全的代价写进了信息论**，
  于是现实只能退而求「计算安全」
- **Diffie-Hellman**（1976，《密码学的新方向》）：公开信道上商定共享秘密——
  公钥革命开始；**RSA**（1978）给出第一个公钥加密与签名实现。
  密钥分发这个两千年的死结，被数论解开
- **工程化时代**：DES 1977 → AES 2001（公开竞赛选出的全球标准）→
  后量子（NIST 2016 全球征集 → 2024-08-13 三标准终版，见 01 章）

📖 **故事框**：1976 年，Diffie 和 Hellman 的论文没有给出能用的公钥方案——
只有一个存在性论证和一个离散对数密钥交换。数学界最初反应冷淡：
「这算什么结果？」两年后 RSA 落地，人们才明白 1976 年改变的不是
某个算法，而是**可能性本身**：从此「陌生人可以在众目睽睽之下
约定秘密」从矛盾修辞变成教科书第一章。安全的地基从「藏」
变成了「藏不住也没关系」。

### 1.2 发源二：协议之坑——最简单的消息交换（1978-）

密码原语对了，协议照样死。这条发源线的里程碑全是「翻车-补课」：

| 年份 | 事件 | 教训 |
|------|------|------|
| 1978 | Needham-Schroeder 认证协议发表 | 分布式认证的开山之作 |
| 1989 | BAN 逻辑（Burrows-Abadi-Needham） | 第一个协议**形式化分析**语言——证据不行了上逻辑 |
| 1996 | Lowe 用 CSP 模型检查发现 NS 公钥版中间人攻击 | 协议发表 **17 年后**被机器抓出致命漏洞——形式化方法首胜 |
| 1995-2018 | SSL 2.0 → SSL 3.0 → TLS 1.0/1.2/1.3 | 一部「每个版本死于上一个版本的教训」的演化史；1.3（2018）把前向保密与握手安全写死 |
| 2002-2014 | 填充预言机攻击（Vaudenay 2002）→ POODLE 等 | 「加密≠认证」的世纪补课（见 §六反直觉②） |

### 1.3 发源三：系统与工程——保护机器本身（1972-）

- **Anderson 报告**（1972，美国空军）：第一次系统论述计算机安全威胁模型
- **Saltzer-Schroeder 八原则**（1975，《计算机系统中的信息保护》）：
  最小权限、完全调解、机制经济性、失败安全默认……——**50 年后仍是
  系统安全设计的第一性清单**（系统安全支的正典）
- **TCSEC「橙皮书」**（1983，美国国防部）：第一个安全评估标准
  （保密等级 C1→A1），评估传统从此开始 → 1999 年国际化为
  **通用准则 Common Criteria**（ISO/IEC 15408）
- **Morris 蠕虫**（1988-11-02）：互联网第一次大规模感染——「网络是共享的
  攻击面」的觉醒事件，CERT/CC 因它成立（网络安全支的起点）
- **Thompson《对信任的反思》**（1984）：编译器后门思想实验——
  你审查了源码也未必信得过二进制（软件安全支的正典）
- 工程化补课：微软 SDL（2004）→ DevSecOps（2010s）→
  零信任架构（NIST SP 800-207，2020）

### 1.4 暗线：对手模型升级史（本学科的真正主线）

| 时代 | 对手模型 | 防御响应 |
|------|---------|---------|
| 古典-19 世纪 | 读信人（识字+耐心） | 换字、多表、重合分析 |
| 一战-二战 | 机器+国家实验室（Enigma vs Bletchley Park） | 机电密码机；**密码分析催生了计算机** |
| 冷战-1970s | 数学化的对手 | Kerckhoffs 原则、计算复杂度防御 |
| 1990s-2010s | 脚本小子→有组织犯罪→APT（高级持续威胁） | 深度防御、监测响应、威胁情报 |
| 2010s- | 国家级+「先窃取后解密」（harvest now, decrypt later）+ 供应链潜伏 | 零信任、供应链审计、形式化验证 |
| 2024- | + 未来量子计算机 | 后量子迁移（01 章） |

**对手升级是单向棘轮**：防御重建从不降低对手模型——这是本学科
与其他工程学科最大的结构性不同（详见 03 章「攻防不对称」）。

## 二、CIA 三柱与第四柱

| 柱 | 一句话 | 敌人想干什么 | 主手段 |
|----|--------|------------|--------|
| 机密性 Confidentiality | 不该看的人看不到 | 窃听、泄露 | 加密、访问控制 |
| 完整性 Integrity | 没人能悄悄改 | 篡改、伪造、重放 | MAC/签名、版本控制 |
| 可用性 Availability | 该用时用得上 | 拒绝服务、破坏 | 冗余、限流、备份 |
| （第四柱）可证明/可问责 | 证明你值得信任 | 「你凭什么让我信」 | 形式化验证、测评、审计、不可否认 |

> 三柱互相不可还原：加密再好不防删库（A 柱），签名再强不保密（C 柱）。
> 第四柱是工程学科的入场券：**安全主张必须可被第三方复核**——
> 这就是测评支与工程支存在的理由。

## 三、核心问题清单（③核心问题）

| 问题 | 状态 |
|------|------|
| 无条件保密何时可能 | ✅ 已解（Shannon 1949：当且仅当密钥真随机、只用一次、不短于明文） |
| 公钥密码是否存在 | ✅ 已解（DH 1976 论证+RSA 1978 构造；单向函数存在性仍开） |
| 「打破这个加密⇒解出那个难题」的归约 | ✅ 方法成熟（归约证明，标准方案标配） |
| 协议安全性可判定吗 | 🟡 有界会话数下可判定（模型检查实战）；无界情形不可判定 |
| 加密与认证统一 | ✅ 认证加密 AEAD 成熟（2000s；TLS 1.3 强制） |
| 量子对手下的公钥密码 | ✅ 算法已标准化（FIPS 203/204/205, 2024）；❌ 全球迁移未完（01 章） |
| 形式证明覆盖实现 | 🟡 密码原语的验证实现出现（HACL* 等）；侧信道与全栈验证仍开 |
| 软件无内存安全漏洞 | 🟡 内存安全语言重写推进中；存量 C/C++ 生态数十年 |
| 「足够安全」的度量 | ❌ 未解：评估等级、CVSS 分与真实风险的相关性长期受质疑 |
| 人因 | ❌ 未解：钓鱼仍是第一大入口，无工程解 |

## 四、假设与代价（④假设与代价）

1. **Kerckhoffs 假设**（算法公开，只保密钥）
   - 买到：可公开审计、标准化、规模化——**保密的东西越少，出错的面积越小**
   - 付出：算法必须经受全世界密码分析者的免费攻击（这也是红利：免费审计）
2. **计算安全假设**（对手算力有限+某难题真的难）
   - 买到：密钥可以比明文短亿倍（128 比特钥匙护 TB 级数据）
   - 付出：①安全是**相对的**（相对当前知识与算力）；②地基借自
     [讲透计算复杂度](../../讲透数学/讲透计算复杂度/)，而 P≠NP 未证——
     每个具体假设（大整数分解、离散对数、格问题）都可能**明天**倒下，
     RSA/ECC 已因量子确定性多项式算法（Shor 1994）被判死缓
3. **攻防不对称假设**（防御要赢在所有点，攻击只需赢一点）
   - 买到：诚实的设计框架（纵深防御、最小权限都是它的推论）
   - 付出：安全预算永远不饱和；「没出事」≠「安全」（看不见的攻击）
4. **信任根假设**（总有一块硬件/一段代码必须盲信）
   - 买到：信任链可以折叠到一个可审计的小核（TPM/安全启动）
   - 付出：根被攻破则全链塌（Thompson 1984 的永恒提醒：信任没有免费的第一环）
5. **理性人假设**（对手为收益攻击）
   - 买到：风险排序、经济学分析可用
   - 付出：面对纯破坏（黑客主义/战时）或无限预算对手失效

## 六、反直觉发现（⑥，至少记住这四条）

1. **一次一密完美保密，但密钥不短于明文**——Shannon 界 |K|≥|M|：
   信息论上无懈可击的加密**无法用于规模化通信**（密钥分发问题
   恰是它本要解决的）。完美与实用不可兼得，是 1949 年就写死的定理
   （本家族实验第 2 部分亲手验证）
2. **加密 ≠ 认证**——密文可被篡改而不被发现（比特翻转攻击）；
   「能解密的密文」不等于「对方发的密文」。这条认知世纪之交才普及
   （Bellare-Namprempre 2000 形式化；Vaudenay 2002 填充预言机实战演示），
   代价是二十年间的无数事故。今天答案是认证加密 AEAD 一体化
3. **格问题的「最坏情况→平均情况」归约**（Ajtai 1996；Regev 2005 LWE）：
   破一个**随机实例**就等于解**最难实例**——平均情况硬度有定理保证。
   这是密码学里罕见的奢侈品（RSA/ECC 只有启发式信心），
   也是后量子标准敢押注格的数学底气（01 章）
4. **绝大多数入侵不破密码**——现实攻击走实现缺陷、配置错误、
   供应链与人因；密码学原语被直接攻破的案例罕见。**学科最硬的部分
   不是最常被攻破的部分**——这条断层定义了 4132040/4132045 两支的存在

✨ **美之时刻 ①**：Diffie-Hellman 1976——两个从未谋面的人，
在全世界都能听的信道上，大声商量出一个谁都算不出的秘密。
没有密使、没有预约、没有预先共享任何东西。两千年来「密钥必须
先秘密送达」的铁律，被一个模幂运算的交换律 quietly 终结。
数学上它只是一步 (g^a)^b=(g^b)^a；文明史上它把「信任」从物流问题
变成了数学问题。

## ✍️ 练习

1. **三柱自检**：任选一个你用的系统（网盘/聊天工具/门禁），各举一个
   机密性、完整性、可用性的威胁，并指出对应防御——再找一条
   「三柱之外」的需求（不可否认？可审计？），体会第四柱为何存在
2. **Kerckhoffs 换算**：把「算法保密」的安全方案换算成攻击面——
   内部人员、逆向工程、标准迭代各泄漏一次算法的概率，乘起来
   与「只保密钥」比较。写出你的估算假设

   与「加密≠认证」是同一族问题（都是**通过公开可观测的量泄漏结构**）？

## 📌 收束

信息安全技术的体系结构=**一场数学化（香农）+ 一场公钥革命（DH/RSA）+
一场协议与工程的百年补课（NS→TLS；橙皮书→零信任）**，
暗线是对手模型的单向棘轮。三柱定对象，归约定地基，
不对称定预算——去 [01-近五年创新](01-近五年创新.md) 看这条主线
正在动什么：一场提前二十年的大迁移。

**🧠 认知升维（这章给了你什么新眼睛）**：
- **敌手眼**：看到任何系统先问「对手是谁、预算多少、要什么」——
  没有敌手模型的安全讨论都是空谈
- **差值眼**：安全不是属性是差值（你的防御 − 对手能力），且自动衰减——
  一切安全决策都是「现在值多少」的决策
- **三柱眼**：听到「安全」先拆柱——机密性/完整性/可用性/可证明，
  四个词各自独立，各自的敌人与手段都不同
