# 控制科学与技术思维技能（GB/T 41310 · 家族抽象层）

> 定理正主在 [讲透信息科学与系统科学/讲透控制理论](../../讲透信息科学与系统科学/讲透控制理论/)（12030）；
> 本技能管**工程实现与装置层**：整定、选型、实时、认证、落地。

## ① 何时用此分支（问题特征触发词）

1. "这个回路怎么调/整定/超调大/稳态差"——单回路工程问题
2. "选什么传感器/执行器/PLC/控制器硬件"——装置选型
3. "控制周期该多快/抖动/延迟对环路的影响"——实时性预算
4. "串级还是前馈？比值还是超驰？"——回路结构选型
5. 导航制导、惯性/组合导航、轨迹跟踪与命中
6. 机电一体化：机械刚度/间隙/谐振 vs 控制带宽
7. 机器人控制部署：关节伺服、力控、阻抗/导纳、sim2real
8. 产线/过程自动化：批处理、ISA-88/95、黑灯工厂、自动化悖论
9. 学习控制（RL/神经策略）要上真机：安全过滤器、认证三道门
10. 4-20mA/现场总线/OPC-UA/HIL/数字孪生——集成与验证

## ② 核心思维模式

- **回路眼**：任何自动机器先找传感-计算-执行三件套+时钟；
  找不到环它就不是自动的
- **最坏情况眼**：工程的品质标准是"最坏多糟"不是"平均多好"——
  饱和、死区、噪声、最坏延迟全要进设计
- **结构优先眼**：性能问题先查结构（该串级吗？前馈测得到吗？），
  再调参数——顺序反了是白工
- **时钟眼**：晚到的正确答案就是错误答案；实时性是物理约束
  不是性能优化
- **许可证眼**：机械限电、时钟限带宽、结构限鲁棒——
  柔性（算法/软件）的努力不能越过刚性的许可
- **证据眼**：装置界的通行证不是精度是证据链——
  验收试验、标准符合性、安全等级（SIL）

## ③ 工具箱（何时用什么）

| 工具 | 何时用 |
|------|--------|
| PID（+抗饱和/微分滤波） | 默认起手式：无模型、鲁棒、车间通用（九成回路） |
| ZN 整定/继电自整定 | 要"任何人可复现"地调参数时 |
| 串级/前馈/比值/超驰结构库 | 扰动快/可测/异常工况需要自动切安全侧 |
| 频域验证（裕度/带宽） | 回路会不会振、能多快——进真机前必查 |
| 卡尔曼滤波/状态估计 | 状态测不到、测量噪声大、多源融合 |
| MPC（含数据驱动 deePC） | 有约束、有多变量耦合、模型/数据可用 |
| CBF-QP 安全过滤器 | 学习策略/遗留控制器要外挂安全网 |
| HIL/数字孪生 | 真机前的验证与回归证据链 |
| WCET/抖动预算表 | 选控制周期与算力、排查环路不稳的非算法原因 |
| ISA-88/95 分层模型 | 全厂集成、批处理、层级责任划分 |

## ④ 常见误区与禁忌

- **把理论保证当工程现实**：定理假设无噪/线性/无饱和——
  进真机先过饱和、死区、延迟三关
- **最优化执念**：最优依附模型，模型必有错；鲁棒的简单 > 脆弱的最优
  （车间里 PID 常赢 LQR）
- **连续设计直接数字化**：采样延迟/量化/抖动会吃掉裕度——
  Z 变换与数字重设计是必经步骤
- **梯形图"土"所以淘汰**：它是为凌晨两点的电工设计的——
  读者工况优先于语言先进性
- **盲信仿真通过**：sim2real 缺口没有数字源；仿真=左岸，
  验收试验才是终审
- **忽视单位与量程**：工程事故的经典来源——%开度 vs 流量、
  工程量 vs 原始 ADC 值，换算错误比算法错误多十倍
- **给学习控制器直接上产线**：先过 sim2real/实时/认证三道门，
  或外挂 CBF 安全过滤器
