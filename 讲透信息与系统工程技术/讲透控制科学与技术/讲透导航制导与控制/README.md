# 讲透导航制导与控制 · 把自己运到 B 并命中（GB/T 41310 三级：导航制导与控制）

> **这支负责的问题**：飞行器/舰船/车辆如何**知道自己在哪（导航）、
> 决定去哪（制导）、稳住自己（控制）**——一句钉住：
> **导航答"我在哪"，制导答"往哪去"，控制答"怎么稳"——三问一体，
> 全部要实时、自主、在无人兜底的极端环境里完成。**

## 诞生

1944 年 V-2 火箭首次把陀螺+加速度计装上弹体（惯性器件雏形）；
1950s 麻省理工 Draper 团队造出实用**惯性导航系统（INS）**——
北极星导弹与核潜艇的心脏；1960 年卡尔曼滤波发表，组合导航有了
理论引擎；1969 年阿波罗 AGC 把制导-导航-控制装进 4KB 内存的
实时计算机，人类精确落在月球静海。

## 核心问题

| 问题 | 状态 |
|------|------|
| 纯惯性自主导航（无外部信号） | ✅ 已解（1950s Draper；潜艇水下 90 天公里级） |
| 惯性/卫星/天文多源组合（卡尔曼） | ✅ 已解（1960 起，现代标配；深空用脉冲星等新锚 2010s-） |
| 制导律（比例导引等） | ✅ 已解（比例导引 1940s-50s，至今仍是防空主流） |
| GNSS 拒止环境导航 | 🔄 前线（干扰/欺骗下的视觉/地磁/量子惯性组合 2020s-） |
| 全自主等级与失控恢复 | ❌ 未解（自主性分级与责任边界，与 C2 支共担） |

## 这支最美的一个事实

惯性导航是**纯数学的航位推算**：陀螺测角速度积分得姿态、
加速度计积分得速度与位置——**不依赖任何外部信号**；
核潜艇在水下潜航九十天不上浮、不通讯，仍能知道自己在哪里，
靠的是把"二重积分"做到了机械与算法的极致。

## 假设与依赖

惯性器件误差慢漂（需外部源或机动观测校正）；重力场模型已知
（惯性导航测的是"比力"，要扣重力）；制导-控制回路时间尺度分离
（制导慢环给指令、控制快环跟踪）。依赖理论家族的卡尔曼滤波
（12030·状态估计支）与航天动力学。
