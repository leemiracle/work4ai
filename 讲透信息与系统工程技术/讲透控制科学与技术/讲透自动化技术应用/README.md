# 讲透自动化技术应用 · 按行业落地的总装厂（GB/T 41310 三级：自动化技术应用）

> **这支负责的问题**：把前七支的能力**装进具体行业的具体流程**——
> 过程自动化（石化/电力/冶金）、工厂自动化（汽车/半导体）、
> 楼宇/农业/物流——一句钉住：**技术不解决问题，工程才解决问题：
> 本支研究"这套环、这条产线、这个行业、这些人"怎么咬合。**

## 诞生

1913 年福特流水线是自动化前传（人肉自动化）；1962 年英国 ICI
化工厂 DDC 开连续过程数字化先河；1970s-80s 汽车焊装线机器人化、
DCS（集散控制系统）定型工厂架构；1990s-2000s 半导体 300mm 晶圆厂
把"黑灯工厂"从口号做成现实（全自动物料+整厂调度）；
2010s- 工业互联网/工业 4.0 把层级金字塔向网络化改造。

## 核心问题

| 问题 | 状态 |
|------|------|
| 连续过程控制的大规模集成（DCS） | ✅ 已解（1975 Honeywell TDC2000 起，标准架构） |
| 批处理标准化（ISA-88 配方模型） | ✅ 已解（1995 标准，跨行业通用语法） |
| 企业-控制系统集成（ISA-95 五层） | ✅ 已解（2000 标准，ERP-MES-PLC 的世界语） |
| 全局优化（单回路最优≠全厂最优） | ❌ 未解（实时调度+多层优化的联合求解仍靠经验分层） |
| 自动化悖论（人因：越自动越需要人） | 🔄 持续（Bainbridge 1983 至今的方法论课） |
| 黑灯工厂的极限（哪些环节永远要人） | 🔄 前线（2020s，与 C2 支的放权问题同构） |

## 这支最美的一个事实

Bainbridge 1983《自动化的讽刺》（Ironies of Automation）：
**你把容易的都自动化了，剩下的全是难的**——人只处理最异常的工况，
却因平时无事可做而技能荒废，真到异常时恰是最没准备的时刻。
这篇论文精准预言了四十年的航空与工业事故模式。

## 假设与依赖

行业流程可标准化（ISA-88/95 的前提是"流程可写成配方"）；
层级时钟与责任分离（03 章递阶刚性）；人有且必须有位（监控、
例外处置、问责——自动化改变人的工作内容而非取消岗位）。
依赖前七支全部能力 + 行业工艺知识（know-how 在行业侧）。
