# 讲透控制系统仿真技术 · 闭环的飞行前体检（GB/T 41310 三级：控制系统仿真技术）

> **这支负责的问题**：真机又贵又危险，**先把控制闭环在数字/半实物
> 替身上跑通**——一句钉住：**仿真是控制系统的"飞行前体检"：
> 让错误死在仿真里，而不是死在装置上。**

## 诞生

1960s 阿波罗计划：登月舱模拟器让宇航员在地面练出"最后 12 秒"
的肌肉记忆；航空模拟器工业同期成型。1980s 汽车电子把
**硬件在环（Hardware-in-the-Loop, HIL）**变成标配——真控制器、
假对象（实时数学模型），量产前每版固件跑回归。

## 核心问题

| 问题 | 状态 |
|------|------|
| 实时仿真（步长与真实时钟锁死） | ✅ 已解（实时 OS+定步长求解器，1970s-） |
| HIL 台架方法学 | ✅ 已解（车规/航空认证证据链的标准生产方式） |
| 模型验证与确认（V&V：模型多像才算像） | 🔄 部分已解（一致性检验有法，"够用性"判断仍靠经验） |
| sim2real 差距定界 | ❌ 未解（物理毛边无数字源——家族 04 章裂缝①） |
| 数字孪生（在线孪生+双向数据流） | 🔄 前线（2010s-，工业 4.0 旗舰词） |

## 这支最美的一个事实

阿波罗 13 号服务舱爆炸后，地面工程师**用登月模拟器连夜验证了
返回方案**再上传给宇航员——仿真系统在真实事故里当了"平行宇宙"：
**那条世界线里本会死人的错误，先在模拟器里死了一遍**。

## 假设与依赖

仿真模型的误差结构已知（哪可信哪不可信要明示）；
实时步长内算得完（与家族 04 章走廊⑤共享约束）；
仿真可信度≠模型精确度——"目的合适"（fit-for-purpose）是本支的
第一判断准则。依赖仿真科学技术（41315）的平台方法。
