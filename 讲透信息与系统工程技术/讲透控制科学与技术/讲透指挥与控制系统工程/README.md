# 讲透指挥与控制系统工程 · 体系级的大闭环（GB/T 4131015 指挥与控制系统工程）

> **这支负责的问题**：当"被控对象"从一台机器变成**多传感器、
> 多决策节点、多执行单元的整个体系**时，控制工程怎么做——
> 一句钉住：**单回路控机器，C2 控体系：让"观察-判断-决策-行动"
> 本身成为一个被工程化的闭环（OODA）。**

## 诞生

1958 年美军 SAGE（半自动地面防空系统）上线——MIT 林肯实验室
把雷达、电话线、显示器和人类军官连成第一台**实时计算机系统**，
本支随之诞生：问题从"稳住一个物理量"变成"在对抗、延迟、
信息不完全下组织体系响应"。

## 核心问题

| 问题 | 状态 |
|------|------|
| 多传感器数据融合 | ✅ 已解（JDL 融合模型，1970s-90s 定型） |
| 实时指挥决策支持 | ✅/🔄 部分已解（规则系统成熟，自主决策在前线） |
| 人机权限分配（武器放权） | ❌ 未解（技术与法律交织，见家族 00 章悬而未决） |
| 抗毁与降级体系设计 | 🔄 前线（分布式 C2、马赛克战概念 2010s-） |
| 对抗环境下的 OODA 加速 | 🔄 前线（博弈与控制交叉） |

## 这支最美的一个事实

SAGE 为了防空造出的实时联网订票/调度技术，直接孵化了民航
订座系统 SABRE——**军用 C2 工程是整个商用实时计算产业的父系**。

## 假设与依赖

通信延迟有界但不可控；传感器各源误差结构可建模；
决策环里永远有人（责任层不可删除——家族 03 章递阶刚性）。
依赖通信工程（传得来）、数据融合（看得清）、决策论（选得对）。
