# 讲透自动化仪器仪表与装置 · 控制系统的感官与肌肉（GB/T 41310 三级：自动化仪器仪表与装置）

> **这支负责的问题**：闭环的硬件底座——**传感器怎么测得准、
> 变送器怎么传得稳、执行器怎么动得狠、控制器装置怎么靠得住**——
> 一句钉住：**算法再聪明，也要住在仪表和执行器的世界里：
> 4-20mA、防爆认证、量程迁移，这些"低科技"才是环的骨架。**

## 诞生

1930s-50s 气动仪表时代：3-15 psi 气信号驱动过程工业；
1950s-70s 电动化：**4-20mA 电流环**成为模拟信号的世界语；
1962 年 DDC、1969 年 PLC（Modicon 084，Morley 团队）——
**控制从仪表柜搬进可编程装置**；1980s-2000s 智能仪表
（HART/现场总线）把诊断能力装进表里。

## 核心问题

| 问题 | 状态 |
|------|------|
| 恶劣环境下的精确测量（温漂/老化/振动） | ✅/🔄 已解+持续（补偿方法成熟，新材料在前线） |
| 本质安全/防爆（化工矿井的能源受限信号） | ✅ 已解（本安栅标准成套） |
| 信号标准与互操作（4-20mA→现场总线→OPC-UA） | ✅ 每代已解（迁移永远在进行时） |
| 阀门与执行器的非线性（死区/滞环/粘滑） | 🔄 持续（定位器补偿成熟，"最后一纳米"仍在打仗） |
| 自诊断与预测性维护 | 🔄 前线（智能仪表+边缘计算 2010s-） |

## 这支最美的一个事实

**4-20mA 电流环的"活零点"**：信号与供电共用一对线，正常量程
从 4mA 起步——**断线时电流掉到 0，读数 <3.6mA 自动报"断线故障"**。
一个 1950s 的模拟标准活到工业 4.0，因为"断线自检"这个功能
至今无可替代。

## 假设与依赖

信号的物理载体（电流/气压/报文）在环境应力下可辨识；
量程与精度的三角关系（量程越大精度越低）被诚实申报；
防爆等级与环境分区匹配（区域 0/1/2）。依赖传感物理、
微电子与通信协议栈。
