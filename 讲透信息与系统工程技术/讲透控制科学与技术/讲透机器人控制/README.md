# 讲透机器人控制 · 从关节伺服到全身控制（GB/T 4131050 机器人控制）

> **这支负责的问题**：机器人这个"多关节、强耦合、要碰世界"的对象
> 怎么控——一句钉住：**机器人控制的三重奏：位置控制（别处别去）、
> 力控制（别捏碎）、阻抗控制（该硬时硬、该软时软）。**

## 诞生

1961 年 Unimate（Devol 专利、Engelberger 商业化）上线 GM
压铸线——第一台工业机器人，本质是**倒装的 CNC 伺服**；
1970s Stanford Arm 把轨迹规划与关节控制合流；1985 年 Hogan
提出**阻抗控制（impedance control）**——控制"力与位置的关系"
而不是力或位置本身，机器人才学会"温柔地碰世界"；
2022-2026 人形机器人浪潮把全身控制（whole-body control）
推上 01 章四热线的主战场。

## 核心问题

| 问题 | 状态 |
|------|------|
| 关节伺服（高速高精位置控制） | ✅ 已解（CNC/伺服百年积累，μm/亚毫米级） |
| 计算力矩/逆动力学控制 | ✅ 已解（1970s-80s，非线性解耦标准化） |
| 阻抗/导纳控制（柔顺交互） | ✅ 已解（Hogan 1985 起，协作机器人标配） |
| 接触丰富操作（装配/插销/灵巧手） | ❌/🔄 未解（接触-脱离-再接触的混杂动态是当前最硬核） |
| 全身控制（人形/移动操作，实时 MPC） | 🔄 前线（2020s，算力与算法双线竞赛） |
| 学习策略的真机部署（sim2real+安全） | 🔄 前线（家族 01 章三道门的旗舰现场） |

## 这支最美的一个事实

现代协作机器人能在 **10ms 内完成"刚→柔"切换**：无碰撞时是
钢一样的位置控制，碰到人瞬间切换为柔顺的力/阻抗控制——
**同一副机械身躯，靠控制律在两种"性格"之间瞬间换魂**，
这就是它敢和人并肩工作的全部底气。

## 假设与依赖

动力学模型（质量阵/重力项）大体已知（模型误差由高增益+鲁棒项兜住）；
关节力矩可测或可估（力控的前提）；
控制频率远高于机械谐振（kHz 级环 vs 百 Hz 级共振）。
依赖机电一体化支（本体）、应用理论支（伺服方法）。
