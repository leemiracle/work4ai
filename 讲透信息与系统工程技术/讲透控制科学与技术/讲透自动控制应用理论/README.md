# 讲透自动控制应用理论 · 车间里的控制理论（GB/T 41310 三级：自动控制应用理论）

> **这支负责的问题**：把 12030 的定理翻译成车间可用的设计方法——
> 整定、串级、前馈、比值、超驰……一句钉住：**理论说"反馈能稳"，
> 本支回答"周一早上八点、在真装置上、由这个班的运行工，怎么把它调稳"。**

## 诞生

1922 年 Minorsky 船舶自动舵——观察熟练舵手"抄"出 PID；
1942 年 Ziegler & Nichols 发表整定法则——**一步实验+一张表**，
把回路设计从工程师的直觉变成任何人可复现的规程；
1984 年 Åström & Hägglund 继电自整定——同一实验变成按钮。

## 核心问题

| 问题 | 状态 |
|------|------|
| 无模型的回路参数构造（ZN 法） | ✅ 已解（1942，统治八十年） |
| 自整定/自适应整定产品化 | ✅ 已解（1984 继电法起，DCS/PLC 标配） |
| 回路结构选型方法（串级/前馈/比值/超驰） | ✅ 已解（教科书定型，结构库见家族 03 章） |
| 非线性补偿（阀特性/粘滑/死区） | 🔄 部分（多靠工程诀窍，无统一方法） |
| 数据驱动整定与回路性能监控 | 🔄 前线（2020s，与家族 01 章方向一同线） |

## 这支最美的一个事实

ZN 法则：让回路自激振荡一下，读两个数（临界增益/临界周期），
查一张两位数的表——**1942 年的一行公式至今是很多控制器的出厂默认值**。

## 假设与依赖

对象局部可用线性近似；执行器饱和可由抗饱和兜住；
结构选型依赖扰动可测性（前馈）与时间尺度分离（串级副环快 3 倍以上）。
依赖仪表支供测量、理论家族（12030）供判稳依据。
