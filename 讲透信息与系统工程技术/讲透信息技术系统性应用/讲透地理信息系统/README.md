# 讲透地理信息系统 · 把"哪里有什么"变成可计算对象(GB/T 4133010)

> **定位句**:GIS 支负责空间数据的采集、存储、管理、分析与可视化成套体系——
> 它把人类最古老的 信息技术(地图)变成数据库+分析引擎+服务,
> 回答的问题从"这是什么地方"升级为"哪里在发生什么、哪里将要发生什么";家族:[讲透信息技术系统性应用](../README.md)。

## 诞生

**Roger Tomlinson,1963,加拿大土地清查(Canada Land Inventory)**:
几十种土地专题图叠加分析,人工描图需要几百人年;他说服农业部用计算机造出
**CGIS——世界第一个地理信息系统**。谱系:哈佛 SYMAP(1964)/ODYSSEY;
McHarg《Design with Nature》(1969)图纸叠加蓝图;ESRI(1969/ARC/INFO 1981)
商用化;OGC(1994)立标准;Google Maps(2005)装进口袋,Web Mercator 成事实标准。

## 核心问题(已解决/未解决)

- 球面如何在平面/计算机中表示?——**已解决(否定式)**:等角/等积/等距不可
  兼得,投影=三选二的折衷(Gauss 证明无等距映射)
- 空间数据怎么组织与索引?——**已解决**:弧-节点拓扑、R 树(Guttman 1984)、
  四叉树、瓦片金字塔,全部工业化
- 叠加分析/地图代数?——**已解决**:Tomlin 制图建模(1980s),GIS 的 Hello World
- 可变面元问题 MAUP(Openshaw 1984)——**原则上未解决**:同一数据换聚合单元,
  结论可反号;只能多尺度披露,不能算掉
- 语义互操作——**未解决**:格式转换≠语义对齐,两图层的"道路"是否同义
  需人终审(01 章 LLM agent 时代反而更尖锐)

## ✨ 这支最美的一个事实

格陵兰(216.6 万 km²)在 Web Mercator 上看起来与非洲(3037 万 km²)同大甚至更大,
**实为 1/14**——失真因子 sec²(纬度),60°N 放大 4 倍、75°N 约 15 倍;
全球默认底座的投影选择,悄悄重塑了 20 亿人对世界形状的直觉(家族实验二可复算)。

## 假设与依赖

- 依赖:测绘/大地测量提供基准(椭球/水准/ITRF;本体归 GB/T 420,宇宙未建,待办)
- 假设:矢量边界精确(测量有误差);栅格格内均匀(30 m 一格掩盖格内一切);
  图层语义一致(概念不承诺)
- 代价:结论随尺度变(MAUP);Web 底座极地失语(±85.05° 切割)
