# 讲透全球定位系统 · 把星空变成标尺(GB/T 4133020)

> **定位句**:GNSS 支负责"任何地点、任何时刻,我在哪、现在几点"——24+ 颗
> 带原子钟的卫星把三维位置与时间变成全球免费公共服务;定位与授时(timing)
> 是同一件事的两面,金融、电网、通信的秒表也住在里面。家族:[讲透信息技术系统性应用](../README.md)。

## 诞生

**军方子午仪→1973 批准→1995 全运行→2000 开精度**:1957 年 Sputnik 升空,APL 的
Guier 与 Weiffenbach听多普勒频移算轨道,McClure 反转"轨道已知则听频移可定位"
→**子午仪 1964 服役**(核潜艇导航),但一次过顶、只给二维。**1973 年**国防部
合并 621B 与 TIMATION 批准 GPS 计划(Parkinson 任总师);1978 首星,**1995-07
全运行(FOC)**;**2000-05-01 取消选择可用性(SA)**,民用精度一夜 100 m→10 m;
今日四强并立:GPS/GLONASS/Galileo/北斗。

## 核心问题(已解决/未解决)

- 三球交汇几何——**已解决**:3 球面交两点(其一在太空舍去);钟差逼出**第四未知
  数(x,y,z,cδt)→第四颗星**;线性化迭代最小二乘是标准解(家族实验一)
- 卫星几何与 DOP——**已解决**:GDOP=√tr((HᵀH)⁻¹);6 轨道面/55°/24 星压 DOP
- 大气延迟——**基本解决**:双频改正+Klobuchar 模型(1987);多路径在城市峡谷仍是痛点
- 厘米级定位(RTK/PPP)——**已解决**:载波相位+差分,代价是基准站/收敛时间
- GNSS 欺骗检测——**悬而未决**:民用信号无认证;真实干扰事件驱动研究热潮
  (01 章方向三;多源一致性是当前防线)

## ✨ 这支最美的一个事实

GPS 定位的本质是**"把钟变成尺"**——光速 30 万 km/s 下 1 纳秒钟误差=30 厘米、
1 毫秒=300 公里;卫星载原子钟,接收机只需几美元石英钟:**把钟差当第四个
未知数解掉,是整个系统最优雅的经济决策**(多打一颗星,便宜过人人带原子钟)。

## 假设与依赖

- 依赖:相对论修正(卫星钟每天快约 38 μs——引力+速度效应,不改则日误差
  累积公里级);地面运控段的精密定轨与时间同步
- 假设:信号来自那颗星(欺骗攻击正是让此假设破产);椭球高≠海拔高
- 代价:室内/水下/深空不适用(信号遮挡与物理);室内定位是另一门工程
