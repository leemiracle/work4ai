# 02 · 语言特征:六层方言,每个坐标都在说话

> **本章回答五问之三(家族层):这门学科怎么说话?**
> 系统性应用的语言不是一门语言而是**六层方言的栈**:参照语言(坐标系)、
> 数据模型方言(矢量/栅格)、拓扑谓词、服务与交换协议、GNSS 机器语言、
> 海洋数据语言。每层都有三件事要讲清:**表达力**(能说什么)、
> **逻辑性质**(哪里会撒谎)、**规范化**(谁在管、管住了什么)。
> 概念三步法贯穿本章:每个术语先给**直觉**,再给**精确定义**,最后给**边界反例**。

---

## 一、六层语言总表(三栏)

| 语言层 | 表达力(能说什么) | 逻辑性质(哪里会撒谎) | 规范化(谁在管) |
|--------|------------------|----------------------|----------------|
| ①空间参照 | 经纬高/ECEF/ENU/投影坐标;EPSG 代码一行钉死基准 | 同一数字换基准=错几百米;"经纬度"不说是谁家的经纬度=最常见事故 | EPSG 注册表;ISO 19111;WKT/PROJ 字符串 |
| ②数据模型 | 矢量(点线面+属性)/栅格(格网+波段)/TIN | 矢量撒谎在"边界精确的假象",栅格撒谎在"格内均匀的假象" | ISO 19107(空间模式);GeoJSON RFC 7946;Shapefile/GeoPackage |
| ③拓扑谓词 | intersects/contains/overlaps/equals… | 谓词语义在边界处敏感;浮点坐标让"相切"不可判定 | DE-9IM(九交模型);OGC Simple Features (SFA/SQL) |
| ④服务与交换 | 请求地图/要素/瓦片;跨系统搬图层 | 瓦片金字塔 z/x/y 各家原点不一;样式随数据漂移 | OGC WMS/WFS/WMTS;XYZ 瓦片事实标准 |
| ⑤GNSS 机器语言 | 接收机吐 NMEA 句子;观测文件 RINEX;差分改正 RTCM | NMEA 只有一位校验和——**整句可伪造**;坐标默认 WGS84 无声明 | NMEA 0183;RINEX;RTCM;接口控制文档(ICD) |
| ⑥海洋数据 | 自描述多维数组(时间×深度×经纬);单位与坐标进元数据 | "深度"向下为正还是向上为正;格点中心还是格点边缘——CF 之前各说各话 | NetCDF+CF 约定;Argo 数据格式;GRIB(WMO) |

## 二、逐层速写:每层一个"撒谎案例"

### 2.1 参照语言:数字不撒谎,基准才撒谎

- **概念三步法示例①——"EPSG:4326"**:
  - 直觉:一个编号,指"GPS 给你的那种经纬度"
  - 精确:WGS84 地心坐标系下的**地理坐标**(经纬度,度),**未投影**
  - 边界反例:把 EPSG:4326 的经纬度直接当平面坐标画图(轴序还经常 lon/lat
    与 lat/lon 颠倒)——这是 GIS 工程事故榜第一名;它的"兄弟"EPSG:3857
    (Web Mercator)才是 Web 地图上的平面米制坐标
- 撒谎案例:同一组经纬度,WGS84 与 1954 北京坐标系下差几十至几百米——
  **数字相同,地面上的点不是同一个**。基准变换(helmert 七参数/格网改正)
  是 GIS 工程里最沉默的坑

### 2.2 数据模型方言:两种世界观

- **概念三步法示例②——"图层(layer)"**:
  - 直觉:一张透明硫酸纸,画着同一类东西(道路/河流/地块)
  - 精确:同一空间域上、同一几何类型与属性模式的空间要素集合,
    叠加分析=图层层叠的数字实现(Tomlinson 1963 的原始动机)
  - 边界反例:两张"道路层"来自不同部门,一条路在 A 层是线、在 B 层是面,
    拓扑叠加产生一堆碎片多边形(sliver polygons)——**图层这个概念
    不承诺语义一致**,语义住在数据之外
- 矢量与栅格的互补谎言:矢量边界精确是假象(测量本身有误差,1:1 万地形图
  的等高线有米级不确定度);栅格格内均匀是假象(一格 30 m 的"平均土地"
  掩盖格内一切)。**两种谎言都不可消除,只能按用途选择哪种谎更便宜**

### 2.3 拓扑谓词:边界上的战争

DE-9IM(维度扩展九交模型)用两个几何的内部/边界/外部的 3×3 交集维度
定义空间关系,使 contains/overlaps 等**有一致的机器语义**。
撒谎案例:浮点数下,"两个多边形恰好共享一条边"不可判定——
容差(snap tolerance)一调,相离变相邻、相邻变相离;**GIS 里的拓扑
是带容差的拓扑**,工程上"容差"比"谓词"更值得写进文档。

### 2.4 服务与交换语言:瓦片的巴别塔

WMS(动态渲染图)/WFS(取要素)/WMTS(预切瓦片)是 OGC 三件套;
Google 式 z/x/y 瓦片是事实标准。撒谎案例:XYZ 瓦片的 z/x/y 原点
(左上还是左下)、Y 轴方向在不同生态里相反;Web Mercator 切到
±85.0511° 就到顶——**极地在这套语言里没有词**(格陵兰在 Web 地图上
"看起来同大实为 1/14"的语言学根源,00 章 §五-2)。

### 2.5 GNSS 机器语言:NMEA 的信任裸奔

- **概念三步法示例③——"伪距(pseudorange)"**:
  - 直觉:接收机自报的"到卫星的距离"
  - 精确:信号传播时间×光速,含接收机钟差(bias)——**之所以叫"伪",
    是因为它是"距离+一个未知的公共错位"**;四颗星把错位当第四未知数解掉
  - 边界反例:电离层延迟可让伪距偏数米至数十米(双频改正);欺骗者
    重放信号时伪距"完美一致地错"——**残差检验看不出单源欺骗**
    (01 章 §三的检测难题在语言层早已注定:NMEA 无认证字段)
- NMEA 0183 例句:`$GPGGA,123519,4807.038,N,01131.000,E,1,08,0.9,545.4,M,46.9,M,,*47`
  最后 `*47` 只是一位异或校验——防误码,**不防伪造**

### 2.6 海洋数据语言:CF 约定的自律革命

NetCDF 自描述数组 + CF(Climate and Forecast)约定,把"每个变量的
标准名、单位、坐标指向、正方向"写进元数据——**海洋/大气学界用"约定"
完成了别处要靠委员会标准完成的事**。撒谎案例:深度坐标 positive=down
还是 up、格点代表中心还是边缘,CF 之前的古董数据集各说各话——
今天读 1990 年代的海洋数据集,第一件事仍是"考古"其坐标语义。

## 三、规范化地图:谁在管哪层

| 管理者 | 管的层 | 代表产物 |
|--------|--------|---------|
| IOGP(EPSG) | ①参照 | EPSG 注册表(每个坐标系一个号) |
| ISO/TC 211 | ①②③ | ISO 19100 系列(19107 空间模式/19111 坐标/19115 元数据) |
| OGC | ②③④ | Simple Features、WMS/WFS/WMTS、GeoPackage |
| IETF | ② | GeoJSON RFC 7946(永远 WGS84——简单性战胜表达力) |
| NMEA/RTCM/ GPS 联合办公室 | ⑤ | NMEA 0183、RTCM 差分、接口控制文档(ICD) |
| UCAR/Unidata 与 CF 社区 | ⑥ | NetCDF、CF 约定、标准名表 |
| WMO/IOC | ⑥ | GRIB、BUFR、Argo 格式 |

> 观察:这张表里**没有一个是单一权威**——参照归石油业出身的 EPSG、
> 服务归 OGC、海洋归学界自律。系统性应用的语言层是**条块化的演化产物**,
> 不是设计产物;这解释了为什么"互操作"永远是本领域的一线问题(04 章裂缝③)。

## 五、跨层翻译事故榜(层与层接口的经典错误)

| 事故 | 接口 | 一句话病根 |
|------|------|-----------|
| 同数字不同基准混用 | ①↔① | WGS84 vs 地方坐标系差几十至几百米,join 前忘做基准变换 |
| 经纬度直接算平面距离 | ①→② | 地理坐标是曲线坐标;经度 1° 的长度随纬度收缩(实验一 §C) |
| Web 地图上量面积 | ①→④ | 3857 平面米≠地面米,面积×sec²(纬度)(实验二) |
| 叠加产生碎片多边形 | ②↔② | 两层边界各自带误差,容差不一致导致 sliver |
| NMEA 当可信输入 | ⑤→③ | 一位异或校验只防误码不防伪造(01 章 §三) |
| 再分析格点当观测 | ⑥→④ | 格点=模式+观测杂交(档④),统计前必须声明同化先验 |
| 深度正方向打架 | ⑥→⑥ | positive=down/up 不看元数据,剖面拼接错千米 |

> 这张表的用法:每条事故都是**两层方言之间的翻译税**——
> 单层内部各治其事,事故全部发生在接口;所以工程纪律第一条是
> "跨层搬运时显式声明源层方言"。

## ✍️ 练习

1. **事故重演**:找一个公开 Shapefile 与它的 .prj 文件,把 .prj 删掉后
   在 GIS 软件里按错误基准加载——记录偏了多少米,写出事故报告三行
2. **谓词边界**:构造两个共享一条边但坐标差 1e-9 的正方形,分别在
   容差 0 与 1e-8 下求 intersects——解释"带容差的拓扑"为何必须写进工程文档
3. **NMEA 考古**:解析一个 `$GPGGA` 句子(手工算异或校验),列出句中
   **没有**的字段(谁发的?签过名吗?哪颗星贡献了什么?)——
   体会 01 章 §三的信任危机在语言层的样子

## 📌 收束

这门学科的语言=**六层方言栈**:数字诚实,基准撒谎;谓词清晰,容差含糊;
句子自述,身份缺失。规范化的真相是**条块演化的拼盘**而非统一设计——
所以读任何空间/导航/海洋数据的第一问永远是:"这句话是哪个方言,
在哪个基准下,带不带容差,有没有签名?"

**🧠 认知升维**:
- **方言眼**:先辨层再读数——数字属于哪一层方言,决定了它可能撒哪一类谎
- **合同眼**:坐标不是数字而是合同(基准条款+容差条款+署名条款),
  缺一条款的数字都是未完成的句子
- **考古眼**:老数据集的语义要考古——约定(CF)与标准(ISO)只覆盖
  它们诞生之后的世界
