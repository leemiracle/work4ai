# 讲透信息技术系统性应用 · 覆盖全域的空间信息底座(GB/T 41330)

> **本质一句话**:信息技术系统性应用=信息技术长成"基础设施"的形态——不是解决某个问题的
> 单点算法,而是**覆盖全域的空间信息底座**:GIS 把"哪里有什么"变成可计算对象,GPS 把
> "我在哪、现在几点"变成任何角落免费可得的公共服务,海洋信息技术给那 71% 没有路标、
> 没有基站、电磁信号不透水的疆域装上观测与传输系统。
> GB/T 13745-2009:413 · 二级学科 **41330 信息技术系统性应用**(GB/T 三级 3 支全落子)。
> 宇宙:[讲透信息与系统工程技术](../README.md)。

## 〇、家族定位与成员

- 学科身份:**成套工程学科**——每一支都是"基准→观测→解算→服务"四环齐备并长期运转的
  系统,这是它与"单点算法"的判据(00 章 §1.4)
- 与 413 宇宙兄弟的分工:控制(41310)管"让系统按意图动",仿真(41315)管"造系统替身",
  信息安全(41320)管"信息在敌意环境存活",**本家族管"把地球装进信息系统"**
- 三个成员=GB/T 三级全部:地理信息系统(4133010)、全球定位系统(4133020)、海洋信息技术

## 一、三支家族树

```
讲透信息技术系统性应用/
├── 讲透地理信息系统/   把"哪里有什么"变成数据库与地图服务(Tomlinson 1963 加拿大土地清查)
├── 讲透全球定位系统/   把星空变成标尺:四星伪距=三维位置+钟差(子午仪→1973 批准→2000 开精度)
└── 讲透海洋信息技术/   给 71% 的疆域装神经系统(泰坦尼克→冰山巡逻→卫星海洋学→Argo 2000)
```

> 共同骨架:**三支都不是"发明了一个算法",而是"建成了一座默认存在的地面"**——
> 你打开地图、收到定位、看到海况预报时,从没想过它们,这正是系统性应用的成就。

## 特征速查(问题→支)

- 地图/图层/叠加分析/空间索引/投影与基准 → 地理信息系统支
- 定位/伪距/钟差/DOP/RTK/欺骗检测/授时 → 全球定位系统支
- 海洋观测/浮标/测深/声学/再分析格点/数据同化 → 海洋信息技术支
- 分不清时先问四环(基准/观测/解算/服务)缺哪环——缺环即最脆弱处
