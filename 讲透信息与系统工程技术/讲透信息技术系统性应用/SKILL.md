# 信息技术系统性应用思维技能(GB/T 41330 · 家族的抽象层)

## ① 何时用此分支(问题特征触发词)

1. 出现"哪里/在哪/多远/覆盖范围"——把问题升维成坐标基准+几何问题
2. 地图、图层、瓦片、空间索引、叠加分析、缓冲区——GIS 工作流
3. GPS/北斗/伽利略/定位/伪距/钟差/DOP/RTK——GNSS 解算与几何
4. 位置数据要和别的数据 join——先问坐标系是否同基准(最大事故源)
5. 空间数据做统计/机器学习——空间自相关警报(Tobler 定律)
6. 面积/距离在 Web 地图上量测——投影失真警报(Web Mercator 面积×sec²纬度)
7. 海洋观测/剖面/再分析格点——采样代表性与"模式先验混入"检查
8. 定位信号可信度/jamming/spoofing——信号无认证的信任模型检查

## ② 核心思维模式

- **底座眼**:这个技术是工具还是地面?地面类系统按"基准→观测→解算→服务"
  四环审视,缺环即定位其脆弱点
- **合同眼**:坐标不是数字是合同——基准条款、容差条款、署名条款,缺一即危险
- **四档构造眼**:闭式/迭代/统计重构/学习重构——先问产品是第几档,
  档位决定它能支撑什么级别的论证
- **几何税眼**:GNSS 精度=测距误差×DOP,几何不好观测再准也白搭;
  推广:一切反演都有几何因子,先算因子再谈精度
- **采样眼**:每张图/每个格点都是采样的产物,数据点之间是假设在补白

## ③ 工具箱(何时用什么)

| 工具 | 何时用 |
|------|--------|
| EPSG 注册表+PROJ/pyproj | 任何坐标换基准前,先查码(4326≠3857≠平面) |
| 150 行自写伪距定位器(家族实验) | 理解/验证 GNSS 解算;教学与原型 |
| R 树/四叉树(rtree, PostGIS) | "附近/相交"查询到十万级以上要素 |
| 瓦片金字塔预算 | 全球影像/地图服务的容量与缓存规划 |
| Kriging/PySAL | 空间内插与面数据统计(必须披露变差函数选择) |
| DE-9IM 谓词(shapely) | 拓扑关系的机器判定(注意容差) |
| NetCDF+xarray+CF 约定 | 海洋/气象格点与剖面数据的正确读法 |
| 多尺度重聚合 | MAUP 披露:同数据换分区单元看结论稳定性 |
| 残差一致性检验(RAIM 思想) | 定位可疑星/欺骗的最低成本检查(需冗余) |

## ④ 常见误区与禁忌

- **把经纬度当平面坐标**:小范围近似可教,工程不可用;Web Mercator 上量
  面积是常见事故(格陵兰"看起来"与非洲同大,实为 1/14)
- **同数字不同基准混用**:WGS84 与地方坐标系差几十至几百米——
  join 前必须做基准变换
- **空间数据随机划分训练/验证集**:空间自相关使精度虚高,
  必须按空间块划分
- **点密度图直接当"风险图"**:聚合单元(MAUP)可让结论反号,
  不做多尺度披露的空间统计不可信
- **盲信定位输出**:民用 GNSS 信号无认证,单源可被欺骗;
  关键应用必须多源一致性(惯性/地图/多频)
- **把再分析格点当观测**:格点值=模式+观测的杂交(档④),
  统计前先声明同化先验
- **恰好 4 星就谈完好性**:零冗余=单星故障直接变成位置漂移且不可检
——完好性是用第 5 颗星买的
