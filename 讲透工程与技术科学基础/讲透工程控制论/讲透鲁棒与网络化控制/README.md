## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 鲁棒稳定性 | 摄动在界内时稳定不丢——裕度概念的精确化 |
| H∞ 控制 | 最小化最坏情况增益:为最大误差而非平均误差设计 |
| 小增益定理 | 环路增益(加权)小于 1 则闭环稳定——鲁棒判据基石 |
| μ(结构奇异值) | 结构化摄动下的稳定半径——多回路鲁棒性的量尺 |
| 水床效应 | Bode 积分:误差这里按下去,别处必鼓起来——不确定性守恒律 |
| 网络化控制(NCS) | 传感器/控制器/执行器分处网络两端:时延丢包进回路方程 |
| 事件触发控制 | 误差够大才通信——用通信资源换控制性能的显式权衡 |
| CPS | 计算+通信+物理融合体:1954 间关系科学的当代版 |

## ✨ 这支最美的一个事实

**Bode 敏感度积分**:对稳定回路,敏感度函数对数增益的积分
恒为零(通说)——反馈不能消灭误差,只能**搬运**它:低频把
扰动压下去 40 dB,就得在高频把噪声放大回来。性能与鲁棒性
共用一条守恒律;一切"两头全要"的调参执念都被它温和而无情
地拒绝(家族 00 章美之时刻②;实验断言⑤是它的时域收据)。
