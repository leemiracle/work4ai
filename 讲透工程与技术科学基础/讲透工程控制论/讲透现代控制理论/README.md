## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 状态 | 系统的全部记忆:知道 x(t₀) 与 u(·),未来完全确定 |
| 状态空间 | ẋ=Ax+Bu, y=Cx:四矩阵说尽一切(时域方言身份证) |
| 能控性/能观性 | 输入能否驱动状态 / 输出能否暴露状态——对偶的一枚硬币 |
| 极点配置 | 状态反馈 K 自由摆放闭环极点(前提:能控) |
| 观测器 | 从输出重构状态:估计误差自己衰减的迷你闭环 |
| 分离原理 | 先估计再控制=一步最优(线性情形居然成立) |
| LQR | 性能指标进方程,Riccati 出增益——线性最优设计的完全解 |

## ✨ 这支最美的一个事实

**对偶性**:能控性与能观性互为转置镜像——"输入能否驱动状态"
与"输出能否暴露状态"是同一问题的两副面孔(卡尔曼,通说);
由此 LQR(控制)与 Kalman 滤波(估计)解的是同一族 Riccati
方程,分离原理再保证两步设计等于一步最优。控制与估计,
看似两门手艺,实为一个数学对象的两个投影。
