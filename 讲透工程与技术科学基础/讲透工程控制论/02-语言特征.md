# 02 · 语言特征——回路的三种方言与稳定性证书

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程控制论说的是**三种数学方言的互译语法**
> ——方块图(图语言)、传递函数(频域方言)、状态空间(时域
> 方言);判断一段控制写作的优劣,不看文采,看**稳定性断言
> 是否附了证书**(哪类证书、适用条件抄全没有)。三栏分别回答:
> 这三种方言能说什么(表达力)、稳定性断言凭什么可信
> (逻辑性质)、术语如何被标准化(规范化)。

---

## 0. 开篇:同一回路的两种文本

📖 **故事框:一个直流电机的三种写法**。图语言:方块图上四个
方块(控制器→放大器→电机→测速发电机),一个求和点把参考与
测速相减——工程师的普通话,车间墙上贴的就是它。频域方言:
传递函数 G(s)=K/(s(Js+b)),微分方程被拉普拉斯变换压成代数式,
伯德图上一条幅频一条相频——频率响应学派的世界观。时域方言:
状态空间 ẋ=Ax+Bu, y=Cx,四个矩阵说尽一切——卡尔曼革命后的
世界观。**三种文本说的是同一台电机,但每种文本丢失的与买到
的都不同**:图语言丢定量买直观,频域丢非线性买洞察(根在哪、
裕度多少),状态空间丢单输入单输出的直观买多变量与最优设计
的全部产能。控制工程师的语言工作,就是在三种文本之间**带着
证书翻译**。

## 1. 表达力:三种方言能说什么(三栏之一)

**能说的**:

| 能力 | 方言 | 例 |
|------|------|-----|
| 连接的显式表达 | 方块图 | 串联/并联/反馈三种连接一画即明——间关系的母语 |
| 稳定性的几何直觉 | 传递函数 | 极点=右半平面的雷区;零点=响应的哑穴;根轨迹=增益扫描下的迁移图 |
| 频域裕度 | 传递函数 | 增益裕度/相位裕度:离 -1 点多远,一句话报出鲁棒性 |
| 多变量与内部结构 | 状态空间 | 能控性/能观性:输入输出看不到的内部性质,只有矩阵语言能说 |
| 最优设计 | 状态空间 | LQR/Kalman 滤波:性能指标进方程,解从 Riccati 方程出来 |
| 全流程代数化 | 状态空间 | 仿真=矩阵指数的数值积;数字实现=离散化一步到位(04 章走廊) |

**不能说的**(表达力边界,与生俱来):

- **方块图不能算**:它是交流语言不是计算语言;每个方块里的
  定量内容要靠另两种方言补
- **传递函数不能说内部**:只看输入输出(外部等价),内部
  状态的能控能观、隐藏振型(零极点对消的暗病)它静默——
  卡尔曼批评经典方法的要害即在此(通说)
- **状态空间不能白给直觉**:极点在哪、裕度多少,不画图
  (再转频域)就看不出;多变量系统的"增益"是矩阵,
  Bode 图式的单曲线直觉失效(MIMO 的μ/H∞ 复杂性由此起)
- **三种方言都不能说非线性大范围行为**:极限环/分岔/混沌
  需要李雅普诺夫与相平面(00 章假设一的代价面)

## 2. 逻辑性质:稳定性断言的证书学(三栏之二)

控制断言的可信度来自**证书**(certificate)——不是"我调出来了",
是"附了可独立检验的判据"。稳定性证书三类:

| 证书类型 | 判据 | 适用 | 检验方式 |
|---------|------|------|---------|
| 代数证书 | Routh-Hurwitz:不解特征方程,系数表直接判根位置 | 线性、特征多项式在手 | 造系数表,机械可查 |
| 频率证书 | Nyquist:开环 G(jω) 绕 -1 点圈数 ↔ 闭环稳定 | 线性、开环可测(含不稳定对象,右半平面极点数要已知) | 画/测一条曲线,实验可做 |
| 能量证书 | Lyapunov:找 V(x) 正定且 V̇ 负定 | **非线性也适用**——最一般 | 构造 V(没有系统方法,是艺术) |

### 2.5 断言强度阶梯(控制版 E1-E5)

| 阶梯 | 措辞 | 证据状态 | 控制特有注意 |
|------|------|---------|-------------|
| E1 定理级 | "由奈奎斯特判据,闭环稳定" | 判据+条件全满足 | **右半平面开环极点数必须先数清**——最常漏抄的前提 |
| E2 线性化级 | "在平衡点附近局部稳定" | 线性化证书 | 只覆盖邻域;大范围行为未证(00 章假设一) |
| E3 仿真级 | "时域仿真显示收敛" | 数值证据 | 仿真≠证明:初值/激励没扫到的区域无证据;时延未建模的仿真自欺(01 章方向五) |
| E4 整定级 | "现场整定后运行良好" | 回路实证 | 单工况良好≠全工况良好;裕度没报=鲁棒性未知 |
| E5 认证级 | "通过安全认证规范" | 规范证据 | 功能安全(如通说的 IEC 61508 系)是制度不是数学,两者互补 |

**误用告示**:把 E2(线性化稳定)当 E1(全局)——非线性系统
在邻域外照样进入极限环;把 E3(仿真收敛)当鲁棒性证据——
仿真没带摄动与噪声,收敛说明不了抗扰。

### 2.6 三个内部语法规则

- **名义对象声明规则**:任何设计结论必附名义模型+摄动界
  ("对 G_nom 设计,摄动 |Δ|<0.3 时稳定裕度保持")——没有
  摄动界的"稳定"是脆弱断言
- **裕度必报规则**:线性回路的设计交付必带增益/相位裕度
  (或等价的 H∞ 范数);报性能不报裕度=只报速度不报刹车
- **线性化点声明规则**:线性化在哪一点、什么工况做的,必须
  写明;工况变了设计要重做(增益调度的存在理由)

## 3. 规范化:术语与对译(三栏之三)

- 国际语境下控制术语高度标准化(IEEE/IFAC 词汇表传统);
  中英写作必须声明口径——特别是"控制论/控制理论/工程控制论"
  三词在中文里共用"控制"字头,而英文是三个学科词
- 度量:稳定性裕度(增益裕度 dB/相位裕度 度)、带宽(Hz 还是
  rad/s)、超调量(百分比)必须带单位;PID 参数必附作用方向
  (正/反作用)与微分位置(理想式/串级式、微分先行与否)

**术语对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 反馈/负反馈 | feedback / negative feedback | "负"反馈才是稳定化方向;正反馈=振荡器/自增强 |
| 控制论 | cybernetics | 维纳谱系:动物与机器中的控制与通信;≠控制理论 |
| 工程控制论 | engineering cybernetics | 1954 学科命名;间关系科学(00 章故事框三) |
| 受控对象 | plant | 工厂(plant)借来;也译"过程/对象" |
| 设定值 | setpoint | 也译"给定值";与参考值 reference 微差(时变与否) |
| 伺服/调节 | servo / regulation | 跟踪问题 vs 稳住问题——两类性能指标不同 |
| 传递函数 | transfer function | 频域方言的身份证;只描述外部(零状态)等价 |
| 状态空间 | state space | 时域方言;内部描述——与传递函数世界观之争是学科史主线 |
| 能控性/能观性 | controllability / observability | 卡尔曼造词;"能"是结构性性质,不随增益消失 |
| 极点/零点 | poles / zeros | 极点=自有动态;零点=响应凹陷;零极点对消=隐藏振型(暗病) |
| 根轨迹 | root locus | Evans 1948-50;增益扫描的极点迁移图,频域设计地图 |
| 伯德图 | Bode plot | 幅频+相频;"增益穿越/相位穿越"两词勿混 |
| 增益裕度/相位裕度 | gain margin / phase margin | 离临界点的两把尺;裕度=鲁棒性的零阶量度 |
| 前馈 | feedforward | 与"反馈"对偶;依赖模型精度(家族实验的对象) |
| PID 控制 | proportional-integral-derivative control | 工业回路统治结构;积分消稳态误差,微分供阻尼 |
| 李雅普诺夫稳定性 | Lyapunov stability | 能量证书;第二法=直接法(构造 V),勿与线性近似混称 |
| 鲁棒控制 | robust control | robust=扛模型错,不是"结实"的泛称;对应 worst-case 设计哲学 |
| H∞ 控制 | H-infinity control | 范数指标的最小敏感度设计;读"H 无穷" |
| 敏感度/补敏感度函数 | sensitivity / complementary sensitivity | S=1/(1+L), T=L/(1+L);S+T=1 是恒等式也是权衡律 |
| 采样控制 | sampled-data control | 连续→离散的一跳;ZOH 采样保持;02 章走廊的地基 |
| 网络化控制系统 | networked control system (NCS) | 回路跑在共享网络上:时延/丢包/量化 |
| 时间敏感网络 | time-sensitive networking (TSN) | 确定性以太网标准族;控制流量优先级(01 章方向五) |
| 信息物理系统 | cyber-physical systems (CPS) | 计算+通信+物理融合;"cyber"指计算非"网络"泛称 |
| 韧性控制 | resilient control | 抗攻击/抗退化设计;与鲁棒(抗摄动)分工 |
| 数字孪生 | digital twin | 在线孪生模型;与控制闭环合流(01 章方向三) |

## 📌 收束

工程控制论的语言=**三种方言的互译(方块图/传递函数/状态空间,
各有表达力边界)+证书学(代数/频率/能量三类稳定性证书与
E1-E5 阶梯)+名义-摄动-裕度的规范化**。它写下的每个"稳定"
都在等一张证书。下一章把回路上的对象压成数据结构:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **证书眼**:听到"稳定/收敛",先问证书类型——代数/频率/
  能量?适用条件抄全了吗?没有证书的稳定是轶事
- **方言眼**:同一回路三种文本,翻译必声明口径——方块图给人
  看,传递函数给洞察,状态空间给机器
- **裕度眼**:性能(快/准)与裕度(稳不稳得住)分开报——
  只报性能不报裕度的方案,是没装刹车的高速方案
