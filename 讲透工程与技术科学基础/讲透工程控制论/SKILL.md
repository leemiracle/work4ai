## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **回路眼** | 任何自适应系统拆五要素:对象/测量/比较/执行/扰动;拆不出五要素的"反馈"是修辞 |
| **三角眼** | 稳定、鲁棒、最优互不蕴含——听到"最优方案"先问稳不稳、扛不扛模型错 |
| **裕度眼** | 设计不是找一个点,是找一个域;只报性能不报裕度=没装刹车的高速方案 |
| **关系眼** | 系统的麻烦与本事都在连接里不在元件里——排查先看回路,设计先设计连接 |
| **证书眼** | "稳定"必附证书:代数(Routh-Hurwitz)/频率(Nyquist)/能量(Lyapunov);适用条件抄全 |
| **成对眼** | 对象=名义+摄动界,只谈名义不谈界的模型是半张合同 |
| **环内眼** | 反馈红利只发环内——环外的误差(参考传感器/前馈通道)原样通行 |
| **账单眼** | 每一分鲁棒性都有账单(噪声/能量/带宽);增益升=账单升,水床必在别处鼓起 |

## 3. 工具箱(何时用什么)

- **五要素分诊**(00 章):对象-测量-比较-执行-扰动——
  识别真反馈回路的最小工具
- **三角定位**(00 章):任何控制需求先定位——入场券
  (稳定)/保险单(鲁棒)/奢侈品(最优)?三者顺序不可颠倒
- **证书学**(02 章):三类稳定性证书+E1-E5 断言阶梯
  (定理/线性化/仿真/整定/认证)——收断言先看级
- **名义-摄动-裕度三件套**(03 章):schema 化的回路记录;
  入库三问:名义定住了吗/回路代数对吗/有证书吗
- **前馈vs反馈对比**(`experiments/feedback_value.py`):
  Δ=0 等效可用→Δ=0.5 前馈崩塌(≈9e2)反馈保持(<0.02)
  →增益权衡曲线(扰动峰值 0.42→0.09,控制量噪声∝g)——
  三分钟把反直觉①与权衡律全部落成数
- **走廊五条**(04 章):C1 时域仿真(已成)/C2 根轨迹
  (稳定域)/C3 裕度(频率扫描)/C4 整定(参数网格)/
  C5 数据驱动(免建模边界)

## 4. 常见误区与禁忌

- ❌ **把"最优"当验收**:LQG 最优控制器可被任意小摄动
  失稳(Doyle 1978)——最优性与鲁棒性是两个独立命题
- ❌ **只交名义模型**:鲁棒断言=名义+摄动界+裕度三件套,
  缺一即"半张合同"
- ❌ **仿真冒充验收**:仿真收敛是 E3 级;场景/摄动/时延
  没扫到的区域无证据
- ❌ **裸微分上噪声**:微分项必带滤波——执行器的噪声账单
  随增益近乎线性增长(实验断言⑤)
- ❌ **零极点对消图省事**:对消的极点仍活在系统里
  (隐藏振型/暗病)
- ❌ **把"控制论"泛化为万物理论**:回路眼只适用于拆得出
  五要素的系统;拆不出的场合用系统学/复杂系统语言
- ❌ **线性化稳定当全局稳定**:邻域外的极限环与分岔,
  线性证书管不着
