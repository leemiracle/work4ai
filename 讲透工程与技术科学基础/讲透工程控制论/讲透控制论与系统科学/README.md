## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 控制论(cybernetics) | 维纳 1948:动物与机器中控制与通信的统一科学 |
| 工程控制论 | 1954 命名:工程系统中间关系的科学(本家族总纲) |
| 间关系 | 性质不住在元件里,住在连接里——反馈/振荡/鲁棒皆然 |
| 负反馈 | 通向稳定的通用机构:从调速器到恒温器到 RLHF 同构 |
| 同源分流 | 控制论→工程侧(本家族)/组织侧(系统工程)/科学侧(系统学) |

## ✨ 这支最美的一个事实

1948 年前后,"反馈"在互不相识的领域被反复独立发现:工程师
用它稳住放大器与火炮随动(奈奎斯特/伺服机构学派),神经生理
学家用它解释目标的追踪(小脑与随动系统的类比,维纳-罗森
布鲁斯-别格罗 1943 论文,通说),数学家用它造控制论——
**同一语法,三门方言**。1954 年《工程控制论》把工程方言整理
成学科:"间关系"从此有了正名(按史实通说中性陈述)。
