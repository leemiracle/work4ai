## 0. 开篇:反馈的价值,代码自己说

「都说反馈鲁棒,模型不准时它到底鲁棒多少?高增益的账单
到底多大?」——`experiments/feedback_value.py` 让代码回答:
不稳定二阶对象 ÿ=b·y+u 上,开环前馈(名义模型逆动力学)与
闭环反馈(增益参数化 PID)对线。五个断言:Δ=0 时两案等效
可用(前馈 9.3e-10 完美逆,反馈终段 RMS 0.017);刚度失准
Δ=0.5 时**前馈指数崩塌(max≈9e2)而反馈保持**(终段 RMS
仍 0.013);增益扫描上扰动峰值 0.42→0.09 单调降,**控制量
噪声 RMS 0.08→1.14 近乎 ∝g**(输出端近持平:通带内补敏感度
|T|≈1,账单在执行器)。**一条脚本把 00 章反直觉①与三角里的
"鲁棒性-性能权衡"全部落成可复现的数。**

## 1. 可机械化边界(三件套之一)

**能进代码的**(回路数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 时域仿真 | 闭环 ODE 数值积分(RK4),摄动/扰动/噪声逐件加(家族实验) |
| 极点追踪 | 特征多项式随增益参数化→逐点求根→根轨迹的数值版 |
| 裕度扫描 | L(jω) 频率响应计算→穿越频率→增益/相位裕度 |
| 整定网格 | (Kp,Ki,Kd) 格点上批量仿真+约束过滤→可行域地图 |
| 李雅普诺夫证书检查 | 给定 V(x),数值验证 V̇<0(给定证书的机检,不是构造) |
| 摄动回路批量验证 | Δ 在界内采样→蒙特卡洛稳定检查(鲁棒性的实证面) |

**不能进代码的**(工程控制论的"不可判定域"):

1. **对象建模判断**——哪组方程配这团物理:机理与辨识的责任;
   代码只能对已声明的名义+摄动算裕度,不能裁定模型对错
2. **李雅普诺夫函数的构造**——证书的发现是艺术,代码只做
   证书的检验(00 章问题表"悬而未决"项)
3. **真实回路的验收**——E4/E5 级证据要现场整定与规范认证;
   仿真级证据(E3)冒充验收是 02 章阶梯的头号误用
4. **架构判断**——这个环节值不值得闭环、前馈与反馈怎么配比:
   系统结构设计,不是参数搜索(03 章结构眼)

> 边界的一句话:**代码是回路的验尸台与试验场,不是设计师。**

## 2. C1 时域仿真走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 对象 | ÿ=b·y+u+d(可失准 b=1+Δ,可加扰动) | 二阶不稳定对象=倒立摆最小替身;高维对象归状态空间法 |
| 积分 | RK4 定步长(dt=0.002) | 刚性对象需隐式积分;步长要小于最快闭环时间常数一个量级 |
| 控制律 | 前馈(逆动力学)/反馈(PID,微分在测量侧) | 噪声 ZOH 化是教学处理;真实微分要滤波(03 章必备件) |
| 证据 | 逐 Δ/逐增益断言+同种子噪声 | 仿真证据=E3 级;场景没扫到的工况无证据(02 章) |

成品=`experiments/feedback_value.py`。**改对象改一行(微分
方程),改控制律改一处(控制器函数)**——schema 分离的好处
(03 章)在走廊里兑现。

## 3. C2 根轨迹思想走廊(极点随增益迁移)

经典控制理论的根轨迹是手绘图,数值版十行即得:

```python
# 根轨迹思想:闭环极点 = 1 + g·L(s) = 0 的根,随 g 迁移
# 对象 L(s)=1/(s*(s-1))(不稳定对象+积分器),PD 闭环示意
def closed_loop_roots(g, kp=8.0):
    # 闭环特征多项式 s² + g*kd*s + (g*kp - b),b=1(名义)
    a, b, c = 1.0, 4.0*g, 8.0*g - 1.0     # s²+a? 逐系数列表
    poly = [1.0, b, c]                      # s² + b*s + c
    return quadratic_roots(poly)            # 解析求根(高阶→数值库)
# 扫描 g ∈ [0.1, 8]:观察极点从右半平面(不稳)迁入左半平面
# ——稳定域边界 g > 1/(kp) 由"极点穿越虚轴"直接读出
```

要点:其一,**稳定域=极点穿越虚轴的临界增益**,数值版根
轨迹把"稳定域"从定理变成可扫的图;其二,失准 Δ 进入系数
(b=1+Δ),同一张轨迹图平移——**鲁棒性=摄动下极点仍在左半
平面的富余量**,这就是裕度概念的根轨迹面;其三,高阶系统
求根需要数值伴侣矩阵方法(通说),教学规模解析即可。

## 4. C3 鲁棒裕度走廊(频率扫描)

裕度的数值版=对开环 L(jω) 做频率扫描:

```python
# 增益/相位裕度:L(jω) 的穿越点离 -1 有多远
def margins(L, w_grid):
    # L: 频率响应函数(对象×控制器);w_grid: 角频率列表
    mag = [abs(L(1j*w)) for w in w_grid]
    ph  = [angle_deg(L(1j*w)) for w in w_grid]
    # 增益裕度 = -20log10|L| @ 相位穿越(-180°)
    # 相位裕度 = 180° + ph @ 增益穿越(|L|=1)
    return gain_margin_db, phase_margin_deg
# 断言风格:GM > 6 dB 且 PM > 30°(工程通说下限)才入交付
```

要点:其一,**裕度把"鲁棒"量化成一个数**——摄动界多大仍稳,
答案就是裕度多宽(02 章证书的数值面);其二,频率响应可由
传递函数直接算,也可由**实验测得**(扫频/阶跃辨识)——
这是频域方言对实验友好的结构性优点(00 章反直觉②);其三,
MIMO 系统的单曲线裕度失效,需奇异值/H∞ 范数
([12030 鲁棒控制支](../../讲透信息科学与系统科学/讲透控制理论/讲透鲁棒控制/)
的正主)。

## 5. C4 整定走廊(参数空间的网格)与 C5 数据驱动走廊(桥)

- **C4 整定网格**:(Kp,Ki,Kd) 三维格点批量跑 C1 仿真,
  按指标(超调/调节时间/噪声 RMS)过滤——整定从口诀
  (Ziegler-Nichols,通说)升级为**可行域地图**;家族实验
  断言④⑤的权衡曲线就是这张地图上沿增益方向的一条切线。
  坑:格点爆炸(三维已吃力),生产用坐标下降/贝叶斯优化
- **C5 数据驱动**(通向 01 章方向四):从一批闭环/开环数据
  直接回归控制策略(免机理建模)——示意=对 (u,y) 数据做
  最小二乘拟合控制律参数;边界=训练工况之外无保证
  ("模型搬进数据",00 章反直觉①的当代注脚);装置落地与
  安全滤波在
  [41310 转代码章](../../讲透信息与系统工程技术/讲透控制科学与技术/04-控制科学与技术转代码.md)

**走廊三警告**(共用):

1. 仿真证据是 E3 级:场景、摄动、噪声没扫到的区域无证据
2. 名义模型算出的裕度只对声明过的摄动界负责(03 章成对眼)
3. 带时延的回路必须把时延建进仿真——网络化回路的理想化
   仿真自欺(01 章方向五)

## 6. 工程师落点(把这门学科带回家)

- **回路眼读一切自适应系统**:TCP 拥塞控制(AIMD=积分式
  调节)、重试与退避(继电式反馈)、限流与负载均衡(容量
  反馈)、缓存淘汰(误差驱动的策略更新)——用五要素
  (对象/测量/比较/执行/扰动)拆,拆不出的"智能"是修辞
- **整定思维→参数调优**:一切"调参"皆整定——先看清你在
  哪个参数空间、可行域边界在哪(稳定/资源饱和),再动手;
  家族实验的权衡曲线就是范式:收益单调升的地方,账单也在
  单调升
- **裕度思维→容量规划**:性能工程的"余量"(headroom/峰值
  预留)与增益裕度同构——满负荷运行=零裕度运行,摄动一来
  即崩;给系统留裕度=给回路留稳定域
- **对性能工程的接口**:反馈控制器就是最古老的"自适应
  调度器"——GPU 频率调节、拥塞窗口、限流器全是控制回路;
  分析它们的振荡(限流抖动/雪崩)用裕度语言比用直觉快
  (00 章练习三的延伸)

"稳定域在哪",C3 裕度管"扛多错",C4 整定管"参数怎么选",
C5 数据驱动管"免建模的边界";五条共用一条边界——**建模

回头再看 00 章那句话:反馈的全部价值在模型不准处——代码
能替你量出这份价值,替不了你决定为它付多少噪声账单。

**🧠 认知升维**:

- **轨迹眼**:稳定不是点是域——参数与摄动扫描下极点仍在
  左半平面,才算数
- **账单眼**:每一分鲁棒性/抑制力都有账单(噪声/能量/带宽),
  谁付、付在哪,设计前先问清
- **证据眼**:仿真给了收敛只是开始——场景覆盖、摄动界、
  时延建模三件套齐了,数字才开口说话
