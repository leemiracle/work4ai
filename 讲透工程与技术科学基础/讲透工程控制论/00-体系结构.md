## 一、这门学科怎么来的(②怎么产生的)

📖 **故事框一:麦克斯韦百年前的稳定性方程(1868)**。瓦特 1788
年的离心调速器让蒸汽机自己管自己的转速——飞球转快则阀门关,
转慢则阀门开,纯机械的负反馈。但十八世纪的工程师很快遇到一个
幽灵:**调速器会"发脾气"**——某些工况下阀门与转速互相追打,
越振越凶(通说称 hunting,追逐)。调速器用了八十年,没人说得清
它何时稳定、何时振荡。1868 年,麦克斯韦发表《On Governors》:
把每个部件的运动方程写下来,在平衡点附近**线性化**,得到特征
方程,然后问:**方程的根是不是都有负实部?**——"机器发脾气"
从此变成"根跑进了右半平面",控制理论的第一句话,就是工程
控制论的第一句话(工程问题翻译成数学语言;通说:第一篇控制
理论论文)。

📖 **故事框二:奈奎斯特与放大器的振荡(1932)**。贝尔实验室,
1927 年布莱克发明负反馈放大器:把输出的一部分反相喂回输入,
换取通带内的稳定增益——长途电话的中继器就靠它。代价是同一个
幽灵回来了:**放大器会自激振荡**。围绕一个环路绕一圈的信号,
若在某频率上恰好同相且不衰减,它就自己唱起来。1932 年奈奎斯特
发表《Regeneration Theory》:**不解闭环特征方程,只画开环频率
响应 G(jω) 绕 -1 点的圈数,就能判定闭环稳定**。设计者手里的
数据(开环,可测)与想知道的性质(闭环,难算)被一条曲线接通
——负反馈设计从此有了宪法(通说;细节在经典控制理论支)。

📖 **故事框三:1954 与"间关系科学"**。维纳 1948 年《控制论》
把"动物与机器中的控制与通信"统一成一门学问;1954 年,钱学森
在 McGraw-Hill 出版《Engineering Cybernetics》,把这门学问落到
工程地基上。该书把工程控制论定位为研究**工程系统中各部分之间
相互作用的规律**的学科——不问单个元件(那是力学/电磁学的事),
只问**元件之间的关系**(按学科史实与文献通说中性呈现;1958 年
中译本《工程控制论》出版,学科以此命名)。这一"间关系"定位
在七十年后被重新发现:当计算、通信与物理过程融成一体(CPS),
"关系"本身就是设计对象——见 01 章方向一。

### 1.1 学科史节点表:从调速器到信息物理系统

| 年代 | 节点 | 内容(通说) |
|------|------|------------|
| 1788 | **机械反馈** | 瓦特离心调速器:负反馈进入工业,稳定性问题随之而来(故事框一) |
| 1868 | **线性化判稳** | 麦克斯韦《On Governors》:特征根判稳——控制理论第一篇论文 |
| 1877/1895 | 代数判据 | Routh 与 Hurwitz 各自给出不解高阶特征方程判根位置的代数方法 |
| 1927 | 负反馈放大器 | Black(贝尔实验室):以反馈换稳定增益,自激振荡问题登场 |
| 1932 | **频率判据** | Nyquist 判据(故事框二):从开环响应读闭环稳定性 |
| 1938-45 | 战时伺服 | 火炮随动系统/雷达跟踪;维纳的滤波与预测工作(控制论前史) |
| 1948 | 控制论奠基 | 维纳《Cybernetics》:控制与通信的统一框架 |
| 1948-50 | 根轨迹 | Evans(1948-50):增益变化时闭环极点的迁移轨迹——频域设计可视化 |
| 1954 | **工程控制论** | Tsien《Engineering Cybernetics》(故事框三):间关系科学,学科命名 |
| 1960 | **卡尔曼革命** | Kalman:状态空间、能控性/能观性、LQR 与 Kalman 滤波——一年内重写学科语言 |
| 1960s-70s | 自适应与整定 | Åström 等的自适应控制与 PID 整定理论化;工业仪表化(PID 统治确立) |
| 1981 | **鲁棒转向** | Zames 提出 H∞:模型必然有错,为最坏情况设计——鲁棒控制开端 |
| 1990s | 网络化控制 | 分布式控制系统(DCS)普及;时延/丢包进入控制问题 |
| 2006 前后 | **CPS 提名** | 信息物理系统(cyber-physical systems)成为独立研究领域(通说) |
| 2015-2026 | 学习与数据驱动 | 数据驱动控制/安全学习控制升温(01 章方向三四;与 413 宇航热线同源) |

读这张表的正确姿势:学科史不是定理发明史,是**"关系"的扩容
史**——十九世纪把"机械连接"变成方程(麦克斯韦),二十世纪
中叶把"信号连接"变成曲线(奈奎斯特)与矩阵(卡尔曼),八十
年代把"模型与真实的差距"变成设计对象(Zames),今天把"计算
与通信的接入"变成新的间关系(CPS)。每一层都把上一层的"已知"
变成新的"连接问题"。

### 1.2 工程控制论在中国的建制(简述)

工程控制论作为学科建制以 1954 年英文原作与 1958 年中译本《工程
控制论》为学科史节点(按公开文献通说中性陈述);其后控制学科
在中国经历传播、中断与重建的曲折过程,改革开放后与国际控制界
恢复交流,形成今天的自动化/控制科学与工程建制(传播史细节见
01 章方向二所引专文,按素材转述)。GB/T 13745 将工程控制论列
为工程与技术科学基础二级学科(41015),无三级明细——本家族
自定主干支。

## 二、核心问题清单(③):稳定性-鲁棒性-最优性三角

工程控制论的一切问题,都挂在三角的三个顶点或其边上:

| 问题 | 状态 | 年代锚 | 证据级 |
|------|------|--------|--------|
| 回路在什么条件下稳定(线性:已有完整判据体系) | **已解决**(线性) | Maxwell 1868→Routh-Hurwitz 1877/95→Nyquist 1932 | 定理 |
| 非线性系统的李雅普诺夫函数系统构造法 | **悬而未决**(逐例构造) | Lyapunov 1892 起 | 理论问题 |
| 模型不准时,稳定还能保多少(鲁棒稳定性与裕度) | 线性框架成熟(H∞/μ),非线性未决 | Zames 1981 起 | 定理+设计 |
| 鲁棒性与最优性能否兼得 | **不能免费兼得**(有定量权衡律) | Bode 积分;Doyle 1978 LQG 反例 | 定理 |
| 最优控制的解怎么算(大规模/非线性) | LQR/LQG 框架成熟,维数与非线性受限 | Kalman 1960;Pontryagin 1956(极大值原理) | 定理+数值 |
| 网络(时延/丢包/量化)下的稳定域与调度 | 进行中 | 1990s 起网络化控制 | 定理+经验 |
| 计算与物理融合系统(CPS)的统一建模与验证 | 进行中 | 2006 前后起 | 规范+实证 |
| 学习型控制器的安全证书 | **悬而未决**(01 章方向四) | 2020s | 实证+理论 |
| PID 为何统治工业回路(理论解释滞后于实践) | 通说议题(鲁棒性-简单性平衡的主流解释) | Åström & Hägglund 2006 | 综述 |

**三角的分工直觉**:稳定性是入场券(不稳一切免谈),鲁棒性是
保险单(模型必然有错),最优性是奢侈品(在前两者约束下追求);
三者两两之间都有定量关系——Bode 积分把性能与鲁棒性锁在同一
杆秤上(美之时刻②),LQG 反例把最优与鲁棒拆成两个独立命题
(反直觉③)。

## 三、假设与代价(④)

1. **线性假设**(在平衡点附近把世界当线性):买到:特征根/
   传递函数/频域判据/状态空间整套工具,稳定=根在左半平面,
   一目了然。付出:**大范围行为不在语言内**——极限环、分岔、
   混沌这些非线性现象对线性耳朵是静默的;更隐蔽的代价是
   "线性化在哪一点做"悄悄成为设计假设(工况变了,设计跟着作废
   ——增益调度因此存在)
2. **模型可得假设**(设计者握有对象的可信数学模型):买到:
   设计的系统性——频域整定有公式、LQR 有解析解、仿真可在造出
   系统之前跑。付出:**对未建模动态的盲区**;模型的"可信"与
   "精确"之间隔着全频段的摄动,而反馈恰是为这个gap而生
   (反直觉①)——但 Bode 积分说赎金有限:不确定性与性能在
   频域里总量守恒(美之时刻②)
3. **集中式假设**(一个控制器看得见全部状态、且与传感器/执行器
   同处一个时钟):买到:全局信息+同步世界,教科书里的一切定理
   成立。付出:**通信成为新的物理**——时延、丢包、量化、乱序
   进入回路,集中式定理逐条失效;网络一旦可被攻击,回路本身
   成为攻击面(01 章方向五)——网络化控制与 CPS 的全部问题,
   都住在这条假设的代价面里

## 五、反直觉发现(⑥,家族级 ≥2)

1. **反馈的价值在于模型不准**。直觉以为反馈是"更精确的执行";
   恰恰相反——模型完全准确时,开环前馈用逆动力学就能完美复现
   参考(家族实验断言①:Δ=0 时前馈误差 9.3e-10,数值精度级),
   反馈毫无优势;**模型一失准,前馈在不稳定对象上指数崩塌**
   (Δ=0.5 时误差 ≈9e2),反馈却靠"看见误差就纠正"保持工作
   (终段 RMS 仍 <0.02)。前馈的优势生活在 Δ=0 这个**测度零的
   点**上;反馈的全部价值,恰在模型不准处——这就是"间关系
   科学"的第一定理:连接(反馈)对内容(模型误差)的免疫力
2. **从开环读闭环**。想知道闭环稳不稳,直觉要解闭环特征方程
   (高阶、参数摄动下近乎不可解);奈奎斯特判据说:画一条**开环**
   频率响应曲线,数它绕 -1 点几圈,闭环生死立判——你手里最
   容易测的数据,恰好包含你最难得的性质的全部信息。这不是
   技巧,是间关系科学的结构性红利:回路把信息折叠进开环
3. **最优≠鲁棒**。1960 年代的 LQG(线性二次高斯)是"最优控制
   的完全解";1978 年 Doyle 证明:**任意小的模型不确定性可以
   使 LQG 最优控制器失稳**(通说)。三问互不蕴含:稳定的不
   鲁棒,鲁棒的不最优,最优的可以两者皆非——工程控制论的
   设计史,就是在这三个互不蕴含的目标之间找可行域的历史

## 六、宇宙承接(⑦)与美之时刻(⑧)

- 承接:[讲透工程与技术科学基础宇宙](../README.md)全景表
  (41015 行);理论上游 12030,装置下游 41310(三链消歧框);
  本家族下设四支(README 家族树)

✨ **美之时刻 ①:麦克斯韦的翻译(1868)**。一个纯工程的烦恼
(调速器发疯)被翻译成一句纯数学的判词(特征根实部为负)——
从此"机器的脾气"有了代数。控制论百年史里最美的一个动作
反复重演:**把工程直觉折成可判定的数学**;工程控制论的学科
身份(接口层)在 1868 年第一次显形。

✨ **美之时刻 ②:Bode 积分——不确定性的守恒律**。对稳定回路,
   敏感度函数的对数积分恒为零(单积分约束,通说):**你把误差
   在某个频段按下去,它必然在别的频段鼓起来**——像水床。
   反馈不能消灭不确定性,只能搬运它;性能与鲁棒性共用一条
   守恒律。工程里所有"这里好了那里坏了"的调参玄学,背后
   常是这条积分在收税。

✨ **美之时刻 ③:1954 的"间关系"**。单个元件是力学,单个信号
   是电磁学,把它们**连起来**才出现稳定、振荡、鲁棒——性质
   不住在元件里,住在连接里。七十年后 CPS 把计算、通信、物理
   融成一体,"关系"从设计约束升级为设计对象本身:1954 年的
   学科定位预表了它(01 章方向一)。

## 📌 收束

工程控制论的体系结构=**一个对象(反馈回路里的"间关系)+
一部扩容史(机械连接→信号连接→模型差距→计算通信接入)+
一个三角(稳定性-鲁棒性-最优性,两两互不蕴含)+三条假设
(线性/模型可得/集中式,各有代价)**。它研究的问题是:元件
各自都懂的系统,连起来之后凭什么稳定、凭什么扛错、凭什么
最优。下一章看七十年回望与 CPS 时代,这个"间关系"怎么扩容
到计算与通信:[01-近五年创新](01-近五年创新.md)。

**🧠 认知升维(这章给了你什么新眼睛)**:

- **回路眼**:看到任何自适应系统(恒温器/推荐系统/重试逻辑/
  组织流程)先拆五要素——对象/测量/比较/执行/扰动;拆不出
  五要素的"反馈"是修辞
- **三角眼**:稳定、鲁棒、最优互不蕴含——听到"最优方案"
  先问稳不稳、扛不扛模型错;听到"鲁棒设计"先问牺牲了什么
  性能(水床在别处鼓起来了)
- **裕度眼**:设计不是找一个点,是找一个**域**——参数摄动、
  时延、噪声都要还在域内;只有点的方案是纸面方案
- **关系眼**:系统的麻烦与本事都不在元件里,在连接里——
  排查问题先看回路,再看部件;设计系统先设计连接,再选部件
