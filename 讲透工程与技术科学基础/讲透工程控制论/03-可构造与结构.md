# 03 · 可构造与结构——模型、控制器与回路作为数据对象

> **本章回答五问之 Q4(可构造性与结构)。**
> **本质一句话**:工程控制论里"可构造"的不是物理,而是
> **回路上的三类对象**——对象模型是名义式+摄动界的成对记录,
> 控制器是带结构的参数空间,闭环是方块图代数的连接记录;把
> 这些结构显式化,回路设计就从手艺变成工程:可校验、可对表、
> 可交接(04 章走廊的地基)。

---

## 0. 开篇:一份"控制任务单"的三件结构化家具

拆开任何一次严肃的回路设计委托,都能拆出三件家具:其一是
**对象模型**(名义动态+不确定性界——"它大概是什么,错多少"),
其二是**控制器结构**(选什么结构、参数空间多大——"拿什么去
调它"),其三是**闭环规格**(要什么证书、什么裕度、什么带宽
——"怎么算调好了")。三件家具在手,00 章的三角
(稳定性-鲁棒性-最优性)就变成**可机检的数据流水线**。

## 1. 什么是"可构造"的:三类回路对象

| 对象 | 数化身 | 可构造性 | 构造中的坑 |
|------|--------|---------|-----------|
| **传递函数结构** | 零极点+增益:G(s)=K·∏(s-zᵢ)/∏(s-pᵢ) | ✅ 高度可构造 | 零极点对消=隐藏振型进系统(02 章术语表);极点实部是稳定性的全部信息 |
| **状态空间模型** | 四矩阵 (A,B,C,D):ẋ=Ax+Bu, y=Cx | ✅ 高度可构造 | 实现不唯一(相似变换);最小实现(能控能观)才是身份证 |
| **不确定性结构** | 摄动块:加性/乘性/输出反馈形式 + 界函数 w(ω) | ✅ 可构造 | 摄动界没来源(实验/厂家/拍脑袋)则鲁棒断言无根;界的形状决定用哪种鲁棒工具 |
| **PID 参数空间** | (Kp,Ki,Kd) 三维格子+整定面 | ✅ 高度可构造 | 参数间强耦合(改 Kp 动了阻尼);微分项必带滤波与防积分饱和 |
| **回路连接结构** | 方块图代数:串=乘,并=加,反馈=G/(1+GH) | ✅ 高度可构造 | 代数化=信号流图化简;连接顺序(谁在环内)决定谁被反馈"免费"校准 |
| **整定/验证记录** | 仿真证据+工况清单+裕度读数 | ✅ 可构造 | 单工况记录无意义;证据要带工况坐标(02 章 E3-E5) |

**不可构造的**:对象的真实动态(辨识只能给估计,真值属于
物理)、李雅普诺夫函数的系统构造(逐例的艺术,00 章问题表)、
"这个回路值不值得闭环"(架构判断,支四的系统科学切面)、
以及安全性的最终裁定(规范与制度的事,02 章 E5)。

### 1.5 最小数据模式(动手者的 schema)

```yaml
# 对象模型(名义+摄动成对出现,缺一即"三无产品")
plant:
  nominal: {form: tf|ss,        # 传递函数或状态空间
            expr: "K/(s*(J*s+b))",   # 或 A,B,C,D 矩阵
            source: str}        # 机理推导/辨识/手册——必填
  uncertainty: {kind: additive|multiplicative,
                bound: "w(ω)",  # 摄动界(频率函数),必附来源
                basis: str}     # 实验/厂家数据/经验——必填
  op_point: str                 # 线性化工况(02 章语法规则三)

# 控制器(结构先于参数)
controller:
  structure: PID|lead-lag|state_fb|Hinf     # 结构=设计决策
  params: {Kp: float, Ki: float, Kd: float}
  d_filter: {alpha: float}       # 微分滤波(必填,勿裸微分)
  antiwindup: {kind: str}        # 抗积分饱和(执行器会饱和的必填)

# 闭环规格(验收口径)
closed_loop_spec:
  stability: {certificate: nyquist|lyapunov|routh,
              conditions: str}   # 证书类型+适用条件抄全(02 章)
  margins: {gain_db: float, phase_deg: float}   # 裕度必报
  bandwidth_hz: float            # 带宽(rad/s 还是 Hz 要写明)
  constraints: [saturation, slew_rate]          # 执行器约束

# 验证记录(证据带工况坐标)
verification:
  sim: {dt: float, horizon: float, scenarios: [str]}
  field: {tuning_log: str, operating_points: [str]}
```

注意 `uncertainty.bound` 与 `margins` 两处必填:把 02 章的
证书纪律写进数据结构——**数据层自带校验点,是控制计算区别于
普通脚本的第一特征**(承工程数学家族 schema 同款精神)。

## 2. 骨架一:对象模型结构(名义+摄动成对出现)

- **名义模型是合同不是真相**:它写的是"设计所依据的假设",
  真实对象的全部信息=(名义,摄动界)这个**对**;只交名义不交
  摄动界,等于把 00 章假设二的代价面静默转嫁给下游
- **实现要最小化**:同一传递函数有无穷多状态空间实现,
  能控能观的最小实现才是"同一对象"(02 章方言之争的结构面);
  非最小实现对消掉的极点仍活在系统里(暗振型)
- **摄动界的三种来源分级**:机理误差(可推导)/实验辨识
  (有置信区间)/经验包络(最弱)——鲁棒断言的证据级随来源
  定级(02 章阶梯)

## 3. 骨架二:控制器结构(PID 参数空间)

- **结构先于参数**:选 PID 还是超前滞后还是状态反馈+观测器,
  是一次结构性决策,之后才是参数;参数救不了错误的结构
  (执行器速率受限却上高增益微分=结构性错误)
- **参数空间是三维格子,整定是在格子上找可行域**:可行域由
  稳定边界+裕度要求+约束(饱和/速率)围成;整定方法
  (从 Ziegler-Nichols 到继电反馈自整定,通说)都是在这格子上
  走路的策略——家族实验断言④⑤就是这张格子上一条切线上的
  权衡曲线
- **工程必备件**:微分滤波(噪声会经裸微分爆炸——00 章
  实验断言⑤的执行器账单)、抗积分饱和(执行器饱和时积分
  仍在积累=windup,失稳的经典路径);schema 里两字段必填

## 4. 骨架三:回路连接结构(方块图的代数)

- **方块图是代数不是图画**:串联=传递函数相乘,并联=相加,
  负反馈=前向/(1+前向×反馈)——回路化简就是这套代数的
  机械化(信号流图/Mason 公式是其通说工具)
- **谁在环内,谁就被校准**:反馈的免费红利只发给环内元件——
  传感器在环内则其漂移被对抗,执行器在环内则其增益误差被
  对抗(家族实验:刚度失准 Δ=0.5 时闭环仍稳,因为对象就在
  环内);**环外的一切(参考输入传感器、前馈通道)保留
  全部误差**——这是"间关系科学"的结构化表述
- **连接顺序是设计变量**:扰动在哪注入、噪声在哪进入、
  执行器限幅在环内还是环外,三种排布给出三种鲁棒性结构——
  02 章敏感度/补敏感度(S+T=1)权衡律就住在这张连接表里

## 5. 从结构到校验:这套骨架买到了什么

- 名义+摄动成对 → 鲁棒断言有根(界有来源,断言可证伪)
- 参数空间+必备件声明 → 整定可复现(滤波/抗饱和没写=不可交)
- 连接代数显式化 → 化简可机检(谁在环内一目了然)
- 规格带证书类型 → 验收可对表(裕度没报的交付退回)

## 6. 构造合法性清单(动手前三问)

把任何回路构想变成数据结构之前,先过三问——本家族的
"类型检查":

1. **名义定住了吗**:名义模型有来源、摄动界有出处、线性化
   工况写明了?——三缺一的"稳定"是脆弱断言
2. **回路代数对吗**:连接结构化简过、谁在环内清楚、执行器
   约束在规格里?——环外的误差没人兜底
3. **有证书吗**:稳定性证书类型选了(代数/频率/能量)、裕度
   可算、验证场景覆盖工况清单?——没有证书的方案进不了
   04 章走廊

三问全过,数据才获得进入 [04 章走廊](04-工程控制论转代码.md)
的资格。**控制计算的第一特征不是算法,是入库纪律。**

## 📌 收束

可构造的是**回路上的对象**(名义+摄动/控制器结构/连接代数),
不可构造的是**真实动态与李雅普诺夫函数的系统构造法**;
结构化不是为了替代工程师,是为了让回路可校验、可交接、
可复盘。下一章把骨架接上代码:
[04-工程控制论转代码](04-工程控制论转代码.md)。

**🧠 认知升维**:

- **成对眼**:对象=名义+摄动界,只谈名义不谈界的模型是
  半张合同
- **结构眼**:参数救不了结构——先问结构与连接,再谈整定
- **环内眼**:反馈的红利只发环内——看任何回路先画环内环外,
  环外误差原样通行
