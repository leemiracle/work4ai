## 支定位与地盘

- 地盘:传递函数/零极点语言;稳定性证书两件(Routh-Hurwitz

  PID 与超前滞后校正——工业回路九成以上仍靠这套语法(通说)

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 传递函数 | G(s)=Y(s)/U(s):微分方程压成代数式,频域方言身份证 |
| 极点/零点 | 极点=自有动态(右半平面=雷区);零点=响应凹陷;对消=暗病 |
| 奈奎斯特判据 | 开环曲线绕 -1 点圈数定闭环生死——从开环读闭环 |
| 增益/相位裕度 | 离临界稳定两把尺;鲁棒性的零阶量度(家族 02 章) |
| 根轨迹 | 增益扫描下闭环极点的迁移图——稳定域的地图 |
| 敏感度函数 | S=1/(1+L):反馈改写回路性质的全部语法 |
| PID | 比例(快)+积分(准)+微分(稳):工业回路的通用语 |

## ✨ 这支最美的一个事实

奈奎斯特 1932 年判据:想知道闭环稳不稳,不必解闭环特征方程
(高阶、摄动下近乎不可解),只需画**开环**频率响应曲线,
数它绕 -1 点几圈——**手里最容易测的数据,恰好装着最难算的
性质的全部信息**。回路把闭环信息折叠进开环:间关系科学的
结构性红利(家族 00 章反直觉②,通说)。
