## 五、教材锚

- Maxwell《On Governors》(1868,控制理论第一篇,通说)
- Nyquist《Regeneration Theory》(1932,BSTJ,负反馈设计的宪法)
- Wiener《Cybernetics》(1948,控制论奠基)
- Tsien《Engineering Cybernetics》(McGraw-Hill 1954;中译本《工程控制论》1958,学科命名之作,按史实通说)
- Kalman(1960,状态空间/能控性/LQR 系列论文)
- Zames(1981,H∞ 鲁棒控制开端)
- Åström & Murray《Feedback Systems》(2008 起,理论与工程的桥,开源)
- Åström & Hägglund《Advanced PID Control》(工业回路实况报告)
