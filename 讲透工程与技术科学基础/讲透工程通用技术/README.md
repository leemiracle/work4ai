# 讲透工程通用技术 · 通用工艺层:八种跨越一切行业的工艺动词(GB/T 41070)

> **工程通用技术=行业的公共动作**:密封管界面、粉末管成形、
> 真空管介质、薄膜管表面、爆破管能量释放、包装管流通、
> 照相管成像链、物料搬运管物流——八种**不专属于任何行业、
> 却被一切行业使用**的工艺。它们像字母表:没有哪本书只由
> 某个字母写成,但每本书都靠整张字母表。一句钉住:**产品
> 定义行业,通用技术定义行业的公共动作**;通用层的尊严
> 不在离市场多近,在别的学科离不开它(00 章方法论之争)。

## 一、家族定位

- 410 地基层的**通用工艺层**:[工程数学](../讲透工程数学/README.md)
  供算法语言,[工程力学](../讲透工程力学/README.md)与
  [工程物理学](../讲透工程物理学/README.md)供物理本体,
  本家族把物理做成**跨行业复用的工艺**——新 frontline 是
  **精密沉积**(真空-薄膜双主轴,01 章检索校准)
- 百年主线:真空之路(1643 气压计→1905 旋片泵→1916 扩散
  泵→半导体洁净真空)→表面工程三级跳(1935 增透膜→
  溅射普及→1977 ALE/1996 ALD→先进制程渗透)→粉末冶金
  (1909 钨丝→1923 硬质合金→增材用粉)→控制爆破与安全
  设计→流通系统(瓦楞纸箱→无菌包装→单元化物流→AS/RS)
- 结构:五章正文以**真空与薄膜两支为主轴**(半导体时代的
  理论与产业纵深所在),其余六支以「支速写」进 00/02/03 章
  (薄支纪律:GB/T 有条目、材料薄者写薄不注水)
