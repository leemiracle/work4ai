# 讲透照相技术 · 4107070——感光与成像链:从卤化银到硅(GB/T 支)

> **支定位**:GB/T 13745 三级明细 **4107070 照相技术**:研究**把光变成可保存的像**的整条技术链——卤化银时代(潜影形成、显影定影、感光测定),数字时代(光电转换、CCD/CMOS 阵列、读出与去噪),以及两代共享的成像物理(曝光、颗粒/噪声、锐度与 MTF)。一句钉住:**照相是光的信息存储术——银盐把它存进化学,传感器把它存进电荷;链条换了,曝光三角没换**。GB/T 原生支(非自定);技术史按学科史通说。本支为薄支:当代学科重心已迁往传感器与计算成像,写薄不注水(家族治理)。

## 支定位与地盘

- 地盘:感光化学(卤化银晶体、潜影与显影催化放大、特性曲线);成像光学(曝光、景深、像差);数字传感器(光电二极管阵列、满阱与读出噪声,通说);成像链评价(MTF、颗粒性与噪声、动态范围)
- 在家族中的位置:八支中最「信息味」的一支;传感器工艺是薄膜支的下游客户,成像链的信号侧通往信息宇宙(413,纯文字互提)

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 潜影 | 几个银原子的胚芽点亮整颗晶粒:显影是催化放大器 |
| 特性曲线 | 曝光量-密度曲线:感光材料的身份证(肩、趾、直线段) |
| 曝光三角 | 光圈/快门/感光度:银盐与硅共享的三个旋钮 |
| MTF | 调制传递函数:锐度的诚实度量,镜头与传感器通算 |

## ✨ 这支最美的一个事实

**潜影:几个原子点亮一整颗晶粒**(通说)。卤化银微晶里,曝光只生成寥寥几个银原子;显影时这几个原子作为催化剂,让整颗约 10⁹ 个银原子的晶粒还原变黑——**十亿倍的化学放大**,在明胶里完成。数字时代把同样的「光子→信号→放大」搬进硅:**灵敏靠放大,放大靠单事件的雪崩式兑现**——本支给一切传感技术的家训。
