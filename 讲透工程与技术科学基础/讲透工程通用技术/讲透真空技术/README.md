## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 平均自由程 | λ=kT/(√2πd²P);空气 300 K 时 λ·P=6.74×10⁻³ m·Pa(常数) |
| 真空谱系 | 低(粗)/中/高/超高真空分段:每降一个量级,气体行为换一套近似 |
| 分子流/黏滞流 | Kn=λ/D 分界:两侧从连续流体变分子弹道,算法不再通用 |
| 抽速与通导 | 1/S_eff=1/S_pump+1/C:泵标不算数,系统才算数 |
| 放气 | 器壁脱附是极限真空的真敌人:烘烤与选材比换泵有效 |
| 残余气体 | 极限真空里剩的主要是水汽:质谱是系统的体检单 |

## ✨ 这支最美的一个事实

**同一根公式跨 9 个量级**(家族实验律1)。λ=kT/(√2·π·d²·P):大气压下 λ≈67 nm(分子挤成一团);抽到 10⁻⁴ Pa,λ≈67 m(分子互不相撞)。压强每降一个量级,λ 恰升一个量级——严格反比,逐点可断言。**Kn<0.01 的世界用流体力学,Kn>1 的世界用弹道光学**;从 10⁵ 抽到 10⁻⁴ Pa,跨越的是气体行为的整条谱系,不是一个「更空」的形容词。买泵先问放气,再问抽速——极限真空由材料放气与泵速的平衡决定,不由泵体铭牌决定。
