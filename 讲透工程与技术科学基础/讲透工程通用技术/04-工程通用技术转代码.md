# 04 · 工程通用技术转代码——λ 谱系·行星盘·自限制的走廊

> **本章回答五问之 Q5(问题→代码转换)。**
> **本质一句话**:通用技术问题一旦变成「平均自由程与流态
> 的计算、轨道时间平均的积分、饱和曲线与单调性的统计」,
> 就能进代码——真空谱系可逐档断言、均匀性可算出两个不等
> 式、自限制可算成平台方差;**唯一不可外包给代码的,是工艺
> 诀窍的显性化**(显性化之前它是手感)、**设备与材料的最终
> 裁定**(选型是工程判断)与**安全边界的拍板**(爆破与高压
> 的红线在规范与人,不在脚本)。

---

## 0. 开篇:两个不等式和一条平台,代码自己说

「真空度到底差几个量级?行星盘凭什么匀?ALD 的『多了不涨』
怎么验?」——`experiments/vacuum_and_deposition.py` 让代码
回答:平均自由程 λ=kT/(√2·π·d²·P)(空气 d=3.72 Å、T=300 K),
λ·P=6.7368×10⁻³ m·Pa 是与压强无关的谱系常数——P=10⁵ Pa 时
λ≈67 nm,P=10⁻⁴ Pa 时 λ≈67 m,**跨 9 个量级且逐档严格反比**
(律1);点源沉积 T(r)=h/(h²+r²)^{3/2}(cosθ 投影+平方衰减),
静止盘中心-边缘落差 11.6%>10%,行星盘公转+自转后轨道
时间平均把整盘压到 0.63%<1%——**几何出题、运动学解题**
(律2);ALD 的 GPC(D)=GPC_max·(1−e^{−D/D₀}),20 个递增
剂量点的后半段 std/mean=0.13%、极差/均值=0.40%(平台恒定),
而 CVD 速率 R(F)=R_max·F/(F+K) 随流量严格单调增,流量翻倍
速率+50%、剂量翻倍 GPC 纹丝不动——**自限制=ALD 的工艺
本体**(律3)。一条脚本把 00 章三条反直觉与 02 章参数纪律
全部落成可复现的数。

## 1. 可机械化边界(三件套之一)

**能进代码的**(工艺数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 真空谱系计算 | λ(P) 逐档表+Kn=λ/D 流态判据+单位换算链 |
| 泵链与通导 | 串联调和 1/S_eff=1/S_pump+1/C+量程衔接校验 |
| 均匀性分析 | 点源/分布源的轨道积分+不均匀度指标+参数扫描 |
| ALD 工艺验证 | 饱和曲线拟合+平台方差/极差检验+厚度=cycles×GPC 换算 |
| CVD 速率建模 | 流量-速率单调性检验+窗口扫描 |
| 验收抽样 | 膜厚/均匀性取点方案的统计模拟(分布眼) |
| 振速预测 | 爆破质点振速经验式回归+限值反算单段药量(通说式) |
| 缓冲校核 | 跌落高度×脆值→缓冲曲线选材(五步法的算术段) |

**不能进代码的**(工程通用技术的「不可判定域」):

1. **诀窍的显性化**——听泵声辨故障、看膜色判厚度,代码
   能积累振动/光谱数据,「显性化」那一步是人的归纳
2. **选型裁定**——泵型/靶材/缓冲材料/起重机型谱的最终
   选择是工程判断,脚本只供参数扫描的情报
3. **安全红线**——爆破与高压的边界条件拍板在规范与
   有资质的人;脚本的振速预测是参考项,不是放行章
   (写作红线同 00 章)
4. **工艺移植的等价判定**——「新腔体跑老配方算不算同一
   工艺」最终靠工艺验证试验(与[标准科学技术]
   (../讲透标准科学技术/README.md)04 章「符合性边界交人」
   同宗)

> 边界的一句话:**代码是工艺的验算台与均匀性的模拟器,
> 不是工艺员,更不是安全员。**

## 2. C1 真空谱系走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 平均自由程 | λ=kT/(√2·π·d²·P) | 常数 λ·P=6.7368×10⁻³ m·Pa(空气 300 K);d 用刚球有效直径 |
| 量级反比 | λ(10P)=10·λ(P) 逐档断言 | 「真空是谱」的可计算化:跨 9 个量级不换公式 |
| 流态判据 | Kn=λ/D(D 腔体尺度) | Kn=1 分界两侧换物理;先判段再选算法(00 章谱系眼) |
| 泵链校验 | 量程衔接+通导调和 | 断档检测;细管通导 ∝d³(分子流)——加粗管道优先于换大泵 |

成品=`experiments/vacuum_and_deposition.py` 律1。**改介质换
一行 (T,d),改腔体换一个 D,改单位走换算链**——03 章系统卡
的量程字段就是这条走廊的输入接口。

## 3. C2 行星盘均匀性走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 源模型 | T(r)=h/(h²+r²)^{3/2} | 点源+余弦发射;cosθ 投影与平方衰减的双重惩罚 |
| 静止判据 | 中心-边缘落差>10%(h=3.5) | 「不均匀」的量化底线;h 越小越糟 |
| 轨道平均 | ⟨t⟩(ρ)=∫T(√(R²+ρ²+2Rρcosψ))dψ | 自转使方位无关化——唯一不变量是半径环 |
| 代价字段 | 平均速率比(×0.007) | 均匀性买速率;大面积源/多源/穹顶找补(设备侧) |
| 蒙特卡洛 | 固定种子轨道采样 | 与积分互证(偏差<0.5%)——采样自由度的自检 |

成品=同脚本律2。教学要点:改善因子 18× 不是源变了,是
**每点在时间平均上经历同一分布**;把「均匀性问题」翻译成
「时间平均问题」,是本走廊给一切连续生产的通用思路
(包装的堆码平均、搬运的节拍平均同构)。

## 4. C3 自限制走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| ALD 模型 | GPC(D)=GPC_max·(1−e^{−D/D₀}) | 饱和曲线:欠饱和陡升、过饱和平台 |
| 平台检验 | 后半段 std/mean<1% 且极差<0.5% | 「恒定」的可计算化;不用 R² 说平台(极差更严) |
| CVD 模型 | R(F)=R_max·F/(F+K) | 供给驱动:严格单调,无化学天花板 |
| 对照实验 | 供给翻倍:ALD 不动(+2×10⁻⁷%)vs CVD +50% | 两种「多了」的物理学;选工艺的第一判据 |
| 厚度身份 | ALD:cycles×GPC;CVD:∫rate·dt | 03 章配方卡的强制区分,不可混用 |

成品=同脚本律3。教学要点:**「多了不涨」不是浪费,是
精度**——剂量不敏感性直接转化为工艺窗口与良率;把这条
与 C1 的谱系眼合用,就得到本家族的工艺世界观:**先问物理
给不给硬顶(自限制),再问介质在哪个量级(真空谱),最后
才谈参数怎么写(配方)**。

**走廊三警告**(共用):

1. 量纲与条件不齐不收算:压强不带单位与规管、均匀性不带
   取点方案的输入,一律打回(02 章 P 阶梯)
2. 分布不看过零不成立:平台检验要看方差与极差,不看单点
   差值;均匀性要看过极差,不看平均值好看
3. 安全判据不进脚本:爆破振速、高压放行的最终裁定在规范
   与人——脚本的输出永远标注「参考」

## 5. 工程师落点(把这门学科带回家)

- **谱系眼→一切「档位」问题**:存储 tiers、缓存层级、网络
  分档,先问量级差几档、分界判据是什么——跨量级系统用
  分段世界观设计(λ 走廊的移植)
- **平均眼→一切均匀性问题**:服务负载均衡、测试覆盖、
  数据采样——「让每个单元经历同一分布」的通用解法;先算
  改善因子,再查速率栏的代价(行星盘的移植)
- **自限制眼→一切精度问题**:预算按「硬顶」设计(每循环
  固定额度)比按流量设计(多多益善)更抗失控——把「多了
  不涨」从浪费重估为精度(ALD 的移植)
- **界面眼→一切泄漏问题**:安全边界、权限边界、数据边界
  的「泄漏率」要不要量化?多数组织的边界只有「漏/不漏」
  的形容词,没有 mL·s⁻¹ 的数(密封的移植)
- **接力眼→一切系统设计**:任何「串联能力」的链(泵链/
  供应链/缓存/审批流)先画量程衔接图再谈短板——断档处
  才是到不了目标的原因(03 章接力眼的算术化)

## 📌 收束

走廊三条:C1 真空谱系管「介质在哪个量级、流态用什么物理」,
C2 行星盘管「均匀性怎么用时间平均买」,C3 自限制管「精度
怎么靠物理硬顶兜底」;三条共用一条边界——**诀窍、选型、
安全永远留在人与规范那边**。跑到这里回头再看 00 章那句话:
产品定义行业,通用技术定义行业的公共动作;代码算的是
公共动作的算术,不是动作本身。

**🧠 认知升维**:

- **平台眼**:验收「恒定」看方差与极差,不看拟合好看——
  平台是统计性质,不是画出来的直线
- **环带眼**:自转把方位抹平、公转把半径摊匀——任何
  「每点经历同一分布」的机构都在做行星盘做的事
- **硬顶眼**:最可靠的精度来自物理给的天花板,不是控制
  的努力——找得到硬顶,就把开环做成确定性
