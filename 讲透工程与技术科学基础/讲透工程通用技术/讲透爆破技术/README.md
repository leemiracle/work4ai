# 讲透爆破技术 · 4107050——工业控制爆破的安全设计学(GB/T 支)

> **支定位**:GB/T 13745 三级明细 **4107050 爆破技术**(工业与民用工程侧):研究**怎么把炸药的能量当工具用**——台阶爆破(最小抵抗线、孔网参数与装药结构)、光面与预裂爆破(轮廓控制)、拆除爆破(失稳设计、定向倾倒)、爆破安全(振动与飞石控制、盲炮处置、延时起爆网络)。一句钉住:**控制爆破不是「炸得响」,是「炸得准」——能量按设计释放,边界之外寸土不动**。GB/T 原生支(非自定)。
> **写作红线(家族宪法)**:只写工业与民用工程控制爆破的工程通说,不写武器化内容、不写攻击性配方细节;炸药只述类别与工程属性;涉军工爆破一律不写。

## 支定位与地盘

- 地盘:爆破设计通说参数(最小抵抗线、单孔药量、孔距排距、堵塞与装药结构);轮廓爆破(周边孔与半孔率);拆除爆破(失稳铰点与切口高度);振动控制(质点振速预测通说式、分区延时);安全距离与盲炮处置(规范通说)
- 在家族中的位置:八支唯一的「一次性能量释放」工艺;与真空/薄膜的「连续可控」观形成对照

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 最小抵抗线 W | 药包到自由面的最短路径:能量往阻力最小处走,设计先定 W |
| 光面爆破 | 周边孔少药密孔+同时起爆:开挖轮廓线上的「撕纸线」 |
| 拆除爆破 | 炸掉关键支撑、制造铰点:结构自重完成大部分拆除功 |
| 爆破振动 | 按质点振速限值反推单段药量:安全以振速计,不以响度计 |

## ✨ 这支最美的一个事实

**拆除爆破:让重力做大部分功**(通说)。控制拆除不把建筑物炸碎,只精确削弱少量关键承重构件、制造失稳铰点,结构在自重下按预定方向倾倒解体——**炸药是扳机,重力是推土机**。工程的克制在此显影:用药量求少不求多,起爆顺序求巧不求猛。
