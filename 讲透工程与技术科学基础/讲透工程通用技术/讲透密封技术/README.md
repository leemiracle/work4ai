# 讲透密封技术 · 4107010——泄漏与密封界面的工程学(GB/T 支)

> **支定位**:GB/T 13745 三级明细 **4107010 密封技术**:研究**「让流体待在它该待的地方」**——垫片(静密封)、O 型圈(挤压弹性体)、机械密封(旋转轴端面液膜)、填料与迷宫(间隙节流)。核心对象不是密封件而是**密封界面**:泄漏住在界面的间隙里,密封是用压紧力、回弹力与液膜把界面「管理」住。一句钉住:**密封不消灭泄漏,只把泄漏率压到可接受量级**——「零泄漏」是修辞,泄漏率才是工程量。GB/T 原生支(非自定);案例按学科史与文献通说。

## 支定位与地盘

- 地盘:静密封(垫片比压、O 型圈压缩率与沟槽、法兰刚度);动密封(端面比压与液膜、填料、迷宫);泄漏率与紧密性等级;密封材料与工况匹配
- 在家族中的位置:与真空支共享「气密界面」(真空法兰是高量程应用);管道与压力容器是主场

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 密封界面 | 泄漏住在两面的间隙里:密封设计=界面几何+压紧力的管理 |
| 垫片系数 | 预紧与操作两态的比压要求(压力容器设计通说参数) |
| 端面液膜 | 机械密封端面靠微米级液膜又隔又润:密封与润滑一体两面 |
| 泄漏率 | 验收量不是「漏/不漏」,是带介质与压差条件的数 |

## ✨ 这支最美的一个事实

**机械密封:两端面既不接触,也不漏**(通说)。旋转轴密封端面间保持约微米量级液膜——太厚则泄漏,太薄则干磨烧毁;粗糙度、比压与液膜动压在界面处达成平衡。**它把「堵」做成了「浮」**:让一层受控薄膜同时承担隔离与润滑——界面工程的典型一课。
