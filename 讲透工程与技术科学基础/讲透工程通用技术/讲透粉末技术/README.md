# 讲透粉末技术 · 4107020——不熔化也能成形的工艺链(GB/T 支)

> **支定位**:GB/T 13745 三级明细 **4107020 粉末技术**(粉末冶金工艺链):研究**制粉—成形—烧结**三步把金属/陶瓷粉末变成零件:制粉(雾化/还原/破碎,粒径与分布是第一变量)、成形(模压/等静压/注射,压坯密度分布)、烧结(固相/液相,致密化与晶粒长大的竞争)。一句钉住:**熔铸问「怎么把材料化开」,粉末冶金问「怎么根本不化开**——难熔金属、多孔材料、硬质合金,凡是熔炉到不了的地方,都是这条链的地盘。GB/T 原生支(非自定);案例按学科史与文献通说。

## 支定位与地盘

- 地盘:制粉方法与粉末表征(粒径分布、流动性、松装密度);成形与压坯密度均匀性;烧结机理(驱动力=表面能差);材料族(钨钼难熔金属、WC-Co 硬质合金、含油轴承与多孔件)
- 在家族中的位置:与薄膜支构成「材料加减法」对偶——薄膜一层层加,粉末压起来再长合;溅射靶材是本支产品(实物接口)

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 制粉-成形-烧结 | 三段链:粒径决定一切的上游,致密化决定一切的下游 |
| 烧结驱动力 | 粉末表面积巨大:表面能差推着颈长与孔闭合,不熔化也致密 |
| 液相烧结 | 少量液相润湿固相:WC-Co 致密化的发动机(硬质合金通说) |
| 粒度分布 | 不是平均粒径,是整条分布曲线(D10/D50/D90)决定行为 |

## ✨ 这支最美的一个事实

**钨丝:不熔化,照样拉成丝**(通说)。钨熔点约 3422 °C,实用熔炉够不着它;Coolidge 路线(1909-1910 间完善)把钨粉压坯烧结后旋锻拉拔,白炽灯丝从此量产。**粉末冶金出生的第一个大工业,就是替熔炉解决「到不了的温度」**——今天溅射靶、含油轴承、硬质合金刀具,都是同一条逻辑的后代。
