# 03 · 可构造与结构——真空系统、工艺配方与验收单作为数据对象

> **本章回答五问之 Q4(可构造性与结构)。**
> **本质一句话**:工程通用技术里「可构造」的不是工艺诀窍
> 本身,而是**它的三类载体**——真空系统是把「泵-阀-规-室」
> 写成带通导的图,工艺配方是把「怎么做」写成参数-允差-
> 测量成对的步骤序列,验收单是把「多好才算好」写成厚度/
> 均匀性/泄漏率/振速的判据;把这些结构显式化,工艺就从
> 师徒手艺变成工程:可校验、可交接、可复现(04 章走廊的
> 地基)。主轴取真空与薄膜两支;六薄支各附一节结构速写。

---

## 0. 开篇:一份工艺文件的三个结构化家具

拆开任何一次严肃的工艺工作(新建镀膜线/移植工艺/验收
批次),都能拆出三件家具:其一是**系统结构**(介质从哪来
——泵链拓扑与通导预算),其二是**工艺配方**(介质上做什么
——步骤×参数×允差的序列),其三是**验收判据**(做完怎么判
——测什么、几处、允差多少)。三件家具在手,「介质-界面-
表面」的工艺链(00 章)每一环都变成**可机检的数据流水线**;
从盖德泵的手工阀门到今天全自动镀膜机,在数据结构层面是
同一套 schema——变的是参数密度,不变的是结构。

## 1. 什么是"可构造"的:四类结构对象

| 对象 | 数化身 | 可构造性 | 构造中的坑 |
|------|--------|---------|-----------|
| **真空系统** | 泵-阀-规-室图+通导链+烘烤位 | ✅ 高度可构造 | 通导漏算(细管杀人);规管量程与流态不匹配 |
| **工艺配方** | 步骤×{温度,压强,流量/剂量,时间,功率}×允差×测量对 | ✅ 高度可构造 | 参数无允差、无测量对(02 章 P 阶梯裸参数) |
| **验收判据** | 项目×方法×取点方案×限值(膜厚/均匀性/泄漏/振速) | ✅ 高度可构造 | 均匀性不写取点方案;泄漏率不带压差介质 |
| **膜层栈** | 层序×(材料,厚度,功能,界面处理) | ✅ 高度可构造 | 界面层隐没(吸附层/过渡层不入栈表) |

**不可构造的**:工艺诀窍的显性化之前的部分(老师傅听声辨
故障)、表面与亚表面的完整状态(只装得下代理指标)、设备
漂移史(维护记录是叙事不是参数)、以及「这条工艺线值不值得
建」的投资判断(00 章方法论之争的边界)。

### 1.5 最小数据模式(动手者的 schema)

```yaml
# 真空系统结构卡(泵-阀-规-室的机读版)
vacuum_system:
  chamber: {volume_l: float, material: str, bakeout_c: float}   # 烘烤温度必填(放气斗争)
  pumps:
    - {kind: roughing|roots|diffusion|turbo|cryo|getter,
       pumping_speed_l_per_s: float, ultimate_pa: float,
       range_pa: [lo, hi]}                                      # 量程显式(谱系眼)
  gauges:
    - {kind: pirani|capacitance|ion|BA, range_pa: [lo, hi],
       calibrated_by: str}                                      # 校准链(计量学接口)
  links:                                                        # 通导链:串联如电阻
    - {from: node, to: node, conductance_l_per_s: float,
       note: "细管/窄缝的通导在分子流区与 d³ 成正比"}
# 工艺配方卡(PVD/CVD/ALD 通用的最小骨架)
recipe:
  target_stack: [film_layer_ref]
  steps:
    - {phase: pumpdown|bake|clean|deposit|vent,
       params: {pressure_pa: [set, tol], temperature_c: [set, tol],
                flow_or_dose: [set, tol], power_w: [set, tol],
                duration_s: [set, tol]},
       measured_by: gauge_ref|crystal|pyrometer,                # 测量对必填(02 章 P1-P4)
       interlock: str}                                          # 越限动作
# ALD 循环子模式(自限制的 schema 化)
ald_cycle:
  substeps: [{act: pulse_a, dose: [set, tol]}, {act: purge, t_s: ...},
             {act: pulse_b, dose: [set, tol]}, {act: purge, t_s: ...}]
  gpc_nm: {expected: 0.11, tol: 0.01, measured_by: ellipsometry}
  cycles: int                                                   # 厚度=cycles×GPC(律3)
# 验收判据卡
acceptance:
  - {item: thickness, method: ellipsometry|profilometer,
     sampling: "每片 5 点", limit_nm: [lo, hi]}
  - {item: uniformity, definition: "(max-min)/mean",
     sampling: "3 片×9 点", limit_pct: 1.0}                     # 定义+取点+限值三件套
  - {item: leak_rate, method: helium_sniff|bubble,
     condition: {media: He, delta_pa: ...}, limit: str}
```

注意 `range_pa`、`measured_by`、`sampling` 三处必填:把 02 章
的条件显式纪律写进数据结构——**数据层自带校验点,是工艺
文件区别于笔记的第一特征**(与[工程物理学家族]
(../讲透工程物理学/03-可构造与结构.md)schema 同款精神)。

## 2. 骨架一:真空系统结构卡(介质从哪来)

- **泵链是接力不是堆叠**:每台泵有自己的量程区间,前级泵
  先把系统带到主泵的「启动压强」以下——图上必须画量程衔接,
  断档=系统抽不到目标(通说设计第一课)
- **通导是管道的电阻**:有效抽速 1/S_eff=1/S_pump+1/C,
  一根细管能把名义 2000 L/s 的泵拖成 200 L/s;分子流区通导
  对口径的三次方敏感——**加粗管道比换大泵便宜**(03 章最
  常被忽略的一行账)
- **规管要贴流量**:每个量程段配对应规(热偶/皮拉尼/
  电离),量程错配的读数比没有读数更危险(02 章开篇故事框
  的数据面)
- **放气预算**:腔体材料、烘烤温度与时间是系统卡的一等
  公民——极限真空由放气与泵速的平衡决定(00 章假设一)

## 3. 骨架二:工艺配方卡(介质上做什么)

- **步骤-参数-允差-测量对四件套**:缺允差是愿望,缺测量
  是盲跑(02 章 P 阶梯的 schema 版);PVD 与 CVD 的配方是
  连续参数序列,ALD 是循环子模式嵌套——**厚度字段的身份
  因此不同:CVD 里 thickness=∫rate·dt,ALD 里
  thickness=cycles×GPC**(家族实验律3 的结构显影)
- **互锁显式化**:越限动作(关阀/断功率/充气)写进步骤,
  不是写在操作规程的附录里——安全的结构化就是把「出事了
  谁先动」变成数据(爆破支的盲炮处置同款思想)
- **漂移字段留白**:靶材贫化、晶振漂移的维护事件挂到配方
  版本上——配方版本与设备状态的配对,是复现性的档案学

## 4. 骨架三:验收判据卡(做完怎么判)

- **定义-取点-限值三件套**:均匀性必须写 (max−min)/mean
  还是 ±% 偏差、几片几点(02 章条件显式规则);只写「均匀
  性 <1%」而不写取点方案的验收单,可以被采样的自由度玩坏
- **判据与工艺对偶**:ALD 的厚度判据是循环数开环+抽检
  修正,溅射的厚度判据是晶振在线闭环——**工艺的物理
  (自限制与否)决定验收的开环度**(01 章方向三的产线面)
- **安全判据同卡**:爆破的质点振速限值、包装的跌落试验
  谱与产品判据同属验收卡——安全不是附录,是判据清单的
  一等行(与[标准科学技术](../讲透标准科学技术/README.md)
  03 章「条款带验证」同宗)

## 5. 六薄支结构速写

### 5.1 密封选型卡

界面(静/动)×介质×温度压力×泄漏率等级×压紧方式——五行
决策表;坑:把「动密封」按「更严的静密封」选(液膜平衡被
压死,磨损即失效)。

### 5.2 粉末工艺链卡

粉(分布/流动性)→压(压力/保压/润滑)→烧(温度曲线/
气氛)→后处理;每段出口设密度与尺寸检验位;坑:压坯密度
梯度无记录,烧结变形变成「玄学」。

### 5.3 爆破设计参数卡

抵抗线/孔网/单孔药量/堵塞/延时分区/振速限值与测点——
安全字段占卡一半(红线:配方细节不入卡);坑:药量表与
起爆网络表分离,变更不同步。

### 5.4 包装缓冲五步卡

脆值→跌落高度→材料候选→缓冲曲线选静应力→厚度校核;
坑:脆值用「同类产品估的」而不是测的——整张卡的地基是
借来的。

### 5.5 照相成像链卡

光源→光学(孔径/快门)→介质(感光度/满阱)→处理(显影/
算法)→输出;两代链共用曝光三角字段;坑:把 MTF 归给
镜头或传感器单边——链上每环都乘上去。

### 5.6 搬运系统单元卡

单元(托盘规格)→设备(输送/起重/堆垛)→路径→节拍→
缓冲位;坑:设备清单齐而单元未定——「字」没统一,「文章」
白写(托盘是物流的字母表)。

## 6. 从结构到校验:这套骨架买到了什么

- 系统卡带通导与量程 → 泵链断档、规管错配可机检
- 配方卡带测量对与允差 → 裸参数、盲跑步骤可机检
- 验收卡带取点方案 → 「均匀性 <1%」类裸判据可机检
- ALD 循环子模式 → 厚度计算方式(循环数×GPC)被结构强制,
  与 CVD 的积分式不可混用

## 7. 构造合法性清单(动手前三问)

把任何工艺构想变成数据结构之前,先过三问——本家族的
「类型检查」:

1. **测量对写全了吗**:每个设定值指向哪种测量手段(P1-P4)?
   允差给了吗?量程与流态匹配吗?
2. **取点方案写明了吗**:验收判据的定义、片数点数、
   条件(压差/介质/距离)齐了吗?
3. **漂移与安全挂账了吗**:维护事件、互锁动作、安全限值
   在卡上有位置吗?

三问全过,数据才获得进入 [04 章走廊](04-工程通用技术转代码.md)
的资格。**工艺工程的第一特征不是参数多,是账目清楚。**

## 📌 收束

可构造的是**三类数据对象**(系统结构/工艺配方/验收判据,
外加膜层栈),不可构造的是**诀窍的隐性部分与状态的全貌**;
结构化不是为了替代老师傅,是为了让介质-界面-表面的链条
可校验、可交接、可复盘。下一章把骨架接上代码:
[04-工程通用技术转代码](04-工程通用技术转代码.md)。

**🧠 认知升维**:

- **接力眼**:泵链看量程衔接不看台数——任何「串联能力」
  的系统,断档比短板更致命
- **通导眼**:有效能力=源能力与通道能力的串联调和——
  加粗通道常比换大源便宜
- **开环眼**:判据的开环度由物理决定——自限制的工艺敢
  开环,供给驱动的工艺必须闭环
