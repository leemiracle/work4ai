# 讲透物料搬运技术 · 4107080——输送、起重与仓储的系统设计(GB/T 支)

> **支定位**:GB/T 13745 三级明细 **4107080 物料搬运技术**:研究**物料在厂内与链上的受控移动**——输送(带式/辊道/链式/气力,连续流)、起重(桥式/臂式起重机与葫芦,间歇重载)、仓储(货架系统与自动化立体库 AS/RS),以及把三段接起来的**搬运系统设计**:单元化(托盘/集装)、路径与节拍、装卸点设计。一句钉住:**搬运不创造产品,只创造位置**——它的全部经济学是「用更少的移动次数、更短的距离、更合手的单元,完成必要的位置改变」。GB/T 原生支(非自定);案例按学科史与文献通说。

## 支定位与地盘

- 地盘:连续输送机械(带式托辊与张力、气力悬浮速度);起重机械(三运动、起升机构与制动安全);仓储系统(货架、堆垛机、AS/RS 节拍);搬运系统设计(单元载荷原则、搬运活性系数、EIQ 分析通说)
- 在家族中的位置:与包装支构成「流通姊妹」;**产线布局与设施规划的优化侧归工业工程学(41075,同批在建,纯文字互提),本支管搬运设备与搬运系统的本体**

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 单元载荷 | 把散件集成为一个搬运单元:一次搬 1 吨远胜千次搬 1 公斤 |
| 搬运活性 | 物品待运状态的灵活度分级:搬运改进=活性升级 |
| 连续/间歇 | 输送机走连续流,起重机走间歇批:两种节拍 |
| 出入库节拍 | AS/RS 吞吐上限=堆垛机走行-升降-货叉循环时间 |

## ✨ 这支最美的一个事实

**托盘:把货物变成一个「字」**(通说)。单元载荷原则之下,散件货物一旦码上托盘,搬运系统的「字母表」就从「件」换成「单元」——叉车、货架、卡车、集装箱全部按同一单元设计;装卸点从逐件作业变成整单元交接,装卸成本数量级下降(通说量级)。**先统一搬运的「字」,再谈物流的「文章」**——与包装的单元化、标准学的托盘尺寸条款是同一件事的三个面。
