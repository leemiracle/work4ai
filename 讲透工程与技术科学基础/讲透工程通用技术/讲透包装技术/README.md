# 讲透包装技术 · 4107060——流通中的短命建筑(GB/T 支)

> **支定位**:GB/T 13745 三级明细 **4107060 包装技术**:研究**包装的功能学**——防护(缓冲减振、阻隔防潮防氧、无菌屏障)、标识(信息与溯源)、流通(单元化集装、堆码与运输工况),以及把三者合起来的**包装工程系统观**:包装不是盒子,是产品从出厂到消费之间的**一次性建筑**,要在流通环境谱下以最低成本守住产品脆值。一句钉住:**包装不防摔,包装管理碰撞的能量**。GB/T 原生支(非自定);案例按学科史与文献通说。

## 支定位与地盘

- 地盘:缓冲设计(跌落高度-脆值-缓冲曲线五步法,通说);阻隔技术(透湿透气、真空与气调、无菌包装);容器力学(瓦楞抗压与堆码);单元化(托盘与集装);包装测试谱与标识规范
- 在家族中的位置:与物料搬运支构成「流通姊妹」;与密封支共享阻隔界面问题;真空包装与阻隔膜是薄膜支的下游

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 脆值 | 产品不损坏能承受的最大加速度:包装设计的资格线 |
| 缓冲曲线 | 静应力-最大加速度曲线:选缓冲材料就是选曲线谷底 |
| 阻隔性 | 透湿/透气率:货架期是把阻隔性能换算成时间 |
| 单元化 | 把散件捆成托盘单元:包装与搬运的握手协议 |

## ✨ 这支最美的一个事实

**缓冲设计的五步法把「怕摔」变成算术**(通说)。定脆值→定流通跌落高度→选缓冲材料→按缓冲曲线找静应力谷底→校核厚度——包装的任务是把冲击衰减到脆值线以下,不是「变结实」。谷底的存在是本支最有教学价值的不对称:材料太薄触底、太硬回弹过冲,**软不是安全,合适才是安全**。
