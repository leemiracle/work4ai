## 支定位与地盘

- 地盘:三大沉积族(PVD/CVD[常压-低压-等离子增强]/ALD 自限制循环);厚度均匀性(源几何与行星盘);生长模式与结构(Frank-van der Merwe 层状/Volmer-Weber 岛状/Stranski-Krastanov 混合,通说三分;织构与应力);台阶覆盖与保形性;工艺监控(晶振/椭偏原位测厚)
- 在家族中的位置:真空支的**第一客户**;硬质涂层/光学膜/半导体栅介质是三个行业的门面;家族实验律2律3 是本支宪法级事实

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| PVD/CVD/ALD | 物理蒸出来/化学反应长出来/一层一层喂出来——三族工艺的能量与化学身份 |
| GPC | growth per cycle:ALD 每循环生长量,典型 0.05~0.15 nm(通说)——「化学计量的日工资」 |
| 剂量饱和 | 前驱体够量后 GPC 恒定:多投不再多长——自限制的实验显影(家族律3) |
| 自限制 | ALD 的工艺本体:表面反应位是硬顶,厚度=循环数×饱和 GPC |
| 行星盘 | 公转+自转让基片每点时间平均经历同一分布:运动学换均匀性(家族律2) |
| 台阶覆盖 | 深孔内壁/表面膜厚比:ALD≈1,CVD 次之,PVD 遮蔽最差(通说序) |

## ✨ 这支最美的一个事实

**自限制=ALD 的工艺本体**(家族实验律3)。同一问「多投一点前驱体会怎样」:CVD 的沉积速率随流量单调增——流量翻倍速率上移 50%;ALD 的 GPC 走饱和曲线——过饱和后 std/mean<1%、极差<0.5%,剂量翻倍厚度纹丝不动。**ALD 把「这一层只长一个原子层」从工程师的手感变成化学本身的保证**:厚度=循环数×GPC,像数台阶一样确定;这条「多了不涨」换来原子层级厚度控制与深高宽比保形覆盖——先进制程节点请它进生产线的全部理由(01 章方向三,检索校准 2026-09-07)。
