# 工程通用技术思维技能卡(GB/T 41070 · 讲透工程通用技术家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「**真空度**差几个量级什么意思」「**平均自由程**怎么算」
  ——λ=kT/(√2·π·d²·P):空气 300 K 时 λ·P=6.74×10⁻³ m·Pa,
  压强每降十倍 λ 升十倍(家族实验律1);「高真空」与
  「真空度高」的中西方向反义先对齐(02 章)
- 「**Kn 判据**」「黏滞流/分子流怎么分」——Kn=λ/D:分界
  两侧气体从连续流体变分子弹道,泵与算法全部换套(00 章
  谱系眼)
- 「**泵链**怎么配」「**通导**是什么」——1/S_eff=
  1/S_pump+1/C:管道像电阻,细管杀人;加粗管道比换大泵便宜
- 「**放气**治不了」「极限真空卡住」——器壁脱附不是漏:
  极限真空由放气与泵速的平衡决定,烘烤与材料选择是主杠杆
- 「**PVD/CVD/ALD** 怎么选」「**GPC** 什么意思」——精度
  与通量分工:公差原子级+形貌复杂归 ALD(厚度=循环数×GPC),
  通量优先归 PVD/CVD(01 章方向三)
- 「**自限制**是什么」「多投前驱体为什么不多长」——表面
  反应位是硬顶:ALD 过饱和段 std/mean<1%、极差<0.5%,剂量
  翻倍纹丝不动;CVD 流量翻倍速率+50%(家族实验律3)
- 「**行星盘**/公转自转为什么匀」「镀膜均匀性怎么保证」
  ——让每点时间平均经历同一分布:静止盘>10% 压到<1%,
  改善 18×,代价在速率栏(家族实验律2)
- 「**台阶覆盖**/保形性」——深孔内壁/表面膜厚比:ALD≈1,
  CVD 次之,PVD 遮蔽最差(通说序)
- 「**机械密封**为什么不磨轴」「**泄漏率**怎么验收」
  ——端面液膜"浮面"原理;密封验收量是 mL·s⁻¹ 的数,
  「零泄漏」是修辞(密封支)
- 「**粉末冶金**流程」「钨/硬质合金为什么不熔化成形」
  ——制粉-成形-烧结三步链,烧结驱动力=表面能差(粉末支)
- 「**最小抵抗线**/振速限值/光面爆破」——控制爆破工程
  通说:能量按设计释放,炸药是扳机重力是推土机;红线:
  只谈工业与民用安全设计(爆破支)
- 「**脆值**/**缓冲曲线**」「包装怎么防摔」——五步法把
  「怕摔」变成算术:软不是安全,合适才是(包装支)
- 「**潜影**/满阱容量」——银盐十亿倍化学放大与硅的
  电荷存储:两代成像同构「灵敏靠放大」(照相支)
- 「**单元载荷**/搬运活性」——托盘是物流的字母表:一次
  搬一个单元,装卸点成本数量级下降(搬运支)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **谱系眼** | 跨量级的量先分段:真空度/流态/公差档——先问在哪个量级,再问用什么物理与算法 |
| **自限制眼** | 看到「多了不涨」先想表面饱和:硬顶不是缺陷,是可以托付精度与良率的物理保证 |
| **平均眼** | 时间平均抹平空间梯度:几何出的难题到运动学找解;改善因子与速率代价成对报告 |
| **界面眼** | 泄漏、镀膜、烧结、粘接,一半工程现象住在界面上——先定位界面,再谈材料 |
| **接力眼** | 串联能力看量程衔接不看台数:泵链、供应链、缓存层级,断档比短板致命 |
| **分布眼** | 粒径/膜厚/节拍,均值是谣言分布是事实:D10/D50/D90、取点方案先行 |
| **硬顶眼** | 最可靠的精度来自物理天花板不是控制努力:ALD 开环、CVD 闭环,开环度由物理决定 |

## 3. 工具箱(何时用什么)

- **工艺三问**(00 章):介质在哪个量级(真空谱)→物理
  给不给硬顶(自限制)→参数怎么写(配方四件套)——先分诊
  再谈工艺
- **参数纪律**(02 章 P1-P4):设定值必配测量手段与允差;
  条件显式(规管/取点/压差介质)、单位归一(SI+换算)
- **schema 三件套**(03 章):真空系统结构卡(泵链+通导+
  规管量程)+工艺配方卡(步骤×参数×允差×测量对)+验收
  判据卡(定义-取点-限值);ALD 循环子模式与 CVD 积分式
  不可混用
- **家族实验**(`experiments/vacuum_and_deposition.py`):
  λ 谱系逐档反比+Kn 分界→行星盘两个不等式(>10%→<1%,
  速率代价)→ALD 平台(std/mean<1%,极差<0.5%)vs CVD
  单调(三律三分钟落成数)
- **走廊三条**(04 章):C1 真空谱系(已成)/C2 行星盘
  均匀性(已成)/C3 自限制检验(已成);共用警告:条件
  不齐不收算、分布看过零才成立、安全判据不进脚本

## 4. 常见误区与禁忌

- ❌ **拿「真空度」当形容词**:「高真空」中文指压强低、
  英文 high vacuum 指「高真空区」——方向相反;先对单位、
  量级与规管再对数(02 章开篇)
- ❌ **把极限真空归给泵的铭牌**:极限真空由放气与泵速的
  平衡决定;堵漏治不了放气,换泵不如烘烤(00 章假设一)
- ❌ **把 ALD 当慢版 CVD**:两者厚度身份不同——ALD 厚度=
  循环数×GPC(开环确定),CVD 厚度=∫速率·dt(必须闭环);
  「速率」一词在 ALD 语境非法,只有 GPC(03 章)
- ❌ **均匀性只报一个数**:不写定义((max−min)/mean 还是
  ±%)、不写取点方案的均匀性数字,可以被采样自由度玩坏
  (02 章条件显式规则)
- ❌ **以为多投多长**:ALD 过饱和后剂量翻倍纹丝不动——
  工艺窗口的不敏感是良率,不是浪费;CVD 才是多多益善
  (家族实验律3)
- ❌ **把「零泄漏」写进验收**:密封只把泄漏率压到量级;
  验收量必须带介质与压差条件(密封支)
- ❌ **爆破谈配方**:红线——只写工业与民用控制爆破的
  安全设计通说,配方细节与武器化内容不写(家族写作宪法)
- ❌ **均值思维选粉/验膜**:中位径相同的两条分布可以有
  相反的烧结行为;不看 D10/D90 的粉体决策是掷骰子(02 章
  分布眼)
- ❌ **把通用层当设备操作合集**:八支的公共语法(介质-
  界面-成形-表面-能量-流通-信息)是学科身份;存在感稀释
  是通用性的代价,不是不存在论(00 章方法论之争二)
