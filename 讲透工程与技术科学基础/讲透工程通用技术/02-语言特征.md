# 02 · 语言特征——量与单位的工程学:工艺语言的证据规则

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程通用技术说的是**一种把感觉全部换算成
> 数的语言**——「真空好」必须写成 10⁻⁴ Pa 与放气率,「膜匀」
> 必须写成 ±0.5% 的厚度分布,「封得住」必须写成 mL·s⁻¹ 的
> 泄漏率,「炸得准」必须写成质点振速限值与抵抗线;工艺配方
> (recipe)是它的标准句型:**每个参数可测、可控、可复现,
> 缺一项就只是手艺而不是工艺**。三栏分别回答:这套语言能
> 说什么(表达力)、工艺凭什么可信(逻辑性质)、术语怎么
> 被钉死(规范化)。主轴词汇取真空与薄膜两支;六薄支各附
> 一节术语速写。

---

## 0. 开篇:同一句「抽好了」,三种意思(教学例)

📖 **故事框(教学例)**。镀膜机前,三个班组长都说「真空抽
好了」:甲看的是机械泵表——10 Pa,对蒸发铝的实验够了;乙
看的是「真空室已到设备默认值」——10⁻³ Pa,溅射的开工线;
丙等的是烘烤后的稳定读数——10⁻⁵ Pa 且一小时不爬升,这是
放气被压住了的「好」。**同一句话在真空谱系上差 4 个量级**
(00 章反直觉①):介质纯净度、分子平均自由程、膜层纯度
全部不同。工艺语言的全部要义浓缩于此:**形容词不算数,
数+单位+测量条件才算数**——「好」必须回答「好在哪个量级、
用什么规读的、稳定了多久」。

## 1. 表达力:工艺语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 环境定量 | **介质语言** | 压强(Pa/Torr/mbar)、平均自由程、放气率——把「干净」写成数 |
| 过程定量 | **配方语言** | recipe=步骤×(温度/压强/流量/时间/功率)序列——把「手艺」写成程序 |
| 结果定量 | **验收语言** | 膜厚与均匀性、泄漏率、振速限值、脆值——把「合格」写成公差 |
| 生长机理 | **自限制语言** | GPC(nm/cycle)、饱和剂量、生长窗口——把化学计量写成工艺参数 |
| 流态判别 | **无量纲语言** | Kn=λ/D、压缩比、充气系数——量纲分析做分档 |
| 系统结构 | **链路语言** | 泵-阀-规-室的拓扑与通导——把系统写成图(03 章) |

**不能说的**(表达力边界,与生俱来):

- **手感与隐性知识**:老镀膜工听泵声辨故障、看膜色判厚度,
  进不了 recipe——语言系统性地低估未显性化的经验(显性化
  之前它们只是「玄学」)
- **界面的一切微妙**:表面能、亚表面损伤、界面扩散层的
  完整刻画超出常规词汇——能用角分辨、剖面电镜逼近,但
  常态工艺语言只装得下代理指标
- **长期漂移**:泵油老化、靶材贫化、腔壁积膜——慢变量的
  词汇是「维护记录」,不是工艺参数本身;漂移因此常在语言
  盲区里酿成事故
- **跨量纲的直觉**:「这台泵抽得快」在黏滞流与分子流区
  含义不同——量纲没换物理就换了谱段(00 章谱系眼)

## 2. 逻辑性质:工艺的可复现性规则(三栏之二)

工艺配方与验收条款的可信度来自**参数链的完整性**,不是
经验资历:

### 2.5 参数验证阶梯(工艺版 P1-P4)

| 阶梯 | 形式 | 验证状态 | 注意 |
|------|------|---------|------|
| P1 直读参数 | 温度/压强/流量直接设定并记录 | 参数+传感器成对 | 压强必须注明量程与规管种类(热偶不读高真空) |
| P2 导出参数 | 功率密度/沉积速率(石英晶振) | 标定链 | 速率测头会漂移,定期对片称重校准 |
| P3 结果参数 | 膜厚/均匀性(椭偏/台阶仪抽检) | 统计验证 | 均匀性必须写明取点方案(几片×几点) |
| P4 机理参数 | GPC/饱和剂量(工艺窗口实验) | 模型+数据 | 窗口要扫边界,不能只报中心点 |

### 2.6 三个内部语法规则

- **参数成对规则**:每个设定值必须指向一种测量手段与一个
  允差;写参数不写允差=写了一张无法验收的支票(与
  [标准科学技术](../讲透标准科学技术/README.md) 02 章
  「应条款必须带验证」同宗)
- **条件显式规则**:所有数值带条件——压强带流态与规管,
  均匀性带取点方案,泄漏率带介质与压差,振速带距离与频率
  范围;裸数(「真空 10⁻⁴」)在工程语言里不合法
- **单位归一规则**:报告单位统一到 SI(Pa),工程习惯单位
  (Torr/mbar)必须给出换算——真空行业是「单位方言」最重
  的领域之一,对表前先对单位

## 3. 规范化:术语与对译(三栏之三)

- 国际语境:ISO/IEC 真空技术词汇标准族(通说);中文语境
  GB/T 真空技术名词术语类标准(通说)。中英写作必须声明
  口径——特别是 vacuum degree 这类中式直译词
- 度量:压强语言带单位与量级(Pa 的十进位);膜厚语言带
  手段(椭偏/晶振/台阶仪);时间语言带阶段(抽气/稳定/
  工艺)

**术语对译表(日常语→工艺语;中英对照)**:

| 中文(工艺语) | 英文 | 日常语陷阱 |
|------|------|---------|
| 真空度(以压强计) | vacuum(以 residual pressure 计) | 中文「真空度高」=压强低,与英文 high vacuum 的「高」方向相反——先对方向再对数 |
| 平均自由程 | mean free path | ≠「跑得远」:是两次碰撞之间的统计距离,不是分子行程 |
| 抽速 | pumping speed | ≠「抽得快」:是体积流率(L/s),还受管道通导拖累 |
| 通导 | conductance | 管道对气流的「电导」:串联像电阻叠加,细管杀人于无形 |
| 放气 | outgassing | ≠「漏」:器壁脱附,不是外面进来——堵漏治不了放气 |
| 沉积速率 | deposition rate | 单位时间的厚度增长(nm/min);CVD 随流量单调,ALD 无此参数(有 GPC) |
| 每循环生长量 | GPC (growth per cycle) | ALD 专属:约 0.05-0.15 nm/cycle(通说);「速率」一词在 ALD 语境非法 |
| 饱和剂量 | saturation dose | 前驱体投够即停:多投不多长(自限制的实验判据) |
| 均匀性 | uniformity | 必须带定义:(max−min)/mean 还是 ±% 厚度偏差,取点几片几点 |
| 台阶覆盖 | step coverage | 深孔内壁/表面膜厚比;保形性 conformality 的量化面 |
| 泄漏率 | leak rate | 单位时间的漏气体积(Pa·m³/s 或 mL/s);「零泄漏」是修辞 |
| 脆值 | fragility (G) | 产品能承受的最大冲击加速度;≠「易碎」的形容词用法 |
| 最小抵抗线 | burden (W) | 药包到自由面的最短距离;爆破设计的第 0 个参数 |
| 烧结 | sintering | 低于熔点的固相致密化;≠「烧化」 |
| 单元载荷 | unit load | 托盘化的搬运单元;物流的「握手协议」 |

## 4. 六薄支术语速写

### 4.1 密封支词汇

垫片系数与比压(y/m,压力容器通说参数)、压缩率与沟槽
填充(O 型圈设计)、端面比压与液膜厚度(机械密封)、
紧密性等级(分级泄漏率验收)。核心纪律同 2.6:**泄漏率
必带介质与压差条件**——氦检与水检的灵敏度差着量级。

### 4.2 粉末支词汇

粒径分布(D10/D50/D90 而非「平均粒径」)、松装与振实密度、
流动性(霍尔流速)、压坯密度、烧结致密化曲线(密度-时间-
温度)。纪律:**分布语言优先于均值语言**——两条中位径相同
的分布可以有完全相反的烧结行为。

### 4.3 爆破支词汇

最小抵抗线、孔网参数(孔距×排距)、单孔装药量、堵塞长度、
单段最大药量、质点振速(安全判据,通说以 cm/s 计)。纪律
(与红线一致):参数语言只服务安全设计与振动预测,配方
细节不入本家族文本。

### 4.4 包装支词汇

脆值(G)、缓冲曲线(静应力-峰值加速度)、抗压强度与堆码
高度、透湿/透气率(WVTR/OTR)、单元尺寸链(托盘-车厢-
货架)。纪律:**流通环境谱显式化**——跌落高度与温湿度
不定,一切包装设计数字悬空。

### 4.5 照相支词汇

感光度、特性曲线(H-D 曲线,肩/趾/直线段)、颗粒度、
满阱容量、读出噪声、动态范围。两代词汇对照教学:银盐的
「颗粒性」与硅的「噪声」是同一个信息极限的两个名字。

### 4.6 搬运支词汇

单元载荷、搬运活性系数(物品待运状态的分级,通说五级)、
输送量(t/h)、起升高度与工作级别、出入库节拍(次/h)。
纪律:**次数语言优先于重量语言**——搬运成本的大头常在
装卸次数,不在单次重量。

## 📌 收束

工程通用技术语言=**把感觉换成数的换算系统(介质/配方/
验收三层语件)+参数成对的复现性规则(P1-P4 阶梯与条件
显式、单位归一的纪律)+行业方言的钉死术(真空度方向的
中西反义、GPC 对速率的排他、分布对均值的优先)**。它写下
的每个参数都在等一个测量手段与一个允差。下一章把工艺
问题压成数据结构:[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **量级眼**:形容词一律换算成量级——「好真空」差 4 个
  数量级时,先问在哪个量级再谈别的
- **条件眼**:任何工艺数值不带测量条件即不合法——规管
  种类、取点方案、压差介质,缺一不可
- **分布眼**:粉末与膜厚的世界里,均值是谣言,分布才是
  事实
