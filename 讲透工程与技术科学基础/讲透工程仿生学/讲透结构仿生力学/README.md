# 讲透结构仿生力学 · 砖泥线——轻质强韧与能量吸收(自定主干支)

> **支定位**:家族的**力学主干**——珍珠母砖泥/蛛丝/
> 骨骼这条线:生物怎么用普通成分(95% 脆性文石、
> 丝蛋白、羟基磷灰石)造出轻质强韧的材料,工程怎么
> 把这套能量学译成吸能结构。结构力学本体是
> [工程力学](../../讲透工程力学/README.md)的强度/
> 断裂框架,**互链:那边写一般力学,本支写"生物
> 层级结构"这种特殊材料组织方式的力学**——裂纹偏转、
> 桥联、摩擦拔出,强与韧两个旋钮分开调。GB/T 13745:
> 41040 无三级明细,本支为自定主干支;案例按学科史
> 通说,不指认现实个人或组织(家族写作红线)。

## 支定位与地盘

- 地盘:生物复合材料层级(分子→纳观→微观→宏观);
  砖泥结构(brick-and-mortar)能量学;裂纹偏转与
  Cook-Gordon 弱界面止裂;桥联与拔出的耗能接力;
  蛛丝分子弹簧与逐级卸载;骨骼密质/松质结构与自适应
  重塑;仿生吸能结构(夹层/梯度/点阵)的工程译法
- 在家族中的位置:翻译链"功能抽象→工程指标"环的
  力学供给方;表面支的界面强度、方法学支的优化目标
  (04 章走廊 C2/C3),都回这里取能量学

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 砖泥结构 | 95% 脆性文石+百分之几弱界面:裂纹偏转+摩擦拔出,断裂功放大约三个数量级(家族 00 章反直觉②) |
| 强韧解耦 | 峰值力由砖强度定、断裂功由界面密度定——两旋钮分开调(家族实验律3) |
| 弱界面止裂 | Cook-Gordon 机制:弱界面先张开裂尖,迫使裂纹偏转——弱点编排进设计就是耗能机关 |
| 层级增韧 | 每一级尺度设一道耗能关卡;单尺度复制出成分,复制不出涌现(00 章假设二) |
| 分子弹簧 | 蛛丝 β-折叠区逐级展开卸载:多级"保险丝",牺牲结构换延性(通说) |
| 自适应重塑 | 骨按载荷史增删材料;工程侧多为被动模拟,措辞降档(02 章对译表) |

## ✨ 这支最美的一个事实

**弱即强**(家族 00 章美之时刻②)。工程文化本能是
消除弱点,珍珠母反其道:**泥的强度故意低**,裂纹一
进界面就被偏转,拉拔过程靠摩擦持续耗能;界面越密,
拐弯与滑移的次数越多,断裂功按次累加(家族实验律3:
密度加倍,功近乎翻倍,峰值力不动)。同一个思想在
工程里到处有同构——保险丝、溃缩区、限流器:**把
"弱点"编排进系统,它就从隐患变成耗能机关**;这是
本支对一切韧性设计的赠礼。
