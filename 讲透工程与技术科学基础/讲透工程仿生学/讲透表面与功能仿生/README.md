# 讲透表面与功能仿生 · 浸润线——荷叶/壁虎/鲨鱼皮的界面(自定主干支)

> **支定位**:家族的**界面主干**——荷叶自清洁/壁虎
> 黏附/鲨鱼皮减阻这条线:功能不住在体材料里,住在
> 表面与界面的微纳结构里。表面与界面物理本体是
> [应用物理](../../../讲透物理学/讲透应用物理/README.md)
> 的浸润/黏附/摩擦框架,**互链:那边写一般界面物理,
> 本支写"生物表面"这类功能结构的翻译**——复合浸润、
> 干黏附、肋条减阻,指标全部可测。GB/T 13745:41040
> 无三级明细,本支为自定主干支;案例按学科史通说,
> 不指认现实个人或组织(家族写作红线)。

## 支定位与地盘

- 地盘:润湿性与接触角(Young 本征角);Wenzel 粗糙度
  放大与 Cassie 复合浸润;接触角滞后与滚动角;荷叶
  自洁(乳突+蜡晶+气垫);壁虎干黏附(分级刚毛+范德华);
  鲨鱼皮肋条(riblet)湍流减阻;超疏水/超亲水/图案化
  表面的工程译法与失效(浸润坍塌/粉尘)
- 在家族中的位置:翻译链"工程指标"环的主力供给方
  (接触角/滚动角是全家族最规范的对译样板);结构支
  的界面强度、方法学支的指标双写,都回这里取语法

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 复合浸润 | Cassie 式 cosθ*=f(cosθ_Y+1)−1:空气不浸润,住在括号的 +1 里(家族 00 章美之时刻①) |
| 粗糙度放大 | Wenzel 式 cosθ*=r·cosθ_Y:粗糙不改变润湿性,只放大本征性,90° 是不动点(家族实验律1) |
| 双指标定义 | 自洁=接触角>150° **且** 滚动角<10°——合取,单指标是半张合同(02 章规则二) |
| 浸润态坍塌 | 同一微结构 Cassie≈159° vs Wenzel≈133°:高压把气垫按进去,功能掉 26°(家族实验律2;头号失效模式) |
| 干黏附 | 分级刚毛分到纳米毛尖,范德华分子力累加出体重级黏附,不分泌胶(Autumn 2000,通说) |
| 肋条减阻 | 顺流向微沟槽抑制展向涡:湍流阻力降约 6-8%(通说量级),只在湍流边界层有效 |

## ✨ 这支最美的一个事实

**荷叶的秘密一半是空气**(家族 00 章反直觉③与美之
时刻①)。光滑蜡面的本征角只有约 110°——够疏水但
远不够自洁;荷叶把 90% 以上的接触面换成**空气垫**
(f≈0.05~0.1),Cassie 式一下把表观角推过 160°,
滚动角压到个位数。材料(蜡)是旧知识,结构(乳突)
是旧工艺,**新东西是"空气也是一种表面组分"这个
翻译**——功能不住在固体里,住在固-液-气三相的
复合里(家族实验律2 的最小标本)。
