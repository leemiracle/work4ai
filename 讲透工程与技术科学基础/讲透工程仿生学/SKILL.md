# 工程仿生学思维技能卡(GB/T 41040 · 讲透工程仿生学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「**向生物学习**怎么做才不是修辞」——翻译链四环:
  生物原型→功能抽象→工程指标→使能工艺(00 章)
- 「**荷叶为什么自洁**」——不是蜡,是蜡+微结构+气垫的
  复合浸润:Cassie 式 cosθ*=f(cosθ_Y+1)−1,f→0 时
  θ*→180°(家族实验律2)
- 「**珍珠母为什么韧**」——砖泥结构:95% 脆性文石+
  弱界面,裂纹偏转与拔出把断裂功放大;弱即强(00 章
  反直觉②)
- 「**Velcro 是仿生学吗**」——是起点不是终点:形态可抄,
  功能要翻译(00 章故事框二)
- 「**Wenzel/Cassie** 什么区别」「**超疏水**怎么定义」
  ——粗糙度放大 vs 气垫复合:同一微结构两态差约 26°;
  接触角>150°+滚动角<10° 才叫自洁(02 章对译表)
- 「**仿生设计流程**怎么走」「**AI+仿生**怎么合流」
  ——五接口:生物模式识别/结构优化等(01 章方向三,
  检索校准 2026-09-07)
- 「**3D 打印**与仿生什么关系」——使能技术决定仿生上限:
  功能级仿生(多尺度/梯度)第一次可制造(01 章方向一)
- 「仿生学/**生物学**什么关系」——互链:生物机制本体在
  生物学宇宙(180,待建;GB/T 注"参见 1801460"),
  本家族管翻译侧(README §〇)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **翻译眼** | 看到生物先问功能不问形态:"荷叶自洁"译成"微结构截留空气的复合浸润",物种只是线索,原理句才是产品 |
| **层级眼** | 生物解法几乎都是跨尺度的:分子(蛛丝弹簧)→纳观(文石片)→微观(砖泥)→宏观(板层);单尺度复制不出功能 |
| **平台眼** | 使能技术决定仿生上限:没有增材制造,梯度与多尺度设计只是论文插图;设计自由度的天花板在工艺 |
| **指标眼** | 一切生物学描述必须落到可测指标:"自洁"→接触角+滚动角双指标;单指标=半张合同 |
| **对照眼** | 仿生声明要过两道对照:vs 自然原型(差多少)、vs 现有工程方案(强多少);"像生物"不是性能 |
| **证据眼** | 生物断言分级:传说/形态观察/微观表征/机制实验/定量模型;壁虎三说被逐一排除才有 van der Waals(02 章阶梯) |
| **演化眼** | 演化解的是"繁殖最优"不是"工程最优":尺度/能耗/寿命/可制造四道 veto 过不了,好策略也进不了图纸 |

## 3. 工具箱(何时用什么)

- **翻译链四问**(00 章):原型是谁/功能是什么/指标几
  个/工艺靠什么——先分诊再谈设计
- **功能句柄检索**(03 章):按功能(而非物种)检索
  生物策略库——"怎样让表面不粘灰"比"荷叶"检索得宽
- **证据阶梯 B1-B5**(02 章):传说级→形态观察级→微观
  表征级→机制实验级→定量模型级——收生物断言先看级
- **译卡四栏**(03 章):生物原型/功能抽象/工程指标/
  使能工艺;入库三问:功能句柄写了吗/指标双写了吗/
  工艺与尺度写了吗
- **荷叶与珍珠母实验**(`experiments/lotus_and_nacre.py`):
  Wenzel 双单调+90° 不动点 → Cassie 气垫(荷叶参数
  稳过 150°线,两态差 26°)→ 砖泥拉拔(密度加倍功翻倍、
  峰力不变、数十倍于均质)
- **走廊三条**(04 章):C1 润湿角模型(已成)/C2 砖泥
  拉拔能量学(已成)/C3 仿生结构优化代理(设计变量化)

## 4. 常见误区与禁忌

- ❌ **形态模仿当功能仿生**:抄了乳突形状没抄复合浸润
  机制——自洁功能不出来;抄了刚毛形状没做到分子级
  接触——黏附不出来(00 章方法论之争)
- ❌ **生物故事当机制证明**:"荷叶能自洁因为它有蜡"
  是 B2 级断言;机制要排除法(壁虎三说的教训,02 章)
- ❌ **单尺度复制**:只做微结构不做低表面能(或反之)
  ——超疏水是材料×结构×气垫三件的合取,缺一即废
- ❌ **指标单写**:只报接触角不报滚动角——高接触角+
  高滚动的表面照样粘灰;功能指标至少双写(02 章规则二)
- ❌ **无使能技术谈设计**:实验室 cm² 的微结构复制不到
  m² 产线;TRL 与尺度不声明,译卡是半张合同(03 章)
- ❌ **仿生=更好**:演化解对的是繁殖不是工程;过了
  尺度/能耗/寿命/可制造四道 veto 再说"更优"(00 章
  反直觉③)
- ❌ **超疏水就是荷叶一种**:荷叶是复合浸润+低滞后;
  只有高接触角的"超疏水"可能滚动角很差——指标套装
  定义,不单指标定义
