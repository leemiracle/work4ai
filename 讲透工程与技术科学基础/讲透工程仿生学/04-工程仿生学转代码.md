# 04 · 工程仿生学转代码——润湿角·砖泥拉拔·优化代理的走廊

> **本章回答五问之 Q5(问题→代码转换)。**
> **本质一句话**:仿生问题一旦变成"关于润湿角的复合
> 浸润计算、砖泥结构的拉拔能量学、生物启发特征的参数
> 优化"的计算,就能进代码——接触角可扫描、浸润态可
> 对比、断裂功可数值积分、设计变量可寻优;**唯一不可
> 外包给代码的,是生物原型的选择与解读**(哪个物种
> 哪个器官哪个生态位——证据与判断归 02 章阶梯)、
> **功能抽象的裁定**(原理句怎么写——00 章方法论

## 0. 开篇:一片荷叶,一块珍珠母,代码自己说

「都说"荷叶的秘密一半是空气",公式里住在哪里?95%
的脆材料怎么组成韧材料?」——`experiments/lotus_and_nacre.py`
让代码回答:Wenzel 式 cosθ*=r·cosθ_Y,扫描粗糙度 r,
本征疏水(θ_Y>90°)越糙越疏、本征亲水越糙越亲,90°
是**不动点**——粗糙度不改变润湿性,只放大本征润湿性
(律1);换 Cassie 式 cosθ*=f(cosθ_Y+1)−1,固面占比
f→0 时 θ*→180°,荷叶参数(f≈0.05~0.1、θ_Y≈110°)
稳过 150° 超疏水线,而同一微结构若按进 Wenzel 态掉回
133°——**"空气不浸润"就住在括号的 +1 里**(律2);
再看珍珠母:一维砖泥拉拔锯齿模型,界面密度加倍,断裂
功近乎翻倍,峰值力纹丝不动,均质脆性对照的总功只有
它的几十分之一——**强与韧两个旋钮就此分开**(律3)。
一条脚本把 00 章假设二与 02 章证据纪律全部落成可复现
的数。

## 1. 可机械化边界(三件套之一)

**能进代码的**(仿生数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 润湿角预测 | Wenzel/Cassie 复合浸润式:微结构参数→表观接触角 |
| 浸润态对比 | 同一微结构两态(Cassie/Wenzel)的角度差与坍塌余量 |
| 拉拔能量学 | 锯齿力-位移曲线生成+梯形数值积分→断裂功 |
| 密度敏感性 | 界面密度/板径比扫描→断裂功与峰值力的双响应面 |
| 生物启发优化 | 以层级特征为设计变量的代理模型寻优(走廊 C3) |
| 库检索与匹配 | 功能句柄→条目匹配(AI 五接口的确定性子集) |
| 证据级过滤 | 入库闸门:evidence/指标对/工艺三字段齐全性机检 |

**不能进代码的**(工程仿生学的"不可判定域"):

1. **生物原型的选择与解读**——哪个物种哪个器官哪个
   生态位、B 几级证据:这是判断(02 章阶梯);代码只对
   已声明的原型算,原型选错了,算得越准错得越远
2. **功能抽象的裁定**——原理句怎么写、保留哪些层级:
   这是 00 章方法论之争的领地;"抽象"没有最优解,
   只有与证据同档的解
3. **使能工艺的可行性裁定**——TRL、尺度上限、成本:
   工艺判断与产线现实;代码能扫描设计空间,扫不出
   车间
4. **"仿生=更好"的价值裁定**——vs 自然/vs 现役的
   双对照怎么加权、失效工况怎么取舍:这是产品决策;
   代码能给响应面,不能替人画红线

> 边界的一句话:**代码是原理句的验算台与设计空间的
> 扫描仪,不是翻译本身。**

## 2. C1 润湿角模型走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| Wenzel 式 | cosθ*=r·cosθ_Y(r≥1 为粗糙度) | 只放大本征性:θ_Y>90° 越糙越疏、<90° 越糙越亲、=90° 不动点(实验律1) |
| Cassie 式 | cosθ*=f·(cosθ_Y+1)−1(f 为固面占比) | "空气不浸润"在 +1 里;f→0 ⇒ θ*→180°(实验律2) |
| 荷叶参数 | f≈0.05~0.1、θ_Y≈110° | 稳过 150° 超疏水线;光滑蜡面(f=1,r=1)仅 110°——材料×结构缺一不可 |
| 两态对比 | 同一微结构:r=2/f=0.1 下 Cassie≈159° vs Wenzel≈133° | 差约 26°;浸润坍塌(Cassie→Wenzel)是超疏水的头号失效模式(03 章失效册) |
| 边界 | 静态角≠功能 | 滚动角/滞后需另建模型;浸润态转变的压力判据是下一条走廊(未铺) |

成品=`experiments/lotus_and_nacre.py` 实验 [1][2]。**改
材料换 θ_Y,改结构换 r 或 f——03 章译卡分离的好处:
材料栏与结构栏分居两列,敏感性分析就是在列间扫描。**

## 3. C2 砖泥结构拉拔能量吸收走廊(✅ 已实现)

一维 brick-mortar 拉拔锯齿模型:界面密度可调,每界面
"弹性上升→峰值跌落→摩擦滑移"三段;断裂功=力-位移
曲线下面积(梯形数值积分,与解析式互证):

```python
# 教学版:第 i 个界面的力-位移锯齿(N 个串行)
#   段1 弹性:F=K_eff·u 升到 F_pk(储能 ½·F_pk·δ_rise)
#   段2 跌落:F 掉到残余摩擦 F_fr(裂纹偏转的释放)
#   段3 滑移:F=F_fr 保持 δ_slip(摩擦耗能 F_fr·δ_slip)
W_per_interface = 0.5 * F_pk * delta_rise + F_fr * delta_slip
W_total = trapezoid(F_series, u_series)        # 数值积分
# 断言风格:W(N) ≈ N·W1(线性);W(2N)/W(N)≈2;
# W(N)/W_均质 ≥ 数十倍(均质只有 ½·F_c·δ_c 的弹性储能,
# 裂纹一穿而过);F_max 恒 ≤ F_pk——强度不动,功在涨
```

要点:其一,**强韧解耦**——峰值力由界面强度决定、
断裂功由界面**次数**决定,两个旋钮分开调(00 章反直觉
②的最小标本);其二,教学模型的线性增长是下界——真实
珍珠母还有过程区桥联的并行参与,增益超线性(通说);
其三,加 5% 随机涨落后总功仍稳在 1% 邻域内——**锯齿
的次序无关性**正是"按次计费"型耗能的稳健性(实验
[3] 的鲁棒性小节)。

## 4. C3 仿生结构拓扑优化代理走廊(设计变量化)

工程问题:吸能件的界面密度/板径比/梯度怎么配?最小
完整版本是**代理模型寻优**:把律3 的断裂功 W(密度)
当目标、峰值力上限当约束,扫描寻优:

```python
# 教学版:峰力约束下的界面密度选优(代理=实验律3 的模型)
def objective(N):                 # 代理:断裂功随密度近似线性
    return bm_work(N, F_pk, delta_rise, F_fr, delta_slip)
def peak_force(N):                # 代理:峰力≈F_pk(密度不抬峰)
    return F_pk
best = max((N for N in range(2, 65) if peak_force(N) <= F_allow),
           key=objective)         # 教学结论:峰力不约束时取工艺上限
# 断言风格:加"板厚下限 t_min=工艺分辨率"后 N≤N_max,
# 出现解析上界 N_max=L/t_min——使能工艺(00 章假设三)
# 变成优化里的硬约束:工艺分辨率=设计空间的墙
```

要点:其一,**使能工艺进约束**——工艺分辨率(打印
最小壁厚)直接决定密度上限,这是"工艺决定仿生上限"
的算法化表达(01 章方向一);其二,梯度设计(前密后
疏)是本走廊的自然扩展——把密度 N(x) 分布当设计
变量,通向真正的拓扑优化;其三,本体在
[数学宇宙·讲透优化](../../讲透数学/讲透优化/README.md)
——本走廊只管"生物启发特征如何变成设计变量",算法
本体不重述。

**走廊三警告**(共用):

1. 原型先于计算:生物原型与功能抽象没过 B4 证据就
   建模,算的是故事不是机制(不可判定域第一条)
2. 指标双写齐收算:只报接触角或只报断裂功的走廊输出
   是半张合同(02 章规则二)
3. 代理要标域:教学代理的线性区之外(密度极高/板极薄)
   结论失效;换域重扫,不外推

## 5. 工程师落点(把这门学科带回家)

- **功能抽象法通吃一切跨域借鉴**:把"抄方案"改为
  "抽原理句再重译"——邻域学科/竞品/旧系统的经验,
  先去名词化(原理句),再落到自己的指标与工艺;
  **任何跨域搬运少了这一步,搬的是形态,丢的是功能**
- **指标双写→一切"XX 很好"断言**:性能声明至少两个
  正交指标+工况;与
  [工程物理学](../讲透工程物理学/04-工程物理学转代码.md)
  的误差预算三段式对表——同宗的账本纪律
- **强韧解耦→系统韧性设计**:峰值(容量)与总功
  (韧性)是两个旋钮——服务器集群的限流(保峰)与
  降级链路(耗能)、电池包的吸能结构、组织的冗余
  设计,都是砖泥语法的同构题:**弱点编排进系统,
  就是耗能机关,不是隐患**
- **使能技术眼→一切方法论移植**:任何"新方法好用"
  的断言先问使能件(算力/数据/工艺/工具链)在你
  的环境里成熟到几级——**仿生学六十年最大的教训:
  设计自由度的天花板从来不在想象力,在使能技术**
