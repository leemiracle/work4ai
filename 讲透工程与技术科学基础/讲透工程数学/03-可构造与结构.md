# 03 · 可构造与结构——方程、网格与网络作为数据对象

> **本章回答五问之 Q4(可构造性与结构)。**
> **本质一句话**:工程数学里"可构造"的不是物理,而是**翻译链
> 上的三类对象**——PDE 问题是带 schema 的声明式记录,网格是
> 带质量的图与单元表,神经求解器是带损失结构的参数化函数族;
> 把这些结构显式化,工程分析就从手艺变成工程,可校验、可对表、
> 可交接(04 章走廊的地基)。

---

## 0. 开篇:一份"计算任务单"的三件结构化家具

拆开任何一次严肃的工程计算委托,都能拆出三件家具:其一是
**PDE 问题记录**(方程+定义域+初边值+参数,声明式);其二是
**离散结构**(网格:节点-单元-自由度;或配点集:无网格的
采样表);其三是**求解器架构**(格式族或网络族+损失结构)。
三件家具在手,00 章的四跳链条就变成了**可机检的数据流水线**。

## 1. 什么是"可构造"的:三类工程数学对象

| 对象 | 数化身 | 可构造性 | 构造中的坑 |
|------|--------|---------|-----------|
| **PDE 问题** | 声明式 schema(方程项+域+初边值+参数) | ✅ 高度可构造 | 适定性未声明即"三无产品"(存在/唯一/稳定都不问);参数必带来源与单位 |
| **网格结构** | 图(节点-单元-邻接)+几何质量字段 | ✅ 高度可构造 | 单元退化(钝角/负体积)使刚度矩阵病态;网格质量是格式精度的前置条件 |
| **配点结构** | 采样表(位置+权重),无网格方法用 | ✅ 可构造 | 配点分布影响训练但**不提供收敛保证**(家族实验断言③)——与网格的地位本质不同 |
| **神经求解器架构** | 参数化函数族+损失结构(残差/边界/数据) | ✅ 可构造 | 损失各项的权重是方法参数不是客观量;表达力与可训练性之间的缺口(01 章方向二) |
| **误差估计子** | 后验泛函(残差驱动/恢复型) | ✅ 可构造 | 估计子自身有可靠性与效率两指标;"常数未知"的老病(02 章 E2) |
| **解算映射(算子学习)** | 网络(G: 参数↦解) + 数据集 | ✅ 可构造 | 训练分布外的泛化无保证;数据集来源要过证据级 |

**不可构造的**:物理本体对错(validation 要靠实验,翻译链内
无自足判据)、湍流封闭模型的选择(经验与尺度分离的艺术)、
训练是否找到"好解"(全局最优不可判)、以及"这个模型该不该
建"(建模判断,数学建模家族的领地)。

### 1.5 最小数据模式(动手者的 schema)

```yaml
# PDE 问题记录(00 章第一二跳的形式化)
pde_problem:
  name: str
  strong_form: "L[u] = f"           # 强形式;弱形式另记 weak_form
  domain: str                        # 定义域(几何来源/单位)
  bc: [{type: Dirichlet|Neumann|Robin,
        where: str, value: str}]     # 初边值;缺项即不合规
  params: [{sym: str, value: float,
            unit: str, source: str}] # 参数必带来源(02 章口径声明)
  wellposedness_note: str            # 适定性:引用定理或声明存疑

# 网格结构(第三跳的离散对象)
mesh:
  nodes: [[x, y]]                    # 节点坐标
  cells: [[n1, n2, n3]]              # 单元-节点邻接(三角形示例)
  dof_map: {cell: [local]}           # 单元→自由度映射
  quality: {metric: str,             # 质量度量(最小角/雅可比)
            value: float}            # 质量字段必填,退化即红旗

# 神经求解器(第四跳的数据线对象)
neural_solver:
  architecture: {type: MLP|FNO|DeepONet,
                 width: int, depth: int}   # 架构即假设
  hard_bc: "x(1-x)·N(x)"             # 边界硬编码(或惩罚项声明)
  loss: {pde_residual: {weight, points},
         boundary:    {weight, kind},
         data:        {weight, dataset}}   # 各项权重=方法参数,须声明
  training: {collocation: int,        # 采样密度(参数化,非网格)
             seed: int}               # 可复现性
```

注意 `wellposedness_note` 与 `quality` 两处必填:把 02 章的口径
声明纪律写进数据结构——**数据层自带校验点,是工程数学计算
区别于普通脚本的第一特征**(承仿真家族 VV&A"数据层自带信任
等级"同款精神)。

## 2. 骨架一:PDE 问题结构(第一二跳的语法)

- **强形式与弱形式是两个对象**:强形式 L[u]=f 逐点成立,适合
  差分;弱形式(分部积分后的积分恒等式)降低光滑性要求、天然
  吸收 Neumann 条件,适合有限元——**同一物理的两种代数形态**,
  schema 里分字段记录,混写即埋错
- **初边值的完备性是"定住"问题的一票**:方程+不完备边界条件
  =不适定;Dirichlet/Neumann/Robin 的组合合法性有定理可查,
  schema 的 bc 列表因此可机检(漏项红旗)
- **参数的三元组**(值+单位+来源):单位错配是工程计算事故的
  头号来源(火星气候探测器的单位事故是全行业教材);来源字段
  把参数接到证据阶梯上(02 章)

## 3. 骨架二:网格结构(第三跳的几何骨架)

- **网格是图,不是图画**:节点-单元-邻接的图结构承载稀疏矩阵
  的骨架;刚度矩阵/差分 stencil 的邻接模式直接从图导出
  (数值线代家族的地盘:大型稀疏求解)
- **质量字段是精度的前置条件**:同样的格式,退化单元上的误差
  可以差几个量级;自适应加密(误差估计子驱动)把质量字段变成
  控制回路——00 章问题表"后验估计与自适应"的数据面
- **网格生成是成本,不只是工序**:复杂几何的网格人工工时占
  工程分析大头(00 章假设二的代价面)——这是无网格方法的
  第一卖点,也是它失去网格误差结构的第一代价(00 章反直觉③)

## 4. 骨架三:神经求解器结构(第四跳的数据线骨架)

- **损失结构即问题声明**:PDE 残差项+边界项+数据项的加权组合
  ——每一项都是翻译(方程→残差惩罚,边界条件→约束,观测→
  拟合);**权重是方法参数不是物理**,声明进 schema
  (01 章方向四自适应加权的方法论面)
- **边界处理的两条路线**:硬编码(解的函数族恒满足边界,
  如乘 x(1-x) 因子——家族实验的做法)与惩罚项(边界进损失);
  前者解空间小而干净,后者通用但多一个权重要调
- **架构即假设**:MLP/FNO/DeepONet 的选择=对解结构的先验假设
  (FNO 假设频域结构有效);配点表只参数化采样,**不是网格**
  ——"网络+配点"与"格式+网格"是两种方法论结构,03 章的
  表把它们分列就是这个理由

## 5. 从结构到校验:这套骨架买到了什么

- PDE schema → 完备性可机检(bc 漏项/参数缺源红旗)
- 网格质量字段 → 病态预警可自动化(退化单元/条件数)
- 损失结构声明 → 训练可复现、可对比(seed/权重/配点全记录)
- 误差估计子 → 自适应回路可闭环(哪里加密由数据说话)

## 6. 构造合法性清单(动手前三问)

把任何工程计算构想变成数据结构之前,先过三问——本家族的
"类型检查":

1. **定住了吗**:方程+初边值完备,适定性有引文或有存疑声明?
   ——不定的问题算出的数没有收件人
2. **骨架干净吗**:网格质量字段达标(或配点/架构假设已声明)?
   ——离散结构的病态在求解之前就存在
3. **能对表吗**:验证手段(解析特例/基准/收敛阶复现)与
   不确定度口径想好了?——没有对表方案的记录进不了 04 章走廊

三问全过,数据才获得进入 [04 章走廊](04-工程数学转代码.md)
的资格。**工程数学计算的第一特征不是算法,是入库纪律。**

## 📌 收束

可构造的是**翻译链上的对象**(PDE schema/网格/损失结构/
估计子),不可构造的是**物理本体的对错与建模的判断**;
结构化不是为了替代工程师,是为了让分析可校验、可交接、
可复盘。下一章把骨架接上代码:[04-工程数学转代码](04-工程数学转代码.md)。

**🧠 认知升维**:

- **声明眼**:PDE 问题是一份合同(方程+域+初边值+参数),
  缺条款的合同不签
- **质量前置眼**:先查网格质量与条件数,再谈格式精度——
  骨架病态,精度是装饰
- **架构假设眼**:选网络架构=押注解结构;配点不是网格,
  采样密度买不来收敛
