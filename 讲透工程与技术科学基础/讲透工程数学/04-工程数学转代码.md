# 04 · 工程数学转代码——方程·验证·损失的走廊

> **本章回答五问之 Q5(问题→代码转换)。**
> **本质一句话**:工程数学的问题一旦变成"关于离散结构、收敛
> 阶与损失函数的计算",就能进代码——方程可离散、误差可复现、
> 物理可写成损失;**唯一不可外包给代码的,是建模判断**(这个
> 方程配不配物理)与**可信度裁定**(这个数敢不敢签字)——
> 那是 validation 与 UQ 的事,要实验与规范做主。

---

## 0. 开篇:一道方程,两种机器

「-u″=f 到底怎么算?网格方法和无网格方法差在哪?」——这个
教科书级问题,能不能让代码自己说话?

`experiments/pinn_vs_fdm.py` 给出同一泊松问题的三解法对比:
有限差分(中心差分+追赶法)、教学版 PINN(随机 tanh 特征+
输出层最小二乘,边界 x(1-x) 硬编码)、解析解(参考基准)。
跑出来三组结论:FDM 误差按 h² 干净收敛(数值收敛阶≈2);
小规模 PINN 达到粗网格 FDM 同量级误差(教学版可行性);
**PINN 误差不随配点密度下降**——误差由基表达力决定,不由
采样密度决定(方法论分野的最小展示)。**但脚本同时打印纪律
提醒:教学版 PINN 非生产 PINN;两条路线的胜负不在精度在
结构**(00 章反直觉③)。

## 1. 可机械化边界(三件套之一)

**能进代码的**(翻译链数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 离散与求解 | 方程+网格 → 稀疏线性方程组(家族实验 FDM 走廊) |
| 收敛阶复现 | 逐次加密 → log2(e_h/e_{h/2}) 数值验证(E3 证据的制造机) |
| 残差与损失 | 方程 → 配点残差/损失结构(PINN 的"物理"怎么进代码) |
| 后验误差估计 | 残差泛函 → 加密建议(自适应回路) |
| 参数反演 | 观测数据+正问题 → 优化/贝叶斯后验(反问题支走廊) |
| 不确定度传播 | 输入分布 → 输出矩/区间(蒙特卡洛/多项式混沌,UQ 支) |

**不能进代码的**(工程数学的"不可判定域"):

1. **建模判断**——哪个方程配这团物理:本构选择、维度取舍、
   简化合法性;代码只能对已声明的模型求解,不能裁定模型对错
2. **validation**——与物理对表要实验;代码可做 verification
   (收敛阶/manufactured solution),两闸不可互冒(00 章反直觉②)
3. **网格的艺术**——复杂几何的优质网格生成长期是半手艺;
   自适应在压缩这个域,但初始构型仍需人的几何判断
4. **训练的"找到"**——优化器停在哪个解、是否伪收敛,
   没有完备判据(表达力≠可训练性,01 章方向二)

> 边界的一句话:**代码是翻译链的加速器,不是翻译者本身**。

## 2. C1 有限差分走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 方程 | -u″=f,u(0)=u(1)=0 | 泊松一维版;schema 见 03 章 |
| 格式 | 中心差分 (2u_i-u_{i-1}-u_{i+1})/h² | 二阶截断;时间相关问题先过 CFL(稳定性前置,02 章) |
| 求解 | 三对角追赶法(Thomas) | O(n);大型稀疏的一般情形归[讲透数学/讲透数值线代](../../讲透数学/讲透数值线代/) |
| 验证 | 逐次加密收敛阶复现 | 制造 E3 证据的标准动作 |

成品=`experiments/pinn_vs_fdm.py` §FDM(离散+追赶+收敛阶)。
十行核心完成的事:一份方程声明 → 稀疏方程组 → 误差曲线。
**改格式改一行,改问题改一处**——schema 分离的好处在此兑现。

## 3. C2 收敛阶验证走廊(制造你自己的证据)

02 章断言阶梯的 E3(验证级)怎么制造?**逐次加密+对数斜率**:

```python
# 收敛阶复现(02 章 E3 证据的制造机;示意:对任意 solver 可复用)
errors = []
for n in (16, 32, 64, 128):          # 网格逐次加密一倍
    h, u = solve_fdm(n)              # 任何带收敛的离散求解器
    errors.append(max_err(u, exact)) # 与已知解比(解析/制造解)
orders = [math.log2(errors[i-1]/errors[i])
          for i in range(1, len(errors))]
assert all(1.7 < p < 2.3 for p in orders)   # 二阶格式,数值复现
```

**manufactured solution 变体**:没有解析解时,任取光滑 u*,
令 f = L[u*]——即把解"造"出来再反推右端——同一套斜率检验
照跑——V&V 手册的标准武器(通说)。**警告:这只制造
verification 证据;方程对不对物理,这条走廊一字不提。**

## 4. C3 PINN 损失结构走廊(物理怎么进代码)

PINN 的"物理信息"在代码里就是**损失结构**(03 章 schema 的
落地):

```python
# 教学版 PINN:u_θ(x) = x(1-x)·Σ w_j·tanh(s_j·x + c_j)
# 边界硬编码(x(1-x) 因子恒零于两端);隐层固定随机(随机特征),
# 输出层权重 w 由配点残差最小二乘解析求解(教学简化:免梯度训练)
def residual_row(basis_j, x):        # -g_j″(x):残差对 w 线性
    g, gp, gpp = basis_j(x)          # 基函数及其一、二阶导
    return -gpp
# L(w) = Σ_i [Σ_j w_j·residual_row(j, x_i) - f(x_i)]²
# → 正规方程 (AᵀA + λI)w = Aᵀf,纯 math 高斯消元可解
```

要点三条:其一,**边界用因子硬编码**(u 恒满足 Dirichlet),
损失只剩物理残差——边界处理两条路线(硬编码/惩罚)的最小
示范;其二,**残差对输出层权重线性**,最小二乘解析可解——
这是"解析最小网络"的教学简化,生产 PINN 是全网络梯度训练
(01 章方向四);其三,**配点密度是采样参数不是网格**——
密度加密买不来收敛,表达力(隐层规模)才买得来(家族实验
断言③;练习 2 动手验证)。

## 5. C4-C5 反演与 UQ 走廊(通向两支的桥)

- **C4 参数反演**:观测数据 z_obs + 正问题 u(θ) →
  min‖u(θ)-z_obs‖²(+正则化 λ‖θ-θ₀‖²)——Tikhonov 形式;
  与 C3 的损失结构同构(数据项+物理项加权),**PINN 反问题的
  代码面就是正问题损失加一列**。正主在
  [讲透数学/讲透计算数学/讲透反问题](../../讲透数学/讲透计算数学/讲透反问题/)
  (数学理论)与工程反问题支(工程现场)
- **C5 不确定度传播**:输入分布 → 输出统计:蒙特卡洛(万能、
  1/√N 慢)与多项式混沌(光滑快、维度受限)双轨;输出从"一个
  数"变"一个分布"——UQ 支的走廊,与计量学(波 5 待建)的
  测量不确定度在规范层合流

**走廊三警告**(共用):

1. 口径即证据:每个数字出口必带证据级(E1-E5,02 章)
2. verification 冒充 validation 是工程计算的第一大案
3. 训练类走廊的结论必带 seed 与损失结构声明——无复现性的
   亮点图不构成证据

## 6. 工程师落点(把这门学科带回家)

- **收敛阶检验**→ CI 的同构物:任何数值组件上线前跑"逐次
  加密斜率"——它就是数值代码的单元测试
- **损失结构**→ 多目标系统的通用语法:你的 PDE 残差/边界/
  数据三项,与推荐系统的多目标权重同构(权重=方法参数须声明)
- **schema 分离**→ 配置驱动的计算服务:方程声明/离散参数/
  求解器配置三层分离,即"基础设施即代码"在计算侧的形态
- **FDM 三对角**→ 流水线作业的骨架:追赶法即动态规划的
  线性代数亲戚;理解它就理解了"局部依赖性"怎么变成 O(n)
- **对性能工程的接口**:大规模 PDE 求解=稀疏矩阵乘+通信
  (GPU/HPC 家族的主战场);格式选择直接决定并行度
  (显式格式天然并行、隐式格式要解全局方程组——CFL 的
  并行代价面)

## 📌 收束

走廊五条:FDM(C1,已成)管"怎么算",收敛阶验证(C2)管
"信多少",PINN 损失(C3)管"物理怎么进数据线",反演(C4)
与 UQ(C5)管另外半边天下;五条共用一条边界——**建模判断、
validation、可信度裁定永远留在人与规范那边**。跑到这里,
回头再看 00 章那句钉住本质的话:工程数学把物理直觉变成
机器上可信的数;代码能替你算数,替不了你担保。

**🧠 认知升维**:

- **斜率眼**:任何数值结果先问收敛阶复现过没有——
  没有斜率的精度是轶事
- **损失眼**:看到任何"学习+物理"系统,先拆损失结构——
  每一项是什么、权重谁定的
- **口径眼**:交接计算结论时自带四件套(方程/离散/验证/
  不确定度)——不写口径的交接是把责任一起交出去
