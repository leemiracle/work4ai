## 一、这门学科怎么来的(②怎么产生的)

📖 **故事框一:CFL 条件的诞生(1928)**。格廷根,库朗、弗里德里
希斯与列维三人为双曲方程写一篇存在性证明:把连续方程换成有限
差分,证明差分解收敛,极限即为连续解的存在性——**差分格式本是
证明工具,不是计算工具**(那时没有电子计算机)。证明需要的
一个技术条件后来变成了工程的守门员:信息在一个时间步里跑的
距离不能超过一个网格——Δt ≤ Δx/|c|,CFL 条件。这篇 1928 年的
论文在计算时代被重新发现,今天每一台机器上每一个显式格式的
时间步长都要过这道闸(通说陈述;§六美之时刻①)。

📖 **故事框二:有限元的起源之争(1943-1965)**。有限元至少被
独立发明了三次,三次互不通气。其一,库朗 1943 年在 Bulletin of
the American Mathematical Society 上把 Rayleigh-Ritz 变分法用在
三角剖分上,逐片线性逼近——数学上的雏形,沉睡十余年(其思想
与 1928 年那篇一脉相承:变分与离散的联姻)。其二,1950 年代
波音的工程集团(Turner-Clough-Martin-Topp,1956)为机翼结构
分析发明刚度矩阵法,Clough 1960 年造出"finite element"一词——
工程需求驱动的第二次发明。其三,冯康 1965 年发表《基于变分原理
的差分格式》,在中国独立给出有限元的数学理论(通说:三项独立
发明,殊途同归)。**同一台机器被数学的变分传统与工程的结构
需求各造一次**——工程数学的学科身份(接口层)在这段历史里
第一次显形。

📖 **故事框三:Raissi 时刻(2019)**。用神经网络解 PDE 并不新:
1990 年代已有 Lagaris 等(1998,通说)的先例。2019 年,Raissi、
Perdikaris 与 Karniadakis 在 Journal of Computational Physics
(378:687-707)把两件旧事拼成新范式:**自动微分**让网络的
PDE 残差可以精确可微,于是物理定律(方程本身)从"解的存在的
前提"变成**损失函数里的一项**——在配点上惩罚 -u″-f,加上边界
条件,梯度下降即可解方程。PINN(physics-informed neural
network)随之引爆:无网格、可融合数据、天然适配反问题。
热点之下的冷判断留到 §二与 01 章:它在粗网格 FDM 毫秒解决的
正问题上不占优,赢面在反问题、高维与复杂几何。

### 1.1 学科史节点表:从纳维-斯托克斯到物理信息神经网络

| 年代 | 节点 | 内容(通说) |
|------|------|------------|
| 1822/1845 | **方程层的奠基** | Navier 与 Stokes 给出粘性流体运动方程(NS 方程)——工程数学的"物理→方程"第一跳在十九世纪上半叶完成 |
| 1908 | 直接变分近似 | Ritz 法:把解方程换成求泛函极小的逼近——变分路线的开端(有限元的精神祖先) |
| 1928 | **差分稳定性** | Courant-Friedrichs-Lewy:CFL 条件(故事框一);差分格式从证明工具走向计算工具的前夜 |
| 1943 | **有限元雏形** | Courant 三角剖分上的变分解(故事框二第一棒) |
| 1946-50s | 计算机登场 | 蒙特卡洛(乌拉姆/冯诺依曼 1946)与数值天气预报同期起步——"可算"的硬件条件成形 |
| 1956/1960 | **有限元命名** | Turner-Clough-Martin-Topp 刚度矩阵;Clough 造词 finite element(故事框二第二棒) |
| 1965 | **中国学派** | 冯康《基于变分原理的差分格式》独立提出有限元(故事框二第三棒) |
| 1967 | 工程正典化 | Zienkiewicz《The Finite Element Method》出版——有限元从航空航天专属变为通用工程语言 |
| 1968-70s | **CFD 产业化前夜** | NASTRAN(1968,NASA)向工业扩散;1972 Patankar-Spalding 的 SIMPLE 算法把流场压力-速度耦合变成工程流程 |
| 1956/1970s | 数学侧理论化 | Lax 等价定理(1956,通说);Babuška-Brezzi 有限元误差理论——工程格式获得数学保证书 |
| 1960s-90s | 反问题与正则化 | Tikhonov 学派:不适定问题的正则化(数学宇宙反问题支的诞生史) |
| 1990s-2010s | **V&V 规范化** | Roache 命名 verification & validation;ASME/AIAA 出 V&V 规范(如 ASME V&V 20)——可信度成为制度而不只是手艺 |
| 2019 | **PINN** | Raissi-Perdikaris-Karniadakis(故事框三)——物理定律进入损失函数 |
| 2019-2021 | **神经算子** | DeepONet(Lu 等)与 FNO(Li 等,ICLR 2021):从"解一个方程"到"学解算子的映射" |
| 2021-2026 | 数据-物理融合扩域 | 自适应加权/课程学习/概率 PINN/工业落地(01 章三分天下) |

读这张表的正确姿势:学科史不是格式发明史,是**翻译层的增层史**
——十九世纪补全"物理→方程",二十世纪中叶建成"方程→离散",
世纪末补上"可算→可信"(V&V),2019 年后新开一层"数据→模型"。
每一层的语法在 02 章展开。

### 1.2 中国的工程数学建制(简述)

中国计算数学学派自冯康(有限元独立发明者之一)以来,在有限元、
辛几何算法等方向形成自有谱系(学科建制史实,通说陈述);工程
数学作为工科公共数学课程与 CAE 产业(有限元/CFD 商用软件)的
语言基础,由工科数学教学与工业仿真实践共同承载。GB/T 13745
将工程数学列为工程与技术科学基础二级学科(41010),无三级明细
——本家族自定主干支。

## 二、核心问题清单(③):解析-数值-数据三分天下

当代工程计算的格局是三种语言的天下:解析(公式)、数值(网格)、
数据(神经网络)。核心问题按此三分:

| 问题 | 状态 | 年代锚 | 证据级 |
|------|------|--------|--------|
| NS 方程解的存在性与光滑性 | **悬而未决**(千禧年问题) | Clay 所列七问题之一(2000) | 数学问题 |
| 湍流封闭:DNS 成本随 Re 急剧增长,怎么算工程湍流 | **悬而未决**(实用路线:RANS/LES/WMLES 分层) | Richardson-Kolmogorov 谱系;1950s 起工程近似 | 理论+经验 |
| 后验误差估计与自适应:加密哪儿的网格 | 进行中(残差型估计子已入工业求解器) | Babuška-Rheinboldt 1978 起 | 定理+工程 |
| 神经逼近的表达力与可训练性差距(spectral bias 等训练失败模式) | **悬而未决** | 2019 后(PINN 时代) | 实证+理论 |
| 多任务损失权重怎么定(loss balancing) | 进行中(自适应加权/课程学习) | 2021-2026(01 章方向三) | 实证 |
| 反问题的正则化参数怎么选 | 框架已有(Tikhonov/贝叶斯),自动化选择未决 | 1960s 起 | 定理+经验 |
| 计算结果的可信度怎么陈述(V&V&UQ) | 进行中(规范已成,贯通未成) | ASME V&V 20(2008)起 | 规范 |
| 解析/数值/数据三线何时用哪线(方法选型) | 转化为工程判断题(本家族 02/04 章供判据) | 2019 后凸显 | 方法论 |

**三分天下的分工直觉**(01 章展开):解析给洞察与极限情形,
数值给正问题的精度与认证,数据给反问题、高维与快速求值;
三者正在互相进入对方的领地(物理信息机器学习=数据线向正问题
领地的进击,而自适应有限元=数值线的智能化)。

## 三、假设与代价(④)

1. **连续介质假设**(物理→方程的跳):物体可由连续场(密度/
   温度/速度)描述。买到:PDE 语言、边值问题的完整数学装置、
   两百年的方程库。付出:**多尺度与离散结构失效**——裂纹尖端、
   颗粒流、稀薄气体里连续语言说不了话;更隐蔽的代价是**网格
   分辨率悄悄变成物理假设**(一个网格单元内发生的一切都不在
   模型里,湍流模型的整个行业因此存在)
2. **可离散化假设**(方程→离散的跳):连续问题可由有限自由度
   逼近且逼近可证。买到:线性方程组、收敛阶、误差控制——
   现代工程仿真的全部产能。付出:**稳定性条件把步长锁死在网格
   上**(显式格式的 CFL:网格减半、时间步长也须减半,计算量
   立方级增长);网格生成本身占工程分析大量人工工时——
   "可算"的成本大头常常不在求解,在离散化
3. **可学习假设**(数据→模型的跳):解算子可由网络逼近,且
   训练能找到它。买到:一次学习、毫秒求值;无缝融合观测数据;
   反问题不再需要无数次正问题求解。付出:**表达力与可训练性
   的理论缺口**(训练失败模式仍是实证科学);域外泛化无保证;
   可信度认证缺位——与传统数值"每一步都有误差界"相比,
   数据线的错误是**无声的**(这是 41099 都装不下的新问题,
   由 UQ 支认领)

## 五、反直觉发现(⑥,家族级 ≥2)

1. **更快的求解器改变的是工程决策结构,不只是工程速度**。
   1970 年代一个有限元模型跑一夜,工程师的流程是"冻结参数、
   单次验证、经验兜底";求解加速千倍后,流程变成"设计空间
   探索+优化闭环"——仿真从**验证器**变成**探索器**。素材里的
   工业案例(01 章方向五:Shell 反应器仿真加速达亿倍量级,
   按来源转述)落点正是"把仿真塞进设计环",而不是"同一仿真
   算得快"。由此获得一副眼镜:**评估任何计算加速,先问它改写
   了哪一层的流程**,只省时间不改结构的加速会被旧流程消化掉
2. **收敛的格式可以给出错误的物理解**。Lax 等价定理保证:
   格式相容且稳定,则网格加密时收敛到**这个方程**的解——
   但它不保证"这个方程是**那个物理**"。数值耗散能把非物理
   振荡抹得干干净净(解看起来漂亮),网格无法分辨的物理
   (小尺度湍流)悄悄被格式吞掉。**verification(解对了
   方程)与 validation(方程对了物理)是两道独立的闸**
   (Roache 的 V&V 命名的全部意义);只跑第一道闸的仿真,
   精确地错着
3. **无网格方法的第一卖点是"没有网格",第一代价也是"没有
   网格"**。PINN 免去网格生成(工程分析的隐性成本大头),
   但也失去网格提供的误差结构与收敛保证——误差不随"采样
   密度"系统下降(家族实验的断言③:误差由基/网络表达力
   决定,不由配点数决定)。**方法论的分水岭不在精度,在误差
   的结构**:数值线的误差有阶、可外推,数据线的误差有界、
   难外推

✨ **美之时刻 ①:CFL 条件(1928)**。一个为了证明存在性而生的
技术条件,三十多年后成为每一台计算机上每一个显式格式的守门员:
Δt·|c| ≤ Δx——**信息不能在一个时间步里跑得比网格远**。一句话
把波动传播的物理、离散的几何与计算的代价绑在一起;它是"物理
直觉变成代数不等式"的最小完整样本(00 章三层假设里"可离散化
假设"的价格标签)。

✨ **美之时刻 ②:Lax 等价定理(1956)**。对线性适定问题:
**相容+稳定 ⇔ 收敛**。三个性质,两个可独立检验,一个是我们
真正想要的——"能不能信屏幕上这个数"被压缩成两条可检条件。
工程数学版的"美即真":把无限维的信任问题,折叠成有限步的
检查表(与计算数学宇宙共享的锚;本家族侧的展开在 02 章断言
阶梯)。

✨ **美之时刻 ③:三次独立发明(1943/1956/1965)**。有限元在
格廷根的变分传统、波音的结构需求与中国的计算数学学派被各造
一次——数学要它证明收敛,工程要它算机翼,冯康要它搭差分与
变分之间的桥。**接口学科的终极证据:两岸同时修桥,桥必然
在河中央合拢。**

## 📌 收束

工程数学的体系结构=**一条四跳的翻译链(物理→方程→离散→
可算→可信)+一部增层史(方程层 19 世纪,离散层 20 世纪中叶,
可信层世纪末,数据层 2019 后)+三条假设(连续介质/可离散化/
可学习,各有代价)**。它研究的问题是:工程师的物理直觉怎么

**🧠 认知升维(这章给了你什么新眼睛)**:

- **翻译眼**:看到任何仿真数字先问四跳——方程谁写的?离散
  谁做的?求解谁解的?验证谁做的?四问缺一,数字就是占卜
- **两闸眼**:verification(解对了方程)与 validation(方程
  对了物理)是两道独立的闸——只过第一闸的仿真精确地错着
- **误差结构眼**:数值线的误差有阶可外推,数据线的误差有界
  难外推——选方法先选你要哪种"错法"
- **流程眼**:计算加速的价值在于改写流程,不在于节省时间——
  评估任何加速先问它改了哪一层
