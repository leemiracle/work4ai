## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 离散化 | 连续自由度换成有限自由度——买可解性,卖无限维 |
| CFL 条件 | Δt·\|c\| ≤ Δx:信息一步不能跑过一网格——显式格式守门员 |
| 刚度矩阵 | K·u=F:有限元把物理变成线代问题的招牌句 |
| 网格质量 | 精度的前置条件:退化单元使一切格式难看(03 章必填字段) |
| 收敛阶 | log2(e_h/e_{h/2}):数值结果的"单元测试"(04 章 C2) |
| Verification/Validation | 两道独立的闸:解对了方程/方程对了物理 |
| Manufactured solution | 无解析解时的验证武器:任取光滑 u*,反推右端 f |

## ✨ 这支最美的一个事实

1928 年 Courant-Friedrichs-Lewy 为证明双曲方程解的存在性发明
差分格式,**稳定性条件(CFL)只是证明的副产品**;三十多年后
电子计算机把差分变成日常工具,这个副产品成了每一台机器上每一
个显式格式的守门员——**为纯粹数学理由发明的东西,成了工程世界
最繁忙的闸门**(家族 00 章美之时刻①,通说)。
