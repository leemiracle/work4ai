# 讲透不确定度量化 · 工程计算的可信度层(自定主干支)

> **支定位**:家族的**可信度出口**——工程计算给出的不该是一个
> 数,而是一个带不确定度的陈述;UQ 管三件事:输入不确定性怎么
> 传到输出(前向)、参数怎么校准(逆向)、结果怎么可信地交付
> (V&V&UQ 链)。GB/T 13745:41010 无三级明细,本支为自定主干支。

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| UQ | 不确定度量化:输入的疑→输出的疑,全链路记账 |
| 前向传播 | 给定输入分布,推输出统计——蒙特卡洛万能而慢(1/√N) |
| 多项式混沌 | 正交多项式基的确定性谱展开——光滑快、维度受限 |
| Sobol 指数 | 方差分解归因:哪个输入参数贡献了输出的不确定 |
| 贝叶斯校准 | 用观测更新参数后验——与反问题支同一台机器 |
| 认知/偶然不确定 | epistemic(可减:加数据)/aleatory(固有)——分类决定对策 |
| V&V&UQ | 验证-确认-不确定度:可信度交付的三级链条 |

## ✨ 这支最美的一个事实

蒙特卡洛的收敛速度 **1/√N 与维度无关**:不管模型有多少个输入
参数,误差都只按样本数的平方根下降——高维积分的维数灾难在这里
失效(代价是慢:精度每加一位数,样本 ×100)。**用最笨的均匀
采样买到维度免疫**,是"简单打败聪明"的招牌案例(与仿真科学
技术家族的蒙特卡洛锚同源,通说)。
