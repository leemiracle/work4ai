## ✨ 这支最美的一个事实

用神经网络解 PDE 的想法 1990 年代就有(Lagaris 等,1998,通说),
二十年无人引爆;2019 年 Raissi-Perdikaris-Karniadakis 把**自动
微分**接到旧想法上——网络对自身的 PDE 残差精确可微,物理定律
于是可以写成损失函数里的一项(家族 00 章故事框三)。**范式引爆
常常不是新想法,而是旧想法等到了它的机器**。
