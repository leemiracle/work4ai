# 工程数学思维技能卡(GB/T 41010 · 讲透工程数学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「这个物理问题**怎么变成能算的方程**」——翻译链作业需求
- 「**网格怎么划/时间步长怎么定**」——离散化与 CFL 稳定性
- 「**PINN 是什么、为什么热**、什么时候用」——数据线进正
  问题领地(近五年主战场)
- 「**有限元和神经网络**什么分工」——三分天下选型题
- 「从**观测数据反推参数**/材料属性」——反问题(工程数学
  的另一半)
- 「仿真结果**能信到什么程度**」——V&V 两闸与 UQ
- 「**收敛阶/验证**怎么做」——E3 证据的制造机(逐次加密斜率)
- 「**加速 X 倍**的仿真该不该信」——口径分诊(精确解同一
  方程 vs 代理模型替流程)
- 学 PDE 觉得太抽象、学数值分析觉得离工程远时——接口层
  的语法在此

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **翻译眼** | 看到任何仿真数字问四跳:方程谁写的?离散谁做的?求解谁解的?验证谁做的?缺一即占卜 |
| **两闸眼** | verification(解对了方程)与 validation(方程对了物理)是两道独立的闸——只过第一闸的仿真精确地错着 |
| **误差结构眼** | 数值线的误差有阶可外推,数据线的误差有界难外推——选方法先选你要哪种"错法" |
| **稳定性前置眼** | 先查 CFL/条件数/损失景观,再谈精度——不稳定的格式给出的位数是装饰品 |
| **口径眼** | "加速一亿倍"必问口径:精确解同一方程,还是代理模型替流程;两者价值不同 |
| **流程眼** | 计算加速的价值在改写决策结构,不在省时间;只省时间不改结构的加速被旧流程消化 |
| **声明眼** | PDE 问题=合同(方程+域+初边值+参数+来源);缺条款的合同不签 |
| **采样≠网格眼** | 配点密度是采样参数,买不来收敛;表达力(基/网络规模)才买得来 |

## 3. 工具箱(何时用什么)

- **四跳链条**(00 章):物理→方程→离散→可算→可信——任何
  工程计算的自查骨架
- **三分天下选型**(00/01 章):解析给洞察、数值给精度与
  认证、数据给反问题/高维/快速求值;互相进入对方的领地是
  这五年的事
- **E1-E5 断言阶梯**(02 章):E1 定理→E2 先验估计→E3 后验/
  验证→E4 基准→E5 校准;"理论上 O(h²)"与"本例误差 1e-3"
  差一级,收断言先看级
- **收敛阶复现**(04 章 C2):逐次加密+log2 斜率——数值代码
  的单元测试;manufactured solution 是无解析解时的标准武器
- **损失结构模板**(04 章 C3):PDE 残差+边界+数据三项加权;
  权重=方法参数必须声明;边界硬编码(x(1-x) 因子)与惩罚项
  两条路线
- **泊松三解法对比**(家族实验 `experiments/pinn_vs_fdm.py`):
  FDM 二阶收敛/PINN 教学版/解析解;断言"PINN 误差不随采样
  密度下降"——无网格方法论差异的最小展示
- **schema 三件套**(03 章):PDE 问题记录/网格结构(带质量
  字段)/神经求解器(带损失声明)——入库纪律三问:定住了吗/
  骨架干净吗/能对表吗

## 4. 常见误区与禁忌

- ❌ **格式精度冒充结论可信**:"二阶格式所以结果对"——
  E2 冒充 E3,常数十未知
- ❌ **verification 冒充 validation**:与解析解/manufactured
  solution 对上了就宣布"物理正确"——只证明解对了方程
- ❌ **口径混写**:代理模型替代流程的"亿倍加速"写成"求解
  加速亿倍"——两种声明价值不同(01 章方向五)
- ❌ **采样密度当网格加密**:PINN 误差不降就加配点——
  误差由表达力决定,先加宽度/改架构
- ❌ **无口径交接**:交接结论不带四件套(方程/离散/验证/
  不确定度)——等于把责任一起交出去
- ❌ **跳过稳定性谈精度**:显式格式不查 CFL、病态系统不查
  条件数,先谈多少位有效数字
- ❌ **建模外包**:让代码选本构/定维度——模型对不对物理,
  代码无权裁定
