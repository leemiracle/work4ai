# 02 · 语言特征——三种数学语言的互译语法

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程数学说的是**三种数学语言的互译语法**——
> 连续语言(方程与函数)、离散语言(网格与代数)、数据语言
> (样本与网络);判断一段工程数学写作的优劣,不看文采,看
> **翻译是否声明了口径**(哪个方程、哪种离散、哪批数据、错多少)。
> 三栏分别回答:这三种语言能说什么(表达力)、它们的断言受什么
> 约束(逻辑性质)、术语如何被标准化(规范化)。

---

## 0. 开篇:同一个问题的三种文本

📖 **故事框:一根梁的三种写法**。连续语言:挠度 w 满足
EI·w⁗ = q(x),边界条件写在梁端——一份边值问题。离散语言:
把梁切成 N 个单元,节点位移组成向量,方程变成 K·u = F
(K 是刚度矩阵)——一份线性方程组。数据语言:给网络喂参数
(载荷/材料)与对应解样本,或直接把残差 EI·w⁗-q 写进损失——
一份训练任务。**三个文本说的是同一根梁,但每个文本丢失的
与买到的都不同**:连续文本丢可算性买普适性,离散文本丢
无限自由度买可解性,数据文本丢误差阶买速度与融合力。工程
数学的语言工作,就是在三个文本之间**带着声明翻译**。

## 1. 表达力:三种语言能说什么(三栏之一)

**能说的**:

| 能力 | 语言 | 例 |
|------|------|-----|
| 守恒律与本构 | 连续 | 质量/动量/能量守恒 + 材料关系 → PDE(物理→方程跳的全部语法) |
| 边界与初始条件 | 连续 | Dirichlet/Neumann/Robin 初边值把问题"定住" |
| 逼近与代数化 | 离散 | 插值(单元形函数/差分 stencil)把场变成自由度向量 |
| 误差阶 | 离散 | "二阶格式,网格减半误差约降四倍"——**离散语言独有的自白条** |
| 解算映射 | 数据 | G: 参数↦解,一次学习族内毫秒求值(01 章方向三) |
| 物理残差 | 数据 | 方程本身进损失(-u″-f=0 在配点上受罚)——物理定律的新用法 |
| 数据融合 | 数据 | 观测点直接进损失,正反问题同一语法(反问题支的地盘) |

**不能说的**(表达力边界,与生俱来):

- **连续语言不能算**:方程本身不产出数字;任何数都来自后两种
  语言——"解析解存在"与"解析解可用"是两件事
- **离散语言不能分辨网格下的物理**:一个单元内发生的一切不在
  模型里(00 章连续介质假设的代价面);湍流模型的全部业务
  就是给这句话打补丁
- **数据语言不能自证收敛**:误差不随采样密度系统下降(家族
  实验断言③),域外泛化无保证——它有"能学到"与"学到了"
  的区分,但没有"加密必准"的承诺
- **三种语言都不能裁定物理本体对错**:方程对不对物理
  (validation)要用实验说话,翻译链的任何一环都不自足
  (00 章两闸眼)

## 2. 逻辑性质:数值断言的约束(三栏之二)

工程数学断言的可信度有五个来源,各带结构性偏置:

| 来源 | 典型措辞 | 偏置 |
|------|---------|------|
| 定理(收敛性/稳定性) | "格式相容且稳定,故收敛" | 多限线性/光滑/规则网格;工程构型常在定理外 |
| 先验误差估计 | "误差 ≤ C·h^p" | C 常数未知,给量级不给数 |
| 后验误差估计子 | "本例误差约 1e-3,建议加密此处" | 依赖估计子质量;自适应的发动机 |
| 基准对比(benchmark) | "与参考解偏差 x%" | 参考解自身证据级决定上限 |
| 实验/现场数据 | "与实测吻合" | 测量不确定度+工况偏置(计量学,波 5 待建) |

### 2.5 断言强度阶梯(工程数学版 E1-E5)

| 阶梯 | 措辞 | 证据状态 | 工程数学特有注意 |
|------|------|---------|----------------|
| E1 定理级 | "由定理,…" | 收敛/稳定性/适定性证明 | **适用条件先抄全**:线性?光滑?网格形状正则?工程常在定理边界外 |
| E2 先验估计级 | "误差 O(h²)" | 理论量级 | 常数未知;只可比较不可验收 |
| E3 后验/验证级 | "计算验证显示…" | 收敛阶数值复现/manufactured solution | verification≠validation:只证明"解对了方程" |
| E4 基准级 | "与 XX 基准一致" | 对标参考解 | 参考解的证据级要追问一层 |
| E5 校准级 | "与实测吻合,可用于预测" | 实验/现场对照 | **最强断言也带不确定度**;训练集内吻合不担保外推 |

**误用告示**:把 E2(理论上 O(h²))当 E3(本例误差多少)——
"格式是二阶的所以结果可信"是工程报告头号病;把训练集上的
吻合当 E5——数据线的"无声错误"(00 章假设三)多从这道门
溜进来。

### 2.6 三个内部语法规则

- **口径声明规则**:任何计算结论必附四件套——方程(哪个模型)、
  离散(什么格式/网格/网络)、验证(与谁对过)、不确定度
  (能信到哪)——缺件即不合规
- **稳定性前置规则**:先查稳定性条件(CFL/条件数/损失景观),
  再谈精度——不稳定的格式给出的位数是装饰品
- **两闸分立规则**:verification 与 validation 的证据不得互相
  冒充(00 章反直觉②的语法面)

## 3. 规范化:术语与对译(三栏之三)

- 国际语境下工程计算术语高度标准化(ASME/AIAA 的 V&V 规范、
  有限元的形函数/刚度矩阵词汇);中英写作必须声明口径——
  特别是"仿真精度"这类横跨两闸的词
- 度量:误差用范数(L2/最大/能量)与相对/绝对必须写明;
  "加速 X 倍"必附口径(同一方程精确求解,还是代理模型替代
  ——01 章方向五的两种声明不可混)

**术语对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 偏微分方程 | PDE (partial differential equation) | 方程的"解"在三种语言里是三个对象(函数/向量/网络) |
| 有限差分法 | FDM (finite difference method) | 强形式上动手;与 FEM(弱形式)路线不同,精度口径不可直接比 |
| 有限元法 | FEM (finite element method) | "元"=单元(element)非"元素";刚度矩阵 K·u=F 是其招牌句 |
| 有限体积法 | FVM (finite volume method) | 守恒律友好(CFD 主力);"体积"指控制体 |
| CFL 条件 | Courant-Friedrichs-Lewy condition | 时间步长上限;Δt·\|c\|/Δx ≤ 1(显式格式的守门员,00 章) |
| 收敛阶 | order of convergence (p) | "p=2"是 E2 级断言,须数值复现升到 E3 |
| 相容性/稳定性 | consistency / stability | Lax 等价定理的两根支柱;中文教材偶将"相容"写作"协调"——指格式逼近方程,非网格协调 |
| 验证/确认 | verification / validation | 验证=解对了方程;确认=方程对了物理——两闸不可互冒(00 章) |
| 网格无关性检验 | grid/mesh independence study | 实为收敛性自检;报告术语常被误当验证结论 |
| 物理信息神经网络 | PINN (physics-informed neural network) | "physics-informed"旧译"物理知情"已弃;informed=以物理为约束,非"了解物理" |
| 配点 | collocation point | 无网格方法的"采样点";改变配点密度≠加密网格(家族实验断言③) |
| 自动微分 | automatic differentiation (AD) | ≠数值差分≠符号求导;PINN 残差可微的地基(01 章故事) |
| 谱偏差 | spectral bias | 网络先学低频后学高频——训练失败模式的实证面(01 章方向二) |
| 神经算子 | neural operator | 学"解算映射"的网络族;单点求解器(如 PINN)≠算子学习 |
| 傅里叶神经算子 | FNO (Fourier neural operator) | 频域卷积结构;与"傅里叶变换解 PDE"无关,是网络架构名 |
| 深度算子网络 | DeepONet | 分支-主干(branch-trunk)结构;与 FNO 是神经算子两大家 |
| 代理模型 | surrogate model | "亿倍加速"多属此类口径(替代高保真仿真),≠精确求解同一方程(01 章方向五) |
| 正问题/反问题 | forward / inverse problem | 正:模型→数据;反:数据→模型;反转天然病态(反问题支) |
| 正则化 | regularization | 反问题的赎金(Tikhonov);与机器学习"正则化"同词同源,语境分 |
| 不确定度量化 | UQ (uncertainty quantification) | 计算的不确定度;与计量的测量不确定度同源不同物(UQ 支/计量学) |
| 自适应加权 | (loss/adaptive) weighting | 多任务损失权重调节;01 章方向四训练方法论 |
| 课程学习 | curriculum learning | 从易到难安排训练;借自教育心理学的通说术语 |

## 📌 收束

工程数学的语言=**三种语言的互译(连续/离散/数据,各有表达力
边界)+断言阶梯(E1-E5,稳定性前置与两闸分立)+口径声明的
规范化**。它写下的每个数都在等一次对表。下一章把翻译链上的
对象压成数据结构:[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **口径眼**:读任何"仿真表明",先问四件套(方程/离散/验证/
  不确定度)——缺件的结论是占卜
- **阶梯眼**:"理论上 O(h²)"与"本例误差 1e-3"差两级——
  收谁的断言先看它在哪级
- **声明白眼**:"加速一亿倍"必问口径——精确解同一方程,还是
  代理模型替流程;两种声明价值不同,不可混写
