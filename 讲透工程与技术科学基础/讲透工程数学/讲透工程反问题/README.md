## 支定位与地盘

- 地盘:参数识别(材料属性/源项/边界反推);不适定性与正则化
  的工程执行(Tikhonov/早停/贝叶斯先验);伴随方法与灵敏度;
  PINN 反问题;工程母题(无损检测/历史拟合/成像)
- 在家族中的位置:四跳链条的**逆向运行**——观测数据不动,参数
  动;与物理信息机器学习支共享"数据融合"语法,与 UQ 支共享
  "后验即不确定度"世界观
- 理论坐标:Hadamard 适定性三条件(存在/唯一/连续依赖)是起点
  ——反问题天然病态,正则化把"不可救"变成"可赎"

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 正/反问题 | 正:模型→数据;反:数据→模型——箭头反转天然病态 |
| 适定性 | Hadamard 三条件;反问题常缺第三条(连续依赖) |
| 正则化 | 用先验换稳定:Tikhonov 的 λ 是"平滑代价"的旋钮 |
| 正则化参数选择 | 偏差原理/L 曲线/GCV——λ 怎么定,三法则未竟 |
| 伴随方法 | 一个伴随方程换来全部参数的梯度——大规模反演引擎 |
| 贝叶斯反演 | 正则化=先验,后验=正则化解的统计版;解=分布非点 |
| PINN 反问题 | 数据项加进损失,正反问题同一语法——数据线的反演红利 |

## ✨ 这支最美的一个事实

1905 年 Hadamard 给适定性立法,并亲自找到一个不适定例子、断言
此类问题**没有物理意义**;历史开了个玩笑——CT 扫描(反散射)、
地震勘探(反演)、图像去模糊,全是他判过死刑的问题。1960 年代
苏联学派(Tikhonov 等)发明正则化,被判死刑的问题成了医学与
工业的心脏(转述自
[数学宇宙反问题支](../../../讲透数学/讲透计算数学/讲透反问题/README.md)
诞生史,通说)。
