# 02 · 语言特征——人因语言:负荷、情境意识与 SDT 的词汇

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程心理学说的是**一种双层语言**——
> 口语层是用户的抱怨(「找不到」「太吵」「没注意」),
> 指标层是人因的量(搜索时间/d′/情境意识缺失),两层
> 之间靠**对译表**缝合;判断一段人因写作的优劣,不看
> 文采,看**每个数字背后站着哪种证据**(控制实验/
> 模拟器/现场/运营数据)与**哪个人群哪份任务**。三栏
> 分别回答:这套语言能说什么(表达力)、人因断言凭
> 什么可信(逻辑性质)、术语如何被对译与规范化
> (规范化)。

---

## 0. 开篇:同一个控制室的三种抱怨

📖 **故事框:「不好用」的解剖**。操作员说「这系统
不好用」——这句话在口语层是结论,在指标层是**一串
待分诊的症状**:「按钮找不到」是**搜索时间与错误率**
(显示-控制兼容问题);「报警响个不停,不知道先看
哪个」是**虚警率与告警分级**(SDT 判据+注意力引导);
「手忙脚乱」是**工作负荷**(NASA-TLX 六维);「那个
页面我根本不知道出了什么事」是**情境意识缺失**
(SA 三层的哪一层断的);「它说的我都不信了」是
**信任失准**(校准差,狼来了之后)。人因工程师的第
一手艺就是这台「翻译机」:把抱怨翻译成指标,把
指标接到设计参数,再把设计改完的回信翻译回用户的
语言。**「不好用」不是信息,是对译表的目录页。**

## 1. 表达力:人因语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 人的极限 | **边界语言** | 视敏度(分角)/工作记忆 7±2 组块/反应时 ms/菲茨定律系数 |
| 任务的占用 | **负荷语言** | NASA-TLX 六维(心智/时间/努力/挫折/绩效/体力);主任务+次任务双测 |
| 理解的深度 | **情境意识语言** | SA 三层:感知(看到没)→理解(懂了吗)→投影(接下来会怎样) |
| 判断的质量 | **SDT 语言** | 命中/虚警/漏检/正确拒斥;d′(敏感度)/c(判据);ROC 曲线 |
| 关系的健康度 | **信任语言** | 信任量表/依赖率/校准差(T 对 R 的跟踪误差);误用与弃用 |
| 差错的解剖 | **差错语言** | slip/lapse/mistake/violation+潜伏条件(00 章分类学) |
| 群体的差异 | **百分位语言** | P5-P95 人体尺寸/新手-专家分档(平均人假设的补丁) |

**不能说的**(表达力边界,与生俱来):

- **个体下一秒的状态**:一切指标是统计量;「张三此刻
  的 d′」只有测量之后才知道(00 章假设三)
- **体验的总量**:「舒服」「顺手」是多维交互的涌现,
  分解语言只能逼近,不能穷尽(00 章假设二)
- **该不该信**:语言能说「信任与可靠性错配 0.2」,
  不能说「你应当信」——校准是工程量,立场不进词汇
- **没测过的任务**:一切人因参数绑任务与人群;换任务
  换人群,数字不随行(规则一)

## 2. 逻辑性质:人因结论的证据规则(三栏之二)

人的高噪声让证据纪律加倍重要——人因断言的可信度
来自**证据的层级与复现**,不是被试人数的堆叠:

### 2.5 断言强度阶梯(人因版 E1-E5)

| 阶梯 | 措辞 | 证据状态 | 人因特有注意 |
|------|------|---------|-------------|
| E1 通说经验级 | 「老师傅都说这样布局顺手」 | 口碑间接 | 有启发价值,无归因效力;不能进验收条款 |
| E2 实验室级 | 「控制实验(n=24)显示搜索时间降 18%」 | 机制直接 | 内部效度高;生态效度未证——结论限定在实验任务内 |
| E3 模拟器级 | 「高保真仿真中诊断错误率减半」 | 情境逼近 | 保真度依赖声明;样本通常小;场景覆盖有限 |
| E4 现场级 | 「三个运行班组实测负荷达标」 | 真实环境 | 观察期有限;难归因(变量没锁) |
| E5 运营复现级 | 「两年运营数据+事故档案复现该模式」 | 跨站复现 | 最强;但事故样本稀有,统计功效是天花板 |

**误用告示**:把 E2(实验室)写成 E5(现场已证)是
供应商文案的头号措辞越权;拿 E1(经验)当 E4(现场)
反驳实验结论是常见的修辞偷换;**结论的层级不能高于
证据的层级**——与[工程物理学](../讲透工程物理学/02-语言特征.md)
的证据级阶梯同宗,但人因多一重困难:测量对象会
学习、会疲劳、会猜你的假设(需求特征)。

### 2.6 三个内部语法规则

- **任务人群规则**:一切人因指标必附「什么任务×什么
  人群×什么状态」——「反应时 300 ms」不注任务是简单
  反应还是选择反应、被试是新手还是专家、白天还是
  凌晨,数字不可比(00 章假设一的语法面)
- **负荷双证规则**:工作负荷结论须主客观双写(主观
  量表+绩效代价,最好加生理指标)——单写主观,
  分不清真负荷与社会赞许;单写绩效,看不见代偿
  (人撑住成绩的隐性加价)
- **代偿声明规则**:绩效没掉≠没超负荷——人会让着
  系统:放慢速度、牺牲次要任务、透支后备资源;
  断言「能应付」必须声明**用什么代价换的**,否则
  是半张合同

## 3. 规范化:对译与术语(三栏之三)

- 国际语境下人因术语高度标准化(ISO 9241 系列工效
  标准/HFES 术语/IEA 体系);中英写作必须声明口径
  ——特别是「工效学/人因学/工程心理学」的并称与
  分工(中文语境三家互补,见 00 章 1.2)
- 度量:反应时 ms、负荷无量纲(TLX 加权 0-100)、
  d′ 与 c 以标准差为单位、信任量表分、依赖率 %
  (每个数字带任务人群标签,规则一)

**口语→指标对译表**(本家族招牌,中文优先):

| 口语抱怨 | 人因指标 | 走廊/支 |
|---------|---------|--------|
| 「按钮找不到」 | 搜索时间/错误率/菲茨定律难度指数 | 人因工程支 |
| 「老是点错」 | 差错率+slip 分类;目标宽度 W 太小 | 人因工程支 |
| 「太吵了/分不清」 | 信噪比↓→d′ 下降;虚警率 | 家族实验律 1 |
| 「报太多了,没人当真」 | 虚警率→感知可靠性→信任崩(狼来了) | 家族实验律 2 |
| 「手忙脚乱」 | NASA-TLX 升高;次任务绩效掉 | 人因工程支 |
| 「没注意到」 | SA 第一层缺失(感知) | 人-自动化支 |
| 「不明白怎么了」 | SA 第二层缺失(理解) | 人-自动化支 |
| 「没想到会这样」 | SA 第三层缺失(投影) | 人-自动化支 |
| 「系统在干嘛?」 | 模式混淆/透明性缺失 | 人-自动化支 |
| 「它行的,我不用看」 | 过度信任→误用(U 形右翼) | 家族实验律 3 |
| 「它不行,我全自己来」 | 信任不足→弃用(U 形左翼) | 家族实验律 3 |
| 「AI 队友靠得住吗」 | 校准差+团队信任(涌现状态) | 人-AI组队支 |

**中英术语对照**(翻译陷阱版):

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 工程心理学 | engineering psychology | ≠psychology(本体);=人-机界面学科;与 ergonomics 互补并称 |
| 人类工效学 | ergonomics/human factors | 欧系偏作业/物理侧,美系 human factors 偏认知侧;中文并用 |
| 工作负荷 | (mental) workload | ≠difficulty(难度是任务属性,负荷是人的占用) |
| 情境意识 | situation awareness (SA) | ≠alertness(警觉);SA 分感知-理解-投影三层 |
| 自动化自满 | automation complacency | ≠lazy;是监督注意的系统性衰减(通说) |
| 模式混淆 | mode confusion | 人对系统当前模式的认知与实际不符(人-自动化支) |
| 监督控制 | supervisory control | 人定目标与监督、机器执行的控制结构 |
| 敏感度 | sensitivity (d′) | ≠准确率(accuracy);准确率混淆了 d′ 与判据 |
| 判据 | criterion/bias (c) | 阈值;与敏感度是两个自由度(家族实验律 1) |
| 虚警 | false alarm | ≠false positive(统计检验语境);检测语境同义混用要声明 |
| 信任校准 | trust calibration | 信任匹配**真实**能力;≠高信任(方向不是越多越好) |
| 误用/弃用 | misuse/disuse | 过度信任/信任不足的行为后果(Lee & See 对偶) |
| 涌现状态 | emergent states | 团队层属性(凝聚/安全感);个体测量里不存在 |
| 差错 | error (slip/lapse/mistake/violation) | 四分类不可混;「人为差错」是症状不是原因 |

## 📌 收束

工程心理学的语言=**双层语件(口语抱怨+人因指标,
对译表缝合)+证据的证书学(E1-E5 阶梯,任务人群/
负荷双证/代偿声明三规则)+术语的规范化**。它写下
的每个数字都在等一行任务标签与一份证据级。下一章
把人因问题压成数据结构:[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **对译眼**:听到「不好用」先翻对译表——搜索时间/
  d′/负荷/SA/信任,五个抽屉总有一个装得下
- **标签眼**:一切人因数字带任务×人群×状态标签;
  naked 指标不可比,不可复算
- **代偿眼**:成绩是加价买来的——「能应付」的旁边
  一定站着「拿什么换的」
