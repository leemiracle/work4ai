# 讲透工程心理学 · 界面层——系统里那个会累会错的人(GB/T 41045)

> **工程心理学=人-机-环境系统中「人」这一环的工程科学**:
> 系统里最灵活也最不可靠的元件是人——机器有手册与
> 公差,人有边界与漂移。这门学科把**「人会怎么看、
> 怎么想、怎么错」写成设计参数**:视敏度与工作记忆
> 容量、菲茨定律的系数、信号检测论的判据、信任的
> 更新速率——不是让人适应机器,而是**让机器学会人
> 的边界**。
>
> GB/T 13745:41045(二级学科,工程与技术科学基础 410 之下;
> **GB/T 该二级无三级明细→本家族自定主干支**)。
> 互链声明(宇宙 README §二):**心理学机制本体在心理学
> 宇宙(GB/T 190,待建)**——感知/认知/记忆/动机的理论
> 本体归它;**本家族=工程侧落点**——不重述心理学理论,
> 问的是人的特性怎么进显示、进控制、进自动化等级、
> 进信任设计。宇宙:[讲透工程与技术科学基础](../README.md)。
