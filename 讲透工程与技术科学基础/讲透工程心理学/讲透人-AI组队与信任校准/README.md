## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 信任校准 | 信任的程度匹配真实的能力:不是多信,是信对(方向不是越多越好) |
| 误用/弃用 | 过度信任→漏检系统错误;信任不足→弃用系统(misuse/disuse 对偶) |
| 感知可靠性 | 信任由 R̂ 生成不由 R 生成:虚警扣款、漏检常不可见——账本不对称 |
| 狼来了效应 | 高虚警系统稳态信任显著更低,即使漏检率相同(家族实验断言②) |
| U 形依赖成本 | 成本关于依赖倾向 D 呈 U 形,最优 D* 随真实可靠性 R 右移(断言③) |
| 团队涌现状态 | 凝聚/安全感/共享心智:不属于任何个体,个体测量里不存在 |
| 工具-助手-队友 | 三代际:队友有可依赖性与可解释性义务,工具没有(01 章方向四) |

## ✨ 这支最美的一个事实

**把「信不信」变成设计参数(2004)**。Lee & See 之前,
「信任机器」是伦理味与文学味的词;正典化之后,信任
是**可测量的态度、可仿真的动力学、可设计的对象**:
家族实验把这条正典压成三行数——高虚警系统稳态信任
0.70 vs 低虚警 0.93(漏检率相同,狼来了);最优依赖
D* 随 R 从 0.80→0.90 右移 0.20→0.80(校准的靶子在
动);U 形两翼都是钱(误用与弃用同样昂贵)。**信任
校准=把 D 调到 R 对应的最优点**——一句可以被代码
检验的设计哲学。
