> **支定位**:家族的**关系主干**——三哩岛(1979,按学科
> 史通说)与 Bainbridge(1983)开创的那条线:自动化改变
> 了「人在回路里的位置」,人从操作员变成监督员,于是
> 警觉、模式意识、交接质量成为新的设计对象。人-机闭环
> 的回路语法本体在[工程控制论](../../讲透工程控制论/README.md),
> **互链:那边写回路的一般理论,本支写「人这一环」
> 在自动化回路里的特殊行为**——监督恰是人最不擅长
> 的差事。GB/T 13745:41045 无三级明细,本支为自定
> 主干支;案例按学科史通说呈现,不指认现实个人/组织
> 责任(家族写作红线)。

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 监督控制 | 人定目标、看状态、处理异常:自动化把人从回路里挪到回路上方 |
| 自动化的反讽 | 自动化接管常规、留下异常,而异常处理恰需被剥夺的练习(Bainbridge 1983) |
| 自动化自满 | 监督注意的系统性衰减:不是懒,是人的默认设定(通说) |
| 模式混淆 | 人以为系统在 A 模式,其实在 B 模式:歧义是设计预置的 |
| 情境意识三层 | 感知→理解→投影:SA 断在哪一层,对策完全不同 |
| 告警即 SDT | 每个告警面板都是判据工程:漏检/虚警坐在同一条 ROC 上 |

## ✨ 这支最美的一个事实

**更多自动化不等于更安全(1983,通说)**。Bainbridge
的「自动化的反讽」:设计者把人做不好的交给机器,把
机器做不好的留给人——结果是人退成监督员,警觉衰减、
技能退化、回路外麻木同时发生;真出事时,接管需要的
恰是长期没练习的手动技能与情境意识。**把人从回路里
拿掉很容易,把他装回异常场景很难**——所以 2000 年的
共识不是「多自动化还是少自动化」,而是**分功能配权**:
每个功能该自动化到第几级,是逐条裁定,不是全有全无
(00 章反直觉①;家族实验断言②的告警账本是它的运营版)。
