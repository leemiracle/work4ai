## ✨ 这支最美的一个事实

**一条 log₂ 统一一切指点(1954)**。菲茨定律把运动
难度写成 log₂(2D/W) 比特数:从操纵杆、钢琴键盘到
ATM 按键、手机图标、眼动点击,六十年界面共享同一条
定律——**一次测量,通吃所有指点**;距离减半与宽度
加倍等价(难度指数都降 1 比特),所以「好点」不止
「做大」一条路,还有「挪近」。家族 04 章走廊 C3 用它
把界面之争变成算术。
