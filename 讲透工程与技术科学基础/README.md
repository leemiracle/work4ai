## 三、特征速查(问题→家族)

- 工程中的数学建模与计算 → 工程数学(数值方法本体去数学宇宙)
- 工程系统的通用控制原理 → 工程控制论(先看消歧三链)
- 强度/刚度/振动/疲劳 → 工程力学
- 工程中的物理效应利用 → 工程物理学;地基/边坡/渗流 → 工程地质学
- 水文设计洪水/径流 → 工程水文学;仿生结构/功能 → 工程仿生学;人机交互工效 → 工程心理学
- 标准制定/标准体系 → 标准科学技术;量值传递/单位制/测量不确定度 → 计量学
- 投影/图样/制图规范 → 工程图学;勘探钻探取样 → 勘查技术
- 密封/真空/薄膜/爆破/包装/照相/物料搬运 → 工程通用技术;生产系统效率/设施布局 → 工业工程学

## 四、治理

- 波次:波5(14 家族,4+4+4+2 批);支宪法随家族落盘(GB/T 支 11:标准科学技术 3+工程通用技术 8;其余 12 家族自定 2-4 支标"自定主干支")
- 待办:力学/地球科学/生物学/心理学宇宙建立后回收归入条目;兜底类 41099 不设系列
- 薄学科纪律:工程图学/照相技术等材料薄者章精简至下限不注水
