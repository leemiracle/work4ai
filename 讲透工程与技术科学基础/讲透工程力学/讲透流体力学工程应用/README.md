## 支定位与地盘

- 地盘:空气动力学工程计算(升阻力/气动载荷)、水动力学
  工程侧(波浪/洋流载荷)、边界层与流动分离的工程后果、
  气动弹性(颤振/驰振/抖振)、风工程(桥梁与高层建筑的风

- 在家族中的位置:三问的"载荷生成器"——风载/波浪载怎么算
  出来,是固体侧强度校核的输入;边界:湍流本体与计算流体
  力学算法归待建宇宙 130 与数学宇宙,本支取工程判据与
  耦合问题(00 章故事框三的塔科马即本支正典案例)

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 升力/阻力 | 流动给结构的两个力分量;系数 C_L/C_D 是无量纲通货 |
| 边界层 | 壁面附近薄层:摩擦与分离都住这里(普朗特 1904,通说) |
| 雷诺数 | 惯性/粘性之比:同一结构换介质换尺度,流态可能整个换 |
| 气动弹性 | 气动力+弹性结构耦合:载荷不再是给定的(00 章耦合眼) |
| 颤振 | 气弹自激振荡(负气动阻尼回路)——塔科马的死因(通说) |
| 失速 | 大攻角分离:升力崩塌,载荷模型整个换挡 |
| 涡脱 | 尾流周期性旋涡脱落:驰振与涡激振动的能量来源 |

## ✨ 这支最美的一个事实

塔科马海峡大桥(1940)给工程力学的永久教具:教科书流传
几十年的"共振"解释是错的(00 章反直觉①,含正误之争,
通说常引 Billah & Scanlan 1991)——真实机制是**气动自激
失稳**:桥面运动改变风攻角,改变的风推力又助推运动,
等价于一个负阻尼回路,能量从定常风中被结构自己的运动泵入。
结构工程师与空气动力学家由此学会同一门语言:**当载荷随
响应变化,结构问题必须按回路问题重新提**——这是本家族
与工程控制论最深的交叉点(00 章练习三)。
