## 0. 开篇:一根桁架,代码自己说

「都说超静定要矩阵法,静定手算就行——矩阵法到底强在哪?
拆掉一根杆会怎样?」——`experiments/truss_fem_toy.py` 让
代码回答:平面桁架的节点-单元拓扑上,手写直接刚度法组装
总刚(每根杆 k=(EA/L)·bᵀb),划行划列施加约束,自写高斯
消元求解。三组结构:静定三角桁架的矩阵解与节点法手算逐杆
一致(斜杆压 P√13/6、底弦拉 P/3,误差 1e-9 级);超静定
方框(未知量 9>平衡方程 8)静力法欠定而矩阵法直解,且与
对称力法手算互证,斜杆 EA×10 后内力重分配约 109%——**内力
依赖刚度比,正是静力法算不了超静定的原因**;撤一根斜杆
回到静定(此对称载荷下剩余斜杆内力恰为 0),再撤一根后
m+r<2j,消元最小主元比精确塌到 0,**机构报警而非输出
垃圾解**。一条脚本把 00 章反直觉③与 02 章"解的证据"全部
落成可复现的数。

## 1. 可机械化边界(三件套之一)

**能进代码的**(结构数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 平面/空间桁架求解 | 直接刚度法组装+消元/分解求解(家族实验) |
| 梁/刚架求解 | 杆端自由度扩展(转角进来),同一套组装 |
| 特征值问题 | 屈曲(K φ=λK_G φ)与模态(K φ=ω²M φ)——线性代数接口 |
| 收敛研究 | 网格加密序列+关键量序列+收敛率估计(C2 走廊) |
| 本构拟合 | σ-ε 数据最小二乘/牛顿迭代(C3 走廊) |
| 后处理与校核 | 应力/内力提取+许用值比对+组合工况扫描 |

**不能进代码的**(工程力学的"不可判定域"):

1. **本构与单元族谱的选型**——该用弹塑性还是粘弹、粗短
   梁该不该用梁单元:02 章 E2 级静默失效住在这一步,代码
   只对已声明的 schema 算,不裁定 schema 对错
2. **网格划分的工程判断**——哪里加密、哪里可以粗:几何与
   应力梯度的先验阅读,自动化只是辅助
3. **安全与验收的裁定**——E4/E5 级证据要试验与规范认证;
   数值级(E3)冒充验收是 02 章阶梯的头号误用
4. **裂纹会不会在未见构型上走这条路**——ML 代理给的是
   插值还是预测,物理不归代码担保(01 章方向三)

> 边界的一句话:**代码是结构的验算台与试验场,不是设计师。**

## 2. C1 桁架矩阵法走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 拓扑 | 节点坐标+杆件连接表(03 章 schema) | 铰接假设:梁刚架要加转角自由度,别拿桁架单元算刚架 |

| 证据 | 轴力对截面法手算/力法手算双路互证 | 互证是 02 章 E3 级证据的自检义务 |

## 3. C2 收敛性走廊(解是网格的函数)

数值版的可信度=关键量随加密的稳定:

```python
# 收敛研究思想:同一结构,网格序列 h0 > h1 > h2 ...
# 关键量 q(如孔边应力/最大挠度)随自由度变化
def convergence_study(mesh_levels):
    qs = [solve_and_extract(h) for h in mesh_levels]
    # 相邻比率 r = (q2-q1)/(q1-q0) → 收敛阶 p ≈ log2(r)
    # |q2-q1| < tol 才允许报告"网格收敛";应力集中区单独报
    return qs
# 断言风格:相邻加密差 < 工程容差(如 2%)才入交付(02 章规则二)
```

要点:其一,**收敛是报告出来的,不是感觉出来的**——交付
物里没有网格研究,数值就没有证据级;其二,应力集中区收敛
慢(奇异性邻近,通说),全局量(位移)比局部量(孔边应力)
先稳——分开设容差;其三,理论收敛阶的数学本体在
[数学宇宙计算数学](../../讲透数学/讲透计算数学/),
本家族用其结论,不重述证明。

## 4. C3 本构拟合走廊(从数据到参数)

本构参数从试验数据来,最老牌的机器学习就是最小二乘:

```python
# 线弹性拟合:σ = E·ε,试验点 (εi, σi) 最小二乘
def fit_E(data):
    num = sum(e * s for e, s in data)
    den = sum(e * e for e, s in data)
    return num / den            # E 的解析最小二乘解
# 弹塑性(屈服+硬化)参数非线性 → 牛顿迭代/网格搜索;
# MINN(01 章方向二)是这条走廊的极限版:全场数据+力学约束
# 一起进损失——走廊精神四百年没变:让残差说话
```

要点:其一,**拟合域=适用域**——回归管插值不管外推,03 章
"训练域声明"在这里首发;其二,弹塑性参数与加载路径相关,
单向拉伸拟合的参数直接用于循环载荷是经典违规;其三,
参数的散布(批次/试样)要进记录——确定性假设的安放处
(00 章假设三)。

## 5. C4 特征值走廊(屈曲与模态)与 C5 数据驱动走廊(桥)

- **C4 特征值**:线性屈曲=广义特征值问题 K φ=λK_G φ
  (欧拉公式是一般式的手算特例),固有模态=K φ=ω²M φ——
  两问都化作矩阵特征值,求解器本体在
  [数学宇宙数值线代](../../讲透数学/讲透数值线代/);
  坑:线性屈曲只给分岔点(理想化),**给不了屈曲后的下场**
  (00 章稳定性行的未决面),后屈曲要几何非线性分析
- **C5 数据驱动**(通向 01 章方向二四):从全场数据
  (DIC 位移场)反演本构(MINN 思想)=C3 走廊的力学约束版:
  平衡方程残差进损失函数;降阶模型=把 C1-C4 的高保真解
  压缩成快查表(实时仿真的引擎);边界=训练域外无保证
  ("模型搬进数据");最近邻参照系:
  [工程数学家族的 PINN 对比实验](../讲透工程数学/experiments/pinn_vs_fdm.py)
  (那边管通用流程,本家族管本构与力学侧)

**走廊三警告**(共用):

1. 数值证据是 E3 级:网格、工况、边界没扫到的区域无证据
2. 静定/超静定的判定先行:静定内力与刚度无关,超静定
   内力随刚度重排(家族实验)——别拿静定直觉读超静定结果
3. 奇异性检测必须开着:机构/欠约束在 K 上留下签名,消元
   主元比是最便宜的哨兵

## 6. 工程师落点(把这门学科带回家)

- **传力路径眼读一切系统**:软件架构的"承重墙"(核心模块)
  与冗余路径、组织的关键人依赖,与桁架的临界杆/冗余杆
  同构——找出"拆了就塌"的那一根,与"拆了重排"的那一片
- **裕度思维→容量与冗余**:安全系数是结构工程的 headroom
  语言——满负荷运行=零安全系数运行;性能工程的过载能力
  与许用应力是同一个词的两种方言(与工程控制论裕度眼对表)
- **对性能工程的接口**:K·u=F 是最古老的大规模稀疏求解
  问题——刚度矩阵对称正定、带宽优化、并行组装,与性能
  工程的矩阵计算同源;CAE 求解器是稀疏数值线代最大的
  工程用户之一
- **K 奇异思维→系统体检**:刚度矩阵奇异=系统存在无代价
  的漂移自由度(机构)——组织/代码/数据里"没有约束的
  自由度"都长这样,消元主元比是它的探针
