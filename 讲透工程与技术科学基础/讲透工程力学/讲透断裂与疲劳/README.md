## 招牌概念

| Miner 法则 | 变幅损伤线性累积:工程能用,机理上粗糙(通说) |

## ✨ 这支最美的一个事实

Griffith 1920(通说):把 Inglis 的应力集中推到极限——
裂纹是极端椭圆,尖端应力理论上无穷大,**但玻璃的强度
问题不在于尖端应力多大,而在于释放的弹性能够不够支付
新表面的能量账单**。能量判据绕开了"不允许问的问题"
(尖端应力,02 章),断裂力学由此诞生;它还顺手解释了
实测强度比理论键合强度低两个数量级的百年困惑:**强度
不是材料常数,是"材料+缺陷几何"的结构性质**(00 章
反直觉②)——"名义应力合格"与"安全"之间隔着一道裂纹。
