# 03 · 可构造与结构——本构、网格与多尺度作为数据对象

> **本章回答五问之 Q4(可构造性与结构)。**
> **本质一句话**:工程力学里"可构造"的不是物理,而是
> **结构问题的三类数据对象**——本构模型是带标定来源的
> 参数化结构,网格与单元是节点-单元的离散 schema,多尺度
> 嵌套是跨尺度的传递契约;把这些结构显式化,结构分析就从
> 手艺变成工程:可校验、可对表、可交接(04 章走廊的地基)。

---

## 0. 开篇:一份"结构分析任务单"的三件结构化家具

拆开任何一次严肃的结构分析委托,都能拆出三件家具:其一是
**本构模型**(材料怎么说话——参数、形式、标定来源),其二是
**离散结构**(几何怎么算——节点、单元、网格质量),其三是
**尺度契约**(微结构与构件怎么连——分层还是并发,传什么)。
三件家具在手,00 章三问(强度/刚度/稳定性)就变成**可机检
的数据流水线**;伽利略的四百年(从比例语言到数据 schema),
在这一步完成最后一次搬家。

## 1. 什么是"可构造"的:三类结构对象

| 对象 | 数化身 | 可构造性 | 构造中的坑 |
|------|--------|---------|-----------|
| **本构模型结构** | 形式(弹性/弹塑性/粘弹/损伤)+参数+适用域+标定来源 | ✅ 高度可构造 | 外推即违约:参数在标定应变路径外无依据(01 章方向二) |
| **网格与单元 schema** | 节点坐标+单元连接+材料号+截面号+约束+载荷工况 | ✅ 高度可构造 | 解是网格的函数:不附网格收敛性=没交付(02 章规则二) |
| **多尺度嵌套** | 宏观点↔微观 RVE 的传递契约(输入应变/输出应力或切线) | ✅ 可构造 | 跨尺度误差累积无规范;代理模型训练域必须声明(01 章方向一) |
| **载荷工况与组合** | 工况表+组合规则(设计规范语言) | ✅ 高度可构造 | 组合系数是规范决策不是物理;确定性假设的安放处(00 章假设三) |
| **验证记录** | 网格研究+试验对照+工况清单 | ✅ 可构造 | 单工况单网格的记录无证据力(02 章阶梯) |

**不可构造的**:材料的真实响应(标定与学习都只给估计,
真值属于物理)、裂纹路径的先验预测(要算出来才知道,
支四)、"网格无关解"本身(只能给出收敛性证据,不能给出
"无关")、以及安全性的最终裁定(规范与制度的事,02 章 E5)。

### 1.5 最小数据模式(动手者的 schema)

```yaml
# 本构(形式+参数+标定来源成套出现,缺一即"半张合同")
constitutive:
  form: elasticity|plasticity|viscoelasticity|damage
  params: {E: float, nu: float}        # 例:线弹性双参数
  domain: str                          # 适用域(应变范围/温度/率相关?)
  source: test|handbook|minn           # 试验标定/手册/数据驱动(01 章三来源)

# 离散结构(节点-单元-约束-载荷四件套)
mesh:
  nodes: [[x, y, z], ...]
  elements: {conn: [[i, j], ...], type: truss|beam|shell|solid,
             sec: int, mat: int}       # 单元族谱见 §3
  quality: {min_jacobian: float, max_aspect: float}  # 网格质量必填
study:
  refinements: int                     # 网格加密级数(≥2 才谈收敛)
  key_quantities: [str]                # 关注量(位移/孔边应力/特征值)

# 多尺度契约(声明传递方向与代理域)
multiscale:
  mode: sequential|concurrent          # 分层(RVE 离线)或并发(在线)
  transfer: {macro2micro: strain, micro2macro: stress+tangent}
  surrogate: {kind: none|nn, train_domain: str}   # 训练域必填

# 验证记录(证据带工况坐标)
verification:
  mesh_study: str                      # 加密序列+关键量收敛
  experiment: {specimen: str, scale_note: str}    # 缩比/尺寸效应注记
```

注意 `constitutive.source` 与 `mesh.quality` 两处必填:把
02 章的证书纪律写进数据结构——**数据层自带校验点,是力学
计算区别于普通脚本的第一特征**(承
[工程数学家族](../讲透工程数学/03-可构造与结构.md)
schema 同款精神)。

## 2. 骨架一:本构模型结构(参数化的层级)

- **层级化选型**:线弹性(E,ν)→弹塑性(屈服面+硬化律:
  现在多参数进来)→粘弹性(Prony 级数:时间进来)→损伤
  (刚度退化场:局部化进来)——每上一层,参数翻倍、标定
  数据需求翻倍、适用域义务翻倍;**结构先行,参数后到**:
  选错层(该弹塑性处用线弹性)参数救不回来
- **标定三来源分级**(01 章方向二):试验标定(有条件与
  散布)/手册查表(材料批次的"平均人格")/数据驱动(MINN,
  全场数据学出,域外即未建模)——证据级随来源定级(02 章
  E2-E4)
- **热力学相容**:正经本构要过客观性(坐标系无关)与能量
  不等式两道闸(通说要求);学出来的网络本构(MINN)要
  检查证书,不是许愿

## 3. 骨架二:网格与单元 schema(离散的结构)

- **单元族谱降维链**:实体(3D 场)→壳(2D,厚度收口)→
  梁(1D,截面收口)→桁架杆(0D 内力,只有轴力)——降维
  买到自由度骤减,付出适用条件(细长比/圣维南的许可证,
  00 章美之时刻③);族谱选错=E2 级静默失效(02 章误用
  告示)
- **网格质量是数值健康**:长宽比/雅可比/扭曲度决定 K 的
  条件数——**质量差的网格不产生错误答案,产生病态的
  正确答案**(求解慢、精度烂),家族实验的消元主元比是其
  微型先兆
- **h 收敛与 p 收敛**:加密网格(h)或升阶多项式(p)都逼近
  真解;工程常规是 h 收敛+关键区局部加密;收敛性报告是
  交付物的一部分,不是附加题(02 章规则二)

## 4. 骨架三:多尺度嵌套(跨尺度的契约)

- **分层与并发**:分层(sequential)先均匀化出宏观本构再算
  结构——尺度分离清晰时用;并发(concurrent)宏观每算一步、
  微观 RVE 在线跟着算——局部化/路径相关时用;契约内容不同:
  前者交"等效本构",后者交"应力+切线刚度"(01 章方向一)
- **代理模型与训练域**:RVE 求解昂贵→离线训练代理(神经网络
  查表);**训练域声明是契约的免责条款**——没写训练域的
  代理模型,等于没写适用域的本构(02 章半张合同)
- **误差的跨尺度账本**:微观代理的小误差经宏观积分可能被
  放大,也可能被平均掉——跨尺度误差累积的定量控制是
  01 章未决问题,账本(逐层误差界)是未来规范的方向

## 5. 从结构到校验:这套骨架买到了什么

- 本构带来源 → 应力断言有根(参数的适用域可查)
- 网格带质量与收敛研究 → 数值证据成级(02 章 E3 站直)
- 尺度契约带训练域 → 多尺度结果可复现(01 章方向一)
- 验证记录带工况坐标 → 交付可对表(单工况记录退回)

## 6. 构造合法性清单(动手前三问)

把任何结构分析构想变成数据结构之前,先过三问——本家族的
"类型检查":

1. **本构定住了吗**:形式层级选对了吗(该塑性处别用弹性)?
   参数有来源吗?适用域写明了吗?——三缺一的应力断言是
   脆弱断言
2. **离散合格吗**:单元族谱配几何吗(粗短梁别用梁单元)?
   网格质量达标吗?加密研究做了吗?——解是网格的函数
3. **跨尺度/跨工况的边界写了吗**:代理模型训练域声明了
   吗?载荷组合按哪本规范?——边界静默=换题

三问全过,数据才获得进入 [04 章走廊](04-工程力学转代码.md)
的资格。**力学计算的第一特征不是算法,是入库纪律。**

## 📌 收束

可构造的是**三类数据对象**(本构结构/离散 schema/尺度
契约),不可构造的是**真实材料响应与裂纹路径的先验**;
结构化不是为了替代工程师,是为了让分析可校验、可交接、
可复盘。下一章把骨架接上代码:
[04-工程力学转代码](04-工程力学转代码.md)。

**🧠 认知升维**:

- **来源眼**:一切参数吊在标定来源上——E 从哪来、谁测的、
  哪批材料,不问来源的参数是匿名证人
- **网格眼**:数值解是网格的函数——看到任何有限元图,
  先问网格多细、关键区加密没有、收敛研究在哪
- **契约眼**:跨尺度/跨模型/实验与仿真之间都是契约——
  传什么、域多大、误差谁担,写清楚才叫接口
