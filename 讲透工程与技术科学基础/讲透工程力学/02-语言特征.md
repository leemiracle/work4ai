# 02 · 语言特征——力学语言三件套与三证据

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程力学说的是**一种三层语言**——本构方程
> (材料怎么说话)、平衡与几何方程(世界怎么说话)、边界条件
> 与失效准则(工程怎么收口);判断一段力学写作的优劣,不看
> 文采,看**断言背后站着哪种证据**(解析解/数值/实验三证据,
> 证据级必须抄全)。三栏分别回答:这套语言能说什么(表达力)、
> 力学断言凭什么可信(逻辑性质)、术语如何被标准化(规范化)。

---

## 0. 开篇:同一根梁的三种文本

📖 **故事框:一根悬臂梁的四种写法**。伽利略的写法(1638):
几何与重量的比例语言——三次方律,没有应力的概念,错了一
个量级,但问对了问题(00 章故事框一)。材料力学的写法:
内力-截面-应力——弯矩图一条折线,σ=My/I 一行公式,中性
层假设收口。弹性力学的写法:应力张量场σᵢⱼ 满足偏微分方程
组,梁是它的一个特解(圣维南原理发放近似许可证,00 章
美之时刻③)。有限元的写法:节点-单元-刚度矩阵,K·u=F
一次组装。**四种文本说的是同一根梁,但每种文本丢失的与
买到 的都不同**:比例语言丢内力买直觉,材料力学丢场的
一般性买三行公式,弹性力学丢可解性买严格性,有限元丢
解析性买任意几何。工程师的语言工作,就是在这四种文本
之间**带着证据翻译**。

## 1. 表达力:力学语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 面上的力与体内的场 | 应力/应变张量 | 柯西应力六分量;一点的受力状态一句话说完(00 章故事框二) |
| 材料的脾气 | **本构方程** | 线弹性(胡克)/弹塑性(屈服面+硬化)/粘弹性(时间进来)/损伤(刚度退化) |
| 工程的收口 | **边界条件** | 力边界/位移边界/混合;同一方程+不同边界=完全不同的结构 |
| 何时算坏 | **失效准则** | 强度(屈服/断裂准则)、稳定性(特征值)、疲劳(S-N/Paris 律) |
| 降维的理想化 | 梁/板/壳/桁架 | 把三维场折叠成一维内力——手算时代的全部产能 |
| 变形换力 | 能量语言 | 卡氏定理/虚功原理:求变形变求导(00 章美之时刻①) |
| 任意几何 | 离散语言 | 形函数+单元组装:K·u=F 的通用句子(03 章) |

**不能说的**(表达力边界,与生俱来):

- **连续介质之外**:微结构尺度与离散材料(颗粒/纺织)上,
  应力张量的"一点"没有定义(00 章假设一的代价面)
- **裂纹尖端的应力值**:线弹性解在尖端发散,语言内部自爆
  ——断裂力学绕道能量释放率与应力强度因子说话(支四),
  "尖端应力多大"是一个**不允许问的问题**
- **失效之后**:本构描述到失效为止;裂纹扩展路径、碎片
  运动(冲击/侵彻)需要另外的语言(显式动力学/离散元)
- **非线性同时全开**:几何非线性+材料非线性+接触同时,
  语言在、解法勉强(收敛性是数值问题不是语言问题,但工程
  可用性大打折扣)

## 2. 逻辑性质:力学断言的三证据(三栏之二)

力学断言的可信度来自**证据的类型**,不是计算的精美:

| 证据 | 是什么 | 特权与陷阱 |
|------|--------|-----------|
| 解析解 | 闭式公式(欧拉临界力/梁弯曲解/厚壁筒) | 特权:数值格式验证的标尺;陷阱:只活在理想化几何里 |
| 数值解 | 有限元/有限差分的离散解 | 特权:任意几何;陷阱:**解是网格的函数**——不报告网格收敛性等于没报告 |
| 实验 | 试样/缩比/全机/全桥试验 | 特权:最终裁判(彗星空难推翻静力安全观);陷阱:试样≠结构,缩比≠原型(尺寸效应,00 章尺寸眼) |

### 2.5 断言强度阶梯(力学版 E1-E5)

| 阶梯 | 措辞 | 证据状态 | 力学特有注意 |
|------|------|---------|-------------|
| E1 定理级 | "由能量原理/上限下限定理……" | 变分原理与极值定理 | 塑性极限分析的上/下限定理是工程少有的"包死"断言(通说) |
| E2 理想化级 | "按梁理论,应力为……" | 理论近似 | 近似误差有量级(细长梁 O(h/L)²)——粗短梁上梁理论静默失效,换实体单元 |
| E3 数值级 | "有限元计算显示……" | 离散证据 | 必附网格收敛性;应力集中区局部值未收敛不许直接用于校核 |
| E4 试验级 | "试样/缩比试验表明……" | 实物证据 | 单一批次≠材料全体;缩比外推要过尺寸眼(00 章反直觉②) |
| E5 规范级 | "满足规范许用值" | 规范证据 | 规范是工程共识的制度化(安全系数的现行形态),不替代物理理解 |

**误用告示**:把 E3(算出来了)当 E4(测到了)——网格加密
只逼近理想化模型,不逼近真实结构;把 E2 当 E1——梁理论在
开孔/粗短/复合材料段上的静默失效是工程事故的经典源头。

### 2.6 三个内部语法规则

- **本构声明规则**:任何应力结论必附所依本构与参数来源
  (试验标定/手册/数据驱动——01 章方向二的三来源);
  "弹性模量取 E"不说来源,断言是半张合同
- **网格收敛规则**:数值解交付必附网格研究(加密序列+
  关键量收敛曲线);应力集中区单独说明
- **边界条件声明规则**:约束怎么简化的(哪个实际连接被
  理想成了铰/固支)必须写明——边界条件是弹性力学的
  "另一半方程",静默简化=静默换题

## 3. 规范化:术语与对译(三栏之三)

- 国际语境下力学术语高度标准化(力学学会词汇表与 CAE 软件
  术语传统);中英写作必须声明口径——特别是"刚度"一词
  中英都不止一个意思(构件刚度 EA/EI vs 结构刚度矩阵 K vs
  系统刚度 spring constant)
- 度量:应力 MPa、弹性模量 GPa、能量释放率 kJ/m²、应力
  强度因子 MPa·√m(不开根号的单位是错的);安全系数无量纲
  但要声明是对什么量取的(应力/载荷/寿命)

**术语对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 本构模型/本构方程 | constitutive model / equation | constitute=组成;译"构造"错;指应力-应变关系律 |
| 有限元法 | finite element method (FEM) | 1960 Clough 命名;不与"有限差分"混称 |
| 直接刚度法 | direct stiffness method | 1956 波音小组;位移法组装总刚的工程名 |
| 形函数 | shape function | 也译"插值函数/试探函数";单元内场的主角 |
| 刚度矩阵 | stiffness matrix | K·u=F 的 K;对称正定(卡氏/互等定理的遗产) |
| 静定/超静定 | statically determinate / indeterminate | 超静定亦译"静不定";冗余度=鲁棒性(00 章反直觉③) |
| 屈曲 | buckling | 失稳的一种(分岔失稳);≠collapse(坍塌) |
| 颤振 | flutter | 气弹自激振荡(塔科马);≠共振 resonance(00 章反直觉①) |
| 气动弹性 | aeroelasticity | 气动力+弹性结构耦合学科;简称气弹 |
| 应力集中 | stress concentration | 集中系数 K_t 认形状不认尺寸(Inglis) |
| 应力强度因子 | stress intensity factor (K) | 与"应力集中系数 K_t"不是一个量;单位含√m |
| 断裂韧性 | fracture toughness (K_Ic) | 材料抗裂纹扩展的能力;I 型平面应变值为正典 |
| 能量释放率 | energy release rate (G) | Griffith 判据的量;与 K 在线弹性下等价(通说) |
| 疲劳极限 | fatigue limit / endurance limit | 钢的有争议的水平段;铝合金无水平段(通说) |
| 损伤容限 | damage tolerance | 带裂纹安全的设计哲学(彗星空难的制度遗产) |
| 安全寿命 | safe life | 与损伤容限并列的设计哲学;不检查裂纹、到期退役 |
| 多尺度 | multiscale | 分层 sequential / 并发 concurrent 要分开 |
| 均匀化 | homogenization | 把微结构"平均"进宏观本构;RVE=代表性体积单元 |
| 降阶模型 | reduced-order model (ROM) | 实时仿真/数字孪生的引擎(01 章方向四) |
| 力学信息神经网络 | mechanics-informed neural network (MINN) | PINN 的固体力学定制版(01 章方向二) |
| 数据驱动计算力学 | data-driven computational mechanics | 不写本构、数据流形上求平衡解的路线 |
| 验证与确认 | verification & validation (V&V) | 验证=解对方程(数学),确认=方程对世界(物理);勿倒置 |
| 许用应力 | allowable stress | 规范语言;安全系数=极限/许用,对什么取的要写明 |

## 📌 收束

工程力学的语言=**三层语件(本构/平衡与几何/边界与失效
准则)+三证据的证书学(解析/数值/实验,E1-E5 阶梯)+
术语与单位的规范化**。它写下的每个"安全"都在等一张证据。
下一章把结构问题压成数据结构:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **证据眼**:听到"算出来没问题",先问证据级——解析/
  数值/实验哪级?网格收敛了吗?试样还是结构?
- **本构眼**:一切应力结论都吊在本构上——本构从哪来、
  适用域到哪,不声明就是半张合同
- **边界眼**:边界条件是另一半方程——先看约束怎么简化的,
  再看计算精不精
