## ✨ 这支最美的一个事实

**同一套 K·u=F,从两根杆到一架飞机**(家族 00 章美之时刻
②)。教学的两杆桁架(家族实验)与百万自由度整机模型,解
的是同一个代数句子;变化的只是单元里装什么(轴力→应力场
→多场耦合)。离散化没有改变力学——伽利略的问题还是那个
问题,只是答案的产地从手稿搬到了矩阵;而 K 的对称正定
(能量泛函的遗产)给了数值线代一族专用求解器
(Cholesky/共轭梯度)。**物理的统一性经由代数的统一性
落地**,这是本支最结实的一条审美线索。
