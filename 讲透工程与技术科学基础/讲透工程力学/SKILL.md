# 工程力学思维技能卡(GB/T 41020 · 讲透工程力学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「**这结构扛得住吗**」「强度/刚度/稳定性怎么校核」——
  三问分诊(00 章)
- 「**有限元原理**是什么」「刚度矩阵怎么来的」——直接
  位移法→组装(00 章美之时刻②/04 章 C1)
- 「**超静定**为什么手算解不了」——平衡方程数<未知量数,
  内力由刚度比分配(00 章反直觉③/家族实验)
- 「**塔科马桥**为什么塌」——气弹自激失稳,不是共振
  (00 章反直觉①,含正误之争)
- 「**小孔/裂纹**要不要紧」——应力集中认形状不认尺寸;
  Griffith:强度是"材料+缺陷"的结构性质(00 章反直觉②)
- 「**疲劳寿命**怎么算」「**损伤容限**是什么」——安全
  寿命 vs 损伤容限两哲学(00 章故事框四/支四)
- 「CAE 结果**能不能信**」——三证据+网格收敛规则
  (02 章/04 章 C2)
- 「**数据驱动本构/MINN**是什么」——本构来源清单的
  第三项(01 章方向二/04 章 C3C5)
- 「工程力学/力学/工程数学**什么关系**」——归入声明与
  消歧(README §〇:力学本体待建宇宙 130)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **三问眼** | 强度(会断吗)/刚度(会变形吗)/稳定性(会突然换构形吗)分开问、分开报;互不蕴含 |
| **传力路径眼** | 结构=载荷进口→力流→支座出口的一条路;找临界杆(拆了塌)与冗余杆(拆了重排) |
| **耦合眼** | 载荷不总独立于结构——风/屈曲/接触里载荷随响应变,结构问题变回路问题(去工程控制论对表) |
| **证据眼** | "安全"必附证据级:解析(E1-E2)/数值(E3,必附网格收敛)/试验(E4)/规范(E5) |
| **本构眼** | 一切应力结论吊在本构上——形式层级、参数来源、适用域三件套不齐=半张合同 |
| **组装眼** | 任意结构=单元刚度按自由度散射叠加——K·u=F 从两杆桁架到整机同一个句子 |
| **奇异眼** | 解不出先查约束:机构/欠约束在 K 上留签名(近零主元),报警优于垃圾解 |
| **尺寸眼** | 集中系数认形状不认尺寸;几何相似≠强度相似(平方-立方律),缩比外推先过审 |

## 3. 工具箱(何时用什么)

- **三问分诊**(00 章):任何受力问题先定位三问坐标+失效
  时间维(疲劳/蠕变/振动),再谈方法
- **静定/超静定判式**(00 章):m+r vs 2j——静定:平衡
  定内力(与刚度无关);超静定:刚度参与分配;差值=冗余度
- **三证据证书学**(02 章):E1-E5 阶梯+三语法规则(本构
  声明/网格收敛/边界条件声明)——收力学断言先看级
- **schema 三件套**(03 章):本构结构+离散 schema+尺度
  契约;入库三问:本构定了吗/离散合格吗/边界写了吗
- **桁架矩阵法实验**(`experiments/truss_fem_toy.py`):
  静定矩阵解=截面法手算→超静定静力法欠定而矩阵法直解
  (EA×10 内力重排 109%)→撤杆成机构,主元比塌到 1e-15
  报警——三分钟把反直觉③与证据纪律全部落成数
- **走廊五条**(04 章):C1 桁架矩阵法(已成)/C2 收敛
  研究/C3 本构拟合/C4 屈曲与模态特征值/C5 数据驱动边界

## 4. 常见误区与禁忌

- ❌ **把"算出来没问题"当"结构安全"**:数值是 E3 级,
  必附网格收敛;静默简化边界=静默换题(02 章)
- ❌ **拿静定直觉读超静定**:超静定内力随刚度比重排
  (家族实验断言④),一根杆加强可能让它旁边更受力
  (内力重分配,支一)
- ❌ **把线性屈曲当屈曲后**:特征值只给分岔点,给不了
  后屈曲下场(00 章稳定性行的未决面)
- ❌ **裂纹尖端问应力值**:线弹性解发散,语言内不允许
  问——换 K/能量释放率说话(支四)
- ❌ **缩比试验直接外推**:尺寸效应在站岗(Inglis/平方-
  立方律,00 章尺寸眼)
- ❌ **塔科马讲成共振**:通说已澄清为气动自激失稳
  (负阻尼回路)——含正误之争,按通说史实呈现
- ❌ **学习本构当万能**:MINN 管训练域内插值,域外即
  未建模(01 章方向二)——"模型搬进数据"没有豁免权
