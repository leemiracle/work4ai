## ✨ 这支最美的一个事实

功的互等定理(Maxwell-Betti,通说):第一组力在第二组力
造成的位移上做的功,等于第二组力在第一组力造成的位移上
做的功——**推的地方与让的地方可以对调**。它不只是巧:
线弹性世界里刚度矩阵必然对称(K_ij=K_ji)正是它的矩阵
形态;今天每个有限元求解器的对称存储,都是这条对称律在
收租(00 章美之时刻①)。
