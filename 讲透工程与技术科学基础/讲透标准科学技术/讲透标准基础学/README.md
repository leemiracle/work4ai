## ✨ 这支最美的一个事实

**一条方程给「先发优势」定价**(家族实验律3)。锁定
动力学 ds/dt=k·s(1−s)·[a(s−1/2)+q] 把「劣多少能被
多少先发救」写成临界份额 s*=1/2−q/a——质量差与网络
强度在方程里平等竞争。经济学由此获得「接口动力学」,
标准学由此获得理论地基;QWERTY 是它最著名的史例
(机制成立,效率劣势幅度按文献通说存疑)——**把
轶事升格为可计算的结构,是本支作为本体层的美学**
(00 章美之时刻②)。
