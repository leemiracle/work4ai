## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 协商一致 | 不是全体同意:重大异议被考虑后的大体同意(ISO/IEC Guide 2 义) |
| WTO/TBT | 技术性贸易壁垒协定:标准与合格评定的全球贸易接口 |
| 体系标准 | 认证对象是过程不是产品:9001 管质量过程,42001 管 AI 过程 |
| 实施监督 | 标准发布后的闭环:备案、监督检查、复审(通说不超五年) |
| 团体标准 | 学会/协会等社会团体制定:2018 年入法,快变量响应主力(通说) |
| 工效标准化 | 把人的能力与限制数据写成接口条款:显示器可调范围、操纵力上限 |

## ✨ 这支最美的一个事实

**体系标准认证的是「管得好」,不是「产品好」**
(03 章区分卡的核心)。ISO 9001 证书证明组织有质量
过程,不证明任何一件产品合格;ISO/IEC 42001 证书
证明组织有 AI 治理体系,不证明模型安全。这层区分
常被市场话术抹掉,却是现代合格评定金字塔的设计
精髓:**过程可审核、产品需检测、机构须认可**——
三件事三种证据,不可互相冒充(01 章方向一的未决
问题正是它)。
