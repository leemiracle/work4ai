# 讲透标准原理与方法 · 4105010——怎么立、怎么验的方法本体(GB/T 支)

> **支定位**:GB/T 13745 三级明细 **4105010 标准原理与
> 方法**:包括标准原理、标准体系、标准一致性测试、
> 标准统计方法、标准化认证与认可方法、标准规程与
> 格式等方面的研究。家族「立-验」两环的方法供给方:
> 别的支研究标准是什么、标准怎么落地,**本支研究
> 立标与验证的方法本身**——把「怎么收敛分歧、怎么
> 证明符合」写成可教可算的程序。GB/T 原生支(非自定);
> 案例按学科史与文献通说(家族写作红线)。

## 支定位与地盘

- 地盘:标准原理(通说「简化、统一、协调、优化」
  四大原理);标准体系与体系表方法(GB/T 13016);
  一致性测试(符合性判定的试验设计);标准统计方法
  (计数/计量抽样、AQL/LTPD、OC 曲线);认证与认可
  方法(检测→认证→认可金字塔、IAF/ILAC 互认);标准
  规程与格式(GB/T 1.1 起草规则、章条款架构)
- 在家族中的位置:「立」环(体系表/规程格式)与
  「验」环(一致性测试/抽样/认证认可)的双料主力;
  基础学支供历史与经济学解释,工程应用支供体制落地,
  都回这里取方法

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 四大原理 | 简化(砍多样性)、统一(钉接口)、协调(消冲突)、优化(选最优)——通说框架 |
| 一致性测试 | 对「声称符合」的判定实验:每条「应」配一种测法(02 章验证对) |
| AQL/LTPD | 抽样两点:护生产方(p₁,α)与护使用方(p₂,β)的风险锚 |
| OC 曲线 | 抽样方案的真容:P_a(p) 单调整条曲线,严格度住在斜率里 |
| 认证与认可 | 认证对产品/体系/人员,认可对认证机构——「认证的认证」 |
| 起草规则 | GB/T 1.1:范围先行、条款带效力档、附录分层——「写标准的标准」 |

## ✨ 这支最美的一个事实

**两点定一条曲线**(家族实验律1/律2)。零接受方案
(n,Ac=0)只有一个自由度,而「同时保护买卖双方」
需要钉住两个风险点——单自由度钉不住两点,这是
抽样标准族必须给 (n,Ac) 成对档位的数学理由;而两点
越靠近(5%→3%→1%),所需样本量超线性激增
(45→76→230,理论值 229.1)。**「验收的严格度」不是态度,是 OC
曲线的形状**——把公平写成曲线,是本支作为方法本体
最漂亮的演出。
