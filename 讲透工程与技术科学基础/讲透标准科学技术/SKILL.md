# 标准科学技术思维技能卡(GB/T 41050 · 讲透标准科学技术家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「**应/宜/可**有什么区别」「**shall** 条款怎么写」——
  助动词三档效力:要求/推荐/允许,语气即合同(02 章)
- 「**AQL** 怎么定」「**LTPD** 是什么」「抽检方案
  (n,Ac) 怎么选」——两点定抽样:生产方风险点
  (p₁,α)+使用方风险点(p₂,β),OC 曲线是真容
  (家族实验律1/律2)
- 「**认证和认可**什么区别」——认证对产品/体系/
  人员,认可对认证机构:「认证的认证」(03 章区分卡)
- 「**QWERTY** 为什么没人换」「先发优势怎么量化」——
  锁定动力学:ds/dt=k·s(1−s)·[a(s−1/2)+q],临界
  份额 s*=1/2−q/a(家族实验律3;优势幅度争议按
  文献通说)
- 「**事实标准 vs 法定标准**」——de facto 装机量统治,
  de jure 正当性兜底;法定性≠传播力(00 章反直觉③)
- 「**FRAND**/SEP 怎么回事」——专利嵌入标准的承诺
  语法:开放共识买传播,FRAND 买创新回报(00 章
  方法论之争第二场)
- 「**ISO 42001**/NIST AI RMF 什么关系」「**AI 标准**
  现在到哪了」——可认证体系标准 vs 自愿框架;预
  标准化研究(01 章方向一二,检索校准 2026-09-07)
- 「标准**什么时候立**合适」——太早锁死劣技术,太晚
  错过窗口:时机是决策变量不是行政日程(00 章反直觉①)
- 「**机器可读标准**是什么」——条款→断言的编译:
  「应」编译、「宜」不编译,编译失败=不可判定条款
  (04 章 C3)
- 「标准学/计量学/质量管理什么关系」——分工:计量
  管数准不准,管理学管组织做没做,本家族管条款怎么
  立、怎么验、怎么扩散(README §〇)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **接口眼** | 标准定义的是界面不是产品——统一螺纹不统一螺钉,统一角件孔不统一箱子;见标准先问「它钉住哪个界面」 |
| **锁定眼** | 先发标准有路径依赖:装机量+转换成本+网络外部性;更好的方案先问「切换成本谁付」,临界份额可算 |
| **风险两点眼** | 抽样方案永远双侧:AQL(p₁,α)护生产方,LTPD(p₂,β)护使用方;只写一侧的验收是半张合同;零接受方案单自由度钉不住两点 |
| **翻译眼** | 术语与编码标准化是把语义钉死:一物一名、码树无环;互操作的第 0 层是同义词归一 |
| **效力眼** | 条款效力分层:应/宜/可×规范性/资料性;每个「应」背后必须站着可执行的验证 |
| **时机眼** | 立标有窗口:研究收敛但方案未锁死时动;预标准化研究就是给时机之问供情报 |
| **金字塔眼** | 合格评定三层:检测→认证→认可;听到「认证」先问谁认证谁、认证的什么 |

## 3. 工具箱(何时用什么)

- **立-验-传三问**(00 章):接口怎么立(简化/统一/
  协调/优化)→条款怎么验(测试/抽样/认证)→标准
  怎么传(锁定/网络/生态)——先分诊再谈方法
- **验证成对审计**(02 章规则一):把全部「应」抽出
  来对表——每条指向试验方法/检验规则/审核证据哪种?
  对不出的就是不可判定条款
- **schema 三件套**(03 章):标准文献结构卡+认证
  认可区分卡+标准体系表;入库三问:验证对写全了吗/
  效力分层了吗/状态钉死了吗
- **OC 曲线实验**(`experiments/oc_curve_and_lockin.py`):
  P_a 单调降+n 增大变陡→Ac=0 两点冲突+LTPD 样本量
  代价表(45/76/230)→劣标准临界锁定 s*=1/2−q/a
  (三律三分钟落成数)
- **走廊三条**(04 章):C1 抽样 OC(已成)/C2 术语
  与编码机读(归一+树校验)/C3 机器可读标准(条款→
  断言编译)

## 4. 常见误区与禁忌

- ❌ **把「宜」当「应」执行**:推荐不满足≠不符合;
  验收拒收引用「宜」条款是效力越权(02 章开篇)
- ❌ **只写 AQL 不写 β**:验收条款单侧风险=半张
  合同;「全数严检」的直觉替代不了 OC 曲线的账
  (00 章反直觉②)
- ❌ **认证认可混称**:认可对机构、认证对产品体系;
  拿体系认证证书宣传产品性能是话术(03 章区分卡)
- ❌ **引用不带状态**:标准是时效文献;引用作废
  标准=引用失效法条(03 章体系表)
- ❌ **把 QWERTY 讲成「劣币铁律」**:锁定机制成立,
  「显著劣于 Dvorak」证据不足(Liebowitz & Margolis
  质疑,按文献通说);机制与幅度分开说(00 章故事框三)
- ❌ **法定性=传播力**:用得最多的常是事实标准;
  读标准先问生态装机量,再问强制力(00 章反直觉③)
- ❌ **条款写成愿望**:「应鲁棒」「应安全」给不出
  度量与测试=不可判定条款;机器可读化时第一个被
  编译器打回(04 章 C3)
- ❌ **时机当行政日程**:技术未收敛抢立标=把不成熟
  方案焊死;错过窗口再立=给事实标准追认(00 章
  反直觉①)
