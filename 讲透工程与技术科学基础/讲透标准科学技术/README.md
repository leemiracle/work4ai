# 讲透标准科学技术 · 横断层:把协商一致写成技术法(GB/T 41050)

> **标准=把协商一致写成技术法**:一门研究「如何让千万个
> 陌生的零件、组织与系统互操作」的工程科学。标准不是
> paperwork,是**负熵**——把技术可能性空间收窄到**可组合**
> 的程度:螺纹统一了扳手,集装箱统一了码头,shall/should/may
> 统一了合规的语言。一句钉住:**市场选出事实,委员会写成
> 规则,认证让它长牙;标准学管的正是这三步之间的全部
> 工程**。
>
> GB/T 13745:41050(二级学科,工程与技术科学基础 410 之下,
> 又名标准学)。**GB/T 该二级有三级明细→本家族三支用
> GB/T 原生支(标注「GB/T 支」),不自定**(4105099 兜底
> 不设支,见治理)。互链声明(宇宙 README §二):标准与
> 质量的**管理侧**在[管理学宇宙](../../讲透管理学/README.md);

  **AI 标准化与机器可读标准**(01 章)

  (1901/1947)→抽样检验与 AQL(1929-1950s)→体系认证

  事实标准与开放共识(2000s)→AI 标准化竞赛(2023-,01 章)
