# 工程图学思维技能卡(GB/T 41060 · 讲透工程图学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「**第一角/第三角**怎么读」——投影角约定:ISO 默认
  第一角、ASME 默认第三角;读图先认标题栏的投影角标识,
  约定用错,图不唯一指称一物(02 章术语表第一陷阱)
- 「**坐标公差 vs 位置度**哪个严谨」——方形带的语义
  漏洞:四角偏差是边中点 √2 倍;位置度圆带按同一最大
  偏差多给 57% 合格区域,还把判定换成径向当量——**更
  宽松的区域,更明确的语义**(00 章反直觉①)
- 「**MMC** 到底什么意思」——按**实体量**定义不按数值
  大小:孔的 MMC 是最小直径;偏离 MMC 多少,bonus 线性
  补入几何公差(有效公差=尺寸+几何+bonus,家族实验
  律3)
- 「**尺寸链**怎么叠」——两法对表:最坏法=Σt(线性,
  环数翻倍公差翻倍),RSS=√Σtᵢ²(8 环 0.141 vs 最坏
  0.40,比值 √n);先验独立性再选公式(律1/律2)
- 「**RSS** 什么时候不能信」——偏差独立才有抵消;刀具
  磨损/夹具偏置是系统性同向漂移,统计叠加系统性乐观
  (00 章方法论之争第一场)
- 「**基准**为什么不能乱」——误差没有主语就不能判定:
  方向/位置类公差必须挂基准;A|B|C 优先序把六点定位的
  装配物理写成语言(02 章规则二)
- 「**虚拟条件**是什么」——MMC∓几何公差=功能量规销径;
  恒等式 e≤tol+(D−MMC) ⟺ D−e≥VC 把「图纸条款」与
  「量规判定」焊成同一件事(律3;00 章美之时刻②)
- 「**MBD** 是不是就是电子图纸」——不是:模型+PMI 是
  **权威定义本身**,视图降格为投影输出;MBD→MBE 是组织
  转型(01 章方向一,检索校准 2026-09-07)
- 「**PMI/数字线程**谁消费」——CAM 与 CMM:计量软件直接
  读模型里的特征/公差带/基准生成检测程序,设计→制造→
  计量同源(01 章方向二,检索校准 2026-09-07)
- 「**剖视与断面**」——剖视是剖后整体投影,断面只画
  切口(GB 语境两词有别);轴测图不可当正投影量(度量
  只在显真形处)
- 「图学/几何学/计量学什么关系」——分工:几何学写投影
  为什么成立,本家族写意图怎么落成可执行的图,计量学写
  图怎么被量具兑现(README §〇)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **合同眼** | 图不是画,是合同——每根线每个符号都在等一个唯一解读与一把量具的兑现;见标注先问「验收时怎么判」 |
| **降维眼** | 投影丢深度、约定补信息;度量只在显真形处——见任何压缩表示先问丢了什么、靠什么约定补回 |
| **公差带眼** | 「合格」=落入某个带;问齐四要素:带的形状(方/圆/圆柱)、大小、方向、位置 |
| **基准眼** | 听到任何误差先问「相对谁」;基准序=装配的参照系条款,缺基准的精度是悬空句子 |
| **两法眼** | 叠加风险永远 worst/rss 双算:最坏法线性放大买绝对安全,RSS 买统计折扣——独立性是折扣的兑付条件 |
| **实体眼** | MMC/LMC 按实体量不按数值:孔越大实体越少、允许误差越多——公差与功能联动(虚拟边界担保) |
| **判例眼** | 特征控制框=微缩判例:对象+限值+验证+参照系四件套,缺一件就是坏条款 |

## 3. 工具箱(何时用什么)

- **画-标-验-流四问**(00 章):形怎么画(投影/视图)→
  量怎么标(公差/GD&T)→怎么验(量具/量规/判定式)→
  意图怎么流(PMI/数字线程)——先分诊再谈方法
- **不变量表**(02 章):正投影保从属/平行/定比/真形,
  不保角度与一般长度——一切图解方法=不变量+投影变换
- **FCF 四件套审计**(02/03 章):把特征控制框拆成
  符号/带形与大小/修正符/基准序——四件齐才有判定资格
- **公差叠加实验**(`experiments/tolerance_stackup.py`):
  worst 线性 vs RSS √n → MMC bonus 线性+虚拟边界恒等式
  → 蒙特卡洛装配率对比(三律三分钟落成数)
- **走廊三条**(04 章):C1 公差叠加(已成)/C2 投影
  不变量断言/C3 PMI 谓词编译——条款变 lambda 的最短路径

## 4. 常见误区与禁忌

- ❌ **把 MMC 当「最大尺寸」**:孔的 MMC 是最小直径
  (实体最多);按数值大小理解 MMC/LMC,bonus 方向全反
- ❌ **坐标公差当万能**:方形带四角漏水、无基准参照——
  「有界」不等于「可判定」(02 章开篇教学例)
- ❌ **只标公差不标基准**:方向/位置公差没挂基准=没有
  主语的句子;测量端只能自造参照系,验收必起争议
- ❌ **沉默即兜底**:独立原则(通说 ISO 默认)下尺寸
  合格不管几何合格——以为尺寸能兜形位,恰是它要防的
  错觉;联动要显式修正符
- ❌ **无脑最坏法或无脑 RSS**:前者贵(环数翻倍公差
  翻倍),后者在系统性漂移下乐观;先验独立性,再选公式
- ❌ **投影角不声明**:ISO/ASME 默认相反,跨体系图纸
  不认标识就开读——装反了都不知道哪错
- ❌ **轴测图上量尺寸**:轴测有轴向伸缩,「看起来像」
  不可量;度量只发生在显真形处(不变量阶梯)
- ❌ **把 MBD 当「电子图纸」**:模型+PMI 是权威定义本身;
  视图是派生输出;把 MBD 项目当「扫图入库」做,语义链
  一开始就是断的(01 章)
