## 招牌概念

| 概念 | 一句话 |
|------|--------|
| MBD | 模型+PMI=权威定义本身;不是「电子图纸」(视图是派生输出) |
| PMI | 挂在特征上的结构化工程意图:尺寸/GD&T/注释 |
| 数字线程 | 设计→制造→计量的同源数据流;转录环节消失(01 章方向二) |
| 单一权威源 | 改模型+PMI+配置三元组,任一滞后即版本事故 |
