# 02 · 语言特征——图纸的语法:投影、公差与基准三层语件

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程图学说的是**一种把几何事实写成可
> 判定条款的语言**——视图语言负责「形」(投影把三维压成
> 二维而不失决定性信息),尺寸与公差语言负责「量」(把
> 「差不多」写成带区域的条款),基准语言负责「参照系」
> (误差相对谁测量),修正符语言负责「功能关系」(实体
> 多少与允许误差多少的联动);判断一张图的好坏,不看
> 线条漂亮,看**每个符号是否只允许一个解读、每个公差
> 是否指向一种判定**。三栏分别回答:这套语言能说什么
> (表达力)、凭什么可判定(逻辑性质)、术语如何对译
> (规范化)。

---

## 0. 开篇:同一张图的三种读法(教学例)

📖 **教学例:一个孔的「位置」到底许了多少?**。同一块
板上的同一个孔,三种写法命运不同:甲图写两向坐标公差
±0.1/±0.1——验收者量出 x 偏 0.12、y 偏 0.05,合规吗?
方形带内(0.12<0.1?不合规)——但若 x 偏 0.08、y 偏
0.09,径向已偏 0.120,却「合规」;乙图标位置度 ⌀0.28
@MMC:判定只有一个数(径向偏差的直径当量),与功能
(销能不能插)同构。丙图更糟:没标基准——坐标从哪条边
量起?毛坯边还是精加工边?三种写法,三种判定结果,同
一批零件三种命运。图样语言的全部要义浓缩于此:**词汇
即判定,基准即合同的一方**。这个教学例与 00 章故事框三
(Parker 的方形带)是同一课:语言的含混不是修辞问题,
是验收问题。

## 1. 表达力:图样语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 定形 | **视图语言** | 正投影多视图/剖视/断面/轴测——降维语法:压掉一维,约定补回(00 章故事框一) |
| 定位 | **基准语言** | 基准要素→基准体系(三基面按 A/B/C 优先序);设计/工艺/测量基准三重身份 |
| 定量 | **尺寸公差语言** | 基本尺寸+极限偏差→公差带;配合(基孔制/基轴制,间隙/过盈/过渡) |
| 定误差 | **GD&T 符号** | 特征控制框:形状(直线度/平面度…)、方向(垂直度/平行度…)、位置(位置度…)、跳动、轮廓,分组管控 |
| 定功能 | **修正符语言** | Ⓜ(MMC)/Ⓛ(LMC)——实体多少与允许误差多少联动(律3 的 bonus);⌀ 与公差带形状 |
| 定状态 | **标题栏语言** | 图号/版本/比例/投影角标识(第一角/第三角识别符号,通说截头圆锥符号)——图纸的「身份与效力」字段 |

**不能说的**(表达力边界,与生俱来):

- **设计意图的「为什么」**:功能上为什么这个面必须对齐、
  这个公差为什么是 0.1——符号不带 rationale,只能靠设计
  师口头传承;MBD 的语义化 PMI 部分偿还(00 章假设三)
- **工艺方法**:图定义 what not how——车还是铣、先热处理
  还是后热处理,留给工艺文件;越界的工艺标注会绑架
  制造选择(通说惯例)
- **非刚性状态**:装配变形、受力后的位置——除非特别声明,
  公差都在自由态/刚性假定下判定
- **未声明的公差相关关系**:两个公差各自独立验证(独立
  原则,通说 ISO 默认),要联动必须用基准或修正符显式
  声明——「默认独立」是这套语言最容易被误读的一条

## 2. 逻辑性质:投影的不变量与条款的可判定性(三栏之二)

### 2.5 投影不变量阶梯(图学的「真值表」)

| 命题 | 正投影下 | 推论 |
|------|---------|------|
| 点属于线/线属于面 | **保持**(从属性不变) | 图解求交点/相贯线的合法性来源 |
| 两线平行 | **保持** | 平行关系可在图上直接判定 |
| 平行线段之比 | **保持**(定比性) | 分割线段、作相似形的图解依据 |
| 平行于投影面的平面图形 | **显真形** | 「量在显真形的视图上」——度量规则 |
| 垂直于投影面的面/线 | **积聚**成线/点 | 积聚性:降维压缩信息的机制本身 |
| 角度、一般长度、面积 | **不保持** | 除非显真形;轴测图「看起来像」不能量 |

读法:画法几何的一切图解方法(求真长、真形、两面夹角、
相贯线)=**不变量+投影变换**(把不保真的量换到保真的
位置去量)。这就是蒙日体系的逻辑骨架:它不是画得像,
是把「什么可信、什么不可信」列成了表。

### 2.6 三个可判定性规则(图样条款的证据规则)

- **判定成对规则**:每条公差标注必须能指向一种判定程序
  (量具/仪器/检测程序);方形带写法给不出与功能同构的
  判定(开篇教学例),位置度给得出——「可判定」是 GD&T
  对坐标公差的代差优势(00 章方法论之争第二场的判据)
- **基准显式规则**:方向/位置类公差必须挂在显式基准上;
  无基准的形状公差只能「自检」(面平不平与装在哪无关)。
  基准优先序(A/B/C)把「六点定位」的物理装配关系写成
  语言——**基准是图纸合同里的参照系条款,缺了它,误差
  没有说话的主语**
- **默认独立规则**(通说 ISO 8015):尺寸公差与几何公差
  各自独立验证,互不放大不缩小;例外必须显式声明(包容
  要求 E 的圈号 E/修正符 Ⓜ)——「沉默即独立」,与法律
  条文的「明示其一即排除其他」同构;误读者以为尺寸合格
  能兜底几何,恰是独立原则要防的错觉

## 3. 规范化:术语与对译(三栏之三)

- 国际语境两大体系:ISO(默认第一角投影,GPS 体系)与
  ASME(默认第三角投影,Y14.5);中英图纸互读必须先认
  投影角标识,再谈术语;中文语境 GB/T 4457/4458 与 ISO
  协调,默认第一角(通说)
- 体系差异的读法:同一几何事实,两大体系的符号与默认
  规则存在差异(如某些修正符与默认独立原则的表述),
  跨体系图纸必须声明所依标准——「声明口径」永远先于
  「对符号」(通说惯例;01 章方向三)
- 度量:尺寸链语言带单位;计量基准温度 20 °C(通说);
  公差值恒非负,偏差可正可负——「公差」与「偏差」混用
  是入门第一错

**术语对译表(日常语→图学语;中英对照)**:

| 中文(图学语) | 英文 | 日常语陷阱 |
|------|------|---------|
| 图样 | drawing | ≠随手一张图:带标题栏与规范语法的正式技术文件 |
| 视图 | view | ≠「看一眼」:按投影法约定生成的图形 |
| 第一角/第三角投影 | first-/third-angle projection | 默认值随标准体系反转;读图先认投影角符号 |
| 剖视图/断面图 | section / cross-section | 剖视是「剖后整体投影」,断面只画「切口」——GB 语境两词有别 |
| 轴测图 | isometric (axonometric) drawing | ≠「立体图」泛称;有轴向伸缩规律,不可当正投影量 |
| 基本尺寸 | basic size (nominal) | ≠「实际尺寸」:只是理论值,实测永不等于它 |
| 偏差/公差 | deviation / tolerance | 偏差可有正负,公差恒为区间宽度(非负)——混用即概念错 |
| 配合 | fit | 间隙/过盈/过渡三分;≠「组装上去就行」 |
| 基孔制/基轴制 | hole-basis / shaft-basis | 「制」指固定哪一侧的公差带位置 |
| 基准 | datum | ≠「基础」:误差测量的参照体系,按要素指定 |
| 形位/几何公差 | geometric (geometrical) tolerance | ASME 称 GD&T;ISO 语境称 GPS 几何规范 |
| 位置度 | true position / position | 判定用径向偏差直径当量,与坐标公差不可直接换读 |
| 最大实体状态 | MMC (maximum material condition) | **≠最大尺寸**:孔的 MMC 是最小直径(实体最多) |
| 最小实体状态 | LMC (least material condition) | 同理反转;两词按「实体量」定义,不按数值大小 |
| 实效/虚拟条件 | virtual condition | MMC∓几何公差——功能量规销径的来源(律3) |
| 独立原则 | independency principle | 「沉默即独立」:尺寸与几何公差互不兜底(通说默认) |
| 包容要求 | envelope requirement (Ⓔ) | 泰勒原则的图学化身:尺寸公差同时管住形状 |
| 产品制造信息 | PMI (product manufacturing information) | ≠普通注记:挂在 3D 模型上的结构化公差语义 |
| 基于模型的定义 | MBD (model-based definition) | ≠「电子图纸」:模型+PMI 是权威定义本身(01 章) |
| 数字线程 | digital thread | 设计→制造→计量的同源数据流(01 章方向二) |

## 📌 收束

工程图学语言=**投影的不变量语法(从属/平行/定比/真形,
什么可信什么不可信列成表)+公差的可判定条款(特征控制
框=谓词+公差带+基准,每个符号只许一个解读)+术语的
钉死术(MMC/LMC 按实体不按数值、独立原则沉默即独立)**。
它写下的每条公差都在等一把量具与一套参照系。下一章把
图与公差压成数据结构:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **不变量眼**:任何表示先问「什么被保真、什么被压缩」
  ——度量只发生在显真形的地方
- **基准眼**:听到任何误差先问「相对谁」——没有基准的
  精度是悬空的句子
- **公差带眼**:「合格」永远是「落入某个区域」——问清
  带的形状(方/圆/圆柱)、大小、方向、位置四要素
