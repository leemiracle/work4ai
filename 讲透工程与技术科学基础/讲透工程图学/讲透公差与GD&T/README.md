## 支定位与地盘

- 地盘:尺寸公差与配合制(基孔制/基轴制;间隙/过盈/过渡);
  形位公差符号体系(ASME Y14.5/ISO GPS,通说);特征控制框
  四件套;基准体系与六点定位;MMC/LMC/RFS 与虚拟条件;
  独立原则与包容要求(通说 ISO 默认);尺寸链(最坏法/RSS)
- 在家族中的位置:投影支给「标在哪」,本支给「怎么判」;PMI 语义是本支条款的序列化

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 特征控制框 | 微缩判例:对象+限值+验证+参照系,缺一即坏条款 |
| 基准优先序 | A\|B\|C 写下装配物理;无基准=无主语句 |
| MMC/LMC | 按实体不按数值:孔的 MMC 是最小直径;bonus 线性补入 |
| 虚拟条件 | MMC∓几何公差=量规销径;条款式⟺量规式(恒等式) |

## ✨ 这支最美的一个事实

**一行代数焊死条款与量具(家族实验律3)**。恒等式:
e≤0.2+(D−10.0) ⟺ D−e≥9.8——左边是图纸条款语言,右边是
车间量规语言(⌀9.8 销能不能插)。蒙特卡洛十万件:RFS 判 33%
合格,MMC 判 73%,救回的四万件全部过量规——**功能性由代数
担保,不靠运气**(00 章美之时刻②)。
