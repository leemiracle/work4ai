# 讲透投影与制图原理 · 降维的语法——理论主干(自定支)

> **支定位**:家族的**理论主干**——研究「三维的物怎么压成二维的
> 图而不失决定性信息」:蒙日画法几何(两投影面体系/投影变换/
> 图解法)、视图与表达(基本视图/剖视/断面/局部放大)、轴测
> 投影、投影角约定(第一角/第三角,ISO 与 ASME 默认相反,
> 通说)。互链:投影与变换的数学本体在[数学宇宙·几何学](../../../讲透数学/讲透几何学/README.md),
> 本支写它的工程方言与制图规范。GB/T 13745:41060 无三级明细,
> 本支为自定支;蒙日史按通说不编造(薄学科纪律)。

## 支定位与地盘

- 地盘:正投影与两投影面体系;投影变换与图解法(真长/真形/
  夹角/相贯线);不变量阶梯(02 章);视图选择与剖视/断面;
  轴测;第一角/第三角与识别符号;GB/T 4457/4458 制图规范
  (与 ISO 128 协调,通说)
- 在家族中的位置:给公差支供「标在哪」,给 MBD 支供「视图=
  模型投影输出」的原理;家族语言的数学地基

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 降维语法 | 两投影面+翻转约定唯一确定三维形体;压掉一维,约定补回 |
| 不变量阶梯 | 保从属/平行/定比/真形,不保角度与一般长度(02 章表) |
| 投影角 | 第一角(ISO/GB 默认)与第三角(ASME 默认)相反 |
| 剖视/断面 | 剖视=剖后整体投影,断面=只画切口(GB 语境有别) |

## ✨ 这支最美的一个事实

**丢什么、补什么,算得清楚(00 章美之时刻①)**。蒙日体系不是
「画得像」,是把可信度列成表:从属、平行、定比投影下不动,
角度与一般长度会变形——图解方法的骨架都是「先把要量的量
变换到显真形处再量」,两百年没换骨架(04 章 C2 把它写成
单元测试)。
