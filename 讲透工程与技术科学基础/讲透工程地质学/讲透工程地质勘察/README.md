## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 三重证据 | 钻探(点直接)/物探(线间接)/遥感(面间接):层级+互证,不是三选一 |
| 一孔之见 | 钻孔是体的一亿分之一的点:直接但极稀,代表性靠布孔逻辑 |
| 反演多解 | 同一物探异常可由多种地层组合造成:未验证只能"推测"措辞 |
| 覆盖声明 | 每条地质断言必附证据范围(点/线/面):不写=半张合同(家族 02 章) |
| 取样质量 | 扰动让试验失真:试样是"带指纹的证据" |
| 地层模型 | 勘察的最终产品:分层+结构面+地下水,每条带证据级(家族 03 章) |

## ✨ 这支最美的一个事实

**卫星普查+钻探点名:抽样的逻辑被倒过来了**(家族 00 章
美之时刻③、01 章方向四)。传统勘察按"工程需要"布点——
先有工程,后有钻孔;InSAR 时代地壳先"自首":BGS 用
AI+卫星在全国尺度识别约 3000 处活动边坡(检索校准
2026-09-07),勘察从"应需求查"变成"按异常核"。但三重
证据的语法一寸没变——卫星看见的是形变(结果),物探
圈的是异常(候选),钻孔才能定名(证据);**眼睛升级了,
仲裁权还在钻探与地面核查手里**。
