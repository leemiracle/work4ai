# 工程地质学思维技能卡(GB/T 41030 · 讲透工程地质学家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「**地质条件怎么进设计参数**」——翻译链六环:
  勘察→地层模型→参数→安全评价→风险区划→监测预警
  (00 章)
- 「**有效应力**是什么」「**孔压**为什么降强度」——
  σ'=σ−u,孔隙水不承剪:一个减法统一固结/排水强度/
  雨季滑坡(00 章故事框一)
- 「**瓦依昂**怎么了」——结构面被均匀化平均掉,地质
  档案没进计算书:地壳用事故给安全系数回信(00 章
  故事框二)
- 「**承载力/安全系数/沉降**怎么读」——设计语言三件
  套:工况并列、统计身份、峰值还是残余(02 章)
- 「**钻探物探遥感**谁说了算」——三重证据 E1-E5 阶梯:
  覆盖声明/多解消解/统计身份三规则(02 章)
- 「**滑坡易发性/危险性/风险**怎么分」——链式相乘:
  易发性×危险性×暴露×易损,只乘第一项的不叫风险图
  (03 章)
- 「**InSAR+AI**怎么监测边坡」「**主动防控**是什么」
  ——卫星普查→AI 初筛→地面核查→动态台账(01 章方向
  一四,检索校准 2026-09-07)
- 「**FS=1.5 就安全吗**」「**安全系数还是失效概率**」
  ——同一 FS 可装着 Pf=1% 或 10%:范式差与双写方案
  (00 章方法论之争/家族实验断言③)
- 「工程地质学/岩土工程/**地学**什么关系」——互链:
  地学本体在地球科学宇宙(170,待建),本家族管工程侧
  (README §〇)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **界面眼** | 任何岩土问题先拆两侧:工程要什么(参数/系数),地壳给了什么(证据/档案);翻译损耗在哪环,风险就住哪环 |
| **档案眼** | 结构面、老滑坡、历史采空都是设计参数;峰值与残余之差写在地质历史里,不在试验报告里 |
| **水眼** | 土的强度问题一半是水的问题:看到强度先问排水路径与孔压状态(σ'=σ−u 管到底) |
| **工况眼** | 安全系数没有单值身份——"FS 多少"后面不跟工况等于没说;天然/饱和/地震并列 |
| **画像眼** | FS 是平均画像,Pf 是分布画像;参数变异性不进语言,安全评价是半张合同 |
| **阶梯眼** | 听到"地下有××"先问证据级:遥感/物探/钻探/试验/原型观测哪级?覆盖多大? |
| **概化眼** | 计算之前先审概化:分层、滑面、边界条件错了,精度都是装饰(瓦依昂) |
| **观测眼** | 不确定性消不净就把设计变闭环:预报-观测-修正(Peck 观测法) |

## 3. 工具箱(何时用什么)

- **翻译链六问**(00 章):地下有什么/参数取多少/安全
  吗/水怎么办/坏了怎样/怎么知道要坏——先分诊再谈方法
- **三重证据证书学**(02 章):E1-E5 阶梯+三语法规则
  (覆盖声明/多解消解/统计身份)——收地质断言先看级
- **schema 三件套**(03 章):地层模型+边坡参数卡+
  风险区划图;入库三问:证据级写全了吗/工况并列了吗/
  后果链完整吗
- **无限边坡实验**(`experiments/slope_stability_fs.py`):
  干燥 FS=tanφ/tanβ 双单调、β=φ 处 FS=1 → 孔压线性
  压低 FS(全饱和≈减半,雨季机关参数化)→ A 场地
  FS=1.51 却 Pf≈8.5%、B 场地 FS=1.31 却 Pf<0.1%
  (范式差三分钟落成数)
- **走廊三条**(04 章):C1 无限边坡 FS(已成)/C2 地层
  插值(IDW/克里金:插值+方差成套)/C3 风险叠加
  (链式相乘+显式分级阈值)

## 4. 常见误区与禁忌

- ❌ **把物探推断当钻探揭示**:反演多解——未经钻孔
  验证的物探结论只配"推测"措辞(02 章规则二)
- ❌ **naked 参数**:"c'=10 kPa"不带来源/工况/统计
  身份,无法复算;特征值与均值不可混(02 章规则三)
- ❌ **易发性图冒充风险图**:后果缺席时只有危险性,
  没有风险;跳级相乘是区划偷工(03 章)
- ❌ **只报单工况 FS**:天然工况 FS 的报告是半张合同;
  饱和/地震缺席,审查不可复算
- ❌ **拿峰值当残余**:超固结土与老滑坡体默认按残余
  强度;渐进破坏在 FS 略大于 1 的状态里推进(00 章
  反直觉②)
- ❌ **只盯坡度图层**:最危险的滑坡往往不是最陡的——
  缓坡+厚土+高水位才是大户(00 章反直觉①)
- ❌ **AI 结论当机制**:卫星看见的是形变不是原因;
  物理引导 ML 胜过纯黑箱,"眼睛升级了,判断没外包"
  (01 章元趋势)
- ❌ **涉及现实工程隐患点**:案例按学科史实通说(瓦依
  昂等),不做任何在役工程的安全性引申(家族写作红线)
