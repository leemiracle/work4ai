# 03 · 可构造与结构——地层模型、参数卡与风险图作为数据对象

> **本章回答五问之 Q4(可构造性与结构)。**
> **本质一句话**:工程地质学里"可构造"的不是地壳本身,
> 而是**地质问题的三类数据对象**——地层模型是把"地下
> 有什么"写成带证据级的三维分层结构,边坡稳定性参数卡
> 是把"安全吗"写成方法-工况-参数-系数成套的报告结构,
> 风险区划图是把"坏了会怎样"写成易发性→危险性→风险
> 的图层级 schema;把这些结构显式化,岩土工作就从手艺
> 变成工程:可校验、可对表、可交接(04 章走廊的地基)。

---

## 0. 开篇:一份"边坡评估任务单"的三件结构化家具

拆开任何一次严肃的岩土评估(边坡/地基/隧道),都能
拆出三件家具:其一是**地层模型**(地下有什么——分层、
结构面、地下水,每条都带证据级),其二是**稳定性参数
卡**(安全吗——方法、参数来源、工况、系数,成套
出现),其三是**风险台账/区划**(坏了怎样——易发性、
危险性、暴露、易损,逐级相乘)。三件家具在手,00 章
翻译链的每一环就变成**可机检的数据流水线**;从瓦依昂
到 InSAR 时代,在数据结构层面是同一套 schema——变
的是证据密度,不变的是结构。

## 1. 什么是"可构造"的:三类结构对象

| 对象 | 数化身 | 可构造性 | 构造中的坑 |
|------|--------|---------|-----------|
| **地层模型** | 分层(成因-时代-定名)+顶底标高+结构面产状+地下水+逐条证据级 | ✅ 高度可构造 | 物探推断层与钻探揭示层混写不分(02 章规则二);模型边界=证据边界不声明 |
| **边坡稳定性参数卡** | 方法(无限边坡/条分)+参数(带统计身份)+工况+FS/失效概率双写 | ✅ 高度可构造 | 只报单值 FS 不报工况与参数来源;峰值冒充残余 |
| **风险区划图** | 图层栈(易发性×危险性×暴露×易损)+分级图例+验证指标 | ✅ 可构造(新) | 易发性当风险用(后果缺席);图层权重无来源 |
| **监测台账** | 测点/时序/形态分段(匀速-加速)/预警状态 | ✅ 可构造 | 形态判读规则不显式;InSAR 盲区不入册 |
| **滑坡编目** | 边界/类型/体积/时间/证据级清单 | ✅ 可构造 | 编目偏差直接变成 ML 训练偏差(01 章方向三) |

**不可构造的**:钻孔之间的真值(模型是概化,00 章假设
一)、确切失效时刻(监测只有形态)、未来的参数(风化
与蠕变让设计值随时间漂移)、以及"这面坡此刻的完整
状态"(一切模型都是快照,观测法就是为此存在的)。

### 1.5 最小数据模式(动手者的 schema)

```yaml
# 地层模型(每层带证据级与参数的统计身份)
ground_model:
  layers:
    - {genesis: residual, age: Q4, name: clay,
       top_elev: float, bottom_elev: float,
       evidence: E3-drilled|E2-geophysics|E1-inferred,  # 揭示/推断分级
       params: {c_kpa: [float, float], phi_deg: [float, float],
                coV: float, kind: characteristic|test}}   # 特征值+变异系数
  discontinuities: [{type: bedding, dip_deg: float,
                     dip_dir: float, evidence: E3}]
  groundwater: {level_elev: float, season_range: float}

# 边坡稳定性参数卡(方法-参数-工况-系数成套出现)
slope_report:
  method: infinite_slope|fellenius|bishop|spencer|finite_element
  params_source: ground_model_ref          # 参数从地层模型来,不另写
  cases:                                   # 工况并列,缺一不可
    - {name: natural,  ru: 0.0, fs: float}
    - {name: saturated, ru: 0.5, fs: float}
  reliability: {pf: float, beta: float, basis: monte_carlo|fosa}  # 双写(00 章之争的和解)
  acceptance: {fs_min: 1.5, pf_max: 0.05, code: str}

# 风险区划图(图层栈+分级图例+验证)
hazard_map:
  susceptibility: {raster: str, factors: [slope, lithology, soils, hydro],
                   model: rf|lr|expert, validation_auc: float}
  hazard: {trigger: rainfall_24h_mm, scenario: str}
  elements: {exposure: roads|buildings, vulnerability: table_ref}
  risk: {classes: [low, moderate, high, very_high], rule: str}
  caveats: [inSAR_blind_zones, inventory_bias]     # 盲区与偏差显式入册
```

注意 `evidence`、`cases` 与 `kind` 三处必填:把 02 章的
证据纪律写进数据结构——**数据层自带校验点,是岩土工程
区别于论文表格的第一特征**(与
[工程物理学家族](../讲透工程物理学/03-可构造与结构.md)
schema 同款精神:参数不 naked,工况不缺席)。

## 2. 骨架一:地层模型(证据的三维化)

- **分层三元组+证据级**:每层是"成因-时代-定名+一条
  证据级"——E3 钻探揭示的层画实线,E2 物探推断的层
  画虚线;**一张图上两种线型,是勘察报告的诚实度测试**
- **结构面不缺席**:层面/节理/断带的产状单独入册;
  均匀化模型(00 章假设一)覆盖不了控制性弱面时,
  结构面就是模型本身(瓦依昂;岩体力学支的立身之地)
- **地下水是动态层**:水位不是一个标高,是带季节变幅
  的区间——暴雨工况的水位就是安全系数的工况(家族
  实验断言②的 schema 版)
- **模型边界=证据边界**:模型外推到钻孔控制范围之外
  的部分必须显式声明(02 章覆盖声明规则的几何面)

## 3. 骨架二:边坡稳定性参数卡(安全的成套语法)

- **方法-参数-工况-系数四件套缺一不可**:方法决定参数
  怎么进方程(无限边坡用 φ,条分法要 c、φ 沿滑面分布);
  参数从地层模型引用(不另写,防两处不同步);工况并列
  (天然/饱和/地震);系数按工况报(家族实验断言②:
  同一坡,饱和工况 FS 约为干燥的一半)
- **FS 与 Pf 双写**:00 章方法论之争的和解方案——FS
  管规范通信与审查,Pf 管风险排序与优化;双写的共同
  前提是参数带统计身份(02 章规则三)。实验断言③的
  A/B 两场地就是双写的教学标本:FS 排序与 Pf 排序
  可以相反,双写才看得见
- **强度身份**:峰值还是残余(00 章反直觉②)?老滑坡
  体与超固结土默认按残余写;工况行必注

## 4. 骨架三:风险区划图(后果的语言)

- **四级链式相乘**:易发性(容易滑吗)→危险性(某触发
  下多大可能滑)→暴露(滑了砸到什么)→易损(砸了坏
  多少)→风险;**每一级都有独立的数据源与验证法**,
  跳级相乘是区划的常见偷工(易发性图直接当风险图用)
- **图层栈的证据身份**:每个图层的来源、分辨率与权重
  要可追溯——ML 时代这变成"特征重要性表+清单偏差
  声明"(01 章方向三);专家打分时代是"打分表",制度
  相同:权重不是自然常数,是决策约定,要签名
- **验证与盲区入册**:ROC/AUC 类指标说明图对历史编目
  的拟合;InSAR 盲区、编目空白区显式写入 caveats——
  **一张不写盲区的风险图,是决策系统的定时输入**

## 5. 从结构到校验:这套骨架买到了什么

- 地层模型带证据级 → 概化与揭示可区分,审图可机检
- 参数卡成套 → 安全结论可复算(独立于写它的人)
- FS/Pf 双写 → 两种安全画像并读,范式差可见(00 章)
- 风险图带图层身份与盲区 → 管理决策的输入可问责
- 监测台账带形态分段 → 预警状态可交接(动态台账,
  01 章方向一的"一体化"地基)

## 6. 构造合法性清单(动手前三问)

把任何岩土构想变成数据结构之前,先过三问——本家族的
"类型检查":

1. **证据级写全了吗**:每一层、每条结构面、每个参数,
   E1-E5 哪级?覆盖范围多大?推断层与揭示层分线型了吗?
2. **工况并列了吗**:天然/饱和/地震各在哪一行?强度
   是峰值还是残余?水位变幅进地下水层了吗?
3. **后果链完整吗**:易发性之外,暴露与易损在哪一层?
   盲区与偏差入册了吗?——以及 FS 之外,Pf 写了吗?

三问全过,数据才获得进入 [04 章走廊](04-工程地质学转代码.md)
的资格。**岩土工程的第一特征不是算得深,是账目清楚。**

## 📌 收束

可构造的是**三类数据对象**(地层模型/参数卡/风险图),
不可构造的是**钻孔间真值与失效时刻**;结构化不是为了
替代地质师,是为了让勘察-设计-监测的链条可校验、可
交接、可复盘。下一章把骨架接上代码:
[04-工程地质学转代码](04-工程地质学转代码.md)。

**🧠 认知升维**:

- **证据眼**:模型里每条线都有证据级——揭示画实线,
  推断画虚线;两种线型混用的图不可读
- **工况眼**:安全系数没有单值身份——"FS 多少"后面
  不跟工况,等于没说
- **后果眼**:风险=易发性×暴露×易损;只乘第一项的
  图叫易发性图,不叫风险图
