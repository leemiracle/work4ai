## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 易发性 | "容易滑"的程度:只看地质本体条件,不看哪天下雨 |
| 危险性 | 易发性×触发概率:某工况下多大可能成灾 |
| 风险链 | 易发性×危险性×暴露×易损:后果缺席没有风险(家族 03 章) |
| 临滑判据 | 位移加速形态:统计经验不是物理时刻(家族 00 章语言边界) |
| 雨季触发 | 入渗抬孔压→FS 线性下坠:水是主犯的参数化(家族实验断言②) |
| 动态台账 | 卫星普查→AI 初筛→入册更新:风险区划从静态图变数据流(01 章方向四) |

## ✨ 这支最美的一个事实

**最危险的滑坡往往不是最陡的**(家族 00 章反直觉①)。
直觉按坡度排风险,但陡坡的松散物质早已在地质历史上
卸荷运走;滑坡大户是中缓坡上的厚层残积土与老滑坡体
——坡度 15°-30°,土厚,汇水大,雨季孔压一升 FS 线性
下坠。家族实验的对照:φ=40°、β=26° 的坡干燥 FS=1.72,
饱和度爬到 85% 即到失稳线;β=20° 的缓坡同机制下反而不
失稳——**风险的排序住在"坡度×土厚×水文"的乘积里,
不住在坡度一列里**。这就是易发性制图必须多图层、区划
不能只描陡坡的力学根据。
