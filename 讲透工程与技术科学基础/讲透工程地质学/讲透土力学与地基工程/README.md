## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 有效应力 | σ'=σ−u,孔隙水不承剪:一个减法统一一门学科(家族 00 章美之时刻①) |
| 固结 | 孔压消散才有效应力增长:沉降是时间的函数 |

## ✨ 这支最美的一个事实

**孔压是土力学的万能旋钮**(家族 00 章故事框一)。同一层
饱和粘土,快剪强度低、慢剪强度高——不是土变了,是孔压
消散程度变了;同一面坡,旱季站得住、雨季滑——不是重力
变了,是入渗抬了孔压(家族实验断言②:FS 对饱和度严格
线性)。太沙基的减法把"水"从工地麻烦升格为设计变量:
**一个问题只要落到孔压上,它就同时有了物理解释、试验
方案与工程对策**——这是本支作为理论主干的方法论含义。
