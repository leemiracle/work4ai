# 02 · 语言特征——地层语言、设计语言与三重证据

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程地质学说的是**一种双层语言**——
> 地层语言(成因-时代-定名-结构面,描述地壳给的东西)
> 与设计语言(承载力 kPa/安全系数 FS/沉降 mm,工程要的
> 东西),两层之间靠**参数升格链**(地层单元→试验值→
> 特征值→设计值)缝合;判断一段岩土写作的优劣,不看
> 文采,看**每个参数背后站着哪种证据**(钻探-物探-
> 遥感三重证据的层级与互证)。三栏分别回答:这套语言
> 能说什么(表达力)、地质断言凭什么可信(逻辑性质)、
> 术语如何被标准化(规范化)。

---

## 0. 开篇:同一个边坡的三种文本

📖 **故事框:一面坡的三份报告**。地质师的文本:地层
剖面图——"坡体上部为第四系残积粘性土,厚 3-8 m,下伏
泥质粉砂岩,岩层倾向与坡向一致(顺层),发育两组构造
节理"——**写的是地壳给的东西**,一个数字都没有,但
"顺层"两个字已经预报了滑面候选。土力学家的文本:
条分法计算书——"取滑面残余参数 c'=8 kPa、φ'=15°,
天然工况 FS=1.42,暴雨饱和工况 FS=1.05"——**写的是
工程要的东西**,地层被压缩成两个参数,但工况并列让
安全水平可比。风险师的文本:"该坡体年度失效概率约
10⁻² 量级,威胁对象为坡脚道路,建议入册监测"——
**写的是决策要的东西**,FS 消失了,换成概率与暴露。
三种文本说的是同一面坡:**地质文本丢数字买结构,计算
文本丢结构买可比,风险文本丢力学买决策**。工程师的
语言工作,就是在三种文本之间**带着证据翻译**(升格与
降格都留痕)。

## 1. 表达力:工程地质语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 地壳的可读性 | **地层语言** | 成因(残积/冲积/滑坡堆积)-时代(第四系/白垩系)-定名(粘性土/泥质粉砂岩)三元组;结构面(层面/节理/断带)产状三要素 |
| 强度的可比性 | **设计语言** | 承载力特征值(kPa)/边坡 FS/沉降(mm 与固结度)/渗透系数(m/d) |
| 参数的升格链 | **统计身份语言** | 试验值(一孔一样)→统计均值±变异系数→特征值/标准值→设计值(分项系数后) |
| 工况的并列 | **工况语言** | 天然/暴雨饱和/地震三工况并列的 FS 表——安全水平是工况的函数,不是单值 |
| 空间的分级 | **区划语言** | 易发性五级分区/风险分区——把连续空间切成管理可用的离散等级 |
| 时间的可读性 | **监测语言** | 位移-时间曲线(匀速段/加速段)/年形变速率(mm/a)——地壳的行为记录 |

**不能说的**(表达力边界,与生俱来):

- **钻孔之间的真相**:模型画的是概化(00 章假设一);
  尖灭、透镜体、局部软夹层的"不可见性"是语言自带属性
- **没采到的那层**:参数只对试样负责,滑面恰好穿过
  没取到的泥化夹层时,计算书无法自证其错(瓦依昂)
- **确切的失效时刻**:监测语言只有形态(加速趋势),
  临滑时刻是统计判据不是物理时刻;经验性是它的胎记
- **未来的参数**:风化/蠕变/水位变迁让"设计值"随
  时间漂移(00 章假设三),语言里没有自动的老化语法

## 2. 逻辑性质:钻探-物探-遥感三重证据(三栏之二)

地质断言的可信度来自**证据的层级与互证**,不是图幅
的美观:

| 证据 | 是什么 | 特权与陷阱 |
|------|--------|-----------|
| 遥感 | 卫星影像/InSAR 形变/航片地貌判读 | 特权:全域覆盖、可时序重复;陷阱:看的是表象(形变/植被/色调),不是岩土本身;几何盲区 |
| 物探 | 地震/电阻率/地质雷达剖面 | 特权:剖面连续、覆盖钻孔之间;陷阱:**反演多解**——同一异常可由多种地层组合造成,不经验证不能进模型 |
| 钻探 | 岩芯、编录、取样 | 特权:**唯一直接证据**——"一孔之见"但货真价实;陷阱:点是体的一亿分之一,孔位偏差即代表性偏差 |
| 原位+室内试验 | 标贯/静力触探/剪切试验 | 特权:参数的物理来源;陷阱:扰动与尺寸效应(试样≠原位),方法系统差要当指纹管理 |
| 原型观测 | 竣工后监测/反分析/滑坡编目 | 特权:全尺度真相;陷阱:样本少、代价高;"已发生"不等于"全知道" |

### 2.5 断言强度阶梯(工程地质版 E1-E5)

| 阶梯 | 措辞 | 证据状态 | 岩土特有注意 |
|------|------|---------|-------------|
| E1 遥感/地貌级 | "影像显示该坡体存在老滑坡地貌" | 区域间接 | 覆盖广但非直接;判读经验决定质量 |
| E2 物探级 | "电法剖面显示基岩面埋深约 12 m" | 剖面间接 | 多解性:未经钻探验证只能"推测"措辞 |
| E3 钻探级 | "ZK3 揭示 8.2 m 处泥化夹层" | 点直接 | 一孔之见:横向延伸要靠 E1/E2 补,不敢外推太远 |
| E4 试验统计级 | "粘土特征值 c'=12 kPa、φ'=16°(n=9)" | 参数直接 | 统计身份必附(n/变异系数);原位与室内的系统差要声明 |
| E5 原型观测级 | "三年监测显示坡体累计位移 4 mm,处于匀速段" | 行为直接 | 全尺度但样本少;外推要谨慎 |

**误用告示**:把 E2(物探推断)写成 E3(钻探揭示)是
勘察报告的头号措辞越权;把 E4(试样参数)直接当设计值
(漏掉特征值与工况折减)是计算书的头号跳步;拿 E1
(影像异常)直接圈定工程处置范围——中间隔着两级证据
的距离(02 章规则二)。

### 2.6 三个内部语法规则

- **覆盖声明规则**:任何地质断言必附证据覆盖范围
  (一点/一线/一面/全域);"存在泥化夹层"后面不写
  "见于 ZK3,延伸范围据物探推测",断言是半张合同
- **多解消解规则**:物探异常须经钻探验证才能以"揭示"
  级措辞进地层模型;E2 不得单独支撑设计参数
- **统计身份规则**:一切参数必附来源与身份(试验值/
  特征值/经验值;n 与变异系数;天然/饱和/残余工况
  何者)——"c'=10 kPa"不写这些,读者无法复算安全
  水平(00 章方法论之争的共同前提)

## 3. 规范化:术语与对译(三栏之三)

- 国际语境下岩土术语高度标准化(欧洲规范 Eurocode 7
  体系/各国岩土规范;ISSMGE/ISRM/IAEG 术语),中英
  写作必须声明口径——特别是"承载力/特征值"这类
  制度性指标(对什么工况、什么失效准则)
- 度量:强度 kPa、重度 kN/m³、渗透系数 m/d(或 cm/s,
  底数单位必写)、沉降 mm、形变速率 mm/a、安全系数
  无量纲(但工况必注)

**术语对译表(中文优先,中英对照)**:

| 中文 | 英文 | 翻译陷阱 |
|------|------|---------|
| 工程地质学 | engineering geology | ≠geology(地学本体);=工程-地壳界面学科 |
| 岩土工程 | geotechnical engineering | 与工程地质学高度重叠但偏设计侧;欧洲体系常并称 geotechnics |
| 有效应力 | effective stress | σ'=σ−u;土力学第一原理(00 章故事框一) |
| 孔隙水压力 | pore water pressure | 正孔压降强度;负值(吸力)属非饱和土语境 |
| 安全系数 | factor of safety (FS/FoS) | 无量纲但工况必注;天然 FS≠饱和 FS |
| 承载力 | bearing capacity | 特征值/极限值/允许值三档,制度不同不可混 |
| 边坡稳定性 | slope stability | 极限平衡条分法族的总问题名 |
| 滑坡易发性 | landslide susceptibility | "容易滑"的程度;≠危险性(含触发)≠风险(含后果) |
| 滑坡危险性 | landslide hazard | 易发性×触发概率;中文常与"易发性"混用要分清 |
| 残余强度 | residual strength | 剪损后强度;与峰值之差是渐进破坏的机关(00 章反直觉②) |
| 原位试验 | in-situ test | 标贯 SPT/静探 CPT;≠室内试验(有扰动) |
| 岩体 | rock mass | ≠岩块(intact rock):岩体=岩块+结构面(瓦依昂的教训) |
| 结构面 | discontinuity / joint set | 层面/节理/断带统称;产状=倾向+倾角 |
| 围岩 | surrounding rock | 隧道语境的岩体;围岩分级≠岩石强度分级 |
| 时序干涉测量 | InSAR (interferometric SAR) | 毫米级形变普查;有几何盲区(01 章方向四) |
| 特征值 | characteristic value | 欧体系术语:谨慎估计的参数值;≠平均值 |
| 群测群防 | community-based monitoring | 中文制度语境;社区灾害监测网络(通说) |
| 观测法 | observational method | Peck 1969:预报-观测-修正闭环(00 章美之时刻②) |
| 易发性区划 | susceptibility mapping/zoning | ML 时代的主流工作流(01 章方向三) |

## 📌 收束

工程地质学的语言=**双层语件(地层语言+设计语言,
参数升格链缝合)+三重证据的证书学(钻探-物探-遥感
+试验+原型观测,E1-E5 阶梯)+术语与工况的规范化**。
它写下的每个参数都在等一行证据与一个工况。下一章把
地质问题压成数据结构:[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **阶梯眼**:听到"地下有××",先问证据级——遥感/
  物探/钻探/试验/原型观测哪级?覆盖范围多大?
- **身份眼**:一切岩土参数有统计身份——试验值还是
  特征值?几个样?什么工况?峰值还是残余?
- **多解眼**:物探剖面是"可能的世界"不是"地层本身";
  未经钻探验证的物探结论只配"推测"措辞
