# 04 · 工程地质学转代码——安全系数·地层插值·风险叠加的走廊

> **本章回答五问之 Q5(问题→代码转换)。**
> **本质一句话**:工程地质问题一旦变成"关于极限平衡
> 的安全系数计算、钻孔间参数的空间插值、风险图层的
> 链式叠加"的计算,就能进代码——FS 可扫描、孔压可
> 参数化、失效概率可蒙特卡洛、区划可叠图;**唯一不可
  外包给代码的,是地质概化的裁定**(地层怎么分层、
  滑面取在哪、参数用峰值还是残余——证据与判断归
  02 章阶梯)、**规范特征值的裁定**(取值制度是规范
  语境)与**风险接受的裁定**(阈值是社会决策)。

## 0. 开篇:一个边坡,代码自己说

「都说"水是滑坡的主犯",公式里住在哪里?FS=1.5 就
安全吗?」——`experiments/slope_stability_fs.py` 让代码
回答:无限边坡模型,干燥时 FS=tan(φ)/tan(β),扫描
φ 严格升、扫描 β 严格降,β=φ 处 FS 精确等于 1(自然
休止角的语言学);加入孔隙水压力项,FS 随饱和度**严格
线性**下坠,平行坡面渗流全饱和时 FS 几乎砍半(γ_w/γ
≈0.49)——**雨季滑坡的机制被参数化成一行减法**(00 章
故事框一:有效应力的最纯演出);再把 φ 当随机变量做
蒙特卡洛:A 场地确定性 FS=1.51、失效概率却约 8.5%,
B 场地 FS=1.31、失效概率不到 0.1%——**确定论与概率
两种安全画像给出相反的排序**(00 章方法论之争的定量
标本)。一条脚本把 00 章假设三与 02 章证据纪律全部
落成可复现的数。

## 1. 可机械化边界(三件套之一)

**能进代码的**(地质数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 边坡安全系数 | 极限平衡(无限边坡/条分迭代)+孔隙水压力参数化 |
| 可靠度 | 参数分布的蒙特卡洛/一阶二阶矩(FOSM)求 Pf 与 β |
| 地层插值与建模 | IDW/克里金/地质统计模拟(钻孔→三维体) |
| 渗流 | 稳定渗流有限元→孔压场(本实验用 ru 参数化其结果) |
| 风险区划 | 图层栅格叠加+链式相乘+分级规则 |
| 监测形态识别 | 位移时序分段(匀速/加速)与阈值告警 |
| 编目分析 | 滑坡清单的频率-体积统计、ROC/AUC 验证 |

**不能进代码的**(工程地质学的"不可判定域"):

1. **地质概化的裁定**——分几层、滑面走哪条、结构面
   是否控制:这是证据与判断(02 章阶梯);代码只对
   已声明的概化算,概化错了 FS 再精确也是错概化的
   精确答案(瓦依昂式的错不在算)
2. **规范特征值的裁定**——试验统计到设计值之间的
   折减制度属规范语境;把"样本均值"直接当"特征值"
   是跳步,不是保守
3. **风险接受的裁定**——FS≥1.5 还是 Pf≤5%、风险分级
   阈值:这是社会与制度决策;代码能算 Pf,不能替社会
   说"多大才算安全"
4. **失效时刻的预报**——加速段判据是经验统计;
   "哪一天滑"不是代码的可判定问题(00 章语言边界)

> 边界的一句话:**代码是概化的验算台与不确定性的
> 试验场,不是地质师。**

## 2. C1 无限边坡安全系数走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 模型 | FS=(c'+(γz·cos²β−u)·tanφ')/(γz·sinβ·cosβ) | 无限边坡:滑面平行坡面、深度 z、土层厚且均质(00 章假设一的教学版) |
| 干燥退化 | c'=0,u=0 ⇒ FS=tanφ/tanβ | 与全式逐位相等(实验断言①);β=φ 处 FS=1 |
| 孔压参数化 | u=ru·γz;饱和度 s 版 u=s·γ_w·z·cos²β | FS 对 ru/s 严格线性;全饱和≈减半(断言②) |
| 可靠度 | φ~N(μ,σ) 蒙特卡洛,解析 Φ 互证 | 教学版只让 φ 带不确定性;生产版 c、φ、水位联合分布同构扩展 |
| 断言风格 | 单调性/线性/范式差全部 assert | MC 涨落容差显式;固定种子可复现 |

成品=`experiments/slope_stability_fs.py`。**改强度换一行
参数,改水文换一个饱和度,改范式换一段统计**——03 章
schema 分离的好处:参数(来自地层模型)、工况(饱和度)、
方法(FS 或 Pf)分居三列,敏感性分析就是在列间扫描。

## 3. C2 地层插值走廊(钻孔→体)

工程问题:三个钻孔揭出同一层顶板标高,场地任一点的
层厚是多少?最小完整版本是**反距离加权(IDW)**:

```python
# 教学版 IDW:钻孔控制的空间插值(权随距离衰减)
def idw(points, values, x, y, power=2.0):
    # points=[(x,y)],values=[标高];同点保护用 eps
    num = sum(v / ((x-px)**2 + (y-py)**2 + 1e-9)**(power/2)
              for (px, py), v in zip(points, values))
    den = sum(1 / ((x-px)**2 + (y-py)**2 + 1e-9)**(power/2)
              for (px, py) in points)
    return num / den
# 断言风格:插值点过钻孔时恢复钻孔值;power→大 时趋最近邻;
# 克里金进一步给方差(插值+不确定度成套),本体见
# [数学宇宙·计算数学](../../讲透数学/讲透计算数学/)——
# 注意:插值给的是 E[标高],地质不连续(断距/尖灭)处
# IDW 平滑掉结构,概化裁定仍在人这边
```

要点:其一,**插值是概化的算术执行**,断层与尖灭要
作为"不连续面"先入模型再插值——连续函数拟不来地质
结构;其二,克里金比 IDW 多给**插值方差**(不确定度
成套交付,呼应 02 章统计身份);其三,插值结果的
证据级自动降为 E1(推断)——**钻孔间没有新证据,
只有新算术**。

## 4. C3 风险叠加走廊(图层栈)

风险区划的最小机械化是**链式相乘+分级**:

```python
# 教学版风险叠加:易发性×暴露×易损→风险分级(03 章 schema)
def risk_class(suscept, exposure, vuln, rule=None):
    risk = suscept * exposure * vuln        # 逐栅格链式相乘
    for bound, cls in (rule or [(0.6, "very_high"), (0.3, "high"),
                                (0.1, "moderate")]):
        if risk >= bound:
            return cls
    return "low"
# 断言风格:suscept 单独升高不改变"无暴露区=low"——
# 后果链的乘法结构保证:无人区没有风险,只有危险性;
# 分级阈值 rule 是决策约定,必须显式传参(不可硬编码)
```

要点:其一,**乘法结构是制度**(后果缺席则风险为零
——易发性图冒充风险图的第一破绽);其二,分级阈值
是**社会决策不是地质参数**,代码里必须显式传参留痕;
其三,ML 时代的易发性图层自带验证指标(AUC)与偏差
声明(01 章方向三),叠加时这些元数据要跟着图层走——
**没有元数据的栅格进不了风险台账**。

**走廊三警告**(共用):

1. 概化先于计算:滑面与分层错了,FS 的精度毫无意义
   (瓦依昂;不可判定域第一条)
2. 蒙特卡洛的统计涨落要声明:试验数×容差,Pf 的误差
   棒与结论一起交付;换种子结论漂移超容差=试验数不够
3. 工况不齐不收算:只有天然工况 FS 的报告是半张合同;
   饱和与地震工况缺席,审查不可复算(02 章规则三)

## 5. 工程师落点(把这门学科带回家)

- **安全系数的工况语法通吃一切系统设计**:任何"余量"
  断言都要问工况——容量规划的高峰/常态、结构设计的
  静载/动载、供应链的旺季/断供;**"FS=1.5"不注工况,
  在任何工程语境都是半句话**
- **可靠度思维→一切含参决策**:A/B 两场地的范式差
  (断言③)是通用课:两个项目都"达标题均值的 1.5 倍",
  一个波动 5%、一个波动 20%,风险排序完全不同——
  变异性不进语言,排序就是赌(与
  [工程物理学](../讲透工程物理学/04-工程物理学转代码.md)
  的误差预算三段式对表:同宗的账本纪律)
- **插值+方差→估值工程的通用件**:任何稀疏采样→
  连续场的问题(传感器布局/灰度发布覆盖/A/B 测试
  外推)都是 IDW/克里金的同构题:插值给中心估计,
  方差给置信,两者成套交付
- **观测法→灰度发布与可回滚设计**:预报-观测-修正
  (00 章美之时刻②)就是今天的灰度发布+监控告警+
  回滚预案;岩土工程师 1969 年的离经叛道,已是软件
  工程的常规操作——**设计书是可修订的假设**

**🧠 认知升维**:

- **工况眼**:安全系数没有单值身份——任何余量断言
  先问"哪个工况下的"
- **概率眼**:同一 FS 可以装着完全不同的失效概率;
  参数变异性进语言,安全画像才完整
- **概化眼**:计算之前先审概化——分层、滑面、边界
  条件错了,后面的精度都是装饰
