# 讲透工程水文学 · 地基层:河流与工程的对话(GB/T 41035)

> **工程水文学=把流域的水循环翻译成工程设计数字的学科**:
> 上部工程要的是定量的设计输入(设计洪峰 m³/s/设计
> 洪量/校核洪水),下部河流给的是有限年份的实测记录
> 与一场场不可重复的暴雨;这门学科的全部工作,就是把
> **不可重复的水文过程压缩成可设计的数字**——从
> Mulvaney 1851 推理公式第一式,到谢尔曼 1932 单位线把
> 流域当卷积器,再到 Gumbel 把"最大值"变成分布、
> "百年一遇"成为工程语言,直到今天 AI 混合模型把洪水
> 预报精度抬升数倍。一句钉住:**河流不回答问题,只留下
> 记录;工程水文学的工作,是从有限的记录里赌对未来一遇**。

> GB/T 该二级注「参见 17055」,**无三级明细→本家族自定
> 主干支**)。互链声明(宇宙 README §二):**水文学本体在
> 地球科学宇宙(GB/T 170,待建)**——降水物理、径流形成
> 机制、河流动力学归它;**本家族=工程侧落点**——不重述
