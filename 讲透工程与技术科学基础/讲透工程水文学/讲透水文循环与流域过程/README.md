## ✨ 这支最美的一个事实

**流域是一台卷积器(家族 00 章故事框一)**。1932 年谢尔曼
发现:任取一场雨,出口过程线都像同一条"指纹"的加权
错时段叠加——流域把时间上乱的雨,整理成时间上有序的
流。一场单位线标定,买下任何雨型的可算性(家族 04 章
走廊 C2 的卷积就是它的算术执行)。它的美在于**乘法结构
换来了泛化**:工程水文学从此不必为每场雨单独建模,
只要问流域要一次指纹——这条思路后来在信号与系统里
重演,而工程界先用了二十年。
