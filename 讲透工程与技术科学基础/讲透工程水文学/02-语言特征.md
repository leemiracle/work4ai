# 02 · 语言特征——重现期语言、设计语言与水文证据

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:工程水文学说的是**一种双层语言**——
> 随机语言(重现期/频率曲线/超标概率,把小概率翻译成
> 可谈判的标准)与设计语言(设计洪峰 m³/s/单位线/汇流
> 时间,把标准落成工程输入),两层之间靠**序列升格链**
> (原始记录→年最大序列→插补还原序列→频率曲线→设计
> 值→设计过程线)缝合;判断一段水文写作的优劣,不看
> 文采,看**每个数字背后站着哪级证据**(站网实测/历史
> 调查/单位线反推/模型模拟/遥感反演)。三栏分别回答:
> 这套语言能说什么(表达力)、水文断言凭什么可信(逻辑
> 性质)、术语如何被标准化(规范化)。

---

## 0. 开篇:同一场洪水的三种文本

📖 **故事框:一场洪水的三份记录**。年鉴的文本:水文年鉴
里的一行——"7 月 14 日 20 时,洪峰流量 4200 m³/s,
相应水位 88.42 m"——**写的是河流给的东西**,一个瞬时
峰值,没有成因,没有概率身份。设计计算书的文本:频率
计算成果表——"经 P-III 型/Gumbel 曲线适线,洪峰均值
2100 m³/s,Cv=0.52,x₁%=5300 m³/s(百年一遇)"——
**写的是工程要的东西**,一场洪水被压缩成曲线上的一个
刻度,但"百年一遇"四个字带上了全部统计身份。预报值班
的文本:"预计 15 日 02 时洪峰到达本站,量级 3900-4400
m³/s,置信区间含历史第二大洪水"——**写的是调度要的
东西**,峰值变成了带时刻与区间的预告。三种文本说的是
同一场水:**年鉴文本丢概率买真实,计算书文本丢真实买
标准,预报文本丢确定买提前量**。工程师的语言工作,就
是在三种文本之间**带着证据翻译**(升格与降格都留痕)。

## 1. 表达力:工程水文语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 小概率的可读性 | **重现期语言** | "T 年一遇"=年超标概率 1/T 的速记;寿命内遭遇概率 1−(1−1/T)^L 才是工程买到的保险(00 章反直觉①) |
| 标准的可谈判性 | **设计语言** | 设计洪峰/设计洪量/校核洪水,按工程等级与失事后果分级(规范语境) |
| 流域的可描述性 | **流域特征语言** | 集水面积 km²/河长/比降/形状系数/下垫面类型——产汇流的静态档案 |
| 过程的可计算性 | **单位线语言** | 单位净雨→出口过程线;雨型=净雨的时段柱状图,响应=加权错时段叠加(00 章故事框一) |
| 传播的可推演性 | **演算语言** | 马斯京根 K、x 参数:洪水波从上游断面推到下游断面的时间与坦化 |
| 未来的可预告性 | **预报语言** | 预见期/洪峰时刻/量级区间/置信度(01 章 AI 混合的主场) |

**不能说的**(表达力边界,与生俱来):

- **没观测到的尾巴**:序列之外的量级全靠外推;百年
  设计值住在均值上方 4.6σ 处,资料多短,赌注多大(00 章
  反直觉②)
- **确切的到访时刻**:重现期是频率不是周期,"百年一遇
  明年不来"与"连续两年来"都不违反它(00 章假设三)
- **变化后的未来**:城市化、水库调节、气候趋势都在
  改写序列;语言里没有自动的"曲线保鲜期"语法(00 章
  反直觉③)
- **大洪水的非线性**:单位线按线性叠加外推到漫滩量级,
  "形"的误差不进语言,只能靠声明(00 章假设二)

## 2. 逻辑性质:水文证据的五级阶梯(三栏之二)

水文断言的可信度来自**证据的层级与互证**,不是曲线的
美观:

| 证据 | 是什么 | 特权与陷阱 |
|------|--------|-----------|
| 站网实测 | 雨量/水位/流量站的仪器记录 | 特权:**一切频率分析的唯一直接证据**;陷阱:点代表面(雨量站对暴雨中心的采样误差)、大水时测验失准甚至缺测 |
| 历史洪水调查 | 洪痕高程/文献/碑刻/访问 | 特权:把序列在时间上前延,救短样本(00 章反直觉②的解药);陷阱:量级与年份考证带不确定度,须降精度入册 |
| 单位线反推 | 从实测雨洪对反演流域响应 | 特权:流域指纹,可移置可叠加;陷阱:反演的适定性差——雨误差与响应误差纠缠,同场洪水可解出多族单位线 |
| 模型模拟 | 概念性模型/数值模型/AI 混合输出 | 特权:填时空空白,无资料区可算;陷阱:模型是概化不是观测,输出值只对输入与结构负责 |
| 遥感反演 | 卫星降水/雷达测雨/水面高度 | 特权:面覆盖、全球可及(01 章方向四);陷阱:反演偏差系统性存在,须以站网为锚订正 |

### 2.5 断言强度阶梯(工程水文版 E1-E5)

| 阶梯 | 措辞 | 证据状态 | 水文特有注意 |
|------|------|---------|-------------|
| E1 站网实测级 | "本站 1950-2020 年最大洪峰 4200 m³/s" | 点直接 | 大水缺测年要声明;"有记录以来最大"≠历史最大 |
| E2 历史调查级 | "据洪痕考证,1849 年洪水约 5000 m³/s" | 时延直接 | 量级带考证不确定度,入册须降精度、附依据 |
| E3 反演级 | "由 7 场雨洪对反得单位线,汇流约 12 h" | 参数间接 | 雨量误差全进单位线;多场分歧要显式(中值/外包) |
| E4 模拟级 | "模型率定期 NSE=0.87,验证期 0.81" | 概化直接 | 对输入与结构负责;外推量级不背书 |
| E5 遥感级 | "卫星降水显示流域面雨量约 180 mm" | 面间接 | 须站网订正;无锚区的系统偏差要声明 |

**误用告示**:把 E3(单位线反推)当 E1(实测)写,是把
反演的适定性问题藏进参数;把 E4(模型输出)当证据引用
却不给率定/验证分期,是水文写作的头号跳步;拿 E5(卫星
产品)直接做设计暴雨而不做站网订正——偏差会顺着频率
曲线放大到设计值里。

### 2.6 三个内部语法规则

- **序列身份规则**:任何频率结论必附序列身份——年限/
  起讫/缺测处理/历史洪水插补/人类活动还原(水库调节、
  城市化的还原处理);"x₁%=5300"后面不写这些,读者无法
  复算(00 章假设一的制度化防线)
- **曲线身份规则**:分布线型(Gumbel/P-III 等)、参数
  估计法(矩法/适线法/极大似然)、适线统计与检验必须
  成套出现;换线型不换结论要说明,换线型换结论更要
  说明(方法论之争的作业面)
- **概率身份规则**:一切"设计值"必附重现期与用途
  (设计/校核),一切"预报值"必附预见期与区间;
  设计值与预报值混写(拿校核洪水当预报上限)是范畴
  错误

## 3. 规范化:术语与对译(三栏之三)

- 国际语境下水文术语高度标准化(WMO 术语体系/各国设计
  洪水规范);中英写作必须声明口径——特别是"重现期/
  设计标准"这类制度性指标(对什么断面、什么工程等级、
  什么失事后果分级)
- 度量:流量 m³/s、雨量 mm、面雨量 mm(附面平均法)、
  集水面积 km²、汇流时间 h、重现期 a(年)无量纲概率
  倒数;洪量常用 亿 m³ 或 (m³/s)·h——单位制度必一致

**术语对译表(水文口语→工程书面语,中英对照)**:

| 中文(工程书面语) | 英文 | 口语→书面的翻译陷阱 |
|------|------|---------|
| 重现期 | return period | "百年一遇"≠"百年一次";必译回年概率 1/T(00 章反直觉①) |
| 年最大序列 | annual maximum series (AMS) | "每年的最大洪水"→严格取样规程;与"年超大值法"有别 |
| 设计洪水 | design flood | ≠预报洪水:一个是标准(概率身份),一个是预告(时间身份) |
| 校核洪水 | check flood / PMF 语境 | 高坝校核标准的语言;与设计洪水分级不同,不可混写 |
| 频率曲线 | frequency curve | 线型+参数法+检验三件套才算"有身份" |
| 适线 | curve fitting | 矩法定参数≠目估适线;方法不同结果不同,必声明 |
| 集水面积 | catchment/drainage area | "流域多大"→km² 且附分水岭依据 |
| 净雨 | excess rainfall | 雨扣损失(入渗/填洼)后才进单位线;"这场雨"≠净雨 |
| 单位线 | unit hydrograph | 流域的脉冲响应;"单位"=单位时段×单位净雨深,两个约定缺一不可 |
| 汇流时间 | time of concentration | 最远一点的水到出口的时间;与"涨洪历时"是两个概念 |
| 河道演算 | flood routing | 马斯京根是"法"不是"模型全部";参数 K、x 有物理身份 |
| 可能最大降水 | PMP (probable maximum precipitation) | 无概率身份的上限估计;不可译作"百年一遇的雨" |
| 可能最大洪水 | PMF (probable maximum flood) | PMP 演算的洪水;校核语境专用 |
| 径流系数 | runoff coefficient | 强依赖雨强与下垫面;"系数 0.7"不附条件等于没说 |
| 产流 | runoff generation | 雨变净雨的环节;与"汇流"(净雨变流量)分账不分家 |
| 面雨量 | areal rainfall | 点雨量→面雨量要插值(泰森多边形/等值线);方法必声明 |
| 预见期 | lead time | 预报的合同期限;精度必附预见期,预见期必附精度 |
| 还原处理 | naturalization / restoration | 把水库调节等人类活动影响"还原"成天然序列;中国规范语境常用 |

## 📌 收束

工程水文学的语言=**双层语件(重现期语言+设计语言,
序列升格链缝合)+水文证据的五级阶梯(站网实测-历史
调查-反演-模拟-遥感)+序列/曲线/概率三身份规则**。
它写下的每个数字都在等一行证据与一个身份。下一章把
水文问题压成数据结构:[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **身份眼**:一切水文数字有身份——序列身份(年限/插补/
  还原)、曲线身份(线型/参数法/检验)、概率身份(重现期/
  预见期);三个身份不齐,数字不可复算
- **阶梯眼**:听到"某年洪水多大",先问证据级——实测、
  考证、反演、模拟还是遥感?量级的精度上限由证据级决定
- **翻译眼**:口语的"百年一遇"到书面语必经两次翻译——
  译回年概率 1/T,再乘设计寿命算遭遇概率;不翻译直接
  引用,是把统计速记当成自然规律
