## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 重现期 | 年超标概率 1/T 的速记;50 年寿命遭遇 T=100 的概率≈39.5%(断言①) |
| 年最大法 | 每年抽一个最大值:取样规程本身就是方法的一部分 |
| Gumbel 矩法 | σ=s·√6/π,μ=x̄−0.5772σ;x₁₀₀ 住在均值上方 4.6σ 处 |
| 短样本陷阱 | n 小→σ̂ 系统性偏小→x_T 方向性低估+离散度大(断言②) |
| PMP-PMF | 物理上限路线:无概率身份,高危工程校核专用 |
| 非平稳 | 趋势下稳态 x₁₀₀ 的真实超标概率翻倍以上(断言③) |

## ✨ 这支最美的一个事实

**设计值住在尾巴上,而尾巴由序列长度决定(家族实验
断言②)**。同一个"真值"总体,15 年资料与 60 年资料估出
的 x₁₀₀ 不是精度之差,是**方向之差**——矩法的 σ̂ 向下
有偏,设计值又住在均值上方 4.6σ 处,σ 低估一分,x₁₀₀
低估 4.6 分。这就是历史洪水调查值钱的原因:1849 年的
一道洪痕,是二十世纪中叶一次分布参数的修正。**频率
分析的第一投资不是更精的曲线,是更长的序列**——学科
史上"资料比公式更要紧"的通说,在这支有定量的家。
