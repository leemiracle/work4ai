# 04 · 工程水文学转代码——设计值·卷积汇流·河道演算的走廊

> **本章回答五问之 Q5(问题→代码转换)。**

> 的裁定**(趋势该不该进曲线——气候判断与社会决策)。

## 0. 开篇:一个设计值,代码自己说

「都说"百年一遇不等于百年一次",差多少?只有几十年
资料,设计值敢信几成?」——`experiments/design_flood_gumbel.py`
让代码回答:先算遭遇概率,T=100 的洪水在 50 年设计寿命内
至少来一次的概率 1−(1−1/100)^50≈**39.5%**(工程真正
买的保险);再用 Gumbel 矩法(σ=s·√6/π,μ=x̄−0.5772σ)
对同一总体反复抽样:n=15 的 x₁₀₀ 估计比 n=60 **离散度大
大约两倍(实测约 1.9 倍)且均值系统性偏低**(矩法 σ̂ 偏小,而设计值住在均值
上方 4.6σ 处——σ 低估一分,x₁₀₀ 低估 4.6 分);最后给
序列装上气候趋势项,前半段稳态拟合的 x₁₀₀ 在序列末端的
真实年超标概率**翻倍以上**——稳态假设的保质期被量化。
一条脚本把 00 章假设一与 02 章身份纪律全部落成可复现
的数。

## 1. 可机械化边界(三件套之一)

**能进代码的**(水文数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 重现期换算 | 遭遇概率 1−(1−1/T)^L;T 与年概率互译 |
| 设计值 | Gumbel/P-III 参数估计(矩法/极大似然)→x_T=μ+y_T·σ |
| 抽样误差 | 重抽样蒙特卡洛→设计值的抽样分布与区间 |
| 非平稳检验 | 趋势检验+分段频率;时变参数拟合 |
| 产流扣损 | 初损-稳渗/SCS 类扣损,雨→净雨 |
| 汇流 | 单位线卷积叠加(净雨过程→出口流量) |
| 河道演算 | 马斯京根槽蓄法逐时段推进 |
| 预报评价 | 精度/可靠性/经济价值三栏(01 章方向一协议) |

**不能进代码的**(工程水文学的"不可判定域"):

1. **序列身份的裁定**——插补合不合法、还原做到什么
   程度、历史调查量级取上包还是中值:这是证据与考证
   (02 章阶梯);代码只对已声明的序列算,序列错了
   x₁₀₀ 再精确也是错序列的精确答案
2. **标准分级的裁定**——设计/校核、频率/PMF、工程
   等级对应的重现期:这是规范与制度语境;代码能算
   任何 T 的 x_T,不能替规范说"该用哪个 T"
3. **非平稳的裁定**——趋势要不要进曲线、进多少年:
   气候归因与社会决策;代码能检验趋势、能算非平稳
   设计值,不能替决策者选"保守还是更新"
4. **单位线外推的裁定**——线性叠加推到多大洪水还敢
   用:概化的边界;代码照卷不误,**敢不敢用是判断**

> 边界的一句话:**代码是序列的验算台与尾巴的试验场,
> 不是水文工程师。**

## 3. C2 单位线卷积走廊(净雨→出口过程)

工程问题:设计暴雨扣损成净雨过程,出口断面的设计洪水
过程线长什么样?最小完整版本是**谢尔曼卷积**:

```python
# 教学版单位线卷积:Q(t) = Σ I(k)·u(t−k)·A/Δt 缩放(04 章走廊 C2)
def uh_convolve(excess_mm, uh_q, dt_h, area_km2):
    # excess_mm=各时段净雨深;uh_q=单位线流量(m³/s,单位净雨);
    # 流域面积把 mm·km² 换成 m³:1 mm·km² = 1000 m³
    n = len(excess_mm) + len(uh_q) - 1
    out = [0.0] * n
    for k, depth in enumerate(excess_mm):
        for j, u in enumerate(uh_q):
            out[k + j] += depth * u      # 叠加原理:加权错时段
    return out                            # 断言:总径流深守恒
# ΣQ·Δt = Σexcess·A·1000(m³):水量平衡是卷积的第一断言;
# 单位线时移不变是第二断言(净雨错一时段,过程线整体错一时段);
# 大洪水外推比(设计净雨/单位线率定净雨)要显式——线性
# 假设在漫滩量级破功(00 章假设二),代码照卷,敢不敢用是人
```

要点:其一,**卷积是叠加原理的算术执行**——一条单位线
买下任何雨型的可算性(00 章美之时刻①);其二,水量平衡
(净雨总量=径流总量)是第一道断言,卷积错了水就凭空
生灭;其三,单位线反演的适定性差(02 章阶梯 E3),正算
干净、反算带病——多场分歧显式入档。数值求积与卷积的
算法本体见[数学宇宙·计算数学](../../讲透数学/讲透计算数学/README.md)。

## 4. C3 马斯京根演算走廊(洪水波推下游)

工程问题:上游断面的洪水过程,推到几十公里外的下游
断面——峰什么时候到、削多少?最小完整版本是**马斯京根
槽蓄演算**:

```python
# 教学版马斯京根:S=K·[x·I+(1−x)·O],联立水量平衡逐时段推进
def muskingum(inflow, k_h, x, dt_h):
    c0 = (dt - 2*k*x) / (2*k*(1-x) + dt)     # 三个系数
    c1 = (dt + 2*k*x) / (2*k*(1-x) + dt)     # 由 S=K[xI+(1−x)O]
    c2 = (2*k*(1-x) - dt) / (2*k*(1-x) + dt) # 与 ΔS=I−O 联立
    out = [inflow[0]]
    for t in range(1, len(inflow)):
        o = c0*inflow[t] + c1*inflow[t-1] + c2*out[t-1]
        out.append(max(o, 0.0))              # 数值稳定保护
    return out
# 断言风格:c0+c1+c2=1(水量守恒的系数表达);k=传播时间
# (峰现时滞≈k);x→0 坦化最强,x→0.5 接近纯平移;
# Δt 与 k 不匹配(如 dt>2k(1−x))系数变负→数值震荡,
# 稳定域要显式声明——参数率定用上下游实测对(00 章翻译链
# "怎么到下游"一环)
```

要点:其一,**槽蓄方程是水量平衡的储罐化**——河段被
概化成一个带权蓄水池,x 是入流-出流对蓄量的权重;其二,
参数 K(传播时间)与 x(坦化权重)有物理身份,用实测
洪水的入出流对率定;其三,数值稳定域(Δt 与 K 的配比)
必须显式——系数变负时输出震荡,是教学版与生产版的
分界线。明渠水力学的动力波本体见
[工程力学](../讲透工程力学/README.md)流体侧,数值推进
算法见[计算数学](../../讲透数学/讲透计算数学/README.md)。

**走廊三警告**(共用):

1. 序列先于计算:序列身份不清(缺测/未还原/插补不合法),
   设计值精度毫无意义(不可判定域第一条)
2. 蒙特卡洛的统计涨落要声明:试验数×容差,区间与结论
   一起交付;换种子结论漂移超容差=试验数不够
3. 外推幅度要落款:单位线外推比、频率曲线外推年份、
   AI 预报超出训练量级的部分——**代码照算不误,结论
   要带外推声明**(00 章假设二的制度化)

## 5. 工程师落点(把这门学科带回家)

- **重现期语言通吃一切风险标准**:容量规划的"5 个 9"、
  结构设计的"五十年荷载"、供应链的"百年断供"都是
  T 年一遇的同构语——先译回年概率,再乘寿命算遭遇,
  **"T 年一遇"不注寿命与后果,在任何工程语境都是半
  句话**(家族实验断言①)
- **短样本思维→一切数据稀缺决策**:用 15 个数据点估
  "百年一遇"的失真(断言②),与用 3 个 A/B 测试估
  千分之一转化率、用一个季度数据估十年一遇流量峰值
  是同一道题:**尾巴不在样本里,估计就会系统性乐观**
  ——置信区间与点估计成套交付,是所有"用过去赌未来"
  行业的公共纪律
- **卷积思维→系统响应的通用件**:任何"输入流→缓冲
  →输出流"的系统(订单→产线→交付、雨→河网→出口)
  都可用脉冲响应刻画——标定一次,推演一切输入;
  **水量(物料)平衡是卷积的第一断言**,通吃离散事件
  仿真
- **稳态审计→一切"历史基准"的保鲜期**:SLO 的历史
  分位数、风控的历史 VaR、设计洪水的 x₁₀₀,都押在
  "过去代表未来"上;趋势与变点让基准漂移(断言③)
  ——**重要的基准要带出厂日期与复核周期**

  来,基准就带保质期——重要的基准要定期复检
