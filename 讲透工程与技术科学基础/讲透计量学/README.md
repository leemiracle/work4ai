> **计量学=让测量可信**:一切测量都是拿未知与已知比较,
> 计量学一生只做三件事——把「已知」**造出来**(单位与基准)、
> **传下去**(量值传递与溯源)、**算清账**(测量不确定度)。

> 从巴黎的地下室换成了宇宙常数——误差没有消失,只是
> 搬进了每一台实现单位的装置里。
