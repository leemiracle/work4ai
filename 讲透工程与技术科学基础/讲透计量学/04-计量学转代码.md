# 04 · 计量学转代码——合成律·量纲代数·溯源链机读的走廊

> **本章回答五问之 Q5(问题→代码转换)。**
> **本质一句话**:计量学问题一旦变成「不确定度的合成
> 与区间计算、量纲指数的向量代数、校准链的图遍历」,
> 就能进代码——预算可复算、主导分量可排序、小样本
> 区间可自动乘 t、方程齐次性可机检、链上断链与过期
> 证书可报警;**唯一不可外包给代码的,是被测量的定义**
> (定义是领域知识决策)、**B 类分布假设的选择**(建模
> 判断)与**比对分歧的物理归因**(实验室的活)。

## 0. 开篇:一本账,代码自己算

「两个不确定度怎么合?测五次报 95% 区间该乘几?我的
表离国家基准三级的账是多少?」——
`experiments/uncertainty_propagation.py` 让代码回答:
合成律 u_c=√(u₁²+u₂²):10%⊕1%=**10.0499%≈10.05%**,
1% 分量被主导分量平方后吞没(砍掉它 u_c 只降 0.499%),
等权两分量=单分量×√2(律1);A 类标准误按 1/√n 收敛
(n=4→16 恰减半),但小样本 95% 区间须乘 t 因子:n=5
时 t₀.₉₇₅(4)=2.776(闭式 CDF 反解互证 2.7764),比
正态 1.96 宽 41.6%≈42%,硬套 1.96 名义 95% 实际覆盖
仅 87.8%(律2);传递链 u_{i+1}=√((r·u_i)²+w²):r=1/1.2/1.5
三链逐级严格增大,末端 5.477→6.344→8.240,几何平均
放大率 1.76→1.85→2.02——传递比越大末端越快失控,且
链长本身有代价(r=1 直连省 24.7%)(律3)。一条脚本
把 00 章反直觉①②④与 02 章账本规则全部落成可复现的数。

## 1. 可机械化边界(三件套之一)

**能进代码的**(测量数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 不确定度合成 | 方和根+相关交叉项;灵敏系数 cᵢ=∂f/∂xᵢ(数值微分) |
| 区间计算 | Welch-Satterthwaite 有效自由度→k=t(ν) 或 2;包含区间 |
| 分布传播 | 蒙特卡洛(GUM S1 路线):抽样输入分布→直方图输出区间 |
| 量纲校验 | 量纲指数向量代数:方程两边指数相等断言;单位换算表 |
| 无量纲群生成 | Buckingham π:量纲矩阵零空间解出无量纲组合 |
| 预算表审计 | 科目对测量方程对表(全源规则)+主导分量排序 |
| 证书管理 | date/due 时效检查;示值-参考值插值(校准曲线) |
| 溯源链审计 | 图遍历:环/断链检测;末端 u 全链复算;传递比阈值 |

**不能进代码的**(计量学的「不可判定域」):

1. **被测量怎么定义**——「纯度」以什么取样、「延迟」
   以什么分位数定义,是领域决策;代码能检查定义写没
   写全,不能替你写
2. **B 类分布假设的选择**——证书信息只给「±0.3,置信
   约 95%」,换算成标准不确定度要选正态还是均匀;
   选哪个是建模判断,代码只能列出候选与后果
3. **比对分歧的物理归因**——两家实验室差了 2σ,是链上
   哪一级的系统性问题?归因要懂装置物理(01 章方向一
   的未决问题)
4. **「差 0.5% 算不算合格」的裁定**——MPE 边缘情形的
   判定规则(保护带怎么设)是管理与法律决定,代码只
   执行已裁定的规则

> 边界的一句话:**代码是账本的验算台与链路的巡检员,
> 不是测量定义者。**

## 2. C1 不确定度传播与预算走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 合成 | u_c=√(Σ(cᵢuᵢ)²+2Σrᵢⱼcᵢcⱼuᵢuⱼ) | 相关项默认零=隐含假设;同源分量必标 r(02 章规则三) |
| 主导分量 | 按 (cᵢuᵢ)²/u_c² 排序 | 砍头名一半>消灭全部小分量(律1 的治理面板) |
| A 类 | u=s/√n(贝塞尔 s,ν=n−1) | √n 收敛:n 扩 4 倍才减半——平均的边际收益递减 |
| 小样本区间 | k=t₀.₉₇₅(ν)(查表:ν=4→2.776,9→2.262,29→2.045) | 硬套 1.96 的「95%」小样本实际 ~87.8%(律2) |
| 链传播 | u_{i+1}=√((r·u_i)²+w²) | r≥1、w>0 ⇒ 逐级严格增;末端=链拓扑的函数(律3) |

成品=`experiments/uncertainty_propagation.py`。**改预算
换一行分量表,改样本量换一个 n,改链换一组 (r,w)**——
03 章 schema 分离的好处:分量、区间、链三居三列,
敏感性分析就是在列间扫描。

## 3. C2 量纲代数机读走廊(把「对不对」变成向量等式)

单位制与量纲(支一)的核心工程:量纲齐次性检查,本质
是**把每个量写成 7 维指数向量,方程校验变成向量加法**:

```python
# 教学版:量纲指数向量 + 齐次性断言(02 章开篇事故的机检版)
DIMS = {  # 基本量纲:长度 质量 时间 电流 温度 物质的量 发光强度
    "m": [1,0,0,0,0,0,0], "kg": [0,1,0,0,0,0,0],
    "s": [0,0,1,0,0,0,0], "A": [0,0,0,1,0,0,0],
    "K": [0,0,0,0,1,0,0], "mol": [0,0,0,0,0,1,0],
    "cd": [0,0,0,0,0,0,1],
}
def dim_pow(d, p): return [e * p for e in d]
def dim_mul(a, b): return [x + y for x, y in zip(a, b)]
def dim_div(a, b): return [x - y for x, y in zip(a, b)]
# 断言风格:F=m·a 的两边:
#   dim("N") == dim_mul(DIMS["kg"], dim_div(DIMS["m"], dim_pow(DIMS["s"], 2)))
#   → [1,1,-2,0,0,0,0] == [1,1,-2,0,0,0,0] ✓
# 不等即式子必错,不用代入数值——物理定律的免费类型检查器。
# 进阶:Buckingham π——把全部量的指数向量排成矩阵,
# 零空间的基向量=独立无量纲群(相似设计与模型缩尺的地基)。
```

要点:其一,**量纲向量空间是自由阿贝尔群**,检查是
精确的代数运算,不涉及浮点误差——「免费类型检查器」
名副其实;其二,**单位换算是向量空间的基变换**
(磅秒→牛顿秒差一个标量系数),「单位不匹配」事故在
schema 层就应被断言拦下;其三,Buckingham π 的零空间
计算(高斯消元即可)把「找无量纲数」变成线性代数——
雷诺数、马赫数这些经典无量纲群全是该机器的输出。

## 4. C3 校准证书与溯源链机读走廊(把链变成图程序)

「数字化证书」的最小机械化是**把 03 章 schema 接上
校验器**:

```python
# 教学版:溯源链审计三断言(03 章骨架三的运行时)
def audit_chain(graph, today):
    # 1) 时效:每条边的证书 date ≤ today ≤ due,过期即断链
    assert all(edge.date <= today <= edge.due for edge in graph.edges)
    # 2) 拓扑:链是 DAG(无环)且从 primary 到 field 无断链
    #    (DFS/BFS 从基准出发可达所有现场级节点)
    # 3) 账目:末端 u 全链复算
    #    u_field = sqrt((r·u_prev)^2 + w^2) 逐边递推(律3),
    #    与证书标称值对表,偏差超阈值报警
    ...
# 断言风格:过期证书、环、断链、复算不符——四类事故
# 全部机检;TUR 判定(标准器 u ≤ 被检 u 的 1/4 或 1/10)
# 是每条边的入场检查(律1 的淹没效应当门槛用)。
```

要点:其一,**链是图程序**:节点携带 u,边携带 (r, w,
date, due),末端不确定度是图的折叠求值——「链怎么排」
从行政问题变成可计算的设计问题(01 章方向四);其二,
**TUR 入场检查**是律1 的制度化:标准器分量小于被检
1/10 时对合成影响不足 0.5%,检定规程的「可忽略线」
由淹没效应背书;其三,数字化证书的互认依赖「账可机读」
与「账是真的」两层——后者仍靠比对与建制(00 章美之
时刻①的制度逻辑在数字时代重演)。

**走廊三警告**(共用):

1. 分布不显式不收算:B 类科目没有分布假设,合成不可
   复审(03 章预算表)
2. 相关不登记不合成:同源分量的 r 必须成对入表,
   默认独立=系统性低估(02 章规则三)
3. 裁定不外包:边缘合格、定义补全、归因分析,代码
   给证据,人给结论(不可判定域四条)

## 5. 工程师落点(把这门学科带回家)

- **账本眼→一切报数**:性能报告写「12 340 ± 180
  (k=2)」而不是「约 12 300」;run-to-run 波动就是 A 类
  评定的现场——跑 n 次取均值与区间,先过 t 因子账
  (律2)再定 n;**没有区间的基准数字是裸数**
- **主导分量→优化预算**:延迟优化/误差预算/噪声治理,
  先列科目找头名——砍头名一半,胜过把十个尾部科目
  清零(律1 的治理面);「不知道谁是主导」比「主导
  太大」更糟
- **齐次眼→一切公式**:推导与代码里的任何物理公式,
  单位当成类型系统用(04 章 C2):一次量纲断言,胜过
  十次数值试错;混用单位制的事故在 CI 里就该被拦下
- **链眼→工具链校准**:你的测量工具(示波器/温度计/
  压力传感器/云监控的时钟)每件都有溯源等级与证书
  时效——**精度可信度是维护出来的,不是采购出来的**;
  关键判决前查一眼 due(03 章时效眼)
- **淹没眼→标准器选型**:给被检设备配标准器,按 1/10
  (严格)或 1/4(工程)线配——反着配=白测;这条线
  的算术出身就是 10%⊕1%=10.05%(律1)

## 📌 收束

走廊三条:C1 不确定度传播与预算管「准到多少的账怎么
算、区间怎么诚实」,C2 量纲代数管「式子对不对的免费
类型检查」,C3 溯源链机读管「链怎么审计、怎么排最优」;
三条共用一条边界——**定义、假设、归因、裁定永远留在
人与实验室那边**。跑到这里回头再看 00 章那句话:常数
给了单位零误差,把全部不确定性赶进了实现、评定与传递
三关;代码算的是三关上的账,不是关本身。

**🧠 认知升维**:

- **区间眼**:数字的真身是「值±账」——见到裸数先补账,
  见到区间先验 k
- **类型眼**:单位是物理量的类型系统——量纲断言是
  编译期检查,数值代入是运行期验证,前者免费
- **折叠眼**:链的末端是整条链的折叠求值——问一个数
  的可信度,先问它的溯源图长什么样
