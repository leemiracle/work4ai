## ✨ 这支最美的一个事实

**链是花钱买方便,每级都收税**(家族实验律3)。传递律
u_{i+1}=√((r·u_i)²+w²) 把「高等级实验室为什么必须少而精」
写成算术:理想无损传递(r=1)时,中间级自身分量照样按
平方和进末级方差——基准(1)→参考(2)→工作(3)→现场(4)
末端 √30≈5.48,直连只要 √17≈4.12,链本身多付 24.7%;
r 越大末端越快失控(1→1.2→1.5:末端 5.48→6.34→8.24)。
