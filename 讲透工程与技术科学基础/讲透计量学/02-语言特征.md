# 02 · 语言特征——不确定度的语法:计量语言与它的术语纪律

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:计量学说的是**一种给数字配账本的语言**
> ——量值语言把「测的是什么」钉死(被测量/示值/修正),
> SI 语言把「拿什么量」钉死(单位/词头/量纲),不确定度
> 语言把「准到多少」钉死(A/B 类/合成/包含因子),溯源
> 语言把「跟谁比、经谁手」钉死(基准/校准/传递链);
> 判断一段测量表述的优劣,不看形容词多华丽,看**每个
> 数字后面站着哪个分量、哪种评定、哪级标准**。三栏分别
> 回答:这套语言能说什么(表达力)、账本凭什么可信
> (逻辑性质)、术语如何被钉死(规范化)。

---

## 0. 开篇:两个数字,一场事故(教学例)

📖 **故事框(教学例,按公开调查报告通说)**。1999 年,
NASA 的火星气候探测器在入轨阶段坠毁:事故调查给出的
技术原因是**单位不匹配**——一段软件输出的推进器冲量
以英制磅秒(lbf·s)计,另一段按公制牛顿秒(N·s)解读,
同一根管道里两个「数字」各自正确,合在一起差了 4.45
倍(换算系数,通说)。价值数亿美元的探测器,输给了
一个没写的单位后缀。这个故事的教学点有三:其一,
**数值不是量,数值×单位才是量**——丢掉单位的数字
是不可运算的;其二,量纲齐次性(支一)不是书生气,
是方程的**类型检查器**:磅秒与牛顿秒的量纲虽然同为
「质量×长度/时间」,但单位制混用破坏的是「同一SI」
这个前置约定;其三,计量语言的全部要义浓缩于此:
**词即量,数必配账,账必有源**。

## 1. 表达力:计量语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 量值钉死 | **量值语言** | 被测量(定义了什么)/示值(表上读的)/测得值/修正值(加到示值上的补偿)——「测的是什么」四件套 |
| 单位钉死 | **SI 语言** | 基本单位/导出单位/词头(纳/微/吉)/量纲符号(L M T I Θ N J)——「拿什么量」的公共词表 |
| 分散性钉死 | **不确定度语言** | 标准不确定度 u/A 类/B 类/合成 u_c/扩展 U/包含因子 k/自由度 ν——「准到多少」的完整语法 |
| 关系钉死 | **校准语言** | 示值-参考值对应(校准曲线/修正表)+各级标准器+溯源声明——「跟谁比、经谁手」 |
| 判定钉死 | **合格评定语言** | 最大允许误差(MPE)/准确度等级/检定结论(合格/不合格)——「过不过线」的条款侧(与[标准科学技术](../讲透标准科学技术/README.md)共用) |
| 可比性钉死 | **比对语言** | 计量比对/参考值/等效度——「两家实验室谁对」的仲裁程序 |

**不能说的**(表达力边界,与生俱来):

- **真值的确切位置**:GUM 语法只报测得值与分散性,
  永不承诺「真值在区间内」的真值论断(00 章方法论
  之争第二场的语法面)
- **准确度的数字**:「准确度」是 VIM 定义的**定性概念**,
  只能说高低,不能说「准确度 0.5%」——定量表述必须
  改口不确定度(常见语言违规第一名)
- **定义不完整的被测量**:「这批料的纯度」没钉死取样
  方式与基准物质,不确定度语言无从下嘴——先修定义
  (被测量),再谈账本(00 章假设一)
- **「零误差」的测量**:定义可以零误差(常数化),
  测量永远有账;宣称「无误差」的话语在计量语法里
  不可判定,等于没说

## 2. 逻辑性质:账本的可信规则(三栏之二)

计量表述的可信度来自**账本规则**的遵守,不是形容词:

### 2.5 证据来源阶梯(不确定度主张的 E1-E4)

| 阶梯 | 来源 | 典型 | 注意 |
|------|------|------|------|
| E1 国家计量院级 | 基准复现/国家证书 | 基布尔秤复现、国家基准证书 | 链最上游;账最可信(00 章律3 的 u₀) |
| E2 校准实验室级 | 认可实验室证书 | CNAS 认可实验室出具的校准证书 | 看 U 与 k,不看机构名字响不响 |
| E3 厂商规格级 | 数据表/说明书 | 技术指标(常为区间或典型值) | 常缺 k 与置信水平;「典型值」≠保证值,按 B 类评定要打折建模 |
| E4 经验估计级 | 工程师判断 | 「大概 ±2% 吧」 | 合法(B 类的合法来源),但分布假设必须显式;写不出假设就别写数 |

### 2.6 五个内部语法规则

- **全源规则**:测量模型 y=f(x₁,…,xₙ) 上**每个输入量
  都要有一个分量**;漏一项=系统性少算(最隐蔽的账目
  造假是不列科目)。审查不确定度预算的第一动作:
  对着测量方程数科目
- **单位一致规则**:合成前所有分量换算到同一单位(或
  全部转相对不确定度);「%与绝对量混算」是新手第一错
- **相关性显式规则**:方和根合成省略交叉项的前提是
  相关系数 r=0;两台仪器溯源到同一上级标准时 r≠0,
  必须加交叉项 2r·uᵢ·uⱼ——默认独立是隐含假设,
  不是自然事实(00 章假设三)
- **报数对齐规则**:不确定度保留 1-2 位有效数字,量值
  的末位对齐到不确定度同一位(GUM 7.2.2 通说);
  「1.23456789±0.05」的后六位是噪声装正经
- **小样本 t 规则**:95% 区间=k·u_c,k 的取值随自由度
  走:n=5 乘 t(4)=2.776 而非 1.96(家族实验律2;
  硬套 1.96 名义 95% 实际 87.8%);报 U 必报 k,
  报 k 必交代它怎么来的

## 3. 规范化:术语的钉死术(三栏之三)

- 国际语境三宪法:BIPM《SI Brochure》(单位)、JCGM 200
  《VIM》(术语)、JCGM 100《GUM》(评定);中文语境:
  GB/T 27418 与 JJF 1059.1 承接(通说)。中英对译必须
  声明口径——特别是 accuracy/precision 这对被日常语
  搅浑的词
- 度量:不确定度带单位(与量值同单位)或用相对形式
  (量纲一);包含区间必须配概率与 k;溯源声明必须
  落到具体标准器与不确定度

**术语三栏表(概念-通俗-精确)**:

| 概念(标准语) | 通俗说法(陷阱) | 精确含义(VIM/GUM 义) |
|------|------|------|
| 准确度 accuracy | 「很准」 | 测量值与被测量真值之间的一致程度——**定性概念**,不给数字 |
| 精密度 precision | 「很稳」 | 规定条件下重复测量的**分散性小**——与偏倚无关 |
| 正确度 trueness | 「没偏」 | 大量重复测量的均值与参考值之偏倚小——与分散无关 |
| 误差 error | 「差了多少」 | 测得值−参考量值,**带符号**;因参考值自身有不确定度,误差原则不可确切知道 |
| (测量)不确定度 uncertainty | 「误差范围」 | 基于**所用信息**表征被测量量值分散性的**非负参数**——描述的是状态不是动作 |
| 标准不确定度 u | 「一倍σ」 | 以标准偏差表示的不确定度 |
| A 类评定 Type A | 「实测统计」 | 对观测列用统计方法得到的 u(如 s/√n) |
| B 类评定 Type B | 「拍脑袋」❌ | 用非统计方法(证书/规格/经验/手册)得到的 u——**与 A 类同级,不是将就** |
| 合成标准不确定度 u_c | 「总误差」 | 各分量按传播律(方和根+相关项)合成后的 u |
| 扩展不确定度 U | 「误差限」 | U=k·u_c,给包含区间 [y−U, y+U];**报 U 必报 k** |
| 包含因子 k | 「置信系数」 | 区间半宽与 u_c 之比;k=2≈95% 只在自由度大+近正态时成立(小样本用 t) |
| 包含区间 | 「置信区间」 | 以给定概率(包含概率)包含被测量一组合理量值的区间 |
| 示值 indication | 「读数」 | 测量仪器/测量系统给出的量值 |
| 修正值 correction | 「补差」 | 代数相加于未修正测得值以补偿系统效应的值:修正值=−(估计的)误差 |
| 被测量 measurand | 「要测的东西」 | **拟测量的量**——其定义(温度/位置/程序)是测量的一部分,定义不完整=定义不确定度 |
| 测量模型 | 「计算公式」 | y=f(x₁,…,xₙ):输出量与输入量的函数关系——预算表的科目来源 |
| 校准 calibration | 「标定」 | 在规定条件下建立示值与对应量值之间关系的操作,**给数据(曲线/修正/不确定度),不给合格结论** |
| 检定 verification | 「年检」 | 查明和确认计量器具符合法定要求的程序,**给合格/不合格判定**;带法制性(中国语境) |
| 计量溯源性 traceability | 「可追溯」❌(管理学术语撞车) | 通过**不间断的校准链**使测量结果与参考(国家基准)联系起来的性质,链上每环有不确定度——与「产品可追溯」的 logistics 义完全不同 |
| 重复性 repeatability | 「自己重复」 | 同条件(同人/同仪/同地/短时)重复测量的一致性 |
| 复现性 reproducibility | 「换人换地」 | 变化了的条件(不同实验室/方法/时间)下测量结果的一致性 |
| 分辨力 resolution | 「最小格」 | 引起示值可觉察变化的被测量最小变化——B 类分量的常客(均匀分布 u=分辨力/√12,通说) |
| (测量)标准 standard | 「标准器」 | 为定义、实现、保存或复现量的单位(或其倍数/分数)而作为参考的实物量具/测量仪器/参考物质——注意与 41050 的「标准文本」一词两义,语境分诊 |
| 标准物质 reference material | 「标准样品」 | 具有足够均匀与稳定的特性量值之物质——把量值搬进实验室的载体(4105020 与本家族的接头) |
| (计量)基准 primary standard | 「国家级标准」 | 经法定程序确认的国内最高等级标准(原器时代的遗风:2019 后基准=常数实现流程) |
| 计量比对 comparison | 「比对试验」 | 同一量在规定条件下由两家以上实验室测量的组织仲裁(CIPM MRA 关键比对是国际层) |
| 测量不确定度预算 | 「误差分析表」 | 列全分量(来源/类型/分布/u/灵敏系数/自由度/贡献)的**账本**——计量学的核心文档(03 章 schema) |

## 📌 收束

计量学语言=**量值四件套(被测量/示值/测得值/修正)+
SI 词表(单位/词头/量纲)+不确定度语法(u/u_c/U/k/ν,
A/B 同级)+溯源句法(基准→校准链→标准物质)**,外加
一条铁的术语纪律(准确度定性、不确定度定量、校准给数、
检定给判)。它写下的每个数字都在等一本账;账上每个
科目都在等一个来源。下一章把账本压成数据结构:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **账本眼**:见到任何带小数点的结论先问账——u 多少、
  k 多少、主导分量是谁、来源是 E 几级
- **定性定量分界眼**:准确度只说高低,不确定度才带
  数字;把形容词换算成区间,是工程对话升级为计量
  对话的第一步
- **来源眼**:每个不确定度主张都有出处(基准/证书/
  规格/经验);问「E 几级」比问「准不准」更有信息量
