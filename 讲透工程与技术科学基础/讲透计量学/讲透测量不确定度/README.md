## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 标准不确定度 u | 以标准偏差表示的分散性度量——A/B 类殊途同归 |
| 合成律 | u_c=√Σ(cᵢuᵢ)²(+相关交叉项):方差相加,不是不确定度相加 |
| 扩展不确定度 U | U=k·u_c 给包含区间;报 U 必报 k;k=2≈95% 只在自由度大+近正态成立,小样本乘 t(ν) |
| 不确定度预算表 | 科目(来源/类型/分布/u/灵敏系数/自由度/贡献)——核心文档 |
| 定义不确定度 | 被测量定义不完整贡献的分量——语义的散,装置救不了 |

## ✨ 这支最美的一个事实

**一行公式统一了全球的可信语言**(00 章美之时刻③)。
u_c=√Σ(cᵢuᵢ)² 加上 U=k·u_c,把「准到多少」从形容词变成
**可审计的账本**:每个分量有来源、有方法、有自由度,合成
有规则,区间有包含因子——东京的伏特与柏林的伏特第一次
可以在同一张预算表上对话。第一课是淹没律:10%⊕1%=10.0499%≈10.05%——**先找主导分量**(实验律1)。
