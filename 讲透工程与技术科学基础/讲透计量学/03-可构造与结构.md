# 03 · 可构造与结构——预算表、校准证书与溯源链作为数据对象

> **本章回答五问之 Q4(可构造性与结构)。**
> **本质一句话**:计量学里「可构造」的不是测量过程本身,
> 而是**它的四类产出**——测量模型是把「测什么」写成
> 函数 y=f(x₁,…,xₙ),不确定度预算表是把「准到多少」
> 写成科目-来源-分量的账本,校准证书是把「跟谁比」写成
> 示值-参考值-不确定度的对照表,溯源等级图是把「经谁手」
> 写成基准→参考→工作→现场的链;把这些结构显式化,
> 测量工作就从仪器手艺变成工程:可校验、可对表、可交接
> (04 章走廊的地基)。

---

## 0. 开篇:一份「出报告任务」的四件结构化家具

拆开任何一次严肃的测量任务(研发报数/型式试验/校准
服务),都能拆出四件家具:其一是**测量模型**(测的是
什么、怎么从原始读数算到结果——函数关系),其二是
**不确定度预算表**(账本:分量从哪来、各多大、怎么
合成),其三是**校准证书**(标准器的示值-量值对照与
它的不确定度),其四是**溯源等级图**(这把尺子经过
谁校准、离国家基准几级)。四件家具在手,02 章的语法
就变成**可机检的数据流水线**;从存档千克的比对记录到
数字化校准证书(01 章方向四),在数据结构层面是同一套
schema——变的是量值与密度,不变的是结构。

## 1. 什么是"可构造"的:四类结构对象

| 对象 | 数化身 | 可构造性 | 构造中的坑 |
|------|--------|---------|-----------|
| **测量模型** | y=f(x₁,…,xₙ)+输入量清单 | ✅ 高度可构造 | 输入量漏列(全源规则的对面);被测量定义不完整就开写 |
| **不确定度预算表** | 分量(来源/A-B 类/分布/u/灵敏系数/自由度/贡献占比) | ✅ 高度可构造 | 单位不一致就合成;相关分量不标 r;只报 U 不报 k |
| **校准证书** | 示值-参考值-差值-U-k-溯源声明 | ✅ 高度可构造 | 把证书当合格证(校准给数不给判);证书过期还引用 |
| **溯源等级图** | 节点(基准/参考/工作/现场)+边(校准关系,带传递不确定度) | ✅ 高度可构造 | 链上出现环或断链;传递比失控不设阈值 |
| **SI 常数表** | 7 定义常数×精确值×7 基本单位(2019 版) | ✅ 高度可构造 | 把实现不确定度当成定义不确定度(定义=0) |
| **量纲向量** | 量×7 基本量纲的指数向量 | ✅ 高度可构造 | 单位制混用(02 章开篇事故的 schema 面) |

**不可构造的**:测量作业本身(对表/控温/读数的物理
过程)、B 类评定的「分布假设从哪来」(工程师判断的
建模直觉)、比对中对系统性分歧的解释(物理归因)、
以及「这个被测量该怎么定义」(定义是领域知识决策,
00 章假设一)。

### 1.5 最小数据模式(动手者的 schema)

```yaml
# 测量模型卡(预算表的科目来源)
measurement_model:
  measurand: {name: str, definition: str}        # 被测量及其定义(温度/位置/程序)必写全
  equation: "y = f(x1, ..., xn)"                  # 测量方程
  inputs:                                         # 每个输入量一枚科目(全源规则)
    - {name: str, unit: str, source: E1|E2|E3|E4} # 来源等级(02 章阶梯)

# 不确定度预算表(计量学的核心文档)
uncertainty_budget:
  for: {quantity: str, value: num, unit: str}
  components:
    - {id: str, source: str, type: A|B,           # A/B 类:按评定方法分,无高下
       distribution: normal|rectangular|triangular|...,  # B 类必须显式分布假设
       u: num, unit: str,                         # 标准不确定度(单位统一!)
       sensitivity: num,                          # 灵敏系数 c_i = ∂f/∂x_i
       dof: int|None, contribution: num}          # 自由度+方差贡献占比(找主导)
  correlations:                                   # 相关分量显式登记(02 章规则三)
    - {pair: [id1, id2], r: num, reason: str}     # 默认独立=隐含假设,同源必标
  combined: {uc: num, dof_eff: num}               # 合成+有效自由度(Welch-Satterthwaite)
  expanded: {U: num, k: num, prob: 0.95}          # 报 U 必报 k(小样本 k=t)

# 校准证书(示值-量值对照,校准给数不给判)
calibration_certificate:
  subject: {instrument_id: str, type: str}
  results:
    - {indication: num, reference: num, correction: num,   # 示值/参考值/修正值
       U: num, k: num, unit: str}
  traceability: {reference_standard: str, level: national|reference|working,
                 certificate_ref: str, date: iso8601, due: iso8601}   # 有效期必钉死
  # 注意:无 conformity 字段——合格判定是检定/判定的业务,不是校准的

# 溯源等级图(链是图不是清单)
traceability_scheme:
  nodes:
    - {id: str, level: primary|reference|working|field,
       u: num, realization: str}                  # 2019 后基准=常数实现流程
  edges:
    - {from: node, to: node, transfer_ratio: num, # 传递比 r(链的税率的入账处)
       w: num, method: str, cert_ref: str}        # 本级自身分量+校准方法
  # 校验:无环、无断链、每边传递不确定度已知、末端 u 随级数单调增

# SI 定义常数表(2019 版)
si_constants:
  - {constant: "Δν_Cs", value: 9192631770, unit: Hz, defines: second}
  - {constant: c, value: 299792458, unit: "m/s", defines: metre}
  - {constant: h, value: "6.62607015e-34", unit: "J·s", defines: kilogram}
  - {constant: e, value: "1.602176634e-19", unit: C, defines: ampere}
  - {constant: k, value: "1.380649e-23", unit: "J/K", defines: kelvin}
  - {constant: N_A, value: "6.02214076e23", unit: "1/mol", defines: mole}
  - {constant: K_cd, value: 683, unit: "lm/W", defines: candela}
  # 定义值全部精确(不确定度=0);实现不确定度另记(定义-实现分离)

# 量纲向量(齐次性机检的输入)
dimensional_vector:
  # 例:力 = M·L·T^-2 → [M:1, L:1, T:-2, I:0, Θ:0, N:0, J:0]
  quantity: {name: str, exponents: [num × 7]}
```

注意 `distribution`、`correlations`、`k`、`due` 四处必填:
把 02 章的账本纪律写进数据结构——**数据层自带校验点,
是计量文档区别于普通文档的第一特征**(与
[工程物理学家族](../讲透工程物理学/03-可构造与结构.md)
schema 同款精神:数值不 naked,账目不缺席)。

## 2. 骨架一:测量模型卡(科目的户口)

- **被测量定义先行**:「长度」必须钉死温度基准与测点
  (20 °C 标准温度,通说),「浓度」必须钉死取样与基准
  物质——定义不完整,预算表就是给错的对象记账(GUM
  的定义不确定度,00 章假设一)
- **方程即科目表**:y=f(x₁,…,xₙ) 的每个 xᵢ 自动成为
  一个预算科目;**从方程到预算表是机械展开**,反过来
  (预算表里出现了方程没有的科目)就是账实不符
- **灵敏系数是杠杆**:cᵢ=∂f/∂xᵢ 把输入量的不确定度
  放大或缩小后计入输出——「哪个输入最要命」=uᵢ 与 cᵢ
  的乘积排序(主导分量分析的机械版,00 章反直觉①)

## 3. 骨架二:不确定度预算表(账本本体)

- **科目四列缺一不可**:来源(物理出处)、类型(A/B)、
  分布(B 类的假设)、数值(u 带单位);缺分布的 B 类
  科目=不可复审的估计
- **贡献占比列是治理面板**:按 (cᵢuᵢ)²/u_c² 排序,
  头名就是「砍它一半」的对象;小于主导 1/10 的科目
  集体沉默(家族实验律1 的表格版)
- **合成与扩展分两栏**:u_c(标准)与 U=k·u_c(扩展)
  分开记;有效自由度(Welch-Satterthwaite 通说)决定
  k 取 2 还是 t——小样本的诚实住在这一栏(律2)
- **相关分量成对登记**:r≠0 的 pair 单列;「默认全部
  独立」的预算表在评审时按未完成品处理(02 章规则三)

## 4. 骨架三:校准证书与溯源等级图(链的两端)

- **证书的三明治**:示值(被校表读的)-参考值(标准器
  给的)-差值与修正;每行带 U 与 k;**校准证书没有
  合格栏**(给判定的叫检定/判定,02 章术语表)——拿
  证书当合格证是对象错位
- **有效期必钉死**:证书的 date/due 字段是链的时效;
  引用过期证书=链上出现时间性断链(与标准文献的
  「引用作废标准」同构,[标准科学技术](../讲透标准科学技术/README.md)
  03 章的镜像问题)
- **溯源等级图是图**:节点(各级标准)+边(校准关系,
  携带传递比与本级分量);校验三断言——无环、无断链、
  每条边的 w 已知(家族实验律3 的 schema 版:末端
  不确定度由链的拓扑与各级分量共同决定)
- **标准物质是链的水下冰山**:把量值搬进实验室的载体,
  其研制与定值规范归标准学(4105020),量值溯源本体
  归本家族——一张证书两宇宙接头(README 消歧表)

## 5. 从结构到校验:这套骨架买到了什么

- 模型卡带输入清单 → 全源规则可机检(科目与方程
  逐一对表)
- 预算表带分布与相关 → 合成可复算、主导分量可排序、
  「漏科目」可报警
- 证书带 U/k/due → 过期引用可机检;「校准当合格」的
  话术可自动识破
- 溯源图带边权 → 链上环/断链可检测;末端不确定度可
  全链复算(04 章 C3)
- SI 常数表带「定义=精确」标记 → 「定义不确定度=0、
  实现不确定度另算」的直觉可机护(00 章反直觉③)

## 6. 构造合法性清单(动手前三问)

把任何测量任务变成数据结构之前,先过三问——本家族的
「类型检查」:

1. **被测量定义写全了吗**:温度/位置/程序/取样钉死了
   吗?测量方程的输入量列全了吗(漏一个=账实不符)?
2. **账本科目齐吗**:每个输入量有 u 吗?B 类的分布
   显式吗?相关分量登记了吗?U 报 k 了吗?
3. **链钉死了吗**:证书在有效期内吗?溯源图无环无断
   链吗?传递比在阈值内吗?

三问全过,数据才获得进入 [04 章走廊](04-计量学转代码.md)
的资格。**测量工程的第一特征不是读数多精,是账目清楚。**

## 📌 收束

可构造的是**四类数据对象**(测量模型/预算表/校准证书/
溯源等级图),不可构造的是**测量作业与建模判断的
过程**;结构化不是为了替代实验室,是为了让「准到多少」
可校验、可交接、可复盘。下一章把骨架接上代码:
[04-计量学转代码](04-计量学转代码.md)。

**🧠 认知升维**:

- **科目眼**:测量方程的每个输入都是预算科目——见数先
  数科目,账实不符的预算一票否决
- **链图眼**:溯源是图不是清单——节点、边、边权三件
  齐,末端不确定度才能全链复算
- **时效眼**:证书与标准器都是时效资源——引用不看
  date/due,等于开过期支票
