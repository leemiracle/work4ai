# 讲透钻探与取样 · 取样扰动的物理学——第一通道(自定支)

> **支定位**:家族三通道之**直接通道**——把固体样本搬上来:钻探工艺(回转/冲击/螺旋,泥浆护壁)、岩芯采取率与取样扰动(面积比/间隙比/质量分级)、钻孔结构与编录。立身命题:**「原状」不是有或无,是差多少——扰动是取样器几何与工艺的函数,可设计、可度量**(Hvorslev 1949,家族 00 章故事框一)。GB/T 13745:41065 无三级明细,本支为自定支;案例按报告与教材通说,孔内事故按工程通说不渲染(写作红线)。

## 支定位与地盘

- 地盘:钻探方法的地层适应性(土层/基岩/卵石/岩溶);护壁与冲洗;岩芯钻探(单/双层岩芯管);采取率与 RQD 的工艺敏感性;取样器设计(薄壁/厚壁/回转式);取样质量等级;岩芯编录与柱状图(受控词表)
- 在家族中的位置:唯一带回「眼见样本」的通道——给原位测试供对照组,给物探供身份鉴定;「扰动账」是与原位测试支争论(直接 vs 间接)的本钱

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 面积比 | (De²−Di²)/Di²:取样器挤土的几何账;约≤10% 为薄壁界线(通说) |
| 取样质量等级 | Ⅰ~Ⅳ 级:原状是程度词,随面积比/工艺/土类评定 |
| 岩芯采取率 | 回收长度/进尺:岩体完整与工艺质量的混合读数 |
| RQD | ≥10 cm 完整段占比:对孔径与钻具敏感 |
| 编录受控词表 | 稠度/密实度从词表取值:一孔一方言是清洗债务 |

## ✨ 这支最美的一个事实

**一个减法比给「原状」定了身份(家族美之时刻①)**。Ar=(De²−Di²)/Di²——管壁多占的那一圈截面,就是土样被挤压改性的份:厚壁常超 30%,薄壁压到约 10% 以内,扰动的几何账就还了大半。**工程语言的进步,常常就是把一个形容词换成一个比值**——1949 年以后,「原状土样」背后必须站着一个可算的数。
