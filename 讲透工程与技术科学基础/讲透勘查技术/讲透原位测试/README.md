# 讲透原位测试 · 原位 vs 扰动的物理逻辑——第二通道(自定支)

> **支定位**:家族三通道之**原位通道**——把仪器送下去:CPT/CPTu(锥尖阻力/侧摩阻/孔压连续曲线)、标准贯入 SPT(N 与 N60 能量校正)、旁压与扁铲侧胀。立身命题:**与其把土搬上来(必然扰动),不如把仪器送下去(保持原位,但读数间接)**——原位与扰动的物理逻辑就是这一笔权衡的全部展开(家族 00 章方法论之争)。GB/T 13745:41065 无三级明细,本支为自定支;方法按正典教材与规范通说(写作红线)。

## 支定位与地盘

- 地盘:CPT/CPTu(贯入机理、qc/qt/Rf/Bq、土行为分类图、归一化);SPT(能量比、N60、N1₆₀、经验关联的边界);旁压(预钻孔扰动入账、极限压力与旁压模量);扁铲侧胀(材料指数族);原位与室内的配对设计(什么参数只能原位测:密实度/应力历史敏感指标/结构性)
- 在家族中的位置:连续读数的主力——给钻探支供孔内连续性,给物探供标定锚点;家族实验律1(变点分层)与律2(N60)都落在本支地盘

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| N60 | N×ER/60:除掉锤击能量效应,击数才跨钻机可比(Skempton 1986) |
| 能量比 ER | 传到钻杆/理论落锤能量:锤型与释放机构的身份证 |
| qc→qt | 锥尖面积的孔压修正:校正链第一环 |
| Rf / Bq | 摩阻比与孔压比:土类与排水状态的贯入线索 |
| 土行为分类 | Robertson 图:按贯入行为分,不按岩性分 |
| 采样密度 | 每 2 cm 一点:分辨率住在采样密度里(律1) |

## ✨ 这支最美的一个事实

**一只锤的计量学(家族实验律2)**。一个数了半个世纪的「土性指标」N,原来一半是仪器效应:同一层土,ER=45 的老式吊锤打 16 击,ER=90 的自动锤打 9 击;一行校正 N60=N×ER/60 把四台钻机的读数归到同一个土(CV 从 0.228 压到 0.054)。**击数不是土的性质,是仪器的读数——先除仪器,再谈地层**;这条纪律适用于一切带传感器的测量。
