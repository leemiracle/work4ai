# 讲透工程物探 · 反问题与多解性——第三通道(自定支)

> **支定位**:家族三通道之**间接通道**——把波与场送下去再收回来:地震波法(折射/反射/面波频散)、电法(电阻率成像/激电/自电)、探地雷达(高频电磁双程走时)。立身命题:**物探成果不是「看到」,是「在先验约束下猜得有纪律」**——反演天生多解,正则化拿分辨率换方差,身份鉴定必须钻孔锚定(Backus & Gilbert/Tikhonov,家族 00 章故事框四)。GB/T 13745:41065 无三级明细,本支为自定支;方法按应用地球物理教材通说(写作红线)。

## 支定位与地盘

- 地盘:折射波法(初至走时/层速度/盲区与隐层);反射与面波法(频散曲线反演 Vs 剖面,MASW/SASW);电法(视电阻率=装置加权体积平均;高密度电法;激电与自电);探地雷达(介电界面/双程走时/高频浅分辨);反演理论(不适定性、正则化、先验、分辨率-方差权衡);物探-钻探联合解释(锚定与互检)
- 在家族中的位置:唯一给「孔间连续性」的通道——钻孔点稀疏、原位沿孔轴,物探补面;代价是多解,纪律是申报(家族 02 章规则三;04 章 C3 的地盘)

## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 初至走时 | 折射法原料:距离-时距曲线换层速度 |
| 盲区/隐层 | 折射法的身份限制:近炮点无折射、低速夹层不现 |
| 频散曲线 | 面波法原料:不同波长采样不同深度 → Vs 剖面 |
| 视电阻率 | 装置加权体积平均:不是某点真值 |
| 双程走时 | 雷达原料:t×介电常数定深;高频浅而细 |
| 多解性/正则化 | 不同模型同样合法,必须申报;先验换稳定解 |
| 钻孔锚定 | 物探层位与柱状图的外键:连续性配身份 |

## ✨ 这支最美的一个事实

**「看不见」从叹息变成定理(家族美之时刻③)**。Backus & Gilbert(1967-68)证明地球物理反演天生不适定——观测有限而模型自由,分辨率与方差不可兼得;Tikhonov(1963)的正则化给「猜」以纪律:先验申报、参数显式、残差随行。**承认猜,才猜得好**——多解性不是物探的耻辱,是间接取证的物理身份;双先验对照是它最低成本的显影实验(家族 04 章 C3)。
