# 02 · 语言特征——让不可见变得可数:勘查语言与它的仪器效应纪律

> **本章回答五问之 Q3(语言特征:表达力/逻辑性质/规范化)。**
> **本质一句话**:勘查技术说的是一种**把地下翻译成可数
> 对象**的语言——编录的分级词(坚硬/硬塑/可塑)把定性
> 钉成档,击数与采取率把工艺变成整数,qc/u2 连续曲线把
> 地层变成数据流,走时与视电阻率把波场变成层参数,校正
> 链(N→N60→N1₆₀,qc→qt)把仪器效应从读数里除掉;判断
> 一段勘查记录的优劣,不看辞藻,看**每个数后面跟着哪条
> 工艺元数据与哪条校正链**。三栏分别回答:这套语言能说
> 什么(表达力)、读数凭什么可信(逻辑性质)、术语如何
> 被钉死(规范化)。

---

## 0. 开篇:同一层「粉砂」的三种说法(教学例)

📖 **故事框(教学例)**。同一层粉砂,三种记录:钻孔编录
写「中密,粉砂,摇振反应迅速,含云母」(分级词+行为
暗示);SPT 记录写「N=12」——但只有同时记着 63.5 kg
落锤、76 cm 落距、能量比 ER=55,这个 12 才可比(换成
ER=90 的自动锤,同一层只剩 9 击,家族实验律2);CPT 记录
写「qc=5.0 MPa,fs=80 kPa,Rf=1.6%,每 2 cm 一点,锥头
截面积 10 cm²,率定日期在案」。三种语言说的是同一层土,
可数性、连续性与失真各不相同——**勘查语言的全部要义:
词汇即工艺,数字带链**。

## 1. 表达力:勘查语言能说什么(三栏之一)

**能说的**:

| 能力 | 语件 | 例 |
|------|------|-----|
| 分级描述 | **编录词表** | 稠度分档(坚硬/硬塑/可塑/软塑/流塑)、密实度(松散/稍密/中密/密实)、颜色与包含物——把地质家的眼变成可传的档 |
| 计数量测 | **整数语言** | 岩芯采取率、RQD、标贯击数 N——工艺次数当读数(须校正链,规则一) |
| 连续曲线 | **模拟量语言** | qc/fs/u2(每 2 cm)、旁压压力-体积曲线——采样密度即分辨率(律1) |
| 波场走时 | **时间语言** | 初至走时、面波频散、雷达双程走时——深度=速度×时间的反演原料 |
| 校正链 | **元数据语言** | N→N60→N1₆₀(能量+上覆应力)、qc→qt(孔压面积修正)、归一化——把仪器与应力效应除掉 |
| 反演模型 | **参数语言** | 层速度、视电阻率、介电常数剖面——带先验的推断产物(必须申报) |

**不能说的**(表达力边界,与生俱来):

- **钻孔之间的地下**:柱状图的层界线是外推线,两点之间
  的一切靠代表性假设垫底(00 章假设一)
- **应力历史与组构的完整状态**:取样即扰动——「原状」
  是程度词,敏感指标的原始值永远丢失一部分(假设二)
- **岩性身份(物探)**:物探测的是物理响应差异,「低速
  异常」不等于「软土」——身份鉴定必须钻孔锚定(假设三)
- **尺度以下的真相**:厘米级试样测得的参数与米级工程
  尺度的行为之间隔着尺度效应——室内精确不等于场地真实

## 2. 逻辑性质:读数的证据规则(三栏之二)

勘查读数的可信度来自**仪器效应被显式分离、工艺被显式
配对、多解被显式申报**,不是来自数字位数:

### 2.5 验证强度阶梯(勘查版 V1-V4)

| 阶梯 | 通道 | 状态 | 注意 |
|------|------|------|------|
| V1 直接观测级 | 岩芯+编录 | 「眼见为实」 | 眼见的是扰动后的样本+解译的眼;RQD 对钻探工艺敏感 |
| V2 原位连续级 | CPT/CPTu、旁压、扁铲 | 原位+连续 | 间接:测的是贯入/膨胀响应,参数靠力学解译或经验关联 |
| V3 半直接级 | SPT、取样+室内试验 | 带扰动链 | 击数带锤效(N60),试样带扰动等级(面积比) |
| V4 反演推断级 | 物探剖面 | 全覆盖 | 多解:结论带先验,未经钻孔锚定不得作设计依据 |

(直接/间接与保真是两回事:V1 最「直接」但状态已扰,
V2 最连续但读数间接——00 章方法论之争的证据面。)

### 2.6 三个内部语法规则

- **仪器效应分离规则**:每个读数=土性×仪器×工艺。N60
  把锤击能量效应除掉(律2:CV 从 0.228 降到 0.054),锥头
  率定把传感器漂移除掉,面积比把取样器几何效应记进扰动
  账(Hvorslev)——不除仪器,读数不是土的数
- **工艺-数据配对规则**:每个数据必须携带工艺元数据
  (锤型与 ER、取样器类型与面积比、护壁与冲洗液、物探
  采集与反演参数)才可入库、才可比——无元数据的击数=
  不可比数据,二十年后连升级为 N60 的机会都没有(03 章
  schema 的必填列;01 章方向二数据平台的清洗债务)
- **多解性显式规则**:物探结论必须随附反演方法、初始
  模型与正则化参数;未申报多解性的「反演成果」不可用于
  设计锚定——多解性不是缺陷,是必须申报的物理身份
  (00 章故事框四;04 章 C3 的运行时版)

## 3. 规范化:术语与对译(三栏之三)

- 国际语境:ISSMGE 勘探与测试方法报告传统、ASTM
  D1586(SPT)/D5778(CPTu)谱系、EN ISO 22475(取样与
  地下水测量)/22476(原位测试)系列(通说);中文语境
  GB 50021 及各行业勘察规范。中英写作必须声明口径——
  特别是 recovery、disturbance 这类一词多义的制度词
- 命名陷阱一批:「触探」家族(静力/动力/标准贯入)在
  中文里共享「贯入」意象,但机理(静压/冲击)与读数
  (阻力/击数)不同科;跨语言写作时先对表再下笔(规范
  语境的错译多半错在这批词上)
- 度量:击数无量纲(击/30 cm),阻力 MPa 与 kPa 分档
  (锥尖阻力 MPa、侧摩阻 kPa,通说习惯),采取率与 RQD
  为百分比,走时 ms、速度 m/s

**术语对译表(日常语→勘查语;中英对照)**:

| 中文(标准语) | 英文 | 日常语陷阱 |
|------|------|---------|
| 岩芯采取率 | core recovery | ≠「打到多深」:回收长度/进尺;岩体完整与工艺质量的混合指标 |
| 岩石质量指标 | RQD | ≥10 cm 完整岩芯段占比;对孔径与钻具工艺敏感 |
| 面积比 | area ratio | (De²−Di²)/Di²:取样器挤土的几何账(Hvorslev) |
| 原状土样 | undisturbed sample | **≠「没动过」**:取样质量分级的程度词 |
| 标准贯入试验 | SPT | 63.5 kg/76 cm 规程;劈管取样的副产品起家 |
| 能量比 | ER (energy ratio) | 传到钻杆的能量/理论落锤能量;基准 60% |
| N60 | N₆₀ | N×ER/60:跨钻机可比形态(律2) |
| 锥尖阻力 | qc / qt | qt 含孔压面积修正;须随锥头几何与率定 |
| 摩阻比 | Rf | fs/qt×100%:土类行为线索 |
| 孔压比 | Bq | u2 超孔压归一:细粒土敏感 |
| 土行为分类 | SBT 分类图 | 分类的是「贯入行为」不是岩性(Robertson 传统) |
| 旁压试验 | PMT | 钻孔内膨胀;Ménard 型须预成孔(孔壁扰动入账) |
| 扁铲侧胀 | DMT | 薄板贯入+膜片膨胀;材料指数 ID 等一族指数 |
| 十字板剪切 | vane shear test | 原位测不排水强度的老工具;重塑比(灵敏度)的现场读法 |
| 动力触探 | DPT | 重锤贯入计数;与 SPT 同属「工艺次数当读数」,同须能量纪律 |
| 静力触探 | CPT | 中文的「静力」说的是贯入方式(非冲击),别与「静载试验」混 |
| 折射波法 | seismic refraction | 初至+层速度;盲区与隐层是方法身份的一部分 |
| 面波法 | MASW/SASW | 频散曲线反演 Vs 剖面;深度分辨率随波长变 |
| 视电阻率 | apparent resistivity | 装置加权体积平均,非某点真值 |
| 探地雷达 | GPR | 双程走时×介电常数;高频=浅而细 |
| 反演 | inversion | 由观测反推模型——是推断不是读取 |
| 多解性 | non-uniqueness | 不同模型对同一数据的合法性;须申报 |
| 正则化 | regularization | 给不适定问题加先验换稳定解 |
| 变点 | change point | 机器分层的统计本体(律1) |
| 净上覆应力 | σ′v0 (effective overburden stress) | 归一化的分母:同一 N 在浅层与深层不是一回事 |
| 随钻测量 | MWD (measurement while drilling) | 钻进参数流:地层×工艺的耦合读数,须解耦(01 章方向一) |
| 勘察阶段 | investigation stages | 可行性/初步/详细(通说三级):阶段=信息投资分期 |

## 📌 收束

勘查技术语言=**分级词与整数的描述系统(编录/击数/采取率)
+仪器效应分离的证据规则(V1-V4 阶梯与三规则)+校正链
与多解性申报的术语纪律(N60/SBT/视电阻率/正则化)**。
它写下的每个数都在等一行工艺元数据与一条校正链。
下一章把勘查产出压成数据结构:
[03-可构造与结构](03-可构造与结构.md)。

**🧠 认知升维**:

- **仪器眼**:每个读数都是「土性×仪器×工艺」——先问
  校正链走完没有,再谈数值
- **链眼**:数字的价值在链上:N 不带 ER 是半个数;
  无校正链的数据库是债务不是资产
- **多解眼**:反演结论自带先验——不申报多解性的剖面,
  是把「猜」冒充「看」
- **密度眼**:曲线的采样密度就是它的分辨能力——读
  连续数据先问「点距多少」
