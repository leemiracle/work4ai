# 勘查技术思维技能卡(GB/T 41065 · 讲透勘查技术家族的抽象层)

## 1. 何时用此分支(问题特征触发词)

- 「**采取率**多少正常」「**RQD** 怎么算」——
  回收长度/进尺;≥10 cm 完整段占比——都对钻探工艺
  敏感,是「岩体×工艺」的混合读数(02 章整数语言)
- 「**原状样**到底原不原状」——原状是程度词:面积比
  Ar=(De²−Di²)/Di²(取样器几何的扰动账)+取样质量
  分级(Hvorslev 1949 框架,00 章故事框一)
- 「**N 值**能不能直接用」「**N60** 是什么」——
  N60=N×ER/60:击数是仪器读数,ER 是锤的计量学
  (家族实验律2;02 章仪器效应分离规则的出生地)
- 「**CPT 曲线**怎么读」——qc/fs/u2 连续曲线+摩阻比
  Rf+孔压比 Bq+土行为分类(SBT):每 2 cm 一点的
  「流证据」(律1 变点分层的原料)
- 「**旁压/扁铲**测什么」——钻孔内膨胀(PMT)与薄板
  贯入+膜片膨胀(DMT):原位变形响应的两个窗口
- 「**折射/面波/电阻率/雷达**各自测什么」——初至走时
  (层速度)/频散(Vs 剖面)/视电阻率(装置加权体积
  平均)/双程走时(介电界面)——测的都是物理响应,
  岩性身份要钻孔锚定
- 「反演为什么**多解**」「**正则化**在干嘛」——观测
  有限模型自由:正则化=拿分辨率换方差,解的形状由
  先验决定(00 章故事框四;04 章 C3)
- 「**机器分层**怎么做」——变点检测:滑窗均值差的峰
  即界面,采样密度决定界面精度(律1 实测误差≤±0.5 m)
- 「**孔距**怎么定」「为什么不能均匀网格到底」——
  规范间距是零先验默认策略;信息价值布孔把不确定性
  当目标函数(律3:贪心总方差 0.24 vs 均匀 2.32)
- 「**数字钻探**/**AI 布孔**到哪了」——MWD 数据流把
  钻头变传感器;DRL 序贯布孔与岩土数据平台
  (01 章两方向,检索校准 2026-09-07)
- 「勘查技术与**工程地质学**什么关系」——分工:它管
  判断怎么下(证据→设计参数的翻译链),本家族管证据
  怎么来(README §〇)

## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **扰动眼** | 每次观测都在改被观测者——取样改土样、探针改系统;先问「我的观测本身改了什么」(面积比是它的几何账) |
| **仪器眼** | 每个读数=土性×仪器×工艺——N60 除锤效、率定除漂移、扣观测开销;不除仪器,读数不是对象的数 |
| **链眼** | 数字的价值在链上:读数-工艺-校正-用途四环相扣;断链数据是债务不是资产(03 章 schema 的必填列) |
| **信息眼** | 布孔是买信息,间距是价格——证据不足的隐性成本永远贵于取证的显性成本;不知道的地方标方差 |
| **多解眼** | 间接证据自带先验——反演结论的边界写在假设里;双先验对照是多解性的最低成本显影实验 |
| **三角眼** | 钻探(真而稀疏且扰动)/原位(连续而间接)/物探(全覆盖而多解)是证据三角——勘察设计=预算内配平组合 |

## 3. 工具箱(何时用什么)

- **通道分诊三问**(00 章):要身份还是要连续性(钻探
  vs 原位/物探)?要参数还是要界面(取样试验 vs 曲线)?
  预算买哪种失真(扰动/间接/多解)?——先配平再谈精度
- **仪器效应审计**(02 章规则一):把读数列出来,逐个
  问「仪器×工艺」份额多少、校正链走完没有——跨源
  数据合并前的必检
- **变点分层与校正链实验**
  (`experiments/site_investigation.py`):滑窗均值差
  检出界面(误差≤±0.5 m)→N60 校正(CV 0.228→0.054)
  →贪心布孔(总方差 0.24 vs 均匀 2.32)——三律三分钟
  落成数
- **走廊三条**(04 章):C1 变点+校正链(已成)/C2 布
  孔优化(教学版已成)/C3 最小反演+多解性检查(骨架)

## 4. 常见误区与禁忌

- ❌ **把 N 当土性直接对表**:不同锤型的击数不可比
  (ER=45 与 90 差近一倍);用经验关联表前先问 N60
  校正了没有(律2)
- ❌ **把「原状」当绝对**:原状是质量等级的程度词;
  敏感指标(不排水强度/结构)在扰动下系统性失真,
  面积比不问就取数,等于不问精度就用仪器
- ❌ **物探异常当地质结论**:低速≠软土、高阻≠基岩——
  物探测的是物理响应差异,身份鉴定必须钻孔锚定;
  未锚定的物探层位不得进设计依据
- ❌ **反演不报先验**:初始模型+正则化参数+残差三缺
  一,多解性就不可复核——「反演成果」变成不可审计的
  图(02 章规则三)
- ❌ **数据不带工艺元数据入库**:只存 N 不存 ER、只存
  qc 不存率定——二十年后数据无法归一升级,是最大的
  数据债务(03 章三问第一问)
- ❌ **把直接当可靠**:眼见的岩芯是扰动后的样本;
  连续的间接曲线(CPT)对界面的分辨常胜过稀疏的直接
  取样——保真与直接是两个维度(00 章反直觉②)
- ❌ **孔距只有规范没有理由**:规范间距是零先验默认,
  不是设计;每个孔应有 rationale(条款引用或方差
  缩减预期)
- ❌ **均匀网格当最优**:已有信息偏置时,等距加孔把
  钱花在已知处——先画方差图,再定下一孔(律3)
