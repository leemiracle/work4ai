## 1. 可机械化边界(三件套之一)

**能进代码的**(勘查数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 机器分层 | 滑窗均值差/变点统计(律1)+分层读数 |
| 校正链 | N60/N1₆₀ 计算、qt 面积修正、归一化(律2) |
| 布孔优化 | 克里金式方差图+贪心/序贯设计(律3) |
| 一维反演 | 折射走时拟合、频散反演+阻尼最小二乘(C3) |
| 质量统计 | 采取率/RQD 统计、面积比合规检查 |
| 数据校验 | 工艺元数据完整性、校正链断链检测(03 章三问的机检版) |

**不能进代码的**(勘查技术的「不可判定域」):

1. **编录的地质解译**——描述词到地层故事的映射是地质
   判断;代码能查词表合规,不能替你「读」岩芯
2. **扰动等级的现场评定**——面积比是几何账,试样实际
   状态的触感评定有经验份
3. **反演先验的选择**——多解性的裁决:初始模型给什么,
   解就长什么样;这是知识决策,正则化只保证纪律
4. **勘察阶段与孔深的风险权衡**——规范下限之上的深度、
   优化方案与规范审查的衔接,是责任决策(01 章方向二
   未决问题)

> 边界的一句话:**代码是证据的放大器,不是编录员。**

## 2. C1 变点分层与校正链走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| qc 序列 | 逐深度数组(每 2 cm 教学版 0.1 m) | 采样密度即界面精度(律1 的信噪账:窗均值噪声 σ√(2/w)) |
| 变点统计 | 滑窗均值差/更精细的累积和 | 窗长是平滑-灵敏旋钮:太窄对噪声敏感,太宽抹薄层 |
| 能量校正 | N60=N×ER/60 | ER 不入库则校正链断链(数据债务) |
| 可比性审计 | 跨钻机 CV 对比 | 校正前后 CV 比值是仪器效应的量化读数(律2:23.5%) |

成品=`experiments/site_investigation.py` 律1+律2。**改地层
换两端的层均值,改钻机换一组 ER,改噪声换 σ**——03 章
schema 分离的好处:观测(曲线)、仪器(元数据)、校正
(链)分居三列,敏感性分析就是在列间扫描。

## 3. C2 布孔优化走廊(✅ 教学版已实现)

```python
# 教学版:贪心主动布孔(律3 的骨架)
def var_at(x, holes):                       # 简单克里金式方差
    v = 1.0                                  # σ₀²
    for h in holes:
        v *= 1.0 - exp(-((x-h)**2) / (2*ell**2))   # 距离核衰减缩减
    return v
holes = initial_holes                        # 既有孔网(可能偏置)
for _ in range(k):                           # 逐孔贪心
    x_best = min(candidates, key=lambda x: total_var(holes + [x]))
    holes.append(x_best)                     # 选总方差缩减最大处
# 断言风格:total_var(贪心孔网) <= total_var(均匀等距加孔);
# 先验 ℓ 从区域数据(变异函数)来——AI 布孔(01 章方向二)
# 就是把 ℓ 从人工假设变成数据驱动
```

要点:其一,**方差模型=先验知识的化身**——ℓ(相关长度)
决定「一孔管多宽」,它来自区域变异函数,没有它贪心退
化为瞎忙;其二,贪心对这类「收益递减」(次模)目标有
理论保证(通说:近似最优界),均匀网格是**零先验的
默认策略**,信息价值布孔对它的胜利来自「把钱花在方差
最大的地方」;其三,单次随机场实现上 MSE 可能相当
(实验 [3] 的诚实读数)——**方差优势是先验期望意义上的,
这正是勘察风险管理的语言**(Peck 观测法的数学亲戚)。

要点:其一,**正演是反演的另一半**——没有可信的正演
(波传播/电场物理),反演无从谈起(本体在

地球科学);其二,**正则化参数是分辨率-方差的旋钮**,
调它不是数值技巧,是地质决策(要尖锐界面还是要稳定
解);其三,双先验对照(同一观测、两个初始模型、两个
解)是**多解性的最低成本显影实验**——好的物探团队
把它当例行动作,而不是防御性 disclaimer。

**走廊三警告**(共用):

1. 无工艺元数据不入库:先过 03 章三问,再谈计算

## 5. 工程师落点(把这门学科带回家)

- **仪器眼→一切传感数据**:性能剖析的观测开销、APM
  探针的插桩代价,就是击数里的锤效——**先扣观测开销,
  再谈系统行为**;没有「空载基线」的测量平台和没有 ER
  的 N 一样,是半个数
- **扰动眼→采样式观测**:取样改土样,采样改系统——
  低开销采样(像薄壁取土器压面积比)优于粗暴全量插桩;
  观测者效应要入预算,不装看不见
- **信息眼→监控点部署**:传感器布在方差最大处(哪里
  最不知道,就在哪测),不是均匀网格——**贪心布孔是
  一切「有限探针怎么摆」问题的母模型**(律3 直接平移)
- **链眼→数据管道设计**:原始读数与校正参数分开存、
  校正可重放——数据平台的 N60 时刻会在十年后到来,
  那时你存的是资产还是债务,取决于今天有没有把 ER
  存进去

## 📌 收束

走廊三条:C1 变点分层与校正链(已成)管「读数怎么变成
可比的证据」,C2 布孔优化(教学版已成)管「取证的钱花
在哪」,C3 最小反演管「间接证据怎么猜得有纪律」;三条
共用一条边界——**解译、评定、先验、权衡永远留在人与
程序那边**。跑到这里回头再看 00 章那句话:地下不给答案,
只给证据;代码算的是证据的算术,把证据变成判断的,
始终是下一站的[工程地质学](../讲透工程地质学/README.md)。

**🧠 认知升维**:

- **变点眼**:分层的本质是变点——界面住在统计量的峰上,
  不住在眼力上
- **旋钮眼**:窗长、正则化、相关长度都是「先验强度」
  旋钮——调参就是在申报你相信什么
- **方差眼**:不知道的地方标方差——把不确定性当一等
  公民管理,是主动勘察与被动合规的分水岭
