## ✨ 这支最美的一个事实

**五个动作,三倍砌砖**(00 章故事框二)。吉尔布雷斯把砌
一块砖的动作从 18 个减到约 5 个,每小时砌砖数从约 120 块
升到约 350 块(通说)——工人没有更用力,是**弯腰与多余
抓取被设计掉了**。这支的哲学浓缩于此:先取消再合并再
重排,最后才轮到简化——给烂流程上机器人,是给浪费买加速器。
