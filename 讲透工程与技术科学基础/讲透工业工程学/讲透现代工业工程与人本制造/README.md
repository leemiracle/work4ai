## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 从至表 | 单位间流量的账本——布局目标 Σ流量×距离 的输入(SLP,通说) |
| 总移动量 | Σ流量×距离——布局版本可比的唯一标尺 |
| 数字孪生 | 车间的实时数字镜像——布局与节拍先在孪生里试错再动真线 |
| Industry 5.0 | 欧盟 2021 议程:人本/韧性/可持续——效率从目的降为约束之一(通说) |
| Human Digital Twin | 操作员的可计算映像(状态/行为/技能)——人本中心基石技术(检索校准 2026-09-07) |
