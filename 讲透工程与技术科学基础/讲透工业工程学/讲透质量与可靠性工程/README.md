## 招牌概念

| 概念 | 一句话 |
|------|--------|
| 常识原因/可查原因 | 过程固有噪声(忍住别管)对外来干扰(去查)——控制图的存在理由 |
| 控制限 | 过程自身统计特性的边界(3σ)——回答「过程变了没」,不是「产品合格没」 |
| 过程能力 Cp/Cpk | 公差带/过程分散(含对中修正)——**前提是过程受控** |
| PDCA | 计划-执行-检查-处置(承休哈特,戴明推广,通说)——改善的语法 |
| 浴盆曲线 | 早期/随机/耗损三段失效(通说)——可靠度的全生命周期 |

## ✨ 这支最美的一个事实

**一张图管住干预的手**(00 章故事框四/美之时刻②)。
1924 年 5 月 16 日,休哈特在备忘录里画出第一张控制图
(通说):把波动分成「过程自己的声音」与「外来的信号」,
点在限内,忍住别动。**对噪声动手就是制造噪声**——勤快的
管理与有效的管理被一条 3σ 界限分开;此后一切「告警阈值」的
监控(SRE/风控/质检)都是这张图的后代。
