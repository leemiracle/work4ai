## 2. 核心思维模式

| 模式 | 操作 |
|------|------|
| **翻译链眼** | 任何器件先拆链:效应→器件→工艺→系统→产业;断链在哪环,瓶颈就在哪环 |
| **工况眼** | 实验室性能≠产品性能——温度/噪声/老化/良率四关;规格书外的断言无据 |
| **批次眼** | 一切参数有统计身份:典型/最小/分布;英雄器件进不了规格书 |
| **预算眼** | "不可能"分两栏:物理极限还是工艺现状?源+合成+余量的封闭账本是分辨工具 |
| **阈值眼** | 冗余先测阈值:低于逐级压低、高于逐级放大;阈值=噪声谱×码的联合属性,随噪声类型偏移 |
| **通道眼** | 噪声=独立可参数化的通道;指数衰减相乘律(1/t_eff=1/t1+1/t2)是签名 |
| **阶梯眼** | 器件断言分五级:原理/仿真/单器件/批次/鉴定(E1-E5),收断言先看级 |
| **追溯眼** | 性能是造出来的——指标背后有工艺链,链上每步要有量测点 |

## 3. 工具箱(何时用什么)

- **翻译链五问**(00 章):效应能否封装/工况能否扛住/
  复制能否上量/平台能否通用/噪声能否工程化——先分诊
  再谈方法
- **五证据证书学**(02 章):E1-E5 阶梯+三语法规则
  (工况声明/统计身份/预算封闭)——收器件断言先看级
- **schema 三件套**(03 章):器件参数卡+误差预算表+
  工艺链契约;入库三问:工况写全了吗/统计身份定了吗/
  账本封闭了吗
- **量子比特噪声实验**(`experiments/qubit_noise.py`):
  保真度指数衰减(合成率互证)→重复码低于阈值逐级
  压低(0.1→0.028→0.0023)、高于阈值逐级放大
  (0.6→0.648→0.715)→阈值随噪声偏置偏移(0.5→
  ≈0.83)——三分钟把阈值工程与证据纪律全部落成数
- **走廊三条**(04 章):C1 量子比特噪声(已成)/C2
  器件速率方程(激光阈值)/C3 误差预算(RSS vs 最坏值)

## 4. 常见误区与禁忌

- ❌ **把"原理允许"当"工程不远"**:概念到量产隔着
  材料纯度十七年(Lilienfeld,00 章反直觉①);E1 与
  E4 之间隔着整条翻译链
- ❌ **拿英雄器件当产品**:单件破纪录≠批次分布;统计
  身份不明的参数是半张合同(02 章规则二)
- ❌ **工况外推**:规格书之外的行为无据——封装假设的
  泄题区;新工况重走鉴定(02 章规则一)
- ❌ **阈值之上加冗余**:悬崖不是斜坡——高于阈值冗余
  放大误差(家族实验断言②);先测阈值再谈冗余收益
- ❌ **不封闭的误差预算**:漏列噪声源≠保守,=失效;
  合成方式(RSS/最坏值)不写明,账本没法复算
- ❌ **仿真冒充实测**:未标定的 TCAD/噪声模型是循环
  论证;量子器件评审的头号争论正在这一级(01 章)
- ❌ **量子技术做商业/国防引申**:按工程学科进展中性
  呈现(家族写作红线)
