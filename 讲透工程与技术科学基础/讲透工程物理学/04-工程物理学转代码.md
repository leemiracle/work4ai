# 04 · 工程物理学转代码——噪声·速率方程·预算的走廊

> **本章回答五问之 Q5(问题→代码转换)。**
> **本质一句话**:工程物理问题一旦变成"关于噪声通道的
> 演化与纠错、器件速率方程的积分、误差预算的合成"的
> 计算,就能进代码——保真度可仿真、阈值可扫描、起振
> 条件可积分、预算可封闭;**唯一不可外包给代码的,是
> 噪声模型的选取**(哪种噪声占主导要实测,03 章噪声谱
> 字段)、**工况与验收的裁定**(证据归 02 章阶梯与鉴定,
  不归仿真)与**工艺窗口的实验判定**。

---

## 0. 开篇:一个量子比特,代码自己说

「都说纠错要"低于阈值",阈值到底是什么?超了会怎样?」
——`experiments/qubit_noise.py` 让代码回答:单量子比特
在退相干(t1)与比特翻转(t2)两通道参数化下演化,
蒙特卡洛逐发采样,保真度随时间精确指数衰减,合成率
1/t_eff=1/t1+1/t2(两独立通道的指数相乘,解析与仿真
互证到千分位);换成 3 比特重复码多数表决:物理误差
0.1 时逻辑误差压到 0.028,级联再压到 0.0023——**低于
阈值,冗余逐级换精度**;物理误差 0.6 时 0.648、级联
0.715——**高于阈值,冗余逐级放大误差**;再把噪声从
纯比特翻转换成混合(偏置 0.6),按总误差率测得的阈值
从 0.5 移到约 0.83——**阈值随噪声类型偏移,工程余量
要按实测噪声谱重标**。一条脚本把 00 章假设三与 02 章
证据纪律全部落成可复现的数。

## 1. 可机械化边界(三件套之一)

**能进代码的**(器件数据化后的一切计算):

| 任务 | 机械化形式 |
|------|-----------|
| 噪声通道演化 | 概率通道的蒙特卡洛/解析合成(家族实验) |
| 纠错与阈值扫描 | 重复码多数表决+级联+阈值二分搜索 |
| 器件速率方程 | 常微分方程数值积分(定步长 RK)/稳态解 |
| 链路与误差预算 | 独立源合成(RSS/最坏值)+余量计算(C3) |
| 可靠性统计 | 分布拟合/加速寿命外推(模型假设必附) |
| 工艺量测数据分析 | 控制图/窗口标定的统计计算 |

**不能进代码的**(工程物理学的"不可判定域"):

1. **噪声模型的选取**——热噪声还是退相干占主导、
   偏置多大:这是测量问题(03 章噪声谱字段),代码只
   对已声明的噪声模型算,不裁定模型对错
2. **工况与验收的裁定**——E4/E5 级证据要实测与鉴定;
   仿真级(E3)冒充验收是 02 章阶梯的头号误用(量子
   器件领域正在发生的争论,01 章)
3. **工艺窗口的判定**——窗口两侧的失效边界要实验
   设计(DOE)喂出来,仿真的窗口是模型的窗口
4. **良率的先验**——总良率=各步连乘的估算是账本,
   真值要拿晶圆喂(00 章假设二)

> 边界的一句话:**代码是器件的验算台与噪声的试验场,
> 不是验收官。**

## 2. C1 量子比特噪声走廊(✅ 已实现)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| 通道模型 | 比特翻转 p_b(t)+相位翻转 p_d(t),独立参数化 | t1/t2 各管一条通道;相关性未建模(声明在案) |
| 演化 | 逐发蒙特卡洛,固定随机种子 | 单发无意义,统计才说话;种子固定=可复现 |
| 解析互证 | F(t)=(1+e^(-t/t_eff))/2,1/t_eff=1/t1+1/t2 | 独立通道指数相乘;仿真对解析差<1%(E3 对 E1 自检) |
| 纠错 | 3 比特重复码多数表决+二级级联 | 只护 X 通道;级联递推 P→3P²-2P³ |
| 阈值 | 网格扫描+交叉点定位 | 纯比特翻转阈值=0.5(解析精确);MC 有统计涨落,容差声明 |

成品=`experiments/qubit_noise.py`。**改噪声换一行参数,
改码距换一个函数**——03 章 schema 分离的好处:噪声谱
(输入)与纠错结构(设计)分居两列,阈值实验就是在两列

## 3. C2 速率方程走廊(器件的动力学)

激光器的最小完整动力学是两条速率方程(光子数 P 与载流子
数 N),工程问题是**起振条件与稳态**:

```python
# 教学版速率方程:dN/dt = I/q - N/tau - G(N)·P;dP/dt = (G(N) - 1/tau_p)·P
def step(N, P, I, dt, tau, tau_p, gain):
    G = gain(N)                       # 增益随载流子数增长
    N1 = N + dt*(I/1.0 - N/tau - G*P) # 载流子:注入-复合-受激消耗
    P1 = P + dt*(G - 1.0/tau_p)*P     # 光子:增益超过损耗即起振
    return N1, P1
# 断言风格:阈值之上 P 随 I 线性增长,之下 P≈0——
# "阈值电流"就是 G(N)=1/tau_p 的那个 N 对应的注入
```

要点:其一,**阈值是方程的不动点性质**,不是拟合出的
经验数——增益=损耗一行定生死;其二,定步长积分要看
稳定性(步长过大数值自激,与激光器物理自激撞脸——
先排查步长再谈物理);其三,半导体器件方程(漂移-扩散)
的数值本体在
[工程数学家族](../讲透工程数学/04-工程数学转代码.md),
本家族管器件侧的方程与指标。理论本体(受激辐射/能级)
见[物理学宇宙·光学](../../讲透物理学/讲透光学/README.md)。

## 4. C3 误差预算走廊(账本的机械化)

```python
# 封闭账本:独立源+合成方式+余量三段齐全(03 章 schema)
def budget(sources, spec, mode="rss"):
    total = (sum(s**2 for s in sources) ** 0.5) if mode == "rss" \
            else sum(sources)                      # RSS 或最坏值,必填
    margin = spec - total                          # 余量单独一行
    return total, margin
# 断言风格:margin>0 才放行;mode 换成 worst_case 重算一遍——
# 两种合成的差值就是"统计独立性假设"的价格
```

要点:其一,**合成方式是合同条款**——RSS 假设源独立,
最坏值假设齐坏;两者的差距就是独立性假设的价格,预算
表必须能两种都算;其二,量子版把 spec 换成纠错阈值、
sources 换成各门误差源——**与阈值的余量**是新的货架
指标(01 章方向三);其三,漏列源的预算跑不出错(代码
只算你列的)——封闭性是人的义务,代码只是算盘。

**走廊三警告**(共用):

1. 仿真证据是 E3 级:噪声模型没实测标定前,一切阈值
   结论是"模型的结论"不是"器件的结论"
2. 蒙特卡洛的统计涨落要声明:试验数×容差,交叉点定位
   的误差棒与结论一起交付
3. 随机种子固定=可复现,但**换种子结论漂移超过容差
   说明试验数不够**——先加试验数,再谈物理

## 5. 工程师落点(把这门学科带回家)

- **误差预算表通吃一切工程**:软件系统的延迟预算/
  机器学习训练的不确定性来源/项目工期的风险分解——
  "独立源+合成+余量"三段式是通用文体,高锟账单
  (00 章故事框三)是范本
- **阈值思维→过载设计**:系统在标称负载外多少还能撑
  (headroom)=离阈值的余量;纠错阈值的悬崖提醒:
  余量不是线性的,接近阈值时加冗余先变毒药(与
  [工程力学](../讲透工程力学/04-工程力学转代码.md)
  的安全系数眼对表:那边线性保险,这边悬崖结构)
- **噪声谱先行→可观测性工程**:先测噪声占主导的来源
  再对症下药——性能工程里的 profiling(先测量再优化)
  与噪声表征是同一句方法论,反例是"没有谱的调参"
- **对性能工程的接口**:量子纠错的开销-余量权衡、
  器件良率的连乘链、误差预算的 RSS 合成,与系统的
  冗余设计/容量规划/尾部延迟分析同构——翻译链的
  思维方式比量子本身更可迁移

## 📌 收束

走廊三条:C1 量子比特噪声(已成)管"噪声怎么演化、
纠错何时有效",C2 速率方程管"器件何时起振、稳态在哪",
C3 误差预算管"余量还剩多少";三条共用一条边界——
**噪声模型选取、验收裁定、工艺窗口判定永远留在人与
实测那边**。跑到这里回头再看 00 章那句话:四次翻译
链的机器都在走廊里,效应封装与工况的家务事一寸没动。

**🧠 认知升维**:

- **通道眼**:一切噪声是通道——独立、可参数化、可
  合成;指数衰减的相乘律是它的签名
- **阈值眼**:冗余先过阈值再谈收益——低于阈值逐级
  压低,高于阈值逐级放大;阈值随噪声类型偏移
- **账本眼**:预算的三段式(源/合成/余量)——写不清
  余量的设计不是设计,是愿望
