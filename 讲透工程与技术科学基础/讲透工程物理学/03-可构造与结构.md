# 03 · 可构造与结构——器件卡、误差预算与工艺链作为数据对象

> **本章回答五问之 Q4(可构造性与结构)。**
> **本质一句话**:工程物理学里"可构造"的不是物理效应,
> 而是**器件问题的三类数据对象**——器件参数卡是带工况
> 与批次身份的参数化结构,误差预算表是封闭的噪声账本,
> 工艺-结构-性能链是把"怎么造出来"写成可追溯的传递
> 契约;把这些结构显式化,器件开发就从手艺变成工程:
> 可校验、可对表、可交接(04 章走廊的地基)。

---

## 0. 开篇:一份"器件开发任务单"的三件结构化家具

拆开任何一次严肃的器件开发(新型激光器/量子比特工艺/
传感器量产),都能拆出三件家具:其一是**器件参数卡**
(器件怎么说话——参数、工况、批次身份),其二是**
误差预算表**(噪声怎么记账——独立源、合成、余量),
其三是**工艺链契约**(性能怎么被造出来——工序、参数、
窗口)。三件家具在手,00 章翻译链的每一环就变成**可
机检的数据流水线**;从晶体管到量子比特的四次翻译
(00 章节点表),在数据结构层面是同一套 schema。

## 1. 什么是"可构造"的:三类结构对象

| 对象 | 数化身 | 可构造性 | 构造中的坑 |
|------|--------|---------|-----------|
| **器件参数卡** | 参数+工况+批次身份(典型/最小/分布)+标定来源 | ✅ 高度可构造 | 工况缺行=半张合同(02 章规则一);单器件冒充批次 |
| **误差预算表** | 独立噪声源清单+合成方式(RSS/最坏值)+余量行 | ✅ 高度可构造 | 不封闭的预算(漏源/合成不明)没有证据力 |
| **工艺链契约** | 工序序列+每步参数+窗口+量测点(过程-结构-性能链) | ✅ 高度可构造 | 量测点缺失=链不可追溯;窗口拍脑袋=量产灾难 |
| **可靠性记录** | 应力条件+寿命数据+外推模型 | ✅ 可构造 | 加速外推藏模型假设(E4 的陷阱列) |
| **量子比特校准数据** | T1/T2/保真度×位置×批次+噪声谱表征 | ✅ 可构造(新) | 单比特校准不外推到阵列(00 章假设二的量子版) |

**不可构造的**:效应本身的物理真值(器件卡只装测量与
模型估计)、良率的先验值(要拿晶圆喂出来,00 章)、
失效的确切时刻(可靠性只有统计陈述)、以及"这支器件
今天的状态"(老化是路径依赖的,抽检≠全知)。

### 1.5 最小数据模式(动手者的 schema)

```yaml
# 器件参数卡(参数+工况+批次身份+来源成套出现)
device_card:
  params: {threshold_v: float, slope_eff: float}   # 例:激光二极管双参数
  envelope: {temp_range: [int, int], bias: float}  # 工况包络(必填)
  stats: {kind: typ|min|dist, spread: float}       # 批次身份(02 章规则二)
  source: bench|datasheet|tcad                     # 台架/规格书/仿真

# 误差预算表(封闭账本:源-合成-余量三段齐全)
error_budget:
  sources: [{name: str, value: float, unit: str}, ...]  # 独立源清单
  combine: rss|worst_case                           # 合成方式必填
  margin: float                                     # 余量单独一行(02 章规则三)

# 工艺链契约(过程-结构-性能三层映射)
process_chain:
  steps: [{name: str, params: {doping: float, thickness: float},
           window: [float, float],                  # 工艺窗口两侧都是失效
           metro: str}]                             # 量测点(追溯性)
  psp_map: str                                      # 过程→结构→性能映射记录

# 量子比特校准(01 章方向三的工程地基)
qubit_record:
  metrics: {t1_us: float, t2_us: float, fidelity: float}
  location: int                                     # 阵列位置(不外推,02 章)
  noise_spectrum: str                               # 噪声谱表征(阈值重标的根据)
```

注意 `envelope` 与 `stats` 两处必填:把 02 章的证书纪律
写进数据结构——**数据层自带校验点,是器件工程区别于
论文表格的第一特征**(承
[工程数学家族](../讲透工程数学/03-可构造与结构.md)
schema 同款精神)。

## 2. 骨架一:器件参数卡(参数的升格链)

- **升格链三级**:材料常数(能隙/迁移率,物理宇宙的
  领地)→器件参数(阈值/斜率效率,本家族的领地)→
  系统指标(功耗/误码率,系统工程的领地)——每升一级,
  自由度收窄一档、工况义务重一档;**器件物理的核心
  手艺就是管理这条升格链**:哪级参数能锁死、哪级必须
  留散布
- **典型值与分布双轨**:规格书给典型值,制造给分布;
  两轨并写(02 章规则二)——把"英雄器件"升格为"批次
  分布"是器件从论文走向产品的数据仪式
- **工况包络即合同边界**:包络外的一切性能断言无据
  (00 章假设一的泄题区);降额规范是包络的制度化

## 3. 骨架二:误差预算表(噪声的账本)

- **三段式**:独立源清单(热噪声/散粒噪声/暗计数/
  串扰/退相干……)→合成(RSS 或最坏值,方式必填)→
  **余量单独一行**——余量不是误差的尾巴,是设计的
  头寸(高锟式预算的骨架,00 章故事框三)
- **量子版**:保真度预算替代误码率预算(每门误差源
  列表+合成+与阈值的距离);**与阈值的余量是新的货架
  指标**(01 章方向三),随噪声谱重标(家族实验断言③)
- **账本的封闭性**:漏列一个源,预算不是"保守"而是
  "失效"——未知源恰好在 02 章 E4 实测时以神秘偏差的
  形式还债

## 4. 骨架三:工艺链契约(制造的可追溯性)

- **过程-结构-性能链**:工序参数(过程)决定微观形貌
  (结构)决定器件行为(性能)——器件物理学科的核心
  数据结构(00 章故事框二:提纯→单晶→掺杂→钝化就是
  第一条完整链);契约内容:每步的量测点把三层缝起来
- **窗口两侧都是失效**:工艺窗口不是公差,是两面悬崖
  之间的可行区;窗口标定要实验设计(DOE,通说),不
  是拍脑袋
- **量子器件的当代考场**:同轴量子比特到晶圆级阵列,
  工艺链从"手工校准"走向"统计过程控制"——良率语言
  (00 章假设二)正在接管量子制造(01 章方向二未决面)

## 5. 从结构到校验:这套骨架买到了什么

- 参数卡带工况与批次 → 性能断言有根(条件可查、身份
  可核)
- 预算表封闭 → 噪声结论可复算(独立于写它的人)
- 工艺链带量测点 → 失效可追溯(哪一步漂了能查)
- 校准数据带位置与噪声谱 → 阈值余量可重标(工程余量
  的根据地)

## 6. 构造合法性清单(动手前三问)

把任何器件构想变成数据结构之前,先过三问——本家族的
"类型检查":

1. **工况写全了吗**:温度/偏置/占空比/寿命条件各在哪
   一行?缺行的指标是脆弱断言
2. **统计身份定了吗**:典型值还是分布?单器件还是批次?
   英雄数据有没有偷偷混进规格?
3. **账本封闭了吗**:噪声源列表全不全?合成方式是什么?
   余量是多少——以及量子系统离阈值多远?

三问全过,数据才获得进入 [04 章走廊](04-工程物理学转代码.md)
的资格。**器件工程的第一特征不是巧妙,是账目清楚。**

## 📌 收束

可构造的是**三类数据对象**(器件卡/预算表/工艺链),
不可构造的是**效应真值与良率先验**;结构化不是为了替代
工程师,是为了让开发可校验、可交接、可复盘。下一章把
骨架接上代码:[04-工程物理学转代码](04-工程物理学转代码.md)。

**🧠 认知升维**:

- **身份眼**:一切参数有统计身份——典型/最小/分布,
  英雄与批次不得混写
- **账本眼**:噪声要记账——源、合成、余量三段齐全才
  叫预算;漏列即失效
- **追溯眼**:性能是造出来的——每一个指标背后有一条
  工艺链,链上每步要有量测点
