## ✨ 这支最美的一个事实

**概念可以等工艺十七年**(家族 00 章反直觉①)。利连费尔德
1930 年就取得场效应器件专利——与后来的 MOSFET 同宗;
但当时没有工艺能把半导体表面做干净,专利只能是纸面构想;
直到区域提纯把纯度推进近十个数量级(1950 前后),概念才
落地。**发现与应用之间隔着的不是灵感,是笨功夫**——这条
教训在量子器件上原样重演(单比特性能与阵列良率的落差)。
