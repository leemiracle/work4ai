## 四、实验

| 文件 | 用途 | 状态 |
|------|------|------|
| [experiments/qubit_noise.py](experiments/qubit_noise.py) | 量子比特噪声工程教学版(纯标准库):①单比特在退相干(t1)与比特翻转(t2)参数化下,保真度随时间精确指数衰减(合成率 1/t_eff=1/t1+1/t2,蒙特卡洛与解析互证),误差率对退相干时间单调 ②教学版 3 比特重复码多数表决:物理误差低于阈值时级联纠错逐级压低(0.1→0.028→0.0023),高于阈值反而逐级放大(0.6→0.648→0.715) ③阈值随噪声类型偏移:纯比特翻转阈值=0.5,混合噪声(偏置 0.6)按总误差率测得阈值移至≈0.83——纠错阈值不是材料常数,是"噪声谱×码"的联合属性,工程余量要按噪声类型重测 | ✅ |
