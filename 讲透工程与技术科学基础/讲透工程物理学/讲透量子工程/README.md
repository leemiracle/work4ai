## ✨ 这支最美的一个事实

**不完美的零件,完美的机器**(家族 00 章美之时刻①的量子
续篇)。阈值定理(1996-97,通说)说:只要每个物理量子比特
的误差率低于某阈值,冗余编码就能把逻辑误差压到任意小——
家族实验的最小标本:物理误差 0.1,3 比特多数表决压到
0.028,级联再压到 0.0023。**用更多会出错的东西,造出更
不容易错的整体**;而同一机制在阈值之上反向运行(0.6→
0.648→0.715 逐级放大)——悬崖先于收益。这与 1948 年
香农的有噪信道编码定理是同一思想的两次现身:**可靠性不是
零件给的,是结构给的**。
