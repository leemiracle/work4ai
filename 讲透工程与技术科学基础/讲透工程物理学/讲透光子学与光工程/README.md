## ✨ 这支最美的一个事实

**一篇论文的账单,四年拉出一根光纤**(家族 00 章故事框三)。
1966 年高锟与霍克姆算出:玻璃衰减若降到 20 dB/km 以下,
光通信就成立——当时通行判断"玻璃天生不透明"(实测约
1000 dB/km);论文说那是杂质问题,不是物理问题。1970 年
康宁做到约 17 dB/km,预算被击穿。这是**工程物理学独门
文体的诞生:把物理极限翻译成工艺指标**——今天量子光源
的损耗指标、纠错系统的阈值余量,走的都是这笔账的写法。
