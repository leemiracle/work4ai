## 1. 灵魂：拓扑决定行为

$$
\boxed{\text{拓扑} \neq \text{节点} \quad \Rightarrow \quad \text{同样的部件，换连线，行为完全不同}}
$$

- **规则网络**（格子图）：局部聚类高，但全局距离远
- **随机网络**（Erdős–Rényi）：距离短，但无结构
- **小世界**（Watts-Strogatz 1998）：**既局部聚类，又全局近距离**——真实网络的普遍特征
- **无标度**（Barabási–Albert 1999）：少数 hub 承载大部分流量——**幂律**度分布

> 🎯 **一句话**：复杂系统不是随机连接的，它有**特定的拓扑签名**——高聚类 + 短路径 + 幂律度分布。理解这个签名，才能理解为什么脑/互联网/社交网/神经网"长得像"。

## 2. 小世界：六度分隔的数学

### 2.1 Watts-Strogatz 模型（1998）

从一个 $N$ 个节点的**环形格子**开始，每个节点连 $k$ 个邻居（$k/2$ 左 $k/2$ 右）。然后以概率 $p$ **随机重连**每条边：

```
p=0（纯规则）        p=0.1（小世界）       p=1（纯随机）
 ○—○—○—○              ○—○—○—○              ○  ○  ○  ○
 |  |  |  |           \  ×    \              |\/|\/|\/|
 ○—○—○—○              ○—○—○—○              ○  ○  ○  ○
高聚类/远距离          高聚类/短距离          低聚类/短距离
```

### 2.2 两个核心度量

$$
L(p) = \text{特征路径长度} = \frac{1}{N(N-1)}\sum_{i \neq j} d(i,j)
$$

$$
C(p) = \text{聚类系数} = \frac{3 \times \text{三角形数}}{\text{连通三元组数}}
$$

- $L$ 小 = 任意两节点之间跳数少（全局"近"）
- $C$ 大 = 你朋友之间也彼此认识（局部"抱团"）

### 2.3 小世界现象（实验核心）

| 重连概率 $p$ | $L(p)$ | $C(p)$ | 解读 |
|:------:|:----:|:----:|:------|
| 0.0 | 大 | 大 | 规则格子：高聚类但远距离 |
| **0.01–0.1** | **骤降** | **几乎不变** | **★ 小世界：捷径让 $L$ 暴跌，但 $C$ 保持** |
| 1.0 | 小 | 小 | 随机图：短距离但无聚类 |

**反直觉**：只需重连 **1%** 的边，$L$ 就从 $O(N)$ 降到 $O(\log N)$，而 $C$ 几乎不变——**少数"捷径"重塑全局**。

```bash
cd experiments && python3 03_networks.py
```

实测输出（$N=1000, k=10$）：
```
p=0.000  L=50.0   C=0.667   [规则：远但抱团]
p=0.010  L=8.2    C=0.628   [小世界：L暴跌83%，C仅降6%] ← 拐点
p=0.100  L=3.6    C=0.392   [强小世界]
p=1.000  L=3.3    C=0.010   [随机：近但不抱团]
```

## 3. 无标度：幂律与 hub

### 3.1 Barabási–Albert 模型（1999）

**增长 + 优先连接**：网络不断加入新节点，新节点优先连到**已有连接数多**的节点（"富者愈富"）：

$$
P(\text{连到节点 } i) \propto \frac{k_i}{\sum_j k_j}
$$

结果是**幂律度分布**：

$$
P(k) \sim k^{-\gamma}, \quad \gamma \approx 3
$$

- 大部分节点度数低（叶子）
- 少数节点度数极高（**hub**）——承载大部分流量

### 3.2 幂律 vs 正态（实验对比）

| 网络 | 度分布 | 最大度 | 解读 |
|---|---|---|---|
| 随机图（ER） | 泊松（钟形） | ~$\log N$ | 有上限，无 hub |
| **无标度（BA）** | **幂律 $k^{-3}$** | ~$N^{1/2}$ | **无特征尺度，少数 hub 极大** |

**实测**（$N=1000$）：
```
随机图:   平均度=10, 最大度=28,  度>20的节点=1个
无标度:   平均度=10, 最大度=142, 度>20的节点=8个(hub)
```

### 3.3 hub 的后果：鲁棒与脆弱

- **对随机故障鲁棒**：随机删节点大概率删叶子，网络不断
- **对蓄意攻击脆弱**：删掉几个 hub，网络**碎片化**

这解释了为什么互联网"平时不断、被攻击就崩"、为什么脑损伤特定区域会失能。

## 4. 神经网络的拓扑

### 4.1 神经网络是什么图

一个 MLP 的计算图是**层间全连接的有向无环图**——不是小世界也不是无标度，是**规则分层图**。

但**训练后**呢？研究发现（Frankle & Carbin 2018 "Lottery Ticket Hypothesis"）：

> 训练好的网络里，存在一个**稀疏子网络**（"中奖彩票"），单独训练就能达到原网络性能。

这个子网络的拓扑——**接近小世界**（高聚类 + 短路径）。

### 4.2 剪枝 = 拓扑稀疏化

| 剪枝比例 | 保留连接 | 拓扑变化 | 性能 |
|:----:|:----:|:----:|:----:|
| 0% | 100% | 全连接（规则） | 基准 |
| 50% | 50% | 开始稀疏 | ≈ 不变 |
| 90% | 10% | 稀疏 + hub 涌现 | 略降 |
| 99% | 1% | 极稀疏（彩票）| 仍可用（如果选对）|

**洞察**：训练后的有效网络不是全连接的，是**稀疏的、有小世界特征的**。这与脑皮层网络（也稀疏 + 小世界）同构。

### 4.3 架构搜索 = 拓扑优化

NAS（Neural Architecture Search）本质上是在"网络拓扑空间"里搜索——哪些层连哪些层、哪里加 skip connection。ResNet 的 skip = 加捷径 = **人为制造小世界效应**。

## 5. 批判性：模型简化了什么

- **WS/BA 是生成模型，不是真实网络**：真实网络（脑/互联网）的形成机制比"重连/优先连接"复杂得多
- **幂律的 $\gamma$ 不总是 3**：真实网络 $\gamma \in [2,3]$，BA 模型固定 3，太理想化
- **小世界不等于高效**：短路径存在 ≠ 信息真的走最短路径（路由协议、注意力机制可能不用捷径）
- **网络科学是"描述性"的**：它能测量拓扑，但**难以预测**——知道是小世界，能推出动力学吗？部分能（同步阈值），但不完整

> **诚实结论**：网络科学给了我们"拓扑透镜"，但它更像**分类学**（描述网络长什么样）而非**力学**（为什么这样演化）。后者仍开放。
