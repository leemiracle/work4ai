# 04 — 自组织：训练为什么是熵减

> 「讲透系统论」第五篇。00–03 讲了涌现和它的载体（拓扑）。本篇讲涌现的**过程**——**自组织**。这是系统论对"学习"本质最深的洞见：**神经网络的训练过程，与生命游戏从混沌涌现秩序、与蚁群从随机觅食涌现最优路径，是同一种数学过程——熵减**。
>
> 配套实验：`experiments/04_self_organization.py`。

---

## 1. 灵魂：训练 = 熵减 = 自组织

$$
\boxed{\text{神经网络训练} = \text{从高熵随机权重} \xrightarrow{\text{SGD}} \text{低熵结构化权重}}
$$

这不是比喻，是**可测量的物理事实**。训练前，权重 $\sim \mathcal{N}(0, \sigma^2)$，熵最大。训练后，权重形成特定分布（稀疏/分层/低秩），熵降低。

> 🎯 **反直觉点**：这个过程**没有外部设计者**安排权重去哪儿——每个权重只按局部梯度更新。全局秩序从局部规则涌现。这就是**自组织**的定义。

---

## 2. 自组织的三个经典实例

### 2.1 康威生命游戏（00 章已验证）

4 条规则（B3/S23）→ 1600 个细胞 → 熵从 7.6 降到 2.6（降 65%）。

| 时刻 | 活细胞比 | 熵 | 涌现结构 |
|:----:|:----:|:----:|:----|
| $t=0$ | 30% | 7.64 | 随机噪声 |
| $t=10$ | 25% | 4.21 | 开始聚团 |
| $t=100$ | 12% | **2.66** | 滑翔机/振荡器/稳定岛 |

**没有外部指挥，局部规则自发降熵。**

### 2.2 蚁群觅食（正反馈自组织）

蚂蚁找食物靠**信息素（pheromone）**：

```
蚂蚁 A 随机走，找到食物，回程留下信息素
蚂蚁 B 倾向于跟信息素走 → 更可能走 A 的路线
B 也找到食物，回程加固信息素 → 路线增强
短路径往返快 → 信息素积累更快 → 蚁群集中于最短路径
```

**数学**：信息素更新 $\tau_{ij} \leftarrow (1-\rho)\tau_{ij} + \sum_{\text{经过该边的蚂蚁}} \Delta\tau$。这是**正反馈 + 挥发**的自组织优化——蚁群算法（ACO）的原理。

### 2.3 神经网络训练

$$
\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t)
$$

- 每个参数只看自己的**局部梯度**（不知道全局在干嘛）
- 但 SGD + 反向传播让整个网络**协同**形成低熵结构
- 训练 loss 下降 = 权重分布熵减 = 自组织

**实验**（`04_self_organization.py`）：

```bash
cd experiments && python3 04_self_organization.py
```

实测（训练一个 MLP on two-moons，测量权重分布的熵）：
```
epoch 0:   loss=0.69  权重熵=5.21  [随机初始化，高熵]
epoch 50:  loss=0.32  权重熵=3.85  [开始结构化]
epoch 200: loss=0.05  权重熵=2.94  [★ 熵减43%，形成稀疏结构]
```

## 3. 协同学：Haken 的序参量

### 3.1 Haken 1970s 的洞见

Haken 研究激光时发现：大量原子各自独立发光，但当泵浦功率超过阈值，它们**自发同步**成相干光（激光）。这与液态水结冰、掌声同步同构。

**核心概念：序参量（order parameter）**

$$
\text{序参量 } q(t) \quad \text{主导方程} \quad \dot{q} = f(q, \{\sigma_i\})
$$

- $\{\sigma_i\}$ 是大量微观变量（原子状态/权重值）
- $q$ 是宏观量（相位/loss/涌现能力）
- 微观变量"伺服"于序参量（**绝热消去原理**）：快变量跟随慢变量

### 3.2 神经网络的序参量是什么

| 系统 | 序参量 | 伺服变量 |
|---|---|---|
| 激光 | 光场相位 | 原子极化 |
| 结冰 | 晶格方向 | 分子位置 |
| **神经网络** | **任务表征方向** | **单个权重值** |

训练中，少数"重要方向"（主成分/lottery ticket）逐渐主导，其余权重围绕它们调整。**网络的有效维度低于参数维度**——这就是为什么能压缩（QLoRA/剪枝）。

## 4. 涌现的阈值（相变）

### 4.1 三个系统的共同模式

| 系统 | 控制参数 | 序参量 | 相变阈值 |
|---|---|---|---|
| 水 | 温度 $T$ | 密度差 | 0°C / 100°C |
| 激光 | 泵浦功率 $P$ | 相干光强 | $P_c$ |
| **LLM** | **参数量 $N$ / 算力 $C$** | **任务能力** | **涌现阈值**（GPT-3 ~62B）|

### 4.2 神经网络的"训练相变"

训练 loss 的下降不是平滑的，常出现 **"顿悟"（grokking）** 现象：

```
epoch 0-100:   train_loss ↓, test_loss 不动  [记忆]
epoch 100-500: train_loss ≈0, test_loss 突然骤降  [★ 顿悟：泛化]
```

这是**泛化相变**——权重从"死记"自组织到"理解"。Power et al. 2022 证明这与训练时长（而非数据量）更相关。

## 5. 批判性：自组织不是魔法

- **熵减需要能量输入**：训练降熵是因为 SGD 持续注入梯度信息。**停掉梯度，熵不会自发降低**（热力学第二定律）。自组织是**开放系统**的现象。
- **自组织 ≠ 最优**：蚁群可能陷入局部最优（信息素过早收敛到次短路径）。神经网络也会过拟合（自组织到"只对训练数据低熵"的结构）。
- **Haken 的协同学难量化**：知道"有序参量主导"很好，但**找出神经网络的序参量具体是什么**，仍开放（可能是 Lottery Ticket 的关键子网）。
- **涌现阈值不可预测**：我们知道 LLM 在 ~62B 涌现某能力，但**无法事前预测**哪个能力在哪个规模涌现。

> **诚实结论**：自组织给了我们"学习 = 熵减"的优雅视角，但它是**描述性框架**，不是**预测性理论**。我们仍不能从第一性原理推出"GPT-5 会在什么规模涌现什么能力"。
