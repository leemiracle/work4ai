## 实验索引

### `01_3d_conv_vs_2d_temporal.py` ★ —— 验证轴①（时间耦合）

**验证**：3D 卷积看见运动，2D 对时间无感。

```python
conv3d = nn.Conv3d(1, 8, kernel_size=(3,3,3), padding=(1,1,1))   # 224 参数
conv2d = nn.Conv2d(1, 8, kernel_size=(3,3), padding=(1,1))       # 80 参数
# 关键检验: 对"倒放再倒"的不变性
#   2D: out_fwd == flip(out_rev, time)  → 差异 ≡ 0
#   3D: 差异 > 0
```

**实测结果**：
```
[参数量] 3D Conv: 224  |  2D Conv: 80  (2.8x)
[顺序敏感性] 3D Conv: 差异 = 0.0134  (>0: 顺序敏感)
             2D Conv: 差异 = 0.00e+00  (每帧独立, 无视顺序)
```

> 这就是 C3D / I3D 存在的理由：**必须跨时间耦合才能看见运动**。对应 [05-视频理解路线](05-视频理解路线.md) §2。

### `02_tubelet_embedding.py` —— 验证视频 tokenizer

**验证**：视频如何变成一串 token（Conv3D 一步完成）。

```python
tubelet = nn.Conv3d(C, embed_dim, kernel_size=(t,h,w), stride=(t,h,w))
tokens = tubelet(video)   # (1, embed_dim, T', H', W')
```

**实测**：16×224×224 视频 → 1568 个 tubelet token。**这是所有视频 Transformer 的输入层标准**，也是 Sora 潜空间压缩的基础。

### `05_optical_flow.py` —— 验证显式运动表示

**验证**：Lucas-Kanade 光流，及其线性化局限。

```python
# 亮度守恒: I2(x) ≈ I1(x-d), 一阶泰勒 → 局部最小二乘解 d
A = np.stack([Ix_w, Iy_w], axis=1)
d = np.linalg.lstsq(A, -It_w)[0]
```

**实测**：真值位移 (2,1)，LK 估计 (0.74, 0.39)——**低估**。这正是大位移下线性化失效的经典失败，解释了为什么需要金字塔 LK，以及为什么现代模型转向隐式运动学习。
