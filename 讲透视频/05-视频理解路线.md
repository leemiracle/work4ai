# 05 · 视频理解路线：从 C3D 到 V-JEPA 的十年演进

> **一条线讲透**：人类怎么让机器"看懂"视频？这是 2014–2025 的主线故事——每一步都在回答同一个问题：**时间维度该怎么融进来？** 答案的演进，就是理解模型的演进。

每个里程碑都在解决前一个的痛点：

| 年份 | 模型 | 解决的痛点 | 引入的新痛点 |
|---|---|---|---|
| 2014 | **Two-Stream** | "怎么看见运动" → 加光流腿 | 光流要预计算，慢 |
| 2014 | **C3D** | 不要光流，让卷积自学运动 | 3D 参数多、数据少难训 |
| 2017 | **I3D** | "3D 没数据" → 用 2D 预训练膨胀 | 仍是局部时间感受野 |
| 2019 | **SlowFast** | "单时间尺度不够" → 快慢双路 | 模型更复杂 |
| 2021 | **TimeSformer/ViViT** | "卷积局部" → 注意力全局 + 可继承 ViT | 注意力 $O(N^2)$ 太贵 |
| 2022 | **VideoMAE** | "标注贵" → 自监督掩码预训练 | 仍是像素级 |
| 2025 | **V-JEPA 2** | "像素≠理解" → 潜空间预测 | 训练更难防坍塌 |

## 1. 2014 Two-Stream：双腿走路（光流登台）

### 直觉
视频信息有两种：**外观**（单帧就能认的"是什么"）和**运动**（跨帧才能认的"怎么动"）。Two-Stream 用两条独立的网络分别处理，最后融合。

- **空间流**：单帧 RGB → CNN → 外观特征。
- **时间流**：连续多帧的**光流**堆叠 → CNN → 运动特征。
- **融合**：两类 log平均 / 或加一个融合网络。

### 为什么是里程碑
第一次明确**把"运动"作为一等公民**喂给网络。但它依赖**预计算光流**——每个视频要先跑一遍光流算法（FlowNet/RAFT），慢且不端到端。

### 它落在哪里
- **轴①**：2D 卷积（无显式时间耦合，时间信息全靠光流输入）。
- **轴④**：**显式光流**——这是它最鲜明的特征。

> 现代（2020+）模型基本抛弃了显式光流，但 Two-Stream 的"外观+运动双流"思想，以**隐式形式**活在 SlowFast（双通路）和很多模型里。见 [`experiments/05`](experiments/05_optical_flow.py) 感受光流鼻祖 Lucas-Kanade。

## 2. 2014 C3D：让卷积自己学运动

### 直觉
别再依赖预计算光流了。把卷积核从 $(k,k)$ 升级成 $(t,k,k)$ 的**3D 立方核**，让它**自己学会**捕捉运动——端到端。

### 关键公式
$$
Y[t,h,w,c'] = \sum_{\Delta t,\Delta h,\Delta w,c} W[\Delta t,\Delta h,\Delta w,c,c'] \; X[t+\Delta t, h+\Delta h, w+\Delta w, c]
$$

3D 卷积在时间和空间上**联合滑动**，天然耦合时空。**实验 [`01`](experiments/01_3d_conv_vs_2d_temporal.py) 证明：3D 卷积对时间倒放敏感（差异 0.0134），2D 精确为 0。**

### 痛点
- 3D 核参数是 2D 的 $t$ 倍（实验：224 vs 80，2.8×）。
- **3D 视频数据少**，从头训不好 → 引出 I3D。

## 3. 2017 I3D：用 2D 预训练初始化 3D

### 直觉
ImageNet 上有海量 2D 预训练权重。把它们**膨胀**（inflate）成 3D：$W_{k \times k} \to W_{t \times k \times k}/t$（沿时间复制再归一化），就能继承 2D 的强初始化。

### 意义
解决了"3D 数据少"的鸡生蛋问题——**用现成的 2D 知识启动 3D 学习**。I3D 在 Kinetics 上长期作为强 baseline。

### 派生：R(2+1)D 与 SlowFast
- **R(2+1)D**（2018）：把 3D 卷积**分解**成"空间 2D + 时间 1D"，参数更少、非线性更多——**这是"因子化"思想在卷积族的体现**（对应注意力族的 TimeSformer）。
- **SlowFast**（2019）：**双时间分辨率**——慢通路（4 fps、宽通道，看语义）+ 快通路（16 fps、窄通道，看运动），仿生视觉 P/Q 通路。在 Kinetics 刷爆 SOTA。

## 4. 2021 TimeSformer / ViViT：Transformer 接管视频

### 直觉
ViT 在图像上成功 → 视频也用 Transformer。但视频 token $N = T \cdot H' \cdot W'$ 很大，全注意力 $O(N^2)$ 吃不消。于是**因子化**。

### TimeSformer 的四种时空注意力分解
TimeSformer 论文系统对比了：
1. **Space-only**（基线，不跨时间）
2. **Joint Space-Time**（全时空，贵）
3. **Factorized Divided**（先空间后时间，每层分开）★ 最优性价比
4. **Sparse Local Global**（局部+全局混合）

结论：**Divided（因子化）性价比最高**。

### ViViT 的三种模型
ViViT 提出了三种分解策略 + **Tubelet 嵌入**（把视频切成 $t{\times}h{\times}w$ 小管子，Conv3D 一步成 token）：
- **Model 1**：Factorised Encoder（先空间 Transformer 编码每帧，再时间 Transformer 聚合）。
- **Model 2**：Factorised Self-Attention（每层内部分空间/时间）。
- **Model 3**：全时空（贵但强）。

### 关键数字（来自实验 03）
| 规模 (T×H×W) | 全时空 GFLOP | 因子化 GFLOP | 加速 |
|---|---|---|---|
| 16×16×16 | 12.9 | 0.86 | **15×** |
| 32×16×16 | 51.5 | 1.81 | **28×** |

> 见 [`experiments/03`](experiments/03_temporal_attention.py)。

## 5. 2022 VideoMAE：自监督预训练的王者 ★

### 直觉
视频标注极贵（动作标签难标）。**VideoMAE 把图像 MAE 的掩码自编码搬过来**：随机遮掉大量 tubelet，只编码可见的，再重建被遮像素。这样能用**无标签**海量视频预训练。

### 关键技巧：极高掩码率
- 图像 MAE 遮 75%；**VideoMAE 遮 90%**。
- 为什么能遮这么多？**视频时空冗余极高**——相邻帧太像，遮少了网络直接复制邻居就行，学不到东西。遮 90% 才逼它学真正的时空表示。

### 形式
$$
\mathcal{L}_{\text{VideoMAE}} = \frac{1}{|\mathcal{M}|}\sum_{i \in \mathcal{M}} \|X_i - \hat X_i\|^2
$$
其中 $\mathcal{M}$ 是被遮的 tubelet 集合（90%）。只对被遮位置算 loss（非对称）。

### 地位
**当前视频理解的事实标准预训练方法。** VideoMAE V2（2023）进一步 scale up + 多模态数据，刷爆多个 benchmark。下游：加个分类头做动作识别，或接 LLM 做视频问答（VideoLLaMA）。

### 轴定位
- **轴①**：因子化注意力。
- **轴③**：掩码生成（MIM）。

## 6. 2024–2025 V-JEPA / V-JEPA 2：奔向世界模型 ★

### 直觉（LeCun 路线）
VideoMAE 在**像素**层重建——LeCun 认为像素太嘈杂、太底层，学到的是"模式匹配"不是"理解"。**V-JEPA 在抽象潜空间预测**：遮住一段视频的潜表示，让模型预测它，但不要求重建像素。

### 关键机制
1. 用 **Siameses 双塔**：student 编码可见部分，teacher（EMA 更新）编码完整/被遮部分。
2. 在潜空间预测被遮区域的表示 $\hat r_{\text{mask}} \approx r_{\text{mask}}$。
3. **不重建像素** → 学到更抽象、更"语义"的表示。

### V-JEPA 2（2025）：从表示学习到世界模型
> 📄 **arXiv:2506.09985**（2025-06-11）——已核实

V-JEPA 2 把这个思想推到**动作条件预测**——给定当前状态 + 动作，预测未来潜状态。**已核实的关键数字**：

- 预训练于 **>100 万小时**互联网视频（无动作 JEPA 目标）；
- 运动理解 Something-Something v2 **77.3** top-1；
- 动作预期 Epic-Kitchens-100 **39.7** recall@5（超任务专用模型）；
- 对齐 LLM 后（8B 规模）视频 QA：PerceptionTest **84.0** / TempCompass **76.9**；
- **V-JEPA 2-AC**（动作条件版）：仅 **<62 小时**无标注机器人视频后训练，**零样本**部署到两个实验室的 Franka 机械臂做抓放规划——无任务训练、无奖励函数。

这让它能用于**机器人规划**（在潜空间想象动作后果）。Meta 宣称这是迈向"理解物理世界"的一步。

### 争议
LeCun 派 vs 像素生成派（Sora）的根本分歧：
- **LeCun**：像素生成注定学不到抽象，潜预测才对。
- **Sora 派**：足够大的像素生成模型会"涌现"出世界理解。

## 7. 视频理解 × LLM：视频问答与对话

2023+ 的另一条线：**视频大语言模型**——把视频编码器输出喂给 LLM，让模型"看视频聊天"。

- **VideoLLaMA / Video-LLaVA / VideoChat**：视频编码器（VideoMAE/CLIP-ViT）→ projector → LLM。
- **LongVU**（2024）：解决长视频（小时级）的 token 过多问题，用 DINOv2 的显著性做时空剪枝。
- 本质：**视频 token 是另一种"语言"**，LLM 学会处理它——见 [`讲透多模态`](../讲透多模态/)。

## 一句话总结

> 🎯 **视频理解的十年 = "时间怎么融进来"的四种回答**：① 显式光流（Two-Stream）→ ② 3D 卷积自学（C3D/I3D）→ ③ 注意力因子化（TimeSformer/ViViT）→ ④ 自监督掩码（VideoMAE）→ ⑤ 潜预测（V-JEPA）。每一步都在前一步的痛点上迭代。
