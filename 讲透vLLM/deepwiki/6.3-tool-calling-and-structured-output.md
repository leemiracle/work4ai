This page documents vLLM's tool calling and structured output systems. These features enable models to generate outputs that conform to specific formats (structured output via grammars) and to invoke external tools or functions (tool calling).

* * *

## Purpose and Scope

The tool calling and structured output systems provide:

  1. **Tool Calling** : Mechanisms for models to generate function/tool invocations in OpenAI-compatible format, with support for tool parsers, MCP (Model Context Protocol) integration, and auto tool selection [vllm/tool_parsers/abstract_tool_parser.py35-39](https://github.com/vllm-project/vllm/blob/185cada3/vllm/tool_parsers/abstract_tool_parser.py#L35-L39) [vllm/entrypoints/openai/parser/harmony_utils.py150-162](https://github.com/vllm-project/vllm/blob/185cada3/vllm/entrypoints/openai/parser/harmony_utils.py#L150-L162)
  2. **Structured Output** : Grammar-based output constraints using FSM (Finite State Machine) compilation (via backends like `xgrammar`, `guidance`, or `outlines`) to ensure model outputs conform to specified JSON schemas, regex, or EBNF grammars [vllm/v1/structured_output/backend_xgrammar.py78-126](https://github.com/vllm-project/vllm/blob/185cada3/vllm/v1/structured_output/backend_xgrammar.py#L78-L126) [vllm/v1/structured_output/__init__.py129-164](https://github.com/vllm-project/vllm/blob/185cada3/vllm/v1/structured_output/__init__.py#L129-L164)
  3. **Reasoning Integration** : Support for reasoning models (e.g., DeepSeek R1, Qwen3) to separate thinking/reasoning content from final structured conclusions using specialized reasoning parsers [vllm/reasoning/abs_reasoning_parsers.py26-32](https://github.com/vllm-project/vllm/blob/185cada3/vllm/reasoning/abs_reasoning_parsers.py#L26-L32) [vllm/reasoning/__init__.py22-147](https://github.com/vllm-project/vllm/blob/185cada3/vllm/reasoning/__init__.py#L22-L147)

* * *

## Tool Calling Architecture

### Tool Parser System

Tool parsers extract structured tool call information from model-generated text. vLLM implements model-specific parsers to handle varying output formats, such as XML-based tags, specialized JSON markers, or DSML tokens [vllm/tool_parsers/__init__.py24-217](https://github.com/vllm-project/vllm/blob/185cada3/vllm/tool_parsers/__init__.py#L24-L217)
