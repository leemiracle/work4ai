# 01 — State Space Models (S4/Mamba)：O(n) 复杂度的复兴

> 上一篇 [00-为什么Transformer不是终点](00-为什么Transformer不是终点.md) 用实测证明了 attention 的 O(n²) 复杂度：N=131072 时 FLOPs 是 Mamba 的 7800 倍。本篇拆透那个「7800 倍」里站在对面的家伙——**State Space Model（SSM）**：它怎么把连续动力系统离散成线性递推、怎么靠 HiPPO 矩阵获得长程记忆、Mamba 的「选择性」又为什么让它能像 attention 一样按内容读写，却只花 O(n)。
>
> 配套实验：`experiments/01_ssm.py`（纯 NumPy，`python3 -u 01_ssm.py` 几秒跑完）。

---

## 1. 灵魂：把"记忆"建成一个线性动力系统

$$
\boxed{\text{SSM 把序列建模成连续动力系统 } \dot{x}=Ax+Bu \text{，离散成线性递推 } h_t=\bar A h_{t-1}+\bar B x_t}
$$

一句话钉死：**SSM = 一个可并行训练的线性 RNN**。
- **推理**：像 RNN 一样逐步递推，每步 O(1)，全程 O(n)——没有 attention 的 n² 矩阵。
- **训练**：因为递推是**线性**的，它可以被改写成 1D 卷积，用 FFT / parallel-scan **整体并行**——绕过了 RNN 不能并行的死穴。
- **记忆**：S4 靠 **HiPPO 矩阵**给 $A$ 注入"多时间尺度"结构，让信号慢衰减；Mamba 进一步让 $A,B,C$ **随输入变化**（选择性），能像 attention 一样"按内容决定记什么、忘什么"。

---

## 2. 直觉层：从 RNN 的失忆 → S4 的记忆 → Mamba 的选择性

### 2.1 为什么 RNN 记不住长序列？

经典 RNN：$h_t = \tanh(W_h h_{t-1} + W_x x_t)$。问题在 $W_h$——**随机初始化**的 $W_h$ 把每一步的信号乘上一个随机收缩，几百步后早期 token 的贡献**指数归零**。这就是"梯度消失/记忆消失"。

本实验给 RNN 一个谱半径很小的随机 $A$，实测**初始信号存活率**：

| 步数 t | 0 | 4 | 8 | 16 |
|:---:|:---:|:---:|:---:|:---:|
| RNN 信号存活率 | 1.000 | **0.010** | 0.000 | 0.000 |

t=4 步信号就只剩 1%——RNN 本质上是个"金鱼记忆"。

### 2.2 S4 的解法：HiPPO 矩阵——给记忆装上"多档变速"

S4（Albert Gu, 2022）的关键洞察：**别让 $A$ 随机，给它一个数学结构**。HiPPO-LegS 矩阵是一个下三角矩阵（0-indexed）：

$$
A_{ij} = \begin{cases} -(i+1) & i = j \ (\text{对角}) \\ -\sqrt{(2i+1)(2j+1)} & i > j \ (\text{严格下三角}) \\ 0 & i < j \ (\text{上三角}) \end{cases}
$$

它的对角元是 $-(1, 2, 3, 4, \dots)$——**等间距负整数，对应等间距的衰减时间尺度**。低阶模态（-1）衰减极慢（记很久），高阶模态（-N）变化快（记细节）。就像相机的"多档快门"同时记录长短曝光。实测同一信号存活率：

| 步数 t | 0 | 8 | 32 | 64 |
|:---:|:---:|:---:|:---:|:---:|
| S4 信号存活率 | 1.000 | 0.615 | 0.301 | **0.225** |

t=64 步还有 22% 信号——比 RNN 强了无数倍。这就是 S4 能在 Long Range Arena（长度 1K–16K）上碾压 Transformer 的根本原因。

### 2.3 Mamba 的解法：选择性——让参数随输入变

S4 有个软肋：$A,B,C$ 是**固定**的，不管输入是"关键信息"还是"无用空白"，它都用同一套衰减。于是遇到"8 个有用 token + 248 个空白"这种序列，S4 也会在空白期缓慢泄漏记忆。

**Mamba（Gu & Dao, 2023）** 让 $A,B,C$ 变成**输入的函数**——也就是"选择性"（selectivity）：
- 看到**重要 token**：开大门，写入更新；
- 看到**空白/噪声**：把门关死，状态**冻结**。

实测 Mamba 在空白期信号存活率恒为 **1.000**——永不遗忘，且**与序列长度无关**。这本质上是把 attention「按内容决定关注谁」的能力，塞进了一个 O(n) 的递推里。

## 3. 数学层：从连续方程到可并行卷积

### 3.1 连续状态空间方程

SSM 源自控制论里的线性时不变系统（输入 $u(t)$，隐状态 $x(t)$，输出 $y(t)$）：

$$
\dot{x}(t) = A\,x(t) + B\,u(t), \qquad y(t) = C\,x(t) + D\,u(t)
$$

这是一个**连续时间**的 ODE。要处理离散的 token 序列，必须**离散化**。

### 3.2 离散化：ZOH 与双线性（两种方法）

连续 ODE 必须离散化成递推才能处理 token 序列。离散递推形式：

$$
\boxed{\;h_t = \bar A\,h_{t-1} + \bar B\,x_t,\qquad y_t = C\,h_t\;}
$$

$\bar A, \bar B$ 的计算方式取决于离散化方法——**这两种不是同义词**：

| 方法 | $\bar A$ 公式 | 性质 | 用于 |
|---|---|---|---|
| **ZOH**（零阶保持，精确）| $\bar A = e^{\Delta A}$ | 输入分段常数时的**精确解** | **Mamba** |
| **双线性/Tustin**（近似）| $\bar A = (I - \frac{\Delta}{2}A)^{-1}(I + \frac{\Delta}{2}A)$ | $e^{\Delta A}$ 的 Padé(1,1) 近似，保持稳定性 | S4（也可用 ZOH）|

> ⚠️ **ZOH ≠ 双线性**：ZOH 是精确的矩阵指数 $e^{\Delta A}$，双线性是其有理近似。S4 论文两者都讨论；**Mamba 统一用 ZOH**（$\bar{A}_t = e^{\Delta_t A}$，且步长 $\Delta_t$ 随输入变化——这就是"选择性"的实现）。

> **关键**：$\bar A$ 的特征值 $|\lambda|<1$（稳定），信号每步被乘以 $\lambda$——$\lambda$ 越接近 1，记忆越长。HiPPO 的多档对角元正好给了一组从"很接近 1"到"显著小于 1"的特征值，覆盖各种时间尺度。

### 3.3 卷积视角：为什么 SSM 能并行训练

把递推展开：$y_t = \sum_{k\le t} C\,\bar A^{\,t-1-k}\bar B\,x_k$。这正是**一个 1D 卷积**，卷积核 $K_t = C\bar A^{t-1}\bar B$：

$$
y = K * x,\qquad K = \big(C\bar B,\; C\bar A\bar B,\; C\bar A^2\bar B,\;\dots\big)
$$

**线性**是魔法所在：因为递推是线性的（没有 $\tanh$），整个序列的输出可以一次性算出（FFT 卷积或 parallel scan），**没有逐步依赖**。这就是 S4 能并行训练、而带非线性的 RNN 不能的根本区别。

> SSM 有**双形态**（dual mode）：训练时切到**卷积模式**（并行），推理时切回**递推模式**（每生成一个 token 只需 O(1)，且无 KV cache）。

### 3.4 Mamba 的选择性：参数变成输入的函数

S4 里 $\bar A,\bar B$ 是常数。Mamba 让步长 $\Delta_t$、输入矩阵 $B_t$、输出矩阵 $C_t$ 都**依赖当前输入** $x_t$：

$$
\Delta_t = \text{softplus}(W_\Delta\, x_t),\qquad
\bar A_t = \exp(\Delta_t \cdot A),\qquad h_t = \bar A_t\,h_{t-1} + \bar B_t\,x_t
$$

当 $\Delta_t\to 0$（遇到"不重要"输入）：$\bar A_t\to I$，状态**冻结**；当 $\Delta_t$ 大（遇到"重要"输入）：$\bar A_t$ 收缩、$\bar B_t$ 放大，状态**写入更新**。这就是「选择性」——一个连续可微的"记忆开关"。代价是失去了纯线性卷积形式，Mamba 改用 **hardware-aware parallel scan** 仍保持 O(n) 并行。

## 4. 代码层：bash 跑实验，看真实数字

```bash
cd 讲透模型可能性/experiments && python3 -u 01_ssm.py
```

**任务**：长度 $L$ 的延迟复制——前 8 步放随机 ±1 信号，其余全空白；用最后一个隐状态线性解码出这 8 个 token（readout 用岭回归训练，冻结 $A$ 以干净隔离架构差异）。

### Part 1：三模型 × 三长度的复制精度（实测）

| 序列长度 L | 经典 RNN | S4 (HiPPO) | Mamba (选择性) |
|:---:|:---:|:---:|:---:|
| 16  | 59.2% | **97.5%** | **100.0%** |
| 64  | 58.2% | **84.7%** | **100.0%** |
| 256 | 58.2% | 73.6% | **100.0%** |

- **RNN** 全长度卡在 ~58%（接近随机猜 50%）——随机 $A$ 让信号迅速塌缩，失忆。
- **S4** 短序列 97%，随长度**优雅衰减**（97→85→74）——HiPPO 多时间尺度带来长程记忆，但固定参数下空白期仍会缓慢泄漏。
- **Mamba** 全长度 100%——选择性门控在空白期冻结状态，**长度无关**。

### Part 2：记忆保持曲线 —— 初始信号存活率 $\|\bar A^t\bar B\|/\|\bar B\|$

| t(步) | 经典 RNN | S4 (HiPPO) | Mamba (空白) |
|:---:|:---:|:---:|:---:|
| 0  | 1.000 | 1.000 | 1.000 |
| 4  | **0.010** | 0.769 | 1.000 |
| 16 | 0.000 | 0.439 | 1.000 |
| 64 | 0.000 | 0.225 | 1.000 |

RNN 几步归零；S4 多项式慢衰减；Mamba 冻结不动。

### Part 3：卷积视角的并行性（实测）

```
顺序递推 (RNN 风格): 0.163 ms/seq   ← 必须逐步, 有依赖, 难并行
卷积视图 (1D conv) : 0.038 ms/seq   ← 各步独立, 可整体并行 (FFT/parallel-scan)
```

## 5. 横评表：RNN vs S4 vs Mamba

| 维度 | 经典 RNN | S4 | Mamba |
|------|:--:|:--:|:--:|
| 推理复杂度 | O(n) | O(n) | O(n) |
| 训练复杂度 | O(n) 顺序 | O(n) **可并行** | O(n) parallel-scan |
| 长程记忆 | 差（指数失忆） | 强（HiPPO 结构） | 极强（选择性冻结） |
| 内容感知 | 无 | 无（参数固定） | **有**（参数随输入变） |
| 复制 L=64 精度 | ~58% | ~85% | ~100% |
| 能否并行训练 | ❌ | ✅ | ✅ |
| 推理时 KV cache | 不需要 | 不需要 | 不需要 |
| 关键缺陷 | 梯度消失 | 空白期泄漏 / 召回弱 | 精确事实召回弱 |

**演化主线**：RNN（随机 $A$，失忆）→ S4（HiPPO $A$，结构化记忆，可并行）→ Mamba（选择性 $A,B,C$，按内容读写）。每一步都**只动 $A$ 矩阵**，却带来质的飞跃。

## 6. 批判性：SSM 擅长什么、不擅长什么

### ✅ 擅长

1. **超长上下文**：O(n) 复杂度 + 无 KV cache，做 256K/1M token 成本远低于 attention（Jamba 256K 已商用）。
2. **连续/时序数据**：源自连续 ODE，对音频、EEG、金融、基因序列等天然契合。
3. **推理便宜**：每 token O(1)，无 attention 那种"读全部历史"的开销，边缘部署友好。

### ❌ 不擅长（这是 hype 不会告诉你的）

1. **精确事实召回弱**：Mamba 的状态是**压缩**的（固定大小的隐向量），而 attention 是**精确查表**（保留所有 K/V）。在"大海捞针"这类需要逐字召回的任务上，纯 SSM **不如 attention**——这正是 Jamba 等**混合架构**（几层 Mamba + 几层 Attention）存在的原因。
2. **复制能力上限**：本实验已显示 S4 在长空白后衰减到 74%——固定参数的 SSM 对"间隔很远的精确重复"有结构性弱点。
3. **理论收益难全部兑现**：parallel scan 在 GPU 上的常数因子比 attention 的成熟 kernel 大，短序列上 Mamba 不一定跑赢优化过的 attention。

> **一句话**：SSM 不是 attention 的"替代品"，而是它的"长程补丁"。务实派的做法是**混用**——长上下文用 Mamba 省成本，关键召回层用 attention 保精度。

---

## 7. 一句话总结

> **SSM 把连续动力系统 $\dot{x}=Ax+Bu$ 离散成线性递推 $h_t=\bar A h_{t-1}+\bar B x_t$——推理 O(n)、训练可并行（线性 → 1D 卷积 → FFT）。S4 用 HiPPO 矩阵给 $A$ 注入多时间尺度结构，获得长程记忆（复制任务短序列 97%、长序列优雅衰减）；Mamba 让 $A,B,C$ 随输入变化（"选择性"），像 attention 一样按内容读写，长度无关地接近 100%。实测：RNN ~58%（失忆）/ S4 ~85% / Mamba ~100%。但 SSM 的压缩状态在"精确事实召回"上弱于 attention——所以 Jamba 选择混用。SSM 的真正定位是 O(n) 的长程补丁，不是 attention 的全面替代。**

## ✍️ 练习（`experiments/01_ssm.py`）

1. **手推离散化**：取 $A=-1,\ B=1,\ \Delta=0.1$，用双线性公式手算 $\bar A,\bar B$，验证 $\bar A\approx 0.905$。
2. **改谱半径**：把 RNN 的特征值范围从 [25,50] 改成 [1,2]，观察复制精度和衰减曲线怎么变——体会"随机 $A$ 不一定失忆，强收缩才失忆"。
3. **打破选择性**：把 Mamba 的"空白冻结"去掉（让它和 S4 用同样的固定递推），验证精度会从 100% 掉到 S4 水平——亲自证明"选择性才是 Mamba 的核心"。
4. **加非线性**：在递推里加 $\tanh$，看 S4 还能不能用卷积并行训练（提示：不能——这正解释了 RNN 为何难并行）。
5. **大海捞针**：把任务改成"序列中随机一个位置藏一个 key，末尾要召回它"，对比 S4 vs 一个小型 attention——观察 SSM 在精确召回上的弱点。

## 📌 下一步

本篇看到 SSM 用**线性递推**绕开 O(n²)，但它的"线性"既是优点（可并行）也是枷锁（表达力受限、精确召回弱）。下一篇 **[02-LinearAttention.md](02-LinearAttention.md)** 走另一条路：**不改递推，改 attention 本身**——用核函数把 $QK^\top$ 近形成 $\phi(Q)\phi(K)^\top$，让 attention 也降到 O(n)，却保留"逐字查表"的能力。两条 O(n) 路线，一个牺牲线性、一个牺牲核近似——你会看到模型设计里永恒的权衡。
