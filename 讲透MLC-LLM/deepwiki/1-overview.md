## Mission

 MLC LLM is a machine learning compiler and high-performance deployment engine for large language models. Its mission is to enable everyone to develop, optimize, and deploy AI models natively on everyone's platforms. It provides a unified high-performance LLM inference engine across various hardware backends, backed by a consistent OpenAI-compatible API.

## How It Works: Two Phases

 MLC LLM operates in two distinct phases. The **Compile-Time** phase uses TVM Unity/Relax to produce platform-specific model libraries and quantized weights. The **Runtime** phase uses `MLCEngine` to load those artifacts and serve inference.

### Compilation Artifacts

 To run a model on any platform, the system requires:

 
 - **Model Weights**: Converted to MLC format (quantized and sharded).
 - **Model Library**: Compiled binary comprising the optimized inference logic for the target device.
 - **Chat Config**: Metadata (e.g., `context_window_size`, `prefill_chunk_size`) generated by `gen_config`.

## MLCEngine: Unified Runtime

 `MLCEngine` is the central runtime abstraction. All deployment targets — Python scripts, REST API servers, iOS/Android apps, and web browsers — are backed by the same C++ core (`EngineImpl`) and load the same compiled model library artifacts.

## OpenAI-Compatible API Surface

 MLC LLM exposes an OpenAI-compatible API at every interface layer. The same `chat.completions.create` and `completions.create` call signatures work through Python, REST, and mobile SDKs.

 
| Interface | Entry Point / Usage |
|---|---|
| Python | from mlc_llm import MLCEngine |
| REST Server | mlc_llm serve MODEL (FastAPI based) |
| CLI | mlc_llm chat MODEL (Interactive) |
| iOS | MLCEngine Swift API in ios/MLCSwift/ |
| Android | Java/Kotlin SDK in android/ |
| Web | WebLLM package (consuming .wasm libraries) |

## Key Subsystems

 
| Subsystem | Primary Code Location | Purpose |
|---|---|---|
| Compilation | python/mlc_llm/ | Weight conversion, config generation, and TVM compilation. |
| Engine Core | cpp/serve/ | Request orchestration, KV cache management, and sampling. |
| Python Engine | python/mlc_llm/engine/ | Async/Sync wrappers for the C++ engine. |
| Serving | python/mlc_llm/serve/ | FastAPI routes and OpenAI protocol implementation. |
| Mobile SDKs | ios/, android/ | Platform-specific bindings and UI for mobile deployment. |
| Web | web/ | WebGPU/WASM runtime and WebLLM integration. |
