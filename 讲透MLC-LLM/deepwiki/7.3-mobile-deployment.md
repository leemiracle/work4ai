## Purpose and Scope

 This document describes the deployment of MLC LLM to mobile platforms (Android and iOS). It covers the build system architecture, compilation process, library packaging, and integration of compiled models into native mobile applications. For server-side deployment, see [Server Deployment](https://deepwiki.com/mlc-ai/mlc-llm/7.2-server-deployment). For web-based deployment, see [Web Deployment](https://deepwiki.com/mlc-ai/mlc-llm/7.4-web-deployment). For compilation system details, see [Compilation System](https://deepwiki.com/mlc-ai/mlc-llm/4-compilation-system).

 Mobile deployment requires cross-compilation of model libraries to platform-specific formats with appropriate GPU backends: OpenCL for Android devices and Metal for iOS/iPadOS devices. The deployment process produces static libraries that bundle the TVM runtime, tokenizers, and compiled model executables.

## ADB bundle_weight.py

 For Android, when `bundle_weight` is set to `true`, the `bundle_weight.py` script is used to package weights into the APK. This process involves:

 
 - Downloading weights from Hugging Face.
 - Placing weights in the `assets/` directory of the Android project.
