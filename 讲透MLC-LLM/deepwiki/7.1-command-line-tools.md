  This page documents all CLI commands exposed by the `mlc_llm` package, including their full argument lists, accepted values, and usage examples. These commands cover the complete model lifecycle: weight conversion, config generation, compilation, interactive chat, REST server startup, and mobile packaging.

 For information about the REST API endpoints exposed by `mlc_llm serve`, see [REST API Server](https://deepwiki.com/mlc-ai/mlc-llm/6.2-rest-api-server). For the Python engine API, see [Engine Classes](https://deepwiki.com/mlc-ai/mlc-llm/6.1-engine-classes). For the underlying compilation pipeline triggered by `compile`, see [Compilation System](https://deepwiki.com/mlc-ai/mlc-llm/4-compilation-system).

## Overview of Commands

 
| Command | Purpose | Key Output |
|---|---|---|
| convert_weight | Convert HuggingFace weights to MLC format | params_shard_*.bin, tensor-cache.json |
| gen_config | Generate mlc-chat-config.json and process tokenizer | mlc-chat-config.json, tokenizer files |
| compile | Compile a model library for a target device | .so, .dylib, .dll, .tar, .wasm |
| chat | Launch an interactive terminal chat session | (interactive I/O) |
| serve | Start an OpenAI-compatible REST API server | HTTP server |
| package | Build runtime and model libraries for mobile | dist/lib/, dist/bundle/ |

## `convert_weight`

 Converts HuggingFace model weights into the MLC binary format (quantized or unquantized). The output directory can be shared across all target platforms. It uses a `LOADER` to map source parameters to quantized MLC parameters [python/mlc_llm/interface/convert_weight.py168-174](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/convert_weight.py#L168-L174)

```

```

 
### Arguments

 
| Argument | Required | Description |
|---|---|---|
| CONFIG | Yes | Path to a HuggingFace model directory (containing config.json) or path to the config.json file directly. |
| --quantization | Yes | Quantization scheme, e.g. q4f16_1, q0f32, q8f16_1. |
| --model-type | No | Model architecture name (e.g. llama). Inferred from config.json if not set. |
| --device | No | Device for quantization, e.g. cuda or cuda:0. Auto-detected if not set python/mlc_llm/interface/convert_weight.py36 |
| -o / --output | Yes | Output directory for MLC-format weights. |
| --lora-adapter | No | Path to a LoRA adapter to merge with the base model before conversion python/mlc_llm/interface/convert_weight.py67-99 |

## `gen_config`

 Generates the `mlc-chat-config.json` file for a model and copies/processes tokenizer files into the output directory. This config is required by both `compile` and the runtime engine.

 
### Syntax

 
```

```

 
### Arguments

 
| Argument | Required | Description |
|---|---|---|
| CONFIG | Yes | Path to a HuggingFace model directory or config.json. |
| --quantization | Yes | Quantization scheme. Must match the scheme used in convert_weight. |
| --conv-template | Yes | Conversation template name (e.g., llama-2, redpajama_chat). |
| --context-window-size | No | Override the maximum sequence length supported by the model python/mlc_llm/interface/compiler_flags.py144 |
| --sliding-window-size | No | Override the sliding window size for SWA models python/mlc_llm/interface/compiler_flags.py145 |
| --prefill-chunk-size | No | Maximum tokens per prefill chunk. Lower this to reduce memory usage python/mlc_llm/interface/compiler_flags.py146 |
| --tensor-parallel-shards | No | Number of tensor-parallel shards for multi-GPU python/mlc_llm/interface/compiler_flags.py149 |
| -o / --output | Yes | Output directory. |
