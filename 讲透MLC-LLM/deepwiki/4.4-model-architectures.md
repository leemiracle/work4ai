## The `MODELS` Registry

 All supported architectures are registered in a single dictionary. Each entry maps a model-type string to a `Model` dataclass.

 
### `Model` Dataclass

 [python/mlc_llm/model/model.py63-90](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/model/model.py#L63-L90)

 
| Field | Type | Description |
|---|---|---|
| name | str | Canonical model-type string (e.g. "ministral3") |
| config | ModelConfig | Class with a from_file(Path) -> ModelConfig class method |
| model | Callable[[ModelConfig], nn.Module] | Factory that constructs the TVM Relax nn.Module |
| source | Dict[str, FuncGetExternMap] | Keyed by source format, e.g. "huggingface-safetensor", "awq" |
| quantize | Dict[str, FuncQuantization] | Keyed by quantization kind, e.g. "group-quant", "no-quant" |

 `FuncGetExternMap`: `(ModelConfig, Quantization) -> ExternMapping`

 `FuncQuantization`: `(ModelConfig, Quantization) -> Tuple[nn.Module, QuantizeMapping]`

## Multimodal Models

## HuggingFace Weight Loader

 Each model provides a loader (e.g., `llama_loader.py`) that defines an `ExternMapping`. This mapping tells the `convert_weight` tool how to transform HuggingFace parameter names and shapes into the MLC format.

 Key mapping patterns:

 
 - **Identity**: Direct mapping of weights like `norm.weight`.
 - **Fusion**: Concatenating `q_proj`, `k_proj`, and `v_proj` into a single `qkv_proj.weight` [python/mlc_llm/model/phi3v/phi3v_loader.py](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/model/phi3v/phi3v_loader.py)
 - **Quantization Aware**: Mapping scale factors and zero-points for models using `BlockScaleQuantize` or `GroupQuantize` [python/mlc_llm/model/deepseek_v2/deepseek_v2_model.py65-89](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/model/deepseek_v2/deepseek_v2_model.py#L65-L89)

## Quantization Entry Points

 Models register quantization functions that modify the `nn.Module` tree.

 
 - `no_quant`: Returns the model in its original floating-point format.
 - `group_quant`: Replaces `nn.Linear` with `GroupQuantizeLinear`, applying weight-only quantization with per-group scales.
 - `block_scale_quant`: Used for FP8 models (like DeepSeek V3), replacing layers with `BlockScaleQuantizeLinear` which utilizes hardware-accelerated block scaling [python/mlc_llm/model/deepseek_v2/deepseek_v2_model.py65-89](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/model/deepseek_v2/deepseek_v2_model.py#L65-L89)
