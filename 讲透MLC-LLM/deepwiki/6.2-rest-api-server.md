  This page documents the FastAPI-based HTTP server that exposes an OpenAI-compatible REST API for MLC LLM. It covers the server entrypoint, route handlers, `ServerContext` multi-model management, the `PopenServer` subprocess wrapper, and the `mlc_llm serve` CLI.

 For the engine classes (`AsyncMLCEngine`, `MLCEngine`) that the server delegates inference to, see [Engine Classes](https://deepwiki.com/mlc-ai/mlc-llm/6.1-engine-classes). For the protocol data structures (`ChatCompletionRequest`, `CompletionResponse`, etc.), see [OpenAI API Protocol and Configuration](https://deepwiki.com/mlc-ai/mlc-llm/6.3-openai-api-protocol-and-configuration). For practical deployment guidance (engine modes, speculative decoding, prefix caching), see [Server Deployment](https://deepwiki.com/mlc-ai/mlc-llm/7.2-server-deployment).

## `mlc_llm serve` CLI

 The `mlc_llm serve` command is the primary way to start the server. It is parsed by `main()` in [python/mlc_llm/cli/serve.py106-257](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/cli/serve.py#L106-L257) which delegates to `serve()` in [python/mlc_llm/interface/serve.py24-131](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L24-L131)

## FastAPI Application Setup

 `serve()` in [python/mlc_llm/interface/serve.py24-131](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L24-L131) performs the following startup sequence:

 
 - Creates an `AsyncMLCEngine` instance (the primary inference engine) [python/mlc_llm/interface/serve.py61-87](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L61-L87)
 - Optionally creates an `AsyncEmbeddingEngine` if `--embedding-model` is provided [python/mlc_llm/interface/serve.py91-101](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L91-L101)
 - Enters a `ServerContext` context manager and registers the engines [python/mlc_llm/interface/serve.py103-107](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L103-L107)
 - Creates a `fastapi.FastAPI()` instance [python/mlc_llm/interface/serve.py109](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L109-L109)
 - Attaches `CORSMiddleware` with the provided CORS settings [python/mlc_llm/interface/serve.py110-116](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L110-L116)
 - Includes three routers unconditionally: [python/mlc_llm/interface/serve.py118-120](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L118-L120) 
 - `openai_entrypoints.app` — the OpenAI-compatible API routes
 - `metrics_entrypoints.app` — the `/metrics` Prometheus-format endpoint
 - `microserving_entrypoints.app` — internal microserving routes
 - Conditionally includes `debug_entrypoints.app` when `--enable-debug` is set [python/mlc_llm/interface/serve.py124-126](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L124-L126)
 - Registers a `BadRequestError` exception handler [python/mlc_llm/interface/serve.py128-130](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L128-L130)
 - Calls `uvicorn.run(app, host=host, port=port)` — this call blocks until the server shuts down [python/mlc_llm/interface/serve.py131](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/serve.py#L131-L131)

### `GET /v1/models`

 Handler: `request_models()` [python/mlc_llm/serve/entrypoints/openai_entrypoints.py125-130](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/entrypoints/openai_entrypoints.py#L125-L130)

### `POST /v1/completions`

 Handler: `request_completion()` [python/mlc_llm/serve/entrypoints/openai_entrypoints.py137-220](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/entrypoints/openai_entrypoints.py#L137-L220)

 Accepts a `CompletionRequest`. Resolves the model engine via `ServerContext.get_engine(request.model)`.

 
 - **Streaming** (`request.stream = True`): Returns a `StreamingResponse` with `media_type="text/event-stream"`. Each chunk is serialized as `data: {json}\n\n`. The generator first fetches the initial chunk with `anext()` to surface immediate exceptions in the route scope [python/mlc_llm/serve/entrypoints/openai_entrypoints.py160-184](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/entrypoints/openai_entrypoints.py#L160-L184)
 - **Non-streaming**: Accumulates all chunks, then assembles a single `CompletionResponse` [python/mlc_llm/serve/entrypoints/openai_entrypoints.py187-220](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/entrypoints/openai_entrypoints.py#L187-L220)
 
 
### `POST /v1/chat/completions`

 Handler: `request_chat_completion()` [python/mlc_llm/serve/entrypoints/openai_entrypoints.py226-332](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/entrypoints/openai_entrypoints.py#L226-L332)

 Accepts a `ChatCompletionRequest`. The path mirrors `request_completion()` but uses `async_engine._handle_chat_completion()`.

 
### `POST /v1/embeddings`

 Handler: `request_embedding()` [python/mlc_llm/serve/entrypoints/openai_entrypoints.py46-118](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/entrypoints/openai_entrypoints.py#L46-L118)

 - `dimensions`: optional Matryoshka-style truncation with L2 re-normalization [python/mlc_llm/serve/entrypoints/openai_entrypoints.py92-98](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/entrypoints/openai_entrypoints.py#L92-L98)
 
 Returns an `EmbeddingResponse` with per-input `EmbeddingObject` items and `EmbeddingUsage`.

## `ServerContext`

 `ServerContext` ([python/mlc_llm/serve/server/server_context.py11-73](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/server_context.py#L11-L73)) is a singleton that bridges the FastAPI route handlers with the live engine instances. It is used as a context manager in `serve()`.

 

 Key behaviors:

 
 - **Singleton access**: `ServerContext.current()` returns the active context [python/mlc_llm/serve/server/server_context.py40-42](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/server_context.py#L40-L42) Route handlers call this to access engines without holding a direct reference.
 - **Engine resolution**: `get_engine(model)` returns the engine registered under `model`. ## `PopenServer`

 `PopenServer` ([python/mlc_llm/serve/server/popen_server.py18-185](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/popen_server.py#L18-L185)) launches the full `mlc_llm serve` process as a background subprocess. It is primarily used in tests and debugging scenarios.

 **Constructor parameters** mirror those of the CLI: `model`, `device`, `model_lib`, `mode`, `engine_config`, `enable_debug`, `enable_tracing`, `host`, `port` [python/mlc_llm/serve/server/popen_server.py25-37](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/popen_server.py#L25-L37)

 **`start()`** [python/mlc_llm/serve/server/popen_server.py59-162](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/popen_server.py#L59-L162):

 
 - Assembles the `python -m mlc_llm serve ...` command line from the stored configuration.
 - Launches it via `subprocess.Popen()`; deliberately does **not** use `stdout=PIPE` or `stderr=PIPE` to avoid buffer deadlocks [python/mlc_llm/serve/server/popen_server.py125-130](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/popen_server.py#L125-L130)
 - Polls `GET /v1/models` in a loop until the server responds successfully (up to 120s timeout) [python/mlc_llm/serve/server/popen_server.py137-150](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/popen_server.py#L137-L150)
 - Sets `self.base_url` and `self.openai_v1_base_url` after the server is ready.
 
 **`terminate()`** [python/mlc_llm/serve/server/popen_server.py163-185](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/popen_server.py#L163-L185) kills the subprocess and all child processes using `psutil`.

 Sources: [python/mlc_llm/serve/server/popen_server.py18-185](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/serve/server/popen_server.py#L18-L185)
