  This page covers how MLC LLM compiles and packages model libraries for mobile and embedded targets through the `mlc_llm package` command. It describes the configuration format, JIT compilation caching, target auto-detection, and platform-specific static library generation for iOS and Android.

 For the general three-step compilation pipeline (`convert_weight`, `gen_config`, `compile`), see page [4](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/4) For deployment-side usage of these artifacts in Android and iOS apps, see page [7.3](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/7.3)

 
---

 
## Overview

 The packaging system bridges model compilation (see page [4](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/4)) and platform-specific app integration. Its job is to take a list of models defined in `mlc-package-config.json`, compile them into platform-appropriate binary libraries, bundle model weights if requested, and produce a `dist/` directory ready for integration into Android Studio or Xcode projects.

 **Entry point:** `python/mlc_llm/interface/package.py`, invoked via `mlc_llm package` [python/mlc_llm/interface/package.py1-10](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/package.py#L1-L10)

 **Supported targets:** `iphone`, `macabi`, `android` [python/mlc_llm/interface/package.py18](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/package.py#L18-L18)

## `mlc-package-config.json` Format

 This JSON file, located in the app source directory (e.g., `android/MLCChat/mlc-package-config.json`), drives the entire packaging process [android/MLCChat/mlc-package-config.json1-50](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/android/MLCChat/mlc-package-config.json#L1-L50)

 
### Top-Level Fields

 
| Field | Type | Description |
|---|---|---|
| device | string | Target platform: "android", "iphone", or "macabi" |
| model_list | list | One entry per model to compile and include |
| model_lib_path_for_prepare_libs | dict | Optional: manually compiled lib paths, keyed by model_lib name |

 
### Per-Model Entry Fields

 
| Field | Required | Type | Description |
|---|---|---|---|
| model | Yes | string | HuggingFace URL (HF://...) or local path |
| model_id | Yes | string | Unique identifier used at runtime |
| estimated_vram_bytes | Yes | int | Runtime VRAM estimate used by the app |
| bundle_weight | No | bool | If true, copy weights into dist/bundle/ |
| overrides | No | dict | Config overrides: prefill_chunk_size, context_window_size, etc. |
| model_lib | No | string | System lib prefix; must match a key in model_lib_path_for_prepare_libs if set |

 Sources: [android/MLCChat/mlc-package-config.json1-50](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/android/MLCChat/mlc-package-config.json#L1-L50) [python/mlc_llm/interface/package.py36-101](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/package.py#L36-L101)

## JIT Compilation (`jit.py`)

 When no pre-built library is specified for a model, `build_model_library` calls `jit.jit()` from `python/mlc_llm/interface/jit.py` [python/mlc_llm/interface/package.py92-99](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/package.py#L92-L99) This function compiles the model on-demand and caches the result.

### Compilation Cache

 The JIT cache lives under `MLC_LLM_HOME`. Cache keys are derived from a hash of model configuration, quantization, device target, and optimization flags [python/mlc_llm/interface/jit.py50-80](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/jit.py#L50-L80)

 
### `MLC_JIT_POLICY` Environment Variable

 
| Value | Behavior |
|---|---|
| ON (default) | Use cache if present; compile and cache if not |
| OFF | Disable JIT entirely; raise RuntimeError |
| REDO | Always recompile and overwrite cache |
| READONLY | Use cache only; error if not cached |

## Target Detection and Build Function Selection (`auto_target.py`)

 `python/mlc_llm/support/auto_target.py` maps a target hint string (e.g., `"android"`, `"iphone"`, `"cuda"`) to a TVM `Target` object and a `BuildFunc` [python/mlc_llm/support/auto_target.py31-61](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/support/auto_target.py#L31-L61)

 
### `detect_target_and_host(target_hint, host_hint)`

 
 - Calls `_detect_target_gpu(target_hint)` to resolve a `Target` and `BuildFunc` [python/mlc_llm/support/auto_target.py43](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/support/auto_target.py#L43-L43)
 - If `target.host` is `None`, calls `_detect_target_host(host_hint)` to attach a CPU host [python/mlc_llm/support/auto_target.py45](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/support/auto_target.py#L45-L45)
 - For CUDA targets, appends `"thrust"` to `target.libs` [python/mlc_llm/support/auto_target.py46-52](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/support/auto_target.py#L46-L52)
 - For ROCm targets, appends `["thrust", "rocblas", "miopen", "hipblas"]` [python/mlc_llm/support/auto_target.py54-60](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/support/auto_target.py#L54-L60)

## iOS Static Library (`prepare_libs.sh`)

 For iOS targets, `mlc_llm package` invokes `ios/prepare_libs.sh` to build the MLC LLM runtime as a static library [ios/prepare_libs.sh1-12](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/ios/prepare_libs.sh#L1-L12)

 
### What It Does

 
 - Checks for `rustup` (required for cross-compiling tokenizers) [ios/prepare_libs.sh20-28](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/ios/prepare_libs.sh#L20-L28)
 - Accepts flags: `--simulator`, `--catalyst`, `--arch x86_64|arm64`, `--deployment-target` [ios/prepare_libs.sh31-54](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/ios/prepare_libs.sh#L31-L54)
 - Adds the appropriate Rust target via `rustup target add` (e.g., `aarch64-apple-ios`) [ios/prepare_libs.sh74-94](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/ios/prepare_libs.sh#L74-L94)
 - Runs CMake with `-DMLC_LLM_INSTALL_STATIC_LIB=ON` and `-DUSE_METAL=ON` [ios/prepare_libs.sh98-108](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/ios/prepare_libs.sh#L98-L108)
 - Builds the `mlc_llm_static` CMake target [ios/prepare_libs.sh136-137](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/ios/prepare_libs.sh#L136-L137)
 - Creates `ios/MLCSwift/tvm_home` as a symlink to `3rdparty/tvm` [ios/prepare_libs.sh140-141](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/ios/prepare_libs.sh#L140-L141)

## Android Output Structure

 After `mlc_llm package` completes for an Android target, the `dist/` directory contains the runtime and model build output [docs/deploy/android.rst147-150](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/docs/deploy/android.rst#L147-L150)

 
```
dist
└── lib
    └── mlc4j
        ├── build.gradle
        ├── output
        │   ├── arm64-v8a
        │   │   └── libtvm4j_runtime_packed.so
        │   └── tvm4j_core.jar
        └── src
            ├── cpp
            │   └── tvm_runtime.h
            └── main
                ├── AndroidManifest.xml
                ├── assets
```

 Sources: [docs/deploy/android.rst152-166](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/docs/deploy/android.rst#L152-L166)

 Model execution logic is packed into `libtvm4j_runtime_packed.so`, which embeds the compiled model `.tar` artifacts. `tvm4j_core.jar` provides the Java JNI bindings [docs/deploy/android.rst158-159](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/docs/deploy/android.rst#L158-L159)

## `mlc-app-config.json` (Runtime Config)

 `build_model_library` writes a `mlc-app-config.json` to the app config path. This file is read at runtime by the mobile app to know which models are available and how to load them [python/mlc_llm/interface/package.py147-159](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/python/mlc_llm/interface/package.py#L147-L159)

 
| Field | Source |
|---|---|
| model_id | From mlc-package-config.json model_id python/mlc_llm/interface/package.py106 |
| model_lib | System lib prefix used in compiled artifact python/mlc_llm/interface/package.py107 |
| model_url | HuggingFace URL (when bundle_weight is false) python/mlc_llm/interface/package.py140 |
| model_path | Local path (when bundle_weight is true, iOS only) python/mlc_llm/interface/package.py138 |
| estimated_vram_bytes | From mlc-package-config.json python/mlc_llm/interface/package.py143 |
