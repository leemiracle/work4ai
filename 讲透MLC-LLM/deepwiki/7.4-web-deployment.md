  This page covers how MLC LLM models are compiled and deployed in the browser via WebGPU and WebAssembly (WASM). It documents the `web/Makefile` build system, the `emcc` compilation target, the relationship to the WebLLM JavaScript framework, and how compiled `.wasm` model libraries are consumed at runtime.

 For general model compilation across all platforms, see [Compilation System](https://deepwiki.com/mlc-ai/mlc-llm/4-compilation-system). For mobile deployment (iOS/Android), see [Mobile Deployment](https://deepwiki.com/mlc-ai/mlc-llm/7.3-mobile-deployment).

 
---

 
## Overview

 Web deployment in MLC LLM targets the browser runtime using two technologies:

 
 - **WebGPU** — the browser's GPU compute API, used for accelerated matrix operations [docs/deploy/webllm.rst13-15](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/docs/deploy/webllm.rst#L13-L15)
 - **WebAssembly (WASM)** — the binary format that carries both the model inference logic and the MLC runtime into the browser [docs/install/emcc.rst11-12](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/docs/install/emcc.rst#L11-L12)
 
 There are two distinct WASM artifacts produced:

 
| Artifact | Source | Tool | Purpose |
|---|---|---|---|
| mlc_wasm_runtime.wasm | web/emcc/mlc_wasm_runtime.cc | emcc via web/Makefile | MLC LLM + TVM runtime for the browser web/Makefile29-46 |
| <model>-webgpu.wasm | mlc_llm compile | mlc_llm compile --device webgpu | Model-specific inference logic docs/deploy/webllm.rst64-67 |

 The JavaScript project [WebLLM](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/WebLLM) acts as the browser-side consumer, loading both artifacts and exposing an OpenAI-compatible API [docs/deploy/webllm.rst10-15](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/docs/deploy/webllm.rst#L10-L15)

 Emscripten is required to compile C++ source code to WebAssembly. It is recommended to use version `3.1.56` to avoid runtime link errors with `wasi_snapshot_preview1` [docs/install/emcc.rst25-35](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/docs/install/emcc.rst#L25-L35)

## `web/Makefile` Internals

 The Makefile orchestrates the compilation of the C++ runtime using `emcc` (Emscripten).

 **Diagram: Web Runtime Compilation Flow**

 
```

```

 Key `emcc` flags defined in the Makefile:

 
 - `WASM_BIGINT=1`: Enables 64-bit integer support in the JS-WASM interface [web/Makefile35](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/web/Makefile#L35-L35)
 - `ALLOW_MEMORY_GROWTH=1`: Allows the WASM heap to expand as needed for large KV caches [web/Makefile35](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/web/Makefile#L35-L35)
 - `STANDALONE_WASM=1`: Produces a WASM module that can be loaded without standard JS glue code [web/Makefile35](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/web/Makefile#L35-L35)
 - `-emit-llvm`: Generates intermediate LLVM bitcode [web/Makefile41](https://github.com/mlc-ai/mlc-llm/blob/fcce2cc3/web/Makefile#L41-L41)
