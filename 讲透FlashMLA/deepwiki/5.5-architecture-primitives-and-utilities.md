  This document covers the foundational utilities, architecture detection mechanisms, and dispatcher patterns used throughout FlashMLA. These primitives provide cross-architecture abstractions for error handling, memory management, feature validation, and architecture-specific kernel selection. The utilities enable clean separation between high-level API logic and low-level kernel implementations across SM90 (Hopper) and SM100 (Blackwell) architectures.

## Ring Buffer State Management

 The `RingBufferState` struct manages multi-stage pipeline scheduling for kernel execution. It tracks the current position in a circular buffer and computes stage indices with phase bits for double buffering.

## Dispatch Macros

 FlashMLA provides compile-time dispatch macros that convert runtime parameters to `static constexpr` constants. This enables aggressive compiler optimizations (loop unrolling, constant folding) in CUDA kernels.

 
### Available Macros

 
| Macro | Purpose | Values |
|---|---|---|
| DISPATCH_NUM_HEADS | Dispatches query head counts | 64, 128 |
| DISPATCH_HEAD_DIM | Dispatches QK head dimensions | 512, 576 |
| DISPATCH_BOOLEAN_FLAG | Dispatches boolean flags | true, false |
| DISPATCH_MODEL_TYPE | Dispatches MLA model type | V32, MODEL1 |

 **Sources:** [csrc/api/common.h51-99](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/api/common.h#L51-L99)

 
## SM100-Specific Primitives

 SM100 (Blackwell) introduces specialized intrinsics for tensor memory operations and synchronization.

 
### Tensor Memory (TMEM) Intrinsics

 SM100 introduces Tensor Memory (TMEM), a specialized on-chip memory for tensor operations. FlashMLA provides low-level intrinsics for efficient TMEM load and store operations.

 
 - **TMEM Load:** `tmem_ld_32dp32bNx<N, T>` uses `tcgen05.ld.sync.aligned.32x32b.xN.b32` PTX instructions. [csrc/sm100/intrinsics.h138-293](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/intrinsics.h#L138-L293)
 - **TMEM Store:** `tmem_st_32dp32bNx<N, T>` uses `tcgen05.st.sync.aligned.32x32b.xN.b32` PTX instructions. [csrc/sm100/intrinsics.h296-451](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/intrinsics.h#L296-L451)
 
 
### UMMA Barrier Operations

 Universal Matrix Multiply-Accumulate (UMMA) operations on SM100 require specialized barrier mechanisms for multi-CTA coordination.

 
 - `umma_arrive_noelect`: Commits for a single CTA group. [csrc/sm100/intrinsics.h55-62](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/intrinsics.h#L55-L62)
 - `umma_arrive_2x1SM_noelect`: Commits for a 2-CTA group. [csrc/sm100/intrinsics.h64-71](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/intrinsics.h#L64-L71)
 - `umma_arrive_multicast_noelect`: Commits with multicast support. [csrc/sm100/intrinsics.h73-81](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/intrinsics.h#L73-L81)
