## Purpose and Scope

 This page documents the warp-specialized kernel architecture for the backward pass of dense attention on SM100 (Blackwell B200) GPUs. It covers the multi-stage pipeline design, TMEM (Tensor Memory) allocation strategy, and coordination between specialized warp groups that compute gradients with respect to Q, K, V, and O tensors.

 For SM100 forward pass implementations, see [SM100 Kernels (Blackwell)](https://deepwiki.com/deepseek-ai/FlashMLA/5.2-sm100-kernels-(blackwell)). For general SM100 primitives and data types, see [Architecture Primitives and Utilities](https://deepwiki.com/deepseek-ai/FlashMLA/5.5-architecture-primitives-and-utilities).

## Warp Specialization Model

 The backward pass kernel uses a **warp-specialized architecture** with 16 warps per CTA, where each warp is assigned one of five roles. This specialization enables overlapping of data movement, computation, and reduction operations.

## TMEM Allocation Strategy

 The SM100 backward pass leverages Tensor Memory (TMEM) as a high-bandwidth accumulation buffer. TMEM is partitioned to store multiple intermediate tensors via the `TmemAllocation` struct [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp72-80](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L72-L80)

### Overlapping Allocations

 The kernel exploits temporal locality by overlapping TMEM allocations for tensors that are not live simultaneously [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp76-79](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L76-L79):

 
| TMEM Offset | Overlapping Tensors | Reason for Overlap |
|---|---|---|
| kDP == kDQ | dP and dQ | dP consumed before dQ computed |
| kS == kP | S and P | S consumed immediately to compute P |

 **Sources:** [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp72-85](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L72-L85) [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_mla_kernel_tma_warpspecialized.hpp70-78](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_mla_kernel_tma_warpspecialized.hpp#L70-L78)

 
## Pipeline Architecture

 The backward pass uses a multi-stage pipeline with distinct pipeline objects coordinating data flow between warp groups, including `PipelineLoadMmaQ`, `PipelineMmaComputeS`, and `PipelineMmaReduceDQ` [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp189-203](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L189-L203)

 
### Pipeline Object Mapping

 
| Pipeline Type | Producer Role | Consumer Role | Stages | Resource |
|---|---|---|---|---|
| PipelineLoadMmaQ | Load | Mma | 2 | Q tensors in SMEM |
| PipelineLoadMmaDO | Load | Mma | 1 | dO tensors in SMEM |
| PipelineLoadComputeLSE | Load | Compute | 1 | LSE in SMEM |
| PipelineLoadComputeSumOdO | Load | Compute | 1 | sum(O*dO) in SMEM |
| PipelineMmaComputeS | Mma | Compute | 1 | S in TMEM |
| PipelineMmaComputeDP | Mma | Compute | 1 | dP in TMEM |
| PipelineComputeMmaP | Compute | Mma | 1 | P in TMEM |
| PipelineComputeMmaDS | Compute | Mma | 1 | dS in SMEM |
| PipelineMmaReduceDQ | Mma | Reduce | 1 | dQ in TMEM |
| PipelineMmaComputeDKDV | Mma | Compute | 2 | dK, dV in TMEM |

## Preprocessing and Conversion

 Before the main backward kernel, a preprocessing step computes `sum(O*dO)` using `FmhaKernelBwdSumOdO` [csrc/sm100/prefill/dense/kernel/fmha_kernel_bwd_sum_OdO.hpp44](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/fmha_kernel_bwd_sum_OdO.hpp#L44-L44) After the main kernel, a conversion pass handles output scaling and type conversion via `FmhaKernelBwdConvert` [csrc/sm100/prefill/dense/kernel/fmha_kernel_bwd_convert.hpp44](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/fmha_kernel_bwd_convert.hpp#L44-L44)

 
### sum(O*dO) Computation

 The `FmhaKernelBwdSumOdO` kernel computes the dot product of `O` and `dO` for each query token, which is required for the `dsoftmax` calculation in the backward pass [csrc/sm100/prefill/dense/kernel/fmha_kernel_bwd_sum_OdO.hpp129-147](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/fmha_kernel_bwd_sum_OdO.hpp#L129-L147)

## Warp Group Responsibilities

 
### Load Warp (Role: 0x1)

 The Load warp handles TMA loads from global memory to SMEM [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp432-657](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L432-L657) It manages double-buffering for `smem_q` to overlap loads with computation [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp249-252](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L249-L252)

 
### Mma Warps (Role: 0x2)

 Two Mma warps perform Tensor Core matrix multiplications, accumulating results in TMEM. They use `UMMA::ScaleOut` to control whether to zero the accumulator or add to it [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp787-790](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L787-L790)

 
### Compute Warps (Role: 0x3)

 Eight Compute warps handle softmax and dsoftmax calculations [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp1132-1402](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L1132-L1402) They are split into two warpgroups that cooperate using named barriers like `TransformBarrier` [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp1313-1316](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L1313-L1316)

 
### Reduce Warps (Role: 0x4)

 Four Reduce warps handle dQ accumulation and writeback using TMA reduction operations `tma_red_dq` [csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp1405-1499](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/sm100/prefill/dense/kernel/sm100_fmha_bwd_kernel_tma_warpspecialized.hpp#L1405-L1499)
