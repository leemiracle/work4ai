  The C++ API layer provides the architecture-aware dispatch mechanism between the Python bindings and the CUDA kernel implementations. This layer is responsible for:

 
 - **Architecture detection** via the `Arch` struct to identify GPU capabilities (SM90/SM100) [csrc/api/common.h21-41](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/api/common.h#L21-L41)
 - **Feature validation** through the `ImplBase` dispatcher pattern to ensure kernel compatibility [csrc/api/common.h160-231](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/api/common.h#L160-L231)
 - **Template specialization dispatch** using compile-time macros for performance-critical paths [csrc/api/common.h51-99](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/api/common.h#L51-L99)
 - **Type-safe parameter structures** to organize kernel launch parameters (e.g., `DenseAttnDecodeParams`, `SparseAttnDecodeParams`) [csrc/params.h19-103](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L19-L103)
 
 The core API infrastructure is defined in [csrc/api/common.h](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/api/common.h) which provides the foundational abstractions used by all kernel implementations.

## Template Dispatch Macros

 The C++ API provides compile-time dispatch macros that generate specialized template instantiations for performance-critical parameters. These macros enable the compiler to optimize for specific configurations without runtime overhead.

 
| Macro | Purpose | Supported Values |
|---|---|---|
| DISPATCH_NUM_HEADS | Dispatch on number of attention heads | 64, 128 csrc/api/common.h51-62 |
| DISPATCH_HEAD_DIM | Dispatch on head dimension | 512, 576 csrc/api/common.h64-75 |
| DISPATCH_BOOLEAN_FLAG | Dispatch on boolean flag | true, false csrc/api/common.h77-86 |
| DISPATCH_MODEL_TYPE | Dispatch on model type enum | ModelType::V32, ModelType::MODEL1 csrc/api/common.h88-99 |

## Enum-to-String Conversion Utilities

 The C++ API provides compile-time enum-to-string conversion for debugging and error reporting. This enables human-readable feature names in validation error messages.

 
 - `get_static_enum_name<value>()`: Uses compiler-specific `__PRETTY_FUNCTION__` or `__FUNCSIG__` to extract enum name at compile time [csrc/api/common.h102-121](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/api/common.h#L102-L121)
 - `get_dynamic_enum_name(value)`: Performs runtime lookup in a compile-time generated array of strings [csrc/api/common.h133-141](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/api/common.h#L133-L141)

## Core Parameter Structures

 Kernel parameters are organized into specialized structs to ensure type safety and memory alignment.

 
### DenseAttnDecodeParams

 Used for dense decoding operations.

 
 - `b`, `s_q`, `h_q`, `h_k`: Batch and head dimensions [csrc/params.h22-26](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L22-L26)
 - `q_ptr`, `k_ptr`, `o_ptr`: Data pointers for Q, K, and Output [csrc/params.h32-34](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L32-L34)
 - `block_table`, `page_block_size`: Paged KV cache configuration [csrc/params.h47-49](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L47-L49)
 - `tile_scheduler_metadata_ptr`: Pointer to `DecodingSchedMeta` for work distribution [csrc/params.h52](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L52-L52)
 
 
### SparseAttnDecodeParams

 Extends parameters for sparse attention mechanisms.

 
 - `indices`, `topk`: Sparse attention indices and K-value [csrc/params.h73](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L73-L73)
 - `model_type`: Enum for `V32` or `MODEL1` [csrc/params.h69](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L69-L69)
 - `extra_kv`, `extra_indices`: Support for secondary/extra KV cache parts [csrc/params.h81-82](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L81-L82)
 - `lse_accum`, `o_accum`: Accumulators for Split-KV reduction [csrc/params.h96-97](https://github.com/deepseek-ai/FlashMLA/blob/15f13e50/csrc/params.h#L96-L97)
