# 02 — 数据增强深挖：从翻转到大模型生成

> 「讲透数据」第二章。01 讲了 Data-Centric AI 的理念。本篇深入**数据增强**（Data Augmentation）——怎么从有限数据"变"出更多有效训练样本。这是不增加采集成本就能提升模型的方法。

---

## 1. 灵魂：同一种信息，多种表象

$$
\boxed{\text{增强} = \text{保持语义不变，变换表象} \quad \to \quad \text{模型学到不变性}}
$$

- 翻转的猫还是猫（语义不变，像素变）
- 同义改写的句子还是同义（语义不变，token 变）

模型从增强数据中学到**什么是不变的**（语义/结构），什么是可变的（视角/措辞）。

---

## 2. 图像增强（CV 经典）

### 2.1 基础变换

| 方法 | 效果 | 风险 |
|---|---|---|
| **翻转**（水平/垂直）| 位置不变 | 6/9 翻转后变 9/6 |
| **旋转**（小角度）| 角度不变 | 数字 6/9 |
| **裁剪** | 尺度不变 | 可能丢目标 |
| **颜色抖动** | 光照不变 | 过度可能改类别 |
| **Cutout** | 遮挡鲁棒 | — |

### 2.2 Mixup（2018）

$$
x_{\text{new}} = \lambda x_1 + (1-\lambda) x_2, \quad y_{\text{new}} = \lambda y_1 + (1-\lambda) y_2
$$

两个样本**线性混合** → 创造"中间态"样本。模型学到**连续的决策边界**而非离散。

### 2.3 CutMix

把一个样本的**矩形区域**粘贴到另一个上——比 Mixup 更自然（保留局部纹理）。

### 2.4 AutoAugment / RandAugment

用**强化学习/随机搜索**自动找最优增强策略组合——比手工设计好。

---

## 3. 文本增强（NLP）

### 3.1 词汇级

- **同义词替换**（WordNet/上下文嵌入）→ 换词不换义
- **随机删除/插入/交换** → 增加鲁棒性

### 3.2 回译（Back-Translation）

```
中文 → 机器翻译 → 英文 → 机器翻译 → 中文（改写版）
```

**语义基本不变，表述变化** → 增加多样性。旧版机器翻译质量限制了效果。

### 3.3 LLM 生成（现代主流）

用 GPT-4 生成改写/扩展/变体：

```
Prompt: 改写以下句子，保持语义不变，使用不同表述：
"这家餐厅的服务很好"
→ "这里的侍者非常周到" / "服务质量令人满意" / ...
```

比传统方法多样性强，但要注意**不改变语义**（LLM 可能过度改写）。

---

## 4. 音频/视频增强

- **音频**：加噪声/变速/SpecAugment（掩蔽频谱）
- **视频**：时间裁剪/帧重排/混合

---

## 5. 什么时候增强有用

| 场景 | 增强有用吗 | 理由 |
|---|---|---|
| **数据少**（<10K）| ✅ 强烈有用 | 数据稀缺时增强收益大 |
| **过拟合**（train↓ test↑）| ✅ | 增强等效正则 |
| **数据多**（>1M）| △ 弱 | 数据够多时增强边际收益小 |
| **领域特定** | ⚠️ 要小心 | 医疗图像翻转可能改变诊断（左右心房不对称）|

> 🎯 **增强的本质是归纳偏置**——你告诉模型"这些变化不重要"。如果变化其实重要（翻转医学图像），增强有害。

---

## 6. 合成数据（LLM 时代的新范式）

### 6.1 用大模型生成训练数据

- Alpaca/self-instruct：用 GPT-4 生成指令-回答对，训练小模型
- Constitutional AI：用 AI 自我修正生成安全数据

### 6.2 Model Collapse 风险

如果用 AI 生成的数据再训 AI → **退化**（讲透数据 03 章）。合成数据必须混入真实数据。

### 6.3 领域特异合成

- 医疗：GAN 生成合成病历（隐私安全）
- 自动驾驶：游戏引擎生成场景（可控）
- 代码：变异已有代码生成测试用例

---

## 7. 批判性

- **增强不是免费午餐**：过度增强引入噪声，可能降性能
- **增强策略是经验**：不同任务最优策略不同，需实验
- **合成数据的根本矛盾**：AI 生成的数据继承了 AI 的偏见——可能放大

> **诚实结论**：数据增强是最实用的 ML 技巧之一——简单、有效、零采集成本。但它的本质是"注入归纳偏置"——增强对了帮模型学不变性，增强错了教模型错东西。
