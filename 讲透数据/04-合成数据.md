## 一、直觉层

### 1.1 一个具体时刻

> 2023 年 6 月，Microsoft 的 Sëbastien Bubeck 在 Phi-1 论文里写下一句话震惊同行：1.3B 参数的代码模型，只用 **"textbook quality" 合成数据**，在 HumanEval 上**超过用 100 倍数据量训练的模型**。秘诀不是架构——是让 GPT-3.5 精心**生成"教科书级别"的 Python 例子**，而不是抓 GitHub 海量脏数据。
>
> 几乎同时，斯坦福的 Self-Instruct 团队（Wang et al. 2022）和 WizardLM 的 Evol-Instruct（Xu et al. 2023）在指令侧走另一条路：让 LLM **自己提问、自己进化难度**。Anthropic 的 Constitutional AI（Bai et al. 2022）又把它推到对齐侧——**让模型按一份"宪法"自批自改**。
>
> **角色**：你（数据工程师）。**冲突**：真实数据用完了，但合成数据有 Model Collapse 诅咒（[03 章](./03-Model-Collapse.md)）。**时刻**：你看着 Phi 团队的曲线交叉——意识到**合成不是"无中生有"，是用一个贵模型去蒸馏出便宜模型**，而"质量"是用算力换出来的。

这就是本章：**合成数据的四条主流方法谱系，以及它们各自踩过的坑**。

### 1.2 为什么需要合成数据

| 动机 | 解释 |
|---|---|
| **突破数据墙** | 公开人类文本 2026-2028 用尽（[00 章](./00-数据是新的代码.md)）|
| **可控** | 想要数学题 → 让模型生成数学题，不必去爬奥数 PDF |
| **对齐** | 生成"安全 / 有用"示范，绕开人类标注瓶颈 |
| **降本** | GPT-4 标 1M 条数据比雇专家便宜几个数量级 |
| **长尾** | 真实数据里稀缺的主题（罕见语言、罕见技能），合成可补 |

## 二、方法谱系

### 2.1 Self-Instruct（Wang et al. 2022）

**思路**：用 175 条种子指令，让 LLM **自动生成新指令 + 输入 + 输出**，再用过滤器去重 / 去低质。Alpaca、Vicuna 都是这个路线。

```
种子指令（175 条人工）
   ↓ LLM 生成新指令（如 "Classify the sentiment of..."）
   ↓ LLM 生成对应输入 + 输出
   ↓ 过滤（ROUGE-SIM 去重、长度过滤、毒性过滤）
指令数据集（52K 条，Alpaca 用 GPT-3.5 生成成本约 500 美元）
```

**坑**：生成的指令**分布很窄**——大半是"分类""翻译""摘要"的变体；难度也偏低。

### 2.2 Evol-Instruct（WizardLM，Xu et al. 2023）

**思路**：在 Self-Instruct 上加一个"进化算子"——把简单指令**迭代变复杂**：

```
种子："写一个加法函数"
   ↓ in-depth evolving（加深）：→ "实现支持大整数的加法，处理溢出"
   ↓ in-breadth evolving（加宽）：→ "写一个泛型的数值运算接口"
   ↓ 淘汰无效进化（重复、跑题）
复杂指令集
```

**收益**：指令难度分布显著拉宽，WizardLM 在复杂任务上超过同尺寸 Alpaca。

**坑**：进化的"复杂度"是 LLM 自己评的——它会**自欺**，把"啰嗦"当"复杂"。

### 2.3 Phi 路线（Microsoft，Bubeck et al. 2023-2024）

**核心宣言**："Textbook quality > Quantity"。让 GPT-3.5/4 **生成结构化的、像教科书一样的代码 / 推理数据**——不是抓 Stack Overflow 的问答碎片。

```
"教科书"特征：
  - 有清晰的概念引入
  - 有动机和反例
  - 循序渐进
  - 代码可运行、风格规范
```

Phi-1（1.3B）→ Phi-2（2.7B）→ Phi-3（mini/small/medium）反复证明：**"少而精"胜过"多而杂"**。

**坑**：Bubeck 团队承认"textbook quality"**没有自动度量**——靠人审 + 下游 benchmark 调，**不可大规模复制**。这是 Quantity → Quality 范式转移里最深的开放问题。

### 2.4 Constitutional AI（Anthropic，Bai et al. 2022）

**思路**：让模型**自批自改**——给定一份"宪法"（一组原则，如"不要帮助制造武器"），模型先生成 response，再**对照宪法自我批评、自我改写**：

```
用户 prompt → 模型生成 response v1
   ↓ 模型读取宪法 → 找出 v1 的问题
   ↓ 模型改写为 response v2（更安全 / 更有用）
   ↓ 用 (prompt, v2) 做 RLHF 训练
```

**收益**：**大幅减少对人类标注的依赖**——RLHF 里最贵的是人类偏好数据，CAI 用模型评分替代。

**坑**：宪法本身就是**人写的**，模型遵守宪法的"严谨度"无法验证——容易在长尾 case 上崩。

### 2.5 R1 蒸馏（DeepSeek 2025 起）

**思路**：用一个强 reasoning 模型（如 DeepSeek-R1）**生成 chain-of-thought 轨迹**，把轨迹当数据蒸馏给小模型。本质是**"行为克隆"**——小模型学的不是知识，是推理风格。

```
R1 在数学 / 代码题上生成 <think>...</think><answer>...</answer>
   ↓ 过滤（答对的保留）
   ↓ 蒸馏给 Qwen / LLaMA 系小模型
小模型获得"显式推理"能力
```

**坑**：小模型容易学到**推理的"形式"而非"内核"**——长 CoT 但答案错，比短 CoT 答案错更难调试。

## 三、数学层

### 3.1 合成数据分布偏移的 KL 视角

设真实数据分布 $p_{\text{real}}$，合成数据分布 $q_{\text{synth}}$。在合成数据上训练，期望风险：

$$R_{\text{synth}}(f) = \mathbb{E}_{x \sim q_{\text{synth}}}[\ell(f(x), y)]$$

但真实评估风险：

$$R_{\text{real}}(f) = \mathbb{E}_{x \sim p_{\text{real}}}[\ell(f(x), y)]$$

两者差由 **KL 散度** bound（变分法标准结果）：

$$|R_{\text{real}}(f) - R_{\text{synth}}(f)| \leq C \cdot \sqrt{D_{\text{KL}}(p_{\text{real}} \| q_{\text{synth}})}$$

**含义**：合成数据越偏离真实分布，训练-评估 gap 越大。**这正是 Model Collapse 的源头**——多代合成后 $q$ 漂离 $p$，KL 散度累积（见 [03 章](./03-Model-Collapse.md) Shumailov 的几何级数证明）。

### 3.2 蒸馏的信息瓶颈

把 teacher $T$ 的输出分布蒸馏给 student $S$，目标是最小化：

$$\mathcal{L}_{\text{distill}} = (1-\alpha) \cdot \text{CE}(y, S(x)) + \alpha \cdot D_{\text{KL}}(T(x) \| S(x))$$

$\alpha$ 调"硬标签 vs 软标签"权重。**Phi/R1 路线偏 $\alpha > 0.5$**（吃 teacher 的暗知识），**Self-Instruct 路线偏 $\alpha \to 0$**（只用 hard label）——这是两种范式效果不同的根因。

### 3.3 Mode Collapse 的概率密度视角

合成数据生成器 $G$（一个已训好的 LLM）会**低估真实分布的尾部**（采样温度、top-p 截断、安全过滤都加剧这一点）：

$$q_{\text{synth}}(x) \propto p_{\text{teacher}}(x) \cdot \mathbb{1}[\text{safe}(x)] \cdot \mathbb{1}[\text{diverse}(x)]$$

两个 indicator 都会把 $q$ 拉向 $p$ 的高密度区——**长尾消失**。多代递归后 $q^{(n)} \to \delta_{\text{mode}}$（点质量），这是 [03 章](./03-Model-Collapse.md) σ → 0 的另一种叙述。

## 四、代码层

最小可跑的 Self-Instruct 风格合成（用 OpenAI 兼容 API）：

```python
# pip install openai
from openai import OpenAI
import json, re

client = OpenAI()  # 走环境变量 OPENAI_API_KEY

SEED = [
    "写一个函数判断字符串是否为回文",
    "把一段中文翻译成英文",
    "给一个数组分两半并返回较大的那一半",
]

GEN_PROMPT = """你是指令生成器。给定种子指令，请生成 5 条**风格多样、难度递增**的新指令。
要求：
- 不要照抄种子
- 覆盖代码、推理、写作三类
- 每条指令后跟一个示例输入和期望输出
种子：
{seeds}
输出 JSON 数组：[{{"instruction": ..., "input": ..., "output": ...}}, ...]
"""

def synth_batch(seeds):
    rsp = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": GEN_PROMPT.format(seeds=json.dumps(seeds, ensure_ascii=False))}],
        temperature=0.9,   # 高温保多样性
    )
    return json.loads(rsp.choices[0].message.content)

def filter_quality(items):
    kept = []
    seen = set()
    for it in items:
        key = re.sub(r"\W+", "", it["instruction"])[:32]
        if len(it["instruction"]) < 5 or key in seen:
            continue
        seen.add(key)
        kept.append(it)
    return kept

# Evol-Instruct 进化算子（最小版）
def evolve(instruction):
    prompt = f"把下面这条指令变复杂（加深或加宽），输出新指令：\n{instruction}"
    rsp = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.7,
    )
    return rsp.choices[0].message.content

# CAI 自批自改（最小版）
CONSTITUTION = ["不要输出有害内容", "回答要基于事实，不要编造"]

def cai_rewrite(prompt, response_v1):
    critique = client.chat.completions.create(
        model="gpt-4",
        messages=[
            {"role": "user", "content": f"宪法：{CONSTITUTION}\n用户问：{prompt}\n当前回答：{response_v1}\n请找出违反宪法的问题，并改写"},
        ],
    )
    return critique.choices[0].message.content
```

**反直觉数字**：Alpaca 用 GPT-3.5 生成 52K 条 Self-Instruct 数据，**总成本约 500 美元**——而 OpenAI 的 InstructGPT 标注同样规模人类数据成本是**数十万美元**。合成数据的成本优势是数量级的，**但前提是 teacher 模型够强且 license 允许**（见 [06 章](./06-数据伦理与合规.md)）。

## 五、不足层

诚实标注合成数据的边界：

- **已证明的**：在 teacher 足够强 + distill KL 目标正确的前提下，student 在 teacher 任务上的性能**有下界保证**（distillation theory）。
- **经验但未证**：Phi 的"textbook quality"显著优于普通合成——但**什么叫 textbook quality 没有自动度量**，不可复制。
- **未解**：
  1. **Mode Collapse**：所有方法最终都被 Shumailov 诅咒笼罩——多代合成必然退化（[03 章](./03-Model-Collapse.md)）。
  2. **分布窄化**：Self-Instruct/Evol-Instruct 生成的指令**真实多样性远低于人类需求**，长期训会让模型"会做的题型越训越像"。
  3. **Teacher 偏见继承**：合成数据**继承 teacher 的偏见、幻觉、安全漏洞**——CAI 能缓解但不能根除。
  4. **License 风险**：用 GPT-4 生成数据训练竞品模型违反 OpenAI ToS；用 Llama 生成的数据商业化受 Llama license 约束（见 [06 章](./06-数据伦理与合规.md)）。
  5. **评估污染**：合成数据很容易**意外混入 benchmark 题面**（teacher 见过 eval set），让 student 在 benchmark 上虚高。

## 六、费曼回炉（L2 自检）

- **F2 卡壳点**：我最初把"合成数据"等同于"模型蒸馏"。重读 Phi 论文 + Self-Instruct + CAI 后才意识到这是**四个正交维度**——内容质量（Phi）、指令多样性（Self-Instruct/Evol）、对齐方式（CAI）、知识迁移（R1 蒸馏），可以任意组合。卡壳是低估了方法的多样性。
- **F3 术语翻译**：
  - "Self-Instruct" → 模型自己给自己出题、自己答题，靠种子指令引导。
  - "Evol-Instruct" → Self-Instruct 的升级版，加一个"进化算子"把简单指令变复杂。
  - "Constitutional AI" → 给模型一份"宪法"（一组原则），让它自批自改，少依赖人类标注。
  - "Textbook quality" → Phi 团队说的"像教科书一样结构清晰、有动机、有反例"的数据，**不可自动度量**。
- **F4 回炉**：v1 把所有合成方法混在一节；v2 按四条独立谱系拆开 + 数学层加 KL 视角，把 mode collapse 的根因和 03 章对齐。
