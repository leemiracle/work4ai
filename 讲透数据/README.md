# 讲透数据（Data）

> 算力、算法、数据是 AI 三要素——但**前两个都被讨论得太多了，第三个被严重低估**。
>
> 2024-2026 业界共识：**真正的瓶颈不是算力，是数据**。互联网公开数据快被训完（"数据墙"），合成数据是解药但会引发 Model Collapse，数据质量比数据量更重要但**怎么衡量质量没有共识**。本系列把"数据"从"工程杂物"提升到**第一公民**——这是 AI 工程里被忽视的根基。
>
> 一句话定位：[`讲透基础模型`](../讲透基础模型/) 讲"模型怎么训"，本系列讲"**用什么训**"——前者是引擎，后者是燃料。
>
> 配套：[`讲透AI应用全景/07-AI for AI`](../讲透AI应用全景/07-AI for AI.md) 第③层（AI 训练 AI）+ [`讲透微调`](../讲透微调/)（数据对齐）+ [`讲透科学的现代性/02-可重复性危机`](../讲透科学的现代性/02-可重复性危机.md)（数据污染）

## 为什么单独开

- **数据墙来了**：Common Crawl 已被 LLM 训过 N 遍，2026 年公开人类文本数据基本用尽
- **合成数据是双刃剑**：Phi/R1 蒸馏靠它，但 Model Collapse 是根本性风险
- **数据质量没有统一理论**：Quantity → Quality 范式转移在进行，但"什么是好数据"仍是经验主义
- **被忽视的根基**：多数书/课讲模型，少有讲数据；但**做实际 ML，80% 时间在搞数据**

## 🎭 欺骗动力学视角：数据污染与投毒

> 承接 [`欺骗动力学-社会进步的隐秘引擎.md`](欺骗动力学-社会进步的隐秘引擎.md) §5。

### 三问

1. **讲透数据 防的是什么欺骗？** → 训练数据被注入恶意样本或低质内容。
2. **被什么攻破？** → 数据集污染 / 后门触发器 / Model Collapse。
3. **沉淀进哪条主链？** → 验证主链——数据完整性审计 / 数据卡 / 数据集复现。

### 一句话

> 数据是模型的上游，污染的数据就是在源头注入欺骗；数据工程的核心是反投毒。
