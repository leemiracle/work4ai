## experiment runs 

These provides the scripts and other resources used to perform the feasbility study in our forthcoming ICML paper [**Understanding the Logic of Direct Preference Alignment through Logic**](https://arxiv.org/abs/2412.17696). 

- `best_qwen.sh`: The training scripts for the best qwen models reported. See inside for additional details (e.g., [wandb runs](https://wandb.ai/ai2-llm/icml_declarative_preference))
- `run_inference.sh`: How to run inference uses the models produced above.
