# 08 · 让 AI 决策：强化学习的王者归来（2013-2026）

> **时间**：2013-2026，13 年
> **核心冲突**：RL 长期是"玩具"。怎么让 RL 进入真实世界？
> **嵌入概念**：MDP、Q-learning、DQN、Policy Gradient、PPO、AlphaGo、AlphaZero、RLHF、o1

---

## 🎬 故事

### 1989 · Watkins 的 Q-learning

Christopher Watkins，Cambridge PhD。1989 年博士论文提出 **Q-learning**：

**核心思想**：学一个 Q 函数 Q(s, a)——在状态 s 做动作 a，期望回报是多少。

Q-learning 算法：
```
Q(s, a) ← Q(s, a) + α [r + γ max_a' Q(s', a') - Q(s, a)]
```

简单优雅。但**90 年代 RL 只能玩小游戏**——状态空间小。

### 2013 · DeepMind 的 Atari 实验

**Demis Hassabis**，2010 创立 DeepMind。2014 被 Google 4 亿英镑收购。

2013 年 12 月，DeepMind 发 **"Playing Atari with Deep RL"**：

- 一个 **CNN + Q-network** 玩 Atari 游戏
- 输入：游戏画面（像素）
- 输出：每个动作的 Q 值
- **同一个算法，玩 49 个游戏，29 个超过人类**

**这是 RL 的 ImageNet 时刻**——**深度 RL（Deep RL）诞生**。

### 2015 · DQN 论文 Nature

2015 年 2 月，**"Human-level control through deep RL"** 发 Nature。算法叫 **DQN**。

DQN 的两大创新：
1. **Experience Replay**：把 (s, a, r, s') 存池子，随机 batch 训练。打破样本相关。
2. **Target Network**：用一个"延迟更新"的网络算 target，稳定训练。

### 2016 年 3 月 · AlphaGo 击败李世乭

整个世界震动。**围棋曾被认为 AI 至少 10 年内攻不下**。

AlphaGo 的秘密：
1. **CNN** 学棋盘模式（supervised learning from human games）
2. **RL** 自我对弈提升（policy gradient + value network）
3. **MCTS**（蒙特卡洛树搜索）：在 inference 时搜索

### 2017 · AlphaGo Zero 颠覆

**AlphaGo Zero**（2017）：**完全不用人类棋谱**。从零自我对弈。

3 天超过 AlphaGo Lee。**21 天超过 AlphaGo Fan**。

**人类几千年的围棋知识，AlphaGo Zero 21 天重新发现 + 超越**。

### 2017 · PPO 诞生

**OpenAI**（Schulman et al.）发 **PPO**（Proximal Policy Optimization）。

**为什么 PPO 重要**：之前 policy gradient（REINFORCE / TRPO）不稳定 / 计算贵。**PPO 是简单 + 稳定 + 高效**。

```
PPO loss = E[min(r_t · A_t, clip(r_t, 1-ε, 1+ε) · A_t)]
```

`r_t = π(a|s) / π_old(a|s)`（重要性采样比）

**2017 后 PPO 成为 RL 标准**——AlphaGo Zero / OpenAI Five / ChatGPT RLHF 都用 PPO。

### 2018 · OpenAI Five 击败人类

5 个 PPO agent 组队打 Dota 2，**击败业余人类队伍**。

2019 击败世界冠军 OG（**有让步条件**：固定英雄 / 无幻觉）。

### 2022 · RLHF 让 ChatGPT 爆炸

如前一篇 06 讲的：PPO + reward model = ChatGPT。

**RL 从"玩游戏"变成"训 LLM"**——这是 RL 最重要的应用。

### 2024 · AlphaProof 数学证明

2024 年 7 月，DeepMind **AlphaProof + AlphaGeometry 2** IMO 银牌水平。

**AlphaProof 的秘密**：
- 用 **Lean 4** 当环境
- **RL** 训练证明搜索
- verifiable reward（证对了 1，错了 0）

**这是 RLVR（RL with Verifiable Rewards）的胜利**——不需要 reward model，规则就是 reward。

### 2024-2025 · o1 / R1 推理革命

**OpenAI o1**（2024-09）：让模型"思考很久"再答。**test-time scaling**。

o1 用 **RL** 训练推理（具体细节未公开）。**数学 / 代码准确率大幅提升**。

**DeepSeek R1**（2025-01）：开源 o1 级别推理。**GRPO + verifiable rewards**。

**RLVR 范式**：
- 数学：对错明确
- 代码：单元测试通过与否
- 证明：Lean 通过与否

**RL 再次王者归来——这次是推理**。

## 🧠 核心概念

- **MDP**（Markov Decision Process）：状态 + 动作 + 奖励 + 转移。RL 的数学模型。
- **Q-learning**：学 Q(s, a)。**值函数方法**。
- **DQN**：Q-learning + 神经网络 + experience replay + target network。
- **Policy Gradient**：直接学策略 π(a|s)。
- **PPO**：2017 OpenAI。**稳定 policy gradient**。RL 标准。
- **MCTS**（Monte Carlo Tree Search）：搜索算法。AlphaGo 用。
- **RLHF**：reward model + PPO，让 LLM 对齐。
- **RLVR**：verifiable rewards（规则驱动），不需要 reward model。**o1 / R1 / AlphaProof**。

## 🎨 类比

- **MDP** = 一盘棋：当前局面（state）+ 你能下的子（action）+ 赢 / 输（reward）
- **Q-learning** = 学一个"评委"：对每个 (state, action) 打"未来回报"分
- **DQN** = Q-learning + 神经网络评委 + 记忆池（experience replay）+ 双评委（target network）
- **Policy Gradient** = 直接学"该下什么子"
- **PPO** = 谨慎调整策略——每次只动一点点，不破坏已有成果
- **MCTS** = 在脑子里模拟 N 局棋，看哪个动作胜率高
- **RLHF** = 用一个"老板"（reward model）不断给员工（policy）打分，员工调整
- **RLVR** = 不用老板，规则就是裁判——数学对就是 1，错就是 0

## 💡 反直觉发现

1. **AlphaGo Zero 不需要人类知识**：21 天超过人类几千年积累。**人类不是必需**。

2. **PPO 不是最优，但是最稳**：PPO 论文里不声称 SOTA。**但简单稳定 → 工程选择**。ChatGPT 选 PPO 就是这个原因。

3. **RLHF 把 RL 推上主流**：2017-2021 RL 是小众。2022 ChatGPT 后**所有 LLM 都用 RL**。

4. **RLVR 比 RLHF 更强（在某些任务）**：数学 / 代码这种**对错明确**的任务，verifiable reward 比 reward model 强。**o1 / R1 / AlphaProof 都用 RLVR**。

5. **test-time scaling 是新维度**：传统 scaling 是"训更大模型"。**o1 揭示"推理时多算"也是有效维度**。

6. **围棋死过 2 次**：1997 Deep Blue（象棋）后大家觉得围棋还很远。2016 AlphaGo 杀死。**预测 AI 进度几乎不可能**。
