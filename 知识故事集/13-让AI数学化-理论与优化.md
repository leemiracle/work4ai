# 13 · 让 AI 数学化：理论与优化（2010-2026）

> **时间**：2010-2026，16 年
> **核心冲突**：深度学习"工作得很好"，但**没人知道为什么**。理论圈和工程圈分裂。
> **嵌入概念**：泛化界、双层下降、Scaling Laws、凸优化、信息论、PAC

---

## 🎬 故事

### 2010s · 经典 ML 理论的工具箱

经典 ML 理论（2000-2015）有一套工具：
- **VC 维**（Vapnik-Chervonenkis）
- **Rademacher complexity**
- **PAC 学习**（Probably Approximately Correct）
- **bias-variance tradeoff**

这些理论给出"泛化上界"——模型在训练集表现好，测试集最坏能差多少。

**问题**：这些上界**对深度学习完全失效**。

### 2015 · 深度学习的理论丑闻

2015 年 **Zhang, Bengio, Hardt, Recht, Vinyals** 发 **"Understanding deep learning requires rethinking generalization"**：

**实验**：
- 训 ResNet on ImageNet（真标签）→ 0% 训练误差
- 训 ResNet on ImageNet（**完全随机标签**）→ **也 0% 训练误差**

**意味着**：ResNet 参数容量**大到可以记住任何东西**——但泛化能力很强。

**经典理论解释不了**。VC 维 + Rademacher 都给出"训练-测试差距应该巨大"的预测，但实际几乎无差距。

**这是深度学习理论的丑闻**——大家用得很好，但**不知道为什么 work**。

### 2017-2020 · 隐式正则的发现

- **2017 Keskar**：sharp vs flat minima
- **2018 Neyshabur**：norm-based generalization bounds
- **2019**：**SGD 隐式偏好简单解**

**核心 idea**：SGD 不是随机优化——它**隐式偏好"平坦极小值" / "低范数解"**，所以泛化好。

但具体机制**至今不清楚**。

### 2019 · 双层下降的复现

**Belkin et al. 2019 "Reconciling modern machine-learning practice and the bias-variance trade-off"**：

经典 bias-variance：模型大到一定程度，测试误差上升。

**Belkin 的发现**：模型继续变大，**测试误差会再下降一次**。

**double descent（双层下降）**：
```
测试误差
   ↑
   │●     经典 bias-variance
   │ \   ╱
   │  \ ╱
   │   ● ← interpolation threshold（模型刚好能记住）
   │   │
   │   ╲
   │    ╲
   │     ╲ ← "现代" regime：模型继续大，反而更好
   └────────────→ 模型容量
```

**意义**：经典 bias-variance 是错的——**只在 interpolation 之前对**。深度学习在 interpolation 之后。

### 2020 · Scaling Laws 给出可预测性

**Kaplan et al. 2020**（Anthropic / Johns Hopkins）——见故事 05。

Scaling Laws 给出**经验可预测性**：
```
L(N, D, C) = 幂律
```

**理论圈震动**：原来 scale 不是黑洞，**有规律**。

但**为什么是幂律**？至今没完美理论解释。

### 2022 · Chinchilla 修正

Chinchilla（见故事 05）修正了 Kaplan 的具体常数，**但幂律结构没变**。

### 2020+ · 现代深度学习理论

- **Jaeckel / Nakkiran**：双层下降的理论
- **Roberts et al. 2022**：feature learning 的 NTK 视角
- **Bordelon et al. 2024**：neural scaling laws 的理论模型

**这些理论都在尝试**——但**没人完全解释清楚**。

### 凸优化：能解释的部分

虽然深度学习是非凸的，但**很多 ML 子问题还是凸的**：

- **SVM**：凸 QP
- **Logistic regression**：凸
- **Lasso / Ridge**：凸
- **PCA**：凸（SVD）
- **Matrix completion**：凸（核范数最小化）

凸优化理论完备（KKT 条件、强对偶、Slater 条件）。**Boyd & Vandenberghe《Convex Optimization》** 是圣经。

### 信息论：连接一切

**信息论**（Shannon 1948）是 AI 的"通用语言"：
- **cross-entropy = entropy + KL divergence**
- **VAE 的 ELBO 用 KL**
- **RLHF 的 reward 用 KL**
- **Diffusion 的 score = ∇log p(x)**

**MacKay《Information Theory, Inference, and Learning Algorithms》** 是神书——同时讲信息论 + 概率 + ML。

### 为什么理论重要

很多人觉得"我不做理论，工程会用就行"。**这是误解**：

1. **理论让你识别 hype**：Scaling Laws 让你不信"少量数据训大模型"这种鬼话。
2. **理论让你 debug**：知道 double descent，你就不会用 interpolation 临界点的模型。
3. **理论让你设计实验**：知道 bias-variance，你就知道什么时候减小 vs 增大模型。
4. **理论让你读懂论文**：NeurIPS 论文 math section 不再跳过。

**理论不是"远离实战"，是"实战的根基"**。

## 🧠 核心概念

- **VC 维 / Rademacher complexity**：经典泛化上界工具。**对深度学习失效**。
- **PAC 学习**（Probably Approximately Correct）：可学习性的理论框架。
- **bias-variance tradeoff**：经典理论。**被 double descent 修正**。
- **double descent**：模型过 interpolation 临界点后，测试误差再下降。
- **隐式正则**：SGD 隐式偏好"平坦极小值 / 低范数解"。
- **Scaling Laws**：loss 幂律。**深度学习经验理论**。
- **凸优化**：KKT 条件 / 强对偶 / Slater 条件。
- **信息论**：熵 / KL / 互信息。**ML 的通用语言**。

## 🎨 类比

- **经典泛化界** = 一条紧身裤：只能装小模型。深度学习的"大屁股"穿不进去
- **双层下降** = 一座山的另一面：传统说"山顶最好"，实际上**山顶是陷阱**，越过山顶继续往上才好
- **隐式正则** = 一个有品味的厨师：你给他任何食材，他倾向于做**简单清爽**的菜（不一定要做"复杂豪华"）
- **Scaling Laws** = 加水加糖浆，浓度按幂律上升
- **凸优化** = 一个**碗**：球放进去自然滚到最低点（最优解）
- **非凸优化** = 一个**山脉**：球可能滚到局部最低，找不到全局最优
- **信息论** = **度量"惊讶"的科学**：罕见事件发生 = 信息量大

## 💡 反直觉发现

1. **经典 ML 理论对深度学习失效**：VC 维 + Rademacher 给出的泛化界**比实际差几个数量级**。**深度学习的成功没有理论解释**。

2. **双层下降颠覆教科书**：你大学学的 bias-variance tradeoff 是**部分错的**。**interpolation 之后才更好**。

3. **Scaling Laws 是经验的，不是理论的**：Kaplan 发现了幂律，**但没人能从第一性原理推导出来**。

4. **SGD 是隐式正则化器**：换成 Adam 有时效果差——不是因为 Adam 错，而是 SGD 的隐式正则更适合深度学习。

5. **凸优化不只是经典 ML**：现代 LLM 训练的子问题（如 Proximal Adam）仍是凸的。**凸优化没死**。

6. **信息论统一 ML**：cross-entropy、KL、ELBO、RLHF reward——**全是信息论量**。

7. **理论 vs 工程分裂**：DeepMind 有理论团队（DeepMind Theory），OpenAI 几乎没有。**两种文化**。
