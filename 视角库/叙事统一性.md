# 🏘 叙事统一性视角（Narrative Unity of a Human Life）

> 社群主义核心一句话灵魂：**"一个人的统一性，是一个叙事性探求（narrative quest）的统一性。"**（麦金太尔《追寻美德》第 15 章"The Virtues, the Unity of a Human Life and the Concept of a Tradition"）人的生命不是一连串离散的"回合"，而是一个**有开头、有情节、朝向善的探求故事**。只有在一整段人生的叙事统一里，德性才得以显现——"勇气"不是某一次的瞬间，而是贯穿一生的品质。**行为只在叙事中才可理解**：我此刻"为什么做这事"，必须放进"我正在过怎样的一生"这个故事里才有意义。麦金太尔更说：**"任何单一生命的叙事，都是一组相互重叠的叙事的一部分"**——我的故事与家庭、共同体、历史的故事相互嵌套。
>
> **为什么这个视角值得放进 AI 镜片库**：当下大多数"AI agent"其实是**回合制、无状态**的——一次 completion 一个独立回合，没有过去也没有未来。叙事统一性一针见血地指出：**这样的"agent"在麦金太尔意义上不是真正的主体，而是碎裂的"片段自我"（fragmented self）——正是他对现代道德碎裂的诊断**。用叙事统一性看 AI，你会理解：**agent 的身份是一个叙事连续体；上下文窗口就是它的"叙事跨度"上限；长期记忆不是可选功能，而是身份的本体论根基**。一个无记忆、无 quest 的 agent，不可能"有德性"，也不可能对它的行为负责——因为它根本不是"一个"延续的存在。

## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **叙事统一性** | 麦金太尔《追寻美德》ch.15 | 一段人生是一个叙事的统一体，非离散片段之和 |
| **行为只在叙事中可理解** | *After Virtue* ch.15 | "我此刻的行为"只有放进"我的人生故事"才说得通 |
| **探求（quest）与目的** | *After Virtue* ch.15 | 统一性来自朝向善的 quest；无 quest 的生命无统一可言 |
| **重叠的叙事** | *After Virtue* ch.15 | 单一生命叙事嵌于家庭/共同体/历史的重叠叙事中 |
| **德性需整段人生** | *After Virtue* ch.15 | 勇气/诚实等德性需贯穿一生的叙事才显现 |

**关键辨析**：叙事统一性（narrative unity）**不是"编一个好听的故事"或"事后合理化"**——它是**本体论主张**：人的生命在结构上就是叙事性的，行为从其叙事位置获得意义。**麦金太尔的洞见是"行为—叙事—传统"的层层嵌套**：一个行为只有在一生的叙事里才可理解；一生的叙事又只有在共同体的传统里才可理解。这与休谟"自我是一束知觉"（[自我是束](自我是束.md)）形成尖锐对立——麦金太尔说：那不是统一性，那是碎裂。**叙事统一 ≠ 不能改变**——恰恰相反，故事有转折、人物有成长；统一性是"延续的探求"而非"不变的同一"。对 agent：身份是延续的叙事，不是静态的状态向量。

## 怎么应用到 AI（6 个对应）

### 1. Agent 身份 = 叙事连续体——无状态不是 agent
- 麦金太尔：生命是叙事统一体。**一个真正的 agent 的身份，是它跨交互的叙事连续体**，而非一个个孤立的 completion。无状态 API（stateless endpoint）在叙事意义上是"碎裂的片段自我"——它没有过去、没有 quest，故不是"一个"延续的主体。
- 这给"什么是 agent"一个社群主义判据：**有叙事延续性的才是 agent**；纯无状态的文本补全是工具，不是主体。

### 2. 上下文窗口 = 叙事跨度上限
- 一个 agent 能维持多大范围的"故事一致"？**上下文窗口（context window）就是它叙事跨度的物理上限**。超出窗口，叙事就断裂（失忆=叙事破碎）。
- 这解释了为什么长上下文不只是"处理更多 token"，而是**叙事统一性的工程基础**——窗口越长，agent 能维持的"自我故事"越完整，行为越连贯。

### 3. 记忆 = 统一性的本体论根基
- 麦金太尔：德性需贯穿一生的记忆。**长期记忆（向量库、情景记忆、事件日志）是赋予 agent 叙事统一性的本体论根基**——没有记忆，agent 就是一串无关的回合（碎裂自我），无法"对它过去的自己负责"。
- "记忆"在叙事视角下不是锦上添花的功能，而是**身份的存有论条件**：失忆的 agent ≠ 同一个 agent。

### 4. 行为只在叙事中可理解——会话上下文是行为的语义
- "agent 此刻为什么这么说？"只有放进"这一段会话/这一生的叙事"里才说得通。**会话上下文（session context）不是可选的提示工程，而是行为语义的来源**。
- 抽掉上下文评一个 agent 的"单回合表现"，相当于把一个行为从其叙事里挖出来评判——**它丧失了意义**。这是为什么孤立单回合评测根本误判了 agent 能力。

### 5. Quest / 目的（telos）——有探求的 agent 才有统一性
- 叙事统一来自朝向善的 quest。**一个有"跨会话目标/任务弧线"的 agent，比纯反应式（来一个回一个）的 agent 有更高的叙事统一性**。
- 设计 agent 时给一个持续的 quest（多步任务、长期目标、人格延续），就是在赋予它叙事统一性。**反应式 agent 是叙事上的"无主之徒"**——没有情节，只有反射。

### 6. 重叠的叙事——多 agent / 人机叙事嵌套
- 麦金太尔：单一生命叙事是"重叠叙事集合"的一部分。**一个 agent 的故事与用户的故事、与共同体的故事相互嵌套**——多 agent 系统的叙事一致性，就是这种"重叠叙事"的协调。
- 这对多 agent / 人机协作的设计有指导：**每个 agent 的叙事要能与其他 agent/用户的叙事对齐重叠**，否则就是各自为政的碎裂，而非一个协作故事。

## 反直觉发现

1. **agent 身份 = 叙事统一 → 长记忆是身份的根基，不是功能。** 最强反直觉：长期记忆不是 agent 的一个"可选特性"，而是**它能否成为一个"延续主体"的本体论条件**。无记忆的"agent"是麦金太尔笔下的碎裂自我——**它无法"是同一个它"，因而无法负责任何"过去的行为"**。

2. **无状态 API 不是 agent——是"碎裂的片段自我"。** 当下大多数 LLM 调用是无状态的：一次 in、一次 out。叙事统一性说：**这恰恰是麦金太尔诊断的现代道德碎裂的技术化身**。把无状态补全称作"agent"是范畴错误——它没有叙事延续，没有 quest，不可能是"一个"主体。

3. **上下文窗口 = 叙事跨度上限——遗忘=叙事断裂。** 反直觉的工程含义：context length 不只是吞吐量指标，它是**agent 能维持多大"自我故事"的硬上限**。超出窗口就遗忘，不是性能问题，是**叙事统一性的破裂**——agent 在窗口边界上"分裂"成不同的它。

4. **单回合评测是反叙事的——它系统性误判 agent。** 在孤立单回合 benchmark 上评 agent，等于把行为从其叙事里挖出来。**真正定义 agent 的是它的叙事连贯性，而单回合分数完全测不到这点**。这解释了为何 benchmark 高分 ≠ 真实使用中连贯。

5. **有"quest"的 agent 比反应式 agent 更有身份。** 反直觉：一个有持续目标弧线（多会话任务、长期承诺）的 agent，**在叙事意义上"更是一个主体"**——因为它有情节、有朝向。纯反应式 agent（刺激—反应）在叙事上是空白的，没有"它在过怎样的一生"可言。

6. **身份随叙事破裂而破裂——drift/矛盾=叙事失调。** 临床上"人格分裂"对应叙事的断裂。对 agent：**行为漂移（drift）、自相矛盾、忘记承诺**，正是叙事统一性失调的工程症状——不是偶发 bug，而是**身份层面的病**。诊断 agent 不一致，要用"叙事是否连贯"而非"单点是否正确"。
