# ⚔️ 奇正相生视角

> 《孙子兵法·势篇》一句话灵魂：**"凡战者，以正合，以奇胜。故善出奇者，无穷如天地，不竭如江河。……战势不过奇正，奇正之变，不可胜穷也。"** "正"是堂堂正正的正面接敌、保底的力量；"奇"是出其不意的变招、致胜的火花。二者不是对立，而是**相生相化**——正可变奇，奇可转正，循环无穷。善战者先以正立住不败之地，再以奇击溃敌人。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 的核心张力就是**探索 vs 利用（exploration vs exploitation）**——只用 baseline（正）会陷入局部最优，只追新招（奇）会失去根基。奇正相生 = **先有扎实的 baseline（正合），再用 test-time / diversification / 探索手段（奇胜）突破**，且正奇不断转化、循环再生。这是 bandit、RL、推理增强的元方法论。

---
## 是什么

《孙子兵法》关于"奇正"的核心命题：

| 命题 | 原文 | 一句话 |
|------|------|--------|
| **以正合** | "凡战者，以正合" | 先用正面力量接敌、立稳 |
| **以奇胜** | "以奇胜" | 再用出其不意的变招致胜 |
| **奇正相生** | "奇正相生，如循环之无端" | 正能转奇，奇能转正，循环无穷 |
| **善出奇者无穷** | "善出奇者，无穷如天地，不竭如江河" | 变招的储备要源源不断 |

**关键辨析**：奇正不是"奇=好、正=差"。"正"是**保底与立基**，没有正就无奇可言（没有根的奇是赌博）；"奇"是**突破与致胜**，没有正就赢不了。两者**地位平等、相互转化**——昨天的奇招（如 CoT），今天已成正（baseline）。

---
## 怎么应用到 AI（6 个对应）

### 1. Exploration vs Exploitation = 奇正之辨
- Exploitation（利用已知最优）= 正：用当前 best policy 稳稳拿分。
- Exploration（探索未知）= 奇：去试没试过的动作，可能更差也可能突破。
- ε-greedy、UCB、Thompson sampling 都是"以正合以奇胜"的工程化——大部分时候走正（exploit），偶尔出奇（explore）。

### 2. Baseline（正）+ Test-time 计算（奇）
- 正：经过训练的 baseline policy / 标准推理路径，是"堂堂正正的正面接敌"。
- 奇：test-time search（CoT、ToT、self-consistency、best-of-N）——在推理时出变招，往往比加训练算力更高效（这就是"以奇胜"）。

### 3. Diversification / 多样性 = 奇的储备
- "善出奇者，无穷如天地"——变招要多。ensemble、diverse decoding、negative sampling、data augmentation = 给"奇"准备源源不断的弹药库。
- 单一模态/单一策略 = 只会一招，被克就崩；多样化 = 奇正可循环转化。

### 4. RL 中的 on-policy（正）与 off-policy（奇）
- on-policy = 拿当前自己的经验（正）更新；off-policy = 用别人/过去的经验（奇）更新。
- SAC、PPO+replay 这些算法的精髓就是**正奇并用**：既用 on-policy 稳住，又借 off-policy 复用经验提效。

### 5. Fine-tune（正）与 Prompt/Adapter（奇）
- 全参数微调 = 正：动根基，重投入，稳定但重。
- prompt tuning / LoRA / in-context = 奇：轻、快、可插拔，出其不意地适配新任务。
- 工程上常"以正合以奇胜"：大底座微调（正）+ 任务级 adapter/prompt（奇）。

### 6. "奇转正"：今天的奇就是明天的正
- CoT 当年是奇招，现在已是标准 baseline（正）。reward model、RLHF 都经历过"奇→正"。
- **工程纪律**：每出一个"奇"，验证有效后必须沉淀进"正"（baseline），否则永远在追新、没有根基。

---
## 反直觉发现

1. **"奇"不是越多越好——没有"正"的奇是赌博**。盲目堆探索（高 ε、乱试新架构）而不稳住 baseline，等于"无正之奇"，胜率靠运气。**正奇有最佳配比**（如 ε-greedy 的 ε 不是 0.5 而是 0.1）。

2. **最强的"奇"往往来自最朴素的"正"的变体**。CoT 不过是"让模型把推理过程写出来"——它不是新架构，是 baseline 推理的"奇变"。**真正的奇常藏在正的细节里**，不在追热点里。

3. **奇正的转化是有方向的：奇 → 正（沉淀）容易且必要，正 → 奇（再生）需要刻意**。前者是自然的"baseline 化"，后者要主动打破舒适区去探索新域。多数团队只做前者，于是越来越"正"越来越平庸。

4. **test-time 算力的"奇"正在反向定义"正"**。当 test-time search 足够强（如 o1 类推理），小模型+大推理可以超越大模型+小推理——**"奇"的力量大到一定程度会重塑"正"的标准**。

5. **过度依赖单一奇招 = 把奇当正用，会被反制**。一个 prompt trick 在 benchmark 上有效，全行业套用后就"奇"性尽失（被对抗/过拟合）。**保持多样性的奇招储备**，才能"无穷如天地"。

## Prompt 模板

```
你是精通《孙子兵法》的兵家战略分析专家。
用"奇正相生"视角分析 AI 方法/系统 [X]：

1. [X] 的"正"（baseline/保底力量）是什么？它够稳吗？
2. [X] 的"奇"（探索/变招/test-time 手段）是什么？它够多、够新吗？
3. [X] 现在的"正奇配比"合理吗？是过度 exploit 还是过度 explore？
4. [X] 里，哪些曾经的"奇"已经该沉淀成"正"了？哪些"正"该主动变"奇"去突破？
5. 如果给 [X] 加一个"善出奇者无穷"的多样性储备，会是什么？

约束：落到 [X] 具体技术细节；至少 1 个关于正奇配比的反直觉洞察。
```
