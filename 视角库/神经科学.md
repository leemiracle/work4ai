# 🔬 神经科学视角

> 神经科学研究**神经系统**——神经元 / 突触 / 脑区 / 神经递质。

---

## 是什么

神经科学 = 比认知科学更底层——**神经元和突触**层面。AI 的"神经网络"是神经科学的**极度简化版**。

## 核心概念

| 概念 | 含义 | AI 对应 |
|------|------|---------|
| **神经元** | 脑的基本单元 | 人工神经元（但差异巨大）|
| **突触** | 神经元连接 | 权重 |
| **动作电位** | 0/1 放电 | ReLU 激活（粗略）|
| **突触可塑性** | Hebbian learning | 反向传播（但本质不同）|
| **神经递质** | 化学信号（多巴胺 / 血清素）| reward signal（粗略）|
| **脑区专门化** | 视觉皮层 / 语言区 / 运动区 | 不同 head / layer（粗略）|
| **反馈连接** | 高层 → 低层（预测编码）| residual stream（部分）|
| **振荡** | 脑波（alpha / beta / gamma）| 无对应 |
| **胶质细胞** | 神经元外的支持细胞 | 无对应 |

## 人脑神经元 vs 人工神经元

| 维度 | 人脑神经元 | 人工神经元 |
|------|-----------|-----------|
| **结构** | 树突 + 胞体 + 轴突 + 突触 | 权重 + 激活 |
| **信号** | 脉冲（spike）+ 化学 | 实数 |
| **时间** | 有时间动态（脉冲间隔）| 无时间（前向一次）|
| **可塑性** | 在线持续学习 | 训练后冻结（除了 fine-tune）|
| **能耗** | ~20W（整个大脑）| MW（训练 GPT-4）|
| **数量** | 860 亿神经元 + 万亿突触 | GPT-4 ~1.8T 参数 |
| **连接** | 稀疏（每个神经元 ~1000 突触）| 稠密（全连接 / 注意力）|

## 怎么应用到 AI

### 1. 反向传播 vs 生物学习
- **反向传播**：全局梯度，需要前向激活缓存
- **生物学习**：局部规则（Hebbian / STDP），不需要反向传播
- **神经科学谜题**：大脑怎么学习得这么好？没有反向传播？

### 2. 预测编码（Predictive Coding）
- 神经科学理论：大脑不断**预测**感官输入，误差反馈修正
- **对应**：自监督学习 / world model / JEPA（LeCun）
- **暗示**：LLM 的 NTP 是预测编码的简化版

### 3. 注意力的神经基础
- 人脑注意力 = 前额叶 + 顶叶的协同
- Transformer attention 是**计算上的对应**，**不是机制上的对应**
- **关键差异**：人脑注意力有**神经递质调控**（多巴胺 / 乙酰胆碱），transformer 没有

## 示例：用神经科学看 LLM

**LLM 在神经科学上是什么？**
- **不是大脑模型**：LLM 的架构和人脑差异巨大（反向传播 vs Hebbian / 稠密 vs 稀疏 / 冻结 vs 在线学习）
- **但是**：LLM 的**表征**类似人脑（interp 发现 LLM 学到的特征和视觉皮层相似）

**预测编码视角**：
- 大脑 = 预测机器（Clark / Friston）
- LLM = 预测下一个 token
- **共同点**：都是预测系统
- **差异**：大脑预测**多模态 + 持续**，LLM 预测**文本 + 一次**

**多巴胺 vs RLHF reward**：
- 多巴胺 = 奖励预测误差（不是奖励本身）
- RLHF reward = 学到的偏好函数
- **差异**：多巴胺是**生理的**（饥饿 / 性 / 安全），RLHF reward 是**学到的**

## 反直觉发现

1. **反向传播不是大脑用的**：大脑可能用某种"近似反向传播"（反馈对齐），但不是反向传播本身。**AI 最有效的算法，生物不用**。

2. **胶质细胞被忽略**：大脑 50% 是胶质细胞（不是神经元）。它们调节学习。AI 没有对应。**AI 忽略了大脑的一半**。

3. **大脑稀疏，AI 稠密**：每个神经元只连 ~1000 个其他神经元（稀疏）。GPT 每层全连接。**稠密 ≠ 更强**——大脑用稀疏达到更强。

4. **大脑 20W vs GPT MW**：能效差 5-6 个数量级。**这不是工程差距，是原理差距**——大脑用了我们不懂的算法。

5. **LLM 表征 ≠ 大脑表征**：虽然 interp 发现一些相似，但**相似不等于相同**。LLM 学到的是文本统计，大脑学到的是**多模态 + 具身**。
