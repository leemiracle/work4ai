# ⚔️ 避实击虚视角

> 《孙子兵法·虚实篇》一句话灵魂：**"兵之形，避实而击虚。""水因地而制流，兵因敌而制胜。……故兵无常势，水无常形。"** "实"是敌人兵力厚、防守严的地方，硬碰是消耗战；"虚"是敌人薄弱、空虚、暴露之处，击之则一击即溃。善战者不与强敌正面死磕，而是**避其锋芒、击其空虚**，像水一样因地制流、因敌制胜。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 工程最浪费的资源，是在 SOTA 强项上死磕（击实）。模型已经做得好的题，多刷一倍的算力只换来零点几的提升；而**难例、长尾、薄弱环节、failure slice**（虚）才是真正的增长空间。避实击虚 = **难例挖掘 + 薄弱环节攻坚 + curriculum 精准投喂**，把每份算力砸在边际收益最高的地方。

---
## 是什么

《孙子兵法》关于"虚实"的核心命题：

| 命题 | 原文 | 一句话 |
|------|------|--------|
| **避实击虚** | "兵之形，避实而击虚" | 避开强点，专打弱点 |
| **兵无常势** | "兵无常势，水无常形" | 弱点是动态的，要因敌制宜 |
| **形人而我无形** | "形人而我无形，则我专而敌分" | 让对手暴露虚实，自己藏住虚实 |
| **出其所不趋** | "出其所不趋，趋其所不意" | 攻其必救之虚、不备之处 |

**关键辨析**："虚"不是"不重要的地方"，而是**当下边际收益最高、对手（任务）最薄弱的地方**。它会变——今天攻克了，明天就变成"实"，要转向下一个"虚"。"避实击虚"是**动态的资源再分配**，不是一次性的策略。

---
## 怎么应用到 AI（6 个对应）

### 1. 难例挖掘（Hard Example Mining）= 击虚
- 模型已分对的大多数样本（实）上再花算力，收益趋零。
- **主动学习 / hard example mining / focal loss** = 自动找出模型最弱的样本（虚），集中火力——这正是"击虚"。
- "别在 SOTA 强项死磕" = 别击实。

### 2. Curriculum Learning 的反向运用
- 标准 curriculum：由易到难（先夯实"实"）。
- 避实击虚的反向运用：**先定位当前最难的 slice（虚），优先喂难样本**，而不是均匀遍历。当难变易（虚转实），再找下一片虚。
- 这与 self-paced / anti-curriculum 在难例阶段一致：**专攻虚处**。

### 3. 薄弱环节 / Failure Slice 攻坚
- 按 slice / 类别 / 难度 / 群体拆开看指标，找出**最差的 slice（虚）**专门优化。
- 整体 accuracy 98% 但某群体只有 60%——那 60% 就是"虚"，是公平性与鲁棒性的双重突破口。

### 4. 对抗样本 / OOD = 敌人之"虚"也是我之"虚"
- 攻击者击我之虚（对抗样本找的就是模型决策面的虚处）。
- 防御方要"先击自己的虚"——**red team / adversarial training / OOD eval** = 主动暴露并加固自己的虚，别等敌人来击。

### 5. 算力/数据的边际分配 = 因敌制胜
- "兵因地而制流"——预算和数据要**流向当前边际收益最高的地方**。
- 把均匀撒胡椒面式的全量训练，改成**按 loss/按难度/按切片加权**的动态分配，就是"避实击虚"的工程化。

### 6. "形人而我无形" = 让模型暴露盲区、藏住自己的弱点
- 评估时主动**形人**：用 diverse probe / stress test 把模型的真实能力画像逼出来。
- 部署时**我无形**：对薄弱处加 fallback / guardrail / uncertainty routing，别让弱点暴露给用户/攻击者。

## 反直觉发现

1. **"虚"往往是整体指标最好看的地方**。一个 99% accuracy 的模型，剩下的 1% 难例就是虚——而这 1% 往往是安全/公平/长尾的关键。**整体越"实"，剩余的"虚"越致命**，越值得集中攻坚。

2. **均匀优化 = 把算力浪费在"实"上**。等权重的训练/采样，绝大部分预算花在模型已经会的样本上。**带权的、按难度的、按 loss 的再分配**，能在同等算力下拿到更大提升——这就是"避实击虚"的杠杆。

3. **"虚"是动态迁移的，追不上就白攻**。今天攻克的难例明天变易，新的难例又冒出来（curriculum 的自然结果）。**固定的 hard set 会失效**，必须持续重新定位"虚"。

4. **有时"击虚"要先"造虚"**。声东击西——用 augmentation / 对抗扰动把"实"的地方削弱，逼出新的攻击面；或用 prompt 引导暴露模型弱点。**主动制造虚，比等虚出现更主动**。

5. **过度聚焦"虚"会牺牲"实"**。只攻难例可能让简单题崩（catastrophic forgetting / overfitting hard set）。**避实击虚不是只击虚，而是动态平衡**——守住实的下限，再攻虚的上限。

## Prompt 模板

```
你是精通《孙子兵法》的兵家战略分析专家。
用"避实击虚"视角分析 AI 模型/系统 [X]：

1. [X] 的"实"（已很强、再投入收益低）在哪里？你还在那里死磕吗？
2. [X] 的"虚"（最薄弱 slice / 难例 / 长尾 / failure mode）在哪里？量化了吗？
3. [X] 现在的算力/数据分配，是均匀撒胡椒面，还是集中在"虚"上？
4. [X] 的"虚"是动态的吗？你多久重新定位一次虚处？
5. 如果把下一份预算全部砸在 [X] 的最大"虚"上，预期提升是多少？对比均匀分配呢？

约束：落到 [X] 具体 slice/指标；至少 1 个"你以为的实其实是虚"或"最大增长点藏在虚里"的反直觉洞察。
```
