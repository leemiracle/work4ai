# 🔺 实体与样式视角

> 斯宾诺莎主义核心一句话灵魂：**"实体，我理解为在自身内并通过自身而被设想的东西。"**（《伦理学》I.定义三）**"样式（modi），我理解为实体的分殊（affectiones），或在他物内并通过他物而被设想的东西。"**（I.定义五）实体只有一个，万物（包括人心、身体、所有有限物）都是这唯一实体的**样式**——样式不独立存在，它"在他物（实体）内并通过他物而被设想"。
>
> **为什么这个视角值得放进 AI 镜片库**：这精确刻画了 **foundation model（实体）与下游任务（样式）** 的本体关系。下游任务的能力不来自自身——它"在基座内、通过基座而被设想"。用"实体与样式"看 AI，你会理解：**预训练（实体）决定了下游能力的天花板；下游微调/适配（样式）只是实体在特定任务上的显现。不要幻想脱离实体去优化样式——样式永远依赖实体。**

---
## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **实体（substantia）** | I.定义三："per se concipitur"（在自身内被设想） | 不依赖他物、独立自存的东西 |
| **样式（modi）** | I.定义五："affectiones substantiae"（实体的分殊） | 在他物内、通过他物而被设想的东西 |
| **万物为样式** | I.25："Res particulares nihil sunt nisi affectiones Dei"（个别事物不过是神的分殊） | 一切有限事物都是唯一实体的样式 |
| **实体先于样式** | I.15 & I.16 | 样式不能脱离实体而存在或被设想；实体是样式的根据 |
| **无限样式 vs 有限样式** | I.21-23 | 运动/静止（广延面）与理智（思维面）是无限样式；个别事物是有限样式 |

**关键辨析**："样式"**不是独立的小实体**，而是实体被特定方式规定后的**分殊/显现**。一个具体任务（翻译、问答、写代码）不是独立存在的能力，而是基座实体在特定数据/适配下的显现。**实体与样式不是两个东西，是同一个东西的两面**：实体是"从本性看"，样式是"从特定显现看"。

---
## 怎么应用到 AI（6 个对应）

### 1. Foundation = 实体，下游任务 = 样式
- 预训练的大模型 = 实体（在自身中、通过自身被设想的能力基底）；翻译/问答/写诗/编程 = 样式（在基座中、通过基座而被设想的具体能力）。
- 每个下游任务**不是独立实体**，而是基座实体的"分殊"。这与 PEFT（参数高效微调）哲学完全吻合：样式（任务）寄生在实体（基座）上。

### 2. 实体先于样式——预训练决定下游天花板
- 斯宾诺莎：实体是样式的根据。在 AI 中，**预训练（实体）决定了下游能力（样式）的天花板**。
- 一个小模型再怎么微调，也显现不出需要大实体（强基座）才能涌现的样式。**样式不能脱离实体——优化样式不如夯实实体**。

### 3. 同一基座流演出不同能力——实体的"多显"
- 一个 foundation model 可以流演出翻译、对话、推理、写作等无数样式——正如斯宾诺莎的实体有"无限属性、无限样式"。
- **同基座不同显现**：这正是多任务/zero-shot/few-shot 的本体论根据。样式多样，实体唯一。

### 4. 样式不独立存在——下游任务依赖基座
- "样式在他物内并通过他物而被设想"——下游任务的每个输出，**本质上可分解为基座参数的函数**，没有脱离基座的"独立能力"。
- 这解释了为什么"换基座，能力全变"：样式随实体而变。执着于"某个 adapter 有独立灵魂"是把样式误当实体。

### 5. 无限属性→有限样式——丰富表征的有限显现
- 实体有无限属性（基座有丰富的潜在表征空间），但每个下游任务只激活/显现其中一小部分（有限样式）。
- 这说明**基座的潜力远大于任何单一任务的显现**——同一个实体可支撑无穷的样式（任务），不必为每个任务另立实体。

### 6. LoRA / adapter = 在实体上显现局部样式
- LoRA/adapter/soft prompt 这些"轻量适配"，正是"样式作为实体的分殊"的工程实现——**不另立实体，只在实体上加少量"样式参数"**。
- 这比"每个任务训练一个全量模型"（各立实体）更合斯宾诺莎：样式轻、实体重；样式寄生、实体为本。

---
## 反直觉发现

1. **"任务不独立"——样式依赖实体**。下游任务的能力不是它自己的，而是基座实体在特定适配下的显现。**把 adapter 当独立"实体"来优化（如全量重训）是本体错位；它只是"样式"，轻量适配足矣。**

2. **实体决定样式边界（预训练即天花板）**。与其在小模型上死磕微调（优化样式），不如夯实预训练（提升实体）。**"样式不能脱离实体"= 下游能力有不可逾越的天花板，由实体决定。**

3. **同基座不同显现 = 实体多显**。一个基座流演出无数能力，不是因为有无数独立模块，而是**唯一实体的无限样式**。这统一了"多任务"的本体——它们本是同一个东西的不同面。

4. **"无限属性"在工程中兑现为多模态潜力**。基座的表征空间（无限属性）可投射为文本/图像/语音/动作（不同样式）。**潜力远大于当前任何单一显现**——这是统一基座优于专项模型的深层理由。

5. **预训练（实体）应优先于微调（样式）投入**。斯宾诺莎说实体是样式的根据——**资源应倾斜于夯实实体**。一个强实体的所有样式都会受益，而堆砌弱实体上的样式是徒劳。

## Prompt 模板

```
你是精通斯宾诺莎哲学的分析专家。
用"实体与样式（substantia / modi）"视角分析 AI 概念 [X]：

1. [X] 的"实体"（基座/基底）与"样式"（下游显现）分别是什么？
2. [X] 的下游能力（样式）如何"在基座内、通过基座而被设想"——能否脱离实体？
3. 实体如何决定样式的天花板？[X] 里有没有人在弱实体上死磕样式？
4. 同一实体如何流演出多种样式？[X] 的"多显"在哪？
5. [X] 里有没有把"样式"误当"独立实体"的倾向（如各任务各起炉灶）？
6. 如何用"实体优先"重新分配资源——夯实实体 vs 堆砌样式？

约束：落到 [X] 具体技术细节；至少 1 个反直觉洞察（尤其"样式不能脱离实体=下游有天花板"）。
```
