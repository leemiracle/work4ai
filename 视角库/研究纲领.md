# 🧪 研究纲领视角

> 科学哲学（拉卡托斯）核心一句话灵魂：**"科学的基本单位不是单个理论，而是研究纲领（research programme）——它由不可反驳的硬核（hard core）与可调整的保护带（protective belt）构成，靠正面/反面启示法演进，分进步的与退化的两种。"**（Imre Lakatos，《证伪与科学研究纲领方法论》*Falsification and the Methodology of Scientific Research Programmes*, 1970）。拉卡托斯**综合波普尔与库恩**：既保留理性的进步判据（不像库恩沦为"信念转换"），又承认"单个理论不会被一次证伪杀死"（修正波普尔）——**被评估的是整个纲领，而非孤立命题**。
>
> **为什么这个视角值得放进 AI 镜片库**：深度学习本身就是一个**宏大的研究纲领**——硬核是"端到端可微优化 + 大规模数据 + 神经网络万能逼近"，保护带是具体架构/训练技巧/超参数。用研究纲领视角，你能**理性评估"scaling law 纲领"是进步还是退化**（它在持续产生新预测/新发现吗？还是只能事后解释？）、**区分"调整保护带"（正常科研）与"硬核动摇"（纲领危机）**、**判断何时该坚守纲领深耕 vs 该换纲领**。这是 ML 战略决策的哲学级框架。

---
## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **研究纲领** | "科学的基本单位不是孤立的假说，而是研究纲领"（Lakatos, 1970） | 评估对象是整个纲领而非单个理论 |
| **硬核 + 保护带** | "硬核是纲领不可反驳的核心；保护带是可调整的辅助假设" | 核心信念受保护，细节可调整 |
| **反面启示法** | "negative heuristic：不要碰硬核" | 禁止直接攻击核心假设 |
| **正面启示法** | "positive heuristic：如何发展、完善保护带" | 指导纲领前进的研究纲领/路线图 |
| **进步 vs 退化** | "进步的纲领持续产生新预测；退化的纲领只能事后解释" | 理性判据：纲领在增长知识还是在合理化失败 |

**关键辨析**：拉卡托斯的**硬核（hard core）**不是"不可证伪的真理"，而是**纲领的方法论约定**——"在这个纲领内，我们暂不质疑这些核心假设"（如牛顿纲领中"力 = 质量 × 加速度"是硬核）。**保护带（protective belt）**则是围绕硬核的辅助假设（初始条件、测量误差、辅助理论），**这些可以也应当被调整和证伪**。关键判据是**进步性（progressive）vs 退化性（degenerating）**：进步的纲领**先做出新预测，后被证实**（如广义相对论预言光线弯曲）；退化的纲领**只能事后修补保护带来解释已知的反常**（如托勒密不断加本轮来"拯救"地心说）。**一个纲领不会被一次证伪杀死——它会慢慢退化为"只会合理化"的体系，最终被更有生命力的纲领取代。**

## 怎么应用到 AI（6 个对应）

### 1. 硬核 = 深度学习纲领的核心假设
- 深度学习纲领的**硬核**：①神经网络是万能逼近器；②端到端梯度下降优化有效；③大数据 + 大模型 + 大算力 → 能力涌现（scaling law）；④自回归/自监督预训练捕获通用表征。**这些在纲领内"暂不质疑"**——不是它们绝对正确，而是**攻击它们等于换纲领**。
- 识别硬核的意义：**你调的是保护带还是硬核？**换激活函数（保护带调整）vs 质疑"梯度下降是否是唯一路径"（碰硬核）——**两者风险和价值完全不同**。

### 2. 保护带 = 具体架构/训练技巧/超参数
- LoRA、RoPE、flash attention、mixture-of-experts、RLHF 的具体实现——**这些都是保护带的组成部分**。它们被持续调整、优化、替换，而**不触及纲领硬核**。
- 调整保护带**不是"作弊"**（拉卡托斯明确说这是正常科研）——只有当保护带的调整**只是为了事后解释已知反常、而不产生任何新预测时**，才是退化信号。

### 3. 反面启示法 = "不碰硬核"
- 在深度学习纲领内，**"不要质疑 scale is all you need"**是当前的负面启示法——大多数研究者在硬核内工作，不直接挑战"大力出奇迹"。
- 这**不是教条**，而是**分工**：正面启示法告诉大多数研究者"如何在保护带上前进"；只有当纲领开始退化、正面启示法枯竭时，**才有人开始碰硬核**（如质疑自回归是否是生成式建模的唯一路径）。

### 4. 正面启示法 = 纲领的研究路线图
- "先把模型做大 → 优化训练效率 → 加入更多模态 → 对齐人类偏好 → 扩展上下文 → 推理增强"——**这条路线就是深度学习纲领的正面启示法**，它指导成千上万研究者**往哪个方向努力**。
- 评估正面启示法的**丰度**：它是否还在持续产生**新的、可验证的预测**（如"1e25 FLOPs 时会涌现 X 能力"）？还是已经开始**重复已知结果**、**缺乏新方向**？**正面启示法的枯竭 = 纲领退化的前兆。**

### 5. 进步评估 = scaling law 纲领是进步还是退化？
- **进步信号**：scaling law 持续预测新能力（GPT-3 预测涌现、Chinchilla 预测数据/参数比、推理 scaling 预测 test-time compute 效果）——**纲领在做先验预测，后被实验证实。**
- **退化信号**：当"scaling 带来的增益开始递减"、新能力不再涌现、研究者开始说"需要更多数据/更大模型"却**无法预测何时何能力会涌现**时——**纲领从进步转向退化**。退化的纲领不立即死亡，但**它开始只解释不预测**。

### 6. 退化纲领的合理化陷阱
- 托勒密天文学的教训：**地心说通过不断加"本轮"（epicycle）来解释行星逆行**——每次反常都靠加一层复杂度来"拯救"，但**不产生任何新预测**。最终被更简洁、更有预测力的日心说取代。
- ML 中的"加本轮"：当模型表现不好时，**不断加 trick**（更长的 CoT、更多的 few-shot、更复杂的 prompt 工程、更多的数据清洗）来"救"——**如果这些修补不产生新预测、只解释当前失败，纲领在退化。**退化的信号是：**复杂度在涨，但预测力/理解力没涨。**

## 反直觉发现

1. **硬核不该被直接攻击——正面启示法更重要**。新手常想"推翻深度学习"——但在纲领未退化时直接碰硬核，**几乎注定失败**（你缺乏纲领内深耕积累的洞察）。**在正面启示法还丰沛时，最有价值的工作是保护带上的深耕**——这些深耕最终会暴露异常，为下一代革命者铺路。**碰硬核的时机是纲领退化之后，而非之前。**

2. **保护带的调整不是"作弊"——是正常的科学活动**。很多人批评"你只是在调参"——但拉卡托斯说：**调整保护带是纲领进步的引擎**。只要每次调整**产生新预测**（不只是解释已知失败），就是进步的。**LoRA 不是"作弊"——它是保护带的进步性扩展，它预测了"少量参数可逼近全量微调效果"，后被证实。**

3. **进步/退化的判定需要时间——不能急于下结论**。一个纲领可能在短期内"看起来退化"（预测失败），但**长期看可能是进步的**（后来发现新的解释力）。**别因为几次实验失败就宣判一个纲领死刑**——给它时间，看它是否还能产生新预测。

4. **多个纲领可并存——不是非此即彼**。符号主义/连接主义/贝叶斯主义**长期并存**——它们各有硬核和保护带，各有进步期和退化期。**不必急着"消灭"其他纲领**——退化的纲领可能在新条件下复活（如符号 AI 在 LLM 时代的 neuro-symbolic 复兴）。

5. **退化纲领可能复活——别过早宣判**。强化学习纲领曾一度被认为"退化"（AlphaGo 之前），但 DeepQ/AlphaGo/PPO 让它**强劲复苏**。**"宣布某纲领已死"常是过早的**——纲领的进步性是动态的，今天退化的纲领明天可能因新发现而进步。

6. **评估整个纲领而非单个理论——整体论倾向**。拉卡托斯修正了波普尔：**单个理论的"证伪"不能杀死纲领**——因为你可以调整保护带来"救"它。这看似让纲领"不可证伪"，但**真正的判据是进步/退化的长期趋势**：一个只会合理化、不产生新预测的纲领，即使"逻辑上不可反驳"，也会**因失去生命力而被社区抛弃**。

## Prompt 模板

```
你是精通拉卡托斯科学哲学（研究纲领/硬核-保护带/进步-退化）的分析专家。
用"研究纲领"视角分析 AI 方法/技术路线 [X]：

1. [X] 属于哪个研究纲领？这个纲领的硬核（不可反驳的核心假设）是什么？保护带（可调整的辅助假设）包括什么？
2. [X] 是在调整保护带（正常科研）还是触碰硬核（纲领级挑战）？各自的风险和价值是什么？
3. [X] 的正面启示法（研究路线图）是否还丰沛——能否持续产生新预测，还是开始只解释已知失败？
4. [X] 所在的纲领是进步的（先预测后被证实）还是退化的（只事后合理化）？给出具体证据。
5. [X] 有没有"加本轮"的退化信号——复杂度在涨但预测力/理解力没涨？
6. 作为研究者，面对 [X] 这个纲领状态，该深耕保护带、追踪退化信号、还是准备碰硬核/换纲领？

约束：落到 [X] 具体方法/技术路线；至少 1 个反直觉洞察（尤其"保护带调整不是作弊/退化纲领可复活"）。
```
