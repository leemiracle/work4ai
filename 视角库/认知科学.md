# 🧠 认知科学视角

> 认知科学研究**心智如何工作**——感知 / 注意 / 记忆 / 语言 / 推理 / 决策。

---

## 是什么

认知科学 = 心理学 + 神经科学 + AI + 语言学 + 哲学的交叉。核心信念：**心智是信息处理系统**。

## 核心概念

| 概念 | 含义 | AI 对应 |
|------|------|---------|
| **工作记忆** | 临时存储（7±2 项）| context window |
| **长时记忆** | 永久存储 | 训练权重 / 向量库 |
| **注意力** | 选择性聚焦 | attention mechanism |
| **启发式** | 心理捷径 | inductive bias |
| **双系统** | System 1 快 / System 2 慢 | 普通 LLM / o1 reasoning |
| **组块** | 把信息打包 | token / chunk |
| **心智模型** | 内部世界表征 | world model |
| **元认知** | 思考自己的思考 | self-reflection / Reflexion |

## 怎么应用到 AI

### 1. LLM 是哪种认知系统？
- **GPT-4** = System 1（快思考，直觉反应）
- **o1 / R1** = System 2（慢思考，逐步推理）
- **Anthropic Claude thinking** = 混合

### 2. Context window = 工作记忆
- 人工作记忆 7±2 项 → LLM 200K token
- 但 LLM 也有 **"lost in the middle"**（类似人注意力衰减）

### 3. 启发式 vs 算法
- 人用启发式（快但易错）
- LLM 学到的也是"启发式"（统计模式）
- 真正的算法推理（System 2）需要显式 CoT / thinking

## 示例：用认知科学看 Attention

**人类视觉注意力**：
- 自上而下（top-down）：目标驱动（"找红色"）
- 自下而上（bottom-up）：刺激驱动（突然闪光）

**Transformer attention**：
- **自注意力** = 自下而上 + 自上而下混合
- **Multi-head** = 多个并行注意焦点（人不能同时注意多个，但 transformer 可以）

**反直觉**：人注意力是**串行**的（一次一个焦点），transformer 是**并行**的（所有 head 同时）。这是 transformer 比人快的原因之一。

## 反直觉发现

1. **LLM 没有"心智模型"**：人不只靠语言理解世界——我们有物理直觉 / 空间感 / 因果感。LLM 只有文本。这是 LeCun 批评 LLM 的核心。

2. **人脑 20W，LLM MW**：人脑功耗 20 瓦，GPT-4 训练耗电兆瓦级。**能效差 5-6 个数量级**。

3. **人有"具身认知"**：我们的思维扎根于身体（拿过杯子才知道"重量"）。LLM 没身体 → 可能缺少某些基础概念。

4. **7±2 不是 200K**：人工作记忆极小但很聪明。LLM 有 200K 但仍犯蠢。**记忆大小 ≠ 智能**。

## 推荐资源

- **Kahneman《Thinking, Fast and Slow》** — System 1/2
- **Fodor《The Modularity of Mind》** — 心智模块化
- **Lakoff《Women, Fire, and Dangerous Things》** — 具身认知 + 隐喻
- **Clark《Surfing Uncertainty》** — 预测编码
- **Tenenbaum 等 "Computational Cognitive Science"**
