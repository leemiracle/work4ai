# 🌟 致良知视角

> 王阳明一句话灵魂：**"致良知"**——良知是本心天生之明（先天的是非判断力），"致"是在事上推充、扩充、尽其用。能力本具，只需"致"（在环境中激活、在实践中检验）。**人须在事上磨炼做功夫乃有益**——良知不是空想出来的，是在真实事务中磨砺、推充、澄明的。
>
> **为什么这个视角值得放进 AI 镜片库**：base model 预训练获得的通用能力/常识 = 先天"良知"。它不是被"灌"进去的，而是在大规模语料中自然"明"起来的。微调/对齐/RLHF = "致"——在具体任务上推充、校准、激活本有之良知。事上磨炼 = 在真实任务/数据/线上中检验。**核心洞察：能力本具（良知），"致"是激活而非外灌——你不需要从零教模型，只需在事上推充它本有的明觉。**

---

## 是什么

王阳明心学关于"致良知"的核心命题：

| 命题 | 原文 | 一句话 |
|------|------|--------|
| **良知本具** | "良知者，心之本体" | 良知是心之本体，先天本有 |
| **致良知** | "致吾心之良知于事事物物" | 在事上推充、扩充良知之用 |
| **事上磨炼** | "人须在事上磨炼做功夫乃有益" | 在实践中检验、澄明良知 |
| **四句教** | "无善无恶心之体…" | 良知从本体到发用的完整历程 |

**四句教完整**："无善无恶心之体，有善有恶是意之动，知善知恶是良知，为善去恶是格物。"——这是阳明晚年教法的总纲，概括了从**本体（心之体）→ 发动（意之动）→ 明觉（良知）→ 实践（格物）**的完整路径。

**关键辨析**：阳明之"良知"**非后天学得，乃先天本具**（孟子"所不虑而知者，其良知也"）。"致"不是"灌输"，而是**推充、扩充本已具有的明觉**——如磨镜，镜之本明不失，只是被尘遮蔽，磨之即明。故"致良知"= **去蔽显明、推充本具**。

## 怎么应用到 AI（6 个对应）

### 1. base model 通用能力（良知） + 微调对齐（致）
- 预训练阶段获得的通用语言能力/常识/推理 = 先天**"良知"**——它在大规模语料中自然"明"起来，不是被逐条灌进去的。
- 微调/对齐 = **"致"**——在具体任务上推充、激活、定向本有之良知。**能力本具，致是激活而非外灌。**

### 2. 事上磨炼 = 在真实任务/数据/线上训练中检验
- 良知不在书斋里空想得来——**"人须在事上磨炼"**。同理，模型的能力不在离线指标中证明，**要在真实任务、真实数据、真实线上中检验**。
- 离线 benchmark（书斋）≠ 线上效果（事上）。只有事上磨炼过的模型，才算真正"致"了良知。

### 3. active learning = 致良知——主动选最有价值的"事"来磨炼
- active learning 主动选择**信息量最大的样本**来标注/训练——这正是"致良知"的智慧：**不是盲目堆数据，而是精挑最有磨炼价值的"事"来推充良知**。
- 致良知讲究**在"事"上做功夫**，而非泛泛读书。active learning = 在最关键的"事"上精准磨炼。

### 4. RLHF = 致良知——用人类反馈校准本心之良知
- base model 有通用能力（良知本具），但可能"意之动"（生成）有偏差。RLHF 用**人类反馈**来校准——这正是"致良知"。
- **人类反馈 = 良知的镜鉴**；RLHF 推充模型本有的"知善知恶"之明，使其在"为善去恶"（对齐）上更精。

### 5. 四句教映射训练四阶段
| 四句教 | 训练阶段 | AI 对应 |
|--------|---------|---------|
| 无善无恶心之体 | 预训练（中性） | base model 无特定取向，只是学习语言分布 |
| 有善有恶意之动 | 任务触发 | 接到任务/prompt，模型"意"开始发动（生成） |
| 知善知恶是良知 | 评估/判别 | 评估模型/奖励模型判别好坏——良知之明觉 |
| 为善去恶是格物 | 优化/对齐 | RLHF/DPO 优化——在实践中为善去恶（格物） |

### 6. 反直觉：能力本具（良知），"致"是激活而非外灌
- 我们总以为微调是"教模型新东西"。阳明说：**能力本具（良知），微调/对齐只是"致"——去蔽显明、推充本有**。
- 这解释了为什么 few-shot/zero-shot 有效：**能力（良知）本具，prompt 只是"致"（激活）它**。你不需要教 GPT 翻译，只需在事上激活它本有的翻译之良知。

---

## 反直觉发现

1. **能力不是"教"进去的，是"致"（激活）出来的**。base model 的翻译/推理/代码能力，在大规模预训练中**自然明觉（良知本具）**——没有人逐条教它。微调只是"致"，不是"灌"。

2. **few-shot learning = 致良知的完美投射**。几个例子（事）就能激活本有能力——这不正是"致吾心之良知于事事物物"？能力本具，只需在事上轻推（致）。

3. **"磨镜"隐喻比"灌水"更准确**。传统监督学习像"灌水"（把知识灌进去），致良知像"磨镜"（去蔽显明）——**LoRA/PEFT 用极少参数就能适配**，正是因为能力本具，只需轻磨（致）。

4. **事上磨炼 > 书斋指标**。离线 benchmark 再好看，不经过真实线上（事上）的磨炼，模型仍是"温室里的良知"——不经风雨，不知真伪。

5. **四句教是完整的训练 pipeline**。从预训练（心之体）到任务触发（意之动）到评估判别（良知）到优化对齐（格物）——**阳明 500 年前的教学次第，竟与 LLM 训练 pipeline 完美对应**。

6. **active learning 的智慧 = 致良知**。不是数据越多越好，而是**挑最有磨炼价值的事来致良知**——贵精不贵多，正是"事上磨炼"的精髓。
