# 🧩 贵因视角

> 《吕氏春秋·贵因》一句话灵魂：**"禹通三江，因水也；舜擅让，因民也。"** "因"是因循、顺应、沿着已有之势走。大禹治水不是自己开路，而是**顺着水的本性疏导**。贵因 = **不另起炉灶，沿着已有的基础/结构/先验顺势而为**。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 里最大的浪费，是"弃前人成基于不顾，从头来过"。Transfer learning、in-context learning、fine-tuning 之所以高效，恰恰因为它们"贵因"——**顺着预训练打下的基础走，而非从零训练**。贵因 = 最大化复用已有成果，因势利导。

---
## 是什么

《吕氏春秋·贵因》关于"贵因"的核心命题：

| 命题 | 原文 | 一句话 |
|------|------|--------|
| **因水通江** | "禹通三江，因水也" | 顺着水的本性疏导，不逆势 |
| **因民而治** | "舜擅让，因民也" | 顺着民意民心走 |
| **因而不为** | 《贵因》总旨 | 因循已有之势，减少无谓的新建 |
| **因则成** | 杂家引申 | 顺着已有结构走，事半而功倍 |

**关键辨析**："因"不是照搬不动，是**"顺势改造"**——大禹不是不管水，而是**理解水往低处流的"势"，在这个势里做疏导**。贵因 = 先认清势（pretrained knowledge / 已有结构），再在势中作为。

---
## 怎么应用到 AI（6 个对应）

### 1. 迁移学习（Transfer Learning）= 贵因的典型
- 预训练模型 = "水势"。Fine-tuning = "因水疏导"。不从零训练 = "不另起炉灶"。
- "禹通三江，因水也"→ **ImageNet / BERT / GPT 是"江"，下游任务是"通"，fine-tune 是"因"**。

### 2. In-context Learning = 贵因的极致
- ICL 零参数更新，纯靠"因着 prompt 的势"——这是贵因的最高境界：**连 fine-tune 都省了，直接因提示而行**。
- "因而不为"= 不更新权重（不为），却完成任务（因则成）。

### 3. 复用预训练 = 因基础模型
- 预训练投入巨大，贵因者绝不浪费——**每个下游任务都"因"着 foundation model 走**。
- 从头训练小模型 vs fine-tune 大模型——后者几乎总是赢，因为"贵因"。

### 4. 利用已有结构 / 先验（Inductive Bias as 势）
- CNN 的局部性、Transformer 的注意力、数据的 manifold 结构——都是"水势"。
- 贵因者设计架构时**先问"数据/问题本来的势是什么"**，然后顺着势设计，而非强行套不匹配的结构。

### 5. LoRA / Adapter = 贵因的轻量实现
- 不动全模型（因基础），只调一小部分（疏导）——LoRA = **最小代价的"因"**。
- "因民也"→ 不改大框架（不扰民），只做局部适配（顺民意）。

### 6. Agent 的 Tool Use = 因已有工具
- Agent 调用现成的搜索 / 计算 / 数据库——是"因"已有能力，而非自己从头实现。
- 贵因的 Agent **编排已有工具**（因），而非自己生成一切（逆势造水）。

---
## 反直觉发现

1. **贵因不是偷懒，是高明**。从零训练看起来"有本事"，实则浪费——**重复造预训练的轮子是最大的工程浪费**。

2. **"因"需要先理解"水势"**。不读懂预训练模型的表征空间，fine-tune 就是瞎调——**贵因的前提是 deep understanding of the foundation**。

3. **贵因 ≠ 照搬**。大禹"因水"但做了大量疏导工程——**因是顺势改造，不是躺平不动**。LoRA 改了参数，ICL 选了 prompt，都是"因中有为"。

4. **强行 from-scratch 往往不如因势 fine-tune**。数据不够时硬训 = "逆水行舟"；fine-tune = "顺水推舟"——**同样的算力，贵因者走得更远**。

5. **In-context learning 揭示了"因"的极限**。零参数更新就能完成任务——说明 **"因"的威力可以大到连权重都不用动，纯靠已有结构 + prompt 的势**。

## Prompt 模板

```
你是精通《吕氏春秋》的杂家哲学分析专家。
用"贵因"视角分析 AI 方法 [X]：

1. [X] "因"着什么已有基础？（预训练模型？已有数据结构？已有工具？）
2. [X] 的"水势"是什么？（pretrained knowledge？inductive bias？数据的 manifold？）
3. [X] 是纯"因"（零改），还是"因中有为"（顺势力改造）？改造了哪部分？
4. 如果 [X] 不"贵因"（从零开始），会浪费什么？贵因省了多少？
5. [X] 对"水势"的理解够深吗？还是盲目 fine-tune 没读懂 foundation？

约束：落到 [X] 具体技术细节；至少 1 个反直觉洞察。
```
