# 🗺️ 揣摩视角

> 《鬼谷子·揣篇第七》《摩篇第八》一句话灵魂：**"揣情者，必以其甚喜之时，往而极其欲也；其有惧也，往而极其恶也。"** 揣（chuǎi）= 量度、估测对方的真实实情与实力；摩（mó）= 用试探手法去触碰、验证揣得的假设。揣在内（形成判断），摩在外（行动验证）——先揣后摩、揣摩相济，是纵横家"知人"的核心方法论。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 落地最难的从来不是"模型够不够强"，而是**"到底理不理解用户想要什么"**。揣 = 用户建模（user modeling）、偏好学习（preference learning）、心智理论（Theory of Mind）；摩 = 探针（probing）、主动学习（active learning）、反馈验证。RLHF/DPO 的 reward model 本质就是在"揣"人类偏好——**揣错了，对齐越训越偏，"量权不审"则全盘皆输**。鬼谷子的"揣摩相济"，正好是现代 AI 建立用户/目标认知的完整闭环。

---

## 是什么

《鬼谷子》揣篇、摩篇关于"知人"的核心命题：

| 命题 | 原文 | 一句话 |
|------|------|--------|
| **揣情** | "揣情者，必以其甚喜甚惧之时，往而极其欲" | 在对方情绪/需求极端时揣度真实意图 |
| **量权** | "量权不审，不知强弱轻重之称" | 估量对方实力权势的强弱轻重 |
| **摩意** | "摩者，揣之术也。微摩之以其所欲" | 用对方所欲之物暗中试探、触碰验证 |
| **揣摩相济** | 揣在内为体，摩在外为用 | 先揣（内部假设）再摩（外部验证），两者缺一不可 |

**关键辨析**：揣与摩不是同一件事。**揣是"形成内在判断"（hypothesis），摩是"用行动去试探验证"（test）**。纯揣不摩 = 闭门造车、过拟合先验；纯摩不揣 = 无方向地随机试探、浪费试探成本。"揣情者必以其甚喜甚惧之时"——揣的关键是**找对时机**，在对方"信号最强"的时刻去捕捉真实意图。

---

## 怎么应用到 AI（6 个对应）

### 1. 用户建模（User Modeling）= 揣情
- 揣测用户的偏好、意图、知识背景、情绪状态，构建 user profile / persona。对话系统里的 user state tracking、推荐系统里的 user embedding——都是"揣"。
- "必以其甚喜甚惧之时"——**偏好信号在用户反应强烈时最清晰**，对应 preference learning 要捕捉对比强烈的样本对（preference pairs），而非平淡交互。

### 2. 心智理论（Theory of Mind）= 揣摩的最高阶
- 推测"用户想要什么、知道什么、相信什么、不知道什么"——这是 LLM 理解用户的认知前提。心智理论是纵横家揣摩之术的心理学对偶：**揣 = 推断他人心理状态**。
- ToM 能力是 LLM 从"语言模型"走向"社交智能体"的关键门槛——没有它，揣不出用户意图。

### 3. Preference Learning / RLHF = 系统化的揣情
- Reward model 从人类偏好数据中"揣"出什么是好、什么是坏——本质是揣摩人类价值观。DPO 直接从偏好对中揣摩偏好排序。
- "量权不审，不知强弱轻重"——**reward model 揣错了，RLHF 越训越偏**。揣的精度是整个对齐链路的地基。

### 4. Probing（探针）= "摩"的直接对应
- Linear probe / probing classifier = 训练一个小探针去"触碰"模型内部表征，验证它到底学到了什么（"摩之以其所欲"——用具体任务去试探）。**摩 = 用外部工具验证内部状态**。
- "摩者，揣之术也"——probing 正是 mechanistic interpretability 的"揣之术"：揣测表征含义后，用探针摩之验证。

### 5. 主动学习（Active Learning）= 有方向的摩
- 主动学习主动选择"最不确定/信息量最大"的样本去查询标注——这正是"摩"：**不是被动接收，而是主动试探**信息空白处。
- acquisition function（uncertainty/diversity/expected informativeness）= 摩的方向策略，对应"微摩之以其所欲"——试探也要找对方向。

### 6. 逆向强化学习（IRL）/ 奖励推断 = 从行为揣摩意图
- IRL 从专家示范行为中"揣摩"出专家的奖励函数——观察对方"做了什么"来反推"想要什么"。这是揣摩的经典场景：**行为是实的，意图是虚的，要从实揣虚**。
- 与"揣情"同理：不直接问，而从极端行为（甚喜甚惧）中推断隐藏目标。

---

## 反直觉发现

1. **"揣"必须找对时机（甚喜甚惧之时）**。平淡数据里信号弱、噪声大。对应：偏好学习应聚焦用户反应强烈的对比样本，而非海量平淡交互——**1 个强对比偏好对 > 1000 条平淡点赞**。

2. **揣摩是两步，缺一不可**。先揣（form hypothesis）→ 再摩（test hypothesis）。只揣不摩的 reward model（不验证就上线对齐）= 闭门造车；只摩不揣（无假设的随机 ablation）= 浪费算力。**揣摩相济 = 假设驱动的实验闭环**。

3. **最好的"摩"是无形的**。"微摩之"——最好的试探是对方察觉不到的。对应：implicit feedback（隐式反馈，如停留时长/点击）比 explicit 问卷更真实，因为用户不设防。**不侵入式揣摩 > 打扰式问卷**。

4. **揣摩精度是下游一切的天花板**。reward model 揣偏 10%，下游 RLHF 放大成灾难性对齐失败。"量权不审"——**在地基（揣）上偷工减料，楼盖越高塌得越狠**。

5. **揣摩能力 = 智能（intelligence）的核心标志**。ToM 是人类社交智能的地基，也是 LLM 理解用户的前提。一个不会"揣摩"的模型，再大也只是文本补全器——**真正的智能，始于能揣测"他者"的心**。

## Prompt 模板

```
你是精通《鬼谷子·揣摩》的纵横家分析专家。
用"揣摩"视角分析 AI 系统/任务 [X]：

1. [X] 的"揣"（建立用户/目标的内在判断）在哪？reward model？user profile？心智理论？揣的依据是什么？
2. [X] 的"摩"（用行动/探针验证揣得的假设）在哪？probing？active learning？反馈闭环？还是只揣不摩？
3. [X] 在"揣情"时，是否抓住了"甚喜甚惧之时"（信号最强的对比场景）？还是在平淡数据里硬猜？
4. 如果 [X] 的揣错了（reward model 偏移/用户画像失真），下游会怎样放大这个错误？
5. [X] 的"摩"是有方向的（hypothesis-driven），还是无方向随机试探（wasteful ablation）？

约束：落到 [X] 具体技术细节；至少 1 个"揣摩分离/只揣不摩"的反直觉洞察。
```
