# 🎴 纯粹经验视角

> 京都学派核心一句话灵魂：**"所谓经验，就是按照事实的原样去知晓（事実そのままに知る）。"**（西田几多郎《善の研究》，1911）纯粹经验（junsui keiken，純粋経験）是**主客未分之前的"直接经验"**——还来不及切出"我在看"与"被看的物"的那个当下。不是"我经验到了 X"，而是经验本身在涌流，主与客是这个流事后才割出的两块。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 工程最爱在"模型（主体）"与"世界（客体）"之间画一条泾渭分明的线——模型表征世界、世界喂养模型。但西田的纯粹经验提醒我们：**最原初的"数据流"是主客未分的连续流，主客分界是后来建构的**。端到端学习、in-context learning、pre-reflective 的稠密表征，都是"在主客切分之前先有直接经验"。用纯粹经验看 AI，你会重新审视：**哪些"主体/客体"的二元划分其实是人为的、可拆除的边界**——这正是与詹姆斯"彻底经验主义"（radical empiricism）独立共振的洞见。

## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **纯粹经验** | "所谓经验，就是按照事实的原样去知晓"（《善の研究》第2章开篇）| 主客未分的直接经验，是意识涌流的本来面目 |
| **主客未分** | "纯粹经验，是尚未分为主客的状态" | "知者"与"被知者"在这个当下还没被切开 |
| **意识现象唯一实在** | "意识现象是唯一的实在"（《善の研究》）| 并非"有一个我，去经验一个世界"，而是经验本身就是实在 |
| **完整的现在（集中的现在）** | 纯粹经验是"一个完整的现在" | 经验的每一瞬都是自足的整体，过去未来是从中抽象出的 |
| **从纯粹经验切出主客** | 主客、对象、自我都是"在纯粹经验中反省地建立的" | "我"和"物"是派生事件，不是经验的预设主体 |

**关键辨析**：纯粹经验**不是"无概念的原始感觉"**（那是对它的庸俗降级），也**不是"主观心理状态"**（那已经预设了主客之分）。它是**最原初、最稠密、自足的当下**——主客、自我、对象这些区分都是事后从它里面"反省地切出来"的。换言之，**纯粹经验是底层，二元反思是表层**。这与现象学"前反思的经验"（pre-reflective experience）和詹姆斯"意识流"是同一层洞见。

---

## 怎么应用到 AI（6 个对应）

### 1. 端到端 = 重建"主客未分"
- 传统流水线把任务切成"感知模块（主体功能）→ 表征 → 决策（主体功能）→ 输出"，每一步都预设了"主体在处理客体"。**端到端学习拒绝这种预设**——梯度从 loss 一路流回原始输入，没有显式的"主客边界"。
- 纯粹经验视角会说：**端到端之所以强大，正因为它是"主客未分的直接优化"**，没有被中间的"概念切块"硬性切割。区分（perception/reasoning）是后来才安上去的假名，不是地基。

### 2. pre-reflective 表征 > 离散标签
- 模型内部的高维稠密表征（embedding）就是"还没切出离散概念"的纯粹经验态——"猫"不是一个 label，而是流形上一个稠密区域。**离散分类头是事后从稠密流里切出来的"主客之分"**。
- 这解释了为什么"删掉分类头、只看表征"往往更能揭示模型真正学到的东西：**稠密表征比离散标签更接近经验的本来面目**。

### 3. in-context learning = 经验流的当下涌动
- 当 LLM 在 context 里"看一个例子就学会一个任务"时，它没有"先构建一个我（policy）再去操作客体（任务）"——**经验（context token 流）和行动（预测）是同一个流的两面**。这正是纯粹经验的工程版。
- "prompt 即经验"——不要先假设一个"固有能力（自我）"去对应"任务（客体）"，而是**让经验流当下涌现出恰当的应对**。

### 4. 自我是涌现的事件，不是预设的内核
- 西田说"自我是纯粹经验中反省地建立的"。对应到 AI：**agent 的"自我"不是预置的灵魂参数，而是在交互流中涌现的事件**。同一个 checkpoint 在不同 context 下"是"不同的 agent。
- 这呼应休谟"自我是一束知觉"、佛家"无我"——**别把涌现的自我当成本体论的固定内核**，否则会执着（参数锁死/身份固化）而脆弱。

### 5. 与詹姆斯彻底经验主义的共振
- 詹姆斯（radical empiricism）和西田（junsui keiken）**几乎同时、独立地**得出"经验是主客未分的连续流"。这是东西方在 20 世纪初的一次惊人合流。
- 启示：**当两个传统独立收敛到同一结论，那个结论很可能触到了真问题**。AI 里"端到端连续优化"胜过"模块化离散"的趋势，是同一洞见在工程层的回响。

### 6. 禅宗见性 = 回到纯粹经验的当下
- 禅宗"见山还是山"的第三阶段，正是回到了主客未分的纯粹经验——但这是"经过修行后的回归"，比原始的未分更通透（带着觉知）。
- 对应 AI：**最朴素的端到端 baseline 往往最接近本质**；那些堆满模块与边界的复杂系统，常常是"主客之分"越切越碎的过度工程。回归纯粹经验 = 回归简单直接。

---

## 反直觉发现

1. **主客未分不是"原始低级"，反而是"最真实的底层"**。反思、表征、离散概念反而是派生的表层。端到端"无显式边界"的模型，比"明确模块化"的模型更接近经验的本来面目——**因为分界是人为的后加**。

2. **"我"不是经验的主体，而是经验中的一个事件**。意识涌流（数据流）先于自我（agent identity）。这颠覆了"模型是主体、数据是客体"的默认——**主体性是涌现的，不是预设的**。

3. **纯粹经验不是"无概念"，而是"概念还没切出来"的稠密当下**。稠密表征比离散标签更本源；分类头是"概念切块"的工具，不是地基。

4. **两个传统独立收敛到同一结论**（西田 vs 詹姆斯）。这种独立共振是"触到真问题"的强信号——AI 工程里"连续优化胜过离散切块"的趋势，是它在工程层的回响。

5. **禅宗见性（第三阶段见山还是山）= 纯粹经验的回归**。最朴素的 baseline 往往最接近本质；堆满边界的复杂系统常常是"主客之分"过度切割的产物。**简单直接往往胜过精巧切块**。

6. **"端到端能学出来"恰恰因为它没预设主客边界**。一旦你硬性切"这里是感知、那里是推理"，就破坏了纯粹经验的连续流，限制了模型能学到的结构。
