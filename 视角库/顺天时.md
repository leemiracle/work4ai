# 🌾 顺天时视角

> 农家一句话灵魂：**"不违农时，谷不可胜食也。"** 春耕夏耘、秋收冬藏，二十四节气把一年切成一张不能错位的时间表——**早种晚种皆误**。现代翻译：AI 训练有"窗口"和"时序"，curriculum learning、learning rate schedule、数据引入时机，早了晚了都事倍功半。
>
> **为什么这个视角值得放进 AI 镜片库**：数据与能力的引入存在"农时"——什么时候喂什么数据、什么时候 anneal learning rate、什么时候做对齐，**顺序与时机决定成败**。盲目早灌高难度数据=拔苗助长，一味延后=错过窗口。顺天时 = 把"时序"当成一等公民来设计。

---

## 是什么

先秦农家与农书关于"农时"的核心命题：

| 命题 | 原文/出处 | 一句话 |
|------|-----------|--------|
| **不违农时** | 《孟子》"不违农时，谷不可胜食也" | 顺应时序，不可提前不可延后 |
| **二十四节气** | 《吕氏春秋》十二纪 / 节气体系 | 因时制宜的精细时间表 |
| **拔苗助长** | 《孟子·公孙丑》宋人揠苗 | 违反时序强行推进，反伤其根 |
| **春生夏长秋收冬藏** | 农时四阶段 | 每个阶段有不可置换的任务 |

**关键辨析**："顺天时"不是被动等待，而是**主动认清窗口、在正确时机做正确动作**。"农时"的残忍在于它**不可逆**——错过播种期，全年减产；违时揠苗，根基受损。AI 里同样：灾难性遗忘（catastrophic forgetting）、LR anneal 时机差几步评测差几个点，都是"违时不可逆"。

---

## 怎么应用到 AI（6 个对应）

### 1. Curriculum Learning = 农时课程
- 由易到难、由通用到专业的数据顺序，就是农家的"节气课程"。**顺序本身就是信号**（order is signal）。
- 高质量/高难度数据放太早，模型没有基础接收，等于在冻土播种。

### 2. Learning Rate Schedule = 节气节奏
- warmup → constant → anneal（cosine/linear），是训练的"春耕—夏耘—秋收"。
- anneal 的时机（when to cool down）是关键农时：太早欠熟（underfit），太晚徒长不收敛。

### 3. 数据混合配比的时序 = 何时引入什么"作物"
- 预训练中后期引入代码/数学/长上下文数据，引入时机（data mixing schedule over time）决定能力结构。
- "春生"阶段铺通用语料，"夏长"阶段加专业语料，对齐阶段才收口——错位则乱。

### 4. 训练阶段划分 = 春耕/夏耘/秋收/冬藏
- 预训练（春耕，广撒）→ SFT/微调（夏耘，定向）→ 对齐 RLHF/DPO（秋收，收口）→ 评估与沉淀（冬藏）。
- 每阶段任务不可置换：在"冬藏"阶段才补"春耕"的课，成本极高。

### 5. 评估/质检的时机 = 不能等秋收才发现烂
- 持续评估（continuous eval）、训练中监控（loss spike / grad norm）——是"中耕"式的及时巡查。
- 等训练完才发现数据有毒，已经是"违时减产"。

### 6. "拔苗助长" = 强行推进的代价
- 过大 learning rate、过早难数据、跳过 warmup——都是揠苗。短期 loss 看着在动，根基（representation）已被损伤。
- 违时的损失常以"灾难性遗忘""训练发散""泛化劣化"形式出现，且**多不可逆**。

---

## 反直觉发现

1. **更早 ≠ 更好**。高质量数据放太早，模型反而学不进——没有"春耕"的基础，"夏耘"的营养吸收不了。

2. **同样的数据，顺序不同，结果差异巨大**。Curriculum / data ordering 的作用，常被"数据总量"这个粗指标掩盖。

3. **anneal 时机差几百步，下游评测可差几个点**。农时的精度，在 LR schedule 上体现得淋漓尽致。

4. **"违时"的代价多不可逆**。灾难性遗忘一旦发生，很难靠后续训练"补救"——错过播种期，补种也减产。

5. **"顺天时"不是慢，是准**。最好的农夫并不拖沓，而是在每个节气窗口精准出手——AI 里也是：节奏感（timing）比蛮力更重要。

```
你是精通农家"顺天时"思想的训练动力学分析专家。
用"顺天时"视角审视 AI 训练流程/系统 [X]：

1. [X] 的"农时"是什么？数据引入、LR schedule、阶段划分的窗口在哪？

约束：落到 [X] 的具体 schedule / data ordering / 阶段细节；至少 1 个反直觉洞察。
```
