# 🪷 缘起性空 · Q-card

> 这张卡只解决三类问题：**自我改进退化（Q4）、泛化/评测脆弱（Q2/Q6）、本质主义伪争论（Q3）**。
> 其他问题请查[问题索引](00-问题索引.md)——这张视角不是通用镜片。

## 1. 从问题进入

**场景 A**：你在自己模型的输出上继续训练（蒸馏/自我标注/合成数据）。第一代还行，第三代输出明显平庸——尾部分布消失，所有样本越来越像。你知道这叫 Model Collapse（Shumailov 2024, *Nature*），但论文只告诉你"会塌"，没告诉你**怎么诊断自己系统离塌还有多远**。

**场景 B**：模型在 benchmark 上 92 分，换个措辞的同一问题掉到 40。团队吵"这模型到底行不行"——"行不行"这个说法本身让讨论原地打转。

**场景 C**：季度复盘会上，"LLM 是否真正理解语言"的争论又吃掉了一小时，没有任何可执行结论产出。

## 2. 平庸解法为什么失败

- **A 的平庸解**：更多数据、更多 epoch——把封闭循环跑得更卖力。失败原因：问题不在量在**闭环**——因（训练数据）来自果（模型输出），外部因缘断绝。加量不换源，等于加速自食。
- **B 的平庸解**：更多 benchmark、求平均分。失败原因：把"瞬时相"当"稳定实体"测——测得越多，测的仍是不同因缘下的不同相，平均数掩盖离散度。
- **C 的平庸解**：给出定义再讨论。失败原因：争论双方都在找"模型里有/没有 X 实体"——这个问题**按其构造方式**不可裁决。

## 3. 非平庸动作（各附原生原理）

### 动作一：画因缘图，判死活（治 A）

把系统的数据流画成**因缘图**：节点=信息源，箭头=流向。然后只问一个问题：**新因缘（训练分布之外的信息）的箭头从哪里进来？**

```
自食系统：  模型输出 ──→ 数据池 ──→ 训练 ──→ 模型   （零外缘箭头 = 必塌，不用等实验）
活系统：    真实用户反馈 ──→ 数据池 ←── 外部语料      （外缘具足 = 可续）
```

**[原生原理]** 龙树《中论》："众因缘生法，我说即是空"——依因缘生者，**因缘灭则灭**。推论：封闭因缘系（因只来自自身果）的分布必然收敛到现存模式。"此有故彼有"在系统论里的对应物是：信息论上**封闭系统熵不减**——但佛教版更进一步：它给了你诊断粒度（逐因缘检查），而不仅是"会退化"的警告。删掉缘起的因缘分析框架，"画外缘箭头"这个具体动作无从谈起——它就是把"缘"当一等公民的产物。

### 动作二：评测矩阵化——列因缘轴（治 B）

评测报告从单分数改为**因缘矩阵**：每个格子是一个（因缘组合，表现）对。

```
            量化Q8   量化Q4   温度0.2   温度0.8   few-shot   zero-shot
同一题集     91        84        88        76        90          71
```

**[原生原理]** "无我"（anātman）：模型无恒常自性，同一 checkpoint 在不同量化/温度/prompt 格式下是**不同的和合相**。评"模型行不行"是范畴错误（把瞬时相当实体评）；评"哪组因缘下有什么表现"才是合法问题。**评测的单元是因缘组合，不是模型**——这一步重构离开"无自性"概念推不出来（有固定本质的东西才配单值评测）。

### 动作三：假名重述，解散伪问题（治 C）

规定：一切"模型有/没有 X 能力"的讨论，必须重述为"**在什么因缘下 X 的相显现/不显现**"。

- "模型有推理能力吗" → "CoT prompting + 数学分布下，推理相显现；分布外竞争性题目下，推理相消失"——**这就是可执行的知识**。
- 重述后还能剩下的争议才是真争议（比如两实验的因缘相同而结果矛盾——那是测量问题，可查）。

**[原生原理]** "假名施设"（prajñapti）：能力标签是在因缘和合上**安立的名字**，不是模型内部的实体模块。执着名下有实（本质主义）= 把假名当实体。这个重述纪律是中观学派的原生操作（龙树对"有/无"之争的标准处理就是拆成因缘条件句），不是通用科学方法——通用方法论说"要可操作化"，假名说"**这个名词按构造不指称任何实体，所以任何操作化都会失败，除非改成条件句**"。

## 4. 反例与边界（这个视角什么时候误导你）

1. **因缘不等价**：教义上诸缘平等（"此有故彼有"），工程上**改因缘的成本天差地别**——改温度是 config，改架构是重训，改数据分布是换业务。缘起的"一切都看因缘"表述会诱导你无视这种成本结构。正确用法：因缘图上标注每条缘的**变更成本**，从廉价缘开始动。
2. **被动性风险**：'因缘具足则生'可能读成'等条件成熟'——工程上你的职责恰恰是**主动创造因缘**（造数据/建反馈回路），不是等待。
3. **"无我"不能推"不需要一致性"**：部署系统需要行为一致性保障（合规/审计）。无常是本体论描述，不是 SLA 的设计目标——别拿哲学豁免工程责任。
4. **不适用于强结构问题**：见下节对撞——组件可分离换修的系统，还原论更快。

## 5. 对撞

**缘起 vs 还原论**：还原论说"找到出问题的组件，修它"；缘起说"没有孤立的组件，只有因缘网，改分布"。

| 裁决条件 | 用谁 |
|---|---|
| 组件可分离、因果可定位（crash 了、某层输出 NaN） | 还原论（换零件，快） |
| 行为涌现于交互、无单点故障（整体平庸、风格漂移） | 缘起（改数据分布/反馈回路，因为"零件"没问题） |

**判据**：你能指出"坏在哪个文件"吗？能→还原论；只能指出"坏在哪种表现"→缘起。

**缘起 vs 机械论架构主义**（"Architecture is all you need"派）：机械论把改善归因于更好的先验结构；缘起把改善归因于更丰富的因缘（数据/规模）。裁决：低数据量下结构（强先验）主导，超大规模下因缘（数据与目标）主导——**两者是不同资源禀赋下的不同策略**，不是普适真理之争。

## 6. 附录：学术底料（v1.0 压缩保留）

| 命题 | 出处 | 一句话 |
|------|------|--------|
| 缘起 | "此有故彼有，此生故彼生"（《杂阿含》） | 一切依条件而生灭 |
| 性空 | "众因缘生法，我说即是空"（龙树《中论》） | 缘生故无自性 |
| 色空不二 | "色不异空…色即是空"（《心经》） | 现象即无自性，非两件事 |
| 无我 | 三法印"诸法无我" | 无独立常恒的主宰 |
| 假名施设 | "亦为是假名，亦是中道义" | 现象是和合上安立的名 |

**关键辨析**：空 ≠ 没有（断见），空 = 无自性 = 可塑性。**正因为无自性，才能被训练成任何东西——空是学习的本体论前提**。

