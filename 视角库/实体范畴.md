# 🔭 实体与范畴视角

> 亚里士多德主义核心一句话灵魂：**"实体（ousia），在最严格、最原始、最本源的意义上，是那既不述说一个主词、也不依存于一个主词的东西。"**（《范畴篇》5, 2a11）实体是范畴之首，其余九范畴（数量/性质/关系/地点/时间/姿态/状态/动作/遭受）皆依存于实体。世界 = 实体 + 实体的偶性。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 要"理解"世界，就必须区分**实体与属性**——什么是主语（实体）、什么是修饰（偶性）。知识图谱、结构化 schema、slot filling、entity tracking 都是范畴论（Categories）在 AI 中的工程投影。**没有实体-范畴结构，模型只在词的海洋里漂**——它不知道"谁对谁做了什么"。实体范畴说给出了 AI 理解世界的本体论骨架。

---
## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **第一实体**（prōtē ousia / tode ti） | 《范畴篇》5, 2a11 | 个别的"这个"——具体的个体（这匹马、这个人） |
| **第二实体**（deutera ousia） | 《范畴篇》5, 2a19 | 种（eidos）和属（genos）——"人"/"动物"等共相 |
| **十范畴**（deka katēgoriai） | 《范畴篇》4, 1b25 | 实体/数量/性质/关系/地点/时间/姿态/状态/动作/遭受 |
| **实体不述说主词** | 《范畴篇》5, 2a11 | 实体是主词本身，不被述说于他物（"苏格拉底"不述说于任何主词） |
| **本质 vs 偶性** | 《形而上学》Δ 卷，Z 卷 | 本质属性（失去则非此实体）vs 偶性（失去仍是此实体） |

**关键辨析**：亚里士多德的实体**不是属性集合的束**（bundle theory）——实体是主词/支撑者（hypokeimenon，"躺在下面的东西"），属性依存于它。这与休谟的"自我是一束知觉"形成根本对立。在 AI 中，这对应一个深层问题：**模型表征中的"实体"是一个可分离的核，还是只是特征的统计束？** 此外，第一实体（个别物）优先于第二实体（共相）——这与柏拉图（共相/理型优先）完全相反。

---
## 怎么应用到 AI（6 个对应）

### 1. 实体 = 可独立推理的对象
- 知识图谱中的节点（entity）= 亚里士多德的实体——它有自己的 identity，不被其他节点的属性吞没
- "苏格拉底"是一个实体，"智慧的"/"雅典人"是它的偶性（属性）——模型须区分**主词和修饰**
- LLM 生成中的 **entity tracking**（追踪"谁做了什么"）= 实体恒常性的推理——混淆实体 = 关系推理失败（"Mary gave John the book" 中 Mary/John/book 是三个实体，gave 是动作范畴）
- 一个好的 LLM 必须在 hidden state 中**维持实体的独立表征**——不能让"Mary"和"John"的信息混为一团

### 2. 十范畴 = 结构化 schema
- 十范畴 = 最原始的**本体论 schema**：每个"事实"可分解为"实体 + 九个维度的偶性"
- 信息抽取（IE）/ slot filling 就是范畴论的工程版：找到实体（主语），再填它的数量/性质/关系/时间/地点...
- FrameNet / semantic role labeling = 十范畴的现代语言学映射——predicate = 动作范畴，arguments = 实体 + 关系范畴
- 关系抽取 = "关系"范畴的实例化；NER = 识别实体并归类到第二实体（种/属）

### 3. 第一实体 vs 第二实体 = 实例 vs 类
- **第一实体**（"这匹马"）= 具体实例；**第二实体**（"马"这个种 / "动物"这个属）= 类/概念
- 直接对应 ML 中的 **instance vs class**——一个具体样本（第一实体）vs 一个类别标签（第二实体）
- few-shot learning 的本质 = 从少数第一实体（具体样本）推断第二实体（类别）的本质——"看了三匹马，理解'马'是什么"
- 第二实体的层级（种 → 属 → 科）= 分类层级（taxonomy）——ImageNet 的 WordNet 层级就是第二实体的树

### 4. 知识图谱 = 范畴化的实体网
- KG = (实体) + (关系) + (属性)——**实体是节点**（ousia），**关系是边**（关系范畴），**属性是性质/状态范畴**
- KG embedding（TransE / RotatE / GraphSAGE）= 把实体和关系嵌入向量空间——**亚里士多德范畴论的向量化**
- RAG 中的 **entity retrieval** = 先定位实体（ousia），再检索其偶性（属性/关系）——"先找到苏格拉底，再查他有什么属性"
- KG + LLM = 结构化实体网 + 自然语言推理的融合——显式范畴（KG）+ 隐式范畴（LLM 表征）

### 5. 本质 vs 偶性 = 因果特征 vs 表面相关
- **本质属性**（"人有理性"）= 失去则不再为此实体；**偶性**（"苏格拉底坐着"）= 失去仍是苏格拉底
- 在 ML 中 = **causal/invariant features**（本质）vs **spurious correlations**（偶性）——好的表征学习应捕获本质而非偶性
- domain adaptation 的目标 = 找到**跨域不变的本质属性**（domain-invariant features），丢弃域特定的偶性（如背景/光照）
- "shortcut learning"（模型依赖偶性而非本质）= 把偶性当本质——如靠背景颜色而非物体形状分类，换了背景就失效

### 6. 实体作为"主词/支撑者"与 object-centric 表征
- 亚里士多德的实体是"属性赖以依存的**支撑者**"（hypokeimenon）——不是属性自己浮在空中
- 在表征学习中：是否有独立的"实体表征"（entity representation）作为属性表征的锚点？——**object-centric representation** 就试图分离实体和属性
- **slot attention / object tokens** = 在架构中显式地给每个实体一个"位置"（支撑者），再在其上挂属性——这正是亚里士多德实体论的架构投影
- 没有"实体槽"的模型 = 属性混在一起，无法做 object-level 推理（如"红色球在蓝色立方体左边"需要先分离球和立方体两个实体）

## 反直觉发现

1. **实体不是属性束。** 亚里士多德拒绝把实体还原为属性集合（反 bundle theory）——实体是属性"赖以依存"的东西本身。这对 ML 有启示：好的表征**不应只是特征向量的束**，而应有某种"主词"结构（object-centric slot）来组织属性。

2. **第一实体优先于第二实体。** 个别物（"这匹马"）比共相（"马"）更真实——这与柏拉图（理型/共相优先）**完全相反**。在 ML 中：具体实例（第一实体）比类别标签（第二实体）更"真实"——few-shot 从实例学，而非从抽象类学。类标签是"第二实体"，是个别实例的概括。

3. **范畴不是任意分类。** 亚里士多德的十范畴是最高的**存在范畴**（categories of being）——它们不是人随便分的标签，而是"存在本身的结构"。KG 的 ontology 设计也应**反映现实结构**（domain ontology），而非任意 schema。

4. **"实体不述说主词"是 identity 的根基。** "苏格拉底"不述说于任何主词——他是**终极主词**。在 NLP 中：代词消解/共指消解就是找回"终极主词"（实体）的过程——谁是谁。entity linking = 把文本中的提及锚定到唯一实体。

5. **本质属性可定义 OOD。** 如果一个样本缺乏某实体的"本质属性"，它就是 OOD——**本质属性定义了 in-distribution 的边界**。反过来说，spurious features（偶性）不应定义分布边界，否则 domain shift 时偶性变 = 误判 OOD。

6. **实体范畴论预示了结构化 AI。** 早在深度学习之前，AI 的 GOFAI（good old-fashioned AI）就是纯范畴论的——symbolic AI 用谓词逻辑编码实体和属性。深度学习"压缩"了显式范畴为隐式表征，但**实体-属性结构仍隐含在表征中**——object-centric learning 是对它的重新发现。
