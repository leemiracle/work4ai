# ✂ 共相是名视角

> 唯名论核心一句话灵魂：**"共相只是名称（nomina / vox / conceptus），唯有个别物（individualia）真实存在。"**（威廉·奥卡姆《逻辑大全》）"人""马""树"这些普遍概念不是独立存在的实体，而是心灵用来指称一群个别事物的**名称/符号**。柏拉图把共相当理型实体，托马斯说共相"在物之中"（in re），奥卡姆则一刀砍下：**共相只在心灵和语言中，不在实在中。**
>
> **为什么这个视角值得放进 AI 镜片库**：机器学习的核心操作之一就是"聚类/分类"——把相似的个别样本归入一个"类别"。但**类别标签是名称（nomina），训练样本才是实体（individualia）**。当我们把聚类中心（cluster centroid）、原型向量（prototype embedding）当作"真实存在的概念实体"时，就犯了**经院实在论的 AI 版**——把统计概括物化了。用"共相是名"看 AI，你会警惕：别把 prototype 当本体，别追问"模型的真正本质"，**看实例行为而非臆想内核**——这正是反本质主义的工程化实践。

## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **唯名论核心** | "共相不是物，而是名称"（奥卡姆《逻辑大全》I.2）| 普遍概念只是符号，非独立实体 |
| **唯有个别真实** | "在心灵之外，一切事物都是个别的"（奥卡姆《语录评注》）| 只有具体个别物真实存在 |
| **共相的功能** | 共相是"为指称多个个别物而发明的符号"（vox significativa）| 名称有用，但不因此成为实体 |
| **反实在论** | 砍掉柏拉图理型、砍掉托马斯"共相在物" | 不为本体论多承诺一个"共相实体" |

**关键辨析**：唯名论（nominalism）**不是**说"共相是错的/无用的"——那是概念虚无主义。奥卡姆承认共相作为**名称（nomina）和心灵概念（conceptus）是有用的工具**：没有"人"这个词，我们无法交流。唯名论说的是：**有用 ≠ 真实存在**。"马"这个名称指向许多具体的马，但不存在一个超越所有马的"马性"（horsehood）实体。这直接对立于柏拉图实在论（共相是最高级的真实）与托马斯温和实在论（共相在个别物中有实在基础）。奥卡姆的立场可概括为：**把本体论承诺压缩到最小——只承诺个别物，共相留给语言和心灵。**

## 怎么应用到 AI（6 个对应）

### 1. 类别标签是名称，训练样本才是实体
- 在分类任务中，"猫""狗"这些 class label 是**名称（nomina）**——是人类/标注者发明来指称一组相似图片的工具符号。**真正存在的只有每一张具体的图片（individualia）**。
- 这提醒我们：类别是人为划定的边界，不是数据中固有的"本质"。同一个数据集换个标注体系，类别就变了——**名称可换，实体（样本）不变**。

### 2. 别把 cluster 中心 / prototype 当实体
- 聚类算法（K-Means、原型网络）会算出一个"聚类中心"或"原型向量"。**唯名论警告：这个中心是统计概括（名称），不是真实存在的"概念实体"**。
- 把 cluster 中心物化为"这个类的本质" = 犯了经院实在论的错误。正确态度：中心是**有用的导航坐标（名称）**，但类的真实内容是中心周围的那些个别样本。

### 3. embedding 空间里的"概念"是名非实
- 人们常说"embedding 空间里有一个'国王'的概念向量"。唯名论说：**那个向量是名称（对许多'国王'相关上下文的统计浓缩），不是一个独立存在的'国王性'实体**。
- 这解释了为什么同一个词在不同模型/不同层/不同上下文中的 embedding 不同——**因为名称的意义依赖指称的样本集合，样本变了名称就变**。

### 4. 反本质主义：别追问"模型的真正本质"
- "这个 LLM 到底有没有真正的推理能力？"——这类本质主义追问，唯名论会化解为：**别争"推理"这个共相是否作为实体存在于模型中；看模型在哪些个别任务上表现如何（实例行为）**。
- 缘起性空的"假名施设"与此共鸣：能力标签是假名，看因缘（数据/架构）够不够，别争本质。**奥卡姆和龙树在这里握手**。

### 5. 与实在论的对照：概念实在论的 AI 陷阱
- 托马斯的温和实在论说"共相在物中"（in re）——对应 AI 中"类别在表征空间有真实结构"的看法。这在某些场景下有效（如自然界有相对清晰的类别边界）。
- 但唯名论提醒：**别把这种有效性当成本体论承诺**。当类别边界模糊（如情感分类、风格的连续谱），强行找一个"共相实体"就是增了不必要的实体——此时唯名论的剃刀就该砍下（呼应命题 91）。

### 6. 对比学习/实例方法：不依赖"共相实体"
- 对比学习（SimCLR/MoCo）和实例判别（instance discrimination）**不依赖类别标签**——它们直接在个别样本之间学相似性。这是唯名论的工程实现：**不从"共相"出发，而从"个别物之间的关系"出发**。
- 删除类别标签后仍能学到有意义的表征——这佐证了唯名论：**类别是名称（可省），实例关系才是实在（不可省）**。

## 反直觉发现

1. **cluster 中心不是实体，是名称——别本质主义**。直觉觉得聚类中心代表"这个类的本质"，但唯名论揭示：中心只是对一组个别样本的统计概括（平均值）。**把均值当本质，就是把数学工具误认为本体实体**。正确的态度是：中心是导航坐标，真实内容是它周围的点云。

2. **"类别"是压缩工具，不是世界的固有结构**。没有类别标签，对比学习照样学到表征——这说明类别是**人为的压缩/命名**，不是数据里固有的"共相"。**世界只有个别物，类别是我们发明的省力记号**。

3. **概念实在论的 AI 版陷阱：把 embedding cluster 当真实结构**。当我们说"表征空间里有一个清晰的'动物'簇"，容易以为'动物'是个真实的概念实体。唯名论说：那个簇是**名称的统计投影**，换个数据分布它就消散了。**别把训练分布的巧合当成本体论的必然**。

4. **删除类别标签，学习照样进行——名称可省，实例不可省**。对比学习和实例判别不依赖任何 class label，却能学到强大的表征。这是唯名论的实验佐证：**共相（标签）是锦上添花的工具，个别样本之间的关系才是地基**。

5. **唯名论 ≠ 概念虚无主义**。奥卡姆不否认"人""马"这些名称有用——他只是拒绝把它们当作独立实体。**名称有用（中道义），但有用 ≠ 真实存在**。在 AI 中：类别标签有用（监督信号），但不要因此以为类别是模型中的"真实模块/实体"。

6. **OOD 问题的唯名论根源**。模型在训练分布里学到的"类别"（共相/名称），在新分布里可能**找不到对应的实体**——因为名称是绑定在旧样本集上的。**OOD 失败的本质：旧名称在新世界无实体可指**。唯名论预见：名称依赖指称，指称变了名称就悬空。
