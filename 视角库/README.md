## 🎮 核心升级：强化学习 = 元视角

2026-08-13 加入第 15 个视角后，视角库有了**层级结构**：

```
        🎮 强化学习（元视角）
              │
   ┌──────────┼──────────┐
   │          │          │
硬科学切片   软科学切片   工程切片
数学/物理    认知/心理    控制论
信息论/生物  经济/社会    Agent/系统
哲学/历史    人类/语言
```

**为什么 RL 是元视角**（详见 [`../强化学习视角-元迭代器.md`](../强化学习视角-元迭代器.md)）：

> 14 个视角各只能给一个切片——控制论给反馈，经济学给激励，神经科学给多巴胺。**只有 RL 同时给出 reward + exploration + credit assignment + policy 四件套**，能自治地解释"学习本身"。其他 14 个视角都是 RL 的特例或投影。

### RL 视角统一其他 14 个视角

| 视角 | 是 RL 的什么特例 |
|------|-----------------|
| 🎯 控制论 | 连续控制 + 即时奖励的 RL |
| 💰 经济学 | 多智能体 RL（博弈论）|
| 🧠 认知科学 | 脑的 RL（前额叶=价值，纹状体=策略）|
| 🔬 神经科学 | 多巴胺 = TD error 的生物实现 |
| 📐 数学 | RL 的公理化基础（Bellman/测度论）|
| 🔥 物理 | 变分原理 ≈ 最大化"奖励" |
| 🧬 生物 | 进化 = 代际 RL（基因=策略，适应度=奖励）|
| 💾 信息论 | 信息约束下的 reward 最大化 |
| 🏛️ 哲学 | reward function 谁设的 = 目的论形式化 |
| ⏳ 历史+未来 | discount factor = 时间偏好形式化 |
| 🌍 人类学 | 文化演化 = 群体 RL（模因=策略）|
| 👥 社会学 | 制度演化 = 多智能体 RL 均衡 |
| 📝 语言学 | 语用学 = 交流的 RL（listener reward=理解）|
| 💭 心理学 | 习惯=model-free RL，目标导向=model-based RL |

## 🎯 怎么用

### 组合示例（升级版，加入 RL 元视角）
- 学 **attention** → 数学 + 物理 + **认知科学** + **神经科学** + 🎮 **RL**（attention 是 token 选择策略）
- 学 **RLHF** → 🎮 **RL（核心）** + 哲学 + **心理学** + **经济学**
- 学 **LLM** → **语言学** + **认知科学** + 哲学 + **社会学** + 🎮 **RL**（预训练+SFT+RLHF 是退化→完整 RL）
- 学 **Agent** → 🎯 **控制论** + **心理学** + **经济学** + 🎮 **RL（Agent = RL 闭环的显化）**

### 推荐用量
- 每个核心概念至少用 **3 视角**（工程 + 1 硬科学 + 1 软科学）
- 涉及"学习/决策/优化/反馈"的概念，**用 RL 视角做骨架**，其他视角当补充
- 涉及"本质/意义"的概念，用 **哲学** 做骨架

### 每个视角文档结构
```
1. 是什么 + 核心概念
2. 怎么应用到 AI（3-6 个对应）
3. 示例：用这个视角看 attention / RLHF / LLM
4. 反直觉发现
5. 推荐资源（书 / 论文 / 项目内链接）
6. Prompt 模板（让 AI 用这个视角分析）
```
