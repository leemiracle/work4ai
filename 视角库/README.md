## 🎯 怎么用

### 组合示例
- 学 **attention** → 数学 + 物理 + **认知科学** + **神经科学**
- 学 **RLHF** → 哲学 + **心理学** + **经济学** + **人类学**
- 学 **LLM** → **语言学** + **认知科学** + 哲学 + **社会学**
- 学 **Agent** → **控制论** + **心理学** + **经济学**

### 每个视角文档结构
```
1. 是什么 + 核心概念
2. 怎么应用到 AI（3-5 个对应）
3. 示例：用这个视角看 attention / RLHF / LLM
4. 反直觉发现
5. 推荐资源（书 / 论文）
6. Prompt 模板（让 AI 用这个视角分析）
```

## 📐 视角叠加公式

**单一视角 = 盲人摸象的一只手**。
**N 视角重叠 = 接近全象**。

建议：每个核心概念至少用 **3 视角**（工程 + 1 个"硬"视角如数学/物理 + 1 个"软"视角如认知科学/心理学）。
