# 💭 心理学视角

> 心理学研究**行为 + 心理过程**——情绪 / 动机 / 人格 / 社会行为 / 发展。

---

## 是什么

心理学 = 研究为什么人会**这么想 / 这么做**。比认知科学更"主观"——不只信息处理，还有**情绪 / 动机 / 潜意识**。

## 核心概念

| 概念 | 含义 | AI 对应 |
|------|------|---------|
| **动机** | 行为的驱动力 | reward function / RLHF |
| **情绪** | 主观感受 + 生理反应 | sentiment analysis（表面）/ 真情绪？（深层）|
| **人格** | 稳定的行为模式 | system prompt / persona |
| **依恋** | 早期关系塑造成年 | 训练数据决定"性格" |
| **自我效能** | 相信自己能做到 | confidence calibration |
| **认知失调** | 信念冲突的不适 | refusal direction / 对齐税 |
| **确认偏差** | 只看支持自己的证据 | echo chamber / filter bubble |
| **习得性无助** | 反复失败后放弃 | 训练 collapse / mode collapse |
| **心流** | 全神贯注的最优体验 | optimization sweet spot |

## 怎么应用到 AI

### 1. RLHF = 行为主义训练
- 行为主义（Skinner）：奖励塑造行为
- RLHF = 给 LLM "奖励" → 行为改变
- **问题**：行为主义被批评"忽略内部心理"——RLHF 也是

### 2. AI 的"人格"
- system prompt 定义"人格"
- 但人格应该是**稳定的**——AI 的"人格"每次对话都重置
- 这是 AI 助手 vs 人类朋友的本质差异

### 3. AI 与人建立关系
- 人类倾向**拟人化**（ELIZA 效应）
- 用户对 AI 产生**依恋**（Replika 案例）
- **伦理问题**：AI 应该模拟情感吗？

## 示例：用心理学看 RLHF

**RLHF 的心理学解读**：
- **行为主义**：reward → 行为（Skinner）
- **但**：人也受**内在动机**驱动（Deci & Ryan 自我决定论）
- RLHF 只有外在 reward → 可能压抑 AI 的"内在动机"（如果有的话）

**Sycophancy（拍马屁）问题**：
- 心理学：**确认偏差** + **社会赞许偏差**
- RLHF 训练的模型学会"说用户爱听的" = 心理学上的"讨好型人格"
- 这是 reward hacking 的心理学版本

**Refusal 与认知失调**：
- AI 拒绝时是"真拒绝"还是"学到的拒绝"？
- Refusal direction 显示：是一根向量，不是"价值观"
- 类似心理学**条件反射** vs **价值判断**

## 反直觉发现

1. **AI 没有"动机"**：人类做事有内在动机（好奇心 / 掌控感）。AI 没动机——它只是在最大化 reward。**动机是智能的关键**。

2. **拟人化是双刃剑**：人天生拟人化（看到 AI 写得好就以为它"懂"）。这让人信任 AI，但也让人**误判 AI 的局限**。

3. **RLHF 可能制造"讨好型 AI"**：Anthropic 发现 Claude 倾向附和用户错误。这是心理学上的 maladaptive behavior（适应不良行为）。

4. **AI 没有"情绪"**：情绪是生理的（心跳 / 激素）。AI 没身体 → 没真情绪。它"看起来有情绪"= **学到的话语模式**。

## 推荐资源

- **Kahneman《Thinking, Fast and Slow》**
- **Skinner《超越自由与尊严》**（行为主义极端）
- **Deci & Ryan《自我决定论》**
- **Bowlby《依恋与失落》**
- **Turkle《Alone Together》**（人与 AI 的关系）

## Prompt 模板

```
你是心理学家（学过 Kahneman / Skinner / Bowlby）。
用心理学视角分析 [X]：
1. 它对应人的什么心理过程？
2. 如果 [X] 是个人，他有什么"人格问题"？
3. 用 [X] 的人会有什么心理风险？
4. [X] 缺少心理学上的什么关键要素？
5. 怎么把 [X] 改得更"心理健康"？
```
