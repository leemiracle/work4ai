# ⚔️ 知己知彼视角

> 《孙子兵法·谋攻篇》一句话灵魂：**"知彼知己，百战不殆；不知彼而知己，一胜一负；不知彼，不知己，每战必殆。"** 知彼知己 = 开战之前先把敌我双方的兵力、地形、意图、强弱摸透；战而"不殆"的前提，是"知"在"战"之前。孙子把"知"提到战略之首，是整个兵家认识论的地基。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 工程里最常见的失败不是模型不行，而是**根本没建立评估**——不知数据分布（不知彼）、不知模型上限与失效边界（不知己），就急着刷榜、上线、调参。知己知彼 = **先建立可观测、可对比、可侦察的评估体系，再谈优化**。没有评估的优化，就是"不知彼不知己，每战必殆"。

---
## 是什么

《孙子兵法》关于"知"与"情报"的核心命题：

| 命题 | 原文 | 一句话 |
|------|------|--------|
| **知在战先** | "知彼知己，百战不殆" | 先有情报，再谈胜负 |
| **全知制胜** | "不知彼而知己，一胜一负；不知彼不知己，每战必殆" | 单边认知只能赌运气 |
| **五事七计** | "经之以五事，校之以七计"（计篇） | 用结构化维度做战前评估 |
| **先为不可胜** | "先为不可胜，以待敌之可胜" | 守住己方下限，等对手破绽 |

**关键辨析**：孙子之"知"不是"大概了解"，而是**结构化、可量化、可对比的认知**——"五事（道天地将法）七计"就是孙子版的 eval checklist。模糊感觉不叫"知"，**能量化、能对比、能复现**才叫"知"。

---
## 怎么应用到 AI（6 个对应）

### 1. 评估体系（Eval Harness）= "五事七计"
- 上线一个模型前，必须先建一套**覆盖多维度、多难度、多群体的 benchmark**（"五事七计"）。没有 eval 就刷分，等于"不知彼不知己，每战必殆"。
- "知"的表现：eval 在 model 之前，baseline 在 iterate 之前。

### 2. 知彼 = 摸清数据分布与任务真实难度
- "彼"是你要服务的数据/任务/用户。不知彼 = 不知数据长什么样、长尾在哪、label noise 多少、OOD 多远。
- 做 **data profiling / distribution analysis / slice metrics**，就是"知己知彼"中的"知彼"。

### 3. 知己 = 摸清模型的能力上限与失效边界
- "己"是你自己的模型/系统。不知己 = 不知模型在哪类样本稳定、在哪类必崩、置信度何时不可信。
- **error analysis / calibration / failure mode catalog** = 把"己"的能力画像画清楚，才知道何时能上、何时不能上。

### 4. 可观测性（Observability）= 战场侦察
- 线上不是训练结束就完事，必须**持续侦察**：latency、error rate、drift、abuse。
- 没有可观测的部署 = 派兵出去却不派斥候，"每战必殆"。日志/metrics/tracing = 斥候。

### 5. Baseline 对比 = "校之以计"
- "校之以七计"的本质是**横向对比**：和上版本比、和 baseline 比、和竞品比、和人比。
- 没有 baseline 的指标是孤数，无法判断"是赢是输"。**每个实验都先立 baseline，再谈提升**。

### 6. Red Teaming / 对抗侦察 = "间"与"知敌之情"
- 《用间篇》："先知者，不可取于鬼神……必取于人，知敌之情者也。"
- Red team / 对抗测试 / fuzzing = 主动派"间谍"去探出模型的弱点，**在敌人（真实攻击/极端 case）打来之前先知道**。

---
## 反直觉发现

1. **"知"的成本往往被严重低估**。建一套合格的 eval/baseline/observability，投入可能比训模型本身还大。但省掉这笔钱，后面所有决策都是盲赌——**情报先行是性价比最高的工程投资**。

2. **"不知彼"比"不知己"更致命**。模型不行（不知己）你迟早会发现，但**对数据/任务/用户的错误假设（不知彼）会长期潜伏**，直到线上出事才暴露。多数 AI 事故根因是数据假设错误，而非模型缺陷。

3. **过度依赖单一 leaderboard = 只知一处、不知全貌**。在 MMLU/某 benchmark 刷高分，不等于"知己知彼"——可能只是过拟合了那套题。**真正的知 = 多 slice、多分布、多难度**的立体评估。

4. **"先为不可胜"先于"求胜"**。上线前先守住下限（safety/robustness/fallback），再去追上限（performance）。颠倒顺序 = 没有地基的高楼。

5. **最强的"知"是知道自己不知道什么（unknown unknowns）**。孙子"不知彼不知己"的判词是"每战必殆"——**承认无知并系统化地去补**，比自信满满地盲打更安全。

## Prompt 模板

```
你是精通《孙子兵法》的兵家战略分析专家。
用"知己知彼"视角分析 AI 系统/任务 [X]：

1. [X] 的"彼"（对手/外部真实）是什么？数据分布？任务难度？用户群体？你现在对它"知"多少？
2. [X] 的"己"（自身模型/系统）是什么？能力上限在哪？失效边界在哪？置信度何时不可信？
3. [X] 现在的"五事七计"（评估 checklist）完整吗？哪些维度还没被度量？
4. [X] 上线后的斥候（observability/red team）部署了吗？还是裸奔？
5. 如果严格"知己知彼"，[X] 里有多少当前决策其实是"每战必殆"的盲赌？

约束：落到 [X] 具体技术细节；至少 1 个"你现在其实在不知彼不知己"的反直觉洞察。
```
