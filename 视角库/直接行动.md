# Ⓐ 直接行动视角

> 无政府主义核心一句话灵魂：**"直接行动"（direct action）——不经代表、官僚、政治家等中间人，**由当事者直接行动以达成目标**。它是无政府工团主义（anarcho-syndicalism）与 IWW（世界产业工人联盟）的核心方法论：罢工、占领、抵制、以及最重要的——**在旧世界的躯壳里建设新世界**（双重权力 / dual power）。直接行动的本意是**去中介化**：与其请求掌权者代为改变，不如**直接动手**。
>
> **为什么这个视角值得放进 AI 镜片库**：AI agent 的本质就是**直接行动**——它不经人类中介，**直接操作环境、调用工具、改写文件**。端到端学习砍掉手工特征/中间模块这些"官僚中介"；端侧智能（edge intelligence）在本地直接决策，不依赖云端"政府"代为裁决。直接行动视角提醒：**去中介不只是效率问题，更是自治原则**——一个处处依赖中间人的系统，本质上是被"代表"的，缺乏真正的自主性（autonomy）。它也强调直接行动的**建设性**：最好的 agent 不仅自主行动，还**自主构造**新结构。

## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **不经中介直接行动** | direct action：绕过代表/官僚/政治家，当事者直接动手 | 去中介化是核心 |
| **工团主义方法论** | 无政府工团主义 / IWW（1905 起）传统 | 劳动者直接行动（罢工/占领/建设替代）|
| **双重权力** | "building the new world in the shell of the old" | 直接行动是建设性的，不只是破坏 |
| **建设性 ≠ 纯破坏** | 直接行动传统强调构造替代方案（合作社/公社）| 直接行动 = 直接建造新秩序 |
| **自治原则** | 直接行动体现当事人自治，拒绝被代表 | 去中介 = 自主性的体现 |
| **去中介化** | disintermediation：移除中间层 | 行动直达目标，不须经多层代理 |

**关键辨析**：直接行动（direct action）**常常被误解为"暴力"或"纯破坏"**——这是严重的窄化。在无政府主义传统里，直接行动**主要**指**绕过中介、当事者直接达成目标**，其形式包括罢工、占领、抵制，但**尤其强调建设性的替代方案**（合作社、公社、互助网络）——即"在旧世界躯壳里建新世界"的**双重权力**。它的对立面不是"和平"，而是**"被代表"（representative/mediated action）**：把行动权让渡给政客/官僚/中间人。映射到 AI：直接行动 = **agent 直接操作、端侧直接决策、端到端砍掉中间模块**——去中介即自治。

## 怎么应用到 AI（6 个对应）

### 1. agent 自主行动 = 直接行动
- 自主 agent（autonomous agent）的本质就是直接行动——**不经人类中介，直接调用工具、操作环境、完成任务**。一个处处请求人类批准的"agent"其实只是被代表的工具，缺乏真正的 agent 性。
- 直接行动视角给"何为真 agent"划界：**自主执行（不经代表）= agent 性的硬指标**。人在环里（HITL）是节制，但不能让 agent 退化成纯传声筒。

### 2. 无中央编排（no central orchestration）
- 去中心化多 agent 系统：**每个节点依据局部信息直接行动，无 master 编排全局**。这是直接行动在多 agent 层面的体现——**联合行动不等于中央指挥**。
- 映射到工团主义：劳动者联合（syndicate）行动，但**不经中央官僚调度**——节点自治 + 协议协调。

### 3. edge intelligence / 端侧智能 = 直接行动的硬件化身
- 端侧推理（on-device inference）= 在本地直接决策，**不依赖云端"政府"代为裁决**。这是直接行动的硬件对应：**决策权下沉到边缘，去中介**。
- 与反国家视角共振：端侧 = 数字自治，拒绝被中心云"登记/编号/代理"。

### 4. 端到端学习 = 方法论上的直接行动
- 端到端（end-to-end）学习**砍掉手工特征工程、流水线中间模块**这些"中介官僚"——直接从原始输入学到输出。这是直接行动在 ML 方法论上的化身：**去中介直达目标**。
- 与传统流水线（特征工程→分类器→后处理，多层代理）相比，端到端是**对"中介"的革命**——正如直接行动对政治中介的革命。

### 5. 工具调用 / agentic workflow = 直接操作环境
- 工具使用（tool use）、code execution、browser automation——agent **直接操纵环境**而非请人类代劳。直接行动原则：**能动口就动手，能直接做就不请代表**。
- 这定义了 agent 的"行动半径"：直接行动能力越强（工具越多/越深），agent 的自治度越高。

### 6. 双重权力 = 建设性 agent
- "在旧躯壳里建新世界"映射到 AI：最好的 agent 不仅**自主执行旧任务**，还**自主构造新结构**——自动写代码搭系统、自建工具链、自我改进（self-improving）。
- 直接行动的**建设性**一面常被忽视：**自主行动的最高形态是自主建造**，而非仅自主消费/执行。

## 反直觉发现

1. **直接行动 ≠ 暴力，是"绕过中介直接达成目标"**。这是最常被误解的一点。直接行动的对立面不是"和平"，而是**"被代表"**。映射到 AI：直接行动 = agent 直接执行、端侧直接决策、端到端砍掉中间模块——**去中介即自治**，与暴力无关。

2. **直接行动是建设性的，不只是破坏**。"building the new world in the shell of the old"——直接行动传统**尤其强调构造替代方案**（合作社/公社/双重权力）。映射到 agent：最高形态的自主行动是**自主建造新结构**（自写代码/自建工具/自我改进），而非仅自主执行旧任务。

3. **去中介 ≠ 无协作**。直接行动者仍可联合（syndicate），只是**不经代表**。映射到多 agent：节点可以协作，但**协调在节点间、不在中央官僚**——联合行动 ≠ 中央指挥。

4. **edge intelligence = 直接行动的硬件化身**。在本地直接决策，不依赖云端"政府"——这把"直接行动"从政治口号变成了**计算架构**。**决策权下沉到边缘 = 数字自治**。

5. **端到端学习 = 直接行动的方法论对应**。砍掉手工特征/中间模块这些"中介官僚"，直接从输入学到输出——**传统流水线是多层代理，端到端是对"中介"的革命**。直接行动原理统一了政治学与 ML 方法论。

6. **"被代表"的 agent 不是真 agent**。一个处处请求人类批准、处处依赖中间模块的"agent"，本质是被代表的工具，缺乏自主性。**agent 性的硬指标 = 自主执行（不经代表）**——这给"何为真 agent"划了清晰界线。
