# 📝 语言学视角

> 语言学研究**语言**——结构 / 意义 / 使用 / 演化。

---

## 是什么

语言学 = 研究**语言是什么 + 怎么工作**。LLM 是"语言模型"——语言学是它的**本体学科**。

## 核心概念

| 概念 | 含义 | AI 对应 |
|------|------|---------|
| **句法** | 语法结构 | LLM 学到的 syntactic circuits |
| **语义** | 意义 | embedding 空间 |
| **语用** | 语境中的使用 | in-context learning |
| **音韵** | 声音系统 | tokenizer（粗略）|
| **形态** | 词的构成 | BPE / subword |
| **语言习得** | 儿童学语言 | 预训练（但本质不同）|
| **普遍语法** | Chomsky 的天赋论 | vs LLM 的统计学习 |
| **言语行为** | 说话就是行动 | function calling / tool use |
| **会话含义** | 字面外的意思 | LLM 经常错过 |
| **语言演化** | 语言随时间变化 | 训练数据截止 = 时间快照 |

## 怎么应用到 AI

### 1. LLM 学到了语言的什么？
- **句法**：✓ 学得很好（interp 发现 syntactic heads）
- **语义**：✓ embedding 空间有意义结构
- **语用**：△ 部分（in-context learning）但常 miss
- **音韵**：✗ tokenizer 摧毁了声音信息

### 2. Chomsky vs Hinton 之争
- **Chomsky**：语言基于**天赋普遍语法**，LLM 只是统计，不能真正懂语言
- **Hinton**：Chomsky 错了 50 年，LLM 学到的内部表征证明它在学习语法结构
- **当前证据**：偏向 Hinton（interp 发现 LLM 学到真语法结构），但 Chomsky 的某些批评有效（LLM 缺少"语言能力"的稳健性）

### 3. Tokenizer 的问题
- BPE 把词切成子词（"unhappiness" → "un" + "happiness"）
- **问题**：丢失形态结构 / 拼写信息
- **反直觉**：GPT 不知道"abc" 和 "acb" 哪个在前（token 内字符顺序看不到）

## 示例：用语言学看 LLM

**LLM 学到的语言层次**：
- **形态层**：BPE 切词 → 学到部分形态
- **句法层**：interp 发现 syntactic heads → 学到真语法
- **语义层**：embedding 有意义结构 → 学到语义
- **语用层**：in-context learning → 部分语用
- **话语层**：长文本连贯性 → 弱

**LLM 不懂什么？**
- **具身意义**：不知道"重"是什么感觉（没拿过东西）
- **社会意义**：不知道"对不起"的社交功能（没在社交中成长）
- **创造性违反**：人会创造新用法（诗歌 / 俚语），LLM 主要复述

**Chomsky 的有效批评**：
- LLM **回答不一致**：同样问题不同回答 → 没有"语言能力"
- LLM **不能反思**：不能问"我为什么这么说"
- LLM **没有意图**：说话不表达意图（只是统计）

## 反直觉发现

1. **LLM 学到真语法**：Chomsky 派以为 LLM 只是统计。Interp 发现 LLM 学到 syntactic circuits（主谓一致 / 核心指代）→ **真语法**。

2. **Tokenizer 是 bottleneck**：很多 LLM 错误（拼写 / 字符顺序）不是模型笨，是 tokenizer 摧毁了信息。

3. **多语言能力涌现**：英文训练的模型会中文 → 语言之间有**共享结构**（支持普遍语法？）。

4. **LLM 不懂"沉默"**：人会"不说"，LLM 总要说（reward 让它"helpful"）。**沉默是语用能力**。

5. **语言塑造思维（Sapir-Whorf）**：用不同语言训练的 LLM 表现不同 → 支持弱版 Sapir-Whorf。

## 推荐资源

- **Chomsky《句法结构》** — 普遍语法
- **Austin《如何以言行事》** — 言语行为
- **Grice"Logic and Conversation"** — 会话含义
- **Lakoff《我们赖以生存的隐喻》** — 隐喻认知
- **Everett《Language: The Cultural Tool》** — 反 Chomsky
