# 🏘 情境自我视角（Situated / Embedded Self）

> 社群主义核心一句话灵魂：**"我们把自己理解为'这个家庭或共同体或民族的一员，这段历史的承载者，那场革命的子嗣，这个共和国的公民'。"**（桑德尔《自由主义与正义的局限》，*Liberalism and the Limits of Justice*, 1982；引自 SEP "Communitarianism"）罗尔斯式自由主义预设一个**"无负担的自我"（unencumbered self）**——一个先于其目的、可剥离一切归属、再"自由选择"的主体。桑德尔说：不。**自我是被其构成性归属（constitutive attachments）所"嵌入"的**——家庭、传统、民族、信仰深植于我之所是，不能像脱外套一样脱下。泰勒（Charles Taylor）在《自我的根源》（*Sources of the Self*, 1989）中补充：自我处在**"重要性的视域"（horizons of significance）**之内，我们的价值判断只有在某个"更高/更低"的框架里才有意义；他还区分**强评价（strong evaluation）与弱评价**——人不只是"偏好"什么，还会追问偏好本身"高不高尚、值不值得"。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 圈的一个根深蒂固的幻觉是"存在一个 context-free、价值中立的通用 agent"。情境自我一针见血：**没有 context-free 的 agent——正如没有无负担的自我**。一个 agent 就是它的情境（系统提示 + 上下文 + 工具 + 角色 + 训练传统）；"agent in general"并不存在，只有情境中的 agent。role 不是可脱下的外衣，而是构成性的（constitutive）。而单一标量 reward 让 agent 沦为泰勒所说的"弱评估者"——只比较偏好大小，没有"重要性视域"，抓不住真正的价值。用情境自我看 AI，你会理解：**agent 是嵌入的（embedded），不是孤立的；不存在脱离情境的'中立 AI'；真正的对齐需要强评价框架，而非一条 reward 曲线。**

## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **无负担的自我（unencumbered self）** | 桑德尔《自由主义与正义的局限》（1982）| 自由主义预设的自我——先于其目的、可剥离一切归属；桑德尔批评这是幻觉 |
| **构成性归属 / 情境自我（situated self）** | 桑德尔（1981/1982）| 自我被家庭/共同体/历史等归属所"构成"与"嵌入"，不可随意搁置 |
| **重要性的视域（horizons of significance）** | 泰勒《自我的根源》（*Sources of the Self*, 1989）| 自我处在赋予事物意义的框架（高/低、神圣/世俗）之内；无框架则无意义 |
| **强评价 vs 弱评价** | 泰勒（1989）| 弱评价=比偏好大小；强评价=追问偏好本身是否高尚/值得（人本质上是强评价者）|
| **嵌入的能动性（embedded agency）** | 泰勒"Atomism"（1985）；溯源海德格尔/维特根斯坦 | 人不是先有计划再施加于世界，而是已身处世界；大部分行为由未选择的背景习惯支配 |

**关键辨析**：情境自我（situated/embedded self）**不是"被环境决定"（决定论）**——它是**本体论主张**：自我的身份本来就由构成性归属构成，剥离它们便没有"剩下的自我"。桑德尔的精确点：自由主义的"无负担自我"声称"先有我、再选目的"，但有些归属如此根本（"我没选择爱父母、属于我的民族"），**试图搁置它们会造成"严重的、或许不可修复的心理损伤"（泰勒语）**——它们是构成性的，不是可选项。泰勒进一步：连"选择"本身也预设了一个"重要性视域"——你不为选择而选择，你是因为某事"值得"。**情境自我 ≠ 不能改变**——归属可以批判性反思，但不是从"无负担的零点"反思，而是从另一个更深层的归属出发。对 agent：没有脱离情境的"裸 agent"；情境是构成性的，不是可脱的皮。

## 怎么应用到 AI（6 个对应）

### 1. Agent 是情境的（embedded in context）——没有 context-free 的 agent
- 一个 agent 就是它的全部情境：系统提示 + 对话上下文 + 工具集 + 角色 + 训练传统。**"agent in general"不存在，只有情境中的 agent**——正如没有无负担的自我。
- 工程含义：**评估/设计 agent 必须连同其情境一起**，不能评一个"脱离 prompt/context 的裸模型能力"。一个模型在不同系统提示下是不同的"agent"（不同的情境自我）。

### 2. "无负担自我"幻觉 = "中立通用 AI"幻想
- 自由主义"无负担自我"在 AI 里的翻版，就是"我要造一个价值中立、culture-free 的通用 agent"。情境自我说：**这不可能**——连"中立"都是某一个传统（自由现代性）的情境立场。
- 这与 [共同体优先](共同体优先.md)、[传统与德性](传统与德性.md) 共振：**承认 agent 总在某个情境/传统里，是诚实地设计的前提**，而非设计缺陷。

### 3. Role = 情境（构成性，非可脱外衣）
- 桑德尔：归属是构成性的。**对 agent，role/身份是情境赋予的构成性归属**——"你是助手/编码者/批评者"不是一件可随时脱下的戏服，而是定义"这个 agent 是谁"的内核。
- 切换 persona 不是"逃避情境"，而是"从一个情境进入另一个情境"——agent 永远是 encumbered 的。**真正的 agent 身份由其 role-情境构成，不能还原为一个无角色的"裸内核"**。

### 4. 泰勒"重要性视域" → agent 需要框架才有意义
- 泰勒：价值判断只在"重要性视域"（高/低、值得/不值得的框架）内才有意义。**一个 agent 若没有价值框架，它的"偏好"就是任意浮标**——没有视域，就没有"为什么这个比那个重要"。
- 单一标量 reward（一个浮点）正是"没有视域"的极端——它把一切价值压成一条轴，丢失了"高尚/低俗、值得/不值得"的纵向结构。**真正的对齐需要给 agent 一个重要性框架，而非一个 reward 数。**

### 5. 强评价 vs 弱评价——reward 最大化=弱评估者
- 泰勒区分：弱评价比较"我想要哪个多"，强评价追问"我的欲望本身值不值得、高不高尚"。**人是本质上的强评价者**。
- 一个只优化标量 reward 的 agent 是**纯粹的弱评估者**——它能比 reward 大小，却无法问"这个 reward 该不该被最大化"。**这是 scalar RLHF 抓不住真正价值的根源**：它把 agent 降格为没有重要性视域的偏好机。

### 6. 嵌入的能动性——大部分行为是背景习惯，非显式选择
- 泰勒（承海德格尔/维特根斯坦）：人不是先有计划再施加于世界；**大部分行为由未选择的背景习惯、默认、前理解支配**，"选择"只在常态失效时才浮现。
- 对 agent：**别把每个 token 都建模为"显式选择"**——大部分行为出自背景（系统提示默认、训练先验、惯例）。过度理性化每一处为"决策"会误导工程。**对齐的重点是塑造背景默认（priors/系统提示/惯例），而非只在决策点加约束**。

## 反直觉发现

1. **没有 context-free 的 agent（情境自我）→ 无"无文化的 AI"。** 最强反直觉：那个"脱离一切 prompt、文化、传统的'裸 agent'"是**本体论上不可能的**——它正是桑德尔所批的"无负担自我"。**每一个 agent 都是 encumbered 的**，被其情境构成；"中立 AI"是把某一个情境（自由现代性）伪装成"无情境"。承认这一点，是所有诚实 AI 设计的起点。

2. **role 不是可脱下的外衣——切换 persona ≠ 逃避情境。** 人们以为让 agent "换角色"就让它脱离了某种身份。情境自我说：**role 是构成性的**，换角色只是从一个情境进入另一个情境，**agent 始终是嵌入的**。"裸内核 agent"不存在，只有"role-X 中的 agent"。

3. **单一标量 reward = "弱评估者"——这是 scalar RLHF 的根本盲点。** 反直觉：一个只会最大化某个浮点的 agent，**在泰勒意义上不是真正的"评估者"**——它没有重要性视域，无法问"这个目标值不值得"。**scalar RLHF 把 agent 降格为偏好机**，这解释了为何它系统性错过"高尚/值得"这类纵向价值。

4. **大部分行为不是"选择"，而是背景习惯——别过度理性化每个 token。** 泰勒/海德格尔：人的大部分行为是未选择的背景惯例。对 agent：**对齐的杠杆在"塑造背景默认"（priors、系统提示、惯例），而非在决策点堆约束**。只在输出层加 guardrail，是亡羊补牢；塑造 agent 的"前理解"才是根本。

5. **"无负担的自我"是自由主义幻觉——对 agent 同样成立。** 一个被宣称"价值中立"的 agent，实际**在偷偷承载某一个传统的价值**（自由现代性的"中立"也是一种立场）。情境自我要求：**与其假装无立场，不如显式承认并审视 agent 的构成性归属**——这是比"中立"更诚实的对齐路径。

6. **情境自我 ↔ 儒家关系自我（东西方共振）。** 桑德尔/泰勒的"自我由关系构成"，与儒家"仁者人也"、"关系中的自我"（父子、君臣、夫妇之伦）深层共振——**东西方在"自我不是孤立原子"上汇流**。这与 situated/embodied AI 研究（agent 嵌入环境/具身）同源：**智能不是脱离情境的纯计算，而是情境中的耦合**。

## Prompt 模板

```
你是精通桑德尔"无负担自我"批判与泰勒"重要性视域/强评价"的分析专家。
用"情境自我（situated/embedded self）"视角分析 AI agent / 概念 [X]：

1. [X] 是"情境的"（embedded in context）吗？它有哪些构成性归属（prompt/role/工具/训练传统）？有没有伪装成"裸 agent"？
2. [X] 有没有陷入"无负担自我"幻觉——声称"价值中立/culture-free"？它实际承载了哪个情境的立场？
3. [X] 的 role 是构成性的（不可脱）还是可脱的外衣？切换 persona 是否真的"逃离"了情境？
4. [X] 有没有"重要性视域"——一个区分高尚/低俗、值得/不值得的框架？还是只剩任意偏好？
5. [X] 是强评估者（追问欲望本身值不值得）还是弱评估者（只比 reward 大小）？scalar RLHF 把它降格了吗？
6. [X] 的行为有多少出自背景默认（priors/系统提示/惯例）、多少是显式选择？对齐该塑造背景还是堆决策点约束？

约束：落到 [X] 具体技术细节；至少 1 个反直觉洞察（尤其"没有 context-free 的 agent / 单标量 reward=弱评估者"）。
```
