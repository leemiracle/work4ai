# 🔍 反对本本主义视角（调查论 / 方法论）

> 毛泽东《反对本本主义》（1930，原名《调查工作》）一句话灵魂：**没有调查，没有发言权；调查就是解决问题。** 它反对把"本本"（书本、文件、权威结论、教条）当真理，主张一切结论必须来自对实际情况的调查。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 行业是"本本主义"的重灾区——照搬 SOTA 论文、迷信 benchmark 分数、把 demo 当产品、把开源模型当通用解、prompt 抄来不改。**《反对本本主义》给的是 AI 工程的认识纪律**：先看自己的数据，先复现，先 profile，先到"群众"（真实用户/线上分布）中去。它和《实践论》是同一枚硬币的两面——实践论讲"认识从实践来"，本本主义视角讲"认识不能从本本来"。

---
## 是什么

《反对本本主义》的四条核心命题：

| 命题 | 原文要旨 | 一句话 |
|------|---------|--------|
| **没有调查，没有发言权** | "你对于那个问题不能解决吗？那末，你就去调查那个问题的现状和它的历史吧！" | 不调查别下结论 |
| **调查就是解决问题** | "调查就像'十月怀胎'，解决问题就像'一朝分娩'。" | 调查本身就在产出答案 |
| **反对本本至上** | "以为上了书的就是对的……完全不是共产党人从斗争中创造新局面的思想路线。" | 书/论文不是裁判，实践才是 |
| **到群众中去调查** | "到斗争中去！到群众中作实际调查去！" | 答案在现场，不在办公室 |

底层方法论——**正确调查的姿势**：

| 要点 | 原文精神 | AI 翻译 |
|------|---------|---------|
| **不调查没发言权** | 凭空判断 = 0 信用 | 没 profile / 没看数据分布 / 没复现，别下"这个不行"的结论 |
| **调查要解决问题** | 调查不是写报告，是动手解 | debug 不是猜，是复现 + 最小化 + 定位 |
| **反对教条** | 本本 ≠ 真理 | 论文 SOTA ≠ 你的最优解；开源模型 ≠ 通用解 |
| **走群众路线** | 结论产生于群众斗争 | 结论产生于真实数据/用户/线上 |

## 核心概念（映射到 AI 的"九阳神功"）

| 《反对本本主义》概念 | AI/ML 对应 | 为什么是灵魂 |
|---------------------|-----------|-------------|
| **本本（书本）** | 论文 / 教程 / benchmark / 开源 README / "业界最佳实践" | 间接经验，需实践检验 |
| **没有调查没发言权** | 先复现、先 profile、先 EDA、先看真实数据 | 杜绝拍脑袋 |
| **调查就是解决问题** | 复现 bug = 调查；最小复现 = 调查到位 | 调查过程即解决过程 |
| **反对教条主义** | 反对"论文这么做就这么做""大厂这么做就这么做" | 一切以自己场景的实践为准 |
| **到群众中去** | 到真实数据 / 真实用户 / 线上分布中去 | 真理在现场 |
| **具体问题具体分析** | 同矛盾论——每场景矛盾特殊 | 不套通用配方 |
| **从斗争中创造新局面** | 在真实约束下创新，而非复制别人 | 真正的进步来自自己的实践 |

## 怎么应用到 AI（6 个对应）

### 1. "没有调查没有发言权" = 先看数据，再谈模型
- 接到任务第一件事不是选模型，是 **EDA（探索性数据分析）**：标签分布、长尾、脏数据、train/test 分布差。
- "你对于那个问题不能解决吗？那就去调查那个问题的现状和它的历史吧"——**数据就是 AI 的"问题现状和历史"**。
- 模型选错 80% 是因为没调查数据就开训。

### 2. "调查就是解决问题" = Debug 的正确姿势
- 原文："调查就像'十月怀胎'，解决问题就像'一朝分娩'。"——**调查本身就是解决过程**。
- Bug 不是靠猜，是靠**复现 → 最小化 → 二分定位**。复现了，问题就解决了一半。
- "十月怀胎"警告：**真正的调查需要耐心和样本量**，不是瞄一眼就下结论。

### 3. 反对"论文本本主义" = SOTA ≠ 你的最优
- "以为上了书的就是对的"——AI 版："**以为发了 paper / 刷了 SOTA 就是对的**"。
- 论文的 setting ≠ 你的 setting：数据分布、算力预算、延迟约束、标签成本全不同。
- **正确姿势**：把论文当"假设"，在自己的数据上做受控实验（A/B / 消融）来"实践检验"，再决定用不用。这就是《实践论》的"真理标准"。

### 4. 反对"开源本本主义" = 预训练模型 ≠ 通用解
- 开源 LLM 是别人语料（间接经验）的产物，**不是为你的领域/任务/合规要求量身定做**。
- 直接拿来用 = 把别人的"本本"当自己的真理。
- **正确姿势**：在自己数据上评估 → 微调/适配 → 持续反馈（RAG / DPO）——把间接经验转成自己的直接经验。

### 5. "到群众中去" = 到真实用户/线上分布中去
- 答案不在离线 benchmark，在**真实用户的 query、真实的失败 case、真实的线上分布漂移**里。
- **数据飞轮 / active learning / human-in-the-loop = "走群众路线"的工程化**：让真实反馈持续流回模型。
- 闭门造车的模型，无论离线多漂亮，必然在真实世界"水土不服"。

### 6. "从斗争中创造新局面" = 真正的创新来自真实约束
- 跟着论文抄，最多复制；**在真实约束（资源/数据/场景）下硬解，才可能创造新方法**。
- LoRA 出于"显存不够"、vLLM 出于"推理太慢"、量化出于"端侧部署"——**都是被真实斗争逼出来的新局面**，不是本本里抄来的。

## 示例：用反对本本主义视角看一次"照搬论文翻车"

团队照搬一篇 SOTA 论文，上线后效果拉胯。《反对本本主义》会这样诊断：

| 翻车症状 | 反对本本主义解读 |
|---------|----------------|
| 直接用论文默认超参 | "以为上了书的就是对的"——本本主义 |
| 没在自己数据上消融 | "没有调查"就上了"发言权"（决策） |
| 只看论文报的指标 | 把间接经验（别人的 benchmark）当直接实践 |
| 没看真实 query 分布 | 没到"群众"中去调查 |
| 出问题先怀疑实现 bug，没怀疑分布差 | 调查方向错了——没调查"问题的现状和历史" |

**处方**：先 EDA 自己数据 → 复现论文 baseline → 在自己分布上消融 → 灰度上线看真实指标 → 据反馈迭代。**这就是"调查—复现—检验—再调查"的工程化**。

## 反直觉发现

1. **"没有发言权"是最省时间的纪律**。看似调查耽误时间，实则**避免了你基于错误前提浪费几周**。AI 工程里，"先调查再开干"几乎是永远的最优策略。

2. **本本主义在 AI 里常以"专业感"伪装**。"这是 Transformer / SOTA / 大厂做法"听着专业，但**未经自己场景验证的专业感就是高级本本主义**。真正专业的人会说："这在我的数据上验证过，结果是 X"。

3. **"调查就是解决问题"意味着：调查本身在产出价值**。很多人把调查当"开工前的准备"，想快点点过去。但 profile/EDA/复现的过程，往往**已经让答案浮现**——调查到位时，结论是"一朝分娩"般自然出现的。

4. **最危险的本本是"自己的旧经验"**。论文是别人的本本，**你上次成功的经验是你自己的本本**。场景变了，旧经验就是教条。"具体问题具体分析"要求**每一次都重新调查当前条件**。

5. **"到群众中去"在 LLM 时代 = 看 real prompts**。模型的真正瓶颈藏在用户真实输入的长尾里，不在 benchmark 的干净样本里。**只盯 benchmark = 只在办公室里想问题**。

6. **反对本本主义 ≠ 反对读书**。毛泽东自己读书极多。它反对的是**"上了书就当真理"的态度**。论文要读，但读它是为了"得到假设"，不是"得到结论"。读完必须去自己的实践里检验。这与《实践论》"间接经验最终来自他人直接实践"完全一致。

## Prompt 模板

```
你是精通《反对本本主义》的调查方法论专家。
用反对本本主义视角分析 AI 概念/项目 [X]：

1. [X] 里，人们最容易照搬的"本本"是什么？（论文？大厂做法？开源默认值？旧经验？）
2. 针对 [X]，"没有调查没有发言权"具体要求先调查什么？（数据分布？复现？profile？真实 query？）
3. [X] 的"调查就是解决问题"——什么样的调查一旦做了，答案就自然浮现？
4. [X] 里，"到群众中去"= 去看什么真实信号？（线上指标？用户 case？长尾？）
5. [X] 有没有"以专业感伪装的本本主义"在流行？指出 1-2 个。
6. 针对 [X]，设计一个最小的"反本本主义"验证流程（如何用最少成本把本本变成自己实践检验过的结论）。

约束：
- 必须落到 [X] 的具体技术细节，不能空谈"要调查"
- "本本"要指出具体是哪类（论文/开源/旧经验/大厂做法）
- 至少 1 个反直觉洞察
```
