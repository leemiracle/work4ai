# 💰 经济学视角

> 经济学研究**稀缺资源配置**——激励 / 博弈 / 市场 / 外部性。

---

## 是什么

经济学 = 研究**人在激励下怎么决策**。AI 是新型"经济主体"——消耗资源 / 做决策 / 影响市场。

## 核心概念

| 概念 | 含义 | AI 对应 |
|------|------|---------|
| **激励** | 行为的奖励 / 惩罚 | reward function |
| **博弈** | 多主体策略互动 | multi-agent RL |
| **市场清算** | 供需匹配 | attention softmax |
| **外部性** | 行为影响第三方 | AI 的社会影响 |
| **公共地悲剧** | 共享资源被过度使用 | AI 算力 / 数据集中 |
| **信息不对称** | 一方信息多 | AI 公司 vs 用户 |
| **垄断** | 单一供应商 | OpenAI / Anthropic 主导 |
| **规模经济** | 大者恒大 | scaling laws |
| **机会成本** | 选 A 放弃 B | 训练大模型 vs 小模型 |
| **边际成本** | 多生产 1 单位 | 推理 cost / token |

## 怎么应用到 AI

### 1. Scaling Laws = 规模经济
- 经济学：规模越大，单位成本越低
- AI：参数越多，性能越好（幂律）
- **结果**：大公司垄断（OpenAI / Anthropic / Google）——小公司玩不起

### 2. RLHF = 激励设计
- 经济学：怎么设计激励让人做"对"的事（mechanism design）
- AI：怎么设计 reward 让 LLM 学"对"的行为
- **共同问题**：reward hacking = 经济学的"博弈规则被钻空子"

### 3. 数据是新型石油
- 经济学：石油是工业血液
- AI：数据是训练血液
- **公共地悲剧**：互联网数据被各家抓取，公共质量下降

### 4. AI 的外部性
- 正外部性：AI 提升生产力
- 负外部性：失业 / 假新闻 / 注意力碎片化
- 经济学：外部性需要**政府干预**（税 / 监管）

## 示例：用经济学看 LLM 竞争

**LLM 市场的经济学**：
- **寡头垄断**：OpenAI + Anthropic + Google（3 家）
- **进入壁垒**：训练成本 $100M+（资本壁垒）+ 数据（资源壁垒）+ 人才（人力壁垒）
- **价格战**：API 价格 2023-2025 下降 90%（竞争 + 规模经济）
- **差异化**：Anthropic 主打 safety，OpenAI 主打 capability，Google 主打 integration
- **锁定效应**：开发者生态（LangChain / Cursor）锁定用户

**开源 vs 商业**：
- Llama / DeepSeek 开源 = "免费商品"冲击商业定价
- 类比：Linux vs Windows / Android vs iOS
- 经济学预测：开源占据底层，商业占据高端

## 反直觉发现

1. **API 价格战让小公司活下来**：2023 GPT-4 $60/1M → 2025 $3/1M。**便宜让 AI 应用爆发**。

2. **AI 可能加剧不平等**：高技能工作者生产力 + 50%，低技能被替代。**能力溢价扩大**。

3. **训练成本下降比摩尔定律快**：同等性能模型，2 年成本降 10x。

4. **开源不一定民主化**：Llama 开源，但 Meta 仍控制。**"开源"可能是新垄断策略**。

5. **AI 算力是新 OPEC**：NVIDIA = 新石油供应商。H100 = 新原油。
