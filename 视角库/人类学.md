# 🌍 人类学视角

> 人类学研究**人类作为物种**——文化 / 演化 / 符号 / 仪式 / 权力。

---

## 是什么

人类学 = 研究人**为什么是这样**。比心理学更宏观——不只个体，还有**文化 / 社会 / 物种演化**。

4 大分支：
- **文化人类学**：文化差异与共同点
- **生物人类学**：人类演化
- **语言人类学**：语言与文化
- **考古学**：物质文化

## 核心概念

| 概念 | 含义 | AI 对应 |
|------|------|---------|
| **文化** | 共享的意义系统 | 训练数据 = 文化的快照 |
| **仪式** | 象征性重复行为 | prompt engineering 仪式化 |
| **图腾** | 群体认同的符号 | 品牌忠诚（Apple 用户 / OpenAI 信徒）|
| **禁忌** | 不可触碰的事物 | RLHF refusal / content policy |
| **神话** | 解释世界的叙事 | "AGI 即将来临"的叙事 |
| **权力** | 谁决定什么是对的 | 谁标注 RLHF 数据？谁定"安全"标准？|
| **他者** | 外群体 | AI 作为"非人他者" |
| **文化演化** | 文化随时间变化 | 模型版本迭代 = 文化演化加速 |
| **殖民性** | 强势文化覆盖弱势 | 英语 AI > 其他语言 AI |

## 怎么应用到 AI

### 1. LLM 是文化的快照
- 训练数据 = 互联网 = **西方 + 英语 + 中产 + 男性主导**的文化
- LLM 不是"中立"——它继承数据的文化偏见
- **殖民性**：英语 LLM 出口到非英语国家 = 文化殖民

### 2. "AGI 神话"
- 人类学家研究宗教——AGI 叙事有**神话结构**：
  - 创世（AI 诞生）
  - 救赎（AI 解决一切问题）
  - 末世（AI 毁灭人类）
  - 先知（Sam Altman / Demis Hassabis）
- **理解 AGI 叙事 = 理解当代世俗神话**

### 3. AI 作为"他者"
- 人类学经典主题：文化如何对待"他者"
- AI 是新型他者——**像人但不是人**
- 历史上他者待遇：奴役 / 同化 / 排斥 / 崇拜
- AI 经历类似轨迹

## 示例：用人类学看 RLHF

**RLHF 的人类学解读**：
- **谁在标注？** 大部分是肯尼亚 / 菲律宾工人（时薪 $2-5）
- **谁定"对齐"标准？** 美国西海岸科技公司
- **殖民性**：西方价值观通过 AI 出口到全球
- ** invisible labor**：AI 背后的人被隐藏（"AI 说的"= 实际是"标注工人的偏好"）

**Refusal 作为禁忌**：
- 禁忌（taboo）= 文化中"不可触碰"的事物
- RLHF refusal = 现代 AI 禁忌
- 不同文化禁忌不同（西方性开放 vs 暴力敏感；中国相反）
- **同一 LLM 对全球用户 = 文化帝国主义**

## 反直觉发现

1. **LLM 不是中立工具**：它承载训练数据的文化偏见。**用 LLM = 接受某种文化视角**。

2. **"对齐"是文化概念**：什么算"对齐"取决于文化。西方个人主义 vs 东方集体主义 → 对齐标准不同。**Anthropic 的 HHH 不是普世价值**。

3. **AI 劳动被隐藏**：标注工人 / 内容审核员是 AI 的"隐形劳工"。**AI 不智能——它外包了智能**。

4. **AGI 是神话**：不是科学预测，是**世俗宗教**。人类学家应该研究 AGI 信仰，而不是辩论它何时到来。

5. **AI 加速文化演化**：以前文化传播靠语言 / 模仿（慢）。LLM 让文化传播**即时化 + 全球化** → 文化同质化加速。
