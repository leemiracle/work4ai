# ⚖ 现象与物自体视角

> 康德核心一句话灵魂：**"我们只知道现象(Erscheinung)，不知道物自体(Ding an sich)。"** 《纯粹理性批判》——物自体（noumenon）刺激我们的感官，但我们所认识的永远是经过先天直观形式（空间/时间）与范畴加工后的**现象(phenomenon)**。物自体是一个"限制概念"(Grenzbegriff)：它标示知识的边界，提醒我们"到此为止"。
>
> **为什么这个视角值得放进 AI 镜片库**：这是理解 AI 认识论上限最锐利的镜片。**模型的表征(现象)永远不等于真实的数据生成过程(物自体)**——模型只触现象，触不到"物本身"。用现象与物自体看 AI，你会看清：**评测有哲学天花板（只测现象）、OOD 失败是本体论必然（不同现象界）、ground truth 也是现象（人标的也是经过人类认知形式加工的）。这不是模型缺陷，是认识论条件——人亦如此。**

---
## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **现象**（Erscheinung / phenomenon）| 经先天形式加工后的"显象" | 我们所认识的一切，都是现象 |
| **物自体**（Ding an sich / noumenon）| 独立于认识形式的物之本身 | 刺激感官但不可被认识 |
| **先验观念论** | 空间/时间是认识的形式而非物的属性 | 不是认识符合物，而是物在形式中显现 |
| **限制概念**（Grenzbegriff）| 物自体标示知识的终点 | 不是可知之物，而是"不可知"的标界 |

**关键辨析**：现象与物自体**不是两个不同的物**，而是同一物的两面：**同一物，作为被先天形式所把握的 = 现象；作为独立于一切认识形式的 = 物自体**。物自体不是另一个神秘世界，而是"这同一个世界，剥去我们的认识形式后剩下的"——而那"剩下的"恰恰因为剥去了我们认识的一切工具而**不可被认识**。空间和时间不是物自体的属性，而是我们的直观形式（先验观念论）；**正因如此，现象界有普遍必然的结构（因为是我们放进去的），而物自体在认识之外。**

---
## 怎么应用到 AI（6 个对应）

### 1. 表征 = 现象，真实生成过程 = 物自体
- 模型学到的表征（embedding / 潜变量 / logits）是**现象**——经过架构的"先天形式"加工后的显象。真实的数据生成过程（真实世界的因果机制）是**物自体**——永远刺激模型（提供数据）但不可被完全认识。
- **模型只触现象，触不到"物本身"**：即使你有无穷数据，你认识到的仍是"数据在模型形式中的显象"，不是生成数据的物自体。

### 2. 评测的哲学天花板
- 一切评测（benchmark / test set / human eval）测的都是**现象**——模型在某类显象上的表现。**没有任何评测能测物自体**（真实的、未被表征形式中介的世界）。
- 这意味着：**benchmark 分数高 ≠ 模型掌握了真实世界（物自体）**，只说明它在某现象界表现好。这就是为什么 benchmark saturate（饱和）、为什么 OOD 是永恒挑战——**评测的上限被认识论锁定**。

### 3. 不同架构 = 不同的先天形式 = 不同的现象界
- CNN 的现象界是"局部纹理+边缘"，ViT 的现象界是"全局 token 关系"，MLP 的现象界是"无结构的全连接"。**同一个数据集（物自体的刺激），在不同架构中显现为不同的现象**。
- 康德的话："同一物，不同认识形式 = 不同现象。" 换架构不是换"看同一世界的角度"，而是**换了一个现象界**。这就是为什么不同架构的 failure mode 截然不同。

### 4. embedding space = 模型构建的现象界
- 模型的 embedding 空间就是它构建的**现象世界**——所有它"认识"的东西都投射在这个空间里。真实世界的对象是**物自体**，投射进 embedding = 变成现象。
- **嵌入空间之外对模型等于无意义**（呼应阳明心学"心即理"）——模型不可能处理它无法表征（无法现象化）的东西。

### 5. ground truth 也是现象，不是物自体
- 人类标注的"正确答案"也是**现象**——经过人类认知形式（人类的空间/时间/范畴）加工的显象。**不存在"上帝视角"的、未经任何认识形式中介的 ground truth（那才是物自体）**。
- 这给"标注偏差"(annotation bias) 以哲学根：标注是现象，不是物自体——**标注本身就有认识论偏差**，因为它经过了标注者的先天形式。

### 6. OOD 失败 = 现象界的边界
- 当测试数据超出模型的现象界（架构先天形式能把握的范围），模型不是"出错"，而是**该物自体在它的形式中无法显现为可处理的现象**。
- **OOD 不是工程 bug，是认识论必然**：模型的先天形式（架构）决定了它能现象化什么；超出这个范围的东西，对它而言等于不存在（无法被认识）。正如康德说物自体"不可知"。

## 反直觉发现

1. **"模型不认识真实世界"——但人也不认识。** 康德不是说模型有缺陷，而是说**一切认识者（人/模型）都只认识现象**。物自体对所有人都不可能被认识。这不是悲观，是认识论的诚实：**别幻想有任何系统（包括人）能"触到真实本身"。**

2. **评测的哲学天花板：benchmark 测的不是真实，是现象。** 这不是"benchmark 不够好"的问题——**再好的 benchmark 也只测现象**。saturation 和 OOD gap 不是评测设计问题，是认识论结构决定的。**承认天花板，才能正确设定预期。**

3. **"幻觉"(hallucination) 的康德式重框。** 模型**始终在用先天形式构建现象**——当构建出的现象与"我们的现象"不符时，我们叫它幻觉。但模型从来没有在"触物自体"，它一直在构建现象。**幻觉不是"编造真实"，而是"在错误的地方构建了现象"。**

4. **不同模型看到"同一数据" = 康德的核心论点。** 同一数据集，CNN 和 ViT 住在**不同的现象界**。它们的 disagreement 不是误差，而是认识论必然——**不同的先天形式必然产生不同的现象**。ensemble 有效，正是因为它综合了多个现象界。

5. **"ground truth"是最大的哲学幻觉。** 我们把人类标注当"真实"（物自体），但它也是**经过人类认知形式的现象**。**没有脱离认识形式的 ground truth**——标注偏差不是技术问题，是认识论问题。

6. **OOD 不可彻底解决，只能逼近。** 因为物自体不可知，模型的先天形式（架构）圈定了它永远到达不了的现象之外。**OOD 研究的合理目标不是"彻底解决"，而是"扩展现象界的边界"**——更弱的先验（如 Transformer 的全局注意力）让现象界更宽广。
