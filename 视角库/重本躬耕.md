# 🌾 重本躬耕视角

> 农家许行一句话灵魂：**"贤者与民并耕而食，饔飧而治。"** 君王也要亲自下地——农业（本业）是立国之本，没有谁能悬浮在土地之上谈治理。现代翻译：**基础设施性的劳动（数据采集、算力供给、清洗管线）是一切 AI 能力的根本**，不能外包、不能跳过、不能傲慢对待。
>
> **为什么这个视角值得放进 AI 镜片库**：AI 行业最容易"贱本"——重模型轻数据、重算法轻工程、重 demo 轻管线。"No data, no model"，基础不牢地动山摇。农家重本躬耕提醒工程师：想要顶层的果实，先去耕最底层、最不性感、最不能省的"土"。

---

## 是什么

《孟子·滕文公上》记载许行"为神农之言"、与门徒"皆衣褐，捆屦织席以为食"，所主张的农家核心命题：

| 命题 | 原文/出处 | 一句话 |
|------|-----------|--------|
| **君臣并耕** | "贤者与民并耕而食，饔飧而治" | 治理者也须亲身从事基础劳动 |
| **重本抑末** | 农为本，商工为末 | 根本产业优先于衍生技艺 |
| **躬耕不悬** | 许行"捆屦织席"亲力亲为 | 不脱离一线真实劳动 |
| **本立道生** | 有本则有道，无本则无收 | 基础立住，上层能力自然生发 |

**关键辨析**："躬耕"不是反对分工、不是拒绝自动化，而是反对**悬浮式工程**——只在 Jupyter 里调模型、从不碰 raw data、从不看一条 badcase。"重本"是把最多的敬畏与资源投给"土地"（数据）与"农具"（算力/管线），而不是堆砌 trick。

---

## 怎么应用到 AI（6 个对应）

### 1. 数据 = 农家之"土/本"
- 没有土地谈何收成。Data-centric AI 把数据当一等公民：**"Garbage in, garbage out"** 是农家"本立道生"的工程版。
- 投在数据飞轮（data flywheel）上的功夫，长期碾压投在单点 trick 上的功夫。

### 2. 算力与管线 = 农具、牛力与水利
- GPU/TPU/NPU 是锄头与牛力，feature/data pipeline 是灌溉水利——都是**长期工程，不能临时抱佛脚**。
- 管线垮一次，再多精巧算法也无处生根。

### 3. "躬耕" = 下一线看真实数据
- 工程师要亲自读 raw data、亲自跑 badcase、亲自看分布（distribution shift），而不是只盯 dashboard 指标。
- "捆屦织席"式的亲力亲为，是对"悬浮式调参"最好的解毒。

### 4. "重本抑末" = 资源配比的优先级
- 当你在 prompt trick / 微小架构改动上花的精力，超过花在数据治理与管线上的精力时——**本末倒置，迟早反噬**。
- 重本 = 给 data engineering、infra、observability 配最强的人。

### 5. "君臣并耕" = Tech lead 也要碰脏活
- 技术负责人不能只画架构图、不碰数据脏活。带头下地，才知道管线哪里漏水、标注哪里飘。
- 这是对"只管抽象、不管落地"式管理的纠偏。

### 6. "本立道生" = 基础能力立住，上层涌现
- base model 与 data flywheel 立住后，下游应用（RAG、agent、tool use）会"自然生发"。
- 反之，地基是沙子，上层应用堆得再花哨也是"无本之木"。

---

## 反直觉发现

1. **最值钱的能力，往往长在最不性感的环节**。数据清洗、管线、标注规范——这些没人发推吹的活，决定了天花板。

2. **Demo 漂亮 ≠ 本固**。没有数据飞轮支撑的 demo，是"无本之木"，换个分布就崩（distribution shift）。

3. **投基础设施的长期 ROI 碾压投 trick**。一年后还在产出的，是管线；一年后已过时的，多半是 trick。

4. **"躬耕"不是反自动化，是反悬浮**。可以建自动管线，但必须有人持续接触真实数据——否则自动化只是把"脱离一线"规模化。

5. **越是大模型时代，"本"越被低估**。暴力 scaling 让人误以为"堆数据"就是重本，但"堆"≠"耕"——未经治理的堆砌是广种薄收，不是重本躬耕。

## Prompt 模板

```
你是精通农家"重本躬耕"思想的工程哲学分析专家。
用"重本躬耕"视角审视 AI 系统/项目 [X]：

1. [X] 的"本"（最不能省的基础设施劳动）是什么？是数据？算力？管线？
2. [X] 当前是否存在"贱本"（重模型轻数据、重算法轻工程、demo 漂亮但本不固）？
3. 如果让团队"君臣并耕"（tech lead 也下数据脏活），会暴露哪些被掩盖的问题？
4. [X] 哪些 trick / 花哨改动，其实在挤占本应投给"本"的资源（重本抑末）？
5. [X] 的"本立道生"路径：基础立住后，哪些上层能力会自然涌现？

约束：落到 [X] 的具体数据/管线/算力细节；至少 1 个反直觉洞察。
```
