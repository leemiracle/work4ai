# 🔗 因果即习惯视角

> 休谟主义核心一句话灵魂：**"我们一切关于因果的推断，都derived from nothing but custom/habit."**（休谟《人性论》）所谓"因果必然性"不在对象之中，而在心灵之中——我们观察到事件 A 之后恒常地伴随事件 B（constant conjunction），于是习惯（habit）使心灵由 A 的印象自然地推移到 B 的观念。"因果"不是客观联系，只是**恒常联结养成的心理习惯**。
>
> **为什么这个视角值得放进 AI 镜片库**：这是 **correlation ≠ causation 的哲学原点**。机器学习模型干的事，几乎就是休谟描述的——它从海量样本里学到"X 恒常伴随 Y"的统计相关（即"习惯"），却几乎没有触及真正的因果机制。用"因果即习惯"看 AI，你会看清：**模型越"智能"，往往越像一个靠海量数据养成的"超级习惯"机器；它学到的相关在训练分布内近乎完美，可一旦到了需要真因果的 OOD 场景，习惯就失灵**。要做因果推断、反事实推理、干预决策，必须有"习惯"之外的东西。

---
## 是什么

| 命题 | 出处/原文 | 一句话 |
|------|----------|--------|
| **因果无印象根据** | 《人性论》"我们永远观察不到因果力(causal power)，只观察到恒常联结" | 因果"必然性"不可被感官直接把握 |
| **恒常联结（constant conjunction）** | "相似对象恒常地结合" | 我们实际能观测的只是 A 类事件总伴随 B 类 |
| **习惯（custom/habit）是因果推断之源** | 《人类理解研究》"Custom is the great guide of human life" | 是心理习惯，不是理性，让我们由果推因 |
| **必然性在心不在物** | "必然性是心灵由一对象推移到其通常伴随物的情感" | 因果力是心灵的投射，非对象的客观属性 |
| **因果推断≠逻辑演绎** | "因果联结不可被先天地(a priori)发现" | 即便看到火，也不可纯凭逻辑推出它会烫——须靠经验 |

**关键辨析**：休谟**没有否认因果存在**，而是追问"我们对因果的信念从何而来"。他发现：它不能来自逻辑（因果联结不是分析命题，否定它不自相矛盾），也不能来自某个"因果力"的直接印象（我们只看到事件相继）。结论是——它来自**经验反复形成的心理习惯**。这正是"相关≠因果"最深刻的版本：我们以为是因果的，其实多数只是**恒常联结 + 习惯的投射**。

## 怎么应用到 AI（6 个对应）

### 1. ML 学的是"相关（习惯）"，不是因果
- 监督学习从（X, Y）配对里学的，本质是 **P(Y|X) 的统计相关**——这正是休谟说的"恒常联结"。
- 模型把"训练分布里 X 恒常伴随 Y"内化为权重（习惯）。它**不知道为什么** X 会带来 Y，只知道它们**总是一起出现**。相关≠因果，模型学到的永远是休谟意义上的"习惯"。

### 2. 模型把"恒常联结"误当因果机制
- 训练集里"下雨（A）总伴随"打伞（B）"，模型学到 A→B；但真实因果是 A、B 都由"天气变坏（C）"引起，或 A→B 也有反向。
- 模型无法区分"X 因为 Y"和"X 与 Y 在样本里同时出现"——这正是休谟指出的**混淆：把恒常联结当作客观因果力**。在分布内看似无误，迁移即败。

### 3. 混淆变量（confounder）陷阱 = 习惯的致命缺陷
- 当存在混淆变量 C 同时影响 X 和 Y，纯观测学到的 X→Y 是**虚假相关（spurious correlation）**——经典案例：公鸡打鸣（X）与日出（Y）恒常联结，但公鸡不导致日出。
- 休谟的洞察预演了这一陷阱：**只靠观察（恒常联结），永远无法排除混淆**。这正是为什么 ML 在 OOD / 反事实场景频繁翻车。

### 4. 因果推断需要"习惯"之外的手段：干预与反事实
- Pearl 的 do-calculus、Rubin 的潜在结果框架，都是对休谟问题的工程回应——**通过 do(X) 干预（而非纯条件 P(Y|X)）来逼近因果**。
- 反事实（"若改变 X，Y 会怎样"）是因果的试金石：模型只学条件分布，回答不了反事实；要回答，必须额外引入因果图（causal graph / SCM）。**因果性比相关性"多"的东西，不在数据里，在干预结构里**。

### 5. 强化学习的 action 是"准干预"，比纯观测更接近因果
- 离线监督学习 = 纯观测（恒常联结）；RL 的 agent 主动选择 action（X）观察 reward（Y），这构成 **intervention**——更接近因果实验。
- 因此 RL 学到的 policy 在一定程度上捕捉了"行动→回报"的因果方向（虽然仍受混杂困扰）。这解释了为什么**交互式学习比纯被动观测更可能学到因果结构**。

### 6. Scaling 不能把"相关"变成"因果"
- 更大数据、更大模型只是**养成更强的"习惯"**——更精确地拟合 P(Y|X)，但并不自动引入 do(X) 的因果结构。
- "用更多数据解决 OOD"是休谟式的幻觉：**恒常联结再多，仍然是恒常联结**。要真因果，必须额外注入因果归纳偏置（如因果发现、结构先验、干预数据）。

## 反直觉发现

1. **模型越"智能"，越像休谟笔下的人**——它靠海量数据养成的"超级习惯"运作，而非靠把握真因果。所谓"涌现能力"，多数是**更精细、更广覆盖的恒常联结**，不等于掌握了因果机制。

2. **"恒常联结"在分布内近乎完美，OOD 才暴露它只是习惯**。模型在 benchmark 上刷榜（训练分布内的恒常联结），不能证明它懂因果——换一个混淆结构不同的分布，习惯就失灵。

3. **因果性比相关性"多"的东西，不在数据里，在干预结构里**。这是休谟 270 年前就埋下的伏笔：再多的观察也无法从相关跳到因果，必须靠干预 / 反事实 / 结构假设。所以"暴力堆数据解决一切"的信念，违背休谟。

4. **"相关性即能力"在封闭分布内是对的，但它是赌注不是保证**。我们部署模型，本质上是在赌"未来（部署分布）会 resembled 过去（训练分布）"——一旦这个休谟式前提崩塌（distribution shift），能力就消失。

5. **呼应墨家三表法的"原之"**。墨家主张"原之"——用实际事用/百姓耳目之实来检验。休谟说恒常联结不足以断因果，正对应墨家要求**实证干预**而非纯然观察。因果即习惯视角提醒：要验因果，必须做"三表法"式的干预实验，不能只看相关表。
