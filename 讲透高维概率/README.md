## 〇、为什么高维概率是 ML 理论的核心

### 0.1 ML 的"维度诅咒"是祝福

低维直觉在高维**全部失效**：
- 高维球体积几乎都在"赤道"
- 两个随机高维向量几乎正交
- 高维随机变量**集中在**均值附近（concentration）

这些"反直觉"恰好是 ML 的**武器**——它们让泛化成为可能。

### 0.2 你的目标对接

你的方向是 ML 理论 / 形式化数学交叉。高维概率是 ML 理论的**语言**：
- 泛化界：基于集中不等式（Hoeffding / Bernstein）
- 优化收敛：基于凸几何 / 鞅
- 神经网络理论：基于随机矩阵 / 谱
