# 01 - 集中不等式：Hoeffding / Bernstein / ML 泛化的根基

> 本章是 Vershynin《HDP》Ch 2 的讲透版。**掌握集中不等式 = 掌握 ML 泛化的数学根基**。

---

## 一、直觉层

### 1.1 一个反直觉事实

掷硬币 $n$ 次，记正面比例为 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$。

直觉：$\bar{X}_n$ 应该接近 $1/2$。

**反直觉**：偏离 $1/2$ 超过 $\epsilon$ 的概率**指数级下降**——比多项式快。

$$\mathbb{P}(|\bar{X}_n - 1/2| > \epsilon) \leq 2 e^{-2n\epsilon^2}$$

这就是 **Hoeffding 不等式**。$\epsilon = 0.1$，$n=1000$ 时右边 $\approx 10^{-17}$——比宇宙年龄还不可能发生。

### 1.2 为什么这是 ML 的根基

ML 泛化 = "训练误差 $\approx$ 测试误差"。

形式化：训练集 $S$ 的经验风险 $\hat{R}_S(h)$ vs 真实风险 $R(h)$。两者差的概率上界由 Hoeffding 类不等式给。

**没有集中不等式，就没有 ML 的理论保证**。

## 二、数学层：3 大不等式

### 2.1 Markov 不等式（最基础）

$X \geq 0, \mathbb{E}X = \mu$ ⟹ $\mathbb{P}(X \geq t) \leq \mu/t$。

直觉：如果均值小，大值的概率不会太高。

### 2.2 Chebyshev 不等式（用方差）

$\mathbb{P}(|X - \mu| \geq t) \leq \text{Var}(X)/t^2$。

**缺点**：多项式衰减（$1/t^2$），不够紧。

### 2.3 Chernoff 界（指数衰减）★

对独立有界 $X_i \in [a_i, b_i]$：

$$\mathbb{P}\left(\left|\sum_{i=1}^n (X_i - \mathbb{E}X_i)\right| \geq t\right) \leq 2 \exp\left(-\frac{2t^2}{\sum_i (b_i - a_i)^2}\right)$$

### 2.4 Hoeffding 不等式（Chernoff 的均值版）⭐

$X_1, \ldots, X_n$ 独立，$X_i \in [a_i, b_i]$，记 $\bar{X} = \frac{1}{n}\sum X_i$，$\bar{\mu} = \mathbb{E}\bar{X}$：

$$\mathbb{P}(|\bar{X} - \bar{\mu}| \geq \epsilon) \leq 2 e^{-2n\epsilon^2 / (b-a)^2}$$

特别地，若 $X_i \in [0, 1]$：

$$\boxed{\mathbb{P}(|\bar{X} - \bar{\mu}| \geq \epsilon) \leq 2 e^{-2n\epsilon^2}}$$

### 2.5 Bernstein 不等式（用方差，更紧）

如果还知道方差，Bernstein 比 Hoeffding 紧：

$$\mathbb{P}(|\bar{X} - \bar{\mu}| \geq \epsilon) \leq 2 \exp\left(-\frac{n\epsilon^2}{2\sigma^2 + 2\epsilon/3}\right)$$

其中 $\sigma^2 = \frac{1}{n}\sum \text{Var}(X_i)$。

## 三、应用：ML 泛化界

### 3.1 固定假设 $h$ 的泛化界

固定分类器 $h: \mathcal{X} \to \{0,1\}$，从分布 $\mathcal{D}$ 抽 $n$ 个样本 $S$。记：
- 真实风险 $R(h) = \mathbb{P}_{(x,y)\sim\mathcal{D}}(h(x) \neq y)$
- 经验风险 $\hat{R}_S(h) = \frac{1}{n}\sum_{i=1}^n \mathbb{1}(h(x_i) \neq y_i)$

$\mathbb{1}(h(x_i) \neq y_i) \in [0,1]$ iid，期望 $R(h)$。用 Hoeffding：

$$\boxed{\mathbb{P}(|\hat{R}_S(h) - R(h)| \geq \epsilon) \leq 2 e^{-2n\epsilon^2}}$$

**等价形式**（置信度 $\delta$）：以概率 $\geq 1 - \delta$，

$$R(h) \leq \hat{R}_S(h) + \sqrt{\frac{\log(2/\delta)}{2n}}$$

### 3.2 多个假设的修正（union bound）

如果从 $\mathcal{H}$ 中选最优 $h$（ERM），不能直接用 3.1——因为选了最利的。

**Union bound**：$|\mathcal{H}|$ 个假设，每个置信 $\delta / |\mathcal{H}|$：

$$R(\hat{h}_{ERM}) \leq \hat{R}_S(\hat{h}_{ERM}) + \sqrt{\frac{\log(2|\mathcal{H}|/\delta)}{2n}}$$

**问题**：$|\mathcal{H}|$ 大（如神经网络无穷多假设），union bound 失效。这引出 VC 维 / Rademacher 复杂度（见 [`../讲透统计学习理论/`](../讲透统计学习理论/)）。

## 五、不足

- **紧度**：Hoeffding 是宽松上界。真实偏离概率常比界小 10-1000 倍
- **假设**：要求独立。ML 数据常有依赖（时间序列 / 数据增强）
- **分布无关**：Hoeffding 不用分布信息。如果知道是正态，可以更紧

---

## 六、应用扩展

| 应用 | 用什么 |
|------|-------|
| ML 泛化 | Hoeffding / Bernstein |
| Multi-armed bandit | Hoeffding + 信心 |
| 统计假设检验 | Chernoff |
| 随机算法 | 集中现象（如随机投影保距）|
| 随机矩阵 | Bernstein 矩阵版 |
