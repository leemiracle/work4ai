  This document describes DeepGEMM's distribution system and continuous integration/continuous deployment (CI/CD) infrastructure. It covers the GitHub Actions workflows that automate wheel building across multiple Python/PyTorch/CUDA configurations, the dual-ABI build strategy for compatibility with both standard PyTorch and NGC containers, and the intelligent wheel caching mechanism that avoids compilation during installation.

 
## Release Workflow Overview

 The release process is triggered when a version tag (format `v*`) is pushed to the repository. The `publish.yml` workflow orchestrates the creation of a GitHub release, building approximately 60 wheel variants across multiple Python/PyTorch/CUDA configurations, and publishing the source distribution to PyPI.

## Build Matrix Configuration

 The build matrix spans four dimensions to ensure compatibility across diverse Python and CUDA environments. The matrix is defined in the `strategy.matrix` section of the `build_wheels` job.

 
| Dimension | Values | Source | Purpose |
|---|---|---|---|
| Python Version | 3.8, 3.9, 3.10, 3.11, 3.12, 3.13 | matrix.python-version | Support multiple Python runtimes |
| PyTorch Version | 2.4.0, 2.5.1, 2.6.0, 2.7.1, 2.8.0 | matrix.torch-version | Match user PyTorch installations |
| CUDA Version | 12.9.1 | matrix.cuda-version | Build with recent CUDA toolkit |
| CXX11 ABI | FALSE, TRUE | matrix.cxx11_abi | Compatibility with PyPI wheels vs NGC containers |

## Wheel Build Process

 The wheel build process is managed by `setup.py` through custom `setuptools` commands. The `CachedWheelsCommand` class extends `_bdist_wheel` to download pre-built wheels, while the `CustomBuildPy` class prepares include directories and generates configuration files.

### Wheel Naming Convention

 The wheel filename encodes compatibility information: `deep_gemm-{version}+cu{cuda}-torch{torch}-cxx11abi{abi}-{python}-{platform}.whl` [setup.py83-99](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L83-L99)

 The `get_wheel_url()` function constructs this by querying:

 
 - `deep_gemm_version`: From `get_package_version()` [setup.py54-73](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L54-L73)
 - `cuda_version`: Major version from `torch.version.cuda` [setup.py90](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L90-L90)
 - `torch_version`: Major.minor from `torch.__version__` [setup.py91](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L91-L91)
 - `cxx11_abi`: Integer value of `torch._C._GLIBCXX_USE_CXX11_ABI` [setup.py92](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L92-L92)

## CXX11 ABI Dual Build Strategy

 The dual ABI build strategy ensures compatibility with both standard PyTorch wheels (`_GLIBCXX_USE_CXX11_ABI=0`) and NGC containers (`_GLIBCXX_USE_CXX11_ABI=1`).

 
| ABI Setting | Target Environment | Matrix Value |
|---|---|---|
| FALSE (0) | PyTorch wheels from pytorch.org | matrix.cxx11_abi: "FALSE" |
| TRUE (1) | NGC containers, conda builds | matrix.cxx11_abi: "TRUE" |

 **Sources:** [.github/workflows/publish.yml47-51](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/.github/workflows/publish.yml#L47-L51) [setup.py28-29](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L28-L29)

 The compiler flag is set in `setup.py` based on PyTorch's compiled ABI [setup.py28-29](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L28-L29) At runtime, `get_wheel_url()` queries `torch._C._GLIBCXX_USE_CXX11_ABI` to select the matching wheel [setup.py92-97](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L92-L97)

 
## CustomBuildPy Command Details

 The `CustomBuildPy` class performs three critical preparation steps:

 
 - **`prepare_includes()`** (lines 149-166): Copies `cute` and `cutlass` headers into the build location so they are included in the wheel's `package_data` [setup.py149-166](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L149-L166)
 - **`generate_default_envs()`** (lines 140-147): Generates `envs.py` with persistent JIT environment variables like `DG_JIT_CACHE_DIR` [setup.py140-147](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L140-L147)
 - **`generate_pyi_file()`** (lines 128-138): Creates Python type stubs for the `_C` extension module [setup.py128-138](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/setup.py#L128-L138)
