  This document provides a deep technical dive into DeepGEMM's Just-In-Time (JIT) compilation system. It covers the `Compiler` class hierarchy, kernel signature generation, the dual compilation paths (NVCC vs NVRTC), `KernelRuntime` loading, and the `KernelRuntimeCache` mechanism. This page is intended for developers who need to understand or extend the JIT infrastructure.

 For information about the overall JIT compilation pipeline from API call to execution, see [JIT Compilation Pipeline](https://deepwiki.com/deepseek-ai/DeepGEMM/3.2-jit-compilation-pipeline). For guidance on adding new kernel types using the JIT system, see [Extending DeepGEMM](https://deepwiki.com/deepseek-ai/DeepGEMM/5.5-extending-deepgemm).

## Handle Types and Launch Abstraction

 DeepGEMM supports both the CUDA Driver API and the newer CUDA Runtime API (available for CUDA >= 12.8) via conditional compilation.

 
### Library and Kernel Handles

 The system abstracts the underlying handle types based on whether `DG_JIT_USE_RUNTIME_API` is defined [csrc/jit/handle.hpp48-131](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/handle.hpp#L48-L131):

 
| Concept | Runtime API (>= 12.8) | Driver API (Legacy) |
|---|---|---|
| Library Handle | cudaLibrary_t csrc/jit/handle.hpp51 | CUmodule or CUlibrary csrc/jit/handle.hpp128-130 |
| Kernel Handle | cudaKernel_t csrc/jit/handle.hpp52 | CUfunction csrc/jit/handle.hpp119 |
| Launch Config | cudaLaunchConfig_t csrc/jit/handle.hpp53 | CUlaunchConfig csrc/jit/handle.hpp120 |

 
### Kernel Launch Configuration

 The `construct_launch_config` function standardizes how grid, block, and cluster dimensions are passed to the kernel. It supports programmatic stream serialization (PDL) [csrc/jit/handle.hpp101-105](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/handle.hpp#L101-L105) and cluster dimensions [csrc/jit/handle.hpp94-98](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/handle.hpp#L94-L98) On SM90/SM100, `cudaLaunchAttributeClusterDimension` is used to specify the cluster shape [csrc/jit/handle.hpp96-97](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/handle.hpp#L96-L97)

### Runtime Cache

 The `KernelRuntimeCache` [csrc/jit/cache.hpp11-27](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/cache.hpp#L11-L27) maintains an in-memory mapping of directory paths to `KernelRuntime` objects. ## Kernel Runtime Loading

 The `KernelRuntime` class [csrc/jit/kernel_runtime.hpp28-115](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L28-L115) handles loading compiled CUBIN files and extracting kernel function pointers.

 
### Symbol Extraction via cuobjdump

 Because C++ templates can lead to mangled names, DeepGEMM uses `cuobjdump` to inspect the CUBIN and find the entry point symbol [csrc/jit/kernel_runtime.hpp56-79](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L56-L79):

 
 - Executes `cuobjdump -symbols kernel.cubin` [csrc/jit/kernel_runtime.hpp57](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L57-L57)
 - Filters for `STT_FUNC` symbols with `STO_ENTRY` [csrc/jit/kernel_runtime.hpp62](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L62-L62)
 - Excludes internal symbols like `vprintf`, `__instantiate_kernel`, or `__assertfail` [csrc/jit/kernel_runtime.hpp56](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L56-L56)
 - Asserts that exactly one valid kernel symbol remains [csrc/jit/kernel_runtime.hpp79](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L79-L79)
 
 
### Module Loading

 Once the symbol is identified, it is loaded using `load_kernel()` [csrc/jit/kernel_runtime.hpp82](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L82-L82) which populates the `library` and `kernel` handles. On newer drivers (CUDA >= 12.4), `cuLibraryEnumerateKernels` is preferred and supported via `DG_JIT_USE_LIBRARY_ENUM_KERNELS` [csrc/jit/handle.hpp124-127](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/handle.hpp#L124-L127)

## LaunchRuntime Abstraction

 The `LaunchRuntime<Derived>` CRTP [csrc/jit/kernel_runtime.hpp120-163](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L120-L163) provides a standardized interface for kernel code generation and execution.

 
### generate()

 Calls `Derived::generate_impl(args)` to create the CUDA source string [csrc/jit/kernel_runtime.hpp124](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L124-L124) It also calculates an `include_hash` to track header dependencies [csrc/jit/kernel_runtime.hpp127-129](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L127-L129) This hash is prepended to the generated code to ensure that changes in headers invalidate the cache [csrc/jit/kernel_runtime.hpp132](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L132-L132)

 
### launch()

 Orchestrates the kernel execution [csrc/jit/kernel_runtime.hpp139-162](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L139-L162):

 
 - Retrieves the `KernelHandle` from the `KernelRuntime` [csrc/jit/kernel_runtime.hpp140](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L140-L140)
 - Gets the current CUDA stream via `at::cuda::getCurrentCUDAStream()` [csrc/jit/kernel_runtime.hpp141](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L141-L141)
 - Checks for runtime PDL (Programmatic Stream Serialization) overrides from `device_runtime` [csrc/jit/kernel_runtime.hpp146](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L146-L146)
 - Constructs the launch config using `construct_launch_config` [csrc/jit/kernel_runtime.hpp152-153](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L152-L153)
 - Delegates the final call to `Derived::launch_impl(kernel, config, args)` [csrc/jit/kernel_runtime.hpp161](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit/kernel_runtime.hpp#L161-L161)
