  DeepGEMM is a unified, high-performance tensor core kernel library designed for modern large language models. It provides optimized computation primitives for FP8, FP4, and BF16 GEMMs, as well as specialized kernels for Mixture-of-Experts (MoE), Multi-Query Attention (MQA), and HyperConnection.

 
---

 
## Purpose and Scope

 This page serves as the entry point for developers and researchers looking to integrate or extend DeepGEMM. It covers:

 
 - System requirements for SM90 (Hopper) and SM100 (Blackwell) architectures.
 - Installation procedures for both development and production environments.
 - The fundamental JIT compilation workflow.
 - Basic code examples for dense and grouped GEMM operations.

### Hardware Requirements

 DeepGEMM is specifically optimized for NVIDIA's latest architectures.

 
| Architecture | Compute Capability | Example GPUs | Notes |

## First GEMM Operations

 DeepGEMM uses a JIT compilation model. The first time a specific GEMM shape or configuration is called, the library generates and compiles the CUDA kernel.

 
### Basic FP8 GEMM (Dense)

 DeepGEMM follows the convention `D = C + A @ B`. The layout is typically NT (Non-transposed A, Transposed B), meaning the operation performed is `D = A @ B.T`.

 
```

```

 **Key Layout Rules**:

 
 - **SM90**: Supports **NT** layout only [README.md65](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/README.md?plain=1#L65-L65)
 - **SM100**: Supports **NT, TN, NN, TT** layouts [README.md65](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/README.md?plain=1#L65-L65)
 - **Alignment**: Scaling factors must be TMA-aligned using `transform_sf_into_required_layout` [README.md72](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/README.md?plain=1#L72-L72)
 - **SM100 Scaling**: Requires packed `UE8M0` format, where 4 scales are packed into a single `torch.int` [README.md70-71](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/README.md?plain=1#L70-L71)

## Configuration and Environment Variables

 
| Variable | Default | Description |
|---|---|---|
| DG_JIT_USE_NVRTC | 0 | Enable NVRTC for faster compilation (up to 10x) README.md22 |
| DG_JIT_USE_RUNTIME_API | 0 | Use CUDA Runtime API instead of Driver API for JIT setup.py25 |
| DG_SKIP_CUDA_BUILD | 0 | Skip building the _C extension during installation setup.py22 |
| DG_JIT_CACHE_DIR | ~/.cache/deep_gemm | Directory where compiled .cubin files are stored setup.py143 |
| DG_PRINT_CONFIGS | N/A | Print kernel configurations for debugging/tuning README.md27 |
