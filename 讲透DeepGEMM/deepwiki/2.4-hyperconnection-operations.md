  The DeepSeek hyperconnection operation is a specialized fusion kernel designed for high-performance pre-normalization layers. It performs a TF32-precision General Matrix Multiplication (GEMM) while simultaneously calculating the squared sum of the input activations ($A$) along the $K$ dimension. This fusion reduces memory bandwidth pressure by avoiding a separate pass over the activation tensor for normalization statistics.

 
## Overview of `tf32_hc_prenorm_gemm`

 The primary interface for this operation is `deep_gemm.tf32_hc_prenorm_gemm` [csrc/apis/hyperconnection.hpp64-66](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L64-L66) It is optimized for the DeepSeek architecture where $N$ (output features) is typically small (e.g., 24 or 32) and $K$ (input features) is large.

 
### Mathematical Operation

 The kernel computes two outputs simultaneously:

 
 - **GEMM**: $D = A \times B^T$ (where $A$ is BF16 and $B$ is FP32).
 - **Squared Sum**: $S_i = \sum_{j=0}^{K-1} (A_{i,j})^2$.
 
 
### Key Parameters

 
 - **`a` (Tensor)**: Input activations of shape $(M, K)$ in `torch.bfloat16` [csrc/apis/hyperconnection.hpp40](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L40-L40) Must be K-major [csrc/apis/hyperconnection.hpp19](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L19-L19)
 - **`b` (Tensor)**: Weight matrix of shape $(N, K)$ in `torch.float32` [csrc/apis/hyperconnection.hpp41](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L41-L41) Must be K-major [csrc/apis/hyperconnection.hpp20](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L20-L20)
 - **`d` (Tensor)**: Output GEMM result in `torch.float32` [csrc/apis/hyperconnection.hpp42](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L42-L42)
 - **`sqr_sum` (Tensor)**: Output squared sums in `torch.float32` [csrc/apis/hyperconnection.hpp43](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L43-L43)
 - **`num_splits` (Optional[int])**: If provided, the kernel performs a Split-K style decomposition. The outputs `d` and `sqr_sum` must include an additional leading dimension of size `num_splits` to hold partial results [csrc/apis/hyperconnection.hpp29-33](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/hyperconnection.hpp#L29-L33)

## Architecture-Specific Details

 
### SM90 (Hopper) Implementation

 The SM90 kernel leverages NVIDIA's Tensor Memory Accelerator (TMA) for efficient data movement.

 
 - **Thread Blocks**: Uses a fixed block size of $M=64, K=64$ [csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp72-73](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp#L72-L73)
 - **Constraints**: Currently supports small $N$ values ($\le 32$) aligned to 8 [csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp81](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp#L81-L81)
 - **Staging**: Dynamically calculates the number of pipeline stages (up to 12) based on shared memory capacity [csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp106-118](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp#L106-L118)
 - **Warp Specialization**: Splits threads into `num_math_threads` (128) and `num_tma_threads` (128) [csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp74-75](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp#L74-L75)
 
 
### SM100 (Blackwell) Implementation

 The SM100 implementation introduces support for Blackwell-specific features like Tensor Memory (TMEM).

 
 - **Memory Layout**: Uses `make_tma_3d_desc` when `num_splits > 1` to handle multi-dimensional output tensors for partial reductions [csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp97-101](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp#L97-L101)
 - **Thread Groups**: Uses `num_mma_threads` and `num_cast_and_reduce_threads` to handle the dual GEMM and squared-sum reduction logic [csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp74-75](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp#L74-L75)
 - **Shared Memory**: Includes allocations for `smem_tmem_ptr` and specialized barriers for Blackwell's execution model [csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp109-112](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp#L109-L112)
 - **Constraints**: Supports slightly larger $N$ values ($\le 128$) compared to SM90 [csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp79](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/jit_kernels/impls/sm100_tf32_hc_prenorm_gemm.hpp#L79-L79)

## Usage Requirements

 
| Feature | Requirement |
|---|---|
| Precision | Input $A$ must be BF16, Weight $B$ must be FP32 csrc/apis/hyperconnection.hpp40-41 |
| Alignment | $K$ must be a multiple of 64 csrc/jit_kernels/impls/sm90_tf32_hc_prenorm_gemm.hpp82 |
| Layout | $A$ and $B$ must be K-major; $D$ must be N-major csrc/apis/hyperconnection.hpp19-21 |
| Split-K | If num_splits > 1, the user must provide tensors with an extra leading dimension csrc/apis/hyperconnection.hpp29-33 |
