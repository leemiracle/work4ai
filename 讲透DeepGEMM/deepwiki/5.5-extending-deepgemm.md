### Kernel Registration Process

 The [csrc/indexing/main.cu1-31](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/indexing/main.cu#L1-L31) file serves as the kernel registry. All kernel implementations must be included here to be accessible to the JIT compiler. This file is compiled once at installation time to generate symbol information.

## Legacy Triton Kernels (`deep_gemm.legacy`)

 DeepGEMM maintains a set of Triton-based kernels in `deep_gemm.legacy` primarily for A100 (SM80) support or as baseline implementations for grouped GEMMs. These kernels are exposed via the `deep_gemm.legacy` package [deep_gemm/legacy/__init__.py1-5](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/__init__.py#L1-L5).

 
### Supported Legacy Kernels

 The legacy module provides specialized grouped GEMM implementations:

 
 - **M-Grouped**: `m_grouped_bf16_gemm_nt_contiguous_tl` [deep_gemm/legacy/m_grouped_gemm.py61-79](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/m_grouped_gemm.py#L61-L79)
 - **A-Fused M-Grouped**: `a_fused_m_grouped_bf16_gemm_nt_contiguous_tl` [deep_gemm/legacy/a_fused_m_grouped_gemm.py64-88](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/a_fused_m_grouped_gemm.py#L64-L88)
 - **A-Fused K-Grouped**: `a_fused_k_grouped_bf16_gemm_tn_contiguous_tl` [deep_gemm/legacy/a_fused_k_grouped_gemm.py69-88](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/a_fused_k_grouped_gemm.py#L69-L88)
 - **B-Fused K-Grouped**: `b_fused_k_grouped_bf16_gemm_tn_contiguous_tl` [deep_gemm/legacy/b_fused_k_grouped_gemm.py68-86](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/b_fused_k_grouped_gemm.py#L68-L86)
 
 
### Implementation Details

 These kernels use Triton's `@triton.autotune` to select optimal block sizes [deep_gemm/legacy/m_grouped_gemm.py10](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/m_grouped_gemm.py#L10-L10). They handle grouped indexing by loading batch IDs or row indices from metadata tensors:

 
 - `batch_id` is loaded from `m_indices_ptr` to determine which weight matrix to use for a specific block of tokens [deep_gemm/legacy/m_grouped_gemm.py36-40](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/m_grouped_gemm.py#L36-L40).
 - `rows` are loaded from `m_row_indices_ptr` for fused mapping scenarios [deep_gemm/legacy/a_fused_m_grouped_gemm.py45](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/deep_gemm/legacy/a_fused_m_grouped_gemm.py#L45-L45).

## Profiling with NCU

 DeepGEMM provides scripts for deep performance analysis using NVIDIA Nsight Compute (NCU).

 
### Mega MoE Profiling

 The script `scripts/run_ncu_mega_moe.sh` automates profiling the complex Mega MoE kernel across multiple processes.

 
 - It sets `DG_JIT_WITH_LINEINFO=1` to enable source-level counters [scripts/run_ncu_mega_moe.sh48](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/run_ncu_mega_moe.sh#L48-L48).
 - It warms up the JIT cache before profiling to ensure consistent results [scripts/run_ncu_mega_moe.sh50-51](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/run_ncu_mega_moe.sh#L50-L51).
 - It configures NCU to target the `sm100_fp8_fp4_mega_moe_impl` kernel specifically [scripts/run_ncu_mega_moe.sh58](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/run_ncu_mega_moe.sh#L58-L58).
 - It uses `PmSampling` and `SourceCounters` sections for detailed hardware utilization data [scripts/run_ncu_mega_moe.sh61-62](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/run_ncu_mega_moe.sh#L61-L62).
 
 
### Metric Visualization

 The `scripts/quick_plot_pm.py` script parses NCU reports and generates plots for curated metrics.

 
 - **Curated Metrics**: Includes SM Throughput, Tensor Pipe Throughput, L2 Hit Rate, and NVLink Bandwidth [scripts/quick_plot_pm.py77-123](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/quick_plot_pm.py#L77-L123).
 - **Categories**: Metrics are organized into "Overview", "SM", "L1", "L2", "DRAM", and "Interconnect" [scripts/quick_plot_pm.py47-54](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/quick_plot_pm.py#L47-L54).
 - **Usage**: Can be used to generate a PNG summary of a `.ncu-rep` file [scripts/quick_plot_pm.py2-9](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/quick_plot_pm.py#L2-L9).

## Contributing to the Project

 
### Development Workflow

 
 - **Setup**: Use `develop.sh` to create a symlinked installation for rapid iteration.
 - **Implementation**: Add CUDA kernels in `csrc/jit_kernels/impls/` and register them in `csrc/indexing/main.cu` [csrc/indexing/main.cu1-31](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/indexing/main.cu#L1-L31).
 - **Bindings**: Update `csrc/python_api.cpp` and use `scripts/generate_pyi.py` to update Python type hints.
 - **Testing**: Add a corresponding test in the `tests/` directory. For legacy kernels, refer to `tests/test_legacy.py` [tests/test_legacy.py1-91](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/tests/test_legacy.py#L1-L91).
 
 
### Metadata Generation

 The `scripts/generate_pyi.py` script automates the creation of `.pyi` files by scanning the C++ codebase.

 
 - `build_cpp_function_index`: Extracts function signatures from header and source files [scripts/generate_pyi.py5-94](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/generate_pyi.py#L5-L94).
 - `extract_m_def_statements`: Specifically targets pybind11 `m.def` calls to bridge the C++/Python boundary [scripts/generate_pyi.py151-205](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/generate_pyi.py#L151-L205).
 - `BracketTracker`: A utility class used during parsing to correctly identify nested template and function arguments [scripts/generate_pyi.py97-150](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/scripts/generate_pyi.py#L97-L150).
