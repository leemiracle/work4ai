## Purpose and Scope

 This document describes the Einstein summation (einsum) operations provided by DeepGEMM. These operations allow for concise expression of complex tensor contractions, which are fundamental to attention mechanisms and batched projections in modern transformer architectures.

 DeepGEMM provides two primary einsum APIs:

 
 - `einsum()`: For BFloat16 tensors with support for specific hardcoded patterns and optional cuBLASLt fallback.
 - `fp8_einsum()`: For FP8 (E4M3) tensors, incorporating scaling factors and supporting per-block quantization.
 
 For general GEMM operations without batch dimensions, see [GEMM Operations](https://deepwiki.com/deepseek-ai/DeepGEMM/2.1-gemm-operations). For specialized attention kernels, see [Attention Operations](https://deepwiki.com/deepseek-ai/DeepGEMM/2.2-attention-operations).

## Pattern Implementation Details

 
### Batch-Reduced Contraction (bmk,bnk->mn)

 This pattern is unique because it reduces the batch dimension `b` into a single output matrix `mn`.

 **Logic:**

 
 - Each thread block processes a tile of the output `(M, N)`.
 - The kernel iterates through all batches `s` and all K-tiles.
 - Partial sums are accumulated in registers (SM90) or Tensor Memory (TMEM on SM100).
 - For BF16 outputs, an implicit cast from FP32 accumulation is performed via a workspace buffer. [csrc/apis/einsum.hpp32-39](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L32-L39)
 
 **Implementation specifics:**

 
 - **SM90**: Dispatches to `sm90_bmn_bnk_mn_gemm`. [csrc/apis/einsum.hpp52-53](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L52-L53)
 - **SM100**: Dispatches to `sm100_bmn_bnk_mn_gemm`. [csrc/apis/einsum.hpp54-55](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L54-L55)

### FP8 Batched Matrix Multiply (fp8_bmm)

 The `fp8_bmm` function is the workhorse for `fp8_einsum`. It handles the layout detection and scaling factor transformation.

 **Key Steps:**

 
 - **Layout Detection**: Determines if tensors are K-major or MN-major by checking `stride(-1)`. [csrc/apis/einsum.hpp144-146](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L144-L146)
 - **Scaling Factor Transformation**: Calls `layout::transform_sf_pair_into_required_layout`. On SM100, this packs scaling factors into the format required by the hardware. [csrc/apis/einsum.hpp165-167](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L165-L167)
 - **Architecture Dispatch**: 
 - **SM90**: Currently unsupported for `fp8_bmm` in the provided `einsum.hpp` snippet (only SM100 path shown).
 - **SM100**: Dispatches to `sm100_fp8_bmm`. [csrc/apis/einsum.hpp171-177](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L171-L177)
 
 **Sources:** [csrc/apis/einsum.hpp137-177](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L137-L177)

## Data Layout and Constraints

 
### BFloat16 Requirements

 
 - **Contiguity**: Inputs `a`, `b`, and output `d` must be contiguous for the `bmk,bnk->mn` pattern. [csrc/apis/einsum.hpp42-44](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L42-L44)
 - **Alignment**: For attention projections (`bhr,hdr->bhd` and `bhd,hdr->bhr`), the rightmost dimension must be contiguous (`stride(2) == 1`). [csrc/apis/einsum.hpp67-69](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L67-L69) [csrc/apis/einsum.hpp90-92](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L90-L92)
 
 
### FP8 Requirements

 
 - **Majorness**: Supports both K-major and MN-major layouts, but requires `stride(-1) == 1` or `stride(-2) == 1`. [csrc/apis/einsum.hpp147-148](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L147-L148)
 - **Alignment**: Output `d` must have `stride(-1) == 1`. [csrc/apis/einsum.hpp149](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L149-L149)
 - **Scaling Factors**: Must match the granularity specified in the `recipe`. [csrc/apis/einsum.hpp165-167](https://github.com/deepseek-ai/DeepGEMM/blob/559d79fb/csrc/apis/einsum.hpp#L165-L167)
