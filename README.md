## 六、统一方法论

1. **原理优先于 API**：先讲为什么，再讲怎么调库
2. **每个结论都有可运行代码佐证**：不凭记忆，数字是跑出来的
3. **批判性**：每篇有「局限/争议」
4. **离散 vs 连续分水岭**：从 MSE 跨到 CE 必须翻的坎
5. **博士级标准**：论文挂载 + 数学严格 + 开放问题 + 批判性
6. **本质探索**：不只是技术——反思每个学科的根本问题
