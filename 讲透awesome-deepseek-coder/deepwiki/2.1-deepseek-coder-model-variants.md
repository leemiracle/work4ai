## Model Size Categories

 DeepSeek Coder is available in four distinct model sizes, each designed for different computational requirements and use cases. The model family spans from lightweight 1.3B parameter models suitable for edge deployment to large 33B parameter models for high-performance applications.

 
| Model Size | Parameters | Base Model | Instruct Model | Status |
|---|---|---|---|---|
| 1.3B | 1.3 billion | deepseek-coder-1.3b-base | deepseek-coder-1.3b-instruct | Available |
| 5.7B | 5.7 billion | deepseek-coder-5.7bmqa-base | deepseek-coder-5.7bmqa-instruct | Base available, Instruct coming soon |
| 6.7B | 6.7 billion | deepseek-coder-6.7B-base | deepseek-coder-6.7B-instruct | Available |
| 33B | 33 billion | deepseek-coder-33B-base | deepseek-coder-33B-instruct | Available |

 The 5.7B model includes "mqa" in its identifier, indicating Multi-Query Attention architecture for improved inference efficiency.

## Base vs Instruct Variants

 Each model size is available in two primary variants that serve different purposes in the development workflow:

 
```

```

 
### Base Models

 Base models are the foundation models trained on large code corpora without specific instruction tuning. These models are primarily designed for:

 
 - **Code completion**: Continuing partially written code
 - **Code generation**: Creating code from scratch based on context
 - **Fine-tuning**: Serving as base models for domain-specific training
 - **Research applications**: Academic and experimental use cases
 
 
### Instruct Models

 Instruct models are fine-tuned versions of the base models, specifically trained to follow instructions and engage in conversational interactions. These models excel at:

 
 - **Interactive coding assistance**: Responding to natural language queries about code
 - **Code explanation**: Providing detailed explanations of existing code
 - **Debugging assistance**: Helping identify and fix code issues
 - **Educational applications**: Teaching programming concepts

## Use Case Recommendations

 The choice of model variant depends on specific requirements regarding computational resources, response quality, and deployment constraints:

 
### Model Selection Matrix

 
| Use Case | Recommended Size | Variant | Rationale |
|---|---|---|---|
| Edge deployment, mobile apps | 1.3B | Base | Minimal resource requirements |
| Interactive coding assistant | 6.7B | Instruct | Best balance of capability and efficiency |
| High-performance completion | 33B | Base | Maximum raw generation capability |
| Educational chatbot | 6.7B or 33B | Instruct | Optimized for explanatory responses |
| Research and fine-tuning | Any | Base | Foundation for custom training |
| Production API service | 5.7B MQA | Instruct | Optimized inference efficiency |

 
### Performance Characteristics

 Based on community feedback and leaderboard results, the `deepseek-coder-6.7B` models represent the optimal balance of performance and resource efficiency for most applications, as evidenced by their top performance on the Tabby leaderboard.

## Model Availability Status

 Not all model variants have the same availability status:

 
### Currently Available Models

 
 - **1.3B**: Both base and instruct variants fully available
 - **6.7B**: Both base and instruct variants fully available
 - **33B**: Both base and instruct variants fully available
 
 
### Pending Releases

 
 - **5.7B Instruct**: The `deepseek-coder-5.7bmqa-instruct` model is marked as "coming soon" in the documentation
 
 This staggered release pattern suggests that the 5.7B MQA architecture may represent a newer or experimental approach that is still undergoing instruct fine-tuning.
