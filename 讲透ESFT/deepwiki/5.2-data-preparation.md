### Dataset Requirements

 
 - **File Format**: Data must be stored in JSONL files (one JSON object per line)
 - **Object Structure**: Each JSON object must have a `messages` field containing an array of conversation turns
 - **Message Format**: Each message in the array must have: 
 - `role`: Either "user" or "assistant"
 - `content`: The text content of the message

## Conversion Process Details

 
### 1. Formatting Conversations

 The system formats each conversation using specific templates:

 
 - User messages: `User: {input}\n\n`
 - Assistant prompts: `Assistant:`
 - Assistant responses: `{input}` (note the leading space)
 
 This formatting is handled by the `get_formatted_question` and `get_formatted_answer` functions.

 
```

```

 Sources: [utils.py7-16](https://github.com/deepseek-ai/ESFT/blob/579a7711/utils.py#L7-L16) [utils.py17-44](https://github.com/deepseek-ai/ESFT/blob/579a7711/utils.py#L17-L44)

 
### 2. Tokenization and Target Creation

 The `get_formatted_input_and_target` function handles:

 
 - Converting messages to formatted text
 - Tokenizing the text using the model's tokenizer
 - Creating two parallel sequences: 
 - `input_ids`: All tokens that the model sees during inference
 - `target_ids`: Tokens used for loss calculation, with user prompts masked with `-100`
 
 This masking ensures the model is only trained to predict the assistant's responses, not to reproduce the user's prompts.

 
### 3. Sequence Handling and Padding

 The `get_examples_from_buffer_pad` function prepares the tokenized sequences for training:

 
 - Handles examples that exceed the maximum sequence length
 - Optionally concatenates examples (controlled by `random_concat_ratio`)
 - Pads shorter sequences to the required length
 - Converts the processed data into PyTorch tensors

## Dataset Creation and Splitting

 After processing, the system:

 
 - Creates a TensorDataset from input_ids and labels
 - Splits the dataset into training (98%) and validation (2%) sets
 - Uses the validation set to monitor training progress and prevent overfitting
