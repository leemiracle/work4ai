## Purpose and Scope

 This document describes the standard training pipeline in DeepSeek ESFT, which implements the core functionality for fine-tuning large language models using Expert Selection for Fine-Tuning (ESFT). The standard training pipeline processes a pre-trained model and applies expert selection based on a provided expert configuration to efficiently fine-tune the model on specific tasks.

 This page focuses on the non-parallelized training implementation. For the expert parallelism training approach, which distributes experts across multiple GPUs, see [Expert Parallelism Training](https://deepwiki.com/deepseek-ai/ESFT/3.2-expert-parallelism-training).

## Key Components

 
### Command-Line Interface

 The standard training pipeline accepts several command-line arguments:

 
| Argument | Description |
|---|---|
| --base_model_path | Path to the base model to fine-tune |
| --expert_config | Path to the expert configuration JSON file |
| --train_dataset | Name of the training dataset to use |
| --output_dir | Directory to save checkpoints and results |
| --train_config | Path to the training configuration YAML file |
| --wandb_api_key | (Optional) API key for Weights & Biases logging |

 Sources: [train.py19-28](https://github.com/deepseek-ai/ESFT/blob/579a7711/train.py#L19-L28) [scripts/train.sh7-12](https://github.com/deepseek-ai/ESFT/blob/579a7711/scripts/train.sh#L7-L12)

### Data Formatting

 The pipeline formats conversation data into input IDs and target IDs using the following process:

 
 - Load samples from a JSONL file
 - Process each instance to create input and target sequences
 - Add sequences to a buffer
 - Concatenate examples to the desired sequence length
 - Create a TensorDataset with input_ids and labels
 - Split into training and validation sets

## Running the Pipeline

 To run the standard training pipeline, use the `train.sh` script:

 
```
./scripts/train.sh
```

 Alternatively, you can run the `train.py` script directly with the required arguments:

 
```
python train.py \
    --base_model_path=<path_to_base_model> \
    --expert_config=<path_to_expert_config> \
    --train_dataset=<dataset_name> \
    --train_config=<path_to_train_config> \
    --output_dir=<output_directory>
```
