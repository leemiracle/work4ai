  This page documents all the command-line tools available in the DeepSeek ESFT system, their parameters, and example usage. These tools are designed to help users evaluate models, calculate expert scores, generate expert configurations, and train models with the ESFT approach. For information about data preparation for these tools, see [Data Preparation](https://deepwiki.com/deepseek-ai/ESFT/5.2-data-preparation).

## Evaluation Tools

 
### eval_multigpu.py

 This script evaluates the performance of the model on various datasets using multiple GPUs in parallel.

 
#### Parameters

 
| Parameter | Description | Default | Required |
|---|---|---|---|
| --eval_datasets | Comma-separated list of datasets to evaluate | None | Yes |
| --base_model_path | Path to the base model | None | Yes |
| --adapter_dir | Directory containing model adapters | None | No |
| --output_dir | Directory to save evaluation results | None | Yes |
| --max_new_tokens | Maximum number of new tokens to generate | 512 | No |
| --openai_api_key | OpenAI API key for evaluation | None | Yes |
| --eval_batch_size | Batch size for evaluation | 2 | No |
| --world_size | Number of processes for distributed evaluation | 4 | No |
| --gpus_per_rank | Number of GPUs per process | 2 | No |

## Expert Selection Tools

 
### get_expert_scores.py

 This script calculates scores for each expert in a mixture-of-experts model based on their contribution to the model's performance on specific tasks.

 
#### Parameters

 
| Parameter | Description | Default | Required |
|---|---|---|---|
| --eval_dataset | Dataset to evaluate | None | Yes |
| --base_model_path | Path to the base model | None | Yes |
| --output_dir | Directory to save expert scores | None | Yes |
| --n_sample_tokens | Number of tokens to sample for scoring | 131072 | No |
| --world_size | Number of processes for distributed scoring | 4 | No |
| --gpus_per_rank | Number of GPUs per process | 2 | No |

### generate_expert_config.py

 This script analyzes expert scores and generates a configuration file that determines which experts should be fine-tuned for specific tasks.

 
#### Parameters

 
| Parameter | Description | Default | Required |
|---|---|---|---|
| --eval_datasets | Comma-separated list of evaluation datasets | None | Yes |
| --expert_scores_dir | Directory containing expert scores | None | Yes |
| --output_dir | Directory to save generated configurations | None | Yes |
| --score_function | Scoring function to use (e.g., token) | token | No |
| --top_p | Proportion of top experts to select | 0.2 | No |
| --train_shared_experts | Flag to train shared experts | False | No |
| --train_non_expert_modules | Flag to train non-expert modules | False | No |

## Script Wrappers

 The ESFT system provides shell script wrappers for all main Python tools to simplify their usage.

 
| Script | Purpose | Related Python Tool |
|---|---|---|
| scripts/eval.sh | Evaluate model performance | eval_multigpu.py |
| scripts/eval_expert.sh | Calculate expert scores and generate configurations | get_expert_scores.py, generate_expert_config.py |
| scripts/train.sh | Train model with standard approach | train.py |
| scripts/train_ep.sh | Train model with expert parallelism | train_ep.py |
