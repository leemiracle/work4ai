## Purpose and Scope

 This document describes the Expert-Specialized Fine-Tuning (ESFT) Adaptation mechanism - a core component of the ESFT system that enables selective fine-tuning of large language models with Mixture-of-Experts (MoE) architecture. ESFT Adaptation is responsible for transforming a pre-trained MoE model into a partially trainable model where only task-relevant experts are fine-tuned while other parameters remain frozen.

 For information about the overall DeepseekV2 model architecture, see [DeepseekV2 Model](https://deepwiki.com/deepseek-ai/ESFT/4.1-deepseekv2-model). For details on the Mixture of Experts architecture, see [Mixture of Experts Architecture](https://deepwiki.com/deepseek-ai/ESFT/4.3-mixture-of-experts-architecture).

 
## Core Concept

 ESFT Adaptation is based on the insight that different downstream tasks require different types of expertise. Rather than fine-tuning an entire MoE model for a specific task (which is computationally expensive and can lead to catastrophic forgetting), ESFT selectively updates only the experts that are most relevant to the target task.

### Parameter Conversion Functions

 The core of ESFT Adaptation relies on two key functions:

 
 - `to_buffer()`: Converts module parameters to buffers, making them non-trainable during backpropagation
 - `to_param()`: Converts buffers back to parameters, making them trainable
 
 This parameter-buffer conversion mechanism allows for fine-grained control over which components of the model participate in gradient updates during training.

## Expert Selection Details

 The ESFT adaptation takes an expert configuration JSON that specifies which experts should be trainable for a given task. This configuration is typically generated by the Expert Evaluation System based on expert scoring (see [Expert Scoring](https://deepwiki.com/deepseek-ai/ESFT/2.1-expert-scoring) and [Expert Configuration Generation](https://deepwiki.com/deepseek-ai/ESFT/2.2-expert-configuration-generation)).

 
### Expert Configuration Format

 The expert configuration is a JSON object that specifies which experts should be trainable for each layer. Here's an example structure:

 
```
{
  "non_expert_modules": false,
  "shared_experts": false,
  "experts": {
    "0": [1, 3, 5],
    "1": [0, 2, 7],
    "2": [4, 6],
    ...
  }
}
```

 In this example, for layer 0, experts 1, 3, and 5 will be trainable, while all other experts will be frozen.

## Technical Implementation Details

 The ESFT adaptation mechanism makes extensive use of PyTorch's parameter management system. Here's a detailed look at the technical aspects:

 
### Parameter vs. Buffer in PyTorch

 In PyTorch, there are two types of tensors that can be associated with a module:

 
 - **Parameters**: Registered with `register_parameter()` or by assigning to `nn.Parameter`. These are tracked by optimizers and updated during backpropagation.
 - **Buffers**: Registered with `register_buffer()`. These are not tracked by optimizers and remain constant during training unless explicitly modified.
 
 ESFT leverages this distinction to control which parts of the model participate in training.

 
### Recursive Parameter Management

 ESFT uses recursive functions to traverse the module hierarchy:

 
 - `recursive_getattr()`: Retrieves nested module attributes using dot notation
 - `recursive_setattr()`: Sets nested module attributes using dot notation
 
 These utility functions enable precise targeting of specific components within the model's complex hierarchy.

## Practical Usage

 To use ESFT adaptation in practice:

 
 - Generate an expert configuration using the expert scoring system:

 
```
python scripts/expert/generate_expert_config.py --eval_datasets=task_name --expert_scores_dir=results/expert_scores --output_dir=results/expert_configs
```
 - Apply ESFT adaptation during training:

 
```
python train.py --base_model_path=model_path --expert_config=results/expert_configs/task_name.json --train_dataset=task_name
```
 
 The training process will then only update the task-relevant experts, providing efficient and effective fine-tuning.
