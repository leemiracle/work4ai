  This document explains the end-to-end workflow of the ESFT (Expert-Specialized Fine-Tuning) system. It covers how to progress from a base MoE model through evaluation, expert selection, and specialized training to produce a fine-tuned model with only task-relevant experts active. For details on the system architecture, see [System Architecture](https://deepwiki.com/deepseek-ai/ESFT/1.1-system-architecture), and for in-depth information about expert evaluation, see [Expert Evaluation System](https://deepwiki.com/deepseek-ai/ESFT/2-expert-evaluation-system).

 
## ESFT Workflow Overview

 The ESFT system follows a systematic workflow designed to identify and train only the most relevant experts for specific tasks within a Mixture-of-Experts (MoE) model architecture.

## 1. Model Evaluation

 The first step in the ESFT workflow is to evaluate the base model's performance on specific tasks or datasets.

 
### Purpose

 
 - Establish baseline performance
 - Generate data needed for expert scoring
 - Identify which tasks need improvement
 
 
### Implementation

 Model evaluation is implemented in `eval_multigpu.py`, which can be executed through `scripts/eval.sh`. This script evaluates the model's performance on various datasets, leveraging multi-GPU parallelism for efficiency.

## 2. Expert Scoring

 After evaluation, the system calculates relevance scores for each expert in the MoE model to determine which experts contribute most to a specific task.

 
### Purpose

 
 - Identify task-relevant experts
 - Quantify the contribution of each expert
 - Prepare data for expert configuration generation
 
 
### Implementation

 Expert scoring is implemented in `scripts/expert/get_expert_scores.py`. This script analyzes the model's behavior when processing task-specific data, calculating relevance scores for each expert.

## 3. Expert Configuration Generation

 Using the expert scores, the system generates a configuration file that specifies which experts should be fine-tuned and which should remain frozen.

 
### Purpose

 
 - Convert expert scores into actionable training configuration
 - Specify which experts to train for a given task
 - Optimize computational resources by focusing on relevant experts
 
 
### Implementation

 Expert configuration generation is implemented in `scripts/expert/generate_expert_config.py`. This script takes expert scores as input and produces a JSON configuration file that will guide the training process.

## 4. Specialized Training

 The final step is to train the model using the generated expert configuration, where only the specified experts are updated during fine-tuning.

 
### Purpose

 
 - Fine-tune only task-relevant experts
 - Maintain performance on unrelated tasks
 - Reduce computational requirements
 
 
### Implementation Options

 ESFT provides two training scripts:

 
 - `train.py` - Standard training for smaller models or single-GPU setups
 - `train_ep.py` - Expert parallelism training optimized for multi-GPU environments
