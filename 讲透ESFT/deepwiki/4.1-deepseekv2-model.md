## Overview

 This document provides a technical description of the DeepseekV2 model architecture implemented in the DeepSeek ESFT (Expert Selection for Fine-Tuning) codebase. It covers the model's structure, components, and implementation details. For information about adapting the model using ESFT techniques, see [ESFT Adaptation](https://deepwiki.com/deepseek-ai/ESFT/4.2-esft-adaptation).

 
## Model Architecture

 The DeepseekV2 model is a transformer-based language model that employs a decoder-only architecture with Mixture of Experts (MoE) capabilities. It is implemented as two main classes: `DeepseekV2Model` (the base model) and `DeepseekV2ForCausalLM` (the model with a language modeling head).

### Core Components

 The model consists of the following core components:

 
 - **Input Embeddings**: Converts token IDs into dense vector representations
 - **Decoder Layers**: Series of transformer decoder layers (typically 30-32)
 - **Normalization**: RMS normalization applied to the output of the last layer
 - **Language Modeling Head**: Linear projection to vocabulary size (in `DeepseekV2ForCausalLM`)

 - A self-attention mechanism

## Attention Mechanism

 The DeepseekV2 model implements two attention mechanisms:

 
 - `DeepseekV2Attention`: Standard attention implementation
 - `DeepseekV2FlashAttention2`: Optimized implementation using the Flash Attention algorithm

### Key Attention Features

 
 - **Dual Head Dimensions**: Uses different dimensions for attention heads (`qk_rope_head_dim`, `qk_nope_head_dim`, and `v_head_dim`)
 - **Hybrid Position Encoding**: Combines RoPE (Rotary Position Embedding) with non-positional embeddings
 - **Attention Scaling**: Special scaling techniques for longer context lengths
 
 
### Rotary Position Embeddings

 The model implements several variants of rotary positional embeddings:

 
 - `DeepseekV2RotaryEmbedding`: Basic rotary embeddings
 - `DeepseekV2LinearScalingRotaryEmbedding`: Linear scaling for longer contexts
 - `DeepseekV2DynamicNTKScalingRotaryEmbedding`: Dynamic NTK scaling for extrapolation
 - `DeepseekV2YarnRotaryEmbedding`: YaRN (Yet another RoPE extension) method

### Expert Gating

 The `MoEGate` class determines which experts to use for each token:

 
 - Computes a routing score for each expert
 - Selects the top-k experts for each token
 - Normalizes the weights assigned to selected experts
 - Computes an auxiliary load balancing loss during training

 - **Routed Experts**: Selected dynamically through the gating mechanism

## Integration with ESFT

 The DeepseekV2 model is designed to integrate with the ESFT (Expert Selection for Fine-Tuning) system. The model's MoE architecture allows selective training of specific experts while keeping others frozen, which is the core mechanism of ESFT. For details on how the model is adapted for ESFT, see [ESFT Adaptation](https://deepwiki.com/deepseek-ai/ESFT/4.2-esft-adaptation).
