# feynman-check · 费曼学习法质量门 + 陪练

> 把"费曼学习法"变成可执行的工作流：**对教学内容做"真懂 vs 自以为懂"的自检**，而不是"讲得通俗"。

## 何时触发

- 用户说「用费曼学习法改造/检查这篇文档」「这个讲得透不透」「我到底懂没懂」
- 用户写完一篇「讲透 X」要发布前
- 用户学完一个概念，想验证理解深度
- 用户说「F1/F2/F3/F4」「卡壳自检」「术语黑名单」「回炉」

## 核心理念（必须内化）

**费曼学习法 ≠ "讲得通俗"**。它是一个 4 步**闭环自检**：

| 步骤 | 动作 | 灵魂 |
|---|---|---|
| ① | 假装教给完全不懂的人 | 强制换语言 |
| ② | 用大白话讲，不许用术语 | 暴露理解深度 |
| ③ | **标出卡壳点 / 偷懒用术语处** | **这才是没真懂的地方** |
| ④ | 回炉重学，简化，循环 | 迭代 |

**关键洞察**：第 ③ 步是灵魂。大多数"讲得通俗"教程只做 ①②，跳过 ③④。feynman-check 强制做 ③④。

## 两套工具（按场景选）

### A. 质量门（面向作者，对文档做发布前自检）

跑 4 道检验 **F1-F4**，不改原文，新建 `X.费曼检验.md` 旁置文件。

| 检验 | 干什么 | 红灯标准 |
|---|---|---|
| **F1** 外行复述版 | 12 岁小孩版的核心讲解 + 3 个概念的大白话 + 类比 | 任一概念 3 行讲不明白 |
| **F2** 卡壳点清单 | 作者自曝写这篇时卡过壳、偷懒用术语的地方 | 挖不出至少 1 个卡壳点 |
| **F3** 术语黑名单 | 列所有术语，每个必须给外行翻译 | 任一术语给不出外行翻译 |
| **F4** 回炉记录 | v1 → 自检 gap → 重学 → v2 的迭代过程 | 首次写成无回炉且无 gap 标记 |

**发布门**：4 道全 🟢 才发布。任一 🔴 → 回炉。

### B. 陪练脚本（面向学习者，主动被戳穿）

```bash
python3 费曼学习法/feynman-coach.py "注意力机制" --rounds 3
```

AI 扮演 **3 个角色** 连环追问，每问完检测你的回答：
- 🧒 **12 岁小孩**："这个词什么意思？用学校里的例子讲"
- 📰 **调查记者**："怎么证明？有反例吗？数据来源？"
- 🏛️ **苏格拉底哲学家**："你说的 X 到底指什么？给工作定义"

**偷懒信号检测**（启发式）：
- `vague` 含糊带过：「本质上/其实就是/简单来说/换句话说」
- `evasion` 回避：「这取决于/学界尚无共识/这是个哲学问题」
- `term_density` 术语堆砌：每 100 字超过 5 个黑名单术语

报告输出 `feynman-report-<主题>-<时间>.md`，含每问的偷懒信号标注。

## 执行流程（用户触发后）

### 场景 1：用户给一篇文档要"费曼检验"
1. 读完整文档，提取核心论点 + 所有术语。
2. 照 费曼检验模板（待写/未落盘） 逐项填 F1-F4。
3. **F2 必须挖出至少 1 个真卡壳点**——挖不出本身就是 🔴（作者在自欺）。
4. **F3 红灯术语**就是用户下一步该学什么的清单。
5. 输出旁置 `.费曼检验.md` + 发布建议（🟢/🔴）。

### 场景 2：用户说"我懂 XX，你考考我"
1. 直接进入 feynman-coach 的角色循环（不需要脚本也能跑——AI 当场扮演三角色）。
2. 每轮检测偷懒信号，当场反馈。
3. 至少跑 9 问（3 角色 × 3 轮）。
4. 最后给卡壳报告 + F2/F3 建议登记项。

### 场景 3：用户说"用费曼法改造整个项目"
1. 先在一个真实样本上试点（参考 `示例-物理本质探索.费曼检验.md`（待写/未落盘））。
2. 让用户看到效果再决定铺开范围。
3. 不要贸然改大量文件——费曼检验是**追加质量门**，不是重写。

## 反模式（禁止）

- ❌ 把费曼法理解成"用大白话重写一遍"——丢失深度，错。
- ❌ F2 写"我觉得都懂"——这本身就是 🔴。
- ❌ 跳过 F4（回炉记录）——没回炉 = 要么真懂（罕见），要么跳过自检（大概率）。
- ❌ 把费曼检验当"第六层内容"——它是**对前五层的批判性自检**，不是新内容。
- ❌ 贸然对项目所有文件批量改造——先试点。

## 与项目其他 skill 的关系

- 与 `concept-3layer`（三层讲解）互补：三层管"讲深"，费曼管"真懂"。
- 与 `paper-mastery` 协作：论文精读后用 F2 自曝"哪些段落我其实没懂"。
- 与 `ml-experiment` 协作：实验做完用 F4 记录"这次哪里卡过壳"。
- 与 `karpathy-guidelines` 一致：都强调"surface assumptions, 不要自欺"。
