# 费曼学习法 · 项目质量门与陪练（A + C 方案）

> **费曼学习法 ≠ "讲得通俗"**——它是 4 步闭环自检：假装教外行 → 用大白话 → **戳卡壳点** → 回炉。
>
> 本目录给 `work4ai` 项目加两件东西：
> - **A · 质量门**：任何「讲透 X」文档发布前，跑 4 道费曼检验（F1-F4），戳穿"自以为懂"。
> - **C · 陪练**：AI 扮演 12 岁小孩/记者/哲学家连环追问你，自动检测偷懒信号。

---

## 为什么需要它

`work4ai` 项目已有成熟的「直觉 → 数学 → 代码 → 不足 → 本质」五层范式（管"**深度**"）。但它缺一个东西：**对"真懂 vs 自以为懂"的检验**。

费曼学习法补的就是这个缺口。它不替代五层范式，而是**追加在五层之后的批判性自检**：

```
原：直觉 → 数学 → 代码 → 不足 → 本质
                                    ↓
新：直觉 → 数学 → 代码 → 不足 → 本质 → 【费曼检验 F1-F4】→ 可发布
                                              ↑
                                    质量门：戳穿"自以为懂"
```

**一句话**：五层范式管你写得**深不深**，费曼检验管你写得**真不真懂**——后者更稀缺。

## A 方案 · 怎么用（30 秒上手）

任何「讲透 X」文档发布前：

```bash
# 1. 复制模板
cp 费曼学习法/费曼检验模板.md  讲透XXX/X.费曼检验.md

# 2. 逐项填 F1-F4（边填边自检）
#    F1 外行复述：能 3 句大白话讲核心吗？
#    F2 卡壳自曝：写这篇时我卡在哪？（必须挖 ≥1 个，挖不出 = 🔴）
#    F3 术语黑名单：每个术语能给 12 岁讲懂吗？
#    F4 回炉记录：v1 → gap → 重学 → v2

# 3. 自检 5 问全 🟢 → 发布；任一 🔴 → 回炉
```

**铁律**：
- 不改原文，新建 `.费曼检验.md` 旁置文件。
- F2 挖不出卡壳点本身就是 🔴（你在自欺）。
- F3 红灯术语 = 你下一步该学什么的清单。

## C 方案 · 怎么用（陪练脚本）

```bash
cd 费曼学习法

# 演示模式（无需 API key，立刻能跑）
python3 feynman-coach.py "注意力机制" --rounds 3

# 基于项目某个文档
python3 feynman-coach.py --file ../讲透AIfor各学科/物理/本质探索.md

# 接真 LLM（OpenAI/智谱/豆包/DeepSeek 任一兼容 endpoint）
export OPENAI_API_KEY=sk-xxx
export OPENAI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
export OPENAI_MODEL=glm-4-flash
python3 feynman-coach.py "波函数"
```

**输出**：`feynman-report-<主题>-<时间>.md`，含每问的偷懒信号标注 + 诊断建议。

**偷懒检测三类**：
- `vague` 含糊带过：「本质上 / 其实就是 / 简单来说 / 换句话说」
- `evasion` 回避：「这取决于 / 学界尚无共识 / 这是个哲学问题」
- `term_density` 术语堆砌：每 100 字超过 5 个黑名单术语

## 试点结论（已验证）

在 [`讲透AIfor各学科/物理/本质探索.md`](../讲透AIfor各学科/物理/本质探索.md) 上跑了一遍完整 F1-F4，结果：

| 检验 | 结果 | 说明 |
|---|---|---|
| F1 外行复述 | 🟢 | 核心能讲 |
| F2 卡壳自曝 | 🟢 | **挖出 5 处真没懂的** |
| F3 术语黑名单 | 🔴 | 波函数/哥本哈根给不出外行翻译 |
| F4 回炉记录 | 🟢 | 一次回炉，把"AI 制造新危机"修正为"老账被翻出来" |
| **总结** | **🔴 阻断发布** | 必须先处理波函数段 |

**关键发现**：原文思想深度 ★★★★★，但"真懂度" ★★★☆☆——**这是两个独立维度**，费曼检验专门测后者。

## 常见误用（避免）

| 误用 | 正确 |
|---|---|
| 把费曼法当"用大白话重写一遍" | 它是**自检**，不是重写。原文不动，旁置 `.费曼检验.md` |
| F2 写"我觉得都懂" | 挖不出 ≥1 个卡壳点本身就是 🔴 |
| 跳过 F4（回炉记录）| 没回炉 = 要么真懂（罕见）要么跳过自检（大概率）|
| 批量改项目所有文件 | 先试点一个，看到效果再决定铺开 |
| 把它当"第六层内容" | 它是**对前五层的批判性自检**，不是新内容 |
