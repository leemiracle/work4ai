# 费曼检验模板（项目级质量门 v1.0）

> **费曼学习法 ≠ "讲得通俗"。** 它是一个 4 步**闭环自检**：假装教外行 → 用大白话 → 戳卡壳点 → 回炉重学。
>
> 本模板用于：任何「讲透 X」文档**发布前**，跑一遍这 4 道检验。**不改原文**，新建 `X.费曼检验.md` 旁置文件。
>
> **铁律**：4 道全过 = 可发布；任一标红（🔴）= 必须回炉。

---

## 0. 为什么需要它（与项目现有范式的差异）

| 项目现有「五层范式」 | 缺什么 | 费曼检验补的缺口 |
|---|---|---|
| 直觉 → 数学 → 代码 → 不足 → 本质 | "直觉层"是作者**自以为**的直觉 | F1 强制"**外行**能复述"检验 |
| 每篇有「局限/争议」 | 写的是**已知**局限 | F2 逼作者暴露**自己**没真懂的点 |
| 大量术语 + 公式 | 术语可能掩盖理解空洞 | F3 术语黑名单——每个术语必须能讲给外行 |
| 文档是"成品输出" | 不记录"卡过哪、怎么想通" | F4 回炉记录——让产出 = 学习过程 |

**一句话**：五层范式管"**深度**"，费曼检验管"**真懂 vs 自以为懂**"。

## 使用流程（3 步）

```
① 复制本模板 → 改名 <原文件名>.费曼检验.md，与原文同目录
② 逐项填 F1-F4（边填边标 🔴/🟢）
③ 自检 checklist 5 问全 🟢 → 可发布；任一 🔴 → 回炉，改完重填 F4
```

## F1 · 外行复述版（12 岁小孩版）🟢/🔴

**规则**：
- 不许用任何专业术语（包括"模型/训练/参数/梯度/涌现/认识论/表征"等）。
- 每个核心概念**一句话**讲清楚，配一个**生活类比**。
- 超过 3 行讲不明白 = 🔴（你没真懂）。

### 模板

```markdown
### F1 外行复述

**这篇文档的核心一句话**：<不用任何术语，1 句话>

**3 个核心概念的大白话**：
| 原术语 | 大白话 | 生活类比 |
|---|---|---|
| XXX | "就像…" | 例：菜谱/电话簿/乐高 |
| YYY | "…" | … |
| ZZZ | "…" | … |

**如果讲给 12 岁表弟听，他会卡在哪一问？**
- 卡点 1：…
- 卡点 2：…

**结果**：🟢 全部能讲 / 🔴 卡在 ___
```

---

## F2 · 卡壳点清单（作者自曝）🟢/🔴

**规则**：
- 列出**写这篇时**自己卡过壳、绕过弯、偷懒用术语糊弄的地方。
- 这些就是你**没真懂**的地方——费曼法的灵魂就在这里。
- **禁止**写"我觉得都懂"——至少挖出 1 个卡壳点，挖不出本身就是 🔴（你在自欺）。

### 模板

```markdown
### F2 卡壳点清单

| # | 哪一段/哪个论断 | 我卡在哪 | 当时怎么绕过的 | 真懂了吗 |
|---|---|---|---|---|
| 1 | "AI 是第三种方法" | "第三种"和"工具"的区别我没讲清 | 用"认识论改变"一词糊弄 | 🔴 没懂 |
| 2 | "预测对了 ≠ 理解了" | "理解"的标准我没定义 | 直接甩结论 | 🟡 半懂 |
| 3 | … | … | … | … |

**最难回答的 1 个追问**（如果被外行问，我会哑口无言）：
> <问题>

**结果**：🟢 所有卡点已标出且有补救 / 🔴 还有 ___ 处绕过
```

---

## F3 · 术语黑名单 🟢/🔴

**规则**：
- 列出本文所有专业术语。
- 每个术语必须给"**外行翻译**"。
- 给不出外行翻译 = 🔴（这个术语在掩盖你的理解空洞）。

### 模板

```markdown
### F3 术语黑名单

| 术语 | 外行翻译 | 在原文哪用 | 能给 12 岁讲吗 |
|---|---|---|---|
| 认识论危机 | "搞不清自己是'懂了'还是'只是会算'" | §3.3 | 🟢 |
| emergent law | "一堆东西凑一起会出现单个没有的性质（像水湿但水分子不湿）" | §1.3 | 🟢 |
| 波函数 | "…" | §2.1 | 🔴 给不出 |
| … | … | … | … |

**🚨 红灯术语**（给不出外行翻译的，必须回炉或删除）：
- <术语>：<为什么给不出>

**结果**：🟢 全部有外行翻译 / 🔴 ___ 个术语在掩盖空洞
```

---

## F4 · 回炉记录 🟢/🔴

**规则**：
- 记录本文的**迭代过程**：v1 → 自检发现 gap → 重学 → v2。
- 没回炉过 = 🟡（要么你真懂，要么你跳过了自检——后者概率更大）。

### 模板

```markdown
### F4 回炉记录

**v1（初稿）**：<日期>，卡壳点 ____ 个
**自检发现的最大 gap**：<我以我懂其实不懂的事>
**重学动作**：<读了什么/问了谁/跑了什么代码>
**v2（当前）**：<日期>，原卡壳点解决情况：____

**仍未解决**（诚实标记，可进 advanced/）：
- <问题>

**结果**：🟢 至少回炉 1 次且记录可追溯 / 🟡 首次写成无回炉 / 🔴 跳过自检
```

## 发布前自检 Checklist（5 问，全 🟢 才发布）

- [ ] **Q1**：我能用 3 句大白话讲清这篇的核心吗？（不出现任何术语）
- [ ] **Q2**：我列出了至少 1 个自己卡过壳的点吗？（不是 0 个）
- [ ] **Q3**：每个术语都有外行翻译吗？（包括"涌现""认识论""表征"这种高级词）
- [ ] **Q4**：我能举出一个**反例**或**让本文论断失效的场景**吗？
- [ ] **Q5**：如果被一个 12 岁小孩连环追问 5 个"为什么"，我会哑口无言吗？哑在哪？

> **Q5 是终极检验**：如果你能预测到自己会卡在哪，那才是真懂。

## 与五层范式的关系（不替代，而是追加）

```
原：直觉 → 数学 → 代码 → 不足 → 本质
                                    ↓
新：直觉 → 数学 → 代码 → 不足 → 本质 → 【费曼检验 F1-F4】→ 可发布
                                              ↑
                                    质量门：戳穿"自以为懂"
```

**费曼检验是五层范式的"最终验收"**，不是第六层内容，而是**对前五层的批判性自检**。
