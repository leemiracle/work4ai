# 多元视角审视（Multi-Lens Review）

> **费曼法只有一个视角：外行能懂吗？** 但"真懂"是多维的——一篇文档可能外行能懂但**论证不完整**，或论证完整但**停在低认知层**，或认知层高但**缺反馈环视角**。
>
> 本目录补充 **6 个互补视角**，加上已有费曼 = **7 视角审视体系**。每个视角都用**可执行启发式**而非空喊术语。

---

## 为什么是 6 个而不是 20+

我调研了 20+ 个学习方法/认知理论/批判框架（SQ3R / Cornell / Zettelkasten / Spaced Repetition / 双编码 / 建构主义 / 最近发展区 / 认知负荷 / 苏格拉底法 / 思维导图 / MECE / SCQA / 六顶思考帽 / 5 Whys / Paul-Elder / 信息论 / 贝叶斯 / 几何 / 优化 / 历史演化 / 学科视角 ...），精选的依据是：

1. **可启发式**——能自动检测文档特征，不只是空问题
2. **互补不重叠**——每个视角测独立维度
3. **AI/技术内容相关**——不是通用学习方法

淘汰的理由：
- SQ3R/Cornell/Zettelkasten：是**阅读笔记法**，不是文档质量评价
- Spaced Repetition/双编码：是**记忆强化**，不是内容质量
- 六顶思考帽/SCMEA：和图尔敏/红队重叠
- 信息论/贝叶斯/几何：**学科特定**，不该强加给所有文档
- 历史演化：合入"第一性原理"的子项（追溯假设来源）

## 各视角的核心问题（作者必答）

### 1. 第一性原理（First Principles）
- 这篇的**最底层假设**是什么？能再往下一层吗？
- 从底层假设到结论的**推导链**有几环？哪一环最弱？
- 如果底层假设不成立，结论还成立吗？

### 2. 布鲁姆 6 层（Bloom's Taxonomy）
- 记忆 / 理解 / 应用 / 分析 / 评价 / 创造——这篇主要在哪层？
- 是不是**停在低层**（描述现象）而没到**评价/创造**（提出新框架）？
- 如果是教程，作者有没有引导读者到更高层？

### 3. 图尔敏论证（Toulmin Model）
- **主张（Claim）**：核心论断明确吗？
- **数据（Data）**：有具体证据/数字/实验吗？
- **保证（Warrant）**：数据到主张的桥梁规则是什么？
- **支撑（Backing）**：桥梁规则的一般性 backing？
- **限定（Qualifier）**：主张的适用边界？
- **反驳（Rebuttal）**：考虑了反例吗？

### 4. 红队（Red Team）
- 如果我是攻击者，**最想攻哪个论断**？
- 作者用了多少**绝对化语言**（"必然/永远/不可能"）？
- 作者**主动提了反例**吗？还是只摆正面证据？

### 5. 系统论（Systems Thinking）
- 这里有没有**反馈环**（正/负）？
- 是不是**涌现**（整体行为不能从部分推出）？
- 作者指出了**杠杆点**（最有效的干预位置）吗？

### 6. 跨学科类比（Cross-Disciplinary Analogy）
- 作者用了什么**类比**（X 像 Y）？
- 类比对象 Y 在**原领域**有严格定义吗？还是模糊修辞？
- 类比的**失效边界**在哪？（X 和 Y 在哪一点上不再相似？）

## 怎么用

```bash
# 单篇跑（推荐先试一篇）
python3 费曼学习法/multi-lens-batch.py --only "讲透基础模型" --dry-run

# 全 312 强制/推荐文档
python3 费曼学习法/multi-lens-batch.py

# 指定视角
python3 费曼学习法/multi-lens-batch.py --lens first_principles,red_team
```

产出：`<原名>.多视角.md`，含 6 个视角的启发式扫描结果 + 作者必答问题。

**与费曼检验的关系**：
- `<原名>.费曼检验.md`：费曼视角（F1-F4 深度自检）
- `<原名>.多视角.md`：另外 6 个视角（横向广度）
- 两者互补，不重复。

## 已知限制

1. **启发式只能抓表面特征**：能数"假设"出现的次数，但不能判断假设是否合理。每条标 🤖，作者须复核。
2. **学科特定视角（信息论/贝叶斯/几何）未纳入**：避免对纯人文文档强加数学视角。如需，作者可单独跑。
3. **6 视角 ≠ 完备**：还有**伦理视角 / 美学视角 / 历史演化视角**等没纳入。本体系是**实用子集**，不是终极框架。
