# 🎓 教学法 (Methods) · 总览

> "学怎么发生的"由学习理论回答（见 [`../LEARNING_THEORIES/`]）；**"怎么把课堂/产品组织起来让学习发生"由教学法回答**。教学法 = 学习理论的**工程化**。
>
> 本目录覆盖 4 大教学法族。每个都给：**核心机制 + 何时有效 + 何时翻车 + 证据**。

---

## 教学法的根本张力

所有教学法都在同一个张力上摆动：

$$\text{直接指导} \quad \longleftrightarrow \quad \text{自主建构}$$

- **左端**（直接教学/讲授）：高效、保证覆盖、新手友好；风险=被动、不迁移。
- **右端**（发现/PBL/探究）：主动、迁移好、动机高；风险=低效、新手易迷路、依赖支架。

> 🪶 这正是 [`../EDUCATION_FEYNMAN_NARRATIVE.md`] 第六幕的"杜威钟摆"。没有"最佳教学法"，只有**与学习者水平/目标匹配**的方法。

**Kirschner/Sweler/Clark (2006)** 的元证据：**对新手，直接教学 + worked examples 显著优于纯发现**。但对熟手，发现/PBL 才有效。**关键变量是学习者已有图式**。

## 四大教学法族

### 1. 直接教学 (Direct Instruction) —— [`01_direct_instruction.md`]
- **机制**：教师明确讲解 + 引导练习 + 即时反馈。
- **旗手**：Engelmann（Distar 项目）、Rosenshine（教学原则）。
- **证据**：Project Follow Through 大规模实验，直接教学组**显著胜出**。Hattie d≈0.6。
- **何时用**：新手、结构化知识（数学/语法）、技能奠基。
- **何时翻车**：高阶能力（批判思维/创造）、动机已高的熟手。

### 2. 发现学习 / PBL —— [`02_discovery_pbl.md`]
- **机制**：学生在真实问题中自主探究，教师做支架。
- **旗手**：布鲁纳（发现学习）、Buck Institute（PBL）、Papert（建构主义 constructionism）。
- **证据**：对**熟手**有效；对**新手纯发现**有害（Kirschner 2006）。增强版"引导式发现" (guided discovery) 折中。
- **何时用**：已有基础 + 复杂问题 + 高动机。
- **何时翻车**：新手无支架、时间紧、目标不明。

### 3. 掌握学习 + 翻转课堂 —— [`03_mastery_flipped.md`]
- **机制**：**掌握学习**（Bloom）= 不达标不前进，每个人走完所有步；**翻转课堂** = 课下看讲解、课上做练习讨论。
- **证据**：掌握学习是 Bloom 2σ 的两个组件之一。翻转课堂 d≈0.3–0.5（取决于执行）。
- **何时用**：内容可分阶、有自学资源（视频/AI）、课堂用于高阶互动。
- **何时翻车**：学生不预学（翻转的前提崩塌）、无即时反馈机制。

### 4. 苏格拉底法 / 案例法 —— [`04_socratic_case.md`]
- **机制**：通过**提问**引导学生自己发现，或用真实**案例**讨论。
- **旗手**：苏格拉底（产婆术）、哈佛法学院案例法、Harkness 讨论。
- **证据**：高阶思维有效（d≈0.4–0.6），但极依赖教师提问质量。
- **何时用**：法学/伦理/文学/科研等无标准答案的领域。
- **何时翻车**：有标准答案的事实知识（直接讲更快）、教师提问能力弱。

## 教学法选择决策树

```
学习者水平？
├─ 新手（图式少）→ 直接教学 + worked examples  [01]
│                    + 即时反馈（行为主义）
│
├─ 中级 → 引导式发现 / 翻转课堂  [03]
│           + 支架（建构主义）
│
└─ 熟手 → PBL / 苏格拉底 / 案例  [02, 04]
           + 自主（人本主义）

目标类型？
├─ 技能/事实 → 直接教学 + 间隔练习
├─ 概念理解 → worked example + 概念图（认知主义）
├─ 高阶思维 → PBL / 苏格拉底（建构主义）
└─ 态度/价值 → 案例 + 讨论人本主义）
```

## 教学法的 Hattie 效应量对照（速查）

| 干预 | d | 归属教学法 |
|---|---|---|
| 直接教学（高质量）| 0.6 | [01] |
| 反馈（形成性）| 0.7 | 所有 |
| 掌握学习 | 0.6+ | [03] |
| 苏格拉底式 meta-cognition | 0.6 | [04] |
| 纯发现学习（无支架）| <0.4 ❌ | [02] 警告 |
| 问题解决（对新手）| <0.4 ❌ | [02] 警告 |
| 微型 lecturing + 互动 | 0.5+ | 混合 |

## 与本项目锚点

- **RL 视角**：直接教学 = dense reward shaping（小步子高反馈）；发现学习 = sparse reward + exploration；翻转 = off-policy（课下）+ on-policy（课上）；苏格拉底 = 暗示性 reward（引导学生自己 reward 自己）。
- **ZPD（维果茨基）**：所有教学法的有效性都取决于**是否把学习者留在 ZPD**。直接教学对新手友好是因为它把任务切到 ZPD 下沿；PBL 对熟手有效是因为它在 ZPD 上沿挑战。
- **熵治理**：好教学法 = 高效熵减；坏教学法 = 廉价熵减（刷题）或无熵减（纯发现空转）。
- **费曼 F2**：所有教学法最终都被 F2"能否复述/迁移"检验。
