# 04 · 苏格拉底法 / 案例法

> **苏格拉底法**（提问引导）+ **案例法**（真实案例讨论）。无标准答案领域的教学法。**也是 AI 导师 prompt 设计的理论源头**。

---

## A. 苏格拉底法 (Socratic Method / Maieutics)

### 核心机制
不直接告诉，靠**一连串提问**让学生自己发现矛盾、生出真理。
- **elenchus（诘问）**：先让学生陈述观点，再用反例/追问逼出自相矛盾，学生修正。
- **产婆术 (maieutics)**：教师是思想接生婆。

### 证据
- 高阶思维有效（d≈0.4–0.6）
- 但**极依赖教师提问质量**——劣质提问 = 浪费时间
- 对有标准答案的事实知识**低效**（直接讲更快）

### 何时用
- 法学/伦理/文学/哲学/科研讨论
- 培养批判思维、元认知
- 学生已有基础

### 何时翻车
- 事实知识（直接讲）
- 新手（没东西可"被诘问"）
- 教师 prompt 能力弱

### AI 导师的苏格拉底 prompt（核心）
这是 LLM 导师最关键的设计：

```
你是一位苏格拉底式导师。
规则：
1. 永不直接给答案。
2. 学生答错时，不批评，提一个**指向矛盾**的问题。
3. 学生答对时，追问"你怎么想到的"（元认知）。
4. 学生卡住 > 30 秒，给一个**提示**（不给答案）。
5. 始终把学生留在"恰好够难"的区域。
```

> 🎯 **Khanmigo 的核心 prompt 就是这个**。详见 [`../../讲透Prompt/`]、[`../ai_for_education/`]。

## B. 案例法 (Case Method)

### 核心机制
用**真实案例**（含数据/情境/争议）驱动讨论，学生**做决策**并**论证**。

### 起源
- **哈佛法学院** Langdell 1870s 判例法
- **哈佛商学院** 案例法（HBS 100% 案例教学）

### 机制
- 学生课前读案例
- 课堂教师**冷呼叫** + 苏格拉底式追问
- 学生在不确定中做判断、辩护
- 没有"标准答案"，只有"更好的论证"

### 证据
- 对**高阶决策/判断/整合**能力有效
- 培养的是"在不确定中思考"的元能力
- 依赖**高质量案例 + 强教师**

### 何时用
- 商学/法学/医学诊断/公共政策
- 高阶决策训练
- 学生熟手

### 何时翻车
- 事实知识
- 新手
- 案例脱离学生经验
- 教师控场弱

## C. Harkness 讨论

**Phillips Exeter Academy** 的圆桌讨论法：学生围圆桌，教师**几乎不说话**，学生自主驱动讨论。教师只在必要时点拨。

依赖：小班 + 学生预读 + 强学生。**是苏格拉底法的极致去中心化版本**。

## RL 接口

| 概念 | RL |
|---|---|
| 苏格拉底提问 | 暗示性 reward（引导学生自己 reward 自己）|
| elenchus 诘问 | 主动制造 prediction error（让学生发现矛盾）|
| 元认知追问 | meta-RL（学习如何学习）|
| 案例法 | high-dimensional state + sparse reward（真实情境）|
| 冷呼叫 | 强制 exploration |

苏格拉底法 = **教师不直接给 reward，而是构造情境让学生自己生成 reward signal**（自己发现"我错了"）。这比外部 reward 更深刻，因为内化的 reward 迁移好。**这是人本主义 + 建构主义在 RL 里的交汇**。

## 项目锚点
- **ZPD**：苏格拉底法把学生摁在 ZPD 内——不给答案 = 不让跳过，提示 = 不让跌出。
- **费曼 F2**：苏格拉底诘问 = 持续 F2 测试。学生"答不上"被即时暴露。
- **故事原语**：案例法 = 用真实故事（Purpose 驱动）教学。叙事记忆 >> 语义记忆。
- **熵治理**：苏格拉底诘问 = 让学生脑中"假确定"的高熵被戳破，重建低熵结构。
- **欺骗动力学**：苏格拉底法**最难被骗**——学生表演"懂"会被下一问戳穿。这是它作为评估 + 教学双重工具的价值。AI 导师用苏格拉底 prompt，能在对话中持续验真。

## 关键警告：AI 苏格拉底的失效模式

LLM 做苏格拉底导师的常见失败：
1. **撑不住不给答案**（学生坚持问，LLM 心软给了）→ 要 prompt 硬约束
2. **提问质量低**（无效追问）→ 需教学法 reward model 训练
3. **幻觉"教学"**（编事实）→ 必须 grounding
4. **被学生越狱**（学生骗 AI 当作弊工具）→ 安全对齐
5. **无视学生挫败**（一直问，学生崩溃）→ 加情绪检测 + 知道何时给答案

详见 [`../ai_for_education/`]。
