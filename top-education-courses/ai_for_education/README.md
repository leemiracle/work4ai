## 二、AI for Education 的五大技术族

### 1. 智能辅导系统 ITS（Intelligent Tutoring Systems）
- **历史**：SCHOLAR (1970) → ACT-R / Cognitive Tutor (Anderson) → ASSISTments / ALEKS。
- **原理**：领域知识模型 + 学生模型 + 教学模型。追踪学生掌握状态，按 ZPD 给题。
- **效应量**：VanLehn (2011) 元分析：ITS ≈ 0.76（接近真人导师的 ~0.8）。
- **局限**：领域建模昂贵（一门课要专家手工建模数年）、NLP 弱、难迁移。
- **LLM 的影响**：LLM 可能解决"领域建模昂贵"+"自然语言交互"两大瓶颈。

### 2. 自适应学习算法（知识追踪）
- **贝叶斯知识追踪 BKT**（Corbett & Anderson 1995）：用隐马尔可夫模型追踪每个技能的掌握概率。
- **深度知识追踪 DKT**（Piech et al. 2015）：用 RNN 学学生状态。**第一次把深度学习引入学生建模**。
- **Transformer 知识追踪**：最新用 Transformer 建长程序列 **【待联网核实】**。
- **局限**：数据饥渴、冷启动、可解释性差、技能定义模糊。
- **数学骨架**：见 [`../ASSESSMENT/03_psychometrics.md`]（IRT 是 BKT 的近亲）。

### 3. LLM 导师（2023–）⭐⭐⭐
- **代表**：Khanmigo / ChatGPT Edu / Duolingo Max / 国内各类。
- **核心设计原则**（来自学习理论）：
  | 原则 | 理论来源 | prompt 设计 |
  |---|---|---|
  | **不给答案，给提示** | 建构主义 ZPD | 苏格拉底 prompt |
  | **即时反馈** | 行为主义 + 测试效应 | 答完即评 |
  | **耐心共情** | 人本主义罗杰斯三条件 | 永不批评语气 |
  | **适配难度** | ZPD + 心流 | 据学生状态调题 |
  | **表扬努力非聪明** | 成长型思维 Dweck | "你刚才的尝试很棒" |
  | **元认知提问** | 元认知策略 | "你怎么想到的？" |
  | **教判断信息** | 联结主义 | "我们怎么验证这个？" |
- **关键 prompt 范式**：见 [`../../讲透Prompt/`]。

### 4. 自动批改（Automated Assessment）
- **作文评分 AES**：从 e-rater (1997) 到 GPT-4。GRE/TOEFL 早用。
- **代码评分**：单元测试 + LLM 语义评分（[`../../讲透代码生成/`]）。
- **数学题评分**：不只判对错，判**步骤**（GSM8K benchmark）。
- **风险**：幻觉、偏见、学生申诉难。

### 5. 教育数据挖掘 EDM + 学习分析 LAK
- 从日志数据**预测**：谁会辍学、谁卡在哪、何时干预。
- 顶会：**EDM / LAK**。
- **伦理**：学生监控、算法偏见、隐私。

## 三、Bloom 2σ：AI 教育的圣杯

### 问题陈述（Bloom 1984）
- 一对一辅导 + 掌握学习 = 平均 +2σ（超 98% 学生）。
- 40 年无解——**导师太贵**。

### AI 解的可能（2023–）
- LLM 导师**可能**规模化"近似一对一"。
- 初步效应量 **【待联网核实】**：+0.3–0.8σ（远低于 2σ 理想，但已超普通课堂）。

### 还差什么？（用学习理论诊断）
| 差距 | 学习理论诊断 |
|---|---|
| 幻觉 | 学生无法识别错误反馈 → 信任崩塌 |
| 变懒 | AI 直接给答案 → 学生绕过 ZPD 挣扎 |
| 不会元认知 | AI 不教"怎么想"，只教"答案" → 元认知萎缩 |
| 缺社会性 | 纯人机缺同伴/师生关系（d≈0.72）|
| 不公平 | 富人用好模型 → 反而拉大差距 |

> 🎯 **AI 导师要逼近 2σ，必须**：(1) 严格 ZPD 不给答案；(2) 强制元认知提问；(3) 混入社会性（同伴/教师）；(4) 平等可及。

## 四、教育大模型的对齐与评估（与通用 LLM 的差异）

教育场景的对齐**比通用场景严苛**：

| 维度 | 通用 LLM | 教育 LLM |
|---|---|---|
| 幻觉容忍 | 低 | **极低**（错一次失信）|
| 价值对齐 | 一般 helpful/harmless | + **教学法对齐**（不给答案）|
| 评估 | benchmark | + 学生学习增益（因果）|
| 安全 | 拒绝有害内容 | + **适龄 + 防诱导（学生越狱）** |

### 教育对齐的方法
- **教学法 reward model**：不只 reward "答案对"，reward "苏格拉底式 + 学生学到了"。
- **过程 reward**：reward 中间步骤而非最终答案（PRM 思路，[`../../讲透RL/`]）。
- **学生模型协同训练**：模拟学生在 loop 里，RLHF 据学生进步给 reward。

### 教育评估的特殊性
- 不能只用"答对率"——要看**学习增益**（前测→后测因果）。
- 要测**高阶能力**（Bloom 分析/评价/创造），不能只测记忆。
- 要测**长期**（一周/一月后还记不记得），不只即时。
- 要防**数据污染**（学生用别的 AI 做作业）。

## 五、设计 AI 教育产品的检查清单

基于五范式 + ZPD + Hattie，给 AI 教育产品经理/工程师：

### ✅ 必须做
- [ ] **ZPD 设计**：实时定位学生水平，给恰好够难的提示（不给答案）
- [ ] **苏格拉底 prompt**：引导而非告知
- [ ] **即时形成性反馈**：每步都评，不只终评
- [ ] **元认知提问**：定期问"你怎么想的/为什么"
- [ ] **防过度依赖**：检测学生"只问答案不思考"，触发反问
- [ ] **幻觉缓解**：领域知识库 grounding、明确不确定时说"我不确定"
- [ ] **适龄/分级**：语言、难度按学生调整
- [ ] **保留挣扎**：让学生在卡点停留足够时间再给提示

### 🚫 必须避免
- [ ] 直接给答案（绕过 ZPD）
- [ ] 纯积分/徽章驱动（过度理由效应）
- [ ] 假装无所不知（幻觉）
- [ ] 只测记忆（绕过 Bloom 高层）
- [ ] 替代教师（缺社会性）

### ⚠️ 伦理
- [ ] 数据隐私（学生数据特别敏感）
- [ ] 算法偏见（性别/种族/语言）
- [ ] 公平可及（免费版要够好）
- [ ] 透明（学生/家长知道何时用 AI）

## 六、开放研究问题（PhD 级）

1. **LLM 能稳定逼近 Bloom 2σ 吗？** 什么条件下？
2. **学生长期用 LLM 导师，元认知会萎缩还是增强？**（关键 longitudinal 研究）
3. **教学法 reward model** 怎么训？标签怎么定？
4. **幻觉在教育里的容忍度**是 0 吗？如何量化？
5. **AI 导师 vs 真人导师的效应量差**，能否缩小到 d<0.2？
6. **LLM 时代的评估范式**——怎么测"真懂"在代写普遍的世界？
7. **教育 LLM 的对齐失败模式**——学生越狱让 AI 当作弊工具，怎么防？
8. **文化/语言迁移**——英美训的导师能用在中国/非洲吗？
