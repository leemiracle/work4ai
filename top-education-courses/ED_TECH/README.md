# 💻 教育技术史 (EdTech History) · 百年回环

> 从斯金纳教学机器 (1958) 到 Khanmigo (2023)。教育技术不是新事物——**100 年来，每代人都宣称"机器将革命教育"，每代人都部分失望**。本 README 是这份反复的历史，**用来防止 LLM 时代重蹈覆辙**。
>
> 强烈推荐配套读 **Audrey Watters《Teaching Machines》(2021)**——教育技术批判史，**【待联网核实】**。

---

## 一、百年时间线

### 1920s · 教学机器的先驱
- **Sidney Pressey**（俄亥俄州立）：1924 制造"教学机器"——选择题自动计分。宣称"解放教师"。**商业失败**。

### 1958 · 斯金纳的教学机器 ⭐
- **B.F. Skinner** 发表 "Teaching Machines"（*Science*）。
- 原理：小步子 + 即时反馈 + 答对才进下一题 = **操作性条件反射的机械化**。
- **这是所有自适应学习 + RLHF 的祖宗**。
- 影响有限：硬件贵、内容制作成本高、教师抵触。

### 1960s · PLATO 系统
- **PLATO**（Illinois 大学）：计算机辅助教学 CAI 鼠祖。终端教学、论坛、游戏。
- 影响深远但昂贵，未普及。

### 1970s · ITS 智能辅导系统崛起
- **SCHOLAR**（Carbonell 1970）：第一个基于知识的对话辅导系统。
- **ACT-R / Cognitive Tutor**（Anderson）：基于认知模型的自适应。
- **West (1975) "General Diagnostic Tests"**
- ITS 持续到今天：**ASSISTments / Cognitive Tutor / ALEKS / Knewton**。

### 1980s · CAI 普及 + LOGO
- **Papert LOGO**：孩子用编程学数学（建构主义 constructionism）。
- 个人电脑进校，但效果被高估（Larry Cuban《Oversold and Underused》）。**【待联网核实】**

### 1990s · 多媒体 + 网络课程
- **Mayer 多媒体学习**理论成熟。
- 早期在线课程、WebCT/Blackboard。

### 2000s · 学习对象 + LMS + 早期开放课
- **MIT OCW** (2001)：开放课件运动起点。
- LMS（Moodle/Canvas）普及。

### 2012 · "MOOC 之年" ⭐
- Coursera / edX / Udacity。
- **宣称革命**：免费、大规模、全球。
- **现实**：完成率 < 10%，缺支架（维果茨基是对的）、缺社会性、缺反馈。**MOOC 主要服务已有学历者**，扩大不平等而非缩小。

### 2013–2020 · 自适应 + 数据
- **Khan Academy** 规模化（视频 + 练习 + 自适应）。
- **ALEKS / Knewton**：IRT-based 自适应。
- **学习分析 LAK / EDM** 会议兴起。
- **Piech et al. 2015 深度知识追踪 DKT**——把深度学习引入学生建模。

### 2020 · 疫情强制在线
- 全球学校停课 → 在线教育被迫普及。
- 暴露数字鸿沟、效果下降（特别是低龄）。

### 2022– · 生成式 AI ⭐⭐⭐
- **ChatGPT** (2022.11) → 教育震动。
- **Khanmigo** (2023.3)：GPT-4 导师。
- **Duolingo Max**、**ChatGPT Edu** (2024)。
- 作业代写危机、检测失败、学校政策转向。
- **这是教育技术 100 年来最大的变量**。

## 二、百年回环：反复的承诺与失望

```
1924 Pressey 教学机器   → 商业失败
1958 Skinner 教学机器   → 未普及
1960s PLATO            → 太贵
1980s PC 进校          → "Oversold and Underused"
2012 MOOC              → 完成率 <10%
2020 在线教育          → 效果下降
2023 LLM 导师          → ？
```

> 🪶 **Larry Cuban 的规律**：每代技术都宣称革命，**教室核心结构（教师 + 班级 + 讲授）从未被颠覆**。技术多在**边缘**（家庭作业、补充练习）渗透。

**为什么反复失望？** 四个原因：
1. **学习是社会性的**（维果茨基）——机器缺关系。
2. **学习需要支架**（ZPD）——纯技术难实时定位。
3. **教师角色复杂**——不只是讲，是动员、关怀、纪律、榜样。
4. **教育系统惯性**——评估/制度/师资培训跟不上技术。

## 三、LLM 时代有何不同？（这次真的可能不同）

| 旧技术 | LLM 导师 |
|---|---|
| 预设脚本、有限分支 | 自然语言对话、无限分支 |
| 内容固定 | 实时生成个性化 |
| 单向呈现 | 双向苏格拉底 |
| 难做高阶（作文/讨论）| 擅长高阶（作文/代码/讨论）|
| 缺情感 | 可模拟共情（罗杰斯三条件）|

**但风险也升级**：
- 幻觉（旧技术至少不会编）。
- 学生变懒（旧技术不替学生思考，LLM 会）。
- 不平等（好模型付费）。
- 评估危机（代写）。

> 🕳️ **历史教训**：不要重蹈 MOOC 的覆辙——**只给内容不给支架/社会性，必然失败**。LLM 导师要成功，必须**模拟 ZPD 支架 + 社会性 + 保留学生挣扎**。

## 四、教育技术的"有效 vs 神话"

| 技术 | 证据 |
|---|---|
| **自适应练习（带反馈）**| ✅ 有效（d≈0.4–0.7）|
| **多媒体教学（Mayer 原则）**| ✅ 有效 |
| **在线 vs 面授（同质量）**| ≈ 等效（前提：设计好）|
| **翻转课堂**| ✅ 中等有效（前提：学生预学）|
| **纯视频课（无互动）**| ❌ 低完成率 |
| **游戏化学习**| ⚠️ 混合证据，过度理由风险 |
| **脑训练**| ❌ 不迁移 |
| **学习风格匹配**| ❌ 证伪 |
| **VR/AR 教学**| ⚠️ 潜力大但证据仍弱 |
| **LLM 导师**| 🆕 初步 +0.3–0.8σ **【待联网核实】** |

## 五、关键教训（给 AI 教育产品的人）

1. **技术不替代教师**——它**增强**教师或**补位**（课后辅导）。
2. **支架 > 内容**——内容网上都有，难的是适配 ZPD。
3. **社会性不能省**——协作/师生关系效应量大。
4. **保留学生挣扎**——让 AI 直接给答案是毒药（绕过 ZPD）。
5. **评估要升级**——传统作业评估已被代写攻破，往 Bloom 高层走。
6. **公平设计**——默认免费版要好，否则扩大不平等。

## 六、与本项目锚点

- **欺骗动力学**：每代教育技术都伴随"伪学习"欺骗（学生表演用了技术但没学）。LLM 时代最严重——AI 代写是新型欺骗。详见 [`../欺骗动力学-锚点块.md`]。
- **熵治理**：技术 = 熵减工具，但**外包依赖** = 丧失自主熵减能力（[`../LEARNING_THEORIES/05_connectivism.md`] 的局限）。
- **RL 视角**：教育技术史 = reward signal 越来越密集、越来越贴身的历程。Skinner 教学机器 = 第一个 dense reward 机器；LLM 导师 = reward 个性化到每个学生每个时刻。
- **费曼 F2**：所有教育技术都要过 F2 门——"用了这个技术，学生能复述/迁移吗？" 不能 = 没用。
