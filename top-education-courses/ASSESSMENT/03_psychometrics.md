# 03 · 心理测量 / 项目反应理论 IRT

> 评估的**测量精度**。把"学生能力"和"题目难度"放同一尺度。**所有自适应学习 + 知识追踪的数学根基**。AI 教育工程师必读。

---

## A. 经典测试理论 CTT

最简单的模型：

$$X = T + E$$

- $X$：观察分数
- $T$：真分数
- $E$：随机误差

CTT 简单但**题目难度依赖样本**（一道题对尖子班"易"、对普通班"难"）——不可迁移。

## B. 项目反应理论 IRT ⭐

IRT 把**题目**和**人**放同一尺度，解决 CTT 的样本依赖。

### 1 参数 Rasch 模型（最简）
$$P(\text{答对} | \theta, b) = \frac{1}{1 + e^{-(\theta - b)}}$$

- $\theta$：学生能力
- $b$：题目难度
- 两者**同尺度**（logit）

含义：能力比难度高 1 个 logit → 答对概率 ≈ 0.73。

### 3 参数模型 3PL（加猜测 + 区分度）
$$P = c + \frac{1-c}{1+e^{-a(\theta-b)}}$$

- $a$：区分度（题能把力高低分开的能力）
- $b$：难度
- $c$：猜测参数（蒙对下限）

### 4 参数 4PL（加上限，防"失误"）

IRT 的优势：
- **题目参数不依赖样本**（考过一次的题，参数固定，下次直接用）
- **能力估计不依赖题目**（同一人不同题测，能力可比）
- **可建题库**——这是 CAT 的前提

## C. 计算机化自适应测试 CAT ⭐⭐

**IRT 最大的应用**。原理：
1. 给一道中等难度题
2. 答对 → 给更难的题（提高 $\theta$ 估计）
3. 答错 → 给更易的题（降低 $\theta$ 估计）
4. 每题后重估 $\theta$，直到估计**置信区间足够窄**

**效果**：用**更少题**（通常 1/2 到 1/3）达到比固定卷**更高精度**。GMAT/GRE 都用 CAT。

> 🎯 **CAT = ZPD 的测量实现**。每题恰好把学生放在能力估计的"边缘"——这就是维果茨基 ZPD 在测试上的形式化。

## D. 知识追踪（ITS 的核心）

ITS 把 IRT 扩展到**时间序列**——追踪学生掌握状态的变化。

### 贝叶斯知识追踪 BKT（Corbett & Anderson 1995）
隐马尔可夫模型：
- 隐状态：掌握 (1) / 未掌握 (0)
- 观察：答对/答错
- 转移：未掌握→掌握的概率（学到了）
- 发射：掌握/未掌握时答对的概率（含失误/猜测）

每答一题，贝叶斯更新掌握概率。**ALEKS / Cognitive Tutor 用 BKT**。

### 深度知识追踪 DKT（Piech et al. 2015）
用 RNN 学学生状态。**第一次把深度学习引入学生建模**，超过 BKT。

### 局限
- **冷启动**（新学生无数据）
- **技能定义模糊**（一道题考几个技能？）
- **数据饥渴**
- **可解释性差**（DKT）
- **【待联网核实】** 最新 Transformer-KT 进展

## E. 大规模评估：PISA / TIMSS / NAEP

- **PISA**（OECD）：15 岁阅读/数学/科学，三年一次。**跨国比较影响力巨大**。
- **TIMSS**：数学/科学（4/8 年级）。
- **NAEP**（美国"国家成绩单"）。

陷阱：排名常被误读。PISA 测的是"应用能力"非"课程覆盖"，且受文化/动机/抽样影响。**排名 ≠ 教育好坏**。

## RL 接口

| IRT/CAT/KT | RL |
|---|---|
| 能力 $\theta$ | state / value function |
| 题目难度 $b$ | action 难度 |
| 答对/错 | reward |
| CAT 选下一题 | **policy**（选最有信息量的 action）|
| BKT 贝叶斯更新 | belief state update（部分可观测 RL）|
| DKT | learned state representation |
| 知识追踪 | **POMDP**（部分可观测马尔可夫决策过程）|

> 🎯 **核心同构**：**ITS 自适应 = POMDP**。学生真实掌握状态不可直接观测（隐），从答题（观察）推断。AI 导师选下一题 = 在 belief state 上选信息增益最大的 action。这是 [`../../讲透RL/`] POMDP 章节的教育实例。

## 项目锚点
- **ZPD**：CAT 每题恰好把学生放能力估计边缘 = ZPD 测量实现。
- **熵治理**：CAT 最小化"测量熵"——用最少题把能力估计的不确定性降到最低。信息论最优（[`../../讲透信息论/`]）。
- **费曼 F2**：好 F2 题 = 高区分度题（IRT 语言）。
- **欺骗动力学**：选择题易蒙（IRT 的 $c$ 猜测参数）。要降猜测 → 用构造题/苏格拉底追问（[`../METHODS/04_socratic_case.md`]）。
