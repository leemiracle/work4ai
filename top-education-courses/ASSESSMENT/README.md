# 📊 评估与测量 (Assessment) · 总览

> "学习发生了吗？"——这是教育学最难、也最被忽视的一环。**你不知道学会了没有，所有教学法都是瞎调**。评估是教育学的**测量精度**，正如物理学需要仪器。
>
> 本目录三块：**Bloom 分类法（测什么）→ 形成性/总结性（怎么测）→ 心理测量/IRT（怎么测得准）**。

---

## 评估的根本问题

> 🔥 学生做对了一道题，意味着什么？
> - 他真懂了？（认知层）
> - 他记住了？（记忆层）
> - 他蒙对的？（概率）
> - 他在表演"做对"骗过评估？（欺骗动力学）

**评估 = 推断**：从可观察的表现，推断不可观察的认知状态。所有评估误差都源于这个推断的不完美。

---

## 三块结构

### 1. Bloom 教育目标分类法 —— [`01_bloom_taxonomy.md`]（测什么层级）
- **原版 (1956)**：知识 → 理解 → 应用 → 分析 → 综合 → 评价
- **修订 (Anderson & Krathwohl 2001)**：记忆 → 理解 → 应用 → 分析 → 评价 → **创造**
- **用途**：设计题/目标/标准时，明确你在测哪一层。
- **关键洞察**：传统考试多停在"记忆/理解"，但**21 世纪能力在"分析/评价/创造"**。AI 时代尤甚——记忆层 AI 全包了，人要往上走。

### 2. 形成性 vs 总结性评估 —— [`02_formative_summative.md`]（怎么测）
- **Scriven 1967** 的区分：
  - **形成性 (formative)** = **为了学习**的评估，改进中，给反馈。
  - **总结性 (summative)** = **对学习**的评估，事后判定。
- **Black & Wiliam (1998) "Inside the Black Box"**：形成性反馈是**提升低成就学生最有效**的手段（d≈0.4–0.7）。
- **Hattie**：教师反馈 d≈0.75，顶级干预。
- **关键洞察**：传统教育重总结性（期末考），轻形成性（日常反馈）。**AI 时代让形成性反馈成本归零**——这是 AI 教育的最大机会。

### 3. 心理测量 / IRT —— [`03_psychometrics.md`]（怎么测得准）
- **经典测试理论 CTT**：真分数 $T = O - E$（观察 = 真 + 误差）。
- **项目反应理论 IRT**：用数学模型把**学生能力 $\theta$** 和**题目难度 $b$** 放同一尺度。
  - Rasch 模型：$P(\text{对} | \theta, b) = \frac{1}{1+e^{-(\theta-b)}}$
- **计算机化自适应测试 CAT**：根据答题实时选题 → 用更少题精确测能力。**这是 ITS / 自适应学习的数学根基**。
- **大规模评估**：PISA / TIMSS / NAEP。

## 评估的 Hattie 效应量

| 评估相关干预 | d |
|---|---|
| 形成性评估（带反馈）| 0.4–0.7 |
| 教师反馈 | 0.75 |
| 学生自我评分（含偏）| 1.33 ⚠️ |
| 总结性考试本身 | ~0（不直接促学）|

> 🪶 **反直觉**：考试本身不促学，**考试后的反馈才促学**。所以"多考试"没用，"多反馈"才有用。AI 导师的价值不在出题，在**即时个性化反馈**。

## AI 时代的评估危机与机会

### 危机
- **AI 代写作业**：传统作业评估失效（essay/code 全能代写）。
- **检测失败**：AI 检测器准确率不够，误伤学生。
- **评估降级**：学校转向"课堂表现"等软指标，但这些更难标准化。

### 机会
- **过程评估**：AI 可追踪学生**解题过程**（不只是答案），评估高阶思维。
- **连续形成性反馈**：成本归零，每个学生每分钟都能有反馈。
- **自适应测试 CAT 普及**：IRT + AI = 每个学生一套个性化测验。
- **新评估范式**：从"一次大考"→"长程能力档案"。**这是 100 年来评估的范式转移**。

## 评估设计的 Bloom × 反馈 矩阵

设计一道好题 = 同时决定**测哪一层**（Bloom）和**给什么反馈**（形成性/总结性）：

| | 记忆/理解 | 应用/分析 | 评价/创造 |
|---|---|---|---|
| **形成性** | 即时正误 + 解释 | 提示卡在哪步 | 同伴/教师讨论 |
| **总结性** | 选择题/默写 | 应用题/案例分析 | 项目/作品集 |

> 🎯 **AI 导师的优势**：能在右上两格（应用/分析/创造 × 形成性）做人力做不到的事——对每个学生的每个作品给即时深度反馈。

## 与本项目锚点

- **RL 视角**：评估 = reward signal。形成性 = dense reward（高频）；总结性 = sparse reward（低频）。**Dense reward 训得快**（这就是为什么形成性反馈 d 大）。IRT = 把 reward 校准到能力尺度（避免太难/太易的无信号 reward）。
- **熵治理**：评估 = 测量学生脑中的"剩余不确定熵"。好评估 = 高信息量（能区分真懂/假懂）。
- **费曼 F2**：F2"卡壳测试"= 高质量形成性评估。本项目 [`../费曼学习法/`] 的 F1-F4 门就是评估系统的设计。
- **欺骗动力学**：评估系统永远面临"表演学习"的欺骗。传统选择题最易骗（只测记忆）。**评估层级越高（创造），越难骗**——这给了反欺骗的方向：往 Bloom 高层走。
