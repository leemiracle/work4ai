# 04 · 人本主义 (Humanism)

> 旗手：**Carl Rogers / Abraham Maslow / Malcolm Knowles (成人教育)**。在行为/认知/建构都讲"机制"之后，人本主义问一个更根本的问题：**学生为什么愿意学？**
>
> 结构：直觉 → 数学骨架 → 教育应用 → 局限 → RL 接口。

---

## 一、直觉

行为主义、认知主义、建构主义都假设"学生**想**学"。但任何一个真实老师都知道：

> 🔥 真正的难题不是"怎么教"，是"**怎么让他想学**"。

人本主义说：动机不是外部加的（奖惩），是**内在的**。每个孩子天生有**自我实现** (self-actualization) 的趋向——想成为自己能成为的最好样子。教育要做的，是**不压制**这个趋向，给它土壤。

### 罗杰斯的"以学习者为中心"

三个条件（教师 side）：
1. **真实 (genuineness)**：教师不戴面具。
2. **无条件积极关注 (unconditional positive regard)**：接纳学生，不论成绩。
3. **共情 (empathy)**：理解学生的内在参照系。

满足这三条，学生会**自我驱动**地学"有意义"的东西。

> 🪶 这与行为主义的"奖惩塑形"形成鲜明对比。行为主义把学生当可训练的动物；人本主义把学生当**有内在目的的人**。

## 二、数学骨架（人本主义最难形式化，但能借用 SDT）

人本主义本身抗拒量化（"意义怎么测？"）。但可以用 **自我决定论 (Self-Determination Theory, Deci & Ryan)** ——人本主义的科学化后裔——来给数学：

### 2.1 内在动机 = 三个心理需要满足度

$$IM = f(\text{Autonomy}, \text{Competence}, \text{Relatedness})$$

- **自主 (Autonomy)**：我能选吗？
- **胜任 (Competence)**：我能做到吗？
- **归属 (Relatedness)**：我属于这里吗？

三者满足 → 内在动机高；任一受挫 → 内在动机下降，转向外部控制。

### 2.2 过度理由效应（overjustification）

$$\text{新 } IM = \text{原 } IM - \text{外部 reward 的"挤出"}$$

**给一个本来有内在动机的行为加外部 reward，反而会降低内在动机**。经典实验：给本来爱画画的孩子发奖章，奖章停了，孩子不再画了。（Lepper et al. 1973）

> 🪶 这是人本主义对行为主义最锋利的反批评：**外部奖惩会腐蚀内在动机**。游戏化学习、积分制、KPI——都可能触发过度理由效应。

### 2.3 心流 (Csikszentmihalyi)

当**任务难度 ≈ 能力**时，进入心流 (flow)：

$$\text{心流概率} \uparrow \quad \text{当} \quad \text{挑战} \approx \text{技能}$$

太难 = 焦虑；太易 = 无聊；匹配 = 心流。

> 🪶 这与维果茨基 ZPD **几乎同构**——ZPD 是认知版本，心流是情感版本。两者说的是同一件事：**恰好够难**。

## 三、教育应用

| 应用 | 机制 |
|---|---|
| **兴趣驱动选课** | 满足自主 |
| **项目式学习（自己选题）** | 自主 + 胜任 |
| **成长型思维表扬（Dweck）** | 表扬**努力**而非**聪明** → 保胜任感 |
| **小班/导师制/师生关系** | 满足归属（Hattie d≈0.72）|
| **契约式学习 / 学生自治** | 自主 |
| **避开过度游戏化** | 防过度理由效应 |
| **AI 导师的"耐心/共情"设计** | 罗杰斯三条件映射到 AI |

> 🎯 **AI 导师的人本设计**：Khanmigo 不批评、永远耐心、按学生节奏——这是罗杰斯三条件的 AI 实现。**人本主义不是软技术，是 AI 导师留存率的核心**。

---

## 四、局限

1. **难操作化**："意义""自我实现"难测，难做大样本实验。
2. **对低动机/低基础学生不够**：自我驱动需要**基础能力 + 元认知**，缺失时纯人本主义会放任（夏山学校的失败案例）。
3. **忽略结构/文化不平等**：罗杰斯的"无条件接纳"在资源不平等的现实里显得天真（批判教育学的批评）。
4. **与直接教学冲突时难取舍**：纯人本反对直接教学，但 Kirschner 等证据支持新手需直接教学。

## 五、RL 接口

人本主义 = **intrinsic reward RL**：

| 人本主义 | RL |
|---|---|
| 内在动机 | intrinsic reward（curiosity, empowerment）|
| 自主 | action space 大 / 选项多 |
| 胜任 | 可达 reward / mastery signal |
| 归属 | multi-agent cooperation reward |
| 过度理由效应 | 外部 reward 挤压 intrinsic（empirical RL 发现）|
| 心流 | 探索-利用平衡的最优点 |
| 自我实现 | empowerment / 可控性最大化 |

> 🎯 **关键发现**：现代 RL 证实了人本主义的直觉——**纯外部 reward 训出的 agent 泛化差、脆弱**；加 intrinsic reward（curiosity, prediction error）训出的 agent 更鲁棒、更会探索。**机器学习领域独立"重新发现"了人本主义**。

代表：ICM (Pathak 2017)、RND (Burda 2018)、empowerment maximization。详见 [`../讲透RL/`]。

## 六、与本项目锚点

- **熵治理**：内在动机 = 学习者自带"低熵源"（对世界的兴趣）。压制它 = 浪费免费能源。
- **故事原语**：有意义的学习 = 把内容编织进学生自己的"人生故事"。无意义学习 = 故事断片，存不住。
- **费曼 F2**：F2 复述能否"用学生自己的话"= 检查是否建构进个人意义。机械背诵过不了。
- **欺骗动力学**：外部 reward 制度（分数/排名）催生"表演学习"——为 reward 学，不是为意义学。这是最大规模的教育欺骗。
- **RL 视角**：人本主义补完了 RL 的 intrinsic reward 维度。无 intrinsic reward 的 RL 像纯行为主义——脆弱、不泛化。

---

## 七、五范式至此的拼图

| 范式 | 回答 | RL 组件 |
|---|---|---|
| 行为主义 | 行为怎么改 | model-free |
| 认知主义 | 脑内怎么建构 | model-based |
| 建构主义 | 怎么在社会中建构 | model-based + social |
| **人本主义** | **为什么愿意学** | **intrinsic reward** |

四者拼出一个完整的学习者：有外在 reward 塑形（行为）+ 内在图式建构（认知）+ 社会共建（建构）+ 内在动力（人本）。
