# 05 · 联结主义 (Connectivism)

> 旗手：**George Siemens (2004) / Stephen Downes**。数字时代的新学习理论。前四范式都假设"知识**在脑里**"；联结主义说：**数字时代，知识在网络的连接里**。
>
> 结构：直觉 → 数学骨架 → 教育应用 → 局限 → RL 接口。

---

## 一、直觉

前四范式的世界里，学习 = 把知识装进**一个脑**。

但你现在怎么"知道"日本现在几点？
- 你**不一定记得**时区换算；
- 但你**知道在哪查**（手机/Google/问 AI）。

Siemens (2004) 说：数字时代，**"知道在哪找" 比 "记住" 更重要**。知识分布在**人 + 机器 + 数据库 + AI** 的网络里。学习 = 在这个网络里**建立并维护连接**。

> 🔥 反直觉点：你"知道"的东西，**大部分不在你脑里**——在你手机里、在你的 Zotero 里、在你能问到的 ChatGPT 里、在你的人脉里。**认知已经外化了**。

### 联结主义四原则
1. 学习 = 在节点间形成连接。
2. 知识 = 网络结构（不是单个节点）。
3. 能力 = **持续学习 + 网络维护**（不是一次性掌握）。
4. **决策本身是学习**（信息过载时代，"知道什么重要"是核心能力）。

---

## 二、数学骨架

### 2.1 网络学习的形式化

设知识网络 $G = (V, E)$：
- $V$ = 节点（人/文档/AI/数据库）。
- $E$ = 连接（你能调用的关系）。

学习者能力 $\approx$ **从 $G$ 中提取信息的能力**：

$$\text{Capability} = f(\text{覆盖度}(V_{accessible}), \text{连通性}(E), \text{检索效率})$$

类比图论：你不需要**拥有**所有节点，但需要**连通**到它们（small-world / shortest path）。

### 2.2 分布式认知

认知不只在脑内，**分布在工具和环境中**（Hutchins 1995《Cognition in the Wild》）。

例子：心算 $347 \times 28$。你脑内 + 纸笔 + 可能的计算器——**整个系统**在算。脑只是系统的一个节点。

### 2.3 RAG 式学习的数学

LLM + 检索增强 (RAG) 是联结主义的机器实现：

$$P(\text{答案} | \text{query}) = P(\text{LLM} | \text{query}, \text{retrieved context})$$

知识不在权重里（不"记住"），在**检索到的 context** 里（连接）。这正是 Siemens 2004 主张的机器版。

## 三、教育应用

| 应用 | 机制 |
|---|---|
| **数字素养教育** | 教"判断信息可信度""搜索策略" |
| **个人知识管理 (PKM)** | Zotero/Obsidian/Notion = 维护连接 |
| **MOOC / 开放教育资源** | 扩大可访问节点集 |
| **PLN (Personal Learning Network)** | 主动构建人脉网络 |
| **AI 协作学习** | 把 AI 作为网络节点，学会"问对问题"|
| **RAG 式学习** | **不强求记住，强求知道在哪找 + 怎么验证** |
| **批判性使用 AI** | 防过度依赖（认知外包风险）|

> 🎯 **AI 时代的核心能力重定义**：从"记住多少"→"**能否提出好问题 + 验证答案**"。Prompt 工程就是联结主义的核心技能。见 [`../讲透Prompt/`]。

## 四、局限

1. **依赖网络基础设施**：网络断/付费墙/审查 → 能力崩。数字鸿沟放大不平等。
2. **元认知负担重**：知道在哪找，需要"**知道自己不知道什么**"——新手恰恰缺这个（Dunning-Kruger）。
3. **外包风险**：把思考全交给 AI/搜索 → 工作记忆萎缩、深度思考能力下降（《The Shallows》Carr 的担忧）。
4. **难评估**：传统考试测"记住"，联结主义能力（"会查会判"）难在标准化测试里测。
5. **被批评"不是理论"**：Verhagen (2006) 等认为联结主义是"数字时代的学习观"，不是严格学习理论。**争议至今**。

## 五、RL 接口

联结主义 = **分布式 / 多 agent RL**：

| 联结主义 | RL |
|---|---|
| 知识在节点网络 | 分布式 RL / federated learning |
| 连接 = 可调用 | agent 间的通信信道 |
| RAG 式学习 | LLM + 工具调用（function calling）|
| 检索效率 | exploration 的 query cost |
| 决策 = 学习 | active inference / 在线学习 |
| 个人 PKM | agent 的外部记忆库 (episodic memory) |
| 多智能体协作 | multi-agent RL（[`../讲透多Agent协作/`]）|

> 🎯 **关键同构**：**LLM agent + 工具调用 = 联结主义在机器上的实现**。一个能调搜索、调计算器、调数据库的 Agent，就是 Siemens 设想的"数字学习者"。**AI agent 工程是联结主义教学法**。

## 六、与本项目锚点

- **故事原语**：联结主义挑战"故事在单个脑里"——故事可能**分布在多人多机**。这扩展了本项目元理论：世界 = 多 agent 共同迭代的故事。
- **熵治理**：外部网络 = 廉价的低熵源（搜索引擎把世界压缩成答案）。善用 = 大幅熵减；滥用 = 丧失自主熵减能力（外包依赖）。
- **RL 视角**：联结主义补完了 RL 的**分布式**维度。前四范式是单 agent；联结主义是多 agent + 外部记忆。
- **欺骗动力学**：联结主义面临新的欺骗——**幻觉信息、SEO 操纵、深度伪造**。"会查"必须升级为"会判"，否则会被网络欺骗攻破。这是 AI 素养教育的核心。
- **费曼 F2**：F2 在联结主义里要升级——不只测"能否复述"，还要测"**能否在没有网络时复述 / 能否批判网络答案**"。防止"假懂"（其实是查的）。

## 七、五范式完整拼图（本系列收官）

| 范式 | 回答 | RL 组件 | 时代 |
|---|---|---|---|
| 行为主义 | 行为怎么改 | model-free | 1900s |
| 认知主义 | 脑内怎么建构 | model-based | 1950s |
| 建构主义 | 怎么在社会中建构 | model-based + social | 1970s |
| 人本主义 | 为什么愿意学 | intrinsic reward | 1980s |
| **联结主义** | **数字时代知识在哪** | **分布式 RL / 多 agent** | **2000s+** |

**五者叠加 = 一个完整的数字时代学习者**：
- 有外部塑形（行为）
- + 内在图式（认知）
- + 社会共建（建构）
- + 内在动力（人本）
- + 分布式网络（联结）

> 🎯 **这就是本项目主张"五范式 = RL 五组件"的完整图**。任何真实学习都同时调动多个组件。**好的 AI 导师 = 五组件按目标配比**。

## 八、回到 AI for Education 的设计准则

基于五范式，AI 导师的设计准则：

| 准则 | 来自范式 |
|---|---|
| 即时反馈、小步子 | 行为主义 |
| 概念图式 + worked examples + 双重编码 | 认知主义 |
| 苏格拉底提问 + 支架 + 不给答案 | 建构主义（ZPD）|
| 耐心共情 + 表扬努力 + 自主选择 | 人本主义 |
| 接入工具 + 教判断信息可信度 | 联结主义 |

**Khanmigo 的好，在于它同时调用了多范式**——不是任何一派的纯信徒。
