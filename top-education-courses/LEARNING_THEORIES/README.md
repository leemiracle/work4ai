# 🧠 学习理论五范式 · 总览

> 教育学的"标准模型"。对标物理学的"四大基本力"——学习理论也有五大范式，几乎覆盖了所有"学习是怎么发生的"解释。
>
> **本 README 的核心主张（本项目原创）**：**五范式 = 强化学习 (RL) 的五个组件**。它们不是对立的，而是 RL 在不同假设下的特例。把五范式统一到 RL，是本库最重要的理论贡献。

## 五范式速览

| 范式 | 旗手 | 一句话 | 核心问题 | RL 对应 | 何时用 |
|---|---|---|---|---|---|
| **行为主义** | 桑代克/斯金纳/巴甫洛夫 | 学习 = 可观察行为的改变 | 怎么强化行为 | **model-free RL** | 训练明确技能（打字/乘法表）|
| **认知主义** | 皮亚杰/布鲁纳/奥苏贝尔 | 学习 = 内部心理结构改变 | 脑内怎么编码 | **model-based RL** | 概念理解（为什么）|
| **建构主义** | 维果茨基/皮亚杰后期 | 学习 = 社会互动中主动建构 | 怎么搭意义 | **social + model-based RL** | 复杂能力（写作/科研）|
| **人本主义** | 罗杰斯/马斯洛 | 学习 = 自我实现 | 意义与动机 | **intrinsic reward** | 动机/情感/价值观 |
| **联结主义** | Siemens (2004) | 学习 = 网络中连接的建立 | 数字时代知识在哪 | **分布式/多 agent RL** | 网络/数字学习 |

## 本项目核心主张：五范式 = RL 五组件

### 主张陈述

教育学百年大战（行为 vs 认知 vs 建构 vs 人本），其实吵的是同一件事的不同部分。**它们都是 RL，只是在不同假设下简化**：

#### 1. 行为主义 = model-free RL
- 只用 reward 信号，不建 world model。
- 优势：样本效率高（对明确任务），可解释（刺激-反应）。
- 局限：不解释"理解"，无法迁移到新情境。
- AI 对应：Q-learning、操作条件反射、RLHF 的 reward model。
- 教育应用：乘法表、打字、技能训练。

#### 2. 认知主义 = model-based RL
- 建 world model（图式），靠 model 规划。
- 优势：能解释"理解"和迁移。
- 局限：建模型需要认知资源（工作记忆瓶颈）。
- AI 对应：model-based RL、world model（见 [`../讲透世界模型/`]）。
- 教育应用：概念教学、原理理解。

#### 3. 建构主义 = model-based + social RL
- model 不是独建的，是在社会互动 + 工具中**共建**的。
- 维果茨基：高级认知起源于社会。
- 优势：解释复杂能力（语言、科研、批判思维）。
- 局限：慢、依赖高质量社会环境。
- AI 对应：multi-agent RL、social learning、LLM 多 agent 协作。
- 教育应用：PBL、讨论课、师徒制。

#### 4. 人本主义 = intrinsic reward RL
- 不是所有 reward 来自外部；**意义感/成长感**是内在 reward。
- 罗杰斯：意义学习 > 机械学习。
- 优势：解释长期动机、创造力。
- 局限：难操作化（"意义"怎么测？）。
- AI 对应：intrinsic motivation、curiosity-driven RL。
- 教育应用：兴趣驱动、自我决定论 (SDT)。

#### 5. 联结主义（Siemens）= 分布式 RL
- 知识不在脑里，**在网络连接里**（人+机+数据库）。
- 数字时代：知道"在哪找"比"记住"更重要。
- AI 对应：分布式 RL、federated learning、LLM + 检索 (RAG)。
- 教育应用：数字素养、RAG 式学习。

### 为什么这个统一有用？

| 好处 | 说明 |
|---|---|
| **消解派别之争** | 不再"谁对谁错"，而是"什么情境用哪个组件" |
| **给 AI 教育产品理论框架** | 设计 AI 导师时，明确它在用哪个 RL 组件 |
| **预测有效性** | 用 RL 理论预测什么教学干预会有效（密集 reward + ZPD → 高效应量）|
| **桥接两个学科** | 教育学 ↔ AI 真正打通（见 [`../CROSS_DISCIPLINARY.md`]）|

### 一个具体例子：解释 Hattie 的效应量

Hattie 元元分析发现**教师反馈 (d≈0.75)** 是顶级干预。用 RL 语言解释：
- 反馈 = **密集、即时的 reward signal**；
- 密集 reward 加速 credit assignment；
- 所以效应量大。

而**班级规模 (d≈0.21)** 效应小：
- 小班不改变 reward 密度，只改变"理论上可获得的 reward 上限"；
- 但 reward 实际密度没变（老师还是一节课讲一次）；
- 所以无效。

> 🎯 **RL 语言比教育学语言更能预测"什么有效"**。这是本项目的实证主张，可被检验。

## 五范式不是非此即彼，而是叠加

真实的复杂学习**同时调动多个组件**：

例：学写一篇论文
- **行为主义**：练打字速度、引文格式（model-free）
- **认知主义**：理解论文结构（model-based）
- **建构主义**：和导师/同侪讨论打磨（social）
- **人本主义**：找到自己想写的主题（intrinsic）
- **联结主义**：用 Zotero/RAG 找文献（分布式）

> 🪶 好的学习设计 = 五组件按目标配比。新手重行为主义（打基础），熟手重建构主义（高阶能力），全程保人本主义（动机）。

## 范式的历史时间线

```
1900s  行为主义崛起（桑代克 1898 / 巴甫洛夫 1927 / 斯金纳 1938）
   │
1950s  认知革命（皮亚杰成熟 / 布鲁纳 / 信息加工）
   │
1970s  建构主义（维果茨基英译 1978 / 社会建构）
   │
1980s  人本主义（罗杰斯 / Maslow）+ 建构主义深化
   │
2000s  联结主义（Siemens 2004，数字时代）
   │
2020s  全部五范式 → 在 LLM 导师中重新组合（你在这里）
```
