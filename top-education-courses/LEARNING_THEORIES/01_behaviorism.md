# 01 · 行为主义 (Behaviorism)

> 旗手：**Thorndike / Pavlov / Skinner / Bandura（社会学习过渡）**。学习理论里最古老、最可操作、也最被高阶理论批评的一派。但它是**所有自适应教育技术 + RLHF 的祖宗**。
>
> 结构：直觉 → 数学骨架 → 教育应用 → 局限 → RL 接口。

---

## 一、直觉

想象训一只狗。摇铃 → 给食 → 狗流口水。重复几次后，光摇铃狗就流口水。

这就是**经典条件反射**（巴甫洛夫 1927）。学习 = 把一个中性刺激和反应绑起来。

再想象训一只鸽子。它偶然转一圈，你给食。它更可能再转。重复，它学会"转圈 = 食"。这是**操作性条件反射**（斯金纳 1938）。学习 = 行为被**后果**塑造。

行为主义的全部直觉就这两条：**刺激可以绑定反应；后果可以塑造行为**。

> 🔥 反直觉点：行为主义**拒绝谈脑内**。斯金纳说"思维"是黑箱，只看"输入(刺激)→输出(行为)"。这看似粗暴，却让学习**第一次可测量、可工程化**。

## 二、数学骨架

### 2.1 经典条件反射（巴甫洛夫）

记 US（无条件刺激，如食）、UR（无条件反应，如流口水）、CS（条件刺激，如铃）、CR（条件反应）。

学习规则（Rescorla-Wagner 模型，1972）：

$$\Delta V_{CS} = \alpha \cdot \beta \cdot (\lambda - V_{total})$$

- $V_{CS}$：CS 的"关联强度"
- $\lambda$：US 能支持的最大关联强度（US 强度）
- $\alpha, \beta$：CS 和 US 的可学习率
- $V_{total}$：所有在场刺激的关联强度之和

含义：**学习的增量 = 预测误差 × 学习率**。当 CS 已经能完全预测 US（$V_{total} \to \lambda$），就不再学（$\Delta V \to 0$）。

> 🪶 这正是 **TD-learning** 的雏形：reward prediction error $\delta = r + \gamma V' - V$。Rescorla-Wagner 比 TD 早 20 年发明了 prediction error 学习。

### 2.2 操作性条件反射（斯金纳）

四种后果（行为 × 后果的 2×2 矩阵）：

| | 加刺激 | 撤刺激 |
|---|---|---|
| **增行为** | 正强化（给糖）| 负强化（撤痛）|
| **减行为** | 正惩罚（给电）| 负惩罚（撤糖）|

强化程式（schedule of reinforcement）：固定比率 FR、可变比率 VR、固定间隔 FI、可变间隔 VI。VR 最难消退（赌博机制）。

### 2.3 桑代克效果律 (1898)

$$P(行为) \propto e^{\beta \cdot \text{satisfying consequence}}$$

带来满意后果的行为，概率上升。**这是 RL policy update 的最早表述**。

## 三、教育应用

| 应用 | 机制 |
|---|---|
| **乘法表 / 单词卡** | 重复 + 即时正反馈 → S-R 绑定 |
| **代币制（token economy）**| 正强化，行为治疗/特殊教育常用 |
| **斯金纳教学机器 (1958)** | 答对才进下一题 = 即时强化 + 小步子 |
| **程序教学 (programmed instruction)** | 拆成极小步，每步即时反馈 |
| **课堂管理**| 表扬准时（正强化）、忽略小动作（消退）|
| **Anki / 闪卡** | 间隔 + 主动检索 + 正反馈 |
| **游戏化学习** | 积分/徽章 = 代币制 |

## 四、局限

1. **不解释"理解"**：学生能背公式不代表懂。行为主义无法区分"机械记忆"和"有意义学习"（奥苏贝尔的批评）。
2. **不可迁移**：训出的行为只在训练情境。鸽子在斯金纳箱转圈，出了箱子不会转。
3. **忽视内部状态**：认知革命（1950s）正是因为行为主义解释不了思维、记忆、问题解决。
4. **伦理争议**：斯金纳《超越自由与尊严》被批为"驯化人类"。
5. **过度依赖外部 reward** → 挤压 intrinsic motivation（人本主义的批评，见 [`04_humanism.md`]）。

## 五、RL 接口

行为主义 = **model-free RL** 的哲学化前奏：

| 行为主义 | RL |
|---|---|
| 刺激-反应 | state-action |
| 后果塑造行为 | reward 更新 Q 值 |
| 强化程式 (FR/VR/...) | reward schedule |
| 消退 | Q 值衰减（无 reward）|
| 效果律 | policy gradient $\nabla J = E[\nabla\log\pi(a\|s) \cdot R]$ |
| Rescorla-Wagner | TD error $\delta = r + \gamma V' - V$ |

> 🎯 **关键事实**：**RLHF（人类反馈强化学习）= 斯金纳操作性条件反射的 AI 版**。reward model = 斯金纳箱的"按杆给食"。ChatGPT 的对齐，本质是 1938 年斯金纳的范式在 2022 年的复现。

---

## 六、与本项目锚点

- **熵治理**：强化 = 重复某条行为路径 = 在 policy 空间局部熵减。
- **故事原语**：行为主义不关心"故事"，只关心"刺激序列"。这是它的力量也是盲点。
- **费曼 F2 门**：行为主义能让学生"做对"但不能保证"懂"。F2 卡壳测试正是用来戳穿"做对≠懂"。
- **欺骗动力学**：纯行为主义训练的学生容易"表演学习"——做出学习的外部行为骗过评估，但没真学。
