# 02 · 认知主义 (Cognitivism)

> 旗手：**Piaget / Bruner / Ausubel / Gagné / 信息加工学派**。1950s "认知革命"打开行为主义的黑箱，问："**脑内发生了什么？**"
>
> 结构：直觉 → 数学骨架 → 教育应用 → 局限 → RL 接口。

---

## 一、直觉

行为主义说"学习 = 行为改变"。但费曼会追问：

> 🔥 如果一个学生背下了 $E=mc^2$，另一个学生理解了质量和能量等价——**行为**都是"能背出公式"，但**学习**完全不同。行为主义怎么区分？

认知主义说：区别在**脑内**。前者只存了一个字符串，后者建了一个**图式 (schema)**——一组关联的概念结构，能推理、能迁移。

学习 = **内部心理结构的改变**，不只是可观察行为。

### 信息加工模型（Atkinson-Shiffrin 1968）

```
感觉记忆 (<1s) → 注意 → 工作记忆 (4±1 chunks, ~30s) → 编码 → 长时记忆 (无限)
                                  ↑                          ↓
                                  └──────── 提取 ────────────┘
```

瓶颈在**工作记忆**：只能同时持有 4±1 个组块（Cowan 2001；米勒 1956 说 7±2，后来修正）。所有教学设计的核心约束 = **不要让工作记忆溢出**。

## 二、数学骨架

### 2.1 皮亚杰：图式平衡

- **图式 (schema)** $S$：内部认知结构。
- **同化 (assimilation)**：用现有 $S$ 解释新信息 $\Delta I$。
- **顺应 (accommodation)**：修改 $S$ 以容纳 $\Delta I$。
- **平衡 (equilibration)**：当 $\Delta I$ 与 $S$ 冲突（不平衡），驱动 $S$ 更新。

可形式化：用 KL 散度类比——

$$\text{不平衡} \propto D_{KL}(P_{world} \| P_{S})$$

当世界和图式的预测分歧大（KL 大），驱动图式更新（$S \to S'$）使 KL 减小。**这与 Bayesian belief update 同构**。

### 2.2 ACT-R 认知架构 (Anderson)

ACT-R 把认知建模为：
- **陈述性块 (declarative chunk)**：事实，有激活值 $A_i = \ln(\sum t_j^{-d})$（$t_j$ 是第 $j$ 次练习距今时间，$d$ 衰减率）。
- **产生式规则 (production)**：if-then，有效用 $P_i$。
- 学习 = 块的激活增长 + 规则效用强化。

> 🪶 ACT-R 的激活公式 = 间隔效应的数学化。$A_i$ 随练习次数增、随时间衰减——和 Ebbinghaus 遗忘曲线一致。

### 2.3 认知负荷（Sweller）

总负荷 $W$ 分三部分：

$$W = W_{intrinsic} + W_{extraneous} + W_{germane} \le W_{capacity}$$

- $W_{intrinsic}$：任务本身难度（不可降，除非拆分）
- $W_{extraneous}$：呈现方式造成的浪费（**要降**）
- $W_{germane}$：用于建构图式的投入（**要保/增**）

教学优化 = 减 $W_{extraneous}$，让 $W_{germane}$ 有空间。

## 三、教育应用

| 应用 | 认知原理 |
|---|---|
| **分块教学** | 工作记忆 4±1 → 一节课 3-5 个新概念 |
| **先行组织者（奥苏贝尔）**| 学新知前给框架 → 减 $W_{extraneous}$ |
| **worked examples** | 给完整解题范例 → 降新手负荷（比刷题有效）|
| **概念图 / 思维导图** | 外显图式结构 |
| **螺旋课程（布鲁纳）** | 同一概念随年龄加深 = 图式迭代 |
| **多模态呈现（Mayer）**| 图文结合 = 双重编码，降负荷 |
| **元认知训练** | 监控自己的图式状态 |

---

## 四、局限

1. **过于"脑内"**，忽视社会文化（维果茨基的批评，见 [`03_constructivism.md`]）。
2. **图式难直接测**：我们只能从行为推断图式，与行为主义的部分难题重现。
3. **发展阶段论被挑战**：皮亚杰四阶段过严，婴儿能力被低估（Baillargeon 违背预期范式）。
4. **个体差异**：ACT-R 等模型参数人各不同，难统一。

---

## 五、RL 接口

认知主义 = **model-based RL**：

| 认知主义 | RL |
|---|---|
| 图式 schema | world model $\hat{P}(s'\|s,a)$ |
| 同化/顺应 | model update（Bayesian / gradient）|
| 不平衡 = KL 大 | model prediction error / surprise |
| 工作记忆容量 | recurrent state / context window |
| 长时记忆 | 训练后的权重 / 外部检索库 |
| 螺旋课程 | curriculum learning（难度递进）|
| 元认知 | meta-RL / learning to learn |

> 🎯 **关键洞察**：认知主义的"建构图式" = model-based RL 的"建 world model"。本项目 [`../讲透世界模型/`] 讲的 AI world model，**就是认知主义在机器上的实现**。两个学科在同一概念上汇合。

---

## 六、与本项目锚点

- **熵治理**：图式 = 压缩世界信息的低熵结构。学一个图式 = 在脑中熵减（用少量参数解释大量现象）。
- **故事原语**：图式天然是"故事"形态（有 agent/act/purpose）。认知主义 ≈ 把世界建构成故事原子。
- **费曼 F2**：F2 测试"能否复述/迁移" = 测试图式是否真建成（vs 字符串记忆）。
- **欺骗动力学**：学生可以"记住答案"骗过形成性测验，但骗不过需要图式迁移的 F2 题。
