# 03 · 建构主义 (Constructivism)

> 旗手：**Vygotsky / Piaget 后期 / Bruner / Papert (constructionism)**。在认知主义"建图式"基础上，加上两个关键修饰：**主动 + 社会**。学习 = 学习者在**社会互动**中**主动**建构意义。
>
> 结构：直觉 → 数学骨架 → 教育应用 → 局限 → RL 接口。

---

## 一、直觉

认知主义说"脑建构图式"。建构主义追问：

> 🔥 图式是**一个人**独自建的吗？

维果茨基说：**不是**。

一个孩子学说话，不是先在脑里建好语法再开口。是**先和大人互动**，大人说、孩子模仿、大人纠正、孩子调整——**语法在社会互动中长出来**，然后才"内化"到脑内。

> "高级心理功能最初是社会的，后来才变成个体的。" —— 维果茨基

认知主义（皮亚杰）= **个人建构**（individual constructivism）。
维果茨基 = **社会建构**（social constructivism）。

建构主义的两个修饰词：
- **主动**：学习者不是被动接收，是主动建构（≠ 行为主义的"被塑造"）。
- **社会**：建构发生在与他人的互动中，借助工具和符号（语言是最大的工具）。

### 最锋利的一刀：ZPD

**最近发展区 (Zone of Proximal Development)**：

$$\text{ZPD} = [\text{独立能做的}, \text{在帮助下能做的}]$$

- 低于下沿 = 太简单，无聊；
- 高于上沿 = 太难，挫败；
- **ZPD 内** = 恰好够难 + 恰好够帮助 = **学习发生的地方**。

教师/AI 的任务：**定位 ZPD，提供支架 (scaffolding)，逐步撤除支架**，直到学生独立能做。

---

## 二、数学骨架

### 2.1 ZPD 的形式化

设学生能力 $\theta$，任务难度 $b$（IRT 语言，见 [`../ASSESSMENT/03_psychometrics.md`]）。

- 独立能做：$P(\text{成功} | \theta, b, \text{无帮助}) > 0.5$ 的任务集合。
- 在帮助下能做：$P(\text{成功} | \theta, b, \text{有帮助}) > 0.5$ 的任务集合。
- ZPD = 两者之差。

支架 = 提供帮助 $h$ 使 $P(\text{成功} | \theta, b, h)$ 进入可学区。教学目标 = 让 $h \to 0$ 时仍能成功（支架撤除）。

### 2.2 内化（维果茨基）

$$\text{社会间 (intermental)} \xrightarrow{\text{内化}} \text{个人内 (intramental)}$$

高级功能轨迹：先是人际间的活动，再变成个人内的认知。**私语 (private speech)** 是中间态——孩子自言自语解题，后来变成默想。

### 2.3 社会建构作为协作学习

协作学习的数学：多 agent 共享信息，群体智慧涌现。群体表现 > 个体之和，当且仅当**信息互补 + 协调成本 < 信息增益**。

> 🪶 这正是多智能体 RL 的核心 trade-off：**协作收益 vs 协调成本**（见 [`../讲透多Agent协作/`]）。

## 三、教育应用

| 应用 | 机制 |
|---|---|
| **支架式教学** | 恰好够帮助，逐步撤除 |
| **协作学习 / 同伴教学** | 社会互动内化 |
| **项目式学习 PBL** | 在真实复杂任务中主动建构 |
| **苏格拉底式研讨** | 提问引导，不直接给答案 |
| **师徒制 / 认知学徒制** | 专家示范 → 学习者做 → 专家撤支架 |
| **LOGO / 建构主义 (Papert)** | 编程让孩子建构知识 |
| **AI 导师 (Khanmigo)** | **不给答案，给提示 = 留学生在 ZPD** ⭐ |

> 🎯 **AI 导师的全部理论根基就是建构主义 ZPD**。Khanmigo 为什么"苏格拉底式不给答案"？因为给答案 = 学生跳出 ZPD，没学到。给提示 = 把学生摁在 ZPD 里挣扎，学习发生。

---

## 四、局限

1. **"纯发现"对新手有害**：Kirschner/Sweler/Clark (2006) "最小指导失败"——纯发现学习的证据远不如直接教学 + worked examples。**建构 ≠ 不教**。
2. **慢**：建构需要时间，时间紧时（应试）效率低。
3. **依赖高质量社会环境**：同伴/教师水平低，社会建构反而拖累。
4. **ZPD 难精确定位**：理论锋利，操作上"恰好够帮助"难量化（AI 时代才可能实时定位）。
5. **文化相对主义风险**：激进建构主义（von Glasersfeld）滑向"真理是建构的"，被批相对主义。

## 五、RL 接口

建构主义 = **model-based + social RL**：

| 建构主义 | RL |
|---|---|
| ZPD | 可学的 state 子集（reward 可达、难度合适）|
| 支架 scaffolding | reward shaping（给中间 reward 引导）|
| 帮助 $h$ | 外部辅助动作 / 奖励加成 |
| 撤支架 | reward shaping 逐步衰减 |
| 内化 | social RL → 单 agent policy 提取 |
| 协作学习 | multi-agent RL / 共享 experience |
| 主动建构 | 主动采样（curiosity-driven）|

> 🎯 **ZPD = curriculum 的可学边界**。AI 训练里的 curriculum learning、AI 导师里的自适应难度，**都是在数学化维果茨基的 ZPD**。

## 六、与本项目锚点

- **故事原语**：建构主义 ≈ 学习者把世界"重述"成自己能上手的故事原子。教学 = 迭代这个故事直到学习者能独立复述。
- **熵治理**：社会互动 = 引入外部低熵（成熟 agent 的图式）帮助学生熵减。支架 = 局部熵减辅助。
- **RL 视角**：ZPD 是本主张"五范式 = RL 五组件"里最可操作的一刀——它定义了 RL 的可学 state 集合。
- **费曼 F2**：F2"卡壳"= 学生在 ZPD 边缘挣扎。教师/AI 的介入点正是 F2。
- **欺骗动力学**：纯建构可能让学习者在 ZPD 外空转（假装在学）。F2 门防这种"伪建构"。

## 七、与认知主义的关系（澄清一个常见混淆）

| | 认知主义（皮亚杰）| 建构主义（维果茨基）|
|---|---|---|
| 建构什么 | 图式 | 意义 |
| 谁建构 | 个人 | 个人 + 社会 |
| 语言的角色 | 工具之一 | **核心中介**（思维源于语言）|
| 发展动力 | 内在成熟 + 不平衡 | 社会互动 |
| 教学重点 | 匹配发展阶段 | **支架 + ZPD** |

两者不是对立，是补充。皮亚杰讲"个体建构机制"，维果茨基讲"社会来源"。现代学习科学两者都认。
