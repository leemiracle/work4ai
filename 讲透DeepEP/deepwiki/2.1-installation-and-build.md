  DeepEP V2 is a high-performance communication library for Mixture-of-Experts (MoE) expert parallelism. This page provides a technical guide to installing and building the library. Unlike V1, DeepEP V2 primarily uses the **NCCL Gin backend**, which eliminates the mandatory dependency on NVSHMEM for the primary communication path, although NVSHMEM support is still maintained for legacy paths [setup.py93-117](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/setup.py#L93-L117)

 
## Prerequisites

 DeepEP V2 requires specific hardware and software environments to leverage its high-performance kernels.

 
| Component | Requirement | Note |
|---|---|---|
| GPU | NVIDIA Hopper (H800/H100) or Ampere (A100) | Hopper (SM90) is the primary target setup.py141-143 |
| CUDA | 12.1+ | Required for SM90 features and JIT setup.py144-145 |
| NCCL | 2.20.5+ | Required for Symmetric Memory and Gin backend deep_ep/__init__.py46-50 |
| PyTorch | 2.1+ | Used for tensor management and build system setup.py10 |

## Environment Variables

 DeepEP V2 relies on several environment variables at both build-time and runtime to configure the NCCL Gin backend and JIT compiler.

 
### Build-time Variables

 These variables are captured during installation by the `CustomBuildPy` class and stored in `deep_ep/envs.py` as `persistent_envs` [setup.py70-90](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/setup.py#L70-L90)

 
| Variable | Description | Default |
|---|---|---|
| EP_NCCL_ROOT_DIR | Path to the NCCL installation root setup.py95 | Auto-detected |
| EP_NUM_TOPK_IDX_BITS | Bit width for topk_idx (32 or 64) setup.py163-164 | 32 |
| TORCH_CUDA_ARCH_LIST | Target GPU architecture (e.g., "9.0") setup.py142 | 9.0 |
| DISABLE_SM90_FEATURES | Set to 1 to disable H100-specific optimizations setup.py130-136 | 0 |
| EP_JIT_CACHE_DIR | Persistent cache directory for JIT-compiled kernels setup.py13 | None |

 
### Runtime Variables

 These variables control the JIT compiler and hardware resource management.

 
| Variable | Description |
|---|---|
| EP_JIT_CACHE_DIR | Directory to store JIT-compiled kernel binaries setup.py13 |
| EP_NIC_NAME | Name of the network interface to use for RDMA (e.g., ib0). |
| EP_OVERRIDE_RDMA_SL | Service Level (SL) for RDMA traffic. |
| EP_SUPPRESS_NCCL_CHECK | Set to 1 to bypass NCCL version verification deep_ep/__init__.py51-52 |

## NCCL Version Verification

 DeepEP V2 is highly sensitive to the NCCL version because it uses low-level symmetric memory APIs. At runtime, the library performs a strict check to ensure the NCCL library loaded by PyTorch matches the one DeepEP was linked against.

 
### `check_nccl_so` Implementation

 The function `check_nccl_so` [deep_ep/__init__.py46-69](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/deep_ep/__init__.py#L46-L69) performs the following steps:

 
 - Scans `/proc/self/maps` to identify the NCCL library currently loaded in the process memory [deep_ep/__init__.py55-59](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/deep_ep/__init__.py#L55-L59)
 - Locates the linked NCCL library using `find_nccl_root()` [deep_ep/__init__.py60-62](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/deep_ep/__init__.py#L60-L62)
 - Performs a binary-level comparison using `filecmp.cmp` [deep_ep/__init__.py66-69](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/deep_ep/__init__.py#L66-L69)
 
 If a mismatch is found, the library aborts to prevent memory corruption or illegal memory access.

 
## JIT Initialization

 DeepEP V2 uses a Just-In-Time (JIT) compilation system to generate optimized kernels for specific MoE configurations (e.g., specific SM counts or expert alignments).

 
### `init_jit` Sequence

 When `deep_ep` is imported, it automatically calls `init_jit()` [deep_ep/__init__.py84](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/deep_ep/__init__.py#L84-L84) This function:

 
 - Locates the CUDA home directory using `find_cuda_home()` [deep_ep/__init__.py21-43](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/deep_ep/__init__.py#L21-L43)
 - Passes the library root, CUDA path, and NCCL path to the C++ backend via `_C.init_jit` [deep_ep/__init__.py71-80](https://github.com/deepseek-ai/DeepEP/blob/01dc3aaa/deep_ep/__init__.py#L71-L80)
