# 农业 · 多光谱遥感 + AI

> **博士级**：卫星 / 无人机遥感 + AI 的农业应用。

## 一、遥感数据

### 1.1 卫星

| 卫星 | 分辨率 | 频段 |
|---|---|---|
| **Landsat 8/9** | 30m | 多光谱（11 波段）|
| **Sentinel-2** | 10m | 多光谱（13 波段）|
| **MODIS** | 250m-1km | 每日 |
| **Planet Labs** | 3m | 每日全球 |
| **Maxar** | 0.3m | 高分辨率 |

### 1.2 无人机

- **多光谱相机**（5-10 波段）
- 分辨率：cm 级
- 灵活 + 即时

### 1.3 关键指数

| 指数 | 公式 | 用途 |
|---|---|---|
| **NDVI** | (NIR-R)/(NIR+R) | 植被健康 |
| **NDWI** | (G-NIR)/(G+NIR) | 水分 |
| **EVI** | 改进 NDVI | 高生物量 |
| **GNDVI** | 绿光替代红 | 叶绿素 |

## 二、AI 任务

### 2.1 作物分类

- **什么作物**（玉米 / 小麦 / 大豆）
- CNN + 时序（Transformer）
- **精度 90%+**

### 2.2 产量预测

- 时序 NDVI + 气象 + 土壤
- **CNN / LSTM / Transformer**
- 国家级 + 田块级

### 2.3 病虫害检测

- 多光谱异常
- 早期预警（5-10 天前）
- **CNN + 主动学习**

### 2.4 灌溉管理

- 土壤湿度（SMAP 卫星）
- AI 预测灌溉需求
- **节水 20-30%**

### 2.5 杂草识别

- 高分辨率图像
- 像素级分割
- **变量喷洒**（See & Spray）

## 三、方法学

### 3.1 时序遥感

- 每周 / 每日卫星
- **RNN / Transformer**
- 考虑云遮（缺失）

### 3.2 多模态融合

- 卫星 + 无人机 + 地面传感器
- 天气 + 土壤
- **多模态 AI**

### 3.3 迁移学习

- 高资源地区（美国 / 欧洲）→ 低资源（非洲）
- **跨域适应**

### 3.4 边缘 AI

- 拖拉机 / 无人机上推理
- **实时**
- TinyML
