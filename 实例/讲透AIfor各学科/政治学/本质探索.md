# 政治学 · 本质探索——权力 + AI

> 权力的本质是什么？AI 让民主更强还是更弱？

## 一、政治学的第一性问题

### 1.1 研究/什么

政治学 = 研究**权力 + 政府 + 公民**。

核心问题：**谁在什么时候以什么方式获得什么**（Lasswell）。

### 1.2 政治的本质

- **权力**：谁控制谁
- **合法性**：为什么服从
- **冲突 + 合作**：利益分配

### 1.3 政治学的"科学性"

- **可实验**？（部分——投票 / 政策）
- **可预测**？（极难——2016 教训）
- **价值中立**？（争议）

> 🎯 **本质**：政治学研究**有权力关系的人类行为**——不能完全脱离价值。
