# 社会学 · LLM 社会模拟数学

> **博士级**：用 LLM agent 模拟社会的方法论。

## 一、社会模拟的历史

### 1.1 经典 ABM（Agent-Based Model）

- **Schelling 隔离模型**（1971）：简单规则涌现
- **Sugarscape**（Epstein-Axtell 1996）
- **规则硬编码**

### 1.2 LLM 时代

- 复杂行为**不硬编码**
- 自然语言交互
- **更接近真实人类**

## 二、LLM 社会模拟架构

### 2.1 单个 agent

```
身份（年龄 / 性别 / 职业 / 价值观）
   ↓
记忆 stream（事件列表）
   ↓
反思（定期总结）
   ↓
规划（每日 / 每周）
   ↓
行动（基于情境）
```

### 2.2 交互

- 两 agent 遇到 → **对话**
- 对话影响记忆 / 关系
- **社会网络涌现**

### 2.3 环境

- 地点（家 / 工作 / 公共）
- 时间步（分钟 / 小时）
- 资源 / 信息

## 三、SmallVille 的涌现（Park 2023）

### 3.1 现象

- **情人节派对**：一个 agent 提出，传播，其他人参加
- **选举**：候选 + 辩论
- **没显式编程**

### 3.2 数学刻画

复杂系统科学：
- **phase transition**（相变）
- **criticality**（临界）
- **emergence**（涌现）

### 3.3 验证

- 模拟结果 vs 真实社会调查
- **校准**难题

## 四、方法学挑战

### 4.1 校准

- LLM 输出 vs 真实人类行为
- **过度信任**风险

### 4.2 复现

- LLM 输出有随机性
- 不同 LLM 行为不同
- **标准化**难

### 4.3 计算成本

- 1000 agent × 1000 步 = 100 万次 LLM 调用
- $1000+
- **小模型 / 蒸馏**

### 4.4 评估

- 怎么判断模拟"真实"？
- 多维度指标
- **争议**

## 六、伦理

### 6.1 LLM 偏见

- 训练于西方 / 英语数据
- **模拟偏向西方社会**

### 6.2 操纵风险

- 模拟可被"调"到想要结果
- **政策误导**

### 6.3 透明度

- 模拟假设必须公开
- **可审计**
