# 地球气候 · 本质探索——地球系统的复杂性

> 气候系统的本质是什么？AI 能预测百年后的地球吗？

## 一、地球系统科学

### 1.1 研究什么

地球 = **大气 + 海洋 + 冰雪 + 陆地 + 生物**的**耦合复杂系统**。

### 1.2 核心挑战

- **非线性**：小输入 → 大输出（蝴蝶效应）
- **多尺度**：秒到亿年
- **耦合**：子系统相互影响
- **临界点**：可能突然崩溃

### 1.3 混沌的本质

Lorenz 1963：天气是**混沌的**——长期预测**理论上不可能**。

**问题**：AI 能突破 Lorenz 极限吗？

## 二、AI 改变了什么

### 2.1 GraphCast 的意义

- 2023 完胜 ECMWF——**40 年标杆被推翻**
- 但这是**短期预报**（10 天）
- **长期 / 气候**呢？

### 2.2 从数值到 AI

经典：**Navier-Stokes + 超算**。
AI：**学物理场映射**。

**本质改变**：从**第一性原理**到**数据驱动**。

### 2.3 物理一致性

- GraphCast 没有**显式物理约束**
- 但**涌现**学到守恒
- **这是理解吗？**
