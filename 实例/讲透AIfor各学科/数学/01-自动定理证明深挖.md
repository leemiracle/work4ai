# 01 · 自动定理证明深挖

> **博士级****：从 ATP 到 AlphaProof 的演进。

## 一、自动定理证明（ATP）的历史

### 1.1 1950s 开端

- **Logic Theorist**（Newell-Simon 1956）：证明罗素《数学原理》定理 38/52
- **GPS**（General Problem Solver, 1957）：means-ends analysis

### 1.2 1960s-1970s 方法

- **归结原理**（Robinson 1965）：resolution
- **Prolog**（Colmerauer 1972）：逻辑编程
- **Boyer-Moore**（1973）：递归证明

### 1.3 1970s-2000s 成熟

- **NQTHM / ACL2**（Boyer-Moore / Kaufmann）
- **HOL**（Gordon）
- **Coq**（Huet / Paulin-Mohring）
- **Isabelle**（Paulson）
- **Mizar**（Trybulec）
- **PVS**（Owre / Rushby）

### 1.4 2010s AI 增强

- **sledgehammer / HOL hammer**：找已有引理
- **GPT-f**（Polu-Sutskever 2020）：神经网络引导
- **MetaMath** + ML

## 二、Lean 的崛起（2020+）

### 2.1 为什么是 Lean

- **Dependent Type Theory** 基础
- **程序 = 证明**（Curry-Howard）
- **mathlib** 社区驱动
- **Leonardo de Moura** 设计

### 2.2 mathlib

- **100 万+ 行**
- 3000+ 贡献者
- 覆盖：分析 / 代数 / 拓扑 / 数论 / 几何 / 类域论 /...

### 2.3 关键形式化

- **Fermat 大定理**（2023）
- **Liquid Tensor Experiment**（Scholze perfectoid, 2022）
- **4 色定理**（Gonthier 2005, Coq）
- **Kepler 猜想**（Hales Flyspeck, 2014）

## 四、AlphaProof（2024）

### 4.1 架构

```
自然语言 IMO 题
   ↓ Gemini LLM
翻译为 Lean
   ↓ AlphaZero 风格 MCTS
证明搜索（数百万 Lean 策略）
   ↓ Lean 验证
通过 = True proof
```

### 4.2 IMO 2024 成绩

- **4/6 题**（银牌水平）
- 包括最难的几何题（AlphaGeometry 2）
- **Algebra 4**: 完美
- **不等式 2**: 部分失败

### 4.3 意义

- **AlphaGo 时刻 for 数学**
- 2025-2026 目标：金牌
- **改变数学研究**
