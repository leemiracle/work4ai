# 文学 · 早期经典（古希腊-2010s）

## 一、Aristotle——诗学
- 悲剧理论：情节 / 人物 / 思想
- 模仿（mimesis）
- **西方文学理论开端**

## 二、Dante 1320——神曲
- 中世纪文学巅峰
- 俗语写作的开创
- **意大利语之父**

## 三、Shakespeare 1600s
- 戏剧 + 诗歌
- 人性的最深处
- **英语文学之神**

## 四、 Romanticism 1800s
- Wordsworth / Coleridge
- 情感 / 自然 / 个体
- **浪漫主义革命**

## 五、Modernism 1900s
- Joyce / Eliot / Woolf
- 意识流 / 碎片化
- **现代文学**

## 六、Barthes 1967——作者已死
**Roland Barthes**：
- "The Death of the Author"
- 读者创造意义
- **后结构主义**

## 七、数字人文 1990s-
- TEI（文本编码）
- 文本挖掘
- Moretti 远读（2005）
