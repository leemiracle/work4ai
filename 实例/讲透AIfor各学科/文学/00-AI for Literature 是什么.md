# 00 · AI for Literature 是什么

> **第一性问题**：文学是**人类心智的最高表达**——故事 / 诗歌 / 戏剧。AI 时代，**机器能创作文学吗**？同时 AI 也在改变**文学研究**——大规模文本分析 / 风格学 / 比较。

## 一、AI 与文学的两个方向

### 1.1 AI 创作

- LLM 写小说 / 诗歌 / 剧本
- **GPT-4 / Claude** 创意写作
- 争议：算文学吗？

### 1.2 AI 研究

- 数字人文
- 大规模文本分析
- **远读**（Moretti）

## 二、AI 文学创作

### 2.1 诗歌生成

- **GPT-4 / Claude** 写诗
- 中国古诗 / 现代诗
- **风格迁移**（模仿特定诗人）

### 2.2 小说 + 故事

- 短篇小说
- 长篇（章节续写）
- **AI + 人类协作**

### 2.3 剧本

- 电影 / 电视 / 游戏
- 互动叙事（AI Dungeon）

### 2.4 局限

- **缺乏原创性**（基于训练数据）
- **情感深度**争议
- **风格重复**

## 三、AI 文学研究

### 3.1 远读（Distant Reading）

- Moretti 概念
- 大规模文本分析
- **LDA / BERT**

### 3.2 风格学（Stylometry）

- 作者识别
- **联邦党人文集**（Mosteller-Wallace）
- **Deep stylometry**

### 3.3 文学网络

- 人物关系图
- 情节结构
- **网络分析**

### 3.4 文学史

- 词频历史（Google Ngrams）
- 主题演化
- **diachronic embeddings**

## 四、关键争议

### 4.1 "随机鹦鹉" vs 创造

- Bender 等批评

### 4.3 文学的本质

- 机器能"创造"吗？
- 详见 [`哲学`](../哲学/)

## 领域知识深化：文学研究方法与数字人文

| 方法 | 核心思想 | AI 工具 |
|---|---|---|
| **远读(Distant Reading)** | 用计算分析海量文本模式 | 主题模型/词频统计/网络分析 |
| **近读(Close Reading)** | 深入文本细节/修辞/结构 | LLM 辅助标注/对比 |
| **叙事学** | 叙事结构/视角/时间线 | 情节图/情感弧线 |
| **文体学** | 词汇/句法/风格量化 | Stylometry(作者鉴定) |
| **互文性** | 文本间的引用/改写关系 | 引用网络/语义相似度 |

**关键理论家**：Moretti(远读) / Barthes(作者之死) / Genette(叙事学) / Jockers(宏观分析)

**数字人文工具**：Voyant(文本分析) / Gephi(网络) / NLTK/spaCy(NLP) / Topic Modeling
