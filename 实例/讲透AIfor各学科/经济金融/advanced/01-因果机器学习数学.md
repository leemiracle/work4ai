# 经济金融 · 因果机器学习数学

> **博士级**：EconML / Double ML 的数学。

## 一、为什么需要因果 ML

### 1.1 问题

**估计处理效应**（Treatment Effect）：
- 单个效果：$\tau_i = Y_i(1) - Y_i(0)$
- 平均：$\text{ATE} = \mathbb{E}[Y(1) - Y(0)]$
- 异质：$\text{CATE}(x) = \mathbb{E}[Y(1) - Y(0) | X = x]$

### 1.2 挑战

**根本问题**：每个个体只观察到一个 $Y_i$（$T=1$ 或 $T=0$）。

## 二、经典方法回顾

### 2.1 RCT（随机对照试验）

随机分配 $T$ → 直接比较。但**伦理 / 成本 / 不可能**。

### 2.2 倾向得分（PSM）

**Rosenbaum-Rubin 1983**：

$$P(T=1|X) = e(X)$$

匹配相同 $e(X)$ 的个体。

**问题**：高维 $X$ 时 $e(X)$ 估计难。

## 三、Double ML（Chernozhukov 2018）

### 3.1 核心思想

用 ML 估计 nuisance functions，然后做"debias"。

### 3.2 数学

假设 **partially linear model**：

$$Y = \theta D + g_0(X) + \epsilon, \quad \mathbb{E}[\epsilon|D, X] = 0$$

$$D = m_0(X) + \nu, \quad \mathbb{E}[\nu|X] = 0$$

- $\theta$ = 处理效应（要估）
- $g_0, m_0$ = nuisance

**步骤**：
1. ML 估 $\hat{g}$（$Y$ on $X$）
2. ML 估 $\hat{m}$（$D$ on $X$）
3. 计算 residuals：$\tilde{Y} = Y - \hat{g}(X)$, $\tilde{D} = D - \hat{m}(X)$
4. OLS：$\tilde{Y}$ on $\tilde{D}$ → $\hat{\theta}$

### 3.3 性质

- **$\sqrt{n}$-consistent + asymptotic normal**
- ML 估计慢收敛也行（只要 $n^{-1/4}$）
- **置信区间**

## 四、Causal Forests（Wager-Athey 2018）

### 4.1 核心

随机森林，但**预测 CATE**。

### 4.2 数学

每棵树估 $\hat{\tau}_b(x)$，平均：

$$\hat{\tau}(x) = \frac{1}{B}\sum_b \hat{\tau}_b(x)$$

**关键**：诚实分裂（honest splitting）保证一致性。

## 五、EconML 工具库

### 5.1 主要方法

- **DML**：Double ML
- **DR Learner**：Doubly Robust
- **Causal Forest**
- **Meta-learners**（T/S/X learner）

### 5.2 应用

- **政策评估**：减税 / 教育
- **个性化治疗**：医学
- **uplift modeling**：营销
