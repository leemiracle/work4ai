# 经济金融 · LLM 经济模拟前沿

> **博士级**：LLM 多智能体模拟经济——经济学的新方法论。

## 一、为什么用 LLM 模拟经济

### 1.1 经典经济学模型局限

- **DSGE**（动态随机一般均衡）：假设太强
- **Agent-Based Model (ABM)**：行为规则硬编码
- **缺人类复杂性**（理性 + 非理性混合）

### 1.2 LLM 的优势

- **复杂行为**：不用硬编码
- **自然语言交互**
- **多角色**（消费者 / 企业 / 政府）

## 二、关键工作

### 2.1 SmallVille（Park 2023）

- 25 个 LLM agent 模拟小镇
- 涌现：情人节派对 / 选举
- **意义**：社会模拟可以"现实"

### 2.2 Homo Silicus（Horton 2023）

- LLM 做经济实验被试
- 对比人类被试
- **结果**：部分匹配

### 2.3 Phantom（2024）

- 完整经济模拟
- 政策测试（减税 / 加息）
- **政府/央行可用**

## 三、模拟架构

### 3.1 典型流程

```
1. 设计 agent（人格 / 目标 / 资源）
   ↓
2. 环境设定（市场 / 政策 / 历史）
   ↓
3. 多轮交互（agent 间 / agent 与环境）
   ↓
4. 涌现观察 + 数据分析
```

### 3.2 关键组件

- **Memory**（agent 记忆）
- **Reflection**（反思）
- **Planning**（规划）
- **Action**（执行）

## 四、应用

### 4.1 政策模拟

- "减税 5% 影响经济多少？"
- LLM agent 模拟消费 / 投资 / 就业
- **央行 / 财政部** 可用

### 4.2 行为经济学

- 测试认知偏差（损失厌恶 / 锚定）
- LLM 表现人类偏差？
- **心理学 + 经济学**

### 4.3 市场模拟

- 多企业竞争
- 价格 / 创新 / 广告
- **战略模拟**

### 4.4 危机模拟

- 金融恐慌 / 银行挤兑
- **系统性风险**

## 五、挑战

### 5.1 可信度

- LLM 是不是"真经济行为"？
- 复现难
- **过度信任**风险

### 5.2 计算成本

- 1000 agent × 1000 轮 = 100 万次 LLM 调用
- 成本 $1000+
- **小模型 / 蒸馏**

### 5.3 校准

- 怎么让模拟匹配真实经济数据
- **缺少"基准"**

## 六、前沿方向

### 6.1 多模态经济模拟

- 加新闻 / 图像 / 视频
- **更接近真实**

### 6.2 LLM + ABM 混合

- LLM 做核心决策
- 经典 ABM 做大规模
- **平衡成本 + 复杂性**

### 6.3 政策制定

- 政府用 LLM 模拟测试政策
- **立法前测试**
- IMF / Fed 关注

## 七、博士级练习

1. 用 LangChain + GPT-4 模拟简单市场
2. 测试 LLM 的行为偏差
3. 校准 SmallVille 到真实数据
