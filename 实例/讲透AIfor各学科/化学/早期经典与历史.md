# 化学 · 早期经典论文深读（1960s-2018）

> **博士级**：计算化学的奠基——从分子力学到机器学习势能。

## 一、分子力学的起源（1940s-1960s）

### 1.1 Westheimer 1946

- 第一个**分子力学**计算
- 手算有机分子构象
- 用经典力学近似量子

### 1.2 Allinger MM 系列（1960s-1990s）

- **MM2 / MM3 / MM4**：分子力场
- 键长 / 键角 / 扭转 + van der Waals
- **标准工具几十年**

### 1.3 影响

- 药物设计的计算基础
- 后来的 ML 势能函数**替代**这些

## 二、量化计算（1970s-2000s）

### 2.1 Kohn-Sham DFT（1965）

**密度泛函理论**——Walter Kohn（1998 Nobel）

- 用电子密度（而非波函数）描述系统
- 大幅降低计算量
- **化学的标准工具**

### 2.2 Hartree-Fock + Post-HF

- 从 1930s Hartree-Fock 到 CCSD(T)
- 精度阶梯
- **化学精度**（~1 kcal/mol）

### 2.3 Car-Parrinello 1985

- **Ab initio MD**
- 同时优化电子 + 原子
- 开创**第一性原理分子动力学**

## 三、定量结构-活性关系（QSAR）

### 3.1 Hansch 1962

- **线性回归**预测生物活性
- $\log(1/C) = a \log P + b \sigma + c$
- QSAR 的开端

### 3.2 3D-QSAR（1980s）

- **CoMFA**（Cramer 1988）
- 3D 场 + PLS
- 药物设计标准

### 3.3 ML QSAR（2000s）

- 随机森林 / SVM 替代线性
- **MoleculeNet** benchmark
- 现代 GNN 的前驱

## 四、分子对接（Docking）

### 4.1 Kuntz 1982——DOCK

- 第一个自动对接程序
- 几何匹配
- **药物虚拟筛选**开端

### 4.2 Autodock（1990s）

- Morris 1998（Autodock 4）
- 半柔性对接
- **最广泛使用的对接工具**

### 4.3 Glide（2003+）

- Schrödinger 商业
- 精度提升
- 行业标准之一

## 五、反应数据库 + 预测

### 5.1 Corey-Wipke 1969——OCSS

- 第一个**逆合成**程序
- 人机交互
- 后续 LHASA

### 5.2 Reaxys / SciFinder（1990s-）

- 大规模反应数据库
- 信息检索
- 现代 AI 反应预测的数据基础

### 5.3 Automated retrosynthesis

- **Segler 2018**：深度学习逆合成
- **Schwaller 2019**：Molecular Transformer
- 从规则 → 数据驱动

## 六、机器学习势能（NEP）

### 6.1 Behler-Parrinello 2007

**Behler & Parrinello, "Generalized Neural-Network Representation of High-Dimensional Potential-Energy Surfaces"** *Phys. Rev. Lett.* 2007.

### 6.2 核心创新

- 用**神经网络近似 DFT 势能**
- 高维（>1000 原子）可行
- BPNN 架构：每个原子一个 NN

### 6.3 意义

- **NEP 领域的开端**
- 加速 MD 1000×
- 后续 SchNet / NequIP / MACE 都基于此

### 6.4 2007-2024 演进

```
2007  Behler-Parrinello BPNN
   ↓
2017  SchNet (Schütt)
   ↓
2018  DimeNet (Gasteiger)
   ↓
2020  GemNet
   ↓
2022  NequIP / Allegro / MACE
   ↓
2024  EquiformerV2 / MACE-MP-0
```

## 七、早期商业计算化学

### 7.1 Schrödinger（1990-）

- **FEP+**：自由能微扰
- 行业标准
- 2020 IPO

### 7.2 OpenEye

- **ROCS / OMEGA**
- 3D 形状匹配
- 学术友好

### 7.3 CCDC（Cambridge Crystallographic Data Centre）

- **CSD**（Cambridge Structural Database）
- 100 万+ 晶体结构
- **材料/药物设计的数据基础**
