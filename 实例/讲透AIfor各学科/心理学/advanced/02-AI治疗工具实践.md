# 心理学 · AI 治疗工具实践

> **博士级**：AI 心理治疗的工程 + 伦理。

## 一、AI 治疗的兴起

### 1.1 市场需求

- 全球**心理健康危机**（COVID 后加剧）
- 治疗师短缺（美国 1.6 亿县缺精神科医生）
- **成本**：传统治疗 $100-300/小时

### 1.2 AI 解药

- 24/7 可用
- 低成本 / 免费
- 匿名（减少耻感）

## 二、关键产品

### 2.1 Woebot

- **Alison Darcy**（Stanford）创立 2017
- 基于 CBT（认知行为疗法）
- 规则 + LLM 混合
- **临床研究**：减少抑郁症状（JMIR）

### 2.2 Wysa

- 印度起家
- AI 聊天 + 人类治疗师（必要时）
- 400 万+ 用户

### 2.3 Replika

- 陪伴 AI（非治疗）
- 但很多用户当治疗用
- **争议**：情感依赖

### 2.4 ChatGPT / Claude

- 通用 LLM 被当治疗用
- **风险**：无临床验证 + 误导

## 三、FDA 监管

### 3.1 第一个 AI 治疗工具（2024）

- **FDA 批准**：首个 AI 治疗抑郁
- 标志：AI 治疗合法化

### 3.2 监管框架

- SaMD（Software as a Medical Device）
- 临床证据要求
- 算法透明

## 四、CBT + AI

### 4.1 CBT（认知行为疗法）

- 结构化（10-20 周）
- 识别 → 挑战 → 重塑负面思维
- **适合 LLM**

### 4.2 AI 实现

```
用户陈述负面想法
   ↓ LLM 识别认知扭曲
分类（catastrophizing / overgeneralization）
   ↓ LLM 提挑战问题
引导用户重塑
   ↓
记录情绪 + 进度
```

### 4.3 效果

- **轻度 - 中度抑郁 / 焦虑**：有效
- **重度**：必须人类治疗师
- **辅助**：人类治疗的补充

## 五、关键挑战

### 5.1 临床有效性

- 随机对照试验少
- **出版偏差**
- **长期效果**未知

### 5.2 伦理

- **依赖风险**：用户依赖 AI
- **误诊**：AI 错过严重症状
- **自杀风险**：检测能力？

### 5.3 隐私

- 心理数据极敏感
- **HIPAA / GDPR**
- 数据使用透明

### 5.4 公平

- 高资源语言优先
- 低收入群体受益？
- **算法偏见**
