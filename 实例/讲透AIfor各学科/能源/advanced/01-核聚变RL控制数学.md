# 能源 · 核聚变 RL 控制数学

> **博士级**：DeepMind 控制托卡马克的 RL 数学。

## 一、核聚变的核心挑战

### 1.1 托卡马克

- 等离子体加热到 **1 亿度**（比太阳核心还热）
- 用**磁场**约束
- 避免接触容器壁

### 1.2 控制难题

- **非线性** + **混沌**
- **多目标**：形状 / 位置 / 稳定性
- **实时**：ms 级响应

经典控制（PID）不够。

## 二、DeepMind 2022 *Nature*

### 2.1 方法

**RL agent** 控制 TCV（EPFL 瑞士）托卡马克：

```
状态 s：等离子体诊断（位置 / 形状 / 电流）
动作 a：磁场线圈电流
奖励 r：跟踪目标形状 + 避免破裂
```

### 2.2 训练

- **仿真预训练**（精英物理模拟器）
- **Sim2Real**（迁移到真实）
- **PPO** 算法

### 2.3 成就

- 控制多种**等离子体形状**
- 实时（ms 级）
- **首次 RL 控制真实聚变设备**

## 三、RL 控制的数学

### 3.1 MDP 形式化

$$\max_\pi \mathbb{E}\left[\sum_t \gamma^t r(s_t, a_t)\right]$$

- $\pi(a|s)$：策略
- $\gamma$：折扣
- $r$：奖励

### 3.2 PPO 算法

详见 [`讲透RL/02`](../../../讲透RL/02-策略梯度与PPO.md)。

核心：clip importance ratio + 信赖域。

### 3.3 Sim2Real

- **域随机化**：仿真物理参数随机
- 部署到真实——robust policy

## 四、为什么经典方法不够

### 4.1 PID 局限

- 线性控制器
- 难处理非线性等离子体
- **手动调参**

### 4.2 模型预测控制（MPC）

- 优化未来轨迹
- 但**计算慢**（ms 级难）

### 4.3 RL 优势

- 离线训练，在线推理快
- **端到端学习**
- 可优化复杂奖励

## 五、当前挑战

### 5.1 Sim2Real gap

- 仿真不精确
- **真实等离子体**更复杂

### 5.2 安全

- 失败代价高（设备损坏）
- **约束 RL**

### 5.3 长期稳定

- RL 训练于短时段
- 长时稳定（分钟+）挑战
