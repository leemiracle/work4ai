# 人类学 · 古 DNA + 演化分析

> **博士级**：古基因组学的 AI 分析。

## 一、古 DNA 的革命

### 1.1 Pääbo 的开创

- **2022 Nobel Medicine**：古基因组学
- 测序尼安德特人（2010）
- 发现丹尼索瓦人（2010）

### 1.2 数据

- 数千古基因组
- **Allen Ancient DNA Resource**
- 覆盖 5 万年人类史

### 1.3 AI 的角色

- 处理海量基因数据
- 推断**人群关系 / 迁徙 / 混血**

## 二、关键方法

### 2.1 基因组比对

- 古 DNA 降解（片段短）
- **AI 比对 + 重建**
- 比经典 BLAST 准

### 2.2 群体遗传学 + ML

- **PCA**（主成分）：人群聚类
- **ADMIXTURE**：混血比例
- **TreeMix**：迁移树

**ML 增强**：
- **核 PCA** / **UMAP** / **t-SNE**
- **深度学习**的人群分类

### 2.3 演化推断

- **Bayesian skyline**：历史人口规模
- **dN/dS**：自然选择
- **IBD**（Identity by Descent）：亲缘

**AI**：
- **变分推断** 加速
- **图神经网络** 的人群关系

## 三、关键发现

### 3.1 走出非洲（强化）

- 多波迁徙
- 与尼安德特人 / 丹尼索瓦人混血
- 非非洲人 ~2% 尼安德特基因

### 3.2 印欧语系起源

- **Yamnaya 文化** 扩散
- 古 DNA 证实
- **Haak 2015 Nature**

### 3.3 英国 / 欧洲历史

- 多次大规模替换
- Beaker 文化
- **Olalde 2018 Nature**

### 3.4 美洲 / 亚洲

- 多波迁徙到美洲
- 东亚人群演化
- **Yang 2020 Nature**

### 3.5 中国古 DNA

- 中原 / 北方 / 南方
- 汉族形成
- 多源融合
