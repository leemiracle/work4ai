# 讲透 AI for 各学科

> 把 AI 应用到**所有学科**——一个一个来，每个博士级深做。
>
> 与 [`讲透AI应用全景`](../讲透AI应用全景/) **互补**：
> - 应用全景 = 7 大领域总览（每领域 1 篇综述）
> - 本系列 = **每个学科独立深做**（4-6 篇博士级内容）
>
> **博士级标准**：不只讲"AI 应用了什么"，而是问——**AI 改变了这个学科的方法论吗？认识论冲击是什么？开放问题在哪？**

## 怎么用

- **想理解 AI 在某学科的影响**：直接看该学科的 00
- **想做研究**：advanced/ 论文清单 + 开放问题
- **想跨学科比较**：看本 README 的学科地图 + [`讲透AI应用全景/00`](../讲透AI应用全景/00-AI应用的统一框架.md) 的统一框架
