# 复杂系统 · 城市科学 + 经济物理

> **博士级**：AI 在城市 / 经济复杂系统的应用。

## 一、城市科学（Urban Science）

### 1.1 Bettencourt 2013 *Nature*

- **城市规模律**（scaling law）
- 人口 ↑ 1.15× → 收入 / 创新 / 犯罪 ↑ 1.15×（超线性）
- 基础设施 ↓ 0.85×（亚线性）

### 1.2 AI + 城市

- **交通流预测**（Uber / Lyft）
- **犯罪预测**（争议：算法歧视）
- **能源消耗优化**
- **城市规划**

### 1.3 West 2017 *Scale*

- 生物 / 城市 / 公司的统一规模律
- AI 验证 + 推广

## 二、经济物理（Econophysics）

### 2.1 核心

- 用统计力学方法研究经济
- 财富分布（幂律）/ 市场崩盘

### 2.2 关键发现

- **财富分布** ≈ Pareto（幂律）
- **市场波动**：自相似 / 长期记忆
- **网络效应**：金融危机传染

### 2.3 AI 方法

- **GNN** 分析金融网络
- **异常检测**（崩盘预测）
- **agent-based + LLM**（详见 [`经济金融/advanced/02`](../../经济金融/advanced/02-LLM经济模拟前沿.md)）
