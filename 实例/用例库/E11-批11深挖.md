### plotly/dash
- **DeepWiki**：30 章；Overview+1.3 React 兼容矩阵

- **核心算法/协议**：连接韧性三算法（WebSocketManager.ts）：① 指数退避+抖动重连 `delay = min(1s*2^retry + rand*1000, 30s)`，显式 connect 或用户活动将 retryCount 归零（L265-289, L131-136）；② 心跳 ping/ack + 10s 无 ack 则 `close(4000)`；③ 5 分钟非心跳活动静默则 `close(4001,'Inactivity timeout')`，且 1000/4001 不触发重连（L206-208）——应用层 close code 当协议语义用。断线期间 send 进 messageQueue、重连后 flush（L115-138）。服务端批量消息在 Router 侧按 renderer 聚合 SET_PROPS 成 `SET_PROPS_BATCH` 一次投递，组内顺序保持（MessageRouter.ts:L112-159）。
- **设计模式与工程决策**：① JupyterLab 集成走 kernel comm target `'dash'`，Python 侧经 comm消息弹 iframe Widget（jupyterlab/src/index.ts:L99-120）——notebook 内嵌服务端口 UI 的零重构方案；② 共享 Worker 使 N 个 tab 只有一条服务端连接，回调合并天然去重；③ 组件库（dcc/html/table）从 React 源自动生成 Python/R/Julia 绑定+完整类型标注（DW Component Generation System）。
- **教学映射**：透视Agent系统工程（回调=受限 RPC 的十年演化）+ 上下文缓存（批量 set_props 合并投递）
- **一句话本质**：把"Python 函数绑定 DOM 事件"做成带心跳、退避和共享连接总线的工业协议。

## 组内横断发现

1. **确定性外壳圈住 LLM 的三重同构**：12-factor-agents 的 `while(true)+Thread reducer`（agent.ts:L89-114）、Archon 的 YAML DAG+`loop.until`（README:L43-74）、pandas-ai 的 generate→execute→error-回喂 retry（agent/base.py:L171-216）是同一条公理的三种语法——"own your control flow"跨 TS/Python/声明式三语系成立；连 learnopencv 都在教 LangGraph self-correcting agent，范式已外溢出 Agent 圈。
2. **HITL 收敛为"事件回填"而非控制流**：humanlayer 把审批结果作为 tool_response 事件 push 回 Thread（cli.ts:L26-27）、Archon 用 `until: APPROVED + interactive: true` 审批节点、vanna 用 WorkflowHandler 确定性命令旁路 LLM——三仓都把"等人类"实现为数据流中的一个可持久化事件，而非阻塞调用。
3. **浏览器信任模型的双面硬币**：NeoPass 用 defineProperty+Proxy 伪造 visibility/hasFocus/rAF（main.js:L21-163）与 stagehand evals 的 ActionTarget/WaitSpec 精确契约（targets.ts）共享同一前提——DOM 事件层不可信；前者证明感知可欺骗，后者干脆绕过 DOM 直连 CDP 并把动作抽象成六种可验证寻址，防御与对抗在 API 设计层对峙。
4. **版本转世的考古学**：vanna `__init__.py:9` 的 0.1.0 vs `pyproject.toml:7` 的 2.0.2 暴露重写过渡期新旧魂体共存；Archon v1 Python RAG 整体封进 archive 分支；learnopencv 干脆 vendor 整棵 gsplat/DINO 上游——三种"携带前世行李"策略（忘改版本号/分支木乃伊/直接内嵌）。
5. **零依赖安全/基建件的复兴**：Archon auth-service 手写 node:http+HMAC+timingSafeEqual+开放重定向白名单（server.js:L35-65）、gin-vue-admin Cutter 每条日志重算文件名开闭句柄（cutter.go:L58-95）、plotly SharedWorker 单连接多 renderer 复用——在依赖膨胀时代，核心件"少依赖+显式协议"（dash 连 close code 4000/4001 都语义化）反而成为可审计性的卖点。
