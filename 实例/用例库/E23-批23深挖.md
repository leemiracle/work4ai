## 组内横断发现

1. **差分计算是本批的共同算法底座**：cocoindex（输入+AST 双指纹 Δ 重算）、Crucix（跨 sweep 语义去重 delta engine）、wandb（事务日志增量重放/`wandb sync`）、tensorzero（variant A/B 差分）——"只算变化"已从缓存技巧升格为跨仓架构原则。
2. **跨语言边界三态样本齐全**：进程内 FFI（cocoindex PyO3/maturin）、进程外 IPC（wandb protobuf+UDS+mailbox slot 信箱）、HTTP 代理+装饰器桥（ida-pro-mcp `@idasync` execute_sync 钉主线程）——同一"Python 前端×系统级后端"问题的三种工业解，可作对照课三联。
3. **Skills 正在成为新的包管理对象**：Orchestra（canonical 存储+symlink+lock+7 agent 检测+CI 同步三注册表）与 walkinglabs（harness-creator skill）、cocoindex（仓库内 skill 教 agent 写本框架 API）、EmbraceAGI（收录 awesome-claude-skills-zh）四仓互证："给 agent 的知识"已具备 npm 式分发、版本与多市场同步形态。
4. **安全旁路的共同语法：显式标记+可过期+可审计**：humanlayer `DangerouslySkipPermissions` 带过期时间自动回收 vs ida-pro-mcp `@unsafe` 集合+60s 超时+输出截断缓存+netnode trace——两仓不约而同拒绝永久豁免，"危险"必须是一等公民数据而非注释。
