## 🎯 投稿路径（按门槛递增）

```
                      ┌─────────────────┐
                      │  Personal blog  │  ← 第 1 步：写 5 篇
                      │  (季度产出)     │
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │  arXiv preprint │  ← 第 2 步：建立时间戳
                      │  (无需 peer)    │
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │ Workshop paper  │  ← 第 3 步：50-70% 录取
                      │ @ NeurIPS/ICLR  │     新人入口！
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │  Main track     │  ← 第 4 步：25% 录取
                      │  @ NeurIPS/ICLR │     目标
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │ Oral / Spotlight │  ← 第 5 步：< 5%
                      │  + Best Paper   │     顶级专家认证
                      └─────────────────┘
```

**典型时序（新人）**：
- 月 1-6：精读 + 复现
- 月 7-12：第 1 篇 blog
- 月 13-18：第 2-3 篇 blog + arXiv preprint
- 月 19-24：第 1 篇 workshop paper 投稿
- 月 25-36：第 1 篇 main track 投稿

## 📰 论文 / 资讯日常入口

### [必] arXiv daily（每天）
- **URL**: `arxiv.org/list/cs.LG/recent` / `cs.CL/recent` / `cs.AI/recent`
- **更友好**: `huggingface.co/papers`（HF Daily Papers，每日精选）
- **AK 速报**: Twitter `@_akhaliq` 每天发 5-15 篇
- **机器人**: Telegram 频道、Discord bot 都有
- **每天 15 分钟**：扫标题，感兴趣的存到 Notion / Obsidian

### [必] Hugging Face Daily Papers ⭐⭐⭐⭐⭐
- **URL**: `huggingface.co/papers`
- **特点**: 每日由社区 + HF 团队精选 20-40 篇高质量论文
- **入门动作**: 每天早上 15 分钟扫一遍

### [重] Papers with Code
- **URL**: `paperswithcode.com`
- **特点**: 论文 + 代码 + benchmark + SOTA 表
- **何时用**: 找 baseline / 比较方法时

### [重] Semantic Scholar
- **URL**: `semanticscholar.org`
- **特点**: 免费论文搜索 + citation graph
- **何时用**: 查作者所有论文 / 引用关系

### [重] Connected Papers
- **URL**: `connectedpapers.com`
- **特点**: 输入一篇论文，生成相关论文图
- **何时用**: 进入新领域时建文献图

### [选] arXiv Sanity
- **URL**: `arxiv-sanity-lite.com`
- **特点**: 个性化推荐 arXiv 论文

## 🛠️ Paper 阅读工具

### [必] 工具栈
- **Zotero**（`zotero.org`）— 论文管理，免费
- **Notion / Obsidian** — 笔记，论文摘要
- **chatpdf / humata.ai / sci.space** — PDF 问答
- **Connected Papers**（前述）— 文献图

### [必] 读论文方法（Karpathy 法）
1. **第一遍**（5 分钟）：标题 + abstract + intro + 结论 + 图
2. **第二遍**（30 分钟）：method + experiments，跳过细节
3. **第三遍**（2-3 小时）：每句话理解 + 推导 + 找 reference
4. **第四遍（如果是必复现）**：跑代码 + 重现实验
