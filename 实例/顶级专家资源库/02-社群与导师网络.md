# 02 · 社群与导师网络（P0，本周必做）

> **铁律**：知识可独学，专家身份不能。导师的核心作用不是教知识（书都有），是**指出你看不到的盲区 + 给资源 + 撕你的工作**。AI 永远替代不了真人 reviewer。

---

## 🎯 三层社群金字塔

```
                    ┌──────────────────┐
                    │   Mentor (1:1)   │  ← 最难进，价值最高
                    │  MATS / SOAR /   │
                    │  APART / PhD     │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  Cohort (1:N)    │  ← 中间层，结构化训练
                    │  Fellowship /    │
                    │  Study Group     │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │ Community (N:N)  │  ← 入口层，先泡这
                    │ Discord / Forum  │

                    └──────────────────┘
```

## 🟢 入口层（Community）— 本周必加

### [必] 1. EleutherAI Discord ⭐⭐⭐⭐⭐
- **URL**: `eleuther.ai/community`（直接点 Join Discord）
- **是什么**: 全球最活跃的开源 AI 研究社群。2020 年由 Connor Leahy 创立，从 GPT-3 讨论群成长为顶尖非营利研究所。核心方向：**interpretability / alignment / 大模型训练**。员工+志愿者+合作者一视同仁。
- **何时用**: 立即潜水。先 2 周不发言，只看 `#papers`、`#interp`、`#alignment` 频道每天讨论什么。
- **入门动作**:
  1. 加 Discord，自我介绍："Chinese self-learner, interested in mechanistic interpretability, currently doing [你的当前项目]"
  2. 关注 #papers / #interp / #alignment 三个频道
  3. 第 2 周回答一个比你新的人的问题（教是最好的学）

### [必] 2. ML Collective Open Collab Discord ⭐⭐⭐⭐⭐
- **URL**: `mlcollective.org/community/`
- **是什么**: 501(c)(3) 非营利，专门为新人研究员提供 free mentorship。比 EleutherAI 更"教育向"。有 The Lab（更像正式实验室）+ Open Collab（开放社区）。
- **何时用**: 立即加。
- **入门动作**: 在 `#introductions` 频道自我介绍，订阅 `#dlct` 频道。

### [必] 3. MLC DLCT 阅读组（Deep Learning: Classics and Trends）⭐⭐⭐⭐⭐
- **URL**: `mlcollective.org/dlct/`
- **邮件组**: `groups.google.com/g/deep-learning-classics-trends`（必订阅）
- **是什么**: Rosanne Liu（前 Uber AI Labs）2018 年起办的周读论文会。**每周五**线上，5000+ 邮件列表，平均 80 人参会。**允许 stupid questions**，特别为新人友好。**不录像**——这是为了创造安全的提问空间。
- **何时用**: 本周五必参加（即使只听）。从未停过（2026-08-07 仍在运行）。
- **入门动作**:
  1. 订阅邮件组
  2. 本周五 9am PT / 12am ET 上线（Zoom 链接在最近邮件里）
  3. **本月内必须发言提问 1 次**（哪怕只是问"这个 baseline 训练数据规模是多少"）

## 🟠 中间层（Cohort）— 3-6 月内申请

### [必] 1. APART Research Sprint（月度 hackathon）⭐⭐⭐⭐⭐
- **URL**: `apartresearch.com/sprints`
- **是什么**: APART 的入口。每月一次周末 hackathon（在线），任何人都能参加。最佳项目会被邀请进入 Studio（6-8 周）→ Fellowship（12-24 周，每周 10-20h）→ 论文。
- **关键路径**: **Sprint（无门槛）→ Studio（5-20% 入选）→ Fellowship（40% 入选）→ 论文**。整个旅程 4-8 月。
- **何时用**: 当你完成 1-2 个月 interp 学习后，下次 Sprint 必参加。
- **入门动作**: 订阅 APART newsletter（`apart.kit.com/d7a2cad55a`），关注下次 Sprint 主题。

### [必] 2. EleutherAI SOAR（Summer of Open AI Research）⭐⭐⭐⭐⭐
- **URL**: `eleuther.ai/soar`
- **是什么**: 5 周线上研究训练，配真人 mentor（MIT CSAIL / Stanford / EleutherAI / Cohere / Apart）。2026 年第 2 届，500+ 人申请录 142 人。**门槛比想象低**，主要看申请文书 + 项目匹配。
- **关键日期**: 每年 5 月开放申请，6 月截止，7-8 月开营。
- **何时用**: 2027 年 5 月必申（2026 已结束）。
- **入门动作**: 现在开始泡 EleutherAI Discord，关注 SOAR 频道，提前 3 月准备申请。

### [重] 3. MLC RFP（Request for Proposals）
- **URL**: `mlcollective.org`（滚动开放）
- **是什么**: MLC 帮你 match mentor + 提供 compute + 反馈，研究你自己的想法。
- **何时用**: 当你有具体研究 idea 时申请。

### [重] 4. MLC The Lab
- **URL**: `mlcollective.org`，邮件 `hello@mlcollective.org`
- **是什么**: MLC 的"正式实验室"层，成员有自己的研究项目 + 每周组会。
- **何时用**: 6 月后，当你 interp 方向已经有 prototype。

## 💬 邮件模板：第一次联系研究员

**不要发**：「老师好我对 AI 感兴趣求指导」（垃圾邮件）

**要发**（约 200 词，英文）：

```
Subject: Question about [Specific Paper/Result]

Hi [Name],

I'm [Your name], a self-learner working through [your project:
e.g., "reproducing your 2023 SAE results on Gemma-2-2B"].

I got stuck / noticed something unexpected:
- [Specific question / observation in 2-3 sentences]
- [What I tried + my numbers]

[Optional: link to your blog post or repo with details]

I know you're busy—no rush. If you can point me to a reference or
a 1-line answer, I'd be grateful.

Best,
[Your name]
[Personal site / GitHub]
```

**关键原则**：
1. **具体**（不是「求指导」，而是「关于 X 的具体问题」）
2. **证明你做过功课**（"我读了你的 paper，跑了实验"）
3. **尊重时间**（"no rush", "1-line answer is enough"）
4. **可验证身份**（链接你的 GitHub / blog）
