## 📦 必贡献的开源项目（按门槛）

### [必] 1. Hugging Face Transformers ⭐⭐⭐⭐⭐
- **URL**: `github.com/huggingface/transformers`
- **现状**: 2026-08 版本 v5.14（v4 已 deprecated）
- **是什么**: NLP / LLM 标准库。所有大模型实现都在这里。
- **贡献门槛**: Good first issue 标签的 bug fix / 文档改进
- **为什么是 [必]**: 学习模型实现的最佳教材。每个 model file 都是一篇论文的代码版。
- **入门动作**:
  1. Star + clone repo
  2. 看 `CONTRIBUTING.md`
  3. 找 `good first issue` 标签的 ticket
  4. 在 Discord `huggingface.co/blog` 群里问问题

### [必] 2. vLLM ⭐⭐⭐⭐⭐
- **URL**: `github.com/vllm-project/vllm`
- **现状**: 2026-08 v0.27.0（刚发，561 commits / 242 contributors / 64 new）
- **是什么**: 高性能 LLM 推理引擎。PagedAttention（v0.25 已被删除，使用 Model Runner V2）。
- **贡献门槛**: 中等。需要懂 CUDA / attention 内核。
- **特别关注**:
  - 新模型支持（如 Inkling / Kimi K3 / Qwen3.5）—— 提供 PR 的好机会
  - Transformers backend（v5）—— `huggingface.co/blog/native-speed-vllm-transformers-backend`
- **Slack**: `vllm-dev.slack.com`（SIG 频道丰富）
- **SIG（Special Interest Groups）**: 见 `github.com/vllm-project/vllm/issues/32455`
  - `#sig-torch-compile`
  - `#sig-models` 等
- **入门动作**: 每周参加一个 SIG Zoom 会（公开日历：`zoom-lfx.platform.linuxfoundation.org/meetings/vllm`）

### [重] 3. tinygrad ⭐⭐⭐⭐
- **URL**: `github.com/tinygrad/tinygrad`
- **是什么**: George Hotz 的极简 DL 框架。<10k 行代码，能跑 LLaMA / Stable Diffusion。
- **为什么重要**: 学 DL 框架内部的最佳代码库。
- **贡献门槛**: 中等。需要懂 compiler / kernel。

### [重] 4. PyTorch
- **URL**: `github.com/pytorch/pytorch`
- **贡献门槛**: 高。但 fix typo / 文档也能进。

### [重] 5. EleutherAI 项目

- **是什么**: interp / 大模型评估 / 开源模型训练
- **特别推荐**: `lm-evaluation-harness` —— 所有 LLM benchmark 的标准实现

## 🐛 训练 Debug 资源（**最值钱的能力**）

### [必] 必读：训练失败排查清单
1. **loss 不降**: lr 太大/小？数据 label 错？模型 bug？
2. **loss = NaN**: lr 太大 / 数值不稳 / bf16 overflow / 检查 gradient clipping
3. **OOM**: 降 batch / 用 Grad Accumulation / bf16 / FSDP / offload to CPU
4. **训练很慢**: 用 FlashAttention / bf16 / torch.compile / 数据 loader workers
5. **loss spike**: 数据有问题 / lr schedule / Grad clipping 调小

### [必] Andrej Karpathy "A Recipe for Training Neural Networks"
- **URL**: `karpathy.github.io/2019/04/25/recipe`
