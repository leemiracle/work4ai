
## Configuration Recommendations

 For different use cases, consider these configuration adjustments:

 
| Scenario | Recommended Configuration Changes |
|---|---|
| Maximum performance | Use RMaxTS.py with RL model, increase sample_num |
| Faster results | Decrease sample_num, increase concurrent_num |
| Memory constraints | Reduce lean_max_concurrent_requests and n_search_procs |
| Complex theorems | Increase lean_timeout and lean_memory_limit |

 
## Experiment Resource Requirements

 Running experiments with DeepSeek-Prover-V1.5 can be resource-intensive:

 
| Algorithm | GPU Memory | CPU Cores | Disk Space | Typical Runtime |
|---|---|---|---|---|
| RMaxTS | 40GB+ | 64+ | 10GB+ | Hours to days |
| Sampling | 20GB+ | 32+ | 5GB+ | Hours |
| Few-Shot | 20GB+ | 32+ | 5GB+ | Hours |

 Note: These are approximate values and may vary based on specific configuration parameters.
