## Overview of Lean 4 Integration

 DeepSeek-Prover-V1.5 uses Lean 4 as its backend proof verification system. The language models generate proof attempts, which are then verified by Lean 4. This verification feedback is critical for both:

 
 - Evaluating the correctness of generated proofs during inference
 - Providing training signals for the reinforcement learning from proof assistant feedback (RLPAF) approach

## Lean 4 and mathlib4 in DeepSeek-Prover-V1.5

 
### Lean 4 Proof Assistant

 Lean 4 is a functional programming language and interactive theorem prover developed by Microsoft Research. In DeepSeek-Prover-V1.5, it serves as the verification engine that checks the correctness of the generated proofs.

 
### mathlib4 Library

 The system incorporates a customized version of mathlib4, which is the mathematics library for Lean 4. This is included as a Git submodule in the repository.

## Setup and Installation

 To properly integrate with Lean 4, users must:

 
 - Install Lean 4 following the official Lean 4 installation instructions
 - Clone the repository with submodules to get the custom mathlib4 library
 - Build the mathlib4 library
 
 The repository includes specific instructions for this setup process:

 
```
git clone --recurse-submodules git@github.com:deepseek-ai/DeepSeek-Prover-V1.5.git
cd DeepSeek-Prover-V1.5
pip install -r requirements.txt
cd mathlib4
lake build
```

## Lean Interface

 The Lean interface acts as a bridge between the proof search algorithms and the Lean 4 verification system. It:

 
 - Translates the generated proof scripts into a format that can be executed by Lean 4
 - Manages the verification requests and responses
 - Interprets the verification results and provides feedback to the proof search algorithms
 
 This component is crucial for both:

 
 - Simple sampling approaches, where the feedback determines if a proof is correct
 - More advanced algorithms like RMaxTS, where the feedback influences the search strategy

## Configuration Parameters

 The following parameters control the Lean 4 integration:

 
| Parameter | Default Value | Description |
|---|---|---|
| lean_max_concurrent_requests | 64 | Maximum number of concurrent verification requests to Lean 4 |
| lean_memory_limit | 10 | Memory limit for Lean 4 processes (in GB) |
| lean_timeout | 300 | Timeout for Lean 4 verification (in seconds) |

 These parameters can be adjusted based on available computational resources and specific requirements of the proof verification tasks.

## Integration Benefits

 The integration with Lean 4 provides several key benefits:

 
 - **Formal Verification**: Ensures the mathematical correctness of generated proofs
 - **Learning Signal**: Provides feedback for reinforcement learning to improve model performance
 - **Tree Search Guidance**: Informs the RMaxTS algorithm about promising proof paths
 - **Standardization**: Uses a widely recognized formal verification system for mathematical proofs
 
 The DeepSeek-Prover-V1.5-RL model combined with RMaxTS achieves state-of-the-art results on both miniF2F (63.5%) and ProofNet (25.3%) benchmarks, demonstrating the effectiveness of the Lean 4 integration.
