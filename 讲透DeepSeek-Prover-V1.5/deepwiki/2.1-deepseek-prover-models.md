## Purpose and Scope

 This document details the three variants of the DeepSeek-Prover-V1.5 model family: Base, SFT (Supervised Fine-Tuning), and RL (Reinforcement Learning). It explains their architectural differences, training process, capabilities, and performance metrics. This page focuses specifically on the model component of the DeepSeek-Prover system; for information about proof search algorithms that utilize these models, see [Proof Search Algorithms](https://deepwiki.com/deepseek-ai/DeepSeek-Prover-V1.5/2.2-proof-search-algorithms).

 
## Model Overview

 DeepSeek-Prover-V1.5 is a family of language models specifically designed for formal theorem proving in Lean 4. These 7B-parameter models are specialized for processing and generating formal mathematical languages. The models represent a progression in capabilities, with each variant building upon the previous one through additional training techniques.

## Model Variants

 
### DeepSeek-Prover-V1.5-Base

 The Base model serves as the foundation for the DeepSeek-Prover-V1.5 family. It is pre-trained on DeepSeekMath-Base with specialization in formal mathematical languages. This model provides the initial capabilities for understanding and generating mathematical proofs in Lean 4 syntax.

 
#### Performance Metrics

 
 - miniF2F-test: 42.2%
 - ProofNet: 13.2%
 
 
### DeepSeek-Prover-V1.5-SFT

 The SFT model builds upon the Base model through supervised fine-tuning using an enhanced formal theorem proving dataset derived from DeepSeek-Prover-V1. This training process significantly improves the model's ability to generate valid proofs.

 
#### Performance Metrics

 
 - miniF2F-test: 57.4%
 - ProofNet: 22.9%
 
 
### DeepSeek-Prover-V1.5-RL

 The RL model represents the most advanced variant, further refining the SFT model through reinforcement learning from proof assistant feedback (RLPAF). This approach leverages feedback from the Lean 4 proof assistant to optimize the model's proof generation capabilities.

 
#### Performance Metrics

 
 - miniF2F-test: 60.2%
 - ProofNet: 22.6%
 - With RMaxTS algorithm: 63.5% (miniF2F-test), 25.3% (ProofNet)

## Training Process

 
```

```

 The DeepSeek-Prover-V1.5 models undergo a progressive training process:

 
 - **Pre-training Phase**: The Base model is derived from DeepSeekMath-Base, a foundation model with specialization in formal mathematical languages.
 - **Supervised Fine-Tuning (SFT)**: The Base model is fine-tuned using an enhanced formal theorem proving dataset derived from DeepSeek-Prover-V1, creating the SFT variant.
 - **Reinforcement Learning**: The SFT model is further refined through reinforcement learning from proof assistant feedback (RLPAF), where the model learns from the verification results provided by the Lean 4 proof assistant.

## Model Integration with System Components

 
```

```

 The DeepSeek-Prover models integrate with other system components:

 
 - **Proof Search Algorithms**: The models are used by different proof search algorithms:

 
 - RMaxTS (a variant of Monte-Carlo tree search) primarily uses the RL model
 - Basic Sampling can use either the SFT or RL model
 - Few-shot Sampling typically uses the Base model with example proofs
 - **Lean 4 Interface**: The models generate proof attempts that are sent to the Lean 4 interface for verification
 - **Proof Verifier**: Validates the generated proofs against the Lean 4 proof assistant and mathlib4 library

## Model Usage

 The DeepSeek-Prover models can be used directly through Hugging Face's Transformers library. Here's a basic workflow for using the models:

 
 - **Model Loading**: Load the desired model variant (Base, SFT, or RL) from Hugging Face.
 - **Proof Generation**: Use the model to generate proof attempts for mathematical theorems.
 - **Proof Verification**: Verify the generated proofs using the Lean 4 proof assistant.
 
 For more advanced usage, the models can be integrated with specialized proof search algorithms like RMaxTS to improve proof generation capabilities. The RMaxTS algorithm combined with the RL model achieves the best performance.

## Performance Comparison

|---|---|---|
| ReProver | 26.5% | 13.8% |

 The DeepSeek-Prover-V1.5 models demonstrate significant performance improvements over previous approaches:

 
 - The SFT model shows a substantial improvement over the Base model
 - The RL model further improves performance
 - When combined with the RMaxTS algorithm, the RL model achieves state-of-the-art results on both the miniF2F and ProofNet benchmarks
