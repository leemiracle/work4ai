## Available Configuration Files

 The repository provides three main configuration files, each tailored for a different proof search approach:

 
| Configuration File | Algorithm | Primary Use Case |
|---|---|---|
| configs/RMaxTS.py | RMaxTS (Reinforcement Learning with Intrinsic Rewards) | Most powerful search approach, requires more computational resources |
| configs/sampling.py | Basic Sampling | Simpler approach with fewer samples, requires fewer resources |
| configs/sampling_few_shot.py | Few-shot Sampling | Uses examples to guide the base model without fine-tuning |

 Sources: [configs/RMaxTS.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/RMaxTS.py) [configs/sampling.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/sampling.py) [configs/sampling_few_shot.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/sampling_few_shot.py)

## Configuration Selection Guidelines

 
| Goal | Recommended Configuration | Key Parameters to Adjust |
|---|---|---|
| Maximum proof success rate | RMaxTS | Increase sample_num and concurrent_num |
| Faster evaluation | Sampling | Reduce sample_num |
| Using base model effectively | Few-shot Sampling | Adjust few_shot_num |
| Resource-constrained environment | Sampling | Reduce lean_max_concurrent_requests and n_search_procs |
| Memory-intensive theorems | Any | Increase lean_memory_limit |
| Long-running proofs | Any | Increase lean_timeout |

 Sources: [configs/RMaxTS.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/RMaxTS.py) [configs/sampling.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/sampling.py) [configs/sampling_few_shot.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/sampling_few_shot.py)

 
## Default Configuration Files Comparison

 The following table summarizes the key differences between the default configuration files:

 
| Parameter | RMaxTS.py | sampling.py | sampling_few_shot.py |
|---|---|---|---|
| data_split | 'test' | ['valid', 'test'] | ['valid', 'test'] |
| data_repeat | 16 | 1 | 1 |
| batch_size | 512 | 32 | 32 |
| model_path | 'deepseek-ai/DeepSeek-Prover-V1.5-RL' | 'deepseek-ai/DeepSeek-Prover-V1.5-RL' | 'deepseek-ai/DeepSeek-Prover-V1.5-Base' |
| n_search_procs | 256 | 64 | 64 |
| algorithm | RMaxTS | Sampling | Sampling |
| sample_num | 6400 | 128 | 128 |
| Few-shot support | No | No | Yes |

 Sources: [configs/RMaxTS.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/RMaxTS.py) [configs/sampling.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/sampling.py) [configs/sampling_few_shot.py](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5/blob/2c4ba911/configs/sampling_few_shot.py)

 This comparison highlights that the RMaxTS configuration is set up for more extensive search with higher computational requirements, while the sampling approaches use fewer resources but may have lower success rates. The few-shot configuration is unique in using the base model with example proofs rather than a fine-tuned model.
