  This page documents the command-line interfaces for Local Deep Research, including the three main entry points (`ldr`, `ldr-web`, `ldr-mcp`) and the Model Context Protocol (MCP) server that enables AI assistant integration with Claude Desktop and Claude Code.

 
## Entry Points

 Local Deep Research provides three command-line entry points defined in the project configuration [pyproject.toml109-113](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L109-L113):

 
| Entry Point | Module Target | Purpose |
|---|---|---|
| ldr | local_deep_research.main:main | Primary CLI interface for core research logic pyproject.toml110 |
| ldr-web | local_deep_research.web.app:main | Starts the Flask web application and UI pyproject.toml111 |
| ldr-mcp | local_deep_research.mcp:run_server | Starts the MCP server for AI assistant integration pyproject.toml112 |

### ldr-web: Web Application Server

 The `ldr-web` command starts the Flask application [pyproject.toml111](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L111-L111) It serves the frontend assets and provides the backend API for the research system [src/local_deep_research/web/static/js/services/api.js9-11](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/static/js/services/api.js#L9-L11) The server utilizes `SQLCipher` for per-user encrypted databases, with platform-specific binaries for `x86_64` and `aarch64` to ensure data privacy [pyproject.toml85-87](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L85-L87)

### Available Tools

 The MCP integration supports agentic research modes where the LLM can decide which specialized engines to use [README.md104](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L104-L104) Key tools include:

 
| Tool Name | Purpose |
|---|---|
| quick_research | Performs a fast research query and returns a summary README.md117 |
| generate_report | Synthesizes research findings into a full markdown report with citations README.md100 |
| mcp_strategy | Allows agents to use the autonomous langgraph-agent strategy README.md104 |

 
### Security and Transport

 The MCP server is designed for local integration via `STDIO` transport. It inherits the security posture of the main application, including the requirement for `SQLCipher` encrypted databases [README.md15](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L15-L15) For security, the application includes a `file-whitelist-check` to prevent unauthorized binary or large files from bloating the repository or leaking data [.github/scripts/file-whitelist-check.sh106-117](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/.github/scripts/file-whitelist-check.sh#L106-L117)

## CLI Configuration and Docker

 
### Environment Variables

 CLI tools and the web server respect `LDR_` prefixed environment variables. These variables override UI settings and lock them to prevent accidental changes [docs/docker-compose-guide.md53-57](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/docker-compose-guide.md?plain=1#L53-L57)

 
 - `LDR_DATA_DIR`: Sets the path for the research library and databases [docs/docker-compose-guide.md63](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/docker-compose-guide.md?plain=1#L63-L63)
 - `LDR_LLM_PROVIDER`: Selects the LLM backend (e.g., `ollama`, `openai`) [docs/docker-compose-guide.md65](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/docker-compose-guide.md?plain=1#L65-L65)
 - `LDR_LLM_MODEL`: Specifies the model to pull and use (e.g., `gemma3:12b`) [docs/docker-compose-guide.md66](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/docker-compose-guide.md?plain=1#L66-L66)

## Research Execution Flow

 When a research task is triggered via the CLI (`ldr`) or an MCP tool, it utilizes the core research engine to perform web searches and synthesize reports.

 
### CLI Execution Sequence

 The `ldr` entry point invokes the main execution logic which handles query processing and strategy selection [pyproject.toml110](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L110-L110)

 
 - **Initialization**: The CLI loads settings from environment variables or the encrypted database.
 - **Strategy Selection**: Based on the query, it selects from 20+ strategies (e.g., `langgraph-agent`, `quick`) [README.md102-104](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L102-L104)
 - **Search & Synthesis**: The engine performs searches across web and academic sources, downloading relevant PDFs into the library [README.md117](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L117-L117)
 - **Reporting**: Findings are synthesized into a markdown report with proper citations [README.md100](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L100-L100)
