  This page covers how Local Deep Research reads its configuration from environment variables, the naming rules that govern variable names, and the full catalogue of variables by category. It focuses on the environment variable layer specifically. For the full layered settings system (including the per-user encrypted database and the web UI), see **Settings Management (4.1)**. For Docker-specific deployment configuration, see **Docker Deployment (2.1)**.

## Naming Convention

 All application settings follow a dot-separated key format (e.g., `llm.provider`, `search.tool`). To address a setting via an environment variable, apply this transformation:

 
 - Prepend `LDR_`
 - Convert to uppercase
 - Replace every `.` with `_`
 
 **Examples:**

 
| Setting Key | Env Var |
|---|---|
| llm.provider | LDR_LLM_PROVIDER |
| llm.openai.api_key | LDR_LLM_OPENAI_API_KEY |
| app.max_concurrent_researches | LDR_MAX_CONCURRENT (Explicit mapping) |
| web.port | LDR_WEB_PORT |

 The system also supports deprecated aliases for backward compatibility (e.g., `LDR_ALLOW_UNENCRYPTED` for `LDR_BOOTSTRAP_ALLOW_UNENCRYPTED`) [docs/CONFIGURATION.md34-54](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L34-L54)

 The conversion and lookup are handled by `SettingsManager` in `src/local_deep_research/settings/manager.py` [src/local_deep_research/settings/manager.py19-26](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/settings/manager.py#L19-L26) The `get_typed_setting_value` function specifically checks `os.environ` for these prefixed keys using `check_env` logic [src/local_deep_research/settings/manager.py188-204](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/settings/manager.py#L188-L204)

## Configuration Priority

 When a setting is requested (via `SettingsManager.get_setting()`), the following priority order applies. Higher entries win. Note that environment variables act as "locks" — if a non-empty environment variable exists, it overrides the database value and makes the setting read-only in the UI [docs/env_configuration.md27-29](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/env_configuration.md?plain=1#L27-L29) Empty environment variables (e.g., `LDR_LLM_PROVIDER=""`) are treated as not set and will not override the UI [docs/env_configuration.md29](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/env_configuration.md?plain=1#L29-L29)

## Pre-Database (Bootstrap) Settings

 Bootstrap settings are resolved before the database is initialized and can only be set via environment variables. These are required for the application to start and locate its data [docs/CONFIGURATION.md27-31](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L27-L31)

 
| Env Var | Type | Default | Description |
|---|---|---|---|
| LDR_BOOTSTRAP_DATA_DIR | Path | None | Root data directory for DB, logs, and cache docs/CONFIGURATION.md37 |
| LDR_BOOTSTRAP_ENCRYPTION_KEY | Secret | None | Master key for database encryption docs/CONFIGURATION.md39 |
| LDR_BOOTSTRAP_ALLOW_UNENCRYPTED | Boolean | False | Allow unencrypted DB (dev only) docs/CONFIGURATION.md34 |
| LDR_DB_CONFIG_KDF_ITERATIONS | Integer | 256000 | PBKDF2 iterations for SQLCipher docs/CONFIGURATION.md47 |
| LDR_DB_CONFIG_CIPHER_MEMORY_SECURITY | Enum | 'OFF' | ON clears memory after use (requires mlock/IPC_LOCK) docs/CONFIGURATION.md43 |
| LDR_BOOTSTRAP_SECRET_KEY | Secret | None | Application secret key for session encryption docs/CONFIGURATION.md41 |

## Application Behaviour Settings

 These settings control the web server and global application limits. Server-level settings like `web.port` are managed in `server_config.py` and are loaded during early startup [src/local_deep_research/web/server_config.py1-10](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/server_config.py#L1-L10)

 
| Env Var | Setting Key | Default | Notes |
|---|---|---|---|
| LDR_APP_DEBUG | app.debug | false | Produces informative errors; may expose sensitive data docs/CONFIGURATION.md66 |
| LDR_WEB_PORT | web.port | 5000 | Port the server listens on src/local_deep_research/web/server_config.py58 |
| LDR_MAX_CONCURRENT | app.max_concurrent_researches | 3 | Max simultaneous research threads per user docs/CONFIGURATION.md114-128 |
| LDR_SERVER_MAX_CONCURRENT_RESEARCH | app.max_global_concurrent_researches | 10 | Server-wide concurrency limit docs/CONFIGURATION.md57 |
| LDR_APP_ALLOW_REGISTRATIONS | app.allow_registrations | true | Disabling this blocks new account creation docs/CONFIGURATION.md65 |
| LDR_APP_LOCK_SETTINGS | app.lock_settings | false | Freezes all settings globally via UI docs/CONFIGURATION.md100-113 |

These are read at research-thread startup time via the `settings_snapshot` mechanism [src/local_deep_research/settings/manager.py220-225](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/settings/manager.py#L220-L225)

| Env Var | Setting Key | Default | Description |
|---|---|---|---|
| LDR_LLM_PROVIDER | llm.provider | ollama | Active provider (e.g., ollama, openai, anthropic, google) docs/CONFIGURATION.md76 |
| LDR_LLM_MODEL | llm.model | gemma3:12b | Model name string docs/CONFIGURATION.md75 |

## System Locking (LDR_LOCKED_SETTINGS)

 Administrators can strictly enforce specific settings using the `LDR_LOCKED_SETTINGS` variable.

 
 - **Format**: Comma-separated list of setting keys (e.g., `llm.model,app.port`) [docs/CONFIGURATION.md18](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L18-L18)
 - **Behavior**: 
 - Listed settings **MUST** have a corresponding `LDR_` environment variable defined [docs/CONFIGURATION.md20](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L20-L20)
 - Settings become **read-only** in the Web UI [docs/CONFIGURATION.md21](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L21-L21)
 - Environment variable values take absolute precedence, ignoring any value in the database [docs/CONFIGURATION.md22](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L22-L22)
