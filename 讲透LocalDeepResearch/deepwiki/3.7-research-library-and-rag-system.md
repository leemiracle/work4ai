## Purpose and Scope

 The Research Library and RAG System provides unified document storage, organization, and semantic search capabilities for Local Deep Research. This system manages three distinct workflows:

 
 - **Research Downloads**: Automatic download and indexing of PDFs/papers from research sessions [src/local_deep_research/research_library/services/download_service.py68-150](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/services/download_service.py#L68-L150)
 - **User Uploads**: Direct file uploads for personal document collections [src/local_deep_research/database/models/library.py136-161](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L136-L161)
 - **RAG Indexing**: Vector-based semantic search across document collections [src/local_deep_research/research_library/services/library_rag_service.py43-154](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/services/library_rag_service.py#L43-L154)
 
 The system implements a flexible storage architecture with three modes (database/filesystem/text-only), per-collection RAG configuration, and FAISS-based vector search. All text content is stored encrypted in SQLCipher databases for security [src/local_deep_research/database/models/library.py223-225](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L223-L225)

### Storage Modes

 The system supports three PDF storage modes configured via `research_library.pdf_storage_mode` [src/local_deep_research/database/models/library.py105-111](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L105-L111):

 
| Mode | Description | Security | Use Case |
|---|---|---|---|
| database | PDFs encrypted in DocumentBlob table | AES-256 via SQLCipher | Default. Portable, isolated per-user |
| filesystem | Unencrypted files in library/pdfs/ | None (file permissions only) | Large files, external tool access |
| none | Text extraction only, no PDF storage | N/A | Minimal storage footprint |

 Text content is **always** stored in `Document.text_content` regardless of PDF storage mode [src/local_deep_research/database/models/library.py223-225](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L223-L225) This column is encrypted within the user's SQLCipher database.
