## What is Local Deep Research?

 Local Deep Research is an AI-powered research assistant that performs deep, agentic research using multiple LLMs and search engines with proper citations [README.md32-34](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L32-L34) It is designed to be "local-first" for privacy, allowing users to build a searchable knowledge base from research findings while maintaining ownership of their data [README.md42-45](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L42-L45)

 The system is accessible through multiple interfaces:

 
 - **Web UI**: Primary interface for research and settings (default port 5000) [docs/CONFIGURATION.md65-69](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L65-L69) accessible via the `ldr-web` entry point [pyproject.toml111](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L111-L111)
 - **REST API**: Authenticated endpoints for programmatic integration using Flask blueprints.
 - **Python API**: Programmatic access via the core library for enterprise integration.
 - **MCP Server**: Model Context Protocol integration via `ldr-mcp` for tools like Claude Desktop [pyproject.toml112](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L112-L112)
 
 The application version is currently **1.6.9**, tracked in [src/local_deep_research/__version__.py1](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/__version__.py#L1-L1)

## Key Features

 
### Local-First and Privacy-Focused

 LDR prioritizes privacy by supporting fully local stacks. Users can run LLMs via **Ollama** and search via **SearXNG** [README.md50-65](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L50-L65) Every user's data is isolated in a per-user **SQLCipher** database [README.md15](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L15-L15) Encryption parameters like `LDR_DB_CONFIG_KDF_ITERATIONS` (default 256,000) and `LDR_DB_CONFIG_HMAC_ALGORITHM` (default HMAC_SHA512) are configurable via bootstrap settings [docs/CONFIGURATION.md44-47](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L44-L47)

 
### Multi-Strategy Research

 The system coordinates different search strategies via the `AdvancedSearchSystem`.

 
 - **langgraph-agent**: Autonomous research mode where the LLM decides search tools (arXiv, PubMed, etc.) and synthesis timing [README.md104](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L104-L104)
 - **20+ Strategies**: Choose from specialized strategies for quick facts, deep analysis, or academic research [README.md102](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L102-L102)
 - **Citation-Heavy**: Every research session finds valuable sources, extracts text, and indexes them for compound knowledge [README.md117-118](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L117-L118)
 
 
### Research Library and RAG

 Research findings become part of a compound knowledge base. LDR can download sources into an encrypted library, index them using **FAISS**, and use them for future RAG-based queries [README.md106-115](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L106-L115) [pyproject.toml49](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L49-L49)

## Architectural Philosophy

 
### 1. Zero-Knowledge and Isolation

 The system uses a per-user database architecture powered by **SQLCipher**. Access is protected by password-derived keys; the system is designed so that data remains encrypted at rest [README.md15](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L15-L15) [docs/CONFIGURATION.md39-40](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L39-L40)

 
### 2. Thread-Safe Settings and Context

 Research tasks run in background threads. LDR uses a settings management system that handles thread-local contexts and database session management to ensure safe execution during concurrent research tasks [docs/CONFIGURATION.md11-13](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L11-L13)

 
### 3. Resource Lifecycle Management

 The system includes automated schedulers for managing background tasks like news subscriptions [docs/CONFIGURATION.md51-52](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L51-L52) Concurrency is strictly managed via limits like `LDR_SERVER_MAX_CONCURRENT_RESEARCH` [docs/CONFIGURATION.md57](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/CONFIGURATION.md?plain=1#L57-L57)

 
### 4. Pluggable Integration

 The architecture uses a strategy pattern for search engines and LLMs. The `AdvancedSearchSystem` allows selecting from various strategies, while abstractions in the `web_search_engines` layer handle provider-specific logic for engines like arXiv, PubMed, and Wikipedia [pyproject.toml45-47](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L45-L47)
