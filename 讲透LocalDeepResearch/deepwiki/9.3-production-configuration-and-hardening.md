## Purpose and Scope

 This page documents the production-specific configuration and security hardening measures for Local Deep Research (LDR). It covers the hierarchical settings system, HTTP security middleware, container isolation strategies, and deployment-specific best practices for Unraid and Docker environments.

 
---

 
## Environment Variable Configuration System

 Local Deep Research employs a robust configuration system where environment variables (prefixed with `LDR_`) interact with a per-user encrypted database.

 
### Configuration Hierarchy and Locking

 The system differentiates between standard overrides and security-critical locks. Environment variables always take precedence over database values or defaults [docs/env_configuration.md27-29](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/env_configuration.md?plain=1#L27-L29)

 
```

```

 
 - **Override Mode**: Non-empty environment variables override UI settings and lock them as read-only in the interface [docs/env_configuration.md27-29](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/env_configuration.md?plain=1#L27-L29)
 - **Locked Mode**: Administrators can specify a list of settings in `LDR_LOCKED_SETTINGS` to prevent any modification via the Web UI, ensuring infrastructure stability in multi-user deployments.

## Security Hardening and Middleware

 
### HTTP Security Headers

 The `SecurityHeaders` class implements a middleware stack that injects defensive headers into every Flask response to mitigate XSS, Clickjacking, and MIME-sniffing [src/local_deep_research/security/security_headers.py13-24](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/security/security_headers.py#L13-L24)

 
```

```

 **Key Directives:**

 
 - **Content-Security-Policy (CSP)**: Restricts `script-src` and `style-src` to `'self'`. It specifically includes `'unsafe-inline'` to maintain compatibility with Socket.IO real-time updates but removes `'unsafe-eval'` to block common XSS vectors [src/local_deep_research/security/security_headers.py103-133](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/security/security_headers.py#L103-L133)
 - **X-Frame-Options**: Forced to `SAMEORIGIN` to prevent the UI from being embedded in malicious iframes [src/local_deep_research/security/security_headers.py18](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/security/security_headers.py#L18-L18)
 - **Permissions-Policy**: Disables high-risk browser features like `camera`, `microphone`, and `geolocation` by default [src/local_deep_research/security/security_headers.py135-156](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/security/security_headers.py#L135-L156)
 - **COEP**: Cross-Origin-Embedder-Policy is set to `credentialless` by default to allow cross-origin requests without credentials [src/local_deep_research/security/security_headers.py83](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/security/security_headers.py#L83-L83)

### Container Hardening

 Production Docker images are hardened to minimize the attack surface:

 
 - **Non-Root User**: Containers are configured to run as a non-privileged user (typically `ldruser`) to prevent host-level compromise.
 - **Resource Limits**: Production deployments are advised to set `memlock` to unlimited to allow SQLCipher's `mlock()` to protect encryption keys in RAM.
 - **Volume Persistence**: Critical data including the SQLCipher database (`ldr.db`) and the secret key must be mapped to persistent volumes to prevent session loss or data corruption [docs/env_configuration.md168-179](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/docs/env_configuration.md?plain=1#L168-L179)

### Rate Limiting

 Production instances use `Flask-Limiter` (configured via `LDR_SECURITY_RATE_LIMIT_*`) to prevent brute-force attacks on sensitive endpoints:

 
 - **Login**: Defaults to `5 per 15 minutes` [src/local_deep_research/web/server_config.py63](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/server_config.py#L63-L63)
 - **Registration**: Defaults to `3 per hour` [src/local_deep_research/web/server_config.py64](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/server_config.py#L64-L64)

### Hardware Warnings

 The system includes proactive checks to prevent production crashes due to resource exhaustion. The `check_high_context` and `check_model_mismatch` functions trigger UI warnings if a user attempts to run a large model (e.g., 70B) with a context window exceeding 8192 tokens on local providers (`ollama`, `llamacpp`, `lmstudio`), which might lead to VRAM OOM (Out of Memory) errors [src/local_deep_research/web/warning_checks/hardware.py12-64](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/warning_checks/hardware.py#L12-L64)
