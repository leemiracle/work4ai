## Document Storage Model

 Documents use a unified storage architecture where all sources (research downloads, user uploads) converge into a single `Document` table [src/local_deep_research/database/models/library.py163-168](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L163-L168) Text content is always stored encrypted in the database.

 
| Field | Type | Purpose |
|---|---|---|
| id | String(36) UUID | Primary key src/local_deep_research/database/models/library.py170 |
| document_hash | String(64) SHA256 | Deduplication by content src/local_deep_research/database/models/library.py205-207 |
| text_content | Text | Extracted text (encrypted) src/local_deep_research/database/models/library.py223-225 |

## FAISS Index Management

 
### Index Types and Distance Metrics

 FAISS indices are configured per collection with three index types and three distance metrics:

 **Index Types [src/local_deep_research/database/models/library.py88-94](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L88-L94):**

 
| Type | Class | Use Case |
|---|---|---|
| flat | IndexFlatL2 or IndexFlatIP | Exact search, small-medium collections |
| hnsw | IndexHNSWFlat | Fast approximate search, large collections |
| ivf | Inverted File Index | Optimized for very large datasets |

 **Distance Metrics [src/local_deep_research/database/models/library.py80-86](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L80-L86):**

 
| Metric | Index | Normalization | Use Case |
|---|---|---|---|
| cosine | IndexFlatIP | Required (normalize_vectors=True) | Semantic similarity |
| dot_product | IndexFlatIP | Optional | Raw inner product |
| l2 | IndexFlatL2 | Not needed | Euclidean distance |

## Indexing Pipeline

 
### Batch Indexing

 The indexing process processes documents in batches. The batch size is configurable via `rag.indexing_batch_size` in the library settings [src/local_deep_research/defaults/research_library/library_settings.json71](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/defaults/research_library/library_settings.json#L71-L71)

 **Optimization Strategy:**

 
 - Process documents in batches (default 15).
 - Parallel text splitting into chunks.
 - Deduplicate chunks within the batch using SHA256 hashes.
 - Batch embedding generation for efficiency.
 - Bulk insert to the FAISS index.
 
 
### Bulk Indexing with Progress Tracking

 The RAG routes provide endpoints for bulk indexing with progress tracking [src/local_deep_research/research_library/routes/rag_routes.py4-9](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/routes/rag_routes.py#L4-L9) A global `ThreadPoolExecutor` handles background indexing tasks to prevent thread proliferation [src/local_deep_research/research_library/routes/rag_routes.py67-80](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/routes/rag_routes.py#L67-L80)

 Default settings are defined in `library_settings.json`:

 
| Setting Key | Default | Description |
|---|---|---|
| rag.indexing_batch_size | 15 | Docs processed in parallel src/local_deep_research/defaults/research_library/library_settings.json71 |
| research_library.pdf_storage_mode | database | How PDFs are stored src/local_deep_research/defaults/research_library/library_settings.json56 |

 
### Collection-Specific Configuration

 When a collection is first indexed, its embedding configuration (model, provider, chunk size) is stored in the `RAGIndex` record [src/local_deep_research/database/models/library.py544-632](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L544-L632) Subsequent indexing operations for that collection use the stored settings to ensure vector compatibility [src/local_deep_research/web_search_engines/engines/search_engine_collection.py67-75](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web_search_engines/engines/search_engine_collection.py#L67-L75)

## Collection Management

 
### Default Library Collection

 On first access, a default "Library" collection is used for research downloads. Users can filter by this or custom collections in the UI [src/local_deep_research/web/templates/pages/library.html111-124](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/templates/pages/library.html#L111-L124)

 
### Custom Collections

 Users can create custom collections to group documents. The `LibraryService` provides methods to retrieve all collections for a user [src/local_deep_research/research_library/services/library_service.py185-186](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/services/library_service.py#L185-L186)
