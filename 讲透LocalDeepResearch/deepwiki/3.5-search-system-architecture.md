## Purpose and Scope

 This document describes the **AdvancedSearchSystem** and its strategy-based architecture for conducting iterative research across multiple search engines. It covers the strategy pattern implementation, shared state management via `all_links_of_system`, citation handling, question generation, and the 30+ available research strategies.

 For search engine provider implementations (SearXNG, arXiv, PubMed), see [Search Engine Integration Layer](https://deepwiki.com/LearningCircuit/local-deep-research/3.6-search-engine-integration-layer). For the report generation system that calls `AdvancedSearchSystem`, see [Report Generation and Export System](https://deepwiki.com/LearningCircuit/local-deep-research/3.9-report-generation-and-export-system).

 
---

 
## System Overview

 The search system uses a **strategy pattern** to support multiple research approaches while maintaining a consistent interface. A single `AdvancedSearchSystem` instance coordinates the strategy, manages shared state (`all_links_of_system`), and provides progress callbacks.

## Strategy Pattern Architecture

 The strategy pattern allows different research approaches to be used interchangeably. All strategies inherit from `BaseSearchStrategy` and implement the `analyze_topic(query) -> Dict` interface.

 
### BaseSearchStrategy

 The abstract base class defines the common interface and shared functionality for all strategies. It handles progress reporting via `_update_progress`, setting retrieval via `get_setting`, and termination checks. [src/local_deep_research/advanced_search_system/strategies/base_strategy.py12-136](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/base_strategy.py#L12-L136)

 
### Strategy Factory

 The `create_strategy()` function in `search_system_factory.py` acts as the single source of truth for strategy instantiation, reading configuration from the `settings_snapshot` to customize strategy behavior. [src/local_deep_research/search_system_factory.py32-177](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/search_system_factory.py#L32-L177)

 **Key Strategies:**

 
| Strategy Name | Class | Description |
|---|---|---|
| source-based | SourceBasedSearchStrategy | Default. Iterative generation → parallel search → synthesis. src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py22 |
| focused-iteration | FocusedIterationStrategy | Optimized for SimpleQA (96.51% accuracy). Uses entity extraction and ProgressiveExplorer. src/local_deep_research/advanced_search_system/strategies/focused_iteration_strategy.py40 |
| parallel | ParallelSearchStrategy | Simultaneous execution of all queries for maximum speed. src/local_deep_research/advanced_search_system/strategies/parallel_search_strategy.py21 |

| rapid | RapidSearchStrategy | Quick single-pass search for fast responses. src/local_deep_research/advanced_search_system/strategies/rapid_search_strategy.py20 |

## Shared State: all_links_of_system

 The `all_links_of_system` list is the **single source of truth** for all citations in the final report. This list is created in `AdvancedSearchSystem` and **passed by reference** to the strategy.

 
### Why Shared Reference Matters

 In detailed report mode, `IntegratedReportGenerator` calls `analyze_topic()` multiple times (once per subsection). Each call:

 
 - **Extends** `self.all_links_of_system` with new results. [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py46-56](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L46-L56)
 - Uses the length of the list to ensure citation indices are unique across the entire report. [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py40-44](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L40-L44)

## Citation and Findings Handling

 The `CitationHandler` manages citation formatting and numbering in synthesized content.

 
### Flow of Synthesis

 
 - **Accumulate Results:** Strategies gather search results across iterations.
 - **Cross-Engine Filter:** Results are filtered and reordered for relevance via `CrossEngineFilter`. [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py117-123](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L117-L123)
 - **Extend Global State:** Results are added to `all_links_of_system`.
 - **Synthesize:** `CitationHandler.analyze_followup()` generates text using the global list for indexing. [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py40-44](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L40-L44)
