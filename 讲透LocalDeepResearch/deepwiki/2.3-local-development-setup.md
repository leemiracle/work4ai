## Troubleshooting

 **SQLCipher "ModuleNotFoundError"** Ensure system libraries (`libsqlcipher-dev`) are installed *before* `pdm install`. PDM uses specific logic to select `sqlcipher3-binary` on Linux x86_64 to simplify setup [pyproject.toml85](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/pyproject.toml#L85-L85)

 **Lockfile Mismatch** If `pyproject.toml` is updated without updating the lockfile, run `pdm lock` to synchronize.

 **Environment Overrides** Environment variables prefixed with `LDR_` will force settings. To use unencrypted SQLite during development if SQLCipher is missing, use `LDR_BOOTSTRAP_ALLOW_UNENCRYPTED=true` [README.md89](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/README.md?plain=1#L89-L89)
