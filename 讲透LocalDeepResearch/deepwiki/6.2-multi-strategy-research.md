## Overview

 Local Deep Research implements over 30 research strategies, each optimized for specific scenarios such as factual Q&A, comprehensive literature review, or rapid entity lookup. The strategy pattern, managed by the `AdvancedSearchSystem`, allows the system to adapt its iteration patterns, question generation, and result filtering based on query complexity [src/local_deep_research/search_system.py20-83](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/search_system.py#L20-L83)

 **Key Components:**

 
 - **Strategy Factory**: `create_strategy` in `search_system_factory.py` provides a centralized registry and creation logic for all strategies [src/local_deep_research/search_system_factory.py32-177](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/search_system_factory.py#L32-L177)
 - **Base Strategy**: `BaseSearchStrategy` defines the common interface and shared state (e.g., `all_links_of_system`) [src/local_deep_research/advanced_search_system/strategies/base_strategy.py12-48](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/base_strategy.py#L12-L48)
 - **Orchestration**: `AdvancedSearchSystem` coordinates LLM and Search Engine instances with the selected strategy [src/local_deep_research/search_system.py20-83](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/search_system.py#L20-L83)

## Core Research Strategies

 
### 1. Source-Based Strategy (Default)

 **Implementation**: `SourceBasedSearchStrategy` [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py22](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L22-L22)

 The primary comprehensive strategy. It uses an iterative loop where each step generates follow-up questions based on accumulated search results as context [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py28-31](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L28-L31)

 **Key Characteristics**:

 
 - **Parallel Search**: Questions within an iteration are searched concurrently using `ThreadPoolExecutor` [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py32](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L32-L32)
 - **Cross-Engine Filter**: Uses `CrossEngineFilter` to rank and reduce results (e.g., filtering 60 down to 10) based on LLM relevance [src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py35-39](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/advanced_search_system/strategies/source_based_strategy.py#L35-L39)
