## Overview

 The library system provides two layers of configuration:

 
 - **Global library settings**: Control PDF storage behavior, batch sizes, and default indexing parameters.
 - **Collection-specific settings**: Override RAG parameters per collection, frozen at index creation time to ensure vector compatibility.
 
 All settings are stored in per-user encrypted SQLCipher databases via the `SettingsManager` and can be overridden via environment variables for deployment control.

 **Sources:** [src/local_deep_research/defaults/research_library/library_settings.json1-127](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/defaults/research_library/library_settings.json#L1-L127) [src/local_deep_research/research_library/routes/rag_routes.py133-154](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/routes/rag_routes.py#L133-L154)

## PDF Storage Modes

 The library supports three PDF storage strategies, controlled by the `research_library.pdf_storage_mode` setting. This determines how the `PDFStorageManager` handles incoming files during the download pipeline.

 
| Mode | Description | Storage Location | Encryption | Use Case |
|---|---|---|---|---|
| database | PDFs stored in SQLCipher DB | DocumentBlob table | AES-256-CBC | Recommended: Secure, portable, per-user isolated. |
| filesystem | PDFs saved to disk | library_root/pdfs/ | None | Large files, external tool access. |
| none | Text extraction only | Document.text_content | AES-256-CBC | Minimal storage, re-download as needed. |

 **Setting Location:** `research_library.pdf_storage_mode` in per-user settings database [src/local_deep_research/research_library/routes/library_routes.py133-135](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/routes/library_routes.py#L133-L135) **Default Value:** `"database"` [src/local_deep_research/database/models/library.py229-230](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/models/library.py#L229-L230) **Environment Override:** `LDR_RESEARCH_LIBRARY_PDF_STORAGE_MODE`.

## RAG Indexing Configuration

 RAG indexing behavior is controlled by settings that determine embedding generation, text chunking, and FAISS index construction.

 
### Default RAG Settings

 Default settings are stored under the `local_search_*` prefix. The `get_rag_service` function in `rag_routes.py` is responsible for resolving these values.

 
| Setting | Description | Default | Type |
|---|---|---|---|
| local_search_embedding_provider | Provider type (sentence_transformers or ollama) | "sentence_transformers" | select |
| local_search_embedding_model | Model name (e.g., all-MiniLM-L6-v2) | "all-MiniLM-L6-v2" | text |
| local_search_chunk_size | Characters per chunk | 1000 | number |
| local_search_chunk_overlap | Overlap between chunks | 200 | number |
| local_search_splitter_type | Chunking strategy (recursive, semantic, token, sentence) | "recursive" | select |
| local_search_text_separators | Split delimiters (JSON array) | ["\n\n", "\n", ". ", " ", ""] | JSON |
| local_search_distance_metric | Similarity metric (cosine, l2, dot_product) | "cosine" | select |
| local_search_normalize_vectors | L2 normalization for cosine similarity | true | boolean |
| local_search_index_type | FAISS index type (flat, hnsw, ivf) | "flat" | select |

## Upload-Specific Settings

 User uploads have a specialized storage setting to enforce security and minimize footprint. The `PDFUploadHandler` in the frontend interacts with these limits.

 
| Setting | Value | Reason |
|---|---|---|
| research_library.upload_pdf_storage | "database" or "none" | Filesystem storage is disabled for uploads to prevent SSRF/Path Traversal. |
| Default | "none" | Optimized for text-only search to keep the encrypted DB size manageable. |
| max_file_size | 50MB (default) | Enforced by PDFUploadHandler.fetchUploadLimits(). |

 **Sources:** [src/local_deep_research/defaults/research_library/library_settings.json88-111](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/defaults/research_library/library_settings.json#L88-L111) [src/local_deep_research/research_library/routes/rag_routes.py133-154](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/routes/rag_routes.py#L133-L154)

## Performance Considerations

 
### Auto-Indexing Concurrency

 The system uses a global `ThreadPoolExecutor` for auto-indexing tasks to prevent thread proliferation.

 
 - **Worker Limit:** 4 workers [src/local_deep_research/research_library/routes/rag_routes.py76-80](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/routes/rag_routes.py#L76-L80)
 - **Naming Prefix:** `auto_index_` [src/local_deep_research/research_library/routes/rag_routes.py78](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/routes/rag_routes.py#L78-L78)
 
 
### Index Type Performance

 
 - **`flat`**: Exact search using `IndexFlatL2` or `IndexFlatIP`. Best for collections < 5,000 documents [src/local_deep_research/research_library/services/library_rag_service.py37-38](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/services/library_rag_service.py#L37-L38)
 - **`hnsw`**: Approximate search using `IndexHNSWFlat`. Recommended for large libraries [src/local_deep_research/research_library/services/library_rag_service.py37-38](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/research_library/services/library_rag_service.py#L37-L38)
