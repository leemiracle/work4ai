### Directory Resolution

 The application determines its static and template directories based on whether it's running from an installed package or development environment:

 
```
Try: importlib.resources.files() for package paths
Fallback: Path("templates").resolve() for development
```

 Static folder is explicitly set to `None` to disable Flask's built-in static handling, allowing custom static route logic at [src/local_deep_research/web/app_factory.py105-120](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/app_factory.py#L105-L120)

## Settings Handling and Validation

 The settings system utilizes a dual-mode submission pattern to handle checkboxes correctly, ensuring compatibility with and without JavaScript [src/local_deep_research/web/routes/settings_routes.py6-39](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/routes/settings_routes.py#L6-L39)

 
 - **AJAX Mode**: JSON submission where JavaScript reads `checkbox.checked` directly [src/local_deep_research/web/routes/settings_routes.py10-15](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/routes/settings_routes.py#L10-L15)
 - **Traditional POST**: Uses a hidden fallback input pattern to ensure unchecked checkboxes are captured (submitting "false") [src/local_deep_research/web/routes/settings_routes.py17-23](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/routes/settings_routes.py#L17-L23)
 
 Settings are validated against their defined `ui_element` type (e.g., checkbox, number, slider, select) and constraints like `min_value` or `max_value` [src/local_deep_research/web/routes/settings_routes.py158-202](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/routes/settings_routes.py#L158-L202) Namespace validation restricts the creation of new settings to allowed prefixes like `llm.`, `search.`, or `rag.` [src/local_deep_research/web/routes/settings_routes.py93-131](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/routes/settings_routes.py#L93-L131)
