  This document describes the News and Subscription Management subsystem, which enables users to monitor news topics, RSS feeds, and search queries, automatically triggering research tasks and providing a personalized news feed.

 
---

 
## Purpose and Scope

 The News and Subscription Management system provides:

 
 - **News Monitoring**: Automated tracking of topics using LLM-powered analyzers and search strategies [src/local_deep_research/news/api.py154-161](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/api.py#L154-L161)
 - **Subscription Management**: Tools to create, update, and organize subscriptions with custom refresh intervals [src/local_deep_research/news/flask_api.py193-204](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/flask_api.py#L193-L204)
 - **Intelligent Scheduler**: A background service with activity-based tracking and jitter settings to prevent API spikes and resource contention.
 - **News Analyzer & Headline Generator**: AI components that synthesize search results into structured news items and generate concise, meaningful headlines.
 - **Flask News API**: Secure endpoints for feed retrieval, subscription control, and user feedback [src/local_deep_research/news/flask_api.py101-105](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/flask_api.py#L101-L105)
 
 The system is designed with a "local-first" philosophy, storing all subscription configurations and news history in encrypted per-user databases [src/local_deep_research/database/session_context.py15-16](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/database/session_context.py#L15-L16)

### Data Flow: Personalized News Retrieval

 
 - **Client Request**: The frontend `news.js` calls `loadNewsFeed()`, which performs a GET request to `/news/api/feed` [src/local_deep_research/web/static/js/pages/news.js173](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/web/static/js/pages/news.js#L173-L173)
 - **Authentication**: The Flask route is protected by `@login_required`, ensuring the `session["username"]` is available [src/local_deep_research/news/flask_api.py123](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/flask_api.py#L123-L123)
 - **Service Invocation**: The API calls the underlying `api.get_news_feed` with parameters for limits, focus, and subscription IDs [src/local_deep_research/news/flask_api.py154-161](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/flask_api.py#L154-L161)
 - **Database Query**: The system retrieves news items associated with the user's specific research history and subscriptions from the encrypted database [src/local_deep_research/news/flask_api.py137-140](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/flask_api.py#L137-L140)

## News Scheduler and API Control

 
### Scheduler Security

 Global scheduler controls are gated by the `scheduler_control_required` decorator. This checks the `news.scheduler.allow_api_control` setting (env var `LDR_NEWS_SCHEDULER_ALLOW_API_CONTROL`) [src/local_deep_research/news/flask_api.py23-33](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/flask_api.py#L23-L33)

 
| Setting | Key | Default |
|---|---|---|
| API Control | news.scheduler.allow_api_control | False src/local_deep_research/news/flask_api.py37 |
| Default Limit | news.feed.default_limit | From Settings Manager src/local_deep_research/news/flask_api.py142-143 |

 
### Error Handling Strategy

 The `safe_error_message` function provides a security layer by mapping internal exceptions to generic messages for the client [src/local_deep_research/news/flask_api.py62-84](https://github.com/LearningCircuit/local-deep-research/blob/4a6a9088/src/local_deep_research/news/flask_api.py#L62-L84)
