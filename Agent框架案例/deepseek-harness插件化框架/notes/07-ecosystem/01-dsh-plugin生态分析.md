## 2. 生态结构分析

### 2.1 四类构成（59 个的分布）

| 类 | 数量 | 占比 | 典型 |
|---|---|---|---|
| (a) 真插件/skill/目录 | 28 | 47% | dsh-web-ui、dsh-TUI、modlens、archify、DSH-better-sidebar |
| (b) 周边载体（桌面/发行版/画廊） | 3 | 5% | deepseek-harness-desktop、oh-dsh、petdex |
| (c) 独立产品（集成或蹭挂） | 21 | 36% | open-design、iPolloWork、OpenBiliClaw、mobius |
| (d) 明显刷量/无关 | 7 | 12% | tencentmeeting-cli、PicGo-Core、zhuzhiliao、KimiX |

**一半是真插件、一半是杠杆**：独立产品把 `dsh-plugin` topic 当 SEO 通道（挂上 = 出现在 1802 仓库的浏览流里）；纯梗仓库（竹知了 2.7k 星）说明该 topic 已进入中文社区的玩梗循环——**生态热度的标志，也是信噪比的代价**。

### 2.2 真插件的六大赛道

| 赛道 | 代表 | 对应框架机制 |
|---|---|---|
| **Web UI 扩展** | dsh-web-ui、DSH-better-sidebar、dsh-genui、dsh-visualize、皮肤/桌宠（deep-whale、whale-girl、petdex） | `ui-*` 插件 + slots + ChatNodeMap（04-assembly 笔记 §2）；`.dsh-plugin` 格式与 config.yaml 安装 |

| **发现/目录/文档** | 4 个 awesome 列表、dsh-find-plugins、dsh-handbook | 官方**无 marketplace**（插件机制笔记 §4）——发现层完全由社区自建，且 Radar→精选的两段式质量门思路与官方测试文化同构 |

### 2.3 关键洞察

1. **扩展点分布验证了架构赌注**。官方提供的四类扩展面（Cordis 插件 / Web UI slot / skill 数据 / MCP 桥）全部长出了头部社区项目——"一切皆插件"不是口号，是社区用 star 投票的结果。最深的两条：Web UI slots（改"宿主长什么样"）和 skill（改"模型会什么"，且零代码）。
2. **无 marketplace 是刻意留白**。仓库内无任何插件市场机制（`dsh plugin add` 只是把 npm 包写进 profile）；发现层由 4 个 awesome 列表 + 发现插件 + 手册补齐。类比早期 Homebrew：核心管安装，目录归社区。
3. **skill 是跨 harness 的通用货币**。头部 skill 包（archify、colleague-skill、harmony-next、sealos-skills）全部同时面向 Claude Code/Codex/DSH 多宿主——因为 SKILL.md 是数据不是代码，谁都能加载。**插件绑生态、skill 绑工作流**，两条曲线分叉。（SKILL.md 已标准化为 [agentskills.io](https://agentskills.io) 开放格式，46 客户端采纳——深度解析见 [`前沿与媒体/103-AgentSkills开放标准深度解析.md`](../../../../前沿与媒体/103-AgentSkills开放标准深度解析.md)）
4. **"第一个 X 插件"是有效的定位策略**。modlens 自称"全网第一个视觉插件"（1.1k 星）：生态早期，空白赛道 + 明确声明 = 头部。
5. **周边载体证明运行时中性**。Electron 桌面端、社区发行版（oh-dsh：TUI+桌面+Web 统一分层安装）、甚至竞品工作台（iPolloWork）都把 dsh 当**引擎**嵌入——harness 越像库，宿主形态越多。
6. **刷量模式可识别**：无描述仅 topic（easyeda-agent）、企业无关 CLI（tencentmeeting-cli）、老项目补 tag（PicGo-Core）、竞品（KimiX）、纯梗（zhuzhiliao）。治理启示：topic 是无准入的元数据，**质量信号要看"是否声明 `dsh.bundle`/`.dsh-plugin` 格式、是否有 SKILL.md、是否走 `dsh plugin add` 安装路径"**。

### 2.4 对 harness 工程的借鉴

- **插件 API 的表面积决定生态形状**：dsh 的 slots 让 UI 也是插件 → 皮肤/桌宠/面板这类"低门槛高展示度"插件大量涌现，这是冷启动燃料。
- **官方做机制、社区做发现**：不建 marketplace 反而催生 4 个列表竞争——发现层的演化速度比官方目录快。
- **数据型扩展（skill）的传播成本是代码型的 1/10**：跨宿主 skill 包的星数普遍高于同功能插件。设计扩展点时留一条"纯数据"通道。
- **诚实边界**：本清单基于 topic 页抓取快照（2026-08-14），star 与分类含主观判断；`>66` 阈值下界恰在列表页第 3 页末尾，覆盖完备（第 4 页起 ≤65）。
