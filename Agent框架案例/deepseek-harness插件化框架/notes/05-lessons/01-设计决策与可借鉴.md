## 2. 同类对比

| 维度 | dsh | Claude Code | opencode / Codex 类 |
|---|---|---|---|
| harness 本身可插件化 | ✅ 全部（含 loop/日志） | 配置层（hooks/skills），核心闭源 | 部分（MCP、扩展点） |
| 能力接缝三角色 | ✅ 制度化（+文档+门禁） | 隐式 | 隐式 |
| 会话事实源 | 单一 append-only 日志，运行时断言 | 内部 transcript | 各异 |
| 沙箱 | 三平台原生（bwrap/Landlock/Seatbelt/Win ACL）+ 先审后执升级 | 平台沙箱 / 权限模式 | 权限模式为主 |
| 子 agent | 7 provider（含竞品 codex/claude-code 作为出身） | 单一内建 | 单一内建 |
| 外部协议 | JSON-RPC SDK + ACP + Python 单文件 | SDK/CLI | CLI/MCP |
| 状态 | developer preview（无兼容承诺） | 商业成熟 | 成熟 |

**dsh 的独特卖点**：把同类产品"内建"的一切（loop、审批、记忆、子代理、甚至 Web UI 行）全部还原为可替换插件 + 可审计日志。代价：概念面大（219 包）、pre-release 漂移快。

## 3. 已知局限（v0.1.0-rc.5，官方自认）

1. **developer preview**——README 明示破坏性变更；无外部消费者，优先正确地基而非兼容垫片（`AGENTS.md:5-7`）。
2. **Windows 沙箱 partial enforcement**——WRITE_RESTRICTED 保留 Everyone SID、NTFS 硬链接别名（`sandbox-local/src/index.ts:8-19` 注释）。
3. **Web 载体无认证层**——`0.0.0.0` 故意不支持；栅栏是可达性策略（`connection/README.md:9`）。
4. **E2B 仍是 POC**（`packages/README.md` 标 POC）。
5. **vendored Cordis 18 处本地修改**——升级需按 manifest 重放（`vendor/README.md:29-50`）。

## 4. 对本项目的借鉴清单（写作时可直接引用）

- 写 agent loop 设计 → 引用 turn/step 状态机与"零 step turn"（loop 笔记）。
- 写记忆/会话设计 → 引用 event sourcing + surface 投影（session 笔记）——与 mem0 案例（检索式记忆）成对照：**dsh 证明"不检索、只重放"也够用**。
- 写 agent 安全 → 引用信任七机制表（trust 笔记 §8）——与 `欺骗动力学-AI纪实验包.md` 实验 5 互链。
- 写插件化/扩展性 → 引用接缝三角色 + 组合即数据（seams/assembly 笔记）。
- 写工程文化 → 引用门禁即产品 + Agent Note 制（本篇 §1 #14）。
