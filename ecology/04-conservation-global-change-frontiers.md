## 十三、保护生物学（"危机学科"，Soulé 1985）

### 13.1 灭绝的科学
- 背景灭绝率 ~0.1–1 种/百万种·年；当前高 100–1000 倍 → **第六次大灭绝**（Kolbert 普利策奖）
- IUCN 等级：LC/NT/VU/EN/CR/EW/EX
- **HIPPO**（Wilson）：栖息地丧失、过度开发、入侵种、污染、气候变化
- **灭绝债**（Tilman 1994）：栖息地已毁，灭绝延迟但注定
- **Allee 效应**：密度过低 → 小种群漩涡

### 13.2 保护区设计
- **SLOSS 辩论**：现代共识"大、连通、圆"
- MVP ~50/500 规则（Franklin）；**PVA**（矩阵/随机模型算灭绝概率；注意 Ellner 等对 PVA 过度自信的批判）

### 13.3 保护策略演进
堡垒保护（黄石模式，殖民色彩批判）→ 社区保护（CBCD）→ **再野化**（狼回黄石）→ **Half-Earth（E.O. Wilson）** → **30x30**（《昆明-蒙特利尔框架》2022）→ de-extinction（Colossal 猛犸象项目）

## 十四、全球变化生态学（人类世，Crutzen 2000）

### 14.1 五大驱动
气候变化（物候错配）、生物地球化学改变（N/P 翻倍、海洋酸化）、土地利用变化、**生物同质化**、大气成分。

### 14.2 气候-生态正反馈（最危险）
永冻土→甲烷；森林枯死→碳释放；海洋酸化→钙化崩溃；**亚马逊部分区域已从碳汇转碳源**（2021）。

### 14.3 Living Planet Index
1970–2020 脊椎动物种群下降 ~69%（WWF 2022，淡水最重）。

## 十五、临界点与稳态转换（最前沿）

### 15.1 稳态转换（Scheffer 2001/2009）
多稳态 + 超过生态韧性阈值 → 突变 + **滞后**（移除扰动也不回）。清澈湖 ↔ 浊湖；萨瓦纳 ↔ 雨林。

### 15.2 数学：fold 分岔
平衡态曲线折叠；逼近折叠点 → **临界慢化（critical slowing down）**：恢复速率 → 0。

### 15.3 早期预警信号（EWS）
| 信号 | 现象 |
|------|------|
| 方差 ↑ | 扰动放大 |
| AR(1) ↑ | 状态记忆增强 |
| 互相关 ↑ | 子系统同步 |
| 偏度 ↑ / 闪烁 | 不对称 / 暂时越界 |
| 谱红移 | 低频功率升 |

数值验证见 `ews_tipping.py`：Var Kendall τ=0.24(p=1.6e-5)、AR(1) τ=0.93(p=9.1e-63) 显著上升。方法已外溢到气候/金融/医学。

### 15.4 地球临界点（Lenton 2008/2019）
9 大临界要素 + **级联（tipping cascades）**（详见第六篇表）。"1.5°C 而非 2°C"的科学根据。

## 十六、地球边界（Rockström 2009，2023 更新）

9 个地球系统过程：气候变化、生物圈完整性、生物地球化学流（N/P）、土地利用、**新型实体**、淡水、海洋酸化、气溶胶、臭氧。
**2023：6 项已越界**（前五 + 淡水临界）。臭氧在恢复（蒙特利尔议定书成功案例）。

## 十七、前沿技术：测量革命

### 17.1 eDNA / 宏基因组（详细流水线见第六篇）
环境 DNA → metabarcoding → DADA2/分类比对 → 群落统计。比传统样方法快几个数量级。

### 17.2 生态 AI
| 任务 | 方法 |
|------|------|
| 相机陷阱物种识别 | CNN（Wildlife Insights、Snapshot Serengeti）|
| SDM | MaxEnt / GLM / GAM / BRT / RF / 深度 SDM |
| 遥感 | U-Net 分割、Global Forest Watch 实时砍伐监测 |
| 声景 | 音频 CNN（Rainforest Connection）|
| 多模态 | **BioCLIP / TreeOfLife-10M（2024）**零样本物种识别 |

三大挑战：长尾（罕见种样本少）、数据偏倚（欧美过采样）、分布外泛化。

### 17.3 SDM 算法
**MaxEnt（Phillips 2006）**：最大熵原理，presence-only 事实标准，等价于正则化对率回归。

### 17.4 捕获-重捕
Lincoln-Petersen $N = MC/R$；**Cormack-Jolly-Seber**（MARK/RMARK）；空间捕获重捕 SCR。

### 17.5 生物多样性估算
Chao1 / ACE（稀有种外推）；rarefaction（稀疏化）。

## 十八、多视角批判

### 18.1 生态伦理学
| 流派 | 主张 | 代表 |
|------|------|------|
| 人类中心 | 只人有内在价值 | 传统 |
| 生物中心 | 所有生命有内在价值 | Taylor |
| 生态中心/整体 | 物种、系统有价值 | **Leopold 土地伦理（1949）** |
| 深层生态学 | 生物圈平等 | **Næss 1973** |
| 生态女性主义 | 压迫女性与自然同源 | Warren, Merchant |
| 动物权利 | 个体不可侵犯 | Singer / Regan |

关键区分：**整体主义 vs 个体主义**（详见第六篇深辩）。

### 18.2 原住民传统生态知识（TEK）
火烧管理、轮作、渔业禁忌；批判殖民保护；**两眼通看（Two-Eyed Seeing）**；联合管理、权益型保护。

### 18.3 生态经济学
《增长的极限》（Meadows 1972，Turner 2008 核验）；生态足迹 1.7 地球；**Doughnut（Raworth 2017）**；稳态经济（Daly）、degrowth；生态系统服务（MA 2005）——政治有效但"自然商品化"争议。

### 18.4 认识论反思
平衡范式衰落 → 非平衡/历史偶然/多稳态；"原始自然"多为人类塑造（基线问题）；**novel ecosystems（Hobbs 2006）**——该接纳还是抗争？
