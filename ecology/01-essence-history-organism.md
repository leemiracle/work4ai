# 第一篇：本质 · 历史 · 学科层级 · 个体与生理生态 · 生活史

> 生态学的灵魂是**尺度（scale）**与**联结（connection）**——一只蝴蝶的翅膀、一片森林的呼吸、全球碳循环，是同一个故事的不同镜头。

---

## 〇、全景：生态学是什么？

**一句话定义**：生态学是研究**生物与其环境（生物环境 + 非生物环境）之间相互关系**的科学（Haeckel 1866 首次提出 "Ökologie"，源自希腊语 *oikos* = "家"，与 economy 同源——**生态学就是"自然的家政学"**）。

现代生态学要回答四个根本问题：
1. **分布**（Why here?）——为什么这个物种在这里而不是那里？
2. **多度**（How many?）——为什么这个种群数量这么多/这么少？
3. **过程**（How does it work?）——能量与物质如何流动？
4. **演化与命运**（What will happen?）——系统会如何随时间和变化而改变？

## 一、生态学的组织层级（学科骨架）

```
生物圈 Biosphere          ← 地球系统生态学 / 全球变化生态学
  └ 生态系统 Ecosystem    ← 生态系统生态学（能流、物质循环）
      └ 群落 Community    ← 群落生态学（物种互作、多样性、演替）
          └ 种群 Population ← 种群生态学（动态、增长、调节）
              └ 个体 Organism ← 个体/生理生态学（适应、耐受、生活史）
                  └ 组织/器官/细胞 ← 生理学（生态学的下边界）
                      └ 分子/基因 ← 分子生态学、进化生态学
```

- **景观生态学**横切层级（空间格局），**进化/行为生态学**贯穿所有层。
- **核心张力**：层级间有**涌现性（emergence）**——"整体 ≠ 部分之和"是生态学对抗还原论的根本立场。

## 二、历史与范式转变

| 时期 | 范式 | 代表 |
|------|------|------|
| 18C前 | 自然史 | 亚里士多德→林奈→洪堡 |
| 1866 | 命名 | **Haeckel** |
| 1890s–1920s | 有机体论/超有机体 | Clements（顶极 climax） |
| 1920s | 个体论/连续体 | Gleason（大论战） |
| 1920s–30s | 定量种群生态学 | Lotka-Volterra、Gause |
| 1950s | 能量生态学 | Lindeman（1942）、Odum 兄弟 |
| 1960s | 岛屿生物地理学 | MacArthur & Wilson（1967） |
| 1960s–70s | 生态位理论 | Hutchinson（n 维超体积） |
| 1970s | r/K 选择、博弈论 | Maynard Smith（ESS） |
| 1970s | 稳定性-复杂性辩论 | **May 1972：复杂性反而降低稳定性！** |
| 1980s | 集合种群、韧性 | Levins, Holling |
| 1990s | 空间生态学、BEF | Tilman, Naeem |
| 2000s | 网络生态学、全球变化 | 复杂网络、气候-生态耦合 |
| 2010s | 大数据/基因组/遥感 | eDNA、宏基因组、卫星 |
| 2020s | 临界点、地球边界、生态 AI | Rockström、Anthropocene |

**两个未决根本之争**：
1. **平衡 vs 非平衡**：群落趋向稳定平衡（Clements-Odum），还是永远非平衡涨落（Gleason-现代复杂系统）？现代共识：局部稳定、全局漂移，但有临界点。
2. **还原 vs 整体**：能否用种群动力学还原生态系统？涌现论者说不能。

## 三、个体生态学 / 生理生态学

### 3.1 限制因子定律

**(1) Liebig 最小因子定律（1840）**：生长受**最稀缺的必需因子**限制（木桶理论）。
**(2) Shelford 耐受性定律（1913）**：每物种对每因子有耐受范围 [下限, 上限]，最适点居中。耐受窄 = 狭适性（steno-），广 = 广适性（eury-）。→ 生态位概念的物理基础。

### 3.2 主要生态因子

| 因子 | 作用 | 经典现象 |
|------|------|---------|
| 光 | 光合、节律、光周期 | 阳/阴性植物、长/短日照 |
| 温度 | 酶活性、代谢 Q10 | Bergmann（寒区体型大）、Allen（附肢短）|
| 水 | 生化介质 | 渗透调节 |
| 土壤/矿质 | 营养 | 盐碱/钙质植物 |
| 火 | 干扰、再生 | 火依赖种子 |
| O₂/CO₂ | 呼吸光合 | 缺氧区、海洋酸化 |

### 3.3 适应的三种时间尺度

| 类型 | 尺度 | 机制 | 可逆性 |
|------|------|------|--------|
| 驯化 acclimation | 天~周 | 生理调节 | 可逆 |
| 表型可塑性 | 个体发育期 | 同基因型不同表型 | 部分可逆 |
| 进化适应 | 多代 | 选择改变基因频率 | 不可逆 |

### 3.4 Kleiber 定律与 WBE 理论（"大统一"候选）

**Kleiber（1932）**：基础代谢率
$$B = B_0 \cdot M^{3/4}$$
横跨细菌到鲸鱼 **27 个数量级**。

**West-Brown-Enquist（1997/99）**：**分形分支传输网络**（空间填充、终端单元不变、能耗优化）推导出 3/4。

**代谢标度理论（MET）**：用 $M^{3/4}$ 推广解释种群增长率、寿命、世代时间、密度——生态学的"大统一理论"尝试。部分成功，也备受争议。

### 3.5 异速生长四分之一幂律

- 心率 $\propto M^{-1/4}$、寿命 $\propto M^{1/4}$、种群密度 $\propto M^{-3/4}$（Damuth 能量等价）、世代时间 $\propto M^{1/4}$
- "**生命的四分之一幂律**"——生态学最接近物理定律的东西。

## 四、生态位（Niche）——最核心也最多歧义的概念

| 提出者 | 年代 | 定义 | 侧重 |
|--------|------|------|------|
| Grinnell | 1917 | 环境和栖息地（"地址"） | 空间 |
| Elton | 1927 | 食物网功能角色（"职业"） | 营养 |
| **Hutchinson** | 1957 | **n 维超体积** | 多维抽象 |

- **基础生态位**（无竞争）vs **实际生态位**（含互作，⊆ 基础）。
- **竞争排斥原理（Gause 1934）**：完全相同生态位 → 必然排斥。共存物种必然生态位分化。
- Hutchinson 超体积的计算实现 = **物种分布模型 SDM/ENM**（MaxEnt 等）。

## 五、生活史对策

### 5.1 r/K 选择（MacArthur & Wilson 1967）

| | r-选择者 | K-选择者 |
|--|---------|---------|
| 环境 | 多变短暂 | 稳定可预测 |
| 繁殖 | 早、多、一次 | 晚、少、多次 |
| 后代 | 多、小、无照顾 | 少、大、重照顾 |
| 代表 | 昆虫、杂草 | 大型兽、乔木 |

### 5.2 CSR 三角（Grime 1979，植物）
C 竞争型（高资源低干扰）/ S 胁迫忍耐型（低资源低干扰）/ R 杂草型（高资源高干扰）。

### 5.3 快慢连续体（现代整合）
r/K 实为一维"快-慢"轴，由代谢与体型驱动（与 WBE 相通）。

### 5.4 生活史不变量（Charnov 1993）
跨物种无量纲不变量（如繁殖起始年龄/寿命 ≈ 常数）——生态学向物理式普适律的雄心。

### 5.5 三大权衡
1. 数量 vs 大小（Lack clutch size）
2. 当前 vs 未来繁殖（semelparity vs iteroparity）
3. 生长 vs 繁殖

数学基础：适合度最大化 + 资源约束下的最优分配（拉格朗日/动态规划）。
