# 09 · ★ Meta / Self / Evo：harness 优化 harness 的能与不能

> 核心实验：**E7 mini-Evo 外环**（[experiments/e7_mini_evo.py](../experiments/e7_mini_evo.py)，results/e7_mini_evo.json）｜姊妹活案例：[讲透Loop E4 双相外环](../讲透Loop/)（8%→53.3%）

## 直觉

论述里的"Meta-Harness（生成 harness）/ Self-Harness（运行时自调）/ Evo-Harness（进化搜索）"是同一件事的三个侧脸：**把 harness 本身变成优化对象**。AHE（arXiv:2604.25850）是这条线的旗舰证据——但它的另一面（消融与过拟合）同样重要。本章用 E7 把两面都摸一遍。

## AHE：旗舰证据与其边界（已核实）

| 发现 | 数字 | 读法 |
|---|---|---|
| 自动进化 harness（GPT-5.4-high 外环） | Terminal-Bench 2：69.7→77.0（**+7.3pp**，超人工 Codex 71.9%） | 进化 > 人工设计 |
| 消融 | 增益全在 tools/middleware/长期记忆；**system prompt-only 负收益** | 优化要动结构层，别动文案层 |
| 跨模型迁移 | +2.3~+10.1pp（弱模型获益大） | 收益随模型饱和衰减 |
| 同家族非单调 | medium +2.3 / high +7.3 / xhigh +2.3 | **超参（step budget/timeout）对模型过拟合** |
| 方法纪律 | 冻结迁移验证（TB 进化→SWE-bench 验证） | 防"对进化基准过拟合" |

## 本地复现（E7）：小样本上的搜索是伪命题

设计：贪心 hill-climbing 搜 harness 配置（retries ∈ {0,1,2} × feedback ∈ {raw,guided}，模型/温度/seed 全冻结），train t1-t4 选配置 → held-out t5-t8 验证迁移。

```bash
cd 讲透Harness/experiments && timeout 1400 python3 e7_mini_evo.py
```

**结果（results/e7_mini_evo.json）**：

| 阶段 | 配置 | 得分 |
|---|---|---|
| train baseline | (1, raw) | 3/4 = 75%（6 calls） |
| train 扫 retries=0 | (0, raw) | 2/4 = 50%（更差） |
| train 扫 retries=2 | (2, raw) | 3/4 = 75% 平手但 7 calls（更贵） |
| train 扫 guided | (1, guided) | 3/4 = 75% 平手 |
| **终配置** | **(1, raw) = 默认本身** | 搜索零收益 |
| held-out chosen | (1, raw) | **4/4 = 100%** |
| held-out baseline | (1, raw) | 4/4 = 100%（gap=0 恒等） |

![E7](../experiments/results/e7_mini_evo.png)

## 三个读数（负结果的三层剥洋葱）

1. **搜索零收益**：17 次调用扫完全空间，结论"默认就好"。在 4 任务池上，harness 超参搜索的成本 > 收益——**AHE 的 +7.3pp 需要全基准池 × 10 轮进化的预算**，不是配置旋钮的免费午餐。
2. **难度方差淹没配置效应**：train 75% vs held-out 100%（t4 slugify 对 0.5B 难，t5-t8 容易）——样本远小于效应量时，你测到的是任务难度，不是配置好坏。
3. **gap=0 是恒等式不是成功**：chosen==baseline 时"迁移 gap"没有信息量。**报告实验时先问度量的自由度**——这一条是 E7 给所有"搜索型优化"实验的方法论警告。

**结论（论述概念的诚实边界）**：Meta/Self/Evo-Harness 谱系是真的（AHE 证据链），但它有**入场费**：足够大的任务池（私有回归集，exercises #11 是起步）+ 冻结迁移验证 + 结构层（工具/中间件/记忆）而非文案层。没有这三样，"harness 优化 harness" 退化为昂贵的自我安慰。

## 姊妹活案例：讲透Loop E4（正结果侧）

同一思想的正结果版本已在姊妹单元跑通：双相外环（自评→验证器校正）8%→53.3% + Goodhart 剪刀差现场——它优化的不是配置而是**循环的验证结构**，且任务分布够大。E7（配置轴，负结果）与 Loop E4（结构轴，正结果）合起来才是完整故事：**优化什么比优化本身更重要**。
