# 讲透十九世纪末至二十世纪中叶西方哲学 · 世纪之交的产房:旧轴断裂与三大原创的诞生

> **定位句**:这支负责「**换轴的第一现场**」——从古典体系崩塌(1870s)到战后重组(1950s),
> 现代哲学的全部基因(分析/现象学/实用主义/解释学/符号学)都在这八十年里配对完成。
> GB/T 13745 72035 现代外国哲学 · GB/T 三级。家族:[讲透现代外国哲学](../README.md)

## 诞生

- **谁/何时**:尼采(1872《悲剧的诞生》-1900 逝世)宣判「上帝死了」;
  狄尔泰 1883《精神科学引论》为人文科学争方法论;新康德主义(马堡/西南两派)
  以「回到康德」统治德语学界;柏格森生命哲学横扫世纪之交的巴黎。
- **因什么问题**:①黑格尔体系死后「哲学还能做什么」的空位竞赛;
  ②自然科学(进化论/物理学)挤压下人文经验的辩护问题;③「历史感」的兴起
  (历史主义:一切思想都有时代地址)。
- **关键定格**:1900 前后三事件同时引爆(弗雷格冲击波/《逻辑研究》/实用主义被命名——
  家族 [00 章](../00-体系结构.md) §一的完整故事);1929 达沃斯论战(卡西尔 vs 海德格尔)
  为「新康德主义→生存哲学」的换代加冕。

## 核心问题

**已解决**:
- 「哲学=体系建构」的古典范式被正式替换为「哲学=方法论自觉」——三大原创各立方法
- 人文科学(精神科学)的自主性有了纲领(狄尔泰:理解 vs 说明的二分)
- 哲学史写作自身的哲学化(哲学史不再是意见博物馆,而是问题史)

**未解决/深水区**:
- 尼采的「重估一切价值」是完成了还是流落为风格(与大陆支共管)
- 生命哲学的「直接经验」诉求与自然科学的第三人称方法,整合无共识
- 「时代诊断」作为哲学文体的合法性(诊断的判据是什么——同宇宙自然辩证法共管)

## ✨ 这支最美的一个事实

**达沃斯 1929**:卡西尔(新康德主义王座,「人是符号的动物」)与海德格尔(《存在与时间》
出版两年,「此在」旋风)在瑞士雪山上当面对质——卡西尔护住文化的普遍性,
海德格尔挖出有限性的深渊。听众里有年轻的列维-斯特劳斯和伽达默尔。
一个时代的上半场与下半场同桌留影,十年后二战把它变成绝版。
**一支哲学史的换挡现场被完整记录成文献——这在哲学史上几乎唯一。**
