# 讲透现代外国哲学 · 哲学的语言学转向之后——两条河与一张意义地形图

> **本质一句话**:现代外国哲学=哲学的**语言学转向之后**——
> 古典体系(笛卡尔到黑格尔)在十九世纪末崩塌后,哲学不再直接谈世界与心灵,
> 而是先审查**谈世界与心灵的语言**;这一审查分成两条河:
> **分析的河**(把语言的形式结构照清楚:弗雷格-罗素-维特根斯坦-维也纳学派)与
> **大陆的河**(把语言的生存境域揭出来:胡塞尔-海德格尔-萨特-伽达默尔),
> 外加三条公共水系(实用主义/符号学/解释学)。本家族=两河全流域地图。
>
> GB/T 13745-2009:720 哲学 · 二级学科 **72035 现代外国哲学**
> (GB/T 三级:十九世纪末至二十世纪中叶西方哲学/分析哲学/欧洲大陆人文哲学/解释学/符号学/实用主义哲学/现代外国哲学其他学科)。
> 宇宙:[../README.md](../README.md)(一级 720 全景,本家族代码序第六)。

## 〇、家族树(GB/T 三级 6 支落子)

```
讲透现代外国哲学/
├── 讲透十九世纪末至二十世纪中叶西方哲学/  GB/T 三级——世纪之交的产房:古典体系崩塌与三大原创的诞生
├── 讲透分析哲学/                          GB/T 三级——语言批判与逻辑分析:弗雷格→罗素→维特根斯坦→蒯因→克里普克
├── 讲透欧洲大陆人文哲学/                  GB/T 三级——现象学→存在主义→他者伦理:胡塞尔→海德格尔→萨特→列维纳斯
├── 讲透解释学/                            GB/T 三级——理解如何可能:施莱尔马赫→狄尔泰→海德格尔→伽达默尔
├── 讲透符号学/                            GB/T 三级——意义的一般科学:皮尔士三分号 vs 索绪尔二元符号
├── 讲透实用主义哲学/                      GB/T 三级——观念是行动的工具:皮尔士→詹姆斯→杜威→罗蒂
└── (现代外国哲学其他学科 → 兜底,见 §三)
```

> 六支的共同血统:**都从「哲学该用什么方法」的世纪总危机里出生**——
> 分析支答「把语言逻辑化」,大陆支答「回到事情本身」,解释学答「理解必有前结构」,
> 符号学答「意义在差异与解释项」,实用主义答「观念的意义=实践差分」。
> 五个答案,一个考题。

## 三、长尾归属与兜底(穷尽声明)

- **现象学**:GB/T 未单列——作 [`讲透欧洲大陆人文哲学/README.md`](讲透欧洲大陆人文哲学/README.md) **内节**
  (从胡塞尔《逻辑研究》到梅洛-庞蒂身体现象学,这一脉的根就是大陆人文哲学的主干,
  不是并列地盘;海德格尔同理——他在解释学支与本支双挂号,以本支为主)。
- **结构主义与后结构主义**(索绪尔语言的继嗣:列维-斯特劳斯/拉康/巴尔特/德里达/福柯)
  → 不设支:巴尔特/艾柯一脉归 [`讲透符号学/README.md`](讲透符号学/README.md),
  德里达的解构与福柯的知识考古归 [`讲透欧洲大陆人文哲学/README.md`](讲透欧洲大陆人文哲学/README.md) 内节。
- **西方马克思主义/法兰克福学派**(霍克海默/阿多诺/马尔库塞/哈贝马斯)
  → 归同宇宙马克思主义哲学家族的「国外马克思主义研究」内节(文字提及,建成互链);
  本家族解释学支只收哈贝马斯-伽达默尔之争的方法论侧。
- **「现代外国哲学其他学科」**(GB/T 兜底类)→ 不设系列;零散条目(过程哲学/怀特海、
  弗洛伊德主义哲学、新托马斯主义等)按近亲归入六支,成气候再立支。
- 与哲学宇宙兄弟家族的边界(逻辑学/自然辩证法/美学/西方哲学史):
  见 [`00-体系结构.md`](00-体系结构.md) §三领土谈判;同波兄弟建成后互链回填。
