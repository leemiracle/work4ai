## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **语言哲学类**:意义、指称、涵义、摹状词、真理条件、「这句话什么意思」、
  分析真理 vs 综合真理、同义性、定义之争
- **分析传统类**:逻辑分析、证实、可证伪、维特根斯坦、维也纳学派、
  日常语言、言语行为、语力、会话含义(implicature)、格赖斯准则
- **现象学/存在主义类**:意向性、「关于性」、第一人称视角、悬搁、
  本质变更、生活世界、此在、在世存在、存在先于本质、身体性、他者
- **解释学类**:理解如何可能、前见/偏见、解释学循环、视域融合、
  经典重读、「文本的本义」、接受与效果历史
- **实用主义类**:观念的实践差分、探究、信念与怀疑、真理=验证过程、
  概念工程、做哲学 vs 建体系
- **符号学类**:能指/所指、符号三分、差异生义、解释项、隐喻机制
- **AI×哲学类**:机器能否理解、中文屋、图灵测试的意义、LLM 有没有意向性、
  提示词为什么有效、零样本的哲学地位

## ② 核心思维模式(这个分支怎么想问题)

1. **语法体检先行**:斩钉截铁的句子先拆逻辑形式——表面语法承诺了哪些
   不存在的对象?(「当今法国国王是秃头」的麻烦不在世界在语法)
2. **担保方案分诊**:听到「X 有意义/无意义」,先问担保方案是哪一家
   (证实/使用/真值条件/涵义)——四家各有失败方式,没有全胜方案
3. **循环分诊**:见到「循环」先分诊——定义图里的环(bug,要报错)
   还是理解图里的环(bootstrap,是理解的生产条件)?同一个环两种命运
4. **前见显题化**:不存在零立场的理解——把初始投射写下来再迭代
   (解释学螺旋:投射→被顶回→修订,错误是初值不是噪音)
5. **方法账单**:任何方法论纯化都是议题取舍(清晰↔窄化)——
   接受一个方法先填「假设/买到/付出」三行表
6. **操作化之眼**:形而上问题问一句「能否改写成可判定的协议」
   (图灵动作);但记住操作化换掉的是问题的级别,不是答案

## ③ 工具箱(理论/程序 + 何时用)

| 工具 | 一句话何时用 |
|------|-------------|
| 摹状词拆解(The F is G→∃∧∀∧G) | 消除「不存在的对象」类伪问题;需求文档的语法体检 |
| 证实原则(及其自指失败) | 判断一句话是否可检验;同时警惕对不可检验议题的过度清洗 |
| 意义=使用(后期维特根斯坦) | 概念争议先看用法分布,别急着找本质定义(家族相似) |
| 格赖斯四准则(量/质/关/方式) | 提示词/需求文档/技术写作的清晰度检查表 |
| 言语行为三分(语谓/语力/语效) | 分析指令、预设、间接请求;提示的语力审计 |
| 悬搁+本质变更 | 概念澄清的第一人称程序:变换实例找不变项 |
| 解释学螺旋(不动点迭代读法) | 读经典/读旧代码/读需求:三轮迭代优于一次「客观」通读 |
| 皮尔士探究循环(abduction→deduction→induction) | 故障排查/根因分析的标准循环;怀疑要有真实触发 |
| 实践差分准则 | 一个概念之争先问:接受与否对后续行动有什么差别? |
| 卡尔纳普阐释四标准(似/精/简/多产) | 概念重构/领域建模/定义评审(概念工程的操作版) |
| 蒯因整体论(信念之网) | 「修定义还是修事实」无算法规定——预测失败后的修补自由度是真实的 |
| 中文屋/句法≠语义红线 | 给「全自动理解」的宣称划界:工程做近亲,不做哲学替身 |

## ④ 常见误区与禁忌

- ❌ **把「分析 vs 欧陆」当愚智之分**:分叉一半是 1933 年后机构/流亡的社会学固化,
  不是本质之争;两边互相能读懂对方的病历
- ❌ **把维特根斯坦读成一个人**:前后期是两套相反纲领(图像论→语言游戏);
  引用必须标明时期
- ❌ **把解释学循环当恶性循环**:前见是理解的初值;「无前见的客观解读」
  得到的不是客观是空转
- ❌ **把实用主义读成「有用即真」**:那是庸俗版;原版问的是观念的
  **实践差分**与探究的收敛条件
- ❌ **把「意义=使用」直接兑现给 LLM**:分布语义是「使用」的统计化身,
  是实验材料不是结论(走廊 B 的开放点)
- ❌ **零样本神话**:模型的预训练分布=默认前见;「零样本」应译作
  「使用默认前见」,提示=前见手术
