# 讲透实用主义哲学 · 观念是行动的工具:从实践差分准则到概念工程

> **定位句**:这支负责「**意义落户实践**」——
> 一个观念的意义=它的实践差分(接受与否,经验会有什么可察觉的差别);
> 真理不是与实在的静止符合,而是在探究共同体中不断被验证的过程。
> GB/T 13745 72035 现代外国哲学 · GB/T 三级。家族:[讲透现代外国哲学](../README.md)
> 血统:皮尔士(1878 准则)→詹姆斯(1898 命名,1907《实用主义》)→
> 杜威(探究理论/工具主义)→刘易斯-蒯因系谱→罗蒂新实用主义(1979)→概念工程(当代回声)。

## 诞生

- **谁/何时**:皮尔士《如何使我们的观念清晰》(1878)立准则;1898 年詹姆斯
  加州演讲借走「实用主义」一名推向世界(皮尔士另名「实效主义」自保);
  杜威把工具主义写进芝加哥学派与教育哲学;二战后经刘易斯传给蒯因
  (两个教条的批判带着实用主义血统);罗蒂《哲学与自然之镜》(1979)引爆新实用主义。
- **因什么问题**:①观念清晰性的可操作标准(对「清晰」「分明」的笛卡尔式宣称不耐烦);
  ②学院形而上学争论的空转(争了几百年不影响任何经验的命题=伪问题);
  ③实验科学的时代精神要求哲学把「探究」而非「静观」当作模型。

## 核心问题

**已解决**:
- 实践差分准则:概念争议的快速分诊(无实践差分的争点可以搁置)
- 探究循环:信念(习惯)→怀疑(真实触发)→探究(溯因-演绎-归纳)→新信念
  (家族 [03 章](../03-可构造与结构.md) §1.3 的程序版)
- 「笛卡尔普遍怀疑是伪程序」的批判:怀疑是事件,不是可以自由调用的方法

**未解决/深水区**:
- 真理的收敛论题:探究共同体的长期共识是否趋近真理(皮尔士的信念 vs 罗蒂的反实在论——内战未决)
- 「有用」与「真」的切割:如何不滑向庸俗的「有用即真」
- 概念工程的功能标准:概念「好不好用」由谁的实践判(2024 元伦理学现场,
  与家族 [01 章](../01-近五年创新.md) 主线二共管)

## ✨ 这支最美的一个事实

**皮尔士的实践差分准则**(1878):问「钻石是硬的吗」——
如果「硬」指的是「划伤一切而不被划伤」,而这块钻石烧掉前从未被摩擦,
两种回答**没有实践差分**;一旦实验条件出现(拿它划玻璃),差分显现,
问题自动获得答案。**意义不在观念内部,在观念与实验的接缝上**——
一句准则把中世纪式的「共相之争」就地清场,也预告了七十年后操作主义与分析的清洗剂。

## 假设与依赖

- 押注「意义=实践差分」:买到反空转与科学无缝;付出真理的共识化风险
  (「探究锚定的是意见还是真理」——皮尔士内战)
- 詹姆斯的「真理是验证过程」依赖彻底经验主义(经验=流,不是感觉原子);
  杜威的工具主义依赖情境本体论(思想是解决问题的器官)
- 与分析传统的通婚(刘易斯→蒯因→概念工程)是本支当代生命线;
  与大陆传统也有近亲(杜威与海德格尔都对「理论优先」翻脸)
