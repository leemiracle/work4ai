# 讲透符号学 · 意义的一般科学:三分号与二元符号的两条建国路线

> **定位句**:这支负责「**意义的形式条件**」——
> 不是研究某个符号系统(那是各学科自己的事),而是研究「一物代表另一物」这件事本身:
  皮尔士的三分号(符号-对象-解释项)与索绪尔的二元符号(能指-所指)各建一国。
> GB/T 13745 72035 现代外国哲学 · GB/T 三级。家族:[讲透现代外国哲学](../README.md)
> 血统:皮尔士(1867-1914)与索绪尔(《普通语言学教程》1916)互不知情地双开国;
  莫里斯三分(句法/语义/语用,1938)→巴尔特/艾柯的文化符号学(1960s-)。

## 诞生

- **谁/何时**:皮尔士从逻辑与范畴论出发:符号=再现体-对象-解释项的三元关系,
  解释项又引发新符号——意义是**无限衍义**(semiosis)的过程;
  索绪尔从语言学出发:语言=差异系统,符号=能指/所指的捆绑,
  **「语言中只有差异,没有肯定项」**。
  两条路线 1960s 合流国际符号学运动(塔图学派/巴黎学派)。
- **因什么问题**:①逻辑学的基础(皮尔士:思想即符号过程);
  ②语言学能否成为人文科学模型(索绪尔:语言学的«符号学»蓝图);
  ③意义研究需要一个跨媒介(语言/图像/仪式/商品)的统一框架。

## 核心问题

**已解决**:
- 符号三分法(icon 像/ index 指/ symbol 约)成为一切媒介分析的标准件
- 「差异生义」原则:从音位学到结构主义的发动机(家族 [03 章](../03-可构造与结构.md) §3.1)
- 莫里斯三分(句法/语义/语用)成为 NLP 与语言哲学共享的部门划分

**未解决/深水区**:
- 皮尔士线与索绪尔线的深度整合(「过程一极」与「系统一极」)
- 符号学边界的弹性和争议——「意义的一般科学」是纲领还是越界
- 计算符号学:机器生成的「符号过程」缺不缺解释项(与家族 [04 章](../04-现代外国哲学转代码.md) 走廊 B 共管)

## ✨ 这支最美的一个事实

**皮尔士的无限衍义链**:符号的意义是它引发的下一个符号,下一个又是下下一个……
意义不是终点站的货物,而是**永不到站的传递**——你读这句话时,
每个词都在你心里激起另一个念头,那个念头又是新符号。
(与 60 年后德里达的「延迟」论隔代击掌:两人从不同起点推出同一张欠条。)
亲历:对一个术语追问三层「这让你想到什么?」——链条第一次分叉,
就是你的私人符号系统与词典分道的现场。

## 假设与依赖

- 押注「一切意义皆可入符号之网」:买到跨媒介通吃(语言/图像/文化/代码);
  付出边界失控(「一般意义科学」的领空无限延伸,内爆为方法论风险)
- 皮尔士线依赖三元关系与过程本体论;索绪尔线依赖系统与共时优先——
  两线各自「假设/买到/付出」的账单见家族 [00 章](../00-体系结构.md) §六的方法
- 解释项的非对象化(§「芯」)使符号学永远留一块不可完全形式化的领地
