# 04 · 现代外国哲学转代码:把语言批判装进机器

> **本章回答五问之五(家族层):这个分支的问题怎么变成 code 问题?**
> 本质一句话:**本家族的百年内战在 2020s 有了意外结局——LLM 把
> 「意义是什么」从书斋争论变成工程实验**;两条代码走廊
> (论证形式化/意义理论实验)+ 一个工程师落点(提示工程的语用学),
> 哲学第一次能对自己的核心问题**跑代码**。

## 〇、先给直觉:哲学问题的三种「可跑」

| 哲学问题 | 可跑形态 | 现状 |
|---------|---------|------|
| 「这个论证成立吗?」 | 论证形式化+有效性检查 | 成熟走廊(§二 A) |
| 「这句话什么意思?」 | 意义理论的机器实验(分布语义/语用标注) | 新开走廊(§二 B) |
| 「机器说的话有意义吗?」 | 图灵测试/中文屋的实测重演 | 开放前沿(§一红线) |

## 一、可机械化边界(三件套之一):哪几条线机器迈不过去

| 边界 | 哲学依据 | 工程含义 |
|------|---------|---------|
| **句法≠语义红线** | 塞尔中文屋(1980):符号操作不构成理解 | 形式系统永远缺一样东西(意向性);但 LLM 的分布语义是不是反例=**开放问题**——这是红线不是定理,工程上保持敬畏 |
| **理解=应用红线** | 伽达默尔:理解发生在应用中,无「无立场的解读」算法 | RAG/IR 是检索不是解释;「全自动文本理解」在哲学侧无照驾驶——用途定位要诚实 |
| **前见不可清零红线** | 解释学:无零语境阅读(03 章 §二) | 零样本(few-shot)是神话的另一说法:模型的前见=预训练分布,它不是「无前见」而是「默认前见」;提示=换前见的手术 |
| **溯因无算法线** | 皮尔士:abduction 出好假说是本能+习惯 | LLM 的「假设生成」可批量,优劣判定不可全自动(仍回到人/回到实践检验) |
| **可判定的那部分** | 摹状词翻译/论证有效性(形式化后) | 一旦翻进形式语言,数学宇宙接手:[../../讲透数学/讲透数理逻辑/](../../讲透数学/讲透数理逻辑/) 的可判定孤岛表、SAT/SMT/证明助手全线可用 |

**判据口诀**:「先问这是意义问题还是有效性问题——
有效性问题翻成形式语言(走廊 A),意义问题设计实验(走廊 B),
理解问题(解释/意向性)承认红线,做工程近亲不做哲学替身。」

## 二、代码走廊清单(三件套之二):两条走廊

### 走廊 A:论证形式化——语言批判的工程直译

**理论**:罗素摹状词(1905,第一条人话→逻辑的翻译规则)→
自然语言推理(NLI)与论证挖掘(argument mining,2015-)→
NL→FOL 神经翻译(2020s,LLM 时代的新货)。

**流水线**(可自己搭最小版,纯标准库即可起步):

```
自然语言论证
  → ① 句子切分与论证挖掘(前提/结论标记词:「因为/所以/然而」)
  → ② 逐句逻辑化(摹状词拆解;量词与联结词恢复;歧义显式化)
  → ③ 有效性检查(命题级:真值表;谓词级:Prolog/SMT;高阶:Lean)
  → ④ 产出:有效/无效+前提可疑点清单(形式化失败的句子=歧义热点,本身就是产出)
```

**工程要点**:② 是瓶颈——摹状词/预设/辖域歧义使翻译不能全自动;
**形式化失败的句子列表**是走廊 A 最有价值的副产品(它就是罗素式「语法体检报告」)。
形式化之后的全部武器在数学宇宙:有效性检查=可满足性求解,
语义工具=模型论——参见 [../../讲透数学/讲透数理逻辑/](../../讲透数学/讲透数理逻辑/)
04 章的四条走廊(SAT/模型检查/证明助手/归约)。

### 走廊 B:LLM 时代的意义理论实验——书斋争论的实验室化

本家族意义理论四大担保方案(02 章第二栏)在 LLM 时代**全部可实验**:

| 意义理论 | 机器实验 | 已知结果/开放点 |
|---------|---------|----------------|
| 意义=使用(后期维特根斯坦) | 分布语义:词向量/上下文表征=「使用」的统计化身 | 「使用」确实长出结构(聚类/类比);开放:统计使用够不够构成意义 |
| 证实论(维也纳学派) | 用可验证任务探测:模型能否区分可检验句与不可检验句 | 有部分校准能力;「不可证实」句的处理=软肋(幻觉区) |
| 真值条件论(戴维森) | 真值判断基准(factuality/claim verification) | 模型部分习得;组合性错误是主要失败模式 |
| 涵义论(弗雷格) | 「晨星是暮星」测试:同一指称不同呈现方式,表征是否分开 | 表征几何中确有「呈现方式」维度的证据(方向锚,引用前再核) |

**三个经典实验的代码化**:

1. **图灵测试(1950)的操作化**:模仿游戏=把「机器能思考吗」改写成可判定协议。
   代码化:双人盲评协议+统计报告——注意图灵的哲学点常被读丢:
   他换掉的是**问题的合法性**(从形而上问到行为问到),不只是出题技巧。
2. **中文屋(1980)的模拟**:规则书+符号操作者(实验:用 LLM 当「屋」,
   探测其内部表征是否「关于」故事——probing 实验)。这是「句法≠语义红线」的实验现场。
3. **格赖斯会话含义的计算建模**:合作原则四准则→对话系统/聊天机器人的
   含义推理(「他能吃点苦」→ 暗示「吃不了大苦」)——语用学的可跑部分。

**本家族实验**:[`experiments/00_two_dogmas.py`](experiments/00_two_dogmas.py)(纯标准库)——
把蒯因《经验论的两个教条》做成四个可跑演示:
§1 定义图循环检测(定义图里的环是 bug)、§2 同义性的内部不可判定
(可替换性测不出意义:心脏/肾脏反例)、§3 分析/综合身份翻转
(同一句子在两种语言约定下一枚分析一枚综合)、§4 信念之网的整体论修补
(修定义还是修事实,无算法规定——第二教条)。

## 三、工程师落点(三件套之三):提示工程的语用学

**你每天都在用本家族,只是没人给你发过教材。**

### 3.1 提示是言语行为(奥斯汀/塞尔)

写提示不是「输入查询」,是**发出言语行为**:
「写一首诗」=指令语力;「假设你是资深编译器工程师」=**预设+角色指派**
(施为句 performativity:说即在分派身份);「能否请你…」=礼貌包装的间接指令。
**可操作推论**:审视提示的语力是否明确——
模型对模糊语力(这是让我总结还是让我评价?)的自由裁量是失败输出的第一来源。

### 3.2 格赖斯四准则=提示词清晰度检查表

| 准则(会话合作原则,1975) | 提示工程版本 | 检查句 |
|------------------------|-------------|--------|
| 量(信息适量) | 上下文窗口经济:该给的不缺,不该给的不塞 | 「模型需要知道的都给了吗?噪音占几成?」 |
| 质(不说假话) | 反幻觉约束:可证伪来源/不确定时的行为规定 | 「要求模型标注不确定了吗?禁编了吗?」 |
| 关系(相关) | 任务聚焦:指令与任务的语用关联显式化 | 「每句话都服务任务吗?模型会不会抓错重点?」 |
| 方式(表达清晰) | 无歧义:术语定死、格式示例(few-shot)、结构化 | 「同一个词在提示里只有一个意思吗?」 |

### 3.3 指示语与上下文工程(语用学的 API 化)

- **指示语(deixis)**:「它/上面/刚才那个」=索引词,指称依赖语境——
  上下文窗口管理就是**指示语消解的工程版**(哪个「它」指哪个实体)。
- **前见的工程对应**(03 章 §二红线):模型不是无前见的——
  预训练分布=默认前见;提示/few-shot/系统消息=**前见的定向手术**。
  「零样本」的正确翻译是「使用默认前见」。
- **框架效应=语用包装的实证**:同一请求的两种措辞(「指出这段代码的问题」
  vs「评价这段代码的质量」)产生系统性不同输出——
  这是语用学(意义不止于字面)在 LLM 上最便宜的实测实验,
  也是提示工程师每天在做、但很少自知的概念工程(01 章主线二)。

### 3.4 概念工程落点(卡尔纳普阐释四标准的提示版)

给模型/给文档定义一个概念时,照搬阐释(explication)四标准:
**相似**(与日常用法大体相接)、**精确**(边界可判)、**简单**、**多产**(能推出/useful)。
「我们对『完成』的定义」这类团队争议,多数是四标准里缺了哪条的显式化问题。

## ✨ 美之时刻 4|图灵的操作化与塞尔的拆解:一轮完整回合

1950 年图灵把「机器能思考吗?」(形而上,无法开局)改写成模仿游戏
(行为协议,立即可跑)——**哲学问题第一次被操作化成测试**,这个动作本身
就是本家族方法论(语言批判:问题的级别重整)的最纯样本。
1980 年塞尔用中文屋把测试**拆回形而上**:通过测试≠理解(句法红线)。
2020s LLM 让这个回合**进入第三局**:分布语义是「意义即使用」的机器实现,
它够不够?工程界与哲学界第一次在同一个对象上对表。
美在:一问两答三局,每一局都换了方法但没丢掉问题——这就是活的哲学。

## 六、反直觉发现(本章)

**形式化失败是产出,不是失败**。走廊 A 里翻不进逻辑语言的句子
(歧义/预设/语力)在 NLP 工程里叫 bug,在本家族的读法里恰恰是**诊断报告**:
每一处翻译失败都标出了一个「自然语言在做事而形式语言做不了」的位置
(02 章 1.3 的价目表逐行兑现)。**哲学的语法体检=NLP 的错误分析,
两家用同一份数据说相反的结论**——这个对表本身比任一结论都值钱。

## 📌 收束 + 🧭 这章给了你什么新眼睛(认知升维)

两条走廊、一个落点、一轮三局的棋。本章给你的**转码之眼**:

- **分诊之眼**:听到「让 AI 理解/判断 X」先问——X 是有效性问题(可形式化,
  数学宇宙接手)、意义问题(可实验,走廊 B)还是理解问题(有红线,做近亲不做替身)?

  模型把它当什么,决定它给你什么
- **前见之眼**:模型的「零样本」=「默认前见」;提示=前见手术——
  你的每次 prompt 都是一次视域调整(03 章的哲学直接上岗)
