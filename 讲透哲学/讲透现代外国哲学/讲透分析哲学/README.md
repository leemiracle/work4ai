# 讲透分析哲学 · 语言批判与逻辑分析:从摹状词到两个教条再到克里普克

> **定位句**:这支负责「**给语言做体检,给哲学治病**」——
> 哲学难题多数不是世界深,而是语言痉挛;治疗方式是逻辑分析,不是构建体系。
> GB/T 13745 72035 现代外国哲学 · GB/T 三级。家族:[讲透现代外国哲学](../README.md)
> 血统:弗雷格(1879)→罗素(1905)→维特根斯坦(1921/1953)→维也纳学派(1929)→
> 蒯因(1951)→戴维森/克里普克(1960s-70s)→形式认识论与概念工程(当代)。

## 诞生

- **谁/何时**:弗雷格《概念文字》(1879)造出工具;罗素「论指称」(1905)把工具
  对准自然语言(「当今法国国王」的幽灵被三行逻辑式驱散);维特根斯坦《逻辑哲学论》
  (1921)把它推到「为思想划界」的极致;维也纳学派(1924-1936)把它变成运动;
  战后牛津(奥斯汀/赖尔)完成「理想语言→日常语言」的换血。
- **因什么问题**:①黑格尔式形而上学的空转(「绝对精神在自我展开」说什么?);
  ②数学基础危机(悖论:家族 [00 章](../00-体系结构.md) 美之时刻);
  ③「有意义的断言」的准入标准(证实原则的兴衰)。

## 核心问题

**已解决**:
- 摹状词理论:存在悖论类伪问题的分诊范式(教科书共识)
- 意义理论四方案的领地地图:证实/使用/真值条件/涵义各自的能与不能(家族 [02 章](../02-语言特征.md))
- 分析性的约定地位澄清(蒯因之后:人工语言内可画,无约定的边界没有)

**未解决/深水区**:
- 形式认识论老问题的新数学化到什么程度算「进步」(01 章「八十年最强期」的争议)
- 概念工程:概念可以「设计」,但谁授权、按什么功能标准(2024 元伦理学现场)
- AI 时代意向性:分布语义够不够构成意义(开放前沿,[04 章](../04-现代外国哲学转代码.md) 走廊 B)

## ✨ 这支最美的一个事实

**罗素的摹状词一手**(1905):「当今法国国王是秃头」的麻烦不在世界在语法——
把「The F is G」拆成「存在一个 F、至多一个 F、它 G」,
**不存在的对象被三个可检验断言取代,幽灵从本体论里蒸发**。
一次手术示范了整支纲领:哲学问题常常是「语言去度假」造成的假案。
(亲历:拿一句需求文档的话做同款手术——家族 00 章练习 1。)
