# 讲透马克思主义美学 · 劳动、实践、灵光:审美的社会历史之维

> **定位句**:这支负责"**审美的社会发生学**"——美与艺术不在真空中:
  劳动创造了美(马克思),审美能力是历史的产物(积淀),艺术生产随生产方式
  变形(灵光的凋谢/文化工业)。家族宪法 [../README.md](../README.md)。
> GB/T 13745 72050 美学 · GB/T 三级「马克思主义美学」。

## 诞生

- **谁/何时**:起点在《1844 年经济学哲学手稿》("劳动创造了美,
  却使工人变成畸形")——《手稿》1932 年全文发表后才引爆;
  两条展开线:苏联-中国线(列宁反映论/毛泽东延安讲话→中国五六十年代
  美学大讨论:美在客观/主观/主客观统一/客观社会性四派→李泽厚实践美学);
  西方马克思主义线(本雅明《机械复制时代的艺术作品》1935/阿多诺《美学理论》1970/
  马尔库塞"新感性"/葛兰西文化霸权)。
- **因什么问题**:①美的根源:形式属性还是社会历史的对象化;
  ②艺术生产与一般生产的关系(上层建筑的相对自主性);
  ③复制技术/文化工业对艺术地位的改造。

## 核心问题

**已解决**:
- 中国美学大讨论的问题场成形:美的客观性问题以四种立场的对峙被精确化
- 实践美学的体系表述(李泽厚"积淀说":审美心理是社会历史的积淀)
- 复制时代艺术的诊断框架(灵光/展示价值/艺术民主化的双向账本)

**未解决/深水区**:
- 实践美学之后:后实践美学/生命美学/生态美学的竞争未决(话语自主之争的子题)
- 文化工业批判在算法平台时代的形式:01 章主线 D 的接口
  (生成式 AI、日常审美生产与环境的合流——Critical AI 议题)
- "美是人的本质力量的对象化"的当代校准:对象化概念能否装下 AI 生产

## ✨ 这支最美的一个事实

本雅明 1935 年诊断:**机械复制凋谢了艺术品的"灵光"(Aura)——
但凋谢同时是解放**:艺术从仪式的独占中解放出来,第一次可以成为
大众的东西。"灵光"与"可复制"不是好坏二选一,而是同一枚硬币的
两面账本——批判理论最好的辩证操作,也是媒介理论的受孕时刻。

## 假设与依赖

- **社会存在决定审美意识**(唯物史观的美学推论)——买来对一切
  "永恒趣味"的去魅,付出:相对自主性(形式规律的独立性)的证明负担
- 借用家族总账:审美无利害假设在本支受最重审判(布迪厄账单的社会学版本)
