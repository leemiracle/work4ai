# 04 · 美学转代码:判断不可算,但风格可量

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(设计系统与推荐审美多样性)。

---

## 开篇:一条先立字据的红线

"美学转代码"听起来像笑话——甚至像亵渎:审美判断恰恰是那个
**无概念可证**的判断(00 章康德悖论、02 章二律背反),
而代码是概念证明的机器。拿不可算的东西去算,不是徒劳是什么?

先拆掉这个雷。本家族的立场立字据如下:

1. **能转的**:审美**对象的可测面**——比例、复杂度、对称性、色彩统计、
   构图的负空间、风格谱系的特征;审美**行为的统计面**——偏好数据、
   评分分布、文化锚点的差异;审美**生产的流程面**——生成、搜索、
   设计令牌(技术美学的工程化)。
2. **不能转的**:审美**判断的规范力**(哪个更好,最终仍是"带你看"式的
   展示与训练,不是计算);**趣味的二律背反**(可争论不可争辩——
   没有算法能终结审美分歧,只能定位分歧);**经验的第一人称性**
   (愉悦本身不进数据库,进库的只是它的行为影子)。
3. **转的时候的红线**:一切"审美评分"必须申报它是**偏好聚合**,
   不是审美判断;一切美学指标必须申报它测不到什么(03 章 §五表格的下游化)。

一句话:**代码是审美世界的显微镜,不是审美法庭的法官**。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 美学对象 | 代码化身 | 备注 |
|---------|---------|------|
| 形式比例 | 黄金比/√2 矩形检测、栅格对齐检查 | 走廊 1 主角;**注意结论只是"用了这个比例"**,不是"因此美" |
| 复杂度与秩序 | 图像熵、压缩比、分形维数、对称度 | Birkhoff M=O/C 的当代变体 |
| 风格特征 | 色彩分布、笔触统计、构图骨架(显著性图) | "风格可量"的中坚;风格迁移的工程根据 |
| 负空间/留白 | 前景-背景分割的占比与分布 | 意境语法的可测面(03 章规则 2) |
| 审美偏好 | 评分/选择/注视/停留时长数据 | 偏好聚合≠判断,但反映趣味的分布与漂移 |
| 生成搜索 | 参数空间采样+偏好模型排序 | 生成艺术的工程本体 |
| 出处与传承 | 元数据/内容寻址/版本树 | 03 章框架层的落地(NFT 的正当用途) |

**转不动的边界(红色区)**:

1. **审美判断不可算**:无概念可证=没有可执行的判据函数。
   LLM 的"评分"是训练分布上的偏好聚合( RLHF 的民主化机器),
   统计上有效,规范上无权——它答"多数人会怎样反应",不答"哪个更好"。
   工程对策:把评分系统命名清楚(Preference Model,别叫 Judge),
   并在产品文案里保留这个区分。
2. **二律背反不可算**:审美分歧只能靠展示与训练收敛(02 章),
   算法只能**定位**分歧(分歧落在哪个特征上),不能裁决。
3. **崇高不可算**:00 章发现 3——愉悦可以由"想象力统摄失败"产生,
   而"流畅性=美感"类指标(Birkhoff 后裔)在崇高类对象上系统性翻车:
   它们惩罚的(不适配/过载)恰是崇高产生的条件。
   工程对策:复杂度指标只在其校准域(设计/装饰/排版)内使用。
4. **框架层不可全算**:艺术地位的授予是共同体的历史实践,
   元数据只能**记录**它,不能**产生**它(03 章 §五)。

## 二、代码走廊清单(两条走廊,每条=对象→数据结构→算法→真实系统)

### 走廊 1:计算美学——从黄金比到复杂度指标

```
审美对象 ──特征提取──▶ 测度向量(比例/熵/对称/负空间)
    │                          │
    └──指标组合(M=O/C 型)──▶ 美学分数(带申报的局部有效性)
                                   │
                                   ▼
                     设计 lint / 排版建议 / 风格一致性检查
```

- **对象→结构**:矩形比例表;图像的直方图/边缘图/分割掩码;
  版面的栅格对齐点集。
- **算法**:黄金比与 √2 检测(纵横比容差匹配);熵与压缩复杂度
  (PNG 字节数作复杂度代理);对称度(镜像差);负空间占比(分割后背景比例)。
- **真实系统**:设计 lint 工具(对齐/密度检查)、摄影构图辅助、
  字体排印的网格检查、A/B 测试里的"视觉复杂度"分层变量。
- **本家族实验**:[`experiments/00_golden_ratio.py`](experiments/00_golden_ratio.py)——
  黄金比「审美偏好」的文化锚定模拟:多比例矩形偏好的模拟人群,
  断言(i)偏好分布的种子稳健性、(ii)文化锚点参数敏感性
  (锚点=1.0 时方形称王——黄金比不特权)、(iii)双文化混合人群峰值瓦解。
  文献对照声明在脚本头:费希纳 1876 的金矩形实验是实验美学起点,
  但后续大样本复制(如 Green 1995 综述)发现偏好峰值弱、跨研究不稳定
  ——脚本模拟的是"文化锚点+个体噪声"这一**生成机制**,不替真实人群背书。

✨ **美之时刻 4(加映):Birkhoff 把美写成一道除法**。
1933 年,数学家伯克霍夫在《审美测量》里给出 **M=O/C**:美度=秩序除以复杂度。
为什么美:第一次有人把"美"写成一个显式公式——而且**错得极有教益**:
它抓住了"有序而不单调"的一半真相(设计/装饰/排版域至今有效),
又在崇高、崇高、怪异、表现性上全面失灵(红色区 3 的历史根源)。
亲历:在实验脚本里改复杂度参数,看"最优矩形"如何随 O/C 假设搬家
——你会亲眼看到:美学的量化不是发现定律,是**选择你在哪个域里有权谈论定律**。

### 走廊 2:生成艺术的评价——AI 时代的美学工程

```
生成模型 ──提示词/参数──▶ 候选作品集
    │                          │
    │                    评价维度分解:喜好度/美感/新颖性/风格符合度
    │                          │
    └──偏好模型(RLHF)──▶ 排序与筛选 ──▶ 人审终裁(判断仍归人)
```

- **对象→结构**:作品+生成条件(提示词/种子/参考图)的双记录;
  评价向量的分维(不是单一分数)。
- **算法**:偏好模型(人类两两比较数据训练);新颖性=嵌入空间的距离
  (**陷阱**:嵌入距离度量的是"与语料的差异",不是审美新颖——
  新颖性指标会把噪声当创新,需与质量指标联用);
  多样性=候选集的离散度(下接落点 2)。
- **真实系统**:AI 绘图工具的出图筛选、音乐生成的demo分级、
  内容平台的 AIGC 质量分层。
- **实证对照(检索校准 2026-09-07)**:01 章实证锚——
  人类作品在喜好/美/新颖上仍胜 AI(PMC 2025 认知研究),
  且"AI 制造"标签本身压低评分(出处参与审美愉悦——
  康德"共通感"与认知主义路线的实证弹药)。
  工程含义:生成艺术的评价管线里,**出处信息的呈现方式是一个合法变量**,
  不是待消除的偏差。

## 三、工程师落点(两个,各自带红线)

### 落点 1:设计系统——技术美学的代码化

设计系统(design tokens + 组件库)是技术美学支的当代形态:
比例令牌(模块化比例 1.414/1.618 序列)、间距令牌(8pt 栅格的倍数系统)、
留白令牌(负空间作为一等公民——意境规则 2 的工程直译)。
- 走法:风格特征可量(走廊 1)→ 令牌化(把"好看"的规定变成可检查的约束)
  → 设计 lint 自动检查。
- 红线:令牌系统是**趣味的制度化**(布迪厄的提醒:谁的"克制"成了全公司的默认?);
  版本化+显式的风格决策记录,让制度可审计。

### 落点 2:推荐系统的审美多样性——对抗趣味坍缩

推荐系统若只按即时偏好优化,会发生**趣味坍缩**(用户被锁死在
当下喜欢的狭窄风格带里,审美探索的"慢愉悦/回甘"结构——03 章经验时序——
被算法的即时反馈截断)。
- 走法:多样性/新颖性/惊喜度(serendipity)进目标函数;
  审美探索的显式配额(给它"回甘"留时间预算);风格谱系的覆盖度指标
  (不是"多推荐几类",是**风格空间的分布监控**)。
- 红线:多样性的"多样化"标准仍是偏好数据(二律背反不可算);
  多样性目标申报它是**审美教育的立场**(把用户当可培养的趣味主体,
  不是当留存数字),这是产品价值观,不是算法结论。

## 四、家族实验导读与总收束

本家族唯一实验 [`experiments/00_golden_ratio.py`](experiments/00_golden_ratio.py)
用 150 行纯标准库回答一个问题:**"黄金矩形最受偏爱"这一流传最广的
美学-数学断言,在机制层面意味着什么?**——答案是:偏好的众数
不过忠实跟随文化锚点;混合文化的房间里没有"普适最美比例"。
这正是本家族三件套的缩影:可量的是分布,不可算的是判断,
而区分这两者是工程师的美学修养。

## 📌 收束 + 🧭 认知升维

一条红线(显微镜不是法官)、两个走廊(计算美学/生成艺术评价)、
两个落点(设计系统/推荐多样性)、一张申报单(一切美学指标的效力域)。
本章之后你应该带走的:

- **申报之眼**:看到"美学评分/AI 判美",先问:偏好聚合还是判断?
  校准域在哪里?出处变量公平吗?
- **机制之眼**:听到"人类天生偏爱 X",先问:锚点在哪、样本是谁——
  普遍人性断言的最便宜替代解释是共同的文化锚定(实验脚本的全部教训)。
- **负空间之眼**(工程版):设计系统里,留白与多样性与"功能"同权——
  它们不是剩余,是结构。
