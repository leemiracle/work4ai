# 美学思维技能卡(讲透美学)

> 本卡把分支抽象成可复用思维。深读走 [README.md](README.md) → 五问五章;
> 触发后按 §一 判断支路,按 §三 取工具,按 §五 组合。

## 一、何时用此分支(触发特征,一眼对号)

1. 问"**美是什么**/XX 为什么美"——美的本体论问题(不是问某个具体作品好不好)
2. 问"**审美判断凭什么要求别人同意**/趣味有没有对错"——趣味二律背反
3. 问"**这算不算艺术**/艺术是什么"——艺术定义(杜尚之后的标准问题)
4. 中文语境出现"**意境/气韵/风骨/味/妙**"——中国美学范畴系统
5. 问"**崇高/侘寂/物哀/幽玄**"这类审美范畴的意思与用法
6. 设计/产品侧问"**好看**的依据/功能为什么美"——技术美学与功能美
7. 工程侧:AI 生成内容的**审美评价**、推荐/设计系统的**美学指标与多样性**

## 二、核心思维模式(这个分支怎么想问题)

| 模式 | 口诀 | 反例警示 |
|------|------|---------|
| **判断优先** | 先问"这个'美'字在做什么判断",再问对象有什么 | 直接给对象列"美的属性清单"是外行 |
| **无利害检查** | 这个愉悦依赖占有/使用/道德吗?依赖则混入了非审美成分 | 把纯粹快感/效用满足当审美 |
| **普遍性裸奔** | 审美要求同意却无概念可证——用展示与训练,别用论证 | 试图"证明"某物美,必然失败(康德悖论) |
| **框架之眼** | 艺术地位在理论×惯例×历史框架里,不在物件特征里 | 在特征向量里找"艺术性"(《泉》的教训) |
| **留白之眼(中式)** | 空白是构形手段,虚处生韵 | 把留白/未言处当"没做完" |
| **趣味社会学** | 听到"纯粹的趣味",先问这是谁的趣味、谁付得起这份无利害 | 把特定阶级品味当普遍人性(布迪厄) |
| **装配线意识** | "艺术/美的艺术"是 18 世纪装配的范畴盒,有出厂日期 | 把当代艺术系统的分类当永恒自然类 |

## 三、工具箱(概念/方法 + 一句话何时用)

| 工具 | 何时用 |
|------|--------|
| 四契机分析(质/量/关系/模态) | 解剖任何一个"X 真美"的判断,做分诊 |
| 二律背反裁决(可争论不可争辩) | 处理审美分歧:先分诊依据层还是感受层 |
| 理想批评家五条件(休谟) | 谈趣味标准/评审资格的参照系(并警惕其循环) |
| 崇高二分(数学的/力学的) | 处理巨大/威力/恐怖类对象的审美(复杂度指标会翻车的域) |
| 制度论/历史定义(迪基/列文森) | 裁决"现成品/AI 作品算不算艺术"的当代主力 |
| 家族相似检查(维特根斯坦-魏茨) | 拒绝给开放概念强加充要条件("艺术""审美经验") |
| 意境三规则(情景互渗/虚实相生/象外结构) | 分析中国诗画与一切以留白工作的对象 |
| 礼乐结构(别异/和同) | 分析审美作为社会形式而非私人事件 |
| rasa 味论/物哀/侘寂 | 处理印度与日本审美范畴的原生语法(勿硬译回西方词) |
| 类型-殊例/亲笔-代笔 | 处理作品同一性、复制品、NFT、版本的哲学层 |
| 灵光(Aura)概念 | 分析复制/生成时代艺术地位的变化 |
| 功能美判定/设计十诫 | 设计侧"好看"的结构化依据 |
| 计算美学指标(比例/熵/压缩复杂度/负空间) | 可量面的测量——永远申报校准域 |
| 偏好聚合≠审美判断 | 一切 AI 评分/推荐美学变量的命名纪律 |

## 四、常见误区与禁忌

1. **审美=主观随意**:错——判断有规范结构(可争论、可教育、可"趣味有失"),
   只是不可证明
2. **黄金比=普遍人性**:实证不支持(偏好峰值弱且文化敏感)——当文化锚定现象处理
3. **"艺术不可定义"=什么都是艺术**:迪基之后的争论恰恰在精细化定义,不是躺平
4. **无利害=冷漠/无情感**:是"不占有的关切",情感照常在场
5. **中国美学=西方框架+中国例子**:范畴系统不同(气/味/韵不是 beauty 的方言),
   比较时先查语法再查词汇
6. **审美评分=审美判断**:模型答"多数人会怎么反应",不答"哪个更好"——命名纪律
