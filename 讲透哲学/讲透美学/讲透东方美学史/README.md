# 讲透东方美学史 · 味论、物哀、侘寂、书法几何:非西方感性学的原生语法

> **定位句**:这支负责"**中国之外的东方**"——印度 rasa 味论、日本物哀/幽玄/侘寂、
  伊斯兰书法与几何:它们不是"等待西方美学发现的素材",而是各自完整自洽的
  感性学语法。家族宪法 [../README.md](../README.md)。
> GB/T 13745 72050 美学 · GB/T 三级「东方美学史」。

## 诞生

- **谁/何时**:
  印度——婆罗多《舞论》(Nāṭyaśāstra,约 2 世纪起成型)立 rasa(味)论:
  戏剧唤起八种普遍化的审美情感(味),审美是"品尝"不是"判断";
  日本——《源氏物语》(11 世纪)的"物哀"(mono no aware)传统、
  世阿弥《风姿花传》(15 世纪初)的"花"与"幽玄"论、茶道集大成(16 世纪)
  的侘寂(wabi-sabi);伊斯兰——书法美学与几何装饰(19 世纪以前无独立
  "美学"学科之名,审美内嵌于书法/纹样/诗歌的实践规范)。
- **因什么问题**:①戏剧/诗如何唤情(印度);②无常与残缺为何动人(日本);
  ③无限如何以有限纹样显影(伊斯兰的负空间与无限重复)。
- 学科化是 19-20 世纪的事(井上哲次郎/冈仓天心/今道友信等),
  传统本身各自独立生长了千年以上。

## 核心问题

**已解决**:
- rasa 论的经典结构:情由/情态/不定情→味的显影(戏剧诗学化的审美机制论)
- 侘寂的价值表:不完美/不恒久/不完成作为正面审美范畴
- 日本美学范畴史(物哀→幽玄→侘寂→涩味)的谱系整理

**未解决/深水区**:
- 原生范畴的翻译损耗:rasa≠"情调"、侘寂≠"质朴"——硬译即蒸发
- 伊斯兰美学的方法论:无独立学科传统的审美体系如何被表述(艺术史语料 vs 哲学文本)
- 东方美学"统一性"的神话:所谓"东方"是对照"西方"发明的伞,还是真实家族

## ✨ 这支最美的一个事实

**rasa 味论**:审美情感不是我的私情,而是被作品"酿"出、供人"品尝"的
普遍化的情(八味:艳/滑稽/悲/怒/勇/怖/厌/惊)——
**审美是一种味觉隐喻的认知理论**:观众品尝味,如同舌头品尝滋味。
比西方"趣味"(taste/gusto)隐喻早了一千五百年,且结构远为精细。

## 假设与依赖

- **可比性假设**:东方各传统间(及与中西之间)的比较有合法锚点
  (代价:比较框架仍多半是西方学科装配线的产品——本支自带此自反性)
- 中国母题的辐射假设(儒释道对日本/朝鲜半岛的深层影响)——辐射不等于同质

## 教材锚

- 《舞论》第六-七章(rasa 论核心,中译选段见金克木等印度文论选)
- 世阿弥《风姿花传》(风姿之"花"与幽玄——日本艺道的自我表述)
- 今道友信《东方的美学》(东方美学的哲学化尝试)
- 大西克礼《幽玄·物哀·寂》(日本三大范畴的美学史整理)
