# 讲透技术美学 · 从包豪斯到设计系统:功能之美的工程学

> **定位句**:这支负责"**造物之美**"——工业产品/界面/系统设计的哲学:
  功能为什么美、"好看"如何变成可检查的工程约束、设计的道德-审美双账本。
> 它是家族最年轻的支,也是 04 章工程师落点(设计系统/推荐多样性)的户口。
> 家族宪法 [../README.md](../README.md)。GB/T 13745 72050 美学 · GB/T 三级「技术美学」。

## 诞生

- **谁/何时**:前史是维特鲁威三原则(坚固/实用/美观)与工艺美术运动
  (莫里斯 1880s,对工业丑的抵抗);正名时刻是**包豪斯**(1919,
  格罗皮乌斯:《包豪斯宣言》"艺术与技术的新统一")与沙利文"形式追随功能"
  (1896);二战后成型:乌尔姆设计学院(1953)把设计方法学化;
  中国于 1980 年代引入"技术美学"学科名(=设计美学的通行称呼);
  当代形态:迪特·拉姆斯"好设计十原则"(1970s)与**设计系统**
  (design tokens,2010s——审美约束的代码化)。
- **因什么问题**:①机器生产的物品配得上"美"吗(莫里斯之问);
  ②功能与装饰的对立是真的吗(功能美的辩护);
  ③审美如何在大规模生产与协作中**不失控**(设计系统的动机)。

## 核心问题

**已解决**:
- 功能美的表述框架:功能即形式合法性的来源之一
  ("无目的的合目的性"的工程倒转——家族 00 章的张力带)
- 设计原则的可传授化:拉姆斯十原则/人体工学/可用性规范
- 审美约束的代码化路径:令牌→组件→lint 检查(04 章落点 1)

**未解决/深水区**:
- 功能美的哲学地基:功能与美的联系是概念性的还是统计性的(分析美学侧)
- 设计伦理与美学的边界:可持续/关怀(帕帕奈克"为真实的世界设计")
  与"好看"谁仲裁(日常美学-关怀美学的接口,家族 01 章主线 C)
- 算法设计的审美责任:A/B 测试优化的"美"与趣味坍缩(04 章落点 2)

## ✨ 这支最美的一个事实

拉姆斯的"好设计十原则"(好的设计是创新的/实用的/审美的/易懂的/
不显眼的/诚实的/持久的/彻底的/环保的/尽量少的设计)——
康德说美是"**无**目的的合目的性";拉姆斯把话倒过来:
**有**目的的合目的性就是美的一种。两百年前的哲学倒装,
变成一代工程师的日常检查表。

## 假设与依赖

- **可传授假设**:审美判断可以被规程化到设计系统(直接顶撞家族的
  "天才论"假设——本支全站在天才论与民主化的张力带上,家族 00 章 §五)
- 规范依赖:可用性/无障碍标准(工程规范)与审美判断(哲学问题)分层申报
