# 讲透中国美学史 · 从礼乐到境界说:一部用范畴写成的美学史

> **定位句**:这支负责"**中国感性的自我表述史**"——不是"西方美学+中国例证",
> 而是另一套语法的展开:范畴(气韵/意境/味/妙)与构图(留白/虚实)如何
> 从礼乐传统一路演化出王国维的境界说。家族宪法 [../README.md](../README.md)。
> GB/T 13745 72050 美学 · GB/T 三级「中国美学史」。

## 诞生

- **谁/何时**:无独立学科之名,有连续两千年的范畴生产史——
  《乐记》(战国-汉)立"乐者天地之和"的教化框架;魏晋人物品藻与
  谢赫《古画品录》六法(气韵生动居首)把评价范畴化;唐司空图《二十四诗品》
  与宋严羽《沧浪诗话》成型"意境-妙悟"论;1908 年前后王国维《人间词话》
  以"境界"总其成;1950-80 年代朱光潜/宗白华/李泽厚完成现代学科化。
- **因什么问题**:①审美如何安顿人伦秩序(礼乐);②艺术品的"神"与"形"
  谁优先(气韵);③诗画语言如何超出言象之外(意境)。
- "美学"汉字译名是进口的(日本中江兆民 1883-84 译《維氏美学》再入华)——
  但译名之下装的是本土两千年的范畴库存。

## 核心问题

**已解决**:
- 范畴系统的清理与训释:气/韵/味/妙/逸/腴/涩的谱系表(20 世纪学科化的最大功绩)
- 意境论的结构表述(情景互渗/虚实相生/象外结构——家族 03 章 §四)
- 中国美学的分期地图(先秦礼乐→魏晋风度→唐宋意境→明清性情→近代转型)

**未解决/深水区**:
- 中国美学与西方美学的可通约性:普世现象的方言,还是不可互译的范畴系统
  (本家族取"两套语法"立场)
- 实践美学(李泽厚"积淀说")之后的再出发:后实践美学/生命美学/生态美学的竞争未决
- 中国美学史史料学:诗话词话/书论画论的点评分散性如何系统化

## ✨ 这支最美的一个事实

王国维《人间词话》借三句词写人生三境界——"昨夜西风凋碧树"/
"衣带渐宽终不悔"/"蓦然回首,那人却在灯火阑珊处":
**批评方法本身就是美学的示范**——用作品谈人生,
范畴("境界")不靠定义靠实例生长。这是中国批评语法的极致展示(家族 02 章 §三)。

## 假设与依赖

- **范畴连续性假设**:从《乐记》到《人间词话》的范畴有可追溯的谱系
  (代价:强读谱系会掩盖断裂与外来影响,佛学对意境论的重塑即一例)
- "美学"作为学科框架的适用性:用西方学科盒装中国材料,盒与货的张力永远在场

## 教材锚

- 李泽厚《美的历程》(最短的中国美学通史)
- 宗白华《美学散步》(中国艺术精神的散点透视)
- 叶朗《中国美学史大纲》(范畴谱系的教科书整理)
- 原典选读:《乐记》/《二十四诗品》/《沧浪诗话》/《人间词话》
