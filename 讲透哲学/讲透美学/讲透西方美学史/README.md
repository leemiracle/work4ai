# 讲透西方美学史 · 柏拉图到黑格尔:美的形而上学两千年

> **定位句**:这支负责"**西方古典段**"——从柏拉图"美本身"的追问,
  经中世纪的神学美学与经验主义的趣味转向,到德国古典哲学的体系巅峰:
  一部"美的形而上学"如何建立、如何转向、如何把接力棒交给现代的美学元叙事。
> 家族宪法 [../README.md](../README.md)。GB/T 13745 72050 美学 · GB/T 三级「西方美学史」。

## 诞生

- **谁/何时**:柏拉图《大希庇阿斯》(前 5 世纪末)首问"美是什么"
  (答案:美是难的);《会饮》给出从个别美到美本身的上升阶梯;
  亚里士多德《诗学》转向作品(模仿/卡塔西斯/整一性);
  中世纪(奥古斯丁/阿奎那)把美接入神学(比例/明晰/和谐);
  18 世纪双响:伯克《崇高与美》(1757)把崇高与美分家、
  鲍姆加登 1750 命名学科;德国古典(康德 1790/席勒/谢林/黑格尔 1820s)
  把美学造成哲学体系的正式部门。
- **因什么问题**:①美是事物属性还是主体状态(实在论 vs 心灵论的长期摆锤);
  ②感性认识的权利;③艺术的真理价值(模仿说两千年的辩护与清算)。

## 核心问题

**已解决**:
- 模仿说框架的建立与解体(亚里士多德立/现代艺术终)
- 崇高范畴的确立(伯克的恐惧-距离说/康德的数学-力学二分)
- 美学作为哲学体系部门的合法化(德国古典的工程)

**未解决/深水区**:
- 美的理念论遗产:美的属性归属(共相/倾向/反应)仍是当代形而上学议题
- 中世纪美学的当代复权(光/比例传统对现象学美学的滋养被长期低估)
- 史学问题:美学史是"问题史"(概念接力的内在逻辑)还是"语境史"
  (社会史的函数)——写作范式之争未决

## ✨ 这支最美的一个事实

**《会饮》的上升阶梯**:从爱一个美的身体,到爱一切美的身体,到爱美的灵魂、
美的制度、美的知识,最后**刹那观照美本身**——
柏拉图把审美写成一条**形而上学的登山路**,爱的欲望是登山杖。
西方美学两个母题(爱欲与理念)在开篇一次焊死。

## 假设与依赖

- **希腊源头假设**:西方美学的基本问题座标系由希腊奠定(代价:
  中世纪与阿拉伯的中间环节被叙事压缩)
- 教科书叙事的"三段论"(古典-近代-现代)自带的简化——本支阅读时
  始终要求对照原典(席勒书简/伯克全文而非选段)

- 朱光潜《西方美学史》(中文母本;两卷,作家作品式的经典叙事)

- 原典选读:柏拉图《大希庇阿斯》/《会饮》、亚里士多德《诗学》、
  伯克《崇高与美》、康德《判断力批判》、黑格尔《美学》导言
