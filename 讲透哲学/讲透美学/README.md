> 先追问"美"这个判断本身:它凭什么要求别人同意(美的本体),人的感受如何成为可谈论的对象(审美如何可能)。

## 三、长尾归属与兜底(穷尽声明)

- **「美学其他学科」(GB/T 三级兜底类)→ 不设系列**:环境美学/生活美学/身体美学等
  零散条目按近亲归属——环境美学与生活美学作
  [`讲透美学原理/README.md`](讲透美学原理/README.md) 的内节(它们是原理的应用扩张,不是并列地盘),
  身体美学(舒斯特曼)作 [`讲透西方现代美学/README.md`](讲透西方现代美学/README.md) 的内节。
- **与文艺美学的分工声明(互链)**:美学家族(72050,哲学宇宙)问**美的本体**——
  美是什么/审美如何可能/艺术何以为艺术;文艺美学(75014,文学宇宙)问**作品**——
  文学作品的具体审美形态与批评。见 [../../讲透文学/README.md](../../讲透文学/README.md) 的对应声明行。
- **与艺术学的归入声明**:门类艺术史/艺术批评的实操(音乐学/美术学/戏剧学等)
  归 GB/T 760 艺术学一级学科(本仓库未建宇宙,文字声明);本家族
  [`讲透艺术美学/`](讲透艺术美学/) 只做**哲学层**(这门艺术的观念问题),不做史论实操。
- **美育**:哲学根据(审美何以能教)在本家族 02 章;美育的实操与制度归教育学宇宙(GB/T 880,文字提及)。
- 与哲学宇宙兄弟家族的边界:美的形而上学地基见讲透西方哲学史(同波兄弟,文字提及);
  美善之辨(趣味与德性)邻接讲透伦理学(同波兄弟,建成后互链回填);
  技术美学的技术哲学侧邻接讲透自然辩证法(同波兄弟,文字提及)。

## 四、前置与路径

- **零门槛**:本家族不预设哲学史基础——审美经验人人都有,本家族只是把
  "你已经有过的那份感受"变成可以追问的对象;术语随用随讲(三步法:直觉图像→严格陈述→最小例子)。
- 路线 A(问题派,主推):读 00 章三个出生故事 → 直奔两个反直觉(康德悖论/杜尚小便池)→
  按你自己的困惑选支(问"美是什么"去原理,问"这算艺术吗"去西方现代)。
- 路线 B(历史派):西方美学史 → 西方现代美学 → 中国美学史 → 东方美学史(先西后中,
  便于看见中国范畴系统不是西方框架的例证而是另一套语法)。
- 路线 C(创作者快轨):技术美学 + 04 章 → 回头补原理支的"审美判断结构"。
- 工程师快轨:直接跳 [`04-美学转代码.md`](04-美学转代码.md) 的设计系统与推荐多样性落点。
