# 讲透辩证唯物主义 · 物质、运动与矛盾:世界观和思维方法的总库

> **定位句**:这支负责"**世界的看法与想问题的方法**"——
> 唯物主义的本体承诺(物质/运动/时空/意识)加上唯物辩证法的规律与范畴,
> 一切"怎么分析变化着的东西"的操作手册都从这块地基出。
> GB/T 13745 72010 马克思主义哲学 · GB/T 三级。家族:[讲透马克思主义哲学](../README.md)

## 诞生

- **谁/何时**:概念名定型于**恩格斯**(《反杜林论》1878;《自然辩证法》手稿 1873-1883,
  恩格斯未完成);**狄慈根**独立提出"辩证唯物主义"一词(1886);苏联教科书定型于
  **1938**(斯大林《论辩证唯物主义与历史唯物主义》小册子);
  中国化形态=**毛泽东《实践论》《矛盾论》(1937)**。
- **因什么问题**:①费尔巴哈式旧唯物主义"解释世界"无力(提纲第一条);
  ②黑格尔辩证法的唯心主义外壳必须剥掉(倒转);
  ③革命运动需要可传授的分析方法(教科书化与手册化的动力)。

## 核心问题

**已解决**:
- 唯物辩证法的**表述体系**(三规律+范畴对的操作化表述;1938 教科书定稿)
- 实践范畴的确立(认识的基础=社会实践,检验标准=实践)
- 《矛盾论》把矛盾分析做成**可执行的排序程序**(主要矛盾/主次方面/转化条件)

**未解决/深水区**:
- 辩证逻辑能否**形式化**(弗协调逻辑等候选语义无共识——与哲学宇宙逻辑学家族共管)
- 自然辩证法的当代形态:辩证法规律对自然科学还只是启发性类比还是实质方法
  (与同波兄弟讲透自然辩证法家族共管)
- 意识的唯物主义解释如何吸收认知科学/AI(意识是"物质的最高产物"的当代兑现)

## ✨ 这支最美的一个事实

**对立统一是发展的动力**——事物运动的源泉不在外部推动,而在自身包含的对立面:
生物每个瞬间既是他自己又是别的(同化与异化),资本靠"剥削与实现"的矛盾活着。
矛盾不是思维的故障,是存在的呼吸。

## 假设与依赖

- **唯物主义承诺**(世界的统一性在于物质性):换来对一切神秘化的解毒,
  代价是要持续解释数学/逻辑/审美观念的"自律"现象(家族 00 章 §五账单)
- 意识是物质的产物+反映——"反映"概念的弹性(能动反映论)是本支最大的理论工位
- 下游喂养[历史唯物主义](../讲透历史唯物主义/)(方法用到历史上)与全部应用分析

## 内节:实践唯物主义

80 年代中国学界大讨论的阵地:物质本体论 vs 实践唯物主义之争。
本支主张两者不该二选一——**实践范畴正是《提纲》第一条的立脚点**:
"对象……当作实践去理解"。实践唯物主义不是异端,是本支的解释重心。
