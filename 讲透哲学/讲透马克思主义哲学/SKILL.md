# 马克思主义哲学思维技能卡(讲透马克思主义哲学 · GB/T 72010)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **辩证法类**:矛盾、对立统一、量变质变、否定之否定、扬弃、辩证逻辑、
  "既……又……"是不是诡辩、形式逻辑 vs 辩证逻辑
- **历史类**:经济基础、上层建筑、生产力、生产关系、社会存在、社会形态、
  阶级分析、唯物史观、历史规律与人的能动
- **批判类**:异化、物化、商品拜物教、货币拜物教、意识形态、文化霸权、
  "统治阶级的思想"、虚假意识、去自然化
- **方法类**:从抽象到具体、历史与逻辑的一致、总体性、功能解释、征候读法
- **当代类**:平台资本主义、数字劳动、算法管理、零工经济、996、注意力经济、
  "技术是中立的吗"、数据是谁的劳动

## ② 核心思维模式(这个分支怎么想问题)

1. **生产之眼**:见到观念先问——它从哪种生产与生活的组织方式里长出来?
   又回头加固了哪种生活?("永恒原则"被历史化)
2. **翻译之眼(拜物教检测)**:见到"物的性质"(价格/排名/KPI/算法输出)
   先翻译——这是哪种人与人的关系被投影到了物上?
3. **矛盾分析**:找对立面→定主要矛盾与主要方面→给转化条件
   (带条件翻转的优先级队列,不可机械化的是"定主次"这一步)
4. **从后思索**:理解历史的钥匙在最发达的形态手里——
   用平台经济回读 1844 手稿是合法操作,从头讲起反而看不清
5. **从抽象到具体**:不从混沌整体("社会""用户")开始,
   从最简单的规定(商品/一次交换)开始让矛盾自己发育
6. **实践标准+循环自觉**:理论靠实践检验,但"实践成功"的判定本身内含理论——
   循环不被消除,只能被自觉管理

## ③ 工具箱(范畴/程序 + 何时用)

| 工具 | 何时用 |
|------|--------|
| 范畴对(现象-本质/形式-内容/必然-偶然/可能-现实) | 分析任何"表里不一/形式与内容打架"的现象(计件 vs 计时的强度差) |
| 异化四重规定(与产品/过程/类本质/他人) | 劳动体验/职业倦怠的制度性分析——先问结构再问心境 |
| 商品拜物教解剖 | 价格/品牌/数据定价等"物自己会说话"的幻觉 |
| 意识形态三层问(何时出现?出现前后生产组织差在哪?让谁省心?) | 任何行规/常识/"中立标准"的户口检查 |
| 矛盾分析五步(列/定主次/定方面/查转化/落特殊) | 复杂局面排序:多方张力里先解决什么 |
| 从抽象到具体(叙述机器) | 写研究/报告/白皮书的结构次序 |
| 从后思索(人体解剖钥匙) | 研究顺序设计:先解剖最发达形态 |
| 征候读法 | 读经典/读公司文档:读它没有问什么 |
| 功能解释检验(科恩) | "X 存在因为它对 Y 有功能"——追问:有机制还是神秘化? |
| 再生产视角 | 制度为何延续:它如何不断重造自己的条件 |

## ④ 常见误区与禁忌

- **经济决定论漫画化**:把"归根到底"读成"明天股价决定哲学"——
  恩格斯晚年书信明确加了"归根到底"限定与上层建筑反作用,弹性是申报过的
- **辩证法当万金油**:用"既对立又统一"结束讨论=句式体操;
  客观矛盾(存在结构)与逻辑矛盾(论述错误)是两个层次,后者不豁免
- **异化≠心情不好**:异化是制度性颠倒的范畴,不是心理量表分数;
  把结构问题翻译成个人调适问题恰是意识形态操作的教科书案例
- **拿教科书当马克思**:三规律并列铺陈是 1938 教科书体系的整理,
  马克思本人的定义是"对现存事物的肯定理解中同时包含否定理解"——读原文
- **拜物教批判≠阴谋论**:"统治思想"命题不需要任何人撒谎,
  只需要生产精神产品的资料(今天:分发算法)集中在少数结构位置
- **预测化滥用**:唯物史观给趋势+条件不给时刻表;用三层结构预测
  "何时崩溃"是型号误读
- **模拟当证据**:交换/再生产模拟的价值是前提声明下的机制演示,
  不是经验世界的拟合证书(见实验脚本的纪律声明)
