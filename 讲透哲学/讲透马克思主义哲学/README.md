## 四、前置与路径

- **零门槛**:本家族不预设任何哲学史基础——它恰好是哲学宇宙里最不"哲学史依赖"的入口
  (黑格尔不必先读:马克思的辩证法是从黑格尔那里**救出来又倒转过来**的,倒转的路线图本家族自带)。
- **文本路线(主推)**:以马克思恩格斯原文选读为主——《关于费尔巴哈的提纲》(1845,3000 字)→
  《共产党宣言》(1848)→《政治经济学批判》序言(1859,唯物的史观的经典公式)→
  《资本论》第一卷第一章(1867,商品拜物教)→ 列宁《哲学笔记》选段 / 毛泽东《实践论》《矛盾论》。
  原文都短,难的从来不是篇幅是范畴——范畴的解码本家族五章承包。
- 路线 A(问题派):读 00 章故事 → 直奔商品拜物教与异化(最锋利的两把刀)→ 回头补辩证法。
- 路线 B(体系派):辩证唯物主义 → 历史唯物主义 → 哲学史(教科书顺序,配 02 章"教科书 vs 原文"对照读)。
- 工程师快轨:直接跳 [`04-马克思主义哲学转代码.md`](04-马克思主义哲学转代码.md) 的平台劳动落点。
