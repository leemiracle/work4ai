# 04 · 马克思主义哲学转代码:批判的范畴怎么接上键盘

> **本章回答五问之五:这个分支的问题怎么变成 code 问题?**
> 三件套:**可机械化边界 / 代码走廊清单 / 工程师落点**(平台劳动分析)。

---

## 开篇:一个先要拆掉的雷

把马克思主义哲学"转代码",第一个反应往往分成两派:
一派觉得荒谬(哲学是批判,代码是工具,风马牛不相及);
一派觉得危险(把拜物教"物化"成代码,等于用拜物教的手段研究拜物教)。

两派都对了一半。本家族的立场先立字据:

1. **能转的**:范畴的**操作化指标**(异化→可测量的劳动过程变量)、
   经典文本的**形式特征**(概念共现/词频漂移——概念史可算)、
   社会结构的**机制模拟**(交换/再生产/阶层流动——结构动力学可算)。
2. **不能转的**:批判的**规范立场**(什么是"好的社会"不由代码判定;
   代码能显影不公的分布,不能裁决公义的标准)、
   **总体性**(数据的预切分已经是范畴操作——你选择记录什么,
   就已经预设了什么重要;这是本家族版本的"观察渗透理论")。
3. **转的时候的红线**:凡是模拟,必须申报模型前提(见 experiments 脚本的
   纪律声明);凡是指标,必须申报它测不到什么。

一句话:代码是批判的**显微镜**,不是批判的**法官**。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 哲学对象 | 代码化身 | 备注 |
|---------|---------|------|
| 概念的历史运动 | 文本挖掘:词频/共现/语义漂移 | 概念史可算;"异化→拜物教"的范畴接力可被词汇分布验证(走廊 1) |
| 交换价值的社会性 | 交换模拟(多智能体信念动力学) | 价值表作为社会共识的涌现可被复现(走廊 2;本家族实验脚本) |
| 再生产图式 | 两大部类投入产出模拟 | 《资本论》第二卷的图式本来就是差分方程,天然可算 |
| 阶级结构 | 职业分类×资产×控制权的量化 | 赖特的新中产阶级定位就是可计算的分类学 |
| 意识形态的分布 | 话语语料分析/框架检测 | "统治思想"命题的操作化:曝光量×来源集中度 |
| 异化的四重规定 | 劳动过程量表(自主性/完整性/目的性/联结) | 调查研究标准操作;边界在解释权不在测量 |

**转不动的边界(红色区)**:

1. **批判立场不可机械化**:"这个劳动过程是异化的"最终是一个规范判断——
   量表分数高的地方,仍需论证为什么这四维构成"异化"而非"辛苦"。
   工程对策:指标显影+论证分离,永远不在代码里偷运价值判断。
2. **拜物教本身不可被数据"去除"**:数据表上的价格列就是拜物教的形式——
   统计永远在"物与物的关系"层打转,拆回"人与人的关系"需要理论翻译。
   工程对策:数据管道自带"翻译层"注释(这一列是谁的劳动时间的化身?)。
3. **总体性不可全量数据化**:任何数据集都是总体的切片,而总体规定部分——
   "看不见的手"在数据里永远表现为缺失变量。工程对策:多切片三角互证,
   且明示切片的立场。
4. **"归根到底"不可拟合**:三层结构的弹性(03 章红色区二)意味着
   没有可回归的决定系数——试图用回归"验证唯物史观"是范畴错误。
   工程对策:只检验具体的、有机制的功能命题(如"教育扩张与技能需求错配"),
   不检验总命题。

## 二、代码走廊清单(两条走廊,每条=对象→数据结构→算法→真实系统)

### 走廊 1:概念共现分析《资本论》——把哲学史做成文本管道

```
经典文本(MEGA/选集) ──分词与范畴表──▶ 概念标注语料
      │                                     │
      └──窗口化共现 ──▶ 概念网络 ──▶ 时序对比(1844 手稿 vs 资本论)
                                            │
                                            ▼
                          范畴接力的实证检验(03 章 §一的六层表)
```

- **对象→结构**:概念表(异化/拜物教/剩余价值/剥削/物化/类本质……);
  每个概念是词汇集合(异化≈{异化,外化,Entfremdung 的译名……});
  数据结构=按著作分段的文档流+滑动窗口共现矩阵。
- **算法层**:词频(概念的显要度)、共现 PMI(概念的亲和度)、
  按写作年代排序的迁移矩阵(哪些概念对在 1844 强联结、在 1867 被替换)。
  纯标准库可做:`collections.Counter`+字典共现计数即可起步。
- **可检验的哲学命题**(这是走廊的灵魂):
  ①"认识论断裂"命题(阿尔都塞):1844 高频的异化/类本质在 1867 是否让位于
  价值/剩余价值?②连续性命题(01 章主线 B):异化是否以低频但结构性的方式
  仍在《资本论》承担组织工作?——**两个对立的经典论文本特征层面可判分**,
  数字人文把哲学史争论变成可复查的计算对象。
- **真实系统**:数字人文界的 Marx-Engels-Gesamtausgabe(MEGA)文本库研究、
  Voyant Tools 等文本分析环境;R/Python 的 tidytext/lda 生态。
- **性能工程要点**:中文分词与译名对齐是本走廊的"脏活"——
  概念表的质量上限决定一切(垃圾进垃圾出在人文数据上是平方级惩罚);
  窗口大小的敏感性分析必须做(换窗口重跑=稳健性报告)。

### 走廊 2:社会模拟——把结构动力学做成可跑的实验室

```
哲学设定(生产/交换/信念) ──行为化前提声明──▶ 多智能体模拟
      │                                        │
      ▼                                        ▼
 再生产图式(两大部类)              交换模拟(价值表涌现)
      └────────── 输出:结构变量的时间轨迹 ──────────┘
                         │
                         ▼
              命题检验/教学演示/反事实实验(改参数!)
```

- **对象→结构**:本家族实验脚本 `experiments/00_commodity_fetish.py` 是这条走廊的
  最小版:给定社会分工的生产者-消费者智能体,二维偏好(使用价值 u/交换价值信念 v),
  每期"生产→随机配对议价→成交则校准信念→卖不掉则降价",断言四连
  (排序共识 4/24→24/24=公共价值表成为社会事实;价值排序从跟随使用价值翻转为
  跟随劳动成本=交换价值脱离使用价值;每个个体的用处排序都与公共价值表显著不同;
  价值逻辑接管晚期多数成交)。
- **算法层**:信念更新的共识动力学(成交即校准)+饱和边际效用
  (持有越多,多一件的用处越小)+失败销售的重新定价——易生产的商品泛滥而不值钱,
  费工的商品稀缺而金贵,劳动价值锚**通过稀缺-价值通道内生涌现**,
  不外加任何定价公式(古典"引力"机制的行为化)。
- **可检验的哲学命题**:商品拜物教的发生学叙事("人们自己的社会运动
  对他们来说具有物的运动形式")不再只是引文,而是**可执行、可改参数、可反事实**
  的过程:把 USE 列改成与 COST 同向,断言 B 会翻转——学生亲眼看到
  "价值语言与使用语言脱钩"需要什么社会条件。
- **更大规模的同型研究**:简单再生产/扩大再生产图式的模拟(两大部类比例失衡
  如何酿成危机)、Schelling 隔离模型(社会学宇宙的经典,
  唯物史观版本的"个体无心、结构有情")、平台匹配市场的抽成模拟(练习 3)。
- **真实系统**:NetLogo/Python ABM 生态;计算社会科学(computational social
  science)的期刊阵地——本走廊是与 [../../讲透社会学/README.md](../../讲透社会学/README.md)
  的数理社会学家族共管的地界。
- **性能工程要点**:模拟的第一美德是**可复现**(固定种子)与**敏感性分析**
  (关键参数全扫描)——单点结果在 ABM 里一文不值;第二美德是前提声明前置
  (模型锚定劳动价值是前提不是结论,脚本头部的纪律声明就是为此)。

## 三、工程师落点:平台劳动分析(本家族的前线阵地)

这是 2021-2026 哲学-工程交叉最热的一块(01 章主线 D),也是工程师
**带着手艺入场**的地方。核心思想:算法管理=计件工资的数字化回归,
马克思的劳动过程范畴与平台数据结构有近乎一一对应的翻译表:

| 平台数据(工程师天天见) | 劳动过程范畴(1844/1867) | 测量要点 |
|------------------------|--------------------------|---------|
| 接单日志/派单算法参数 | 劳动强度与控制权(计件制的回归:算法计件) | 派单接受率是被"训练"出来的还是自由选择? |
| 评分系统 | "消费者主权"的形式(监督劳动的外包) | 评分影响派单的弹性=控制权指标 |
| 等级/勋章/gamification | 相对剩余价值提取的情感装置 | 游戏化指标与实际报酬的换算率 |
| 计费规则/抽成比例 | 剩余分配格局 | 抽成变化的承担方弹性(平台/骑手/消费者谁吸收) |
| 每单 GPS 轨迹 | 劳动过程的完全记录(泰勒制的极限) | 等红灯/上厕所算谁的?非计费时间的黑箱 |
| 账号封禁/降权 | 纪律权(无需法庭的准司法) | 申诉路径的存在性=正当程序指标 |

**三步法(一个最小可行研究)**:
直觉图像——把骑手 App 的规则页想象成一张 1850 年曼彻斯特纱厂的
工厂法对照表,逐行找同构;
严格陈述——用异化四重规定(与产品/过程/类本质/他人)构造量表,
每条规定锚定一个平台可观测变量(如"过程异化"←任务拒单自由度、
议价空间、工作片段化程度);
最小例子——一周的接单日志样本+10 份深访:量化轨迹给出"何时何地多紧",
访谈校准范畴("你觉得自己在给谁干活")——量化与质性缺一即残。

**工程师的独特杠杆**:
- 你**读得懂**派单算法的参数——这是外部研究者拿不到的证据层;
- 你能把"抽成比例""派单弹性"写成可审计的指标,让"剩余分配"从口号变成曲线;
- 你在伦理上站在结构性位置: whistle-blowing 的成本函数本身就是研究对象。

**红线重申**(承§一):所有指标只显影不裁决;"骑手是异化的"这一步
永远需要范畴论证+当事人的自我理解(问卷/访谈),代码只负责让证据不可抵赖。

## 四、可机械化的检验仪式(把本家族用成瑞士军刀)

遇到任何系统(平台/公司/AI 应用),做三问:
1. **生产关系问**:这个系统里,谁的劳动被记录?谁的劳动不可见?
   产出归谁所有?数据是生产资料吗?
2. **历史问**:这个"自然规则"(KPI/评分/竞价排名)是什么时候发明的?
   发明前用什么?替代方案为什么死掉(技术原因还是权力原因)?
3. **总体问**:局部指标(效率/增长)接进总体图景后,哪个结构性矛盾
   被这个系统放大了(买与卖的分裂?生产与实现的分裂?)

三问过完,系统的社会骨架就裸露了——剩下的才是纯技术问题。
(对照数学宇宙离散数学家族的"三问仪式":那边裸露的是算法骨架,
这边是社会骨架;两问叠用,工程师就同时看见机器的两层。)
