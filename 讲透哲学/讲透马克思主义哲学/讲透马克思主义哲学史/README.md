# 讲透马克思主义哲学史 · 从《提纲》到中国化:一部"改变世界"思想的生产与再生产谱系

> **定位句**:这支负责"**这个哲学自己的历史**"——
> 手稿、论战、国家化、分裂与再批判:马克思主义哲学的传记,
> 同时是唯物史观方法论的自我示范(思想的形态由其传播与斗争条件解释)。
> GB/T 13745 72010 马克思主义哲学 · GB/T 三级。家族:[讲透马克思主义哲学](../README.md)

## 诞生

- **谁/何时**:恩格斯晚年书信与《费尔巴哈论》(1886/1888,发表《提纲》)开启自我叙述;
  第二国际(考茨基/伯恩施坦,1895-1914)第一次体系化与第一次分裂;
  **列宁**(《唯物主义和经验批判主义》1909/《哲学笔记》1914-16);
  **1923 年**卢卡奇《历史与阶级意识》、柯尔施、葛兰西=西方马克思主义起点;
  法兰克福学派(霍克海默→阿多诺→哈贝马斯);**中国化**(李大钊/艾思奇/毛泽东→实践标准讨论)。
- **因什么问题**:①革命在西方为何未发生/在东方为何发生——理论必须解释自己的预言;
  ②手稿群的陆续刊布(1844 手稿 1932、《大纲》1939-41)不断改写"马克思是谁";
  ③国家化之后,批判哲学如何重新做回批判。

## 核心问题

**已解决**:
- 马恩思想发展的**阶段轮廓**(1843-45 转折/1848/1859/1867 的节点划分)
- 手稿学基础(哪些文本何时刊布、如何改变解读格局)
- 各大流派的谱系定位(第二国际/列宁主义/西方马克思主义/中国化的分叉条件)

**未解决/深水区**:
- **"马恩对立论"之争**:恩格斯的"自然辩证法"路线是马克思的方法还是偏离
  (文本证据与理论论证的双向拉锯,悬而未决)
- **1844 手稿与《资本论》的连续性**(01 章「广义政治经济学批判」重述的主战场)
- 中国化的哲学形态:从《实践论》到实践标准讨论再到当代,"本土化"的哲学含量如何评定
- 21 世纪的批判理论建制化(见家族 01 章)算不算新的"段"

## ✨ 这支最美的一个事实

一个以"改变世界"为纲领的哲学,在 20 世纪成了**国家哲学**,
在新世纪又回到**批判的批判**——立场随物质条件的变迁而变迁,
它自己的传记就是唯物史观最好的案例:**哲学的形态由它的传播与斗争条件解释**。

## 假设与依赖

- **谱系假设**:分期(断裂或连续)是解释工具不是史实本身——同一手稿在不同问题意识下
  读出不同"马克思"(阿尔都塞征候读法的功与过)
- 依赖手稿的刊布史(文献条件决定理论史——又一个自指)
- 黑格尔前史见同波兄弟讲透西方哲学史家族(文字提及)

## 内节:国外马克思主义研究

西方马克思主义(卢卡奇/葛兰西/法兰克福学派)、分析马克思主义(科恩/埃尔斯特/赖特)、
生态马克思主义、后马克思主义——按 GB/T 属本支内节不另设支:它们是谱系的当代段,
入口为家族 [01 章](../01-近五年创新.md)。
