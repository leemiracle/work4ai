# 讲透日本哲学 · 进口、消化与反哺:从佛教公传到京都学派的「绝对无」

> **定位句**:这支负责讲清一条「进口-消化-反哺」全程的哲学史——
> 佛教公传(552)与国家佛教、镰仓新佛教的平民化重写、江户古学
> 「回到原典」的反形上学、明治「哲学」造词的学科建制,直到京都学派
> 以「绝对无」加入世界哲学的牌桌——**每一次大规模进口之后,
> 都跟着一次本土化的反刍,最后反哺出口**。
> GB/T 13745 72025 东方哲学史 · GB/T 三级。家族:[讲透东方哲学史](../README.md)。

## 诞生

- **谁/何时**:552 年佛教公传(《日本书纪》所记,另有 538 说)是可考的思想
  进口起点;圣德太子《十七条宪法》(604)已见佛儒混合的国家伦理;
  最澄·空海入唐求法(805)确立「进口的制度化」。
- **因什么问题**:①外来思想如何在本土壤扎根(镰仓新佛教把贵族佛教
  改写为平民的宗教哲学:亲鸾他力本愿/道元只管打坐/日莲唱题);
  ②江户古学(伊藤仁斋 1683《语孟字义》、荻生徂徕 1717《辨名》)发现
  「连朱子学也是外来形上学」——用回到原典的方式反掉一切形上学外套;
  ③明治面对整个西方学科体系,西周造「哲学」(1874)完成语言接生;
  ④京都学派(西田 1911《善的研究》起)消化西方哲学后宣布:真正的普遍性
  必须穿过「绝对无」——**最民族的时刻与最普遍的时刻是同一刻**。

## 核心问题

**已解决**:
- 前近代骨架:国家佛教(奈良-平安)→镰仓新佛教→江户儒学与古学→
  兰学通道(1774《解体新书》)的时序与文献基础
- 「哲学」译名的造词史(西周 1874)与日造汉语词汇回流中国的传播史
- 京都学派三代谱系(西田-田边/西谷-战后)与主要著作定位;
  战后忏悔哲学(田边 1946《忏悔道的哲学》)的定位

**未解决/深水区**:
- **京都学派与战争责任的分层评价**:「近代的超克」(1942)与成员战时言论
  的档案研究不断细化,「思想成就/政治参与」如何分账仍是方法论争论
  (家族 00 章 §5 直接引用此案)
- 「日本哲学」的正典边界:国民史学叙事(井上哲次郎式学派史)退场后,
  新正典按什么标准写(与热线 B 同题)
- 西田「场所」与欧陆哲学(现象学/辩证法)的影响-原创比例
- 「无」的谱系学:中观之空-禅之无-西田绝对无之间 1300 年中介层的
  精确重建(家族 03 章 §2.4 的概念史课题)

## ✨ 这支最美的一个事实

西田几多郎(1926)的翻转:一切判断都需要一个「场所」——判断「花是红的」时,
花与红都被看见,而**看见这一切的眼睛自己不在画面里**;最终的场所不能是
任何「有」,只能是**绝对无**。「无」第一次从神秘词汇变成逻辑功能位:
不是缺乏,而是**让一切被看见的背景**。直觉主义由此拿到了论证形态——
这是三河中最晚出生、却最快完成世界化的哲学事件。
