## 〇、家族树(GB/T 三级 3 支落子 + 中国分工声明)

```
讲透东方哲学史/
├── 讲透印度哲学/      GB/T 三级——从吠陀到吠檀多:梵我合一、缘起性空与因明的发源地
├── 讲透伊斯兰哲学/    GB/T 三级——从肯迪到萨德尔:希腊遗产的阿拉伯保存者与苏菲形上学
├── 讲透日本哲学/      GB/T 三级——从佛教公传到京都学派:一条「进口-消化-反哺」的哲学史
└── (东方哲学史其他学科 → GB/T 兜底,见 §三)
```

> 三支的共同处境:**都在别人的语言里问过哲学,也各自把「哲学」翻译了一次**——
> 印度把 darśana(见/观)译成了学科,伊斯兰把希腊的 falsafa(爱智)接成了 hikmah(智慧),
> 日本干脆造了一个汉字新词「哲学」(西周,1874),再出口回中国。
> 三条河的性格:印度重「见」(直观与论证并举,因明即产于斯),
> 伊斯兰重「传」(启示与理性互审,一手接希腊一手超希腊),
> 日本重「场」(思想与生活世界、政治处境高度咬合)。

**中国哲学分工声明(硬边界)**:中国哲学(先秦至现代,含佛学中国化段:格义/判教/禅宗)
一律归同波兄弟家族**讲透中国哲学史(72020)**,本家族零触碰。佛教这条长线两家族共管、
一线切开:**印度段**(缘起/中观/唯识/因明的印度源头,含南传上座部与北传大乘的起点)
归本家族印度支;**中国化段**(汉传宗派/禅宗/近代唯识复兴)归中哲史家族——
玄奘(645 年开译场)就是这条线的官方切点。藏传佛教的中观应成文献归印度支内节
(那烂陀-超戒寺的藏地保存线),其制度与语境侧归历史学宇宙。

## 三、长尾归属与兜底(穷尽声明)

- **东方哲学史其他学科**(GB/T 三级兜底类)→ 不设系列。零散条目按近亲归入:
  **波斯前伊斯兰思想**(琐罗亚斯德/玛兹达克)→ 伊斯兰支内节(伊朗前史窗口,实验脚本即如此落子);
  **犹太教哲学**(萨阿底/迈蒙尼德,与 kalām 同场对话)→ 伊斯兰支内节(「伊斯兰世界」的共域成员);
  **东南亚上座部佛教思想**(缅甸论书传统/泰国森林派)→ 印度支内节(南传线的下游);
  **朝鲜半岛与越南儒学** → 属汉字儒家文化圈,文字提及并指向中哲史家族的辐射圈,本家族不设支;
  **锡克教/耆那教近现代思想** → 印度支内节。
- **「亚洲哲学」(Anglo-American 课程范畴)**:作为教学筐与研究对象的双重身份在
  [00 章](00-体系结构.md) §6 与 [01 章](01-近五年创新.md) 热线 A 处理,不设支。
- **宗教侧归入声明**:佛教/印度教/伊斯兰教/神道教的**宗教现象、制度与仪式**研究
  属宗教学(GB/T 730,本批未建宇宙)——本家族只取其**哲学内容**(义理/论证/概念史),
  与中哲史家族对佛教的处理口径一致。
