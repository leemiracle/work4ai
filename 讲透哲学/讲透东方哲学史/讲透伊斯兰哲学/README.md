# 讲透伊斯兰哲学 · 希腊遗产的保存者与超越者:从肯迪到伊斯法罕学派

> **定位句**:这支负责讲清「启示语境里的理性事业」——阿拉伯语哲学
> 如何在翻译运动中接住希腊遗产(肯迪-法拉比-阿维森纳),如何在
> 安萨里的批判与阿威罗伊的辩护中定型,又如何在苏菲形上学
> (光照/存在单一论)与伊斯法罕学派(萨德尔)里走出自己的路,
> 最后在 20 世纪被「连续性论题」重新写进世界哲学史。
> GB/T 13745 72025 东方哲学史 · GB/T 三级。家族:[讲透东方哲学史](../README.md)。

## 诞生

- **谁/何时**:830 年前后,巴格达智慧宫(哈里发马蒙的国策机构)的翻译运动
  把亚里士多德经叙利亚语接力译入阿拉伯语;**肯迪(约 800-873)**作为
  第一位阿拉伯语哲学家立题:启示与理性真理不冲突——「真理不分来源」。
- **因什么问题**:①一神启示的强势框架如何安放异教文明的理性遗产;
  ②法拉比把「哲学家-先知」做成同秩双职,阿维森纳以存在/本质之分、
  必然/可能存在给出体系答案;③安萨里《哲学家的矛盾》(1095)从教内发起
  总攻,阿威罗伊《矛盾的矛盾》(约 1180)总辩护——**争的不是要不要理性,
  而是理性的权限清单**;④另一条线苏菲(鲁米/伊本·阿拉比/苏赫拉瓦迪)
  在「体验」处开出第三条路:照明不是论证,但照明有自己的知识论。

## 核心问题

**已解决**:
- 翻译运动的传播史骨架(智慧宫→托莱多→巴黎;阿威罗伊以「注释者」之名
  进入拉丁正典)——欧洲经院哲学的阿拉伯前史已成学界共识
- falsafa-kalām-苏菲理论三线互动的框架取代「哲学 vs 神学」旧二分
- 「阿威罗伊之后哲学终结论」(勒南 1852)被翻案:照明哲学与伊斯法罕学派
  (萨德尔:存在优先、本质运动)进入正典(科宾/纳斯尔一代的工程)

**未解决/深水区**:
- **连续性的程度**:13-19 世纪伊斯兰哲学是「活的传统的延续」还是
  「地方学院的保存」?纳斯尔的强连续论与急进史学仍有拉锯
- 阿维森纳「存在与本质之分」的准确义界(区分是真实的、心智的、还是
  言说的——中世纪与当代注释者至今分歧)
- 「伊斯兰哲学」的边界:犹太教哲学(迈蒙尼德)与伊朗前伊斯兰思想
  (琐罗亚斯德)在本支的「伊斯兰世界共域」内节身份如何学理化
- 苏菲体验书写(诗/寓言)的哲学重构合法性(家族 02 章 §4「诗与论证可分」
  假设的伊斯兰段)

## ✨ 这支最美的一个事实

阿维森纳的「悬浮人」思想实验(约 1020):设想一个人被凭空创造,
悬浮在虚空里,没有感官输入、没有肢体接触——他仍然能**直接确信自己的存在**
(「我」的自觉不需要任何外部证据)。这个思想实验比笛卡尔的「我思」早六百年,
走的却是同一条路:向内找那个不可怀疑的点——**欧洲近代哲学的第一步,
在 11 世纪的波斯已经预演过一次**。

## 假设与依赖

- 依赖抄本文献学与拉丁译本对勘(阿拉伯原文与拉丁译本的传播差是
  「欧洲读到的阿维森纳」研究的主战场)
- 「伊斯兰哲学」是**以语言文化圈(阿拉伯语/波斯语)为界的学术范畴**,
  不等于宗教归属——犹太教哲学(迈蒙尼德)与基督教阿拉伯作者在本支内节,
  波斯前史(琐罗亚斯德)作伊朗前史窗口内节(归属声明见家族 README §三)
- 警惕两个对称的坑:「哲学终结论」的欧洲中心投影与「一切哲学皆伊斯兰」
  的反向扩张——**两条都是史学错误**
