# 讲透印度哲学 · 从吠陀到近代复兴:梵我合一、缘起性空与因明的发源地

> **定位句**:这支负责讲清东方三条河中最长的一条——印度思想从祭祀之问
> (吠陀/梵书)到解脱之学(奥义书/佛教/耆那教),从论辩工具(因明)
> 到体系综合(吠檀多诸家),再到近代世界化(辨喜/奥罗宾多)的全程;
> 梵我关系(究竟者与个体是什么关系)是贯穿两千年的总问题。
> GB/T 13745 72025 东方哲学史 · GB/T 三级。家族:[讲透东方哲学史](../README.md)。

## 诞生

- **谁/何时**:前 800 年前后,早期奥义书作者在森林书写的传统中首次把
  祭祀主义的「仪式如何有效」替换为「祭祀背后的究竟是什么」——
  **梵(宇宙本体)与我(个体自我)的同一**(`汝即彼`)是这门学问的第一命题。
- **因什么问题**:①祭祀主义的世界观饱和——仪式秩序需要一个解释者;
  ②沙门思潮(佛陀/大雄,前 6-5 世纪)把问题从「梵是什么」换成「苦如何止息」,
  缘起论不设第一因——印度哲学从此在**婆罗门正统(āstika)与异端(nāstika)**
  的长期论辩中长出论证文化;③那烂陀(约 5-12 世纪)把论辩制度化为大学,
  因明与量论在此成熟。

## 核心问题

**已解决**:
- 文献骨架:吠陀→奥义书→经书体系(前 1500-前 200)与佛教部派/大乘
  (龙树中观/瑜伽行唯识/陈那法称因明)的正典谱系
- 南传(巴利语系,阿育王时代起)与北传(梵语系,经汉译/藏译)的分流史;
  汉藏译本在梵本佚失处作为「回溯母本」的地位
- 商羯罗-罗摩努阇-马陀婆三家吠檀多的分叉结构(不二/限定不二/二元)
- 英美学界正典化(达斯古普塔 1922/拉达克里希南 1923 起)

**未解决/深水区**:
- **佛教在印度本土衰亡之谜**(外力说 1193 前后那烂陀之劫/内因说僧团学院化
  与梵语化脱离民间——两说并存,证据链不完整)
- 奥义书的层积年代学(千年层积物,各层边界仍在校订)
- 「无我」与「业报载体」的兼容问题(部派共许的难题,今天仍是佛学研究的
  第一线争论——见分析佛学的当代重述)
- 梵语思想与「哲学」范畴的可译性(家族 00 章 §5 的印度段)

## ✨ 这支最美的一个事实

「空」的辩证法(龙树,约 200):对任何立场 P,P、非 P、P 且非 P、非 P 且非非 P
**四句皆立不住**,连「空」自身也「空亦复空」——只剩下「缘起」这个动作本身。
1600 年后,弗协调逻辑在形式上重新接住了这个结构(Priest-Garfield 2003)——
一首偈颂与一套现代语义表隔着时空握手。

## 假设与依赖

- 依赖写本文献学与语言层积学(贝叶/桦皮写本;口传千年的文本稳定性问题)
- 「正统-异端」二分(āstika/nāstika)是教内视角的范畴,学术使用须加引号——
  佛教对「印度哲学史」的贡献恰恰在「异端」侧最大
- 家族分工依赖:佛学中国化段归中哲史家族(切点=玄奘 645);
  因明的形式逻辑展开归逻辑学家族;藏传中观文献归本支内节
- 警惕双重选样:殖民东方学的正典+印度民族复兴的正典都预选过「谁算哲学家」
