# 04 · 东方哲学史转代码——多语文献对齐的最小走廊

> **本章回答五问之 Q5(问题→代码转换)**。
> **本质一句话**:东方哲学史的问题一旦变成「关于文本与概念数据的计算」,就能进代码——
> 编年变密度矩阵、术语表变对齐图、因明变论证检查器;
> **唯一不可外包给代码的,是哲学与文献学的判断本身(选样、对译的恰当性、重构的合法性)**。

---

## 0. 开篇:76 条记录检验两个百年直觉

「轴心时代多条文明同时发问」「明治之后日本哲学突然加速」——这两个教科书叙事,`experiments/00_eastern_timeline.py` 用 76 条「年代×文明×人物×事件」记录做了最朴素的检验:按文明×大时代切片,轴心期窗口(前 800-前 200)呈现印度(7 条)+伊朗前史(1 条)的多文明共振;日本线在明治-昭和窗口(1868-1945)的密度是江户及以前的 **11 倍**。

但脚本同时打印了选样声明:76 条是「入选正史的事件」,密度曲线度量的是**正典机制的关注度**(结集体/译场/大学/期刊的产出被系统性优先记录),不是「思想产出」本身。**代码替你算数,替不了你解释数**——这句警告在东方哲学史比在数学史更重:因为这里的正典本身经历过殖民选样+民族复兴选样的双重加工(家族 [00 章](00-体系结构.md) §5)。

## 1. 可机械化边界(三件套之一)

**能进代码的**(文本与概念数据化后的一切):

| 任务 | 机械化形式 |
|------|-----------|
| 编年密度/共振检验 | 事件点列 → 文明×时代矩阵、窗口密度比(本家族 C1 走廊) |
| 多语概念对齐 | 五语术语表 → 对齐图、一对多分叉点检测(C2) |
| 概念史 | 分期语料 → 词频时间线、术语兴衰曲线(C3) |
| 论证结构检查 | 三支作法/因三相 → 结构校验器(C4) |
| 注疏堆栈分析 | 原典-注-疏边表 → 分叉树、同一句异读对照表 |
| 传播链重建 | 翻译事件 → 有向时间图(03 章 §2.1 四波次表的代码版) |

**不能进代码的**(本学科的「不可判定域」):

1. **对译的恰当性**——「śūnyatā 该译成什么」没有算法解;对齐器只能标出**分叉点**(哪里的译法分裂了),分叉的正当性要人读语境(02 章 §1 损失标注的人工性)。
2. **哲学性的判定**——「这段偈颂算不算在做哲学」的裁决权属于分层 S1-S6 的学术共同体,任何分类器输出的都只是「像已入库条目」。
3. **重构的合法性**——分析佛学式的重建(四句=FDE?)是哲学论证,不是数据拟合;代码可以列真值表,**论证住在表外**([03 章](03-可构造与结构.md) §4)。
4. **价值与叙事**——「谁算重要哲学家」的排序=把正典判断伪装成超参数(选样陷阱,03 章 §5.3)。

> 边界的一句话:**代码是五语文献的显微镜,不是哲学家**。放大倍数越高,越要记得镜头是谁选的、对着哪条河。

## 2. 代码走廊清单(三件套之二)

本家族的四条走廊(由浅入深):

| 走廊 | 输入 | 输出 | 对应实验/章 |
|------|------|------|------------|
| C1 编年走廊 | (年份, 文明, 人物, 事件) 列表 | 文明×时代矩阵、共振/密度断言 | `experiments/00_eastern_timeline.py`(✅ 已实现) |
| C2 对译走廊 | 概念五语对照表(02 章 §1) | 对齐图、分叉点清单 | 本章 §2.2 示例 |

### 2.1 C1 数据字典(00_eastern_timeline.py 的模式)

| 字段 | 类型 | 约束/坑 |
|------|------|--------|
| year | int | 负数=公元前;**无 0 年**(承数学史家族 02 章 §5.5 的纪年纪律);传统纪年条目必须在 text 内自带 S6 标注 |
| civ | 枚举 | 印度/伊斯兰/日本/跨文明;**枚举表=归属声明**(伊朗前史/犹太教哲学归伊斯兰线是 README §〇-§三的宪法决定) |
| person | str | 「传说/传统纪年」随格标注;群体作者(结集/座谈会)合法 |
| text | str | 不带形容词——数据与叙事分离(承数学史家族纪律) |
| tier | S1..S6 | 02 章 §2.5 的译注强度阶梯;无此字段的编年库一律视为 S6 |

### 2.2 C2 对译走廊:分叉点=概念史事件(15 行核心)

```python
# 五语对照表的最小版(全表见 02 章 §1;此处演示分叉检测)
TERMS = {
    "śūnyatā":  {"zh": "空", "ja": "空/くう", "en": "emptiness"},
    "darśana":  {"zh": "见", "ja": "見",     "en": "view/philosophy"},   # 一格多译
    "场所":     {"ja": "場所", "en": "place/locus/topos"},               # 一格三译
    "hikma":    {"en": "wisdom", "zh": ""},                             # 空格=汉译缺席
}
for sans, row in TERMS.items():
    for lang, surface in row.items():
        n = len(surface.split("/")) if surface else 0
        if n != 1:
            print(f"分叉/缺席: {sans}·{lang} -> {surface or '(空)'}"
                  f"  # 分叉点=该概念的语义 contested 区")
```

跑一遍你会看到:分叉点清单(darśana 译 view 还是 philosophy、场所译 place 还是 topos)恰好就是 [02 章](02-语言特征.md) 损失标注最长的那几格——**对齐器的报警器与哲学家的深水区地图是同一张**。这就是「跨语言知识图谱」工程里「争议即信号」的设计原理(§3)。

### 2.3 C3 概念史走廊:词频时间线(史籍断代的日晷)

```python
from collections import Counter
text_by_era = {"江户前期": "……", "幕末": "……", "明治10年代": "……", "明治20年代": "……"}
for era, text in sorted(text_by_era.items()):
    hits = Counter(w for w in ["哲学", "理学", "穷理学", "西洋哲学", "東洋哲学"] if w in text)
    print(era, dict(hits))   # 「哲学」何时挤掉「理学」——译词竞争的实测曲线
```

明治文献的实例问题:「哲学」(1874 定名)如何在十年内挤掉「理学」「穷理学」成为标准译词——词频曲线是概念史的体温计;但解读权在文献学家手里(02 章 §3 的分工纪律)。

### 2.4 C4 论证走廊:因三相结构校验(结构级,不是真值级)

```python
TRI = {
    "宗":   {"subject": "此山", "predicate": "有火"},
    "因":   {"subject": "此山", "predicate": "有烟"},
    "同喻": {"whenever": "有烟", "then": "有火", "example": "灶"},
    "异喻": {"whenever": "无火", "then": "无烟", "example": "水"},
}

def check_three_marks(t):
    # 因三相的结构接线近似(02 章 §2):只查结构,不查事实真值
    assert t["因"]["subject"] == t["宗"]["subject"], \
        "第一相·遍是宗法性:因必须落在宗的主词上"
    assert t["同喻"]["whenever"] == t["因"]["predicate"], \
        "第二相·同品定有性:同喻的『凡』端须接因的谓词"
    assert t["同喻"]["then"] == t["宗"]["predicate"], \
        "同喻的『皆』端须接宗的谓词(正例方向)"
    assert t["异喻"]["whenever"] == "无" + t["宗"]["predicate"].lstrip("有") and \
        t["异喻"]["then"] == "无" + t["因"]["predicate"].lstrip("有"), \
        "第三相·异品遍无性:异喻须为『无宗谓→无因谓』的逆连锁"
    return "结构接线通过——真值判断留给立敌双方(人)"

print(check_three_marks(TRI))
```

**这条走廊的天花板要写明**:代码只校验三支的**结构接线**(主词覆盖、喻与因谓词的钩连),「此山是否真有烟」是现量(知觉)的事,「凡有烟者必有火」的普遍性是比量的哲学承诺——**结构与真值分层,正是因明自己的分层**([02 章](02-语言特征.md) §2)。

## 3. 工程落点(三件套之三):跨语言知识图谱

本家族的工程师落点只有一个大方向:**跨语言哲学知识图谱**——把 03 章 §1.5 的 schema(概念形态-转译边-接触事件)建成图数据库。三个现实工程课题:

1. **节点设计课题**:节点=「概念在某语言某文本的某形态」(form 带 sense_note),不是「概念本身」——否则幽灵节点陷阱(03 章 §5.1)直接毁图。这是本体设计问题,不是性能问题。
2. **对齐课题**:embedding 对齐(多语词向量/LLM 表示)可以提候选边,但**边要分层**——「同形」「同源」「同义」三种边必须分存(空[中观]与空[京都学派]同形不同义,同义边要人工审)。评估不对称性:错边(伪同义)污染整个下游,漏边只是少发现——**评估策略与推荐系统相反**。
3. **语义漂移测量课题**:同一概念沿转译链(śūnyatā→空→くう→emptiness)的表示距离变化,可以做成「翻译损耗」的量化指标——这是 [02 章](02-语言特征.md) 损失标注的数据化,也是 LLM 多语哲学翻译评估器(01 章 §2 末题)的地基。

与性能工程的接口(用户领域):大语料对齐是典型的可缓存、可增量的批处理负载;图查询模式固定(邻域展开/路径回溯),预计算与物化视图的权衡空间大——**哲学史的图比社交图小几个量级,但边的语义密度高几个量级**,工程优化的对象是「每条边的人工审核成本」,不是 QPS。

## 4. 敏感性分析:本学科的「测试框架」

承家族体例(数学史 04 章 §4.5),三条可复用:

- **换选样**:C1 的「正史大事」换成「译经目录(经录)收录数」或「现存写本数」两种选样各跑一遍——若「轴心期共振」在写本选样下消失,说明共振部分是结集制度的投影(实验脚本的警告就有了定量版本)。
- **移窗口**:轴心期窗口从前 800/-200 移到前 1000/-300 重跑;日本窗口从 1868 移到 1853(黑船)重跑——结论对切口不敏感才可断言「时代性」而非「单点事件」。
- **留一检验**:随机抽掉 10% 条目重跑密度比——波动 <20% 说明结论不依赖个别「大事件」(如佛陀条目单独缺席时,轴心期共振是否仍在?数据上:仍在,余 6 条)。

## 4.5 走廊×断言阶梯对照(哪条走廊能支撑哪级断言)

| 走廊 | 最高可支撑(02 章 §2.5) | 常被误用于 |
|------|------------------------|-----------|
| C1 编年 | S2(事件在某文献系有载) | 被当「思想产出结论」——密度是正典关注度 |
| C2 对译 | S2(译法在某文本在场) | 被当 S4「语义等价」——分叉点恰说明不等价 |
| C3 概念史 | S2(词频分布) | 被当 S5「概念含义变迁」——需要人读语境 |
| C4 论证 | S2(结构接线在场) | 被当「论证有效性判定」——真值层在结构外 |

## 5. 这章给了你什么新眼睛(⑨)

- **走廊眼**:看到任何东方哲学史断言,自动翻译成「什么文本数据+什么计算能检验它」;翻译不出来的,就站在不可机械化边界上——那里往往正是哲学所在。
- **争议信号眼**:对齐失败、分叉、缺席不是工程的 bug,是**概念史的正面证据**——深水区地图比平坦航道值钱。
- **不对称评估眼**:错边比漏边贵——在人文数据上,precision 的优先级压倒 recall,与常规 ML 直觉相反。
