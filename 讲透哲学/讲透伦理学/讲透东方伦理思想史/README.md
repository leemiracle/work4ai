# 讲透东方伦理思想史 · 法与不害——儒家圈之外的东方道德世界

> **定位句**:这支负责"东方伦理的另三条河"——印度(达摩/业报/慈悲/不害)、
> 伊斯兰(沙里亚与美德)、日本(义理与人情/耻感),兼及东南亚与中亚。
> 它们的共同挑战:把"义务/美德/后果"三分的西方切法放进这些传统时,
> 总有装不下的剩余物——**剩余物本身就是这门支的教具**。
> GB/T 13745 72045 伦理学 · 三级。家族:[讲透伦理学](../README.md)

## 诞生

- **谁/何时**:印度吠陀(前 1500-)→奥义书(前 800-)→佛教与耆那教
  (前 6-前 5 世纪,不害 ahimsā 与慈悲的立法)→《摩奴法论》(约前 2 世纪-
  2 世纪,达摩的体系化);伊斯兰伦理随《古兰经》(7 世纪)与沙里亚法学;
  日本:圣德太子十七条宪法(604,"以和为贵")→武士道(12 世纪-)
  →近世町人伦理(石门心学)。
- **因什么问题**:①宇宙秩序与个人义务如何挂钩(达摩:你在种姓、
  人生阶段里的位置即你的义务);②伤害的边界画在哪(不害:从战争
  到饮食到微生物的极端推演);③神法与理性的关系(伊斯兰:
  哲学家的"理性善"与启示法的紧张);④人情与义理冲突时听谁的
  (日本:忠孝不能两全的悲剧美学)。

## 核心问题

**已解决**:
- 佛教伦理的系统重构(基翁 Keown《佛教伦理学》:戒定慧的结构化,
  佛教是不是"美德伦理"的争论由此进入可讨论的形态)
- 日本伦理的"义理/人情"二项式获得文化社会学定性(本尼迪克特等
  的描述框架,虽有其战时用途的局限)

**未解决/深水区**:
- "东方伦理"作为分析单元的合法性:印度法论/伊斯兰法/日本义理
  各自独立,还是可比的"非西方语法"?单元本身的资格在争
- 达摩(dharma/dhamma)的不可译性:义务/法/秩序/美德/宗教的多义
  体——任何单义词翻译都是一次切割(家族 02 章词法分析的头号案例)
- 传统与现代国家法的关系(沙里亚与成文法/达摩与宪法):

## ✨ 这支最美的一个事实

**一个词喂出三个现代运动**:"不害"(ahimsā,耆那教推到极致——
蒙面防吸入微生物)经佛教与甘地的再发明,成为**非暴力抵抗**
(不合作运动→马丁·路德·金)的哲学引擎,又经辛格《动物解放》的
转世,成为动物权利运动的地基。一个公元前 6 世纪的宗教戒律,
三次改写现代世界史——伦理思想的传播力上限案例。

## 假设与依赖

- **秩序优先假设**(印度):道德是宇宙秩序(rita/dharma)的局部,
  不是个体理性的发明——买到与形上学/社会结构的无缝,
  付出变革论证的困难(秩序不义时凭什么改?)
- **共同体优先假设**(日本/伊斯兰):道德单位是共同体(家/乌玛/藩),
  买到凝聚,付出个体的退出权
