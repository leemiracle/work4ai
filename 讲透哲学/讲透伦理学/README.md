# 讲透伦理学 · 人应如何活的语法——从苏格拉底之问到 AI 对齐

> **本质一句话**:伦理学=人应如何活的语法——
> 其他学科告诉你世界**是**什么样、怎样改变它;伦理学追问那个更扎人的问题:
> **那我该怎样活?**(苏格拉底)它把习俗、直觉、律令、算计这些"人人都在说、
> 却没人检查过"的道德语言摆上解剖台——查它的词法(善/正当/义务/应当)、
> 句法(原则如何推出结论)、方言(功利语/义务语/德性语)与病理(两难)。
>

## 三、长尾归属与兜底(穷尽声明)

- **「伦理学其他学科」(GB/T 三级兜底类)→ 不设系列**;零散条目(如道德心理学纯实验侧、伦理学辞书学)按近亲归属:道德判断的实证研究归 00 章 §六联系表所述道德心理学文献,职业现场归各应用支。
- **与哲学宇宙兄弟家族的分流声明**(同波建设中,文字提及):
  - **西方哲学史家族(72030)**管哲学家的全貌与语境,本家族管**规范理论的谱系本身**——康德在本家族是"定言令式的立法者",在那边是"批判哲学的体系家";两边互为深挖库。
  - **中国哲学史(72020)/东方哲学史(72025)**管思想体系,本家族管其**道德理论面**——"仁"在本家族进规范理论比较(与美德伦理学对读),在那边进心性论语境。
  - **现代外国哲学家族(72035)**管存在主义/现象学的伦理语境(克尔凯郭尔的生存悖论),本家族管其规范主张与元伦理争论。
  - **逻辑学家族(72040)**与本体互链:道义逻辑(应当的形式化)的形式侧住逻辑学家族,本家族管它的哲学动机与悖论解读(02 章)。
  - **美学家族(72050)**:善与美之辨(审美判断与道德判断的类比是康德《判断力批判》的接头货),互链待建。
  - **自然辩证法家族(72015)**:AI 哲学(技术哲学侧)管"技术是什么",本家族管"技术**应当**怎样";AI 伦理是两家的共管地带(01 章主线 A)。
- **与马克思主义哲学家族的政治伦理边界声明**(同波兄弟,文字提及):本家族[讲透政治伦理学](讲透政治伦理学/README.md)支管**规范性的正义理论**(罗尔斯/诺齐克之争、正义战争、权威正当性);马哲家族管**国家与意识形态的批判理论**(阶级分析方法)。同一对象(正义)两种问法:政治伦理学问"什么制度是对的",马哲问"正义话语为谁服务"。接头货:马克思的正义观之争(本家族[讲透马克思主义伦理思想史](讲透马克思主义伦理思想史/README.md)支内节)。
- **生态 vs 环境两支分界**:生态伦理学管**自然共同体本体**(内在价值/土地伦理/深生态——"自然有没有道德地位"),环境伦理学管**人类行为与环境的规范关系**(代际正义/气候责任/政策——"我们对未来和公共环境负什么债");《寂静的春天》为两家共同的起点文献。

## 四、前置与路径

- **零门槛**:本家族是哲学宇宙最特殊的入口——它不要求你先学任何东西,因为**你已带着二十年的道德直觉数据进门**(你每天都在作"应不应该"的判断)。伦理学做的事只是把这些数据变成可检查的对象。
- 路线 A(问题派):先读 00 章三层楼地图 → 直奔电车难题与器官移植悖论(00 章 §七)→ 跑实验脚本亲眼看直觉翻转。
- 路线 B(谱系派):原理 → 中/东/西/马四部思想史 → 按职业兴趣挑应用支(医学/政治/生命伦理为热门)。
- 工程师快轨:直接跳 [`04-伦理学转代码.md`](04-伦理学转代码.md) 的 AI 对齐价值层(2026 年最热的前线)。
