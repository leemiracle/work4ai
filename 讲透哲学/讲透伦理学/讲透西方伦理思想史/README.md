# 讲透西方伦理思想史 · 三足鼎立的谱系现场——从雅典之问到无知之幕

> **定位句**:这支负责"规范理论从哪来"——苏格拉底把"该如何活"
> 没收给理性,亚里士多德造出德性论;基督教千年把爱立法;
> 1785/1789 康德与边沁双子立法造出义务论与功利主义;
> 1958 安斯康姆让德性论复活;1971 罗尔斯用无知之幕重开政治伦理。
> 今天教科书里的"三大理论",每一足都有两千年的施工现场。
> GB/T 13745 72045 伦理学 · 三级。家族:[讲透伦理学](../README.md)

## 诞生

- **谁/何时**:古典(前 5 世纪-529):苏格拉底之问→柏拉图善的理念→
  亚里士多德德性与中道→斯多亚与伊壁鸠鲁(希腊化的自助伦理);
  中世纪:奥古斯丁(爱与自由意志)-阿奎那(自然法+四枢德);
  近代:霍布斯自利契约、休谟道德感、斯密同情论(1759《道德情操论》);
  1785/1789 双子立法;密尔 1863 融贯化功利主义并辩护自由;
  20 世纪:摩尔元伦理转向、安斯康姆德性论复活、罗尔斯契约论重建。
- **因什么问题**:①德性即知识吗(苏格拉底悖论:无人自愿作恶);
  ②道德的根基是理性还是情感(康德 vs 休谟,至今未合);
  ③最大幸福如何计量(边沁-密尔的高 low 快乐之争);
  ④"现代道德哲学"是否迷失在律法观念里(安斯康姆之问)。

## 核心问题

**已解决**:
- 是与应当区分的谱系三级强化(休谟提出-摩尔正面立论-黑尔语言分析)
  ——规范推理必须显式带规范前提已成教科书共识
- 德性论复活完成:从 1958 宣言到 1981 麦金太尔《追寻美德》,
  "三足鼎立"成为标准图景(教科书结构就此定型)

**未解决/深水区**:
- 密尔"高级快乐"辩护的融贯性(快乐的质量分层是否偷偷
  用了"尊严"这个非快乐标准——功利主义内部的百年裂缝)
- 康德式普遍化检验的充分性(反例:绝对不撒谎者对凶手撒谎——
  康德本人的回答多数人拒收)
- 理性 vs 情感之争的当代裁决(道德心理学与神经科学加入后,
  反而更悬而未决)

## ✨ 这支最美的一个事实

**1785/1789 双子立法**:四年之内,柯尼斯堡与伦敦几乎同时立法——
康德:"人是目的,永远不可仅仅当作手段";边沁:"最大多数人的
最大幸福"。一个把道德钉在理性的形式上,一个钉在苦乐的算术上。
此后一切规范伦理学争论几乎都是这场双子立法的续集——
包括本家族实验里"同算术、反判决"的移植医生悖论
(见 [../experiments/00_trolley_variants.py](../experiments/00_trolley_variants.py)):
它就是双子立法在你直觉里的交火现场。
