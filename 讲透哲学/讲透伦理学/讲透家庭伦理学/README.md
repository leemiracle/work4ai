# 讲透家庭伦理学 · 孝与照护——亲密关系的道德结构

> **定位句**:这支负责"伦理学进家门"——家庭是道德发生的第一现场
> (没人先学理论就会爱),却是理论伦理学的最后边疆(普遍原则
> 与个体权利的语言在这里集体失灵):孝是自然义务还是互惠契约?
> 照护是美德还是被系统性免费化的劳动?婚姻是契约还是身份?
> 本支是家族里对"个人主义假设"补账最重的一支。
> GB/T 13745 72045 伦理学 · 三级。家族:[讲透伦理学](../README.md)

## 诞生

- **谁/何时**:东方=《孝经》(约战国-汉,"夫孝,德之本也"——
  孝首次获得专门经典)与丧服制度(亲亲尊尊的差序网格);
  西方近代=密尔《妇女的屈从地位》(1869,婚姻的一半人口
  是"合法的奴隶")与恩格斯《家庭、私有制和国家的起源》
  (1884,家庭的历史化);20 世纪:婚姻的契约定性确立
  (无过错离婚),照护伦理起义(吉利根《不同的声音》1982
  ——科尔伯格道德发展阶段只测了男孩;诺丁斯《关怀》1984);
  费孝通《生育制度》(1947,中国代际"反馈模式"的理论化)。
- **因什么问题**:①血缘关系产生道德义务吗(孝的哲学地基:
  感恩论/友谊论/目的论,每论都有反例);②照护劳动的
  不可见性(谁在免费扛,为何女性居多——结构不正义现场);
  ③婚姻制度的边界(一夫一妻/异性/可退出,哪个定义是道德的
  而非习俗的);④国家该管家吗(反家暴的干预正当性)。

## 核心问题

**已解决**:
- 婚姻的契约定性建制化:婚姻=可退出的自愿契约而非终身身份
  (无过错离婚+夫妻平等入法)——"婚姻是身份枷锁"的
  旧定则被逐国拆除
- 反家暴的国家干预正当性确立(隐私不再豁免暴力)——
  公私二分的家庭例外被关闭

**未解决/深水区**:
- 孝的道德地位:自然义务(血缘自动生债)vs 互惠契约
  (养育的对价)vs 友谊论(无债,只有关系)——哲学家
  三派分立,每种都有想脱离却逃不掉的义务感做反例
- 照护伦理能否升格为一般道德理论(关系先于规则的
  "第二十世纪伦理学起义"成果之争)
- 代际索取的边界:父母能要求到什么程度(生育决定的
  非同意问题——孩子没签过出生协议)

## ✨ 这支最美的一个事实

**费孝通的"反馈模式"**:中国代际关系的结构=甲代抚育乙代、
乙代赡养甲代的**双向反馈回路**,不同于西方的"接力模式"
(甲养乙,乙只养丙,一路向下)。孝在结构上不是"落后风俗",
而是一种**代际契约的建筑**——伦理直觉(养儿防老)底下
埋着清晰的社会学骨架。一个概念让"孝"从道德评判对象
变成可分析的制度,这是本支方法论的标准示范。

## 假设与依赖

- **亲缘特殊性假设**:血缘/亲密关系承载不可普遍化的义务
  ——买到家庭伦理的自主领地,付出与普遍公正的冲突
  (该救母亲还是十个陌生人——威廉斯之问)
- **照护的道德优先性**(吉利根-诺丁斯):关系先于规则,
  回应先于原则——买到对依赖与脆弱的真实描述,
  付出"照护者自我牺牲"的正当化风险
