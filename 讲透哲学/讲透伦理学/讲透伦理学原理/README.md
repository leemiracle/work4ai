## 诞生

- **谁/何时**:源头=苏格拉底之问(前 399,"该如何活");学科定名=亚里士多德
  《尼各马可伦理学》(约前 330,ta ēthika——"伦理的"成为学科名);
  现代三层结构定型于 20 世纪:摩尔《伦理学原理》(1903)劈出元伦理学,
  安斯康姆《现代道德哲学》(1958)复活德性论,战后应用伦理学大扩张
  反向要求原理层供给清晰的概念原语。
- **因什么问题**:①幸福与德性谁定义谁(希腊);②道德的权威从哪来
  ——神/自然/理性/苦乐(近代立法之争);③"善"是否可定义
  (摩尔对一切还原定义的宣战);④"lawless"时代的道德如何自处
  (安斯康姆:没有立法者的律法观念已死,回德性)。

## 核心问题

**已解决**:
- 是与应当的区分(休谟 1739 指出)成为方法论水位线——
  任何从纯事实推出规范结论的论证被共同体自动标记
- 三大理论的"分工地图"成为工作共识:功利→公共政策权衡,
  义务→权利底线,德性→品格养成——单足独站的方案普遍被认为脆

**未解决/深水区**:
- 道德实在论 vs 反实在论(元伦理旗舰,百年未决):道德事实客观存在吗?
  麦基 1977"奇怪性论证"之后争论每十年换主战场,无收敛
- 三大理论能否统一(规范伦理圣杯):同一深层理论的三个投影,
  还是不可调和的范式?
- AI 伦理的理论地位(家族 00 章 §四;机器道德代理人/责任缺口)

## ✨ 这支最美的一个事实

**开放问题论证**(摩尔 1903):无论你把"善"定义成什么——快乐、
进化适应、神之所欲——总可以继续追问"**那它是善的吗?**",
而这问题永远仍然是开放的(不等于问"它是快乐的吗")。
一个"小学生问题",百年后仍在岗:它证明了"善"不可用自然性质穷尽定义
(或证明了定义本身就是错的问法)——本支因此出生。

- **普遍性假设**:原则对所有理性者成立——买到可辩护性,

  时姿势就是不一样)
