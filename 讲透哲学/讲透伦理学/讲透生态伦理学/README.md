# 讲透生态伦理学 · 自然共同体的会员证——从业主到公民

> **定位句**:这支负责"伦理学给自然发会员证"——把道德共同体
> 的边界从"所有人"外推到动物、物种、生态系统、荒野:
> 自然的内在价值是本支的第一命题。与[讲透环境伦理学](../讲透环境伦理学/README.md)
> 的分工:本支管**自然共同体本体**("自然有没有道德地位"),
> 彼管**人类行为与环境的规范关系**("我们对未来与环境负什么债");
> 《寂静的春天》为两家共同的起点文献。
> GB/T 13745 72045 伦理学 · 三级。家族:[讲透伦理学](../README.md)

## 诞生

- **谁/何时**:前奏=梭罗《瓦尔登湖》(1854,荒野的价值感受);
  立法三连——利奥波德《沙乡年鉴》"土地伦理"(1949,
  "人是生物共同体的普通成员与公民,不是征服者");
  卡逊《寂静的春天》(1962,生态链的灾难叙事引爆公众);
  辛格《动物解放》(1975,"疼痛就是疼痛,不问物种"——
  动物伦理的功利论证)与雷根《动物权利论》(1983,权利论证);
  奈斯"深生态学"纲领(1973,自我实现+生态中心平等两条最高原则)。
- **因什么问题**:①道德地位的传统门槛(理性/语言/互约)
  系统性排除动物与自然——门槛本身合法吗(辛格:疼痛是
  唯一不任意的门槛);②个体与整体谁优先(救一只鹿还是
  救一个种群?个体主义 vs 整体主义之战);③"自然价值
  不需要人类评价者"在哲学上站得住吗(内在价值之争)。

## 核心问题

**已解决**:
- 动物痛苦的道德地位:辛格论证(苦乐感受 suffices)已使
  "动物只是机器"的笛卡尔式立场在学理上破产——
  工厂化养殖的伦理质疑由此获得哲学地基
- "环境问题需要伦理学而不仅是管理学"的学科资格确立:
  生态伦理学从 1970s 的边缘成为标准课程

**未解决/深水区**:
- 内在价值之争:个体主义(动物有权利——雷根)vs
  整体主义(物种/生态系统才是价值单位——卡尔利科特);
  两派在"为了种群淘汰病弱个体是否正当"上直接互射
- 物种保护的道德单位:保护熊猫是救个体(每只都金贵)
  还是救基因库(个体的工具化)?——保护生物学的
  实践被迫在两套伦理间横跳
- 深生态学的"自我实现"纲领是哲学还是灵修(浅绿 vs 深绿
  的内战;社会生态学与生态女性主义对"深"的批评)

## ✨ 这支最美的一个事实

**利奥波德的一句换轴**:"把人从生物共同体的**征服者**改成
**普通成员与公民**。"一个介词级的改动(征服者→成员),
重写了人与自然的全部关系语法:征服者对领土只有处置权,
成员对共同体有义务且自身受共同体法约束——"土地伦理
改变了人的角色"。伦理学史上罕见的**单句立法**,
此后一切生态伦理(深浅皆然)都在这句话的延长线上。

## 假设与依赖

- **内在价值假设**:自然物的价值不依赖人类评价
  (valuers independent)——买到"没有人类在场荒野也值得
  保护"的强论证,付出形而上学账单(价值没有评价者
  如何存在?反实在论者的老问题换了生态外衣)
- **整体主义假设**(深生态侧):生态系统是道德单位——
  买到保护政策的目标清晰,付出个体权利的反直觉推论
  (可以为种群牺牲个体)
- 上游:[伦理学原理](../讲透伦理学原理/README.md)支
  (道德地位概念)、[东方伦理思想史](../讲透东方伦理思想史/README.md)支
  (不害/众生平等的跨文化资源)。下游:与[环境伦理学](../讲透环境伦理学/README.md)支
  分界协作;物种干预(基因驱动)通[生命伦理学](../讲透生命伦理学/README.md)支
