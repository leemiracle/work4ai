# 讲透中国伦理思想史 · 仁义礼智的谱系——从一个字到一个文明的行为语法

> **定位句**:这支负责"伦理学的中国路径"——孔子以一个"仁"字
> 把道德从天命与鬼神那里接管给人心与关系;此后两千五百年,
> 义利之辨、理欲之辨、群己之辨轮番开庭,直到近代遭逢
> "三千年未有之大变局"被迫现代转化。它不是西方伦理学的中国案例集,
> 而是一套**独立发明的规范语法**(关系本位/角色本位/修养本位)。
> GB/T 13745 72045 伦理学 · 三级。家族:[讲透伦理学](../README.md)

## 诞生

- **谁/何时**:孔子(前 551-479)以"仁"重构礼——礼不再是周王室的
  仪文,而是仁心的外化;战国孟子性善四端、荀子性伪之分;
  汉董仲舒(前 134 独尊儒术)制度化;宋明理学(11-16 世纪)
  天理人欲的形上重构;1915 新文化运动"打倒孔家店"开启现代转化。
- **因什么问题**:①礼崩乐坏之后,道德的根基何在(孔子的回答:
  不在天命,在人心);②人性善恶(孟荀之争:善是天生的还是
  圣人化性起伪造的);③义与利(道德与利益能否两全);
  ④与西方相遇后,儒家伦理是现代化的障碍还是资源。

## 核心问题

**已解决**:
- 先秦伦理争论的问题地图成熟:仁/义/礼/智/信、义利、王霸、
  性善性恶——范畴谱系与文献考据(出土简帛补强)已成学术基础设施
- 儒家伦理的关系定性获得结构性描述:五伦(父子/君臣/夫妇/
  长幼/朋友)是角色义务网而非普遍规则的清单

**未解决/深水区**:
- 儒家伦理是不是"德性伦理学"(与亚里士多德对读成立到什么程度)——
  中英语学界激辩(角色伦理学的挑战:"孝"装不进任何西方格子)
- 儒家伦理与现代性(人权/民主/平等)的兼容性:港台新儒家(牟宗三等)
  的"良知坎陷"论 vs 大陆政治儒学 vs 批判派,争中未决
- "儒学是伦理学还是宗教/生活方式"的定性本身(定性的定性问题)

## ✨ 这支最美的一个事实

**"仁"的字形即论证**:"仁"从"人"从"二"——善不在孤独的个体里,
而在**两个人之间**。汉字把关系伦理学预装进了词形:
一个字的写法,两千五百年前就宣布了"道德的单位是关系不是个体"——
这恰是对家族 00 章"个人主义假设"的最早补账(比照护伦理早了
两千四百年)。

## 假设与依赖

- **关系本位假设**:道德的基本单位是关系(父子/君臣/朋友)而非
  个体选择——买到家庭与共同体的无缝描述,付出普遍规则与
  陌生人伦理的薄弱(墨子"兼爱"的批评正打在此)
- **修养本位假设**:道德的重心是修身(成己)而后治人——
  买到道德与人格的深度绑定,付出制度设计的次级地位(重人治轻规制)
