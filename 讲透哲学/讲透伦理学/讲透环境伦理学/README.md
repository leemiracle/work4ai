# 讲透环境伦理学 · 对未来的债务——代际正义与气候责任

> **定位句**:这支负责"伦理学管人对环境的账"——污染者付费、
> 可持续发展、气候责任分配、对未出生者的义务:环境的道德问题
> 结构是**受众缺席**(受害者还没出生/不住在这)与**加害分散**
> (每个人的排放都"微不足道")。与[讲透生态伦理学](../讲透生态伦理学/README.md)
> 的分工:那支管自然共同体本体("自然有没有道德地位"),
> 本支管人类行为与环境的规范关系("我们负什么债、欠谁、怎么还")。
> GB/T 13745 72045 伦理学 · 三级。家族:[讲透伦理学](../README.md)

## 诞生

- **谁/何时**:起点=卡逊《寂静的春天》(1962,农药与生态链
  ——公众环境意识的引爆点);建制线:斯德哥尔摩人类环境会议
  (1972,环境问题进入国际法)→布伦特兰报告《我们共同的未来》
  (1987,"可持续发展"的定名:满足当代需求而不损害后代
  满足其需求的能力)→里约宣言(1992,"共同但有区别的责任")
  →巴黎协定(2015);哲学化:帕菲特《理与人》(1984,
  非同一性问题——未来人身份取决于我们现在的行为,
  "伤害未来人"的经典论证被打出结构性裂缝);加德纳
  《一个完美的道德风暴》(2006/2011,气候伦理的奠基分析:
  全球风暴+代际风暴+理论风暴三重叠加)。
- **因什么问题**:①我们对**不存在的人**(未来世代)有义务吗
  ——权利需要权利主体,未来人还不存在;②气候责任怎么分:
  历史排放者(发达国家的工业史)vs 当下能力者 vs 当下排放者
  ——三种账单算法给出三个答案;③分散性伤害的个体责任:
  我的开车排放"微不足道",可百万个微不足道正在改写大气
  ——个体道德与集体结果的结构错位。

## 核心问题

**已解决**:
- 可持续发展原则的建制化:代际公平从哲学口号变成
  国际法与国内政策的标准条款(布伦特兰定义的全球采纳)
- "共同但有区别的责任"作为谈判框架入法(CBDR,
  里约原则 7)——哲学上未夯平、政治上先通行(务实妥协的典范)

**未解决/深水区**:
- 非同一性问题的严格化(帕菲特):我们的行为决定**谁**将出生
  ——"我们的政策伤害了未来人"在逻辑上失据(被"伤害"的
  那批人若政策改变根本不会出生)。替代方案(无论何人论证/
  人格化的义务)四十年未成定论
- 气候责任分配的地基:历史责任(你烧了两百年)/
  现实能力(你付得起)/人均平等(大气按人头分)——
  三种正义观各执一票,没有共同公理系
- 个体责任的存在性:消费选择在结构中的道德分量
  ("个人碳足迹"概念曾由石油公司推广以转移系统责任
  ——伦理概念的政治出身问题)

## ✨ 这支最美的一个事实

**帕菲特的非同一性问题:伦理学被自己的逻辑反杀**。
1984 年帕菲特指出:你今晚是否避孕,决定了两百年后的
将是**哪一批**人(早一班晚一班的相遇都换人)。
于是"我们过度排放伤害了 2200 年的人"这个标准环保论证
出现裂缝——那批人若没有高排放的经济史就不会存在,
谈何"使他们变差"(存在 vs 更好的存在)?这个问题
不是抬杠:它逼整个义务论传统(伤害-权利框架)在
代际语境重构。一个论证同时震撼了伦理学与人口学,
是"哲学问题改变问题清单"的教科书案例。

  ——买到可计算(气候经济模型可跑),付出伦理争议

  的贴现率之争=伦理立场的数学化身)
