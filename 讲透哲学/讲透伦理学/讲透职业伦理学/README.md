# 讲透职业伦理学 · 专业共同体的社会契约——代码为谁而立

> **定位句**:这支负责"伦理学进职场"——职业不是一份工作,
> 是一份**对社会的不对称承诺**:社会授予专业共同体垄断执业权
> (执照/学位门槛),共同体回报以自我约束(伦理代码/同行评议/
> 吹哨制度)。医生、工程师、律师、教师、心理学家、程序员——
> 每个职业的代码都是这份契约的成文条款,AI 时代正在批量重签。
> GB/T 13745 72045 伦理学 · 三级。家族:[讲透伦理学](../README.md)

## 诞生

- **谁/何时**:原型=希波克拉底誓词(前 5 世纪,医业对社会的第一份
  承诺书);近代职业化浪潮(19-20 世纪:AMA 1847、NSPE 工程师
  伦理规范 1946、ACM 伦理准则 1972/2018 修订);二战后的建制化
  (纽伦堡审判 1947 → 各行业代码化);2023-24 出现 AI 使用指南潮
  (APA/ABPP 等职业组织密集出台,检索校准 2026-09-07——见家族
  [01 章](../01-近五年创新.md) 主线 D)。
- **因什么问题**:①专业人士握有外行没有的信息与权力
  (信息不对称)——谁来约束?②忠诚归谁:雇主/客户/公众/职业,
  四方冲突时听谁的?③技术跑得比代码快(代码更新以年计,
  技术迭代以月计)——滞后悖论怎么办?

## 核心问题

**已解决**:
- 职业代码的标准结构定型:对公众/对客户/对雇主/对职业四义务
  分章+利益冲突条款+举报保护——全球行业代码的趋同形态
- 吹哨的伦理分析框架成熟:内部逐级上报优先、公共危难例外、
  证据充分性门槛(航空与医疗安全史上的判例积累)

**未解决/深水区**:
- 代码滞后悖论在 AI 上达到峰值:APA/ABPP 们用"指南快修补丁"
  追技术的"持续发布"——指南与代码的分层(软法/硬法)能撑多久
- 吹哨的忠诚冲突:对雇主忠诚 vs 对公众忠诚,无词典序
  (每一代吹哨者都在重付学费)
- "职业"边界本身:程序员/数据科学家/提示工程师是不是"专业
  共同体"(无执照垄断,何来社会契约?)——新行业的代码资格之争

## ✨ 这支最美的一个事实

**代码的第一读者不是公众而是同行**:职业伦理代码的奇特效力来自
它本质上是**专业共同体对社会的公开承诺书**——ACM 2018 修订把
"避免伤害"列为 1.1 条(高于"诚实可信"),等于当着全世界的面
把伤害预防写进行业的自我定义。一份没人执法的文本,靠共同体
的成员资格压力运转——道德的制度化最小可行产品。

## 假设与依赖

- **共同体自治假设**:专业共同体能自我约束(同行评议有效)——
  买到灵活性,付出"狐狸看鸡窝"的结构性风险(行业失灵史:
  从烟草到化石燃料到平台算法)
- **不对称承诺假设**:职业伦理严于日常道德(医生可拒绝、
  工程师必须吹哨而普通人不必)——买到公共信任,付出
  从业者的角色负担(角色道德 vs 个人道德的张力)
