# 讲透政治伦理学 · 强制权力的正当性——什么制度是对的

> **定位句**:这支负责"伦理学审国家"——国家是唯一被授权
> **强制**的机构(收税/监禁/开战),政治伦理学追问这份强制力
> 凭什么正当:权威来自同意吗(契约论)?财富再分配是抢劫还是
> 救赎(罗尔斯 vs 诺齐克)?战争有正义的吗(正义战争论)?
> 与马哲家族的边界:本支管**规范性正义理论**("什么制度是对的"),
> 马哲管**批判分析**("正义话语为谁服务")——同一对象,两种问法。

## 诞生

- **谁/何时**:原型=柏拉图《国家》(正义即各司其职);
  社会契约三连:霍布斯《利维坦》(1651,秩序换保护)、
  洛克《政府论》(1689,天赋权利+反抗权)、卢梭《社会契约论》
  (1762,公意);功利主义立法(边沁:法律改革的算术);
  现代复兴=罗尔斯《正义论》(1971,无知之幕+两个正义原则)
  引发 50 年论战(诺齐克《无政府、国家与乌托邦》1974 应战);
  正义战争论现代化(沃尔泽《正义与不正义的战争》1977)。
- **因什么问题**:①我为什么该服从国家(政治义务问题——
  同意/受益/公平游戏/自然义务,每种证成都有一戳就疼的软肋);
  ②不平等什么时候不正义(运气平等主义的战场);③对暴力机器
  (军队/警察)的使用设什么限(jus ad bellum 开战正义/
  jus in bello 战争中正义);④边界是道德任意的吗
  (全球正义:国界内互助义务为什么止于国界)。

## 核心问题

**已解决**:
- 罗尔斯的论证结构成为学界定论:原初状态+无知之幕
  (装置有效性)→两个正义原则(自由优先/机会均等+
  差别原则)——前提可争,结构无可争
- 正义战争的双重法典化:开战正义(正当理由/最后手段/
  成功可能)与战争中正义(区分原则/比例原则)——
  国际人道法的伦理骨架

**未解决/深水区**:
- 罗尔斯-诺齐克之争 50 年未合:差别原则(不平等只有在
  有利于最差者时才正当)vs 资格理论(持有正义=获取+转移+
  矫正,再分配侵犯权利)——分配正义的两大范式僵局
- 全球正义的边界:国家边界是道德任意的历史事故
  (博格:全球穷人有正义要求)vs 政治共同体有特殊义务
  (米勒:同胞优先不是偏见)——移民/外援/气候责任的
  共同理论地基
- 政治义务的证成:服从义务到底存不存在(哲学无政府主义
  的"没有一个论点过线"指控至今未被整体回应)

## ✨ 这支最美的一个事实

**无知之幕:用一个约束买一种美德**:罗尔斯的设计——
让立约者忘记自己的阶级/天赋/性别/信仰,再让他们立法。
不能消除人的自利,就让自利在信息结构里自我抵消:
你不知道自己会落在哪个位置,于是你为最差位置立法
(最大最小化)。公平不再依赖圣人的美德,而依赖**幕布的厚度**
——把"人心"问题转译成"信息"问题,伦理学史上最优雅的
一次工程化(家族 [03 章](../03-可构造与结构.md) 美之时刻 3 的展开现场)。

## 假设与依赖

- **契约论假设**:正当性来自(假想的)同意——买到直觉亲和力
  (自由社会的自我理解),付出"没人在场签过字"的隐喻债
  (假想同意到底有没有约束力)
- **国家中心假设**:政治伦理的单位是国家——买到制度可操作性,
  付出全球/地方/非国家行为体(企业/平台/算法)的半盲区

  下游:与[环境伦理学](../讲透环境伦理学/README.md)支共管气候责任分配
