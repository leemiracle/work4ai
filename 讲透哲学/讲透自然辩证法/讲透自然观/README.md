# 讲透自然观 · 自然界的总图景——辩证唯物自然观的百年更新

> **定位句**:这支负责自然辩证法的**地基问题**:自然界作为整体是什么样子——
> 物质、运动、时空、演化,以及人在其中的位置。恩格斯手稿的主体就是它:
> 用当时自然科学的三大发现给辩证法作证;今天它更新为系统自然观与生态自然观,
> 回答「人与自然是什么关系」这个 21 世纪最贵的问题。
> GB/T 13745-2009:72015 自然辩证法 · 三级 **7201510 自然观**。家族:[../README.md](../README.md)。

## 诞生

1873-1883 年,恩格斯写《自然辩证法》手稿(1925 年首次出版):把自然科学史
梳理成「自然界辩证发展」的证据链——康德星云假说(起源论)、能量守恒与转化、
细胞学说、达尔文进化论,合称三大发现(星云假说常列为前奏)。19 世纪末的
「物质消灭了」恐慌(电子/X 射线的发现)成为辩证唯物论与现代物理的第一场论战
(列宁《唯物主义和经验批判主义》1908)。20 世纪中叶起,一般系统论(贝塔朗菲
1948)、耗散结构(普里戈金 1969)、混沌与复杂性(1980s)推动「系统自然观」;
《寂静的春天》(1962)与《增长的极限》(1972)催生「生态自然观」——中国的
「人与自然和谐共生」话语是其建制化形态。

## 核心问题

- 自然界的**图景**如何从「存在」(机械论)翻转为「演化」(历史)?(恩格斯:
  「自然界不是存在着,而是生成着并消逝着」)
- 物质/运动/时空/信息谁是终极范畴?(「物质消灭了」论战的当代版:暗物质/
  量子场/信息本体论)
- 系统与还原:整体性质能不能从组分推出?(涌现——复杂性科学的哲学战场)
- 人与自然的关系:征服、契约还是共生?(生态危机把 1876 年恩格斯的警告
  变成全球议程)
- 人工智能是不是「自然观的新成员」?(机器智能迫使自然图景容纳第二种智能)

## ✨ 这支最美的一个事实

1876 年,恩格斯在《劳动在从猿到人转变过程中的作用》里写下:「我们不要过分
陶醉于我们人类对自然界的胜利。对于每一次这样的胜利,自然界都对我们进行报复。」
——比《寂静的春天》早 87 年、比气候变化议程早一个多世纪,一个 19 世纪的
哲学手稿精确预言了「技术胜利的生态账单」。生态自然观不是进口理论,
它的最早版本写在这门学科的开山手稿里。

## 假设与暗面

- 假设:自然科学的总体图景可以**综合**为统一世界观(三大发现→辩证图景;
  今天:复杂系统→系统图景)——假设「综合不背叛科学」。
- 假设:演化/历史性是自然的普遍维度(从星云到生命到社会单线贯通)。
- 暗面:19 世纪的「科学作证」后来两度为政治服务——李森科事件(1948)证明
  「自然观裁决科学」可以变成科学的灾难;综合的权力必须被科学生产的知识约束。
- 暗面:系统语言易被滥用成万物灵丹(「系统工程」修辞通胀)。

## 教材锚

- 恩格斯《自然辩证法》(手稿 1873-1883;1925 年初版)——开山文本
- 《自然辩证法概论》(教育部统编教材)「自然观」编——中国建制的标准表述
