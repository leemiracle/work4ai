# 讲透自然辩证法 · 科学技术的自我审视——亦称科学技术哲学

> **本质一句话**:自然辩证法=科学技术的自我审视——当科学追问「科学知识凭什么可靠」、
> 技术追问「改造世界时谁负责」,一门**以科学技术自身为研究对象**的二阶学科就诞生了;
> 亦称科学技术哲学(GB/T 13745-2009:720 哲学 · 二级学科 **72015 自然辩证法**)。
>
> **双名声明**(先读这个再读本家族):「自然辩证法」是恩格斯手稿(1873-1883)传下来的
> **中国建制名**——全世界只有中国把这门课开成理工科研究生公共课;「科学技术哲学」是
> 国际学界的**内容名**。本家族两块牌匾都挂:建制线(恩格斯→1956 规划→统编教材)与
> 内容线(维也纳学派→波普尔→库恩)在 02 章 §三的「规范化」栏正式谈判。

## 〇、家族树(GB/T 三级 4 支落子)

```
讲透自然辩证法/
├── 讲透自然观/          7201510——自然界的总图景:物质/运动/时空/演化,人与自然的关系
├── 讲透科学哲学/        7201520——科学之为科学:划界/证伪/范式/归纳/实在论
├── 讲透技术哲学/        7201530——技术之为技术:人工物/座架/责任/负责任创新
└── 讲透专门科学哲学/    7201540——具体科学的哲学现场:人工智能哲学、数学哲学、物理哲学(内节)
```

> 四支的共同血统:**二阶性**——研究对象不是自然界,而是「关于自然界的知识及其改造力量」。
