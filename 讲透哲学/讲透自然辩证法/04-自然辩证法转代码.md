## 0. 开篇:一句黑格尔式的断言,被一个直方图检验

「2010 年代后,科学哲学的重心从『范式』移向『不透明性』」——这是写在无数
导论里的叙事断言。它对吗?这类断言的结构是:**概念消长**——而词频恰好可数。
把一批标志性文献(教材目录、SEP 词条修订史、《自然辩证法研究》/《通讯》专题)
的关键词按年代切片,数一数:

```python
# 概念消长的极简检验(数据=示意缩样,方法=正式)
freq = {  # 概念: {年代段: 次数(示意)}
    "范式":      {"1970s": 42, "1990s": 55, "2010s": 61, "2020s": 58},
    "证伪":      {"1970s": 38, "1990s": 30, "2010s": 22, "2020s": 19},
    "不透明性":  {"1970s":  0, "1990s":  2, "2010s": 14, "2020s": 47},
    "负责任创新": {"1970s":  0, "1990s":  0, "2010s": 11, "2020s": 39},
}
for term, row in freq.items():
    assert row["2020s"] >= row["1970s"] or term == "证伪"   # 唯证伪下滑
rising = [t for t, r in freq.items() if r["2020s"] > 2 * max(r["1970s"], 1)]
print("上升概念:", rising)   # -> 不透明性、负责任创新(治理语言接管)
```

**走廊的第一课当场显形**:代码替你数词,替不了你解释词——「不透明性」词频上升
度量的是**关注度**,不是**概念成熟度**;断言被数据确认的部分(消长方向)与
数据沉默的部分(意义变迁)必须分开交付(02 章概念三步法负责后者)。

## 2. 代码走廊 C1:科学计量(科学学传统的哲学化使用)

**思想来源**:普赖斯《小科学,大科学》(1963)与加菲尔德引文索引(1964)——
本家族用法与科学社会学(管理学宇宙 63035,归入声明)的分界:**他们问建制
(产出/合作/资助),我们问概念**(哪些元理论语言在扩张,02 章 §一的层别)。

最小工作流(纯标准库,数据可换真语料):

```python
from collections import Counter
docs = {  # 示意:文献条目 {id: (年代, 词集)}
    "kuhn1962":   (1962, {"范式", "常规科学", "危机"}),
    "popper1963": (1963, {"猜想", "反驳", "证伪"}),
    "humphreys04": (2004, {"计算", "不透明性", "模拟"}),
    "ai4s2024":   (2024, {"不透明性", "可靠性", "预测知识"}),
}
OTHER = 9                           # 未入层词(分词词典即理论承诺,见诚实条款)
def layer(word):  # 02 章 §一六层语言的关键词粗分类
    for i, vocab in enumerate([
        {"辩证", "自然观"}, {"证实", "逻辑重构"}, {"猜想", "反驳", "证伪"},
        {"范式", "危机", "不可通约"}, {"纲领", "贝叶斯", "先验"},
        {"不透明性", "可靠性", "负责任", "预测知识"}]):
        if word in vocab: return i
    return OTHER
late = Counter(layer(w) for k, (y, ws) in docs.items() if y >= 2004 for w in ws)
early = Counter(layer(w) for k, (y, ws) in docs.items() if y < 2000 for w in ws)
assert late[5] > early[5]          # 第⑥层(计算-治理语言)只在近期出现
print("近期语言层分布:", dict(sorted(late.items(), key=str)))  # -> 第5层独大
```

**C1 的诚实条款**(走廊规范):语料选样声明必须随结果交付(正史偏差,03 章 §6);
词频是关注度的代理变量;分词词典即理论承诺(把「可靠性」归第⑥层本身就是立场)。

## 3. 代码走廊 C2:论证挖掘(元理论立场 → 图结构)

**思想来源**:图尔敏论证模型与当代 argument mining;本家族的独特原料是
**哲学史自带的高密度论证网**——三大立场百年混战,天然是标注好的图:

```python
nodes = {  # 节点:立场/主张
    "证实主义": "科学靠经验确证积累真理",
    "证伪主义": "科学靠大胆猜想与无情反驳进步",
    "历史主义": "常规科学不检验范式,危机才有革命",
    "纲领主义": "硬核受保护,保护带吸收反例",
    "贝叶斯主义": "责备与确认都是概率更新",
}
edges = [  # (源, 类型, 靶):attack/support
    ("证伪主义", "attack", "证实主义"),
    ("历史主义", "attack", "证伪主义"),
    ("纲领主义", "support", "历史主义"),
    ("纲领主义", "rescue", "证伪主义"),   # 把证伪吸收为纲领竞争判据
    ("贝叶斯主义", "rescue", "证伪主义"),  # 把证伪改写为责备分配特例
]
def undeafeated(n):  # 简易存活分析:被 attack 且无 rescue 的立场
    attacked = {t for s, k, t in edges if k == "attack"}
    rescued  = {t for s, k, t in edges if k == "rescue"}
    return n in attacked and n not in rescued
assert not any(undeafeated(x) for x in nodes)  # 每个被攻击的立场都被抢救过
print("图密度:", len(edges), "/", len(nodes) * (len(nodes) - 1) // 2)
```

跑通后你会看到本学科的**结构事实**:没有任何立场被干净杀死——每个被攻击的
立场都以「被改写吸收」的方式存活(证实主义活在贝叶斯确认里,证伪活在责备分配里)。
这正是 00 §七发现 1 的图论版本:**立场免疫是常态,死于免疫的是表述不是内核**。

**C2 的工程出口**:论文论证链审计(自动抽取主张-证据边,找断裂)、
政策论证的可视化(伦理审查意见书变成可检查的图)、AI 生成文本的
「论证密度」体检(01 章科研诚信线的技术底座)。

## 4. 工程师落点(三件套之三)

### 落点 A:可解释 AI——认识不透明性的分级治理工程

01 章 §一的「不透明性光谱+可协商」共识,工程化为一个决策表:

| 错误代价 | 不透明容忍度 | 工程动作 | 哲学根据 |
|---|---|---|---|
| 低(推荐排序) | 高 | 事后指标监控即可 | 划界宽松:预测成功即可(工具主义) |
| 中(招聘/信贷) | 中 | 特征归因+反事实解释+审计日志 | 算法歧视治理的判据矩阵(01 §三) |
| 高(医疗/司法/科研结论) | 低 | 形式验证/机理模型/人在环否决 | 责任原理:远期伤害须有可问责链(技术哲学支) |

这张表是 02 章 §一第⑥层语言的「可执行文本」——**治理词汇第一次有了
与③⑤层同等的严格性**。工程师读法:不透明性不是 bug,是**按代价定价的资源**。

### 落点 B:科研诚信工具——默顿四规范的可操作化

| 默顿规范 | 制度对译 | 工具形态 |
|---|---|---|
| 公有性 | 数据/代码共享政策 | 仓库+许可证+复现包 |
| 普遍主义 | 双盲评审/标准化评测 | 评审平台的去身份化管道 |
| 无私利性 | 利益冲突披露 | COI 声明与关联检测 |
| 有组织的怀疑 | AIGC 披露+图像查重+引用审计 | 01 §五的技术栈(检测器+政策) |

四行对译表=03 章 §三社会结构四件套的工程化身。**判断一个诚信工具的哲学品质**:
看它保护哪条规范、误伤哪条(查重工具误伤公有性:吓得没人敢公开草稿)——
工具设计就是规范排序的显式化。

## 6. 反直觉发现

**哲学问题被代码「解决」的部分,恰恰是哲学不关心的部分**。责备分配的算术
五分钟能算完——波普尔与库恩谁都没兴趣争这个;他们争的是**哪次免疫值得付价格**
(价值),算术只是把事实部分剥出来让争点显形。代码进入哲学的方式不是接管,
是**提纯**:把可计算的渣质滤掉,留下真正需要人的那部分。反过来,
指望「用代码终结哲学争论」的项目(历史上有过好几波)全部死在
三保留地——因为它们把提纯误当成了替代。
