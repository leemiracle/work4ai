# 讲透技术哲学 · 技术之为技术——从人工物到责任

> **定位句**:这支负责自然辩证法的**另一条腿**:科学问「世界是什么」,
> 技术问「我们如何改造世界、凭什么、谁负责」。它从「技术是科学的婢女」
> 的偏见里解放出来,追问技术的自主性、人工物的本体地位、
> 以及 21 世纪最贵的哲学问题——自主系统的责任鸿沟。
> GB/T 13745-2009:72015 自然辩证法 · 三级 **7201530 技术哲学**。家族:[../README.md](../README.md)。

## 诞生

两条脐带:工程技术哲学——卡普《技术哲学原理》(1877,器官投影说:工具是
人体器官的投影),恩格斯手稿里「劳动创造人本身」的技术发生学;人文技术哲学——
芒福德《技术与文明》(1934,技术分为多元技术与单一技术)、埃吕尔《技术社会》
(1954,技术的自主性)、海德格尔《技术的追问》(1954,座架 Gestell:现代技术
把自然摆置为「持存物」,莱茵河成为水电站的供应商)。1979 年约纳斯《责任原理》
给技术时代立新命令:「你的行动要使其后果与地球上真正人类生命的存续相容」。
米切姆《通过技术思考》(1994)完成两传统合流与学科建制化。中国:自然辩证法
建制里「技术论」板块 1980s 起生长,今天以科技伦理与负责任创新为主战场。

## 核心问题

- 技术是中性的吗?(「枪不杀人」命题 vs 座架论:技术先于使用就框定了世界)
- 技术有自主性吗?(埃吕尔:技术按自身逻辑生长;反方:资本与制度才是引擎)
- 人工物的本体:技术物是发现的还是发明的?功能如何「附加」在物理之上?
- 责任的边界:远期/累积/不可知的伤害谁来负责(约纳斯的责任原理);
  **责任鸿沟**——自动驾驶/自主系统的伤害找不到可问责的人
- AI 技术的特殊性:算法歧视(历史数据继承历史不公)、情绪识别
  (技术重新定义人的内心范畴)、生成式 AI 的治理(风险分级)

## ✨ 这支最美的一个事实

海德格尔的莱茵河:同一条河,「桥」让它作为风景**显摆**自己,
水电站把它**摆置**成压力供应商——技术的本质不在机器里,而在它让世界
以何种方式向我们显现(座架)。一个 1954 年的哲学意象,精准预言了
2020 年代的争论:推荐系统不是「工具」,它是先把你的注意力摆置成
「可变现持存物」的那只先在的手——问「推荐算法是不是中立工具」的人,
都欠海德格尔一次阅读。

## 假设与暗面

- 假设:技术**作为整体**是可反思的对象(技术哲学的对象假设)——
  「技术」这个单数名词本身是 19-20 世纪的抽象,工匠知道吗?
- 假设:责任原理可行——远期后果的知识前提常常不成立(我们无法预知
  五十年的技术后果,却要为其负责:命令与能力的剪刀差)
- 暗面:治理语言(风险分级/伦理审查)可能变成合规装饰——
  「伦理漂白」(ethics washing)是 2020s 治理热的新病理
- 暗面:对技术的浪漫主义批判(把「技术」恶魔化)与座架论被滥用为
  万能解释,一样是懒惰
