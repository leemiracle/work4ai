# 讲透科学哲学 · 科学之为科学——从证伪到贝叶斯的资格审计

> **定位句**:这支负责自然辩证法的**心脏问题**:科学知识凭什么可靠——
> 划界(什么是科学)、方法(归纳/证伪/确认)、进步(范式/纲领)、
> 实在性(理论谈的东西存在吗)。它是内容传统(科学技术哲学)的旗舰,
> 也是中国建制里与国际学界重叠度最高的一支。
> GB/T 13745-2009:72015 自然辩证法 · 三级 **7201520 科学哲学**。家族:[../README.md](../README.md)。

## 诞生

1929 年维也纳学派《科学的世界观》宣言:可证实原则(证实主义);1934 年波普尔
《研究的逻辑》反叛:可证伪性+划界问题;1951 年蒯因《经验主义的两个教条》
引爆整体论;1958 年汉森提出「观察渗透理论」;1962 年库恩《科学革命的结构》:
范式/常规科学/不可通约——学科重心从「证明的逻辑」移到「变化的动力学」;
1970 年拉卡托斯《科学研究纲领方法论》(硬核/保护带)试图救回理性;
1975 年费耶阿本德《反对方法》:「怎么都行」;1970s-80s 科学实在论大论战
(范·弗拉森《科学的形象》1979);1990s 起贝叶斯主义成为确认理论的数学主流。
中国建制:1980s 起「科学哲学」成为自然辩证法研究的核心板块。

## 核心问题

- **划界**:科学与伪科学的判据(证伪标准失败后 60 年无共识;治理需求使其回潮)
- **归纳**:休谟问题(1739)——普遍规律凭什么从有限观察得出?(永久开放;
  贝叶斯主义将其公理化而非解决)
- **理论结构**:观察术语与理论术语的两分还能维持吗?(整体论/语义观)
- **科学变化**:革命是理性还是社会学事件?(范式 vs 纲领 vs 无政府主义)
- **实在论**:成功理论谈的不可观测物(夸克/场/黑洞)存在吗?
  (「无奇迹论证」vs「悲观归纳」——科学哲学自己的未决对决)
- **AI 时代新题**:AI 生成的预测知识算不算知道(与专门科学哲学支共管)

## ✨ 这支最美的一个事实

波普尔把「错误」变成科学引擎:人类知识只能是猜想,但猜想可以被批评杀死——
科学之所以优于玄学,不因为犯得更少,而因为**唯一欢迎被反驳**。一个否定性
概念(不可证伪即非科学)撑起整个科学合理性的重述,并顺手解释了为什么
占星术万年不出错(从不出错正是它的死罪)——错误的自由市场里,
不怕死的理论才配谈真理。

## 假设与暗面

- 假设:科学是**理性且进步**的事业(合理性假设)——范式理论反手证明
  合理性标准本身随范式变,循环风险内置。
- 假设:存在可分析的「科学方法」这个对象(方法论一元论)——费耶阿本德
  证明历史上有多少成功科学就有多少方法。
- 暗面:证伪主义的通俗版成了打击对手的棍子(「你这个不可证伪!」)——
  忘了迪昂-蒯因:谁都不容易被干净证伪。
- 暗面:范式语言被相对主义挪用(「你有你的真理我有我的」)——库恩本人
  至死否认自己是相对主义者。
