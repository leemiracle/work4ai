# 讲透中国少数民族哲学思想 · 多民族的哲学图景:汉语中心之外的思考

> **定位句**:这支负责**目录层面的视野纠偏**——
> 中国哲学不等于汉语哲学:蒙古族的「长生天」与天命观、
> 藏传佛教的空性与道次第、维吾尔族的《福乐智慧》、
> 彝族的宇宙生成论、纳西东巴经的本源观,
> 都在用自己的语言回答「世界与人如何安顿」。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(中国少数民族哲学思想,不分断代)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:不分断代,横切多民族传统。坐标举例:
  《福乐智慧》(玉素甫·哈斯·哈吉甫,11 世纪喀喇汗王朝)、
  《蒙古秘史》(13 世纪)与藏传佛教格鲁派宗喀巴《菩提道次第广论》
  (15 世纪)、明清回族学者的汉文伊斯兰哲学(王岱舆/刘智)、
  彝族毕摩文献(《宇宙人文论》等,整理出版于 20 世纪后期)、
  纳西东巴经、傣族南传佛教论典。
- **因什么问题**:①学科建设期的问题——「哲学思想」的判定
  在口传传统与宗教文献上如何落地(毕摩经有没有「哲学」?);
  ②文献学基础——多语种(回鹘文/八思巴文/彝文/东巴文/傣文)
  文本的整理翻译远未完成;
  ③方法问题——用汉语哲学的范畴(道/理/心)套民族思想,
  是否复制了「以西释中」的老问题(二阶格义)?

## 核心问题

**已解决**:
- 通史性框架的建立(20 世纪后期多卷本《中国少数民族哲学史》类成果):
  诸民族哲学思想进入学科视野,「中国哲学=汉语哲学」的默认被制度性打破
- 若干经典文本的哲学定性:《福乐智慧》的「四德」(知识/公正/幸运/知足)
  伦理学、宗喀巴道次第的修行次第论、彝族「清浊二气」宇宙论
  ——均可与汉语传统的问题对读

**未解决/深水区**:
- 判定标准:「哲学思想」与宗教观念、民俗智慧的边界在哪?
  (家族 00 章「合法性之争」的民族版,更尖锐)
- 口传传统的哲学史书写:无文本的思想如何入史(方法空白)
- 汉译与概念表的立场问题:民族语概念(如蒙古「腾格里」)的
  汉译词典未经学界充分谈判(家族 02 章范畴对译的民族段)

## ✨ 这支最美的一个事实

**《福乐智慧》的四主角结构**:玉素甫·哈斯·哈吉甫用四个人物
——国王(日出,公正)、大臣(月圆,幸运)、大臣之子(贤明,知识)、
苦行者(觉醒,知足)——把一场人生观的四方会谈写成 13000 行长诗:
知识与知足的辩论(服务世界还是遁世修行)贯穿全书,
结构与柏拉图对话录的戏剧化论证同构,却是喀喇汗王朝
用回鹘语诗歌完成的。**哲学论证的文学形式,各文明独立发明**——
「对话体」不是地中海的专利。
