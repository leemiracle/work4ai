# 讲透先秦哲学 · 轴心突破:道术为天下裂,诸子各自救世

> **定位句**:这支负责中国哲学的**原创纪元**——
> 王官之学解体后,儒道墨法名阴阳各自回答同一个问题:
> **礼崩乐坏之后,秩序何以重建?**此后两千年的思想,
> 大多是这些答案的注释、组合与反叛。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(先秦哲学)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:前 770(平王东迁,官学下移)至前 221(秦统一)。
  制度背景:**天子失官,学在四夷**(《左传》昭公十七年)——
  王官之学的教师与典籍流散,私学兴起(孔子「有教无类」是标志),
  士阶层成为思想的载体。
- **因什么问题**:周文疲弊(牟宗三语)——礼乐制度还在,共同的信仰已断。
  诸子九流是同一场危机的九张诊断书(《汉书·艺文志》「诸子出于王官」说
  与胡适的反驳,是本支第一桩百年公案)。
- **学术回响**:20 世纪诸子学复兴(章太炎/胡适/冯友兰)重估九流;
  出土文献(郭店楚简/上博简)持续改写本支的底稿(儒道关系已被实质重绘)。

## 核心问题

**已解决**:
- 人性论四种基本答案(孟性善/荀性恶/告子无善无恶/世硕有善有恶)
  铺满逻辑空间,后世性论皆在此坐标系内组合
- 名实之辩的概念遗产(白马非马=语义分层;《墨经》故理类=论证三要素)
- 天人关系的两极(孔孟「知命」/荀子「天人之分」)确立后世辩论的坐标轴

**未解决/深水区**:
- 老子其人与《老子》其书的系年(春秋末说/战国中期说/出土多文本层说)
- 儒道关系:对立(《老子》「绝仁弃义」)还是互动(郭店简无此语)?
  底稿更新中(家族 01 章主线 E)
- 墨家中绝之谜(名辩与科技传统为何断流?——家族 02 章「死亡与复活」)

## ✨ 这支最美的一个事实

**濠梁之辩**(《庄子·秋水》):「子非鱼,安知鱼之乐?」——
惠施以标准他心问题诘难,庄子以「我知之濠上」转移辩护位置:
知识的辩护依赖于知道者所处的位置。八句话演完视角主义 vs 语义分析,
两千三百年后的 AI 他心问题(「你怎么知道模型有体验」)仍是同一辩题。

## 假设与依赖

- 「诸子=哲学」是学科化筛子的产物:诸子文本兼含政论/伦理/方技,
  取「哲学」必舍旁枝(家族 00 章 §五筛子账单,本支是账单最大户)
- 系年全部带误差棒:先秦断代依赖传世文献+出土简互证,
  单点结论不可靠,密度统计可靠(实验脚本断言 A 的适用域)
- 上游依赖家族 [00 章](../00-体系结构.md)的七次转场 T1;
  下游喂养秦汉支(诸子如何被经学收编)与全部后世支
