# 讲透魏晋南北朝哲学 · 玄学的清峻与佛学的入华:有无之辩

> **定位句**:这支负责**价值根据的换轨**——
> 汉代宇宙论破产之后,玄学家回到《老》《易》《庄》,
> 把问题从「天对人间说什么」换成「有无本末,何者为真实」;
> 同期佛教入华,格义误读开启了一场改变中国思想的漫长消化。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(魏晋南北朝哲学)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:220(汉亡)至 589(隋统一)。正始之音(240 顷)开题,
  竹林(250s)、元康(裴頠/郭象)接续;佛学一线:佛图澄(310)入中原、
  鸠摩罗什(401)译经、竺道生(420 顷)孤发、范缜《神灭论》(507)收官。
- **因什么问题**:①名教危机——经学谶纬随汉室一起破产,
  「礼法」成了篡夺者的工具,价值需要新地基;
  ②清谈的制度化——人物品评与论辩文化把「谈辩」变成思想生产方式;
  ③生死之问——乱世(汉末大疫+八王之乱+永嘉南渡)把个体安顿
  问题推到最前,为佛学入华腾出了需求侧。

## 核心问题

**已解决**:
- 玄学三期的完整弧线:贵无(何晏/王弼)→ 崇有(裴頠)→ 独化(郭象)
  ——「名教与自然」的关系被正面论证了一整轮
- 诠释学的自觉:王弼「得意忘言」确立「超越字面抓义理」的注释纲领
  (中国诠释学的方法论宣言)
- 政教关系的第一次理论化:慧远《沙门不敬王者论》
  (出世秩序与王权秩序的边界谈判文本)

**未解决/深水区**:
- 郭象《庄子注》的著作权(向秀注的改写幅度)——注疏层定谳难题
- 「格义」的评价:误读的失败史,还是概念本土化的必经通道?
  (家族 00 章反直觉 3:误读成就了转化)
- 神灭神不灭之辩为何不了了之——范缜赢了论辩,佛教照样兴盛:
  论辩胜负与信仰分布为何脱钩?

## ✨ 这支最美的一个事实

**王弼的「言意之辨」**:《周易略例·明象》——言(卦辞)是象(卦象)的
工具,象是意(义理)的工具,**「得象而忘言,得意而忘象」**。
一个 23 岁去世的青年,把「文本/隐喻/意义」三层结构说透:
理解的本质是穿过表达形式抵达意义,而形式注定要被穿越后放下。
这是诠释学的普遍问题在中国最早的系统表述——
比「媒介即讯息」的反面(讯息非媒介)早一千六百年。

## 假设与依赖

- 「玄学=魏晋主流」是史料偏差:清谈名士是精英层的可见史,
  民间信仰与佛教寺院经济的体量未必更小(幸存者偏差,家族 00 章 §五)
- 佛学入华的叙事依赖译经史,译经的选择性(什么被译/什么没译)
  塑造了此后的「佛教中国」——语料偏差即思想偏差
- 上游依赖秦汉支(名教是玄学的批判对象);下游喂养隋唐支
  (格义的欠债由判教与宗派偿还)
