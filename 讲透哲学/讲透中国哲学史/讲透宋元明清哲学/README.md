# 讲透宋元明清哲学 · 理学的帝国:伦理学做成形而上学,及其考据反动

> **定位句**:这支负责**汉语思想的建设巅峰与其自我批判**——
> 理学家把仁义礼智上推为宇宙法则(「天理」),让儒学第一次
> 拥有不输佛教的心性形上学;五百年后,考据学调转武器,
> 用训诂证明那个「理」是后人的意义漂移。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(宋元明清哲学)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:960(北宋建)至 1840(鸦片战争)。
  宋初三先生(1040 顷)开学,周敦颐《太极图说》(1050)、
  张载气学(1056)、二程天理(1080)、朱陆鹅湖之会(1175)、
  朱熹《四书章句集注》(1190)、官学化(1315)、
  王阳明龙场悟道(1508)、泰州平民化(1525)、李贽异端(1602)、
  顾炎武开清学(1670)、戴震《孟子字义疏证》(1777)。
- **因什么问题**:①回应佛教——儒学必须在心性论与宇宙论上
  拿出自己的体系(不然士人「淡泊」都跑去禅门);
  ②重建价值秩序——唐末五代的失序要求比礼法更内在的根基
  (「人心惟危,道心惟微」的十六字心传被立为新道统的枢纽);
  ③后期反动——理学官学化后的空疏与「以理杀人」(戴震语)
  逼出「回到汉儒」的考据路线。

## 核心问题

**已解决**:
- 心性形上学的完整体系:理气(宇宙论)+心性(人性论)+
  工夫论(修养方法)+境界论(圣贤气象)四件套,
  理学与心学给出两套引擎(性即理/格物 vs 心即理/致知)
- 「四书」体系的建立(朱熹):儒学元典从「六经」重心
  转移到「四书」——课程改革改变了一个文明的必修课
- 考据学的方法论成熟(版本/校勘/辨伪/音韵):
  「理」的概念史审查(戴震)是概念史方法的古典完成

**未解决/深水区**:
- 理学定性之争:儒学的完成(牟宗三:道德的形上学)还是歧出
  (阳儒阴佛,先秦本义被佛教范畴扭曲)?——本支最大断代争议
- 李约瑟问题思想版:理学自然观(格物)为何没有长出近代科学?
- 戴震式批判的政治史定位:「以理杀人」批判是儒学内部
  的启蒙,还是被后世(胡适)追认的启蒙?(家族 02 章美之时刻 4)

## ✨ 这支最美的一个事实

**「天理」二字,自家体贴**:二程自述「天理」二字是
「自家体贴出来」——不是从经典考据出的名词,
是为回答「秩序为何对人有必然性」而**铸造**的新范畴:
它同时是宇宙的法则(万物所以然)、人性的结构(性即理)、
道德的命令(存天理)。一个词同时接通「是」与「应该」,
此后六百年,中国人骂人最重的话是「天理难容」——
形上学的范畴变成了百姓的日常语法。
(实验脚本断言 B:这组范畴只出现在本支窗口——概念即断代指纹。)

## 假设与依赖

- 「理学=官方意识形态」的通叙事有压缩:理学的官学化(1315 科举)
  是体制收编而非思想胜利——朱熹生前被伪学之禁,身后才成官学
- 牟宗三「三系说」等判教框架本身是 20 世纪新儒家的构造,
  用它读宋明,读出的是两次创造的总和(家族 00 章三谱系)
- 上游依赖隋唐支(佛教心性论的引力场);下游喂养近代支
  (今文经学的反弹以「回到孔子」为旗)

## 教材锚

- **冯友兰《中国哲学史》下册**(道学时代;其「理学=柏拉图式实在论」
  的读法本身就是判教史的一部分)
- **劳思光《新编中国哲学史》卷三**(宋明的「退化史观」最重的一家)
- **张岱年《中国哲学大纲》**(理气心性诸范畴的结构化梳理)
- 原典入门:朱熹《四书章句集注》选读+《近思录》;王阳明《传习录》——两本语录体,各选三分之一即可入门
