# 03 · 可构造与结构:一门「注出来的学问」有什么骨架

> **本章回答五问之四:哪些对象可构造?结构刚性从哪来?**
> **本质一句话**:中国哲学史的「可构造」不在义理层(道不可算法化),
> 而在**四个自产的数据结构**里——卦象(离散生成系统)、注疏堆栈
> (分层解释架构)、道统谱系(构造出的传承链)、学案体(前现代的
> 结构化学术数据库);把四件看清楚,「思想史能不能变成数据」
> 的边界就自己显形了。

---

## 开篇:哲学史里的「可构造」是什么意思

数学说「可构造」,意思是能写出算法或有限描述(见数学宇宙 03 章传统)。
义理——仁的体证、顿悟的境界——当然没有这种构造。
但中国哲学史是一个**特别结构化的思想传统**:它有两千多年连续的
文本层积、自发的知识管理制度(注疏)、自觉的谱系编目(学案),
甚至内嵌了一个纯离散的对象(卦象)。本章盘四件可构造物——
它们正是 04 章两条代码走廊的数据模型。

## 一、卦象:中国哲学里唯一的离散结构对象

六十四卦是汉语思想传统中**最接近数学对象**的东西——
一个六位二元符号系统:

- **生成规则**:阴爻(0)/阳爻(1)×6 位 → `2^6=64` 个状态(卦);
  三位一组得八卦,八卦两两相重得六十四卦——组合式的生成语法。
- **状态的丰富结构**:任取一卦,变 k 爻得到另一卦(汉易「卦变」
  系统就是在 64 个状态上定义变换规则);n 爻变的可能数 = C(6,n)——
  二项式系数 1,6,15,20,15,6,1 自动出现在卦变表里。
- **历史回响**:邵雍(北宋)先天六十四卦次序(坤→剥→……→乾,
  按两分递增排列)与二进制计数严格同构——莱布尼茨 1703 年见到
  传教士寄去的先天图后写信确认了这一点(他先有二进制,后有图,
  两者独立而同构——「多重发现」的经典案例)。

**三步法(卦象作为可构造对象)**:
直觉图像——一个 6 bit 的寄存器,每个状态配一段「情境说明」
(卦辞)与六条「状态迁移注释」(爻辞);
严格陈述——(卦集,变爻规则,辞的指派)构成一个带注释的
有限状态转换系统;《易传》把它哲学化(「一阴一阳之谓道」=
用最少的生成元解释最大状态空间的原则);
最小例子——用 6 个二元判据给你关心的领域建 64 格分类表
(00 章美之时刻 1 的亲历),然后问「从格 A 到格 B 要翻哪一爻」——
你就是在做「卦变」。

**边界要立刻声明**:卦系统的可构造性属于**符号层**;
「筮法的随机性与道德解释如何挂钩」(为什么这个卦应**这件事**)
属于义理层,不可构造。古代易学的伟大恰恰是拿一个可构造的符号系统
去做不可构造的释义——结构之壳与意义之肉,分清楚是第一纪律。

## 二、注疏堆栈:分层解释架构(「疏不破注」=兼容性约束)

一部经典的完整知识栈是一个**分层架构**,与计算系统的层级惊人同构:

```
   经(先秦文本)              ←  base 文本层(ABI:稳定接口)
   传(《易传》《左传》……)   ←  系统级扩展(随文成篇的框架层)
   笺/注(郑玄/王弼……)      ←  patch 层(随文释义,逐条绑定)
   疏(孔颖达《正义》……)     ←  兼容层:解经+护注(向后兼容!)
   集注/纂疏(朱熹《集注》…)|   汇编层(带义理立场的选编重写)
   ──────────────────────
   「疏不破注」= 解释层不得推翻既定注释层 → 版本兼容的明规则
   汉学(训诂优先)vs 宋学(义理优先)= 同一 source 的两个编译器之争
```

- **为什么说它是架构**:每一层有独立的语法(注贴字面、疏包圆两层、
  集注带立场),层间有明确的不变量(「注不驳经,疏不破注」)——
  与「下层稳定接口、上层自由实现」的协议栈设计是同一智慧。
  唐《五经正义》(653 颁行)以国家标准的形式把这个兼容约束制度化,
  换来注疏体系四百年的稳定复用。
- **结构刚性的来源**:不是逻辑一致性(那是公理系统的刚性),
  而是**文本权威+层级礼让**——每代新解释都必须声明自己「接着说」
  的位置(我在解谁、护谁、驳谁)。这给了中国解释史一个
  西方注释传统少见的性质:**解释的谱系自带版本号**。
- **范式更替的表现**:学风转移不是推翻,是**换层**——宋学兴起
  不是驳倒汉注,而是绕过它直接「回到经文+义理重写」(朱熹《集注》
  的操作);清代汉学复兴又用「回到汉注」反将一军。
  永远是「回滚到更早的层」,从来不删层——这就是为什么
  《十三经注疏》能作为一个多层 artifact 完整传世。

**三步法(注疏堆栈的使用)**:
直觉图像——git blame 一行代码,你会看到 patch 层层叠叠的历史,
但没有一层被 squash;
严格陈述——任一注疏文本的可定位坐标 =(所据经文位置,所释层级,
相对上层的态度:护/驳/补),三轴一给,文本在知识栈里的位置就定了;
最小例子——朱熹《论语集注》「学而时习之」条:集注引程子曰(汇纂)、
释「习」为鸟数飞(注体)、末尾圈发义理(己说)——一段之内三层齐活。

## 三、道统与学案:谱系树与结构化数据库

**道统:一条「向后构造」的传承链**。韩愈《原道》(819)发明了那条
著名的链:尧→舜→禹→汤→文武周公→孔→孟,「轲之死,不得其传焉」——
孟子之后一千年断链,暗示接链者(韩愈自任,后由宋儒接走)。
禅宗几乎同时在做同构操作(西天二十八祖→达摩东来→慧可……单传一脉,
敦煌文献证明这个线性法统是后代重构的)。
**谱系的惊人收束**:道统链上每个人之间未必有真实师承
(孟子自称「私淑」孔子,隔了一百多年)——**先有谱系的需求
(谁是正统),后有谱系的构造**。道统是思想斗争的武器,
不是历史记录:这是本家族最重要的「数据≠史实」案例。

**学案体:前现代的结构化学术数据库**。黄宗羲《明儒学案》(1676 顷)、
《宋元学案》(后人续成)发明了一种体裁,每案有固定 schema:

```
学案(学派单元)
 ├── 案主:人物小传(师承、仕履、著作)
 ├── 语录:原文选辑(带出处)
 └── 评断:案主的学术定位+与本学派的关系(「宗某某」「门户」标注)
+ 案间连线:师承表(《师说》)+学派归属判定
```

这是**人物—师承—文本—判定四字段的关系数据库**,比西方哲学史
的连续叙事更接近今天的知识图谱——本家族 04 章走廊 2(概念谱系工具)
的古代原版。为什么它出现在中国:注疏传统把「学问=继承的链条」
制度化了两千年,学案体只是把这条链显式建模。

## 四、可构造边界:什么造不了(红区)

- **红区一:义理的创造性诠释不可算法化**。「六经注我」合格的判据
  (落在经典整体语境+自家体系一致)没有机械程序——诠释的创造性
  (视域融合:理解=解释者视域与文本视域的融合)正是不可构造的部分。
  工程对策:工具止步于「把用例、版本、注疏史摆在你面前」(证据层),
  「接着讲」的那一步永远是人做的。
- **红区二:年代学自带误差棒**。《老子》成书(春秋末说/战国中期说/
  两个文本层说)、《易传》成篇跨度、诸篇真伪——本家族时间轴的
  每个先秦坐标都有置信区间。工程对策:编年数据必须带「系年依据」
  字段,断言只在密度层(统计稳健)而不在单点层(单条可错)。
- **红区三:概念史只有外壳可算**。「理」的词频曲线可算,
  「理」从「玉之纹理」到「天理」的**意义跃迁**判定不可算
  (需要训诂+义理双素养)。工程对策:词频=证据,语义=判读,
  两层分离交付(04 章红线)。
- **红区四:谱系的武器性质不可在图上消去**。道统图/学案连线是
  **立场性数据**(画线本身就是判教)——同一批人物,
  《宋元学案》与《明儒学案》的连线不同,朱熹版道统又不同。
  工程对策:谱系数据必须多版本并存(谁画的线,算谁的),
  不做合并的「权威版」。

**反直觉发现(本章铁律):学案体与道统先于数据库七百年**。
直觉认为:结构化数据管理是现代数字工具的产物。反例:
学案体(固定 schema+关系连线+判定字段)完成于 17 世纪,
道统/法统的链表结构完成于 9 世纪——**中国思想传统自发地把自己的
历史结构化了**,而且带着现代数据库都不敢有的自觉:
黄宗羲在每个学案的「评断」字段里公开声明自己的判定立场
(数据与判据并存)。对比今天把谱系图当客观事实入库的做法,
古人的数据伦理反而更先进——这是「向传统学数据设计」的活案例。

## 五、与其他分支的结构联系表

| 结构动词 | 本家族形态 | 邻居家的形态 |
|---------|----------|-------------|
| 离散生成系统 | 卦象(2^6 状态+变爻规则) | 数学宇宙:群/格(严格代数结构);卦象是有注释无定理的系统 |
| 分层架构 | 经-注-疏-正义(疏不破注) | 计算机体系:协议栈(层间稳定接口);《十三经注疏》=多层 artifact |
| 版本与兼容 | 注不驳经、疏不破注、学风=换层 | 软件工程:语义版本/回滚;汉宋之争=编译器之争 |
| 谱系树 | 道统链/师承表(立场性数据) | 数学宇宙:导师谱系(Mathematics Genealogy)——那边是事实链,这边兼是判教链 |
| 结构化个案库 | 学案体(案主-语录-评断) | 数据库:实体-证据-注记三字段;知识图谱的先声 |
| 概念档案 | 训诂/字义疏证(用例统计) | NLP:词义消歧/语义漂移检测(04 章走廊 2) |

## ✍️ 练习

1. ✋ 给你领域的一门「经典」(如《人月神话》)画注疏堆栈:
   原文层、权威注层、争议层各是什么?「疏不破注」在你的领域
   对应哪条潜规则?
2. ✋ 画两条道统:你们领域的「正统链」按官方叙事一条、
   按你的独立判断一条——两条的差异处,就是谱系的武器性质显形处。
3. 🐍 跑 `experiments/00_pre_qin_timeline.py` 后,把 TIMELINE 里
   任意五条改成「系年依据」缺失的模糊条目,观察断言 A 的余量
   ——密度断言为什么对单条错位稳健?(红区二的工程对策)
4. ✋ 用学案体 schema 给你团队的知识写一「案」:案主(谁的洞见)、
   语录(原话与出处)、评断(定位与局限)——体验一次
   「数据与判据并存」的17世纪数据伦理。

## 📌 收束 + 🧭 新眼睛(认知升维)

**结构之眼**:看到任何思想文本,先找三件事——它接在哪个堆栈的
哪一层(版本坐标)?它画的谱系线是谁画的(立场坐标)?
它的判定字段与证据字段分开了吗(数据伦理)?
三层坐标一定,「接着说」的位置就合法了。
