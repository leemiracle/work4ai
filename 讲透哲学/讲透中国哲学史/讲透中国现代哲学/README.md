# 讲透中国现代哲学 · 学科的诞生:哲学史书写与新儒家的创造

> **定位句**:这支负责**「中国哲学」的自我命名**——
> 胡适冯友兰用西方体裁把三千年的书重新写成「中国哲学史」,
> 熊十力金岳霖贺麟则反过来用中国范畴做当代哲学创造:
> 书写传统与创造哲学,同一枚硬币的两面。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(中国现代哲学,1919-1949,余波至今)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:1919(胡适《中国哲学史大纲》)至 1949(两岸三地格局),
  方法论余波至今。胡适大纲(1919)、科玄论战(1923)、
  冯友兰《中国哲学史》两卷(1931/1934)、熊十力《新唯识论》语体本(1940)、
  金岳霖《论道》(1940)、冯友兰《新原人》(1943)、
  郭沫若《十批判书》(1945)、贺麟《当代中国哲学》(1947)。
- **因什么问题**:①体裁问题——「哲学史」是西方舶来体裁,
  用它筛中国材料,筛子与材料的磨合即学科史;
  ②科玄论战(1923):科学能解决人生观吗?——
  中西哲学在现代中国的第一次正面碰撞;
  ③「照着讲还是接着讲」(冯友兰):整理国故与哲学创造的分岔,
  新儒家选择接着讲(熊十力「体用不二」是典范)。

## 核心问题

**已解决**:
- 学科典范三母版:胡适(证明的方法+系统观念)、
  冯友兰(完整体裁+子学/经学分期)、张岱年《中国哲学大纲》(范畴为纲)
  ——此后所有教科书都是三者的组合(家族 00 章 §三)
- 唯物史观读诸子的方法论样板(郭沫若/侯外庐):
  思想史的社会语境化,与哲学宇宙的马克思主义哲学家族互鉴
- 「照着讲/接着讲」的自觉:哲学史书写与哲学创造的分工命名

**未解决/深水区**:
- 「中国哲学合法性之争」的当代形态(2000 年代大讨论):
  以西方体裁写中国思想的合法性与其替代方案(汉语哲学/
  以中国义理自为纲)——元问题至今在场(家族 01 章主线 A/C)
- 1949 后多谱系并立的书写:大陆、港台新儒家(牟宗三《心体与性体》
  1968-69)、英语世界(陈荣捷《中国哲学文献选编》)的
  三地叙事如何整合——「一部中国哲学史还是多部」?
- 现代支的时间下限:GB/T 定在 1949,但学科自身的当代史
  在续写(大陆儒学哲学复兴即最新章,01 章主线 A)

## ✨ 这支最美的一个事实

**科玄论战(1923)**:张君劢(柏格森系)说科学无论如何发达,
也解决不了人生观(自由意志/价值/审美「无论如何不能适用科学方法」);
丁文江(马赫系)回击「玄学鬼」,双方连同梁启超胡适陈独秀全部下场。
论战没有赢家,却把此后一百年中国思想的全部坐标轴
(科学 vs 人文/自由意志 vs 决定论/西学 vs 中学/启蒙 vs 保守)
在一场辩论里**全部竖了起来**——今天每一场
「AI 能不能有价值观」的争论,都还是这场论战的换装重演。

## 假设与依赖

- 「现代=西化」叙事的简化:新儒家的创造(熊十力/金岳霖)证明

- 1949 切线的代价:港台与海外线被推到「余波」位置,
  其学术体量(牟宗三/唐君毅/徐复观)与地位不成比例
  (GB/T 体例约束,内节声明补偿)
