# 讲透隋唐五代哲学 · 佛学中国化:禅宗与道统的双重诞生

> **定位句**:这支负责**外来思想被消化的完成式**——
> 佛教经格义、判教、创宗三步,最终在禅宗完成中国化:
> 印度佛教的庞大体系被激进简化为「直指人心」;
> 同期韩愈发明「道统」,儒学的反攻也在此发令。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(隋唐五代哲学)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:589(隋统一)至 960(北宋建立)。玄奘译场(645)、
  《五经正义》(653)、《坛经》(713 顷)、马祖日用禅(780)、
  韩愈《原道》(819)、李翱《复性书》(830)、宗密判教(841)。
- **因什么问题**:①佛教的体系优势——心性论与轮回安顿
  是儒学当时没有的装备,如何回应?
  ②判教的内需——传入的经典互相矛盾(空/有/顿/渐),
  需要一个消化系统给全部经典排座次;
  ③科举与官僚制——儒学靠制度存续,佛教靠寺院经济扩张,
  政教双方的摩擦(三武灭佛)要求理论边界。

## 核心问题

**已解决**:
- 佛教中国化的技术路线定型:格义(借玄学词汇)→判教(消化矛盾)
  →创宗(天台/华严/禅/净土——中国自己的宗派形态)
- 禅宗的范式:不立文字+顿悟+农禅并重——
  一个不依赖经院体系、可自复制的思想-组织复合体
- 儒学复兴的纲领文件:韩愈《原道》道统说+李翱《复性书》心性化——
  宋明理学的两份出生证明

**未解决/深水区**:
- 唯识宗速亡之谜:最忠实的印度哲学(玄奘/窥基)两三代即衰——
  忠实与本土化的张力,思想传播史的头号案例
- 《坛经》文本层积(敦煌本/惠昕本/契嵩本/宗宝本)与慧能形象的建构——
  「禅宗史是层层写成的」到什么程度?
- 「理学源于禅」争议:李翱—《起信论》—禅的链条多硬?
  (宋元明清支的最大方法论前史)

## ✨ 这支最美的一个事实

**「一阐提皆得成佛」的孤明先发**:竺道生(其实是东晋末,本支前夜)在
《涅槃经》全本未至、旧译经文说一阐提(断善根者)不能成佛时,
仅凭「众生皆有佛性」的义理必然性断言:一阐提也能成佛——
被守旧僧团逐出建业。数年后昙无谶译《涅槃经》后至,
经文果然说「一阐提皆有佛性」,道生被迎回,尊为「涅槃圣」。
**一个哲学家用体系的融贯性赌赢了尚在运输途中的经文**——
理性演绎击败文本教条的名场面,也是判教精神的极致。

## 假设与依赖

- 「隋唐佛学=中国哲学高峰期」的叙事有立场:这是清末民初
  (杨文会金陵刻经处一系)重建的谱系,宋明儒者眼里它是异端时代
- 禅宗史料的灯史/语录经过宗派立场层层改写(谱系的武器性质,
  家族 03 章 §三)——单文本不可作史实直接用
- 上游依赖魏晋支(格义的开局);下游喂养宋元明清支
  (理学 = 儒学装上佛教心性论的引擎)
