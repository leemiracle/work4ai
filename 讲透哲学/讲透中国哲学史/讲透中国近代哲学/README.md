# 讲透中国近代哲学 · 西学东渐:经学解体与进化论入华

> **定位句**:这支负责**传统思想的危机管理**——
> 帝国的军事失败变成哲学的合法性危机:
> 经学的最后两支军队(今文改制论/考据诸子学)冲进战场,
> 进化论(「物竞天择」)则趁乱接管了所有人的思想底盘。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(中国近代哲学,1840-1919)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:1840(鸦片战争)至 1919(五四运动)。
  魏源《海国图志》(1842)、李善兰译业(1859)、
  康有为《新学伪经考》(1891)/《孔子改制考》(1897)、
  严复《天演论》(1898)、张之洞「中体西用」(1898)、
  章太炎诸子学(1904)、梁启超学术史叙事(1902)、
  陈独秀《青年杂志》(1915)。
- **因什么问题**:①富强之问——经学答不了「为什么挨打」,
  「师夷长技」从器物(洋务)追到制度(变法)再追到文化(新文化);
  ②经典权威的最后透支——康有为用考据学的武器证明古文经全是伪作,
  又把孔子改造成改制教主:救经典的方法杀死了经典;
  ③思想底盘更换——「天演」范式(竞争/进步/适者生存)
  一次性替换「三代/循环/华夷」的旧宇宙论。

## 核心问题

**已解决**:
- 西学名词的汉化体系(李善兰「代数/微分」、严复「天演/逻辑/群学」)——
  范畴翻译的工程在此一次性完成大半(格义 2.0 的词典层)
- 传统资源的政治化改写模板:托古改制(康有为路线)与
  以诸子反经学(章太炎路线)——两条「从内部拆解」的路线图
- 「中体西用」公式的提出与失效:分层消化外来文明的
  一次国家级实验及其失败记录

**未解决/深水区**:
- 严复译名的得失:在天演/群学/名学 vs 进化/社会学/逻辑学的
  词典竞争中,败者(严译)输在哪(家族 02 章范畴对译的案例库)
- 近代思想史的分期争议:「1840 起点」是政治事件切哲学史,
  思想的近代化是否早于战争(乾嘉的自我批判算不算近代性)?
- 五四「全盘反传统」的重估:是思想断裂,还是传统的
  另一种转生(现代支的直接前史)?

## ✨ 这支最美的一个事实

**《天演论》的翻译政治**:严复译赫胥黎,却在按语里
用斯宾塞纠正赫胥黎(原著主张伦理过程对抗自然过程,
译本读起来更像「天行人治,同归天演」的救亡动员);
「物竞天择,适者生存」八个字不是原文的直译,
是**为汉语思想界量身定制的动员令**——
一本书(译作)成为几代人的世界观来源(胡适取名「适」、
陈炯明字「竞存」,都是这本译名的婴儿)。
翻译即创造:格义传统的近代巅峰,也是它的绝唱
(此后白话文时代,翻译不再需要古典锻造)。

## 假设与依赖

- 「冲击—回应」叙事(费正清系)的代价:把近代中国思想
  写成对西方的单向应答,忽略内生脉络(今文经学的内在演化);
  「在中国发现历史」的修正与本支共存(语境侧归历史学宇宙)
- 进化论接受的简化叙事:斯宾塞/赫胥黎/社会达尔文主义
  在汉语语境的混合面貌,需逐文本核对(家族 02 章红区三)
- 上游依赖宋元明清支(考据学的兵器库);下游喂养现代支
  (新文化运动直接接生学科化的中国哲学)
