# 讲透秦汉哲学 · 经学的建立:儒学从百家之一变成帝国的形上学

> **定位句**:这支负责**思想与帝国的第一次合谋**——
> 大一统需要统一的地基,董仲舒把儒学改造成天人感应的宇宙论,
> 经学从此既是学问又是制度;王充站在对面证明批判传统从未死透。
> GB/T 13745 72020 中国哲学史 · GB/T 三级(秦汉哲学)。家族:[讲透中国哲学史](../README.md)

## 诞生

- **谁/何时**:前 221(秦统一)至 220(汉亡)。关键节点:
  前 136 董仲舒对策、罢黜百家表章六经;前 51 石渠阁会议(经义国家标准);
  79 白虎观会议(谶纬法典化);80 顷王充《论衡》。
- **因什么问题**:①帝国正当性——谁替皇权提供宇宙论辩护?
  ②思想统一——焚书(暴力方案,失败)之后,经学(制度方案)接手;
  ③文本权威——劫余经文的真伪与师法(今文口授 vs 古文壁藏)。
- **格局**:今文经学(微言大义,政治神学)vs 古文经学(文献考据)
  ——这对张力贯穿两千年,清代考据学与康有为改制论是它的两次回声。

## 核心问题

**已解决**:
- 经学体系的建制形态(师法/家法/章句+国家会议定标准)——
  「经典+注释+官学」的知识制度在此定型
- 天人感应的完整宇宙论(阴阳五行×人事灾异)——
  中国思想史上最完整的「关联式宇宙论」样本
- 批判的武器库:王充「疾虚妄」以元气自然论逐条清算虚妄
  (论证形态=中国古代的证伪精神高点)

**未解决/深水区**:
- 董仲舒哲学的评价分歧:哲学体系还是政治神学?
  (「屈民而伸君,屈君而伸天」的双重结构如何定性)
- 谶纬的定位:愚昧的副产品,还是经学内在逻辑的极端化?
- 王充为何后继无人——批判理性为什么不成传统?

## ✨ 这支最美的一个事实

**王充的「效验」**:《论衡》要求每个论断给出可查的效验
(「事有证验,以效实然」)——一位东汉学者用近乎证伪的姿势
对当时全部流行信念(雷是天怒/鬼神感应/虚言夸说)逐条开刀,
且孤身一人、绝意仕途地写完八十五篇。
批判理性在不利于它的制度环境里依然长出来了——这是「思想生态」
比「思想正确」更重要的头号证据。

## 假设与依赖

- 「儒学国教化」叙事有简化:汉代实际是儒法合流+阴阳杂糅
  (霸王道杂之),「独尊」是经学地盘独尊,不是思想内容独占
- 宇宙论类比(人副天数)的代价:解释力强、可检验性弱——
  关联式思维的得失账单(家族 02 章表达力表的地层来源)
- 上游依赖先秦支(儒家被改造的对象);下游喂养魏晋支
  (名教危机正是经学谶纬化的反动)
