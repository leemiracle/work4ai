# 讲透十七十八世纪欧洲哲学 · 方法怀疑与社会契约:理性对自然与国家同时立法

> **定位句**:这支负责"**理性的独立宣言与双重立法**"——1600-1780,
> 理性不再注释权威,而是从头重建:对自然立**方法**之律(培根/笛卡尔),
> 对国家立**契约**之律(霍布斯/洛克/卢梭),对心灵立**经验**之律(洛克/休谟)——
> 最后休谟把三张立法书一起送上了审判席,判决书由康德来写(下一支)。
> GB/T 13745 72030 西方哲学史 · 三级。家族:[讲透西方哲学史](../README.md)

## 诞生

- **谁/何时**:培根《新工具》(1620)与笛卡尔《方法谈》(1637)双开国;
  伽利略审判(1633)让"自然之书的数学语言"(1623《试金者》)带上政治压力;
  1687 牛顿《原理》让机械论世界观封王;1739 休谟引爆因果危机。
- **因什么问题**:①宗教战争(1618-48)之后:共同基础不能再是教派,
  必须是**人人可复查的方法**——确定性从启示搬到理性;
  ②新科学要哲学地基:什么保证数学化的自然知识为真?
  ③国家正当性:不再来自君权神授(菲尔默),来自契约(洛克《政府论》1690
  的直接论战对象)。

## 核心问题

**已解决**:
- 方法论自觉:普遍怀疑/归纳程序/观念来源三分(天赋/感觉/反思)成为
  后世一切"知识论"的默认框架
- 政治哲学词汇表定型:自然状态/自然权利/社会契约/分权/公意——
  现代政治的全部合法性语言在本支铸成
- "是-应当"鸿沟(休谟)被明确指出——此后任何伦理学都得先过这条沟

**未解决/深水区**:
- 身心问题:笛卡尔交互论的原始困境至今无共识版本(当代心灵哲学仍在还债)
- 归纳的证成:休谟问题两百年无解,波普尔"绕开"方案争议未消
- 理性主义 vs 经验主义的分派叙事本身被史学界持续拆解
  (斯宾诺莎/莱布尼茨根本不在同一张棋盘上)

## ✨ 这支最美的一个事实

**莱布尼茨的"最好可能世界"一石三鸟**:上帝全能且善→此世是所有可能世界中
最好的;而"最好"要求世界服从**可计算的普遍规律**(充足理由律)——
神学动机、形而上学与科学规律性被同一个概念焊住。
《神义论》(1710)与微积分(1684 发表)是**同一个头脑的同一套直觉**
(数学宇宙的莱布尼茨与本支的莱布尼茨互为镜像,家族 00 章 §8)。
里斯本地震(1755)让伏尔泰用小说砸了这套乐观主义——哲学史罕见的
**地质事件改写哲学议程**的案例。
