# 讲透德国古典哲学 · 先验转向与体系之巅:理性认出自己是立法者

> **定位句**:这支负责"**批判与体系**"——1781-1831 五十年,
> 康德把理性送上自己的法庭(对象绕主体转),费希特把自我做成发动机,
> 谢林打开自然,黑格尔把整部哲学史吸收进逻辑——
> 西方哲学史在这个高点上**认出了自己是自己的历史**。
> GB/T 13745 72030 西方哲学史 · 三级。家族:[讲透西方哲学史](../README.md)

## 诞生

- **谁/何时**:康德《纯粹理性批判》(1781,哥白尼革命 1787 B 版定型);
  费希特《知识学》(1794);谢林《自然哲学观念》(1797);
  黑格尔《精神现象学》(1807)至卒(1831)。
- **因什么问题**:①休谟把因果还原为习惯——"独断论的迷梦"被打破,
  形而上学需要**自我辩护**而非自我扩张;②二律背反:理性对超验问题
  正反都能证明——问题出在范畴的**适用范围**;③法国大革命(1789)与
  虔敬派背景:自由如何既是真的又是可服从规律的(自律问题的时代现场)。

## 核心问题

**已解决**:
- 先验方法:问"经验如何可能"替代"对象是什么"——认识论的重心转移
  被永久制度化(现象学与分析哲学都以不同方式回应它)
- 自由的第二定位:自由不在现象界(那里一切有因果),在实践理性的
  自我立法——道德法则的存在本身就是自由的证据
- 体系形式的可能性证明:哲学可以做成全贯通的整体(黑格尔《哲学全书》
  的工程成就本身即是答案)

**未解决/深水区**:
- 物自体的地位:不可知剩余物还是范畴误用(两派至今未合)
- "形式伦理 vs 伦理生活"(康德 vs 黑格尔的善之争)——2024 年首部
  综合研究出版,争论刚进入新回合(家族 01 章主线 C)
- 黑格尔"逻辑学=本体论"纲领的可信度:Karen Ng《Hegel's Concept of Life》
  (方向锚)代表的"生命"读法仍在扩张影响,未成定论

## ✨ 这支最美的一个事实

**"休谟把我从独断论的迷梦中唤醒"**:康德自述,因果怀疑不是敌人而是闹钟——
一个苏格兰人的怀疑,直接制造了德国五十年的哲学大爆发。
哲学史的接力在这里显形得毫无遮掩:**上一支的危机=本支的发动机**
(家族 00 章 §4 三次危机表的最强一例)。

## 假设与依赖

- **体系假设**:真理是全体(黑格尔)——买到无与伦比的解释纵深,
  付出"体系闭合"的傲慢(1841 年后每一种新哲学都以反黑格尔起家)
- **先验框架恒定假设**:范畴表对一切理性者恒定——人类学的可变性
  (尼采以降)与认知科学的可塑性都在磨这条假设
- 上游:[讲透十七十八世纪欧洲哲学](../讲透十七十八世纪欧洲哲学/README.md)
  (休谟危机+莱布尼茨遗产);下游:分三路——
  叔本华-尼采-现象学线归**现代外国哲学家族(72035,同波建设中,文字提及)**;
  马克思的倒转归**马克思主义哲学家族(72010,同波兄弟)**;
