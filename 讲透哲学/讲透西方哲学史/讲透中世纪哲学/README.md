# 讲透中世纪哲学 · 信仰与理性的千年谈判:论证基础设施的建成期

> **定位句**:这支负责"**理性与启示的分权谈判**"——
> 从奥古斯丁(400 前后)到库萨的尼古拉(1440),哲学在神学屋顶下
> 干成了两件大事:建成欧洲第一个**论证质检流水线**(大学 quaestio 制度),
> 并把亚里士多德全集变成公共课程——近代哲学的起义对象,正是本支的遗产。
> GB/T 13745 72030 西方哲学史 · 三级。家族:[讲透西方哲学史](../README.md)

## 诞生

- **谁/何时**:奥古斯丁(387 皈依,《上帝之城》413 开笔)定下"信仰寻求理解"
  的总议程;波爱修斯(卒 524)传下逻辑文本;1100-1300 大翻译运动+大学建制
  让经院哲学成为**泛欧论证工业**。
- **因什么问题**:①启示真理与理性论证是什么关系(和谐/分居/服务)?
  ②共相(普遍概念)实在吗——唯名论 vs 实在论贯穿全程;
  ③1277 大谴责之后:哲学家**有权**推出哪些结论——论证的训诫边界首次成文。

## 核心问题

**已解决**:
- 经院论证体制:quaestio 正反对峙/obligatio 论辩规则/注释层级——
  论证质量第一次被**制度性质检**(家族 01 章主线 B 的再评价对象)
- 词项逻辑精细化:指代理论(suppositio)的语义学,精密程度超前五百年
- 本体论论证(安瑟尔谟 1077)与"存在是不是谓词"问题的定型

**未解决/深水区**:
- 范围重划(01 章主线 A):拜占庭/伊斯兰/犹太哲学进入正典的整合仍在进行
- 唯名论遗产:1277 后的"两位神圣全能者"研究(奥卡姆的上帝)与近代
  机械论的因果谱系,学术争论未定
- 经院逻辑与现代形式逻辑的**对接翻译**(术语对齐)尚无标准表

## ✨ 这支最美的一个事实

**本体论论证:一段十行的话,吵了一千年**——"上帝=无可设想更伟大者;
存在于心中又存在于实在中更伟大;故上帝存在。"安瑟尔谟 1077 年写下,
高尼罗立即反驳,阿奎那换路,康德断"存在非谓词",20 世纪分析哲学
(普兰丁格的模态版)还在打——**一个论证的接受史本身就是一部哲学史**
(家族 03 章"论证重构"的第一教学案例)。
