# 西方哲学史思维技能卡(讲透西方哲学史 · GB/T 72030)

## ① 何时用此分支(问题特征触发词)

看到这些词,先来本家族:

- **分期类**:前苏格拉底、米利都学派、苏格拉底转向、柏拉图理念论、
  亚里士多德实体、希腊化、斯多亚、经院哲学、文艺复兴人文主义、
  近代理性主义 vs 经验主义、启蒙运动、德国古典哲学、先验哲学
- **概念户口类**:本原(archē)、逻各斯、理念、实体(ousia/substantia)、
  四因、共相与唯名论、本体论论证、第一性质/第二性质、
  天赋观念、白板、单子、物自体、先验/超验、二律背反、绝对精神、扬弃
- **论证类**:安瑟尔谟论证、笛卡尔怀疑、我思、休谟因果怀疑、
  是与应当、康德哥白尼革命、定言命令、主奴辩证法
- **方法类**:概念谱系、思想史分期、语境解读、正典(canon)、
  辉格史观、问题史、接受史、术语翻译史
- **当代接口类**:知识本体、范畴表设计、分类体系审查、
  "这个分类是谁定的"、数字人文、概念史计算

## ② 核心思维模式(这个分支怎么想问题)

1. **问法眼**:每个断言背后有一个问法,问法有生日——
   见"本质/合法性"类大词,先问这个问法属于哪个世纪(问法比答案更能定位人)
2. **接力眼**:没有问题凭空出现——找上游(休谟的因果是四因的残局,
   康德的先验是休谟的清盘);理解任何立场的第一动作=找它继承谁、反转谁
3. **论证重构**:把任何文本切成"前提-推理-结论"标准形,
   分开评:前提真吗?推理有效吗?(多数"哲学吵架"其实是两边在不同环节失误)
4. **语境眼**:"永恒问题"多是论战的化石——先问这个文本在跟谁吵架
   (剑桥学派纪律),再问它说了什么
5. **翻译链眼**:关键术语永远带原文;同一词在不同世纪是不同户口
   (理念:柏拉图≠洛克≠黑格尔);跨时代直接等同是语言事故
6. **范畴自审**:自己用的分类(本体论/认识论/伦理学三分法等)也是历史产品
   ——分类有生日与利益,先审自己的格子再装别人

## ④ 常见误区与禁忌

- **辉格史观**:把历史读成"通往当代正确答案的路线"——
  中世纪被跳过、败者被除名;解毒=问"当时的人在争什么"
- **进步错觉**:哲学没有数学的淘汰机制;同一立场两千年可满血复活
  (斯多亚→认知行为疗法)——"哲学史证明 X 越来越对"是范畴错误
- **黑暗中世纪神话**:经院逻辑的精密(词项指代理论、强制论辩)超前五百年;
  "黑暗"是文艺复兴人的营销修辞,史学界已废弃
- **术语跨代混用**:"黑格尔的理念=柏拉图的理念"——同词不同脑(见②-5)
- **残篇当原典**:前苏格拉底全部是二手转述,引"泰勒斯说"必须注明
  是谁转述的——你引用的永远是某人的泰勒斯
- **重构即原文**:论证标准形是删减产品,修辞与语境被删掉了——
  标准形必须回链原文位置,否则是"哲学提要"不是哲学史
- **数字人文越界**:共现≠影响,词频≠重要性,进步不可拟合;
  机器只提候选,认定边永远人裁(04 章红色区)

| 症状像西方哲学史,其实是… | 判别 |

| 1879 后的形式逻辑(弗雷格以后) | → [../../讲透数学/讲透数理逻辑/](../../讲透数学/讲透数理逻辑/);本家族管三段论→莱布尼茨的哲学史侧 |
