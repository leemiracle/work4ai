> × **两次大转向**(苏格拉底:从自然到人事;康德:从对象到主体)。
> 俄国哲学支是这条线的**东方支流**——拜占庭神学与德国唯心论在俄语世界的合流,时间上越出
> 1831 但血统上仍是这段谱系的嗣子,GB/T 也把它划在"西方哲学史"名下。

## 三、长尾归属与兜底(穷尽声明)

- **现当代分流声明**:黑格尔(卒 1831)之后的西方哲学——叔本华、克尔凯郭尔、尼采、
  现象学、存在主义、解释学、分析哲学——一律归**现代外国哲学家族(72035,同波建设中,文字提及)**;
  本家族的下游边界=1831。两家的接头货:康德研究(当代康德学两边都做,本家族管历史语境,
  现代外哲管当代争论)。
- **逻辑史的断点声明**:亚里士多德三段论→中世纪词项逻辑→莱布尼茨普遍文字→弗雷格概念文字,
  这条线在本家族各支内节讲其**哲学史侧**;1879 弗雷格之后的形式逻辑史归
  [../../讲透数学/讲透数理逻辑/](../../讲透数学/讲透数理逻辑/)(GB/T 明文 72040 数理逻辑三级归入 11014)——
  **逻辑的诞生地在本家族,逻辑的成年礼在数学宇宙**。
- **西方哲学史其他学科**(GB/T 三级兜底类)→ 不设系列;零散条目(如犹太哲学史的散段、
  拜占庭哲学、西班牙晚期经院)按近亲归入各支内节,不另起炉灶。
- 俄国哲学支内部:俄国马克思主义(普列汉诺夫、列宁《唯物主义与经验批判主义》)与
  马克思主义哲学家族(72010)共管,本支管其俄国语境。

- **零门槛**:本家族是哲学宇宙最好的入口——不预设任何哲学词汇;
  它本身就是这些词汇的**出生登记处**("理念""实体""先验"都在这里有第一现场)。
- 推荐看法:先读 00 章的六次奠基建立地图 → 按兴趣挑支读宪法 README →
