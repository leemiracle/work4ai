# 讲透文艺复兴时期哲学 · 古书复活与人的尊严:旧语法学新科学

> **定位句**:这支负责"**过渡带的哲学**"——1453-1600,人道主义者用**更好的语文学**
> 复活了古代(一半靠批判,一半靠想象);大学里的亚里士多德主义变成了
> 早期近代科学的**概念车间**。近代哲学不是从虚无起义,是从本支的课堂上起义。
> GB/T 13745 72030 西方哲学史 · 三级。家族:[讲透西方哲学史](../README.md)

## 诞生

- **谁/何时**:费奇诺主持卡雷吉学园(1462,美第奇资助)开启柏拉图复兴;
  庞波纳齐《论灵魂不朽》之争(1516)引爆亚里士多德主义自然主义;
  蒙田《随笔集》(1580)把怀疑论带回生活。
- **因什么问题**:①拜占庭陷落(1453)与希腊手稿西流——**一手文本**取代
  中世纪转译的权威链;②"人"的地位:皮科《论人的尊严》(1486)——
  人没有固定本质,人是自我塑造者;③宗教改革(1517)摧毁统一裁判所,
  信仰-理性谈判被迫重启(自由意志之争=第一场全国级哲学论战)。

## 核心问题

**已解决**:
- 语文学成为批判武器:回溯希腊原文(而非拉丁转译)重定经典
- 亚里士多德主义内部分派地图(亚历山大主义/阿威罗伊主义/蒂米斯塔斯)
  被思想史研究澄清——不再是"旧秩序残余"一块铁板(SEP 持续更新,见 01 章主线 D)
- "黑暗中世纪"修辞的专利登记:彼特拉克们的营销,被史学界整体废弃

**未解决/深水区**:
- 文艺复兴哲学的**独立地盘**有多大:是独立章节还是近代的序曲?
  (学界仍在争——本支的建制正当性本身就是活的学术问题)
- "复兴的古代"与"历史的古代"的差距测绘:费奇诺的柏拉图掺了多少普罗提诺
  (家族 00 章反直觉 3 的正面战场)

## ✨ 这支最美的一个事实

**皮科的 900 题(1486)**:一个 23 岁的年轻人宣布要在罗马 defended 九百条
论题——把柏拉图、亚里士多德、卡巴拉、阿威罗伊**全部放进同一个论证场**,
教皇判其中十三条异端,辩论没开成,宣言《论人的尊严》却成了
"人的尊严"的第一份现代宣言:**哲学第一次为"并列所有立场"本身辩护**。

- **"复兴"假设**:回到源头=回到真实——实际上源头是按当下问题重构的
