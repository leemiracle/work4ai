# 讲透逻辑史 · 三次发明与两次转向——推理语法的中外编年

> **定位句**:这支负责"**推理的语法是怎么被发明和改写的**"——
> 古希腊(亚里士多德/斯多亚)、先秦(墨家名辩)、古印度(因明)
> 三次平行发明,中世纪的工程化,密尔的归纳加盟,1879 弗雷格的分家。
> 它是全家族的"户口登记处":每个逻辑概念在这里有出生证明。
> GB/T 13745 72040 逻辑学 · 三级。家族:[讲透逻辑学](../README.md)

## 诞生

- **谁/何时**:亚里士多德《工具论》(前 350 前后)立三段论;
  墨家《墨经》(前 4-前 3 世纪)立"名实故理类"与"悖"论;
  因明从足目《正理经》到陈那三支改法(2-6 世纪)。
- **因什么问题**:说服的效力从哪来——三家同问,答案同构:
  把"讲得好"变成"形状对"(三段论/三支/辩的法则),
  使论证可检验、可教学、可裁决。

## 核心问题

**已解决**:
- 三大传统的结构对照:三段论(大前提-小前提-结论)与因明三支
  (宗-因-喻)**结构同源而方向相反**(先结论后理由);
  墨家"彼"之"不俱当"与矛盾律同胚
- 中世纪的命名工程:19 个有效式的拉丁 mnemonic
  (Barbara 的元音=A-A-A)——记忆术反哺学科本体

**未解决/深水区**:
- 斯多亚命题逻辑的"失传与复原"(19 世纪后才被重估)——
  逻辑史的进步叙事是否辉格?
- 墨家名辩的断绝与清代复活:中断的传统如何被现代术语
  "反向翻译"而不失真——墨学与现代逻辑的对齐表无标准版

## ✨ 这支最美的一个事实

**三个文明没有商量,却发明了同一样东西**——"推理有形状,形状可判定"。
亚里士多德的 Barbara、因明的三支、墨家的"效"(以法为效,中效则是),
都在说:论证的对错不由人裁,由**式**裁。平行发明是最强的
"必然性证据":逻辑不是希腊的地方文化,是理性文明的收敛点
(家族 00 章 §一开篇故事在本支展开为全编年)。
