# 讲透非形式逻辑与论证理论 · 野外理赔部——谬误、型式、论辩

> **定位句**:这支负责"**自然语言论证的实际评价**"——谬误理论、
> 论证型式(scheme)+批判性问题、论辩术、论证图。
> 1970s 起家(反对形式逻辑教材垄断"逻辑"课),
> 如今是本学科**最大的增长极**与最大工程出口(AI 推理评估,家族 01 章主线 D)。
> GB/T 13745 72040 逻辑学 · 三级「逻辑学其他学科」**槽位改造**:
> GB/T 2009 未给 informal logic 单设条目,本支以「其他」槽位改造立支,
> 接续 1970s 以来的 informal logic 传统(家族 README §三改造声明)。
> 家族:[讲透逻辑学](../README.md)

## 诞生

- **谁/何时**:1970s 温莎大学《Informal Logic》创刊(1978)+
  Johnson-Blair《Logical Self-Defense》发难;Toulmin《论证的使用》(1958)
  备好新框架(主张-根据-正当理由-支援-限定词-反驳)。
- **因什么问题**:好论证 ≠ 有效式——前提可接受性、举证义务、
  语境恰当性全在形式有效性之外;"逻辑课教的用不上"——本支为落差而生。

## 核心问题

**已解决**:
- 谬误论升级:罪名清单→型式+批判性问题(每个经典谬误都是
  某合法型式的堕落形态——家族 03 章)
- 评价三标准(RAS):相干×可接受×充分——替代"有效性"独裁的验收单;
  Toulmin 六件套:比标准形多出限定词与反驳位

**未解决/深水区**:
- **particularism vs generalism**(家族 01 章主线 A,2024 年
  Informal Logic/LLP 专题交锋):论证评价有无普遍标准,决定本支能否工程化
- 型式的边界:何时算合法使用、何时算堕落,CQ 敲到多细算够——"开放纹理"

## ✨ 这支最美的一个事实

**"诉诸权威"不是谬误,是一张带免责条款的保单**——型式论一翻案:
专家证言是**可辩护的归纳型式**,效力随批判性问题逐项衰减
(专家对口吗?同行一致吗?有利害吗?)。谬误不是坏词,
是**好型式的坏用法**;指认谬误从此是出示体检报告,不是扣帽子。
