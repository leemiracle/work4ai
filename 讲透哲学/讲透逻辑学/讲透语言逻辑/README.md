# 讲透语言逻辑 · 自然语言的逻辑现场——预设、蕴涵、言语行为

> **定位句**:这支负责"**不讲理的自然语言里藏的逻辑**"——
> 预设("你几点到的?"预设你到了)、会话蕴涵("他字写得好"
> 涵着他别的不好)、言语行为(说"保证"就是在做事)、
> 量词辖域("每个老师追一部剧")。形式逻辑压掉的那一半语境,
> 在这支被一寸寸找回来。
> GB/T 13745 72040 逻辑学 · 三级。家族:[讲透逻辑学](../README.md)

## 诞生

- **谁/何时**:弗雷格与罗素的摹状词分析(1905)开题;
  斯特劳森 1950 反罗素(预设不是断言);奥斯汀《如何以言行事》(1962)
  与塞尔立言语行为理论;格赖斯 1967 讲座立会话蕴涵
  (合作原则与四准则)。
- **因什么问题**:形式逻辑翻译自然语言时处处碰壁——
  "当今法国国王是秃头"是真是假?问句、命令句、暗示
  全都塞不进真值表。语言逻辑承认:**语用力与语义力是两种力**。

## 核心问题

**已解决**:
- 预设的触发词清单与投射规律(复合句的预设怎么合并);
  蕴涵取消测试("他字写得好,而且人也好"取消涵着义——
  会话蕴涵可取消,逻辑蕴涵不可)
- 言语行为的分类学(断言/指令/承诺/表达/宣告五式)

**未解决/深水区**:
- 预设的语义说 vs 语用说:预设是真值条件的一部分还是语境适应项?
- 规范语句的逻辑("应当"的道义逻辑)与规范词的对接
  ——法学侧"法律逻辑学"的通用理论面(归入声明,文字提及)

## ✨ 这支最美的一个事实

**"说了的"与"涵着的"是两本账——格赖斯的发现让逻辑学长出第二层**。
"他字写得好"逻辑上不谈别的;会话上涵着"别的平平"。
一本账查真值,一本账查合作——两本账分开记,"违反准则的
巧妙利用"(反讽/暗示/外交辞令)才第一次有了严格的描述工具。
实质蕴涵怪论(家族 00 章反直觉 1)的日常困惑,大半是**把两本账记混了**。

  恰好测试这条假设的边界
