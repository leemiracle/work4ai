# 讲透归纳逻辑 · 从案例到置信——密尔五法与贝叶斯的两百年

> **定位句**:这支负责"**不保证必然的推理怎么管好自己**"——
> 密尔五法(求同/求异/求同求异并用/共变/剩余)给因果探测立操作手册,
> 贝叶斯定理给"证据更新置信"立算法,休谟问题在门口立碑:
> 归纳的证成至今悬案。演绎保必然,归纳只保**支持度**。
> GB/T 13745 72040 逻辑学 · 三级。家族:[讲透逻辑学](../README.md)

## 诞生

- **谁/何时**:培根《新工具》(1620)立"归纳的旗帜";
  休谟《人性论》(1739)挖走地基(归纳不能证成归纳);
  密尔《逻辑体系》(1843)出版五法;贝叶斯定理(1763 遗稿)
  在 20 世纪被挖掘为"置信度演算"的主引擎。
- **因什么问题**:科学定律从有限观察来,凭什么对无限未来有效?
  演绎逻辑对此沉默(它只传递真,不生产真)——
  归纳逻辑的任务:给"生产新知"的推理立质量标准。

## 核心问题

**已解决**:
- 密尔五法:因果探测的实验设计语法(求异法=控制变量的逻辑原型)
- 贝叶斯更新:先验×似然→后验,置信度有了演算法则;
  古德曼"绿蓝"(grue)悖论逼出"哪些谓词可投射"的
  规律性标准问题——归纳理论最重要的当代催化剂

**未解决/深水区**:
- **休谟问题**(家族 00 章未决清单):归纳的证成——
  用归纳证归纳是循环,用演绎证归纳是范畴错误;
  实用主义/先验论证/贝叶斯路线各自挂账
- 先验的合法性:贝叶斯演算不管先验从哪来——
  "无信息先验"的设计仍是开放工程+哲学问题

## ✨ 这支最美的一个事实

**休谟拆掉的地基,贝叶斯在原地盖了新楼——但产权证没办下来**。
贝叶斯定理回答"**如何**更新置信"几乎无可挑剔(数学正文归
数学宇宙概率家族);休谟问的是"**凭什么该**这么更新"——
两百年两问各答各的,新楼照盖,地基问题照悬。
一个学科能带着未决的地基问题运转两百年,
这本身就是"归纳如何可能"的最佳 Exhibit。
