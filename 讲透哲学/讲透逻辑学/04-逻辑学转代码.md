> 总原则先立字据:**形式验证归数学宇宙,本家族管论证评估工具**——
> 证明检查器、SAT 求解器、定理证明助手住在

## 开篇:三台不同的机器

"逻辑+代码"在 2026 年意味着三台不同的机器,先分清免得串台:

1. **机器验证推理**(数学侧):形式系统内"这条证明对不对"——
   Coq/Lean/CDCL 求解器;前提是推理**已经是形式的**。
2. **机器评估论证**(本家族):自然语言论证"这段说理好不好"——
   谬误检测、论证挖掘、LLM 评审;前提是论证**还穿着自然语言的衣服**。
3. **机器模拟常识推理**(本家族×AI 侧):带默认与例外的推理
   "据新证据撤回旧结论"——非单调系统;经典逻辑装不下它。

本家族的代码领土是后两台;第一台的门票在姊妹家族手里。
三台的边界画在哪,就是 §一的正题。

## 一、可机械化边界(什么能转,什么转不动)

**能机械化(绿色区)**:

| 逻辑对象 | 代码化身 | 备注 |
|---------|---------|------|
| 三段论判定 | 周延规则引擎 | 本家族 `experiments/00_syllogism.py`:256 式三方对拍(走廊 0) |
| 论证结构 | 标准形/论证图数据格式 | 03 章三大构造物天然可序列化(走廊 2) |
| 型式检查 | 型式模板+批判性问题表 | Walton 型式表可直接入库,逐问打分(走廊 1) |
| 谬误的**结构性子类** | 规则触发(循环检测/前提缺失检测) | 环检测、隐前提显形是图算法,能做(走廊 1) |
| 非单调知识库 | 默认规则+论辩语义 | "鸟会飞,企鹅例外"的可撤销推理(走廊 3) |
| 对当方阵运算 | 真值/外延的穷举 | 小论域穷举=语义判定的袖珍版(实验脚本实验 3) |

**转不动的边界(红色区)**:

1. **语境可接受性不可全自动**:前提"该不该信"住在语境与认识论里
   (01 章主线 A 的 particularism 据点)。工程对策:
   评估器输出"支持度评分+所依据的 CQ 清单",把终裁权留给人。
2. **谬误标签的信度天花板**:人工标注"哪句是谬误"的一致率长期不高
   ——标签本身是构造物(03 章 §四)。工程对策:
   数据集必须报告标注一致率;检测器报告**置信区间**而非判决。
3. **修辞效力不可结构化**:同一论证图的语序变体说服力不同;
   结构评分≠论证价值(03 章反直觉)。工程对策:
   产品里永远把"结构分"与"文本质量分"分开两列。
4. **"扣谬误帽"的反驳幻觉**:机器说"检出诉诸权威"——
   但诉权威是合法型式,是否堕落要看 CQ 逐项敲的结果
   (argumentum ad logicam 的机器版)。工程对策:
   谬误检测器的输出必须携带型式+CQ 明细,禁止只报罪名。
5. **形式验证不在本家族权限内**:自然语言→一阶逻辑的翻译
   没有可靠全自动(量词/预设/辖域歧义);翻译件上的定理证明
   更是数学侧领土。工程对策:两宇宙分工协作
   (人工翻译/受限语料→数学侧求解器,见走廊 0 接口)。

## 二、代码走廊清单(一条接口走廊+三条主走廊)

### 走廊 0(接口走廊):三段论判定器——本家族↔数学宇宙的关隘

```
中文论证 ──标准形/classify()──▶ (格, 式)
   │                              │
   │                    ┌─────────┴──────────┐
   │                    ▼                    ▼
   │            周延规则判定(语法)      3 元论域穷举(语义)
   │                    └─────────┬──────────┘
   │                              ▼
   └──有效式拉丁名 + 反例外延(无效时)◀── 24/256 对拍
```

- **对象→结构**:词项逻辑是最老的**可判定系统**——
  `experiments/00_syllogism.py` 全流程:分类→规则判定→语义对拍→反例取证。
- **语义开关的工程含义**:存在预设(existential_import)一个参数,
  有效式 24↔15——**语义决策=产品决策**:做法律/医疗论证检查器,
  词项空类(如"所有未注册用户")怎么处理必须写成显式配置,
  否则判定结果隐含立场。这就是"逻辑系统的选型是立法行为"
  的工程版(00 章 §五假设表的直接兑现)。
- **与数学宇宙的接口**:三段论之外(多重量化/关系推理)→
  一阶逻辑→SAT/定理证明器,全部
  [../../讲透数学/讲透数理逻辑/](../../讲透数学/讲透数理逻辑/)
  04 章的求解器走廊;本走廊只管"词项逻辑这一格"
  (历史上它撑到 1879 年,工程上它撑到谓词出现为止)。

### 走廊 1:谬误检测——从罪名清单到型式+CQ 引擎

```
论证文本 ──标准形重构──▶ 前提/结论/推理标注
   │
   ├─结构性检查(可全自动):循环检测(图上找环)/隐前提缺失/
   │  联合支撑误用(AND 当 OR)
   │
   └─型式匹配(半自动):匹配 Walton 型式 → 加载 CQ 表
        → 逐问检查(可 LLM 辅助作答)→ 支持度评分+明细
```

- **对象→结构**:谬误=型式的堕落形态(03 章),检测器的主数据
  是**型式库+CQ 表**,不是 200 个罪名 one-hot。
- **算法层**:环检测/拓扑检查(图算法);型式匹配
  (模板/分类器);CQ 逐项作答(LLM 或人工)。
- **可检验命题**:①"结构性能捕获的谬误"(循环/不一致前提)
  规则引擎可全检;②"语义型谬误"(稻草人/不当类比)必须走
  型式+CQ 路线——两类谬误的自动化难度断崖,可被任意标注集
  分桶验证。
- **红色区重申**(§一-2/4):标签信度与扣帽幻觉是本走廊的
  两台事故机;产品上必须双列输出(结构分/型式明细)。
- **性能工程要点**:谬误数据集的**类别不均衡**(常见谬误淹没罕见谬误)
  与**定义漂移**(同名谬误各教材边界不同)先于模型选择——
  数据治理占本走廊八成功力。

### 走廊 2:论证图与论证挖掘——把 03 章构造物跑起来

```
语料 ──论证挖掘(ADU 切分:主张/前提分类)──▶ 论证图
   │                                            │
   ├─联合 vs 独立支撑判定(关系分类)          │
   ▼                                            ▼
结构指标(前提覆盖率/链深/断头链)      下游:评审辅助/审议平台/教学反馈
```

- **对象→结构**:03 章不变量直接变成数据校验
  (无环性 assert;联合/独立是边属性不是装饰)。
- **算法层**:ADU(argumentative discourse unit)切分与角色分类
  是论证挖掘的两步主线;结构指标全部可由图计算
  (链深=最长路径,断头链=出度 0 的前提节点)。
- **可检验命题**:①"好论证与好文章的结构指标可分吗"
  (教学场景:学生作文的断头链数量与人工评分的相关性);
  ②"论证图训练是否提升论证能力"(01 章主线 C 的方向锚:
  实证仍在积累,做实验时按预注册口径设计)。
- **红色区**(§一-1/3):ADU 切分的人工一致率低——
  挖掘管线的质量天花板是标注一致性;结构指标不可冒充文章质量。
- **性能工程要点**:联合/独立支撑是全管线最难的一步
  (它要求真正"读懂"缺一不可),预算分配别被切分任务吃光。

### 走廊 3:非单调推理——常识的机器模型

```
知识库 = 事实 + 默认规则(⇒,可带例外) + 优先序
   │
   ├─经典逻辑(单调):前提只增,结论永不撤回 ← 装不下常识
   │
   └─非单调:新增事实可触发例外 → 撤回旧结论
        例:鸟(x)⇒会飞(x);企鹅(x)→¬会飞(x);鸟(Tweety);企鹅(Tweety)
        ⇒ 先得"会飞",再撤回——"曾经合理"≠"最终结论"
```

- **对象→结构**:默认规则的"可撤销性"正是论辩语义的"幸存集"
  (03 章 §二结构 2):结论=当前攻击图的不动点;新证据改图→
  重新求解(数学正文:默认逻辑/优先语义/ASP,归
  [../../讲透数学/讲透数理逻辑/](../../讲透数学/讲透数理逻辑/)
  与 AI 知识表示;本家族管它的哲学账:撤回的"合理性"标准)。
- **纯标准库最小实现**(30 行起步):默认规则集+封闭世界假设+
  例外出触发回溯;assert 链:"加入企鹅事实后,会飞结论必须消失"
  ——非单调性的定义式测试。
- **可检验命题**:①经典单调解算器加"例外表+重算"能否逼近
  默认逻辑的直觉判定(小型可,规模化坍塌——为什么需要论辩语义);
  ②LLM 的常识回答是否表现非单调一致(给例外后能否稳定撤回
  先前结论——顺带连到 §三落点)。
- **性能工程要点**:非单调系统的重算代价(事实一变全图重评)
  是工程痛点,真值维护系统(TMS)是历史方案;
  2026 年的实用主义答案常是"LLM 生成+符号层校验"的双层架构
  (neuro-symbolic 的论证侧版本)。

## 三、工程师落点:LLM 的推理评估(本家族的前线阵地)

这是哲学侧逻辑学在 2026 年最直接兑现的工程职业方向——
**推理评估工程师/论证质量数据工程师**:给 LLM 的推理输出
定标准、造数据、建评测。

| 逻辑学装备(工程师已有) | 推理评估现场(可直接上岗) |
|------------------------|--------------------------|
| 有效性 vs 健全性(02 章 §三) | 评测双榜:推理链有效性榜 × 结论准确率榜——必须分开,合并即作弊 |
| 谬误=型式堕落(03 章) | 负样本构造:给合法型式注入堕落条件,得到可控的谬误数据(标签自带户口) |
| 批判性问题表(CQ) | 评审 rubric 的现成条目:LLM 评审员拿 CQ 表逐问打分,可解释可复核 |
| 论证图不变量(03 章) | 思维链的结构质检:前提覆盖率/断头链/循环——图算法全自动,先筛一道 |
| 非单调直觉(走廊 3) | "改前提后撤回结论"的一致性测试集:量 LLM 常识推理的刚性 |
| 实质蕴涵怪论(00 章) | 蕴涵类陷阱题的构造原理:形式对而直觉反的样本,专测模型对"如果"的语义 |

- **行业现场**:LLM 评测机构(推理/论证类基准)、内容安全与
  信息质量团队(谬误与操纵话术检测)、教育科技(作文论证自动反馈)、
  法律科技(论证检索与摘要——法学侧"法律逻辑学"的应用面,
  文字提及,互链待其家族建成)、智能体评估
  (agent 的决策理由质检:理由与行动的对齐审计)。
- **三步法(一个最小可行练习)**:
  直觉图像——找 20 条 LLM 回答,人肉标"结论对/推理对"四象限
  (对对/对错/错对/错错);严格陈述——用 02 章双榜+03 章型式表
  把四象限写成标注规范(什么算"推理错":无效?隐前提假?型式堕落?);
  最小例子——50 行 Python 做一个四象限统计器+一个
  "断头链检测器"(思维链里前提未被任何结论使用的句子),
  在自己标的数据上跑出第一张双榜。
- **为什么逻辑学训练在这里值钱**:评测的深坑从来不是写脚本,
  而是**标准立得稳不稳**——"什么叫好的推理链"这个 2400 岁
  的问题,现在以 ROI 的面目出现在每一次评测设计会上。
  particularism vs generalism(01 章主线 A)不是学究闲棋:
  它决定你的评测是规则引擎还是语境评审,决定预算怎么花。

## 四、可机械化的检验仪式(把本家族用成瑞士军刀)

遇到任何"论证/说理/评测"任务,做三问:
1. **形式问**:这段推理能剥出标准形吗?剥出后形状对吗
   (三段论判定/图校验可全自动)?
2. **语境问**:评价的关键项住在语境里吗(前提可信/举证义务)?
   住在语境里的项,机器只能给评分+明细,不能给终审。
3. **撤回问**:新证据来了,结论要不要撤?经典工具不撤——
   需要撤的场景立刻切非单调栈(走廊 3)。
三问过完,任何"逻辑+AI"项目的工具选型就定了——
剩下的才是调参。(对照西哲史家族的本体三问:
那边裸露范畴骨架,这边裸露**推理质检协议**。)
