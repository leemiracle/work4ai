# 讲透辩证逻辑 · 概念的自己运动——A∧¬A 在什么解读下有意义

> **定位句**:这支负责"**流动对象的推理形式**"——概念在发展中把握自身
> (正-反-合)、对立规定的统一("运动就是物体在同一瞬间既在这里又不在这里")。
> 与形式逻辑的关系是本家族最深的断层线:不是替代,是另一种提问——
> 形式逻辑问"断言间的关系",辩证逻辑问"概念如何把握过程"。
> GB/T 13745 72040 逻辑学 · 三级。家族:[讲透逻辑学](../README.md)

## 诞生

- **谁/何时**:柏拉图《巴曼尼得斯篇》的"一/多"辩证练习是远祖;
  康德二律背反(1781)把矛盾还给理性自身;黑格尔《逻辑学》(1812-16)
  立"概念自己运动"体系;马克思《资本论》叙述方法(从抽象上升到具体)
  是其社会科学应用;恩格斯/列宁笔记定型科目名。
- **因什么问题**:形式逻辑的同一律(A=A)以**抽象固定**为前提;
  而运动、发展、质变的对象恰是"正在变成别的东西的东西"——
  固定概念的剪刀剪不住流动的对象时,需要第二种思维工具。

## 核心问题

**已解决**:
- "抽象上升到具体"的叙述方法:起点范畴→展开矛盾→丰富到具体总体
  (《资本论》从"商品"到"资本总公式"的标准示范)
- 与形式逻辑的分工论:形式逻辑管**思维形式的正确性**(无矛盾),
  辩证逻辑管**思维内容的具体性**(把握对立统一)——各管一层,不争一职

**未解决/深水区**:
- **矛盾限定的判定程序**:哪类"A∧¬A"是过程性记录(运动/波粒二象),
  哪类是思维混乱?无公认手续——家族 00 章反直觉 2 的悬而未决版
- 形式化尝试的边界:弗协调逻辑(矛盾不爆炸)能否充当其形式骨架?
  文献并立无定论(形式正文归数学宇宙)

## ✨ 这支最美的一个事实

**芝诺悖论的两副面孔:形式逻辑的悖论,辩证逻辑的教科书**。
"飞矢不动"——形式视角:前提混淆"瞬间"与"区间",论证无效;
辩证视角:悖论精确暴露"运动=连续位置的不连续描述"的概念困境,
矛盾被当**诊断书**而非待清除的病毒。同一个芝诺,两种逻辑各取所需。

## 假设与依赖

- **过程性解读假设**:"A 且 ¬A"须限定在**不同规定性/不同阶段**上
  (波性/粒子性;此瞬间/彼瞬间)——不做限定的"无遮拦矛盾"
  连辩证逻辑自己也判为诡辩
- 辩证**法**(三大规律的哲学学说)归同波马克思主义哲学家族
  (72010,文字提及);本支只管**推理形式**侧
