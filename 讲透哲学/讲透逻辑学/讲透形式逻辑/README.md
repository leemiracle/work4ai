# 讲透形式逻辑 · 传统逻辑——三段论的引擎室,24/256 的故乡

> **定位句**:这支负责"**词项与命题的古典机器**"——概念(词项)、
> 判断(命题 A/E/I/O)、直接推理(换质换位)、三段论(格与式)、
> 周延规则。它是人类第一个**可判定的推理系统**,
> 也是本家族实验脚本 `experiments/00_syllogism.py` 的全部理论现场。
> GB/T 13745 72040 逻辑学 · 三级(形式逻辑/传统逻辑)。
> 家族:[讲透逻辑学](../README.md)

## 诞生

- **谁/何时**:亚里士多德《前分析篇》(前 350 前后)立格与式;
  中世纪补齐判定规则与 mnemonic;金岳霖《形式逻辑》(1960s)
> 定为中文世界标准教材——传统逻辑的中文正典化。
- **因什么问题**:给"什么样的推理由真只能到真"一个
  **纯形状的判定**——不问内容,只看词项的排列。

## 核心问题

**已解决**:
- **三段论有效性的判定**:4 格 × 64 式 = 256 候补,五条周延规则裁出
  24 个有效式——两千三百年前的完备判定算法
  (本家族实验脚本三方对拍验证:规则=穷举=教科书)
- 对当方阵(A/E/I/O 的真假关系表)、直接推理的换质换位系统

**未解决/深水区**:
- 表达力天花板:关系推理("A 比 B 高,B 比 C 高")、多重量化
  ("每个学生读过某本书")超出词项逻辑——正是弗雷格 1879 的动因
  (现代续篇归 [../../../讲透数学/讲透数理逻辑/](../../../讲透数学/讲透数理逻辑/))
- 存在预设的合法性:传统读法(词项非空,24 式)vs 现代读法
  (允许空类,15 式)——教材至今两说并存

## ✨ 这支最美的一个事实

**曲全公理一粒种子,长出 256 式的完整判定系统**——
"凡对全类所言,皆真于其每一分子"(dictum de omni et nullo)。
Barbara 只是它的一句话展开;五条周延规则只是它拆开的零件。
欧几里得《几何原本》的公理理想,第一次在**推理本身**上实现
(家族 00 章美之时刻 1 在本支成为全部正文)。
