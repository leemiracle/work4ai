# 讲透哲理逻辑 · 改公理的逻辑——模态、多值、构造、时态、模糊

> **定位句**:这支负责"**改动经典逻辑假设后得到的逻辑**"——
> 模态(必然/可能)、多值(不止真假)、构造(直觉主义拒斥排中律)、
> 时态(真值随时间)、模糊(高矮的边界带)。经典逻辑不是唯一的几何:
> 每改一条公理,得到一种新世界观。
> GB/T 13745 72040 逻辑学 · 三级(哲理逻辑:模态、多值、构造、时态、模糊逻辑等)。
> 家族:[讲透逻辑学](../README.md)

## 诞生

- **谁/何时**:麦加拉-斯多亚学派早已讨论"可能/必然"(带角论证);
  刘易斯 1918 立严格蕴涵与模态系统 S1-S5;乌卡谢维奇 1920 立三值逻辑
  (未来偶然句取第三值);海廷 1930 形式化直觉主义逻辑;
  扎德 1965 模糊集合(模糊逻辑的数学基座)。
- **因什么问题**:每支都始于经典逻辑的一条"翻车现场"——
  实质蕴涵怪论逼出模态/相关;"明天海战"逼出多值;
  排中律的非构造性逼出直觉主义;"高个子的边界"逼出模糊。

## 核心问题

**已解决**:
- Kripke 语义(1963):模态逻辑的可能世界语义——"必然=在所有可及世界真",
  模态系统的谱系从此可判定可比较
- 多值/模糊的真值表工程:三值到 n 值到 [0,1] 区间值的推广
  (数学正文与代数结构归数学宇宙,本支取哲学面)

**未解决/深水区**:
- 模态形而上学:可能世界是发现还是工具?(刘易斯实在论 vs 工具论)
- 模糊逻辑的连锁悖论(sorites):一粒沙不成堆,为何万粒成堆?
  超真值/认识论/模糊逻辑诸方案并立,无共识
- 直觉主义的哲学边界:"排中律失败"是数学事实还是态度选择?

## ✨ 这支最美的一个事实

**"如果排中律不成立,推理还剩下什么?"——海廷的回答:全须全尾**。
直觉主义逻辑不删经典定理的"多数",它把每个经典定理翻译成
构造性版本(A∨¬A 变成"可判定性断言")——换一种证明观(证明=构造),
整座大厦换了地基却仍能住人。逻辑不是天然的一神教:
不同公理=不同的"什么算证明"。
