## 一、库恩框架回顾（recap）

### 1.1 库恩的范式转移模型

```
① 常规科学（normal science）
    ↓
② 异常累积（anomalies）—— 老范式解释不了的现象
    ↓
③ 危机（crisis）—— 学术圈分裂、信任流失
    ↓
④ 范式转移（paradigm shift）—— 新范式诞生
    ↓
⑤ 新常规科学
```

### 1.2 关键概念

- **范式（paradigm）**：学术圈共享的假设 + 方法 + 价值观
- **不可通约性（incommensurability）**：新旧范式之间无法完全翻译
- **异常（anomaly）**：老范式解释不了的现象
- **危机（crisis）**：异常累积到信任崩塌

## 二、AI 史的五次范式转移

### 2.1 第一次：控制论 → 符号主义（1956）

| 维度 | 控制论（1940s-1955）| 符号主义（1956-1985）|
|---|---|---|
| **核心假设** | 智能来自反馈网络 | 智能来自符号操作 |
| **代表** | Wiener / McCulloch / Ashby | McCarthy / Newell / Simon / Minsky |
| **方法** | 微分方程 / 神经网络 | 逻辑 / LISP / 启发式搜索 |
| **触发异常** | 控制论难处理高层认知（语言、推理）| — |
| **危机标志** | 没有具体"危机"——Dartmouth 是发起 | — |
| **新范式触发** | **Dartmouth Conference 1956** | — |

**库恩视角**：
- 这次转移**特殊**——不是"危机驱动"，是**主动发起**
- McCarthy 等 4 人**主动定义新范式**——罕见
- "AI" 一词本身就是**营销产物**——为申请经费造词

### 2.2 第二次：符号主义 → 连接主义（1969-1986）

| 维度 | 符号主义（顶峰）| 连接主义复兴 |
|---|---|---|
| **顶峰** | 1970s 专家系统 | — |
| **触发异常** | 专家系统维护成本爆炸（XCON 几千条规则）| XOR / 反向传播 / Hopfield 网络 |
| **危机标志** | Lighthill Report 1973 / 第二次寒冬 1987 | — |
| **新范式触发** | — | **Rumelhart-Hinton-Williams 1986**（反向传播）|
| **不可通约性** | "符号 vs 神经元" 是不同语言 | — |

**库恩视角**：
- 这次是**经典危机驱动**——专家系统的失败累积，符号主义信任崩塌
- 反向传播（1986）+ Hopfield（1982）共同触发
- 老一辈（McCarthy/Minsky）**几乎没转向**——Minsky 终生是符号派

### 2.3 第三次：连接主义 → 概率派（1995）

| 维度 | 连接主义（1980s 末）| 概率派 + 统计学习（1990s）|
|---|---|---|
| **顶峰** | 反向传播复活 | — |
| **触发异常** | 算力不够跑不动深网络；过拟合 | SVM / Boosting 在小数据胜出 |
| **危机标志** | 神经网络被边缘化（"voodoo"）| — |
| **新范式触发** | — | **Vapnik SVM (1995) / Pearl 因果 (2000)** |
| **不可通约性** | "可学习性 vs 因果性"不同语言 | — |

**库恩视角**：
- 这次转移**不是危机驱动**——是**新方法在小数据胜出**
- 概率派和连接主义**共存**了 10-15 年
- **数据挖掘 / 统计学习**成为工业界主流

### 2.4 第四次：概率派 → 深度学习（2012）

| 维度 | 概率派 + 统计学习 | 深度学习 |
|---|---|---|
| **顶峰** | 2000s SVM/RF 主导工业 | — |
| **触发异常** | 高维数据（图像/语音）特征工程爆炸 | AlexNet 大幅超越 |
| **危机标志** | ImageNet 2012——SVM 被吊打 | — |
| **新范式触发** | — | **AlexNet (2012) + GPU + ImageNet 数据** |
| **不可通约性** | "手工特征 vs 端到端学习" | — |

**库恩视角**：
- 这次是**算力 + 数据 + 算法**三重到位——AlexNet 不是孤立突破
- Hinton/Bengio/LeCun 三巨头坚持了 20+ 年——**老一辈反而成新范式**
- Vapnik 等老派**有抗议**——"为什么需要深度？"——但被边缘化

### 2.5 第五次：深度学习 → 大模型 / Foundation Model（2017-2020）

| 维度 | 深度学习（窄模型）| Foundation Model（大模型）|
|---|---|---|
| **顶峰** | ResNet / GAN / BERT | — |
| **触发异常** | 任务特异性（每任务一个模型）| GPT-3 few-shot——通用 |
| **危机标志** | "每任务训一个模型"成本爆炸 | — |
| **新范式触发** | — | **Transformer (2017) + GPT-3 (2020)** |
| **不可通约性** | "窄 vs 通用"，"任务 vs 涌现" | — |

**库恩视角**：
- 这次是**新概念**——"涌现"和"few-shot"是范式内新词
- "Foundation Model"（2021 Stanford）是**主动造词**——像 1956 McCarthy
- 大模型范式**正在统治**——但有反抗（LeCun JEPA、Pearl 因果派）

## 三、五次转移的共同模式

观察 5 次转移，找规律：

### 3.1 触发器类型

| 类型 | 例子 |
|---|---|
| **危机驱动**（库恩经典）| 符号主义→连接（专家系统失败）|
| **算力驱动** | 概率派→深度（GPU 到位）|
| **数据驱动** | ImageNet / 互联网数据 |
| **主动发起**（罕见）| 控制论→符号（Dartmouth）/ 深度→FM（Stanford 造词）|

### 3.2 老一辈的命运

| 模式 | 例子 |
|---|---|
| **终生不转**（库恩经典观察）| McCarthy 终生符号派 / Vapnik 抗议深度 |
| **转向**（罕见）| Hinton 从统计学习转向深度 |
| **发起者即老一辈**（罕见）| Hinton/Bengio/LeCun 是连接主义老一辈，发起深度学习 |

**库恩名言**："Paradigm changes do cause scientists to see the world differently... But they are not transformed, nor do they simply see what they have been looking at all along."（范式转移让科学家看到不同世界——但他们不会转变，也不会突然看清自己一直在看的东西。）

### 3.3 不可通约性

每次范式转移，**新旧语言无法完全翻译**：
- 符号主义的"知识"≠ 连接主义的"权重"
- SVM 的"margin"≠ 深度学习的"特征学习"
- FM 的"涌现"≠ 窄模型的"性能曲线"

**博士级洞察**：**跨范式辩论几乎总是鸡同鸭讲**——双方用的是同一个词，意思不同。

### 3.4 范式不消失，被吸收

- **符号主义**：在 Knowledge Graph / Neurosymbolic / AlphaProof 复活
- **连接主义**：演化为深度学习
- **概率派**：贝叶斯网络仍在用；变分推断是 VAE 的祖父
- **统计学习**：SVM/RF 仍是工业基线

> 🎯 **博士级核心**：**没有任何范式真正死亡**——它们被新范式吸收或边缘化，但思想资源长存。

## 四、第六次范式转移的可能

### 4.1 当前大模型范式的"异常"

```
异常 1: 数据墙 —— 公开数据快训完（详见 讲透数据）
异常 2: 能耗 —— 训 GPT-5 耗电几千万度
异常 3: Model Collapse —— 合成数据退化（详见 讲透数据/03）
异常 4: 安全风险 —— deceptive alignment 难解
异常 5: 评估失效 —— benchmark 污染（详见 讲透科学的现代性/02）
异常 6: 理论空白 —— scaling law 无物理解释（详见 讲透基础模型/advanced/01）
```

**6 个异常在累积**——大模型范式可能在 5-15 年内进入危机。

### 4.2 候选新范式

| 候选 | 触发可能 | 抵抗 |
|---|---|---|
| **Neurosymbolic**（神经符号融合）| AlphaProof 的成功 | LLM 团队不愿引入符号 |
| **Causal AI**（因果 AI）| Pearl 的长期呼吁 | 工程上难落地 |
| **World Model / JEPA** | LeCun 路线 | 还没工业证明 |
| **Energy-based Models** | LeCun 反复推 | 难训练 |
| **量子 ML** | 硬件未到位 | 5-15 年外 |
| **生物启发 / 神经科学回归** | 神经形态芯片 | 太早期 |

### 4.3 历史规律的预测

基于 5 次范式转移的模式：
- **下一次转移可能在 2028-2035**（10-15 年周期）
- **可能由算力/数据天花板驱动**（不是单纯算法突破）
- **可能由年轻一代 PhD 主导**（库恩定律）
- **新范式不一定让旧范式死**——LLM 可能被吸收

> ⚠️ **博士级警示**：**任何"X 是未来"的宣称都要警惕**——历史告诉我们预测经常错。1960s 说"20 年 AGI"，1970s 说"10 年"，1980s 说"5 年"——**全错**。

## 五、博士级研究方法论

### 5.1 怎么用历史训练判断力

**真实测试**：你看到一篇"突破"论文/产品，问自己：

1. **这个想法的前世是什么**？1970s 有过吗？
2. **为什么此时此地爆发**？算力/数据/评测到位？
3. **谁在推动**？年轻 PhD 还是老一辈？机构背景？
4. **失败模式可能是什么**？类似历史上的哪次？
5. **5 年后还会被记住吗**？

### 5.2 怎么读范式转移型论文

读 AlexNet / Transformer / BERT 时：
- **不只看方法**，看**为什么此时此地**
- 找**早期引用**——谁是先驱？
- 找**抵抗者**——谁反对？为什么？
- 找**吸收过程**——老方法怎么被吸收

### 5.3 怎么避免历史重演

读 RAG 时想：**1970s 专家系统怎么处理知识库的？** 失败模式相似吗？
读 Agent 时想：**1980s 分布式 AI / 黑板系统**怎么失败的？
读 World Model 时想：**1980s 第五代计算机**怎么泡沫化的？

## 八、一句话总结

> 🎯 **博士级五句话**：
> 1. **AI 史至少 5 次范式转移**：控制论→符号(1956)→连接(1986)→概率(1995)→深度(2012)→大模型(2017)。
> 2. **共同模式**：危机/算力/数据/主动发起驱动；老一辈少转变；不可通约性高；老范式被吸收。
> 3. **当前大模型范式有 6 个异常累积**——下次转移可能在 **2028-2035**，候选：Neurosymbolic / Causal AI / World Model / EBM / 量子 ML。
> 4. **博士级训练**：用历史看当前——任何"X 是未来"警惕，**预测经常错**。
> 5. **博士级核心**：**没有任何范式真正死亡**——它们被吸收或边缘化，但思想资源长存。
