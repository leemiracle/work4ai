# 第一幕 · 直觉：36 仓 = 1 个系统

## 1. 三条设计直觉（读完全部底稿后剩下的话）

### 直觉一：稀疏性是第一性原理，且不限于 MoE

把五条技术线并排看，会发现 DeepSeek 反复在做同一件事——**把"全量计算"换成"按需激活"**：

| 层 | 全量版本 | 稀疏版本 | 稀疏机制 |
|---|---|---|---|
| 参数（MoE） | dense 671B | 激活 37B | sigmoid top-8 + 组限制路由 |
| 注意力（DSA） | O(L²) | O(L×2048) | Lightning Indexer top-2048 |
| KV 存储（MLA） | 128 头 × 全维 | 每 token 576 维 | 低秩潜在压缩（−93.3%） |
| 记忆（Engram） | 全词表进权重 | 哈希寻址查表 | 128k 词表压缩 23% + 零 FLOPs 扩容 |
| 微调（ESFT） | 全参微调 | 4-6/64 专家 | 激活统计选专家（~7% 参数） |
| 生成（OCR） | 整页像素 | ~795 token | 上下文启发式光学压缩 |

**这不是六个巧合，是一个品味**：Engram 论文自己就把条件记忆称作"第二稀疏轴"（A New Axis of Sparsity）。当一家公司把稀疏性从 MoE 一路推进到记忆和微调，它就是在把同一个数学信念铺满全栈。

### 直觉二：确定性优于搜索

- DeepGEMM 不 autotune，用 L1/L2 带宽解析式直接算 tile 尺寸；
- FlashMLA 用 FLOPs/byte 判据选 seesaw 调度而非试跑；
- DeepEP V2 用 SM 读/写带宽公式（×1.25 余量）算 SM 配额；
- 3FS 把恢复期放置问题形式化为整数规划（BIBD + Pyomo/HiGHS）；
- Prover 用 Lean 验证器替代神经网络奖励；
- Engram 用确定性哈希寻址（而非学习检索）换"100B 参数表驻 DRAM + PCIe 预取"。

**翻译**：在已知硬件（H800 集群）上，DeepSeek 相信"算得出"胜过"搜得到"。这与学术界的 autotune/NAS 文化是鲜明对照——底稿 B 称之为"封闭已知集群上的全局最优"策略。

### 直觉三：评测诚信是组织人格，不是合规动作

V1 拒用中文多选题刷分（MMLU 60.9 也不用）、OCR 公布对自己不利的压缩边界（20×→60%）、OCR-2 披露 mBART 方案不收敛、Math 公布 arXiv 语料无增益、DeepSpec 笔记纠偏社区误传、Prover-V2 注记论文与 README 的 47 vs 49 分歧。**负结果的公开发布=向生态注入负熵**，这是复杂系统视角下最稀缺的开源行为。

## 2. 咬合图：为什么说"相互咬合"

```
        宪法层：激活成本第一 + 稀疏性第一性 + 解析式方法论
                          │
   ┌──────────┬──────────┼──────────┬──────────┐
   模型线      内核线       通信线      存储线      应用线
   V1→V3.2   DeepGEMM    DeepEP     3FS        R1/Coder/
   MLA/MoE/  FlashMLA    DualPipe   smallpond  Math/Prover
   MTP/DSA   TileKernels EPLB/LPLB  (KV缓存     OCR/dsh
                          profile    56.3%命中)
                          │
        约定层：per-128 FP8 标度贯穿 dispatch/GEMM/KV/量化四层
        证据层：profile-data 把生产内核名（per_token_cast_to_fp8_
                with_channels<bf16,128>）留给公众核对
```

**咬合的判据**：外部拼装的开源栈（如任意公司用 vLLM+Ray+Lustre）不可能出现"量化标度四层一致""通信库内嵌与 GEMM 同族的 cast 内核"这种级联一致性。这是"一次设计"vs"一堆组件"的可证伪区别。

## 3. 历史动力学：四波开源的温度曲线

2023-11（V1/Coder）→ 2024-12（V3）→ 2025-01~09（R1+infra 大爆发）→ 2025-10~2026-08（新轴：OCR/Engram/OCR-2/dsh）。
用《复杂系统迭代》的语言：前两波是**探索期高 T**（架构革命），第三波是**固化期低 T**（把已验证的 V3 底座固化开源），第四波又升温（Apache 协议切换的三仓=新探索的标记）。**开源节奏本身就是温度计**——详见元理论文件 §6 增补。

## 4. 一个反直觉收束

> 星王不是 V3 也不是 R1，而是仓龄两天的 deepseek-harness（104k）。**模型公司最被需要的产出，正在从"权重"迁移到"壳"**——这与 Harness 镜（topic:harness 37 仓、54% 创建于 2026）的赛道级相变互证：当模型能力商品化，组织价值的护城河回到 harness 层的信任平面（沙箱/审批/事件溯源）。DeepSeek 两头下注（自建 dsh + 教用户把模型接进 Claude Code）是对议价权的对冲。
