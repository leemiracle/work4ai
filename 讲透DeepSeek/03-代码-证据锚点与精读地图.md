## 2. 最值得打开的文件（20 小时主干路径）

### 第 1 站：`DeepSeek-V3/inference/model.py`（808 行）
单文件全景：MLA absorb 实现、Gate 类 aux-loss-free 路由（L564-594）、MTP 模块（eh_proj 拼接）、sigmoid+route_scale。**性价比最高的一站**——四条技术线在一处交汇。

### 第 2 站：`DeepGEMM/deep_gemm/`（JIT 内核）
看 `BLOCK_K==128` 静态断言与 cost model（L1/L2 cycle 解析式）；对照 `tests/` 的性能脚本理解 1550 TFLOPS@H800 怎么测。

### 第 3 站：`FlashMLA/`（两处）
`README.md` 的 seesaw 调度示意（64×512 输出超寄存器一半 → 劈 O_L/O_R 交错 11 步）+ 源码里的 64×64 TMA copy 流水与 EVICT_FIRST。

### 第 4 站：`DeepEP/`（dispatch/combine）
`LEGACY_NUM_MAX_NVL_PEERS=8`（NVLink 域）→ 低延迟内核的纯 RDMA 路径与 QP=专家数约束 → hook 的 SEND/RECV_PHASE 拆分（解码 0 SM 占用的出处）。

### 第 5 站：`3FS/`
按底稿 C 的「源码模块地图」走：`specs/`（微软 P 语言对 CRAQ 的模型检查——**用形式化方法验证分布式协议的开源孤例**）→ `src/storage/chunk_engine/`（Rust 重写的 chunk→group→file→disk 层级）→ `deploy/data_placement/`（整数规划放置）。

### 第 6 站：`DeepSpec/`（投机解码工厂）
`trainer` 的损失三件套（0.1CE+0.9L1 分布距离+置信头 BCE，理论接受率 1−0.5Σ|p_d−p_t| 直接进损失）；对照 E 底稿的"社区传闻纠偏清单"。

### 第 7 站：`DeepSeek-Prover-V2/` + `DeepSeek-Math-V2/`
读 README 的课程构造（V3 出 `have sorry` 骨架→7B 递归解子目标）与 verifier rubrics 设计；Math-V2 的"提示内嵌评委 rubrics"是 reward hacking 的教科书反制。

### 第 8 站：`deepseek-harness/`
`vendor/README.md`（18 条本地修改审计——vendor 第三方代码的诚实范本）→ `docs/capability-seams.md`（~60 个 ctx key 能力表）→ 会话事件溯源（"Model-visible⟺logged" 运行时断言）。深入走 Agent框架案例 16 篇。
