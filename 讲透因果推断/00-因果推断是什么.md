# 00 · 因果推断是什么

> **第一性问题**：冰淇淋销量和溺水人数高度相关——**吃冰淇淋导致溺水吗**？
>
> 显然不是。两者都被第三个变量（**夏天**）共同影响。这是**因果 vs 相关**的最经典例子。
>
> **核心问题**：怎么用数学严格区分相关与因果？怎么从观察数据**推断因果**？
>
> 配套：[`讲透概率图模型`](../讲透概率图模型/) + [`讲透世界模型`](../讲透世界模型/) + [`讲透科学的现代性/03`](../讲透科学的现代性/03-AI时代的科学哲学.md)

---

**1995 年，UCLA 计算机系。** Judea Pearl 50 多岁，已是贝叶斯网络之父（1985 那篇开创性论文让他成名）。但他最近十年转向了一个更难的问题：**因果**。统计学家告诉他"因果不是数学，是哲学，别碰"；经济学家告诉他"我们用工具变量凑合"；AI 同行说"机器学习只要相关就够"。Pearl 不接受。他花了 10 年把"因果"严格化为 do-calculus 三条公理，2011 年因此拿 Turing 奖。今天，他"从相关中推断因果"的整套语言，正是 RLHF、world model、AlphaProof 等所有"AI 理解世界"路线的隐藏地基。这就是本系列的全部起点：**没有因果，AI 永远只在做统计**。

---

## 一、为什么相关 ≠ 因果

### 1.1 相关（correlation）

$$\text{Corr}(X, Y) = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

**性质**：对称——$\text{Corr}(X, Y) = \text{Corr}(Y, X)$。

**局限**：不能区分"$X$ 导致 $Y$"、"$Y$ 导致 $X$"、"$Z$ 导致两者"。

### 1.2 因果（causation）

**性质**：**不对称**——"吸烟导致肺癌" ≠ "肺癌导致吸烟"。

**Pearl 的反例**：气压计读数下降 + 下雨——两者相关，但**气压计读数不导致下雨**。

### 1.3 为什么 ML 只学到相关

监督学习的目标：$P(Y|X)$。这是**条件分布**——纯统计。

- LLM 学到 $P(\text{下一个 token} | \text{前文})$
- 分类器学到 $P(\text{标签} | \text{图像})$

**都没学到**"$X$ 怎么**导致** $Y$"——只是观察相关。

> 🎯 **Pearl 的批评**："深度学习只是曲线拟合"——所有监督学习都只是统计相关，没有因果。

## 二、Pearl 的因果阶梯

**Judea Pearl**（《Causality》2000）的因果三层级：

| 阶梯 | 问题 | 例子 |
|---|---|---|
| **L1 观察（Seeing）** | "如果我观察 X，Y 怎样？" | 看到乌云 → 估计下雨概率 |
| **L2 干预（Doing）** | "如果我做 X，Y 怎样？" | **撒碘化银** → 下雨吗？|
| **L3 反事实（Imagining）**| "如果当时没做 X，Y 会怎样？" | **如果当时没撒**，会下雨吗？|

### 2.1 当前 ML 在哪一级

- 监督学习：**L1**
- 强化学习：**L2**（部分）
- LLM agent：**L2**（部分）
- **反事实（L3）几乎没人做**

### 2.2 为什么反事实（L3）最难

L3 需要回答**"另一种现实"**——但数据里只有"已发生的现实"。

**例**："如果我当年没读这个大学，现在会怎样？"

数据里没有"另一种现实"——需要**因果模型**才能推断。

---

## 三、Pearl 的结构因果模型（SCM）

### 3.1 结构方程

$$X_i := f_i(\text{parents}(X_i), U_i)$$

- $:=$ 是**赋值**（不是等式）——方向性
- $U_i$ 是外生噪声

**关键**：等式右边决定左边——这是**因果方向**。

### 3.2 do 算子

**do(X=x)**：**强制** $X = x$（外部干预），不是观察 $X = x$。

$$P(Y | do(X=x)) \neq P(Y | X=x) \text{（一般情况）}$$

**例**：
- $P(\text{雨} | \text{气压计}=低)$：观察气压计低，估计下雨——相关
- $P(\text{雨} | do(\text{气压计}=低))$：**敲坏气压计让它低**——下雨概率不变（气压计不导致雨）

### 3.3 do-calculus 三规则

Pearl 证明：**任何可识别的因果量**可以用 do-calculus 三规则化简为观察量。

```
规则 1（插入/删除观察）
规则 2（行动/观察交换）
规则 3（插入/删除行动）
```

**意义**：**因果推断可以机械化**——给图 + 数据，算法能判定能不能算因果效应。

## 四、Rubin 的潜在结果框架

**Donald Rubin**（1974）的另一套数学——和 Pearl 等价但语言不同。

### 4.1 潜在结果

对每个个体 $i$：
- $Y_i(1)$：如果接受 treatment（$T=1$）的结果
- $Y_i(0)$：如果不接受（$T=0$）的结果

**因果效应**：$\tau_i = Y_i(1) - Y_i(0)$

**问题**：**永远只观察到一个**——个体不可能同时 $T=1$ 和 $T=0$。

### 4.2 平均处理效应（ATE）

$$\text{ATE} = \mathbb{E}[Y(1) - Y(0)]$$

**估计方法**：

| 方法 | 思路 |
|---|---|
| **RCT（随机对照）** | 随机分配 T → 消除混杂 |
| **倾向得分匹配（PSM）** | 匹配相似个体 |
| **逆概率加权（IPW）** | 用 $1/P(T|X)$ 加权 |
| **Doubly Robust** | IPW + 回归，任一对就行 |

## 五、因果图与后门准则

### 5.1 因果图（causal DAG）

```
例子：吸烟 → 肺癌
       ↓     ↓
      黄牙   咳嗽

观察"黄牙"和"肺癌"相关——但黄牙不导致肺癌（混杂）
```

### 5.2 后门准则

**判断**：从 $X$ 到 $Y$ 的因果效应能否从观察数据识别？

**后门路径**：任何 $X \leftarrow \cdots \rightarrow Y$ 的路径（箭头指向 $X$）。

**准则**：如果能找到一个变量集 $Z$ **阻断所有后门路径**，则：

$$P(Y | do(X)) = \sum_Z P(Y | X, Z) P(Z)$$

——后门调整公式。

## 六、因果发现（causal discovery）

**问题**：从观察数据**自动学因果图**。

### 6.1 主要算法

| 算法 | 思路 |
|---|---|
| **PC 算法** | 条件独立测试 + DAG 假设 |
| **FCI** | 允许隐变量 |
| **NOTEARS** | 连续优化（2018 突破）|
| **LiNGAM** | 非高斯假设下的因果 |

### 6.2 难度

**基本定理**（Pearl）：仅靠观察数据，**只能学 Markov 等价类**——不能区分 $A→B$ 和 $B→A$（如果都是 DAG-compatible）。

**突破**：需要**额外假设**（非高斯 / 非线性 / 时间序列）。

## 七、AI 中的因果——当前热点

### 7.1 LLM 有因果吗

**争论**：
- **支持**：LLM 能回答"如果 X 会怎样"的反事实问题（部分）
- **反对**：LLM 只是统计模式，没有真因果模型

**实测**：LLM 在简单因果推理上接近人类，复杂场景失败。

### 7.2 Causal Representation Learning

**目标**：学表示同时学因果结构。

**代表**：Schölkopf 团队（Max Planck）的 IRM / Causal RL。

## 九、一句话总结

> 🎯 **四句话**：
> 1. **相关 ≠ 因果**——监督学习只学到 L1（观察），缺 L2（干预）/ L3（反事实）。
> 2. Pearl 的 SCM + do-calculus / Rubin 的潜在结果——两套等价数学。
> 3. **后门准则**：能不能从观察数据识别因果效应。
> 4. **当前 AI 缺因果**——Pearl 长期批评；Causal AI 是 2024+ 前沿。

## 费曼回炉记录（L2 自检）

- **F2 卡壳点**：我长期卡在"$P(Y|do(X))$ 和 $P(Y|X)$ 到底哪里不一样"——直觉上"做 X"和"看到 X"不就是一回事吗？重读 Pearl 气压计例子才顿悟：**观察是被动的**（你看到气压计低，意味着气压低，气压低意味着要下雨，所以 $P(\text{雨}|\text{气压计}=低)$ 高），**干预是主动的**（你把气压计砸到低读数，气压没变，雨该不下还是不下，所以 $P(\text{雨}|do(\text{气压计}=低)) = P(\text{雨})$）。差异的根源是：观察告诉你"现在世界处于什么状态"，干预改变了世界状态本身。$do$ 算子切断了指向 $X$ 的所有因果箭头——这是 Pearl 的天才一笔。
- **F3 术语翻译**：
  - "混杂（confounding）" → 同时影响"因"和"果"的第三变量，像夏天同时推高冰淇淋销量和溺水人数，让你误以为吃冰淇淋导致溺水
  - "后门路径" → 从因变量倒着流回果变量的"漏电小路"（箭头指向因变量），必须用条件变量堵住它，否则估计出来的是相关不是因果
  - "反事实（counterfactual）" → "如果当时没做 X 会怎样"——数据里永远没有这种"平行宇宙"的样本，只能靠结构因果模型 $Y_x(u)$ 推断
- **F4 回炉**：v1 我把 Pearl 的 SCM 和 Rubin 的潜在结果框架写成"两套竞争理论"——这是**对立误读**。v2 改成"两套**数学等价**但语言不同的框架：Pearl 用图 + 结构方程，Rubin 用 $\{Y(0), Y(1)\}$ 配对；Pearl 的 $P(Y|do(X))$ 在无混杂时等于 Rubin 的 ATE 估计。Pearl 自己在《Causality》§3 里证明了这个等价"。diff：从"对立"改为"同构不同语言"，对应 §四 Rubin 框架末尾的"等价但语言不同"。

## 🎭 欺骗动力学视角：相关冒充因果

> 承接 [`欺骗动力学-社会进步的隐秘引擎.md`](../欺骗动力学-社会进步的隐秘引擎.md) §5。

### 三问

1. **讲透因果推断 防的是什么欺骗？** → 观察到的相关性被误读为因果性。
2. **被什么攻破？** → 混杂偏倚 / 选择偏倚 / 工具变量失效。
3. **沉淀进哪条主链？** → 验证主链——因果识别把「相关」升级为「可干预的因果」，是反数据欺骗的核心工具。

### 一句话

> 统计学最大的欺骗是「相关不等于因果」，因果推断这门学科的全部存在理由就是反这种欺骗。
